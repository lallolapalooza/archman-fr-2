NOM

mpathpersist - Gère les réservations persistantes SCSI sur les périphériques dm-multipath.

SYNTAXE

mpathpersist [OPTIONS] périphérique

DESCRIPTION

Cet utilitaire est utilisé pour gérer les réservations persistantes SCSI sur les périphériques Device Mapper Multipath. Pour pouvoir utiliser cette fonctionnalité, l'attribut reservation_key doit être défini dans le fichier /etc/multipath.conf. Sinon, le démon multipathd ne vérifiera pas les réservations persistantes pour les chemins nouvellement découverts ou rétablis.

mpathpersist prend en charge les mêmes options en ligne de commande que l'utilitaire sg_persist. Consultez la page de manuel de sg_persist (8) pour une discussion approfondie des différentes options.

OPTIONS

1

2
Messages d'avertissement.
3
Messages d'information.
4
Messages d'information avec suivi activé.
--périphérique=PÉRIPHÉRIQUE|-d PÉRIPHÉRIQUE
Interroge ou modifie le PÉRIPHÉRIQUE.
--fichier-lot=PÉRIPHÉRIQUE|-f FICHIER
Lit les commandes depuis le FICHIER. Voir la section « FICHIERS BATCH » ci-dessous. Cette option ne peut être donnée qu'une seule fois.
--aide|-h
Affiche ce message d'utilisation.

Affiche la réponse en hexadécimal.

EXEMPLE

Enregistrer la clé « 123abc » pour le périphérique /dev/mapper/mpath9 :

mpathpersist --out --register --param-sark=123abc /dev/mapper/mpath9

Lire les clés de réservation enregistrées pour le périphérique /dev/mapper/mpath9 :

mpathpersist -i -k /dev/mapper/mpath9

Créer une réservation pour le périphérique /dev/mapper/mpath9 avec la clé de réservation donnée :

mpathpersist --out --reserve --param-rk=123abc --type-prout=8 -d /dev/mapper/mpath9

Lire l'état de la réservation du périphérique /dev/mapper/mpath9 :

mpathpersist -i -s -d /dev/mapper/mpath9

Libérer la réservation précédemment créée (notez que le type de commande doit être le même que ci-dessus) :

mpathpersist --out --release --param-rk=123abc --type-prout=8 -d /dev/mapper/mpath9

Supprimer la clé actuellement enregistrée pour cet hôte (c'est-à-dire la réinitialiser à 0) :

mpathpersist --out --register-ignorer -K 123abc -S 0 /dev/mapper/mpath9

Supprimer la réservation actuelle et désenregistrer toutes les clés enregistrées de tous les nexus I_T :

mpathpersist -oCK 123abc /dev/mapper/mpath9

FICHIERS BATCH

L'option --fichier-lot (-f) définit un fichier d'entrée à traiter par mpathpersist. Le regroupement des commandes dans des fichiers batch peut offrir un gain de vitesse, en particulier sur de grandes installations, car mpathpersist n'a besoin d'analyser les chemins et les maps existants qu'une seule fois au démarrage.

Le fichier d'entrée est un fichier texte analysé ligne par ligne. Chaque ligne du fichier est interprétée comme une ligne de commande (c'est-à-dire une liste d'options et de paramètres) pour mpathpersist. Les options et les paramètres sont séparés par un ou plusieurs espaces blancs (espace ou TAB). Les lignes peuvent, mais ne doivent pas, commencer par le mot « mpathpersist ». Le caractère « # », soit au début de la ligne, soit après un espace blanc, dénote le début d'un commentaire qui dure jusqu'à la fin de la ligne. Les lignes vides sont autorisées. La continuation des commandes mpathpersist sur plusieurs lignes n'est pas prise en charge.

Toutes les options listées dans cette page de manuel, à l'exception de -f et -v, sont autorisées dans les fichiers batch. Les formats d'options courts et longs peuvent être utilisés. L'utilisation de l'option -f à l'intérieur du fichier batch est une erreur. L'option -v est ignorée dans les fichiers batch.

La map multipath sur laquelle agir doit être spécifiée sur chaque ligne d'entrée, par exemple en utilisant l'option -d. Des commandes agissant sur différentes maps multipath peuvent être combinées dans un fichier batch, et plusieurs commandes peuvent agir sur la même map multipath. Les commandes sont exécutées une par une, de sorte que les commandes situées plus loin dans le fichier voient les changements d'état causés par les commandes précédentes. Si mpathpersist rencontre une erreur lors du traitement d'une ligne dans le fichier batch, le traitement du fichier batch n'est **pas** interrompu ; les commandes suivantes sont néanmoins exécutées. Le code de sortie de mpathpersist est le code de sortie de la première commande échouée, ou 0 si toutes les commandes ont réussi.

Si d'autres options et paramètres sont utilisés avec -f sur la ligne de commande mpathpersist, la ligne de commande sera exécutée en premier, suivie des commandes du fichier batch.

Voici un exemple de fichier d'entrée batch valide.

# Ceci est un fichier d'entrée mpathpersist.
# Formes courtes et longues de la même commande
-i -k /dev/dm-1 # forme courte, ce commentaire est ignoré
mpathpersist --in --lire-clés --périphérique=/dev/dm-1
# Mélange d'options longues et courtes, espace blanc variable
  --out  --enregistrer    -S  abcde     /dev/dm-1
# Mélange de com

NAME

mpathpersist

maintain persistent reservations for device-mapper devices

SYNOPSIS

mpathpersist

       [basic_options]
       [reservation_options]
       device

DESCRIPTION

The mpathpersist utility is used to manage persistent reservations on device-mapper devices. Persistent reservations are a SCSI standard for maintaining access control on shared storage devices.

Persistent reservations allow a host to register a persistent reservation on a target device. This reservation is maintained by the target device even if the host loses connectivity or crashes. Other hosts attempting to access the device will be denied access until the reservation is released.

The mpathpersist utility allows you to view, establish, and clear persistent reservations on specific devices.

OPTIONS

The mpathpersist utility accepts the following options:

basic_options
-h, --help
Display help text and exit.
-V, --version
Display version information and exit.
-v, --verbose
Enable verbose output.
reservation_options
-i, --inquire
Inquire about the persistent reservation status of the specified device.
-c, --clear
Clear any existing persistent reservation on the specified device.
-e, --establish
Establish a persistent reservation on the specified device.
-p, --param name
Set a parameter for the persistent reservation operation. The available parameters depend on the operation being performed. For example, when establishing a reservation, you might use all-tg-pt to reserve for all target ports.
-r, --read-reservation
Read and display the current persistent reservation key from the specified device.
-w, --write-reservation key
Write a persistent reservation key to the specified device. This is typically used when establishing a reservation.
-k, --key key
Specify the reservation key to use for operations. This is a 64-bit value.
--in
Read the reservation key from the device.
--out
Write the reservation key to the device.
--prout-type type
Specify the PR OUT type for establishing a reservation. Common types include 0 (Write Protect), 1 (Read Write), 5 (Read Only).
--reserve
Establish a reservation on the device.
--rk key
Specify the reservation key.
--prout-type type
Specify the PR OUT type.
--fail-if-reservation-found
Fail the operation if a reservation is already present.
--fail-if-reservation-not-found
Fail the operation if no reservation is present.

EXAMPLE

To inquire about the persistent reservation status of device /dev/dm-0:

 mpathpersist -i /dev/dm-0

To establish a persistent reservation of type 5 (Read Only) on device /dev/dm-1 with reservation key abcde:

 mpathpersist --out --param-rk abcde --reserve --prout-type 5 /dev/dm-1

To clear the persistent reservation on device /dev/dm-1:

 mpathpersist -c /dev/dm-1

To read the reservation key from device /dev/dm-1:

 mpathpersist -r /dev/dm-1

BATCH FILES

You can also use batch files to perform operations on multiple devices. Each line in the batch file should contain a command and its arguments, similar to how you would use the command line.

Example batch file content:

# Inquire about different maps
-ir /dev/dm-0
-ir /dev/dm-1
mpathpersist --out --param-rk abcde --reserve --prout-type 5 /dev/dm-1
# This should now show a reservation
-ir /dev/dm-1
-oCK abcde /dev/dm-1
--in --read-reservation /dev/dm-1

SEE ALSO

multipath(8), multipathd(8), sg_persist(8).

AUTHORS

NOM

mpathpersist

maintient des réservations persistantes pour les périphériques device-mapper

SYNTAXE

mpathpersist

       [options_de_base]
       [options_de_réservation]
       périphérique

DESCRIPTION

L'utilitaire mpathpersist est utilisé pour gérer les réservations persistantes sur les périphériques device-mapper. Les réservations persistantes sont une norme SCSI pour maintenir le contrôle d'accès sur les périphériques de stockage partagés.

Les réservations persistantes permettent à un hôte d'enregistrer une réservation persistante sur un périphérique cible. Cette réservation est maintenue par le périphérique cible même si l'hôte perd la connectivité ou plante. Les autres hôtes tentant d'accéder au périphérique se verront refuser l'accès jusqu'à ce que la réservation soit libérée.

L'utilitaire mpathpersist vous permet de visualiser, d'établir et d'effacer les réservations persistantes sur des périphériques spécifiques.

OPTIONS

L'utilitaire mpathpersist accepte les options suivantes :

options_de_base
-h, --help
Affiche le texte d'aide et quitte.
-V, --version
Affiche les informations de version et quitte.
-v, --verbose
Active la sortie détaillée.
options_de_réservation
-i, --inquire
Interroge l'état de la réservation persistante du périphérique spécifié.
-c, --clear
Efface toute réservation persistante existante sur le périphérique spécifié.
-e, --establish
Établit une réservation persistante sur le périphérique spécifié.
-p, --param nom
Définit un paramètre pour l'opération de réservation persistante. Les paramètres disponibles dépendent de l'opération effectuée. Par exemple, lors de l'établissement d'une réservation, vous pouvez utiliser all-tg-pt pour réserver pour tous les ports cibles.
-r, --read-reservation
Lit et affiche la clé de réservation persistante actuelle du périphérique spécifié.
-w, --write-reservation clé
Écrit une clé de réservation persistante dans le périphérique spécifié. Ceci est généralement utilisé lors de l'établissement d'une réservation.
-k, --key clé
Spécifie la clé de réservation à utiliser pour les opérations. Il s'agit d'une valeur de 64 bits.
--in
Lit la clé de réservation depuis le périphérique.
--out
Écrit la clé de réservation dans le périphérique.
--prout-type type
Spécifie le type PR OUT pour l'établissement d'une réservation. Les types courants incluent 0 (Protection en écriture), 1 (Lecture Écriture), 5 (Lecture seule).
--reserve
Établit une réservation sur le périphérique.
--rk clé
Spécifie la clé de réservation.
--prout-type type
Spécifie le type PR OUT.
--fail-if-reservation-found
Échoue l'opération si une réservation est déjà présente.
--fail-if-reservation-not-found
Échoue l'opération si aucune réservation n'est présente.

Pour interroger l'état de la réservation persistante du périphérique /dev/dm-0 :

Pour établir une réservation persistante de type 5 (Lecture seule) sur le périphérique /dev/dm-1 avec la clé de réservation abcde :

 mpathpersist --out --param-rk abcde --reserve --prout-type 5 /dev/dm-1

Pour effacer la réservation persistante sur le périphérique /dev/dm-1 :

 mpathpersist -c /dev/dm-1

Pour lire la clé de réservation du périphérique /dev/dm-1 :

 mpathpersist -r /dev/dm-1

Vous pouvez également utiliser des fichiers batch pour effectuer des opérations sur plusieurs périphériques. Chaque ligne du fichier batch doit contenir une commande et ses arguments, de la même manière que vous utiliseriez la ligne de commande.

Contenu d'exemple de fichier batch :
