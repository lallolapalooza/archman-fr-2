mpicc, mpic++, mpicxx, mpifort, mpijavac — Compilateurs d'enrobage Open MPI

SYNTAXE

mpicc [--showme | --showme:compile | --showme:link] ...

mpic++ [--showme | --showme:compile | --showme:link] ...

mpicxx [--showme | --showme:compile | --showme:link] ...

mpifort [--showme | --showme:compile | --showme:link] ...

mpijavac [--showme | --showme:compile | --showme:link] ...

Les commandes obsolètes suivantes sont également disponibles — mais mpifort doit être utilisé à la place :

mpif77 [--showme | --showme:compile | --showme:link] ...

mpif90 [--showme | --showme:compile | --showme:link] ...

Sur les systèmes de fichiers sensibles à la casse, la commande suivante sera également disponible :

mpiCC [--showme | --showme:compile | --showme:link] ...

OPTIONS

Les options ci-dessous s'appliquent à tous les compilateurs d'enrobage :

•
--showme : Cette option existe en plusieurs variantes (voir ci-dessous). Aucune des variantes n'invoque le compilateur sous-jacent ; elles fournissent toutes des informations sur la manière dont le compilateur sous-jacent aurait été invoqué si --showme n'avait pas été utilisé. L'option de base --showme affiche la ligne de commande qui serait exécutée pour compiler le programme.

NOTE :

Si un argument qui n'est pas un nom de fichier est passé sur la ligne de commande, l'option --showme n'affichera aucun drapeau supplémentaire. Par exemple, "mpicc --showme et mpicc --showme my_source.c afficheront tous les drapeaux fournis par l'enrobage. Mais mpicc --showme -v n'affichera que le nom du compilateur sous-jacent et -v.
  • --showme:compile : Affiche les drapeaux du compilateur qui auraient été fournis au compilateur sous-jacent.
  • --showme:link : Affiche les drapeaux de l'éditeur de liens qui auraient été fournis au compilateur sous-jacent.
  • --showme:command : Affiche la commande du compilateur sous-jacent (qui peut être un ou plusieurs jetons).
  • --showme:incdirs : Affiche une liste de répertoires séparés par des espaces (mais sinon non décorée) que le compilateur d'enrobage aurait fournis au compilateur sous-jacent pour indiquer où se trouvent les fichiers d'en-tête pertinents.
  • --showme:libdirs : Affiche une liste de répertoires séparés par des espaces (mais sinon non décorée) que le compilateur d'enrobage aurait fournis à l'éditeur de liens sous-jacent pour indiquer où se trouvent les bibliothèques pertinentes.
  • --showme:libs Affiche une liste de noms de bibliothèques séparés par des espaces (mais sinon non décorée) que le compilateur d'enrobage aurait utilisés pour lier une application. Par exemple : mpi open-pal util.
  • --showme:version : Affiche le numéro de version d'Open MPI.
  • --showme:help : Affiche un bref message d'aide d'utilisation.

Consultez la page de manuel de votre compilateur sous-jacent pour connaître les autres options qui peuvent être passées via mpicc.

DESCRIPTION

Conceptuellement, le rôle de ces commandes est assez simple : ajouter de manière transparente à la ligne de commande de l'utilisateur les drapeaux de compilation et d'édition de liens pertinents nécessaires pour compiler / lier des programmes Open MPI, puis invoquer le compilateur sous-jacent pour exécuter réellement la commande.

En tant que tels, ces commandes sont souvent appelées compilateurs “ d'enrobage ” car elles ne compilent ou ne lient pas les applications elles-mêmes ; elles ajoutent seulement des drapeaux à la ligne de commande et invoquent le compilateur de traitement.

CONTEXTE

Open MPI fournit des compilateurs d'enrobage pour plusieurs langages :

  • mpicc : C
  • mpic++, mpicxx (et sur les systèmes avec des systèmes de fichiers sensibles à la casse, mpiCC) : C++

    NOTE :

mpic++, mpicxx et mpiCC invoquent tous le même compilateur C++ sous-jacent avec les mêmes options. Tous sont fournis par compatibilité avec d'autres implémentations MPI.
  • mpifort (et ses alias hérités/obsolètes mpif77 et mpif90) : Fortran
  • mpijavac : Java

Les compilateurs d'enrobage pour chacun des langages sont identiques ; ils peuvent être utilisés de manière interchangeable. Les différents noms sont fournis uniquement pour des raisons de compatibilité descendante.

NOTES FORTRAN

Le compilateur d'enrobage Fortran pour MPI (mpifort, et ses noms hérités/obsolètes mpif77 et mpif90) peut compiler et lier des applications MPI qui utilisent tout/tous les liens Fortran MPI : mpif.h, le module mpi et le module mpi_f08 (en supposant qu'Open MPI a été installé avec la prise en charge de chacun de ces liens Fortran). Plus précisément : il n'est plus nécessaire d'utiliser différents compilateurs d'enrobage pour les applications qui utilisent mpif.h par rapport aux applications qui utilisent le module mpi — utilisez simplement mpifort pour toutes les applications MPI Fortran.

Notez cependant que le compilateur Fortran peut nécessiter des options de ligne de commande supplémentaires pour imposer un dialecte Fortran spécifique. Par exemple, dans certaines versions du compilateur IBM XLF, -qfixed peut être nécessaire pour compiler des fichiers source Fortran au format fixe.

Enfin, notez que mpifort sera inopérant et retournera une erreur d'utilisation si le support Fortran n'a pas été intégré à la couche MPI.

VUE D'ENSEMBLE

mpicc est un enveloppement de commodité pour le compilateur C sous-jacent. La traduction d'un programme Open MPI nécessite la liaison des bibliothèques spécifiques à Open MPI qui peuvent ne pas se trouver dans l'un des répertoires de recherche standards de ld(1). Elle nécessite également souvent l'inclusion de fichiers d'en-tête qui peuvent également ne pas être trouvés dans un emplacement standard.

mpicc transmet ses arguments au compilateur C sous-jacent ainsi que les options -I, -L et -l requises par les programmes Open MPI.

Il en va de même pour tous les autres compilateurs d'enrobage de langage.

L'équipe Open MPI encourage vivement l'utilisation des compilateurs d'enrobage au lieu d'essayer de lier manuellement aux bibliothèques Open MPI. Cela permet à l'implémentation spécifique d'Open MPI de changer sans forcer les changements dans les directives de l'éditeur de liens des Makefiles des utilisateurs. En effet, l'ensemble spécifique de drapeaux et de bibliothèques utilisé par les compilateurs d'enrobage dépend de la manière dont Open MPI a été configuré et construit ; les valeurs peuvent changer entre différentes installations de la même version d'Open MPI.

En effet, comme les enveloppements ne sont que de minces surcouches d'un compilateur sous-jacent, il y a très, très peu de raisons impérieuses de ne pas utiliser les compilateurs d'enrobage d'Open MPI. Lorsqu'il n'est pas possible d'utiliser directement les enveloppements, les options --showme:compile et --showme:link doivent être utilisées pour déterminer quels drapeaux les enveloppements auraient utilisés. Par exemple :

shell$ cc -c file1.c `mpicc --showme:compile`
shell$ cc -c file2.c `mpicc --showme:compile`
shell$ cc file1.o file2.o `mpicc --showme:link` -o my_mpi_program

NOTES

Il est possible de rendre les compilateurs d'enrobage conscients de plusieurs bibliothèques (multi-lib). C'est-à-dire que les bibliothèques et les inclusions spécifiées peuvent différer en fonction des drapeaux du compilateur spécifiés (par exemple, avec les compilateurs GNU sous Linux, un chemin de bibliothèque différent peut être utilisé si -m32 est vu par rapport à -m64 étant vu). Ce n'est pas le comportement par défaut dans une construction standard, mais cela peut être activé (par exemple, dans un paquet binaire fournissant un support 32 et 64 bits). Plus d'informations peuvent être trouvées ici.

FICHIERS

Les chaînes que les compilateurs d'enrobage insèrent dans la ligne de commande avant d'invoquer le compilateur sous-jacent sont stockées dans un fichier texte créé par Open MPI et installé dans $pkgdata/NOM-wrapper-data.txt, où :

  • $pkgdata est typiquement $prefix/share/openmpi
  • $prefix est le répertoire d'installation principal d'Open MPI
  • NOM est le nom du compilateur d'enrobage (par exemple, $pkgdata/mpicc-wrapper-data.txt)

mpif90(1)
Fortran compiler wrapper for Open MPI

SYNTAX

mpif90 [options] [source files] [library files]

OPTIONS

The mpif90 command accepts all the options that are accepted by the underlying Fortran compiler (see f95(1), for example). It also accepts the following options:

-showme
Prints the compiler and linker flags that mpif90 would use to compile and link a Fortran program. This is useful for debugging or incorporating the MPI compiler flags into build systems.
-showme:compile
Prints only the compiler flags that mpif90 would use to compile a Fortran program.
-showme:link
Prints only the linker flags that mpif90 would use to link a Fortran program.

DESCRIPTION

The mpif90 command is a wrapper for the Fortran compiler. It is used to compile and link Fortran programs that use the MPI API. The mpif90 command automatically includes the necessary MPI include files and libraries that are required for MPI programs.

BACKGROUND

Open MPI provides compiler wrappers for C, C++, and Fortran. These wrappers simplify the process of compiling and linking MPI applications by automatically providing the correct compiler and linker flags. The wrappers ensure that the correct MPI libraries are linked and that the necessary compiler options are set.

FORTRAN NOTES

Fortran is case-insensitive, and the MPI standard defines all MPI function names in uppercase. However, Fortran source code often uses lowercase or mixed-case function names. The MPI Fortran bindings automatically handle this by mapping lowercase or mixed-case calls to the corresponding uppercase MPI function names.

OVERVIEW

The mpif90 command is a front-end to the underlying Fortran compiler (e.g., gfortran, ifort). When you run mpif90, it essentially performs the following steps:

  1. It determines the underlying Fortran compiler that was configured with Open MPI.
  2. It adds the necessary compiler flags to enable Fortran 90/95 support and any Open MPI-specific compiler flags.
  3. It adds the necessary linker flags to link against the Open MPI libraries.
  4. It invokes the underlying Fortran compiler with the appropriate flags and source files.

NOTES

It is generally recommended to use the MPI compiler wrappers (mpicc, mpicxx, mpif77, mpif90) rather than directly invoking the underlying compilers. This ensures that your MPI applications are compiled and linked correctly with the Open MPI libraries.

If you need to pass specific flags to the underlying compiler or linker, you can usually do so by simply including them on the mpif90 command line. For example:

    mpif90 my_program.f90 -lmylib -L/path/to/mylib

The wrappers are designed to be as transparent as possible, passing most command-line arguments directly to the underlying compiler.

FILES

The compiler wrappers use configuration files to determine the compiler and linker flags. These files are typically located in the installation prefix of Open MPI, under the `share/openmpi` directory.

  • `mpi.h`: The main MPI include file.
  • `mpif.h`: The MPI Fortran include file.

It is rarely necessary to edit these files, but they can be examined to gain insight into what flags the wrappers are placing on the command line.

ENVIRONMENT VARIABLES

By default, the wrappers use the compilers that were selected when Open MPI was configured. These compilers were either found automatically by Open MPI’s “configure” script, or were selected by the user in the CC, CXX, and/or FC environment variables before configure was invoked. Additionally, other arguments specific to the compiler may have been selected by configure.

These values can be selectively overridden by either editing the text files containing this configuration information (see the FILES section), or by setting selected environment variables of the form ompi_value.

Valid value names are:

  • CPPFLAGS: Flags added when invoking the preprocessor (C or C++)
  • LDFLAGS: Flags added when invoking the linker (C, C++, or Fortran)
  • LIBS: Libraries added when invoking the linker (C, C++, or Fortran)
  • CC: C compiler
  • CFLAGS: C compiler flags
  • CXX: C++ compiler
  • CXXFLAGS: C++ compiler flags
  • FC: Fortran compiler
  • FCFLAGS: Fortran compiler flags

mpif90(1)
Fortran compiler wrapper for Open MPI

SYNTAXE

mpif90 [options] [fichiers source] [fichiers bibliothèques]

OPTIONS

La commande mpif90 accepte toutes les options acceptées par le compilateur Fortran sous-jacent (voir f95(1), par exemple). Elle accepte également les options suivantes :

-showme
Affiche les options du compilateur et de l'éditeur de liens que mpif90 utiliserait pour compiler et lier un programme Fortran. Ceci est utile pour le débogage ou pour intégrer les options du compilateur MPI dans les systèmes de construction.
-showme:compile
Affiche uniquement les options du compilateur que mpif90 utiliserait pour compiler un programme Fortran.
-showme:link
Affiche uniquement les options de l'éditeur de liens que mpif90 utiliserait pour lier un programme Fortran.

DESCRIPTION

La commande mpif90 est un wrapper pour le compilateur Fortran. Elle est utilisée pour compiler et lier des programmes Fortran qui utilisent l'API MPI. La commande mpif90 inclut automatiquement les fichiers d'en-tête et les bibliothèques MPI nécessaires aux programmes MPI.

CONTEXTE

Open MPI fournit des wrappers de compilateur pour C, C++ et Fortran. Ces wrappers simplifient le processus de compilation et de liaison des applications MPI en fournissant automatiquement les options correctes du compilateur et de l'éditeur de liens. Les wrappers garantissent que les bibliothèques MPI correctes sont liées et que les options du compilateur nécessaires sont définies.

NOTES SUR FORTRAN

Fortran est insensible à la casse, et la norme MPI définit tous les noms de fonctions MPI en majuscules. Cependant, le code source Fortran utilise souvent des noms de fonctions en minuscules ou en casse mixte. Les liaisons Fortran MPI gèrent cela automatiquement en mappant les appels en minuscules ou en casse mixte aux noms de fonctions MPI majuscules correspondants.

APERÇU

La commande mpif90 est une interface pour le compilateur Fortran sous-jacent (par exemple, gfortran, ifort). Lorsque vous exécutez mpif90, elle effectue essentiellement les étapes suivantes :

  1. Elle détermine le compilateur Fortran sous-jacent qui a été configuré avec Open MPI.
  2. Elle ajoute les options de compilation nécessaires pour activer le support de Fortran 90/95 et toute option de compilation spécifique à Open MPI.
  3. Elle ajoute les options de l'éditeur de liens nécessaires pour lier aux bibliothèques Open MPI.
  4. Elle invoque le compilateur Fortran sous-jacent avec les options et les fichiers source appropriés.

NOTES

Il est généralement recommandé d'utiliser les wrappers de compilateur MPI (mpicc, mpicxx, mpif77, mpif90) plutôt que d'appeler directement les compilateurs sous-jacents. Cela garantit que vos applications MPI sont compilées et liées correctement avec les bibliothèques Open MPI.

Si vous avez besoin de passer des options spécifiques au compilateur ou à l'éditeur de liens sous-jacent, vous pouvez généralement le faire en les incluant simplement sur la ligne de commande mpif90. Par exemple :

    mpif90 mon_programme.f90 -lmylib -L/chemin/vers/mylib

Les wrappers sont conçus pour être aussi transparents que possible, transmettant la plupart des arguments de la ligne de commande directement au compilateur sous-jacent.

FICHIERS

Les wrappers de compilateur utilisent des fichiers de configuration pour déterminer les options du compilateur et de l'éditeur de liens. Ces fichiers sont généralement situés dans le préfixe d'installation d'Open MPI, sous le répertoire `share/openmpi`.

  • `mpi.h`: Le fichier d'en-tête MPI principal.
  • `mpif.h`: Le fichier d'en-tête Fortran MPI.

Il est rarement nécessaire de modifier ces fichiers, mais ils peuvent être examinés pour mieux comprendre quelles options les wrappers placent sur la ligne de commande.

VARIABLES D'ENVIRONNEMENT

Par défaut, les wrappers utilisent les compilateurs qui ont été sélectionnés lors de la configuration d'Open MPI. Ces compilateurs ont été soit trouvés automatiquement par le script de configuration “configure” d'Open MPI, soit sélectionnés par l'utilisateur dans les variables d'environnement CC, CXX et/ou FC avant l'invocation de configure. De plus, d'autres arguments spécifiques au compilateur peuvent avoir été sélectionnés par configure.

Ces valeurs peuvent être remplacées sélectivement soit en modifiant les fichiers texte contenant ces informations de configuration (voir la section FICHIERS), soit en définissant des variables d'environnement sélectionnées de la forme ompi_valeur.

Les noms de valeurs valides sont :

  • CPPFLAGS : Options ajoutées lors de l'invocation du préprocesseur (C ou C++)
  • LDFLAGS : Options ajoutées lors de l'invocation de l'éditeur de liens (C, C++ ou Fortran)
  • LIBS : Bibliothèques ajoutées lors de l'invocation de l'éditeur de liens (C, C++ ou Fortran)
  • CC : Compilateur C
  • CFLAGS : Options du compilateur C
  • CXX : Compilateur C++
  • CXXFLAGS : Options du compilateur C++
  • FC : Compilateur Fortran
  • FCFLAGS : Options du compilateur Fortran
