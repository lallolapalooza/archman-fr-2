mpicc, mpic++, mpicxx, mpifort, mpijavac — Compilateurs enveloppants Open MPI

SYNTAX

mpicc [--showme | --showme:compile | --showme:link] ...

mpic++ [--showme | --showme:compile | --showme:link] ...

mpicxx [--showme | --showme:compile | --showme:link] ...

mpifort [--showme | --showme:compile | --showme:link] ...

mpijavac [--showme | --showme:compile | --showme:link] ...

Les commandes obsolètes suivantes sont également disponibles — mais mpifort doit être utilisé à la place :

mpif77 [--showme | --showme:compile | --showme:link] ...

mpif90 [--showme | --showme:compile | --showme:link] ...

Sur les systèmes de fichiers sensibles à la casse, la commande suivante sera également disponible :

mpiCC [--showme | --showme:compile | --showme:link] ...

OPTIONS

Les options ci-dessous s'appliquent à tous les compilateurs enveloppants :

•
--showme : Cette option se présente sous plusieurs variantes (voir ci-dessous). Aucune des variantes n'invoque le compilateur sous-jacent ; elles fournissent toutes des informations sur la façon dont le compilateur sous-jacent aurait été invoqué si --showme n'avait pas été utilisé. L'option de base --showme affiche la ligne de commande qui serait exécutée pour compiler le programme.

REMARQUE :

Si un argument n'est pas un nom de fichier est passé sur la ligne de commande, l'option --showme n'affichera pas de drapeaux supplémentaires. Par exemple, "mpicc --showme et mpicc --showme my_source.c afficheront tous les drapeaux fournis par l'enveloppe. Mais mpicc --showme -v n'affichera que le nom du compilateur sous-jacent et -v.
  • --showme:compile : Affiche les drapeaux de compilation qui auraient été fournis au compilateur sous-jacent.
  • --showme:link : Affiche les drapeaux d'édition des liens qui auraient été fournis au compilateur sous-jacent.
  • --showme:command : Affiche la commande du compilateur sous-jacent (qui peut être un ou plusieurs jetons).
  • --showme:incdirs : Affiche une liste de répertoires, séparés par des espaces (mais sinon non décorée), que le compilateur enveloppant aurait fournis au compilateur sous-jacent pour indiquer où se trouvent les fichiers d'en-tête pertinents.
  • --showme:libdirs : Affiche une liste de répertoires, séparés par des espaces (mais sinon non décorée), que le compilateur enveloppant aurait fournis à l'éditeur de liens sous-jacent pour indiquer où se trouvent les bibliothèques pertinentes.
  • --showme:libs : Affiche une liste de noms de bibliothèques, séparés par des espaces (mais sinon non décorée), que le compilateur enveloppant aurait utilisés pour lier une application. Par exemple : mpi open-pal util.
  • --showme:version : Affiche le numéro de version d'Open MPI.
  • --showme:help : Affiche un bref message d'aide d'utilisation.

Consultez la page de manuel de votre compilateur sous-jacent pour les autres options qui peuvent être transmises via mpicc.

DESCRIPTION

Conceptuellement, le rôle de ces commandes est assez simple : ajouter de manière transparente les indicateurs de compilation et d'édition des liens pertinents à la ligne de commande de l'utilisateur, nécessaires pour compiler / éditer les liens des programmes Open MPI, puis invoquer le compilateur sous-jacent pour exécuter réellement la commande.

En tant que tels, ces commandes sont souvent appelées compilateurs « enveloppants » car elles ne compilent ni n'éditent les liens d'applications elles-mêmes ; elles ajoutent uniquement des indicateurs à la ligne de commande et invoquent le compilateur backend.

BACKGROUND

Open MPI fournit des compilateurs enveloppants pour plusieurs langages :

  • mpicc : C
  • mpic++, mpicxx (et sur les systèmes avec des systèmes de fichiers sensibles à la casse, mpiCC) : C++

    REMARQUE :

mpic++, mpicxx et mpiCC invoquent tous le même compilateur C++ sous-jacent avec les mêmes options. Tous sont fournis pour assurer la compatibilité avec d'autres implémentations MPI.
  • mpifort (et ses alias anciens/obsolètes mpif77 et mpif90) : Fortran
  • mpijavac : Java

Les compilateurs enveloppants pour chacun des langages sont identiques ; ils peuvent être utilisés de manière interchangeable. Les différents noms sont fournis uniquement pour des raisons de compatibilité ascendante.

NOTES FORTAN

Le compilateur enveloppant Fortran pour MPI (mpifort, et ses noms anciens/obsolètes mpif77 et mpif90) peut compiler et lier des applications MPI qui utilisent tout/tous les liaisons Fortran MPI : mpif.h, le module mpi, et le module mpi_f08 (en supposant qu'Open MPI a été installé avec le support pour chacun de ces liaisons Fortran). Spécifiquement : il n'est plus nécessaire d'utiliser différents compilateurs enveloppants pour les applications qui utilisent mpif.h vs. les applications qui utilisent le module mpi — utilisez simplement mpifort pour toutes les applications MPI Fortran.

Notez cependant que le compilateur Fortran peut nécessiter des options de ligne de commande supplémentaires pour imposer un dialecte Fortran spécifique. Par exemple, dans certaines versions du compilateur IBM XLF, si xlf90 est le compilateur Fortran sous-jacent, -qfixed peut être nécessaire pour compiler des fichiers source Fortran au format fixe.

Enfin, notez que mpifort sera inopérant et retournera une erreur à l'utilisation si le support Fortran n'a pas été intégré à la couche MPI.

VUE D'ENSEMBLE

mpicc est une enveloppe de commodité pour le compilateur C sous-jacent. La traduction d'un programme Open MPI nécessite la liaison des bibliothèques spécifiques à Open MPI qui peuvent ne pas résider dans l'un des répertoires de recherche standard de ld(1). Elle nécessite également souvent l'inclusion de fichiers d'en-tête qui peuvent également ne pas se trouver dans un emplacement standard.

mpicc transmet ses arguments au compilateur C sous-jacent ainsi que les options -I, -L et -l requises par les programmes Open MPI.

Il en va de même pour tous les autres compilateurs enveloppants de langage.

L'équipe Open MPI encourage fortement l'utilisation des compilateurs enveloppants au lieu de tenter de lier les bibliothèques Open MPI manuellement. Cela permet à l'implémentation spécifique d'Open MPI de changer sans forcer de changements dans les directives d'édition des liens des Makefiles des utilisateurs. En effet, l'ensemble spécifique d'indicateurs et de bibliothèques utilisés par les compilateurs enveloppants dépend de la façon dont Open MPI a été configuré et construit ; les valeurs peuvent changer entre différentes installations de la même version d'Open MPI.

En fait, puisque les enveloppes ne sont que de minces couches sur un compilateur sous-jacent, il y a très, très peu de raisons impérieuses de ne pas utiliser les compilateurs enveloppants d'Open MPI. Lorsqu'il n'est pas possible d'utiliser directement les enveloppes, les options --showme:compile et --showme:link doivent être utilisées pour déterminer quels indicateurs les enveloppes auraient utilisés. Par exemple :

shell$ cc -c file1.c `mpicc --showme:compile`
shell$ cc -c file2.c `mpicc --showme:compile`
shell$ cc file1.o file2.o `mpicc --showme:link` -o my_mpi_program

NOTES

Il est possible de rendre les compilateurs enveloppants conscients des bibliothèques multiples. C'est-à-dire que les bibliothèques et les inclusions spécifiées peuvent différer en fonction des options du compilateur spécifiées (par exemple, avec les compilateurs GNU sous Linux, un chemin de bibliothèque différent peut être utilisé si -m32 est vu par rapport à -m64). Ce n'est pas le comportement par défaut dans une construction standard, mais cela peut être activé (par exemple, dans un paquet binaire fournissant un support 32 et 64 bits). Plus d'informations peuvent être trouvées ici.

FICHIERS

Les chaînes que les compilateurs enveloppants insèrent dans la ligne de commande avant d'invoquer le compilateur sous-jacent sont stockées dans un fichier texte créé par Open MPI et installé dans $pkgdata/NOM-wrapper-data.txt, où :

  • $pkgdata est généralement $prefix/share/openmpi
  • $prefix est le répertoire d'installation principal d'Open MPI
  • NOM est le nom du compilateur enveloppant (par exemple, $pkgdata/mpicc-wrapper-data.txt)

class="Pp">Il est rarement nécessaire de modifier ces fichiers, mais ils peuvent être examinés pour mieux comprendre les indicateurs que les wrappers placent sur la ligne de commande.

VARIABLES D'ENVIRONNEMENT

Par défaut, les wrappers utilisent les compilateurs qui ont été sélectionnés lors de la configuration d'Open MPI. Ces compilateurs ont été soit trouvés automatiquement par le script “configure” d'Open MPI, soit sélectionnés par l'utilisateur dans les variables d'environnement CC, CXX et/ou FC avant l'invocation de configure. De plus, d'autres arguments spécifiques au compilateur peuvent avoir été sélectionnés par configure.

Ces valeurs peuvent être sélectivement remplacées soit en modifiant les fichiers texte contenant ces informations de configuration (voir la section FICHIERS), soit en définissant des variables d'environnement sélectionnées de la forme ompi_valeur.

Les noms de valeurs valides sont :

  • CPPFLAGS : Indicateurs ajoutés lors de l'invocation du préprocesseur (C ou C++)
  • LDFLAGS : Indicateurs ajoutés lors de l'invocation de l'éditeur de liens (C, C++ ou Fortran)
  • LIBS : Bibliothèques ajoutées lors de l'invocation de l'éditeur de liens (C, C++ ou Fortran)
  • CC : Compilateur C
  • CFLAGS : Indicateurs du compilateur C
  • CXX : Compilateur C++
  • CXXFLAGS : Indicateurs du compilateur C++
  • FC : Compilateur Fortran
  • FCFLAGS : Indicateurs du compilateur Fortran
