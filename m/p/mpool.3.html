mpool(3) Manuel des fonctions de bibliothèque mpool(3)

NOM

mpool - pool de tampons de mémoire partagée

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <db.h>
#include <mpool.h>
MPOOL *mpool_open(DBT *key, int fd, pgno_t pagesize, pgno_t maxcache);
void mpool_filter(MPOOL *mp,
                  typeof(void (void *, pgno_t, void *)) *pgin,
                  typeof(void (void *, pgno_t, void *)) *pgout,
                  void *pgcookie);
void *mpool_new(MPOOL *mp, pgno_t *pgnoaddr);
void *mpool_get(MPOOL *mp, pgno_t pgno, unsigned int flags);
int mpool_put(MPOOL *mp, void *pgaddr, unsigned int flags);
int mpool_sync(MPOOL *mp);
int mpool_close(MPOOL *mp);

DESCRIPTION

Note bien : Cette page documente les interfaces fournies jusqu'à glibc 2.1. Depuis glibc 2.2, glibc ne fournit plus ces interfaces. Probablement, vous recherchez les API fournies par la bibliothèque libdb à la place.

Mpool est l'interface de bibliothèque destinée à fournir une gestion de tampons orientée pages de fichiers. Les tampons peuvent être partagés entre processus.

La fonction mpool_open() initialise un pool de mémoire. L'argument key est la chaîne d'octets utilisée pour négocier entre plusieurs processus souhaitant partager des tampons. Si les tampons de fichier sont mappés en mémoire partagée, tous les processus utilisant la même clé partageront les tampons. Si key est NULL, les tampons sont mappés en mémoire privée. L'argument fd est un descripteur de fichier pour le fichier sous-jacent, qui doit être cherchable (seekable). Si key n'est pas NULL et correspond à un fichier déjà mappé, l'argument fd est ignoré.

L'argument pagesize est la taille, en octets, des pages dans lesquelles le fichier est décomposé. L'argument maxcache est le nombre maximum de pages du fichier sous-jacent à mettre en cache à un moment donné. Cette valeur n'est pas relative au nombre de processus qui partagent les tampons d'un fichier, mais sera la valeur la plus élevée spécifiée par l'un des processus partageant le fichier.

La fonction mpool_filter() est destinée à rendre possible un traitement transparent des entrées et sorties des pages. Si la fonction pgin est spécifiée, elle est appelée chaque fois qu'un tampon est lu dans le pool de mémoire à partir du fichier source. Si la fonction pgout est spécifiée, elle est appelée chaque fois qu'un tampon est écrit dans le fichier source. Les deux fonctions sont appelées avec le pointeur pgcookie, le numéro de page et un pointeur vers la page en cours de lecture ou d'écriture.

La fonction mpool_new() prend un pointeur MPOOL et une adresse en arguments. Si une nouvelle page peut être allouée, un pointeur vers la page est retourné et le numéro de page est stocké à l'adresse pgnoaddr. Sinon, NULL est retourné et errno est défini.

La fonction mpool_get() prend un pointeur MPOOL et un numéro de page en arguments. Si la page existe, un pointeur vers la page est retourné. Sinon, NULL est retourné et errno est défini. L'argument flags n'est actuellement pas utilisé.

La fonction mpool_put() désépingle la page référencée par pgaddr. pgaddr doit être une adresse précédemment retournée par mpool_get() ou mpool_new(). La valeur du drapeau est spécifiée en combinant par OU les valeurs suivantes :

MPOOL_DIRTY
La page a été modifiée et doit être écrite dans le fichier source.

mpool_put() retourne 0 en cas de succès et -1 en cas d'erreur.

La fonction mpool_sync() écrit toutes les pages modifiées associées au pointeur MPOOL dans le fichier source. mpool_sync() retourne 0 en cas de succès et -1 en cas d'erreur.

La fonction mpool_close() libère toute la mémoire allouée associée au cookie du pool de mémoire. Les pages modifiées ne sont pas écrites dans le fichier source. mpool_close() retourne 0 en cas de succès et -1 en cas d'erreur.

ERREURS

La fonction mpool_open() peut échouer et définir errno pour l'une des erreurs spécifiées pour la routine de bibliothèque malloc(3).

La fonction mpool_get() peut échouer et définir errno pour les raisons suivantes :

EINVAL
L'enregistrement demandé n'existe pas.

Les fonctions mpool_new() et mpool_get() peuvent échouer et définir errno pour l'une des erreurs spécifiées pour les routines de bibliothèque read(2), write(2), et malloc(3).

La fonction mpool_sync() peut échouer et définir errno pour l'une des erreurs spécifiées pour la routine de bibliothèque write(2).

La fonction mpool_close() peut échouer et définir errno pour l'une des erreurs spécifiées pour la routine de bibliothèque free(3).

NORMES

BSD.
