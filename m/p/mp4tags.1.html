mp4tags(1)

Paquet: libmp4v2

Licences: MPL

MP4TAGS(-) Mai 2023 MP4TAGS(-)

NOM

mp4tags - MP4v2 - page de manuel pour mp4tags - MP4v2 2.1.3

SYNTAXE

mp4tags OPTION... FICHIER...

DESCRIPTION

Ajoute ou modifie les balises compatibles iTunes sur les fichiers MP4.

-aide
Affiche ce texte d'aide et quitte
-version
Affiche les informations de version et quitte
-A, -album
STR Définit le titre de l'album
-a, -artiste
STR Définit les informations de l'artiste
-b, -tempo
NUM Définit le tempo (battements par minute)
-c, -commentaire
STR Définit un commentaire général
-C, -droitdauteur
STR Définit les informations de droit d'auteur
-d, -disque
NUM Définit le numéro du disque
-D, -disques
NUM Définit le nombre de disques
-e, -encodeur
STR Définit le nom de la personne ou de l'entreprise qui a encodé le fichier
-E, -outil
STR Définit le logiciel utilisé pour l'encodage
-g, -genre
STR Définit le nom du genre
-G, -regroupement
STR Définit le nom du regroupement
-H, -hdvideo
NUM Définit le drapeau HD (0/1)
-i, -type
STR Définit le Type de Média (série TV, film, musique, ...)
-I, -contentid
NUM Définit l'identifiant du contenu
-j, -genreid
NUM Définit l'identifiant du genre
-l, -longdesc
STR Définit la description longue
-L, -paroles
NUM Définit les paroles
-m, -description
STR Définit la description courte
-M, -episode
NUM Définit le numéro de l'épisode
-n, -saison
NUM Définit le numéro de la saison
-N, -reseau
STR Définit le réseau TV
-o, -episodeid
STR Définit l'identifiant de l'épisode TV
-O, -categorie
STR Définit la catégorie
-p, -playlistid
NUM Définit l'identifiant de la playlist
-P, -image
PTH Définit l'image sous forme de .png
-B, -podcast
NUM Définit le drapeau podcast.
-R, -artistealbum
STR Définit l'artiste de l'album
-s, -chanson
STR Définit le titre de la chanson
-S -serie
STR Définit la série TV
-t, -piste
NUM Définit le numéro de la piste
-T, -pistes
NUM Définit le nombre de pistes
-x, -xid
STR Définit le xid globalement unique (vendeur:schéma:id)
-X, -notation
STR Définit la Notation (aucune, propre, explicite)
-w, -compositeur
STR Définit les informations du compositeur
-y, -annee
NUM Définit la date de sortie
-z, -artisteid
NUM Définit l'identifiant de l'artiste
-Z, -compositeurid
NUM Définit l'identifiant du compositeur
-sortname
STR Définit le nom de tri
-sortartist
STR Définit l'artiste de tri
-sortalbum
STR Définit l'album de tri
-sorttvshow
STR Définit la série TV de tri
-sortalbumartist STR
Définit l'artiste de l'album de tri
-sortcomposer
STR Définit le compositeur de tri
-purchasedate
STR Définit la date d'achat
-r, -supprimer
STR Supprime les balises par code (par ex. "-r commentaire,chanson" ou "-r cs" supprime les balises commentaire et chanson)
