MPATH_PERSISTENT_RESERVE_OUT(3) Manuel des fonctions de bibliothèque MPATH_PERSISTENT_RESERVE_OUT(3)

NOM

mpath_persistent_reserve_out - envoyer une commande PROUT à un périphérique DM

SYNTAXE

#include <mpath_persist.h>

int mpath_persistent_reserve_out(int fd, int rq_servact, struct prin_resp *resp, int noisy, int verbose)

DESCRIPTION

La fonction mpath_persistent_reserve_out () envoie une commande PROUT au périphérique DM et récupère la réponse.

Paramètres :
fd
Le descripteur de fichier d'un périphérique multipath. Argument d'entrée.
rq_servact
Action de service de la commande PROUT. Argument d'entrée.
rq_scope
Portée de la réservation persistante. La valeur doit toujours être LU_SCOPE (0h).
rq_type
Type de réservation persistante. Les valeurs valides des types de réservation persistante sont :
5h (Exclusive en écriture - enregistrés uniquement).
6h (Accès exclusif - enregistrés uniquement).
7h (Exclusive en écriture - Tous les enregistrés).
8h (Accès exclusif - Tous les enregistrés).
paramp
Données du paramètre de la commande PROUT. `paramp` est une structure qui décrit la liste des paramètres PROUT. L'appelant doit gérer l'allocation mémoire de cette structure.
noisy
Activer le traçage de débogage : argument d'entrée. 0->Désactivé, 1->Activé.
verbose
Définir le niveau de verbosité. Argument d'entrée. valeur : 0 à 3. 0->Erreurs, 1->Avertissements, 2->Infos, 3->Débogage.

RETOURNE

MPATH_PR_SUCCESS
Si la commande PR réussit, sinon renvoie l'un des statuts mentionnés ci-dessous.
MPATH_PR_SYNTAX_ERROR
En cas d'erreur de syntaxe ou de paramètre invalide.
MPATH_PR_SENSE_NOT_READY
Si la commande échoue avec [sk,asc,ascq : 0x2,*,*].
MPATH_PR_SENSE_MEDIUM_ERROR
Si la commande échoue avec [sk,asc,ascq : 0x3,*,*].
MPATH_PR_SENSE_HARDWARE_ERROR
Si la commande échoue avec [sk,asc,ascq : 0x4,*,*].
MPATH_PR_SENSE_INVALID_OP
Si la commande échoue avec [sk,asc,ascq : 0x5,0x20,0x0].
MPATH_PR_ILLEGAL_REQ
Si la commande échoue avec [sk,asc,ascq : 0x5,*,*].
MPATH_PR_SENSE_UNIT_ATTENTION
Si la commande échoue avec [sk,asc,ascq : 0x6,*,*].
MPATH_PR_SENSE_ABORTED_COMMAND
Si la commande échoue avec [sk,asc,ascq : 0xb,*,*].
MPATH_PR_NO_SENSE
Si la commande échoue avec [sk,asc,ascq : 0x0,*,*].
MPATH_PR_SENSE_MALFORMED
Si la commande SCSI est malformée.
MPATH_PR_FILE_ERROR
Si une erreur survient lors de l'accès au fichier (nœud de périphérique) (par exemple, introuvable).
MPATH_PR_DMMP_ERROR
En cas d'erreur liée à Device Mapper (par exemple, erreur lors de l'obtention des informations dm).
MPATH_PR_OTHER
Si une autre erreur/avertissement s'est produit (par exemple, erreur de transport ou de pilote).
MPATH_PR_RESERV_CONFLICT
Si la commande échoue avec un conflit de réservation.

VOIR AUSSI

mpathpersist(8).
