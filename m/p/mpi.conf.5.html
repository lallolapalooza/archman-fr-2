NOM

mpi.conf - Fichier de configuration Slurm pour permettre la configuration des plugins MPI.

DESCRIPTION

mpi.conf est un fichier ASCII qui définit les paramètres contrôlant le comportement des plugins MPI. Actuellement, le fichier de configuration ne peut être utilisé que pour configurer le plugin PMIx, mais il peut être étendu pour supporter d'autres plugins MPI. Le fichier sera toujours situé dans le même répertoire que slurm.conf. Ce fichier est optionnel.

Les noms de paramètres ne sont pas sensibles à la casse. Tout texte suivant un "#" dans le fichier de configuration est traité comme un commentaire jusqu'à la fin de la ligne. Les modifications apportées au fichier de configuration prennent effet au redémarrage des démons Slurm, à la réception du signal SIGHUP par un démon, ou à l'exécution de la commande "scontrol reconfigure", sauf indication contraire.

Les paramètres de ce fichier de configuration peuvent être consultés dans la sortie de la commande "scontrol show config". Ce fichier de configuration peut être inclus lors de l'utilisation du mode "configless". Les informations de mpi.conf sont lues au démarrage ou lors de la reconfiguration par slurmctld et slurmd. Les instances de slurmstepd pour les tâches batch recevront des informations sur le plugin demandé à slurmd.

PARAMETRES

PMIxCliTmpDirBase=<chemin>
Répertoire que PMIx utilisera pour les fichiers temporaires. Par défaut, non défini.
PMIxCollFence={mixed|tree|ring}
Définit le type de clôture à utiliser pour la collecte de données inter-nœuds. Par défaut, non défini. Voir également PMIxFenceBarrier.
PMIxDebug={0|1}
Active la journalisation de débogage pour le plugin PMIx. Par défaut, 0.
PMIxDirectConn={true|false}
Désactive le lancement direct des tâches. Par défaut, "true".
PMIxDirectConnEarly={true|false}
Permet des connexions précoces à un nœud parent. Par défaut, "false".
PMIxDirectConnUCX={true|false}
Permet à PMIx d'utiliser UCX pour la communication. Par défaut, "false".
PMIxDirectSameArch={true|false}
Active des optimisations de communication supplémentaires lorsque PMIxDirectConn est défini sur true, en supposant que tous les nœuds du job ont la même architecture. Par défaut, "false".
PMIxEnv=<variables d'environnement>
Liste de variables d'environnement séparées par des points-virgules à définir dans les environnements de job pour être utilisées par PMIx. Par défaut, non défini.
PMIxFenceBarrier={true|false}
Définit s'il faut clôturer la communication inter-nœuds pour la collecte de données. Par défaut, "false". Voir également PMIxCollFence.
PMIxNetDevicesUCX=<type de périphérique>
Type de périphérique réseau à utiliser pour la communication. Cela définira la variable d'environnement UCX_NET_DEVICES uniquement dans l'environnement slurmstepd. Par défaut, non défini.
PMIxShareServerTopology={true|false}
Permet au serveur PMIx de partager sa copie de la topologie locale des nœuds du job avec les clients. Si défini sur true, le serveur PMIx définira les paires clé-valeur nécessaires dans les informations au niveau du job fournies à chaque client. La topologie ne sera pas partagée via la mémoire partagée. Par défaut, "false".

NOTE : Ceci n'est pris en charge que par PMIx v4.x+.

PMIxTimeout=<temps>
Temps maximum (en secondes) autorisé pour la communication entre les hôtes. Par défaut, 300 secondes.
PMIxTlsUCX=<tl1>[,<tl2>...]
Définit la variable UCX_TLS, qui limite les transports à utiliser, dans l'environnement slurmstepd. Les valeurs acceptées sont définies dans la documentation UCX et peuvent varier entre les installations. Plusieurs valeurs peuvent être définies et doivent être séparées par des virgules. Si non défini, UCX essaie d'utiliser tous les transports disponibles et sélectionne les meilleurs selon leurs capacités de performance et leur échelle. Par défaut, non défini.
