NOM

mpcd - Démon client MPOA (Multi-Protocol Over ATM) pour ATM

SYNTAXE

mpcd [ -s Adresse de contrôle ATM ] [ -l Adresse de données ATM ] [ -c Adresse de contrôle MPS ] [ -i Numéro d'interface ] [ -m Adresse MAC du MPS ] [ -L Adresse LEC [ -n Nom ELAN ] [ -C Adresse LECS ]]

DESCRIPTION

Le client MPOA (MPC) est responsable de la création et de la réception de raccourcis au niveau inter-réseau. En utilisant ces raccourcis, les MPC acheminent efficacement les paquets de niveau inter-réseau en monodiffusion sur ATM sans nécessiter de protocoles de routage.

Le MPC a deux rôles : entrant et sortant. Dans le rôle entrant, le MPC détecte les flux destinés à l'extérieur de son propre sous-réseau et tente d'établir des raccourcis vers ces destinations. Dans le rôle sortant, le MPC accepte les raccourcis et les paquets arrivant sur ces raccourcis. La gestion des raccourcis est effectuée à l'aide du serveur MPOA (MPS).

Tout comme le client d'émulation LAN (LEC) de Linux, le client MPOA est également divisé en deux parties : un composant noyau et un processus démon. Le démon ouvre et reçoit les raccourcis de données et les connexions de contrôle avec le composant noyau. Le composant noyau compte les paquets circulant hors du périphérique LANE et décide si un paquet doit être acheminé en utilisant les raccourcis LANE ou MPOA.

Si le démon est arrêté avec SIGHUP, il fermera toutes les connexions ouvertes, purgera les entrées du cache entrant et sortant, interrogera le LECS si applicable, puis redémarrera.

Le client MPOA Linux ne prend en charge que les raccourcis non muxés LLC. Le nombre de clients MPOA pris en charge est illimité.

OPTIONS

-s Adresse de contrôle ATM
Adresse ATM locale que ce MPC utilise pour les connexions de contrôle MPOA.
-l Adresse de données ATM
Adresse ATM locale à partir de laquelle et vers laquelle les raccourcis MPOA sont établis.
-c Adresse de contrôle MPS
Adresse ATM du MPS. Nécessaire uniquement si le MPS ne peut pas s'annoncer lui-même.
-i Numéro d'interface
Le numéro d'interface du LEC que ce MPC dessert. Par exemple, 2 pour "lec2".
-m Adresse MAC du MPS
Adresse MAC du routeur par défaut où réside le MPS. Utile uniquement si le serveur MPOA ne parvient pas à s'annoncer.
-L Adresse LEC
Adresse d'écoute du zeppelin client LANE. mpcd utilise cette adresse comme sa propre adresse ATM lorsqu'il interroge le LECS pour les paramètres de configuration MPC. Si cette option n'est pas présente, mpcd n'utilisera pas le LECS pour interroger les paramètres de configuration. Cette option est normalement identique à l'option -l de zeppelin.
-n Nom ELAN
Nom de l'ELAN pour lequel mpcd demande des paramètres lors de sa connexion au LECS. Si cette option n'est pas fournie, le LECS devrait répondre avec les paramètres appartenant à l'ELAN par défaut s'il en existe un. Cette option est normalement identique à l'option -n de zeppelin.
-C Adresse LECS
Adresse ATM du LECS auprès duquel mpcd demande des paramètres. Si cette option est laissée vide et que -L est fourni, mpcd utilise l'adresse LECS à adresse connue attribuée par l'ATM Forum. Cette option est normalement identique à l'option -c de zeppelin.

EXEMPLES

Cet extrait de script montre comment exécuter LANE et MPOA. Après le démarrage de la signalisation UNI et de l'ILMI, LANE (zeppelin) et MPOA (mpcd) sont démarrés. La ligne commentée montre comment démarrer mpcd afin qu'il interroge le LECS pour les paramètres MPC.

Les arguments jaarli[1-3] sont des adresses ATM locales listées dans le fichier /etc/hosts.atm.

ATM=/usr/src/atm
case "$1" in
start)
cd $ATM
if [ -x sigd/atmsigd ] ; then


sigd/atmsigd -b
fi
if [ -x ilmid/ilmid ] ; then

ilmid/ilmid -b -x
fi
if [ -x led/zeppelin ] ; then

led/zeppelin -2 -n sampo -i2 -l jaarli3 &
ifconfig lec2 10.10.10.208 \

netmask 255.255.255.192 \
broadcast 10.10.10.255
ifconfig lec2 up
route add default gw 10.10.10.193
fi
if [ -x mpoad/mpcd ] ; then

mpoad/mpcd -i2 -s jaarli1 -l jaarli2 &
#mpoad/mpcd -i2 -s jaarli1 -l jaarli2 \
-L jaarli3 -n sampo &
fi
;;
esac
exit 0

BOGUES

Ne prend en charge que les ELAN de type Ethernet. Probablement d'autres aussi.
