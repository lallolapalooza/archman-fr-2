mpicc, mpic++, mpicxx, mpifort, mpijavac — Compilateurs enveloppes Open MPI

SYNTAX

mpicc [--showme | --showme:compile | --showme:link] ...

mpic++ [--showme | --showme:compile | --showme:link] ...

mpicxx [--showme | --showme:compile | --showme:link] ...

mpifort [--showme | --showme:compile | --showme:link] ...

mpijavac [--showme | --showme:compile | --showme:link] ...

Les commandes dépréciées suivantes sont également disponibles — mais mpifort doit être utilisé à leur place :

mpif77 [--showme | --showme:compile | --showme:link] ...

mpif90 [--showme | --showme:compile | --showme:link] ...

Sur les systèmes de fichiers sensibles à la casse, la commande suivante sera également disponible :

mpiCC [--showme | --showme:compile | --showme:link] ...

OPTIONS

Les options ci-dessous s'appliquent à tous les compilateurs enveloppes :

•
--showme : Cette option existe en plusieurs variantes (voir ci-dessous). Aucune des variantes n'invoque le compilateur sous-jacent ; elles fournissent toutes des informations sur la façon dont le compilateur sous-jacent aurait été invoqué si --showme n'avait pas été utilisé. L'option basique --showme affiche la ligne de commande qui serait exécutée pour compiler le programme.

NOTE :

Si un argument qui n'est pas un nom de fichier est passé sur la ligne de commande, l'option --showme n'affichera aucun drapeau supplémentaire. Par exemple, "mpicc --showme et mpicc --showme my_source.c afficheront tous les drapeaux fournis par l'enveloppe. Mais mpicc --showme -v n'affichera que le nom du compilateur sous-jacent et -v.
  • --showme:compile : Affiche les drapeaux du compilateur qui auraient été fournis au compilateur sous-jacent.
  • --showme:link : Affiche les drapeaux de l'éditeur de liens qui auraient été fournis au compilateur sous-jacent.
  • --showme:command : Affiche la commande du compilateur sous-jacent (qui peut être un ou plusieurs jetons).
  • --showme:incdirs : Affiche une liste d'espaces délimités (mais par ailleurs non décorés) de répertoires que le compilateur enveloppe aurait fournis au compilateur sous-jacent pour indiquer où se trouvent les fichiers d'en-tête pertinents.
  • --showme:libdirs : Affiche une liste d'espaces délimités (mais par ailleurs non décorés) de répertoires que le compilateur enveloppe aurait fournis à l'éditeur de liens sous-jacent pour indiquer où se trouvent les bibliothèques pertinentes.
  • --showme:libs : Affiche une liste d'espaces délimités (mais par ailleurs non décorés) de noms de bibliothèques que le compilateur enveloppe aurait utilisés pour lier une application. Par exemple : mpi open-pal util.
  • --showme:version : Affiche le numéro de version d'Open MPI.
  • --showme:help : Affiche un bref message d'aide d'utilisation.

Consultez la page de manuel de votre compilateur sous-jacent pour les autres options qui peuvent être transmises via mpicc.

DESCRIPTION

Conceptuellement, le rôle de ces commandes est assez simple : ajouter de manière transparente les compilateurs et les éditeurs de liens pertinents à la ligne de commande de l'utilisateur, nécessaires pour compiler/lier les programmes Open MPI, puis invoquer le compilateur sous-jacent pour exécuter réellement la commande.

En tant que tels, ces commandes sont souvent appelées compilateurs "enveloppes" car elles ne compilent ou ne lient pas les applications elles-mêmes ; elles ajoutent seulement des drapeaux à la ligne de commande et invoquent le compilateur de fond.

CONTEXTE

Open MPI fournit des compilateurs enveloppes pour plusieurs langages :

  • mpicc : C
  • mpic++, mpicxx (et sur les systèmes avec des systèmes de fichiers sensibles à la casse, mpiCC) : C++

    NOTE :

mpic++, mpicxx et mpiCC invoquent tous le même compilateur C++ sous-jacent avec les mêmes options. Tous sont fournis pour la compatibilité avec d'autres implémentations MPI.
  • mpifort (et ses alias hérités/dépréciés mpif77 et mpif90) : Fortran
  • mpijavac : Java

Les compilateurs enveloppes pour chacun des langages sont identiques ; ils peuvent être utilisés de manière interchangeable. Les différents noms sont fournis uniquement pour des raisons de compatibilité descendante.

NOTES FORTAN

Le compilateur enveloppe Fortran pour MPI (mpifort, et ses noms hérités/dépréciés mpif77 et mpif90) peut compiler et lier des applications MPI qui utilisent n'importe lesquels/tous les bindings Fortran MPI : mpif.h, le module mpi, et le module mpi_f08 (en supposant qu'Open MPI a été installé avec le support pour chacun de ces bindings Fortran). Spécifiquement : il n'est plus nécessaire d'utiliser différents compilateurs enveloppes pour les applications qui utilisent mpif.h par rapport aux applications qui utilisent le module mpi — utilisez simplement mpifort pour toutes les applications MPI Fortran.

Notez cependant que le compilateur Fortran peut nécessiter des options de ligne de commande supplémentaires pour imposer un dialecte Fortran spécifique. Par exemple, dans certaines versions du compilateur IBM XLF, si xlf90 est le compilateur Fortran sous-jacent, -qfixed peut être nécessaire pour compiler des fichiers source Fortran au format fixe.

Enfin, notez que mpifort sera inopérant et retournera une erreur en cas d'utilisation si le support Fortran n'a pas été intégré dans la couche MPI.

APERÇU

mpicc est une enveloppe de commodité pour le compilateur C sous-jacent. La traduction d'un programme Open MPI nécessite la liaison des bibliothèques spécifiques à Open MPI qui peuvent ne pas résider dans l'un des répertoires de recherche standards de ld(1). Elle nécessite également souvent l'inclusion de fichiers d'en-tête qui peuvent également ne pas se trouver dans un emplacement standard.

mpicc transmet ses arguments au compilateur C sous-jacent avec les options -I, -L et -l requises par les programmes Open MPI.

Il en va de même pour tous les autres compilateurs enveloppes de langage.

L'équipe Open MPI encourage vivement à utiliser les compilateurs enveloppes plutôt que d'essayer de lier manuellement les bibliothèques Open MPI. Cela permet à l'implémentation spécifique d'Open MPI de changer sans forcer de changements aux directives de l'éditeur de liens dans les Makefiles des utilisateurs. En effet, l'ensemble spécifique de drapeaux et de bibliothèques utilisés par les compilateurs enveloppes dépend de la manière dont Open MPI a été configuré et construit ; les valeurs peuvent changer entre différentes installations de la même version d'Open MPI.

En effet, puisque les enveloppes ne sont que des coquilles minces au-dessus d'un compilateur sous-jacent, il y a très, très peu de raisons convaincantes de ne pas utiliser les compilateurs enveloppes d'Open MPI. Lorsqu'il n'est pas possible d'utiliser directement les enveloppes, les options --showme:compile et --showme:link doivent être utilisées pour déterminer quels drapeaux les enveloppes auraient utilisés. Par exemple :

shell$ cc -c file1.c `mpicc --showme:compile`
shell$ cc -c file2.c `mpicc --showme:compile`
shell$ cc file1.o file2.o `mpicc --showme:link` -o my_mpi_program

NOTES

Il est possible de rendre les compilateurs enveloppes conscients des bibliothèques multiples. C'est-à-dire que les bibliothèques et les inclusions spécifiées peuvent différer en fonction des drapeaux du compilateur spécifiés (par exemple, avec les compilateurs GNU sous Linux, un chemin de bibliothèque différent peut être utilisé si -m32 est vu par rapport à -m64 étant vu). Ce n'est pas le comportement par défaut dans une construction standard, mais peut être activé (par exemple, dans un paquet binaire fournissant un support 32 et 64 bits). Plus d'informations peuvent être trouvées ici.

FICHIERS

Les chaînes que les compilateurs enveloppes insèrent dans la ligne de commande avant d'invoquer le compilateur sous-jacent sont stockées dans un fichier texte créé par Open MPI et installé dans $pkgdata/NAME-wrapper-data.txt, où :

  • $pkgdata est généralement $prefix/share/openmpi
  • $prefix est le répertoire d'installation principal d'Open MPI
  • NAME est le nom du compilateur enveloppe (par exemple, $pkgdata/mpicc-wrapper-data.txt)

FILES

The Open MPI compilers wrappers (mpicc, mpicxx, mpif77, mpif90) are implemented by a script that is configured during the Open MPI installation. The configuration information is stored in a set of text files within the Open MPI installation tree. These files contain information about the compilers that are to be invoked, and also other flags that are appended to the command line.

It is rarely necessary to edit these files, but they can be examined to gain insight into what flags the wrappers are placing on the command line.

VARIABLE D'ENVIRONNEMENT

Par défaut, les wrappers utilisent les compilateurs qui ont été sélectionnés lors de la configuration d'Open MPI. Ces compilateurs ont été trouvés automatiquement par le script de configuration d'Open MPI, ou ont été sélectionnés par l'utilisateur dans les variables d'environnement CC, CXX et/ou FC avant que la configuration ne soit appelée. De plus, d'autres arguments spécifiques au compilateur peuvent avoir été sélectionnés par la configuration.

Ces valeurs peuvent être remplacées sélectivement soit en modifiant les fichiers texte contenant ces informations de configuration (voir la section FICHIERS), soit en définissant des variables d'environnement sélectionnées de la forme ompi_value.

Les noms de valeurs valides sont :

  • CPPFLAGS : Indicateurs ajoutés lors de l'invocation du préprocesseur (C ou C++).
  • LDFLAGS : Indicateurs ajoutés lors de l'invocation de l'éditeur de liens (C, C++ ou Fortran).
  • LIBS : Bibliothèques ajoutées lors de l'invocation de l'éditeur de liens (C, C++ ou Fortran).
  • CC : Compilateur C.
  • CFLAGS : Indicateurs du compilateur C.
  • CXX : Compilateur C++.
  • CXXFLAGS : Indicateurs du compilateur C++.
  • FC : Compilateur Fortran.
  • FCFLAGS : Indicateurs du compilateur Fortran.
