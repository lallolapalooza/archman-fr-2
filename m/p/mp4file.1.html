mp4file(1)

Paquet: libmp4v2

Licences: MPL

MP4FILE(-) Mai 2023 MP4FILE(-)

NOM

mp4file - MP4v2 - page de manuel pour mp4file - MP4v2 2.1.3

SYNTAXE

mp4file [OPTION]... ACTION fichier...

DESCRIPTION

Pour chaque fichier mp4 spécifié, effectuez l'ACTION spécifiée. Une action doit être spécifiée. Certaines options ne sont pas applicables à certaines actions.

ACTIONS

--list
lister (informations sommaires)
--optimize
optimiser la structure mp4
--dump
extraire la structure mp4 dans un format lisible par l'homme

OPTIONS

-y, --dryrun
ne pas créer ou modifier réellement de fichiers
-k, --keepgoing
continuer le traitement par lots même après les erreurs
-q, --quiet
équivalent à --verbose 0
-d, --debug NUM
augmenter le débogage ou l'option longue pour définir NUM
-v, --verbose NUM
augmenter la verbosité ou l'option longue pour définir NUM
-h, --help
afficher une aide brève ou une option longue pour une aide étendue
--version
afficher les informations de version et quitter

NIVEAUX DE DÉBOGAGE (pour l'E/S brute de fichiers mp4)

0
supprimé
1
ajouter des avertissements et des erreurs (par défaut)
2
ajouter des détails de table
3
ajouter des implicites
4
tout

NIVEAUX DE VERBOSITÉ

0
avertissements et erreurs
1
messages informatifs normaux (par défaut)
2
messages plus informatifs
3
tout
