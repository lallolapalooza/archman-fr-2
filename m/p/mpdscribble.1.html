NOM

mpdscribble - Un client Music Player Daemon (MPD) qui soumet des informations sur les pistes en cours de lecture à un scrobbler (par ex. last.fm).

SYNTAXE

mpdscribble [options]

DESCRIPTION

mpdscribble est un client pour MPD, le Music Player Daemon. mpdscribble se connecte à un MPD en cours d'exécution sur le réseau local et fonctionne en parallèle avec d'autres clients MPD sur le réseau.

Par défaut, il obtiendra le nom d'hôte et le port de mpd à partir des variables d'environnement MPD_HOST et MPD_PORT. mpdscribble utilisera localhost:6600 si elles ne sont pas définies. Le nom d'hôte et le port peuvent également être spécifiés dans le fichier de configuration ou sur la ligne de commande.

$ mpdscribble --host monhote --port=12345

Les valeurs spécifiées sur la ligne de commande remplacent les valeurs du fichier de configuration ou des variables d'environnement.

Si vous souhaitez utiliser mpdscribble avec un MPD protégé par mot de passe, définissez la variable d'environnement MPD_HOST sur motdepasse@hote, ou spécifiez l'hote de manière similaire dans le fichier de configuration.

En cas d'échec de soumission, mpdscribble attend un certain temps puis réessaie. L'envoi d'un signal USR1 à un processus mpdscribble en cours d'exécution le fait soumettre immédiatement.

OPTIONS

--help
Affiche l'aide et quitte.
--version
Affiche les informations de version et quitte.
--no-daemon
Ne pas démoniser mpdscribble, le faire tourner en avant-plan.
--pidfile FICHIER
Écrit l'identifiant du processus dans ce fichier.
--daemon-user NOMUTILISATEUR
Changer pour cet utilisateur système après la démonisation.
--log FICHIER
Spécifie le fichier journal. La valeur spéciale « syslog » fait utiliser à mpdscribble le démon syslog local (ce qui est le défaut). « - » signifie enregistrer sur stderr.
--conf FICHIER
Lit les options de configuration à partir du fichier. /etc/mpdscribble.conf est utilisé par défaut (si --sysconfdir=/etc).
--host [MOTDEPASSE@]NOMHOTE
Spécifie l'hôte protégé par un mot de passe. Pour se connecter via un socket Unix Domain, spécifiez un chemin absolu ici.
--port PORT
Spécifie sur quel port MPD écoute.
--proxy URL
URL du proxy HTTP.
--verbose NIVEAU
Spécifie le niveau de verbosité de la journalisation de mpdscribble. Les valeurs possibles sont de 0 à 3, avec 1 par défaut.

CONFIGURATION

mpdscribble recherche son fichier de configuration dans l'ordre suivant : $XDG_CONFIG_HOME/mpdscribble/mpdscribble.conf, ~/.config/mpdscribble/mpdscribble.conf, ~/.mpdscribble/mpdscribble.conf, /etc/mpdscribble.conf (si --sysconfdir=/etc), mais cela peut être remplacé en spécifiant un fichier de configuration alternatif à l'aide de l'option de ligne de commande --conf.

Options de configuration supportées :

pidfile = FICHIER
Écrit l'identifiant du processus dans ce fichier.
log = FICHIER
Le fichier auquel mpdscribble doit écrire les informations de débogage. La valeur spéciale « syslog » fait utiliser à mpdscribble le démon syslog local (ce qui est le défaut). « - » signifie enregistrer sur stderr.
host = [MOTDEPASSE@]NOMHOTE
L'hôte exécutant MPD, potentiellement protégé par un mot de passe. Pour se connecter via un socket Unix Domain, spécifiez un chemin absolu ici.
port = PORT
Le port sur lequel MPD écoute et auquel mpdscribble doit essayer de se connecter.
proxy = URL
URL du proxy HTTP.
verbose = 0, 1, 2, 3
Le niveau de verbosité de la journalisation de mpdscribble. Par défaut 1. « 0 » signifie enregistrer uniquement les erreurs critiques (par ex. « manque de mémoire ») ; « 1 » enregistre également les erreurs non critiques (par ex. « serveur inaccessible ») ; « 2 » enregistre les messages informatifs (par ex. « nouvelle chanson ») ; « 3 » affiche beaucoup de messages de débogage.

SCROBBLEURS

Ces options sont suivies d'au moins une section de scrobbler (choisissez un nom de section unique comme « libre.fm » qui n'apparaît que dans le fichier journal ; le nom « mpdscribble » est réservé).

file = CHEMIN
Enregistrer dans un fichier au lieu de soumettre les chansons à un serveur AudioScrobbler.
url = URL
L'URL de poignée de main du scrobbler. Exemple : "https://post.audioscrobbler.com/", "http://turtle.libre.fm/"
username = NOMUTILISATEUR
Votre nom d'utilisateur audioscrobbler.
password = SOMMEDEMD5
Votre mot de passe Last.fm, en clair ou sa somme MD5.
journal = FICHIER
Le fichier où mpdscribble doit stocker son journal au cas où vous n'auriez pas de connexion au scrobbler. Cette option était auparavant appelée « cache ». Elle est facultative.

FICHIERS

/etc/mpdscribble.conf

Le fichier de configuration système.

~/.config/mpdscribble/mpdscribble.conf

Fichier de configuration par utilisateur.

/var/cache/mpdscribble/mpdscribble.cache

Le fichier cache Last.fm système.

~/.cache/mpdscribble/mpdscribble.cache

Fichier cache Last.fm par utilisateur.

/var/log/mpdscribble/mpdscribble.log

Le fichier journal système.

BOGUES

Les permissions de fichier sur le fichier cache/journal peuvent être insécuritaires par défaut.

Veuillez signaler les nouveaux bogues au traqueur de bogues de MPD : http://www.musicpd.org/mantis
