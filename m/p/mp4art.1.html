NOM

mp4art - MP4v2 - page de manuel pour mp4art - MP4v2 2.1.3

SYNTAXE

mp4art [OPTION]... ACTION fichier...

DESCRIPTION

Pour chaque fichier mp4 (m4a) spécifié, effectuez l'ACTION spécifiée. Une action doit être spécifiée. Certaines options ne sont pas applicables à certaines actions.

ACTIONS

--list
lister toutes les covr-boxes
--add IMG
ajouter une covr-box à partir du fichier IMG
--replace IMG
remplacer la covr-box par le fichier IMG
--remove
supprimer la covr-box
--extract
extraire la covr-box

PARAMÈTRES D'ACTION

--art-any
agir sur toutes les covr-boxes (par défaut)
--art-index IDX
agir sur la covr-box d'index IDX

OPTIONS

-z, --optimize
optimiser le fichier mp4 après modification
-y, --dryrun
ne pas créer ni modifier réellement de fichiers
-k, --keepgoing
continuer le traitement par lots même en cas d'erreurs
-o, --overwrite
écraser les fichiers existants lors de la création
-f, --force
forcer l'écrasement même si le fichier est en lecture seule
-q, --quiet
équivalent à --verbose 0
-d, --debug NUM
augmenter le débogage ou l'option longue pour définir NUM
-v, --verbose NUM
augmenter la verbosité ou l'option longue pour définir NUM
-h, --help
afficher l'aide courte ou l'option longue pour l'aide étendue
--version
afficher les informations de version et quitter

NIVEAUX DE DÉBOGAGE (pour les entrées/sorties brutes de fichiers mp4)

0
supprimé
1
ajouter des avertissements et des erreurs (par défaut)
2
ajouter des détails de table
3
ajouter des implicites
4
tout

NIVEAUX DE VERBOSITÉ

0
avertissements et erreurs
1
messages informatifs normaux (par défaut)
2
messages plus informatifs
3
tout
