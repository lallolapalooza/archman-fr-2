MPSTAT(1) Manuel de l'utilisateur Linux MPSTAT(1)

NOM

mpstat - Rapporte les statistiques relatives aux processeurs.

SYNTAXE

mpstat [ -A ] [ --dec={ 0 | 1 | 2 } ] [ -H ] [ -n ] [ -U ] [ -u ] [ -T ] [ -V ] [ -I { mot-clé[,...] | ALL } ] [ -N { liste-nœuds | ALL } ] [ -o JSON ] [ -P { liste-cpu | ALL } ] [ intervalle [ compte ] ]

DESCRIPTION

La commande mpstat écrit sur la sortie standard les activités pour chaque processeur disponible, le processeur 0 étant le premier. Les activités moyennes globales entre tous les processeurs sont également rapportées. La commande mpstat peut être utilisée sur les machines SMP et UP, mais dans ce dernier cas, seules les activités moyennes globales seront imprimées. Si aucune activité n'a été sélectionnée, le rapport par défaut est le rapport d'utilisation du CPU.

Le paramètre intervalle spécifie la durée en secondes entre chaque rapport. Une valeur de 0 (ou aucun paramètre) indique que les statistiques des processeurs doivent être rapportées depuis le démarrage du système (boot). Le paramètre compte peut être spécifié en conjonction avec le paramètre intervalle si celui-ci n'est pas mis à zéro. La valeur de compte détermine le nombre de rapports générés à intervalle secondes d'intervalle. Si le paramètre intervalle est spécifié sans le paramètre compte, la commande mpstat génère des rapports en continu.

OPTIONS

-A
Cette option est équivalente à la spécification de -n -u -I ALL. Cette option implique également la spécification de -N ALL -P ALL sauf si ces options sont explicitement définies sur la ligne de commande.
--dec={ 0 | 1 | 2 }
Spécifie le nombre de décimales à utiliser (0 à 2, la valeur par défaut est 2).
-H
Détecte et affiche également les statistiques pour les vCPUs physiquement hotplugged.
-I { mot-clé[,...] | ALL }
Rapporte les statistiques d'interruptions. Les mots-clés possibles sont CPU, SCPU et SUM.
Avec le mot-clé CPU, le nombre de chaque interruption individuelle reçue par seconde par le(s) CPU est affiché. Les interruptions sont celles listées dans le fichier /proc/interrupts.

Avec le mot-clé SCPU, le nombre de chaque interruption logicielle individuelle reçue par seconde par le(s) CPU est affiché. Cette option ne fonctionne qu'avec les noyaux 2.6.31 et plus récents. Les interruptions logicielles sont celles listées dans le fichier /proc/softirqs.

Avec le mot-clé SUM, la commande mpstat rapporte le nombre total d'interruptions par processeur. Les valeurs suivantes sont affichées :

CPU
Numéro du processeur. Le mot-clé all indique que les statistiques sont calculées comme des moyennes entre tous les processeurs.
intr/s
Affiche le nombre total d'interruptions reçues par seconde par le(s) CPU.
Le mot-clé ALL est équivalent à la spécification de tous les mots-clés ci-dessus et par conséquent toutes les statistiques d'interruptions sont affichées.
-N { liste-nœuds | ALL }
Indique les nœuds NUMA pour lesquels les statistiques doivent être rapportées. liste-nœuds est une liste de valeurs séparées par des virgules ou des plages de valeurs (par exemple, 0,2,4-7,12-). Notez que le nœud all est la moyenne globale entre tous les nœuds. Le mot-clé ALL indique que les statistiques doivent être rapportées pour tous les nœuds.
-n
Rapporte les statistiques CPU résumées basées sur le placement du nœud NUMA. Les valeurs suivantes sont affichées :
NODE
Numéro logique du nœud NUMA. Le mot-clé all indique que les statistiques sont calculées comme des moyennes entre tous les nœuds.
Tous les autres champs sont identiques à ceux affichés avec l'option -u (voir ci-dessous).
-o JSON
Affiche les statistiques au format JSON (JavaScript Object Notation). L'ordre des champs de sortie JSON est indéfini, et de nouveaux champs peuvent être ajoutés à l'avenir.
-P { liste-cpu | ALL }
Indique les processeurs pour lesquels les statistiques doivent être rapportées. liste-cpu est une liste de valeurs séparées par des virgules ou des plages de valeurs (par exemple, 0,2,4-7,12-). Notez que le processeur 0 est le premier processeur, et le processeur all est la moyenne globale entre tous les processeurs. Le mot-clé ALL indique que les statistiques doivent être rapportées pour tous les processeurs. Les processeurs hors ligne ne sont pas affichés.
-T
Affiche les éléments de topologie dans le rapport CPU (voir l'option -u ci-dessous). Les éléments suivants sont affichés :
CORE
Numéro logique du cœur.
SOCK
Numéro logique du socket.
NODE
Numéro logique du nœud NUMA.
-U
Affiche l'horodatage (UTC - Temps Universel Coordonné) en secondes depuis l'époque.
-u
Rapporte l'utilisation du CPU. Les valeurs suivantes sont affichées :
CPU
Numéro du processeur. Le mot-clé all indique que les statistiques sont calculées comme des moyennes entre tous les processeurs.
%usr">%usr
Affiche le pourcentage d'utilisation du CPU qui s'est produit lors de l'exécution au niveau utilisateur (application).
%nice">%nice
Affiche le pourcentage d'utilisation du CPU qui s'est produit lors de l'exécution au niveau utilisateur avec une priorité nice.
%sys">%sys
Affiche le pourcentage d'utilisation du CPU qui s'est produit lors de l'exécution au niveau système (noyau). Notez que cela n'inclut pas le temps passé à traiter les interruptions matérielles et logicielles.
%iowait">%iowait
Affiche le pourcentage de temps pendant lequel le(s) CPU était inactif(s) et pendant lequel le système avait une requête d'E/S disque en attente.
%irq">%irq
Affiche le pourcentage de temps passé par le(s) CPU à traiter les interruptions matérielles.
%soft">%soft
Affiche le pourcentage de temps passé par le(s) CPU à traiter les interruptions logicielles.
%steal">%steal
Affiche le pourcentage de temps passé en attente involontaire par le(s) CPU virtuels pendant que l'hyperviseur gérait un autre processeur virtuel.
%guest">%guest
Affiche le pourcentage de temps passé par le(s) CPU à exécuter un processeur virtuel.
%gnice">%gnice
Affiche le pourcentage de temps passé par le(s) CPU à exécuter un invité niced.
%idle">%idle
Affiche le pourcentage de temps pendant lequel le(s) CPU était inactif(s) et pendant lequel le système n'avait pas de requête d'E/S disque en attente.
-V
Affiche le numéro de version puis quitte.

ENVIRONNEMENT

La commande mpstat prend en compte la variable d'environnement suivante :

S_COLORS
Par défaut, les statistiques sont affichées en couleur lorsque la sortie est connectée à un terminal. Utilisez cette variable pour modifier les paramètres. Les valeurs possibles pour cette variable sont never, always ou auto (cette dernière est équivalente aux paramètres par défaut).
Veuillez noter que la couleur (rouge, jaune ou une autre couleur) utilisée pour afficher une valeur n'indique aucun problème simplement à cause de la couleur. Elle indique seulement différentes plages de valeurs.
S_COLORS_SGR
Spécifie les couleurs et autres attributs utilisés pour afficher les statistiques sur le terminal. Sa valeur est une liste de capacités séparées par des deux-points par défaut à I=32;22:N=34;1:W=35;1:X=

NOM

mpstat - signaler des statistiques du processeur.

SYNOPIS

mpstat [ OPTIONS ] [ interval [ count ] ]

DESCRIPTION

La commande mpstat collecte et signale les statistiques du processeur à partir du système de fichiers /proc. La commande peut être utilisée pour surveiller l'activité globale du système ou l'activité de processeurs individuels.

OPTIONS

-A
Ceci est l'équivalent de spécifier les options -u, -I, -N, -o, -w, et -x.
-I { keyword,... | ALL }
Statistiques d'interruption. La spécification de ALL ou de plusieurs mots-clés produira des rapports sur les statistiques d'interruption du processeur.
-N { keyword,... | ALL }
Statistiques de noyau. La spécification de ALL ou de plusieurs mots-clés produira des rapports sur les statistiques du noyau du processeur.
-o [ filename ]
Exporte les statistiques des compteurs de performance dans un fichier spécifié par le paramètre filename. Si le paramètre filename n'est pas fourni, alors la sortie sera écrite sur la sortie standard.
-P { cpu,... | ALL }
Indique la liste des processeurs pour lesquels les statistiques doivent être rapportées. Le mot-clé ALL fait référence à tous les processeurs. Par défaut, seules les statistiques globales de tous les processeurs sont affichées.
-u
Signale les statistiques d'utilisation du processeur.
-V
Affiche la version et quitte.
-w
Signale les statistiques d'utilisation de la mémoire.
-x [ filename ]
Affiche des statistiques d'extensions. Ces statistiques incluent des compteurs avancés qui peuvent être utiles pour le débogage de problèmes de performance.
Z=
Sous-chaîne SGR pour les valeurs nulles.
I=
Sous-chaîne SGR pour le numéro de CPU.
N=
Sous-chaîne SGR pour les valeurs de statistiques non nulles.
W= (ou M=)
Sous-chaîne SGR pour les valeurs en pourcentage comprises entre 75 % et 90 % (ou comprises entre 10 % et 25 % selon la signification de la métrique).
X= (ou H=)
Sous-chaîne SGR pour les valeurs en pourcentage supérieures ou égales à 90 % (ou inférieures ou égales à 10 % selon la signification de la métrique).
Z=
Sous-chaîne SGR pour les valeurs nulles.
S_TIME_FORMAT
Si cette variable existe et que sa valeur est ISO, alors le paramètre régional actuel sera ignoré lors de l'impression de la date dans l'en-tête du rapport. La commande mpstat utilisera le format ISO 8601 (AAAA-MM-JJ) à la place. L'horodatage sera également conforme au format ISO 8601.

EXEMPLES

mpstat 2 5
Affiche cinq rapports de statistiques globales sur tous les processeurs avec des intervalles de deux secondes.
mpstat -P ALL 2 5
Affiche cinq rapports de statistiques pour tous les processeurs avec des intervalles de deux secondes.

BOGUES

Le système de fichiers /proc doit être monté pour que la commande mpstat fonctionne.

FICHIERS

/proc contient divers fichiers avec des statistiques système.
