mpartition(1) Manuel des commandes générales mpartition(1)

Nom

mpartition - partitionner un disque dur MSDOS

Note déavertissement

Cette page de manuel a été générée automatiquement à partir de la documentation texinfo de mtools, et peut ne pas être entièrement exacte ou complète. Voir la fin de cette page de manuel pour plus de détails.

Description

La commande mpartition est utilisée pour créer des systèmes de fichiers MS-DOS en tant que partitions. Ceci est destiné à être utilisé sur des systèmes non-Linux, c'est-à-dire des systèmes où fdisk et un accès facile aux périphériques SCSI ne sont pas disponibles. Cette commande ne fonctionne que sur les disques dont la variable partition est définie.

mpartition -p disque
mpartition -r disque
mpartition -I [-B secteurDémarrage] disque 
mpartition -a disque
mpartition -d disque
mpartition -c [-s secteurs] [-h têtes]
[-t cylindres] [-v [-T type] [-b
début] [-l longueur] [-f]

Mpartition supporte les opérations suivantes :

p 
Affiche une ligne de commande pour recréer la partition pour le disque. Rien n'est affiché si la partition pour le disque n'est pas définie, ou si une incohérence a été détectée. Si verbose (-v) est également défini, affiche la table de partition actuelle.
r 
Supprime la partition décrite par disque.
I 
Initialise la table de partition, et supprime toutes les partitions.
c 
Crée la partition décrite par disque.
a 
"Active" la partition, c'est-à-dire la rend démarrable. Une seule partition peut être démarrable à la fois.
d 
"Désactive" la partition, c'est-à-dire la rend non-démarrable.

Si aucune opération n'est donnée, les paramètres actuels sont affichés.

Pour les créations de partition, les options suivantes sont disponibles :

s secteurs 
Le nombre de secteurs par piste de la partition (qui est aussi le nombre de secteurs par piste pour le disque entier).
h têtes 
Le nombre de têtes de la partition (qui est aussi le nombre de têtes pour le disque entier). Par défaut, les informations de géométrie (nombre de secteurs et de têtes) sont déduites des entrées voisines de la table de partition, ou devinées à partir de la taille.
t cylindres 
Le nombre de cylindres de la partition (pas le nombre de cylindres du disque entier).
b début 
L'offset de départ de la partition, exprimé en secteurs. Si début n'est pas donné, mpartition laisse la partition commencer au début du disque (partition numéro 1), ou immédiatement après la fin de la partition précédente.
l longueur 
La taille (longueur) de la partition, exprimée en secteurs. Si fin n'est pas donné, mpartition déduit la taille à partir du nombre de secteurs, de têtes et de cylindres. Si ceux-ci ne sont pas non plus donnés, il donne à la partition la plus grande taille possible, en tenant compte de la taille du disque et du début de la partition suivante.

L'option suivante est disponible pour toutes les opérations qui modifient la table de partition :

f 
Habituellement, avant de réécrire les modifications sur la partition, mpartition effectue certaines vérifications de cohérence, comme la vérification des chevauchements et un alignement correct des partitions. Si l'une de ces vérifications échoue, la table de partition n'est pas modifiée. L'option -f vous permet de outrepasser ces mesures de sécurité.

Les options suivantes sont disponibles pour toutes les opérations :

v 
Associé à -p, affiche la table de partition telle qu'elle est actuellement (aucune opération de modification), ou telle qu'elle est après modification. Avec une double verbosité (-vv), mpartition affichera un hexdump de la table de partition lors de sa lecture depuis et de son écriture sur le périphérique.

L'option suivante est disponible pour l'initialisation de la table de partition :

B secteurDémarrage 
Lit le secteur d'amorçage maître modèle à partir du fichier secteurDémarrage.

Choix du type de partition

Mpartition procède comme suit pour choisir un type pour la partition :

-  
Les partitions FAT32 se voient attribuer le type 0x0C ("Win95 FAT32, LBA").
-  
Pour toutes les autres, si la partition rentre entièrement dans les 65536 premiers secteurs du disque, attribuer 0x01 ("DOS FAT12, CHS") pour les partitions FAT12 et 0x04 ("DOS FAT16, CHS") pour les partitions FAT16.
-  
Si non couvert par ce qui précède, attribuer 0x06 ("DOS BIG FAT16 CHS") si la partition rentre entièrement dans les 1024 premiers cylindres (mode CHS).
-  
Tous les cas restants reçoivent 0x0E ("Win95 BIG FAT16, LBA").

Si le nombre de bits FAT est inconnu (non spécifié dans la définition du disque), alors FAT12 est supposé pour tous les disques avec moins de 4096 secteurs, et FAT16 pour ceux avec plus de 4096 secteurs.

Ceci correspond plus ou moins aux définitions décrites sur https://en.wikipedia.org/wiki/Partition_type#List_of_partition_IDs et https://docs.microsoft.com/en-us/previous-versions/windows/it-pro/windows-2000-server/cc977219(v=technet.10), avec deux différences notables :

-  
Si les bits FAT sont inconnus, les documents de référence considèrent les disques avec moins de 32680 secteurs comme FAT12. Mtools utilise 4096 secteurs comme seuil, car les anciennes versions de DOS ne supportent FAT12 que sur les disques de moins de 4096 secteurs (et ce sont ces anciennes versions qui seraient les plus susceptibles d'utiliser FAT12 en premier lieu).
-  
Les documents de référence utilisent une limite de 8 Go (wikipedia) ou 4 Go (Microsoft) entre 0x06 (DOS BIG FAT16 CHS) et 0x0E. Mtools utilise 1024 cylindres. En effet, toute partition au-delà de 1024 cylindres doit être LBA et ne peut pas être CHS. 8 Go correspond à la capacité maximale qui peut être représentée en CHS (63 secteurs, 255 têtes et 1024 cylindres). 4 Go est la limite de capacité pour Windows 2000, il est donc logique qu'une documentation pour Windows 2000 spécifie ceci comme limite supérieure pour tout type de partition.

Viewing the texi doc

This manpage has been automatically generated from mtools's texinfo documentation. However, this process is only approximative, and some items, such as crossreferences, footnotes and indices are lost in this translation process. Indeed, these items have no appropriate representation in the manpage format. Moreover, not all information has been translated into the manpage version. Thus I strongly advise you to use the original texinfo doc. See the end of this manpage for instructions how to view the texinfo doc.

*   
To generate a printable copy from the texinfo doc, run the following commands: 
    ./configure; make dvi; dvips mtools.dvi

*   
To generate a html copy, run: 
    ./configure; make html

A premade html can be found at `http://www.gnu.org/software/mtools/manual/mtools.html'

*   
To generate an info copy (browsable using emacs' info mode), run: 
    ./configure; make info

The texinfo doc looks most pretty when printed or as html. Indeed, in the info version certain examples are difficult to read due to the quoting conventions used in info.
