mpicc, mpic++, mpicxx, mpifort, mpijavac — Compilateurs enveloppants Open MPI

SYNTAX

mpicc [--showme | --showme:compile | --showme:link] ...

mpic++ [--showme | --showme:compile | --showme:link] ...

mpicxx [--showme | --showme:compile | --showme:link] ...

mpifort [--showme | --showme:compile | --showme:link] ...

mpijavac [--showme | --showme:compile | --showme:link] ...

Les commandes obsolètes suivantes sont également disponibles — mais mpifort doit être utilisé à leur place :

mpif77 [--showme | --showme:compile | --showme:link] ...

mpif90 [--showme | --showme:compile | --showme:link] ...

Sur les systèmes de fichiers sensibles à la casse, la commande suivante sera également disponible :

mpiCC [--showme | --showme:compile | --showme:link] ...

OPTIONS

Les options ci-dessous s'appliquent à tous les compilateurs enveloppants :

•
--showme : Cette option se présente sous plusieurs variantes différentes (voir ci-dessous). Aucune des variantes n'invoque le compilateur sous-jacent ; elles fournissent toutes des informations sur la manière dont le compilateur sous-jacent aurait été invoqué si --showme n'avait pas été utilisé. L'option de base --showme affiche la ligne de commande qui serait exécutée pour compiler le programme.

NOTE :

Si un argument autre qu'un nom de fichier est passé sur la ligne de commande, l'option --showme n'affichera aucun indicateur supplémentaire. Par exemple, "mpicc --showme et mpicc --showme my_source.c afficheront tous les indicateurs fournis par l'enveloppe. Mais mpicc --showme -v n'affichera que le nom du compilateur sous-jacent et -v.
  • --showme:compile : Affiche les indicateurs de compilation qui auraient été fournis au compilateur sous-jacent.
  • --showme:link : Affiche les indicateurs d'édition de liens qui auraient été fournis au compilateur sous-jacent.
  • --showme:command : Affiche la commande du compilateur sous-jacent (qui peut être un ou plusieurs jetons).
  • --showme:incdirs : Affiche une liste de répertoires, séparés par des espaces (mais sinon non décorée), que le compilateur enveloppant aurait fournie au compilateur sous-jacent pour indiquer où se trouvent les fichiers d'en-tête pertinents.
  • --showme:libdirs : Affiche une liste de répertoires, séparés par des espaces (mais sinon non décorée), que le compilateur enveloppant aurait fournie à l'éditeur de liens sous-jacent pour indiquer où se trouvent les bibliothèques pertinentes.
  • --showme:libs : Affiche une liste de noms de bibliothèques, séparés par des espaces (mais sinon non décorée), que le compilateur enveloppant aurait utilisés pour lier une application. Par exemple : mpi open-pal util.
  • --showme:version : Affiche le numéro de version d'Open MPI.
  • --showme:help : Affiche un bref message d'aide d'utilisation.

Consultez la page de manuel de votre compilateur sous-jacent pour connaître les autres options qui peuvent être transmises via mpicc.

DESCRIPTION

Conceptuellement, le rôle de ces commandes est assez simple : ajouter de manière transparente à la ligne de commande de l'utilisateur les indicateurs de compilation et d'édition de liens pertinents qui sont nécessaires pour compiler / lier des programmes Open MPI, puis invoquer le compilateur sous-jacent pour exécuter réellement la commande.

En tant que tels, ces commandes sont souvent appelées compilateurs “enveloppants” car elles ne compilent ni ne lient les applications elles-mêmes ; elles n'ajoutent que des indicateurs de ligne de commande et invoquent le compilateur backend.

BACKGROUND

Open MPI fournit des compilateurs enveloppants pour plusieurs langages :

  • mpicc : C
  • mpic++, mpicxx (et sur les systèmes avec des systèmes de fichiers sensibles à la casse, mpiCC) : C++

    NOTE :

mpic++, mpicxx et mpiCC invoquent tous le même compilateur C++ sous-jacent avec les mêmes options. Tous sont fournis pour la compatibilité avec d'autres implémentations MPI.
  • mpifort (et ses alias obsolètes/dépréciés mpif77 et mpif90) : Fortran
  • mpijavac : Java

Les compilateurs enveloppants pour chacun des langages sont identiques ; ils peuvent être utilisés de manière interchangeable. Les différents noms sont fournis uniquement pour des raisons de compatibilité ascendante.

NOTES FORTAN

Le compilateur enveloppant Fortran pour MPI (mpifort, et ses noms obsolètes/dépréciés mpif77 et mpif90) peut compiler et lier des applications MPI qui utilisent tout/tous les bindings Fortran MPI : mpif.h, le module mpi, et le module mpi_f08 (en supposant qu'Open MPI a été installé avec le support pour chacun de ces bindings Fortran). Spécifiquement : il n'est plus nécessaire d'utiliser différents compilateurs enveloppants pour les applications qui utilisent mpif.h par rapport aux applications qui utilisent le module mpi — utilisez simplement mpifort pour toutes les applications MPI Fortran.

Notez cependant que le compilateur Fortran peut nécessiter des options de ligne de commande supplémentaires pour imposer un dialecte Fortran spécifique. Par exemple, dans certaines versions du compilateur IBM XLF, -qfixed peut être nécessaire pour compiler des fichiers source Fortran au format fixe.

Enfin, notez que mpifort sera inopérant et retournera une erreur à l'utilisation si le support Fortran n'a pas été intégré à la couche MPI.

APERÇU

mpicc est une enveloppe pratique pour le compilateur C sous-jacent. La traduction d'un programme Open MPI nécessite la liaison des bibliothèques spécifiques à Open MPI qui peuvent ne pas se trouver dans l'un des répertoires de recherche standard de ld(1). Elle nécessite également souvent l'inclusion de fichiers d'en-tête qui peuvent également ne pas être trouvés dans un emplacement standard.

mpicc transmet ses arguments au compilateur C sous-jacent ainsi que les options -I, -L et -l requises par les programmes Open MPI.

Il en va de même pour tous les autres compilateurs enveloppants de langage.

L'équipe Open MPI encourage *fortement* l'utilisation des compilateurs enveloppants au lieu d'essayer de lier manuellement aux bibliothèques Open MPI. Cela permet à l'implémentation spécifique d'Open MPI de changer sans forcer les changements dans les directives de l'éditeur de liens des Makefiles des utilisateurs. En effet, l'ensemble spécifique d'indicateurs et de bibliothèques utilisés par les compilateurs enveloppants dépend de la manière dont Open MPI a été configuré et construit ; les valeurs peuvent changer entre différentes installations de la même version d'Open MPI.

En effet, puisque les enveloppes ne sont que de minces couches au-dessus d'un compilateur sous-jacent, il y a très, très peu de raisons impérieuses de *ne pas* utiliser les compilateurs enveloppants d'Open MPI. Lorsqu'il n'est pas possible d'utiliser directement les enveloppes, les options --showme:compile et --showme:link doivent être utilisées pour déterminer quels indicateurs les enveloppes auraient utilisés. Par exemple :

shell$ cc -c file1.c `mpicc --showme:compile`
shell$ cc -c file2.c `mpicc --showme:compile`
shell$ cc file1.o file2.o `mpicc --showme:link` -o my_mpi_program

NOTES

Il est possible de rendre les compilateurs enveloppants conscients des multiples bibliothèques. C'est-à-dire que les bibliothèques et les includes spécifiés peuvent différer en fonction des indicateurs de compilateur spécifiés (par exemple, avec les compilateurs GNU sous Linux, un chemin de bibliothèque différent peut être utilisé si -m32 est vu par rapport à -m64). Ce n'est pas le comportement par défaut dans une construction standard, mais cela peut être activé (par exemple, dans un paquet binaire fournissant un support 32 et 64 bits). Plus d'informations peuvent être trouvées ici.

FICHIERS

Les chaînes que les compilateurs enveloppants insèrent dans la ligne de commande avant d'invoquer le compilateur sous-jacent sont stockées dans un fichier texte créé par Open MPI et installé dans $pkgdata/NOM-wrapper-data.txt, où :

  • $pkgdata est typiquement $prefix/share/openmpi
  • $prefix est le répertoire d'installation principal d'Open MPI
  • NOM est le nom du compilateur enveloppant (par exemple, $pkgdata/mpicc-wrapper-data.txt)

Ce fichier contient les chaînes spécifiques à la plateforme qui sont ajoutées à la ligne de commande du compilateur sous-jacent.

mpicxx(1) - Open MPI C++ compiler wrapper

SYNTAX

mpicxx [ options ] [ program ]

OPTIONS

See the mpicc(1) man page for a list of common options.

DESCRIPTION

The mpicxx command is a wrapper around the underlying C++ compiler. It is used to compile and link MPI programs written in C++. mpicxx is intended to be invoked by the user from the command line. It automatically passes the correct compiler and linker flags to the underlying C++ compiler to ensure that the MPI C++ bindings are used.

In general, users should invoke mpicxx in the same way they would invoke their native C++ compiler (e.g., g++(1), CC(1), etc.).

For example:

mpicxx my_mpi_program.cpp -o my_mpi_program

Note that mpicxx is a wrapper around the C++ compiler. It is *not* a compiler itself.

BACKGROUND

Open MPI provides a set of wrapper compilers that make it easy to compile and link MPI programs. These wrappers are designed to be compatible with standard compilers and to add the necessary flags and libraries required to use the Open MPI library. They are installed in the Open MPI installation directory, typically in the bin subdirectory.

The wrapper compilers are: mpicc, mpicxx, and mpifort (for Fortran).

FORTRAN NOTES

The mpicxx wrapper is only used for C++ programs. For Fortran programs, use the mpifort wrapper.

OVERVIEW

The mpicxx command invokes the C++ compiler (e.g., g++(1) or CC(1)) after adding the appropriate command-line flags and libraries necessary to link against the Open MPI library. The specific compiler and flags used are determined during the Open MPI configuration process.

The goal of the wrapper compilers is to provide a simple and transparent interface for compiling and linking MPI applications.

NOTES

The wrapper compilers are configured at Open MPI build time. They can be configured to use specific C++ compilers and to add specific flags and libraries. The default behavior is usually sufficient for most users.

If you need to customize the compiler or flags used by the wrappers, you can do so by setting environment variables before running Open MPI's configure script, or by editing the wrapper compiler files directly (see the FILES section).

FILES

The wrapper compilers are typically installed in the <prefix>/bin directory, where <prefix> is the installation prefix for Open MPI.

The actual compiler commands and flags used by the wrappers are stored in text files within the Open MPI installation directory, typically under <prefix>/share/openmpi. These files are:

  • openmpi-wrapper-data.txt: Contains general information about the Open MPI build, including the default compilers and flags.
  • openmpi-compiler-args.txt: Contains specific compiler and linker arguments used by the wrapper compilers.

It is rarely necessary to edit these files, but they can be examined to gain insight into what flags the wrappers are placing on the command line.

ENVIRONMENT VARIABLES

By default, the wrappers use the compilers that were selected when Open MPI was configured. These compilers were either found automatically by Open MPI’s “configure” script, or were selected by the user in the CC, CXX, and/or FC environment variables before configure was invoked. Additionally, other arguments specific to the compiler may have been selected by configure.

These values can be selectively overridden by either editing the text files containing this configuration information (see the FILES section), or by setting selected environment variables of the form ompi_value.

Valid value names are:

  • CPPFLAGS: Flags added when invoking the preprocessor (C or C++)
  • LDFLAGS: Flags added when invoking the linker (C, C++, or Fortran)
  • LIBS: Libraries added when invoking the linker (C, C++, or Fortran)
  • CC: C compiler
  • CFLAGS: C compiler flags
  • CXX: C++ compiler
  • CXXFLAGS: C++ compiler flags
  • FC: Fortran compiler
  • FCFLAGS: Fortran compiler flags
