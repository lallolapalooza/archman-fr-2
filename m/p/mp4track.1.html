mp4track(1)

Paquet: libmp4v2

Licences: MPL

MP4TRACK(-) Mai 2023 MP4TRACK(-)

NOM

mp4track - MP4v2 - page de manuel pour mp4track - MP4v2 2.1.3

SYNTAXE

mp4track [OPTION]... [PARAMÈTRES]... ACTION fichier...

DESCRIPTION

Pour chaque fichier mp4 spécifié, effectuer l'ACTION demandée. Une action doit être spécifiée. Certaines options ne sont pas applicables à certaines actions.

ACTIONS

--list
lister toutes les pistes dans le mp4
--enabled BOOL
définir les drapeaux trak.tkhd.flags (bit activé)
--inmovie BOOL
définir les drapeaux trak.tkhd.flags (bit inMovie)
--inpreview BOOL
définir les drapeaux trak.tkhd.flags (bit inPreview)
--layer NUM
définir trak.tkhd.layer
--altgroup NUM
définir trak.tkhd.alternate_group
--volume FLOAT
définir trak.tkhd.volume
--width FLOAT
définir trak.tkhd.width
--height FLOAT
définir trak.tkhd.height
--language CODE
définir trak.mdia.mdhd.language
--hdlrname STR
définir trak.mdia.hdlr.name
--udtaname STR
définir trak.udta.name.value
--udtaname-remove
supprimer l'atome trak.udta.name
--colr-list
lister toutes les boîtes colr dans le mp4
--colr-add
ajouter une boîte colr à une piste vidéo
--colr-set
définir les paramètres de la boîte colr
--colr-remove
supprimer la boîte colr de la piste
--pasp-list
lister toutes les boîtes pasp dans le mp4
--pasp-add
ajouter une boîte pasp à une piste vidéo
--pasp-set
définir les paramètres de la boîte pasp
--pasp-remove
supprimer la boîte pasp de la piste

PARAMÈTRES

--track-any
agir sur n'importe quelle/toutes les pistes
--track-index IDX
agir sur la piste d'index IDX
--track-id ID
agir sur la piste d'identifiant ID
--colr-parms CSV
où CSV est IDX1,IDX2,IDX3
--colr-parm-hd
équivalent à --colr-parms=1,1,1
--colr-parm-sd
équivalent à --colr-parms=6,1,6
--pasp-parms CSV
où CSV est hSPACING,vSPACING

OPTIONS

-z, --optimize
optimiser le fichier mp4 après modification
-y, --dryrun
ne pas créer ou modifier réellement de fichiers
-k, --keepgoing
continuer le traitement par lots même en cas d'erreurs
-o, --overwrite
écraser les fichiers existants lors de la création
-f, --force
forcer l'écrasement même si le fichier est en lecture seule
-q, --quiet
équivalent à --verbose 0
-d, --debug NUM
augmenter le débogage ou l'option longue pour définir NUM
-v, --verbose NUM
augmenter la verbosité ou l'option longue pour définir NUM
-h, --help
afficher l'aide brève ou l'option longue pour une aide étendue
--version
afficher les informations de version et quitter

NIVEAUX DE DÉBOGAGE (pour les E/S brutes de fichiers mp4)

0
supprimé
1
ajouter des avertissements et des erreurs (par défaut)
2
ajouter des détails de table
3
ajouter des implicites
4
tout

NIVEAUX DE VERBOSITÉ

0
avertissements et erreurs
1
messages informatifs normaux (par défaut)
2
messages plus informatifs
3
tout
