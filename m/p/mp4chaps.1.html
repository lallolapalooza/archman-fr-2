MP4CHAPS(-) Mai 2023 MP4CHAPS(-)

NOM

mp4chaps - MP4v2 - page de manuel pour mp4chaps - MP4v2 2.1.3

SYNOPSIS

mp4chaps [OPTION]... ACTION [PARAMÈTRES D'ACTION] fichier_mp4...

DESCRIPTION

Pour chaque fichier mp4 spécifié, effectue l'ACTION demandée. Une action doit être spécifiée. Certaines options ne sont pas applicables à certaines actions.

ACTIONS

-l, --lister
lister les chapitres disponibles
-c, --convertir
convertir les chapitres disponibles
-e, --tous les NUM
créer des chapitres toutes les NUM secondes
-x, --exporter
exporter les chapitres vers mp4file.chapters.txt
-i, --importer
importer les chapitres depuis mp4file.chapters.txt
-r, --supprimer
supprimer tous les chapitres

PARAMÈTRES D'ACTION

-A, --chapitre-tous
agir sur n'importe quel type de chapitre (par défaut)
-Q, --chapitre-qt
agir sur les chapitres QuickTime
-N, --chapitre-nero
agir sur les chapitres Nero
--format-natif
exporter les chapitres au format natif (par défaut)
-C, --format-commun
exporter les chapitres au format commun

OPTIONS

-z, --optimiser
optimiser le fichier mp4 après modification
-y, --simulation
ne pas créer ni modifier réellement de fichiers
-k, --continuer
continuer le traitement par lots même en cas d'erreurs
-o, --ecraser
écraser les fichiers existants lors de la création
-f, --forcer
forcer l'écrasement même si le fichier est en lecture seule
-q, --silencieux
équivalent à --verbeux 0
-d, --debug NUM
augmenter le débogage ou utiliser l'option longue pour définir NUM
-v, --verbeux NUM
augmenter la verbosité ou utiliser l'option longue pour définir NUM
-h, --aide
afficher une aide brève ou utiliser l'option longue pour une aide étendue
--version
afficher les informations de version et quitter

NIVEAUX DE DÉBOGAGE (pour les E/S brutes de fichiers mp4)

0
supprimé
1
avertissements et erreurs ajoutés (par défaut)
2
détails de table ajoutés
3
implicites ajoutés
4
tout

NIVEAUX DE VERBOSITÉ

0
avertissements et erreurs
1
messages informatifs normaux (par défaut)
2
messages plus informatifs
3
tout
