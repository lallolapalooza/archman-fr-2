mcheck(3) Manuel des fonctions de bibliothèque mcheck(3)

NOM

mcheck, mcheck_check_all, mcheck_pedantic, mprobe - vérification de la cohérence du tas

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <mcheck.h>
int mcheck(typeof(void (enum mcheck_status mstatus)) *f);
int mcheck_pedantic(
           typeof(void (enum mcheck_status mstatus)) *f);
void mcheck_check_all(void);
enum mcheck_status mprobe(void *ptr);

DESCRIPTION

La fonction mcheck() installe un ensemble de hooks de débogage pour les fonctions d'allocation mémoire de la famille malloc(3). Ces hooks entraînent l'exécution de certaines vérifications de cohérence sur l'état du tas. Les vérifications peuvent détecter des erreurs d'application telles que la libération d'un bloc de mémoire plus d'une fois ou la corruption des structures de données de gestion qui précèdent immédiatement un bloc de mémoire allouée.

Pour être efficace, la fonction mcheck() doit être appelée avant le premier appel à malloc(3) ou une fonction apparentée. Dans les cas où il est difficile de garantir cela, lier le programme avec -lmcheck insère un appel implicite à mcheck() (avec un argument NULL) avant le premier appel à une fonction d'allocation mémoire.

La fonction mcheck_pedantic() est similaire à mcheck(), mais effectue des vérifications sur tous les blocs alloués chaque fois qu'une des fonctions d'allocation mémoire est appelée. Cela peut être très lent !

La fonction mcheck_check_all() provoque une vérification immédiate de tous les blocs alloués. Cet appel n'est efficace que si mcheck() a été appelé au préalable.

Si le système détecte une incohérence dans le tas, la fonction fournie par l'appelant, pointée par f, est invoquée avec un seul argument, mstatus, qui indique le type d'incohérence détecté. Si f est NULL, une fonction par défaut affiche un message d'erreur sur stderr et appelle abort(3).

La fonction mprobe() effectue une vérification de cohérence sur le bloc de mémoire allouée pointé par ptr. La fonction mcheck() doit être appelée au préalable (sinon mprobe() renvoie MCHECK_DISABLED).

La liste suivante décrit les valeurs renvoyées par mprobe() ou passées comme argument mstatus lorsque f est invoquée :

MCHECK_DISABLED (uniquement mprobe())
mcheck() n'a pas été appelé avant le premier appel à une fonction d'allocation mémoire. La vérification de cohérence n'est pas possible.
MCHECK_OK (uniquement mprobe())
Aucune incohérence détectée.
MCHECK_HEAD
La mémoire précédant un bloc alloué a été écrasée.
MCHECK_TAIL
La mémoire suivant un bloc alloué a été écrasée.
MCHECK_FREE
Un bloc de mémoire a été libéré deux fois.

VALEUR RENVOYÉE

mcheck() et mcheck_pedantic() renvoient 0 en cas de succès, et -1 en cas d'erreur.

NOTES

Lier un programme avec -lmcheck et utiliser la variable d'environnement MALLOC_CHECK_ (décrite dans mallopt(3)) détectent les mêmes types d'erreurs. Cependant, l'utilisation de MALLOC_CHECK_ ne nécessite pas que l'application soit relinkée.

EXEMPLES

Le programme ci-dessous appelle mcheck() avec un argument NULL, puis libère le même bloc de mémoire deux fois. La session shell suivante montre ce qui se passe lors de l'exécution du programme :


$ ./a.out
About to free
About to free a second time
block freed twice
Aborted (core dumped)

Source du programme

#include <mcheck.h>
#include <stdio.h>
#include <stdlib.h>
int
main(void)
{
    char *p;
    if (mcheck(NULL) != 0) {
        fprintf(stderr, "mcheck() failed\n");
        exit(EXIT_FAILURE);
    }
    p = malloc(1000);
    fprintf(stderr, "About to free\n");
    free(p);
    fprintf(stderr, "\nAbout to free a second time\n");
    free(p);
    exit(EXIT_SUCCESS);
}
