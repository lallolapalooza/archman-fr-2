NOM

mpc - Documentation de mpc

DESCRIPTION

mpc est un client en ligne de commande pour le Music Player Daemon (MPD). Il se connecte à un MPD et le contrôle selon les commandes et arguments qui lui sont passés. Si aucune commande n'est donnée, l'état actuel est affiché (identique à "mpc status").

SYNTAXE

mpc [options] <commande> [--] [<arguments>]

Après --, tous les paramètres sont considérés comme des arguments, pas des options, même s'ils commencent par un tiret.

OPTIONS

-f, --format
Configure le format utilisé pour afficher les chansons.

Les délimiteurs de métadonnées sont :

Nom Description
%name% Un nom pour cette chanson. Ce n'est pas le titre de la chanson. La signification exacte de cette balise n'est pas bien définie. Elle est souvent utilisée par des stations de radio Internet mal configurées avec des balises défectueuses pour y glisser à la fois le nom de l'artiste et le titre de la chanson dans une seule balise.
%artist% Balise de fichier de l'artiste
%album% Balise de fichier de l'album
%albumartist% Balise de fichier de l'artiste de l'album
%comment% Balise de fichier de commentaire (pas activée par défaut dans les métadonnées à utiliser de mpd.conf)
%composer% Balise de fichier du compositeur
%date% Balise de fichier de la date
%originaldate% Balise de fichier de la date originale
%disc% Balise de fichier du disque
%genre% Balise de fichier du genre
%performer% Balise de fichier de l'interprète
%title% Balise de fichier du titre
%track% Balise de fichier du morceau
%time% Durée du fichier
%file% Chemin du fichier, relatif à la variable music_directory de MPD
%position% Numéro du morceau dans la file d'attente
%id% Numéro d'identifiant du morceau dans la file d'attente
%prio% Priorité dans la file d'attente (aléatoire).
%mtime% Date et heure de la dernière modification du fichier
%mdate% Date de la dernière modification du fichier
%audioformat% Le format audio de la chanson.

L'opérateur [] est utilisé pour grouper la sortie de telle sorte que si aucun délimiteur de métadonnées n'est trouvé ou ne correspond entre [ et ], alors aucun des caractères entre [ et ] ne sera affiché. & et | sont des opérateurs logiques pour ET et OU. # est utilisé pour échapper les caractères. Quelques exemples utiles pour le format sont : "%file%" et "[[%artist% - ]%title%|[%file%]". Cette commande accepte également les séquences d'échappement définies suivantes :

\ antislash
\[ crochet ouvrant
\] crochet fermant
\a alarme
\b retour arrière
\e échappement
\t tabulation
\n nouvelle ligne
\v tabulation verticale
\f saut de page
\r retour chariot

Si elle n'est pas donnée, la valeur de la variable d'environnement MPC_FORMAT est utilisée.

--wait
Attend que l'opération se termine (par ex. mise à jour de la base de données).
--range=[DEBUT]:[FIN]
Opérer sur

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

un gamme (par exemple, lors du chargement d'une playlist). START est le premier indice de la plage, END est le premier indice après la plage (c'est-à-dire exclus). START et END peuvent être omis, rendant la plage ouverte à cette extrémité. Les indices commencent à zéro.
--with-prio
Afficher uniquement les chansons qui ont une priorité non nulle.
-q, --quiet, --no-status
Empêche l'affichage de l'état de la chanson en cours à la fin de certaines commandes.
--verbose
Sortie détaillée.
--host=HOST
Le serveur MPD auquel se connecter. Il peut s'agir d'un nom d'hôte, d'une adresse IPv4/IPv6, d'un chemin absolu (c'est-à-dire un socket local) ou d'un nom commençant par @ (c'est-à-dire un socket abstrait, uniquement sous Linux).

Pour utiliser un mot de passe, fournissez une valeur de la forme "motdepasse@hôte".

Si non spécifié, la valeur de la variable d'environnement MPD_HOST est utilisée.

--port=PORT, -p PORT
Le port TCP du serveur MPD auquel se connecter.

Si non spécifié, la valeur de la variable d'environnement MPD_PORT est utilisée.

--partition=PARTITION, -a PARTITION
La partition du serveur MPD sur laquelle opérer.

Si non spécifié, la partition par défaut est utilisée.

COMMANDES

Les commandes peuvent être utilisées à partir du préfixe le moins ambigu (par exemple insert ou ins).

Commandes du lecteur

consume <on|off> - Active/désactive le mode de consommation si l'état (on
ou off) n'est pas spécifié.
crossfade [<secondes>] - Obtient et définit la durée actuelle du
fondu enchaîné entre les chansons (0 désactive le fondu enchaîné).
current [--wait] - Affiche la chanson en cours de lecture. Avec
--wait, mpc attend que la chanson change (ou que la lecture soit démarrée/arrêtée) avant d'interroger le serveur pour connaître la chanson en cours.

queued - Affiche la chanson actuellement mise en file d'attente (suivante).

mixrampdb [<db>] - Obtient et définit le niveau de volume auquel
les chansons avec des tags MixRamp seront superposées. Cela désactive le fondu de la commande de fondu enchaîné et mélange simplement les chansons. -50.0 éliminera efficacement tout espace, 0.0 mélangera les pistes. La durée du chevauchement est limitée par le paramètre de configuration MPD audio_buffer_size.
mixrampdelay [<secondes>] - Obtient et définit la durée supplémentaire
ajoutée à la valeur calculée à partir des tags MixRamp. (Une valeur négative désactive le chevauchement avec les tags MixRamp et restaure la valeur précédente du fondu enchaîné).

next - Commence la lecture de la prochaine chanson de la file d'attente.

pause - Met la lecture en pause.

play <position> - Commence la lecture de la chanson dont le numéro
de position est spécifié. S'il n'y en a pas, joue le numéro 1.

prev - Commence la lecture de la chanson précédente.

random <on|off> - Active/désactive le mode aléatoire si l'état (on
ou off) n'est pas spécifié.
repeat <on|off> - Active/désactive le mode de répétition si l'état (on
ou off) n'est pas spécifié.
replaygain [<off|track|album>] - Définit le mode de gain de relecture.
Sans arguments, il affiche le mode de gain de relecture.
single <on|once|off> - Active/désactive le mode single si l'état (on,
once, ou off) n'est pas spécifié. once passe à off.
seek [+-][<HH:MM:SS>] ou <[+-]<0-100>%> - Recherche par heure,
minute ou seconde, les heures ou les minutes peuvent être omises. Si la recherche est effectuée en pourcentage, elle se fait dans la chanson actuelle de la manière spécifiée. Si un signe + ou - est utilisé, la recherche est effectuée par rapport à la position actuelle de la chanson. Recherche absolue par défaut.
seekthrough [+-][<HH:MM:SS>] - Recherche par heure,
minute ou seconde, les heures ou les minutes peuvent être omises, relativement à la position actuelle. Si la durée dépasse la limite de la chanson actuelle, la commande de recherche continue de chercher dans la playlist jusqu'à ce que la durée soit atteinte. Si un + est utilisé, la recherche est vers l'avant. Si un - est utilisé, la recherche est vers l'arrière. Recherche vers l'avant par défaut.

stop - Arrête la lecture.

toggle - Bascule entre lecture et pause. Si arrêté, démarre
la lecture. Ne prend pas en charge le démarrage de la lecture à un numéro de chanson (utilisez play).

Commandes de la file d'attente

add <fichier> - Ajoute une chanson de la base de données musicale à la
file d'attente. Peut également lire l'entrée depuis des tuyaux. Utilisez "mpc add /" pour ajouter tous les fichiers à la file d'attente.
insert <fichier> - La commande insert fonctionne de manière similaire à
add sauf qu'elle ajoute la/les chanson(s) après celle en cours de lecture, plutôt qu'à la fin. Lorsque le mode aléatoire est activé, la nouvelle chanson est mise en file d'attente après la chanson actuelle.

clear - Vide la file d'attente.

crop - Supprime toutes les chansons sauf celle en cours de
lecture.
del <position_chanson> - Supprime une chanson de la file d'attente par son numéro. Peut
également lire l'entrée depuis des tuyaux (0 supprime la chanson en cours de lecture).
mv, move <depuis> <vers> - Déplace la chanson à la position <depuis> vers la
position <vers> dans la file d'attente.
searchplay <type> <requête> [<type> <requête>]... - Recherche dans la file
d'attente une chanson correspondante et la joue.

shuffle - Mélange toutes les chansons de la file d'attente.

Commandes de playlist

load <fichier> - Charge <fichier> comme file d'attente. L'option
--range peut être utilisée pour charger seulement une partie du fichier.

lsplaylists: - Liste les playlists disponibles.

playlist [<playlist>] - Liste toutes les chansons de <playlist>. Si
aucune <playlist> n'est spécifiée, liste toutes les chansons de la file d'attente actuelle.

rm <fichier> - Supprime une playlist spécifique.

save <fichier> - Sauvegarde la playlist sous le nom <fichier>.

addplaylist <playlist> <fichier> - Ajoute une chanson de la base de données à la playlist.
La playlist sera créée si elle n'existe pas. Peut également lire l'entrée depuis des tuyaux.
delplaylist <playlist> <position_chanson> - Supprime la chanson à la position donnée de la playlist. Peut
également lire l'entrée depuis des tuyaux.
moveplaylist <playlist> <depuis> <vers> - Déplace la chanson à la position <depuis>
vers la position <vers> dans la playlist.

renplaylist <playlist> <nouvelle playlist> - Renomme une playlist.

clearplaylist <playlist> - Efface le nom de la playlist (c'est-à-dire tronque playlist.m3u).

Commandes de la base de données

listall [<fichier>] - Liste <fichier> de la base de données. Si aucun
fichier n'est spécifié, liste toutes les chansons de la base de données.
ls [<répertoire>] - Liste tous les fichiers/dossiers dans
répertoire. Si aucun répertoire n'est spécifié, liste tous les fichiers du répertoire musical.
lsdirs [<répertoire>] - Liste les sous-répertoires de
répertoire. Si aucun répertoire n'est spécifié, liste les sous-répertoires du répertoire musical.
search <type> <requête> [<type> <requête>]... - Recherche des
sous-chaînes dans les tags des chansons. Un nombre quelconque de types de tags et de requêtes peuvent être spécifiés. Les types de tags possibles sont : artist, album, title, track, name, genre, date, composer, performer, comment, disc, filename, ou any (pour correspondre à n'importe quel tag).
search <expression> - Recherche avec une expression de filtre,
par exemple : 
mpc search '((artist == "Kraftwerk") AND (title == "Metall auf
Metall"))'

Consultez la documentation du protocole MPD pour plus de détails. Cette syntaxe peut également être utilisée avec find et findadd. (Nécessite libmpdclient 2.16 et MPD 0.21)

find <type> <requête> [<type> <requête>]... - Identique à
search, mais les valeurs des tags doivent correspondre exactement à la requête au lieu d'une correspondance de sous-chaîne.
findadd <type> <requête> [<type> <requête>]... - Identique à
find, mais ajoute le résultat à la file d'attente actuelle au lieu de l'afficher.
list <type> [<type> <requête>]... [group <type>]... -
Retourne une liste de tous les tags du type de tag donné. La requête/type de recherche optionnelle limite les résultats d'une manière similaire à la recherche. Les résultats peuvent être regroupés par un ou plusieurs tags. Exemple :
mpc list album group artist

stats - Affiche des statistiques sur MPD.

update [--wait] [<chemin>] - Analyse les fichiers mis à jour dans le
répertoire musical. Le paramètre optionnel chemin (relatif au répertoire musical) peut limiter la portée de la mise à jour.

Avec --wait, mpc attend que MPD ait terminé la mise à jour.

rescan [--wait] [<chemin>] - Identique à update, mais analyse également
les fichiers non modifiés.

Commandes de fichiers

albumart <fichier> - Télécharge la pochette de l'album pour la chanson donnée et
l'écrit sur stdout.
readpicture <fichier> - Télécharge une image intégrée dans la
chanson donnée et l'écrit sur stdout.

Commandes de montage

mount - Liste tous les montages.

mount <chemin-de-montage> <uri-stockage> - Crée un nouveau montage :
monte un stockage sur le chemin donné. Exemple :
mpc mount server nfs://10.0.0.5/mp3
mpc mount stick udisks://by-id-ata-FOO-part2

unmount <chemin-de-montage> - Supprime un montage.

listneighbors - Affiche une liste de "voisins"
(c'est-à-dire des stockages détectés automatiquement qui peuvent être montés). Cela nécessite l'activation d'au moins un plugin voisin dans mpd.conf. Exemple :
$ mpc listneighbors
upnp://uuid:01234567-89ab-cdef-0123-456789abcdef/urn:schemas-upnp-org:service:ContentDirectory:1
udisks://by-id-dm-name-_dev_sdb3
udisks://by-id-ata-FOO-part2

Commandes de collants

La commande sticker vous permet d'obtenir et de définir les stickers de chansons.

sticker <fichier> set <clé> <valeur> - Définit la valeur d'un sticker de chanson.
sticker <fichier> get <clé> - Affiche la valeur d'un sticker de chanson.

sticker <fichier> list - Liste tous les stickers d'une chanson.

sticker <fichier> delete <clé> - Supprime un sticker de chanson.

sticker <répertoire> find <clé> - Recherche les stickers portant le nom
spécifié, sous le répertoire spécifié.

Commandes de sortie

volume [+-]<num> - Définit le volume à <num> (0-100). Si
+ ou - est utilisé, alors il ajuste le volume par rapport au volume actuel.

outputs - Liste toutes les sorties disponibles

disable [only] <# ou nom de sortie> [...] - Désactive la ou les
sorties ; une liste d'un ou plusieurs noms ou numéros est requise. Si only est le premier argument, toutes les autres sorties sont activées.
enable [only] <# ou nom de sortie> [...] - Active la ou les
sorties ; une liste d'un ou plusieurs noms ou numéros est requise. Si only est le premier argument, toutes les autres sorties sont désactivées.
toggleoutput <# ou nom de sortie> [...] - Change le statut
de la ou des sorties données ; une liste d'un ou plusieurs noms ou numéros est requise.
moveoutput <# ou nom de sortie> - Déplace la sortie donnée
vers la partition actuelle (voir --partition).

Commandes de partition

partitions - Liste toutes les partitions disponibles

makepart <nom> [...] - Crée de nouvelles partitions

delpart <nom> [...] - Supprime des partitions

Commandes client-à-client

channels - Liste les canaux auxquels d'autres clients se sont
abonnés.
sendmessage <canal> <message> - Envoie un message au canal
spécifié.
waitmessage <canal> - Attend au moins un message sur le canal
spécifié.
subscribe <canal> - S'abonne au canal spécifié
et reçoit en continu des messages.

Autres commandes

idle [événements] - Attend qu'un événement se produise. Affiche une liste
de noms d'événements, un par ligne. Consultez la documentation du protocole MPD pour plus d'informations.

Si vous spécifiez une liste d'événements, seuls ces événements sont pris en compte.

idleloop [événements] - Similaire à idle, mais
ré-entre en état "idle" après que les événements ont été affichés.

Si vous spécifiez une liste d'événements, seuls ces événements sont pris en compte.

status [format] - Sans argument, affiche une sortie de statut à trois lignes
équivalente à "mpc" sans arguments. Si une chaîne de format est fournie, les délimiteurs sont traités exactement comme pour les métadonnées. Voir l'option '-f' dans Options.
Nom Description
%totaltime% La durée totale de la chanson.
%currenttime% L'heure actuelle du client.
%percenttime% Le pourcentage du temps écoulé pour la chanson actuelle.
%songpos% La position de la chanson actuelle dans la playlist.
%length% Le nombre de chansons dans la playlist.
%state% Soit 'playing', 'paused' ou 'stopped'.
%volume% Le volume actuel espacé sur 4 caractères, incluant un signe pourcentage.
%random% Statut actuel du mode aléatoire. 'on' ou 'off'.
%repeat% Statut actuel du mode de répétition. 'on' ou 'off'.
%single% Statut actuel du mode single. 'on', 'once', ou 'off'.
%consume% Statut actuel du mode de consommation. 'on' ou 'off'.
%kb itrate% Le débit binaire en kbps pour la chanson actuelle.
%audioformat% Le format audio que MPD joue actuellement sous la forme 'taux d'échantillonnage:bits:canaux'.
%samplerate% Le taux d'échantillonnage en Hz extrait du format audio MPD actuel.
%bits% Le nombre de bits significatifs par taille d'échantillon extrait du format audio MPD actuel.
%channels% Le nombre de canaux extraits du format audio MPD actuel.
version - Indique la version du protocole parlé, pas la vraie
version du démon.

VARIABLES D'ENVIRONNEMENT

Toutes les variables d'environnement sont remplacées par les valeurs spécifiées via les options de ligne de commande.

MPC_FORMAT
Configure le format utilisé pour afficher les chansons. Voir l'option --format.
MPD_HOST
Le serveur MPD auquel se connecter. Voir l'option --host.
MPD_PORT
Le port TCP du serveur MPD auquel se connecter. Voir l'option --port.

BOGUES

Signalez les bogues sur https://github.com/MusicPlayerDaemon/mpc/issues

Comme MPD utilise UTF-8, mpc doit convertir les caractères dans le jeu de caractères utilisé par le système local. Si vous obtenez des erreurs de conversion de caractères lorsque vous exécutez mpc, vous devrez probablement configurer votre locale. Cela se fait en définissant l'une des variables d'environnement LC_CTYPE, LANG ou LC_ALL (LC_CTYPE n'affecte que la gestion des caractères).
