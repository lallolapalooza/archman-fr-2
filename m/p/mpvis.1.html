MPVIS(1) Manuel des commandes générales MPVIS(1)

NOM

mpvis - visualisation de l'utilisation/performance du CPU

SYNTAXE

mpvis [-biV] [-r longueur_ligne] [-R longueur_ligne] [options pmview] [id_cpu ...]

DESCRIPTION

mpvis affiche un graphique en barres tridimensionnel de l'utilisation du CPU. L'affichage est mis à jour avec de nouvelles valeurs récupérées de l'hôte ou de l'archive cible toutes les intervalle secondes (par défaut 2 secondes).

La hauteur des barres est proportionnelle à l'utilisation du CPU dans chacun des modes idle (sans E/S en attente), wait (idle, mais en attente d'E/S - visible uniquement sous IRIX), intr (traitement des interruptions - visible uniquement sous IRIX), nice (état nice - visible uniquement sous Linux), sys (dans le noyau) et user.

Le nombre de CPUs par ligne dans la scène est régi par la longueur de ligne maximale par défaut, et par les options -b, -r et -R. Si aucun de ces drapeaux n'est spécifié, mpvis utilise la longueur de ligne maximale par défaut pour calculer le nombre réel de lignes et de colonnes dans la vue, selon :

lignes = (ncpus + longueur_ligne_max - 1) / longueur_ligne_max
colonnes = (ncpus + lignes - 1) / lignes.

L'option -r utilise l'algorithme ci-dessus, mais permet à l'utilisateur de remplacer la longueur de ligne maximale.

Les CPUs sont triés dans l'ordre croissant. Ils sont affichés de gauche à droite, et d'avant en arrière (dans le cas où il y a plus d'une ligne de CPUs).

L'utilisateur peut spécifier une liste de CPUs comme arguments id_cpu en utilisant le schéma de nommage rapporté par

$ pminfo -f kernel.percpu.cpu.user

c'est-à-dire cpuN ou cpuA:B selon la version du système d'exploitation et la plateforme. Alternativement, si l'argument id_cpu contient l'un des caractères ^ ou . ou [ alors id_cpu sera traité comme une expression régulière dans le style de egrep(1) et l'ensemble correspondant de noms de CPU sera utilisé à la place de id_cpu.

Si un ou plusieurs arguments id_cpu sont spécifiés, alors seuls les CPUs de cette liste sont affichés dans la vue. La liste des CPUs est triée par numéro de CPU croissant et ils sont affichés de gauche à droite, et d'avant en arrière (dans le cas où il y a plus d'une ligne de CPUs).

mpvis génère un fichier de configuration pmview(1), et passe la plupart des options de ligne de commande à pmview(1). Par conséquent, les options de ligne de commande -A, -a, -C, -h, -n, -O, -p, -S, -t, -T, -Z et -z, ainsi que l'interface utilisateur sont décrites dans la page de manuel pmview(1).

OPTIONS DE LIGNE DE COMMANDE

Les options spécifiques à mpvis sont :

-b
Utilise un ratio ligne:colonne de 1:8. Cette option est préférable pour un grand nombre de CPUs. Si la longueur de ligne n'est pas un facteur du nombre de CPUs, alors la dernière ligne sera plus courte que toutes les autres lignes. Cette option ignore la longueur de ligne maximale.
-i
Étiquette chaque colonne de CPU avec le numéro du CPU.
-r
Divise la vue en un certain nombre de lignes, où chaque ligne a une longueur maximale de n CPUs. C'est une limite souple. La longueur de ligne réelle est calculée par un algorithme (voir ci-dessus) qui produit une vue équilibrée avec pas plus de n CPUs par ligne.
-R
Divise la vue en un certain nombre de lignes, où chaque ligne a une longueur de n CPUs. C'est une limite stricte. Si la longueur de ligne n'est pas un facteur du nombre de CPUs, alors la dernière ligne sera plus courte que toutes les autres lignes.
-V
Mode verbeux - affiche le fichier de configuration pmview(1) généré.

EXÉCUTION

Le comportement de pmchart(1) lors de son lancement depuis mpvis dépend du nombre de CPUs dans chaque ligne. S'il y a plus de 6 CPUs par ligne, alors chaque graphique contiendra une métrique séparée, sinon chaque graphique contiendra une instance de CPU séparée.

FICHIERS

$PCP_VAR_DIR/config/pmlogger/config.mpvis
Un fichier de configuration pmlogger(1) pour les métriques mpvis.
$PCP_SHARE_DIR/lib/pmview-args
Procédures shell pour l'analyse des options de ligne de commande de pmview(1).

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, tel que décrit dans pcp.conf(4).
