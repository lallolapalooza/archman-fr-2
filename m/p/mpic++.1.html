mpicc, mpic++, mpicxx, mpifort, mpijavac — Compilateurs enveloppants Open MPI

SYNTAXE

mpicc [--showme | --showme:compile | --showme:link] ...

mpic++ [--showme | --showme:compile | --showme:link] ...

mpicxx [--showme | --showme:compile | --showme:link] ...

mpifort [--showme | --showme:compile | --showme:link] ...

mpijavac [--showme | --showme:compile | --showme:link] ...

Les commandes obsolètes suivantes sont également disponibles — mais mpifort doit être utilisé à leur place :

mpif77 [--showme | --showme:compile | --showme:link] ...

mpif90 [--showme | --showme:compile | --showme:link] ...

Sur les systèmes de fichiers sensibles à la casse, la commande suivante sera également disponible :

mpiCC [--showme | --showme:compile | --showme:link] ...

OPTIONS

Les options ci-dessous s'appliquent à tous les compilateurs enveloppants :

•
--showme : Cette option se présente sous plusieurs variantes différentes (voir ci-dessous). Aucune des variantes n'invoque le compilateur sous-jacent ; elles fournissent toutes des informations sur la manière dont le compilateur sous-jacent aurait été invoqué si --showme n'avait pas été utilisé. L'option de base --showme affiche la ligne de commande qui serait exécutée pour compiler le programme.

NOTE :

Si un argument qui n'est pas un nom de fichier est passé sur la ligne de commande, l'option --showme n'affichera *pas* de drapeaux supplémentaires. Par exemple, "mpicc --showme et mpicc --showme my_source.c montreront tous les drapeaux fournis par l'enveloppant. Mais mpicc --showme -v ne montrera que le nom du compilateur sous-jacent et -v.
  • --showme:compile : Affiche les drapeaux du compilateur qui auraient été fournis au compilateur sous-jacent.
  • --showme:link : Affiche les drapeaux de l'éditeur de liens qui auraient été fournis au compilateur sous-jacent.
  • --showme:command : Affiche la commande du compilateur sous-jacent (qui peut être un ou plusieurs jetons).
  • --showme:incdirs : Affiche une liste de répertoires, délimitée par des espaces (mais sinon non décorée), que le compilateur enveloppant aurait fournie au compilateur sous-jacent pour indiquer où se trouvent les fichiers d'en-tête pertinents.
  • --showme:libdirs : Affiche une liste de répertoires, délimitée par des espaces (mais sinon non décorée), que le compilateur enveloppant aurait fournie à l'éditeur de liens sous-jacent pour indiquer où se trouvent les bibliothèques pertinentes.
  • --showme:libs : Affiche une liste de noms de bibliothèques, délimitée par des espaces (mais sinon non décorée), que le compilateur enveloppant aurait utilisée pour lier une application. Par exemple : mpi open-pal util.
  • --showme:version : Affiche le numéro de version d'Open MPI.
  • --showme:help : Affiche un bref message d'aide sur l'utilisation.

Consultez la page de manuel de votre compilateur sous-jacent pour connaître les autres options qui peuvent être transmises via mpicc.

DESCRIPTION

Conceptuellement, le rôle de ces commandes est assez simple : ajouter de manière transparente les indicateurs de compilateur et d'éditeur de liens pertinents à la ligne de commande de l'utilisateur qui sont nécessaires pour compiler/lier des programmes Open MPI, puis invoquer le compilateur sous-jacent pour exécuter réellement la commande.

En tant que tels, ces commandes sont souvent appelées compilateurs « enveloppants » car elles ne compilent ni ne lient les applications elles-mêmes ; elles ne font qu'ajouter des indicateurs à la ligne de commande et invoquer le compilateur backend.

CONTEXTE

Open MPI fournit des compilateurs enveloppants pour plusieurs langages :

  • mpicc : C
  • mpic++, mpicxx (et sur les systèmes sensibles à la casse, mpiCC) : C++

    NOTE :

mpic++, mpicxx et mpiCC invoquent tous le même compilateur C++ sous-jacent avec les mêmes options. Ils sont tous fournis pour assurer la compatibilité avec d'autres implémentations MPI.
  • mpifort (et ses alias hérités/obsolètes mpif77 et mpif90) : Fortran
  • mpijavac : Java

Les compilateurs enveloppants pour chacun des langages sont identiques ; ils peuvent être utilisés de manière interchangeable. Les différents noms sont fournis uniquement pour des raisons de compatibilité ascendante.

NOTES FORTRAN

Le compilateur enveloppant Fortran pour MPI (mpifort, et ses noms hérités/obsolètes mpif77 et mpif90) peut compiler et lier des applications MPI qui utilisent tout/tous les bindings Fortran MPI : mpif.h, le module mpi, et le module mpi_f08 (en supposant qu'Open MPI ait été installé avec le support pour chacun de ces bindings Fortran). Plus précisément : il n'est plus nécessaire d'utiliser différents compilateurs enveloppants pour les applications qui utilisent mpif.h par rapport aux applications qui utilisent le module mpi — utilisez simplement mpifort pour toutes les applications MPI Fortran.

Notez cependant que le compilateur Fortran peut nécessiter des options de ligne de commande supplémentaires pour imposer un dialecte Fortran spécifique. Par exemple, dans certaines versions du compilateur IBM XLF, si xlf90 est le compilateur Fortran sous-jacent, -qfixed peut être nécessaire pour compiler des fichiers source Fortran au format fixe.

Enfin, notez que mpifort sera inopérant et renverra une erreur en cas d'utilisation si le support Fortran n'a pas été intégré à la couche MPI.

APERÇU

mpicc est un wrapper pratique pour le compilateur C sous-jacent. La traduction d'un programme Open MPI nécessite la liaison des bibliothèques spécifiques à Open MPI qui peuvent ne pas résider dans l'un des répertoires de recherche standard de ld(1). Elle nécessite également souvent l'inclusion de fichiers d'en-tête qui peuvent également ne pas se trouver dans un emplacement standard.

mpicc transmet ses arguments au compilateur C sous-jacent ainsi que les options -I, -L et -l requises par les programmes Open MPI.

Il en va de même pour tous les autres compilateurs enveloppants de langage.

L'équipe Open MPI encourage *vivement* l'utilisation des compilateurs enveloppants au lieu de tenter de lier manuellement les bibliothèques Open MPI. Cela permet à l'implémentation spécifique d'Open MPI de changer sans forcer de changements dans les directives de l'éditeur de liens des Makefiles des utilisateurs. En effet, l'ensemble spécifique d'indicateurs et de bibliothèques utilisés par les compilateurs enveloppants dépend de la manière dont Open MPI a été configuré et construit ; les valeurs peuvent changer entre différentes installations de la même version d'Open MPI.

En fait, étant donné que les enveloppants ne sont que des coquilles minces au-dessus d'un compilateur sous-jacent, il existe très, très peu de raisons impérieuses de ne pas utiliser les compilateurs enveloppants d'Open MPI. Lorsqu'il n'est pas possible d'utiliser directement les enveloppants, les options --showme:compile et --showme:link doivent être utilisées pour déterminer quels indicateurs les enveloppants auraient utilisés. Par exemple :

shell$ cc -c file1.c `mpicc --showme:compile`
shell$ cc -c file2.c `mpicc --showme:compile`
shell$ cc file1.o file2.o `mpicc --showme:link` -o my_mpi_program

NOTES

Il est possible de rendre les compilateurs enveloppants conscients des multi-bibliothèques. C'est-à-dire que les bibliothèques et les inclusions spécifiées peuvent différer en fonction des indicateurs du compilateur spécifiés (par exemple, avec les compilateurs GNU sous Linux, un chemin de bibliothèque différent peut être utilisé si -m32 est vu par rapport à -m64). Ce n'est pas le comportement par défaut dans une compilation standard, mais cela peut être activé (par exemple, dans un paquet binaire fournissant un support 32 et 64 bits). *Plus d'informations peuvent être trouvées ici*.

FICHIERS

Les chaînes de caractères que les compilateurs enveloppants insèrent dans la ligne de commande avant d'invoquer le compilateur sous-jacent sont stockées dans un fichier texte créé par Open MPI et installé dans $pkgdata/NAME-wrapper-data.txt, où :

  • $pkgdata est généralement $prefix/share/openmpi
  • $prefix est le répertoire d'installation principal d'Open MPI
  • NAME est le nom du compilateur enveloppant (par exemple, $pkgdata/mpicc-wrapper-data.txt)

mpic++.1.fr.html

NOM

mpic++, mpicxx - Compilateurs d'enrobage pour les applications C++ Open MPI

SYNTAXIS

mpic++ [options] [fichiers source] -o [exécutable]

mpicxx [options] [fichiers source] -o [exécutable]

OPTIONS

Voir mpicc(1) pour une description complète des options disponibles. Les options qui ne sont pas comprises par mpic++ sont transmises directement au compilateur C++ sous-jacent.

DESCRIPTION

mpic++ et mpicxx sont des noms de liens symboliques pour le compilateur C++ de l'enrobage Open MPI. Ils sont utilisés pour compiler des applications C++ qui utilisent la bibliothèque MPI.

Ces wrappers appellent le compilateur C++ sélectionné lors de la configuration d'Open MPI (généralement g++), et ajoutent les commutateurs appropriés pour inclure les en-têtes et les bibliothèques MPI.

BACKGROUND

Open MPI fournit un ensemble de compilateurs d'enrobage pour faciliter la compilation des applications qui utilisent MPI. Ces enrobages garantissent que les options correctes sont transmises au compilateur et à l'éditeur de liens sous-jacents pour lier correctement votre application avec la bibliothèque MPI.

Pour le C++, il existe des enrobages nommés mpic++ et mpicxx. Ces deux noms font référence au même exécutable.

FORTRAN NOTES

Notez que ces wrappers sont spécifiquement pour le C++. Il existe des wrappers distincts pour Fortran (mpif77, mpif90, mpifort) et C (mpicc).

OVERVIEW

Le fonctionnement de base des wrappers de compilateur Open MPI est le suivant :

  1. Lorsque vous exécutez mpic++ ou mpicxx, ils analysent leurs arguments de ligne de commande.

  2. Ils déterminent le compilateur C++ sous-jacent à utiliser (déterminé lors de la configuration d'Open MPI ou via la variable d'environnement CXX).

  3. Ils construisent une ligne de commande pour ce compilateur sous-jacent, incluant les commutateurs nécessaires pour trouver les en-têtes MPI et pour lier la bibliothèque MPI.

  4. Ils exécutent ensuite le compilateur C++ sous-jacent avec la ligne de commande construite.

NOTES

Il est rare de devoir modifier ces fichiers, mais ils peuvent être examinés pour comprendre quels commutateurs les wrappers placent sur la ligne de commande.

FILES

Les informations de configuration utilisées par les wrappers de compilateur sont stockées dans des fichiers texte dans le répertoire des variables d'environnement d'Open MPI (généralement /etc/openmpi/sorted_wrapper_argv.openmpi, /etc/openmpi/openmpi-wrapper-data.txt, etc.).

Il est rare de devoir modifier ces fichiers, mais ils peuvent être examinés pour comprendre quels commutateurs les wrappers placent sur la ligne de commande.

VARIABLES D'ENVIRONNEMENT

Par défaut, les wrappers utilisent les compilateurs qui ont été sélectionnés lors de la configuration d'Open MPI. Ces compilateurs ont été soit trouvés automatiquement par le script “configure” d'Open MPI, soit sélectionnés par l'utilisateur dans les variables d'environnement CC, CXX et/ou FC avant l'invocation de configure. De plus, d'autres arguments spécifiques au compilateur peuvent avoir été sélectionnés par configure.

Ces valeurs peuvent être remplacées sélectivement soit en modifiant les fichiers texte contenant ces informations de configuration (voir la section FILES), soit en définissant des variables d'environnement sélectionnées de la forme ompi_value.

Les noms de valeurs valides sont :

  • CPPFLAGS : Commutateurs ajoutés lors de l'invocation du préprocesseur (C ou C++)
  • LDFLAGS : Commutateurs ajoutés lors de l'invocation de l'éditeur de liens (C, C++ ou Fortran)
  • LIBS : Bibliothèques ajoutées lors de l'invocation de l'éditeur de liens (C, C++ ou Fortran)
  • CC : Compilateur C
  • CFLAGS : Commutateurs du compilateur C
  • CXX : Compilateur C++
  • CXXFLAGS : Commutateurs du compilateur C++
  • FC : Compilateur Fortran
  • FCFLAGS : Commutateurs du compilateur Fortran
