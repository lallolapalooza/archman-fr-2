mp3unicode(1) Manuel des commandes générales mp3unicode(1)

NOM

mp3unicode — Convertit les balises MP3 en Unicode

SYNTAXE

mp3unicode [options] fichier1 [fichier2] [...]

DESCRIPTION

mp3unicode MP3Unicode est un utilitaire en ligne de commande pour convertir les balises ID3 dans les fichiers mp3 entre différents encodages.

Pour voir les encodages disponibles, exécutez :

iconv --list

OPTIONS

-s, --source-encoding <encodage>
Lit les balises mp3 actuelles en supposant qu'elles sont encodées avec <encodage>. <encodage> est soit « unicode », soit un encodage 8 bits valide.
-1, --id3v1-encoding <encodage>
Écrit la balise id3v1 dans <encodage>. Si <encodage> est « none », alors la balise id3v1 est supprimée. <encodage> peut être tout encodage 8 bits valide. Notez cependant qu'il n'est pas possible d'écrire en id3v1 en Unicode.
-2, --id3v2-encoding <encodage>
Écrit la balise id3v2 dans <encodage>. Si <encodage> est « none », alors la balise id3v2 est supprimée. <encodage> peut être soit « unicode », soit un encodage 8 bits valide.
-p, --preserve-unicode
Si l'encodage source est spécifié comme un encodage spécifique et non Unicode, mais que l'encodage réel semble être Unicode, alors il est considéré comme Unicode. Par exemple, si vous voulez traiter de nombreux fichiers, dont certains sont en Unicode (ou contiennent des caractères Unicode), tandis que d'autres sont en cp1251, lancez simplement -s cp1251 -p avec d'autres options. Cela devrait fonctionner comme vous le souhaitez.
-w, --preview
Ne modifie pas les fichiers, mais affiche les balises qui seraient écrites. Utile pour tester la correction des options spécifiées.
-v, --version
Affiche le numéro de version, la date et l'heure de compilation.
-q, --quiet
Ne signale pas les fichiers traités.

EXEMPLE

mp3unicode --source-encoding cp1251 --id3v1-encoding none --id3v2-encoding unicode fichier.mp3

lira la balise id3v2 (ou id3v1 s'il n'y a pas de id3v2) du fichier, convertira les champs de texte de la balise de cp1251 vers Unicode et écrira la balise id3v2 en retour, en supprimant la balise id3v1.
