NOM


mptopdf - convertir des figures MetaPost en PDF

SYNTAXE

mptopdf [ OPTIONS ... ] [ FICHIERS ]

DESCRIPTION

convertir des figures MetaPost en PDF

OPTIONS

--metafun
utiliser le format metafun pour traiter le fichier (par défaut, mpost)
--texexec
utiliser texexec (context) pour traiter les extraits de texte
--latex
utiliser latex pour traiter les extraits de texte
