NOM

mpopd - Un serveur POP3 minimal

SYNTAXE

mpopd [option...]

DESCRIPTION

Mpopd est un serveur POP3 minimal qui distribue les mails depuis une boîte aux lettres locale au format maildir. Il peut être utilisé par les utilisateurs finaux comme moyen de gérer les courriels entrants avec mpop, pour les clients de messagerie qui insistent pour utiliser POP3. Voir la section EXEMPLES ci-dessous.
Mpopd écoute sur 127.0.0.1 port 1100 par défaut, mais peut également fonctionner sans ses propres sockets réseau en mode inetd, où il gère une seule session POP3 sur l'entrée/sortie standard.
Pour éviter les abus, mpopd n'autorisera qu'un nombre limité de sessions POP3 simultanées, et en cas d'échec d'authentification, les futures requêtes d'authentification dans toute session POP3 seront (pour une durée limitée) traitées uniquement après un court délai.

OPTIONS

--version
Affiche les informations de version
--help
Affiche l'aide
--inetd
Lance une seule session POP3 sur stdin/stdout
--interface=ip
Écoute sur l'adresse IPv6 ou IPv4 donnée au lieu de 127.0.0.1
--port=nombre
Écoute sur le numéro de port donné au lieu de 25
--log=aucun|syslog|nom_fichier
Définit la journalisation : aucun (par défaut), syslog, ou journalisation dans le fichier donné.
--auth=utilisateur[,eval_motdepasse]
Exige l'authentification avec ce nom d'utilisateur. Le mot de passe sera récupéré à partir de la commande eval_motdepasse donnée (cela fonctionne comme passwordeval dans mpop) ou, si aucun n'est donné, depuis le trousseau de clés ou, si cela échoue, depuis une invite.
--maildir=rép
Utilise ce maildir comme boîte aux lettres.

EXEMPLES

Utilisation de mpopd pour gérer les courriels entrants pour un client de messagerie basé sur POP3
Certains clients de messagerie ne peuvent pas récupérer les courriels depuis des fichiers locaux et insistent plutôt pour utiliser un serveur POP3. Vous pouvez configurer mpopd pour qu'il soit ce serveur POP3 et qu'il serve vos courriels entrants à partir d'un dossier maildir local.
(De même, certains clients de messagerie ne peuvent pas envoyer de courriels sortants via un programme tel que msmtp et insistent plutôt pour utiliser un serveur SMTP. Vous pouvez configurer msmtpd pour qu'il soit ce serveur SMTP et qu'il transmette le mail à msmtp. Voir la section pertinente du manuel de msmtp.)
À cette fin, mpopd doit écouter sur un port non privilégié, par exemple 1100 (par défaut). Une boîte aux lettres est définie en utilisant d'abord l'option --auth pour définir un nom d'utilisateur et un mot de passe, puis en utilisant l'option --maildir pour spécifier le dossier maildir qui contient les courriels entrants. Plusieurs paires d'options de ce type peuvent être utilisées pour définir plusieurs boîtes aux lettres, par exemple, provenant de différents comptes de messagerie distants. Des programmes comme mpop peuvent livrer de nouveaux courriels dans les dossiers maildir à tout moment, mais tant que mpopd est en cours d'exécution, aucun autre programme ne peut modifier ou supprimer les courriels de ces dossiers.
Utilisons le nom d'utilisateur mpopd-user. Vous avez deux options pour gérer le mot de passe :

Stockez le mot de passe dans votre trousseau de clés, par exemple avec secret-tool store --label=mpopd host localhost service pop3 user mpopd-user. Dans ce cas, utilisez l'option mpopd --auth=mpopd-user.
Stockez le mot de passe dans un fichier crypté et utilisez le mécanisme passwordeval. Exemple pour gpg : mpopd ... --auth=mpopd-user,'gpg -q -d ~/.mpopd-password.gpg'

La commande complète est alors (en utilisant le trousseau de clés) : mpopd --auth=mpopd-user --maildir=/chemin/vers/votre/dossier/maildir
Le logiciel client de messagerie doit alors être configuré pour utiliser localhost sur le port 1100 pour les courriels entrants via POP3, et pour utiliser l'authentification avec l'utilisateur mpopd-user et le mot de passe que vous avez choisi. Le client de messagerie se plaindra probablement que le serveur POP3 ne prend pas en charge TLS, mais dans ce cas spécifique, c'est acceptable car toute la communication entre votre client de messagerie et mpopd restera sur la machine locale.
