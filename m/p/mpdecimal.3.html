NOM

mpdecimal - 4.0.1

SYNOPIS

Bibliothèques C/C++ pour l'arithmétique décimale à virgule flottante de précision arbitraire avec arrondi correct.

DESCRIPTION

Les bibliothèques libmpdec et libmpdec++ implémentent entièrement la spécification générale de l'arithmétique décimale, voir :
   https://speleotrove.com/decimal/decarith.html
Comme décrit dans la section « scope » de la spécification, les bibliothèques sont conformes - avec des restrictions mineures - à la norme IEEE 754-2008 pour l'arithmétique à virgule flottante si le contexte est initialisé avec les paramètres appropriés.
Selon la distribution, la documentation HTML complète est disponible dans le paquet mpdecimal-doc ou à l'adresse :
   https://www.bytereef.org/mpdecimal/index.html
