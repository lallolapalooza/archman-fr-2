mpicc, mpic++, mpicxx, mpifort, mpijavac — Compilateurs enveloppants d'Open MPI

SYNTAX

mpicc [--showme | --showme:compile | --showme:link] ...

mpic++ [--showme | --showme:compile | --showme:link] ...

mpicxx [--showme | --showme:compile | --showme:link] ...

mpifort [--showme | --showme:compile | --showme:link] ...

mpijavac [--showme | --showme:compile | --showme:link] ...

Les commandes dépréciées suivantes sont également disponibles — mais mpifort devrait être utilisé à leur place :

mpif77 [--showme | --showme:compile | --showme:link] ...

mpif90 [--showme | --showme:compile | --showme:link] ...

Sur les systèmes de fichiers sensibles à la casse, la commande suivante sera également disponible :

mpiCC [--showme | --showme:compile | --showme:link] ...

OPTIONS

Les options ci-dessous s'appliquent à tous les compilateurs enveloppants :

•
--showme : Cette option existe en plusieurs variantes (voir ci-dessous). Aucune des variantes n'invoque le compilateur sous-jacent ; elles fournissent toutes des informations sur la manière dont le compilateur sous-jacent aurait été invoqué si --showme n'avait pas été utilisé. L'option de base --showme affiche la ligne de commande qui serait exécutée pour compiler le programme.

NOTE :

Si un argument autre qu'un nom de fichier est passé sur la ligne de commande, l'option --showme n'affichera pas de drapeaux supplémentaires. Par exemple, « mpicc --showme et mpicc --showme my_source.c afficheront tous les drapeaux fournis par l'enveloppe. Mais mpicc --showme -v n'affichera que le nom du compilateur sous-jacent et -v.
  • --showme:compile : Affiche les drapeaux du compilateur qui auraient été fournis au compilateur sous-jacent.
  • --showme:link : Affiche les drapeaux de l'éditeur de liens qui auraient été fournis au compilateur sous-jacent.
  • --showme:command : Affiche la commande du compilateur sous-jacent (qui peut être un ou plusieurs jetons).
  • --showme:incdirs : Affiche une liste de répertoires, séparés par des espaces (mais sinon non décorée), que le compilateur enveloppant aurait fournie au compilateur sous-jacent pour indiquer où se trouvent les fichiers d'en-tête pertinents.
  • --showme:libdirs : Affiche une liste de répertoires, séparés par des espaces (mais sinon non décorée), que le compilateur enveloppant aurait fournie à l'éditeur de liens sous-jacent pour indiquer où se trouvent les bibliothèques pertinentes.
  • --showme:libs Affiche une liste de noms de bibliothèques, séparés par des espaces (mais sinon non décorée), que le compilateur enveloppant aurait utilisés pour lier une application. Par exemple : mpi open-pal util.
  • --showme:version : Affiche le numéro de version d'Open MPI.
  • --showme:help : Affiche un bref message d'aide d'utilisation.

Consultez la page de manuel de votre compilateur sous-jacent pour connaître les autres options qui peuvent être passées via mpicc.

DESCRIPTION

Conceptuellement, le rôle de ces commandes est très simple : ajouter de manière transparente à la ligne de commande de l'utilisateur les compilateurs et éditeurs de liens pertinents nécessaires pour compiler / lier des programmes Open MPI, puis invoquer le compilateur sous-jacent pour exécuter la commande.

En tant que tels, ces commandes sont souvent appelées compilateurs « enveloppants » car elles ne compilent ou ne lient pas elles-mêmes les applications ; elles ajoutent uniquement des drapeaux à la ligne de commande et invoquent le compilateur backend.

BACKGROUND

Open MPI fournit des compilateurs enveloppants pour plusieurs langages :

  • mpicc : C
  • mpic++, mpicxx (et sur les systèmes sensibles à la casse, mpiCC) : C++

    NOTE :

mpic++, mpicxx, et mpiCC invoquent tous le même compilateur C++ sous-jacent avec les mêmes options. Tous sont fournis pour la compatibilité avec d'autres implémentations MPI.
  • mpifort (et ses alias obsolètes/dépréciés mpif77 et mpif90) : Fortran
  • mpijavac : Java

Les compilateurs enveloppants pour chacun des langages sont identiques ; ils peuvent être utilisés de manière interchangeable. Les différents noms sont fournis uniquement pour des raisons de compatibilité ascendante.

NOTES FORTRAN

Le compilateur enveloppant Fortran pour MPI (mpifort, et ses noms obsolètes/dépréciés mpif77 et mpif90) peut compiler et lier des applications MPI qui utilisent tout/tous les bindings Fortran MPI : mpif.h, le module mpi, et le module mpi_f08 (en supposant qu'Open MPI ait été installé avec le support pour chacun de ces bindings Fortran). Spécifiquement : il n'est plus nécessaire d'utiliser des compilateurs enveloppants différents pour les applications qui utilisent mpif.h par rapport aux applications qui utilisent le module mpi — utilisez simplement mpifort pour toutes les applications MPI Fortran.

Notez cependant que le compilateur Fortran peut nécessiter des options de ligne de commande supplémentaires pour imposer un dialecte Fortran spécifique. Par exemple, dans certaines versions du compilateur IBM XLF, xlf90 peut être nécessaire pour compiler des fichiers source Fortran au format fixe.

Enfin, notez que mpifort sera inopérant et retournera une erreur lors de son utilisation si le support Fortran n'a pas été intégré à la couche MPI.

VUE D'ENSEMBLE

mpicc est un wrapper de commodité pour le compilateur C sous-jacent. La traduction d'un programme Open MPI nécessite la liaison des bibliothèques spécifiques à Open MPI qui peuvent ne pas se trouver dans l'un des répertoires de recherche standard de ld(1). Elle nécessite également souvent l'inclusion de fichiers d'en-tête qui peuvent également ne pas se trouver dans un emplacement standard.

mpicc transmet ses arguments au compilateur C sous-jacent, ainsi que les options -I, -L et -l requises par les programmes Open MPI.

Il en va de même pour tous les autres compilateurs enveloppants de langage.

L'équipe d'Open MPI encourage *fortement* l'utilisation des compilateurs enveloppants plutôt que d'essayer de lier les bibliothèques Open MPI manuellement. Cela permet à l'implémentation spécifique d'Open MPI de changer sans forcer les changements dans les directives de l'éditeur de liens des Makefiles des utilisateurs. En effet, l'ensemble spécifique de drapeaux et de bibliothèques utilisé par les compilateurs enveloppants dépend de la manière dont Open MPI a été configuré et construit ; les valeurs peuvent changer entre différentes installations de la même version d'Open MPI.

En fait, puisque les enveloppes ne sont que des coquilles minces au-dessus d'un compilateur sous-jacent, il y a très, très peu de raisons impérieuses de *ne pas* utiliser les compilateurs enveloppants d'Open MPI. Lorsqu'il n'est pas possible d'utiliser directement les enveloppes, les options --showme:compile et --showme:link doivent être utilisées pour déterminer quels drapeaux les enveloppes auraient utilisés. Par exemple :

shell$ cc -c file1.c `mpicc --showme:compile`
shell$ cc -c file2.c `mpicc --showme:compile`
shell$ cc file1.o file2.o `mpicc --showme:link` -o my_mpi_program

NOTES

Il est possible de rendre les compilateurs enveloppants conscients des bibliothèques multiples. C'est-à-dire que les bibliothèques et les includes spécifiés peuvent différer en fonction des drapeaux du compilateur spécifiés (par exemple, avec les compilateurs GNU sous Linux, un chemin de bibliothèque différent peut être utilisé si -m32 est vu par rapport à -m64 étant vu). Ce n'est pas le comportement par défaut dans une construction standard, mais peut être activé (par exemple, dans un paquet binaire fournissant un support 32 et 64 bits). Plus d'informations peuvent être trouvées ici.

FICHIERS

Les chaînes que les compilateurs enveloppants insèrent dans la ligne de commande avant d'invoquer le compilateur sous-jacent sont stockées dans un fichier texte créé par Open MPI et installé dans $pkgdata/NOM-wrapper-data.txt, où :

  • $pkgdata est généralement $prefix/share/openmpi
  • $prefix est le répertoire d'installation principal d'Open MPI
  • NOM est le nom du compilateur enveloppant (par exemple, $pkgdata/mpicc-wrapper-data.txt)

FILES

The following files contain configuration information that the wrappers use:

${prefix}/share/openmpi/mpifort.h-armci-prefix
MPI Fortran header file (used for Fortran bindings).
${prefix}/share/openmpi/mpif.h
MPI Fortran header file (used for Fortran bindings).
${prefix}/share/openmpi/mpi-fort-compilers.conf
Configuration file used by the Fortran wrappers.

It is rarely necessary to edit these files, but they can be examined to gain insight into what flags the wrappers are placing on the command line.

VARIABLES D’ENVIRONNEMENT

Par défaut, les wrappers utilisent les compilateurs qui ont été sélectionnés lors de la configuration d’Open MPI. Ces compilateurs ont soit été trouvés automatiquement par le script “configure” d’Open MPI, soit sélectionnés par l’utilisateur dans les variables d’environnement CC, CXX et/ou FC avant l’invocation de configure. De plus, d’autres arguments spécifiques au compilateur ont pu être sélectionnés par configure.

Ces valeurs peuvent être sélectivement remplacées soit en modifiant les fichiers texte contenant ces informations de configuration (voir la section FICHIERS), soit en définissant des variables d’environnement sélectionnées de la forme ompi_value.

Les noms de valeur valides sont :

  • CPPFLAGS : Options ajoutées lors de l’invocation du préprocesseur (C ou C++).
  • LDFLAGS : Options ajoutées lors de l’invocation de l’éditeur de liens (C, C++ ou Fortran).
  • LIBS : Bibliothèques ajoutées lors de l’invocation de l’éditeur de liens (C, C++ ou Fortran).
  • CC : Compilateur C.
  • CFLAGS : Options du compilateur C.
  • CXX : Compilateur C++.
  • CXXFLAGS : Options du compilateur C++.
  • FC : Compilateur Fortran.
  • FCFLAGS : Options du compilateur Fortran.
