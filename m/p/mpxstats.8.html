NOM

mpxstats - Démon de statistiques de surveillance de multiplexage

SYNTAXE

mpxstats [options] -p port

DESCRIPTION

Le démon mpxstats multiplexe les flux de données de surveillance xrootd et cmsd dans un format séquentiel unique adapté à l'ingestion par un agent de surveillance (par exemple, ganglia, MonaLisa, nagios, etc.). La syntaxe d'utilisation peut être affichée en tapant "mpxstats". La documentation HTML complète se trouve à l'adresse


https://xrootd.web.cern.ch/doc/dev57/xrd_monitoring.htm

NOTES

La documentation de tous les composants associés à mpxstats peut être trouvée à l'adresse https://xrootd.org/docs.html

DIAGNOSTICS

Les erreurs génèrent un message d'erreur et un statut de sortie non nul. Le programme ne se termine jamais en cas de succès. Utilisez la commande kill pour terminer le programme.

LICENCE

Les conditions de licence peuvent être affichées en tapant "xrootd -H".

NIVEAU DE SUPPORT

Le démon mpxstats est pris en charge par la collaboration xrootd. Les coordonnées peuvent être trouvées à l'adresse
https://xrootd.org/contact.html
