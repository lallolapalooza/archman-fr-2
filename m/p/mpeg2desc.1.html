NOM

mpeg2desc - multiplexe des flux audio/vidéo

SYNTAXE

mpeg2desc [ -a flux ] [ -v flux ] [ -o FICHIER ] [ -s ] [ -m ] [ -h ] [ < movie.mpg ... ]

DESCRIPTION

mpeg2desc multiplexe des flux audio et vidéo

OPTIONS

-a flux
Flux audio de sortie flux (0 .. 31) vers la sortie standard
-v flux
Flux vidéo de sortie flux (0 .. 15) vers la sortie standard
-o FICHIER
sauvegarde le flux précédent dans FICHIER au lieu de la sortie standard
-s
passe au premier en-tête valide -- garantit que mplex peut gérer la sortie
-m
sortie du décalage mplex vers la sortie standard
-u
ne pas afficher les messages concernant les en-têtes non reconnus
-h
afficher une aide courte

UTILISATION

mpeg2desc mpeg2desc [options] < movie.mpg

CAVEATS

Aucun.

BUGS

Aucun.
