MRTG2PCP(1) Manuel des commandes générales MRTG2PCP(1)

NOM

mrtg2pcp - importer des données MRTG et créer une archive PCP

SYNTAXE

mrtg2pcp nom_hôte nom_périphérique fuseau_horaire fichier_entrée fichier_sortie

DESCRIPTION

mrtg2pcp est conçu pour lire un fichier journal MRTG tel que créé par mrtg(1) et le traduire en une archive Performance Co-Pilot (PCP) avec le nom de base fichier_sortie. Les arguments nom_hôte, nom_périphérique et fuseau_horaire spécifient des informations sur le système pour lequel les statistiques ont été collectées.

L'archive PCP résultante peut être utilisée avec tous les outils clients PCP pour graphique des sous-ensembles des données à l'aide de pmchart(1), effectuer une réduction et une génération de rapports de données, filtrer avec le moteur d'inférence PCP pmie(1), etc.

Une série de fichiers physiques sera créée avec le préfixe fichier_sortie. Ce sont fichier_sortie.0 (les données de performance), fichier_sortie.meta (les métadonnées qui décrivent les données de performance) et fichier_sortie.index (un index temporel pour améliorer l'efficacité des opérations de relecture pour l'archive). Si l'un de ces fichiers existe déjà, mrtg2pcp ne les écrasera **pas** et quittera avec un message d'erreur de la forme

__pmLogNewFile: ``blah.0'' existe déjà, non écrasé

mrtg2pcp est un script Perl qui utilise l'enveloppe Perl PCP::LogImport autour de la bibliothèque PCP libpcp_import, et à ce titre pourrait être utilisé comme exemple pour développer de nouveaux outils afin d'importer d'autres types de données de performance et de créer des archives PCP.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

mrtg(1), pmchart(1), pmie(1), pmlogger(1), LOGIMPORT(3) et PCP::LogImport(3).
