mrd - supprimer un sous-répertoire MSDOS

Note de mise en garde

Cette page de manuel a été générée automatiquement à partir de la documentation texinfo de mtools, et pourrait ne pas être entièrement précise ou complète. Voir la fin de cette page de manuel pour plus de détails.

Description

La commande mrd est utilisée pour supprimer un sous-répertoire MS-DOS. Sa syntaxe est la suivante :

mrd [-v] répertoiredos [ répertoiresdos... ]

Mrd supprime un répertoire d'un système de fichiers MS-DOS. Une erreur se produit si le répertoire n'existe pas ou n'est pas vide.
