MRED(1) Manuel des commandes générales MRED(1)

NOM

mred - exécutable de compatibilité pour GRacket

SYNTAXE

mred [ option ... ] [ argument ... ]

DESCRIPTION

MrEd est l'ancien nom de l'implémentation Racket GUI.

Dans la plupart des cas, exécuter mred est identique à exécuter gracket, sauf que le langage d'interaction par défaut est légèrement différent pour des raisons de compatibilité ascendante.

INFORMATIONS COMPLÉMENTAIRES

Pour plus d'informations, exécutez


raco docs

pour ouvrir la documentation installée dans votre navigateur web.

Alternativement, consultez la documentation en ligne et d'autres informations disponibles sur


http://racket-lang.org/
