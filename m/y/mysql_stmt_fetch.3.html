Nom

mysql_stmt_fetch - Récupère une ligne de jeu de résultats à partir d'une instruction préparée

Synopsis

#include <mysql.h>
int mysql_stmt_fetch(MYSQL_STMT * stmt);

Description

Récupère le résultat d'une instruction préparée dans le tampon lié par mysql_stmt_bind_result(3).

Paramètres

•
stmt - un descripteur d'instruction, qui a été précédemment alloué par mysql_stmt_init(3).

Valeur de retour

Retourne 0 en cas de succès, MYSQL_NO_DATA si la fin du jeu de résultats a été atteinte, ou MYSQL_DATA_TRUNCATION si une ou plusieurs valeurs ont été tronquées.

Notes

•
Notez que toutes les colonnes doivent être liées par l'application avant d'appeler mysql_stmt_fetch().
•
Les données sont transférées sans mise en tampon, sans appeler mysql_stmt_store_result(3), ce qui peut réduire les performances (mais diminue le coût en mémoire).
•
Le rapport de troncature doit être activé par la fonction mysql_optionsv(3) avec l'option MYSQL_REPORT_DATA_TRUNCATION.
