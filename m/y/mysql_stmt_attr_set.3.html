mysql_stmt_attr_set(3)

Paquet: mariadb

Licences: GPL-2.0-only

mysql_stmt_attr_set(3) MariaDB Connector/C mysql_stmt_attr_set(3)

Nom

mysql_stmt_attr_set - Définit un attribut d'une instruction préparée

Synopsis

#include <mysql.h>
my_bool mysql_stmt_attr_set(MYSQL_STMT * stmt,
                            enum enum_stmt_attr_type,
                            const void * attr);

Description

Utilisé pour modifier le comportement d'une instruction préparée. Cette fonction peut être appelée plusieurs fois pour définir plusieurs attributs. Retourne zéro en cas de succès, une valeur non nulle en cas d'échec.

Paramètres

•
stmt - un handle d'instruction, qui a été précédemment alloué par mysql_stmt_init(3).
•
enum_stmt_attr_type - l'attribut que vous souhaitez définir. Voir ci-dessous.
•
attr - la valeur à assigner à l'attribut

Types d'attributs

L'attribut enum_stmt_attr_type peut avoir une des valeurs suivantes :

Valeur Type Description
STMT_ATTR_UPDATE_MAX_LENGTH my_bool * Si défini à 1, mysql_stmt_store_result(3) mettra à jour la valeur max_length des structures MYSQL_FIELD.
STMT_ATTR_CURSOR_TYPE unsigned long * type de curseur lors de l'invocation de mysql_stmt_execute(3). Les valeurs possibles sont CURSOR_TYPE_READ_ONLY ou la valeur par défaut CURSOR_TYPE_NO_CURSOR.
STMT_ATTR_PREFETCH_ROWS unsigned long * nombre de lignes qui seront pré-chargées. La valeur par défaut est 1.
STMT_ATTR_PREBIND_PARAMS unsigned int * nombre de marqueurs de paramètres lors de l'utilisation de mariadb_stmt_execute_direct(3). Si le handle d'instruction est réutilisé, il sera automatiquement réinitialisé à l'état après mysql_stmt_init(). Cette option a été ajoutée dans Connector/C 3.0
STMT_ATTR_ARRAY_SIZE unsigned int * nombre d'éléments de tableau. Cette option a été ajoutée dans Connector/C 3.0 et nécessite MariaDB 10.2 ou version ultérieure.
STMT_ATTR_ROW_SIZE size_t * spécifie la taille d'une structure pour la liaison ligne par ligne. Cette longueur doit inclure l'espace pour tous les paramètres liés et tout remplissage de la structure ou du tampon pour garantir que lorsque l'adresse d'un paramètre lié est incrémentée de la longueur spécifiée, le résultat pointera vers le début du même paramètre dans le prochain ensemble de paramètres. Lors de l'utilisation de l'opérateur sizeof en C ANSI, ce comportement est garanti. Si la valeur est zéro, la liaison colonne par colonne sera utilisée (par défaut). Cette option a été ajoutée dans Connector/C 3.0 et nécessite MariaDB 10.2 ou version ultérieure.

Notes

•
Si vous utilisez l'option MYSQL_STMT_ATTR_CURSOR_TYPE avec MYSQL_CURSOR_TYPE_READ_ONLY, un curseur est ouvert pour l'instruction lorsque vous appelez mysql_stmt_execute(3). S'il existe déjà un curseur ouvert d'un appel précédent à mysql_stmt_execute(3), il ferme le curseur avant d'en ouvrir un nouveau. mysql_stmt_reset(3) ferme également tout curseur ouvert avant de préparer l'instruction pour la ré-exécution.
•
Si vous ouvrez un curseur pour une instruction préparée, il n'est pas nécessaire d'appeler mysql_stmt_store_result(3).
•
mysql_stmt_free_result(3) ferme tout curseur ouvert.
