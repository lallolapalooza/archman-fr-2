MARIADB-STRESS-TEST(1) Système de base de données MariaDB MARIADB-STRESS-TEST(1)

NOM

mariadb-stress-test.pl - programme de test de charge du serveur

SYNOPIS

mariadb-stress-test.pl [options]

DESCRIPTION

Le script Perl mariadb-stress-test.pl effectue des tests de charge du serveur MariaDB.

mariadb-stress-test.pl nécessite une version de Perl qui a été compilée avec le support des threads.

Invoquez mariadb-stress-test.pl comme suit :

shell> mariadb-stress-test.pl [options]

mariadb-stress-test.pl prend en charge les options suivantes :

•--help

Affiche un message d'aide et quitte.

•--abort-on-error=N

Indique au programme d'avorter si une erreur de gravité inférieure ou égale à N a été rencontrée. Réglez à 1 pour avorter en cas d'erreur.

•--check-tests-file

Vérifie périodiquement le fichier qui liste les tests à exécuter. S'il a été modifié, relit le fichier. Ceci peut être utile si vous mettez à jour la liste des tests à exécuter pendant un test de charge.

•--cleanup

Force le nettoyage du répertoire de travail.

•--log-error-details

Enregistre les détails des erreurs dans le fichier journal global des erreurs.

•--loop-count=N

En mode de test séquentiel, le nombre de boucles à exécuter avant de quitter.

•--mariadb-test=chemin

Le chemin d'accès au programme mariadb-test.

•--server-database=nom_db

La base de données à utiliser pour les tests. La valeur par défaut est test.

•--server-host=nom_hôte

Le nom d'hôte de la machine locale à utiliser pour établir une connexion TCP/IP au serveur local. Par défaut, la connexion est établie à localhost en utilisant un fichier socket Unix.

•--server-logs-dir=chemin

Cette option est requise. chemin est le répertoire où seront stockés tous les journaux de session client. Habituellement, il s'agit du répertoire partagé associé au serveur utilisé pour les tests.

•--server-password=mot_de_passe

Le mot de passe à utiliser lors de la connexion au serveur.

•--server-port=num_port

Le numéro de port TCP/IP à utiliser pour la connexion au serveur. La valeur par défaut est 3306.

•--server-socket=nom_fichier

Pour les connexions à localhost, le fichier socket Unix à utiliser, ou, sous Windows, le nom du pipe nommé à utiliser. La valeur par défaut est /tmp/mariadb.sock.

•--server-user=nom_utilisateur

Le nom d'utilisateur MariaDB à utiliser lors de la connexion au serveur. La valeur par défaut est root.

•--sleep-time=N

Le délai en secondes entre les exécutions de tests.

•--stress-basedir=chemin

Cette option est requise. chemin est le répertoire de travail pour l'exécution du test. Il est utilisé comme emplacement temporaire pour le suivi des résultats pendant le test.

•--stress-datadir=chemin

Le répertoire des fichiers de données à utiliser pendant les tests. L'emplacement par défaut est le répertoire de données sous l'emplacement donné par l'option --stress-suite-basedir.

•--stress-init-file[=chemin]

nom_fichier est l'emplacement du fichier contenant la liste des tests à exécuter une fois pour initialiser la base de données pour les tests. S'il est absent, le fichier par défaut est stress_init.txt dans le répertoire de la suite de tests.

•--stress-mode=mode

Cette option indique l'ordre des tests en mode test de charge. La valeur de mode est soit random pour sélectionner les tests dans un ordre aléatoire, soit seq pour exécuter les tests dans chaque thread dans l'ordre spécifié dans le fichier liste des tests. Le mode par défaut est random.

•--stress-suite-basedir=chemin

Cette option est requise. chemin est le répertoire contenant les sous-répertoires t et r, qui contiennent les fichiers de cas de test et de résultats. Ce répertoire est également l'emplacement par défaut du fichier stress-test.txt qui contient la liste des tests. (Un emplacement différent peut être spécifié avec l'option --stress-tests-file.)

•--stress-tests-file[=nom_fichier]

Utilisez cette option pour exécuter les tests de charge. nom_fichier est l'emplacement du fichier contenant la liste des tests. Si nom_fichier est omis, le fichier par défaut est stress-test.txt dans le répertoire de la suite de tests. (Voir --stress-suite-basedir.)

•--suite=nom_suite

Exécute la suite de tests nommée. Le nom par défaut est main (la suite de tests régulière située dans le répertoire mariadb-test).

•--test-count=N

Le nombre de tests à exécuter avant de quitter.

•--test-duration=N

La durée du test de charge en secondes.

•--threads=N

Le nombre de threads. La valeur par défaut est 1.

•--verbose

Mode détaillé. Affiche plus d'informations sur ce que fait le programme.
