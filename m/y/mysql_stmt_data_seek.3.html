Nom

mysql_stmt_data_seek - Se positionne sur une ligne arbitraire dans le jeu de résultats de l'instruction

Synopsis

#include <mysql.h>
void mysql_stmt_data_seek(MYSQL_STMT * stmt,
                          my_ulonglong offset);

Description

Se positionne sur une ligne arbitraire dans le jeu de résultats de l'instruction obtenu par un appel précédent à mysql_stmt_store_result(3).

Paramètre

•
stmt - un descripteur d'instruction, qui a été précédemment alloué par mysql_stmt_init(3).
•
offset - décalage de ligne. Cette valeur doit être comprise entre 0 et le nombre de lignes - 1.

Valeur de retour

Retourne void

Notes

•
Le nombre de lignes peut être obtenu avec la fonction mysql_stmt_num_rows(3).
