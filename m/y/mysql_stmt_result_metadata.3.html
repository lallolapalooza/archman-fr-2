Nom

mysql_stmt_result_metadata - Retourne les métadonnées de l'ensemble de résultats d'une instruction préparée.

Synopsis

#include <mysql.h>
MYSQL_RES * mysql_stmt_result_metadata(MYSQL_STMT * stmt);

Description

Si une instruction passée à mysql_stmt_prepare(3) est de celles qui produisent un ensemble de résultats, mysql_stmt_result_metadata() retourne l'ensemble de résultats qui peut être utilisé pour traiter les informations méta telles que le nombre total de champs et les informations de chaque champ.

Paramètre

•
stmt - un handle d'instruction, précédemment alloué par mysql_stmt_init(3).

Valeur de retour

Retourne un ensemble de résultats qui peut être utilisé pour traiter les informations de métadonnées.

Notes

•
L'ensemble de résultats retourné par mysql_stmt_result_metadata() contient uniquement les métadonnées. Il ne contient aucun résultat de ligne. Les lignes sont obtenues par mysql_stmt_fetch(3).
•
Ce pointeur d'ensemble de résultats peut être passé comme argument à n'importe laquelle des fonctions basées sur les champs qui traitent les métadonnées d'ensemble de résultats, telles que : mysql_num_fields(3), mysql_fetch_field(3), mysql_fetch_field_direct(3), mysql_fetch_fields(3), mysql_field_count(3), mysql_field_seek(3), mysql_field_tell(3), mysql_free_result(3)
