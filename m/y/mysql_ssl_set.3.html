mysql_ssl_set(3)

Paquet: mariadb

Licences: GPL-2.0-only

mysql_ssl_set(3) Connecteur MariaDB/C mysql_ssl_set(3)

Nom

mysql_ssl_set - Définit les options TLS/SSL

Synopsis

#include <mysql.h>
my_bool mysql_ssl_set(MYSQL *mysql,
                      const char *key,
                      const char *cert,
                      const char *ca,
                      const char *capath,
                      const char *cipher)

Description

Utilisé pour établir une connexion TLS sécurisée. Il doit être appelé avant de tenter d'utiliser mysql_real_connect(3). Le support TLS doit être activé dans la bibliothèque cliente pour que la fonction ait un effet.

NULL peut être utilisé pour un paramètre inutilisé. Retourne toujours zéro.

Pour activer TLS sans spécifier de certificats, définissez toutes les valeurs à NULL :

mysql_ssl_set(mysql, NULL, NULL, NULL, NULL, NULL)

Ceci est équivalent à mysql_optionsv(mysql, MYSQL_OPT_SSL_ENFORCE, &yes).

Paramètre

•
mysql - un pointeur vers une structure MYSQL, qui a été précédemment allouée par mysql_init(3).
•
key - chemin vers le fichier de clé.
•
cert - chemin vers le fichier de certificat.
•
ca - chemin vers le fichier de l'autorité de certification.
•
capath - chemin vers le répertoire contenant les certificats de CA TLS approuvés au format PEM.
•
cipher - liste des suites de chiffrement autorisées (SSLv3, TLSv1.0 ou TLSv1.2) à utiliser pour le chiffrement TLS.

Notes

•
mysql_real_connect(3) retournera une erreur si une tentative de connexion échoue et que TLS est incorrectement configuré.
•
Même si Connector/C prend en charge le protocole TLSv1.3, il n'est pas encore possible de spécifier les suites de chiffrement TLSv1.3 via le paramètre cipher.
