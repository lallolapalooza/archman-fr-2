NOM

mysqlrouter_passwd - Outil de mots de passe MySQL Router

SYNTAXE

mysqlrouter_passwd [options]

DESCRIPTION

L'utilitaire mysqlrouter_passwd est une application en ligne de commande pour gérer les comptes dans le fichier passwd. Pour un exemple d'utilisation, voir la Section 6.1, “Un guide simple de l'API REST MySQL Router”.

Informations d'utilisation :

Usage
  bin/mysqlrouter_passwd [opts] <cmd> <filename> [<username>]
  bin/mysqlrouter_passwd --help
  bin/mysqlrouter_passwd --version
Commandes
  delete
      Supprime l'utilisateur (s'il existe) de <filename>.
  list
      liste un ou tous les comptes de <filename>.
  set
      ajoute ou écrase le compte de <username> dans <filename>.
  verify
      vérifie si le mot de passe correspond aux identifiants de <username> dans <filename>.
Options
  -?, --help
      Affiche cette aide et quitte.
  --kdf <nom>
      Fonction de dérivation de clé pour 'set'. L'un des choix suivants : pbkdf2-sha256, pbkdf2-sha512,
      sha256-crypt, sha512-crypt. par défaut : sha256-crypt
  -V, --version
      Affiche les informations de version et quitte.
  --work-factor <num>
      Indication du facteur de travail pour KDF si le compte est mis à jour.
