mysql_real_escape_string(3) MariaDB Connector/C mysql_real_escape_string(3)

Nom

mysql_real_escape_string - échappe une chaîne en tenant compte du jeu de caractères de la connexion

Synopsis

#include <mysql.h>
unsigned long mysql_real_escape_string(MYSQL * mysql,
                                       char * to,
                                       const char * from,
                                       unsigned long);

Description

Cette fonction est utilisée pour créer une chaîne SQL légale que vous pouvez utiliser dans une instruction SQL. La chaîne donnée est encodée en une chaîne SQL échappée, en tenant compte du jeu de caractères actuel de la connexion.

Paramètre

•
mysql - un handle mysql, précédemment alloué par mysql_init(3) et connecté par mysql_real_connect(3).
•
to - tampon pour la chaîne encodée. La taille de ce tampon doit être de la longueur * 2 + 1 octets : dans le pire des cas, chaque caractère de la chaîne from doit être échappé. De plus, un caractère nul de fin sera ajouté.
•
from - une chaîne qui sera encodée par mysql_real_escape_string().
•
long - la longueur de la chaîne from.

Valeur de retour

Retourne la longueur de la chaîne encodée (to).
