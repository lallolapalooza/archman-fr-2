mysql_stmt_warning_count(3) MariaDB Connector/C mysql_stmt_warning_count(3)

Nom

mysql_stmt_warning_count - Retourne le nombre d'avertissements de la dernière instruction exécutée.

Synopsis

#include <mysql.h>
unsigned int mysql_stmt_warning_count(MYSQL_STMT * stmt);

Description

Retourne le nombre d'avertissements de la dernière instruction exécutée, ou zéro s'il n'y a pas d'avertissements. ## Paramètre * stmt - un handle d'instruction, qui a été précédemment alloué par mysql_stmt_init(3).

Valeur de retour

Retourne le nombre d'avertissements.

Notes

•
Pour récupérer les messages d'avertissement, vous devez utiliser la commande SQL SHOW WARNINGS.
•
Si SQL_MODE TRADITIONAL est activé, une erreur au lieu d'un avertissement sera retournée. Pour des informations détaillées, vérifiez la documentation du serveur. ## Historique Cette fonction a été ajoutée dans Connector/C 3.0.
