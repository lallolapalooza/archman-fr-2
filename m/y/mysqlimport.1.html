MARIADB-IMPORT(1) Système de base de données MariaDB MARIADB-IMPORT(1)

NOM

mariadb-import - un programme d'importation de données (mariadb-import est maintenant un lien symbolique vers mariadb-import)

SYNOPIS

mariadb-import [options] nom_base_de_donnees fichier_texte1 ...

DESCRIPTION

Le client mariadb-import fournit une interface en ligne de commande à l'instruction SQL LOAD DATA INFILE. La plupart des options de mariadb-import correspondent directement aux clauses de la syntaxe de LOAD DATA INFILE.

Invoquez mariadb-import comme ceci :

shell> mariadb-import [options] nom_base_de_donnees fichier_texte1 [fichier_texte2 ...]

Pour chaque fichier texte nommé sur la ligne de commande, mariadb-import supprime toute extension du nom de fichier et utilise le résultat pour déterminer le nom de la table dans laquelle importer le contenu du fichier. Par exemple, les fichiers nommés patient.txt, patient.text et patient seraient tous importés dans une table nommée patient.

mariadb-import prend en charge les options suivantes, qui peuvent être spécifiées sur la ligne de commande ou dans les groupes de fichiers d'options [mariadb-import] et [client]. mariadb-import prend également en charge les options de traitement des fichiers d'options.

•--help, -?

Affiche un message d'aide et quitte.

•--character-sets-dir=chemin

Le répertoire où les jeux de caractères sont installés.

•--columns=liste_colonnes, -c liste_colonnes

Cette option prend une liste de noms de colonnes séparés par des virgules comme valeur. L'ordre des noms de colonnes indique comment faire correspondre les colonnes du fichier de données avec les colonnes de la table.

•--compress, -C

Compresse toutes les informations envoyées entre le client et le serveur si les deux prennent en charge la compression.

•--debug[=options_debug], -# [options_debug]

Écrit un journal de débogage. Une chaîne options_debug typique est 'd:t:o,nom_fichier'. La valeur par défaut est 'd:t:o'.

•--debug-check

Affiche certaines informations de débogage lors de la sortie du programme.

•--debug-info

Affiche des informations de débogage et des statistiques d'utilisation de la mémoire et du CPU lors de la sortie du programme.

•--default-auth=nom_plugin

Plugin client par défaut pour l'authentification à utiliser.

•--default-character-set=nom_jeu_caracteres

Utilise nom_jeu_caracteres comme jeu de caractères par défaut.

•--defaults-extra-file=nom_fichier

Définit nom_fichier comme fichier à partir duquel lire les options par défaut après que les fichiers de valeurs par défaut globaux ont été lus. Doit être fourni comme première option.

•--defaults-file=nom_fichier

Définit nom_fichier comme fichier à partir duquel lire les options par défaut, remplaçant les fichiers de valeurs par défaut globaux. Doit être fourni comme première option.

•--delete, -d

Vide la table avant d'importer le fichier texte.

•--fields-terminated-by=..., --fields-enclosed-by=..., --fields-optionally-enclosed-by=..., --fields-escaped-by=...

Ces options ont la même signification que les clauses correspondantes pour LOAD DATA INFILE.

•--force, -f

Ignore les erreurs. Par exemple, si une table pour un fichier texte n'existe pas, continue le traitement des fichiers restants. Sans --force, mariadb-import se termine si une table n'existe pas.

•--host=nom_hote, -h nom_hote

Importe les données vers le serveur MariaDB sur l'hôte donné. L'hôte par défaut est localhost.

•--ignore, -i

Voir la description de l'option --replace.

•--ignore-foreign-keys, -k

Désactive les vérifications de clés étrangères pendant l'importation des données.

•--ignore-lines=N

Ignore les N premières lignes du fichier de données.

•--innodb-optimize-keys

Crée les index secondaires après le chargement des données, ce qui accélère le chargement (InnoDB uniquement). Activé par défaut ; utilisez --skip-innodb-optimize-keys pour désactiver.

•--lines-terminated-by=...

Cette option a la même signification que la clause correspondante pour LOAD DATA INFILE. Par exemple, pour importer des fichiers Windows dont les lignes se terminent par des paires retour chariot/nouvelle ligne, utilisez --lines-terminated-by="\r\n". (Vous pourriez avoir à doubler les barres obliques inverses, selon les conventions d'échappement de votre interpréteur de commandes.).

•--local, -L

Lit les fichiers d'entrée localement depuis l'hôte client.

•--lock-tables, -l

Verrouille toutes les tables en écriture avant de traiter les fichiers texte. Cela garantit que toutes les tables sont synchronisées sur le serveur.

•--low-priority

Utilise LOW_PRIORITY lors du chargement de la table. Cela n'affecte que les moteurs de stockage qui utilisent uniquement le verrouillage au niveau de la table (tels que MyISAM, MEMORY et MERGE).

•--no-defaults

Ne lit pas les options par défaut à partir d'un fichier d'options. Doit être donné comme premier argument.

•--parallel=N, -j N

Nombre de tâches LOAD DATA exécutées en parallèle. --use-threads est un synonyme.

•--password[=mot_de_passe], -p[mot_de_passe]

Le mot de passe à utiliser lors de la connexion au serveur. Si vous utilisez la forme courte de l'option (-p), vous ne pouvez pas laisser d'espace entre l'option et le mot de passe. Si vous omettez la valeur mot_de_passe après l'option --password ou -p sur la ligne de commande, mariadb-import vous demandera de le saisir.

Spécifier un mot de passe sur la ligne de commande doit être considéré comme peu sûr. Vous pouvez utiliser un fichier d'options pour éviter de donner le mot de passe sur la ligne de commande.

•--pipe, -W

Sous Windows, se connecte au serveur via un pipe nommé. Cette option ne s'applique que si le serveur prend en charge les connexions par pipe nommé.

•--plugin-dir=nom


Répertoire pour les plugins côté client.

•--port=num_port, -P num_port

Le numéro de port TCP/IP à utiliser pour la connexion. Force --protocol=tcp lorsqu'il est spécifié sur la ligne de commande sans autres propriétés de connexion.

•--protocol={TCP|SOCKET|PIPE|MEMORY}

Le protocole de connexion à utiliser pour se connecter au serveur. Il est utile lorsque les autres paramètres de connexion provoqueraient normalement l'utilisation d'un protocole autre que celui que vous souhaitez.

•--print-defaults

Affiche la liste des arguments du programme et quitte. Doit être donné comme premier argument.

•--replace, -r

Les options --replace et --ignore contrôlent la gestion des lignes d'entrée qui dupliquent des lignes existantes sur des valeurs de clé uniques. Si vous spécifiez --replace, les nouvelles lignes remplacent les lignes existantes ayant la même valeur de clé unique. Si vous spécifiez --ignore, les lignes d'entrée qui dupliquent une ligne existante sur une valeur de clé unique sont ignorées. Si vous ne spécifiez aucune des deux options, une erreur se produit lorsqu'une valeur de clé dupliquée est trouvée, et le reste du fichier texte est ignoré.

•--silent, -s

Mode silencieux. N'affiche une sortie qu'en cas d'erreurs.

•--socket=chemin, -S chemin

Pour les connexions à localhost, le fichier socket Unix à utiliser, ou, sous Windows, le nom du pipe nommé à utiliser. Force --protocol=socket lorsqu'il est spécifié sur la ligne de commande sans autres propriétés de connexion ; sous Windows, force --protocol=pipe.

    NAME

    mysqlimport — client utility program that provides a convenient way to import data files into MariaDB tables.

    SYNOPSIS

    mysqlimport [options] [database] file...

    DESCRIPTION

    mysqlimport is a client utility program that provides a convenient way to import data files into MariaDB tables. It is a wrapper around the LOAD DATA INFILE SQL statement. For each file specified on the command line, mysqlimport infers the table name from the filename. It then executes a LOAD DATA LOCAL INFILE statement to load the file contents into the table.

    The default behavior is to treat the file as a tab-separated values file. Options can be used to override this.

    The following options are available for mysqlimport:

    •--bind-address=host

    Use the given IP address to connect to the MariaDB server.

    •--compress, -C

    Use compression for the client-server connection.

    •--database=db_name, -D db_name

    The database to use.

    •--debug[=debug_options], -#[debug_options]

    Write a debugging log to a socket or a file. The default debug area is `default',the default file is `/tmp/mysqladmin.trace\'.

    •--debug-init=debug_options

    Perform the same debugging as --debug, but only for the initialization protocol.

    •--default-auth=method

    Use the specified authentication plugin.

    •--delimiter=char

    The character that separates fields. Default is tab ('\t').

    •--fields-enclosed-by=char

    The character that encloses fields. Default is none.

    •--fields-optionally-enclosed-by=char

    The character that optionally encloses fields. Default is none.

    •--fields-terminated-by=char

    The character that terminates fields. Default is tab ('\t').

    •--force, -f

    Continue even if errors occur.

    •--host=host_name, -h host_name

    Connect to the specified host.

    •--ignore-lines=N

    Ignore the first N lines of input.

    •--local, -L

    Read input from the client host and send it to the server. This option is required if the server is not running on the same host as the client.

    •--lines-terminated-by=string

    The string that terminates lines. Default is newline ('\n').

    •--lines-starting-by=string

    The string that starts lines.

    •--lines-terminated-by=string

    The string that terminates lines. Default is newline ('\n').

    •--lines-ending-by=string

    The string that ends lines.

    •--no-defaults

    Do not read default options from any of the usual option files.

    •--null-value=string

    The string that represents NULL values. Default is 'NULL'.

    •--option-file=file_name, -o file_name

    Read options from the given file.

    •--password[=password], -p[password]

    The password to use for connecting to the server. If password is not given, it will be prompted for.

    •--port=port_num, -P port_num

    The TCP/IP port number to use for connecting to the server.

    •--protocol=protocol

    Use the specified connection protocol (e.g., TCP, SOCKET, PIPE, MEMORY).

    •--skip-ssl

    Disable SSL when connecting. This is the default unless other SSL flags are enabled.

    •--ssl-ca=name

    CA file in PEM format (check OpenSSL docs, implies --ssl).

    •--ssl-capath=name

    CA directory (check OpenSSL docs, implies --ssl).

    •--ssl-cert=name

    X509 cert in PEM format (check OpenSSL docs, implies --ssl).

    •--ssl-cipher=name

    SSL cipher to use (check OpenSSL docs, implies --ssl).

    •--ssl-key=name

    X509 key in PEM format (check OpenSSL docs, implies --ssl).

    •--ssl-crl=name

    Certificate revocation list (check OpenSSL docs, implies --ssl).

    •--ssl-crlpath=name

    Certificate revocation list path (check OpenSSL docs, implies --ssl).

    •--ssl-verify-server-cert

    Verify server's "Common Name" in its cert against hostname used when connecting. This option is disabled by default.

    •--user=user_name, -u user_name

    The MariaDB user name to use when connecting to the server.

    •--use-threads=N

    Load files in parallel using N threads. Synonym for -j, --parallel=num

    •--verbose, -v

    Verbose mode. Print more information about what the program does.

    •--version, -V

    Display version information and exit.
