mysql_autocommit(3) MariaDB Connector/C mysql_autocommit(3)

Nom

mysql_autocommit - Bascule le mode autocommit

Synopsis

#include <mysql.h>
my_bool mysql_autocommit(MYSQL * mysql, my_bool auto_mode);

Description

Bascule le mode autocommit en marche ou à l'arrêt pour la connexion de base de données actuelle. Le mode autocommit sera activé si mode=1 ou désactivé si mode=0.

Paramètres :

•
mysql est un identifiant de connexion, qui a été précédemment alloué par mysql_init(3) et connecté par mysql_real_connect(3).
•
auto_mode - pour activer ou désactiver l'autocommit.

Notes

•
Le mode autocommit n'affecte que les opérations sur les types de tables transactionnelles. Pour déterminer l'état actuel du mode autocommit, utilisez la commande SQL SELECT @@autocommit ou vérifiez le statut du serveur (voir exemple ci-dessous).
•
Attention : la fonction [mysql_rollback()}(mysql_rollback() ne fonctionnera pas si le mode autocommit est activé.

Exemples

SQL

# Désactiver l'autocommit
SET AUTOCOMMIT=0;
# Récupérer l'autocommit
SELECT @@autocommit;
+--------------+
| @@autocommit |
+--------------+
|            0 |
+--------------+

MariaDB Connector/C

static int test_autocommit(MYSQL *mysql)
{
  int rc;
  unsigned int server_status;
  /* Désactiver l'autocommit */
  rc= mysql_autocommit(mysql, 0);
  if (rc)
    return rc; /* Erreur */
  /* Si autocommit = 0 a réussi, le dernier paquet OK a mis à jour le statut du serveur */
  rc= mariadb_get_infov(mysql, MARIADB_CONNECTION_SERVER_STATUS, &server_status);
  if (rc)
    return rc; /* Erreur */
  if (server_status & SERVER_STATUS_AUTOCOMMIT)
  {
    printf("Erreur: autocommit est activé\n");
    return 1;
  }
  printf("OK: autocommit est désactivé\n");
  return 0;
}
