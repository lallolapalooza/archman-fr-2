Nom

mysql_session_track_get_first - récupère les informations de la première modification d'état de session

Synopsis

#include <mysql.h>
int mysql_session_track_get_first(MYSQL * mysql,
                                  enum enum_session_state_type type,
                                  const char **data,
                                  size_t *length );

Description

mysql_session_track_get_first() récupère les premières informations de modification d'état de session reçues du serveur.

Selon le type spécifié, le pointeur de données en lecture seule contiendra les informations suivantes : * SESSION_TRACK_SCHEMA : le nom du schéma par défaut (base de données) * SESSION_TRACK_SYSTEM_VARIABLES : si une variable système de session est modifiée, le premier appel contient le nom de la variable système modifiée, le deuxième appel contient la nouvelle valeur. Le nom et la valeur sont représentés sous forme de chaînes de caractères. * SESSION_TRACK_STATE_CHANGE : indique si l'état de la session a changé. La valeur est modifiée en chaîne de caractères “1” (modifié) ou “0” (inchangé).

Les données supplémentaires doivent être obtenues en appelant mysql_session_track_get_next(3).

Paramètre

•
mysql - handle mysql, préalablement alloué par mysql_init(3) et connecté par mysql_real_connect(3).
•
type - type d'information. Les valeurs valides sont
•
SESSION_TRACK_SYSTEM_VARIABLES
•
SESSION_TRACK_SCHEMA
•
SESSION_TRACK_STATE_CHANGE
•
SESSION_TRACK_GTIDS (non pris en charge)
•
data - pointeur vers les données, qui doit être déclaré comme const char *
•
length - pointeur vers une variable de type size_t, qui contiendra la longueur des données

Retour

Zéro en cas de succès, une valeur non nulle si aucune information de suivi de session n'est disponible.

Historique

mysql_session_track_get_first() a été ajoutée dans Connector/C 3.0 et MariaDB Server 10.2.
