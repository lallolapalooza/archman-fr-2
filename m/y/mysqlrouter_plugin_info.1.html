NOM

mysqlrouter_plugin_info - Informations sur les plugins MySQL Router

SYNTAXE

mysqlrouter_plugin_info [options]

DESCRIPTION

L'utilitaire mysqlrouter_plugin_info est un outil de débogage qui inspecte un plugin MySQL Router à la recherche de conflits potentiels et de problèmes généraux.

Informations d'utilisation :

$> ./mysqlrouter_plugin_info --help
Usage:
  ./mysqlrouter_plugin_info <mysqlrouter_plugin_file> <mysql_plugin_name>
Example:
  ./mysqlrouter_plugin_info /usr/lib/mysqlrouter/routing.so routing
Pour afficher les informations d'aide :
  ./mysqlrouter_plugin_info --help
Pour afficher la version de l'application :
  ./mysqlrouter_plugin_info --version
$> ./bin/mysqlrouter_plugin_info --version
MySQLRouter Plugin Info App 8.4.3

Exemple d'utilisation :

$> ./bin/mysqlrouter_plugin_info lib/mysqlrouter/routing.so routing
{
    "abi-version": "2.0",
    "arch-descriptor": "i386/darwin//",
    "brief": "Routing MySQL connections between MySQL clients/connectors and servers",
    "plugin-version": "0.0.1",
    "requires": [],
    "conflicts": []
}
