Nom

mysql_read_query_result - attend un ensemble de résultats de serveur ou un paquet de réponse

Synopsis

#include <mysql.h>
my_bool mysql_read_query_result(MYSQL * mysql);

Description

Attend un ensemble de résultats de serveur ou un paquet de réponse d'un mysql_send_query(3) précédemment exécuté.

Paramètres

•
mysql - une poignée mysql, qui a été précédemment allouée par mysql_init(3) et connectée par mysql_real_connect(3).

Valeur de retour

Zéro en cas de succès, non zéro en cas d'erreur.

Exemple

Pour un exemple d'utilisation de ’mysql_send_query()` dans un modèle piloté par les événements, veuillez consulter l'entrée du blog de Jan Kneschke “Requêtes MySQL asynchrones avec l'API C”.
