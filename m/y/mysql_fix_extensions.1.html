MARIADB-FIX-EXTENSIONS(1) Système de base de données MariaDB MARIADB-FIX-EXTENSIONS(1)

NOM

mariadb-fix-extensions - normalise les extensions de noms de fichiers de table (mariadb-fix-extensions est maintenant un lien symbolique vers mariadb-fix-extensions)

SYNTAXE

mariadb-fix-extensions répertoire_données

DESCRIPTION

Ce script est obsolète et sera supprimé dans une future version.

mariadb-fix-extensions convertit les extensions des fichiers de table MyISAM (ou ISAM) vers leurs formes canoniques. Il recherche les fichiers avec des extensions correspondant à n'importe quelle variante de casse de .frm, .myd, .myi, .isd et .ism et les renomme pour avoir les extensions .frm, .MYD, .MYI, .ISD et .ISM, respectivement. Cela peut être utile après avoir transféré les fichiers d'un système avec des noms de fichiers insensibles à la casse (comme Windows) vers un système avec des noms de fichiers sensibles à la casse.

Appelez mariadb-fix-extensions comme ceci, où répertoire_données est le nom du chemin vers le répertoire de données MariaDB.

shell> mariadb-fix-extensions répertoire_données
