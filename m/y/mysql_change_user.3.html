mysql_change_user(3) Connecteur C MariaDB mysql_change_user(3)

Nom

mysql_change_user - change l'utilisateur et la base de données par défaut

Synopsis

#include <mysql.h>
my_bool mysql_change_user(MYSQL * mysql,
                          const char * user,
                          const char * passwd,
                          const char * db);

Description

Change l'utilisateur et la base de données par défaut de la connexion actuelle.

Pour changer d'utilisateur avec succès, des paramètres de nom d'utilisateur et de mot de passe valides doivent être fournis, et cet utilisateur doit disposer des permissions suffisantes pour accéder à la base de données souhaitée. Si, pour une raison quelconque, l'autorisation échoue, l'authentification de l'utilisateur actuel restera.

Paramètres

•
mysql est un identifiant de connexion, précédemment alloué par mysql_init(3) et connecté par mysql_real_connect(3).
•
user - le nom d'utilisateur pour l'authentification du serveur
•
passwd - le mot de passe pour l'authentification du serveur
•
db - la base de données par défaut. Si désiré, la valeur NULL peut être passée, ce qui ne fera que changer l'utilisateur et ne sélectionnera pas de base de données. Pour sélectionner une base de données dans ce cas, utilisez la fonction mysql_select_db(3).

Notes

•
mysql_change_user provoquera toujours le comportement de la connexion de base de données actuelle comme s'il s'agissait d'une connexion de base de données complètement nouvelle, indépendamment du succès de l'opération. Cette réinitialisation comprend l'exécution d'un rollback sur toutes les transactions actives, la fermeture de toutes les tables temporaires et le déverrouillage de toutes les tables verrouillées.
•
Pour prévenir les attaques par déni de service et les attaques par force brute, le serveur bloquera la connexion si mysql_change_user() a échoué trois fois de suite.

Valeur de retour

Retourne zéro en cas de succès, une valeur non nulle si une erreur s'est produite.
