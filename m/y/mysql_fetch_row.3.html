Nom

mysql_fetch_row - récupère une ligne de données de l'ensemble de résultats

Synopsis

#include <mysql.h>
MYSQL_ROW mysql_fetch_row(MYSQL_RES * result);

Description

Récupère une ligne de données de l'ensemble de résultats et la retourne sous forme de tableau de pointeurs char (MYSQL_ROW), où chaque colonne est stockée à un décalage à partir de 0 (zéro). Chaque appel suivant à cette fonction retournera la ligne suivante dans l'ensemble de résultats, ou NULL s'il n'y a plus de lignes.

Paramètre

•
result - un identifiant d'ensemble de résultats retourné par mysql_store_result(3) ou mysql_use_result(3).

Notes

•
Si une colonne contient une valeur NULL, le pointeur char correspondant sera défini sur NULL.
•
La mémoire associée à MYSQL_ROW sera libérée lors de l'appel à la fonction mysql_free_result(3).

Valeur de retour

Une structure MYSQL_ROW (tableau de pointeurs de caractères) représentant les données de la ligne actuelle. S'il n'y a plus de lignes disponibles, NULL sera retourné.
