Nom

mysql_real_query - exécute une requête (binaire sécurisé)

Synopsis

#include <mysql.h>
int mysql_real_query(MYSQL * mysql,
                     const char * query,
                     unsigned long length);

Description

mysql_real_query() est la fonction binaire sécurisée pour exécuter une requête sur le serveur de base de données.

Paramètres

•
mysql - un handle mysql, qui a été préalablement alloué par mysql_init(3) et connecté par mysql_real_connect(3).
•
query - une chaîne contenant la requête à exécuter.
•
length - la longueur de la chaîne.

Notes

•
Contrairement à la fonction mysql_query(3), mysql_real_query est binaire sécurisée.
•
Pour déterminer si mysql_real_query retourne un jeu de résultats, utilisez la fonction mysql_num_fields(3).

Valeur de retour

Retourne zéro en cas de succès, sinon une valeur non nulle.
