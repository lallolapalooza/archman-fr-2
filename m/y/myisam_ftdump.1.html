NOM

myisam_ftdump - afficher des informations sur l'index full-text

SYNTAXE

myisam_ftdump [options] nom_table num_index

DESCRIPTION

myisam_ftdump affiche des informations sur les index FULLTEXT dans les tables MyISAM. Il lit directement le fichier d'index MyISAM, il doit donc être exécuté sur l'hôte serveur où se trouve la table. Avant d'utiliser myisam_ftdump, assurez-vous d'abord d'exécuter une instruction FLUSH TABLES si le serveur est en cours d'exécution.

myisam_ftdump analyse et décharge l'intégralité de l'index, ce qui n'est pas particulièrement rapide. D'un autre côté, la distribution des mots change rarement, il n'est donc pas nécessaire de l'exécuter souvent.

Invoquez myisam_ftdump comme suit :

shell> myisam_ftdump [options] nom_table num_index

L'argument nom_table doit être le nom d'une table MyISAM. Vous pouvez également spécifier une table en nommant son fichier d'index (le fichier avec le suffixe .MYI). Si vous n'invoquez pas myisam_ftdump dans le répertoire où se trouvent les fichiers de table, le nom de la table ou du fichier d'index doit être précédé du chemin d'accès au répertoire de la base de données de la table. Les numéros d'index commencent à 0.

Exemple : Supposons que la base de données test contienne une table nommée mytexttablel qui a la définition suivante :

CREATE TABLE mytexttable
(
  id   INT NOT NULL,
  txt  TEXT NOT NULL,
  PRIMARY KEY (id),
  FULLTEXT (txt)
);

L'index sur id est l'index 0 et l'index FULLTEXT sur txt est l'index 1. Si votre répertoire de travail est le répertoire de la base de données test, invoquez myisam_ftdump comme suit :

shell> myisam_ftdump mytexttable 1

Si le chemin d'accès au répertoire de la base de données test est /usr/local/mysql/data/test, vous pouvez également spécifier l'argument nom_table en utilisant ce chemin d'accès. Ceci est utile si vous n'invoquez pas myisam_ftdump dans le répertoire de la base de données :

shell> myisam_ftdump /usr/local/mysql/data/test/mytexttable 1

Vous pouvez utiliser myisam_ftdump pour générer une liste des entrées d'index par ordre de fréquence d'apparition comme ceci :

shell> myisam_ftdump -c mytexttable 1 | sort -r

myisam_ftdump prend en charge les options suivantes :

•--help, -h -?

Affiche un message d'aide et quitte.

•--count, -c

Calcule les statistiques par mot (comptes et poids globaux).

•--dump, -d

Décharge l'index, y compris les décalages de données et les poids des mots.

•--length, -l

Rapport sur la distribution de la longueur.

•--stats, -s

Rapport sur les statistiques globales de l'index. C'est l'opération par défaut si aucune autre opération n'est spécifiée.

•--verbose, -v

Mode verbeux. Affiche plus d'informations sur ce que fait le programme.
