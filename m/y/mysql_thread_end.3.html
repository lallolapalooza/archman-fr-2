Nom

mysql_thread_end - Libère la mémoire spécifique au thread

Synopsis

#include <mysql.h>
void mysql_thread_end(void );

Description

La fonction mysql_thread_end() doit être appelée avant qu'un thread client ne se termine. Elle libère la mémoire spécifique au thread, qui a été allouée par un appel précédent à mysql_thread_init(3). Renvoie void.

Notes

Contrairement à mysql_thread_init(3), mysql_thread_end() ne sera pas invoquée automatiquement si le thread se termine. Pour éviter les fuites de mémoire, mysql_thread_end() doit être appelée explicitement.

Historique

Cette fonction est obsolète depuis MariaDB Connector/C 3.0.0.
