mysql_get_ssl_cipher(3) MariaDB Connector/C mysql_get_ssl_cipher(3)

Nom

mysql_get_ssl_cipher - renvoie le jeu de chiffrements utilisé

Synopsis

#include <mysql.h>
const char *mysql_get_ssl_cipher(MYSQL *mysql)

Description

Retourne le nom du jeu de chiffrements actuellement utilisé pour la connexion sécurisée, ou NULL pour les connexions non TLS.

Paramètre

•
mysql - un identifiant de connexion, qui a été préalablement alloué par mysql_init(3) et connecté par mysql_real_connect(3).

Notes

•
Pour utiliser mysql_get_ssl_cipher(), MariaDB Connector/C doit être compilé avec le support TLS/SSL, sinon la fonction retournera NULL.
•
`mysql_get_ssl_cipher()’ peut être utilisé pour déterminer si la connexion client-serveur est sécurisée.
•
Selon la bibliothèque TLS utilisée (OpenSSL, GnuTLS ou Windows Schannel), le nom des jeux de chiffrements peut différer. Par exemple, le jeu de chiffrements 0x002F (TLS_RSA_WITH_AES_128_CBC_SHA) a différents noms : AES128-SHA pour OpenSSL et Schannel, et TLS_RSA_AES_128_CBC_SHA1 pour GnuTLS.

Valeur de retour

Retourne une chaîne terminée par un zéro contenant le jeu de chiffrements utilisé pour une connexion sécurisée, ou NULL si la connexion n’utilise pas TLS/SSL.
