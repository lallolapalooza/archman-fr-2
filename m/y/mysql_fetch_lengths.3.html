Nom

mysql_fetch_lengths - retourne un tableau des valeurs de longueur pour la ligne courante

Synopsis

#include <mysql.h>
unsigned long * mysql_fetch_lengths(MYSQL_RES * result);

Description

La fonction mysql_fetch_lengths() retourne un tableau contenant les longueurs de chaque colonne de la ligne courante dans l'ensemble de résultats (sans inclure le caractère nul de terminaison) ou NULL si une erreur s'est produite.

Paramètre

•
result - un identifiant d'ensemble de résultats retourné par mysql_store_result(3) ou mysql_use_result(3). ### Notes mysql_fetch_lengths() n'est valide que pour la ligne courante de l'ensemble de résultats. Elle retourne NULL si vous l'appelez avant d'appeler mysql_fetch_row(3) ou après avoir récupéré toutes les lignes de l'ensemble.

Valeur de retour

Un tableau de valeurs `unsigned long`. La taille du tableau peut être déterminée par le nombre de champs dans l'ensemble de résultats courant.
