mysql_thread_init(3) MariaDB Connector/C mysql_thread_init(3)

Nom

mysql_thread_init - initialiser un thread

Synopsis

#include <mysql.h>
my_bool mysql_thread_init(void );

Description

Initialisation du thread pour les clients multithreadés. Les clients multithreadés doivent appeler mysql_thread_init() au début de l'initialisation du thread pour initialiser les variables spécifiques à la bibliothèque cliente du thread. Si mysql_thread_init() n'a pas été appelé explicitement, il sera appelé automatiquement par mysql_init(3) ou mysql_real_connect(3).

Notes

Avant qu'un thread client ne se termine, la fonction mysql_thread_end(3) doit être appelée pour libérer la mémoire - sinon, la bibliothèque cliente signalera une erreur.

Valeur de retour

Retourne zéro en cas de succès ou 1 si une erreur s'est produite.

Historique

Cette fonction est dépréciée depuis MariaDB Connector/C 3.0.0.
