NOM

myisamlog - afficher le contenu d'un fichier journal MyISAM

SYNTAXE

myisamlog [options] [fichier_journal [nom_tbl] ...]

DESCRIPTION

myisamlog traite le contenu d'un fichier journal MyISAM.

Exécutez myisamlog comme suit :

shell> myisamlog [options] [fichier_journal [nom_tbl] ...]
shell> isamlog [options] [fichier_journal [nom_tbl] ...]

L'opération par défaut est la mise à jour (-u). Si une récupération est effectuée (-r), toutes les écritures et éventuellement les mises à jour et suppressions sont effectuées et les erreurs sont seulement comptées. Le nom de fichier journal par défaut est myisam.log pour myisamlog et isam.log pour isamlog si aucun argument fichier_journal n'est donné. Si des tables sont nommées sur la ligne de commande, seules ces tables sont mises à jour.

myisamlog prend en charge les options suivantes :

•-?, -I

Affiche un message d'aide et quitte.

•-c N

Exécute seulement N commandes.

•-f N

Spécifie le nombre maximum de fichiers ouverts.

•-i

Affiche des informations supplémentaires avant de quitter.

•-o offset

Spécifie le décalage de départ.

•-p N

Supprime N composants du chemin.

•-r

Effectue une opération de récupération.

•-R fichier_pos_enregist pos_enregist

Spécifie le fichier de position d'enregistrement et la position d'enregistrement.

•-u

Effectue une opération de mise à jour.

•-v

Mode verbeux. Affiche plus de sorties sur ce que fait le programme. Cette option peut être donnée plusieurs fois pour produire de plus en plus de sorties.

•-w fichier_ecriture

Spécifie le fichier d'écriture.

•-V

Affiche les informations de version.
