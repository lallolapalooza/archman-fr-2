MYSQL.SERVER(1) Système de gestion de base de données MariaDB MYSQL.SERVER(1)

NOM

mysql.server - Script de démarrage du serveur MariaDB

SYNTAXE

mysql {start|stop}

DESCRIPTION

Les distributions MariaDB sur Unix incluent un script nommé mysql.server. Il peut être utilisé sur des systèmes tels que Linux et Solaris qui utilisent des répertoires de démarrage de style System V pour démarrer et arrêter les services système. Il est également utilisé par l'élément de démarrage de Mac OS X pour MariaDB.

mysql.server peut être trouvé dans le répertoire support-files sous votre répertoire d'installation MariaDB ou dans une distribution source de MariaDB.

Si vous utilisez le paquet RPM du serveur Linux (MySQL-server-VERSION.rpm), le script mysql.server sera installé dans le répertoire /etc/init.d sous le nom mysql. Vous n'avez pas besoin de l'installer manuellement.

Certains fournisseurs fournissent des paquets RPM qui installent un script de démarrage sous un nom différent, tel que mariadbd.

Si vous installez MariaDB à partir d'une distribution source ou en utilisant un format de distribution binaire qui n'installe pas mysql.server automatiquement, vous pouvez l'installer manuellement.

mysql.server lit les options des sections [mysql.server] et [mariadbd] des fichiers d'options. Pour la compatibilité ascendante, il lit également les sections [mysql_server], bien que vous devriez renommer ces sections en [mysql.server].

mysql.server prend en charge les options suivantes.

•--basedir=chemin

Le chemin vers le répertoire d'installation de MariaDB.

•--datadir=chemin

Le chemin vers le répertoire de données de MariaDB.

•--pid-file=nom_fichier

Le nom du chemin du fichier dans lequel le serveur doit écrire son identifiant de processus. S'il n'est pas fourni, la valeur par défaut, "host_name.pid", est utilisée.

•--service-startup-timeout=nom_fichier

Combien de secondes attendre la confirmation du démarrage du serveur. Si le serveur ne démarre pas dans ce délai, mysql.server se termine avec une erreur. La valeur par défaut est 900. Une valeur de 0 signifie ne pas attendre du tout le démarrage. Les valeurs négatives signifient attendre indéfiniment (pas de délai d'attente).

•--use-mariadbd_safe

Utiliser mariadbd_safe pour démarrer le serveur. C'est la valeur par défaut.

•--use-manager

Utiliser Instance Manager pour démarrer le serveur.

•--user=nom_utilisateur

Le nom d'utilisateur de connexion à utiliser pour exécuter mariadbd.
