NOM

my_print_defaults - affiche les options à partir des fichiers d'options

SYNOPSIS

my_print_defaults [options] groupe_options ...

DESCRIPTION

my_print_defaults affiche les options présentes dans les groupes d'options des fichiers d'options. La sortie indique quelles options seront utilisées par les programmes qui lisent les groupes d'options spécifiés. Par exemple, le programme mariadb-check lit les groupes d'options [mariadb-check] et [client]. Pour voir quelles options sont présentes dans ces groupes dans les fichiers d'options standards, invoquez my_print_defaults comme suit :

shell> my_print_defaults mariadb-check client
--user=myusername
--password=secret
--host=localhost

La sortie se compose d'options, une par ligne, sous la forme où elles seraient spécifiées sur la ligne de commande.

my_print_defaults supporte les options suivantes.

•--help, -?

Affiche un message d'aide et quitte.

• --defaults-file=nom_fichier, -c nom_fichier

Lit uniquement le fichier d'options donné. Si aucune extension n'est fournie, l'extension par défaut (.ini ou .cnf) sera utilisée. Si --defaults-file est la première option, alors il lit uniquement ce fichier, ne lit pas les fichiers de configuration globaux ou par utilisateur ; il doit être la première option.

•--debug=options_debug, -# options_debug

Écrit un journal de débogage. Une chaîne options_debug typique est 'd:t:o,nom_fichier'. La valeur par défaut est 'd:t:o,/tmp/my_print_defaults.trace'.

•--defaults-extra-file=nom_fichier, -e nom_fichier

Lit ce fichier d'options après le fichier d'options global mais (sur Unix) avant le fichier d'options utilisateur. Doit être la première option.

•--defaults-group-suffix=suffixe, -g suffixe

En plus des groupes nommés sur la ligne de commande, lit les groupes qui ont le suffixe donné.

•--mariadbd

Lit le même ensemble de groupes que le binaire mariadbd.

• --mariadb-multi

Lit le même ensemble de groupes que le binaire mariadb-multi.

•--no-defaults, -n

Retourne une chaîne vide (utile pour les scripts).

•--verbose, -v

Mode verbeux. Affiche plus d'informations sur ce que fait le programme.

•--version, -V

Affiche les informations de version et quitte.
