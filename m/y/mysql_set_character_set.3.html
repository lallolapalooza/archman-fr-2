Nom

mysql_set_character_set - Définit le jeu de caractères par défaut pour la connexion

Synopsis

#include <mysql.h>
int mysql_set_character_set(MYSQL * mysql,
                            const char * csname);

Description

Définit le jeu de caractères par défaut pour la connexion actuelle. Retourne zéro en cas de succès, une valeur non nulle en cas d'échec.

Paramètres

•
mysql - un handle mysql, qui a été précédemment alloué par mysql_init(3) ou mysql_real_connect(3).
•
csname - nom du jeu de caractères ### Notes
•
Il est fortement recommandé d'utiliser mysql_set_character_set() au lieu de SET NAMES ... car mysql_real_escape_string(3) pourrait échouer ou donner des résultats inattendus.

Valeur de retour

Zéro en cas de succès, une valeur non nulle si une erreur s'est produite.
