Nom

mysql_warning_count - Renvoie le nombre d'avertissements

Synopsis

#include <mysql.h>
unsigned int mysql_warning_count(MYSQL * mysql);

Description

Renvoie le nombre d'avertissements de la dernière requête exécutée, ou zéro s'il n'y a pas d'avertissements.

Paramètre

•
mysql - un descripteur mysql, qui a été précédemment alloué par mysql_init(3) et connecté par mysql_real_connect(3).

Notes

•
Pour récupérer les messages d'avertissement, vous devriez utiliser la commande SQL SHOW WARNINGS.
•
Si le mode SQL TRADITIONAL est activé, une erreur au lieu d'un avertissement sera retournée. Pour des informations détaillées, consultez la documentation du serveur.

Valeur de retour

Renvoie le nombre d'avertissements
