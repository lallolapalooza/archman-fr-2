NOM

mympd-config - outil de configuration de myMPD

SYNTAXE

mympd-config [-b </usr/bin/mympd>] [-c </var/lib/mympd/config>] [-s <0|1>] [PARAMÈTRE VALEUR ...]

DESCRIPTION

mympd-config est un petit outil en ligne de commande pour configurer les paramètres de base de myMPD.

OPTIONS

-b <//usr/bin/mympd>
Définit le chemin vers l'exécutable myMPD.
-c </var/lib/mympd/config>
Définit le chemin vers le répertoire de configuration de myMPD.
-s <0|1>
0 = myMPD s'exécute avec un compte utilisateur Linux normal. 1 = myMPD est démarré avec un utilisateur privé systemd.
PARAMÈTRE VALEUR
Les paramètres valides sont les variables d'environnement respectées par "mympd -c".

Référence: https://jcorporation.github.io/myMPD/configuration/configuration-files
