MARIADB-SHOW(1) Système de gestion de base de données MariaDB MARIADB-SHOW(1)

NOM

mariadb-show - affiche des informations sur les bases de données, les tables et les colonnes (mariadb-show est maintenant un lien symbolique vers mariadb-show)

SYNTAXE

mariadb-show [options] [nom_base_de_donnees [nom_table [nom_colonne]]]

DESCRIPTION

Le client mariadb-show peut être utilisé pour voir rapidement quelles bases de données existent, leurs tables, ou les colonnes ou index d'une table.

mariadb-show fournit une interface en ligne de commande pour plusieurs instructions SQL SHOW. Les mêmes informations peuvent être obtenues en utilisant ces instructions directement. Par exemple, vous pouvez les exécuter depuis le programme client mariadb.

Appelez mariadb-show comme ceci :

shell> mariadb-show [options] [nom_base_de_donnees [nom_table [nom_colonne]]]
•Si aucune base de données n'est donnée, une liste des noms de bases de données est affichée.
•Si aucune table n'est donnée, toutes les tables correspondantes dans la base de données sont affichées.
•Si aucune colonne n'est donnée, toutes les colonnes et types de colonnes correspondants dans la table sont affichés.

La sortie n'affiche que les noms des bases de données, tables ou colonnes pour lesquels vous avez des privilèges.

Si le dernier argument contient des caractères génériques shell ou SQL (« * », « ? », « % » ou « _ »), seuls les noms correspondant au caractère générique sont affichés. Si un nom de base de données contient des underscores, ceux-ci doivent être échappés avec une barre oblique inverse (certains shells Unix en nécessitent deux) pour obtenir une liste correcte des tables ou colonnes. Les caractères « * » et « ? » sont convertis en caractères génériques SQL « % » et « _ ». Cela peut prêter à confusion lorsque vous essayez d'afficher les colonnes d'une table dont le nom contient un « _ », car dans ce cas, mariadb-show n'affiche que les noms de tables correspondant au modèle. Ceci est facilement résolu en ajoutant un « % » supplémentaire à la fin de la ligne de commande comme argument séparé.

mariadb-show prend en charge les options suivantes, qui peuvent être spécifiées sur la ligne de commande ou dans les groupes de fichiers d'options [mariadb-show] et [client]. mariadb-show prend également en charge les options de traitement des fichiers d'options décrites.

•--help, -?

Affiche un message d'aide et quitte.

•--character-sets-dir=chemin, -c chemin

Le répertoire où sont installés les jeux de caractères.

•--compress, -C

Compresse toutes les informations envoyées entre le client et le serveur si les deux prennent en charge la compression.

•--count

Affiche le nombre de lignes par table. Cela peut être lent pour les tables autres que MyISAM.

•--debug[=options_debug], -# [options_debug]

Écrit un journal de débogage. Une chaîne typique options_debug est 'd:t:o,nom_fichier'. La valeur par défaut est 'd:t:o'.

•--debug-check

Affiche des informations de débogage lors de la sortie du programme.

•--debug-info

Affiche des informations de débogage ainsi que des statistiques sur l'utilisation de la mémoire et du CPU lors de la sortie du programme.

•--default-auth=nom

Plugin client d'authentification par défaut à utiliser.

•--default-character-set=nom_jeu_caracteres

Utilise nom_jeu_caracteres comme jeu de caractères par défaut.

•--defaults-extra-file=nom_fichier

Définit nom_fichier comme fichier à lire pour les options par défaut après la lecture des fichiers de configuration globaux. Doit être spécifié comme première option.

•--defaults-file=nom_fichier

Définit nom_fichier comme fichier à lire pour les options par défaut, remplaçant les fichiers de configuration globaux. Doit être spécifié comme première option.

•--defaults-group-suffix=suffixe

En plus des groupes nommés sur la ligne de commande, lit les groupes qui ont le suffixe donné.

•--host=nom_hote, -h nom_hote

Se connecte au serveur MariaDB sur l'hôte donné.

•--keys, -k

Affiche les index de table.

•--no-defaults

Ne lit pas les options par défaut dans aucun fichier d'options. Doit être spécifié comme premier argument.

•--password[=mot_de_passe], -p[mot_de_passe]

Le mot de passe à utiliser lors de la connexion au serveur. Si vous utilisez la forme courte de l'option (-p), vous ne pouvez pas mettre d'espace entre l'option et le mot de passe. Si vous omettez la valeur mot_de_passe après l'option --password ou -p sur la ligne de commande, mariadb-show vous la demandera.

Spécifier un mot de passe sur la ligne de commande doit être considéré comme non sécurisé. Vous pouvez utiliser un fichier d'options pour éviter de donner le mot de passe sur la ligne de commande.

•--pipe, -W

Sous Windows, se connecte au serveur via un pipe nommé. Cette option ne s'applique que si le serveur prend en charge les connexions par pipe nommé.

•--plugin-dir=nom_repertoire

Répertoire pour les plugins côté client.

•--port=num_port, -P num_port

Le numéro de port TCP/IP à utiliser pour la connexion. Force --protocol=tcp lorsqu'il est spécifié sur la ligne de commande sans autres propriétés de connexion.

•--protocol={TCP|SOCKET|PIPE|MEMORY}

Le protocole de connexion à utiliser pour se connecter au serveur. Il est utile lorsque les autres paramètres de connexion provoqueraient normalement un protocole autre que celui souhaité.

•--print-defaults

Affiche la liste des arguments du programme et quitte. Doit être spécifié comme premier argument.

•--show-table-type, -t

Affiche une colonne indiquant le type de table, comme dans SHOW FULL TABLES. Le type est BASE TABLE ou VIEW.

•--socket=chemin, -S chemin

Pour les connexions à localhost, le fichier socket Unix à utiliser, ou, sous Windows, le nom du pipe nommé à utiliser. Force --protocol=socket lorsqu'il est spécifié sur la ligne de commande sans autres propriétés de connexion ; sous Windows, force --protocol=pipe.

•--ssl

Active le SSL pour la connexion (activé automatiquement avec d'autres indicateurs). Désactive avec --skip-ssl.

•--ssl-ca=nom

Fichier CA au format PEM (consultez la documentation OpenSSL, implique --ssl).

•--ssl-capath=nom

Répertoire CA (consultez la documentation OpenSSL, implique --ssl).

•--ssl-cert=nom

Certificat X509 au format PEM (consultez la documentation OpenSSL, implique --ssl).

•--ssl-cipher=nom

Chiffrement SSL à utiliser (consultez la documentation OpenSSL, implique --ssl).

•--ssl-key=nom

Clé X509 au format PEM (consultez la documentation OpenSSL, implique --ssl).

•--ssl-crl=nom

Liste de révocation de certificats (consultez la documentation OpenSSL, implique --ssl).

•--ssl-crlpath=nom

Chemin de la liste de révocation de certificats (consultez la documentation OpenSSL, implique --ssl).

•--ssl-verify-server-cert

Vérifie le "Common Name" du serveur dans son certificat par rapport au nom d'hôte utilisé lors de la connexion. Cette option est désactivée par défaut.

•--status, -i

Affiche des informations supplémentaires sur chaque table.

•--user=nom_utilisateur, -u nom_utilisateur

Le nom d'utilisateur MariaDB à utiliser lors de la connexion au serveur.

•--verbose, -v

Mode verbeux.

mysqlshow(1) — MariaDB documentation

NAME

mysqlshow — display database, table, and column information

SYNOPSIS

mysqlshow [options] [db_name [tbl_name [col_name]]]

DESCRIPTION

mysqlshow is a client program that displays information about the databases, tables, and columns that a MySQL server maintains.

The program can be used to display information at three levels of granularity:

•Databases: If invoked without arguments, mysqlshow displays a list of databases that you are permitted to access.

•Tables: If you specify a database name, mysqlshow lists the tables in that database.

•Columns: If you specify both a database name and a table name, mysqlshow lists the columns in that table.

•Column Information: If you specify a database name, table name, and column name, mysqlshow displays information about that specific column, including its type, whether it can be `NULL`, whether it is a key, default values, and any extra information (such as auto_increment).

mysqlshow accepts the same command-line options as the mysql client program.

Some of the most commonly used options are:

•--help, -?

Display help information and exit.

•--host=host_name, -h host_name

Use the given host name for connecting.

•--password=password, -p[password]

Password to use when connecting to the server. If password is not given directly following the option, it is prompted for.

•--port=port_num, -P port_num

Use the given TCP/IP port number when connecting.

•--protocol=protocol

The connection protocol to use (e.g. TCP, SOCKET, PIPE, MEMORY).

•--user=user_name, -u user_name

User name with which to log in.

•--verbose, -v

Print more information about what the program does. This option can be used multiple times to increase the amount of information.

•--version, -V

Display version information and exit.
