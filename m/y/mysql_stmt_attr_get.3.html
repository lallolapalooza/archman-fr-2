mysql_stmt_attr_get(3) MariaDB Connector/C mysql_stmt_attr_get(3)

Nom

mysql_stmt_attr_get - Obtient la valeur actuelle d'un attribut de requête préparée

Synopsis

#include <mysql.h>
my_bool mysql_stmt_attr_get(MYSQL_STMT * stmt,
                            enum enum_stmt_attr_type,
                            void * attr);

Description

Obtient la valeur actuelle d'un attribut de requête préparée. Retourne zéro en cas de succès, une valeur non nulle en cas d'échec.

Paramètre

•
stmt - un descripteur de requête préparée, qui a été précédemment alloué par mysql_stmt_init(3).
•
enum_stmt_attr_type - l'attribut. Voir ci-dessous.
•
attr - un pointeur vers une variable qui contiendra la valeur de l'attribut.

Types d'attributs

Le paramètre enum_stmt_attr_type peut prendre les valeurs suivantes :

Valeur Type Description
STMT_ATTR_UPDATE_MAX_LENGTH my_bool * Indique si mysql_stmt_store_result(3) mettra à jour la valeur max_length des structures MYSQL_FIELD.
STMT_ATTR_CURSOR_TYPE unsigned long * Les valeurs possibles sont CURSOR_TYPE_READ_ONLY ou la valeur par défaut CURSOR_TYPE_NO_CURSOR.
STMT_ATTR_PREFETCH_ROWS unsigned long * Nombre de lignes qui seront préchargées. La valeur par défaut est 1.
STMT_ATTR_PREBIND_PARAMS unsigned int * Nombre de paramètres utilisés pour mariadb_stmt_execute_direct(3)
STMT_ATTR_STATE enum mysql_stmt_state * État de la requête préparée. Les valeurs possibles sont définies dans enum mysql_stmt_state. Cette option a été ajoutée dans MariaDB Connector/C 3.1.0.

Notes

•
La définition du nombre de lignes préchargées ne fonctionnera que pour les curseurs en lecture seule.
