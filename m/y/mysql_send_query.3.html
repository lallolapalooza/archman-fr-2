Nom

mysql_send_query - envoie une requête SQL sans attendre la réponse du serveur

Synopsis

#include <mysql.h>
int mysql_send_query(MYSQL * mysql,
                     const char *query,
                     unsigned long length);

Description

Envoie une instruction au serveur, sans attendre le paquet OK du serveur et/ou le jeu de résultats.

Paramètres

•
mysql - un descripteur mysql, préalablement alloué par mysql_init(3) et connecté par mysql_real_connect(3).
•
query - l'instruction SQL
•
length - la longueur de l'instruction SQL

Notes

•
Le paquet OK et le jeu de résultats doivent être récupérés par la fonction mysql_read_query_result(3).
•
mysql_send_query() peut être utilisé pour une opération semi-asynchrone. Bien que la fonction elle-même soit bloquante, une application pilotée par événements peut effectuer d'autres tâches jusqu'à ce que le jeu de résultats soit disponible.

Exemple

Pour un exemple sur la façon d'utiliser ’mysql_send_query()` dans un modèle piloté par événements, veuillez consulter l'article de Jan Kneschke “Async MySQL Queries with C-API”.
