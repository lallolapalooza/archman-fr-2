MARIADB-FIND-ROWS(1) Système de base de données MariaDB MARIADB-FIND-ROWS(1)

NOM

mariadb-find-rows - extraire des instructions SQL à partir de fichiers (mariadb-find-rows est maintenant un lien symbolique vers mariadb-find-rows)

SYNOPIS

mariadb-find-rows [options] [nom_fichier ...]

DESCRIPTION

mariadb-find-rows lit des fichiers contenant des instructions SQL et extrait les instructions qui correspondent à une expression régulière donnée ou qui contiennent USE db_name ou des instructions SET. L'utilitaire a été écrit pour être utilisé avec des fichiers journaux de mise à jour (tels qu'utilisés avant MySQL 5.0) et, à ce titre, s'attend à ce que les instructions soient terminées par des points-virgules (;). Il peut être utile avec d'autres fichiers contenant des instructions SQL tant que ces instructions sont terminées par des points-virgules.

Appelez mariadb-find-rows comme suit :

shell> mariadb-find-rows [options] [nom_fichier ...]

Chaque argument nom_fichier doit être le nom d'un fichier contenant des instructions SQL. Si aucun nom de fichier n'est donné, mariadb-find-rows lit l'entrée standard.

Exemples :

mariadb-find-rows --regexp=problem_table --rows=20 < update.log
mariadb-find-rows --regexp=problem_table  update-log.1 update-log.2

mariadb-find-rows prend en charge les options suivantes :

•--help, --Information

Affiche un message d'aide et quitte.

•--regexp=motif

Affiche les requêtes qui correspondent au motif.

•--rows=N

Quitte après avoir affiché N requêtes.

•--skip-use-db

N'inclut pas les instructions USE db_name dans la sortie.

•--start_row=N

Commence la sortie à partir de cette ligne.
