Nom

mysql_stmt_fetch_column - Récupère une seule colonne dans un tampon de liaison

Synopsis

#include <mysql.h>
int mysql_stmt_fetch_column(MYSQL_STMT * stmt,
                            MYSQL_BIND * bind_arg,
                            unsigned int column,
                            unsigned long offset);

Description

Cette fonction peut être utilisée pour récupérer de grandes données d'une seule colonne par morceaux.

Paramètres

•
stmt - un descripteur d'instruction, qui a été précédemment alloué par mysql_stmt_init(3).
•
bind_arg - un pointeur vers une structure MYSQL_BIND.
•
column - le numéro de colonne, la première colonne est numérotée zéro.
•
offset - le décalage à partir duquel commencer la récupération des données.

Valeur de retour

Retourne zéro en cas de succès, une valeur non nulle en cas d'échec.

Notes

•
La taille du tampon est spécifiée dans la structure MYSQL_BIND.
