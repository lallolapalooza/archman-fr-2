NOM

mygpo-bpsync - Synchronise les abonnements BashPodder avec gpodder.net

SYNTAXE

mygpo-bpsync (put|get) [device-id]

DESCRIPTION

bpsync est une application client simple pour gpodder.net permettant de synchroniser une liste d'abonnements BashPodder (http://lincgeek.org/bashpodder/) depuis et vers le service web. Comme BashPodder utilise un format de liste d'abonnements simple avec une seule URL par ligne, ce script peut également être utilisé avec d'autres applications (ou simplement pour sauvegarder les URLs d'abonnement de gpodder.net sous forme de fichier texte brut).

Si vous avez ajouté un abonnement sur gpodder.net, vous pouvez utiliser la sous-commande get pour écraser la liste d'abonnements locale avec la liste stockée sur gpodder.net. Si vous avez ajouté un abonnement localement, vous pouvez utiliser la sous-commande put pour écraser la liste sur gpodder.net avec la liste stockée dans la liste d'abonnements BashPodder.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes doivent être définies pour que mygpo-bpsync fonctionne :

MYGPO_USERNAME

Nom d'utilisateur pour le service web

MYGPO_PASSWORD

Mot de passe pour le service web

Les variables d'environnement suivantes sont facultatives :

BPSYNC_BP_CONF

Chemin vers votre fichier bp.conf (par défaut : bp.conf)

MYGPO_HOSTNAME

Hôte ou URL du service web à utiliser (par défaut : http://gpodder.net)

EXEMPLES

mygpo-bpsync put

Téléverse bp.conf en tant que périphérique « bp »

mygpo-bpsync get

Télécharge les abonnements pour le périphérique « bp »

mygpo-bpsync get mydev

Télécharge les abonnements pour le périphérique « mydev »
