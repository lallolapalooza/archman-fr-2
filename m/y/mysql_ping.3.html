mysql_ping(3) MariaDB Connector/C mysql_ping(3)

Nom

mysql_ping - vérifie si la connexion entre le client et le serveur fonctionne

Synopsis

#include <mysql.h>
int mysql_ping(MYSQL * mysql);

Description

Vérifie si la connexion au serveur fonctionne. Si elle s'est perdue, et que l'option globale `reconnect` est activée, une tentative de reconnexion automatique est effectuée.

Cette fonction peut être utilisée par les clients qui restent inactifs pendant une longue période, pour vérifier si le serveur a fermé la connexion et pour la rétablir si nécessaire.

Paramètres

•
mysql - un descripteur mysql, qui a été précédemment alloué par mysql_init(3) et connecté par mysql_real_connect(3). ### Notes
•
Si une reconnexion s'est produite, l'ID du thread (`thread_id`) changera. De plus, les ressources liées à la connexion (instructions préparées, verrous, tables temporaires, ...) seront libérées.

Valeur de retour

Retourne zéro en cas de succès, une valeur non nulle si une erreur s'est produite.
