Nom

mysql_stmt_errno - Renvoie le code d'erreur pour la dernière erreur de requête préparée

Synopsis

#include <mysql.h>
unsigned int mysql_stmt_errno(MYSQL_STMT * stmt);

Description

Renvoie le code d'erreur pour la dernière fonction de requête préparée appelée qui peut réussir ou échouer.

Paramètre

•
stmt - un descripteur de requête préparée, qui a été précédemment alloué par mysql_stmt_init(3).

Valeur de retour

Renvoie le code d'erreur. Une valeur de zéro signifie qu'aucune erreur ne s'est produite.

Notes

•
Les messages d'erreur client sont listés dans le fichier d'en-tête errmsg.h, les messages d'erreur serveur sont listés dans le fichier d'en-tête mysqld_error.h de la distribution source du serveur.
