Nom

mysql_stmt_num_rows - Retourne le nombre de lignes dans le résultat d'une instruction préparée

Synopsis

#include <mysql.h>
unsigned long long mysql_stmt_num_rows(MYSQL_STMT * stmt);

Description

Retourne le nombre de lignes dans le jeu de résultats. L'utilisation de mysql_stmt_num_rows() dépend de l'utilisation ou non de mysql_stmt_store_result(3) pour mettre en tampon l'ensemble du jeu de résultats dans le descripteur d'instruction.

Paramètre

•
stmt - un descripteur d'instruction, qui a été précédemment alloué par mysql_stmt_init(3).

Valeur de retour

Nombre de lignes dans le jeu de résultats.

Notes

•
Si vous utilisez mysql_stmt_store_result(3), mysql_stmt_num_rows() peut être appelé immédiatement.
