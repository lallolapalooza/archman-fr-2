mysql_optionsv(3) MariaDB Connector/C mysql_optionsv(3)

Nom

mysql_optionsv - Utilisé pour définir des options de connexion supplémentaires et affecter le comportement d'une connexion

Synopsis

#include <mysql.h>
int mysql_optionsv(MYSQL * mysql,
                   enum mysql_option,
                   const void * arg,
                   ...);

Description

Utilisé pour définir des options de connexion supplémentaires et affecter le comportement d'une connexion. Cette fonction peut être appelée plusieurs fois pour définir plusieurs options. mysql_optionsv() doit être appelée après mysql_init(3).

Options

•
MYSQL_OPT_SSL_ENFORCE

Active ou désactive TLS. Cette option peut être utilisée pour activer TLS sans avoir à fournir de certificats, clés ou CA TLS.

Note : actuellement, cela n'impose pas TLS comme le suggérerait le nom de l'option. Si le serveur ne prend pas en charge TLS, le protocole reviendra à une communication non chiffrée. Pour forcer l'utilisation de TLS, utilisez plutôt MYSQL_OPT_SSL_VERIFY_SERVER_CERT.

•
MYSQL_INIT_COMMAND

Commande(s) qui sera(ont) exécutée(s) lors de la connexion et de la reconnexion au serveur.

•
MYSQL_OPT_COMPRESS

Utilise le protocole compressé pour la communication client-serveur. Si le serveur ne prend pas en charge le protocole compressé, le protocole par défaut sera utilisé.

•
MYSQL_OPT_CONNECT_TIMEOUT

Délai d'attente de connexion en secondes. Cette valeur sera passée comme paramètre unsigned ##int##.

•
MYSQL_OPT_LOCAL_INFILE

Active ou désactive l'utilisation de LOAD DATA LOCAL INFILE

•
MYSQL_OPT_NAMED_PIPE

Pour les systèmes d'exploitation Windows uniquement : utilise des tubes nommés pour la communication client/serveur.

•
MYSQL_PROGRESS_CALLBACK

Spécifie une fonction de rappel qui pourra visualiser la progression de certaines instructions longues (par exemple, LOAD DATA LOCAL INFILE ou ALTER TABLE). La fonction de rappel doit être définie comme suit :

static void report_progress(const MYSQL *mysql __attribute__((unused)),
                            uint stage, uint max_stage,
                            double progress __attribute__((unused)),
                            const char *proc_info __attribute__((unused)),
                            uint proc_info_length __attribute__((unused)))
•
MYSQL_OPT_PROTOCOL

Spécifie le type de protocole client/serveur. Les valeurs possibles sont : MYSQL_PROTOCOL_TCP, MYSQL_PROTOCOL_SOCKET, MYSQL_PROTOCOL_PIPE et MYSQL_PROTOCOL_MEMORY.

•
MYSQL_OPT_RECONNECT

Active ou désactive la reconnexion automatique.

•
MYSQL_OPT_READ_TIMEOUT

Spécifie le délai d'attente en secondes pour la lecture des paquets du serveur.

•
MYSQL_OPT_WRITE_TIMEOUT

Spécifie le délai d'attente en secondes pour l'envoi des paquets au serveur.

•
MYSQL_READ_DEFAULT_FILE

Lit les options à partir du fichier de configuration spécifié. Si une chaîne vide est passée, les fichiers de configuration par défaut (tels que /etc/my.cnf, /etc/mysql/my.cnf) seront lus. Par défaut, les fichiers de configuration ne sont pas traités à moins que cette option ne soit spécifiée.

•
MYSQL_READ_DEFAULT_GROUP Lit les options à partir du groupe spécifié dans le fichier de configuration par défaut ou le fichier spécifié par MYSQL_READ_DEFAULT_FILE. Passer une chaîne vide entraînera le traitement de toutes les sections. Si aucun fichier spécifique n'est fourni via MYSQL_READ_DEFAULT_FILE, tous les fichiers de configuration par défaut disponibles seront pris en compte.

Note: En plus du groupe spécifié, les groupes suivants seront toujours traités :

•
[client]
•
[client-server]
•
[client-mariadb]
•
MYSQL_REPORT_DATA_TRUNCATION

Active ou désactive le signalement des erreurs de troncature de données pour les instructions préparées.

•
MYSQL_OPT_BIND

Spécifie l'interface réseau à partir de laquelle se connecter au serveur MariaDB.

•
MYSQL_PLUGIN_DIR

Spécifie l'emplacement des plugins client.

•
MYSQL_OPT_NONBLOCK

Spécifie la taille de la pile pour les opérations non bloquantes. L'argument pour MYSQL_OPT_NONBLOCK est la taille de la pile utilisée pour sauvegarder l'état d'une opération non bloquante pendant qu'elle attend l'E/S et que l'application effectue d'autres traitements. Normalement, les applications n'auront pas à changer cela, et il peut être passé à zéro pour utiliser la valeur par défaut.

•

•
MYSQL_OPT_MAX_ALLOWED_PACKET

Longueur maximale du paquet autorisé. La valeur par défaut est 1073741824 (1 Gio) côté client. Si la limite est dépassée par un paquet envoyé par le serveur, une erreur est générée.

•
MARIADB_OPT_CONNECTION_HANDLER

Spécifie le nom d'un plugin de gestionnaire de connexion.

•
MARIADB_OPT_USERDATA

Regroupe des données utilisateur avec la connexion actuelle, par exemple pour une utilisation dans les plugins de gestionnaire de connexion. Cette option nécessite 4 paramètres : connexion, option, clé et valeur :

mysql_optionsv(mysql, MARIADB_OPT_USERDATA, (void *)"ma_cle", (void *)valeur);
•
MARIADB_OPT_CONNECTION_READ_ONLY

Cette option est utilisée par les plugins de gestionnaire de connexion et indique que la connexion actuelle sera utilisée uniquement pour les opérations de lecture.

•
MYSQL_OPT_CAN_HANDLE_EXPIRED_PASSWORDS

Si cette option est définie, le client indique qu'il pourra gérer les mots de passe expirés en définissant le drapeau de capacité CLIENT_CAN_HANDLE_EXPIRED_PASSWORDS. Si le mot de passe a expiré et que CLIENT_CAN_HANDLE_EXPIRED_PASSWORDS est défini, le serveur ne renverra pas d'erreur lors de la connexion, mais mettra la connexion en mode sandbox, où toutes les commandes renverront l'erreur 1820 (ER_MUST_CHANGE_PASSWORD) à moins qu'un nouveau mot de passe n'ait été défini. Cette option a été ajoutée dans MariaDB Connector/C 3.0.4

•
MARIADB_OPT_STATUS_CALLBACK

Spécifie une fonction de rappel qui sera appelée chaque fois que le statut du serveur change ou que le serveur envoie des informations session_track au client :

mysql_optionsv(mysql, MARIADB_OPT_STATUS_CALLBACK, fonction, données)

La fonction de rappel doit être définie comme suit :

    void statut_rappel(void *donnees, enum enum_mariadb_status_info type, ..)

Paramètres :

    - donnees  Pointeur passé avec l'enregistrement de la fonction de rappel
            (généralement un handle de connexion)
    - type  Type d'information  STATUS_TYPE ou SESSION_TRACK_TYPE

Paramètres Variadiques :

 si (type == STATUS_TYPE):
    - statut du serveur (unsigned int)
 if (type == SESSION_TRACK_TYPE)
    - enum enum_session_state_type type_suivi - type de suivi de session
    if (type_suivi == SESSION_TRACK_SYSTEM_VARIABLES)
      - MARIADB_CONST_STRING *cle
      - MARIADB_CONST_STRING *valeur
    else
      - MARIADB_CONST_STRING *valeur

` Note : Spécifier une fonction de rappel écrase la fonction de suivi de session interne, donc les fonctions API mysql_session_track_get_first()/next() ne peuvent pas être utilisées.

Un exemple se trouve dans unittest/libmariadb/connection.c (test_status_callback)

Ajouté dans la version 3.3.2

•
MARIADB_OPT_SKIP_READ_RESPONSE

Ne pas lire les paquets de réponse en protocole binaire.

Ajouté dans la version 3.1.13

Options API de réplication/binlog

•
MARIADB_OPT_RPL_REGISTER_REPLICA

Spécifie le nom d'hôte et le port pour le Binlog/API. Lorsque cette option est définie, rpl_open() enregistrera la réplique avec server_id, hôte et port auprès du serveur connecté. Ces informations peuvent être récupérées par la commande SHOW SLAVE STATUS. Cette option a été ajoutée dans la version 3.3.1

Options TLS/SSL et de sécurité

•
MYSQL_OPT_SSL_KEY

Spécifie le nom d'une clé pour une connexion sécurisée. Si la clé est protégée par une phrase secrète, la phrase secrète doit être spécifiée avec l'option MARIADB_OPT_PASSPHRASE.

•
MYSQL_OPT_SSL_CERT

Spécifie le nom d'un certificat pour une connexion sécurisée.

•
MYSQL_OPT_SSL_CA

Spécifie le nom d'un fichier contenant une ou plusieurs CA de confiance.

•
MYSQL_OPT_SSL_CAPATH

Spécifie le chemin contenant les CA de confiance.

•
MYSQL_OPT_SSL_CIPHER

Spécifie une ou plusieurs suites de chiffrement (SSLv3, TLSv1.0 ou TLSv1.2) pour le chiffrement TLS. Même si Connector/C prend en charge le protocole TLSv1.3, il n'est pas encore possible de spécifier des suites de chiffrement TLSv1.3.

•
MYSQL_OPT_SSL_CRL

Spécifie un fichier contenant une liste de révocation de certificats.

•
MYSQL_OPT_SSL_CRLPATH

Spécifie un répertoire contenant des fichiers avec des listes de révocation de certificats.

•
MARIADB_OPT_SSL_FP

Spécifie l'empreinte digitale du hachage d'un certificat serveur pour la validation pendant la négociation TLS. Pour les versions antérieures à 3.4.0, le hachage est un hachage SHA1, pour les versions 3.4.0 et plus récentes SHA256,SHA384 ou SHA512.

•
MARIADB_OPT_SSL_FP_LIST

Spécifie un fichier contenant une ou plusieurs empreintes digitales de hachage de certificats serveurs pour la validation pendant la négociation TLS. Pour les versions antérieures à 3.4.0, le hachage est un hachage SHA1, pour les versions 3.4.0 et plus récentes SHA256,SHA384 ou SHA512.

•
MARIADB_OPT_SSL_PASSPHRASE

Spécifie une phrase secrète pour une clé client protégée par phrase secrète.

•
MYSQL_OPT_SSL_VERIFY_SERVER_CERT

Active (ou désactive) la vérification du nom d'hôte par rapport au nom commun (CN) du certificat d'hôte du serveur.

•
MYSQL_SERVER_PUBLIC_KEY

Spécifie le nom du fichier contenant la clé publique RSA du serveur de base de données. Le format de ce fichier doit être au format PEM. Cette option est utilisée par le plugin caching_sha2_password et a été ajoutée dans Connector/C 3.1.0

•
MARIADB_OPT_TLS_CIPHER_STRENGTH

Cette option n'est plus utilisée.

•
MARIADB_OPT_RESTRICTED_AUTH

Spécifie un ou plusieurs plugins d'authentification séparés par des virgules qui sont autorisés pour l'authentification. Si le serveur de base de données demande un plugin d'authentification non listé dans cette option, MariaDB Connector/C renverra une erreur. Cette option a été ajoutée dans MariaDB Connector/C 3.3.0

Paramètres du proxy

Conformément à la spécification du protocole proxy, le client qui se connecte peut préfixer son premier paquet avec un en-tête de protocole proxy. Le serveur analysera l'en-tête et supposera que l'adresse IP du client est celle définie dans l'en-tête proxy. * MARIADB_OPT_PROXY_HEADER - spécifie l'en-tête proxy qui sera préfixé au premier paquet. Les paramètres sont void * pour le tampon de préfixe et size_t pour la longueur du tampon :

const char *hdr="PROXY TCP4 192.168.0.1 192.168.0.11 56324 443\r\n";
mysql_optionsv(mysql, MARIADB_OPT_PROXY_HEADER, hdr,  strlen(hdr));

Attributs de connexion

Les attributs de connexion sont stockés dans les tables session_connect_attrs et session_account_connect_attrs du Performance Schema. Par défaut, MariaDB Connector/C envoie les attributs de connexion suivants au serveur : * _client_name : toujours “libmariadb” * _client_version : version de MariaDB Connector/C * _os : système d'exploitation * _pid : identifiant du processus * _platform : par exemple, x86 ou x64 * _server_host : le nom d'hôte (tel que spécifié dans mysql_real_connect). Cet attribut a été ajouté dans Connector/C 3.0.5

Note : Si le Performance Schema est désactivé, les attributs de connexion ne seront pas stockés sur le serveur.

•
MYSQL_OPT_CONNECT_ATTR_DELETE

Supprime un attribut de connexion pour la clé donnée.

•
MYSQL_OPT_CONNECT_ATTR_ADD

Ajoute une paire clé/valeur aux attributs de connexion. La longueur totale des attributs de connexion stockés est limitée à un maximum de 65535 octets.

•
MYSQL_OPT_CONNECT_ATTR_RESET

Efface la liste actuelle des attributs de connexion.
