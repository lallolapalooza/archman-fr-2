mysql_info(3) MariaDB Connector/C mysql_info(3)

Nom

mysql_info - fournit des informations sur la dernière instruction exécutée

Synopsis

#include <mysql.h>
const char * mysql_info(MYSQL * mysql);

Description

La fonction mysql_info() renvoie une chaîne fournissant des informations sur la dernière instruction exécutée.

Paramètre

•
mysql - un identifiant de connexion, qui a été préalablement alloué par mysql_init(3) et connecté par mysql_real_connect(3).

Notes

Les instructions qui n'entrent pas dans l'un des formats précédents ne sont pas prises en charge (par ex. SELECT). Dans ces situations, mysql_info() renverra une chaîne vide.

Valeur de retour

Chaîne d'information terminée par un zéro. Les informations dépendent du type d'instruction :

Type de requête Exemple de chaîne de résultat
INSERT INTO...SELECT... Enregistrements : 100 Doublons : 0 Avertissements : 0
INSERT INTO...VALUES (...),(...),(...) Enregistrements : 3 Doublons : 0 Avertissements : 0
LOAD DATA INFILE Enregistrements : 1 Supprimés : 0 Ignorés : 0 Avertissements : 0
ALTER TABLE ... Enregistrements : 3 Doublons : 0 Avertissements : 0
UPDATE ... Lignes correspondantes : 40 Modifiées : 40 Avertissements : 0
