mysql_stmt_prepare(3) MariaDB Connector/C mysql_stmt_prepare(3)

Nom

mysql_stmt_prepare - Prépare une chaîne SQL

Synopsis

#include <mysql.h>
int mysql_stmt_prepare(MYSQL_STMT * stmt,
                       const char * query,
                       unsigned long length);

Description

Prépare la requête SQL.

Paramètres

•
stmt - un handle de requête, qui a été précédemment alloué par mysql_stmt_init(3).
•
query - instruction SQL
•
length - longueur de l'instruction SQL

Valeur de retour

Zéro en cas de succès, non nul en cas d'erreur.

Notes

•
Les marqueurs de paramètres doivent être liés à des variables d'application à l'aide de mysql_stmt_bind_param(3).
•
Le nombre maximum de paramètres est de 65535 (0xFFFF).
•
Les marqueurs ne sont légaux que dans certains endroits des instructions SQL. Par exemple, ils sont autorisés dans la liste VALUES() d'une instruction INSERT (pour spécifier les valeurs des colonnes pour une ligne), ou dans une comparaison avec une colonne dans une clause [select()](WHERE]] pour spécifier une valeur de comparaison. Cependant, ils ne sont pas autorisés dans les identifiants (tels que les noms de table ou de colonne) dans la liste de sélection qui nomme les colonnes à retourner par une instruction SELECT, ni pour spécifier les deux opérandes d'un opérateur binaire tel que le signe égal. La dernière restriction est nécessaire car il serait impossible de déterminer le type du paramètre. En général, les paramètres ne sont légaux que dans les instructions de langage de manipulation de données (DML), et non dans les instructions de langage de définition de données (DDL).
