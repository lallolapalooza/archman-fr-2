my(n) Commandes TclOO my(n)

NOM

my - invoque n'importe quelle méthode de l'objet courant

SYNTAXE

package require TclOO
my nomMethode ?arg ...?

DESCRIPTION

La commande my est utilisée pour permettre aux méthodes des objets d'invoquer n'importe quelle méthode de l'objet (ou de sa classe). En particulier, l'ensemble des valeurs valides pour nomMethode est l'ensemble de toutes les méthodes supportées par un objet et ses superclasses, y compris celles qui ne sont pas exportées. L'objet sur lequel la méthode est invoquée est toujours celui qui est le contexte courant de la méthode (c'est-à-dire l'objet retourné par self object) à partir de laquelle la commande my est invoquée.

Chaque objet possède sa propre commande my, contenue dans son espace de noms d'instance.

EXEMPLES

Cet exemple montre une utilisation basique de my pour utiliser la méthode variables de la classe oo::object, qui n'est pas visible publiquement par défaut :

oo::class create c {
    method count {} {
        my variable compteur
        puts [incr compteur]
    }
}
c create o
o count              → imprime "1"
o count              → imprime "2"
o count              → imprime "3"
