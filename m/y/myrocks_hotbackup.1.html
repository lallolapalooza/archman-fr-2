NOM

myrocks_hotbackup - sauvegarde en continu pour MariaDB MyRocks

DESCRIPTION

Utilisation :

Sauvegarde : définir -o pipefail ; myrocks_hotbackup --user=root --password=mot_de_passe --port=3306 --checkpoint_dir=<répertoire où les liens symboliques de sauvegarde temporaires sont créés> | ssh -o NoneEnabled=yes serveur_distant 'tar -xi -C <répertoire sur le serveur distant où les sauvegardes seront envoyées>' . Vous devez exécuter la commande de sauvegarde sur un serveur où vous effectuez les sauvegardes.

Sauvegarde utilisant WDT : myrocks_hotbackup --user=root --password=mot_de_passe --stream=wdt --checkpoint_dir=<répertoire où les liens symboliques de sauvegarde temporaires sont créés> --destination=<nom de l'hôte distant> --backup_dir=<nom du répertoire distant>. Ceci doit être exécuté sur l'hôte source.

Déplacer-Sauvegarde : myrocks_hotbackup --move_back --datadir=<datadir mysql de destination> --rocksdb_datadir=<rocksdb datadir de destination> --rocksdb_waldir=<rocksdb wal dir de destination> --backup_dir=<où les fichiers de sauvegarde sont stockés> . Vous devez exécuter la commande move-back sur un serveur où les fichiers de sauvegarde sont envoyés.

OPTIONS

-h, --help
affiche ce message d'aide et quitte
-i INTERVALLE_DE_POINT_DE_CONTRÔLE, --interval=INTERVALLE_DE_POINT_DE_CONTRÔLE
Nombre de secondes pour renouveler le point de contrôle
-c RÉPERTOIRE_DE_POINT_DE_CONTRÔLE, --checkpoint_dir=RÉPERTOIRE_DE_POINT_DE_CONTRÔLE
Nom du répertoire local où les points de contrôle seront créés.
-d DATADIR, --datadir=DATADIR
mode sauvegarde : datadir MySQL source. mode move_back : datadir MySQL de destination
-s FLUX_SORTIE, --stream=FLUX_SORTIE
Paramétrage des options de sauvegarde en continu. Actuellement, tar, WDT et xbstream sont supportés. Par défaut : tar
--destination=DESTINATION
Nom du serveur distant. Utilisé uniquement pour le mode WDT jusqu'à présent.
--avg_mbytes_per_sec=MOYENNE_MO_PAR_SEC
Taux de sauvegarde moyen en Mo/sec. WDT seulement.
--extra_wdt_sender_options=OPTIONS_SUPPLÉMENTAIRES_ENVOYEUR_WDT
Options supplémentaires pour l'envoyeur WDT
--extra_wdt_receiver_options=OPTIONS_SUPPLÉMENTAIRES_RÉCEPTEUR_WDT
Options supplémentaires pour le récepteur WDT
-u UTILISATEUR_MYSQL, --user=UTILISATEUR_MYSQL
Nom d'utilisateur MySQL
-p MOT_DE_PASSE_MYSQL, --password=MOT_DE_PASSE_MYSQL
Nom du mot de passe MySQL
-P PORT_MYSQL, --port=PORT_MYSQL
Numéro de port MySQL
-S SOCKET_MYSQL, --socket=SOCKET_MYSQL
Chemin du socket MySQL. Prend la priorité sur --port.
-m, --move_back
Déplacement des fichiers de sauvegarde MyRocks vers les emplacements appropriés.
-r ROCKSDB_DATADIR, --rocksdb_datadir=ROCKSDB_DATADIR
Répertoire de données cible RocksDB où les fichiers de données de sauvegarde seront déplacés. Doit être vide.
-w ROCKSDB_WALDIR, --rocksdb_waldir=ROCKSDB_WALDIR
Répertoire de données cible RocksDB où les fichiers wal de sauvegarde seront déplacés. Doit être vide.
-b RÉPERTOIRE_SAUVEGARDE, --backup_dir=RÉPERTOIRE_SAUVEGARDE
mode sauvegarde pour WDT : Répertoire distant pour stocker la sauvegarde. mode move_back : Emplacements où les fichiers de sauvegarde sont stockés.
-f, --skip_check_frm_timestamp
saut de la vérification si les fichiers frm sont mis à jour après le début de la sauvegarde.
-D FICHIER_SIGNAL_DEBUG, --debug_signal_file=FICHIER_SIGNAL_DEBUG
à des fins de débogage : attente jusqu'à ce que le fichier spécifié soit créé
