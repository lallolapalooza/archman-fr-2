mysql_sqlstate(3) Connecteur MariaDB/C mysql_sqlstate(3)

Nom

mysql_sqlstate - retourne le code d'erreur SQLSTATE

Synopsis

#include <mysql.h>
const char * mysql_sqlstate(MYSQL * mysql);

Description

Retourne une chaîne contenant le code d'erreur SQLSTATE de la fonction la plus récemment appelée qui peut réussir ou échouer. Le code d'erreur est composé de cinq caractères. `00000' signifie aucune erreur. Les valeurs sont spécifiées par ANSI SQL et ODBC

Paramètre

Notes

Veuillez noter que tous les codes d'erreur de la bibliothèque client ne sont pas mappés aux erreurs SQLSTATE. Les erreurs qui ne peuvent pas être mappées seront retournées avec la valeur HY000.

Valeur de retour

Une chaîne contenant le code d'erreur SQLSTATE.
