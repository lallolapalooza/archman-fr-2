mysql_reset_connection(3) MariaDB Connector/C mysql_reset_connection(3)

Nom

mysql_reset_connection - Réinitialise la connexion et efface l'état de la session

Synopsis

#include <mysql.h>
int mysql_reset_connection(MYSQL * mysql);

Description

Réinitialise la connexion actuelle et efface l'état de la session. Similaire à mysql_change_user(3) ou mariadb_reconnect(3), mysql_reset_connection() réinitialise l'état de la session, mais sans se déconnecter, ouvrir ou réauthentifier.

Côté client, mysql_reset_connection() * efface les ensembles de résultats en attente ou non traités * efface les statuts tels que affected_rows, info ou last_insert_id * invalide les instructions préparées actives

Côté serveur, mysql_reset_connection() * supprime les tables temporaires * annule la transaction active * réinitialise le mode autocommit * libère les verrous de table * initialise les variables de session (et les définit à la valeur des variables globales correspondantes) * ferme les instructions préparées actives * efface les variables utilisateur

Paramètre

•
mysql - un descripteur mysql, qui a été précédemment alloué par mysql_init(3) et connecté par mysql_real_connect(3).

Valeur de retour

Retourne zéro en cas de succès, une valeur non nulle en cas d'erreur.

Historique

Cette fonction a été ajoutée dans MariaDB Connector/C 3.0.0.
