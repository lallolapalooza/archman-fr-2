NOM

mysql2dlf - convertir les fichiers journaux mysql au format dlf

SYNTAXE

mysql2dlf

DESCRIPTION

mysql2dlf convertit un fichier journal de requêtes MySQL au format DLF. Des informations sur MySQL sont disponibles sur http://www.mysql.org/. Le fichier journal de requêtes est défini par l'option --log[=fichier] de mysqld, ou par le réglage log=fichier dans le fichier de configuration MySQL.

Un tel fichier journal ressemble par exemple à ceci :

/usr/sbin/mysqld, Version : 3.23.43-debug-log, démarré avec :
Port TCP : 3306  Socket Unix : /var/run/mysqld/mysqld.sock
Heure                 Id Commande    Argument
011218 15:02:58       1 Connect     root@localhost on
                      1 Query       SHOW VARIABLES LIKE 'pid_file'
                      1 Shutdown
011226 21:35:59       6 Connect     joe@localhost on
                      6 Init DB     nmrshiftdb
                      6 Query       SHOW VARIABLES

ou

    42401 Query       SELECT
    bannerID,
    banner,
    format,
    width,
    height,
    alt,
    url
FROM
    banners
WHERE
    act = 'true'  AND (keyw = 'fullsize' OR keyw = 'global')

Le format générique de base de données dlf est décrit dans database.xml.

EXEMPLES

Pour traiter un journal tel que produit par MySQL :

$ mysql2dlf < mysql-log

mysql2dlf sera rarement utilisé seul, mais sera plus probablement appelé par lr_log2report :

$ lr_log2report mysql < /var/log/mysql-log

NOTES

L'analyseur a été testé pour les fichiers journaux de requêtes pour MySQL 3.23.46 seulement.

BOGUES

Ce convertisseur stocke toutes les informations des fichiers journaux dans un grand tableau imbriqué en mémoire, avant de les écrire. Par conséquent, la consommation de mémoire est linéaire par rapport à la taille du journal.

VOIR AUSSI

mysql(1), mysqld(1)
