Nom

mysql_stmt_send_long_data - Envoie des données par morceaux

Synopsis

#include <mysql.h>
my_bool mysql_stmt_send_long_data(MYSQL_STMT * stmt,
                                  unsigned int,
                                  const char * data,
                                  unsigned long);

Description

Permet d'envoyer des données de paramètres au serveur par morceaux (ou blocs), par exemple si la taille d'un blob dépasse la taille du paquet maximum autorisé (max_allowed_packet). Cette fonction peut être appelée plusieurs fois pour envoyer les parties d'une valeur de données caractère ou binaire pour une colonne, qui doit être l'un des types de données TEXT ou BLOB.

Paramètres

•
stmt - Un descripteur d'instruction, qui a été précédemment alloué par mysql_stmt_init(3).
•
param_no - Indique quel paramètre associer aux données. Les paramètres sont numérotés à partir de 0.
•
data - Un tampon contenant les données à envoyer.
•
long - La taille du tampon de données.

Valeur de retour

Retourne zéro en cas de succès, une valeur non nulle si une erreur s'est produite.

Notes

•
mysql_stmt_send_long_data() doit être appelée avant mysql_stmt_execute(3).
•
Les variables liées pour cette colonne seront ignorées lors de l'appel à mysql_stmt_execute(3).

Voir aussi

•
mysql_stmt_execute(3).
