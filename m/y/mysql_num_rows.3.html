mysql_num_rows(3) MariaDB Connector/C mysql_num_rows(3)

Nom

mysql_num_rows - Renvoie le nombre de lignes dans un jeu de résultats.

Synopsis

#include <mysql.h>
my_ulonglong mysql_num_rows(MYSQL_RES * );

Description

Renvoie le nombre de lignes dans un jeu de résultats.

Paramètres

•
MYSQL_RES - un identifiant de jeu de résultats retourné par mysql_store_result(3) ou mysql_use_result(3). ### Notes Le comportement de mysql_num_rows() dépend de si des jeux de résultats mis en tampon ou non mis en tampon sont utilisés. Pour les jeux de résultats non mis en tampon, mysql_num_rows() ne renverra pas le nombre correct de lignes tant que toutes les lignes du résultat n'auront pas été récupérées.
