mysql_stmt_insert_id(3) MariaDB Connector/C mysql_stmt_insert_id(3)

Nom

mysql_stmt_insert_id - Renvoie l'ID généré automatiquement à partir d'une requête préparée précédemment exécutée.

Synopsis

#include <mysql.h>
my_ulonglong mysql_stmt_insert_id(MYSQL_STMT * stmt);

Description

La fonction mysql_stmt_insert_id() renvoie l'ID généré par une requête préparée sur une table comportant une colonne avec l'attribut AUTO_INCREMENT. ## Paramètre * stmt - un handle de requête, qui a été précédemment alloué par mysql_stmt_init(3). ## Valeur de retour Renvoie l'ID généré automatiquement à partir de la requête préparée précédemment exécutée. Si la dernière requête n'était pas une instruction INSERT ou UPDATE ou si la table modifiée n'a pas de colonne avec l'attribut AUTO_INCREMENT, cette fonction retournera zéro.

Notes

•
Lors de l'exécution d'une requête préparée d'insertion multiple, mysql_stmt_insert_id() renverra la valeur de la première ligne.
