mysql_commit(3) MariaDB Connector/C mysql_commit(3)

Nom

mysql_commit - Valide la transaction courante

Synopsis

#include <mysql.h>
my_bool mysql_commit(MYSQL * mysql);

Description

Valide la transaction courante pour la connexion à la base de données spécifiée. Retourne zéro en cas de succès, une valeur non nulle si une erreur s'est produite.

Paramètres

•
mysql est un identifiant de connexion, précédemment alloué par mysql_init(3) et connecté par mysql_real_connect(3).

Notes

L'exécution de mysql_commit() n'affecte pas le comportement de l'autocommit. Cela signifie que toute instruction UPDATE ou INSERT suivant mysql_commit() sera annulée lors de la fermeture de la connexion.
