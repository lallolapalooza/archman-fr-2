mysql_stmt_error(3) MariaDB Connector/C mysql_stmt_error(3)

Name

mysql_stmt_error - Retourne une description textuelle de la dernière erreur d'instruction

Synopsis

#include <mysql.h>
const char * mysql_stmt_error(MYSQL_STMT * stmt);

Description

Retourne une chaîne contenant le message d'erreur de la dernière fonction d'instruction appelée qui a pu réussir ou échouer. La chaîne sera vide si aucune erreur ne s'est produite.

Paramètre

•
stmt - un descripteur d'instruction, qui a été précédemment alloué par mysql_stmt_init(3).

Valeur de retour

•
Une chaîne décrivant la dernière erreur ou une chaîne vide si aucune erreur ne s'est produite.

Notes

•
Les messages d'erreur du client sont listés dans le fichier d'en-tête errmsg.h, les messages d'erreur du serveur sont listés dans le fichier d'en-tête mysqld_error.h de la distribution source du serveur.
