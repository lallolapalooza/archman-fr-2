Nom

mysql_stmt_next_result - prépare le prochain jeu de résultats d'une instruction préparée

Synopsis

#include <mysql.h>
int mysql_stmt_next_result(MYSQL_STMT * stmt);

Description

Prépare le prochain jeu de résultats d'un appel précédent à mysql_stmt_execute(3) qui peut être récupéré par mysql_stmt_store_result(3).

Paramètre

•
stmt - un handle d'instruction, qui a été précédemment alloué par [mysql_stmt_init()](mysql_stmt_init().]]

Valeur de retour

Retourne zéro en cas de succès, une valeur non nulle si une erreur s'est produite.

Notes

•
La fonction mysql_stmt_more_results(3) indique si d'autres jeux de résultats sont disponibles.
•
Si l'exécution d'une procédure stockée a produit plusieurs jeux de résultats, la valeur de retour de mysql_stmt_errno(3)/error() peut changer et aucun jeu de résultats ne sera disponible.
