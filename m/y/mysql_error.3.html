mysql_error(3) Connecteur MariaDB/C mysql_error(3)

Nom

mysql_error - renvoie le dernier message d'erreur pour l'appel de fonction le plus récent

Synopsis

#include <mysql.h>
const char * mysql_error(MYSQL * mysql);

Description

Renvoie le dernier message d'erreur pour l'appel de fonction le plus récent qui peut réussir ou échouer. Une chaîne vide signifie qu'aucune erreur ne s'est produite.

Paramètre

•
mysql est un identifiant de connexion, qui a été précédemment alloué par mysql_init(3) et connecté par mysql_real_connect(3).

Notes

•
Les codes d'erreur client sont listés dans le fichier d'en-tête errmsg.h, les codes d'erreur serveur sont listés dans le fichier d'en-tête mysqld_error.h de la distribution source du serveur.
•
Les messages d'erreur client peuvent être obtenus en appelant mariadb_get_infov(3) et en passant le paramètre MARIADB_CLIENT_ERRORS
