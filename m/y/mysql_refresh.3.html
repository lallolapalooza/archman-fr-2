Nom

mysql_refresh - vide les informations sur le serveur

Synopsis

#include <mysql.h>
int mysql_refresh(MYSQL * mysql, unsigned int options);

Description

Vide différents types d'informations stockées sur le serveur. Le paramètre options, sous forme de masque de bits, spécifie quel type d'information sera vidé.

Paramètres

•
mysql - un handle mysql, qui a été précédemment alloué par mysql_init(3) et connecté par mysql_real_connect(3).
•
options - un entier composé d'un masque de bits. Voir ci-dessous.

Le paramètre options peut être n'importe quelle combinaison des drapeaux suivants :

Option Description
REFRESH_GRANT Rafraîchir les tables de privilèges.
REFRESH_LOG Vider les logs.
REFRESH_TABLES Vider le cache des tables.
REFRESH_HOSTS Vider le cache des hôtes.
REFRESH_STATUS Réinitialiser les variables d'état.
REFRESH_THREADS Vider le cache des threads.
REFRESH_SLAVE Réinitialiser les informations du serveur maître et redémarrer les esclaves.
REFRESH_MASTER Supprimer les fichiers de logs binaires.

Notes

•
Pour combiner différentes valeurs dans le paramètre options, utilisez l'opérateur OU `|'.
•
mysql_reload() est un alias pour mysql_refresh().

Valeur de retour

Retourne zéro en cas de succès, sinon une valeur non nulle.
