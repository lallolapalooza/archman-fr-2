mysql_server_end(3) Connecteur C MariaDB mysql_server_end(3)

Nom

mysql_server_end - Appelée une fois que vous avez fini d'utiliser le Connecteur C MariaDB

Synopsis

#include <mysql.h>
void mysql_server_end(void)

Description

À appeler une fois que vous avez fini d'utiliser la bibliothèque, par exemple après vous être déconnecté du serveur. Pour un programme client, cela ne fait que nettoyer en effectuant des tâches de gestion de la mémoire.

Notes

•
mysql_library_end() est un alias pour mysql_server_end().
•
Dans les versions 3.0.1 à 3.0.4 du Connecteur C MySQL, il n'était pas possible d'appeler mysql_server_init(3) et mysql_server_end() plusieurs fois.
