mysql_server_init(3) Connecteur/C MariaDB mysql_server_init(3)

Nom

mysql_server_init - Initialise la bibliothèque

Synopsis

#include <mysql.h>
int mysql_library_init(int argc __attribute__((unused)),
                       char **argv __attribute__((unused)),
                       char **groups __attribute__((unused)))

Description

Appelée pour initialiser la bibliothèque avant d'appeler d'autres fonctions.

Paramètres

Tous les paramètres sont inutilisés, ils existent uniquement pour des raisons de compatibilité.

Notes

•
Appelez mysql_server_end(3) pour nettoyer après l'achèvement.
•
Si la bibliothèque n'a pas été explicitement initialisée par mysql_server_init(), tout appel à mysql_init(3) initialisera automatiquement la bibliothèque.
•
mysql_library_init() est un alias pour mysql_server_init()

Valeur de retour

Retourne zéro en cas de succès, ou une valeur non nulle en cas d'erreur. ## Voir aussi * mysql_server_end(3)
