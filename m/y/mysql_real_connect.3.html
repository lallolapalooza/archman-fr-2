Paquet: mariadb

mysql_real_connect(3) MariaDB Connector/C mysql_real_connect(3)

Nom

mysql_real_connect - établit une connexion à un serveur de base de données MariaDB

Synopsis

MYSQL * mysql_real_connect(MYSQL *mysql,
                           const char *host,
                           const char *user,
                           const char *passwd,
                           const char *db,
                           unsigned int port,
                           const char *unix_socket,
                           unsigned long flags);

Description

Établit une connexion à un serveur de base de données.

Paramètres

•
mysql - un handle mysql, précédemment alloué par mysql_init(3)
•
host - peut être un nom d'hôte ou une adresse IP. En passant la valeur NULL ou la chaîne “localhost” à ce paramètre, l'hôte local est supposé. Lorsque possible, des pipes seront utilisés au lieu du protocole TCP/IP. Depuis la version 3.3.0, il est également possible de fournir une liste d'hôtes séparés par des virgules pour un basculement simple en cas d'indisponibilité d'un ou plusieurs hôtes.
•
user - le nom d'utilisateur. Si NULL ou une chaîne vide “” est spécifié, l'utilisateur actuel sera utilisé.
•
passwd - Si fourni ou NULL, le serveur tentera d'authentifier l'utilisateur par rapport aux enregistrements d'utilisateurs qui n'ont pas de mot de passe uniquement. Cela permet d'utiliser un nom d'utilisateur avec des autorisations différentes (selon qu'un mot de passe soit fourni ou non).
•
db - si fourni, spécifiera la base de données par défaut à utiliser lors de l'exécution des requêtes.
•
port - spécifie le numéro de port auquel tenter de se connecter au serveur.
•
unix_socket - spécifie le socket ou le tuyau nommé qui doit être utilisé.
•
flags - les drapeaux permettent de définir diverses options de connexion
Drapeau Description
CLIENT_FOUND_ROWS Retourne le nombre de lignes correspondantes au lieu du nombre de lignes modifiées.
CLIENT_NO_SCHEMA Interdit l'utilisation de la syntaxe database.tablename.column et force le parseur SQL à générer une erreur.
CLIENT_COMPRESS Utiliser le protocole de compression
CLIENT_IGNORE_SPACE Autorise les espaces après les noms de fonctions. Tous les noms de fonctions deviendront des mots réservés.
CLIENT_LOCAL_FILES Autorise les instructions LOAD DATA LOCAL
CLIENT_MULTI_STATEMENTS Permet au client d'envoyer plusieurs instructions en une seule commande. Les instructions seront séparées par un point-virgule.
CLIENT_MULTI_RESULTS Indique que le client est capable de gérer plusieurs jeux de résultats provenant de procédures stockées ou d'instructions multiples. Cette option sera automatiquement définie si CLIENT_MULTI_STATEMENTS est défini.
CLIENT_REMEMBER_OPTIONS Mémorise les options passées à mysql_optionsv(3) si une tentative de connexion a échoué. Si l'option MYSQL_OPTIONS_RECONNECT a été définie sur true, les options seront enregistrées et utilisées pour la reconnexion.

Valeur de retour

retourne un handle de connexion (identique à celui passé en 1er paramètre) ou NULL en cas d'erreur. En cas d'erreur, veuillez vérifier mysql_errno(3) et mysql_error(3) pour plus d'informations.

Notes

•
Le mot de passe n'a pas besoin d'être crypté avant l'exécution de mysql_real_connect(). Cela sera géré dans le protocole client serveur.
•
Le handle de connexion ne peut pas être réutilisé pour établir une nouvelle connexion. Il doit être fermé et réinitialisé au préalable.
•
mysql_real_connect() doit se terminer avec succès avant de pouvoir exécuter toute autre fonction API à l'exception de mysql_optionsv(3).
•
Le paramètre host peut contenir plusieurs combinaisons hôte/port (supporté depuis la version 3.3.0). La syntaxe suivante est requise :
•
le nom d'hôte et le port doivent être séparés par un deux-points (:)
•
les adresses IPv6 doivent être entourées de crochets
•
les paires nom d'hôte:port doivent être séparées par une virgule (,)
•
si un seul hôte:port a été spécifié, la chaîne hôte doit se terminer par une virgule.
•
si aucun port n'a été spécifié, le port par défaut sera utilisé.

Exemples de chaînes d'hôtes pour le basculement :

host=[::1]:3306,192.168.0.1:3306,test.example.com

host=127.0.0.1:3306,
