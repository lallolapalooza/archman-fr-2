NOM

myMPD - client mpd autonome et optimisé pour mobile

SYNOPIS

mympd [options]

DESCRIPTION

myMPD est un client MPD léger basé sur le web et autonome. Il est optimisé pour une utilisation minimale des ressources et ne nécessite que très peu de dépendances. Par conséquent, myMPD est idéal pour les Raspberry Pi et les appareils similaires.

Le backend est écrit en C et n'a aucune dépendance vis-à-vis de bases de données externes ou de serveurs web. La configuration est stockée dans des fichiers texte brut et toutes les données sont extraites à la demande de MPD. La base de données MPD est la seule source de vérité pour myMPD.

Le frontend est optimisé pour mobile, écrit comme une PWA (Progressive Web App) et offre les mêmes fonctionnalités sur tous les appareils. Il communique via AJAX et WebSockets en utilisant le protocole json-rpc 2.

myMPD intègre également des fonctionnalités étendues telles qu'un mode jukebox avancé, des minuteries, des déclencheurs et des listes de lecture intelligentes. Avec l'interpréteur Lua intégré, les fonctions de myMPD peuvent également être scriptées.

OPTIONS

-c, --config
Crée les fichiers de configuration et les certificats SSL, puis quitte.
-d, --dump
Affiche la configuration par défaut et quitte.
-h, --help
Affiche toutes les options valides et quitte.
-v, --version
Affiche les informations de version.
-p, --pin
Définit un code PIN pour les paramètres de myMPD.
-s, --syslog
Active la journalisation syslog (installation : daemon).
-w, --workdir PATH
Répertoire de travail (par défaut : /var/lib/mympd).
-a, --cachedir PATH
Répertoire de cache (par défaut : /var/cache/mympd).
-p, --pin
Définit un code PIN pour les paramètres de myMPD.
