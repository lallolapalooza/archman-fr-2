mysql_select_db(3) Connecteur MariaDB/C mysql_select_db(3)

Nom

mysql_select_db - sélectionne une base de données comme défaut

Synopsis

#include <mysql.h>
int mysql_select_db(MYSQL * mysql,
                    const char * db);

Description

Sélectionne une base de données comme défaut. Retourne zéro en cas de succès, une valeur non nulle en cas d'échec.

Paramètres

•
mysql est un identifiant de connexion, précédemment alloué par mysql_init(3) et connecté par mysql_real_connect(3).
•
db - le nom de la base de données par défaut

Notes

•
Pour récupérer le nom de la base de données par défaut, exécutez la commande SQL SELECT DATABASE() ou récupérez la valeur via la fonction API mariadb_get_infov(3).
•
La base de données par défaut peut également être définie par le paramètre db dans mysql_real_connect(3).

Exemples

SQL

# passez à la base de données par défaut test
USE test;
# vérifiez la base de données par défaut
SELECT DATABASE();
+------------+
| database() |
+------------+
| test       |
+------------+

Connecteur MariaDB/C

static int set_default_db(MYSQL *mysql)
{
  int rc;
  char *default_db;
  /* changer la base de données par défaut en test */
  rc= mysql_select_db(mysql, "test");
  if (rc)
    return rc;  /* Erreur */
  /* obtenir la base de données par défaut */
  rc= mariadb_get_infov(mysql, MARIADB_CONNECTION_SCHEMA, &default_db);
  if (rc)
    return rc; /* Erreur */
  if (strcmp("test", default_db) != NULL)
  {
    printf("Mauvaise base de données par défaut\n");
    return 1;
  }
  printf("Base de données par défaut : %s", default_db);
  return 0;
}
