mysql_options(3) Connecteur MariaDB/C mysql_options(3)

Nom

mysql_options - Utilisé pour définir des options de connexion supplémentaires et affecter le comportement d'une connexion

Synopsis

#include <mysql.h>
int mysql_options(MYSQL * mysql,
                  enum mysql_option,
                  const void * arg);

Description

Utilisé pour définir des options de connexion supplémentaires et affecter le comportement d'une connexion. Cette fonction peut être appelée plusieurs fois pour définir plusieurs options. mysql_options() doit être appelée après mysql_init(3).

Notes

Cette fonction est obsolète, les nouvelles implémentations devraient utiliser la fonction d'API mysql_optionsv(3) à la place.

Options

Un aperçu des options possibles se trouve dans la description de la fonction d'API mysql_optionsv(3).
