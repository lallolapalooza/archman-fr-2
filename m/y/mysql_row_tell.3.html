Nom

mysql_row_tell - Renvoie le décalage de ligne d'un curseur de résultat

Synopsis

#include <mysql.h>
MYSQL_ROW_OFFSET mysql_row_tell(MYSQL_RES * res);

Description

Renvoie le décalage de ligne d'un curseur de résultat. La valeur du décalage renvoyée peut être utilisée pour repositionner le curseur de résultat en appelant mysql_row_seek(3).

Paramètre

•
res - un identifiant de jeu de résultats renvoyé par mysql_store_result(3).

Notes

•
Cette fonction ne fonctionnera pas si le jeu de résultats a été obtenu par mysql_use_result(3).
