MARIADB-HOTCOPY(1) Système de base de données MariaDB MARIADB-HOTCOPY(1)

NOM

mariadb-hotcopy - un programme de sauvegarde de base de données (mariadb-hotcopy est maintenant un lien symbolique vers mariadb-hotcopy)

SYNTAXE

mariadb-hotcopy arguments

DESCRIPTION

mariadb-hotcopy est un script Perl écrit à l'origine et contribué par Tim Bunce. Il utilise FLUSH TABLES, LOCK TABLES et cp ou scp pour effectuer une sauvegarde de base de données. C'est un moyen rapide de sauvegarder la base de données ou des tables individuelles, mais il ne peut être exécuté que sur la même machine où se trouvent les répertoires de la base de données. mariadb-hotcopy fonctionne uniquement pour la sauvegarde des tables MyISAM et ARCHIVE. Il fonctionne sur Unix et NetWare.

Pour utiliser mariadb-hotcopy, vous devez avoir un accès en lecture aux fichiers des tables que vous sauvegardez, le privilège SELECT pour ces tables, le privilège RELOAD (pour pouvoir exécuter FLUSH TABLES) et le privilège LOCK TABLES (pour pouvoir verrouiller les tables).

shell> mariadb-hotcopy nom_db [/chemin/vers/nouveau_repertoire]
shell> mariadb-hotcopy nom_db_1 ... nom_db_n /chemin/vers/nouveau_repertoire

Sauvegarder les tables de la base de données donnée qui correspondent à une expression régulière :

shell> mariadb-hotcopy nom_db./regex/

L'expression régulière pour le nom de la table peut être niée en la faisant précéder d'un tilde (« ~ ») :

shell> mariadb-hotcopy nom_db./~regex/

mariadb-hotcopy prend en charge les options suivantes, qui peuvent être spécifiées sur la ligne de commande ou dans les groupes de fichiers d'options [mariadb-hotcopy] et [client].

•--help, -?

Affiche un message d'aide et quitte.

•--addtodest

Ne renomme pas le répertoire cible (s'il existe) ; ajoute simplement les fichiers dedans.

•--allowold

N'interrompt pas si une cible existe ; la renomme en ajoutant un suffixe _old.

•--checkpoint=nom_db.nom_tbl

Insère des entrées de point de contrôle dans la base de données spécifiée nom_db et la table nom_tbl.

•--chroot=chemin

Répertoire de base de la prison chroot dans laquelle mariadbd opère. La valeur chemin doit correspondre à celle de l'option --chroot donnée à mariadbd.

•--debug

Active la sortie de débogage.

•--dryrun, -n

Rapporte les actions sans les effectuer.

•--flushlog

Vide les journaux après que toutes les tables soient verrouillées.

•--host=nom_hote, -h nom_hote

Le nom d'hôte de la machine locale à utiliser pour établir une connexion TCP/IP avec le serveur local. Par défaut, la connexion est établie avec localhost en utilisant un fichier socket Unix.

•--keepold

Ne supprime pas la cible précédente (renommée) une fois terminé.

•--method=commande

La méthode de copie des fichiers (cp ou scp). Par défaut, c'est cp.

•--noindices

N'inclut pas les fichiers d'index complets pour les tables MyISAM dans la sauvegarde. Cela rend la sauvegarde plus petite et plus rapide. Les index pour les tables rechargées peuvent être reconstruits plus tard avec myisamchk -rq.

•--old-server

Se connecte à un ancien serveur MySQL (avant la v5.5) qui n'a pas FLUSH TABLES WITH READ LOCK implémenté entièrement.

•--password=mot_de_passe, -pmot_de_passe

Le mot de passe à utiliser lors de la connexion au serveur. La valeur du mot de passe n'est pas facultative pour cette option, contrairement aux autres programmes MariaDB.

Spécifier un mot de passe sur la ligne de commande doit être considéré comme peu sûr. Vous pouvez utiliser un fichier d'options pour éviter de donner le mot de passe sur la ligne de commande.

•--port=num_port, -P num_port

Le numéro de port TCP/IP à utiliser lors de la connexion au serveur local.

•--quiet, -q

Être silencieux sauf en cas d'erreurs.

•--record_log_pos=nom_db.nom_tbl

Enregistre le statut du maître et de l'esclave dans la base de données spécifiée nom_db et la table nom_tbl.

•--regexp=expr

Copie toutes les bases de données dont les noms correspondent à l'expression régulière donnée.

•--resetmaster

Réinitialise le journal binaire après avoir verrouillé toutes les tables.

•--resetslave

Réinitialise le fichier master.info après avoir verrouillé toutes les tables.

•--socket=chemin, -S chemin

Le fichier socket Unix à utiliser pour les connexions à localhost.

•--suffix=str

Le suffixe à utiliser pour les noms des bases de données copiées.

•--tmpdir=chemin

Le répertoire temporaire. Par défaut, c'est /tmp.

•--user=nom_utilisateur, -u nom_utilisateur

Le nom d'utilisateur MariaDB à utiliser lors de la connexion au serveur.

Utilisez perldoc pour obtenir une documentation supplémentaire sur mariadb-hotcopy, y compris des informations sur la structure des tables nécessaires pour les options --checkpoint et --record_log_pos :

shell> perldoc mariadb-hotcopy
