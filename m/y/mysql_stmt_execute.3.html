Nom

mysql_stmt_execute - Exécute une requête préparée

Synopsis

#include <mysql.h>
int mysql_stmt_execute(MYSQL_STMT * stmt);

Description

Exécute une requête préparée qui a été précédemment préparée par mysql_stmt_prepare(3). Lors de l'exécution, tous les marqueurs de paramètres existants seront automatiquement remplacés par les données appropriées.

Paramètre

•
stmt - Un descripteur de requête, qui a été précédemment alloué par mysql_stmt_init(3).

Valeur de retour

Retourne zéro en cas de succès, une valeur non nulle en cas d'échec.

Notes

•
Si la requête est UPDATE, REPLACE, DELETE ou INSERT, le nombre total de lignes affectées peut être déterminé en utilisant la fonction mysql_stmt_affected_rows(3). De même, si la requête produit un jeu de résultats, la fonction mysql_stmt_fetch(3) est utilisée.
