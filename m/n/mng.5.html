NOM

mng - Format Multiple-image Network Graphics (MNG)

DESCRIPTION

MNG (Multiple-image Network Graphics) est l'extension d'animation du format d'image populaire PNG. PNG (Portable Network Graphics) est un format de fichier extensible pour le stockage sans perte, portable et bien compressé d'images matricielles.

MNG possède des fonctionnalités d'animation avancées qui en font un remplacement complet très utile pour les animations GIF. Ces fonctionnalités permettent des animations impossibles avec GIF ou résultent en des fichiers beaucoup plus petits que GIF.

Comme MNG est basé sur la même structure que PNG, il est robuste, extensible et sans brevet. Il conserve les mêmes vérifications intelligentes d'intégrité des fichiers que PNG.

MNG intègre également le format d'image JPEG, qui peut être avec ou sans perte, dans un sous-format nommé JNG, qui permet la transparence alpha et la correction des couleurs sur des images hautement compressées (photographiques).
