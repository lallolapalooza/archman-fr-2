mxml(3) API Mini-XML mxml(3)

NOM

mxml - API Mini-XML

FICHIER INCLUS

#include <mxml.h>

BIBLIOTHEQUE

-lmxml

DESCRIPTION

Mini-XML est une petite bibliothèque d'analyse XML que vous pouvez utiliser pour lire des fichiers de données XML et similaires dans votre application sans nécessiter de bibliothèques volumineuses non standard. Mini-XML nécessite uniquement un compilateur compatible ANSI C (GCC fonctionne, tout comme les compilateurs ANSI C de la plupart des fournisseurs) et un programme "make".

Mini-XML fournit les fonctionnalités suivantes :

  • Lecture de fichiers et chaînes XML encodés en UTF-8 et UTF-16 et écriture de fichiers et chaînes XML encodés en UTF-8.
  • Les données sont stockées dans une structure arborescente chaînée, préservant la hiérarchie des données XML.
  • Prend en charge des noms d'éléments, des attributs et des valeurs d'attributs arbitraires sans limites prédéfinies, uniquement la mémoire disponible.
  • Prend en charge les types de données entier, réel, opaque ("CDATA") et texte dans les nœuds "feuilles".
  • Fonctions pour créer, indexer et gérer des arbres de données.
  • Fonctions "Find" et "walk" pour localiser et naviguer facilement dans les arbres de données.

Mini-XML ne fait pas de validation ou d'autres types de traitement sur les données basés sur des fichiers de schéma ou d'autres sources d'informations de définition, et il ne prend pas en charge les entités de caractères autres que celles requises par la spécification XML.

UTILISATION DE MINI-XML

Mini-XML fournit un seul fichier d'en-tête que vous incluez :

    #include <mxml.h>

Les nœuds sont définis par la structure "mxml_node_t" ; le membre "type" définit le type de nœud (élément, entier, opaque, réel ou texte) qui détermine quelle valeur vous souhaitez consulter dans l'union "value". De nouveaux nœuds peuvent être créés à l'aide des fonctions "mxmlNewElement()", "mxmlNewInteger()", "mxmlNewOpaque()", "mxmlNewReal()" et "mxmlNewText()". Seuls les éléments peuvent avoir des nœuds enfants, et le nœud supérieur doit être un élément, généralement "?xml".

Vous chargez un fichier XML à l'aide de la fonction "mxmlLoadFile()" :

    FILE *fp;
    mxml_node_t *tree;
    fp = fopen("nom_du_fichier.xml", "r");
    tree = mxmlLoadFile(NULL, fp, MXML_NO_CALLBACK);
    fclose(fp);

De même, vous enregistrez un fichier XML à l'aide de la fonction "mxmlSaveFile()" :

    FILE *fp;
    mxml_node_t *tree;
    fp = fopen("nom_du_fichier.xml", "w");
    mxmlSaveFile(tree, fp, MXML_NO_CALLBACK);
    fclose(fp);

Les fonctions "mxmlLoadString()", "mxmlSaveAllocString()" et "mxmlSaveString()" chargent des arbres de nœuds XML à partir de chaînes et en sauvegardent des arbres de nœuds XML dans des chaînes :

    char buffer[8192];
    char *ptr;
    mxml_node_t *tree;
    ...
    tree = mxmlLoadString(NULL, buffer, MXML_NO_CALLBACK);
    ...
    mxmlSaveString(tree, buffer, sizeof(buffer),
                   MXML_NO_CALLBACK);
    ...
    ptr = mxmlSaveAllocString(tree, MXML_NO_CALLBACK);

Vous pouvez trouver un élément/nœud nommé à l'aide de la fonction "mxmlFindElement()" :

    mxml_node_t *node = mxmlFindElement(tree, tree, "nom",
                                        "attribut", "valeur",
                                        MXML_DESCEND);

Les arguments "nom", "attribut" et "valeur" peuvent être passés comme NULL pour agir comme des jokers, par exemple :

    /* Trouver le premier élément "a" */
    node = mxmlFindElement(tree, tree, "a", NULL, NULL,
                           MXML_DESCEND);
    /* Trouver le premier élément "a" avec l'attribut "href" */
    node = mxmlFindElement(tree, tree, "a", "href", NULL,
                           MXML_DESCEND);
    /* Trouver le premier élément "a" avec "href" vers une URL */
    node = mxmlFindElement(tree, tree, "a", "href",
                           "http://www.easysw.com/~mike/mxml/",
                           MXML_DESCEND);
    /* Trouver le premier élément avec un attribut "src" */
    node = mxmlFindElement(tree, tree, NULL, "src", NULL,
                           MXML_DESCEND);
    /* Trouver le premier élément avec "src" = "foo.jpg" */
    node = mxmlFindElement(tree, tree, NULL, "src",
                           "foo.jpg", MXML_DESCEND);

Vous pouvez également itérer avec la même fonction :

    mxml_node_t *node;
    for (node = mxmlFindElement(tree, tree, "nom", NULL,
                                NULL, MXML_DESCEND);
         node != NULL;
         node = mxmlFindElement(node, tree, "nom", NULL,
                                NULL, MXML_DESCEND))
    {
      ... faire quelque chose ...
    }

Pour trouver la valeur d'un nœud spécifique dans l'arbre, utilisez la fonction "mxmlFindPath()" :

    mxml_node_t *valeur = mxmlFindPath(tree, "chemin/vers/*/foo/bar");

Les fonctions "mxmlGetInteger()", "mxmlGetOpaque()", "mxmlGetReal()" et "mxmlGetText()" récupèrent la valeur d'un nœud :

    mxml_node_t *node;
    int intvalue = mxmlGetInteger(node);
    const char *opaquevalue = mxmlGetOpaque(node);
    double realvalue = mxmlGetReal(node);
    int whitespacevalue;
    const char *textvalue = mxmlGetText(node, &whitespacevalue);

Enfin, une fois que vous avez terminé avec les données XML, utilisez la fonction "mxmlDelete()" pour libérer récursivement la mémoire utilisée par un nœud particulier ou par l'arbre entier :

    mxmlDelete(tree);

FONCTIONS

mxmlAdd

Ajouter un nœud à un arbre.

void mxmlAdd (
    mxml_node_t *parent,
    int where,
    mxml_node_t *child,
    mxml_node_t *node
);

Ajoute le nœud spécifié au parent. Si l'argument child n'est pas NULL, place le nouveau nœud avant ou après l'enfant spécifié en fonction de la valeur de l'argument where. Si l'argument child est NULL, place le nouveau nœud au début de la liste des enfants (MXML_ADD_BEFORE) ou à la fin de la liste des enfants (MXML_ADD_AFTER). La constante MXML_ADD_TO_PARENT peut être utilisée pour spécifier un pointeur enfant NULL.

mxmlDelete

Supprimer un nœud et tous ses enfants.

void mxmlDelete (
    mxml_node_t *node
);

Si le nœud spécifié a un parent, cette fonction supprime d'abord le nœud de son parent à l'aide de la fonction mxmlRemove.

const char * mxmlElementGetAttrByIndex (

Si l'attribut nommé existe déjà, la valeur de l'attribut est remplacée par la nouvelle chaîne formatée. La chaîne formatée est copiée dans le nœud élément. Cette fonction ne fait rien si le nœud n'est pas un élément.

void mxmlEntityRemoveCallback (

mxmlFindElement

Trouver l'élément nommé.

mxml_node_t * mxmlFindElement (
    mxml_node_t *node,
    mxml_node_t *top,
    const char *element,
    const char *attr,
    const char *value,
    int descend
);

La recherche est limitée par le nom, le nom de l'attribut et la valeur ; tous les noms ou valeurs NULL sont traités comme des caractères génériques, de sorte que différents types de recherches peuvent être implémentés en recherchant tous les éléments d'un nom donné ou tous les éléments avec un attribut spécifique. L'argument descend détermine si la recherche descend dans les nœuds enfants ; normalement, vous utiliserez MXML_DESCEND_FIRST pour la recherche initiale et MXML_NO_DESCEND pour trouver d'autres descendants directs du nœud. L'argument du nœud supérieur contraint la recherche aux enfants d'un nœud particulier.

mxmlFindPath

Trouver un nœud avec le chemin donné.

mxml_node_t * mxmlFindPath (
    mxml_node_t *top,
    const char *path
);

Le "chemin" est une liste de noms d'éléments séparés par des barres obliques. Le nom "" est considéré comme un caractère générique pour un ou plusieurs niveaux d'éléments. Par exemple, "foo/one/two", "bar/two/one", "/one", et ainsi de suite.

Le premier nœud enfant du nœud trouvé est retourné si le nœud donné a des enfants et que le premier enfant est un nœud de valeur.

int  mxmlGetRefCount (
    mxml_node_t *node
);

Le nombre de références initial des nouveaux nœuds est de 1. Utilisez les fonctions mxmlRetain et mxmlRelease pour incrémenter et décrémenter le nombre de références d'un nœud.

mxmlGetText

Obtenir la valeur textuelle pour un nœud ou son premier enfant.

const char * mxmlGetText (
    mxml_node_t *node,
    int *whitespace
);

NULL est retourné si le nœud (ou son premier enfant) n'est pas un nœud texte. L'argument "whitespace" peut être NULL.

Note : Les nœuds texte sont constitués de mots délimités par des espaces blancs. Vous n'obtiendrez que des mots de texte uniques lors de la lecture d'un fichier XML avec des nœuds MXML_TEXT. Si vous voulez la chaîne entière entre les éléments du fichier XML, vous DEVEZ lire le fichier XML avec des nœuds MXML_OPAQUE et obtenir les chaînes résultantes en utilisant la fonction mxmlGetOpaque à la place.

mxmlIndexEnum

Retourner le nœud suivant dans l'index.

mxml_node_t * mxmlIndexEnum (
    mxml_index_t *ind
);

Vous devriez appeler mxmlIndexReset avant d'utiliser cette fonction pour obtenir le premier nœud de l'index. Les nœuds sont retournés dans l'ordre trié de l'index.

mxmlIndexFind

Trouver le nœud correspondant suivant.

mxml_node_t * mxmlIndexFind (
    mxml_index_t *ind,
    const char *element,
    const char *value
);

Vous devez appeler mxmlIndexReset avant d'utiliser cette fonction pour la première fois avec un jeu particulier de chaînes "element" et "value". Passer NULL pour "element" et "value" est équivalent à appeler mxmlIndexEnum.

mxmlIndexGetCount

int  mxmlIndexGetCount (
    mxml_index_t *ind
);

mxmlIndexNew

Créer un nouvel index.

mxml_index_t * mxmlIndexNew (
    mxml_node_t *node,
    const char *element,
    const char *attr
);

L'index contiendra tous les nœuds qui contiennent l'élément nommé et/ou l'attribut. Si "element" et "attr" sont tous deux NULL, alors l'index contiendra une liste triée des éléments dans l'arbre de nœuds. Les nœuds sont triés par nom d'élément et éventuellement par valeur d'attribut si l'argument "attr" n'est pas NULL.

mxmlIndexReset

Réinitialiser le pointeur d'énumération/recherche dans l'index et renvoyer le premier nœud de l'index.

mxml_node_t * mxmlIndexReset (
    mxml_index_t *ind
);

Cette fonction doit être appelée avant d'utiliser mxmlIndexEnum ou mxmlIndexFind pour la première fois.

mxmlLoadFd

Charger un descripteur de fichier dans un arbre de nœuds XML.

mxml_node_t * mxmlLoadFd (
    mxml_node_t *top,
    int fd,
    mxml_load_cb_t cb
);

Les nœuds du fichier spécifié sont ajoutés au nœud supérieur spécifié. Si aucun nœud supérieur n'est fourni, le fichier XML DOIT être bien formé avec un unique nœud parent comme
pour l'ensemble du fichier. La fonction de rappel renvoie le type de valeur qui doit être utilisé pour les nœuds enfants. Les constantes MXML_INTEGER_CALLBACK, MXML_OPAQUE_CALLBACK, MXML_REAL_CALLBACK et MXML_TEXT_CALLBACK sont définies pour charger les nœuds enfants (de données) du type spécifié.

Note : L'erreur de programmation la plus courante lors de l'utilisation de la bibliothèque Mini-XML est de charger un fichier XML en utilisant MXML_TEXT_CALLBACK, qui renvoie le texte en ligne sous forme d'une série de mots séparés par des espaces, au lieu d'utiliser MXML_OPAQUE_CALLBACK qui renvoie le texte en ligne sous forme d'une seule chaîne (espaces inclus).

mxmlNewCDATA

Créer un nouveau nœud CDATA.

mxml_node_t * mxmlNewCDATA (
    mxml_node_t *parent,
    const char *data
);

Le nouveau nœud CDATA est ajouté à la fin de la liste d'enfants du parent spécifié. La constante MXML_NO_PARENT peut être utilisée pour spécifier que le nouveau nœud CDATA n'a pas de parent. La chaîne de données doit être terminée par un caractère nul et est copiée dans le nouveau nœud. Les nœuds CDATA utilisent actuellement le type MXML_ELEMENT.

Le nouveau nœud de texte est ajouté à la fin de la liste d'enfants du parent spécifié. La constante MXML_NO_PARENT peut être utilisée pour spécifier que le nouveau nœud de texte n'a pas de parent. Le paramètre whitespace est utilisé pour spécifier s'il y a des espaces blancs en tête avant le nœud. La chaîne de format doit être terminée par un caractère nul et est formatée dans le nouveau nœud.

mxmlSAXLoadFd

Charger un descripteur de fichier dans un arbre de nœuds XML à l'aide d'un rappel SAX. 

mxml_node_t * mxmlSAXLoadFd (
    mxml_node_t *top,
    int fd,
    mxml_load_cb_t cb,
    mxml_sax_cb_t sax_cb,
    void *sax_data
);

Les nœuds du fichier spécifié sont ajoutés au nœud supérieur spécifié. Si aucun nœud supérieur n'est fourni, le fichier XML DOIT être bien formé avec un seul nœud parent tel que
pour l'ensemble du fichier. La fonction de rappel renvoie le type de valeur qui doit être utilisé pour les nœuds enfants. Les constantes MXML_INTEGER_CALLBACK, MXML_OPAQUE_CALLBACK, MXML_REAL_CALLBACK et MXML_TEXT_CALLBACK sont définies pour charger les nœuds enfants du type spécifié.

Le rappel SAX doit appeler mxmlRetain pour tous les nœuds qui doivent être conservés pour une utilisation ultérieure. Sinon, les nœuds sont supprimés lorsque le nœud parent est fermé ou après chaque nœud de données, commentaire, CDATA ou directive.

Si MXML_NO_CALLBACK est spécifié, les espaces ne seront ajoutés qu'avant les nœuds MXML_TEXT avec des espaces en tête et avant les noms d'attributs dans les balises d'éléments ouvrants.
