NOM

miniflux - Lecteur de flux minimaliste et opinionné

SYNTAXE

miniflux [-vic] [-config-dump] [-config-file] [-create-admin] [-debug]
[-flush-sessions] [-healthcheck] [-info] [-migrate] [-refresh-feeds]
[-reset-feed-errors] [-reset-feed-next-check-at] [-reset-password]
[-run-cleanup-tasks] [-version]

DESCRIPTION

miniflux est un lecteur de flux minimaliste et opinionné.

OPTIONS

-config-dump

Affiche les valeurs de configuration analysées. Cela inclut des informations sensibles comme les mots de passe.

-c /chemin/vers/miniflux.conf

Charge le fichier de configuration.

-config-file /chemin/vers/miniflux.conf

Charge le fichier de configuration.

-create-admin

Crée un utilisateur administrateur depuis un terminal interactif.

-debug

Définit le niveau de journalisation sur debug.

-export-user-feeds <nomutilisateur>

Exporte les flux d'un utilisateur (fournir le nom d'utilisateur en argument).
Exemple : "miniflux -export-user-feeds quelquun > feeds.xml".

-flush-sessions

Supprime toutes les sessions (déconnecte les utilisateurs).

-healthcheck <point-de-terminaison>

Effectue une vérification de bon fonctionnement sur le point de terminaison donné.
La valeur "auto" tente de deviner le point de terminaison de vérification de bon fonctionnement.

-i

Affiche les informations de construction.

-info

Affiche les informations de construction.

-migrate

Exécute les migrations SQL.

-refresh-feeds

Actualise un lot de flux et quitte.

-reset-feed-errors

Efface toutes les erreurs de flux pour tous les utilisateurs.

-reset-feed-next-check-at

Réinitialise l'heure de prochaine vérification pour tous les flux.

-reset-password

Réinitialise le mot de passe de l'utilisateur.

-run-cleanup-tasks

Exécute les tâches de nettoyage (supprime les anciennes sessions et archive les anciennes entrées).

-v

Affiche la version de l'application.

-version

Affiche la version de l'application.

FICHIER DE CONFIGURATION

Le fichier de configuration est un fichier texte qui suit ces règles :

- Miniflux attend que chaque ligne soit au format CLÉ=VALEUR.
- Les lignes commençant par # sont traitées comme des commentaires et ignorées.
- Les lignes vides sont ignorées.
- Il n'y a pas d'interpolation de variables.

Les clés sont les mêmes que les variables d'environnement décrites ci-dessous.
Les variables d'environnement remplacent les valeurs définies dans le fichier de configuration.

ENVIRONNEMENT

ADMIN_PASSWORD
Mot de passe de l'utilisateur administrateur, utilisé uniquement si $CREATE_ADMIN est activé.
Par défaut, est vide.
ADMIN_PASSWORD_FILE
Chemin vers une clé secrète exposée sous forme de fichier, elle doit contenir la valeur de $ADMIN_PASSWORD.
Par défaut, est vide.
ADMIN_USERNAME
Nom d'utilisateur de l'administrateur, utilisé uniquement si $CREATE_ADMIN est activé.
Par défaut, est vide.
ADMIN_USERNAME_FILE
Chemin vers une clé secrète exposée sous forme de fichier, elle doit contenir la valeur de $ADMIN_USERNAME.
Par défaut, est vide.
AUTH_PROXY_HEADER
En-tête HTTP d'authentification du proxy.
Par défaut, est vide.
AUTH_PROXY_USER_CREATION
Défini sur 1 pour créer des utilisateurs basés sur les informations d'authentification du proxy.
Désactivé par défaut.
BASE_URL
URL de base pour générer les liens HTML et le chemin de base pour les cookies.
Par défaut, est http://localhost/.
BATCH_SIZE
Nombre de flux à envoyer dans la file d'attente pour chaque intervalle.
Par défaut, 100 flux.
CERT_DOMAIN
Utilise Let's Encrypt pour obtenir automatiquement un certificat pour ce domaine.
Par défaut, est vide.
CERT_FILE
Chemin vers le certificat SSL.
Par défaut, est vide.
CLEANUP_ARCHIVE_BATCH_SIZE
Nombre d'entrées à archiver pour chaque intervalle de tâche.
Par défaut, 10000 entrées.
CLEANUP_ARCHIVE_READ_DAYS
Nombre de jours après avoir marqué les entrées lues comme supprimées.
Défini sur -1 pour conserver toutes les entrées lues.
Par défaut, 60 jours.
CLEANUP_ARCHIVE_UNREAD_DAYS
Nombre de jours après avoir marqué les entrées non lues comme supprimées.
Défini sur -1 pour conserver toutes les entrées non lues.
Par défaut, 180 jours.
CLEANUP_FREQUENCY_HOURS
Fréquence de la tâche de nettoyage. Supprime les anciennes sessions et archive les entrées.
Par défaut, 24 heures.
CLEANUP_REMOVE_SESSIONS_DAYS
Nombre de jours après la suppression des anciennes sessions de la base de données.
Par défaut, 30 jours.
CREATE_ADMIN
Défini sur 1 pour créer un utilisateur administrateur à partir des variables d'environnement.
Désactivé par défaut.
DATABASE_CONNECTION_LIFETIME
Définit la durée maximale pendant laquelle une connexion peut être réutilisée.
Par défaut, 5 minutes.
DATABASE_MAX_CONNS
Nombre maximum de connexions à la base de données.
Par défaut, 20.
DATABASE_MIN_CONNS
Nombre minimum de connexions à la base de données.
Par défaut, 1.
DATABASE_URL
Paramètres de connexion PostgreSQL.
Par défaut, "user=postgres password=postgres dbname=miniflux2 sslmode=disable".
DATABASE_URL_FILE
Chemin vers une clé secrète exposée sous forme de fichier, elle doit contenir la valeur de $DATABASE_URL.
Par défaut, est vide.
DISABLE_HSTS
Désactive l'en-tête HTTP Strict Transport Security si HTTPS est défini.
Par défaut, false (Le HSTS est activé).
DISABLE_HTTP_SERVICE
Définit la valeur à 1 pour désactiver le service HTTP.
Par défaut, false (Le service HTTP est activé).
DISABLE_LOCAL_AUTH
Désactive l'authentification locale.
Lorsque défini sur true, le formulaire nom d'utilisateur/mot de passe est masqué de l'écran de connexion, et les options pour changer le nom d'utilisateur/mot de passe ou dissocier un compte OAuth2 sont masquées de la page des paramètres.
Par défaut, false.
DISABLE_SCHEDULER_SERVICE
Définit la valeur à 1 pour désactiver le service de planification interne.
Par défaut, false (Le service de planification interne est activé).
FETCH_BILIBILI_WATCH_TIME
Définit la valeur à 1 pour scraper la durée de la vidéo du site Bilibili et l'utiliser comme

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

temps de lecture.
Désactivé par défaut.
FETCH_NEBULA_WATCH_TIME
Définissez la valeur à 1 pour extraire la durée de la vidéo du site Web Nebula et l'utiliser comme temps de lecture.
Désactivé par défaut.
FETCH_ODYSEE_WATCH_TIME
Définissez la valeur à 1 pour extraire la durée de la vidéo du site Web Odysee et l'utiliser comme temps de lecture.
Désactivé par défaut.
FETCH_YOUTUBE_WATCH_TIME
Définissez la valeur à 1 pour extraire la durée de la vidéo du site Web YouTube et l'utiliser comme temps de lecture.
Désactivé par défaut.
FILTER_ENTRY_MAX_AGE_DAYS
Nombre de jours après lesquels les nouvelles entrées doivent être conservées.
Définissez 7 pour récupérer uniquement les entrées vieilles de 7 jours.
La valeur par défaut est 0 (désactivé).
FORCE_REFRESH_INTERVAL
L'intervalle minimum pour le rafraîchissement manuel.
Par défaut, 30 minutes.
HTTP_CLIENT_MAX_BODY_SIZE
Taille maximale du corps pour les requêtes HTTP en Mébibyte (MiB).
Par défaut, 15 MiB.
HTTP_CLIENT_PROXIES
Activez la rotation des proxys pour les requêtes sortantes en fournissant une liste séparée par des virgules d'URL de proxy.
Par défaut, vide.
HTTP_CLIENT_PROXY
URL du proxy à utiliser lorsque l'option d'alimentation "Récupérer via proxy" est activée.
Par défaut, vide.
HTTP_CLIENT_TIMEOUT
Limite de temps en secondes avant que le client HTTP n'annule la requête.
Par défaut, 20 secondes.
HTTP_CLIENT_USER_AGENT
L'en-tête User-Agent par défaut à utiliser pour le client HTTP. Peut être remplacé dans les paramètres par flux.
Lorsqu'il est vide, Miniflux utilise un User-Agent par défaut qui inclut la version de Miniflux.
Par défaut, vide.
HTTP_SERVER_TIMEOUT
Limite de temps en secondes avant que le client HTTP n'annule la requête.
Par défaut, 300 secondes.
HTTPS
Force les cookies à utiliser le drapeau sécurisé et à envoyer l'en-tête HSTS.
Par défaut, désactivé.
INVIDIOUS_INSTANCE
Définissez une instance invidious personnalisée à utiliser.
Par défaut, yewtu.be.
KEY_FILE
Chemin vers la clé privée SSL.
Par défaut, vide.
LISTEN_ADDR
Adresse sur laquelle écouter. Utilisez un chemin absolu pour écouter sur un socket Unix (/var/run/miniflux.sock).
Plusieurs adresses peuvent être spécifiées, séparées par des virgules. Par exemple : 127.0.0.1:8080, 127.0.0.1:8081.
Par défaut, 127.0.0.1:8080.
LOG_DATE_TIME
Affiche la date et l'heure dans les messages de journal.
Désactivé par défaut.
LOG_FILE
Les valeurs prises en charge sont "stderr", "stdout", ou un nom de fichier .
Par défaut, "stderr".
LOG_FORMAT
Les formats de journal pris en charge sont "text" ou "json".
Par défaut, "text".
LOG_LEVEL
Les valeurs prises en charge sont "debug", "info", "warning", ou "error".
Par défaut, "info".
MAINTENANCE_MESSAGE
Définissez un message de maintenance personnalisé.
Par défaut, "Miniflux est actuellement en maintenance".
MAINTENANCE_MODE
Définissez sur 1 pour activer le mode maintenance.
Désactivé par défaut.
MEDIA_PROXY_CUSTOM_URL
Définit un serveur externe pour le proxy des médias.
Par défaut, vide, Miniflux effectue le proxy.
MEDIA_PROXY_HTTP_CLIENT_TIMEOUT
Limite de temps en secondes avant que le client HTTP du proxy média n'annule la requête.
Par défaut, 120 secondes.
MEDIA_PROXY_RESOURCE_TYPES
Une liste séparée par des virgules des types de médias à proxifier. Les valeurs prises en charge sont : image, audio, video.
Par défaut, image.
MEDIA_PROXY_MODE
Valeurs possibles : http-only, all, ou none.
Par défaut, http-only.
MEDIA_PROXY_PRIVATE_KEY
Définissez une clé privée personnalisée utilisée pour signer les URL de médias proxifiés.
Par défaut, une clé secrète est générée aléatoirement au démarrage.
METRICS_ALLOWED_NETWORKS
Liste des réseaux autorisés à accéder au point de terminaison des métriques (séparées par des virgules).
Par défaut, 127.0.0.1/8.
METRICS_COLLECTOR
Définissez sur 1 pour activer le collecteur de métriques. Expose un point de terminaison /metrics pour Prometheus.
Désactivé par défaut.
METRICS_PASSWORD
Mot de passe du point de terminaison des métriques pour l'authentification HTTP de base.
Par défaut, vide.
METRICS_PASSWORD_FILE
Chemin vers un fichier contenant le mot de passe pour l'authentification HTTP du point de terminaison des métriques.
Par défaut, vide.
METRICS_REFRESH_INTERVAL
Intervalle de rafraîchissement pour la collecte des métriques de la base de données.
Par défaut, 60 secondes.
METRICS_USERNAME
Nom d'utilisateur du point de terminaison des métriques pour l'authentification HTTP de base.
Par défaut, vide.
METRICS_USERNAME_FILE
Chemin vers un fichier contenant le nom d'utilisateur pour l'authentification HTTP du point de terminaison des métriques.
Par défaut, vide.
OAUTH2_CLIENT_ID
Identifiant client OAuth2.
Par défaut, vide.
OAUTH2_CLIENT_ID_FILE
Chemin vers une clé secrète exposée sous forme de fichier, il doit contenir la valeur $OAUTH2_CLIENT_ID.
Par défaut, vide.
OAUTH2_CLIENT_SECRET
Secret client OAuth2.
Par défaut, vide.
OAUTH2_CLIENT_SECRET_FILE
Chemin vers une clé secrète exposée sous forme de fichier, il doit contenir la valeur $OAUTH2_CLIENT_SECRET.
Par défaut, vide.
OAUTH2_OIDC_DISCOVERY_ENDPOINT
Point de terminaison de découverte OpenID Connect.
Par défaut, vide.
OAUTH2_OIDC_PROVIDER_NAME
Nom à afficher pour le fournisseur OIDC.
Par défaut, "OpenID Connect".
OAUTH2_PROVIDER
Les valeurs possibles sont "google" ou "oidc".
Par défaut, vide.
OAUTH2_REDIRECT_URL
URL de redirection OAuth2.
Cette URL doit être enregistrée auprès du fournisseur et ressemble à https://miniflux.example.org/oauth2/oidc/callback.
Par défaut, vide.
OAUTH2_USER_CREATION
Définissez sur 1 pour autoriser la création d'utilisateurs OAuth2.
Désactivé par défaut.
POLLING_FREQUENCY
Intervalle pour le planificateur de tâches en arrière-plan.
Détermine la fréquence à laquelle un lot de flux est sélectionné pour le rafraîchissement, en fonction de leur dernière heure de rafraîchissement.
Par défaut, 60 minutes.
POLLING_LIMIT_PER_HOST
Limite le nombre de requêtes simultanées vers le même nom d'hôte lors de l'interrogation des flux.
Cela permet d'éviter de submerger un seul serveur lors du traitement par lots par le pool de travailleurs.
Par défaut, 0 (désactivé).
POLLING_PARSING_ERROR_LIMIT
Le nombre maximum d'erreurs d'analyse que le programme tentera avant d'arrêter l'interrogation d'un flux.
Une fois la limite atteinte, l'utilisateur doit actualiser manuellement le flux. Définissez sur 0 pour illimité.
Par défaut, 3.
POLLING_SCHEDULER
Détermine la stratégie utilisée pour planifier l'interrogation des flux.
Les valeurs prises en charge sont "round_robin" et "entry_frequency".
- "round_robin" : Les flux sont interrogés dans un ordre fixe et rotatif.
- "entry_frequency" : L'intervalle d'interrogation pour chaque flux est basé sur la fréquence de mise à jour moyenne au cours de la semaine écoulée.
Le nombre de flux interrogés sur une période donnée est limité par les paramètres POLLING_FREQUENCY et BATCH_SIZE.
Quel que soit le planificateur utilisé, le nombre total de flux interrogés ne dépassera pas le maximum autorisé par cycle de sonderie.
Par défaut : "round_robin".
PORT
Remplace LISTEN_ADDR par 0.0.0.0:$PORT.
Par défaut : vide.
RUN_MIGRATIONS
Mettre à 1 pour exécuter les migrations de la base de données.
Désactivé par défaut.
SCHEDULER_ENTRY_FREQUENCY_FACTOR
Facteur pour augmenter la fréquence d'actualisation pour le planificateur de fréquence d'entrées.
Par défaut : 1.
SCHEDULER_ENTRY_FREQUENCY_MAX_INTERVAL
Intervalle maximum en minutes pour le planificateur de fréquence d'entrées.
Par défaut : 1440 minutes (24 heures).
SCHEDULER_ENTRY_FREQUENCY_MIN_INTERVAL
Intervalle minimum en minutes pour le planificateur de fréquence d'entrées.
Par défaut : 5 minutes.
SCHEDULER_ROUND_ROBIN_MAX_INTERVAL
Intervalle maximum en minutes pour le planificateur round robin.
Par défaut : 1440 minutes (24 heures).
SCHEDULER_ROUND_ROBIN_MIN_INTERVAL
Intervalle minimum en minutes pour le planificateur round robin.
Par défaut : 60 minutes.
WATCHDOG
Activer ou désactiver le watchdog Systemd.
Activé par défaut.
WEBAUTHN
Activer ou désactiver l'authentification WebAuthn/Passkey.
Vous devez fournir un nom d'utilisateur sur la page de connexion si vous utilisez des clés non résidentielles. Cependant, ceci n'est pas requis pour les identifiants découvrables.
Désactivé par défaut.
WORKER_POOL_SIZE
Nombre de workers en arrière-plan.
Par défaut : 16 workers.
YOUTUBE_API_KEY
Clé API YouTube à utiliser avec FETCH_YOUTUBE_WATCH_TIME. Si elle n'est pas vide, la durée sera récupérée de l'API YouTube. Sinon, la durée sera récupérée du site web YouTube.
Par défaut : vide.
YOUTUBE_EMBED_URL_OVERRIDE
URL YouTube qui sera utilisée pour les intégrations.
Par défaut : https://www.youtube-nocookie.com/embed/.
