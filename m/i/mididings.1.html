mididings(1) Manuel des commandes générales mididings(1)

NOM

mididings - Un routeur et processeur MIDI basé sur Python.

DESCRIPTION

L'outil en ligne de commande mididings offre plusieurs façons d'exécuter des scripts sans écrire de scripts Python complets.

OPTIONS

--version

Affiche le numéro de version de Python et mididings.

-h, --help

Affiche le message d'aide.

OPTIONS DE BACKEND

-A

Utilise le séquenceur ALSA.

-J

Utilise JACK MIDI (tamponné).

-R

Utilise JACK MIDI (temps réel).

-c nom_client

Nom du client ALSA ou JACK.

-i ports

Nombre de ports d'entrée.

-o ports

Nombre de ports de sortie.

-I connexions

Connexions des ports d'entrée. Expression régulière.

-O connexions

Connexions des ports de sortie. Expression régulière.

OPTIONS GÉNÉRALES

-d délai

Délai (en secondes) avant le début du traitement.

-t décalage

Décalage d'octave.

-z décalage

Décalage pour les numéros de port, de canal et de programme.

OPTIONS DE MODE

-f nom_fichier

Nom du fichier du script à exécuter.

-s

Shell interactif.

-S

Shell interactif avec exécution automatique des scripts.

-p

Affiche les événements MIDI. Aucun traitement n'est effectué.

VOIR AUSSI

Consultez la documentation en ligne sur https://mididings.github.io/mididings/ pour des informations à jour sur mididings et ses outils associés.

BOGUES

Des bogues ? Vous plaisantez ; il n'y a pas de bogues dans ce logiciel. Mais si nous nous trompions, soumettez un rapport de bogue avec autant de détails que possible à https://github.com/mididings/mididings/issues.
