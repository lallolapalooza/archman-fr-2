MINIUPNPC(3) Manuel des fonctions de bibliothèque MINIUPNPC(3)

NOM

miniupnpc - Bibliothèque client UPnP

SYNTAXE

DESCRIPTION

La bibliothèque miniupnpc implémente le protocole UPnP défini pour dialoguer avec les passerelles Internet (Internet Gateway Devices - IGD). Elle a également la capacité d'utiliser les données recueillies par minissdpd(1) sur les appareils UPnP présents sur le réseau afin de sauter le long processus de découverte des appareils UPnP.

Dans un premier temps, upnpDiscover(3) doit être utilisé pour découvrir les IGD UPnP présents sur le réseau. Ensuite, UPNP_GetValidIGD(3) permet de sélectionner le bon appareil. Alternativement, UPNP_GetIGDFromUrl(3) peut être utilisé pour contourner le processus de découverte si l'URL de description racine de l'appareil à utiliser est connue. Ensuite, toutes les fonctions UPNP_* peuvent être utilisées, telles que UPNP_GetConnectionTypeInfo(3), UPNP_AddPortMapping(3), etc...

FICHIERS HEADER

miniupnpc.h
C'est le fichier header principal pour l'API de la bibliothèque miniupnpc. Il contient toutes les fonctions et structures relatives à la découverte des appareils.
upnpcommands.h
Ce fichier header contient les méthodes UPnP IGD accessibles via l'API miniupnpc. Le nom des fonctions C correspond aux noms des méthodes UPnP. Par exemple : GetGenericPortMappingEntry est UPNP_GetGenericPortMappingEntry.

FONCTIONS API

struct UPNPDev * upnpDiscover(int delay, const char * multicastif, const char * minissdpdsock, int localport, int ipv6, int * error);
exécute le processus de découverte. `delay` (en milliseconde) est le temps maximum d'attente pour toute réponse d'appareil. Si disponible, la liste des appareils sera obtenue à partir de MiniSSDPd. Le chemin par défaut pour le socket de minissdpd sera utilisé si l'argument `minissdpdsock` est NULL. Si `multicastif` n'est pas NULL, il sera utilisé à la place de l'interface multicast par défaut pour envoyer les paquets de découverte SSDP. Si `localport` est réglé sur UPNP_LOCAL_PORT_SAME(1), les paquets SSDP seront envoyés depuis le port source 1900 (identique au port de destination), s'il est réglé sur UPNP_LOCAL_PORT_ANY(0), le système attribuera un port source, toute autre valeur sera tentée comme port source. Si `ipv6` n'est pas 0, l'IPv6 est utilisé à la place de l'IPv4 pour le processus de découverte.
void freeUPNPDevlist(struct UPNPDev * devlist);
libère la liste retournée par upnpDiscover().
int UPNP_GetValidIGD(struct UPNPDev * devlist, struct UPNPUrls * urls, struct IGDdatas * data, char * lanaddr, int lanaddrlen, char * wanaddr, int wanaddrlen);
parcourt la liste des appareils retournée par upnpDiscover(), trouve un appareil passerelle Internet UPnP actif et remplit les structures passées en argument avec les données utilisées pour l'invocation des méthodes UPNP.
int UPNP_GetIGDFromUrl(const char * rootdescurl, struct UPNPUrls * urls, struct IGDdatas * data, char * lanaddr, int lanaddrlen);
permet de contourner l'appel à upnpDiscover() si l'URL de description racine XML de l'IGD UPnP est connue. Remplit les structures passées en argument avec les données utilisées pour l'invocation des méthodes UPNP.
void GetUPNPUrls(struct UPNPUrls *, struct IGDdatas *, const char *);
void FreeUPNPUrls(struct UPNPUrls *);
