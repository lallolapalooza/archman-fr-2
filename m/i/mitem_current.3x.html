mitem_current(3X) Appels de bibliothèque mitem_current(3X)

NOM

mitem_current - définir et obtenir l'élément_courant_du_menu

SYNTAXE

#include <menu.h>
int set_current_item(MENU *menu, ITEM *item);
ITEM *current_item(const MENU *menu);
int set_top_row(MENU *menu, int row);
int top_row(const MENU *menu);
int item_index(const ITEM *item);

DESCRIPTION

La fonction set_current_item définit l'élément courant (l'élément sur lequel le curseur du menu est positionné). current_item renvoie un pointeur vers l'élément courant du menu donné.

La fonction set_top_row définit la ligne supérieure du menu pour afficher la ligne donnée (la ligne supérieure est initialement 0 et est réinitialisée à cette valeur chaque fois que l'option O_ROWMAJOR est basculée). L'élément le plus à gauche sur la ligne donnée devient l'élément courant. La fonction top_row renvoie le numéro de la ligne supérieure du menu affichée.

La fonction item_index renvoie l'indice (d'origine zéro) de item dans la liste des pointeurs d'éléments du menu.

VALEUR DE RETOUR

current_item renvoie un pointeur (qui peut être NULL). Elle ne définit pas errno.

top_row et item_index renvoient ERR (la valeur d'erreur générale de curses) si leur paramètre menu est NULL.

set_current_item et set_top_row renvoient l'une des valeurs suivantes :

E_OK
La routine a réussi.
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.
E_BAD_STATE
La routine a été appelée depuis une fonction d'initialisation ou de terminaison.
E_NOT_CONNECTED
Aucun élément n'est connecté au menu.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).

PORTABILITE

Ces routines émulent la bibliothèque de menus de System V. Elles n'étaient pas prises en charge sur les versions Version 7 ou BSD.

La documentation de la bibliothèque de menus SVr4 spécifie que la valeur d'erreur de top_row et index_item est -1 (qui est la valeur de ERR).
