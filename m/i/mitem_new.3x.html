mitem_new(3X) Appels de bibliothèque mitem_new(3X)

NOM

new_item, free_item - créer et détruire des éléments de menu

SYNTAXE

#include <menu.h>
ITEM *new_item(const char *name, const char *description);
int free_item(ITEM *item);

DESCRIPTION

La fonction new_item alloue un nouvel élément et l'initialise à partir des pointeurs name et description. Veuillez noter que l'élément ne stocke que les pointeurs vers le nom et la description. Ces pointeurs doivent être valides pendant la durée de vie de l'élément. Vous devez donc être très prudent avec les noms ou les descriptions alloués sur la pile de certaines routines.
La fonction free_item désalloue un élément. Veuillez noter qu'il est de la responsabilité de l'application de libérer la mémoire pour le nom ou la description de l'élément.

VALEUR DE RETOUR

La fonction new_item retourne NULL en cas d'erreur. Elle définit errno en fonction de l'échec de la fonction :

E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.
E_SYSTEM_ERROR
Une erreur système s'est produite, par exemple, échec de malloc.

La fonction free_item retourne l'une des valeurs suivantes :

E_OK
La routine a réussi.
E_BAD_ARGUMENT
La routine a détecté un argument incorrect ou hors limites.
E_CONNECTED
L'élément est connecté à un menu.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).

PORTABILITÉ

Ces routines émulent la bibliothèque de menus System V. Elles n'étaient pas prises en charge dans les versions Version 7 ou BSD.

AUTEURS
