NOM

mimeopen - Ouvrir des fichiers par type MIME

SYNTAXE

mimeopen [options] [-] fichiers

DESCRIPTION

Ce script tente de déterminer le type MIME d'un fichier et de l'ouvrir avec l'application de bureau par défaut. Si aucune application par défaut n'est configurée, l'utilisateur est invité à choisir dans un menu « ouvrir avec » dans le terminal.

Pour utiliser ce script, vous avez besoin de la base de données des informations MIME de freedesktop et du paquet File::MimeInfo::Applications(3). Voir File::MimeInfo::Applications(3) pour plus de détails.

OPTIONS

-a, --demander
Ne pas exécuter l'application par défaut mais demander quelle application lancer. Cela ne change pas l'application par défaut.
-d, --demander-par-defaut
Laisser l'utilisateur choisir un nouveau programme par défaut pour les fichiers donnés.
-n, --ne-pas-demander
Ne pas demander à l'utilisateur quel programme utiliser. Choisir le programme par défaut ou le premier programme connu pour gérer le type MIME du fichier. Cela ne définit pas l'application par défaut.
-M, --magique-seulement
Ne pas vérifier les extensions, les globes ou le type d'inode, regarder uniquement le contenu du fichier. Ceci est particulièrement utile si, pour une raison quelconque, vous n'avez pas confiance dans le nom ou l'extension d'un fichier.
--base-de-donnees=mimedir:mimedir:...
Forcer le programme à rechercher dans ces répertoires la base de données partagée des informations MIME. Les répertoires spécifiés par la spécification de base sont ignorés.
-D, --debug
Afficher des informations de débogage sur la manière dont le type MIME a été déterminé.
-h, --aide
-u, --utilisation
Afficher un message d'aide et quitter.
-v, --version
Afficher la version du programme et quitter.

OPTIONS OBSOLÈTES

-L, --suivre-liens
Suivre les liens symboliques. Obsolète car c'est le comportement par défaut logique pour cette commande. Ignoré silencieusement.

BOGUES

Si vous trouvez des bogues, veuillez les signaler sur notre traqueur de problèmes Github à https://github.com/mbeijen/File-MimeInfo/issues.

Voir File::MimeInfo::Applications(3) et File::DesktopEntry(3) pour certaines limitations.
