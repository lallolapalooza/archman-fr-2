NOM

mid3v2 - éditeur de tags audio similaire à 'id3v2'

SYNTAXE

mid3v2 [options] nom_de_fichier ...

DESCRIPTION

mid3v2 est un remplacement basé sur Mutagen pour id3v2 de id3lib. Il prend en charge les ID3v2.4 et plus de trames ; il n'a pas non plus les nombreux bugs qui affligent id3v2.

Ce programme existe principalement pour assurer la compatibilité avec les programmes qui souhaitent taguer des fichiers en utilisant id3v2. Pour une interface plus utilisable, nous recommandons Ex Falso.

OPTIONS

-q, --quiet
Silencieux : ne mentionne pas les opérations de fichier qui exécutent la requête de l'utilisateur. Les avertissements seront toujours affichés.
-v, --verbose
Verbeux : indique toutes les opérations effectuées. C'est l'inverse de --quiet. C'est le comportement par défaut.
-e, --escape
Active l'interprétation des échappements par antislash pour les valeurs de tags. Permet d'échapper le séparateur deux-points dans les valeurs TXXX, WXXX, COMM comme '\:' et d'insérer des séquences d'échappement comme '\n', '\t', etc.
-f, --list-frames
Affiche toutes les trames ID3v2.3/2.4 prises en charge et leurs significations.
-L, --list-genres
Liste tous les genres numériques ID3v1. Ceux-ci peuvent être utilisés pour définir des trames TCON, mais ce n'est pas recommandé.
-l, --list
Liste tous les tags dans les fichiers. Le format de sortie n'est *pas* le même que celui de id3v2 ; il est facilement analysable et lisible. Certains tags peuvent ne pas avoir de représentations lisibles par l'homme.
--list-raw
Liste tous les tags dans les fichiers, au format brut. Bien que ce format soit nominalement lisible par l'homme, il peut être très long si le tag contient des données binaires intégrées.
-d, --delete-v2
Supprime les tags ID3v2.
-s, --delete-v1
Supprime les tags ID3v1.
-D, --delete-all
Supprime tous les tags ID3.
--delete-frames=TRAMES
Supprime des trames ID3v2 spécifiques (ou des groupes de trames) des fichiers. TRAMES est une liste de noms de trames séparés par des virgules, par exemple "TPE1,TALB"
-C, --convert
Convertit les tags ID3v1 en tags ID3v2. Cela se produira également automatiquement lors de toute édition.
-a,--artist=ARTISTE
Définit les informations de l'artiste (TPE1).
-A,--album=ALBUM
Définit les informations de l'album (TALB).
-t,--song=TITRE
Définit les informations du titre (TIT2).
-c,--comment=<DESCRIPTION:COMMENTAIRE:LANGUE>
Définit un commentaire (COMM). La langue et la description peuvent être omises, auquel cas la langue par défaut est l'anglais et la description une chaîne vide.
-p,--picture=<NOM_FICHIER:DESCRIPTION:TYPE_IMAGE:TYPE_MIME>
Définit l'image jointe (APIC). Tout sauf le nom de fichier peut être omis, auquel cas les valeurs par défaut seront utilisées.
-g,--genre=GENRE
Définit les informations du genre (TCON).
-y,--year=<AAAA>, --date=<AAAA-[MM-JJ]>
Définit les informations de l'année/date (TDRC).
-T,--track=<NUM/NUM>
Définit le numéro de piste (TRCK).

Toute trame de texte ou d'URL (celles commençant par T ou W) peut être modifiée ou ajoutée en préfixant le nom de la trame avec "--". Par exemple, --TIT3 "Monkey!" définira la trame TIT3 (sous-titre) à Monkey!.

La trame TXXX a le format <DESCRIPTION:TEXTE> ; de nombreuses trames TXXX peuvent être définies dans le fichier tant qu'elles ont des clés différentes. Pour définir cette clé, séparez simplement le texte par un deux-points, par exemple --TXXX "ALBUMARTISTSORT:Exemples, Le". La description peut être omise, auquel cas elle prend par défaut une chaîne vide.

La trame WXXX a le même format que TXXX mais comme les URL contiennent généralement un ":", vous devez fournir une description ou activer l'échappement (-e) : --WXXX "desc:http://foo.bar" ou -e --WXXX "http\\://foo.bar"

La trame USLT a le format <DESCRIPTION:TEXTE:LANGUE>. La langue et la description peuvent être omises, auquel cas la langue par défaut est l'anglais et la description une chaîne vide.

La trame spéciale POPM peut être définie de manière similaire : --POPM "bob@example.com:128:2" pour définir la note de Bob à 128/255 avec 2 lectures.

BOGUES

Aucune vérification de validité n'est effectuée sur les opérations d'édition que vous effectuez, donc mid3v2 acceptera volontiers --TSIZ lors de l'édition d'une trame ID3v2.4. Cependant, elle sera également automatiquement rejetée lors de la prochaine opération d'édition.
