midid(1) Manuel des commandes générales midid(1)

NOM

midid - Interpréteur MIDI brut

SYNTAXE

midid [OPTIONS] [fichier_entree]

DESCRIPTION

Cette page de manuel documente brièvement la commande midid.

midid lit la STDIN ou le fichier_entree et l'interprète comme des données MIDI brutes conformément au standard General Midi.

Les données General Midi sont envoyées à un périphérique sonore (par défaut), à un fichier .MID, ou à timidity(1) si vous le spécifiez.

midid inclut un mode autonome pour timidity(1) : midid tentera alors de démarrer et de configurer timidity(1) lui-même pour vous.

OPTIONS

Options standard

-o secondes--timeout=secondes
Désactive la sortie après secondes d'inactivité. (par défaut : 0 - pas de délai d'attente)
-r,--resident
Reste résident ; ne s'arrête pas à la fin du fichier. Ne fonctionne que si fichier_entree n'est pas la STDIN.
-g,--emulate-gm
Sélectionne le mode GM (par défaut).
-m,--emulate-mt
Sélectionne le mode MT32.
-d périphérique,--device=périphérique
Liste des périphériques séparés par des virgules à utiliser pour la sortie.
-l,--list-devices
Liste les périphériques.
-h
Affiche un message d'aide.

Options pour le périphérique de sortie fichier .MID

-f,--file nom_fichier
Définit le nom_fichier de sortie .MID. Par défaut : midid.mid.
-t bpm,--tempo=bpm
Définit le tempo (battements par minute). Par défaut : 120.
-q taux_ticks,--tick-rate=taux_ticks
Définit le nombre de ticks par noire. Par défaut : 144.

Options pour le client timidity(1)

-s serveur,--server-name=serveur,
Définit le nom d'hôte du serveur timidity(1). Par défaut : localhost.
-p port,--port=port
Définit le port de contrôle du serveur timidity(1). Par défaut : 0. Spécifier 0 active le mode autonome : midid tentera de démarrer et de configurer timidity(1) lui-même.

Options pour l'utilisation du mode autonome avec timidity(1)

-B chemin,--timidity-bin=chemin
Définit le chemin de l'exécutable timidity.
-A args,--timidity-args=args
Spécifie des arguments supplémentaires à passer à timidity(1). Par défaut :  -EFreverb=0 -EFchorus=0 -EFresamp=1 -EFvlpf=0 -EFns=0.
-M,--timidity-mono
Indique à timidity(1) de produire un son mono au lieu de stéréo.
-L,--timidity-low
Indique à timidity(1) de produire un son 8 bits de faible qualité au lieu de 16 bits.
-U,--timidity-uns
Indique à timidity(1) de produire des échantillons non signés au lieu de signés.
-F taux,--timidity-freq=taux
Définit le taux d'échantillonnage pour timidity(1).
-C,--timidity-capture
Active le mode capture : les données produites par timidity(1) sont capturées par midid et transmises à la sortie standard. Vous n'entendrez aucun son dans ce mode.

VOIR AUSSI
