NOM

misc_conv - fonction de conversation basée sur du texte

SYNOPSIS

#include <security/pam_misc.h>

int misc_conv(int num_msg, const struct pam_message **msgm, struct pam_response **response, void *appdata_ptr);

DESCRIPTION

La fonction misc_conv fait partie de libpam_misc et non de la bibliothèque standard libpam. Cette fonction sollicitera l'utilisateur avec les commentaires appropriés et obtiendra les entrées appropriées comme dirigé par les modules d'authentification.

En plus de s'intégrer simplement dans la fonction pam_conv(3) appropriée, cette fonction fournit certaines facultés de délai d'attente. La fonction exporte cinq variables qui peuvent être utilisées par un programmeur d'application pour limiter le temps pendant lequel cette fonction de conversation passera à attendre que l'utilisateur tape quelque chose. Les cinq variables sont les suivantes :

time_t pam_misc_conv_warn_time;

Cette variable contient le temps (tel que retourné par time(2)) où l'utilisateur devrait être averti pour la première fois que l'horloge tourne. Par défaut, elle a la valeur 0, ce qui indique qu'aucun avertissement de ce type ne sera donné. L'application peut définir sa valeur à un moment dans le futur, mais cela doit être fait avant de passer le contrôle à la bibliothèque Linux-PAM.

const char *pam_misc_conv_warn_line;

Utilisée en conjonction avec pam_misc_conv_warn_time, cette variable est un pointeur vers la chaîne qui sera affichée lorsqu'il sera temps d'avertir l'utilisateur que le délai d'attente approche. Sa valeur par défaut est une version traduite de “...Le temps presse...”, mais cela peut être modifié par l'application avant de passer le contrôle à Linux-PAM.

time_t pam_misc_conv_die_time;

Cette variable contient le temps (tel que retourné par time(2)) où l'attente expirera. Par défaut, elle a la valeur 0, ce qui indique que la fonction de conversation n'expirera pas. L'application peut définir sa valeur à un moment dans le futur, mais cela doit être fait avant de passer le contrôle à la bibliothèque Linux-PAM.

const char *pam_misc_conv_die_line;

Utilisée en conjonction avec pam_misc_conv_die_time, cette variable est un pointeur vers la chaîne qui sera affichée lorsque la conversation expirera. Sa valeur par défaut est une version traduite de “...Désolé, votre temps est écoulé !”, mais cela peut être modifié par l'application avant de passer le contrôle à Linux-PAM.

int pam_misc_conv_died;

Suite à un retour de la bibliothèque Linux-PAM, la valeur de cette variable indique si la conversation a expiré. Une valeur de 1 indique que le délai d'attente s'est produit.

Les deux pointeurs de fonction suivants sont disponibles pour prendre en charge les invites binaires dans la fonction de conversation. Ils sont optimisés pour l'incarnation actuelle de la bibliothèque libpamc et sont sujets à modification.

int (*pam_binary_handler_fn)(void *appdata, pamc_bp_t *prompt_p);

Ce pointeur de fonction est initialisé à NULL mais peut être rempli avec une fonction qui fournit un échange de messages machine à machine (caché). Il est destiné à être utilisé avec des protocoles d'authentification cachés tels que les échanges de clés RSA ou Diffie-Hellman. (Ceci est encore en développement.)

int (*pam_binary_handler_free)(void *appdata, pamc_bp_t *delete_me);

Ce pointeur de fonction est initialisé à PAM_BP_RENEW(delete_me, 0, 0), mais peut être redéfini comme souhaité par l'application.

VOIR AUSSI

pam_conv(3), pam(8)

NORMES

La fonction misc_conv fait partie de la bibliothèque libpam_misc et n'est définie dans aucune norme.
