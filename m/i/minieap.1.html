minieap(1) Manuel des commandes générales minieap(1)

NOM

minieap - Client 802.1x extensible avec support Ruijie v3/v4

SYNTAXE

minieap [OPTIONS...]

DESCRIPTION

minieap peut être utilisé comme supplicant pour des méthodes d'authentification 802.1x modifiées comme Ruijie.

OPTIONS

--help, -h
afficher l'aide
--kill, -k [0|...]
tuer les autres instances et quitter. Les arguments autres que 0 signifient de tuer les autres instances et de continuer à fonctionner.
--save, -w
sauvegarder la configuration actuelle
--username, -u <nom d'utilisateur>
nom d'utilisateur
--password, -p <nom d'utilisateur>
mot de passe
--nic, -n <interface>
interface réseau
--stage-timeout, -t <secondes>
délai d'attente pour chaque authentification [défaut 5]
--wait-after-fail, -r <secondes>
temps d'attente après un échec (mais commencera immédiatement si le serveur le demande) [défaut 30]
--max-fail, -l <nombre>
nombre maximum d'échecs [défaut 3]
--no-auto-reauth, -x
ne pas réessayer après déconnexion [défaut oui]
--daemonize, -b <0-3>
0 = exécuter en premier plan
1 = exécuter en tant que démon, sans sortie
2 = exécuter en tant que démon, sortie vers la console
3 = exécuter en tant que démon, sortie vers le log
[défaut 0]
--proxy-lan-iface, -z <interface>
l'interface LAN si authentification via proxy [défaut aucune]
--auth-round, -j <compte>
nombre de fois nécessaires pour authentifier [défaut 1]
--max-retries <compte>
nombre maximum de nouvelles tentatives [défaut 3]
--pid-file <fichier pid>
définir sur none pour désactiver [défaut /var/run/minieap.pid]
--conf-file <fichier conf>
fichier de configuration [défaut /etc/minieap.conf]
--if-impl <module>
choisir le module réseau. L'option ne peut être utilisée qu'une seule fois. [défaut le premier disponible]
--pkt-plugin <plugin>
activer le modificateur de paquet correspondant. L'option peut être utilisée plusieurs fois. [défaut aucun]
--module <module>
activer le module correspondant. L'option peut être utilisée plusieurs fois.

Si vous utilisez --module ou --pkt-plugin en ligne de commande, toutes les lignes du fichier de configuration contenant "module=" seront ignorées.

Modules réseau disponibles

sockraw
un module utilisant un Socket RAW

Modificateur de paquet disponible

printer
imprimer tous les paquets qui le traversent
rjv3
utiliser l'algorithme d'authentification de hyrathb@GitHub Ruijie V3
--heartbeat, -e <secondes>
secondes entre les paquets [défaut 60]
--eap-bcast-addr, -a <0-1>
adresse de diffusion du paquet de démarrage [défaut BROADCAST_STANDARD] 0 = standard, 1 = adresse de ruijie
--dhcp-type, -d <0-3>
méthodes DHCP [défaut HCP_AFTER_AUTH]
0 = ne pas utiliser DHCP
1 = authentification secondaire
2 = DHCP post-authentification
3 = DHCP pré-authentification
--dhcp-script, -c <script>
exécuter un script entre l'authentification secondaire et le DHCP post-authentification [défaut aucun]
--rj-option <type>:<valeur>[:r]
personnaliser les sections, le type et la valeur doivent être en hexadécimal.

Par exemple, --rj-option 6a:000102 signifie ajouter une section de type 0x6a, avec le contenu 0x00 0x01 0x02 .

:r signifie remplacer le contenu par défaut généré par ce programme. Par exemple, --rj-option 6f:000102:r signifie remplacer le contenu de type 0x6f par 0x00 0x12 0x02 .

Si la ligne de commande et le fichier de configuration ont tous deux cette option, les deux configurations fonctionneront.

--service <service>
personnaliser le nom du service [défaut internet]
--version-str <version>
personnaliser la chaîne de version [défaut RG-SU For Linux V1.0]
--fake-dns1 <DNS>
personnaliser l'adresse DNS principale (IPv4 en notation décimale pointée) [obtiendra une adresse par défaut]
--fake-dns2 <DNS>
personnaliser l'adresse DNS secondaire (IPv4/IPv6)
--fake-serial <serial>
personnaliser le numéro de série du disque dur [obtiendra un numéro par défaut]
--max-dhcp-count <compte>
le nombre de délais autorisés en attendant le DHCP lors de l'authentification secondaire [défaut 3]
