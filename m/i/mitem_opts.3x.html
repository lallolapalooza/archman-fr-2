mitem_opts(3X) Appels de bibliothèque mitem_opts(3X)

NOM

set_item_opts, item_opts_on, item_opts_off, item_opts - définir et obtenir les options d'un élément de menu

SYNTAXE

#include <menu.h>
int set_item_opts(ITEM *item, Item_Options opts);
Item_Options item_opts(const ITEM *item);
int item_opts_on(ITEM *item, Item_Options opts);
int item_opts_off(ITEM *item, Item_Options opts);

DESCRIPTION

La fonction set_item_opts définit tous les bits d'option de l'élément donné (les bits d'option de menu peuvent être combinés logiquement avec un OU).

La fonction item_opts_on active les bits d'option donnés et laisse les autres inchangés.

La fonction item_opts_off désactive les bits d'option donnés et laisse les autres inchangés.

La fonction item_opts retourne les bits d'option actuels de l'élément.

Il n'existe qu'un seul masque d'option défini, O_SELECTABLE. Lorsqu'il est activé, l'élément peut être sélectionné pendant le traitement du menu. Cette option est activée par défaut.

VALEUR DE RETOUR

À l'exception de item_opts, chaque routine retourne l'une des valeurs suivantes :

E_OK
La routine a réussi.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).

PORTABILITÉ

Ces routines émulent la bibliothèque de menus System V. Elles n'étaient pas prises en charge sur les versions 7 ou BSD.

AUTEURS

Juergen Pfeifer. Pages de manuel et adaptation pour le nouveau curses par Eric S. Raymond.
