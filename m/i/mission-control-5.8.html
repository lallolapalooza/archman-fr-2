MISSION-CONTROL-5(8) Services D-Bus MISSION-CONTROL-5(8)

NOM

mission-control-5 - Gestionnaire de compte/répartiteur de canaux Telepathy

SYNTAXE

/usr/lib/telepathy/mission-control-5

DESCRIPTION

Mission Control 5 implémente les services AccountManager et ChannelDispatcher décrits dans la spécification Telepathy D-Bus, permettant aux clients tels que empathy(1) de stocker les détails du compte, de se connecter aux comptes, de demander des canaux de communication et de faire répartir ces canaux vers eux.

C'est un service D-Bus qui s'exécute sur le bus de session, et devrait généralement être démarré automatiquement par l'activation D-Bus. Cependant, il peut être utile de le démarrer manuellement pour le débogage.

OPTIONS

Il n'y a pas d'options en ligne de commande.

ENVIRONNEMENT

MC_DEBUG=all ou MC_DEBUG=catégorie[,catégorie...]
Peut être défini sur "all" pour une sortie de débogage complète de Mission Control et telepathy-glib, ou diverses catégories non documentées (qui peuvent changer d'une version à l'autre) pour filtrer la sortie. Voir le code source de Mission Control et telepathy-glib pour les catégories disponibles.
MC_DEBUG=niveau
Définit un niveau de débogage numérique pour Mission Control lui-même (mais pas pour telepathy-glib). Le niveau 0 ne journalise rien, le niveau 1 journalise la plupart des messages, et le niveau 2 journalise tous les messages.
MC_TP_DEBUG=type
Peut être défini sur "all" pour une sortie de débogage complète de telepathy-glib, ou diverses options non documentées (qui peuvent changer d'une version à l'autre de telepathy-glib) pour filtrer la sortie. Voir le code source de telepathy-glib pour les options disponibles.
