mitem_value(3X) Appels de bibliothèque mitem_value(3X)

NOM

set_item_value, item_value - définir et obtenir les valeurs des éléments de menu

SYNTAXE

#include <menu.h>
int set_item_value(ITEM *item, bool value);
bool item_value(const ITEM *item);

DESCRIPTION

Si vous désactivez l'option de menu O_ONEVALUE (par exemple, avec set_menu_opts ou menu_opts_off ; voir menu_opts(3X)), le menu devient multi-valeur ; c'est-à-dire que plusieurs éléments peuvent être sélectionnés simultanément.

Dans un menu multi-valeur, vous pouvez utiliser set_item_value pour sélectionner l'élément de menu donné (deuxième argument TRUE) ou le désélectionner (deuxième argument FALSE).

VALEUR DE RETOUR

La fonction set_item_value retourne l'une des valeurs suivantes :

E_OK
La routine a réussi.
E_SYSTEM_ERROR
Une erreur système s'est produite (voir errno(3)).
E_REQUEST_DENIED
Le pilote de menu n'a pas pu traiter la demande.

PORTABILITÉ

Ces routines émulent la bibliothèque de menus de System V. Elles n'étaient pas prises en charge sur les versions 7 ou BSD.

AUTEURS
