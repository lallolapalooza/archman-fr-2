NOM

miniupnpd - Démon de passerelle de périphérique UPnP

SYNTAXE

miniupnpd [--version] [-f fichier_config] [-i nom_interface_ext] [-I nom_interface_ext6] [-o ip_ext] [-a ip_ecoute] [-p port] [-d] [-U] [-S0] [-N] [-u uuid] [-s serial] [-m numero_modele] [-t intervalle_notification] [-P nom_fichier_pid] [-B bas haut] [-w url] [-r intervalle_nettoyage_regles] [-A regle_permission] [-b BOOTID] [-1]

DESCRIPTION

miniupnpd agit comme une passerelle de périphérique UPnP. Il est conçu pour s'exécuter sur la passerelle entre Internet et un réseau local NAT. Il fournit une interface, telle que définie par la norme UPnP, permettant aux clients du réseau local de demander des redirections de port.

OPTIONS

-f fichier_config
charge la configuration depuis le fichier.
-i nom_interface_ext
interface utilisée pour se connecter à Internet.
-o ip_ext
adresse utilisée pour se connecter à Internet. L'adresse par défaut de l'interface sera utilisée si elle n'est pas spécifiée.
-a ip_ecoute
adresse sur le réseau local. L'option -a peut être utilisée plusieurs fois si le réseau local est subdivisé en plusieurs sous-réseaux.
-p port
port utilisé pour HTTP.
-d
mode débogage : ne pas passer en arrière-plan, afficher les messages sur la console et ne pas filtrer les messages de faible priorité.
-U
rapporte le temps de fonctionnement du système au lieu du temps de fonctionnement du démon aux clients.
-S0
désactive le mode "sécurisé" afin que les clients ne puissent ajouter des mappages qu'à d'autres adresses IP.
-N
active les fonctionnalités NAT-PMP et PCP.
-u uuid
définit l'UUID de la passerelle de périphérique UPnP.
-s serial
numéro de série de la passerelle de périphérique UPnP.
-m numero_modele
numéro de modèle de la passerelle de périphérique UPnP.
-t intervalle_notification
intervalle de notification SSDP en secondes. Par défaut, 900 secondes. Les messages d'annonce SSDP seront diffusés à cet intervalle.
-P nom_fichier_pid
fichier PID. Par défaut, /var/run/miniupnpd.pid
-B bas haut
débits de téléchargement et d'envoi rapportés aux clients.
-w url
URL de présentation. Par défaut, la première adresse sur le réseau local, port 80.
-r intervalle_nettoyage_regles
intervalle (minimum) entre les vérifications de nettoyage des règles inutilisées.
-A regle_permission
utilise la syntaxe suivante pour les règles de permission :
(allow|deny) (plage de ports externes) ip/masque (plage de ports internes)
exemples :
"allow 1024-65535 192.168.1.0/24 1024-65535"
"deny 0-65535 0.0.0.0/0 0-65535"
-b BOOTID
définit la valeur de l'en-tête SSDP BOOTID.UPNP.ORG
-1
force le rapport d'IGDv1 dans rootDesc lorsqu'il est compilé comme IGDv2 *à utiliser avec prudence*
