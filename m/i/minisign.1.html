NOM

minisign - Un outil ultra-simple pour signer des fichiers et vérifier des signatures.

SYNTAXE

minisign -G [-p pubkey_file] [-s seckey_file] [-W]

minisign -R [-s seckey_file] [-p pubkey_file]

minisign -C [-s seckey_file] [-W]

minisign -S [-H] [-x sig_file] [-s seckey_file] [-c untrusted_comment] [-t trusted_comment] -m file [file ...]

minisign -V [-x sig_file] [-p pubkey_file | -P pubkey] [-o] [-q] -m file

DESCRIPTION

Minisign est un outil extrêmement simple pour signer des fichiers et vérifier des signatures.

Il est portable, léger et utilise le système de signature à clé publique hautement sécurisé Ed25519 http://ed25519.cr.yp.to/.

OPTIONS

Ces options contrôlent les actions de minisign.

-G
Générer une nouvelle paire de clés.
-C
Changer/supprimer le mot de passe d'une clé secrète.
-R
Recréer un fichier de clé publique à partir d'un fichier de clé secrète.
-S
Signer des fichiers.
-V
Vérifier qu'une signature est valide pour un fichier donné.
-H
Exige que l'entrée soit pré-hachée.
-l
Signer en utilisant le format hérité.
-m <fichier>
Fichier à signer/vérifier.
-o
Combiné avec -V, affiche le contenu du fichier après vérification.
-p <fichier_cle_publique>
Fichier de clé publique (par défaut : ./minisign.pub).
-P <cle_publique>
Clé publique, sous forme de chaîne base64.
-s <fichier_cle_secrete>
Fichier de clé secrète (par défaut : ~/.minisign/minisign.key).
-W
Ne pas chiffrer/déchiffrer la clé secrète avec un mot de passe.
-x <fichier_signature>
Fichier de signature (par défaut : <fichier>.minisig).
-c <commentaire>
Ajouter un commentaire d'une ligne non fiable.
-t <commentaire>
Ajouter un commentaire d'une ligne fiable.
-q
Mode silencieux, supprime la sortie.
-Q
Mode quasi-silencieux, n'affiche que le commentaire fiable.
-f
Forcer. Combiné avec -G, écrase une paire de clés précédente.
-v
Afficher le numéro de version.

EXEMPLES

Création d'une paire de clés

minisign -G

La clé publique est affichée et placée dans le fichier minisign.pub. La clé secrète est chiffrée et enregistrée dans un fichier nommé ~/.minisign/minisign.key.

Signature de fichiers

$ minisign -Sm myfile.txt $ minisign -Sm myfile.txt myfile2.txt *.c

Ou pour inclure un commentaire dans la signature, qui sera vérifié et affiché lors de la vérification du fichier :

$ minisign -Sm myfile.txt -t ´Ce commentaire sera également signé´

La clé secrète est chargée depuis ${MINISIGN_CONFIG_DIR}/minisign.key, ~/.minisign/minisign.key, ou son chemin peut être explicitement défini avec le commutateur de ligne de commande -s <chemin>.

Vérification d'un fichier

$ minisign -Vm myfile.txt -P <cle_publique>

ou

$ minisign -Vm myfile.txt -p signature.pub

Cela nécessite que la signature myfile.txt.minisig soit présente dans le même répertoire.

La clé publique peut soit résider dans un fichier (./minisign.pub par défaut), soit être directement spécifiée sur la ligne de commande.

Notes

Les fichiers de signature incluent une ligne de commentaire non fiable qui peut être modifiée librement, même après la création de la signature.

Ils incluent également une deuxième ligne de commentaire, qui ne peut pas être modifiée sans la clé secrète.

Les commentaires fiables peuvent être utilisés pour ajouter des instructions ou des métadonnées spécifiques à l'application (nom de fichier prévu, horodatages, identifiants de ressources, numéros de version pour éviter les attaques par dégradation).
