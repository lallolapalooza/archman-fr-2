miniserve(1) Manuel des commandes générales miniserve(1)

NOM

miniserve - Quand vous voulez vraiment servir des fichiers via HTTP maintenant !

SYNTAXE

miniserve [-v|--verbose] [--temp-directory] [--index] [--spa] [--pretty-urls] [-p|--port] [-i|--interfaces] [-a|--auth] [--auth-file] [--route-prefix] [--random-route] [-P|--no-symlinks] [-H|--hidden] [-S|--default-sorting-method] [-O|--default-sorting-order] [-c|--color-scheme] [-d|--color-scheme-dark] [-q|--qrcode] [-u|--upload-files] [--web-upload-files-concurrency] [--chmod] [--directory-size] [-U|--mkdir] [-m|--media-type] [-M|--raw-media-type] [-o|--on-duplicate-files] [-R|--rm-files] [-r|--enable-tar] [-g|--enable-tar-gz] [-z|--enable-zip] [-C|--compress-response] [-D|--dirs-first] [-t|--title] [--header] [-l|--show-symlink-info] [-F|--hide-version-footer] [--hide-theme-selector] [-W|--show-wget-footer] [--print-completions] [--print-manpage] [--tls-cert] [--tls-key] [--readme] [-I|--disable-indexing] [--enable-webdav] [--size-display] [--file-external-url] [-h|--help] [-V|--version] [CHEMIN]

DESCRIPTION

Quand vous voulez vraiment servir des fichiers via HTTP maintenant !

OPTIONS

-v, --verbose
Soyez verbeux, inclut l'émission des logs d'accès
Peut également être spécifié avec la variable d'environnement MINISERVE_VERBOSE.
--temp-directory <CHEMIN_TEMPORAIRE>
Le chemin vers l'emplacement où les fichiers téléchargés seront écrits avant d'être déplacés vers leur emplacement correct. Il est conseillé de s'assurer que ce répertoire sera écrit sur le disque et non en mémoire.

Cette valeur ne sera utilisée **QUE SI** le téléchargement de fichiers est activé. Si cette option n'est pas définie, le répertoire temporaire par défaut du système d'exploitation sera utilisé.

Peut également être spécifié avec la variable d'environnement MINISERVER_TEMP_UPLOAD_DIRECTORY.
--index <INDEX>
Le nom d'un fichier d'index de répertoire à servir, comme "index.html"

Normalement, lorsque miniserve sert un répertoire, il crée une liste de ce répertoire. Cependant, si un répertoire contient ce fichier, miniserve servira ce fichier à la place.

Peut également être spécifié avec la variable d'environnement MINISERVE_INDEX.
--spa
Activer le mode SPA (Single Page Application)

Cela fera servir le fichier donné par --index pour tous les chemins de fichiers inexistants. En effet, cela servira le fichier index chaque fois qu'une 404 se produirait autrement, afin de permettre au routeur SPA de gérer la requête.

Peut également être spécifié avec la variable d'environnement MINISERVE_SPA.
--pretty-urls
Activer le mode Pretty URLs

Cela fera servir par le serveur le fichier `.html` équivalent indiqué par le chemin.

`/about` essaiera de trouver `about.html` et de le servir.

Peut également être spécifié avec la variable d'environnement MINISERVE_PRETTY_URLS.
-p, --port <PORT> [défaut : 8080]
Port à utiliser
Peut également être spécifié avec la variable d'environnement MINISERVE_PORT.
-i, --interfaces <INTERFACES>
Interface sur laquelle écouter
Peut également être spécifié avec la variable d'environnement MINISERVE_INTERFACE.
-a, --auth <AUTH>
Définir l'authentification

Formats actuellement supportés : username:password, username:sha256:hash, username:sha512:hash (ex: joe:123, joe:sha256:a665a45920422f9d417e4867efdc4fb8a04a1f3fff1fa07e998e86f7f7a27ae3)

Peut également être spécifié avec la variable d'environnement MINISERVE_AUTH.
--auth-file <FICHIER_AUTH>
Lire les valeurs d'authentification à partir d'un fichier

Exemple de contenu de fichier :

joe:123 bob:sha256:a665a45920422f9d417e4867efdc4fb8a04a1f3fff1fa07e998e86f7f7a27ae3 bill:

Peut également être spécifié avec la variable d'environnement MINISERVE_AUTH_FILE.
--route-prefix <PREFIXE_ROUTE>
Utiliser un préfixe de route spécifique
Peut également être spécifié avec la variable d'environnement MINISERVE_ROUTE_PREFIX.
--random-route
Générer une route aléatoire de 6 chiffres hexadécimaux
Peut également être spécifié avec la variable d'environnement MINISERVE_RANDOM_ROUTE.
-P, --no-symlinks
Masquer les liens symboliques dans la liste et les empêcher d'être suivis
Peut également être spécifié avec la variable d'environnement MINISERVE_NO_SYMLINKS.
-H, --hidden
Afficher les fichiers cachés
Peut également être spécifié avec la variable d'environnement MINISERVE_HIDDEN.
-S, --default-sorting-method <METHODE_TRI_DEFAUT> [défaut : name]
Méthode de tri par défaut pour la liste de fichiers

Valeurs possibles :

  • name : Trier par nom
  • size : Trier par taille
  • date : Trier par date de dernière modification (tri naturel : suit l'ordre alphanumérique)
Peut également être spécifié avec la variable d'environnement MINISERVE_DEFAULT_SORTING_METHOD.
-O, --default-sorting-order <ORDRE_TRI_DEFAUT> [défaut : desc]
Ordre de tri par défaut pour la liste de fichiers

Valeurs possibles :

  • asc : Ordre ascendant
  • desc : Ordre descendant
Peut également être spécifié avec la variable d'environnement MINISERVE_DEFAULT_SORTING_ORDER.
-c, --color-scheme <SCHEMA_COULEUR> [défaut : squirrel]
Schéma de couleur par défaut

[valeurs possibles : squirrel, archlinux, zenburn, monokai]

Peut également être spécifié avec la variable d'environnement MINISERVE_COLOR_SCHEME.
-d, --color-scheme-dark <SCHEMA_COULEUR_FOND_FONCE> [défaut : archlinux]
Schéma de couleur par défaut

[valeurs possibles : squirrel, archlinux, zenburn, monokai]

Peut également être spécifié avec la variable d'environnement MINISERVE_COLOR_SCHEME_DARK.
-q, --qrcode
Activer l'affichage du code QR
Peut également être spécifié avec la variable d'environnement MINISERVE_QRCODE.
-u, --upload-files [<REPERTOIRE_TELECHARGEMENT_AUTORISE>]
Activer le téléchargement de fichiers (et éventuellement spécifier pour quel répertoire)

Le chemin fourni n'est pas un chemin physique du système de fichiers. Ins

tead, il est relatif au répertoire de service (`serve dir`). Par exemple, si le répertoire de service est '/home/hello', définissez ceci sur '/upload' pour autoriser les téléversements vers '/home/hello/upload'. Lorsqu'il est spécifié via une variable d'environnement, un chemin doit toujours être spécifié.

Peut également être spécifié avec la variable d'environnement MINISERVE_ALLOWED_UPLOAD_DIR.
--web-upload-files-concurrency <WEB_UPLOAD_CONCURRENCY> [défaut : 0]
Configure le nombre de téléversements simultanés lors de la visite du site web. L'option `upload-files` doit être activée pour que ce paramètre soit pris en compte.

Par exemple, une valeur de 4 signifierait que le navigateur web ne téléversera que 4 fichiers à la fois vers le serveur web lors de l'utilisation de l'interface du navigateur web.

Lorsque la valeur est conservée à 0, il tente de résoudre tous les téléversements simultanément dans le navigateur web.

NOTE : Les pages web ont une limite quant au nombre de connexions HTTP actives qu'elles peuvent établir simultanément, donc même si vous définissez une limite de concurrence de 100, le navigateur ne fera progresser que le nombre maximum de connexions que la page web peut avoir ouvertes.

Peut également être spécifié avec la variable d'environnement MINISERVE_WEB_UPLOAD_CONCURRENCY.
--chmod <CHMOD>
Définit les permissions Unix des fichiers téléversés.

Ceci prend un nombre octal, par exemple 0600. Par défaut, 0666 & ~umask est utilisé pour simuler le comportement par défaut du système.

Peut également être spécifié avec la variable d'environnement MINISERVE_CHMOD.
--directory-size
Active le calcul récursif de la taille des répertoires.

Ceci est désactivé par défaut car il s'agit d'une opération potentiellement très intensive en termes d'E/S.

Peut également être spécifié avec la variable d'environnement MINISERVE_DIRECTORY_SIZE.
-U, --mkdir
Active la création de répertoires.
Peut également être spécifié avec la variable d'environnement MINISERVE_MKDIR_ENABLED.
-m, --media-type <MEDIA_TYPE>
Spécifie les types de médias téléversables.

[valeurs possibles : image, audio, video]

Peut également être spécifié avec la variable d'environnement MINISERVE_MEDIA_TYPE.
-M, --raw-media-type <MEDIA_TYPE_RAW>
Spécifie directement l'expression du type de média téléversable.
Peut également être spécifié avec la variable d'environnement MINISERVE_RAW_MEDIA_TYPE.
-o, --on-duplicate-files <ON_DUPLICATE_FILES> [défaut : error]
Que faire si des fichiers existants du même nom sont présents lors du téléversement de fichiers.

Si vous activez le renommage de fichiers, le renommage se fera en ajoutant un suffixe numérique au nom du fichier avant l'extension finale. Par exemple, `file.txt` sera téléversé sous `file-1.txt`, le numéro sera incrémenté jusqu'à ce qu'un nom de fichier disponible soit trouvé.

[valeurs possibles : error, overwrite, rename]

Peut également être spécifié avec la variable d'environnement MINISERVE_ON_DUPLICATE_FILES.
-R, --rm-files [<ALLOWED_RM_DIR>]
Active la suppression de fichiers et de répertoires (et spécifie facultativement pour quel répertoire).
Peut également être spécifié avec la variable d'environnement MINISERVE_ALLOWED_RM_DIR.
-r, --enable-tar
Active la génération d'archives tar non compressées.
Peut également être spécifié avec la variable d'environnement MINISERVE_ENABLE_TAR.
-g, --enable-tar-gz
Active la génération d'archives tar compressées par gz.
Peut également être spécifié avec la variable d'environnement MINISERVE_ENABLE_TAR_GZ.
-z, --enable-zip
Active la génération d'archives zip.

ATTENTION : La compression de grands répertoires en zip peut entraîner une exception de manque de mémoire car la génération du zip se fait en mémoire et ne peut pas être envoyée à la volée.

Peut également être spécifié avec la variable d'environnement MINISERVE_ENABLE_ZIP.
-C, --compress-response
Compresse la réponse.

ATTENTION : L'activation de cette option peut ralentir les transferts en raison de la surcharge CPU, elle est donc désactivée par défaut.

N'activez cette option que si vous savez que vos utilisateurs ont des connexions lentes ou si vous souhaitez minimiser l'utilisation de bande passante de votre serveur.

Peut également être spécifié avec la variable d'environnement MINISERVE_COMPRESS_RESPONSE.
-D, --dirs-first
Liste les répertoires en premier.
Peut également être spécifié avec la variable d'environnement MINISERVE_DIRS_FIRST.
-t, --title <TITLE>
Affiché à la place de l'hôte dans le titre et l'en-tête de la page.
Peut également être spécifié avec la variable d'environnement MINISERVE_TITLE.
--header <HEADER>
Insère des en-têtes personnalisés dans les réponses. Spécifiez chaque en-tête comme une paire 'Header:Valeur'. Ce paramètre peut être utilisé plusieurs fois pour ajouter plusieurs en-têtes.

Exemple : --header ""En-tête1:Valeur1"" --header ""En-tête2:Valeur2"" (Si un en-tête est déjà défini ou précédemment inséré, il ne sera pas écrasé.)

Peut également être spécifié avec la variable d'environnement MINISERVE_HEADER.
-l, --show-symlink-info
Visualise les liens symboliques dans la liste des répertoires.
Peut également être spécifié avec la variable d'environnement MINISERVE_SHOW_SYMLINK_INFO.
-F, --hide-version-footer
Masque le pied de page de version.
Peut également être spécifié avec la variable d'environnement MINISERVE_HIDE_VERSION_FOOTER.
--hide-theme-selector
Masque le sélecteur de thème.
Peut également être spécifié avec la variable d'environnement MINISERVE_HIDE_THEME_SELECTOR.
-W, --show-wget-footer
Si activé, affiche une commande wget pour télécharger récursivement le répertoire courant.
Peut également être spécifié avec la variable d'environnement MINISERVE_SHOW_WGET_FOOTER.
--print-completions <shell>
Génère un fichier de complétion pour un shell.

[valeurs possibles : bash, elvish, fish, powershell, zsh]

--print-manpage
Génère la page de manuel.
--tls-cert <TLS_CERT>
Certificat TLS à utiliser.
Peut également être spécifié avec la variable d'environnement MINISERVE_TLS_CERT.
--tls-key <TLS_KEY>
Clé privée TLS à utiliser.
Peut également être spécifié avec la variable d'environnement MINISERVE_TLS_KEY.
--readme
Active le rendu de README.md dans les répertoires.
Peut également être spécifié avec la variable d'environnement MINISERVE_README.
-I, --disable-indexing
Désactive l'indexation.

Cela empêchera la génération des listes de répertoires et renverra une erreur à la place.

Peut également être spécifié avec la variable d'environnement MINISERVE_DISABLE_INDEXING.
--enable-webdav
Active le support WebDAV en lecture seule (requêtes PROPFIND).
Peut également être spécifié avec la variable d'environnement MINISERVE_ENABLE_WEBDAV.
--size-display <SIZE_DISPLAY> [défaut : human]
Affiche la taille du fichier servi en octets exacts.

[valeurs possibles : human, exact]

Peut également être spécifié avec la variable d'environnement MINISERVE_SIZE_DISPLAY.
--file-external-url <FILE_EXTERNAL_URL>
URL externe facultative (par exemple, 'http://external.example.com:8081') précédant les liens de fichiers dans les listes.

Permet de servir des fichiers depuis une URL différente de celle de l'instance de navigation. Utile pour des configurations comme : une instance authentifiée pour la navigation, reliant des fichiers (via cette option) à une seconde instance, non indexée (-I), pour des téléchargements directs. Cela masque la liste complète des fichiers sur le serveur de téléchargement, tandis que les utilisateurs peuvent toujours copier des URL de fichiers directes pour les partager. L'URL externe est placée telle quelle devant l'emplacement relatif du fichier, y compris le protocole. L'utilisateur doit s'assurer que cela résulte en une URL valide, aucune vérification supplémentaire n'est effectuée.

Peut également être spécifié avec la variable d'environnement MINISERVE_FILE_EXTERNAL_URL.
-h, --help
Affiche l'aide (voir un résumé avec '-h').
-V, --version
Affiche la version.
[PATH]
Quel chemin servir.
Peut également être spécifié avec la variable d'environnement MINISERVE_PATH. miniserve(1) - Page de manuel

NAME

miniserve - Un serveur HTTP statique simple pour partager des fichiers.

SYNOPSIS

miniserve [-p PORT] [-P PASSWORD] [-a ADDRESS] [-t TEMPLATE] [-i] [-I] [-c] [-h] [DIR]

DESCRIPTION

Le programme miniserve sert de serveur HTTP statique. Il est idéal pour partager rapidement des fichiers dans un réseau local, ou pour servir des fichiers statiques pour un site web.

Par défaut, il sert le répertoire courant.

OPTIONS

Les options suivantes sont disponibles :

-p, --port PORT
Le numéro de port sur lequel le serveur doit écouter. La valeur par défaut est 8080.
-P, --password PASSWORD
Définit un mot de passe pour protéger l'accès aux fichiers. Si cette option est utilisée sans argument, l'utilisateur sera invité à entrer un mot de passe.
-a, --address ADDRESS
L'adresse IP sur laquelle le serveur doit écouter. La valeur par défaut est 0.0.0.0 (toutes les interfaces).
-t, --template TEMPLATE
Le chemin vers un fichier de modèle HTML personnalisé pour la page d'index.
-i, --index
Permet la navigation dans les répertoires (valeur par défaut).
-I, --no-index
Désactive la navigation dans les répertoires. Seuls les fichiers listés dans la racine seront accessibles.
-c, --cors
Active le partage de ressources entre origines multiples (CORS) pour toutes les origines.
-h, --help
Affiche un message d'aide et quitte.

Le dernier argument facultatif DIR spécifie le répertoire à servir. S'il n'est pas fourni, le répertoire courant est utilisé.
