MIDICAT(1) Manuel des commandes générales MIDICAT(1)

NOM

midicat — envoyer vers ou recevoir depuis des ports MIDI

SYNTAXE

midicat [-d] [-i fichier] [-o fichier] [-q port]

DESCRIPTION

L'utilitaire midicat reçoit des données MIDI depuis le port MIDI d'entrée spécifié et/ou les envoie vers le port MIDI de sortie spécifié. Les options sont les suivantes :

-d
Affiche les données transférées en hexadécimal sur stderr.
-i fichier
Lit les données MIDI depuis ce fichier au lieu de les recevoir depuis le port MIDI. Si l'argument de l'option est « - », l'entrée standard sera utilisée.
-o fichier
Écrit les données MIDI dans ce fichier au lieu de les envoyer vers le port MIDI. Si l'argument de l'option est « - », la sortie standard sera utilisée.
-q port
Utilise ce port MIDI sndio(7) pour l'entrée/sortie. Si l'option est utilisée deux fois, la première spécifie le port d'entrée et la seconde le port de sortie.

Si aucun fichier n'est spécifié, alors midicat transfère les données du port d'entrée MIDI vers le port de sortie MIDI.

EXEMPLES

Envoyer le fichier donné vers rmidi/0 :

$ midicat -i fichier.syx -q rmidi/0

Afficher les données reçues de rmidi/0 sur stderr :

$ midicat -d -q rmidi/0 -o /dev/null

Envoyer les données de rmidi/0 vers midithru/0 :

$ midicat -q rmidi/0 -q midithru/0
