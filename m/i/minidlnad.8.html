NOM

minidlnad - Serveur MiniDLNA DLNA/UPnP-AV

SYNTAXE

minidlnad options

DESCRIPTION

minidlna est un serveur DLNA/UPnP-AV léger mais très fonctionnel, permettant de partager facilement vos fichiers multimédias, y compris les images, avec tout appareil ou client capable sur votre réseau local filaire et sans fil. Les logiciels PC courants comme totem sont un bon choix léger et rapide pour Linux/BSD ; les logiciels plus complets pour Linux, Windows et MAC sont XBMC, ainsi que Mediahouse sur Android, et tout DVR/TV compatible partage de médias, etc.

OPTIONS

Les options de minidlna sont normalement définies dans le fichier global /etc/minidlna.conf.

Mais il peut y avoir des moments où vous avez besoin de modifier temporairement
certaines de ces options, vous pouvez le faire en exécutant minidlna avec les
options de ligne de commande suivantes.
-R Recherche
Ceci force minidlna à rechercher à nouveau dans tous les répertoires media_dir.
-f fichier_configuration
Exécute minidlna avec un fichier de configuration différent de la valeur par défaut globale.
-p port
Permet d'exécuter minidlna sur un port différent.
-w url_présentation
Modifie l'adresse par défaut de l'URL de présentation.
-d débogage
minidlna s'exécutera en premier plan avec des sorties de débogage.
-P nom_fichier_pid
Spécifie un emplacement pour le fichier PID.
-m modèle
Force minidlna à rapporter un numéro de modèle spécifique.
-s numéro_de_série
Force minidlna à rapporter un numéro de série spécifique.
-t intervalle_notification
Modifie l'intervalle de notification, en secondes. La valeur par défaut est 895 secondes.
-h aide
Affiche les options de base pour l'exécution de minidlna.
-V Version
Affiche le numéro de version du programme et quitte.
