MIDICOPY(1) Manuel des commandes générales MIDICOPY(1)

NOM

midicopy - Copie une piste, un canal, un intervalle de temps sélectionné d'un fichier MIDI vers un autre fichier MIDI

SYNOPSIS

midicopy [-ver] [-trks n1,n2,..] [-xtrks n1,n2,..] [-xchns n1,n2,..] [-chans n1,n2,...] [-from n (en pulsations MIDI)] [-to n (en pulsations MIDI)] [-fromsec %f n (en secondes)] [-tosec n (en secondes)] [-frombeat %f n (en temps)] [-tobeat n (en temps)] [-replace trk,loc,val] [-tempo %n] [-speed %f] [-drumfocus n m] [-mutenodrum [%d]] [-setdrumloudness n m] [-focusontrack n1,n2,... (à partir de 1)] [-focusonchannel n1,n2,... (à partir de 1)] [-attenuation n] [-nobends] [-indrums n1,n2,...] [-xdrums n1,n2,...] [-onlydrums] [-nodrums] [-transpose n (demi-tons)] input.mid output.mid

DESCRIPTION

midicopy est utilisé pour copier une partie d'un fichier MIDI vers un autre fichier MIDI. Vous pouvez sélectionner un intervalle de temps particulier, des canaux particuliers et des pistes particulières ou toute combinaison. Si l'un ou les deux paramètres d'exécution -from ou -to sont inclus, le programme retourne le temps de lecture en secondes du fichier de sortie. Midicopy a été développé par Seymour Shlien à partir de la distribution midifilelib disponible sur http://www.harmony-central.com/MIDI/midifilelib.tar.gz.

OPTIONS

-ver
affiche le numéro de version puis quitte
-trks n1,n2, etc
Sélectionne les pistes à copier où les numéros de piste commencent à 1. Si plus d'une piste est spécifiée, elles doivent être séparées par des virgules. Vous devriez toujours copier la piste 1 car par convention elle contient des informations pertinentes pour toutes les autres pistes. Par défaut, toutes les pistes sont copiées à moins que vous ne spécifiiez des pistes particulières à l'aide de ce paramètre d'exécution.
-xtrks n1,n2, etc
Liste les pistes à exclure de la copie. Toutes les autres pistes sont copiées. Cette option ne fonctionne pas en combinaison avec -trks.
-xchns n1,n2, etc
Liste les canaux à exclure de la copie. Tous les autres canaux sont copiés. Cette option ne fonctionne pas en combinaison avec -chns.
-chns n
Comme ci-dessus, spécifie les canaux MIDI à copier. Par défaut, tous les canaux sont copiés. Les numéros de canal commencent également à 1.
-from n
Le programme copiera toutes les commandes MIDI à partir de la pulsation MIDI numéro n. Par défaut, il commencera à partir du temps zéro ou du début du fichier MIDI.
-to n
Arrête la copie de tous les événements après la pulsation MIDI numéro n. Par défaut, le fichier est copié jusqu'à la fin.
-frombeat n
Le programme copiera toutes les commandes MIDI à partir du quart de temps numéro n. Par défaut, il commencera à partir du temps zéro ou du début du fichier MIDI.
-tobeat n
Arrête la copie de tous les événements après le quart de temps numéro n. Par défaut, le fichier est copié jusqu'à la fin.
-fromsec n
Le programme copiera toutes les commandes MIDI à partir du temps n en secondes.
-tosec n
Arrête la copie de tous les événements après le temps n en secondes. Ces deux options (-fromsec et -tosec) ne fonctionnent pas avec précision si le fichier MIDI contient plus d'une commande de tempo. Seule la première est utilisée pour convertir les secondes en unités de pulsation MIDI. Il est donc préférable d'utiliser les options -from et -to.
-replace trk,loc,val
Cette option doit être utilisée seule. Midicopy copiera le fichier entier verbatim, sauf qu'il remplacera un octet par val, où l'octet est situé dans la piste (trk) et la position (loc) spécifiées. Couramment, cette fonction est utilisée pour changer un numéro de programme MIDI particulier (instrument) associé à un canal. Vous devez connaître le nombre d'octets dans la piste de ce paramètre pour utiliser cette fonction.
-tempo quartiers de notes/minute
Toutes les indications de tempo dans le fichier MIDI seront remplacées par la valeur ci-dessus.
-speed facteur
Toutes les indications de tempo dans le fichier MIDI seront multipliées par ce facteur. Les valeurs supérieures à 1,0 accéléreront la musique, tandis que les valeurs inférieures la ralentiront. Le facteur est une valeur à virgule flottante.
-drumfocus code_percu_exclure_velocités
La ligne de percussion sélectionnée (spécifiée par la valeur du code de hauteur de percussion) est mise en évidence en réduisant le volume de toutes les autres lignes de percussion à la valeur des vélocités exclues. La valeur du code de percussion doit être comprise entre 35 et 81 inclus.
-mutenodrum [niveau]
Tous les canaux qui ne sont pas 9 (canal de percussion) sont atténués au niveau donné. Si le niveau n'est pas spécifié, il est supposé être zéro.
-setdrumloudness n m
où n est compris entre 35 et 81 inclus et m est le volume entre 0 et 127. Le volume de toutes les instances de percussion n est modifié à m.
-focusontrack n1,n2,...
Les vélocités des notes dans toutes les pistes sauf n sont atténuées.
-focusonchannel n1,n2,...
Les vélocités des notes dans tous les canaux sauf n sont atténuées.
-attenuation n
Spécifie la quantité dont les vélocités des notes sont réduites par -focusontracks ou -focusonchannels. La valeur par défaut actuelle est 70.
-nobends
Supprime toutes les commandes de pitchbend de canal.
-indrums n1,n2,...
N'autoriser que les percussions avec les codes n1,n2,...
-xdrums n1,n2,...
Exclure les percussions avec les codes n1,n2,...
-onlydrums
Copier uniquement le canal de percussion.
-nodrums
Copier tous les canaux sauf le canal de percussion.
-transpose n (demi-tons)
Transposer la hauteur pour tous les canaux sauf la percussion de n demi-tons.

EXEMPLE

midicopy.exe -trks 1,5 -from 2669 -to 8634 uzicko.mid fragment.mid Midicopy copiera les pistes 1 et 5 à partir de la position de pulsation MIDI 2669 et se terminant à la position de pulsation MIDI 8634.
