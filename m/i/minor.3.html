makedev(3) Manuel des fonctions de bibliothèque makedev(3)

NOM

makedev, major, minor — gérer un numéro de périphérique

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/sysmacros.h>
dev_t makedev(unsigned int maj, unsigned int min);
unsigned int major(dev_t dev);
unsigned int minor(dev_t dev);

DESCRIPTION

Un ID de périphérique se compose de deux parties : un ID majeur, identifiant la classe du périphérique, et un ID mineur, identifiant une instance spécifique d'un périphérique dans cette classe. Un ID de périphérique est représenté par le type dev_t.

À partir des ID de périphérique majeurs et mineurs, makedev() les combine pour produire un ID de périphérique, qui est retourné comme résultat de la fonction. Cet ID de périphérique peut être transmis à mknod(2), par exemple.

Les fonctions major() et minor() effectuent la tâche inverse : à partir d'un ID de périphérique, elles retournent respectivement les composantes majeure et mineure. Ces macros peuvent être utiles pour, par exemple, décomposer les ID de périphérique dans la structure retournée par stat(2).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
makedev (), major (), minor () Sécurité des threads MT-Safe

VERSIONS

Les BSD exposent les définitions de ces macros via <sys/types.h>.

NORMES

Aucune.

HISTORIQUE

BSD, HP-UX, Solaris, AIX, Irix.

Ces interfaces sont définies comme des macros. Depuis glibc 2.3.3, elles sont des alias pour trois fonctions spécifiques à GNU : gnu_dev_makedev(), gnu_dev_major() et gnu_dev_minor(). Ces derniers noms sont exportés, mais les noms traditionnels sont plus portables.

Selon la version, glibc expose également des définitions pour ces macros à partir de <sys/types.h> si des macros de test de fonctionnalités appropriées sont définies. Cependant, ce comportement a été déprécié dans glibc 2.25, et depuis glibc 2.28, <sys/types.h> ne fournit plus ces définitions.

VOIR AUSSI

mknod(2), stat(2)
