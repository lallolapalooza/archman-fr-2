mitem_userptr(3X) Appels de bibliothèque mitem_userptr(3X)

NOM

set_item_userptr, item_userptr - associer des données d'application à un élément de menu

SYNTAXE

#include <menu.h>
int set_item_userptr(ITEM *item, void *userptr);
void *item_userptr(const ITEM *item);

DESCRIPTION

Chaque élément de menu possède un champ qui peut être utilisé pour stocker des données spécifiques à l'application (c'est-à-dire que le code du pilote de menu le laisse tel quel). Ces fonctions obtiennent et définissent ce champ.

VALEUR DE RETOUR

La fonction item_userptr renvoie un pointeur (potentiellement NULL). Elle ne définit pas errno.

set_item_userptr renvoie toujours E_OK (succès).

PORTABILITÉ

Ces routines émulent la bibliothèque de menus System V. Elles n'étaient pas prises en charge dans les versions Version 7 ou BSD.

Le pointeur utilisateur est un pointeur void. Nous avons choisi de ne pas le laisser comme pointeur char pour la compatibilité SVr4.

AUTEURS
