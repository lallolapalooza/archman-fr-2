minidlna.conf(5) Manuel des formats de fichier minidlna.conf(5)

NOM

minidlna

DESCRIPTION

minidlna est un serveur DLNA léger mais très fonctionnel. Dans la plupart des cas, les valeurs par défaut n'ont pas besoin d'être modifiées. Le fichier de configuration global est /etc/minidlna.conf, mais les utilisateurs locaux sans accès root système peuvent exécuter minidlna avec leur propre fichier de configuration.

OPTIONS

Les options configurables par l'utilisateur dans /etc/minidlna.conf sont les suivantes. minidlna s'exécute par défaut en tant qu'utilisateur nobody, assurez-vous donc que les permissions système sont correctement définies pour l'accès en lecture aux médias et l'accès en écriture aux répertoires de cache et de logs.

friendly_name
Le nom sous lequel vous souhaitez que votre serveur multimédia soit visible, par exemple : friendly_name=Serveur Média Maison
port
Port pour le trafic HTTP (descriptions, SOAP, transfert de médias) etc., par défaut 8200.
Il ne devrait pas être nécessaire de le changer.
network_interface
Interfaces réseau à servir, séparées par des virgules. Maximum de 8 interfaces. Par défaut, toutes les interfaces sont utilisées.
strict_dlna
Définissez ceci pour adhérer strictement aux normes DLNA.
Cela permettra au serveur de réduire la taille des images JPEG très grandes côté serveur,
ce qui peut nuire aux performances de transfert des fichiers JPEG sur (au moins) les
produits DLNA Sony.
notify_interval
Intervalle de notification en secondes. La valeur par défaut est de 895 secondes.
minissdpdsocket
Spécifiez le chemin vers le socket MiniSSDPd,
par exemple : minissdpdsocket=/var/run/minissdpd.sock
serial
Numéro de série que le démon rapportera aux clients dans sa description XML.
Par défaut : 12345678
model
Numéro de modèle que le démon rapportera aux clients dans sa description XML.
Par défaut : 1
media_dir
Chemin vers le répertoire contenant les fichiers multimédias que minidlna doit partager.
Utilisez cette option plusieurs fois si vous avez plus d'un répertoire à partager.
Exemple :
 media_dir=/opt/multimedia/videos
 media_dir=/opt/multimedia/movies

Vous pouvez également restreindre une entrée à un type de média spécifique en utilisant la syntaxe suivante :

   la lettre 'A', 'V' ou 'P', suivie d'une virgule (',') suivie du chemin.
   La signification de la première lettre est la suivante :
                      'A' pour les fichiers audio
                      'V' pour les fichiers vidéo
                      'P' pour les fichiers image
    Par exemple, si vous ne souhaitez inclure que les fichiers vidéo situés
    dans le répertoire /opt/multimedia/videos, et uniquement la musique
    dans /opt/multimedia/music, alors vous utiliseriez
                       media_dir=V,/opt/multimedia/videos
                       media_dir=A,/opt/multimedia/music
    Un autre exemple serait
                       media_dir=V,/opt/multimedia/videos
                       media_dir=V,/opt/multimedia/movies
                       media_dir=A,/opt/multimedia/music
    Ou, si vous ne vous souciez pas du type trouvé, vous pourriez utiliser
                       media_dir=/opt/multimedia/videos
                       media_dir=/opt/multimedia/movies
                       media_dir=/opt/multimedia/music
    Vous pouvez mélanger, trouver n'importe quoi dans la musique, mais seulement des vidéos,
    dans les répertoires vidéo et films
                       media_dir=V,/opt/multimedia/videos
                       media_dir=V,/opt/multimedia/movies
                       media_dir=/opt/multimedia/music
presentation_url
L'URL de présentation par défaut est l'adresse http sur le port 80
Par exemple : presentation_url=http://www.mediaserver.lan/index.php
db_dir
Où minidlna stocke les fichiers de données, y compris les fichiers de cache d'albums. Par défaut, c'est /var/cache/minidlna.
log_dir
Chemin vers le répertoire où le fichier journal upnp-av.log doit être stocké. Par défaut, c'est /var/log.
log_level
Définissez ceci pour changer le niveau de détail des informations journalisées. Chaque section peut utiliser un niveau différent : off, fatal, error, warn, info, ou debug. 
Exemple
log_level=general,artwork,database,inotify,scanner,metadata,http,ssdp,tivo=warn
inotify
Définissez sur 'yes' pour activer la surveillance inotify des fichiers sous media_dir afin de découvrir automatiquement les nouveaux fichiers. Définissez sur 'no' pour désactiver inotify.
album_art_names
Il doit s'agir d'une liste de noms de fichiers à vérifier lors de la recherche de pochettes d'album. Les noms doivent être séparés par une barre oblique inverse (`/`). 
Exemple
album_art_names=Cover.jpg/cover.jpg/AlbumArtSmall.jpg/albumartsmall.jpg/AlbumArt.jpg
/albumart.jpg/Album.jpg/album.jpg/Folder.jpg/folder.jpg/Thumb.jpg/thumb.jpg
enable_tivo
Définissez sur 'yes' pour activer la prise en charge du streaming des fichiers .jpg et .mp3 vers un TiVo compatible HMO. Par défaut, c'est 'no'.
tivo_discovery
Définissez sur 'beacon' pour utiliser la méthode de découverte broadcast héritée de TiVo. Par défaut, utilise Bonjour si le support Avahi est disponible.
root_container
Utiliser un conteneur différent comme racine de l'arborescence exposée aux clients. 
Les valeurs possibles sont :
             '.' pour utiliser le conteneur standard (c'est la valeur par défaut)
             'B' pour utiliser le conteneur "Browse Directory" ;
             'M' pour utiliser le conteneur "Music" ;
             'V' pour utiliser le conteneur "Video" ;
             'P' pour utiliser le conteneur "Pictures".
  Si vous spécifiez 'B' et que le périphérique client est uniquement audio, alors
  "Music/Folders" sera utilisé comme conteneur racine et vous ne verrez pas les vidéos.
force_sort_criteria
Force toujours le SortCriteria à cette valeur, quel que soit le SortCriteria passé par le client. 
Vous pouvez préfixer le critère de tri par "!" pour modifier les titres des objets afin
qu'ils soient triés alphanumériquement dans l'ordre que vous spécifiez ici, afin de contourner
les clients qui effectuent leur propre tri alphanumérique.
Exemple
force_sort_criteria=+upnp:class,+upnp:originalTrackNumber,+dc:title
wide_links
Définissez sur 'yes' pour autoriser les liens symboliques qui pointent en dehors des répertoires multimédias définis par l'utilisateur. Par défaut, les liens symboliques externes ne sont pas suivis.
enable_subtitles
Définissez sur 'no' pour désactiver la prise en charge des sous-titres sur les clients inconnus. Par défaut, les sous-titres sont activés pour les clients inconnus ou génériques.
