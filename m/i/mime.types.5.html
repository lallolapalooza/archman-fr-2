NOM

mime.types - fichier de description des types mime pour CUPS

DESCRIPTION

Le fichier mime.types définit les types de fichiers reconnus.

Des types de fichiers supplémentaires sont spécifiés dans des fichiers avec l'extension .types dans le répertoire de configuration de CUPS.

Chaque ligne du fichier mime.types est un commentaire, une ligne vide ou une ligne de règle. Les lignes de commentaire commencent par le caractère # . Les lignes de règle commencent par le type de média MIME et sont éventuellement suivies d'une série de règles de reconnaissance de fichiers :

    mime/type [ règle ... règle ]
Les règles peuvent être étendues sur plusieurs lignes en utilisant le caractère backslash (\) : 
    mime/type [ règle-vraiment-vraiment-vraiment-longue ... \
      règle ]
Les types de médias MIME spécifiés par le champ mime/type ne sont pas sensibles à la casse et sont triés par ordre alphabétique ascendant aux fins de la correspondance. Voir la section "CORRESPONDANCE DES TYPES ET PRIORITÉ" pour plus d'informations.

Les règles peuvent être groupées à l'aide de parenthèses, jointes par "+" pour un ET logique, jointes par "," ou des espaces blancs pour un OU logique, et niées à l'aide de "!".

RÈGLES

Les règles prennent deux formes : une extension de nom de fichier seule et des fonctions avec des valeurs de test entre parenthèses. Les fonctions suivantes sont disponibles :

match("motif")
Vrai si le nom de fichier correspond au motif de caractère générique shell donné.
ascii(décalage,longueur)
Vrai si les longueur octets commençant au décalage sont des caractères ASCII imprimables valides (CR, NL, TAB, BS, 32-126). La longueur ne peut pas dépasser 8192 octets.
printable(décalage,longueur)
Vrai si les longueur octets commençant au décalage sont des caractères 8 bits imprimables (CR, NL, TAB, BS, 32-126, 128-254). La longueur ne peut pas dépasser 8192 octets.
priority(nombre)
Spécifie la priorité relative de ce type de média MIME. La priorité par défaut est de 100. Les valeurs plus grandes ont une priorité plus élevée tandis que les valeurs plus petites ont une priorité plus faible.
string(décalage,"chaîne")
Vrai si les octets commençant au décalage sont identiques à chaîne.
istring(décalage,"chaîne")
Vrai si les octets commençant au décalage correspondent à chaîne sans tenir compte de la casse.
char(décalage,valeur)
Vrai si l'octet au décalage est identique à valeur.
short(décalage,valeur)
Vrai si l'entier 16 bits big-endian au décalage est identique à valeur.
int(décalage,valeur)
Vrai si l'entier 32 bits big-endian au décalage est identique à valeur.
locale("chaîne")
Vrai si la locale actuelle correspond à chaîne.
contains(décalage,longueur,"chaîne")
Vrai si les octets commençant au décalage sur longueur octets contiennent chaîne. La longueur ne peut pas dépasser 8192 octets.

CONSTANTES DE CHAÎNE

Les constantes de chaîne peuvent être spécifiées entre guillemets ("") pour les chaînes contenant des espaces et entre chevrons (<>) pour les chaînes hexadécimales.

CORRESPONDANCE DES TYPES ET PRIORITÉ

Lorsque CUPS doit déterminer le type de média MIME d'un fichier donné, il vérifie chaque type de média MIME défini dans les fichiers .types. Lorsque deux types ou plus correspondent à un fichier donné, le type choisi dépendra du nom du type et de la priorité, les types de priorité plus élevée étant utilisés par rapport aux types de priorité plus faible. Si les types ont la même priorité, les noms des types sont triés par ordre alphabétique ascendant et le premier type est choisi.

Par exemple, si deux types "text/bar" et "text/foo" sont définis comme correspondant à l'extension "doc", normalement le type "text/bar" sera choisi car son nom est alphabétiquement plus petit que "text/foo". Cependant, si "text/foo" définit également une priorité plus élevée que "text/bar", "text/foo" sera choisi à la place.

FICHIERS

/etc/cups - Répertoire de configuration typique de CUPS.

EXEMPLES

Définir deux types de médias MIME pour les données raster, l'un étant un sous-ensemble avec une priorité plus élevée :

    application/vnd.cups-raster  string(0,"RaSt") string(0,"tSaR") \
                                  string(0,"RaS2") string(0,"2SaR") \
                                  string(0,"RaS3") string(0,"3SaR")
    image/pwg-raster              string(0,"RaS2") + \
                                  string(4,PwgRaster<00>) priority(150)
