NOM

mid3iconv - convertir les encodages des tags ID3

SYNOPSIS

mid3iconv [options] fichier ...

DESCRIPTION

mid3iconv convertit les tags ID3 des encodages hérités en Unicode et les stocke au format ID3v2.

OPTIONS

--debug, -d
Imprimer les tags mis à jour
--dry-run, -p
Ne pas modifier réellement les fichiers
--encoding, -e
Convertir depuis cet encodage. Par défaut, l'encodage par défaut de votre locale est utilisé.
--force-v1
Utiliser un tag ID3v1 même si un tag ID3v2 est présent
--quiet, -q
Afficher uniquement les erreurs
--remove-v1
Supprimer tout tag ID3v1 après le traitement des fichiers

AUTEUR

Emfox Zhou.

Basé sur id3iconv (http://www.cs.berkeley.edu/~zf/id3iconv/) par Feng Zhou.
