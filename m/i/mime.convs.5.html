NOM

mime.convs - fichier de conversion de types MIME pour CUPS (obsolète)

DESCRIPTION

Le fichier mime.convs définit les filtres disponibles pour convertir des fichiers d'un format à un autre. Les filtres standard prennent en charge les fichiers texte, PDF, PostScript et de nombreux types de fichiers image.

Des filtres supplémentaires sont spécifiés dans des fichiers avec l'extension .convs dans le répertoire de configuration de CUPS.

Chaque ligne du fichier mime.convs est un commentaire, une ligne vide ou une ligne de filtre. Les lignes de commentaire commencent par le caractère #. Les lignes de filtre spécifient les types MIME source et destination ainsi qu'un coût relatif associé au filtre et au filtre à exécuter :

    source/type destination/type coût filtre
Le champ source/type spécifie le type MIME source des données consommées par le filtre.

Le champ destination/type spécifie le type MIME destination produit par le filtre.

Le champ coût spécifie le coût relatif d'exécution du filtre. Une valeur de 100 signifie que le filtre utilise une grande quantité de ressources, tandis qu'une valeur de 0 signifie que le filtre utilise très peu de ressources.

Le champ filtre spécifie le nom du programme filtre. Les noms de fichiers sont relatifs au répertoire des filtres CUPS.

FICHIERS

/etc/cups - Répertoire de configuration typique de CUPS.
/usr/lib/cups/filter - Répertoire des filtres CUPS typique.
/usr/libexec/cups/filter - Répertoire des filtres CUPS sur macOS.

EXEMPLES

Définir un filtre qui convertit les documents PostScript au format CUPS Raster :

    application/vnd.cups-postscript application/vnd.cups-raster 50 pstoraster

NOTES

Les filtres CUPS sont obsolètes et ne seront plus pris en charge dans une future version de CUPS. Les imprimantes qui ne prennent pas en charge IPP peuvent être prises en charge en utilisant des applications telles que ippeveprinter(1).
