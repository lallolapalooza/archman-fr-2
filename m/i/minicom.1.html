NOM

minicom - programme de communication série convivial

SYNTAXE

minicom [options] [configuration]

DESCRIPTION

minicom est un programme de communication qui ressemble quelque peu au programme shareware TELIX, mais il est gratuit, avec son code source, et fonctionne sur la plupart des systèmes Unix. Ses fonctionnalités incluent un répertoire de numérotation avec rappel automatique, la prise en charge des fichiers de verrouillage de style UUCP sur les périphériques série, un interpréteur de langage de script séparé, la capture dans un fichier, plusieurs utilisateurs avec des configurations individuelles, et plus encore.

LIGNE DE COMMANDE

-s, --setup
Setup (configuration). Root édite les valeurs par défaut du système dans /etc/minirc.dfl avec cette option. Lorsqu'elle est utilisée, minicom n'initialise pas, mais vous place directement dans le menu de configuration. C'est très pratique si minicom refuse de démarrer car votre système a changé, ou lors de la première exécution de minicom. Pour la plupart des systèmes, des valeurs par défaut raisonnables sont déjà compilées.
-o, --noinit
Ne pas initialiser. Minicom ignorera le code d'initialisation. Cette option est pratique si vous quittez minicom sans réinitialiser, puis que vous souhaitez redémarrer une session. Elle est potentiellement dangereuse cependant : aucune vérification des fichiers de verrouillage, etc., n'est effectuée, de sorte qu'un utilisateur normal pourrait interférer avec des choses comme UUCP... peut-être que cela sera supprimé plus tard. Pour l'instant, on suppose que les utilisateurs ayant accès à un modem sont suffisamment responsables de leurs actions.
-M, --metakey8
Identique à -m, mais suppose que votre touche Meta définit le 8ème bit du caractère à 1 (envoie 128 + code caractère).
-z, --statline
Utiliser la ligne d'état du terminal. Cela ne fonctionne que sur les terminaux qui la prennent en charge et qui disposent des informations pertinentes dans leur entrée de base de données termcap ou terminfo.
-l, --ansi
Traduction Littérale des caractères ayant le bit de poids fort activé. Avec ce drapeau activé, minicom essaiera de traduire les caractères de ligne IBM en ASCII. De nombreux clones PC-Unix afficheront correctement les caractères sans traduction (Linux en mode spécial, Coherent et SCO).
-L, --iso
Idem, mais suppose que l'écran utilise un jeu de caractères ISO8859.
-w, --wrap
Active le retour à la ligne par défaut au démarrage.
-H, --displayhex
Active la sortie en mode hexadécimal.
-a, --attrib=on/off
Utilisation des **A**ttributs. Certains terminaux, notamment les Televideo, ont une gestion des attributs défectueuse (série au lieu de parallèle). Par défaut, minicom utilise '-a on', mais si vous utilisez un tel terminal, vous pouvez (devez !) fournir l'option '-a off'. Le 'on' ou 'off' final est nécessaire.
-t, --term=TERM
Type de **T**erminal. Avec ce drapeau, vous pouvez remplacer la variable d'environnement TERM. C'est utile pour l'utiliser dans la variable d'environnement MINICOM ; on peut créer une entrée termcap spéciale pour une utilisation avec minicom sur la console, qui initialise l'écran en mode brut afin qu'en conjonction avec le drapeau -l, les caractères de ligne IBM soient affichés sans traduction.
-c, --color=on/off
Utilisation de la **C**ouleur. Les terminaux (comme la console Linux) prennent en charge la couleur avec les séquences d'échappement ANSI standard. S'il n'y a pas de prise en charge, l'utilisation de la couleur peut être désactivée avec '-c off'. Ceci, ainsi que l'option '-m', sont de bons candidats à placer dans la variable d'environnement MINICOM.
-S, --script=SCRIPT
Exécuter le script nommé au démarrage. Jusqu'à présent, la transmission du nom d'utilisateur et du mot de passe à un script de démarrage n'est pas prise en charge. Si vous utilisez également l'option -d pour démarrer la numérotation au démarrage, le script -S sera exécuté AVANT de composer les entrées spécifiées avec -d.
-d, --dial=ENTRY
Composer une entrée du répertoire de numérotation au démarrage. Vous pouvez spécifier un numéro d'index, mais aussi une sous-chaîne du nom de l'entrée. Si vous spécifiez un nom qui a plusieurs entrées dans le répertoire, elles sont toutes sélectionnées pour la composition. Vous pouvez également spécifier plusieurs noms ou numéros d'index en les séparant par des virgules. La composition commencera par la première entrée spécifiée une fois que toutes les autres procédures d'initialisation du programme seront terminées.
-p, --ptty=TTYP
Pseudo terminal à utiliser. Cela remplace le port terminal défini dans les fichiers de configuration, mais uniquement s'il s'agit d'un pseudo TTY. Le nom de fichier fourni doit être de la forme (/dev/)tty[p-z/][0-f], (/dev/)pts[p-z/][0-f] ou (/dev/)pty[p-z/][0-f]. Par exemple, /dev/ttyp1, pts/0 ou /dev/ptyp2.
-C, --capturefile=FILE
Nom de fichier. Ouvrir le fichier de capture au démarrage.
--capturefile-buffer-mode=MODE
Mode de mise en mémoire tampon du fichier de capture. MODE peut être :
N Non mis en mémoire tampon (par défaut).
L Mis en mémoire tampon par ligne.
F Entièrement mis en mémoire tampon.
-F, --statlinefmt
Format de la ligne d'état. Les spécificateurs de format suivants sont disponibles :
%H Touche d'échappement pour l'écran d'aide.
%V Chaîne de version de minicom.
%b Informations sur la connexion, telles que le débit en bauds.
%T Type de terminal.
%C Mode curseur.
%D Chemin du périphérique, éventuellement raccourci à l'espace disponible restant.
%t Temps en ligne.
%% caractère %.

Exemple : "%H pour l'aide | %b | Minicom %V | %T | %C | %t"

-b, --baudrate
Spécifier le débit en bauds, remplaçant la valeur donnée dans le fichier de configuration.
-D, --device
Spécifier le périphérique, remplaçant la valeur donnée dans le fichier de configuration.
-O, --option
Définir une option. L'argument peut être un mot unique, ou une paire clé=valeur. Options reconnues :

timestamp avec les valeurs simple, delta, persecond, et extended. Si aucune valeur n'est donnée, 'simple' est sélectionné.

-R, --remotecharset
Spécifier le jeu de caractères utilisé par le système distant et le convertir au jeu de caractères local. Exemple : 'latin1'.
-7, --7bit
Mode 7 bits pour les terminaux qui ne sont pas compatibles 8 bits. 8 bits est par défaut si l'environnement est configuré pour cela via LANG ou LC_ALL, sinon 7 bits.
-8, --8bit
Les caractères 8 bits passent sans aucune modification. 'Continu' signifie qu'aucune séquence de contrôle de localisation/attribut n'est insérée sans modification réelle de la localisation/attribut. Ce mode sert à afficher des caractères multi-octets 8 bits tels que le japonais. Pas nécessaire dans toutes les langues avec des caractères 8 bits. (Par exemple, afficher du texte finlandais ne nécessite pas cela.)
-h, --help
Afficher l'aide et quitter.
-v, --version
Afficher la version de minicom.
Lorsque minicom démarre, il recherche d'abord dans la variable d'environnement MINICOM des arguments de ligne de commande, qui peuvent être remplacés sur la ligne de commande elle-même. Ainsi, si vous avez fait
MINICOM='-m -c on'

export MINICOM

ou l'équivalent, et que vous démarrez minicom, minicom supposera que votre terminal *possède* une touche Meta ou <ALT> et

que la couleur est supportée. Si vous vous connectez ensuite depuis un terminal sans prise en charge des couleurs, et que vous avez défini MINICOM dans votre fichier de démarrage (.profile ou équivalent), et que vous ne souhaitez pas redéfinir votre variable d'environnement, vous pouvez taper 'minicom -c off' et exécuter sans prise en charge des couleurs pour cette session.

configuration
L'argument configuration est plus intéressant. Normalement, minicom obtient ses valeurs par défaut à partir d'un fichier appelé "minirc.dfl". Si vous fournissez un argument à minicom, il essaiera d'obtenir ses valeurs par défaut à partir d'un fichier appelé "minirc.configuration". Il est donc possible de créer plusieurs fichiers de configuration, pour différents ports, différents utilisateurs, etc. Le plus judicieux est d'utiliser des noms de périphériques, tels que tty1, tty64, sio2, etc. Si un utilisateur crée son propre fichier de configuration, il apparaîtra dans son répertoire personnel sous le nom ".minirc.dfl" ou ".minirc.configuration".

UTILISATION

Minicom est basé sur des fenêtres. Pour faire apparaître une fenêtre avec la fonction souhaitée, appuyez sur Contrôle-A (à partir de maintenant, nous utiliserons C-A pour désigner Contrôle-A), puis sur la touche de fonction (a-z ou A-Z). En appuyant d'abord sur C-A puis sur 'z', un écran d'aide apparaît avec un bref résumé de toutes les commandes. Cette touche d'échappement peut être modifiée lors de la configuration de minicom (option -s ou C-A O), mais nous nous en tiendrons à Contrôle-A pour l'instant.

Pour chaque menu, les touches suivantes peuvent être utilisées :

HAUT
flèche haut ou 'k'
BAS
flèche bas ou 'j'
GAUCHE
flèche gauche ou 'h'
DROITE
flèche droite ou 'l'
CHOISIR
Entrée
ANNULER
ÉCHAP.

L'écran est divisé en deux parties : les 24 lignes supérieures sont l'écran de l'émulateur de terminal. Dans cette fenêtre, les séquences d'échappement ANSI ou VT100 sont interprétées. S'il reste une ligne en bas, une ligne de statut y est placée. Si ce n'est pas possible, la ligne de statut sera affichée à chaque fois que vous appuierez sur C-A. Sur les terminaux qui ont une ligne de statut spéciale, celle-ci sera utilisée si les informations termcap sont complètes *et* si le drapeau -k a été donné.

Les commandes possibles sont listées ci-dessous, par ordre alphabétique.

C-A
Appuyer une deuxième fois sur C-A enverra simplement un C-A au système distant. Si vous avez modifié votre "caractère d'échappement" pour qu'il soit différent de C-A, cela fonctionne de manière analogue pour ce caractère.
A
Active/désactive 'Ajouter retour à la ligne'. S'il est activé, un retour à la ligne est ajouté avant chaque retour chariot affiché à l'écran.
B
Donne accès à un tampon de défilement. Vous pouvez défiler vers le haut avec u, vers le bas avec d, une page vers le haut avec b, une page vers le bas avec f, et si vous les avez, les touches flèches et page haut/page bas peuvent également être utilisées. Vous pouvez rechercher du texte dans le tampon avec s (sensible à la casse) ou S (insensible à la casse). N trouvera la prochaine occurrence de la chaîne. c entrera en mode citation. Un curseur de texte apparaît et vous spécifiez la ligne de départ en appuyant sur la touche Entrée. Ensuite, le mode de défilement arrière se terminera et le contenu avec le préfixe '>' sera envoyé.
C
Efface l'écran.
D
Compose un numéro, ou accède à l'annuaire téléphonique.
E
Active/désactive l'écho local (si votre version de minicom le prend en charge).
F
Un signal de rupture est envoyé au modem.
G
Exécute le script (Go). Lance un script de connexion.
H
Raccrocher.
I
Active/désactive le type de séquence d'échappement que les touches fléchées envoient entre le mode normal et le mode application. (Voir aussi le commentaire sur la ligne de statut ci-dessous).
J
Accède à un shell. Au retour, tout l'écran sera redessiné.
K
Efface l'écran, lance kermit et redessine l'écran au retour.
L
Active/désactive la capture de fichier. Si elle est activée, tout ce qui est envoyé à l'écran sera également capturé dans le fichier.
M
Envoie la chaîne d'initialisation du modem. Si vous êtes en ligne et que le paramètre de la ligne DCD est activé, vous êtes invité à confirmer avant l'initialisation du modem.
N
Bascule entre les modes d'horodatage à ajouter à la sortie. Disponibles : formats d'heure simples et étendus pour chaque ligne, un delta par rapport à la ligne précédente, un affichage de l'heure chaque seconde et pas d'horodatage (par défaut).
O
Configure minicom. Vous place dans le menu de configuration.
P
Paramètres de communication. Permet de modifier le débit en bps, la parité et le nombre de bits.
Q
Quitte minicom sans réinitialiser le modem. Si des macros ont été modifiées et non sauvegardées, vous aurez la possibilité de le faire.
R
Réception de fichiers. Choisissez parmi différents protocoles (externes). Si vous avez la fenêtre de sélection de nom de fichier et l'invite du répertoire de téléchargement activées, vous obtiendrez une fenêtre de sélection pour choisir le répertoire de téléchargement. Sinon, le répertoire de téléchargement défini dans le menu Noms de fichiers et chemins sera utilisé.
S
Envoi de fichiers. Choisissez le protocole comme pour la commande de réception. Si vous n'avez pas la fenêtre de sélection de nom de fichier activée (dans le menu Protocoles de transfert de fichiers), vous devrez simplement écrire le(s) nom(s) de fichier dans une fenêtre de dialogue. Si vous avez la fenêtre de sélection activée, une fenêtre apparaîtra montrant les noms de fichiers dans votre répertoire d'envoi. Vous pouvez marquer et dé-marquer des noms de fichiers en appuyant sur la barre d'espace, et déplacer le curseur vers le haut ou vers le bas avec les touches fléchées ou j/k. Les noms de fichiers sélectionnés sont affichés en surbrillance. Les noms de répertoires sont affichés [entre crochets] et vous pouvez monter ou descendre dans l'arborescence des répertoires en appuyant deux fois sur la barre d'espace. Enfin, envoyez les fichiers en appuyant sur ENTRÉE ou quittez en appuyant sur ÉCHAP.
T
Choix de l'émulation de terminal : Ansi (couleur) ou vt100. Vous pouvez également modifier la touche retour arrière ici, activer/désactiver la ligne de statut, et définir un délai (en millisecondes) après chaque nouvelle ligne si vous en avez besoin.
U
Ajoute un retour chariot à chaque ligne reçue.
W
Active/désactive le retour à la ligne.
X
Quitte minicom, réinitialise le modem. Si des macros ont été modifiées et non sauvegardées, vous aurez la possibilité de le faire.
Y
Colle un fichier. Lit un fichier et envoie son contenu comme s'il était tapé.
Z
Affiche l'écran d'aide.

ANNUAIRE TÉLÉPHONIQUE

En appuyant sur C-A D, le programme vous place dans l'annuaire téléphonique. Sélectionnez une commande en appuyant sur la lettre majuscule ou en déplaçant le curseur à droite/à gauche avec les touches fléchées ou les touches h/l et en appuyant sur Entrée. Vous pouvez ajouter, supprimer ou modifier des entrées et les déplacer de haut en bas dans la liste de l'annuaire. En choisissant "composer", les numéros de téléphone des entrées marquées, ou si rien n'est marqué, le numéro de l'entrée mise en surbrillance sera composé. Pendant que le modem compose, vous pouvez appuyer sur Échap pour annuler la composition. Toute autre touche fermera la fenêtre de composition, mais n'annulera pas la composition elle-même. Votre annuaire téléphonique sera sauvegardé dans le fichier ".dialdir" dans votre répertoire personnel. Vous pouvez faire défiler vers le haut et vers le bas avec les touches fléchées, mais vous pouvez également faire défiler des pages entières en appuyant sur Page Haut ou Page Bas. Si vous ne les avez pas, utilisez Contrôle-B (Arrière) et Contrôle-F (Avant). Vous pouvez utiliser la barre d'espace pour marquer un certain nombre d'entrées et minicom basculera à travers cette liste si une connexion ne peut être établie. Un symbole '>' est dessiné dans l'annuaire avant les noms des entrées marquées.

Le menu "modifier" se passe d'explication, mais je vais en discuter brièvement ici.

A - Nom
Le nom de cette entrée
B - Numéro
et son numéro de téléphone.
C - Chaîne de composition #
Quelle chaîne de composition spécifique vous souhaitez utiliser pour vous connecter. Il existe trois chaînes de composition différentes (préfixes et suffixes) qui peuvent être configurées dans le menu Modem et composition.
D - Écho local
peut être activé ou désactivé pour ce système (si votre version de minicom le prend en charge).
E - Script
Le script qui doit être exécuté après l'établissement d'une connexion réussie (voir le manuel pour runscript)
F - Nom d'utilisateur
Le nom d'utilisateur qui est passé au programme runscript. Il est passé dans la chaîne d'environnement "$LOGIN".
G - Mot de passe
Le mot de passe est passé sous le nom "$PASS".
H - Émulation de terminal
Utilise l'émulation ANSI ou VT100.
I - La touche retour arrière envoie
Quel code (Retour arrière ou Supprimer) la touche retour arrière envoie.
J - Retour à la ligne
Peut être activé ou désactivé.
K - Paramètres de ligne
Débit en bps, bits, parité et nombre de bits d'arrêt à utiliser pour cette connexion. Vous pouvez choisir actuel pour la vitesse, de sorte qu'elle utilisera la vitesse en cours (utile si vous avez plusieurs modems).
L - Table de conversion
Vous pouvez spécifier une table de conversion de caractères à charger chaque fois que cette entrée répond, avant d'exécuter le script de connexion. Si ce champ est vide, la table de conversion reste inchangée.

Le menu modifier affiche également la dernière date et heure d'appel de cette entrée et le nombre total d'appels effectués, mais ne vous permet pas de les modifier. Ils sont mis à jour automatiquement lorsque vous vous connectez.

La commande moVe permet de déplacer l'entrée sélectionnée vers le haut ou vers le bas dans l'annuaire téléphonique à l'aide des touches fléchées haut/bas ou des touches k et j

s. Appuyez sur Entrée ou ESC pour terminer le déplacement de l'entrée.

CONFIGURATION

En appuyant sur C-A O, vous accéderez au menu de configuration.

Noms de fichiers et chemins

Ce menu définit vos répertoires par défaut.
A - Répertoire de téléchargement
où les fichiers téléchargés sont placés.
B - Répertoire d'envoi
d'où les fichiers envoyés sont lus.
C - Répertoire des scripts
Où vous conservez vos scripts de connexion.
D - Programme de script
Quel programme utiliser comme interpréteur de script. Par défaut, le programme "runscript", mais si vous souhaitez utiliser autre chose (par exemple, /bin/sh ou "expect"), c'est possible. L'entrée standard et la sortie standard sont connectées au modem, l'erreur standard à l'écran.
Si le chemin est relatif (c'est-à-dire qu'il ne commence pas par un slash), il est relatif à votre répertoire personnel, à l'exception de l'interpréteur de script.
E - Programme Kermit
Où trouver l'exécutable de kermit et ses options. Certaines macros simples peuvent être utilisées sur la ligne de commande : '%l' est développé en nom de fichier complet du périphérique de numérotation sortante, '%f' est développé en descripteur de fichier du port série et '%b' est développé en vitesse actuelle du port série.
F - Options de journalisation
Options pour configurer l'écriture du fichier journal.
A - Nom du fichier
Ici, vous pouvez entrer le nom du fichier journal. Le fichier sera écrit dans votre répertoire personnel, et la valeur par défaut est "minicom.log". Si vous laissez le nom vide, toute journalisation est désactivée.
B - Journaliser les connexions et déconnexions
Cette option définit si le fichier journal est écrit lorsque le correspondant répond à l'appel ou raccroche. Ou lorsque vous donnez vous-même la commande de déconnexion ou quittez minicom sans déconnexion pendant que vous êtes en ligne.
C - Fichier journal des transferts
Souhaitez-vous des entrées dans le journal pour la réception et l'envoi de fichiers.
La commande 'log' dans les scripts n'est pas affectée par les options de journalisation B et C. Elle est toujours exécutée, si vous avez seulement le nom du fichier journal défini.

Protocoles de transfert de fichiers

Les protocoles définis ici apparaîtront lorsque C-A s/r sera appuyé. "Name" au début de la ligne est le nom qui apparaîtra dans le menu. "Program" est le chemin d'accès au protocole. "Name" après cela définit si le programme a besoin d'un argument, par exemple un fichier à transmettre. U/D définit si cette entrée doit apparaître dans le menu d'envoi ou de téléchargement. Fullscr définit si le programme doit s'exécuter en plein écran, ou si minicom n'affichera que son erreur standard dans une fenêtre. IO-Red définit si minicom doit attacher l'entrée et la sortie standard du programme au port modem ou non. "Multi" indique à la fenêtre de sélection de nom de fichier si le protocole peut envoyer plusieurs fichiers avec une seule commande. Il n'a aucun effet sur les protocoles de téléchargement, et il est également ignoré pour les protocoles d'envoi si vous n'utilisez pas la fenêtre de sélection de nom de fichier. Les anciens sz et rz ne sont pas en plein écran et ont IO-Red activé. Cependant, il existe des versions basées sur curses d'au moins rz qui ne veulent pas que leur entrée et sortie standard soient redirigées, et qui s'exécutent en plein écran. Tous les protocoles de transfert de fichiers sont exécutés avec l'UID de l'utilisateur, et non avec UID=root. '%l', '%f' et '%b' peuvent être utilisés sur la ligne de commande comme avec kermit. Dans ce menu, vous pouvez également définir si vous souhaitez utiliser la fenêtre de sélection de nom de fichier lorsque vous êtes invité à choisir des fichiers à envoyer, et si vous souhaitez être invité à spécifier le répertoire de téléchargement à chaque fois que le téléchargement automatique est démarré. Si vous désactivez l'invite du répertoire de téléchargement, le répertoire de téléchargement défini dans le menu des fichiers et répertoires sera utilisé.

Configuration du port série

A - Périphérique série
/dev/tty1 ou /dev/ttyS1 pour la plupart des gens. /dev/cua<n> est toujours possible sous GNU/Linux, mais n'est plus recommandé car ces périphériques sont obsolètes et de nombreux systèmes avec le noyau 2.2.x ou plus récent ne les ont pas. Utilisez /dev/ttyS<n> à la place. Vous pouvez également avoir /dev/modem comme lien symbolique vers le véritable périphérique.
Si vous avez des modems connectés à deux ports série ou plus, vous pouvez les spécifier tous ici dans une liste séparée par un espace, une virgule ou un point-virgule. Lorsque Minicom démarre, il vérifie la liste jusqu'à ce qu'il trouve un modem disponible et l'utilise. (Cependant, vous ne pouvez pas leur spécifier des chaînes d'initialisation différentes... du moins pas encore.)
Pour utiliser un socket UNIX pour la communication, le nom du périphérique doit être précédé de "unix#" suivi du chemin complet et du nom de fichier du socket. Minicom tentera alors de se connecter à ce socket en tant que client. Tant qu'il ne peut pas se connecter au socket, il reste 'hors ligne'. Dès que la connexion est établie, minicom passe à nouveau 'en ligne'. Si le serveur ferme le socket, minicom repasse à nouveau à 'hors ligne'.
B - Emplacement du fichier de verrouillage
Sur la plupart des systèmes, ce devrait être /usr/spool/uucp. Les systèmes GNU/Linux utilisent /var/lock. Si ce répertoire n'existe pas, minicom ne tentera pas d'utiliser de fichiers de verrouillage.
C - Programme d'appel entrant
Si vous avez un uugetty ou quelque chose sur votre port série, il se pourrait que vous souhaitiez qu'un programme soit exécuté pour basculer le modem, c'est-à-dire le port, en mode appelant/appelé. C'est le programme pour passer en mode appelant.
D - Programme d'appel sortant
Et celui-ci pour passer en mode appel sortant.
E - Bps/Par/Bits
Paramètres par défaut au démarrage.

Si l'une des entrées est laissée vide, elle ne sera pas utilisée. Donc, si vous ne vous souciez pas du verrouillage et que vous n'avez pas de getty en cours d'exécution sur votre ligne modem, les entrées B à D doivent être laissées vides.

Modem et numérotation

Ici, les paramètres de votre modem sont définis. Je n'expliquerai pas cela plus loin car les valeurs par défaut sont pour les modems Hayes génériques et devraient toujours fonctionner. Ce fichier n'est pas un tutoriel Hayes :-) Les seules choses qui valent la peine d'être notées sont que les caractères de contrôle peuvent être envoyés en les préfixant par un '^', où '^^' signifie '^' lui-même, et le caractère '\' doit également être doublé en '\\', car la barre oblique inverse est utilisée spécialement dans les définitions de macros. Certaines options, cependant, n'ont pas grand-chose à voir avec le modem mais plutôt avec le comportement de minicom lui-même :
M - Délai d'appel
Le nombre de secondes avant que minicom n'expire si aucune connexion n'est établie.
N - Délai avant recomposition
Minicom recomposera si aucune connexion n'a été établie, mais il attend d'abord un certain temps.
O - Nombre d'essais
Nombre maximum de tentatives de numérotation par minicom.
P - Délai de chute DTR
Si vous réglez cela sur 0, minicom raccroche en envoyant une séquence de raccrochage de type Hayes. Si vous spécifiez une valeur non nulle, le raccrochage sera effectué en abaissant la ligne DTR. La valeur indique en secondes combien de temps DTR restera abaissé.
Q - Détection automatique de bps
Si ceci est activé, minicom essaie de faire correspondre la vitesse du correspondant appelé. Avec la plupart des modems modernes, ce n'est PAS souhaitable, car le modem met les données en mémoire tampon et convertit la vitesse.
R - Le modem a une ligne DCD
Si votre modem et votre système d'exploitation prennent tous deux en charge la ligne DCD (qui passe à 'haut' lorsqu'une connexion est établie), minicom l'utilisera. Lorsque cette option est activée, minicom ne commencera pas non plus à composer pendant que vous êtes déjà en ligne.
S - La ligne d'état affiche la vitesse DTE / vitesse de ligne
Vous pouvez basculer la ligne d'état pour afficher soit la vitesse DTE (la vitesse que minicom utilise pour communiquer avec votre modem), soit la vitesse de ligne (la vitesse que votre modem utilise sur la ligne pour communiquer avec l'autre modem). Notez que la vitesse de ligne peut changer pendant la connexion, mais vous ne verrez toujours que la vitesse initiale avec laquelle les modems ont établi la connexion. En effet, le modem ne dit pas au programme si la vitesse est modifiée. De plus, pour voir la vitesse de ligne, vous devez configurer le modem pour qu'il l'affiche dans la chaîne de connexion. Sinon, vous ne verrez que 0 comme vitesse de ligne.
T - Désactiver multi-lignes
Vous pouvez activer la fonction pour désactiver les entrées du répertoire de numérotation lorsqu'une connexion est établie avec un BBS multi-lignes. Toutes les entrées marquées portant le même nom sont désactivées.
Notez qu'une exception spéciale est faite pour ce menu : chaque utilisateur peut modifier tous les paramètres ici, mais certains d'entre eux ne seront pas enregistrés.

Écran et clavier

A - La touche de commande est
la 'touche d'action' qui vous amène en mode commande. Si elle est définie sur 'ALT' ou 'touche méta', vous pouvez appeler directement les commandes en utilisant la touche alt au lieu de la touche d'action.
B - La touche Retour arrière envoie
Il existe encore certains systèmes qui souhaitent qu'un VT100 envoie DEL au lieu de BS. Avec cette option, vous pouvez activer cette stupidité. (Eh, c'est même activé par défaut...)
C - La ligne d'état est
Activée ou désactivée. Certains terminaux lents (par exemple, les terminaux X) font sauter la ligne d'état "en haut et en bas" lors du défilement, vous pouvez donc la désactiver si vous le souhaitez. Elle sera toujours affichée en mode commande.
D - Son d'alarme
Si activé, minicom émettra un son d'alarme (sur la console uniquement) après une connexion réussie et à la fin des transferts montant/descendant.
E - Couleur de premier plan (menu)
indique la couleur de premier plan à utiliser pour toutes les fenêtres de configuration dans minicom.
F - Couleur d'arrière-plan (menu)
indique la couleur d'arrière-plan à utiliser pour toutes les fenêtres de configuration dans minicom. Notez que minicom ne vous permettra pas de définir des couleurs de premier plan et d'arrière-plan identiques.
G - Couleur de premier plan (terminal)
indique la couleur de premier plan à utiliser dans la fenêtre du terminal.
H - Couleur d'arrière-plan (terminal)
indique la couleur d'arrière-plan à utiliser dans la fenêtre du terminal. Notez que minicom ne vous permettra pas de définir des couleurs de premier plan et d'arrière-plan identiques.
I - Couleur de premier plan (statut)
indique la couleur de premier plan à utiliser pour la barre de statut.
J - Couleur d'arrière-plan (statut)
indique la couleur à utiliser pour la barre de statut. Notez que minicom vous permettra de définir des couleurs de premier plan et d'arrière-plan identiques pour la barre de statut. Cela rendra effectivement la barre de statut invisible, mais si telles sont vos intentions, veuillez consulter l'option
K - Taille du tampon d'historique
Le nombre de lignes à conserver dans le tampon d'historique (pour le défilement arrière).
L - Fichier de macros
est le chemin complet vers le fichier qui contient les macros. Les macros vous permettent de définir une chaîne à envoyer lorsque vous appuyez sur une touche spécifique. Dans minicom, vous pouvez définir F1 à F12 pour envoyer jusqu'à 256 caractères [ceci est défini à la compilation]. Le nom de fichier que vous spécifiez est vérifié dès que vous appuyez sur ENTRÉE. Si vous n'avez pas les autorisations nécessaires pour créer le fichier spécifié, un message d'erreur vous l'indiquera et vous serez obligé de rééditer le nom du fichier. Si vous êtes autorisé à créer le fichier, minicom
vérifie s'il existe déjà. Si c'est le cas, il suppose qu'il s'agit d'un fichier de macros et le lit. Sinon, eh bien, c'est votre problème :-) Si le fichier n'existe pas, le nom de fichier est accepté.
M - Modifier les macros
ouvre une nouvelle fenêtre qui vous permet de modifier les macros F1 à F12.
N - Macros activées
- Oui ou Non. Si les macros sont désactivées, les touches F1-F12 enverront simplement les séquences d'échappement des touches de fonction VT100/VT220.
O - Conversion de caractères
Le nom du fichier de table de conversion actif est affiché ici. Si vous ne voyez aucun nom, aucune conversion n'est active. En appuyant sur O, vous verrez le menu d'édition de la table de conversion.
Modifier les macros
Ici, les macros pour F1 à F12 sont définies. Le bas de la fenêtre affiche une légende des combinaisons de caractères qui ont une signification spéciale. Elles vous permettent d'entrer des caractères de contrôle spéciaux avec du texte brut en les préfixant par un '^', où '^^' signifie '^' lui-même. Vous pouvez envoyer un délai de 1 seconde avec le code '^~'. Ceci est utile lorsque vous essayez de vous connecter après avoir ftp'é ou telnet'é quelque part. Vous pouvez également inclure votre nom d'utilisateur et votre mot de passe actuels du répertoire téléphonique dans les macros avec '\u' et '\p', respectivement. Si vous avez besoin du caractère barre oblique inverse dans la macro, écrivez-le doublé comme '\\'. Pour éditer une macro, appuyez sur le numéro ou la lettre indiqué et vous serez déplacé à la fin de la macro. Lors de l'édition de la ligne, vous pouvez utiliser les flèches gauche et droite, les touches Début et Fin, Suppr et Retour arrière, ainsi que ESC et RETOUR. ESC annule les modifications apportées tandis que RETOUR accepte les modifications.
Conversion de caractères
Ici, vous pouvez modifier la table de conversion de caractères. Si vous n'êtes pas américain, vous savez que dans de nombreuses langues, il existe des caractères qui ne sont pas inclus dans l'ensemble de caractères ASCII, et dans les temps anciens, ils ont peut-être remplacé certains caractères moins importants en ASCII et maintenant ils sont souvent représentés par des codes de caractères supérieurs à 127. ET il existe diverses manières de les représenter. C'est ici que vous pouvez modifier les tables de conversion pour les systèmes qui utilisent un jeu de caractères différent de celui de votre ordinateur.
A - Charger la table
Vous l'avez probablement deviné. Cette commande charge une table depuis le disque. On vous demande un nom de fichier pour la table. Les tables prédéfinies .mciso, .mcpc8 et .mcsf7 devraient être incluses avec le programme. La table .mciso n'effectue aucune conversion, .mcpc8 est à utiliser pour les connexions avec des systèmes qui utilisent le jeu de caractères pc 8 bits, et .mcsf7 est pour la compatibilité avec les systèmes qui utilisent le bon vieux codage 7 bits pour remplacer les caractères {|}[]\ par les caractères diacritiques utilisés en finnois et en suédois.
B - Sauvegarder la table
Celle-ci sauvegarde la table active sous le nom de fichier que vous spécifiez.
C - modifier caractère
C'est ici que vous pouvez apporter vos propres modifications à la table existante. Vous êtes d'abord invité à entrer la valeur du caractère (en décimal) dont vous souhaitez modifier la conversion. Ensuite, vous indiquerez quel caractère vous souhaitez voir à l'écran lorsque ce caractère provient du monde extérieur. Et ensuite, vous serez invité à indiquer ce que vous voulez envoyer lorsque vous entrez ce caractère depuis votre clavier.
D - écran suivant
E - écran précédent
Oui, vous avez probablement remarqué que cet écran vous montre quel type de conversions sont actives. L'écran est juste (généralement) trop petit pour afficher toute la table en même temps dans un format facile à comprendre. C'est ainsi que vous pouvez faire défiler la table vers la gauche et la droite.
F - convertir la capture
Active ou désactive l'utilisation de la table de conversion de caractères lors de l'écriture du fichier de capture.
Sauvegarder la configuration par défaut
Enregistre les paramètres par défaut pour la prochaine fois que le programme sera lancé. Au lieu de dfl, tout autre nom de paramètre peut apparaître, en fonction de celui qui a été utilisé lors du lancement du programme.
Sauvegarder la configuration sous..
Enregistre les paramètres sous un nom spécial. Chaque fois que Minicom est lancé avec ce nom comme argument, il utilisera ces paramètres. Cette option est bien sûr réservée à root.
Quitter
Quitte ce menu sans sauvegarder. Cela peut également être fait avec ESC.
Quitter minicom
Seul root verra cette entrée de menu, s'il/elle a lancé minicom avec l'option '-s'. De cette façon, il est possible de modifier la configuration sans réellement exécuter minicom.

LIGNE DE STATUT

La ligne de statut a plusieurs indicateurs qui parlent d'eux-mêmes. L'indicateur mystérieux APP ou NOR a probablement besoin d'une explication. Les touches fléchées VT100 peuvent être dans deux modes : mode application et mode curseur. Ceci est contrôlé par une séquence d'échappement. Si vous trouvez que les touches fléchées ne fonctionnent pas, disons, dans vi lorsque vous êtes connecté en utilisant minicom, alors vous pouvez voir avec cet indicateur si les touches fléchées sont en mode application ou curseur. Vous pouvez basculer entre les deux avec la combinaison de touches C-A I. Si les touches fléchées fonctionnent alors, c'est probablement une erreur dans les chaînes d'initialisation termcap du système distant (is).

LOCALES

Minicom prend en charge les langues locales. Cela signifie que vous pouvez changer la plupart des messages anglais et d'autres chaînes dans une autre langue en définissant la variable d'environnement LANG.

DIVERS

Si minicom est bloqué, tuez-le avec SIGTERM. (Cela signifie kill -15, ou puisque sigterm est par défaut, juste "kill ". Cela entraînera une sortie propre de minicom, effectuant les réinitialisations et tout. Vous pouvez tuer minicom à partir d'un script avec la commande "! killall -9 minicom" sans raccrocher la ligne. Sans le paramètre -9, minicom raccroche d'abord avant de quitter.

Comme de nombreuses séquences d'échappement commencent par ESC (Flèche vers le haut est ESC [ A), Minicom ne sait pas si le caractère d'échappement qu'il reçoit est vous qui appuyez sur la touche d'échappement, ou une partie d'une séquence.

Une ancienne version de Minicom, V1.2, résolvait cela de manière assez grossière : pour obtenir la touche d'échappement, vous deviez appuyer dessus deux fois.

Depuis la version 1.3, cela s'est un peu amélioré : un délai de 1 seconde est maintenant intégré, comme dans vi. Pour les systèmes qui ont l'appel système select(), le délai est de 0,5 seconde. Et... surprise : un hack spécial dépendant de Linux :-) a été ajouté. Maintenant, minicom peut séparer la touche d'échappement et les séquences d'échappement. Pour voir à quel point c'était sale, regardez dans wkeys.c. Mais ça marche à merveille !

FICHIERS

Minicom conserve ses fichiers de configuration dans un répertoire, généralement /var/lib/minicom, /usr/local/etc ou /etc. Pour savoir quel répertoire par défaut minicom a compilé, lancez la commande minicom -h. Vous y trouverez probablement aussi les fichiers de démonstration pour runscript(1), et des exemples de tables de conversion de caractères, soit là, soit dans les sous-répertoires de /usr/doc/minicom*. Les tables de conversion s'appellent quelque chose comme mc.* dans ce répertoire, mais vous voudrez probablement copier celles dont vous avez besoin dans votre répertoire personnel sous un nom commençant par un point.

minirc.*
$HOME/.minirc.*
$HOME/.dialdir
$HOME/minicom.log
/usr/share/locale/*/LC_MESSAGES/minicom.mo

    NAME

    minicom - un émulateur de terminal à usage général pour les ports série

    SYNOPSIS

    minicom [-a] [-b] [-c] [-C fichier] [-d numéro] [-e] [-f] [-F fichier] [-h] [-i] [-k] [-l] [-m] [-n] [-o] [-p port] [-P fichier_script] [-r] [-s] [-t couleur] [-v] [-w] [-X] [-Y] [-z] [--no-ansi] [--no-color] [--version]

    DESCRIPTION

    minicom est un programme d'émulation de terminal convivial. Il prend en charge les ports série et les modems. Il est très facile à configurer et à utiliser. Il prend également en charge la journalisation des données, la gestion des scripts, l'envoi et la réception de fichiers à l'aide de divers protocoles (Zmodem, Xmodem, Ymodem, Kermit), ainsi que la configuration des paramètres du port série.

    OPTIONS

    -a
    Ignore les caractères de contrôle lors de la mise en veille.
    -b
    Désactive la mise en veille automatique.
    -c
    Force l'utilisation des numéros de ligne ANSI pour la mise en page.
    -C fichier
    Spécifie le fichier journal des données. Par défaut, il s'agit de minicom.log.
    -d numéro
    Définit le numéro de profil à charger. Les profils sont stockés dans /etc/minicom/defaults.d/.
    -e
    Désactive le mode écho local.
    -f
    Ignore le fichier de configuration utilisateur.
    -F fichier
    Spécifie le fichier de script à charger. Par défaut, il s'agit de minicom.script.
    -h
    Affiche un message d'aide.
    -i
    N'affiche pas le message de bienvenue.
    -k
    Désactive le traitement des séquences d'échappement du clavier.
    -l
    Utilise des lignes de longueur variable.
    -m
    Désactive l'envoi de la séquence d'échappement de la touche ESC au début d'une commande.
    -n
    Désactive la mise en veille.
    -o
    Désactive l'envoi des caractères de fin de ligne.
    -p port
    Spécifie le port série à utiliser. Par exemple, /dev/ttyS0.
    -P fichier_script
    Spécifie le fichier de script à exécuter au démarrage. Par défaut, il s'agit de minicom.script.
    -r
    Désactive la réception de fichiers.
    -s
    Active le mode script.
    -t couleur
    Spécifie le type de terminal pour les couleurs. Les valeurs possibles sont ansi, vt100, xterm.
    -v
    Affiche la version de minicom.
    -w
    Active la mise en veille des lignes larges.
    -X
    Désactive le support des chaînes de caractères pour les programmes externes.
    -Y
    Active le support des chaînes de caractères pour les programmes externes.
    -z
    Maintient le programme actif lorsque le port est fermé.
    --no-ansi
    Désactive le traitement des séquences d'échappement ANSI.
    --no-color
    Désactive les couleurs.
    --version
    Affiche les informations de version et quitte.

    USAGE

    Après avoir lancé minicom, vous pouvez accéder aux commandes en appuyant sur Ctrl+A, puis sur la touche de commande souhaitée. Par exemple, pour accéder au menu de configuration, appuyez sur Ctrl+A puis sur O.

    CONFIGURATION

    minicom utilise plusieurs fichiers de configuration. Le fichier de configuration principal est ~/.minirc. Vous pouvez également avoir des fichiers de configuration par défaut dans /etc/minicom/defaults.d/.

    Les options de configuration incluent la définition du port série, des paramètres de vitesse de transmission, des scripts, des protocoles de transfert de fichiers, etc.

    COMMANDES

    Voici quelques commandes courantes :

    • Ctrl+A O : Menu de configuration
    • Ctrl+A P : Envoyer un fichier
    • Ctrl+A R : Recevoir un fichier
    • Ctrl+A X : Quitter minicom
    • Ctrl+A Z : Afficher le menu d'aide

    STATUS LINE

    La ligne d'état affiche des informations sur la connexion actuelle, telles que le port série utilisé, la vitesse de transmission, et l'état des flux de données.

    LOCALES

    minicom prend en charge les paramètres régionaux pour l'internationalisation.

    MISC

    Cette section contient des informations diverses et des notes sur l'utilisation de minicom.

    FILES

    • ~/.minirc : Fichier de configuration utilisateur.
    • /etc/minicom/minirc.dfl : Fichier de configuration par défaut.
    • /etc/minicom/keymap.d/ : Répertoire des fichiers de mappage de touches.
    • /etc/minicom/script.d/ : Répertoire des scripts.
