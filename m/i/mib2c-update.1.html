NOM

mib2c-update - script pour fusionner du code personnalisé dans le code mib2c mis à jour

SYNTAXE

mib2c-update

DESCRIPTION

Utilisez mib2c-update pour générer vos modèles de code mib2c, et il suivra le code original ainsi que les modifications que vous apporterez au code. Si le modèle mib2c change (corrections de bugs, améliorations dans les versions ultérieures), réexécuter mib2c mettra à jour le modèle et tentera ensuite de réappliquer vos modifications.

Cela peut être extrêmement utile lors du développement de vos propres modèles mib2c.

Lorsque vous exécutez mib2c-update pour la première fois, il créera plusieurs répertoires cachés et un fichier .mib2c-updaterc. Vous devez modifier le fichier .mib2c-udpaterc pour spécifier deux valeurs. La première, UPDATE_OID, est le nom de la table à spécifier lors de l'exécution de mib2c. La seconde, UPDATE_CONF, est le fichier de configuration mib2c à spécifier lors de l'exécution de mib2c.

Des options mib2c supplémentaires peuvent être spécifiées dans UPDATE_MIB2C_OPTS.

BOGUES

mib2c-update n'a été testé que sur des tables individuelles. Spécifier un scalaire ou un MIB entier pourrait ne pas fonctionner.
