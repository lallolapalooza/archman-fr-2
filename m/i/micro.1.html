micro(1) Manuel des commandes générales micro(1)

NOM

micro - Un éditeur de texte moderne et intuitif basé sur le terminal

SYNTAXE

micro [OPTIONS] [FICHIER]...

DESCRIPTION

Micro est un éditeur de texte basé sur le terminal qui vise à être facile à utiliser et intuitif, tout en exploitant toutes les capacités des terminaux modernes. Il est fourni en un seul binaire statique "tout compris" sans dépendances.

Comme son nom l'indique, micro se veut une sorte de successeur de l'éditeur nano en étant facile à installer et à utiliser en cas de besoin, mais micro vise également à être agréable à utiliser à plein temps, que vous travailliez dans le terminal parce que vous le préférez (comme moi), ou parce que vous devez le faire (via ssh).

Utilisez Ctrl-q pour quitter, Ctrl-s pour enregistrer et Ctrl-g pour ouvrir le menu d'aide dans l'éditeur.

OPTIONS

-clean

Nettoie le répertoire de configuration

-config-dir dir

Spécifie un emplacement personnalisé pour le répertoire de configuration

[FICHIER]:LIGNE:COL

Spécifie une ligne et une colonne pour positionner le curseur lors de l'ouverture d'un tampon

-options

Affiche l'aide de toutes les options

-debug

Active le mode débogage (active la journalisation dans ./log.txt)

-version

Affiche le numéro de version et les informations

Les plugins de micro peuvent être gérés en ligne de commande avec les commandes suivantes.

-plugin remove [PLUGIN]...

Supprime un ou plusieurs plugins

-plugin update [PLUGIN]...

Met à jour un ou plusieurs plugins (si aucun argument n'est donné, met à jour tous les plugins)

-plugin search [PLUGIN]...

Recherche un plugin

-plugin list

Liste les plugins installés

-plugin available

Liste les plugins disponibles

Les options de micro peuvent également être définies via des arguments en ligne de commande pour des ajustements rapides. Pour une vraie configuration, veuillez utiliser le fichier settings.json (voir 'help options').

-option valeur

Définit `option` à `valeur` pour cette session. Par exemple : `micro -syntax off file.c`

CONFIGURATION

Micro utilise $MICRO_CONFIG_HOME comme répertoire de configuration. Si cette variable d'environnement n'est pas définie, il utilise $XDG_CONFIG_HOME/micro à la place. Si cette variable d'environnement n'est pas définie, il utilise ~/.config/micro comme répertoire de configuration. Dans la documentation, nous utilisons ~/.config/micro pour faire référence au répertoire de configuration (même s'il peut en réalité se trouver ailleurs si vous avez défini l'une des variables d'environnement ci-dessus).

AVIS

Cette page de manuel est uniquement destinée à servir de guide rapide pour l'invocation de micro et n'a pas pour but de remplacer la documentation complète incluse avec micro, qui est accessible depuis micro. Micro vous indique quelle combinaison de touches appuyer pour obtenir de l'aide en bas à droite.

BOGUES

Une liste complète des bogues ne sera pas répertoriée dans cette page de manuel. Consultez la page Github à l'adresse https://github.com/zyedidia/micro/issues pour une liste des bogues connus et pour signaler tout nouveau bogue que vous pourriez rencontrer. Nous nous efforçons de corriger les bogues aussi rapidement que possible.
