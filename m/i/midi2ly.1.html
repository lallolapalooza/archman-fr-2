MIDI2LY(1) Commandes utilisateur MIDI2LY(1)

NOM

midi2ly - page de manuel pour midi2ly (LilyPond) 2.24.4

SYNTAXE

midi2ly [OPTION]... FICHIER

DESCRIPTION

Convertit MIDI en entrée LilyPond.

OPTIONS

-a, --absolute-pitches
imprimer les hauteurs absolues
-d, --duration-quant=DUR
quantifier les durées de notes sur DUR
-D, --debug
impression de débogage
-e, --explicit-durations
imprimer les durées explicites
-h, --help
afficher cette aide et quitter
-i, --include-header=FICHIER
précéder la sortie de FICHIER
-k, --key=ALT[:MINEURE]
définir la tonalité : ALT=+dièses|-bémols ; MINEURE=1
-o, --output=FICHIER
écrire la sortie dans FICHIER
-p, --preview
aperçu des 4 premières mesures
-q, --quiet
supprimer les messages de progression et les avertissements concernant les voix excessives
-s, --start-quant=DUR
quantifier les débuts de notes sur DUR
-S, --skip
utiliser s au lieu de r pour les silences
-t, --allow-tuplet=DUR*NUM/DEN
autoriser les durées de triolet DUR*NUM/DEN
-V, --verbose
être verbeux
--version
afficher le numéro de version et quitter
-w, --warranty
afficher la garantie et les droits d'auteur
-x, --text-lyrics
traiter chaque texte comme une parole

EXEMPLES

$ midi2ly --key=-2:1 --duration-quant=32 --allow-tuplet=4*2/3 --allow-tuplet=2*4/3 foo.midi

SIGNALEMENT DE BOGUES

Signaler les bogues à bug-lilypond@gnu.org

VOIR AUSSI

La documentation complète de midi2ly est maintenue sous forme de manuel Texinfo. Si les programmes info et midi2ly sont correctement installés sur votre système, la commande

info midi2ly

devrait vous donner accès au manuel complet.
