Nom

mcopy - copie des fichiers MSDOS vers/depuis Unix

Note de prudence

Cette page de manuel a été générée automatiquement à partir de la documentation texinfo de mtools et peut ne pas être entièrement précise ou complète. Voir la fin de cette page de manuel pour plus de détails.

Description

mcopy est utilisé pour copier des fichiers MS-DOS vers et depuis Unix. Il utilise la syntaxe suivante :

mcopy [-bspanvmQT] [-D option_clash] fichier_source fichier_cible
mcopy [-bspanvmQT] [-D option_clash] fichier_source [ fichiers_source... ] répertoire_cible
mcopy [-tnvm] fichier_source_MSDOS

Mcopy copie le fichier spécifié vers le fichier nommé, ou copie plusieurs fichiers vers le répertoire nommé. La source et la cible peuvent être des fichiers MS-DOS ou Unix.

L'utilisation d'une désignation de lettre de lecteur sur les fichiers MS-DOS, 'a:' par exemple, détermine la direction du transfert. Une désignation de lecteur manquante implique un fichier Unix dont le chemin commence dans le répertoire courant. Si une lettre de lecteur source est spécifiée sans nom de fichier attaché (par exemple mcopy a: .), tous les fichiers sont copiés depuis ce lecteur.

Si seul un seul paramètre source MS-DOS est fourni (par exemple "mcopy a:foo.exe"), une destination implicite du répertoire courant (`.') est supposée.

Un nom de fichier de `-' signifie l'entrée standard ou la sortie standard, selon sa position sur la ligne de commande.

Mcopy accepte les options de ligne de commande suivantes :

t 
Transfert de fichier texte. Mcopy traduit les retours chariot/sauts de ligne entrants en sauts de ligne lors de la copie de MS-DOS vers Unix, et vice-versa lors de la copie d'Unix vers MS-DOS. De plus, la copie s'arrête aux caractères Control-Z lors de la copie de MS-DOS vers Unix, et Control-Z est ajouté à la fin lors de la copie d'Unix vers MS-DOS.
b 
Mode batch. Optimisé pour les copies récursives énormes, mais moins sécurisé en cas de crash pendant la copie.
s 
Copie récursive. Copie également les répertoires et leur contenu
p 
Conserve les attributs des fichiers copiés
Q 
Lors de la copie de plusieurs fichiers, quitte dès qu'une copie échoue (par exemple en raison d'un manque d'espace de stockage sur le disque cible)
a 
Transfert de fichier texte (ASCII). Identique à t ci-dessus.
T 
Transfert de fichier texte (ASCII) avec conversion de jeu de caractères. Diffère de -a en ce que ASCII traduit également les caractères PC-8 entrants en équivalents ISO-8859-1 autant que possible. Lors de la lecture de fichiers DOS, les caractères non traduisibles sont remplacés par '#'; lors de l'écriture de fichiers DOS, les caractères non traduisibles sont remplacés par '.'.
n 
Pas de confirmation lors de l'écrasement de fichiers Unix. ASCII n'avertit pas l'utilisateur lors de l'écrasement d'un fichier Unix existant. Si le fichier cible existe déjà, et que l'option -n n'est pas activée, mcopy demande s'il faut écraser le fichier ou renommer le nouveau fichier (voir `gestion des conflits de noms' pour les détails). Pour désactiver la confirmation pour les fichiers DOS, utilisez -o.
m 
Conserve l'heure de modification du fichier.
v 
Verbeux. Affiche le nom de chaque fichier lors de sa copie.

Bugs

Contrairement à MS-DOS, l'opérateur '+' (ajout) de MS-DOS n'est pas supporté. Cependant, vous pouvez utiliser mtype pour obtenir le même effet :

mtype a:fichier1 a:fichier2 a:fichier3 >fichier_unix
mtype a:fichier1 a:fichier2 a:fichier3 | mcopy - a:fichier_msdos

*   
Pour générer une copie imprimable à partir de la documentation texinfo, exécutez les commandes suivantes : 
    ./configure; make dvi; dvips mtools.dvi

*   
Pour générer une copie html, exécutez : 
    ./configure; make html

Une copie html pré-générée peut être trouvée à l'adresse `http://www.gnu.org/software/mtools/manual/mtools.html'

*   
Pour générer une copie info (navigable avec le mode info d'emacs), exécutez : 
    ./configure; make info

La documentation texinfo est la plus belle lorsqu'elle est imprimée ou en html. En effet, dans la version info, certains exemples sont difficiles à lire en raison des conventions de citation utilisées dans info.
