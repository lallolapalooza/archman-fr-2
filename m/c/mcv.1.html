NOM

mcv - convertisseur de fichiers de maillage

SYNTAXE

mcv [options] [imfile] [omfile] [oxfile]

DESCRIPTION

Le programme mcv convertit les fichiers de maillage Scotch vers et depuis d'autres formats de fichiers externes.

Le fichier imfile est converti en fichier de maillage omfile, les données géométriques optionnelles étant placées dans le fichier géométrique oxfile, s'il est disponible.

Lorsque les noms de fichiers ne sont pas spécifiés, les données sont lues depuis l'entrée standard et écrites vers la sortie standard. Les flux standard peuvent également être représentés explicitement par un tiret '-'.

Lorsque les bibliothèques appropriées ont été incluses lors de la compilation, mcv peut gérer directement les maillages compressés, à la fois en entrée et en sortie. Un flux est traité comme compressé chaque fois que son nom est suffixé par une extension de fichier compressé, comme dans 'brol.msh.bz2' ou '-.gz'. Les formats de compression qui peuvent être pris en charge sont le format bzip2 ('.bz2'), le format gzip ('.gz') et le format lzma ('.lzma').

OPTIONS

-h
Afficher une aide.
-i?ifmt
Définir le format du fichier de maillage d'entrée, qui peut être :
b?num
Format Boeing-Harwell. C'est un format de matrice élémentaire. Seules les matrices carrées sont prises en charge. Dans le cas où le fichier contient plusieurs matrices, le paramètre num permet à l'utilisateur de fournir l'indice de la matrice à convertir, en commençant à 0. Lorsque le paramètre num n'est pas défini, il est supposé être 0.
s
Format de maillage Scotch.
-o?ofmt
Définir le format du fichier de maillage de sortie, qui peut être :
s
Format de maillage Scotch. C'est le seul choix possible à l'heure actuelle.
-V
Afficher la version du programme et le copyright.

EXEMPLE

Convertir un maillage élémentaire Harwell-Boeing en un maillage Scotch.

    $ mcv -ib brol.hb brol.msh
