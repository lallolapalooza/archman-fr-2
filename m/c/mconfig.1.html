NOM

mconfig, - Utilitaire pour modifier les fichiers de configuration .NET

SYNTAXE

mconfig [options] commande [paramètres_commande]

DESCRIPTION

mconfig peut être utilisé pour éditer les fichiers de configuration .NET, en ajoutant des "fonctionnalités" (c'est-à-dire des ensembles d'instructions xml) définies dans l'un des fichiers de configuration lus par mconfig. Le fichier de configuration peut également définir des structures de fichiers de configuration par défaut, ce qui peut être utile pour le démarrage de vos projets .NET.

Pour voir la liste des commandes reconnues, des fichiers de configuration et des fonctionnalités par défaut, exécutez mconfig sans paramètres.

OPTIONS

-c <fichier_config>, --config=<fichier_config>
Lit le fichier de configuration spécifié après avoir lu les autres fichiers de configuration préconfigurés pour l'utilitaire. Les paramètres du fichier spécifié remplacent ceux trouvés dans les autres emplacements de configuration.
-t {any | web | application}, --target={any | web | application}
Les fonctionnalités et les fichiers de configuration par défaut définis dans les fichiers de configuration mconfig peuvent être assignés à l'une des trois cibles : web (pour les fonctionnalités/fichiers de configuration ASP.NET), application - pour les applications .NET, any - applicable aux deux cibles précédentes. La valeur par défaut est any.
-?, -h, --help
Affiche un résumé de l'utilisation.
-v, --version
Affiche la version de mconfig

COMMANDES

{addfeature, af} <nom_fonctionnalite> [chemin_fichier_config]
Ajoute la fonctionnalité nommée <nom_fonctionnalite> au fichier de configuration spécifié. Si [chemin_fichier_config] est omis, le nom du fichier de configuration de sortie sera choisi en fonction de la cible sélectionnée (voir l'option -t). La cible web génère la configuration dans un fichier nommé Web.config, et la cible application génère dans un fichier nommé application.exe.config. La cible any n'a pas de nom de fichier de sortie par défaut.

Si le fichier de configuration spécifié existe, la fonctionnalité sera injectée aux emplacements spécifiés par la configuration de mconfig. Si le fichier de configuration cible n'existe pas, il sera créé et ne contiendra que la fonctionnalité spécifiée et toutes ses dépendances.

{defaultconfig, dc} [nom_config [repertoire_cible]]
Génère un fichier de configuration par défaut en utilisant l'entrée de configuration nommée [nom_config] et sort le fichier de configuration résultant dans le répertoire spécifié par l'option [repertoire_cible]. Si [nom_config] est omis, il prend par défaut Web.config pour la cible web et la cible application. La cible any ne spécifie aucun nom de fichier de configuration de sortie par défaut. Si le paramètre [repertoire_cible] est omis, il prend par défaut le répertoire courant.

Le nom du fichier de configuration de sortie créé dans [repertoire_cible] est indiqué dans la définition de la structure du fichier de configuration.

FICHIERS

Les fichiers de configuration sont lus dans l'ordre indiqué ci-dessous. Chaque fichier ultérieur peut remplacer les paramètres trouvés dans les fichiers lus avant lui.

$prefix/etc/mono/mconfig/config.xml
Le fichier de configuration par défaut, distribué avec mconfig. $prefix est le préfixe d'installation de mconfig spécifié au moment de la compilation.
$config_dir/mconfig/config.xml
$config_dir est le répertoire spécifié dans la variable d'environnement XDG_CONFIG_HOME ou,
s'il est vide, dans le répertoire .config situé dans le répertoire personnel de l'utilisateur. Ce fichier n'est pas distribué avec Mono.
./mconfig.xml
Fichier de configuration local qui peut contenir des paramètres par application.
