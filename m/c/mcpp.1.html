NOM

mcpp - Matsui CPP, un préprocesseur C alternatif

SYNTAXE

mcpp [options] [<fichier_entree> [<fichier_sortie>]]

DESCRIPTION

mcpp est un préprocesseur C/C++ avec la plus haute conformité qui implémente C90, C99 et C++98. mcpp possède des diagnostics pléthoriques et de nombreux #pragmas. Il est utile pour vérifier la portabilité de votre programme, ainsi que pour déboguer des macros compliquées. Ceci est une page de manuel pour mcpp de la construction indépendante du compilateur.

OPTIONS

mcpp attend deux noms de fichiers comme arguments, <fichier_entree> et <fichier_sortie>. S'ils ne sont pas spécifiés, <fichier_entree> est par défaut l'entrée standard et <fichier_sortie> est par défaut la sortie standard.

Il accepte les options suivantes.

Options couramment utilisées :

-@MODE
Spécifie le mode de préprocessing. MODE doit être l'un de ces 4 :
-@std
Mode conforme au standard. (défaut)
-@poststd, -@post
Mode spécial 'post-Standard'.
-@kr
Mode K&R 1ère édition.
-@oldprep, -@old
Mode « old_preprocessor » (c'est-à-dire le cpp du « modèle Reiser »).
-@compat
Mode 'compatible' au standard.
-C
Inclure également les commentaires.
-D <macro>[=<valeur>]
Définit <macro> comme <valeur> (défaut :1).
-D <macro(args)>[=<remplacement>]
Définit <macro(args)> comme <remplacement>.
-e <encodage>
Change l'encodage par défaut des caractères multi-octets en l'un des suivants : euc_jp, gb2312, ksc5601, big5, sjis, iso2022_jp, utf8.
-I <répertoire>
Ajoute <répertoire> à la liste de recherche des #include.
-I-
Supprime les répertoires d'inclusion spécifiques au système ou au site.
-j
Ne pas inclure la ligne source dans les diagnostics.
-k
Garder les espaces blancs des lignes d'entrée tels quels.
-M, -MM, -MD, -MMD, -MP, -MQ cible, -MT cible, -MF fichier
Génère la ligne de dépendance du fichier source pour le makefile.
-m32
Change le CPU cible de x86_64, ppc64 en i386, ppc, respectivement.
-m64
Change le CPU cible de i386, ppc en x86_64, ppc64, respectivement.
-[no-]mmx
Définit/Annule la définition de __MMX__.
-N
Ne pré-définit aucune macro non standard.
-o <fichier>
Écrit dans <fichier>.
-P
Ne pas générer les lignes #line.
-Q
Écrit les diagnostics dans « mcpp.err » (défaut : stderr).
-U <macro>
Annule la définition de <macro>.
-v
Affiche la version de mcpp.
-W <niveau>
Définit le niveau d'avertissement à <niveau> (OR de {0,1,2,4,8,16}, défaut :1).
-z
Ne pas afficher le fichier inclus, seulement les macros définies.

Options disponibles avec les options -@std (défaut) ou -@poststd :

-+
Traite le code source C++.
-2
Active les digraphes.
-h <n>
Redéfinit la macro pré-définie __STDC_HOSTED__ en <n>.
-S <n>
Redéfinit __STDC__ en <n>, annule les macros de style ancien.
-V <n>
Redéfinit __STDC_VERSION__ ou __cplusplus en <n>.
C avec -V199901L spécifie le mode C99.
C++ avec -V199901L spécifie le mode compatible C99.

Options disponibles uniquement avec l'option -@std (défaut) :

-@compat
Développe les macros récursives plus que le standard.
-3
Active les trigraphes.
-K
Intègre les annotations de macros dans les commentaires.

Options disponibles avec les options -@std (défaut), -@kr ou -@oldprep :

-a
Traite le code source « assembleur ».

PRAGMA

mcpp possède les directives #pragma suivantes.

#pragma once
Lit le fichier d'en-tête une seule fois, même s'il est inclus plusieurs fois.
#pragma __setlocale( "encodage")
Spécifie l'encodage des caractères multi-octets à « encodage ». Voir l'option -e pour les encodages.
#pragma MCPP put_defines
Affiche toutes les définitions de macros actuellement valides.
#pragma MCPP debug <args>
Commence à afficher les informations de débogage.
<args> doit être un ou plusieurs des éléments suivants :
token expand macro_call path if expression memory getc
#pragma MCPP end_debug <args>
Arrête l'affichage des informations de débogage.
<args> sont les mêmes que pour 'debug'.
Aucun argument ne spécifie tous les arguments.
#pragma MCPP push_macro( "MACRO")
Sauvegarde la définition de la macro dans la pile.
#pragma MCPP pop_macro( "MACRO")
Récupère la définition de la macro depuis la pile.
#pragma MCPP preprocess
« Pré-traite » les fichiers d'en-tête suivants pour mcpp.
#pragma MCPP warning any message
Affiche l'avertissement « any message ».
