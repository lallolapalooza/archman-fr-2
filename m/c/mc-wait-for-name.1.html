NOM

mc-wait-for-name - s'exécute jusqu'à ce qu'un nom D-Bus apparaisse sur le bus de session

SYNTAXE

mc-wait-for-name NOM-BIEN-CONNU

[Service D-BUS]
Name=org.freedesktop.Telepathy.Client.Something
Exec=/usr/bin/mc-wait-for-name org.freedesktop.Telepathy.Client.Something

DESCRIPTION

mc-wait-for-name s'exécute jusqu'à ce qu'un nom de bus apparaisse, puis se termine avec succès. Ceci peut être utilisé comme aide à l'activation de service pour un nom de bus qui n'est pas directement activable, mais qui sera automatiquement fourni (après un certain temps) par la session de bureau.

STATUT DE SORTIE

0
Le nom du bus est apparu.
64 (EX_USAGE)
Erreur d'invocation (trop ou pas assez d'arguments, ou le nom de bus donné n'était pas un nom de bus bien connu syntaxiquement valide).
69 (EX_UNAVAILABLE)
mc-wait-for-name n'a pas pu se connecter au bus de session.
75 (EX_TEMPFAIL)
Le nom n'est pas apparu dans un délai raisonnable.

OPTIONS

Il n'y a pas d'options de ligne de commande supplémentaires.

BOGUES

Le "délai raisonnable" pour attendre est actuellement codé en dur.
