MCDIFF(1) GNU Midnight Commander MCDIFF(1)

NOM

mcdiff - Visionneur de différences interne de GNU Midnight Commander.

UTILISATION

mcdiff [-bcCdfhstVx?] fichier1 fichier2

DESCRIPTION

mcdiff est un lien vers mc, l'exécutable principal de GNU Midnight Commander. L'exécution de GNU Midnight Commander sous ce nom demande le démarrage du visionneur de différences interne qui compare fichier1 et fichier2 spécifiés sur la ligne de commande.

OPTIONS

-b
Force l'affichage en noir et blanc.
-c
Force le mode couleur sur les terminaux où mcdiff utilise par défaut le noir et blanc.
-C <mot-clé>=<couleur-avant>,<couleur-arrière>,<attributs>:<mot-clé>= ...
Spécifie un jeu de couleurs différent. Voir la section Couleurs de mc(1) pour plus d'informations.
-d
Désactive le support de la souris.
-f
Affiche les chemins de recherche compilés pour les fichiers Midnight Commander.
-t
Utilisé uniquement si le code a été compilé avec S-Lang et terminfo : il fait en sorte que Midnight Commander utilise la valeur de la variable TERMCAP pour les informations du terminal au lieu des informations de la base de données des terminaux système.
-V
Affiche la version du programme.
-x
Force le mode xterm. Utilisé lors de l'exécution sur des terminaux compatibles xterm (deux modes d'écran, et capable d'envoyer des séquences d'échappement de souris).

COULEURS

Les couleurs par défaut peuvent être modifiées en ajoutant à la variable d'environnement MC_COLOR_TABLE. Des paires de couleurs de premier plan et d'arrière-plan peuvent être spécifiées par exemple avec :

MC_COLOR_TABLE="$MC_COLOR_TABLE:\
normal=lightgray,black:\
selected=black,green"

FICHIERS

/usr/share/mc/mc.hlp

Le fichier d'aide du programme.

/usr/share/mc/mc.ini

La configuration système par défaut de GNU Midnight Commander, utilisée uniquement si le fichier ~/.config/mc/ini de l'utilisateur est manquant.

/usr/share/mc/mc.lib

Paramètres globaux pour Midnight Commander. Les paramètres de ce fichier affectent tous les utilisateurs, qu'ils aient ou non ~/.config/mc/ini.

~/.config/mc/ini

La configuration propre à l'utilisateur. Si ce fichier est présent, la configuration est chargée à partir de là au lieu du fichier de démarrage système.
