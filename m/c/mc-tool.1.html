NOM

mc-tool - manipuler les comptes Mission Control en ligne de commande

SYNTAXE

mc-tool list

mc-tool add PROFIL NOM-AFFICHAGE [PARAMÈTRE-RÉGLAGES...]

mc-tool add GESTIONNAIRE/PROTOCOLE [PARAMÈTRE-RÉGLAGES...]

mc-tool update COMPTE [PARAMÈTRE-RÉGLAGES...]

mc-tool display COMPTE NOM-AFFICHAGE

mc-tool nick COMPTE NOM-SUCCÉDANÉ

mc-tool service COMPTE NOM-SERVICE

mc-tool icon COMPTE ICONE

mc-tool show COMPTE

mc-tool get COMPTE PARAMÈTRE [PARAMÈTRE...]

mc-tool auto-presence COMPTE STATUT [MESSAGE]

mc-tool request COMPTE STATUT [MESSAGE]

mc-tool auto-connect COMPTE on|off

mc-tool remove COMPTE

DESCRIPTION

L'utilisation de mc-tool dépend de son premier argument (la "commande")

SPÉCIFICATION DES COMPTES

Lorsqu'un nom de compte est nécessaire, il peut être donné sous forme de chemin d'objet complet (par exemple /org/freedesktop/Telepathy/Account/gabble/jabber/example), ou sous forme de suffixe unique spécifique au compte (par exemple gabble/jabber/example).

SPÉCIFICATION DES RÉGLAGES DE PARAMÈTRES

De nombreuses commandes acceptent des arguments représentant les paramètres du gestionnaire de connexion Telepathy (voir la spécification Telepathy pour plus de détails). Chaque argument a la forme suivante :

TYPE:NOM=VALEUR

où TYPE est soit int, uint, bool, ou string (d'autres types de paramètres existent, mais ne sont actuellement pas pris en charge par mc-tool), NOM est le nom du paramètre du gestionnaire de connexion (par exemple account ou password), et VALEUR est la valeur du paramètre (avec les entiers en décimal, et les booléens comme 0 ou 1).

La commande update accepte également des arguments de la forme clear:NOM qui suppriment le paramètre nommé de la configuration du compte.

LIST

mc-tool list liste les comptes disponibles.

ADD

mc-tool add ajoute un compte. Le gestionnaire de connexion et le protocole peuvent être donnés soit comme nom d'un profil Mission Control, (par exemple gtalk), soit comme nom de gestionnaire de connexion et protocole séparés par une barre oblique (par exemple gabble/jabber).

DISPLAY

mc-tool display COMPTE NOM-AFFICHAGE définit la propriété DisplayName de COMPTE à NOM-AFFICHAGE.

NICK

mc-tool nick COMPTE NOM-SUCCÉDANÉ définit la propriété Nickname de COMPTE à NOM-SUCCÉDANÉ.

SERVICE

mc-tool service COMPTE NOM-SERVICE définit la propriété Service de COMPTE à NOM-SERVICE.

ICON

mc-tool icon COMPTE ICONE définit la propriété Icon de COMPTE à ICONE.

SHOW

mc-tool show COMPTE affiche des informations sur COMPTE.

GET

mc-tool get COMPTE PARAMÈTRE [PARAMÈTRE...] affiche les valeurs des paramètres donnés de COMPTE.

ENABLE

mc-tool enable COMPTE définit la propriété Enabled de COMPTE à True.

DISABLE

mc-tool disable COMPTE définit la propriété Enabled de COMPTE à False.

AUTO-PRESENCE

mc-tool auto-presence COMPTE STATUT [MESSAGE] définit la propriété AutomaticPresence de COMPTE à STATUT avec le message optionnel MESSAGE.

REQUEST

mc-tool request COMPTE STATUT [MESSAGE] définit la propriété RequestedPresence de COMPTE à STATUT avec le message optionnel MESSAGE ; c'est ainsi que l'on demande à un compte de se connecter ou de se déconnecter, par exemple.

AUTO-CONNECT

mc-tool auto-connect COMPTE on définit la propriété ConnectAutomatically de COMPTE à True. mc-tool auto-connect COMPTE off la définit à False.
