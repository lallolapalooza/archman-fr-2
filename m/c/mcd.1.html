Nom

mcd - changer de répertoire MSDOS

Note d'avertissement

Cette page de manuel a été générée automatiquement à partir de la documentation texinfo de mtools, et peut ne pas être entièrement exacte ou complète. Voir la fin de cette page de manuel pour plus de détails.

Description

La commande mcd est utilisée pour changer le répertoire de travail mtools sur le disque MS-DOS. Elle utilise la syntaxe suivante :

mcd [répertoiredos]

Sans arguments, mcd rapporte le périphérique actuel et le répertoire de travail. Sinon, mcd change le périphérique actuel et le répertoire de travail actuel par rapport à un système de fichiers MS-DOS.

La variable d'environnement MCWD peut être utilisée pour localiser le fichier où sont stockées les informations sur le périphérique et le répertoire de travail actuel. Le défaut est `$HOME/.mcwd'. Les informations dans ce fichier sont ignorées si le fichier a plus de 6 heures.

Mcd retourne 0 en cas de succès ou 1 en cas d'échec.

Contrairement aux versions MS-DOS de CD, mcd peut être utilisé pour changer vers un autre périphérique. Il peut être judicieux de supprimer les anciens fichiers `.mcwd' à la déconnexion.
