NOM

mcabber - un client Jabber (XMPP) en console simple

SYNTAXE

mcabber [ -h | -V | -f fichier_config ]

DESCRIPTION

mcabber(1) est un petit client Jabber (XMPP) en console. Pour l'instant, il nécessite un fichier de configuration pour démarrer, donc veuillez copier le fichier exemple mcabberrc et adapter vos paramètres de connexion.

Vous devez également posséder un compte Jabber existant pour utiliser ce logiciel, car il ne peut pas encore enregistrer (ou désenregistrer) de comptes.

Voici quelques-unes des fonctionnalités de mcabber :

•Prise en charge de SASL/SSL/TLS.
•Prise en charge de MUC (Multi-User Chat).
•Prise en charge de PGP, OTR
•États de discussion (notifications de frappe)
•Journalisation de l'historique : Si elle est activée (voir la section FICHIER DE CONFIGURATION), mcabber peut enregistrer les discussions dans des fichiers journaux d'historique texte.
•Complétion de commandes : Si possible, mcabber essaiera de compléter votre ligne de commande si vous appuyez sur la touche Tab.
•Historique de la ligne d'entrée : Tout message ou commande saisi est dans l'historique de la ligne d'entrée et peut être réutilisé facilement.
•Actions externes : Certains événements (comme la réception d'un message) peuvent déclencher une action externe telle qu'un script shell si vous l'activez dans votre fichier de configuration. Un script d'événements exemple ("eventcmd") est fourni avec le code source de mcabber, dans le répertoire contrib.
•Modules : mcabber peut charger des modules (également appelés plugins) à la volée qui étendent ses fonctionnalités.

OPTIONS

-h

Message d'aide rapide

-V

Affiche la version de mcabber et les définitions au moment de la compilation.

-f fichier_config

FENÊTRES/VOLETS

L'écran de mcabber(1) est divisé en 4 régions. Le roster, alias liste d'amis, se trouve à gauche. La fenêtre de discussion, ou tampon de discussion, se trouve à droite. La ligne de saisie se trouve en bas de l'écran, sous une petite fenêtre de journal.

Deux lignes d'état entourent la fenêtre de journal. La ligne d'état du bas est la "ligne d'état principale" et reflète l'état général de mcabber. L'autre ligne est la "ligne d'état de discussion" et affiche l'état du contact actuellement sélectionné.

Pour afficher les fenêtres de discussion des contacts, vous devrez entrer en mode discussion. Vous pouvez entrer en mode discussion en appuyant sur Entrée (sauf si le mode vi est activé), et quitter le mode discussion avec la touche ÉCHAP. Envoyer simplement un message activera également le mode discussion (sauf si le mode vi est activé).

L'implémentation à deux modes présente plusieurs avantages : premièrement, elle permet une fonctionnalité précise de message "non lu", comme décrit dans la section suivante ; sans cela, le simple défilement vers un contact spécifique "lira" les nouveaux messages de tous les contacts intermédiaires. Deuxièmement, elle permet de masquer rapidement la conversation d'une seule pression de touche. Troisièmement, elle permet de passer rapidement entre les quelques contacts avec lesquels vous conversez à l'aide de la commande /roster alternate décrite dans une autre section, sans avoir à faire défiler manuellement.

TOUCHES

La saisie de texte se fait dans la ligne de saisie ; les opérations de base sont prises en charge (flèche gauche, flèche droite, touches début/fin, insertion, suppression, retour arrière...).

Les touches PagePréc et PageSuiv sont utilisées pour se déplacer dans le roster.

Les touches flèche Haut/Bas peuvent être utilisées pour se déplacer dans l'historique de la ligne de saisie ; elles sautent à la ligne précédente/suivante de l'historique commençant par la même chaîne (de la première colonne à la colonne du curseur).

Pour envoyer un message, déplacez-vous vers le contact choisi dans la liste d'amis, tapez votre message et appuyez sur Entrée. Si la ligne commence par une barre oblique, elle sera interprétée comme une commande (voir la section COMMANDES ci-dessous). Appuyez sur Échap pour quitter le mode discussion.

ROSTER DE MCABBER

Le premier élément listé dans le roster est [statut], qui conserve un journal de tout ce qui apparaît dans le court

mkinitcpio(1) pacman(8)
fenêtre de log sous la zone de chat principale. Alors que la fenêtre de log était conçue pour afficher les derniers éléments, le tampon [statut] dédié permet une visualisation plus confortable du log, ainsi qu'un défilement de manière standard.

Les noms de groupe sont affichés au-dessus des éléments qui s'y trouvent, et sont indiqués par --- à gauche du nom.

Pour chaque contact Jabber réel, la liste affiche quatre informations : le nom ou l'alias du contact, son statut en ligne, son statut d'autorisation, et s'il y a des messages non lus de ce contact qui vous attendent.

Le statut en ligne est l'un des suivants :

o

en ligne

f

libre pour discuter

a

absent

n

non disponible (labelisé absent prolongé dans certains clients)

d

ne pas déranger

_

hors ligne (ou invisible pour vous)

?

inconnu, signifiant généralement que vous n'êtes pas autorisé à voir le statut de ce contact

x

une salle de conférence à laquelle vous ne participez pas

C

une salle de conférence à laquelle vous participez

Le statut d'autorisation indique si un contact est autorisé à recevoir vos mises à jour de statut en ligne, et est affiché par les crochets entourant le statut en ligne du contact. Des crochets carrés, comme [o], indiquent que ce contact est autorisé à recevoir votre statut. Des accolades, comme {o}, indiquent qu'il n'est pas autorisé à recevoir votre statut.

Lorsqu'il y a des messages non lus d'un contact que vous n'avez pas encore consultés, un signe dièse (#) apparaît dans la section la plus à gauche de la liste pour ce contact. Le signe dièse disparaît une fois que vous avez consulté le tampon de message de ce contact. Lorsque l'attention de l'utilisateur est requise (ou lorsque vous recevez un message contenant votre nom d'utilisateur dans une salle MUC), le signe dièse est remplacé par le signe d'attention, un point d'exclamation (!).

Exemples :

' --- Amis'

Ceci est un groupe nommé Amis

#[o] John

John est en ligne, peut voir votre statut, et vous a envoyé un message que vous n'avez pas encore lu

' {?} Sally'

Ni vous ni Sally ne vous êtes mutuellement autorisés à voir votre statut en ligne

' {a} Jane'

Jane est absente, mais elle ne peut pas voir votre statut en ligne

#[C] x@y.c

Vous participez à la salle de conférence x@y.c, et il y a des messages non lus

COMMANDES

Veuillez vous référer à l'aide en ligne (commande /help), elle est probablement plus à jour que cette page de manuel. De plus, les fichiers d'aide ont été traduits dans plusieurs langues. Vous trouverez un aperçu des commandes de mcabber dans ce manuel.

COMMANDES LIÉES À MCABBER

/add [jid [alias]]

Ajoute l'utilisateur Jabber "jid" à notre liste (groupe par défaut), et envoie une demande de notification à ce contact. Si aucun alias n'est spécifié, le jid est utilisé. Si aucun jid (ou une chaîne vide "") n'est fourni ou si jid est ".", le contact actuel est utilisé.

[jid [alias]]

Ajoute à notre liste "jid" comme "alias" 
Exemple : "/add somebody@jabber.server.com Somebody"

/alias [nom [= ligne de commande]]

Cette commande vous permet d'ajouter des alias qui peuvent simplifier des commandes sophistiquées.

Vous pouvez gérer vos alias par :

(sans arguments)

Affiche la liste des alias actuellement définis

nom

Affiche la valeur de l'alias nommé "nom"

nom=

Supprime l'alias nommé "nom"

nom = ligne de commande

Définit l'alias nommé "nom" avec la valeur "ligne de commande" 
Exemple : "/alias away = status away"

/authorization allow|cancel|request|request_unsubscribe [jid]

Cette commande gère les abonnements de présence : elle vous permet de demander des abonnements de présence à d'autres personnes de votre liste, et vous permet de contrôler qui reçoit vos notifications de présence.

Si aucun JID n'est fourni, le contact actuellement sélectionné est utilisé.

allow

Autorise le contact à recevoir vos mises à jour de présence

cancel

Annule l'abonnement du contact à vos mises à jour de présence

request

Demande un abonnement aux mises à jour de présence du contact

request_unsubscribe

Demande la désinscription des mises à jour de présence du contact

/bind [code_touche [= ligne de commande]]

Lie la commande à la touche donnée sous forme de "code_touche". Pour examiner quelles touches ne sont pas utilisées actuellement, regardez la fenêtre de log de mcabber et appuyez sur la touche examinée. Par exemple : "Unknown key=265" signifie que vous pouvez lier une commande à la touche #265.

(sans arguments)

Affiche la liste des liaisons actuelles

code_touche

Affiche la ligne de commande liée à cette touche

code_touche=

Délier la touche avec le code "code_touche"

code_touche = ligne de commande

Lie la "ligne de commande" à la touche avec le code "code_touche" 
Exemple : "/bind 265 = status away" (265 est F1). +
Note : les codes de touche peuvent être différents en fonction de votre configuration ncurses. +
Astuce : les alias peuvent également être utilisés à la place des commandes.

Efface la fenêtre de chat du contact actuel

close [jid]

Vide tout le contenu du tampon et ferme la fenêtre de chat du contact actuel

close_all

Vide tout le contenu des tampons de chat et ferme les fenêtres de chat

Affiche la liste des tampons existants, avec leur taille (lignes/blocs)

Saute au début du tampon de chat du contact actuel

bottom

Fait défiler le tampon vers le haut de [n] lignes (défaut : une demi-écran)

Fait défiler le tampon vers le bas de [n] lignes (défaut : une demi-écran)

Saute à la première ligne après la [date] spécifiée dans le tampon de chat (format de date : "AAAA-mm-jj")

/chat_disable [--show-roster]

Désactive le mode chat.

Avec --show-roster, le mode plein écran sera désactivé.

/clear

Cette commande est en fait un alias pour "/buffer clear". Elle efface la fenêtre de chat du contact actuel.

/color roster (statut joker (couleur|-)|clear), /color mucnick nick (couleur|-), /color muc (jid|.|*) [on|preset|off|-]

La commande color permet de définir des propriétés de couleur dynamiques de l'écran.

roster clear

Supprime toutes les règles de couleur pour la liste. Tous les éléments de la liste recevront leur couleur par défaut.

roster statut joker couleur

Définit une règle de couleur (ou la remplace, si elle existe déjà). Le statut est une chaîne contenant tous les statuts que l'élément de la liste peut avoir pour que la règle corresponde, ou * si tout statut est OK. Le joker est le joker de correspondance de fichier qui sera appliqué au JID. La couleur est la couleur souhaitée. Si la couleur est -, la règle est supprimée. Si plus d'une règle correspond, la couleur de la dernière créée (non écrasée) est utilisée.

mucnick nick (couleur|-)

Marque le pseudo à colorier avec la couleur donnée. Si un MUC a des pseudos colorés, celui-ci sera utilisé. Si la couleur est -, la couleur est marquée comme choisie automatiquement, ce qui signifie qu'elle ne sera pas utilisée en mode de coloration preset, mais restera la même en mode de coloration on.

muc (jid|.|*) [on|preset|off|-]

Définit un mode de coloration de pseudo MUC. Si un jid (. signifie le jid actuellement sélectionné) est fourni, le mode s'appliquera à ce MUC spécifique. Si * est utilisé, il s'appliquera à tous les MUCs, sauf ceux définis par leur jid. Le mode on colore tous les pseudos, preset uniquement ceux définis manuellement par la commande /color mucnick, et off ne colore aucun. Si non spécifié, le défaut est on. Le mode - supprime le mode du JID donné, ce qui signifie que le mode global s'appliquera. Vous ne pouvez pas supprimer le mode global. Le mode de coloration global par défaut est off.

/connect

Établit la connexion au serveur Jabber.

/del

Supprime le contact actuel de notre liste, se désabonne de sa notification de présence et le désabonne de la nôtre.

/disconnect

Termine la connexion au serveur Jabber.

Remarque : la liste n'est disponible que lorsque la connexion au serveur est active, donc la liste des contacts est vide lorsque la connexion est interrompue.

#N|* ignore [arguments spécifiques à l'événement]

L'événement numéro #N/Tous les événements seront ignorés

#N|* reject [arguments spécifiques à l'événement]

L'événement numéro #N/Tous les événements seront rejetés

list

Liste tous les événements en attente

/move [nomdugroupe]

Déplace le contact courant vers le groupe demandé. Si aucun groupe n'est spécifié, le contact est déplacé vers le groupe par défaut. Si le groupe "nomdugroupe" n'existe pas, il est créé.

Astuce : si le mode chat est activé, vous pouvez utiliser "/roster alternate" pour sauter vers le contact déplacé.

/msay begin|verbatim|send|send_to|toggle|toggle_verbatim|abort

Envoie un message multiligne. Pour écrire un seul message avec plusieurs lignes, le mode multiligne doit être utilisé.

En mode multiligne, chaque ligne (sauf les lignes de commande) tapée dans la ligne d'entrée sera ajoutée au message multiligne. Une fois le message terminé, il peut être envoyé au contact actuellement sélectionné avec la commande "/msay send".

La sous-commande begin active le mode multiligne. Notez qu'elle permet de spécifier un sujet de message.

Le mode multiligne verbatim désactive les commandes, de sorte qu'il est possible de saisir des lignes commençant par une barre oblique. Seule la commande "/msay" (avec les paramètres send ou abort) peut être utilisée pour quitter le mode verbatim.

La sous-commande toggle peut être liée à une touche pour utiliser le mode multiligne rapidement (par exemple, "bind M13 = msay toggle" pour basculer en utilisant la combinaison Meta-Entrée).

begin [sujet]

Entrer en mode multiligne

verbatim

Entrer en mode multiligne verbatim

send [-n|-h]

Envoie le message multiligne courant au contact actuellement sélectionné

send_to [-n|-h] jid

Envoie le message multiligne courant à "jid"

toggle|toggle_verbatim

Bascule vers/depuis le mode multiligne (begin/send)

abort

Quitte le mode multiligne sans envoyer le message 
Les indicateurs -n ou -h transforment le message en "normal" ou "headline" respectivement, par opposition au message "chat" par défaut.

Affiche toutes les politiques OTR dans le tampon de statut

(default|jid) (plain|manual|opportunistic|always)

Définit la politique par défaut ou la politique pour le jid donné. La politique "plain" ne devrait jamais être utilisée, car vous ne pourrez recevoir ni envoyer de messages cryptés OTR. Si vous définissez la politique sur "manual", vous ou votre interlocuteur devrez démarrer le cryptage OTR manuellement (par exemple avec "/otr start"). La politique "opportunistic" le fait elle-même en envoyant une séquence d'espacement spéciale à la fin des messages non cryptés. Ainsi, l'autre client compatible OTR sait que vous souhaitez utiliser OTR. Notez que le premier message sera toujours non crypté si vous utilisez cette politique. Avec la politique "always", aucun message ne sera envoyé en clair. Si vous essayez d'envoyer le premier message non crypté, mcabber essaiera d'établir un canal OTR. Veuillez renvoyer votre message lorsque vous recevez l'information que le canal a été établi. Si quelqu'un vous envoie des messages en texte brut alors que la politique est définie sur "always", vous pourrez lire le message mais il ne sera pas enregistré dans l'historique.

/pgp disable|enable|force|info [jid], /pgp setkey [jid [key]]

Cette commande manipule les paramètres PGP pour le jid spécifié (par défaut, le contact actuellement sélectionné).

Veuillez noter que le cryptage PGP ne sera pas utilisé si aucun support PGP distant n'est détecté, même si PGP est activé avec cette commande. Vous pouvez forcer le cryptage PGP avec la sous-commande "force".

disable [jid]

PGP Commands

disable [jid]

Désactiver le chiffrement PGP pour jid (ou le contact actuellement sélectionné)

enable [jid]

Activer le chiffrement PGP pour jid (ou le contact actuellement sélectionné)

force [jid]

Forcer le chiffrement PGP, même pour les messages hors ligne, et supposer toujours que le destinataire prend en charge PGP. Si un message ne peut pas être chiffré (clé ou id de clé manquant), les messages ne seront pas envoyés du tout. Cette option est ignorée lorsque PGP est désactivé.

info [jid]

Afficher les paramètres PGP actuels pour le contact

setkey [jid [key]]

Définir la clé PGP à utiliser pour chiffrer les messages destinés à ce contact. Si aucune clé n'est fournie, la clé actuelle est supprimée. Vous pouvez utiliser le raccourci-jid "." pour le contact actuellement sélectionné.

/quit

Cette commande ferme toutes les connexions et quitte mcabber.

/rawxml send string

Envoie la "chaîne" (format XML brut) au serveur Jabber.

Aucune vérification n'est effectuée sur la chaîne fournie.

ATTENTION ! Utilisez ceci uniquement si vous savez ce que vous faites, sinon vous pourriez terminer la connexion.

Exemple : "/rawxml send <presence><show>away</show></presence>"

/rename name

Renommer le contact ou le groupe actuel en "name". Si "name" est -, le nom est supprimé du carnet d'adresses (et mcabber affichera le JID ou le nom d'utilisateur).

/request last|ping|time|vcard|version [jid]

Envoie une requête "IQ" au contact actuel, ou à l'utilisateur Jabber spécifié. Si la ressource n'est pas fournie avec le jid, mcabber enverra la requête à toutes les ressources connues pour cet utilisateur.

last

Demande les informations "last" (généralement le temps d'inactivité)

ping

Envoie une requête Ping XMPP. Notez que vous devriez utiliser le JID complet car un ping envoyé à un JID nu sera géré par le serveur.

time

Demande l'heure au contact

vcard

Demande la VCard au contact

version

Demande la version au contact

/room join|leave|names|nick|remove|topic|unlock|destroy, /room privmsg|invite|whois|kick|ban|unban|role|affil, /room setopt print_status|auto_whois [value], /room bookmark [add|del] [-autojoin|+autojoin] [-|nick]

La commande room gère les actions des salons de chat multi-utilisateurs (MUC).

join [room [nick [pass]]]

Rejoindre le "room", en utilisant "nick" comme pseudonyme. Si aucun pseudonyme n'est fourni (ou s'il s'agit d'une chaîne vide), la valeur de l'option "nickname" est utilisée (voir le fichier de configuration d'exemple). Si l'entrée actuellement sélectionnée est correctement reconnue comme un salon par mcabber, le raccourci "." peut être utilisé à la place de l'identifiant complet du salon. Un mot de passe peut être fourni pour entrer dans les salons protégés. Si votre pseudonyme contient des espaces, utilisez des guillemets.

leave [message]

Quitter le salon actuel

names [--detail|--short|--quiet|--compact]

Afficher les membres du salon actuel

nick newnick

Changer votre pseudonyme dans le salon actuel

privmsg nick msg

Envoyer un message privé "msg" à "nick"

remove

Supprimer le salon actuel du carnet d'adresses (vous devez avoir quitté ce salon auparavant)

topic -|newtopic

Définir le sujet du salon actuel

unlock

Déverrouiller le salon actuel (si vous en êtes le propriétaire)

destroy [reason]

Détruire le salon actuel (à utiliser avec prudence !)

whois nick

Afficher les informations MUC concernant "nick"

ban jid [reason]

Bannir jid du salon actuel

unban jid

Débannir jid du salon actuel

invite jid [reason]

Inviter jid dans le salon actuel

kick nick [reason]

Expulser "nick" du salon actuel

role nick role [reason]

Changer le rôle de nick (le rôle peut être "none", "visitor", "participant", "moderator")

affil jid affil [reason]

Changer l'affiliation de jid (l'affiliation peut être "none", "member", "admin", "owner")

setopt print_status|auto_whois [value]

Changer les paramètres du salon actuel Pour print_status, les valeurs possibles sont "default", "none", "in_and_out", "all". Pour auto_whois, les valeurs possibles sont "default", "off", "on". Lorsque la valeur est "default", les options muc_print_status / muc_auto_whois sont utilisées.

bookmark [add|del] [-autojoin|+autojoin] [-|nick]

Ajouter, supprimer ou mettre à jour un marque-page (par défaut, c'est ajouter). Si autojoin est défini, mcabber rejoindra automatiquement le salon MUC lorsqu'il se connectera au serveur. Pour voir la liste des marque-pages, utilisez /room bookmark dans le tampon d'état.

/roster bottom|top|up|down|group_prev|group_next, /roster alternate|unread_first|unread_next, /roster search bud, /roster display|hide_offline|show_offline|toggle_offline, /roster item_lock|item_unlock|item_toggle_lock, /roster hide|show|toggle, /roster note [-|text]

La commande roster manipule le carnet d'adresses/liste de contacts.

Voici les paramètres disponibles :

bottom

Aller en bas de la liste des contacts

top

Aller en haut de la liste des contacts

up [n]

Monter [n lignes] dans la liste des contacts

down [n]

Descendre [n lignes] dans la liste des contacts

group_prev

Aller au groupe précédent dans la liste des contacts

group_next

Aller au groupe suivant dans la liste des contacts

alternate

Aller au contact alternatif. Le contact "alternatif" est le dernier contact quitté tout en étant en mode chat. Cette commande est donc particulièrement utile après des commandes comme "/roster unread_next" (Ctrl-q).

unread_first

Aller au premier message non lu

unread_next

Aller au prochain message non lu

search bud

Rechercher un contact dont le nom ou le jid contient "bud" (uniquement dans la liste des contacts affichée)

display [mask]

Voir ou mettre à jour le filtre de la liste des contacts. Le masque doit contenir les lettres raccourcies des statuts que vous souhaitez voir ([o]nline, [f]ree_for_chat, [d]o_not_disturb, [n]ot_available, [a]way, [_]offline). Par exemple "ofdna" pour n'afficher que les contacts connectés.

hide_offline

Masquer les contacts hors ligne (équivalent à /roster display ofdna)

show_offline

Afficher les contacts hors ligne (équivalent à /roster display ofdna_)

toggle_offline

Activer/désactiver l'affichage des contacts hors ligne

item_lock [jid]

Verrouiller l'élément de la liste des contacts afin qu'il reste visible quel que soit son statut

item_unlock [jid]

Annuler les effets de item_lock

item_toggle_lock [jid]

Inverser le drapeau de verrouillage actuel

hide

Masquer la liste des contacts (fenêtre de chat pleine largeur)

show

Afficher la liste des contacts

toggle

Afficher/masquer la liste des contacts

note [-|text]

Définir/mettre à jour/supprimer une annotation. S'il n'y a pas de texte, l'annotation de l'élément actuel est affichée - si vous êtes dans le tampon d'état, toutes les notes sont affichées. Si le texte est "-", la note est effacée.

/say [-n|-h|--] text

Envoie le message "text" au contact actuellement sélectionné. Cela peut être utile si vous souhaitez envoyer un message commençant par une barre oblique, par exemple.

L'indicateur "-n" transforme le message en type "normal", "-h" en "headline". "--" peut être utilisé pour envoyer des messages de chat commençant par -n ou -h.

/say_to [-n|-h] [-q] [-f file] jid text

Envoie le message "text" au jid spécifié.

Veuillez noter que cette commande ne définit pas la ressource par défaut pour un contact, donc si vous souhaitez envoyer plusieurs messages à une ressource spécifique, vous devrez utiliser "/say_to" pour chaque message.

Vous pouvez envoyer un message à une ressource spécifique du contact actuellement sélectionné en utilisant /say_to ./nom_de_ressource message.

L'indicateur "-n" transforme le message en type "normal", "-h" en "headline". "--" peut être utilisé pour envoyer des messages de chat commençant par -n ou -h.

Lorsque "-q" est utilisé, le message sera envoyé en arrière-plan et ne changera pas la fenêtre active actuelle.

Un fichier texte peut être fourni avec l'option "-f" (auquel cas il n'est bien sûr pas nécessaire de fournir un argument texte après le jid).

/screen_refresh

Rafraîchit l'écran mcabber.

/set [option [= value]]

Affiche ou définit la valeur d'une option.

Sans arguments, affiche une liste de toutes les options définies avec leurs valeurs

/source pattern

Lit les fichiers de configuration qui correspondent au modèle glob (triés par ordre alphabétique).

/status [online|avail|free|dnd|notavail|away [-|statusmessage]], /status message -|statusmessage

Affiche ou définit le statut actuel.

Si aucun statut n'est spécifié, affiche le statut actuel.

Si un message de statut est spécifié, il remplacera les variables message* (ces variables peuvent être définies dans le fichier de configuration).

Si aucune variable message* pertinente n'est définie et qu'aucun message de statut n'est fourni, le message de statut actuel est conservé.

Si StatusMessage est "-", le message de statut actuel est effacé.

Avec la commande "/status message", mcabber mettra à jour le message tout en préservant le statut.

/status_to jid online|avail|free|dnd|no

tavail|away [message], /status_vers jid message statusmessage

Envoyez le statut demandé à l'utilisateur Jabber spécifié.

Si le jid spécifié est « . », le contact actuel est utilisé.

Note : Ce statut sera remplacé par les commandes "/status" ultérieures. Si vous utilisez la fonction d'éloignement automatique, le statut sera également remplacé.

Note : Le jid peut inclure une ressource (par exemple, utilisateur@serveur/ressource).

/version

Affiche la version actuelle de mcabber.
