TARSNAP.CONF(5) Manuel des formats de fichiers TARSNAP.CONF(5)

NOM

tarsnap.conf — fichier de configuration pour tarsnap(1)

DESCRIPTION

Le fichier tarsnap.conf est lu par l'utilitaire tarsnap(1) et spécifie les options par défaut qui seront ignorées si les options en question sont spécifiées en ligne de commande. Les options peuvent être spécifiées dans /etc/tarsnap/tarsnap.conf et/ou ~/.tarsnaprc ; si les deux fichiers entrent en conflit, la configuration locale de l'utilisateur a la priorité.

Les fichiers tarsnap.conf contiennent des lignes composées d'un nom d'option sensible à la casse et de zéro ou un paramètre selon l'option. Les lignes vides et les lignes commençant par un caractère ‘#’ sont ignorées.

Si un paramètre commence par un caractère ‘~’, il sera remplacé par le répertoire personnel de l'ID utilisateur effectif.

Les options suivantes peuvent être spécifiées :

aggressive-networking
 
cachedir cache-dir
 
checkpoint-bytes bytesparcheckpoint
 
disk-pause X
 
exclude pattern
 
force-resources
 
humanize-numbers
 
include pattern
 
insane-filesystems
 
iso-dates
 
keyfile fichier-clé
 
lowmem
 
maxbw
 
maxbw-rate
 
maxbw-rate-down
 
maxbw-rate-up
 
nodump
 
normalmem
 
no-aggressive-networking
 
no-config-exclude
 
no-config-include
 
no-disk-pause
 
no-force-resources
 
no-humanize-numbers
 
no-insane-filesystems
 
no-iso-dates
 
no-maxbw
 
no-maxbw-rate-down
 
no-maxbw-rate-up
 
no-nodump
 
no-print-stats
 
no-quiet
 
no-retry-forever
 
no-snaptime
 
no-store-atime
 
no-totals
 
print-stats
 
quiet
 
retry-forever
 
snaptime fichier
 
store-atime
 
totals
 
verylowmem
 

Chaque option est traitée de la même manière que l'option correspondante --option ; voir tarsnap(1) pour plus de détails. Notez que les options normalmem et no-* ne sont utiles que dans le fichier de configuration spécifique à l'utilisateur ~/.tarsnaprc, auquel cas elles servent à remplacer les options définies dans le fichier de configuration global /etc/tarsnap/tarsnap.conf.

FICHIERS

/etc/tarsnap/tarsnap.conf
Le fichier de configuration global système tarsnap.conf. Les paramètres spécifiés ici ne prennent effet que s'ils ne sont pas spécifiés via le fichier de configuration local de l'utilisateur actuel ou via la ligne de commande.
~/.tarsnaprc
Le fichier de configuration tarsnap.conf pour l'utilisateur actuel. Les paramètres spécifiés ici prennent effet sauf s'ils sont spécifiés via la ligne de commande.
