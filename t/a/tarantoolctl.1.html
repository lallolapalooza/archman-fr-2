TARANTOOLCTL(1) Contrôle des instances Tarantool TARANTOOLCTL(1)

NOM

tarantoolctl - utilitaire pour contrôler les instances Tarantool

SYNTAXE

tarantoolctl COMMANDE [INSTANCE] [FICHIER] [URI] [OPTIONS...]

DESCRIPTION

tarantoolctl peut être utilisé pour introspecter et contrôler l'état des instances Tarantool.

L'"INSTANCE" représente le nom d'un fichier d'instance.

COMMANDES

Les commandes suivantes sont comprises :

start INSTANCE
Démarre l'instance Tarantool spécifiée en ligne de commande si l'instance n'est pas en cours d'exécution. Ne fait rien si une instance est en cours d'exécution.
stop INSTANCE
Arrête l'instance Tarantool spécifiée en ligne de commande si l'instance est en cours d'exécution. Ne fait rien si une instance n'est pas en cours d'exécution.
status INSTANCE
Affiche l'état de l'instance Tarantool spécifiée en ligne de commande (démarrée/arrêtée). Si le fichier pid existe et qu'un socket de contrôle actif existe, le code de retour est 0. Sinon, le code de retour n'est pas 0. Signale les problèmes typiques à stderr (par exemple, le fichier pid existe et le socket de contrôle n'existe pas).
restart INSTANCE
Arrête et démarre l'instance Tarantool spécifiée en ligne de commande si l'instance est en cours d'exécution. Ne fait rien si une instance n'est pas en cours d'exécution.
logrotate INSTANCE
Fait tourner les journaux de l'instance Tarantool spécifiée en ligne de commande si l'instance est en cours d'exécution. Cela fonctionne uniquement si la journalisation dans un fichier est activée dans le fichier d'instance (paramètre "box.cfg{log=...}"). Les pipes/syslog n'ont aucun effet.
check INSTANCE
Vérifie s'il y a des erreurs de syntaxe dans le script d'instance de l'instance Tarantool spécifiée en ligne de commande.
enter INSTANCE
Accède à la console interactive de l'instance Tarantool spécifiée en ligne de commande.
eval INSTANCE FICHIER
COMMANDE | tarantoolctl eval INSTANCE
Évalue un fichier local sur l'instance Tarantool spécifiée en ligne de commande si l'instance est en cours d'exécution. Ne fait rien si une instance n'est pas en cours d'exécution.
connect URI
COMMANDE | tarantoolctl connect URI
Se connecte à un port de console d'administration à l'instance Tarantool avec l'URI spécifiée en ligne de commande. Cela prend en charge les sockets TCP/Unix.
cat FICHIER... [--space=num_espace...] [--show-system] [--from=lsn_debut] [--to=lsn_fin] [--replica=id_replica]
Affiche dans stdout le contenu des fichiers .snap/.xlog spécifiés en ligne de commande.
play URI FICHIER... [--space=num_espace...] [--show-system] [--from=lsn_debut] [--to=lsn_fin] [--replica=id_replica]
Joue le contenu des fichiers .snap/.xlog vers une autre instance Tarantool avec l'URI spécifiée en ligne de commande.

OPTIONS

Les options suivantes sont comprises :

--space=num_espace
Filtre la sortie par numéro d'espace. Peut être passé plusieurs fois.
--show-system
Affiche/joue le contenu des espaces système.
--from=lsn_debut
Affiche/joue les opérations à partir du lsn donné.
--to=lsn_fin
Affiche/joue les opérations jusqu'au lsn donné.
--replica=id_replica
Filtre la sortie par identifiant de réplique. Peut être passé plusieurs fois.

CONFIGURATION

Le fichier contenant les valeurs par défaut système pour tarantoolctl est installé dans "/etc/default/tarantool". Ce fichier est utilisé lorsque tarantoolctl est invoqué par l'utilisateur root. Lorsqu'il est invoqué par un utilisateur local, tarantoolctl recherche d'abord son fichier de configuration par défaut dans le répertoire courant ("$PWD/.tarantoolctl"), puis dans le répertoire personnel de l'utilisateur courant ("$HOME/.config/tarantool/tarantool"). S'il n'est pas trouvé, tarantoolctl se rabat sur les valeurs par défaut intégrées :

default_cfg = {
pid_file  = "/var/run/tarantool",
wal_dir   = "/var/lib/tarantool",
memtx_dir = "/var/lib/tarantool",
vinyl_dir = "/var/lib/tarantool",
log       = "/var/log/tarantool",
username  = "tarantool",
}
instance_dir = "/etc/tarantool/instances.enabled"

La plupart de ces paramètres sont similaires à ceux de "box.cfg{}" :

pid_file
Répertoire pour le fichier pid et le fichier socket de contrôle ; tarantoolctl ajoutera "/nom_instance" au nom du répertoire.
wal_dir
Répertoire pour les fichiers de type *.xlog d'écriture anticipée ; tarantoolctl ajoutera "/nom_instance" au nom du répertoire.
memtx_dir
Répertoire pour les fichiers de type *.snap ; tarantoolctl ajoutera "/nom_instance" au nom du répertoire.
vinyl_dir
Répertoire pour les fichiers vinyl ; tarantoolctl ajoutera "/nom_instance" au nom du répertoire.
log
L'endroit où ira le journal de l'application ; tarantoolctl ajoutera "/nom_instance.log" au nom.
username
L'utilisateur qui exécute l'instance Tarantool. Il s'agit du nom d'utilisateur du système d'exploitation et non du nom d'utilisateur du client Tarantool. Tarantool changera son utilisateur effectif vers cet utilisateur après être devenu un démon.
instance_dir
Le répertoire où tous les fichiers d'instance pour cet hôte sont stockés. Placez les fichiers d'instance dans ce répertoire, ou créez des liens symboliques.

À titre d'exemple complet, vous pouvez prendre le script "example.lua" fourni avec Tarantool et qui définit toutes les options de configuration.

STATUS DE SORTIE

En cas de succès, 0 est retourné, un code d'échec non nul sinon.
