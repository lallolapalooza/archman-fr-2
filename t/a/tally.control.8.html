NOM

tally.control - Garder une trace des créations et suppressions de groupes de nouvelles

SYNOPSIS

tally.control < fichier_journal

DESCRIPTION

tally.control est normalement invoqué quotidiennement par scanlogs. Il lit son entrée standard, qui doit être les fichiers journaux de contrôle newgroup.log et rmgroup.log. Ils contiennent une ligne de résumé décrivant le message de contrôle et l'action entreprise par controlchan, suivie par l'article indenté de quatre espaces, et une ligne vide. Ensuite, tally.control met à jour la liste cumulative des créations et suppressions de groupes de nouvelles qui est conservée dans control.log.

Tous ces fichiers journaux résident dans le répertoire pathlog défini dans inn.conf. Pour les générer, vous devez activer la journalisation des articles de contrôle dans control.ctl(5), comme expliqué dans l'entrée control.log de newslog(5).

FICHIERS

pathbin/tally.control
Le script Shell lui-même utilisé pour comptabiliser les créations et suppressions de groupes de nouvelles.
pathlog/control.log
Ce fichier maintient un compte du nombre de messages de contrôle newgroup et rmgroup vus pour chaque groupe de nouvelles. Le compte correspond au nombre de messages de contrôle avec les arguments indiqués, indépendamment du fait qu'ils aient été effectivement traités. Tous les arguments de contrôle, y compris les invalides, sont comptés. Un exemple de lignes que l'on peut trouver dans ce fichier journal est : 
3 Control: newgroup foo.bar moderated
3 Control: rmgroup misc.removed
1 Control: newgroup misc.created
