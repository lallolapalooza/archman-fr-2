tanh(3) Manuel des fonctions de bibliothèque tanh(3)

NOM

tanh, tanhf, tanhl - fonction tangente hyperbolique

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double tanh(double x);
float tanhf(float x);
long double tanhl(long double x);
Exigences de macro de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

tanhf(), tanhl() :

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions retournent la tangente hyperbolique de x, qui est définie mathématiquement comme :

    tanh(x) = sinh(x) / cosh(x)

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent la tangente hyperbolique de x.

Si x est un NaN, un NaN est retourné.

Si x est +0 (-0), +0 (-0) est retourné.

Si x est l'infini positif (infini négatif), +1 (-1) est retourné.

ERREURS

Aucune erreur ne se produit.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
tanh (), tanhf (), tanhl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C99, POSIX.1-2001.

La variante retournant double est également conforme à SVr4, 4.3BSD, C89.

VOIR AUSSI

acosh(3), asinh(3), atanh(3), cosh(3), ctanh(3), sinh(3)
