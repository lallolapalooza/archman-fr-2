tar.h(0P) Manuel du programmeur POSIX tar.h(0P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

tar.h — définitions étendues de tar

SYNTAXE

#include <tar.h>

DESCRIPTION

L'en-tête <tar.h> définira les constantes symboliques suivantes avec les valeurs indiquées.

Définitions générales :

Nom Valeur Description
TMAGIC "ustar" Utilisé dans le champ magic du bloc d'en-tête ustar, y compris le caractère nul final.
TMAGLEN 6 Longueur en octets du champ magic.
TVERSION "00" Utilisé dans le champ version du bloc d'en-tête ustar, sans le caractère nul final.
TVERSLEN 2 Longueur en octets du champ version.

Définitions du champ Typeflag :

Nom Valeur Description
REGTYPE '0' Fichier régulier.
AREGTYPE '\0' Fichier régulier.
LNKTYPE '1' Lien.
SYMTYPE '2' Lien symbolique.
CHRTYPE '3' Spécial caractère.
BLKTYPE '4' Spécial bloc.
DIRTYPE '5' Répertoire.
FIFOTYPE '6' FIFO spécial.
CONTTYPE '7' Réservé.

Définitions des bits du champ Mode (octal) :

Nom Valeur Description
TSUID 04000 Set UID lors de l'exécution.
TSGID 02000 Set GID lors de l'exécution.
TSVTX 01000 Sur les répertoires, drapeau de suppression restreinte.   
TUREAD 00400 Lecture par le propriétaire.
TUWRITE 00200 Écriture par le propriétaire spécial.
TUEXEC 00100 Exécution/recherche par le propriétaire.
TGREAD 00040 Lecture par le groupe.
TGWRITE 00020 Écriture par le groupe.
TGEXEC 00010 Exécution/recherche par le groupe.
TOREAD 00004 Lecture par autrui.
TOWRITE 00002 Écriture par autrui.
TOEXEC 00001 Exécution/recherche par autrui.
