tagmp3(1) Manuel utilisateur tagmp3(1)

NOM

tagmp3 - manipuler les balises ID3v1

SYNTAXE

tagmp3 [ -n ] mode [ format ] [ fichier ] ...

DESCRIPTION

tagmp3 vous permet de définir et de supprimer les balises ID3v1 des fichiers mp3. De plus, le mode move peut être utilisé pour déplacer des fichiers mp3 selon leur balise ID3v1. Une balise ID3v1 est un bloc d'informations supplémentaires telles que le nom de l'artiste, l'album et le genre. Les balises ID3v1 sont affichées par la plupart des lecteurs mp3.

MODE

show
affiche la balise ID3v1 du fichier.
set
définit la balise ID3v1 du fichier selon le format.
move
déplace le fichier vers une destination basée sur FORMAT.
del
supprime la balise ID3v1 du fichier, s'il y en a une.
list
affiche les genres musicaux numériques ainsi que leur signification.
-h
affiche un message d'aide (pas si court).
-v
affiche la version et quitte.

OPTIONS

-n
Montre ce qui sera fait, ne modifie aucun fichier.

CHAINE DE FORMAT

La chaîne de format est une chaîne de caractères composée de zéro ou plusieurs directives : des caractères ordinaires (pas %) qui ne sont pas interprétés et des spécifications de conversion, chacune résultant en la substitution du champ de balise ID3v1 correspondant. Chaque spécification de conversion est introduite par le caractère %. Les lignes suivantes décrivent chaque spécification de conversion avec son champ ID3v1 associé. La séquence spéciale %% est substituée par un seul %.

%A
Nom de l'Artiste
%a
Nom de l'Album
%t
Titre de la Chanson
%T
Numéro de Piste
%y
Année
%g
Genre
%c
Commentaires

chaîne de format pour le mode set

Pour le mode set, la chaîne de format est une liste de champs ID3v1 suivis d'un ':' (les caractères suivants sont la valeur du champ) ou d'un '?' (demander à l'utilisateur la valeur du champ)

exemple : tagmp3 set "%A:Pink Floyd %a:The Wall %t? %T?" *.mp3
Pour chaque mp3 de ce répertoire, définit le nom de l'artiste à Pink Floyd et l'album à The Wall. Pour chaque fichier, demande le titre et le numéro de piste. Laisse les autres champs inchangés. Attention, le champ genre nécessite une valeur numérique. Les genres connus peuvent être affichés avec le mode list.

chaîne de format pour le mode move

La chaîne de format est le chemin de destination où chaque identifiant de champ est substitué par la valeur de la balise.

exemple : tagmp3 move "/home/foo/mp3/%A/%a/%T-%t.mp3" *.mp3
avec l'exemple set ci-dessus déplacera tous les mp3 vers "/home/foo/mp3/Pink Floyd/The Wall/{piste}-{titre}.mp3"
Si vous préférez le schéma de nommage "plat", vous utiliserez quelque chose comme
tagmp3 move "%A-%t.mp3" *.mp3

NOTES

Le mode move ne remplace jamais les fichiers.
Le mode move crée les répertoires intermédiaires spécifiés dans la chaîne de format. La création de chaque répertoire doit être confirmée par l'utilisateur.
Les balises ID3v2 ne sont pas supportées pour le moment.
Si un fichier ne peut pas être déplacé (type de fichier incorrect, balise ID3v1 absente ou champ vide, ...), il est laissé intact.
Les faux mp3 (c'est-à-dire les fichiers Wave avec l'extension .mp3) sont déplacés dans le répertoire "fake-mp3/" en mode move. Le mode set refuse de les taguer car cela ajouterait des artefacts indésirables à la fin de la chanson.

BOGUES

Plein :)
Pour le mode move, la source et la destination doivent résider sur le même système de fichiers / partition.
