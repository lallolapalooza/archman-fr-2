FBB::TableLines(3bobcat) Classe de support de tableau FBB::TableLines(3bobcat)

NOM

FBB::TableLines - Une spécialisation de TableSupport pour écrire des lignes de séparation horizontales

SYNTAXE

#include <bobcat/tableLines>
Option de liaison : -lbobcat

DESCRIPTION

Cette classe est une spécialisation de FBB::TableSupport et peut être utilisée pour écrire des séparateurs de lignes horizontaux (et verticaux) dans des tableaux générés par des objets Table ou TableBuf.

ESPACE DE NOM

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

FBB::TableSupport

CONSTRUCTEURS

Les constructeurs par défaut, de déplacement et l'opérateur d'affectation par déplacement sont disponibles.

FONCTIONS MEMBRES

Tous les membres publics de TableSupport sont disponibles. Référez-vous à la page de manuel tablesupport(3bobcat) pour les détails.

EXEMPLE

#include <iostream>
#include <bobcat/table>
#include <bobcat/tablelines>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    TableLines tablelines;
                                // largeur/séparateurs des colonnes 0, 1 et 2
    tablelines << 0 << " | " << " | ";
                                // ligne horizontale sur les colonnes 1 et 2 de la ligne 1
    tablelines << TableLines::HLine(1, 1, 3);
    Table tab(tablelines, 3, Table::ROWWISE, Table::EQUALWIDTH);
    // ou: Table tab(tablelines, 3, Table::ROWWISE);
    tab << Align(0, std::left);     // définir un alignement non par défaut pour la colonne
    tab.fill(argv + 1, argv + argc);// remplir la plage de valeurs
    cout << tab << ’\n’;            // compléter le tableau et l'insérer
    tab << "hello" << "" << "wo";   // ajouter des éléments supplémentaires.
    if (tab.nRows() > 2)
        tab << Align(2, 2, center); // définir la mise en page d'un élément spécifique
    cout << tab << ’\n’;
}
