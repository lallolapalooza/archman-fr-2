FBB::TableSupport(3bobcat) Classe de base du support de table FBB::TableSupport(3bobcat)

NOM

FBB::TableSupport - Définit les protocoles pour les classes de support de table

SYNTAXE

#include <bobcat/tableSupport>
Option de liaison : -lbobcat

DESCRIPTION

FBB::TableSupport est utilisée par les objets FBB::Table et FBB::TableBuf, gérant une partie de leur fonctionnalité. Les utilisateurs peuvent dériver des classes de TableSupport, en redéfinissant ses membres virtuels pour déterminer la disposition réelle des tables. Par défaut, les membres virtuels de TableSupport ne séparent pas les colonnes de la table les unes des autres.

La bibliothèque Bobcat offre la classe spécialisée TableLines qui étend les fonctionnalités de base de TableSupport, offrant des moyens de séparer les lignes par des lignes horizontales (partielles) (voir tablelines(3bobcat) pour plus de détails).

Une gestion plus spécialisée peut être réalisée en dérivant de nouvelles classes de FBB::TableSupport, en redéfinissant des membres pour qu'ils implémentent les intentions du programmeur. Un objet de cette classe dérivée peut être passé à un constructeur de FBB::Table ou FBB::TableBuf, pour activer la gestion spéciale.

ENUMERATION

L'énumération ColumnType définit les valeurs suivantes (voir aussi la description de la struct HLine, ci-dessous) :

o
SKIP :
une section d'une ligne séparant les lignes doit rester vide. Cette valeur n'est normalement pas utilisée par les applications ;
o
USE :
une section d'une ligne séparant les lignes doit être utilisée (par exemple, en écrivant une ligne (horizontale)) ;
o
LEFT_FULL :
une ligne (horizontale) doit être écrite sur toute la largeur du séparateur à gauche d'une série de colonnes ;
o
RIGHT_FULL :
une ligne (horizontale) doit être écrite sur toute la largeur du séparateur à droite d'une série de colonnes ;
o
LEFT_MID :
une ligne (horizontale) doit être écrite sur la moitié droite de la largeur du séparateur à gauche d'une série de colonnes ; la partie gauche reste vide ;
o
RIGHT_MID :
une ligne (horizontale) doit être écrite sur la moitié gauche de la largeur du séparateur à droite d'une série de colonnes ; la partie droite reste vide ;

La valeur SKIP doit toujours être utilisée seule ; les autres valeurs de l'énumération peuvent être combinées en utilisant l'opérateur OU binaire (|).

TYPE PUBLIC `HLine’

o
struct HLine :
Cette structure a les champs suivants : 
    size_t d_row;
    size_t d_begin;
    size_t d_end;
    size_t d_type;
Elle propose deux constructeurs :
o
HLine(size_t row, size_t begin, size_t end) :
o
HLine(ColumnType type, size_t row, size_t begin, size_t end) :
Les objets de type TableSupport::HLine peuvent être insérés dans un objet TableSupport pour spécifier des sections d'un séparateur horizontal entre les lignes de la table qui doivent être affichées ou ignorées.
Par exemple, pour spécifier qu'un séparateur doit être écrit
o
dans la ligne 1,
o
de la colonne 2 jusqu'à (mais sans inclure) la colonne 5,
o
étendant le séparateur vers la gauche sur la moitié de la largeur du séparateur entre les colonnes 1 et 2, et vers la droite sur toute la largeur du séparateur entre les colonnes 4 et 5
l'objet HLine suivant doit être inséré dans l'objet TableSupport ts : 
ts << HLine(LEFT_MID | RIGHT_FULL, 1, 2, 5);
Plusieurs objets HLine peuvent être insérés, dans n'importe quel ordre, dans des objets TableSupport. Lorsque des plages de colonnes se chevauchent, leurs ColumnType sont fusionnés.

TYPES PROTEGES

o
const_iterator :
L'itérateur const_iterator est défini dans la section protégée de la classe. C'est un itérateur d'entrée retournant des itérateurs vers des objets struct Field (voir ci-dessous) ;
pour les colonnes de table et les séparateurs de colonnes (voir ci-dessous aux membres begin et end)
o
struct Field :
Un Field a deux membres de données : width et type, représentant respectivement la largeur et le ColumnType d'une colonne ou d'une colonne séparatrice. Les valeurs type des objets Field retournés par les membres de TableSupport ne contiennent que des valeurs simples (comme SKIP ou LEFT_MID) (notez que les types de colonnes peuvent être combinés lors de leur insertion dans des objets Table en utilisant des objets HLine).

CONSTRUCTEURS

Les constructeurs par défaut, de copie et de déplacement, ainsi que les opérateurs d'affectation par copie et par déplacement sont disponibles.

OPERATEURS SURCHARGES

Les opérateurs surchargés suivants définissent les séparateurs entre les colonnes. La première valeur insérée dans un objet TableSupport définit le séparateur avant la colonne 0, la suivante définit le séparateur avant la colonne 1, etc., jusqu'à l'insertion du séparateur nColumns + 1, qui définit le séparateur à droite de la dernière colonne de la table. L'insertion de séparateurs supplémentaires est ignorée.

o
TableSupport &operator<<(TableSupport &support, size_t width) :
Cet opérateur définit un séparateur de colonne de width caractères espaces. Width peut être zéro, auquel cas aucun séparateur visible n'est utilisé ;
o
TableSupport &operator<<(TableSupport &support, std::string const &text) :
Cet opérateur définit un séparateur à travers du texte. La longueur du text définit la largeur du séparateur. Aucun séparateur n'est utilisé lorsque text est vide ;
o
TableSupport &operator<<(TableSupport &support, HLine const &hsep) :
Cet opérateur définit comment un séparateur horizontal d'une ligne donnée doit être affiché (voir la description de HLine ci-dessus).

FONCTIONS MEMBRES PUBLIQUES

o
void hline(size_t row) const :
Lors de l'insertion d'une table dans un std::ostream, les objets Table et TableBuf appellent ce membre juste avant que la ligne indiquée (décalage) ne soit insérée dans un std::ostream. Il appelle le membre virtuel v_hline, en lui passant row. Par défaut, v_hline n'effectue aucune action ;
o
void hline() const :
Lors de l'insertion d'une table dans un std::ostream, les objets Table et TableBuf appellent ce membre après l'insertion de la dernière ligne de la table. Il appelle le membre virtuel v_hline sans arguments, qui appelle par défaut hline(nRows) ;
o
void v_hline(size_t row) :
Les classes dérivées peuvent redéfinir ce membre virtuel pour implémenter la façon dont les séparateurs horizontaux doivent être affichés. Par défaut, cette fonction ne fait rien. Elle est appelée par la fonction membre hline (voir ci-dessus).
o
const_iterator begin() const :
Retourne un itérateur pointant vers le premier élément de la structure de table interne. Les éléments retournés sont des Fields décrivant les colonnes de la table et les séparateurs de colonnes.
o
const_iterator end() const :
Retourne un itérateur pointant vers le dernier élément de la structure de table interne.
o
size_t nColumns() const :
Retourne le nombre de colonnes dans la table.
o
size_t nSepColumns() const :
Retourne le nombre de séparateurs de colonnes dans la table. Cela correspond à nColumns() + 1.
o
size_t width() const :
Retourne la largeur totale des colonnes de la table, sans tenir compte des séparateurs.
o
size_t sepWidth() const :
Retourne la largeur totale des séparateurs de colonnes.
o
size_t totalWidth() const :
Retourne la largeur totale de la table, y compris les séparateurs.
o
void insert(HLine const &hsep) :
Insère une description de séparateur horizontal (voir le type public HLine ci-dessus).

AUTRES

Les objets TableSupport gèrent les informations relatives à la disposition des tables, comme la largeur des colonnes et des séparateurs, ainsi que les informations relatives aux séparateurs horizontaux.

Les membres suivants sont disponibles pour les classes dérivées de TableSupport. À l'exception de sep et sepWidth, leurs valeurs ne sont définies qu'après l'appel de setParam, qui est appelé à partir du membre def ou des manipulateurs des objets Table ou TableBuf.

o
std::vector<Align> const &align() const:
Retourne une référence à un vecteur d'objets Align, définissant les alignements et les largeurs des colonnes du tableau.
o
const_iterator begin(size_t row) const:
Retourne un itérateur contenant des informations sur le premier élément de colonne lors de l'affichage du séparateur horizontal avant la ligne row. Utilisez l'argument nRows() pour obtenir des informations sur le séparateur après la dernière ligne. Les « éléments de colonne » du tableau comprennent ses séparateurs et ses colonnes de données.
Déréférencer le const_iterator retourné renvoie une structure Field contenant des informations sur la largeur et le type d'un élément de colonne. Déréférencer l'itérateur retourné par begin fournit des informations sur le séparateur de colonne le plus à gauche. En incrémentant l'itérateur, tous les éléments de colonne suivants sont visités. Déréférencer l'itérateur est défini jusqu'à ce que l'itérateur ait atteint la valeur retournée par end (voir ci-dessous) ;
o
size_t colWidth(size_t col) const:
Retourne la largeur de la colonne indiquée ;
o
const_iterator end(size_t row) const:
Retourne un itérateur indiquant la fin de la plage d'itérateurs commençant à begin(row) ;
o
size_t nColumns() const:
Retourne le nombre de colonnes du tableau ;
o
size_t nRows() const:
Retourne le nombre de lignes du tableau ;

std::ostream &out() const:
Retourne une référence au flux dans lequel le tableau est inséré ;

std::vector<std::string> const &sep():
Retourne une référence aux séparateurs définis pour les colonnes du tableau. L'élément col fait référence au séparateur à gauche de la colonne col du tableau, l'élément nColumns() fait référence au séparateur à droite de la colonne la plus à droite ;

FONCTIONS MEMBRES VIRTUELLES

Les fonctions membres suivantes peuvent être redéfinies par les classes dérivées pour redéfinir la manière dont les séparateurs horizontaux et verticaux sont affichés.

o
virtual void v_hline(size_t row) const:
Ce membre est appelé depuis hline(size_t row), en recevant son paramètre row. Sa tâche est d'écrire un séparateur horizontal avant la ligne row. Par défaut, rien n'est inséré. Il peut insérer le séparateur horizontal en itérant sur la plage définie par les membres begin et end, en décidant quoi faire sur la base des objets Field mis à disposition en déréférençant les itérateurs. Alternativement, pour que v_hline insère une ligne horizontale couvrant toute la largeur de la ligne du tableau, l'implémentation suivante peut être utilisée : 
    void Derived::v_hline(size_t row) const
    {
        out() << setfill(’-’) << setw(width()) << "-" << 
                                                setfill(’ ’);
    }
o
virtual void v_hline() const:
Ce membre est appelé depuis hline(). Sa tâche est d'écrire une ligne horizontale (partielle) après la dernière ligne du tableau. Par défaut, il appelle hline(nRows) ;
o
virtual void v_vline(size_t col) const:
Ce membre est appelé depuis vline(size_t col), en recevant son paramètre col. Sa tâche est d'écrire un séparateur avant la colonne de données col. Par défaut, il insère separator[col] s'il est disponible (si ce séparateur n'est pas disponible, aucun séparateur n'est inséré avant la colonne col) ;
o
virtual void v_vline() const:
Ce membre est appelé depuis vline() à la fin de chacune des lignes du tableau. Sa tâche est d'écrire un séparateur de colonne et de terminer la ligne du tableau pour laquelle il est appelé. Par défaut, il insère le séparateur de colonne final (s'il est défini) et un caractère de saut de ligne (\n).
