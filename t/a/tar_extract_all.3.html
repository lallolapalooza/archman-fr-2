tar_extract_all(3)

Paquet: libtar

tar_extract_all(3) Appels de bibliothèques C tar_extract_all(3)

NOM

tar_extract_all, tar_extract_glob, tar_append_tree - fonctions de manipulation d'archives tar de haut niveau

SYNTAXE

#include <libtar.h>

int tar_extract_all(TAR *t, char *prefix);

int tar_extract_glob(TAR *t, char *globname, char *prefix);

int tar_append_tree(TAR *t, char *realdir, char *savedir);

VERSION

Cette page de manuel documente la version 1.2 de libtar.

DESCRIPTION

La fonction tar_extract_all() extrait tous les fichiers de l'archive tar associée au descripteur TAR t dans le chemin nommé par l'argument prefix.

La fonction tar_extract_glob() extrait tous les fichiers correspondant au motif glob donné de l'archive tar associée au descripteur TAR t dans le chemin nommé par l'argument prefix.

La fonction tar_append_tree() ajoute tous les fichiers de l'arborescence de répertoires nommée par realdir à l'archive tar associée au descripteur TAR t. Les noms de chemin stockés dans l'archive tar sont modifiés en remplaçant realdir par savedir, de sorte que les fichiers seront extraits dans savedir.

VALEURS DE RETOUR

En cas de succès, ces fonctions retourneront 0. En cas d'échec, elles retourneront -1 et définiront errno à une valeur appropriée.

ERREURS

Ces fonctions échoueront dans les mêmes conditions que les fonctions tar_skip_regfile(), tar_extract_regfile(), opendir(), lstat(), ou tar_append_file() échouent.

VOIR AUSSI

opendir(2), lstat(2), tar_skip_regfile(3), tar_extract_regfile(3), tar_append_file(3)
