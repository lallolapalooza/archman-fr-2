TANGLE(1) Manuel des commandes générales TANGLE(1)

NOM

tangle - traduire WEB en Pascal

SYNTAXE

tangle [options] fichierweb[.web] [{fichierchange[.ch]|-} [fichierde saída[.p]]]

DESCRIPTION

Cette page de manuel n'est pas censée être exhaustive. La documentation complète pour cette version de TeX se trouve dans le fichier info ou le manuel Web2C: Une implémentation de TeX.

Le programme tangle convertit un document source Web en un programme Pascal qui peut être compilé de la manière habituelle avec le compilateur Pascal en ligne (par exemple, pc(1)). Le fichier de sortie est conditionné en lignes de 72 caractères ou moins, avec comme seule concession à la lisibilité la terminaison des lignes aux points-virgules lorsque cela peut être fait facilement.

Le langage Web permet de préparer un document unique contenant toutes les informations nécessaires à la fois pour produire un programme Pascal compilable et pour produire un document bien formaté décrivant le programme avec autant de détails que le souhaite l'auteur. L'utilisateur de Web doit être familier avec TeX et Pascal. Web fournit également un système de macros relativement simple, bien qu'adéquat, qui permet d'écrire un programme Pascal en petits modules faciles à comprendre.

La ligne de commande doit contenir un, deux ou trois noms. Le premier est pris comme fichier Web (et .web est ajouté s'il n'y a pas d'extension). S'il y a un deuxième nom, il s'agit d'un fichier de modification (et .ch est ajouté s'il n'y a pas d'extension). Le fichier de modification remplace des parties du fichier Web, comme décrit dans la documentation du système Web.

S'il y a un troisième nom, il s'agit du fichier de sortie Pascal (et .p est ajouté s'il n'y a pas d'extension). Dans ce cas, vous pouvez spécifier un fichier de modification vide avec '-' comme deuxième argument. Sinon, le nom du fichier Pascal est formé en ajoutant .p à la racine du nom du fichier Web.

Un deuxième fichier de sortie optionnel est un fichier de pool de chaînes, dont le nom est formé en ajoutant .pool à la racine du nom du fichier Pascal.

OPTIONS

Cette version de tangle comprend les options suivantes. Notez que certaines de ces options peuvent rendre la sortie impropre au traitement par un compilateur Pascal.

--help
Affiche le message d'aide et quitte.
--length nombre
Compare uniquement les nombre premiers caractères des identificateurs lors de la vérification des collisions. La valeur par défaut est 32, le tangle original utilisait 7.
--loose
Lors de la vérification des collisions entre identificateurs, respecte les paramètres des options --lowercase, --mixedcase, --uppercase et --underline. C'est le comportement par défaut.
--lowercase
Convertit tous les identificateurs en minuscules.
--mixedcase
Conserve la casse des identificateurs. C'est le comportement par défaut.
--strict
Lors de la vérification des collisions entre identificateurs, supprime les traits de soulignement et convertit d'abord tous les identificateurs en majuscules.
--underline
Conserve les traits de soulignement (aussi appelés underscores) dans les identificateurs.
--uppercase
Convertit tous les identificateurs en majuscules. C'est le comportement du tangle original.
--version
Affiche les informations sur la version et quitte.

ENVIRONNEMENT

La variable d'environnement WEBINPUTS est utilisée pour rechercher les fichiers d'entrée, ou la valeur par défaut du système si WEBINPUTS n'est pas définie. Voir tex(1) pour les détails de la recherche.
