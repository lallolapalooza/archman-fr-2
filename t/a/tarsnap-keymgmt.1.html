TARSNAP-KEYMGMT(1) Manuel des commandes générales TARSNAP-KEYMGMT(1)

NOM

tarsnap-keymgmt — génère des sous-ensembles des fichiers de clés de tarsnap(1)

SYNTAXE

tarsnap-keymgmt --outkeyfile fichier-nouvelle-clé [-r] [-w] [-d] [--nuke] [--passphrased] [--passphrase-mem maxmem] [--passphrase-time maxtime] fichier-clé ...

tarsnap-keymgmt --print-key-id fichier-clé

tarsnap-keymgmt --print-key-permissions fichier-clé

tarsnap-keymgmt --version

DESCRIPTION

tarsnap-keymgmt lit les fichiers de clés fournis et écrit un nouveau fichier de clés (spécifié par --outkeyfile fichier-nouvelle-clé) contenant uniquement les clés requises pour les opérations spécifiées via les indicateurs -r (lister et extraire les archives), -w (écrire les archives), -d (supprimer les archives) et --nuke. Notez que -d implique -r car il est impossible de supprimer une archive individuelle sans pouvoir la lire ; tandis qu'un fichier de clés généré avec --nuke peut être utilisé pour supprimer toutes les archives stockées, mais pas les archives individuelles.

La liste suivante montre les permissions requises pour les différents tarsnap(1) modes de commande.

--recover
requiert soit (1) -d (suppression d'archives), (2) -w (création d'archives), soit (3) des clés --nuke.
--fsck
requiert soit (1) les clés -w (écriture d'archives) et -r (lecture d'archives), soit (2) les clés -d (suppression d'archives).
--fsck-prune
requiert des clés -d (suppression d'archives), car il faut pouvoir supprimer les archives corrompues.

Si l'option --passphrased est spécifiée, l'utilisateur sera invité à entrer une phrase secrète (deux fois) pour crypter le fichier de clés.

Si l'option --passphrase-mem maxmem est spécifiée, un maximum de maxmem octets de RAM seront utilisés dans la fonction de dérivation de clé scrypt pour crypter le fichier de clés ; il peut être nécessaire de définir cette option si un fichier de clés est créé sur un système disposant de beaucoup plus de RAM que le système sur lequel le fichier de clés sera utilisé.

Si l'option --passphrase-time maxtime est spécifiée, un maximum d'environ maxtime secondes sera utilisé dans la fonction de dérivation de clé scrypt pour crypter le fichier de clés.

Notez que si aucune des options -w, -r, -d ou --nuke n'est spécifiée, un fichier de clés sera produit ne contenant aucune clé. Ceci n'est probablement pas très utile.

L'option --print-key-id fichier-clé affiche l'entier 64 bits correspondant au numéro de machine de la clé. Ceci peut être utile pour des scripts ou des IHM qui gèrent le compte Tarsnap d'un utilisateur, mais n'est probablement pas utile pour une utilisation en ligne de commande.

L'option --print-key-permissions fichier-clé affiche les permissions que possède la clé.

L'option --version affiche le numéro de version de tarsnap-keymgmt, puis quitte.
