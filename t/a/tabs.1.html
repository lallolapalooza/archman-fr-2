tabs(1) Commandes utilisateur tabs(1)

NOM

tabs - définir les taquets de tabulation du terminal

SYNTAXE

tabs [options] [liste-des-taquets]

DESCRIPTION

Le programme tabs efface et définit les taquets de tabulation sur le terminal. Il utilise les capacités clear_all_tabs et set_tab de terminfo. Si l'une d'elles est absente, tabs est incapable d'effacer/définir les taquets de tabulation. Le terminal doit être configuré pour utiliser des tabulations matérielles, par exemple :

stty tab0

Comme clear(1), tabs écrit sur la sortie standard. Vous pouvez rediriger la sortie standard vers un fichier (ce qui empêche tabs de réellement modifier les taquets de tabulation), puis plus tard utiliser cat pour afficher le fichier à l'écran, définissant ainsi les taquets de tabulation à ce moment-là.

Il s'agit de tabulations matérielles, qui ne peuvent pas être interrogées rapidement par les applications exécutées dans le terminal, si tant est qu'elles le puissent. Curses et autres applications en mode plein écran peuvent utiliser des tabulations matérielles pour optimiser leur sortie vers le terminal. Si les taquets de tabulation matériels diffèrent des informations de la base de données du terminal, le résultat est imprévisible. Avant d'exécuter des programmes curses, vous devriez soit réinitialiser les taquets de tabulation à l'intervalle standard

tabs -8

soit utiliser le programme reset, car les séquences d'initialisation normales ne garantissent pas la réinitialisation des taquets de tabulation.

OPTIONS

Options générales

-Tnom
Indique à tabs quel type de terminal utiliser. Si cette option n'est pas donnée, tabs utilisera la variable d'environnement $TERM. Si celle-ci n'est pas définie, il utilisera l'entrée ansi+tabs.
-d
L'option de débogage affiche une ligne de règle, suivie de deux lignes de données. La première ligne de données montre les taquets de tabulation attendus marqués d'astérisques. La seconde ligne de données montre les taquets de tabulation réels, marqués d'astérisques.
-n
Cette option indique à tabs de vérifier les options et d'exécuter toute option de débogage, mais sans modifier les paramètres du terminal.
-V
rapporte la version de ncurses qui a été utilisée dans ce programme, puis quitte.

Le programme tabs traite une seule liste de taquets de tabulation. La dernière option traitée qui définit une liste est celle qui détermine la liste à traiter.

Listes implicites

Utilisez un seul nombre comme option, par exemple, “-5” pour définir des tabulations à l'intervalle donné (dans ce cas 1, 6, 11, 16, 21, etc.). Les tabulations sont répétées jusqu'à la marge droite de l'écran.

Utilisez “-0” pour effacer toutes les tabulations.

Utilisez “-8” pour définir les tabulations à l'intervalle standard.

Listes explicites

Une liste explicite peut être définie après les options (elle n'utilise pas de “-”). Les valeurs de la liste doivent être dans un ordre numérique croissant et supérieures à zéro. Elles sont séparées par une virgule ou un espace, par exemple,

tabs 1,6,11,16,21
tabs 1 6 11 16 21

Utilisez un “+” pour considérer un nombre comme un incrément par rapport à la valeur précédente, par exemple,

tabs 1,+5,+5,+5,+5

ce qui est équivalent à l'exemple 1,6,11,16,21.

Marges

Quelques terminaux offrent un moyen de changer leurs marges gauche et droite. tabs prend en charge cette fonctionnalité avec une option.

+m marge
L'effet dépend du fait que le terminal possède ou non les capacités de marge :
  • Si le terminal fournit la capacité de définir la marge gauche, tabs l'utilise et ajuste les largeurs des taquets de tabulation disponibles.
  • Si le terminal ne fournit pas les capacités de marge, tabs imite leur effet, plaçant des taquets de tabulation aux endroits appropriés sur chaque ligne. La marge gauche du terminal n'est pas modifiée.
Si le paramètre marge est omis, la valeur par défaut est 10. Utilisez +m0 pour réinitialiser la marge gauche, c'est-à-dire pour la faire coïncider avec le bord gauche de l'affichage du terminal. Avant de définir une marge gauche, tabs réinitialise la marge pour réduire les problèmes qui pourraient survenir lors du déplacement du curseur vers la gauche de la marge gauche actuelle.

Lors de la définition ou de la réinitialisation de la marge gauche, tabs peut également réinitialiser la marge droite.

FICHIERS

/usr/share/tabset
base de données d'initialisation des taquets de tabulation

PORTABILITÉ

IEEE Std 1003.1/The Open Group Base Specifications Issue 7 (POSIX.1-2008) décrit un utilitaire tabs. Cependant,

  • cette norme décrit une option +m pour définir la marge gauche d'un terminal. Très peu des entrées de la base de données des terminaux fournissent les capacités set_left_margin (smgl) ou set_left_margin_parm (smglp) nécessaires pour supporter cette fonctionnalité.
  • Il n'y a pas de contrepartie dans X/Open Curses Issue 7 pour cet utilitaire, contrairement à tput(1).

Les options -d (débogage) et -n (sans opération) sont des extensions ncurses non fournies par d'autres implémentations.

HISTORIQUE

Un utilitaire tabs est apparu dans PWB/Unix 1.0 (1977). Une version réduite a été livrée dans Seventh Edition Unix (début 1979) et dans 3BSD (plus tard la même année) ; elle prenait en charge une option “-n” pour définir le premier taquet de tabulation à la marge gauche. Cette option n'est pas spécifiée par POSIX.

L'utilitaire tabs de PWB/Unix est revenu dans System III (1980), et utilisait des tables intégrées pour supporter une demi-douzaine de types de terminaux d'impression. Il avait également une logique pour supporter la définition de la marge gauche, ainsi qu'une fonctionnalité pour copier les paramètres de tabulation à partir d'un fichier.

Les versions du programme dans les versions ultérieures d'AT&T Unix, telles que SVr4, ont ajouté la prise en charge de la base de données des terminaux, mais ont conservé les tables pour supporter les imprimantes. À cette époque, tput de System V avait incorporé la fonctionnalité d'initialisation des taquets de tabulation de tset de BSD datant de 1982, mais utilisait la base de données terminfo pour ce faire.

L'option +m a été documentée dans les Spécifications de base POSIX Issue 5 (Unix98, 1997), puis omise dans l'Issue 6 (Unix03, 2004) sans motivation explicite, bien qu'un commentaire introductif “et ajuste optionnellement la marge” subsiste, négligé lors de la suppression. L'utilitaire tabs documenté dans les numéros 6 et suivants n'a aucun mécanisme pour définir les marges. tabs(1) - Arch manual pages

NAME

tabs - set terminal tab stops

SYNOPSIS

tabs [-cdfsu] [-a _number_] [_tablist_]

DESCRIPTION

The tabs utility initializes the active tab stops on the terminal.

By default, tabs are set at every eighth column. The -c, -f, -s, and -u options select different default tab lists.

An explicit list of tab stops can be given as the argument _tablist_. This is a comma-separated list of column numbers.

The default tab list options are:

  • -c: IBM/PC-style tabs, every eighth column.
  • -f: Fortran-style tabs, every seventh column.
  • -s: Sixth-column tabs, for the DECsystem-20.
  • -u: UniSoft-style tabs, every eighth column.

The -a option takes an integer argument, _number_, which specifies the number of columns to use for the tab stops. If the terminfo entry for the terminal has an entry for “cols”, then this number is used as the right margin. Otherwise, the number is ignored.

If no options are specified, tabs uses the default tab stops.

OPTIONS

All options can be preceded by a “-” (minus sign) to reset the tabs. For example, “tabs –” resets all tabs.

The options are:

-a number
Set the tab stops up to the specified column, number.
-c
IBM/PC-style tabs (every eighth column).
-f
Fortran-style tabs (every seventh column).
-s
Sixth-column tabs (for the DECsystem-20).
-u
UniSoft-style tabs (every eighth column).

FILES

termcap, terminfo

PORTABILITY

This utility is not portable. The concept of setting arbitrary tab stops is not supported by all terminals. The tabs utility in ncurses attempts to set tab stops for the right margin if the list of tab stops is sufficiently long.

POSIX documents no limit on the number of tab stops. Other implementations impose one; the limit is 20 in PWB/Unix's tabs utility. While some terminals may not accept an arbitrary number of tab stops, ncurses tabs attempts to set tab stops up to the right margin if the list thereof is sufficiently long.

The “Rationale” section of the Issue 6 tabs reference page details how the committee considered redesigning the tabs and tput utilities, without settling on an improved solution. It claims that

“no known historical version of tabs supports the capability of setting arbitrary tab stops.”

The feature described in subsection “Explicit Lists” above was implemented in PWB/Unix, and permitted the setting of abitrary tab stops nevertheless.

HISTORY

A tabs command appeared in Version 1 AT&T UNIX.
