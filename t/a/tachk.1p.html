NOM

tachk - Vérifie la validité des ancres de confiance dans un fichier named.conf

SYNTAXE

tachk [options] <named.conf>

DESCRIPTION

tachk vérifie la validité des ancres de confiance dans le fichier named.conf spécifié. Le résultat dépend des options sélectionnées.

Note : Ce script pourrait être supprimé dans les futures versions.

OPTIONS

tachk accepte deux types d'options : les options d'attributs d'enregistrement et les options de style de sortie. Ces ensembles d'options sont détaillés ci-dessous.

Options d'Attributs d'Enregistrement

Ces options définissent quels enregistrements d'ancres de confiance seront affichés.

-valid
Cette option affiche les ancres de confiance valides dans un fichier named.conf.
-invalid
Cette option affiche les ancres de confiance invalides dans un fichier named.conf.

Options de Format de Sortie

Ces options définissent comment les informations d'ancres de confiance seront affichées. Sans aucune de ces options, le nom de la zone et l'étiquette de la clé seront affichés pour chaque ancre de confiance.

-count
Le nombre d'enregistrements correspondants sera affiché, mais pas les enregistrements correspondants eux-mêmes.
-long
La forme longue de la sortie sera donnée. Le nom de la zone et l'étiquette de la clé seront affichés pour chaque ancre de confiance.
-terse
Cette option affiche uniquement le nom des zones sélectionnées par les autres options.
-Version
Affiche les informations de version pour tachk et le paquet DNSSEC-Tools.
-help
Affiche un message d'utilisation.
