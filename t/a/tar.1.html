DESCRIPTION

GNU tar est un programme d'archivage conçu pour stocker plusieurs fichiers dans un seul fichier (une archive), et pour manipuler de telles archives. L'archive peut être un fichier régulier ou un périphérique (par exemple, une unité de bande, d'où le nom du programme, qui signifie tape archiver), qui peut être situé localement ou sur une machine distante.

Styles d'options

Les options de GNU tar peuvent être fournies dans trois styles différents. Dans le style traditionnel, le premier argument est un groupe de lettres d'option et tous les arguments suivants fournissent les arguments aux options qui les nécessitent. Les arguments sont lus dans le même ordre que les lettres d'option. Tous les mots de la ligne de commande restants après le traitement de toutes les options sont traités comme des arguments sans option : des noms de fichiers ou de membres d'archive.

Par exemple, l'option c nécessite la création de l'archive, l'option v demande une opération détaillée (verbeuse), et l'option f prend un argument qui définit le nom de l'archive à traiter. La commande suivante, écrite dans le style traditionnel, demande à tar de stocker tous les fichiers du répertoire /etc dans le fichier archive etc.tar, en listant de manière détaillée les fichiers archivés :

tar cfv etc.tar /etc

Dans le style UNIX ou options courtes, chaque lettre d'option est précédée d'un seul trait, comme dans les autres utilitaires en ligne de commande. Si une option prend un argument, l'argument la suit, soit comme un mot distinct de la ligne de commande, soit immédiatement après l'option. Cependant, si l'option prend un argument facultatif, l'argument doit suivre la lettre d'option sans aucun espace blanc intermédiaire, comme dans -g/tmp/snar.db.

Un nombre quelconque d'options ne prenant pas d'arguments peut être regroupé sous un seul trait, par exemple -vkp. Une option qui prend un argument (obligatoire ou facultatif) peut apparaître à la fin d'un tel groupe, par exemple -vkpf a.tar.

L'exemple de commande ci-dessus écrit dans le style d'options courtes pourrait ressembler à ceci :

tar -cvf etc.tar /etc
ou 
tar -c -v -f etc.tar /etc

Dans le style GNU ou options longues, chaque option commence par deux traits et a un nom significatif, composé de lettres minuscules et de traits. Lorsqu'elle est utilisée, l'option longue peut être abréviée à ses lettres initiales, à condition que cela ne crée pas d'ambiguïté. Les arguments des options longues sont fournis soit comme un mot distinct de la ligne de commande, immédiatement après l'option, soit séparés de l'option par un signe égal sans espace blanc intermédiaire. Les arguments facultatifs doivent toujours utiliser cette dernière méthode.

Voici plusieurs façons d'écrire la commande d'exemple dans ce style :

tar --create --file etc.tar --verbose /etc
ou (en abrégeant certaines options) : 
tar --cre --file=etc.tar --verb /etc

Les options dans les trois styles peuvent être mélangées, bien que le faire avec d'anciennes options ne soit pas recommandé.

Mode opératoire

Les options listées dans le tableau ci-dessous indiquent à GNU tar quelle opération il doit effectuer. Exactement une d'entre elles doit être fournie. La signification des arguments sans option dépend du mode opératoire demandé.

-A, --catenate, --concatenate
Concaténer des archives à la fin d'une autre archive. Les arguments sont traités comme les noms des archives à concaténer. Toutes les archives doivent être du même format que l'archive à laquelle elles sont ajoutées, sinon l'archive résultante pourrait être inutilisable avec des implémentations non-GNU de tar. Notez également que lorsque plusieurs archives sont données, les membres des archives autres que la première ne seront accessibles dans l'archive résultante qu'en utilisant l'option -i (--ignore-zeros).

Les archives compressées ne peuvent pas être concaténées.

-c, --create
Créer une nouvelle archive. Les arguments fournissent les noms des fichiers à archiver. Les répertoires sont archivés récursivement, sauf si l'option --no-recursion est donnée.
-d, --diff, --compare
Trouver les différences entre l'archive et le système de fichiers. Les arguments sont facultatifs et spécifient les membres d'archive à comparer. S'ils ne sont pas fournis, le répertoire de travail courant est supposé.
--delete
Supprimer de l'archive. Les arguments fournissent les noms des membres d'archive à supprimer. Au moins un argument doit être donné.

Cette option n'opère pas sur les archives compressées. Il n'y a pas d'équivalent en option courte.

-r, --append
Ajouter des fichiers à la fin de l'archive. Les arguments fournissent les noms des fichiers à ajouter. Les fichiers sont ajoutés à la fin de l'archive, sans affecter les membres existants. Notez que les fichiers ajoutés de cette manière seront ajoutés dans l'archive après tous les membres existants.

OPTIONS

Main operation

-a, --add-file=FILE
Add FILE to the archive. This option is only valid when used with --c (--create) or --r (--append).
-c, --create
Create a new archive. Arguments specify the members of the archive. When used with --c, arguments specify the members to add to the archive.
--delete
Delete files from the archive. Arguments specify the members to delete.
--diff
Compare archive contents against the file system. Arguments specify the files or directories to compare against. When no arguments are given, the entire archive is compared.
--end-of-file[=EOF]
Specify the end-of-file marker for multi-volume archives. Defaults to "goodbye".
-x, --extract, --get
Extract files from an archive. Arguments are optional. When given, they specify names of the archive members to be extracted.
-r, --append
Append files to the end of an archive. Arguments specify the members to append.
-t, --list
List the contents of an archive. Arguments are optional. When given, they specify the names of the members to list.
--test-label
Test the archive volume label and exit. When used without arguments, it prints the volume label (if any) and exits with status 0. When one or more command line arguments are given. tar compares the volume label with each argument. It exits with code 0 if a match is found, and with code 1 otherwise. No output is displayed, unless used together with the -v (--verbose) option.

There is no short option equivalent for this option.

-u, --update
Append files which are newer than the corresponding copy in the archive. Arguments have the same meaning as with the -c and -r options. Notice, that newer files don't replace their old archive copies, but instead are appended to the end of archive. The resulting archive can thus contain several members of the same name, corresponding to various versions of the same file.
-W, --verify
Verify the archive after writing it.

Other operations

-A, --catenate, --concatenate
Append one or more archives to the end of another archive. The first archive named is the one to append to. Subsequent archives are appended to the first. Arguments have the same meaning as for -c (--create).
-j, --bzip2
Filter the archive through bzip2.
-J, --xz
Filter the archive through xz.
-k, --keep-old-files
Don't replace existing files when extracting.
-m, --no-same-owner
Don't save user and group ownerships.
-p, --same-owner
Preserve user and group ownerships.
-z, --gzip
Filter the archive through gzip.
-Z, --compress
Filter the archive through compress.
--auto-compress[=LIST]
Automatically compress/decompress the archive using LIST of filters. Recognized filters are: gz, bzip2, lzma, xz, lz, lzip, lzop, lz4, zstd.
--auto-compress-version=VERSION
Use the specified version of compression filter.
--compare
Synonym for --diff.
--concatenate
Synonym for --catenate.
--get
Synonym for --extract.
--show-defaults
Show built-in defaults for various tar options and exit.
--test-label
Test the archive volume label.
--use-compress-program=PROG[:SUFFIX]
Filter the archive through PROG. PROG must be the name of the filter program. Optionally, a suffix may be specified using :SUFFIX. This suffix is used to identify archives that were compressed with this program.
--use-compress-program-tar-options=OPTIONS
Pass OPTIONS to the compression program.
--version
Print program version and copyright information and exit.
-?, --help
Display a short option summary and exit.
--usage
Display a list of available options and exit.
--version
Print program version and copyright information and exit.

OPTIONS

Operation modifiers

--check-device
Check device numbers when creating incremental archives (default).
-g, --listed-incremental=FILE
Handle new GNU-format incremental backups. FILE is the name of a snapshot file, where tar stores additional information which is used to decide which files changed since the previous incremental dump and, consequently, must be dumped again. If FILE does not exist when creating an archive, it will be created and all files will be added to the resulting archive (the level 0 dump). To create incremental archives of non-zero level N, you need a copy of the snapshot file created for level N-1, and use it as FILE.

When listing or extracting, the actual content of FILE is not inspected, it is needed only due to syntactical requirements. It is therefore common practice to use /dev/null in its place.

--hole-detection=METHOD
Use METHOD to detect holes in sparse files. This option implies --sparse. Valid values for METHOD are seek and raw. Default is seek with fallback to raw when not applicable.
-G, --incremental
Handle old GNU-format incremental backups.
--ignore-failed-read
Do not exit with nonzero on unreadable files.
--level=NUMBER
Set dump level for a created listed-incremental archive. Currently only --level=0 is meaningful: it instructs tar to truncate the snapshot file before dumping, thereby forcing a level 0 dump.
-n, --seek
Assume the archive is seekable. Normally tar determines automatically whether the archive can be seeked or not. This option is intended for use in cases when such recognition fails. It takes effect only if the archive is open for reading (e.g. with --list or --extract options).
--no-check-device
Do not check device numbers when creating incremental archives.
--no-seek
Assume the archive is not seekable.
--occurrence[=N]
Process only the Nth occurrence of each file in the archive. This option is valid only when used with one of the following subcommands: --delete, --diff, --extract or --list and when a list of files is given either on the command line or via the -T option. The default N is 1.
--restrict
Disable the use of some potentially harmful options.
--sparse-version=MAJOR[.MINOR]
Set which version of the sparse format to use. This option implies --sparse. Valid argument values are 0.0, 0.1, and 1.0. For a detailed discussion of sparse formats, refer to the GNU Tar Manual, appendix D, "Sparse Formats". Using the info reader, it can be accessed running the following command: info tar 'Sparse Formats'.
-S, --sparse
Handle sparse files efficiently. Some files in the file system may have segments which were actually never written (quite often these are database files created by such systems as DBM). When given this option, tar attempts to determine if the file is sparse prior to archiving it, and if so, to reduce the resulting archive size by not dumping empty parts of the file.

Overwrite control

These options control tar actions when extracting a file over an existing copy on disk.

-k, --keep-old-files
Don't replace existing files when extracting.
--keep-newer-files
Don't replace existing files that are newer than their archive copies.
--keep-directory-symlink
Don't replace existing symlinks to directories when extracting.
--no-overwrite-dir
Preserve metadata of existing directories.
--one-top-level[=DIR]
Extract all files into DIR, or, if used without argument, into a subdirectory named by the base name of the archive (minus standard compression suffixes recognizable by --auto-compress).
--overwrite
Overwrite existing files when extracting.
--overwrite-dir
Overwrite metadata of existing directories when extracting (default).
--recursive-unlink
Recursively remove all files in the directory prior to extracting it.
--remove-files
Remove files from disk after adding them to the archive.
--skip-old-files
Don't replace existing files when extracting, silently skip over them.
-U, --unlink-first
Remove each file prior to extracting over it.
-W, --verify
Verify the archive after writing it.

Output stream selection

--ignore-command-error
Ignore subprocess exit codes.
--no-ignore-command-error
Treat non-zero exit codes of children as error (default).
-O, --to-stdout
Extract files to standard output.
--to-command=COMMAND
Pipe extracted files to COMMAND. The argument is the pathname of an external program, optionally with command line arguments. The program will be invoked and the contents of the file being extracted supplied to it on its standard input. Additional data will be supplied via the following environment variables:
TAR_FILETYPE
Type of the file. It is a single letter with the following meaning: 
f	Regular file
d	Directory
l	Symbolic link
h	Hard link
b	Block device
c	Character device

Currently only regular files are supported.

TAR_MODE
File mode, an octal number.
TAR_FILENAME
The name of the file.
TAR_REALNAME
Name of the file as stored in the archive.
TAR_UNAME
Name of the file owner.
TAR_GNAME
Name of the file owner group.
TAR_ATIME
Time of last access. It is a decimal number, representing seconds since the Epoch. If the archive provides times with nanosecond precision, the nanoseconds are appended to the timestamp after a decimal point.
TAR_MTIME
Time of last modification.
TAR_CTIME
Time of last status change.
TAR_SIZE
Size of the file.
TAR_UID
User ID of the file owner.
>TAR_UID
UID du propriétaire du fichier.
TAR_GID
GID du propriétaire du fichier.

En outre, les variables suivantes contiennent des informations sur le mode de fonctionnement de tar et sur l'archive en cours de traitement :

TAR_VERSION
Numéro de version de GNU tar.
TAR_ARCHIVE
Nom de l'archive traitée par tar.
TAR_BLOCKING_FACTOR
Facteur de blocage actuel, c'est-à-dire le nombre de blocs de 512 octets dans un enregistrement.
TAR_VOLUME
Numéro d'ordre du volume traité par tar (défini lors de la lecture d'une archive multi-volumes).
TAR_FORMAT
Format de l'archive traitée. L'une des valeurs suivantes : gnu, oldgnu, posix, ustar, v7.
TAR_SUBCOMMAND
Une option courte (avec un tiret en préfixe) décrivant l'opération exécutée par tar.

Gestion des attributs de fichiers

--atime-preserve[=MÉTHODE]
Préserve les temps d'accès sur les fichiers sauvegardés, soit en rétablissant les temps après la lecture (MÉTHODE=replace, c'est le défaut), soit en ne définissant pas les temps en premier lieu (MÉTHODE=system).
--delay-directory-restore
Retarde la définition des temps de modification et des permissions des répertoires extraits jusqu'à la fin de l'extraction. Utilisez cette option lors de l'extraction à partir d'une archive dont l'ordre des membres est inhabituel.
--group=NOM[:GID]
Force NOM comme groupe pour les fichiers ajoutés. Si GID n'est pas fourni, NOM peut être soit un nom d'utilisateur, soit un GID numérique. Dans ce cas, la partie manquante (GID ou nom) sera déduite de la base de données des groupes de l'hôte actuel.

Lorsqu'il est utilisé avec --group-map=FICHIER, n'affecte que les fichiers dont le groupe propriétaire ne figure pas dans FICHIER.

--group-map=FICHIER
Lit la table de traduction des groupes à partir de FICHIER. Les lignes vides sont ignorées. Les commentaires sont introduits par le signe # et s'étendent jusqu'à la fin de la ligne. Chaque ligne non vide de FICHIER définit une traduction pour un groupe unique. Elle doit consister en deux champs, délimités par n'importe quelle quantité d'espaces blancs : 
ANCIENGRP NOUVEAUGROUPE[:NOUVEAUGID]

ANCIENGRP est soit un nom de groupe valide, soit un GID précédé de +. Sauf si NOUVEAUGID est fourni, NOUVEAUGROUPE doit également être soit un nom de groupe valide, soit un +GID. Sinon, ni NOUVEAUGROUPE ni NOUVEAUGID n'ont besoin d'être listés dans la base de données des groupes du système.

En conséquence, chaque fichier d'entrée dont le groupe propriétaire est ANCIENGRP sera stocké dans l'archive avec le groupe propriétaire NOUVEAUGROUPE et le GID NOUVEAUGID.

--mode=CHANGEMENTS
Force le mode symbolique CHANGEMENTS pour les fichiers ajoutés.
--mtime=DATE-OU-FICHIER
Définit le mtime pour les fichiers ajoutés. DATE-OU-FICHIER est soit une date/heure dans un format presque arbitraire, soit le nom d'un fichier existant. Dans ce dernier cas, le mtime de ce fichier sera utilisé.
-m, --touch
Ne pas extraire le temps de modification du fichier.
--no-delay-directory-restore
Annule l'effet de l'option précédente --delay-directory-restore.
--no-same-owner
Extrait les fichiers en tant que vous-même (par défaut pour les utilisateurs ordinaires).
--no-same-permissions
Applique le umask de l'utilisateur lors de l'extraction des permissions de l'archive (par défaut pour les utilisateurs ordinaires).
--numeric-owner
Utilise toujours des nombres pour les noms d'utilisateur/groupe.
--owner=NOM[:UID]
Force NOM comme propriétaire pour les fichiers ajoutés. Si UID n'est pas fourni, NOM peut être soit un nom d'utilisateur, soit un UID numérique. Dans ce cas, la partie manquante (UID ou nom) sera déduite de la base de données des utilisateurs de l'hôte actuel.

Lorsqu'il est utilisé avec --owner-map=FICHIER, n'affecte que les fichiers dont le propriétaire ne figure pas dans FICHIER.

--owner-map=FICHIER
Lit la table de traduction des propriétaires à partir de FICHIER. Les lignes vides sont ignorées. Les commentaires sont introduits par le signe # et s'étendent jusqu'à la fin de la ligne. Chaque ligne non vide de FICHIER définit une traduction pour un UID unique. Elle doit consister en deux champs, délimités par n'importe quelle quantité d'espaces blancs : 
ANCIENUSR NOUVEAUUSR[:NOUVEAUUID]

ANCIENUSR est soit un nom d'utilisateur valide, soit un UID précédé de +. Sauf si NOUVEAUUID est fourni, NOUVEAUUSR doit également être soit un nom d'utilisateur valide, soit un +UID. Sinon, ni NOUVEAUUSR ni NOUVEAUUID n'ont besoin d'être listés dans la base de données des utilisateurs du système.

En conséquence, chaque fichier d'entrée appartenant à ANCIENUSR sera stocké dans l'archive avec le nom de propriétaire NOUVEAUUSR et l'UID NOUVEAUUID.

-p, --preserve-permissions, --same-permissions
Définit les permissions des fichiers extraits sur celles enregistrées dans l'archive (par défaut pour le superutilisateur).
--same-owner
Essaie d'extraire les fichiers avec la même propriété que celle existant dans l'archive (par défaut pour le superutilisateur).
-s, --preserve-order, --same-order
Indique à tar que la liste des noms de fichiers à traiter est triée dans le même ordre que les fichiers dans l'archive.
--sort=ORDRE
Lors de la création d'une archive, trie les entrées de répertoire selon ORDRE, qui est l'une des valeurs suivantes : none, name, ou inode.

Le défaut est --sort=none, qui stocke les membres de l'archive dans l'ordre retourné par le système d'exploitation.

L'utilisation de --sort=name garantit que l'ordre des membres dans l'archive créée est uniforme et reproductible.

L'utilisation de --sort=inode réduit le nombre de recherches sur disque lors de la création de l'archive et peut donc accélérer considérablement l'archivage. Cet ordre de tri n'est pris en charge que si le système sous-jacent fournit les informations nécessaires.

Attributs étendus de fichiers

--acls
Active la prise en charge des ACL POSIX.
--no-acls
Désactive la prise en charge des ACL POSIX.
--selinux
Active la prise en charge des contextes SELinux.
--no-selinux
Désactive la prise en charge des contextes SELinux.
--xattrs
Active la prise en charge des attributs étendus.
--no-xattrs
Désactive la prise en charge des attributs étendus.
--xattrs-exclude=MODÈLE
Spécifie le modèle d'exclusion pour les clés xattr. MODÈLE est un modèle de globbing, par exemple --xattrs-exclude='user.*' pour inclure uniquement les attributs de l'espace de noms utilisateur.
--xattrs-include=MODÈLE
Spécifie le modèle d'inclusion pour les clés xattr. MODÈLE est un modèle de globbing.

Sélection et commutation des périphériques

-f, --file=ARCHIVE
Utilise le fichier ou le périphérique d'archive ARCHIVE. Si cette option n'est pas fournie, tar examine d'abord la variable d'environnement `TAPE'. Si elle est définie, sa valeur sera utilisée comme nom d'archive. Sinon, tar utilisera la valeur par défaut compilée. La valeur par défaut peut être inspectée soit en utilisant l'option --show-defaults, soit à la fin de la sortie de tar --help.

Un nom d'archive contenant un deux-points spécifie un fichier ou un périphérique sur une machine distante. La partie avant le deux-points est considérée comme le nom de la machine ou l'adresse IP, et la partie après comme le chemin du fichier ou du périphérique, par exemple :

--file=remotehost:/dev/sr0

Un nom d'utilisateur optionnel peut être préfixé au nom d'hôte, en plaçant un signe @ entre eux.

Par défaut, l'hôte distant est accédé via la commande rsh(1). De nos jours, il est courant d'utiliser ssh(1) à la place. Vous pouvez le faire en donnant l'option de ligne de commande suivante :

--rsh-command=/usr/bin/ssh

La machine distante doit avoir la commande rmt(8) installée. Si son chemin ne correspond pas à celui par défaut de tar, vous pouvez informer tar du chemin correct à l'aide de l'option --rmt-command.

--force-local
Le fichier d'archive est local même s'il contient un deux-points.
-F, --info-script=COMMANDE, --new-volume-script=COMMANDE
Exécute COMMANDE à la fin de chaque bande (implique -M). La commande peut inclure des arguments. Lors de son démarrage, elle héritera de l'environnement de tar plus les variables suivantes :
TAR_VERSION
Numéro de version de GNU tar.
TAR_ARCHIVE
Le nom de l'archive que tar est en train de traiter.
TAR_BLOCKING_FACTOR
Facteur de blocage actuel, c'est-à-dire le nombre de blocs de 512 octets dans un enregistrement.
TAR_VOLUME
Numéro d'ordre du volume que tar traite (défini si lecture d'une archive multi-volumes).
TAR_FORMAT
Format de l'archive en cours de traitement. Un des formats suivants : gnu, oldgnu, posix, ustar, v7.
TAR_SUBCOMMAND
Une option courte (avec un tiret au début) décrivant l'opération que tar exécute.
TAR_FD
Descripteur de fichier pouvant être utilisé pour communiquer le nouveau nom du volume à tar.

Si le script d'information échoue, tar se termine ; sinon, il commence à écrire le volume suivant.

-L, --tape-length=N
Changer de bande après avoir écrit Nx1024 octets. Si N est suivi d'un suffixe de taille (voir la sous-section Suffixes de taille ci-dessous), le suffixe spécifie le facteur multiplicateur à utiliser au lieu de 1024.

Cette option implique -M.

-M, --multi-volume
Créer/lister/extraire une archive multi-volumes.
--rmt-command=COMMAND
Utiliser COMMAND au lieu de rmt lors de l'accès aux archives distantes. Voir la description de l'option -f, ci-dessus.
--rsh-command=COMMAND
Utiliser COMMAND au lieu de rsh lors de l'accès aux archives distantes. Voir la description de l'option -f, ci-dessus.
--volno-file=FILE
Lorsque cette option est utilisée conjointement avec --multi-volume, tar suivra le volume de l'archive multi-volumes sur lequel il travaille dans FILE.

Blocage du périphérique

-b, --blocking-factor=BLOCKS
Définir la taille de l'enregistrement à BLOCKSx512 octets.
-B, --read-full-records
Lors de la liste ou de l'extraction, accepter les enregistrements d'entrée incomplets après le marqueur de fin de fichier.
-i, --ignore-zeros
Ignorer les blocs zéro dans l'archive. Normalement, deux blocs consécutifs de 512 octets remplis de zéros signifient la fin du fichier (EOF) et tar s'arrête de lire après les avoir rencontrés. Cette option lui demande de continuer la lecture et est utile lors de la lecture d'archives créées avec l'option -A.
--record-size=NUMBER
Définir la taille de l'enregistrement. NUMBER est le nombre d'octets par enregistrement. Il doit être un multiple de 512. Il peut être suffixé d'un suffixe de taille, par exemple --record-size=10K pour 10 kilo-octets. Voir la sous-section Suffixes de taille pour une liste des suffixes valides.

Sélection du format d'archive

-H, --format=FORMAT
Créer une archive du format donné. Les formats valides sont :
gnu
Format GNU tar 1.13.x
oldgnu
Format GNU tel que dans tar <= 1.12.
pax, posix
Format POSIX 1003.1-2001 (pax).
ustar
Format POSIX 1003.1-1988 (ustar).
v7
Ancien format tar V7.
--old-archive, --portability
Identique à --format=v7.
--pax-option=keyword[[:]=value][,keyword[[:]=value]]...
Contrôler les mots-clés pax lors de la création d'archives PAX (-H pax). Cette option est équivalente à l'option -o de l'utilitaire pax(1).
--posix
Identique à --format=posix.
-V, --label=TEXT
Créer une archive avec le nom de volume TEXT. En cas de liste ou d'extraction, utiliser TEXT comme modèle de globbing pour le nom du volume.

Options de compression

-a, --auto-compress
Utiliser le suffixe de l'archive pour déterminer le programme de compression.
-I, --use-compress-program=COMMAND
Filtrer les données via COMMAND. Il doit accepter l'option -d pour la décompression. L'argument peut contenir des options de ligne de commande.
-j, --bzip2
Filtrer l'archive via bzip2(1).
-J, --xz
Filtrer l'archive via xz(1).
--lzip
Filtrer l'archive via lzip(1).
--lzma
Filtrer l'archive via lzma(1).
--lzop
Filtrer l'archive via lzop(1).
--no-auto-compress
Ne pas utiliser le suffixe de l'archive pour déterminer le programme de compression.
-z, --gzip, --gunzip, --ungzip
Filtrer l'archive via gzip(1).
-Z, --compress, --uncompress
Filtrer l'archive via compress(1).
--zstd
Filtrer l'archive via zstd(1).

Sélection des fichiers locaux

--add-file=FILE
Ajouter FILE à l'archive (utile si son nom commence par un tiret).
--backup[=CONTROL]
Sauvegarder avant la suppression. L'argument CONTROL, s'il est fourni, contrôle la politique de sauvegarde. Ses valeurs valides sont :
none, off
Ne jamais faire de sauvegardes.
t, numbered
Faire des sauvegardes numérotées.
nil, existing
Faire des sauvegardes numérotées si des sauvegardes numérotées existent, des sauvegardes simples sinon.
never, simple
Toujours faire des sauvegardes simples

Si CONTROL n'est pas donné, la valeur est prise dans la variable d'environnement VERSION_CONTROL. Si elle n'est pas définie, existing est supposé.

-C, --directory=DIR
Se déplacer dans DIR avant d'effectuer toute opération. Cette option est sensible à l'ordre, c'est-à-dire qu'elle affecte toutes les options qui la suivent.
--exclude=PATTERN
Exclure les fichiers correspondant à PATTERN, un modèle de joker de type glob(3).
--exclude-backups
Exclure les fichiers de sauvegarde et de verrouillage.
--exclude-caches
Exclure le contenu des répertoires contenant le fichier CACHEDIR.TAG, sauf le fichier tag lui-même.
--exclude-caches-all
Exclure les répertoires contenant le fichier CACHEDIR.TAG et le fichier lui-même.
--exclude-caches-under
Exclure tout sous les répertoires contenant CACHEDIR.TAG
--exclude-ignore=FILE
Avant de sauvegarder un répertoire, vérifier s'il contient FILE. Si oui, lire les modèles d'exclusion de ce fichier. Les modèles n'affectent que le répertoire lui-même.
--exclude-ignore-recursive=FILE
Identique à --exclude-ignore, sauf que les modèles de FILE affectent à la fois le répertoire et tous ses sous-répertoires.
--exclude-tag=FILE
Exclure le contenu des répertoires contenant FILE, sauf FILE lui-même.
--exclude-tag-all=FILE
Exclure les répertoires contenant FILE.
--exclude-tag-under=FILE
Exclure tout sous les répertoires contenant FILE.
--exclude-vcs
Exclure les répertoires des systèmes de contrôle de version.
--exclude-vcs-ignores
Exclure les fichiers qui correspondent aux modèles lus à partir des fichiers d'ignorance spécifiques au VCS. Les fichiers pris en charge sont : .cvsignore, .gitignore, .bzrignore, et .hgignore.
-h, --dereference
Suivre les liens symboliques ; archiver et sauvegarder les fichiers vers lesquels ils pointent.
--hard-dereference
Suivre les liens matériels ; archiver et sauvegarder les fichiers auxquels ils font référence.
-K
, --starting-file=MEMBRE
Commencer par le membre donné dans l'archive.
--newer-mtime=DATE
Travailler sur les fichiers dont les données ont changé après la DATE. Si DATE commence par / ou . elle est considérée comme un nom de fichier ; le mtime de ce fichier est utilisé comme date.
--no-null
Désactiver l'effet de l'option précédente --null.
--no-recursion
Éviter de descendre automatiquement dans les répertoires.
--no-unquote
Ne pas désambiguïser les noms de fichiers ou de membres en entrée.
--no-verbatim-files-from
Traiter chaque ligne lue à partir d'une liste de fichiers comme si elle était fournie dans la ligne de commande. C'est-à-dire, les espaces blancs en début et fin sont supprimés et, si la chaîne résultante commence par un tiret, elle est traitée comme une option de commande tar.

C'est le comportement par défaut. L'option --no-verbatim-files-from est fournie pour rétablir ce comportement après l'option --verbatim-files-from.

Cette option est positionnelle : elle affecte toutes les options --files-from qui la suivent, jusqu'à l'option --verbatim-files-from ou la fin de la ligne, selon ce qui survient en premier.

Elle est implicite avec l'option --no-null.

--null
Indiquer aux options -T suivantes de lire les noms séparés par des NUL verbatim (désactive le traitement spécial des noms commençant par un tiret).

Voir aussi --verbatim-files-from.

-N, --newer=DATE, --after-date=DATE
Stocker uniquement les fichiers plus récents que DATE. Si DATE commence par / ou . elle est considérée comme un nom de fichier ; le mtime de ce fichier est utilisé comme date.
--one-file-system
Rester dans le système de fichiers local lors de la création de l'archive.
-P, --absolute-names
Ne pas supprimer les barres obliques initiales des noms de fichiers lors de la création des archives.
--recursion
Récursivité dans les répertoires (par défaut).
--suffix=CHAINE
Sauvegarde avant suppression, remplace le suffixe habituel. Le suffixe par défaut est ~, sauf s'il est remplacé par la variable d'environnement SIMPLE_BACKUP_SUFFIX.
-T, --files-from=FICHIER
Obtenir les noms à extraire ou à créer depuis FICHIER.

Sauf indication contraire, le FICHIER doit contenir une liste de noms séparés par un LF ASCII (c'est-à-dire un nom par ligne). Les noms lus sont traités de la même manière que les arguments de la ligne de commande. Ils subissent une suppression d'échappement et une division par mots, et toute chaîne commençant par un - est traitée comme une option de commande tar.

Si ce comportement n'est pas souhaité, il peut être désactivé à l'aide de l'option --verbatim-files-from.

L'option --null indique à tar que les noms dans FICHIER sont séparés par un caractère NUL ASCII, au lieu de LF. C'est utile si la liste est générée par le prédicat find(1) -print0.

--unquote
Désambiguer les noms de fichiers ou de membres (par défaut).
--verbatim-files-from
Traiter chaque ligne obtenue d'une liste de fichiers comme un nom de fichier, même si elle commence par un tiret. Les listes de fichiers sont fournies avec l'option --files-from (-T). Le comportement par défaut est de traiter les noms fournis dans les listes de fichiers comme s'ils étaient tapés sur la ligne de commande, c'est-à-dire que tout nom commençant par un tiret est traité comme une option tar. L'option --verbatim-files-from désactive ce comportement.

Cette option affecte toutes les options --files-from qui la suivent sur la ligne de commande. Son effet est annulé par l'option --no-verbatim-files-from.

Cette option est implicite avec l'option --null.

Voir aussi --add-file.

-X, --exclude-from=FICHIER
Exclure les fichiers correspondant aux motifs listés dans FICHIER.

NAME

tar — GNU version of the tar program

SYNOPSIS

tar [OPTION...] [FILE]...

NOTE

This man page describes the GNU version of tar. It is not compatible with the POSIX or historic BSD versions.

DESCRIPTION

The GNU tar program saves and extracts files from a tape or disk archive, and also lists the contents of an archive without extracting the files.

This utility is used to bundle multiple files into one, and also to extract them. This is the equivalent of the zip command, but tar is a standard Unix utility.

GNU tar supports compressing and decompressing archives using bzip2(1), gzip(1), lzma(1), lzop(1), xz(1), and zstd(1).

OPTIONS

You can use either short options (like -f) or long options (like --file). Long options are more descriptive.

Most options are mutually exclusive. For example, you can specify only one of --create, --extract, or --list.

The following options are available:

-c, --create
Create a new archive.
-t, --list
List the contents of an archive.
-x, --extract, --get
Extract files from an archive.
-f, --fileARCHIVE
Use archive file or device ARCHIVE.
-v, --verbose
Give verbose output.
-u, --update
Only append files newer than the current archive.
-r, --append
Append files to the end of an archive.
-d, --compare, --diff
Compares archive contents to files on disk.
--exclude=PATTERN
exclude files matching PATTERN.
--exclude-from=FILE
exclude patterns listed in FILE.
--files-from=FILE
get names to extract or create from FILE.
--no-recursion
do not recurse into directories.
--one-file-system
do not cross file system boundaries.
--check-device
create tarcks on files not on appropriate devices.
--no-same-owner
do not keep owner.
--no-same-permissions
do not keep permissions.
--numeric-owner
always use numeric user and group IDs.
--same-owner
same as -o when creating.
--strip-components=NUM
remove NUM leading directory components.
--warning=KEYWORD
enable warning KEYWORD.

RETURN VALUE

Tar's exit code indicates whether it was able to successfully perform the requested operation, and if not, what kind of error occurred.

0
Successful termination.
1
Some files differ. If tar was invoked with the --compare (--diff, -d) command line option, this means that some files in the archive differ from their disk counterparts. If tar was given one of the --create, --append or --update options, this exit code means that some files were changed while being archived and so the resulting archive does not contain the exact copy of the file set.
2
Fatal error. This means that some fatal, unrecoverable error occurred.

If a subprocess that had been invoked by tar exited with a nonzero exit code, tar itself exits with that code as well. This can happen, for example, if a compression option (e.g. -z) was used and the external compressor program failed. Another example is rmt failure during backup to a remote device.
