tar_block_read(3) Appels de bibliothèque C tar_block_read(3)

NOM

tar_block_read, tar_block_write - macros pour appeler les fonctions de lecture et d'écriture pour le type d'archive tar correct

SYNTAXE

#include <libtar.h>

int tar_block_read(TAR *t, char *buf);

int tar_block_write(TAR *t, char *buf);

VERSION

Cette page man documente la version 1.2 de libtar.

DESCRIPTION

Les macros tar_block_read() et tar_block_write() appellent les fonctions de lecture et d'écriture pour le type d'archive tar associé au handle TAR t. Ce type est défini lors de la création du handle TAR à l'aide de tar_open().

VALEUR DE RETOUR

Ces macros retournent les mêmes valeurs que les fonctions de lecture et d'écriture correspondantes.

VOIR AUSSI

read(2), write(2), tar_open(3)
