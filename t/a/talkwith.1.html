TALKWITH(1) Commandes utilisateur TALKWITH(1)

NOM

talkwith - script pour changer facilement le synthétiseur vocal de speakup

SYNTAXE

talkwith synth daemon [options ...]

DESCRIPTION

talkwith est un script qui rend le changement de synthétiseur vocal dans speakup très simple.

Les options sont les suivantes :

synth - n'importe quel synthétiseur supporté par speakup

daemon - pour le synthétiseur 'soft', ceci doit être soit spd pour speechd-up, soit espeakup pour exécuter espeakup. Pour les autres synthétiseurs, ceci est ignoré.

options - pour un synthétiseur logiciel, le reste de la ligne de commande est passé au daemon ; sinon, il est ignoré.

Talkwith n'installe ni ne supprime de modules, assurez-vous donc que tout module de pilote requis est installé ou intégré au noyau avant d'exécuter talkwith.
