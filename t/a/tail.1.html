TAIL(1) Commandes utilisateur TAIL(1)

NOM

tail - afficher la dernière partie des fichiers

SYNTAXE

tail [OPTION]... [FICHIER]...

DESCRIPTION

Imprimer les 10 dernières lignes de chaque FICHIER sur la sortie standard. Avec plus d'un FICHIER, précéder chacun d'un en-tête donnant le nom du fichier.

Sans FICHIER, ou quand FICHIER est -, lire l'entrée standard.

Les arguments obligatoires pour les options longues sont aussi obligatoires pour les options courtes.

-c, --bytes=[+]NUM
afficher les NUM derniers octets ; ou utiliser -c +NUM pour afficher à partir de l'octet NUM de chaque fichier
-f, --follow[={name|descriptor}]
afficher les données ajoutées au fur et à mesure que le fichier grandit ; un argument d'option absent signifie 'descriptor'
-F
identique à --follow=name --retry
-n, --lines=[+]NUM
afficher les NUM dernières lignes, au lieu des 10 dernières ; ou utiliser -n +NUM pour sauter NUM-1 lignes au début
--max-unchanged-stats=N
avec --follow=name, rouvrir un FICHIER qui n'a pas changé de taille après N (par défaut 5) itérations pour voir s'il a été supprimé ou renommé (c'est le cas habituel des fichiers journaux en rotation) ; avec inotify, cette option est rarement utile
--pid=PID
avec -f, quitter après que le PID n'existe plus ; peut être répété pour surveiller plusieurs processus
-q, --quiet, --silent
ne jamais afficher les en-têtes donnant les noms de fichiers
--retry
continuer à essayer d'ouvrir un fichier s'il est inaccessible
-s, --sleep-interval=N
avec -f, attendre environ N secondes (par défaut 1.0) entre les itérations ; avec inotify et --pid=P, vérifier le processus P au moins une fois toutes les N secondes
-v, --verbose
toujours afficher les en-têtes donnant les noms de fichiers
-z, --zero-terminated
le délimiteur de ligne est NUL, pas un saut de ligne
--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter

NUM peut avoir un suffixe multiplicateur : b 512, kB 1000, K 1024, MB 1000*1000, M 1024*1024, GB 1000*1000*1000, G 1024*1024*1024, et ainsi de suite pour T, P, E, Z, Y, R, Q. Les préfixes binaires peuvent aussi être utilisés : KiB=K, MiB=M, et ainsi de suite.

Avec --follow (-f), tail suit par défaut le descripteur de fichier, ce qui signifie que même si un fichier suivi est renommé, tail continuera à suivre sa fin. Ce comportement par défaut n'est pas souhaitable lorsque vous voulez vraiment suivre le nom réel du fichier, pas le descripteur de fichier (par exemple, la rotation des journaux). Utilisez --follow=name dans ce cas. Cela fait en sorte que tail suive le fichier nommé d'une manière qui prend en compte les renommages, les suppressions et les créations.
