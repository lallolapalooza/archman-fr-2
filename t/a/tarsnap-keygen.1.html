TARSNAP-KEYGEN(1) Manuel des commandes générales TARSNAP-KEYGEN(1)

NOM

tarsnap-keygen — génère un fichier de clés pour l'utilisation avec tarsnap(1)

SYNTAXE

tarsnap-keygen --keyfile fichier-clé --user nom-utilisateur --machine nom-machine [--passphrased] [--passphrase-mem maxmem] [--passphrase-time maxtime]

tarsnap-keygen --version

DESCRIPTION

tarsnap-keygen génère des clés cryptographiques, s'enregistre auprès du serveur tarsnap et écrit un fichier de clés pour être utilisé avec tarsnap(1).

L'option --keyfile fichier-clé spécifie le nom du fichier dans lequel écrire les clés nouvellement générées. L'option --user nom-utilisateur spécifie le nom (c'est-à-dire l'adresse e-mail) du compte Tarsnap. L'option --machine nom-machine spécifie un nom qui sera affiché dans les rapports comptables afin que vous puissiez voir combien de données chaque machine stocke.

Si l'option --passphrased est spécifiée, l'utilisateur sera invité à entrer une phrase de passe (deux fois) qui sera utilisée pour chiffrer le fichier de clés.

Si l'option --passphrase-mem maxmem est spécifiée, un maximum de maxmem octets de RAM seront utilisés dans la fonction de dérivation de clé scrypt pour chiffrer le fichier de clés ; il peut être nécessaire de définir cette option si un fichier de clés est généré sur un système disposant de beaucoup plus de RAM que le système sur lequel le fichier de clés sera utilisé.

Si l'option --passphrase-time maxtime est spécifiée, un maximum d'environ maxtime secondes sera utilisé dans la fonction de dérivation de clé scrypt pour chiffrer le fichier de clés.

L'option --version affiche le numéro de version de tarsnap-keygen, puis se termine.
