NAME

tarsnap-keyregen — générer un fichier de clés à utiliser avec tarsnap-recrypt(1)

SYNOPSIS

tarsnap-keyregen --keyfile fichier-clé --oldkey fichier-clé-ancienne --user nom-utilisateur --machine nom-machine [--passphrased] [--passphrase-mem maxmem] [--passphrase-time maxtime]

tarsnap-keyregen --version

DESCRIPTION

tarsnap-keyregen génère un ensemble de clés cryptographiques compatibles avec un ensemble existant de clés cryptographiques, s'enregistre auprès du serveur Tarsnap et écrit un fichier de clés pour utilisation avec tarsnap-recrypt(1) et tarsnap(1). Le terme "compatible" signifie ici qu'il est possible de ré-encoder des archives stockées avec le premier ensemble de clés pour qu'elles soient stockées avec le second ensemble de clés. Ceci est nécessaire car Tarsnap possède certaines clés qui doivent rester les mêmes lors du ré-encodage des données ; sinon, les archives existantes deviendront illisibles et ne pourront pas être utilisées pour la déduplication.

L'option --keyfile fichier-clé spécifie le nom du fichier dans lequel écrire les clés nouvellement générées. L'option --oldkey fichier-clé-ancienne spécifie le nom du fichier contenant les anciennes clés. L'option --user nom-utilisateur spécifie le nom (c'est-à-dire l'adresse e-mail) du compte Tarsnap. L'option --machine nom-machine spécifie un nom qui sera affiché dans les rapports de comptabilité afin que vous puissiez voir quelle quantité de données chaque machine stocke.

Si l'option --passphrased est spécifiée, l'utilisateur sera invité à entrer une phrase secrète (deux fois) pour chiffrer le fichier de clés.

Si l'option --passphrase-mem maxmem est spécifiée, un maximum de maxmem octets de RAM seront utilisés dans la fonction de dérivation de clé scrypt pour chiffrer le fichier de clés ; il peut être nécessaire de définir cette option si un fichier de clés est généré sur un système disposant de beaucoup plus de RAM que le système sur lequel le fichier de clés sera utilisé.

Si l'option --passphrase-time maxtime est spécifiée, un maximum d'environ maxtime secondes sera utilisé dans la fonction de dérivation de clé scrypt pour chiffrer le fichier de clés.

L'option --version affiche le numéro de version de tarsnap-keyregen, puis se termine.
