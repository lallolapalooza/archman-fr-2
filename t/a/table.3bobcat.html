FBB::Table(3bobcat) Table-formatter FBB::Table(3bobcat)

NOM

FBB::Table - Génère des tableaux remplis ligne par ligne ou colonne par colonne

SYNTAXE

#include <bobcat/table>
Option de liaison : -lbobcat

DESCRIPTION

Les objets FBB::Table peuvent être utilisés pour créer des tableaux. Les tableaux sont remplis soit colonne par colonne, soit ligne par ligne. De nombreuses caractéristiques du tableau peuvent être affinées à l'aide d'un objet FBB::TableSupport distinct (cf. tablesupport(3bobcat)). Lorsqu'aucun objet FBB::TableSupport n'est utilisé, un tableau simple, rempli ligne par ligne ou colonne par colonne, est construit et peut être inséré dans un std::ostream.

Les tableaux définis par Table sont constitués de lignes et d'un nombre fixe de colonnes. Le nombre de colonnes est spécifié au moment de la construction, le nombre de lignes dépend également du nombre d'éléments insérés. Les colonnes et les lignes sont adressées à l'aide d'indices (commençant à 0). Avant la colonne la plus à gauche, entre les colonnes et après la dernière colonne, des séparateurs sont définis. Par défaut, ces séparateurs sont vides, mais chaque séparateur peut recevoir une largeur ou un contenu (fixe). Le séparateur avant la colonne col est adressé comme séparateur col, le séparateur le plus à droite est adressé comme séparateur nColumns.

Les lignes peuvent également être séparées les unes des autres à l'aide de séparateurs. Ces lignes séparatrices sont vides par défaut. Le séparateur de ligne avant la ligne row est adressé comme séparateur de ligne row. Le séparateur de ligne suivant la dernière ligne est adressé comme séparateur de ligne nRows, où nRows est la valeur retournée par la fonction membre nRows.

Les séparateurs non par défaut (c'est-à-dire non vides) sont définis à l'aide d'objets FBB::TableSupport (cf. tablesupport(3bobcat)).

Les objets Table ressemblent beaucoup aux objets ostream, utilisant un moyen simple de définir de nouveaux éléments : chaque insertion nouvelle définit un autre élément de tableau, et il est difficile de terminer une ligne avant qu'elle n'ait reçu son nombre d'éléments nColumn. La classe sœur de Table, TableBuf, est une classe de type std::streambuf, offrant un contrôle supplémentaire grâce à l'utilisation d'un objet classe ostream enveloppant.

FBB

HERITE DE

std::ostringstream - Table hérite de std::ostringstream, permettant les insertions dans un objet Table. Chaque insertion séparée ajoute un autre élément à l'objet Table.

FBB::TableBase - Cette classe implémente des éléments communs de l'implémentation du tableau. La classe TableBase n'est pas destinée à être utilisée seule, et aucune page de manuel distincte n'est fournie. Les fonctionnalités fournies par Table qui ont été héritées de TableBase sont décrites dans cette page de manuel.

ENUMERATIONS

Les énumérations suivantes sont définies par la classe FBB::Table : enum FillDirection
Cette énumération définit deux valeurs :

l
ROWWISE :
Lorsque cette valeur est spécifiée au moment de la construction, les éléments sont ajoutés ligne par ligne au tableau. Autrement dit, le deuxième élément inséré dans le Table sera trouvé dans la deuxième colonne de la première ligne ;
c
COLUMNWISE :
Lorsque cette valeur est spécifiée au moment de la construction, les éléments sont ajoutés colonne par colonne au tableau. Autrement dit, le deuxième élément est trouvé dans la deuxième ligne de la première colonne.

enum WidthType
Cette énumération définit deux valeurs :

c
COLUMNWIDTH :
Spécifiez cette valeur lorsque les colonnes peuvent avoir des largeurs variables. Dans ce cas, chaque colonne aura la largeur de l'élément le plus large qu'elle contient. C'est le WidthType par défaut utilisé par les objets Table.
e
EQUALWIDTH :
Spécifiez cette valeur lorsque toutes les colonnes du tableau doivent avoir des largeurs égales (c'est-à-dire égales à la largeur de l'élément de tableau le plus large),

CONSTRUCTEURS

t
Table(size_t nColumns, Table::FillDirection direction, Table::WidthType widthType = Table::COLUMNWIDTH) :
Le nombre de colonnes du tableau, la direction de remplissage et le type de largeur des colonnes doivent être fournis. Le nombre de lignes est déduit de la combinaison de ce paramètre et du nombre d'éléments effectivement insérés dans l'objet Table. Le paramètre direction spécifie la manière dont les nouveaux éléments sont ajoutés à l'objet Table : ligne par ligne ou colonne par colonne. Enfin, le paramètre widthType est utilisé pour spécifier la manière dont la largeur des colonnes du tableau est déterminée. Chaque colonne définit sa propre largeur ou toutes les colonnes ont des largeurs égales.
t
Table(TableSupport &tableSupport, size_t nColumns, Table::FillDirection direction, Table::WidthType widthType = Table::COLUMNWIDTH) :
Ce constructeur fonctionne de manière identique au constructeur précédent, mais attend en plus une référence à un objet TableSupport. Un objet TableSupport offre des fonctionnalités de formatage supplémentaires utilisées par les éléments définissant le tableau, tels que des lignes horizontales entre les lignes, des séparateurs supplémentaires, etc. L'objet TableSupport est passé en référence non constante car l'objet Table doit être capable de manipuler ses données. Voir tablesuppport(3bobcat) pour plus d'informations sur TableSupport.

Les constructeurs par copie et par déplacement (ainsi que les opérateurs d'affectation) ne sont pas disponibles.

OPERATEURS SURCHARGES

o
std::ostream &operator<<(std::ostream &str, Table &table) :
Cet opérateur insère un Table dans un objet std::ostream. Cet opérateur nécessite une table non constante car elle pourrait avoir besoin de compléter le tableau en ajoutant des éléments vides (c'est-à-dire des chaînes vides) pour obtenir un tableau rectangulaire complètement rempli ;
o
Table &operator<<(Table &obj, Align const &align) :
Cet opérateur modifie l'alignement par défaut d'une colonne ou d'un élément. C'est un wrapper autour du membre setAlign (voir ci-dessous pour sa description). Par défaut, tous les éléments sont alignés à droite (voir également align(3bobcat)) ;
o
Table &operator<<(Table &obj, Type const &item) :
Cet opérateur est défini comme un modèle de fonction : Type est un paramètre de type modèle instancié pour un type pour lequel les insertions std::ostringstream sont possibles. Il insère la valeur/l'objet item dans l'objet de classe de base std::ostringstream du Table comme prochain élément du tableau.

FONCTIONS MEMBRES

a
Table &append(std::string const &text char const *sep = " \t", bool addEmpty = false) :
Les champs dans text séparés par l'un des caractères de sep sont ajoutés comme éléments à l'objet Table. Les champs vides sont ignorés sauf si le paramètre addEmpty est true ;
c
void clear() :
Le contenu du tableau est effacé ;
c
void clearStr() :
Le contenu du tampon de sa classe de base std::ostringstream est effacé ;
d
Table &def() :
Après avoir inséré des éléments dans un objet Table, son nombre d'éléments peut ou non être un multiple entier du nombre de colonnes spécifié à la constructi

FONCTIONS MEMBRES

o
void def():
Pour `compléter' un objet Table en un objet rectangulaire, pour lequel toutes les largeurs de colonnes et alignements ont été déterminés, def peut être appelé. Il est automatiquement appelé par operator<<(ostream, Table). Dans d'autres situations, il peut être appelé explicitement pour forcer l'insertion d'une autre ligne dans un tableau en utilisant des insertions ROWWISE. Avec des insertions COLUMNWISE, son fonctionnement est complexe, car les nouveaux éléments ajoutés à un tableau rempli en mode COLUMNWISE reorganiseront ses éléments dans les colonnes du tableau ;
o
void fill(InputIterator begin, InputIterator end):
Ce membre est défini comme un membre template ; InputIterator est un paramètre de type template représentant n'importe quel itérateur d'entrée. Il peut également être, par exemple, un pointeur vers un type insérable. Les itérateurs doivent pointer vers des éléments de données qui peuvent être insérés dans un std::ostream. La plage de valeurs impliquée par la paire d'itérateurs du membre sont insérées dans le tableau comme de nouveaux éléments ;
o
void push_back(std::string const &element):
De nouveaux éléments peuvent être ajoutés au tableau en utilisant push_back. Il pourrait par exemple être appelé à partir d'un adaptateur back_inserter ;
o
size_t nRows():
Le nombre actuel de lignes du tableau est retourné. Il est initialisé à 0, et mis à jour par la suite après l'appel de def ;
o
Table &setAlign(Align const &align):
Le type d'alignement d'une colonne ou d'un élément de l'objet Table est défini en utilisant setAlign. Les alignements standards std::left, std::right et std::internal peuvent être spécifiés, mais en plus, l'alignement FBB::center peut être utilisé si les éléments doivent être centrés dans leur colonne. Une construction comme 
tab << Align(2, FBB::center)
demande le centrage de tous les éléments dans la colonne du tableau ayant l'indice 2 (c'est-à-dire la 3ème colonne du tableau), tandis qu'une construction comme 
tab << Align(2, 3, FBB::center)
demande le centrage de l'élément [2][3]. Il incombe au programmeur de s'assurer que de tels éléments existent. Par défaut, tous les éléments sont alignés à droite. )

MANIPULATEURS

o
Table &def(Table &table):
Ce manipulateur peut être inséré dans un tableau pour appeler le membre def du tableau.

EXEMPLE

#include <iostream>
#include <bobcat/table>
#include <bobcat/tablelines>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    TableLines tablelines;
                                // largeur/séparateurs des colonnes 0, 1 et 2
    tablelines << 0 << " | " << " | ";
                                // ligne horizontale au-dessus des colonnes 1 et 2 de la ligne 1
    tablelines << TableLines::HLine(1, 1, 3);
    Table tab(tablelines, 3, Table::ROWWISE, Table::EQUALWIDTH);
    // ou : Table tab(tablelines, 3, Table::ROWWISE);
    tab << Align(0, std::left);     // définir l'alignement non par défaut de la colonne
    tab.fill(argv + 1, argv + argc);// remplir la plage de valeurs
    cout << tab << ’\n’;            // compléter le tableau et l'insérer
    tab << "hello" << "" << "wo";   // ajouter des éléments supplémentaires.
    if (tab.nRows() > 2)
        tab << Align(2, 2, center); // définir la disposition d'un élément spécifique
    cout << tab << ’\n’;
}
