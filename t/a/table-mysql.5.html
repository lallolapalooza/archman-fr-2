TABLE_MYSQL(5) Manuel des formats de fichiers TABLE_MYSQL(5)

NOM

table_mysql — description du format des tables MySQL ou MariaDB pour smtpd

DESCRIPTION

Cette page de manuel documente le format des tables MySQL ou MariaDB utilisées par le démon de messagerie smtpd(8).

Le format décrit ici s'applique aux tables définies dans smtpd.conf(5).

TABLE MYSQL

Une table mysql permet le stockage des noms d'utilisateur, mots de passe, alias et domaines dans un format partageable entre diverses machines supportant mysql(1).

La table est utilisée par smtpd(8) lors de l'authentification d'un utilisateur, lorsque des informations utilisateur telles que l'ID utilisateur et/ou le répertoire personnel sont nécessaires pour une livraison, lorsqu'une recherche de domaine peut être requise, et/ou lors de la recherche d'un alias.

Une table MySQL se compose d'une ou plusieurs bases de données mysql(1) contenant une ou plusieurs tables.

Si la table est utilisée pour l'authentification, le mot de passe doit être crypté en utilisant la fonction crypt(3). De tels mots de passe peuvent être générés à l'aide de l'utilitaire encrypt(1) ou de la commande smtpctl(8) encrypt.

FICHIER CONFIG TABLE MYSQL

Les options de configuration suivantes sont disponibles :

host nom d'hôte
C'est l'hôte exécutant MySQL ou MariaDB. Par exemple : 
host db.example.com
username nom d'utilisateur
Le nom d'utilisateur requis pour communiquer avec la base de données MySQL ou MariaDB. Par exemple : 
username maildba
password mot de passe
Le mot de passe requis pour communiquer avec la base de données MySQL ou MariaDB. Par exemple : 
password OpenSMTPDRules!
database base de données
Le nom de la base de données MySQL ou MariaDB. Par exemple : 
databse opensmtpdb
query_alias instruction SQL
Ceci est utilisé pour fournir une requête afin de rechercher des alias. Le point d'interrogation est remplacé par les données appropriées. Pour un alias, c'est la partie gauche de l'adresse SMTP. Cela attend qu'une chaîne VARCHAR soit retournée avec le nom d'utilisateur vers lequel l'alias se résout.
query_credentials instruction SQL
Ceci est utilisé pour fournir une requête pour la recherche des identifiants utilisateur. Le point d'interrogation est remplacé par les données appropriées. Pour les identifiants, c'est la partie gauche de l'adresse SMTP. La requête attend que deux chaînes VARCHAR soient retournées, une avec un nom d'utilisateur et une avec un mot de passe au format crypt(3).
query_domain instruction SQL
Ceci est utilisé pour fournir une requête pour la recherche d'un domaine. Le point d'interrogation est remplacé par les données appropriées. Pour le domaine, ce serait la partie droite de l'adresse SMTP. Cela attend qu'une chaîne VARCHAR soit retournée avec un nom de domaine correspondant.
query_mailaddrmap instruction SQL
Ceci est utilisé pour fournir une requête afin de rechercher des expéditeurs. Le point d'interrogation est remplacé par les données appropriées. Cela attend qu'une chaîne VARCHAR soit retournée avec l'adresse depuis laquelle l'expéditeur est autorisé à envoyer des courriels.

Une instruction SQL générique ressemblerait à ceci :

query_ SELECT value FROM table WHERE key=?;

EXEMPLES

EXEMPLE GÉNÉRIQUE

Exemple basé sur la FAQ d'OpenSMTPD : Construction d'un serveur de messagerie. La partie filtrage est exclue de cet exemple.

La configuration ci-dessous est pour un serveur de messagerie de taille moyenne qui gère plusieurs domaines avec plusieurs utilisateurs virtuels et est basée sur plusieurs hypothèses. L'une d'elles est qu'un seul utilisateur système nommé vmail est utilisé pour tous les utilisateurs virtuels. Cet utilisateur doit être créé :

# useradd -g =uid -c "Virtual Mail" -d /var/vmail -s /sbin/nologin vmail
# mkdir /var/vmail
# chown vmail:vmail /var/vmail

Schéma MySQL

CREATE TABLE domains (
  id INT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  domain VARCHAR(255) NOT NULL DEFAULT ''
);
CREATE TABLE virtuals (
    id INT AUTO_INCREMENT PRIMARY KEY,
    email VARCHAR(255) NOT NULL DEFAULT '',
    destination VARCHAR(255) NOT NULL DEFAULT ''
);
CREATE TABLE credentials (
    id INT AUTO_INCREMENT PRIMARY KEY,
    email VARCHAR(255) NOT NULL DEFAULT '',
    password VARCHAR(255) NOT NULL DEFAULT ''
);
INSERT INTO domains VALUES (1, "example.com");
INSERT INTO domains VALUES (2, "example.net");
INSERT INTO domains VALUES (3, "example.org");

INSERT INTO virtuals VALUES (1, "abuse@example.com", "bob@example.com");
INSERT INTO virtuals VALUES (2, "postmaster@example.com", "bob@example.com");
INSERT INTO virtuals VALUES (3, "webmaster@example.com", "bob@example.com");
INSERT INTO virtuals VALUES (4, "bob@example.com", "vmail");
INSERT INTO virtuals VALUES (5, "abuse@example.net", "alice@example.net");
INSERT INTO virtuals VALUES (6, "postmaster@example.net", "alice@example.net");
INSERT INTO virtuals VALUES (7, "webmaster@example.net", "alice@example.net");
INSERT INTO virtuals VALUES (8, "alice@example.net", "vmail");

INSERT INTO credentials VALUES (1, "bob@example.com", "$2b$08$ANGFKBL.BnDLL0bUl7I6aumTCLRJSQluSQLuueWRG.xceworWrUIu");
INSERT INTO credentials VALUES (2, "alice@example.net", "$2b$08$AkHdB37kaj2NEoTcISHSYOCEBA5vyW1RcD8H1HG.XX0P/G1KIYwii");

/etc/mail/mysql.conf

host db.example.com
username maildba
password OpenSMTPDRules!
database opensmtpdb
query_alias SELECT destination FROM virtuals WHERE email=?;
query_credentials SELECT email, password FROM credentials WHERE email=?;
query_domain SELECT domain FROM domains WHERE domain=?;

/etc/mail/smtpd.conf

table domains mysql:/etc/mail/mysql.conf
table virtuals mysql:/etc/mail/mysql.conf
table credentials mysql:/etc/mail/mysql.conf
listen on egress port 25 tls pki mail.example.com
listen on egress port 587 tls-require pki mail.example.com auth <credentials>
accept from any for domain <domains> virtual <virtuals> deliver to mbox

table-mysql.5.en

NAME

table-mysql - OpenSMTPD MySQL database table lookup

DESCRIPTION

The mysql table is used to query information from a MySQL database.

This table requires the opensmtpd-mysql package to be installed.

The mysql table requires a configuration file which specifies the database connection parameters and the queries to be performed.

MYSQL TABLE

The mysql table can be used to perform lookups for various purposes such as:

  • query_source: To get the source address or hostname for a given IP address.
  • query_mailaddr: To check if a given email address is valid.
  • query_addrname: To get the address name for a given email address.

MYSQL TABLE CONFIG FILE

The configuration file for the mysql table has the following format:

database  mysql  <table_name>  <config_file>

Where:

  • database: Specifies that this is a database table.
  • mysql: Specifies the type of database (MySQL).
  • <table_name>: A name for this table that will be used in the smtpd.conf(5) file.
  • <config_file>: The path to the MySQL configuration file.

The MySQL configuration file should contain the connection parameters and the queries. The format is as follows:

[client]
host     = <hostname>
port     = <port>
user     = <username>
password = <password>
database = <database_name>

[query_source]
query    = "SELECT <address_column> FROM <table_name> WHERE <ip_column> = ?"

[query_mailaddr]
query    = "SELECT COUNT(*) FROM <table_name> WHERE <address_column> = ?"

[query_addrname]
query    = "SELECT <address_column> FROM <table_name> WHERE <email_column> = ?"

Replace the placeholders with your actual database details.

EXAMPLES

In smtpd.conf(5):

table mysql mysql_users /etc/mail/mysql_users.conf

In /etc/mail/mysql_users.conf:

[client]
host     = localhost
port     = 3306
user     = opensmtpd
password = secret
database = mail

[query_source]
query    = "SELECT ip FROM allowed_hosts WHERE hostname = ?"

[query_mailaddr]
query    = "SELECT COUNT(*) FROM valid_users WHERE email = ?"

[query_addrname]
query    = "SELECT name FROM user_aliases WHERE email = ?"
