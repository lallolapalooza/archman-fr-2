NOM

tangd-rotate-keys - Effectuer la rotation des clés tang

SYNTAXE

tangd-rotate-keys [-h] [-v] -d <REPCLÉ>

DESCRIPTION

Afin de préserver la sécurité du système à long terme, vous devez périodiquement faire pivoter vos clés. L'intervalle précis auquel vous devriez effectuer la rotation dépend de votre application, de la taille des clés et de la politique institutionnelle. Pour des recommandations courantes, voir : https://www.keylength.com.

tangd-rotate-keys génère de nouvelles clés dans le répertoire de la base de données des clés indiqué par l'option -d. Il s'agit typiquement de /var/db/tang. Il renomme également les anciennes clés en leur ajoutant un point (.) au début afin de les masquer de la publicité.

Tang prendra immédiatement en compte tous les changements. Aucun redémarrage n'est requis.

À ce stade, les nouvelles liaisons clients récupéreront les nouvelles clés et les anciens clients pourront continuer à utiliser les anciennes clés. Une fois que vous serez sûr que tous les anciens clients ont été migrés pour utiliser les nouvelles clés, vous pourrez supprimer les anciennes clés. Sachez que la suppression des anciennes clés pendant que les clients les utilisent peut entraîner une perte de données. Vous avez été prévenu.

OPTIONS

•-d <REPCLÉ>: Le répertoire contenant les clés, par ex. /var/db/tang
•-h: Afficher les informations d'utilisation
•-v: Verbeux. Afficher des informations supplémentaires sur les clés créées/rotées
