tar_append_file(3)

Paquet: libtar

Licences: BSD

tar_append_file(3) Appels de bibliothèque C tar_append_file(3)

NOM

tar_append_file, tar_append_eof, tar_append_regfile - ajouter des données aux archives tar

SYNTAXE

#include <libtar.h>

int tar_append_file(TAR *t, char *realname, char *savename);

int tar_append_regfile(TAR *t, char *realname);

int tar_append_eof(TAR *t);

VERSION

Cette page de manuel documente la version 1.2 de libtar.

DESCRIPTION

La fonction tar_append_file() crée un bloc d'en-tête de fichier tar décrivant le fichier nommé par l'argument realname, mais avec le nom de fichier encodé de savename. Elle définit ensuite l'en-tête courant associé au handle TAR t au bloc d'en-tête nouvellement créé, et écrit ce bloc dans l'archive tar associée à t. Si le fichier nommé par realname est un fichier régulier (et n'est pas encodé comme un lien physique), tar_append_file() appellera tar_append_regfile() pour ajouter le contenu du fichier.

La fonction tar_append_regfile() ajoute le contenu d'un fichier régulier à l'archive tar associée à t. Puisque cette fonction est appelée par tar_append_file(), elle ne devrait être nécessaire que pour les applications qui construisent et écrivent l'en-tête du fichier tar par elles-mêmes.

La fonction tar_append_eof() écrit un marqueur de fin de fichier (deux blocs de zéros) dans le fichier tar associé à t.

VALEURS DE RETOUR

En cas de succès, ces fonctions retournent 0. En cas d'échec, elles retournent -1 et définissent errno à une valeur appropriée.

ERREURS

Les fonctions tar_append_*() échoueront si :

EINVAL
Moins de T_BLOCKSIZE octets ont été écrits dans l'archive tar.
EINVAL
Moins de T_BLOCKSIZE octets ont été lus du fichier realname.

Elles peuvent également échouer si l'une des fonctions suivantes échoue : lstat(), malloc(), open(), read(), th_write(), ou la fonction d'écriture pour le type de fichier associé au handle TAR t.

VOIR AUSSI

read(2), open(2), lstat(2), th_write(3)
