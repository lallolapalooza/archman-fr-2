DESCRIPTION

Ces macros définissent et opèrent sur des files d'attente à doublement chaînée.

Dans les définitions de macros, TYPE est le nom d'une structure définie par l'utilisateur, qui doit contenir un champ de type TAILQ_ENTRY, nommé NAME. L'argument HEADNAME est le nom d'une structure définie par l'utilisateur qui doit être déclarée en utilisant la macro TAILQ_HEAD().

Création

Une file d'attente est dirigée par une structure définie par la macro TAILQ_HEAD(). Cette structure contient une paire de pointeurs, l'un vers le premier élément de la file et l'autre vers le dernier élément de la file. Les éléments sont doublement chaînés de sorte qu'un élément arbitraire puisse être supprimé sans parcourir la file. De nouveaux éléments peuvent être ajoutés à la file après un élément existant, avant un élément existant, en tête de la file ou à la fin de la file. Une structure TAILQ_HEAD est déclarée comme suit :


TAILQ_HEAD(HEADNAME, TYPE) head;

où struct HEADNAME est la structure à définir, et struct TYPE est le type des éléments à lier dans la file. Un pointeur vers la tête de la file peut être ultérieurement déclaré comme :


struct HEADNAME *headp;

(Les noms head et headp sont sélectionnables par l'utilisateur.)

TAILQ_ENTRY() déclare une structure qui connecte les éléments de la file.

TAILQ_HEAD_INITIALIZER() évalue à un initialiseur pour la file head.

TAILQ_INIT() initialise la file référencée par

TAILQ_EMPTY() évalue à vrai s'il n'y a pas d'éléments dans la file. head.

Insertion

TAILQ_INSERT_HEAD() insère le nouvel élément elm en tête de la file.

TAILQ_INSERT_TAIL() insère le nouvel élément elm à la fin de la file.

TAILQ_INSERT_BEFORE() insère le nouvel élément elm avant l'élément listelm.

TAILQ_INSERT_AFTER() insère le nouvel élément elm après l'élément listelm.

Parcours

TAILQ_FIRST() renvoie le premier élément de la file, ou NULL si la file est vide.

TAILQ_LAST() renvoie le dernier élément de la file. Si la file est vide, la valeur de retour est NULL.

TAILQ_PREV() renvoie l'élément précédent de la file, ou NULL si cet élément est le premier.

TAILQ_NEXT() renvoie l'élément suivant de la file, ou NULL si cet élément est le dernier.

TAILQ_FOREACH() parcourt la file référencée par head dans le sens avant, attribuant chaque élément successivement à var. var est mis à NULL si la boucle se termine normalement, ou s'il n'y avait aucun élément.

TAILQ_FOREACH_REVERSE() parcourt la file référencée par head dans le sens inverse, attribuant chaque élément successivement à var.

Suppression

TAILQ_REMOVE() supprime l'élément elm de la file.

Autres fonctionnalités

TAILQ_CONCAT() concatène la file dirigée par head2 à la fin de celle dirigée par head1, en supprimant toutes les entrées de la première.

VALEUR DE RETOUR

TAILQ_EMPTY() renvoie une valeur non nulle si la file est vide, et zéro si la file contient au moins une entrée.

TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), et TAILQ_NEXT() renvoient un pointeur vers la structure TYPE première, dernière, précédente ou suivante, respectivement.

TAILQ_HEAD_INITIALIZER() renvoie un initialiseur qui peut être assigné à la tête de file head.

NORMES

BSD.

HISTORIQUE

4.4BSD.

AVERTISSEMENTS

TAILQ_FOREACH() et TAILQ_FOREACH_REVERSE() ne permettent pas que var soit supprimé ou libéré pendant la boucle, car cela interférerait avec le parcours. TAILQ_FOREACH_SAFE() et TAILQ_FOREACH_REVERSE_SAFE(), qui sont présents sur les systèmes BSD mais pas dans glibc, corrigent cette limitation en permettant à var d'être supprimé en toute sécurité de la liste et libéré pendant la boucle sans interférer avec le parcours.

    struct entry *n1, *n2, *n3, *np;

DESCRIPTION

These macros provide an implementation of tail queues. A tail queue is a doubly linked list with a pointer to the head and tail of the list. The macros are defined in the <queue.h> header file.

To use these macros, you must first define a structure that contains a struct tailq_head. This structure will be used to represent the head of the queue.

struct my_item {
    int data;
    struct my_item_tailq_entry {
        struct my_item *tqe_next;
        struct my_item *tqe_prev;
    } item_list;
};

struct my_queue {
    struct my_item_tailq_entry tailq_head;
};

The macros operate on pointers to the struct tailq_head. The field argument to the macros is the name of the member within your item structure that holds the struct tailq_head.

TAILQ_HEAD_INITIALIZER
This macro returns a statically initialized tail queue head. It can be used to initialize a tail queue head variable at compile time.
TAILQ_INIT
This macro initializes the tail queue pointed to by head. It should be called before any other tail queue operations are performed on the queue.
TAILQ_INSERT_HEAD
This macro inserts the element elm at the head of the queue pointed to by head. The field argument is the name of the tail queue entry member in the element structure.
TAILQ_INSERT_TAIL
This macro inserts the element elm at the tail of the queue pointed to by head.
TAILQ_INSERT_AFTER
This macro inserts the element elm after the element listelm in the queue pointed to by head.
TAILQ_INSERT_BEFORE
This macro inserts the element elm before the element listelm in the queue.
TAILQ_REMOVE
This macro removes the element elm from the queue pointed to by head.
TAILQ_SWAP
This macro swaps the contents of the queues head1 and head2. The type argument must be the name of the type of the queue head structure.
TAILQ_FIRST
This macro returns a pointer to the first element in the queue pointed to by head, or NULL if the queue is empty.
TAILQ_LAST
This macro returns a pointer to the last element in the queue pointed to by head, or NULL if the queue is empty. headname is the name of the type of the queue head structure.
TAILQ_NEXT
This macro returns a pointer to the next element in the queue after elm, or NULL if elm is the last element.
TAILQ_PREV
This macro returns a pointer to the previous element in the queue before elm, or NULL if elm is the first element. headname is the name of the type of the queue head structure.
TAILQ_EMPTY
This macro returns true if the queue pointed to by head is empty, and false otherwise.
TAILQ_FOREACH
This macro iterates over the elements of the queue pointed to by head. In each iteration, var is assigned a pointer to the current element.
TAILQ_FOREACH_REVERSE
This macro iterates over the elements of the queue pointed to by head in reverse order. In each iteration, var is assigned a pointer to the current element. headname is the name of the type of the queue head structure.
TAILQ_CONCAT
This macro concatenates the queue pointed to by head2 onto the end of the queue pointed to by head1. After the operation, head2 will be empty.
TAILQ_PEEK_HEAD
This macro returns a pointer to the first element in the queue pointed to by head without removing it. It is equivalent to TAILQ_FIRST.
TAILQ_PEEK_TAIL
This macro returns a pointer to the last element in the queue pointed to by head without removing it. It is equivalent to TAILQ_LAST.
TAILQ_MOVE_UP
This macro moves the element elm up in the queue pointed to by head. This operation is only available when linked against libbsd.
TAILQ_MOVE_DOWN
This macro moves the element elm down in the queue pointed to by head. This operation is only available when linked against libbsd.
TAILQ_MAXDIRTY
This macro returns the maximum number of dirty elements allowed in the queue. This is only available when linked against libbsd.

RETURN VALUE

Functions that return pointers to elements return NULL if the queue is empty or the element is not found.

STANDARDS

The tail queue macros are part of the BSD operating system and are not part of any official standard.

HISTORY

The tail queue macros first appeared in 3.0BSD.

CAVEATS

The TAILQ_SWAP, TAILQ_MOVE_UP, TAILQ_MOVE_DOWN, and TAILQ_MAXDIRTY macros are only available when linked against libbsd.

When removing an element from a tail queue, it is important to ensure that the removed element is no longer referenced by the queue before freeing its memory. The following example demonstrates how to safely remove and free an element:

struct my_item *n1, *n2;
struct my_queue head;

// ... initialize head and add elements ...

n1 = TAILQ_FIRST(&head);
while (n1 != NULL) {
    n2 = TAILQ_NEXT(n1, item_list);
    free(n1);
    n1 = n2;
}
TAILQ_INIT(&head);
exit(EXIT_SUCCESS);

EXAMPLES

The following example demonstrates how to use the tail queue macros to create and manipulate a queue of integers.

#include <stdio.h>
#include <stdlib.h>
#include <queue.h>

struct item {
    int data;
    struct entries {
        struct item *tqe_next;
        struct item *tqe_prev;
    } entries;
};

int
main() {
    struct item *n1, *n2;
    struct item *current;
    struct item_head {
        struct item *tqh_first;
        struct item **tqh_last;
    } head;

    TAILQ_HEAD_INITIALIZER(head);
    TAILQ_INIT(&head);

    // Add elements to the tail queue
    n1 = malloc(sizeof(struct item));
    n1->data = 10;
    TAILQ_INSERT_TAIL(&head, n1, entries);

    n1 = malloc(sizeof(struct item));
    n1->data = 20;
    TAILQ_INSERT_TAIL(&head, n1, entries);

    n1 = malloc(sizeof(struct item));
    n1->data = 30;
    TAILQ_INSERT_HEAD(&head, n1, entries);

    // Iterate over the tail queue and print elements
    printf("Forward traversal:\n");
    TAILQ_FOREACH(current, &head, entries) {
        printf("%d\n", current->data);
    }

    // Remove and free elements
    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head);

    return 0;
}
