taskwarrior-tui — Une interface utilisateur terminale pour taskwarrior (https://github.com/kdheepak/taskwarrior-tui)

SYNTAXE

taskwarrior-tui

taskwarrior-tui est une interface utilisateur terminale pour taskwarrior.

EXEMPLES

taskwarrior-tui
Lance une interface utilisateur terminale pour taskwarrior.
alias tt=taskwarrior-tui
Ajoutez ce qui précède à vos fichiers de configuration (dotfiles) pour utiliser tt afin de lancer taskwarrior-tui.

taskwarrior-tui

taskwarrior-tui - une interface utilisateur graphique pour Taskwarrior.

SYNOPSIS

taskwarrior-tui [options]

DESCRIPTION

taskwarrior-tui est une interface utilisateur graphique (TUI) écrite en Rust pour le gestionnaire de tâches en ligne de commande Taskwarrior. Elle permet de visualiser, d'ajouter, de modifier, de supprimer et de compléter des tâches de manière interactive dans un terminal.

OPTIONS

--config <chemin>
Spécifie un fichier de configuration personnalisé pour taskwarrior-tui.
--help
Affiche le message d'aide et quitte.
--version
Affiche les informations de version et quitte.

EXEMPLES

# Lance taskwarrior-tui avec la configuration par défaut
taskwarrior-tui

# Lance taskwarrior-tui avec un fichier de configuration spécifique
taskwarrior-tui --config ~/.config/taskwarrior-tui/config.toml

KEYBINDINGS

Voici quelques raccourcis clavier courants :

  • ? : Affiche l'aide des raccourcis clavier.
  • a : Ajoute une nouvelle tâche.
  • e : Édite la tâche sélectionnée.
  • d : Supprime la tâche sélectionnée.
  • c : Marque la tâche sélectionnée comme complétée.
  • <Up>, <Down> : Navigue entre les tâches.
  • / : Recherche une tâche.
  • q : Quitte taskwarrior-tui.

Pour une liste complète des raccourcis clavier, consultez l'aide intégrée (?) ou la documentation de taskwarrior-tui.

EXIT STATUSES

Le code de sortie est généralement 0 en cas de succès. Des codes d'erreur spécifiques peuvent être retournés en cas de problème lors de l'exécution.
