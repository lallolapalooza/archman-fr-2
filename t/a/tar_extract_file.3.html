tar_extract_file(3)

Paquet: libtar

Licences: BSD

tar_extract_file(3) Appels de bibliothèque C tar_extract_file(3)

NOM

tar_extract_file, tar_extract_regfile, tar_extract_hardlink, tar_extract_symlink, tar_extract_chardev, tar_extract_blockdev, tar_extract_dir, tar_extract_fifo, tar_skip_regfile, tar_set_file_perms - extraire des fichiers d'une archive tar

SYNTAXE

#include <libtar.h>

int tar_extract_file(TAR *t, char *realname);

int tar_extract_regfile(TAR *t, char *realname);

int tar_skip_regfile(TAR *t);

int tar_extract_dir(TAR *t, char *realname);

int tar_extract_hardlink(TAR *t, char *realname);

int tar_extract_symlink(TAR *t, char *realname);

int tar_extract_blockdev(TAR *t, char *realname);

int tar_extract_chardev(TAR *t, char *realname);

int tar_extract_fifo(TAR *t, char *realname);

int tar_set_file_perms(TAR *t, char *realname);

VERSION

Cette page de manuel documente la version 1.2 de libtar.

DESCRIPTION

La fonction tar_extract_file() agit comme une interface pour les autres fonctions tar_extract_*(). Elle vérifie l'en-tête tar courant associé au descripteur TAR t (qui doit d'abord être initialisé en appelant th_read()) pour déterminer à quel type de fichier l'en-tête fait référence. Elle appelle ensuite la fonction appropriée tar_extract_*() pour extraire ce type de fichier.

La fonction tar_skip_regfile() saute les blocs de contenu de fichier et positionne le pointeur de fichier à l'emplacement attendu du prochain bloc d'en-tête tar.

La fonction tar_set_file_perms() définit les attributs du fichier extrait pour correspondre aux valeurs encodées. Cela inclut l'heure de modification du fichier, son mode, son propriétaire et son groupe. Cette fonction est automatiquement appelée par tar_extract_file(), mais les applications qui appellent directement les autres fonctions tar_extract_*() devront appeler tar_set_file_perms() manuellement si ce comportement est souhaité.

VALEURS DE RETOUR

En cas de succès, les fonctions documentées ici retourneront 0. En cas d'échec, elles retourneront -1 et définiront errno à une valeur appropriée.

La fonction tar_extract_dir() retournera 1 si le répertoire existe déjà.

ERREURS

La fonction tar_extract_file() échouera si :

EEXIST
Si le drapeau O_NOOVERWRITE est défini et que le fichier existe déjà.

Les fonctions tar_extract_*() échoueront si :

EINVAL
Une entrée n'a pas pu être ajoutée à la table de hachage interne du fichier.
EINVAL
Moins de T_BLOCKSIZE octets ont été lus à partir de l'archive tar.
EINVAL
L'en-tête de fichier courant associé à t fait référence à un type de fichier autre que celui que la fonction appelée connaît.

Elles peuvent également échouer si l'une des fonctions suivantes échoue : mkdir(), write(), link(), symlink(), mknod(), mkfifo(), utime(), chown(), lchown(), chmod(), ou lstat().

VOIR AUSSI

mkdir(2), write(2), link(2), symlink(2), mknod(2), mkfifo(2), utime(2), chown(2), lchown(2), chmod(2), lstat(2)
