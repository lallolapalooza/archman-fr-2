NOM

tailcall - Remplace la procédure actuelle par une autre commande

SYNOPSIS

tailcall commande ?arg ...?

DESCRIPTION

La commande tailcall remplace la procédure en cours d'exécution, l'application lambda ou la méthode par une autre commande. La commande, à laquelle arg ... seront passés en tant qu'arguments s'ils sont fournis, sera recherchée dans le contexte de l'espace de noms actuel, et non dans celui de l'appelant. À part cette différence dans la résolution, elle est équivalente à :

return [uplevel 1 [list commande ?arg ...?]]

Cette commande ne peut pas être invoquée depuis l'intérieur d'une instruction uplevel dans une procédure ou à l'intérieur d'un bloc catch dans une procédure ou une lambda.

EXEMPLE

Calculer la factorielle d'un nombre.

proc factorial {n {accum 1}} {
    if {$n < 2} {
        return $accum
    }
    tailcall factorial [expr {$n - 1}] [expr {$accum * $n}]
}

Afficher les éléments d'une liste avec des sauts de ligne alternant des indentations différentes.

proc printList {theList} {
    if {[llength $theList]} {
        puts "> [lindex $theList 0]"
        tailcall printList2 [lrange $theList 1 end]
    }
}
proc printList2 {theList} {
    if {[llength $theList]} {
        puts "< [lindex $theList 0]"
        tailcall printList [lrange $theList 1 end]
    }
}
