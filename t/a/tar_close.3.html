NOM

tar_open, tar_close - accéder à une archive tar via un handle

SYNTAXE

#include <libtar.h>

int tar_open(TAR **t, char *pathname, tartype_t *type, int oflags, int mode, int options);

int tar_fdopen(TAR **t, int fd, char *pathname, tartype_t *type, int oflags, int mode, int options);

int tar_fd(TAR *t");"

int tar_close(TAR *t");"

VERSION

Cette page de manuel documente la version 1.2 de libtar.

DESCRIPTION

La fonction tar_open() ouvre un fichier d'archive tar correspondant au nom de fichier spécifié par l'argument pathname. L'argument oflags doit être soit O_RDONLY, soit O_WRONLY.

L'argument type spécifie les méthodes d'accès pour le type de fichier donné. La structure tartype_t a des membres nommés openfunc, closefunc, readfunc() et writefunc(), qui sont des pointeurs vers les fonctions d'ouverture, de fermeture, de lecture et d'écriture du fichier, respectivement. Si type est NULL, le type de fichier est par défaut un fichier normal, et les fonctions standard open(), close(), read() et write() sont utilisées.

L'argument options est une combinaison de zéro ou plusieurs des options suivantes, combinées par un OU logique :

TAR_GNU
Utiliser les extensions GNU.
TAR_VERBOSE
Envoyer des messages d'état sur stdout.
TAR_NOOVERWRITE
Ne pas écraser les fichiers préexistants.
TAR_IGNORE_EOT
Ignorer les blocs tout zéro au lieu de les traiter comme EOT (End Of Tape).
TAR_IGNORE_MAGIC
Ne pas valider le champ magique dans les en-têtes de fichiers.
TAR_CHECK_VERSION
Vérifier le champ de version dans les en-têtes de fichiers. (Ce champ est normalement ignoré.)
TAR_IGNORE_CRC
Ne pas valider le CRC des en-têtes de fichiers.

La fonction tar_open() alloue de la mémoire pour un handle TAR, et un pointeur vers la mémoire allouée est enregistré à l'endroit spécifié par t. Le handle TAR peut être passé à d'autres appels libtar pour modifier l'archive tar ouverte. Le handle TAR maintient toutes les informations sur l'archive tar ouverte, y compris le type de l'archive, les options et les oflags sélectionnés lors de l'appel à tar_open().

Le handle TAR généré par tar_open() contient une structure d'en-tête de fichier. Lors de la lecture d'une archive tar, cette structure contient le dernier en-tête de fichier lu à partir de l'archive tar. Lors de l'écriture d'une archive tar, cette structure est utilisée comme zone de transit pour construire le prochain en-tête de fichier à écrire dans l'archive. De plus, le handle TAR contient une table de hachage qui est utilisée pour suivre les informations de périphérique et d'inode pour chaque fichier qui est écrit dans l'archive tar. Ceci est utilisé pour détecter les liens physiques, de sorte que les fichiers n'ont pas besoin d'être dupliqués dans l'archive.

La fonction tar_fdopen() est identique à la fonction tar_open(), sauf que fd est utilisé comme descripteur de fichier pré-ouvert pour le fichier tar au lieu d'appeler type->openfunc() pour ouvrir le fichier.

La fonction tar_fd() renvoie le descripteur de fichier associé au handle TAR t.

La fonction tar_close() ferme le descripteur de fichier associé au handle TAR t et libère toute la mémoire allouée dynamiquement.

VALEUR DE RETOUR

Les fonctions tar_open(), tar_fdopen() et tar_close() renvoient 0 en cas de succès. En cas d'échec, elles renvoient -1 et définissent errno.

La fonction tar_fd() renvoie le descripteur de fichier associé au handle TAR t.

ERREURS

tar_open() échouera si :

EINVAL
L'argument oflags était autre chose que O_RDONLY ou O_WRONLY.

De plus, tar_open() et tar_close() peuvent échouer si elles ne parviennent pas à allouer de mémoire en utilisant calloc(), ou si les fonctions d'ouverture ou de fermeture pour le type d'archive tar spécifié échouent.

VOIR AUSSI
