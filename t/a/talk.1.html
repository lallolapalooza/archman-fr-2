TALK(1) Commandes utilisateur TALK(1)

NOM

talk - Client de discussion

SYNTAXE

talk [OPTION...] personne [nom-tty]

DESCRIPTION

Discutez avec un autre utilisateur.

-?, --help
donne cette liste d'aide
--usage
donne un court message d'utilisation
-V, --version
affiche la version du programme

AUTEUR
