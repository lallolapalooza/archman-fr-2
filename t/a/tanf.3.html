tan(3) Manuel des fonctions de bibliothèque tan(3)

NOM

tan, tanf, tanl - fonction tangente

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double tan(double x);
float tanf(float x);
long double tanl(long double x);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

tanf(), tanl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Ces fonctions retournent la tangente de x, où x est exprimé en radians.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent la tangente de x.

Si x est un NaN, un NaN est retourné.

Si x est l'infini positif ou l'infini négatif, une erreur de domaine se produit, et un NaN est retourné.

Si le résultat correct devait déborder, une erreur de plage se produit, et les fonctions retournent respectivement HUGE_VAL, HUGE_VALF, ou HUGE_VALL, avec le signe mathématiquement correct.

ERREURS

Voir math_error(7) pour plus d'informations sur la manière de déterminer si une erreur s'est produite lors de l'appel de ces fonctions.

Les erreurs suivantes peuvent survenir :

Erreur de domaine : x est un infini
errno est défini à EDOM (mais voir BUGS). Une exception de point flottant invalide (FE_INVALID) est levée.
Erreur de plage : dépassement de capacité du résultat
Une exception de point flottant de dépassement de capacité (FE_OVERFLOW) est levée.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
tan (), tanf (), tanl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C99, POSIX.1-2001.

La variante retournant double est également conforme à SVr4, 4.3BSD, C89.

BOGUES

Avant glibc 2.10, l'implémentation glibc ne définissait pas errno à EDOM lorsqu'une erreur de domaine se produisait.

VOIR AUSSI

acos(3), asin(3), atan(3), atan2(3), cos(3), ctan(3), sin(3)
