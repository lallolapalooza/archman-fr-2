TABS(1P) Manuel du programmeur POSIX TABS(1P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

tabs — définir les tabulations du terminal

SYNTAXE

tabs [-n|-a|-a2|-c|-c2|-c3|-f|-p|-s|-u] [-T type]
tabs [-T type] n[[sep[+]n]...]

DESCRIPTION

L'utilitaire tabs doit afficher une série de caractères qui effacent d'abord les paramètres de tabulation matérielle du terminal, puis initialisent les arrêts de tabulation aux positions spécifiées et ajustent éventuellement la marge.

L'expression « position d'arrêt de tabulation N » doit être interprétée comme signifiant que, depuis le début d'une ligne de sortie, le passage à la position N entraînera l'affichage du prochain caractère dans la (N+1)ème position de colonne sur cette ligne. Le nombre maximum d'arrêts de tabulation autorisés dépend du terminal.

Il n'est pas nécessairement possible d'implémenter tabs sur certains terminaux. Si le type de terminal obtenu à partir de la variable d'environnement TERM ou de l'option -T représente un tel terminal, un message de diagnostic approprié doit être écrit sur la sortie d'erreur standard et tabs doit se terminer avec un statut supérieur à zéro.

OPTIONS

L'utilitaire tabs doit être conforme aux directives de syntaxe utilitaire du volume Définitions de base de POSIX.1‐2017, Section 12.2, à l'exception de diverses extensions : les options -a2, -c2 et -c3 sont composées de plusieurs caractères.

Les options suivantes doivent être prises en charge :

-n
Spécifie des arrêts de tabulation répétitifs séparés par un nombre uniforme de positions de colonne, n, où n est un chiffre décimal à un seul chiffre. L'utilisation par défaut de tabs sans arguments équivaut à tabs -8. Lorsque -0 est utilisé, les arrêts de tabulation sont effacés et aucun nouveau n'est défini.
-a
1,10,16,36,72
Assembleur, applicable à certains mainframes.
-a2
1,10,16,40,72
Assembleur, applicable à certains mainframes.
-c
1,8,12,16,20,55
COBOL, format normal.
-c2
1,6,10,14,49
COBOL, format compact (colonnes 1 à 6 omises).
-c3
1,6,10,14,18,22,26,30,34,38,42,46,50,54,58,62,67
Format compact COBOL (colonnes 1 à 6 omises), avec plus de tabulations que -c2.
-f
1,7,11,15,19,23
FORTRAN
-p
1,5,9,13,17,21,25,29,33,37,41,45,49,53,57,61
PL/1
-s
1,10,55
SNOBOL
-u
1,12,20,44
Assembleur, applicable à certains mainframes.
-T type
Indique le type de terminal. Si cette option n'est pas fournie et que la variable TERM est non définie ou nulle, un type de terminal par défaut non spécifié sera utilisé. Le réglage de type aura la priorité sur la valeur de TERM.

OPERANDES

L'opérande suivant doit être pris en charge :

n[[sep[+]n]...]
Un seul argument de ligne de commande consistant en une ou plusieurs valeurs d'arrêt de tabulation (n) séparées par un caractère séparateur (sep) qui est soit une virgule (<comma>) soit un espace (<blank>). L'application doit s'assurer que les valeurs d'arrêt de tabulation sont des entiers décimaux positifs dans un ordre strictement ascendant. Si une valeur d'arrêt de tabulation (sauf la première) est précédée d'un signe plus (<plus-sign>), elle est considérée comme un incrément à ajouter à la valeur précédente. Par exemple, les listes de tabulation 1,10,20,30 et "110+10+10" sont considérées comme identiques.

STDIN

Non utilisé.

FICHIERS D'ENTRÉE

Aucun.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes affecteront l'exécution de tabs :

LANG
Fournit une valeur par défaut pour les variables d'internationalisation non définies ou nulles. (Voir le volume Définitions de base de POSIX.1‐2017, Section 8.2, Variables d'internationalisation pour la priorité des variables d'internationalisation utilisées pour déterminer les valeurs des catégories de localisation.)
LC_ALL
Si définie à une chaîne de caractères non vide, remplace les valeurs de toutes les autres variables d'internationalisation.
LC_CTYPE
Détermine la locale pour l'interprétation des séquences d'octets de données textuelles en caractères (par exemple, caractères mono-octet par opposition aux caractères multi-octets dans les arguments).
LC_MESSAGES

Détermine la locale qui doit être utilisée pour affecter le format et le contenu des messages de diagnostic écrits sur la sortie d'erreur standard.
NLSPATH
Détermine l'emplacement des catalogues de messages pour le traitement de LC_MESSAGES.
TERM
Détermine le type de terminal. Si cette variable est non définie ou nulle, et si l'option -T n'est pas spécifiée, un type de terminal par défaut non spécifié sera utilisé.

ÉVÉNEMENTS ASYNCHRONES

Par défaut.

STDOUT

Si la sortie standard est un terminal, la séquence appropriée pour effacer et définir les arrêts de tabulation peut être écrite sur la sortie standard dans un format non spécifié. Si la sortie standard n'est pas un terminal, des résultats indéfinis se produisent.

STDERR

La sortie d'erreur standard ne sera utilisée que pour les messages de diagnostic.

Les sections suivantes sont informatives.

UTILISATION PAR L'APPLICATION

Cet utilitaire utilise les tabulations matérielles du terminal et l'option stty tabs.

Cet utilitaire n'est pas recommandé pour une utilisation par les applications.

Certaines unités d'affichage intégrées peuvent ne pas avoir de séquences d'échappement pour définir les arrêts de tabulation, mais celles-ci peuvent être définies par des appels système internes. Sur ces terminaux, tabs fonctionne si la sortie standard est dirigée vers le terminal ; si la sortie est dirigée vers un autre fichier, cependant, tabs échoue.

JUSTIFICATION

La possibilité d'avoir l'utilitaire tput gérant toutes les fonctions décrites dans tabs a été envisagée. Cependant, l'utilitaire distinct tabs a été conservé car il semble plus intuitif d'utiliser une commande nommée tabs plutôt que tput avec une nouvelle option. L'utilitaire tput ne prend pas en charge la définition ou l'effacement des tabulations, et aucune version historique connue de tabs ne prend en charge la capacité de définir des arrêts de tabulation arbitraires.

L'interface tabs de System V est très complexe ; la version de ce volume de POSIX.1-2017 a une liste de fonctionnalités réduite, mais beaucoup des fonctionnalités omises ont été restaurées dans le cadre de l'option XSI, même si les langages et les styles de codage pris en charge sont principalement historiques.

Il y avait un sentiment considérable pour ne spécifier qu'un moyen de réinitialiser les tabulations à un état connu - présumiblement la norme de tabulations toutes les huit positions. Les fonctionnalités suivantes ont été omises :

*
Définir les arrêts de tabulation via la première ligne d'un fichier, en utilisant --fichier. Comme même le SVID n'a pas d'explication complète de cette fonctionnalité, il est douteux qu'elle soit largement utilisée.

Dans une proposition antérieure, une option -t liste_tabulations a été ajoutée pour la cohérence avec expand ; elle a été supprimée plus tard lorsque des incohérences avec la liste historique des tabulations ont été identifiées.

La possibilité d'ajouter une option -p qui afficherait les paramètres de tabulation actuels afin qu'ils puissent être sauvegardés puis restaurés plus tard a été envisagée. Cela n'a pas été accepté car l'interrogation des arrêts de tabulation du terminal n'est pas une capacité des facilités historiques terminfo ou termcap et pourrait ne pas être prise en charge sur une large gamme de terminaux.
