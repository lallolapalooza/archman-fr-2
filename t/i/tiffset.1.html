NOM

tiffset - définir ou annuler un champ dans un en-tête TIFF

SYNOPSIS

tiffset [ options ] nom_fichier.tif

DESCRIPTION

tiffset définit la valeur d'un en-tête TIFF à une valeur spécifiée ou supprime un paramètre existant.

OPTIONS

-d num_répertoire
Change le répertoire courant (en commençant à 0).
-s numéro_tag [ compte ] valeur …
Définit la valeur du tag nommé à la ou aux valeurs spécifiées.
-sd décalage_répertoire
Change le répertoire courant par décalage.
-sf numéro_tag nom_fichier
Définit la valeur du tag au contenu du fichier. Cette option est prise en charge uniquement pour les tags ASCII.
-u numéro_tag
Annule le tag.

EXEMPLES

L'exemple suivant définit le tag de description de l'image (270) de a.tif au contenu du fichier descrip :

tiffset -sf 270 descrip a.tif

L'exemple suivant définit le tag de l'artiste (315) de a.tif à la chaîne Anonymous :

tiffset -s 315 Anonymous a.tif

Ceci définit la résolution du fichier a.tif à 300 dpi :

tiffset -s 296 2 a.tif
tiffset -s 282 300.0 a.tif
tiffset -s 283 300.0 a.tif

Définit l'interprétation photométrique de la troisième page de a.tif à min-is-black (c'est-à-dire qu'elle l'inverse) :

tiffset -d 2 -s 262 1 a.tif
