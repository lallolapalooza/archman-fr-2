timespec(3type) timespec(3type)

NOM

timespec - temps en secondes et nanosecondes

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <time.h>
struct timespec {
    time_t     tv_sec;   /* Secondes */
    /* ... */  tv_nsec;  /* Nanosecondes [0, 999'999'999] */
};

DESCRIPTION

Décrit les temps en secondes et en nanosecondes.

tv_nsec est d'un type signé dépendant de l'implémentation, capable de contenir la plage spécifiée. Sous glibc, il s'agit généralement de long, et long long sur X32. Il peut être converti en toute sécurité vers un type entier concret de 32 bits pour le traitement.

VERSIONS

Avant C23, tv_nsec était de type long.

NORMES

C11, POSIX.1-2024.

HISTORIQUE

POSIX.1-2001.

NOTES

Les en-têtes suivants fournissent également ce type : <aio.h>, <mqueue.h>, <sched.h>, <signal.h>, <sys/select.h>, et <sys/stat.h>.

VOIR AUSSI

clock_gettime(2), clock_nanosleep(2), nanosleep(2), timerfd_gettime(2), timer_gettime(2), time_t(3type), timeval(3type)
