NOM

timew-tags - affiche une liste d'étiquettes

SYNTAXE

timew tags [<plage>]

DESCRIPTION

Affiche par défaut toutes les étiquettes qui ont été utilisées. Lorsqu'un filtre est spécifié, il montre uniquement les étiquettes qui ont été utilisées pendant cette période.

CONFIGURATION

tags.<tag>.color

Attribue une couleur de premier plan et d'arrière-plan spécifique à une étiquette. Des exemples de couleurs valides incluent 'white', 'gray8', 'black on yellow', et 'rgb345'.
