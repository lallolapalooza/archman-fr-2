NOM

tiffdump - affiche des informations brutes sur les fichiers TIFF

SYNTAXE

tiffdump [ options ] nom …

DESCRIPTION

tiffdump affiche les informations de répertoire des fichiers créés conformément au format Tag Image File Format, révision 6.0. L'en-tête de chaque fichier TIFF (nombre magique, version et décalage du premier répertoire) est affiché, suivi par le contenu des balises de chaque répertoire dans le fichier. Pour chaque balise, le nom, le type de données, le nombre et la ou les valeurs sont affichés. Lorsque le nom symbolique d'une balise ou d'un type de données est connu, le nom symbolique est affiché suivi de sa valeur numérique (décimale). Les valeurs des balises sont affichées entre des caractères <> précédés immédiatement de la valeur du champ de comptage. Par exemple, une balise ImageWidth pourrait être affichée comme ImageWidth (256) SHORT (3) 1<800>.

tiffdump est particulièrement utile pour examiner le contenu des fichiers TIFF que libtiff ne comprend pas.

OPTIONS

-h
Force l'affichage des données numériques en hexadécimal plutôt qu'en décimal par défaut.
-m items
Change le nombre d'éléments de données indirects qui sont affichés. Par défaut, ce nombre sera de 24.
-o offset
Affiche le contenu de l'IFD à un décalage de fichier particulier. Le décalage de fichier peut être spécifié en utilisant la syntaxe habituelle de style C ; c'est-à-dire un préfixe 0x pour l'hexadécimal et un préfixe 0 pour l'octal.
