NOM

tinysparql-introspect - Inspecte les points d'accès SPARQL.

SYNOPSIS

tinysparql introspect [(-d |--database) <fichier> | (-b | --dbus-service) <nom_bus> | (-r | --remote-service) <url>]
    [(-t | --tree)] [(-t | --tree) <classe>] [(-s | --search) <aiguille>]t
tinysparql introspect [(-d |--database) <fichier> | (-b | --dbus-service) <nom_bus> | (-r | --remote-service) <url>]
    [(-c | --list-classes)] [(-p | --list-properties)] [(-i | --list-indexes)] [(-n | --list-notifies)] [(-g | --list-graphs)]

DESCRIPTION

Cette commande permet de sonder le schéma actuel de la base de données (également appelé ontologie) et les capacités du point d'accès. Si elle est appelée sans arguments supplémentaires à celui spécifiant la connexion à la base de données, toutes les informations sont extraites.

En termes d'ontologie de base de données, il est facile de savoir quelles propriétés sont indexées pour la vitesse, ou notifiées lors des changements, quelles classes sont disponibles et les propriétés appartenant à ces classes. Il existe également des outils visuels pour afficher une représentation arborescente en texte des classes et de leurs relations entre elles.

OPTIONS

-b, --dbus-service=<nom_service>

Se connecte à un point d'accès SPARQL par un nom D-Bus.

-d, --database-path=<chemin_base_de_données>

Se connecte à une base de données par son emplacement dans le système de fichiers.

-r, --remote-service=<url>

Se connecte à un point d'accès SPARQL HTTP.

-c, --list-classes

Retourne une liste de classes qui décrivent l'ontologie utilisée pour stocker les données. Ces classes sont également utilisées dans les requêtes. Par exemple, http://www.w3.org/2000/01/rdf-schema#Resource est une des nombreuses classes qui devraient être retournées ici.

-x, --list-class-prefixes

Retourne une liste de préfixes sous forme abrégée et longue. Toutes les classes et propriétés RDF ont un tel préfixe qui peut être exprimé sous l'une ou l'autre forme.

-p, --list-properties=[classe]

Retourne une liste de propriétés qui concernent une classe. Vous pouvez utiliser les deux formats ici pour la classe, soit le nom complet http://tracker.api.gnome.org/ontology/v3/nfo#Video, soit le nom de préfixe abrégé nfo:Video. Voir aussi --tree et --query.

-n, --list-notifies=[classe]

Retourne une liste de classes qui sont notifiées via D-Bus de tout changement survenant dans la base de données. La classe n'a pas besoin d'être fournie ici. Ceci est facultatif et filtre les résultats en fonction de tout argument fourni. Sans classe, toutes les classes sont listées.

-i, --list-indexes=[propriété]

Retourne une liste de propriétés qui sont indexées dans la base de données. Les index améliorent la vitesse des requêtes mais ajoutent également une pénalité d'indexation. La propriété n'a pas besoin d'être fournie ici. Ceci est facultatif et filtre les résultats en fonction de tout argument fourni. Sans propriété, toutes les propriétés sont listées.

-g, --list-graphs

Liste tous les graphes nommés dans la base de données. Ils sont utilisés par le mineur de système de fichiers pour séparer les métadonnées afin que les applications ne voient que les informations qui leur sont pertinentes.

-t, --tree=[classe]

Affiche un arbre montrant toutes les classes parentes de la classe dans l'ontologie. La classe peut être fournie en raccourci ou en version longue (voir --get-shorthand et --get-longhand pour plus de détails).

Si aucune classe n'est donnée, l'arbre entier est affiché.

L'option de ligne de commande --search peut être utilisée pour mettre en évidence les parties de l'arbre que vous recherchez. La recherche ne tient pas compte de la casse.

L'option de ligne de commande --properties peut être utilisée pour afficher les propriétés de chaque classe affichée

-s, --search=<aiguille>

Retourne une liste de classes et de propriétés qui correspondent partiellement à aiguille dans l'ontologie. La recherche ne tient pas compte de la casse. Voir aussi --tree.
