NOM

tipc-bearer - afficher ou modifier les porteurs TIPC

SYNTAXE


tipc bearer add media udp name NOM remoteip IPDISTANTE

tipc bearer enable [ domain DOMAINE ] [ priority PRIORITÉ ] media
{ { eth | ib } device PÉRIPHÉRIQUE } |
{ udp name NOM localip IPLOKALE [ localport PORTLOCAL ] [ remoteip IPDISTANTE ] [ remoteport PORTDISTANT ] }

tipc bearer disable media
{ { eth | ib } device PÉRIPHÉRIQUE } |
{ udp name NOM }

tipc bearer set { priority PRIORITÉ | tolerance TOLÉRANCE | window FENÊTRE } media
{ { eth | ib } device PÉRIPHÉRIQUE } |
{ udp name NOM }

tipc bearer get [ priority | tolerance | window ] media
{ { eth | ib } device PÉRIPHÉRIQUE } |
{ udp name NOM [ localip | localport | remoteip | remoteport ] }

tipc bearer list

OPTIONS

Options (indicateurs) qui peuvent être passées n'importe où dans la chaîne de commandes.

-h, --help
Affiche l'aide sur la dernière commande valide. Par exemple, tipc bearer --help affichera l'aide sur les porteurs et tipc --help affichera l'aide générale. La position de l'option dans la chaîne est sans importance.

DESCRIPTION

Identification des porteurs

media MÉDIA

Spécifie le type de média TIPC sur lequel un porteur particulier opérera. Différents types de média ont différentes façons d'identifier un porteur unique. Par exemple, ib et eth identifient un porteur avec un PÉRIPHÉRIQUE tandis que udp identifie un porteur avec une IPLOKALE et un NOM.

ib - Infiniband

eth - Ethernet

udp - User Datagram Protocol (UDP)

name NOM

Identifiant logique du porteur valide pour les porteurs sur le média udp.
device PÉRIPHÉRIQUE

Périphérique physique du porteur valide pour les porteurs sur les médias eth et ib.

Propriétés des porteurs

domain

Le domaine d'adressage (région) dans lequel un porteur établira des liens et acceptera des demandes d'établissement de lien.
priority

Priorité de lien par défaut héritée par tous les liens établis ultérieurement sur un porteur. Un seul porteur ne peut héberger qu'un seul lien vers un nœud particulier. Cela signifie que la priorité de lien par défaut d'un porteur affecte généralement quel porteur utiliser lors de la communication avec un nœud particulier dans une configuration multi-porteurs. Pour plus d'informations sur la priorité des liens, voir tipc-link(8).
tolerance

Tolérance de lien par défaut héritée par tous les liens établis ultérieurement sur un porteur. Pour plus d'informations sur la tolérance des liens, voir tipc-link(8).
window

Taille de fenêtre de lien par défaut héritée par tous les liens établis ultérieurement sur un porteur. Pour plus d'informations sur la taille de la fenêtre de lien, voir tipc-link(8).

Options du porteur UDP

localip IPLOKALE

Spécifie une adresse IP v4/v6 locale pour un porteur udp.
localport PORTLOCAL

Spécifie le port local pour un porteur udp. Le port par défaut 6118 est utilisé si aucun port n'est spécifié.
remoteip IPDISTANTE

Spécifie une IP distante pour un porteur udp. Si aucune IP distante n'est spécifiée, un porteur udp fonctionne en mode multicast et essaie de découvrir automatiquement ses voisins. L'adresse IP multicast est générée en fonction de l'ID réseau TIPC. Si une IP distante est spécifiée, le porteur udp fonctionne en mode point à point.

Plusieurs adresses remoteip peuvent être ajoutées via la commande bearer add. L'ajout d'une ou plusieurs adresses remoteip unicast à un porteur udp existant met le porteur en mode réplicast où le multicast IP est émullé en envoyant plusieurs messages unicast à chaque remoteip configuré. Lorsqu'un pair reçoit un message de découverte TIPC d'un pair inconnu, l'adresse du pair est automatiquement ajoutée à la liste remoteip (réplicast), de sorte qu'un seul côté d'un lien doit être configuré manuellement. Une adresse remoteip ne peut pas être ajoutée à un porteur multicast.

remoteport PORTDISTANT

Spécifie le port distant pour un porteur udp. Le port par défaut 6118 est utilisé si aucun port n'est spécifié.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi ou un entier positif en cas d'échec.

NOM

tipc-bearer — gestionnaire de porteurs TIPC

SYNTAXE

tipc-bearer [OPTIONS]

DESCRIPTION

Le programme tipc-bearer est utilisé pour gérer les porteurs du protocole TIPC (Transparent Inter-Process Communication). Il permet d'ajouter, de supprimer ou de modifier les informations relatives aux porteurs réseau utilisés par TIPC pour la communication inter-processus.

OPTIONS

Aucune option n'est spécifiée dans cette version du manuel.
