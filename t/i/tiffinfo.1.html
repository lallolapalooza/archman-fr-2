NOM

tiffinfo - afficher les informations sur les fichiers TIFF

SYNTAXE

tiffinfo [ options ] input.tif …

DESCRIPTION

tiffinfo affiche des informations sur les fichiers créés conformément au format Tag Image File Format, révision 6.0. Par défaut, le contenu de chaque répertoire TIFF dans chaque fichier est affiché, avec la valeur de chaque balise affichée symboliquement (lorsque c'est pertinent).

OPTIONS

-c
Affiche la palette de couleurs et les courbes de réponse des couleurs/gris, si elles sont présentes.
-D
En plus d'afficher les balises du répertoire, lit et décompresse toutes les données de chaque image (mais ne les affiche pas).
-d
En plus d'afficher les balises du répertoire, imprime chaque octet de données décompressées en hexadécimal.
-j
Affiche les balises liées au JPEG qui sont présentes.
-o
Définit le répertoire TIFF initial en fonction du décalage de fichier spécifié. Le décalage de fichier peut être spécifié en utilisant la syntaxe C habituelle; c'est-à-dire un préfixe 0x pour l'hexadécimal et un préfixe 0 pour l'octal.
-s
Affiche les décalages et les décomptes d'octets pour chaque bande de données dans un répertoire.
-z
Active le découpage des bandes lors de la lecture des données de l'image.
-#
Définit le répertoire TIFF initial sur #.
