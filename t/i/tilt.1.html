TILT(1) Manuel des commandes générales TILT(1)

NOM

tilt - traite des modèles

SYNTAXE

tilt -l
tilt [-t motif] [-y fichier] [-D nom=valeur] [-d fichier] [--vars=ruby] fichier

DESCRIPTION

Traite le modèle fichier et écrit la sortie sur stdout. En l'absence de fichier ou lorsque fichier est ´-´, lit le modèle depuis stdin et utilise l'option --type pour déterminer le type du modèle.

OPTIONS

-l, --list
Liste les moteurs de modèles + motifs de fichiers et quitte
-t, --type=motif
Utilise ce moteur de modèle ; requis si aucun fichier n'est spécifié
-y, --layout=fichier
Utilise fichier comme modèle de disposition
-Dnom=valeur
Définit la variable nom à la valeur
-d, --define-file=fichier
Charge YAML ou JSON depuis fichier et utilise pour les variables
--vars=ruby
Évalue ruby en Hash et utilise pour les variables
-h, --help
Affiche ce message d'aide

EXEMPLES

Convertir markdown en HTML :

$ tilt foo.markdown > foo.html

Traiter un modèle ERB :

$ echo "Réponse : <%= 2 + 2 %>" | tilt -t erb
Réponse : 4

Définir des variables :

$ echo ´{"n":40}´ > data.json
$ echo "Réponse : <%= 2 + n %>" | tilt -t erb -d data.json
Réponse : 42
$ echo "Réponse : <%= 2 + n %>" | tilt -t erb --vars="{:n=>40}"
Réponse : 42
$ echo "Réponse : <%= 2 + n.to_i %>" | tilt -t erb -Dn=40
Réponse : 42
