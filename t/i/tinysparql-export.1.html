TINYSPARQL-EXPORT(1) Manuel TinySPARQL TINYSPARQL-EXPORT(1)

NOM

tinysparql-export - Exporter toutes les données d'une base de données TinySPARQL.

SYNOPHIS

tinysparql export [options...] [IRI...]

DESCRIPTION

tinysparql export exporte les données stockées dans une base de données TinySPARQL, au format Turtle. Par défaut, toutes les données sont exportées ; si un IRI est spécifié, seules ces ressources seront imprimées.

La sortie est destinée à être lisible par machine, pas par humain. Utilisez un outil tel que rapper(1) pour convertir les données dans différents formats.

OPTIONS

-o, --output-format=<FORMAT_RDF>

Choisit le format RDF à utiliser pour la sortie des résultats. Les formats supportés sont turtle, trig et json-ld.

-g, --show-graphs

Obsolète. Fait la même chose que --output-format trig.

--2to3

Aide à la migration des données des bases de données Tracker 2.x. Cette option prend un argument spécifiant la portée. Seul l'argument “files-starred” est disponible jusqu'à présent.

--keyfile

Exporte les données dans un format de fichier clé. Ne peut être utilisé qu'avec --2to3

EXEMPLES

Exporter toutes les données de l'index Tracker et prettifier la sortie avec rapper(1).::

$ tinysparql export -b org.freedesktop.Tracker3.Miner.Files | rapper - -I . -i turtle -o turtle

VOIR AUSSI

tinysparql-import(1), tinysparql-sparql(1).
