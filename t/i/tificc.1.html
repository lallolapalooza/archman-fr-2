TIFICC(1) Manuel des commandes générales TIFICC(1)

NOM

tificc - Appliqueur de profil ICC pour TIFF avec little cms.

SYNTAXE

tificc [options] entree.tif sortie.tif

DESCRIPTION

lcms est un moteur CMM autonome, qui gère la gestion des couleurs. Il implémente une transformation rapide entre profils ICC. tificc est un applicateur de profil ICC pour TIFF avec little cms.

OPTIONS

-a
Traite les canaux > 4 comme des canaux alpha.
-b
Compensation du point noir.
-c NB
Prédit la transformation (0=Désactivé, 1=Normal, 2=Haute résolution, 3=Basse résolution) [par défaut 1].
-d NB
État d'adaptation de l'observateur (col. abs. seulement), (0..1.0, valeur flottante) [défaut 0.0].
-e
Intègre le profil de destination.
-g
Marque les couleurs hors gamut lors de l'épreuvage.
-h NB
Affiche un résumé des options et des exemples (0=aide, 1=Exemples, 2=Profils intégrés, 3=Informations de contact)
-i profil
Profil d'entrée (par défaut sRGB).
-k limiteencre
Limite d'encre en % (CMJN seulement), (0..400.0, valeur flottante) [défaut 400.0].
-l profil
Transforme par profil de liaison de périphérique.
-m TODO: vérifier si des valeurs en dehors de 0..3 sont possibles
Intention d'épreuvage [par défaut 0].
-n
Ignore le profil intégré en entrée.
-o profil
Profil de sortie (par défaut sRGB).
-p profil
Profil d'épreuvage.
-s nouveaude_profil
Enregistre le profil intégré sous le nom de nouveaude_profil.
-t NB
Intention de rendu
0=Perceptuel [par défaut]
1=Colorimétrique relatif
2=Saturation
3=Colorimétrique absolu
10=Perceptuel préservant l'encre noire
11=Colorimétrique relatif préservant l'encre noire
12=Saturation préservant l'encre noire
13=Perceptuel préservant le plan noir
14=Colorimétrique relatif préservant le plan noir
15=Saturation préservant le plan noir
-v
Mode détaillé.
-w NB
Profondeur de sortie (8, 16 ou 32). Utiliser 32 pour la virgule flottante.

PROFILS INTÉGRÉS

*Lab2  -- CIEL*a*b v2 basé sur D50
*Lab4  -- CIEL*a*b v4 basé sur D50
*Lab   -- CIEL*a*b v4 basé sur D50
*XYZ   -- CIE XYZ (PCS)
*sRGB  -- Espace colorimétrique sRGB
*Gray22 - Monochrome de Gamma 2.2
*Gray30 - Monochrome de Gamma 3.0
*null   - Noir monochrome pour toutes les entrées
*Lin2222- Linéarisation CMJN de gamma 2.2 sur chaque canal

EXEMPLES

Pour corriger les couleurs d'un scanner à sRGB :
	tificc -iscanner.icm in.tif out.tif
Pour convertir d'un moniteur1 à un moniteur2 :
	tificc -imon1.icm -omon2.icm in.tif out.tif
Pour faire une séparation CMJN :
	tificc -oprinter.icm inrgb.tif outcmyk.tif
Pour récupérer sRGB à partir d'une séparation CMJN :
	tificc -iprinter.icm incmyk.tif outrgb.tif
Pour convertir un TIFF CIELab à sRGB
	tificc -i*Lab in.tif out.tif
