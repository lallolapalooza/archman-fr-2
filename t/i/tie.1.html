TIE(1) Manuel des commandes générales TIE(1)

NOM

tie - fusionner ou appliquer des fichiers de modification WEB

SYNTAXE

tie -c|-m fichierSortie fichierMaître fichierModification...

DESCRIPTION

Le programme tie est utilisé pour traiter plusieurs fichiers de modification utilisés avec le système WEB pour la programmation lettrée. Les programmes WEB permettent d'appliquer des correctifs à un fichier source (le fichierMaître) au moyen d'un certain nombre de fichiers de modification (souvent un seul fichier de modification est autorisé). Tie peut être utilisé pour fusionner jusqu'à 32 fichiers de modification en un seul ou pour appliquer les modifications au fichierMaître afin d'en créer un nouveau. La sortie, soit du nouveau fichier de modification, soit du fichier maître corrigé, va dans fichierSortie.

OPTIONS

-c
Créer un seul fichier de modification à partir des fichierModifications donnés.
-m
Créer un nouveau fichier maître en appliquant les fichierModifications donnés.

ENVIRONNEMENT

La variable d'environnement WEBINPUTS est utilisée pour rechercher les fichiers d'entrée, ou la valeur par défaut du système si WEBINPUTS n'est pas définie. Voir tex(1) pour les détails de la recherche. Pour éviter les conflits avec d'autres programmes qui utilisent également l'environnement WEBINPUTS, vous pouvez être plus spécifique et utiliser WEBINPUTS_tie pour des exigences particulières dans TIE.

VOIR AUSSI

web(1), ctie(1), cweb(1).
