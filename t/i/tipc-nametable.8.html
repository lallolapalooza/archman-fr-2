NOM

tipc-nametable - afficher la table des noms TIPC

SYNTAXE


tipc nametable show

OPTIONS

Options (indicateurs) qui peuvent être passées n'importe où dans la chaîne de commandes.

-h, --help
-j, -json
Afficher les résultats au format JavaScript Object Notation (JSON).
-p, -pretty
Le format JSON par défaut est compact et plus efficace à analyser mais difficile à lire pour la plupart des utilisateurs. Cet indicateur ajoute une indentation pour la lisibilité.

Afficher l'aide concernant la dernière commande valide. Par exemple, tipc nametable --help affichera l'aide de la table des noms et tipc --help affichera l'aide générale. La position de l'option dans la chaîne est sans importance.

DESCRIPTION

La table des noms affiche les informations de publication TIPC.

Format de la table des noms

Type

Le champ de type 32 bits du nom du port. Le champ de type indique souvent la classe de service fournie par un port.
Inférieur

La borne inférieure du champ d'instance 32 bits du nom du port. Le champ d'instance est souvent utilisé comme indicateur de sous-classe.
Supérieur

La borne supérieure du champ d'instance 32 bits du nom du port. Le champ d'instance est souvent utilisé comme indicateur de sous-classe. Une différence entre inférieur et supérieur signifie que la socket est liée à la plage de noms de port [inférieur,supérieur].
Identifiant du port

L'identifiant unique de socket (port) au sein du cluster TIPC. L'identifiant du port se compose d'un identifiant de nœud suivi d'un numéro de référence de socket.
Publication

L'ID de publication est un nombre aléatoire utilisé en interne pour représenter une publication.
Portée

La portée de publication spécifie la visibilité d'un nom de port lié. La portée peut être spécifiée pour englober trois domaines différents : nœud, cluster et zone. Les applications résidant dans la portée spécifiée peuvent voir et accéder au port en utilisant le nom de port affiché.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi ou un entier positif en cas d'échec.
