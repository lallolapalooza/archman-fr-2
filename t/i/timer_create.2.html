timer_create(2) Manuel des appels système timer_create(2)

NOM

timer_create - créer un minuteur POSIX par processus

BIBLIOTHÉQUE

Bibliothèque temps réel (librt, -lrt)

SYNTAXE

#include <signal.h>           /* Définition des constantes SIGEV_* */
#include <time.h>
int timer_create(clockid_t clockid,
                 struct sigevent *_Nullable restrict sevp,
                 timer_t *restrict timerid);
Exigences de macro de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

timer_create():

    _POSIX_C_SOURCE >= 199309L

DESCRIPTION

timer_create() crée un nouveau minuteur d'intervalle par processus. L'identifiant du nouveau minuteur est retourné dans le tampon pointé par timerid, qui doit être un pointeur non nul. Cet identifiant est unique au sein du processus, jusqu'à ce que le minuteur soit supprimé. Le nouveau minuteur est initialement désarmé.

L'argument clockid spécifie l'horloge que le nouveau minuteur utilise pour mesurer le temps. Il peut être spécifié comme l'une des valeurs suivantes :

CLOCK_REALTIME
Une horloge temps réel système réglable.
CLOCK_MONOTONIC
Une horloge non réglable, croissante de manière monotone, qui mesure le temps à partir d'un point indéterminé dans le passé qui ne change pas après le démarrage du système.
CLOCK_PROCESS_CPUTIME_ID (depuis Linux 2.6.12)
Une horloge qui mesure le temps CPU (utilisateur et système) consommé par (tous les threads du) processus appelant.
CLOCK_THREAD_CPUTIME_ID (depuis Linux 2.6.12)
Une horloge qui mesure le temps CPU (utilisateur et système) consommé par le thread appelant.
CLOCK_BOOTTIME (Depuis Linux 2.6.39)
Comme CLOCK_MONOTONIC, c'est une horloge croissante de manière monotone. Cependant, alors que l'horloge CLOCK_MONOTONIC ne mesure pas le temps pendant qu'un système est suspendu, l'horloge CLOCK_BOOTTIME inclut le temps pendant lequel le système est suspendu. Ceci est utile pour les applications qui doivent être conscientes de la suspension. CLOCK_REALTIME ne convient pas à de telles applications, car cette horloge est affectée par des changements discontinus de l'horloge système.
CLOCK_REALTIME_ALARM (depuis Linux 3.0)
Cette horloge est similaire à CLOCK_REALTIME, mais elle réveillera le système s'il est suspendu. L'appelant doit posséder la capacité CAP_WAKE_ALARM pour pouvoir régler un minuteur sur cette horloge.
CLOCK_BOOTTIME_ALARM (depuis Linux 3.0)
Cette horloge est similaire à CLOCK_BOOTTIME, mais elle réveillera le système s'il est suspendu. L'appelant doit posséder la capacité CAP_WAKE_ALARM pour pouvoir régler un minuteur sur cette horloge.
CLOCK_TAI (depuis Linux 3.10)
Une horloge système dérivée de l'heure du cadran mais comptant les secondes intercalaires.

Voir clock_getres(2) pour plus de détails sur les horloges ci-dessus.

En plus des valeurs ci-dessus, clockid peut être spécifié comme le clockid retourné par un appel à clock_getcpuclockid(3) ou pthread_getcpuclockid(3).

L'argument sevp pointe vers une structure sigevent qui spécifie comment l'appelant doit être notifié lorsque le minuteur expire. Pour la définition et les détails généraux de cette structure, voir sigevent(3type).

Le champ sevp.sigev_notify peut avoir les valeurs suivantes :

SIGEV_NONE
Ne pas notifier de manière asynchrone à l'expiration du minuteur. La progression du minuteur peut être surveillée en utilisant timer_gettime(2).
SIGEV_SIGNAL
À l'expiration du minuteur, générer le signal sigev_signo pour le processus. Voir sigevent(3type) pour les détails généraux. Le champ si_code de la structure siginfo_t sera défini à SI_TIMER. À tout moment, au plus un signal est mis en file d'attente pour le processus pour un minuteur donné ; voir timer_getoverrun(2) pour plus de détails.
SIGEV_THREAD
À l'expiration du minuteur, appeler sigev_notify_function comme si c'était la fonction de démarrage d'un nouveau thread. Voir sigevent(3type) pour les détails.
SIGEV_THREAD_ID (spécifique à Linux)
Comme pour SIGEV_SIGNAL, mais le signal est ciblé vers le thread dont l'identifiant est donné dans sigev_notify_thread_id, qui doit être un thread du même processus que l'appelant. Le champ sigev_notify_thread_id spécifie un identifiant de thread noyau, c'est-à-dire la valeur retournée par clone(2) ou gettid(2). Ce drapeau est destiné uniquement à être utilisé par les bibliothèques de threads.

Spécifier sevp comme NULL est équivalent à spécifier un pointeur vers une structure sigevent dans laquelle sigev_notify est SIGEV_SIGNAL, sigev_signo est SIGALRM, et sigev_value.sival_int est l'identifiant du minuteur.

VALEUR DE RETOUR

En cas de succès, timer_create() retourne 0, et l'identifiant du nouveau minuteur est placé dans *timerid. En cas d'échec, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EAGAIN
Erreur temporaire lors de l'allocation noyau des structures de minuteur.
EINVAL
L'identifiant d'horloge, sigev_notify, sigev_signo, ou sigev_notify_thread_id est invalide.
ENOMEM
Impossible d'allouer de la mémoire.
ENOTSUP
Le noyau ne prend pas en charge la création d'un minuteur sur cette clockid.
EPERM
clockid était CLOCK_REALTIME_ALARM ou CLOCK_BOOTTIME_ALARM, mais l'appelant ne possédait pas la capacité CAP_WAKE_ALARM.

VERSIONS

Différences bibliothèque C/noyau

Une partie de l'implémentation de l'API des minuteurs POSIX est fournie par glibc. En particulier :

•
La majeure partie de la fonctionnalité pour SIGEV_THREAD est implémentée au sein de glibc, plutôt que dans le noyau. (C'est nécessairement le cas, car le thread impliqué dans la gestion de la notification est celui qui doit être géré par l'implémentation des threads POSIX de la bibliothèque C.) Bien que la notification délivrée au processus se fasse via un thread, interne, l'implémentation NPTL utilise une valeur sigev_notify de SIGEV_THREAD_ID avec un signal temps réel qui est réservé par l'implémentation (voir nptl(7)).
•
L'implémentation du cas par défaut où evp est NULL est gérée à l'intérieur de glibc, qui appelle l'appel système sous-jacent avec une structure sigevent convenablement remplie.
•
Les identifiants de minuteurs présentés au niveau utilisateur sont maintenus par glibc, qui fait correspondre ces identifiants aux identifiants de minuteurs utilisés par le noyau.

HISTORIQUE

Linux 2.6. POSIX.1-2001.

Avant Linux 2.6, glibc fournissait une implémentation dans l'espace utilisateur incomplète (temporisateurs CLOCK_REALTIME uniquement) utilisant des threads POSIX, et avant glibc 2.17, l'implémentation revient à cette technique sur les systèmes exécutant des noyaux plus anciens que Linux 2.6.

NOTES

Un programme peut créer plusieurs temporisateurs à intervalles en utilisant timer_create().

Les temporisateurs ne sont pas hérités par l'enfant d'un fork(2), et sont désarmés et supprimés lors d'un execve(2).

Le noyau préalloue un « signal temps réel mis en file d'attente » pour chaque temporisateur créé à l'aide de timer_create(). Par conséquent, le nombre de temporisateurs est limité par la limite de ressources RLIMIT_SIGPENDING (voir setrlimit(2)).

Les temporisateurs créés par timer_create() sont communément appelés « temporisateurs POSIX (d'intervalle) ». L'API des temporisateurs POSIX se compose des interfaces suivantes :

timer_create()
Créer un temporisateur.
timer_settime(2)
Armer (démarrer) ou désarmer (arrêter) un temporisateur.
timer_gettime(2)
Obtenir le temps restant jusqu'à la prochaine expiration d'un temporisateur, ainsi que le réglage de l'intervalle du temporisateur.
timer_getoverrun(2)
Retourner le nombre de dépassements pour la dernière expiration du temporisateur.
timer_delete(2)
Désarmer et supprimer un temporisateur.

Depuis Linux 3.10, le fichier /proc/pid/timers peut être utilisé pour lister les temporisateurs POSIX pour le processus avec PID pid. Voir proc(5) pour plus d'informations.

Depuis Linux 4.10, la prise en charge des temporisateurs POSIX est une option configurable qui est activée par défaut. La prise en charge du noyau peut être désactivée via l'option CONFIG_POSIX_TIMERS.

EXEMPLES

Le programme ci-dessous prend deux arguments : une période de mise en veille en secondes et une fréquence de temporisateur en nanosecondes. Le programme établit un gestionnaire pour le signal qu'il utilise pour le temporisateur, bloque ce signal, crée et arme un temporisateur qui expire avec la fréquence donnée, se met en veille pendant le nombre de secondes spécifié, puis débloque le signal du temporisateur. En supposant que le temporisateur ait expiré au moins une fois pendant que le programme dormait, le gestionnaire de signal sera appelé, et le gestionnaire affichera des informations sur la notification du temporisateur. Le programme se termine après une invocation du gestionnaire de signal.

Dans l'exemple d'exécution suivant, le programme dort pendant 1 seconde, après avoir créé un temporisateur dont la fréquence est de 100 nanosecondes. Au moment où le signal est débloqué et délivré, il y a eu environ dix millions de dépassements.


$ ./a.out 1 100;
Établissement du gestionnaire pour le signal 34
Blocage du signal 34
ID du temporisateur : 0x804c008
Mise en veille pendant 1 seconde
Déblocage du signal 34
Signal 34 intercepté
    sival_ptr = 0xbfb174f4 ;    *sival_ptr = 0x804c008
    compteur de dépassements = 10004886

Source du programme

#include <err.h>
#include <signal.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include <unistd.h>
#define CLOCKID CLOCK_REALTIME
#define SIG SIGRTMIN
static void
print_siginfo(siginfo_t *si)
{
    int      or;
    timer_t  *tidp;
    tidp = si->si_value.sival_ptr;
    printf("    sival_ptr = %p ;                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     si->si_value.sival_ptr);
    or = timer_getoverrun(*tidp);
    if (or == -1)
        err(EXIT_FAILURE, "timer_getoverrun");
    printf("    compteur de dépassements = %d\n", or);
}
static void
handler(int sig, siginfo_t *si, void *uc)
{
    /* Note : l'appel à printf() à partir d'un gestionnaire de signal n'est pas sûr
       (et ne doit pas être fait dans des programmes de production), car
       printf() n'est pas async-signal-safe ; voir signal-safety(7).
       Néanmoins, nous utilisons printf() ici comme un moyen simple de
       montrer que le gestionnaire a été appelé.  */
    printf("Signal %d intercepté\n", sig);
    print_siginfo(si);
    signal(sig, SIG_IGN);
}
int
main(int argc, char *argv[])
{
    timer_t            timerid;
    sigset_t           mask;
    long long          freq_nanosecs;
    struct sigevent    sev;
    struct sigaction   sa;
    struct itimerspec  its;
    if (argc != 3) {
        fprintf(stderr, "Usage : %s <sleep-secs> <freq-nanosecs>\n",
                argv[0]);
        exit(EXIT_FAILURE);
    }
    /* Établir le gestionnaire pour le signal du temporisateur.  */
    printf("Établissement du gestionnaire pour le signal %d\n", SIG);
    sa.sa_flags = SA_SIGINFO;
    sa.sa_sigaction = handler;
    sigemptyset(&sa.sa_mask);
    if (sigaction(SIG, &sa, NULL) == -1)
        err(EXIT_FAILURE, "sigaction");
    /* Bloquer temporairement le signal du temporisateur.  */
    printf("Blocage du signal %d\n", SIG);
    sigemptyset(&mask);
    sigaddset(&mask, SIG);
    if (sigprocmask(SIG_SETMASK, &mask, NULL) == -1)
        err(EXIT_FAILURE, "sigprocmask");
    /* Créer le temporisateur.  */
    sev.sigev_notify = SIGEV_SIGNAL;
    sev.sigev_signo = SIG;
    sev.sigev_value.sival_ptr = &timerid;
    if (timer_create(CLOCKID, &sev, &timerid) == -1)
        err(EXIT_FAILURE, "timer_create");
    printf("ID du temporisateur : %#jx\n", (uintmax_t) timerid);
    /* Démarrer le temporisateur.  */
    freq_nanosecs = atoll(argv[2]);
    its.it_value.tv_sec = freq_nanosecs / 1000000000;
    its.it_value.tv_nsec = freq_nanosecs % 1000000000;
    its.it_interval.tv_sec = its.it_value.tv_sec;
    its.it_interval.tv_nsec = its.it_value.tv_nsec;
    if (timer_settime(timerid, 0, &its, NULL) == -1)
         err(EXIT_FAILURE, "timer_settime");
    /* Mettre en veille pendant un certain temps ; pendant ce temps, le temporisateur
       peut expirer plusieurs fois.  */
    printf("Mise en veille pendant %d secondes\n", atoi(argv[1]));
    sleep(atoi(argv[1]));
    /* Débloquer le signal du temporisateur, afin que la notification du
       temporisateur puisse être délivrée.  */
    printf("Déblocage du signal %d\n", SIG);
    if (sigprocmask(SIG_UNBLOCK, &mask, NULL) == -1)
        err(EXIT_FAILURE, "sigprocmask");
    exit(EXIT_SUCCESS);
}
