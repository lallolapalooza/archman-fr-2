timeval(3type) timeval(3type)

NOM

timeval - temps en secondes et microsecondes

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <sys/time.h>
struct timeval {
    time_t       tv_sec;   /* Secondes */
    suseconds_t  tv_usec;  /* Microsecondes */
};

DESCRIPTION

Décrit des temps en secondes et microsecondes.

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001.

NOTES

Les en-têtes suivants fournissent également ce type : <sys/resource.h>, <sys/select.h>, et <utmpx.h>.

VOIR AUSSI

gettimeofday(2), select(2), utimes(2), adjtime(3), futimes(3), timeradd(3), suseconds_t(3type), time_t(3type), timespec(3type)
