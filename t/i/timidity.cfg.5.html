NOM

timidity.cfg - fichier de configuration de TiMidity++

DESCRIPTION

Le fichier timidity.cfg décrit les environnements d'exécution de TiMidity++ : le chemin des banques de sons, les configurations d'instruments, etc.
TiMidity++ recherche le fichier de configuration timidity.cfg au démarrage, avant de traiter les options. S'il ne peut pas y accéder et que le chemin de bibliothèque est modifié avec une option -L en ligne de commande, le fichier par défaut sera recherché à nouveau le long du nouveau chemin de bibliothèque après le traitement de toutes les options, à moins qu'un autre fichier de configuration n'ait été spécifié avec l'option -c.
Les fichiers de configuration définissent le mappage des programmes MIDI aux fichiers d'instruments. Plusieurs fichiers peuvent être spécifiés, et les instructions des fichiers ultérieurs remplaceront celles des fichiers précédents.

VARIABLE

Lorsque des caractères alphanumériques et/ou des traits de soulignement `_' continuent après le signe dollar `$'. Il est considéré que la chaîne est une variable et que le fichier de configuration est traité, il est transposé à une autre chaîne. Le nom de la variable peut également être écrit entre parenthèses, afin d'être séparé d'un caractère suivant.

Par exemple :
$variable
${variable} # identique à $variable

Pour le moment, la commande qui définit de nouvelles variables n'est pas prête. La variable non définie est transposée à une chaîne nulle.
La variable définie comme variable régulière est seulement la suivante.

$basedir
Exprime le répertoire où se trouve le fichier de configuration. Par la commande qui spécifie principalement un chemin, il est utilisé pour spécifier le chemin relatif à partir d'un fichier de configuration.
Lorsqu'un espace peut être inclus dans $basedir, il est nécessaire de le mettre entre guillemets.

Par exemple :
Dans /usr/local/share/timidity/timidity.cfg
dir $basedir/inst # source /usr/local/share/timidity/inst

SYNTAXE

Les instructions suivantes peuvent être utilisées dans un fichier de configuration :

dir répertoire [...]
Ajoute répertoire au chemin de recherche de la même manière que l'option de ligne de commande -L.
Les fichiers d'archive sont également autorisés.

Par exemple :
dir /usr/local/share/timidity/inst/foo.zip#
bank 0
0 bar.pat
1 baz.pat
2 zoo.pat

Dans un premier temps, dir spécifie le nom de l'archive (suivi de `#') pour le chemin des fichiers de patchs, de la même manière qu'un nom de répertoire (dans ce cas, /usr/local/share/timidity/inst/foo.zip). TiMidity++ reconnaît que le chemin est un fichier d'archive si l'expression a le dernier caractère `#', et lit également les fichiers contenus dans cette archive. Dans l'exemple précédent, les fichiers de patchs bar.pat, baz.pat et zoo.pat contenus dans foo.zip sont également installés.

source fichier [...]
Lit un autre fichier de configuration, puis continue le traitement du fichier actuel.
progbase nombre
Définit et affiche le numéro de ton de nombre à nombre+128. Si progbase 1 est spécifié, les numéros de tons suivants sont définis et affichés comme les numéros de 1 à 128.
bank [MapID1] nombre
Sélectionne la banque de tons à modifier. Les mappages de patchs suivants affecteront cette banque de tons. Vous pouvez indiquer une carte spécifique en tant que cible, en spécifiant l'un des éléments suivants pour MapID1 : gm2, sc55, sc88, sc88pro, sc8850, xg et xgsfx64.
drumset [MapID2] nombre
Sélectionne le jeu de percussions à modifier. Les mappages de patchs suivants affecteront ce jeu de percussions. Vous pouvez indiquer une carte spécifique en tant que cible, en spécifiant l'un des éléments suivants pour MapID2 : gm2drum, sc55drum, sc88drum, sc88prodrum, sc8850drum, xgdrum et xgsfx126.
number fichier [options]

number %font fichier banque prog [clé] [options]

number %sample fichier [options]
Spécifie que le numéro de programme MIDI dans la banque de tons actuelle ou le jeu de percussions doit être joué en utilisant le fichier de patchs. Si fichier est une SoundFont, l'instrument spécifique avec banque, prog et clé est extrait selon le format de number %font. Si fichier sont des données d'échantillon AIFF ou WAV linéaires, le numéro de programme MIDI est spécifié par le format de number %sample. Les options peuvent être l'une des suivantes :
amp=amplification
Amplifie le volume de l'instrument de amplification pour cent. Si aucune valeur n'est spécifiée, une sera déterminée automatiquement chaque fois que l'instrument sera chargé.
note=note
Spécifie une note MIDI fixe à utiliser lors de la lecture de l'instrument. Si note est 0, l'instrument sera joué à la note que l'événement Note On qui le déclenche a. Pour les instruments de percussion, si aucune valeur n'est spécifiée dans le fichier de configuration, la valeur par défaut du fichier de patch sera utilisée.
pan=panoramique
Définit le panoramique par défaut de l'instrument. panoramique peut être left, right, center, ou un entier compris entre -100 et 100, désignant respectivement la gauche totale et la droite totale. Si aucune valeur n'est spécifiée, le défaut du fichier de patch sera utilisé. Notez que les contrôles de panoramique dans les fichiers MIDI remplaceront cette valeur.
tune=accord[,...]
Ajuste la fréquence fondamentale de l'instrument. tune=1 entraîne une augmentation de 1 demi-ton. Comme une fraction est disponible pour accord, il est possible de faire des ajustements fins tels que tune=-0.2. Lorsque deux ou plusieurs données d'échantillon sont contenues, les arguments après le second peuvent spécifier des valeurs différentes respectivement.
rate=attaque:decay:sustain:release1:release2:release3[,...]
Définit le taux ADSR de l'instrument. Chaque valeur peut être un entier entre 0 et 255. Lorsque vous définissez uniquement le taux de sustain,

6 GUS/hrpschrd.pat rate=::60

est disponible. Lorsque vous définissez uniquement l'attaque rapide,

6 GUS/hrpschrd.pat rate=255

est disponible. Lorsque deux ou plusieurs données d'échantillon sont contenues, les arguments après le second peuvent spécifier des valeurs différentes respectivement.

offset=attaque:decay:sustain:release1:release2:release3[,...]
Définit le décalage ADSR de l'instrument. Chaque valeur peut être un entier entre 0 et 255. Le format est le même que rate=.
keep={loop|env}
Par défaut, les instruments de percussion ont leurs informations de boucle et d'enveloppe supprimées. Les enveloppes de forme étrange sont également automatiquement supprimées des instruments mélodiques. keep= peut être utilisé pour empêcher la suppression des données de boucle ou d'enveloppe. Par exemple, les instruments de percussion Short et Long Whistle (numéros General Midi 71 et 72) nécessitent que `keep=loop keep=env' soit spécifié dans le fichier de configuration.
strip={loop|env|tail}
Force la suppression des informations de boucle ou d'enveloppe de tous les patchs de l'instrument, ou supprime la queue, c'est-à-dire toutes les données après la boucle. Certains instruments tiers ont des données inutiles après la boucle, comme en témoigne un bruit de clic lorsque l'instrument est joué, donc l'ajout de l'option strip=tail améliorera nettement la qualité sonore.
tremolo=sweep_increment:control_ratio:depth[,...]
Définit le trémolo de l'instrument. Chaque valeur peut être un entier entre 0 et 255. Le format est similaire à rate=. sweep_increment est le temps avant le démarrage du trémolo. control_ratio est le taux de modification de l'amplification. depth est la profondeur de modification de l'amplification.
on.
vibrato=sweep_increment:phase_increment:depth[,...]
Définit le vibrato de l'instrument. Chaque valeur peut être un entier compris entre 0 et 255. Le format est similaire à rate=. sweep_increment est le temps avant le démarrage du vibrato. phase_increment est le taux de changement de fréquence. depth est le taux de changement de profondeur.
sclnote=note[,...]
Définit la note standard de l'instrument pour le réglage de l'échelle. Par exemple, sclnote=60 fait du Do central la note standard pour le réglage de l'échelle. Lorsque deux échantillons de données ou plus sont contenus, les arguments après le deuxième peuvent spécifier des valeurs différentes respectivement.
scltune=tune[,...]
Définit le facteur de réglage de l'échelle de l'instrument en cents. Par exemple, scltune=50 fait que les demi-tons sont de 50 cents. Lorsque deux échantillons de données ou plus sont contenus, les arguments après le deuxième peuvent spécifier des valeurs différentes respectivement.
comm=comment
Spécifie le commentaire comment.
modrate=attack:decay:sustain:release1:release2:release3[,...]

modoffset=attack:decay:sustain:release1:release2:release3[,...]
Définit le comportement de l'instrument lors du changement de l'enveloppe de modulation. Le format et les valeurs sont fondamentalement identiques à l'enveloppe de volume. À l'exception de certaines SoundFonts, même si une seule option est spécifiée, rien ne se passe.
envkeyf=attack:decay:sustain:release1:release2:release3[,...]
Définit le suivi de note de l'enveloppe de volume de l'instrument. Basé sur note=60, il modifie le temps de l'enveloppe en fonction de la note. L'unité est +-cent/note. Par exemple, envkeyf=100 signifie que le temps d'attaque doublera lorsqu'il augmentera d'une octave. Le format est similaire à rate=. Le paramètre de decay et sustain peut être prédéfini dans certaines SoundFont.
envvelf=attack:decay:sustain:release1:release2:release3[,...]
Définit le suivi de vélocité de l'enveloppe de volume de l'instrument. Basé sur velocity=64, il modifie le temps de l'enveloppe en fonction de la vélocité. L'unité est +-cent/vélocité. Par exemple, envvelf=100 signifie que le temps d'attaque sera multiplié par 38 à velocity=127. Le format est similaire à rate=. À l'avenir, la spécification de cette option pourrait être modifiée.
modkeyf=attack:decay:sustain:release1:release2:release3[,...]
Définit le suivi de note de l'enveloppe de modulation de l'instrument. Basé sur note=60, il modifie le temps de l'enveloppe en fonction de la note. L'unité est +-cent/note. Par exemple, modkeyf=100 signifie que le temps d'attaque doublera lorsqu'il augmentera d'une octave. Le format est similaire à rate=. Le paramètre de decay et sustain peut être prédéfini dans certaines SoundFont.
modvelf=attack:decay:sustain:release1:release2:release3[,...]
Définit le suivi de vélocité de l'enveloppe de modulation de l'instrument. Basé sur velocity=64, il modifie le temps de l'enveloppe en fonction de la vélocité. L'unité est +-cent/vélocité. Par exemple, modvelf=100 signifie que le temps d'attaque sera multiplié par 38 à velocity=127. Le format est similaire à rate=. À l'avenir, la spécification de cette option pourrait être modifiée.
trempitch=num[,...]
Définit la profondeur du changement de hauteur de l'instrument en fonction du trémolo. L'effet lui-même est identique au vibrato, il est utilisé pour fonctionner dans un autre système. L'unité est +-cent. Le format est similaire à rate=.
tremfc=num[,...]
Définit la profondeur du changement de fréquence de coupure de l'instrument en fonction du trémolo. Il peut exprimer l'effet dit "glowl". L'unité, etc. sont identiques à trempitch=.
modpitch=num[,...]
Définit la profondeur du changement de hauteur de l'instrument en fonction de l'enveloppe de modulation. Il peut exprimer temporairement une augmentation de hauteur uniquement pour l'attaque. L'unité, etc. sont identiques à trempitch=.
modfc=num[,...]
Définit la profondeur du changement de fréquence de coupure de l'instrument en fonction de l'enveloppe de modulation. L'unité, etc. sont identiques à trempitch=.
fc=num[,...]
Définit la référence de fréquence de coupure de l'instrument. L'unité est Hz. Le format est similaire à rate=.
q=num[,...]
Définit le Q (résonance) de l'instrument. L'unité est cB. Le format est similaire à rate=.
fckeyf=num
Définit le suivi de note du filtre de l'instrument. Basé sur note=60, il modifie la fréquence de coupure en fonction de la note. L'unité est +-cent/note. Par exemple, fckeyf=100 signifie qu'il change de la même manière que la hauteur.
fcvelf=num
Définit le suivi de vélocité du filtre de l'instrument. Basé sur velocity=127, il modifie la fréquence de coupure en fonction de la vélocité. L'unité est +-cent. Dans SoundFont, -2400 est défini comme une valeur caractéristique.
qvelf=num
Définit le suivi de vélocité de la résonance de l'instrument. Basé sur velocity=0, il modifie la résonance en fonction de la vélocité. L'unité est +-cB.
default file
Lorsque le programme MIDI apparaît, et qu'il n'est pas mappé à un fichier d'instrument, ce fichier est joué en remplacement.
map MapID1 from-bank from-prog to-bank to-prog
Le ton existant est attribué comme ton de GS/XG chaque carte. gm2, sc55, sc88, sc88pro, sc8850, xg et xgsfx64 peuvent être spécifiés pour MapID1.
map MapID2 from-drumset from-keynote to-drumset to-keynote
La batterie existante est attribuée comme batterie GS/XG chaque carte. gm2drum, sc55drum, sc88drum, sc88prodrum, sc8850drum, xgdrum et xgsfx126 peuvent être spécifiés pour MapID2.
soundfont file [options]
Lit toute la SoundFont. options peuvent être l'une des suivantes :
order=number
Définit l'ordre de recherche de l'instrument. Lorsque order=0, on lit d'abord la SoundFont, puis on recherche les échantillons manquants dans GUS/patch. Lorsque order=1, après avoir lu GUS/patch, on recherche dans la SoundFont.
amp=amplification
Définit l'amplification de toute la SoundFont en pourcentage amplification%. Si la valeur n'est pas spécifiée, elle est définie à 100%.
cutoff=number
Spécifie si le LPF de la SoundFont est activé (1) ou désactivé (0). Si la valeur n'est pas spécifiée, elle est considérée comme activée.
reso=number
Spécifie si la résonance de la SoundFont est activée (1) ou désactivée (0). Si la valeur n'est pas spécifiée, elle est considérée comme activée.
remove
Annule la SoundFont cible de la mémoire.
font exclude bank [prog [key]]
Supprime la recherche de SoundFont de bank, prog. Si l'échantillon est un set de batterie, la banque est 128, le set de batterie est prog, la clé est key.
font order number bank [prog [key]]
Définit l'ordre de recherche des instruments individuellement. Le format est identique à font exclude.

Les instructions suivantes sont disponibles uniquement dans la dernière version de TiMidity++.

#extension altassign program1 program2 ...
Définit l'attribution alternative pour le set de batterie. Par exemple, si vous souhaitez jouer les cymbales Hi-Hat (numéros de note 42, 44 et 46) dans le drumset 0 exclusivement les unes par rapport aux autres, spécifiez :

drumset 0
altassign 42 44 46

Notez que l'attribution alternative du drumset 0 est utilisée par défaut.

#extension comm program comment
Spécifie le commentaire comment pour le numéro de ton program. Ces commentaires sont affichés dans la ligne d'indicateur lorsque TiMidity++ est démarré avec les options -int, -iTt.
#extension timeout program second
Spécifie la valeur de dépassement de délai (timeout) pour le program. Si des notes jouées avec le numéro de ton program sont suspendues pendant plus de second secondes, TiMidity++ arrête les notes.
#extension copydrumset drumset
Copie tous les réglages du drumset dans le set de batterie actuel.
#extension copybank bank
Copie tous les réglages de la bank dans la banque actuelle.
#extension copymap to-MapID from-MapID
Copie tous les réglages des banques définies pour la carte from-MapID vers la carte to-MapID.
#extension HTTPproxy hostname:port
Spécifie le proxy pour le protocole HTTP. hostname et port sont ceux de l'hôte proxy.
#extension FTPproxy hostname:port
Spécifie le proxy pour le protocole FTP. Identique à HTTP.
#extension mailaddr your-mail-address
Spécifie l'adresse e-mail de l'utilisateur. Cette adresse est envoyée au serveur FTP si TiMidity++ accède à un fichier via FTP.
#extension opt option
Définit la valeur des options de démarrage.
#extension undef progno
Annule la définition du ton progno de la banque de tons actuelle.
#extension legato progno {0|1}
Spécifie si le legato est activé (1) ou désactivé (0) sur progno.
#extension level progno tva_level
Définit le
e valeur standard du changement d'amplification lors du traitement d'un instrument de batterie Niveau TVA de l'instrument de batterie NRPN. Sauf si le niveau TVA de l'instrument de batterie est spécifié lors de la lecture, l'amplification n'est pas influencée. progno peut effectuer une spécification de paquet par `,' et/ou [début]-[fin]. Si début et fin sont omis, ils sont supposés être 0 et 127 respectivement.
#extension damper progno {0|1}
Spécifie si le redamper et le demi-damper sont activés (1) ou désactivés (0) sur progno.
#extension playnote progno note
Définit la fréquence de prononciation à note. Si la fréquence de prononciation est spécifiée par GS SysEx Play Note, la hauteur est modifiée appropriément selon la valeur. progno peut effectuer une spécification de paquet par `,' et/ou [début]-[fin]. Si début et fin sont omis, ils sont supposés être 0 et 127 respectivement.

Par exemple :
drumset 0
#extension playnote -37,39,44-46,55-60

#extension delaysend progno level

#extension chorussend progno level

#extension reverbsend progno level
Définit le niveau d'envoi lorsque l'effet de partie de batterie est activé. Toutes les valeurs initiales sont 127. Si au moins un des effets delay, chorus ou reverb est configuré, l'effet qui n'est pas configuré comme ton deviendra la valeur initiale 0. progno peut effectuer une spécification de paquet par `,' et/ou [début]-[fin]. Si début et fin sont omis, ils sont supposés être 0 et 127 respectivement.
#extension rnddelay progno msec
Pour chaque prononciation, un délai aléatoire inférieur à un maximum de msec est appliqué. La distribution de la valeur aléatoire est un bruit rose (fluctuation 1/f) plutôt qu'un bruit blanc.

Ces déclarations #extension commencent par le caractère `#' qui est le drapeau de commentaire de l'ancien TiMidity (version 0.2i ou antérieure). Donc ces déclarations sont traitées comme des lignes de commentaire.
Le dernier TiMidity++ traite #extension comme un espace blanc. Vous pouvez donc l'omettre.

Si une expression de nom de fichier se termine par le caractère `|' (Ascii 0x7c), le nom de fichier est traité comme une commande et les sorties de la commande sont également examinées comme arguments des déclarations.
source commande| provoque la sortie de commande qui devient l'argument de source. C'est pratique pour choisir les paramètres de TiMidity++ en fonction de l'environnement. De plus, si un espace apparaît en cours de route comme commande |, il sera divisé lors de la lecture du fichier de configuration, et ne sera plus considéré comme une commande. Cette fonction est applicable à tous les endroits où un nom de fichier peut être spécifié.

timidity 'cat fild.mid|'

lire depuis la sortie de cat fild.mid.
