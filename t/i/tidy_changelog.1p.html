NOM

tidy_changelog - outil en ligne de commande pour CPAN::Changes

SYNTAXE

$ tidy_changelog Changelog

DESCRIPTION

Prend un fichier de journal des modifications (changelog), le parse en utilisant CPAN::Changes et affiche le résultat. Si aucun fichier n'est fourni, le programme essaie de trouver un fichier dans le répertoire courant commençant par 'change' (insensible à la casse) et, si c'est le cas, suppose que c'est le journal des modifications.

ARGUMENTS

--next

Si fourni, suppose qu'il existe un en-tête de remplacement pour la prochaine version à venir. Le jeton de remplacement est donné via --token.

--token

Expression régulière à utiliser pour détecter le jeton d'une version à venir si --next est utilisé. Si non explicitement donné, par défaut à "\{\{\$NEXT\}\}".

--headers

Si donné, affiche uniquement les lignes d'en-tête de version, sans aucune des modifications.

--reverse

Affiche les versions dans l'ordre inverse (de la plus ancienne à la plus récente).

--check

Vérifie uniquement si le journal des modifications est correctement formaté en utilisant la fonction changes_file_ok de Test::CPAN::Changes.

--help
