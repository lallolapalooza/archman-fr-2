TIMESHIFT(1) Commandes utilisateur TIMESHIFT(1)

NOM

Timeshift - page de manuel pour Timeshift 25.07.7

DESCRIPTION

Timeshift v25.07.7 par Tony George (teejeetech@gmail.com)

Syntaxe :

timeshift --check timeshift --create [OPTIONS] timeshift --restore [OPTIONS] timeshift --delete-[all] [OPTIONS] timeshift --list-{snapshots|devices} [OPTIONS]

OPTIONS

Liste :

--list[-snapshots]
Lister les snapshots
--list-devices
Lister les périphériques

Sauvegarde :

--check
Créer un snapshot s'il est planifié
--create
Créer un snapshot (même s'il n'est pas planifié)
--comments <chaîne>
Définir la description du snapshot
--tags {O,B,H,D,W,M}
Ajouter des tags au snapshot (par défaut : O)

Restauration :

--restore
Restaurer un snapshot
--snapshot <nom>
Spécifier le snapshot à restaurer

--target[-device] <périphérique> Spécifier le périphérique cible

--grub[-device] <périphérique>
Spécifier le périphérique pour l'installation du chargeur de démarrage GRUB2
--skip-grub
Sauter la réinstallation de GRUB2

Suppression :

--delete
Supprimer un snapshot
--delete-all
Supprimer tous les snapshots

Global :

--snapshot-device <périphérique> Spécifier le périphérique de sauvegarde (par défaut : config)

--yes
Répondre OUI à toutes les invites de confirmation
--btrfs
Passer en mode BTRFS (par défaut : config)
--rsync
Passer en mode RSYNC (par défaut : config)
--debug
Afficher des messages de débogage supplémentaires
--verbose
Afficher la sortie de rsync (par défaut)
--quiet
Masquer la sortie de rsync
--scripted
Exécuter en mode non interactif
--help
Afficher toutes les options
--version
Afficher le numéro de version

EXEMPLES

timeshift --list timeshift --list --snapshot-device /dev/sda1 timeshift --create --comments "après mise à jour" --tags D timeshift --restore timeshift --restore --snapshot '2014-10-12_16-29-08' --target /dev/sda1 timeshift --delete --snapshot '2014-10-12_16-29-08' timeshift --delete-all

Notes :

1) --create créera toujours un nouveau snapshot 2) --check créera un snapshot uniquement si un snapshot planifié est dû 3) Utiliser --restore sans autres options pour sélectionner les options interactivement 4) L'UUID peut être spécifié à la place du nom de périphérique 5) Les valeurs par défaut seront chargées à partir de la configuration de l'application si les options ne sont pas spécifiées
