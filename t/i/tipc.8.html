NOM

tipc - un outil de configuration et de gestion TIPC

SYNTAXE


tipc [ OPTIONS ] COMMANDE ARGUMENTS

COMMANDE := { bearer | link | media | nametable | node | socket }

OPTIONS := { -h[aide] }

DESCRIPTION

Le protocole Transparent Inter-Process Communication (TIPC) offre une transparence d'adresse totale entre les processus, ce qui permet aux applications dans un environnement informatique en cluster de communiquer rapidement et de manière fiable entre elles, quelle que soit leur position au sein du cluster.

TIPC est né chez l'équipementier en télécommunications Ericsson. La première version open source de TIPC a été créée en 2000 lorsque Ericsson a publié sa première version Linux de TIPC. TIPC a été introduit dans le noyau Linux principal en 2006 et est maintenant largement utilisé à l'intérieur et à l'extérieur d'Ericsson.

OPTIONS

-h, --help
Afficher l'aide sur la dernière commande donnée. Par exemple, tipc bearer --help affichera l'aide du porteur et tipc --help affichera l'aide générale. La position de l'option dans la chaîne est sans importance.
-j, -json
Afficher les résultats au format JavaScript Object Notation (JSON).
-p, -pretty
Le format JSON par défaut est compact et plus efficace à analyser mais difficile à lire pour la plupart des utilisateurs. Ce drapeau ajoute une indentation pour une meilleure lisibilité.

COMMANDES

BEARER
- Afficher ou modifier les porteurs TIPC
LINK
- Afficher ou modifier les liens TIPC
MEDIA
- Afficher ou modifier les médias TIPC
NAMETABLE
- Afficher la table des noms TIPC
NODE
- Afficher ou modifier les paramètres du nœud TIPC
SOCKET
- Afficher les sockets TIPC

ARGUMENTS

Les arguments de la commande sont décrits dans une page de manuel spécifique à la commande et consistent généralement en des commandes imbriquées avec des paires clé-valeur. Si aucun argument n'est donné, une commande affiche généralement son texte d'aide. L'option d'aide explicite -h ou --help peut apparaître n'importe où parmi les arguments et affichera l'aide pour la dernière commande valide donnée.

ETAT DE SORTIE

L'état de sortie est 0 si la commande a réussi ou un entier positif en cas d'échec.
