time.h(0P) Manuel du programmeur POSIX time.h(0P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

time.h — types de temps

SYNTAXE

#include <time.h>

DESCRIPTION

Certaines des fonctionnalités décrites sur cette page de référence étendent la norme ISO C. Les applications doivent définir la macro de test de fonctionnalité appropriée (voir le volume Interfaces système de POSIX.1‐2017, Section 2.2, L'environnement de compilation) pour activer la visibilité de ces symboles dans ce fichier d'en-tête.

Le fichier d'en-tête <time.h> doit définir les types clock_t, size_t, time_t, tels que décrits dans <sys/types.h>.

Le fichier d'en-tête <time.h> doit définir les types clockid_t et timer_t tels que décrits dans <sys/types.h>.

Le fichier d'en-tête <time.h> doit définir le type locale_t tel que décrit dans <locale.h>.

Le fichier d'en-tête <time.h> doit définir le type pid_t tel que décrit dans <sys/types.h>.

Le tag sigevent doit être déclaré comme nommant un type de structure incomplète, dont le contenu est décrit dans le fichier d'en-tête <signal.h>.

Le fichier d'en-tête <time.h> doit déclarer la structure tm, qui doit inclure au moins les membres suivants :

int    tm_sec   Secondes [0,60].
int    tm_min   Minutes [0,59].
int    tm_hour  Heure [0,23].
int    tm_mday  Jour du mois [1,31].
int    tm_mon   Mois de l'année [0,11].
int    tm_year  Années depuis 1900.
int    tm_wday  Jour de la semaine [0,6] (Dimanche =0).
int    tm_yday  Jour de l'année [0,365].
int    tm_isdst Indicateur d'heure d'été.

La valeur de tm_isdst doit être positive si l'heure d'été est en vigueur, 0 si l'heure d'été n'est pas en vigueur, et négative si l'information n'est pas disponible.

Le fichier d'en-tête <time.h> doit déclarer la structure timespec, qui doit inclure au moins les membres suivants :

time_t  tv_sec   Secondes.
long    tv_nsec  Nanosecondes.

Le fichier d'en-tête <time.h> doit également déclarer la structure itimerspec, qui doit inclure au moins les membres suivants :

struct timespec  it_interval  Période du timer.
struct timespec  it_value     Expiration du timer.

Le fichier d'en-tête <time.h> doit définir les macros suivantes :

NULL
Tel que décrit dans <stddef.h>.
CLOCKS_PER_SEC
Un nombre utilisé pour convertir la valeur renvoyée par la fonction clock() en secondes. La valeur doit être une expression de type clock_t. La valeur de CLOCKS_PER_SEC doit être de 1 million sur les systèmes conformes XSI. Cependant, elle peut être variable sur d'autres systèmes, et il ne faut pas supposer que CLOCKS_PER_SEC est une constante de compilation.

Le fichier d'en-tête <time.h> doit définir les constantes symboliques suivantes. Les valeurs doivent avoir un type compatible avec clockid_t pour l'affectation.

CLOCK_MONOTONIC

L'identifiant de l'horloge monotone à l'échelle du système, qui est définie comme une horloge mesurant le temps réel, dont la valeur ne peut pas être définie via clock_settime() et qui ne peut pas avoir de sauts d'horloge négatifs. Le saut d'horloge maximum possible est défini par l'implémentation.
CLOCK_PROCESS_CPUTIME_ID

L'identifiant de l'horloge CPU associée au processus effectuant un appel de fonction clock() ou timer*().
CLOCK_REALTIME
L'identifiant de l'horloge système mesurant le temps réel.
CLOCK_THREAD_CPUTIME_ID

L'identifiant de l'horloge CPU associée au thread effectuant un appel de fonction clock() ou timer*().

Le fichier d'en-tête <time.h> doit définir la constante symbolique suivante :

TIMER_ABSTIME
Indicateur indiquant que le temps est absolu. Pour les fonctions prenant des objets de timer, cela fait référence à l'horloge associée au timer.

Le fichier d'en-tête <time.h> doit fournir une déclaration ou une définition pour getdate_err. Le symbole getdate_err doit s'étendre à une expression de type int. Il n'est pas spécifié si getdate_err est une macro ou un identifiant déclaré avec une liaison externe, et si c'est une lvalue modifiable ou non. Si la définition d'une macro est supprimée afin d'accéder à un objet réel, ou si un programme définit un identifiant portant le nom getdate_err, le comportement est indéfini.

Les éléments suivants doivent être déclarés comme fonctions et peuvent également être définis comme macros. Les prototypes de fonctions doivent être fournis.

Le fichier d'en-tête <time.h> doit déclarer les variables suivantes :

extern int    daylight;
extern long   timezone;
extern char  *tzname[];

L'inclusion du fichier d'en-tête <time.h> peut rendre visibles tous les symboles du fichier d'en-tête <signal.h>.

Les sections suivantes sont informatives.

UTILISATION PAR L'APPLICATION

La plage [0,60] pour tm_sec permet les secondes intercalaires occasionnelles.

tm_year est une valeur signée ; par conséquent, les années avant 1900 peuvent être représentées.

Pour obtenir le nombre de ticks d'horloge par seconde renvoyé par la fonction times(), les applications doivent appeler sysconf(_SC_CLK_TCK).

RATIONNELLE

La plage de [0,60] secondes permet les secondes intercalaires positives ou négatives. La définition formelle de l'UTC ne permet pas les doubles secondes intercalaires, par conséquent toute mention de doubles secondes intercalaires a été supprimée, et la plage a été raccourcie par rapport aux [0,61] secondes vues dans les versions précédentes de cette norme.
