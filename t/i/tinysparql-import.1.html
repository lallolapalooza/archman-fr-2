TINYSPARQL-IMPORT(1) Manuel TinySPARQL TINYSPARQL-IMPORT(1)

NOM

tinysparql import - Importer des données dans une base de données TinySPARQL.

SYNTAXE

tinysparql import FICHIER.ttl

DESCRIPTION

tinysparql import importe des données dans une base de données TinySPARQL.

Les données doivent être conformes à l'ontologie existante de la base de données.

Les données doivent être au format Turtle. Vous pouvez utiliser un outil tel que rapper(1) pour convertir les données d'autres formats en Turtle.

VOIR AUSSI

tinysparql-export(1), tinysparql-sparql(1).
