timersub(3) Manuel des fonctions de bibliothèque timersub(3)

NOM

timeradd, timersub, timercmp, timerclear, timerisset - opérations sur timeval

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/time.h>
void timeradd(struct timeval *a, struct timeval *b,
              struct timeval *res);
void timersub(struct timeval *a, struct timeval *b,
              struct timeval *res);
void timerclear(struct timeval *tvp);
int timerisset(struct timeval *tvp);
int timercmp(struct timeval *a, struct timeval *b, CMP);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

Toutes les fonctions affichées ci-dessus :

    Depuis glibc 2.19 :
        _DEFAULT_SOURCE
    glibc 2.19 et versions antérieures :
        _BSD_SOURCE

DESCRIPTION

Les macros sont fournies pour opérer sur les structures timeval, définies dans <sys/time.h> comme suit :


struct timeval {
    time_t      tv_sec;     /* secondes */
    suseconds_t tv_usec;    /* microsecondes */
};

timeradd() ajoute les valeurs temporelles dans a et b, et place la somme dans le timeval pointé par res. Le résultat est normalisé de sorte que res->tv_usec ait une valeur comprise entre 0 et 999 999.

timersub() soustrait la valeur temporelle dans b de la valeur temporelle dans a, et place le résultat dans le timeval pointé par res. Le résultat est normalisé de sorte que res->tv_usec ait une valeur comprise entre 0 et 999 999.

timerclear() met à zéro la structure timeval pointée par tvp, de sorte qu'elle représente l'Époque : 1er janvier 1970 00:00:00 +0000 (UTC).

timerisset() renvoie vrai (non nul) si l'un des champs de la structure timeval pointée par tvp contient une valeur non nulle.

timercmp() compare les valeurs de temps dans a et b en utilisant l'opérateur de comparaison CMP, et renvoie vrai (non nul) ou faux (0) en fonction du résultat de la comparaison. Certains systèmes (mais pas Linux/glibc), ont une implémentation défectueuse de timercmp(), dans laquelle les opérateurs CMP >=, <= et == ne fonctionnent pas ; les applications portables peuvent à la place utiliser


!timercmp(..., <)
!timercmp(..., >)
!timercmp(..., !=)

VALEUR DE RETOUR

timerisset() et timercmp() renvoient vrai (non nul) ou faux (0).

ERREURS

Aucune erreur n'est définie.

NORMES

Aucune.

HISTORIQUE

BSD.

VOIR AUSSI
