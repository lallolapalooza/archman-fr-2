NOM

timew-export - exporter le temps suivi en JSON

SYNTAXE

timew export [ <id>... | ([<plage>] [<étiquette>...]) ]

DESCRIPTION

Exporte tout le temps suivi au format JSON.

Fournissez soit une liste d'identifiants d'intervalles, soit une plage et/ou un filtre d'étiquettes (voir timew-ranges(7) et timew-tags(1)) pour exporter seulement un sous-ensemble d'intervalles.

Les données sont exportées sous forme de tableau JSON d'objets d'intervalles, chacun contenant l'heure de début, l'heure de fin, l'identifiant actuel, les étiquettes et l'annotation de l'intervalle, si présents.

EXEMPLES

Exporter tous les intervalles

Appeler la commande export sans aucun argument exporte tous les intervalles suivis au format JSON :

$ timew export
[
{"id":2,"start":"20231001T103000Z","end":"20231001T120000Z","tags":["work"],"annotation":"Project work"},
{"id":1,"start":"20231001T090000Z","end":"20231001T100000Z","tags":["work"],"annotation":"Morning meeting"},
]

Dans cet exemple, seuls deux intervalles sont présents dans la base de données. La sortie est triée par heure de début, l'intervalle le plus ancien étant le premier.

Exporter les intervalles filtrés par plage et étiquette

$ timew export from 2016-01-01 for 3wks tag1
...

Exporter les intervalles par leurs identifiants

$ timew export @1 @3 @7
...
2025-08-16 timew 1.9.1
