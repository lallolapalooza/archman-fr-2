timerate(n)

Paquet: tcl

Licences: TCL

timerate(n) Commandes intégrées Tcl timerate(n)

NOM

timerate - Mesure de performance calibrée de l'exécution de scripts

SYNTAXE

timerate script ?temps? ?max-compteur?

timerate ?-direct? ?-surcharge double? script ?temps? ?max-compteur?

timerate ?-calibrer? ?-direct? script ?temps? ?max-compteur?

DESCRIPTION

La commande timerate effectue une mesure de performance calibrée d'une commande ou d'un script Tcl, script. Le script doit être écrit de manière à pouvoir être exécuté plusieurs fois pendant le processus de mesure de performance. Le temps est mesuré en temps écoulé en utilisant la résolution de timer la plus fine possible, pas le temps CPU ; si script interagit avec le système d'exploitation, le coût de cette interaction est inclus. Cette commande peut être utilisée pour fournir des informations sur la performance d'un script ou d'une commande Tcl, et peut aider à identifier les goulots d'étranglement et à affiner les performances de l'application.

La première et la deuxième forme évalueront script jusqu'à ce que l'intervalle temps donné en millisecondes soit écoulé, ou pendant 1000 millisecondes (1 seconde) si temps n'est pas spécifié.

Le paramètre max-compteur pourrait en outre imposer une restriction supplémentaire par le nombre maximal d'itérations pour évaluer le script. Si max-compteur est spécifié, l'évaluation s'arrêtera soit lorsque ce nombre d'itérations sera atteint, soit lorsque le temps sera dépassé.

Elle retournera alors une liste Tcl canonique de la forme :

0.095977 µs/# 52095836 # 10419167 #/sec 5000.000 net-ms

qui indique :

  • la quantité moyenne de temps requise par itération, en microsecondes ([lindex $résultat 0])
  • le nombre de fois où il a été exécuté ([lindex $résultat 2])
  • le taux estimé par seconde ([lindex $résultat 4])
  • le temps d'exécution réel estimé sans surcharge de mesure ([lindex $résultat 6])

Les options suivantes peuvent être fournies à la commande timerate :

-calibrer
Pour mesurer des scripts très rapides aussi précisément que possible, un processus de calibration peut être nécessaire. L'option -calibrer est utilisée pour calibrer timerate lui-même, calculant la surcharge estimée du script donné comme surcharge par défaut pour les invocations futures de la commande timerate. Si le paramètre temps n'est pas spécifié, la procédure de calibration s'exécute pendant 10 secondes maximum.

Notez que la calibration n'est pas thread-safe dans l'implémentation actuelle.

-surcharge double
Le paramètre -surcharge fournit une estimation (en microsecondes) de la surcharge de mesure de chaque itération du script testé. Cette quantité sera soustraite du temps mesuré avant de rapporter les résultats. Ceci peut être utile pour supprimer le coût des commandes de réinitialisation de l'état de l'interpréteur du script mesuré.
-direct
L'option -direct provoque l'exécution directe du script fourni, sans compilation, d'une manière similaire à la commande time. Elle peut être utilisée pour mesurer le coût de Tcl_EvalObjEx, de l'invocation de listes canoniques, et des versions non compilées des commandes bytecodées.

Contrairement à la commande time, qui exécute le script testé pour un nombre fixe d'itérations, la commande timerate l'exécute pendant un temps fixe. De plus, la variante compilée du script sera utilisée pendant toute la durée de la mesure, comme si le script faisait partie d'une procédure compilée, si l'option -direct n'est pas spécifiée. La période de temps fixe et la possibilité de compilation permettent des résultats plus précis et évitent des temps d'exécution très longs pour des scripts lents, ce qui la rend pratique pour mesurer des scripts dont les temps d'exécution sont très incertains.

EXEMPLES

Estimer la rapidité d'une simple boucle for Tcl (incluant les opérations sur la variable i) pour compter jusqu'à dix :

# calibrer
timerate -calibrer {}
# mesurer
timerate { for {set i 0} {$i<10} {incr i} {} } 5000

Estimer la rapidité d'une simple boucle for Tcl, en ignorant la surcharge de la gestion de la variable qui contrôle la boucle :

# calibrer pour la surcharge des opérations de variables
set i 0; timerate -calibrer {expr {$i<10}; incr i} 1000
# mesurer
timerate {
    for {set i 0} {$i<10} {incr i} {}
} 5000

Estimer la vitesse de calcul de l'heure de la journée en utilisant uniquement clock format, en ignorant la surcharge de la partie du script qui prépare le temps pour son calcul :

# calibrer
timerate -calibrer {}
# estimer la surcharge
set tm 0
set ovh [lindex [timerate {
    incr tm [expr {24*60*60}]
}] 0]
# mesurer en utilisant la surcharge estimée
set tm 0
timerate -surcharge $ovh {
    clock format $tm -format %H
    incr tm [expr {24*60*60}]; # la surcharge pour ceci est ignorée
} 5000
