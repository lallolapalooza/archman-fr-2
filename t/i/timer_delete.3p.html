TIMER_DELETE(3P) Manuel du programmeur POSIX TIMER_DELETE(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

timer_delete — supprimer un minuteur par processus

SYNTAXE

#include <time.h>
int timer_delete(timer_t timerid);

DESCRIPTION

La fonction timer_delete() supprime le minuteur spécifié, timerid, précédemment créé par la fonction timer_create(). Si le minuteur est armé lors de l'appel à timer_delete(), le comportement sera comme si le minuteur était automatiquement désarmé avant sa suppression. La disposition des signaux en attente pour le minuteur supprimé n'est pas spécifiée.

Le comportement est indéfini si la valeur spécifiée par l'argument timerid à timer_delete() ne correspond pas à un ID de minuteur retourné par timer_create() mais non encore supprimé par timer_delete().

VALEUR RENVOYÉE

En cas de succès, la fonction timer_delete() renvoie la valeur zéro. Sinon, la fonction renvoie la valeur -1 et définit errno pour indiquer l'erreur.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION PAR L'APPLICATION

Aucun.

RATIONNEL

Si une implémentation détecte que la valeur spécifiée par l'argument timerid à timer_delete() ne correspond pas à un ID de minuteur retourné par timer_create() mais non encore supprimé par timer_delete(), il est recommandé que la fonction échoue et signale une erreur [EINVAL].
