TIMEW-STOP(1) Manuels d'utilisation TIMEW-STOP(1)

NOM

timew-stop - arrêter le suivi du temps

SYNTAXE

timew stop [<date>] [<tag>...]

DESCRIPTION

Arrête le suivi du temps. Si des tags sont spécifiés, ils ne sont plus suivis. Si aucun tag n'est spécifié, tout le suivi s'arrête.

EXEMPLES

Par exemple :

$ timew start tag1 tag2
...
$ timew stop tag1

Initialement, le temps est suivi pour 'tag1' et 'tag2', puis le suivi de 'tag1' s'arrête, laissant 'tag2' actif. Pour arrêter tout suivi :

$ timew stop
