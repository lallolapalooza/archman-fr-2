TINYPROXY(8) Manuel Tinyproxy TINYPROXY(8)

NOM

tinyproxy - Un démon proxy HTTP léger

SYNTAXE

tinyproxy [-vdch]

DESCRIPTION

tinyproxy est un démon proxy HTTP léger conçu pour consommer un minimum de ressources système. Il écoute sur un port TCP donné et gère les requêtes proxy HTTP. Conçu dès le départ pour être rapide et pourtant petit, c'est une solution idéale pour des cas d'utilisation tels que les déploiements embarqués où un proxy HTTP complet est requis, mais où les ressources système pour un proxy plus grand sont indisponibles.

OPTIONS

tinyproxy accepte les options suivantes :

-c <fichier-config>
Utiliser un fichier de configuration alternatif.
-d
Ne pas démoniser et rester au premier plan. Utile à des fins de débogage.
-h
Afficher un bref écran d'aide des arguments de la ligne de commande et quitter.
-v
Afficher les informations de version et quitter.

SIGNAUX

En plus des options de ligne de commande, il existe également plusieurs signaux qui peuvent être envoyés à tinyproxy pendant son exécution pour générer des informations de débogage et forcer certains événements.

SIGHUP
Forcer Tinyproxy à effectuer un nettoyage de la liste chaînée des connexions actuelles. Ceci est généralement fait automatiquement après qu'un certain nombre de connexions ont été traitées. (Mode démon uniquement)
SIGUSR1
Forcer le rechargement du fichier de configuration et de la liste des filtres. Ceci est utile pour mettre à jour la configuration si Tinyproxy est exécuté en premier plan sans abandonner les connexions actives.

FICHIERS DE MODÈLE

Il y a deux occasions où Tinyproxy délivre lui-même des pages HTML au client :

  • Lorsqu'une erreur s'est produite, une page d'erreur correspondante est renvoyée.
  • Lorsqu'une requête pour le stathost est faite, une page résumant les statistiques de connexion est renvoyée. (Voir STATHOST ci-dessous.)

La disposition des pages d'erreur et de la page de statistiques peut être contrôlée via des fichiers modèles HTML configurables qui sont des fichiers HTML simples comprenant en outre quelques variables de modèle.

VARIABLES DE MODÈLE

Il existe plusieurs variables HTML standard disponibles dans chaque fichier modèle :

requête
La ligne de requête HTTP complète.
cause
La cause abrégée de la condition d'erreur.
clientip
L'adresse IP du client effectuant la requête.
clienthost
Le nom d'hôte du client effectuant la requête.
version
La version de Tinyproxy.
paquet
Le nom du paquet. Actuellement, se résout en 'tinyproxy'.
date
La date/heure actuelle au format HTTP.

De plus, presque tous les modèles prennent en charge :

détail
Une explication détaillée en langage naturel de l'erreur et des causes possibles.

Lorsque Tinyproxy trouve un nom de variable entre accolades, par exemple "{requête}", il est remplacé par la valeur de la variable correspondante avant la livraison de la page.

STATHOST

Tinyproxy renvoie une page HTML avec des statistiques de connexion lorsqu'il reçoit une requête HTTP pour un certain hôte - le stathost. Le nom du stathost est par défaut `tinyproxy.stats` et peut être modifié à la volée pour n'importe quel nom ou adresse IP avec la variable de configuration `StatHost`.

Le modèle de fichier de statistiques peut être modifié à la volée via la variable de configuration `StatFile`.

FICHIERS

`/etc/tinyproxy/tinyproxy.conf`, `/var/run/tinyproxy/tinyproxy.pid`, `/var/log/tinyproxy/tinyproxy.log`

BOGUES

Pour signaler des bogues dans Tinyproxy, veuillez visiter https://tinyproxy.github.io/.
