NOM

timew-fill - ajuste les intervalles pour remplir les vides environnants

SYNTAXE

timew fill <id>

DESCRIPTION

La commande 'fill' est utilisée pour ajuster tout intervalle afin de remplir les vides environnants.

Remplir le premier ou le dernier intervalle ne résultera qu'en un remplissage avant ou arrière respectivement, c'est-à-dire que la commande 'fill' ne créera pas d'intervalle ouvert.

Le même effet peut être obtenu avec la commande 'modify range' en combinaison avec l'indice ':fill'.

EXEMPLES

Par exemple, en supposant les intervalles suivants :

$ timew summary
Sem  Date       Jour ID Tags    Début      Fin      Temps   Total
---  ---------- --- ---- -------- -------- ------- -------
S32  2025-08-10 Dim @3 FOO   8:00:00  9:00:00 1:00:00
                   @2 BAR  10:00:00 11:00:00 1:00:00
                   @1 BAZ  12:00:00 13:00:00 1:00:00 3:00:00
                                                     -------
                                                     3:00:00

Ensuite, après avoir sélectionné '@2' comme intervalle que vous souhaitez remplir :

$ timew fill @2
Remplissage arrière de @2 à 2025-08-10T09:00:00
Remplissage de @2 à 2025-08-10T12:00:00

Cela étendra le début et la fin de l'intervalle sélectionné aux intervalles adjacents :

$ timew summary
Sem  Date       Jour ID Tags    Début      Fin      Temps   Total
---  ---------- --- ---- -------- -------- ------- -------
S32  2025-08-10 Dim @3 FOO   8:00:00  9:00:00 1:00:00
                   @2 BAR   9:00:00 12:00:00 3:00:00
                   @1 BAZ  12:00:00 13:00:00 1:00:00 5:00:00
                                                     -------
                                                     5:00:00
