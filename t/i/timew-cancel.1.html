NOM

timew-cancel - annuler le suivi du temps

SYNOPSIS

timew cancel

DESCRIPTION

S'il existe un intervalle ouvert, il est abandonné.

EXEMPLES

Annuler avec suivi du temps actif

$ timew start
...
$ timew cancel
Canceled active time tracking.

Ceci supprime l'intervalle ouvert.

Annuler sans suivi du temps actif

...
$ timew stop
$ timew cancel
There is no active time tracking.

L'annulation n'a aucun effet, seul un avertissement est affiché.

VOIR AUSSI

timew-continue(1), timew-start(1), timew-stop(1), timew-track(1)
