ISO_8859-11(7) Manuel d'informations diverses ISO_8859-11(7)

NOM

iso_8859-11 - Jeu de caractères ISO/IEC 8859-11 codé en octal, décimal et hexadécimal

DESCRIPTION

La norme ISO/IEC 8859 comprend plusieurs extensions 8 bits au jeu de caractères ASCII (également connu sous le nom d'ISO/IEC 646-IRV). ISO/IEC 8859-11 code les caractères utilisés dans la langue thaïlandaise.

Alphabet ISO/IEC 8859

L'ensemble complet des alphabets ISO/IEC 8859 comprend :

ISO/IEC 8859-1 Langues d'Europe occidentale (Latin-1)
ISO/IEC 8859-2 Langues d'Europe centrale et orientale (Latin-2)
ISO/IEC 8859-3 Langues d'Europe du Sud-Est et diverses (Latin-3)
ISO/IEC 8859-4 Langues scandinaves/baltes (Latin-4)
ISO/IEC 8859-5 Latin/Cyrillique
ISO/IEC 8859-6 Latin/Arabe
ISO/IEC 8859-7 Latin/Grec
ISO/IEC 8859-8 Latin/Hébreu
ISO/IEC 8859-9 Modification de Latin-1 pour le turc (Latin-5)
ISO/IEC 8859-10 Langues laponnes/nordiques/esquimaudes (Latin-6)
ISO/IEC 8859-11 Latin/Thaï
ISO/IEC 8859-13 Langues du pourtour baltique (Latin-7)
ISO/IEC 8859-14 Celtique (Latin-8)
ISO/IEC 8859-15 Langues d'Europe occidentale (Latin-9)
ISO/IEC 8859-16 Roumain (Latin-10)

NAME

tis-620 - TIS 620-2533 character set

DESCRIPTION

ISO/IEC 8859-11:2001 defines the repertoire of characters for the Thai language. It is identical to TIS (Thai Industrial Standard) 620-2533, commonly known as TIS-620.

The characters in the range 0xA0-0xFF are defined as follows:

NOTES

ISO/IEC 8859-11 is the same as TIS (Thai Industrial Standard) 620-2253, commonly known as TIS-620, except for the character in position A0: ISO/IEC 8859-11 defines this as NO-BREAK SPACE, while TIS-620 leaves it undefined.
