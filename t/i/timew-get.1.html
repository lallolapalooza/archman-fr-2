NOM

timew-get - afficher les valeurs DOM

SYNTAXE

timew get <DOM>...

DESCRIPTION

Valide la référence DOM, puis obtient la valeur et l'affiche.

En cas de référence invalide, un message d'erreur est affiché sur stderr et le code de sortie est 1.

Toutes les références DOM commencent par dom, il y a 4 sous-références auxquelles on peut accéder :

•dom.tracked, tous les intervalles
•dom.active, suivi actif du temps
•dom.tags, toutes les étiquettes
•dom.rc, paramètres de configuration

Voir timew-config(7) pour plus de détails à ce sujet. Il est erroné de référencer un intervalle ou une étiquette qui n'existe pas.

Si plus d'une référence DOM valide est donnée, les résultats sont concaténés par un espace.

EXEMPLES

Interroger le suivi du temps actuel

$ timew get dom.active 1

Cette requête renvoie 1 si le suivi du temps est actif, 0 sinon.

Afficher le 3ème intervalle d'une requête au format JSON

Pour la référence dom.tracked, des filtres par plage et par étiquettes peuvent être appliqués : 
$ timew get dom.tracked.3.json :month FOO
{"id":42,"start":"20250802T101224Z","end":"20250802T101224Z","tags":["FOO","BAR"]}

Notez que le 3 dans la référence désigne le 3ème intervalle dans le résultat de la requête, et non l'intervalle avec l'ID 3 !
