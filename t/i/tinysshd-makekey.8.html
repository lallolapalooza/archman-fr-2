NOM

tinysshd-makekey - créer un répertoire de clés TinySSH

SYNTAXE

tinysshd-makekey [ options ] repertoirecle

DESCRIPTION

tinysshd-makekey crée en toute sécurité des clés secrètes et les clés publiques correspondantes dans le répertoire repertoirecle.

OPTIONS

-q
pas de messages d'erreur
-Q
afficher les messages d'erreur (par défaut)
repertoirecle
répertoire pour les clés TinySSH, typiquement /etc/tinyssh/sshkeydir

EXEMPLE

tinysshd-makekey /etc/tinyssh/sshkeydir

VOIR AUSSI

tinysshd(8), tinysshd-printkey(8)
