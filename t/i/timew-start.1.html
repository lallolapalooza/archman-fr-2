NOM

timew-start - démarrer le suivi du temps

SYNTAXE

timew start [<date>] [<étiquette>...]

DESCRIPTION

Commence le suivi en utilisant l'heure actuelle avec l'ensemble des étiquettes spécifiées. Si une étiquette contient plusieurs mots, donc des espaces, utilisez des guillemets pour entourer l'étiquette entière.

ASTUCES

La commande start accepte les astuces suivantes :

:fill

L'astuce ':fill' peut être utilisée pour créer un nouvel intervalle qui commence juste après le dernier intervalle fermé. Ceci est utile quand vous voulez commencer à suivre le temps immédiatement après avoir terminé une tâche précédente, sans spécifier d'heure de début.

EXEMPLES

Par exemple, cette commande spécifie deux étiquettes ('weekend' et 'Home & Garden'), la seconde nécessitant des guillemets.

$ timew start weekend 'Home & Garden'

Une date optionnelle peut être spécifiée pour indiquer le début prévu du temps suivi :

$ timew start 8h weekend 'Home & Garden'

S'il y a un intervalle ouvert précédent, il sera fermé à l'heure de début donnée.

Les guillemets sont inoffensifs s'ils sont utilisés inutilement.

VOIR AUSSI
