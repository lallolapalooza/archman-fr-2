NOM

tipc-node - modifier et afficher les paramètres du nœud local ou lister les nœuds pairs

SYNOPSIS


tipc node set { address ADRESSE | netid NETID }

tipc node get { address | netid }

tipc node list

OPTIONS

Options (indicateurs) qui peuvent être passées n'importe où dans la chaîne de commandes.

-h, --help
Afficher l'aide sur la dernière commande valide. Par exemple tipc node --help affichera l'aide du nœud et tipc --help affichera l'aide générale. La position de l'option dans la chaîne est sans importance.

DESCRIPTION

Paramètres du nœud

address

L'adresse logique TIPC. Sous la forme x.y.z où x, y et z sont des entiers non signés.
netid

Identité réseau. Peut être utilisée pour créer des clusters TIPC individuels sur le même média.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi ou un entier positif en cas d'échec.
