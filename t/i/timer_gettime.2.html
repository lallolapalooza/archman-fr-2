timer_settime(2) Manuel des appels système timer_settime(2)

NOM

timer_settime, timer_gettime - Armer/désarmer et récupérer l'état d'un minuteur POSIX par processus

BIBLIOTHQUE

Bibliothèque temps réel (librt, -lrt)

SYNOPIS

#include <time.h>
int timer_gettime(timer_t timerid, struct itimerspec *curr_value);
int timer_settime(timer_t timerid, int flags,
                  const struct itimerspec *restrict new_value,
                  struct itimerspec *_Nullable restrict old_value);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

timer_settime(), timer_gettime() :

    _POSIX_C_SOURCE >= 199309L

DESCRIPTION

timer_settime() arme ou désarme le minuteur identifié par timerid. L'argument new_value est un pointeur vers une structure itimerspec qui spécifie la nouvelle valeur initiale et le nouvel intervalle du minuteur. La structure itimerspec est décrite dans itimerspec(3type).

Chacune des sous-structures de la structure itimerspec est une structure timespec(3) qui permet de spécifier une valeur de temps en secondes et en nanosecondes. Ces valeurs de temps sont mesurées selon l'horloge qui a été spécifiée lors de la création du minuteur par timer_create(2).

Si new_value->it_value spécifie une valeur non nulle (c'est-à-dire, si l'une ou l'autre sous-structure est non nulle), alors timer_settime() arme (démarre) le minuteur, le réglant pour qu'il expire initialement au moment spécifié. (Si le minuteur était déjà armé, les réglages précédents sont écrasés.) Si new_value->it_value spécifie une valeur nulle (c'est-à-dire, si les deux sous-structures sont nulles), alors le minuteur est désarmé.

Le champ new_value->it_interval spécifie la période du minuteur, en secondes et en nanosecondes. Si ce champ est non nul, alors à chaque fois qu'un minuteur armé expire, le minuteur est rechargé à partir de la valeur spécifiée dans new_value->it_interval. Si new_value->it_interval spécifie une valeur nulle, alors le minuteur n'expire qu'une seule fois, au moment spécifié par it_value.

Par défaut, le temps d'expiration initial spécifié dans new_value->it_value est interprété par rapport à l'heure actuelle sur l'horloge du minuteur au moment de l'appel. Ceci peut être modifié en spécifiant TIMER_ABSTIME dans flags, auquel cas new_value->it_value est interprété comme une valeur absolue mesurée sur l'horloge du minuteur ; c'est-à-dire, le minuteur expirera lorsque la valeur de l'horloge atteindra la valeur spécifiée par new_value->it_value. Si l'heure absolue spécifiée est déjà passée, alors le minuteur expire immédiatement, et le compteur de dépassements (voir timer_getoverrun(2)) sera correctement défini.

Si la valeur de l'horloge CLOCK_REALTIME est ajustée pendant qu'un minuteur absolu basé sur cette horloge est armé, alors l'expiration du minuteur sera correctement ajustée. Les ajustements de l'horloge CLOCK_REALTIME n'ont aucun effet sur les minuteurs relatifs basés sur cette horloge.

Si old_value n'est pas NULL, alors il pointe vers un tampon qui est utilisé pour retourner l'intervalle précédent du minuteur (dans old_value->it_interval) et le temps restant avant que le minuteur n'expire précédemment (dans old_value->it_value).

timer_gettime() retourne le temps jusqu'à la prochaine expiration, et l'intervalle, pour le minuteur spécifié par timerid, dans le tampon pointé par curr_value. Le temps restant jusqu'à la prochaine expiration du minuteur est retourné dans curr_value->it_value ; il s'agit toujours d'une valeur relative, quel que soit le drapeau TIMER_ABSTIME utilisé lors de l'armement du minuteur. Si la valeur retournée dans curr_value->it_value est nulle, alors le minuteur est actuellement désarmé. L'intervalle du minuteur est retourné dans curr_value->it_interval. Si la valeur retournée dans curr_value->it_interval est nulle, alors il s'agit d'un minuteur "one-shot".

VALEUR DE RETOUR

En cas de succès, timer_settime() et timer_gettime() retournent 0. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

Ces fonctions peuvent échouer avec les erreurs suivantes :

EFAULT
new_value, old_value ou curr_value n'est pas un pointeur valide.
EINVAL
timerid est invalide.

timer_settime() peut échouer avec les erreurs suivantes :

EINVAL
new_value.it_value est négative ; ou new_value.it_value.tv_nsec est négatif ou supérieur à 999 999 999.

NORMES

POSIX.1-2024.

HISTORIQUE

Linux 2.6. POSIX.1-2001.

EXEMPLES

Voir timer_create(2).

VOIR AUSSI

timer_create(2), timer_getoverrun(2), timespec(3), time(7)
