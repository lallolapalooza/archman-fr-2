NOM

timew-gaps - afficher les écarts de suivi temporel

SYNTAXE

timew gaps [<plage>] [<étiquette>...]

DESCRIPTION

Affiche un résumé du temps qui n'est ni suivi ni exclu du suivi.

Le paramètre de configuration 'reports.gaps.range' remplace la plage de dates par défaut. L'indicateur ':blank' fait en sorte que seul le temps exclu soit affiché, sans aucun temps suivi. La plage de dates par défaut affichée est ':day'.

INDICATEURS

Outre les indicateurs de plage (voir timew-hints(7)), le rapport d'écarts respecte les indicateurs suivants :

:blank

Afficher uniquement le temps exclu du suivi, sans afficher aucun temps suivi.

CONFIGURATION

reports.gaps.range

Pour les rapports qui affichent une plage de données, ce paramètre remplace la valeur par défaut. La valeur doit être un indicateur de plage, voir timew-hints(7).
