NOM

tipc-socket - afficher les informations sur les sockets (ports) TIPC

SYNTAXE


tipc socket list

OPTIONS

Options (flags) pouvant être passées n'importe où dans la chaîne de commandes.

-h, --help
Afficher l'aide sur la dernière commande valide. Par exemple, tipc socket --help affichera l'aide sur les sockets et tipc --help affichera l'aide générale. La position de l'option dans la chaîne est sans importance.

DESCRIPTION

Un socket TIPC est représenté par un entier non signé.

État lié

Un socket lié a un nom de port TIPC logique qui lui est associé.

État connecté

Un socket connecté est directement connecté à un autre socket, créant une connexion point à point entre les sockets TIPC. Si la connexion à X a été établie en utilisant un nom de port logique Y, ce nom apparaîtra comme connected to X via Y

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi, ou un entier positif en cas d'échec.
