NOM

timew-config - obtenir et définir la configuration de Timewarrior

SYNOPSIS

timew config [<nom> {<valeur>|''}]

DESCRIPTION

Permet de définir et de supprimer des valeurs de configuration, en alternative à l'édition directe de votre fichier timewarrior.cfg.

EXEMPLES

Par exemple :

$ timew config verbose yes
$ timew config verbose ''
$ timew config verbose

La première commande définit 'verbose' sur 'yes'. La seconde la définit sur une valeur vide, ce qui remplace la valeur par défaut. Le troisième exemple supprime le réglage 'verbose'.

Lors de la modification de la configuration de cette manière, une confirmation interactive sera demandée. Pour outrepasser cette confirmation, utilisez l'indice ':yes', qui signifie que vous avez l'intention de répondre 'yes' aux questions de confirmation :

$ timew config verbose '' :yes

Si aucun argument n'est fourni, tous les paramètres de configuration sont affichés :

$ timew config
verbose = yes
...

VOIR AUSSI

timew-hints(7), timew-show(1)
