NOM

tig - interface en mode texte pour Git

SYNTAXE

tig        [options] [révisions] [--] [chemins]
tig log    [options] [révisions] [--] [chemins]
tig show   [options] [révisions] [--] [chemins]
tig reflog [options] [révisions]
tig blame  [options] [rév] [--] chemin
tig grep   [options] [motif]
tig refs   [options]
tig stash  [options]
tig status
tig <      [sortie de commande Git]

DESCRIPTION

Tig est une interface en mode texte basée sur ncurses pour git(1). Il fonctionne principalement comme un navigateur de dépôts Git, mais peut également aider à la mise en scène des modifications pour le commit au niveau du bloc et agir comme un pager pour la sortie de diverses commandes Git.

OPTIONS

Les options de ligne de commande reconnues par Tig incluent toutes les options valides de git-log(1) et git-diff(1), ainsi que les sous-commandes suivantes et les options spécifiques à Tig. Le premier paramètre de ligne de commande ne commençant pas par "-" est interprété comme une spécification de révision ou un chemin et met fin à l'analyse des options. Toutes les options supplémentaires seront transmises à la commande Git sous-jacente.

Notez que cela signifie que tous les arguments des options doivent être spécifiés ensemble. Par exemple, exécutez tig -Sfoo au lieu de tig -S foo, et tig --grep=foo au lieu de tig --grep foo, sinon foo sera interprété comme une révision plutôt que comme un argument.

show

Ouvre la vue de différence en utilisant les options git-show(1) données.

blame

Affiche le fichier donné annoté par les commits. Prend zéro ou plusieurs options git-blame(1). Optionnellement limité à partir de la révision donnée.

status

Démarre dans la vue de statut.

log

Démarre dans la vue de journal, affichant la sortie de git-log(1).

reflog

Démarre dans la vue reflog.

refs

Démarre dans la vue refs. Toutes les refs sont affichées à moins d'être limitées en utilisant l'un des paramètres --branches, --remotes ou --tags.

stash

Démarre dans la vue stash.

grep

Ouvre la vue grep. Prend en charge les mêmes options que git-grep(1).

+<nombre>

Affiche la première vue avec la ligne <nombre> visible et sélectionnée.

-v, --version

Affiche la version et quitte.

-h, --help

Affiche le message d'aide et quitte.

-C <chemin>

S'exécute comme si Tig avait été démarré dans <chemin> au lieu du répertoire de travail actuel.

MODE PAGER

Tig entre en mode pager lorsque l'entrée est fournie via stdin et prend en charge les sous-commandes et options suivantes :

•Lorsque la sous-commande show est spécifiée et l'option --stdin est donnée, stdin est supposé être une liste d'IDs de commit et sera transmis à la commande git-show(1) sous-jacente de la vue diff. Par exemple :
$ git rev-list --author=vivien HEAD | tig show --stdin
•Lorsque --stdin est donné, stdin est supposé être une liste d'IDs de commit et sera transmis à la commande git-log(1) sous-jacente de la vue principale. Par exemple :
$ tig --no-walk --stdin < cherry-picks.txt
•Lorsque --pretty=raw est donné, stdin est supposé être une sortie formatée "pretty=raw" similaire à celle de git-log(1). Par exemple :
$ git reflog --pretty=raw | tig --pretty=raw

Lorsqu'aucune sous-commande ni option n'est donnée, la vue pager sera utilisée pour afficher l'entrée de commande Git donnée sur stdin. La vue pager suppose que l'entrée provient de git-log(1) ou git-diff(1) et la mettra en surbrillance de manière similaire aux vues log et diff. Par exemple :

$ git log -Schange -p --raw | tig

EXEMPLES

Afficher la liste des commits pour la branche actuelle :

$ tig

Afficher les commits d'une ou plusieurs branches :

$ tig test master

Faire comme si toutes les refs dans refs/ étaient listées sur la ligne de commande :

$ tig --all

Afficher les différences entre deux branches :

$ tig test..master

Afficher les changements pour les versions de sous-modules :

$ tig --submodule

Afficher les changements pour un seul fichier :

$ tig -- README

Afficher le contenu du fichier README dans une révision spécifique :

$ tig show tig-0.8:README

Afficher les révisions entre deux dates pour un fichier spécifique :

$ tig --after="2004-01-01" --before="2006-05-16" -- README

Blâmer un fichier avec la détection de copie activée :

$ tig blame -C README

Afficher la liste des stashes :

$ tig stash

Grepper tous les fichiers pour des lignes contenant DEFINE_ENUM :

$ tig grep -p DEFINE_ENUM

Afficher les références (branches, remotes et tags) :

$ tig refs

Utiliser le diff par mot dans la vue diff :

$ tig --word-diff=plain

VARIABLES ENVIRONNEMENT

En plus des variables d'environnement utilisées par Git (par exemple GIT_DIR), Tig définit celles ci-dessous. Les variables d'environnement liées aux commandes ont accès à l'état interne de Tig via des variables de remplacement, telles que %(commit) et %(blob). Voir tigrc(5) pour une liste complète.

TIGRC_USER

Chemin du fichier de configuration utilisateur (par défaut ~/.tigrc ou $XDG_CONFIG_HOME/tig/config).

TIGRC_SYSTEM

Chemin du fichier de configuration système (par défaut {sysconfdir}/tigrc). Définir sur une chaîne vide pour utiliser la configuration intégrée.

TIG_LS_REMOTE

Commande pour récupérer toutes les références du dépôt. La commande doit produire des données dans le même format que git-ls-remote(1).

TIG_DIFF_OPTS

Les options de diff à utiliser dans la vue diff. La vue diff utilise git-show(1) pour le formatage et passe toujours --patch-with-stat. Vous pouvez également définir le paramètre diff-options dans le fichier de configuration.

TIG_TRACE

Chemin pour le fichier de trace où les informations sur les commandes Git sont enregistrées.

TIG_SCRIPT

Chemin vers un script qui doit être exécuté automatiquement au démarrage. Si cette variable d'environnement est définie sur une chaîne vide, le script est lu depuis stdin. Le script est interprété ligne par ligne et peut contenir des commandes de prompt et des mappages de touches. Notez que le caractère < doit être encodé en <LT> dans le script. 
Par exemple : TIG_SCRIPT=<(echo :set main-view-commit-title-graph = no) tig

TIG_NO_DISPLAY

Ouvre Tig sans rien rendre sur le terminal. Cela force Ncurses à écrire vers /dev/null. L'utilisation principale est pour les tests automatisés de Tig.

TIG_EDITOR

La commande d'éditeur à utiliser lors de la visite des fichiers. Cette variable d'environnement remplace (par ordre de priorité) $GIT_EDITOR, la configuration core.editor, $VISUAL et $EDITOR, elle permet donc d'utiliser un éditeur différent de celui que Git utilise. La valeur est destinée à être interprétée par le shell lors de son utilisation.

FICHIERS

$XDG_CONFIG_HOME/tig/config, ~/.config/tig/config, ~/.tigrc

Le fichier de configuration utilisateur de Tig est chargé de la manière suivante. Si $XDG_CONFIG_HOME est défini, lire la configuration utilisateur depuis $XDG_CONFIG_HOME/tig/config. Si $XDG_CONFIG_HOME est vide ou non défini, lire la configuration utilisateur depuis ~/.config/tig/config s'il existe et se rabattre sur ~/.tigrc s'il n'existe pas. Voir tigrc(5) pour des exemples.

/etc/tigrc

Fichier de configuration système.

$GIT_DIR/config, ~/.gitconfig, /etc/gitconfig

NAME

tig - an ncurses based text-mode interface for Git

SYNOPSIS

tig [ -h | -v ] [ -C file ] [ -c file ] [ -T tags ] [ -t tag ] [ -p path ] [ -r ref ] [ -l line ] [ -S stage ] [ -- git(7) arguments ] [ repository ]

DESCRIPTION

Tig is a ncurses based text-mode interface that shows the last command in the current directory. You can navigate the history using the same keys that you use to navigate the man page.

Tig can be used for staging, committing, viewing the log, blame, etc. It can also be used for interactive rebasing, merging, and other Git operations.

Tig can be configured using a tigrc(5) file.

OPTIONS

The following options are available:

-h, --help
Show help message and exit.
-v, --version
Show version information and exit.
-C file, --git-config file
Use specified file as global git(7) configuration file.
-c file, --config file
Use specified file as Tig configuration file.
-T tags, --tags tags
Show specified tags.
-t tag, --tag tag
Show specified tag.
-p path, --path path
Show specified path.
-r ref, --ref ref
Show specified ref.
-l line, --line line
Show specified line.
-S stage, --stage stage
Show specified stage.

Any arguments not starting with - are interpreted as a git(7) repository.

PAGER MODE

When Tig is launched with the -p or -l options, it enters pager mode. In this mode, Tig will display the specified file or line and then exit.

EXAMPLES

tig

Show the log for the current repository.

tig -p path/to/file

Show the log for the specified file.

tig -r HEAD~2

Show the log for the last two commits.

tig -- git(7) log --graph

Show the log with a graph.

ENVIRONMENT VARIABLES

See tigrc(5) for environment variables that affect Tig.

FILES

/etc/tigrc, ~/.tigrc

The Tig configuration file.

$XDG_DATA_HOME/tig/history, ~/.local/share/tig/history, ~/.tig_history

When compiled with readline support, Tig writes a persistent command and search history. The location of the history file is determined in the following way. If $XDG_DATA_HOME is set and $XDG_DATA_HOME/ exists, create $XDG_DATA_HOME/tig/ if needed and store history to $XDG_DATA_HOME/tig/history. If $XDG_DATA_HOME is empty or undefined, store history to ~/.local/share/tig/history if the directory ~/.local/share/tig/ exists, and fall back to ~/.tig_history if it does not exist.
