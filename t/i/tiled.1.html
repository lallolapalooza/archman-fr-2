NOM

tiled - éditeur de cartes tuilées

SYNTAXE

tiled [OPTIONS] [FICHIERS...]

DESCRIPTION

Tiled est un éditeur de cartes tuilées polyvalent. Il est conçu pour être facile à utiliser, tout en étant suffisamment flexible pour fonctionner avec divers moteurs de jeu, que votre jeu soit un RPG, un jeu de plateforme ou un clone de Breakout. Tiled est un logiciel libre écrit en C++, utilisant le framework d'application Qt.

OPTIONS

-h --help
Affiche l'aide
-v --version
Affiche la version
--quit
Vérifie uniquement la validité des arguments
--disable-opengl
Désactive le rendu accéléré par matériel
--export-map [format] fichier tmx fichier cible
Exporte le fichier tmx spécifié vers la cible
--export-formats
Affiche une liste des formats d'exportation pris en charge
