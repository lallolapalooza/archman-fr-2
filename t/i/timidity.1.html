timidity(1) Manuel des commandes générales timidity(1)

NOM

TiMidity++ - Convertisseur et lecteur MIDI vers WAVE

SYNOPSIS

timidity [options] nom_de_fichier [...]

DESCRIPTION

TiMidity++ est un convertisseur qui transforme divers fichiers MIDI (formats supportés : fichiers MIDI standards (*.mid), fichiers Recomposer (*.rcp, *.r36, *.g18, *.g36) et fichiers Module (*.mod)) en fichiers audio formatés (par ex. RIFF WAVE). TiMidity++ utilise des fichiers patch compatibles Gravis Ultrasound ou des Soundfonts (*.sfx, *.sf2) pour générer des données audio numériques à partir des fichiers MIDI. Les données audio numériques générées par TiMidity++ peuvent être stockées dans un fichier pour traitement, ou être jouées en temps réel via un périphérique audio.
Lors de la lecture en temps réel, TiMidity++ peut afficher les paroles contenues dans les fichiers KAR ou WRD.

NOM DE FICHIER

Vous pouvez utiliser les expressions suivantes comme argument nom_de_fichier :

-
Lire un fichier MIDI depuis l'entrée standard.
chemin/nom_de_fichier
Lire un fichier MIDI depuis le chemin spécifié sur un système de fichiers.
rep:répertoire

répertoire/
Lire et jouer tous les fichiers MIDI dans le répertoire spécifié. Par exemple,

% timidity quelque/part/

joue tous les fichiers dans le répertoire quelque/part/.

Fichier Archive
Extraire et jouer le(s) fichier(s) dans l'archive. Si vous souhaitez spécifier un fichier MIDI particulier dans l'archive, ajoutez #<nom_de_fichier_MIDI> au nom de l'archive. Le chemin après `#' permet l'utilisation d'expressions génériques (insensible à la casse).
Vous pouvez utiliser la séquence d'échappement \xHH, où `HH' est un nombre ASCII en entier hexadécimal.

Par exemple :

% timidity fichier.zip#fichier.mid
Joue fichier.mid dans fichier.zip
% timidity fichier.lzh#*.mid
Joue tous les fichiers correspondant à l'expression générique *.mid dans fichier.lzh
% timidity fichier.tgz#*
Cette expression est identique à fichier.tgz

Comme ces mécanismes sont intégrés à TiMidity++, vous pouvez utiliser cette syntaxe même dans l'environnement MS Windows.

TiMidity++ peut gérer les formats d'archive suivants :

tar (*.tar)
tar+gzip (*.tar.gz, *.tgz)
zip (*.zip)
lzh (*.lzh, *.lha)
(lh0, lh1, lh2, lh3, lh4, lh5, lh6, lz4, lzs et lz5 sont disponibles)

D'autres archives peuvent être décompressées si une commande d'extraction est spécifiée lors de la compilation. TiMidity++ utilisera un pipe avec cette commande.

news://serveur-news[:port]/ID-Message

news://serveur-news[:port]/groupe-de-discussion[/premier-dernier]
Lire le fichier MIDI dans l'article spécifié sur le serveur de news. Si un groupe de discussion est spécifié, TiMidity++ lit tous les fichiers MIDI trouvés dans n'importe quel article posté dans ce groupe de discussion.
TiMidity++ analyse les messages Multi-parts MIME dans le cas du schéma news://*, extrait le fichier MIDI qui a été posté dans ce groupe, ou dans le cas d'un fichier normal, vous pouvez explicitement gérer les documents MIME en nommant ce fichier avec l'extension *.mime, ou en préférant ce fichier par mime:

Les types MIME suivants sont autorisés :

fichier encodé uu
begin
est requis
encodé base64
Content-Transfer-Encoding: base64
est requis
quoted-string
Content-Transfer-Encoding: quoted-string
est requis
format Mac BinHex
seul le format HQX est disponible
http://adresse

ftp://adresse
Lire le fichier spécifié dans l'URL.

Par exemple :

% timidity http://www.goice.co.jp/member/mo/dist/midi/impromptu.mid
joue le fichier MIDI spécifié directement depuis le réseau.

Si ces expressions sont utilisées dans les fichiers *.cfg, vous pouvez même utiliser des fichiers patch (et autres) depuis des machines distantes.

FICHIER D'ENTRÉE

TiMidity++ peut gérer les formats de fichiers suivants :

.mid, .rmi (Format 0, 1, 2)
Fichier MIDI Standard
.rcp, .r36, .g18, .g36 (formats Recomposer)
Format Recomposer produit par COME ON MUSIC co.
.mfi (MFi Version 3 - Format Mélodie pour i-Mode)
i-Mode est un téléphone mobile local japonais
.kar (Format Karaoke)
Affiche les paroles sous forme de message d'événement Meta de paroles.
.mod, mod.* (Fichier Module)
.wrd (Format WRD)

OPTIONS

Les options de ligne de commande suivantes sont acceptées par TiMidity++ :

-A [n][,m](a)

--amplification=n

--drumpower=m

--[no-]volume-compensation
Multiplie le volume maître par n%. La valeur par défaut est 70%. Une amplification plus élevée produit des sons plus forts. Vous pouvez spécifier la puissance des tambours, le ratio du volume des tambours par rapport aux autres canaux. Les valeurs autorisées pour l'amplification vont de 0 (aucun son) à 800.
Optionnellement, ajouter le caractère `a' avec l'option -a, ou utiliser --volume-compensation, demande à TiMidity++ de régulariser le volume. Vous pouvez facilement obtenir une plage dynamique.

Par exemple :

-A90
volume 90%, puissance des tambours 100%, compensation désactivée
-A,120
volume 70%, puissance des tambours 120%, compensation désactivée
-A90,120
volume 90%, puissance des tambours 120%, compensation désactivée
-Aa
volume 70%, puissance des tambours 100%, compensation activée
-A90a
volume 90%, puissance des tambours 100%, compensation activée
-A,120a
volume 70%, puissance des tambours 120%, compensation activée
-A90,120a
volume 90%, puissance des tambours 120%, compensation activée
-a, --[no-]anti-alias
Active l'anti-aliasing. Les échantillons sont traités par un filtre passe-bas avant la lecture, ce qui réduit le bruit d'aliasing aux basses fréquences d'échantillonnage.
-B n,m, --buffer-fragments=n,m
Pour le pilote audio Linux/FreeBSD/OSS/ALSA/Windows, sélectionne le nombre de fragments de tampon en mode interactif. Augmenter le nombre de fragments peut réduire les saccades lorsque de nombreux processus sont en cours d'exécution. Cela donnera l'impression que TiMidity++ répond lentement aux commandes d'avance rapide, de retour arrière et de volume, et cela désynchronisera l'affichage de l'état. Spécifiez un nombre de fragments de 0 pour utiliser le nombre maximal de fragments disponibles.
-C n, --control-ratio=n
Définit le rapport entre les fréquences d'échantillonnage et de contrôle. Cela détermine la fréquence de recalcul des enveloppes -- des rapports plus petits donnent une meilleure qualité mais consomment plus de temps CPU.
-c fichier, --config-file=fichier
Lit un fichier de configuration supplémentaire.
-D n, --drum-channel=n
Marque le canal comme canal de batterie. Si le canal est négatif, le canal -n est marqué comme canal instrumental. Si n est 0, tous les canaux sont marqués comme instrumentaux.
-d dir, --interface-path=dir
Spécifie le répertoire contenant les modules d'interface à liaison dynamique installés.
-E mode, --ext=mode
Définit les modes d'extension de TiMidity++. Les modes suivants sont disponibles (la casse majuscule de l'option signifie désactiver cette fonctionnalité) :
w/W, --[no-]mod-wheel
Active/désactive le contrôle de la molette de modulation.
p/P, --[no-]portamento
Active/désactive le contrôle du portamento.
v/V, --[no-]vibrato
Active/désactive la vibration NRPM.
s/S, --[no-]ch-pressure
Active/désactive le contrôle de la pression du canal.
e/E, --[no-]mod-envelope
Active/désactive le contrôle de l'enveloppe de modulation.
t/T, --[no-]trace-text-meta
Active/désactive le traçage de tous les événements Meta Texte.
o/O, --[no-]overlap-voice
Accepte/rejette la prononciation de notes identiques multiples.
z/Z, --[no-]temper-control
Active/désactive le contrôle du tempérament MIDI Tuning Standard.
mHH, --default-mid=HH
Définit l'ID du fabricant à HH (où HH sont deux chiffres hexadécimaux).
Les valeurs HH de GS/gs, XG/xg ou GM/gm sont comprises comme 41, 43 et 7e respectivement.
MHH, --system-mid=HH
Définit l'ID du fabricant du système à HH (où HH sont deux chiffres hexadécimaux).
Dans cette option, l'ID du fabricant est défini de manière immuable. L'ID du fabricant du fichier d'entrée sera ignoré.
bn, --default-bank=n
Utilise la banque de sons n par défaut.
Bn, --force-bank=n
Définit le numéro de banque de tous les canaux à n.
in[/m], --default-program=n[/m]
Utilise le numéro de programme comme instrument par défaut. Tout événement de changement de programme dans les fichiers MIDI remplacera cette option.
Si n est suivi de /m, le numéro de programme par défaut du canal m est spécifié par n.
In[/m], --force-program=n[/m]
Similaire à -Ei mais ignore tous les changements de programme.
F args
Pour les effets. Voir ci-dessous. Dans l'option args, vous pouvez spécifier les options d'effet suivantes :
delay=(d|l|r|b)[,msec], --delay=(d|l|r|b)[,msec]
Définit le type de délai.
d, 0
Effet de délai désactivé.
l, 1
Délai gauche.
r, 2
Délai droit.
b, 3
Inverse gauche et droite.

msec optionnel est le temps de délai.

chorus=(d|n|s)[,level], --chorus=(d|n|s)[,level]
d, 0
Désactive cet effet.
n, 1
Active le contrôle de l'effet chorus MIDI.
s, 2
Son surround, chorus désaccordé à un degré moindre (par défaut).

Le paramètre optionnel level spécifie le niveau du chorus de 0 à 127.

reverb=(d|n|g)[,level], --reverb=(d|n|g)[,level]
reverb=(f|G)[,level,scaleroom,offsetroom,predelay]
--reverb=(f|G)[,level,scaleroom,offsetroom,predelay]
d, 0
Désactive le contrôle de l'effet reverb MIDI.
n, 1
Active le contrôle de l'effet reverb MIDI. Cet effet n'est disponible qu'en stéréo.
g, 2
Effet de reverb global.
f, 3
Contrôle de l'effet reverb MIDI Freeverb (par défaut).
G, 4
Effet Freeverb global.

Le paramètre optionnel level spécifie le niveau de reverb de 0 à 127.
Pour l'effet Freeverb, des paramètres supplémentaires scaleroom, offsetroom et predelay peuvent être spécifiés. scaleroom et offsetroom spécifient des variables pour la taille de la pièce calculée comme
roomsize = C * scaleroom + offsetroom
où C est le caractère de la réverbération. predelay spécifie le facteur du temps de pré-délai de la réverbération en pourcentage. N'importe lequel des paramètres optionnels peut être omis. Les valeurs par défaut sont 0.28, 0.7 et 100 respectivement.

vlpf=(d|c|m), --voice-lpf=(d|c|m)
d, 0
Désactive l'effet LPF.
c, 1
Filtre passe-bas résonant de Chamberlin (12dB/oct) (par défaut).
m, 2
Filtre passe-bas résonant Moog (24dB/oct)
ns=n, --noise-shaping=n
Active le filtre de mise en forme du bruit de degré n. La distorsion au stade de la décroissance est améliorée, mais le bruit ressenti par l'audition humaine augmente car il est déplacé vers des fréquences élevées. Dans le cas d'un encodage linéaire 8 bits, les valeurs valides de n sont comprises dans l'intervalle de 0 (min) à 4 (max). La valeur par défaut est 4. Dans le cas d'un encodage linéaire 16 bits, les valeurs valides de n sont comprises dans l'intervalle de 0 à 4. Selon la valeur, cela fonctionne comme suit. La valeur par défaut est 4.
0
Aucune mise en forme du bruit.
1
Mise en forme du bruit traditionnelle.
2
Soft-clipping de type overdrive + nouvelle mise en forme du bruit.
3
Soft-clipping de type amplificateur à lampe + nouvelle mise en forme du bruit.
4
Nouvelle mise en forme du bruit.
resamp=(d|l|c|L|n|g), --resample=(d|l|c|L|n|g)
d, 0
Pas d'interpolation.
l, 1
Interpolation linéaire.
c, 2
Interpolation par spline cubique.
L, 3
Méthode de Lagrange.
n, 4
Interpolation par polynôme de Newton.
g, 5
Effet Gauss modifié (par défaut).

Cette option affecte le comportement de l'option -N.

-e, --evil
Rend TiMidity++ "evil". Pour la version Win32, cela augmente la priorité de la tâche d'un cran. Cela peut améliorer la lecture lors du changement de tâches, au détriment du ralentissement de toutes les autres tâches.
-F, --[no-]fast-panning
Active le panoramique rapide pour gérer les morceaux MIDI qui attendent des ajustements de panoramique pour affecter les notes déjà jouées. Certains fichiers qui ne s'attendent pas à cela ont tendance à faire basculer la balance rapidement entre la gauche et la droite, ce qui peut provoquer des craquements sévères lorsque le drapeau -F est utilisé.
Dans la version actuelle de TiMidity++, cette option est une bascule.
-f, --[no-]fast-decay
Active/désactive les enveloppes rapides. Cette option rend TiMidity++ plus rapide mais le temps de relâchement des notes est raccourci.
-G debut1-fin1[,debut2-fin2,...](m)

--segment=debut1-fin1[,debut2-fin2,...](m)
Joue uniquement les sous-segments spécifiés par des segments de temps séparés par des virgules.
Chaque segment de temps est défini par des valeurs de temps séparées par un tiret : debut-fin - par défaut 0-infini. Joue de debut à fin.

Format de temps : [<minutes>:]<secondes>[.<millisecondes>]

Ajouter le caractère `m' avec l'option la traite comme une mesure et un temps au lieu de secondes.

Format de temps : <mesure>[.<temps>] (mesure et temps sont à base 1)

Par exemple :

-G12-1:00.500
Saute 12 secondes et s'arrête à 1 minute et une demi-seconde.
-G-5,2:00-
Joue les 5 premières secondes, puis saute à 2 minutes du début et joue jusqu'à la fin.
-G11.4-20m -G4:00-
Joue depuis le 4ème temps de la 11ème mesure jusqu'à la 20ème mesure, puis saute à 4 minutes du début et joue jusqu'à la fin.
-g sec, --spectrogram=sec
Ouvre la fenêtre du spectrogramme sonore. Cette option est activée si le système prend en charge le système X Window.
-H n, --force-keysig=n
Spécifie le nombre de dièses de la tonalité. Le fichier MIDI est interprété avec transposition à la tonalité du nombre de dièses (lorsque n est positif) ou de bémols (lorsque n est négatif). Les valeurs valides de n sont dans l'intervalle de -7 à 7. Par exemple, si n est 1, un fichier MIDI de n'importe quelle tonalité sera interprété en transposant à 1 bémol (c'est-à-dire Fa majeur ou ré mineur). Il est donc pratique de l'utiliser pour l'accompagnement lors de la pratique d'un instrument de musique dans une tonalité facile à interpréter.
-h, --help
Affiche le message d'aide.
-i mode, --interface=mode

--realtime-priority=n

--sequencer-ports=n
Sélectionne les interfaces utilisateur parmi les alternatives compilées. mode doit commencer par l'un des identifiants d'interface pris en charge. Exécutez TiMidity++ avec l'option -h pour voir la liste.
Pour l'interface séquenceur ALSA, éventuellement pour utiliser --realtime-priority, définissez la priorité temps réel par n, et pour utiliser --sequencer-ports, définissez le nombre de ports séquenceurs ouverts. La valeur par défaut est 4.
Les identifiants suivants peuvent être disponibles :
-id
interface dumb
-in
interface ncurses
-is
interface S-Lang
-ia
interface X Athena Widget
-ik
interface Tcl/Tk
-im
interface Motif
-iT
interface vt100
-ie
interface Emacs
(utilisez ``M-x timidity'' dans Emacs)
-ii
interface skin
La variable d'environnement TIMIDITY_SKIN doit être définie sur le chemin des données du skin (les données compressées sont également prises en charge).
-ig
interface GTK+
-ir
Lance TiMidity++ en tant que serveur MIDI.
-iA
Lance TiMidity++ en tant que client séquenceur ALSA.
-iW
interface synthétiseur Windows
-iw
interface graphique Windows
-iP
interface synthétiseur PortMIDI
-ip
interface UMP
Options d'interface
Des caractères d'option peuvent être ajoutés immédiatement après l'identifiant d'interface. Les options suivantes sont reconnues :
v, --verbose=n
Augmente le niveau de verbosité. Cette option est cumulative.
q, --quiet=n
Diminue le niveau de verbosité. Cette option est cumulative.
t, --[no-]trace
Active/désactive le mode trace. En mode trace, TiMidity++ tente d'afficher son état actuel en temps réel. Pour le pilote son Linux, cela est accompli par l'utilisation de petits fragments de tampon DMA, qui peuvent être ajustés via l'option -B.
l, --[no-]loop
Joue en boucle (certaines interfaces ignorent cette option)
r, --[no-]random
Mélange la liste des fichiers arguments avant de jouer
s, --[no-]sort
Trie la liste des fichiers arguments avant de jouer
D, --[no-]background
Démonise TiMidity++ en arrière-plan (pour alsaseq uniquement)
-j, --[no-]realtime-load
Active le chargement des fichiers de patch pendant la lecture.
-K n, --adjust-key=n
Ajuste la tonalité (c'est-à-dire transpose la chanson) de n demi-tons. Plage de -24 à 24.
-k msec, --voice-queue=msec
Spécifie la limite de temps de la file d'attente audio pour réduire les voix. Si le tampon audio restant est inférieur à msec millisecondes, TiMidity++ essaie de supprimer certaines voix. Cette fonctionnalité permet de jouer des fichiers MIDI compliqués sur des CPU lents. Définir msec à zéro indique à TiMidity++ de ne jamais supprimer de voix.
-L chemin, --patch-path=chemin
Ajoute chemin au chemin de la bibliothèque. Les fichiers de patch, de configuration et MIDI sont recherchés le long de ce chemin. Les répertoires ajoutés en dernier seront recherchés en premier. Notez que le répertoire actuel est toujours recherché en premier avant le chemin de la bibliothèque.
-M nom, --pcm-file=nom
TiMidity++ peut lire un fichier PCM au lieu d'un fichier MIDI. Si ``auto'' est spécifié, TiMidity++ essaie d'ouvrir foo.mid.wav ou foo.mid.aiff lors de la lecture de foo.mid. Si ``none'' est spécifié, cette fonctionnalité est désactivée. Sinon, lit simplement nom.
-m msec, --decay-time=msec
Modifie le temps de déclin du volume de l'enveloppe. msec est le nombre minimum de millisecondes pour maintenir une note tenue.
-m0
Désactive le rampe de sustain, provoque des sustains à volume constant (par défaut).
-m1
Se comporte effectivement comme si tous les sustains étaient ignorés, la rampe de volume est la même que le stade normal 3.
-m3000
Une note à plein volume déclinera pendant 3 secondes une fois qu'elle commence à être tenue (en supposant que le taux normal du stade 3 ne provoquerait pas un déclin encore plus long). Les notes plus douces s'éteindront bien sûr plus tôt.
-N n, --interpolation=n
Définit le paramètre d'interpolation. Cette option dépend de la valeur de l'option -EFresamp.
cspline, lagrange
Active/désactive l'interpolation linéaire à 4 points (par défaut, elle est activée).
newton
Interpolation à n points utilisant des polynômes de Newton. n doit être un nombre impair compris entre 1 et 57.
gauss
Interpolation Gauss modifiée à n+1 points. Plage de 0 (désactivé) à 34 (max), par défaut 25.

Dans tous les cas, une interpolation linéaire est utilisée si la file d'attente audio est < 99 %.

-O mode, --output-mode=mode

--flac-verify

--flac-padding=n

--flac-complevel=n

--oggflac

--speex-quality=n

--speex-vbr

--speex-abr=n

--speex-vad

--speex-dtx

--speex-complexity=n

--speex-nframes=n
Sélectionne le mode de sortie parmi les alternatives compilées. mode doit commencer par l'un des identifiants de mode de sortie pris en charge. Exécutez TiMidity++ avec l'option -h pour voir la liste.
Spécialement en mode de sortie Ogg FLAC, la vérification des données générées (sera un peu plus lente), la taille du padding d'en-tête (par défaut 4096), le niveau de compression (0 à 8) (par défaut 5), et l'activation du flux OggFLAC peuvent être spécifiés par les options --flac-verify, --flac-padding, --flac-complevel et --oggflac respectivement.
Spécialement en mode de sortie Ogg Speex, la qualité de compression (0 à 10) (par défaut 8), l'activation de la sortie VBR, l'activation de la sortie ABR et la définition du ratio à n, l'activation de la VAD (détection d'activité vocale), l'activation de la DTX (transmission discontinue), la complexité d'encodage (0 à 10) (par défaut 3), et le nombre d'images par paquet Ogg (0 à 10) (par défaut 1) peuvent être spécifiés par les options --speex-quality, --speex-vbr, --speex-abr, --speex-vad, --speex-dtx, --speex-complexity et --speex-nframes respectivement.

Options de format
Les caractères d'option peuvent être ajoutés immédiatement après l'identifiant du mode pour modifier le format de sortie. Les options suivantes sont reconnues :
S, --output-stereo
Stéréo
M, --output-mono
Monophonique

Sortie signée
u, --output-unsigned
Sortie non signée

Profondeur d'échantillon 16 bits
2, --output-24bit
Profondeur d'échantillon 24 bits
8, --output-8bit
Profondeur d'échantillon 8 bits

Encodage linéaire

Notez que certaines options n'ont aucun effet sur certains modes. Par exemple, vous ne pouvez pas générer un fichier RIFF WAVE avec octets échangés, ni forcer une sortie uLaw sur un périphérique PCM Linux.

-o fichier, --output-file=fichier
Placer la sortie dans fichier, qui peut être un fichier, un périphérique ou le serveur audio HP-UX, en fonction du mode de sortie sélectionné avec l'option -O. Le nom de fichier spécial `-' provoque le placement de la sortie sur stdout.
-P fichier, --patch-file=fichier
Utiliser le fichier de patch pour tous les programmes.
-p [n](a)

--polyphony=n

--[no-]polyphony-reduction
Définit la polyphonie (nombre maximum de voix simultanées) à n.
Optionnellement, placer le caractère `a' avec l'option -p, ou utiliser --polyphony-reduction, instruit TiMidity++ à activer l'algorithme de réduction automatique de polyphonie.
-Q n[,...](t)

--mute=n[,...]

--temper-mute=n[,...]
Mettre le canal n en sourdine. n peut être spécifié par paquet via `,'. Si n est 0, tous les canaux sont désactivés. Inversement, spécifier -n réactive le canal n.
D'autre part, placer le caractère `t' après l'option -Q ou utiliser --temper-mute décrit la mise en sourdine de tempérament. Ceci met en sourdine les canaux d'un type de tempérament spécifique n. Pour les tempéraments prédéfinis, n peut varier de 0 à 3. Pour les tempéraments définis par l'utilisateur, n peut varier de 4 à 7.
-q sec/n, --audio-buffer=sec/n
Spécifie le tampon audio en secondes. sec est la taille maximale du tampon, n est le pourcentage rempli au début (par défaut 5.0/100) (une taille de 100% équivaut à la taille totale du tampon du périphérique).
-R msec
Active le mode pseudo-réverbération. Il définit la durée de relâchement de chaque instrument à msec ms. Si msec est 0, msec est défini à 800 (par défaut).
-S n, --cache-size=n
Définit la taille du cache de ré-échantillonnage à n octets. Si n est égal à 0, tous les caches d'échantillons sont désactivés. La valeur par défaut de n est 2097152 (2 Mo).
-s freq, --sampling-freq=freq
Définit la fréquence de ré-échantillonnage (Hz ou kHz). Tous les périphériques audio ne sont pas capables de toutes les fréquences - une fréquence approximative peut être sélectionnée, en fonction de l'implémentation.
-T n, --adjust-tempo=n
Ajuste le tempo à n % ; 120 joue les fichiers MOD avec la synchronisation d'un Amiga NTSC.
-t code, --output-charset=code
Définit le codage de sortie du texte japonais. Les valeurs possibles de code sont :
auto
déterminé par la variable d'environnement LANG.
ascii
Traduit le code non ASCII en période.
nocnv
Aucune conversion.
1251
Convertit de windows-1251 vers koi8-r.
euc
Sortie en codage EUC (Japon).
jis
Sortie en codage JIS.
sjis
Sortie en codage SJIS.
-U, --[no-]unload-instruments
Décharge tous les instruments de la mémoire entre les fichiers MIDI. Cela peut réduire les besoins en mémoire lors de la lecture de nombreux fichiers consécutivement.
-V power, --volume-curve=power
Définit la puissance de la courbe de volume. L'amplification totale devient volume^power. 0 (par défaut) utilise les tables régulières. Toute valeur non nulle provoque l'utilisation de toutes les pistes MIDI de la nouvelle courbe vitesse/volume/expression définie par l'utilisateur (linéaire : 1, idéale : ~1.661, GS : ~2).
-v, --version
Affiche la chaîne de version
-W mode, --wrd=mode
Joue le fichier WRD.

Les valeurs autorisées de mode sont :

x
Mode X Window System
w
Mode console Windows
t
Mode TTY
d
Mode Dumb (sortie directe des événements WRD)
-
ne pas tracer WRD
R[opts]
Définit les options WRD :
a1=b1,a2=b2,...
Définit les options WRD. an est le nom de l'option et bn est la valeur.
d=n
Émule les bugs de synchronisation (@WAIT, @WMODE) du lecteur MIMPI original. Les niveaux d'émulation sont :
-WRd=0
ne pas émuler de bugs MIMPI
-WRd=1
émuler uniquement certains bugs (par défaut)
-WRd=2
émuler tous les bugs connus
F=fichier
Utiliser fichier comme fichier WRD uniquement si aucun fichier correspondant à *.wrd n'est trouvé.
f=fichier
Utilise fichier comme fichier WRD.

Le mode WRD doit également utiliser le mode de traçage (option -i?t) ou la synchronisation des événements WRD sera médiocre.

-w mode, --rcpcv-dll=mode
Mode étendu pour MS Windows. Les options suivantes sont disponibles :
-w r
Utiliser rcpcv.dll pour jouer les fichiers RCP/R36.
-w R
Ne pas utiliser rcpcv.dll (par défaut).
-x str, --config-string=str
Configure TiMidity++ avec str. Le format de str est le même que celui de timidity.cfg.

Par exemple :
-x'bank 0\n0 violin.pat'
Définit l'instrument numéro 0 sur violon.
Le caractère `\' (Ascii 0x5c) dans str est traité comme un caractère d'échappement comme dans les littéraux C.

Par exemple, \n est traité comme un retour chariot.

-Z fichier, --freq-table=fichier
Force la lecture de la table des fréquences à partir de fichier. Ceci est utile pour définir une syntonisation différente du tempérament égal à 12 demi-tons. Si « pure » est spécifié, TiMidity++ joue en intonation pure d'essai.
-Zpure[n(m)], --pure-intonation=[n(m)]
Joue en intonation pure d'essai via l'événement méta de signature de clé dans le fichier MIDI. Vous pouvez spécifier la signature de clé initiale manuellement, au cas où le fichier MIDI ne contiendrait pas l'événement méta. Optionnellement, n est le numéro de la signature de clé. En cas de dièse, n est positif. En cas de bémol, n est négatif. Les valeurs valides de n sont dans l'intervalle de -7 à 7. En cas de mode mineur, vous devriez ajouter le caractère `m' avec l'option -Zpure.
