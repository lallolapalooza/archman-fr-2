NOM

timew-report - exécute un rapport d'extension

SYNTAXE

timew [report] <rapport> [<plage>] [<étiquette>...]
timew [report] <rapport> <id>...

DESCRIPTION

Exécute un rapport d'extension et permet de filtrer les données. La commande 'report' elle-même est optionnelle, ce qui signifie que ces deux commandes sont équivalentes :

$ timew report foo :week
$ timew        foo :week

Cela suppose cependant qu'une extension nommée 'foo' est installée.

Le code de retour est le code de retour de l'extension. Si l'extension ne produit aucune sortie et un code retour non nul, 255 est renvoyé.

Le filtrage est possible par plage et/ou par étiquettes, ou par identifiants.

CONFIGURATION

reports.range

Définit la plage de dates par défaut pour tous les rapports. La valeur doit correspondre à un indice de plage, voir timew-hints(7). Par défaut : all

reports.<nom>.range

Définit la plage de dates pour le rapport nom, utilisée si aucune plage n'est donnée en ligne de commande. Ici, nom est le nom de l'exécutable du rapport sans son extension (c'est-à-dire qu'un exécutable de rapport 'foo.py' est référencé par 'foo'). La valeur doit correspondre à un indice de plage, voir timew-hints(7). Par défaut : la valeur de reports.range.
