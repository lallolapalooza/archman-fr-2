NOM

tikztosvg - Rendre les diagrammes TikZ en SVG.

SYN。

tikztosvg [OPTION]... CHEMIN_ENTRÉE

DESCRIPTION

La commande tikztosvg(1) rend les diagrammes TikZ en SVG.

Si CHEMIN_ENTRÉE est défini à - l'entrée sera lue depuis stdin.

OPTIONS

-o, --output=CHEMIN_SORTIE

Écrit la sortie dans le fichier CHEMIN_SORTIE. Si défini à - la sortie sera écrite sur stdout. Par défaut, le nom de base du fichier d'entrée est suffixé par l'extension .svg. Le fichier est résolu par rapport au répertoire de travail.

-p, --package=+PAQUET

Inclut \usepackage{PAQUET} lors du rendu du diagramme. Les paquets tikz, tikz-cd, pgfplots, amsmath et amssymb sont toujours inclus par défaut.

-l, --library=+BIBLIOTHÈQUE

Inclut \usetikzlibrary{BIBLIOTHÈQUE} lors du rendu du diagramme.

-q, --quiet

Silence les messages de journalisation de l'application et les avertissements du script.

--lualatex

Utilise LuaTeX comme moteur TeX. LuaTeX est déjà le défaut, donc cette option ne fait pas grand-chose.

--xelatex

Utilise XeTeX comme moteur TeX.

--pdflatex

Utilise pdfTeX comme moteur TeX.

-h, --help

Imprime un message d'aide.

-v, --version

Imprime les informations de version.

ENVIRONNEMENT

tikztosvg nécessite XeTeX et pdf2svg installés. Assurez-vous que tous les paquets LaTeX supplémentaires sont installés avant de les utiliser dans un diagramme.
