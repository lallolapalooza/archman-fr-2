TIME(3P) Manuel du programmeur POSIX TIME(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

time — obtenir l'heure

SYNOPSIS

#include <time.h>
time_t time(time_t *tloc);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

La fonction time() renvoie la valeur de l'heure en secondes depuis l'Époque.

L'argument tloc pointe vers une zone où la valeur de retour est également stockée. Si tloc est un pointeur nul, aucune valeur n'est stockée.

VALEUR DE RETOUR

En cas de succès, time() renvoie la valeur de l'heure. Sinon, (time_t)-1 est renvoyé.

ERREURS

La fonction time() peut échouer si :

EOVERFLOW
Le nombre de secondes depuis l'Époque ne peut pas tenir dans un objet de type time_t.

Les sections suivantes sont informatives.

EXEMPLES

Obtenir l'heure actuelle

L'exemple suivant utilise la fonction time() pour calculer le temps écoulé, en secondes, depuis l'Époque, localtime() pour convertir cette valeur en une heure décomposée, et asctime() pour convertir les valeurs de temps décomposé en une chaîne imprimable.

#include <stdio.h>
#include <time.h>
int main(void)
{
time_t result;
    result = time(NULL);
    printf("%s%ju secs since the Epoch\n",
        asctime(localtime(&result)),
            (uintmax_t)result);
    return(0);
}

Cet exemple écrit l'heure actuelle sur stdout sous la forme :

Mer 26 juin 10:32:15 1996
835810335 secs since the Epoch

Minuter un événement

L'exemple suivant obtient l'heure actuelle, l'affiche dans le format de l'utilisateur, et affiche le nombre de minutes avant un événement chronométré.

#include <time.h>
#include <stdio.h>
...
time_t now;
int minutes_to_event;
...
time(&now);
minutes_to_event = ...;
printf("The time is ");
puts(asctime(localtime(&now)));
printf("There are %d minutes to the event.\n",
    minutes_to_event);
...

Aucun.

RATIONALE

La fonction time() renvoie une valeur en secondes, tandis que clock_gettime() et gettimeofday() renvoient une struct timespec (secondes et nanosecondes) et une struct timeval (secondes et microsecondes), respectivement, et sont donc capables de renvoyer des heures plus précises. La fonction times() est également capable de plus de précision que time() car elle renvoie une valeur en ticks d'horloge, bien qu'elle renvoie le temps écoulé depuis un point arbitraire tel que le démarrage du système, et non depuis l'époque.

Les implémentations dans lesquelles time_t est un entier signé de 32 bits (de nombreuses implémentations historiques) échouent en l'an 2038. POSIX.1‐2008 ne traite pas ce problème. Cependant, l'utilisation du type time_t est obligatoire afin de faciliter la correction éventuelle.

Sur certains systèmes, la fonction time() est implémentée à l'aide d'un appel système qui ne renvoie pas de condition d'erreur en plus de la valeur de retour. Sur ces systèmes, il est impossible de différencier les valeurs de retour valides et invalides, et par conséquent, les conditions de dépassement ne peuvent pas être détectées de manière fiable.

L'utilisation de l'en-tête <time.h> au lieu de <sys/types.h> permet la compatibilité avec la norme ISO C.

De nombreuses implémentations historiques (y compris la version 7) et la norme /usr/group de 1984 utilisent long au lieu de time_t. Ce volume de POSIX.1‐2017 utilise ce dernier type afin d'être en accord avec la norme ISO C.

DIRECTIONS FUTURES

Dans une future version de ce volume de POSIX.1‐2017, time_t sera probablement requis pour pouvoir représenter des dates futures lointaines. Qu'il s'agisse d'un type de 64 bits ou d'une exigence qu'une date spécifique dans le futur soit représentable (par exemple, l'an 10000) n'est pas encore déterminé. Les systèmes achetés après l'approbation de ce volume de POSIX.1‐2017 devraient être évalués pour déterminer si leur durée de vie s'étendra au-delà de 2038.

SYNOPSIS

#include <time.h>

time_t time(time_t *tloc);

DESCRIPTION

La fonction time() renvoie le nombre de secondes écoulées depuis l'Epoch (00:00:00 UTC, le 1er janvier 1970) jusqu'à présent. Si tloc n'est pas un pointeur nul, la valeur renvoyée est également stockée dans l'objet pointé par tloc.

VALEUR DE RETOUR

La fonction time() renvoie la valeur des secondes écoulées depuis l'Epoch, ou (time_t) -1 si une erreur survient.

ERREURS

Aucune erreur n'est définie pour la fonction time().
