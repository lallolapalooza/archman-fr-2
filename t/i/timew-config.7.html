NOM

timew-config - Fichier de configuration et options de surcharge de Timewarrior

SYNTAXE

timew rc.<nom>=<valeur> <commande>

DESCRIPTION

Timewarrior stocke sa configuration dans le répertoire personnel de l'utilisateur, dans ~/.timewarrior/timewarrior.cfg sur les systèmes non-Unix (par ex. Windows).

Sur les systèmes Unix, la spécification XDG Base Directory est prise en charge, si le répertoire ~/.timewarrior n'existe pas (l'ancien répertoire de configuration est toujours pris en charge et a la priorité sur les emplacements conformes à XDG BD).

Cela signifie que la configuration est stockée dans $XDG_CONFIG_HOME/timewarrior/timewarrior.cfg, qui est par défaut ~/.config/timewarrior/timewarrior.cfg si la variable d'environnement $XDG_CONFIG_HOME n'est pas spécifiée.

Ceux qui souhaitent migrer leurs données vers un nouveau schéma de répertoires peuvent le faire avec l'extrait de shell suivant :

LEGACY="${HOME}/.timewarrior"
CONFIG_DIR="${XDG_CONFIG_HOME:-$HOME/.config}/timewarrior"
DATA_DIR="${XDG_DATA_HOME:-$HOME/.local/share}/timewarrior"
mkdir -p "${CONFIG_DIR}"
mkdir -p "${DATA_DIR}"
mv "${LEGACY}/timewarrior.cfg" "${CONFIG_DIR}"
mv "${LEGACY}/extensions" "${CONFIG_DIR}"
mv "${LEGACY}/data" "${DATA_DIR}"
rmdir "${LEGACY}"

Ce fichier contient un mélange de règles et de paramètres de configuration. Notez que la variable d'environnement TIMEWARRIORDB peut être définie pour remplacer cet emplacement.

Les valeurs 'true', '1', 'y', 'yes' et 'on' sont toutes équivalentes et activent un réglage. Toute autre valeur signifie désactiver le réglage.

Les valeurs par défaut peuvent être remplacées par les valeurs de timewarrior.cfg, qui peuvent à leur tour être remplacées en ligne de commande en utilisant : rc.<nom>=<valeur>

Par exemple, pour désactiver le mode verbeux :

rc.verbose=0

Notez que les indices peuvent également le faire (:quiet).

CONFIGURATION

confirmation

Détermine si les opérations dangereuses nécessitent une confirmation interactive.

Peut être remplacée par l'indice ':yes'.

La valeur par défaut est 'yes'.

verbose

Détermine si Timewarrior génère des informations.

Peut être remplacée par l'indice ':quiet'.

La valeur par défaut est 'yes'.

debug

Détermine si les informations de débogage diagnostique sont affichées.

Utile pour le dépannage, mais pas pour un usage général.

La valeur par défaut est 'off'.

debug.indicator

La chaîne de préfixe de la sortie de débogage.

La valeur par défaut est '>>'.
