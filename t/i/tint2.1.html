NOM

tint2 - panneau/barre des tâches léger

DESCRIPTION

tint2 est un panneau/une barre des tâches simple conçu pour les gestionnaires de fenêtres X modernes. Il a été spécifiquement créé pour Openbox mais devrait également fonctionner avec d'autres gestionnaires de fenêtres (GNOME, KDE, XFCE, etc.).

Caractéristiques :

  • Panneau avec barre des tâches, zone de notification système, horloge et icônes de lanceur ;
  • Facile à personnaliser : couleur/transparence des polices, icônes, bordures et arrière-plans ;
  • Capacités similaires à un paginateur : déplacer des tâches entre les espaces de travail (bureaux virtuels), basculer entre les espaces de travail ;
  • Capacité multi-moniteurs : créer un panneau par moniteur, n'affichant que les tâches du moniteur actuel ;
  • Événements de souris personnalisables.

Objectifs :

  • Être discret et léger (en termes de mémoire, de CPU et d'esthétique) ;
  • Suivre les spécifications freedesktop.org ;
  • Rendre certains flux de travail, tels que le multi-bureau et le multi-moniteur, faciles à utiliser.

SYNTAXE

tint2 [OPTION...]

OPTIONS

-c chemin_vers_fichier_config
Spécifie quel fichier de configuration utiliser à la place du fichier par défaut.
-v, --version
Affiche les informations de version et quitte.
-h, --help
Affiche cette aide et quitte.

Introduction

Ce sont les instructions pour configurer tint2 directement en modifiant son fichier de configuration. Vous pouvez également utiliser l'interface graphique tint2conf.

La première fois que vous exécutez tint2, il créera le fichier de configuration dans $HOME/.config/tint2/tint2rc (Ceci s'applique si vous avez effectué une installation propre. L'exécution de tint2 dans le répertoire source sans faire 'make install' ne créera pas le fichier de configuration.)

Vous pouvez également spécifier un autre fichier sur la ligne de commande avec l'option -c, par exemple : tint2 -c $HOME/tint2.conf. Ceci peut être utilisé pour exécuter plusieurs instances de tint2 qui utilisent des paramètres différents.

Si vous modifiez le fichier de configuration pendant que tint2 est en cours d'exécution, la commande killall -SIGUSR1 tint2 forcera tint2 à le recharger.

Toutes les options de configuration prises en charge dans le fichier de configuration sont listées ci-dessous. Essayez de respecter autant que possible l'ordre des options tel qu'indiqué ci-dessous.

Arrière-plans et bordures

Le fichier de configuration de tint2 commence par les options définissant les éléments d'arrière-plan avec des bordures :

  • rounded = nombre_de_pixels : le rayon des coins
  • border_width = entier : la largeur de la bordure en pixels
  • border_sides = LTRB : les côtés sur lesquels dessiner la bordure (gauche, droite, haut, bas). Si non spécifié, tous les côtés sont utilisés. (depuis 0.12.12)
  • background_color = couleur opacité
  • couleur est spécifiée en RGB hexadécimal, par exemple #ff0000 est rouge
  • opacité varie de (0 à 100), où 0 est complètement transparent, 100 est complètement opaque. Notez que pour un panneau transparent, vous devez activer un compositeur de bureau (tel que compton ou compiz).
•
border_color = couleur opacité
  • couleur est spécifiée en RGB hexadécimal, par exemple #ff0000 est rouge
  • opacité varie de (0 à 100), où 0 est complètement transparent, 100 est complètement opaque
•
background_color_hover = couleur opacité (par défaut : identique à background_color) (depuis 0.12.3)
  • couleur est spécifiée en RGB hexadécimal, par exemple #ff0000 est rouge
  • opacité varie de (0 à 100), où 0 est complètement transparent, 100 est complètement opaque. Notez que pour un panneau transparent, vous devez activer un compositeur de bureau (tel que compton ou compiz)
•
border_color_hover = couleur opacité (par défaut : identique à border_color) (depuis 0.12.3)
  • couleur est spécifiée en RGB hexadécimal, par exemple #ff0000 est rouge
  • opacité varie de (0 à 100), où 0 est complètement transparent, 100 est complètement opaque
•
background_color_pressed = couleur opacité (par défaut : identique à background_color_hover) (depuis 0.12.3)
  • couleur est spécifiée en RGB hexadécimal, par exemple #ff0000 est rouge
  • opacité varie de (0 à 100), où 0 est complètement transparent, 100 est complètement opaque. Notez que pour un panneau transparent, vous devez activer un compositeur de bureau (tel que compton ou compiz)
•
border_color_pressed = couleur opacité (par défaut : identique à border_color_hover) (depuis 0.12.3)
  • couleur est spécifiée en RGB hexadécimal, par exemple #ff0000 est rouge
  • opacité varie de (0 à 100), où 0 est complètement transparent, 100 est complètement opaque
  • border_content_tint_weight = entier : Mélange la couleur de la bordure avec la couleur du contenu (pour les tâches, il s'agit de la couleur moyenne de l'icône de la fenêtre). Les valeurs doivent être comprises entre 0 (pas de mélange) et 100 (remplace complètement la couleur). (depuis 16.0)
  • background_content_tint_weight = entier : Mélange la couleur de l'arrière-plan avec la couleur du contenu (pour les tâches, il s'agit de la couleur moyenne de l'icône de la fenêtre). Les valeurs doivent être comprises entre 0 (pas de mélange) et 100 (remplace complètement la couleur). (depuis 16.0)

Vous pouvez définir autant d'arrière-plans que vous le souhaitez. Par exemple, la configuration suivante définit deux arrière-plans :

rounded = 1
border_width = 0
background_color = #282828 100
border_color = #000000 0
rounded = 1
border_width = 0
background_color = #f6b655 90
border_color = #cccccc 40

tint2 identifie automatiquement chaque arrière-plan avec un numéro commençant à 1 (1, 2, ...). Ensuite, vous pouvez appliquer un arrière-plan aux objets (panneau, barre des tâches, tâche, horloge, zone de notification) en utilisant l'ID de l'arrière-plan, par exemple :

panel_background_id = 1
taskbar_background_id = 0
task_background_id = 0
task_active_background_id = 2
systray_background_id = 0
clock_background_id = 0

L'identifiant 0 fait référence à un arrière-plan spécial entièrement transparent, l'identifiant 1 applique le premier arrière-plan défini dans le fichier de configuration, etc.

Dégradés

(Disponible depuis 0.13.0)

Les arrière-plans permettent également de spécifier des couches de dégradés qui sont dessinées par-dessus l'arrière-plan de couleur unie.

Tout d'abord, l'utilisateur doit définir un ou plusieurs dégradés dans le fichier de configuration, chacun commençant par gradient = TYPE. Ceux-ci doivent être ajoutés avant les arrière-plans.

Ensuite, les dégradés peuvent être ajoutés par index aux arrière-plans, en utilisant gradient_id = INDEX, gradient_id_hover = INDEX et gradient_id_pressed = INDEX, où INDEX est l'index du dégradé, commençant à 1.

Types de dégradés

Dégradés

ients varient la couleur entre les points de contrôle fixes : * dégradés verticaux : haut-vers-bas ; * dégradés horizontaux : gauche-vers-droite ; * dégradés radiaux : centre-vers-coins.

L'utilisateur doit spécifier les couleurs de début et de fin, et peut facultativement ajouter des couleurs intermédiaires supplémentaires à l'aide de l'option color_stop, comme expliqué ci-dessous.

Dégradé vertical, avec couleur variant du bord supérieur au bord inférieur, deux couleurs

gradient = vertical
start_color = #rrggbb opacité
end_color = #rrggbb opacité

Dégradé horizontal, avec couleur variant du bord gauche au bord droit, deux couleurs

gradient = horizontal
start_color = #rrggbb opacité
end_color = #rrggbb opacité

Dégradé radial, avec couleur variant du centre au coin, deux couleurs :

gradient = radial
start_color = #rrggbb opacité
end_color = #rrggbb opacité

Ajout de couleurs intermédiaires (0% et 100% restent fixes, plus de couleurs à x% entre les points de contrôle de début et de fin)

color_stop = pourcentage #rrggbb opacité

Panneau

•
panel_items = LTSBC définit les éléments que tint2 affichera et leur ordre. Chaque lettre fait référence à un élément, défini comme suit :
  • L affiche le Lanceur
  • T affiche la Barre des tâches
  • S affiche la Zone de notification (aussi appelée zone système)
  • B affiche l'état de la Batterie
  • C affiche l'Horloge
  • F ajoute un espace extensible (espace libre). Vous pouvez en spécifier plusieurs. N'a aucun effet si T est également présent. (depuis 0.12)
  • E ajoute un plugin d'exécution. Vous pouvez en spécifier plusieurs. (depuis 0.12.4)
  • P ajoute un bouton poussoir. Vous pouvez en spécifier plusieurs. (depuis 0.14)
  • : ajoute un séparateur. Vous pouvez en spécifier plusieurs. (depuis 0.13.0)

Par exemple, panel_items = STC affichera la zone de notification, la barre des tâches et l'horloge (de gauche à droite).

•
panel_monitor = monitor (all ou primary ou 1 ou 2 ou ...) : Sur quel moniteur tint2 dessine le panneau
  • Le premier moniteur est le 1
  • Utilisez panel_monitor = all pour avoir un panneau séparé par moniteur
•
primary_monitor_first = boolean (0 ou 1) : Place le moniteur principal avant tous les autres moniteurs de la liste. (depuis 0.12.4 ; supprimé en 1.0, utilisez plutôt primary)

[](images/panel_padding.jpg)

•
panel_position = position_verticale position_horizontale orientation
  • position_verticale est l'une des valeurs suivantes : bottom, top, center
  • position_horizontale est l'une des valeurs suivantes : left, right, center
  • orientation est l'une des valeurs suivantes : horizontal, vertical
•
panel_size = largeur hauteur
•
largeur et hauteur peuvent être spécifiés sans unité (par exemple, 123) en pixels, ou suivis de % pour des pourcentages de la taille de l'écran (par exemple, 50%). Utilisez 100% pour une largeur/hauteur d'écran complète. Exemple :
  • scale_relative_to_dpi = entier : Si défini sur une valeur non nulle, la mise à l'échelle HiDPI est activée. Chaque panneau est visible sur un écran différent. Ainsi, chaque panneau a un facteur de mise à l'échelle spécifique. Le facteur de mise à l'échelle est calculé comme le rapport entre le DPI du moniteur (obtenu à partir des dimensions en pixels et en millimètres de RandR) et un DPI de référence configuré - c'est le DPI pour lequel les configurations utilisateur existantes semblaient normales, pour la compatibilité ascendante.
  • scale_relative_to_screen_height = entier : Similaire à scale_relative_to_dpi, sauf que le facteur de mise à l'échelle est calculé comme le rapport entre la hauteur du moniteur et scale_relative_to_screen_height. L'effet est cumulatif avec scale_relative_to_dpi, c'est-à-dire que si les deux options sont présentes, les facteurs sont multipliés.
# La largeur du panneau est 94% de la taille du moniteur, la hauteur est de 30 pixels :
panel_size = 94% 30
  • panel_shrink = boolean (0 ou 1) : Si défini sur 1, le panneau se réduira dynamiquement à une taille compacte. (depuis 0.13)
  • panel_margin = marge_horizontale marge_verticale : Les marges définissent la distance entre le panneau et le bord horizontal/vertical du moniteur. Utilisez 0 pour obtenir un panneau de la même taille que le bord du moniteur (pas de marge).

•
panel_padding = remplissage_horizontal remplissage_vertical espacement : Veuillez vous référer à l'image ci-dessous.

[](images/panel_padding.jpg)

  • font_shadow = boolean (0 ou 1)
  • panel_background_id = entier : Quel arrière-plan utiliser pour le panneau.
  • wm_menu = boolean (0 ou 1) : Définit si tint2 transmet les événements de souris non gérés à votre gestionnaire de fenêtres. Utile pour les gestionnaires de fenêtres tels qu'openbox, qui affichent le menu de démarrage si vous cliquez avec le bouton droit sur le bureau.
  • panel_dock = boolean (0 ou 1) : Définit si tint2 est placé dans le dock du gestionnaire de fenêtres. Pour le gestionnaire de fenêtres openbox, il est conseillé d'utiliser également un modificateur pour l'option moveButton, sinon le clic de souris n'est pas transmis à tint2 (dans ~/.config/openbox/rc.xml).
  • panel_pivot_struts = boolean (0 ou 1) : Définit si tint2 ment au gestionnaire de fenêtres concernant son orientation (horizontale ou verticale) lors de la demande d'espace réservé avec les STRUTs (voir strut_policy ci-dessous). Sur certains gestionnaires de fenêtres, cela permet de placer un panneau au milieu de l'écran virtuel, par exemple sur le bord inférieur d'un écran supérieur dans une configuration bi-écran verticale.
  • panel_layer = bottom/normal/top : Place tint2 dans la couche inférieure/normale/supérieure. Ceci est utile pour spécifier si le panneau peut être recouvert par d'autres fenêtres ou non. La valeur par défaut est la couche inférieure, mais avec une transparence réelle, les couches normale ou supérieure peuvent être une bonne alternative.
  • strut_policy = follow_size/minimum/none : Les STRUTs sont utilisés par le gestionnaire de fenêtres pour décider de la taille des fenêtres maximisées. Remarque : dans les configurations multi-moniteurs (Xinerama), le panneau doit généralement être placé sur le bord (pas au milieu) de l'écran virtuel pour que cela fonctionne correctement (bien que sur certains gestionnaires de fenêtres, la définition de panel_pivot_struts puisse contourner cette limitation).
  • follow_size signifie que les fenêtres maximisées se redimensionnent toujours pour avoir un bord commun avec tint2.
  • minimum signifie que les fenêtres maximisées s'étendent toujours pour avoir un bord commun avec le panneau masqué. Ceci est utile si l'option autohide est activée.
  • none signifie que les fenêtres maximisées utilisent toute la taille de l'écran.
  • panel_window_name = chaîne : Définit le nom de la fenêtre du panneau. Par défaut : 'tint2'. (depuis 0.12)
  • disable_transparency = boolean (0 ou 1) : Désactive la transparence au lieu de détecter si elle est prise en charge. Utile sur des piles graphiques défectueuses. (depuis 0.12)
  • mouse_effects = boolean (0 ou 1) : Active les effets de survol de la souris pour les éléments cliquables. (depuis 0.12.3)
  • mouse_hover_icon_asb = alpha (0 à 100) saturation (-100 à 100) luminosité (-100 à 100) : Ajuste la couleur et la transparence de l'icône au survol de la souris (fonctionne uniquement lorsque mouse_effects = 1).` (depuis 0.12.3)
  • mouse_pressed_icon_asb = alpha (0 à 100) saturation (-100 à 100) luminosité (-100 à 100) : Ajuste la couleur et la transparence de l'icône lors du clic de souris (fonctionne uniquement lorsque mouse_effects = 1).` (depuis 0.12.3)
  • autohide = boolean (0 ou 1) : Active le masquage du panneau lorsque le curseur de la souris quitte le panneau.
  • autohide_show_timeout = flottant : Délai d'affichage en secondes après que le curseur de la souris entre dans le panneau. Utilisez '.' comme séparateur décimal.
  • autohide_hide_timeout = flottant : Délai de masquage en secondes après que le curseur de la souris quitte le panneau. Utilisez '.' comme séparateur décimal.
  • autohide_height = entier : hauteur du panneau (largeur pour les panneaux verticaux) en mode masqué.

    Boutons de la barre des tâches

    Les options suivantes configurent les boutons de tâche dans la barre des tâches :

    • task_icon = booléen (0 ou 1) : Afficher ou non l'icône de la tâche. Il n'y a pas d'option explicite pour contrôler la taille de l'icône de la tâche ; elle dépend du padding vertical défini avec task_padding.
    • task_text = booléen (0 ou 1) : Afficher ou non le texte de la tâche.
    • task_centered = booléen (0 ou 1) : Centrer ou non le texte de la tâche.
    • task_tooltip = booléen (0 ou 1) : Afficher ou non les info-bulles pour les tâches.
    • task_thumbnail = booléen (0 ou 1) : Afficher ou non les miniatures dans les info-bulles pour les tâches. (depuis 16.0)

    Actions de la souris pour les boutons de la barre des tâches

    Les événements de souris possibles sont : gauche, milieu, droite, scroll_haut, scroll_bas.

    Les actions de souris possibles sont : none, close, toggle, iconify, shade, toggle_iconify, maximize_restore, desktop_left, desktop_right, next_task, prev_task.

    Utilisez mouse_event = action pour personnaliser les actions de la souris. Exemple :
    mouse_middle = none
    mouse_right = close
    mouse_scroll_up = toggle
    mouse_scroll_down = iconify

    La sémantique des actions :
    * none : Si wm_menu = 1 est défini, l'événement de souris est transmis au gestionnaire de fenêtres. Sinon, il est ignoré. * close : ferme la tâche * toggle : bascule la tâche * iconify : icônifie (minimise) la tâche * toggle_iconify : bascule ou icônifie la tâche * maximize_restore : maximise ou restaure la tâche * shade : met en accordéon (réduit) la tâche * desktop_left : envoie la tâche au bureau de gauche * desktop_right : envoie la tâche au bureau de droite * next_task : envoie le focus à la tâche suivante * prev_task : envoie le focus à la tâche précédente

    Exécuteur

    • execp = new : Commence la configuration d'un nouveau plugin exécuteur. Plusieurs plugins de ce type sont supportés ; utilisez simplement plusieurs E dans panel_items. (depuis 0.12.4)
    • execp_command = texte : Commande à exécuter. (depuis 0.12.4)
    • execp_interval = entier : La commande est réexécutée après execp_interval secondes à partir du moment où elle se termine. Si c'est zéro, la commande n'est exécutée qu'une seule fois. (depuis 0.12.4)
    • execp_continuous = entier : Si non nul, les dernières execp_continuous lignes de la sortie de la commande sont affichées, toutes les execp_continuous lignes ; ceci est utile pour afficher la sortie des commandes qui s'exécutent indéfiniment, comme ping 127.0.0.1. Si c'est zéro, la sortie de la commande est affichée après sa fin d'exécution. (depuis 0.12.4)
    • execp_has_icon = booléen (0 ou 1) : Si execp_has_icon = 1, la première ligne imprimée par la commande est interprétée comme un chemin vers un fichier image. (depuis 0.12.4)
    • execp_cache_icon = booléen (0 ou 1) : Si execp_cache_icon = 0, l'image est rechargée chaque fois que la commande est exécutée (utile si le fichier image est modifié sur disque par le programme exécuté par execp_command). (depuis 0.12.4)
    • execp_icon_w = entier : Vous pouvez utiliser execp_icon_w et execp_icon_h pour redimensionner l'image. Si l'un d'eux est zéro/absent, l'image est redimensionnée proportionnellement. Si les deux sont zéro/absents, l'image n'est pas redimensionnée. (depuis 0.12.4)
    • execp_icon_h = entier : Voir execp_icon_w. (depuis 0.12.4)
    • execp_tooltip = texte : L'info-bulle. Si laissé vide, aucune info-bulle n'est affichée. Si absent, l'erreur standard de la commande est affichée comme info-bulle (une séquence de nettoyage d'écran ANSI peut réinitialiser le contenu, bash : printf '\e[2J', C : printf("\x1b[2J");). Si l'erreur standard est vide, l'info-bulle affichera des informations sur le moment où la commande a été exécutée pour la dernière fois. (depuis 0.12.4)
    • execp_font = [LISTE_FAMILLES] [OPTIONS_STYLE] [TAILLE] : La police utilisée pour dessiner le texte. (depuis 0.12.4)
    • execp_font_color = couleur opacité : La couleur de la police. (depuis 0.12.4)
    • execp_markup = booléen (0 ou 1) : Si non nul, la sortie de la commande est traitée comme du balisage Pango, ce qui permet une mise en forme de texte riche. Le format est documenté ici : ⟨https://developer.gnome.org/pygtk/stable/pango-markup-language.html⟩. Notez que l'utilisation de cette option avec des commandes qui impriment des données téléchargées depuis Internet présente un risque potentiel pour la sécurité. (depuis 0.12.4)
    • execp_background_id = entier : Quel arrière-plan utiliser. (depuis 0.12.4)
    • execp_centered = booléen (0 ou 1) : Centrer le texte ou non. (depuis 0.12.4)
    • execp_padding = padding_horizontal padding_vertical espacement_entre_l_icone_et_le_texte (depuis 0.12.4)
    • execp_monitor = entier (1, 2, ...), principal ou tous : Sur quel moniteur afficher l'exécuteur. Le premier moniteur est 1. (depuis 17.0)
    • execp_lclick_command = texte : Commande à exécuter lors d'un clic gauche. Si non définie, execp_command est exécutée immédiatement, sauf si elle est en cours d'exécution. (depuis 0.12.4)
    • execp_mclick_command = texte : Commande à exécuter lors d'un clic droit. Si non définie, execp_command est exécutée immédiatement, sauf si elle est en cours d'exécution. (depuis 0.12.4)
    • execp_rclick_command = texte : Commande à exécuter lors d'un clic du milieu. Si non définie, execp_command est exécutée immédiatement, sauf si elle est en cours d'exécution. (depuis 0.12.4)
    • execp_uwheel_command = texte : Commande à exécuter lors d'une molette de défilement vers le haut. Si non définie, execp_command est exécutée immédiatement, sauf si elle est en cours d'exécution. (depuis 0.12.4)

    Exemples d'exécuteur

    Afficher le nom d'hôte

    execp = new
execp_command = hostname
execp_interval = 0

    Afficher l'utilisation du disque pour la partition racine toutes les 10 secondes

    execp = new
execp_command = df -h | awk '/\/$/ { print $6 ": " $2 " " $5}'
execp_interval = 10

    SYNOPIS

    Les panneaux tint2 sont configurés dans le fichier ~/.config/tint2/tint2rc. Les options de configuration sont détaillées ci-dessous.

    OPTIONS

    Les sections suivantes décrivent les différentes options de configuration disponibles pour tint2.

    Bouton avec icone et texte riche, exécute une commande au clic

    execp = nouveau
execp_command = echo /usr/share/icons/elementary-xfce/emblems/24/emblem-colors-blue.png; echo '<span foreground="#7f7">Cliquez</span> <span foreground="#77f">moi</span> <span foreground="#f77"> SVP</span>'
execp_has_icon = 1
execp_interval = 0
execp_centered = 1
execp_font = sans 9
execp_markup = 1
execp_font_color = #aaffaa 100
execp_padding = 2 0
execp_tooltip = Je vais vous dire un secret...
execp_lclick_command = zenity --info "--text=$(uname -sr)"
execp_background_id = 2

    Pagineur de bureau avec texte

    execp = nouveau
execp_command = xprop -root -spy | awk '/^_NET_CURRENT_DESKTOP/ { print "Espace de travail " ($3 + 1) ; fflush(); }'
execp_interval = 1
execp_continuous = 1

    Pagineur de bureau avec icône

    execp_command = xprop -root -spy | awk -v home="$HOME" '/^_NET_CURRENT_DESKTOP/ { print home "/.config/myPager/" ($3 + 1) ".png\n" ; fflush(); }'
execp_interval = 1
execp_has_icon = 1
execp_cache_icon = 1
execp_continuous = 2

    Temps de latence vers la passerelle, rafraîchi chaque seconde

    execp = nouveau
execp_command = ping -i 1 -c 1 -W 1 -O -D -n $(ip route | grep default | grep via | grep -o '[0-9]*\.[0-9]*\.[0-9]*\.[0-9]*') | awk '/no/ { print "<span foreground=\"#faa\">timeout</span>"; fflush(); }; /time=/ { gsub(/time=/, "", $8); printf "<span foreground=\"#7af\">%3.0f %s</span>\n", $8, $9; fflush(); } '
execp_continuous = 0
execp_interval = 1
execp_markup = 1

    Utilisation de la mémoire

    # Notez l'utilisation de "stdbuf -oL" pour forcer le programme à vider la sortie ligne par ligne.
execp = nouveau
execp_command = free -b -s1 | stdbuf -oL awk '/^Mem:/ { printf "Mem: %s %.0f%%\n", $2, 100 * ($2 - $7) / $2 }' | stdbuf -oL numfmt --to=iec-i --field=2 -d' '
execp_interval = 1
execp_continuous = 1

    Charge réseau

    execp = nouveau
execp_command = stdbuf -oL bwm-ng -o csv -t 1000 | stdbuf -oL awk -F ';' '/total/ { printf "Net: %.0f Mb/s\n", ($5*8/1.0e6) }'
execp_continuous = 1
execp_interval = 1
