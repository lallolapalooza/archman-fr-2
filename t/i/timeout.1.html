TIMEOUT(1) Commandes utilisateur TIMEOUT(1)

NOM

timeout - exécuter une commande avec une limite de temps

SYNTAXE

timeout [OPTION]... DURÉE COMMANDE [ARG]...

DESCRIPTION

Démarre COMMANDE, et la termine si elle est toujours en cours d'exécution après DURÉE.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-f, --foreground

lorsque timeout n'est pas exécuté directement depuis une invite de commande, permet à COMMANDE de lire depuis le TTY et de recevoir des signaux TTY ; dans ce mode, les processus enfants de COMMANDE ne seront pas soumis à une limite de temps.

-k, --kill-after=DURÉE

envoie également un signal KILL si COMMANDE est toujours en cours d'exécution après cette durée depuis l'envoi du signal initial.

-p, --preserve-status

se termine avec le même statut que COMMANDE, même lorsque la commande atteint sa limite de temps.

-s, --signal=SIGNAL

spécifie le signal à envoyer lors de l'expiration du délai ; SIGNAL peut être un nom comme 'HUP' ou un numéro ; voir 'kill -l' pour une liste des signaux.
-v, --verbose
diagnostique sur la sortie d'erreur standard tout signal envoyé lors de l'expiration du délai.
--help
affiche cette aide et quitte.
--version
affiche les informations de version et quitte.

DURÉE est un nombre à virgule flottante avec un suffixe optionnel : 's' pour secondes (par défaut), 'm' pour minutes, 'h' pour heures ou 'd' pour jours. Une durée de 0 désactive le délai associé.

Lors de l'expiration du délai, envoie le signal TERM à COMMANDE, si aucun autre SIGNAL n'est spécifié. Le signal TERM termine tout processus qui ne bloque pas ou ne capture pas ce signal. Il peut être nécessaire d'utiliser le signal KILL, car ce signal ne peut pas être capturé.

Statut de sortie :

124
si COMMANDE expire, et que --preserve-status n'est pas spécifié.
125
si la commande timeout elle-même échoue.
126
si COMMANDE est trouvée mais ne peut pas être invoquée.
127
si COMMANDE ne peut pas être trouvée.
137
si COMMANDE (ou timeout lui-même) reçoit le signal KILL (9) (128+9).
-
le statut de sortie de COMMANDE sinon.

BOGUES
