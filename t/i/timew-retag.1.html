NOM

timew-retag - remplace toutes les étiquettes dans les intervalles

SYNOPSIS

timew retag [<id>...] <étiquette>...

DESCRIPTION

La commande 'retag' est utilisée pour remplacer toutes les étiquettes d'un intervalle par les nouvelles étiquettes fournies. En utilisant la commande 'summary', et en spécifiant l'indice ':ids' affiche les identifiants d'intervalle. En utilisant le bon ID, vous pouvez identifier un intervalle à retaguer.

EXEMPLES

Par exemple, afficher les identifiants :

$ timew summary :week :ids

Ensuite, ayant sélectionné '@2' comme l'intervalle que vous souhaitez retaguer :

$ timew retag @2 'Nouvelle Étiquette'

Notez que vous pouvez retaguer plusieurs intervalles, avec plusieurs étiquettes :

$ timew retag @2 @10 @23 'Étiquette Un' etiquette2 etiquette3

S'il y a un suivi de temps actif, vous pouvez omettre l'ID lorsque vous souhaitez retaguer l'intervalle ouvert actuel :

$ timew start foo
$ timew retag bar

Ceci a pour résultat que l'intervalle actuel n'a que l'étiquette 'bar'.

VOIR AUSSI
