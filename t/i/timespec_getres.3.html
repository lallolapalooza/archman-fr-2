timespec_get(3) Manuel des fonctions de bibliothèque timespec_get(3)

NOM

timespec_get, timespec_getres - Interface ISO C pour les fonctions d'horloge et de temps

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc),

SYNTAXE

#include <time.h>
int timespec_get(struct timespec *res, int base);
int timespec_getres(struct timespec *tp, int base);

DESCRIPTION

La fonction timespec_get() stocke l'heure actuelle, basée sur la base de temps spécifiée, dans la structure timespec(3type) pointée par res.

La fonction timespec_getres() stocke la résolution des temps obtenus par timespec_get() avec la base de temps spécifiée dans la structure timespec(3type) pointée par tp, si tp n'est pas NULL. Pour une base de temps donnée, la résolution est constante pendant la durée de vie du processus appelant.

TIME_UTC est toujours une base de temps prise en charge, et est la seule base de temps prise en charge sous Linux. Le temps et la résolution dans cette base de temps sont identiques à ceux obtenus par clock_gettime(CLOCK_REALTIME, res) et clock_getres(CLOCK_REALTIME, tp), respectivement. D'autres systèmes peuvent prendre en charge des bases de temps supplémentaires.

VALEUR DE RETOUR

timespec_get() renvoie la valeur non nulle de base si c'est une base de temps prise en charge et que l'heure actuelle a été récupérée avec succès, ou 0 sinon.

timespec_getres() renvoie la valeur non nulle de base si c'est une base de temps prise en charge, ou 0 sinon.
