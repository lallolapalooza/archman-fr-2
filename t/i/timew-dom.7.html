NOM

timew-dom - DOM de Timewarrior

SYNOPIS

DESCRIPTION

Toutes les références DOM commencent par dom, il y a 4 sous-références accessibles :

•dom.tracked, tous les intervalles
•dom.active, suivi de temps actif
•dom.tags, tous les étiquettes
•dom.rc, paramètres de configuration

Tous les intervalles

dom.tracked est une référence à tous les intervalles du résultat de la requête de base de données. Lors de l'utilisation de cette référence, un filtrage par plage et par étiquettes peut être appliqué. 
dom.tracked.count           Nombre de tous les intervalles dans le résultat de la requête
dom.tracked.ids             Identifiants de tous les intervalles dans le résultat de la requête
dom.tracked.tags            Étiquettes de tous les intervalles dans le résultat de la requête
dom.tracked.tags.count      Nombre de toutes les étiquettes dans le résultat de la requête
dom.tracked.tags.<n>        N-ième étiquette de toutes les étiquettes dans le résultat de la requête

dom.tracked.<n> est une référence au n-ième intervalle du résultat de la requête de base de données. Selon le filtrage appliqué, le n-ième intervalle n'est pas nécessairement celui avec l'identifiant @n !

dom.tracked.<n>.tags        Toutes les étiquettes du n-ième intervalle
dom.tracked.<n>.tags.count  Nombre d'étiquettes du n-ième intervalle
dom.tracked.<n>.tags.<m>    N-ième intervalle, m-ième étiquette
dom.tracked.<n>.start       N-ième intervalle, heure de début (date ISO étendue)
dom.tracked.<n>.end         N-ième intervalle, heure de fin (date ISO étendue, vide si ouvert)
dom.tracked.<n>.duration    N-ième intervalle, durée (ISO Durée)
dom.tracked.<n>.json        N-ième intervalle, au format JSON

Suivi de temps actif

dom.active est une référence au dernier intervalle du suivi de temps actif. Elle est invalide lorsqu'aucun temps n'est suivi. 
dom.active                  '1' s'il y a un suivi actif, sinon '0'
dom.active.tags             Toutes les étiquettes du suivi actif
dom.active.tags.count       Nombre d'étiquettes
dom.active.tags.<n>         N-ième étiquette
dom.active.start            Horodatage de début (date ISO étendue)
dom.active.duration         Temps écoulé (Période ISO)
dom.active.json             Intervalle au format JSON

Toutes les étiquettes

dom.tags est une référence à toutes les étiquettes de la base de données. 
dom.tags                    Toutes les étiquettes
dom.tags.count              Nombre de toutes les étiquettes
dom.tags.1                  N-ième étiquette

Sans filtre appliqué, dom.tracked.tags fait référence au même ensemble d'étiquettes que dom.tags.

Paramètres de configuration

dom.rc est une référence à tous les paramètres de configuration de Timewarrior. Comme il n'y a pas de restrictions pour les clés de configuration, toutes ces références sont valides par conception. 
dom.rc.<nom>              Paramètre de configuration <nom>
