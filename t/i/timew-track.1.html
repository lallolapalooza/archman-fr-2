NOM

timew-track - ajouter des intervalles à la base de données

SYNTAXE

timew track <intervalle> [<étiquette>...]

DESCRIPTION

La commande track est utilisée pour ajouter du temps enregistré dans le passé. Peut-être avez-vous oublié d'enregistrer du temps, ou vous remplissez simplement d'anciennes entrées.

INDICES

Outre les indices d'intervalle (voir timew-hints(7)), la commande track accepte les indices suivants :

:fill

L'indice ':fill' peut être utilisé pour créer un nouvel intervalle qui comble le vide entre deux intervalles adjacents.

EXEMPLES

Enregistrement d'un intervalle fermé

Par exemple : 
$ timew track :yesterday 'Formation'
$ timew track 9h - 11h 'Réunion du personnel'

Notez que la commande track attend un intervalle fermé (heure de début et heure de fin) lors de l'enregistrement. Si un intervalle fermé n'est pas fourni, la commande 'track' se comporte de la même manière que la commande 'start'.

Combler le vide entre deux intervalles

Pour combler le vide entre deux intervalles, sans avoir à spécifier les heures exactes, on peut utiliser l'indice :fill. Lorsque, par exemple, le premier intervalle se termine un peu avant 10h00 et le second intervalle commence un peu après 11h00, l'appel 
$ timew track 10:00 - 11:00 :fill 'Pause café'

demandera à Timewarrior d'étendre l'intervalle de manière à ce qu'il commence juste après le premier intervalle et se termine juste avant le second intervalle.
