NOM

tinysparql query - Interroger des points d'accès SPARQL.

SYNTAXE

tinysparql query [(-d |--database) <fichier> | (-b | --dbus-service) <nom_bus> | (-r | --remote-service) <url>]
    [(-f | --file) <fichier>] [(-u | --update)] [-a <paramètre>:<valeur>]... [SPARQL]

DESCRIPTION

Cette commande permet d'exécuter des requêtes ou des mises à jour sur un point d'accès SPARQL.

Lorsque l'appelant exécute une requête, celle-ci est dans le langage SPARQL. Cela peut être fait de deux manières : soit en fournissant un fichier contenant la requête, soit en fournissant une chaîne avec la requête sparql.

L'argument fichier peut être un chemin local ou une URI. Il n'a pas non plus besoin d'être un chemin absolu.

OPTIONS

-b, --dbus-service=<nom_service>

Se connecte à un point d'accès SPARQL via un nom D-Bus.

-d, --database-path=<chemin_base_de_données>

Se connecte à une base de données par son emplacement dans le système de fichiers.

-r, --remote-service=<url>

Se connecte à un point d'accès SPARQL HTTP.

-f, --file=<fichier>

Utilise un fichier contenant du contenu SPARQL pour interroger ou mettre à jour.

-u, --update

Doit être utilisé avec --query. Cela indique à « tinysparql query » d'utiliser les extensions de mise à jour SPARQL afin qu'il sache qu'il ne s'agit pas d'une requête de recherche de données régulière. Donc, si votre requête est destinée à modifier des données dans la base de données, cette option est nécessaire.

-a, --arg=<paramètre>:<valeur>

Fournit un argument pour un paramètre déclaré dans la chaîne de requête SPARQL. Ceci peut être utilisé avec --file, --query ou --update. Plusieurs arguments peuvent être fournis pour plusieurs paramètres. Les valeurs d'argument sont fournies sous forme de chaîne séparée par des deux-points contenant 3 valeurs : nom, type et valeur. Le nom est le même que celui utilisé dans la chaîne de requête, la valeur est la valeur souhaitée, et le type est une chaîne d'un seul caractère définissant le type :
•i : La valeur décrira un entier
•d : La valeur décrira un nombre à virgule flottante
•b : La valeur décrira une valeur booléenne
•s : La valeur décrira une chaîne de caractères simple

EXEMPLES

Interrogation d'un point d'accès D-Bus

$ tinysparql query --dbus-service org.example.Endpoint "SELECT ('Hello World' AS ?str) {}"

Mise à jour d'une base de données directement à partir d'une requête dans un fichier

$ tinysparql query --database /tmp/db/ --update --file ./update.rq

Utilisation de --arg pour fournir des arguments aux paramètres de requête

$ tinysparql query -b org.example.Endpoint \
    -a name:s:"John" -a age:i:42 -a available:b:true \
    "SELECT (~name AS ?name) (~age AS ?age) (~available AS ?avail) { }"
