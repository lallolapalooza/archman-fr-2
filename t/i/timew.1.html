NOM

timew - un outil de suivi temporel en ligne de commande

SYNTAXE

timew [--version|--help]
timew [<commande> [<arg>...]]

DESCRIPTION

Timewarrior est un outil de suivi temporel en ligne de commande. Il vous permet de suivre facilement votre temps et de générer des rapports de synthèse.

Ceci est une référence, pas un tutoriel. Si vous cherchez un tutoriel, consultez la documentation en ligne ici :

https://timewarrior.net/docs/

Lorsque exécuté sans arguments ni options, la commande par défaut est exécutée, indiquant s'il y a un suivi actif, et si c'est le cas, affiche un résumé et se termine avec le code 0. S'il n'y a pas de suivi temporel actif, le code de sortie est 1.

OPTIONS

--version

Affiche les informations de version de Timewarrior

--help

Affiche les informations d'utilisation de Timewarrior

COMMANDES TIMEWARRIOR

Timewarrior prend en charge de nombreuses commandes. Par ordre alphabétique :

timew-annotate(1)

Ajoute une annotation aux intervalles

timew-cancel(1)

Annule le suivi temporel

timew-config(1)

Récupère et définit la configuration de Timewarrior

timew-continue(1)

Reprend le suivi d'un intervalle existant

timew-day(1)

Affiche le graphique du jour

timew-delete(1)

Supprime des intervalles

timew-diagnostics(1)

Affiche des informations de diagnostic

timew-export(1)

Exporte le temps suivi au format JSON

timew-extensions(1)

Liste les extensions disponibles

timew-get(1)

Affiche les valeurs DOM

timew-help(1)

Affiche l'aide

timew-join(1)

Joint des intervalles

timew-lengthen(1)

Allonge les intervalles

timew-modify(1)

Modifie l'heure de début ou de fin d'un intervalle

timew-month(1)

Affiche le graphique du mois

timew-move(1)

Modifie l'heure de début d'un intervalle

timew-report(1)

Exécute un rapport d'extension

timew-resize(1)

Définit la durée d'un intervalle

timew-retag(1)

Remplace les étiquettes dans les intervalles

timew-shorten(1)

Raccourcit les intervalles

timew-show(1)

Affiche la configuration

timew-split(1)

Divise des intervalles

timew-start(1)

Démarre le suivi temporel

timew-stop(1)

Arrête le suivi temporel

timew-summary(1)

Affiche un résumé du suivi temporel

timew-tag(1)

Ajoute des étiquettes aux intervalles

timew-tags(1)

Affiche une liste d'étiquettes

timew-track(1)

Ajoute des intervalles à la base de données

timew-undo(1)

Annule les commandes Timewarrior

timew-untag(1)

Supprime des étiquettes des intervalles

timew-week(1)

Affiche le graphique de la semaine

FICHIERS

Systèmes non-Unix

~/.timewarrior/timewarrior.cfg

Fichier de configuration utilisateur.

~/.timewarrior/data/YYYY-MM.data

Fichiers de données de suivi temporel.

Systèmes Unix

${XDG_CONFIG_HOME:-$HOME/.config}/timewarrior/timewarrior.cfg

Fichier de configuration utilisateur si le répertoire hérité ~/.timewarrior n’existe pas.

${XDG_DATA_HOME:-$HOME/.local/share}/timewarrior/data/YYYY-MM.data

Fichiers de données de suivi temporel si le répertoire hérité ~/.timewarrior n’existe pas.
