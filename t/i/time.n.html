time(n) Commandes intégrées Tcl time(n)

NOM

time - Chronométrer l'exécution d'un script

SYNTAXE

time script ?compte?

DESCRIPTION

Cette commande appellera l'interpréteur Tcl compte fois pour évaluer script (ou une fois si compte n'est pas spécifié). Elle renverra ensuite une chaîne de la forme

503.2 microsecondes par itération

qui indique le temps moyen requis par itération, en microsecondes. Le temps est mesuré en temps écoulé, pas en temps CPU.

EXEMPLE

Estimer le temps nécessaire à une simple boucle for Tcl pour compter jusqu'à mille :

time {
    for {set i 0} {$i<1000} {incr i} {
        # corps vide
    }
}

MOTS CLÉS
