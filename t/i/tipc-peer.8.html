NOM

tipc-peer - modifier les informations du pair

SYNTAXE


tipc peer remove address ADRESSE

OPTIONS

Options (indicateurs) pouvant être passées n'importe où dans la chaîne de commandes.

-h, --help
Afficher l'aide sur la dernière commande valide. Par exemple, tipc peer --help affichera l'aide pour 'peer' et tipc --help affichera l'aide générale. La position de l'option dans la chaîne est indifférente.

DESCRIPTION

Pair supprimer

Supprime un nœud pair hors ligne des structures de données locales. Le pair est identifié par son adresse.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi ou un entier positif en cas d'échec.
