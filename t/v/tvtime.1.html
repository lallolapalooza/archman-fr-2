NOM

tvtime - une application de télévision de haute qualité

SYNOPSIS

tvtime [ OPTION ] ...

DESCRIPTION

tvtime est une application de télévision de haute qualité destinée à être utilisée avec des cartes d'acquisition vidéo. tvtime traite l'entrée d'une carte d'acquisition et l'affiche sur un moniteur d'ordinateur ou un projecteur.

tvtime prend en charge :

  • Une sortie désentrelacée au taux complet de 59,94 images par seconde pour une source NTSC, ou 50 images par seconde pour des sources PAL. Cela offre une fluidité de mouvement et une haute qualité visuelle.
  • Plusieurs algorithmes de désentrelacement pour trouver le mode optimal pour le contenu vidéo et la vitesse du processeur disponible.
  • Un mode d'affichage 16:9 pour la plus haute résolution disponible lors du traitement de l'entrée d'un lecteur DVD externe ou d'un récepteur satellite numérique.
  • Un affichage à l'écran super-élégant pour une expérience télévisuelle complète, avec un système de menu riche en fonctionnalités.

OPTIONS

-a, --widescreen
Cette option démarre tvtime en mode d'affichage 16:9.
-A, --nowidescreen
Cette option démarre tvtime en mode d'affichage 4:3.
-h, --help
Afficher les informations d'utilisation.
-k, --slave
Désactive l'entrée clavier dans tvtime pour le mode esclave. Le mode esclave a été ajouté pour l'intégration avec des applications PVR comme freevo ou mythtv, afin que freevo puisse gérer l'entrée clavier pendant que tvtime fonctionne. En mode esclave, les frappes sont ignorées mais elles sont imprimées sur la sortie standard, et les commandes sont lues depuis l'entrée standard dans la même syntaxe que tvtime-command.
-m, --fullscreen
Démarrer tvtime en mode plein écran.
-M, --window
Démarrer tvtime en mode fenêtré.
-s, --showdrops
Afficher les informations de saut d'images (pour le débogage).
-S, --saveoptions
Enregistre les options de la ligne de commande dans le fichier de configuration. Cela enregistrera le périphérique V4L, le périphérique VBI, le numéro d'entrée, la norme, la fréquence, le réglage de démarrage en plein écran, le rapport d'aspect, le mode verbeux et la hauteur de la fenêtre de sortie.
-v, --verbose
Le réglage verbeux indique que nous devons afficher des messages d'information et d'avertissement complets sur la sortie d'erreur standard pendant l'exécution de tvtime. Sinon, seuls les erreurs critiques seront affichées.
-F, --configfile=FICHIER
Fichier de configuration supplémentaire pour charger les paramètres.
-g, --geometry=GEOMETRIE
Définit la géométrie de la fenêtre, par exemple, 400x300 pour une fenêtre de 400 pixels de large et 300 pixels de haut. Une valeur de largeur de 0 signifie que la largeur appropriée pour la hauteur donnée sera utilisée. Pour du contenu 4:3 sur un écran à pixels carrés, cela utilise par défaut une fenêtre de 768×576.
-I, --inputwidth=ECHANTILLONNAGE
Échantillonnage des lignes de balayage d'entrée V4L (par défaut 720. Ceci définit le nombre de pixels par ligne de balayage à demander à la carte d'acquisition. Un réglage plus élevé donne une meilleure qualité, tandis qu'un réglage plus bas signifie moins de travail, et donc tvtime s'exécutera plus rapidement. Si vous avez un CPU plus lent (par exemple, moins de 500 MHz environ), des valeurs de 480 ou 400 pourraient vous convenir. Pour une meilleure qualité, choisissez une valeur élevée comme 720 ou 768. De nombreuses cartes d'acquisition ne peuvent pas échantillonner au-delà de 768 pixels par ligne de balayage.
-d, --device=NOM
Périphérique video4linux à utiliser (par défaut /dev/video0).
-b, --vbidevice=PERIPHERIQUE
Périphérique VBI à utiliser (par défaut /dev/vbi0).
-i, --input=NUMEROENTREE
Numéro d'entrée video4linux (par défaut 0). Les cartes ont couramment plusieurs sources, par exemple, sur ma carte WinTV, la source 0 est mon tuner et la source 1 est l'entrée composite.
-c, --channel=CHAINE
Au démarrage, tvtime syntonise la chaîne donnée. Sinon, les chaînes du fichier de configuration seront utilisées.
-n, --norm=NORME
Le mode dans lequel régler le tuner (par défaut NTSC). Les modes valides sont :
• NTSC
• PAL
• SECAM
• PAL-NC
• PAL-M
• PAL-N
• NTSC-JP
-f, --frequencies=NOM
Les chaînes que vous recevez avec le tuner (par défaut us-cable). Les valeurs valides sont :
• us-cable
• us-broadcast
• japan-cable
• japan-broadcast
• europe
• australia
• australia-optus
• newzealand
• france
• russia
• custom (première exécution 'tv tvtime(1) — tvtime

NAME

tvtime - TV viewer for Linux

SYNOPSIS

tvtime [OPTIONS]

DESCRIPTION

tvtime is a TV viewer for Linux that uses the Video4Linux API. It is designed to be a simple and easy-to-use application for watching television on your computer.

USAGE

Run tvtime from the command line. Use the keyboard shortcuts or the graphical interface to control playback, change channels, and adjust settings.

OPTIONS

-b, --blur
Enables blurring of the video image.
-c, --capture
Enables video capture mode.
-d, --driver=DRIVER
Specify the video driver to use (e.g., 'v4l', 'v4l2').
-f, --fullscreen
Start in fullscreen mode.
-h, --help
Display a help message and exit.
-i, --input=INPUT
Specify the video input device (e.g., '/dev/video0').
-m, --menu
Display the configuration menu on startup.
-n, --nomenus
Disable all menus.
-p, --preset=NAME
Load a preset configuration.
-s, --scan
Scan for available channels.
-t, --subtitles
Enable subtitle display.
-v, --version
Display version information and exit.
-x, --xmltv=FILE
Read XMLTV listings from the specified file for OSD display. Channels are looked up by name. tvtime displays the show title, subtitle, and description on the OSD.
-X, --xmltvlanguage=LANG
Use XMLTV data in the specified language if available. Use two-letter language codes (e.g., 'de' for German). Defaults to the language specified in the file if unset or set to 'none'.
-D, --display=DISPLAY
Use the specified X display to connect to.
-m, --mixer=DEVICE[:CH]
The mixer device and channel for volume controls (defaults to /dev/mixer:line). Valid channels include:
• vol
• bass
• treble
• synth
• pcm
• speaker
• line
• mic
• cd
• mix
• pcm2
• rec
• igain
• ogain
• line1
• line2
• line3
• dig1
• dig2
• dig3
• phin
• phout
• video
• radio
• monitor
