tvtime-configure(1) Manuel des commandes générales tvtime-configure(1)

NOM

tvtime-configure - modifier les paramètres dans le fichier de configuration tvtime

SYNTAXE

tvtime-configure [ OPTION ] ...

DESCRIPTION

tvtime-configure permet à un utilisateur de définir les paramètres de configuration pour tvtime sans démarrer l'application. Ceci est utile pour les programmes d'installation tels que debconf afin de leur permettre de configurer tvtime sans avoir à écrire un analyseur pour le fichier de configuration. Les options de ligne de commande sont un sous-ensemble de celles de tvtime lui-même.

OPTIONS

-a, --widescreen
Cette option démarre tvtime en mode de format 16:9.
-A, --nowidescreen
Cette option démarre tvtime en mode de format 4:3.
-h, --help
Afficher les informations d'utilisation.
-m, --fullscreen
Démarrer tvtime en mode plein écran.
-M, --window
Démarrer tvtime en mode fenêtré.
-p, --fspos=POS
Définir la position de la fenêtre en plein écran. Utilisez ceci si vous avez un projecteur pour aider tvtime à s'adapter correctement à votre écran.
• top
† bottom
† centre (par défaut)
-F, --configfile=FICHIER
Fichier de configuration supplémentaire à charger à partir duquel les paramètres sont lus.
-H, --height=HAUTEUR
Définit la hauteur de la fenêtre de sortie au démarrage en lignes de balayage. La taille de fenêtre de sortie par défaut est de 576 lignes de balayage.
-I, --inputwidth=ÉCHANTILLONNAGE
Échantillonnage des lignes de balayage d'entrée V4L (par défaut 720. Ceci définit le nombre de pixels par ligne de balayage à demander à la carte d'acquisition. Un réglage plus élevé donne une meilleure qualité, tandis qu'un réglage plus bas signifie moins de travail, et donc tvtime fonctionnera plus rapidement. Si vous avez un processeur plus lent (comme, moins de 500 MHz environ), des valeurs de 480 ou 400 pourraient vous convenir le mieux. Pour une meilleure qualité, choisissez une valeur élevée comme 720 ou 768. De nombreuses cartes d'acquisition ne peuvent pas échantillonner plus de 768 pixels par ligne de balayage.
-d, --device=NOM
Périphérique video4linux à utiliser (par défaut /dev/video0).
-b, --vbidevice=PÉRIPHÉRIQUE
Périphérique VBI à utiliser (par défaut /dev/vbi0).
-i, --input=NUMÉRO_ENTRÉE
Numéro d'entrée video4linux (par défaut 0). Les cartes ont couramment plusieurs sources, par exemple, sur ma carte WinTV, la source 0 est mon tuner et la source 1 est l'entrée composite.
-c, --channel=CHAÎNE
Au démarrage, tvtime se syntonise sur la chaîne donnée. Sinon, les chaînes du fichier de configuration seront utilisées.
-n, --norm=NORM
Le mode auquel le tuner doit être réglé (par défaut NTSC). Les modes valides sont :
• NTSC
• PAL
• SECAM
• PAL-NC
• PAL-M
• PAL-N
• NTSC-JP
-f, --frequencies=NOM
Les chaînes que vous recevez avec le tuner (par défaut us-cable). Les valeurs valides sont :
• us-cable
• us-broadcast
• japan-cable
• japan-broadcast
• europe
• australia
• australia-optus
• newzealand
• france
• russia
-R, --priority=PRI
Définit la priorité du processus (voir nice(1)) à laquelle tvtime doit être exécuté.
-t, --xmltv=FICHIER
Lit les listes XMLTV du fichier donné pour les afficher sur l'OSD. Les chaînes sont recherchées en fonction de leur nom, et tvtime affichera le titre du spectacle, le sous-titre et la description du spectacle sur l'OSD.
-l, --xmltvlanguage=LANG
Utilise les données XMLTV dans la langue donnée, si disponible. Les langues sont représentées par leur code langue à deux lettres (par exemple, "fr" pour le français). La langue par défaut utilisée dans le fichier sera utilisée si ce paramètre est absent ou défini sur "none".
-x, --mixer=PÉRIPHÉRIQUE[:CH]
Le périphérique et le canal du mixeur pour les contrôles de volume. (par défaut /dev/mixer:line). Les canaux valides sont :
• vol
• bass
• treble
• synth
• pcm
• speaker
• line
• mic
• cd
• mix
• pcm2
• rec
• igain
• ogain
• line1
• line2
• line3
• dig1
• dig2
• dig3
• phin
• phout
• video
• radio
• monitor
