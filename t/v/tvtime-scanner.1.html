tvtime-scanner(1) Manuel des commandes générales tvtime-scanner(1)

NOM

tvtime-scanner - un scanner toutes bandes pour tvtime afin d'aider les utilisateurs des fournisseurs de câble européens qui n'utilisent pas de fréquences standard

SYNTAXE

tvtime-scanner [ OPTION ] ...

DESCRIPTION

tvtime-scanner permet à l'utilisateur de scanner toutes les fréquences pour les stations. Ceci est utile pour les fournisseurs de câble européens tels que UPC ou Casema qui n'utilisent pas de tables de fréquences standard pour leurs chaînes. tvtime-scanner vérifie les fréquences sur toute la bande et l'écrit dans votre fichier stationlist.xml dans une table appelée "Custom". Ceci peut être sélectionné en exécutant "tvtime --frequencies=custom" ou en sélectionnant la table de fréquences personnalisée dans le menu OSD de tvtime.

OPTIONS

-h, --help
Afficher les informations d'utilisation.
-F, --configfile=FICHIER
Fichier de configuration supplémentaire pour charger les paramètres.
-d, --device=NOM
Périphérique video4linux à utiliser (par défaut /dev/video0).
-i, --input=NUMENTREE
Numéro d'entrée video4linux (par défaut 0). Les cartes ont couramment plusieurs sources, par exemple, sur ma carte WinTV, la source 0 est mon tuner et la source 1 est l'entrée composite. Le scanner nécessite d'utiliser une entrée qui possède un tuner.
-n, --norm=NORM
Le mode dans lequel régler le tuner (par défaut NTSC). Les modes valides sont :
• NTSC
• PAL
• SECAM
• PAL-NC
• PAL-M
• PAL-N
• NTSC-JP
