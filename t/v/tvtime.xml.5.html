tvtime.xml(5) Manuel des formats de fichiers tvtime.xml(5)

NOM

tvtime.xml - fichier de configuration de tvtime

SYNTAXE

~/.tvtime/tvtime.xml
/etc/tvtime/tvtime.xml

DESCRIPTION

Le fichier tvtime.xml est le fichier de configuration principal de tvtime. Il contient tous les paramètres par défaut et les raccourcis clavier. Le fichier tvtime.xml est mis à jour par tvtime pendant l'exécution, pour enregistrer les paramètres entre les sessions. Pour cette raison, vous ne devez pas modifier le fichier tvtime.xml pendant que tvtime est en cours d'exécution, car vos modifications pourraient être écrasées.

La syntaxe globale est la suivante :


<?xml version="1.0"?>
<!DOCTYPE tvtime PUBLIC "-//tvtime//DTD tvtime 1.0//EN"
"http://tvtime.sourceforge.net/DTD/tvtime1.dtd">
<tvtime xmlns="http://tvtime.sourceforge.net/DTD/">
</tvtime>

Vous pouvez trouver le DTD et d'autres informations sur les fichiers de configuration XML à l'adresse http://tvtime.sourceforge.net/DTD/

OPTIONS

tvtime prend en charge une multitude d'options. La balise <option> doit être contenue dans une balise <tvtime>.

Voici une liste des options et de leurs valeurs par défaut, avec une description de ce que fait l'option.

<option name="Verbose" value="0"/>
Le paramètre verbeux indique que nous devrions afficher des messages d'information et d'avertissement complets sur la sortie d'erreur standard pendant l'exécution de tvtime. Sinon, seules les erreurs fatales seront affichées en sortie.
<option name="V4LDevice" value="/dev/video0"/>
Ceci définit le périphérique de capture par défaut à utiliser.
<option name="V4LInput" value="0"/>
Ceci définit l'entrée de la carte de capture par défaut à ouvrir par tvtime. Par exemple, ma carte WinTV a le tuner comme source 0, et son entrée composite comme source 1. Les sources peuvent être modifiées à l'exécution à l'aide de la commande toggle_input, qui est la commande clavier “i” par défaut.
<option name="Norm" value="NTSC"/>
Ceci définit la norme TV par défaut. Les options valides sont :
• NTSC
• NTSC-JP
• SECAM
• PAL
• PAL-Nc
• PAL-M
• PAL-N
• PAL-60
<option name="SaveAndRestorePictureSettings" value="1"/>
Cette option indique si tvtime doit activer sa propre sauvegarde et restauration des paramètres d'image, à la fois au démarrage et lors du changement de chaîne.
<option name="AudioMode" value="stereo"/>
Cette option enregistre le dernier mode audio utilisé. Il sera utilisé pour se souvenir du mode audio à sélectionner lors du prochain démarrage de l'application. Les options valides ici sont "mono", "stereo", "lang1", "lang2" ou "sap".
<option name="AudioBoost" value="-1"/>
Cette option définit le boost audio. Il s'agit d'un pourcentage pour savoir jusqu'où régler le volume sortant de la carte de capture. Par défaut, tvtime ne régle pas du tout le volume. Cependant, comme le volume n'a parfois pas de valeur par défaut sensée, ou est réinitialisé par d'autres applications, vous pouvez utiliser cette valeur pour qu'il soit toujours réglé à votre volume préféré. Utilisez -1 pour que tvtime ne touche pas au volume.
<option name="ShowCC" value="0"/>
Cette option enregistre l'état du décodage des sous-titres. Les sous-titres sont une version texte spécifique à NTSC de l'audio pour les malentendants.
<option name="ColourInvert" value="0"/>
Cette valeur enregistre l'état marche/arrêt du filtre d'inversion de couleur entre les sessions.
<option name="MirrorInput" value="0"/>
Cette valeur enregistre l'état marche/arrêt du filtre miroir entre les sessions.
<option name="Frequencies" value="US-Cable"/>
Définit la table de fréquences par défaut à utiliser pour les tuners trouvés. Les possibilités sont :
• us-cable
• us-broadcast
• japan-cable
• japan-broadcast
• europe
• australia
• australia-optus
• newzealand
• france
• russia
<option name="NTSCCableMode" value="Standard"/>
Il existe deux normes spéciales de câble NTSC aux États-Unis : IRC et HRC. En mode IRC, les canaux 5 et 6 sont sur des fréquences différentes, et le mode HRC décale toutes les fréquences vers le haut de 1,25 MHz (et est également particulier sur les canaux 5 et 6). Utilisez cette option pour régler le mode câble sur Standard, IRC ou HRC. Il est très rare de rencontrer des systèmes de câble utilisant IRC ou HRC.
<option name="CheckForSignal" value="1"/>
Active/désactive la vérification par tvtime s'il y a un signal présent lors du changement de chaîne, etc. Si votre carte n'est pas nulle, vous n'aurez pas besoin de désactiver cela. La désactivation de cette fonctionnalité désactivera également le scanner de canaux.
<option name="InputWidth" value="720"/>
Définit le nombre de pixels par ligne de balayage à demander à la carte de capture. Une valeur plus élevée offre une meilleure qualité, tandis qu'une valeur plus faible signifie moins de travail, et donc tvtime fonctionnera plus rapidement. Si vous avez un CPU plus lent (par exemple, moins de 500 MHz ou similaire), des valeurs de 480 ou 400 pourraient vous convenir. Pour une meilleure qualité, choisissez une valeur élevée comme 720 ou 768. La plupart des cartes de capture ne peuvent pas échantillonner au-delà de 768 pixels par ligne de balayage.
<option name="XMLTVFile" value="none"/>
Définissez-le sur un nom de fichier pour obtenir les listes d'émissions à partir d'un fichier xmltv. Définissez-le sur "none" si vous ne souhaitez pas utiliser xmltv.
<option name="XMLTVLanguage" value="none"/>
Définissez-le sur un code langue à deux lettres pour spécifier la langue à utiliser pour les entrées dans le fichier XMLTV (par exemple, utilisez "de" pour l'allemand). Définissez-le sur "none" si vous souhaitez utiliser la langue par défaut du fichier.
<option name="UseXDS" value="0"/>
Définissez-le sur 1 pour activer le décodage des informations de canal XDS. Cette option est spécifique aux régions NTSC. XDS est utilisé pour envoyer des informations sur le canal, y compris le nom du réseau et les lettres d'appel, et parfois des informations sur l'émission en cours.
<option name="VBIDevice" value="/dev/vbi0"/>
Définit quel périphérique utiliser pour le décodage VBI.
<option name="MixerDevice" value="/dev/mixer:line"/>
Définit le périphérique et le canal du mixeur à utiliser. Le format est nom du périphérique:nom du canal pour le mixeur OSS (par exemple, "/dev/mixer:Line") ou périphérique/canal pour ALSA (par exemple, "hw:0/CD").

Les canaux OSS valides sont :

vol, bass, treble, synth, pcm, speaker, line, mic, cd, mix, pcm2, rec, igain, ogain, line1, line2, line3, dig1, dig2, dig3, phin, phout, video, radio, monitor

OPTIONS

<option name="SquarePixels" value="1"/>
Désactiver cette option indique à tvtime d'utiliser le DPI du serveur X pour déterminer la forme des pixels. Par défaut, tvtime suppose que les pixels sont carrés. Réglez cette option sur 0 si vous avez un moniteur 4:3 mais l'exécutez en 1280x1024 et que vous voulez que tvtime fasse la bonne chose.
<option name="Widescreen" value="0"/>
Cette option active le mode de format d'image 16:9 au démarrage.
<option name="WindowGeometry" value="0x576"/>
Définit la géométrie de la fenêtre. Une valeur de largeur de 0 signifie que la largeur appropriée pour la hauteur donnée sera utilisée. Pour un contenu 4:3 sur un écran à pixels carrés, cela donne par défaut une fenêtre de 768×576.
<option name="Overscan" value="0.0"/>
Ceci définit le pourcentage des bords à laisser à la surbalayage (overscan), c'est-à-dire, ne pas les montrer du tout. La zone d'action sûre sur un téléviseur est de 10% dans le surbalayage, mais c'est un peu restrictif. Si vous voulez que tvtime ressemble à une télévision, une bonne valeur serait d'environ 6 à 8 %. La valeur est en pourcentage, donc pour 8%, utilisez 8.0.
<option name="Fullscreen" value="0"/>
Réglez cette option sur 1 pour que tvtime démarre en mode plein écran. Ce paramètre est défini à l'exécution afin que lorsque vous quittez tvtime en mode plein écran, le redémarrer le relance en mode plein écran.
<option name="AlwaysOnTop" value="0"/>
Réglez cette option sur 1 pour que tvtime démarre en mode toujours au premier plan sous les gestionnaires de fenêtres compatibles. Ce paramètre est défini à l'exécution afin que lorsque vous quittez tvtime en mode toujours au premier plan, le redémarrer le relance en mode toujours au premier plan.
<option name="FullscreenPosition" value="Centre"/>
Définit la position de la sortie en mode plein écran : top (haut), bottom (bas) ou centre. Lorsqu'elle est réglée sur top, tvtime en mode plein écran placera sa sortie en haut de l'écran. Utilisez cela si vous avez un projecteur pour aider tvtime à s'adapter correctement à votre écran.
<option name="FramerateMode" value="0"/>
Ceci définit la fréquence d'images de la sortie de tvtime.
0
Mode fréquence d'images complète, chaque trame est désentrelacée. 59.94fps pour NTSC, 50fps pour PAL.
1
Mode fréquence d'images réduite, désentrelacer chaque trame supérieure en une image (TFF). 29.97fps pour NTSC, 25fps pour PAL.
2
Mode fréquence d'images réduite, désentrelacer chaque trame inférieure en une image (BFF). 29.97fps pour NTSC, 25fps pour PAL.
Les deux modes de fréquence d'images réduite sont utiles pour le contenu progressif des consoles de jeux vidéo. Utilisez le tressage (weave) et sélectionnez TFF ou BFF, celui qui n'affiche pas d'effets d'entrelacement.
<option name="QuietScreenshots" value="0"/>
Lorsque cette option est activée, les captures d'écran ne s'annoncent pas sur l'OSD. C'est utile si vous avez l'intention de prendre beaucoup de captures d'écran et que vous ne voulez pas que le texte interrompe votre visionnage de télévision ou apparaisse dans d'autres captures d'écran.
<option name="ProcessPriority" value="-10"/>
Définit la priorité du processus par défaut. Par défaut, tvtime essaie de se définir à une priorité de -10, ce qui est supérieur aux applications normales. Les valeurs acceptables vont de -20 à 20, les valeurs les plus basses signifiant une priorité plus élevée.
<option name="TimeFormat" value="%X"/>
Définit le format de l'heure utilisé dans l'affichage à l'écran de tvtime. Le format est une chaîne dans le même format que strftime(3). Par défaut, il utilise le format horaire de votre locale.
<option name="ScreenShotDir" value="~"/>
Ceci est le répertoire par défaut dans lequel les captures d'écran sont placées. Par défaut, elles sont sauvegardées dans le répertoire personnel de l'utilisateur.
<option name="ChannelTextFG" value="0xFFFFFF00"/>
<option name="OtherTextFG" value="0xFFF5DEB3"/>
Ces options définissent les couleurs ARGB utilisées pour le texte dans l'affichage à l'écran. La couleur par défaut pour le nom de la chaîne est le « jaune » (0xffffff00), et la couleur par défaut pour le texte environnant est le « blé » (0xfff5deb3). Le format de couleur peut être hexadécimal ou décimal. Si le canal alpha n'est pas spécifié, la valeur par défaut est « opaque » (255).
Exemples :
0xffaadd, 0xff0000ff, 0xff, 0xffff, 255 255 0, 0, 16777215.
<option name="UnmuteVolume" value="-1"/>
Ce paramètre sauvegarde le volume avant de le couper entre les sessions tvtime. Vous ne devriez jamais avoir besoin de le définir vous-même.
<option name="Muted" value="0"/>
Ce paramètre sauvegarde si tvtime était muet ou non lors de sa dernière sortie. Vous ne devriez jamais avoir besoin de le définir vous-même.
<option name="MuteOnExit" value="0"/>
Ce paramètre contrôle si tvtime doit couper son périphérique mixeur à la sortie. Utilisez-le pour contourner les problèmes avec des cartes de capture bruyantes.
<option name="ShowTaglines" value="1"/>
Ce paramètre contrôle si tvtime doit afficher les phrases d'accroche amusantes dans la barre de titre de la fenêtre. Réglez sur 0 pour les désactiver.
<option name="PrevChannel" value="2"/>
Ce paramètre est sauvegardé à l'exécution pour se souvenir de la chaîne précédente.
<option name="Channel" value="2"/>
Ce paramètre est sauvegardé à l'exécution pour se souvenir de la chaîne actuelle.
<option name="DeinterlaceMethod" value="AdaptiveAdvanced"/>
Ce paramètre est sauvegardé à l'exécution pour se souvenir du désentrelaceur utilisé.

Les désentrelaceurs supportés sont :

TelevisionFull
Télévision : Pleine Résolution
TelevisionHalf
Télévision : Résolution Demi
BlurVertical
Flou : Vertical
BlurTemporal
Flou : Temporel
AdaptiveSearch
Adaptatif au mouvement : Recherche de mouvement
AdaptiveAdvanced
Adaptatif au mouvement : Détection avancée
AdaptiveSimple
Adaptatif au mouvement : Détection simple
ProgressiveTFF
Progressif : Trame supérieure d'abord
ProgressiveBFF
Progressif : Trame inférieure d'abord

BINDINGS

Les frappes de touches et les clics de boutons de souris peuvent être associés à des commandes tvtime. Pour une description de chaque commande, voir tvtime-command(1).

Plusieurs touches et boutons de souris peuvent être liés à la même commande. Pour plus de commodité, tvtime fournit des alias pour les touches spéciales. Les touches spéciales connues de tvtime sont :

Up, Down, Left, Right, Insert, Home, End,R PageUp, PageDown, F1, F2, F3, F4, F5, F6, F7, F8, F9, F10, F11, F12, F13, F14, F15, Backspace, Escape, Enter, Print, Menu

Un exemple de liaison de touche serait pour la commande CHANNEL_INC. Dans ce cas, nous avons deux touches (Up et k) liées à la commande ainsi qu'un bouton de souris (4).


<bind command="channel_inc">
<keyboard key="up"/>
<keyboard key="k"/>
<mouse button="4"/>
</bind>

Certaines commandes peuvent prendre des arguments, par exemple, la commande SCREENSHOT peut prendre un argument pour le nom du fichier. Les arguments peuvent être donnés à une liaison de touche comme suit :


<bind command="screenshot" argument="/tmp/last-screenshot.png">
<keyboard key="s"/>
</bind>
