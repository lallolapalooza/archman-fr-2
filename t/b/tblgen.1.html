NOM

tblgen - Description en code C++

SYNTAXE

clang-tblgen [options] [fichier]

lldb-tblgen [options] [fichier]

llvm-tblgen [options] [fichier]

mlir-tblgen [options] [fichier]

DESCRIPTION

*-tblgen est une famille de programmes qui traduisent des fichiers de description de cible (.td) en code C++ et autres formats de sortie. La plupart des utilisateurs de LLVM n'auront pas besoin d'utiliser ce programme. Il est uniquement utilisé pour l'écriture de parties du compilateur, du débogueur et des backends de cible LLVM.

Les détails de l'entrée et de la sortie des programmes *-tblgen dépassent le cadre de cette courte introduction ; veuillez consulter l'aperçu de TableGen <> pour une introduction et des références à des documents supplémentaires sur TableGen.

L'argument fichier spécifie le nom du fichier de Description de Cible (.td) que TableGen traite.

OPTIONS

Options Générales

-help
Affiche une description des options de la ligne de commande.
-help-list
Affiche une description des options de la ligne de commande dans un format de liste simple.
-D=nom_macro
Spécifie le nom d'une macro à définir. Le nom est défini, mais il n'a pas de valeur particulière.
-d=fichier
Spécifie le nom du fichier de dépendances.
-debug
Active la sortie de débogage.
-dump-json
Affiche une représentation JSON de tous les enregistrements, adaptée à un traitement automatisé ultérieur.
-I répertoire
Spécifie où trouver d'autres fichiers de description de cible pour l'inclusion. La valeur répertoire doit être un chemin complet ou partiel vers un répertoire contenant des fichiers de description de cible.
-null-backend
Analyse les fichiers source et construit les enregistrements, mais n'exécute aucun backend. Ceci est utile pour chronométrer le frontend.
-o fichier
Spécifie le nom du fichier de sortie. Si fichier est -, alors *-tblgen envoie sa sortie à la sortie standard.
-print-records
Affiche toutes les classes et tous les enregistrements sur la sortie standard (option de backend par défaut).
-print-detailed-records
Affiche un rapport détaillé de toutes les variables globales, classes et enregistrements sur la sortie standard.
-stats
Affiche un rapport avec toutes les statistiques collectées par le backend.
-time-phases
Chronomètre les phases de l'analyseur et du backend et affiche un rapport.
-version
Affiche le numéro de version du programme.
-write-if-changed
Écrit le fichier de sortie uniquement s'il est nouveau ou a été modifié.

NAME

tblgen

TableGen — A generic table driven code generator

SYNOPSIS

tblgen [options] [input file]

DESCRIPTION

tblgen is a generic table driven code generator. It is used extensively within the LLVM infrastructure for tasks such as generating instruction descriptions, register information, and other machine-specific details from textual descriptions.

The tool reads a description file written in a specific domain-specific language (DSL), processes it, and generates output code based on the specified options.

Generate instruction emitter code.
