Paquet: tcl

tell(n) Commandes intégrées Tcl tell(n)

NOM

tell - Retourne la position d'accès actuelle pour un canal ouvert

SYNTAXE

tell channelId

DESCRIPTION

Retourne une chaîne d'entiers donnant la position d'accès actuelle dans channelId. La valeur retournée est un décalage d'octets qui peut être passé à seek afin de positionner le canal à un endroit particulier. Notez que cette valeur est en octets, et non en caractères comme avec read. La valeur retournée est -1 pour les canaux qui ne supportent pas le déplacement.

ChannelId doit être un identifiant pour un canal ouvert tel qu'un canal standard Tcl (stdin, stdout, ou stderr), la valeur de retour d'une invocation de open ou socket, ou le résultat d'une commande de création de canal fournie par une extension Tcl.

EXEMPLE

Lire une ligne d'un canal de fichier uniquement si elle commence par foobar :

# Sauvegarder le décalage au cas où nous aurions besoin d'annuler la lecture...
set offset [tell $chan]
if {[read $chan 6] eq "foobar"} {
    gets $chan line
} else {
    set line {}
    # Annuler la lecture...
    seek $chan $offset
}
