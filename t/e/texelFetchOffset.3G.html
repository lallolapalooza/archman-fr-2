TEXELFETCHOFFSET(3G) [FIXME: manuel] TEXELFETCHOFFSET(3G)

NOM

texelFetchOffset - effectue une recherche d'un seul texel dans une texture avec un décalage

DECLARATION

gvec4 texelFetchOffset(gsampler1D sampler, int P, int lod, int offset);

gvec4 texelFetchOffset(gsampler2D sampler, ivec2 P, int lod, ivec2 offset);

gvec4 texelFetchOffset(gsampler3D sampler, ivec3 P, int lod, ivec3 offset);

gvec4 texelFetchOffset(gsampler2DRect sampler, ivec2 P, ivec2 offset);

gvec4 texelFetchOffset(gsampler1DArray sampler, ivec2 P, int lod, ivec2 offset);

gvec4 texelFetchOffset(gsampler2DArray sampler, ivec3 P, int lod, ivec2 offset);

PARAMÈTRES

sampler

Spécifie l'échantillonneur auquel est liée la texture à partir de laquelle les texels seront récupérés.

P

Spécifie les coordonnées de texture auxquelles la texture sera échantillonnée.

lod

S'il est présent, spécifie le niveau de détail dans la texture à partir duquel le texel sera récupéré.

offset

Spécifie le décalage, en texels, qui sera appliqué à P avant la recherche du texel.

DESCRIPTION

texelFetchOffset effectue une recherche d'un seul texel à partir des coordonnées de texture P dans la texture liée à sampler. Avant de récupérer le texel, le décalage spécifié dans offset est ajouté à P. offset doit être une expression constante. La couche de tableau est spécifiée dans le dernier composant de P pour les formes de tableau. Le paramètre lod (s'il est présent) spécifie le niveau de détail à partir duquel le texel sera récupéré. Le paramètre sample spécifie quel échantillon dans le texel sera renvoyé lors de la lecture à partir d'une texture multiserveur.

Documentation Linux

Bienvenue dans la documentation Linux. Ce guide fournit des informations sur l'utilisation et la gestion d'un système Linux.

Introduction

Linux est un système d'exploitation open source largement utilisé sur les serveurs, les ordinateurs de bureau et les appareils embarqués. Il est connu pour sa stabilité, sa flexibilité et sa sécurité.

Commandes de base

Voici quelques commandes Linux de base que vous trouverez utiles :

  • ls : Lister le contenu d'un répertoire.
  • cd : Changer de répertoire.
  • pwd : Afficher le répertoire de travail actuel.
  • mkdir : Créer un nouveau répertoire.
  • rm : Supprimer des fichiers ou des répertoires.
  • cp : Copier des fichiers ou des répertoires.
  • mv : Déplacer ou renommer des fichiers ou des répertoires.
  • man : Afficher le manuel d'une commande.

Gestion des paquets

La gestion des paquets est le processus d'installation, de mise à jour et de suppression de logiciels sur un système Linux. Les deux systèmes de gestion de paquets les plus courants sont :

APT (Debian/Ubuntu)

Pour les distributions basées sur Debian comme Ubuntu, vous utiliserez le gestionnaire de paquets APT.

  • sudo apt update : Met à jour la liste des paquets disponibles.
  • sudo apt upgrade : Met à niveau les paquets installés vers leurs dernières versions.
  • sudo apt install : Installe un nouveau paquet.
  • sudo apt remove : Supprime un paquet.

YUM/DNF (Fedora/CentOS/RHEL)

Pour les distributions basées sur Red Hat comme Fedora, CentOS et RHEL, vous utiliserez YUM (plus ancien) ou DNF (plus récent).

  • sudo yum update ou sudo dnf update : Met à jour tous les paquets installés.
  • sudo yum install ou sudo dnf install : Installe un nouveau paquet.
  • sudo yum remove ou sudo dnf remove : Supprime un paquet.

Fichiers et répertoires

Comprendre la structure des fichiers Linux est essentiel. Voici quelques répertoires importants :

  • / : Le répertoire racine.
  • /home : Contient les répertoires personnels des utilisateurs.
  • /etc : Contient les fichiers de configuration du système.
  • /var : Contient les fichiers variables tels que les journaux et les caches.
  • /bin : Contient les exécutables binaires essentiels.
  • /usr : Contient les applications et les utilitaires.
