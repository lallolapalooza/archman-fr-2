TEXTDOMAIN(3) Manuel des fonctions de bibliothèque TEXTDOMAIN(3)

NOM

textdomain - définir le domaine pour les appels gettext() futurs

SYNTAXE

#include <libintl.h>

char * textdomain (const char * domainname);

DESCRIPTION

La fonction textdomain définit ou récupère le domaine de messages courant.

Un domaine de messages est un ensemble de messages msgid traduisibles. Généralement, chaque paquet logiciel possède son propre domaine de messages. Le nom du domaine est utilisé pour déterminer le catalogue de messages où une traduction est recherchée ; il doit s'agir d'une chaîne non vide.

Le domaine de messages courant est utilisé par les fonctions gettext, ngettext, et par les fonctions dgettext, dcgettext, dngettext et dcngettext lorsqu'elles sont appelées avec un argument domainname NULL.

Si domainname n'est pas NULL, le domaine de messages courant est défini à domainname. La chaîne que la fonction stocke internelement est une copie de l'argument domainname.

Si domainname est NULL, la fonction renvoie le domaine de messages courant.

VALEUR DE RETOUR

En cas de succès, la fonction textdomain renvoie le domaine de messages courant, après l'avoir éventuellement modifié. La chaîne résultante est valide jusqu'au prochain appel à textdomain et ne doit être ni modifiée ni libérée. Si une erreur d'allocation mémoire se produit, elle définit errno à ENOMEM et renvoie NULL.

ERREURS

Les erreurs suivantes peuvent survenir, entre autres :

ENOMEM
Pas assez de mémoire disponible.

BOGUES

Le type de retour devrait être const char *, mais c'est char * pour éviter les avertissements dans le code C antérieur à ANSI C.

VOIR AUSSI

gettext(3), ngettext(3), bindtextdomain(3), bind_textdomain_codeset(3)
