NOM

texlinks - maintenir les liens symboliques des formats vers les moteurs

SYNTAXE

texlinks [ OPTIONS... ] RÉPERTOIRES...

DESCRIPTION

texlinks est utilisé pour créer ou recréer des liens symboliques des formats vers les moteurs selon les informations de fmtutil.cnf ou un fichier spécifié avec --cnffile.

RÉPERTOIRES est une liste optionnelle de répertoires dans lesquels opérer. Si aucun répertoire n'est spécifié, la liste des répertoires dépend de l'option --multiplatform.

OPTIONS

--cnffile FICHIER ou -f FICHIER
utiliser le fichier comme fichier de configuration (par défaut : fmtutil.cnf)
--help ou -h
afficher un texte d'aide
--multiplatform ou -m
opérer dans tous les répertoires spécifiques à la plateforme (par défaut : opérer uniquement dans le répertoire pour cette plateforme)
--silent ou -s
ignorer silencieusement les scripts/binaires existants au lieu d'imprimer un avertissement
--unlink ou -u
Supprimer les liens symboliques précédemment créés
--verbose ou -v
activer le mode verbeux (par défaut : désactivé)

FICHIERS

fmtutil.cnf
fichier de configuration par défaut

VOIR AUSSI

fmtutil(1), fmtutil.cnf(5)

Page web : https://tug.org/texlive/

BOGUES
