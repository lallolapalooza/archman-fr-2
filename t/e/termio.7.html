termio(7) Manuel d'informations diverses termio(7)

NOM

termio - Interface du pilote de terminal System V

DESCRIPTION

termio est le nom de l'ancienne interface du pilote de terminal System V. Cette interface définissait une structure termio utilisée pour stocker les paramètres du terminal, ainsi qu'une gamme d'opérations ioctl(2) pour obtenir et définir les attributs du terminal.

L'interface termio est maintenant obsolète : POSIX.1-1990 a standardisé une version modifiée de cette interface, sous le nom de termios. La structure de données POSIX.1 diffère légèrement de la version System V, et POSIX.1 a défini une suite de fonctions pour remplacer les diverses opérations ioctl(2) qui existaient dans System V. (Cela a été fait car ioctl(2) n'était pas standardisé, et son troisième argument variadique ne permet pas la vérification du type des arguments.)

Si vous cherchez une page appelée « termio », vous trouverez probablement la plupart des informations que vous recherchez dans termios(3) ou ioctl_tty(2).

VOIR AUSSI

reset(1), setterm(1), stty(1), ioctl_tty(2), termios(3), tty(4)
