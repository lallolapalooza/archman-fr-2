tep_get_header_page_size(3)

Paquet: libtraceevent

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manuel libtraceevent LIBTRACEEVENT(3)

NOM

tep_get_header_page_size, tep_get_header_timestamp_size, tep_is_old_format - Obtenir les données stockées dans la page d'en-tête, dans le contexte du noyau.

SYNTAXE

#include <event-parse.h>
int tep_get_header_page_size(struct tep_handle *tep);
int tep_get_header_timestamp_size(struct tep_handle *tep);
bool tep_is_old_format(struct tep_handle *tep);

DESCRIPTION

Ces fonctions récupèrent des informations du contexte du noyau, stockées dans les événements tracefs/header_page. Les anciens noyaux n'ont pas d'informations de page d'en-tête, donc les valeurs par défaut du contexte de l'espace utilisateur sont utilisées.

La fonction tep_get_header_page_size() retourne la taille d'un entier long, dans le contexte du noyau. L'argument tep est le contexte de l'analyseur d'événements de trace. Cette information est récupérée à partir du champ "commit" de tracefs events/header_page.

La fonction tep_get_header_timestamp_size() retourne la taille des horodatages, dans le contexte du noyau. L'argument tep est le contexte de l'analyseur d'événements de trace. Cette information est récupérée à partir du champ "timestamp" de tracefs events/header_page.

La fonction tep_is_old_format() retourne vrai si le noyau est antérieur à l'ajout de events/header_page, sinon elle retourne faux.

VALEUR DE RETOUR

La fonction tep_get_header_page_size() retourne la taille d'un entier long, en octets.

La fonction tep_get_header_timestamp_size() retourne la taille des horodatages, en octets.

La fonction tep_is_old_format() retourne vrai si un ancien noyau est utilisé pour générer les données de traçage, qui n'a pas event/header_page. Si le noyau est nouveau, ou si tep est NULL, faux est retourné.

EXEMPLE

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
        int longsize;
        int timesize;
        bool old;
        longsize = tep_get_header_page_size(tep);
        timesize = tep_get_header_timestamp_size(tep);
        old = tep_is_old_format(tep);
        printf ("%s kernel est utilisé pour générer les données de traçage.\n",
                old?"Ancien":"Nouveau");
        printf("La taille d'un entier long est de %d octets.\n", longsize);
        printf("La taille des horodatages est de %d octets.\n", timesize);
...
