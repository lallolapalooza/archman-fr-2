NOM

texture - récupère les texels d'une texture

DÉCLARATION

gvec4 texture(gsampler1D sampler, float P, [float bias]);

gvec4 texture(gsampler2D sampler, vec2 P, [float bias]);

gvec4 texture(gsampler3D sampler, vec3 P, [float bias]);

gvec4 texture(gsamplerCube sampler, vec3 P, [float bias]);

float texture(sampler1DShadow sampler, vec3 P, [float bias]);

float texture(sampler2DShadow sampler, vec3 P, [float bias]);

float texture(samplerCubeShadow sampler, vec4 P, [float bias]);

gvec4 texture(gsampler1DArray sampler, vec2 P, [float bias]);

gvec4 texture(gsampler2DArray sampler, vec3 P, [float bias]);

gvec4 texture(gsamplerCubeArray sampler, vec4 P, [float bias]);

float texture(sampler1DArrayShadow sampler, vec3 P, [float bias]);

float texture(sampler2DArrayShadow sampler, vec4 P, [float bias]);

gvec4 texture(gsampler2DRect sampler, vec2 P);

float texture(sampler2DRectShadow sampler, vec3 P);

float texture(samplerCubeArrayShadow sampler, vec4 P, float compare);

PARAMÈTRES

sampler

Spécifie l'échantillonneur auquel la texture, à partir de laquelle les texels seront récupérés, est liée.

P

Spécifie les coordonnées de texture auxquelles la texture sera échantillonnée.

bias

Spécifie un biais optionnel à appliquer lors du calcul du niveau de détail.

compare

Spécifie la valeur à laquelle le texel récupéré sera comparé lors de l'échantillonnage à partir de samplerCubeArrayShadow.

DESCRIPTION

texture échantillonne les texels de la texture liée à sampler aux coordonnées de texture P. Un biais optionnel, spécifié dans bias, est inclus dans le calcul du niveau de détail qui est utilisé pour choisir le(s) mipmap(s) à partir desquel(s) échantillonner.

Pour les formes *shadow*, lorsque compare est présent, il est utilisé comme Dsub et la couche de tableau est spécifiée dans P.w. Lorsque compare n'est pas présent, le dernier composant de P est utilisé comme Dsub et la couche de tableau est spécifiée dans l'avant-dernier composant de P. (Le deuxième composant de P est inutilisé pour les recherches d'ombre 1D.)

Pour les variantes non-shadow, la couche de tableau provient du dernier composant de P.
