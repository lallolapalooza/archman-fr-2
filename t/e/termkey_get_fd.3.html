NOM

termkey_get_fd - obtenir le descripteur de fichier pour le terminal

SYNTAXE

#include <termkey.h>

int termkey_get_fd(TermKey *tk);

Lier avec -ltermkey.

DESCRIPTION

termkey_get_fd() renvoie le descripteur de fichier que l'instance de termkey(7) utilise pour lire les octets.

VALEUR DE RETOUR

termkey_get_fd() renvoie le descripteur de fichier actuel, ou -1 si aucun descripteur de fichier n'est associé à cette instance.

VOIR AUSSI

termkey_new(3), termkey_get_flags(3), termkey(7)
