FBB::TempStream(3bobcat) Flux temporaire FBB::TempStream(3bobcat)

NOM

FBB::TempStream - Flux temporaire

SYNTAXE

#include <bobcat/tempstream>

DESCRIPTION

Les objets FBB::TempStream sont des std::fstreams temporaires ouverts avec le mode 0600 (lecture/écriture uniquement pour l'utilisateur). Le fichier créé par un objet TempStream est supprimé du système de fichiers une fois que l'objet TempStream sort de sa portée.

Un objet TempStream crée un fichier vide, et des informations peuvent immédiatement être insérées dans l'objet TempStream. Pour basculer entre l'insertion et l'extraction, appelez simplement seekg (pour l'extraction) ou seekp (pour l'insertion).

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HÉRITE DE

std::fstream

CONSTRUCTEURS

o
TempStream(std::string const &base = "/tmp/FBB::TempStream"):
Le constructeur initialise l'objet et crée un fichier avec le nom de base donné auquel six caractères aléatoires sont ajoutés. Si le TempStream n'a pas pu être construit, une FBB::Exception est levée.

Les constructeurs et opérateurs de copie et de déplacement ne sont pas disponibles.

FONCTIONS MEMBRES

Tous les membres de std::fstream sont disponibles, car FBB::TempStream en hérite. De plus, TempStream offre lui-même

o
std::string const &fileName() const:
Le nom du fichier temporaire créé.

EXEMPLE

    #include <iostream>
    #include <bobcat/tempstream>
    using namespace std;
    using namespace FBB;
    int main()
    {
        TempStream ts("/tmp/demo");
        ts << "Hello world\n";
        ts.seekg(0);
        string line;
        getline(ts, line);
        cout << line << ", removed: " << ts.fileName() << ’\n’;
    }
