tee(2) Manuel des appels système tee(2)

NOM

tee - dupliquer le contenu d'un tube

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <fcntl.h>
ssize_t tee(int fd_in, int fd_out, size_t size, unsigned int flags);

DESCRIPTION

tee() duplique jusqu'à size octets de données depuis le tube référencé par le descripteur de fichier fd_in vers le tube référencé par le descripteur de fichier fd_out. Il ne consomme pas les données qui sont dupliquées depuis fd_in ; par conséquent, ces données peuvent être copiées par un appel ultérieur à splice(2).

flags est un masque de bits composé en combinant par OU zéro ou plusieurs des valeurs suivantes :

SPLICE_F_MOVE
N'a actuellement aucun effet pour tee() ; voir splice(2).
SPLICE_F_NONBLOCK
Ne pas bloquer sur l'E/S ; voir splice(2) pour plus de détails.
SPLICE_F_MORE
N'a actuellement aucun effet pour tee(), mais pourrait être implémenté à l'avenir ; voir splice(2).
SPLICE_F_GIFT
Non utilisé pour tee() ; voir vmsplice(2).

VALEUR DE RETOUR

En cas de succès, tee() retourne le nombre d'octets qui ont été dupliqués entre l'entrée et la sortie. Une valeur de retour de 0 signifie qu'il n'y avait pas de données à transférer, et qu'il n'était pas judicieux de bloquer, car aucun écrivain n'est connecté à l'extrémité d'écriture du tube référencé par fd_in.

En cas d'erreur, tee() retourne -1 et errno est défini pour indiquer l'erreur.

ERREURS

EAGAIN
SPLICE_F_NONBLOCK a été spécifié dans flags ou l'un des descripteurs de fichiers avait été marqué comme non bloquant (O_NONBLOCK), et l'opération aurait bloqué.
EINVAL
fd_in ou fd_out ne fait pas référence à un tube ; ou fd_in et fd_out font référence au même tube.
ENOMEM
Pas assez de mémoire.

NORMES

Linux.

HISTORIQUE

Linux 2.6.17, glibc 2.5.

NOTES

Conceptuellement, tee() copie les données entre les deux tubes. En réalité, aucune copie réelle de données n'a lieu : sous le capot, tee() attribue les données à la sortie en prenant simplement une référence à l'entrée.

EXEMPLES

L'exemple ci-dessous implémente un programme tee(1) de base utilisant l'appel système tee(). Voici un exemple d'utilisation :


$ date | ./a.out out.log | cat;
Tue Oct 28 10:06:00 CET 2014
$ cat out.log;
Tue Oct 28 10:06:00 CET 2014

Source du programme

#define _GNU_SOURCE
#include <errno.h>
#include <fcntl.h>
#include <limits.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/types.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    int      fd;
    ssize_t  size, ssize;
    if (argc != 2) {
        fprintf(stderr, "Usage: %s <file>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    fd = open(argv[1], O_WRONLY | O_CREAT | O_TRUNC, 0644);
    if (fd == -1) {
        perror("open");
        exit(EXIT_FAILURE);
    }
    for (;;) {
        /*
         * Dupliquer stdin vers stdout.
         */
        size = tee(STDIN_FILENO, STDOUT_FILENO,
                  INT_MAX, SPLICE_F_NONBLOCK);
        if (size < 0) {
            if (errno == EAGAIN)
                continue;
            perror("tee");
            exit(EXIT_FAILURE);
        }
        if (size == 0)
            break;
        /*
         * Consommer stdin en le copiant vers un fichier.
         */
        while (size > 0) {
            ssize = splice(STDIN_FILENO, NULL, fd, NULL,
                          size, SPLICE_F_MOVE);
            if (ssize < 0) {
                perror("splice");
                exit(EXIT_FAILURE);
            }
            size -= ssize;
        }
    }
    close(fd);
    exit(EXIT_SUCCESS);
}
