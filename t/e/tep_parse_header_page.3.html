NOM

tep_parse_header_page - Analyse les données stockées dans la page d'en-tête.

SYNTAXE

#include <event-parse.h>
int tep_parse_header_page(struct tep_handle *tep, char *buf, unsigned long size, int long_size);

DESCRIPTION

La fonction tep_parse_header_page() analyse les données de la page d'en-tête à partir de buf, et initialise le contexte de l'analyseur d'événements de trace tep avec ces données. Le tampon buf a une taille size et est censé être copié depuis tracefs/events/header_page.

Certains anciens noyaux ne disposent pas des informations de la page d'en-tête. Dans ce cas, la fonction tep_parse_header_page() peut être appelée avec size égal à 0. Le contexte tep est initialisé avec des valeurs par défaut. Le paramètre long_size peut être utilisé dans ce cas pour définir la taille d'un entier long.

VALEUR DE RETOUR

La fonction tep_parse_header_page() renvoie 0 en cas de succès, ou -1 en cas d'erreur.

EXEMPLE

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
char *buf;
int size;
buf = read_file("/sys/kernel/tracing/events/header_page", &size);
if (tep_parse_header_page(tep, buf, size, sizeof(unsigned long)) != 0) {
        /* Échec de l'analyse de la page d'en-tête */
}
...
