TEXINDEX(1) Commandes utilisateur TEXINDEX(1)

NOM

texindex - trie les fichiers d'index Texinfo

SYNTAXE

texindex [OPTION]... FICHIER...

DESCRIPTION

Génère un index trié pour chaque FICHIER de sortie TeX. Habituellement, FICHIER... est spécifié comme `foo.??' pour un document `foo.texi'.

OPTIONS

-h, --help
affiche cette aide et quitte
--version
affiche les informations de version et quitte
--
termine le traitement des options
