TELNET(1) Commandes utilisateur TELNET(1)

NOM

telnet - Interface utilisateur de TELNET

SYNTAXE

telnet [OPTION...] [HÔTE [PORT]]

DESCRIPTION

Se connecter à un système distant HÔTE (facultativement, sur le port de service PORT)

Options générales :
-4, --ipv4
utiliser uniquement IPv4
-6, --ipv6
utiliser uniquement IPv6
-8, --binary
utiliser une transmission de données 8 bits
-a, --login
tenter une connexion automatique
-b, --bind=ADRESSE
lier à une ADRESSE locale spécifique
-c, --no-rc
ne pas lire le fichier .telnetrc de l'utilisateur
-d, --debug
activer le débogage
-e, --escape=CAR
utiliser CAR comme caractère d'échappement
-E, --no-escape
ne pas utiliser de caractère d'échappement
-K, --no-login
ne pas se connecter automatiquement au système distant
-l, --user=UTILISATEUR
tenter une connexion automatique en tant qu'UTILISATEUR
-L, --binary-output
utiliser une transmission de données 8 bits uniquement pour la sortie
-n, --trace=FICHIER
enregistrer les informations de trace dans FICHIER
-r, --rlogin
utiliser une interface utilisateur similaire à rlogin
-?, --help
afficher cette liste d'aide
--usage
afficher un court message d'utilisation
-V, --version
afficher la version du programme

Les arguments obligatoires ou facultatifs des options longues sont également obligatoires ou facultatifs pour les options courtes correspondantes.
