TELNET-PROBE(1) Manuel des commandes générales TELNET-PROBE(1)

NOM

telnet-probe - sonde de port légère de type telnet

SYNTAXE

$PCP_BINADM_DIR/telnet-probe [-cv?] hote port

DESCRIPTION

telnet-probe permet aux démons pmdashping(1) d'établir des connexions à des démons arbitraires fournissant des services, locaux et distants, afin d'obtenir des informations sur le temps de réponse et la disponibilité du service.

Les arguments requis hote et port ont la même signification que leurs équivalents dans telnet(1).

L'option -c fait en sorte que telnet-probe effectue uniquement une opération de connect(2). Cela évite l'exercice de read(2) et write(2) qui serait autrement effectué après la connexion (voir ci-dessous).

Une fois la connexion telnet établie, telnet-probe lit depuis stdin jusqu'à la fin du fichier, et écrit toutes les données d'entrée sur la connexion telnet. Ensuite, telnet-probe lira depuis la connexion telnet jusqu'à la fin du fichier, en ignorant quelles que soient les données qu'il reçoit. Ensuite, telnet-probe se termine.

Pour fonctionner avec succès, l'entrée passée via telnet-probe au service distant doit être suffisante pour que le service distant ferme la connexion lorsque la dernière ligne d'entrée a été traitée, par exemple en terminant par « quit » lors du sondage SMTP sur le port 25.

Par défaut, telnet-probe ne produira aucune sortie, sauf en cas d'erreur, auquel cas un message de diagnostic peut être affiché (en mode verbeux uniquement) et le code de sortie sera non nul, indiquant un échec.

OPTIONS

Les options de ligne de commande disponibles sont :

-c
Connexion uniquement, ne pas lire ni écrire.
-v
Activer le mode verbeux.
-?
Afficher le message d'utilisation et quitter.

DIAGNOSTICS

Si telnet-probe réussit, alors 0 sera retourné. Si la tentative d'établissement d'une connexion échoue ou est terminée, un code de sortie non nul sera retourné.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1), pmdashping(1), pmie(1), telnet(1), connect(2), read(2) et write(2).
