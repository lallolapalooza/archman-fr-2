NOM

terminator_config - le fichier de configuration pour l'émulateur de terminal Terminator

DESCRIPTION

Ce fichier contient la configuration de terminator(1). Terminator gère son fichier de configuration via la bibliothèque ConfigObj pour allier flexibilité et fichiers clairs, modifiables par l'utilisateur.
Terminator offre un éditeur de préférences graphique complet qui enregistre automatiquement son fichier de configuration, vous évitant ainsi de devoir écrire un fichier de configuration manuellement.

EMPLACEMENT DU FICHIER

Normalement, le fichier de configuration se trouve à ~/.config/terminator/config, mais il peut être remplacé par $XDG_CONFIG_HOME (auquel cas il sera à $XDG_CONFIG_HOME/terminator/config).

FORMAT DU FICHIER

Voici à quoi ressemble un fichier de configuration Terminator :

# Ceci est un commentaire
[global_config]
  focus = system
[keybindings]
  full_screen = <Ctrl><Shift>F11
[profiles]
  [[default]]
    font = Fixed 10
    background_color = "#000000" # Un commentaire
    foreground_color = "#FFFFFF" # Notez que les valeurs de couleur hexadécimales doivent être mises entre guillemets
    scrollback_lines = '500' #Autre commentaire. Les guillemets simples sont également valides
    cursor_blink = True
    custom_command = "echo \"foo#bar\"" #Commentaire final - cela fonctionnera comme prévu.
[layouts]
  [[default]]
    [[[window0]]]
      type = Window
      parent = ""
    [[[child1]]]
      type = Terminal
      parent = window0
[plugins]

CONFIGURATIONS_GLOBALES

Voici les options que Terminator prend actuellement en charge dans la section global_config.

Comportement et apparence de la fenêtre

window_state = chaîne

Contrôle la manière dont la fenêtre Terminator s'ouvre. 'normal' pour s'ouvrir normalement. 'maximise' pour s'ouvrir en étant maximisée. 'fullscreen' pour s'ouvrir en plein écran. 'hidden' pour rester cachée.
Valeur par défaut : normal

always_on_top = booléen

Si défini sur True, la fenêtre restera toujours au-dessus des autres fenêtres.
Valeur par défaut : False

sticky = booléen

Si défini sur True, la fenêtre sera visible sur tous les espaces de travail.
Valeur par défaut : False

hide_on_lose_focus = booléen

Si défini sur True, la fenêtre sera cachée lorsque le focus est perdu.
Valeur par défaut : False

hide_from_taskbar = booléen

Si défini sur True, la fenêtre sera cachée de la barre des tâches.
Valeur par défaut : False

geometry_hinting = booléen

Si défini sur True, la fenêtre se redimensionnera en fonction de la taille des polices.
Valeur par défaut : False

ask_before_closing = chaîne

Spécifie quand demander une confirmation avant de fermer une fenêtre ou un onglet. Peut être n'importe laquelle de ces valeurs : 'always', 'multiple_terminals', 'never'. Valeur par défaut : multiple_terminals

borderless = booléen

Si défini sur True, la fenêtre sera lancée sans bordures.
Valeur par défaut : False

Comportement et apparence des onglets

tab_position = chaîne

Spécifie l'emplacement des onglets. Peut être n'importe laquelle de ces valeurs : 'top', 'left', 'right', 'bottom', 'hidden'. Si défini sur 'hidden', la barre d'onglets ne sera pas affichée. Cacher l'onglet n'est pas recommandé, car cela peut être très déroutant.
Valeur par défaut : top

close_button_on_tab = booléen

Si défini sur True, les onglets auront un bouton de fermeture dessus.
Valeur par défaut : True

scroll_tabbar = booléen

Si défini sur True, la barre d'onglets ne remplira pas la largeur de la fenêtre. Les barres de titre des onglets ne prendront que l'espace nécessaire pour le texte qu'elles contiennent. Sauf si les onglets ne tiennent plus dans la largeur de la fenêtre, auquel cas des boutons de défilement apparaîtront pour parcourir les onglets.
Valeur par défaut : False

Comportement et apparence du terminal

focus = chaîne

Spécifie comment le focus est attribué aux terminaux. 'click' signifie que le focus ne se déplace vers un terminal qu'après avoir cliqué dedans. 'sloppy' signifie que le focus suit le pointeur de la souris. 'system' signifie que le focus correspondra à celui utilisé par un gestionnaire de fenêtres GNOME.
Valeur par défaut : click

always_split_with_profile = booléen

Spécifie si les divisions/onglets continueront à utiliser le profil de leur terminal pair. Si défini sur False, ils utiliseront toujours le profil par défaut.
Valeur par défaut : False

link_single_click = booléen

Si défini sur True, cliquer sur un lien l'ouvrira même si la touche Ctrl n'est pas enfoncée.
Valeur par défaut : False

putty_paste_style = booléen

Si défini sur True, un clic droit collera le texte, tandis qu'un clic milieu affichera le menu contextuel. La source du texte collé dépend de la valeur de putty_paste_style_source_clipboard.
Valeur par défaut : False

putty_paste_style_source_clipboard = booléen

Si défini sur True, le presse-papiers sera utilisé comme source pour coller dans le style PuTTY. Sinon, la sélection primaire sera utilisée.
Cette option est ignorée à moins que putty_paste_style ne soit défini sur True.
Valeur par défaut : False

disable_mouse_paste = booléen

Si défini sur True, le collage par souris sera désactivé.
Valeur par défaut : False

smart_copy = booléen

Si défini sur True, et qu'il n'y a pas de sélection, le raccourci est autorisé à passer. C'est utile pour surcharger Ctrl-C afin de copier une sélection, ou d'envoyer le SIGINT au processus actuel s'il n'y a pas de sélection. Si False, le raccourci ne passe pas du tout, et le SIGINT n'est pas envoyé.
Valeur par défaut : True

clear_select_on_copy = booléen

Si défini sur True, la sélection de texte sera effacée après avoir copié en utilisant la combinaison de touches copy.
Valeur par défaut : False

handle_size = entier

Spécifie la largeur du séparateur entre les terminaux. Toute valeur en dehors de la plage 0-20 (incluse) sera ignorée et la valeur du thème par défaut sera utilisée à la place.
Valeur par défaut : 1

inactive_color_offset = flottant

Spécifie dans quelle mesure réduire les valeurs de couleur des polices dans les terminaux qui n'ont pas le focus.
Valeur par défaut : 0.8

inactive_bg_color_offset = flottant

Spécifie dans quelle mesure réduire les valeurs de couleur de l'arrière-plan dans les terminaux qui n'ont pas le focus.
Valeur par défaut : 1.0

cell_width = flottant

Spécifie l'échelle horizontale des cellules de caractères dans le terminal.
Valeur par défaut : 1.0

cell_height = flottant

Spécifie l'échelle verticale des cellules de caractères dans le terminal.
Valeur par défaut : 1.0

title_at_bottom = booléen

Si défini sur True, la barre de titre du terminal sera dessinée en bas au lieu d'en haut.
Valeur par défaut : False

Divers

dbus = booléen

Spécifie si Terminator chargera son serveur DBus. Lorsque ce serveur est chargé, lancer Terminator plusieurs fois provoquera le démarrage du premier processus Terminator pour ouvrir des fenêtres supplémentaires. Si cet élément de configuration est défini sur False, ou si le module python dbus est indisponible, lancer Terminator plusieurs fois exécutera un processus Terminator distinct pour chaque invocation.
Valeur par défaut : True

extra_styling = booléen

Si défini sur True, Terminator peut charger un fichier de style CSS supplémentaire, en fonction du thème.
Défaut

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

Valeur par défaut : Vrai

broadcast_default = chaîne

Spécifie le comportement de diffusion par défaut. Peut être l'une des valeurs suivantes : 'all', 'group', 'off'.
Valeur par défaut : group

use_custom_url_handler = booléen

Si défini sur Vrai, la gestion des URL sera entièrement confiée au programme spécifié par 'custom_url_handler'.
Valeur par défaut : Faux

custom_url_handler = chaîne

Spécifie le chemin d'accès à un programme qui accepte une URI en argument et en fait quelque chose de pertinent. Cette option est ignorée à moins que use_custom_url_handler ne soit défini sur Vrai.

case_sensitive = booléen

Si défini sur Vrai, les caractères majuscules et minuscules seront considérés comme différents lors de la recherche de texte dans le terminal.
Valeur par défaut : Vrai

invert_search = booléen

Si défini sur Vrai, la direction de recherche sera inversée (du bas vers le haut) lors de la recherche de texte dans le terminal.
Valeur par défaut : Faux

enabled_plugins = liste de chaînes

Spécifie quels plugins seront chargés par défaut. Toutes les autres classes de plugins seront ignorées.
Valeur par défaut : ['LaunchpadBugURLHandler', 'LaunchpadCodeURLHandler', 'APTURLHandler']

PROFILS

Ce sont les options que Terminator prend actuellement en charge dans la section profiles. Chaque profil doit être sa propre sous-section avec un en-tête au format [[nom]].

Général

allow_bold = booléen

Si défini à True, le texte dans le terminal peut être affiché en gras.
Valeur par défaut : True

copy_on_selection = booléen

Si défini à True, les sélections de texte seront automatiquement copiées dans le Presse-papiers, en plus d'être copiées dans la Sélection primaire.
Valeur par défaut : False

disable_mousewheel_zoom = booléen

Si défini à True, Ctrl + molette de la souris ne zoomera ou dézoomera pas le terminal.
Valeur par défaut : False

word_chars = chaîne de caractères

Spécifie les caractères qui seront considérés comme faisant partie d'un mot unique lors de la sélection de texte par mot. Le trait d'union et les alphanumériques n'ont pas besoin d'être spécifiés. Les plages peuvent être données, par exemple, "A-Z".
Par exemple, si word_chars = ",", alors "foo,bar" est considéré comme un seul mot.
Valeur par défaut : -,./?%&#:_

mouse_autohide = booléen

Si défini à True, le pointeur de la souris sera masqué lors de la frappe.
Valeur par défaut : True

term = chaîne de caractères

Spécifie la valeur que Terminator attribuera à la variable d'environnement 'TERM'.
Valeur par défaut : xterm-256color

colorterm = chaîne de caractères

Spécifie la valeur que Terminator attribuera à la variable d'environnement 'COLORTERM'.
Valeur par défaut : truecolor

split_to_group = booléen

Si défini à True, le terminal créé par division sera inséré dans le groupe du terminal actuel.
Valeur par défaut : False

autoclean_groups = booléen

Si défini à True, les groupes vides seront supprimés.
Valeur par défaut : True

use_system_font = booléen

Si défini à True, la police par défaut du système sera utilisée pour le texte dans le terminal. Sinon, la valeur de font sera utilisée.
Valeur par défaut : True

font = chaîne de caractères

Spécifie quelle police utiliser pour le texte dans le terminal. Cette option est ignorée à moins que use_system_font ne soit défini à False.
Valeur par défaut : Mono 10

cursor_blink = booléen

Si défini à True, le curseur clignotera lorsqu'il n'y aura pas de frappe.
Valeur par défaut : True

cursor_shape = chaîne de caractères

Spécifie la forme du curseur. Peut être l'un des éléments suivants : 'block', 'underline', 'ibeam'.
Valeur par défaut : block

cursor_color_default = booléen

Si défini à True, les couleurs d'arrière-plan et de premier plan du terminal seront utilisées comme couleurs de premier plan et d'arrière-plan pour le curseur, respectivement.
Valeur par défaut : True

cursor_fg_color = chaîne de couleur

Spécifie la couleur de premier plan à utiliser pour le curseur. Cette option est ignorée à moins que cursor_color_default ne soit défini à False.

cursor_bg_color = chaîne de couleur

Spécifie la couleur d'arrière-plan à utiliser pour le curseur. Cette option est ignorée à moins que cursor_color_default ne soit défini à False.

audible_bell = booléen

Si défini à True, un son sera émis lorsqu'une application écrira la séquence d'échappement pour la cloche du terminal.
Valeur par défaut : False

visible_bell = booléen

Si défini à True, le terminal clignotera lorsqu'une application écrira la séquence d'échappement pour la cloche du terminal.
Valeur par défaut : False

urgent_bell = booléen

Si défini à True, l'indicateur d'urgence de la fenêtre sera défini lorsqu'une application écrira la séquence d'échappement pour la cloche du terminal.
Valeur par défaut : False

icon_bell = booléen

Si défini à True, une petite icône sera affichée sur la barre de titre du terminal lorsqu'une application écrira la séquence d'échappement pour la cloche du terminal.
Valeur par défaut : True

force_no_bell = booléen

Si défini à True, la cloche du terminal sera complètement désactivée.
Valeur par défaut : False

Commande

login_shell = booléen

Si défini à True, le terminal exécutera le shell par défaut (ou la commande spécifiée par custom_command) comme un shell de connexion. Cela signifie que le premier argument passé au shell/commande sera '-l'.
Valeur par défaut : False

use_custom_command = booléen

Si défini à True, la valeur de custom_command sera utilisée à la place du shell par défaut.
Valeur par défaut : False

custom_command = chaîne de caractères

Spécifie la commande à exécuter à la place du shell par défaut. Cette option est ignorée à moins que use_custom_command ne soit défini à True.

exit_action = chaîne de caractères

Spécifie l'action à effectuer lorsque le terminal est fermé. 'close' pour supprimer le terminal. 'restart' pour redémarrer le shell (ou la commande spécifiée par custom_command). 'hold' pour garder le terminal ouvert, même si le processus qu'il contient s'est terminé.
Valeur par défaut : close

Couleurs

use_theme_colors = booléen

Si défini à True, les couleurs de premier plan et d'arrière-plan du thème seront utilisées pour le terminal. Sinon, les valeurs de foreground_color et background_color seront utilisées.
Valeur par défaut : False

foreground_color = chaîne de couleur

Spécifie la couleur de premier plan à utiliser pour le terminal. Cette option est ignorée à moins que use_theme_colors ne soit défini à False.
Valeur par défaut : #AAAAAA

background_color = chaîne de couleur

Spécifie la couleur d'arrière-plan à utiliser pour le terminal. Cette option est ignorée à moins que use_theme_colors ne soit défini à False.
Valeur par défaut : #000000

palette = liste de chaînes de couleurs

Spécifie la palette de 16 couleurs à utiliser pour le terminal. La valeur doit être une chaîne contenant une liste de couleurs séparées par des deux-points au format hexadécimal.
Par exemple, "#000000:#cd0000:#00cd00: ... ".

bold_is_bright = booléen

Si défini à True, le texte en gras aura des couleurs plus vives.
Valeur par défaut : False

Arrière-plan

background_darkness = flottant

Spécifie la transparence de la couleur d'arrière-plan. La valeur doit être comprise entre 0.0 et 1.0. Cette option est ignorée à moins que background_type ne soit défini à 'transparent' ou 'image'.
Valeur par défaut : 0.5

background_type = chaîne de caractères

Spécifie le type d'arrière-plan du terminal. 'solid' pour un arrière-plan uni (opaque). 'transparent' pour un arrière-plan transparent. 'image' pour une image d'arrière-plan.
Si cette option est définie à 'transparent', la transparence de l'arrière-plan sera la valeur de background_darkness. Si elle est définie à 'image', l'image spécifiée par background_image sera l'arrière-plan ; la couleur d'arrière-plan sera alors dessinée par-dessus, avec une transparence spécifiée par background_darkness.
Valeur par défaut : solid

background_image = chemin d'accès chaîne de caractères

Spécifie le chemin d'accès à une image qui sera utilisée en arrière-plan. Cette option est ignorée à moins que background_type ne soit défini à 'image'.

background_image_mode = chaîne de caractères

Spécifie comment l'image d'arrière-plan sera dessinée. 'stretch_and_fill' pour remplir entièrement le terminal, sans nécessairement maintenir le rapport hauteur/largeur. 'scale_and_fit' pour ajuster l'image à l'intérieur du terminal, laissant éventuellement des barres vides, tout en maintenant le rapport hauteur/largeur. 'scale_and_crop' pour remplir entièrement le terminal, recadrant éventuellement l'image, tout en maintenant le rapport hauteur/largeur. 'tiling' pour répéter l'image afin de remplir le terminal. Cette option est ignorée à moins que background_type ne soit défini à 'image'.
Valeur par défaut : stretch_and_fill

background_image_align_horiz = chaîne de caractères

Spécifie l'alignement horizontal de l'image d'arrière-plan. Peut être l'un des éléments suivants : 'left', 'center', 'right'. Cette option est ignorée à moins que background_type ne soit défini à 'image'.
Valeur par défaut : center

background_image_align_vert = chaîne de caractères

Spécifie l'alignement vertical de l'image d'arrière-plan. Peut être l'un des éléments suivants : 'top', 'middle', 'bottom'. Cette option est ignorée à moins que background_type ne soit défini à 'image'.
Valeur par défaut : middle

Défilement

Valeur par défaut : True

Valeur par défaut : False

Spécifie combien de lignes de l'historique de défilement seront conservées par le terminal. Les lignes qui ne rentrent pas dans l'historique de défilement seront rejetées. Notez que la définition de valeurs élevées peut ralentir le réajustement et le redimensionnement. Cette option est ignorée à moins que scrollback_infinite ne soit défini sur False.
Valeur par défaut : 500

DISPOSITIONS

La section dispositions contient toutes les dispositions sauvegardées. Chaque disposition doit être sa propre sous-section avec un en-tête au format [[nom]].

Chaque objet dans une disposition est une sous-sous-section nommée avec diverses propriétés.

type = chaîne

Peut être l'un des suivants : 'Window', 'Notebook', 'HPaned', 'VPaned', 'Terminal'.

parent = chaîne

Spécifie quel objet est le parent du composant en cours de définition. Tous les objets, à l'exception de ceux de type Window, doivent spécifier un parent.

Voici un exemple d'une section dispositions ne contenant que la disposition nommée "défaut".

[dispositions]
  [[défaut]]
    [[[fenêtre0]]]
      type = Fenêtre
      parent = ""
    [[[enfant1]]]
      type = Terminal
      parent = fenêtre0

PLUGINS

Les plugins de Terminator peuvent ajouter leur propre configuration au fichier de configuration et elle apparaîtra comme une sous-section. Veuillez vous référer à la documentation des plugins individuels pour plus d'informations.
