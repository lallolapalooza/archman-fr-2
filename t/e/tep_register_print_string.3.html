LIBTRACEEVENT(3) Manuel libtraceevent LIBTRACEEVENT(3)

NOM

tep_set_function_resolver, tep_reset_function_resolver, tep_register_function, tep_register_print_string, tep_get_function_count - API liées aux fonctions tep

SYNOPSIS

#include <event-parse.h>
typedef char *(tep_func_resolver_t)(void *priv, unsigned long long *addrp, char **modp);
int tep_set_function_resolver(struct tep_handle *tep, tep_func_resolver_t *func, void *priv);
void tep_reset_function_resolver(struct tep_handle *tep);
int tep_register_function(struct tep_handle *tep, char *name, unsigned long long addr, char *mod);
int tep_register_print_string(struct tep_handle *tep, const char *fmt, unsigned long long addr);
int tep_get_function_count(struct tep_handle *tep)

DESCRIPTION

Certains outils peuvent déjà disposer d'un moyen de résoudre les fonctions du noyau. Ces API leur permettent de continuer à l'utiliser au lieu de dupliquer toutes les entrées à l'intérieur.

Le type tep_func_resolver_t est le prototype du résolveur alternatif de fonctions du noyau. Cette fonction reçoit un pointeur vers son contexte personnalisé (défini avec l'appel tep_set_function_resolver() ) et l'adresse d'une fonction du noyau, qui doit être résolue. En cas de succès, elle doit retourner le nom de la fonction et son module (si applicable) dans modp.

La fonction tep_set_function_resolver() enregistre func en tant que résolveur alternatif de fonctions du noyau. L'argument tep est le contexte de l'analyseur d'événements de trace. L'argument priv est un contexte personnalisé de la fonction func. Le résolveur de fonctions est utilisé par les API tep_find_function(3), tep_find_function_address(3), et tep_print_func_field() pour résoudre une adresse de fonction en un nom de fonction.

La fonction tep_reset_function_resolver() réinitialise le résolveur de fonctions du noyau à la fonction par défaut. L'argument tep est le contexte de l'analyseur d'événements de trace.

Ces API peuvent être utilisées pour trouver le nom de la fonction et son adresse de début, par adresse donnée. L'adresse donnée n'a pas besoin d'être exacte, elle sélectionnera la fonction qui la contiendrait.

La fonction tep_register_function() enregistre un nom de fonction mappé à une adresse et (optionnellement) un module. Ce mappage est utilisé si le traceur de fonctions ou les événements ont un paramètre "%pS" dans leur chaîne de format. Il est courant de passer les noms de fonctions kallsyms avec leurs adresses correspondantes avec cette fonction. L'argument tep est le contexte de l'analyseur d'événements de trace. Le name est le nom de la fonction, la chaîne est copiée en interne. L'addr est l'adresse de début de la fonction. Le mod est le module du noyau dans lequel la fonction peut se trouver (NULL pour aucun).

La fonction tep_register_print_string() enregistre une chaîne par l'adresse où elle a été stockée dans le noyau. Certaines chaînes internes au noyau avec une adresse statique sont passées à certains événements. Le "%s" dans le champ de format de l'événement, qui a une adresse, a besoin de savoir quelle chaîne se trouverait à cette adresse. tep_register_print_string() fournit l'analyse avec le mappage entre les adresses du noyau et ces chaînes. L'argument tep est le contexte de l'analyseur d'événements de trace. Le fmt est la chaîne à enregistrer, elle est copiée en interne. L'addr est l'adresse où se trouvait la chaîne.

tep_get_function_count() retourne le nombre de fonctions enregistrées dans un gestionnaire tep.

VALEUR RENVOYÉE

La fonction tep_set_function_resolver() retourne 0 en cas de succès, ou -1 en cas d'erreur.

La fonction tep_register_function() retourne 0 en cas de succès. En cas d'erreur, -1 est retourné et errno est défini sur le numéro d'erreur approprié.

La fonction tep_register_print_string() retourne 0 en cas de succès. En cas d'erreur, -1 est retourné et errno est défini sur le numéro d'erreur approprié.

EXEMPLE

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
char *my_resolve_kernel_addr(void *context,
                             unsigned long long *addrp, char **modp)
{
        struct db *function_database = context;
        struct symbol *sym = sql_lookup(function_database, *addrp);
        if (!sym)
                return NULL;
        *modp = sym->module_name;
        return sym->name;
}
void show_function( unsigned long long addr)
{
        unsigned long long fstart;
        const char *fname;
        if (tep_set_function_resolver(tep, my_resolve_kernel_addr,
                                      function_database) != 0) {
                /* échec de l'enregistrement de my_resolve_kernel_addr */
        }
        /* Ces API utilisent my_resolve_kernel_addr() pour résoudre l'addr */
        fname = tep_find_function(tep, addr);
        fstart = tep_find_function_address(tep, addr);
        /*
           addr est dans la fonction nommée fname, commençant à l'adresse fstart,
           à l'offset (addr - fstart)
        */
        tep_reset_function_resolver(tep);
}
...
        if (tep_register_function(tep, "kvm_exit",
                                (unsigned long long) 0x12345678, "kvm") != 0) {
                /* Échec de l'enregistrement du mappage d'adresse kvm_exit */
        }
...
        if (tep_register_print_string(tep, "print string",
                                (unsigned long long) 0x87654321, NULL) != 0) {
                /* Échec de l'enregistrement du mappage d'adresse "print string" */
        }
...
