texlogfilter

NOM

texlogfilter - filtre la sortie ou le fichier journal des moteurs latex

SYNOPSIS

texlogfilter [options] fichier.log

DESCRIPTION

Filtre la sortie ou le fichier journal des moteurs latex. Pour la sortie ou le fichier journal de latex, pdflatex, lualatex ou xelatex.

Sans fichier d'entrée, l'entrée standard est utilisée. Utilisation sur la sortie du moteur latex avec :

latex fichier.tex < /dev/null | texlogfilter

OPTIONS

--help                 : affiche cette aide et quitte
--version              : affiche la version et quitte
--box                  : affiche les avertissements de boîtes (box)
--no-box               : masque les avertissements de boîtes (box)
--ref                  : affiche les avertissements de références/citations
--no-ref               : masque les avertissements de références/citations
--info                 : affiche les messages d'information de latex
--no-info              : masque les messages d'information de latex
--filename             : affiche le nom du fichier actuel
--no-filename          : n'affiche pas le nom du fichier actuel
--files-ext=string     : modèle regex pour correspondre aux extensions de fichiers (par défaut: tex|sty|cls|bib)
--skips                : indique les lignes ignorées
--no-skips             : masque les lignes ignorées
--skip-marker=string   : marqueur utilisé pour indiquer les lignes ignorées (par défaut: ...)
--add-filter=string    : ajoute un filtre utilisateur (comme une expression régulière perl)
--full-log             : affiche le journal complet (ne filtre pas - seulement coloration de la sortie du moteur latex)
--errors-color=string
--warnings-color=string
--infos-color=string
--skips-color=string
--user-color=string    : couleurs utilisées pour les erreurs, avertissements, informations et lignes ignorées
