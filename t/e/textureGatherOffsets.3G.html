TEXTUREGATHEROFFSETS(3G) [FIXME: manuel] TEXTUREGATHEROFFSETS(3G)

NOM

textureGatherOffsets - collecte quatre texels d'une texture avec un tableau d'offsets

DÉCLARATION

gvec4 textureGatherOffsets(gsampler2D sampler, vec2 P, ivec2 offsets[4], [int comp]);

gvec4 textureGatherOffsets(gsampler2DArray sampler, vec3 P, ivec2 offsets[4], [int comp]);

gvec4 textureGatherOffsets(gsampler2DRect sampler, vec3 P, ivec2 offsets[4], [int comp]);

vec4 textureGatherOffsets(sampler2DShadow sampler, vec2 P, float refZ, ivec2 offsets[4]);

vec4 textureGatherOffsets(sampler2DArrayShadow sampler, vec3 P, float refZ, ivec2 offsets[4]);

vec4 textureGatherOffsets(sampler2DRectShadow sampler, vec2 P, float refZ, ivec2 offsets[4]);

PARAMÈTRES

sampler

Spécifie l'échantillonneur auquel est liée la texture à partir de laquelle les texels seront récupérés.

P

Spécifie les coordonnées de texture auxquelles la texture sera échantillonnée.

comp

Spécifie la composante de la texture source qui sera utilisée pour générer le vecteur résultant.

refZ

Spécifie la valeur Z de référence utilisée dans la comparaison pour les formes d'ombre.

offsets

Spécifie un tableau d'offsets à partir de la coordonnée de texture P spécifiée, à partir desquels les texels seront collectés.

DESCRIPTION

textureGatherOffsets fonctionne de manière identique à textureGatherOffset(), sauf que offsets est utilisé pour déterminer l'emplacement des quatre texels à échantillonner. Chacun des quatre texels est obtenu en appliquant l'offset dans offsets comme un offset de coordonnée (u, v) à P, en identifiant l'empreinte GL_LINEAR de quatre texels, puis en sélectionnant le texel i0i0 de cette empreinte. Les valeurs spécifiées dans offsets doivent être définies avec des expressions intégrales constantes.
