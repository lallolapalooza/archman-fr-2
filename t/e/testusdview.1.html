NOM

testusdview - page de manuel pour testusdview 25.11

DESCRIPTION

usage : /build/usd/pkg/usd/usr/bin/testusdview [-h]

[--renderer {Storm,Embree,GL}]
[--select PRIMPATH] [--camera CAMERA] [--mask PRIMPATH[,PRIMPATH...]] [--clearsettings] [--config {}] [--defaultsettings] [--norender] [--noplugins] [--unloaded] [--bboxStandin] [--timing] [--allow-async] [--traceToFile TRACETOFILE] [--traceFormat {chrome,trace}] [--tracePython] [--memstats {none,stage,stageAndImaging}] [--dumpFirstImage DUMPFIRSTIMAGE] [--numThreads NUMTHREADS] [--ff FIRSTFRAME] [--lf LASTFRAME] [--cf CURRENTFRAME] [--complexity {low,medium,high,veryhigh}] [--quitAfterStartup] [--sessionLayer SESSIONLAYER] [--mute MUTELAYERSRE] [--detachLayers] [--detachLayersInclude PATTERN[,PATTERN...]] [--detachLayersExclude PATTERN[,PATTERN,...]] --testScript TESTSCRIPT usdFile

Afficher un fichier usd

arguments positionnels :

usdFile
Le fichier à afficher

options :

-h, --help
afficher ce message d'aide et quitter
--renderer, -r {Storm,Embree,GL}
Quel backend de rendu utiliser (nommé tel qu'il apparaît dans le menu). 'GL' et 'Storm' sont actuellement des alias pour le même moteur de rendu, Storm.
--select PRIMPATH
Un chemin de prim à sélectionner et cadrer initialement
--camera, -cam CAMERA
Quelle caméra définir comme vue à l'ouverture - peut être donné juste comme le nom de la prim de la caméra (c'est-à-dire le dernier élément du chemin de la prim), ou comme un chemin de prim complet. Notez que si seul le nom de la prim est utilisé, et que plus d'une caméra existe avec ce nom, celle qui sera utilisée sera effectivement aléatoire (défaut=None)
--mask PRIMPATH[,PRIMPATH...]
Limiter la population de la scène à ces prims, leurs descendants et ancêtres. Pour spécifier plusieurs chemins, utilisez des virgules sans espaces ou citez l'argument et séparez les chemins par des virgules et/ou des espaces.
--clearsettings
Restaure les paramètres de usdview par défaut
--config {}
Chargez usdview avec les paramètres d'état trouvés dans la configuration spécifiée. S'il n'est pas fourni, il utilisera l'état de l'application précédemment sauvegardé et persistera automatiquement l'état à la fermeture
--defaultsettings
Lancez usdview avec les paramètres par défaut
--norender
Afficher uniquement le navigateur de hiérarchie
--noplugins
Ne pas charger les plugins
--unloaded
Ne pas charger les payloads
--bboxStandin
Afficher les prims non chargées avec des boîtes englobantes
--timing
Afficher les statistiques de chronométrage dans la console. NOTE : les chronométrages seront peu fiables lorsque l'option --memstats est également utilisée
--allow-async
Activer le traitement asynchrone de la scène hydra
--traceToFile TRACETOFILE
Commencez le traçage au démarrage de l'application et écrivez le format de sortie spécifié par --traceFormat dans le fichier de traçage spécifié à la fermeture de l'application
--traceFormat {chrome,trace}
Format de sortie pour le fichier de traçage spécifié par --traceToFile. Les fichiers 'chrome' peuvent être lus dans Chrome, les fichiers 'trace' sont des rapports texte simples. (défaut=chrome)
--tracePython
Activer la collecte de traces Python, nécessite que --traceToFile soit défini.
--memstats {none,stage,stageAndImaging}
Utiliser le système de comptabilisation de mémoire Pxr MallocTags pour profiler USD, en sauvegardant les résultats dans un fichier temporaire, avec un résumé dans la console. N'aura aucun effet si MallocTags ne sont pas pris en charge dans l'installation USD.
--dumpFirstImage DUMPFIRSTIMAGE
Sauvegarde la première image dans un fichier (au format png)
--numThreads NUMTHREADS
Nombre de threads utilisés pour le traitement (0 signifie max, les nombres négatifs impliquent max - N)
--ff FIRSTFRAME
Définir la première image de la visionneuse
--lf LASTFRAME
Définir la dernière image de la visionneuse
--cf CURRENTFRAME
Définir l'image courante de la visionneuse
--complexity, -c {low,medium,high,veryhigh}
Définir la complexité de raffinement initiale du maillage (low).
--quitAfterStartup
quitter immédiatement après le démarrage
--sessionLayer SESSIONLAYER
Si spécifié, la scène sera ouverte avec le 'sessionLayer' à la place de la couche anonyme par défaut. Comme cela change la couche de session de anonyme à persistante, sachez que les couches enregistrées depuis Export Overrides incluront les opinions de la couche de session persistante.
--mute MUTELAYERSRE
Les identificateurs de couches recherchés par cette expression régulière seront mis en sourdine sur la scène avant et après le chargement. Plusieurs expressions peuvent être fournies en utilisant l'opérateur de séparation d'expressions régulières |. Alternativement, l'argument peut être utilisé plusieurs fois.
--testScript TESTSCRIPT
Le script de test à exécuter après le chargement. Ce script doit s'attendre à recevoir un seul

Couches détachées :

Spécifie les couches à détacher de leur source de données sérialisée lors du chargement. Cela peut augmenter le temps de chargement et l'utilisation de la mémoire, mais évitera les problèmes tels que les descripteurs de fichiers ouverts empêchant d'autres processus de remplacer en toute sécurité une couche chargée.
--detachLayers
Détacher toutes les couches
--detachLayersInclude PATTERN[,PATTERN...]
Détacher les couches dont les identificateurs contiennent l'un des motifs donnés.
--detachLayersExclude PATTERN[,PATTERN,...]
Exclure les couches dont les identificateurs contiennent l'un des motifs donnés de l'ensemble des couches détachées spécifiées par les arguments --detachLayers ou --detachLayerIncludes.

    NAME

    testusdview - View USD files in a window

    DESCRIPTION

    testusdview is a utility to view USD (Universal Scene Description) files in a window. It provides a basic interface for navigating and inspecting USD scenes.
