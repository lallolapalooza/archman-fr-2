NOM

tep_get_long_size, tep_set_long_size - Obtenir / définir la taille d'un entier long sur la machine où la trace est générée, en octets

SYNOPIS

#include <event-parse.h>
int tep_get_long_size(struct tep_handle *tep);
void tep_set_long_size(struct tep_handle *tep, int long_size);

DESCRIPTION

La fonction tep_get_long_size() renvoie la taille d'un entier long sur la machine où la trace est générée. L'argument tep est le contexte de l'analyseur d'événements de trace.

La fonction tep_set_long_size() définit la taille d'un entier long sur la machine où la trace est générée. L'argument tep est le contexte de l'analyseur d'événements de trace. Le long_size est la taille d'un entier long, en octets.

VALEUR DE RETOUR

La fonction tep_get_long_size() renvoie la taille d'un entier long sur la machine où la trace est générée, en octets.

EXEMPLE

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
tep_set_long_size(tep, 4);
...
int long_size = tep_get_long_size(tep);
...
