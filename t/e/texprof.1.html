TEXPROF(1) Manuel des commandes générales TEXPROF(1)

NOM

texprof - Un profileur pour les fichiers source TeX

SYNTAXE

texprof [options] [&format] [fichier|\commandes]

DESCRIPTION

Exécute le profileur TeX sur fichier, créant généralement fichier.dvi et fichier.tprof. Si l'argument fichier n'a pas d'extension, ".tex" lui sera ajouté. Au lieu d'un nom de fichier, une liste de commandes TeX peut être fournie, dont la première doit commencer par une barre oblique inverse. Avec un argument &format, le profileur TeX utilise un ensemble différent de commandes précompilées, contenues dans format.fmt ; il est généralement préférable d'utiliser plutôt l'option -fmt format.

Le profileur TeX est une version de TeX qui mesure le temps nécessaire à TeX pour exécuter des lignes d'entrée ou des macros individuelles. Il écrit les données collectées dans un fichier avec l'extension .tprof. Un programme séparé, texprofile (voir texprofile(1)), est utilisé pour afficher le contenu d'un fichier .tprof sous une forme lisible.

L'utilisation typique du profileur TeX se fait avec des formats pré-générés. La commande texprof utilise l'équivalent du format plain TeX, et la commande latexprof utilise l'équivalent du format LaTeX. Pour examiner les temps d'exécution des macros ciblées pour pdftex ou pdflatex, vous pouvez utiliser pdftexprof ou pdflatexprof.

La gestion des arguments de ligne de commande par le profileur TeX est similaire à celle des autres programmes TeX de l'implémentation web2c.

OPTIONS

Cette version du profileur TeX comprend les options de ligne de commande suivantes.

-cnf-line chaîne
Interprète chaîne comme une ligne de configuration texmf.cnf. Voir le manuel Kpathsea.
-etex
Active les extensions e-TeX. Cette option n'est effective qu'en combinaison avec -ini. Voir etex(1).
-file-line-error
Affiche les messages d'erreur sous la forme fichier:ligne:erreur, ce qui est similaire à la façon dont de nombreux compilateurs les formatent.
-no-file-line-error
Désactive l'affichage des messages d'erreur dans le style fichier:ligne:erreur.
-fmt format
Utilise format comme nom du format à utiliser, au lieu du nom sous lequel le profileur TeX a été appelé ou d'une ligne %&.
-help
Affiche le message d'aide et quitte.
-ini
Démarre en mode INI, utilisé pour déverser les formats. Le mode INI peut être utilisé pour la composition, mais aucun format n'est préchargé, et des initialisations de base comme la définition des codes catégories peuvent être nécessaires.
-interaction mode
Définit le mode d'interaction. Le mode peut être batchmode, nonstopmode, scrollmode, ou errorstopmode. La signification de ces modes est la même que celle des \commandes correspondantes.
-jobname nom
Utilise nom pour le nom du job, au lieu de le dériver du nom du fichier d'entrée.
-kpathsea-debug masque_binaire
Définit les indicateurs de débogage de recherche de chemins selon le masque binaire. Voir le manuel de Kpathsea pour plus de détails.
-ltx
Active les extensions LaTeX. Cette option n'est effective qu'en combinaison avec -ini. Voir latex(1).
-mktex fmt
Active mktexfmt, où fmt doit être tex, tfm, fmt, ou pk.
-no-mktex fmt
Désactive mktexfmt, où fmt doit être tex, tfm, fmt, ou pk.
-output-directory répertoire
Écrit les fichiers de sortie dans répertoire au lieu du répertoire courant. Recherche d'abord les fichiers d'entrée dans répertoire, puis le long du chemin de recherche normal.
-parse-first-line
Si la première ligne du fichier d'entrée principal commence par %&, l'interprète pour rechercher un nom de dump.
-no-parse-first-line
Désactive l'interprétation de la première ligne du fichier d'entrée principal.
-pdf
Active la simulation des primitives communes de pdftex. Cette option nécessite l'option -ini et implique l'option -ltx. Voir pdftex(1).
-prof
Active le profilage dès que TeX entre dans la boucle principale. Si cette option n'est pas utilisée, le profilage doit être activé à l'aide de la primitive \profileon. Le profilage peut être désactivé avec la primitive \profileoff.
-progname nom
Se fait passer pour le programme nom. Cela affecte à la fois le format utilisé et les chemins de recherche.
-version
Affiche les informations de version et quitte.

ENVIRONNEMENT

Voir la documentation de la bibliothèque Kpathsea (par exemple, le nœud `Path specifications') pour des détails précis sur la façon dont les variables d'environnement sont utilisées. L'utilitaire kpsewhich peut être utilisé pour interroger les valeurs des variables.

TEXMFOUTPUT
Normalement, TeX place ses fichiers de sortie dans le répertoire courant. Si un fichier de sortie ne peut pas être ouvert là, il essaie de l'ouvrir dans le répertoire spécifié dans la variable d'environnement TEXMFOUTPUT. Il n'y a pas de valeur par défaut pour cette variable. Par exemple, si vous écrivez texprof paper et que le répertoire courant n'est pas inscriptible et que TEXMFOUTPUT a la valeur /tmp, TeX essaie de créer /tmp/paper.log , /tmp/paper.dvi , et /tmp/paper.tprof . TEXMFOUTPUT est également consulté pour les fichiers d'entrée, car TeX génère souvent des fichiers qui doivent être lus par la suite ; pour l'entrée, aucun suffixe (tel que «.tex») n'est ajouté par défaut, le nom d'entrée est simplement vérifié tel quel.
TEXINPUTS
Chemin de recherche pour les fichiers \input et \openin. Ceci commence normalement par ``.'', de sorte que les fichiers utilisateur soient trouvés avant les fichiers système. Un composant de chemin vide sera remplacé par les chemins définis dans le fichier texmf.cnf. Par exemple, définissez TEXINPUTS sur ".:/home/user/tex:" pour ajouter le répertoire courant et ``/home/user/tex'' au chemin de recherche standard.
TEXFORMATS
Chemin de recherche pour les fichiers de format.
TFMFONTS
Chemin de recherche pour les fichiers de métriques de polices (.tfm).
SOURCE_DATE_EPOCH
Si défini, sa valeur, prise en secondes depuis l'époque, sera utilisée pour la date de création et comme moment de référence pour les primitives liées au temps de LaTeX. Ceci est utile pour rendre les builds reproductibles.
FORCE_SOURCE_DATE
Si défini à la valeur «1», les primitives TeX liées au temps (\year, \month, \day, \time) sont également initialisées à partir de la valeur de SOURCE_DATE_EPOCH. Ce n'est pas recommandé s'il existe une alternative viable.

De nombreuses autres variables d'environnement peuvent être consultées concernant la recherche de chemins. Voir le manuel Kpathsea.

FICHIERS

NOTES

Cette page de manuel n'est pas destinée à être exhaustive. La documentation complète pour le profileur TeX se trouve dans texprof.pdf. Des informations supplémentaires peuvent être trouvées dans le manuel de la bibliothèque Kpathsea.

BUGS

Cette version du profileur TeX n'implémente pas toutes les primitives fournies par pdftex, et de plus, elle ne produira pas les mêmes effets secondaires.

DISPONIBILITÉ

Le profileur TeX devrait compiler sur une grande variété d'architectures de machines et de systèmes d'exploitation. La fonction d'obtention d'informations de chronométrage est spécifique à POSIX.

Les sources du profileur TeX sont hébergées sur https://github.com/ruckertm/HINT
