NOM

textureGatherOffset - récupère quatre texels d'une texture avec un décalage

DÉCLARATION

gvec4 textureGatherOffset(gsampler2D sampler, vec2 P, ivec2 offset, [int comp]);

gvec4 textureGatherOffset(gsampler2DArray sampler, vec3 P, ivec2 offset, [int comp]);

gvec4 textureGatherOffset(gsampler2DRect sampler, vec3 P, ivec2 offset, [int comp]);

vec4 textureGatherOffset(sampler2DShadow sampler, vec2 P, float refZ, ivec2 offset);

vec4 textureGatherOffset(sampler2DArrayShadow sampler, vec3 P, float refZ, ivec2 offset);

vec4 textureGatherOffset(sampler2DRectShadow sampler, vec2 P, float refZ, ivec2 offset);

PARAMÈTRES

sampler

Spécifie l'échantillonneur auquel la texture dont les texels seront récupérés est liée.

P

Spécifie les coordonnées de texture auxquelles la texture sera échantillonnée.

comp

Spécifie le composant de la texture source qui sera utilisé pour générer le vecteur résultant.

refZ

Spécifie la valeur de référence Z utilisée dans la comparaison pour les formes d'ombre.

offset

Spécifie le décalage par rapport aux coordonnées de texture spécifiées P à partir duquel les texels seront récupérés.

DESCRIPTION

textureGatherOffset renvoie la valeur :

    vec4(Sample_i0_j1(P + offset, base).comp,
         Sample_i1_j1(P + offset, base).comp,
         Sample_i1_j0(P + offset, base).comp,
         Sample_i0_j0(P + offset, base).comp);

Elle fonctionne comme textureGather() mais avec offset appliqué comme décrit dans textureOffset(), à l'exception près que les valeurs de décalage minimales et maximales dépendantes de l'implémentation sont données par GL_MIN_PROGRRAM_TEXTURE_GATHER_OFFSET et GL_MAX_PROGRAM_TEXTURE_GATHER_OFFSET, respectivement.

Si spécifié, la valeur de comp doit être une expression constante entière avec une valeur de 0, 1, 2 ou 3, identifiant le composant x, y, z ou w du résultat de recherche de vecteur à quatre composantes pour chaque texel, respectivement. Si comp n'est pas spécifié, il est traité comme 0, sélectionnant le composant x de chaque texel pour générer le résultat.
