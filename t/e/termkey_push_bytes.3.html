NOM

termkey_push_bytes - fournir des octets supplémentaires au tampon d'entrée

SYNOPSIS

#include <termkey.h>

size_t termkey_push_bytes(TermKey *tk, const char *bytes, size_t len);

Lier avec -ltermkey.

DESCRIPTION

termkey_push_bytes() permet de fournir des octets d'entrée supplémentaires directement dans le tampon d'entrée de l'instance termkey(7). S'il n'y avait plus de place dans le tampon, -1 est retourné avec errno défini à ENOMEM.

Cette fonction, avec termkey_getkey(3), permet d'utiliser l'instance termkey avec une source d'octets autre que la lecture d'un descripteur de fichier.

Pour une utilisation synchrone, termkey_waitkey(3) effectue la tâche de blocage de l'entrée. Pour une utilisation avec un descripteur de fichier de flux régulier qui prend en charge read(2), voir termkey_advisereadable(3).

VALEUR RENVOYÉE

termkey_push_bytes() renvoie le nombre d'octets consommés de l'entrée (qui peut être inférieur à la longueur fournie, si le tampon manque d'espace) ou -1 casté en size_t si une erreur se produit, auquel cas errno est défini en conséquence.

VOIR AUSSI

termkey_getkey(3), termkey_advisereadable(3), termkey(7)
