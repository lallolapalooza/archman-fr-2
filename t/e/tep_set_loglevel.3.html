NOM

tep_set_loglevel - Définit le niveau de journalisation de la bibliothèque

SYNOPSIS

#include <event-parse.h>
enum tep_loglevel {
        TEP_LOG_NONE = 0,
        TEP_LOG_CRITICAL,
        TEP_LOG_ERROR,
        TEP_LOG_WARNING,
        TEP_LOG_INFO,
        TEP_LOG_DEBUG,
        TEP_LOG_ALL
};
int tep_set_loglevel(enum tep_loglevel level);

DESCRIPTION

La fonction tep_set_loglevel() définit le niveau des journaux de la bibliothèque qui seront imprimés sur la console. Les niveaux de journalisation de la bibliothèque sont :

        TEP_LOG_NONE - Ne pas imprimer de journaux.
        TEP_LOG_CRITICAL - Imprimer les journaux critiques, problèmes qui pourraient entraîner un crash.
        TEP_LOG_ERROR - Imprimer les journaux d'erreur, problèmes qui pourraient casser la logique principale d'une API.
        TEP_LOG_WARNING - Imprimer les avertissements, problèmes qui pourraient limiter le résultat d'une API.
        TEP_LOG_INFO - Imprimer des informations sur l'exécution normale d'une API.
        TEP_LOG_DEBUG - Imprimer des informations de débogage.
        TEP_LOG_ALL - Imprimer les journaux de tous les niveaux.

Définir le niveau de journalisation à une valeur spécifique signifie que les journaux des niveaux précédents seront également imprimés. Par exemple, TEP_LOG_WARNING imprimera tous les journaux avec une sévérité TEP_LOG_WARNING, TEP_LOG_ERROR et TEP_LOG_CRITICAL. Le niveau de journalisation par défaut est TEP_LOG_CRITICAL.

EXEMPLE

#include <event-parse.h>
tep_set_loglevel(TEP_LOG_ALL);
...
/* appeler les API libtraceevent et observer les journaux qu'elles produisent */
...
tep_set_loglevel(TEP_LOG_CRITICAL);
