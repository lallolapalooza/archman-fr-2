TERMKEY_STRFKEY(3) Manuel des fonctions de bibliothèque TERMKEY_STRFKEY(3)

NOM

termkey_strfkey - formater une chaîne représentant un événement de touche

SYNOPSIS

#include <termkey.h>

size_t termkey_strfkey(TermKey *tk, char *buffer, size_t len,
            TermKeyKey *key, TermKeyFormat format);

Lier avec -ltermkey.

DESCRIPTION

termkey_strfkey() formate un tampon de chaîne pour contenir une représentation lisible par l'homme d'un événement de touche. Il remplit le buffer d'une manière analogue aux fonctions de la bibliothèque standard snprintf(3) ou strftime(3). Cette fonction s'appelait auparavant termkey_snprint_key() mais a été renommée après la version 0.6.

L'argument format spécifie le format de la sortie, sous forme de masque de bits des constantes suivantes :

TERMKEY_FORMAT_LONGMOD
Afficher les noms complets des modificateurs, par ex. "Shift-" au lieu d'abréger en "S-".
TERMKEY_FORMAT_CARETCTRL
Si le seul modificateur est TERMKEY_MOD_CTRL sur une lettre simple, le représenter comme "^X" plutôt que "Ctrl-X".
TERMKEY_FORMAT_ALTISMETA
Utiliser le nom "Meta" ou la lettre "M" au lieu de "Alt" ou "A".
TERMKEY_FORMAT_WRAPBRACKET
Si l'événement de touche est une touche spéciale au lieu de Unicode non modifié, l'encapsuler entre "<crochets>".
TERMKEY_FORMAT_SPACEMOD
Utiliser des espaces au lieu de traits d'union pour séparer le(s) nom(s) du modificateur du nom de la touche de base.
TERMKEY_FORMAT_LOWERMOD
Utiliser des minuscules pour le nom du modificateur.
TERMKEY_FORMAT_LOWERSPACE
Utiliser des minuscules avec des espaces pour le nom de la touche au lieu de camelCase (par exemple "page down" au lieu de "PageDown").
TERMKEY_FORMAT_MOUSE_POS
Si l'événement est un événement de souris, inclure la position rendue comme "@ (col,ligne)".

Les raccourcis suivants sont fournis pour les combinaisons courantes de bits de format :

TERMKEY_FORMAT_VIM
Raccourci pour définir ALTISMETA et WRAPBRACKET, afin de donner une sortie proche du format utilisé par l'éditeur vim.
TERMKEY_FORMAT_URWID
Raccourci pour définir ALTISMETA, LONGMOD, LOWERMOD, SPACEMOD et LOWERSPACE, afin de donner une sortie proche du format utilisé par la bibliothèque Python urwid.

Lors du formatage d'une structure de touche TERMKEY_TYPE_UNICODE, cette fonction utilise le membre utf8. Si ce membre contient une chaîne vide (c'est-à-dire que son premier caractère est 0), ce membre sera pré-rempli par la fonction à partir du membre code.number. Cela peut être pratique lorsque la structure de touche est construite par programme par le code utilisateur.

VALEUR DE RETOUR

termkey_strfkey() renvoie le nombre de caractères écrits dans buffer.
