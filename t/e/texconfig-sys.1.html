NOM

texconfig - configure teTeX ou TeX Live

texconfig-sys - configure teTeX ou TeX Live pour tout le système

SYNTAXE

texconfig

texconfig [ commandes ...]

texconfig-sys

DESCRIPTION

texconfig permet de configurer et de maintenir TeX de manière facile et pratique, en offrant à l'utilisateur une série de boîtes de dialogue. Le répertoire dans lequel texconfig se trouve est également utilisé de manière préférentielle pour trouver les sous-programmes.

Le programme tlmgr a absorbé cette fonction pour TeX Live. Ce programme est toujours supporté, mais l'interface tlmgr est beaucoup plus activement développée et testée.

Après avoir choisi des paramètres ou des options, les fichiers appropriés sont automatiquement modifiés et les nouveaux paramètres sont appliqués pour l'utilisateur. Si nécessaire, des copies des fichiers dans TEXMFDIST ou TEXMFMAIN seront créées dans l'arborescence TEXMFCONFIG de l'utilisateur.

texconfig utilise soit le programme whiptail(1), soit dialog(1) pour communiquer avec l'utilisateur, il doit donc être exécuté dans un terminal.

Pour effectuer des modifications à l'échelle du système, qui s'appliqueront à tous les utilisateurs de TeX (par exemple, la taille de papier par défaut, etc.), exécutez plutôt texconfig-sys. Les fichiers modifiés ou générés seront placés dans TEXMFSYSCONFIG. (Vous pourriez avoir besoin des privilèges root pour cela.)

texconfig propose également un mode batch non interactif accessible avec les commandes suivantes

COMMANDES

Les commandes qui acceptent des options supplémentaires affichent généralement les options disponibles lorsqu'elles sont appelées sans elles. Par exemple, texconfig dvipdfm paper informera sur les paramètres de papier valides.

conf
Affiche la configuration du système.
dvipdfm paper [letter|legal|ledger|tabloid|a4|a3]
Configure dvipdfm pour utiliser par défaut le format de papier PAPER.
dvips add NOM_IMPRIMANTE
Crée un nouveau fichier de configuration (vide) TEXMFCONFIG/dvips/config/config.NOM_IMPRIMANTE. Ce fichier peut être rempli plus tard avec les options mode, offset ou printcmd
dvips del NOM_IMPRIMANTE
Supprime config.NOM_IMPRIMANTE
dvips mode
Liste les modes d'imprimante Metafont disponibles.
dvips [-P IMPRIMANTE] mode MODE
Change le mode Metafont à MODE pour IMPRIMANTE ou pour tous les fichiers de sortie (config.ps), si aucune option -P n'est fournie.
dvips [-P IMPRIMANTE] offset x-OFFSET,y-OFFSET
Définit le décalage de l'imprimante pour IMPRIMANTE ou pour tous les fichiers de sortie (config.ps), si aucune option -P n'est fournie. Les décalages doivent être fournis avec des unités, par exemple 0pt,10pt Vous pouvez utiliser testpage.tex de la distribution LaTeX pour trouver ces nombres.
dvips [-P IMPRIMANTE] printcmd CMD
Définit la commande d'impression pour IMPRIMANTE ou pour tous les fichiers de sortie (config.ps), si aucune option -P n'est fournie. Les commandes peuvent être lp ou lpr. Voir la description de l'option o dans info dvips ou l'option -O dans dvips(1).
faq
Affiche la liste des questions fréquemment posées sur teTeX (et leurs réponses).
font vardir DIR, font ro, font rw
formats
Cette commande permet d'éditer fmtutil.cnf(5) et de (re)créer tous les formats nouveaux ou modifiés par la suite.
hyphen FORMAT
Cette commande permet d'éditer le fichier de configuration de césure pour les formats qui le supportent, et recrée ensuite les formats pour activer les nouvelles langues. Les formats disponibles sont affichés si aucun FORMAT n'est donné.
Notez que pour les formats qui utilisent language.dat de LaTeX,
par exemple (pdf)jadetex et latex lui-même, cette modification n'est pas persistante, car ce fichier est un fichier généré. Vous ne devriez pas utiliser cette commande dans ces cas, lisez update-language(1) pour des alternatives.
init [format]
Recrée format ou tous les formats si aucun n'est donné, ainsi que les informations sur les polices. Ceci équivaut à appeler fmtutil --byfmt format ou fmtutil --all, suivi de updmap.
mode-list
Liste les modes d'imprimante disponibles, ainsi que les imprimantes pour lesquelles ils ont été développés, et leur résolution DPI.
mode MODE
Définit le mode d'imprimante par défaut dans /etc/texmf/web2c/mktex.cnf ou le fichier utilisateur respectif dans $TEXMFCONFIG/web2c à MODE.
paper [a4|letter]
Définit le format de papier par défaut pour dvips, dvipdfm, pdftex et xdvi. L'ensemble est restreint car tous les programmes ne comprennent pas toutes les tailles.
pdftex paper [a4|letter]
Définit le format de papier par défaut pour pdftex.
rehash
Appelle mktexlsr.
xdvi paper PAPER
Définit le format de papier par défaut pour xdvi. La liste (longue) est disponible avec texconfig xdvi paper.

ENVIRONNEMENT

Pour vous permettre de modifier des fichiers, texconfig ouvrira l'éditeur spécifié dans les variables VISUAL ou EDITOR, ou sensible-editor si les deux sont non définies.

VOIR AUSSI

whiptail(1), dialog(1), tlmgr(1), tex(1), mf(1), vi(1), variable d'environnement EDITOR.

NOM

texconfig-sys - utilitaire de configuration pour TeX Live, destiné à l'administrateur système.

SYNTAXE

texconfig-sys [options]

DESCRIPTION

texconfig-sys est un outil interactif qui permet à l'administrateur système de configurer TeX Live. Il offre des fonctionnalités pour la gestion des chemins, des polices, des imprimantes et d'autres paramètres système propres à TeX Live.

OPTIONS

  • --help : Affiche l'aide et quitte.
  • --version : Affiche les informations de version et quitte.

EXEMPLES

Pour lancer l'outil de configuration interactif :

texconfig-sys

VOIR AUSSI

texconfig(1), tex(1), texdoc(1).
