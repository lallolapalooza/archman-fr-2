TEXDIFF(1) Documentation Perl fournie par l'utilisateur TEXDIFF(1)

NOM

texdiff - Compare deux documents (La)TeX pour créer une version fusionnée affichant les modifications, similaire au « Suivi des modifications » de certains traitements de texte.

SYNOPSIS

texdiff [--nofloats⎪-n] ancien.tex nouveau.tex [diff.tex]

DESCRIPTION

Les deux premiers fichiers sont comparés et un nouveau fichier TeX est généré. Lorsque le fichier de sortie est traité avec (La)TeX, il marque les nouvelles modifications en bleu et le texte ancien en rouge avec une ligne barrée. De plus, les passages avec des modifications sont marqués dans la marge avec des barres grises par le paquet LaTeX "changebar" (bien que seulement après avoir exécuté "dvips" ; dans "xdvi", les barres sont décalées d'un pouce vers la gauche pour compenser le décalage d'un pouce inséré par les pilotes d'impression TeX).

"texdiff" utilise et nécessite donc la commande "wdiff" pour insérer ces marques. Si des macros LaTeX sont incluses dans ces passages barrés ou soulignés, l'exécution de LaTeX échouera très probablement. La source de la plupart des problèmes réside dans le fait que "wdiff" décompose les paires d'accolades. Par conséquent, "texdiff" est un script Perl qui appelle "wdiff" en interne et corrige la sortie de "wdiff" en rétablissant les paires d'accolades et en gérant certaines macros LaTeX couramment utilisées.

Pour que texdiff fonctionne, le code LaTeX suivant doit être inséré dans le préambule du document LaTeX :

\usepackage{xcolor} \usepackage{ulem} \usepackage{changebar}
\newcommand\TLSins[1]{\cbstart{}\textcolor{ins}{\uline{#1}}\cbend{}}
\newcommand\TLSdel[1]{\cbdelete{}\textcolor{del}{\sout{#1}}}

Définissez les couleurs d'édition "ins" et "del" avec des noms de couleurs "xcolor" existants :
\colorlet{ins}{blue} \colorlet{del}{red}

Ou à partir de zéro :
\definecolor{ins}{rgb}{0, 0.5, 0}

Ces macros ne sont PAS insérées automatiquement à \begin{document} comme le faisaient les scripts originaux (voir la section REMERCIEMENTS ci-dessous), car cela ne fonctionnerait pas sur les fichiers d'un document multi-fichiers (ceux inclus par \include ou \input). De plus, si vous insérez les macros manuellement, vous pouvez les ajuster comme vous le souhaitez, c'est-à-dire changer la couleur du texte ou la position des barres de modification. Consultez la documentation des paquets ulem et changebar pour savoir comment faire !

OPTIONS

--nofloats, -n
Si spécifié, saute le contenu des environnements de figure, mais affiche les insertions et suppressions dans les commandes de légende. Ceci est fait pour éviter des confusions complexes dans les environnements de sous-figures ou complexes.
--debug, -d
Active le mode débogage. Les fichiers temporaires contenant des accolades numérotées sont conservés et un fichier de différence brute est écrit sous le nom du fichier de sortie auquel est ajouté '-wdiff.tex'. De plus, plusieurs diagnostics d'expressions régulières sont affichés. Attention : produit une grande quantité de sortie.
