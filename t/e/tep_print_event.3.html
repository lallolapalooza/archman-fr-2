tep_print_event(3)

Paquet: libtraceevent

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manuel libtraceevent LIBTRACEEVENT(3)

NOM

tep_print_event - Écrit les informations d'événement dans une séquence de traçage.

SYNTAXE

#include <event-parse.h>
#include <trace-seq.h>
void tep_print_event(struct tep_handle *tep, struct trace_seq*s, struct tep_record *record, const char *fmt, ...)

DESCRIPTION

La fonction tep_print_event() analyse les informations d'événement de l'enregistrement record donné et les écrit dans la séquence de traçage s, selon la chaîne de format fmt. Les informations souhaitées sont spécifiées après la chaîne de format. La chaîne fmt est une chaîne de format de type printf, les arguments suivants sont pris en charge :

        TEP_PRINT_PID, "%d"  - PID de l'événement.
        TEP_PRINT_CPU, "%d"  - CPU de l'événement.
        TEP_PRINT_COMM, "%s" - Chaîne de commande de l'événement.
        TEP_PRINT_NAME, "%s" - Nom de l'événement.
        TEP_PRINT_LATENCY, "%s" - Latence de l'événement. Elle imprime 4 champs ou plus
                        - état d'interruption, état de planification,
                        contexte actuel, et compteur de préemption.
                        Le champ 1 est l'état d'activation des interruptions :
                                d : Interruptions désactivées
                                . : Interruptions activées
                                X : L'architecture ne prend pas en charge cette
                                    information
                        Le champ 2 est l'état de "need resched".
                                N : La tâche est marquée pour appeler le planificateur lorsque
                                    possible, car une autre tâche de priorité supérieure
                                    peut devoir être planifiée.
                                . : La tâche n'est pas marquée pour appeler le planificateur.
                        Le champ 3 est l'état du contexte.
                                . : Contexte normal
                                s : Contexte d'interruption logicielle
                                h : Contexte d'interruption matérielle
                                H : Contexte d'interruption matérielle déclenché
                                    pendant un contexte d'interruption logicielle.
                                z : Contexte NMI
                                Z : Contexte NMI déclenché pendant un contexte d'interruption matérielle
                        Le champ 4 est le compteur de préemption.
                                . : Le compteur de préemption est à zéro.
                        Sur les noyaux préemptibles (où la tâche peut être déplacée à
                        chaque instant dans le contexte du noyau), le compteur de préemption,
                        lorsqu'il est non nul, empêchera la planification de la tâche actuelle.
                        Le nombre du compteur de préemption est affiché lorsqu'il n'est pas nul.
                        Selon le noyau, il peut afficher d'autres champs
                        (profondeur de verrouillage, ou migration désactivée, qui sont spécifiques
                        aux noyaux spécialisés).
        TEP_PRINT_TIME, %d - estampille temporelle de l'événement. Un diviseur et une précision peuvent être
                        spécifiés dans cette chaîne de format :
                        "%precision.divisord". Exemple :
                        "%3.1000d" - diviser le temps par 1000 et afficher les 3
                        premiers chiffres avant le point. Ainsi, l'estampille temporelle
                        "123456000" sera affichée comme "123.456"
        TEP_PRINT_INFO, "%s" - informations sur l'événement.
        TEP_PRINT_INFO_RAW, "%s" - informations sur l'événement, au format brut.

EXEMPLE

#include <event-parse.h>
#include <trace-seq.h>
...
struct trace_seq seq;
trace_seq_init(&seq);
struct tep_handle *tep = tep_alloc();
...
void print_my_event(struct tep_record *record)
{
        trace_seq_reset(&seq);
        tep_print_event(tep, s, record, "%16s-%-5d [%03d] %s %6.1000d %s %s",
                        TEP_PRINT_COMM, TEP_PRINT_PID, TEP_PRINT_CPU,
                        TEP_PRINT_LATENCY, TEP_PRINT_TIME, TEP_PRINT_NAME,
                        TEP_PRINT_INFO);
}
...

FICHIERS

event-parse.h
        Fichier d'en-tête pour inclure l'accès aux API de la bibliothèque.
trace-seq.h
        Fichier d'en-tête pour inclure l'accès aux API relatives aux séquences de traçage.
        Les séquences de traçage sont utilisées pour permettre à une fonction d'appeler plusieurs autres fonctions
        pour créer une chaîne de données à utiliser.
-ltraceevent
        Commutateur de lieur à ajouter lors de la compilation d'un programme utilisant la bibliothèque.
