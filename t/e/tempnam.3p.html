TEMPNAM(3P) Manuel du programmeur POSIX TEMPNAM(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement de Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

tempnam — créer un nom pour un fichier temporaire

SYNTAXE

#include <stdio.h>
char *tempnam(const char *dir, const char *pfx);

DESCRIPTION

La fonction tempnam() génère un nom de chemin qui peut être utilisé pour un fichier temporaire.

La fonction tempnam() permet à l'utilisateur de contrôler le choix d'un répertoire. L'argument dir pointe vers le nom du répertoire dans lequel le fichier doit être créé. Si dir est un pointeur nul ou pointe vers une chaîne qui n'est pas un nom de répertoire approprié, le préfixe de chemin défini comme P_tmpdir dans l'en-tête <stdio.h> sera utilisé. Si ce répertoire n'est pas accessible, un répertoire défini par l'implémentation peut être utilisé.

De nombreuses applications préfèrent que leurs fichiers temporaires aient certaines séquences de lettres initiales dans leurs noms. L'argument pfx doit être utilisé à cette fin. Cet argument peut être un pointeur nul ou pointer vers une chaîne de jusqu'à cinq octets à utiliser comme début du nom de fichier.

Certaines implémentations de tempnam() peuvent utiliser tmpnam() en interne. Sur de telles implémentations, si elle est appelée plus de {TMP_MAX} fois dans un seul processus, le comportement est défini par l'implémentation.

VALEUR DE RETOUR

En cas de succès, tempnam() allouera de l'espace pour une chaîne, y placera le nom de chemin généré et retournera un pointeur vers celle-ci. Le pointeur sera utilisable dans un appel ultérieur à free(). Sinon, elle retournera un pointeur nul et définira errno pour indiquer l'erreur.

ERREURS

La fonction tempnam() échouera si :

ENOMEM
Espace de stockage insuffisant disponible.

Les sections suivantes sont informatives.

EXEMPLES

Génération d'un nom de chemin

L'exemple suivant génère un nom de chemin pour un fichier temporaire dans le répertoire /tmp, avec le préfixe file. Après la création du nom de chemin, l'appel à free() désalloue l'espace utilisé pour stocker le nom de chemin.

#include <stdio.h>
#include <stdlib.h>
...
const char *directory = "/tmp";
const char *fileprefix = "file";
char *file;
file = tempnam(directory, fileprefix);
free(file);

UTILISATION PAR L'APPLICATION

Cette fonction crée uniquement des noms de chemin. Il incombe à l'application de créer et de supprimer les fichiers. Entre le moment où un nom de chemin est créé et le moment où le fichier est ouvert, il est possible qu'un autre processus crée un fichier avec le même nom. Les applications peuvent trouver tmpfile() plus utile.

Les applications doivent utiliser les fonctions tmpfile(), mkdtemp() ou mkstemp() à la place de la fonction obsolète tempnam().

RATIONALE

Aucun.

ORIENTATIONS FUTURES

La fonction tempnam() pourrait être supprimée dans une future version.

VOIR AUSSI

fopen(), free(), mkdtemp(), open(), tmpfile(), tmpnam(), unlink()
