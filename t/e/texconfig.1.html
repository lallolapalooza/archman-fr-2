texconfig(1) TeX Live texconfig(1)

NOM

texconfig - configure teTeX ou TeX Live

texconfig-sys - configure teTeX ou TeX Live pour tout le système

SYNOPIS

texconfig

texconfig [ commandes ...]

texconfig-sys

DESCRIPTION

texconfig permet de configurer et de maintenir TeX de manière facile et pratique, en offrant une série de boîtes de dialogue à l'utilisateur. Le répertoire dans lequel se trouve texconfig est également utilisé de préférence pour trouver les sous-programmes.

Le programme tlmgr a absorbé cette fonction pour TeX Live. Ce programme est toujours pris en charge, mais l'interface tlmgr est beaucoup plus activement développée et testée.

Après avoir choisi des paramètres ou des options, les fichiers appropriés sont automatiquement modifiés et les nouveaux paramètres sont appliqués pour l'utilisateur. Si nécessaire, des copies des fichiers dans TEXMFDIST ou TEXMFMAIN seront créées dans l'arbre TEXMFCONFIG de l'utilisateur.

texconfig utilise le programme whiptail(1) ou dialog(1) pour communiquer avec l'utilisateur, il doit donc être exécuté dans un terminal.

Pour apporter des modifications à l'échelle du système, qui s'appliqueront à tous les utilisateurs de TeX (par exemple, la taille de papier par défaut, etc.), exécutez texconfig-sys à la place. Les fichiers modifiés ou générés seront placés dans TEXMFSYSCONFIG. (Vous devrez peut-être être root pour ce faire.)

texconfig offre également un mode batch non interactif auquel on peut accéder avec les commandes suivantes

COMMANDES

Les commandes qui acceptent des options supplémentaires affichent généralement les options disponibles si elles sont appelées sans elles. Par exemple, texconfig dvipdfm paper informera sur les paramètres de papier valides.

conf
Affiche la configuration du système.
dvipdfm paper [letter|legal|ledger|tabloid|a4|a3]
Configure dvipdfm pour utiliser par défaut le format de papier PAPER.
dvips add NOM_IMPRIMANTE
Crée un nouveau fichier de configuration (vide) TEXMFCONFIG/dvips/config/config.NOM_IMPRIMANTE. Ce fichier peut plus tard être rempli avec les options mode, offset ou printcmd
dvips del NOM_IMPRIMANTE
Supprime config.NOM_IMPRIMANTE
dvips mode
Liste les modes Metafont disponibles.
dvips [-P IMPRIMANTE] mode MODE
Change le mode Metafont à MODE pour IMPRIMANTE ou pour tous les fichiers de sortie (config.ps), si aucune option -P n'est donnée.
dvips [-P IMPRIMANTE] offset DECALAGE_X,DECALAGE_Y
Définit le décalage d'imprimante pour IMPRIMANTE ou pour tous les fichiers de sortie (config.ps), si aucune option -P n'est donnée. Les décalages doivent être donnés avec des unités, par exemple 0pt,10pt Vous pouvez utiliser testpage.tex de la distribution LaTeX pour trouver ces nombres.
dvips [-P IMPRIMANTE] printcmd COMMANDE
Définit la commande d'impression pour IMPRIMANTE ou pour tous les fichiers de sortie (config.ps), si aucune option -P n'est donnée. Les commandes peuvent être lp ou lpr. Voir la description de l'option o dans info dvips ou l'option -O dans dvips(1).
faq
Affiche la liste des questions fréquemment posées sur teTeX (et leurs réponses).
font vardir DIR, font ro, font rw
formats
Cette commande permet de modifier fmtutil.cnf(5) et de (re)créer tous les formats nouveaux ou modifiés par la suite.
hyphen FORMAT
Cette commande permet de modifier le fichier de configuration des césures pour les formats qui le supportent, et recrée les formats par la suite pour activer les nouvelles langues. Les formats disponibles sont affichés lorsqu'aucun FORMAT n'est donné.
Notez que pour les formats qui utilisent le fichier language.dat de LaTeX, par exemple (pdf)jadetex et latex lui-même, cette modification n'est pas persistante, car ce fichier est un fichier généré. Vous ne devriez pas utiliser cette commande dans ces cas, consultez update-language(1) pour les alternatives.
init [format]
Recrée format ou tous les formats si aucun n'est donné, ainsi que les informations sur les polices. Ceci est équivalent à appeler fmtutil --byfmt format ou fmtutil --all, respectivement, suivi de updmap.
mode-list
Liste les modes d'imprimante disponibles, ainsi que les imprimantes pour lesquelles ils ont été développés, et leur résolution DPI.
mode MODE
Définit le mode d'imprimante par défaut dans /etc/texmf/web2c/mktex.cnf ou le fichier utilisateur respectif dans $TEXMFCONFIG/web2c à MODE.
paper [a4|letter]
Définit la taille de papier par défaut pour dvips, dvipdfm, pdftex et xdvi. L'ensemble est restreint car tous les programmes ne comprennent pas toutes les tailles.
pdftex paper [a4|letter]
Définit la taille de papier par défaut pour pdftex.
rehash
Appelle mktexlsr.
xdvi paper PAPER
Définit la taille de papier par défaut pour xdvi. La liste (longue) est disponible avec texconfig xdvi paper.

ENVIRONNEMENT

Pour vous permettre de modifier des fichiers, texconfig ouvrira l'éditeur spécifié dans les variables VISUAL ou EDITOR, ou sensible-editor si les deux sont non définies.

VOIR AUSSI

whiptail(1), dialog(1), tlmgr(1), tex(1), mf(1), vi(1), variable d'environnement EDITOR.
