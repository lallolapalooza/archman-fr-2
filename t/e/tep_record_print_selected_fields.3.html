tep_record_print_selected_fields(3)

Paquet: libtraceevent

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manuel libtraceevent LIBTRACEEVENT(3)

NOM

tep_print_field_content, tep_print_fields, tep_print_num_field, tep_print_func_field, tep_record_print_fields, tep_record_print_selected_fields - Afficher le contenu des champs.

SYNTAXE

#include <event-parse.h>
#include <trace-seq.h>
void tep_print_field_content(struct trace_seq *s, void *data, int size, struct tep_format_field *field);
void tep_print_fields(struct trace_seq *s, void *data, int size, struct tep_event *event);
int tep_print_num_field(struct trace_seq *s, const char *fmt, struct tep_event *event, const char *name, struct tep_record *record, int err);
int tep_print_func_field(struct trace_seq *s, const char *fmt, struct tep_event *event, const char *name, struct tep_record *record, int err);
void tep_record_print_fields(struct trace_seq *s, struct tep_record *record, struct tep_event *event);
void tep_record_print_selected_fields(struct trace_seq *s, struct tep_record *record, struct tep_event *event, int select_mask);

DESCRIPTION

Ces fonctions affichent les données des champs enregistrés, selon le type du champ.

La fonction tep_print_field_content() extrait la valeur du champ field à partir des données brutes enregistrées et l'affiche dans s, selon le type du champ.

La fonction tep_print_fields() affiche chaque nom de champ suivi de la valeur du champ de l'enregistrement selon le type du champ :

"nom_champ1=valeur_champ1 nom_champ2=valeur_champ2 ..."

Elle parcourt tous les champs de l'événement et appelle tep_print_field_content() pour chacun d'eux.

La fonction tep_print_num_field() affiche un champ numérique avec une chaîne de formatage donnée. Une recherche est effectuée dans l'événement pour un champ portant le nom name. Si un tel champ est trouvé, sa valeur est extraite de l'enregistrement et affichée dans s, selon la chaîne de formatage fmt donnée. Si l'argument err est différent de zéro, et qu'une erreur se produit, elle est affichée dans s.

La fonction tep_print_func_field() affiche un champ de fonction avec une chaîne de formatage donnée. Une recherche est effectuée dans l'événement pour un champ portant le nom name. Si un tel champ est trouvé, sa valeur est extraite de l'enregistrement. La valeur est supposée être une adresse de fonction, et une recherche est effectuée pour trouver le nom de cette fonction. Le nom de la fonction (si trouvé) et son adresse sont affichés dans s, selon la chaîne de formatage fmt donnée. Si l'argument err est différent de zéro, et qu'une erreur se produit, elle est affichée dans s.

La fonction tep_record_print_fields() affiche le nom du champ suivi de sa valeur pour tous les champs de l'enregistrement.

La fonction tep_record_print_selected_fields() affiche le nom du champ suivi de sa valeur pour un sous-ensemble sélectionné de champs de l'enregistrement. Les champs à afficher sont définis par le masque de bits select_mask.

VALEUR DE RETOUR

Les fonctions tep_print_num_field() et tep_print_func_field() retournent 1 en cas de succès, -1 en cas d'erreur, ou 0 si le tampon d'affichage s est plein.

EXEMPLE

#include <event-parse.h>
#include <trace-seq.h>
...
struct tep_handle *tep = tep_alloc();
...
struct trace_seq seq;
trace_seq_init(&seq);
struct tep_event *event = tep_find_event_by_name(tep, "timer", "hrtimer_start");
...
void process_record(struct tep_record *record)
{
        struct tep_format_field *field_pid = tep_find_common_field(event, "common_pid");
        trace_seq_reset(&seq);
        /* Afficher la valeur de "common_pid" */
        tep_print_field_content(&seq, record->data, record->size, field_pid);
        /* Afficher tous les champs de l'événement "hrtimer_start" */
        tep_print_fields(&seq, record->data, record->size, event);
        /* Afficher la valeur du champ "expires" avec une chaîne de formatage personnalisée */
        tep_print_num_field(&seq, " l'expiration du minuteur est dans %llu ", event, "expires", record, 0);
        /* Afficher l'adresse et le nom du champ "function" avec une chaîne de formatage personnalisée */
        tep_print_func_field(&seq, " la fonction du minuteur est %s ", event, "function", record, 0);
 }
 ...
