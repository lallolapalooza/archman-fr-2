termkey_set_canonflags(3)

Paquet: libtermkey

Licences: MIT

TERMKEY_SET_CANONFLAGS(3) Manuel des fonctions de bibliothèque TERMKEY_SET_CANONFLAGS(3)

NOM

termkey_set_canonflags, termkey_get_canonflags - contrôler les indicateurs de canonicalisation

SYNTAXE

#include <termkey.h>

void termkey_set_canonflags(TermKey *tk, int newflags);
int termkey_get_canonflags(TermKey *tk);

Lier avec -ltermkey.

DESCRIPTION

termkey_set_canonflags() change l'ensemble des indicateurs de canonicalisation dans l'instance termkey(7) pour ceux fournis par newflags. Pour plus de détails sur les indicateurs disponibles et leur signification, voir la page de manuel termkey.

termkey_get_canonflags() retourne la valeur définie par le dernier appel à termkey_set_canonflags().

VALEUR DE RETOUR

termkey_set_canonflags() ne retourne aucune valeur. termkey_get_canonflags() retourne les indicateurs de canonicalisation actuels.

VOIR AUSSI

termkey_canonicalise(3), termkey(7)
