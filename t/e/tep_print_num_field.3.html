tep_print_num_field(3)

Paquet: libtraceevent

LIBTRACEEVENT(3) Manuel libtraceevent LIBTRACEEVENT(3)

NOM

tep_print_field_content, tep_print_fields, tep_print_num_field, tep_print_func_field, tep_record_print_fields, tep_record_print_selected_fields - Imprimer le contenu des champs.

SYNOPSIS

#include <event-parse.h>
#include <trace-seq.h>
void tep_print_field_content(struct trace_seq *s, void *data, int size, struct tep_format_field *field);
void tep_print_fields(struct trace_seq *s, void *data, int size, struct tep_event *event);
int tep_print_num_field(struct trace_seq *s, const char *fmt, struct tep_event *event, const char *name, struct tep_record *record, int err);
int tep_print_func_field(struct trace_seq *s, const char *fmt, struct tep_event *event, const char *name, struct tep_record *record, int err);
void tep_record_print_fields(struct trace_seq *s, struct tep_record *record, struct tep_event *event);
void tep_record_print_selected_fields(struct trace_seq *s, struct tep_record *record, struct tep_event *event, int select_mask);

DESCRIPTION

Ces fonctions impriment les données des champs enregistrés, en fonction du type de champ.

La fonction tep_print_field_content() extrait de la valeur brute enregistrée data du field et l'imprime dans s, selon le type de champ.

La fonction tep_print_fields() imprime le nom de chaque champ suivi de la valeur du champ de l'enregistrement selon le type de champ :

"nom_champ1=valeur_champ1 nom_champ2=valeur_champ2 ..."

Elle itère sur tous les champs de l'event et appelle tep_print_field_content() pour chacun d'eux.

La fonction tep_print_num_field() imprime un champ numérique avec la chaîne de formatage donnée. Une recherche est effectuée dans l'event pour un champ avec le nom name. Si un tel champ est trouvé, sa valeur est extraite de l'record et est imprimée dans s, selon la chaîne de formatage fmt donnée. Si l'argument err est non nul et qu'une erreur se produit, elle est imprimée dans s.

La fonction tep_print_func_field() imprime un champ de fonction avec la chaîne de formatage donnée. Une recherche est effectuée dans l'event pour un champ avec le nom name. Si un tel champ est trouvé, sa valeur est extraite de l'record. La valeur est supposée être une adresse de fonction, et une recherche est effectuée pour trouver le nom de cette fonction. Le nom de la fonction (si trouvé) et son adresse sont imprimés dans s, selon la chaîne de formatage fmt donnée. Si l'argument err est non nul et qu'une erreur se produit, elle est imprimée dans s.

La fonction tep_record_print_fields() imprime le nom du champ suivi de sa valeur pour tous les champs de l'enregistrement.

La fonction tep_record_print_selected_fields() imprime le nom du champ suivi de sa valeur pour un sous-ensemble sélectionné de champs de l'enregistrement. Les champs à imprimer sont définis par le masque de bits select_mask.

VALEUR DE RETOUR

Les fonctions tep_print_num_field() et tep_print_func_field() retournent 1 en cas de succès, -1 en cas d'erreur, ou 0 si le tampon d'impression s est plein.

EXEMPLE

#include <event-parse.h>
#include <trace-seq.h>
...
struct tep_handle *tep = tep_alloc();
...
struct trace_seq seq;
trace_seq_init(&seq);
struct tep_event *event = tep_find_event_by_name(tep, "timer", "hrtimer_start");
...
void process_record(struct tep_record *record)
{
        struct tep_format_field *field_pid = tep_find_common_field(event, "common_pid");
        trace_seq_reset(&seq);
        /* Imprimer la valeur de "common_pid" */
        tep_print_field_content(&seq, record->data, record->size, field_pid);
        /* Imprimer tous les champs de l'événement "hrtimer_start" */
        tep_print_fields(&seq, record->data, record->size, event);
        /* Imprimer la valeur du champ "expires" avec une chaîne de formatage personnalisée */
        tep_print_num_field(&seq, " le délai d'expiration du timer est de %llu ", event, "expires", record, 0);
        /* Imprimer l'adresse et le nom du champ "function" avec une chaîne de formatage personnalisée */
        tep_print_func_field(&seq, " la fonction du timer est %s ", event, "function", record, 0);
 }
 ...

tep_print_num_field.3

Print a number field

NAME

tep_print_num_field - Print a number field

SYNOPSIS

tep_print_num_field(field, buf, size)

DESCRIPTION

The tep_print_num_field function prints the value of a number field into a buffer.

Parameters:

  • field: A pointer to the number field to print.
  • buf: The buffer to print the number into.
  • size: The size of the buffer.

RETURN VALUE

Returns the number of bytes written to the buffer, or a negative value on error.

EXAMPLE

// Example usage:
char buffer[100];
// Assuming 'num_field' is a valid tep_number_field pointer
int bytes_written = tep_print_num_field(num_field, buffer, sizeof(buffer));
if (bytes_written < 0) {
    // Handle error
} else {
    printf("Number: %s\n", buffer);
}
