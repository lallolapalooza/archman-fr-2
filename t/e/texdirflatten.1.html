NOM

texdirflatten - Collecte tous les composants d'un fichier (La)TeX dans un répertoire de sortie unique — c'est-à-dire, aplatit sa hiérarchie.

SYNTAXE

texdirflatten [-1|--onetex] [-f|--file fichier_entree.tex] [-o rep_sortie]
[--imgexts .ext1,.ext2,...] [--debug] [-V|--version] [-?|--help]

DESCRIPTION

Ce script Perl analyse récursivement un fichier LaTeX, en parcourant tous les fichiers enfants, et collecte des informations sur tous les fichiers inclus et autres fichiers de données, tels que les graphiques et les fichiers de bibliographie BiBTeX. Ces fichiers composants sont ensuite tous placés dans un répertoire unique (aplatissant ainsi l'arborescence du document). Ceci est utile pour distribuer des manuscrits à des collaborateurs ou pour soumettre à des journaux.

OPTIONS

--file, -f fichier.tex
Spécifie le fichier (La)TeX d'entrée.
--onetex, -1
Si spécifié, produit un fichier TeX unique en développant toutes les commandes \input et \include sur place.
--output, -o rep_sortie
Répertoire où collecter tous les fichiers. texdirflatten copiera chaque fichier source, graphique et fichier de bibliographie dans ce répertoire. Il sera créé s'il n'existe pas. S'il n'est pas spécifié, il prend par défaut "flat/".
--imgexts .ext1,.ext2[,...]
Ajoute en tête de la liste prioritaire des extensions d'images à rechercher lorsqu'on essaie de trouver l'image à copier dans le dossier de sortie. Le premier fichier trouvé avec l'extension sera copié et la recherche s'arrêtera. L'ordre par défaut est "", ".eps", ".pdf", ".pstex" (notez que cela inclut les fichiers sans extension). Si vous utilisez pdflatex, vous pourriez vouloir ajouter PDF avant EPS avec "--imgexts .pdf". N'oubliez pas le point avant l'extension !
--debug
Active une quantité importante de sorties de débogage — utile si quelque chose ne fonctionne pas.
--version, -V
Affiche le numéro de version actuel ainsi que l'utilisation et quitte.
--help, -?
Affiche cette page de manuel.

EXEMPLES

L'exemple suivant analyse "manuscrit.tex" dans le répertoire courant et le rassemble ainsi que tous ses composants dans le répertoire "soumettre_01/":

$ texdirflatten -f manuscrit.tex -o soumettre_01

AVERTISSEMENTS

Veuillez faire des sauvegardes avant d'exécuter cette commande. Aucune garantie d'aucune sorte n'est fournie.

Vous devrez peut-être exécuter "epstopdf" sur les fichiers EPS si vous utilisez "pdflatex":

$ for i in *.eps; do epstopdf $i; done
