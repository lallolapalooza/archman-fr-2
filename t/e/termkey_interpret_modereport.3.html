TERMKEY_INTERPRET_MODEREPORT(3) Manuel des fonctions de bibliothèque TERMKEY_INTERPRET_MODEREPORT(3)

NOM

termkey_interpret_modereport - interpréter les données de rapport de mode opaque

SYNTAXE

#include <termkey.h>

TermKeyResult termkey_interpret_modereport(TermKey *tk, const TermKeyKey *key, 
    int *initial, int *mode, int *value);

Lier avec -ltermkey.

DESCRIPTION

termkey_interpret_modereport() remplit les variables dans les pointeurs passés en fonction de l'événement de rapport de mode trouvé dans key. Il doit être appelé si termkey_getkey(3) ou une fonction similaire a renvoyé un événement de touche avec le type TERMKEY_TYPE_MODEREPORT.

Tout pointeur peut être donné comme NULL pour ne pas renvoyer cette valeur.

La variable initial sera remplie avec 0 pour un rapport de mode ANSI, ou '?' pour un rapport de mode DEC. La variable mode sera remplie avec le numéro du mode, et value sera remplie avec la valeur du rapport.

VALEUR DE RETOUR

Si un événement key de type TERMKEY_TYPE_MODEREPORT est passé, cette fonction renverra TERMKEY_RES_KEY et affectera les variables dont les pointeurs ont été passés, comme décrit ci-dessus.

Pour d'autres types d'événements, elle renverra TERMKEY_RES_NONE, et ses effets sur les variables dont les pointeurs ont été passés sont indéfinis.

VOIR AUSSI

termkey_waitkey(3), termkey_getkey(3), termkey(7)
