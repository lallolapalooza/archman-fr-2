TEXWORKS(1) Manuel des commandes générales TEXWORKS(1)

NOM

texworks - un programme frontal simple pour TeX

SYNTAXE

texworks [OPTIONS] [FICHIERS]

DESCRIPTION

TeXworks est un environnement pour la création de documents TeX (LaTeX, ConTeXt, etc.), doté d'un éditeur Unicode sensible à TeX, d'une visionneuse PDF intégrée et d'une interface claire et simple, accessible aux utilisateurs occasionnels et non techniques.

Il s'inspire du programme primé TeXShop de Dick Koch pour Mac OS X, qui a rendu la composition de haute qualité via TeX accessible à un plus grand nombre d'utilisateurs, sans aspect technique ou intimidant. L'objectif de TeXworks est de fournir un environnement intégré et facile à utiliser, similaire, pour les utilisateurs d'autres plateformes, en particulier GNU/Linux et Windows.

OPTIONS

--help, -?
Affiche un bref aperçu de toutes les options de ligne de commande
--position=, -p
Ouvre le fichier spécifié suivant à la position donnée (ligne ou page)
--version, -v
Affiche les informations de version

ENVIRONNEMENT

TW_INIPATH
Remplace l'emplacement du fichier de préférences.
TW_LIBPATH
Remplace l'emplacement des fichiers de configuration et de bibliothèque supplémentaires.
TW_DICPATH
Remplace l'emplacement des fichiers de dictionnaire.
TW_HELPPATH
Remplace l'emplacement des fichiers d'aide.
TW_PLUGINPATH
Remplace l'emplacement des plugins.

FICHIERS

~/.config/TUG/TeXworks.conf
Fichier texte pour stocker les préférences.
~/.TeXworks/*
Fichiers de configuration et de bibliothèque supplémentaires (par ex. pour l'auto-complétion, les modèles, etc.).
/usr/local/bin/texworks-setup.ini
Fichier de configuration pour remplacer l'emplacement des fichiers mentionnés ci-dessus (par ex. pour activer le fonctionnement portable).
