TEAMNL(8) Interface Netlink du réseau d'équipe TEAMNL(8)

NOM

teamnl — outil d'interface Netlink pour les périphériques d'équipe

SYNTAXE

teamnl [-p nom_port] [-a index_tableau] périphérique_équipe commande [args_commande...]
teamnl -h

DESCRIPTION

teamnl est un outil permettant l'interaction avec un périphérique d'équipe via l'interface Netlink du pilote d'équipe. Cet outil est principalement destiné au débogage. Notez qu'il est inutile d'utiliser cet outil pour modifier les options d'un périphérique d'équipe contrôlé par une instance de teamd.

OPTIONS

-h, --help
Affiche l'aide sur la console et quitte.
-p ifname, --port_name ifname
Sélectionne une option par port du nom d'interface fourni.
-a index, --array_index index
Sélectionne une option de tableau de l'index de tableau fourni.

COMMANDE

ports
Affiche les ports d'équipe.
option
Affiche les options d'équipe.
getoption nom_opt
Obtient une option par son nom sélectionné.
setoption nom_opt valeur_opt
Définit une option par son nom sélectionné.
monitor style_opt
Surveille les modifications apportées aux options, aux ports et aux informations d'interface. Le style peut être soit "changed" (par défaut) soit "all".

VOIR AUSSI

teamd(8), teamdctl(8), teamd.conf(5)
