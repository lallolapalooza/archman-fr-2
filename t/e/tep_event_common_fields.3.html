tep_event_common_fields(3)

LIBTRACEEVENT(3) Manuel de libtraceevent LIBTRACEEVENT(3)

NOM

tep_event_common_fields, tep_event_fields - Obtenir une liste des champs d'un événement.

SYNTAXE

#include <event-parse.h>
struct tep_format_field **tep_event_common_fields(struct tep_event *event);
struct tep_format_field **tep_event_fields(struct tep_event *event);

DESCRIPTION

La fonction tep_event_common_fields() renvoie un tableau de pointeurs vers les champs communs pour l'event. Le tableau est alloué par la fonction et doit être libéré par free(). Le dernier élément du tableau est NULL.

La fonction tep_event_fields() renvoie un tableau de pointeurs vers les champs spécifiques à l'événement pour l'event. Le tableau est alloué par la fonction et doit être libéré par free(). Le dernier élément du tableau est NULL.

VALEUR DE RETOUR

Les deux fonctions tep_event_common_fields() et tep_event_fields() renvoient un tableau de pointeurs vers des structures tep_format_field en cas de succès, ou NULL en cas d'erreur.

EXEMPLE

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
int i;
struct tep_format_field **fields;
struct tep_event *event = tep_find_event_by_name(tep, "kvm", "kvm_exit");
if (event != NULL) {
        fields = tep_event_common_fields(event);
        if (fields != NULL) {
                i = 0;
                while (fields[i]) {
                        /*
                          parcourir la liste des champs communs
                          de l'événement kvm_exit
                        */
                        i++;
                }
                free(fields);
        }
        fields = tep_event_fields(event);
        if (fields != NULL) {
                i = 0;
                while (fields[i]) {
                        /*
                          parcourir la liste des champs spécifiques
                          de l'événement kvm_exit
                        */
                        i++;
                }
                free(fields);
        }
}
...
