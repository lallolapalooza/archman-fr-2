NOM

tep_data_type, tep_data_pid, tep_data_preempt_count, tep_data_flags - Extraire les champs communs d'un enregistrement.

SYNOPSIS

#include <event-parse.h>
enum trace_flag_type {
        TRACE_FLAG_IRQS_OFF,
        TRACE_FLAG_IRQS_NOSUPPORT,
        TRACE_FLAG_NEED_RESCHED,
        TRACE_FLAG_HARDIRQ,
        TRACE_FLAG_SOFTIRQ,
};
int tep_data_type(struct tep_handle *tep, struct tep_record *rec);
int tep_data_pid(struct tep_handle *tep, struct tep_record *rec);
int tep_data_preempt_count(struct tep_handle *tep, struct tep_record *rec);
int tep_data_flags(struct tep_handle *tep, struct tep_record *rec);

DESCRIPTION

Cet ensemble de fonctions peut être utilisé pour extraire les champs communs d'un enregistrement.

La fonction tep_data_type() obtient l'identifiant de l'événement de l'enregistrement rec. Elle lit le champ « common_type ». L'argument tep est le contexte d'analyse des événements de trace.

La fonction tep_data_pid() obtient l'identifiant du processus de l'enregistrement rec. Elle lit le champ « common_pid ». L'argument tep est le contexte d'analyse des événements de trace.

La fonction tep_data_preempt_count() obtient le compteur de préemption de l'enregistrement rec. Elle lit le champ « common_preempt_count ». L'argument tep est le contexte d'analyse des événements de trace.

La fonction tep_data_flags() obtient les indicateurs de latence de l'enregistrement rec. Elle lit le champ « common_flags ». L'argument tep est le contexte d'analyse des événements de trace. Les indicateurs de latence pris en charge sont :

        TRACE_FLAG_IRQS_OFF,          Les interruptions sont désactivées.
        TRACE_FLAG_IRQS_NOSUPPORT,    La lecture de l'indicateur IRQ n'est pas prise en charge par l'architecture.
        TRACE_FLAG_NEED_RESCHED,      La tâche doit être replanifiée.
        TRACE_FLAG_HARDIRQ,           Une interruption matérielle est en cours d'exécution.
        TRACE_FLAG_SOFTIRQ,           Une interruption logicielle est en cours d'exécution.

VALEUR DE RETOUR

La fonction tep_data_type() renvoie un entier, représentant l'identifiant de l'événement.

La fonction tep_data_pid() renvoie un entier, représentant l'identifiant du processus.

La fonction tep_data_preempt_count() renvoie un entier, représentant le compteur de préemption.

La fonction tep_data_flags() renvoie un entier, représentant les indicateurs de latence. Voir l'énumération trace_flag_type pour les indicateurs pris en charge.

Toutes ces fonctions retournent un entier négatif en cas d'erreur.

EXEMPLE

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
void process_record(struct tep_record *record)
{
        int data;
        data = tep_data_type(tep, record);
        if (data >= 0) {
                /* Obtenu l'ID de l'événement */
        }
        data = tep_data_pid(tep, record);
        if (data >= 0) {
                /* Obtenu l'ID du processus */
        }
        data = tep_data_preempt_count(tep, record);
        if (data >= 0) {
                /* Obtenu le compteur de préemption */
        }
        data = tep_data_flags(tep, record);
        if (data >= 0) {
                /* Obtenu les indicateurs de latence */
        }
}
...
