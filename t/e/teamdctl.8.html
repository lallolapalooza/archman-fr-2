NOM

teamdctl — outil de contrôle du démon team

SYNOPIS

teamdctl [options] périphérique_team commande [args_commande...]
teamdctl -h

DESCRIPTION

teamdctl est un outil qui permet à un utilisateur d'interagir avec une instance de teamd en cours d'exécution. Il utilise par défaut les sockets de domaine Unix, mais se rabattra sur l'API D-Bus pour assurer un fonctionnement fiable dans tous les environnements.

OPTIONS

-h, --help
Affiche le texte d'aide sur la console et quitte.
-v, --verbosity
Augmente la verbosité de la sortie.
-o, --oneline
Force la sortie sur une seule ligne si possible.
-D, --force-dbus
Force l'utilisation de l'interface D-Bus.
-Z adresse, --force-zmq adresse
Force l'utilisation de l'interface ZMQ. Les formats d'adresse possibles sont "tcp://ip:port", "ipc://path" et autres. Une description détaillée de la bibliothèque ZMQ se trouve sur la page http://zguide.zeromq.org/page:all.
-U, --force-usock
Force l'utilisation de l'interface de socket de domaine UNIX. C'est le comportement par défaut.

COMMANDE

config dump
Affiche la configuration JSON de teamd.
config dump noports
Affiche la configuration JSON de teamd sans inclure la section "ports".
config dump actual
Affiche la configuration JSON actuelle de teamd. Elle inclut les ports actuellement présents.
state dump | state
Affiche l'état de teamd sous forme de document d'état JSON.
state view
Affiche l'état de teamd analysé à partir du document d'état JSON.
state item get chemin_element_etat
Recherche un élément d'état dans le document d'état JSON et renvoie sa valeur.

Si PORTIFNAME dans chemin_element_etat contient des caractères sensibles, utilisez des guillemets doubles pour les échapper, comme ceci : ports."eth1.1".link_watches.up. Le traitement de chemin_element_etat pour 'state item set' est le même qu'ici.

state item set chemin_element_etat valeur
Recherche un élément d'état dans le document d'état JSON et définit sa valeur par le paramètre value. Ceci n'est disponible que pour un nombre limité de chemins :

setup.debug_level — L'utilisateur peut définir le niveau de débogage. Un niveau plus élevé est plus verbeux.

ports.NOM_INTERFACE.runner.aggregator.selected — Ceci est disponible pour le runner lacp. L'utilisateur peut sélectionner manuellement l'agrégateur.

runner.active_port — Ceci est disponible pour le runner activebackup. L'utilisateur peut sélectionner manuellement le port actif.

port add dev_port
Prend le nom du périphérique de port comme argument. Ajoute le périphérique de port à l'équipe.
port remove dev_port
Prend le nom du périphérique de port comme argument. Supprime le périphérique de port de l'équipe.
port present dev_port
Prend le nom du périphérique de port comme argument. Vérifie si le périphérique de port est présent dans l'équipe.
port config update dev_port chaîne_config_port
Prend le nom du périphérique de port comme premier argument et une chaîne de configuration au format JSON comme second argument. Met à jour la configuration du périphérique de port.
port config dump dev_port
Prend le nom du périphérique de port comme premier argument. Affiche la configuration JSON du périphérique de port sur la sortie standard.
