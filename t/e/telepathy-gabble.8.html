TELEPATHY-GABBLE(8) Services D-Bus TELEPATHY-GABBLE(8)

NOM

telepathy-gabble - Gestionnaire de connexion Telepathy pour XMPP (Jabber)

SYNTAXE

/usr/lib/telepathy/telepathy-gabble

DESCRIPTION

Gabble implémente la spécification D-Bus de Telepathy pour XMPP (Jabber), permettant aux clients Telepathy tels que empathy(1) de se connecter à des comptes XMPP, y compris Google Talk.

C'est un service D-Bus qui s'exécute sur le bus de session, et devrait généralement être démarré automatiquement par l'activation D-Bus. Cependant, il peut être utile de le démarrer manuellement pour le débogage.

OPTIONS

Il n'y a pas d'options en ligne de commande.

ENVIRONNEMENT

GABBLE_LOGFILE=nom_fichier
S'il est défini, la sortie de débogage ira dans le fichier spécifié plutôt que sur stderr. Si + est préfixé au nom_fichier (par ex. GABBLE_LOGFILE=+gabble.log), la sortie de débogage sera ajoutée au fichier ; sinon, tout fichier existant sera remplacé.
GABBLE_DEBUG=type
Peut être défini sur "all" pour une sortie de débogage complète, ou diverses options non documentées (qui peuvent changer d'une version à l'autre) pour filtrer la sortie.
WOCKY_DEBUG=type
Peut être défini sur "all" pour une sortie de débogage complète de la bibliothèque XMPP Wocky utilisée par Gabble, ou diverses options non documentées (qui peuvent changer d'une version à l'autre) pour filtrer la sortie. Pour le débogage général de Gabble, "net" est recommandé.
GABBLE_PERSIST=1
S'il est défini (à n'importe quelle valeur), Gabble continuera de s'exécuter jusqu'à ce qu'il soit arrêté, plutôt que de se terminer s'il n'y a pas de connexions ouvertes pendant quelques secondes.
GABBLE_PLUGIN_DIR=répertoire
S'il est défini, et si Gabble a été compilé avec le support des plugins, les plugins seront chargés depuis le répertoire plutôt que depuis le répertoire par défaut.
