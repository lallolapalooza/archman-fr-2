NOM

termkey_interpret_string - récupérer la chaîne de contrôle stockée

SYNTAXE

#include <termkey.h>

TermKeyResult termkey_interpret_string(TermKey *tk, const TermKeyKey *key, 
    const char **strp);

Lier avec -ltermkey.

DESCRIPTION

termkey_interpret_string() récupère la chaîne stockée dans l'instance TermKey à partir du dernier événement TERMKEY_TYPE_DCS ou TERMKEY_TYPE_OSC reçu. Notez qu'il est important d'appeler cette fonction dès que possible après avoir obtenu l'un de ces événements de touche de chaîne ; en particulier, avant d'appeler à nouveau termkey_getkey() ou termkey_waitkey(), car un appel ultérieur écrasera l'espace tampon contenant actuellement cette chaîne.

Le pointeur de chaîne dont l'adresse est donnée par strp sera défini pour pointer vers la chaîne stockée réelle dans l'instance. L'appelant est libre de lire cette chaîne (qui sera correctement terminée par NUL), mais ne doit pas la modifier. Il n'est pas nécessaire de free() le pointeur ; l'instance TermKey parente s'en chargera.

VALEUR DE RETOUR

Si la clé la plus récente key de type TERMKEY_TYPE_DCS ou TERMKEY_TYPE_OSC est passée, cette fonction retournera TERMKEY_RES_KEY et affectera les variables dont les pointeurs ont été passés, comme décrit ci-dessus.

Pour d'autres types d'événements, ou des événements obsolètes, elle retournera TERMKEY_RES_NONE, et ses effets sur les variables dont les pointeurs ont été passés sont indéfinis.

VOIR AUSSI

termkey_waitkey(3), termkey_getkey(3), termkey(7)
