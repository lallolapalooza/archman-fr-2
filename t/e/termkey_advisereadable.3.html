Paquet: libtermkey

TERMKEY_ADVISEREADABLE(3) Manuel des fonctions de bibliothèque TERMKEY_ADVISEREADABLE(3)

NOM

termkey_advisereadable - lire plus d'octets depuis le terminal sous-jacent

SYNTAXE

#include <termkey.h>

TermKeyResult termkey_advisereadable(TermKey *tk);

Lier avec -ltermkey.

DESCRIPTION

termkey_advisereadable() informe l'instance termkey(7) que de nouvelles entrées peuvent être disponibles sur le descripteur de fichier sous-jacent et qu'elle doit donc appeler read(2) pour les obtenir. Si au moins un octet supplémentaire a été lu, elle retournera TERMKEY_RES_AGAIN pour indiquer qu'il pourrait être utile d'appeler à nouveau termkey_getkey(3). Si aucune entrée supplémentaire n'a été lue, alors TERMKEY_RES_NONE est retourné. S'il n'y avait pas d'espace tampon restant, alors TERMKEY_RES_ERROR est retourné avec errno défini à ENOMEM. Si aucun descripteur de fichier n'est associé à cette instance, TERMKEY_RES_ERROR est retourné avec errno défini à EBADF.

Cette fonction, ainsi que termkey_getkey(3), permet d'utiliser l'instance termkey dans un programme asynchrone. Pour fournir des octets sans utiliser un descripteur de fichier lisible, utilisez termkey_push_bytes(3).

Pour une utilisation synchrone, termkey_waitkey(3) effectue la tâche de blocage d'entrée.

VALEUR DE RETOUR

termkey_advisereadable() retourne l'une des constantes suivantes :

TERMKEY_RES_AGAIN
Au moins un octet a été lu.
TERMKEY_RES_NONE
Aucun octet supplémentaire n'a été lu.
TERMKEY_RES_ERROR
Une erreur d'E/S s'est produite. errno sera préservé. Si l'erreur est EINTR, cela ne sera retourné que si le drapeau TERMKEY_FLAG_EINTR n'est pas défini ; s'il l'est, l'opération d'E/S sera retentée à la place.

VOIR AUSSI

termkey_getkey(3), termkey_waitkey(3), termkey_set_waittime(3), termkey(7)
