NOM

teamtype-share - Partager un répertoire avec un nouveau pair

SYNTAXE

teamtype share [--init] [--no-join-code] [--show-secret-address] [--directory] [--sync-vcs] [-h|--help] [-V|--version]

DESCRIPTION

Partager un répertoire avec un nouveau pair

OPTIONS

--init
Ré-initialiser l'historique du répertoire partagé. Vous perdrez l'historique précédent.
--no-join-code
Ne pas générer de code de connexion. Pour empêcher le partage involontaire ou simplement si vous voulez exclure Magic Wormhole de l'opération.
--show-secret-address
Afficher l'adresse secrète. Utile pour partager avec plusieurs personnes.
--directory <RÉPERTOIRE>
Le répertoire partagé. Par défaut, le répertoire courant.
--sync-vcs
EXPÉRIMENTAL : Synchroniser également les répertoires de contrôle de version comme .git/ ou .jj/, qui sont normalement ignorés. Pour Git, cela synchronisera toutes les branches, commits, etc., ainsi que votre .git/config. Cela signifie que les nouveaux commits apparaîtront immédiatement chez tous les pairs, vous pourrez changer de branche ensemble, etc.
-h, --help
Afficher l'aide.
-V, --version
Afficher la version.
