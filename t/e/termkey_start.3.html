termkey_start(3)

Paquet: libtermkey

TERMKEY_START(3) Manuel des fonctions de bibliothèque TERMKEY_START(3)

NOM

termkey_start, termkey_stop, termkey_is_started - activer ou désactiver les opérations du terminal

SYNOPIS

#include <termkey.h>

int termkey_start(TermKey *tk);
int termkey_stop(TermKey *tk);

int termkey_is_started(TermKey *tk);

Lier avec -ltermkey.

DESCRIPTION

termkey_start() active les opérations d'E/S du terminal de l'instance termkey(7) donnée, y compris l'envoi d'une séquence de contrôle du terminal et la définition des modes termios(3) requis.

termkey_stop() désactive les opérations d'E/S du terminal, en inversant les étapes suivies par termkey_start(). Une instance termkey nouvellement construite aura déjà les E/S du terminal activées.

termkey_is_started() interroge si les E/S du terminal sont actuellement activées.

VALEUR DE RETOUR

En cas de succès, termkey_start() et termkey_stop() renvoient une valeur vraie. En cas d'échec, zéro est renvoyé avec errno défini pour indiquer l'échec. termkey_is_started() renvoie vrai ou faux pour indiquer si les E/S du terminal sont actuellement activées.

VOIR AUSSI

termkey_new(3), termkey(7)
