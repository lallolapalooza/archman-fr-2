termkey_getkey(3)

Paquet: libtermkey

Licences: MIT

TERMKEY_GETKEY(3) Manuel des fonctions de bibliothèque TERMKEY_GETKEY(3)

NOM

termkey_getkey, termkey_getkey_force - récupérer l'événement de touche suivant

SYNTAXE

#include <termkey.h>

TermKeyResult termkey_getkey(TermKey *tk, TermKeyKey *key);
TermKeyResult termkey_getkey_force(TermKey *tk, TermKeyKey *key);

Lier avec -ltermkey.

DESCRIPTION

termkey_getkey() tente de récupérer un seul événement de frappe depuis le tampon de l'instance termkey(7), et de le placer dans la structure référencée par key. Il renvoie l'une des valeurs suivantes :

TERMKEY_RES_KEY
une frappe complète a été retirée du tampon, et a été placée dans la structure key.
TERMKEY_RES_AGAIN
un événement de frappe partiel a été trouvé dans le tampon, mais il ne contient pas encore tous les octets requis. Une indication de ce que termkey_getkey_force() renverrait a été placée dans la structure key.
TERMKEY_RES_NONE
aucun octet n'est en attente dans le tampon.
TERMKEY_RES_EOF

aucun octet n'est prêt et le flux d'entrée est maintenant fermé.
TERMKEY_RES_ERROR
appelé avec l'E/S terminal arrêtée, à cause de termkey_stop(3). Dans ce cas, errno sera défini à EINVAL.

termkey_getkey_force() est similaire à termkey_getkey() mais ne renverra pas TERMKEY_RES_AGAIN si une correspondance partielle est trouvée. Au lieu de cela, elle forcera une interprétation des octets, même si cela signifie interpréter le début d'une séquence multi-octets préfixée par Échappement comme une touche Échappement littérale suivie de lettres normales.

Ni l'une ni l'autre de ces fonctions ne bloqueront ni n'effectueront d'opérations d'E/S sur le descripteur de fichier sous-jacent. Pour utiliser l'instance dans un programme asynchrone, voir termkey_advisereadable(3). Pour un appel bloquant adapté à une utilisation dans un programme synchrone, utilisez termkey_waitkey(3) au lieu de termkey_getkey(). Pour fournir des entrées sans descripteur de fichier lisible, utilisez termkey_push_bytes(3).

Avant de renvoyer, cette fonction canonicalise la structure key conformément aux règles données pour termkey_canonicalise(3).

VALEUR DE RETOUR

termkey_getkey() renvoie une énumération de l'un des TERMKEY_RES_KEY, TEMRKEY_RES_AGAIN, TERMKEY_RES_NONE, TERMKEY_RES_EOF ou TERMKEY_RES_ERROR. termkey_getkey_force() renvoie l'un des éléments ci-dessus, à l'exception de TERMKEY_RES_AGAIN.

EXEMPLE

L'exemple de programme suivant affiche les détails de chaque frappe jusqu'à ce que l'utilisateur appuie sur Ctrl-C. Il démontre comment utiliser l'instance termkey dans un programme typique piloté par poll(2), qui peut inclure des E/S mixtes avec d'autres descripteurs de fichiers.


// <poll.h> pourrait nécessiter cela pour sigset_t
#define _XOPEN_SOURCE 600
#include <poll.h>
#include <stdio.h>
#include "termkey.h"
static void on_key(TermKey *tk, TermKeyKey *key)
{
  char buffer[50];
  termkey_strfkey(tk, buffer, sizeof buffer, key, TERMKEY_FORMAT_VIM);
  printf("%s\n", buffer);
}
int main(int argc, char *argv[])
{
  TERMKEY_CHECK_VERSION;
  TermKey *tk = termkey_new(0, 0);
  if(!tk) {
    fprintf(stderr, "Impossible d'allouer l'instance termkey\n");
    exit(1);
  }
  struct pollfd fd;
  fd.fd = 0; /* le descripteur de fichier que nous avons passé à termkey_new() */
  fd.events = POLLIN;
  TermKeyResult ret;
  TermKeyKey key;
  int running = 1;
  int nextwait = -1;
  while(running) {
    if(poll(&fd, 1, nextwait) == 0) {
      // Délai d'attente expiré
      if(termkey_getkey_force(tk, &key) == TERMKEY_RES_KEY)
        on_key(tk, &key);
    }
    if(fd.revents & (POLLIN|POLLHUP|POLLERR))
      termkey_advisereadable(tk);
    while((ret = termkey_getkey(tk, &key)) == TERMKEY_RES_KEY) {
      on_key(tk, &key);
      if(key.type == TERMKEY_TYPE_UNICODE &&
         key.modifiers & TERMKEY_KEYMOD_CTRL &&
         (key.code.codepoint == 'C' || key.code.codepoint == 'c'))
        running = 0;
    }
    if(ret == TERMKEY_RES_AGAIN)
      nextwait = termkey_get_waittime(tk);
    else
      nextwait = -1;
  }
  termkey_destroy(tk);
}
