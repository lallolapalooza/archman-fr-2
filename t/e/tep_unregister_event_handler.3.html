Paquet: libtraceevent

LIBTRACEEVENT(3) Manuel libtraceevent LIBTRACEEVENT(3)

NOM

tep_register_event_handler, tep_unregister_event_handler - Enregistrer / désenregistrer une fonction de rappel pour analyser les informations d'un événement.

SYNTAXE

#include <event-parse.h>
enum tep_reg_handler {
        TEP_REGISTER_SUCCESS,
        TEP_REGISTER_SUCCESS_OVERWRITE,
};
int tep_register_event_handler(struct tep_handle *tep, int id, const char *sys_name, const char *event_name, tep_event_handler_func func, void *context);
int tep_unregister_event_handler(struct tep_handle *tep, int id, const char *sys_name, const char *event_name, tep_event_handler_func func, void *context);
typedef int (*tep_event_handler_func)(struct trace_seq *s, struct tep_record *record, struct tep_event *event, void *context);

DESCRIPTION

La fonction tep_register_event_handler() enregistre une fonction de gestionnaire qui sera appelée pour analyser les informations d'un événement donné. L'argument tep est le contexte de l'analyseur d'événements de trace. L'argument id est l'identifiant de l'événement. L'argument sys_name est le nom du système auquel l'événement appartient. L'argument event_name est le nom de l'événement. Si id est >= 0, il est utilisé pour trouver l'événement, sinon sys_name et event_name sont utilisés. La variable func est un pointeur vers la fonction qui sera appelée pour analyser les informations de l'événement. L'argument context est un pointeur vers les données de contexte qui seront passées à func. Si une fonction de gestionnaire pour le même événement est déjà enregistrée, elle sera remplacée par la nouvelle. Ce mécanisme permet à un développeur de remplacer l'analyse d'un événement donné. Si pour une raison quelconque le format d'impression par défaut n'est pas suffisant, le développeur peut enregistrer une fonction pour un événement à utiliser pour analyser les données à la place.

La fonction tep_unregister_event_handler() désenregistre la fonction de gestionnaire précédemment enregistrée avec tep_register_event_handler(). L'argument tep est le contexte de l'analyseur d'événements de trace. Les arguments id, sys_name, event_name, func et context sont les mêmes que ceux utilisés lors de l'enregistrement de la fonction de rappel func.

tep_event_handler_func est le type de la fonction de gestionnaire d'événements personnalisée. L'argument s est la séquence de trace, elle peut être utilisée pour créer une chaîne de caractères personnalisée décrivant l'événement. Un record pour obtenir l'événement est passé en paramètre d'entrée, ainsi que l'event - le descripteur de l'événement du record. Le context est le contexte personnalisé défini lors de l'enregistrement du gestionnaire d'événements personnalisé.

VALEUR DE RETOUR

La fonction tep_register_event_handler() renvoie TEP_REGISTER_SUCCESS si le nouveau gestionnaire est enregistré avec succès, ou TEP_REGISTER_SUCCESS_OVERWRITE si un gestionnaire existant est remplacé. S'il n'y a pas assez de mémoire pour compléter l'enregistrement, TEP_ERRNO__MEM_ALLOC_FAILED est renvoyé.

La fonction tep_unregister_event_handler() renvoie 0 si func a été supprimé avec succès, ou -1 si l'événement n'a pas été trouvé.

La fonction tep_event_handler_func doit renvoyer -1 en cas d'erreur, ou 0 sinon.

EXEMPLE

#include <event-parse.h>
#include <trace-seq.h>
...
struct tep_handle *tep = tep_alloc();
...
int timer_expire_handler(struct trace_seq *s, struct tep_record *record,
                         struct tep_event *event, void *context)
{
        trace_seq_printf(s, "hrtimer=");
        if (tep_print_num_field(s, "0x%llx", event, "timer", record, 0) == -1)
                tep_print_num_field(s, "0x%llx", event, "hrtimer", record, 1);
        trace_seq_printf(s, " now=");
        tep_print_num_field(s, "%llu", event, "now", record, 1);
        tep_print_func_field(s, " function=%s", event, "function", record, 0);
        return 0;
}
...
        int ret;
        ret = tep_register_event_handler(tep, -1, "timer", "hrtimer_expire_entry",
                                         timer_expire_handler, NULL);
        if (ret < 0) {
                char buf[32];
                tep_strerror(tep, ret, buf, 32)
                printf("Failed to register handler for hrtimer_expire_entry: %s\n", buf);
        } else {
                switch (ret) {
                case TEP_REGISTER_SUCCESS:
                        printf ("Registered handler for hrtimer_expire_entry\n");
                        break;
                case TEP_REGISTER_SUCCESS_OVERWRITE:
                        printf ("Overwrote handler for hrtimer_expire_entry\n");
                        break;
                }
        }
...
        ret = tep_unregister_event_handler(tep, -1, "timer", "hrtimer_expire_entry",
                                           timer_expire_handler, NULL);
        if ( ret )
                printf ("Failed to unregister handler for hrtimer_expire_entry\n");

FICHIERS

        Fichier d'en-tête à inclure pour avoir accès aux API de la bibliothèque.

        Fichier d'en-tête à inclure pour avoir accès aux API liées aux séquences de trace.
        Les séquences de trace sont utilisées pour permettre à une fonction d'appeler
        plusieurs autres fonctions afin de créer une chaîne de données à utiliser.

        Commutateur de liaison à ajouter lors de la compilation d'un programme utilisant la bibliothèque.
