TERMINATOR(1) Manuel pour Terminator TERMINATOR(1)

NOM

terminator - multiples terminaux GNOME dans une seule fenêtre

SYNTAXE

terminator [options]

DESCRIPTION

Cette page de manuel documente Terminator, une application émulateur de terminal.

Terminator est un programme qui permet aux utilisateurs de configurer des agencements flexibles de terminaux GNOME. Il s'adresse à ceux qui organisent normalement de nombreux terminaux à proximité les uns des autres, mais qui ne veulent pas utiliser un gestionnaire de fenêtres basé sur des cadres.

OPTIONS

Ce programme suit la syntaxe habituelle de la ligne de commande GNU, avec des options longues commençant par deux traits d'union (`-'). Un résumé des options est inclus ci-dessous.

-h, --help

Affiche un résumé des options.

-v, --version

Affiche la version de l'installation de Terminator.

-m, -M, --maximise, --maximize

Démarre avec une fenêtre maximisée.

-f, --fullscreen

Démarre avec une fenêtre en plein écran.

-b, --borderless

Demande au gestionnaire de fenêtres de ne pas afficher les bordures/décorations sur la fenêtre Terminator (cela fonctionne bien avec --maximise).

-H, --hidden

Masque la fenêtre Terminator par défaut. Sa visibilité peut être activée/désactivée avec le raccourci clavier hide_window (Ctrl+Shift+Alt+A par défaut).

-T FORCEDTITLE, --title=FORCEDTITLE

Force la fenêtre Terminator à utiliser un nom spécifique plutôt que de le mettre à jour dynamiquement en fonction des souhaits du shell enfant.

--geometry=GEOMETRY

Spécifie la taille et la position souhaitées de la fenêtre de Terminator ; voir X(7).

-e COMMAND, --command=COMMAND

Exécute la commande spécifiée au lieu du shell par défaut ou de la commande spécifiée dans le profil.
Note : si Terminator est lancé en tant que x-terminal-emulator, -e se comporte comme -x, et la forme longue devient --execute2=COMMAND.

-x COMMAND [ARGS], --execute=COMMAND [ARGS]

Exécute le reste de la ligne de commande au lieu du shell par défaut ou de la commande spécifiée dans le profil.

--working-directory=DIR

Définit le répertoire de travail du terminal.

-g FILE, --config=FILE

Utilise le fichier spécifié pour la configuration.

-r ROLE, --role=ROLE

Définit une propriété WM_WINDOW_ROLE personnalisée sur la fenêtre.

-l LAYOUT, --layout=LAYOUT

Démarre Terminator avec une disposition spécifique. L'argument ici est le nom d'une disposition enregistrée.

-s LAYOUT, --select-layout=LAYOUT

Ouvre la fenêtre de sélection de disposition au lieu du terminal normal.

-p, --profile=PROFILE

Utilise un profil différent par défaut.

-i, --icon=FORCEDICON

Définit une icône personnalisée pour la fenêtre (par fichier ou par nom)

-u, --no-dbus

Désactive DBus.

-d, --debug

Active la sortie de débogage (veuillez l'utiliser lors du signalement de bugs). Ceci peut être spécifié deux fois pour activer un serveur de débogage Python intégré.

--debug-classes=DEBUG_CLASSES

Si ceci est spécifié comme une liste séparée par des virgules, la sortie de débogage ne sera imprimée que depuis les classes spécifiées.

--debug-methods=DEBUG_METHODS

Si ceci est spécifié comme une liste séparée par des virgules, la sortie de débogage ne sera imprimée que depuis les fonctions spécifiées. Si ceci est spécifié en plus de --debug-classes, seule l'intersection des deux listes sera affichée.

--new-tab

Si ceci est spécifié et que Terminator est déjà en cours d'exécution, DBus sera utilisé pour lancer un nouvel onglet dans la première fenêtre Terminator.

--toggle-visibility

Si ceci est spécifié et que Terminator est déjà en cours d'exécution, DBus sera utilisé pour basculer la visibilité de la fenêtre Terminator. Utilisable sous Wayland pour remplacer le raccourci clavier de masquage.

terminator(1) — Manual page

NAME

terminator — A newer, faster, and more feature-full terminal emulator.

SYNOPSIS

terminator [options]

DESCRIPTION

Terminator is a program that duplicates the functionality of existing terminal emulators in as many ways as possible. Most importantly, it has keyboard shortcuts to configure and manage terminals in tables, allowing for efficient use of screen space.

The main features include:

  • Tiling terminal emulators.
  • Grouping and broadcasting to multiple terminals.
  • Customizable keyboard shortcuts.
  • Configurable GUI preferences.
  • Configurable session management.
  • Drag and drop support.
  • Pluggable handler support.

OPTIONS

-h, --help
Show help message and exit.
-V, --version
Show program's version number and exit.
-v, --debug
Enable debug logging.
-q, --quiet
Disable logging.
-f, --full
Run in fullscreen mode.
-m, --maximize
Run maximized.
-e, --execute COMMAND
Execute the specified command in the terminal.
-x, --execute-list COMMAND ARGS...
Execute the specified command and arguments in the terminal.
-T, --title TITLE
Set the terminal window title.
-N, --new-tab
Open in a new tab.
-r, --rename TITLE
Rename the current terminal.
--new-window
Open in a new window.
--tab TABID
Specify the tab to open the terminal in.
--config CONFIG_FILE
Use the specified configuration file.
--profile PROFILE_NAME
Use the specified profile.
--layout LAYOUT_FILE
Load the specified layout file.
--list-layouts
List available layouts.
--save-layout LAYOUT_FILE
Save the current layout to a file.
--default-layout LAYOUT_FILE
Set the default layout.
--print-config
Print the default configuration to stdout.
--config-dir CONFIG_DIR
Use the specified configuration directory.
--hidden
Hide the terminal window.
--toggle-visibility
Toggle the visibility of the terminal window.

KEYBINDINGS

Terminator provides a rich set of keyboard shortcuts for controlling its behavior. The exact bindings may vary slightly depending on your configuration, but the defaults are as follows.

Window Management

Ctrl+Shift+O

Move focus to the next terminal.

Ctrl+Shift+I

Move focus to the previous terminal.

Ctrl+Shift+PageUp

Move focus to the terminal above.

Ctrl+Shift+PageDown

Move focus to the terminal below.

Ctrl+Shift+Home

Move focus to the terminal to the left.

Ctrl+Shift+End

Move focus to the terminal to the right.

Ctrl+Shift+W

Close the current terminal.

Ctrl+Shift+T

Open a new terminal in the current tab.

Ctrl+Shift+N

Open a new terminal window.

Ctrl+Shift+R

Split the current terminal vertically.

Ctrl+Shift+E

Split the current terminal horizontally.

Ctrl+Shift+X

Toggle between showing all terminals and only showing a scaled version of the current one (maximise).

Ctrl+Shift+Z

Toggle between showing all terminals and only showing a scaled version of the current one (zoom).

Ctrl+Shift+Alt+A

Hide the initial window. Note that this is a X11 global binding, and can only be bound once. On Wayland use window manager keyboard shortcuts to call terminator --toggle-visibility.

Grouping & Broadcasting

The following items relate to grouping and broadcasting.

Super+T

Group all terminals in the current tab so that any input sent to one of them goes to all of them.

Super+Shift+T

Remove grouping from all terminals in the current tab.

Super+G

Group all terminals so that any input sent to one of them goes to all of them.

Super+Shift+G

Remove grouping from all terminals.

Alt+A

Broadcast to all terminals.

Alt+G

Broadcast to grouped terminals.

Alt+O

Broadcast off.

Miscellaneous

The following items relate to miscellaneous terminal related functions.

Ctrl+Shift+C

Copy selected text to clipboard.

Ctrl+Shift+V

Paste clipboard text.

Ctrl+Shift+S

Toggle scrollbar.

Ctrl+Shift+F

Search within terminal scrollback.

Ctrl+Shift+R

Reset terminal state.

Ctrl+Shift+G

Reset terminal state and clear window.

Ctrl+Plus (+)

Increase font size.
Note: this may require you to press shift, depending on your keyboard.

Ctrl+Minus (-)

Decrease font size.
Note: this may require you to press shift, depending on your keyboard.

Ctrl+Zero (0)

Restore font size to original setting.

Ctrl+Alt+W

Rename window title.

Ctrl+Alt+A

Rename tab title.

Ctrl+Alt+X

Rename terminal title.

Super+1

Insert terminal number, i.e. 1 to 12.

Super+0

Insert padded terminal number, i.e. 01 to 12.

AUTHORS

Terminator was written by Chris Jones <cmsj@tenshu.net> and others.

This manual page was written by Chris Jones <cmsj@tenshu.net> and others.

NOM

terminator — Un émulateur de terminal plus récent, plus rapide et plus riche en fonctionnalités.

SYNTAXE

terminator [options]

DESCRIPTION

Terminator est un programme qui duplique les fonctionnalités des émulateurs de terminal existants de la manière la plus large possible. Plus important encore, il dispose de raccourcis clavier pour configurer et gérer les terminaux en tableaux, permettant une utilisation efficace de l'espace d'écran.

Les principales fonctionnalités incluent :
