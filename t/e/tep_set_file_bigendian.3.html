tep_set_file_bigendian(3)

Paquet: libtraceevent

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manuel libtraceevent LIBTRACEEVENT(3)

NOM

tep_is_file_bigendian, tep_set_file_bigendian - Obtenir / définir l'endianness des données brutes accessibles par le gestionnaire tep.

SYNOPSIS

#include <event-parse.h>
enum tep_endian {
        TEP_LITTLE_ENDIAN = 0,
        TEP_BIG_ENDIAN
};
bool tep_is_file_bigendian(struct tep_handle *tep);
void tep_set_file_bigendian(struct tep_handle *tep, enum tep_endian endian);

DESCRIPTION

La fonction tep_is_file_bigendian() récupère l'endianness des données brutes, accessibles par le gestionnaire tep. L'argument tep est le contexte de l'analyseur d'événements de trace.

La fonction tep_set_file_bigendian() définit l'endianness des données brutes accessibles par le gestionnaire tep. L'argument tep est le contexte de l'analyseur d'événements de trace.

L'argument endian est l'endianness :
        TEP_LITTLE_ENDIAN - les données brutes sont au format little endian,
        TEP_BIG_ENDIAN - les données brutes sont au format big endian.

VALEUR DE RETOUR

La fonction tep_is_file_bigendian() retourne vrai si les données sont au format bigendian, faux sinon.

EXEMPLE

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
        tep_set_file_bigendian(tep, TEP_LITTLE_ENDIAN);
...
        if (tep_is_file_bigendian(tep)) {
                /* Les données brutes sont en big endian */
        } else {
                /* Les données brutes sont en little endian */
        }
