termkey_interpret_mouse(3)

Paquet: libtermkey

Licences: MIT

TERMKEY_INTERPRET_MOUSE(3) Manuel de fonctions de bibliothèque TERMKEY_INTERPRET_MOUSE(3)

NOM

termkey_interpret_mouse - interpréter les données opaques d'événement de souris

SYNTAXE

#include <termkey.h>

TermKeyResult termkey_interpret_mouse(TermKey *tk, const TermKeyKey *key, 
    TermKeyMouseEvent *ev, int *button, int *line, int *col);

Lier avec -ltermkey.

DESCRIPTION

termkey_interpret_mouse() remplit les variables pointées par les pointeurs passés, selon l'événement de souris trouvé dans key. Il doit être appelé si termkey_getkey(3) ou une fonction similaire a retourné un événement de touche dont le type est TERMKEY_TYPE_MOUSE.

Tout pointeur peut être donné comme NULL pour ne pas retourner cette valeur.

La variable ev prendra l'une des valeurs suivantes :

TERMKEY_MOUSE_UNKNOWN
un événement de souris inconnu.
TERMKEY_MOUSE_PRESS
un bouton de souris a été pressé ; button contiendra son numéro.
TERMKEY_MOUSE_DRAG
la souris a été déplacée tout en maintenant un bouton ; button contiendra son numéro.
TERMKEY_MOUSE_RELEASE
un bouton de souris a été relâché, ou la souris a été déplacée sans bouton pressé. Si connu, button contiendra le numéro du bouton relâché. Tous les terminaux ne peuvent pas rapporter cela, il peut donc être 0.

Les variables line et col seront remplies avec la position de la souris, indexée à partir de 1. Notez qu'en raison du nombre limité d'octets dans la structure TermKeyKey, les numéros de ligne et de colonne sont limités respectivement à 2047 et 4095.

VALEUR DE RETOUR

Si un événement key de type TERMKEY_TYPE_MOUSE est passé, cette fonction retournera TERMKEY_RES_KEY et modifiera les variables dont les pointeurs ont été passés, comme décrit ci-dessus.

Pour d'autres types d'événements, elle retournera TERMKEY_RES_NONE, et ses effets sur les variables dont les pointeurs ont été passés sont indéfinis.
