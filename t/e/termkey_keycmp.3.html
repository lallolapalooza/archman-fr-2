NOM

termkey_keycmp - comparer deux événements de touche

SYNTAXE

#include <termkey.h>

int termkey_keycmp(TermKey *tk, const TermKeyKey *key1,
             const TermKeyKey *key2);

Lier avec -ltermkey.

DESCRIPTION

termkey_keycmp() compare deux structures de touche et applique un ordre total, renvoyant une valeur négative, nulle ou positive pour indiquer si les structures données sont croissantes, identiques ou décroissantes. Avant la comparaison, des copies des deux structures référencées sont prises et canonisées selon les règles de termkey_canonicalise(3).

Deux structures de types différents sont ordonnées par TERMKEY_TYPE_UNICODE, TERMKEY_TYPE_KEYSYM, TERMKEY_TYPE_FUNCTION, TERMKEY_TYPE_MOUSE. Les structures Unicode sont ordonnées par point de code, les structures keysym sont ordonnées par numéro de keysym, les structures de fonction sont ordonnées par numéro de touche de fonction, et les structures de souris sont ordonnées de manière opaque par un ordre non spécifié mais cohérent. Au sein de ces valeurs, les touches différant par leurs bits modificateurs sont ordonnées par les modificateurs.

VALEUR DE RETOUR

termkey_keycmp() renvoie un entier supérieur à, égal à, ou inférieur à zéro pour indiquer la relation entre les deux structures de touche données.

VOIR AUSSI

termkey_strpkey(3), termkey_canonicalise(3), termkey(7)
