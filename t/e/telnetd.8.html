NOM

telnetd - Serveur Telnet

SYNTAXE

telnetd [OPTION...]

DESCRIPTION

Serveur du protocole DARPA telnet

-d, --debug[=NIVEAU]
définit le niveau de débogage
-E, --exec-login=CHAÎNE
définit le programme à exécuter à la place de login(1) standard
-h, --no-hostinfo
n'affiche pas les informations sur l'hôte avant que la connexion n'ait été complétée
-l, --linemode[=MODE]
définit le mode ligne
-n, --no-keepalive
désactive les keep-alives TCP
-U, --reverse-lookup
refuse les connexions provenant d'adresses qui ne peuvent pas être re-mappées en un nom symbolique
-?, --help
affiche cette liste d'aide
--usage
affiche un bref message d'utilisation
-V, --version
affiche la version du programme

Les arguments obligatoires ou optionnels pour les options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.
