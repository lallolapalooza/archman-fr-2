NOM

texdoc - trouver & afficher la documentation dans TeX Live

SYNOPIS

texdoc [OPTION]... NOM...
texdoc [OPTION]... ACTION

DESCRIPTION

Essayer de trouver la documentation TeX appropriée pour le(s) NOM(s) spécifié(s). Alternativement, effectuer l'ACTION donnée et quitter.

OPTIONS

-w, --view
Utiliser le mode affichage : démarrer un visualiseur. (par défaut)
-m, --mixed
Utiliser le mode mixte (affichage ou liste).
-l, --list
Utiliser le mode liste : montrer une liste de résultats.
-s, --showall
Utiliser le mode showall : montrer aussi les résultats "mauvais".
-i, --interact
Utiliser des menus interactifs. (par défaut)
-I, --nointeract
Utiliser des listes simples, aucune interaction requise.
-M, --machine
Sortie lisible par machine pour les listes (implique -I).
-q, --quiet
Supprimer les avertissements et la plupart des messages d'erreur.
-v, --verbose
Afficher des informations supplémentaires (par ex. commande du visualiseur).
-D, --debug
Activer toutes les sorties de débogage (équivalent à "--debug=all").
-d LISTE, --debug=LISTE
Activer la sortie de débogage limitée aux catégories spécifiées dans LISTE.
Catégories disponibles : config, files, search, docfile, score, texdocs, tlpdb, version, view, et all pour activer toutes celles-ci.
-c NOM=VALEUR
Définir l'élément de configuration NOM à VALEUR.

ACTIONS

-h, --help
Afficher ce message d'aide.
-V, --version
Afficher le numéro de version.
-f, --files
Afficher la liste des fichiers de configuration utilisés.
--just-view FICHIER
Afficher FICHIER, donné avec le chemin complet (aucune recherche).
--print-completion SHELL
Afficher l'achèvement pour SHELL.

ENVIRONNEMENT

Les variables d'environnement suivantes peuvent être séparées par deux-points et utilisées pour définir les visualiseurs :

BROWSER, BROWSER_texdoc
Définir la commande à utiliser pour les documents HTML.
DVIVIEWER, DVIVIEWER_texdoc
Définir la commande à utiliser pour les documents DVI.
MDVIEWER, MDVIEWER_texdoc
Définir la commande à utiliser pour les documents Markdown.
PAGER, PAGER_texdoc
Définir la commande à utiliser pour les documents texte.
PDFVIEWER, PDFVIEWER_texdoc
Définir la commande à utiliser pour les documents PDF.
PSVIEWER, PSVIEWER_texdoc
Définir la commande à utiliser pour les documents PS.

Les variables d'environnement suivantes sont également utilisées :

LANG, LC_ALL, LANGUAGE, LANGUAGE_texdoc
Définir la locale, ce qui influencera les résultats de recherche.
TEXDOCS
En plus des documents inclus dans la base de données TeX Live, Texdoc recherche également la documentation sous les arbres TEXMF spécifiés par la variable kpathsea TEXDOCS.

FICHIERS

<texmf>/texdoc/texdoc.cnf, voir la sortie de l'option --files.

STATUT DE SORTIE

La commande texdoc se termine avec l'une des valeurs suivantes :

0
Succès.
1
Erreur interne.
2
Erreur d'utilisation.
3
Aucune documentation trouvée.

SIGNALEMENT DE BOGUES

Signaler les bogues à texdoc@tug.org.
