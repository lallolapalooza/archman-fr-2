TEXI2DVI(1) Commandes utilisateur TEXI2DVI(1)

NOM

texi2dvi - convertir des documents Texinfo en DVI ou PDF

SYNTAXE

texi2dvi [OPTION]... FICHIER...
texi2pdf [OPTION]... FICHIER...
pdftexi2dvi [OPTION]... FICHIER...

DESCRIPTION

Exécute chaque FICHIER Texinfo ou (La)TeX tour à tour jusqu'à ce que toutes les références croisées soient résolues, en construisant tous les index. Le répertoire contenant chaque FICHIER est recherché pour les fichiers inclus. Le suffixe de FICHIER est utilisé pour déterminer sa langue ((La)TeX ou Texinfo). Pour traiter des fichiers TeX (e)plain, définissez la variable d'environnement LATEX=tex.

Lorsqu'il est invoqué sous le nom `texi2pdf' ou avec l'option --pdf, il génère une sortie PDF. Sinon, il génère du DVI.

Options générales :

-D, --debug
activer le débogage du shell (définit -x)
-h, --help
afficher cette aide et quitter avec succès
-o, --output=FICHIER_SORTIE
laisser la sortie dans FICHIER_SORTIE ; un seul FICHIER d'entrée est autorisé
-q, --quiet
pas de sortie sauf en cas d'erreurs
-v, --version
afficher les informations de version et quitter avec succès
-V, --verbose
rapporter ce qui est fait
--max-iterations=N
ne pas traiter les fichiers plus de N fois [7]
--mostly-clean
supprimer les fichiers ou répertoires auxiliaires des exécutions précédentes (mais pas la sortie)

Format de sortie :

--dvi
générer un fichier DVI [par défaut]
--dvipdf
générer un fichier PDF via DVI (en utilisant un programme dvi-vers-pdf)
-p, --pdf
utiliser pdftex ou pdflatex pour le traitement
--ps
générer un fichier PostScript via DVI (en utilisant dvips)

Réglage fin de TeX :

-E, --expand
expansion des macros à l'aide de makeinfo
-I DIR
rechercher DIR pour les fichiers Texinfo
-l, --language=LANG
spécifier LANG pour FICHIER, soit latex, soit texinfo
--no-line-error
ne pas passer --file-line-error à TeX
--shell-escape
passer --shell-escape à TeX
--src-specials
passer --src-specials à TeX
--translate-file=FICHIER
utiliser le fichier de traduction de jeu de caractères donné pour TeX
-t, --command=CMD
insérer CMD dans une copie du fichier d'entrée

Modes de construction :

--build=MODE
spécifier le traitement des fichiers auxiliaires [local]
--tidy
identique à --build=tidy
-c, --clean
identique à --build=clean
--build-dir=DIR
spécifier où la compilation tidy est effectuée ; implique --tidy

Le MODE spécifie où la compilation TeX a lieu, et par conséquent, comment les fichiers auxiliaires sont traités.

Les valeurs valides de MODE sont :

`local'
compiler dans le répertoire courant, en laissant tous les fichiers auxiliaires. C'est l'usage traditionnel de TeX.
`tidy'
compiler dans un répertoire local *.t2d, où les fichiers auxiliaires sont laissés. Les fichiers de sortie sont copiés dans le fichier d'origine.
`clean'
identique à `tidy', mais supprime le répertoire auxiliaire ensuite. Chaque compilation nécessite donc un cycle complet.

Le mode de construction peut aussi être défini en utilisant la variable d'environnement TEXI2DVI_BUILD_MODE. Le répertoire de construction tidy peut aussi être défini en utilisant la variable d'environnement TEXI2DVI_BUILD_DIRECTORY.

Les valeurs de ces variables d'environnement sont utilisées pour exécuter les commandes correspondantes, si elles sont définies :

BIBER BIBTEX DVIPDF DVIPS EGREP LATEX MAKEINDEX MAKEINFO PDFLATEX PDFTEX SED TEX TEXINDEX TEXINDY THUMBPDF_CMD

Concernant --dvipdf, si DVIPDF n'est pas défini dans l'environnement, les programmes suivants sont recherchés (dans cet ordre) : dvipdfmx dvipdfm dvipdf dvi2pdf dvitopdf.

Si Texinfo est installé sur votre site, alors la commande

info texi2dvi

devrait vous donner accès à plus de documentation.
