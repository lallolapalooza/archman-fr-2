LIBTRACEEVENT(3) Manuel libtraceevent LIBTRACEEVENT(3)

NOM

tep_alloc, tep_free, tep_ref, tep_unref, tep_get_ref, tep_kbuffer - Créer, détruire, gérer les références du contexte d'analyse des événements de traçage.

SYNTAXE

#include <event-parse.h>
struct tep_handle *tep_alloc(void);
void tep_free(struct tep_handle *tep);
void tep_ref(struct tep_handle *tep);
void tep_unref(struct tep_handle *tep);
int tep_get_ref(struct tep_handle *tep);
struct kbuffer *tep_kbuffer(struct tep_handle *tep);

DESCRIPTION

Ce sont les fonctions principales pour créer et détruire tep_handle - la structure principale, représentant le contexte d'analyse des événements de traçage. Ce contexte est utilisé comme paramètre d'entrée de la plupart des API de la bibliothèque.

La fonction tep_alloc() alloue et initialise le contexte tep.

La fonction tep_free() décrémente la référence du gestionnaire tep. Lorsqu'il n'y a plus de références, elle libère le gestionnaire, ainsi que nettoie toutes ses ressources qu'il avait utilisées. L'argument tep est le pointeur vers le contexte d'analyse des événements de traçage.

La fonction tep_ref() ajoute une référence au gestionnaire tep.

La fonction tep_unref() retire une référence du gestionnaire tep. Lorsque la dernière référence est retirée, le tep est détruit et toutes les ressources qu'il avait utilisées sont nettoyées.

La fonction tep_ref_get() récupère les références actuelles du gestionnaire tep.

La fonction tep_kbuffer() alloue un descripteur kbuffer qui peut être utilisé pour analyser des données brutes représentées par le descripteur tep. Il doit être libéré avec kbuf_free(3).

VALEUR DE RETOUR

tep_alloc() retourne un pointeur vers une structure tep_handle nouvellement créée. NULL est retourné en cas de manque de mémoire libre pour l'allouer.

tep_ref_get() retourne les références actuelles de tep. Si tep est NULL, 0 est retourné.

tep_kbuffer() retourne un descripteur kbuffer qui peut analyser les données brutes qui représentent le descripteur tep. Doit être libéré avec kbuf_free(3).

EXEMPLE

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
int ref = tep_get_ref(tep);
tep_ref(tep);
if ( (ref+1) != tep_get_ref(tep)) {
        /* Quelque chose s'est mal passé, le compteur n'est pas incrémenté de 1 */
}
tep_unref(tep);
...
tep_free(tep);
...
