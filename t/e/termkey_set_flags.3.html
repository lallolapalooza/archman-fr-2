termkey_set_flags(3)

Paquet: libtermkey

Licences: MIT

TERMKEY_SET_FLAGS(3) Manuel des fonctions de bibliothèque TERMKEY_SET_FLAGS(3)

NOM

termkey_set_flags, termkey_get_flags - contrôler les indicateurs opérationnels

SYNTAXE

#include <termkey.h>

void termkey_set_flags(TermKey *tk, int newflags);
int termkey_get_flags(TermKey *tk);

Lier avec -ltermkey.

DESCRIPTION

termkey_set_flags() modifie l'ensemble des indicateurs de fonctionnement dans l'instance termkey(7) à ceux fournis par newflags.

termkey_get_flags() renvoie la valeur définie par le dernier appel à termkey_set_flags(), ou la valeur donnée au constructeur.

VALEUR RENVOYÉE

termkey_set_flags() ne renvoie aucune valeur. termkey_get_flags() renvoie les indicateurs opérationnels actuels.

VOIR AUSSI

termkey_new(3), termkey(7)
