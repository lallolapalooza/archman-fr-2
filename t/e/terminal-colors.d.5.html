TERMINAL-COLORS.D(5) Formats de fichier TERMINAL-COLORS.D(5)

NOM

terminal-colors.d - configurer la coloration de la sortie pour divers utilitaires

SYNTAXE

/etc/terminal-colors.d/[[nom][@term].][type]

DESCRIPTION

Les fichiers de ce répertoire déterminent le comportement par défaut des utilitaires lors de la coloration de la sortie.

Le nom est le nom d'un utilitaire. Ce nom est optionnel et lorsqu'aucun n'est spécifié, le fichier est utilisé pour tous les utilitaires non spécifiés.

Le term est un identifiant de terminal (la variable d'environnement TERM). L'identifiant de terminal est optionnel et lorsqu'aucun n'est spécifié, le fichier est utilisé pour tous les terminaux non spécifiés.

Le type est un type de fichier. Les types de fichiers pris en charge sont :

disable

Désactive la coloration de la sortie pour tous les utilitaires compatibles. Voir également la variable d'environnement NO_COLOR ci-dessous.

enable

Active la coloration de la sortie ; tous les fichiers disable correspondants sont ignorés.

scheme

Spécifie les couleurs utilisées pour la sortie. Le format du fichier peut être spécifique à l'utilitaire, le format par défaut est décrit ci-dessous.

S'il existe plusieurs fichiers qui correspondent à un utilitaire, le fichier avec le nom de fichier le plus spécifique l'emporte. Par exemple, le nom de fichier "@xterm.scheme" a une priorité inférieure à "dmesg@xterm.scheme". Les fichiers ayant la priorité la plus basse sont ceux sans nom d'utilitaire ni identifiant de terminal (par exemple, "disable").

Le répertoire $XDG_CONFIG_HOME/terminal-colors.d ou $HOME/.config/terminal-colors.d, spécifique à l'utilisateur, remplace le réglage global.

FORMAT PAR DÉFAUT DES FICHIERS SCHEME

L'instruction suivante est reconnue :

nom séquence-de-couleur

Le nom est un nom logique de séquence de couleur (par exemple "erreur"). Les noms sont spécifiques aux utilitaires. Pour plus de détails, consultez toujours la section COLORS dans la page de manuel de l'utilitaire.

La séquence-de-couleur est un nom de couleur, des séquences de couleurs ASCII ou des séquences d'échappement.

Noms de couleur

noir, clignotant, bleu, gras, marron, cyan, gris foncé, gris, vert, demi-brillant, bleu clair, cyan clair, gris clair, vert clair, magenta clair, rouge clair, magenta, rouge, réinitialiser, inverser et jaune.

Séquences de couleurs ANSI

Les séquences de couleurs sont composées de séquences de nombres séparés par des points-virgules. Les codes les plus courants sont :

0 pour restaurer la couleur par défaut
1 pour des couleurs plus vives
4 pour du texte souligné
5 pour du texte clignotant
30 pour un premier plan noir
31 pour un premier plan rouge
32 pour un premier plan vert
33 pour un premier plan jaune (ou marron)
34 pour un premier plan bleu
35 pour un premier plan violet
36 pour un premier plan cyan
37 pour un premier plan blanc (ou gris)
40 pour un fond noir
41 pour un fond rouge
42 pour un fond vert
43 pour un fond jaune (ou marron)
44 pour un fond bleu
45 pour un fond violet
46 pour un fond cyan
47 pour un fond blanc (ou gris)

Séquences d'échappement

Pour spécifier des caractères de contrôle ou des espaces dans les séquences de couleurs, la notation d'échappement de style C (\-) peut être utilisée :

\a Sonnerie (ASCII 7)
\b Retour arrière (ASCII 8)
\e Échappement (ASCII 27)
\f Saut de page (ASCII 12)
\n Nouvelle ligne (ASCII 10)
\r Retour chariot (ASCII 13)
\t Tabulation (ASCII 9)
\v Tabulation verticale (ASCII 11)
\? Supprimer (ASCII 127)
\_ Espace
\\ Antislash (\)
\^ Circonflexe (^)
\# Dièse (#)

Veuillez noter que les échappements sont nécessaires pour entrer un espace, un antislash, un circonflexe, ou tout caractère de contrôle n'importe où dans la chaîne, ainsi qu'un dièse comme premier caractère.

Par exemple, pour utiliser un fond rouge pour les messages d'alerte dans la sortie de dmesg(1), utilisez :

echo 'alert 37;41' >> /etc/terminal-colors.d/dmesg.scheme

Commentaires

Les lignes dont le premier caractère non blanc est un # (dièse) sont ignorées. Toute autre utilisation du caractère dièse n'est pas interprétée comme introduisant un commentaire.

ENVIRONNEMENT

TERMINAL_COLORS_DEBUG=all

active la sortie de débogage.

NO_COLOR

si défini, désactive la coloration de la sortie à moins qu'elle ne soit explicitement activée par une option en ligne de commande. Voir https://no-color.org/ pour plus de détails. Pris en charge depuis la version 2.41 de util-linux.

FICHIERS

$XDG_CONFIG_HOME/terminal-colors.d

$HOME/.config/terminal-colors.d

/etc/terminal-colors.d

EXEMPLE

Désactiver les couleurs pour toutes les utilitaires compatibles :

touch /etc/terminal-colors.d/disable

Désactiver les couleurs pour tous les utilitaires compatibles sur un terminal vt100 :

touch /etc/terminal-colors.d/@vt100.disable

Désactiver les couleurs pour tous les utilitaires compatibles, sauf dmesg(1) :

touch /etc/terminal-colors.d/disable

touch /etc/terminal-colors.d/dmesg.enable

COMPATIBILITÉ

La fonctionnalité terminal-colors.d est actuellement prise en charge par toutes les utilitaires de util-linux qui fournissent une sortie colorisée. Pour plus détails, consultez toujours la section COLORS de la page de manuel de l'utilitaire.

SIGNALEMENT DE BOGUES

Pour les signalements de bogues, utilisez le suivi des problèmes https://github.com/util-linux/util-linux/issues.
