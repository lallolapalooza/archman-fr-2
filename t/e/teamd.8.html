NOM

teamd — démon de contrôle de périphérique réseau d'équipe

SYNTAXE

teamd -k [-p fichier_pid] [-g]
teamd -e [-p fichier_pid] [-g]
teamd -c texte_config [-p fichier_pid] [-gdrD] [-Z adresse]
teamd -f fichier_config [-p fichier_pid] [-gdrD] [-Z adresse]
teamd -h|-V

DESCRIPTION

teamd est un démon destiné à contrôler un périphérique réseau d'équipe donné, pendant l'exécution, comme un marionnettiste contrôle une marionnette. Il utilise libteam pour communiquer avec l'instance du périphérique d'équipe du noyau via des sockets Netlink. Le comportement dépend du runner sélectionné et de sa configuration. Ce démon fait partie du projet libteam.

OPTIONS

-h, --help
Affiche le texte d'aide sur la console et quitte.
-V, --version
Affiche les informations de version sur la console et quitte.
-d, --daemonize
Se transforme en démon après le démarrage.
-k, --kill
Tue l'instance de démon en cours d'exécution.
-e, --check
Retourne 0 si un démon est déjà en cours d'exécution.
-f nom_fichier, --config-file nom_fichier
Charge le fichier de configuration spécifié.
-c texte, --config texte
Utilise la chaîne de configuration au format JSON donnée. Si cette option est présente, l'option -f est ignorée.
-p nom_fichier, --pid-file nom_fichier
Utilise le fichier PID spécifié.
-g, --debug
Active les messages de débogage. Répéter l'option augmente la verbosité.
-l, --log-output
Force la sortie du journal de teamd vers stdout, stderr ou syslog.
-r, --force-recreate
Force la recréation du périphérique d'équipe au cas où il existerait déjà.
-o, --take-over
Prend en charge le périphérique s'il existe déjà.
-N, --no-quit-destroy
Cette option garantit également que le périphérique d'équipe n'est pas supprimé après la fin de teamd.
-t nom_periph, --team-dev nom_periph
Utilise le nom du périphérique d'équipe spécifié (remplace la clé "device" dans la configuration).
-n, --no-ports
Démarre sans ports, même s'ils sont listés dans la configuration.
-D, --dbus-enable
Active l'interface D-Bus.
-Z adresse, --zmq-enable adresse
Active l'interface ZMQ. Les formats d'adresse possibles sont "tcp://ip:port", "ipc://path" et autres. La description détaillée de la bibliothèque ZMQ se trouve sur la page http://zguide.zeromq.org/page:all.
-U, --usock-enable
Active l'interface de socket de domaine UNIX. Ceci est activé par défaut.
-u, --usock-disable
Désactive l'interface de socket de domaine UNIX.
