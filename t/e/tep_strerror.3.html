NOM

tep_strerror - Renvoie une chaîne décrivant les numéros d'erreur errno et tep.

SYNTAXE

#include <event-parse.h>
int tep_strerror(struct tep_handle *tep, enum tep_errno errnum, char *buf, size_t buflen);

DESCRIPTION

La fonction tep_strerror() convertit un numéro d'erreur tep en une chaîne lisible par l'homme. L'argument tep est le contexte de l'analyseur d'événements de trace. L'argument errnum est un errno régulier, défini dans errno.h, ou un numéro d'erreur tep. La chaîne, décrivant ce numéro d'erreur, est copiée dans l'argument buf. L'argument buflen est la taille du buf.

C'est un wrapper thread-safe autour de strerror_r(). La fonction de bibliothèque a deux comportements différents - spécifique à POSIX et à GNU. L'API tep_strerror() se comporte toujours comme la version POSIX - la chaîne d'erreur est copiée dans le tampon fourni par l'utilisateur.

VALEUR DE RETOUR

La fonction tep_strerror() renvoie 0 si un errnum valide est passé et que la chaîne est copiée dans buf. Si errnum n'est pas un numéro d'erreur valide, -1 est renvoyé et buf n'est pas modifié.

EXEMPLE

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
char buf[32];
char *pool = calloc(1, 128);
if (tep == NULL) {
        tep_strerror(tep, TEP_ERRNO__MEM_ALLOC_FAILED, buf, 32);
        printf ("Le pool n'est pas initialisé, %s", buf);
}
...
