TEXPROFILE(1) Affichage des profils TeX TEXPROFILE(1)

NOM

texprofile - Affichage des données de profil collectées par texprof.

SYNTAXE

texprofile [Options] fichier_entree

DESCRIPTION

texprofile lit le fichier_entree binaire tel que produit par texprof. L'extension .tprof du fichier d'entrée peut être omise. Il analyse les données et présente les résultats dans une variété de tableaux, soit optimisés pour la lisibilité humaine, soit en fichiers CSV (valeurs séparées par des virgules) pour un traitement ultérieur.

La sortie est écrite sur le flux de sortie standard où elle peut être redirigée vers un fichier ou visualisée immédiatement.

OPTIONS

Il existe quatre types d'options : options générales, options de tableau, options de sélection et options de formatage.

Les options générales :

-? -h --help

Affiche un bref texte d'aide et quitte le programme.
--version

Affiche les informations de version et quitte.

Les options de tableau déterminent les tableaux qui seront affichés. Ces options utilisent toutes des lettres majuscules. Si aucune option de tableau n'est fournie, seules quelques informations globales sont affichées.

-T

Affiche le tableau des 10 lignes d'entrée principales.
-G

Affiche le tableau du graphe d'appels de macros.
-C

Affiche le tableau des temps par commande TeX.
-L

Affiche le tableau des temps par ligne d'entrée.
-R

Affiche le tableau des horodatages bruts.
-S

Affiche le tableau des changements de pile de macros.
-F

Affiche le tableau de tous les fichiers d'entrée.
-M

Affiche le tableau de toutes les macros appelées.
-A

Affiche les tableaux importants (équivalent à -TGFC).
-N

N'affiche pas le tableau des informations globales.

Les options de sélection permettent de réduire la quantité de données affichées dans le tableau en omettant les entrées du tableau qui contribuent peu au temps d'exécution global.

-pn

N'affiche pas les informations pour les entrées du tableau dont le temps cumulé est inférieur à n pour cent. La valeur par défaut est 1,0 pour cent.
-tn

Limite le nombre de lignes d'entrée affichées dans le tableau des « 10 principales » à n. Cette option n'est utile qu'avec l'option -T.

L'option de formatage détermine le formatage des informations dans les tableaux ainsi que la sélection des informations affichées dans les tableaux.

-i

Ajoute les numéros de fichier et de ligne des macros après le nom de la macro. Cette option est utile pour distinguer deux macros portant le même nom.
-m

Optimise la sortie pour la lisibilité par machine. Lorsqu'elle est optimisée pour la lisibilité humaine, les temps sont arrondis et donnés sous une forme courte ajoutant un identifiant d'unité : s pour secondes, ms pour millisecondes, us pour microsecondes et ns pour nanosecondes. Ce format est gênant si vous voulez importer les données, par exemple, dans une feuille de calcul pour un traitement ultérieur. Avec l'option -m, les temps sont simplement donnés en nanosecondes sans unités. De même, le temps combiné pour le temps total utilisé par une macro et le temps utilisé comme sous-macro depuis le graphe d'appels est donné dans une seule colonne séparant les deux nombres par une barre oblique, ce qui est agréable pour les lecteurs humains. Avec l'option -m, les deux nombres seront simplement donnés dans des colonnes séparées.
-n

Affiche les nombres d'horodatage. Cette option est utile avec l'option -R, si vous importez le tableau dans une base de données ou une feuille de calcul. Si vous triez les données par diverses propriétés dans différentes catégories, le nombre d'horodatage peut être utilisé pour maintenir les entrées dans une catégorie triées par temps.
-s

Affiche les changements de la pile de macros. Cette option est utile avec l'option -R si vous voulez voir les changements dans la pile de macros (voir -S) avec les informations de synchronisation dans un seul tableau.

FORMATS DES DONNÉES

NUMÉROS DE FICHIER

Pendant que texprof s'exécute, chaque fichier d'entrée TeX reçoit un numéro de fichier unique. Le nom du fichier seul n'est souvent pas unique car deux fichiers dans des répertoires différents peuvent avoir le même nom de fichier. Afficher le nom complet du fichier avec le chemin complet est cependant souvent peu pratique. Ainsi, si vous observez le même nom de fichier avec des numéros de fichier différents, vous pouvez utiliser l'option -F pour obtenir un tableau de tous les numéros de fichier et de leurs noms de fichier complets.

Mais même au sein du même répertoire, TeX peut lire différents fichiers du même nom pendant une exécution : TeX peut ouvrir un fichier en écriture, écrire du contenu dans le fichier, le fermer, l'ouvrir en lecture, le lire et le refermer. TeX peut alors répéter ce processus une deuxième fois, ou plusieurs fois, réutilisant le même nom de fichier encore et encore. texprof attribuera un nouveau numéro de fichier à ce fichier chaque fois qu'il sera ouvert en lecture. Vous pouvez donc savoir, à partir de la séquence des numéros de fichier, lequel était le premier, le deuxième ou le troisième.

Enfin, il existe des numéros de fichier spéciaux :

0 - inconnu
Si le fichier est inconnu, ce qui devrait rarement arriver, le numéro de fichier 0 est utilisé.
1 - système
texprof mappera les intervalles de temps utilisés pour exécuter certaines routines système au pseudo-fichier « système » en utilisant les numéros de ligne pour identifier la routine spécifique, comme la production du fichier de sortie DVI (shipout), la rupture d'un paragraphe en lignes (linebrk), ou la rupture du document en pages (buildpg). Ces temps ne dépendent pas de l'utilisation de macros mais simplement de la taille du document.
2 - terminal
Les commandes TeX entrées en ligne de commande ou de manière interactive sont mappées au numéro de fichier 2.

TEMPS

Si l'option -m est fournie, les temps sont donnés en nanosecondes. Sinon, les temps sont arrondis à 4 décimales au maximum et affichés avec une unité : secondes (s), millisecondes (ms), microsecondes (um), ou nanosecondes (ns).

NOMS DE MACROS

Les noms de macros sont affichés avec l'antislash initial. Comme les noms de macros ne sont souvent pas uniques, l'option de ligne de commande -i peut être utilisée pour afficher après le nom de la macro, entre crochets, le numéro de fichier et le numéro de ligne où la macro est définie. À moins que deux macros du même nom ne soient définies dans le même fichier et la même ligne, cela suffit à identifier de manière unique une macro. Une macro définie avec « let » résulte en une copie complète de la macro originale. Par conséquent, elle ne fera pas référence au fichier et à la ligne de la commande « let », mais au même fichier et à la même ligne que la macro originale.

EXEMPLES

Supposons que vous émettiez la commande texprof -prof hello.tex. Cela exécutera texprof sur le fichier d'entrée hello.tex avec l'option -prof. Le programme texprof chargera le format plain TeX puis traitera hello.tex pour produire hello.log et hello.dvi. Il exécutera exactement les mêmes étapes que TeX exécuterait si vous aviez émis la commande tex hello.tex.

En plus de hello.log et hello.dvi, texprof produira également le fichier hello.tprof contenant des mesures de temps effectuées pendant l'exécution de texprof. L'option -prof activera la collecte des données de temps dès que texprof entrera dans sa procédure de contrôle principale ; le fichier hello.tprof contiendra une mesure de temps

t, appelé une estampille temporelle, pour chaque commande que TeX a exécutée lors du traitement de l'entrée. Un format binaire est utilisé pour stocker toutes ces données sous une forme simple et compacte. Néanmoins, le fichier hello.tprof peut devenir très volumineux.

Le programme texprofile est utilisé pour extraire et analyser les données contenues dans hello.tprof et produire une sortie utile. Voici quelques exemples :

texprofile hello

Sans options supplémentaires, texprofile écrira des informations générales sur la sortie standard, telles que le temps total mesuré, le nombre d'échantillons, le temps moyen par échantillon, etc. Les informations générales sont toujours fournies, sauf si elles sont explicitement désactivées avec l'option -N ou l'option -m.
texprofile -T hello

Avec l'option -T, texprofile associera chaque estampille temporelle à une ligne d'entrée spécifique, additionnera les intervalles de temps pour chaque ligne d'entrée séparément et produira un tableau montrant les dix lignes qui ont le temps cumulé le plus élevé. Le tableau comporte les sept colonnes suivantes :
1. fichier
La première colonne contient le numéro du fichier d'entrée tel qu'expliqué ci-dessus. Le nom du fichier d'entrée est indiqué dans la colonne 7.
2. ligne
Le numéro de ligne.
3. pourcentage
Le temps passé sur cette ligne et ce fichier en pourcentage du temps total mesuré, tel que fourni dans les informations générales.
4. absolu
Le temps absolu passé sur cette ligne et ce fichier.
5. compte
Le nombre de fois où le chemin d'exécution est entré sur cette ligne. Notez qu'un appel de macro redirige généralement le chemin d'exécution vers une autre ligne à partir de laquelle l'exécution reviendra une fois l'appel de macro terminé. La réentrée de la ligne après une telle excursion vers une autre ligne incrémentera ce compteur. En résumé, ce compteur peut refléter le nombre d'exécutions partielles d'une ligne et non le nombre d'exécutions complètes de la ligne entière.
6. moyenne
Le temps moyen passé sur la ligne est simplement calculé en divisant la valeur de la colonne 4 par la valeur de la colonne 5.
7. fichier
Le nom du fichier d'entrée. Le numéro de fichier correspondant est indiqué dans la colonne 1.
texprofile -G hello

Avec l'option -G, texprofile associera chaque estampille temporelle soit à l'entrée de fichier, soit au corps d'une macro. Le tableau affiché est divisé en plusieurs sections, la première section étant consacrée à l'entrée de fichier, chacune des sections suivantes étant consacrée à une macro spécifique.
Chaque section commence par un en-tête. L'en-tête de la première section est ``File'' (Fichier), l'en-tête d'une section ultérieure est le nom de la macro.
La première ligne après l'en-tête donne le temps total passé dans la section sous deux formats différents :
1. temps
La colonne 1 le donne en temps absolu.
3. pourcentage
La colonne 3 le donne en pourcentage du temps total mesuré.

Pour la première section avec l'en-tête ``File'', le temps absolu sera égal au temps total mesuré car texprof a passé tout le temps à traiter le fichier hello. Et par conséquent, la valeur de la colonne 3 sera de 100%.
Pour accomplir une tâche, une macro appelle généralement d'autres macros que nous appelons macros enfants par la suite. Les lignes suivantes du tableau donneront une répartition du temps indiqué dans la première ligne. La répartition commence par une ligne indiquant le temps passé dans la section, hors temps passé dans les macros enfants. Elle indique dans la colonne 4 le nombre de fois où la macro a été appelée.

1. temps
La colonne 1 donne le temps absolu passé dans la section, hors temps passé dans les macros enfants.
3. pourcentage
La colonne 3 donne le temps de la colonne 1 en pourcentage du temps total passé dans cette section, tel qu'indiqué sur la ligne précédente.
4. compte/total
La colonne 4 donne le nombre de fois où la section a été appelée.

Les lignes suivantes du tableau indiquent le temps passé dans l'une des macros enfants. Les colonnes 2, 4 et 5 nécessitent quelques explications.

2. boucle
Le seul cas où la colonne 2 n'est pas vide est celui d'une macro récursive. Une macro récursive est une macro qui, au cours de la chaîne d'appels de macros, s'appelle elle-même, créant ainsi une boucle récursive. À ce stade, une macro devient son propre descendant et en même temps son propre ancêtre.
Par conséquent, texprofile maintient pour chaque macro enfant deux accumulateurs pour le temps écoulé : Pour le temps indiqué dans la colonne 2 intitulée "boucle", texprofile additionne les différences de temps observées au retour d'une macro enfant. Pour le temps indiqué dans les colonnes intitulées "temps" et "pourcentage", il soustrait des différences de temps observées au retour d'une macro enfant tous ces temps qui ont déjà été ajoutés à l'une des autres lignes de la répartition du temps : la macro elle-même ou l'une des autres macros enfants. Ainsi, les temps indiqués dans la colonne 1 de la ligne 2 et des lignes suivantes s'additionneront au temps indiqué dans la colonne 1 de la ligne 1 ; et les pourcentages indiqués dans la colonne 3 des lignes 2 et suivantes s'additionneront à 100%. Le temps indiqué dans la colonne 3 montrera le temps total nécessaire pour accomplir la sous-tâche assignée à la macro enfant respective.
4. compte/total
La colonne 4 montre deux comptes n/m pour la macro nommée dans la colonne 5. m est le nombre total d'appels à la macro et n est le nombre d'appels en tant que macro enfant dans la section actuelle. Le nombre n sera toujours inférieur ou égal à m.
5. enfant
La colonne 5 montre le nom de la macro enfant, comme expliqué ci-dessus.
texprofile -G -m hello

Ce tableau contiendra les mêmes données que l'exemple précédent, mais cette fois, l'option -m optimisera la sortie pour la lisibilité par machine.
*
Il n'y a pas d'en-têtes de colonne.
*
Les temps dans la colonne 1 "temps" et la colonne 2 "boucle" sont donnés en nanosecondes sans identifiant d'unité.
*
Les nombres n/m dans la colonne 4 sont maintenant affichés dans deux colonnes séparées, 4 et 5 ; le nom de la macro passe de la colonne 5 à la colonne 6.
texprofile -F hello

Avec l'option -F, texprofile affiche le tableau de tous les fichiers d'entrée de TeX en utilisant 5 colonnes :
1. fichier
Le numéro du fichier, comme expliqué ci-dessus.
2. lignes
La différence entre le numéro de ligne le plus élevé et le plus bas trouvé dans les données de profil pour ce fichier. Il ne s'agit généralement que d'un sous-ensemble de toutes les lignes du fichier.
3. pourcentage
Le pourcentage du temps total mesuré attribué au fichier.
4. temps
Le temps absolu attribué au fichier.
5. nom
Le nom complet du fichier.
texprofile -C hello

Avec l'option -C, texprofile affiche le tableau de toutes les commandes TeX exécutées pendant le profilage en utilisant 6 colonnes :
1. cmd
Le code de commande utilisé en interne par TeX. Généralement, le même numéro est utilisé par TeX pour plusieurs tâches étroitement liées. Il existe un code de commande spécial 101 qui est utilisé pour le temps passé dans les routines système qui sont mappées au fichier système, comme expliqué ci-dessus.
2. temps
Le temps total utilisé pour la commande.
3. pourcentage
Le pourcentage du temps total mesuré utilisé pour la commande.
4. compte
Le nombre de fois où cette commande a été exécutée.
5. moyenne
Le temps moyen nécessaire pour exécuter la commande. C'est simplement la valeur de la colonne 2 divisée par la valeur de la colonne 4.
6. nom
Une description verbale de la commande ou des commandes qui partagent ce code de commande.
texprofile -R -m -n hello

Avec les options -R et -m, texprofile affiche le tableau des mesures de temps brutes telles qu'observées par texprof, optimisé pour la lisibilité par machine. L'option -n ajoute une colonne pour le numéro de chaque mesure de temps. En raison de l'option -m, le tableau n'a pas d'en-têtes de colonne. Le tableau comporte 7 colonnes :
1. numéro
Le numéro de la mesure de temps. Ces numéros sont strictement croissants mais pas nécessairement consécutifs. Ils peuvent être utilisés pour maintenir les mesures triées dans l'ordre dans lequel elles ont été effectuées.
2. fichier
Le numéro du fichier, comme expliqué ci-dessus.
3. ligne
Le numéro de ligne, comme expliqué ci-dessus.
4. temps
L'intervalle de temps en nanosecondes.
5. commande
Le nom de la commande tel qu'indiqué dans la colonne 6 de l'exemple précédent.
6. niveau
Le niveau d'imbrication de la pile d'appels de macros.
7. macro
Le nom de la macro.

Ce tableau contient toutes les informations de chronométrage collectées pendant l'exécution de texprof. Certaines informations sur les appels de macros sont contenues dans la colonne 6. Plus d'informations sur les appels de macros pourraient être ajoutées en utilisant l'option -s. Les informations sur les retours de macros peuvent être obtenues à partir de la colonne 6. Le tableau peut être importé dans une feuille de calcul ou une base de données pour une analyse plus approfondie.

BOGUES

Si la dernière commande du corps d'une macro est un appel de macro, nous appelons cela un appel terminal. Si un tel appel terminal lit en avant pour analyser l'entrée suivante à la recherche d'arguments possibles, le mécanisme de prévisualisation de TeX peut empiler d'autres macros ou de nouveaux fichiers d'entrée sur la pile d'entrée de TeX. Ces entrées resteront en haut de la pile d'imbrication des macros de TeXprof, même si TeX annule tous ces jetons sur sa pile d'entrée. Cela peut entraîner une attribution de temps d'exécution à ces entrées en tant qu'entrées secondaires de l'appel terminal. Si cette explication vous semble compliquée, c'est parce que la situation est effectivement compliquée.
