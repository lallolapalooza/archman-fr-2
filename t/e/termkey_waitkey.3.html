termkey_waitkey(3)

Paquet: libtermkey

Licences: MIT

TERMKEY_WAITKEY(3) Manuel des fonctions de bibliothèque TERMKEY_WAITKEY(3)

NOM

termkey_waitkey - attendre et récupérer l'événement clavier suivant

SYNOPSIS

#include <termkey.h>

TermKeyResult termkey_waitkey(TermKey *tk, TermKeyKey *key);

Lier avec -ltermkey.

DESCRIPTION

termkey_waitkey() tente de récupérer un seul événement de pression de touche à partir du tampon de l'instance termkey(7), et de le placer dans la structure référencée par key. En cas de succès, il renverra TERMKEY_RES_KEY pour indiquer que la structure contient maintenant un nouvel événement de pression de touche. S'il n'y a rien dans le tampon, il se bloquera jusqu'à ce qu'un soit disponible. Si aucun événement n'est prêt et que le flux d'entrée est maintenant fermé, il renverra TERMKEY_RES_EOF. Si aucun descripteur de fichier n'est associé à cette instance, TERMKEY_RES_ERROR est renvoyé avec errno défini sur EBADF.

Avant de renvoyer, cette fonction canonicalise la structure key selon les règles données pour termkey_canonicalise(3).

Certaines pressions de touche génèrent plusieurs octets à partir du terminal. Comme il peut y avoir des délais réseau ou autres entre le terminal et une application utilisant termkey, termkey_waitkey() tentera d'attendre l'arrivée des octets restants s'il détecte le début d'une séquence multi-octets. Si aucun octet supplémentaire n'arrive dans un certain délai, les octets seront rapportés tels quels, même si cela conduit à interpréter une séquence d'échappement partiellement complète comme une touche Échap littérale suivie de lettres normales ou d'autres symboles. Le délai d'attente peut être défini par termkey_set_waittime(3).

VALEUR DE RETOUR

termkey_waitkey() renvoie l'une des constantes suivantes :

TERMKEY_RES_KEY
Un événement clavier a été fourni.
TERMKEY_RES_EOF
Aucun événement clavier n'est prêt et le terminal a été fermé, donc aucun autre n'arrivera.
TERMKEY_RES_ERROR
Une erreur d'E/S s'est produite. errno sera préservé. Si l'erreur est EINTR, cela ne sera renvoyé que si le drapeau TERMKEY_FLAG_EINTR n'est pas défini ; s'il l'est, l'opération d'E/S sera retentée à la place. Si cela est appelé avec les E/S du terminal arrêtées, en raison de termkey_stop(3), alors errno sera défini sur EINVAL.

EXEMPLE

L'exemple de programme suivant imprime les détails de chaque pression de touche jusqu'à ce que l'utilisateur appuie sur Ctrl-C.


// nous voulons optarg
#define _XOPEN_SOURCE 600
#include <stdio.h>
#include <unistd.h>
#include <errno.h>
#include "termkey.h"
int main(int argc, char *argv[])
{
  TERMKEY_CHECK_VERSION;
  int mouse = 0;
  int mouse_proto = 0;
  TermKeyFormat format = TERMKEY_FORMAT_VIM;
  char buffer[50];
  TermKey *tk;
  int opt;
  while((opt = getopt(argc, argv, "m::p:")) != -1) {
    switch(opt) {
    case 'm':
      if(optarg)
        mouse = atoi(optarg);
      else
        mouse = 1000;
      break;
    case 'p':
      mouse_proto = atoi(optarg);
      break;
    default:
      fprintf(stderr, "Usage: %s [-m]\n", argv[0]);
      return 1;
    }
  }
  tk = termkey_new(0, TERMKEY_FLAG_SPACESYMBOL|TERMKEY_FLAG_CTRLC);
  if(!tk) {
    fprintf(stderr, "Impossible d'allouer l'instance termkey\n");
    exit(1);
  }
  if(termkey_get_flags(tk) & TERMKEY_FLAG_UTF8)
    printf("Termkey en mode UTF-8\n");
  else if(termkey_get_flags(tk) & TERMKEY_FLAG_RAW)
    printf("Termkey en mode RAW\n");
  TermKeyResult ret;
  TermKeyKey key;
  if(mouse) {
    printf("\033[?%dhMode souris actif\n", mouse);
    if(mouse_proto)
      printf("\033[?%dh", mouse_proto);
  }
  while((ret = termkey_waitkey(tk, &key)) != TERMKEY_RES_EOF) {
    if(ret == TERMKEY_RES_KEY) {
      termkey_strfkey(tk, buffer, sizeof buffer, &key, format);
      if(key.type == TERMKEY_TYPE_MOUSE) {
        int line, col;
        termkey_interpret_mouse(tk, &key, NULL, NULL, &line, &col);
        printf("%s à ligne=%d, colonne=%d\n", buffer, line, col);
      }
      else if(key.type == TERMKEY_TYPE_POSITION) {
        int line, col;
        termkey_interpret_position(tk, &key, &line, &col);
        printf("Rapport de position du curseur à ligne=%d, colonne=%d\n", line, col);
      }
      else if(key.type == TERMKEY_TYPE_MODEREPORT) {
        int initial, mode, value;
        termkey_interpret_modereport(tk, &key, &initial, &mode, &value);
        printf("Rapport de mode %s mode %d = %d\n", initial ? "DEC" : "ANSI", mode, value);
      }
      else if(key.type == TERMKEY_TYPE_UNKNOWN_CSI) {
        long args[16];
        size_t nargs = 16;
        unsigned long command;
        termkey_interpret_csi(tk, &key, args, &nargs, &command);
        printf("CSI inconnu %c %ld;%ld %c%c\n", (char)(command >> 8), args[0], args[1], (char)(command >> 16), (char)command);
      }
      else {
        printf("Touche %s\n", buffer);
      }
      if(key.type == TERMKEY_TYPE_UNICODE &&
         key.modifiers & TERMKEY_KEYMOD_CTRL &&
         (key.code.codepoint == 'C' || key.code.codepoint == 'c'))
        break;
      if(key.type == TERMKEY_TYPE_UNICODE &&
         key.modifiers == 0 &&
         key.code.codepoint == '?') {
        // printf("\033[?6n"); // DECDSR 6 == requête position curseur
        printf("\033[?1$p"); // DECRQM == requête mode, mode origine DEC
        fflush(stdout);
      }
    }
    else if(ret == TERMKEY_RES_ERROR) {
      if(errno != EINTR) {
        perror("termkey_waitkey");
        break;
      }
      printf("Interrompu par un signal\n");
    }
  }
  if(mouse)
    printf("\033[?%dlMode souris désactivé\n", mouse);
  termkey_destroy(tk);
}

COMPATIBILITÉ

Cette fonction n'est pas disponible sous Windows.
