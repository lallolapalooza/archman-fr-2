tep_find_function_address(3)

Paquet: libtraceevent

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manuel libtraceevent LIBTRACEEVENT(3)

NOM

tep_find_function, tep_find_function_address, tep_find_function_info - Trouver le nom / l'adresse de début de fonction.

SYNTAXE

#include <event-parse.h>
const char *tep_find_function(struct tep_handle *tep, unsigned long long addr);
unsigned long long tep_find_function_address(struct tep_handle *tep, unsigned long long addr);
int tep_find_function_info(struct tep_handle *tep, unsigned long long addr, const char **name,
                           unsigned long long *start, unsigned long *size);

DESCRIPTION

Ces fonctions peuvent être utilisées pour trouver le nom et l'adresse de début d'une fonction, à partir d'une adresse donnée. L'adresse fournie n'a pas besoin d'être exacte, elle sélectionnera la fonction qui la contiendrait.

La fonction tep_find_function() renvoie le nom de la fonction qui contient l'adresse donnée addr. L'argument tep est le contexte de l'analyseur d'événements de trace.

La fonction tep_find_function_address() renvoie l'adresse de début de la fonction, à partir de l'adresse donnée addr. L'adresse addr n'a pas besoin d'être exacte, elle sélectionnera la fonction qui la contiendrait. L'argument tep est le contexte de l'analyseur d'événements de trace.

La fonction tep_find_function_info() récupère le nom, l'adresse de début (start) et la taille du texte de la fonction à l'adresse, si elle est trouvée. Notez que si le descripteur tep a un résolveur de fonction (utilisé par perf), alors size est mis à zéro.

VALEUR DE RETOUR

La fonction tep_find_function() renvoie le nom de la fonction, ou NULL si elle ne peut pas être trouvée.

La fonction tep_find_function_address() renvoie l'adresse de début de la fonction, ou 0 si elle ne peut pas être trouvée.

La fonction tep_find_function_info() renvoie 1 si une fonction est trouvée pour l'adresse donnée, ou 0 sinon.

EXEMPLE

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
void show_function_name(unsigned long long addr)
{
        const char *fname = tep_find_function(tep, addr);
        if (fname)
                printf("Fonction trouvée %s à 0x%0llx\n", fname, addr);
        else
                printf("Aucune fonction trouvée à 0x%0llx\n", addr);
}
void show_function_start_addr(unsigned long long addr)
{
        const char *fname = tep_find_function(tep, addr);
        unsigned long long fstart;
        if (!fname) {
                printf("Aucune fonction trouvée à 0x%0llx\n", addr);
                return;
        }
        fstart = tep_find_function_address(tep, addr);
        printf("La fonction %s à 0x%llx commence à 0x%0llx\n",
               fname, addr, fstart);
}
void show_function_info(unsigned long long addr)
{
        const char *fname;
        unsigned long long fstart;
        unsigned long size;
        ret = tep_find_function_info(tep, addr, &fname, &fstart, &size);
        if (!ret) {
                printf("Aucune fonction trouvée à 0x%0lx\n", addr);
                return;
        }
        printf("La fonction %s à 0x%lx commence à 0x%0lx et fait %ld octets de taille\n",
               fname, addr, fstart, size);
}
...
