NOM

text2image - génère des pages d'entraînement OCR.

SYNTAXE

text2image --text FICHIER --outputbase CHEMIN --fonts_dir CHEMIN [OPTION]

DESCRIPTION

text2image(1) génère des pages d'entraînement OCR. À partir d'un fichier texte, il produit une image avec une police et une dégradation données.

OPTIONS

--text FICHIER

Nom du fichier texte d'entrée à utiliser pour créer des données d'entraînement synthétiques. (type:string par défaut:)

--outputbase FICHIER

Nom de base pour le fichier image/boîte de sortie. (type:string par défaut:)

--fontconfig_tmpdir CHEMIN

Remplace le répertoire temporaire par défaut de fontconfig. (type:string par défaut:/tmp)

--fonts_dir CHEMIN

S'il est vide, utilise le défaut du système. Sinon, il remplace l'emplacement des polices par défaut du système. (type:string par défaut:)

--font NOM_POLICE

Nom de description de la police à utiliser. (type:string par défaut:Arial)

--writing_mode MODE

Spécifiez l'un des modes d'écriture suivants. horizontal : Rendu du texte horizontal normal. (par défaut) vertical : Rendu du texte vertical. L'orientation des glyphes est sélectionnée par Pango. vertical-upright : Rendu du texte vertical. L'orientation des glyphes est définie comme droite. (type:string par défaut:horizontal)

--tlog_level INT

Niveau minimum de journalisation pour la sortie tlog() (type:int par défaut:0)

--max_pages INT

Nombre maximum de pages à produire (0=illimité) (type:int par défaut:0)

--degrade_image BOOL

Dégrade l'image rendue avec du bruit speckle, dilatation/érosion et rotation. (type:bool par défaut:true)

--rotate_image BOOL

Fait pivoter l'image de manière aléatoire. (type:bool par défaut:true)

--strip_unrenderable_words BOOL

Supprime les mots non rendables du texte source. (type:bool par défaut:true)

--ligatures BOOL

Reconstruit et rend les ligatures. (type:bool par défaut:false)

--exposure INT

Niveau d'exposition dans le photocopieur. (type:int par défaut:0)

--resolution INT

Pixels par pouce. (type:int par défaut:300)

--xsize INT

Largeur de l'image de sortie. (type:int par défaut:3600)

--ysize INT

Hauteur de l'image de sortie. (type:int par défaut:4800)

--margin INT

Marge autour des bords de l'image. (type:int par défaut:100)

--ptsize INT

Taille du texte imprimé. (type:int par défaut:12)

--leading INT

Espacement entre les lignes (en pixels). (type:int par défaut:12)

--box_padding INT

Rembourrage autour des boîtes englobantes produites. (type:int par défaut:0)

--char_spacing DOUBLE

Espace inter-caractères en ems. (type:double par défaut:0)

--underline_start_prob DOUBLE

Fraction de mots à souligner (valeur dans [0,1]). (type:double par défaut:0)

--underline_continuation_prob DOUBLE

Fraction de mots à souligner (valeur dans [0,1]). (type:double par défaut:0)

--render_ngrams BOOL

Place chaque entité séparée par des espaces du fichier d'entrée dans une boîte englobante. Les n-grammes du fichier d'entrée seront mélangés aléatoirement avant le rendu (afin qu'il y ait une variété suffisante de caractères sur chaque ligne). (type:bool par défaut:false)

--output_word_boxes BOOL

Produit des boîtes englobantes de mots au lieu de boîtes de caractères. Ceci est utilisé pour l'entraînement de Cube, et est implicite par --render_ngrams. (type:bool par défaut:false)

--unicharset_file FICHIER

Fichier contenant les caractères de l'ensemble de caractères unicode. Si --render_ngrams est vrai et --unicharset_file est spécifié, les n-grammes contenant des caractères qui ne sont pas dans l'ensemble de caractères seront omis. (type:string par défaut:)

--bidirectional_rotation BOOL

Fait pivoter les caractères générés dans les deux sens. (type:bool par défaut:false)

--only_extract_font_properties BOOL

Suppose que le fichier d'entrée contient une liste de n-grammes. Rend chaque n-gramme, extrait les propriétés d'espacement et les enregistre dans le fichier output_base/[nom_police].fontinfo. (type:bool par défaut:false)

UTILISER CES INDICATEURS POUR PRODUIRE DES IMAGES DE CARACTÈRES INDIVIDUELS, ZÉRO-REMBOURRÉS ET CARRÉS

--output_individual_glyph_images BOOL

Si vrai, produit également des images de caractères individuels. (type:bool par défaut:false)

--glyph_resized_size INT

Chaque glyphe est carré avec cette longueur de côté en pixels. (type:int par défaut:0)

--glyph_num_border_pixels_to_pad INT

Taille_finale=glyph_resized_size+2*glyph_num_border_pixels_to_pad. (type:int par défaut:0)

UTILISER CES INDICATEURS POUR TROUVER DES POLICES POUVANT RENDRE UN TEXTE DONNÉ

--find_fonts BOOL

Recherche toutes les polices pouvant rendre le texte. (type:bool par défaut:false)

--render_per_font BOOL

Si find_fonts==true, rend chaque police dans sa propre image. Les noms de fichiers image sont de la forme output_name.font_name.tif. (type:bool par défaut:true)

--min_coverage DOUBLE

Si find_fonts==true, la couverture minimale de la police sur les caractères du fichier texte pour l'inclure, entre 0 et 1. (type:double par défaut:1)

Exemple d'utilisation : ``` text2image --find_fonts \ --fonts_dir /usr/share/fonts \ --text ../langdata/hin/hin.training_text \ --min_coverage .9 \ --render_per_font \ --outputbase ../langdata/hin/hin \ |& grep raw | sed -e s/ :.*/" \\/g | sed -e s/^/ "/ >../langdata/hin/fontslist.txt ```

OPTIONS UNIQUES

--list_available_fonts BOOL

Liste les polices disponibles et quitte. (type:bool par défaut:false)

HISTORIQUE

text2image(1) a été rendu disponible pour la première fois pour tesseract 3.03.
