NOM

termkey_set_buffer_size, termkey_get_buffer_size - contrôler la taille du tampon

SYNOPSIS

#include <termkey.h>

int termkey_set_buffer_size(TermKey *tk, size_t size);
size_t termkey_get_buffer_size(TermKey *tk);

Lier avec -ltermkey.

DESCRIPTION

termkey_set_buffer_size() modifie la taille de l'espace tampon dans l'instance termkey(7) à celle donnée par size. Tous les octets en attente dans le tampon seront préservés lors du redimensionnement, bien qu'ils seront tronqués si la nouvelle taille est inférieure au nombre total d'octets dans le tampon.

termkey_get_buffer_size() retourne la taille du tampon définie par le dernier appel à termkey_set_buffer_size(), ou la taille initiale par défaut de 256 octets.

VALEUR DE RETOUR

termkey_set_buffer_size() retourne une valeur vraie, ou zéro si une erreur se produit. termkey_get_buffer_size() retourne la taille actuelle du tampon en octets.

VOIR AUSSI

termkey_new(3), termkey_get_buffer_remaining(3), termkey(7)
