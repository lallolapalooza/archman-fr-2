TEXI2ANY(1) Commandes Utilisateur TEXI2ANY(1)

NOM

texi2any - traduire des documents Texinfo

SYNTAXE

makeinfo [OPTION]... FICHIER_TEXINFO...

DESCRIPTION

Traduire la documentation source Texinfo vers divers autres formats, produisant par défaut des fichiers Info appropriés pour la lecture en ligne avec Emacs ou GNU Info autonome.

Ce programme est couramment installé sous les noms `makeinfo' et `texi2any' ; le comportement est identique et ne dépend pas du nom sous lequel il est installé.

Options générales :

--document-language=CHAINE locale à utiliser pour traduire les mots-clés Texinfo
pour le document de sortie (par défaut C).
--error-limit=NOMBRE
arrêter après NOMBRE erreurs (par défaut 100).
--force
conserver la sortie même en cas d'erreurs.
--help
afficher cette aide et quitter.
--no-validate
supprimer la validation des références croisées de nœuds.
--no-warn
supprimer les avertissements (mais pas les erreurs).
--conf-dir=REP
chercher également les fichiers d'initialisation dans REP.
--init-file=FICHIER
charger FICHIER pour modifier le comportement par défaut.
-c, --set-customization-variable VAR=VAL
définir la variable de personnalisation VAR à la valeur VAL.
--trace-includes
afficher les noms des fichiers inclus.
-v, --verbose
expliquer ce qui est fait.
--version
afficher les informations de version et quitter.

Sélection du format de sortie (par défaut produit du Info) :

--docbook
produire du XML Docbook.
--html
produire du HTML.
--epub3
produire de l'EPUB 3.
--latex
produire du LaTeX.
--plaintext
produire du texte brut plutôt que du Info.
--xml
produire du XML Texinfo.
--dvi, --dvipdf, --ps, --pdf
appeler texi2dvi pour générer la sortie spécifiée, après vérification de la validité du FICHIER_TEXINFO.

Options générales de sortie :

-E, --macro-expand=FICHIER
produire la source avec les macros développées dans FICHIER, en ignorant tout @setfilename.
--no-headers
supprimer les séparateurs de nœuds, les lignes Node: et les menus de la sortie Info (produisant ainsi du texte brut) ou du HTML (produisant ainsi une sortie plus courte). De plus, si la sortie est en Info, écrire sur la sortie standard par défaut.
--no-split
supprimer toute division de la sortie ; générer un seul fichier de sortie.
--[no-]number-sections
produire les numéros de chapitre et de section ; par défaut, c'est activé.
-o, --output=DEST
écrire la sortie dans DEST. Avec une sortie divisée, créer DEST comme un répertoire et y placer les fichiers de sortie. Avec une sortie non divisée, si DEST est déjà un répertoire ou se termine par un /, placer le fichier de sortie là. Sinon, DEST nomme le fichier de sortie.
--disable-encoding
ne pas produire de caractères accentués et spéciaux dans la sortie Info et texte brut basée sur l'encodage du document.
--enable-encoding
outrepasser --disable-encoding (par défaut).

Options pour Info et texte brut :

--fill-column=NOMBRE
couper les lignes Info à NOMBRE colonnes (par défaut 72).
--footnote-style=STYLE
produire les notes de bas de page en Info selon STYLE : `separate' pour les placer dans leur propre nœud ; `end' pour les placer à la fin du nœud où elles sont définies (c'est le défaut).
--paragraph-indent=VAL
indenter les paragraphes Info de VAL espaces (par défaut 3). Si VAL est `none', ne pas indenter ; si VAL est `asis', préserver l'indentation existante.
--split-size=NOMBRE
diviser les fichiers Info à la taille NOMBRE (par défaut 300000).

Options pour HTML :

--css-include=FICHIER
inclure FICHIER dans la sortie <style> HTML ; lire stdin si FICHIER est -.
--css-ref=URL
générer une référence CSS vers URL.
--internal-links=FICHIER
produire une liste de liens internes dans FICHIER.
--split=DIVISION
diviser à DIVISION, où DIVISION peut être `chapter', `section' ou `node'.
--transliterate-file-names
utiliser des noms de fichiers en translittération ASCII.
--node-files
produire des fichiers de redirection pour les nœuds et les ancres ; par défaut, c'est activé seulement si la division est utilisée.

Options pour DVI/PS/PDF :

--Xopt=OPT
passer OPT à texi2dvi ; peut être répété.

Options des fichiers d'entrée :

-D VAR
définir la variable VAR, comme avec @set.
-D 'VAR VAL'
définir VAR à VAL (un seul argument shell).
-I REP
ajouter REP au chemin de recherche de @include.
-P REP
prépendre REP au chemin de recherche de @include.
-U VAR
annuler la définition de la variable VAR, comme avec @clear.

Traitement conditionnel dans l'entrée :

--ifdocbook
traiter @ifdocbook et @docbook même si on ne génère pas Docbook.
--ifhtml
traiter @ifhtml et @html même si on ne génère pas HTML.
--ifinfo
traiter @ifinfo même si on ne génère pas Info.
--iflatex
traiter @iflatex et @latex.
--ifplaintext
traiter @ifplaintext même si on ne génère pas de texte brut.
--iftex
traiter @iftex et @tex.
--ifxml
traiter @ifxml et @xml.
--no-ifdocbook
ne pas traiter le texte @ifdocbook et @docbook.
--no-ifhtml
ne pas traiter le texte @ifhtml et @html.
--no-ifinfo
ne pas traiter le texte @ifinfo.
--no-iflatex
ne pas traiter le texte @iflatex et @latex.
--no-ifplaintext
ne pas traiter le texte @ifplaintext.
--no-iftex
ne pas traiter le texte @iftex et @tex.
--no-ifxml
ne pas traiter le texte @ifxml et @xml.

De plus, pour les options --no-ifFORMAT, traiter le texte @ifnotFORMAT.

Les valeurs par défaut pour les conditionnelles @if... dépendent du format de sortie : si vous générez Docbook, --ifdocbook est activé et les autres sont désactivés ; si vous générez du HTML, --ifhtml est activé et les autres sont désactivés ; si vous générez du Info, --ifinfo est activé et les autres sont désactivés ; si vous générez du texte brut, --ifplaintext est activé et les autres sont désactivés ; si vous générez du LaTeX, --iflatex est activé et les autres sont désactivés ; si vous générez du XML, --ifxml est activé et les autres sont désactivés.

EXEMPLES

makeinfo foo.texi
écrire Info dans @setfilename de foo
makeinfo --html foo.texi
écrire du HTML dans @setfilename
makeinfo --xml foo.texi
écrire du XML Texinfo dans @setfilename
makeinfo --docbook foo.texi
écrire du XML Docbook dans @setfilename
makeinfo --plaintext foo.texi
écrire du texte brut sur la sortie standard
makeinfo --pdf foo.texi
écrire du PDF en utilisant texi2dvi
makeinfo --html --no-headers foo.texi
écrire du HTML sans lignes de nœuds ni menus
makeinfo --number-sections foo.texi
écrire du Info avec des sections numérotées
makeinfo --no-split foo.texi
écrire un seul fichier Info quelle que soit sa taille
