termcap(5) Manuel des formats de fichiers termcap(5)

NOM

termcap — base de données des capacités de terminaux

DESCRIPTION

La base de données termcap est un mécanisme obsolète pour décrire les capacités des terminaux à cellules de caractères et des imprimantes. Elle est conservée uniquement pour la compatibilité avec les anciens programmes ; les nouveaux programmes devraient utiliser la base de données terminfo(5) et les bibliothèques associées.

/etc/termcap est un fichier ASCII (la base de données maître) qui liste les capacités de nombreux types de terminaux. Les programmes peuvent lire termcap pour trouver les codes d'échappement particuliers nécessaires pour contrôler les attributs visuels du terminal effectivement utilisé. (D'autres aspects du terminal sont gérés par stty(1).) La base de données termcap est indexée sur la variable d'environnement TERM.

Les entrées termcap doivent être définies sur une seule ligne logique, avec '\' utilisé pour supprimer le saut de ligne. Les champs sont séparés par ':'. Le premier champ de chaque entrée commence à la marge gauche et contient une liste de noms pour le terminal, séparés par '|'.

Le premier sous-champ peut (dans les entrées termcap BSD de 4.3BSD et antérieures) contenir un nom court composé de deux caractères. Ce nom court peut être composé de lettres capitales ou minuscules. Dans les entrées termcap 4.4BSD, ce champ est omis.

Le deuxième sous-champ (le premier, dans le format plus récent 4.4BSD) contient le nom utilisé par la variable d'environnement TERM. Il devrait être orthographié en lettres minuscules. Les capacités matérielles sélectionnables devraient être marquées en ajoutant un trait d'union et un suffixe à ce nom. Voir ci-dessous pour un exemple. Les suffixes habituels sont w (plus de 80 caractères de large), am (marges automatiques), nam (pas de marges automatiques) et rv (affichage en vidéo inverse).

Les sous-champs suivants contiennent les capacités du terminal ; toute ligne de capacité prolongée doit être indentée d'une tabulation par rapport à la marge gauche.

Bien qu'il n'y ait pas d'ordre défini, il est suggéré d'écrire d'abord les capacités booléennes, puis numériques, et enfin les capacités de chaîne, chacune triée alphabétiquement sans tenir compte de la casse. Les capacités de fonctions similaires peuvent être écrites sur une seule ligne.

Exemple pour :

Ligne d'en-tête : vt|vt101|Terminal DEC VT 101 en mode 80 caractères :\
Ligne d'en-tête : Vt|vt101-w|Terminal DEC VT 101 en mode (large) 132 caractères :\
Booléen : :bs:\
Numérique : :co#80:\
Chaîne : :sr=\E[H:\

NOM

termcap - Base de données de terminal

DESCRIPTION

Les entrées de la base de données termcap décrivent les capacités des terminaux. Chaque entrée commence par une ligne de noms qui sont des alias pour ce terminal. La première chaîne de noms est la plus longue et constitue la façon canonique de nommer le terminal. Les chaînes sont séparées par des caractères | (barre verticale). Chaque entrée se termine par une ligne contenant uniquement deux caractères : une tabulation et un caractère de fin de ligne. Les capacités sont représentées par des chaînes de caractères de deux caractères, qui sont souvent le moyen le plus court pour les atteindre.

Les capacités sont divisées en trois types:

capabilities qui ne nécessitent pas de paramètres
chaînes de caractères
capabilities qui nécessitent un seul paramètre
chaînes de caractères
capabilities qui nécessitent deux paramètres
chaînes de caractères
capabilities qui nécessitent zéro ou plus paramètres
entiers

Les capacités sont délimitées par des virgules.

Les capacités sont pour la plupart des chaînes, mais certaines sont des entiers. La liste suivante répertorie certaines des capacités courantes:

b Démarrer le clignotement

MC Effacer les marges douces

md Démarrer le mode gras

me Finir tous les modes comme, us, mb, md et mr

mh Démarrer le mode demi-luminosité

mk Mode sombre (caractères invisibles)

mm Mettre le terminal en mode méta

mp Activer l'attribut protégé

mr Démarrer le mode inversé

nd Curseur à droite d'un caractère

pc Caractère de remplissage

pl Programmer la touche %1 pour exécuter la chaîne %2 en mode local

pn Programmer l'étiquette douce %1 pour afficher la chaîne %2

po Allumer l'imprimante

pO Allumer l'imprimante pour %1 (<256) octets

r1 Chaîne de réinitialisation 1 pour mettre le terminal dans des modes sains

r2 Chaîne de réinitialisation 2 pour mettre le terminal dans des modes sains

Il existe plusieurs façons de définir les codes de contrôle pour les capacités de chaîne :

Chaque caractère normal se représente lui-même, sauf '^', '\' et '%'.

Un ^x signifie Control-x. Control-A équivaut à 1 en décimal.

\x signifie un code spécial. x peut être l'un des caractères suivants :

E Échappement (27)
n Saut de ligne (10)
r Retour chariot (13)
t Tabulation (9)
b Retour arrière (8)
f Saut de page (12)
0 Caractère nul. Un \xxx spécifie le caractère octal xxx.
i
Incrémente les paramètres d'un.
r
Capacité de paramètre unique
+
Ajoute la valeur du caractère suivant à ce paramètre et effectue une sortie binaire
2
Effectue une sortie ASCII de ce paramètre avec une largeur de champ de 2
d
Effectue une sortie ASCII de ce paramètre avec une largeur de champ de 3
%
Imprime un '%'

Si vous utilisez la sortie binaire, vous devriez éviter le caractère nul ('\0') car il termine la chaîne. Vous devriez réinitialiser l'expansion de tabulation si une tabulation peut être la sortie binaire d'un paramètre.

Attention :
Les métacaractères ci-dessus pour les paramètres peuvent être incorrects : ils documentent le termcap de Minix qui peut ne pas être compatible avec le termcap de Linux.
