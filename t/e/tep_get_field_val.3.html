tep_get_field_val(3)

Paquet: libtraceevent

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manuel de libtraceevent LIBTRACEEVENT(3)

NOM

tep_get_any_field_val, tep_get_common_field_val, tep_get_field_val, tep_get_field_raw - Obtenir la valeur d'un champ.

SYNTAXE

#include <event-parse.h>
#include <trace-seq.h>
int tep_get_any_field_val(struct trace_seq *s, struct tep_event *event, const char *name, struct tep_record *record, unsigned long long *val, int err);
int tep_get_common_field_val(struct trace_seq *s, struct tep_event *event, const char *name, struct tep_record *record, unsigned long long *val, int err);
int tep_get_field_val(struct trace_seq *s, struct tep_event *event, const char *name, struct tep_record *record, unsigned long long *val, int err);
void *tep_get_field_raw(struct trace_seq *s, struct tep_event *event, const char *name, struct tep_record *record, int *len, int err);

DESCRIPTION

Ces fonctions peuvent être utilisées pour trouver un champ et récupérer sa valeur.

La fonction tep_get_any_field_val() recherche dans l'record un champ avec le nom name, faisant partie de l'event. Si le champ est trouvé, sa valeur est stockée dans val. En cas d'erreur et si err n'est pas zéro, une chaîne d'erreur est écrite dans s.

La fonction tep_get_common_field_val() fait la même chose que tep_get_any_field_val(), mais recherche uniquement dans les champs communs. Cela fonctionne pour tout événement car tous les événements incluent les champs communs.

La fonction tep_get_field_val() fait la même chose que tep_get_any_field_val(), mais recherche uniquement dans les champs spécifiques à l'événement.

La fonction tep_get_field_raw() recherche dans l'record un champ avec le nom name, faisant partie de l'event. Si le champ est trouvé, un pointeur vers l'emplacement des données brutes du champ dans l'enregistrement est retourné. La taille des données est stockée dans len. En cas d'erreur et si err n'est pas zéro, une chaîne d'erreur est écrite dans s.

VALEUR DE RETOUR

Les fonctions tep_get_any_field_val(), tep_get_common_field_val() et tep_get_field_val() retournent 0 en cas de succès, ou -1 en cas d'erreur.

La fonction tep_get_field_raw() retourne un pointeur vers les données brutes du champ, et place la longueur de ces données dans len. En cas d'erreur, NULL est retourné.

EXEMPLE

#include <event-parse.h>
#include <trace-seq.h>
...
struct tep_handle *tep = tep_alloc();
...
struct tep_event *event = tep_find_event_by_name(tep, "kvm", "kvm_exit");
...
void process_record(struct tep_record *record)
{
        int len;
        char *comm;
        struct tep_event *event;
        unsigned long long val;
        event = tep_find_event_by_record(tep, record);
        if (event != NULL) {
                if (tep_get_common_field_val(NULL, event, "common_type",
                                             record, &val, 0) == 0) {
                        /* Got the value of common type field */
                }
                if (tep_get_field_val(NULL, event, "pid", record, &val, 0) == 0) {
                        /* Got the value of pid specific field */
                }
                comm = tep_get_field_raw(NULL, event, "comm", record, &len, 0);
                if (comm != NULL) {
                        /* Got a pointer to the comm event specific field */
                }
        }
}

trace-seq.h
        Fichier d'en-tête à inclure pour avoir accès aux API relatives aux séquences de trace.
        Les séquences de trace sont utilisées pour permettre à une fonction d'appeler
        plusieurs autres fonctions pour créer une chaîne de données à utiliser.

        Option de l'éditeur de liens à ajouter lors de la compilation d'un programme
        utilisant la bibliothèque.
