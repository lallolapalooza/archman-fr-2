Paquet: libtermkey

TERMKEY_INTERPRET_POSITION(3) Manuel des fonctions de bibliothèque TERMKEY_INTERPRET_POSITION(3)

NOM

termkey_interpret_position - interpréter les données d'événement de position de curseur opaque

SYNTAXE

#include <termkey.h>

TermKeyResult termkey_interpret_position(TermKey *tk, const TermKeyKey *key, 
    int *line, int *col);

Lier avec -ltermkey.

DESCRIPTION

termkey_interpret_position() remplit les variables des pointeurs passés en fonction de l'événement de rapport de position du curseur trouvé dans key. Elle doit être appelée si termkey_getkey(3) ou similaire ont retourné un événement de touche avec le type TERMKEY_TYPE_POSITION.

N'importe quel pointeur peut être donné comme NULL pour ne pas retourner cette valeur.

Les variables line et col seront remplies avec la position du curseur, indexée à partir de 1. Notez qu'en raison du nombre limité d'octets dans la structure TermKeyKey, les numéros de ligne et de colonne sont limités à 2047 et 4095 respectivement.

VALEUR DE RETOUR

Si une clé de type TERMKEY_TYPE_POSITION est passée, cette fonction retournera TERMKEY_RES_KEY et affectera les variables dont les pointeurs ont été passés, comme décrit ci-dessus.

Pour d'autres types d'événements, elle retournera TERMKEY_RES_NONE, et ses effets sur les variables dont les pointeurs ont été passés sont indéfinis.

VOIR AUSSI

termkey_waitkey(3), termkey_getkey(3), termkey(7)
