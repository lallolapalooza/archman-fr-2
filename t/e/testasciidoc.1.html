NOM

testasciidoc - Exécute les tests de conformité AsciiDoc spécifiés dans le fichier de configuration.

SYNTAXE

testasciidoc [OPTIONS] COMMANDE

DESCRIPTION

La commande testasciidoc exécute les tests de conformité AsciiDoc spécifiés dans le fichier de configuration.

COMMANDES

L'ensemble d'outils testasciidoc dispose de trois commandes différentes :

testasciidoc list
testasciidoc run [-n, --number NUMÉRO] [-b, --backend BACKEND] [OPTIONS]
testasciidoc update [-n, --number NUMÉRO] [-b, --backend BACKEND] [OPTIONS]

Les commandes effectuent les actions suivantes :

list

Liste les cas de test disponibles.

run

Exécute les tests (régénère les fichiers de test temporaires et les compare aux fichiers de référence).

update

Régénère et met à jour les fichiers de référence des données de test. Doit être lancée au moins une fois pour disposer des fichiers de référence à comparer lors des tests.

Où :

NUMÉRO

Est le numéro d'index du cas de test obtenu avec la commande testasciidoc list.

BACKEND

Est le backend asciidoc à utiliser.

OPTIONS

Sont les options listées ci-dessous.

OPTIONS

-f, --conf-file=FICHIER_CONF

Utilise le fichier de configuration FICHIER_CONF. Pour plus d'informations sur le format du fichier de configuration, référez-vous à la documentation des tests.

--force

Met à jour toutes les données de test, en écrasant les données existantes.

EXEMPLES

testasciidoc list

Liste toutes les actions de test disponibles à exécuter ou à mettre à jour.

testasciidoc run

Exécute toutes les actions de test disponibles.

testasciidoc run --number 1 --backend html5 --conf-file=/etc/asciidoc/testasciidoc.conf

Exécute le cas de test 1 pour le backend asciidoc html5 en utilisant le fichier de configuration /etc/asciidoc/testasciidoc.conf.

testasciidoc update --number 1 --backend html5

Génère ou met à jour les fichiers de référence utilisés pour les cas de test, première action du backend asciidoc html5.

CODE DE SORTIE

0

Succès

1

Échec (erreur de syntaxe ou d'utilisation ; erreur de configuration ; échec du traitement du document ; erreur imprévue).
