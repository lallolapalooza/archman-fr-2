TEXELFETCH(3G) [FIXME: manuel] TEXELFETCH(3G)

NOM

texelFetch - effectue une recherche d'un seul texel dans une texture

DECLARATION

gvec4 texelFetch(gsampler1D sampler, int P, int lod);

gvec4 texelFetch(gsampler2D sampler, ivec2 P, int lod);

gvec4 texelFetch(gsampler3D sampler, ivec3 P, int lod);

gvec4 texelFetch(gsampler2DRect sampler, ivec2 P);

gvec4 texelFetch(gsampler1DArray sampler, ivec2 P, int lod);

gvec4 texelFetch(gsampler2DArray sampler, ivec3 P, int lod);

gvec4 texelFetch(gsamplerBuffer sampler, int P);

gvec4 texelFetch(gsampler2DMS sampler, ivec2 P, int sample);

gvec4 texelFetch(gsampler2DMSArray sampler, ivec3 P, int sample);

PARAMETRES

sampler

Spécifie l'échantillonneur auquel la texture à partir de laquelle les texels seront récupérés est lié.

P

Spécifie les coordonnées de texture auxquelles la texture sera échantillonnée.

lod

S'il est présent, spécifie le niveau de détail dans la texture à partir duquel le texel sera récupéré.

sample

Pour les recherches multi-échantillons, spécifie quel échantillon dans le texel sera retourné.

DESCRIPTION

texelFetch effectue une recherche d'un seul texel à partir des coordonnées de texture P dans la texture liée à sampler. La couche du tableau est spécifiée dans la dernière composante de P pour les formes de tableau. Le paramètre lod (s'il est présent) spécifie le niveau de détail à partir duquel le texel sera récupéré. sample spécifie quel échantillon dans le texel sera retourné lors de la lecture d'une texture multi-échantillons.
