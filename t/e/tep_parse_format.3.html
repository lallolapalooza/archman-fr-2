NOM

tep_parse_event, tep_parse_format - Analyser les informations de format d'événement

SYNTAXE

#include <event-parse.h>
enum tep_errno tep_parse_event(struct tep_handle *tep, const char *buf, unsigned long size, const char *sys);
enum tep_errno tep_parse_format(struct tep_handle *tep, struct tep_event **eventp, const char *buf, unsigned long size, const char *sys);

DESCRIPTION

La fonction tep_parse_event() analyse le format de l'événement et crée une structure d'événement pour analyser rapidement les données brutes pour un événement donné. L'argument tep est le contexte de l'analyseur d'événements de trace. La structure d'événement créée est stockée dans le contexte tep. L'argument buf est un tampon de size, où se trouvent les données du format de l'événement. Les données du format de l'événement peuvent être extraites des fichiers tracefs/events/.../.../format. L'argument sys est le système de l'événement.

La fonction tep_parse_format() fait la même chose que tep_parse_event(). La seule différence réside dans l'argument supplémentaire eventp, où la nouvelle structure d'événement créée est retournée.

VALEUR DE RETOUR

Les fonctions tep_parse_event() et tep_parse_format() retournent 0 en cas de succès, ou TEP_ERRNO__... en cas d'erreur.

EXEMPLE

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
char *buf;
int size;
struct tep_event *event = NULL;
buf = read_file("/sys/kernel/tracing/events/ftrace/print/format", &size);
if (tep_parse_event(tep, buf, size, "ftrace") != 0) {
        /* Échec de l'analyse du format d'impression ftrace */
}
if (tep_parse_format(tep, &event, buf, size, "ftrace") != 0) {
        /* Échec de l'analyse du format d'impression ftrace */
}
...
