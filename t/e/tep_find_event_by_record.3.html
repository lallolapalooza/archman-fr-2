LIBTRACEEVENT(3) Manuel libtraceevent LIBTRACEEVENT(3)

NOM

tep_find_event, tep_find_event_by_name, tep_find_event_by_record, tep_record_is_event - Rechercher des événements par clé donnée.

SYNTAXE

#include <event-parse.h>
struct tep_event *tep_find_event(struct tep_handle *tep, int id);
struct tep_event *tep_find_event_by_name(struct tep_handle *tep, const char *sys, const char *name);
struct tep_event *tep_find_event_by_record(struct tep_handle *tep, struct tep_record *record);
bool tep_record_is_event(struct tep_record *record, struct tep_event *event);

DESCRIPTION

Cet ensemble de fonctions peut être utilisé pour rechercher un événement, en basant la recherche sur un critère donné. Toutes les fonctions nécessitent un pointeur vers tep, le contexte de l'analyseur d'événements de trace.

La fonction tep_find_event() recherche un événement par son id donné. L'ID de l'événement est attribué dynamiquement et peut être consulté dans le fichier de format de l'événement, champ "ID".

La fonction tep_find_event_by_name() recherche un événement par son nom donné, sous le système sys. Si sys est NULL (non spécifié), le premier événement portant le nom name est retourné.

La fonction tep_find_event_by_record() recherche un événement à partir d'un record donné.

La fonction tep_record_is_event() teste si le record donné est du type de l'event. Ceci est normalement utilisé pour savoir si le record en cours de traitement est d'un type d'event pour lequel un traitement supplémentaire devrait être effectué.

VALEUR DE RETOUR

Toutes ces fonctions, à l'exception de tep_record_is_event(), retournent un pointeur vers l'événement trouvé, ou NULL s'il n'existe pas d'événement correspondant.

EXEMPLE

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
struct tep_event *event;
event = tep_find_event(tep, 1857);
if (event == NULL) {
        /* Il n'y a pas d'événement avec l'ID 1857 */
}
event = tep_find_event_by_name(tep, "kvm", "kvm_exit");
if (event == NULL) {
        /* Il n'y a pas d'événement kvm_exit, du système kvm */
}
void event_from_record(struct tep_record *record)
{
 struct tep_event *event = tep_find_event_by_record(tep, record);
        if (event == NULL) {
                /* Il n'y a pas d'événement provenant de l'enregistrement donné */
        }
}
