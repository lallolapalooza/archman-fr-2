NOM

testsaslauthd - un outil de test pour saslauthd

SYNTAXE

testsaslauthd -u nom_utilisateur -p mot_de_passe
[-r domaine] [-s nom_service]
[-f chemin_socket] [-R nombre_répétitions]

DESCRIPTION

Cet outil sert à tester le démon saslauthd. Ne l'utilisez pas à moins de savoir ce que vous faites. Lisez le code source si vous avez besoin de plus d'informations.
