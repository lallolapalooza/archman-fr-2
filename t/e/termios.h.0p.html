termios.h(0P) Manuel du programmeur POSIX termios.h(0P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

termios.h — définir les valeurs pour termios

SYNTAXE

#include <termios.h>

DESCRIPTION

L'en-tête <termios.h> contiendra les définitions utilisées par les interfaces d'E/S de terminal (voir Chapitre 11, Interface Générale de Terminal pour les structures et les noms définis).

La Structure termios

L'en-tête <termios.h> définira les types de données suivants via typedef :

cc_t
Utilisé pour les caractères spéciaux du terminal.
speed_t
Utilisé pour les débits en bauds du terminal.
tcflag_t
Utilisé pour les modes du terminal.

Les types ci-dessus seront tous des types entiers non signés.

L'implémentation supportera un ou plusieurs environnements de programmation dans lesquels les largeurs de cc_t, speed_t et tcflag_t ne seront pas supérieures à la largeur du type long. Les noms de ces environnements de programmation peuvent être obtenus en utilisant la fonction confstr() ou l'utilitaire getconf.

L'en-tête <termios.h> définira la structure termios, qui inclura au moins les membres suivants :

tcflag_t  c_iflag     Modes d'entrée.
tcflag_t  c_oflag     Modes de sortie.
tcflag_t  c_cflag     Modes de contrôle.
tcflag_t  c_lflag     Modes locaux.
cc_t      c_cc[NCCS]  Caractères de contrôle.

L'en-tête <termios.h> définira la constante symbolique suivante :

NCCS
Taille du tableau c_cc pour les caractères de contrôle.

L'en-tête <termios.h> définira les constantes symboliques suivantes pour être utilisées comme indices pour le tableau c_cc :

Utilisation des indices
Mode Canonique Mode Non-Canonique Description
VEOF Caractère EOF.
VEOL Caractère EOL.
VERASE Caractère ERASE.
VINTR VINTR Caractère INTR.
VKILL Caractère KILL.
VMIN Valeur MIN.
VQUIT VQUIT Caractère QUIT.
VSTART VSTART Caractère START.
VSTOP VSTOP Caractère STOP.
VSUSP VSUSP Caractère SUSP.
VTIME Valeur TIME.

Les valeurs d'indice seront appropriées pour être utilisées dans des directives de préprocesseur #if et seront distinctes, sauf que les indices VMIN et VTIME peuvent avoir les mêmes valeurs que les indices VEOF et VEOL, respectivement.

Modes d'Entrée

L'en-tête <termios.h> définira les constantes symboliques suivantes pour être utilisées comme drapeaux dans le champ c_iflag. Le champ c_iflag décrit le contrôle basique de l'entrée du terminal.

BRKINT
Signaler une interruption en cas de rupture.
ICRNL
Mapper CR en NL à l'entrée.
IGNBRK
Ignorer la condition de rupture.
IGNCR
Ignorer CR.
IGNPAR
Ignorer les caractères avec erreurs de parité.
INLCR
Mapper NL en CR à l'entrée.
INPCK
Activer la vérification de parité en entrée.
ISTRIP
Supprimer le caractère.
IXANY
Autoriser n'importe quel caractère à redémarrer la sortie.
IXOFF
Activer le contrôle d'entrée start/stop.
IXON
Activer le contrôle de sortie start/stop.
PARMRK
Marquer les erreurs de parité.

Modes de Sortie

L'en-tête <termios.h> définira les constantes symboliques suivantes pour être utilisées comme drapeaux dans le champ c_oflag. Le champ c_oflag spécifie le traitement système de la sortie.

OPOST
Post-traiter la sortie.
ONLCR
Mapper NL en CR-NL à la sortie.
OCRNL
Mapper CR en NL à la sortie.
ONOCR
Pas de sortie CR à la colonne 0.
ONLRET
NL effectue la fonction CR.
OFDEL
Le remplissage est DEL.
OFILL
Utiliser les caractères de remplissage pour le délai.
NLDLY
Sélectionner les délais de nouvelle ligne :
NL0
Type de nouvelle ligne 0.
NL1
Type de nouvelle ligne 1.
CRDLY
Sélectionner les délais de retour chariot :
CR0
Type de délai de retour chariot 0.
CR1
Type de délai de retour chariot 1.
CR2
Type de délai de retour chariot 2.
CR3
Type de délai de retour chariot 3.
TABDLY
Sélectionner les délais de tabulation horizontale :
TAB0
Type de délai de tabulation horizontale 0.
TAB1
Type de délai de tabulation horizontale 1.
TAB2
Type de délai de tabulation horizontale 2.
TAB3
Développer les tabulations en espaces.
BSDLY
Sélectionner les délais de retour arrière :
BS0
Type de délai de retour arrière 0.

DIALECTES

Le traitement des décalages de sortie pour les caractères de tabulation, de nouvelle ligne et de retour arrière est dépendant de l'implémentation.

Les constantes OPOST, ONLCR, OCRNL, ONOCR, ONLRET, OFDEL, OFILL, NLDLY, NL0, NL1, CRDLY, CR0, CR1, CR2, CR3, TABDLY, TAB0, TAB1, TAB2, TAB3, BSDLY, BS0, BS1, VOLDLY, VOL0, VOL1, VOL2, VOL3, FFDLY, FF0, FF1 sont définies.

La constante OPOST peut être combinée avec les autres constantes de masquage de bits de champ c_oflag en utilisant l'opérateur OU au niveau du bit.

La taille du champ c_oflag sera au moins 8 bits.

MODE LOCAL

L'en-tête <termios.h> définira les constantes symboliques suivantes pour être utilisées comme drapeaux dans le champ c_lflag. Le champ c_lflag décrit le contrôle local du terminal.

ECHO
Activer l'écho des caractères d'entrée.
ECHOCTL
Écho des caractères de contrôle, sauf TAB, LF, VT, FF, CR.
ECHOE
Si ERASE est défini, effacer visuellement le caractère effacé sur le terminal.
ECHOK
Si KILL est défini, effacer visuellement la ligne effacée sur le terminal.
ECHOKE
Effacer visuellement la ligne effacée sur le terminal; utilise KILL si défini, sinon utilise ECHOE.
ECHONL
Écho du caractère NL, même s'il n'est pas défini.
ICANON
Activer le mode canonique.
IEXTEN
Activer les fonctions étendues d'entrée.
ISIG
Activer la génération de signaux.
NOFLSH
Désactiver la purge du tampon d'entrée/sortie.
TOSTOP
Envoyer SIGTTIN à un processus s'exécutant en arrière-plan, lorsque celui-ci tente de lire à partir du terminal.

MODES DE BAUD

L'en-tête <termios.h> définira les constantes symboliques suivantes pour être utilisées pour définir la vitesse d'entrée et de sortie.

B0
Décrochage (hang-up).
B50
50 bauds.
B75
75 bauds.
B110
110 bauds.
B134
134.5 bauds.
B150
150 bauds.
B200
200 bauds.
B300
300 bauds.
B600
600 bauds.
B1200
1200 bauds.
B1800
1800 bauds.
B2400
2400 bauds.
B4800
4800 bauds.
B9600
9600 bauds.
B19200
19200 bauds.
B38400
38400 bauds.
EXTA
Vitesse étendue A.
EXTB
Vitesse étendue B.

Les constantes de vitesse de transmission en bauds sont des valeurs entières non négatives. L'implémentation de la vitesse B0 est de 0 bauds. L'implémentation de B38400 est de 38400 bauds.

Les valeurs pour EXTA et EXTB sont dépendantes de l'implémentation.

Les valeurs pour EXTA et EXTB seront supérieures à 38400 bauds.

COMMANDES DE CONTRÔLE

L'en-tête <termios.h> définira les constantes symboliques suivantes pour être utilisées dans la fonction ioctl() pour le contrôle des terminaux.

TCGETS
Obtenir les paramètres du terminal.
TCSETS
Définir les paramètres du terminal.
TCSETSW
Définir les paramètres du terminal et attendre que la sortie soit vidée.
TCSETA
Définir les paramètres du terminal immédiatement.
TCSETAW
Définir les paramètres du terminal immédiatement et attendre que la sortie soit vidée.
TCSETAF
Définir les paramètres du terminal immédiatement et attendre que l'entrée soit vidée.
TCSBRK
Envoyer un signal de rupture ou attendre la fin de la sortie.
TCFLUSH
Vider les tampons d'entrée et/ou de sortie.
TCGETA
Obtenir les paramètres du terminal.
TCGETPGRP
Obtenir le groupe de processus de premier plan du terminal.
TCSETPGRP
Définir le groupe de processus de premier plan du terminal.
TCSBRKP
Envoyer un signal de rupture au terminal.

Les constantes suivantes sont utilisées avec TCSBRK et TCSBRKP :

TCSBRK
Attendre la fin de la sortie avant de renvoyer.
0
Envoyer un signal de rupture.

Les constantes suivantes sont utilisées avec TCFLUSH :

TCIFLUSH
Vider le tampon d'entrée.
TCIOFLUSH
Vider les tampons d'entrée et de sortie.
TCOFLUSH
Vider le tampon de sortie.

L'en-tête <termios.h> définira la constante symbolique suivante, qui est une valeur appropriée pour l'argument category de la fonction tcsetattr() :

TCSANOW
Appliquer les changements immédiatement.

L'en-tête <termios.h> définira la constante symbolique suivante, qui est une valeur appropriée pour l'argument category de la fonction tcsetattr() :

TCSADRAIN
Appliquer les changements une fois que toute la sortie a été transmise.

L'en-tête <termios.h> définira la constante symbolique suivante, qui est une valeur appropriée pour l'argument category de la fonction tcsetattr() :

TCSANDFLUSH
Appliquer les changements une fois que toute la sortie a été transmise et vider tous les tampons d'entrée.

CONFORMITÉ

Les normes POSIX.1-2001 et POSIX.1-2008.

Modes de contrôle

L'en-tête <termios.h> définit les constantes symboliques suivantes pour utilisation comme drapeaux dans le champ c_cflag. Le champ c_cflag décrit le contrôle matériel du terminal ; toutes les valeurs spécifiées ne sont pas obligatoirement prises en charge par le matériel sous-jacent.

CSIZE
Taille du caractère :
CS5
5 bits
CS6
6 bits
CS7
7 bits
CS8
8 bits
CSTOPB
Envoyer deux bits d'arrêt, sinon un.
CREAD
Activer le récepteur.
PARENB
Activer la parité.
PARODD
Parité impaire, sinon paire.
HUPCL
Raccrocher à la dernière fermeture.
CLOCAL
Ignorer les lignes d'état du modem.

L'implémentation doit prendre en charge la fonctionnalité associée aux symboles CS7, CS8, CSTOPB, PARODD et PARENB.

Modes locaux

L'en-tête <termios.h> définit les constantes symboliques suivantes pour utilisation comme drapeaux dans le champ c_lflag. Le champ c_lflag de la structure d'argument est utilisé pour contrôler diverses fonctions du terminal.

ECHO
Activer l'écho.
ECHOE
Écho du caractère d'effacement comme retour arrière corrigeant les erreurs.
ECHOK
Écho de la commande KILL.
ECHONL
Écho du NL.
ICANON
Entrée canonique (traitement d'effacement et de suppression).
IEXTEN
Activer le traitement des caractères d'entrée étendus.
ISIG
Activer les signaux.
NOFLSH
Désactiver la purge après interruption ou quit.
TOSTOP
Envoyer SIGTTOU pour la sortie en arrière-plan.

Sélection des attributs

L'en-tête <termios.h> définit les constantes symboliques suivantes pour utilisation avec tcsetattr() :

TCSANOW
Modifier les attributs immédiatement.
TCSADRAIN
Modifier les attributs une fois la sortie vidée.
TCSAFLUSH
Modifier les attributs une fois la sortie vidée ; également vider l'entrée en attente.

Contrôle de ligne

L'en-tête <termios.h> définit les constantes symboliques suivantes pour utilisation avec tcflush() :

TCIFLUSH
Vider l'entrée en attente.
TCIOFLUSH
Vider l'entrée en attente et la sortie non transmise.
TCOFLUSH
Vider la sortie non transmise.

L'en-tête <termios.h> définit les constantes symboliques suivantes pour utilisation avec tcflow() :

TCIOFF
Transmettre un caractère STOP, destiné à suspendre les données d'entrée.
TCION
Transmettre un caractère START, destiné à redémarrer les données d'entrée.
TCOOFF
Suspendre la sortie.
TCOON
Redémarrer la sortie.

L'en-tête <termios.h> définit le type pid_t tel que décrit dans <sys/types.h>.
