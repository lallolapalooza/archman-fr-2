NOM

textestvis - tests de régression visuelle pour LaTeX

SYNTAXE

textestvis [-cs] [-e MOTEUR] [-d DENSITÉ] [MOTIF]

textestvis approve [-e MOTEUR] [MOTIF]

textestvis compare [-d DENSITÉ] FICHIER FICHIER

textestvis perf [-cs] [-e MOTEUR] FICHIER

DESCRIPTION

Effectue des tests de régression visuelle pour les documents LaTeX.

textestvis
Crée des fichiers PDF pour tous les fichiers tex correspondant au motif et effectue un test de régression visuelle. Si aucun motif n'est spécifié, tous les fichiers du répertoire courant sont testés, à l'exception des fichiers dont les noms commencent par un underscore.
textestvis approve
Remplace les fichiers de référence par les fichiers de test.
textestvis compare
Crée une différence visuelle entre deux fichiers pdf.
textestvis perf
Mesure le temps nécessaire pour créer un fichier pdf à partir du fichier tex donné.

OPTIONS

-c
Efface le cache.
-s
Active l'échappement shell.
-d DENSITÉ
Définit la densité en ppp (par défaut 72).
-e MOTEUR
Définit le moteur latex (par défaut xelatex).
--help
Affiche un message d'aide.
--version
Affiche les informations de version.

ENVIRONNEMENT

textestvis nécessite ImageMagick 7.0 ou supérieur.
