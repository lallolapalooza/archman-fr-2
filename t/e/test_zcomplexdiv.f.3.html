!> Valeurs réelles pour le test :
!> (1) x = 2**m, où m = MINEXPONENT-DIGITS, ..., MINEXPONENT-1.
!>     Notez que toutes les plateformes n'implémentent pas forcément les nombres subnormaux.
!> (2) x = 2**m, où m = MINEXPONENT, ..., 0.
!> (3) x = OV, où OV est le seuil de dépassement de capacité. OV^2 dépasse la capacité mais la norme est OV.
!> (4) x = 2**m, où m = MAXEXPONENT-1, ..., 1.
!>
!> Tests :
!> (a) y = x + 0 * I, y/y = 1
!> (b) y = 0 + x * I, y/y = 1
!> (c) y = x + x * I, y/y = 1
!> (d) y1 = 0 + x * I, y2 = x + 0 * I, y1/y2 = I
!> (e) y1 = 0 + x * I, y2 = x + 0 * I, y2/y1 = -I
!> (f) y = x + x * I, y/conj(y) = I
!>
!> Cas spéciaux :
!>
!> (i) Entrées Inf :
!>    (1) y = ( Inf + 0   * I)
!>    (2) y = ( 0   + Inf * I)
!>    (3) y = (-Inf + 0   * I)
!>    (4) y = ( 0   - Inf * I)
!>    (5) y = ( Inf + Inf * I)
!> Tests :
!>    (a) 0 / y est soit 0, soit NaN.
!>    (b) 1 / y est soit 0, soit NaN.
!>    (c) y / y est NaN.
!>
!> (n) Entrées NaN :
!>    (1) y = (NaN + 0   * I)
!>    (2) y = (0   + NaN * I)
!>    (3) y = (NaN + NaN * I)
!> Tests :
!>    (a) 0 / y est NaN.
!>    (b) 1 / y est NaN.
