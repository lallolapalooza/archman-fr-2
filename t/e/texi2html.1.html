TEXI2HTML(1) Manuel des commandes générales TEXI2HTML(1)

NOM

texi2html - convertisseur Texinfo vers HTML

SYNTAXE

texi2html [options] fichier

DESCRIPTION

Texi2html convertit le fichier Texinfo donné en un ensemble de fichiers HTML. Il essaie de gérer la plupart des commandes Texinfo. Il crée des liens hypertextes pour les références croisées, les notes de bas de page...

Texi2html peut en outre utiliser latex2html pour générer du HTML (code et/ou images) pour les balises @math et @iftex (voir l'option --l2h).

Texi2html crée plusieurs fichiers en fonction du contenu du fichier Texinfo et des options choisies (voir FICHIERS).

Les fichiers HTML créés par texi2html sont en général plus proches de TeX que de Info. En utilisant des fichiers d'initialisation (voir l'option --init-file), d'autres styles ou formats de sortie peuvent être sélectionnés.

OPTIONS

Les options peuvent être abrégées en leur préfixe unique le plus court. La liste suivante n'est qu'une liste incomplète des options disponibles :

--help [1|2]
Affiche les instructions d'utilisation et liste les options de ligne de commande les plus importantes, toutes les options pertinentes, ou toutes les options reconnues (y compris les obsolètes), puis quitte.
--split chapter|section|node
Divise la sortie en plusieurs fichiers HTML (un par chapitre/section principal ou par nœud).
--ifinfo --iftex --ifxml --ifplaintext --ifhtml
Développe les régions @ifinfo, @iftex et @tex, @ifxml et @xml, @ifplaintext, @ifhtml et @html, et ne développe pas les régions @ifnot correspondantes (par défaut : ifhtml).
--no-ifinfo --no-iftex --no-ifxml --no-ifplaintext --no-html
Ne développe pas les régions @ifinfo, @iftex, @ifxml, @ifplaintext et développe les régions @ifnot correspondantes.
-I dir
Ajoute dir à la liste des répertoires recherchés pour les fichiers inclus.
-P dir
Prépone dir à la liste des répertoires recherchés pour les fichiers inclus.
--l2h
Utilise latex2html pour le contenu des balises @math et @tex. Le contenu doit être tel que latex et tex puissent le traduire correctement. Autrement dit, aucune construction spécifique à tex ne doit être utilisée.
--css-include fichier
Utilise le fichier css fichier.
--init-file fichier
Charge le fichier d'initialisation fichier (voir aussi FICHIERS).
--document-language lang
Utilise lang comme langue du document.
--macro-expand fichier
Produit la sortie du code source avec les macros développées dans fichier.
--no-menu
N'affiche pas les menus Texinfo ; par défaut, ils sont affichés.
--no-number
Ne numérote pas les sections.
--use-nodes
Utilise les nœuds pour la structuration en sections.
--prefix
Utilise comme préfixe pour les fichiers de sortie, au lieu du nom de base.
--node-files
Produit un fichier par nœud pour les références croisées.
--l2h-l2h prog
Utilise prog comme programme latex2html (par défaut latex2html). Le programme doit être exécutable.
--l2h-init fichier
Utilise fichier comme fichier d'initialisation de latex2html. fichier doit être utilisé pour spécifier la manière dont latex2html gère les expressions mathématiques et les formules.
--l2h-tmp dir
Utilise dir comme répertoire temporaire pour latex2html. Ce répertoire (resp. son chemin) ne doit pas contenir de point (c'est-à-dire un ".").
--l2h-clean
Supprime tous les fichiers intermédiaires générés par latex2html (empêche la mise en cache !)
--l2h-skip
Ne lance pas réellement latex2html. Utilise les fichiers (conservés) des exécutions précédentes à la place.
--verbose
Fournit une sortie détaillée.
--version
Affiche la version et quitte.

FICHIERS

Les options d'initialisation sont lues d'abord à partir de /usr/share/texi2html/Config (l'emplacement exact pouvant être modifié avec l'option --datadir=dir lors de la configuration), puis à partir de /usr/etc/texi2html/Config (l'emplacement exact pouvant être modifié avec l'option --sysconfdir=dir lors de la configuration), puis à partir de ./Config, de $HOME/.texi2html/Config, et de toute option de ligne de commande, y compris les options --init-file ; les réglages ultérieurs écrasant les précédents.

Par défaut, texi2html crée les fichiers suivants (foo étant le nom du fichier Texinfo) :

foo_toc.html
La table des matières (si @contents est présent).
foo.html
Le contenu du document ou l'élément Top.
foo_fot.html
Les notes de bas de page (s'il y en a).
foo_abt.html
Une section d'aide.
foo_l2h_img*
Les images générées par latex2html (s'il y en a).

Lorsqu'il est utilisé avec l'option --split, il crée plusieurs fichiers (un par chapitre ou nœud), nommés foo_n.html (n étant l'indice du chapitre ou du nœud), et le fichier foo.html contient l'élément Top.

Sinon, il ne crée qu'un seul fichier : foo.html

texi2html(1)

NOM

texi2html - Convertit des fichiers Texinfo en fichiers HTML.

SYNTAXE

texi2html [OPTIONS] FICHIER...

DESCRIPTION

texi2html est un outil qui convertit des documents écrits en Texinfo au format HTML. Il est utile pour publier des documents en ligne ou pour les rendre accessibles sur des appareils qui ne prennent pas en charge le format Texinfo natif.

OPTIONS

-h, --help
Affiche un message d'aide et quitte.
-v, --version
Affiche des informations sur la version et quitte.
-o FICHIER, --output=FICHIER
Spécifie le fichier de sortie. Si omis, la sortie est envoyée à stdout.
--no-headers
Ne génère pas d'en-têtes HTML.
--css-file=FICHIER
Spécifie un fichier CSS à utiliser pour le style.
--no-symbol-table
Ne génère pas de table des symboles.

FICHIERS

/usr/share/texi2html/*
Fichiers de support pour texi2html.
