telldir(3) Manuel des fonctions de bibliothèque telldir(3)

NOM

telldir - renvoie la position actuelle dans un flux de répertoire

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <dirent.h>
long telldir(DIR *dirp);
Exigences relatives aux macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

telldir():

    _XOPEN_SOURCE
       || /* glibc >= 2.19: */ _DEFAULT_SOURCE
       || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

La fonction telldir() renvoie la position actuelle associée au flux de répertoire dirp.

VALEUR DE RETOUR

En cas de succès, la fonction telldir() renvoie la position actuelle dans le flux de répertoire. En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

EBADF
Descripteur de flux de répertoire dirp invalide.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
telldir () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, 4.3BSD.

Jusqu'à glibc 2.1.1, le type de retour de telldir() était off_t. POSIX.1-2001 spécifie long, et c'est le type utilisé depuis glibc 2.1.2.

Dans les systèmes de fichiers anciens, la valeur renvoyée par telldir() était un simple décalage de fichier dans un répertoire. Les systèmes de fichiers modernes utilisent des structures arborescentes ou hachées au lieu de tables plates pour représenter les répertoires. Sur de tels systèmes de fichiers, la valeur renvoyée par telldir() (et utilisée en interne par readdir(3)) est un "cookie" qui est utilisé par l'implémentation pour dériver une position dans un répertoire. Les programmes applicatifs doivent le traiter strictement comme une valeur opaque, sans faire aucune hypothèse sur son contenu.

VOIR AUSSI

closedir(3), opendir(3), readdir(3), rewinddir(3), scandir(3), seekdir(3)
