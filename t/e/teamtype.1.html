teamtype(1) Manuel des commandes générales teamtype(1)

NOM

teamtype - Permet la coédition en temps réel de fichiers texte locaux.

SYNTAXE

teamtype [--directory] [-h|--help] [-V|--version] <sous-commandes>

DESCRIPTION

Permet la coédition en temps réel de fichiers texte locaux.

OPTIONS

--directory <RÉPERTOIRE>
Le répertoire partagé. Par défaut, le répertoire courant.
-h, --help
Afficher l'aide.
-V, --version
Afficher la version.

SOUS-COMMANDES

teamtype-share(1)
Partager un répertoire avec un nouveau pair.
teamtype-join(1)
Rejoindre un répertoire partagé via un code de jointure, ou se connecter au plus récent.
teamtype-client(1)
Ouvrir une connexion JSON-RPC vers le démon Teamtype sur stdin/stdout. Utilisé par les plugins d'éditeurs de texte.
