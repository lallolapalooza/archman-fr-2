NOM

testsolv - exécute un cas de test libsolv à travers le solveur

SYNTAXE

testsolv [OPTIONS] TESTCASE

DESCRIPTION

L'outil testsolv peut être utilisé pour exécuter un cas de test. Les cas de test peuvent être soit créés manuellement pour tester des fonctionnalités spécifiques, soit écrits par la fonction testcase_write de libsolv. Ceci est utile pour évaluer les rapports de bugs concernant le solveur.

-v

Augmente le niveau de débogage du solveur. Cette option peut être spécifiée plusieurs fois pour augmenter davantage la quantité de données de débogage.

-r

Écrit la sortie au format de cas de test au lieu d'un texte lisible par l'homme. La sortie peut ensuite être utilisée dans la section résultat du cas de test. Si l'option -r est donnée deux fois, la sortie est formatée pour une inclusion verbatim.

-l PKGSPEC

Au lieu d'exécuter le solveur, liste les paquets dans les dépôts.

-s SOLUTIONSPEC

Ceci est utilisé dans la suite de tests du solveur pour tester les solutions calculées aux problèmes rencontrés.
