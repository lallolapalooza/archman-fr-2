NOM

tep_register_print_function, tep_unregister_print_function - Enregistre / Désenregistre une fonction d'aide.

SYNTAXE

#include <event-parse.h>
enum tep_func_arg_type {
        TEP_FUNC_ARG_VOID,
        TEP_FUNC_ARG_INT,
        TEP_FUNC_ARG_LONG,
        TEP_FUNC_ARG_STRING,
        TEP_FUNC_ARG_PTR,
        TEP_FUNC_ARG_MAX_TYPES
};
typedef unsigned long long (*tep_func_handler)(struct trace_seq *s, unsigned long long *args);
int tep_register_print_function(struct tep_handle *tep, tep_func_handler func, enum tep_func_arg_type ret_type, char *name, ...);
int tep_unregister_print_function(struct tep_handle *tep, tep_func_handler func, char *name);

DESCRIPTION

Certains événements peuvent avoir des fonctions d'aide dans les arguments du format d'impression. Cela permet à un plugin de créer dynamiquement un moyen de traiter l'une de ces fonctions.

La fonction tep_register_print_function() enregistre une telle fonction d'aide. L'argument tep est le contexte de l'analyseur d'événements de trace. L'argument func est un pointeur vers la fonction d'aide. L'argument ret_type est le type de retour de la fonction d'aide, une valeur de l'énumération tep_func_arg_type. Le name est le nom de la fonction d'aide, tel qu'il apparaît dans les arguments du format d'impression. Le ... est une liste variable d'énumérations tep_func_arg_type, les arguments de la fonction func. Cette liste doit se terminer par TEP_FUNC_ARG_VOID. Voir la section EXEMPLE.

La fonction tep_unregister_print_function() désenregistre une fonction d'aide, précédemment enregistrée avec tep_register_print_function(). L'argument tep est le contexte de l'analyseur d'événements de trace. Les arguments func et name sont les mêmes, utilisés lors de l'enregistrement de la fonction d'aide.

Le type tep_func_handler est le type de la fonction d'aide. L'argument s est la séquence de trace, il peut être utilisé pour créer une chaîne personnalisée. L'argument args est une liste d'arguments, définie lors de l'enregistrement de la fonction d'aide.

VALEUR DE RETOUR

La fonction tep_register_print_function() retourne 0 en cas de succès. En cas d'erreur, un code TEP_ERRNO_... est retourné.

La fonction tep_unregister_print_function() retourne 0 en cas de succès, ou -1 en cas d'erreur.

EXEMPLE

Certains événements ont des appels de fonctions internes, qui apparaissent dans le format d'impression. Par exemple "tracefs/events/i915/g4x_wm/format" contient :

print fmt: "pipe %c, frame=%u, scanline=%u, wm %d/%d/%d, sr %s/%d/%d/%d, hpll %s/%d/%d/%d, fbc %s",
            ((REC->pipe) + 'A'), REC->frame, REC->scanline, REC->primary,
            REC->sprite, REC->cursor, yesno(REC->cxsr), REC->sr_plane,
            REC->sr_cursor, REC->sr_fbc, yesno(REC->hpll), REC->hpll_plane,
            REC->hpll_cursor, REC->hpll_fbc, yesno(REC->fbc)

Remarquez l'appel à la fonction yesno() dans les arguments d'impression. Dans le contexte du noyau, cette fonction a l'implémentation suivante :

static const char *yesno(int x)
{
        static const char *yes = "yes";
        static const char *no = "no";
        return x ? yes : no;
}

L'analyseur d'événements en espace utilisateur n'a aucune idée de la manière de gérer cette fonction yesno(). L'API tep_register_print_function() peut être utilisée pour enregistrer une fonction d'aide en espace utilisateur, mappée à la fonction yesno() du noyau :

#include <event-parse.h>
#include <trace-seq.h>
...
struct tep_handle *tep = tep_alloc();
...
static const char *yes_no_helper(int x)
{
        return x ? "yes" : "no";
}
...
        if ( tep_register_print_function(tep,
                                    yes_no_helper,
                                    TEP_FUNC_ARG_STRING,
                                    "yesno",
                                    TEP_FUNC_ARG_INT,
                                    TEP_FUNC_ARG_VOID) != 0) {
                /* Échec de l'enregistrement de la fonction yes_no_helper */
        }
/*
   Maintenant, lorsque l'analyseur d'événements rencontre cette fonction yesno(),
   il saura comment la gérer.
*/
...
        if (tep_unregister_print_function(tep, yes_no_helper, "yesno") != 0) {
                /* Échec du désenregistrement de la fonction yes_no_helper */
        }

Autres formats : tep_unregister_print_function(3)

Nom

tep_unregister_print_function - Désenregistre une fonction d'impression

Syntaxe

#include <tep.h>

int tep_unregister_print_function(const char *name);

Description

La fonction tep_unregister_print_function() désenregistre une fonction d'impression enregistrée précédemment avec tep_register_print_function().

Le paramètre name est le nom de la fonction d'impression à désenregistrer.

Valeur de retour

En cas de succès, tep_unregister_print_function() renvoie 0. En cas d'échec, elle renvoie une valeur négative.
