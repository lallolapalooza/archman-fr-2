sous-programme ctfttp (caractère transr, caractère uplo, entier n, complexe, dimension( 0: * ) arf, complexe, dimension( 0: * ) ap, entier info)

CTFTTP copie une matrice triangulaire de format Rectangular Full Packed (TF) vers le format Packed standard (TP).

Objectif :

!>
!> CTFTTP copie une matrice triangulaire A du format Rectangular Full Packed
!> (TF) vers le format Packed standard (TP).
!>

Paramètres

TRANSR 
!>          TRANSR est CHARACTER*1
!>          = 'N' : ARF est au format Normal ;
!>          = 'C' : ARF est au format Conjugué-transposé ;
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : A est triangulaire supérieure ;
!>          = 'L' : A est triangulaire inférieure.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice A. N >= 0.
!>

ARF

!>          ARF est un tableau COMPLEXE, dimension ( N*(N+1)/2 ),
!>          En entrée, la matrice triangulaire supérieure ou inférieure A stockée
!>          au format RFP. Pour une discussion plus approfondie, voir ci-dessous.
!>

AP

!>          AP est un tableau COMPLEXE, dimension ( N*(N+1)/2 ),
!>          En sortie, la matrice triangulaire supérieure ou inférieure A, packée
!>          par colonne dans un tableau linéaire. La j-ième colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Univ. du Colorado Denver

NAG Ltd.

sous-programme   zgesdd ()


ZGESDD calcule la décomposition en valeurs singulières (SVD) d'une matrice complexe A.


La SVD est une factorisation de la forme


A = U * S * V**H


où S est un réel diagonal et U et V sont des unitaires.


Objectif :




!>
!> ZGESDD calcule la décomposition en valeurs singulières (SVD) d'une matrice M-by-N,
!> A = U * S * V**H,
!> où A est une matrice complexe M-by-N, U est une matrice unitaire M-by-M,
!> S est une matrice réelle diagonale de rang MIN(M,N) avec des entrées
!> non négatives sur la diagonale, et V est une matrice unitaire N-by-N. ZGESDD
!> renvoie les valeurs singulières, et les vecteurs singuliers gauches U et
!> les vecteurs singuliers droits V.
!> 




Paramètres


JOBZ

!>          JOBZ est CARACTERE*1
!>          Spécifie la computation des vecteurs singuliers :
!>          = 'A': Tous les vecteurs singuliers gauches et droits sont calculés.
!>          = 'S': Les M vecteurs singuliers gauches et les MIN(M,N) vecteurs
!>                 singuliers droits sont calculés.
!>          = 'O': Les M vecteurs singuliers gauches sont calculés, et les vecteurs
!>                 singuliers droits ne sont pas calculés.
!>          = 'N': Aucun vecteur singulier n'est calculé.
!> 


M


!>          M est ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.
!> 


N


!>          N est ENTIER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!> 


A


!>          A est un tableau COMPLEXE*16 de dimension (LDA, N).
!>          À l'entrée, la matrice A à décomposer.
!>          À la sortie, la matrice A est écrasée par le tableau A.
!> 


LDA


!>          LDA est ENTIER
!>          La largeur de la première dimension de A.  LDA >= max(1, M).
!> 


S


!>          S est un tableau REAL de dimension (SMLDIM), où SMLDIM = min(M,N).
!>          À la sortie, les valeurs singulières de A, triées par ordre décroissant.
!> 


U


!>          U est un tableau COMPLEXE*16 de dimension (LDU, LDWORK).
!>          Si JOBZ = 'A', U est une matrice LDU-by-M unitaire contenant les vecteurs
!>          singuliers gauches.
!>          Si JOBZ = 'S', U est une matrice LDU-by-M unitaire contenant les vecteurs
!>          singuliers gauches.
!>          Si JOBZ = 'O', U est une matrice LDU-by-M unitaire contenant les vecteurs
!>          singuliers gauches.
!>          Si JOBZ = 'N', U n'est pas alloué.
!> 


LDU


!>          LDU est ENTIER
!>          La largeur de la première dimension de U.
!>          Si JOBZ = 'A' ou JOBZ = 'S' ou JOBZ = 'O', LDU >= max(1, M).
!>          Si JOBZ = 'N', LDU.
!> 


VT


!>          VT est un tableau COMPLEXE*16 de dimension (LDVT, N).
!>          Si JOBZ = 'A', VT est une matrice LDVT-by-N unitaire contenant les vecteurs
!>          singuliers droits transposés (V**H).
!>          Si JOBZ = 'S', VT est une matrice LDVT-by-N unitaire contenant les vecteurs
!>          singuliers droits transposés (V**H).
!>          Si JOBZ = 'O', VT n'est pas alloué.
!>          Si JOBZ = 'N', VT n'est pas alloué.
!> 


LDVT


!>          LDVT est ENTIER
!>          La largeur de la première dimension de VT.
!>          Si JOBZ = 'A' ou JOBZ = 'S', LDVT >= max(1, MIN(M,N)).
!>          Si JOBZ = 'O' ou JOBZ = 'N', LDVT.
!> 


WORK


!>          WORK est un tableau COMPLEXE*16 de dimension (LWORK).
!>          À l'emploi, il est utilisé comme espace de travail.
!> 


LWORK


!>          LWORK est ENTIER
!>          La taille du tableau WORK. LWORK >= 1.
!>          Pour la meilleure performance, LWORK >= 2*M*N + max(M,N) si JOBZ = 'A' ;
!>          LWORK >= 2*M*N + max(M,N) si JOBZ = 'S' ;
!>          LWORK >= 2*M*N + max(M,N) si JOBZ = 'O' ;
!>          LWORK >= max(1,N) si JOBZ = 'N'.
!>          Si LWORK = -1, alors une taille de travail optimale est calculée. La réponse
!>          est stockée dans WORK(1).
!> 


RWORK


!>          RWORK est un tableau REAL de dimension (LRWORK).
!>          Espace de travail pour les calculs réels.
!> 


LRWORK


!>          LRWORK est ENTIER
!>          La taille du tableau RWORK. LRWORK >= 1.
!>          Pour la meilleure performance, LRWORK >= max(1, 2*MIN(M,N)*MIN(M,N) + MIN(M,N)).
!>          Si LRWORK = -1, alors une taille de travail optimale est calculée. La réponse
!>          est stockée dans RWORK(1).
!> 


INFO


!>          INFO est ENTIER
!>          = 0:  exécution réussie
!>          > 0 :  un algorithme de convergence a échoué à trouver toutes les valeurs
!>                singulières. Retourne le nombre d'éléments non convergents dans INFO.
!>          < 0 :  le i-ème argument avait une valeur illégale.
!> 




Description :




!>
!> ZGESDD utilise la méthode divide-and-conquer pour calculer la SVD.
!> Cette méthode est généralement plus rapide que les méthodes QR par blocs
!> (utilisées par ZGESVD) lorsque le nombre de valeurs singulières à calculer
!> est grand par rapport à la taille de la matrice.
!>

Objectif :

!> les vecteurs singuliers droits V.

Objectif :




!>
!> DGESVD calcule la décomposition en valeurs singulières (SVD) d'une matrice M-by-N,
!> A = U * S * V**T,
!> où A est une matrice réelle M-by-N, U est une matrice orthogonale M-by-M,
!> S est une matrice réelle diagonale de rang MIN(M,N) avec des entrées
!> non négatives sur la diagonale, et V est une matrice orthogonale N-by-N. DGESVD
!> renvoie les valeurs singulières, et les vecteurs singuliers gauches U et
!> les vecteurs singuliers droits V.
!>

!>          Spécifie la computation des vecteurs singuliers gauches :

!>          = 'S': Les MIN(M,N) vecteurs singuliers gauches sont calculés (U est M-by-MIN(M,N)).
!>          = 'O': Les M vecteurs singuliers gauches sont calculés, mais seulement la première

!>          = 'N': Aucun vecteur singulier gauche n'est calculé.

!>          Spécifie la computation des vecteurs singuliers droits :
!>          = 'U': Les N vecteurs singuliers droits sont calculés (V est N-by-N).

!>          = 'O': Les N vecteurs singuliers droits sont calculés, mais seulement la première
!>                 colonne de V**T est renvoyée.
!>          = 'N': Aucun vecteur singulier droit n'est calculé.
!> 


M


!>          M est ENTIER
!>          Le nombre de lignes de la matrice A. M >= 0.

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice A. N >= 0.
