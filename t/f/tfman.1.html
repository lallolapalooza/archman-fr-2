tfman(1) Manuel des commandes générales tfman(1)

NOM

tfman - Navigateur de pages de manuel Swank

SYNOPIS

tfman [-h] [-V] [-q] fichiers

DESCRIPTION

tfman affiche les pages de manuel à la manière de man(1) en utilisant la bibliothèque d'interface utilisateur de terminal Notcurses (notcurses(3)).

OPTIONS

-V : Affiche le nom du programme et sa version, puis quitte avec succès.

-h : Affiche les informations d'aide, puis quitte avec succès.

-q : N'attend aucune entrée et n'utilise pas l'écran alternatif.

fichiers : Fichiers à afficher.

Si les pages sont chargées et analysées avec succès, le haut de la page sera visible. Dans le coin inférieur droit se trouve une liste des sections de la page. Par défaut, le navigateur de page est utilisé ; appuyez sur Tab pour passer du navigateur de page au navigateur de structure. Appuyez sur 's' pour basculer la visibilité du navigateur de structure.

tfman peut identifier les pages de manuel zippées et les décompresser à la volée.

NOTES

Les frappes suivantes sont reconnues :

•
Ctrl-L : Redessine l'écran.
•
q : Quitter.
•
k/haut : Monter d'une ligne.
•
b/Page précédente : Monter d'une page.
•
h/gauche : Déplacer d'une section vers le haut.
•
j/bas : Descendre d'une ligne.
•
f/Page suivante : Descendre d'une page.
•
l/droite : Déplacer d'une section vers le bas.
•
g/début : Aller à la première ligne du fichier.
•
s : Basculer la visibilité du navigateur de structure.

La molette de la souris peut également être utilisée pour monter et descendre dans le navigateur actif.

BOGUES

tfman ne prend pas en charge actuellement (et il est peu probable qu'il le fasse un jour) le langage complet de macros groff.

VOIR AUSSI

man(1), notcurses(3), groff_man(7), man-pages(7), unicode(7)
