TFTP(1) Manuel utilisateur TFTP(1)

NOM

tftp - Client du protocole Trivial File Transfer Protocol IPv4

SYNTAXE

tftp [ options... ] [hôte [port]] [-c commande]

DESCRIPTION

tftp est un client du protocole Trivial File Transfer Protocol, qui peut être utilisé pour transférer des fichiers vers et depuis des machines distantes, y compris certains systèmes très minimalistes, généralement embarqués. L'hôte distant peut être spécifié sur la ligne de commande, auquel cas tftp utilise hôte comme hôte par défaut pour les transferts futurs (voir la commande connect ci-dessous.)

OPTIONS

-4
Se connecter uniquement avec IPv4, même si le support IPv6 a été compilé.
-6
Se connecter uniquement avec IPv6, si compilé.
-c commande
Exécute la commande comme si elle avait été entrée à l'invite tftp. Doit être spécifié en dernier sur la ligne de commande.
-l
Utiliser le mode littéral par défaut. Permet d'éviter le traitement spécial de ':' dans un nom de fichier.
-m mode
Définit le mode de transfert par défaut sur mode. Utilisé généralement avec -c.
-R port:port
Force le numéro de port d'origine à être dans la plage spécifiée de numéros de port.
-v
Utiliser le mode verbeux par défaut.
-V
Affiche le numéro de version et la configuration sur la sortie standard, puis quitte proprement.

COMMANDES

Une fois tftp lancé, il affiche l'invite tftp> et reconnaît les commandes suivantes :

? nom-de-commande...
help nom-de-commande...
Affiche les informations d'aide.
ascii
Raccourci pour mode ascii.
binary
Raccourci pour mode binary.
connect hôte [port]
Définit lhôte (et optionnellement le port) pour les transferts. Notez que le protocole TFTP, contrairement au protocole FTP, ne maintient pas de connexion entre les transferts ; par conséquent, la commande connect ne crée pas réellement de connexion, mais se contente de mémoriser quel hôte doit être utilisé pour les transferts. Vous n'avez pas à utiliser la commande connect ; l'hôte distant peut être spécifié dans le cadre des commandes get ou put.
get fichier
get fichier-distant fichier-local
get fichier1 fichier2 fichier3...
Récupère un fichier ou un ensemble de fichiers à partir des sources spécifiées. Un nom de fichier distant peut se présenter sous l'une des deux formes : un nom de fichier simple sur l'hôte distant, si l'hôte a déjà été spécifié, ou une chaîne de la forme hôte:nom-de-fichier pour spécifier à la fois un hôte et un nom de fichier. Si la dernière forme est utilisée, le nom d'hôte spécifié devient le défaut pour les transferts futurs. Activez le mode literal pour empêcher le traitement spécial du caractère ':' (par exemple, C:\dir\fichier).
literal
Active/désactive le mode littéral. Lorsqu'il est activé, ce mode empêche le traitement spécial de ':' dans les noms de fichiers.
mode mode-de-transfert
Spécifie le mode pour les transferts ; mode-de-transfert peut être l'un des choix : ascii (ou netascii) ou binary (ou octet.) Le mode par défaut est ascii.
put fichier
put fichier-local fichier-distant
put fichier1 fichier2 fichier3... répertoire-distant
Envoie un fichier ou un ensemble de fichiers vers le fichier ou le répertoire distant spécifié. La destination peut se présenter sous l'une des deux formes : un nom de fichier sur l'hôte distant, si l'hôte a déjà été spécifié, ou une chaîne de la forme hôte:nom-de-fichier pour spécifier à la fois un hôte et un nom de fichier. Si la dernière forme est utilisée, le nom d'hôte spécifié devient le défaut pour les transferts futurs. Si la forme répertoire-distant est utilisée, l'hôte distant est supposé être un système UNIX ou un autre système utilisant / comme séparateur de répertoire. Activez le mode literal pour empêcher le traitement spécial du caractère ':' (par exemple, C:\dir\fichier).
quit
Quitte tftp. La fin de fichier provoque également la sortie.
rexmt délai-de-retransmission
Définit le délai de retransmission par paquet, en secondes.
status
Affiche le statut actuel.
timeout délai-total-de-transmission
Définit le délai total de transmission, en secondes.
trace
Active/désactive le traçage des paquets (une fonctionnalité de débogage.)
verbose
Active/désactive le mode verbeux.

NOTES

Le protocole TFTP ne fournit aucune disposition pour l'authentification ou la sécurité. Par conséquent, le serveur distant mettra probablement en œuvre une forme de restriction d'accès ou de pare-feu. Ces restrictions d'accès sont susceptibles d'être spécifiques au site et au serveur.
