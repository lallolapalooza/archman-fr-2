TFTOPL(1) Manuel des commandes générales TFTOPL(1)

NOM

tftopl - convertir les fichiers de métriques de polices TeX (tfm) en listes de propriétés

SYNTAXE

tftopl [OPTIONS] nom_tfm[.tfm] [nom_pl[.pl]]

DESCRIPTION

Cette page de manuel n'est pas destinée à être exhaustive. La documentation complète de cette version de TeX se trouve dans le fichier info ou le manuel Web2C: A TeX implementation.

Le programme tftopl traduit un fichier de métriques de polices (orienté programme) en un fichier de liste de propriétés (orienté humain). Ainsi, vous pouvez modifier le contenu des fichiers TFM, si le concepteur de la police n'a pas fait son travail correctement, ou si vous rencontrez des difficultés étranges, ou si vous êtes simplement curieux. Il sert également de programme de validation des fichiers TFM, c'est-à-dire que s'il n'y a pas de messages d'erreur, le fichier d'entrée est correct.

Le nom nom_pl est prolongé par .pl s'il manque une extension. Si nom_pl n'est pas donné, la sortie standard est utilisée. De même, nom_tfm est prolongé par .tfm s'il manque une extension. De plus, une recherche de chemin est effectuée pour le fichier TFM en utilisant la variable d'environnement TEXFONTS. Si elle n'est pas définie, tftopl utilise la valeur par défaut du système.

Voir tex(1) pour les détails de la recherche.

OPTIONS

-format-code-caractere=format
L'argument format spécifie comment les codes de caractères sont produits dans le fichier PL. Par défaut, seules les lettres et les chiffres sont produits en utilisant le code entier C (c'est-à-dire en ASCII) ; les autres sont produits en octal. (Sauf si le schéma de codage de la police commence par TeX math sy ou TeX math ex, auquel cas tous les codes de caractères sont produits en octal.) Si format est ascii, tous les codes de caractères qui correspondent à des caractères graphiques, outre les parenthèses ouvrantes et fermantes, sont produits en ASCII. Enfin, si format est octal, tous les codes de caractères sont produits en octal.
-verbeux
Sans cette option, tftopl fonctionne silencieusement. Avec elle, une bannière et un rapport de progression sont imprimés sur stdout.
