sous-routine ctftri (caractère transr, caractère uplo, caractère diag, entier n, complexe, dimension( 0: * ) a, entier info)

CTFTRI

Objectif :

!>
!> CTFTRI calcule l'inverse d'une matrice triangulaire A stockée au format
!> RFP.
!>
!> Ceci est une version de l'algorithme de niveau 3 BLAS.
!>

Paramètres

TRANSR 
!>          TRANSR est CARACTERE*1
!>          = 'N' :  Le TRANSR Normal de RFP A est stocké ;
!>          = 'C' :  Le TRANSR Conjugué-Transposé de RFP A est stocké.
!>

UPLO

!>          UPLO est CARACTERE*1
!>          = 'U' :  A est triangulaire supérieure ;
!>          = 'L' :  A est triangulaire inférieure.
!>

DIAG

!>          DIAG est CARACTERE*1
!>          = 'N' :  A est triangulaire non-unitaire ;
!>          = 'U' :  A est triangulaire unitaire.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEXE, dimension ( N*(N+1)/2 ) ;
!>          En entrée, la matrice triangulaire A au format RFP. Le format RFP
!>          est décrit par TRANSR, UPLO et N comme suit : Si TRANSR =
!>          'N', alors RFP A est (0:N,0:k-1) quand N est pair ; k=N/2. RFP A est
!>          (0:N-1,0:k) quand N est impair ; k=N/2. SI TRANSR = 'C', alors RFP est
!>          le Conjugué-Transposé de RFP A tel que défini lorsque
!>          TRANSR = 'N'. Le contenu de RFP A est défini par UPLO comme suit :
!>          Si UPLO = 'U', RFP A contient les nt éléments de A supérieur
!>          empilé ; Si UPLO = 'L', RFP A contient les nt éléments de A
!>          inférieur empilé. Le LDA de RFP A est (N+1)/2 lorsque
!>          TRANSR = 'C'. Quand TRANSR est 'N', le LDA est N+1 lorsque N est
!>          pair et N est impair. Voir la Note ci-dessous pour plus de
!>          détails.
!>
!>          En sortie, l'inverse (triangulaire) de la matrice originale, dans
!>          le même format de stockage.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, A(i,i) est exactement zéro. La matrice
!>               triangulaire est singulière et son inverse ne peut pas être calculée.
!>

Univ. de Californie Berkeley

Univ. du Colorado Denver

NAG Ltd.

sous-routine ztftri (

NAME

ZTFTRI

inverser une matrice triangulaire stockée au format RFP

SYNOPSIS

SUBROUTINE ZTFTRI(TRANSR, UPLO, DIAG, N, A, INFO)
    CHARACTER(LEN=1)   :: DIAG, TRANSR, UPLO
    INTEGER            :: N, INFO
    COMPLEX*16, DIMENSION( * ) :: A

Detailed Description

ZTFTRI calcule l'inverse d'une matrice triangulaire A stockée au format RFP (Rectangular Full Packed).

Il s'agit d'une version de l'algorithme de niveau 3 BLAS.

Arguments

TRANSR

TRANSR est CHARACTER*1

= 'N': Le TRANSR normal de RFP A est stocké ;

= 'C': Le TRANSR conjugué-transposé de RFP A est stocké.

UPLO

UPLO est CHARACTER*1

= 'U': A est triangulaire supérieure ;

= 'L': A est triangulaire inférieure.

DIAG

DIAG est CHARACTER*1

= 'N': A est triangulaire non unitaire ;

= 'U': A est triangulaire unitaire.

N

N est INTEGER

L'ordre de la matrice A. N >= 0.

A

A est un tableau COMPLEX*16, de dimension ( N*(N+1)/2 ).

Sur l'entrée, la matrice triangulaire A au format RFP. Le format RFP est décrit par TRANSR, UPLO et N comme suit : Si TRANSR = 'N' alors RFP A est (0:N,0:k-1) quand N est pair ; k=N/2. RFP A est (0:N-1,0:k) quand N est impair ; k=N/2. SI TRANSR = 'C' alors RFP est le conjugué-transposé de RFP A tel défini quand TRANSR = 'N'. Le contenu de RFP A est défini par UPLO comme suit : Si UPLO = 'U' le RFP A contient les éléments `nt` de A supérieur packé ; Si UPLO = 'L' le RFP A contient les éléments `nt` de A inférieur packé. Le LDA de RFP A est (N+1)/2 quand TRANSR = 'C'. Quand TRANSR est 'N' le LDA est N+1 quand N est pair et N est impair. Voir la Note ci-dessous pour plus de détails.

Sur la sortie, l'inverse (triangulaire) de la matrice originale, dans le même format de stockage.

INFO

INFO est INTEGER

= 0 : sortie réussie

< 0 : si INFO = -i, le i-ème argument avait une valeur illégale

> 0 : si INFO = i, A(i,i) est exactement zéro. La matrice triangulaire est singulière et son inverse ne peut pas être calculé.
