NOM

twolame - encodeur MPEG Audio Layer 2 (MP2) optimisé

SYNTAXE

twolame [options] <fichier_entree> [fichier_sortie]

DESCRIPTION

TwoLAME est un encodeur MPEG Audio Layer 2 (MP2) optimisé basé sur tooLAME de Mike Cheng, qui est lui-même basé sur le code ISO dist10 et des parties de LAME. L'encodage est effectué par le backend de la bibliothèque libtwolame.

OPTIONS

Fichier d'entrée

twolame utilise libsndfile pour lire le fichier sonore d'entrée, donc le fichier d'entrée peut être dans n'importe quel format supporté par libsndfile. Pour lire de l'audio PCM brut depuis STDIN, utilisez - comme nom de fichier d'entrée.

Fichier de sortie

Si aucun nom de fichier de sortie n'est spécifié, l'extension du nom de fichier d'entrée est automatiquement changée en .mp2. Pour écrire l'audio encodé dans STDOUT, utilisez - comme nom de fichier de sortie.

Options d'entrée

-r, --raw-input

Spécifie que l'entrée est de l'audio PCM signé brut. Si l'audio est stéréo, les échantillons audio sont entrelacés entre les deux canaux.

-x, --byte-swap

Force l'inversion des octets de l'entrée. La détection de l'endianness est effectuée automatiquement par libsndfile, donc cette option ne devrait normalement pas être nécessaire.

-s, --samplerate <int>

Si l'entrée est du son PCM brut, vous devez spécifier la fréquence d'échantillonnage de l'audio en Hz. Fréquences d'échantillonnage valides : 16000, 22050, 24000, 32000, 44100, 48000 Hz. La fréquence d'échantillonnage par défaut est de 44100 Hz.

--samplesize <int>

Spécifie la taille de l'échantillon (en bits) de l'audio PCM brut. Tailles d'échantillon valides : 8, 16, 24, 32. La taille d'échantillon par défaut est de 16 bits.

-N, --channels <int>

Si l'entrée est du son PCM brut, vous devez spécifier le nombre de canaux de l'audio d'entrée. Le nombre de canaux par défaut est 2.

-g, --swap-channels

Inverse les canaux gauche et droit d'un fichier d'entrée stéréo.

--scale <float>

Échelle l'audio d'entrée avant l'encodage. Tout l'audio d'entrée est multiplié par la valeur spécifiée. Une valeur entre 0 et 1 réduira le gain audio, et une valeur supérieure à 1 augmentera le gain de l'audio.

--scale-l <float>

Identique à --scale, mais n'affecte que le canal gauche.

--scale-r <float>

Identique à --scale, mais n'affecte que le canal droit.

Options de sortie

-m, --mode <char>

Choisit le mode de l'audio résultant. Le mode par défaut est automatique.
•"a" auto - choisit le mode automatiquement en fonction de l'entrée
•"s" stéréo
•"d" double canal
•"j" stéréo joint
•"m" mono

-a, --downmix

Si le fichier d'entrée est stéréo, mélange les canaux d'entrée gauche et droit en un seul canal mono.

-b, --bitrate <int>

Définit le débit binaire total (en kbps) pour le fichier de sortie. Le débit binaire par défaut dépend du nombre de canaux d'entrée et de la fréquence d'échantillonnage. 
------------------------------
Fréquence Mono    Stéréo
------------------------------
48000         96      192
44100         96      192
32000         80      160
24000         48      96
22050         48      96
16000         32      64
------------------------------

-P, --psyc-mode <int>

Choisit le modèle psychoacoustique à utiliser (-1 à 4). Le modèle numéro -1 désactive la modélisation psychoacoustique et utilise à la place des valeurs par défaut fixes. Veuillez consulter le fichier psycho pour une description complète de chacun des modèles disponibles. Le modèle par défaut est 3.

-v, --vbr

Active le mode VBR (débit binaire variable). Voir le fichier de documentation vbr pour les détails. Le niveau VBR par défaut est 5.0.

-V, --vbr-level <float>

Active le mode VBR et définit le niveau de qualité. Plus le nombre est élevé, meilleure est la qualité. La plage maximale est de -50 à 50, mais la plage utile est de -10 à 10. Voir le fichier de documentation vbr pour les détails.

-l, --ath <float>

Définit le niveau ATH (Seuil d'audibilité). Le niveau par défaut est 0.0.

-q, --quick <int>

Active le mode rapide. Ne recalcule le modèle psychoacoustique que tous les nombres spécifiés de trames.

-S, --single-frame

Active le mode trame unique : une seule trame d'audio MPEG est générée, puis le programme se termine.

Options diverses

-c, --copyright

Active le drapeau Copyright dans le flux binaire de sortie.

-o, --non-original

Désactive le drapeau Original dans le flux binaire de sortie.

--original

Active le drapeau Original dans le flux binaire de sortie.

-p, --protect

Active la protection contre les erreurs CRC dans le flux binaire de sortie. Une somme de contrôle supplémentaire de 16 bits est ajoutée aux trames.

-d, --padding

Active le remplissage (padding) dans le flux binaire de sortie.

-R, --reserve <int>

Réserve un nombre spécifié de bits dans chaque trame du flux binaire de sortie.

-e, --deemphasis <char>

Définit le type de désaccentuation (n/c/5). Par défaut : aucun.

-E, --energy

Active les extensions de niveau d'énergie.

Options de verbosité

-t, --talkativity <int>

Définit le niveau d'informations à afficher sur stderr (0 à 10). Par défaut : 2.

--quiet

N'envoie aucun message à stderr, sauf en cas d'erreur. (Identique à --talkativity=0)

--brief

N'affiche qu'un nombre minimal de messages pendant l'encodage. Ce réglage est moins verbeux que le réglage de talkativité par défaut. (Identique à --talkativity=1)

--verbose

Affiche un nombre accru de messages sur stderr. Ce réglage est utile pour diagnostiquer les problèmes. (Identique à --talkativity=4)

CODES DE RETOUR

Si l'encodage se termine avec succès, twolame retournera 0. Cependant, si l'encodage n'est pas réussi, il retournera l'un des codes suivants :

•1 (Aucun encodage effectué)
•2 (Erreur lors de l'ouverture du fichier d'entrée)
•4 (Erreur lors de l'ouverture du fichier de sortie)
•6 (Erreur d'allocation mémoire)
•8 (Erreur dans les paramètres d'encodage choisis)
•10 (Erreur lors de la lecture de l'audio d'entrée)
•12 (Erreur survenue pendant l'encodage)
•14 (Erreur lors de l'écriture de l'audio de sortie)

EXEMPLES

Ceci encodera sound.wav en sound.mp2 en utilisant le débit binaire constant par défaut de 192 kbps et le modèle psychoacoustique par défaut (modèle 3) :

twolame sound.wav

Débit binaire constant de 160 kbps et encodage stéréo joint, sauvegardé dans le fichier sound_160.mp2 :

twolame -b 160 -m j sound.aiff sound_160.mp2

Encoder sound.wav en newfile.mp2 en utilisant le modèle psychoacoustique 2 et en encodant avec un débit binaire variable :

twolame -P 2 -v sound.wav newfile.mp2

Identique à l'exemple ci-dessus, sauf que la valeur négative de l'argument "-V" signifie que les débits binaires les plus bas seront favorisés par rapport aux plus élevés :

twolame -P 2 -V -5 sound.wav newfile.mp2

Ré-échantillonner un fichier audio en utilisant sox et le transmettre directement à twolame :

sox sound_11025.aiff -t raw -r 16000 | twolame -r -s 16000 - - > out.mp2
