sous-routine ctzrzf (integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, integer info)

CTZRZF

Objectif :

!>
!> CTZRZF réduit la matrice complexe supérieure trapézoïdale A de dimensions M par N ( M<=N )
!> en forme triangulaire supérieure au moyen de transformations unitaires.
!>
!> La matrice trapézoïdale supérieure A est factorisée comme suit :
!>
!>    A = ( R  0 ) * Z,
!>
!> où Z est une matrice unitaire N par N et R est une matrice triangulaire supérieure M par M.
!>

Paramètres

M 
!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice A. N >= M.
!>

A

!>          A est un tableau complexe (COMPLEX), de dimension (LDA,N)
!>          À l'entrée, la partie supérieure trapézoïdale M par N de la matrice A
!>          doit contenir la matrice à factoriser.
!>          À la sortie, la partie supérieure triangulaire M par M de A
!>          contient la matrice triangulaire supérieure R, et les éléments M+1 à
!>          N des M premières lignes de A, avec le tableau TAU, représentent la
!>          matrice unitaire Z sous forme de produit de M réflecteurs élémentaires.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau complexe (COMPLEX), de dimension (M)
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

WORK

!>          WORK est un tableau complexe (COMPLEX), de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la valeur LWORK optimale.
!>

LWORK

!>          LWORK est un entier (INTEGER)
!>          La dimension du tableau WORK. LWORK >= max(1,M).
!>          Pour des performances optimales, LWORK >= M*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Auteur

Université du Tennessee

Université de Californie Berkeley

Université du Colorado Denver

NAG Ltd.

Contributeurs :

A. Petitet, Département d'Informatique, Université du Tenn., Knoxville, USA

Détails supplémentaires :

!>
!>  La matrice Z de dimensions N par N peut être calculée par
!>
!>     Z =  Z(1)*Z(2)* ... *Z(M)
!>
!>  où chaque Z(k) de dimensions N par N est donnée par
!>
!>     Z(k) = I - tau(k)*v(k)*v(k)**H
!>
!>  avec v(k) le k-ème vecteur ligne de la matrice M par N
!>
!>     V = ( I   A(:,M+1:N) )
!>
!>  I est la matrice identité M par M, A(:,M+1:N)
!>  est la sortie stockée dans A à la sortie de CTZRZF,
!>  et tau(k) est le k-ème élément du tableau TAU.
!>
!>

NOM

stzrzf, ztzrzf - réduit une matrice trapézoïdale supérieure réelle ou complexe à une forme triangulaire supérieure.

SYNTAXIS

subroutine   stzrzf (integer m, integer n, real, dimension( lda, * ) a, integer lda, real,   dimension( * ) tau, real, dimension( * ) work, integer lwork, integer   info)

subroutine   ztzrzf (integer m, integer n, complex*16, dimension( lda, * ) a, integer lda,   complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer   lwork, integer info)

VERSION

Version 3.12.0

DESCRIPTION

La routine STZRZF réduit la matrice trapézoïdale supérieure réelle M-par-N ( M<=N ) A sous forme triangulaire supérieure au moyen de transformations orthogonales.

La matrice trapézoïdale supérieure A est factorisée comme suit :

   A = ( R  0 ) * Z,

où Z est une matrice orthogonale N-par-N et R est une matrice triangulaire supérieure M-par-M.

La routine ZTZRZF réduit la matrice trapézoïdale supérieure complexe M-par-N ( M<=N ) A sous forme triangulaire supérieure au moyen de transformations unitaires.

La matrice trapézoïdale supérieure A est factorisée comme suit :

   A = ( R  0 ) * Z,

où Z est une matrice unitaire N-par-N et R est une matrice triangulaire supérieure M-par-M.

PARAMETER

M

STZRZF M est INTEGER. Le nombre de lignes de la matrice A. M >= 0.

ZTZRZF M est INTEGER. Le nombre de lignes de la matrice A. M >= 0.

N

STZRZF N est INTEGER. Le nombre de colonnes de la matrice A. N >= M.

ZTZRZF N est INTEGER. Le nombre de colonnes de la matrice A. N >= M.

A

STZRZF A est un tableau REAL de dimension (LDA,N). En entrée, la partie supérieure trapézoïdale principale M-par-N du tableau A doit contenir la matrice à factoriser. En sortie, la partie triangulaire supérieure principale M-par-M de A contient la matrice triangulaire supérieure R, et les éléments M+1 à N des M premières lignes de A, avec le tableau TAU, représentent la matrice orthogonale Z sous forme de produit de M réflecteurs élémentaires.

ZTZRZF A est un tableau COMPLEX*16 de dimension (LDA,N). En entrée, la partie supérieure trapézoïdale principale M-par-N du tableau A doit contenir la matrice à factoriser. En sortie, la partie triangulaire supérieure principale M-par-M de A contient la matrice triangulaire supérieure R, et les éléments M+1 à N des M premières lignes de A, avec le tableau TAU, représentent la matrice unitaire Z sous forme de produit de M réflecteurs élémentaires.

LDA

STZRZF LDA est INTEGER. La dimension principale du tableau A. LDA >= max(1,M).

ZTZRZF LDA est INTEGER. La dimension principale du tableau A. LDA >= max(1,M).

TAU

STZRZF TAU est un tableau REAL de dimension (M). Les facteurs scalaires des réflecteurs élémentaires.

ZTZRZF TAU est un tableau COMPLEX*16 de dimension (M). Les facteurs scalaires des réflecteurs élémentaires.

WORK

STZRZF WORK est un tableau REAL de dimension (MAX(1,LWORK)). En sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.

ZTZRZF WORK est un tableau COMPLEX*16 de dimension (MAX(1,LWORK)). En sortie, si INFO = 0, WORK(1) contient la taille optimale de LWORK.

LWORK

STZRZF LWORK est INTEGER. La dimension du tableau WORK. LWORK >= max(1,M). Pour une performance optimale, LWORK >= M*NB, où NB est la taille de bloc optimale. Si LWORK = -1, une requête d'espace de travail est supposée ; la routine calcule uniquement la taille optimale du tableau WORK, la renvoie comme première entrée du tableau WORK, et aucun message d'erreur relatif à LWORK n'est émis par XERBLA.

ZTZRZF LWORK est INTEGER. La dimension du tableau WORK. LWORK >= max(1,M). Pour une performance optimale, LWORK >= M*NB, où NB est la taille de bloc optimale. Si LWORK = -1, une requête d'espace de travail est supposée ; la routine calcule uniquement la taille optimale du tableau WORK, la renvoie comme première entrée du tableau WORK, et aucun message d'erreur relatif à LWORK n'est émis par XERBLA.

INFO

STZRZF INFO est INTEGER. = 0: sortie réussie; < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.

ZTZRZF INFO est INTEGER. = 0: sortie réussie; < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
