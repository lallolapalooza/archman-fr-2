TZSET(3P) Manuel du programmeur POSIX TZSET(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

daylight, timezone, tzname, tzset — définir les informations de conversion de fuseau horaire

SYNTAXE

#include <time.h>
extern int daylight;
extern long timezone;
extern char *tzname[2];
void tzset(void);

DESCRIPTION

La fonction tzset() utilise la valeur de la variable d'environnement TZ pour définir les informations de conversion de l'heure utilisées par ctime(), localtime(), mktime() et strftime(). Si TZ est absente de l'environnement, des informations de fuseau horaire par défaut définies par l'implémentation seront utilisées.

La fonction tzset() définit la variable externe tzname comme suit :

tzname[0] = "std";
tzname[1] = "dst";

où std et dst sont tels que décrits dans le volume Définitions de base de POSIX.1‐2017, Chapitre 8, Variables d'environnement.

La fonction tzset() définit également la variable externe daylight à 0 si les conversions de l'heure d'été ne doivent jamais être appliquées pour le fuseau horaire utilisé ; sinon, une valeur non nulle. La variable externe timezone sera définie à la différence, en secondes, entre le Temps Universel Coordonné (UTC) et l'heure standard locale.

Si un thread accède directement à tzname, daylight ou timezone pendant qu'un autre thread est dans un appel à tzset(), ou à toute fonction qui est requise ou autorisée à définir les informations de fuseau horaire comme si par un appel à tzset(), le comportement est indéfini.

VALEUR RENVOYÉE

La fonction tzset() ne renvoie aucune valeur.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Les exemples de variables TZ et leurs différences de fuseau horaire sont donnés dans le tableau ci-dessous :

TZ timezone
EST5EDT 5*60*60
GMT0 0*60*60
JST-9 -9*60*60
MET-1MEST -1*60*60
MST7MDT 7*60*60
PST8PDT 8*60*60

UTILISATION PAR L'APPLICATION

Comme les fonctions ctime(), localtime(), mktime(), strftime() et strftime_l() sont requises pour définir les informations de fuseau horaire comme si par un appel à tzset(), il n'est pas nécessaire d'appeler explicitement tzset() avant d'utiliser ces fonctions. Cependant, les applications portables devraient appeler explicitement tzset() avant d'utiliser ctime_r() ou localtime_r() car la définition des informations de fuseau horaire est facultative pour ces fonctions.
