Paquet: libretls

TLS_CONFIG_SET_SESSION_ID(3) Manuel des fonctions de bibliothèque TLS_CONFIG_SET_SESSION_ID(3)

NOM

tls_config_set_session_fd, tls_config_set_session_id, tls_config_set_session_lifetime, tls_config_add_ticket_key — configurer la reprise des handshakes TLS

SYNOPSIS

#include <tls.h>

int
tls_config_set_session_fd(struct tls_config *config, int session_fd);

int
tls_config_set_session_id(struct tls_config *config, const unsigned char *session_id, size_t len);

int
tls_config_set_session_lifetime(struct tls_config *config, int lifetime);

int
tls_config_add_ticket_key(struct tls_config *config, uint32_t keyrev, unsigned char *key, size_t keylen);

DESCRIPTION

tls_config_set_session_fd() définit un descripteur de fichier à utiliser pour gérer les données des sessions TLS (client uniquement). Le descripteur de fichier fourni doit être un fichier régulier et appartenir à l'utilisateur actuel, avec des permissions restreintes pour n'autoriser que le propriétaire à lire et écrire le fichier (0600). Si le fichier a une longueur non nulle, le client tentera de lire les données de session de ce fichier et de reprendre la session TLS précédente avec le serveur. Après un handshake réussi, le fichier sera mis à jour avec les données de session actuelles, si disponibles. L'appelant est responsable de la fermeture de ce descripteur de fichier, après que tous les contextes TLS qui ont été configurés pour l'utiliser aient été libérés via tls_free().

tls_config_set_session_id() définit l'identifiant de session qui sera utilisé par le serveur TLS lorsque les sessions sont activées (serveur uniquement). Par défaut, une valeur aléatoire est utilisée.

tls_config_set_session_lifetime() définit la durée de vie à utiliser pour les sessions TLS (serveur uniquement). Le support des sessions est désactivé si une durée de vie de zéro est spécifiée, ce qui est le comportement par défaut.

tls_config_add_ticket_key() ajoute une clé utilisée pour le chiffrement et l'authentification des tickets TLS (serveur uniquement). Par défaut, les clés sont générées et pivotées automatiquement en fonction de leur durée de vie. Cette fonction ne doit être utilisée que pour synchroniser la clé de chiffrement des tickets entre plusieurs processus. La ré-ajout d'une clé connue entraînera une erreur, sauf s'il s'agit de la clé ajoutée le plus récemment.

VALEUR DE RETOUR

Ces fonctions renvoient 0 en cas de succès ou -1 en cas d'erreur.

VOIR AUSSI

tls_accept_socket(3), tls_config_set_protocols(3), tls_init(3), tls_load_file(3), tls_server(3)

HISTORIQUE

tls_config_set_session_id(), tls_config_set_session_lifetime() et tls_config_add_ticket_key() sont apparues dans OpenBSD 6.1.

tls_config_set_session_fd() est apparue dans OpenBSD 6.3.
