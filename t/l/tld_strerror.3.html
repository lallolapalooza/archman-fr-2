tld_strerror(3) libidn tld_strerror(3)

NOM

tld_strerror - fonction d'API

SYNTAXE

#include <tld.h>

const char * tld_strerror(Tld_rc rc);

ARGUMENTS

Tld_rc rc
code de retour tld

DESCRIPTION

Convertit un code de retour entier en une chaîne de caractères. Cette chaîne peut être utilisée pour afficher un message de diagnostic à l'utilisateur.

TLD_SUCCESS

Opération réussie. Cette valeur est garantie d'être toujours zéro, les autres sont garanties de contenir des valeurs non nulles, à des fins de comparaison logique.

TLD_INVALID

Caractère invalide trouvé.

TLD_NODATA

Aucune donnée d'entrée n'a été fournie.

TLD_MALLOC_ERROR

Erreur lors de l'allocation mémoire.

TLD_ICONV_ERROR

Erreur de conversion d'encodage de caractères.

TLD_NO_TLD

Aucun domaine de premier niveau trouvé dans la chaîne de domaine.

Valeur de retour : Retourne un pointeur vers une chaîne allouée statiquement contenant une description de l'erreur correspondant au code de retour rc.
