NOM

tlsrpt-reportd - Un démon pour créer et délivrer des rapports TLSRPT conformément à la RFC 8460.

SYNTAXE

tlsrpt-reportd [OPTION]

DESCRIPTION

Le tlsrpt-reportd est le composant final du framework TLSRPT. Un MTA (Mail Transfer Agent) rapporte la livraison réussie ou les erreurs rencontrées via libtlsrpt à un tlsrpt-collectd qui collecte et pré-agrège les données. Le tlsrpt-fetcher associé à un tlsrpt-collectd transfère les données pré-agrégées vers le tlsrpt-reportd. Le tlsrpt-reportd peut récupérer des données de plusieurs tlsrpt-fetchers et agrège les données pré-agrégées dans les rapports finaux. Ces rapports sont compressés avec gzip et envoyés aux destinations comme spécifié dans les enregistrements DNS TLSRPT des domaines ayant reçu des emails du MTA.

Un diagramme simple du flux de données visualisant l'interaction des composants ressemble à ceci : (MTA) v libtlsrt v tlsrpt-collectd v (stockage) v tlsrpt-fetcher v tlsrpt-reportd v (destination du rapport)

OPTIONS

Options de création et de configuration des rapports

--contact_info=addr

Utilise addr comme information de contact dans le rapport TLSRPT conformément à la RFC 8460.

--organization_name=descr

Utilise descr comme nom de l'organisation envoyant le rapport TLSRPT conformément à la RFC 8460.

--sender_address=email

Utilise email comme adresse "From:" lors de l'envoi de rapports par email.

--fetchers=list

Liste des commandes de fetcher pour récupérer les données. Plusieurs commandes de fetcher peuvent être données séparées par des virgules.

--dbname=path

Utilise la base de données SQLite à l'emplacement path.

--compression_level=n

Utilise le niveau de compression n pour compresser les rapports TLSRPT avec gzip.

--keep_days=n

Conserve les anciennes données pendant n jours avant de les supprimer de la base de données.

Options de délivrance des rapports

--spread_out_delivery=sec

Répartit la délivrance des rapports TLSRPT sur sec secondes. Ce paramètre doit être réglé sur plusieurs heures conformément à la RFC 8460, section 4.1. Par exemple, réglez spread_out_delivery sur 14400 pour répartir la délivrance des rapports sur quatre heures.

--sendmail_script=path

Utilise le script path pour envoyer un rapport TLSRPT par email.

--sendmail_timeout=sec

Définit le délai d'attente de sec secondes pour les requêtes d'envoi par email afin de délivrer les rapports.

--http_script=path

Utilise le script path pour téléverser un rapport TLSRPT via HTTP(S).

--http_timeout=sec

Définit le délai d'attente de sec secondes pour les requêtes POST HTTP afin de délivrer les rapports.

--max_retries_delivery=n

Abandonne après n tentatives infructueuses de délivrer un rapport à sa destination.

--min_wait_delivery=sec

Temps minimum d'attente avant de retenter une tentative de délivrance de rapport échouée.

--max_wait_delivery=sec

Temps maximum d'attente avant de retenter une tentative de délivrance de rapport échouée.

Options contrôlant l'interaction avec un ou plusieurs tlsrpt-collectd

--max_collectd_timediff=sec

Affiche un avertissement si l'horloge du collectd rapportée par son fetcher diffère de plus de sec secondes de l'horloge du reportd. Le reportd commence à interroger les fetchers sec secondes après le changement de jour UTC, donc une différence d'horloge supérieure à sec secondes indique que le collectd pourrait ne pas encore être prêt à fournir les données complètes pour la veille.

--max_collectd_timeout=sec

Attend au maximum sec secondes qu'un fetcher termine une requête de données de son collectd.

--max_retries_domaindetails=n

Abandonne après n tentatives infructueuses de récupérer les détails du rapport pour un domaine.

--min_wait_domaindetails=sec

Temps minimum d'attente avant de retenter après une tentative infructueuse d'obtenir les détails du rapport pour un domaine d'un tlsrpt-collectd.

--max_wait_domaindetails=sec

Temps maximum d'attente avant de retenter après une tentative infructueuse d'obtenir les détails du rapport pour un domaine d'un tlsrpt-collectd.

--max_retries_domainlist=n

Abandonne après n tentatives infructueuses de récupérer la liste des domaines d'un tlsrpt-collectd.

--min_wait_domainlist=sec

Temps minimum d'attente avant de retenter après une tentative infructueuse d'obtenir la liste des domaines d'un tlsrpt-collectd.

--max_wait_domainlist=sec

Temps maximum d'attente avant de retenter après une tentative infructueuse d'obtenir la liste des domaines d'un tlsrpt-collectd.

--interval_main_loop=sec

Réveille une boucle principale inactive même s'il n'y a pas de tâches après sec secondes d'inactivité.

Options de débogage et de développement

--debug_db=n

Contrôle le débogage de la base de données : 0 désactive le débogage de la base de données, 1 active l'enregistrement des instructions de la base de données.

--debug_send_file_dest=dir

Sauvegarde les rapports dans le répertoire dir en plus de leur délivrance par email ou requêtes POST HTTP.

--debug_send_mail_dest=path

Remplace la destination email pour envoyer les rapports par email. Veuillez noter : Avec cette option activée, les rapports destinés aux adresses email ne seront pas envoyés à la destination demandée depuis l'enregistrement DNS TLSRPT, mais à cette adresse de remplacement ! Cette option ne doit pas être utilisée sur des systèmes de production !

--debug_send_http_dest=path

Remplace la destination POST HTTP pour envoyer les rapports via des requêtes POST HTTP. Veuillez noter : Avec cette option activée, les rapports destinés aux destinations POST HTTP ne seront pas envoyés à la destination demandée depuis l'enregistrement DNS TLSRPT, mais à cette URL de remplacement ! Cette option ne doit pas être utilisée sur des systèmes de production !

Options générales

--config_file=filename

Lit les options à partir de la section tlsrpt_reportd du fichier de configuration de style INI filename. Les variables d'environnement écrasent les paramètres du fichier de configuration et les options de ligne de commande écrasent les deux.

--help

Affiche un message d'aide décrivant toutes les options.

--pidfilename=path

Spécifie le fichier contenant l'identifiant du processus du démon tlsrpt-reportd. Une chaîne vide n'entraînera la création d'aucun fichier PID.

Options de journalisation

--logfilename=filename

Utilise filename comme fichier journal.

--log_level=level

Définit le niveau de journalisation à level, valeurs autorisées : debug, info, warn, error.

ENVIRONNEMENT

Toutes les options de configuration, sauf --help et --config_file, peuvent également être définies via des variables d'environnement. La variable d'environnement pour une option de configuration est le préfixe TLSRPT_REPORTD_ suivi du nom du paramètre de configuration en majuscules. Par exemple, l'option --log_level peut être configurée à la place en utilisant la variable d'environnement TLSRPT_REPORTD_LOG_LEVEL.

EXEMPLES

1>

Récupérer des données d'un fetcher local avec configuration standard et d'un autre fetcher local avec un stockage différent :

tlsrpt-reportd --fetchers "tlsrpt-fetcher, tlsrpt-fetcher --storage sqlite:///tmp/test.sqlite"

Récupérer des données d'un fetcher local et d'un fetcher distant :

tlsrpt-reportd --fetchers "tlsrpt-fetcher, ssh user@remote tlsrpt-fetcher"
