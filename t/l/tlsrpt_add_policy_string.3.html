TLSRPT_ADD_POLICY_STRING(3) tlsrpt_add_policy_string TLSRPT_ADD_POLICY_STRING(3)

NOM

tlsrpt_add_policy_string - ajoute une chaîne de politique pour décrire la politique actuelle

SYNTAXE

#include <tlsrpt.h>

int tlsrpt_add_policy_string(struct tlsrpt_dr_t* dr, const char* policy_string)

DESCRIPTION

La fonction tlsrpt_add_policy_string ajoute une chaîne de politique pour décrire la politique actuelle. Plusieurs chaînes de politique peuvent être ajoutées au sein d'une même politique.

VALEUR RENVOYÉE

La fonction tlsrpt_add_policy_string renvoie 0 en cas de succès et un code d'erreur combiné en cas d'échec. Le code d'erreur combiné peut être analysé avec la fonction tlsrpt_strerror.

VOIR AUSSI

tlsrpt_strerror(3), tlsrpt_error_code_is_internal(3)
