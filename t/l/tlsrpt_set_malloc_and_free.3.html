NOM

tlsrpt_set_malloc_and_free - remplace l'implémentation malloc utilisée dans libtlsrpt

SYNTAXE

#include <tlsrpt.h>

void tlsrpt_set_malloc_and_free(void* (*malloc_function)(size_t size), void (*free_function)(void *ptr))

DESCRIPTION

La fonction tlsrpt_set_malloc_and_free remplace l'implémentation malloc utilisée dans libtlsrpt. Le malloc remplacé est utilisé au sein de libtlsrpt uniquement pour allouer les structures struct tlsrpt_connection_t et struct tlsrpt_dr_t. Les autres appels malloc provenant de la bibliothèque standard C ne sont pas affectés.


Note

Cette fonction doit être appelée avant que l'une des fonctions d'allocation tlsrpt_open et tlsrpt_init_delivery_request ne soit appelée ! Sinon, une implémentation malloc essaiera de libérer un pointeur alloué par une implémentation malloc différente.

VALEUR DE RETOUR

La fonction tlsrpt_set_malloc_and_free n'a pas de valeur de retour.

VOIR AUSSI

tlsrpt_open(3), tlsrpt_init_delivery_request(3)
