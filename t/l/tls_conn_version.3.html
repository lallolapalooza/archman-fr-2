DESCRIPTION

Ces fonctions retournent des informations sur une connexion TLS et ne réussiront qu'après la fin du handshake (les informations de connexion s'appliquent aux clients et aux serveurs, sauf indication contraire) :

tls_conn_version() retourne une chaîne de caractères correspondant à une version TLS négociée avec le pair connecté à ctx.

tls_conn_cipher() retourne une chaîne de caractères correspondant à la suite de chiffrement négociée avec le pair connecté à ctx.

tls_conn_cipher_strength() retourne la force en bits du chiffrement symétrique utilisé avec le pair connecté à ctx.

tls_conn_alpn_selected() retourne une chaîne de caractères spécifiant le protocole ALPN sélectionné pour une utilisation avec le pair connecté à ctx. Si aucun protocole n'a été sélectionné, NULL est retourné.

tls_conn_servername() retourne une chaîne de caractères correspondant au nom de serveur que le client connecté à ctx a demandé en envoyant une extension TLS Server Name Indication (côté serveur uniquement).

tls_conn_session_resumed() indique si une session TLS a été reprise pendant le handshake avec le serveur connecté à ctx (côté client uniquement).

tls_peer_cert_provided() vérifie si le pair de ctx a fourni un certificat.

tls_peer_cert_contains_name() vérifie si le pair d'un TLS ctx a fourni un certificat contenant un SAN ou un CN correspondant à name.

tls_peer_cert_chain_pem() retourne un pointeur vers la mémoire contenant une chaîne de certificats encodée en PEM pour le certificat du pair de ctx.

tls_peer_cert_subject() retourne une chaîne de caractères correspondant au sujet du certificat du pair de ctx.

tls_peer_cert_issuer() retourne une chaîne de caractères correspondant à l'émetteur du certificat du pair de ctx.

tls_peer_cert_hash() retourne une chaîne de caractères correspondant à un hachage du certificat brut du pair de ctx, préfixé par un nom de hachage suivi de deux points. Le hachage actuellement utilisé est SHA256, bien que cela puisse changer à l'avenir. La chaîne de hachage pour un certificat dans le fichier mycert.crt peut être générée en utilisant les commandes :

h=$(openssl x509 -outform der -in mycert.crt | sha256)
printf "SHA256:${h}\n"

tls_peer_cert_notbefore() retourne le temps correspondant au début de la période de validité du certificat du pair de ctx.

tls_peer_cert_notafter() retourne le temps correspondant à la fin de la période de validité du certificat du pair de ctx.

VALEUR RENVOYÉE

La fonction tls_conn_session_resumed() retourne 1 si une session TLS a été reprise ou 0 si ce n'est pas le cas.

Les fonctions tls_peer_cert_provided() et tls_peer_cert_contains_name() retournent 1 si la vérification réussit ou 0 si elle échoue.

tls_peer_cert_notbefore() et tls_peer_cert_notafter() retournent le temps en secondes depuis l'époque en cas de succès ou -1 en cas d'erreur.

Les fonctions retournant un pointeur retournent NULL en cas d'erreur ou de manque de mémoire.

HISTORIQUE

SYNOPSIS

int tls_conn_version(struct tls_conn *);

const char * tls_conn_version_str(struct tls_conn *);

DESCRIPTION

The tls_conn_version() function returns the negotiated protocol version number for the TLS connection represented by conn. The version numbers are defined in <tls.h> and are of the form TLS_PROTOCOL_VERSION_MAJOR_MINOR.

The tls_conn_version_str() function returns a human-readable string representation of the negotiated protocol version.

RETURN VALUES

tls_conn_version() returns the negotiated protocol version number, or 0 if it is not yet known or the connection is not using TLS.

tls_conn_version_str() returns a pointer to a static string representing the protocol version, or NULL if it is not yet known or the connection is not using TLS.

HISTORY

The tls_conn_version() function first appeared in OpenBSD 5.9.

The functions tls_conn_peer_cert_issuer(), tls_conn_peer_cert_subject(), tls_conn_peer_cert_hash(), tls_conn_peer_cert_notbefore(), and tls_conn_peer_cert_notafter() appeared in OpenBSD 5.9.

tls_conn_servername() and tls_conn_alpn_selected() appeared in OpenBSD 6.1.

tls_conn_session_resumed() appeared in OpenBSD 6.3.

tls_conn_cipher_strength() appeared in OpenBSD 6.7.
