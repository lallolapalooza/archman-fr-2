NOM

tlsrpt_cancel_delivery_request - marque la requête de livraison comme annulée

SYNTAXE

#include <tlsrpt.h>

int tlsrpt_cancel_delivery_request(struct tlsrpt_dr_t** pdr)

DESCRIPTION

La fonction tlsrpt_cancel_delivery_request marque la requête de livraison comme annulée. Ceci est fait via une "erreur factice" interne à la bibliothèque, TLSRPT_ERR_TLSRPT_CANCELLED, qui, comme toutes les erreurs, empêchera l'envoi de la requête de livraison. La fonction appelle ensuite tlsrpt_finish_delivery_request, qui s'occupera du nettoyage des ressources utilisées.

VALEUR DE RETOUR

La fonction tlsrpt_cancel_delivery_request renvoie 0 en cas de succès et un code d'erreur combiné en cas d'échec. Le code d'erreur combiné peut être analysé avec la fonction tlsrpt_strerror.
