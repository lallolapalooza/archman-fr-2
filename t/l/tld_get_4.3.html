NOM

tld_get_4 - Fonction API

SYNOPSIS

#include <tld.h>

int tld_get_4(const uint32_t * in, size_t inlen, char ** out);

ARGUMENTS

const uint32_t * in
Tableau de points de code unicode à traiter. Pas besoin d'être terminé par zéro.
size_t inlen
Nombre de points de code unicode.
char ** out
Pointeur vers la chaîne ASCII résultante terminée par zéro.

DESCRIPTION

Isole le domaine de premier niveau de in et le retourne sous forme de chaîne ASCII dans out.

Valeur de retour : Retourne TLD_SUCCESS en cas de succès, ou le code d'erreur Tld_rc correspondant sinon.
