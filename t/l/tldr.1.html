NOM

tldr - tldr 3.4.3

Client en ligne de commande Python pour tldr

usage: tldr commande [options]

ARGUMENTS POSITIONNELS

commande
commande à rechercher

ARGUMENTS NOMMÉS

-v, --version
affiche la version du programme et quitte
--search
Recherche une commande spécifique à partir d'une requête
-u, --update, --update_cache
Met à jour le cache local des pages et quitte

Défaut : Faux

-k, --clear-cache
Supprime le cache local des pages et quitte

Défaut : Faux

-p, --platform
Choix possibles : android, freebsd, linux, netbsd, openbsd, osx, sunos, windows, common

Remplace le système d'exploitation [android, freebsd, linux, netbsd, openbsd, osx, sunos, windows, common]

-l, --list
Liste toutes les commandes disponibles pour le système d'exploitation

Défaut : Faux

-s, --source
Remplace la source de page par défaut

Défaut : 'https://raw.githubusercontent.com/tldr-pages/tldr/main/pages'

-c, --color
Remplace le retrait de couleur
-r, --render
Rend les fichiers markdown locaux

Défaut : Faux

-L, --language
Remplace la langue par défaut
-m, --markdown
Affiche simplement le fichier de page brut.

Défaut : Faux

--short-options
Affiche les options courtes plutôt que longues

Défaut : Faux

--long-options
Affiche les options longues plutôt que courtes

Défaut : Faux

--print-completion
Choix possibles : bash, zsh, tcsh

Affiche le script d'achèvement du shell
