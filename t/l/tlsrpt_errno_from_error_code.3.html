NOM

tlsrpt_errno_from_error_code - retourne la partie `errno` d'un code d'erreur

SYNOPSIS

#include <tlsrpt.h>

int tlsrpt_errno_from_error_code(int errorcode)

DESCRIPTION

La fonction tlsrpt_errno_from_error_code retourne la partie errno d'un code d'erreur. En cas d'erreurs internes de la bibliothèque du bloc TLSRPT_ERR_TLSRPT, la valeur retournée sera un nombre élevé pour éviter les conflits avec les valeurs errno existantes. Par exemple, TLSRPT_ERR_TLSRPT_NESTEDPOLICY est 10731 au lieu de 10031 pour éviter que la partie errno ne soit décodée comme EMLINK.

VALEUR DE RETOUR

La fonction tlsrpt_errno_from_error_code retourne 0 en cas de succès et un code d'erreur combiné en cas d'échec. Le code d'erreur combiné peut être analysé avec la fonction tlsrpt_strerror.
