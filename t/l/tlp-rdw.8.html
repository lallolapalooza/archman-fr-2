tlp-rdw(8) Gestion de l'alimentation tlp-rdw(8)

NOM

tlp-rdw - désactive temporairement l'assistant de radio (jusqu'au redémarrage).

SYNTAXE

tlp-rdw [commande]

COMMANDES

disable
Désactive les actions RDW.
enable
Active les actions RDW.
<none>
Affiche l'état RDW.
--version
Affiche la version de TLP.

AUTORISATION

La commande tlp-rdw nécessite les privilèges root pour activer/désactiver les actions.

VOIR AUSSI
