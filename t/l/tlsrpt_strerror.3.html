TLSRPT_STRERROR(3) tlsrpt_strerror TLSRPT_STRERROR(3)

NOM

tlsrpt_strerror - renvoie une chaîne statique décrivant l'erreur

SYNOPSIS

#include <tlsrpt.h>

const char* tlsrpt_strerror(int errorcode)

DESCRIPTION

La fonction tlsrpt_strerror renvoie une chaîne statique décrivant l'erreur. Si l'erreur n'est pas une erreur interne (tlsrpt_error_code_is_internal renvoie 0 dans ce cas), le texte décrit la fonction de la bibliothèque C qui a généré une erreur et pour les fonctions de la bibliothèque C qui sont appelées depuis différents endroits dans la bibliothèque TLSRPT, la fonction appelante est mentionnée dans la description. L'erreur réelle doit être récupérée depuis la bibliothèque C via la fonction strerror ou ses alternatives. La valeur errno à passer à la fonction strerror doit être extraite du code d'erreur via la fonction tlsrpt_errno_from_error_code.

VALEUR DE RETOUR

La fonction tlsrpt_strerror renvoie une chaîne statique décrivant l'erreur.

VOIR AUSSI

tlsrpt_error_code_is_internal(3), tlsrpt_errno_from_error_code(3)
