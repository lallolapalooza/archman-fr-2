NOM

tld_check_8z - Fonction d'API

SYNTAXE

#include <tld.h>

int tld_check_8z(const char * in, size_t * errpos, const Tld_table ** overrides);

ARGUMENTS

const char * in
Chaîne UTF8 terminée par un caractère nul à traiter.
size_t * errpos
La position du caractère fautif est retournée ici.
const Tld_table ** overrides
Un tableau Tld_table de structures supplémentaires de restriction de domaine qui complètent et remplacent les informations intégrées.

DESCRIPTION

Teste chacun des caractères de in pour déterminer s'ils sont autorisés par les informations dans overrides ou par les données de restriction TLD intégrées. Lorsque des données pour le même TLD sont disponibles à la fois en interne et dans overrides, les informations dans overrides ont la priorité. Si plusieurs entrées pour un TLD spécifique sont trouvées, la première est utilisée. Si overrides est NULL, seules les informations intégrées sont utilisées. La position du premier caractère fautif est retournée dans errpos. Notez que la position de l'erreur se réfère au décalage du caractère décodé plutôt qu'à la position en octets dans la chaîne.

Valeur de retour : Renvoie la valeur Tld_rc TLD_SUCCESS si tous les caractères sont valides ou si tld est nul, TLD_INVALID si un caractère n'est pas autorisé, ou des codes d'erreur supplémentaires en cas de conditions d'échec générales.
