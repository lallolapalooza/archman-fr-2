TLSRPT_ERROR_CODE_IS_INTERNAL(3) tlsrpt_error_code_is_internal TLSRPT_ERROR_CODE_IS_INTERNAL(3)

NOM

tlsrpt_error_code_is_internal - renvoie si le code d'erreur est interne à la bibliothèque TLSRPT

SYNTAXE

#include <tlsrpt.h>

int tlsrpt_error_code_is_internal(int errorcode)

DESCRIPTION

La fonction tlsrpt_error_code_is_internal indique si le code d'erreur est interne à la bibliothèque TLSRPT. tlsrpt_error_code_is_internal renvoie 1 si le code d'erreur décrit une erreur interne à la bibliothèque TLSRPT. tlsrpt_error_code_is_internal renvoie 0 si le code d'erreur est un code d'erreur composé de la fonction C, du point d'appel au sein de la bibliothèque TLSRPT et de la valeur errno résultant de l'appel échoué à la bibliothèque C.

VALEUR DE RETOUR

La fonction tlsrpt_error_code_is_internal indique si le code d'erreur est interne à la bibliothèque TLSRPT.

VOIR AUSSI

tlsrpt_strerror(3), tlsrpt_errno_from_error_code(3)
