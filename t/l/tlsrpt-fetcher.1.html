NOM

tlsrpt-fetcher - L'agent de transfert de données pour amener les données de rapport TLSRPT du tlsrpt-collectd au tlsrpt-reportd.

SYNTAXE

tlsrpt-fetcher [OPTION] JOUR [DOMAINE]

DESCRIPTION

Le tlsrpt-fetcher est appelé par le tlsrpt-reportd pour collecter les données pré-agrégées des tlsrpt-collectds. La récupération des données se fait en deux étapes.

Dans la première étape, le reportd demande une liste de domaines pour lesquels des données ont été collectées.

Dans cette étape, le reportd vérifie d'abord si le tlsrpt-fetcher prend en charge une version de protocole correspondante, au cas où les futures versions utiliseraient un protocole différent. La version du protocole fetcher est donc la première ligne.

La deuxième ligne est l'heure actuelle du bundle tlsrpt-collectd/tlsrpt-fetcher. Si l'heure diffère trop de celle du tlsrpt-reportd, un avertissement est donné indiquant que les données n'ont peut-être pas été entièrement traitées.

Les lignes suivantes sont les domaines, un domaine par ligne. La fin de la liste est signalée par une ligne ne contenant qu'un seul signe "."

OPTIONS

--storage=URL

Utiliser le stockage de données décrit par URL.

Options générales

--config_file=nom_fichier

Lire les options de la section tlsrpt_fetcher du fichier de configuration de style INI nom_fichier. Les variables d'environnement remplacent les paramètres du fichier de configuration et les options de la ligne de commande remplacent les deux.

--help

Afficher un message d'aide décrivant toutes les options.

Options de journalisation

--logfilename=nom_fichier

Utiliser nom_fichier comme fichier journal.

--log_level=niveau

Définir le niveau de journalisation à niveau, valeurs autorisées : debug, info, warn, error.

ENVIRONNEMENT

Toutes les options de configuration à l'exception de --help et --config_file peuvent également être définies via des variables d'environnement. La variable d'environnement pour une option de configuration est le préfixe TLSRPT_FETCHER_ suivi du nom du paramètre de configuration en majuscules. Par exemple, l'option --log_level peut être configurée à la place en utilisant la variable d'environnement TLSRPT_FETCHER_LOG_LEVEL.

STATUT DE SORTIE

0

Succès.

1

Échec. Les données n'ont pas pu être livrées.

EXEMPLES

Récupère la liste des domaines qui ont des données de rapport pour le jour du 2001-02-03. Imprime un en-tête de protocole de transfert et une liste des domaines avec un domaine par ligne. L'en-tête du protocole se compose de deux lignes : - la version du protocole - l'heure actuelle de la source de données en UTC.

Un seul "." marque la fin de la liste :

tlsrpt-fetcher 2001-02-03

Récupère les détails du rapport pour le domaine example.com pour le jour du 2001-02-03 :

tlsrpt-fetcher 2001-02-03 example.com
