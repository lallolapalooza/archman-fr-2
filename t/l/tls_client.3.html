TLS_CLIENT(3) Manuel des fonctions de bibliothèque TLS_CLIENT(3)

NOM

tls_client, tls_server, tls_configure, tls_reset, tls_free — configurer une connexion TLS

SYNOPSIS

#include <tls.h>

struct tls *
tls_client(void);

struct tls *
tls_server(void);

int
tls_configure(struct tls *ctx, struct tls_config *config);

void
tls_free(struct tls *ctx);

void
tls_reset(struct tls *ctx);

DESCRIPTION

Une connexion TLS est représentée par un objet struct tls appelé « contexte ». Un nouveau contexte est créé par les fonctions tls_client() ou tls_server(). tls_client() est utilisé dans les programmes clients TLS, tls_server() dans les programmes serveurs TLS.

Le contexte peut ensuite être configuré avec la fonction tls_configure(). Le même objet tls_config peut être utilisé pour configurer plusieurs contextes.

Après configuration, tls_connect(3) peut être appelé sur les objets créés avec tls_client(), et tls_accept_socket(3) sur les objets créés avec tls_server().

Après utilisation, un contexte TLS doit être fermé avec tls_close(3), puis libéré en appelant tls_free(). Si tls_free() est appelé avec un argument NULL, aucune action n'est effectuée.

Un contexte TLS peut être réinitialisé en appelant tls_reset(), permettant sa réutilisation. Ceci est essentiellement équivalent à appeler tls_free(), suivi d'un appel à la même fonction qui a été utilisée pour allouer initialement le contexte TLS.

VALEURS DE RETOUR

tls_client() et tls_server() retournent NULL en cas d'erreur ou de manque de mémoire.

tls_configure() retourne 0 en cas de succès ou -1 en cas d'erreur.

VOIR AUSSI

tls_accept_socket(3), tls_config_new(3), tls_connect(3), tls_init(3)

HISTORIQUE

Ces fonctions sont apparues dans OpenBSD 5.6 et ont reçu leurs noms définitifs dans OpenBSD 5.7.
