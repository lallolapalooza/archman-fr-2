TLSRPT_SET_BLOCKING(3) tlsrpt_set_blocking TLSRPT_SET_BLOCKING(3)

NOM

tlsrpt_set_blocking - modifie l'appel `sendto` dans `tlsrpt_finish_delivery_request` pour qu'il soit bloquant

SYNTAXE

#include <tlsrpt.h>

void tlsrpt_set_blocking()

DESCRIPTION

La fonction tlsrpt_set_blocking modifie l'appel sendto au sein de tlsrpt_finish_delivery_request pour qu'il soit bloquant. Le comportement par défaut est non bloquant.

VALEUR RENVOYÉE

La fonction tlsrpt_set_blocking n'a pas de valeur de retour.
