TLSRPT_INIT_DELIVERY_REQUEST(3) tlsrpt_init_delivery_request TLSRPT_INIT_DELIVERY_REQUEST(3)

NOM

tlsrpt_init_delivery_request - alloue et initialise l'objet `struct tlsrpt_dr_t`

SYNTAXE

#include <tlsrpt.h>

int tlsrpt_init_delivery_request(struct tlsrpt_dr_t** pdr, struct tlsrpt_connection_t* con, const char* domainname, const char* policyrecord)

DESCRIPTION

La fonction tlsrpt_init_delivery_request alloue et initialise l'objet struct tlsrpt_dr_t. Les ressources qu'elle alloue doivent être libérées en appelant soit tlsrpt_finish_delivery_request, soit tlsrpt_cancel_delivery_request.

VALEUR DE RETOUR

La fonction tlsrpt_init_delivery_request retourne 0 en cas de succès et un code d'erreur combiné en cas d'échec. Le code d'erreur combiné peut être analysé avec la fonction tlsrpt_strerror.

VOIR AUSSI

tlsrpt_cancel_delivery_request(3), tlsrpt_finish_delivery_request(3), tlsrpt_strerror(3), tlsrpt_error_code_is_internal(3)
