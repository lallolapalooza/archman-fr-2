NOM

tlcockpit - Interface graphique pour le gestionnaire TeX Live tlmgr

SYNTAXE

tlcockpit [-d] [-dd] [-q] [-qq]

DESCRIPTION

TLCockpit vise à être une interface graphique pour tlmgr, le gestionnaire TeX Live, avec un aspect moderne. Nous nous inspirons de TeX Live Utility.

OPTIONS

-d
être verbeux
-dd
être encore plus verbeux
-q
être silencieux
-qq
être encore plus silencieux

AUTEUR

TLCockpit a été écrit par Norbert Preining.
