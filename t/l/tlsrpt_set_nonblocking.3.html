Paquet: libtlsrpt

Licences: LGPL-3.0-or-later

TLSRPT_SET_NONBLOCKING(3) tlsrpt_set_nonblocking TLSRPT_SET_NONBLOCKING(3)

NOM

tlsrpt_set_nonblocking - restaure le comportement par défaut non bloquant de l'appel `sendto` dans `tlsrpt_finish_delivery_request`

SYNTAXE

#include <tlsrpt.h>

void tlsrpt_set_nonblocking()

DESCRIPTION

La fonction tlsrpt_set_nonblocking restaure le comportement par défaut non bloquant de l'appel sendto au sein de tlsrpt_finish_delivery_request.

VALEUR DE RETOUR

La fonction tlsrpt_set_nonblocking n'a pas de valeur de retour.
