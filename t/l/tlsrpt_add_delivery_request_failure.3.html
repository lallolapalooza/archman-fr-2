NOM

tlsrpt_add_delivery_request_failure - ajoute un échec à la politique actuelle

SYNTAXE

#include <tlsrpt.h>

int tlsrpt_add_delivery_request_failure(struct tlsrpt_dr_t* dr, tlsrpt_failure_t failure_code, const char* sending_mta_ip, const char* receiving_mx_hostname, const char* receiving_mx_helo, const char* receiving_ip, const char* additional_information, const char* failure_reason_code)

DESCRIPTION

La fonction tlsrpt_add_delivery_request_failure ajoute un échec à la politique actuelle. Plusieurs échecs peuvent être ajoutés au sein d'une politique.

Certains des paramètres peuvent être NULL et dans ce cas seront omis dans le datagramme.

VALEUR DE RETOUR

La fonction tlsrpt_add_delivery_request_failure retourne 0 en cas de succès et un code d'erreur combiné en cas d'échec. Le code d'erreur combiné peut être analysé avec la fonction tlsrpt_strerror.

VOIR AUSSI

tlsrpt_strerror(3), tlsrpt_error_code_is_internal(3)
