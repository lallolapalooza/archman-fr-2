NOM

tld_check_4t - Fonction d'API

SYNTAXE

#include <tld.h>

int tld_check_4t(const uint32_t * in, size_t inlen, size_t * errpos, const Tld_table * tld);

ARGUMENTS

const uint32_t * in
Tableau de points de code unicode à traiter. Pas besoin d'être terminé par zéro.
size_t inlen
Nombre de points de code unicode.
size_t * errpos
La position du caractère fautif sera retournée ici.
const Tld_table * tld
Une structure de données Tld_table représentant les restrictions pour lesquelles l'entrée doit être testée.

DESCRIPTION

Teste chacun des points de code dans in pour savoir s'ils sont autorisés par la structure de données dans tld , et retourne la position du premier caractère pour lequel ce n'est pas le cas dans errpos .

Valeur de retour : Retourne la valeur Tld_rc TLD_SUCCESS si tous les points de code sont valides ou lorsque tld est nul, TLD_INVALID si un caractère n'est pas autorisé, ou des codes d'erreur supplémentaires en cas de conditions d'échec générales.
