tlp-stat(8) Gestion de l'énergie tlp-stat(8)

NOM

tlp-stat - afficher le statut d'économie d'énergie

SYNTAXE

tlp-stat [options] [-- PARAM_CONFIG=valeur ... ]

DESCRIPTION

Affiche la configuration, les informations système, les réglages d'économie d'énergie du noyau et les données de la batterie. L'appel sans options affiche toutes les catégories d'informations.

OPTIONS

Opération système

-s, --system
Affiche les informations système et le statut TLP.
-m, --mode
Affiche le profil d'alimentation actuellement actif.

Configuration

-c, --config
Affiche la configuration active.
--cdiff
Affiche la différence entre les paramètres par défaut et la configuration utilisateur.
-- PARAM_CONFIG=valeur ...
Ajoute des paramètres de configuration à une commande. Ceux-ci remplacent temporairement la configuration système pendant l'exécution de cette commande uniquement et ne sont pas conservés par la suite. Avertissement : cette fonctionnalité existe dans le seul but d'automatiser les tests lors du développement de TLP. Elle est fournie telle quelle et il n'y a aucun support.

Économie d'énergie

-d, --disk
Affiche les réglages des périphériques de disque.
-e, --pcie
Affiche les réglages des périphériques PCIe. Ajoutez -v pour voir l'état d'exécution du périphérique.
-g, --graphics
Affiche les réglages des cartes graphiques. Ajoutez -v pour voir l'état d'alimentation et les fréquences des GPU AMD.
-p, --processor
Affiche les réglages du processeur. Pour plus de clarté, la sortie standard affiche uniquement cpu0. Ajoutez -v pour voir tous les CPU. Ajoutez -q pour voir uniquement l'état du pilote CPU.
-r, --rfkill
Affiche les états et les réglages des périphériques radio. Ajoutez -v pour voir les détails de NetworkManager et rfkill.
-u, --usb
Affiche les réglages des périphériques USB. Ajoutez -v pour voir l'état d'exécution du périphérique.

Gestion batterie

-b, --battery
Affiche les données de la batterie et les fonctionnalités de gestion de batterie prises en charge par votre matériel. Ajoutez -v pour voir les tensions de la batterie (si disponibles).

Informations

-q, --quiet
Omet l'en-tête de version et affiche moins d'informations dans la catégorie processeur.
-t, --temp
Affiche les températures et la vitesse du ventilateur. Ajoutez -v pour voir tous les capteurs individuels.
-v, --verbose
Affiche plus d'informations dans les catégories batterie, graphique, PCIe, processeur, température, sans fil et USB.
--version
Affiche la version de TLP.

Diagnostics et débogage

--pd-diag
Affiche les diagnostics tlp-pd.
-P, --pev
Surveille les événements udev de l'alimentation.
--psup
Affiche les diagnostics de l'alimentation.
-T, --trace
Affiche la sortie de traçage pour tlp et tlp-pd.
--trace-nm
Affiche la sortie de traçage corrélée avec le journal de NetworkManager.
--udev
Vérifie si les règles udev pour les changements de source d'alimentation et la connexion des périphériques USB sont actives.
-w, --warn
Affiche des avertissements concernant les disques SATA.

AUTORISATION

De nombreuses commandes de tlp-stat (mais pas toutes) nécessitent des privilèges root.

FICHIERS

/etc/tlp.conf

Fichier de configuration utilisateur au niveau du système, décommentez les paramètres ici pour remplacer les paramètres par défaut et les fichiers de personnalisation ci-dessous.

/etc/tlp.d/*.conf

Fichiers de personnalisation de type drop-in au niveau du système, remplaçant les valeurs par défaut ci-dessous.

/usr/share/tlp/defaults.conf

Paramètres par défaut intrinsèques. NE MODIFIEZ PAS ce fichier, utilisez plutôt l'une des alternatives ci-dessus.

/run/tlp/run.conf

Paramètres effectifs consolidés à partir de tous les fichiers ci-dessus. NE MODIFIEZ PAS ce fichier, il est uniquement à titre de référence et est régénéré à chaque invocation de TLP.
