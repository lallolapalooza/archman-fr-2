TOUPPER(3P) Manuel du programmeur POSIX TOUPPER(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

toupper, toupper_l — translittère les caractères minuscules en majuscules

SYNTAXE

#include <ctype.h>
int toupper(int c);
int toupper_l(int c, locale_t locale);

DESCRIPTION

Pour toupper() : Les fonctionnalités décrites sur cette page de référence sont alignées sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

Les fonctions toupper() et toupper_l() ont comme domaine un type int, dont la valeur est représentable comme un unsigned char ou la valeur EOF. Si l'argument a une autre valeur, le comportement est indéfini.

Si l'argument de toupper() ou toupper_l() représente une lettre minuscule, et qu'il existe une lettre majuscule correspondante telle que définie par les informations de type de caractère dans la locale actuelle ou dans la locale représentée par locale, respectivement (catégorie LC_CTYPE), le résultat sera la lettre majuscule correspondante.

Tous les autres arguments du domaine sont retournés inchangés.

Le comportement est indéfini si l'argument locale de toupper_l() est l'objet de locale spécial LC_GLOBAL_LOCALE ou n'est pas un descripteur d'objet de locale valide.

VALEUR DE RETOUR

En cas de succès, toupper() et toupper_l() retourneront la lettre majuscule correspondant à l'argument passé ; sinon, elles retourneront l'argument inchangé.
