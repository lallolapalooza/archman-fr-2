NOM

tohtml - Créer du HTML à partir d'une entrée LaTeX

SYNTAXE

tohtml [-latex] [-info] [-mapref filename] [-basedir dirname] [-userpath path] [-iftex] [-split n] [-headeroffset n ] [-mapman filename ] [-cvtlatex] [-cvttables] [-cvtmath] [-simplemath] [-useimg] [-gaudy] [-iftex] [-default] [-nonavnames] [-notopnames] [-nobottomnav] [-basedef filename] [-endpage filename ] [-beginpage filename] [-citeprefix str] [-citesuffix str] [-o outname ] filename

PARAMÈTRES D'ENTRÉE

-iftex
- Inclure le texte en mode begin{iftex}...end{iftex}
-cvtlatex
- Convertir le LaTeX qui ne peut pas être représenté comme du texte en bitmaps
-cvttables
- Convertir les environnements tabulaires en bitmaps
-useimg
- Utilisé avec -cvtlatex, utilise les bitmaps existants d'une exécution précédente
-gaudy
- Utiliser des images colorées pour les puces d'itemize
-nocopy
- Ne pas copier les bitmaps prédéfinis
-dosnl
- Générer des sauts de ligne de style Windows/DOS (retour à la ligne)
-split n
- Diviser le document jusqu'aux sections au niveau n -split -1 interdit la division ; 0 = chapitre, 1 = section, etc.
-headeroffset n
- Décale les en-têtes HTML générés par la section. Par exemple, pour utiliser H2 au lieu de H1 pour les sections de premier niveau, utilisez -headeroffset 1
-nonavnames
- Ne pas afficher les boutons de _navigation_
-notopnames
- Ne pas afficher les noms en haut de la page
-nobottomnav
- Ne pas afficher les noms ou les boutons en bas d'une section
-nocontents
- Ne pas générer la page de _sommaire_
-mapref file
- Convertir les références dans \\cite en hyperliens en utilisant le fichier spécifié
-mapman file
- Convertir les occurrences de jetons en hyperliens vers des fichiers
-default
- Choisir des valeurs par défaut relativement agréables
-citeprefix str
- Définir le préfixe pour les citations (par défaut '[')
-citesuffix str
- Définir le suffixe pour les citations (par défaut ']')
-basedef name
- Utiliser le nom de fichier pour définir les commandes TeX
-beginpage filename
- Préfixer le HTML dans filename à la fin de chaque page
-endpage filename
- Ajouter le HTML dans filename à la fin de chaque page
-o outname
- Spécifier le nom à utiliser comme nom de fichier de sortie (au lieu de baser le nom du fichier de sortie sur le nom du fichier d'entrée). Ce nom doit inclure l'extension naturelle ; par exemple, pour une sortie HTML, utilisez quelque chose comme tohtml -latex -o myout.htm myfile.tex .

EMPLACEMENT

tohtml.c
