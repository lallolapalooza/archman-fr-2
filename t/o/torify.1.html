NOM

torify - wrapper pour torsocks et tor

SYNTAXE

torify application [arguments de l'application]

DESCRIPTION

torify est un wrapper simple qui appelle torsocks avec un fichier de configuration spécifique à tor.

Il est fourni pour des raisons de compatibilité ascendante ; vous devriez plutôt utiliser torsocks.

AVERTISSEMENT

Lorsqu'il est utilisé avec torsocks, torify ne devrait pas fuir les requêtes DNS ni les données UDP.

torify peut fuir les données ICMP.

torify ne garantira pas que différentes requêtes soient traitées sur différents circuits.

VOIR AUSSI

tor(1), torsocks(1)
