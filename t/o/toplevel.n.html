toplevel(n) Commandes intégrées Tk toplevel(n)

NOM

toplevel - Crée et manipule les widgets de fenêtre principale et popup 'toplevel'

SYNOPSIS

toplevel nomChemin ?options?

OPTIONS STANDARD

-borderwidth	-highlightcolor	-pady
-cursor	-highlightthickness	-relief
-highlightbackground	-padx	-takefocus

Voir l'entrée de manuel options pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de ligne de commande :	-background
Nom de base de données :	background
Classe de base de données :	Background
Cette option est identique à l'option standard -background sauf que sa valeur peut également être spécifiée comme une chaîne vide. Dans ce cas, le widget n'affichera aucun arrière-plan ni bordure, et aucune couleur ne sera consommée de sa carte de couleurs pour son arrière-plan et sa bordure.
Nom de ligne de commande :	-class
Nom de base de données :	class
Classe de base de données :	Class
Spécifie une classe pour la fenêtre. Cette classe sera utilisée lors de la requête de la base de données d'options pour les autres options de la fenêtre, et elle sera également utilisée plus tard à d'autres fins, comme les liaisons (bindings). Certains gestionnaires de fenêtres affichent le nom de la classe pour les fenêtres dans leur barre des tâches tandis que d'autres affichent le titre de la fenêtre. L'option -class ne peut pas être modifiée avec la commande de widget configure.
Nom de ligne de commande :	-colormap
Nom de base de données :	colormap
Classe de base de données :	Colormap
Spécifie une carte de couleurs à utiliser pour la fenêtre. La valeur peut être soit new, auquel cas une nouvelle carte de couleurs est créée pour la fenêtre et ses enfants, soit le nom d'une autre fenêtre (qui doit être sur le même écran et avoir la même visualisation que nomChemin), auquel cas la nouvelle fenêtre utilisera la carte de couleurs de la fenêtre spécifiée. Si l'option -colormap n'est pas spécifiée, la nouvelle fenêtre utilise la carte de couleurs par défaut de son écran. Cette option ne peut pas être modifiée avec la commande de widget configure.
Nom de ligne de commande :	-container
Nom de base de données :	container
Classe de base de données :	Container
La valeur doit être un booléen. Si vrai, cela signifie que cette fenêtre sera utilisée comme conteneur dans lequel une autre application sera intégrée (par exemple, un toplevel Tk peut être intégré en utilisant l'option -use). La fenêtre supportera les protocoles appropriés du gestionnaire de fenêtres pour des choses comme les requêtes de géométrie. La fenêtre ne doit avoir aucun enfant propre dans cette application. Cette option ne peut pas être modifiée avec la commande de widget configure.
Nom de ligne de commande :	-height
Nom de base de données :	height
Classe de base de données :	Height
Spécifie la hauteur souhaitée pour la fenêtre dans n'importe quelle forme acceptable par Tk_GetPixels. Si cette option est inférieure ou égale à zéro, la fenêtre ne demandera aucune taille.
Nom de ligne de commande :	-menu
Nom de base de données :	menu
Classe de base de données :	Menu
Spécifie un widget menu à utiliser comme barre de menus. Sur Macintosh, la barre de menus sera affichée en haut de l'écran principal. Sur Microsoft Windows et toutes les plateformes UNIX, le menu apparaîtra en travers de la fenêtre toplevel dans le cadre de l'habillage de fenêtre géré par le gestionnaire de fenêtres.
Nom de ligne de commande :	-screen
Nom de base de données :	
Classe de base de données :
Spécifie l'écran sur lequel placer la nouvelle fenêtre. Tout nom d'écran valide peut être utilisé, même un nom associé à un écran différent. Par défaut, utilise le même écran que son parent. Cette option est spéciale car elle ne peut pas être spécifiée via la base de données d'options et ne peut pas être modifiée avec la commande de widget configure.
Nom de ligne de commande :	-use
Nom de base de données :	use
Classe de base de données :	Use
Cette option est utilisée pour l'intégration. Si la valeur n'est pas une chaîne vide, elle doit être l'identifiant de fenêtre d'une fenêtre conteneur, spécifié sous forme de chaîne hexadécimale comme celles retournées par la commande winfo id. Le widget toplevel sera créé comme enfant du conteneur donné au lieu de la fenêtre racine de l'écran. Si la fenêtre conteneur est dans une application Tk, elle doit être un widget frame ou toplevel pour lequel l'option -container a été spécifiée. Cette option ne peut pas être modifiée avec la commande de widget configure.
Nom de ligne de commande :	-visual
Nom de base de données :	visual
Classe de base de données :	Visual
Spécifie les informations de visualisation pour la nouvelle fenêtre dans n'importe quelle forme acceptée par Tk_GetVisual. Si cette option n'est pas spécifiée, la nouvelle fenêtre utilisera la visualisation par défaut de son écran. L'option -visual ne peut pas être modifiée avec la commande de widget configure.
Nom de ligne de commande :	-width
Nom de base de données :	width
Classe de base de données :	Width
Spécifie la largeur souhaitée pour la fenêtre dans n'importe quelle forme acceptable par Tk_GetPixels. Si cette option est inférieure ou égale à zéro, la fenêtre ne demandera aucune taille.

DESCRIPTION

La commande toplevel crée un nouveau widget toplevel (donné par l'argument nomChemin). Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer des aspects du toplevel tels que sa couleur d'arrière-plan et son relief. La commande toplevel renvoie le nom du chemin de la nouvelle fenêtre.

Un toplevel est similaire à un frame sauf qu'il est créé comme une fenêtre de plus haut niveau : son parent X est la fenêtre racine d'un écran plutôt que le parent logique de son nom de chemin Tk. Le but principal d'un toplevel est de servir de conteneur pour les boîtes de dialogue et d'autres collections de widgets. Les seules caractéristiques visibles d'un toplevel sont sa couleur d'arrière-plan et une bordure optionnelle en 3D pour faire apparaître le toplevel surélevé ou enfoncé.

COMMANDE DE WIDGET

La commande toplevel crée une nouvelle commande Tcl dont le nom est le même que le nom du chemin de la fenêtre du toplevel. Cette commande peut être utilisée pour invoquer diverses opérations sur le widget. Elle a la forme générale suivante :

nomChemin option ?arg arg ...?

nomChemin est le nom de la commande, qui est le même que le nom du chemin du widget toplevel. Option et les args déterminent le comportement exact de la commande. Les commandes suivantes sont possibles pour les widgets toplevel :

nomChemin cget option
Retourne la valeur actuelle de l'option de configuration donnée par option. Option peut avoir n'importe laquelle des valeurs acceptées par la commande toplevel.
nomChemin configure ?option? ?valeur option valeur ...?
Interroge ou modifie les options de configuration du widget. Si aucune option n'est spécifiée, renvoie une liste décrivant toutes les options disponibles pour nomChemin (voir Tk_ConfigureInfo pour des informations sur le format de cette liste). Si option est spécifiée sans valeur, alors la commande renvoie une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur renvoyée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, alors la commande modifie les options du widget données pour avoir les valeurs données ; dans ce cas, la commande renvoie une chaîne vide. Option peut avoir n'importe laquelle des valeurs acceptées par la commande toplevel.

LIAISONS (BINDINGS)

Lorsqu'un nouveau toplevel est créé, il n'a pas de liaisons d'événements par défaut : les toplevels ne sont pas destinés à être interactifs.

Soyez conscient que les liaisons sur les toplevels peuvent recevoir des événements des sous-widgets.

toplevel

Le widget toplevel est une fenêtre de niveau supérieur.

Les widgets toplevel sont utilisés pour créer des fenêtres principales dans une application Tk.

Syntaxe :

tk_dialog .dialog "Titre" "Message" "?" "Ok"

Options :

  • -title : Définit le titre de la fenêtre.
  • -width : Définit la largeur de la fenêtre.
  • -height : Définit la hauteur de la fenêtre.
  • -bg : Définit la couleur de fond.
  • -fg : Définit la couleur du texte.

Exemple :

toplevel .mywindow
wm title .mywindow "Ma Fenêtre"
label .mywindow.label -text "Ceci est une fenêtre toplevel."
pack .mywindow.label

Le widget toplevel est souvent utilisé en conjonction avec d'autres widgets pour créer des interfaces utilisateur complexes.

Il est également couramment utilisé pour afficher des boîtes de dialogue, des menus et d'autres éléments d'interface utilisateur interactifs.

Le widget toplevel prend en charge la plupart des options de configuration standard de Tk, ainsi que des options spécifiques aux fenêtres.

Ces options spécifiques aux fenêtres comprennent la possibilité de définir la taille, le titre, les bordures, les curseurs, la gestion de la géométrie, la gestion des événements, la gestion des ancrages, la gestion des gestionnaires de fenêtres et la gestion des menus.

Le widget toplevel est un élément puissant et polyvalent de la boîte à outils Tk.

Il peut être utilisé pour créer une grande variété d'interfaces utilisateur, des simples boîtes de dialogue aux applications complexes.
