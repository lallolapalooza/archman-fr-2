NOM

toxic - client CLI pour Tox

SYNTAXE

toxic [-f fichier-donnees] [-x] [-4] [-c fichier-config] [-n fichier-noeuds] [-h]

DESCRIPTION

toxic est un client de messagerie instantanée basé sur ncurses pour Tox, qui résidait auparavant dans le dépôt principal de Tox et est maintenant disponible en tant qu'application autonome.

OPTIONS

-4, --ipv4

Forcer la connexion IPv4

-b, --debug

Activer stderr pour le débogage. Redirigez la sortie pour éviter de casser l'interface curses et de mieux capturer les messages.

-c, --config fichier-config

Utiliser le fichier-config spécifié au lieu de ~/.config/tox/toxic.conf

-d, --default-locale

Utiliser la locale par défaut

-e, --encrypt-data

Chiffrer un fichier de données non chiffré. Une erreur se produira si cette option est utilisée avec un fichier de données chiffré.

-f, --file fichier-donnees

Utiliser le fichier-donnees spécifié au lieu de ~/.config/tox/toxic_profile.tox

-h, --help

Afficher le message d'aide

-l, --logging

Activer la journalisation de toxcore vers stderr

-n, --nodes fichier-noeuds

Utiliser le fichier-noeuds spécifié pour les nœuds de bootstrap DHT au lieu de ~/.config/tox/DHTnodes.json

-o, --noconnect

Ne pas se connecter au réseau DHT

-p, --SOCKS5-proxy

Utiliser un proxy SOCKS5 : nécessite [IP] [port]

-P, --HTTP-proxy

Utiliser un proxy HTTP : nécessite [IP] [port]

-r, --namelist

Utiliser la liste des serveurs de noms spécifiée

-t, --force-tcp

Forcer la connexion TCP (utilisez ceci avec des proxys)

-T, --tcp-relay

Agir comme un serveur relais TCP pour le réseau (Note : cela consomme beaucoup plus de bande passante)

-u, --unencrypt-data

Déchiffrer un fichier de données. Un avertissement apparaîtra si cette option est utilisée avec un fichier de données déjà déchiffré.

FICHIERS

~/.config/tox/DHTnodes.json

Emplacement par défaut pour la liste des nœuds de bootstrap DHT (liste obtenue sur https://nodes.tox.chat). Cette liste est automatiquement mise à jour. Voir toxic.conf(5) pour les détails sur le contrôle de la fréquence de mise à jour.

~/.config/tox/toxic_profile.tox

État de sauvegarde contenant vos informations personnelles (pseudo, ID Tox, contacts, etc.)

~/.config/tox/toxic.conf

Fichier de configuration. Voir toxic.conf(5) pour plus de détails.

/usr/share/toxic/toxic.conf.example

Exemple de configuration.

BOGUES

-Les caractères Unicode dont la largeur est supérieure à 1 colonne peuvent provoquer un comportement étrange.

-Des scintillements d'écran se produisent parfois sur certains terminaux.

-Redimensionner la fenêtre du terminal lorsqu'une fenêtre de jeu est ouverte causera des problèmes.
