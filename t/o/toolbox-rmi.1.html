NOM

toolbox-rmi - Supprimer une ou plusieurs images Toolbx

SYNTAXE

toolbox rmi [--all | -a] [--force | -f] [IMAGE...]

DESCRIPTION

Supprime une ou plusieurs images Toolbx de l'hôte. L'image doit avoir été créée à l'aide de la commande toolbox create.

Une image Toolbx est une image OCI. Par conséquent, toolbox rmi peut être utilisé de manière interchangeable avec podman rmi.

OPTIONS

Les options suivantes sont comprises :

--all, -a

Supprime toutes les images Toolbx. Peut être utilisé conjointement avec --force également.

--force, -f

Force la suppression des images Toolbx utilisées par des conteneurs Toolbx. Les conteneurs dépendants seront également supprimés.

EXEMPLES

Supprimer une image Toolbx nommée localhost/fedora-toolbox-gegl:36

$ toolbox rmi localhost/fedora-toolbox-gegl:36

Supprimer toutes les images Toolbx, mais pas celles utilisées par des conteneurs

$ toolbox rmi --all

Supprimer toutes les images Toolbx et leurs conteneurs dépendants

$ toolbox rmi --all --force
