NOM

tor-gencert - Générer les certificats et clés pour les autorités de répertoire Tor

SYNTAXE

tor-gencert [-h|--help] [-v] [-r|--reuse] [--create-identity-key] [-i fichier_id] [-c fichier_cert] [-m nb] [-a adresse:port]

DESCRIPTION

tor-gencert génère les certificats et les clés privées à utiliser par les autorités de répertoire Tor exécutant le protocole de répertoire Tor v3, tel qu'utilisé par Tor 0.2.0 et versions ultérieures. Si vous n'exécutez pas une autorité de répertoire, vous n'avez pas besoin d'utiliser tor-gencert.

Chaque autorité de répertoire possède une clé d'identité à long terme (qui est distincte de la clé d'identité qu'elle utilise en tant que serveur Tor) ; cette clé doit être conservée hors ligne dans un endroit sécurisé. Elle est utilisée pour certifier des clés de signature à durée de vie plus courte, qui sont conservées en ligne et utilisées par l'autorité de répertoire pour signer les votes et les documents de consensus.

Après avoir utilisé ce programme pour générer une clé de signature et un certificat, copiez ces fichiers dans le sous-répertoire `keys` de votre processus Tor, puis envoyez un signal SIGHUP à Tor. NE COPIEZ PAS LA CLÉ D'IDENTITÉ.

OPTIONS

-v

Affiche une sortie détaillée.

-h ou --help

Affiche le texte d'aide et quitte.

-r ou --reuse

Génère un nouveau certificat, mais pas une nouvelle clé de signature. Ceci peut être utilisé pour changer l'adresse ou la durée de validité associée à une clé donnée.

--create-identity-key

Génère une nouvelle clé d'identité. Vous ne devriez utiliser cette option que la première fois que vous exécutez tor-gencert ; à l'avenir, vous devriez utiliser la clé d'identité déjà présente.

-i NOMFICHIER

Lit la clé d'identité à partir du fichier spécifié. Si le fichier n'est pas présent et que --create-identity-key est fourni, crée la clé d'identité dans le fichier spécifié. Défaut : "./authority_identity_key"

-s NOMFICHIER

Écrit la clé de signature dans le fichier spécifié. Défaut : "./authority_signing_key"

-c NOMFICHIER

Écrit le certificat dans le fichier spécifié. Défaut : "./authority_certificate"

-m NB

Nombre de mois pendant lesquels le certificat doit être valide. Défaut : 12.

--passphrase-fd DESCFICHIER

Descripteur de fichier à partir duquel lire la phrase de passe. Se termine au premier NUL ou retour à la ligne. Défaut : lecture depuis le terminal.

-a adresse:port

Si fourni, annonce la combinaison adresse:port comme port de répertoire préféré de cette autorité dans son certificat. Si l'adresse est un nom d'hôte, le nom d'hôte est résolu en une adresse IP avant d'être publié.

BOGUES

Ceci ne fonctionne probablement pas sous Windows. Ce n'est pas un gros problème, car nous ne voulons pas vraiment que les autorités soient exécutées sous Windows de toute façon.
