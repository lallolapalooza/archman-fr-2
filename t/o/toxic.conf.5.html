NOM

toxic.conf - Fichier de configuration pour toxic

SYNTAXE

~/.config/tox/toxic.conf

DESCRIPTION

Le fichier toxic.conf est le fichier de configuration principal pour le client toxic(1). Il utilise la syntaxe acceptée par libconfig. Les lignes commençant par "//" sont des commentaires et seront ignorées.

EXEMPLE

// Configuration de l'interface
ui = {
    timestamps = true;
    alerts = false;
};
// Configuration audio
audio = {
    input_device = 1;
};

OPTIONS

ui

Configuration liée aux éléments de l'interface.

timestamps

Activer ou désactiver les horodatages. true ou false

time_format

Choisir entre un format horaire sur 24 heures et 12 heures. Spécifier 24 ou 12. La définition de timestamp_format et log_timestamp_format outrepassera ce paramètre.

timestamp_format

Chaîne de formatage de l'heure pour l'interface, encadrée par des guillemets doubles. Voir date(1)

log_timestamp_format

Chaîne de formatage de l'heure pour la journalisation, encadrée par des guillemets doubles. (Note : la partie temporelle de la chaîne de formatage doit être encadrée par des crochets afin d'être analysée par toxic). Voir date(1)

alerts

Activer ou désactiver les alertes sonores lors d'événements. true ou false

show_notification_content

Afficher le contenu des notifications de bureau. true ou false

native_colors

Choisir entre les couleurs natives du terminal et le thème de couleurs de toxic. true ou false

color_bar_bg

Définir la couleur de fond des barres d'état des discussions. (black, white, gray, brown, red, green, blue, cyan, yellow, magenta, orange, pink)

color_bar_fg

Définir la couleur de premier plan (texte) des barres d'état des discussions. (black, white, gray, brown, red, green, blue, cyan, yellow, magenta, orange, pink)

color_bar_accent

Définir la couleur d'accent de premier plan des barres d'état des discussions. (black, white, gray, brown, red, green, blue, cyan, yellow, magenta, orange, pink)

color_bar_notify

Définir la couleur de notification (et de frappe) de premier plan dans la barre d'état de la discussion. (black, white, gray, brown, red, green, blue, cyan, yellow, magenta, orange, pink)

autolog

Activer ou désactiver la journalisation automatique. true ou false

show_typing_other

Afficher lorsque d'autres personnes tapent dans une discussion 1-à-1. true ou false

show_typing_self

Afficher aux autres lorsque vous tapez dans une discussion 1-à-1. true ou false

show_welcome_msg

Afficher le message de bienvenue au démarrage. true ou false

show_connection_msg

Activer les notifications de changement de connexion des amis. true ou false

show_group_connection_msg

Activer les notifications de changement de connexion des groupes. true ou false

nodelist_update_freq

Fréquence de mise à jour de la liste des nœuds DHT en jours. (entier ; 0 pour désactiver)

autosave_freq

Fréquence de sauvegarde automatique du fichier de données Tox en secondes. (entier ; 0 pour désactiver)

history_size

Nombre maximum de lignes pour l'historique de la fenêtre de discussion. Valeur entière. (par exemple : 700)

notification_timeout

Temps en millisecondes pour afficher une notification. Valeur entière. (par exemple : 3000)

line_join

Indicateur lorsque quelqu'un se connecte ou rejoint un groupe. Maximum trois caractères pour les paramètres line_.

line_quit

Indicateur lorsque quelqu'un se déconnecte ou quitte un groupe.

line_alert

Indicateur pour les messages d'alerte.

line_normal

Indicateur pour les messages normaux.

line_padding

Remplit chaque ligne enveloppée d'un message avec suffisamment d'espaces pour l'aligner au début de la première ligne. true ou false

mplex_away

Définit le statut de l'utilisateur lors de la connexion et de la déconnexion de GNU screen ou tmux. true ou false

mplex_away_note

Message de statut à définir lorsque le statut est défini sur absent en raison d'une déconnexion de screen/tmux. Lors de la connexion, le message de statut est rétabli à sa valeur d'origine.

group_part_message

Message de départ qui sera envoyé à tous les pairs du groupe lorsque vous quittez le groupe. 
Les options suivantes contrôlent si un signal sonore du terminal est émis lors de certains événements.
Certains terminaux marquent la fenêtre comme urgente lorsqu'un signal sonore est reçu. Les fenêtres urgentes sont généralement mises en surbrillance dans la barre des tâches et certains gestionnaires de fenêtres fournissent même des raccourcis pour passer à la fenêtre urgente suivante.
Ces options n'affectent pas l'option "alerts".

bell_on_message

Activer/Désactiver le signal sonore du terminal lors de la réception d'un message. true ou false

bell_on_filetrans

Activer/Désactiver le signal sonore du terminal lors de la réception d'un transfert de fichier. true ou false

bell_on_filetrans_accept

Activer/Désactiver le signal sonore du terminal lorsqu'un transfert de fichier a été accepté. true ou false

bell_on_invite

Activer/Désactiver le signal sonore du terminal lors de la réception d'une invitation de groupe/appel. true ou false

audio

Configuration liée aux périphériques audio.

input_device

Périphérique d'entrée audio. Valeur entière. Le numéro correspond à /lsdev dans

output_device

Périphérique de sortie audio. Valeur entière. Le numéro correspond à /lsdev dans

VAD_threshold

Seuil de détection d'activité vocale. Valeur flottante. Les valeurs recommandées sont 1.0-40.0

conference_audio_channels

Nombre de canaux pour la diffusion audio de conférence. Valeur entière. 1 (mono) ou 2 (stéréo)

chat_audio_channels

Nombre de canaux pour la diffusion audio 1-à-1. Valeur entière. 1 (mono) ou 2 (stéréo)

push_to_talk

Activer/Désactiver Push-To-Talk pour les chats audio de conférence (la touche active est F2). true ou false

tox

Configuration liée aux chemins.

download_path

Chemin par défaut pour les téléchargements. Valeur chaîne. Chemin absolu pour les fichiers téléchargés.

avatar_path

Chemin de votre avatar (le fichier doit être un .png et ne peut pas dépasser 16.3 Kio)

autorun_path

Chemin pour tous les scripts qui doivent être exécutés au démarrage

chatlogs_path

Chemin par défaut pour les journaux de discussion. Valeur chaîne. Chemin absolu pour les fichiers de journaux de discussion.

password_eval

Remplace l'invite de mot de passe en exécutant cette commande et en utilisant sa sortie comme mot de passe.

friends

Paramètres spécifiques aux amis (prioritaires sur les paramètres globaux)

alias

Définir un alias pour cet ami. Valeur chaîne.

auto_accept_files

Activer ou désactiver l'acceptation automatique des transferts de fichiers entrants. true ou false

autolog

Activer ou désactiver la journalisation automatique. true ou false

show_connection_msg

Activer les notifications de changement de connexion. true ou false

tab_name_colour

La couleur du nom de l'onglet de l'ami. (black, white, gray, brown, red, green, blue, cyan, yellow, magenta, orange, pink)

groupchats

Paramètres spécifiques aux groupes (prioritaires sur les paramètres globaux)

autolog

Activer ou désactiver la journalisation automatique. true ou false

tab_name_colour

La couleur du nom de l'onglet du groupe. (black, white, gray, brown, red, green, blue, cyan, yellow, magenta, orange, pink)

OPTIONS

conferences

Paramètres spécifiques à la conférence (prioritaires sur les paramètres globaux)

autolog

Activer ou désactiver la journalisation automatique. true ou false

tab_name_colour

La couleur du nom de la fenêtre d'onglet des conférences. (black, white, gray, brown, red, green, blue, cyan, yellow, magenta, orange, pink)

blocked_words

Une liste de mots insensibles à la casse qui ne peuvent pas être envoyés dans les messages. Valeur de type chaîne de caractères. Doit être entre guillemets doubles et ne pas dépasser 256 caractères.

sounds

Configuration relative aux sons de notification. La valeur spéciale "silent" peut être utilisée pour désactiver une notification spécifique.

Chaque valeur est une chaîne de caractères correspondant au chemin d'accès absolu d'un fichier son wav.

notif_error

Son à jouer lorsqu'une erreur se produit.

self_log_in

Son à jouer lors de votre connexion.

self_log_out

Son à jouer lors de votre déconnexion.

user_log_in

Son à jouer lorsqu'un contact devient en ligne.

user_log_out

Son à jouer lorsqu'un contact devient hors ligne.

call_incoming

Son à jouer lorsque vous recevez un appel entrant.

call_outgoing

Son à jouer lorsque vous initiez un appel.

generic_message

Son à jouer lorsqu'un événement se produit.

transfer_pending

Son à jouer lorsque vous recevez une demande de transfert de fichier.

transfer_completed

Son à jouer lorsqu'un transfert de fichier est terminé.

keys

Configuration relative à l'interaction avec l'interface utilisateur. Actuellement supportés : touches modifiées par Ctrl, Tab, PAGEUP et PAGEDOWN.

Chaque valeur est une chaîne de caractères correspondant à une combinaison de touches.

next_tab

Combinaison de touches pour passer à l'onglet suivant.

prev_tab

Combinaison de touches pour passer à l'onglet précédent.

scroll_line_up

Combinaison de touches pour faire défiler une ligne vers le haut.

scroll_line_down

Combinaison de touches pour faire défiler une ligne vers le bas.

half_page_up

Combinaison de touches pour faire défiler une demi-page vers le haut.

half_page_down

Combinaison de touches pour faire défiler une demi-page vers le bas.

page_bottom

Combinaison de touches pour faire défiler jusqu'en bas de la page.

toggle_peerlist

Afficher ou masquer la liste des pairs.

toggle_paste_mode

Basculer entre le traitement des sauts de ligne comme une pression de la touche Entrée.

reload_config

Recharger le fichier de configuration de Toxic.

BUGS

-Les couleurs non par défaut (gray, brown, orange, et pink) ne fonctionneront pas sur les émulateurs de terminaux qui ne prennent pas en charge les 256 couleurs. Konsole, qterminal et potentiellement d'autres sont également connus pour avoir des problèmes avec elles. Si vous utilisez screen ou tmux, essayez de le configurer pour utiliser la variable d'environnement TERM xterm-256color.

-Lors du rechargement du fichier de configuration pendant une session active, certains changements de l'interface utilisateur peuvent être bogués et nécessiter un redémarrage complet du client.
