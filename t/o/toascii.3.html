toascii(3) Manuel des fonctions de bibliothèque toascii(3)

NOM

toascii — convertir un caractère en ASCII

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <ctype.h>
[[deprecated]] int toascii(int c);
Exigences de macro de test de fonctionnalité pour glibc (voir feature_test_macros(7)) :

toascii() :

    _XOPEN_SOURCE
        || /* glibc >= 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPTION

toascii() convertit c en une valeur unsigned char de 7 bits qui s'inscrit dans le jeu de caractères ASCII, en effaçant les bits de poids fort.

VALEUR DE RETOUR

La valeur renvoyée est celle du caractère converti.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
toascii () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

SVr4, BSD, POSIX.1-2001. Obsolète dans POSIX.1-2008, notant qu'il ne peut pas être utilisé de manière portable dans une application localisée.

BOGUES

Beaucoup de gens seront mécontents si vous utilisez cette fonction. Cette fonction convertira les lettres accentuées en caractères aléatoires.

VOIR AUSSI

isascii(3), tolower(3), toupper(3)
