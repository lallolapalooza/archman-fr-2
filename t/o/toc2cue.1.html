NOM

toc2cue - convertit un fichier TOC de cdrdao(1) en fichier .cue

SYNTAXE

toc2cue [-v niveau_verbeux] fichier_toc_entree fichier_cue_sortie

toc2cue [-V]

DESCRIPTION

toc2cue convertit un fichier TOC de cdrdao(1) en fichier .cue.

Veuillez noter que le fichier cue résultant n'est valide que si le fichier toc a été créé avec cdrdao(1) en utilisant les commandes 'read-toc' ou 'read-cd'. Pour les fichiers toc créés ou modifiés manuellement, le fichier cue peut ne pas être correct. Ce programme vérifie uniquement les caractéristiques les plus évidentes du fichier toc qui ne peuvent pas être converties en fichier cue. De plus, si le fichier toc contient des pistes audio, l'ordre des octets du fichier image sera incorrect. Cela entraînera du bruit statique lorsque le fichier cue sera utilisé pour l'enregistrement (même avec cdrdao(1) lui-même).

OPTIONS

-v niveau_verbeux
Définit le niveau de verbosité, qui peut être un entier compris entre 1 et 3. Par défaut, seuls les erreurs fatales sont affichées. Un niveau de verbosité de 1 affiche les avertissements, 2 les avertissements et les erreurs, 3 les avertissements, les erreurs et les erreurs internes.
-V
Affiche la version de toc2cue.
