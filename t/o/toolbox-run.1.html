NOM

toolbox-run - Exécute une commande dans un conteneur Toolbx existant

SYNTAXE

toolbox run [--container NOM | -c NOM]
[--distro DISTRIBUTION | -d DISTRIBUTION]
[--preserve-fds N]
[--release RELEASE | -r RELEASE]
[COMMANDE]

DESCRIPTION

Exécute une commande à l'intérieur d'un conteneur Toolbx existant. Le conteneur devrait avoir été créé à l'aide de la commande toolbox create.

Sur Fedora, le conteneur par défaut est nommé fedora-toolbox-N, où N est la version de l'hôte. Un conteneur spécifique peut être sélectionné à l'aide de l'option --container.

Un conteneur Toolbx est un conteneur OCI. Par conséquent, toolbox run est analogue à une commande podman start suivie d'une commande podman exec.

OPTIONS

Les options suivantes sont comprises :

--container NOM, -c NOM

Exécute la commande à l'intérieur d'un conteneur Toolbx avec le NOM donné. Ceci est utile lorsqu'il existe plusieurs conteneurs Toolbx créés à partir de la même image, ou des conteneurs entièrement personnalisés créés à partir d'images construites sur mesure.

--distro DISTRIBUTION, -d DISTRIBUTION

Exécute la commande à l'intérieur d'un conteneur Toolbx pour un système d'exploitation DISTRIBUTION différent de celui de l'hôte. Doit être couplé avec --release, sauf si la DISTRIBUTION sélectionnée correspond au système hôte.

--preserve-fds N

Transmet à la commande N descripteurs de fichiers supplémentaires (en plus de 0, 1, 2). Le nombre total de descripteurs de fichiers sera de 3+N.

--release RELEASE, -r RELEASE

Exécute la commande à l'intérieur d'un conteneur Toolbx pour une version RELEASE de système d'exploitation différente de celle de l'hôte.

CODE DE SORTIE

Le code de sortie donne des informations sur la raison pour laquelle la commande à l'intérieur du conteneur n'a pas pu être exécutée ou pourquoi elle s'est terminée.

1 Erreur interne dans Toolbx

125 Erreur interne dans Podman

126 La commande d'exécution n'a pas pu être invoquée

$ toolbox run /etc; echo $?
/bin/sh: ligne 1: /etc: Est un répertoire
/bin/sh: ligne 1: exec: /etc: impossible d'exécuter: Est un répertoire
Error: failed to invoke command /etc in container fedora-toolbox-36
126

127 La commande d'exécution est introuvable ou le répertoire de travail n'existe pas

$ toolbox run foo; echo $?
/bin/sh: ligne 1: exec: foo: introuvable
Error: command foo not found in container fedora-toolbox-36
127

Code de sortie Le code de sortie de la commande d'exécution

$ toolbox run false; echo $?
1

EXEMPLES

Exécuter ls dans le conteneur Toolbx par défaut correspondant au système d'exploitation hôte

$ toolbox run ls -la

Exécuter emacs dans le conteneur Toolbx par défaut pour Fedora 36

$ toolbox run --distro fedora --release f36 emacs

Exécuter uptime dans un conteneur Toolbx avec un nom personnalisé

$ toolbox run --container foo uptime
