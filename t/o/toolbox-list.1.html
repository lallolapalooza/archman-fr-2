NOM

toolbox-list - Lister les conteneurs et images Toolbx existants

SYNTAXE

toolbox list [--containers | -c] [--images | -i]

DESCRIPTION

Liste les conteneurs et images Toolbx existants. Ce sont des conteneurs et images OCI, qui peuvent être gérés directement avec un outil comme podman.

OPTIONS

Les options suivantes sont comprises :

--containers, -c

Lister uniquement les conteneurs Toolbx, pas les images.

--images, -i

Lister uniquement les images Toolbx, pas les conteneurs.

EXEMPLES

Lister tous les conteneurs et images Toolbx existants

$ toolbox list

Lister uniquement les conteneurs Toolbx existants

$ toolbox list --containers

Lister uniquement les images Toolbx existantes

$ toolbox list --images

VOIR AUSSI

toolbox(1), podman(1), podman-ps(1), podman-images(1)
