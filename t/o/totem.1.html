NOM

Vidéos GNOME - Lecteur de films

SYNTAXE

totem [option...] [noms_de_fichiers|URI]

DESCRIPTION

Vidéos est un lecteur de films pour le bureau GNOME. Grâce à l'utilisation du backend GStreamer, de nombreux formats de fichiers et de flux populaires sont pris en charge, notamment : H.264 (AVC) et H.265 (HEVC) MPEG-4, WebM et AV1, MPEG-2 et MPEG-1, ainsi que les anciens types de vidéos : Ogg, AVI, ASF, MOV, WMV, QuickTime, et plus encore. La lecture de DVD est également possible.

Pour une documentation supplémentaire sur l'utilisation interactive de Vidéos, sélectionnez l'option de menu Aide. Les menus permettent d'accéder à certaines fonctionnalités non disponibles via les raccourcis clavier ou les options de ligne de commande.

OPTIONS

-?, --help
Affiche un message d'aide plus long puis quitte. (Toute divergence entre cette page de manuel et la sortie de totem --help doit être signalée comme un bug de documentation.)
--version
Affiche les informations de version puis quitte.

Les options suivantes demandent à une instance déjà en cours d'exécution de Vidéos d'effectuer une action ; elles sont utiles pour les scripts de contrôle à distance. Si Vidéos n'est pas déjà en cours d'exécution, ces commandes lanceront une nouvelle instance de Vidéos mais n'effectueront rien de plus.

--play-pause
Demande à une instance déjà en cours d'exécution de Vidéos de basculer entre lecture et pause.
--play
Demande à une instance déjà en cours d'exécution de Vidéos de lire (n'a aucun effet si déjà en lecture).
--pause
Demande à une instance déjà en cours d'exécution de Vidéos de mettre en pause (n'a aucun effet si déjà en pause).
--next
Demande à une instance déjà en cours d'exécution de Vidéos de passer au film ou chapitre suivant dans la liste de lecture.
--previous
Demande à une instance déjà en cours d'exécution de Vidéos de revenir au film ou chapitre précédent dans la liste de lecture.
--seek-fwd
Demande à une instance déjà en cours d'exécution de Vidéos de faire une avance rapide de 15 secondes dans le film actuel.
--seek-bwd
Demande à une instance déjà en cours d'exécution de Vidéos de revenir en arrière de 15 secondes dans le film actuel.
--volume-up
Demande à une instance déjà en cours d'exécution de Vidéos d'augmenter le volume de 8%.
--volume-down
Demande à une instance déjà en cours d'exécution de Vidéos de diminuer le volume de 8%.
--mute
Demande à une instance déjà en cours d'exécution de Vidéos de basculer entre le son activé et le son désactivé.
--fullscreen
Demande à une instance déjà en cours d'exécution de Vidéos de basculer en mode plein écran.
--quit
Demande à une instance déjà en cours d'exécution de Vidéos de se quitter.
--enqueue nom_de_fichier|URI
Demande à une instance déjà en cours d'exécution de Vidéos d'ajouter un nouveau flux à la liste de lecture.
--replace nom_de_fichier|URI
Demande à une instance déjà en cours d'exécution de Vidéos de lire depuis la liste de lecture.

RACCOURCIS CLAVIER

Les informations sur les raccourcis clavier sont disponibles une fois l'application démarrée en tapant Ctrl+Point d'interrogation, ce qui peut nécessiter d'appuyer sur Shift dans certaines configurations de clavier.

FICHIERS

/usr/lib/totem/plugins/

Le répertoire global des plugins, qui contient tous les plugins installés par le système.
~/.local/share/totem/plugins/
Le répertoire utilisateur des plugins, contenant les plugins disponibles uniquement pour cet utilisateur. Il se trouve toujours dans le sous-répertoire « totem/plugins » de votre répertoire XDG_DATA_HOME.
~/.config/totem/state.ini
Le fichier de configuration de l'apparence de la fenêtre principale, stocké dans un format INI simple.

BOGUES

Vidéos ne peut pas lire les fichiers utilisant certains codecs propriétaires.

AUTEUR
