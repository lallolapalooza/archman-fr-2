NOM

topology.yaml - Fichier de configuration Slurm pour les plugins de topologie

DESCRIPTION

topology.yaml est un fichier de configuration au format YAML qui définit plusieurs topologies réseau pour optimiser l'allocation des ressources des tâches dans Slurm. Le fichier doit être situé dans le même répertoire que slurm.conf. Tout texte suivant un "#" dans ce fichier est traité comme un commentaire jusqu'à la fin de cette ligne.

Des détails supplémentaires sont disponibles dans topology.conf(5) et dans le Guide de topologie : https://slurm.schedmd.com/topology.html

NOTE : Slurm recherche d'abord topology.yaml. Si ce fichier existe, topology.conf sera ignoré.

PARAMÈTRES

Chaque topologie contient les attributs suivants :

topologie
Nom unique de la topologie, utilisé pour l'identifier dans les configurations de partition. Doit être le premier attribut.
defaut_cluster
La première topologie définie avec defaut_cluster: true sera utilisée pour les partitions sans topologie explicitement spécifiée et pour les opérations à l'échelle du cluster non liées à une partition (par exemple, communication slurmctld-vers-slurmd). Par défaut à false.

Chaque topologie doit également définir exactement un des types de topologie suivants :

bloc
Cette topologie utilisera le plugin topology/block. Doit contenir des champs supplémentaires, voir ci-dessous.
plat
Si défini sur true, cette topologie utilisera le plugin topology/flat, qui est le plugin par défaut si aucun TopologyPlugin ou topology.yaml n'est spécifié.
arbre
Cette topologie utilisera le plugin topology/tree. Doit contenir des champs supplémentaires, voir ci-dessous.

Définitions de blocs

Chaque topologie de bloc contient les attributs suivants :

tailles_blocs
Liste de la taille de base des blocs de planification, ainsi que des tailles de blocs de niveau supérieur qui seraient appliquées. Les TaillesBlocs successives doivent être une puissance de deux supérieure aux valeurs précédentes.
blocs
Liste des blocs disponibles dans cette topologie. Chaque bloc contient les attributs suivants :
bloc
Le nom d'un bloc. Ce nom est interne à Slurm et arbitraire. Chaque bloc doit avoir un nom unique. Ce champ doit être spécifié.
noeuds
Nœuds enfants du bloc nommé.

Définitions d'arbre

Chaque topologie d'arbre contient l'attribut suivant :

commutateurs
Liste des commutateurs disponibles dans cette topologie. Chaque commutateur contient les attributs suivants :
commutateur
Le nom d'un commutateur. Ce nom est interne à Slurm et arbitraire. Chaque commutateur doit avoir un nom unique. Ce champ doit être spécifié et ne peut pas dépasser 64 caractères.
enfants
Commutateurs enfants du commutateur nommé.
noeuds
Nœuds enfants du commutateur feuille nommé.

EXEMPLE

---
- topologie: topo1
  defaut_cluster: true
  arbre:
    commutateurs:
      - commutateur: sw_root
        enfants: s[1-2]
      - commutateur: s1
        noeuds: node[01-02]
      - commutateur: s2
        noeuds: node[03-04]
- topologie: topo2
  defaut_cluster: false
  bloc:
    tailles_blocs:
      - 4
      - 16
    blocs:
      - bloc: b1
        noeuds: node[01-04]
      - bloc: b2
        noeuds: node[05-08]
      - bloc: b3
        noeuds: node[09-12]
      - bloc: b4
        noeuds: node[13-16]
- topologie: topo3
  defaut_cluster: false
  plat: true
