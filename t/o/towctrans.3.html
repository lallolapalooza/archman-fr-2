towctrans(3) Manuel des fonctions de bibliothèque towctrans(3)

NOM

towctrans - translittération de caractères larges

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <wctype.h>
wint_t towctrans(wint_t wc, wctrans_t desc);

DESCRIPTION

Si wc est un caractère large, alors la fonction towctrans() le traduit selon le descripteur de translittération desc. Si wc est WEOF, WEOF est renvoyé.

desc doit être un descripteur de translittération renvoyé par la fonction wctrans(3).

VALEUR DE RETOUR

La fonction towctrans() renvoie le caractère large traduit, ou WEOF si wc est WEOF.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
towctrans () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, C99.

NOTES

Le comportement de towctrans() dépend de la catégorie LC_CTYPE de la locale courante.

VOIR AUSSI

towlower(3), towupper(3), wctrans(3)
