NOM

tor-print-ed-signing-cert - afficher la date d'expiration du certificat de signature ed25519

SYNTAXE

tor-print-ed-signing-cert <chemin du fichier ed25519_signing_cert>

DESCRIPTION

tor-print-ed-signing-cert est un programme utilitaire pour les opérateurs de relais Tor afin de vérifier la date d'expiration du certificat de signature ed25519.

La date d'expiration est affichée dans trois formats :

•Horodatage lisible par l'homme, localisé dans le fuseau horaire actuel.
•Horodatage RFC 1123 (dans le fuseau horaire GMT).
•Valeur temporelle Unix.
