toe(1M) Commandes utilisateur toe(1M)

NOM

toe - lister les entrées de table des types de terminaux terminfo

SYNTAXE

toe [-ahs] [-v n] [répertoire ...]

toe [-u|-U] fichier

toe -V

DESCRIPTION

toe rapporte sur le flux de sortie standard les noms (principaux) et descriptions des types de terminaux disponibles pour la bibliothèque terminfo. Chaque répertoire est analysé ; si aucun n'est donné, toe analyse le répertoire terminfo par défaut.

OPTIONS

L'option -h peut être utile pour observer où toe recherche les descriptions de terminaux. D'autres options supportent les mainteneurs des descriptions de terminaux terminfo.

-a
liste les entrées de tous les répertoires de base de données de terminaux que terminfo rechercherait, au lieu de seulement le premier qu'il trouve.
Si -s est également donné, toe rapporte en plus, comme conflict(1), quelles entrées correspondent à une base de données de terminaux donnée. Un “*” marque les entrées qui diffèrent, et “+” marque les entrées équivalentes.
Sans l'option -s, toe n'essaie pas de fusionner les doublons dans son rapport.
-h
écrit un en-tête nommant chaque répertoire au fur et à mesure de son accès.
-s
trie la sortie par les noms des entrées.
-u fichier
liste les dépendances de types de terminaux dans fichier, un fichier source d'entrée terminfo ou une base de données termcap. Le rapport résume les relations “use” (terminfo) et tc (termcap) : chaque ligne comprend le nom principal d'un type de terminal utilisant des capacités use/tc, deux-points, une liste séparée par des espaces et des tabulations des noms principaux des types de terminaux ainsi nommés, et une nouvelle ligne.
-U fichier
liste les dépendances inverses de types de terminaux dans fichier, un fichier source d'entrée terminfo ou une base de données termcap. Le rapport résume les relations inverses “use” (terminfo) et tc (termcap) : chaque ligne comprend le nom principal d'un type de terminal apparaissant dans les capacités use/tc, deux-points, une liste séparée par des espaces et des tabulations des noms principaux des types de terminaux les nommant ainsi, et une nouvelle ligne.
-v [n]
rapporte des informations de statut verbeuses sur le flux d'erreur standard, montrant la progression de toe.
Le paramètre optionnel n est un entier compris entre 1 et 10 inclus, interprété comme pour tic(1M). Si ncurses est compilé sans prise en charge du traçage, n est ignoré.
-V
rapporte la version de ncurses associée à ce programme et se termine avec un statut de succès.

FICHIERS

/usr/share/terminfo
base de données de descriptions de terminaux compilée

PORTABILITE

toe n'est pas fourni par d'autres implémentations. Il n'existe aucune norme X/Open ou POSIX applicable pour celui-ci.

HISTORIQUE

toe remplace une option -T qui était brièvement supportée par l'utilitaire ncurses infocmp en 1995.

Les options -a et -s ont été ajoutées respectivement en 2006 et 2011.

Le nom du programme provient d'un jeu de mots d'un développeur :

  • tic,
  • tac (maintenant tack),
  • toe.

EXEMPLES

Lorsqu'on n'utilise pas l'option de tri -s, l'option -a rapporte tous les noms trouvés dans tous les répertoires de base de données de terminaux nommés dans les variables d'environnement TERMINFO et TERMINFO_DIRS.

xterm-color xterm couleur générique
xterm-xfree86 émulateur de terminal xterm (XFree86)
xterm-vt220 xterm émulant vt220
xterm-256color xterm avec 256 couleurs
xterm-r6 version xterm X11R6
xterm-r5 version xterm R5
xterm-mono xterm monochrome
xterm émulateur de terminal xterm (X Window System)
vt220 dec vt220
vt102 dec vt102
vt100 dec vt100 (avec vidéo avancée)
vt52 dec vt52
...

Utilisez les options -a et -s ensemble pour montrer où chaque description de terminal a été trouvée.

--> /etc/terminfo
----> /lib/terminfo
------> /usr/share/terminfo
--*---: vt100 dec vt100 (avec vidéo avancée)
--*---: vt102 dec vt102
--*---: vt220 dec vt220
--*---: vt52 dec vt52
--*---: xterm xterm terminal emulator (X Window System)
--*---: xterm-256color xterm avec 256 couleurs
--*---: xterm-color xterm couleur générique
--*---: xterm-mono xterm monochrome
--*---: xterm-r5 version xterm R5
--*---: xterm-r6 version xterm X11R6
--*---: xterm-vt220 xterm émulant vt220
--*---: xterm-xfree86 émulateur de terminal xterm (XFree86)
...

toe(1m)

Nom

toe - Affiche les fichiers ASCII de manière formatée.

Synopsis

toe [-r] [-h] [-a] [-l] [-f fichier] [-V]

Description

toe est un programme qui affiche le contenu des fichiers ASCII dans un format plus lisible que la commande cat standard. Il prend en charge le surlignage de la syntaxe pour certains langages de programmation, l'affichage des caractères non imprimables et le formatage du texte.

Options

-r
Affiche les fichiers dans l'ordre inverse.
-h
Affiche l'aide et quitte.
-a
Affiche tous les caractères, y compris les caractères non imprimables.
-l
Affiche les numéros de ligne avant chaque ligne.
-f fichier
Spécifie un fichier de configuration pour le surlignage de la syntaxe.
-V
Affiche les informations de version et quitte.

Exemples

Pour afficher un fichier nommé mon_fichier.txt avec les numéros de ligne :

toe -l mon_fichier.txt

Pour afficher un fichier code.py avec le surlignage de la syntaxe Python (si un fichier de configuration approprié est spécifié) :

toe -f python.conf code.py

Voir aussi

cat(1), less(1), more(1)
