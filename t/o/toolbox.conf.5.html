toolbox.conf(5) Manuel des formats de fichiers toolbox.conf(5)

NOM

toolbox.conf - Fichier de configuration de Toolbx

DESCRIPTION

Remplace de manière persistante le comportement par défaut de toolbox(1). La syntaxe est TOML et les noms des options correspondent à leurs équivalents en ligne de commande. Actuellement, la seule section prise en charge est general.

OPTIONS

distro = "DISTRO"

Crée un conteneur Toolbx pour un système d'exploitation DISTRO différent de celui de l'hôte. Ne peut pas être utilisé avec image.

image = "NOM"

Change le NOM de l'image utilisée pour créer le conteneur Toolbx. Ceci est utile pour créer des conteneurs à partir d'images construites sur mesure. Ne peut pas être utilisé avec distro et release.

Si NOM ne contient pas de registre, le stockage d'images local sera consulté, et s'il n'y est pas présent, il sera extrait d'un registre distant approprié.

release = "RELEASE"

Crée un conteneur Toolbx pour un système d'exploitation RELEASE différent de celui de l'hôte. Ne peut pas être utilisé avec image.

FICHIERS

Les emplacements suivants sont recherchés dans un ordre croissant de priorité :

/etc/containers/toolbox.conf

Ceci est destiné à être fourni par le distributeur du système d'exploitation ou l'administrateur système, et affecte tous les utilisateurs sur l'hôte.

Les champs spécifiés ici peuvent être remplacés par l'un des fichiers ci-dessous.

$XDG_CONFIG_HOME/containers/toolbox.conf

Ceci est destiné aux modifications spécifiques à l'utilisateur. Les champs spécifiés ici remplacent tous les fichiers ci-dessus.

EXEMPLES

Remplacer la distribution d'exploitation par défaut :

[general]
distro = "fedora"
release = "36"

Remplacer l'image par défaut :

[general]
image = "registry.fedoraproject.org/fedora-toolbox:36"
