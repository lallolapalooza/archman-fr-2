NOM

toolbox-enter - Entrer dans un conteneur Toolbx pour une utilisation interactive

SYNTAXE

toolbox enter [--distro DISTRO | -d DISTRO]
[--release RELEASE | -r RELEASE]
[CONTENEUR]

DESCRIPTION

Lance un shell interactif dans un conteneur Toolbx créé à l'aide de la commande toolbox create. Il essaie de lancer le shell par défaut de l'utilisateur, mais s'il n'est pas disponible dans le conteneur, il se rabat sur /bin/bash.

Lorsqu'il est invoqué sans aucune option, toolbox enter essaie d'entrer dans le conteneur Toolbx par défaut de l'hôte, ou s'il n'y a qu'un seul conteneur disponible, il l'utilise. Sur Fedora, le conteneur par défaut est connu sous le nom de fedora-toolbox-N, où N est la version de l'hôte. S'il n'y a aucun conteneur, toolbox enter proposera de créer celui par défaut pour vous.

Un conteneur spécifique peut être sélectionné à l'aide de l'argument CONTENEUR.

Un conteneur Toolbx est un conteneur OCI. Par conséquent, toolbox enter est analogue à un podman start suivi d'un podman exec.

OPTIONS

Les options suivantes sont comprises :

--distro DISTRO, -d DISTRO

Entrer dans un conteneur Toolbx pour un système d'exploitation DISTRO différent de celui de l'hôte. Doit être couplé avec --release sauf si le DISTRO sélectionné correspond à l'hôte.

--release RELEASE, -r RELEASE

Entrer dans un conteneur Toolbx pour une version RELEASE de système d'exploitation différente de celle de l'hôte.

EXEMPLES

Entrer dans le conteneur Toolbx par défaut correspondant à l'OS de l'hôte

$ toolbox enter

Entrer dans le conteneur Toolbx par défaut pour Fedora 36

$ toolbox enter --distro fedora --release f36

Entrer dans un conteneur Toolbx avec un nom personnalisé

$ toolbox enter foo
