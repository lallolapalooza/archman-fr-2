topology.conf(5) Fichier de configuration Slurm topology.conf(5)

NOM

topology.conf - Fichier de configuration Slurm pour les plugins de topologie

DESCRIPTION

topology.conf est un fichier ASCII qui décrit la topologie réseau du cluster pour une allocation optimisée des ressources des tâches. Le fichier sera toujours situé dans le même répertoire que slurm.conf. NOTE : Ce fichier est ignoré si topology.yaml(5) existe.

Les noms de paramètres ne sont pas sensibles à la casse. Tout texte suivant un "#" dans le fichier de configuration est traité comme un commentaire jusqu'à la fin de la ligne. Les modifications apportées au fichier de configuration prennent effet au redémarrage des démons Slurm, à la réception du signal SIGHUP par un démon, ou à l'exécution de la commande "scontrol reconfigure" sauf indication contraire.

Consultez le guide de topologie pour plus de détails : https://slurm.schedmd.com/topology.html

topology/tree

Ce plugin nécessite que vous utilisiez le plugin select/cons_tres. La configuration de la topologie réseau, chaque ligne définissant un nom de switch et ses enfants, soit des noms de nœuds soit des noms de switches. L'analyseur d'expressions de listes d'hôtes de Slurm est utilisé, donc les noms de nœuds et de switches n'ont pas besoin d'être consécutifs (par exemple, "Nodes=tux[0-3,12,18-20]" et "Switches=s[0-2,4-8,12]" seront analysés correctement). Une vitesse de lien optionnelle peut également être spécifiée.

Tous les nœuds du réseau doivent être connectés à au moins un switch. Le réseau doit être entièrement connecté pour utiliser TopologyParam=RouteTree. Les tâches ne peuvent s'étendre que sur les nœuds connectés par la même infrastructure de switch, même s'il existe des nœuds inactifs disponibles dans d'autres zones du cluster.

Le fichier topology.conf pour un switch Infiniband peut être généré automatiquement à l'aide de l'outil slurmibtopology que vous trouverez ici : https://github.com/OleHolmNielsen/Slurm_tools/tree/master/slurmibtopology.

Les paramètres de configuration globaux disponibles pour topology/tree incluent :

SwitchName
Le nom d'un switch. Ce nom est interne à Slurm et arbitraire. Chaque switch doit avoir un nom unique. Ce champ doit être spécifié et ne peut pas dépasser 64 caractères.
Switches
Switches enfants du switch nommé.
Nodes
Nœuds enfants du switch feuille nommé.
LinkSpeed
Une valeur optionnelle spécifiant la performance de ce lien de communication. Les unités utilisées sont arbitraires et ces informations ne sont actuellement pas utilisées. Elles pourront être utilisées à l'avenir pour optimiser les allocations de ressources.

topology/block

La configuration de la topologie réseau, chaque ligne définissant un nom de bloc et ses noms de nœuds enfants. L'analyseur d'expressions de listes d'hôtes de Slurm est utilisé, donc les noms de nœuds n'ont pas besoin d'être consécutifs (par exemple, "Nodes=tux[0-3,12,18-20]").

Ce plugin de topologie met l'accent sur la réduction de la fragmentation du cluster, permettant aux tâches de profiter de connexions à latence plus faible entre de plus petits "blocs" de nœuds, plutôt que de lancer les tâches aussi rapidement que possible sur les premières ressources disponibles.

Les blocs de nœuds définis sont associés à d'autres blocs contigus, pour créer un bloc de nœuds de niveau supérieur. Ces blocs plus grands peuvent ensuite être associés à d'autres blocs du même niveau pour des blocs de nœuds contigus de plus en plus grands avec une communication optimisée entre eux. Les tailles de blocs imposées sont définies par BlockSizes.

Les paramètres de configuration globaux disponibles pour topology/block incluent :

BlockName
Le nom d'un bloc. Ce nom est interne à Slurm et arbitraire. Chaque bloc doit avoir un nom unique. Ce champ doit être spécifié.
Nodes
Nœuds enfants du bloc nommé.
BlockSizes
Liste de la taille de bloc de planification de base, ainsi que toute taille de bloc de niveau supérieur qui serait imposée. Chaque bloc doit avoir au moins le nombre de nœuds de la taille de bloc de planification de base. Les BlockSizes successifs doivent être une puissance de deux supérieure aux valeurs précédentes.

EXEMPLE

##################################################################
# Fichier de configuration du réseau de Slurm à utiliser avec le
# plugin topology/tree
##################################################################
SwitchName=s0 Nodes=dev[0-5]
SwitchName=s1 Nodes=dev[6-11]
SwitchName=s2 Nodes=dev[12-17]
SwitchName=s3 Switches=s[0-2]
##################################################################
# Fichier de configuration du réseau de Slurm à utiliser avec le
# plugin topology/block
##################################################################
BlockName=block1 Nodes=node[1-32]
BlockName=block2 Nodes=node[33-64]
BlockName=block3 Nodes=node[65-96]
BlockName=block4 Nodes=node[97-128]
BlockSizes=30,120
