toupper(3) Manuel des fonctions de bibliothèque toupper(3)

NOM

toupper, tolower, toupper_l, tolower_l - convertir en majuscules ou en minuscules

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <ctype.h>
int toupper(int c);
int tolower(int c);
int toupper_l(int c, locale_t locale);
int tolower_l(int c, locale_t locale);
Exigences de macro de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

toupper_l(), tolower_l():

    Depuis glibc 2.10:
        _XOPEN_SOURCE >= 700
    Avant glibc 2.10:
        _GNU_SOURCE

DESCRIPTION

Ces fonctions convertissent les lettres minuscules en majuscules et vice versa.

Si c est une lettre minuscule, toupper() renvoie son équivalent majuscule, s'il existe une représentation majuscule dans la locale actuelle. Sinon, elle renvoie c. La fonction toupper_l() effectue la même tâche, mais utilise la locale référencée par le descripteur de locale locale.

Si c est une lettre majuscule, tolower() renvoie son équivalent minuscule, s'il existe une représentation minuscule dans la locale actuelle. Sinon, elle renvoie c. La fonction tolower_l() effectue la même tâche, mais utilise la locale référencée par le descripteur de locale locale.

Si c n'est ni une valeur unsigned char ni EOF, le comportement de ces fonctions est indéfini.

Le comportement de toupper_l() et tolower_l() est indéfini si locale est l'objet de locale spécial LC_GLOBAL_LOCALE (voir duplocale(3)) ou n'est pas un descripteur d'objet de locale valide.

VALEUR DE RETOUR

La valeur renvoyée est celle de la lettre convertie, ou c si la conversion n'a pas été possible.

NOTES

Les normes exigent que l'argument c pour ces fonctions soit soit EOF, soit une valeur qui est représentable dans le type unsigned char. Si l'argument c est de type char, il doit être transtypé en unsigned char, comme dans l'exemple suivant:


char c;
...
res = toupper((unsigned char) c);

Ceci est nécessaire car char peut être le type équivalent signed char, auquel cas un octet dont le bit supérieur est défini sera étendu en signe lors de la conversion en int, produisant une valeur en dehors de la plage de unsigned char.

Les détails de ce qui constitue une lettre majuscule ou minuscule dépendent de la locale. Par exemple, la locale par défaut **"C"** ne connaît pas les trémas, donc aucune conversion n'est effectuée pour eux.

Dans certaines locales non anglaises, il existe des lettres minuscules sans équivalent majuscule correspondant ; le s allemand (ß) en est un exemple.
