NOM

tor-resolve - résoudre un nom d'hôte en adresse IP via tor

SYNTAXE

tor-resolve [-4|-5] [-v] [-x] [-p port_socks] nom_hote [hote_socks[:port_socks]]

DESCRIPTION

tor-resolve est un script simple pour se connecter à un proxy SOCKS qui comprend la commande SOCKS RESOLVE, lui transmettre un nom d'hôte, et retourner une adresse IP.

Par défaut, tor-resolve utilise le serveur Tor fonctionnant sur 127.0.0.1 sur le port SOCKS 9050. Si ce n'est pas ce que vous souhaitez, vous devriez spécifier explicitement un hote_socks et/ou un port_socks dans la ligne de commande.

OPTIONS

-v

Afficher une sortie détaillée.

-x

Effectuer une recherche inversée : obtenir l'enregistrement PTR pour une adresse IPv4.

-5

Utiliser le protocole SOCKS5. (Par défaut)

-4

Utiliser le protocole SOCKS4a au lieu du protocole SOCKS5 par défaut. Ne prend pas en charge la résolution DNS inversée.

-p port_socks

Substituer le port SOCKS par défaut sans définir le nom d'hôte.

VOIR AUSSI

tor(1), torify(1).

Pour les détails du protocole, voir : https://spec.torproject.org/socks-extensions
