TOWLOWER(3P) Manuel du programmeur POSIX TOWLOWER(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

towlower, towlower_l — translittère un code de caractère large majuscule en minuscule

SYNTAXE

#include <wctype.h>
wint_t towlower(wint_t wc);
wint_t towlower_l(wint_t wc, locale_t locale);

DESCRIPTION

Pour towlower() : Les fonctionnalités décrites sur cette page de référence sont alignées avec la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

Les fonctions towlower() et towlower_l() ont comme domaine un type wint_t, dont la valeur est assurée par l'application comme étant un caractère représentable sous forme de wchar_t, et un code de caractère large correspondant à un caractère valide dans la locale utilisée par la fonction ou la valeur de WEOF. Si l'argument a toute autre valeur, le comportement est indéfini. Si l'argument de towlower() ou towlower_l() représente un code de caractère large majuscule, et qu'il existe un code de caractère large minuscule correspondant tel que défini par les informations de type de caractère dans la locale actuelle ou dans la locale représentée par locale, respectivement (catégorie LC_CTYPE), le résultat sera le code de caractère large minuscule correspondant. Tous les autres arguments dans le domaine sont retournés inchangés.

Le comportement est indéfini si l'argument locale de towlower_l() est la locale spéciale LC_GLOBAL_LOCALE ou s'il ne s'agit pas d'un handle de locale valide.

VALEUR DE RETOUR

En cas de succès, les fonctions towlower() et towlower_l() retourneront la lettre minuscule correspondant à l'argument passé ; sinon, elles retourneront l'argument inchangé.
