NOM

torsocks — Wrapper de shell pour simplifier l'utilisation de la bibliothèque torsocks(8) afin de torifier une application de manière transparente.

SYNTAXE

torsocks [OPTIONS] [COMMANDE [ARG ...]]

DESCRIPTION

torsocks est un wrapper entre la bibliothèque torsocks et l'application afin que toute communication Internet passe par le réseau Tor.

Par défaut, torsocks suppose qu'il doit se connecter au proxy SOCKS Tor exécuté sur 127.0.0.1 sur le port 9050, qui sont les valeurs par défaut du démon Tor.

Afin d'utiliser un fichier de configuration, torsocks essaie de lire le fichier /etc/tor/torsocks.conf ou recherche la variable d'environnement TORSOCKS_CONF_FILE pour l'emplacement du fichier. Si ce fichier ne peut pas être lu, torsocks utilisera des valeurs par défaut raisonnables pour la plupart des installations Tor.

Pour plus d'informations sur la configuration, voir torsocks.conf(5).

OPTIONS

-h, --help
Affiche un résumé des options et commandes possibles.
--shell
Crée un nouveau shell avec LD_PRELOAD incluant torsocks(8).
--version
Affiche la version.
-u, --user
Définit le nom d'utilisateur pour l'authentification SOCKS5. Utilisé pour l'isolement des circuits dans Tor. Notez que vous DEVEZ avoir défini un mot de passe soit par la ligne de commande, la variable d'environnement, soit le fichier de configuration (torsocks.conf(5).
-p, --pass
Définit le mot de passe pour l'authentification SOCKS5. Utilisé pour l'isolement des circuits dans Tor. Notez que vous DEVEZ avoir défini un nom d'utilisateur soit par la ligne de commande, la variable d'environnement, soit le fichier de configuration (torsocks.conf(5)).
-a, --address
Définit l'adresse Tor.
-P, --port
Définit le port Tor.
-i, --isolate
Isolement Tor automatique. Définit le nom d'utilisateur et le mot de passe pour la méthode d'authentification SOCKS5 à une valeur basée sur le PID/heure actuelle automatiquement. Le nom d'utilisateur et le mot de passe NE DOIVENT PAS être définis.
-d, --debug
Active le mode débogage. Les sorties seront écrites sur stderr.
-q, --quiet
Supprime tous les messages de log (même les erreurs).
on | off
Cette option ajoute ou supprime torsocks(8) de la variable d'environnement LD_PRELOAD pour le shell actuel. Si vous souhaitez utiliser cette option, vous DEVEZ sourcer torsocks depuis votre shell. 
Ajouter la bibliothèque torsocks à LD_PRELOAD
$ . torsocks on
Supprimer la bibliothèque torsocks de LD_PRELOAD
$ . torsocks off
show | sh
Affiche la valeur actuelle de la variable d'environnement LD_PRELOAD.

VARIABLES D'ENVIRONNEMENT

Veuillez consulter torsocks(8) pour plus de détails sur les variables d'environnement possibles.
