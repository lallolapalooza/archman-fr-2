NOM

toolbox-help - Affiche des informations d'aide sur Toolbx

SYNTAXE

toolbox help [COMMANDE]

DESCRIPTION

Lorsqu'aucune COMMANDE n'est spécifiée, le manuel de toolbox(1) est affiché. Si une COMMANDE est spécifiée, une page de manuel pour cette commande est affichée.

Notez que toolbox --help ... est identique à toolbox help ... car le premier est converti en interne en ce dernier.

Cette page peut être affichée avec toolbox help help ou toolbox help --help.

EXEMPLES

Afficher le manuel de toolbox

$ toolbox help

Afficher le manuel de la commande create

$ toolbox help create
