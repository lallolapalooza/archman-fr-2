NOM

totem-video-thumbnailer - miniature vidéo pour le bureau GNOME

SYNTAXE

totem-video-thumbnailer [-j|--jpeg] [-l|--no-limit] [-s taille] entrée sortie [options de backend]

DESCRIPTION

Cette page de manuel documente brièvement la commande totem-video-thumbnailer. Cette page de manuel a été écrite pour le projet Debian car le programme original ne dispose pas d'une page de manuel.

totem-video-thumbnailer est utilisé en interne par les applications GNOME telles que nautilus pour générer des miniatures PNG de fichiers vidéo. Bien qu'il soit possible de l'invoquer manuellement, cela est généralement fait automatiquement par nautilus.

ARGUMENTS

entrée
Le nom du fichier d'entrée. Cela peut être dans n'importe quel format que totem peut lire.
sortie
Le nom du fichier de sortie, sortie au format PNG.
options de backend
Options à passer au backend (c'est-à-dire gstreamer).

OPTIONS

-j --jpeg
Basculer le format de sortie sur JPEG. Le défaut est PNG.
-l --no-limit
Ne pas limiter le temps de génération de la miniature à 30 secondes. À des fins de débogage.
-s taille
La taille de la miniature. Exemple : "64x64". La taille par défaut est "128x96".
