toilet(1) Manuel des commandes générales toilet(1)

NOM

TOIlet — affiche de grands caractères colorés

SYNTAXE

toilet [ -hkostvSW ] [ -d répertoiresourcepolices ]

[ -f fichierpolice ] [ -F filtre ] [ -w largeursortie ]
[ -I codedinfo ] [ -E format ] [ message ]

DESCRIPTION

TOIlet affiche du texte en utilisant de grands caractères composés de caractères plus petits. Il est similaire à bien des égards à FIGlet avec des fonctionnalités supplémentaires telles que la gestion Unicode, les polices de caractères colorées, les filtres et divers formats d'exportation.

UTILISATION

TOIlet lit son entrée depuis la ligne de commande ou depuis l'entrée standard.

OPTIONS

-f, --font <nom>
Utilise la police spécifiée à la place de la valeur par défaut. Les polices sont des fichiers .flf ou .tlf stockés dans le répertoire /usr/share/figlet. Les polices sont recherchées d'abord dans le répertoire des polices, puis dans le répertoire courant. Il existe également une police spéciale intégrée appelée term qui sert de solution de repli si aucune police n'est disponible.
-d, --directory <dir>
Spécifie le répertoire dans lequel chercher les polices. La valeur par défaut est définie lors de la compilation et est généralement /usr/share/figlet.
-s, -S, -k, -W, -o
Sélectionne les règles de composition des caractères. -S active le bouchage (fusion agréable des glyphes), -k active l'espacement (rendu des sous-caractères aussi proches que possible), -W rend les caractères à leur pleine largeur et -o active le chevauchement (les glyphes se chevauchent légèrement sur le précédent). -s (comportement par défaut) utilise les informations de bouchage de la police s'il y en a, sinon force le chevauchement, ou ne fait rien si le glyphe n'a qu'un seul sous-caractère.
-w, --width <largeur>
Définit la largeur de sortie. Par défaut, TOIlet retournera à la ligne après 80 colonnes de caractères.
-t, --termwidth
Définit la largeur de sortie à la largeur du terminal.
-F, --filter <filtres>
-F, --filter list
--arc-en-ciel, --metal
Spécifie une liste de filtres à appliquer à la sortie. <filtres> est une liste séparée par des deux-points de filtres tels que rogner:rotation:arc-en-ciel et l'argument spécial liste affiche une liste des filtres disponibles.

--arc-en-ciel et --metal sont des raccourcis vers des filtres couramment utilisés qui sont garantis d'exister. Plusieurs options -F peuvent également être spécifiées sur la ligne de commande, auquel cas les filtres seront appliqués dans l'ordre d'apparition.

-E, --export <format>
-E, --export list
--irc, --html
Spécifie le format de sortie. Par défaut, TOIlet produira du texte UTF-8 utilisant des codes de couleur ANSI adaptés à la plupart des terminaux tels que XTerm ou rxvt. <format> est le nom du format d'exportation tel que reconnu par libcaca. L'argument spécial liste affiche une liste des formats d'exportation disponibles.

--irc et --html sont des raccourcis vers des formats d'exportation couramment utilisés qui sont garantis d'exister.

-h, --help
Affiche un court message d'aide et quitte.
-I, --infocode <code>
Affiche un code d'information FIGlet. Cet indicateur est uniquement présent pour la compatibilité FIGlet, consultez la page de manuel figlet pour plus d'informations.
-v, --version
Affiche les informations de version et quitte.

EXEMPLES

toilet Bonjour le monde

toilet Bonjour | toilet

tail -f /var/log/messages | toilet -f term --arc-en-ciel

BOGUES

La compatibilité avec FIGlet n'est pas encore complète.
