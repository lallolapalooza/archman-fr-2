TMPFILE(3P) Manuel du programmeur POSIX TMPFILE(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

tmpfile — créer un fichier temporaire

SYNOPIS

#include <stdio.h>
FILE *tmpfile(void);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

La fonction tmpfile() crée un fichier temporaire et ouvre un flux correspondant. Le fichier est automatiquement supprimé lorsque toutes les références au fichier sont fermées. Le fichier est ouvert comme avec fopen() pour la mise à jour (wb+), sauf que les implémentations peuvent restreindre les permissions, soit en effaçant les bits du mode de fichier, soit en les définissant à la valeur S_IRUSR | S_IWUSR.

Dans certaines implémentations, un fichier permanent peut subsister si le processus appelant tmpfile() est tué pendant qu'il traite un appel à tmpfile().

Un message d'erreur peut être écrit sur la sortie standard d'erreur si le flux ne peut pas être ouvert.

VALEUR DE RETOUR

En cas de succès, tmpfile() renvoie un pointeur vers le flux du fichier créé. Sinon, il renvoie un pointeur nul et définit errno pour indiquer l'erreur.

ERREURS

La fonction tmpfile() échoue si :

EINTR
Un signal a été intercepté pendant tmpfile().
EMFILE
Tous les descripteurs de fichiers disponibles pour le processus sont actuellement ouverts.
EMFILE
{STREAM_MAX} flux sont actuellement ouverts dans le processus appelant.
ENFILE
Le nombre maximum de fichiers autorisés est actuellement ouvert dans le système.
ENOSPC
Le répertoire ou le système de fichiers qui contiendrait le nouveau fichier ne peut pas être étendu.
EOVERFLOW
Le fichier est un fichier régulier et la taille du fichier ne peut pas être représentée correctement dans un objet de type off_t.

La fonction tmpfile() peut échouer si :

EMFILE
{FOPEN_MAX} flux sont actuellement ouverts dans le processus appelant.
ENOMEM
Il n'y a pas assez d'espace de stockage disponible.

Les sections suivantes sont informatives.

EXEMPLES

Création d'un Fichier Temporaire

L'exemple suivant crée un fichier temporaire pour la mise à jour et renvoie un pointeur vers un flux pour le fichier créé dans la variable fp.

#include <stdio.h>
...
FILE *fp;
fp = tmpfile ();

USAGE PAR L'APPLICATION

Il devrait être possible d'ouvrir au moins {TMP_MAX} fichiers temporaires pendant la durée de vie du programme (cette limite peut être partagée avec tmpnam()) et il ne devrait y avoir aucune limite sur le nombre simultanément ouvert autre que cette limite et toute limite sur le nombre de descripteurs de fichiers ou de flux ouverts ({OPEN_MAX}, {FOPEN_MAX}, {STREAM_MAX}).
