tm(3type) tm(3type)

NOM

tm - temps décomposé

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <time.h>
struct tm {
    int         tm_sec;    /* Secondes          [0, 60] */
    int         tm_min;    /* Minutes          [0, 59] */
    int         tm_hour;   /* Heure            [0, 23] */
    int         tm_mday;   /* Jour du mois [1, 31] */
    int         tm_mon;    /* Mois            [0, 11]  (Janvier = 0) */
    int         tm_year;   /* Année moins 1900 */
    int         tm_wday;   /* Jour de la semaine  [0, 6]   (Dimanche = 0) */
    int         tm_yday;   /* Jour de l'année  [0, 365] (1er Jan = 0) */
    int         tm_isdst;  /* Indicateur d'heure d'été */
    /* Depuis POSIX.1-2024 : */
    long        tm_gmtoff; /* Secondes Est de l'UTC */
    const char *tm_zone;   /* Abréviation du fuseau horaire */
};
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

tm_gmtoff, tm_zone:

    Depuis glibc 2.20 :
        _DEFAULT_SOURCE
    glibc 2.20 et antérieur :
        _BSD_SOURCE

DESCRIPTION

Décrit le temps, décomposé en composantes distinctes.

tm_isdst indique si l'heure d'été est en vigueur au moment décrit. La valeur est positive si l'heure d'été est en vigueur, zéro si elle ne l'est pas, et négative si l'information n'est pas disponible.

tm_gmtoff est la différence, en secondes, du fuseau horaire représenté par ce temps décomposé et l'UTC (c'est l'inverse additif de timezone(3)).

tm_zone est l'équivalent de tzname(3) pour le fuseau horaire représenté par ce temps décomposé.

VERSIONS

En C90, tm_sec pouvait représenter des valeurs dans la plage [0, 61], ce qui pouvait représenter une seconde intercalaire double. L'UTC ne permet pas les secondes intercalaires doubles, elle a donc été limitée à 60 en C99.

timezone(3), en tant que variable, est une extension XSI : certains systèmes fournissent la fonction timezone(3) compatible V7. Le champ tm_gmtoff offre une alternative (avec le signe opposé) pour ces systèmes.

tm_zone pointe vers un stockage statique et peut être remplacé lors d'appels ultérieurs à localtime(3) et fonctions similaires (cependant, cela n'arrive jamais sous glibc).

NORMES

C23, POSIX.1-2024.

HISTORIQUE

C89, POSIX.1-1988.

tm_gmtoff et tm_zone proviennent de 4.3BSD-Tahoe (où tm_zone est un char *), et ont été standardisés pour la première fois dans POSIX.1-2024.

NOTES

tm_sec peut représenter une seconde intercalaire avec la valeur 60.

VOIR AUSSI

ctime(3), strftime(3), strptime(3), time(7)
