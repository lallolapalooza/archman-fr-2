NOM

tmxrasterizer - rend une carte de tuiles en une image

SYNTAXE

tmxrasterizer [OPTIONS] [FICHIER D'ENTRÉE] [FICHIER DE SORTIE]

DESCRIPTION

Cette application peut être utilisée pour rendre les cartes créées par l'Éditeur de cartes Tiled en une image. Ceci est très utile pour créer des aperçus à petite échelle, tels que des mini-cartes.

OPTIONS

-h --help
Affiche l'aide
-v --version
Affiche la version
-s --scale TAILLE
L'échelle de l'image de sortie
-t --tilesize TAILLE
La taille demandée en pixels à laquelle une tuile est rendue. Remplace l'option --scale.
--size TAILLE
L'image de sortie s'inscrit dans un carré de TAILLE x TAILLE. Remplace les options --scale et --tilesize.
-a --anti-aliasing
Lisse l'image de sortie en utilisant l'anti-aliasing
--ignore-visibility
Ignore tous les indicateurs de visibilité des couches dans le fichier de carte et rend toutes les couches dans la sortie (par défaut, les couches invisibles sont omises).
--hide-layer
Spécifie une couche à omettre de l'image de sortie. Peut être répété pour omettre plusieurs couches. Le nom de la couche n'est pas sensible à la casse.
Exemple :
tmxrasterizer --hide-layer collision --hide-layer otherlayer [...]
