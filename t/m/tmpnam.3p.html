TMPNAM(3P) Manuel du programmeur POSIX TMPNAM(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

tmpnam — créer un nom pour un fichier temporaire

SYNTAXE

#include <stdio.h>
char *tmpnam(char *s);

DESCRIPTION

Les fonctionnalités décrites sur cette page de référence sont alignées sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

La fonction tmpnam() génère une chaîne qui est un nom de chemin valide n'identifiant aucun fichier existant. La fonction est potentiellement capable de générer {TMP_MAX} chaînes différentes, mais chacune d'elles peut déjà être utilisée par des fichiers existants et donc ne pas être une valeur de retour appropriée.

La fonction tmpnam() génère une chaîne différente chaque fois qu'elle est appelée depuis le même processus, jusqu'à {TMP_MAX} fois. Si elle est appelée plus de {TMP_MAX} fois, le comportement est défini par l'implémentation.

L'implémentation doit se comporter comme si aucune fonction définie dans ce volume de POSIX.1‐2017, à l'exception de tempnam(), n'appelait tmpnam().

La fonction tmpnam() n'a pas besoin d'être thread-safe si elle est appelée avec un paramètre NULL.

VALEUR DE RETOUR

En cas de succès, tmpnam() renvoie un pointeur vers une chaîne. Si aucune chaîne appropriée ne peut être générée, la fonction tmpnam() renvoie un pointeur NULL.

Si l'argument s est un pointeur NULL, tmpnam() laisse son résultat dans un objet statique interne et renvoie un pointeur vers cet objet. Les appels ultérieurs à tmpnam() peuvent modifier le même objet. Si l'argument s n'est pas un pointeur NULL, il est présumé pointer vers un tableau d'au moins L_tmpnam chars ; tmpnam() y écrira son résultat et renverra l'argument comme valeur.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Génération d'un nom de chemin

L'exemple suivant génère un nom de chemin unique et le stocke dans le tableau pointé par ptr.

#include <stdio.h>
...
char pathname[L_tmpnam+1];
char *ptr;
ptr = tmpnam(pathname);

UTILISATION APPLICATIVE

Cette fonction crée uniquement des noms de chemin. Il incombe à l'application de créer et de supprimer les fichiers.

Entre le moment où un nom de chemin est créé et l'ouverture du fichier, il est possible qu'un autre processus crée un fichier portant le même nom. Les applications pourraient trouver tmpfile() plus utile.

Les applications devraient utiliser les fonctions tmpfile(), mkstemp() ou mkdtemp() au lieu de la fonction obsolète tmpnam().

RATIONALE

Aucun.

DIRECTIONS FUTURES

La fonction tmpnam() pourrait être supprimée dans une future version.

VOIR AUSSI

fopen(), open(), mkdtemp(), tempnam(), tmpfile(), unlink()
