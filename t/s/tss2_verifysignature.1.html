tss2_verifysignature(1) Manuel des commandes générales tss2_verifysignature(1)

NOM

tss2_verifysignature(1) -

SYNTAXE

tss2_verifysignature [OPTIONS]

DESCRIPTION

tss2_verifysignature(1) - Cette commande vérifie une signature à l'aide d'une clé publique trouvée dans le chemin de clé passé. Le schéma de vérification de signature utilisé est spécifié dans le profil cryptographique (voir fapi-profile(5)).

OPTIONS

Voici les options disponibles :

•
-d, --digest=NOM_FICHIER ou - (pour stdin) :

Les données qui ont été signées, déjà hachées selon le profil cryptographique (voir fapi-profile(5)).

•
-p, --keyPath=CHAINE :

Chemin vers la clé publique de vérification.

•
-i, --signature=NOM_FICHIER ou - (pour stdin) :

La signature à vérifier.

OPTIONS COMMUNES

Cette collection d'options est commune à tous les programmes tss2 et fournit des informations que de nombreux utilisateurs peuvent attendre.

•
-h, --help [man|no-man] : Affiche la page de manuel de l'outil. Par défaut, il tente d'invoquer le paginateur de manuel pour l'outil, cependant, en cas d'échec, il affichera un bref résumé de l'outil. C'est le même comportement si l'argument d'option “man” est spécifié, cependant si “man” est explicitement demandé, l'outil fournira les erreurs de man sur stderr. Si l'option “no-man” est spécifiée, ou si le paginateur de manuel échoue, les options courtes seront affichées sur stdout.

Pour utiliser avec succès la fonctionnalité des pages de manuel, il faut que les pages de manuel soient installées ou présentes sur MANPATH. Voir man(1) pour plus de détails.

•
-v, --version : Affiche les informations de version pour cet outil, les tctis supportés et quitte.

EXEMPLE

tss2_verifysignature --keyPath=ext/myRSASign --digest=digest.file --signature=signature.file

RETOUR

0 en cas de succès ou 1 en cas d'échec.
