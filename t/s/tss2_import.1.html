tss2_import(1) Manuel des commandes générales tss2_import(1)

NOM

tss2_import(1) -

SYNOPSIS

tss2_import [OPTIONS]

VOIR AUSSI

fapi-config(5) pour ajuster les paramètres Fapi tels que le profil cryptographique utilisé et le TCTI ou les répertoires pour les stockages de métadonnées Fapi.

fapi-profile(5) pour déterminer les algorithmes cryptographiques et les paramètres pour toutes les clés et opérations d'une interaction TPM spécifique, comme l'algorithme de hachage de nom, l'algorithme de signature asymétrique, le schéma et les paramètres, ainsi que la sélection de la banque PCR.

DESCRIPTION

tss2_import(1) - Cette commande importe une clé, une politique ou un modèle de politique encodé en JSON et le stocke sous le chemin fourni.

OPTIONS

Voici les options disponibles :

•
-p, --path=CHAINE :

Le chemin du nouvel objet.

•
-i, --importData=NOM_FICHIER ou - (pour stdin) :

Les données à importer.

OPTIONS COMMUNES

Cette collection d'options est commune à tous les programmes tss2 et fournit des informations que de nombreux utilisateurs peuvent attendre.

•
-h, --help [man|no-man] : Affiche la page man de l'outil. Par défaut, il tente d'invoquer le visionneur de pages man pour l'outil, cependant, en cas d'échec, il affiche un bref résumé de l'outil. C'est le même comportement si l'argument d'option « man » est spécifié, cependant si « man » est explicitement demandé, l'outil fournira les erreurs de man sur stderr. Si l'option « no-man » est spécifiée, ou si le visionneur de pages man échoue, les options courtes seront affichées sur stdout.

Pour utiliser avec succès la fonctionnalité des pages man, il faut que les pages man soient installées ou présentes dans MANPATH. Voir man(1) pour plus de détails.

•
-v, --version : Affiche les informations de version pour cet outil, les TCTIs pris en charge et quitte.

EXEMPLE

tss2_import --path=/policy/duplicate-policy --importData=importData.json

tss2_import --path=/ext/key --importData=importData.file

RETOURNE

0 en cas de succès ou 1 en cas d'échec.
