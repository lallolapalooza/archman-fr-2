NOM

tcti-spi-ftdi - Bibliothèque TCTI pour TPM basée sur SPI via USB

SYNOPSIS

Un module d'Interface de Transmission de Commandes TPM (TCTI) pour l'interaction avec un TPM basé sur SPI via le pont USB vers SPI FTDI MPSSE.

DESCRIPTION

tcti-spi-ftdi est une bibliothèque qui abstrait les détails de la communication avec un TPM basé sur SPI via le pont USB vers SPI FTDI MPSSE. L'interface exposée par cette bibliothèque est définie dans la spécification « TSS System Level API and TPM Command Transmission Interface Specification ».
