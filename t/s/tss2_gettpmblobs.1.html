tss2_gettpmblobs(1) Manuel des commandes générales tss2_gettpmblobs(1)

NOM

tss2_gettpmblobs(1) -

SYNTAXE

tss2_gettpmblobs [OPTIONS]

VOIR AUSSI

fapi-config(5) pour ajuster les paramètres de Fapi tels que le profil cryptographique utilisé et le TCTI ou les répertoires pour les stockages de métadonnées de Fapi.

fapi-profile(5) pour déterminer les algorithmes cryptographiques et les paramètres pour toutes les clés et opérations d'une interaction spécifique du TPM, comme l'algorithme de hachage de nom, l'algorithme de signature asymétrique, le schéma et les paramètres, ainsi que la sélection de la banque PCR.

DESCRIPTION

tss2_gettpmblobs(1) - Cette commande retourne les blobs publics et privés d'un objet, de telle sorte qu'ils puissent être chargés par une API de bas niveau (par exemple, ESAPI). Elle retourne également la politique associée à ces blobs au format JSON.

OPTIONS

Voici les options disponibles :

•
-f, --force :

Forcer l'écrasement du fichier de sortie.

•
-p, --path=CHAINE :

Le chemin de l'objet pour lequel les blobs seront retournés.

•
-u, --tpm2bPublic=NOMFICHIER ou - (pour stdout) :

La zone publique retournée de l'objet sous forme de TPM2B_PUBLIC marshalisée. Paramètre optionnel.

•
-r, --tpm2bPrivate=NOMFICHIER ou - (pour stdout) :

La zone privée retournée de l'objet sous forme de TPM2B_PRIVATE marshalisée. Paramètre optionnel.

•
-l, --policy=NOMFICHIER ou - (pour stdout) :

La politique retournée associée à l'objet, encodée en JSON. Paramètre optionnel.

OPTIONS COMMUNES

Cette collection d'options est commune à tous les programmes tss2 et fournit des informations que de nombreux utilisateurs peuvent attendre.

•
-h, --help [man|no-man] : Affiche la page man de l'outil. Par défaut, il tente d'appeler le pagineur man pour l'outil, cependant, en cas d'échec, il affichera un bref résumé de l'outil. Ceci est le même comportement si l'argument d'option « man » est spécifié, cependant si « man » est explicitement demandé, l'outil fournira des erreurs de man sur stderr. Si l'option « no-man » est spécifiée, ou si le pagineur man échoue, les options courtes seront affichées sur stdout.

Pour utiliser avec succès la fonctionnalité des pages man, celles-ci doivent être installées ou sur MANPATH. Voir man(1) pour plus de détails.

•
-v, --version : Affiche les informations de version pour cet outil, les tctis pris en charge et quitte.

EXEMPLE

tss2_gettpmblobs --path=HS/SRK/myRSACrypt --tpm2bPublic=tpm2bPublic.file --tpm2bPrivate=tpm2bPrivate.file --policy=policy.file

RETOURNE

0 en cas de succès ou 1 en cas d'échec.
