Paquet: tslib

Licences: LGPL-2.1-only

TS_PRINT_ASCII_LOGO(3) tslib TS_PRINT_ASCII_LOGO(3)

NOM

ts_print_ascii_logo - imprime le logo de tslib sur la sortie standard

SYNTAXE

#include <tslib.h>

void ts_print_ascii_logo(unsinged int pos);

DESCRIPTION

ts_print_ascii_logo() Cette fonction imprime le logo de tslib sur la sortie standard. Elle ajoute `pos` espaces avant celui-ci.

VOIR AUSSI

ts_setup(3), ts_read(3), ts.conf(5)
