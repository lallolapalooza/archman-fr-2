TSK_GETTIMES(1) Manuel des commandes générales TSK_GETTIMES(1)

NOM

tsk_gettimes - Collecte les temps MAC d'une image disque dans un fichier corps.

SYNOPIS

tsk_gettimes [-vV] [ -f fstype ] [ -i imgtype ] [ -b dev_sector_size ] [ -z zone ] [ -s secondes ] image [images]

DESCRIPTION

tsk_gettimes examine chacun des systèmes de fichiers d'une image disque et retourne les données les concernant dans le format de corps MACtime (identique à l'exécution de 'fls -m' sur chaque système de fichiers). La sortie de cette commande peut être utilisée comme entrée pour mactime afin de créer une chronologie de l'activité des fichiers. Les données sont imprimées sur STDOUT, qui peut ensuite être redirigé vers un fichier.

Les arguments sont les suivants :

-v
sortie détaillée sur stderr
-V
Affiche la version
-f fstype
Spécifie le type de système de fichiers. Utilisez '-f list' pour lister les types de systèmes de fichiers pris en charge. Si non spécifié, des méthodes de détection automatique sont utilisées.
-i imgtype
Le format du fichier image, tel que raw. Utilisez '-i list' pour lister les types pris en charge. Si non spécifié, des méthodes de détection automatique sont utilisées.
-b dev_sector_size
La taille (en octets) des secteurs de l'appareil. Si non spécifié, des méthodes de détection automatique sont utilisées.
-o sector_offset
Décalage de secteur pour un volume à récupérer (ne récupère que ce volume). Si non spécifié, tentera de récupérer tous les volumes de l'image et de les enregistrer dans des dossiers différents.
-s secondes
Le décalage temporel du système d'origine en secondes. Par exemple, si le système d'origine était en retard de 100 secondes, cette valeur serait de -100.
-z zone
La chaîne ASCII du fuseau horaire du système d'origine. Par exemple, EST ou GMT. Ces chaînes doivent être définies par votre système d'exploitation et peuvent varier.
image [images]
L'image disque ou de partition à lire, dont le format est spécifié avec '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné, et que son nom est le premier d'une séquence (par exemple, indiqué par se terminant par '.001'), les segments d'image suivants seront inclus automatiquement.

EXEMPLES

Pour collecter des données sur l'image image.dd :

# tsk_gettimes ./image.dd > body.txt
