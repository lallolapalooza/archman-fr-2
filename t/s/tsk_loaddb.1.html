TSK_LOADDB(1) Manuel des commandes générales TSK_LOADDB(1)

NOM

tsk_loaddb - peuple une base de données SQLite avec les métadonnées d'une image disque

SYNTAXE

tsk_loaddb [-ahkvV] [ -i imgtype ] [ -b taille_secteur_dev ] [ -i imgtype ] [ -d base_de_donnees ] image [images]

DESCRIPTION

tsk_loaddb charge les informations du disque depuis image vers une base de données SQLite. Cette base de données peut ensuite être utilisée par des outils dans d'autres langages pour l'analyse. Par défaut, la base de données est stockée dans le même répertoire que l'image avec ".db" ajouté au nom, ou le nom de la base de données peut être spécifié avec '-d'.

Les arguments sont les suivants :

-a
Ajoute l'image à une base de données existante au lieu d'en créer une nouvelle. Nécessite que -d soit également spécifié.
-d base_de_donnees
Chemin d'accès à la base de données (par défaut, le même répertoire que l'image avec un nom dérivé du nom de l'image).
-v
Sortie verbeuse vers stderr.
-V
Affiche la version.
-k
Ne crée pas la table de données des blocs. Cette table mappe chaque bloc au fichier qui l'a alloué. Cette option rendra ce programme plus rapide.
-h
Calcule la valeur de hachage MD5 pour chaque fichier et la stocke dans la table. Cette option rendra le programme plus lent.
-i imgtype
Le format du fichier image, tel que raw. Utilisez '-i list' pour lister les types pris en charge. S'il n'est pas donné, les méthodes de détection automatique sont utilisées.
-b taille_secteur_dev
La taille (en octets) des secteurs du périphérique. S'il n'est pas donné, les méthodes de détection automatique sont utilisées.
image [images]
L'image disque ou partition à lire, dont le format est donné par '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné, et que son nom est le premier d'une séquence (par exemple, indiqué par une terminaison en '.001'), les segments d'image suivants seront inclus automatiquement.

EXEMPLES

Pour charger les données de l'image depuis image.dd vers image.dd.db :

# tsk_loaddb ./image.dd
