NOM

ts_calibrate - Programme de test pour calibrer un écran tactile utilisé par tslib.

SYNTAXE

ts_calibrate

DESCRIPTION

ts_calibrate est utilisé pour configurer manuellement le plugin linear de tslib. Il dessine des réticules sur le framebuffer à toucher par l'utilisateur et enregistre les positions attendues par rapport aux positions réelles des contacts tactiles nécessaires pour appliquer le filtre et offrir une expérience utilisateur tactile désirée. Il utilise la variable d'environnement TSLIB_CALIBFILE pour stocker ses valeurs.

-r, --rotate [valeur]

Fait pivoter l'écran. La valeur est 0 pour 0 degré, 1 pour 90 degrés (sens horaire), 2 pour 180 degrés (à l'envers) et 3 pour 270 degrés (sens anti-horaire). Cette valeur sera ajoutée au fichier de configuration de calibration TSLIB_CALIBFILE et récupérée à partir du module de filtre linéaire. Elle peut être modifiée par un paramètre du module linéaire.

-t, --min_interval

Le temps en millisecondes qui doit s'écouler avant qu'un réticule ne soit pressé par l'utilisateur. Cela peut être utile pour éviter les appuis trop rapides ou accidentellement incorrects, et donc une calibration inexacte. Défaut : 0.

-c, --validate

Valide la calibration. S'assure que le module linéaire est configuré dans ts.conf de manière à ce que la calibration actuelle soit appliquée. Dans ce mode, des croix sont affichées à des emplacements aléatoires sur l'écran et les contacts sont évalués par rapport à leurs positions. Dans ce mode, les options --loops et --boundary sont disponibles.

-b, --boundary

Limite de validation en pixels. Disponible uniquement lorsque --validate est utilisé. Cela définit la rigueur de la validation. C'est la distance à laquelle une entrée tactile évaluée peut se trouver d'une croix pour toujours passer la validation. Si cette limite est franchie, la validation échoue. Défaut : 10.

-o, --border

Nombre de pixels à éloigner du bord de l'écran. Disponible uniquement lorsque --validate est utilisé. Défaut : 0.

-l, --loops

Nombre de boucles en mode de validation. Disponible uniquement lorsque --validate est utilisé. Cela définit combien de croix doivent être touchées et évaluées. Défaut : 3.
