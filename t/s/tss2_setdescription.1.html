tss2_setdescription(1) Manuel des commandes générales tss2_setdescription(1)

NOM

tss2_setdescription(1)

SYNTAXE

tss2_setdescription [OPTIONS]

VOIR AUSSI

fapi-config(5) pour ajuster les paramètres Fapi tels que le profil cryptographique utilisé et le TCTI ou les répertoires pour les stockages de métadonnées Fapi.

fapi-profile(5) pour déterminer les algorithmes et paramètres cryptographiques pour toutes les clés et opérations d'une interaction TPM spécifique comme l'algorithme de hachage de nom, l'algorithme de signature asymétrique, le schéma et les paramètres, ainsi que la sélection des banques PCR.

DESCRIPTION

tss2_setdescription(1) - Cette commande permet à une application d'attribuer une description lisible par l'homme à un objet dans le magasin de métadonnées Fapi. Les données stockées peuvent être récupérées avec tss2_getdescription. Les données précédemment stockées sont écrasées par cette fonction. Si une description vide est passée, les données stockées sont supprimées.

OPTIONS

Voici les options disponibles :

•
-i, --description=CHAÎNE :

Les données à stocker comme description de l'objet. Paramètre optionnel. Les descriptions précédemment stockées sont écrasées par cette fonction. Si omis, toute description stockée est supprimée.

•
-p, --path=CHAÎNE :

Le chemin de l'objet pour lequel la description sera stockée.

OPTIONS COMMUNES

Cette collection d'options est commune à tous les programmes tss2 et fournit des informations que de nombreux utilisateurs peuvent attendre.

•
-h, --help [man|no-man] : Affiche la page de manuel de l'outil. Par défaut, il tente d'appeler le pagineur de manuel pour l'outil, cependant, en cas d'échec, il affiche un bref résumé de l'outil. C'est le même comportement si l'argument d'option « man » est spécifié, cependant si « man » est explicitement demandé, l'outil fournira des erreurs de man sur stderr. Si l'option « no-man » est spécifiée, ou si le pagineur de manuel échoue, les options courtes seront affichées sur stdout.

Pour utiliser avec succès la fonctionnalité des pages de manuel, celles-ci doivent être installées ou sur MANPATH. Voir man(1) pour plus de détails.

•
-v, --version : Affiche les informations de version pour cet outil, les TCTI pris en charge et quitte.

EXEMPLE

tss2_setdescription --path=HS/SRK --description=description

RETOUR

0 en cas de succès ou 1 en cas d'échec.
