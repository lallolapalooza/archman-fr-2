TSK_RECOVER(1) Manuel des commandes générales TSK_RECOVER(1)

NOM

tsk_recover - Exporter des fichiers depuis une image vers un répertoire local

SYNTAXE

tsk_recover [-vVae] [ -f type_fs ] [ -i type_img ] [ -b taille_secteur_dev ] [ -o decalage_secteur ] [ -d num_ino_repertoire ] image [images] repertoire_sortie

DESCRIPTION

tsk_recover récupère des fichiers vers repertoire_sortie depuis l'image. Par défaut, ne récupère que les fichiers non alloués. Avec des options, il exportera tous les fichiers.

Les arguments sont les suivants :

-v
sortie détaillée sur stderr
-V
Afficher la version
-a
Récupérer uniquement les fichiers alloués
-e
Récupérer tous les fichiers (alloués et non alloués)
-f type_fs
Spécifier le type de système de fichiers. Utiliser « -f list » pour lister les types de systèmes de fichiers pris en charge. S'il n'est pas fourni, les méthodes de détection automatique sont utilisées.
-i type_img
Le format du fichier image, comme brut. Utiliser « -i list » pour lister les types pris en charge. S'il n'est pas fourni, les méthodes de détection automatique sont utilisées.
-b taille_secteur_dev
La taille (en octets) des secteurs du périphérique. S'il n'est pas fourni, les méthodes de détection automatique sont utilisées.
-o decalage_secteur
Décalage de secteur pour un volume à récupérer (ne récupère que ce volume). S'il n'est pas fourni, tentera de récupérer tous les volumes de l'image et de les enregistrer dans différents dossiers.
-d num_ino_repertoire
Numéro d'inode du répertoire à récupérer (doit également spécifier une partition spécifique avec -o ou il ne doit pas y avoir de système de volume)
image [images]
L'image de disque ou de partition à lire, dont le format est donné avec « -i ». Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné, et que son nom est le premier d'une séquence (par exemple, s'il se termine par « .001 »), les segments d'image suivants seront inclus automatiquement.
repertoire_sortie
Le répertoire dans lequel enregistrer les fichiers récupérés.

EXEMPLES

Pour récupérer uniquement les fichiers non alloués de image.dd vers le répertoire récupéré :

# tsk_recover ./image.dd ./recupere
