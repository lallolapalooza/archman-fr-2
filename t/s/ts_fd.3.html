NOM

ts_fd - obtenir le descripteur de fichier d'un périphérique tactile

SYNTAXE

#include <tslib.h>

int ts_fd(struct tsdev *);

DESCRIPTION

ts_fd() obtient le descripteur de fichier d'un périphérique tactile ouvert.

VALEUR DE RETOUR

La valeur du descripteur de fichier est retournée. struct tsdev est retourné.

VOIR AUSSI

ts_setup(3), ts_close(3), ts_read(3), ts.conf(5)
