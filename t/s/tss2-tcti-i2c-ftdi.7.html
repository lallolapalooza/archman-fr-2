NOM

tcti-i2c-ftdi - Bibliothèque TCTI pour TPM basé sur I2C via USB

SYNOPIS

Un module d'interface de transmission de commandes TPM (TCTI) pour l'interaction avec un TPM basé sur I2C via le pont USB vers I2C MPSSE de FTDI.

DESCRIPTION

tcti-i2c-ftdi est une bibliothèque qui abstrait les détails de la communication avec un TPM basé sur I2C via le pont USB vers I2C MPSSE de FTDI. L'interface exposée par cette bibliothèque est définie dans la spécification "TSS System Level API and TPM Command Transmission Interface Specification".

AUTEUR

Projet de logiciel TPM2 https://github.com/tpm2-software/tpm2-tss

VOIR AUSSI

Tss2_Tcti_Device_Init(3), Tss2_Tcti_Socket_Init(3), Tss2_TctiLdr_Initialize(3), Tss2_TctiLdr_Finalize(3), tcti-device(7), tcti-socket(7), tcti-tabrmd(7), tpm2-abrmd(8)

COLOPHON

Cette page fait partie de la version 4.1.3 de l'implémentation open source du TCG TPM2 Software Stack (TSS2). Une description du projet, des informations sur le signalement de bugs et la dernière version de cette page sont disponibles sur https://github.com/tpm2-software/tpm2-tss/.
