ts_config(3)

Paquet: tslib

Licences: LGPL-2.1-only

TS_CONFIG(3) tslib TS_CONFIG(3)

NOM

ts_config, ts_reconfig - lire la configuration de tslib

SYNTAXE

#include <tslib.h>

int ts_config(struct tsdev *dev);

int ts_reconfig(struct tsdev *dev);

DESCRIPTION

ts_config() charge et initialise tous les modules configurés dans le fichier de configuration de tslib TSLIB_CONFFILE, voir ts.conf (5). ts_reconfig() ré-exécute ts_config et met à jour la configuration si le fichier de configuration a changé.

VALEUR DE RETOUR

Zéro est retourné en cas de succès. Une valeur négative est retournée en cas d'erreur.

VOIR AUSSI

ts_read(3), ts_open(3), ts_setup(3), ts_close(3), ts.conf(5)
