tss2_writeauthorizenv(1) Manuel des commandes générales tss2_writeauthorizenv(1)

NOM

tss2_writeauthorizenv(1) -

SYNOPSIS

tss2_writeauthorizenv [OPTIONS]

DESCRIPTION

tss2_writeauthorizenv(1) - Cette commande écrit la valeur du résumé (digest) d'une politique dans un index NV de telle sorte que cette politique puisse être utilisée dans d'autres politiques contenant un élément PolicyAuthorizeNv correspondant.

OPTIONS

Voici les options disponibles :

•
-p, --nvPath=CHAÎNE :

Le chemin de l'index NV.

•
-P, --policyPath=CHAÎNE :

Le chemin de la nouvelle politique.

OPTIONS COMMUNES

Cette collection d'options est commune à tous les programmes tss2 et fournit des informations que de nombreux utilisateurs peuvent attendre.

•
-h, --help [man|no-man] : Affiche la page man de l'outil. Par défaut, il tente d'appeler le pagineur man pour l'outil, cependant, en cas d'échec, il affichera un bref résumé de l'outil. Le comportement est le même si l'argument d'option “man” est spécifié, cependant si “man” est explicitement demandé, l'outil fournira des erreurs de man sur la sortie standard. Si l'option “no-man” est spécifiée, ou si le pagineur man échoue, les options courtes seront affichées sur la sortie standard.

Pour utiliser avec succès la fonctionnalité des pages man, il faut que les pages man soient installées ou présentes dans MANPATH. Voir man(1) pour plus de détails.

•
-v, --version : Affiche les informations de version pour cet outil, les tcti supportés et quitte.

EXEMPLE

tss2_writeauthorizenv --nvPath=/nv/Owner/myNV --policyPath=/policy/pcr-policy

RETOURNE

0 en cas de succès ou 1 en cas d'échec.
