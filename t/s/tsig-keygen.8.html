NOM

tsig-keygen - outil de génération de clés TSIG

SYNTAXE

tsig-keygen [-a algorithme] [-h] [nom]

DESCRIPTION

tsig-keygen est un utilitaire qui génère des clés pour utilisation avec TSIG (Transaction Signatures) tel que défini dans la RFC 2845 https://datatracker.ietf.org/doc/html/rfc2845.html. Les clés résultantes peuvent être utilisées, par exemple, pour sécuriser les mises à jour DNS dynamiques d'une zone, ou pour le canal de commande de rndc <#std-iscman-rndc>.

Un nom de domaine peut être spécifié sur la ligne de commande pour être utilisé comme nom de la clé générée. Si aucun nom n'est spécifié, le défaut est tsig-key.

OPTIONS

-a algorithme
Cette option spécifie l'algorithme à utiliser pour la clé TSIG. Les choix disponibles sont : hmac-md5, hmac-sha1, hmac-sha224, hmac-sha256, hmac-sha384, et hmac-sha512. Le défaut est hmac-sha256. Les options ne sont pas sensibles à la casse, et le préfixe "hmac-" peut être omis.
-h
Cette option affiche un bref résumé des options et des arguments.
