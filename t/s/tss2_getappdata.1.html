NOM

tss2_getappdata(1)

SYNTAXE

tss2_getappdata [OPTIONS]

VOIR AUSSI

fapi-config(5) pour ajuster les paramètres Fapi tels que le profil cryptographique utilisé et le TCTI ou les répertoires pour les stockages de métadonnées Fapi.

fapi-profile(5) pour déterminer les algorithmes cryptographiques et les paramètres pour toutes les clés et opérations d'une interaction TPM spécifique comme l'algorithme de hachage de nom, l'algorithme de signature asymétrique, le schéma et les paramètres, ainsi que la sélection de la banque PCR.

DESCRIPTION

tss2_getappdata(1) - Cette commande retourne les données d'application précédemment stockées pour un objet.

OPTIONS

Voici les options disponibles :

•
-f, --force:

Forcer l'écrasement du fichier de sortie.

•
-p, --path=CHAINE:

Chemin de l'objet pour lequel les données d'application seront chargées.

•
-o, --appData=NOMFICHIER ou - (pour stdout):

Retourne une copie des données stockées. Paramètre optionnel.

OPTIONS COMMUNES

Cette collection d'options est commune à tous les programmes tss2 et fournit des informations que de nombreux utilisateurs peuvent attendre.

•
-h, --help [man|no-man]: Affiche la page de manuel de l'outil. Par défaut, il tente d'invoquer le pager de manuel pour l'outil, mais en cas d'échec, il affiche un bref résumé de l'outil. C'est le même comportement si l'argument d'option « man » est spécifié, mais si « man » est explicitement demandé, l'outil fournira les erreurs de man sur stderr. Si l'option « no-man » est spécifiée, ou si le pager de manuel échoue, les options courtes seront affichées sur stdout.

Pour utiliser correctement la fonctionnalité des pages de manuel, il faut que celles-ci soient installées ou présentes dans MANPATH. Voir man(1) pour plus de détails.

•
-v, --version: Affiche les informations de version pour cet outil, les TCTI pris en charge et quitte.

EXEMPLE

tss2_getappdata --path=HS/SRK/myRSACrypt --appData=appData.file

RETOUR

0 en cas de succès ou 1 en cas d'échec.
