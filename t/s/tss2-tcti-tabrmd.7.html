NOM

tcti-tabrmd - Bibliothèque TCTI de tabrmd

SYNOPSIS

Un module TCTI (TPM Command Transmission Interface) pour l'interaction avec tpm2-abrmd.

DESCRIPTION

tcti-tabrmd est une bibliothèque qui abstrait la magie IPC nécessaire pour communiquer avec tpm2-abrmd. Consultez la “TSS System Level API and TPM Command Transmission Interface Specification” pour une discussion détaillée de l'API TCTI.

AUTEUR

Philip Tricca <philip.b.tricca@intel.com>
