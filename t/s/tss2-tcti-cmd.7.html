NOM

tcti-cmd - Bibliothèque TCTI de commande de sous-processus TPM2

SYNOPSIS

Un module TPM Command Transmission Interface (TCTI) pour l'interaction avec un sous-processus.

DESCRIPTION

tcti-cmd est une bibliothèque qui abstrait les détails de la communication directe avec l'interface et le protocole exposés par un sous-processus capable de recevoir et de transmettre des tampons bruts de commandes et de réponses TPM2. L'interface exposée par cette bibliothèque est définie dans la spécification “TSS System Level API and TPM Command Transmission Interface Specification”.

EXEMPLES

Par exemple, si vous vouliez utiliser la commande tpm2_send(1) comme sous-processus pour envoyer et recevoir des données du TPM, vous pourriez le faire comme suit :

tpm2_getrandom -T "cmd:tpm2_send -s" --hex 4

Un exemple plus utile serait de se connecter à une machine distante en utilisant ssh et d'interagir avec le TPM de la machine distante comme s'il était local. Cela utilise tpm2_send(1) sur une machine distante et utilise ssh comme sous-processus pour créer le tunnel vers la machine distante. Si des sessions chiffrées sont utilisées, la machine distante est aveuglée aux données du TPM et ne peut pas intercepter ce trafic.

tpm2_getrandom -T "cmd:ssh remotehost tpm2_send" -s --hex 4
