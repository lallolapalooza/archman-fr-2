NOM

tcti-i2c-helper - bibliothèque de pilote de périphérique TCTI

SYNOPIS

Un module d'interface de transmission de commandes TPM (TCTI) pour la communication via I2C. Pilote de périphérique TPM.

DESCRIPTION

tcti-i2c-helper est une bibliothèque qui abstrait les détails de la communication avec un TPM via le protocole I2C. Elle utilise des méthodes fournies par l'utilisateur pour les opérations I2C et de temporisation afin d'être indépendante de la plateforme. Ces méthodes sont fournies à `Tss2_Tcti_I2c_Helper_Init` via la structure `TSS2_TCTI_I2C_HELPER_PLATFORM`.
