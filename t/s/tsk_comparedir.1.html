TSK_COMPAREDIR(1) Manuel des commandes générales TSK_COMPAREDIR(1)

NOM

tsk_comparedir - comparer le contenu d'un répertoire avec le contenu d'une image ou d'un périphérique local.

SYNTAXE

tsk_comparedir [-vV] [-n inum_départ ] [ -f type_système_fichiers ] [ -i type_image ] [ -b taille_secteur_périphérique ] [ -o décalage_secteur ] image [images] répertoire_comparaison

DESCRIPTION

tsk_comparedir compare le contenu de image avec le contenu de répertoire_comparaison. Ceci peut être utile pour détecter des rootkits et lors des tests. Les rootkits peuvent être détectés en comparant le contenu d'un répertoire local et d'un périphérique brut local. Les rootkits ne cachent généralement pas les données lorsqu'elles sont lues directement à partir du périphérique brut.

Les arguments sont les suivants :

-o décalage_secteur
Décalage de secteur pour une partition dans l'image ou le périphérique à comparer.
-n inum_départ
Inum de départ pour un répertoire dans l'image pour commencer la comparaison.
-v
sortie verbeuse sur stderr
-V
Afficher la version
-f type_système_fichiers
Spécifier le type de système de fichiers. Utiliser '-f list' pour lister les types de systèmes de fichiers pris en charge. S'il n'est pas donné, des méthodes de détection automatique sont utilisées.
-i type_image
Le format du fichier image, tel que 'raw'. Utiliser '-i list' pour lister les types pris en charge. S'il n'est pas donné, des méthodes de détection automatique sont utilisées.
-b taille_secteur_périphérique
La taille (en octets) des secteurs du périphérique. S'il n'est pas donné, des méthodes de détection automatique sont utilisées.
image [images]
L'image disque ou de partition à lire, dont le format est indiqué avec '-i'. Plusieurs noms de fichiers image peuvent être donnés si l'image est divisée en plusieurs segments. Si un seul fichier image est donné, et que son nom est le premier d'une séquence (par exemple, indiqué par une terminaison '.001'), les segments d'image suivants seront inclus automatiquement.

EXEMPLES

Pour comparer les répertoires dans image.dd avec ceux dans directory :

# tsk_comparedir ./image.dd ./directory
