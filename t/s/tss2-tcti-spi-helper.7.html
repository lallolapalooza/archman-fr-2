NOM

tcti-spi-helper - bibliothèque TCTI du pilote de périphérique

SYNOPSIS

Une interface de transmission de commandes TPM (TCTI) pour la communication via SPI. Pilote de périphérique TPM.

DESCRIPTION

tcti-spi-helper est une bibliothèque qui abstrait les détails de la communication avec un TPM via le protocole SPI. Elle utilise des méthodes fournies par l'utilisateur pour les opérations SPI et de temporisation afin d'être indépendante de la plateforme. Ces méthodes sont fournies à `Tss2_Tcti_Spi_Init` via la structure `TSS2_TCTI_SPI_PLATFORM`.
