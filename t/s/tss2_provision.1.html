tss2_provision(1) Manuel des commandes générales tss2_provision(1)

NOM

tss2_provision(1) -

SYNTAXE

tss2_provision [OPTIONS]

VOIR AUSSI

fapi-config(5) pour ajuster les paramètres de Fapi tels que le profil cryptographique utilisé et les TCTI ou les répertoires pour les stockages de métadonnées de Fapi.

fapi-profile(5) pour déterminer les algorithmes cryptographiques et les paramètres pour toutes les clés et opérations d'une interaction TPM spécifique, comme l'algorithme de hachage de nom, l'algorithme de signature asymétrique, le schéma et les paramètres, ainsi que la sélection des banques PCR.

DESCRIPTION

tss2_provision(1) - Cette commande provisionne une instance FAPI et son TPM associé. Les étapes suivies sont :

•
Récupère le modèle EK (Endorsement Key), le nonce et le certificat, vérifie qu'ils correspondent à l'EK du TPM et les stocke dans le magasin de clés.
•
Définit les valeurs d'autorisation et les politiques pour le propriétaire (hiérarchie de stockage), l'administrateur de confidentialité (hiérarchie d'approbation) et l'autorité de verrouillage.
•
Scanne les index NV (Non-Volatile) du TPM et crée des entrées dans le magasin de métadonnées FAPI. Cette opération PEUT utiliser une heuristique pour deviner les programmes d'origine des index NV trouvés et nommer les entrées en conséquence.
•
Crée la SRK (Storage Root Key) à l'intérieur du TPM et la rend persistante si requis par le profil cryptographique (cf., fapi-profile(5)) et stocke ses métadonnées dans le magasin de métadonnées FAPI à l'échelle du système. Notez que la SRK n'aura pas de valeur d'autorisation associée.

Si une valeur d'autorisation est associée à la hiérarchie de stockage, il est fortement recommandé de rendre la SRK sans valeur d'autorisation persistante.

Les chemins des différents stockages de métadonnées pour les clés et les index NV sont configurés dans le fichier de configuration FAPI (cf., fapi-config(5)).

OPTIONS

Voici les options disponibles :

•
-E, --authValueEh=CHAÎNE : La valeur d'autorisation pour l'administrateur de confidentialité, c'est-à-dire la hiérarchie d'approbation. Paramètre optionnel.
•
-S, --authValueSh=CHAÎNE : La valeur d'autorisation pour le propriétaire, c'est-à-dire la hiérarchie de stockage. Paramètre optionnel.
•
-L, --authValueLockout=CHAÎNE : La valeur d'autorisation pour l'autorisation de verrouillage. Paramètre optionnel.

OPTIONS COMMUNES

Cette collection d'options sont communes à tous les programmes tss2 et fournissent des informations que de nombreux utilisateurs peuvent attendre.

•
-h, --help [man|no-man] : Affiche la page de manuel de l'outil. Par défaut, il tente d'appeler le paginator de manuel pour l'outil, cependant, en cas d'échec, il affichera un bref résumé de l'outil. C'est le même comportement si l'argument d'option « man » est spécifié, cependant si « man » explicite est demandé, l'outil fournira les erreurs de man sur stderr. Si l'option « no-man » est spécifiée, ou si le paginator de manuel échoue, les options courtes seront affichées sur stdout.

Pour utiliser correctement la fonctionnalité des pages de manuel, celles-ci doivent être installées ou présentes dans MANPATH. Voir man(1) pour plus de détails.

•
-v, --version : Affiche les informations de version pour cet outil, les TCTI pris en charge et quitte.

EXEMPLE

tss2_provision

RETOURNE

0 en cas de succès ou 1 en cas d'échec.
