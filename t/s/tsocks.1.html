TSOCKS(1) Manuel des commandes générales TSOCKS(1)

NOM

tsocks - Script de wrapper pour simplifier l'utilisation de la bibliothèque tsocks(8) afin de permettre à une application d'utiliser transparencement un proxy SOCKS

SYNTAXE

tsocks [application [arguments de l'application]]
ou tsocks [on|off]
ou tsocks

DESCRIPTION

tsocks est un wrapper entre la bibliothèque tsocks et l'application que vous souhaitez exécuter avec socksification.

OPTIONS

[application [arguments de l'application]]
exécute l'application telle que spécifiée avec l'environnement (LD_PRELOAD) configuré de telle sorte que tsocks(8) proxyera transparentement les connexions SOCKS dans ce programme.
[on|off]
cette option ajoute ou supprime tsocks(8) de la variable d'environnement LD_PRELOAD. Lorsque tsocks(8) est dans cette variable, toutes les applications exécutées sont automatiquement socksifiées. Si vous souhaitez utiliser cette fonction, VOUS DEVEZ sourcer le script shell depuis le vôtre, comme ceci : « source /usr/bin/tsocks » ou « . /usr/bin/tsocks »
Exemple :
« . tsocks on » -- ajoute la bibliothèque tsocks à LD_PRELOAD
« . tsocks off » -- supprime la bibliothèque tsocks de LD_PRELOAD
[show|sh]
affiche la valeur actuelle de la variable LD_PRELOAD.
<sans argument>
crée un nouveau shell avec LD_PRELOAD incluant tsocks(8).

AUTEUR

Ce script a été créé par Tamas SZERB <toma@rulez.org> pour le paquet debian de tsocks. Il (ainsi que cette page de manuel) a depuis été adapté dans le projet principal tsocks et modifié.
