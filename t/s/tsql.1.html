NOM

tsql — utilitaire pour tester les connexions et les requêtes FreeTDS

SYNTAXE

tsql {-S nomserveur [-I interface] | -H nomhote [-L] [-p port]} [-D nombase] [-U utilisateur] [-P motdepasse] [-o options]

tsql -C

DESCRIPTION

tsql est un outil de diagnostic FreeTDS. Il utilise le protocole TDS pour se connecter à un serveur Sybase ou Microsoft SQL Server, et permet à l'utilisateur d'émettre des requêtes. tsql n'utilise pas les bibliothèques clientes FreeTDS. Il utilise plutôt uniquement la bibliothèque de plus bas niveau, libtds, pour tester l'implémentation du protocole.

tsql peut être exécuté de deux manières : une qui utilise freetds.conf et une autre qui se connecte directement en utilisant le nom d'hôte et le port du serveur. Les paramètres -H et -p sont fournis pour permettre à l'utilisateur de vérifier qu'un serveur écoute sur l'hôte et le port nommés. Ces paramètres remplacent tous les fichiers de configuration et variables d'environnement. Le paramètre -S peut être utilisé pour tester la configuration locale. FreeTDS utilisera freetds.conf (ou son équivalent) et les variables d'environnement de la manière habituelle pour déterminer l'adresse IP et le port du serveur. Vous pouvez utiliser -I pour spécifier un nom de fichier, remplaçant ainsi l'algorithme de recherche de fichier de configuration de FreeTDS.

OPTIONS

-S nomserveur
serveur de base de données auquel se connecter.
-D nombase
base de données à utiliser.
-I interface
fichier freetds.conf ou d'interfaces décrivant le nomserveur.
-H nomhote
nom d'hôte DNS du serveur.
-p port
port sur lequel SQL Server écoute.
-U utilisateur
nom de connexion à la base de données. Si l'utilisateur n'est pas fourni, une connexion de domaine est tentée pour les connexions TDS 7+.
-P motdepasse
mot de passe de la base de données.
-L
lister les instances de serveur Microsoft (avec -H).
-C
afficher certains paramètres de configuration à la compilation.
-o options
appliquer les options spécifiées à chaque commande.
-f
Pas de pied de page [nombre de résultats]
-h
Pas d'en-tête [titres]
-t
Afficher le temps
-v
Afficher la version
-q
Silencieux
-a nomapp
nom de l'application.
-t terminateurcol
terminateur de colonne.
-r terminateurligne
terminateur de ligne.
-r terminateurligne
terminateur de ligne.
-J jeu
jeu de caractères.
-v
mode verbeux.

NOTES

Si vous pouvez vous connecter avec ‘tsql -S nomserveur’,votre installation FreeTDS de base fonctionne.

Taper ‘exit’,‘quit’,ou ‘bye’ (ou ^D) quitte tsql.

Taper ‘version’ affiche la version du protocole TDS.

Les lots de commandes peuvent être séparés par ‘go’ ou ‘GO’.Si ‘GO’ est utilisé, la chaîne de version est rapportée avant l'exécution du lot.

Après avoir demandé le mot de passe (s'il n'est pas fourni avec -P), tsql tentera de se connecter au serveur distant. tsql affiche un compteur indiquant le nombre de secondes écoulées pendant la tentative de connexion. Typiquement, tsql répond immédiatement avec un invite ‘1>’. Si vous voyez le compteur (1, 2, 3, ...), il est très probable que tsql ne puisse pas se connecter au serveur indiqué.

tsql ne remplace pas un isql complet comme sqsh (www.sqsh.org). Si vous avez des suggestions pour rendre tsql plus utile en tant qu'outil de diagnostic, veuillez les poster sur la liste de diffusion FreeTDS pour considération.

HISTORIQUE

tsql est apparu pour la première fois dans FreeTDS 0.60.
