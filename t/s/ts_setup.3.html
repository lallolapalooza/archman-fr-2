NOM

ts_setup - trouver, ouvrir et configurer un périphérique d'entrée à écran tactile

SYNTAXE

#include <tslib.h>

struct tsdev *ts_setup(const char *dev_name, int nonblock);

DESCRIPTION

ts_setup() tentera de trouver, d'ouvrir et de configurer le périphérique d'écran tactile. En cas de succès, il allouera de la mémoire pour un nouveau périphérique d'écran tactile, ouvrira et liera le périphérique d'événements d'entrée à celui-ci, puis chargera et initialisera tous les modules configurés dans le fichier de configuration tslib TSLIB_CONFFILE.

Si dev_name est NULL, ts_setup() utilisera le périphérique défini par la variable d'environnement TSLIB_TSDEVICE.

Si TSLIB_TSDEVICE n'est pas défini, ts_setup() essaiera d'utiliser les périphériques suivants :

/dev/input/ts,
/dev/input/touchscreen,
/dev/touchscreen/ucb1x00.
Après cela, ts_setup() parcourt /dev/input/event* pour trouver le premier périphérique avec la propriété INPUT_PROP_DIRECT.

VALEUR DE RETOUR

Un pointeur vers le struct tsdev ouvert est retourné.

VOIR AUSSI

ts_open(3), ts_close(3), ts_read(3), ts_config(3), ts.conf(5)
