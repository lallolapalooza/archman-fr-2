NOM

tss2_getrandom(1) - # SYNOPSIS

tss2_getrandom [OPTIONS]

VOIR AUSSI

fapi-config(5) pour ajuster les paramètres de Fapi comme le profil cryptographique utilisé et le TCTI ou les répertoires pour les stockages de métadonnées Fapi.

fapi-profile(5) pour déterminer les algorithmes cryptographiques et les paramètres pour toutes les clés et opérations d'une interaction TPM spécifique comme l'algorithme de hachage de nom, l'algorithme de signature asymétrique, le schéma et les paramètres, et la sélection de la banque PCR.

DESCRIPTION

tss2_getrandom(1) - Cette commande utilise le TPM pour créer un tableau d'octets aléatoires.

OPTIONS

Voici les options disponibles :

•
-n, --numBytes=ENTIER:

Le nombre d'octets demandé par l'appelant.

•
-f, --force:

Forcer l'écrasement du fichier de sortie.

•
-o, --data=NOMFICHIER ou - (pour stdout):

Les octets aléatoires retournés.

•
--hex

Convertir les données de sortie au format hexadécimal sans le préfixe « 0x ».

OPTIONS COMMUNES

Cette collection d'options est commune à tous les programmes tss2 et fournit des informations que de nombreux utilisateurs peuvent attendre.

•
-h, --help [man|no-man]: Afficher la page man de l'outil. Par défaut, il tente d'invoquer le manpager pour l'outil, cependant, en cas d'échec, il affichera un bref résumé de l'outil. Ceci est le même comportement si l'argument d'option « man » est spécifié, cependant si « man » est explicitement demandé, l'outil fournira des erreurs de man sur stderr. Si l'option « no-man » est spécifiée, ou si le manpager échoue, les options courtes seront affichées sur stdout.

Pour utiliser avec succès la fonctionnalité des pages man, il faut que les pages man soient installées ou présentes dans MANPATH. Voir man(1) pour plus de détails.

•
-v, --version: Afficher les informations de version pour cet outil, les tctis pris en charge et quitter.

EXEMPLE

    tss2_getrandom --numBytes=20 --data=- | hexdump -C

RETOUR

0 en cas de succès ou 1 en cas d'échec.
