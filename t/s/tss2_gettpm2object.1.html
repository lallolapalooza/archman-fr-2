tss2_gettpm2object(1) Manuel des commandes générales tss2_gettpm2object(1)

NOM

tss2_gettpm2object(1)

SYNTAXE

tss2_gettpm2object [OPTIONS]

VOIR AUSSI

fapi-config(5) pour ajuster les paramètres de Fapi tels que le profil cryptographique utilisé et le TCTI, ou les répertoires pour les stockages de métadonnées de Fapi.

fapi-profile(5) pour déterminer les algorithmes et paramètres cryptographiques pour toutes les clés et opérations d'une interaction TPM spécifique, comme l'algorithme de hachage de nom, l'algorithme de signature asymétrique, le schéma et les paramètres, ainsi que la sélection de la banque PCR.

DESCRIPTION

tss2_gettpm2object(1) - Avec cette commande, des fichiers de contexte d'objets FAPI qui peuvent être utilisés par les commandes de l'outil tpm2 peuvent être créés. Pour les objets persistants, seule la représentation textuelle du numéro de handle sous forme de nombre hexadécimal sera écrite, et pour les clés, un fichier de contexte d'outil tpm2 sera écrit. Si le TCTI par défaut diffère du profil FAPI, le TCTI par défaut peut être défini avec l'option -T (–tcti). Note Pour éviter un état de nv_written incorrect dans le keystore avant d'écrire des données dans la RAM NV avec tpm2_nvwrite, une chaîne vide au minimum devrait être écrite avec tss2_nvwrite.

OPTIONS

Voici les options disponibles :

•
-f, --force :

Forcer l'écrasement du fichier de sortie.

•
-p, --path=CHAÎNE :

Chemin de l'objet pour lequel les données de l'application seront chargées.

•
-c, --context=NOMDEFichier ou - (pour stdout) :

Le contexte de clé ou le handle retourné.

OPTIONS COMMUNES

Cette collection d'options est commune à tous les programmes tss2 et fournit des informations que de nombreux utilisateurs peuvent attendre.

•
-h, --help [man|no-man] : Affiche la page de manuel de l'outil. Par défaut, il tente d'appeler le pager de manuel pour l'outil, cependant, en cas d'échec, il affichera un bref résumé de l'outil. C'est le même comportement si l'argument d'option “man” est spécifié, cependant si “man” est explicitement demandé, l'outil fournira les erreurs de man sur stderr. Si l'option “no-man” est spécifiée, ou si le pager de manuel échoue, les options courtes seront affichées sur stdout.

Pour utiliser avec succès la fonctionnalité des pages de manuel, il est nécessaire que les pages de manuel soient installées ou présentes dans MANPATH. Voir man(1) pour plus de détails.

•
-v, --version : Affiche les informations de version pour cet outil, les TCTI pris en charge et quitte.

EXEMPLES

tss2_gettpm2object --path=/HS/SRK/myRSACrypt --key-context=mykey.ctx
tss2_gettpm2object --path=/nv/Owner/mynv -c-

La commande peut être utilisée dans les options des commandes tpm2 :

handle=$(tss2_gettpm2object --path=/nv/Owner/mynv -c-)
tpm2_nvread $handle

RETOUR

0 en cas de succès ou 1 en cas d'échec.
