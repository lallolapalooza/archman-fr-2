NOM

tslminfo - obtenir des informations sur un modèle de langage à décroissance exponentielle threadé

SYNTAXE

tslminfo [option]... fichier_threaded_slm

DESCRIPTION

slminfo fournit des informations sur le modèle de langage à décroissance exponentielle 'fichier_threaded_slm'. Il peut également imprimer le modèle au format ARPA. Lorsqu'aucune option n'est fournie, slminfo imprimera uniquement le nombre d'éléments dans chaque niveau du modèle de langage.

OPTIONS

-v,--verbose
Activer le mode verbeux, imprimer au format arpa.
-p,--pr
Préférer la probabilité normale à -log(Pr) qui est la valeur par défaut. Valide sous l'option -v.
-l,--lexicon fichier_dictionnaire
Spécifier le lexique. Valide sous l'option -v. Substituer l'identifiant du mot par le texte du mot dans la sortie.
