NOM

tcti-swtpm - bibliothèque TCTI de simulateur TPM

SYNOPSIS

Un module TCTI (TPM Command Transmission Interface) pour l'interaction avec le simulateur logiciel TPM2.

DESCRIPTION

tcti-swtpm est une bibliothèque qui abstrait les détails de la communication directe avec l'interface et le protocole exposés par le démon hébergeant l'implémentation de référence TPM2. L'interface exposée par cette bibliothèque est définie dans la spécification « TSS System Level API and TPM Command Transmission Interface Specification ».

NOTES

Il est préférable de ne pas utiliser l'interface CUSE lors de la configuration de swtpm, mais plutôt d'utiliser le proxy du module vtpm :

modprobe tpm_vtpm_proxy
swtpm chardev --vtpm-proxy --tpmstate dir=... --tpm2 ...
