NOM

ts_error_fn - utiliser une fonction d'erreur personnalisée pour les erreurs de la bibliothèque libts

SYNTAXE

#include <tslib.h>

int (*ts_error_fn)(const char *fmt, va_list ap);

DESCRIPTION

ts_error_fn() est implémenté par défaut de manière similaire à ceci :

static int errfn(const char *fmt, va_list ap)
{
        return vfprintf(stderr, fmt, ap);
}

à l'intérieur de la bibliothèque. Il est exposé à l'utilisateur et peut être remplacé par une fonction d'erreur personnalisée. Il suffit d'assigner votre implémentation personnalisée à ts_error_fn comme ceci :

ts_error_fn = my_custom_errfn;

Elle peut être utilisée pour écrire dans les fichiers journaux système, par exemple. Le programme de test ts_print_mt contient un exemple.

VALEUR DE RETOUR

défini par l'utilisateur.

VOIR AUSSI

ts_read(3), ts_open(3), ts_setup(3), ts_close(3), ts.conf(5)
