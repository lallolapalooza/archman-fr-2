tss2_changeauth(1) Manuel général des commandes tss2_changeauth(1)

NOM

tss2_changeauth(1) - Change les données d'autorisation d'une entité référencée par le chemin.

SYNTAXE

tss2_changeauth [OPTIONS]

VOIR AUSSI

fapi-config(5) pour ajuster les paramètres Fapi tels que le profil cryptographique utilisé et le TCTI ou les répertoires pour les stockages de métadonnées Fapi.

fapi-profile(5) pour déterminer les algorithmes cryptographiques et les paramètres pour toutes les clés et opérations d'une interaction TPM spécifique, telles que l'algorithme de hachage de nom, l'algorithme de signature asymétrique, le schéma et les paramètres, et la sélection de la banque PCR.

DESCRIPTION

tss2_changeauth(1) -

OPTIONS

Voici les options disponibles :

•
-a, --authValue=CHAÎNE :

Le nouveau mot de passe UTF-8. Paramètre facultatif. S'il est omis, l'utilisateur est invité interactivement à saisir un mot de passe. Pour définir aucun mot de passe, cette option doit être utilisée avec une chaîne vide (""). La taille maximale du mot de passe est déterminée par la taille du digest de l'algorithme de hachage de nom choisi dans le profil cryptographique (cf., fapi-profile(5)). Par exemple, choisir SHA256 comme algorithme de hachage permet des mots de passe d'une taille maximale de 32 caractères.

•
-p, --entityPath=CHAÎNE :

Le chemin identifiant l'entité à modifier.

OPTIONS COMMUNES

Cette collection d'options est commune à tous les programmes tss2 et fournit des informations que de nombreux utilisateurs peuvent attendre.

•
-h, --help [man|no-man] : Affiche le manuel de l'outil. Par défaut, il tente d'appeler le visionneur de manuel pour l'outil, cependant, en cas d'échec, il affichera un bref résumé de l'outil. C'est le même comportement si l'argument de l'option « man » est spécifié, cependant si « man » est explicitement demandé, l'outil fournira les erreurs de man sur stderr. Si l'option « no-man » est spécifiée, ou si le visionneur de manuel échoue, les options courtes seront affichées sur stdout.

Pour utiliser avec succès la fonctionnalité des manuels, il faut que les manuels soient installés ou sur MANPATH. Voir man(1) pour plus de détails.

•
-v, --version : Affiche les informations de version de cet outil, les TCTI pris en charge et quitte.

EXEMPLES

Changer un mot de passe pour une entité HS/SRK/myRSACryptKey en M1

tss2_changeauth --entityPath=HS/SRK/myRSACryptKey --authValue=M1

Changer un mot de passe pour une entité HS/SRK/myRSACryptKey et demander à l'utilisateur de saisir le mot de passe.

tss2_changeauth --entityPath=HS/SRK/myRSACryptKey

RETOURS

0 en cas de succès ou 1 en cas d'échec.
