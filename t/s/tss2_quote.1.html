tss2_quote(1) Manuel des commandes générales tss2_quote(1)

NOM

tss2_quote(1) -

SYNOPSIS

tss2_quote [OPTIONS]

VOIR AUSSI

fapi-config(5) pour ajuster les paramètres Fapi tels que le profil cryptographique utilisé et le TCTI ou les répertoires pour les stockages de métadonnées Fapi.

fapi-profile(5) pour déterminer les algorithmes cryptographiques et les paramètres pour toutes les clés et opérations d'une interaction TPM spécifique, comme l'algorithme de hachage de nom, l'algorithme de signature asymétrique, le schéma et les paramètres, et la sélection de la banque PCR.

DESCRIPTION

tss2_quote(1) - Cette commande effectue une attestation à l'aide du TPM. La banque PCR pour chaque indice PCR fourni et le schéma de signature sont définis dans le profil cryptographique (cf., fapi-profile(5)).

OPTIONS

Voici les options disponibles :

•
-x, --pcrList=CHAÎNE :

Un tableau contenant les indices PCR à citer.

•
-Q, --qualifyingData=FICHIER ou - (pour stdin) :

Un nonce fourni par l'appelant pour assurer la fraîcheur de la signature. Paramètre optionnel.

•
-l, --pcrLog=FICHIER ou - (pour stdout) :

Retourne le journal PCR pour le PCR choisi. Paramètre optionnel.

Les journaux d'événements PCR sont une liste (tableau JSON de longueur arbitraire) d'entrées de journal avec le contenu suivant.

- recnum : Numéro d'enregistrement unique
- pcr : Indice du PCR
- digest : Les digests
- type : Le type d'événement. Actuellement, la seule valeur possible est : "LINUX_IMA" (IMA legacy)
- eventDigest : Digest de l'événement ; par exemple, le digest du fichier mesuré
- eventName : Nom de l'événement ; par exemple, le nom du fichier mesuré.
•
-f, --force :

Forcer l'écrasement du fichier de sortie.

•
-p, --keyPath=CHAÎNE :

Identifie la clé de signature.

•
-q, --quoteInfo=FICHIER ou - (pour stdout) :

Retourne une structure encodée en JSON contenant les entrées de l'opération de citation. Cela inclut la valeur du digest et les valeurs PCR.

•
-o, --signature=FICHIER ou - (pour stdout) :

Retourne la signature sur le matériel cité.

•
-c, --certificate=FICHIER ou - (pour stdout) :

Le certificat associé à keyPath au format PEM. Paramètre optionnel.

OPTIONS COMMUNES

Cette collection d'options est commune à tous les programmes tss2 et fournit des informations que de nombreux utilisateurs peuvent attendre.

•
-h, --help [man|no-man] : Affiche la page de manuel de l'outil. Par défaut, il tente d'appeler le programme de pagination man pour l'outil, mais en cas d'échec, il affiche un bref résumé de l'outil. C'est le même comportement si l'argument d'option “man” est spécifié, mais si “man” est explicitement demandé, l'outil fournira les erreurs de man sur stderr. Si l'option “no-man” est spécifiée, ou si le programme de pagination man échoue, les options courtes seront affichées sur stdout.

Pour utiliser avec succès la fonctionnalité des pages de manuel, il est nécessaire que les pages de manuel soient installées ou présentes dans MANPATH. Voir man(1) pour plus de détails.

•
-v, --version : Affiche les informations de version pour cet outil, les tctis pris en charge et quitte.

EXEMPLE

tss2_quote --keyPath=HS/SRK/quotekey --pcrList="10,16" --qualifyingData=qualifyingData.file --signature=signature.file --pcrLog=pcrLog.file --certificate=certificate.file --quoteInfo=quoteInfo.info

RETOURNE

0 en cas de succès ou 1 en cas d'échec.
