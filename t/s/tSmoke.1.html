NOM

tSmoke - Outil en ligne de commande pour envoyer des informations SmokePing

SYNOPIS

tSmoke [ --testmail | --morning | --weekly | --version | --help | --man | --slaves ]

Options :
--man      Afficher la page de manuel
--help     Aide :-)
--version  Afficher la version de SmokePing
--testmail Envoyer un message de test
--listrrds Lister les RRD utilisés par ce Smokeping
--morning  Envoyer un résumé matinal
--weekly   Envoyer un rapport de statut hebdomadaire
--to       Adresse e-mail pour envoyer le message (par exemple : '--to=xyz@company.com.invalid'
--detail   Niveau de détail à envoyer dans le rapport hebdomadaire (par exemple : '--detail=1')
--quiet    Ne pas afficher le message de bienvenue
--slaves   Activer la prise en charge des esclaves, suppose tous les esclaves sauf si une liste CSV d'esclaves
           est ajoutée (par exemple : '--slaves' ou '--slaves=esclave1[,esclave2...]')

DESCRIPTION

L'outil tSmoke est un outil en ligne de commande qui s'interface avec le système SmokePing. Sa fonction principale est d'envoyer un message indiquant l'état actuel des systèmes surveillés par Smokeping ou un fichier de courrier HTML contenant l'état du jour précédent, de la semaine précédente et du mois précédent, y compris un aperçu.

Exemples typiques de crontab pour invoquer cet outil sont :

# Alerte matinale rapide pour voir ce qui est en panne
0 6 * * * /usr/local/smokeping/bin/tSmoke.pl --q --to=mobilephone@att.net.invalid --morning
# Rapport hebdomadaire sur le pourcentage de disponibilité des systèmes réseau sans détail
0 8 * * * /usr/local/smokeping/bin/tSmoke.pl --q --to=mailbox@company.com.invalid --weekly --detail=0

INSTALLATION

Lors de l'installation de tSmoke, certaines variables doivent être ajustées pour correspondre à votre système local.

Nous devons utiliser les bibliothèques suivantes :

Smokeping
Bindings Perl pour RRDTool
Getopt::Long

Configurez vos bibliothèques :

use lib "/usr/local/smokeping/lib";
use lib "/usr/local/rrdtool-1.0.39/lib/perl";

Pointez vers le fichier de configuration de Smokeping

my $cfgfile = "/usr/local/smokeping/etc/config";

Modifiez le fichier de configuration de Smokeping pour inclure un chemin pour tmail dans la section Générale :

tmail = /usr/local/smokeping/etc/tmail
