tss2_createnv(1) Manuel des commandes générales tss2_createnv(1)

NOM

tss2_createnv(1) -

SYNOPSIS

tss2_createnv [OPTIONS]

VOIR AUSSI

fapi-config(5) pour ajuster les paramètres Fapi tels que le profil cryptographique utilisé et le TCTI, ou les répertoires pour les stockages de métadonnées Fapi.

fapi-profile(5) pour déterminer les algorithmes cryptographiques et les paramètres pour toutes les clés et opérations d'une interaction TPM spécifique, comme l'algorithme de hachage de nom, l'algorithme de signature asymétrique, le schéma et les paramètres, et la sélection de la banque PCR.

DESCRIPTION

tss2_createnv(1) - Cette commande crée un index NV dans le TPM.

OPTIONS

Voici les options disponibles :

•
-p, --path=CHAÎNE:

Chemin du nouvel espace NV.

Le chemin est composé de trois éléments, séparés par “/”. Un chemin NV commence par “/nv”. Le deuxième élément du chemin identifie la plage de descripteurs NV pour l'objet nv. Cela inclut les valeurs suivantes : Owner, TPM, Platform, Endorsement_Certificate, Platform_Certificate, Component_OEM, TPM_OEM, Platform_OEM, PC-Client, Server, Virtualized_Platform, MPWG, Embedded. Le troisième élément du chemin identifie l'index NV réel à l'aide d'un nom significatif.

•
-t, --type=CHAÎNE:

Identifie l'utilisation prévue. Paramètre optionnel. Les types peuvent être toute combinaison séparée par des virgules de :

- « noda » : Définit l'attribut noda d'une clé ou d'un index NV.
- « bitfield » : Définit le type NV sur bitfield.
- « counter » : Définit le type NV sur counter.
- « pcr » : Définit le type NV sur un comportement similaire à PCR.
- Astuce : Si aucun des trois mots-clés précédents n'est fourni, un index NV
  régulier est créé.
•
-s, --size=ENTIER:

La taille en octets de l'index NV à créer. Peut être omis si la taille peut être déduite du type ; par exemple, un index NV de type counter a une taille de 8 octets.

•
-P, --policyPath=CHAÎNE:

Identifie la politique à associer au nouvel espace NV. Paramètre optionnel. Si omis, aucune politique ne sera associée à la clé.

Un chemin de politique est composé de deux éléments, séparés par “/”. Un chemin de politique commence par “/policy”. Le deuxième élément du chemin identifie la politique ou le modèle de politique à l'aide d'un nom significatif.

•
-a, --authValue=CHAÎNE:

Le nouveau mot de passe UTF-8. Paramètre optionnel. S'il est omis, l'utilisateur est invité interactivement à saisir un mot de passe. Pour définir aucun mot de passe, cette option doit être utilisée avec la chaîne vide (““). La taille maximale du mot de passe est déterminée par la taille du digest de l'algorithme de hachage de nom choisi dans le profil cryptographique (cf., fapi-profile(5)). Par exemple, choisir SHA256 comme algorithme de hachage, permet des mots de passe d'une taille maximale de 32 caractères.

OPTIONS COMMUNES

Cette collection d'options est commune à tous les programmes tss2 et fournit des informations que de nombreux utilisateurs peuvent attendre.

•
-h, --help [man|no-man]: Affiche la page man de l'outil. Par défaut, il tente d'appeler le gestionnaire de pages man pour l'outil, cependant, en cas d'échec, il affichera un bref résumé de l'outil. C'est le même comportement si l'argument d'option « man » est spécifié, cependant, si « man » est explicitement demandé, l'outil fournira des erreurs de man sur stderr. Si l'option « no-man » est spécifiée, ou si le gestionnaire de pages man échoue, les options courtes seront affichées sur stdout.

Pour utiliser avec succès la fonctionnalité des pages man, il est nécessaire que les pages man soient installées ou présentes dans MANPATH. Voir man(1) pour plus de détails.

•
-v, --version: Affiche les informations de version pour cet outil, les tctis pris en charge et quitte.

EXEMPLE

tss2_createnv --authValue=abc --path=/nv/Owner/myNV --size=20 --type="noDa"

RETOUR

0 en cas de succès ou 1 en cas d'échec.
