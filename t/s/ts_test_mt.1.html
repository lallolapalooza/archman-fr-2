NOM

ts_test_mt - Un programme de test multitouche basique pour tslib.

SYNTAXE

ts_test_mt [OPTION]

DESCRIPTION

ts_test_mt est utilisé pour tester tslib avec ts_read_mt(), voir ts_read_mt (3). Il peut être utilisé pour les appareils à contact unique et multi-contacts et vous permet de tester le comportement d'entrée avec les filtres de tslib appliqués. Deux modes sont proposés par des boutons à l'écran :

En mode Drag, un réticule pour chaque contact tactile effectué simultanément est dessiné sur l'écran du framebuffer.

En mode Draw, des lignes sont tracées pour chaque contact tactile.

-r, --rotate [valeur]

Fait pivoter l'écran. valeur est 0 pour 0 degré, 1 pour 90 degrés (sens horaire), 2 pour 180 degrés (à l'envers) et 3 pour 270 degrés (sens antihoraire).

-v, --verbose

Affiche les valeurs des échantillons d'entrée sur la console.

-j, --slots

Remplace le nombre de contacts tactiles simultanés à allouer.

-i, --idev

Choisit explicitement le périphérique d'événement d'entrée original que tslib doit utiliser. Par défaut : la valeur de la variable d'environnement TSLIB_TSDEVICE.

-n, --samples

Quitte automatiquement après avoir lu n échantillons.

-a, --altcross

Affiche un symbole de réticule alternatif aux points tactiles.

VOIR AUSSI

ts.conf (5), ts_calibrate (1), ts_uinput (1), ts_test (1)
