Paquet: tslib

Licences: LGPL-2.1-only

TSLIB_VERSION(3) tslib TSLIB_VERSION(3)

NOM

tslib_version - retourne simplement la chaîne de version de tslib

SYNTAXE

#include <tslib.h>

char *tslib_version();

DESCRIPTION

tslib_version() Cette fonction retourne une chaîne statique contenant les informations de version de tslib.

VOIR AUSSI

ts_libversion(3), ts.conf(5)
