NOM

tspin - Un surligneur de fichiers journaux

SYNTAXE

tspin [OPTION]... [FICHIER]...

DESCRIPTION

tailspin est un outil en ligne de commande qui surligne les fichiers journaux.

OPTIONS

-f, --follow

Suivre (tail) le contenu du fichier. Toujours vrai lors de l'utilisation de l'indicateur --follow-command.

-p, --print

Afficher la sortie sur stdout au lieu de visualiser le contenu dans le paginator less. Toujours vrai si on utilise stdin.

--config-path CHEMIN_CONFIG

Spécifier le chemin vers un fichier de configuration personnalisé. Par défaut XDG_CONFIG_HOME/tailspin/theme.toml ou ~/.config/tailspin/theme.toml s'il n'est pas défini.

-e, --exec COMMANDE

Exécuter une commande et visualiser la sortie dans un paginator. La commande intercepte le signal d'interruption pour permettre d'annuler et de reprendre le mode suivi lorsqu'on est dans less.

Exemple :

tspin --listen-command 'kubectl logs -f pod_name'

--highlight COULEUR1:mot1,mot2,... COULEUR2:mot3,mot4,...

Surligner les mots séparés par des virgules dans la couleur spécifiée. Les couleurs possibles sont rouge, vert, jaune, bleu, magenta et cyan.

Exemple :

tspin logfile.txt --highlight red:error,fail --highlight green:success,ok

--enable=[GROUPE_SURGLIGNAGE]

Désactiver tous les groupes de surlignage sauf ceux spécifiés. Liste de groupes séparés par des virgules. Ne peut pas être utilisé avec --disable=[GROUPE_SURGLIGNAGE].

--disable=[GROUPE_SURGLIGNAGE]

Désactiver les groupes de surlignage spécifiés. Liste de groupes séparés par des virgules. Ne peut pas être utilisé avec --enable=[GROUPE_SURGLIGNAGE].

--disable-builtin-keywords

Désactive le surlignage de tous les groupes de mots-clés intégrés (booléens, sévérité et REST).

VARIABLES D'ENVIRONNEMENT

TAILSPIN_PAGER

Définissez la variable d'environnement TAILSPIN_PAGER pour remplacer le paginator par défaut. La commande doit inclure la chaîne [FILE] qui sera remplacée par le chemin du fichier en interne. Par exemple, "ov -f [FILE]".

VOIR AUSSI

less(1), tail(1)
