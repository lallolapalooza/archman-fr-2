NOM

tss2-tctildr - Simplifie la gestion du cycle de vie des instances TCTI.

SYNOPIS

Cette bibliothèque simplifie l'instanciation et la finalisation des instances TCTI.

DESCRIPTION

Le protocole de chargement dynamique et d'initialisation TCTI nécessite beaucoup de code répétitif. Pour réduire les duplications, la bibliothèque tss2-tctildr ajoute les fonctions Tss2_TctiLdr_Initialize(), Tss2_TctiLdr_Initialize_Ex() et Tss2_TctiLdr_Finalize() pour abstraire la machinerie nécessaire au chargement, à l'initialisation et à la finalisation d'un contexte TCTI.

Pour faciliter la découverte des TCTI, cette bibliothèque fournit la fonction Tss2_TctiLdr_GetInfo(). Cette fonction, associée à une fonction de « libération » pour libérer la mémoire allouée par « GetInfo », fournit une interface de requête simple pour découvrir les TCTI disponibles et par défaut implémentés par tss2-tctildr.

L'interface exposée par cette bibliothèque est définie dans le « TSS System Level API and TPM Command Transmission Interface Specification ».
