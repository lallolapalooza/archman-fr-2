NOM

tcti-spidev - Bibliothèque TCTI pour accéder aux TPM via spidev

SYNOPSIS

Un module TCTI (TPM Command Transmission Interface) pour l'interaction avec un TPM connecté à un nœud de périphérique spidev.

DESCRIPTION

tcti-spidev est une bibliothèque qui abstrait les détails de communication avec un TPM connecté à un nœud de périphérique spidev. L'interface exposée par cette bibliothèque est définie dans la spécification « TSS System Level API and TPM Command Transmission Interface Specification ». La configuration de ce TCTI prend le chemin du fichier vers le nœud de périphérique (Défaut : /dev/spidev0.1).
