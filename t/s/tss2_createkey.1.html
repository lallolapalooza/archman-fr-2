tss2_createkey(1) Manuel des commandes générales tss2_createkey(1)

NOM

tss2_createkey(1) -

SYNTAXE

tss2_createkey [OPTIONS]

VOIR AUSSI

fapi-config(5) pour ajuster les paramètres Fapi tels que le profil cryptographique utilisé et le TCTI ou les répertoires pour les stockages de métadonnées Fapi.

fapi-profile(5) pour déterminer les algorithmes et paramètres cryptographiques pour toutes les clés et opérations d'une interaction TPM spécifique, comme l'algorithme de hachage de nom, l'algorithme de signature asymétrique, le schéma et les paramètres, ainsi que la sélection de la banque PCR.

DESCRIPTION

tss2_createkey(1) - Cette commande crée une clé dans le TPM et la stocke dans le magasin de métadonnées Fapi et, si demandé, de manière persistante dans le TPM. Selon le type de clé spécifié, les algorithmes et paramètres cryptographiques pour la clé créée sont déterminés par le profil cryptographique correspondant (voir fapi-profile(5)).

OPTIONS

Voici les options disponibles :

•
-p, --path=CHAÎNE:

Le chemin d'accès à la nouvelle clé.

•
-t, --type=CHAÎNE:

Identifie l'utilisation prévue. Paramètre optionnel. Les types peuvent être une combinaison de types séparés par des virgules :

- "sign" : Définit l'attribut de signature d'une clé.
- "decrypt" : Définit l'attribut de déchiffrement d'une clé.
- Indice : Si ni 'sign' ni 'decrypt' ne sont fournis, les deux attributs sont définis.
- "restricted" : Définit l'attribut restreint d'une clé.
- Indice : Si 'restricted' est défini, 'sign' ou 'decrypt' (mais pas les deux) doivent être définis.
- "exportable" : Efface les attributs fixedTPM et fixedParent d'une clé ou d'un objet scellé.
- "noda" : Définit l'attribut noda d'une clé ou d'un index NV.
- "system" : Stocke les blobs de données et les métadonnées d'une clé ou d'un scellage créé dans le répertoire système au lieu du répertoire personnel de l'utilisateur.
- Un nombre hexadécimal (par exemple, "0x81000001") : Marque un objet clé pour être rendu persistant et définit le handle de l'objet persistant à cette valeur.
•
-P, --policyPath=CHAÎNE:

La politique à associer à la nouvelle clé. Paramètre optionnel. Si omis, aucune politique ne sera associée à la clé.

Un policyPath est composé de deux éléments, séparés par “/”. Un policyPath commence par “/policy”. Le second élément du chemin identifie la politique ou le modèle de politique à l'aide d'un nom significatif.

•
-a, --authValue=CHAÎNE:

Le nouveau mot de passe UTF-8. Paramètre optionnel. S'il est omis, l'utilisateur sera invité interactivement à entrer un mot de passe. Pour définir aucun mot de passe, cette option doit être utilisée avec une chaîne vide (““). La taille maximale du mot de passe est déterminée par la taille du digest de l'algorithme de hachage de nom choisi dans le profil cryptographique (voir fapi-profile(5)). Par exemple, choisir SHA256 comme algorithme de hachage permet des mots de passe d'une taille maximale de 32 caractères.

OPTIONS COMMUNES

Cette collection d'options est commune à tous les programmes tss2 et fournit des informations que de nombreux utilisateurs peuvent attendre.

•
-h, --help [man|no-man]: Affiche le manuel de l'outil. Par défaut, il tente d'appeler le pagineur de manuel pour l'outil, cependant, en cas d'échec, il affichera un bref résumé de l'outil. Le comportement est le même si l'argument d'option “man” est spécifié, cependant si “man” est explicitement demandé, l'outil affichera les erreurs de man sur stderr. Si l'option “no-man” est spécifiée, ou si le pagineur de manuel échoue, les options courtes seront affichées sur stdout.

Pour utiliser avec succès la fonctionnalité des pages de manuel, il faut que les pages de manuel soient installées ou présentes dans le fichier MANPATH. Voir man(1) pour plus de détails.

•
-v, --version: Affiche les informations de version pour cet outil, les tctis pris en charge et quitte.

EXEMPLE

Créer une clé sans mot de passe

tss2_createkey --path=HS/SRK/myRsaCryptKey --type="noDa, decrypt" --authValue=""

Créer une clé, demander le mot de passe sur la ligne de commande

tss2_createkey --path=HS/SRK/myRsaCryptKey --type="noDa, decrypt"

Créer une clé avec le mot de passe “abc”.

tss2_createkey --path=HS/SRK/myRsaCryptKey --type="noDa, decrypt" --authValue=abc

RETOUR

0 en cas de succès ou 1 en cas d'échec.
