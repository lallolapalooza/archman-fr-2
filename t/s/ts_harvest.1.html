NOM

ts_harvest - Récolte des centaines de coordonnées brutes de l'écran tactile.

SYNTAXE

ts_harvest

DESCRIPTION

ts_harvest peut être utilisé pour linéariser les écrans tactiles non linéaires tels que ceux trouvés dans le périphérique h2200. Les coordonnées de l'écran tactile sont enregistrées dans ts_harvest.out

VOIR AUSSI

ts.conf(5), ts_test(1), ts_test_mt(1), ts_calibrate(1)
