tss2_nvextend(1) Manuel des commandes générales tss2_nvextend(1)

NOM

tss2_nvextend(1) -

SYNTAXE

tss2_nvextend [OPTIONS]

VOIR AUSSI

fapi-config(5) pour ajuster les paramètres Fapi tels que le profil cryptographique utilisé et le TCTI ou les répertoires pour les stockages de métadonnées Fapi.

fapi-profile(5) pour déterminer les algorithmes et paramètres cryptographiques pour toutes les clés et opérations d'une interaction TPM spécifique, comme l'algorithme de hachage de nom, l'algorithme de signature asymétrique, le schéma et les paramètres, ainsi que la sélection de la banque PCR.

DESCRIPTION

tss2_nvextend(1) - Cette commande effectue une opération d'extension sur un index NV (c'est-à-dire un index NV qui se comporte de manière similaire à un PCR).

OPTIONS

Voici les options disponibles :

•
-i, --data=NOMFICHIER ou - (pour stdin) :

Les données à étendre dans l'espace NV.

•
-p, --nvPath=CHAÎNE :

Identifie l'espace NV à écrire.

•
-l, --logData=NOMFICHIER ou - (pour stdin) :

Une représentation JSON des données à écrire dans le journal d'événements du PCR. Paramètre optionnel.

OPTIONS COMMUNES

Cette collection d'options est commune à tous les programmes tss2 et fournit des informations que de nombreux utilisateurs peuvent attendre.

•
-h, --help [man|no-man] : Affiche la page de manuel de l'outil. Par défaut, il tente d'appeler le pagineur man pour l'outil, cependant, en cas d'échec, il affichera un bref résumé de l'outil. C'est le même comportement si l'argument d'option « man » est spécifié, cependant si « man » est explicitement demandé, l'outil fournira les erreurs de man sur stderr. Si l'option « no-man » est spécifiée, ou si le pagineur man échoue, les options courtes seront affichées sur stdout.

Pour utiliser correctement la fonctionnalité des pages de manuel, il faut que les pages de manuel soient installées ou sur MANPATH, voir man(1) pour plus de détails.

•
-v, --version : Affiche les informations de version pour cet outil, les TCTI pris en charge et quitte.

EXEMPLE

tss2_nvextend --nvPath=/nv/Owner/NvExtend --data=data.file --logData=logData.file

RETOUR

0 en cas de succès ou 1 en cas d'échec.
