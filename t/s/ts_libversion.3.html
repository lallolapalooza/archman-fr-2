ts_libversion(3)

Paquet: tslib

TS_LIBVERSION(3) tslib TS_LIBVERSION(3)

NOM

ts_libversion - obtenir des informations de version sur la tslib en cours d'exécution

SYNTAXE

#include <tslib.h>

struct ts_lib_version_data *ts_libversion();

DESCRIPTION

ts_libversion() Cette fonction retourne un pointeur vers une copie statique de la structure d'informations de version :

struct ts_lib_version_data {
        const char      *package_version;
        int             version_num;
        unsigned int    features;
};

package_version est simplement la chaîne contenant le numéro de version de la sortie de compilation, par exemple "1.10".

version_num est un nombre de 24 bits créé comme ceci : <8 bits de numéro majeur> | <8 bits de numéro mineur> | <8 bits de numéro de correctif> de la bibliothèque libts. La version 0.7.1 est donc retournée comme 0x000701.

features peut avoir un ou plusieurs bits définis. Les bits actuellement définis sont :

TSLIB_VERSION_MT le filtrage tslib prend en charge le multitouch ts_read_mt() et il existe au moins un module d'accès brut qui le prend en charge (actuellement evdev input) TSLIB_VERSION_OPEN_RESTRICTED les pointeurs de fonction ts_open_restricted et ts_close_restricted sont disponibles pour implémenter TSLIB_VERSION_EVENTPATH ts_get_eventpath() est disponible puisque tslib peut détecter automatiquement un périphérique TSLIB_VERSION_VERSION les fonctions simples tslib_version() et ts_print_ascii_logo() sont disponibles

VALEUR DE RETOUR

Cette fonction retourne un pointeur vers une copie statique de la structure d'informations de version.

VOIR AUSSI

ts_setup(3), ts_read(3), ts.conf(5)
