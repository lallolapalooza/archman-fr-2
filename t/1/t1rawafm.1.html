T1RAWAFM(1) Manuel des commandes générales T1RAWAFM(1)

NOM

t1rawafm - produire des métriques AFM brutes à partir d'une police PostScript Type 1

SYNTAXE

t1rawafm [OPTIONS...] [police [fichier_sortie]]

DESCRIPTION

T1rawafm génère un fichier AFM avec les informations disponibles dans une police PostScript Type 1. Le fichier AFM manquera de crans, d'informations sur les ligatures et de caractères composites, mais sera sinon utilisable. Le fichier AFM est écrit sur la sortie standard (mais voir l'option --output). Si aucun fichier de police d'entrée n'est fourni, t1rawafm lit une police PFA ou PFB depuis l'entrée standard.

OPTIONS

--output=fichier, -o fichier
Envoyer la sortie vers fichier au lieu de la sortie standard.
-h, --help
Afficher les informations d'utilisation et quitter.
--version
Afficher le numéro de version et des informations courtes non garanties, puis quitter.

VALEURS DE RETOUR

T1rawafm se termine avec la valeur 0 si un fichier de métriques AFM a été généré avec succès, et 1 sinon.

VOIR AUSSI

Adobe Type 1 Font Format, Adobe Font Metrics File Format Specification v4.1
