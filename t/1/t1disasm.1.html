T1DISASM(1) Manuel des commandes générales T1DISASM(1)

NOM

t1disasm - désassembler une police PostScript Type 1

SYNTAXE

t1disasm [entrée [sortie]]

DESCRIPTION

t1disasm désassemble les programmes de polices Adobe Type 1 au format PFA (hexadécimal) ou PFB (binaire) en une forme lisible par l'homme. Si le fichier sortie n'est pas spécifié, la sortie est envoyée à la sortie standard. Si le fichier entrée n'est pas spécifié, l'entrée provient de l'entrée standard.

t1disasm effectue le déchiffrement eexec et charstring comme spécifié dans le « livre noir », Adobe Type 1 Font Format. De plus, les tokens binaires de charstring sont développés en une forme textuelle lisible, en utilisant les noms donnés dans le livre noir et les documents ultérieurs décrivant les opcodes Type 2.

EXEMPLES

% t1disasm Utopia-Regular.pfb Utopia-Regular.raw
% t1disasm Utopia-Regular.pfa Utopia-Regular.raw

Dans Subrs, les entrées dans Utopia-Regular.raw ressembleront à

dup 5 {
        8 111 vstem
        -12 128 hstem
        707 -20 hstem
        return
        } |
et les entrées CharStrings ressembleront à 
/exclam {
        58 242 hsbw
        6 callsubr
        5 4 callsubr
        63 707 rmoveto
        -54 0 -5 -22 4 -45 rrcurveto
        40 -431 rlineto
        29 hlineto
        42 431 rlineto
        4 45 -5 22 -55 0 rrcurveto
        closepath
        6 4 callsubr
        -719 vmoveto
        243 callsubr
        endchar
        } |-

VOIR AUSSI

t1asm(1), t1ascii(1), t1binary(1), t1unmac(1), t1mac(1)

Adobe Type 1 Font Format est disponible gratuitement auprès d'Adobe sous forme de fichier PDF : http://partners.adobe.com/asn/developer/PDFS/TN/T1_SPEC.PDF

The Type 2 Charstring Format, également disponible auprès d'Adobe sous forme de fichier PDF, décrit les opérateurs Type 2 plus récents, qui sont également utilisés dans certaines polices Type 1 multiple-master comme Adobe Jenson et Kepler : http://partners.adobe.com/asn/developer/PDFS/TN/5177.Type2.pdf
