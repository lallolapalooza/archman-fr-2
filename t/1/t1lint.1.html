NOM

t1lint - vérifie la correction d'une police PostScript Type 1

SYNTAXE

t1lint police [police...]

DESCRIPTION

T1lint vérifie la correction des programmes de polices PostScript Type 1. Toutes les erreurs ou divergences par rapport à la spécification sont signalées sur la sortie d'erreur standard. S'il n'y a pas d'erreurs, la commande ne produit rien. Elle se termine avec le statut 0 si toutes les polices étaient correctes, et le statut 1 sinon. Si aucun fichier d'entrée n'est fourni, t1lint lit une police depuis l'entrée standard.

OPTIONS

-q, --quiet
Ne génère aucun message d'erreur. La seule sortie sera le code de sortie.
-h, --help
Affiche les informations d'utilisation et quitte.
-v, --version
Affiche le numéro de version et quelques courtes informations non garanties, puis quitte.
