T1MAC(1) Manuel des commandes générales T1MAC(1)

NOM

t1mac - Traduit une police PostScript Type 1 PFA ou PFB en format Macintosh

SYNOPIS

t1mac [--macbinary | --applesingle | --appledouble | --binhex | --raw] [--filename nom] [entrée [sortie]]

DESCRIPTION

t1mac lit un fichier de police PostScript Type 1 PFA (hexadécimal) ou PFB (binaire) et génère un fichier de police Macintosh Type 1 équivalent. Le fichier de sortie peut être au format MacBinary II, AppleSingle, AppleDouble ou BinHex, ou il peut s'agir d'une fork de ressources brute. Le format par défaut est MacBinary II ; utilisez une option pour choisir un format différent. Si le fichier sortie n'est pas spécifié, la sortie est dirigée vers la sortie standard.

AVERTISSEMENT : La sortie de t1mac n'est pas suffisante pour utiliser la police, car les Macintosh ne peuvent pas lire les polices Type 1 brutes. Vous devrez créer une valise de polices contenant des polices bitmap si vous n'avez pas déjà une telle valise pour la police. t1mac ne peut pas vous aider dans cette tâche.

OPTIONS

--raw, -r
Indique que la sortie doit être une fork de ressources brute.
--macbinary
Indique que la sortie doit être au format MacBinary I ou II. C'est le défaut.
--applesingle
Indique que la sortie doit être au format AppleSingle.
--appledouble
Indique que la sortie doit être au format AppleDouble.
--binhex
Indique que la sortie doit être au format BinHex 4.0.
--filename=nom, -n nom
Définit le nom de fichier Macintosh de la police de sortie sur nom. Le défaut est de construire le nom de fichier à partir du nom de la police en utilisant les conventions Macintosh établies. Cette option n'est pas utile lorsque la sortie est une fork de ressources brute.
