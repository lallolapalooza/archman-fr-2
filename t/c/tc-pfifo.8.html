PBFIFO(8) Linux PBFIFO(8)

NOM

pfifo - File d'attente à taille limitée en paquets, premier entré, premier sorti (First In, First Out)

bfifo - File d'attente à taille limitée en octets, premier entré, premier sorti (First In, First Out)

SYNOPIS

tc qdisc ... add pfifo [ limit paquets ]

tc qdisc ... add bfifo [ limit octets ]

DESCRIPTION

Les qdiscs pfifo et bfifo sont des files d'attente premier entré, premier sorti sans fioritures. Ce sont les files d'attente les plus simples possibles et donc sans surcharge. pfifo contraint la taille de la file d'attente mesurée en paquets. bfifo le fait mesurée en octets.

Comme tous les qdiscs non par défaut, ils maintiennent des statistiques. Cela pourrait être une raison de préférer pfifo ou bfifo au défaut.

ALGORITHME

Une liste de paquets est maintenue, lorsqu'un paquet est mis en file d'attente, il est inséré à la fin d'une liste. Lorsqu'un paquet doit être envoyé sur le réseau, il est retiré du début de la liste.

Si la liste est trop longue, aucun paquet supplémentaire n'est autorisé. C'est ce qu'on appelle le 'tail drop' (chute en queue).

PARAMÈTRES

limit
Taille maximale de la file d'attente. Spécifiée en octets pour bfifo, en paquets pour pfifo. Pour pfifo, la valeur par défaut est la txqueuelen de l'interface, telle que spécifiée avec ip(8). La plage pour ce paramètre est [0, UINT32_MAX].

Pour bfifo, la valeur par défaut est la txqueuelen multipliée par la MTU de l'interface. La plage pour ce paramètre est [0, UINT32_MAX] octets.

Remarque : L'en-tête de la couche de liaison a été pris en compte lors du comptage de la longueur des paquets.

SORTIE

La sortie de tc -s qdisc ls contient la limite, soit en paquets, soit en octets, et le nombre d'octets et de paquets réellement envoyés. Un paquet non envoyé et abandonné n'apparaît qu'entre parenthèses et n'est pas compté comme 'Envoyé'.

Dans cet exemple, la longueur de la file d'attente est de 100 paquets, 45894 octets ont été envoyés sur 681 paquets. Aucun paquet n'a été abandonné, et comme la file d'attente pfifo ne ralentit pas les paquets, il n'y a pas eu de dépassements :

# tc -s qdisc ls dev eth0
qdisc pfifo 8001: dev eth0 limit 100p
 Sent 45894 bytes 681 pkts (dropped 0, overlimits 0)

Si un backlog se produit, il est également affiché.
