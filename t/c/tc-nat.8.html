NOM

nat - action de traduction d'adresse native sans état

SYNTAXE


tc ... action nat DIRECTION ANCIEN NOUVEAU

DIRECTION := { ingress | egress }

ANCIEN := IPV4_ADDR_SPEC

NOUVEAU := IPV4_ADDR_SPEC

IPV4_ADDR_SPEC := { default | any | all | in_addr[/{prefix|netmask}

DESCRIPTION

L'action nat permet d'effectuer du NAT sans la surcharge de conntrack, ce qui est souhaitable si le nombre de flux ou d'adresses à traduire est important. Cette action est mieux utilisée en combinaison avec le filtre u32 pour permettre des recherches efficaces d'un grand nombre de règles NAT sans état en temps constant.

OPTIONS

ingress
Traduit les adresses de destination, c'est-à-dire effectue un DNAT.
egress
Traduit les adresses source, c'est-à-dire effectue un SNAT.
ANCIEN
Spécifie les adresses qui doivent être traduites.
NOUVEAU
Spécifie les adresses dans lesquelles ANCIEN doit être traduit.

NOTES

Le format d'adresse accepté pour ANCIEN et NOUVEAU est très flexible. Il peut soit consister en l'un des mots-clés default, any ou all, représentant l'adresse IP tout-zéro, soit en une combinaison d'adresse IP et de masque réseau ou de longueur de préfixe séparés par un signe slash (/). Dans tous les cas, le masque (ou la longueur de préfixe) de ANCIEN est également utilisé pour NOUVEAU, de sorte qu'une correspondance un à un des adresses soit assurée.

La traduction d'adresses est effectuée à l'aide d'une combinaison d'opérations binaires. Premièrement, l'adresse d'origine (source ou destination) est comparée à la valeur de ANCIEN. Si l'adresse d'origine correspond, la nouvelle adresse est créée en prenant les bits de tête de NOUVEAU (définis par le masque réseau de ANCIEN) et en prenant les bits restants de l'adresse d'origine.

Il existe un support rudimentaire pour les protocoles de couche supérieure, à savoir TCP, UDP et ICMP. Alors que pour les deux premiers seul le recalcul de la somme de contrôle est effectué, l'action prend également en charge les en-têtes IP intégrés dans les paquets ICMP en traduisant également l'adresse respective.
