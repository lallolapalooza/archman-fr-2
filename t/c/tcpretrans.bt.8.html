NOM

tcpretrans.bt - Tracer ou compter les retransmissions TCP. Utilise bpftrace/eBPF de Linux

SYNTAXE

tcpretrans.bt

DESCRIPTION

Trace les retransmissions TCP, affichant l'adresse, le port et les informations d'état TCP, et parfois le PID (bien que généralement pas, car les retransmissions sont généralement envoyées par le noyau en cas de dépassement de délai). Pour maintenir une surcharge très faible, seules les fonctions de retransmission TCP sont tracées. Cela ne trace pas chaque paquet (comme tcpdump(8) ou un analyseur de paquets). Optionnellement, il peut compter les retransmissions sur un intervalle signalé par l'utilisateur pour repérer les chemins réseau potentiellement en perte que les flux traversent.

Ceci utilise le traçage dynamique des fonctions du noyau tcp_retransmit_skb() et tcp_send_loss_probe(), et devra être mis à jour pour correspondre aux changements du noyau concernant ces fonctions.

Comme ceci utilise BPF, seul l'utilisateur root peut utiliser cet outil.

EXIGENCES

CONFIG_BPF et bcc. CONFIG_BPF et bpftrace.

EXEMPLES

Tracer les retransmissions TCP :
# tcpretrans.bt

CHAMPOS

TEMPS
Heure de l'appel, au format HH:MM:SS.
PID
ID du processus qui était sur le CPU. Ceci est moins utile qu'il n'y paraît, car il peut souvent être 0, pour le noyau, pour les retransmissions basées sur un minuteur.
LADDR
Adresse IP locale.
LPORT
Port local.
RADDR
Adresse IP distante.
RPORT
Port distant.
ETAT
État de la session TCP.

SOUS-SURCHARGE

Devrait être négligeable : les événements de retransmission TCP devraient être peu nombreux (<1000/s), et la faible surcharge que cet outil ajoute à chaque événement devrait rendre le coût négligeable.
