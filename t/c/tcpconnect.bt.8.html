NOM

tcpconnect.bt - Trace les connexions TCP actives (connect()). Utilise bpftrace/eBPF de Linux

SYNOPSIS

tcpconnect.bt

DESCRIPTION

Cet outil trace les connexions TCP actives (par exemple, via un appel système connect() ; accept() correspond aux connexions passives). Ceci peut être utile pour le dépannage général afin de voir quelles connexions sont initiées par le serveur local.

Toutes les tentatives de connexion sont tracées, même si elles échouent finalement.

Cela fonctionne en traçant les fonctions noyau tcp_v4_connect() et tcp_v6_connect() à l'aide du traçage dynamique, et nécessitera une mise à jour pour correspondre à tout changement dans ces fonctions.

Comme cela utilise BPF, seul l'utilisateur root peut utiliser cet outil.

EXIGENCES

CONFIG_BPF et bpftrace.

EXEMPLES

Tracer toutes les connexions TCP actives :
# tcpconnect.bt

CHAMPS

HEURE(s)
Heure de l'appel, au format HH:MM:SS.
PID
Identifiant du processus.
COMM
Nom du processus.
SADDR
Adresse IP source.
SPORT
Port source.
DADDR
Adresse IP de destination.
DPORT
Port de destination.

SURCHARGE

Cela trace les fonctions noyau tcp_v[46]_connect et imprime la sortie pour chaque événement. Comme le taux de ceci est généralement attendu comme étant faible (< 1000/s), la surcharge est également attendue comme étant négligeable. Si vous avez une application qui appelle un taux élevé de connect()s, tel qu'un serveur proxy, testez et comprenez cette surcharge avant utilisation.
