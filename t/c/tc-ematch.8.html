tc-ematch(8)

Paquet: iproute2

Licences: GPL-2.0-or-later

ematch(8) Linux ematch(8)

NOM

ematch - correspondances étendues pour une utilisation avec les filtres « basic », « cgroup » ou « flow »

SYNTAXE

tc filter add .. basic match EXPR .. flowid ..

EXPR := TERM [ { and | or } EXPR ]

TERM := [ not ] { MATCH | '(' EXPR ')' }

MATCH := module '(' ARGS ')'

ARGS := ARG1 ARG2 ..

CORRESPONDANCES

cmp

Ematch de comparaison simple : comparaison arithmétique des données du paquet avec une valeur donnée.

cmp( ALIGN à OFFSET [ ATTRS ] { eq | lt | gt } VALUE )

ALIGN := { u8 | u16 | u32 }

ATTRS := [ layer LAYER ] [ mask MASK ] [ trans ]

LAYER := { link | network | transport | 0..2 }

meta

Ematch de métadonnées

meta( OBJECT { eq | lt |gt } OBJECT )

OBJECT := { META_ID | VALUE }

META_ID := id [ shift SHIFT ] [ mask MASK ]

attributs meta:

random valeur aléatoire de 32 bits

loadavg_1 Charge moyenne sur les 5 dernières minutes

nf_mark Marque Netfilter

vlan Tag VLAN

sk_rcvbuf Taille du tampon de réception

sk_snd_queue Longueur de la file d'envoi

Une liste complète des attributs meta peut être obtenue via

# tc filter add dev eth1 basic match 'meta(list)'

nbyte

Correspondance de séquences d'octets de données du paquet

nbyte( NEEDLE à OFFSET [ layer LAYER ] )

NEEDLE := { string | c-escape-sequence }

OFFSET := int

LAYER := { link | network | transport | 0..2 }

u32

Ematch u32

u32( ALIGN VALUE MASK à [ nexthdr+ ] OFFSET )

ALIGN := { u8 | u16 | u32 }

ipset

Teste l'appartenance du paquet à un ipset

ipset( SETNAME FLAGS )

SETNAME := string

FLAGS := { FLAG [, FLAGS] }

Les options de drapeau sont les mêmes que celles utilisées par la correspondance « set » d'iptables.

Lors de l'utilisation de l'ematch ipset avec le type de jeu « ip_set_hash:net,iface », l'interface peut être interrogée en utilisant la syntaxe « src,dst (adresse IP source, interface sortante) ou « src,src » (adresse IP source, interface entrante).

ipt

Teste le paquet par rapport aux correspondances xtables

ipt( [-6] -m MATCH_NAME FLAGS )

MATCH_NAME := string

FLAGS := { FLAG [, FLAGS] }

Les options de drapeau sont les mêmes que celles utilisées par la correspondance xtable.

canid

Règle d'ematch pour faire correspondre les trames CAN

canid( IDLIST )

IDLIST := IDSPEC[IDLIST]

IDSPEC := { ’sff’ CANID | ’eff’ CANID }

CANID := ID[:MASK]

ID, MASK := nombre hexadécimal (par exemple, 0x123)

LIMITATIONS

La syntaxe ematch utilise '(' et ')' pour grouper les expressions. Toutes les accolades doivent être correctement échappées pour empêcher la commande shell de les interpréter directement.

Lors de l'utilisation de l'ematch ipset avec le périphérique « ifb », le périphérique sortant sera le périphérique ifb lui-même, par exemple « ifb0 ». L'interface d'origine (c'est-à-dire le périphérique sur lequel le paquet est arrivé) est traitée comme l'interface entrante.

EXEMPLE & UTILISATION

# tc filter add .. basic match ...

# 'cmp(u16 at 3 layer 2 mask 0xff00 gt 20)'

# 'meta(nfmark gt 24)' and 'meta(tcindex mask 0xf0 eq 0xf0)'

# 'nbyte("ababa" at 12 layer 1)'

# 'u32(u16 0x1122 0xffff at nexthdr+4)'

Vérifie si l'adresse IP source du paquet est membre de l'ensemble nommé bulk :

# 'ipset(bulk src)'

Vérifie si l'adresse IP source du paquet et l'interface sur laquelle le paquet est arrivé sont membres de l'ensemble « hash:net,iface » nommé interactive :

# 'ipset(interactive src,src)'

Vérifie si le paquet correspond à un état IPSec avec reqid 1 :

# 'ipt(-m policy --dir in --pol ipsec --reqid 1)'
