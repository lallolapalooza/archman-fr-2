NOM

simple - action d'exemple de base

SYNTAXE


tc ... action simple [ sdata CHAÎNE ] [ index INDEX ] [ CONTRÔLE ]

CONTRÔLE := { reclassify | pipe | drop | continue | ok }

DESCRIPTION

Ceci est un exemple pédagogique plutôt qu'une action réellement utile. À chaque accès, il affiche la CHAÎNE donnée, qui peut être de longueur arbitraire.

OPTIONS

sdata CHAÎNE
La chaîne réelle à afficher.
index INDEX
Valeur d'index d'action optionnelle.
CONTRÔLE
Indique comment tc doit procéder après avoir exécuté l'action. Pour une description des valeurs de CONTRÔLE possibles, voir tc-actions(8).

EXEMPLES

L'exemple suivant fait que le noyau crie "ICMP entrant !" à chaque fois qu'il voit un ICMP entrant sur eth0. Étapes :

1)
Ajouter un qdisc d'entrée à eth0
2)
Démarrer une chaîne sur l'entrée de eth0 qui correspond d'abord à ICMP puis invoque l'action simple pour crier.
3)
Afficher les statistiques et montrer qu'aucun paquet n'a été vu par l'action
4)
Envoyer un paquet ping vers Google (attendre une réponse)
5)
grep les logs pour voir le message enregistré
6)
afficher à nouveau les statistiques et observer l'incrémentation de 1 
  $ tc qdisc add dev eth0 ingress
  $ tc filter add dev eth0 parent ffff: protocol ip prio 5 \
