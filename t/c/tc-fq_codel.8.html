NOM

CoDel - Fair Queuing (FQ) avec Controlled Delay (CoDel)

SYNTAXE

tc qdisc ... fq_codel [ limit PAQUETS ] [ flows NOMBRE ] [ target TEMPS ] [ interval TEMPS ] [ quantum OCTETS ] [ ecn | noecn ] [ ce_threshold TEMPS ] [ ce_threshold_selector VALEUR/MASQUE ] [ memory_limit OCTETS ]

DESCRIPTION

FQ_Codel (Fair Queuing Controlled Delay) est une discipline de mise en file d'attente qui combine le Fair Queuing avec le schéma AQM CoDel. FQ_Codel utilise un modèle stochastique pour classifier les paquets entrants en différents flux et est utilisé pour fournir une part équitable de la bande passante à tous les flux utilisant la file d'attente. Chaque flux est géré par la discipline de mise en file d'attente CoDel. Le réordonnancement au sein d'un flux est évité car CoDel utilise en interne une file FIFO.

PARAMÈTRES

limit

a la même sémantique que codel et est la limite stricte de la taille réelle de la file d'attente. Lorsque cette limite est atteinte, les paquets entrants sont supprimés. La valeur par défaut est 10240 paquets.

memory_limit

définit une limite sur le nombre total d'octets pouvant être mis en file d'attente dans cette instance FQ-Codel. La plus petite des deux limites, celle du paramètre limit (en paquets) et celle de la limite mémoire, sera appliquée. La valeur par défaut est 32 Mo.

flows

est le nombre de flux dans lesquels les paquets entrants sont classifiés. En raison de la nature stochastique du hachage, plusieurs flux peuvent finir par être hachés dans le même emplacement. Les flux plus récents ont la priorité sur les flux plus anciens. Ce paramètre ne peut être défini qu'au chargement car de la mémoire doit être allouée pour la table de hachage. La valeur par défaut est 1024.

target

a la même sémantique que codel et est le délai minimal acceptable de la file d'attente persistante. Ce délai minimal est identifié en suivant le délai minimal local de la file d'attente que les paquets subissent. La valeur par défaut est 5 ms.

interval

a la même sémantique que codel et est utilisé pour garantir que le délai minimal mesuré ne devienne pas trop obsolète. Le délai minimal doit être rencontré dans la dernière époque d'une longueur égale à interval. Il doit être défini sur l'ordre du RTT pire cas à travers le goulot d'étranglement pour donner aux points d'extrémité suffisamment de temps pour réagir. La valeur par défaut est 100 ms.

quantum

est le nombre d'octets utilisé comme « déficit » dans l'algorithme de file d'attente équitable. La valeur par défaut est fixée à 1514 octets, ce qui correspond à la MTU Ethernet plus la longueur de l'en-tête matériel de 14 octets.

ecn | noecn

a la même sémantique que codel et peut être utilisé pour marquer les paquets au lieu de les supprimer. Si ecn a été activé, noecn peut être utilisé pour le désactiver et vice-versa. Contrairement à codel, ecn est activé par défaut.

ce_threshold

définit un seuil au-dessus duquel tous les paquets sont marqués avec ECN Congestion Experienced. Ceci est utile pour les algorithmes de contrôle de congestion de type DCTCP qui nécessitent un marquage à des seuils de mise en file d'attente très faibles.

ce_threshold_selector

définit un filtre de sorte que la fonctionnalité ce_threshold soit appliquée uniquement à un sous-ensemble du trafic vu par le qdisc. Si elle est définie, la valeur MASQUE sera appliquée comme un ET bit à bit à l'octet diffserv/ECN de l'en-tête IP, et ce n'est que si le résultat de ce masquage est égal à VALEUR que la logique ce_threshold sera appliquée au paquet.

drop_batch

définit le nombre maximum de paquets à supprimer lorsque limit ou memory_limit est dépassé. La valeur par défaut est 64.

EXEMPLES

#tc qdisc add dev eth0 root fq_codel
#tc -s qdisc show
qdisc fq_codel 8002: dev eth0 root refcnt 2 limit 10240p flows 1024 quantum 1514
target 5.0ms interval 100.0ms ecn
Sent 428514 bytes 2269 pkt (dropped 0, overlimits 0 requeues 0)
backlog 0b 0p requeues 0
maxpacket 256 drop_overlimit 0 new_flow_count 0 ecn_mark 0
new_flows_len 0 old_flows_len 0

#tc qdisc add dev eth0 root fq_codel limit 2000 target 3ms interval 40ms noecn
#tc -s qdisc show
qdisc fq_codel 8003: dev eth0 root refcnt 2 limit 2000p flows 1024 quantum 1514 target 3.0ms interval 40.0ms
Sent 2588985006 bytes 1783629 pkt (dropped 0, overlimits 0 requeues 34869)
backlog 0b 0p requeues 34869
maxpacket 65226 drop_overlimit 0 new_flow_count 73 ecn_mark 0
new_flows_len 1 old_flows_len 3
