NOM

skbprio - File d'attente de priorité SKB

SYNTAXE

tc qdisc ... add skbprio [ limit paquets ]

DESCRIPTION

La file d'attente de priorité SKB (SKB Priority Queue) est une discipline de mise en file d'attente destinée à prioriser les paquets les plus importants lors d'une attaque par déni de service (DoS). La priorité d'un paquet est donnée par skb->priority, où une valeur plus élevée place le paquet plus près de la sortie de la file d'attente. Lorsque la file d'attente est pleine, le paquet de priorité la plus basse dans la file d'attente est supprimé pour faire de la place au paquet à ajouter s'il a une priorité plus élevée. Si le paquet à ajouter a une priorité inférieure à celle de tous les paquets de la file d'attente, il est supprimé.

Sans la file d'attente de priorité SKB, des limites de longueur de file d'attente doivent être imposées à des sous-files d'attente individuelles, et il n'existe aucun moyen simple d'imposer une limite de longueur de file d'attente globale sur toutes les priorités. La file d'attente SKBprio impose une limite de longueur de file d'attente globale tout en ne restreignant pas les longueurs des sous-files d'attente individuelles.

Bien que la file d'attente de priorité SKB soit agnostique quant à la manière dont skb->priority est attribué. Un cas d'utilisation typique consiste à copier le champ DS de 6 bits des paquets IPv4 et IPv6 à l'aide de tc-skbedit(8). Si skb->priority est supérieur ou égal à 64, la priorité est supposée être 63. Les priorités inférieures à 64 sont prises telles quelles.

La file d'attente de priorité SKB permet aux routeurs de décider localement quels paquets supprimer en cas d'attaque DoS. Les priorités doivent être attribuées aux paquets de telle sorte que plus la priorité est élevée, plus le comportement attendu d'une source est normal. Les sources ont donc intérêt à respecter les règles.

ALGORITHME

Skbprio maintient 64 listes (les priorités vont de 0 à 63). Lorsqu'un paquet est mis en file d'attente, il est inséré à la **fin** de sa liste de priorité. Lorsqu'un paquet doit être envoyé sur le réseau, il est pris à la tête de la liste de priorité la plus élevée. Lorsque la file d'attente est pleine, le paquet à la fin de la liste de priorité la plus basse est supprimé pour servir le paquet entrant - s'il est de priorité plus élevée, sinon le paquet entrant est supprimé. Cet algorithme alloue autant de bande passante que possible aux paquets de haute priorité, tout en ne desservant les paquets de basse priorité que lorsqu'il y a suffisamment de bande passante.

PARAMETRES

limite
Taille maximale de la file d'attente spécifiée en paquets. Elle est par défaut de 64. La plage pour ce paramètre est [0, UINT32_MAX].
