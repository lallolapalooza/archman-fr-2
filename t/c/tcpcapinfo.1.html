tcpcapinfo(1) Commandes utilisateur tcpcapinfo(1)

NOM

tcpcapinfo - Dissecteur de fichiers Pcap pour le débogage de fichiers pcap corrompus

SYNOPHIS

tcpcapinfo [-flags] [-flag [valeur]] [--option-name[[=| ]valeur]] <fichier(s)_pcap>

tcpcapinfo est un outil pour décoder la structure d'un fichier pcap(3) en mettant l'accent sur la recherche de fichiers pcap corrompus et la détermination des différences entre deux fichiers pcap apparentés.

DESCRIPTION

tcpcapinfo affichera d'abord l'en-tête du fichier pcap (pcap_file_header_t) sous une forme lisible par l'homme, suivi d'un résumé par paquet incluant l'en-tête du paquet (pcap_pkthdr_t) et une simple valeur de somme de contrôle du paquet.

OPTIONS

-d nombre, --dbug=nombre

Active la sortie de débogage. Cette option peut apparaître jusqu'à 1 fois. Cette option prend un nombre entier comme argument. La valeur de nombre est contrainte à être : 
dans la plage de 0 à 5

La valeur par défaut de nombre pour cette option est :
0

Si configuré avec --enable-debug, vous pouvez spécifier un niveau de verbosité pour la sortie de débogage. Des nombres plus élevés augmentent la verbosité.

-V, --version

Affiche les informations de version.
-H, --help

Affiche les informations d'utilisation et quitte.
-!, --more-help

Transmet les informations d'utilisation étendues à un paginator.
