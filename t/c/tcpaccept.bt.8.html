NOM

tcpaccept.bt - Trace les connexions TCP passives (accept()). Utilise bpftrace/eBPF

SYNTAXE

tcpaccept.bt

DESCRIPTION

Cet outil trace les connexions TCP passives (par ex. via un appel système accept() ; connect() sont des connexions actives). Ceci peut être utile pour le dépannage général afin de voir quelles nouvelles connexions le serveur local accepte.

Ceci utilise le traçage dynamique de la fonction de socket du noyau inet_csk_accept() (provenant de tcp_prot.accept), et devra être modifié pour correspondre aux changements du noyau.

Cet outil ne trace que les accept() TCP réussis. Les tentatives de connexion vers des ports fermés ne seront pas affichées (celles-ci peuvent être tracées via d'autres fonctions).

Étant donné que ceci utilise BPF, seul l'utilisateur root peut utiliser cet outil.

EXIGENCES

CONFIG_BPF et bpftrace.

EXEMPLES

Tracer toutes les connexions TCP passives (accept()) :
# tcpaccept.bt

SURCHARGE

Ceci trace la fonction du noyau inet_csk_accept et affiche la sortie pour chaque événement. Le taux de ceci dépend de votre application serveur. S'il s'agit d'un serveur web ou proxy acceptant des dizaines de milliers de connexions par seconde, la surcharge de cet outil peut être mesurable (bien que toujours beaucoup mieux que de tracer chaque paquet). S'il s'agit de moins d'un millier par seconde, la surcharge est supposée être négligeable. Testez et comprenez cette surcharge avant utilisation.
