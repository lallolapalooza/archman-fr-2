NOM

skbmod - action d'édition de paquet conviviale

SYNTAXE


tc ... action skbmod { set SETTABLE | swap SWAPPABLE | ecn } [ CONTROL ] [ index INDEX ]

SETTABLE := [ dmac DMAC ] [ smac SMAC ] [ etype ETYPE ]

SWAPPABLE := mac

CONTROL := { reclassify | pipe | drop | shot | continue | pass }

DESCRIPTION

L'action skbmod est conçue comme une amélioration de convivialité de l'action pedit existante. Au lieu d'avoir à modifier manuellement des morceaux de 8, 16 ou 32 bits d'un en-tête Ethernet, skbmod permet la substitution complète d'éléments pris en charge. L'action doit être l'une des suivantes : set, swap et ecn. Les actions set et swap n'affectent que les paquets Ethernet, tandis que ecn n'affecte que les paquets IP.

OPTIONS

dmac DMAC
Modifie l'adresse MAC de destination pour l'adresse spécifiée.
smac SMAC
Modifie l'adresse MAC source pour l'adresse spécifiée.
etype ETYPE
Modifie l'ethertype pour la valeur spécifiée.
mac
Utilisé pour échanger les adresses MAC.
ecn
Utilisé pour marquer les paquets IP avec le transport capable d'ECN (ECT) comme étant en état de congestion rencontrée (CE). N'affecte pas les paquets sans transport capable d'ECN (Non-ECT).
CONTROL
Les mots-clés suivants permettent de contrôler la manière dont l'arbre de qdisc, de classes, de filtres et d'actions est parcouru par la suite après cette action.
reclassify
Redémarre avec le premier filtre de la liste actuelle.
pipe
Continue avec l'action suivante attachée au même filtre.
drop
shot
Supprime le paquet.
continue
Continue la classification avec le filtre suivant dans l'ordre.
pass
Termine le processus de classification et retourne au qdisc appelant pour un traitement ultérieur du paquet. C'est le comportement par défaut.

EXEMPLES

Pour commencer, observez le filtre suivant avec une action pedit:

tc filter add dev eth1 parent 1: protocol ip prio 10 \
	u32 match ip protocol 1 0xff flowid 1:2 \
	action pedit munge offset -14 u8 set 0x02 \
	munge offset -13 u8 set 0x15 \
	munge offset -12 u8 set 0x15 \
	munge offset -11 u8 set 0x15 \
	munge offset -10 u16 set 0x1515 \
	pipe

En utilisant l'action skbmod, cette commande peut être simplifiée en :

tc filter add dev eth1 parent 1: protocol ip prio 10 \
	u32 match ip protocol 1 0xff flowid 1:2 \
	action skbmod set dmac 02:15:15:15:15:15 \
	pipe

La complexité augmentera si l'adresse MAC source et l'ethertype sont également modifiés dans le cadre de l'action. Si les trois champs doivent être modifiés avec skbmod :

tc filter add dev eth5 parent 1: protocol ip prio 10 \
	u32 match ip protocol 1 0xff flowid 1:2 \
	action skbmod \
	set etype 0xBEEF \
	set dmac 02:12:13:14:15:16 \
	set smac 02:22:23:24:25:26

Pour échanger les adresses MAC de destination et source dans l'en-tête Ethernet :

tc filter add dev eth3 parent 1: protocol ip prio 10 \
	u32 match ip protocol 1 0xff flowid 1:2 \
	action skbmod \
	swap mac

Enfin, pour marquer le point de code CE dans l'en-tête IP pour les paquets avec transport capable d'ECN (ECT) :

tc filter add dev eth0 parent 1: protocol ip prio 10 \
	u32 match ip protocol 1 0xff flowid 1:2 \
	action skbmod \
	ecn

Une seule des actions set, swap et ecn doit être utilisée dans une seule commande. Essayer d'en utiliser plusieurs dans une même commande est considéré comme un comportement indéfini ; utilisez plutôt plusieurs commandes en chaîne.
