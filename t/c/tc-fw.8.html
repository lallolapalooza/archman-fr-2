NOM

fw - filtre de contrôle de trafic pour le marquage de pare-feu

SYNOPSIS


tc filter ... fw [ classid CLASSID ] [ action ACTION_SPEC ]

DESCRIPTION

Le filtre fw permet de classifier les paquets en se basant sur un fwmark préalablement défini par iptables. Si la valeur masquée du fwmark correspond au handle masqué du filtre, le filtre correspond. Par défaut, les 32 bits du handle et du fwmark sont masqués. iptables permet de marquer des paquets individuels avec la cible MARK, ou des connexions entières en utilisant CONNMARK. L'avantage d'utiliser ce filtre au lieu de faire le gros travail avec tc lui-même est que, d'une part, il peut être pratique de garder le filtrage et la classification des paquets au même endroit, et potentiellement de ne faire correspondre un paquet qu'une seule fois, et d'autre part, les utilisateurs familiers avec iptables mais pas avec tc auront moins de difficultés à ajouter de la QoS à leurs configurations.

OPTIONS

classid CLASSID
Pousse les paquets correspondants vers la classe identifiée par CLASSID.
action ACTION_SPEC
Applique une action du framework d'actions génériques aux paquets correspondants.

EXEMPLES

Prenons par exemple l'instruction de filtre tc suivante :

tc filter add ... handle 6 fw classid 1:1

correspondra si la valeur fwmark du paquet est 6. Ceci est un exemple d'instruction iptables marquant les paquets arrivant sur eth0 :

iptables -t mangle -A PREROUTING -i eth0 -j MARK --set-mark 6

Des bits spécifiques du fwmark du paquet peuvent être définis en utilisant l'action skbedit. Par exemple, pour définir uniquement un bit du fwmark sans modifier aucun autre bit :

tc filter add ... action skbedit mark 0x8/0x8

Le filtre fw peut ensuite être utilisé pour faire correspondre ce bit en masquant le handle :

tc filter add ... handle 0x8/0x8 fw action drop

Ceci est utile lorsque différents bits du fwmark sont assignés à des significations différentes.
