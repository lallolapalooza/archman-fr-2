NOM

connmark - action de récupération de la marque de connexion netfilter

SYNTAXE


tc ... action connmark [ zone u16_zone_index ] [ CONTROLE ] [ index u32_index ]

CONTROLE := { reclassify | pipe | drop | continue | ok }

DESCRIPTION

L'action connmark est utilisée pour restaurer la valeur de la marque de connexion dans la marque de pare-feu (fwmark) du paquet.

OPTIONS

zone u16_zone_index
Spécifie la zone conntrack lors de la recherche conntrack pour les paquets. u16_zone_index est une valeur décimale non signée de 16 bits.
CONTROLE
Comment continuer après l'exécution de cette action.
reclassify
Redémarre la classification en sautant vers le premier filtre attaché au parent de cette action.
pipe
Continue avec l'action suivante, c'est le comportement par défaut.
drop
shot
Le paquet sera abandonné sans exécuter d'autres actions.
continue
Continue la classification avec le filtre suivant dans la ligne.
pass
Retourne à la qdisc appelante pour le traitement du paquet. Ceci termine le processus de classification.
index u32_index
Spécifie un index pour cette action afin de pouvoir l'identifier dans les commandes ultérieures. u32_index est une valeur décimale non signée de 32 bits.
