NOM

tcpkill - tuer des connexions TCP sur un réseau local

SYNTAXE

tcpkill [-i interface] [-1...9] expression

DESCRIPTION


tcpkill tue les connexions TCP en cours spécifiées (utile pour les applications basées sur libnids qui nécessitent un handshake TCP complet en 3 étapes pour la création du TCB).

OPTIONS

-i interface
Spécifie l'interface sur laquelle écouter.
-1...9
Spécifie le degré de force brute à utiliser pour tuer une connexion. Les connexions rapides peuvent nécessiter un nombre plus élevé afin d'envoyer un RST dans la fenêtre de réception mobile. La valeur par défaut est 3.
expression
Spécifie une expression de filtrage tcpdump(8) pour sélectionner les connexions à tuer.

VOIR AUSSI
