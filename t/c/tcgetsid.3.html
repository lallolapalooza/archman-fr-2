tcgetsid(3) Manuel des fonctions de bibliothèque tcgetsid(3)

NOM

tcgetsid - obtenir l'identifiant de session

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#define _XOPEN_SOURCE 500        /* Voir feature_test_macros(7) */
#include <termios.h>
pid_t tcgetsid(int fd);

DESCRIPTION

La fonction tcgetsid() renvoie l'identifiant de session de la session courante qui possède le terminal associé à fd comme terminal de contrôle. Ce terminal doit être le terminal de contrôle du processus appelant.

VALEUR DE RETOUR

Lorsque fd fait référence au terminal de contrôle de notre session, la fonction tcgetsid() renverra l'identifiant de session de cette session. Sinon, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EBADF
fd n'est pas un descripteur de fichier valide.
ENOTTY
Le processus appelant n'a pas de terminal de contrôle, ou il en a un mais il n'est pas décrit par fd.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
tcgetsid () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.1. POSIX.1-2001.

Cette fonction est implémentée via le ioctl(2) TIOCGSID, présent depuis Linux 2.1.71.

VOIR AUSSI

getsid(2)
