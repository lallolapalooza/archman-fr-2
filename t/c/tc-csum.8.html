NOM

csum - action de mise à jour de la somme de contrôle

SYNTAXE


tc ... action csum MISEAJOUR

MISEAJOUR := CIBLE [ MISEAJOUR ]

CIBLE := { ip4h | icmp | igmp | tcp | udp | udplite | sctp | SUCRES }

SUCRES := { and | or | + }

DESCRIPTION

L'action csum déclenche le recalcul des sommes de contrôle des en-têtes de paquets spécifiés. Elle est couramment utilisée pour corriger des sommes de contrôle incorrectes après que l'action pedit ait modifié le contenu du paquet.

OPTIONS

CIBLE
Spécifie quels en-têtes mettre à jour : en-tête IPv4 (ip4h), en-tête ICMP (icmp), en-tête IGMP (igmp), en-tête TCP (tcp), en-tête UDP (udp), en-tête UDPLite (udplite) ou en-tête SCTP (sctp).
SUCRES
Il s'agit simplement de sucre syntaxique et ils sont ignorés en interne.

EXEMPLES

L'exemple suivant effectue une traduction d'adresses réseau (NAT) sans état pour les paquets entrants de 192.0.2.100 vers la nouvelle destination 198.51.100.1. En supposant qu'il s'agisse de paquets UDP, les sommes de contrôle IP et UDP doivent être recalculées :

# tc qdisc add dev eth0 ingress handle ffff:
# tc filter add dev eth0 prio 1 protocol ip parent ffff: \
	u32 match ip src 192.0.2.100/32 flowid :1 \
	action pedit munge ip dst set 198.51.100.1 pipe \
	csum ip and udp
