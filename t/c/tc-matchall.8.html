NOM

matchall - filtre de contrôle de trafic qui correspond à chaque paquet

SYNOPIS


tc filter ... matchall [ skip_sw | skip_hw ] [ action ACTION_SPEC ] [ classid CLASSID ]

DESCRIPTION

Le filtre matchall permet de classer chaque paquet qui transite sur le port et d'exécuter une action sur celui-ci.

OPTIONS

action ACTION_SPEC
Applique une action du framework d'actions génériques aux paquets correspondants.
classid CLASSID
Envoie les paquets correspondants dans la classe identifiée par CLASSID.
skip_sw
Ne pas traiter le filtre par logiciel. Si le matériel n'a pas de prise en charge de déchargement pour ce filtre, ou si le déchargement TC n'est pas activé pour l'interface, l'opération échouera.
skip_hw
Ne pas traiter le filtre par matériel.

EXEMPLES

Pour créer une duplication en miroir d'entrée du port eth1 vers le port eth2 :

tc qdisc  add dev eth1 handle ffff: clsact
tc filter add dev eth1 ingress                \
        matchall skip_sw                      \
        action mirred egress mirror           \
        dev eth2

La première commande crée une file d'attente clsact avec le descripteur ffff: sur le périphérique eth1 où la deuxième commande attache un filtre matchall qui duplique les paquets vers le périphérique eth2 pour l'entrée.

Pour créer une duplication en miroir de sortie du port eth1 vers le port eth2 :

tc qdisc add dev eth1 handle ffff: clsact
tc filter add dev eth1 egress                  \
        matchall skip_sw                       \
        action mirred egress mirror            \
        dev eth2

La première commande crée une file d'attente clsact avec le descripteur ffff: sur le périphérique eth1 où la deuxième commande attache un filtre matchall qui duplique les paquets vers le périphérique eth2 pour la sortie.

Pour échantillonner un paquet sur 100 transitant vers l'interface eth0 vers le groupe de psample 12 :

tc qdisc add dev eth0 handle ffff: ingress
tc filter add dev eth0 parent ffff: matchall \
     action sample rate 100 group 12
