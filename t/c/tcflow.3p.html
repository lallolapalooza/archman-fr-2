TCFLOW(3P) Manuel du programmeur POSIX TCFLOW(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

tcflow — suspendre ou reprendre la transmission ou la réception de données

SYNOPSIS

#include <termios.h>
int tcflow(int fildes, int action);

DESCRIPTION

La fonction tcflow() doit suspendre ou reprendre la transmission ou la réception de données sur l'objet référencé par fildes, en fonction de la valeur de action. L'argument fildes est un descripteur de fichier ouvert associé à un terminal.

*
Si action est TCOOFF, la sortie doit être suspendue.
*
Si action est TCOON, la sortie suspendue doit être reprise.
*
Si action est TCIOFF et que fildes fait référence à un périphérique de terminal, le système doit transmettre un caractère STOP, qui est destiné à faire cesser la transmission de données du périphérique de terminal au système. Si fildes est associé à un pseudo-terminal, le caractère STOP ne doit pas nécessairement être transmis.
*
Si action est TCION et que fildes fait référence à un périphérique de terminal, le système doit transmettre un caractère START, qui est destiné à faire reprendre la transmission de données du périphérique de terminal au système. Si fildes est associé à un pseudo-terminal, le caractère START ne doit pas nécessairement être transmis.

Par défaut à l'ouverture d'un fichier terminal, ni son entrée ni sa sortie ne sont suspendues.

Les tentatives d'utilisation de tcflow() à partir d'un processus membre d'un groupe de processus en arrière-plan sur un fildes associé à son terminal de contrôle, doivent entraîner l'envoi d'un signal SIGTTOU au groupe de processus. Si le thread appelant bloque les signaux SIGTTOU ou si le processus ignore les signaux SIGTTOU, le processus doit être autorisé à effectuer l'opération, et aucun signal n'est envoyé.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. Sinon, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

La fonction tcflow() échoue si :

EBADF
L'argument fildes n'est pas un descripteur de fichier valide.
EINVAL
L'argument action n'est pas une valeur prise en charge.
EIO
Le groupe de processus du processus d'écriture est orphelin, le thread appelant ne bloque pas SIGTTOU et le processus n'ignore pas SIGTTOU.
ENOTTY
Le fichier associé à fildes n'est pas un terminal.
