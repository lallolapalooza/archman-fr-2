NOM

basic - filtre de contrôle de trafic de base

SYNTAXE


tc filter ... basic [ match EMATCH_TREE ] [ action ACTION_SPEC ] [ classid CLASSID ]

DESCRIPTION

Le filtre basic permet de classifier les paquets en utilisant l'infrastructure de correspondance étendue.

OPTIONS

action ACTION_SPEC
Applique une action du framework d'actions génériques sur les paquets correspondants.
classid CLASSID
Envoie les paquets correspondants dans la classe identifiée par CLASSID.
match EMATCH_TREE
Correspond aux paquets en utilisant l'infrastructure de correspondance étendue. Voir tc-ematch(8) pour une description détaillée de la syntaxe autorisée dans EMATCH_TREE.

VOIR AUSSI

tc(8), tc-ematch(8)
