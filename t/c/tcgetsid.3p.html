TCGETSID(3P) Manuel du programmeur POSIX TCGETSID(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

tcgetsid — obtenir l'identifiant du groupe de processus du leader de session pour le terminal de contrôle

SYNTAXE

#include <termios.h>
pid_t tcgetsid(int fildes);

DESCRIPTION

La fonction tcgetsid() obtient l'identifiant du groupe de processus de la session pour laquelle le terminal spécifié par fildes est le terminal de contrôle.

VALEUR DE RETOUR

En cas de succès, tcgetsid() renvoie l'identifiant du groupe de processus associé à la session pour le terminal. Sinon, une valeur de -1 est renvoyée et errno est définie pour indiquer l'erreur.

ERREURS

La fonction tcgetsid() échouera si :

EBADF
L'argument fildes n'est pas un descripteur de fichier valide.
ENOTTY
Le processus appelant n'a pas de terminal de contrôle, ou le fichier n'est pas le terminal de contrôle.
