NOM

tca_correct - Calculer l'aberration chromatique transversale

SYNTAXE

tca_correct [options] fichier_entree

<fichier_entree> est le nom de base de 4 fichiers image :

<fichier_entree>
Fichier couleur pour calculer les paramètres TCA
rouge_<fichier_entree>
Canal rouge de <fichier_entree>
vert_<fichier_entree>
Canal vert de <fichier_entree>
bleu_<fichier_entree>
Canal bleu de <fichier_entree>

Les images des canaux doivent être des images couleur avec 3 canaux identiques. Si l'une des options -R, -G, ou -B est donnée, ce nom de fichier est utilisé à la place du nom dérivé.

Sortie : arguments de ligne de commande pour fulla

DESCRIPTION

Génère des paramètres de ligne de commande pour fulla afin de corriger l'aberration chromatique transversale (TCA) à partir de photos d'échantillon. Les photos d'échantillon idéales devraient présenter beaucoup de contraste sur toute la zone de l'image, peu de couleurs saturées et pas de hautes lumières surchargées.

OPTIONS

-h
Afficher l'aide
-l
Le fichier d'entrée est un fichier PTO au lieu d'une image
-m méthode
méthode d'optimisation (0 normal, 1 newfit)
-o vars_opti
chaîne de variables à optimiser ("abcvde")
-r
Réinitialiser les valeurs (cela mettra à zéro les paramètres a, b, c, d, e et définira v à 10) n'a de sens qu'avec l'option -l
-s <échelle>
Échelle pour la détection des coins
-n <nombre>
nombre de points par cellule de grille (défaut : 10)
-g <nombre>
diviser l'image en <nombre>x<nombre> cellules de grille (défaut : 10)
-t num
Supprimer tous les points de contrôle dont l'erreur est supérieure à num pixels (défaut : 1.5)
-v
Verbeux
--save-into-database
Sauvegarde les données TCA dans la base de données des objectifs Hugin
-w nom_fichier
écrire le fichier PTO
-R <r>
Utiliser ce fichier comme canal rouge
-G <g>
Utiliser ce fichier comme canal vert
-B <b>
Utiliser ce fichier comme canal bleu
