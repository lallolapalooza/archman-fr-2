NOM

HFSC - Contrôle Hierarchical Fair Service Curve sous Linux

SYNOPSIS

tc qdisc add ... hfsc [ default CLASSID ]
tc class add ... hfsc [ [ rt SC ] [ ls SC ] | [ sc SC ] ] [ ul SC ]
rt : courbe de service temps réel
ls : courbe de service linkshare
sc : rt+ls courbe de service
ul : courbe de service limite supérieure
• au moins un des arguments rt, ls ou sc doit être spécifié
• ul ne peut être spécifié qu'avec ls ou sc
SC := [ [ m1 BPS ] d SEC ] m2 BPS
m1 : pente du premier segment
d  : coordonnée x de l'intersection
m2 : pente du second segment
SC := [ [ umax OCTETS ] dmax SEC ] rate BPS
umax : unité de travail maximale
dmax : délai maximal
rate : débit

Pour la description de OCTETS, BPS et SEC, veuillez consulter la section UNITÉS de tc(8).

DESCRIPTION (qdisc)

Le qdisc HFSC n'a qu'un seul paramètre optionnel : default. CLASSID spécifie la partie mineure de l'identifiant de classe, où les paquets non classifiés par d'autres moyens (par exemple, filtre u32, cible CLASSIFY d'iptables) seront mis en file d'attente. Si default n'est pas spécifié, les paquets non classifiés seront abandonnés.

DESCRIPTION (classe)

La classe HFSC est utilisée pour créer une hiérarchie de classes pour le planificateur HFSC. Pour une explication de l'algorithme et de la signification des courbes de service rt, ls, sc et ul, veuillez vous référer à tc-hfsc(7).

Comme vous pouvez le voir dans la SYNOPSIS, la courbe de service (SC) peut être spécifiée de deux manières. Soit comme un délai maximal pour une certaine quantité de travail, soit comme une bande passante allouée pour une certaine durée. Évidemment, m1 est simplement umax/dmax.

Les deux m2 et rate sont obligatoires. Si vous omettez les autres paramètres, vous spécifierez une courbe de service linéaire.
