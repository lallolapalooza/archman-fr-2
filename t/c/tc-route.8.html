NOM

route - filtre de contrôle de trafic basé sur le routage

SYNTAXE


tc filter ... route [ from REALM | fromif TAG ] [ to REALM ] [ classid CLASSID ] [ action ACTION_SPEC ]

DESCRIPTION

Filtre les paquets en fonction des entrées de la table de routage. Ce filtre est centré sur la possibilité d'assigner un realm aux entrées de la table de routage. Pour qu'un paquet soit classé par ce filtre, une recherche dans la table de routage est effectuée et le realm retourné est utilisé pour décider si le paquet correspond ou non.

OPTIONS

action ACTION_SPEC
Applique une action du framework d'actions génériques sur les paquets correspondants.
classid CLASSID
Envoie les paquets correspondants dans la classe identifiée par CLASSID.
from REALM
fromif TAG
Effectue des recherches sur la route source. TAG est le nom d'une interface qui doit être présente sur le système au moment de l'invocation de tc.
to REALM
Correspond si le routage normal (c'est-à-dire de destination) retourne le REALM donné.

EXEMPLES

Considérez le sous-réseau 192.168.2.0/24 étant attaché à eth0 :

ip route add 192.168.2.0/24 dev eth0 realm 2

Le filtre route suivant correspondra alors aux paquets provenant de ce sous-réseau :

tc filter add ... route from 2 classid 1:2

et transmettra les paquets à la classe 1:2.

NOTES

En raison des détails d'implémentation, les valeurs de realm doivent être comprises dans une plage de 0 à 255, inclusivement. Alternativement, un nom verbeux défini dans /etc/iproute2/rt_realms peut être donné à la place.
