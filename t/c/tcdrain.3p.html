TCDRAIN(3P) Manuel du programmeur POSIX TCDRAIN(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

tcdrain — attendre la transmission de la sortie

SYNTAXE

#include <termios.h>
int tcdrain(int fildes);

DESCRIPTION

La fonction tcdrain() se bloque jusqu'à ce que toute la sortie écrite dans l'objet référencé par fildes soit transmise. L'argument fildes est un descripteur de fichier ouvert associé à un terminal.

Toute tentative d'utilisation de tcdrain() par un processus membre d'un groupe de processus en arrière-plan sur un fildes associé à son terminal de contrôle, entraîne l'envoi d'un signal SIGTTOU au groupe de processus. Si le thread appelant bloque les signaux SIGTTOU ou si le processus ignore SIGTTOU, l'opération est autorisée et aucun signal n'est envoyé.

VALEUR DE RETOUR

En cas de succès, 0 est retourné. Sinon, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

La fonction tcdrain() échoue si :

EBADF
L'argument fildes n'est pas un descripteur de fichier valide.
EINTR
Un signal a interrompu tcdrain().
EIO
Le groupe de processus de l'appelant est orphelin, le thread appelant ne bloque pas SIGTTOU et le processus n'ignore pas SIGTTOU.
ENOTTY
Le fichier associé à fildes n'est pas un terminal.
