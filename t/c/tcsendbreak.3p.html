TCSENDBREAK(3P) Manuel du programmeur POSIX TCSENDBREAK(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

tcsendbreak — envoyer une interruption pendant une durée spécifique

SYNTAXE

#include <termios.h>
int tcsendbreak(int fildes, int duration);

DESCRIPTION

Si le terminal utilise une transmission de données série asynchrone, tcsendbreak() provoquera la transmission d'un flux continu de bits de valeur nulle pendant une durée spécifique. Si duration est 0, elle provoquera la transmission de bits de valeur nulle pendant au moins 0,25 secondes, et pas plus de 0,5 secondes. Si duration n'est pas 0, elle enverra des bits de valeur nulle pendant une période de temps indéfinie par l'implémentation.

L'argument fildes est un descripteur de fichier ouvert associé à un terminal.

Si le terminal n'utilise pas la transmission de données série asynchrone, il est indéfini par l'implémentation si tcsendbreak() envoie des données pour générer une condition d'interruption ou retourne sans aucune action.

Les tentatives d'utilisation de tcsendbreak() par un processus membre d'un groupe de processus en arrière-plan sur un fildes associé à son terminal de contrôle provoqueront l'envoi d'un signal SIGTTOU au groupe de processus. Si le thread appelant bloque les signaux SIGTTOU ou si le processus ignore SIGTTOU, l'opération sera autorisée, et aucun signal ne sera envoyé.

VALEUR DE RETOUR

En cas de succès, 0 sera retourné. Sinon, -1 sera retourné et errno sera définie pour indiquer l'erreur.

ERREURS

La fonction tcsendbreak() échouera si :

EBADF
L'argument fildes n'est pas un descripteur de fichier valide.
EIO
Le groupe de processus de l'écriture est orphelin, le thread appelant ne bloque pas SIGTTOU, et le processus ignore SIGTTOU.
ENOTTY
Le fichier associé à fildes n'est pas un terminal.
