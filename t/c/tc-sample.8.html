NOM

sample - action d'échantillonnage de paquets tc

SYNOPSIS


tc ... action sample rate TAUX group GROUPE [ trunc TAILLE ] [ index INDEX ]

tc ... action sample index INDEX

DESCRIPTION

L'action sample permet d'échantillonner les paquets correspondant à un classifieur.

Les paquets sont choisis aléatoirement selon le paramètre rate, et sont échantillonnés en utilisant le canal générique netlink psample. L'utilisateur peut également spécifier la troncature des paquets pour économiser le trafic utilisateur-noyau. Chaque échantillon inclut des métadonnées informatives sur le paquet d'origine, qui sont envoyées via des attributs netlink, aux côtés des données du paquet d'origine.

L'utilisateur peut soit spécifier les paramètres de l'action d'échantillonnage tels que présentés dans la première forme ci-dessus, soit utiliser une action d'échantillonnage existante en utilisant son index, tel que présenté dans la seconde forme.

CHAMP(S) MÉTADONNÉES DES PAQUETS ÉCHANTILLONNÉS

Les métadonnées sont livrées aux applications userspace en utilisant le canal générique netlink psample, où chaque échantillon inclut les attributs netlink suivants :

PSAMPLE_ATTR_IIFINDEX
L'index de l'interface d'entrée du paquet, s'il existe.
PSAMPLE_ATTR_OIFINDEX
L'index de l'interface de sortie du paquet. Ce champ n'est pas pertinent lors de l'échantillonnage en entrée.
PSAMPLE_ATTR_ORIGSIZE
La taille du paquet d'origine (avant troncature).
PSAMPLE_ATTR_SAMPLE_GROUP
Le groupe psample vers lequel le paquet a été envoyé.
PSAMPLE_ATTR_GROUP_SEQ
Un numéro de séquence du paquet échantillonné. Ce numéro est incrémenté avec chaque paquet échantillonné du groupe psample actuel.
PSAMPLE_ATTR_SAMPLE_RATE
Le taux auquel le paquet a été échantillonné.

OPTIONS

rate TAUX
Le taux d'échantillonnage des paquets. TAUX est le rapport attendu entre les paquets observés et les paquets échantillonnés. Par exemple, un TAUX de 100 entraînera en moyenne un paquet échantillonné sur 100 observés.
trunc TAILLE
Lorsqu'il est défini, détermine la taille maximale des paquets échantillonnés et provoque la troncature si nécessaire.
group GROUPE
Le groupe psample vers lequel le paquet sera envoyé. Le module psample définit le concept de groupes, ce qui permet à l'utilisateur de faire correspondre des paquets échantillonnés spécifiques en cas de règles d'échantillonnage multiples, identifiant ainsi uniquement les paquets provenant d'une règle spécifique.
index INDEX
Est un identifiant unique pour une action. Lors de la création d'une nouvelle instance d'action, ce paramètre permet de définir le nouvel index de l'action. Lors de l'utilisation d'une action existante, ce paramètre permet de spécifier l'index de l'action existante. L'index doit être un entier non signé de 32 bits supérieur à zéro.

EXEMPLES

Échantillonner un paquet sur 100 parmi ceux arrivant sur l'interface eth0 vers le groupe psample 12 :

tc qdisc add dev eth0 handle ffff: ingress
tc filter add dev eth0 parent ffff: matchall \
     action sample rate 100 group 12 index 19

Utiliser la même instance d'action pour échantillonner également eth1 :

tc qdisc add dev eth1 handle ffff: ingress
tc filter add dev eth1 parent ffff: matchall \
     action sample index 19
