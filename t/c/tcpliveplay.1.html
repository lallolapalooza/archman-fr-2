NOM

tcpliveplay - Rejoue le trafic réseau stocké dans un fichier pcap sur des réseaux en direct en utilisant de nouvelles connexions TCP

SYNTAXE

tcpliveplay [-flags] [-flag [valeur]] [--nom-option[[=| ]valeur]] <eth0/eth1> <fichier.pcap> <IP de destination [1.2.3.4]> <MAC de destination [0a:1b:2c:3d:4e:5f]> <'port aléatoire' dst ou spécifier dport #>

Ce programme, 'tcpliveplay', rejoue un ensemble de paquets capturés en utilisant un format d'événements planifiés et répond avec le paquet approprié si l'hôte distant satisfait l'attente de SEQ/ACK du protocole TCP. Une fois les attentes satisfaites, les paquets locaux sont envoyés avec la même charge utile, sauf avec de nouveaux numéros TCP SEQ et ACK correspondant à la réponse de l'hôte distant.

DESCRIPTION

Le fonctionnement de base de tcpliveplay est de réécrire le fichier pcap donné dans un format d'événements planifiés et de répondre avec le paquet approprié si l'hôte distant satisfait l'attente de SEQ/ACK du protocole TCP. Une fois les attentes satisfaites, les paquets locaux sont envoyés avec la même charge utile, sauf avec de nouveaux numéros SEQ et ACK TCP correspondant à la réponse de l'hôte distant.

Le fichier pcap d'entrée est réécrit pour commencer à la première rencontre du paquet SYN pour un fonctionnement correct, faisant de ce paquet la première action dans le calendrier d'événements de l'hôte local effectuant le rejeu.

Pour plus de détails, veuillez consulter le manuel de Tcpreplay sur : http://tcpreplay.appneta.com

OPTIONS

-d nombre, --dbug=nombre

Active la sortie de débogage. Cette option peut apparaître jusqu'à 1 fois. Cette option prend un nombre entier comme argument. La valeur de nombre est limitée à : 
dans la plage  0 à 5

La valeur par défaut de nombre pour cette option est :
0

Si configuré avec --enable-debug, vous pouvez spécifier un niveau de verbosité pour la sortie de débogage. Des nombres plus élevés augmentent la verbosité.

-V, --version

Affiche les informations de version.
-h, --less-help

Affiche moins d'informations d'aide et quitte.
-H, --help

Affiche les informations d'aide et quitte.
-!, --more-help

Passe les informations d'aide étendues à travers un paginator.
--save-opts [=fichier_cfg]

Enregistre l'état des options dans fichier_cfg. Par défaut, il s'agit du dernier fichier de configuration listé dans la section PRÉCONFIGURATIONS D'OPTIONS ci-dessous. La commande se terminera après la mise à jour du fichier de configuration.
--load-opts=fichier_cfg, --no-load-opts

Charge les options depuis fichier_cfg. La forme no-load-opts désactivera le chargement des fichiers de configuration/rc/ini précédents. --no-load-opts est traité tôt, hors séquence.

PRÉCONFIGURATIONS D'OPTIONS

Toute option qui n'est pas marquée comme non préconfigurable peut être préconfigurée en chargeant des valeurs à partir d'un fichier de configuration (type "RC" ou ".INI"). Le fichier homerc est "$$/", sauf si c'est un répertoire. Dans ce cas, le fichier ".tcpliveplayrc" est recherché dans ce répertoire.
