NOM

skbedit - Action d'édition SKB

SYNTAXE


tc ... action skbedit [ queue_mapping QUEUE_MAPPING ] [ priority PRIORITY ] [ mark MARK[/MASK] ] [ ptype PTYPE ] [ inheritdsfield ]

DESCRIPTION

L'action skbedit permet de modifier les métadonnées associées à un paquet. Elle complète l'action pedit, qui quant à elle, permet de modifier des parties des données du paquet elles-mêmes.

La caractéristique la plus unique de skbedit est sa capacité à décider sur quelle file d'attente d'une interface avec plusieurs files d'attente de transmission le paquet doit être envoyé. Le nombre de files d'attente de transmission disponibles est reflété par des entrées sysfs dans /sys/class/net/<interface>/queues portant le nom tx-N (où N est le numéro de la file d'attente réelle).

OPTIONS

queue_mapping QUEUE_MAPPING
Remplace la file d'attente de transmission du paquet. Utile lorsqu'il est appliqué à des paquets transmis sur des interfaces réseau compatibles MQ. QUEUE_MAPPING est une valeur de 16 bits non signée au format décimal.
priority PRIORITY
Remplace la décision de classification du paquet. PRIORITY est soit root, none, soit un identifiant de classe majeure hexadécimal éventuellement suivi d'un deux-points (:) et d'un identifiant de classe mineure hexadécimal.
mark MARK[/MASK]
Modifie la valeur de la marque de pare-feu du paquet. MARK est une valeur de 32 bits non signée au format automatiquement détecté (c'est-à-dire, préfixer avec '0x' pour une interprétation hexadécimale, etc.). MASK définit le masque de 32 bits sélectionnant les bits de la valeur de la marque. La valeur par défaut est 0xffffffff.
ptype PTYPE
Remplace le type du paquet. Utile pour définir le type de paquet à hôte lorsqu'il est nécessaire d'autoriser les paquets entrants avec une adresse MAC incorrecte mais une adresse IP correcte. PTYPE est l'une des valeurs suivantes : host, otherhost, broadcast, multicast
inheritdsfield
Remplace la décision de classification du paquet, ainsi que toute valeur spécifiée avec priority, en utilisant les informations stockées dans le champ Differentiated Services du header IPv6/IPv4 (RFC2474).
