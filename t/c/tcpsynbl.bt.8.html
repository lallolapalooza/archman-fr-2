NOM

tcpsynbl.bt - Affiche la file d'attente TCP SYN sous forme d'histogramme. Utilise bpftrace/eBPF.

SYNTAXE

tcpsynbl

DESCRIPTION

Cet outil affiche la taille de la file d'attente TCP SYN lors de l'arrivée des SYN sous forme d'histogramme. Cela vous permet de voir à quel point vos applications sont proches d'atteindre la limite de la file d'attente et de laisser tomber les SYN (ce qui entraîne des problèmes de performances avec les retransmissions SYN), et constitue une mesure de la saturation de la charge de travail. L'histogramme affiché est mesuré au moment de la réception du SYN, et un histogramme séparé est affiché pour chaque limite de file d'attente.

Cela fonctionne en traçant les fonctions noyau tcp_v4_syn_recv_sock() et tcp_v6_syn_recv_sock() à l'aide de l'instrumentation dynamique. Comme ces fonctions peuvent changer dans les noyaux futurs, cet outil peut nécessiter une maintenance pour continuer à fonctionner.

Comme il utilise BPF, seul l'utilisateur root peut utiliser cet outil.

PRÉREQUIS

CONFIG_BPF et bpftrace.

EXEMPLES

Affiche la file d'attente TCP SYN sous forme d'histogramme.
# tcpsynbl.bt

CHAMPS

file d'attente
La taille de la file d'attente lorsqu'un SYN a été reçu.
compte
Le nombre de fois où cette taille de file d'attente a été rencontrée.
distribution
Une visualisation ASCII de la colonne de comptage.

SURCOUT

Les SYN entrants devraient être relativement faibles par rapport aux paquets et autres événements, de sorte que le surcoût de cet outil devrait être négligeable.

SOURCE

Voir le livre pour plus de documentation sur cet outil.
