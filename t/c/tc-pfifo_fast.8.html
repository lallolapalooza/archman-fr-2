NOM

pfifo_fast - file d'attente premier entré, premier sorti à trois bandes

DESCRIPTION

pfifo_fast est le qdisc par défaut de chaque interface.

Chaque fois qu'une interface est créée, le qdisc pfifo_fast est automatiquement utilisé comme une file d'attente. Si un autre qdisc est attaché, il supplante le pfifo_fast par défaut, qui reprend automatiquement sa fonction lorsqu'un qdisc existant est détaché.

En ce sens, ce qdisc est magique, et contrairement aux autres qdiscs.

ALGORITHME

L'algorithme est très similaire à celui du qdisc tc-prio(8) basé sur les classes. pfifo_fast est comme trois files tc-pfifo(8) côte à côte, où les paquets peuvent être mis en file d'attente dans l'une des trois bandes en fonction de leurs bits de Type de Service (TOS) ou de leur priorité assignée.

Les trois bandes ne sont pas dépilées simultanément - tant qu'il y a du trafic dans les bandes inférieures, les bandes supérieures ne sont jamais dépilées. Ceci peut être utilisé pour prioriser le trafic interactif ou pénaliser le trafic au 'coût le plus bas'.

Chaque bande peut contenir jusqu'à txqueuelen paquets, tel que configuré avec ip(8). Les paquets supplémentaires entrants ne sont pas mis en file d'attente mais sont plutôt abandonnés.

Voir tc-prio(8) pour les détails complets sur la façon dont les bits TOS sont traduits en bandes.

PARAMÈTRES

txqueuelen
La longueur des trois bandes dépend du txqueuelen de l'interface, tel que spécifié avec ip(8).

BOGUES

Ne maintient pas de statistiques et n'apparaît pas dans `tc qdisc ls`. Ceci est dû au fait qu'il s'agit du défaut automatique en l'absence d'un qdisc configuré.
