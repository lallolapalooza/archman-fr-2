tcl_prefix(n)

Paquet: tcl

Licences: TCL

prefix(n) Commandes intégrées Tcl prefix(n)

NOM

tcl::prefix - facilités pour la correspondance de préfixes

SYNTAXE

::tcl::prefix all table chaîne
::tcl::prefix longest table chaîne
::tcl::prefix match ?option ...? table chaîne

DESCRIPTION

Ce document décrit les commandes permettant de rechercher un préfixe dans une liste de chaînes. Les commandes suivantes sont prises en charge :

::tcl::prefix all table chaîne
Renvoie une liste de tous les éléments de table qui commencent par le préfixe chaîne.
::tcl::prefix longest table chaîne
Renvoie le plus long préfixe commun de tous les éléments de table qui commencent par le préfixe chaîne.
::tcl::prefix match ?option ...? table chaîne
Si chaîne est égal à un élément de table ou est un préfixe d'exactement un élément, l'élément correspondant est renvoyé. Sinon, le résultat dépend de l'option -error. (Il est recommandé que la table soit triée avant d'être utilisée avec cette sous-commande, afin que la liste des correspondances présentées dans le message d'erreur soit également triée, bien que cela ne soit pas strictement nécessaire pour le fonctionnement de cette sous-commande elle-même.) Les options suivantes sont prises en charge :
-exact 
Accepte uniquement les correspondances exactes.
-message chaîne
Utilise chaîne dans le message d'erreur en cas d'inadéquation. La valeur par défaut est « option ».
-error options
Les options sont utilisées lorsqu'aucune correspondance n'est trouvée. Si options est vide, aucune erreur n'est générée et une chaîne vide est renvoyée. Sinon, les options sont utilisées comme options de return lors de la génération du message d'erreur. La valeur par défaut correspond à la définition de « -level 0 ». Exemple : Si « -error {-errorcode MyError -level 1} » est utilisé, une erreur serait générée comme suit :
return -errorcode MyError -level 1 -code error \
       "option ambiguë ..."

EXEMPLES

Utilisation de base :

namespace import ::tcl::prefix
prefix match {apa bepa cepa} apa
     → apa
prefix match {apa bepa cepa} a
     → apa
prefix match -exact {apa bepa cepa} a
     → mauvaise option "a" : doit être apa, bepa ou cepa
prefix match -message "commutation" {apa ada bepa cepa} a
     → commutation ambiguë "a" : doit être apa, ada, bepa ou cepa
prefix longest {fblocked fconfigure fcopy file fileevent flush} fc
     → fco
prefix all {fblocked fconfigure fcopy file fileevent flush} fc
     → fconfigure fcopy

Simplification de la correspondance d'options :

array set opts {-apa 1 -bepa "" -cepa 0}
foreach {arg val} $args {
    set opts([prefix match {-apa -bepa -cepa} $arg]) $val
}

Création d'une commande switch qui prend en charge les préfixes :

switch [prefix match {apa bepa cepa} $arg] {
    apa  { }
    bepa { }
    cepa { }
}
