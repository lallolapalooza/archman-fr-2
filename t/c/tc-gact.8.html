NOM

gact - action générique

SYNTAXE


tc ... action gact CONTROLE [ ALEATOIRE ] [ INDEX ] CONTROLE := { reclassify | drop | continue | pass | pipe |
goto chain INDEX_DE_CHAINE |
jump NBRE_SAUTS }

ALEATOIRE := random TYPEALEATOIRE CONTROLE VALEUR TYPEALEATOIRE := { netrand | determ } VALEUR := nombre ne dépassant pas 10000 NBRE_SAUTS := saut absolu depuis le début de la liste d'actions INDEX := valeur d'index utilisée

DESCRIPTION

L'action gact permet de reclassifier, d'ignorer, de laisser passer ou d'accepter des paquets. Actuellement, il n'y a que deux algorithmes. L'un est déterministe et l'autre utilise le générateur aléatoire interne du noyau (netrand).

OPTIONS

random TYPEALEATOIRE CONTROLE VALEUR
La probabilité d'effectuer l'action est exprimée en termes de 1 sur VALEUR paquets.
CONTROLE
Indique comment tc doit procéder si le paquet correspond. Pour une description des valeurs possibles de CONTROLE, voir tc-actions(8).

EXEMPLES

Appliquer une règle sur l'entrée (ingress) pour ignorer les paquets provenant d'une adresse source donnée.

# tc filter add dev eth0 parent ffff: protocol ip prio 6 u32 match ip src 10.0.0.9/32 flowid 1:16 action drop

Laisser passer aléatoirement 1 paquet sur 10 provenant de la source en utilisant le générateur netrand

# tc filter add dev eth0 parent ffff: protocol ip prio 6 u32 match ip src 10.0.0.9/32 flowid 1:16 action drop random netrand ok 10

Accepter déterministe un paquet sur deux

# tc filter add dev eth0 parent ffff: protocol ip prio 6 u32 match ip src 10.0.0.9/32 flowid 1:16 action drop random determ ok 2
