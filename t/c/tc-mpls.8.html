NOM

mpls - module de manipulation mpls

SYNTAXE


tc ... action mpls { POP | PUSH | MODIFY | dec_ttl } [ CONTROL ]

POP := pop protocol MPLS_PROTO

PUSH := { push | mac_push } [ protocol MPLS_PROTO ] [ tc MPLS_TC ] [ ttl MPLS_TTL ] [ bos MPLS_BOS ] label MPLS_LABEL

MODIFY := modify [ label MPLS_LABEL ] [ tc MPLS_TC ] [ ttl MPLS_TTL ]

CONTROL := { reclassify | pipe | drop | continue | pass | goto chain CHAIN_INDEX }

DESCRIPTION

L'action mpls effectue l'encapsulation ou la décapsulation MPLS d'un paquet, reflétée par les modes d'opération POP, PUSH, MODIFY et DEC_TTL. Le mode POP nécessite l'ethertype de l'en-tête qui suit l'en-tête MPLS (par exemple IPv4 ou un autre MPLS). Il retirera l'en-tête MPLS externe et remplacera l'ethertype dans l'en-tête MAC par celui fourni. Les modes PUSH et MODIFY mettent à jour les informations de l'en-tête MPLS actuel ou ajoutent un nouvel en-tête. PUSH requiert au minimum un MPLS_LABEL. DEC_TTL ne nécessite pas d'arguments et soustrait simplement 1 du champ TTL de l'en-tête MPLS.

OPTIONS

pop
Mode de décapsulation. Nécessite le protocole de l'en-tête suivant.
push
Mode d'encapsulation. Ajoute l'en-tête MPLS entre l'en-tête MAC et l'en-tête réseau. Nécessite au minimum l'option label.
mac_push
Mode d'encapsulation. Ajoute l'en-tête MPLS avant l'en-tête MAC. Nécessite au minimum l'option label.
modify
Mode de remplacement. Le tag MPLS existant est remplacé. label, tc et ttl sont tous optionnels.
dec_ttl
Décrémente le champ TTL sur l'en-tête MPLS le plus externe.
label MPLS_LABEL
Spécifie le LABEL MPLS pour l'en-tête MPLS externe. MPLS_LABEL est un entier non signé de 20 bits, le format est détecté automatiquement (par exemple, préfixez avec '0x' pour une interprétation hexadécimale, etc.).
protocol MPLS_PROTO
Choisit le protocole à utiliser. Pour les actions push, il doit s'agir de mpls_uc ou mpls_mc (mpls_uc est la valeur par défaut). Pour les actions pop, il doit s'agir du protocole de l'en-tête suivant. Cette option ne peut pas être utilisée avec modify.
tc MPLS_TC
Choisit la valeur TC pour l'en-tête MPLS externe. Nombre décimal dans la plage de 0 à 7. La valeur par défaut est 0.
ttl MPLS_TTL
Choisit la valeur TTL pour l'en-tête MPLS externe. Nombre dans la plage de 0 à 255. Une valeur par défaut non nulle sera sélectionnée si elle n'est pas explicitement définie.
bos MPLS_BOS
Configure manuellement le bit de fin de pile pour un push d'en-tête MPLS. La valeur par défaut est que TC définit (ou efface) automatiquement le bit en fonction de l'en-tête suivant du paquet.
CONTROL
Comment continuer après l'exécution de cette action.
reclassify
Redémarre la classification en sautant vers le filtre suivant attaché au parent de cette action.
pipe
Continue avec l'action suivante, c'est le comportement par défaut.
drop
Le paquet sera rejeté sans exécuter d'autres actions.
continue
Continue la classification avec le filtre suivant dans la ligne.
pass
Retourne à la qdisc appelante pour le traitement du paquet. Ceci termine le processus de classification.

EXEMPLES

L'exemple suivant encapsule les paquets IP entrants sur eth0 dans MPLS avec un label 123 et les envoie sur eth1 :

#tc qdisc add dev eth0 handle ffff: ingress
#tc filter add dev eth0 protocol ip parent ffff: flower \
	action mpls push protocol mpls_uc label 123  \
	action mirred egress redirect dev eth1

Dans cet exemple, les paquets MPLS unicast entrants sur eth0 sont décapsulés et redirigés vers eth1 :

#tc qdisc add dev eth0 handle ffff: ingress
#tc filter add dev eth0 protocol mpls_uc parent ffff: flower \
	action mpls pop protocol ipv4  \
	action mirred egress redirect dev eth1

Voici un autre exemple, où les trames Ethernet entrantes sont encapsulées dans MPLS avec le label 123 et TTL 64. Ensuite, un en-tête Ethernet externe est ajouté et la trame résultante est finalement envoyée sur eth1 :

#tc qdisc add dev eth0 ingress
#tc filter add dev eth0 ingress matchall \
	action mpls mac_push label 123 ttl 64 \
	action vlan push_eth \
		dst_mac 02:00:00:00:00:02 \
		src_mac 02:00:00:00:00:01 \
	action mirred egress redirect dev eth1

L'exemple suivant suppose que les paquets MPLS entrants avec le label 123 transportent des trames Ethernet. Les en-têtes Ethernet et MPLS externes sont dépouillés, puis la trame Ethernet interne est envoyée sur eth1 :

#tc qdisc add dev eth0 ingress
#tc filter add dev eth0 ingress protocol mpls_uc \
	flower mpls_label 123 mpls_bos 1 \
	action vlan pop_eth \
	action mpls pop protocol teb \
	action mirred egress redirect dev eth1
