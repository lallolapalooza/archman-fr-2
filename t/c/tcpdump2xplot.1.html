TCPDUMP2XPLOT(1) Manuel des commandes générales TCPDUMP2XPLOT(1)

NOM

tcpdump2xplot — convertit la sortie de tcpdump en entrée xplot pour analyse

SYNTAXE

tcpdump2xplot [-?] [-c] [-help] [-list[nom_fichier]] [-plot[nom_fichier]] [-q] [-r] [-s] [-t] [-w]

DESCRIPTION

tcpdump2xplot prend la sortie de

tcpdump -tt -S ...
et la trace en termes de numéro de séquence par rapport au temps, avec d'autres informations affichées (par exemple, la fenêtre TCP, les accusés de réception, etc.).

OPTIONS

-?, -help affiche un message d'aide.

-c, « cumulatif », ajoute toutes les données provenant d'un serveur.

-list[nom_fichier] affiche la liste des fichiers de tracé générés dans nom_fichier.

-plot[nom_fichier] trace les paquets provenant du fichier nom_fichier. Le nom_fichier peut être construit à partir d'un nom d'hôte et d'un numéro de port, par exemple : abc.def.com:1234. Par défaut, c'est

hote_source:port_source-hote_destination:port_destination.xplot
où hote_source, port_source, hote_destination, port_destination sont extraits comme conversations des données tcpdump.

-q signifie « quiet » (silencieux) --- pas de sortie visible.

-r signifie utiliser des numéros de séquence relatifs.

-s signifie diviser les conversations sur les SYN TCP.

-t convertit le temps en nombre décimal de secondes.

-w trace la fenêtre TCP.

EXEMPLES

VOIR AUSSI

tcpdump(1), xplot(1)

BOGUES

tcpdump2xplot peut ne pas traiter correctement la sortie de tcpdump qui n'est pas TCP. Filtrez pour ne garder que TCP ou soyez prudent.
