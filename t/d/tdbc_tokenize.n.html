tdbc::tokenize(n) Connectivité base de données TDBC tdbc::tokenize(n)

NOM

tdbc::tokenize - Tokeniseur SQL de TDBC

SYNTAXE

package require tdbc 1.0
tdbc::tokenize chaîne

DESCRIPTION

Par souci de commodité pour les pilotes de bases de données, Tcl Database Connectivity (TDBC) fournit une commande pour décomposer le code SQL en jetons afin que les variables liées puissent être facilement identifiées et substituées.

La commande tdbc::tokenize accepte comme paramètre une chaîne qui est censée contenir une ou plusieurs instructions SQL. Elle renvoie une liste de sous-chaînes ; la concaténation de ces sous-chaînes donnera la chaîne originale. Chaque sous-chaîne est l'un des éléments suivants :

[1]
Une variable liée, qui commence par l'un des caractères ':', '@', ou '$'. Le reste de la chaîne est le nom de la variable et sera composé de caractères alphanumériques et de traits de soulignement. (Le caractère initial ne sera pas un chiffre.)
[2]
Un point-virgule qui sépare deux instructions SQL.
[3]
Autre chose dans une instruction SQL. Le tokeniseur ne tente pas d'analyser le SQL ; il identifie simplement les variables liées (en les distinguant des chaînes similaires apparaissant entre guillemets ou dans des commentaires) et les délimiteurs d'instruction.
