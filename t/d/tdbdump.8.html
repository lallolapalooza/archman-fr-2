TDBDUMP(8) Outils d'administration système TDBDUMP(8)

NOM

tdbdump - outil pour imprimer le contenu d'un fichier TDB

SYNTAXE

tdbdump [-k nom_clé] [-e] [-h] [-x] {nom_fichier}

DESCRIPTION

Cet outil fait partie de la suite samba(1).

tdbdump est un utilitaire très simple qui 'déverse' le contenu d'un fichier TDB (Trivial DataBase) sur la sortie standard dans un format lisible par l'homme.

Cet outil peut être utilisé pour diagnostiquer des problèmes avec les fichiers TDB. Il est destiné à ceux qui connaissent un peu le fonctionnement interne de Samba.

OPTIONS

-h

Obtenir les informations d'aide.

-k nom_clé

L'option -k limite le déversement à une seule clé, si elle est trouvée.

-e

L'option -e tente de déverser à partir d'une base de données corrompue. Naturellement, un tel déversement est, au mieux, peu fiable.

-x

L'option -x modifie les données de sortie pour en faire un vidage hexadécimal, par rapport au mélange par défaut de vidage ASCII et hexadécimal.

VERSION

Cette page de manuel est correcte pour la version 3 de la suite Samba.
