tdbc::mysql(n) Connectivité base de données Tcl tdbc::mysql(n)

NOM

tdbc::mysql - Pont TDBC-MYSQL

SYNOPHIS

package require tdbc::mysql 1.0

tdbc::mysql::connection create db ?-option valeur...?
tdbc::mysql::connection new ?-option valeur...?

tdbc::mysql::datasources ?-system|-user?

tdbc::mysql::drivers

tdbc::mysql::datasource commande nomDriver ?mot-clé-valeur?...

DESCRIPTION

Le pilote tdbc::mysql fournit une interface de base de données conforme à la connectivité de base de données Tcl (TDBC) et permet à un script Tcl de se connecter à une base de données MySQL.

La connexion à une base de données MySQL est établie en appelant tdbc::mysql::connection create, en lui passant le nom à donner au descripteur de base de données et un ensemble de paires -option-valeur. Les options disponibles sont énumérées sous OPTIONS DE CONNEXION ci-dessous. Alternativement, tdbc::mysql::connection new peut être utilisé pour créer une connexion de base de données avec un nom attribué automatiquement. La valeur de retour de tdbc::mysql::connection new est le nom qui a été choisi pour le descripteur de connexion.

L'effet secondaire de tdbc::mysql::connection create est la création d'une nouvelle connexion de base de données. Voir tdbc::connection(n) pour les détails sur la façon d'utiliser la connexion pour manipuler une base de données.

OPTIONS DE CONNEXION

La commande d'objet tdbc::mysql::connection create prend en charge les options -encoding, -isolation, -readonly et -timeout communes à tous les pilotes TDBC. L'option -encoding échouera toujours sauf si l'encodage est utf-8 ; la connexion à la base de données utilise toujours l'encodage UTF-8 pour pouvoir transférer des caractères Unicode arbitraires. L'option -readonly doit être 0, car MySQL n'offre pas de connexions en lecture seule.

En outre, les options suivantes sont reconnues :

-host nomHote
Se connecte à l'hôte spécifié par nomHote. Cette option doit être définie lors de la création initiale de la connexion ; elle ne peut pas être modifiée après la connexion. Par défaut, connexion à l'hôte local.
-port nombre
Se connecte à un serveur MySQL écoutant sur le port spécifié par nombre. Cette option ne peut pas être modifiée après la connexion. Elle est utilisée uniquement lorsque host est spécifié et n'est pas localhost.
-socket chemin
Se connecte à un serveur MySQL écoutant sur le socket Unix ou le tuyau nommé spécifié par chemin. Cette option ne peut pas être modifiée après la connexion. Elle est utilisée uniquement lorsque -host n'est pas spécifié ou est localhost.
-user nom
Présente nom comme nom d'utilisateur au serveur MySQL. Par défaut, il s'agit de l'ID utilisateur actuel.
-passwd motDePasse
-password motDePasse
Ces deux options sont synonymes. Elles présentent le motDePasse donné comme mot de passe de l'utilisateur au serveur MySQL. Par défaut, aucun mot de passe n'est présenté.
-database nom
-db nom
Ces deux options sont synonymes. Elles présentent le nom donné comme nom de la base de données par défaut à utiliser dans les requêtes MySQL. Si non spécifié, la base de données par défaut de l'utilisateur actuel est utilisée.
-interactive indicateur
La valeur de indicateur doit être une valeur booléenne. Si elle est true (ou équivalent), le délai d'attente par défaut est défini pour un utilisateur interactif, sinon, le délai d'attente par défaut est défini pour un utilisateur batch. Cette option n'est significative que lors de la connexion initiale. Lorsque vous utilisez la méthode configure sur une connexion MySQL, utilisez l'option -timeout pour définir le délai d'attente souhaité.
-ssl_ca
-ssl_capath
-ssl_cert
-ssl_cipher
-ssl_key
Ces cinq options définissent l'autorité de certification, le chemin de recherche de l'autorité de certification, le certificat SSL, le chiffrement de transfert et la clé SSL aux arguments string donnés. Ces options ne peuvent être spécifiées que lors de la connexion initiale à une base de données, pas dans la méthode configure d'une connexion existante. Par défaut, le SSL n'est pas utilisé.

EXEMPLES

tdbc::mysql::connection -user joe -passwd sesame -db joes_database

Se connecte au serveur MySQL sur l'hôte local en utilisant la méthode de connexion par défaut, en présentant l'ID utilisateur 'joe' et le mot de passe 'sesame'. Utilise 'joes_database' comme nom de base de données par défaut.

METHODES DE CONNEXION ADDITIONNELLES

En plus des méthodes habituelles sur l'objet tdbc::connection(n), les connexions à une base de données MySQL prennent en charge une méthode supplémentaire :

$connection evaldirect sqlStatement
Cette méthode prend le sqlStatement donné et l'interprète comme du code SQL natif MySQL et l'évalue sans la préparer. L'instruction ne peut pas contenir de substitutions de variables. Le jeu de résultats est renvoyé sous forme de liste de listes, chaque sous-liste étant la liste des colonnes d'une ligne de résultat formatée sous forme de chaînes de caractères. Notez que le formatage des chaînes est effectué par MySQL et non par Tcl, de sorte que des détails tels que l'apparence des nombres à virgule flottante peuvent varier. Cette commande n'est pas recommandée pour tout ce où les méthodes habituelles prepare ou preparecall fonctionnent correctement. Elle est fournie afin que les instructions de langage de gestion de données qui ne sont pas implémentées dans l'API de requêtes préparées de MySQL, telles que CREATE DATABASE ou CREATE PROCEDURE, puissent être exécutées.
