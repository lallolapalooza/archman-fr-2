tdbc::postgres(n) Connectivité Base de Données Tcl tdbc::postgres(n)

NOM

tdbc::postgres - Pont TDBC-POSTGRES

SYNOPIS

package require tdbc::postgres 1.0

tdbc::postgres::connection create db ?-option valeur...?
tdbc::postgres::connection new ?-option valeur...?

DESCRIPTION

Le pilote tdbc::postgres fournit une interface de base de données qui est conforme à la connectivité de base de données Tcl (TDBC) et permet à un script Tcl de se connecter à une base de données Postgres.

La connexion à une base de données POSTGRES est établie en invoquant tdbc::postgres::connection create, en lui passant le nom à donner au handle de la base de données et un ensemble de paires -option-valeur. Les options disponibles sont énumérées sous OPTIONS DE CONNEXION ci-dessous. Alternativement, tdbc::postgres::connection new peut être utilisé pour créer une connexion de base de données avec un nom attribué automatiquement. La valeur de retour de tdbc::postgres::connection new est le nom qui a été choisi pour le handle de connexion.

L'effet secondaire de tdbc::postgres::connection create est de créer une nouvelle connexion de base de données. Voir tdbc::connection(n) pour les détails sur la façon d'utiliser la connexion pour manipuler une base de données.

OPTIONS DE CONNEXION

La commande d'objet tdbc::postgres::connection create prend en charge les options -encoding, -isolation, -readonly et -timeout communes à tous les pilotes TDBC. L'option -timeout n'affectera que le processus de connexion; une fois connectée, cette valeur sera ignorée et ne pourra pas être modifiée après la connexion.

De plus, les options suivantes sont reconnues (ces options doivent être définies lors de la création initiale de la connexion; elles ne peuvent pas être modifiées après la connexion) :

-hote nomhote
Se connecte à l'hôte spécifié par nomhote. Par défaut, se connecte en utilisant un socket de domaine Unix local.
-hoteaddr adresse
Se connecte à l'hôte spécifié par l'adresse IP donnée. Si -hote et -hoteaddr sont tous deux donnés, la valeur de -hote est ignorée. Par défaut, se connecte en utilisant un socket de domaine Unix local.
-port nombre
Se connecte à un serveur Postgres écoutant sur le port spécifié par nombre. Il n'est utilisé que lorsque hote ou hostaddr est spécifié.
-utilisateur nom
Présente nom comme nom d'utilisateur au serveur Postgres. Par défaut, utilise l'identifiant utilisateur courant.
-mdp motdepasse
-motdepasse motdepasse
Ces deux options sont synonymes. Elles présentent le motdepasse donné comme mot de passe de l'utilisateur au serveur Postgres. Par défaut, aucun mot de passe n'est présenté.
-base_de_donnees nom
-bd nom
Ces deux options sont synonymes. Elles présentent le nom donné comme nom de la base de données par défaut à utiliser dans les requêtes Postgres. Si non spécifié, la base de données par défaut pour l'utilisateur courant est utilisée.
-options opts
Ceci définit opts comme options de ligne de commande supplémentaires envoyées au serveur.
-tty fichier
Cette option est ignorée sur les nouveaux serveurs. Auparavant, elle spécifiait où envoyer la sortie de débogage. Cette option est laissée pour la compatibilité avec les anciens serveurs.
-modes_ssl mode
Cette option détermine si une connexion SSL sera négociée avec le serveur et avec quelle priorité. Il existe quatre modes : disable tentera uniquement une connexion SSL non chiffrée; allow négociera, en essayant d'abord une connexion non-SSL, puis si cela échoue, en essayant une connexion SSL; prefer (par défaut) négociera, en essayant d'abord une connexion SSL, puis si cela échoue, en essayant une connexion non-SSL normale; require tentera uniquement une connexion SSL. Si PostgreSQL est compilé sans support SSL, l'utilisation de l'option require provoquera une erreur, et les options allow et prefer seront tolérées mais le pilote sera incapable de négocier une connexion SSL.
-requiert_ssl
Cette option est obsolète au profit du réglage -modes_ssl. La valeur du flag doit être une valeur booléenne. Si elle est true (ou équivalent), le pilote refusera alors de se connecter si le serveur n'accepte pas une connexion SSL. La valeur par défaut est false (ou équivalent), et agit de la même manière que -modes_ssl preferred
-service
Il spécifie un nom de service dans le fichier pg_service.conf qui contient des paramètres de connexion supplémentaires. Cela permet aux applications de spécifier uniquement un nom de service afin que les paramètres de connexion puissent être gérés centralement. Référez-vous à la Documentation PostgreSQL ou au fichier PREFIX/share/pg_service.conf.sample pour les détails.

EXEMPLES

tdbc::postgres::connection -utilisateur joe -mdp sesame -bd joes_database

Se connecte au serveur Postgres sur l'hôte local en utilisant la méthode de connexion par défaut, en présentant l'identifiant utilisateur 'joe' et le mot de passe 'sesame'. Utilise 'joes_database' comme nom de base de données par défaut.
