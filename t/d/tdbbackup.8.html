TDBBACKUP(8) Outils d'administration système TDBBACKUP(8)

NOM

tdbbackup - outil pour sauvegarder et valider l'intégrité des fichiers .tdb de samba

SYNTAXE

tdbbackup [-s suffixe] [-v] [-h] [-n taille_hash] [-l]

DESCRIPTION

Cet outil fait partie de la suite samba(1).

tdbbackup est un outil qui peut être utilisé pour sauvegarder les fichiers .tdb de samba. Cet outil peut également être utilisé pour vérifier l'intégrité des fichiers .tdb avant le démarrage de samba ou pendant le fonctionnement normal. S'il détecte des dommages sur le fichier et qu'il trouve une sauvegarde précédente, le fichier de sauvegarde sera restauré.

OPTIONS

-h

Obtenir des informations d'aide.

-s suffixe

L'option -s permet à l'administrateur de spécifier une extension pour la sauvegarde du fichier. Ainsi, il est possible de conserver un historique des fichiers de sauvegarde tdb en utilisant un nouveau suffixe pour chaque sauvegarde.

-v

L'option -v vérifiera la base de données pour détecter des dommages (données corrompues) qui, s'ils sont détectés, provoqueront la restauration de la sauvegarde.

-n taille_hash

L'option -n définit la taille du hash pour la nouvelle base de données tdb de sauvegarde.

-l

Cette option désactive tout verrouillage, en passant TDB_NOLOCK à tdb_open_ex(). N'utilisez cette option que pour les fichiers de base de données qui ne sont utilisés par aucun autre processus ! Et également uniquement s'il n'est pas possible autrement d'ouvrir la base de données, par exemple les bases de données qui ont été créées avec le verrouillage mutex.

COMMANDES

INFORMATIONS GÉNÉRALES

L'utilitaire tdbbackup peut être exécuté en toute sécurité à tout moment. Il a été conçu pour pouvoir être utilisé à tout moment afin de valider l'intégrité des fichiers tdb, même pendant le fonctionnement de Samba. L'utilisation typique de la commande sera :

tdbbackup [-s suffixe] *.tdb

Avant de redémarrer samba, la commande suivante peut être exécutée pour valider les fichiers .tdb :

tdbbackup -v [-s suffixe] *.tdb

Les fichiers .tdb de Samba sont stockés dans divers emplacements, assurez-vous de sauvegarder tous les fichiers .tdb du système. Les fichiers importants incluent :

•secrets.tdb - l'emplacement habituel est dans le répertoire /usr/local/samba/private, ou sur certains systèmes dans /etc/samba.
•passdb.tdb - l'emplacement habituel est dans le répertoire /usr/local/samba/private, ou sur certains systèmes dans /etc/samba.
•*.tdb situés dans le répertoire /usr/local/samba/var ou sur certains systèmes dans les répertoires /var/cache ou /var/lib/samba.
