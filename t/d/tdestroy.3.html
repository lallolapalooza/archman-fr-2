tsearch(3) Manuel des fonctions de bibliothèque tsearch(3)

NOM

tsearch, tfind, tdelete, twalk, twalk_r, tdestroy - gérer un arbre de recherche binaire

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <search.h>
typedef enum { preorder, postorder, endorder, leaf } VISIT;
void *tfind(const void *key, void *const *rootp,
            typeof(int (const void *, const void *)) *compar);
void *tsearch(const void *key, void **rootp,
            typeof(int (const void *, const void *)) *compar);
void *tdelete(const void *restrict key, void **restrict rootp,
            typeof(int (const void *, const void *)) *compar);
void twalk(const void *root,
            typeof(void (const void *nodep, VISIT which, int depth))
                *action);
#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <search.h>
void twalk_r(const void *root,
            typeof(void (const void *nodep, VISIT which, void *closure))
                *action,
            void *closure);
void tdestroy(void *root,
            typeof(void (void *nodep)) *free_node);

DESCRIPTION

tsearch(), tfind(), twalk(), et tdelete() gèrent un arbre de recherche binaire. Ils sont généralisés de l'algorithme T de Knuth (6.2.2). Le premier champ de chaque nœud de l'arbre est un pointeur vers l'élément de données correspondant. (Le programme appelant doit stocker les données réelles.) compar pointe vers une routine de comparaison, qui prend des pointeurs vers deux éléments. Elle doit retourner un entier qui est négatif, zéro ou positif, selon que le premier élément est inférieur, égal ou supérieur au second.

tsearch() recherche un élément dans l'arbre. key pointe vers l'élément recherché. rootp pointe vers une variable qui pointe vers la racine de l'arbre. Si l'arbre est vide, la variable pointée par rootp doit être mise à NULL. Si l'élément est trouvé dans l'arbre, alors tsearch() retourne un pointeur vers le nœud de l'arbre correspondant. (Autrement dit, tsearch() retourne un pointeur vers un pointeur vers l'élément de données.) Si l'élément n'est pas trouvé, alors tsearch() l'ajoute et retourne un pointeur vers le nœud de l'arbre correspondant.

tfind() est similaire à tsearch(), sauf que si l'élément n'est pas trouvé, alors tfind() retourne NULL.

tdelete() supprime un élément de l'arbre. Ses arguments sont les mêmes que ceux de tsearch().

twalk() effectue un parcours en profondeur d'abord, de gauche à droite, d'un arbre binaire. root pointe vers le nœud de départ du parcours. Si ce nœud n'est pas la racine, seule une partie de l'arbre sera visitée. twalk() appelle la fonction utilisateur action chaque fois qu'un nœud est visité (c'est-à-dire trois fois pour un nœud interne, et une fois pour une feuille). action, à son tour, prend trois arguments. Le premier argument est un pointeur vers le nœud visité. La structure du nœud n'est pas spécifiée, mais il est possible de caster le pointeur en pointeur vers pointeur vers un élément pour accéder à l'élément stocké dans le nœud. L'application ne doit pas modifier la structure pointée par cet argument. Le second argument est un entier qui prend l'une des valeurs preorder, postorder, ou endorder selon qu'il s'agit de la première, deuxième ou troisième visite du nœud interne, ou la valeur leaf si c'est la visite unique d'un nœud feuille. (Ces symboles sont définis dans <search.h>.) Le troisième argument est la profondeur du nœud ; le nœud racine a une profondeur zéro.

(Plus communément, preorder, postorder, et endorder sont connus sous les noms de preorder, inorder, et postorder : avant de visiter les enfants, après le premier et avant le second, et après avoir visité les enfants. Ainsi, le choix du nom postorder est assez déroutant.)

twalk_r() est similaire à twalk(), mais au lieu de l'argument depth, le pointeur d'argument closure est passé à chaque invocation de la fonction de rappel d'action, inchangé. Ce pointeur peut être utilisé pour passer des informations à et depuis la fonction de rappel de manière thread-safe, sans recourir à des variables globales.

tdestroy() supprime tout l'arbre pointé par root, libérant toutes les ressources allouées par la fonction tsearch(). Pour les données de chaque nœud de l'arbre, la fonction free_node est appelée. Le pointeur vers les données est passé comme argument à la fonction. Si aucun travail de ce type n'est nécessaire, free_node doit pointer vers une fonction qui ne fait rien.

VALEUR DE RETOUR

tsearch() retourne un pointeur vers un nœud correspondant dans l'arbre, ou vers le nœud nouvellement ajouté, ou NULL s'il n'y avait pas assez de mémoire pour ajouter l'élément. tfind() retourne un pointeur vers le nœud, ou NULL si aucun correspondant n'est trouvé. S'il y a plusieurs éléments correspondant à la clé, l'élément dont le nœud est retourné n'est pas spécifié.

tdelete() retourne un pointeur vers le parent du nœud supprimé, ou NULL si l'élément n'a pas été trouvé. Si le nœud supprimé était le nœud racine, tdelete() retourne un pointeur invalide qui ne doit pas être accédé.

tsearch(), tfind(), et tdelete() retournent également NULL si rootp était NULL à l'entrée.

NOTES

twalk() prend un pointeur vers la racine, tandis que les autres fonctions prennent un pointeur vers une variable qui pointe vers la racine.

tdelete() libère la mémoire requise pour le nœud de l'arbre. L'utilisateur est responsable de la libération de la mémoire pour les données correspondantes.

L'exemple de programme dépend du fait que twalk() ne fait plus référence à un nœud après avoir appelé la fonction utilisateur avec les arguments "endorder" ou "leaf". Cela fonctionne avec l'implémentation de la bibliothèque GNU, mais n'est pas documenté dans System V.

NOM

tdestroy - détruire un arbre de recherche d'arbres

BIBLIOTHÈQUE

Bibliothèque C standard (intro(3))

SYNTAXE

#include <search.h>
void tdestroy(void *root, void (*free_node)(void *));

DESCRIPTION

La fonction tdestroy détruit l'arbre dont la racine est indiquée par root. Le paramètre free_node est un pointeur vers une fonction qui doit être appelée pour libérer la mémoire de chaque élément de l'arbre. Si free_node est NULL, la fonction free est utilisée par défaut.

L'appelant est responsable de fournir une fonction free_node qui correspond à la manière dont les éléments de l'arbre ont été alloués.

La fonction tdestroy parcourt l'arbre en utilisant un parcours post-ordre, appelant free_node pour chaque nœud. Le nœud racine lui-même sera également libéré par cet appel.

VALEUR DE RETOUR

Aucune.

ATTRIBUTS

Pour une explication des termes ci-dessous, voir attributes(7).

Chaîne Attribut
Forme de la fonction GNU | SLEEP_IRQL_PASSIVE_LEVEL

NORMES

Aucune.

HISTORIQUE

La fonction tdestroy est apparue dans le cadre de l'implémentation du sous-système d'arbre de recherche par arbres des pages de manuel GNU.

NOTES

Si l'arbre a été construit à l'aide de tsearch, les éléments insérés dans l'arbre sont généralement des pointeurs vers des données allouées par malloc. Dans ce cas, le paramètre free_node doit être free.

Il est important de noter que tdestroy libère la mémoire de chaque nœud de l'arbre, y compris la structure de données du nœud elle-même (qui est généralement allouée par malloc lors de l'insertion dans l'arbre par tsearch). Si les données stockées dans chaque nœud ont également été allouées dynamiquement, le paramètre free_node doit d'abord libérer ces données, puis la mémoire du nœud lui-même.

Si plusieurs pointeurs pointent vers la même donnée, et que cette donnée n'est pas libérée lorsqu'elle n'est plus utilisée, une utilisation incorrecte de tdestroy peut entraîner des erreurs de double libération. L'implémentation standard de tsearch garantit que si une clé existe déjà dans l'arbre, le pointeur vers les données existantes est retourné au lieu d'un nouveau pointeur. Par conséquent, si vous allouez dynamiquement les données avant d'appeler tsearch, vous devez libérer les données uniquement si le pointeur retourné par tsearch est différent du pointeur que vous avez fourni. Le code d'exemple ci-dessous illustre cette approche.

EXEMPLES

 /* Compilé avec -l
#include <search.h>
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
static void *root = NULL;
static void *
xmalloc(size_t n)
{
    void *p;
    p = malloc(n);
    if (p)
        return p;
    fprintf(stderr, "insufficient memory\n");
    exit(EXIT_FAILURE);
}
static int
compare(const void *pa, const void *pb)
{
    if (*(int *) pa < *(int *) pb)
        return -1;
    if (*(int *) pa > *(int *) pb)
        return 1;
    return 0;
}
static void
action(const void *nodep, VISIT which, int depth)
{
    int *datap;
    switch (which) {
    case preorder:
        break;
    case postorder:
        datap = *(int **) nodep;
        printf("%6d\n", *datap);
        break;
    case endorder:
        break;
    case leaf:
        datap = *(int **) nodep;
        printf("%6d\n", *datap);
        break;
    }
}
int
main(void)
{
    int  *ptr;
    int  **val;
    srand(time(NULL));
    for (unsigned int i = 0; i < 12; i++) {
        ptr = xmalloc(sizeof(*ptr));
        *ptr = rand() & 0xff;
        val = tsearch(ptr, &root, compare);
        if (val == NULL)
            exit(EXIT_FAILURE);
        if (*val != ptr)
            free(ptr);
    }
    twalk(root, action);
    tdestroy(root, free);
    exit(EXIT_SUCCESS);
}
