NOM

tdbc - Connectivité de base de données Tcl

SYNOPSIS

package require tdbc 1.0
package require tdbc::pilote version
tdbc::pilote::connection create db ?-option valeur...?

DESCRIPTION

Tcl Database Connectivity (TDBC) est une interface commune permettant aux programmes Tcl d'accéder aux bases de données SQL. Elle est implémentée par une série de pilotes de base de données : des modules séparés, chacun adaptant Tcl à l'interface d'un système de base de données particulier. Tous les pilotes implémentent une série de commandes communes pour la manipulation de la base de données. Ces commandes sont toutes nommées dynamiquement, car elles représentent toutes des objets dans le système de base de données. Elles incluent les connexions, qui représentent les connexions à une base de données ; les instructions, qui représentent les instructions SQL ; et les ensembles de résultats, qui représentent les ensembles de lignes résultant de l'exécution des instructions. Tous ceux-ci ont leurs propres pages de manuel, listées sous VOIR AUSSI.

De plus, TDBC lui-même possède quelques procédures de service qui intéressent principalement les auteurs de pilotes. VOIR AUSSI les énumère également.

VOIR AUSSI

Tdbc_Init(3), tdbc::connection(n), tdbc::mapSqlState(n), tdbc::resultset(n), tdbc::statement(n), tdbc::tokenize(n), tdbc::mysql(n), tdbc::odbc(n), tdbc::postgres(n), tdbc::sqlite3(n)
