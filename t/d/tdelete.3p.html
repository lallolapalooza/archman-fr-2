TDELETE(3P) Manuel du programmeur POSIX TDELETE(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

tdelete, tfind, tsearch, twalk — gérer un arbre de recherche binaire

SYNTAXE

#include <search.h>
void *tdelete(const void *restrict key, void **restrict rootp,
    int(*compar)(const void *, const void *));
void *tfind(const void *key, void *const *rootp,
    int(*compar)(const void *, const void *));
void *tsearch(const void *key, void **rootp,
    int (*compar)(const void *, const void *));
void twalk(const void *root,
    void (*action)(const void *, VISIT, int));

DESCRIPTION

Les fonctions tdelete(), tfind(), tsearch() et twalk() manipulent des arbres de recherche binaires. Les comparaisons sont effectuées avec une routine fournie par l'utilisateur, dont l'adresse est passée comme argument compar. Cette routine est appelée avec deux arguments, qui sont des pointeurs vers les éléments comparés. L'application doit s'assurer que la routine fournie par l'utilisateur renvoie un entier inférieur, égal ou supérieur à 0, selon que le premier argument doit être considéré comme inférieur, égal ou supérieur au second argument. La fonction de comparaison n'a pas besoin de comparer chaque octet, des données arbitraires peuvent donc être contenues dans les éléments en plus des valeurs comparées.

La fonction tsearch() construit et accède à l'arbre. L'argument key est un pointeur vers un élément à accéder ou à stocker. S'il existe un nœud dans l'arbre dont l'élément est égal à la valeur pointée par key, un pointeur vers ce nœud trouvé sera renvoyé. Sinon, la valeur pointée par key sera insérée (c'est-à-dire qu'un nouveau nœud est créé et la valeur de key est copiée dans ce nœud), et un pointeur vers ce nœud sera renvoyé. Seuls les pointeurs sont copiés, l'application doit donc s'assurer que la routine appelante stocke les données. L'argument rootp pointe vers une variable qui pointe vers le nœud racine de l'arbre. Une valeur de pointeur nulle pour la variable pointée par rootp indique un arbre vide ; dans ce cas, la variable sera définie pour pointer vers le nœud qui sera la racine du nouvel arbre.

Comme tsearch(), tfind() recherche un nœud dans l'arbre, renvoyant un pointeur vers celui-ci s'il est trouvé. Cependant, s'il n'est pas trouvé, tfind() renvoie un pointeur nul. Les arguments de tfind() sont les mêmes que ceux de tsearch().

La fonction tdelete() supprime un nœud d'un arbre de recherche binaire. Les arguments sont les mêmes que ceux de tsearch(). La variable pointée par rootp sera modifiée si le nœud supprimé était la racine de l'arbre. Si le nœud supprimé était la racine de l'arbre et n'avait pas d'enfants, la variable pointée par rootp sera mise à un pointeur nul. La fonction tdelete() renvoie un pointeur vers le parent du nœud supprimé, ou un pointeur non nul non spécifié si le nœud supprimé était le nœud racine, ou un pointeur nul si le nœud n'est pas trouvé.

Si tsearch() ajoute un élément à un arbre, ou si tdelete() supprime avec succès un élément d'un arbre, l'utilisation concurrente de cet arbre dans un autre thread, ou l'utilisation de pointeurs produits par un appel précédent à tfind() ou tsearch() produit des résultats indéfinis.

La fonction twalk() traverse un arbre de recherche binaire. L'argument root est un pointeur vers le nœud racine de l'arbre à traverser. (N'importe quel nœud d'un arbre peut être utilisé comme racine pour une traversée en dessous de ce nœud.) L'argument action est le nom d'une routine à invoquer à chaque nœud. Cette routine est, à son tour, appelée avec trois arguments. Le premier argument est l'adresse du nœud visité. La structure pointée par cet argument n'est pas spécifiée et ne doit pas être modifiée par l'application, mais il doit être possible de caster un pointeur-vers-nœud en un pointeur-vers-pointeur-vers-élément pour accéder à l'élément stocké dans le nœud. Le deuxième argument est une valeur d'un type d'énumération :

typedef enum { preorder, postorder, endorder, leaf } VISIT;

(défini dans <search.h>), selon qu'il s'agit de la première, de la deuxième ou de la troisième visite du nœud (lors d'une traversée en profondeur d'abord, de gauche à droite de l'arbre), ou s'il s'agit d'une feuille. Le troisième argument est le niveau du nœud dans l'arbre, la racine étant au niveau 0.

Si la fonction appelante modifie le pointeur vers la racine, le résultat est indéfini.

Si les fonctions pointées par action ou compar (pour l'une quelconque de ces fonctions de recherche binaire) modifient l'arbre, les résultats sont indéfinis.

Ces fonctions sont thread-safe uniquement tant que plusieurs threads n'accèdent pas au même arbre.

VALEUR DE RETOUR

Si le nœud est trouvé, tsearch() et tfind() renvoient un pointeur vers celui-ci. Sinon, tfind() renvoie un pointeur nul, et tsearch() renvoie un pointeur vers l'élément inséré.

Un pointeur nul est renvoyé par tsearch() s'il n'y a pas assez d'espace disponible pour créer un nouveau nœud.

Un pointeur nul est renvoyé par tdelete(), tfind() et tsearch() si rootp est un pointeur nul à l'entrée.

La fonction tdelete() renvoie un pointeur vers le parent du nœud supprimé, ou un pointeur non nul non spécifié si le nœud supprimé était le nœud racine, ou un pointeur nul si le nœud n'est pas trouvé.

La fonction twalk() ne renvoie pas de valeur.

ERREURS

Aucune erreur n'est définie.

EXEMPLES

Le code suivant lit des chaînes de caractères et stocke des structures contenant un pointeur vers chaque chaîne et le nombre de ses caractères. Il parcourt ensuite l'arbre, affichant les chaînes stockées et leur longueur par ordre alphabétique.

#include <limits.h>
#include <search.h>
#include <stdlib.h>
#include <string.h>
#include <stdio.h>
struct element {      /* Des pointeurs vers ceux-ci sont stockés dans l'arbre. */
    int     count;
    char    string[];
};
void  *root = NULL;          /* Ceci pointe vers la racine. */
int main(void)
{
    char   str[_POSIX2_LINE_MAX+1];
    int    length = 0;
    struct element *elementptr;
    void   *node;
    void   print_node(const void *, VISIT, int);
    int    node_compare(const void *, const void *),
           delete_root(const void *, const void *);
    while (fgets(str, sizeof(str), stdin))  {
        /* Définir l'élément. */
        length = strlen(str);
        if (str[length-1] == '\n')
            str[--length] = '\0';
        elementptr = malloc(sizeof(struct element) + length + 1);
        strcpy(elementptr->string, str);
        elementptr->count = 1;
        /* Placer l'élément dans l'arbre. */
        node = tsearch((void *)elementptr, &root, node_compare);
        if (node == NULL) {
            fprintf(stderr,
                    "tsearch: Pas assez d'espace disponible\n");
            exit(EXIT_FAILURE);
        }
        else if (*(struct element **)node != elementptr) {
            /* Un nœud contenant l'élément existe déjà */
            (*(struct element **)node)->count++;
            free(elementptr);
        }
    }
    twalk(root, print_node);
    /* Supprimer tous les nœuds de l'arbre */
    while (root != NULL) {
        elementptr = *(struct element **)root;
        printf("suppression du nœud : string = %s,  count = %d\n",
               elementptr->string,
               elementptr->count);
        tdelete((void *)elementptr, &root, delete_root);
        free(elementptr);
    }
    return 0;
}
/*
 *  Cette routine compare deux nœuds, basée sur un
 *  ordre alphabétique du champ de chaîne.
 */
int
node_compare(const void *node1, const void *node2)
{
    return strcmp(((const struct element *) node1)->string,
        ((const struct element *) node2)->string);
}

UTILISATION DE L'APPLICATION

L'argument root pour twalk() est un niveau d'indirection inférieur aux arguments rootp pour tdelete() et tsearch().

Il existe deux nomenclatures utilisées pour désigner l'ordre dans lequel les nœuds de l'arbre sont parcourus. La fonction twalk() utilise preorder, postorder et endorder pour désigner respectivement le parcours d'un nœud avant ses enfants, après son enfant gauche et avant son enfant droit, et après ses deux enfants. La nomenclature alternative utilise preorder, inorder et postorder pour désigner les mêmes parcours, ce qui pourrait entraîner une certaine confusion sur le sens de postorder.

Étant donné que la valeur de retour de tdelete() est un pointeur non nul non spécifié dans le cas où la racine de l'arbre a été supprimée, les applications ne doivent utiliser la valeur de retour de tdelete() que comme indication de succès ou d'échec et ne doivent pas supposer qu'elle peut être déréférencée. Certaines implémentations, dans ce cas, retourneront un pointeur vers la nouvelle racine de l'arbre (ou vers un arbre vide si le nœud racine supprimé était le seul nœud de l'arbre) ; d'autres implémentations retourneront des pointeurs non nuls arbitraires.
