NOM

tdbc::mapSqlState - Mapper SQLSTATE à la classe d'erreur

SYNTAXE

package require tdbc 1.0
tdbc::mapSqlState sqlstate

DESCRIPTION

La commande tdbc::mapSqlState accepte une chaîne qui est censée être un 'état SQL' de cinq caractères tel que retourné par une base de données SQL lors d'une erreur. Elle examine les deux premiers caractères de la chaîne et retourne une classe d'erreur sous forme de nom lisible par l'homme et la machine (par exemple, FEATURE_NOT_SUPPORTED, DATA_EXCEPTION ou INVALID_CURSOR_STATE).

La spécification TDBC exige que les pilotes de base de données retournent une description d'une erreur dans le code d'erreur lorsqu'une erreur se produit. La description est une chaîne qui contient au moins quatre éléments : "TDBC errorClass sqlstate driverName details...". La commande tdbc::mapSqlState offre un moyen pratique pour un pilote TDBC de générer l'élément errorClass étant donné l'état SQL retourné par une base de données.
