NOM

tdbrestore - outil pour créer un fichier TDB à partir d'une sortie tdbdump

SYNTAXE

tdbrestore {nom_fichier_tdb}

DESCRIPTION

Cet outil fait partie de la suite samba(1).

tdbrestore est un utilitaire très simple qui 'restaure' le contenu d'un fichier de vidage dans un fichier TDB (Trivial DataBase). Le fichier de vidage est obtenu à partir de la commande tdbdump.

Cet outil attend sur l'entrée standard le contenu du vidage et écrira le tdb dans le paramètre nom_fichier_tdb.

Cet outil peut être utilisé pour décompresser le contenu de tdb en vue de sauvegarde.

VERSION

Cette page de manuel est correcte pour la version 3 de la suite Samba.
