TDBTOOL(8) Outils d'administration système TDBTOOL(8)

NOM

tdbtool - manipuler le contenu des fichiers TDB

SYNTAXE

tdbtool

tdbtool [-l] FICHIERTDB [COMMANDES...]

DESCRIPTION

Cet outil fait partie de la suite samba(1).

tdbtool est un outil pour afficher et modifier le contenu des fichiers TDB (Trivial DataBase) de Samba. Chacune des commandes listées ci-dessous peut être entrée de manière interactive ou fournie sur la ligne de commande.

OPTIONS

-l

Cette option désactive tout verrouillage, en passant TDB_NOLOCK à tdb_open_ex(). N'utilisez ceci que pour les fichiers de base de données qui ne sont utilisés par aucun autre processus ! Et également seulement s'il n'est pas autrement possible d'ouvrir la base de données, par exemple pour les bases de données qui ont été créées avec verrouillage mutex.

COMMANDES

create FICHIERTDB

Crée une nouvelle base de données nommée FICHIERTDB.

open FICHIERTDB

Ouvre une base de données existante nommée FICHIERTDB.

erase

Efface la base de données actuelle.

dump

Affiche la base de données actuelle sous forme de chaînes.

cdump

Affiche la base de données actuelle sous forme d'enregistrements de connexion.

keys

Affiche les clés de la base de données actuelle sous forme de chaînes.

hexkeys

Affiche les clés de la base de données actuelle sous forme de valeurs hexadécimales.

info

Affiche des informations récapitulatives sur la base de données actuelle.

insert CLE DONNEES

Insère un enregistrement dans la base de données actuelle.

move CLE FICHIERTDB

Déplace un enregistrement de la base de données actuelle vers FICHIERTDB.

store CLE DONNEES

Stocke (remplace) un enregistrement dans la base de données actuelle.

storehex CLE DONNEES

Stocke (remplace) un enregistrement dans la base de données actuelle où la clé et les données sont au format hexadécimal.

show CLE

Affiche un enregistrement par sa clé.

delete CLE

Supprime un enregistrement par sa clé.

list

Affiche la table de hachage et la liste libre de la base de données actuelle.

free

Affiche la base de données actuelle et la liste libre.

! COMMANDE

Exécute la commande système donnée.

first

Affiche le premier enregistrement de la base de données actuelle.

next

Affiche l'enregistrement suivant dans la base de données actuelle.

check

Vérifie l'intégrité de la base de données actuelle.

repack

Réempaquette une base de données en utilisant un fichier temporaire pour supprimer la fragmentation.

quit

Quitte tdbtool.

CAVEATS

Le contenu des fichiers TDB de Samba est privé à l'implémentation et ne doit pas être modifié avec tdbtool.

VERSION

Cette page de manuel est correcte pour la version 3.6 de la suite Samba.

ÉTAT DE SORTIE

Le programme tdbtool retourne 0 si l'opération a réussi, ou 1 si l'opération a échoué.
