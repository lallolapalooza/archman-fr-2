NOM

tkpp - interface graphique pour pp écrite en Perl/Tk.

SYNOPSIS

Il vous suffit d'exécuter la commande : tkpp

DESCRIPTION

Tkpp est une interface graphique pour pp, qui peut transformer des scripts Perl en fichiers PAR autonomes, scripts Perl ou exécutables.

Vous pouvez enregistrer la ligne de commande générée, charger et enregistrer votre configuration GUI Tkpp. Ci-dessous une brève explication de l'interface graphique Tkpp.

Menu

Fichier -> Enregistrer ligne de commande

Lorsque vous construisez ou affichez la ligne de commande dans l'interface graphique Tkpp, vous pouvez enregistrer la ligne de commande dans un fichier séparé. Cette ligne de commande peut être exécutée depuis un terminal.

Fichier -> Enregistrer la configuration

Vous pouvez enregistrer la configuration de votre interface graphique (toutes les options utilisées) pour la charger et l'exécuter la prochaine fois.

Fichier -> Charger la configuration

Charge votre fichier de configuration enregistré. Toutes les options enregistrées seront définies dans l'interface graphique.

Fichier -> Quitter

Ferme Tkpp.

Aide -> Documentation Tkpp

Affiche la documentation POD de Tkpp.

Aide -> Documentation pp

Affiche la documentation POD de pp.

Aide -> À propos de Tkpp

Affiche la version et les auteurs de Tkpp.

Aide -> À propos de pp

Affiche la version et les auteurs de pp ( pp --version).

Onglets GUI

Il y a cinq onglets dans l'interface graphique : Options Générales, Informations, Taille, Autres Options et Sortie.

Tous les onglets contiennent toutes les options qui peuvent être utilisées avec pp. Toutes les options par défaut de pp sont conservées. Vous pouvez maintenant définir les options comme vous le souhaitez. Lorsque vous avez terminé, vous pouvez afficher la ligne de commande ou commencer à construire votre paquet. Vous aurez l'onglet de sortie pour voir les messages d'erreur ou les messages détaillés.

NOTES

Sous le système Win32, la construction est exécutée dans un processus séparé, donc l'interface graphique n'est pas figée.

La première fois que vous utiliserez Tkpp, il vous sera demandé d'installer certains modules CPAN pour utiliser l'interface graphique (comme Tk, Tk::ColoredButton...).
