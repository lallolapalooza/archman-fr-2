NOM

tkremind - interface graphique pour le programme Remind

SYNTAXE

tkremind [options] [fichier_lecture [fichier_ecriture [fichier_configuration]]]

DESCRIPTION

TkRemind est une interface graphique pour le programme Remind. Elle fournit une interface conviviale qui vous permet de consulter votre calendrier et d'ajouter des rappels sans apprendre la syntaxe de Remind. Bien que toutes les fonctionnalités de Remind ne soient pas disponibles avec TkRemind, TkRemind vous donne la possibilité d'éditer les commandes de rappel qu'il crée. Cela vous permet d'apprendre la syntaxe de Remind, puis d'ajouter des fonctionnalités supplémentaires à mesure que vous devenez un programmeur Remind plus expérimenté.

TkRemind est écrit en Tcl et nécessite la version 8.5 (ou supérieure) ainsi que l'extension tcllib. Il nécessite également un binaire wish. Si vous utilisez Tcl/Tk 8.5, vous pourriez également avoir besoin de l'extension Img ou tkpng pour gérer les images PNG.

OPTIONS DE LIGNE DE COMMANDE

TkRemind n'a pas d'options de ligne de commande en soi. Cependant, il transmet à Remind tout argument de ligne de commande commençant par - en tant qu'option. De plus, TkRemind respecte les options -m et -b1 et ajuste son apparence en conséquence.

Fichier_lecture est le fichier à partir duquel TkRemind lit les rappels. Il est au format standard Remind. Fichier_ecriture est le fichier dans lequel TkRemind écrit les rappels que vous ajoutez via l'interface graphique. Si Fichier_lecture est omis, il prend par défaut la valeur $HOME/.reminders. Si Fichier_ecriture est omis, il prend par défaut la valeur de Fichier_lecture.

Vous pourriez souhaiter avoir un Fichier_ecriture différent de Fichier_lecture si vous voulez collecter tous les rappels de TkRemind en un seul endroit. Supposons que votre fichier principal soit $HOME/.reminders et que vous vouliez que TkRemind écrive ses rappels dans $HOME/.tkreminders. Dans $HOME/.reminders, incluez la ligne :

INCLUDE [getenv("HOME")]/.tkreminders

Fichier_configuration est le fichier dans lequel TkRemind stocke ses options. S'il est omis, il prend par défaut la valeur $HOME/.config/tkremindrc.

Si $HOME/.reminders est un répertoire, alors TkRemind prend par défaut la lecture de $HOME/.reminders et l'écriture des nouveaux rappels dans $HOME/.reminders/100-tkremind.rem. Si vous voulez conserver vos rappels dans un répertoire $HOME/.reminders, vous devriez créer ce répertoire avant de démarrer TkRemind.

LA FENETRE CALENDRIER

Lorsque vous démarrez TkRemind, il affiche un calendrier pour le mois en cours, avec la date du jour mise en évidence. Les rappels sont inscrits dans chaque case du calendrier. Si une case contient de nombreux rappels, vous pouvez la faire défiler de haut en bas en faisant glisser le bouton 2 de la souris dans la case. Notez qu'il n'y a pas d'indication spécifique pour une case surchargée ; vous devrez simplement remarquer que la case semble complètement pleine.

NAVIGATION

Pour passer au mois précédent ou suivant, cliquez respectivement sur les boutons <- ou ->. Vous pouvez également utiliser les touches fléchées gauche/droite ou PageUp/PageDown pour naviguer.

Pour revenir au mois en cours, cliquez sur Today ou appuyez sur la touche Inicio. Pour aller à un mois spécifique, cliquez sur Go To Date.... Cela fait apparaître une boîte de dialogue qui vous permet de sélectionner un mois et d'entrer une année. Une fois que vous avez fait cela, cliquez sur Go pour aller à la date, ou sur Cancel pour annuler.

Pour quitter TkRemind, cliquez sur Quit.

AJOUT DE RAPPELS

Pour ajouter un rappel, cliquez sur le bouton 1 sur le numéro de n'importe quel jour dans le calendrier. La boîte de dialogue Add Reminder... apparaîtra, avec des valeurs prédéfinies pour le jour sur lequel vous avez cliqué.

La boîte de dialogue comporte six groupes de contrôles de base. Les trois premières lignes sélectionnent l'un des trois types de rappels. Choisissez le type de rappel avec les boutons radio, et choisissez les valeurs des jours, mois et années en sélectionnant les valeurs dans les menus déroulants. Les menus déroulants apparaissent lorsque vous cliquez sur les boutons de valeurs en relief.

Le contrôle suivant spécifie une date d'expiration pour le rappel. Sélectionnez la case à cocher pour activer une date d'expiration, et remplissez les valeurs à l'aide des menus déroulants.

Le troisième contrôle spécifie combien de préavis vous souhaitez (le cas échéant), et si les week-ends et les jours fériés sont comptés ou non lors du calcul du préavis.

Le quatrième contrôle spécifie quels jours Remind considère comme faisant partie du week-end. Cela peut affecter l'interprétation de « weekday » (jour de semaine) dans les deuxième et troisième types de rappels.

Le cinquième groupe de contrôles associe une heure et une durée possible au rappel. Vous pouvez également spécifier un préavis, potentiellement répété.

Le sixième contrôle vous permet de spécifier si le rappel est une tâche à faire (TODO) et, le cas échéant, sa date d'achèvement. Taper une barre oblique (« / ») dans le champ « Complete through: » remplit automatiquement la date de l'entrée du calendrier. Sinon, entrez une date d'achèvement sous la forme AAAA-MM-JJ. Vous pouvez également entrer un nombre dans le champ « Max overdue days: » pour limiter le nombre de jours après la date limite pendant lesquels Remind vous rappellera la tâche.

Le septième contrôle spécifie ce que Remind doit faire si un rappel tombe un jour férié ou un week-end.

Entrez le corps du rappel dans le champ de saisie de texte Summary:. Si vous le souhaitez, vous pouvez entrer un emplacement, une URL et une description plus longue dans les champs Location:, URL: et Description:. Si vous entrez quelque chose ici, ils seront ajoutés en tant qu'éléments INFO au rappel.

Pour ajouter le rappel au fichier de rappels, cliquez sur Add to reminder file. Pour fermer la boîte de dialogue sans ajouter le rappel au fichier, cliquez sur Cancel. Pour prévisualiser le rappel, cliquez sur Preview reminder. Cela fait apparaître la boîte de dialogue Preview reminder.

PREVISUALISATION DES RAPPELS

La boîte de dialogue Preview reminder est un excellent moyen d'apprendre Remind. Elle affiche la commande Remind qui réalise le rappel que vous avez entré à l'aide de la boîte de dialogue Add Reminder.... Vous pouvez éditer le rappel, accédant ainsi aux fonctionnalités avancées de Remind. Vous pouvez également l'utiliser simplement pour expérimenter et découvrir les idiomes de Remind pour exprimer différents types de rappels.

VISUALISER LES RAPPELS D'UNE JOURNEE

Cliquez avec le bouton droit de la souris sur le numéro de n'importe quel jour dans le calendrier pour faire apparaître une fenêtre affichant les rappels de ce jour en mode Agenda. Vous pouvez cliquer avec le bouton gauche ou droit sur l'indicateur de la date et de l'heure actuelles en bas de la fenêtre pour voir les rappels d'aujourd'hui en mode Agenda.

Dans l'affichage du mode Agenda, survoler un rappel affichera des informations auxiliaires telles qu'un Emplacement, une URL ou une Description. Cliquer sur un rappel ouvrira un éditeur sur la commande REM qui a créé le rappel.

IMPRESSION

Pour imprimer le calendrier du mois en cours, cliquez sur Print... dans la fenêtre principale du calendrier. Cela fait apparaître la boîte de dialogue d'impression. L'impression produit soit un fichier PostScript, soit envoie du PostScript à une commande UNIX. (Si vous avez rem2pdf installé, vous pouvez choisir de produire une sortie PDF plutôt que PostScript.)

Sélectionnez la destination d'impression en choisissant soit To file:, soit To command: dans la boîte de dialogue d'impression. Appuyez sur Browse... pour faire apparaître un explorateur de fichiers. Dans l'explorateur de fichiers, vous pouvez entrer un nom de fichier dans le champ de texte, double-cliquer sur un nom de fichier dans la liste, ou double-cliquer sur un répertoire pour naviguer dans le système de fichiers. Vous pouvez également taper les quelques premiers caractères d'un nom de fichier dans le champ de texte et appuyer sur espace pour compléter le nom avec la première entrée correspondante.

La boîte Match: contient un joker de nom de fichier qui filtre les fichiers dans la liste. Vous pouvez modifier le filtre et appuyer sur Entrée pour re-scanner le répertoire.

Sélectionnez la taille de papier et l'orientation appropriées. Activez Fill page si vous voulez que le calendrier remplisse la page. Ce devrait être le cas normal, sauf si vous avez de nombreux rappels pour un jour particulier. (Voir la documentation de Rem2PS ou rem2pdf.)

MODIFICATION DES RAPPELS

Si vous avez créé un rappel avec TkRemind, il deviendra rouge lorsque le curseur de la souris passera dessus dans la fenêtre du calendrier. Cliquez sur le bouton 1 sur le rappel et une boîte de dialogue s'affichera, dont l'état sera identique à celui utilisé pour créer le rappel. À ce stade, vous pouvez modifier le rappel en éditant les entrées de la boîte de dialogue et en sélectionnant Remplacer le rappel. Vous pouvez supprimer complètement le rappel en sélectionnant Supprimer le rappel. Les boutons restants, Aperçu du rappel et Annuler fonctionnent de la même manière que la boîte de dialogue dans "AJOUT DE RAPPELS."

Notez que si vous modifiez un rappel (en utilisant Aperçu du rappel), les modifications que vous avez apportées ne sont pas conservées dans la boîte de dialogue. Vous ne devez pas essayer de modifier de tels rappels ; vous devez les retaper dans la boîte de dialogue Aperçu du rappel.

Si le rappel n'a pas été créé avec TkRemind, vous ne pouvez pas le modifier avec TkRemind.

UTILISATION D'UN ÉDITEUR DE TEXTE

Si vous avez correctement défini l'option « éditeur de texte », un clic droit sur un rappel ouvrira un éditeur de texte sur le fichier contenant le rappel. Le curseur sera positionné sur la ligne qui a généré le rappel. De plus, si vous avez un rappel qui peut être modifié avec un éditeur mais qui n'a pas été créé à l'aide de TkRemind, il sera souligné lorsque vous déplacerez le curseur dessus, et vous pourrez le modifier dans un éditeur de texte en cliquant avec le bouton gauche ou droit sur le rappel.

Si un rappel contient des éléments INFO de localisation ou de description, le passage de la souris sur le rappel fera apparaître une fenêtre contenant les informations de localisation et/ou de description.

HYPERLIENS

Si un rappel contient une chaîne d'information « Url : », un clic du milieu ouvrira l'URL à l'aide de xdg-open.

ERREURS

S'il y a des erreurs dans votre fichier de rappels, le bouton « Filet... » devient « Erreurs... ». Cliquez sur « Erreurs... » pour voir la sortie d'erreur de Remind. Cliquez sur « OK » pour fermer la fenêtre d'erreurs ; cela fait que le bouton de la fenêtre principale TkRemind revient à « Filet... ». Vous pouvez cliquer sur n'importe quel message d'erreur pour ouvrir un éditeur sur le fichier et le numéro de ligne qui ont causé l'erreur.

RAPPELS EN ARRIÈRE-PLAN

Si vous créez des rappels « programmés », TkRemind les mettra dans la file d'attente en arrière-plan et fera apparaître des boîtes lorsqu'ils seront déclenchés. De plus, si vous avez créé le rappel en utilisant TkRemind, vous aurez la possibilité de « désactiver » le rappel pour le reste de la journée. TkRemind gère la mise en file d'attente des rappels en arrière-plan en exécutant Remind en mode serveur, décrit plus loin.

OPTIONS

Le dernier bouton de la fenêtre du calendrier, Options, vous permet de configurer certains aspects de TkRemind. Les options de configuration sont :

Démarrer iconifié
Si cette option est sélectionnée, TkRemind démarre iconifié. Sinon, il démarre dans une fenêtre normale.
Afficher les rappels du jour au démarrage
Si cette option est sélectionnée, TkRemind affiche une fenêtre de texte contenant les rappels qui seraient émis par « remind -q -a -r » au démarrage, et lorsque la date change à minuit.
Confirmer la sortie
Si cette option est sélectionnée, vous serez invité à confirmer lorsque vous appuierez sur Quitter. Sinon, TkRemind quittera sans demander.
Fermer automatiquement les rappels contextuels après une minute
Si cette option est sélectionnée, les boîtes de rappel contextuelles seront fermées après une minute. Sinon, elles restent à l'écran jusqu'à ce que vous les écartiez explicitement.
Utiliser les notifications système lors de l'émission d'un rappel
Cette option est disponible uniquement pour la version Tcl/Tk 9.0 ou ultérieure, ou si vous avez le programme notify-send installé ; elle sera grisée si aucune de ces conditions n'est remplie. Si elle est sélectionnée, lorsqu'un rappel est affiché, il est également envoyé au système de notification de bureau, provoquant l'apparition d'une notification.
Bip du terminal lors de l'affichage d'un rappel
Si cette option est sélectionnée, TkRemind émet un bip de la cloche du terminal lorsqu'un rappel mis en file d'attente apparaît.
Désiconifier la fenêtre du calendrier lors de l'affichage d'un rappel
Si cette option est sélectionnée, fait ce qu'elle dit.
Exécuter une commande lors de l'affichage d'un rappel
Si cette entrée n'est pas vide, la commande spécifiée est exécutée chaque fois qu'un rappel en arrière-plan apparaît.
Alimenter le rappel affiché à l'entrée standard de la commande
Si cette option est sélectionnée, le texte du rappel est transmis à la commande décrite ci-dessus. Le texte du rappel est précédé de « HH:MM », où HH:MM est l'heure du rappel.
Envoyer les rappels par e-mail ici si le popup n'est pas écarté
Si vous entrez une adresse e-mail non vide dans ce champ, TkRemind vous enverra un rappel par e-mail si vous n'écartez pas la boîte de dialogue popup dans la minute. Ceci est utile si vous avez besoin de quitter votre terminal mais que vous souhaitez que vos rappels vous « suivent » par e-mail.
Nom ou adresse IP du serveur SMTP
TkRemind utilise une connexion SMTP directe pour envoyer des e-mails. Entrez l'adresse IP de votre serveur SMTP ici.
Éditeur de texte
Ceci spécifie un éditeur de texte à appeler lorsqu'un rappel est cliqué avec le bouton droit. La séquence « %d » est remplacée par le numéro de ligne du fichier contenant le rappel, et « %s » est remplacé par le nom du fichier. Des chaînes utiles pourraient être « emacs +%d %s » ou « gvim +%d %s ».
Arguments supplémentaires pour Remind
Ceci spécifie tous les arguments supplémentaires qui doivent être passés à Remind lorsque TkRemind appelle remind. À moins que vous ne sachiez ce que vous faites, laissez ceci vide.
Changer la police des entrées...
Ce bouton fait apparaître une boîte de dialogue de sélection de police qui vous permet de changer la police utilisée pour dessiner les éléments du calendrier dans les cases du calendrier.
Changer la police des en-têtes...
Similaire à Changer la police des entrées, mais s'applique aux en-têtes du calendrier (les noms du mois et des jours ainsi que les numéros des jours).

Une fois que vous avez configuré les options comme vous le souhaitez, appuyez sur Appliquer les options pour les mettre en vigueur, Enregistrer les options pour les mettre en vigueur et les enregistrer dans $HOME/.config/tkremindrc, ou Annuler pour annuler toutes les modifications que vous avez apportées.

MISES À JOUR IMMÉDIATES

Si vous exécutez TkRemind sous Linux et que Remind a été compilé avec le support inotify(7), alors TkRemind redessine la fenêtre du calendrier immédiatement si $HOME/.reminders change (ou, s'il s'agit d'un répertoire, si des fichiers dans ce répertoire changent.)

Cela permet à TkRemind de réagir immédiatement aux rappels modifiés à la main ou aux fichiers de rappels qui sont importés d'un autre système de calendrier (par exemple, vous pourriez avoir une tâche cron qui importe périodiquement vos entrées Google Calendar au format Remind.)

DIVERS

TkRemind effectue des vérifications de cohérence basiques lorsque vous ajoutez ou prévisualisez un rappel. Cependant, si vous modifiez un rappel dans le previewer, TkRemind ne vérifie pas le rappel modifié. Vous pouvez produire des rappels illégaux qui peuvent causer des problèmes. (C'est une bonne raison d'isoler les rappels de TkRemind dans un fichier séparé.)

TkRemind ne vérifie pas le corps du rappel de quelque manière que ce soit. Vous pouvez utiliser les séquences de substitution normales de Remind dans le corps. De plus, si vous utilisez le collage d'expressions dans le corps, TkRemind ne valide pas les expressions.

Lorsque TkRemind appelle Remind, il fournit l'option :

-itkremind=1

sur la ligne de commande. Ainsi, dans votre fichier Remind, vous pouvez inclure :

IF defined("tkremind")
	# Je suis probablement appelé par TkRemind
ENDIF

Vous pouvez utiliser ceci pour activer certains rappels de différentes manières pour TkRemind (par exemple).

TkRemind utilise des balises pour suivre les rappels dans le fichier script. Vous pouvez certainement mélanger des rappels « faits main » avec des rappels créés par TkRemind si vous êtes conscient des règles et limitations suivantes :

o
TkRemind utilise des TAGs de la forme TKTAGnnn où nnn est un nombre. Vous ne devriez pas utiliser de tels TAGs dans les rappels faits main.
o
Les rappels faits main ne peuvent pas être modifiés avec TkRemind, et pour tkremind(1) — Man pages — Arch Linux

MODE SERVEUR

Remind possède un mode spécial pour interagir avec des programmes comme TkRemind. Ce mode s'appelle le mode serveur et est sélectionné en fournissant l'option -zj à Remind.

En mode serveur, Remind fonctionne de manière similaire au mode daemon, sauf qu'il lit les commandes (une par ligne) depuis l'entrée standard et écrit des lignes de statut sur la sortie standard. Chaque ligne de statut est un objet JSON.

Les commandes acceptées en mode serveur sont :

QUITTER
Termine le processus Remind. La fin de fichier (EOF) sur l'entrée standard fait de même. Remind se termine immédiatement sans imprimer de ligne de statut JSON.
STATUT
Retourne le nombre de rappels en file d'attente. L'objet JSON ressemble à ceci : 
{"response":"queued","nqueued":n,"command":"STATUS"}
où n est le nombre de rappels en file d'attente.
FILE D'ATTENTE ou JSONFILE D'ATTENTE
Retourne le contenu de la file d'attente. L'objet JSON ressemble à ceci : 
{"response":"queue","queue":[ ... ],"command":"QUEUE"}
La valeur de la clé queue est un tableau d'objets JSON, chacun représentant un rappel en file d'attente.
TRADUIRE Toute chaîne va ici
Retourne la traduction de "Toute chaîne va ici" selon la table de traduction de Remind. Notez qu'il doit y avoir exactement un espace après TRADUIRE et avant la chaîne que vous souhaitez traduire. L'objet JSON résultant de "TRADUIRE Nouvelle Lune" pourrait ressembler à ceci : 
{"response":"translate","translation":{"New Moon":"Nieuwe maan"},"command":"TRANSLATE"}
Comme vous pouvez le voir, la valeur de la clé translation est un objet dont la clé est le texte original et la valeur est le texte traduit. Une interface utilisateur peut utiliser TRADUIRE pour sa propre localisation ; par exemple, TkRemind l'utilise pour localiser la fenêtre contextuelle des phases de lune pour l'affichage SPÉCIAL LUNE.

Si l'argument de TRADUIRE ne se trouve pas dans la table de traduction, alors Remind ne donnera aucune réponse du tout à la commande TRADUIRE.

VIDER_TRADUCTIONS
Retourne le contenu de la table de traduction. L'objet JSON ressemble à ceci : 
{"response":"translate_dump","table":{...},"command":"TRANSLATE_DUMP"}
La valeur de la clé table est un dictionnaire de chaînes originales vers traduites.
SUPPRIMER qid
Supprime le rappel avec l'identifiant de file d'attente qid de la file.
RELIR
Relit le fichier de rappels. Retourne la ligne de statut suivante : 
{"response":"reread","command":"REREAD"}

Les lignes de statut supplémentaires écrites sont les suivantes :

{"response":"reminder","ttime":tt,"now":now,"tags":tags,"qid":qid,"body":body}
Dans cette ligne, tt est l'heure de déclenchement du rappel (exprimée sous forme de chaîne), now est l'heure actuelle, tags (s'ils sont présents) est le ou les tags associés au rappel, et body est le corps du rappel. Cette réponse fait apparaître une notification de rappel à TkRemind. qid est un identifiant unique pour ce rappel. Vous pouvez le supprimer de la file d'attente en envoyant une commande SUPPRIMER qid au serveur. Notez que les qid ne sont pas stables d'une relecture à l'autre ; si Remind se redémarre pour relire le fichier de rappels, alors les valeurs de qid sont susceptibles de changer, et tout rappel supprimé avec une commande SUPPRIMER qid sera probablement remis en file d'attente. 
{"response":"newdate"}

Cette ligne est émise chaque fois que Remind a détecté un changement de date du système. Le programme d'interface utilisateur doit redessiner son calendrier ou prendre toute autre action nécessaire.

{"response":"reread","command":"inotify"}

Si Remind a été compilé avec le support de inotify(7), alors s'il détecte un changement dans le fichier ou le répertoire de rappels de niveau supérieur, il émet la réponse ci-dessus. L'interface utilisateur doit redessiner son calendrier car cette réponse indique qu'un changement a été apporté au fichier ou au répertoire de rappels.

Veuillez noter que Remind peut écrire un message de statut à tout moment et pas seulement en réponse à une commande envoyée à son entrée standard. Par conséquent, un programme qui exécute Remind en mode serveur doit être prêt à gérer les messages de statut asynchrones.
