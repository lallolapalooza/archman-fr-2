tk_setPalette(n) Commandes intégrées Tk tk_setPalette(n)

NOM

tk_setPalette, tk_bisque - Modifier la palette de couleurs de Tk

SYNOPSIS

tk_setPalette arrière-plan

tk_setPalette nom valeur ?nom valeur ...?

tk_bisque

DESCRIPTION

La procédure tk_setPalette modifie le schéma de couleurs de Tk. Elle y parvient en modifiant les couleurs des widgets existants et en changeant la base de données d'options afin que les futurs widgets utilisent le nouveau schéma de couleurs. Si tk_setPalette est appelée avec un seul argument, cet argument est le nom d'une couleur à utiliser comme couleur de fond normale ; tk_setPalette calculera une palette de couleurs complète à partir de cette couleur de fond. Alternativement, les arguments de tk_setPalette peuvent être constitués de toute combinaison de paires nom-valeur, où le premier argument de la paire est le nom d'une option dans la base de données d'options Tk et le second argument est la nouvelle valeur à utiliser pour cette option. Les noms de base de données suivants sont actuellement pris en charge :

activeBackground	foreground	selectColor
activeForeground	highlightBackground	selectBackground
background	highlightColor	selectForeground
disabledForeground	insertBackground	troughColor

tk_setPalette essaie de calculer des valeurs par défaut raisonnables pour toutes les options que vous ne spécifiez pas. Vous pouvez spécifier des options autres que celles ci-dessus et Tk modifiera également ces options sur les widgets. Cette fonctionnalité peut être utile si vous utilisez des widgets personnalisés avec des options de couleur supplémentaires.

Une fois qu'elle a calculé la nouvelle valeur à utiliser pour chaque option de couleur, tk_setPalette parcourt la hiérarchie des widgets pour modifier les options de tous les widgets existants. Pour chaque widget, elle vérifie si l'une des options ci-dessus est définie pour le widget. Si c'est le cas, et si la valeur actuelle de l'option est celle par défaut, alors la valeur est modifiée ; si l'option a une valeur autre que celle par défaut, tk_setPalette ne la modifiera pas. La valeur par défaut d'une option est celle fournie par le widget ([lindex [$w configure $option] 3]) sauf si tk_setPalette a été exécutée précédemment, auquel cas c'est la valeur spécifiée lors de l'invocation précédente de tk_setPalette.

Après avoir modifié tous les widgets de l'application, tk_setPalette ajoute des options à la base de données d'options pour modifier les valeurs par défaut des widgets créés à l'avenir. Les nouvelles options sont ajoutées avec la priorité widgetDefault, de sorte qu'elles seront remplacées par les options du fichier .Xdefaults ou par les options spécifiées sur la ligne de commande qui crée un widget.

La procédure tk_bisque est fournie pour des raisons de compatibilité ascendante : elle restaure les couleurs de l'application au schéma de couleurs brun clair (« bisque ») utilisé dans Tk 3.6 et les versions antérieures.
