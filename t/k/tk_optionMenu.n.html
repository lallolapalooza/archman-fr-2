NOM

tk_optionMenu - Créer un bouton de menu d'options et son menu

SYNTAXE

tk_optionMenu nomChemin varName valeur ?valeur valeur ...?

DESCRIPTION

Cette procédure crée un bouton de menu d'options dont le nom est nomChemin, ainsi qu'un menu associé. Ensemble, ils permettent à l'utilisateur de sélectionner l'une des valeurs fournies par les arguments valeur. La valeur actuelle sera stockée dans la variable globale dont le nom est donné par varName et elle sera également affichée comme libellé dans le bouton de menu d'options. L'utilisateur peut cliquer sur le bouton de menu pour afficher un menu contenant toutes les valeurs et ainsi sélectionner une nouvelle valeur. Une fois qu'une nouvelle valeur est sélectionnée, elle sera stockée dans la variable et apparaîtra dans le bouton de menu d'options. La valeur actuelle peut également être modifiée en définissant la variable.

La valeur de retour de tk_optionMenu est le nom du menu associé à nomChemin, afin que l'appelant puisse modifier ses options de configuration ou le manipuler d'autres manières.

EXEMPLE

tk_optionMenu .foo maVar Foo Bar Boo Spong Wibble
pack .foo

MOTS-CLÉS

menu d'options
