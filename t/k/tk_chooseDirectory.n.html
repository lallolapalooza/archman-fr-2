tk_chooseDirectory(n) Commandes intégrées Tk tk_chooseDirectory(n)

NOM

tk_chooseDirectory - affiche une boîte de dialogue pour que l'utilisateur sélectionne un répertoire.

SYNOPSIS

tk_chooseDirectory ?option valeur ...?

DESCRIPTION

La procédure tk_chooseDirectory affiche une boîte de dialogue pour que l'utilisateur sélectionne un répertoire. Les paires option-valeur suivantes sont possibles comme arguments en ligne de commande :

-command chaîne
Spécifie le préfixe d'une commande Tcl à invoquer lorsque l'utilisateur ferme la boîte de dialogue après avoir sélectionné un élément. Ce rappel n'est pas appelé si l'utilisateur a annulé la boîte de dialogue. La commande réelle se compose de chaîne suivi d'un espace et de la valeur sélectionnée par l'utilisateur dans la boîte de dialogue. Ceci n'est disponible que sur macOS.
-initialdir nom_répertoire
Spécifie que les répertoires dans répertoire doivent être affichés lorsque la boîte de dialogue apparaît. Si ce paramètre n'est pas spécifié, le répertoire initial est le répertoire de travail courant par défaut sur les systèmes non-Windows et sur les systèmes Windows avant Vista. Sur les systèmes Vista et ultérieurs, le répertoire initial est le dernier répertoire sélectionné par l'utilisateur pour l'application par défaut. Si le paramètre spécifie un chemin relatif, la valeur de retour convertira le chemin relatif en chemin absolu.
-message chaîne
Spécifie un message à inclure dans la zone client de la boîte de dialogue. Ceci n'est disponible que sur macOS.
-mustexist booléen
Spécifie si l'utilisateur peut spécifier des répertoires inexistants. Si ce paramètre est vrai, l'utilisateur ne pourra sélectionner que des répertoires qui existent déjà. La valeur par défaut est faux.
-parent fenêtre
Fait de fenêtre le parent logique de la boîte de dialogue. La boîte de dialogue s'affiche au-dessus de sa fenêtre parente. Sur macOS, cela transforme la boîte de dialogue de fichier en une feuille attachée à la fenêtre parente.
-title chaîne_titre
Spécifie une chaîne à afficher comme titre de la boîte de dialogue. Si cette option n'est pas spécifiée, un titre par défaut sera affiché.

EXEMPLE

set dir [tk_chooseDirectory \
        -initialdir ~ -title "Choisir un répertoire"]
if {$dir eq ""} {
   label .l -text "Aucun répertoire sélectionné"
} else {
   label .l -text "Sélectionné $dir"
}
