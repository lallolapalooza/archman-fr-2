NOM

tkwait - Attendre qu'une variable change ou qu'une fenêtre soit détruite

SYNTAXE

tkwait variable nom

tkwait visibility nom

tkwait window nom

DESCRIPTION

La commande tkwait attend qu'une de plusieurs choses se produise, puis elle retourne sans prendre d'autres actions. La valeur de retour est toujours une chaîne vide. Si le premier argument est variable (ou une abréviation de celui-ci), alors le deuxième argument est le nom d'une variable globale et la commande attend que cette variable soit modifiée. Si le premier argument est visibility (ou une abréviation de celui-ci), alors le deuxième argument est le nom d'une fenêtre et la commande tkwait attend un changement dans son état de visibilité (indiqué par l'arrivée d'un événement VisibilityNotify). Cette forme est typiquement utilisée pour attendre qu'une fenêtre nouvellement créée apparaisse à l'écran avant d'entreprendre une action. Si le premier argument est window (ou une abréviation de celui-ci), alors le deuxième argument est le nom d'une fenêtre et la commande tkwait attend que cette fenêtre soit détruite. Cette forme est typiquement utilisée pour attendre qu'un utilisateur ait terminé d'interagir avec une boîte de dialogue avant d'utiliser le résultat de cette interaction.

Pendant que la commande tkwait attend, elle traite les événements de manière normale, de sorte que l'application continue de répondre aux interactions de l'utilisateur. Si un gestionnaire d'événements invoque à nouveau tkwait, l'appel imbriqué à tkwait doit se terminer avant que l'appel extérieur ne puisse se terminer.
