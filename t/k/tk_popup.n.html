NOM

tk_popup - Poster un menu contextuel

SYNTAXE

tk_popup menu x y ?entrée?

DESCRIPTION

Cette procédure affiche un menu à une position donnée sur l'écran et configure Tk de sorte que le menu et ses enfants en cascade puissent être parcourus avec la souris ou le clavier. Menu est le nom d'un widget menu et x et y sont les coordonnées de la racine où afficher le menu. Si entrée est omis ou une chaîne vide, le coin supérieur gauche du menu est positionné au point donné. Sinon, entrée donne l'index d'une entrée dans menu et le menu sera positionné de sorte que l'entrée soit positionnée sur le point donné.

EXEMPLE

Comment attacher un simple menu contextuel à un widget.

# Créer un menu
set m [menu .popupMenu]
$m add command -label "Exemple 1" -command bell
$m add command -label "Exemple 2" -command bell
# Créer quelque chose auquel l'attacher
pack [label .l -text "Cliquez-moi !"]
# Organiser pour que le menu apparaisse lorsque le label est cliqué
bind .l <1> {tk_popup .popupMenu %X %Y}
