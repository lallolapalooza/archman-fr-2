NOM

tkmib - un navigateur graphique interactif MIB pour SNMP

SYNTAXE

tkmib

DESCRIPTION

Le protocole Simple Network Management Protocol (SNMP) fournit un cadre d'échange d'informations de gestion entre les agents (serveurs) et les clients. Les bases d'informations de gestion (MIB) contiennent une description formelle d'un ensemble d'objets réseau qui peuvent être gérés à l'aide du SNMP pour un agent particulier. tkmib est une interface utilisateur graphique pour naviguer dans les MIB. Il est également capable d'envoyer ou de récupérer des informations de gestion SNMP vers/depuis les agents distants de manière interactive.
