NOM

tkiptun-ng - injecter quelques trames dans un réseau WPA TKIP avec QoS

SYNTAXE

tkiptun-ng [options] <interface de rejeu>

DESCRIPTION

tkiptun-ng est un outil créé par Martin Beck alias hirte, un membre de l'équipe aircrack-ng. Cet outil est capable d'injecter quelques trames dans un réseau WPA TKIP avec QoS. Il a travaillé avec Erik Tews (qui a créé l'attaque PTW) pour une conférence à PacSec 2008 : "Gone in 900 Seconds, Some Crypto Issues with WPA".

OPÉRATION

-H, --help
Affiche l'écran d'aide.
Options de filtrage :
-d <dmac>
Adresse MAC de destination.
-s <smac>
Adresse MAC source.
-m <longueur>
Longueur minimale du paquet.
-n <longueur>
Longueur maximale du paquet.
-t <tods>
Contrôle de trame, bit DS "vers".
-f <fromds>
Contrôle de trame, bit DS "depuis".
-D
Désactiver la détection du point d'accès.
Options de rejeu :
-x <nbpps>
Nombre de paquets par seconde.
-p <fctrl>
Définir le mot de contrôle de trame (hex).
-a <bssid>
Définir l'adresse MAC du point d'accès.
-c <dmac>
Définir l'adresse MAC de destination.
-h <smac>
Définir l'adresse MAC source.
-e <essid>
Définir le SSID cible.
-M <sec>
Délai d'attente d'erreur MIC en secondes. Par défaut : 60 secondes.
Options de débogage :
-K <prga>
Flux de clés pour la continuation.
-y <fichier>
Fichier de flux de clés pour la continuation.
-j
Injecter des paquets FromFS.
-P <PMK>
Clé maître de paire (PMK) pour la vérification ou le test de vulnérabilité.
-p <PSK>
Clé pré-partagée (PSK) pour calculer la PMK avec l'essid.
Options source :
-i <iface>
Capturer les paquets depuis cette interface.
-r <fichier>
Extraire les paquets de ce fichier pcap.
