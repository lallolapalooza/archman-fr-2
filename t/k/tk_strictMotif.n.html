tkvars(n) Commandes intégrées Tk tkvars(n)

NOM

geometry, tk_library, tk_patchLevel, tk_strictMotif, tk_version - Variables utilisées ou définies par Tk

DESCRIPTION

Les variables Tcl suivantes sont soit définies, soit utilisées par Tk à différents moments de son exécution :

tk_library
Cette variable contient le nom de fichier d'un répertoire contenant une bibliothèque de scripts Tcl liés à Tk. Ces scripts incluent un fichier d'initialisation qui est normalement traité à chaque démarrage d'une application Tk, ainsi que d'autres fichiers contenant des procédures qui implémentent les comportements par défaut des widgets.

La valeur initiale de tk_library est définie lorsque Tk est ajouté à un interpréteur ; cela est fait en recherchant plusieurs répertoires différents jusqu'à ce qu'un soit trouvé contenant un script de démarrage Tk approprié. Si la variable d'environnement TK_LIBRARY existe, alors le répertoire qu'elle nomme est vérifié en premier. Si TK_LIBRARY n'est pas défini ou ne fait pas référence à un répertoire approprié, alors Tk vérifie plusieurs autres répertoires basés sur un emplacement par défaut compilé, l'emplacement du répertoire de la bibliothèque Tcl, l'emplacement du binaire contenant l'application, et le répertoire de travail courant.

La variable peut être modifiée par une application pour passer à une bibliothèque différente.

tk_patchLevel
Contient une séquence d'entiers décimaux séparés par des points donnant le niveau de correctif actuel pour Tk. Le niveau de correctif est incrémenté pour chaque nouvelle version ou correctif, et il identifie de manière unique une version officielle de Tk.

Cette valeur est normalement la même que le résultat de “package require Tk”.

tk_strictMotif
Cette variable est définie à zéro par défaut. Si une application la définit à un, alors Tk tente d'adhérer autant que possible aux normes d'apparence de Motif. Par exemple, les éléments actifs tels que les boutons et les curseurs de défilement ne changeront pas de couleur lorsque le pointeur passera sur eux. Les applications modernes ne devraient normalement pas définir cette variable.
tk_version
Tk définit cette variable dans l'interpréteur pour chaque application. La variable contient le numéro de version actuel de la bibliothèque Tk sous la forme majeur.mineur. Majeur et mineur sont des entiers. Le numéro de version majeur augmente dans toute version de Tk qui inclut des changements non rétrocompatibles (c'est-à-dire lorsque les applications et scripts Tk existants peuvent devoir être modifiés pour fonctionner avec la nouvelle version). Le numéro de version mineur augmente avec chaque nouvelle version de Tk, sauf qu'il est réinitialisé à zéro lorsque le numéro de version majeur change.

VARIABLES INTERNES ET DE DÉBOGAGE

Ces variables ne devraient normalement pas être définies par le code utilisateur.

tk::Priv
Cette variable est un tableau contenant plusieurs informations qui sont privées à Tk. Les éléments de tk::Priv sont utilisés par les procédures de la bibliothèque Tk et les liaisons par défaut. Ils ne doivent pas être accédés par un code extérieur à Tk.
tk_textRedraw
tk_textRelayout
Ces variables sont définies par les widgets texte lorsque leur débogage est activé. Les valeurs écrites dans ces variables peuvent être utilisées pour tester ou déboguer les opérations des widgets texte. Ces variables sont principalement utilisées par la suite de tests de Tk.

AUTRES VARIABLES GLOBALES

Les variables suivantes sont garanties d'exister uniquement dans les exécutables wish ; la bibliothèque Tk ne les définit pas elle-même mais de nombreux environnements Tk le font.

geometry
Si définie, contient la spécification de géométrie fournie par l'utilisateur à utiliser pour la fenêtre principale Tk.
