tk_chooseColor(n) Commandes intégrées Tk tk_chooseColor(n)

NOM

tk_chooseColor - affiche une boîte de dialogue pour que l'utilisateur sélectionne une couleur.

SYNTAXE

tk_chooseColor ?option valeur ...?

DESCRIPTION

La procédure tk_chooseColor affiche une boîte de dialogue pour que l'utilisateur sélectionne une couleur. Les paires option-valeur suivantes sont possibles en tant qu'arguments de ligne de commande :

-initialcolor couleur
Spécifie la couleur à afficher dans la boîte de dialogue de couleur lorsqu'elle apparaît. couleur doit être dans un format acceptable par la fonction Tk_GetColor.
-parent fenêtre
Fait de fenêtre le parent logique de la boîte de dialogue de couleur. La boîte de dialogue de couleur est affichée au-dessus de sa fenêtre parente.
-title chaineTitre
Spécifie une chaîne de caractères à afficher comme titre de la boîte de dialogue. Si cette option n'est pas spécifiée, un titre par défaut sera affiché.

Si l'utilisateur sélectionne une couleur, tk_chooseColor retournera le nom de la couleur dans un format acceptable par Tk_GetColor. Si l'utilisateur annule l'opération, les deux commandes retourneront une chaîne vide.

EXEMPLE

button .b -bg [tk_chooseColor -initialcolor gray -title "Choisir la couleur"]

MOTS-CLÉS

couleur, sélection de couleur, dialogue
