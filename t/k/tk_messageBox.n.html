tk_messageBox(n) Commandes intégrées Tk tk_messageBox(n)

NOM

tk_messageBox - affiche une fenêtre de message et attend la réponse de l'utilisateur.

SYNOPSIS

tk_messageBox ?option valeur ...?

DESCRIPTION

Cette procédure crée et affiche une fenêtre de message avec un message spécifié par l'application, une icône et un ensemble de boutons. Chacun des boutons de la fenêtre de message est identifié par un nom symbolique unique (voir les options -type). Une fois la fenêtre de message affichée, tk_messageBox attend que l'utilisateur sélectionne l'un des boutons. Elle retourne ensuite le nom symbolique du bouton sélectionné.

Les paires option-valeur suivantes sont prises en charge :

-command chaîne
Spécifie le préfixe d'une commande Tcl à invoquer lorsque l'utilisateur ferme la boîte de dialogue. La commande réelle se compose de chaîne suivi d'un espace et du nom du bouton cliqué par l'utilisateur pour fermer la boîte de dialogue. Ceci n'est disponible que sur macOS.
-default nom
Nom donne le nom symbolique du bouton par défaut pour cette fenêtre de message (« ok », « annuler », etc.). Voir -type pour une liste des noms symboliques. Si cette option n'est pas spécifiée, le premier bouton de la boîte de dialogue sera rendu par défaut.
-detail chaîne
Spécifie un message auxiliaire au message principal donné par l'option -message. Le détail du message sera présenté sous le message principal et, là où il est supporté par le système d'exploitation, dans une police moins accentuée que le message principal.
-icon imageIcone
Spécifie une icône à afficher. imageIcone doit être l'une des suivantes : error, info, question ou warning. Si cette option n'est pas spécifiée, l'icône d'information sera affichée.
-message chaîne
Spécifie le message à afficher dans cette boîte de message. La valeur par défaut est une chaîne vide.
-parent fenêtre
Fait de fenêtre le parent logique de la boîte de message. La boîte de message est affichée au-dessus de sa fenêtre parente.
-title chaîneTitre
Spécifie une chaîne à afficher comme titre de la boîte de message. La valeur par défaut est une chaîne vide.
-type typePrédéfini
Organise l'affichage d'un ensemble prédéfini de boutons. Les valeurs suivantes sont possibles pour typePrédéfini :
abortretryignore
Affiche trois boutons dont les noms symboliques sont abort, retry et ignore.
ok
Affiche un bouton dont le nom symbolique est ok. C'est le défaut.
okcancel
Affiche deux boutons dont les noms symboliques sont ok et cancel.
retrycancel
Affiche deux boutons dont les noms symboliques sont retry et cancel.
yesno
Affiche deux boutons dont les noms symboliques sont yes et no.
yesnocancel
Affiche trois boutons dont les noms symboliques sont yes, no et cancel.

EXEMPLE

set answer [tk_messageBox -message "Voulez-vous vraiment quitter ?" \
        -icon question -type yesno \
        -detail "Sélectionnez \"Oui\" pour quitter l'application"]
switch -- $answer {
    yes exit
    no {tk_messageBox -message "Je sais que vous aimez cette application !" \
            -type ok}
