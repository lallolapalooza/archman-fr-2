NOM

tk_menuBar, tk_bindForTraversal - Support obsolète pour les barres de menus

SYNOPSIS

tk_menuBar frame ?menu menu ...?

tk_bindForTraversal arg arg ...

DESCRIPTION

Ces procédures étaient utilisées dans les versions 3.6 et antérieures de Tk pour aider à gérer les menus déroulants et implémenter la navigation au clavier dans les menus. Dans les versions 4.0 et ultérieures de Tk, elles ne sont plus nécessaires. Des stubs pour ces procédures ont été conservés pour des raisons de compatibilité descendante, mais ils n'ont aucun effet. Vous devriez supprimer les appels à ces procédures de votre code, car éventuellement les procédures disparaîtront.

À partir de Tk 8.0, vous devriez plutôt construire votre barre de menus comme un menu normal, puis la joindre au toplevel de votre choix en utilisant l'option -menu de ce widget.

VOIR AUSSI

menu(n), toplevel(n)

MOTS CLÉS

navigation au clavier, menu, barre de menus, afficher
