NOM

tk_dialog - Créer une boîte de dialogue modale et attendre une réponse

SYNOPSIS

tk_dialog fenêtre titre texte bitmap défaut chaîne chaîne ...

DESCRIPTION

Cette procédure fait partie de la bibliothèque de scripts Tk. Elle est largement obsolète au profit de tk_messageBox. Ses arguments décrivent une boîte de dialogue :

fenêtre
Nom de la fenêtre de niveau supérieur à utiliser pour la boîte de dialogue. Toute fenêtre existante portant ce nom est détruite.
titre
Texte à afficher dans la barre de titre du gestionnaire de fenêtres pour la boîte de dialogue.
texte
Message à afficher dans la partie supérieure de la boîte de dialogue.
bitmap
Si non vide, spécifie un bitmap (dans un format adapté à Tk_GetBitmap) à afficher dans la partie supérieure de la boîte de dialogue, à gauche du texte. Si cette chaîne est vide, aucun bitmap ne sera affiché dans la boîte de dialogue.
défaut
Si c'est un entier supérieur ou égal à zéro, il donne l'indice du bouton qui doit être le bouton par défaut pour la boîte de dialogue (0 pour le bouton le plus à gauche, etc.). Si c'est inférieur à zéro ou une chaîne vide, il n'y aura pas de bouton par défaut.
chaîne
Il y aura un bouton pour chacun de ces arguments. Chaque chaîne spécifie le texte à afficher dans un bouton, dans l'ordre de gauche à droite.

Après avoir créé une boîte de dialogue, tk_dialog attend que l'utilisateur sélectionne l'un des boutons, soit en cliquant dessus avec la souris, soit en appuyant sur retour pour activer le bouton par défaut (s'il y en a un). Ensuite, elle retourne l'indice du bouton sélectionné : 0 pour le bouton le plus à gauche, 1 pour le bouton adjacent, etc. Si la fenêtre de la boîte de dialogue est détruite avant que l'utilisateur ne sélectionne l'un des boutons, -1 est retourné.

Pendant qu'elle attend la réponse de l'utilisateur, tk_dialog définit une saisie locale. Cela empêche l'utilisateur d'interagir avec l'application d'une autre manière que d'activer la boîte de dialogue.

EXEMPLE

set reply [tk_dialog .foo "Le Titre" "Voulez-vous dire oui ?" \
        questhead 0 Oui Non "Je ne suis pas sûr"]
