NOM

tkerror - Commande appelée pour traiter les erreurs en arrière-plan

SYNOPSIS

tkerror message

DESCRIPTION

Remarque : depuis Tk 4.1, la commande tkerror a été renommée en bgerror car la boucle d'événements (qui l'invoque habituellement) fait maintenant partie de Tcl. Pour des raisons de compatibilité ascendante, la commande bgerror fournie par la version actuelle de Tk essaie toujours d'appeler tkerror s'il en existe une (ou une qui peut être chargée automatiquement), de sorte que les anciens scripts définissant ce gestionnaire d'erreurs devraient toujours fonctionner. Cependant, vous devriez modifier vos scripts pour utiliser bgerror au lieu de tkerror, car ce support pour l'ancien nom pourrait disparaître dans un avenir proche. Si cet appel échoue, bgerror affiche une boîte de dialogue présentant l'erreur et offrant à l'utilisateur de voir la trace de la pile. Si vous souhaitez votre propre gestion des erreurs, vous devriez remplacer directement bgerror au lieu de tkerror. La documentation de bgerror est disponible dans le cadre de la documentation Tcl.

MOTS-CLÉS

erreur en arrière-plan, signalement
