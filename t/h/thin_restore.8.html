NOM

thin_restore - restaure un fichier de métadonnées de provisionnement léger sur un périphérique ou un fichier.

SYNTAXE

thin_restore [options] -i {fichier xml} -o {périphérique|fichier}

DESCRIPTION

thin_restore restaure les métadonnées de provisionnement léger créées par la cible de device-mapper correspondante, sauvegardées dans un fichier au format XML (voir thin_dump(8)), qui peut éventuellement être prétraité avant la restauration sur un autre périphérique ou fichier. Si restaurées sur un périphérique de métadonnées, les métadonnées peuvent être traitées par la cible de device-mapper.

Cet outil ne peut pas être exécuté sur des métadonnées actives.

OPTIONS

-h, --help
Affiche l'aide et quitte.
-V, --version
Affiche les informations de version et quitte.
-q, --quiet
Supprime les messages de sortie, retourne uniquement le code de sortie.
-i, --input {fichier xml}
Fichier d'entrée contenant les métadonnées XML.
-o, --output {périphérique|fichier}
Fichier ou périphérique de sortie pour les métadonnées binaires restaurées.
    Si un fichier est utilisé pour la sortie, il doit être pré-alloué et suffisamment
    grand pour contenir les métadonnées.
--transaction-id {naturel}
Remplace l'identifiant de transaction donné dans le fichier XML d'entrée.
--data-block-size {naturel}
Remplace la taille du bloc de données donnée dans le fichier XML d'entrée.
--nr-data-blocks {naturel}
Remplace le nombre de blocs de données donné dans le fichier XML d'entrée.

EXEMPLE

Restaure les métadonnées de provisionnement léger au format XML du fichier métadonnées vers le volume logique /dev/vg/metadata pour un traitement ultérieur par la cible de device-mapper correspondante :

    $ thin_restore -i metadata -o /dev/vg/metadata

DIAGNOSTICS

thin_restore retourne un code de sortie de 0 en cas de succès ou 1 en cas d'erreur.
