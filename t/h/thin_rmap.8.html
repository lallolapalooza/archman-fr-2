NOM

thin_rmap - affiche la carte inverse d'une région allouée de manière fine (thin provisioned) depuis un périphérique ou fichier de métadonnées.

SYNTAXE

thin_rmap [options] {périphérique|fichier}

DESCRIPTION

thin_rmap affiche la carte inverse stockée dans les métadonnées sur un périphérique ou un fichier, entre une région de blocs de pool alloués de manière fine et les périphériques alloués de manière fine associés.

Cet outil ne peut pas être exécuté sur des métadonnées actives.

OPTIONS

-h, --help
Affiche l'aide et quitte.
-V, --version
Affiche les informations de version et quitte.
--region {plage de blocs}
Spécifie la plage de blocs sur le périphérique de données.
    Au moins une région doit être spécifiée. Plusieurs régions peuvent être spécifiées.
    La plage prend le format <début>..<un après la fin>. Par exemple,
    "5..45" spécifie les blocs de données 5 à 44 inclus, mais pas 45.

EXEMPLES

$ thin_rmap --region 5..45 /dev/pool-metadata

DIAGNOSTICS

thin_rmap retourne un code de sortie de 0 en cas de succès ou 1 en cas d'erreur.
