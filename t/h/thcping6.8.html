thcping6(8)

Paquet: thc-ipv6

Licences: AGPL3

thcping6(8) IPv6 thcping6(8)

NOM

thcping6

SYNTAXE

thcping6 [-EafqxO] [-e ethertype] [-H t:l:v] [-D t:l:v] [-F dst] [-e ethertype] [-L length] [-N nextheader] [-V version] [-t ttl] [-c class] [-l label] [-d size] [-S port|-U port|-T type -C code] interface src6 dst6 [srcmac [dstmac [data]]]

OPTIONS

  -T nombre       Type ICMPv6 à envoyer (défaut: 128 = ping)
  -C nombre       Code ICMPv6 à envoyer (défaut: 0)
  -S port         utiliser un paquet TCP SYN sur le port défini au lieu de ping
  -U port         utiliser un paquet UDP sur le port défini au lieu de ping
  -n count        combien de fois envoyer le paquet (défaut: 1)
  -h              afficher plus d'options en ligne de commande (aide !)
Vous pouvez placer un "x" dans src6, srcmac et dstmac pour une valeur automatique.
Construire un paquet ICMPv6/TCP/UDP avec des options d'en-tête IPv6 ou EH spéciales.
Retourne -1 en cas d'erreur ou absence de réponse, 0 pour une réponse normale, 1 pour une réponse d'erreur.
