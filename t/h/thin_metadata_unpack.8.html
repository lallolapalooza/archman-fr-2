NOM

thin_metadata_unpack - décompresse les métadonnées de provisionnement fin.

SYNTAXE

thin_metadata_unpack [options] -i {appareil|fichier} -o {appareil|fichier}

DESCRIPTION

thin_metadata_pack et thin_metadata_unpack sont utilisés pour compresser les métadonnées binaires. Utile pour le support.

thin_metadata_unpack développe les métadonnées qui ont été précédemment compressées avec thin_metadata_pack. Il produit un fichier binaire que le reste des outils thin peut utiliser.

Cet outil ne peut pas être exécuté sur des métadonnées actives.

OPTIONS

-h, --help
Affiche l'aide et quitte.
-V, --version
Affiche les informations de version et quitte.
-i, --input {appareil|fichier}
Fichier ou appareil d'entrée avec les données binaires.
-o, --output {appareil|fichier}
Fichier ou appareil de sortie pour les données binaires.
