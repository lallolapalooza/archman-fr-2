NOM

thin_dump - vide les métadonnées de provisionnement fin d'un périphérique ou d'un fichier vers la sortie standard.

SYNOPSIS

thin_dump [options] {périphérique|fichier}

DESCRIPTION

thin_dump vide les métadonnées binaires de provisionnement fin (éventuellement à partir d'un bloc alternatif; voir l'option --metadata-snap) créées par la cible de provisionnement fin device-mapper sur un périphérique ou un fichier vers la sortie standard pour analyse ou post-traitement, soit au format XML, soit en format lisible par l'homme. Les métadonnées formatées en XML peuvent être transmises à thin_restore (voir thin_restore(8)) afin de les réinsérer sur un périphérique de métadonnées (pour traitement par la cible device-mapper) ou un fichier.

Cet outil ne peut pas être exécuté sur des métadonnées actives, sauf si l'option --metadata-snap est utilisée.

OPTIONS

-h, --help
Affiche l'aide et quitte.
-V, --version
Affiche les informations de version et quitte.
-f, --format {xml|human_readable}
Choisit le format de sortie.
-r, --repair
Répare les métadonnées pendant leur vidage.
-m, --metadata-snap[=<num bloc>]
Vide l'instantané des métadonnées.
    Si le bloc n'est pas fourni, accède à l'instantané des métadonnées par défaut créé par
    la cible device-mapper de provisionnement fin, sinon essaie celui au bloc nr.
    Voir la documentation de la cible de provisionnement fin sur comment créer ou libérer
    un instantané des métadonnées et récupérer le numéro de bloc depuis le noyau.
--dev-id {naturel}
Vide le périphérique spécifié.
    Cette option peut être spécifiée plusieurs fois pour sélectionner plus d'un périphérique fin.
--transaction-id {naturel}
Remplace l'identifiant de transaction donné dans le XML d'entrée.
--data-block-size {secteurs}
Remplace la taille des blocs de données donnée dans le XML d'entrée.
--nr-data-blocks {naturel}
Remplace le nombre de blocs de données donné dans le XML d'entrée.
--skip-mappings
Ne vide pas les mappings.
-o {fichier xml}
Spécifie un fichier pour la sortie plutôt que d'écrire sur stdout.

EXEMPLES

Vide les métadonnées de provisionnement fin sur le volume logique /dev/vg/metadata vers la sortie standard en format lisible par l'homme :

    $ thin_dump -f human_readable /dev/vg/metadata
Vide les métadonnées de provisionnement fin sur le volume logique /dev/vg/metadata vers la sortie standard en format XML : 
    $ thin_dump /dev/vg/metadata
Vide l'instantané des métadonnées de provisionnement fin sur le volume logique /dev/vg/metadata vers la sortie standard en format lisible par l'homme (non traitable par thin_restore(8)) : 
    $ thin_dump --format human_readable --metadata-snap /dev/vg/metadata

DIAGNOSTICS

thin_dump retourne un code de sortie de 0 en cas de succès ou 1 en cas d'erreur.
