NOM

thin_delta - Affiche les différences dans les mappages entre deux périphériques minces.

SYNOPSIS

thin_delta [options] {périphérique|fichier}

DESCRIPTION

thin_delta vous permet de comparer les mappages dans deux volumes minces (les instantanés permettent les blocs communs entre volumes minces).

Cet outil ne peut pas être exécuté sur des métadonnées actives à moins que l'option --metadata-snap ne soit utilisée.

OPTIONS

--thin1, --snap1 {naturel}
L'identifiant numérique du premier volume mince à comparer.
--thin2, --snap2 {naturel}
L'identifiant numérique du second volume mince à comparer.
--metadata-snap [numéro de bloc]
Utiliser un instantané de métadonnées.
    Si vous voulez obtenir des informations à partir d'un pool actif, vous devrez
    prendre un instantané de métadonnées et utiliser ce commutateur. Pour que les informations
    soient significatives, vous devez vous assurer que les volumes minces que vous examinez
    ne changent pas (c'est-à-dire, n'activez pas ces volumes minces).
--verbose
Fournir des informations supplémentaires sur les mappages.
-h, --help
Afficher l'aide et quitter.
-V, --version
Afficher les informations de version et quitter.
