NOM

thumbpdf - générer des images miniatures pour un fichier PDF créé avec pdftex

SYNOPIS

thumbpdf [ OPTION... ] FICHIER_PDF

DESCRIPTION

thumbpdf est utilisé pour créer des images miniatures de pages individuelles au sein d'un document PDF (Portable Document Format).

UTILISATION

Exécutez d'abord pdftex(1) sur votre document pour créer un fichier PDF. Exécutez ensuite thumbpdf pour générer les miniatures, un fichier PDF contenant les miniatures, et un fichier pdfTeX pour inclure les miniatures dans le fichier PDF. Enfin, exécutez à nouveau pdftex(1) sur votre fichier pour créer le fichier PDF final.

thumbpdf appelle gs(1) pour générer des images PNG des pages dans FICHIER_PDF, et pdftex(1) pour créer un fichier PDF contenant les images miniatures.

OPTIONS

--help
afficher l'aide
--(no)makepng
créer des images miniatures PNG (par défaut : vrai)
--(no)makepdf
générer un nouveau fichier PDF contenant les miniatures (par défaut : vrai)
--(no)makedef
créer un fichier TeX que pdftex(1) puisse lire (par défaut : vrai)
--(no)quiet
supprimer les messages (par défaut : faux)
--(no)verbose
messages détaillés (par défaut : faux)
--(no)debug
afficher les informations de débogage pendant l'analyse (par défaut : faux)
--resolution res
résolution pour l'étape GhostScript (par défaut : 9)
--compress n
\pdfcompresslevel pour thumbpdf.pdf (0-9 ; par défaut : 9)
--device | pngdev
périphérique PNG GhostScript ; dev = `mono´, `gray´, `16´, `256´, `16m´ (par défaut : `png16m´)

FICHIERS

thumbnn.png
images miniatures PNG
thumbpdf.pdf
fichier PDF contenant les images miniatures
thumbpdf.tex
un programme pdfTeX pour inclure le fichier des miniatures
thumbpdf.log
fichier journal pdfTeX
thumbpdf.sty
un paquet LaTeX à inclure dans les fichiers pour lesquels un utilisateur souhaite générer des miniatures
