throw(n) Commandes intégrées Tcl throw(n)

NOM

throw - Générer une erreur lisible par machine

SYNOPIS

throw type message

DESCRIPTION

Cette commande provoque le déroulement de l'évaluation courante avec une erreur. L'erreur créée est décrite par les arguments type et message : type doit contenir une liste de mots décrivant l'erreur sous une forme lisible par machine (et qui constituera la partie code d'erreur du dictionnaire de résultat), et message doit contenir du texte destiné à être affiché à un être humain.

La pile sera déroulée jusqu'à ce que l'erreur soit interceptée par une commande catch ou try appropriée. Si elle atteint la boucle d'événements sans être interceptée, elle sera signalée via le mécanisme bgerror. Si elle atteint le niveau supérieur de l'évaluation de script dans tclsh, elle sera imprimée sur la console avant, dans le cas non interactif, de provoquer une sortie (le comportement dans d'autres programmes dépendra des détails de l'intégration et de l'utilisation de Tcl).

Par convention, les mots de l'argument type doivent aller du plus général au plus spécifique.

EXEMPLES

L'exemple suivant produit une erreur identique à celle produite par expr lors de la tentative de division par zéro.

throw {ARITH DIVZERO {division par zéro}} {division par zéro}
