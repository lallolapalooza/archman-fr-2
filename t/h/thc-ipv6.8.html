THC-IPv6(8) Manuel de l'administrateur système THC-IPv6(8)

NOM

The Hacker Choice's IPv6 Attack Toolkit (aka thc-ipv6)

SYNOPSIS

outil [options] ...

DESCRIPTION

Cette page de manuel documente brièvement chacun des outils de attack-toolkit6. Toutes les options ne sont pas listées ici ; pour voir la liste complète des options de chaque outil, invoquez-les avec -h.

Notez que sur Debian (si vous lisez ceci sur Debian) les noms des commandes sont préfixés par atk6-, donc par exemple l'outil alive6 devrait être invoqué comme atk6-alive6. Ceci est une modification spécifique à Debian.
address6 <adresse-mac/adresse-ipv4/adresse-ipv6> [préfixe-ipv6]
Convertit une adresse mac ou ipv4 en une adresse ipv6 (link local si aucun préfixe n'est donné comme deuxième option) ou, lorsqu'une adresse ipv6 est donnée, affiche l'adresse mac ou ipv4. Affiche toutes les variations possibles. Retourne -1 en cas d'erreur ou le nombre de variations trouvées.
alive6 <interface> [adresse-unicast-ou-multicast [routeur-distant]]
Affiche les adresses actives dans le segment. Si vous spécifiez un routeur distant, les paquets sont envoyés avec un en-tête de routage précédé d'un fragmentation.
covert_send6 <interface> <cible> <fichier> [port]
Envoie le contenu de FICHIER de manière dissimulée à la cible.
covert_send6d <interface> <fichier>
Écrit le contenu reçu de manière dissimulée dans FICHIER.
denial6 <interface> <destination> <numéro-cas-de-test>
Effectue diverses attaques par déni de service sur une cible.
detect_sniffer6 <interface> [ip-cible]
Teste si les systèmes du réseau local reniflent. Fonctionne contre les systèmes Windows, Linux, OS/X et *BSD.
dnssecwalk [-e46] <serveur-dns> <domaine>
Effectue une marche NSEC DNSSEC.
dos_mld <interface>
Cet outil empêche les nouvelles interfaces ipv6 de se mettre en place, en envoyant des réponses aux vérifications d'adresse ip6 dupliquée (DAD). Cela se traduit par un déni de service pour les nouveaux périphériques ipv6.
dos-new-ip6 <interface>
Cet outil empêche les nouvelles interfaces ipv6 de se mettre en place, en envoyant des réponses aux vérifications d'adresse ip6 dupliquée (DAD). Cela se traduit par un déni de service pour les nouveaux périphériques ipv6.
detect-new-ip6 <interface> [nom-script]
Cet outil détecte les nouvelles adresses ipv6 rejoignant le réseau local. Si un nom de script est fourni, il est exécuté avec l'adresse IPv6 détectée comme option.
dnsdict6 [-t THREADS] <domaine> [fichier-dictionnaire]
Énumère un domaine pour les entrées DNS, il utilise un fichier dictionnaire si fourni ou une liste intégrée sinon.
dnsrevenum6 <serveur-dns> <adresse-ipv6>
Effectue une énumération rapide du DNS inverse.
dump_router6 <interface>
Affiche tous les routeurs locaux et leurs informations.
dump_dhcp6 <interface>
Affiche tous les serveurs DHCPv6 et leurs informations.
exploit6 <interface> <destination> [numéro-cas-de-test]
Effectue des exploits de diverses vulnérabilités IPv6 connues (CVE) sur la destination.
extract_hosts6 <fichier>
Affiche les parties hôtes des adresses ipv6 dans le fichier.
extract_networks6 <interface>
Affiche les réseaux trouvés dans le fichier.
fake_advertise6 <interface> <adresse-ip> [adresse-cible [adresse-mac-propre]]
Annonce une adresse ipv6 sur le réseau (avec le mac propre si non défini) en l'envoyant à l'adresse multicast all-nodes si aucune cible n'est spécifiée.
fake_dhcps6 <interface> <adresse-réseau/longueur-préfixe> <serveur-dns>
Faux serveur DHCPv6. Utilisé pour configurer une adresse et définir un serveur DNS.
fake_dns6d <interface> <adresse-ipv6>
Faux serveur DNS qui sert la même adresse IPv6 pour toute requête de résolution.
fake_dnsupdate6 <serveur-dns> <fqdn> <adresse-ipv6>
Envoie de fausses requêtes de mise à jour DNS.
fake_mipv6 <interface> <adresse-domicile> <adresse-agent-domicile> <adresse-soin-de>
Si l'agent d'accueil mobile IPv6 est mal configuré pour accepter les mises à jour MIPV6 sans IPSEC, cela redirigera tous les paquets destinés à l'adresse-domicile vers l'adresse-soin-de.
fake_mld6 <interface> <adresse-multicast> [[adresse-cible] [[ttl] [[ip-propre] [adresse-mac-propre]]]]
Annonce votre présence dans un groupe multicast de votre choix.
fake_mld26 [-l] <interface> <ajouter|supprimer|interroger> [adresse-multicast [adresse-cible [ttl [ip-propre [adresse-mac-propre [adresse-mac-destination]]]]]]
Utilise le protocole MLDv2. Seule une partie de ce que le protocole est capable de faire peut être implémentée via une ligne de commande.
fake_mldrouter6 [-l] <interface> <annoncer|solliciter|terminer> [ip-propre [adresse-mac-propre]]
Annonce, supprime ou sollicite un routeur MLD - vous-même ou d'autres.
fake_pim6 [-t ttl] [-s src6] [-d dst6] <interface> {<hello> [dr_priority]|{join|prune} <voisin6> <multicast6> <cible6>}
La commande hello prend éventuellement la priorité DR (par défaut: 0).
fake_router6 <interface> <ip-du-routeur-link-local
adresse-réseau/longueur-préfixe> <mtu> [adresse-mac] Vous annonce comme routeur et tentez de devenir le routeur par défaut. Si une adresse-mac non existante est fournie, cela entraîne un déni de service.
fake_router26 <interface>
Similaire à fake_router6 avec plus d'options disponibles.
fake_solicitate6 <interface> <ip-sollicitée>
Sollicite une adresse IPv6 sur le réseau, en l'envoyant à l'adresse multicast all-nodes.
firewall6 [-u] <interface> <destination> <port> [no-cas-de-test]
Effectue diverses tentatives de contournement ACL pour vérifier les implémentations. Par défaut, utilise les ports TCP, l'option -u passe à UDP. Pour que tous les cas de test fonctionnent, le ping ICMPv6 vers la destination doit être autorisé.
flood_advertise6 <interface>
Inonde le réseau local avec des annonces de voisins.
flood_dhcpc6 <interface> [nom-domaine]
Inondateur de clients DHCP. Utilisé pour épuiser le pool d'adresses IP proposées par un serveur DHCP6. Note : si le pool est très grand, c'est plutôt inutile.
flood_mld6 <interface>
Inonde le réseau local avec des rapports MLD.
flood_mld26 <interface>
Inonde le réseau local avec des rapports MLDv2.
flood_mldrouter6 <interface>
Inonde le réseau local avec des annonces de routeurs MLD.

ATTACK-TOOLKIT6 — Summer 2015

NAME

thc-ipv6

— A collection of tools to attack a network with IPv6.

SYNOPSIS

flood_router6 <interface>

flood_router26 <interface>

flood_rs6 [-sS] interface [target]

flood_solicitate6 <interface> [target-ip]

four2six [-FHD] [-s src6] interface ipv6-to-ipv4-gateway ipv4-src ipv4-dst [port]

fragmentation6 <interface> <target-ip>

fuzz_ip6 [-x] [-t number | -T number] [-p number] [-IFSDHRJ] [-1|-2|-3|-4|-5|-6|-7] <interface> <unicast-or-multicast-address> [address-in-data-pkt]

fuzz_dhcps6 [-t number | -T number] [-e number | -T number] [-p number] [-md] [-1|-2|-3|-4|-5|-6|-7|-8] interface [domain-name]

implementation6 <interface> <destination> [test-case-number]

implementation6d <interface>

inject_alive6 [-ap] <interface>

inverse_lookup6 <interface> <mac-address>

kill_router6 <interface> <target-ip>

ndpexhaust26 <interface> [-acpPTUrR] [-s sourceip6] <target-network>

ndpexhaust6 <interface> <target-network>

node_query6 <interface> <target-ip>

parasite6 <interface> [fake-mac]

passive_discovery6 <interface> [scriptname]

randicmp6 <interface> <target-ip>

redir6 <interface> <src-ip> <target-ip> <original-router> <new-router> [new-router-mac]

redirsniff6 <interface> <victim-ip> <destination-ip> <original-router> [<new-router> [new-router-mac]]

rsmurf6 <interface> <victim-ip>

smurf6 <interface> <victim-ip> [multicast-network-address]

sendpees6 <interface> <key_length> <prefix> <victim-ip>

sendpeesmp6 <interface> <key_length> <prefix> <victim-ip>

trace6 [-d] <interface> targetaddress [port]

thcping6 <interface> <src6> <dst6> <srcmac> <dstmac> <data>

thcsyn6 [-AcDrRS] [-p port] [-s source-ip6] <interface> <target> <port>

toobig6 <interface> <target-ip> <existing-ip> <mtu>

DESCRIPTION

arpind6 <interface> <target-ip> [target-mac]
Send ICMPv6 Neighbor Solicitation to target.
creditcard6 <interface> <target-ip>
Perform various tests on the target to check if it is vulnerable to different ICMPv6 attacks.
fake_router6 <interface> [newrouter]
This tool sends fake router advertisements to the local network.
fake_scan6 <interface> <target-network>
A very fast scanner that sends fake ICMPv6 Information Request packets.
flood_dhcp6 <interface>
Flood the local network with DHCPv6 packets.
flood_echo6 <interface> <target-ip>
Flood target with ICMPv6 echo requests.
flood_ipv6 <interface> <target-ip> [port]
Flood target with ICMPv6 packets.
flood_mld6 <interface> <target-ip>
Flood target with MLDv1 packets.
flood_p2p6 <interface> <target-ip>
Flood a target network with IPv6 packets.
flood_redir6 <interface> <target> [oldrouter [newrouter]]
Flood a target with ICMPv6 redirects
flood_router6 <interface>
Flood the local network with router advertisements.
flood_router26 <interface>
Similar to flood_router6 but with more options available.
flood_rs6 [-sS] interface [target]
Flood a network with ICMPv6 router solicitation messages
flood_solicitate6 <interface> [target-ip]
Flood the network with neighbor solicitations.
four2six [-FHD] [-s src6] interface ipv6-to-ipv4-gateway ipv4-src ipv4-dst [port]
Send (spoofed) packets over a 4to6 tunnel (IPv4 packets over IPv6 networks)
fragmentation6 <interface> <target-ip>
Performs fragment firewall and implementation checks, including denial-of-service.
fuzz_ip6 [-x] [-t number | -T number] [-p number] [-IFSDHRJ] [-1|-2|-3|-4|-5|-6|-7] <interface> <unicast-or-multicast-address> [address-in-data-pkt]
Fuzzes an icmp6 packet.
fuzz_dhcps6 [-t number | -T number] [-e number | -T number] [-p number] [-md] [-1|-2|-3|-4|-5|-6|-7|-8] interface [domain-name]
Fuzzes a DHCPv6 server on specified packet types. implementation6 <interface> <destination> [test-case-number] Performs some ipv6 implementation checks, can be used to test firewalls too.
implementation6d <interface>
Identifies test packets by the implementation6 tool, useful to check what packets passed a firewall.
inject_alive6 [-ap] <interface>
This tool answers to keep-alive requests on PPPoE and 6in4 tunnels; for PPPoE0t also sends keep-alive requests. Note that the appropriate environment variable THC_IPV6_{PPPOE|6IN4} must be set. Option -a will actively send alive requests every 15 seconds. Option -p will not send replies to alive requests.
inverse_lookup6 <interface> <mac-address>
Performs an inverse address query, to get the IPv6 addresses that are assigned to a MAC address. Note that only few systems support this yet.
kill_router6 <interface> <target-ip>
Announce that target router is going down to delete it from the routing tables. If you supply a '*' as target-ip, this tool will sniff the network for RAs and immediately send the kill packet.
ndpexhaust26 <interface> [-acpPTUrR] [-s sourceip6] <target-network>
Flood the target /64 network with ICMPv6 TooBig error messages. This tool version is manyfold more effective than ndpexhaust6. -a add a hop-by-hop header with router alert. -c do not calculate the checksum to save time. -p send ICMPv6 Echo Requests. -P send ICMPv6 Echo Reply. -T send ICMPv6 Time-to-live-exceeded. -U send ICMPv6 Unreachable (no route). -r randomize the source from your /64 prefix. -R randomize the source fully. -s sourceip6 use this as source ipv6 address.
ndpexhaust6 <interface> <target-network>
Randomly pings IPs in target network.
node_query6 <interface> <target-ip>
Sends an ICMPv6 node query request to the target and dumps the replies.
parasite6 <interface> [fake-mac]
This is an "ARP spoofer" for IPv6, redirecting all local traffic to your own system (or nirvana if fake-mac does not exist) by answering falsely to Neighbor Solicitation requests, specifying FAKE-MAC results in a local DOS.
passive_discovery6 <interface> [scriptname]
Passively sniffs the network and dump all client's IPv6 addresses detected. If scriptname is supplied, it is called with the detected IPv6 address as first and the interface as second parameters.
randicmp6 <interface> <target-ip>
Sends all ICMPv6 type and code combinations to target.
redir6 <interface> <src-ip> <target-ip> <original-router> <new-router> [new-router-mac]
Implant a route into src-ip, which redirects all traffic to target-ip to new-ip. You must know the router which would handle the route. If the new-router-mac does not exist, this results in a DOS.
redirsniff6 <interface> <victim-ip> <destination-ip> <original-router> [<new-router> [<new-router-mac>]]
Implant a route into victim-ip, which redirects all traffic to destination-ip to new-router. You must know the router which would handle the route. If the new-router and new-router-mac does not exist, this results in a DoS.
rsmurf6 <interface> <victim-ip>
Smurfs the local network of the victim. Note: this depends on an implementation error, currently only verified on Linux (fixed in current versions). Evil: "ff02::1" as victim will DOS your local LAN completely.
smurf6 <interface> <victim-ip> [multicast-network-address]
Smurf the target with ICMPv6 echo replies. Target of echo request is the local all-nodes multicast address if not specified.
sendpees6 <interface> <key_length> <prefix> <victim-ip>
Send SEND neighbor solicitation messages and make target to verify a lota CGA and RSA signatures.
sendpeesmp6 <interface> <key_length> <prefix> <victim-ip>
Multithreaded version of sendpees6.
trace6 [-d] <interface> targetaddress [port]
A basic but very fast traceroute6 program.
thcping6 <interface> <src6> <dst6> <srcmac> <dstmac> <data>
Craft your special ICMPv6 echo request packet.
thcsyn6 [-AcDrRS] [-p port] [-s source-ip6] <interface> <target> <port>
Flood the target port with TCP-SYN packets. If you supply "x" as port, it is randomized.
toobig6 <interface> <target-ip> <existing-ip> <mtu>
Implants the specified mtu on the target
