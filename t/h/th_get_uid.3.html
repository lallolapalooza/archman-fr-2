NOM

th_get_pathname, th_get_uid, th_get_gid, th_get_mode, th_get_crc, th_get_size, th_get_mtime, th_get_devmajor, th_get_devminor, th_get_linkname - extraire les champs individuels d'un en-tête tar

TH_ISREG, TH_ISLNK, TH_ISSYM, TH_ISCHR, TH_ISBLK, TH_ISDIR, TH_ISFIFO - déterminer à quel type de fichier un en-tête tar fait référence

TH_ISLONGNAME, TH_ISLONGLINK - déterminer si les extensions GNU sont utilisées

VERSION

Cette page de manuel documente la version 1.2 de libtar.

DESCRIPTION

Les fonctions th_get_*() extraient les champs individuels de l'en-tête tar actuel associé au descripteur TAR t.

Les macros TH_IS*() sont utilisées pour évaluer le type de fichier pointé par l'en-tête tar actuel associé au descripteur TAR t.

Les macros TH_ISLONGNAME() et TH_ISLONGLINK() évaluent si les extensions GNU sont utilisées ou non par l'en-tête tar actuel associé au descripteur TAR t. Ceci n'est pertinent que si l'option TAR_GNU a été utilisée lors de l'appel à tar_open().
