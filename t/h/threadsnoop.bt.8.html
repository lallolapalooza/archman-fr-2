NOM

threadsnoop.bt - Trace la création de threads via pthread_create(). Utilise bpftrace/eBPF.

SYNTAXE

threadsnoop.bt

DESCRIPTION

threadsnoop trace les appels à pthread_create(), montrant ce chemin de création de threads. Ceci peut être utilisé pour la caractérisation et la découverte de charges de travail, et est un complément à execsnoop.bt(8) qui trace execve(2).

Cela fonctionne en traçant le pthread_create() de libpthread.so.0. Le chemin vers cette bibliothèque peut nécessiter un ajustement dans le code source de l'outil pour correspondre à votre système.

Puisque cela utilise BPF, seul l'utilisateur root peut utiliser cet outil.

PRÉREQUIS

CONFIG_BPF et bpftrace.

EXEMPLES

Trace les appels à pthread_create():
# threadsnoop.bt

CHAMPS

TIME(ms)
Temps écoulé depuis le début du traçage par l'outil (en millisecondes).
PID
L'identifiant du processus.
COMM
Le nom du processus (thread).
FUNC
Le nom de la routine de démarrage, si le symbole est disponible, sinon une adresse hexadécimale pour l'adresse de la routine de démarrage.

SOUS-COMPTAGE

La création de threads est attendue comme étant faible (<< 1000/s), donc le sous-comptage de cet outil est attendu comme étant négligeable.

SOURCE

Cet outil est originaire du livre "BPF Performance Tools", publié par Addison Wesley (2019) :

http://www.brendangregg.com/bpf-performance-tools-book.html

Consultez le livre pour plus de documentation sur cet outil.

Cette version se trouve dans le dépôt bpftrace :

https://github.com/bpftrace/bpftrace

Regardez également dans la distribution bpftrace un fichier _examples.txt compagnon contenant des exemples d'utilisation, de sortie et des commentaires pour cet outil.
