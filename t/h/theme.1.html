THEME(1) Manuel des commandes générales THEME(1)

NOM

theme — créer une page web à partir d'un fichier modèle

SYNOPIS

theme [-C options-indicateurs] [-c options] [-d racine] [-E] [-f] [-o fichier] [-p nomdepage] [-t modèle] [-V] [fichiertexte]

DESCRIPTION

L'utilitaire theme prend un fichier texte au format markdown(7) (ou l'entrée standard si non spécifié), le compile, et le combine avec un modèle (page.theme par défaut) pour produire une page web. Si un chemin vers le modèle n'est pas spécifié, theme recherche page.theme dans le répertoire courant, puis dans chaque répertoire parent jusqu'à la racine du document (définie avec -d ou, si non définie, le répertoire racine du système.) Si page.theme est trouvé, theme le copie vers la sortie, recherchant des <?thème action?> balises html et traitant l'action intégrée en conséquence.

theme traite les actions suivantes :

auteur
Affiche le(s) nom(s) de l'auteur à partir de la fonction mkd_doc_author(3).
corps
Affiche le fichier d'entrée markdown(7) formaté.
date
Affiche la date renvoyée par mkd_doc_date(3) ou, s'il n'y en a pas, la date de dernière modification du fichier d'entrée.
répertoire
Affiche la partie répertoire du nom de la page
inclure(fichier)
Affiche le contenu de fichier. La traduction Markdown(7) sera NON effectuée sur ce fichier.
source
La partie nom de fichier du nom de la page.
style
Affiche les feuilles de style (voir mkd-extensions(7)) trouvées dans le fichier d'entrée.
titre
Affiche le titre renvoyé par mkd_doc_title(3), ou, si cela n'existe pas, le nom du fichier source.
version
Affiche la version de discount(7) avec laquelle cette copie de theme a été compilée.

Si l'entrée provient d'un fichier et que la sortie n'a pas été définie avec l'option -o, écrit la sortie dans fichier-sans-texte.html (si fichier a un suffixe .text, celui-ci sera retiré et remplacé par .html ; sinon, un .html sera ajouté à la fin du nom de fichier.)

Les options sont les suivantes :

-d racine
Définit la racine du document à racine
-E
Normalement, theme n'expanse pas <?thème corps?> ou <?thème tablematieres?> dans la section <head>, ou <?thème style?> dans la section <body>, mais l'option -E surcharge cela et permet les expansions partout.
-f
Écrase de force les fichiers html existants.
-o nomdefichier
Écrit la sortie dans nomdefichier.
-p chemin
Définit le nom de la page à chemin.
-t nomdefichier
Utilise nomdefichier comme fichier modèle.

VALEURS DE RETOUR

L'utilitaire theme se termine avec 0 en cas de succès, et >0 si une erreur survient.

VOIR AUSSI

markdown(1), markdown(3), markdown(7), mkd-extensions(7).
