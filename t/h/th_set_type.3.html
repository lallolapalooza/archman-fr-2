VERSION

Cette page de manuel documente la version 1.2 de libtar.

DESCRIPTION

Les fonctions th_set_*() définissent chacune un champ individuel de l'en-tête tar courant associé au descripteur t de type TAR. Les fonctions th_set_user() et th_set_group() définissent à la fois les champs numériques d'identifiant utilisateur/groupe et les champs textuels de nom d'utilisateur/groupe. Les autres fonctions définissent uniquement le champ auquel elles se réfèrent.

La fonction th_set_from_stat() utilise les autres fonctions th_set_*() pour définir tous les champs en une seule fois, en se basant sur les données qui lui sont passées dans l'argument s.

La fonction th_finish() définit les constantes appropriées pour les champs magique et version. Elle calcule ensuite la somme de contrôle de l'en-tête et remplit le champ de somme de contrôle.
