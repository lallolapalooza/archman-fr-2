NOM

thread-keyring - porte-clés par thread

DESCRIPTION

Le porte-clés de thread est un porte-clés utilisé pour ancrer des clés au nom d'un processus. Il est créé uniquement lorsqu'un thread le demande. Le porte-clés de thread a le nom (description) _tid.

Une valeur spéciale de numéro de série, KEY_SPEC_THREAD_KEYRING, est définie et peut être utilisée à la place du numéro de série réel du porte-clés de thread du thread appelant.

Depuis l'utilitaire keyctl(1), '@t' peut être utilisé à la place d'un ID numérique de clé de la même manière, mais comme keyctl(1) est un programme exécuté après un fork, cela n'a aucune utilité.

Les porte-clés de thread ne sont pas hérités lors de clone(2) et fork(2) et sont effacés par execve(2). Un porte-clés de thread est détruit lorsque le thread qui y fait référence se termine.

Initialement, un thread n'a pas de porte-clés de thread. Si un thread n'a pas de porte-clés de thread lorsqu'il est accédé, il sera créé s'il doit être modifié ; sinon, l'opération échoue avec l'erreur ENOKEY.
