Paquet: libtar

Licences: BSD

th_print_long_ls(3) Appels de bibliothèque C th_print_long_ls(3)

NOM

th_print, th_print_long_ls - afficher des informations sur un en-tête de fichier tar

SYNTAXE

#include <libtar.h>

void th_print_long_ls(TAR *t);

void th_print(TAR *t);

VERSION

Cette page de manuel documente la version 1.2 de libtar.

DESCRIPTION

La fonction th_print_long_ls() affiche sur la sortie standard stdout une ligne décrivant le fichier pointé par l'en-tête de fichier courant associé au descripteur TAR t. La sortie est similaire à celle de « ls -l ».

La fonction th_print() affiche la valeur de chaque champ de l'en-tête de fichier courant associé au descripteur TAR t sur la sortie standard stdout. Ceci est principalement utilisé à des fins de débogage.
