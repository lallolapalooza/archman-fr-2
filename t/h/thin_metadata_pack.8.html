NOM

thin_metadata_pack - compacter les métadonnées binaires de provisionnement fin.

SYNTAXE

thin_metadata_pack [options] -i {périphérique|fichier} -o {périphérique|fichier}

DESCRIPTION

thin_metadata_pack et thin_metadata_unpack sont utilisés pour compresser les métadonnées binaires. Utile pour le support.

thin_metadata_pack compresse les métadonnées, en omettant tous les blocs de métadonnées inutilisés.

Cet outil ne peut pas être exécuté sur des métadonnées actives.

OPTIONS

-h, --help
Affiche l'aide et quitte.
-V, --version
Affiche les informations de version et quitte.
-i, --input {périphérique|fichier}
Fichier ou périphérique d'entrée avec les données binaires.
-o, --output {périphérique|fichier}
Fichier ou périphérique de sortie pour les données binaires.
