tracecmd_map_vcpus(3)

Paquet: trace-cmd

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACECMD(3) Manuel libtracefs LIBTRACECMD(3)

NOM

tracecmd_map_vcpus, tracecmd_get_cpu_map, tracecmd_map_find_by_host_pid, tracecmd_map_get_host_pid, tracecmd_map_get_guest, tracecmd_map_set_private, tracecmd_map_get_private - Mappage des données hôte et invité

SYNOPSIS

#include <trace-cmd.h>
int tracecmd_map_vcpus(struct tracecmd_input **handles, int nr_handles);
struct tracecmd_cpu_map *tracecmd_get_cpu_map(struct tracecmd_input *handle, int cpu);
struct tracecmd_cpu_map *tracecmd_map_find_by_host_pid(struct tracecmd_input *handle,
                                                      int host_pid);
int tracecmd_map_get_host_pid(struct tracecmd_cpu_map *map);
struct tracecmd_input *tracecmd_map_get_guest(struct tracecmd_cpu_map *map);
void tracecmd_map_set_private(struct tracecmd_cpu_map *map, void *priv);
void *tracecmd_map_get_private(struct tracecmd_cpu_map *map);

DESCRIPTION

Cet ensemble d'API est utilisé pour mapper les fichiers de trace hôte et invité afin de faciliter une analyse de trace ultérieure.

La fonction tracecmd_map_vcpus() prend un tableau de handles où chaque élément de ce tableau a été créé par l'une des fonctions tracecmd_open(3), et le nombre de handles comme nr_handles. Le premier handle dans le tableau de handles est censé être le descripteur du fichier de trace hôte, et les suivants sont les fichiers de trace invité qui s'exécutent sur l'hôte et qui ont été créés par les interactions trace-cmd record(1) et trace-cmd agent(1). Elle renvoie le nombre d'invités trouvés dans handles qui étaient associés à l'hôte, ou un nombre négatif en cas d'erreur.

La fonction tracecmd_get_cpu_map() renvoie un descripteur pour un CPU donné pour un handle. Si le handle était un invité défini à partir de tracecmd_map_vcpus(), alors le mappage créé par cette fonction et associé à ce vCPU particulier (indiqué par cpu) à partir du handle. Ce descripteur peut être utilisé par les fonctions tarcecmd_map_get_guest(), tracecmd_map_set_private() et tracecmd_map_get_private().

La fonction tracecmd_map_find_by_host_pid() renverra un mappage pour un vCPU invité qui est géré par le host_pid donné. Notez que le handle passé peut être soit le handle hôte, soit l'un des handles invités pour cet hôte qui a été mappé par tracecmd_map_vcpus(), même si le handle invité ne possède pas le vCPU que le host_pid représente.

La fonction tracecmd_map_get_host_pid() renverra le host_pid pour un map donné qui a été récupéré par l'une des fonctions ci-dessus.

La fonction tracecmd_map_get_guest() renverra le guest_handle pour un map donné qui a été récupéré par l'une des fonctions ci-dessus.

La fonction tracecmd_map_set_private() permet à l'application d'attribuer des données privées à un mappage thread hôte vers vCPU invité défini par map.

La fonction tracecmd_map_get_private() récupère les données priv de map qui ont été définies par tracecmd_map_set_private().

VALEUR RENVOYÉE

La fonction tracecmd_map_vcpus() renvoie le nombre d'invités dans le tableau handles qui ont été mappés au handle hôte qui est la première entrée dans handles. Elle renvoie -1 en cas d'erreur.

La fonction tracecmd_get_cpu_map() renvoie une carte créée par tracecmd_map_vcpus() pour un cpu donné pour un handle donné, ou NULL s'il n'est pas trouvé.

La fonction tracecmd_map_find_by_host_pid() renvoie une carte qui est associée à la tâche hôte avec host_pid comme identifiant de processus. handle peut être soit le handle hôte, soit l'un des handles invités qui ont été mappés à l'hôte via tracecmd_map_vcpus(), même si le handle invité est un invité différent de celui pour lequel le mappage est destiné. Elle renvoie NULL si non trouvé.

La fonction tracecmd_map_get_host_pid() renvoie l'ID de processus hôte pour un mappage associé défini par map.

La fonction tracecmd_map_get_guest() renvoie le handle invité pour un mappage associé défini par map.

La fonction tracecmd_map_get_private() renvoie les données privées d'un mappage défini par map qui a été défini par tracecmd_map_set_private().

EXEMPLE

#include <stdlib.h>
#include <errno.h>
#include <trace-cmd.h>
int main(int argc, char **argv)
{
        struct tracecmd_input **handles = NULL;
        int nr_handles;
        int i;
        if (argc < 2) {
                printf("usage: host_trace.dat guest1_trace.dat [guest2_trace.dat ...]\n");
                exit(-1);
        }
        for (i = 1; i < argc; i++) {
                handles = realloc(handles, sizeof(*handles) * (nr_handles + 1));
                if (!handles)
                        exit(-1);
                handles[nr_handles] = tracecmd_open(argv[i], 0);
                if (!handles[nr_handles]) {
                        perror(argv[1]);
                        exit(-1);
                }
                tracecmd_set_private(handles[nr_handles], argv[i]);
                nr_handles++;
        }
        tracecmd_map_vcpus(handles, nr_handles);
        for (i = 1; i < nr_handles; i++) {
                struct tracecmd_cpu_map *map;
                struct tep_handle *tep;
                const char *file = tracecmd_get_private(handles[i]);
                int cpus, cpu;
                printf("Mappings for guest %s:\n", file);
                tep = tracecmd_get_tep(handles[i]);
                cpus = tep_get_cpus(tep);
                for (cpu = 0; cpu < cpus; cpu++) {
                        printf("  [%03d] ", cpu);
                        map = tracecmd_get_cpu_map(handles[i], cpu);
                        if (!map) {
                                printf("Has no mapping!\n");
                                continue;
                        }
                        printf("host_pid: %d\n", tracecmd_map_get_host_pid(map));
                }
        }
        for (i = 0; i < nr_handles; i++)
                tracecmd_close(handles[i]);
        free(handles);
        exit(0);
}
