tracefs_trace_on_get_fd(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_trace_is_on, tracefs_trace_on, tracefs_trace_off, tracefs_trace_on_get_fd, tracefs_trace_on_fd, tracefs_trace_off_fd - Fonctions pour activer ou désactiver le traçage.

SYNOPSIS

#include <tracefs.h>
int tracefs_trace_is_on(struct tracefs_instance *instance);
int tracefs_trace_on(struct tracefs_instance *instance);
int tracefs_trace_off(struct tracefs_instance *instance);
int tracefs_trace_on_get_fd(struct tracefs_instance *instance);
int tracefs_trace_on_fd(int fd);
int tracefs_trace_off_fd(int fd);

DESCRIPTION

Cet ensemble de fonctions peut être utilisé pour vérifier, activer ou désactiver l'écriture dans le tampon circulaire de l'instance de traçage donnée. Le traçage est activé lorsque l'écriture dans le tampon circulaire est activée.

La fonction tracefs_trace_is_on() vérifie si le traçage est activé pour l'instance instance donnée. Si instance est NULL, l'instance principale est utilisée.

Les fonctions tracefs_trace_on() et tracefs_trace_off() définissent le traçage dans l'instance instance à l'état activé ou désactivé. Si instance est NULL, l'instance principale est utilisée.

La fonction tracefs_trace_on_get_fd() renvoie un descripteur de fichier vers le fichier "tracing_on" de l'instance instance donnée. Si instance est NULL, l'instance de traçage principale est utilisée. Le descripteur retourné peut être utilisé pour activer ou désactiver rapidement le traçage de l'instance.

Les fonctions tracefs_trace_on_fd() et tracefs_trace_off_fd() définissent l'état du traçage à activé ou désactivé en utilisant le descripteur de fichier fd donné. Ce descripteur de fichier doit être ouvert en écriture avec tracefs_trace_on_get_fd(3) de l'instance de traçage désirée. Ces fonctions sont plus rapides que tracefs_trace_on et tracefs_trace_off.

VALEUR DE RETOUR

La fonction tracefs_trace_is_on() renvoie 0 si le traçage est désactivé, 1 s'il est activé ou -1 en cas d'erreur.

La fonction tracefs_trace_on_get_fd() renvoie un descripteur de fichier vers le fichier "tracing_on" pour lecture et écriture, qui doit être fermé avec close(). En cas d'erreur, -1 est renvoyé.

Les fonctions tracefs_trace_on(), tracefs_trace_off(), tracefs_trace_on_fd() et tracefs_trace_off_fd() renvoient -1 en cas d'erreur ou 0 sinon.

EXEMPLE

#include <tracefs.h>
        int ret;
        ret = tracefs_trace_is_on(NULL);
        if (ret == 0) {
                /* Le traçage est désactivé dans l'instance principale */
        } else if (ret == 1) {
                /* Le traçage est activé dans l'instance principale */
        } else {
                /* Erreur lors de l'obtention de l'état du traçage de l'instance principale */
        }
        ...
        if (!tracefs_trace_on(NULL)) {
            /* Traçage activé dans l'instance principale */
            ...
            if (!tracefs_trace_off(NULL)) {
                /* Traçage désactivé dans l'instance principale */
            } else {
                /* Erreur lors de la désactivation du traçage dans l'instance principale */
            }
        } else {
                /* Erreur lors de l'activation du traçage dans l'instance principale */
        }
        ...
        int fd = tracefs_trace_on_get_fd(NULL);
        if (fd < 0) {
                /* Erreur lors de l'ouverture du fichier tracing_on */
        }
        ...
        if (!tracefs_trace_on_fd(fd)) {
            /* Traçage activé dans l'instance principale */
            ...
            if (!tracefs_trace_off_fd(fd)) {
                /* Traçage désactivé dans l'instance principale */
            } else {
                /* Erreur lors de la désactivation du traçage dans l'instance principale */
            }
        } else {
                /* Erreur lors de l'activation du traçage dans l'instance principale */
        }
        ...
        close(fd);
