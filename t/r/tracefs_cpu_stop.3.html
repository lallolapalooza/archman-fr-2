tracefs_cpu_stop(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_cpu_read_size, tracefs_cpu_read, tracefs_cpu_buffered_read, tracefs_cpu_write, tracefs_cpu_stop, tracefs_cpu_flush, tracefs_cpu_flush_write, tracefs_cpu_pipe - Lecture des données de trace_pipe_raw

SYNOPSIS

#include <tracefs.h>
int tracefs_cpu_read_size(struct tracefs_cpu *tcpu);
int tracefs_cpu_read(struct tracefs_cpu *tcpu, void *buffer, bool nonblock);
int tracefs_cpu_buffered_read(struct tracefs_cpu *tcpu, void *buffer, bool nonblock);
int tracefs_cpu_write(struct tracefs_cpu *tcpu, int wfd, bool nonblock);
int tracefs_cpu_stop(struct tracefs_cpu *tcpu);
int tracefs_cpu_flush(struct tracefs_cpu *tcpu, void *buffer);
int tracefs_cpu_flush_write(struct tracefs_cpu *tcpu, int wfd);
int tracefs_cpu_pipe(struct tracefs_cpu *tcpu, int wfd, bool nonblock);

DESCRIPTION

Cet ensemble d'API peut être utilisé pour lire les données brutes des fichiers trace_pipe_raw dans le système de fichiers tracefs.

La fonction tracefs_cpu_read_size() retourne la taille du sous-buffer de trace_pipe_raw. Elle retourne la taille minimale du buffer qui est passé aux fonctions ci-dessous.

La fonction tracefs_cpu_read() lit les fichiers trace_pipe_raw associés à tcpu dans buffer. buffer doit être au moins de la taille du sous-buffer du buffer circulaire, qui est retournée par tracefs_cpu_read_size(). Si nonblock est défini, et qu'il n'y a pas de données disponibles, elle retourne immédiatement. Sinon, en fonction de la façon dont tcpu a été ouvert, elle bloquera. Si tcpu a été ouvert avec nonblock défini, alors ce paramètre nonblock n'aura aucune différence.

La fonction tracefs_cpu_buffered_read() est essentiellement la même que tracefs_cpu_read(), sauf qu'elle utilise un pipe via splice pour mettre en tampon les lectures. Cela permet de regrouper les lectures, rendant la lecture du buffer circulaire moins intrusive pour le système, car la lecture constante peut causer des perturbations importantes. Notez qu'une différence entre celle-ci et tracefs_cpu_read() est qu'elle ne lira que des pages de sous-buffer. Si le buffer circulaire n'a pas rempli une page, elle ne retournera rien, même avec nonblock défini. Des appels à tracefs_cpu_flush() doivent être faits pour lire le reste du fichier à la fin du traçage.

La fonction tracefs_cpu_write() transmettra les données du fichier trace_pipe_raw associé à tcpu vers le descripteur de fichier wfd. Si nonblock est défini, elle ne bloquera pas s'il n'y a rien à écrire. Notez qu'elle n'écrira que la taille du sous-buffer dans wfd. Des appels à tracefs_cpu_flush_write() sont nécessaires pour écrire le reste.

La fonction tracefs_cpu_stop() tentera de débloquer une tâche bloquée sur la lecture de tcpu. Sur les anciens noyaux, elle peut ne rien faire pour les lectures par pipe, car les anciens noyaux ne réveillent pas les tâches en attente sur le buffer circulaire. Retourne 0 si elle a certainement réveillé tous les attentes possibles, mais retourne 1 si elle n'est pas sûre que cela ait fonctionné et que les attentes pourraient nécessiter l'envoi d'un signal.

La fonction tracefs_cpu_flush() lit le fichier trace_pipe_raw associé par tcpu et le place dans buffer, qui doit être de la taille du sous-buffer récupéré par tracefs_cpu_read_size(). Cet appel doit être effectué à la fin du traçage pour récupérer le reste des données. Cet appel convertira le descripteur de fichier de trace_pipe_raw en mode non bloquant.

La fonction tracefs_cpu_flush_write() est identique à trace_cpu_flush() sauf qu'elle prend un descripteur de fichier wfd pour y transférer les données.

La fonction tracefs_cpu_pipe() est similaire à tracefs_cpu_write() mais le descripteur de fichier wfd doit être un pipe. Cet appel est une optimisation de tracefs_cpu_write() qui utilise deux appels à splice(2) afin de connecter le descripteur de fichier trace_pipe_raw avec le descripteur de fichier d'écriture. splice(2) exige qu'un des descripteurs de fichiers passés soit un pipe. Si l'application souhaite passer les données à un pipe existant, il n'est pas nécessaire de faire deux appels système splice(2) et tracefs_cpu_pipe() peut simplement utiliser un seul appel à wfd.

VALEUR DE RETOUR

La fonction tracefs_cpu_open() retourne un descripteur de type struct tracefs_cpu qui peut être utilisé par les autres fonctions ou NULL en cas d'erreur.

La fonction tracefs_cpu_read_size() retourne la taille minimale des buffers à utiliser avec tracefs_cpu_read(), tracefs_cpu_buffered_read() et tracefs_cpu_flush(). Retourne une valeur négative en cas d'erreur.

La fonction tracefs_cpu_read() retourne le nombre d'octets lus, ou une valeur négative en cas d'erreur.

La fonction tracefs_cpu_buffered_read() retourne le nombre d'octets lus ou une valeur négative en cas d'erreur.

La fonction tracefs_cpu_write() retourne le nombre d'octets écrits dans le fichier ou une valeur négative en cas d'erreur.

La fonction tracefs_cpu_stop() retourne zéro si des attentes ont été garanties d'être réveillées d'une attente d'entrée, ou retourne un si il s'agit d'un ancien noyau qui ne fournit pas cette garantie, et qu'un signal peut devoir être envoyé à toute personne en attente. Retourne une valeur négative en cas d'erreur.

La fonction tracefs_cpu_flush() retourne le nombre d'octets lus ou une valeur négative en cas d'erreur.

La fonction tracefs_cpu_flush_write() retourne le nombre d'octets écrits dans le fichier ou une valeur négative en cas d'erreur.

EXEMPLE

#define _LARGEFILE64_SOURCE
#include <stdlib.h>
#include <ctype.h>
#include <pthread.h>
#include <unistd.h>
#include <tracefs.h>
struct thread_data {
        struct tracefs_cpu      *tcpu;
        int                     done;
        int                     fd;
};
static void *thread_run(void *arg)
{
        struct thread_data *data = arg;
        struct tracefs_cpu *tcpu = data->tcpu;
        int fd = data->fd;
        int ret;
        while (!data->done) {
                ret = tracefs_cpu_write(tcpu, fd, false);
                printf("écrit %d\n", ret);
        }
        return NULL;
}
int main (int argc, char **argv)
{
        struct tracefs_instance *instance;
        struct thread_data data;
        pthread_t thread;
        char *file;
        int secs = 10;
        int cpu;
        int ret;
        if (argc < 3 || !isdigit(argv[1][0])) {
                printf("usage: %s cpu fichier_destination [secondes de pause]\n\n", argv[0]);
                exit(-1);
        }
        cpu = atoi(argv[1]);
        file = argv[2];
        if (argc > 3)
                secs = atoi(argv[3]);
        instance = tracefs_instance_create("cpu_write");
        if (!instance) {
                perror("créer l'instance");
                exit(-1);
        }
        memset(&data, 0, sizeof(data));
        data.tcpu = tracefs_cpu_open(instance, cpu, 0);
        if (!data.tcpu) {
                perror("Ouvrir l'instance");
                exit(-1);
        }
        data.fd = open(file, O_WRONLY | O_CREAT | O_TRUNC | O_LARGEFILE, 0644);
        if (data.fd < 0) {
                perror(file);
                exit(-1);
        }
        pthread_create(&thread, NULL, thread_run, &data);
        sleep(secs);
        data.done = 1;
        printf("arrêt\n");
        ret = tracefs_cpu_stop(data.tcpu);
        printf("jointure %d\n", ret);
        pthread_join(thread, NULL);
        tracefs_trace_off(instance);
        do {
                ret = tracefs_cpu_flush_write(data.tcpu, data.fd);
                printf("vidé %d\n", ret);
        } while (ret > 0);
        tracefs_trace_on(instance);
        tracefs_cpu_close(data.tcpu);
        close(data.fd);
        return 0;
}
