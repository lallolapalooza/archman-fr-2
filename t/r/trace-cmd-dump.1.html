NOM

trace-cmd-dump - afficher les métadonnées d'un fichier de trace, créé par trace-cmd record

SYNTAXE

trace-cmd dump [OPTIONS] [fichier-entrée]

DESCRIPTION

La commande dump de trace-cmd(1) affichera les métadonnées d'un fichier de trace créé par trace-cmd record.

OPTIONS

-i fichier-entrée

Par défaut, trace-cmd dump lit le fichier trace.dat. Mais l'option -i ouvre le fichier-entrée spécifié à la place. Notez que le fichier d'entrée peut également être spécifié comme dernier élément de la ligne de commande.

-v, --validate

Vérifier si le fichier d'entrée est un fichier de trace valide, créé par trace-cmd.

--summary

Afficher un résumé des métadonnées - format initial et une courte description de chaque section de fichier. C'est l'action par défaut, si aucun argument n'est spécifié.

--head-page

Afficher les informations de la page d'en-tête, stockées dans le fichier.

--head-event

Afficher les informations d'en-tête d'événement, stockées dans le fichier.

--ftrace-events

Afficher les formats des événements spécifiques à ftrace.

--systems

Afficher les informations des systèmes d'événements, stockées dans le fichier - nom et nombre d'événements pour chaque système.

--events

Afficher les formats de tous les événements, stockés dans le fichier.

--kallsyms

Afficher les informations du mappage des adresses de fonction aux noms de fonction.

--printk

Afficher les chaînes de format trace_printk(), stockées dans le fichier.

--cmd-lines

Afficher le mappage d'un PID à un nom de processus.

--options

Afficher toutes les options, stockées dans le fichier.

--flyrecord

Afficher le décalage et la taille des données de traçage par CPU.

--clock

Afficher l'horloge de trace, utilisée pour l'horodatage des événements de traçage, stockée dans le fichier.

--all

Afficher toutes les métadonnées du fichier.

--help

Afficher les informations d'utilisation.

--verbose[=niveau]

Définir le niveau de journalisation. Les niveaux de journalisation pris en charge sont "none", "critical", "error", "warning", "info", "debug", "all" ou leurs identifiants "0", "1", "2", "3", "4", "5", "6". La définition du niveau de journalisation à une valeur spécifique active tous les journaux de ce niveau et de tous les niveaux précédents. Le niveau sera par défaut "info" si aucun n'est spécifié. 
Exemple : activer tous les journaux critiques, d'erreur et d'avertissement
trace-cmd report --verbose=warning

# trace-cmd dump --summary -i trace.dat
 Métadonnées de traçage dans le fichier trace.dat :
        [Format initial]
                6       [Version]
                0       [Petit-boutien]
                8       [Octets dans un long]
                4096    [Taille de page, octets]
        [Infos d'en-tête, 205 octets]
        [En-tête d'événement, 205 octets]
        [Format Ftrace, 15 événements]
        [Format des événements, 2 systèmes]
        [Kallsyms, 7144493 octets]
        [Trace printk, 2131 octets]
        [Lignes de commande enregistrées, 117 octets]
        8 [CPUs avec données de traçage]
        [12 options]
        [Données de traçage Flyrecord]
# trace-cmd dump --flyrecord -i trace.dat
        [Données de traçage Flyrecord]
                 7176192 0      [décalage, taille cpu 0]
                 7176192 0      [décalage, taille cpu 1]

                 7180288 4096   [décalage, taille cpu 4]
                 7184384 0      [décalage, taille cpu 5]
                 7184384 0      [décalage, taille cpu 6]
                 7184384 0      [décalage, taille cpu 7]
# trace-cmd dump --summary --systems -i trace.dat
 Métadonnées de traçage dans le fichier trace.dat :
        [Format initial]
                6       [Version]
                0       [Petit-boutien]
                8       [Octets dans un long]
                4096    [Taille de page, octets]
        [Infos d'en-tête, 205 octets]

        8 [CPUs avec données de traçage]

        [Données de traçage Flyrecord]
