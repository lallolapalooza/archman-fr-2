TRANSMISSION-QT(1) Manuel des commandes générales TRANSMISSION-QT(1)

NOM

transmission-qt — un client bittorrent

SYNTAXE

transmission-qt -h

transmission-qt [options] [fichier-torrent ...]

DESCRIPTION

transmission-qt est un client BitTorrent rapide et facile à utiliser.

BitTorrent est un protocole de transfert de fichiers peer-to-peer qui utilise un fichier metainfo (généralement avec l'extension .torrent) et un tracker central pour distribuer des données de fichiers parmi un groupe de pairs. Pour plus d'informations sur le protocole BitTorrent, voir http://www.bittorrent.org/

OPTIONS

-h --help
Affiche les options d'aide
-g --config-dir répertoire
Où chercher les fichiers de configuration. Ceci peut être utilisé pour alterner entre l'utilisation des clients cli, daemon, gtk et qt. Voir https://github.com/transmission/transmission/blob/main/docs/Configuration-Files.md pour plus d'informations.
-m --minimized
Démarrer minimisé dans la zone de notification
-p --port port
Port à utiliser lors de la connexion à une session existante
-r --remote hôte
Se connecter à une session existante à l'hôte spécifié
-u --username nomutilisateur
Nom d'utilisateur à utiliser lors de la connexion à une session existante
-v --version
Affiche le numéro de version et quitte
-w --password motdepasse
Mot de passe à utiliser lors de la connexion à une session existante

Plusieurs fichiers .torrent peuvent être ajoutés au démarrage en les ajoutant sur la ligne de commande. Si transmission-qt est déjà en cours d'exécution, les torrents seront ajoutés à l'instance en cours.

ENVIRONNEMENT

TRANSMISSION_HOME
Définit le répertoire de configuration par défaut.

FICHIERS

~/.config/transmission
Le répertoire de configuration utilisé lorsque ni [TRANSMISSION_HOME] ni [-g] n'est spécifié.
