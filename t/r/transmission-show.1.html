NOM

transmission-show — utilitaire en ligne de commande pour afficher les métadonnées d'un fichier .torrent

SYNTAXE

transmission-show [-h] [-m] [-s] [fichier_torrent]

DESCRIPTION

transmission-show affiche les métadonnées d'un fichier BitTorrent .torrent.

OPTIONS

-h --help
Affiche une courte page d'aide et quitte.
-m --magnet
Affiche un lien magnet pour le fichier .torrent spécifié.
-s --scrape
Demande aux trackers du torrent combien de pairs sont dans le essaim du torrent.
