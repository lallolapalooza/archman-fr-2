Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_snapshot_snap, tracefs_snapshot_clear, tracefs_snapshot_free - API pour créer, effacer et lire des instantanés

SYNTAXE

#include <tracefs.h>
int tracefs_snapshot_snap(struct tracefs_instance *instance);
int tracefs_snapshot_clear(struct tracefs_instance *instance);
int tracefs_snapshot_free(struct tracefs_instance *instance);

DESCRIPTION

Le traçage du noyau Linux fournit une fonctionnalité « d'instantané ». Le noyau possède deux tampons circulaires. L'un est écrit par le système de traçage et l'autre est le tampon « d'instantané ». Lorsqu'un instantané est pris, les deux tampons sont échangés, et le tampon d'instantané actuel devient celui sur lequel on écrit, et le tampon qui était écrit devient l'instantané enregistré.

Notez que le tampon d'instantané est alloué la première fois qu'il est pris. Il est donc préférable de prendre un instantané au début, avant qu'il ne soit nécessaire, afin qu'il soit alloué et qu'un instantané soit prêt. L'instantané se produira alors immédiatement.

La fonction tracefs_snapshot_snap() allouera (si elle n'est pas déjà allouée) le tampon d'instantané, puis prendra un « instantané » (échangera le tampon principal sur lequel on écrit avec le tampon d'instantané alloué). Elle fera cela pour le tampon instance donné ou pour l'instance de niveau supérieur si instance est NULL.

La fonction tracefs_snapshot_clear() effacera le contenu du tampon d'instantané pour l'instance donnée instance ou pour l'instance de niveau supérieur si instance est NULL.

La fonction tracefs_snapshot_free() libérera l'instantané alloué pour l'instance donnée instance ou pour l'instance de niveau supérieur si instance est NULL. C'est-à-dire que si un autre appel à tracefs_snapshot_snap() est effectué après cela, il faudra réallouer le tampon d'instantané avant de pouvoir prendre un instantané. Cette fonction doit être utilisée pour libérer la mémoire du noyau utilisée par le tampon d'instantané lorsqu'il n'est plus utilisé.

VALEUR DE RETOUR

Les fonctions tracefs_snapshot_snap(), tracefs_snapshot_clear() et tracefs_snapshot_free() retournent toutes 0 en cas de succès et -1 en cas d'échec.

EXEMPLE

#include <stdlib.h>
#include <stdio.h>
#include <tracefs.h>
static int callback(struct tep_event *event, struct tep_record *record, int cpu, void *data)
{
        static struct trace_seq seq;
        struct tep_handle *tep = event->tep;
        if (!seq.buffer)
                trace_seq_init(&seq);
        trace_seq_reset(&seq);
        tep_print_event(tep, &seq, record, "[%03d] %s-%d %6.1000d\t%s: %s\n",
                                TEP_PRINT_CPU,
                                TEP_PRINT_COMM,
                                TEP_PRINT_PID,
                                TEP_PRINT_TIME,
                                TEP_PRINT_NAME,
                                TEP_PRINT_INFO);
        trace_seq_do_printf(&seq);
        return 0;
}
int main (int argc, char **argv)
{
        struct tracefs_instance *instance;
        struct tep_handle *tep;
        char *line = NULL;
        size_t len = 0;
        int ret;
        instance = tracefs_instance_create("my_snapshots");
        if (!instance) {
                perror("création de l'instance");
                exit(-1);
        }
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("lecture des formats d'événements");
                goto out;
        }
        /* Assurez-vous que le tampon d'instantané est alloué */
        ret = tracefs_snapshot_snap(instance);
        if (ret < 0)
                goto out;
        ret = tracefs_event_enable(instance, "sched", NULL);
        if (ret < 0) {
                perror("activation de l'événement");
                goto out;
        }
        for (;;) {
                printf("Appuyez sur Entrée sans texte pour prendre un instantané !\n");
                printf("Entrez n'importe quel texte pour afficher l'instantané\n");
                printf("Entrez 'quit' pour quitter\n");
                getline(&line, &len, stdin);
                ret = tracefs_snapshot_snap(instance);
                if (ret < 0) {
                        perror("prise d'instantané");
                        goto out;
                }
                if (!line)
                        break;
                if (strlen(line) < 2)
                        continue;
                if (strncmp(line, "quit", 4) == 0)
                        break;
                tracefs_iterate_snapshot_events(tep, instance, NULL, 0, callback, NULL);
        }
        free(line);
        tracefs_instance_clear(instance);
 out:
        tracefs_snapshot_free(instance);
        tracefs_event_disable(instance, "sched", NULL);
        tracefs_instance_destroy(instance);
        tracefs_instance_free(instance);
        exit(0);
}

tracefs_snapshot_free(3) — Pages de manuel Linux

tracefs_snapshot_free — Libère un instantané de trace

SYNTAXE

#include <tracefs.h>

void tracefs_snapshot_free(struct tracefs_snapshot *snapshot);

DESCRIPTION

La fonction tracefs_snapshot_free() libère la mémoire allouée pour la structure struct tracefs_snapshot et toutes les données qu'elle contient. Elle doit être appelée pour chaque instantané retourné par tracefs_snapshot_create() afin d'éviter les fuites de mémoire.

VALEUR DE RETOUR

Aucune.

EXEMPLES

Créer et libérer un instantané : 

    struct tracefs_snapshot *snapshot;

    snapshot = tracefs_snapshot_create();
    if (!snapshot) {
        perror("tracefs_snapshot_create");
        return 1;
    }

    /* Utiliser l'instantané ici... */

    tracefs_snapshot_free(snapshot);
