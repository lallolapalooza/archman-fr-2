NOM

tracefs_synth_create, tracefs_synth_destroy, tracefs_synth_complete, tracefs_synth_trace, tracefs_synth_snapshot, tracefs_synth_save, tracefs_synth_set_instance, - Création d'événements synthétiques

SYNTAXE

#include <tracefs.h>
int tracefs_synth_create(struct tracefs_synth *synth);
int tracefs_synth_destroy(struct tracefs_synth *synth);
bool tracefs_synth_complete(struct tracefs_synth *synth);
int tracefs_synth_set_instance(struct tracefs_synth *synth, struct tracefs_instance *instance);
int tracefs_synth_trace(struct tracefs_synth *synth,
                        enum tracefs_synth_handler type, const char *var);
int tracefs_synth_snapshot(struct tracefs_synth *synth,
                           enum tracefs_synth_handler type, const char *var);
int tracefs_synth_save(struct tracefs_synth *synth,
                       enum tracefs_synth_handler type, const char *var,
                       char **save_fields);

DESCRIPTION

Les événements synthétiques sont des événements dynamiques créés en mettant en correspondance deux autres événements qui déclenchent un événement synthétique. Un événement est l'événement de départ dont un champ est enregistré, et lorsque le second événement est exécuté, s'il possède un champ (ou des champs) qui correspond au(x) champ(s) de l'événement de départ, alors il déclenche l'événement synthétique. Les valeurs des champs autres que les champs correspondants peuvent être transmises de l'événement de départ à l'événement de fin pour effectuer des calculs, ou simplement comme paramètres de l'événement synthétique.

Un cas d'utilisation courant consiste à définir "sched_waking" comme événement de départ. Cet événement est déclenché lorsqu'un processus est réveillé. Ensuite, définir "sched_switch" comme événement de fin. Cet événement est déclenché lorsqu'une nouvelle tâche est planifiée sur le CPU. En définissant le "common_pid" des deux événements comme champs de correspondance, le temps entre les deux événements est considéré comme la latence de réveil de ce processus. Utilisez TRACEFS_TIMESTAMP comme champ pour les deux événements afin de calculer la différence en nanosecondes, ou utilisez TRACEFS_TIMESTAMP_USECS comme champs de comparaison pour les deux événements afin de calculer la différence en microsecondes. Ceci est utilisé comme exemple ci-dessous.

tracefs_synth_create() crée l'événement synthétique dans le système. Par défaut, les déclencheurs d'histogramme sont créés dans l'instance de trace principale, car tout événement synthétique peut être utilisé globalement dans toutes les instances. Si une application souhaite exclure les déclencheurs d'histogramme de l'instance de niveau supérieur, elle peut utiliser tracefs_synth_set_instance() pour que les histogrammes soient utilisés pour créer l'événement synthétique dans une instance autre que le niveau supérieur. Un descripteur d'événement synthétique doit être créé avec tracefs_synth_alloc(3) avant de pouvoir l'utiliser pour le créer sur le système.

tracefs_synth_destroy() détruit l'événement synthétique. Il tentera d'arrêter son exécution dans son instance (par défaut, l'instance principale), mais s'il s'exécute dans une autre instance, cela peut échouer en raison de son utilisation.

tracefs_synth_complete() renvoie vrai si l'événement synthétique synth a à la fois un événement de début et un événement de fin.

tracefs_synth_trace() Au lieu de simplement tracer lors de la correspondance des événements de début et de fin, effectuez le gestionnaire type où TRACEFS_SYNTH_HANDLE_MAX tracera lorsqu'une nouvelle valeur maximale est atteinte pour la variable donnée var correspondant aux clés. Ou TRACEFS_SYNTH_HANDLE_CHANGE lorsqu'une modification de var se produit. var doit être l'un des éléments name utilisés dans tracefs_synth_add_end_field(3).

tracefs_synth_snapshot() Lorsque la variable donnée var représente soit un nouveau maximum si handler est TRACEFS_SYNTH_HANDLE_MAX, soit a simplement changé si c'est TRACEFS_SYNTH_HANDLE_CHANGE, alors prenez un « instantané » du tampon. L'instantané déplace le tampon de « trace » normal vers un tampon « instantané », qui peut être accédé via le fichier « snapshot » dans le répertoire tracefs de niveau supérieur, ou l'un des instances. var change. var doit être l'un des éléments name utilisés dans tracefs_synth_add_end_field(3).

tracefs_synth_save() Lorsque la variable donnée var représente soit un nouveau maximum si handler est TRACEFS_SYNTH_HANDLE_MAX, soit a simplement changé si c'est TRACEFS_SYNTH_HANDLE_CHANGE, alors enregistrez la liste save_fields donnée. Les champs seront stockés dans le fichier « hist » de l'histogramme de l'événement qui peut être récupéré avec tracefs_event_file_read(3). var doit être l'un des éléments name utilisés dans tracefs_synth_add_end_field(3).

tracefs_synth_set_instance() Définit l'instance de trace, où les déclencheurs d'histogramme qui créent l'événement synthétique seront créés. Par défaut, l'instance principale est utilisée. Cette API doit être appelée avant l'appel à tracefs_synth_create(), afin d'utiliser la nouvelle instance lors de la création de l'événement. Notez que même si l'événement synthétique est créé dans une instance, il reste visible par toutes les autres instances, y compris le niveau supérieur. Cela signifie que d'autres instances peuvent activer l'événement synthétique créé et le tracer dans les tampons appartenant à l'instance qui l'a activé.

VALEUR DE RETOUR

Toutes les fonctions renvoient zéro en cas de succès ou -1 en cas d'erreur.

ERREURS

Les erreurs suivantes s'appliquent à tous les appels mentionnés ci-dessus :

EPERM L'utilisateur ne dispose pas des privilèges root lorsque cela est nécessaire.

EINVAL Soit un paramètre n'est pas valide (NULL alors qu'il ne devrait pas l'être) soit un champ incompatible pour les calculs.

ENODEV Un événement ou l'un de ses champs est introuvable.

EBADE Les champs des événements de début et de fin ne sont pas compatibles pour la correspondance ou la comparaison.

ENOMEM Pas assez de mémoire disponible.

Et d'autres erreurs peuvent s'être produites lors des appels système au système.

EXEMPLE

Voir tracefs_sql(3) pour une utilisation plus approfondie de ce code.

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Charger tous les événements du système */
        tep = tracefs_local_events(NULL);
        /* Initialiser l'événement synthétique */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* Le tep n'est plus nécessaire */
        tep_free(tep);
        /* Sauvegarder le champ "prio" sous le nom "prio" de l'événement de départ */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Sauvegarder le champ "next_comm" sous le nom "comm" de l'événement de fin */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Sauvegarder le champ "prev_prio" sous le nom "prev_prio" de l'événement de fin */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Prendre la différence de temps en microsecondes entre la fin et le début
         * et l'enregistrer sous le nom "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Enregistrer uniquement si le champ "prio" de l'événement de départ est inférieur à 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Enregistrer uniquement si le champ "next_prio" de l'événement de fin est inférieur à 50
         * OU si la priorité de la tâche précédente n'était pas supérieure ou égale à 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
