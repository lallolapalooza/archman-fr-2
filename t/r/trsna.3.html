CTRSNA

Objectif :

!>
!> CTRSNA estime les nombres de condition réciproques pour des valeurs propres
!> et/ou des vecteurs propres droits spécifiés d'une matrice triangulaire supérieure
!> complexe T (ou de toute matrice Q*T*Q**H avec Q unitaire).
!>

Paramètres

JOB 
!>          JOB est CARACTERE*1
!>          Spécifie si les nombres de condition sont requis pour
!>          les valeurs propres (S) ou les vecteurs propres (SEP) :
!>          = 'E' : pour les valeurs propres seulement (S) ;
!>          = 'V' : pour les vecteurs propres seulement (SEP) ;
!>          = 'B' : pour les deux, valeurs propres et vecteurs propres (S et SEP).
!>

HOWMNY

!>          HOWMNY est CARACTERE*1
!>          = 'A' : calculer les nombres de condition pour toutes les paires propres ;
!>          = 'S' : calculer les nombres de condition pour les paires propres sélectionnées
!>                 spécifiées par le tableau SELECT.
!>

SELECT

!>          SELECT est un tableau LOGIQUE, de dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les paires propres pour lesquelles
!>          les nombres de condition sont requis. Pour sélectionner les nombres de condition
!>          pour la j-ème paire propre, SELECT(j) doit être mis à .VRAI..
!>          Si HOWMNY = 'A', SELECT n'est pas référencé.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice T. N >= 0.
!>

T

!>          T est un tableau COMPLEXE, de dimension (LDT,N)
!>          La matrice triangulaire supérieure T.
!>

LDT

!>          LDT est ENTIER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

VL

!>          VL est un tableau COMPLEXE, de dimension (LDVL,M)
!>          Si JOB = 'E' ou 'B', VL doit contenir les vecteurs propres gauches de T
!>          (ou de toute Q*T*Q**H avec Q unitaire), correspondant aux
!>          paires propres spécifiées par HOWMNY et SELECT. Les vecteurs propres
!>          doivent être stockés dans des colonnes consécutives de VL, tels que retournés
!>          par CHSEIN ou CTREVC.
!>          Si JOB = 'V', VL n'est pas référencé.
!>

LDVL

!>          LDVL est ENTIER
!>          La dimension principale du tableau VL.
!>          LDVL >= 1 ; et si JOB = 'E' ou 'B', LDVL >= N.
!>

VR

!>          VR est un tableau COMPLEXE, de dimension (LDVR,M)
!>          Si JOB = 'E' ou 'B', VR doit contenir les vecteurs propres droits de T
!>          (ou de toute Q*T*Q**H avec Q unitaire), correspondant aux
!>          paires propres spécifiées par HOWMNY et SELECT. Les vecteurs propres
!>          doivent être stockés dans des colonnes consécutives de VR, tels que retournés
!>          par CHSEIN ou CTREVC.
!>          Si JOB = 'V', VR n'est pas référencé.
!>

LDVR

!>          LDVR est ENTIER
!>          La dimension principale du tableau VR.
!>          LDVR >= 1 ; et si JOB = 'E' ou 'B', LDVR >= N.
!>

S

!>          S est un tableau REEL, de dimension (MM)
!>          Si JOB = 'E' ou 'B', les nombres de condition réciproques des
!>          valeurs propres sélectionnées, stockés dans des éléments consécutifs du
!>          tableau. Ainsi S(j), SEP(j), et les j-èmes colonnes de VL et VR
!>          correspondent tous à la même paire propre (mais pas nécessairement à la
!>          j-ème paire propre, à moins que toutes les paires propres ne soient sélectionnées).
!>          Si JOB = 'V', S n'est pas référencé.
!>

SEP

!>          SEP est un tableau REEL, de dimension (MM)
!>          Si JOB = 'V' ou 'B', les nombres de condition réciproques estimés des
!>          vecteurs propres sélectionnés, stockés dans des éléments consécutifs du
!>          tableau.
!>          Si JOB = 'E', SEP n'est pas référencé.
!>

MM

!>          MM est ENTIER
!>          Le nombre d'éléments dans les tableaux S (si JOB = 'E' ou 'B')
!>           et/ou SEP (si JOB = 'V' ou 'B'). MM >= M.
!>

M

!>          M est ENTIER
!>          Le nombre d'éléments des tableaux S et/ou SEP réellement
!>          utilisés pour stocker les nombres de condition estimés.
!>          Si HOWMNY = 'A', M est mis à N.
!>

WORK

!>          WORK est un tableau COMPLEXE, de dimension (LDWORK,N+6)
!>          Si JOB = 'E', WORK n'est pas référencé.
!>

LDWORK

!>          LDWORK est ENTIER
!>          La dimension principale du tableau WORK.
!>          LDWORK >= 1 ; et si JOB = 'V' ou 'B', LDWORK >= N.
!>

RWORK

!>          RWORK est un tableau REEL, de dimension (N)
!>          Si JOB = 'E', RWORK n'est pas référencé.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  L'inverse du nombre de condition d'une valeur propre lambda est
!>  défini comme
!>
!>          S(lambda) = |v**H*u| / (norm(u)*norm(v))
!>
!>  où u et v sont les vecteurs propres droits et gauches de T correspondant
!>  à lambda ; v**H est la transposée conjuguée de v, et norm(u)
!>  est la norme euclidienne. Ces nombres de condition réciproques se situent toujours
!>  entre zéro (très mal conditionné) et un (très bien
!>  conditionné). Si n = 1, S(lambda) est défini comme 1.
!>
!>  Une borne d'erreur approximative pour une valeur propre calculée W(i) est donnée par
!>
!>                      EPS * norm(T) / S(i)
!>
!>  où EPS est la précision machine.
!>
!>  L'inverse du nombre de condition du vecteur propre droit u
!>  correspondant à lambda est défini comme suit. Supposons
!>
!>              T = ( lambda  c  )
!>                  (   0    T22 )
!>
!>  Alors le nombre de condition réciproque est
!>
!>          SEP( lambda, T22 ) = sigma-min( T22 - lambda*I )
!>
!>  où sigma-min représente la plus petite valeur singulière. Nous approximons
!>  la plus petite valeur singulière par l'inverse d'une estimation de
!>  la norme unitaire de l'inverse de T22 - lambda*I. Si n = 1, SEP(1) est
!>  défini comme abs(T(1,1)).
!>
!>  Une borne d'erreur approximative pour un vecteur propre droit calculé VR(i)
!>  est donnée par
!>
!>                      EPS * norm(T) / SEP(i)
!>

DTRSNA

Objectif :

!>
!> DTRSNA estime les nombres de condition réciproques pour des valeurs
!> propres et/ou des vecteurs propres droits spécifiés d'une matrice réelle
!> quasi-triangulaire T (ou de toute matrice Q*T*Q**T avec Q orthogonale).
!>
!> T doit être sous forme canonique de Schur (telle que retournée par DHSEQR),
!> c'est-à-dire, bloc triangulaire supérieur avec des blocs diagonaux de 1x1
!> et 2x2 ; chaque bloc diagonal 2x2 a ses éléments diagonaux égaux et ses
!> éléments hors diagonaux de signe opposé.
!>

Paramètres

JOB 
!>          JOB est CHARACTER*1
!>          Spécifie si les nombres de condition sont requis pour
!>          les valeurs propres (S) ou les vecteurs propres (SEP) :
!>          = 'E' : pour les valeurs propres seulement (S) ;
!>          = 'V' : pour les vecteurs propres seulement (SEP) ;
!>          = 'B' : pour les valeurs propres et les vecteurs propres (S et SEP).
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A' : calculer les nombres de condition pour toutes les paires de valeurs propres ;
!>          = 'S' : calculer les nombres de condition pour les paires de valeurs propres sélectionnées
!>                 spécifiées par le tableau SELECT.
!>

SELECT

!>          SELECT est un tableau LOGICAL, de dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les paires de valeurs propres pour lesquelles
!>          les nombres de condition sont requis. Pour sélectionner les nombres de condition
!>          correspondant à une valeur propre réelle w(j),
!>          SELECT(j) doit être mis à .VRAI.. Pour sélectionner les nombres de condition
!>          correspondant à une paire de valeurs propres complexes conjuguées w(j)
!>          et w(j+1), soit SELECT(j) soit SELECT(j+1), soit les deux, doit être
!>          mis à .VRAI..
!>          Si HOWMNY = 'A', SELECT n'est pas référencé.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice T. N >= 0.
!>

T

!>          T est un tableau DOUBLE PRÉCISION, de dimension (LDT,N)
!>          La matrice quasi-triangulaire supérieure T, sous forme canonique de Schur.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

VL

!>          VL est un tableau DOUBLE PRÉCISION, de dimension (LDVL,M)
!>          Si JOB = 'E' ou 'B', VL doit contenir les vecteurs propres gauches de T
!>          (ou de toute Q*T*Q**T avec Q orthogonale), correspondant aux
!>          paires de valeurs propres spécifiées par HOWMNY et SELECT. Les vecteurs propres
!>          doivent être stockés dans des colonnes consécutives de VL, tels que retournés par
!>          DHSEIN ou DTREVC.
!>          Si JOB = 'V', VL n'est pas référencé.
!>

LDVL

!>          LDVL est INTEGER
!>          La dimension principale du tableau VL.
!>          LDVL >= 1 ; et si JOB = 'E' ou 'B', LDVL >= N.
!>

VR

!>          VR est un tableau DOUBLE PRÉCISION, de dimension (LDVR,M)
!>          Si JOB = 'E' ou 'B', VR doit contenir les vecteurs propres droits de T
!>          (ou de toute Q*T*Q**T avec Q orthogonale), correspondant aux
!>          paires de valeurs propres spécifiées par HOWMNY et SELECT. Les vecteurs propres
!>          doivent être stockés dans des colonnes consécutives de VR, tels que retournés par
!>          DHSEIN ou DTREVC.
!>          Si JOB = 'V', VR n'est pas référencé.
!>

LDVR

!>          LDVR est INTEGER
!>          La dimension principale du tableau VR.
!>          LDVR >= 1 ; et si JOB = 'E' ou 'B', LDVR >= N.
!>

S

!>          S est un tableau DOUBLE PRÉCISION, de dimension (MM)
!>          Si JOB = 'E' ou 'B', les nombres de condition réciproques des
!>          valeurs propres sélectionnées, stockés dans des éléments consécutifs du
!>          tableau. Pour une paire de valeurs propres complexes conjuguées, deux
!>          éléments consécutifs de S sont mis à la même valeur. Ainsi
!>          S(j), SEP(j), et les colonnes j de VL et VR correspondent tous
!>          à la même paire de valeurs propres (mais pas en général à la
!>          j-ème paire de valeurs propres, sauf si toutes les paires de valeurs propres sont sélectionnées).
!>          Si JOB = 'V', S n'est pas référencé.
!>

SEP

!>          SEP est un tableau DOUBLE PRÉCISION, de dimension (MM)
!>          Si JOB = 'V' ou 'B', les nombres de condition réciproques estimés
!>          des vecteurs propres sélectionnés, stockés dans des éléments consécutifs du
!>          tableau. Pour un vecteur propre complexe, deux
!>          éléments consécutifs de SEP sont mis à la même valeur. Si
!>          les valeurs propres ne peuvent pas être réordonnées pour calculer SEP(j), SEP(j)
!>          est mis à 0 ; cela ne peut se produire que lorsque la vraie valeur serait
!>          de toute façon très petite.
!>          Si JOB = 'E', SEP n'est pas référencé.
!>

MM

!>          MM est INTEGER
!>          Le nombre d'éléments dans les tableaux S (si JOB = 'E' ou 'B')
!>           et/ou SEP (si JOB = 'V' ou 'B'). MM >= M.
!>

M

!>          M est INTEGER
!>          Le nombre d'éléments des tableaux S et/ou SEP réellement
!>          utilisés pour stocker les nombres de condition estimés.
!>          Si HOWMNY = 'A', M est mis à N.
!>

WORK

!>          WORK est un tableau DOUBLE PRÉCISION, de dimension (LDWORK,N+6)
!>          Si JOB = 'E', WORK n'est pas référencé.
!>

LDWORK

!>          LDWORK est INTEGER
!>          La dimension principale du tableau WORK.
!>          LDWORK >= 1 ; et si JOB = 'V' ou 'B', LDWORK >= N.
!>

IWORK

!>          IWORK est un tableau INTEGER, de dimension (2*(N-1))
!>          Si JOB = 'E', IWORK n'est pas référencé.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

STRSNA

estimates reciprocal condition numbers for specified eigenvalues and/or eigenvectors of a real upper quasi-triangular matrix

subroutine STRSNA (character job, character howmny, logical, dimension( * ) select, integer n, real, dimension( ldt, * ) t, integer ldt, real, dimension( ldvl, * ) vl, integer ldvl, real, dimension( ldvr, * ) vr, integer ldvr, real, dimension( * ) s, real, dimension( * ) sep, integer mm, integer m, real, dimension( ldwork, * ) work, integer ldwork, integer, dimension( * ) iwork, integer info)

STRSNA

Purpose:

!>
!> STRSNA estimates reciprocal condition numbers for specified
!> eigenvalues and/or right eigenvectors of a real upper quasi-triangular
!> matrix T (or of any matrix Q*T*Q**T with Q orthogonal).
!>

Parameters

JOB 
!>          JOB is CHARACTER*1
!>          Specifies whether condition numbers are required for
!>          eigenvalues (S) or eigenvectors (SEP):
!>          = 'E': for eigenvalues only (S);
!>          = 'V': for eigenvectors only (SEP);
!>          = 'B': for both eigenvalues and eigenvectors (S and SEP).
!>

HOWMNY

!>          HOWMNY is CHARACTER*1
!>          = 'A': compute condition numbers for all eigenpairs;
!>          = 'S': compute condition numbers for selected eigenpairs
!>                 specified by the array SELECT.
!>

SELECT

!>          SELECT is LOGICAL array, dimension (N)
!>          If HOWMNY = 'S', SELECT specifies the eigenpairs for which
!>          condition numbers are required. To select condition numbers
!>          for the eigenpair corresponding to a real eigenvalue w(j),
!>          SELECT(j) must be set to .TRUE.. To select condition numbers
!>          corresponding to a complex conjugate pair of eigenvalues w(j)
!>          and w(j+1), either SELECT(j) or SELECT(j+1) or both, must be
!>          set to .TRUE..
!>          If HOWMNY = 'A', SELECT is not referenced.
!>

N

!>          N is INTEGER
!>          The order of the matrix T. N >= 0.
!>

T

!>          T is REAL array, dimension (LDT,N)
!>          The upper quasi-triangular matrix T, in Schur canonical form.
!>

LDT

!>          LDT is INTEGER
!>          The leading dimension of the array T. LDT >= max(1,N).
!>

VL

!>          VL is REAL array, dimension (LDVL,M)
!>          If JOB = 'E' or 'B', VL must contain left eigenvectors of T
!>          (or of any Q*T*Q**T with Q orthogonal), corresponding to the
!>          eigenpairs specified by HOWMNY and SELECT. The eigenvectors
!>          must be stored in consecutive columns of VL, as returned by
!>          SHSEIN or STREVC.
!>          If JOB = 'V', VL is not referenced.
!>

LDVL

!>          LDVL is INTEGER
!>          The leading dimension of the array VL.
!>          LDVL >= 1; and if JOB = 'E' or 'B', LDVL >= N.
!>

VR

!>          VR is REAL array, dimension (LDVR,M)
!>          If JOB = 'E' or 'B', VR must contain right eigenvectors of T
!>          (or of any Q*T*Q**T with Q orthogonal), corresponding to the
!>          eigenpairs specified by HOWMNY and SELECT. The eigenvectors
!>          must be stored in consecutive columns of VR, as returned by
!>          SHSEIN or STREVC.
!>          If JOB = 'V', VR is not referenced.
!>

LDVR

!>          LDVR is INTEGER
!>          The leading dimension of the array VR.
!>          LDVR >= 1; and if JOB = 'E' or 'B', LDVR >= N.
!>

S

!>          S is REAL array, dimension (MM)
!>          If JOB = 'E' or 'B', the reciprocal condition numbers of the
!>          selected eigenvalues, stored in consecutive elements of the
!>          array. For a complex conjugate pair of eigenvalues two
!>          consecutive elements of S are set to the same value. Thus
!>          S(j), SEP(j), and the j-th columns of VL and VR all
!>          correspond to the same eigenpair (but not in general the
!>          j-th eigenpair, unless all eigenpairs are selected).
!>          If JOB = 'V', S is not referenced.
!>

SEP

!>          SEP is REAL array, dimension (MM)
!>          If JOB = 'V' or 'B', the estimated reciprocal condition
!>          numbers of the selected eigenvectors, stored in consecutive
!>          elements of the array. For a complex eigenvector two
!>          consecutive elements of SEP are set to the same value. If
!>          the eigenvalues cannot be reordered to compute SEP(j), SEP(j)
!>          is set to 0; this can only occur when the true value would be
!>          very small anyway.
!>          If JOB = 'E', SEP is not referenced.
!>

MM

!>          MM is INTEGER
!>          The number of elements in the arrays S (if JOB = 'E' or 'B')
!>           and/or SEP (if JOB = 'V' or 'B'). MM >= M.
!>

M

!>          M is INTEGER
!>          The number of elements of the arrays S and/or SEP actually
!>          used to store the estimated condition numbers.
!>          If HOWMNY = 'A', M is set to N.
!>

WORK

!>          WORK is REAL array, dimension (LDWORK,N+6)
!>          If JOB = 'E', WORK is not referenced.
!>

LDWORK

!>          LDWORK is INTEGER
!>          The leading dimension of the array WORK.
!>          LDWORK >= 1; and if JOB = 'V' or 'B', LDWORK >= N.
!>

IWORK

!>          IWORK is INTEGER array, dimension (2*(N-1))
!>          If JOB = 'E', IWORK is not referenced.
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>

!>
!>  The reciprocal of the condition number of an eigenvalue lambda is
!>  defined as
!>
!>          S(lambda) = |v**T*u| / (norm(u)*norm(v))
!>
!>  where u and v are the right and left eigenvectors of T corresponding
!>  to lambda; v**T denotes the transpose of v, and norm(u)
!>  denotes the Euclidean norm. These reciprocal condition numbers always
!>  lie between zero (very badly conditioned) and one (very well
!>  conditioned). If n = 1, S(lambda) is defined to be 1.
!>
!>  An approximate error bound for a computed eigenvalue W(i) is given by
!>
!>                      EPS * norm(T) / S(i)
!>
!>  where EPS is the machine precision.
!>
!>  The reciprocal of the condition number of the right eigenvector u
!>  corresponding to lambda is defined as follows. Suppose
!>
!>              T = ( lambda  c  )
!>                  (   0    T22 )
!>
!>  Then the reciprocal condition number is
!>
!>          SEP( lambda, T22 ) = sigma-min( T22 - lambda*I )
!>
!>  where sigma-min denotes the smallest singular value. We approximate
!>  the smallest singular value by the reciprocal of an estimate of the
!>  one-norm of the inverse of T22 - lambda*I. If n = 1, SEP(1) is
!>  defined to be abs(T(1,1)).
!>
!>  An approximate error bound for a computed right eigenvector VR(i)
!>  is given by
!>
!>                      EPS * norm(T) / SEP(i)
!>

NOM

ZTRSNAT — Calcule les réciproques des nombres de condition de toutes les valeurs propres ou vecteurs propres sélectionnés d'une matrice triangulaire supérieure complexe.

DESCRIPTION

ZTRSNAT calcule les réciproques des nombres de condition de les valeurs propres sélectionnées et/ou des vecteurs propres sélectionnés d'une matrice triangulaire supérieure complexe.

Les valeurs propres et vecteurs propres sont calculés par ZTRNAIT. Cette routine est appelée après ZTRNAIT.

Les valeurs propres sont stockées dans le tableau W.

Les vecteurs propres sont stockés dans les colonnes du tableau Z.

Les matrices F alat et C alat sont les matrices triangulaires supérieures et triangulaires inférieures des facteurs L et U de la décomposition LU de A. Elles sont nécessaires pour calculer les nombres de condition des vecteurs propres.

Le tableau SEP est utilisé pour stocker les réciproques des nombres de condition des vecteurs propres.

Le tableau WORK est un espace de travail.

Le tableau RWORK est un espace de travail.

JOB

JOB est CHARACTER * 1.

Spécifie la tâche à effectuer :

  • 'E' : Calcule uniquement les réciproques des nombres de condition des valeurs propres sélectionnées.
  • 'V' : Calcule uniquement les réciproques des nombres de condition des vecteurs propres sélectionnés.
  • 'B' : Calcule les réciproques des nombres de condition des valeurs propres sélectionnées et des vecteurs propres sélectionnés.
