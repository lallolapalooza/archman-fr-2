tracefs_buffer_stat_entries(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_instance_get_stat, tracefs_instance_put_stat, tracefs_buffer_stat_entries, tracefs_buffer_stat_overrun, tracefs_buffer_stat_commit_overrun, tracefs_buffer_stat_bytes, tracefs_buffer_stat_event_timestamp, tracefs_buffer_stat_timestamp, tracefs_buffer_stat_dropped_events, tracefs_buffer_stat_read_events - Gestion des statistiques des tampons de traçage

SYNTAXE

#include <tracefs.h>
struct tracefs_buffer_stat *tracefs_instance_get_stat(struct tracefs_instance *instance, int cpu);
void tracefs_instance_put_stat(struct tracefs_buffer_stat *tstat);
ssize_t tracefs_buffer_stat_entries(struct tracefs_buffer_stat *tstat);
ssize_t tracefs_buffer_stat_overrun(struct tracefs_buffer_stat *tstat);
ssize_t tracefs_buffer_stat_commit_overrun(struct tracefs_buffer_stat *tstat);
ssize_t tracefs_buffer_stat_bytes(struct tracefs_buffer_stat *tstat);
long long tracefs_buffer_stat_event_timestamp(struct tracefs_buffer_stat *tstat);
long long tracefs_buffer_stat_timestamp(struct tracefs_buffer_stat *tstat);
ssize_t tracefs_buffer_stat_dropped_events(struct tracefs_buffer_stat *tstat);
ssize_t tracefs_buffer_stat_read_events(struct tracefs_buffer_stat *tstat);

DESCRIPTION

Cet ensemble de fonctions lit et analyse le fichier tracefs/per_cpu/cpuX/stats. Ces fichiers contiennent les statistiques du tampon circulaire par CPU, comme le nombre d'événements dans le tampon circulaire, ceux qui ont été lus, etc.

La fonction tracefs_instance_get_stat() lit et analyse un fichier de statistiques donné pour une instance et un cpu donnés. Comme le tampon circulaire est divisé en tampons par CPU, les informations sont uniquement associées au cpu donné. Le pointeur tracefs_buffer_stat retourné peut être utilisé avec les autres fonctions tracefs_buffer_stat et doit être libéré avec tracefs_instance_put_stat().

La fonction tracefs_instance_put_stat() libère les ressources allouées pour le stat donné qui a été créé par tracefs_instance_get_stat().

La fonction tracefs_buffer_stat_entries() retourne le nombre d'événements actuellement présents dans le tampon circulaire associé à tstat.

La fonction tracefs_buffer_stat_overrun() retourne le nombre d'événements qui ont été perdus car l'enregistreur du tampon circulaire a dépassé le lecteur.

La fonction tracefs_buffer_stat_commit_overrun() retourne le nombre d'événements qui ont été perdus car le tampon circulaire était trop petit et qu'une interruption a interrompu l'enregistrement d'un événement de contexte inférieur, ajoutant plus d'événements que le tampon circulaire ne pouvait en contenir. Notez que ce n'est pas une occurrence courante et que cela signifie que quelque chose n'a pas été correctement configuré.

La fonction tracefs_buffer_stat_bytes() retourne le nombre d'octets occupés par les événements actuels. Notez qu'il inclut les métadonnées des événements, mais pas les métadonnées des sous-tampons.

La fonction tracefs_buffer_stat_event_timestamp() retourne l'horodatage du dernier événement dans le tampon circulaire.

La fonction tracefs_buffer_stat_timestamp() retourne l'horodatage actuel du tampon circulaire. Notez qu'il n'est lu que lorsque tracefs_instance_get_stat() est appelé. Il aura l'horodatage du tampon circulaire au moment de l'appel de cette fonction.

La fonction tracefs_buffer_stat_dropped_events() retourne le nombre d'événements qui ont été ignorés si le mode d'écrasement est désactivé. Il affichera les événements qui ont été perdus car l'enregistreur a rattrapé le lecteur et ne pouvait pas écrire plus d'événements.

La fonction tracefs_buffer_stat_read_events() retourne le nombre d'événements qui ont été consommés par un lecteur.

VALEUR DE RETOUR

La fonction tracefs_instance_get_stat() retourne une structure tracefs_buffer_stat qui peut être utilisée pour récupérer les statistiques via les autres fonctions. Elle doit être libérée avec tracefs_instance_put_stat().

Les autres fonctions qui retournent des valeurs différentes de la structure tracefs_buffer_stat retournent toutes la valeur, ou -1 si la valeur n'a pas été trouvée.

EXEMPLE

#include <stdlib.h>
#include <unistd.h>
#include <tracefs.h>
int main(int argc, char **argv)
{
        char *trace;
        char buf[1000];
        int ret;
        int i;
        for (i = 0; i < sizeof(buf) - 1; i++) {
                buf[i] = '0' + i % 10;
        }
        buf[i] = '\0';
        tracefs_instance_clear(NULL);
        for (i = 0; i < 4; i++) {
                ret = tracefs_printf(NULL, "%s\n", buf);
                if (ret < 0)
                        perror("write");
        }
        trace = tracefs_instance_file_read(NULL, "trace", NULL);
        printf("%s\n", trace);
        free(trace);
        for (i = 0; i < sysconf(_SC_NPROCESSORS_CONF); i++) {
                struct tracefs_buffer_stat *tstat;
                ssize_t entries, eread;
                tstat = tracefs_instance_get_stat(NULL, i);
                if (!tstat)
                        continue;
                entries = tracefs_buffer_stat_entries(tstat);
                eread = tracefs_buffer_stat_read_events(tstat);
                if (!entries && !eread) {
                        tracefs_instance_put_stat(tstat);
                        continue;
                }
                printf("CPU: %d\n", i);;
                printf("\tentries: %zd\n", entries);
                printf("\toverrun: %zd\n", tracefs_buffer_stat_overrun(tstat));
                printf("\tcommit_overrun: %zd\n", tracefs_buffer_stat_commit_overrun(tstat));
                printf("\tbytes: %zd\n", tracefs_buffer_stat_bytes(tstat));
                printf("\tevent_timestamp: %lld\n", tracefs_buffer_stat_event_timestamp(tstat));
                printf("\ttimestamp: %lld\n", tracefs_buffer_stat_timestamp(tstat));
                printf("\tdropped_events: %zd\n", tracefs_buffer_stat_dropped_events(tstat));
                printf("\tread_events: %zd\n", eread);
                tracefs_instance_put_stat(tstat);
        }
}
