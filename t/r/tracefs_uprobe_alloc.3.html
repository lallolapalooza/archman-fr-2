tracefs_uprobe_alloc(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_uprobe_alloc, tracefs_uretprobe_alloc - Allouer une nouvelle sonde utilisateur (de retour)

SYNOPSIS

#include <tracefs.h>
struct tracefs_dynevent *
tracefs_uprobe_alloc(const char *system, const char *event,
                     const char *file, unsigned long long offset, const char *fetchargs)
struct tracefs_dynevent *
tracefs_uretprobe_alloc(const char *system, const char *event,
                     const char *file, unsigned long long offset, const char *fetchargs)

DESCRIPTION

tracefs_uprobe_alloc() alloue un nouveau contexte uprobe. Il sera dans le groupe system (ou uprobes si system est NULL) et portant le nom event. La uprobe sera attachée à l'offset dans le file. La liste des arguments, décrits dans fetchargs, sera récupérée avec la uprobe. Le pointeur retourné vers le contexte de sonde utilisateur doit être libéré avec tracefs_dynevent_free(). La uprobe n'est pas configurée dans le système, la série d'API tracefs_dynevent_* peut être utilisée pour la configurer.

tracefs_uretprobe_alloc() se comporte de la même manière que tracefs_uprobe_alloc(), la seule différence est qu'il alloue un contexte pour une sonde de retour utilisateur (uretprobe).

VALEUR DE RETOUR

Les API tracefs_uprobe_alloc() et tracefs_uretprobe_alloc() retournent un pointeur vers une structure tracefs_dynevent allouée, décrivant la sonde utilisateur. Ce pointeur doit être libéré avec tracefs_dynevent_free(3). Notez que cela alloue uniquement un descripteur représentant la uprobe. Cela ne modifie pas le système en cours d'exécution. En cas d'erreur, NULL est retourné.

EXEMPLE

#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>
#include <tracefs.h>
static int callback(struct tep_event *event, struct tep_record *record,
                    int cpu, void *data)
{
        struct trace_seq seq;
        trace_seq_init(&seq);
        tep_print_event(event->tep, &seq, record, "%d-%s: %s",
                        TEP_PRINT_PID, TEP_PRINT_COMM, TEP_PRINT_NAME);
        trace_seq_puts(&seq, "'\n");
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
        trace_seq_destroy(&seq);
        return 0;
}
static pid_t run_exec(char **argv, char **env)
{
        pid_t pid;
        pid = fork();
        if (pid)
                return pid;
        execve(argv[0], argv, env);
        perror("exec");
        exit(-1);
}
const char *myprobe = "my_urobes";
int main (int argc, char **argv, char **env)
{
        struct tracefs_dynevent *uprobe, *uretprobe;
        struct tep_handle *tep;
        struct tracefs_instance *instance;
        const char *sysnames[] = { myprobe, NULL };
        long addr;
        pid_t pid;
        if (argc < 3) {
                printf("usage: %s file_offset command\n", argv[0]);
                exit(-1);
        }
        addr = strtol(argv[1], NULL, 0);
        instance = tracefs_instance_create("exec_open");
        if (!instance) {
                perror("creating instance");
                exit(-1);
        }
        tracefs_dynevent_destroy_all(TRACEFS_DYNEVENT_UPROBE|TRACEFS_DYNEVENT_URETPROBE, true);
        uprobe = tracefs_uprobe_alloc(myprobe, "user_probe", argv[2], addr, NULL);
        uretprobe = tracefs_uretprobe_alloc(myprobe, "user_retprobe", argv[2], addr, NULL);
        if (!uprobe || !uretprobe) {
                perror("allocating user probes");
                exit(-1);
        }
        if (tracefs_dynevent_create(uprobe) ||
            tracefs_dynevent_create(uretprobe)) {
                perror("creating user probes");
                exit(-1);
        }
        tep = tracefs_local_events_system(NULL, sysnames);
        if (!tep) {
                perror("reading events");
                exit(-1);
        }
        tracefs_event_enable(instance, myprobe, "user_probe");
        tracefs_event_enable(instance, myprobe, "user_retprobe");
        pid = run_exec(&argv[2], env);
        /* Let the child start to run */
        sched_yield();
        do {
                tracefs_load_cmdlines(NULL, tep);
                tracefs_iterate_raw_events(tep, instance, NULL, 0, callback, NULL);
        } while (waitpid(pid, NULL, WNOHANG) != pid);
        /* disable and destroy the events */
        tracefs_dynevent_destroy(uprobe, true);
        tracefs_dynevent_destroy(uretprobe, true);
        tracefs_dynevent_free(uprobe);
        tracefs_dynevent_free(uretprobe);
        tracefs_instance_destroy(instance);
        return 0;
}

tracefs_uprobe_alloc(3)

NAME

tracefs_uprobe_alloc - Allocate a uprobe event

SYNOPSIS

#include <tracefs.h> struct tracefs_event * tracefs_uprobe_alloc( const char *name, const char *file, int line, const char *symbol, int offset );

DESCRIPTION

The tracefs(3) library provides functions to interact with the kernel's tracefs filesystem. This function, tracefs_uprobe_alloc, allocates a uprobe event.

A uprobe event is a probe that can be placed at any instruction within a binary executable or library. This allows for dynamic tracing of user-space applications without modifying their code.

The function takes the following arguments:

  • name: The name of the uprobe event. This will be used as the name of the event in tracefs.
  • file: The path to the binary executable or library where the probe should be placed.
  • line: The line number in the source file where the probe should be placed. If 0, the probe will be placed at the specified offset within the symbol.
  • symbol: The name of the symbol (function or variable) near where the probe should be placed. If 0, the probe will be placed at the specified line number.
  • offset: The offset from the beginning of the symbol or file where the probe should be placed. This is used if line is 0 or if symbol is specified.

The function returns a pointer to a struct tracefs_event on success, or NULL on failure. The returned structure contains information about the allocated event, including its name, type, and any associated data.

RETURN VALUE

On success, a pointer to a struct tracefs_event is returned. On failure, NULL is returned.

NOTES

This function allocates a uprobe event structure in memory. It does not enable or attach the probe to the target. To enable and attach the probe, you would typically use other functions from the tracefs library, such as tracefs_event_enable() and tracefs_event_attach().

The tracefs filesystem must be mounted for this function to work. Typically, it is mounted at /sys/kernel/debug/tracing.

Ensure that you have the necessary permissions to create trace events, which usually requires root privileges.

The struct tracefs_event should be freed using tracefs_event_free() when it is no longer needed.
