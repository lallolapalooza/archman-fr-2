NOM

trace-cmd-clear - efface le tampon Ftrace.

SYNTAXE

trace-cmd clear [OPTIONS]

DESCRIPTION

La commande trace-cmd(1) clear efface le contenu du tampon circulaire Ftrace.

OPTIONS

-B nom-tampon

Si le noyau prend en charge plusieurs tampons, cela effacera uniquement le tampon donné. Cela n'affectera aucun autre tampon. Ceci peut être utilisé plusieurs fois pour spécifier différents tampons. Le tampon de niveau supérieur ne sera pas effacé si cette option est donnée.

-a

Efface tous les tampons existants, y compris celui de niveau supérieur.
