NOM

tracefs_hist_alloc, tracefs_hist_alloc_2d, tracefs_hist_alloc_nd, tracefs_hist_alloc_nd_cnt, tracefs_hist_free, tracefs_hist_add_key, tracefs_hist_add_key_cnt, tracefs_hist_add_value - Créer et détruire des histogrammes d'événements

SYNTAXE

#include <tracefs.h>
enum tracefs_hist_key_type {
        TRACEFS_HIST_KEY_NORMAL = 0,
        TRACEFS_HIST_KEY_HEX,
        TRACEFS_HIST_KEY_SYM,
        TRACEFS_HIST_KEY_SYM_OFFSET,
        TRACEFS_HIST_KEY_SYSCALL,
        TRACEFS_HIST_KEY_EXECNAME,
        TRACEFS_HIST_KEY_LOG,
        TRACEFS_HIST_KEY_USECS,
        TRACEFS_HIST_KEY_MAX
};
struct tracefs_hist_axis {
        const char *key;
        enum tracefs_hist_key_type type;
};
struct tracefs_hist *tracefs_hist_alloc(struct tracefs_tep * tep,

                        const char *key, enum tracefs_hist_key_type type);

                        const char *system, const char *event,
                        const char *key1, enum tracefs_hist_key_type type1,
                        const char *key2, enum tracefs_hist_key_type type2));

                        const char *system, const char *event,
                        struct tracefs_hist_axis *axes);

                          struct tracefs_hist_axis_cnt *axes);

                         enum tracefs_hist_key_type type, int cnt);
int tracefs_hist_add_value(struct tracefs_hist *hist, const char *value);

DESCRIPTION

Les histogrammes d'événements sont créés par le fichier « trigger » dans le répertoire de l'événement. La syntaxe peut être complexe et difficile à maîtriser. Cette API gère la syntaxe et facilite la création et l'interaction avec les histogrammes d'événements. Voir https://www.kernel.org/doc/html/latest/trace/histogram.html pour plus d'informations.

tracefs_hist_alloc() alloue un descripteur « struct tracefs_hist » pour un histogramme unidimensionnel et renvoie son adresse. Ce descripteur doit être libéré par tracefs_hist_free(). Le paramètre tep est un handle d'événement de trace (voir tracefs_local_events(3)), qui détient le system et l'event auxquels l'histogramme sera attaché. Le system est le système ou le groupe de l'événement. L' event est l'événement auquel l'histogramme sera attaché. La clé (key) est un champ de l'événement qui sera utilisé comme clé (dimension) de l'histogramme. Le type est le type de la clé. Voir TYPES DE CLÉS ci-dessous.

tracefs_hist_alloc_2d() alloue un descripteur « struct tracefs_hist » pour un histogramme bidimensionnel et renvoie son adresse. Ce descripteur doit être libéré par tracefs_hist_free(). Le paramètre tep est un handle d'événement de trace (voir tracefs_local_events(3)), qui détient le system et l'event auxquels l'histogramme sera attaché. Le system est le système ou le groupe de l'événement. L' event est l'événement auquel l'histogramme sera attaché. La key1 est le premier champ de l'événement qui sera utilisé comme clé (dimension) de l'histogramme. Le type1 est le type de la key1. Voir TYPES DE CLÉS ci-dessous. La key2 est le second champ de l'événement qui sera utilisé comme clé (dimension) de l'histogramme. Le type2 est le type de la key2. Voir TYPES DE CLÉS ci-dessous.

tracefs_hist_alloc_nd() alloue un descripteur « struct tracefs_hist » pour un histogramme N-dimensionnel et renvoie son adresse. Ce descripteur doit être libéré par tracefs_hist_free(). Le paramètre tep est un handle d'événement de trace (voir tracefs_local_events(3)), qui détient le system et l'event auxquels l'histogramme sera attaché. Le system est le système ou le groupe de l'événement. L' event est l'événement auquel l'histogramme sera attaché. Les axes sont un tableau de paires clé / type, définissant les dimensions de l'histogramme.

tracefs_hist_alloc_nd_cnt() initialisera un descripteur d'histogramme qui sera attaché au couple system/event. Ceci initialise uniquement le descripteur avec les clés axes fournies comme principales. Ceci initialise uniquement le descripteur, cela ne démarre pas l'histogramme dans le noyau. La différence entre ceci et tracefs_hist_alloc_nd() est que le paramètre axes est de type struct tracefs_hist_axis_cnt et non struct tracefs_hist_axis.

tracefs_hist_free() libère le descripteur tracefs_hist. Notez qu'il n'arrête ni ne désactive l'histogramme en cours d'exécution s'il était démarré. tracefs_hist_destroy() doit être appelé pour cela.

tracefs_hist_add_key() ajoute une clé secondaire ou tertiaire à l'histogramme. La clé passée à tracefs_hist_alloc_nd() est la clé principale de l'histogramme. La première fois que cette fonction est appelée, elle ajoutera une clé secondaire (ou un histogramme bidimensionnel). Si cette fonction est appelée à nouveau sur le même histogramme, elle ajoutera une clé tertiaire (ou un histogramme tridimensionnel). Le paramètre hist est le descripteur de l'histogramme auquel ajouter la clé. Le type est le type de clé à ajouter (voir TYPES DE CLÉS ci-dessous).

tracefs_hist_add_key_cnt() est identique à tracefs_hist_add_key() sauf qu'elle permet d'ajouter un compteur pour le type donné. Actuellement, seul le type buckets nécessite un compteur. Lors de l'ajout d'une clé de type buckets, tracefs_hist_add_key() n'est pas suffisant, car le type buckets nécessite un compteur ou une taille de bucket. Utilisez tracefs_hist_add_key_cnt() lors de la spécification d'une clé divisée en buckets, et passez la taille de ces buckets dans cnt.

tracefs_hist_add_value() ajoutera une valeur à enregistrer. Par défaut, la valeur est simplement le « hitcount » (nombre de fois où une instance de la clé de l'histogramme a été rencontrée). Le paramètre hist est le descripteur de l'histogramme auquel ajouter la valeur. Le paramètre value est un champ de l'histogramme à ajouter lorsqu'une instance de la clé est rencontrée.

TYPES DE CLÉS

tracefs_hist_alloc_nd() et tracefs_hist_add_key() ajoutent tous deux une clé et exigent que cette clé ait un type. Les types peuvent être :

TRACEFS_HIST_KEY_NORMAL ou zéro (0), ce qui signifie ne pas modifier le type.

TRACEFS_HIST_KEY_HEX pour afficher la clé en hexadécimal.

TRACEFS_HIST_KEY_SYM pour afficher la clé comme un symbole du noyau (si trouvé). Si la clé est une adresse, ceci est utile car cela affichera les noms de fonctions au lieu de simples nombres.

TRACEFS_HIST_KEY_SYM_OFFSET similaire à TRACEFS_HIST_KEY_SYM mais inclura également le décalage de la fonction pour correspondre à l'adresse exacte.

TRACEFS_HIST_KEY_SYSCALL Si la clé est un « id » d'appel système (le nombre passé de l'espace utilisateur au noyau pour lui indiquer quel appel système il effectue), alors le nom de l'appel système est affiché.

TRACEFS_HIST_KEY_EXECNAME Si « common_pid » est la clé (le pid de la tâche en cours d'exécution), au lieu d'afficher le nombre, on affiche le nom de la tâche en cours d'exécution.

TRACEFS_HIST_KEY_LOG affichera la clé sur une échelle logarithmique binaire.

TRACEFS_HIST_KEY_USECS à utiliser avec « common_timestamp » ou TRACEFS_HIST_TIMESTAMP, auquel cas il affichera l'horodatage en microsecondes au lieu de nanosecondes.

VALEUR DE RETOUR

tracefs_hist_alloc_nd() renvoie un descripteur d'histogramme alloué qui doit être libéré par tracefs_hist_free() ou NULL en cas d'erreur.

Toutes les autres fonctions renvoient zéro en cas de succès et -1 en cas d'erreur.

Si tracefs_hist_start() renvoie une erreur, un message peut être affiché dans le noyau et récupéré par tracefs_error_last().

EXEMPLE

#include <stdlib.h>
#include <ctype.h>
#include <unistd.h>
#include <tracefs.h>
enum commandes {
        START,
        PAUSE,
        CONT,
        RESET,
        DELETE,
        SHOW,
};
static void parse_system_event(char *group, char **system, char **event)
{
        *system = strtok(group, "/");
        *event = strtok(NULL, "/");
        if (!*event) {
                *event = *system;
                *system = NULL;
        }
}
static int parse_keys(char *keys, struct tracefs_hist_axis_cnt **axes)
{
        char *sav = NULL;
        char *key;
        int cnt = 0;
        for (key = strtok_r(keys, ",", &sav); key; key = strtok_r(NULL, ",", &sav)) {
                struct tracefs_hist_axis_cnt *ax;
                char *att;
                ax = realloc(*axes, sizeof(*ax) * (cnt + 2));
                if (!ax) {
                        perror("Échec de l'allocation des axes");
                        exit(-1);
                }
                ax[cnt].key = key;
                ax[cnt].type = 0;
                ax[cnt + 1].key = NULL;
                ax[cnt + 1].type = 0;
                *axes = ax;
                att = strchr(key, '.');
                if (att) {
                        *att++ = '\0';
                        if (strcmp(att, "hex") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_HEX;
                        else if (strcmp(att, "sym") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM;
                        else if (strcmp(att, "sym_offset") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM_OFFSET;
                        else if (strcmp(att, "syscall") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYSCALL;
                        else if (strcmp(att, "exec") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_EXECNAME;
                        else if (strcmp(att, "log") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_LOG;
                        else if (strcmp(att, "usecs") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_USECS;
                        else if (strncmp(att, "buckets", 7) == 0) {
                                if (att[7] != '=' && !isdigit(att[8])) {
                                        fprintf(stderr, "Le type de clé 'buckets' nécessite '=<taille>'\n");
                                        exit(-1);
                                }
                                ax[cnt].type = TRACEFS_HIST_KEY_BUCKETS;
                                ax[cnt].cnt = atoi(&att[8]);
                        } else {
                                fprintf(stderr, "Attribut indéfini '%s'\n", att);
                                fprintf(stderr,"  Attributs acceptables:\n");
                                fprintf(stderr,"    hex, sym, sym_offset, syscall, exe, log, usecs\n");
                                exit(-1);
                        }
                }
                cnt++;
        }
        return cnt;
}
static void process_hist(enum commandes cmd, const char *instance_name,
                         char *group, char *keys, char *vals, char *sort,
                         char *ascend, char *desc)
{
        struct tracefs_instance *instance = NULL;
        struct tracefs_hist *hist;
        struct tep_handle *tep;
        struct tracefs_hist_axis_cnt *axes = NULL;
        char *system;
        char *event;
        char *sav;
        char *val;
        int ret;
        int cnt;
        if (instance_name) {
                instance = tracefs_instance_create(instance_name);
                if (!instance) {
                        fprintf(stderr, "Échec de la création de l'instance\n");
                        exit(-1);
                }
        }
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("Impossible de lire les événements");
                exit(-1);
        }
        parse_system_event(group, &system, &event);
        if (cmd == SHOW) {
                char *content;
                content = tracefs_event_file_read(instance, system, event,
                                                  "hist", NULL);
                if (!content) {
                        perror("Lecture du fichier hist");
                        exit(-1);
                }
                printf("%s\n", content);
                free(content);
                return;
        }
        if (!keys) {
                fprintf(stderr, "La commande nécessite l'option -k\n");
                exit(-1);
        }
        cnt = parse_keys(keys, &axes);
        if (!cnt) {
                fprintf(stderr, "Aucune clé ??\n");
                exit(-1);
        }
        /* les buckets nécessitent la fonction nd_cnt */
        switch (cnt) {
        case 2:
                if (axes[1].type == TRACEFS_HIST_KEY_BUCKETS)
                        cnt = -1;
                /* fall through */
        case 1:
                if (axes[0].type == TRACEFS_HIST_KEY_BUCKETS)
                        cnt = -1;
        }
        /* Afficher des exemples de hist1d et hist2d */
        switch (cnt) {
        case 1:
                hist = tracefs_hist_alloc(tep, system, event,
                                          axes[0].key, axes[0].type);
                break;
        case 2:
                hist = tracefs_hist_alloc_2d(tep, system, event,
                                             axes[0].key, axes[0].type,
                                             axes[1].key, axes[1].type);
                break;
        default:
                /* Vraiment, 1 et 2 pourraient aussi utiliser ceci */
                hist = tracefs_hist_alloc_nd_cnt(tep, system, event, axes);
        }
        if (!hist) {
                fprintf(stderr, "Échec de la création de l'hist");
                exit(-1);
        }
        if (vals) {
                sav = NULL;
                for (val = strtok_r(vals, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_value(hist, val);
                        if (ret) {
                                fprintf(stderr, "Échec de l'ajout de la valeur %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (sort) {
                sav = NULL;
                for (val = strtok_r(sort, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_sort_key(hist, val);
                        if (ret) {
                                fprintf(stderr, "Échec de l'ajout de la clé/valeur de tri %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (ascend) {
                sav = NULL;
                for (val = strtok_r(ascend, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_ASCENDING);
                        if (ret) {
                                fprintf(stderr, "Échec de l'ajout de la clé/valeur ascendante %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (desc) {
                sav = NULL;
                for (val = strtok_r(desc, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_DESCENDING);
                        if (ret) {
                                fprintf(stderr, "Échec de l'ajout de la clé/valeur descendante %s\n", val);
                                exit(-1);
                        }
                }
        }
        tracefs_error_clear(instance);
        switch (cmd) {
        case START:
                ret = tracefs_hist_start(instance, hist);
                if (ret) {
                        char *err = tracefs_error_last(instance);
                        if (err)
                                fprintf(stderr, "\n%s\n", err);
                }
                break;
        case PAUSE:
                ret = tracefs_hist_pause(instance, hist);
                break;
        case CONT:
                ret = tracefs_hist_continue(instance, hist);
                break;
        case RESET:
                ret = tracefs_hist_reset(instance, hist);
                break;
        case DELETE:
                ret = tracefs_hist_destroy(instance, hist);
                break;
        case SHOW:
                /* SHOW a déjà été fait */
                break;
        }
        if (ret)
                fprintf(stderr, "Échec : commande\n");
        exit(ret);
}
int main (int argc, char **argv, char **env)
{
        enum commandes cmd;
        char *instance = NULL;
        char *cmd_str;
        char *event = NULL;
        char *keys = NULL;
        char *vals = NULL;
        char *sort = NULL;
        char *desc = NULL;
        char *ascend = NULL;
        if (argc < 2) {
                fprintf(stderr, "usage: %s commande [-B instance][-e [system/]événement][-k clés][-v valeurs][-s tri]\n", argv[0]);
                fprintf(stderr, "      [-a ascendant][-d descendant]\n");
                exit(-1);
        }
        cmd_str = argv[1];
        if (!strcmp(cmd_str, "start"))
                cmd = START;
        else if (!strcmp(cmd_str, "pause"))
                cmd = PAUSE;
        else if (!strcmp(cmd_str, "cont"))
                cmd = CONT;
        else if (!strcmp(cmd_str, "reset"))
                cmd = RESET;
        else if (!strcmp(cmd_str, "delete"))
                cmd = DELETE;
        else if (!strcmp(cmd_str, "show"))
                cmd = SHOW;
        else {
                fprintf(stderr, "Commande inconnue %s\n", cmd_str);
                exit(-1);
        }
        for (;;) {
                int c;
                c = getopt(argc - 1, argv + 1, "e:k:v:B:s:d:a:");
                if (c == -1)
                        break;
                switch (c) {
                case 'e':
                        event = optarg;
                        break;
                case 'k':
                        keys = optarg;
                        break;
                case 'v':
                        vals = optarg;
                        break;
                case 'B':
                        instance = optarg;
                        break;
                case 's':
                        sort = optarg;
                        break;
                case 'd':
                        desc = optarg;
                        break;
                case 'a':
                        ascend = optarg;
                        break;
                }
        }
        if (!event) {
                event = "kmem/kmalloc";
                if (!keys)
                        keys = "call_site.sym,bytes_req";
                if (!vals)
                        vals = "bytes_alloc";
                if (!sort)
                        sort = "bytes_req,bytes_alloc";
                if (!desc)
                        desc = "bytes_alloc";
        }
        process_hist(cmd, instance, event, keys, vals, sort, ascend, desc);
}

NAME

tracefs_hist_alloc_2d, tracefs_hist_free_2d, tracefs_hist_lookup_2d, tracefs_hist_add_2d, tracefs_hist_del_2d, tracefs_hist_dump_2d - Allocate, free, lookup, add, delete, and dump 2D histogram data

SYNOPSIS

#include <tracefs.h>
struct tracefs_hist_entry *
tracefs_hist_alloc_2d(const char *name, const char *event,
    const char *field1, const char *field2);
void
tracefs_hist_free_2d(struct tracefs_hist_entry *entry);
struct tracefs_hist_entry *
tracefs_hist_lookup_2d(const char *name);
int
tracefs_hist_add_2d(struct tracefs_hist_entry *entry, u64 val1, u64 val2);
int
tracefs_hist_del_2d(struct tracefs_hist_entry *entry, u64 val1, u64 val2);
int
tracefs_hist_dump_2d(struct tracefs_hist_entry *entry);

DESCRIPTION

The libtracefs library provides a simple API to interact with tracefs, a trace-point tracing infrastructure available in the Linux kernel.

This API allows the creation and manipulation of 2D histograms, which are useful for analyzing event data by categorizing events based on two fields.

tracefs_hist_alloc_2d allocates a structure to represent a 2D histogram. It requires a unique name for the histogram, the name of the event to trace, and the names of the two field1 and field2 that will be used as axes for the histogram.

tracefs_hist_free_2d frees the memory associated with a histogram entry allocated by tracefs_hist_alloc_2d.

tracefs_hist_lookup_2d searches for an existing 2D histogram by its name.

tracefs_hist_add_2d increments the count for a specific bin in the 2D histogram defined by entry, using the values val1 and val2 from the traced event.

tracefs_hist_del_2d decrements the count for a specific bin in the 2D histogram. This is useful for scenarios where events might be removed or rescinded.

tracefs_hist_dump_2d retrieves the current counts for all bins in the specified 2D histogram. The results are typically printed to the tracefs file system under the histogram's entry.

KEY TYPES

struct tracefs_hist_entry: Represents a histogram entry, containing information about the histogram and its bins.

RETURN VALUE

tracefs_hist_alloc_2d, tracefs_hist_lookup_2d return a pointer to a struct tracefs_hist_entry on success, or NULL on failure.

tracefs_hist_add_2d, tracefs_hist_del_2d, tracefs_hist_dump_2d return 0 on success and a negative value on failure.

tracefs_hist_free_2d returns void.

EXAMPLE

The following example demonstrates how to create a 2D histogram for the `sched_switch` event, using the `prev_pid` and `next_pid` fields, and then dump its contents.

#include <stdio.h>
#include <stdlib.h>
#include <tracefs.h>

int main() {
    struct tracefs_hist_entry *hist_entry;

    // Allocate a 2D histogram for sched_switch event (prev_pid vs next_pid)
    hist_entry = tracefs_hist_alloc_2d("sched_pid_histogram",
                                       "sched_switch",
                                       "prev_pid", "next_pid");
    if (!hist_entry) {
        fprintf(stderr, "Failed to allocate 2D histogram\n");
        return 1;
    }

    printf("Successfully allocated histogram: %s\n", hist_entry->name);

    // In a real scenario, you would enable tracing and let events occur.
    // For demonstration, we'll skip adding/deleting specific entries
    // and proceed to dump (which might be empty if no events occurred).

    // Dump the histogram contents (will likely be empty in this example)
    if (tracefs_hist_dump_2d(hist_entry) < 0) {
        fprintf(stderr, "Failed to dump 2D histogram\n");
        tracefs_hist_free_2d(hist_entry);
        return 1;
    }

    printf("Histogram dump initiated. Check tracefs for results.\n");

    // Free the histogram entry
    tracefs_hist_free_2d(hist_entry);

    return 0;
}
