tracefs_synth_echo_cmd(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_synth_echo_cmd, tracefs_synth_get_start_hist, tracefs_synth_get_name, tracefs_synth_raw_fmt, tracefs_synth_show_event, tracefs_synth_show_start_hist, tracefs_synth_show_end_hist, tracefs_synth_get_event - Récupérer les données des événements synthétiques.

SYNOPIS

#include <tracefs.h>
int tracefs_synth_echo_cmd(struct trace_seq *seq, struct tracefs_synth *synth);
struct tracefs_hist *tracefs_synth_get_start_hist(struct tracefs_synth *synth);
const char *tracefs_synth_get_name(struct tracefs_synth *synth);
int tracefs_synth_raw_fmt(struct trace_seq *seq, struct tracefs_synth *synth);
const char *tracefs_synth_show_event(struct tracefs_synth *synth);
const char *tracefs_synth_show_start_hist(struct tracefs_synth *synth);
const char *tracefs_synth_show_end_hist(struct tracefs_synth *synth);
struct tep_event *tracefs_synth_get_event(struct tep_handle *tep, struct tracefs_synth *synth);

DESCRIPTION

Les événements synthétiques sont des événements dynamiques créés en faisant correspondre deux autres événements qui déclenchent un événement synthétique. Un événement est l'événement de départ dont un champ est enregistré, et lorsque le second événement est exécuté, s'il a un champ (ou des champs) qui correspond au(x) champ(s) de l'événement de départ, il déclenchera l'événement synthétique. Les valeurs des champs autres que les champs correspondants peuvent être transmises de l'événement de départ à l'événement de fin pour effectuer des calculs, ou simplement transmises en paramètre à l'événement synthétique.

Un cas d'utilisation courant consiste à définir "sched_waking" comme événement de départ. Cet événement est déclenché lorsqu'un processus est réveillé. Ensuite, définir "sched_switch" comme événement de fin. Cet événement est déclenché lorsqu'une nouvelle tâche est planifiée sur le CPU. En définissant le "common_pid" des deux événements comme champs correspondants, le temps entre les deux événements est considéré comme la latence de réveil de ce processus. Utilisez TRACEFS_TIMESTAMP comme champ pour les deux événements afin de calculer la différence en nanosecondes, ou utilisez TRACEFS_TIMESTAMP_USECS comme champs de comparaison pour les deux événements afin de calculer la différence en microsecondes. Ceci est utilisé comme exemple ci-dessous.

Voir tracefs_synth_alloc(3) pour l'allocation des événements synthétiques, et tracefs_synth_create() pour la création de l'événement synthétique sur le système.

tracefs_synth_echo_cmd() agit comme tracefs_synth_create(), mais au lieu de créer l'événement synthétique dans le système, il écrira les commandes echo pour le créer manuellement dans le seq donné.

tracefs_synth_get_start_hist() renvoie un descripteur struct tracefs_hist décrivant l'histogramme utilisé pour créer l'événement synthétique.

enum tracefs_synth_handler {
        TRACEFS_SYNTH_HANDLE_MATCH,
        TRACEFS_SYNTH_HANDLE_MAX,
        TRACEFS_SYNTH_HANDLE_CHANGE,
};

tracefs_synth_get_name() renvoie le nom de l'événement synthétique ou NULL en cas d'erreur. La chaîne renvoyée appartient à l'objet synth événement et est libérée avec l'événement par tracefs_synth_free().

tracefs_synth_raw_fmt() écrit les chaînes de format brutes (événement dynamique et histogrammes) de l'événement synthétique dans le seq donné.

tracefs_synth_show_event() renvoie le format de l'événement dynamique utilisé par l'événement synthétique ou NULL en cas d'erreur. La chaîne renvoyée appartient à l'objet synth événement et est libérée avec l'événement par tracefs_synth_free().

tracefs_synth_show_start_hist() renvoie le format de l'histogramme de départ utilisé par l'événement synthétique ou NULL en cas d'erreur. La chaîne renvoyée appartient à l'objet synth événement et est libérée avec l'événement par tracefs_synth_free().

tracefs_synth_show_end_hist() renvoie le format de l'histogramme de fin utilisé par l'événement synthétique ou NULL en cas d'erreur. La chaîne renvoyée appartient à l'objet synth événement et est libérée avec l'événement par tracefs_synth_free().

La fonction tracefs_synth_get_event() renvoie un événement tep, décrivant l'événement synthétique donné. L'API détecte tous les événements dynamiques nouvellement créés ou supprimés. Le pointeur renvoyé vers l'événement tep est contrôlé par @tep et ne doit pas être libéré.

VALEUR DE RETOUR

tracefs_synth_get_name(), tracefs_synth_show_event(), tracefs_synth_show_start_hist() et tracefs_synth_show_end_hist() renvoient une chaîne appartenant à l'objet synth événement.

La fonction tracefs_synth_get_event() renvoie un pointeur vers un événement tep ou NULL en cas d'erreur ou si l'événement synthétique demandé est manquant. Le pointeur renvoyé vers l'événement tep est contrôlé par @tep et ne doit pas être libéré.

Toutes les autres fonctions renvoient zéro en cas de succès et -1 en cas d'erreur.

ERREURS

Les erreurs suivantes s'appliquent à tous les appels ci-dessus :

EPERM Pas exécuté en tant qu'utilisateur root lorsque requis.

EINVAL Soit un paramètre n'est pas valide (NULL alors qu'il ne devrait pas l'être) soit un champ incompatible pour les calculs.

ENODEV Un événement ou l'un de ses champs est introuvable.

EBADE Les champs des événements de début et de fin ne sont pas compatibles pour la correspondance ou la comparaison.

ENOMEM pas assez de mémoire disponible.

Et d'autres erreurs peuvent survenir lors des appels système au système.

EXEMPLE

Voir tracefs_sql(3) pour une utilisation plus approfondie de certains de ces codes.

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Charger tous les événements du système */
        tep = tracefs_local_events(NULL);
        /* Initialiser l'événement synthétique */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* Le tep n'est plus nécessaire */
        tep_free(tep);
        /* Sauvegarder le champ "prio" comme "prio" à partir de l'événement de départ */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Sauvegarder le champ "next_comm" comme "comm" à partir de l'événement de fin */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Sauvegarder le champ "prev_prio" comme "prev_prio" à partir de l'événement de fin */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Calculer la différence de temps en microsecondes entre la fin et le début
         * et l'enregistrer comme "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Enregistrer uniquement si le champ "prio" de l'événement de départ est inférieur à 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Enregistrer uniquement si le champ "next_prio" de l'événement de fin est inférieur à 50
         * ou si la priorité de la tâche précédente n'était pas supérieure ou égale à 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Notez que ce qui précède n'a ajouté que : "next_prio < 50 || !(prev_prio >= 100"
         * En effet, lorsque le synthé sera exécuté, la parenthèse fermante restante
         * sera ajoutée. C'est-à-dire que la chaîne sera finalement :
         * "next_prio < 50 || !(prev_prio >= 100)" lorsqu'une des commandes tracefs_sync_create()
         * ou tracefs_sync_echo_cmd() sera exécutée.
         */
}
/* Afficher comment */



NOM


tracefs_synth_echo_cmd — Écho d'une commande synthétique dans le tampon de traçage






SYNTAXIS


cc [flags] file.c -o prog -ltracefs


#include <tracefs.h>


void tracefs_synth_echo_cmd(struct trace_seq *s, const char *cmd)






DESCRIPTION


La fonction tracefs_synth_echo_cmd écrit la chaîne
    de commande spécifiée dans le tampon de traçage, géré par la structure
    trace_seq. Ceci est généralement utilisé pour générer des
    événements synthétiques qui peuvent être ensuite lus et interprétés par
    d'autres outils de traçage.


La fonction prend deux arguments :



  
s

  
Un pointeur vers une structure trace_seq initialisée,
      qui sert de tampon pour la sortie de traçage.

  
cmd

  
Un pointeur vers une chaîne de caractères terminée par un caractère nul
      contenant la commande à écrire dans le tampon de traçage.




Cette fonction est un outil de bas niveau pour interagir avec le
    système de traçage du noyau. Elle permet de créer des événements de traçage
    personnalisés qui peuvent ensuite être utilisés pour des scénarios de
    débogage ou d'analyse de performance.






VALEUR DE RETOUR


Aucune valeur de retour.






ERREURS


Cette fonction ne définit pas de variables d'erreur spécifiques. Les
    erreurs potentielles sont liées à l'allocation de mémoire ou aux opérations
    d'écriture sous-jacentes dans le système de traçage du noyau, qui peuvent
    échouer pour diverses raisons (par exemple, espace disque insuffisant,
    permissions insuffisantes).






EXEMPLE


Voici un exemple illustrant comment utiliser la fonction
    tracefs_synth_echo_cmd pour créer et afficher un
    événement synthétique.


#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <tracefs.h>

/* Variable globale représentant la commande synthétique */
const char *synth = "synth_event_example";

/* Fonction pour afficher l'événement synthétique */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        /* Utilise tracefs_synth_echo_cmd pour écrire la commande dans le tampon */
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}

int main (int argc, char **argv)
{
        /* Alloue la structure synthétique (exemple simplifié, devrait être plus complexe dans un cas réel) */
        struct tracefs_synth *synth_handle = tracefs_synth_alloc(synth);

        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Créer l'événement synthétique */
                        if (tracefs_synth_create(synth_handle) < 0) {
                                perror("tracefs_synth_create failed");
                                exit(-1);
                        }
                        printf("Synthetic event '%s' created.\n", synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Supprimer l'événement synthétique */
                        if (tracefs_synth_destroy(synth_handle) < 0) {
                                perror("tracefs_synth_destroy failed");
                                exit(-1);
                        }
                        printf("Synthetic event '%s' deleted.\n", synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else {
                /* Affiche l'événement synthétique si aucun argument n'est fourni */
                printf("Displaying synthetic event:\n");
                show_event();
        }

        /* Libère la structure synthétique */
        tracefs_synth_free(synth_handle);
        return 0;
}



Dans cet exemple :


    
  
  • La fonction show_event utilise
      tracefs_synth_echo_cmd pour écrire le nom de
      l'événement synthétique dans un tampon de traçage. Ensuite, elle affiche le
      contenu du tampon.
    • 
  
  • La fonction main gère les arguments de la ligne de
      commande pour créer ou supprimer l'événement synthétique à l'aide des
      fonctions tracefs_synth_create et
      tracefs_synth_destroy. Si aucun argument n'est donné,
      elle appelle show_event.
    • 
  
  • La fonction tracefs_synth_alloc est appelée pour
      allouer les ressources nécessaires à la gestion de l'événement synthétique.
      Notez qu'un cas d'utilisation réel impliquerait une configuration plus
      détaillée de l'événement synthétique (champs, types, etc.).
    •
