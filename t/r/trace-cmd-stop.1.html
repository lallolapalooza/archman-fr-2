NOM

trace-cmd-stop - arrêter le traqueur du noyau Ftrace de l'écriture dans le tampon circulaire.

SYNTAXE

trace-cmd stop [OPTIONS]

DESCRIPTION

trace-cmd(1) stop est un complément à trace-cmd-start(1). Ceci désactivera Ftrace de l'écriture dans le tampon circulaire. Cela n'arrête pas la surcharge que le traçage peut engendrer. Seule la mise à jour du tampon circulaire est désactivée, le traçage Ftrace peut encore induire une surcharge.

Après avoir arrêté le traçage, trace-cmd-extract(1) peut extraire les données du tampon circulaire et créer un fichier trace.dat. Le système de fichiers pseudo Ftrace peut également être examiné.

Pour désactiver complètement le traçage afin de supprimer la surcharge qu'il cause, utilisez trace-cmd-reset(1). Mais après un réinitialisation, les données qui ont été enregistrées sont perdues.

OPTIONS

-B nom-tampon

Si le noyau supporte plusieurs tampons, cela arrêtera le traçage uniquement pour le tampon donné. Cela n'affecte aucun autre tampon. Cette option peut être utilisée plusieurs fois pour spécifier différents tampons. Lorsque cette option est utilisée, l'instance de niveau supérieur ne sera pas arrêtée à moins que -t ne soit spécifié.

-a

Arrête le traçage pour toutes les instances de tampon existantes. Lorsque cette option est utilisée, l'instance de niveau supérieur ne sera pas arrêtée à moins que -t ne soit spécifié.

-t

Arrête le tampon de l'instance de niveau supérieur. Sans l'option -B ou -a, c'est la même chose que par défaut. Mais si -B ou -a est utilisé, cela est requis si le tampon de l'instance de niveau supérieur doit également être arrêté.
