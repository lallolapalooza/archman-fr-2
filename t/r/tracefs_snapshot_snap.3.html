NOM

tracefs_snapshot_snap, tracefs_snapshot_clear, tracefs_snapshot_free - API pour créer, effacer et lire des snapshots

SYNOPSIS

#include <tracefs.h>
int tracefs_snapshot_snap(struct tracefs_instance *instance);
int tracefs_snapshot_clear(struct tracefs_instance *instance);
int tracefs_snapshot_free(struct tracefs_instance *instance);

DESCRIPTION

Le traçage du noyau Linux fournit une fonctionnalité de "snapshot" (instantané). Le noyau dispose de deux tampons circulaires. L'un est écrit par le système de traçage et l'autre est le tampon "snapshot". Lorsqu'un snapshot a lieu, les deux tampons sont échangés, et le tampon snapshot actuel devient celui sur lequel on écrit, et le tampon qui était écrit devient le snapshot sauvegardé.

Notez que le tampon snapshot est alloué la première fois qu'il est pris, il est donc préférable de prendre un snapshot au début avant qu'il ne soit nécessaire afin qu'il soit alloué et qu'un snapshot soit prêt. Le snapshot aura alors lieu immédiatement.

La fonction tracefs_snapshot_snap() allouera (si elle n'est pas déjà allouée) le tampon snapshot, puis prendra un "snapshot" (échangera le tampon principal sur lequel on écrit avec le tampon snapshot alloué). Elle le fera pour le tampon instance donné ou pour l'instance supérieure si instance est NULL.

La fonction tracefs_snapshot_clear() effacera le contenu du tampon snapshot pour l'instance instance donnée ou pour l'instance de niveau supérieur si instance est NULL.

La fonction tracefs_snapshot_free() libérera le snapshot alloué pour l'instance instance donnée ou pour l'instance de niveau supérieur si instance est NULL. C'est-à-dire que si un autre appel à tracefs_snapshot_snap() est effectué après celui-ci, il faudra réallouer le tampon snapshot avant de pouvoir en prendre un. Cette fonction doit être utilisée pour libérer la mémoire du noyau utilisée par le tampon snapshot lorsqu'il n'est plus nécessaire.

VALEUR DE RETOUR

Les fonctions tracefs_snapshot_snap(), tracefs_snapshot_clear() et tracefs_snapshot_free() retournent toutes 0 en cas de succès et -1 en cas d'échec.

EXEMPLE

#include <stdlib.h>
#include <stdio.h>
#include <tracefs.h>
static int callback(struct tep_event *event, struct tep_record *record, int cpu, void *data)
{
        static struct trace_seq seq;
        struct tep_handle *tep = event->tep;
        if (!seq.buffer)
                trace_seq_init(&seq);
        trace_seq_reset(&seq);
        tep_print_event(tep, &seq, record, "[%03d] %s-%d %6.1000d\t%s: %s\n",
                                TEP_PRINT_CPU,
                                TEP_PRINT_COMM,
                                TEP_PRINT_PID,
                                TEP_PRINT_TIME,
                                TEP_PRINT_NAME,
                                TEP_PRINT_INFO);
        trace_seq_do_printf(&seq);
        return 0;
}
int main (int argc, char **argv)
{
        struct tracefs_instance *instance;
        struct tep_handle *tep;
        char *line = NULL;
        size_t len = 0;
        int ret;
        instance = tracefs_instance_create("my_snapshots");
        if (!instance) {
                perror("création de l'instance");
                exit(-1);
        }
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("lecture des formats d'événement");
                goto out;
        }
        /* Assurez-vous que le tampon snapshot est alloué */
        ret = tracefs_snapshot_snap(instance);
        if (ret < 0)
                goto out;
        ret = tracefs_event_enable(instance, "sched", NULL);
        if (ret < 0) {
                perror("activation de l'événement");
                goto out;
        }
        for (;;) {
                printf("Appuyez sur Entrée sans texte pour prendre un snapshot !\n");
                printf("Entrez n'importe quel texte pour afficher le snapshot\n");
                printf("Entrez 'quit' pour quitter\n");
                getline(&line, &len, stdin);
                ret = tracefs_snapshot_snap(instance);
                if (ret < 0) {
                        perror("prise de snapshot");
                        goto out;
                }
                if (!line)
                        break;
                if (strlen(line) < 2)
                        continue;
                if (strncmp(line, "quit", 4) == 0)
                        break;
                tracefs_iterate_snapshot_events(tep, instance, NULL, 0, callback, NULL);
        }
        free(line);
        tracefs_instance_clear(instance);
 out:
        tracefs_snapshot_free(instance);
        tracefs_event_disable(instance, "sched", NULL);
        tracefs_instance_destroy(instance);
        tracefs_instance_free(instance);
        exit(0);
}

tracefs_snapshot_snap.3.en

NOM

tracefs_snapshot_snap — Interroger et manipuler des instantanés de traces du noyau.

SYNOPIS

tracefs_snapshot_snap [options] [commande] [arguments...]

DESCRIPTION

La commande tracefs_snapshot_snap est un outil pour interroger et manipuler des instantanés de traces du noyau à l'aide du système de fichiers tracefs. Elle permet aux utilisateurs de créer, afficher, supprimer et gérer des instantanés des données de traçage du noyau.

OPTIONS

-c, --create
Crée un nouvel instantané avec le nom spécifié.
-l, --list
Liste tous les instantanés existants.
-s, --show
Affiche le contenu d'un instantané spécifié.
-d, --delete
Supprime un instantané spécifié.
-f, --force
Force la suppression d'un instantané, même s'il est utilisé.
-h, --help
Affiche l'aide et quitte.
-v, --version
Affiche les informations de version et quitte.

ÉTATS DE SORTIE

0
Succès.
1
Erreur lors de l'exécution de la commande.
2
Argument invalide.

EXEMPLES

Créer un instantané nommé "initial_trace" :

tracefs_snapshot_snap -c initial_trace

Lister tous les instantanés existants :

tracefs_snapshot_snap -l

Afficher le contenu de l'instantané "initial_trace" :

tracefs_snapshot_snap -s initial_trace

Supprimer l'instantané "old_trace" :

tracefs_snapshot_snap -d old_trace
