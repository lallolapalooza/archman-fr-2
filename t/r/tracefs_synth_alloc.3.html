DESCRIPTION

Les événements synthétiques sont des événements dynamiques créés en faisant correspondre deux autres événements qui déclenchent un événement synthétique. Un événement est l'événement de départ dont un champ est enregistré, et lorsque le second événement est exécuté, s'il possède un champ (ou des champs) qui correspond au champ (ou aux champs) de l'événement de départ, il déclenche l'événement synthétique. Les valeurs des champs autres que les champs correspondants peuvent être transmises de l'événement de départ à l'événement de fin pour effectuer des calculs, ou simplement être passées comme paramètre à l'événement synthétique.

Un cas d'utilisation courant consiste à définir "sched_waking" comme événement de départ. Cet événement est déclenché lorsqu'un processus est réveillé. Ensuite, définir "sched_switch" comme événement de fin. Cet événement est déclenché lorsqu'une nouvelle tâche est planifiée sur le CPU. En définissant le "common_pid" des deux événements comme champs correspondants, le temps écoulé entre les deux événements est considéré comme la latence de réveil de ce processus. Utilisez TRACEFS_TIMESTAMP comme champ pour les deux événements afin de calculer la différence en nanosecondes, ou utilisez *TRACEFS_TIMESTAMP_USECS" comme champs de comparaison pour les deux événements afin de calculer la différence en microsecondes. Ceci est utilisé comme exemple ci-dessous.

tracefs_synth_alloc() alloue et initialise un événement synthétique. Il ne crée pas l'événement synthétique, mais fournit les informations minimales pour le faire. Voir tracefs_synth_create(3) pour savoir comment créer l'événement synthétique dans le système. Il nécessite un gestionnaire tep qui peut être créé par tracefs_local_events(3) pour plus d'informations. Le name contient le nom de l'événement synthétique qui sera créé. Le start_system est le nom du système pour l'événement de départ. Il peut être NULL et le premier événement portant le nom de start_event sera choisi. Le end_system est le nom du système pour l'événement de fin. Il peut être NULL et le premier événement portant le nom de end_event sera choisi comme événement de fin. Si match_name est fourni, alors ce sera le champ de l'événement synthétique créé qui contiendra les clés correspondantes du start_match_field de l'événement de départ et du end_match_field de l'événement de fin. Si match_name est NULL, alors il ne sera pas enregistré dans l'événement synthétique créé.

tracefs_synth_add_match_field() ajoutera une deuxième clé à faire correspondre entre l'événement de départ et l'événement de fin. Si name est fourni, alors le contenu du champ correspondant sera sauvegardé sous ce name dans l'événement synthétique. Le start_match_field est le champ de l'événement de départ à faire correspondre avec le end_match_field de l'événement de fin.

tracefs_synth_add_compare_field() est utilisé pour comparer le start_compare_field de l'événement de départ avec le end_compare_field de l'événement de fin. Le name doit être fourni afin que le résultat soit sauvegardé par l'événement synthétique. Il n'a aucun sens de ne pas passer cela à l'événement synthétique après avoir effectué le travail des champs comparés, car cela ne sert à aucune autre fin. Le paramètre calc peut être l'un des suivants :

TRACEFS_SYNTH_DELTA_END - calculer la différence entre le contenu du end_compare_field et le contenu du start_compare_field.

name = end_compare_field - start_compare_field

TRACEFS_SYNTH_DELTA_START - calculer la différence entre le contenu du start_compare_field et le contenu du end_compare_field.

name = start_compare_field - end_compare_field

TRACEFS_SYNTH_ADD - Ajouter le contenu du start_compare_field au contenu du end_compare_field.

name = start_compare_field + end_compare_field

tracefs_synth_add_start_field() - Enregistre le start_field de l'événement de départ sous le nom name dans l'événement synthétique. Si name est NULL, alors le nom utilisé sera le même que start_field.

tracefs_synth_add_end_field() - Enregistre le end_field de l'événement de fin sous le nom name dans l'événement synthétique. Si name est NULL, alors le nom utilisé sera le même que end_field.

tracefs_synth_append_start_filter() crée un filtre ou y ajoute un élément pour l'événement de départ. Selon le type, il construira une chaîne de jetons pour les parenthèses ou les instructions logiques, ou il ajoutera une comparaison du field à val basée sur compare.

Si type est : TRACEFS_FILTER_COMPARE - Voir ci-dessous TRACEFS_FILTER_AND - Ajoute "&&" au filtre TRACEFS_FILTER_OR - Ajoute "||" au filtre TRACEFS_FILTER_NOT - Ajoute "!" au filtre TRACEFS_FILTER_OPEN_PAREN - Ajoute "(" au filtre TRACEFS_FILTER_CLOSE_PAREN - Ajoute ")" au filtre

field, compare et val sont ignorés sauf si type est égal à TRACEFS_FILTER_COMPARE, alors _compare sera utilisé pour les éléments suivants :

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ "val" : où field est une chaîne de caractères.

TRACEFS_COMPARE_AND - field & val : où field est un champ de drapeaux.

tracefs_synth_append_end_filter() est identique à tracefs_synth_append_start_filter mais filtre sur l'événement de fin.

tracefs_synth_free() libère le descripteur alloué renvoyé par tracefs_synth_alloc().

DESCRIPTION

A synthetic event is an event that is created by combining multiple existing trace events. The goal is to build up complex trace analysis that might be impossible to do with simple trace filters. For example, you can create a synthetic event that traces the latency between a task waking up and when it gets scheduled. This event would be composed of the sched_waking event and the sched_switch event.

The tracefs library provides a set of APIs to create and manage these synthetic events.

tracefs_synth_alloc() allocates and initializes a new synthetic event. The event will be composed of a start event and an end event. The library tries to match the start and end events based on common fields like PID. The synth_name is the name of the new synthetic event. The start_name and end_name are aliases for the start and end events. The trace_start_event and trace_end_event are the names of the actual trace events to be used. The start_field and end_field are used to link the start and end events. The match_name specifies a field that must be the same in both the start and end events for them to be considered a match.

tracefs_synth_add_start_field() and tracefs_synth_add_end_field() are used to add fields from the start and end events, respectively, to the synthetic event. The alias parameter can be used to rename the field in the synthetic event.

tracefs_synth_add_compare_field() adds a field to the synthetic event that is derived from comparing fields in the start and end events. The type parameter specifies the type of comparison, e.g., time difference.

tracefs_synth_append_start_filter() and tracefs_synth_append_end_filter() are used to add filters to the synthetic event. These filters are applied to the start and end events, respectively, before they are matched. The type parameter specifies the filter type (e.g., comparison, logical operators). The op parameter specifies the comparison operator, and value is the value to compare against.

tracefs_synth_create() creates the synthetic event on the tracefs system.

tracefs_synth_destroy() destroys a previously created synthetic event.

tracefs_synth_save() saves the synthetic event definition to a file.

tracefs_synth_trace() and tracefs_synth_snapshot() are used to retrieve trace data related to the synthetic event. tracefs_synth_trace() retrieves live trace data, while tracefs_synth_snapshot() retrieves data from a snapshot.

tracefs_synth_get_start_hist() and tracefs_synth_get_end_hist() return histogram data related to the start and end events of the synthetic event.

tracefs_synth_get_event() returns the underlying `struct tep_event` for either the start (type=0) or end (type=1) event.

tracefs_synth_get_name() returns the name of the synthetic event.

tracefs_synth_raw_fmt() allows printing raw formatted data for the synthetic event.

tracefs_synth_show_event(), tracefs_synth_show_start_hist(), tracefs_synth_show_end_hist() print the definition of the synthetic event and its associated histograms.

tracefs_synth_echo_cmd() prints the command line that would be used to create the synthetic event.

tracefs_synth_free() frees the memory associated with a synthetic event structure.

RETURN VALUE

tracefs_synth_alloc() returns an allocated struct tracefs_synth descriptor on success or NULL on error.

All other functions that return an integer returns zero on success or -1 on error.

ERREURS

The following errors are for all the above calls:

EPERM Not run as root user when required.

EINVAL Either a parameter is not valid (NULL when it should not be) or a field that is not compatible for calculations.

ENODEV An event or one of its fields is not found.

EBADE The fields of the start and end events are not compatible for either matching or comparing.

ENOMEM Not enough memory is available.

And more errors may have happened from the system calls to the system.

EXEMPLE

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Load all events from the system */
        tep = tracefs_local_events(NULL);
        /* Initialize the synthetic event */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* The tep is no longer needed */
        tep_free(tep);
        /* Save the "prio" field as "prio" from the start event */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Save the "next_comm" as "comm" from the end event */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Save the "prev_prio" as "prev_prio" from the end event */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Take a microsecond time difference between end and start
         * and record as "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Only record if start event "prio" is less than 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Only record if end event "next_prio" is less than 50
         * or the previous task's prio was not greater than or equal to 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Note, the above only added: "next_prio < 50 || !(prev_prio >= 100"
         * That's because, when the synth is executed, the remaining close parenthesis
         * will be added. That is, the string will end up being:
         * "next_prio < 50 || !(prev_prio >= 100)" when one of tracefs_sync_create()
         * or tracefs_sync_echo_cmd() is run.
         */
}
/* Display how to create the synthetic event */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Create the synthetic event */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Delete the synthetic event */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}

NOM

tracefs_synth_alloc - Allouer un événement synthétique pour le traçage

SYNOPSIS

#include <tracefs.h>

int tracefs_synth_alloc(const char *name, const char *group,
                        const char *event_fields, const char *event_type);

DESCRIPTION

La fonction tracefs_synth_alloc permet d'allouer un événement synthétique pour le traçage à l'aide du système de fichiers tracefs.

  • name : Le nom de l'événement synthétique.
  • group : Le groupe auquel appartient l'événement.
  • event_fields : Une chaîne décrivant les champs de l'événement.
  • event_type : Le type de l'événement (par exemple, "tracepoint").

Cette fonction écrit dans le fichier approprié sous /sys/kernel/tracing/ pour créer un nouvel événement synthétique.

VALEUR RENVOYÉE

Renvoie 0 en cas de succès, et un nombre négatif en cas d'erreur.

EXEMPLES

Un exemple typique d'utilisation :

#include <tracefs.h>
#include <stdio.h>

int main() {
    const char *event_name = "my_synth_event";
    const char *event_group = "my_group";
    const char *fields = "field1:STRING,field2:u64";
    const char *type = "tracepoint";

    if (tracefs_synth_alloc(event_name, event_group, fields, type) < 0) {
        perror("Erreur lors de l'allocation de l'événement synthétique");
        return 1;
    }

    printf("Événement synthétique '%s' alloué avec succès.\n", event_name);

    // Ici, vous pourriez vouloir ajouter la logique pour libérer l'événement
    // lorsque vous n'en avez plus besoin, en utilisant une fonction comme tracefs_synth_free.

    return 0;
}
