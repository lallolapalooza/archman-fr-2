tracefs_tracing_dir_is_mounted(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_get_tracing_file, tracefs_put_tracing_file, tracefs_tracing_dir, tracefs_debug_dir, tracefs_set_tracing_dir, tracefs_tracing_dir_is_mounted - Trouver et définir les emplacements du répertoire et des fichiers de traçage.

SYNTAXE

#include <tracefs.h>
char *tracefs_get_tracing_file(const char *name);
void tracefs_put_tracing_file(char *name);
const char *tracefs_tracing_dir(void);
const char *tracefs_debug_dir(void);
int tracefs_set_tracing_dir(char *tracing_dir)
int tracefs_tracing_dir_is_mounted(bool mount, const char **path);

DESCRIPTION

Cet ensemble d'API peut être utilisé pour trouver le chemin complet du point de montage du système de fichiers de traçage et les fichiers de traçage qu'il contient.

La fonction tracefs_set_tracing_dir() définit un emplacement personnalisé pour le point de montage du répertoire de traçage du système. Habituellement, la bibliothèque le détecte automatiquement en utilisant les informations du fichier /proc/mounts. Utilisez cette API uniquement si le point de montage n'est pas standard et ne peut pas être détecté par la bibliothèque. L'argument tracing_dir peut être NULL, auquel cas l'emplacement personnalisé est supprimé et la logique de détection automatique de la bibliothèque est utilisée.

La fonction tracefs_get_tracing_file() renvoie le chemin complet du fichier avec le nom name donné dans le système de fichiers de traçage. La fonction ne fonctionne qu'avec les fichiers du répertoire principal de tracefs, elle n'est pas consciente des instances de traçage. Il est recommandé d'utiliser plutôt tracefs_instance_get_file() et tracefs_instance_get_dir(). La chaîne renvoyée doit être libérée avec tracefs_put_tracing_file().

La fonction tracefs_put_tracing_file() libère le nom du fichier de traçage, renvoyé par tracefs_get_tracing_file().

La fonction tracefs_tracing_dir() renvoie le chemin complet vers le système de fichiers de traçage. Lors du premier appel de la fonction, le point de montage du système de fichiers de traçage est localisé, mis en cache et renvoyé. Il le montera s'il n'est pas monté. Lors de tout appel subséquent, le chemin mis en cache est renvoyé. La chaîne renvoyée ne doit pas être libérée.

La fonction tracefs_debug_dir() est similaire à tracefs_tracing_dir(), à la différence qu'elle renvoie où le système de fichiers debugfs est monté. S'il n'est pas monté, elle tentera de le monter. La chaîne renvoyée ne doit pas être libérée.

tracefs_tracing_dir_is_mounted() renvoie 1 si le répertoire de traçage est déjà monté et 0 s'il ne l'est pas. Si mount est vrai, elle tentera de le monter s'il ne l'est pas, et renvoie 0 s'il a été monté avec succès et -1 s'il n'a pas réussi. Si path est défini, il sera assigné au chemin où il a été monté. path est interne et ne doit pas être libéré.

VALEUR RENVOYÉE

La fonction tracefs_set_tracing_dir() renvoie 0 en cas de succès, -1 sinon.

La fonction tracefs_get_tracing_file() renvoie une chaîne ou NULL en cas d'erreur. La chaîne renvoyée doit être libérée avec tracefs_put_tracing_file().

La fonction tracefs_tracing_dir() renvoie une chaîne constante ou NULL en cas d'erreur. La chaîne renvoyée ne doit pas être libérée.

La fonction tracefs_debug_dir() renvoie une chaîne constante ou NULL en cas d'erreur. La chaîne renvoyée ne doit pas être libérée.

tracefs_tracing_dir_is_mounted() renvoie 1 si le répertoire de traçage est déjà monté, 0 s'il ne l'est pas, et -1 en cas d'erreur.

EXEMPLE

#include <tracefs.h>
...
char *trace_on = tracefs_get_tracing_file("tracing_on");
        if (trace_on) {
                ...
                tracefs_put_tracing_file(trace_on);
        }
...
const char *trace_dir = tracefs_tracing_dir();
