tracefs_print_close(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_print_init, tracefs_print_close, tracefs_printf, tracefs_vprintf - Ouvrir, fermer et écrire des chaînes formatées dans le tampon de trace.

SYNOPHIS

#include <tracefs.h>
int tracefs_print_init(struct tracefs_instance *instance);
int tracefs_printf(struct tracefs_instance *instance, const char *fmt, ...);
int tracefs_vprintf(struct tracefs_instance *instance, const char *fmt, va_list ap);
void tracefs_print_close(struct tracefs_instance *instance);

DESCRIPTION

Ensemble de fonctions pour écrire des chaînes formatées dans le tampon de trace. Voir Documentation/trace/ftrace.rst dans l'arborescence du noyau Linux pour plus d'informations sur l'écriture de données depuis l'espace utilisateur dans le tampon de trace. Toutes ces API ont instance comme premier argument. Si NULL est passé comme instance, l'instance de trace principale est utilisée.

La fonction tracefs_print_init() initialise la bibliothèque pour écrire dans le tampon de trace de l'instance sélectionnée. Il n'est pas obligatoire d'appeler cette API avant d'écrire des chaînes, toute les API printf l'appelleront automatiquement si la bibliothèque n'est pas encore initialisée. Mais appeler tracefs_print_init() à l'avance accélérera l'écriture.

La fonction tracefs_printf() écrit une chaîne formatée dans le tampon de trace de l'instance sélectionnée. L'argument fmt est une chaîne au format printf, suivie d'arguments variables ....

La fonction tracefs_vprintf() écrit une chaîne formatée dans le tampon de trace de l'instance sélectionnée. L'argument fmt est une chaîne au format printf, suivie d'une liste d'arguments ap.

La fonction tracefs_print_close() ferme les ressources utilisées par la bibliothèque pour écrire dans le tampon de trace de l'instance sélectionnée.

VALEUR DE RETOUR

Les fonctions tracefs_print_init(), tracefs_printf() et tracefs_vprintf() retournent 0 si l'opération réussit, et -1 en cas d'erreur.

EXEMPLE

#include <tracefs.h>
if (tracefs_print_init(NULL) < 0) {
 /* Échec de l'initialisation de la bibliothèque pour écrire dans le tampon de trace de l'instance de trace principale */
}
void foo_print(char *format, ...)
{
        va_list ap;
        va_start(ap, format);
        if (tracefs_vprintf(NULL, format, ap) < 0) {
                /* Échec de l'impression dans le tampon de trace */
        }
        va_end(ap);
}
void foo_print_string(char *message)
{
        if (tracefs_printf(NULL, "Message de l'espace utilisateur : %s", message) < 0) {
                /* Échec de l'impression dans le tampon de trace */
        }
}
tracefs_print_close();
