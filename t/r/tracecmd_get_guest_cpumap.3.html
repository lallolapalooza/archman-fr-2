tracecmd_get_guest_cpumap(3)

Paquet: trace-cmd

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACECMD(3) Manuel de libtracefs LIBTRACECMD(3)

NOM

tracecmd_get_traceid, tracecmd_get_guest_cpumap - Gérer une session de traçage avec plusieurs homologues de traçage, enregistrés dans plusieurs fichiers de traçage.

SYNTAXE

#include <trace-cmd.h>
unsigned long long tracecmd_get_traceid(struct tracecmd_input *handle);
int tracecmd_get_guest_cpumap(struct tracecmd_input *handle, unsigned long long trace_id, const char **name, int *vcpu_count, const int **cpu_pid);

DESCRIPTION

Cet ensemble d'API peut être utilisé pour gérer une session de traçage avec plusieurs homologues de traçage, par exemple, le traçage d'un hôte et d'une ou plusieurs machines virtuelles invitées. Les données de traçage de chaque homologue de la session sont enregistrées dans des fichiers de traçage distincts. Les informations sur les homologues de la session sont stockées dans les métadonnées de chaque fichier de traçage. Ces API utilisent ces informations pour extraire et synchroniser les données de traçage.

La fonction tracecmd_get_traceid() renvoie l'ID de traçage stocké dans les métadonnées du fichier de traçage associées à handle. Chaque homologue d'une session de traçage possède un ID unique pour cet homologue et cette session de traçage uniquement. Cet ID est utilisé pour faire correspondre plusieurs fichiers de traçage enregistrés dans la même session de traçage.

La fonction tracecmd_get_guest_cpumap() obtient la mise en correspondance des processeurs virtuels (VCPU) invités avec le processus hôte qui représente ces VCPU, et qui est stockée dans les métadonnées du fichier de traçage associé à handle. Ces informations sont collectées lors d'une session de traçage hôte-invité et sont stockées dans le fichier de traçage de l'hôte. Le paramètre trace_id est l'ID de traçage de l'invité dans cette session de traçage particulière. Si un invité avec cet ID faisait partie de cette session, sa mise en correspondance VCPU avec le processus hôte se trouve dans le fichier de traçage de l'hôte et les informations sont renvoyées dans les paramètres name, vcpu_count et cpu_pid. Le paramètre name contient le nom de l'invité, vcpu_count contient le nombre de VCPU de cet invité et le tableau cpu_pid contient la mise en correspondance VCPU avec le processus hôte. Le tableau est de taille vcpu_count où l'indice est le VCPU et la valeur est l'ID du processus (PID) du processus hôte exécutant ce VCPU. Les valeurs de name, vcpu_count et cpu_pid ne doivent pas être libérées.

VALEUR RENVOYÉE

La fonction tracecmd_get_traceid() renvoie un ID de traçage de 64 bits.

La fonction tracecmd_get_guest_cpumap() renvoie -1 en cas d'erreur ou 0 sinon. Si 0 est renvoyé, alors les paramètres name, vcpu_count et cpu_pid contiennent les informations demandées.

EXEMPLE

#include <trace-cmd.h>
...
struct tracecmd_input *host = tracecmd_open("trace.dat");
        if (!host) {
                /* Échec de l'ouverture du fichier de traçage hôte */
        }
struct tracecmd_input *guest1 = tracecmd_open_head("trace-Guest1.dat");
        if (!guest1) {
                /* Échec de l'ouverture du fichier de traçage guest1 */
        }
struct tracecmd_input *guest2 = tracecmd_open_head("trace-Guest2.dat");
        if (!guest2) {
                /* Échec de l'ouverture du fichier de traçage guest2 */
        }
unsigned long long guest_id_1 = tracecmd_get_traceid(guest1);
unsigned long long guest_id_2 = tracecmd_get_traceid(guest2);
int *cpu_pid_1, *cpu_pid_2;
int vcount_1, vcount_2;
char *name_1, *name_2;
        if (!tracecmd_get_guest_cpumap(host, guest_id_1, &name_1, &vcount_1, &cpu_pid_1)) {
                /* L'hôte et un invité guest1 avec name_1 font partie de la même session de traçage.
                 * Obtention de la mise en correspondance VCPU de guest1 avec le PID hôte.
                 */
        }
        if (!tracecmd_get_guest_cpumap(host, guest_id_2, &name_2, &vcount_2, &cpu_pid_2)) {
                /* L'hôte et un invité guest2 avec name_2 font partie de la même session de traçage.
                 * Obtention de la mise en correspondance VCPU de guest2 avec le PID hôte.
                 */
        }
...
        tracecmd_close(guest1);
        tracecmd_close(guest2);
        tracecmd_close(handle);
