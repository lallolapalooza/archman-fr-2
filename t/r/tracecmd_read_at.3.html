tracecmd_read_at(3)

Paquet: trace-cmd

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACECMD(3) Manuel libtracefs LIBTRACECMD(3)

NOM

tracecmd_read_cpu_first, tracecmd_read_data, tracecmd_read_at, tracecmd_free_record, tracecmd_get_tep - Lire les événements enregistrés à partir d'un fichier trace.

SYNTAXE

#include <trace-cmd.h>
struct tep_record *tracecmd_read_cpu_first(struct tracecmd_input *handle, int cpu);
struct tep_record *tracecmd_read_data(struct tracecmd_input *handle, int cpu);
struct tep_record *tracecmd_read_at(struct tracecmd_input *handle, unsigned long long offset, int *cpu);
void tracecmd_free_record(struct tep_record *record);
struct tep_handle *tracecmd_get_tep(struct tracecmd_input *handle);

DESCRIPTION

Cet ensemble d'API peut être utilisé pour lire les données de traçage à partir d'un fichier trace ouvert avec tracecmd_open()(3), tracecmd_open_fd()(3) ou tracecmd_open_head()(3).

La fonction tracecmd_read_cpu_first() lit le premier enregistrement de trace pour un cpu donné à partir d'un fichier trace associé à handle. L'enregistrement retourné doit être libéré avec tracecmd_free_record().

La fonction tracecmd_read_data() lit le prochain enregistrement de trace pour un cpu donné à partir d'un fichier trace associé à handle et incrémente le pointeur de position de lecture, de sorte que le prochain appel à tracecmd_read_data() ne lise pas le même enregistrement à nouveau. L'enregistrement retourné doit être libéré avec tracecmd_free_record().

La fonction tracecmd_read_at() lit un enregistrement de trace à partir d'un offset spécifique dans le fichier associé à handle. Le CPU sur lequel l'événement enregistré s'est produit est stocké dans cpu. La fonction ne modifie pas le pointeur de position de lecture actuel. L'enregistrement retourné doit être libéré avec tracecmd_free_record().

La fonction tracecmd_free_record() libère un record retourné par l'une des API tracecmd_read_.

La fonction tracecmd_get_tep() retourne un contexte tep pour un handle donné.

VALEUR DE RETOUR

Les fonctions tracecmd_read_cpu_first(), tracecmd_read_data() et tracecmd_read_at() retournent un pointeur vers struct tep_record ou NULL en cas d'erreur. L'enregistrement retourné doit être libéré avec tracecmd_free_record().

La fonction tracecmd_get_tep() retourne un pointeur vers le contexte tep ou NULL s'il n'y a pas de contexte tep pour le handle donné. Le pointeur tep retourné ne doit pas être libéré.

EXEMPLE

#include <trace-cmd.h>
...
struct tracecmd_input *handle = tracecmd_open("trace.dat");
        if (!handle) {
                /* Échec de l'ouverture du fichier trace.dat */
        }
...
unsigned long long offset = 0;
struct tep_record *rec;
int cpu = 0;
        rec = tracecmd_read_cpu_first(handle, cpu);
        while (rec) {
                ...
                if ( /* un enregistrement intéressant est remarqué */) {
                        /* stocker le décalage de l'enregistrement intéressant */
                        offset = rec->offset;
                }
                ...
                tracecmd_free_record(rec);
                rec = tracecmd_read_data(handle, cpu);
        }
        ...
        if (offset) {
                rec = tracecmd_read_at(handle, offset, &cpu);
                if (rec) {
                        /* Enregistrement obtenu à l'offset sur le cpu */
                        ...
                        tracecmd_free_record(rec);
                }
        }
...
        tracecmd_close(hadle);
