TRANSMISSION-DAEMON(1) Manuel des commandes générales TRANSMISSION-DAEMON(1)

NOM

transmission-daemon — un client bittorrent

SYNOPIS

transmission-daemon -h

transmission-daemon [-a x.x.x.x,...] [-b | -B] [-c répertoire] [-C] [-d] [-f] [-g répertoire] [-h] [-p port] [-t | -T] [-u nomutilisateur] [-v motdepasse] [-P port] [-m | -M] [-l limite] [-L limite] [-er | -ep | -et] [-utp | -no-utp] [-V] [-w répertoire-téléchargement] [-e fichierjournal] [-x fichierpid] [-log-error | -log-info | -log-debug]

DESCRIPTION

transmission-daemon est une session Transmission basée sur un démon qui peut être contrôlée via des commandes RPC depuis l'interface web de transmission ou transmission-remote(1).

OPTIONS

-a --allowed x.x.x.x,...
Autoriser l'accès RPC à une liste blanche d'adresses IP délimitées par des virgules. Des caractères génériques peuvent être spécifiés dans une adresse en utilisant '*'. Par défaut : "127.0.0.1,::1" Exemple : "127.0.0.*,192.168.1.*"
-b --blocklist
Activer les listes de blocage de pairs. Transmission comprend le format de fichier de liste de blocage bluetack. De nouvelles listes de blocage peuvent être ajoutées en les copiant dans le sous-répertoire "blocklists" du répertoire de configuration.
-c répertoire
Répertoire à surveiller pour de nouveaux fichiers .torrent à ajouter. Lorsqu'ils sont ajoutés à ce répertoire, le démon les chargera dans Transmission.
-C
Ne pas surveiller les nouveaux fichiers .torrent.
-B --no-blocklist
Désactiver les listes de blocage.
-d
Écrire les paramètres de transmission-daemon sur stderr.
-f --foreground
Exécuter en premier plan et afficher les erreurs sur stderr.
-g --config-dir répertoire
Où chercher les fichiers de configuration. Ceci peut être utilisé pour alterner entre l'utilisation des clients cli, daemon, gtk et qt. Voir https://github.com/transmission/transmission/blob/main/docs/Configuration-Files.md pour plus d'informations.
-er --encryption-required
Chiffrer toutes les connexions peer.
-ep --encryption-preferred
Préférer les connexions peer chiffrées.
-et --encryption-tolerated
Préférer les connexions peer non chiffrées.
-gsr --global-seedratio ratio
Tous les torrents, sauf indication contraire par un réglage par torrent, doivent être en seed jusqu'à un ratio spécifique.
-GSR --no-global-seedratio
Tous les torrents, sauf indication contraire par un réglage par torrent, doivent être en seed indépendamment du ratio.
-h --help
Afficher la description des options de ligne de commande.
--incomplete-dir répertoire
Lors de l'ajout de nouveaux torrents, stocker leur contenu dans répertoire jusqu'à ce que le torrent soit terminé.
--no-incomplete-dir
Ne pas stocker les torrents incomplets dans un répertoire différent.
-i --bind-address-ipv4
Écouter les connexions BitTorrent IPv4 sur une adresse spécifique. Une seule adresse d'écoute IPv4 est autorisée. Par défaut : 0.0.0.0 (Toutes les adresses)
-I --bind-address-ipv6
Écouter les connexions BitTorrent IPv6 sur une adresse spécifique. Une seule adresse d'écoute IPv6 est autorisée. Par défaut : :: (Toutes les adresses)
-r --rpc-bind-address
Écouter les connexions RPC sur une adresse spécifique. Ce doit être une adresse IPv4 ou IPv6. Une seule adresse d'écoute RPC est autorisée. Par défaut : 0.0.0.0 (Toutes les adresses IPv4)
--paused
Mettre tous les torrents en pause au démarrage.
-L --peerlimit-global limite
Limite globale de pairs. Utile sur les systèmes embarqués où la limite par défaut pourrait être inadaptée. Par défaut : 240
-l --peerlimit-torrent limite
Limite de pairs par torrent. Utile sur les systèmes embarqués où la limite par défaut pourrait être inadaptée. Par défaut : 60
-m --portmap
Activer la cartographie de ports via NAT-PMP ou UPnP.
-M --no-portmap
Désactiver la cartographie de ports.
-o --dht
Activer la table de hachage distribuée (DHT).
-O --no-dht
Désactiver la table de hachage distribuée (DHT).
-p --port port
Port à ouvrir et à écouter pour les requêtes RPC. Par défaut : 9091
-P --peerport port
Port à écouter pour les pairs entrants. Par défaut : 51413
-t --auth
Exiger des clients qu'ils s'authentifient. Cela n'a pas beaucoup d'utilité à moins que nomutilisateur et motdepasse soient également définis.
-T --no-auth
Ne pas exiger d'authentification des clients.
-u --username nomutilisateur
Utilisé pour l'authentification du client.
--password motdepasse
Utilisé pour l'authentification du client.
-utp --utp
Activer l'utilisation de uTP (μTP).
--no-utp
Désactiver l'utilisation de uTP (μTP).
-V --version
Afficher les informations de version.
-w --download-dir répertoire-téléchargement
Répertoire où les fichiers de torrents terminés seront stockés. Ce répertoire doit être celui spécifié dans settings.json pour l'option "download-dir".
-x --pid-file fichierpid
Écrire l'ID du processus du démon dans fichierpid.
-e --logfile logfile
Écrire les journaux d'activité dans logfile.
--log-debug
Activer le journalisation de débogage.
--log-error
Activer la journalisation des erreurs.
--log-info
Activer la journalisation des informations.

VOIR AUSSI

transmission-remote(1), settings.json(5).

OPTIONS_SPÉCIFIQUES_À_TRANSMISSION-DAEMON

Toutes les options spécifiées dans settings.json seront utilisées. Si une option est définie sur la ligne de commande, elle remplacera la valeur de settings.json.

OPTIONS

-g --config-dir directory
Set the configuration directory.
-h --help
Show a help message and exit
-l --list
List all torrents.
-p --port port
Set the port the daemon listens on for incoming peer connections.
-t --torrent torrent
Add a torrent to the list.
-T --torrent-done-script script
Set the script to run when a torrent finishes.
-q --quit-script script
Set the script to run when the daemon quits.
-P --port-random
Set the port to a random value.
-S --script-torrent-done script
Set the script to run when a torrent finishes.
-a --auth
Enable authentication.
-u --username username
Used for client authentication.
-v --password password
Used for client authentication.
-V --version
Show version number and exit
--utp
Enable uTP for peer connections.
--no-utp
Disable uTP for peer connections.
-w --download-dir
Where to store downloaded data.
-e --logfile
Where to store transmission's log messages.
--log-error
Show error messages
--log-info
Show error and info messages
--log-debug
Show error, info, and debug messages
-x --pid-file
Name of PID file

ENVIRONMENT

http_proxy
libcurl uses this environment variable when performing tracker announces.
TRANSMISSION_HOME
Sets the default config-dir.

FILES

~/.config/transmission-daemon
The config-dir used when neither [TRANSMISSION_HOME] nor [-g] is specified. See https://github.com/transmission/transmission/blob/main/docs/Configuration-Files.md for more information.
