NOM

trace-cmd-hist - afficher un histogramme des événements dans le fichier trace.dat

SYNTAXE

trace-cmd hist [OPTIONS][fichier-entrée]

DESCRIPTION

trace-cmd(1) hist affiche un histogramme à partir du fichier trace.dat. Au lieu d'afficher les événements dans leur ordre d'apparition, il crée un histogramme qui peut être affiché par tâche ou pour toutes les tâches, où les événements les plus fréquents apparaissent en premier. Il utilise le traceur de fonctions et les piles d'appels qu'il trouve pour essayer de reconstituer un graphe d'appels des événements.

OPTIONS

-i fichier-entrée

Par défaut, trace-cmd hist lit le fichier trace.dat. Mais l'option -i ouvre le fichier-entrée spécifié à la place. Notez que le fichier d'entrée peut également être spécifié comme dernier élément de la ligne de commande.

-P

Pour compresser tous les événements et afficher les graphes d'appels en ignorant les tâches et les différents PID, ajoutez -P pour ce faire. Au lieu d'afficher le nom de la tâche, il regroupera toutes les chaînes et affichera "<all pids>".
