TRANSICC(1) Manuel des commandes générales TRANSICC(1)

NOM

transicc - calculateur de conversion d'espaces colorimétriques little cms.

SYNTAXE

transicc [options] [ENTREE_CGATS] [SORTIE_CGATS]

DESCRIPTION

lcms est un moteur CMM autonome, qui gère la gestion des couleurs. Il implémente une transformation rapide entre les profils ICC. transicc est un calculateur de conversion d'espaces colorimétriques lcms.

OPTIONS

-b
Compensation du point noir.
-c NB
Précalcule la transformation (0=Désactivé, 1=Normal, 2=Haute Résolution, 3=Basse Résolution) [par défaut 1].
-d NB
État d'adaptation de l'observateur (col. abs. seulement), (0..1.0, valeur flottante) [par défaut 0.0].
-e
La représentation encodée des nombres n'est pas flottante (Option -w=utiliser 16 bits, Option -x=hexadécimal).
-g
Marque les couleurs hors gamut sur le softproof.
-i profil
Profil d'entrée (par défaut sRGB).
-l
Transformation par profil de lien de périphérique.
-m NB
Intention de SoftProof (0,1,2,3) [par défaut 0].
-n
Sortie succincte, destinée à une utilisation par canal.
-o profil
Profil de sortie (par défaut sRGB).
-q
Quantifie CGATS en 8 bits.
-s
Mode borné.
-t NB
Intention de rendu
0=Perceptuelle [par défaut]
1=Colorimétrique relative
2=Saturation
3=Colorimétrique absolue
10=Perceptuelle préservant l'encre noire
11=Colorimétrique relative préservant l'encre noire
12=Saturation préservant l'encre noire
13=Perceptuelle préservant le plan noir
14=Colorimétrique relative préservant le plan noir
15=Saturation préservant le plan noir
-v verbeux
Niveau de verbosité, (0=Aucun, 1=Normal, 2=Élevé, 3=Très Élevé) [par défaut 1].
-w
Utiliser 16 bits.
-x
Hexadécimal.
Vous pouvez utiliser '*Lab' et '*xyz' comme profils intégrés.

NOTES

Pour des suggestions, commentaires, rapports de bogues, etc., envoyez un e-mail à info@littlecms.com.
