TROJAN(1) Manuel des commandes générales TROJAN(1)

NOM

trojan - un mécanisme non identifiable qui vous aide à contourner le GFW

SYNTAXE

trojan [-htv] [-l JOURNAL] [-k JOURNALCLE] [[-c] CONFIG]

DESCRIPTION

trojan est un mécanisme non identifiable qui vous aide à contourner le GFW. Il chargera le fichier de configuration situé dans CONFIG et démarrera soit un client proxy, soit un serveur proxy.

OPTIONS

-c, --config=CONFIG
Définit le fichier de configuration à charger. Par défaut, /etc/trojan/config.json.
-h, --help
Affiche le message d'aide.
-k, --keylog=JOURNALCLE
Définit le fichier de journalisation des clés à écrire.
-l, --log=JOURNAL
Définit le fichier de journalisation à écrire. Si non spécifié, le journal sera envoyé sur la sortie d'erreur standard.
-t, --test
Teste le fichier de configuration, sans démarrer de serveur.
-v, --version
Affiche la version et les informations de compilation.

FICHIERS

/etc/trojan/config.json
Le fichier de configuration par défaut. Voir https://trojan-gfw.github.io/trojan/config pour les détails.

VOIR AUSSI

Documentation complète sur : https://trojan-gfw.github.io/trojan/
