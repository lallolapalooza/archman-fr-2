LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_file_exists, tracefs_dir_exists, tracefs_instance_get_file, tracefs_instance_get_dir - Travailler avec les fichiers et répertoires des instances de traçage.

SYNOPSIS

#include <tracefs.h>
bool tracefs_file_exists(struct tracefs_instance *instance, char *name);
bool tracefs_dir_exists(struct tracefs_instance *instance, char *name);
char *tracefs_instance_get_file(struct tracefs_instance *instance, const char *file);
char *tracefs_instance_get_dir(struct tracefs_instance *instance);

DESCRIPTION

Cet ensemble d'API peut être utilisé pour travailler avec les fichiers de traçage dans toutes les instances de traçage. Chacune de ces API prend un argument instance, qui peut être NULL pour agir sur l'instance de niveau supérieur. Sinon, elle agit sur une instance créée avec tracefs_insance_create(3)

La fonction tracefs_file_exists() vérifie si un fichier nommé name existe dans instance.

La fonction tracefs_dir_exists() vérifie si un répertoire nommé name existe dans instance.

La fonction tracefs_instance_get_file() renvoie le chemin complet du fichier avec le nom donné name dans instance. Notez qu'elle ne vérifie pas si le fichier existe dans l'instance.

La fonction tracefs_instance_get_dir() renvoie le chemin complet du répertoire avec le nom donné name dans instance. Notez qu'elle ne vérifie pas si le répertoire existe dans l'instance.

VALEUR DE RETOUR

Les fonctions tracefs_file_exists() et tracefs_dir_exists() renvoient true si le fichier / répertoire existe dans l'instance donnée ou false s'il n'existe pas.

Les fonctions tracefs_instance_get_file() et tracefs_instance_get_dir() renvoient une chaîne de caractères ou NULL en cas d'erreur. La chaîne retournée doit être libérée avec tracefs_put_tracing_file().

EXEMPLE

#include <tracefs.h>
struct tracefs_instance *inst = tracefs_instance_create("foo");
        if (!inst) {
                /* Erreur lors de la création d'une nouvelle instance de traçage */
                ...

                /* L'instance foo supporte l'horloge de traçage */

                int size;
                path =  = tracefs_instance_get_file(inst, "trace_clock")
                if (!path) {
                        /* Erreur lors de l'obtention du chemin du fichier trace_clock dans l'instance foo */
                        ...
                }
                ...
                tracefs_put_tracing_file(path);
                clock = tracefs_instance_file_read(inst, "trace_clock", &size);
                if (!clock) {
                        /* Échec de la lecture du fichier trace_clock dans l'instance foo */
                        ...
                }
                ...
                free(clock);
                if (tracefs_instance_file_write(inst, "trace_clock", "global") != strlen("global")) {
                        /* Échec de la définition de l'horloge de traçage globale dans l'instance foo */
                        ...
                }
        } else {
                /* L'instance foo ne supporte pas l'horloge de traçage */
        }
        if (tracefs_dir_exists(inst,"options")) {
                /* L'instance foo supporte les options de traçage */
                char *path = tracefs_instance_get_file(inst, "options");
                if (!path) {
                        /* Erreur lors de l'obtention du chemin du répertoire options dans l'instance foo */
                        ...
                }
                tracefs_put_tracing_file(path);
        } else {
                /* L'instance foo ne supporte pas les options de traçage */
        }
        ...
        if (tracefs_instance_is_new(inst))
                tracefs_instance_destroy(inst);
        else
                tracefs_instance_free(inst);
        ...
        long long int res;
        if (tracefs_instance_file_read_number(NULL, "tracing_on", &res) == 0) {
                if (res == 0) {
                        /* le traçage est désactivé dans l'instance principale */
                } else if (res == 1) {
                        /* le traçage est activé dans l'instance principale */
                } else {
                        /* état de traçage inconnu de l'instance principale */
                }
        } else {
                /* Échec de la lecture d'un entier depuis le fichier tracing_on */
        }
        ...
        int fd;
        fd = tracefs_instance_file_open(NULL, "tracing_on", O_WRONLY);
        if (fd >= 0) {
                /* Descripteur de fichier obtenu pour le fichier tracing_on de l'instance principale pour écriture */
                ...
                close(fd);
        }

tracefs_instance_get_dir(3)

tracefs_instance_get_dir — retrieve the directory path of a tracefs instance

SYNOPSIS

#include <tracefs.h>

char *tracefs_instance_get_dir(const char *instance_name);

DESCRIPTION

The tracefs_instance_get_dir function returns the directory path where the specified tracefs instance is mounted. The tracefs filesystem allows tracing of kernel events. Each instance of tracefs is mounted at a unique path, typically under /sys/kernel/tracing/instances/.

If instance_name is NULL, the function will return the directory path of the default tracefs instance, which is usually mounted at /sys/kernel/tracing/.

The returned string is allocated by the library and should be freed by the caller using free().

RETURN VALUE

On success, tracefs_instance_get_dir returns a pointer to a null-terminated string containing the directory path of the tracefs instance. If an error occurs (e.g., the instance does not exist, or cannot be accessed), it returns NULL and sets errno to indicate the error.

EXAMPLE

#include <stdio.h>
#include <stdlib.h>
#include <tracefs.h>

int main() {
    char *default_dir = tracefs_instance_get_dir(NULL);
    if (default_dir) {
        printf("Default tracefs directory: %s\n", default_dir);
        free(default_dir);
    } else {
        perror("tracefs_instance_get_dir(NULL)");
    }

    char *my_instance_dir = tracefs_instance_get_dir("my_instance");
    if (my_instance_dir) {
        printf("Tracefs instance 'my_instance' directory: %s\n", my_instance_dir);
        free(my_instance_dir);
    } else {
        perror("tracefs_instance_get_dir(\"my_instance\")");
    }

    return 0;
}

FILES

/sys/kernel/tracing/: Default tracefs mount point.

/sys/kernel/tracing/instances/<instance_name>/: Mount point for named tracefs instances.

tracefs_instance_get_dir(3)

tracefs_instance_get_dir — récupérer le chemin du répertoire d'une instance tracefs

SYNTAXE

#include <tracefs.h>

char *tracefs_instance_get_dir(const char *instance_name);

DESCRIPTION

La fonction tracefs_instance_get_dir renvoie le chemin du répertoire où l'instance tracefs spécifiée est montée. Le système de fichiers tracefs permet le traçage des événements du noyau. Chaque instance de tracefs est montée à un chemin unique, généralement sous /sys/kernel/tracing/instances/.

Si instance_name est NULL, la fonction renverra le chemin du répertoire de l'instance tracefs par défaut, qui est généralement montée à /sys/kernel/tracing/.

La chaîne retournée est allouée par la bibliothèque et doit être libérée par l'appelant en utilisant free().

VALEUR DE RETOUR

En cas de succès, tracefs_instance_get_dir renvoie un pointeur vers une chaîne terminée par un caractère nul contenant le chemin du répertoire de l'instance tracefs. Si une erreur se produit (par exemple, l'instance n'existe pas ou ne peut pas être accédée), elle renvoie NULL et définit errno pour indiquer l'erreur.

EXEMPLE

#include <stdio.h>
#include <stdlib.h>
#include <tracefs.h>

int main() {
    char *default_dir = tracefs_instance_get_dir(NULL);
    if (default_dir) {
        printf("Répertoire tracefs par défaut : %s\n", default_dir);
        free(default_dir);
    } else {
        perror("tracefs_instance_get_dir(NULL)");
    }

    char *my_instance_dir = tracefs_instance_get_dir("my_instance");
    if (my_instance_dir) {
        printf("Répertoire de l'instance tracefs 'my_instance' : %s\n", my_instance_dir);
        free(my_instance_dir);
    } else {
        perror("tracefs_instance_get_dir(\"my_instance\")");
    }

    return 0;
}

FICHIERS

/sys/kernel/tracing/ : Point de montage tracefs par défaut.

/sys/kernel/tracing/instances/<nom_instance>/ : Point de montage pour les instances tracefs nommées.
