trunc(3) Manuel des fonctions de bibliothèque trunc(3)

NOM

trunc, truncf, truncl - arrondir à l'entier, vers zéro

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double trunc(double x);
float truncf(float x);
long double truncl(long double x);
Exigences de macro de test de fonctionnalité pour glibc (voir feature_test_macros(7)) :

trunc(), truncf(), truncl() :

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPTION

Ces fonctions arrondissent x à la valeur entière la plus proche, dont la magnitude n'est pas supérieure à celle de x.

VALEUR DE RETOUR

Ces fonctions retournent la valeur entière arrondie, au format flottant.

Si x est un entier, infini, ou NaN, x lui-même est retourné.

ERREURS

Aucune erreur ne se produit.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
trunc (), truncf (), truncl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

glibc 2.1. C99, POSIX.1-2001.

NOTES

La valeur entière retournée par ces fonctions peut être trop grande pour être stockée dans un type entier (int, long, etc.). Pour éviter un dépassement de capacité, qui produira des résultats indéfinis, une application devrait effectuer une vérification de plage sur la valeur retournée avant de l'affecter à un type entier.

VOIR AUSSI

ceil(3), floor(3), lrint(3), nearbyint(3), rint(3), round(3)
