tracecmd_get_cpu_map(3)

Paquet: trace-cmd

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACECMD(3) Manuel libtracefs LIBTRACECMD(3)

NOM

tracecmd_map_vcpus, tracecmd_get_cpu_map, tracecmd_map_find_by_host_pid, tracecmd_map_get_host_pid, tracecmd_map_get_guest, tracecmd_map_set_private, tracecmd_map_get_private - Cartographie des données hôte et invité

SYNTAXE

#include <trace-cmd.h>
int tracecmd_map_vcpus(struct tracecmd_input **handles, int nr_handles);
struct tracecmd_cpu_map *tracecmd_get_cpu_map(struct tracecmd_input *handle, int cpu);
struct tracecmd_cpu_map *tracecmd_map_find_by_host_pid(struct tracecmd_input *handle,
                                                      int host_pid);
int tracecmd_map_get_host_pid(struct tracecmd_cpu_map *map);
struct tracecmd_input *tracecmd_map_get_guest(struct tracecmd_cpu_map *map);
void tracecmd_map_set_private(struct tracecmd_cpu_map *map, void *priv);
void *tracecmd_map_get_private(struct tracecmd_cpu_map *map);

DESCRIPTION

Cet ensemble d'API est utilisé pour mapper des fichiers de trace hôte et invité afin de faciliter l'analyse ultérieure des traces.

La fonction tracecmd_map_vcpus() prend un tableau de handles où chaque élément de ce tableau a été créé par l'une des fonctions tracecmd_open(3), et le nombre de handles comme nr_handles. Le premier handle dans le tableau de handles est censé être le descripteur du fichier de trace hôte, et les suivants sont des fichiers de trace invités qui s'exécutent sur l'hôte, et qui ont été créés par les interactions de trace-cmd record(1) et trace-cmd agent(1). Elle retourne le nombre d'invités trouvés dans handles qui étaient associés à l'hôte, ou une valeur négative en cas d'erreur.

La fonction tracecmd_get_cpu_map() retourne un descripteur pour un CPU donné pour un handle. Si le handle était un invité défini depuis tracecmd_map_vcpus(), alors la cartographie créée par cette fonction qui est associée à ce vCPU particulier (indiqué par cpu) du handle. Ce descripteur peut être utilisé par les fonctions tarcecmd_map_get_guest(), tracecmd_map_set_private() et tracecmd_map_get_private().

La fonction tracecmd_map_find_by_host_pid() retournera une cartographie pour un CPU virtuel invité qui est géré par le host_pid donné. Notez que le handle passé peut être soit le handle hôte, soit l'un des handles invités de cet hôte qui a été mappé par tracecmd_map_vcpus(), même si le handle invité n'a pas le vCPU que le host_pid représente.

La fonction tracecmd_map_get_host_pid() retournera le host_pid pour une map donnée qui a été récupérée par l'une des fonctions ci-dessus.

La fonction tracecmd_map_get_guest() retournera le guest_handle pour une map donnée qui a été récupérée par l'une des fonctions ci-dessus.

La fonction tracecmd_map_set_private() permet à l'application d'assigner des données privées pour une cartographie de thread hôte vers vCPU invité définie par map.

La fonction tracecmd_map_get_private() récupère les données priv de map qui ont été définies par tracecmd_map_set_private().

VALEUR RENVOYÉE

tracecmd_map_vcpus() retourne le nombre d'invités dans le tableau handles qui ont été mappés au handle hôte, qui est la première entrée dans handles. Elle retourne -1 en cas d'erreur.

tracecmd_get_cpu_map() retourne une carte créée par tracecmd_map_vcpus() pour un cpu donné pour un handle donné, ou NULL s'il n'est pas trouvé.

tracecmd_map_find_by_host_pid() retourne une carte qui est associée par la tâche hôte avec host_pid comme son identifiant de processus. handle peut être soit le handle hôte, soit l'un des handles invités qui ont été mappés à l'hôte via tracecmd_map_vcpus(), même si le handle invité est un invité différent de celui pour lequel la cartographie est destinée. Elle retourne NULL si non trouvé.

tracecmd_map_get_host_pid() retourne l'identifiant du processus hôte pour une cartographie associée définie par map.

tracecmd_map_get_guest() retourne le handle invité pour une cartographie associée définie par map.

tracecmd_map_get_private() retourne les données privées d'une cartographie définie par map qui a été définie par tracecmd_map_set_private().

EXEMPLE

#include <stdlib.h>
#include <errno.h>
#include <trace-cmd.h>
int main(int argc, char **argv)
{
        struct tracecmd_input **handles = NULL;
        int nr_handles;
        int i;
        if (argc < 2) {
                printf("usage: host_trace.dat guest1_trace.dat [guest2_trace.dat ...]\n");
                exit(-1);
        }
        for (i = 1; i < argc; i++) {
                handles = realloc(handles, sizeof(*handles) * (nr_handles + 1));
                if (!handles)
                        exit(-1);
                handles[nr_handles] = tracecmd_open(argv[i], 0);
                if (!handles[nr_handles]) {
                        perror(argv[1]);
                        exit(-1);
                }
                tracecmd_set_private(handles[nr_handles], argv[i]);
                nr_handles++;
        }
        tracecmd_map_vcpus(handles, nr_handles);
        for (i = 1; i < nr_handles; i++) {
                struct tracecmd_cpu_map *map;
                struct tep_handle *tep;
                const char *file = tracecmd_get_private(handles[i]);
                int cpus, cpu;
                printf("Mappings for guest %s:\n", file);
                tep = tracecmd_get_tep(handles[i]);
                cpus = tep_get_cpus(tep);
                for (cpu = 0; cpu < cpus; cpu++) {
                        printf("  [%03d] ", cpu);
                        map = tracecmd_get_cpu_map(handles[i], cpu);
                        if (!map) {
                                printf("Has no mapping!\n");
                                continue;
                        }
                        printf("host_pid: %d\n", tracecmd_map_get_host_pid(map));
                }
        }
        for (i = 0; i < nr_handles; i++)
                tracecmd_close(handles[i]);
        free(handles);
        exit(0);
}
