Paquet: libtracefs

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_instance_create, tracefs_instance_destroy, tracefs_instance_alloc, tracefs_instance_free, tracefs_instance_is_new, tracefs_instances, tracefs_instance_clear, tracefs_instance_reset - Gérer les instances de trace.

SYNTAXE

#include <tracefs.h>
struct tracefs_instance *tracefs_instance_create(const char *name);
int tracefs_instance_destroy(struct tracefs_instance *instance);
struct tracefs_instance *tracefs_instance_alloc(const char *tracing_dir, const char *name);
void tracefs_instance_free(struct tracefs_instance *instance);
bool tracefs_instance_is_new(struct tracefs_instance *instance);
char **tracefs_instances(const char *regex);
void tracefs_instance_clear(struct tracefs_instance *instance);
void tracefs_instance_reset(struct tracefs_instance *instance);

DESCRIPTION

Cet ensemble de fonctions peut être utilisé pour gérer les instances de trace. Une instance de trace est un tampon secondaire utilisé par le système de traçage Linux. Étant donné un nom unique, les événements activés dans une instance n'affectent pas le système de traçage principal, ni les autres instances, de même que les événements activés dans le système de traçage principal ou dans d'autres instances n'affectent pas l'instance donnée.

La fonction tracefs_instance_create() alloue et initialise une nouvelle structure tracefs_instance et la retourne. Si l'instance avec le nom name n'existe pas encore dans le système, elle sera créée. Le nom name peut être NULL, auquel cas la nouvelle structure tracefs_instance est initialisée pour l'instance supérieure. Notez que l'instance supérieure ne peut pas être créée dans le système si elle n'existe pas.

La fonction tracefs_instance_destroy() supprime l'instance du système, mais ne libère pas la structure. tracefs_instance_free() doit toujours être appelée sur instance.

La fonction tracefs_instance_alloc()* alloue une nouvelle structure tracefs_instance pour une instance de trace existante. Si l'instance n'existe pas dans le système, la fonction échoue. Le paramètre tracing_dir pointe vers le répertoire de trace du système. Il peut être NULL, auquel cas le répertoire de trace du système par défaut est utilisé. Ce paramètre est utile pour allouer des instances à des répertoires de trace, copiés depuis une autre machine. Le nom name est le nom de l'instance, ou NULL pour l'instance supérieure dans le répertoire tracing_dir donné.

La fonction tracefs_instance_free() libère la structure tracefs_instance, sans supprimer l'instance de trace du système.

La fonction tracefs_instance_is_new() vérifie si l'instance instance donnée a été nouvellement créée par tracefs_instance_create(), ou si elle existait déjà dans le système auparavant.

La fonction tracefs_instances() retourne une liste des instances existantes dans le système qui correspondent à l'expression régulière regex. Si regex est NULL, alors elle correspondra à toutes les instances existantes. La liste retournée doit être libérée avec tracefs_list_free(3). Notez que si aucune instance n'est trouvée, une liste vide est retournée et doit également être libérée avec tracefs_list_free(3).

La fonction tracefs_instance_clear() efface le tampon circulaire de l'instance instance donnée ou le tampon circulaire de niveau supérieur si instance est NULL.

La fonction tracefs_instance_reset() réinitialise l'instance instance donnée à son état par défaut.

VALEUR DE RETOUR

Les fonctions tracefs_instance_create() et tracefs_instance_alloc() retournent un pointeur vers une structure tracefs_instance nouvellement allouée. Elle doit être libérée avec tracefs_instance_free().

La fonction tracefs_instance_destroy() retourne 0 si elle réussit à supprimer l'instance, sinon elle retourne -1 si l'instance n'existe pas ou si elle échoue à la supprimer.

La fonction tracefs_instance_is_new() retourne true si l'appel à tracefs_instance_create() qui a alloué instance a également créé l'instance de trace dans le système, ou false si l'instance de trace existait déjà dans le système lorsque instance a été allouée par tracefs_instance_create() ou tracefs_instance_alloc().

La fonction tracefs_instances() retourne une liste des noms d'instances qui existent sur le système. La liste doit être libérée avec tracefs_list_free(3). Une liste vide est retournée si aucune instance existante ne correspond à regex, et celle-ci doit également être libérée avec tracefs_list_free(3). NULL est retourné en cas d'erreur.

La fonction tracefs_instance_clear() retourne 0 si elle a effacé avec succès le tampon circulaire, ou -1 en cas d'erreur.

EXEMPLE

#include <tracefs.h>
struct tracefs_instance *inst = tracefs_instance_create("foo");
        if (!inst) {
                /* Erreur lors de la création d'une nouvelle instance de trace */
                ...
        }
        ...
        if (tracefs_instance_is_new(inst))
                tracefs_instance_destroy(inst);
        tracefs_instance_free(inst);
...
struct tracefs_instance *inst = tracefs_instance_alloc(NULL, "bar");
        if (!inst) {
                /* Erreur lors de l'allocation de l'instance de trace 'bar' */
                ...
        }
        ...
        tracefs_instance_reset(inst);
        tracefs_instance_free(inst);

tracefs_instance_reset(3)

NOM

tracefs_instance_reset - réinitialiser une instance de traçage

SYNOPSIS

#include <tracefs.h>

int tracefs_instance_reset(struct tracefs_instance *instance);

DESCRIPTION

La fonction tracefs_instance_reset réinitialise une instance de traçage donnée. Cela efface toutes les données de traçage collectées et réinitialise l'état interne de l'instance.

VALEUR DE RETOUR

En cas de succès, la fonction retourne 0. En cas d'échec, elle retourne une valeur négative et définit errno pour indiquer l'erreur.

EXEMPLE

Voici un exemple d'utilisation de tracefs_instance_reset :


#include <tracefs.h>
#include <stdio.h>

int main() {
    struct tracefs_instance *instance;
    int ret;

    // Ouvrir une instance de traçage
    instance = tracefs_open_instance(NULL);
    if (!instance) {
        perror("tracefs_open_instance");
        return 1;
    }

    // Effectuer des opérations de traçage...

    // Réinitialiser l'instance
    ret = tracefs_instance_reset(instance);
    if (ret < 0) {
        fprintf(stderr, "Erreur lors de la réinitialisation de l'instance : %d\n", ret);
        tracefs_close_instance(instance);
        return 1;
    }

    printf("Instance de traçage réinitialisée avec succès.\n");

    // Fermer l'instance
    tracefs_close_instance(instance);

    return 0;
}

FICHIERS

Aucun fichier spécifique n'est utilisé directement par cette fonction, mais elle interagit avec le système de fichiers de traçage du noyau (généralement monté sur /sys/kernel/tracing).
