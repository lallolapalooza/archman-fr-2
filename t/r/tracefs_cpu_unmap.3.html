LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_cpu_open_mapped, tracefs_cpu_is_mapped, tracefs_mapped_is_supported, tracefs_cpu_map, tracefs_cpu_unmap - Mappage mémoire du tampon circulaire

SYNTAXE

#include <tracefs.h>
bool tracefs_cpu_is_mapped(struct tracefs_cpu *tcpu);
bool tracefs_mapped_is_supported(void);
int tracefs_cpu_map(struct tracefs_cpu *tcpu);
void tracefs_cpu_unmap(struct tracefs_cpu *tcpu);
struct tracefs_cpu *tracefs_cpu_open_mapped(struct tracefs_instance *instance,
                                            int cpu, bool nonblock);

DESCRIPTION

Si le `trace_pipe_raw` prend en charge le mappage mémoire, il s'agit généralement d'une méthode plus efficace pour diffuser des données à partir du tampon circulaire du noyau que de le lire, car elle ne nécessite pas de copier la mémoire qui est lue.

Si le mappage mémoire est pris en charge par le noyau et que l'application demande à utiliser le mappage mémoire via `tracefs_cpu_map()` ou via `tracefs_cpu_open_mapped()`, alors les fonctions tracefs_cpu_read(3) et tracefs_cpu_read_buf(3) utiliseront le mappage directement au lieu d'appeler l'appel système `read`.

Notez que le mappage fera que tracefs_cpu_buffered_read(3) et tracefs_cpu_buffered_read_buf(3) se comporteront comme tracefs_cpu_read(3) et tracefs_cpu_read_buf(3) respectivement, car il n'est pas logique d'utiliser un tube `splice` lorsqu'il est mappé. Le noyau effectuera une copie pour les lectures `splice` sur mappage, puis une autre copie dans la fonction lorsqu'il pourra éviter la copie si le tampon circulaire est mappé en mémoire.

Si le `tcpu` est mappé en mémoire, cela forcera également tracefs_cpu_write(3) et tracefs_cpu_pipe(3) à copier à partir du mappage au lieu d'utiliser `splice`. Par conséquent, il faut être prudent lors de la décision de mapper ou non le tampon circulaire, et c'est pourquoi il n'est pas mappé par défaut.

La fonction `tracefs_cpu_is_mapped()` retournera `true` si le `tcpu` a actuellement son tampon circulaire mappé en mémoire et `false` sinon. Ceci ne retourne pas si le noyau prend en charge le mappage mémoire, mais cela peut généralement être déterminé en appelant `tracefs_cpu_map()`.

La fonction `tracefs_mapped_is_supported()` retourne `true` si le tampon circulaire peut être mappé en mémoire.

La fonction `tracefs_cpu_map()` tentera de mapper le tampon circulaire associé à `tcpu` s'il n'est pas déjà mappé.

La fonction `tracefs_cpu_unmap()` dépliera le tampon circulaire associé à `tcpu` s'il est mappé.

La fonction `tracefs_cpu_open_mapped()` est équivalente à appeler tracefs_cpu_open(3) suivi de `tracefs_cpu_map()` sur le `tcpu` retourné par tracefs_cpu_open(3). Notez que cela réussira toujours si le mappage échoue, auquel cas il se comporte de la même manière que tracefs_cpu_open(3). Si vous devez savoir si le mappage a réussi ou non, `tracefs_cpu_is_mapped()` doit être appelé sur le `tcpu` retourné.

VALEUR RETOURNÉE

La fonction `tracefs_cpu_is_mapped()` retourne `true` si le `tcpu` donné a son tampon circulaire mappé en mémoire, `false` sinon.

La fonction `tracefs_mapped_is_supported()` retourne `true` si le tampon circulaire de traçage peut être mappé en mémoire, `false` s'il ne peut pas l'être ou si une erreur s'est produite.

La fonction `tracefs_cpu_map()` retourne 0 en cas de succès et -1 en cas d'erreur lors du mappage. Si 0 est retourné, alors `tracefs_cpu_is_mapped()` retournera `true` par la suite, ou `false` si le mappage a échoué.

La fonction `tracefs_cpu_open_mapped()` retourne un `tracefs_cpu` alloué en cas de succès de création, que le mappage du tampon circulaire ait réussi ou non. Elle retourne NULL pour les mêmes raisons que tracefs_cpu_open(3) retourne NULL. Si le succès du mappage doit être connu, l'appel de `tracefs_cpu_is_mapped()` par la suite est requis.

EXEMPLE

#include <stdlib.h>
#include <ctype.h>
#include <tracefs.h>
static void read_subbuf(struct tep_handle *tep, struct kbuffer *kbuf)
{
        static struct trace_seq seq;
        struct tep_record record;
        int missed_events;
        if (seq.buffer)
                trace_seq_reset(&seq);
        else
                trace_seq_init(&seq);
        while ((record.data = kbuffer_read_event(kbuf, &record.ts))) {
                record.size = kbuffer_event_size(kbuf);
                missed_events = kbuffer_missed_events(kbuf);
                if (missed_events) {
                        printf("[MISSED EVENTS");
                        if (missed_events > 0)
                                printf(": %d]\n", missed_events);
                        else
                                printf("]\n");
                }
                kbuffer_next_event(kbuf, NULL);
                tep_print_event(tep, &seq, &record,
                                "%s-%d %6.1000d\t%s: %s\n",
                                TEP_PRINT_COMM,
                                TEP_PRINT_PID,
                                TEP_PRINT_TIME,
                                TEP_PRINT_NAME,
                                TEP_PRINT_INFO);
                trace_seq_do_printf(&seq);
                trace_seq_reset(&seq);
        }
}
int main (int argc, char **argv)
{
        struct tracefs_cpu *tcpu;
        struct tep_handle *tep;
        struct kbuffer *kbuf;
        bool mapped;
        int cpu;
        if (argc < 2 || !isdigit(argv[1][0])) {
                printf("usage: %s cpu\n\n", argv[0]);
                exit(-1);
        }
        cpu = atoi(argv[1]);
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("Reading trace event formats");
                exit(-1);
        }
        tcpu = tracefs_cpu_open_mapped(NULL, cpu, 0);
        if (!tcpu) {
                perror("Open CPU 0 file");
                exit(-1);
        }
        /*
         * If this kernel supports mapping, use normal read,
         * otherwise use the piped buffer read, although if
         * the mapping succeeded, tracefs_cpu_buffered_read_buf()
         * acts the same as tracefs_cpu_read_buf(). But this is just
         * an example on how to use tracefs_cpu_is_mapped().
         */
        mapped = tracefs_cpu_is_mapped(tcpu);
        if (!mapped)
                printf("Was not able to map, falling back to buffered read\n");
        while ((kbuf = mapped ? tracefs_cpu_read_buf(tcpu, true) :
                        tracefs_cpu_buffered_read_buf(tcpu, true))) {
                read_subbuf(tep, kbuf);
        }
        kbuf = tracefs_cpu_flush_buf(tcpu);
        if (kbuf)
                read_subbuf(tep, kbuf);
        tracefs_cpu_close(tcpu);
        tep_free(tep);
        return 0;
}

RESSOURCES

NOM

tracefs_cpu_unmap - libtracefs

SYNOPIS

#include <tracefs.h>

int tracefs_cpu_unmap(struct tracefs_context *context, unsigned int cpu);

DESCRIPTION

La fonction tracefs_cpu_unmap() retire le CPU spécifié (le décalage du CPU est pris en compte) du contexte de traçage, s'il y est présent. Les données de traçage correspondantes sont vidées du tampon de traçage de ce CPU et l'espace est libéré.

VALEUR RETOURNÉE

En cas de succès, la fonction tracefs_cpu_unmap() retourne 0. En cas d'erreur, elle retourne un code d'erreur négatif.

EXEMPLE

    struct tracefs_context *context;
    int ret;

    context = tracefs_open_context(NULL);
    if (!context) {
        perror("tracefs_open_context");
        return 1;
    }

    /* Retirer le CPU 0 du contexte */
    ret = tracefs_cpu_unmap(context, 0);
    if (ret) {
        fprintf(stderr, "tracefs_cpu_unmap failed for CPU 0: %d\n", ret);
    }

    tracefs_close_context(context);
    return 0;
