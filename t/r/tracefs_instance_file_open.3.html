tracefs_instance_file_open(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_instance_file_open, tracefs_instance_file_write, tracefs_instance_file_write_number, tracefs_instance_file_append, tracefs_instance_file_clear, tracefs_instance_file_read, tracefs_instance_file_read_number - Travailler avec des fichiers dans les instances de traçage.

SYNTAXE

#include <tracefs.h>
int tracefs_instance_file_open(struct tracefs_instance *instance, const char *file, int mode);
int tracefs_instance_file_write(struct tracefs_instance *instance, const char *file, const char *str);
int tracefs_instance_file_write_number(struct tracefs_instance *instance, const char *file, size_t val);
int tracefs_instance_file_append(struct tracefs_instance *instance, const char *file, const char *str);
int tracefs_instance_file_clear(struct tracefs_instance *instance, const char *file);
char *tracefs_instance_file_read(struct tracefs_instance *instance, const char *file, int *psize);
int tracefs_instance_file_read_number(struct tracefs_instance *instance, const char *file, long long int *res);

DESCRIPTION

Cet ensemble d'API peut être utilisé pour travailler avec des fichiers de traçage dans toutes les instances de traçage. Chacune de ces API prend un argument instance, qui peut être NULL pour agir sur l'instance de niveau supérieur. Sinon, elle agit sur une instance créée avec tracefs_insance_create(3).

La fonction tracefs_instance_file_open() ouvre le fichier de traçage file de l'instance donnée et renvoie un descripteur de fichier vers celui-ci. Le mode d'accès au fichier mode peut être spécifié, voir open(3) pour plus de détails. Si -1 est passé comme mode, le mode par défaut O_RDWR est utilisé.

La fonction tracefs_instance_file_write() écrit une chaîne str dans un fichier file de l'instance donnée, sans le caractère NULL de fin. Lors de l'ouverture du fichier, cette fonction tente de tronquer la taille du fichier à zéro, ce qui efface tous les paramètres précédemment existants.

La fonction tracefs_instance_file_write_number() convertit val en chaîne de caractères, puis l'écrit dans le fichier donné. Il s'agit d'une fonction d'aide qui effectue la conversion du nombre en chaîne, puis appelle tracefs_instance_file_write().

La fonction tracefs_instance_file_append() écrit une chaîne str dans un fichier file de l'instance donnée, sans le caractère NULL de fin. Cette fonction est similaire à tracefs_instance_file_write(), mais le contenu existant du fichier n'est pas effacé. Ainsi, les nouveaux paramètres sont ajoutés aux paramètres existants (le cas échéant).

La fonction tracefs_instance_file_clear() tente de tronquer la taille du fichier à zéro, ce qui efface tous les paramètres précédemment existants. Si le fichier contient du contenu qui n'est pas effacé de cette manière, cela n'aura aucun effet.

La fonction tracefs_instance_file_read() lit le contenu d'un fichier file de l'instance donnée.

La fonction tracefs_instance_file_read_number() lit le contenu d'un fichier file de l'instance donnée et le convertit en un entier long long, qui est stocké dans res.

VALEUR DE RETOUR

La fonction tracefs_instance_file_open() renvoie un descripteur de fichier vers le fichier ouvert. Il doit être fermé avec close(3). En cas d'erreur, -1 est renvoyé.

La fonction tracefs_instance_file_write() renvoie le nombre d'octets écrits, ou -1 en cas d'erreur.

La fonction tracefs_instance_file_write_number() renvoie 0 en cas de succès et -1 en cas d'erreur.

La fonction tracefs_instance_file_append() renvoie le nombre d'octets écrits, ou -1 en cas d'erreur.

La fonction tracefs_instance_file_clear() renvoie 0 en cas de succès, ou -1 en cas d'erreur.

La fonction tracefs_instance_file_read() renvoie un pointeur vers une chaîne terminée par NULL, lue à partir du fichier, ou NULL en cas d'erreur. La chaîne renvoyée doit être libérée avec free().

La fonction tracefs_instance_file_read_number() renvoie 0 si un entier valide est lu à partir du fichier et stocké dans res, ou -1 en cas d'erreur.

EXEMPLE

#include <tracefs.h>
struct tracefs_instance *inst = tracefs_instance_create("foo");
        if (!inst) {
                /* Erreur lors de la création d'une nouvelle instance de traçage */
                ...
        }
        if (tracefs_file_exists(inst,"trace_clock")) {
                /* L'instance foo prend en charge l'horloge de traçage */
                char *path, *clock;
                int size;
                path =  = tracefs_instance_get_file(inst, "trace_clock")
                if (!path) {
                        /* Erreur lors de l'obtention du chemin du fichier trace_clock dans l'instance foo */
                        ...
                }
                ...
                tracefs_put_tracing_file(path);
                clock = tracefs_instance_file_read(inst, "trace_clock", &size);
                if (!clock) {
                        /* Échec de la lecture du fichier trace_clock dans l'instance foo */
                        ...
                }
                ...
                free(clock);
                if (tracefs_instance_file_write(inst, "trace_clock", "global") != strlen("global")) {
                        /* Échec de la définition de l'horloge de traçage globale dans l'instance foo */
                        ...
                }
        } else {
                /* L'instance foo ne prend pas en charge l'horloge de traçage */
        }
        if (tracefs_dir_exists(inst,"options")) {
                /* L'instance foo prend en charge les options de traçage */
                char *path = tracefs_instance_get_file(inst, "options");
                if (!path) {
                        /* Erreur lors de l'obtention du chemin du répertoire options dans l'instance foo */
                        ...
                }
                tracefs_put_tracing_file(path);
        } else {
                /* L'instance foo ne prend pas en charge les options de traçage */
        }
        ...
        if (tracefs_instance_is_new(inst))
                tracefs_instance_destroy(inst);
        else
                tracefs_instance_free(inst);
        ...
        long long int res;
        if (tracefs_instance_file_read_number(NULL, "tracing_on", &res) == 0) {
                if (res == 0) {
                        /* le traçage est désactivé dans l'instance principale */
                } else if (res == 1) {
                        /* le traçage est activé dans l'instance principale */
                } else {
                        /* État de traçage inconnu de l'instance principale */
                }
        } else {
                /* Échec de la lecture d'un entier depuis le fichier tracing_on */
        }
        ...
        int fd;
        fd = tracefs_instance_file_open(NULL, "tracing_on", O_WRONLY);
        if (fd >= 0) {
                /* Descripteur de fichier obtenu vers le fichier tracing_on de l'instance principale pour écriture */
                ...
                close(fd);
        }
