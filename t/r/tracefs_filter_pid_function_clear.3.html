tracefs_filter_pid_function_clear(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_filter_pid_function, tracefs_filter_pid_events, tracefs_filter_pid_function_clear, tracefs_filter_pid_events_clear - Ajouter et supprimer le filtrage par PID pour les fonctions et les événements

SYNOPSIS

#include <tracefs.h>
int tracefs_filter_pid_function(struct tracefs_instance *instance, int pid,
                                bool reset, bool notrace);
int tracefs_filter_pid_function_clear(struct tracefs_instance *instance, bool notrace);
int tracefs_filter_pid_events(struct tracefs_instance *instance, int pid,
                             bool reset, bool notrace);
int tracefs_filter_pid_events_clear(struct tracefs_instance *instance, bool notrace);

DESCRIPTION

Les événements et les fonctions peuvent être filtrés par PID, mais ils sont traités séparément. Le filtrage par PID pour les fonctions affecte les traceurs de fonctions et de graphes de fonctions (function_graph), tandis que le filtrage par PID pour les événements affecte tous les événements tels que sched_switch et sched_waking. Si TRACEFS_OPTION_FUNCTION_FORK est activée (voir tracefs_option_enable(3)), tout PID défini dans le cadre du filtrage PID de fonctions aura automatiquement ses enfants ajoutés lors de leur création, ainsi que le PID supprimé lors de leur sortie. Si TRACEFS_OPTION_EVENT_FORK est défini, il en va de même pour le filtrage PID d'événements. Cela inclut également l'option notrace, où les threads et processus enfants des PID marqués comme notrace ne seront pas non plus tracés.

La fonction tracefs_filter_pid_function() affecte le filtrage PID des fonctions et tracefs_filter_pid_events() affecte le filtrage PID des événements. Pour les deux fonctions, elles ajoutent un pid à filtrer dans l' instance donnée. Si reset est vrai, alors tous les PID déjà filtrés seront supprimés, sinon le pid est simplement ajouté au filtrage. Si notrace est vrai, alors le PID est ajouté à la liste des PID à ne pas tracer. Notez que reset n'affecte que la liste associée à notrace. C'est-à-dire que si reset et notrace sont tous deux vrais, cela n'affectera pas les PID à tracer. Il en va de même si reset est vrai et notrace est faux, cela n'affectera pas les PID à ne pas tracer.

La fonction tracefs_filter_pid_function_clear() affecte le filtrage PID des fonctions et tracefs_filter_pid_events_clear() affecte le filtrage PID des événements. Pour les deux fonctions, elles effaceront tous les PID filtrés pour le filtre donné. Si notrace est vrai, elles effacent tous les PID à ne pas tracer, sinon si c'est faux, elles effacent tous les PID à tracer.

VALEUR DE RETOUR

Toutes les fonctions retournent 0 en cas de succès et -1 en cas d'erreur.

EXEMPLE

#include <stdlib.h>
#include <stdio.h>
#include <ctype.h>
#include <tracefs.h>
static void usage(char **argv)
{
        fprintf(stderr, "usage: %s [-e|-f][-c|-n] pid [pid ...]\n", argv[0]);
        fprintf(stderr, "   -e enable event filter\n");
        fprintf(stderr, "   -f enable function filter\n");
        fprintf(stderr, "     (default is both, function and event)\n");
        fprintf(stderr, "   -c clear the filter\n");
        fprintf(stderr, "   -n notrace filter\n");
        exit(-1);
}
int main (int argc, char **argv)
{
        bool events = false;
        bool funcs = false;
        bool neg = false;
        bool clear = false;
        bool reset = true;
        int i;
        for (i = 1; i < argc && argv[i][0] == '-'; i++) {
                char *arg = argv[i];
                int c;
                for (c = 1; arg[c]; c++) {
                        switch (arg[c]) {
                        case 'e': events = true; break;
                        case 'f': funcs = true; break;
                        case 'n': neg = true; break;
                        case 'c': clear = true; break;
                        default:
                                usage(argv);
                        }
                }
                if (c == 1)
                        usage(argv);
        }
        if (i == argc && !clear)
                usage(argv);
        if (!events && !funcs) {
                events = true;
                funcs = true;
        }
        if (clear) {
                if (events)
                        tracefs_filter_pid_events_clear(NULL, neg);
                if (funcs)
                        tracefs_filter_pid_function_clear(NULL, neg);
                exit(0);
        }
        for (; i < argc; i++) {
                int pid = atoi(argv[i]);
                if (events)
                        tracefs_filter_pid_events(NULL, pid, reset, neg);
                if (funcs)
                        tracefs_filter_pid_function(NULL, pid, reset, neg);
                reset = false;
        }
        exit(0);
}
