sous-programme ctrttp (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) ap, integer info)

CTRTTP copie une matrice triangulaire du format plein standard (TR) vers le format condensé standard (TP).

Objectif :

!>
!> CTRTTP copie une matrice triangulaire A du format plein (TR) vers le format
!> condensé standard (TP).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' :  A est triangulaire supérieure ;
!>          = 'L' :  A est triangulaire inférieure.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices AP et A.  N >= 0.
!>

A

!>          A est un tableau de type COMPLEX, de dimension (LDA,N)
!>          À l'entrée, la matrice triangulaire A. Si UPLO = 'U', la partie
!>          supérieure triangulaire de A, de taille N x N, contient la partie
!>          supérieure triangulaire de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L', la
!>          partie inférieure triangulaire de A, de taille N x N, contient la partie
!>          inférieure triangulaire de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AP

!>          AP est un tableau de type COMPLEX, de dimension ( N*(N+1)/2 ),
!>          À la sortie, la matrice triangulaire A supérieure ou inférieure, condensée
!>          par colonne dans un tableau linéaire. La j-ième colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  succès de l'exécution
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>

trttp(3) — LAPACK

NOM

ztrttp — copie une matrice triangulaire d'un format plein standard (TR) vers un format compact standard (TP).

SYNTAXIS

    call ztrttp ( uplo, n, a, lda, ap, info )

    subroutine ztrttp (character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( * ) ap, integer info)

DESCRIPTION

ZTRTTP copie une matrice triangulaire d'un format plein standard (TR) vers un format compact standard (TP).

But :

!>
!> ZTRTTP copie une matrice triangulaire A du format plein (TR) vers le format
!> compact standard (TP).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  A est triangulaire supérieure ;
!>          = 'L':  A est triangulaire inférieure.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices AP et A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, la matrice triangulaire A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire principale N par N de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée.  Si UPLO = 'L', la
!>          partie inférieure triangulaire principale N par N de A contient la
!>          partie triangulaire inférieure de la matrice A, et la partie
!>          strictement supérieure triangulaire de A n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

AP

!>          AP est un tableau COMPLEX*16, de dimension ( N*(N+1)/2 ),
!>          À la sortie, la matrice triangulaire supérieure ou inférieure A,
!>          compactée par colonnes dans un tableau linéaire. La j-ième colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Auteur

Univ. du Tennessee

Univ. du Colorado à Denver
