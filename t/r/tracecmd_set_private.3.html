NOM

tracecmd_open, tracecmd_open_fd, tracecmd_open_head, tracecmd_init_data, tracecmd_close, tracecmd_set_private, tracecmd_get_private - Ouvrir et fermer un fichier de trace.

SYNTAXE

#include <trace-cmd.h>
struct tracecmd_input *tracecmd_open(const char *fichier, int flags);
struct tracecmd_input *tracecmd_open_fd(int fd, int flags);
struct tracecmd_input *tracecmd_open_head(const char *fichier, int flags);
int tracecmd_init_data(struct tracecmd_input *handle);
void tracecmd_close(struct tracecmd_input *handle);
void tracecmd_set_private(struct tracecmd_input *handle, void *data);
void *tracecmd_get_private(struct tracecmd_input *handle);

DESCRIPTION

Cet ensemble d'API peut être utilisé pour ouvrir et fermer un fichier de trace enregistré par trace-cmd(1) et contenant des informations de traçage de ftrace, le traçeur officiel du noyau Linux. Le fichier ouvert est représenté par une structure tracecmd_input, toutes les autres API de la bibliothèque qui travaillent avec le fichier nécessitent un pointeur vers cette structure. Les API pour ouvrir un fichier de trace ont un paramètre d'entrée flag, qui contrôle la manière dont le fichier sera ouvert et analysé. Le flag est une combinaison de ces options :

TRACECMD_FL_LOAD_NO_PLUGINS - Ne charger aucun plugin
TRACECMD_FL_LOAD_NO_SYSTEM_PLUGINS - Ne charger aucun plugin système, ne charger que les plugins "locaux uniquement"
                                       depuis le répertoire personnel de l'utilisateur.

La fonction tracecmd_open() ouvre un fichier de trace donné fichier, analyse les en-têtes de métadonnées du fichier, alloue et initialise une structure de gestionnaire tracecmd_input représentant le fichier. Elle initialise également le gestionnaire pour lire les données de trace depuis le fichier. Le gestionnaire retourné est prêt à être utilisé avec les API tracecmd_read_.

La fonction tracecmd_open_fd() fait la même chose que tracecmd_open(), mais travaille avec un descripteur de fichier vers un fichier de trace, ouvert en lecture.

La fonction tracecmd_open_head() est identique à tracecmd_open(), mais n'initialise pas le gestionnaire pour la lecture des données de trace. Elle lit et analyse uniquement les en-têtes de métadonnées. La fonction tracecmd_init_data() doit être utilisée avant d'utiliser les API tracecmd_read_.

La fonction tracecmd_init_data() initialise un handle, alloué avec tracecmd_open_head(), pour lire les données de trace depuis le fichier qui y est associé. Cette API doit être appelée avant toutes les API tracecmd_read_.

La fonction tracecmd_close() libère un handle, pointeur vers la structure tracecmd_input, précédemment alloué avec les API tracecmd_open(), tracecmd_open_fd() ou tracecmd_open_head().

La fonction tracecmd_set_private() permet d'ajouter des data spécifiques au handle qui peuvent être récupérées plus tard.

La fonction tracecmd_get_private() récupérera les data définies par tracecmd_set_private() pour le handle donné.

VALEUR DE RETOUR

Les fonctions tracecmd_open(), tracecmd_open_fd() et tracecmd_open_head() retournent un pointeur vers la structure tracecmd_input ou NULL en cas d'erreur. La structure retournée doit être libérée avec tracecmd_close(). Notez que si tracecmd_open_fd() est utilisé pour allouer un gestionnaire tracecmd_input, lorsque tracecmd_close() est appelé pour le fermer, ce fd sera également fermé.

La fonction tracecmd_init_data() retourne -1 en cas d'erreur ou 0 sinon.

La fonction tracecmd_get_private() retourne les data définies par tracecmd_set_private().

EXEMPLE

Il existe deux modes d'utilisation distincts pour ouvrir et lire les données de trace
d'un fichier de trace, qui peuvent être utilisés en fonction du cas d'utilisation.
1. Ouvrir et initialiser le fichier de trace en une seule étape :
#include <stdlib.h>
#include <trace-cmd.h>
static int print_events(struct tracecmd_input *handle, struct tep_record *record, int cpu, void *data)
{
        static struct trace_seq seq;
        struct tep_handle *tep = tracecmd_get_tep(handle);
        const char *file = tracecmd_get_private(handle);
        if (!seq.buffer)
                trace_seq_init(&seq);
        trace_seq_reset(&seq);
        trace_seq_printf(&seq, "%s: ", file);
        tep_print_event(tep, &seq, record, "%6.1000d [%03d] %s-%d %s: %s\n",
                        TEP_PRINT_TIME, TEP_PRINT_CPU, TEP_PRINT_COMM, TEP_PRINT_PID,
                        TEP_PRINT_NAME, TEP_PRINT_INFO);
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
        return 0;
}
int main(int argc, char **argv)
{
        struct tracecmd_input *handle;
        if (argc < 2) {
                printf("usage: %s trace.dat\n", argv[0]);
                exit(-1);
        }
        handle = tracecmd_open(argv[i], 0);
        if (!handle)
                exit(-1);
        tracecmd_set_private(handles[nr_handles], argv[i]);
        tracecmd_iterate_events(handles, NULL, 0, print_events, NULL);
        tracecmd_close(handle);
}
2. Ouvrir et initialiser le fichier de trace en deux étapes. Cela permet d'effectuer
un certain traitement basé sur les métadonnées, lues depuis le fichier, avant
d'initialiser les données de trace pour la lecture. L'exemple d'un tel cas
d'utilisation est l'ouverture de plusieurs fichiers de trace enregistrés dans une
même session de trace. Dans ce cas, les horodatages de tous les événements de trace
doivent être ajustés en fonction des informations des métadonnées du fichier
et avant la lecture des données de trace.
#include <trace-cmd.h>
...
struct tracecmd_input *handle = tracecmd_open_head("trace.dat");
        if (!handle) {
                /* Échec de l'ouverture du fichier trace.dat */
        }
...
        /* effectuer un traitement, avant d'initialiser les données de trace pour la lecture */
...
        if (tracecmd_init_data(handle) < 0) {
                /* Échec de l'initialisation du handle pour la lecture des données de trace */
        }
...
        /* Lire les données de traçage depuis le fichier, en utilisant le handle */
...
        tracecmd_close(handle);
...

NOM

tracecmd_set_private - Définir ou obtenir les données privées d'un événement.

SYNTAXE

#include <trace-cmd/trace-cmd.h>
int tracecmd_set_private(struct trace_event_file *event_file,
                           const void *data, size_t size);
const void *tracecmd_get_private(struct trace_event_file *event_file);
size_t tracecmd_get_private_size(struct trace_event_file *event_file);

DESCRIPTION

La fonction tracecmd_set_private permet de définir des données privées associées à un événement spécifique dans le contexte d'un fichier d'événement donné. Les données sont copiées à partir du pointeur data et la taille est spécifiée par size.

Les fonctions tracecmd_get_private et tracecmd_get_private_size permettent de récupérer les données privées et leur taille associées à un fichier d'événement.

VALEUR DE RETOUR

tracecmd_set_private renvoie 0 en cas de succès, ou un code d'erreur en cas d'échec.

tracecmd_get_private renvoie un pointeur vers les données privées, ou NULL si aucune donnée privée n'est définie.

tracecmd_get_private_size renvoie la taille des données privées, ou 0 si aucune donnée privée n'est définie.

EXEMPLE


struct trace_event_file *event_file;
const char *my_data = "Données privées personnalisées";
size_t my_size = strlen(my_data) + 1;

// Obtenir un descripteur de fichier d'événement (supposons qu'il est déjà ouvert)
// event_file = ...;

// Définir les données privées
if (tracecmd_set_private(event_file, my_data, my_size) == 0) {
    printf("Données privées définies avec succès.\n");

    // Récupérer les données privées
    const void *retrieved_data = tracecmd_get_private(event_file);
    size_t retrieved_size = tracecmd_get_private_size(event_file);

    if (retrieved_data && retrieved_size > 0) {
        printf("Données privées récupérées : %s\n", (const char *)retrieved_data);
    }
} else {
    fprintf(stderr, "Erreur lors de la définition des données privées.\n");
}
