NOM

tracecmd_iterate_events, tracecmd_iterate_events_multi, tracecmd_follow_event, tracecmd_follow_missed_events, tracecmd_filter_add, tracecmd_iterate_reset - Lire les événements d'un fichier de trace

SYNTAXE

#include <trace-cmd.h>
int tracecmd_iterate_events(struct tracecmd_input *handle,
                            cpu_set_t *cpus, int cpu_size,
                            int (*callback)(struct tracecmd_input *,
                                            struct tep_record *,
                                            int, void *),
                            void *callback_data);
int tracecmd_iterate_events_multi(struct tracecmd_input **handles,
                                  int nr_handles,
                                  int (*callback)(struct tracecmd_input *,
                                                           struct tep_record *,
                                                           int, void *),
                                  void *callback_data);
int tracecmd_iterate_events_reverse(struct tracecmd_input *handle,
                            cpu_set_t *cpus, int cpu_size,
                            int (*callback)(struct tracecmd_input *,
                                            struct tep_record *,
                                            int, void *),
                            void *callback_data, bool cont);
int tracecmd_follow_event(struct tracecmd_input *handle,
                          const char *system, const char *event_name,
                          int (*callback)(struct tracecmd_input *,
                                          struct tep_event *,
                                          struct tep_record *,
                                          int, void *),
                          void *callback_data);
int tracecmd_follow_missed_events(struct tracecmd_input *handle,
                                   int (*callback)(struct tracecmd_input *,
                                                   struct tep_event *,
                                                   struct tep_record *,
                                                   int, void *),
                                   void *callback_data);
struct tracecmd_filter *tracecmd_filter_add(struct tracecmd_input handle,
                                            const char *filter_str, bool neg);
int *tracecmd_iterate_reset(struct tracecmd_input *handle);

DESCRIPTION

Cet ensemble d'API peut être utilisé pour itérer sur les événements après avoir ouvert un fichier de trace à l'aide de l'une des fonctions d'ouverture comme tracecmd_open(3) ou tracecmd_open_fd(3).

La fonction tracecmd_iterate_events() itérera sur tous les événements dans le fichier de trace défini par handle, où handle est retourné par l'une des fonctions tracecmd_open(3). Elle appellera la fonction callback() sur les événements des CPU définis par cpus. La taille cpu_size doit être la taille de cpus (voir CPU_SET(3)). Si cpus est NULL, alors cpu_size est ignoré et callback() sera appelé pour tous les événements sur tous les CPU du fichier de trace. La donnée callback_data est passée à la callback() en tant que dernier paramètre. callback peut être NULL, ce qui est utile si tracecmd_follow_event() est utilisé, mais notez que si callback est NULL, alors callback_data est ignoré et non envoyé à la callback de tracecmd_follow_event().

La fonction tracecmd_iterate_events_multi() est similaire à tracecmd_iterate_events() sauf qu'elle permet d'itérer sur plus d'un fichier de trace. Si tracecmd agent(1) est utilisé pour obtenir un fichier de trace pour l'hôte et l'invité, assurez-vous que le fichier de trace de l'hôte est la première entrée dans handles et tracecmd_iterate_events_multi() synchronisera les métadonnées pour les fichiers invités qui viennent plus tard dans handles. handles est un tableau de descripteurs de fichiers de trace qui ont été ouverts par tracecmd_open(3) et fonctions similaires. Notez que, contrairement à tracecmd_iterate_events(), tracecmd_iterate_events_multi() ne filtre pas sur les CPU, car cela rendrait l'API trop complexe pour savoir sur quel handle filtrer les CPU. Si le filtrage CPU est souhaité, alors la callback devrait vérifier record→cpu et retourner 0 si ce n'est pas le CPU désiré à traiter. nr_handles désigne le nombre d'éléments dans handles. La donnée callback_data est passée à la callback comme dernier paramètre. callback peut être NULL, ce qui est utile si tracecmd_follow_event() est utilisé, mais notez que si callback est NULL, alors callback_data est ignoré et non envoyé à la callback de tracecmd_follow_event().

La fonction tracecmd_iterate_events_reverse() fonctionne à peu près de la même manière que tracecmd_iterate_events(), mais au lieu d'appeler la fonction callback() pour chaque événement dans l'ordre des horodatages, elle appellera la fonction callback() pour chaque événement dans l'ordre inverse des horodatages. Si cont est faux, elle commencera par appeler l'événement avec le plus ancien horodatage dans le fichier trace.dat. Si cont est défini sur vrai, alors elle continuera là où se trouve la position actuelle des données de traçage. Par exemple, si la callback() retourne quelque chose d'autre que zéro, l'itération s'arrêtera. Si tracecmd_iterate_events_reverse() est appelé à nouveau avec cont à vrai, il continuera là où il s'est arrêté. Si cont est faux, il recommencera à l'événement avec le plus ancien horodatage. Les paramètres handle, cpus, cpu_size et callback_data agissent de la même manière que pour tracecmd_iterate_events().

La callback() pour à la fois tracecmd_iterate_events(), tracecmd_iterate_events_reverse() et tracecmd_iterate_events_multi() est du prototype :

int callback()(struct tracecmd_input *handle, struct tep_record *record, int cpu, void *data);

Le handle est le même handle passé à tracecmd_iterate_events() ou le handle actuel de handles passé à tracecmd_iterate_events_multi() auquel le record appartient. Le record est l'enregistrement de l'événement actuel. Le cpu est le CPU actuel en cours de traitement. Notez que pour tracecmd_iterate_events_multi(), il peut ne pas s'agir du CPU réel du fichier, mais du n-ième CPU de tous les handles combinés. Utilisez record→cpu pour obtenir le CPU réel sur lequel se trouve l'événement.

La fonction tracecmd_follow_event() s'attachera à un descripteur de fichier de trace handle et appellera la callback lorsque l'événement décrit par system et name correspondra à un événement dans l'itération de tracecmd_iterate_events() ou tracecmd_iterate_events_multi(). Notez que le cpu est le n-ième CPU pour tracecmd_iterate_events() et tracecmd_iterate_events_multi(). Si le CPU réel de record est nécessaire, utilisez record→cpu. Pour tracecmd_iterate_events_multi(), la callback n'est appelée que si le handle correspond au descripteur de fichier de trace actuel dans handles. La donnée callback_data est passée comme dernier paramètre à la fonction callback(). Notez que cette fonction callback() sera appelée avant la fonction callback() de soit tracecmd_iterate_events(), soit tracecmd_iterate_events_multi().

Le prototype de callback() pour *tracecmd_follow_event()_ est :

int callback()(struct tracecmd_input *handle, struct tep_event *event, struct tep_record *_record, int cpu, void *data);

La fonction tracecmd_follow_missed_events() s'attachera à un descripteur de fichier de trace handle et appellera la callback lorsque des événements manqués seront détectés. L' event contiendra le type d'événement que le record représente. Le record contiendra les informations des événements manqués. Le cpu est le n-ième CPU pour tracecmd_iterate_events() et tracecmd_iterate_events_multi(). Si le CPU auquel les événements manqués appartiennent est nécessaire, utilisez record→cpu. Si record→missed_events est un nombre positif, alors il contient le nombre d'événements manqués depuis le dernier événement sur son CPU, sinon il sera négatif, ce qui signifiera que le nombre d'événements manqués est inconnu mais que des événements manqués existent depuis le dernier événement sur le CPU. La callback et callback_data ont le même format que tracecmd_follow_event() ci-dessus. Les événements manqués

NOM

tracecmd_iterate_events, tracecmd_iterate_events_reverse, tracecmd_iterate_events_multi, tracecmd_filter_add, tracecmd_iterate_reset - Itérer sur les enregistrements de trace et ajouter des filtres.

SYNTAXIS

#include <trace-cmd.h>
int tracecmd_iterate_events(struct tracecmd_input *handle, cpu_set_t *cpuset, size_t cpusetsize, int (*callback)(struct tracecmd_input *handle, struct tep_record *record, int cpu, void *data), void *data);
int tracecmd_iterate_events_reverse(struct tracecmd_input *handle, cpu_set_t *cpuset, size_t cpusetsize, int (*callback)(struct tracecmd_input *handle, struct tep_record *record, int cpu, void *data), void *data);
int tracecmd_iterate_events_multi(struct tracecmd_input **handles, int nr_handles, int (*callback)(struct tracecmd_input *handle, struct tep_record *record, int cpu, void *data), void *data);
struct tracecmd_input *tracecmd_filter_add(struct tracecmd_input *handle, const char *filter_str, bool neg);
int tracecmd_iterate_reset(struct tracecmd_input *handle);

DESCRIPTION

La fonction tracecmd_iterate_events parcourt les enregistrements de trace contenus dans le handle. Si un cpuset et une cpusetsize sont fournis, seuls les événements provenant des CPU spécifiés dans le jeu de CPU seront traités. Sinon, tous les événements seront traités.

Si un callback est fourni, il sera appelé pour chaque enregistrement de trace lu. Les filtres ajoutés via tracecmd_filter_add seront appliqués avant l'appel de la fonction callback. Si la fonction callback renvoie une valeur non nulle, l'itérateur s'arrêtera avant d'appeler d'autres fonctions de rappel pour l'enregistrement donné.

La fonction tracecmd_iterate_events_reverse fonctionne de manière similaire à tracecmd_iterate_events, mais elle parcourt les événements dans l'ordre inverse.

La fonction tracecmd_iterate_events_multi itère sur plusieurs descripteurs de trace simultanément. Elle appelle la fonction callback pour chaque événement dans l'ordre chronologique, en tenant compte des événements de tous les descripteurs de trace combinés. Les filtres s'appliquent de la même manière que pour tracecmd_iterate_events.

La fonction tracecmd_filter_add ajoute un filtre au handle qui affecte à la fois tracecmd_iterate_events et tracecmd_iterate_events_multi. La chaîne filter_str définit un filtre dans un format spécifié par tep_filter_add_filter_str(3). Si neg est vrai, les événements qui correspondent au filtre seront ignorés, sinon les événements qui correspondent exécuteront la fonction callback() dans les itérateurs.

La fonction tracecmd_iterate_reset réinitialise le handle pour qu'il recommence au début. Ainsi, le prochain appel à tracecmd_iterate_events commencera à nouveau au premier événement, au lieu de continuer là où il s'est arrêté.

VALEUR DE RETOUR

Les fonctions tracecmd_iterate_events, tracecmd_iterate_events_reverse et tracecmd_iterate_events_multi renvoient zéro si elles ont parcouru avec succès tous les événements (en gérant correctement le suivi et les filtres). Ou une valeur d'erreur, qui peut inclure le retour d'un résultat non nul de la fonction callback().

tracecmd_iterate_reset renvoie 0 en cas de succès et -1 en cas d'erreur. Notez que si -1 est renvoyé, une réinitialisation partielle a pu également avoir lieu.

EXEMPLE

#define _GNU_SOURCE
#include <sched.h>
#include <stdlib.h>
#include <getopt.h>
#include <trace-cmd.h>
struct private_data {
        int             cpu;
        const char      *file;
};
static int print_events(struct tracecmd_input *handle, struct tep_record *record, int cpu, void *data)
{
        static struct trace_seq seq;
        struct tep_handle *tep = tracecmd_get_tep(handle);
        struct private_data *pdata = tracecmd_get_private(handle);
        /* Pour les descripteurs multiples nous avons besoin de ceci */
        if (pdata->cpu >= 0 && pdata->cpu != record->cpu)
                return 0;
        if (!seq.buffer)
                trace_seq_init(&seq);
        trace_seq_reset(&seq);
        trace_seq_printf(&seq, "%s: ", pdata->file);
        trace_seq_printf(&seq, "%6.1000d [%03d] %s-%d %s: %s\n",
                        TEP_PRINT_TIME, TEP_PRINT_CPU, TEP_PRINT_COMM, TEP_PRINT_PID,
                        TEP_PRINT_NAME, TEP_PRINT_INFO);
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
        return 0;
}
static int print_event(struct tracecmd_input *handle, struct tep_event *event,
                       struct tep_record *record, int cpu, void *data)
{
        return print_events(handle, record, cpu, data);
}
static int missed_events(struct tracecmd_input *handle, struct tep_event *event,
                         struct tep_record *record, int cpu, void *data)
{
        if (record->missed_events > 0)
                printf("CPU [%03d] a %d événements manqués\n",
                         record->cpu, record->missed_events);
        else
                printf("CPU [%03d] a des événements manqués\n", record->cpu);
        return 0;
}
static void usage(const char *argv0)
{
        printf("usage: [-c cpu][-f filtre][-e événement] %s trace.dat [trace.dat ...]\n",
               argv0);
        exit(-1);
}
int main(int argc, char **argv)
{
        struct tracecmd_input **handles = NULL;
        const char *filter_str = NULL;
        const char *argv0 = argv[0];
        struct private_data *priv;
        cpu_set_t *cpuset = NULL;
        char *event = NULL;
        size_t cpusize = 0;
        int nr_handles = 0;
        int cpu = -1;
        int i;
        int c;
        while ((c = getopt(argc, argv, "c:f:e:")) >= 0) {
                switch (c) {
                case 'c':
                        /* filtrer toutes les données de trace vers ce CPU unique. */
                        cpu = atoi(optarg);
                        break;
                case 'f':
                        filter_str = optarg;
                        break;
                case 'e':
                        event = optarg;
                        break;
                default:
                        usage(argv0);
                }
        }
        argc -= optind;
        argv += optind;
        if (argc == 0)
                usage(argv0);
        for (i = 0; i < argc; i++) {
                handles = realloc(handles, sizeof(*handles) * (nr_handles + 1));
                if (!handles)
                        exit(-1);
                handles[nr_handles] = tracecmd_open(argv[i], 0);
                if (!handles[nr_handles]) {
                        perror(argv[i]);
                        exit(-1);
                }
                if (filter_str) {
                        if (tracecmd_filter_add(handles[nr_handles], filter_str, false) == NULL) {
                                perror("ajout du filtre");
                                exit(-1);
                        }
                }
                priv = calloc(1, sizeof(*priv));
                if (!priv)
                        exit(-1);
                priv->file = argv[i];
                priv->cpu = cpu;
                tracecmd_set_private(handles[nr_handles], priv);
                if (event) {
                        if (tracecmd_follow_event(handles[nr_handles], NULL, event, print_event, NULL) < 0) {
                                printf("Impossible de suivre l'événement %s pour le fichier %s\n", event, argv[i]);
                                exit(-1);
                        }
                }
                tracecmd_follow_missed_events(handles[nr_handles], missed_events, NULL);
                nr_handles++;
        }
        /* Raccourci */
        if (nr_handles == 1) {
                if (cpu >= 0) {
                        cpuset = CPU_ALLOC(cpu + 1);
                        if (!cpuset)
                                exit(-1);
                        cpusize = CPU_ALLOC_SIZE(cpu + 1);
                        CPU_SET_S(cpu, cpusize, cpuset);
                }
                if (event)
                        tracecmd_iterate_events(handles[0], cpuset, cpusize, NULL, NULL);
                else
                        tracecmd_iterate_events(handles[0], cpuset, cpusize, print_events, NULL);
        } else {
                if (event)
                        tracecmd_iterate_events_multi(handles, nr_handles, NULL, NULL);
                else
                        tracecmd_iterate_events_multi(handles, nr_handles, print_events, NULL);
        }
        for (i = 0; i < nr_handles; i++) {
                priv = tracecmd_get_private(handles[i]);
                free(priv);
                tracecmd_close(handles[i]);
        }
        free(handles);
}
