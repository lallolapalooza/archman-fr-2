CTRCON

Objectif :

!>
!> CTRCON estime le réciproque du nombre de condition d'une
!> matrice triangulaire A, dans la norme 1 ou la norme infini.
!>
!> La norme de A est calculée et une estimation est obtenue pour
!> norm(inv(A)), puis le réciproque du nombre de condition est
!> calculé comme
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Paramètres

NORM 
!>          NORM est CARACTERE*1
!>          Spécifie si le nombre de condition en norme 1 ou en norme
!>          infini est requis :
!>          = '1' ou 'O':  norme 1 ;
!>          = 'I':         norme infini.
!>

UPLO

!>          UPLO est CARACTERE*1
!>          = 'U':  A est triangulaire supérieure ;
!>          = 'L':  A est triangulaire inférieure.
!>

DIAG

!>          DIAG est CARACTERE*1
!>          = 'N':  A est triangulaire non unitaire ;
!>          = 'U':  A est triangulaire unitaire.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPOSITE, dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire de taille N-par-N de A contient la
!>          matrice triangulaire supérieure, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée.  Si UPLO = 'L',
!>          la partie inférieure triangulaire de taille N-par-N de A
!>          contient la matrice triangulaire inférieure, et la partie
!>          strictement supérieure triangulaire de A n'est pas référencée.
!>          Si DIAG = 'U', les éléments diagonaux de A ne sont pas non plus
!>          référencés et sont supposés être 1.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

RCOND

!>          RCOND est REEL
!>          Le réciproque du nombre de condition de la matrice A,
!>          calculé comme RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK est un tableau COMPOSITE, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau REEL, dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument était illégal
!>

NAME

trcon — estimate the reciprocal of the condition number of a triangular matrix

SYNOPSIS

  SUBROUTINE STRCON(NORM, UPLO, DIAG, N, A, LDA, RCOND, WORK, INFO)
      CHARACTER          NORM, UPLO, DIAG
      INTEGER            N, LDA, INFO
      REAL               A(LDA, *), WORK(*)
      REAL               RCOND

      SUBROUTINE DTRCON(NORM, UPLO, DIAG, N, A, LDA, RCOND, WORK, INFO)
      CHARACTER          NORM, UPLO, DIAG
      INTEGER            N, LDA, INFO
      DOUBLE PRECISION   A(LDA, *), WORK(*), RCOND

      SUBROUTINE CTRCON(NORM, UPLO, DIAG, N, A, LDA, RCOND, WORK, INFO)
      CHARACTER          NORM, UPLO, DIAG
      INTEGER            N, LDA, INFO
      REAL               RCOND
      COMPLEX            A(LDA, *), WORK(*)

      SUBROUTINE ZTRCON(NORM, UPLO, DIAG, N, A, LDA, RCOND, WORK, INFO)
      CHARACTER          NORM, UPLO, DIAG
      INTEGER            N, LDA, INFO
      DOUBLE PRECISION   RCOND
      COMPLEX*16         A(LDA, *), WORK(*)

Detailed Description

This routine estimates the reciprocal of the condition number of a triangular matrix A. The condition number is computed in the 1-norm or infinity-norm.

The function estimates norm(inv(A)) and then computes RCOND = 1 / (norm(A) * norm(inv(A))).

A is a triangular matrix A. The condition number estimate is computed in three-stage:

  1. The norm of A is computed.
  2. An estimate of the norm of the inverse of A is computed.
  3. The reciprocal of the condition number is computed.

The routine is called after a factorization of A. For example, if A = P*L*U*Q, then RCOND is computed for L, U, P*L, or U*Q.

The input matrix A is a triangular matrix.

subroutine strcon (character norm, character uplo, character diag, integer n, real, dimension( lda, * ) a, integer lda, real rcond, real, dimension( * ) work, integer info)

STRCON

Purpose:

!>
!> STRCON estimates the reciprocal of the condition number of a
!> triangular matrix A, in either the 1-norm or the infinity-norm.
!>
!> The norm of A is computed and an estimate is obtained for
!> norm(inv(A)), then the reciprocal of the condition number is
!> computed as
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Parameters

NORM 
!>          NORM is CHARACTER*1
!>          Specifies whether the 1-norm condition number or the
!>          infinity-norm condition number is required:
!>          = '1' or 'O':  1-norm;
!>          = 'I':         Infinity-norm.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          = 'U':  A is upper triangular;
!>          = 'L':  A is lower triangular.
!>

DIAG

!>          DIAG is CHARACTER*1
!>          = 'N':  A is non-unit triangular;
!>          = 'U':  A is unit triangular.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          The triangular matrix A.  If UPLO = 'U', the leading N-by-N
!>          upper triangular part of the array A contains the upper
!>          triangular matrix, and the strictly lower triangular part of
!>          A is not referenced.  If UPLO = 'L', the leading N-by-N lower
!>          triangular part of the array A contains the lower triangular
!>          matrix, and the strictly upper triangular part of A is not
!>          referenced.  If DIAG = 'U', the diagonal elements of A are
!>          also not referenced and are assumed to be 1.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

RCOND

!>          RCOND is REAL
!>          The reciprocal of the condition number of the matrix A,
!>          computed as RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK is REAL array, dimension (3*N)
!>

IWORK

!>          IWORK is INTEGER array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
