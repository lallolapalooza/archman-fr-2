NOM

tracefs_synth_create, tracefs_synth_destroy, tracefs_synth_complete, tracefs_synth_trace, tracefs_synth_snapshot, tracefs_synth_save, tracefs_synth_set_instance, - Création d'événements synthétiques

SYNOPSIS

#include <tracefs.h>
int tracefs_synth_create(struct tracefs_synth *synth);
int tracefs_synth_destroy(struct tracefs_synth *synth);
bool tracefs_synth_complete(struct tracefs_synth *synth);
int tracefs_synth_set_instance(struct tracefs_synth *synth, struct tracefs_instance *instance);
int tracefs_synth_trace(struct tracefs_synth *synth,
                        enum tracefs_synth_handler type, const char *var);
int tracefs_synth_snapshot(struct tracefs_synth *synth,
                           enum tracefs_synth_handler type, const char *var);
int tracefs_synth_save(struct tracefs_synth *synth,
                       enum tracefs_synth_handler type, const char *var,
                       char **save_fields);

DESCRIPTION

Les événements synthétiques sont des événements dynamiques qui sont créés en faisant correspondre deux autres événements qui déclenchent un événement synthétique. Un événement est l'événement de départ dont un champ est enregistré, et lorsque le second événement est exécuté, s'il a un champ (ou des champs) qui correspond au champ (ou aux champs) de l'événement de départ, alors il déclenche l'événement synthétique. Les valeurs des champs autres que les champs correspondants peuvent être transmises de l'événement de départ à l'événement de fin pour effectuer des calculs, ou simplement pour les passer en tant que paramètre à l'événement synthétique.

Un cas d'utilisation courant est de définir "sched_waking" comme événement de départ. Cet événement est déclenché lorsqu'un processus est réveillé. Ensuite, définissez "sched_switch" comme événement de fin. Cet événement est déclenché lorsqu'une nouvelle tâche est planifiée sur le CPU. En définissant le "common_pid" des deux événements comme champs correspondants, le temps entre les deux événements est considéré comme la latence de réveil de ce processus. Utilisez TRACEFS_TIMESTAMP comme champ pour les deux événements afin de calculer la différence en nanosecondes, ou utilisez TRACEFS_TIMESTAMP_USECS comme champs de comparaison pour les deux événements afin de calculer la différence en microsecondes. Ceci est utilisé comme exemple ci-dessous.

tracefs_synth_create() crée l'événement synthétique dans le système. Par défaut, les déclencheurs d'histogramme sont créés dans l'instance de trace supérieure, car tout événement synthétique peut être utilisé globalement dans toutes les instances. Si une application souhaite exclure les déclencheurs d'histogramme de l'instance de niveau supérieur, elle peut utiliser tracefs_synth_set_instance() pour que les histogrammes soient utilisés pour créer l'événement synthétique dans une instance autre que le niveau supérieur. Un descripteur d'événement synthétique doit être créé avec tracefs_synth_alloc(3) avant que cela puisse être utilisé pour le créer sur le système.

tracefs_synth_destroy() détruit l'événement synthétique. Il tentera d'arrêter son exécution dans son instance (par défaut, la supérieure), mais s'il s'exécute dans une autre instance, cela peut échouer car occupé.

tracefs_synth_complete() renvoie vrai si l'événement synthétique synth a un événement de départ et un événement de fin.

tracefs_synth_trace() Au lieu de simplement tracer lors de la correspondance des événements de départ et de fin, effectue le gestionnaire type où TRACEFS_SYNTH_HANDLE_MAX tracera lorsque la variable var donnée atteindra un nouveau maximum pour les clés correspondantes. Ou TRACEFS_SYNTH_HANDLE_CHANGE lorsque var change. var doit être l'un des éléments name utilisés dans tracefs_synth_add_end_field(3).

tracefs_synth_snapshot() Lorsque la variable var donnée est soit un nouveau maximum si handler est TRACEFS_SYNTH_HANDLE_MAX, soit simplement changée si TRACEFS_SYNTH_HANDLE_CHANGE, prend alors un « instantané » du tampon. L'instantané déplace le tampon de « trace » normal vers un tampon « instantané », qui peut être accessible via le fichier « snapshot » dans le répertoire tracefs de niveau supérieur, ou l'une des instances. var change. var doit être l'un des éléments name utilisés dans tracefs_synth_add_end_field(3).

tracefs_synth_save() Lorsque la variable var donnée est soit un nouveau maximum si handler est TRACEFS_SYNTH_HANDLE_MAX, soit simplement changée si TRACEFS_SYNTH_HANDLE_CHANGE, enregistre alors la liste save_fields donnée. Les champs seront stockés dans le fichier « hist » de l'histogramme de l'événement, qui peut être récupéré avec tracefs_event_file_read(3). var doit être l'un des éléments name utilisés dans tracefs_synth_add_end_field(3).

tracefs_synth_set_instance() Définit l'instance de trace, où les déclencheurs d'histogramme qui créent l'événement synthétique seront créés. Par défaut, l'instance supérieure est utilisée. Cette API doit être appelée avant l'appel à tracefs_synth_create(), afin d'utiliser la nouvelle instance lors de la création de l'événement. Notez que même si l'événement synthétique est créé dans une instance, il est toujours visible par toutes les autres instances, y compris le niveau supérieur. C'est-à-dire que d'autres instances peuvent activer l'événement synthétique créé et le faire tracer dans les tampons appartenant à l'instance qui l'a activé.

VALEUR RENVOYÉE

Toutes les fonctions renvoient zéro en cas de succès ou -1 en cas d'erreur.

ERREURS

Les erreurs suivantes concernent tous les appels ci-dessus :

EPERM Non exécuté en tant qu'utilisateur root lorsque requis.

EINVAL Soit un paramètre n'est pas valide (NULL alors qu'il ne devrait pas l'être), soit un champ n'est pas compatible pour les calculs.

ENODEV Un événement ou l'un de ses champs est introuvable.

EBADE Les champs des événements de départ et de fin ne sont pas compatibles pour la correspondance ou la comparaison.

ENOMEM pas assez de mémoire disponible.

Et d'autres erreurs peuvent s'être produites lors des appels système au système.

EXEMPLE

Voir tracefs_sql(3) pour une utilisation plus approfondie de certains de ces codes.

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Charger tous les événements du système */
        tep = tracefs_local_events(NULL);
        /* Initialiser l'événement synthétique */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* Le tep n'est plus nécessaire */
        tep_free(tep);
        /* Sauvegarder le champ "prio" comme "prio" de l'événement de départ */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Sauvegarder le champ "next_comm" comme "comm" de l'événement de fin */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Sauvegarder le champ "prev_prio" comme "prev_prio" de l'événement de fin */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Calculer la différence en microsecondes entre la fin et le début
         * et l'enregistrer comme "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* N'enregistrer que si le "prio" de l'événement de départ est inférieur à 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * N'enregistrer que si le "next_prio" de l'événement de fin est inférieur à 50
         * ou si le prio de la tâche précédente n'était pas supérieur ou égal à 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL)
