NOM

tracecmd_set_loglevel - Définit le niveau de journalisation de la bibliothèque

SYNTAXE

#include <trace-cmd.h>
int tracecmd_set_loglevel(enum tep_loglevel level);

DESCRIPTION

La fonction tracecmd_set_loglevel() définit le niveau des journaux de la bibliothèque qui seront affichés sur la console. Voir libtraceevent(3) pour une description détaillée des niveaux de journalisation. Définir le niveau de journalisation à une valeur spécifique signifie que les journaux des niveaux précédents seront également affichés. Par exemple, TEP_LOG_WARNING affichera tous les journaux dont la sévérité est TEP_LOG_WARNING, TEP_LOG_ERROR et TEP_LOG_CRITICAL. Le niveau de journalisation par défaut est TEP_LOG_CRITICAL. Lorsqu'un nouveau niveau est défini, il est également propagé à libtracefs et libtraceevent.

EXEMPLE

#include <trace-cmd.h>
...
tracecmd_set_loglevel(TEP_LOG_ALL);
...
/* appelez les API de libtracecmd, libtracefs ou libtraceevent et observez les journaux qu'elles produisent */
...
tracecmd_set_loglevel(TEP_LOG_CRITICAL);
