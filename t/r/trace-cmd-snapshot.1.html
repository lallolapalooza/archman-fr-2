NOM

trace-cmd-snapshot - prendre, réinitialiser, libérer ou afficher un instantané du noyau Ftrace

SYNTAXE

trace-cmd snapshot [OPTIONS]

DESCRIPTION

Le cliché instantané de trace-cmd(1) contrôle ou affiche la fonctionnalité d'instantané du noyau Linux Ftrace (si le noyau la supporte). Ceci est utile pour "geler" une instance d'un traçage en direct mais sans arrêter le traçage.

 trace-cmd start -p function
 trace-cmd snapshot -s
 trace-cmd snapshot
[ déverse le contenu du tampon à 'trace-cmd snapshot -s' ]
 trace-cmd snapshot -s
 trace-cmd snapshot
[ déverse le nouveau contenu du tampon de la dernière opération -s ]

OPTIONS

-s

Prendre un cliché instantané du tampon en cours d'exécution.

-r

Effacer le tampon.

-f

Libérer le tampon d'instantané. Le tampon occupe de la mémoire dans le noyau. Il est préférable de le libérer lorsqu'il n'est pas utilisé. La première opération -s l'allouera s'il n'est pas déjà alloué.

-c cpu

Opérer sur un cliché instantané par CPU (peut ne pas être entièrement pris en charge par tous les noyaux)

-B tampon

Si une instance de tampon a été créée, l'option -B opérera sur le cliché instantané dans le tampon.
