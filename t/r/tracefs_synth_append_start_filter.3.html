DESCRIPTION

Les événements synthétiques sont des événements dynamiques qui sont créés en faisant correspondre deux autres événements, ce qui déclenche un événement synthétique. Un événement est l'événement de départ dont un champ est enregistré, et lorsque le second événement est exécuté, s'il possède un champ (ou des champs) qui correspond au champ (ou aux champs) de l'événement de départ, alors il déclenchera l'événement synthétique. Les valeurs des champs autres que les champs correspondants peuvent être transmises de l'événement de départ à l'événement de fin pour effectuer des calculs, ou simplement pour être transmises en tant que paramètre à l'événement synthétique.

Un cas d'utilisation courant consiste à définir "sched_waking" comme événement de départ. Cet événement est déclenché lorsqu'un processus est réveillé. Ensuite, définir "sched_switch" comme événement de fin. Cet événement est déclenché lorsqu'une nouvelle tâche est planifiée sur le CPU. En définissant le "common_pid" des deux événements comme champs correspondants, le temps entre les deux événements est considéré comme la latence de réveil de ce processus. Utilisez TRACEFS_TIMESTAMP comme champ pour les deux événements afin de calculer la différence en nanosecondes, ou utilisez "*TRACEFS_TIMESTAMP_USECS" comme champs de comparaison pour les deux événements afin de calculer la différence en microsecondes. Ceci est utilisé comme exemple ci-dessous.

tracefs_synth_alloc() alloue et initialise un événement synthétique. Il ne crée pas l'événement synthétique, mais fournit les informations minimales pour le faire. Voir tracefs_synth_create(3) pour savoir comment créer l'événement synthétique dans le système. Il nécessite un gestionnaire tep qui peut être créé par tracefs_local_events(3) pour plus d'informations. Le name contient le nom de l'événement synthétique qui sera créé. Le start_system est le nom du système pour l'événement de départ. Il peut être NULL et le premier événement portant le nom de start_event sera choisi. Le end_system est le nom du système pour l'événement de fin. Il peut être NULL et le premier événement portant le nom de end_event sera choisi comme événement de fin. Si match_name est fourni, alors ce sera le champ de l'événement synthétique créé qui contiendra les clés correspondantes du start_match_field de l'événement de départ et du end_match_field de l'événement de fin. Si match_name est NULL, alors il ne sera pas enregistré dans l'événement synthétique créé.

tracefs_synth_add_match_field() ajoutera une deuxième clé pour faire correspondre l'événement de départ et l'événement de fin. Si name est fourni, alors le contenu du champ correspondant sera sauvegardé sous ce name dans l'événement synthétique. Le start_match_field est le champ de l'événement de départ à faire correspondre avec le end_match_field de l'événement de fin.

tracefs_synth_add_compare_field() est utilisé pour comparer le start_compare_field de l'événement de départ avec le end_compare_field de l'événement de fin. Le name doit être fourni afin que le résultat soit sauvegardé par l'événement synthétique. Il n'a aucun sens de ne pas passer cela à l'événement synthétique après avoir effectué le travail des champs comparés, car il n'a aucun autre but. Le paramètre calc peut être l'un des suivants :

TRACEFS_SYNTH_DELTA_END - calculer la différence entre le contenu de end_compare_field et le contenu de start_compare_field.

name = end_compare_field - start_compare_field

TRACEFS_SYNTH_DELTA_START - calculer la différence entre le contenu de start_compare_field et le contenu de end_compare_field.

name = start_compare_field - end_compare_field

TRACEFS_SYNTH_ADD - Ajouter le contenu de start_compare_field au contenu de end_compare_field.

name = start_compare_field + end_compare_field

tracefs_synth_add_start_field() - Enregistre le start_field de l'événement de départ sous le nom name dans l'événement synthétique. Si name est NULL, alors le nom utilisé sera le même que start_field.

tracefs_synth_add_end_field() - Enregistre le end_field de l'événement de fin sous le nom name dans l'événement synthétique. Si name est NULL, alors le nom utilisé sera le même que end_field.

tracefs_synth_append_start_filter() crée un filtre ou y ajoute des éléments pour l'événement de départ. Selon type, il construira une chaîne de jetons pour les parenthèses ou les instructions logiques, ou il pourra ajouter une comparaison de field à val basée sur compare.

Si type est : TRACEFS_FILTER_COMPARE - Voir ci-dessous TRACEFS_FILTER_AND - Ajoute "&&" au filtre TRACEFS_FILTER_OR - Ajoute "||" au filtre TRACEFS_FILTER_NOT - Ajoute "!" au filtre TRACEFS_FILTER_OPEN_PAREN - Ajoute "(" au filtre TRACEFS_FILTER_CLOSE_PAREN - Ajoute ")" au filtre

field, compare et val sont ignorés sauf si type est égal à TRACEFS_FILTER_COMPARE, alors _compare sera utilisé pour les éléments suivants :

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ "val" : où field est une chaîne.

TRACEFS_COMPARE_AND - field & val : où field est un champ de drapeaux.

tracefs_synth_append_end_filter() est identique à tracefs_synth_append_start_filter mais filtre sur l'événement de fin.

tracefs_synth_free() libère le descripteur alloué retourné par tracefs_synth_alloc().

tracefs_synth_alloc - allouer et initialiser un descripteur d'événement synthétique

SYNOPSIS

#include <tracefs.h>

struct tracefs_synth * tracefs_synth_alloc( struct tep_handle * handle, const char * name, const char * type, const char * start_event, const char * start_event_type, const char * end_event, const char * end_event_type, const char * match_field, const char * diff_field );

int tracefs_synth_add_end_field( struct tracefs_synth * synth, const char * field, const char * name );

int tracefs_synth_add_compare_field( struct tracefs_synth * synth, const char * start_field, const char * end_field, enum tracefs_synth_field_op op, const char * name );

int tracefs_synth_append_start_filter( struct tracefs_synth * synth, enum tracefs_filter_type type, const char * field, enum tracefs_compare_op op, const char * value );

int tracefs_synth_append_end_filter( struct tracefs_synth * synth, enum tracefs_filter_type type, const char * field, enum tracefs_compare_op op, const char * value );

int tracefs_synth_create( struct tracefs_synth * synth );

int tracefs_synth_destroy( struct tracefs_synth * synth );

int tracefs_synth_echo_cmd( struct trace_seq * s, struct tracefs_synth * synth );

void tracefs_synth_free( struct tracefs_synth * synth );

DESCRIPTION

The tracing subsystem allows for creating synthetic events. These are events that are not generated by the kernel directly, but are created by user-space programs. They can be used to correlate events from different sources, or to create new events based on existing ones.

The tracefs library provides functions to create and manage synthetic events.

tracefs_synth_alloc() allocates and initializes a structure for a synthetic event. The parameters specify the event tracing handle, the name of the synthetic event, the type of the synthetic event (can be NULL), the start and end events that will be used to generate the synthetic event, the type of the start and end events (can be NULL), the field to be used to match the start and end events, and the field to be used to calculate the difference between the start and end events.

tracefs_synth_add_start_field() adds a field from the start event to the synthetic event. The field name in the start event is specified by field, and the name of the field in the synthetic event is specified by name. If name is NULL, the field will have the same name as in the start event.

tracefs_synth_add_end_field() adds a field from the end event to the synthetic event. The field name in the end event is specified by field, and the name of the field in the synthetic event is specified by name. If name is NULL, the field will have the same name as in the end event.

tracefs_synth_add_compare_field() adds a field to the synthetic event that is calculated based on the difference between a field in the start event and a field in the end event. The op parameter specifies the operation to be performed. The result is stored in the synthetic event under the name specified by name.

tracefs_synth_append_start_filter() appends a filter condition to the start event. Only events that satisfy the filter condition will be considered as start events. The filter condition is specified by type, field, op, and value.

tracefs_synth_append_end_filter() appends a filter condition to the end event. Only events that satisfy the filter condition will be considered as end events. The filter condition is specified by type, field, op, and value.

tracefs_synth_create() creates the synthetic event in the kernel. This function should be called after all fields and filters have been added to the synthetic event.

tracefs_synth_destroy() destroys the synthetic event in the kernel.

tracefs_synth_echo_cmd() prints the command that would be used to create the synthetic event to the given trace_seq structure. This can be useful for debugging.

tracefs_synth_free() frees the memory allocated for the synthetic event descriptor.

RETURN VALUE

tracefs_synth_alloc() returns an allocated struct tracefs_synth descriptor on success or NULL on error.

All other functions that return an integer returns zero on success or -1 on error.

ERRORS

The following errors are for all the above calls:

EPERM Not run as root user when required.

EINVAL Either a parameter is not valid (NULL when it should not be) or a field that is not compatible for calculations.

ENODEV An event or one of its fields is not found.

EBADE The fields of the start and end events are not compatible for either matching or comparing.

ENOMEM not enough memory is available.

And more errors may have happened from the system calls to the system.

EXAMPLE

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Load all events from the system */
        tep = tracefs_local_events(NULL);
        /* Initialize the synthetic event */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* The tep is no longer needed */
        tep_free(tep);
        /* Save the "prio" field as "prio" from the start event */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Save the "next_comm" as "comm" from the end event */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Save the "prev_prio" as "prev_prio" from the end event */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Take a microsecond time difference between end and start
         * and record as "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Only record if start event "prio" is less than 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Only record if end event "next_prio" is less than 50
         * or the previous task's prio was not greater than or equal to 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Note, the above only added: "next_prio < 50 || !(prev_prio >= 100"
         * That's because, when the synth is executed, the remaining close parenthesis
         * will be added. That is, the string will end up being:
         * "next_prio < 50 || !(prev_prio >= 100)" when one of tracefs_sync_create()
         * or tracefs_sync_echo_cmd() is run.
         */
}
/* Display how to create the synthetic event */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Create the synthetic event */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Delete the synthetic event */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}

tracefs_synth_append_start_filter — ajoute un filtre à une chaîne de filtres synthétiques.

Syntaxe

#include <tracefs.h>

int tracefs_synth_append_start_filter(
    tracefs_synth_handle_t handle,
    const char *filter
);

Description

La fonction tracefs_synth_append_start_filter ajoute le filtre spécifié par filter à la chaîne de filtres synthétiques ouverte par tracefs_synth_open. Le filtre est ajouté à la fin de la chaîne de filtres existante. Si la chaîne de filtres est vide, le filtre sera le premier de la chaîne.

La chaîne de filtres est traitée de gauche à droite par le noyau lors du filtrage des événements. Un événement doit correspondre à tous les filtres de la chaîne pour être considéré comme correspondant.

La chaîne filter doit être terminée par un caractère nul.

La fonction échoue si la chaîne de filtres atteint la limite de taille maximale autorisée par le noyau.

Valeur renvoyée

En cas de succès, renvoie 0. En cas d'erreur, renvoie un nombre négatif et définit errno de manière appropriée.

Erreurs

EINVAL : Le handle handle n'est pas valide ou la chaîne filter est invalide (par exemple, trop longue).

ENOMEM : Pas assez de mémoire pour allouer la nouvelle chaîne de filtres.

EACCES : Permission refusée pour ajouter un filtre.

Exemple

#include <tracefs.h>
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    tracefs_synth_handle_t handle;
    int ret;

    handle = tracefs_synth_open();
    if (!handle) {
        perror("tracefs_synth_open");
        return EXIT_FAILURE;
    }

    ret = tracefs_synth_append_start_filter(handle, "sched:*");
    if (ret < 0) {
        fprintf(stderr, "Failed to add filter 'sched:*': %d\n", ret);
        tracefs_synth_close(handle);
        return EXIT_FAILURE;
    }

    ret = tracefs_synth_append_start_filter(handle, "syscalls:sys_enter_*");
    if (ret < 0) {
        fprintf(stderr, "Failed to add filter 'syscalls:sys_enter_*': %d\n", ret);
        tracefs_synth_close(handle);
        return EXIT_FAILURE;
    }

    printf("Filtres ajoutés avec succès.\n");

    tracefs_synth_close(handle);
    return EXIT_SUCCESS;
}
