NOM

trace-cmd-reset - désactive le traçage Ftrace pour rétablir les performances complètes

SYNOPSIS

trace-cmd reset [OPTIONS]

DESCRIPTION

La commande trace-cmd(1) reset désactive tout traçage Ftrace. Ceci rétablira les performances du système avant l'activation du traçage. C'est nécessaire car trace-cmd-record(1), trace-cmd-stop(1) et trace-cmd-extract(1) ne désactivent pas le traceur, même après que les données aient été extraites des buffers. La raison est que l'utilisateur pourrait vouloir activer manuellement le traceur avec le système de fichiers pseudo Ftrace, ou examiner d'autres parties de Ftrace pour voir ce que trace-cmd a fait. Après l'exécution de la commande reset, les données dans le tampon circulaire (ring buffer), et les options qui ont été utilisées sont toutes perdues.

OPTIONS

Veuillez noter que l'ordre des options spécifiées sur la ligne de commande est important. Voir EXEMPLES.

-b taille_buffer

Lorsque le noyau démarre, le tampon circulaire Ftrace est de taille minimale (3 pages par CPU). La première fois que le traceur est utilisé, la taille du tampon circulaire s'agrandit pour atteindre celle qui lui a été définie (1.4 Mo par CPU par défaut). 
Si plus aucun traçage n'est prévu, cette option permet de réduire la
taille du tampon circulaire pour libérer de la mémoire disponible.
trace-cmd reset -b 1
L'instance de tampon affectée est celle (ou celles) spécifiée(s) par
l'option *-B*, *-t*, ou *-a* la plus récemment précédant cette option :
Lorsqu'elle est utilisée après *-B*, redimensionne l'instance de tampon
qui la précède sur la ligne de commande.
Lorsqu'elle est utilisée après *-a*, redimensionne toutes les instances
de tampon sauf la principale.
Lorsqu'elle est utilisée après *-t* ou avant toute option *-B* ou *-a*,
redimensionne l'instance principale.

-B nom_buffer

Si le noyau supporte plusieurs tampons, ceci réinitialisera le traçage uniquement pour le tampon donné. Cela n'affectera aucun autre tampon. Cette option peut être utilisée plusieurs fois pour spécifier différents tampons. Le tampon de niveau supérieur ne sera pas réinitialisé si cette option est donnée (sauf si l'option -t est également fournie).

-a

Réinitialise le traçage pour toutes les instances de tampon existantes. Lorsque cette option est utilisée, l'instance de niveau supérieur ne sera pas réinitialisée à moins que -t ne soit fourni.

-d

Cette option supprime le(s) tampon(s) d'instance spécifié(s) par l'option -B ou -a la plus récemment précédant. Comme le tampon d'instance de niveau supérieur ne peut pas être supprimé, il est invalide de l'utiliser immédiatement après -t ou avant toute option -B ou -a sur la ligne de commande.

-t

Réinitialise le tampon d'instance de niveau supérieur. Sans l'option -B ou -a, c'est le comportement par défaut. Mais si -B ou -a est utilisé, ceci est requis si le tampon d'instance de niveau supérieur doit également être réinitialisé.

-k nom_dynevent

Cette option permet de préserver des événements dynamiques spécifiés pendant la réinitialisation. Les paramètres valides sont kprobe, kretprobe, uprobe, uretprobe, eprobe, synth et all (pour conserver tous les événements dynamiques). Ceci peut être utilisé plusieurs fois pour spécifier différents types d'événements dynamiques.

EXEMPLES

Réinitialiser le traçage pour instance-one et définir sa taille de tampon par CPU à 4096 Ko. Supprime également instance-two. Le niveau supérieur et toute autre instance restent inchangés :

trace-cmd reset -B instance-one -b 4096 -B instance-two -d

Supprimer tous les tampons d'instance. Le niveau supérieur reste inchangé :

trace-cmd reset -a -d

Supprimer tous les tampons d'instance et réinitialiser également le niveau supérieur :

trace-cmd reset -t -a -d

Invalide. Cette commande implique une tentative de suppression du niveau supérieur :

trace-cmd reset -a -t -d

Réinitialiser le niveau supérieur et définir sa taille de tampon par CPU à 1024 Ko. Si des tampons d'instance existent, ils resteront inchangés :

trace-cmd reset -b 1024

Empêcher la destruction des kprobes et kretprobes pendant la réinitialisation :

trace-cmd reset -k kprobe -k kretprobe
