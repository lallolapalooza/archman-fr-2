NOM

transmission-remote — utilitaire de contrôle à distance pour transmission-daemon(1) et transmission(1)

SYNTAXE

transmission-remote [hôte:port | hôte | port] [-a noms-de-fichiers-ou-URL] [-as] [-AS] [-asd nombre] [-asu nombre] [-asc] [-ASC] [-b] [-c chemin | -C] [-d nombre | -D] [-e taille] [-er | -ep | -et] [--exit] [-f] [-F filtre] [-g fichiers] [-G fichiers] [-gsr ratio] [-GSR] [-h] [-i] [-ic] [-ids] [-if] [-ip] [-it] [-j] [-l] [-m | -M] [-n utilisateur:motdepasse] [-ne] [-N netrc] [-o | -O] [-p port] [-Bh] [-Bn] [-Bl] [-ph fichiers] [-pl fichiers] [-pn fichiers] [-pr pairs] [-r] [-rad] [-s | -S] [-sr ratio] [-SR] [-srd] [-si] [-st] [-t tous | actif | id | hash] [-hl] [-HL] [-u nombre | -U] [-utp | -no-utp] [-v] [-V] [-w dossier-telechargement] [-x | -X] [-y | -Y] [-pi]

DESCRIPTION

transmission-remote est un utilitaire de contrôle à distance pour transmission(1) et transmission-daemon(1).

Par défaut, transmission-remote se connecte à la session transmission sur localhost:9091. D'autres sessions peuvent être contrôlées en spécifiant un hôte et/ou un port différent.

OPTIONS

-a --add noms-de-fichiers-ou-URL
Ajoute des torrents à transmission.
-b --debug
Active le mode débogage.
-as --alt-speed
Utilise les limites alternatives.
-AS --no-alt-speed
N'utilise pas les limites alternatives.
-asd --alt-speed-downlimit limite
Limite la vitesse de téléchargement alternative à limite kilooctets par seconde.
-asu --alt-speed-uplimit limite
Limite la vitesse d'envoi alternative à limite kilooctets par seconde.
-asc --alt-speed-scheduler
Utilise la planification horaire d'activation/désactivation.
-ASC --no-alt-speed-scheduler
N'utilise pas la planification des jours et heures d'activation/désactivation des limites alternatives.
--alt-speed-time-begin heure
Heure à laquelle commencer à utiliser les limites de vitesse alternatives (au format hhmm).
--alt-speed-time-end heure
Heure à laquelle arrêter d'utiliser les limites de vitesse alternatives (au format hhmm).
--alt-speed-days jours
Définit le nombre de jours pendant lesquels activer le planificateur de vitesse, en utilisant une liste telle que "2,4-6".
--torrent-done-script nom-de-fichier
Spécifie un fichier à exécuter chaque fois qu'un torrent se termine.
--no-torrent-done-script
N'exécute aucun script lorsqu'un torrent se termine.
-c --incomplete-dir dossier
Lors de l'ajout de nouveaux torrents, stocke leur contenu dans le dossier jusqu'à ce que le torrent soit terminé.
-C --no-incomplete-dir
Ne stocke pas les torrents incomplets dans un dossier différent.
-d --downlimit limite
Limite la vitesse de téléchargement maximale à limite Ko/s. Si le(s) torrent(s) actuel(s) est/sont sélectionné(s), cela s'applique à eux. Sinon, cela modifie le paramètre global.
-D --no-downlimit
Désactive les limites de vitesse de téléchargement. Si le(s) torrent(s) actuel(s) est/sont sélectionné(s), cela s'applique à eux. Sinon, cela modifie le paramètre global.
-e --cache taille
Définit la taille maximale du cache mémoire de la session en MiB. Ce cache est utilisé pour réduire les entrées/sorties disque.
-er --encryption-required
Chiffre toutes les connexions aux pairs.
-ep --encryption-preferred
Préfère les connexions aux pairs chiffrées.
-et --encryption-tolerated
Préfère les connexions aux pairs non chiffrées.
--exit
Demande à Transmission d'initier un arrêt.
-f --files
Obtient une liste des fichiers.

-gsr --global-seedratio ratio

-GSR --no-global-seedratio

-rad --remove-and-delete
Supprime le ou les torrents actuels et supprime leurs données téléchargées.
--reannounce
Réannonce le ou les torrents actuels. C'est la même chose que le bouton "demander plus de pairs au tracker" de l'interface graphique.
--move
Déplace les données du ou des torrents actuels de leurs emplacements actuels vers le répertoire spécifié.

--find

Laisse le ou les torrents actuels être envoyés jusqu'à atteindre un ratio spécifique.
-SR --no-seedratio
Laisse le ou les torrents actuels être envoyés quel que soit le ratio.

-td --tracker-add tracker

-tr --tracker-remove id-tracker

NOM

transmission-remote — Interface de ligne de commande pour transmission-daemon(1)

SYNOPSIS

transmission-remote [-n username:password] [-t torrent(s)] [-l | -L | -ne | -ns | -d bytes | -u bytes | -s | -S | -i | -f | -r name | -tr name | -ch name | -m | -M | -td directory | -ta directory | -P peerlimit | -rt time | -rg ratio | -sf state | -set field=value | -a file(s) | -au torrent | -A torrent | -x | -X | -y | -Y | -sd seconds | -st seconds | -p priority | -ph file(s) | -pl file(s) | -pn file(s) | -pb file(s) | -hl | -HL | -v | -w directory | -pi | -trash-torrent | -no-trash-torrent | --utp | --no-utp | --blocklist-update]

DESCRIPTION

transmission-remote est un client en ligne de commande qui interagit avec le démon transmission-daemon(1). Il permet de visualiser et de modifier les paramètres du démon et des torrents qu'il gère.

L'option -t peut être utilisée pour spécifier un ou plusieurs torrents sur lesquels agir. Les identifiants des torrents sont séparés par des virgules. Les plages d'identifiants sont autorisées, par exemple -t2,4,6-8 pour opérer sur les torrents dont les identifiants sont 2, 4, 6, 7 et 8.

Si aucun torrent n'est spécifié avec -t, les options s'appliquent alors globalement au démon, sauf indication contraire.

Les options suivantes sont disponibles :

-a --add filename
Ajoute le fichier torrent spécifié.
-au --add-upload filename
Ajoute le fichier torrent spécifié et le démarre immédiatement.
-A --add-paused filename
Ajoute le fichier torrent spécifié et le met en pause immédiatement.
-d limit
Limite la vitesse de téléchargement maximale à limit Ko/s. S'il y a des torrents sélectionnés, cela s'applique à eux. Sinon, cela change le réglage global.
-D --no-downlimit
Désactive les limites de vitesse de téléchargement.
-F filter
Filtre les torrents en fonction du champ et de la valeur spécifiés. Les filtres sont de la forme champ:valeur. Les champs valides sont id, name, label, status, et progress. Les valeurs peuvent être des nombres ou des chaînes de caractères. Par exemple, -F n:debian pour les torrents dont le nom contient "debian", ou -F l:done pour les torrents terminés.
-f
Liste les fichiers du ou des torrents sélectionnés.
-g files
Définit le statut des fichiers spécifiés (séparés par des virgules) à "télécharger". Les numéros de fichiers sont basés sur la sortie de -f.
-G files
Définit le statut des fichiers spécifiés (séparés par des virgules) à "ne pas télécharger". Les numéros de fichiers sont basés sur la sortie de -f.
-i
Affiche des informations détaillées sur le ou les torrents sélectionnés.
-l
Liste tous les torrents.
-L
Liste tous les torrents actifs.
-ids
Extrait les identifiants des torrents qui correspondent aux filtres actuels.
-m
Démarre tous les torrents.
-M
Arrête tous les torrents.
-n username:password
Définit le nom d'utilisateur et le mot de passe pour l'authentification.
-ne
Arrête tous les torrents.
-ns
Démarre tous les torrents.
-P peerlimit
Définit la limite de pairs pour le ou les torrents sélectionnés.
-p priority
Définit la priorité du ou des torrents sélectionnés. Les valeurs valides sont high, normal, low.
-ph files
Définit la priorité des fichiers spécifiés à "haute". Les numéros de fichiers sont basés sur la sortie de -f.
-pl files
Définit la priorité des fichiers spécifiés à "basse". Les numéros de fichiers sont basés sur la sortie de -f.
-pn files
Définit la priorité des fichiers spécifiés à "normale". Les numéros de fichiers sont basés sur la sortie de -f.
-pb files
Définit la priorité des fichiers spécifiés à "très basse". Les numéros de fichiers sont basés sur la sortie de -f.
-r name
Renomme le ou les torrents sélectionnés en name.
-rg ratio
Définit le ratio de partage cible pour le ou les torrents sélectionnés. Si la valeur est none, le ratio est désactivé.
-rt time
Définit le temps de partage cible en minutes pour le ou les torrents sélectionnés. Si la valeur est none, le temps est désactivé.
-s
Désactive le partage automatique.
-S
Active le partage automatique.
-sf state
Définit l'état du ou des torrents sélectionnés. Les états valides sont stopped, paused, downloading, seeding.
-set field=value
Définit une valeur pour un champ spécifique du ou des torrents sélectionnés. Les champs disponibles sont bandwidthPriority, downloadLimit, downloadLimited, peerLimit, seedRatioLimit, seedRatioMode, shareRatioLimit, shareRatioMode, speedLimitMode, storageDir, stoppedSeedingForwarder, uploadLimit, uploadLimited.
-t hash
Opère sur le ou les torrents spécifiés par leur hash ou leur ID. Pour spécifier plusieurs torrents, joignez leurs IDs ensemble dans une liste, comme -t2,4,6-8 pour opérer sur les torrents dont les IDs sont 2, 4, 6, 7 et 8.
--trash-torrent
Supprime les fichiers torrent après leur ajout.
--no-trash-torrent
Ne supprime pas les fichiers torrent après leur ajout.
-hl --honor-session
Fait en sorte que le ou les torrents actuels respectent les limites de session.
-HL --no-honor-session
Fait en sorte que le ou les torrents actuels ne respectent pas les limites de session.
-u --uplimit limit
Limite la vitesse d'envoi maximale à limit Ko/s. Si des torrents sont sélectionnés, cela s'applique à eux. Sinon, cela change le réglage global.
-U --no-uplimit
Désactive les limites de vitesse d'envoi.
--utp
Active uTP pour les connexions pairs.
--no-utp
Désactive uTP pour les connexions pairs. Si des torrents sont sélectionnés, cela s'applique à eux. Sinon, cela change le réglage global.
-v --verify
Vérifie le ou les torrents sélectionnés.
-V --version
Affiche le numéro de version et quitte.
-w --download-dir directory
Lorsqu'il est utilisé avec --add, définit le dossier de téléchargement du nouveau torrent. Sinon, définit le dossier de téléchargement par défaut.
-x --pex
Active l'échange de pairs (PEX).
-X --no-pex
Désactive l'échange de pairs (PEX).
-y --lds
Active la découverte de pairs locaux (LPD).
-Y --no-lds
Désactive la découverte de pairs locaux (LPD).
-pi --peer-info
Liste les pairs connectés du torrent actuel. Dans la section status de la liste, la notation abrégée suivante est utilisée :
D: Téléchargement depuis ce pair
d: Nous téléchargerions de ce pair s'il nous le permettait
E: Connexion cryptée
H: Le pair a été trouvé via DHT
I: Le pair est une connexion entrante
K: Le pair nous a débloqué, mais nous ne sommes pas intéressés
O: Optimistic unchoked
T: Le pair est connecté via uTP
U: Envoi au pair
u: Nous enverrions à ce pair s'il nous le demandait
X: Le pair a été découvert via Peer Exchange (PEX)
?: Nous avons débloqué ce pair, mais il n'est pas intéressé
--blocklist-update
Met à jour la liste de blocage à partir de l'URL spécifiée dans les paramètres du client distant avec la clé blocklist-url.

EXEMPLES

Lister tous les torrents :

$ transmission-remote -l
Lister tous les torrents actifs : 
$ transmission-remote -tactive -l
Lister tous les torrents avec le label "abc" : 
$ transmission-remote -F l:abc -l
Lister tous les torrents dont le nom contient "def" ou avec le label "abc" : 
$ transmission-remote -t $( transmission-remote -F n:def -ids )$( transmission-remote -F l:abc -ids ) -l
Renommer le dossier racine du torrent de "test1/examplefile.txt" à "test2/examplefile.txt" 
$ transmission-remote -t1 --path test1 --rename test2
Définir les limites de téléchargement et d'envoi à 400 Ko/sec et 60 Ko/sec : 
$ transmission-remote -d400 -u60
$ transmission-remote --downlimit=400 --uplimit=60
Définir les limites de téléchargement et d'envoi alternatives à 100 Ko/sec et 20 Ko/sec : 
$ transmission-remote -asd100 -asu20
$ transmission-remote --alt-speed-downlimit=100 --alt-speed-uplimit=20
Définir le planificateur pour utiliser les limites de vitesse alternatives les jours de semaine entre 10h et 23h 
$ transmission-remote --alt-speed-time-begin=1000
$ transmission-remote --alt-speed-time-end=2300
$ transmission-remote --alt-speed-days=1-5
$ transmission-remote --alt-speed-scheduler
Lister les IDs et états de tous les torrents : 
$ transmission-remote -l
Lister tous les torrents d'une session distante qui nécessite une authentification : 
$ transmission-remote host:9091 --auth=username:password -l
Démarrer tous les torrents : 
$ transmission-remote -tall --start
Ajouter deux torrents : 
$ transmission-remote -a one.torrent two.torrent
Ajouter tous les torrents dans ~/Desktop : 
$ transmission-remote -a ~/Desktop/*torrent
Obtenir des informations détaillées sur le torrent dont l'ID est '1' : 
$ transmission-remote -t1 -i
Obtenir une liste des fichiers d'un torrent : 
$ transmission-remote -t1 -f
Télécharger uniquement ses deuxième et quatrième fichiers : 
$ transmission-remote -t1 -Gall -g2,4
Définir la priorité des deux premiers fichiers de tous les torrents à haute : 
$ transmission-remote -tall -ph1,2
Définir la priorité des fichiers de tous les torrents à normale : 
$ transmission-remote -tall -pnall
