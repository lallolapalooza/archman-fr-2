CTREVC

Objectif :

!>
!> CTREVC calcule certains ou tous les vecteurs propres à droite et/ou à gauche
!> d'une matrice triangulaire supérieure complexe T.
!> Les matrices de ce type sont produites par la factorisation de Schur d'une
!> matrice générale complexe : A = Q*T*Q**H, telle que calculée par CHSEQR.
!>
!> Le vecteur propre à droite x et le vecteur propre à gauche y de T correspondant
!> à une valeur propre w sont définis par :
!>
!>              T*x = w*x,     (y**H)*T = w*(y**H)
!>
!> où y**H désigne la transposée conjuguée du vecteur y.
!> Les valeurs propres ne sont pas passées en entrée de cette routine, mais sont lues directement
!> sur la diagonale de T.
!>
!> Cette routine renvoie les matrices X et/ou Y des vecteurs propres à droite et à gauche
!> de T, ou les produits Q*X et/ou Q*Y, où Q est une
!> matrice d'entrée. Si Q est le facteur unitaire qui réduit une matrice A
!> à la forme de Schur T, alors Q*X et Q*Y sont les matrices des
!> vecteurs propres à droite et à gauche de A.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'R' : calculer uniquement les vecteurs propres à droite ;
!>          = 'L' : calculer uniquement les vecteurs propres à gauche ;
!>          = 'B' : calculer les vecteurs propres à droite et à gauche.
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A' : calculer tous les vecteurs propres à droite et/ou à gauche ;
!>          = 'B' : calculer tous les vecteurs propres à droite et/ou à gauche,
!>                  rétro-transformés en utilisant les matrices fournies dans
!>                  VR et/ou VL ;
!>          = 'S' : calculer certains vecteurs propres à droite et/ou à gauche,
!>                  comme indiqué par le tableau logique SELECT.
!>

SELECT

!>          SELECT est un TABLEAU LOGIQUE, de dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les vecteurs propres à calculer.
!>          Le vecteur propre correspondant à la j-ème valeur propre est
!>          calculé si SELECT(j) = .VRAI..
!>          Non référencé si HOWMNY = 'A' ou 'B'.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice T. N >= 0.
!>

T

!>          T est un TABLEAU COMPLEXE, de dimension (LDT,N)
!>          La matrice triangulaire supérieure T. T est modifiée, mais restaurée
!>          à la sortie.
!>

LDT

!>          LDT est ENTIER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

VL

!>          VL est un TABLEAU COMPLEXE, de dimension (LDVL,MM)
!>          À l'entrée, si SIDE = 'L' ou 'B' et HOWMNY = 'B', VL doit
!>          contenir une matrice Q de taille N x N (généralement la matrice unitaire Q des
!>          vecteurs de Schur retournée par CHSEQR).
!>          À la sortie, si SIDE = 'L' ou 'B', VL contient :
!>          si HOWMNY = 'A', la matrice Y des vecteurs propres à gauche de T ;
!>          si HOWMNY = 'B', la matrice Q*Y ;
!>          si HOWMNY = 'S', les vecteurs propres à gauche de T spécifiés par
!>                           SELECT, stockés consécutivement dans les
!>                           colonnes de VL, dans le même ordre que leurs
!>                           valeurs propres.
!>          Non référencé si SIDE = 'R'.
!>

LDVL

!>          LDVL est ENTIER
!>          La dimension principale du tableau VL. LDVL >= 1, et si
!>          SIDE = 'L' ou 'B', LDVL >= N.
!>

VR

!>          VR est un TABLEAU COMPLEXE, de dimension (LDVR,MM)
!>          À l'entrée, si SIDE = 'R' ou 'B' et HOWMNY = 'B', VR doit
!>          contenir une matrice Q de taille N x N (généralement la matrice unitaire Q des
!>          vecteurs de Schur retournée par CHSEQR).
!>          À la sortie, si SIDE = 'R' ou 'B', VR contient :
!>          si HOWMNY = 'A', la matrice X des vecteurs propres à droite de T ;
!>          si HOWMNY = 'B', la matrice Q*X ;
!>          si HOWMNY = 'S', les vecteurs propres à droite de T spécifiés par
!>                           SELECT, stockés consécutivement dans les
!>                           colonnes de VR, dans le même ordre que leurs
!>                           valeurs propres.
!>          Non référencé si SIDE = 'L'.
!>

LDVR

!>          LDVR est ENTIER
!>          La dimension principale du tableau VR. LDVR >= 1, et si
!>          SIDE = 'R' ou 'B'; LDVR >= N.
!>

MM

!>          MM est ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR. MM >= M.
!>

M

!>          M est ENTIER
!>          Le nombre de colonnes dans les tableaux VL et/ou VR effectivement
!>          utilisées pour stocker les vecteurs propres. Si HOWMNY = 'A' ou 'B',
!>          M est mis à N. Chaque vecteur propre sélectionné occupe une
!>          colonne.
!>

WORK

!>          WORK est un TABLEAU COMPLEXE, de dimension (2*N)
!>

RWORK

!>          RWORK est un TABLEAU RÉEL, de dimension (N)
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  L'algorithme utilisé dans ce programme est essentiellement une substitution arrière (avant),
!>  avec mise à l'échelle pour rendre le code robuste contre
!>  un possible dépassement de capacité.
!>
!>  Chaque vecteur propre est normalisé de sorte que l'élément de magnitude maximale
!>  ait une magnitude de 1 ; ici, la magnitude d'un nombre complexe
!>  (x,y) est prise comme |x| + |y|.
!>

NAME

DTREVC, STREVC - computes some or all of the right and/or left eigenvectors of a real upper quasi-triangular matrix T.

SYNOPSIS

SUBROUTINE DTREVC( SIDE, HOWMNY, SELECT, N, T, LDT, VL, LDVL, VR, LDVR, MM, M,

SUBROUTINE STREVC( SIDE, HOWMNY, SELECT, N, T, LDT, VL, LDVL, VR, LDVR, MM, M,

CHARACTER * 1 SIDE, HOWMNY
LOGICAL SELECT( * )
INTEGER N, LDT, LDVL, LDVR, MM, M, INFO
REAL T( LDT, * ), VL( LDVL, * ), VR( LDVR, * ), WORK( * )

DESCRIPTION

A real upper quasi-triangular matrix T.

Matrices of this type are produced by the Schur factorization of a real general matrix: A = Q*T*Q**T, as computed by DHSEQR.

The right eigenvector x and the left eigenvector y of T corresponding to an eigenvalue w are defined by:

   T*x = w*x,     (y**H)*T = w*(y**H)

where y**H denotes the conjugate transpose of y. The eigenvalues are not input to this routine, but are read directly from the diagonal blocks of T.

This routine returns the matrices X and/or Y of right and left eigenvectors of T, or the products Q*X and/or Q*Y, where Q is an input matrix. If Q is the orthogonal factor that reduces a matrix A to Schur form T, then Q*X and Q*Y are the matrices of right and left eigenvectors of A.

PARAMETERS

SIDE

          SIDE is CHARACTER*1
          = 'R':  compute right eigenvectors only;
          = 'L':  compute left eigenvectors only;
          = 'B':  compute both right and left eigenvectors.

HOWMNY

          HOWMNY is CHARACTER*1
          = 'A':  compute all right and/or left eigenvectors;
          = 'B':  compute all right and/or left eigenvectors,
                  backtransformed by the matrices in VR and/or VL;
          = 'S':  compute selected right and/or left eigenvectors,
                  as indicated by the logical array SELECT.

SELECT

          SELECT is LOGICAL array, dimension (N)
          If HOWMNY = 'S', SELECT specifies the eigenvectors to be
          computed.
          If w(j) is a real eigenvalue, the corresponding real
          eigenvector is computed if SELECT(j) is .TRUE..
          If w(j) and w(j+1) are the real and imaginary parts of a
          complex eigenvalue, the corresponding complex eigenvector is
          computed if either SELECT(j) or SELECT(j+1) is .TRUE., and
          on exit SELECT(j) is set to .TRUE. and SELECT(j+1) is set to
          .FALSE..
          Not referenced if HOWMNY = 'A' or 'B'.

N

          N is INTEGER
          The order of the matrix T. N >= 0.

T

          T is DOUBLE PRECISION array, dimension (LDT,N)
          The upper quasi-triangular matrix T in Schur canonical form.

LDT

          LDT is INTEGER
          The leading dimension of the array T. LDT >= max(1,N).

VL

          VL is DOUBLE PRECISION array, dimension (LDVL,MM)
          On entry, if SIDE = 'L' or 'B' and HOWMNY = 'B', VL must
          contain an N-by-N matrix Q (usually the orthogonal matrix Q
          of Schur vectors returned by DHSEQR).
          On exit, if SIDE = 'L' or 'B', VL contains:
          if HOWMNY = 'A', the matrix Y of left eigenvectors of T;
          if HOWMNY = 'B', the matrix Q*Y;
          if HOWMNY = 'S', the left eigenvectors of T specified by
                           SELECT, stored consecutively in the columns
                           of VL, in the same order as their
                           eigenvalues.
          A complex eigenvector corresponding to a complex eigenvalue
          is stored in two consecutive columns, the first holding the
          real part, and the second the imaginary part.
          Not referenced if SIDE = 'R'.

LDVL

          LDVL is INTEGER
          The leading dimension of the array VL.  LDVL >= 1, and if
          SIDE = 'L' or 'B', LDVL >= N.

VR

          VR is DOUBLE PRECISION array, dimension (LDVR,MM)
          On entry, if SIDE = 'R' or 'B' and HOWMNY = 'B', VR must
          contain an N-by-N matrix Q (usually the orthogonal matrix Q
          of Schur vectors returned by DHSEQR).
          On exit, if SIDE = 'R' or 'B', VR contains:
          if HOWMNY = 'A', the matrix X of right eigenvectors of T;
          if HOWMNY = 'B', the matrix Q*X;
          if HOWMNY = 'S', the right eigenvectors of T specified by

                           of VR, in the same order as their
                           eigenvalues.

          is stored in two consecutive columns, the first holding the

          < 0:  if INFO = -i, the i-th argument had an illegal value

FURTHER DETAILS

          The algorithm used in this program is basically backward (forward)
          substitution, with scaling to make the the code robust against
          possible overflow.
          Each eigenvector is normalized so that the element of largest
          magnitude has magnitude 1; here the magnitude of a complex number
          (x,y) is taken to be |x| + |y|.
