tracecmd_follow_event(3)

Paquet: trace-cmd

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACECMD(3) Manuel de libtracefs LIBTRACECMD(3)

NOM

tracecmd_iterate_events, tracecmd_iterate_events_multi, tracecmd_follow_event, tracecmd_follow_missed_events, tracecmd_filter_add, tracecmd_iterate_reset - Lire les événements d'un fichier de trace

SYNOPSIS

#include <trace-cmd.h>
int tracecmd_iterate_events(struct tracecmd_input *handle,
                            cpu_set_t *cpus, int cpu_size,
                            int (*callback)(struct tracecmd_input *,
                                            struct tep_record *,
                                            int, void *),
                            void *callback_data);
int tracecmd_iterate_events_multi(struct tracecmd_input **handles,
                                  int nr_handles,
                                  int (*callback)(struct tracecmd_input *,
                                                           struct tep_record *,
                                                           int, void *),
                                  void *callback_data);
int tracecmd_iterate_events_reverse(struct tracecmd_input *handle,
                            cpu_set_t *cpus, int cpu_size,
                            int (*callback)(struct tracecmd_input *,
                                            struct tep_record *,
                                            int, void *),
                            void *callback_data, bool cont);
int tracecmd_follow_event(struct tracecmd_input *handle,
                          const char *system, const char *event_name,
                          int (*callback)(struct tracecmd_input *,
                                          struct tep_event *,
                                          struct tep_record *,
                                          int, void *),
                          void *callback_data);
int tracecmd_follow_missed_events(struct tracecmd_input *handle,
                                   int (*callback)(struct tracecmd_input *,
                                                   struct tep_event *,
                                                   struct tep_record *,
                                                   int, void *),
                                   void *callback_data);
struct tracecmd_filter *tracecmd_filter_add(struct tracecmd_input handle,
                                            const char *filter_str, bool neg);
int *tracecmd_iterate_reset(struct tracecmd_input *handle);

DESCRIPTION

Cet ensemble d'API peut être utilisé pour itérer sur les événements après avoir ouvert un fichier de trace en utilisant l'une des fonctions d'ouverture telles que tracecmd_open(3) ou tracecmd_open_fd(3).

La fonction tracecmd_iterate_events() itérera sur tous les événements du fichier de trace défini par handle, où handle est retourné par l'une des fonctions tracecmd_open(3). Elle appellera la fonction callback() sur les événements des CPU définis par cpus. cpu_size doit être la taille de cpus (voir CPU_SET(3)). Si cpus est NULL, alors cpu_size est ignoré et callback() sera appelée pour tous les événements sur tous les CPU du fichier de trace. callback_data est passé à callback() comme son dernier paramètre. callback peut être NULL, ce qui est utile si tracecmd_follow_event() est utilisé, mais notez que si callback est NULL, alors callback_data est ignoré et n'est pas envoyé au callback de tracecmd_follow_event().

La fonction tracecmd_iterate_events_multi() est similaire à tracecmd_iterate_events() sauf qu'elle permet d'itérer sur plus d'un fichier de trace. Si tracecmd agent(1) est utilisé pour obtenir un fichier de trace pour l'hôte et l'invité, assurez-vous que le fichier de trace de l'hôte est la première entrée dans handles et tracecmd_iterate_events_multi() synchronisera les métadonnées pour les fichiers invités qui viennent plus tard dans handles. handles est un tableau de descripteurs de fichiers de trace qui ont été ouverts par tracecmd_open(3) et fonctions similaires. Notez que, contrairement à tracecmd_iterate_events(), tracecmd_iterate_events_multi() ne filtre pas sur les CPU, car cela rendrait l'API trop complexe pour savoir sur quel handle filtrer les CPU. Si un filtrage CPU est souhaité, alors le callback doit vérifier record→cpu et retourner 0 s'il ne s'agit pas du CPU souhaité à traiter. nr_handles désigne le nombre d'éléments dans handles. callback_data est passé au callback comme son dernier paramètre. callback peut être NULL, ce qui est utile si tracecmd_follow_event() est utilisé, mais notez que si callback est NULL, alors callback_data est ignoré et n'est pas envoyé au callback de tracecmd_follow_event().

La fonction tracecmd_iterate_events_reverse() fonctionne à peu près de la même manière que tracecmd_iterate_events(), mais au lieu d'appeler la fonction callback() pour chaque événement dans l'ordre des horodatages, elle appellera la fonction callback() pour chaque événement dans l'ordre inverse des horodatages. Si cont est faux, elle commencera par appeler l'événement avec le plus ancien horodatage dans le fichier trace.dat. Si cont est défini à vrai, elle continuera là où se trouve la position actuelle des données de trace. Par exemple, si callback() retourne quelque chose d'autre que zéro, elle sortira de l'itération. Si tracecmd_iterate_events_reverse() est appelée à nouveau avec cont à vrai, elle continuera là où elle s'est arrêtée. Si cont est faux, elle recommencera à l'événement avec le plus ancien horodatage. handle, cpus, cpu_size, et callback_data agissent de la même manière que dans tracecmd_iterate_events().

Le callback() pour tracecmd_iterate_events(), tracecmd_iterate_events_reverse() et tracecmd_iterate_events_multi() a le prototype suivant :

int callback()(struct tracecmd_input *handle, struct tep_record *record, int cpu, void *data);

handle est le même handle passé à tracecmd_iterate_events() ou le handle actuel de handles passé à tracecmd_iterate_events_multi() auquel appartient l'objet record. record est l'enregistrement d'événement courant. cpu est le CPU courant en cours de traitement. Notez que pour tracecmd_iterate_events_multi(), il peut ne pas s'agir du CPU réel du fichier, mais du nième CPU de tous les handles combinés. Utilisez record→cpu pour obtenir le CPU réel sur lequel se trouve l'événement.

La fonction tracecmd_follow_event() s'attachera à un descripteur de fichier de trace handle et appellera le callback lorsque l'événement décrit par system et name correspondra à un événement dans l'itération de tracecmd_iterate_events() ou tracecmd_iterate_events_multi(). Notez que cpu est le nième CPU pour tracecmd_iterate_events() et tracecmd_iterate_events_multi(). Si le CPU réel de record est nécessaire, utilisez record→cpu. Pour tracecmd_iterate_events_multi(), le callback n'est appelé que si le handle correspond au descripteur de fichier de trace courant dans handles. callback_data est passé comme dernier paramètre à la fonction callback(). Notez que cette fonction callback() sera appelée avant la fonction callback() de tracecmd_iterate_events() ou tracecmd_iterate_events_multi().

Le prototype du callback() pour *tracecmd_follow_event()_ est :

int callback()(struct tracecmd_input *handle, struct tep_event *event, struct tep_record *_record, int cpu, void *data);

La fonction tracecmd_follow_missed_events() s'attachera à un descripteur de fichier de trace handle et appellera le callback lorsque des événements manqués sont détectés. event contiendra le type d'événement de l'objet record. record contiendra les informations sur les événements manqués. cpu est le nième CPU pour tracecmd_iterate_events() et tracecmd_iterate_events_multi(). Si le CPU pour lequel les événements manqués sont destinés est nécessaire, utilisez record→cpu. Si record→missed_events est un nombre positif, il contient le nombre d'événements manqués depuis le dernier événement sur son CPU, sinon il sera négatif, ce qui signifiera que le nombre d'événements manqués est inconnu mais que des événements manqués existent depuis le dernier événement sur le CPU. callback est appelé avant tous les autres callbacks et tous les filtres ajoutés par tracecmd_filter_add() sont ignorés. Si callback renvoie une valeur non nulle, cela arrêtera l'itérateur avant qu'il n'appelle d'autres callbacks de l'itérateur pour l'enregistrement donné.

La fonction tracecmd_filter_add() ajoute un filtre au handle qui affecte à la fois tracecmd_iterate_events() et tracecmd_iterate_events_multi(). Le filter_str est une chaîne de caractères définissant un filtre dans un format défini par tep_filter_add_filter_str(3). Si neg est vrai, alors les événements qui correspondent au filtre seront ignorés, sinon les événements qui correspondent exécuteront la fonction callback() dans les itérateurs.

La fonction tracecmd_iterate_reset() remet le handle au début, de sorte que le prochain appel à tracecmd_iterate_events() recommence au premier événement, au lieu de continuer là où il s'est arrêté.

VALEUR DE RETOUR

Les fonctions tracecmd_iterate_events(), tracecmd_iterate_events_reverse() et tracecmd_iterate_events_multi() renvoient zéro si elles ont correctement parcouru tous les événements (en gérant les suivis et les filtres de manière appropriée). Ou une valeur d'erreur, qui peut inclure le retour d'un résultat non nul de la fonction callback().

tracecmd_iterate_reset() renvoie 0 en cas de succès et -1 si une erreur s'est produite. Notez que si -1 est renvoyé, une réinitialisation partielle peut également s'être produite.

EXEMPLE

#define _GNU_SOURCE
#include <sched.h>
#include <stdlib.h>
#include <getopt.h>
#include <trace-cmd.h>
struct private_data {
        int             cpu;
        const char      *file;
};
static int print_events(struct tracecmd_input *handle, struct tep_record *record, int cpu, void *data)
{
        static struct trace_seq seq;
        struct tep_handle *tep = tracecmd_get_tep(handle);
        struct private_data *pdata = tracecmd_get_private(handle);
        /* Pour les handles multiples, nous avons besoin de ceci */
        if (pdata->cpu >= 0 && pdata->cpu != record->cpu)
                return 0;
        if (!seq.buffer)
                trace_seq_init(&seq);
        trace_seq_reset(&seq);
        trace_seq_printf(&seq, "%s: ", pdata->file);
        trace_seq_printf(&seq, "%6.1000d [%03d] %s-%d %s: %s\n",
                        TEP_PRINT_TIME, TEP_PRINT_CPU, TEP_PRINT_COMM, TEP_PRINT_PID,
                        TEP_PRINT_NAME, TEP_PRINT_INFO);
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
        return 0;
}
static int print_event(struct tracecmd_input *handle, struct tep_event *event,
                       struct tep_record *record, int cpu, void *data)
{
        return print_events(handle, record, cpu, data);
}
static int missed_events(struct tracecmd_input *handle, struct tep_event *event,
                         struct tep_record *record, int cpu, void *data)
{
        if (record->missed_events > 0)
                printf("CPU [%03d] a %d événements manqués\n",
                         record->cpu, record->missed_events);
        else
                printf("CPU [%03d] a des événements manqués\n", record->cpu);
        return 0;
}
static void usage(const char *argv0)
{
        printf("utilisation : [-c cpu][-f filtre][-e événement] %s trace.dat [trace.dat ...]\n",
               argv0);
        exit(-1);
}
int main(int argc, char **argv)
{
        struct tracecmd_input **handles = NULL;
        const char *filter_str = NULL;
        const char *argv0 = argv[0];
        struct private_data *priv;
        cpu_set_t *cpuset = NULL;
        char *event = NULL;
        size_t cpusize = 0;
        int nr_handles = 0;
        int cpu = -1;
        int i;
        int c;
        while ((c = getopt(argc, argv, "c:f:e:")) >= 0) {
                switch (c) {
                case 'c':
                        /* filtrer toutes les données de trace vers ce CPU unique. */
                        cpu = atoi(optarg);
                        break;
                case 'f':
                        filter_str = optarg;
                        break;
                case 'e':
                        event = optarg;
                        break;
                default:
                        usage(argv0);
                }
        }
        argc -= optind;
        argv += optind;
        if (argc == 0)
                usage(argv0);
        for (i = 0; i < argc; i++) {
                handles = realloc(handles, sizeof(*handles) * (nr_handles + 1));
                if (!handles)
                        exit(-1);
                handles[nr_handles] = tracecmd_open(argv[i], 0);
                if (!handles[nr_handles]) {
                        perror(argv[i]);
                        exit(-1);
                }
                if (filter_str) {
                        if (tracecmd_filter_add(handles[nr_handles], filter_str, false) == NULL) {
                                perror("ajout du filtre");
                                exit(-1);
                        }
                }
                priv = calloc(1, sizeof(*priv));
                if (!priv)
                        exit(-1);
                priv->file = argv[i];
                priv->cpu = cpu;
                tracecmd_set_private(handles[nr_handles], priv);
                if (event) {
                        if (tracecmd_follow_event(handles[nr_handles], NULL, event, print_event, NULL) < 0) {
                                printf("Impossible de suivre l'événement %s pour le fichier %s\n", event, argv[i]);
                                exit(-1);
                        }
                }
                tracecmd_follow_missed_events(handles[nr_handles], missed_events, NULL);
                nr_handles++;
        }
        /* Raccourci */
        if (nr_handles == 1) {
                if (cpu >= 0) {
                        cpuset = CPU_ALLOC(cpu + 1);
                        if (!cpuset)
                                exit(-1);
                        cpusize = CPU_ALLOC_SIZE(cpu + 1);
                        CPU_SET_S(cpu, cpusize, cpuset);
                }
                if (event)
                        tracecmd_iterate_events(handles[0], cpuset, cpusize, NULL, NULL);
                else
                        tracecmd_iterate_events(handles[0], cpuset, cpusize, print_events, NULL);
        } else {
                if (event)
                        tracecmd_iterate_events_multi(handles, nr_handles, NULL, NULL);
                else
                        tracecmd_iterate_events_multi(handles, nr_handles, print_events, NULL);
        }
        for (i = 0; i < nr_handles; i++) {
                priv = tracecmd_get_private(handles[i]);
                free(priv);
                tracecmd_close(handles[i]);
        }
        free(handles);
}
