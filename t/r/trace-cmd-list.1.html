NOM

trace-cmd-list - lister les plugins, événements ou options Ftrace disponibles.

SYNTAXE

trace-cmd list [OPTIONS]

DESCRIPTION

trace-cmd(1) list affiche les plugins, systèmes d'événements, événements et options Ftrace disponibles et configurés sur la machine actuelle. Si aucune option n'est spécifiée, il liste tout vers la sortie standard.

OPTIONS

-e [regex]

Cette option liste les événements disponibles qui sont activés sur le système local. 
Elle accepte un argument optionnel qui utilise des expressions 'regcomp(3)' pour la recherche.
trace-cmd list -e '^sys.*'

-F

Utilisé avec -e regex pour montrer les champs de l'événement.

--full

Utilisé avec -F, cela montrera le "print fmt" de l'événement ainsi que les champs.

-l

Utilisé avec -e regex pour montrer les filtres d'événements.

-R

Utilisé avec -e regex pour montrer les déclencheurs d'événements.

-s

Cette option liste les systèmes d'événements disponibles.

-t

Cette option liste les traceurs disponibles qui sont activés sur le système local.

-p

Identique à -t et seulement pour des raisons de compatibilité.

-o

Cette option liste les options Ftrace disponibles qui sont configurées sur le système local.

-f [regex]

Cette option liste les fonctions de filtrage disponibles. Ce sont les fonctions du système que vous pouvez tracer ou sur lesquelles filtrer. Elle accepte un argument optionnel qui utilise les expressions regcomp(3) pour la recherche. 
trace-cmd list -f '^sched.*'

-P

Liste les fichiers de plugin qui sont chargés pour le rapport trace-cmd.

-O

Liste les options de plugin qui peuvent être utilisées par l'option -O du rapport trace-cmd.

-B

Liste les instances de tampons définies (sous-tampons).

-C

Liste les horloges définies qui peuvent être utilisées avec trace-cmd record -C. Celle entre crochets ([]) est l'horloge active.

-c

Liste les algorithmes de compression de fichiers de trace disponibles.
