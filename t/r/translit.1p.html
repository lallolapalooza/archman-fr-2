NOM

translit - translittérer du texte entre divers systèmes d'écriture

SYNOPIS

translit -t nom -r -i fichier -o fichier -l -v -h

DESCRIPTION

translit translittère du texte en langue naturelle encodé en UTF-8 d'un système d'écriture à un autre.

Il utilise le module Perl Lingua::Translit pour accomplir cette tâche et suit les normes de translittération fournies aussi strictement que possible.

translit prend en compte les commutateurs de ligne de commande suivants :

--trans, -t nom
Utiliser la norme de translittération nommée nom.
--reverse, -r
Translitérer dans le sens inverse.

NOTE : Toutes les translittérations ne peuvent pas être inversées. En cas de doute, consultez la liste des translittérations supportées à l'aide du commutateur --list.

--infile, -i FICHIER
Lire le texte depuis FICHIER. Par défaut, utilise STDIN.
--outfile, -o FICHIER
Écrire le texte translittéré dans FICHIER. Par défaut, utilise STDOUT.
--list, -l
Imprimer une liste des translittérations supportées montrant leur
  • nom
  • réversibilité
  • description
--verbose, -v
Imprimer des messages de statut détaillés sur STDERR.
--help, -h
Afficher un court texte d'aide présentant uniquement les commutateurs de ligne de commande.

RESTRICTIONS

L'entrée doit être encodée en UTF-8.

Veuillez signaler les bogues en utilisant le système de suivi des demandes de CPAN à l'adresse https://rt.cpan.org/Public/Dist/Display.html?Name=Lingua-Translit.
