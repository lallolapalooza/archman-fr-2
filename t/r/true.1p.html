TRUE(1P) Manuel du programmeur POSIX TRUE(1P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

true — renvoyer la valeur vraie

SYNTAXE

true

DESCRIPTION

L'utilitaire true se termine avec le code de sortie zéro.

OPTIONS

Aucune.

OPÉRANDES

Aucun.

STDIN

Non utilisé.

FICHIERS ENTRANT

Aucun.

VARIABLES ENVIRONNEMENT

Aucune.

ÉVÉNEMENTS ASYNCHRONES

Par défaut.

STDOUT

Non utilisé.

STDERR

Non utilisé.

FICHIERS SORTIE

Aucun.

DESCRIPTION ÉTENDUE

Aucune.

STATUT SORTIE

Zéro.

CONSÉQUENCES ERREURS

Aucune.

Les sections suivantes sont informatives.

USAGE APPLICATIF

Cet utilitaire est généralement utilisé dans les scripts shell, comme illustré dans la section EXEMPLES. L'utilitaire spécial intégré : est parfois plus efficace que true.

EXEMPLES

Cette commande s'exécute indéfiniment :

while true
do
    commande
done

RATIONALE

L'utilitaire true a été conservé dans ce volume de POSIX.1‐2017, même si l'utilitaire spécial intégré du shell : fournit une fonctionnalité similaire, car true est largement utilisé dans les scripts historiques et est moins cryptique pour les lecteurs novices.
