NOM

tracefs_hist_add_sort_key, tracefs_hist_set_sort_key, tracefs_hist_sort_key_direction, tracefs_hist_add_name, tracefs_hist_append_filter, tracefs_hist_echo_cmd, tracefs_hist_command, tracefs_hist_get_name, tracefs_hist_get_event, tracefs_hist_get_system - Mettre à jour et décrire un histogramme d'événements

DESCRIPTION

Les histogrammes d'événements sont créés par le fichier « trigger » dans le répertoire de l'événement. La syntaxe peut être complexe et difficile à maîtriser. Cette API gère la syntaxe et facilite la création et l'interaction avec les histogrammes d'événements. Voir https://www.kernel.org/doc/html/latest/trace/histogram.html pour plus d'informations.

tracefs_hist_add_sort_key() ajoute une clé de tri. hist est le descripteur d'histogramme auquel ajouter la clé de tri. sort_key est une chaîne de caractères qui doit correspondre soit à une clé déjà définie de l'histogramme, soit à une valeur déjà définie. Si hist a déjà des clés de tri (ajoutées précédemment), la nouvelle sort_key aura une priorité plus faible (sera secondaire, etc.) lors du tri.

tracefs_hist_set_sort_key() réinitialise la liste des clés de tri. hist est le descripteur d'histogramme dont la clé de tri doit être réinitialisée. sort_key est une chaîne de caractères qui doit correspondre soit à une clé déjà définie de l'histogramme, soit à une valeur déjà définie. Plusieurs clés de tri peuvent être ajoutées pour définir un ordre de tri secondaire, etc., mais toutes les clés de tri doivent correspondre à une clé ou une valeur existante, ou être TRACEFS_HIST_HITCOUNT. Le dernier paramètre de tracefs_hist_add_sort_key() doit être NULL.

tracefs_hist_sort_key_direction() permet de changer la direction d'une clé de tri existante de hist. sort_key est la clé de tri à changer, et dir peut être soit TRACEFS_HIST_SORT_ASCENDING soit TRACEFS_HIST_SORT_DESCENDING, pour rendre la direction de la clé de tri croissante ou décroissante respectivement.

tracefs_hist_add_name() ajoute un nom à un histogramme. Un histogramme peut être nommé et si le nom correspond entre plusieurs événements, et qu'ils ont des clés compatibles, les histogrammes multiples avec le même nom seront fusionnés en un seul histogramme (affiché par le fichier hist de n'importe quel événement). hist est l'histogramme à nommer, et name est le nom à lui donner.

tracefs_hist_append_filter() crée un filtre ou y ajoute un filtre pour l'événement de l'histogramme. Selon type, il construira une chaîne de jetons pour les parenthèses ou les instructions logiques, ou il pourra ajouter une comparaison de field à val basée sur compare.

Si type est : TRACEFS_FILTER_COMPARE - Voir ci-dessous TRACEFS_FILTER_AND - Ajoute « && » au filtre TRACEFS_FILTER_OR - Ajoute « || » au filtre TRACEFS_FILTER_NOT - Ajoute « ! » au filtre TRACEFS_FILTER_OPEN_PAREN - Ajoute « ( » au filtre TRACEFS_FILTER_CLOSE_PAREN - Ajoute « ) » au filtre

field, compare, et val sont ignorés sauf si type est égal à TRACEFS_FILTER_COMPARE, alors compare sera utilisé pour ce qui suit :

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ « val » : où field est une chaîne.

TRACEFS_COMPARE_AND - field & val : où field est un champ de drapeaux.

trace_hist_echo_cmd() imprime les commandes nécessaires pour créer l'histogramme donné dans l'instance donnée, ou NULL pour le niveau supérieur, dans le seq. La commande qui est imprimée est décrite par command et montre la fonctionnalité qui serait effectuée par tracefs_hist_command(3).

tracefs_hist_command() est appelée pour traiter une commande sur l'histogramme hist pour son événement dans l'instance donnée, ou NULL pour le niveau supérieur. La cmd peut être l'une des suivantes :

TRACEFS_HIST_CMD_START ou zéro pour démarrer l'exécution de l'histogramme.

TRACEFS_HIST_CMD_PAUSE pour mettre en pause l'histogramme donné.

TRACEFS_HIST_CMD_CONT pour continuer un histogramme mis en pause.

TRACEFS_HIST_CMD_CLEAR pour réinitialiser les valeurs d'un histogramme.

TRACEFS_HIST_CMD_DESTROY pour détruire l'histogramme (annuler un START).

Les fonctions ci-dessous sont des wrappers pour tracefs_hist_command() pour rendre les conventions d'appel un peu plus faciles à comprendre.

TYPES DE CLÉS

tracefs_hist_alloc_nd() et tracefs_hist_add_key() ajoutent tous deux une clé et nécessitent que cette clé ait un type. Les types peuvent être :

TRACEFS_HIST_KEY_NORMAL ou zéro (0) ce qui ne modifie pas le type.

TRACEFS_HIST_KEY_HEX pour afficher la clé en hexadécimal.

TRACEFS_HIST_KEY_SYM pour afficher la clé comme un symbole du noyau (si trouvé). Si la clé est une adresse, c'est utile car cela affichera les noms de fonctions au lieu d'un simple nombre.

TRACEFS_HIST_KEY_SYM_OFFSET similaire à TRACEFS_HIST_KEY_SYM mais inclura également le décalage de la fonction pour correspondre à l'adresse exacte.

TRACEFS_HIST_KEY_SYSCALL Si la clé est un « id » d'appel système (le numéro passé de l'espace utilisateur au noyau pour lui indiquer quel appel système il appelle), alors le nom de l'appel système est affiché.

TRACEFS_HIST_KEY_EXECNAME Si « common_pid » est la clé (le pid de la tâche en cours d'exécution), au lieu d'afficher le numéro, on affiche le nom de la tâche en cours d'exécution.

TRACEFS_HIST_KEY_LOG affichera la clé sur une échelle logarithmique binaire.

TRACEFS_HIST_KEY_USECS pour utilisation avec « common_timestamp » ou TRACEFS_HIST_TIMESTAMP, auquel cas il affichera le timestamp en microsecondes au lieu de nanosecondes.

VALEUR DE RETOUR

tracefs_hist_get_name() retourne le nom de l'histogramme ou NULL en cas d'erreur. La chaîne retournée appartient à l'objet histogramme et est libérée avec l'histogramme par tracefs_hist_free().

tracefs_hist_get_event() retourne le nom de l'événement de l'histogramme ou NULL en cas d'erreur. La chaîne retournée appartient à l'objet histogramme et est libérée avec l'histogramme par tracefs_hist_free().

tracefs_hist_get_system() retourne le nom du système de l'histogramme ou NULL en cas d'erreur. La chaîne retournée appartient à l'objet histogramme et est libérée avec l'histogramme par tracefs_hist_free().

tracefs_hist_alloc_nd() retourne un descripteur d'histogramme alloué qui doit être libéré par tracefs_hist_free() ou NULL en cas d'erreur.

tracefs_hist_get_name<

/b>(), tracefs_hist_get_event() et tracefs_hist_get_system() retournent des chaînes appartenant à l'objet histogramme.

Toutes les autres fonctions retournent zéro en cas de succès ou -1 en cas d'erreur.

EXEMPLE

#include <stdlib.h>
#include <unistd.h>
#include <tracefs.h>
enum commands {
        START,
        PAUSE,
        CONT,
        RESET,
        DELETE,
        SHOW,
};
static void parse_system_event(char *group, char **system, char **event)
{
        *system = strtok(group, "/");
        *event = strtok(NULL, "/");
        if (!*event) {
                *event = *system;
                *system = NULL;
        }
}
static int parse_keys(char *keys, struct tracefs_hist_axis **axes)
{
        char *sav = NULL;
        char *key;
        int cnt = 0;
        for (key = strtok_r(keys, ",", &sav); key; key = strtok_r(NULL, ",", &sav)) {
                struct tracefs_hist_axis *ax;
                char *att;
                ax = realloc(*axes, sizeof(*ax) * (cnt + 2));
                if (!ax) {
                        perror("Échec de l'allocation des axes");
                        exit(-1);
                }
                ax[cnt].key = key;
                ax[cnt].type = 0;
                ax[cnt + 1].key = NULL;
                ax[cnt + 1].type = 0;
                *axes = ax;
                att = strchr(key, '.');
                if (att) {
                        *att++ = '\0';
                        if (strcmp(att, "hex") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_HEX;
                        else if (strcmp(att, "sym") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM;
                        else if (strcmp(att, "sym_offset") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM_OFFSET;
                        else if (strcmp(att, "syscall") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYSCALL;
                        else if (strcmp(att, "exec") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_EXECNAME;
                        else if (strcmp(att, "log") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_LOG;
                        else if (strcmp(att, "usecs") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_USECS;
                        else {
                                fprintf(stderr, "Attribut indéfini '%s'\n", att);
                                fprintf(stderr,"  Attributs acceptables:\n");
                                fprintf(stderr,"    hex, sym, sym_offset, syscall, exe, log, usecs\n");
                                exit(-1);
                        }
                }
                cnt++;
        }
        return cnt;
}
static void process_hist(enum commands cmd, const char *instance_name,
                         char *group, char *keys, char *vals, char *sort,
                         char *ascend, char *desc)
{
        struct tracefs_instance *instance = NULL;
        struct tracefs_hist *hist;
        struct tep_handle *tep;
        struct tracefs_hist_axis *axes = NULL;
        char *system;
        char *event;
        char *sav;
        char *val;
        int ret;
        int cnt;
        if (instance_name) {
                instance = tracefs_instance_create(instance_name);
                if (!instance) {
                        fprintf(stderr, "Échec de la création de l'instance\n");
                        exit(-1);
                }
        }
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("Impossible de lire les événements");
                exit(-1);
        }
        parse_system_event(group, &system, &event);
        if (cmd == SHOW) {
                char *content;
                content = tracefs_event_file_read(instance, system, event,
                                                  "hist", NULL);
                if (!content) {
                        perror("Lecture du fichier hist");
                        exit(-1);
                }
                printf("%s\n", content);
                free(content);
                return;
        }
        if (!keys) {
                fprintf(stderr, "La commande nécessite l'option -k\n");
                exit(-1);
        }
        cnt = parse_keys(keys, &axes);
        if (!cnt) {
                fprintf(stderr, "Aucune clé ??\n");
                exit(-1);
        }
        /* Afficher des exemples de hist1d et hist2d */
        switch (cnt) {
        case 1:
                hist = tracefs_hist_alloc(tep, system, event,
                                          axes[0].key, axes[0].type);
                break;
        case 2:
                hist = tracefs_hist_alloc_2d(tep, system, event,
                                             axes[0].key, axes[0].type,
                                             axes[1].key, axes[1].type);
                break;
        default:
                /* Vraiment, 1 et 2 pourraient aussi utiliser ceci */
                hist = tracefs_hist_alloc_nd(tep, system, event, axes);
        }
        if (!hist) {
                fprintf(stderr, "Échec de la création de l'histogramme\n");
                exit(-1);
        }
        if (vals) {
                sav = NULL;
                for (val = strtok_r(vals, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_value(hist, val);
                        if (ret) {
                                fprintf(stderr, "Échec de l'ajout de la valeur %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (sort) {
                sav = NULL;
                for (val = strtok_r(sort, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_sort_key(hist, val);
                        if (ret) {
                                fprintf(stderr, "Échec de l'ajout de la clé/valeur de tri %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (ascend) {
                sav = NULL;
                for (val = strtok_r(ascend, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_ASCENDING);
                        if (ret) {
                                fprintf(stderr, "Échec de l'ajout de la clé/valeur ascendante %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (desc) {
                sav = NULL;
                for (val = strtok_r(desc, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_DESCENDING);
                        if (ret) {
                                fprintf(stderr, "Échec de l'ajout de la clé/valeur descendante %s\n", val);
                                exit(-1);
                        }
                }
        }
        tracefs_error_clear(instance);
        switch (cmd) {
        case START:
                ret = tracefs_hist_start(instance, hist);
                if (ret) {
                        char *err = tracefs_error_last(instance);
                        if (err)
                                fprintf(stderr, "\n%s\n", err);
                }
                break;
        case PAUSE:
                ret = tracefs_hist_pause(instance, hist);
                break;
        case CONT:
                ret = tracefs_hist_continue(instance, hist);
                break;
        case RESET:
                ret = tracefs_hist_reset(instance, hist);
                break;
        case DELETE:
                ret = tracefs_hist_destroy(instance, hist);
                break;
        case SHOW:
                /* SHOW a déjà été fait */
                break;
        }
        if (ret)
                fprintf(stderr, "Échec : commande\n");
        exit(ret);
}
int main (int argc, char **argv, char **env)
{
        enum commands cmd;
        char *instance = NULL;
        char *cmd_str;
        char *event = NULL;
        char *keys = NULL;
        char *vals = NULL;
        char *sort = NULL;
        char *desc = NULL;
        char *ascend = NULL;
        if (argc < 2) {
                fprintf(stderr, "utilisation : %s commande [-B instance][-e [system/]événement][-k clés][-v valeurs][-s tri]\n", argv[0]);
                fprintf(stderr, "      [-a ascendant][-d descendant]\n");
                exit(-1);
        }
        cmd_str = argv[1];
        if (!strcmp(cmd_str, "start"))
                cmd = START;
        else if (!strcmp(cmd_str, "pause"))
                cmd = PAUSE;
        else if (!strcmp(cmd_str, "cont"))
                cmd = CONT;
        else if (!strcmp(cmd_str, "reset"))
                cmd = RESET;
        else if (!strcmp(cmd_str, "delete"))
                cmd = DELETE;
        else if (!strcmp(cmd_str, "show"))
                cmd = SHOW;
        else {
                fprintf(stderr, "Commande inconnue %s\n", cmd_str);
                exit(-1);
        }
        for (;;) {
                int c;
                c = getopt(argc - 1, argv + 1, "e:k:v:B:s:d:a:");
                if (c == -1)
                        break;
                switch (c) {
                case 'e':
                        event = optarg;
                        break;
                case 'k':
                        keys = optarg;
                        break;
                case 'v':
                        vals = optarg;
                        break;
                case 'B':
                        instance = optarg;
                        break;
                case 's':
                        sort = optarg;
                        break;
                case 'd':
                        desc = optarg;
                        break;
                case 'a':
                        ascend = optarg;
                        break;
                }
        }
        if (!event) {
                event = "kmem/kmalloc";
                if (!keys)
                        keys = "call_site.sym,bytes_req";
                if (!vals)
                        vals = "bytes_alloc";
                if (!sort)
                        sort = "bytes_req,bytes_alloc";
                if (!desc)
                        desc = "bytes_alloc";
        }
        process_hist(cmd, instance, event, keys, vals, sort, ascend, desc);
}
