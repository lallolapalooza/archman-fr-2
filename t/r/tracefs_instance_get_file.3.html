tracefs_instance_get_file(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_file_exists, tracefs_dir_exists, tracefs_instance_get_file, tracefs_instance_get_dir - Travailler avec les fichiers et répertoires dans les instances de traçage.

SYNOPSIS

#include <tracefs.h>
bool tracefs_file_exists(struct tracefs_instance *instance, char *name);
bool tracefs_dir_exists(struct tracefs_instance *instance, char *name);
char *tracefs_instance_get_file(struct tracefs_instance *instance, const char *file);
char *tracefs_instance_get_dir(struct tracefs_instance *instance);

DESCRIPTION

Cet ensemble d'API peut être utilisé pour travailler avec les fichiers de traçage dans toutes les instances de traçage. Chacune de ces API prend un argument instance, qui peut être NULL pour agir sur l'instance de niveau supérieur. Sinon, elle agit sur une instance créée avec tracefs_insance_create(3)

La fonction tracefs_file_exists() vérifie si un fichier nommé name existe dans l'instance.

La fonction tracefs_dir_exists() vérifie si un répertoire nommé name existe dans l'instance.

La fonction tracefs_instance_get_file() renvoie le chemin complet du fichier avec le nom file donné dans l'instance. Notez qu'elle ne vérifie pas si le fichier existe dans l'instance.

La fonction tracefs_instance_get_dir() renvoie le chemin complet du répertoire avec le nom donné dans l'instance. Notez qu'elle ne vérifie pas si le répertoire existe dans l'instance.

VALEUR DE RETOUR

Les fonctions tracefs_file_exists() et tracefs_dir_exists() renvoient vrai si le fichier / répertoire existe dans l'instance donnée, ou faux s'il n'existe pas.

Les fonctions tracefs_instance_get_file() et tracefs_instance_get_dir() renvoient une chaîne de caractères ou NULL en cas d'erreur. La chaîne retournée doit être libérée avec tracefs_put_tracing_file().

EXEMPLE

#include <tracefs.h>
struct tracefs_instance *inst = tracefs_instance_create("foo");
        if (!inst) {
                /* Erreur lors de la création d'une nouvelle instance de traçage */
                ...
        }
        if (tracefs_file_exists(inst,"trace_clock")) {
                /* L'instance foo supporte trace_clock */
                char *path, *clock;
                int size;
                path =  = tracefs_instance_get_file(inst, "trace_clock")
                if (!path) {
                        /* Erreur lors de l'obtention du chemin vers le fichier trace_clock dans l'instance foo */
                        ...
                }
                ...
                tracefs_put_tracing_file(path);
                clock = tracefs_instance_file_read(inst, "trace_clock", &size);
                if (!clock) {
                        /* Échec de la lecture du fichier trace_clock dans l'instance foo */
                        ...
                }
                ...
                free(clock);
                if (tracefs_instance_file_write(inst, "trace_clock", "global") != strlen("global")) {
                        /* Échec de la définition de l'horloge de traçage globale dans l'instance foo */
                        ...
                }
        } else {
                /* L'instance foo ne supporte pas trace_clock */
        }
        if (tracefs_dir_exists(inst,"options")) {
                /* L'instance foo supporte les options de traçage */
                char *path = tracefs_instance_get_file(inst, "options");
                if (!path) {
                        /* Erreur lors de l'obtention du chemin vers le répertoire options dans l'instance foo */
                        ...
                }
                tracefs_put_tracing_file(path);
        } else {
                /* L'instance foo ne supporte pas les options de traçage */
        }
        ...
        if (tracefs_instance_is_new(inst))
                tracefs_instance_destroy(inst);
        else
                tracefs_instance_free(inst);
        ...
        long long int res;
        if (tracefs_instance_file_read_number(NULL, "tracing_on", &res) == 0) {
                if (res == 0) {
                        /* le traçage est désactivé dans l'instance principale */
                } else if (res == 1) {
                        /* le traçage est activé dans l'instance principale */
                } else {
                        /* État de traçage inconnu de l'instance principale */
                }
        } else {
                /* Échec de la lecture d'un entier depuis le fichier tracing_on */
        }
        ...
        int fd;
        fd = tracefs_instance_file_open(NULL, "tracing_on", O_WRONLY);
        if (fd >= 0) {
                /* Obtention du descripteur de fichier vers le fichier tracing_on depuis l'instance principale pour écriture */
                ...
                close(fd);
        }
