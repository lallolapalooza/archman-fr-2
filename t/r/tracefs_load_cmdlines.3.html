LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_local_events, tracefs_local_events_system, tracefs_fill_local_events, tracefs_load_cmdlines, tracefs_load_headers - Initialise un gestionnaire tep avec les événements de trace du système local.

SYNTAXE

#include <tracefs.h>
struct tep_handle *tracefs_local_events(const char *tracing_dir);
struct tep_handle *tracefs_local_events_system(const char *tracing_dir, const char * const *sys_names);
int tracefs_fill_local_events(const char *tracing_dir, struct tep_handle *tep, int *parsing_failures);
int tracefs_load_cmdlines(const char *tracing_dir, struct tep_handle *tep);
int tracefs_load_headers(const char *tracing_dir, struct tep_handle *tep);

DESCRIPTION

Fonctions pour initialiser un gestionnaire tep avec les événements de trace du système local.

La fonction tracefs_local_events() alloue un nouveau gestionnaire tep et l'initialise avec les événements de tous les systèmes de trace, situés dans le répertoire tracing_dir donné. Il peut s'agir de NULL ou de l'emplacement du point de montage tracefs pour les systèmes de trace de la machine locale, ou il peut s'agir d'un chemin vers une copie du répertoire tracefs d'une autre machine.

La fonction tracefs_local_events_system() alloue un nouveau gestionnaire tep et l'initialise avec les événements des systèmes de trace spécifiés sys_names, situés dans le répertoire tracing_dir donné. Il peut s'agir de NULL ou de l'emplacement du point de montage tracefs pour les systèmes de trace de la machine locale, ou il peut s'agir d'un chemin vers une copie du répertoire tracefs d'une autre machine. L'argument sys_names est un tableau de noms de systèmes de trace, qui sera utilisé pour l'initialisation du gestionnaire tep. Le dernier élément de ce tableau doit être un pointeur NULL.

La fonction tracefs_fill_local_events() initialise un gestionnaire tep déjà alloué avec les événements de tous les systèmes de trace, situés dans le répertoire tracing_dir donné. Il peut s'agir de NULL ou de l'emplacement du point de montage tracefs pour les systèmes de trace de la machine locale, ou il peut s'agir d'un chemin vers une copie du répertoire tracefs d'une autre machine. L'argument tep doit être un pointeur vers un gestionnaire tep déjà alloué, qui va être initialisé. L'argument parsing_failures peut être NULL ou un pointeur vers un entier, où le nombre d'échecs lors de l'analyse des fichiers d'événements est retourné.

Les fonctions ci-dessus chargeront également les mappages entre les pid et les noms des lignes de commande des processus. Dans certains cas, le gestionnaire tep est créé avec l'une des fonctions ci-dessus avant que le traçage ne commence. Étant donné que les mappages sont mis à jour pendant le traçage, il peut être nécessaire de relire les mappages après le traçage. La fonction tracefs_load_cmdlines() fait exactement cela. tracing_dir est le répertoire du point de montage à partir duquel charger, ou NULL pour utiliser le point de montage du système de fichiers tracefs.

La fonction tracefs_load_headers() lira la page d'en-tête ("header_page") du répertoire des événements, ce qui mettra à jour le gestionnaire tep avec des informations sur la façon de parser le sous-buffer de l'anneau de traçage.

VALEUR DE RETOUR

Les fonctions tracefs_local_events() et tracefs_local_events_system() retournent un pointeur vers un gestionnaire tep alloué et initialisé, ou NULL en cas d'erreur. Le gestionnaire tep retourné doit être libéré avec tep_free(3).

La fonction tracefs_fill_local_events() retourne -1 en cas d'erreur, ou 0 sinon.

La fonction tracefs_load_cmdlines() retourne -1 en cas d'erreur, ou 0 sinon.

EXEMPLE

#include <tracefs.h>
struct tep_handle *tep;
...
        tep = tracefs_local_events(NULL);
        if (!tep) {
                /* Échec de l'initialisation du gestionnaire tep avec les événements locaux de l'instance supérieure */
                ...
        }
...
        tep_free(tep);
...
        const char *systems[] = {"ftrace", "irq", NULL};
        tep = tracefs_local_events_system(NULL, systems);
        if (!tep) {
                /* Échec de l'initialisation du gestionnaire tep avec les événements locaux des
                 * systèmes ftrace et irq dans l'instance supérieure.
                 */
                ...
        }
...
        tep_free(tep);
...
        int parsing_failures;
        tep = tep_alloc();
        if (!tep) {
                /* Échec de l'allocation d'un gestionnaire tep */
                ...
        }
        if (tracefs_fill_local_events(NULL, tep, &parsing_failures) < 0) {
                /* Échec de l'initialisation du gestionnaire tep avec les événements locaux de l'instance supérieure */
        }
        tracefs_load_cmdlines(NULL, tep);
...
        tep_free(tep);
