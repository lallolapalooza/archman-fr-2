CTRSYL3

Objectif :

!>
!>  CTRSYL3 résout l'équation matricielle de Sylvester complexe :
!>
!>     op(A)*X + X*op(B) = scale*C ou
!>     op(A)*X - X*op(B) = scale*C,
!>
!>  où op(A) = A ou A**H, et A et B sont toutes deux triangulaires supérieures. A
!>  est de taille M par M et B est de taille N par N ; le membre de droite C et
!>  la solution X sont de taille M par N ; et scale est un facteur d'échelle
!>  de sortie, défini à <= 1 pour éviter le débordement dans X.
!>
!>  C'est la version par blocs de l'algorithme.
!>

Paramètres

TRANA 
!>          TRANA est CHARACTER*1
!>          Spécifie l'option op(A) :
!>          = 'N': op(A) = A    (Pas de transposée)
!>          = 'C': op(A) = A**H (Conjuguée transposée)
!>

TRANB

!>          TRANB est CHARACTER*1
!>          Spécifie l'option op(B) :
!>          = 'N': op(B) = B    (Pas de transposée)
!>          = 'C': op(B) = B**H (Conjuguée transposée)
!>

ISGN

!>          ISGN est INTEGER
!>          Spécifie le signe dans l'équation :
!>          = +1 : résout op(A)*X + X*op(B) = scale*C
!>          = -1 : résout op(A)*X - X*op(B) = scale*C
!>

M

!>          M est INTEGER
!>          L'ordre de la matrice A, et le nombre de lignes dans
!>          les matrices X et C. M >= 0.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice B, et le nombre de colonnes dans
!>          les matrices X et C. N >= 0.
!>

A

!>          A est un tableau COMPLEX, de dimension (LDA,M)
!>          La matrice triangulaire supérieure A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau COMPLEX, de dimension (LDB,N)
!>          La matrice triangulaire supérieure B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

C

!>          C est un tableau COMPLEX, de dimension (LDC,N)
!>          En entrée, la matrice C de taille M par N du membre de droite.
!>          En sortie, C est écrasé par la matrice solution X.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M)
!>

SCALE

!>          SCALE est REAL
!>          Le facteur d'échelle, scale, défini à <= 1 pour éviter le
!>          débordement dans X.
!>

SWORK

!>          SWORK est un tableau REAL, de dimension (MAX(2, ROWS), MAX(1,COLS)).
!>          En sortie, si INFO = 0, SWORK(1) contient la valeur optimale ROWS
!>          et SWORK(2) contient la valeur optimale COLS.
!>

LDSWORK

!>          LDSWORK est INTEGER
!>          LDSWORK >= MAX(2,ROWS), où ROWS = ((M + NB - 1) / NB + 1)
!>          et NB est la taille de bloc optimale.
!>
!>          Si LDSWORK = -1, alors une requête de mémoire vive est supposée ; la
!>          routine calcule uniquement les dimensions optimales du tableau
!>          SWORK, renvoie ces valeurs comme première et deuxième entrées du
!>          tableau SWORK, et aucun message d'erreur lié à LWORK n'est émis par
!>          XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          = 1 : A et B ont des valeurs propres communes ou très proches ; des
!>               valeurs perturbées ont été utilisées pour résoudre l'équation (mais
!>               les matrices A et B ne sont pas modifiées).
!>

DTRSYL3

Objectif :

!>
!>  DTRSYL3 résout l'équation matricielle de Sylvester réelle :
!>
!>     op(A)*X + X*op(B) = scale*C ou
!>     op(A)*X - X*op(B) = scale*C,
!>
!>  où op(A) = A ou A**T, et A et B sont toutes deux quasi-triangulaires
!>  supérieures. A est de taille M par M et B est de taille N par N ; le
!>  membre de droite C et la solution X sont de taille M par N ; et scale est
!>  un facteur d'échelle de sortie, défini à <= 1 pour éviter le débordement
!>  dans X.
!>
!>  A et B doivent être en forme canonique de Schur (comme renvoyé par DHSEQR),
!>  c'est-à-dire, triangulaires supérieures par blocs avec des blocs diagonaux
!>  de 1x1 et 2x2 ; chaque bloc diagonal 2x2 a ses éléments diagonaux égaux
!>  et ses éléments hors diagonaux de signe opposé.
!>
!>  C'est la version par blocs de l'algorithme.
!>

Paramètres

TRANA 
!>          TRANA est CHARACTER*1
!>          Spécifie l'option op(A) :
!>          = 'N': op(A) = A    (Pas de transposée)
!>          = 'T': op(A) = A**T (Transposée)
!>          = 'C': op(A) = A**H (Conjuguée transposée = Transposée)
!>

TRANB

!>          TRANB est CHARACTER*1
!>          Spécifie l'option op(B) :
!>          = 'N': op(B) = B    (Pas de transposée)
!>          = 'T': op(B) = B**T (Transposée)
!>          = 'C': op(B) = B**H (Conjuguée transposée = Transposée)
!>

ISGN

!>          ISGN est INTEGER
!>          Spécifie le signe dans l'équation :
!>          = +1 : résout op(A)*X + X*op(B) = scale*C
!>          = -1 : résout op(A)*X - X*op(B) = scale*C
!>

M

!>          M est INTEGER
!>          L'ordre de la matrice A, et le nombre de lignes dans
!>          les matrices X et C. M >= 0.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice B, et le nombre de colonnes dans
!>          les matrices X et C. N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, de dimension (LDA,M)
!>          La matrice quasi-triangulaire supérieure A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau DOUBLE PRECISION, de dimension (LDB,N)
!>          La matrice quasi-triangulaire supérieure B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

C

!>          C est un tableau DOUBLE PRECISION, de dimension (LDC,N)
!>          En entrée, la matrice C de taille M par N du membre de droite.
!>          En sortie, C est écrasé par la matrice solution X.
!>

LDC

!>          LDC est INTEGER
!>          La dimension principale du tableau C. LDC >= max(1,M).
!>

SCALE

!>          SCALE est DOUBLE PRECISION
!>          Le facteur d'échelle, scale, défini à <= 1 pour éviter le
!>          débordement dans X.
!>

IWORK

!>          IWORK est un tableau INTEGER de dimension (LIWORK).
!>          Indices pour les blocs de 2x2.
!>

LIWORK

!>          LIWORK est INTEGER
!>          La dimension du tableau IWORK. LIWORK >= MAX(1,MIN(M,N)).
!>

SWORK

!>          SWORK est un tableau DOUBLE PRECISION, de dimension (MAX(2,ROWS), MAX(1,COLS)).
!>          En sortie, si INFO = 0, SWORK(1) contient la valeur optimale ROWS
!>          et SWORK(2) contient la valeur optimale COLS.
!>

LDSWORK

!>          LDSWORK est INTEGER
!>          LDSWORK >= MAX(2,ROWS), où ROWS = ((M + NB - 1) / NB + 1)
!>          et NB est la taille de bloc optimale.
!>
!>          Si LDSWORK = -1, alors une requête de mémoire vive est supposée ; la
!>          routine calcule uniquement les dimensions optimales du tableau
!>          SWORK, renvoie ces valeurs comme première et deuxième entrées du
!>          tableau SWORK, et aucun message d'erreur lié à LWORK n'est émis par
!>          XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          = 1 : A et B ont des valeurs propres communes ou très proches ; des
!>               valeurs perturbées ont été utilisées pour résoudre l'équation (mais
!>               les matrices A et B ne sont pas modifiées).
!>

NAME

TRS_YR3

SYNOPSIS

SUBROUTINE TRS_YR3( UPLO, TRANS, DIAG, M, N, A, LDA, B, LDB, C, LDC,
                   SCALE, SWORK, LDSWORK, INFO )

TRS_YR3 solves the Sylvester matrix equation:

    A*X + X*B = C,

or

    A*X + X*B^H = C,

or

    A*X + X*B^T = C,

or

    A^H*X + X*B = C,

where A and B are upper triangular matrices, and X and C are matrices.

Detailed Description

This routine is a translation of the LAPACK routine ZTRSYL.

Arguments:

Function Documentation

UPLO 

!>          UPLO is CHARACTER*1
!>          Specifies whether A and B are upper or lower triangular.
!>          = 'U': A and B are upper triangular.
!>          = 'L': A and B are lower triangular.
!>

TRANS 

!>          TRANS is CHARACTER*1
!>          Specifies the form of the equations:
!>          = 'N': Solve A*X + X*B = C
!>          = 'T': Solve A*X + X*B**T = C
!>          = 'C': Solve A*X + X*B**H = C
!>

DIAG 

!>          DIAG is CHARACTER*1
!>          Specifies whether A and B are unit triangular.
!>          = 'U': A and B are unit triangular.
!>          = 'N': A and B are not unit triangular.
!>

M 

!>          M is INTEGER
!>          The order of the matrix A, and the number of rows in the
!>          matrices X and C. M >= 0.
!>

N 

!>          N is INTEGER
!>          The order of the matrix B, and the number of columns in the
!>          matrices X and C. N >= 0.
!>

A 

!>          A is COMPLEX*16 array, dimension (LDA,M)
!>          The upper triangular matrix A.
!>

LDA 

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,M).
!>

B 

!>          B is COMPLEX*16 array, dimension (LDB,N)
!>          The upper triangular matrix B.
!>

LDB 

!>          LDB is INTEGER
!>          The leading dimension of the array B. LDB >= max(1,N).
!>

C 

!>          C is COMPLEX*16 array, dimension (LDC,N)
!>          On entry, the M-by-N right hand side matrix C.
!>          On exit, C is overwritten by the solution matrix X.
!>

LDC 

!>          LDC is INTEGER
!>          The leading dimension of the array C. LDC >= max(1,M)
!>

SCALE 

!>          SCALE is DOUBLE PRECISION
!>          The scale factor, scale, set <= 1 to avoid overflow in X.
!>

SWORK 

!>          SWORK is DOUBLE PRECISION array, dimension (MAX(2, ROWS),
!>          MAX(1,COLS)).
!>          On exit, if INFO = 0, SWORK(1) returns the optimal value ROWS
!>          and SWORK(2) returns the optimal COLS.
!>

LDSWORK 

!>          LDSWORK is INTEGER
!>          LDSWORK >= MAX(2,ROWS), where ROWS = ((M + NB - 1) / NB + 1)
!>          and NB is the optimal block size.
!>
!>          If LDSWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal dimensions of the SWORK matrix,
!>          returns these values as the first and second entry of the SWORK
!>          matrix, and no error message related LWORK is issued by XERBLA.
!>

INFO 

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>          = 1: A and B have common or very close eigenvalues; perturbed
!>               values were used to solve the equation (but the matrices
!>               A and B are unchanged).
!>
