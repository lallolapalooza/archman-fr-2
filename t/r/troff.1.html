troff(1) Manuel des commandes générales troff(1)

Nom

troff - composeur et formateur de documents GNU roff

Synopsis

troff [-abcCEiRUz] [-d ctexte] [-d chaine=texte] [-f famille-police] [-F repertoire-police] [-I repertoire-inclusion] [-m paquet-macros] [-M repertoire-macros] [-n numero-page] [-o liste-pages] [-r expression-numerique-c] [-r registre=expression-numerique] [-T appareil-sortie] [-w categorie-avertissement] [-W categorie-avertissement] [fichier ...]
troff --help
troff -v
troff --version

Description

GNU troff transforme l'entrée du langage groff(7) en le format de sortie indépendant de l'appareil décrit dans groff_out(5); troff est donc le cœur du système de formatage de documents GNU roff. Si aucun opérande fichier n'est donné sur la ligne de commande, ou si fichier est « - », le flux d'entrée standard est lu.

GNU troff est fonctionnellement compatible avec le composeur AT&T troff et présente de nombreuses extensions. Beaucoup de gens préfèrent utiliser la commande groff(1), une interface qui exécute également les préprocesseurs et les pilotes de sortie dans l'ordre approprié et avec les options appropriées.

Options

-h et --help affichent un message d'utilisation, tandis que -v et --version affichent les informations de version ; tous se terminent ensuite.

-a
Génère une approximation textuelle de la sortie composée. Le registre en lecture seule .A est mis à 1. Cette option produit une sorte d'aperçu abstrait de la sortie formatée.
•
Les sauts de page sont marqués par une phrase entre crochets ; par exemple, « <début de page> ».
•
Les lignes sont coupées là où elles le seraient dans la sortie formatée.
•
Un mouvement horizontal de toute taille est représenté par un espace. Les mouvements horizontaux adjacents ne sont pas combinés. Les nœuds d'espace inter-phrases (ceux résultant du deuxième argument de la requête .ss) ne sont pas représentés.
•
Les mouvements verticaux ne sont pas représentés.
•
Les caractères spéciaux sont rendus entre crochets ; par exemple, le caractère de trait d'union doux par défaut apparaît sous la forme « <hy> ».
La description ci-dessus ne doit pas être considérée comme une spécification ; les détails de la sortie -a sont sujets à modification.
-b
Écrit une trace arrière rapportant l'état de l'analyseur d'entrée de troff sur le flux d'erreur standard avec chaque message de diagnostic. Les numéros de ligne donnés dans la trace arrière peuvent ne pas toujours être corrects, car l'idée des numéros de ligne de troff peut être confondue par les requêtes qui ajoutent aux macros.
-c
Commence avec la sortie couleur désactivée.
-C
Active le mode de compatibilité AT&T troff ; implique -c. Voir groff_diff(7).
-d ctexte
-d chaine=texte
Définit la chaîne roff c ou chaine comme texte. c doit être un caractère ; chaine peut avoir une longueur arbitraire. De telles affectations de chaîne se produisent avant le chargement de tout fichier macro, y compris le fichier de démarrage. En raison des limitations de getopt_long(3), c ne peut pas être, et chaine ne peut pas contenir, un signe égal, même si c'est un caractère valide dans un identifiant roff.
-E
Interdit les messages d'erreur de troff ; implique -Ww. Cette option ne supprime *pas* les messages envoyés au flux d'erreur standard par les documents ou les paquets de macros utilisant tm ou des requêtes associées.
-f fam
Utilise fam comme famille de polices par défaut.
-F dir
Recherche dans le répertoire dir le répertoire de fichiers de description d'appareil et de polices de l'appareil de sortie sélectionné. Voir la description de GROFF_FONT_PATH dans la section « Environnement » ci-dessous pour les emplacements de recherche par défaut et leur ordre.
-i
Lit le flux d'entrée standard après que tous les fichiers d'entrée nommés ont été traités.
-I dir
Recherche dans le répertoire dir les fichiers (ceux nommés sur la ligne de commande ; dans les requêtes psbb, so et soquiet ; et dans les séquences d'échappement de contrôle d'appareil « \X'ps: import' », « \X'ps: file' » et « \X'pdf: pdfpic' »). -I peut être spécifié plus d'une fois ; chaque dir est recherché dans l'ordre donné. Pour rechercher le répertoire de travail courant avant les autres, ajoutez « -I . » à l'endroit souhaité ; il est par ailleurs recherché en dernier. -I fonctionne de manière similaire à l'option « include » des compilateurs C Unix, et porte le même nom.
-m nom
Traite le fichier nom.tmac avant tout fichier d'entrée. S'il n'est pas trouvé, tmac.nom est tenté. nom (dans les deux arrangements) est présumé être un fichier de macros ; voir la description de GROFF_TMAC_PATH dans la section « Environnement » ci-dessous pour les emplacements de recherche par défaut et leur ordre.
-M dir
Recherche dans le répertoire dir les fichiers de macros. Voir la description de GROFF_TMAC_PATH dans la section « Environnement » ci-dessous pour les emplacements de recherche par défaut et leur ordre.
-n num
Commence la numérotation des pages à num. La valeur par défaut est 1.
-o liste
N'affiche que les pages dans liste, qui est une liste séparée par des virgules de plages de pages inclusives ; n signifie page n, m-n signifie chaque page entre m et n, -n signifie chaque page jusqu'à n, et n- signifie chaque page à partir de n. troff arrête le traitement et se termine après avoir formaté la dernière page énumérée dans liste.
-r expression-numerique-c
-r registre=expression-numerique
Définit le registre roff c ou registre comme expression-numerique. c doit être un nom d'un caractère ; registre peut avoir une longueur arbitraire. Ces affectations de registre se produisent avant le chargement de tout fichier macro, y compris le fichier de démarrage. En raison des limitations de getopt_long(3), c ne peut pas être, et registre ne peut pas contenir, un signe égal, même si c'est un caractère valide dans un identifiant roff.
-R
Ne charge pas troffrc et troffrc-end.
-T dev
Prépare la sortie pour l'appareil dev. La valeur par défaut est ps ; voir groff(1).
-U
Fonctionne en mode non sécurisé, activant les requêtes open, opena,

Avertissements

Les diagnostics d'avertissement émis par troff sont divisés en catégories nommées et numérotées. Le nom associé à chaque catégorie d'avertissement est utilisé par les options -w et -W. Chaque catégorie se voit également attribuer une puissance de deux ; la somme des codes de catégorie activés est utilisée par la requête warn et le registre .warn. Les avertissements de chaque catégorie sont produits dans les circonstances suivantes.

Cet avertissement est également émis lors d'une tentative de déplacer une macro de piège non plantée. Dans de tels cas, la macro non plantée n'est *pas* déréférencée, donc elle n'est pas créée si elle n'existe pas.

Une requête a été invoquée avec un argument obligatoire absent.
number 2
Une expression numérique invalide a été rencontrée. Cette catégorie est activée par défaut.
range 64
Une expression numérique était hors de portée pour son contexte.
reg 1024
Un registre non défini a été utilisé. Lorsqu'un registre non défini est déréférencé, il est automatiquement défini avec une valeur de 0. Ainsi, à moins qu'il ne soit supprimé ultérieurement, un seul avertissement est émis pour chacun.
right-brace 4096
Une séquence d'échappement d'accolade droite \} a été rencontrée là où un nombre était attendu.
scale 32
Une unité de mise à l'échelle inappropriée à son contexte a été utilisée dans une expression numérique.
space 65536
Un espace était manquant entre une requête ou une macro et son argument. Cet avertissement est produit lorsqu'un nom indéfini de plus de deux caractères est rencontré et que les deux premiers caractères du nom constituent un nom défini. Aucune requête n'est invoquée, aucune macro appelée, et aucune macro vide n'est définie. Cette catégorie est activée par défaut. Elle ne se produit jamais en mode compatibilité.
syntax 128
Un mode de césure contradictoire a été demandé ; une expression numérique vide ou incomplète a été rencontrée ; un opérande d'un opérateur numérique était manquant ; une tentative a été faite pour définir une classe de caractères récursive, vide ou absurde ; ou un opérateur d'expression conditionnelle d'extension groff a été utilisé en mode compatibilité.
tab 2048
Un caractère de tabulation a été rencontré là où un nombre était attendu, ou est apparu dans un argument de macro non cité.

Deux noms d'avertissement regroupent d'autres catégories d'avertissement par commodité.

all
Toutes les catégories d'avertissement à l'exception de di, mac et reg. Ce raccourci est destiné à produire tous les avertissements utiles avec les paquets de macros et les documents écrits pour troff AT&T et ses descendants, qui ont des diagnostics moins rigoureux que GNU troff.
w
Toutes les catégories d'avertissement. Les auteurs de documents et de paquets de macros ciblant groff sont encouragés à utiliser ce réglage.

Environnement

GROFF_FONT_PATH et GROFF_TMAC_PATH acceptent chacun un chemin de recherche de répertoires ; c'est-à-dire une liste de noms de répertoires séparés par le caractère séparateur de composant de chemin du système. Sur les systèmes Unix, ce caractère est un deux-points (:); sur les systèmes Windows, c'est un point-virgule (;).

GROFF_FONT_PATH
Une liste de répertoires dans lesquels rechercher le répertoire des fichiers de description de périphériques et de polices du périphérique de sortie sélectionné. troff analysera les répertoires donnés en arguments à toute option -F spécifiée avant ceux-ci, puis dans un répertoire spécifique au site (/usr/share/groff/site-font), un emplacement standard (/usr/share/groff/1.23.0/font), et un répertoire de compatibilité (/usr/lib/font) après eux.
GROFF_TMAC_PATH
Une liste de répertoires dans lesquels rechercher les fichiers de macros. troff analysera
scan les répertoires donnés comme arguments à toutes les options -M spécifiées avant ceux-ci, puis le répertoire courant (uniquement en mode non sécurisé), le répertoire personnel de l'utilisateur, un répertoire spécifique au site (/usr/share/groff/site-tmac), et un emplacement standard (/usr/share/groff/1.23.0/tmac) après ceux-ci.
GROFF_TYPESETTER
Définit le périphérique de sortie par défaut. Si vide ou non défini, ps est utilisé. L'option -T remplace GROFF_TYPESETTER.
SOURCE_DATE_EPOCH
Un horodatage (exprimé en secondes depuis l'époque Unix) à utiliser comme horodatage de création de la sortie à la place de l'heure actuelle. L'heure est convertie en forme lisible par l'homme à l'aide de localtime(3) au démarrage du formateur et stockée dans des registres utilisables par les documents et les paquets de macros.
TZ
Le fuseau horaire à utiliser lors de la conversion de l'heure actuelle (ou de la valeur de SOURCE_DATE_EPOCH) en forme lisible par l'homme ; voir tzset(3).

Fichiers

/usr/share/groff/1.23.0/tmac/troffrc
est un fichier de macros d'initialisation chargé avant tout paquet de macros spécifié avec les options -m.
/usr/share/groff/1.23.0/tmac/troffrc-end
est un fichier de macros d'initialisation chargé après tous les paquets de macros spécifiés avec les options -m.
/usr/share/groff/1.23.0/tmac/name.tmac
sont des fichiers de macros distribués avec groff.
/usr/share/groff/1.23.0/font/devname/DESC
décrit le périphérique de sortie name.
/usr/share/groff/1.23.0/font/devname/F
décrit la police F du périphérique name.

troffrc et troffrc-end ne sont recherchés ni dans le répertoire courant ni dans le répertoire personnel par défaut pour des raisons de sécurité, même si l'option -U est spécifiée. Utilisez l'option de ligne de commande -M ou la variable d'environnement GROFF_TMAC_PATH pour ajouter ces répertoires au chemin de recherche si nécessaire.
