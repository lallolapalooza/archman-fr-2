DESCRIPTION

Les événements synthétiques sont des événements dynamiques créés en faisant correspondre deux autres événements, ce qui déclenche un événement synthétique. Un événement est l'événement de départ dont un champ est enregistré, et lorsque le second événement est exécuté, s'il possède un champ (ou des champs) qui correspond au champ (ou aux champs) de l'événement de départ, il déclenche l'événement synthétique. Les valeurs des champs, autres que les champs correspondants, peuvent être transmises de l'événement de départ à l'événement de fin pour effectuer des calculs, ou simplement pour servir de paramètre à l'événement synthétique.

Un cas d'utilisation courant consiste à définir "sched_waking" comme événement de départ. Cet événement est déclenché lorsqu'un processus est réveillé. Ensuite, définissez "sched_switch" comme événement de fin. Cet événement est déclenché lorsqu'une nouvelle tâche est planifiée sur le CPU. En définissant le "common_pid" des deux événements comme champs de correspondance, le temps entre les deux événements est considéré comme la latence de réveil de ce processus. Utilisez TRACEFS_TIMESTAMP comme champ pour les deux événements afin de calculer la différence en nanosecondes, ou utilisez "TRACEFS_TIMESTAMP_USECS" comme champs de comparaison pour les deux événements afin de calculer la différence en microsecondes. Ceci est utilisé dans l'exemple ci-dessous.

tracefs_synth_alloc() alloue et initialise un événement synthétique. Il ne crée pas l'événement synthétique, mais fournit les informations minimales pour le faire. Voir tracefs_synth_create(3) pour la manière de créer l'événement synthétique dans le système. Il nécessite un gestionnaire tep qui peut être créé par tracefs_local_events(3) pour plus d'informations. Le name contient le nom de l'événement synthétique qui sera créé. Le start_system est le nom du système pour l'événement de départ. Il peut être NULL et le premier événement portant le nom start_event sera choisi. Le end_system est le nom du système pour l'événement de fin. Il peut être NULL et le premier événement portant le nom end_event sera choisi comme événement de fin. Si match_name est spécifié, alors ce sera le champ de l'événement synthétique créé qui contiendra les clés correspondantes du start_match_field de l'événement de départ et du end_match_field de l'événement de fin. Si match_name est NULL, alors il ne sera pas enregistré dans l'événement synthétique créé.

tracefs_synth_add_match_field() ajoutera une seconde clé pour faire correspondre l'événement de départ et l'événement de fin. Si name est spécifié, alors le contenu du champ correspondant sera sauvegardé sous ce name dans l'événement synthétique. Le start_match_field est le champ de l'événement de départ à faire correspondre avec le end_match_field de l'événement de fin.

tracefs_synth_add_compare_field() est utilisé pour comparer le start_compare_field de l'événement de départ avec le end_compare_field de l'événement de fin. Le name doit être spécifié afin que le résultat soit sauvegardé par l'événement synthétique. Il n'est pas logique de ne pas passer cela à l'événement synthétique après avoir effectué le travail des champs comparés, car cela n'a aucune autre utilité. Le paramètre calc peut être l'un des suivants :

TRACEFS_SYNTH_DELTA_END - calcule la différence entre le contenu de end_compare_field et le contenu de start_compare_field.

name = end_compare_field - start_compare_field

TRACEFS_SYNTH_DELTA_START - calcule la différence entre le contenu de start_compare_field et le contenu de end_compare_field.

name = start_compare_field - end_compare_field

TRACEFS_SYNTH_ADD - Ajoute le contenu de start_compare_field au contenu de end_compare_field.

name = start_compare_field + end_compare_field

tracefs_synth_add_start_field() - Enregistre le start_field de l'événement de départ sous le nom name dans l'événement synthétique. Si name est NULL, le nom utilisé sera le même que start_field.

tracefs_synth_add_end_field() - Enregistre le end_field de l'événement de fin sous le nom name dans l'événement synthétique. Si name est NULL, le nom utilisé sera le même que end_field.

tracefs_synth_append_start_filter() crée un filtre ou y en ajoute un pour l'événement de départ. Selon type, il construira une chaîne de jetons pour les parenthèses ou les instructions logiques, ou il pourra ajouter une comparaison de field avec val basée sur compare.

Si type est : TRACEFS_FILTER_COMPARE - Voir ci-dessous TRACEFS_FILTER_AND - Ajoute "&&" au filtre TRACEFS_FILTER_OR - Ajoute "||" au filtre TRACEFS_FILTER_NOT - Ajoute "!" au filtre TRACEFS_FILTER_OPEN_PAREN - Ajoute "(" au filtre TRACEFS_FILTER_CLOSE_PAREN - Ajoute ")" au filtre

field, compare et val sont ignorés sauf si type est égal à TRACEFS_FILTER_COMPARE, alors _compare sera utilisé pour les opérations suivantes :

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ "val" : où field est une chaîne.

TRACEFS_COMPARE_AND - field & val : où field est un champ de drapeaux.

tracefs_synth_append_end_filter() est identique à tracefs_synth_append_start_filter mais filtre sur l'événement de fin.

tracefs_synth_free() libère le descripteur alloué renvoyé par tracefs_synth_alloc().

DESCRIPTION

The tracefs library provides functions to create and manage synthetic events. Synthetic events are not events that are generated by the kernel, but events that are created by user space based on existing kernel events. They are useful for correlating events and calculating derived metrics.

The process of creating a synthetic event involves the following steps:

  1. Allocate a synthetic event descriptor using tracefs_synth_alloc(). This function takes a trace event handle, a name for the synthetic event, and the names of the start and end events, along with their respective fields used for matching and comparing.
  2. Add fields from the start and end events to the synthetic event descriptor using tracefs_synth_add_start_field() and tracefs_synth_add_end_field(). These functions allow you to specify which fields from the original events should be included in the synthetic event, optionally with an alias.
  3. Add a field that represents a comparison between fields from the start and end events using tracefs_synth_add_compare_field(). This is useful for calculating differences or other derived values.
  4. Append filters to the synthetic event using tracefs_synth_append_start_filter() and tracefs_synth_append_end_filter(). Filters allow you to specify conditions that must be met for the synthetic event to be generated.
  5. Optionally, you can use tracefs_synth_echo_cmd() to get a string representation of the command that would create the synthetic event in the tracefs filesystem. This is useful for debugging.
  6. Finally, create the synthetic event in the tracefs filesystem using tracefs_synth_create() or remove it using tracefs_synth_destroy().
  7. Free the synthetic event descriptor when it is no longer needed using tracefs_synth_free().

RETURN VALUE

tracefs_synth_alloc() returns an allocated struct tracefs_synth descriptor on success or NULL on error.

All other functions that return an integer returns zero on success or -1 on error.

ERREURS

The following errors are for all the above calls:

EPERM Not run as root user when required.

EINVAL Either a parameter is not valid (NULL when it should not be) or a field that is not compatible for calculations.

ENODEV An event or one of its fields is not found.

EBADE The fields of the start and end events are not compatible for either matching or comparing.

ENOMEM not enough memory is available.

And more errors may have happened from the system calls to the system.

EXEMPLE

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Load all events from the system */
        tep = tracefs_local_events(NULL);
        /* Initialize the synthetic event */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* The tep is no longer needed */
        tep_free(tep);
        /* Save the "prio" field as "prio" from the start event */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Save the "next_comm" as "comm" from the end event */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Save the "prev_prio" as "prev_prio" from the end event */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Take a microsecond time difference between end and start
         * and record as "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Only record if start event "prio" is less than 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Only record if end event "next_prio" is less than 50
         * or the previous task's prio was not greater than or equal to 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Note, the above only added: "next_prio < 50 || !(prev_prio >= 100"
         * That's because, when the synth is executed, the remaining close parenthesis
         * will be added. That is, the string will end up being:
         * "next_prio < 50 || !(prev_prio >= 100)" when one of tracefs_sync_create()
         * or tracefs_sync_echo_cmd() is run.
         */
}
/* Display how to create the synthetic event */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Create the synthetic event */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Delete the synthetic event */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}
