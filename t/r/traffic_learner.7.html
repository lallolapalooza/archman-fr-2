TRAFFIC_LEARNER(7) Commandes utilisateur TRAFFIC_LEARNER(7)

NOM

traffic_learner - Outil Samba pour aider à la génération de trafic.

SYNTAXE

traffic_learner {-o FICHIER_SORTIE ...} [-h] [--dns-mode {inline|count}] [FICHIER_RESUME] [FICHIER_RESUME ...]

DESCRIPTION

Cet outil fait partie de la suite samba(7).

Cet outil aide à la génération de trafic Samba. Il prend un fichier de résumé de trafic (produit par traffic_summary.pl) en entrée et produit un fichier modèle de trafic qui peut être utilisé par traffic_replay pour la génération de trafic.

Le fichier modèle résume les types de trafic ('conversations' entre un hôte et un DC Samba) qui se produisent sur un réseau. Le fichier modèle décrit le trafic d'une manière qui permet de le mettre à l'échelle afin que soit plus (ou moins) de paquets soient envoyés, et que les paquets puissent être envoyés à un rythme plus rapide (ou plus lent) que celui observé sur le réseau.

OPTIONS

-h|--help

Affiche un résumé des options de la ligne de commande.

FICHIER_RESUME

Fichier contenant un résumé du trafic réseau. Le fichier de résumé de trafic doit être généré par traffic_summary.pl à partir d'une capture de paquets du trafic réseau réel. Plus d'un fichier peut être spécifié, auquel cas le trafic sera combiné en un seul modèle de trafic. Si aucun FICHIER_RESUME n'est spécifié, cet outil lira le résumé de trafic depuis STDOUT, c'est-à-dire que vous pouvez rediriger la sortie de traffic_summary.pl directement vers cet outil.

-o|--out FICHIER_SORTIE

Le modèle de trafic produit sera écrit dans ce fichier. Le FICHIER_SORTIE peut ensuite être passé à traffic_replay pour générer (et manipuler) le trafic réseau Samba.

--dns-mode [inline|count]

Comment le trafic DNS doit être géré par le modèle.

EXEMPLES

Pour prendre un fichier de résumé de trafic et produire un fichier modèle de trafic, utilisez :

traffic_learner traffic-summary.txt -o traffic-model.txt

Pour générer un modèle de trafic à partir d'une capture de paquets, vous pouvez rediriger le résumé de trafic vers STDOUT en utilisant :

tshark -r capture.pcapng -T pdml | traffic_summary.pl | traffic_learner -o traffic-model.txt

FORMAT FICHIER SORTIE

Le fichier modèle de sortie décrit un modèle de Markov estimant la probabilité qu'un paquet se produise étant donné les deux derniers paquets.

Le compte de chaque continuation après une paire de paquets successifs est stocké, et les ratios de ces comptes sont utilisés pour calculer les probabilités pour le paquet suivant.

Le modèle est stocké au format JSON, et contient également des informations sur le débit de paquets et le débit de trafic DNS.

Exemple de liste ngram

La liste suivante montre un exemple inventé d'une seule entrée ngram.

          "ngrams": {
             "ldap:0\tdcerpc:11": {
                 "lsarpc:77": 1,
                 "ldap:2": 370,
                 "ldap:3": 62,
                 "wait:3": 2,
                 "-": 1
             }, [...]
          }

Cela compte les continuations observées après un paquet ldap avec l'opcode 0 (une liaison) suivi d'un paquet dcerpc avec l'opcode 11 (également une liaison). Le paquet suivant le plus courant est "ldap:2", qui est une déconnexion, c'est donc le type de paquet le plus probable à être sélectionné lors de la relecture. À l'autre extrême, lsarpc opcode 77 (lookup names) a été vu une seule fois, et il est peu probable mais possible qu'il soit sélectionné lors de la relecture.

Il y a deux types de paquets spéciaux ici. "wait:3" fait référence à une pause temporaire dans la conversation, où le pseudo-opcode "3" indique la longueur de la pause sur une échelle exponentielle. C'est-à-dire qu'une pause "wait:4" serait environ 2,7 fois plus longue qu'une pause "wait:3", qui à son tour serait de manière similaire plus longue qu'une pause "wait:2".

L'autre paquet spécial est "-", qui représente la fin de la conversation. Dans l'exemple, cela indique qu'une conversation observée s'est terminée après ce ngram particulier. Ce pseudo-opcode est également utilisé au début des conversations, qui sont indiquées par le ngram "-\t-".
