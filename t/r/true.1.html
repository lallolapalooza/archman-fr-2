TRUE(1) Commandes utilisateur TRUE(1)

NOM

true - ne rien faire, avec succès

SYNTAXE

true [arguments de ligne de commande ignorés]
true OPTION

DESCRIPTION

Quitter avec un code d'état indiquant le succès.

--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter

Votre shell peut avoir sa propre version de true, qui remplace généralement celle décrite ici. Veuillez consulter la documentation de votre shell pour connaître les détails des options qu'il prend en charge.
