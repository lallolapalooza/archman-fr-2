tracefs_cpu_flush_buf(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_cpu_read_buf, tracefs_cpu_buffered_read_buf, tracefs_cpu_flush_buf - Lecture des données de trace_pipe_raw retournant un kbuffer

SYNTAXE

#include <tracefs.h>
struct kbuffer *tracefs_cpu_read_buf(struct tracefs_cpu *tcpu, bool nonblock);
struct kbuffer *tracefs_cpu_buffered_read_buf(struct tracefs_cpu *tcpu, bool nonblock);
struct kbuffer *tracefs_cpu_flush_buf(struct tracefs_cpu *tcpu);

DESCRIPTION

Cet ensemble d'API peut être utilisé pour lire les données brutes des fichiers trace_pipe_raw du système de fichiers tracefs et retourner une structure kbuffer pour les lire.

tracefs_cpu_read_buf() lit les fichiers trace_pipe_raw associés à tcpu et retourne une structure kbuffer qui peut être utilisée pour itérer sur les événements. Si nonblock est défini, et qu'aucune donnée n'est disponible, elle retourne immédiatement. Sinon, selon la manière dont tcpu a été ouvert, elle bloquera. Si tcpu a été ouvert avec nonblock défini, alors ce nonblock ne fera aucune différence.

tracefs_cpu_buffered_read_buf() est fondamentalement le même que tracefs_cpu_read_buf(), sauf qu'il utilise un pipe via splice pour mettre en mémoire tampon les lectures. Cela regroupera les lectures, rendant la lecture depuis le tampon circulaire moins intrusive pour le système, car la lecture constante peut causer une perturbation considérable. Notez qu'une différence entre ceci et tracefs_cpu_read() est qu'il ne lira que dans les pages du sous-tampon. Si le tampon circulaire n'a pas rempli une page, alors il ne retournera rien, même avec nonblock défini. Les appels à tracefs_cpu_flush_buf() ou tracefs_cpu_flush() doivent être faits pour lire le reste du fichier à la fin du traçage.

tracefs_cpu_flush_buf() lit le fichier trace_pipe_raw associé par tcpu et le place dans buffer, qui doit être de la taille du sous-tampon récupéré. Ceci devrait être appelé à la fin du traçage pour obtenir le reste des données. Cet appel convertira le descripteur de fichier de trace_pipe_raw en mode non bloquant.

VALEUR DE RETOUR

Les fonctions tracefs_cpu_read_buf(), tracefs_cpu_buffered_read_buf() et tracefs_cpu_flush() retournent un descripteur de kbuffer qui peut être itéré pour trouver les événements. Notez que ce descripteur fait partie de la structure tracefs_cpu et ne doit pas être libéré. Il sera libéré. Il retourne NULL en cas d'erreur ou si nonblock est défini et qu'aucun événement n'est disponible. Dans le cas d'aucun événement, errno sera défini avec EAGAIN.

EXEMPLE

#include <stdlib.h>
#include <ctype.h>
#include <tracefs.h>
static void read_page(struct tep_handle *tep, struct kbuffer *kbuf)
{
        static struct trace_seq seq;
        struct tep_record record;
        if (seq.buffer)
                trace_seq_reset(&seq);
        else
                trace_seq_init(&seq);
        while ((record.data = kbuffer_read_event(kbuf, &record.ts))) {
                record.size = kbuffer_event_size(kbuf);
                kbuffer_next_event(kbuf, NULL);
                tep_print_event(tep, &seq, &record,
                                "%s-%d %9d\t%s: %s\n",
                                TEP_PRINT_COMM,
                                TEP_PRINT_PID,
                                TEP_PRINT_TIME,
                                TEP_PRINT_NAME,
                                TEP_PRINT_INFO);
                trace_seq_do_printf(&seq);
                trace_seq_reset(&seq);
        }
}
int main (int argc, char **argv)
{
        struct tracefs_cpu *tcpu;
        struct tep_handle *tep;
        struct kbuffer *kbuf;
        int cpu;
        if (argc < 2 || !isdigit(argv[1][0])) {
                printf("usage: %s cpu\n\n", argv[0]);
                exit(-1);
        }
        cpu = atoi(argv[1]);
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("Reading trace event formats");
                exit(-1);
        }
        tcpu = tracefs_cpu_open(NULL, cpu, 0);
        if (!tcpu) {
                perror("Open CPU 0 file");
                exit(-1);
        }
        while ((kbuf = tracefs_cpu_buffered_read_buf(tcpu, true))) {
                read_page(tep, kbuf);
        }
        kbuf = tracefs_cpu_flush_buf(tcpu);
        if (kbuf)
                read_page(tep, kbuf);
        tracefs_cpu_close(tcpu);
        tep_free(tep);
        return 0;
}
