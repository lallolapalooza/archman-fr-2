tracefs_list_free(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_tracers, tracefs_tracer_available, tracefs_get_clock, tracefs_list_free, tracefs_list_add, tracefs_list_size - Fonctions d'aide pour travailler avec le système de fichiers trace.

SYNTAXE

#include <tracefs.h>
char **tracefs_tracers(const char *tracing_dir);
bool tracefs_tracer_available(const char *tracing_dir, const char *tracer);
char *tracefs_get_clock(struct tracefs_instance *instance);
void tracefs_list_free(char **list);
char **tracefs_list_add(char *list, const char *string);
int *tracefs_list_size(char **list);

DESCRIPTION

Diverses fonctions utiles pour travailler avec le système de fichiers trace.

La fonction tracefs_tracers() renvoie un tableau de chaînes de caractères contenant les noms des plugins de traçage supportés, situés dans le répertoire tracing_dir spécifié. Il peut s'agir de NULL ou de l'emplacement du point de montage tracefs pour les systèmes de traçage de la machine locale, ou bien d'un chemin vers une copie du répertoire tracefs provenant d'une autre machine. La dernière entrée du tableau est un pointeur NULL. Le tableau doit être libéré avec l'API tracefs_list_free().

La fonction tracefs_tracer_available() renvoie vrai si le tracer est disponible dans le répertoire tracing_dir_director spécifié, et faux sinon.

La fonction tracefs_get_clock() renvoie le nom de l'horloge de traçage actuelle, utilisée dans l'instance spécifiée. Si instance est NULL, l'horloge de l'instance de traçage principale est renvoyée. La chaîne renvoyée doit être libérée avec free().

La fonction tracefs_list_free() libère un tableau de chaînes de caractères, renvoyé par les API tracefs_event_systems(), tracefs_system_events() et tracefs_tracers().

La fonction tracefs_list_add() ajoute la chaîne string à la liste de chaînes list. Si list est NULL, une nouvelle liste est créée avec comme premier élément une copie de string, et le deuxième élément sera un pointeur NULL. Si list n'est pas NULL, il est réalloué pour inclure un nouveau élément et un terminateur NULL, et le nouveau tableau alloué est renvoyé. La liste passée doit être ignorée, car elle sera libérée si une nouvelle a été allouée.

tracefs_list_size() est un moyen rapide de connaître le nombre d'éléments dans un tableau de chaînes qui doit être libéré avec tracefs_list_free(). Notez que cela dépend de métadonnées qui sont créées pour ces listes et ne fonctionnera pas sur des tableaux de chaînes normaux comme argv.

VALEUR RENVOYÉE

La fonction tracefs_tracers() renvoie un tableau de chaînes de caractères. Le dernier élément de ce tableau est un pointeur NULL. Le tableau doit être libéré avec l'API tracefs_list_free(). En cas d'erreur, NULL est renvoyé.

La fonction tracefs_tracer_available() renvoie vrai si le tracer est disponible, et faux sinon.

La fonction tracefs_get_clock() renvoie une chaîne de caractères, qui doit être libérée avec free(), ou NULL en cas d'erreur.

La fonction tracefs_list_add() renvoie un tableau de chaînes alloué qui doit être libéré avec tracefs_list_free() en cas de succès ou NULL en cas d'erreur. Si NULL est renvoyé, la liste list passée en argument reste inchangée. Ainsi, tracefs_list_add() doit être traité similairement à realloc(3).

La fonction tracefs_list_size() renvoie le nombre de chaînes dans la list. La liste passée doit être une liste qui doit être libérée avec tracefs_list_free() car la liste possède des métadonnées utilisées pour déterminer la taille, et cela ne fonctionne pas sur un tableau de chaînes normal comme argv.

EXEMPLE

#include <tracefs.h>
char **tracers = tracefs_tracers(NULL);
        if (tracers) {
                /* Obtenu les plugins de traçage de l'instance de traçage principale */
                ...
                tracefs_list_free(tracers);
        }
....
char *clock = tracefs_get_clock(NULL);
        if (clock) {
                /* Obtenu l'horloge de traçage actuelle de l'instance de traçage principale */
                ...
                free(clock);
        }
