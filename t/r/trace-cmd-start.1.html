NOM

trace-cmd-start - démarre le traçeur du noyau Linux Ftrace sans enregistrement

SYNTAXE

trace-cmd start [OPTIONS]

DESCRIPTION

Le commande trace-cmd(1) start active tout le traçage Ftrace de la même manière que trace-cmd-record(1). La différence est qu'il n'exécute pas de threads pour créer un fichier trace.dat. Ceci est utile pour activer Ftrace et vous ne vous intéressez au trace qu'après qu'un événement se soit produit et que le traçage soit arrêté. Le trace peut alors être lu directement à partir du système de fichiers pseudo Ftrace ou extrait avec trace-cmd-extract(1).

OPTIONS

Les options sont les mêmes que celles de trace-cmd-record(1), sauf qu'il ne prend pas d'options spécifiques à l'enregistrement (-s, -o, -N, et -t).

--fork

Cette option n'est disponible que pour trace-cmd start. Elle indique à trace-cmd de ne pas attendre la fin du processus avant de retourner. Avec cette option, trace-cmd start retournera immédiatement après avoir créé le processus de la ligne de commande. Cette option n'a d'effet que si trace-cmd start exécute également une commande.
