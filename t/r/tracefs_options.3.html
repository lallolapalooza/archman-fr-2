NOM

tracefs_options - options ftrace, qui peuvent être contrôlées à l'aide de la bibliothèque tracefs.

DESCRIPTION

Cette énumération contient toutes les options ftrace, qui peuvent être manipulées à l'aide de la bibliothèque tracefs. Des informations plus détaillées sur chaque option sont disponibles dans Documentation/trace/ftrace.rst dans l'arborescence du noyau Linux, dans la section trace_options. Notez que certaines options ftrace ne peuvent pas être manipulées par cette bibliothèque, car elles sont destinées à des fins internes de débogage. Ces options contrôlent les traceurs ou la sortie de trace. Toutes les options ont deux états - activé et désactivé, l'état par défaut est différent pour chacune d'elles.

Options communes à tous les traceurs :
        TRACEFS_OPTION_INVALID Pas une option ftrace valide, utilisée par l'API pour indiquer une erreur.
        TRACEFS_OPTION_ANNOTATE Affiche quand un nouveau tampon CPU a démarré.
        TRACEFS_OPTION_BIN Affiche les formats en binaire brut.
        TRACEFS_OPTION_CONTEXT_INFO Affiche uniquement les données de l'événement. Masque le nom, le PID, l'horodatage, le CPU et d'autres données utiles.
        TRACEFS_OPTION_BLOCK Lorsque défini, la lecture de trace_pipe ne bloquera pas lors du polling.
        TRACEFS_OPTION_DISABLE_ON_FREE Lorsque free_buffer est fermé, le traçage s'arrêtera.
        TRACEFS_OPTION_DISPLAY_GRAPH Lorsqu'il est défini, les traceurs de latence utiliseront le traçage de graphe de fonctions au lieu du traçage de fonctions.
        TRACEFS_OPTION_EVENT_FORK Lorsqu'il est défini, les tâches avec les PID listés dans set_event_pid auront les PID de leurs enfants ajoutés à set_event_pid lors de la création de leurs enfants.
        TRACEFS_OPTION_FUNCTION_FORK Lorsqu'il est défini, les tâches avec les PID listés dans set_ftrace_pid auront les PID de leurs enfants ajoutés à set_ftrace_pid lors de la création de leurs enfants.
        TRACEFS_OPTION_FUNCTION_TRACE Lorsqu'il est activé, les traceurs de latence traceront les fonctions.
        TRACEFS_OPTION_HEX Affiche les nombres au format hexadécimal.
        TRACEFS_OPTION_IRQ_INFO Affiche les données d'interruption, de compte de préemption, de besoin de planification.
        TRACEFS_OPTION_LATENCY_FORMAT Affiche des informations supplémentaires sur la latence.
        TRACEFS_OPTION_MARKERS Lorsqu'il est défini, trace_marker est activé - accessible en écriture (uniquement par root).
        TRACEFS_OPTION_OVERWRITE Contrôle ce qui se passe lorsque le tampon de trace est plein. S'il est défini, les événements les plus anciens sont supprimés et écrasés. S'il est désactivé, les événements les plus récents sont supprimés.
        TRACEFS_OPTION_PAUSE_ON_TRACE Lorsqu'il est défini, l'ouverture du fichier de trace en lecture mettra en pause l'écriture dans le tampon circulaire. Lorsque le fichier est fermé, le traçage sera réactivé.
        TRACEFS_OPTION_PRINTK_MSG_ONLY Lorsqu'il est défini, trace_printk() n'affichera que le format et non ses paramètres.
        TRACEFS_OPTION_PRINT_PARENT Sur les traces de fonctions, affiche la fonction appelante (parent) ainsi que la fonction tracée.
        TRACEFS_OPTION_RAW Affiche les nombres bruts.
        TRACEFS_OPTION_RECORD_CMD Sauvegarde un mappage avec un pid et la commande correspondante.
        TRACEFS_OPTION_RECORD_TGID Sauvegarde un mappage avec un pid et les identifiants de groupe de threads correspondants.
        TRACEFS_OPTION_STACKTRACE Enregistre une trace de pile après chaque événement de trace.
        TRACEFS_OPTION_SYM_ADDR Affiche l'adresse de la fonction ainsi que le nom de la fonction.
        TRACEFS_OPTION_SYM_OFFSET Affiche non seulement le nom de la fonction, mais aussi le décalage dans la fonction.
        TRACEFS_OPTION_SYM_USEROBJ Lorsque TRACEFS_OPTION_USERSTACKTRACE est défini, recherche dans quel objet l'adresse appartient, et affiche l'objet et une adresse relative.
        TRACEFS_OPTION_TRACE_PRINTK Désactive l'écriture de trace_printk() dans le tampon.
        TRACEFS_OPTION_USERSTACKTRACE Enregistre une trace de pile du thread utilisateur actuel après chaque événement de trace.
        TRACEFS_OPTION_VERBOSE Lorsque TRACEFS_OPTION_LATENCY_FORMAT est activé, affiche des informations plus détaillées.
Options spécifiques au traceur de fonctions :
        TRACEFS_OPTION_FUNC_STACKTRACE Enregistre une trace de pile après chaque fonction.
Options spécifiques au traceur de graphe de fonctions :
        TRACEFS_OPTION_FGRAPH_ABSTIME Affiche l'horodatage à chaque ligne.
        TRACEFS_OPTION_FGRAPH_CPU Affiche le numéro du CPU où la trace s'est produite.
        TRACEFS_OPTION_FGRAPH_DURATION Affiche la durée du temps à la fin de chaque fonction, en microsecondes.
        TRACEFS_OPTION_FGRAPH_IRQS Trace les fonctions qui se produisent à l'intérieur d'une interruption.
        TRACEFS_OPTION_FGRAPH_OVERHEAD Affiche un marqueur si une fonction prend plus d'un certain temps.
        TRACEFS_OPTION_FGRAPH_OVERRUN Affiche un "dépassement" du graphe d'appels, dans le cas de fonctions manquées en raison d'une pile d'appels volumineuse.
        TRACEFS_OPTION_FGRAPH_PROC Affiche la commande de chaque processus à chaque ligne.
        TRACEFS_OPTION_FGRAPH_TAIL Affiche le nom de la fonction lors de son retour.
        TRACEFS_OPTION_SLEEP_TIME Prend en compte le temps pendant lequel la tâche a été planifiée en dehors de l'appel de fonction.
        TRACEFS_OPTION_GRAPH_TIME Affiche le temps nécessaire pour appeler les fonctions imbriquées, si le profileur de fonctions est activé.
Options spécifiques au traceur blk :
        TRACEFS_OPTION_BLK_CGNAME
        TRACEFS_OPTION_BLK_CGROUP
        TRACEFS_OPTION_BLK_CLASSIC Affiche une sortie plus minimaliste.
