NOM

trace-cmd - interagit avec le traçeur interne Ftrace du noyau Linux

SYNTAXE

trace-cmd COMMANDE [OPTIONS]

DESCRIPTION

La commande trace-cmd(1) interagit avec le traçeur Ftrace intégré dans le noyau Linux. Elle accède aux fichiers spécifiques à Ftrace situés dans le système de fichiers debugfs sous le répertoire de traçage. Une COMMANDE doit être spécifiée pour indiquer à trace-cmd ce qu'il doit faire.

COMMANDES

record  - enregistre un traçage en direct et écrit un fichier trace.dat sur
          le disque local ou sur le réseau.
set     - définit un paramètre de configuration ftrace.
report  - lit un fichier trace.dat et convertit les données binaires en
          format texte ASCII lisible.
stream  - démarre le traçage et lit la sortie directement
profile - démarre le profilage et lit la sortie directement
hist    - affiche un histogramme des événements.
stat    - affiche le statut du traçage (ftrace) du système en cours d'exécution
options - liste les options de plugins disponibles pour *report*
start   - démarre le traçage sans enregistrement dans un fichier trace.dat.
stop    - arrête le traçage (désactive uniquement l'enregistrement, la surcharge du traçeur
          est toujours active)
restart - redémarre le traçage après un arrêt précédent (n'affecte que l'enregistrement)
extract - extrait les données du tampon du noyau et crée un fichier trace.dat.

show    - affiche le contenu d'un des fichiers de traçage du noyau Linux Ftrace
reset   - désactive tout traçage et rend les performances du système.
          (efface toutes les données des tampons du noyau)
clear   - efface le contenu des tampons circulaires Ftrace.
split   - divise un fichier trace.dat en fichiers plus petits.
list    - liste les plugins ou événements disponibles qui peuvent être enregistrés.
listen  - ouvre un port pour écouter les connexions de traçage à distance.
agent   - écoute sur un vsocket les clients de trace
setup-guest - crée des FIFOs pour le traçage des VM invitées
restore - restaure les fichiers de données d'une exécution de trace-cmd record plantée
snapshot- prend un instantané du traçage en cours
stack   - exécute et affiche le traçeur de pile
check-events - analyse les chaînes de format pour tous les événements de trace et retourne
               si tous les formats sont analysables
convert   - convertit les fichiers de trace
attach   - attache un fichier trace.dat hôte à un fichier trace.dat invité
dump    - lit les métadonnées d'un fichier de trace

OPTIONS

-h, --help

Affiche le texte d'aide.

Pour les autres options, consultez la page man de la commande correspondante.
