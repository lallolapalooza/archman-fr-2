tracefs_options_get_supported(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_options_get_supported, tracefs_option_is_supported, tracefs_options_get_enabled, tracefs_option_is_enabled, tracefs_option_mask_is_set, tracefs_option_id - Obtenir et vérifier les options ftrace.

SYNTAXE

#include <tracefs.h>
const struct tracefs_options_mask *tracefs_options_get_supported(struct tracefs_instance *instance);
bool tracefs_option_is_supported(struct tracefs_instance *instance, enum tracefs_option_id id);
const struct tracefs_options_mask *tracefs_options_get_enabled(struct tracefs_instance *instance);
bool tracefs_option_is_enabled(struct tracefs_instance *instance, enum tracefs_option_id id);
bool tracefs_option_mask_is_set(const struct tracefs_options_mask options, enum tracefs_option_id id);
enum tracefs_option_id *tracefs_option_id(const char *name);

DESCRIPTION

Cet ensemble d'API peut être utilisé pour obtenir et vérifier les options ftrace actuelles. Les options ftrace prises en charge peuvent dépendre de la version du noyau et de la configuration du noyau.

La fonction tracefs_options_get_supported() obtient toutes les options ftrace prises en charge par le système dans l'instance donnée. Si instance est NULL, les options prises en charge de l'instance de trace principale sont retournées. L'ensemble des options prises en charge est le même dans toutes les instances de trace créées, mais peut être différent de celui de l'instance de trace principale.

La fonction tracefs_option_is_supported() vérifie si l'option avec l'id donné est prise en charge par le système dans l'instance donnée. Si instance est NULL, l'instance de trace principale est utilisée. Si une option est prise en charge au niveau de l'instance de trace principale, elle peut ne pas être prise en charge dans une instance de trace créée.

La fonction tracefs_options_get_enabled() obtient toutes les options ftrace, actuellement activées dans l'instance donnée. Si instance est NULL, les options activées de l'instance de trace principale sont retournées.

La fonction tracefs_option_is_enabled() vérifie si l'option avec l'id donné est activée dans l'instance donnée. Si instance est NULL, l'instance de trace principale est utilisée.

La fonction tracefs_option_mask_is_set() vérifie si le bit, correspondant à l'option avec l'id, est défini dans le masque de bits options retourné par tracefs_option_get_enabled() et tracefs_option_is_supported().

La fonction tracefs_option_id() convertit un nom d'option en son id correspondant, s'il est trouvé. Cela permet de trouver l'id de l'option à utiliser dans les autres fonctions si seul le nom est connu.

VALEUR DE RETOUR

Les fonctions tracefs_options_get_supported() et tracefs_options_get_enabled(), en cas de succès, retournent un pointeur vers le masque de bits dans l'instance, ou un masque de bits global pour le niveau supérieur, ou NULL en cas d'erreur. Comme le masque de bits retourné fait partie de la structure de l'instance (ou d'une variable globale), il ne doit pas être libéré ni modifié.

Les fonctions tracefs_option_is_supported() et tracefs_option_is_enabled() retournent true si l'option est prise en charge / activée, ou false sinon.

La fonction tracefs_option_mask_is_set() retourne true si l'option correspondante est définie dans le masque, ou false sinon.

La fonction tracefs_option_id() retourne l'id correspondant défini par tracefs_options(3) à partir du nom donné. Si le nom ne peut pas être trouvé, alors TRACEFS_OPTION_INVALID est retourné.

EXEMPLE

#include <tracefs.h>
...
const struct tracefs_options_mask *options;
...
options = tracefs_options_get_supported(NULL);
if (!options) {
        /* Échec de l'obtention des options prises en charge */
} else {
        ...
}
...
options = tracefs_options_get_enabled(NULL);
if (!options) {
        /* Échec de l'obtention des options activées dans l'instance principale */
} else {
        ...
}
if (tracefs_options_mask_is_set(options, TRACEFS_OPTION_LATENCY_FORMAT)) {
        ...
}
...
if (tracefs_option_is_supported(NULL, TRACEFS_OPTION_LATENCY_FORMAT)) {
        /* L'option de format de latence est prise en charge */
}
...
if (tracefs_option_is_enabled(NULL, TRACEFS_OPTION_STACKTRACE)) {
        /* L'option de trace de pile est activée dans l'instance principale */
}
