DESCRIPTION

Les histogrammes d'événements sont créés par le fichier `trigger` dans le répertoire de l'événement. La syntaxe peut être complexe et difficile à obtenir correctement. Cette API gère la syntaxe et facilite la création et l'interaction avec les histogrammes d'événements. Voir https://www.kernel.org/doc/html/latest/trace/histogram.html pour plus d'informations.

tracefs_hist_add_sort_key() ajoutera une clé de tri. hist est le descripteur d'histogramme auquel ajouter la clé de tri. sort_key est une chaîne qui doit correspondre soit à une clé déjà définie de l'histogramme, soit à une valeur déjà définie. Si hist a déjà des clés de tri (ajoutées précédemment), la nouvelle sort_key aura une priorité plus basse (sera secondaire, etc.) lors du tri.

tracefs_hist_set_sort_key() réinitialisera la liste des clés de tri. hist est le descripteur d'histogramme dont la clé de tri doit être réinitialisée. sort_key est une chaîne qui doit correspondre soit à une clé déjà définie de l'histogramme, soit à une valeur déjà définie. Plusieurs clés de tri peuvent être ajoutées pour indiquer un ordre de tri secondaire, etc., mais toutes les clés de tri doivent correspondre à une clé ou une valeur existante, ou être TRACEFS_HIST_HITCOUNT. Le dernier paramètre de tracefs_hist_add_sort_key() doit être NULL.

tracefs_hist_sort_key_direction() permet de changer la direction d'une clé de tri existante de hist. sort_key est la clé de tri à changer, et dir peut être soit TRACEFS_HIST_SORT_ASCENDING soit TRACEFS_HIST_SORT_DESCENDING, pour rendre la direction du tri respectivement croissante ou décroissante.

tracefs_hist_add_name() ajoute un nom à un histogramme. Un histogramme peut être nommé et si le nom correspond entre plusieurs événements, et qu'ils ont des clés compatibles, les histogrammes multiples avec le même nom seront fusionnés en un seul histogramme (affiché par le fichier hist de l'un ou l'autre événement). hist est l'histogramme à nommer, et name est le nom à lui donner.

tracefs_hist_append_filter() crée un filtre ou y ajoute une condition pour l'événement de l'histogramme. Selon type, il construira une chaîne de jetons pour les parenthèses ou les instructions logiques, ou il pourra ajouter une comparaison de field à val basée sur compare.

Si type est : TRACEFS_FILTER_COMPARE - Voir ci-dessous TRACEFS_FILTER_AND - Ajoute "&&" au filtre TRACEFS_FILTER_OR - Ajoute "||" au filtre TRACEFS_FILTER_NOT - Ajoute "!" au filtre TRACEFS_FILTER_OPEN_PAREN - Ajoute "(" au filtre TRACEFS_FILTER_CLOSE_PAREN - Ajoute ")" au filtre

field, compare, et val sont ignorés à moins que type ne soit égal à TRACEFS_FILTER_COMPARE, auquel cas compare sera utilisé pour les opérations suivantes :

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ ""val"" : où field est une chaîne.

TRACEFS_COMPARE_AND - field & val : où field est un champ de drapeaux.

trace_hist_echo_cmd() imprime les commandes nécessaires pour créer l'histogramme donné dans l'instance donnée instance, ou NULL pour le niveau supérieur, dans la séquence s. La commande qui est imprimée est décrite par command et montre la fonctionnalité qui serait effectuée par tracefs_hist_command(3).

tracefs_hist_command() est appelée pour traiter une commande sur l'histogramme hist pour son événement dans l'instance donnée instance, ou NULL pour le niveau supérieur. Le cmd peut être l'un des suivants :

TRACEFS_HIST_CMD_START ou zéro pour démarrer l'exécution de l'histogramme.

TRACEFS_HIST_CMD_PAUSE pour mettre en pause l'histogramme donné.

TRACEFS_HIST_CMD_CONT pour continuer un histogramme mis en pause.

TRACEFS_HIST_CMD_CLEAR pour réinitialiser les valeurs d'un histogramme.

TRACEFS_HIST_CMD_DESTROY pour détruire l'histogramme (annuler un START).

Les fonctions ci-dessous sont des wrappers pour tracefs_hist_command() afin de rendre les conventions d'appel un peu plus faciles à comprendre ce qui se passe.

TYPES DE CLÉS

tracefs_hist_alloc_nd() et tracefs_hist_add_key() ajoutent tous deux une clé et nécessitent que cette clé ait un type. Les types peuvent être :

TRACEFS_HIST_KEY_NORMAL ou zéro (0) qui ne modifie pas le type.

TRACEFS_HIST_KEY_HEX pour afficher la clé en hexadécimal.

TRACEFS_HIST_KEY_SYM pour afficher la clé comme un symbole du noyau (s'il est trouvé). Si la clé est une adresse, ceci est utile car cela affichera les noms des fonctions au lieu d'un simple nombre.

TRACEFS_HIST_KEY_SYM_OFFSET similaire à TRACEFS_HIST_KEY_SYM mais inclura également le décalage de la fonction pour correspondre à l'adresse exacte.

TRACEFS_HIST_KEY_SYSCALL Si la clé est un "id" d'appel système (le numéro passé de l'espace utilisateur au noyau pour lui indiquer quel appel système il appelle), alors le nom de l'appel système est affiché.

TRACEFS_HIST_KEY_EXECNAME Si "common_pid" est la clé (le pid de la tâche en cours d'exécution), au lieu d'afficher le nombre, affichez le nom de la tâche en cours d'exécution.

TRACEFS_HIST_KEY_LOG affichera la clé sur une échelle logarithmique binaire.

TRACEFS_HIST_KEY_USECS à utiliser avec "common_timestamp" ou TRACEFS_HIST_TIMESTAMP, auquel cas il affichera le timestamp en microsecondes au lieu de nanosecondes.

VALEUR DE RETOUR

tracefs_hist_get_name() retourne le nom de l'histogramme ou NULL en cas d'erreur. La chaîne retournée appartient à l'objet histogramme et est libérée avec l'histogramme par tracefs_hist_free().

tracefs_hist_get_event() retourne le nom de l'événement de l'histogramme ou NULL en cas d'erreur. La chaîne retournée appartient à l'objet histogramme et est libérée avec l'histogramme par tracefs_hist_free().

tracefs_hist_get_system() retourne le nom du système de l'histogramme ou NULL en cas d'erreur. La chaîne retournée appartient à l'objet histogramme et est libérée avec l'histogramme par tracefs_hist_free().

tracefs_hist_alloc_nd() retourne un descripteur d'histogramme alloué qui doit être libéré par tracefs_hist_free() ou NULL en cas d'erreur.

DESCRIPTION

Ces fonctions sont utilisées pour créer, manipuler et interagir avec les histogrammes de tracefs. Les histogrammes permettent de regrouper les événements de trace en fonction d'une ou plusieurs clés et de compter les occurrences.

tracefs_hist_add_value() ajoute une valeur d'événement à l'histogramme. La valeur doit correspondre à l'une des clés de l'axe de l'histogramme.

tracefs_hist_add_sort_key() ajoute une clé pour le tri des résultats de l'histogramme. Plusieurs clés peuvent être ajoutées pour définir un ordre de tri multi-niveaux.

tracefs_hist_sort_key_direction() définit la direction du tri (ascendante ou descendante) pour une clé de tri donnée.

tracefs_hist_start() démarre la collecte des événements pour l'histogramme spécifié. Si `instance` n'est pas NULL, il utilise l'instance de tracefs spécifiée.

tracefs_hist_pause() met en pause la collecte des événements pour l'histogramme.

tracefs_hist_continue() reprend la collecte des événements après une pause.

tracefs_hist_reset() réinitialise les compteurs de l'histogramme.

tracefs_hist_destroy() libère les ressources associées à l'histogramme.

tracefs_hist_alloc() alloue et initialise une structure d'histogramme unidimensionnel. `tep` est le handle des événements, `system` et `event` spécifient le nom du système et de l'événement à tracer, `key` est la clé de l'axe et `type` est le type de la clé (par exemple, TRACEFS_HIST_KEY_SYM pour les symboles).

tracefs_hist_alloc_2d() alloue et initialise une structure d'histogramme bidimensionnel avec deux clés.

tracefs_hist_alloc_nd() alloue et initialise une structure d'histogramme multidimensionnel avec un tableau de clés d'axe.

tracefs_hist_get_event() et tracefs_hist_get_system() retournent des chaînes de caractères appartenant à l'objet histogramme.

Toutes les autres fonctions retournent zéro en cas de succès ou -1 en cas d'erreur.

EXAMPLE

#include <stdlib.h>
#include <unistd.h>
#include <tracefs.h>
enum commands {
        START,
        PAUSE,
        CONT,
        RESET,
        DELETE,
        SHOW,
};
static void parse_system_event(char *group, char **system, char **event)
{
        *system = strtok(group, "/");
        *event = strtok(NULL, "/");
        if (!*event) {
                *event = *system;
                *system = NULL;
        }
}
static int parse_keys(char *keys, struct tracefs_hist_axis **axes)
{
        char *sav = NULL;
        char *key;
        int cnt = 0;
        for (key = strtok_r(keys, ",", &sav); key; key = strtok_r(NULL, ",", &sav)) {
                struct tracefs_hist_axis *ax;
                char *att;
                ax = realloc(*axes, sizeof(*ax) * (cnt + 2));
                if (!ax) {
                        perror("Failed to allocate axes");
                        exit(-1);
                }
                ax[cnt].key = key;
                ax[cnt].type = 0;
                ax[cnt + 1].key = NULL;
                ax[cnt + 1].type = 0;
                *axes = ax;
                att = strchr(key, '.');
                if (att) {
                        *att++ = '\0';
                        if (strcmp(att, "hex") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_HEX;
                        else if (strcmp(att, "sym") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM;
                        else if (strcmp(att, "sym_offset") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM_OFFSET;
                        else if (strcmp(att, "syscall") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYSCALL;
                        else if (strcmp(att, "exec") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_EXECNAME;
                        else if (strcmp(att, "log") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_LOG;
                        else if (strcmp(att, "usecs") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_USECS;
                        else {
                                fprintf(stderr, "Undefined attribute '%s'\n", att);
                                fprintf(stderr,"  Acceptable attributes:\n");
                                fprintf(stderr,"    hex, sym, sym_offset, syscall, exe, log, usecs\n");
                                exit(-1);
                        }
                }
                cnt++;
        }
        return cnt;
}
static void process_hist(enum commands cmd, const char *instance_name,
                         char *group, char *keys, char *vals, char *sort,
                         char *ascend, char *desc)
{
        struct tracefs_instance *instance = NULL;
        struct tracefs_hist *hist;
        struct tep_handle *tep;
        struct tracefs_hist_axis *axes = NULL;
        char *system;
        char *event;
        char *sav;
        char *val;
        int ret;
        int cnt;
        if (instance_name) {
                instance = tracefs_instance_create(instance_name);
                if (!instance) {
                        fprintf(stderr, "Failed instance create\n");
                        exit(-1);
                }
        }
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("Could not read events");
                exit(-1);
        }
        parse_system_event(group, &system, &event);
        if (cmd == SHOW) {
                char *content;
                content = tracefs_event_file_read(instance, system, event,
                                                  "hist", NULL);
                if (!content) {
                        perror("Reading hist file");
                        exit(-1);
                }
                printf("%s\n", content);
                free(content);
                return;
        }
        if (!keys) {
                fprintf(stderr, "Command needs -k option\n");
                exit(-1);
        }
        cnt = parse_keys(keys, &axes);
        if (!cnt) {
                fprintf(stderr, "No keys??\n");
                exit(-1);
        }
        /* Show examples of hist1d and hist2d */
        switch (cnt) {
        case 1:
                hist = tracefs_hist_alloc(tep, system, event,
                                          axes[0].key, axes[0].type);
                break;
        case 2:
                hist = tracefs_hist_alloc_2d(tep, system, event,
                                             axes[0].key, axes[0].type,
                                             axes[1].key, axes[1].type);
                break;
        default:
                /* Really, 1 and 2 could use this too */
                hist = tracefs_hist_alloc_nd(tep, system, event, axes);
        }
        if (!hist) {
                fprintf(stderr, "Failed hist create\n");
                exit(-1);
        }
        if (vals) {
                sav = NULL;
                for (val = strtok_r(vals, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_value(hist, val);
                        if (ret) {
                                fprintf(stderr, "Failed to add value %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (sort) {
                sav = NULL;
                for (val = strtok_r(sort, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_sort_key(hist, val);
                        if (ret) {
                                fprintf(stderr, "Failed to add sort key/val %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (ascend) {
                sav = NULL;
                for (val = strtok_r(ascend, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_ASCENDING);
                        if (ret) {
                                fprintf(stderr, "Failed to add ascending key/val %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (desc) {
                sav = NULL;
                for (val = strtok_r(desc, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_DESCENDING);
                        if (ret) {
                                fprintf(stderr, "Failed to add descending key/val %s\n", val);
                                exit(-1);
                        }
                }
        }
        tracefs_error_clear(instance);
        switch (cmd) {
        case START:
                ret = tracefs_hist_start(instance, hist);
                if (ret) {
                        char *err = tracefs_error_last(instance);
                        if (err)
                                fprintf(stderr, "\n%s\n", err);
                }
                break;
        case PAUSE:
                ret = tracefs_hist_pause(instance, hist);
                break;
        case CONT:
                ret = tracefs_hist_continue(instance, hist);
                break;
        case RESET:
                ret = tracefs_hist_reset(instance, hist);
                break;
        case DELETE:
                ret = tracefs_hist_destroy(instance, hist);
                break;
        case SHOW:
                /* Show was already done */
                break;
        }
        if (ret)
                fprintf(stderr, "Failed: command\n");
        exit(ret);
}
int main (int argc, char **argv, char **env)
{
        enum commands cmd;
        char *instance = NULL;
        char *cmd_str;
        char *event = NULL;
        char *keys = NULL;
        char *vals = NULL;
        char *sort = NULL;
        char *desc = NULL;
        char *ascend = NULL;
        if (argc < 2) {
                fprintf(stderr, "usage: %s command [-B instance][-e [system/]event][-k keys][-v vals][-s sort]\n", argv[0]);
                fprintf(stderr, "      [-a ascending][-d descending]\n");
                exit(-1);
        }
        cmd_str = argv[1];
        if (!strcmp(cmd_str, "start"))
                cmd = START;
        else if (!strcmp(cmd_str, "pause"))
                cmd = PAUSE;
        else if (!strcmp(cmd_str, "cont"))
                cmd = CONT;
        else if (!strcmp(cmd_str, "reset"))
                cmd = RESET;
        else if (!strcmp(cmd_str, "delete"))
                cmd = DELETE;
        else if (!strcmp(cmd_str, "show"))
                cmd = SHOW;
        else {
                fprintf(stderr, "Unknown command %s\n", cmd_str);
                exit(-1);
        }
        for (;;) {
                int c;
                c = getopt(argc - 1, argv + 1, "e:k:v:B:s:d:a:");
                if (c == -1)
                        break;
                switch (c) {
                case 'e':
                        event = optarg;
                        break;
                case 'k':
                        keys = optarg;
                        break;
                case 'v':
                        vals = optarg;
                        break;
                case 'B':
                        instance = optarg;
                        break;
                case 's':
                        sort = optarg;
                        break;
                case 'd':
                        desc = optarg;
                        break;
                case 'a':
                        ascend = optarg;
                        break;
                }
        }
        if (!event) {
                event = "kmem/kmalloc";
                if (!keys)
                        keys = "call_site.sym,bytes_req";
                if (!vals)
                        vals = "bytes_alloc";
                if (!sort)
                        sort = "bytes_req,bytes_alloc";
                if (!desc)
                        desc = "bytes_alloc";
        }
        process_hist(cmd, instance, event, keys, vals, sort, ascend, desc);
}

NAME

tracefs_hist_reset — reset the history filter for a trace event

SYNOPSIS

#include <tracefs.h>
int tracefs_hist_reset(struct tracefs_entry *entry);

DESCRIPTION

The tracefs_hist_reset() function resets the history filter associated with the given trace event entry. The history filter is used to store and retrieve a history of events. Resetting it clears any stored history.

KEY TYPES

This function operates on a struct tracefs_entry, which represents a trace event. The tracefs_hist_reset() function specifically targets the history filter mechanism within this structure.

RETURN VALUE

On success, tracefs_hist_reset() returns 0. On failure, it returns a negative value indicating the error.

EXAMPLE

struct tracefs_entry *entry;
int ret;

// Assume 'entry' is a valid tracefs_entry obtained from another tracefs function
// ...

ret = tracefs_hist_reset(entry);
if (ret < 0) {
    fprintf(stderr, "Failed to reset history filter: %d\n", ret);
    // Handle error
} else {
    printf("History filter reset successfully.\n");
}
