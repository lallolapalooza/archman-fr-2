CTRTRS

Objectif :

!>
!> CTRTRS résout un système triangulaire de la forme
!>
!>    A * X = B,  A**T * X = B,  ou  A**H * X = B,
!>
!> où A est une matrice triangulaire d'ordre N, et B est une matrice N-par-NRHS.
!>
!> Cette sous-routine vérifie que A est non singulière, mais les appelants doivent noter que seule la
!> singularité exacte est détectée. Il est concevable que des éléments diagonaux de A soient
!> des nombres anormalement petits sans que cette sous-routine ne signale une erreur.
!>
!> Si une perte possible de précision numérique due à des matrices quasi-singulières est une préoccupation,
!> l'appelant doit vérifier que A est non singulière dans une certaine tolérance avant d'appeler cette sous-routine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' :  A est triangulaire supérieure ;
!>          = 'L' :  A est triangulaire inférieure.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N' :  A * X = B     (Pas de transposée)
!>          = 'T' :  A**T * X = B  (Transposée)
!>          = 'C' :  A**H * X = B  (Transposée conjuguée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          = 'N' :  A est triangulaire non unitaire ;
!>          = 'U' :  A est triangulaire unitaire.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie supérieure
!>          triangulaire N-par-N de tête du tableau A contient la matrice
!>          triangulaire supérieure, et la partie strictement inférieure
!>          triangulaire de A n'est pas référencée.  Si UPLO = 'L', la partie inférieure
!>          triangulaire N-par-N de tête du tableau A contient la matrice
!>          triangulaire inférieure, et la partie strictement supérieure
!>          triangulaire de A n'est pas référencée.  Si DIAG = 'U', les éléments diagonaux de A
!>          ne sont pas non plus référencés et sont supposés être 1.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEXE, dimension (LDB,NRHS)
!>          À l'entrée, la matrice du côté droit B.
!>          À la sortie, si INFO = 0, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était invalide
!>          > 0 :  si INFO = i, le i-ème élément diagonal de A est exactement zéro,
!>               indiquant que la matrice est singulière et que les solutions
!>               X n'ont pas été calculées.
!>

trtrs(3) - LAPACK

NAME

trtrs

solves a triangular system of linear equations

SYNOPSIS

subroutine c?trtrs(character uplo, character trans, character diag, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

Detailed Description

The purpose of the routines is to solve the triangular matrix equation

    A * X = B,  or  A**T * X = B,  or  A**H * X = B

where A is an N-by-N triangular matrix, X and B are N-by-NRHS matrices, and A**T and A**H denote the transpose and conjugate transpose of A, respectively.

A typical invocation of the package would be

    CALL STRTRS('U','N','N',N,NRHS,A,LDA,B,LDB,INFO)

Note that the complex routines (c?trtrs) take double precision (complex*16) arguments. The single precision routines (s?trtrs) take single precision (real) arguments.

subroutine ctrtrip (character uplo, character diag, integer n, complex*16, dimension( lda, * ) a, integer lda, integer info)

CTRTRIP

Purpose:

!>
!> CTRTRIP computes the inverse of a triangular matrix A.
!>
!> This subroutine verifies that A is nonsingular, but callers should note that only exact
!> singularity is detected. It is conceivable for one or more diagonal elements of A to be
!> subnormally tiny numbers without this subroutine signalling an error.
!>
!> If a possible loss of numerical precision due to near-singular matrices is a concern, the
!> caller should verify that A is nonsingular within some tolerance before calling this subroutine.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  A is upper triangular;
!>          = 'L':  A is lower triangular.
!>

DIAG

!>          DIAG is CHARACTER*1
!>          = 'N':  A is non-unit triangular;
!>          = 'U':  A is unit triangular.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          On entry, the upper or lower triangular matrix A.
!>          On exit, the strictly upper or strictly lower triangular part of
!>          A is overwritten by the elements of the inverse of A. The
!>          diagonal elements of A are also overwritten by the elements of
!>          the inverse of A.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, the i-th diagonal element of A is exactly zero,
!>               indicating that the matrix is singular and the inverse
!>               has not been computed.
!>

!>
!> DTRTRS solves a triangular system of the form
!>
!>    A * X = B  or  A**T * X = B,

!> subnormally tiny numbers without this subroutine signalling an error.

!> If a possible loss of numerical precision due to near-singular matrices is a concern, the
!> caller should verify that A is nonsingular within some tolerance before calling this subroutine.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  A is upper triangular;
!>          = 'L':  A is lower triangular.
!>

TRANS

!>          TRANS is CHARACTER*1
!>          Specifies the form of the system of equations:
!>          = 'N':  A * X = B  (No transpose)
!>          = 'T':  A**T * X = B  (Transpose)
!>          = 'C':  A**H * X = B  (Conjugate transpose = Transpose)
!>

DIAG

!>          DIAG is CHARACTER*1
!>          = 'N':  A is non-unit triangular;
!>          = 'U':  A is unit triangular.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrix B.  NRHS >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          The triangular matrix A.  If UPLO = 'U', the leading N-by-N
!>          upper triangular part of the array A contains the upper
!>          triangular matrix, and the strictly lower triangular part of
!>          A is not referenced.  If UPLO = 'L', the leading N-by-N lower
!>          triangular part of the array A contains the lower triangular
!>          matrix, and the strictly upper triangular part of A is not
!>          referenced.  If DIAG = 'U', the diagonal elements of A are
!>          also not referenced and are assumed to be 1.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

B

!>          B is REAL array, dimension (LDB,NRHS)
!>          On entry, the right hand side matrix B.
!>          On exit, if INFO = 0, the solution matrix X.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, the i-th diagonal element of A is exactly zero,
!>               indicating that the matrix is singular and the solutions
!>               X have not been computed.
!>

DTRTRS

Objectif :

!>
!> DTRTRS résout un système triangulaire de la forme
!>
!>    A * X = B  ou  A**T * X = B,
!>
!> où A est une matrice triangulaire d'ordre N, et B est une matrice N x NRHS.
!>
!> Cette sous-routine vérifie que A est non singulière, mais les appelants doivent noter que seule la
!> singularité exacte est détectée. Il est concevable qu'un ou plusieurs éléments diagonaux de A soient
!> des nombres anormalement petits sans que cette sous-routine ne signale d'erreur.
!>
!> Si une perte possible de précision numérique due à des matrices quasi singulières est une préoccupation,
!> l'appelant doit vérifier que A est non singulière dans une certaine tolérance avant d'appeler cette sous-routine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  A est triangulaire supérieure;
!>          = 'L':  A est triangulaire inférieure.
!>

TRANS

!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations:
!>          = 'N':  A * X = B  (Pas de transposée)
!>          = 'T':  A**T * X = B  (Transposée)
!>          = 'C':  A**H * X = B  (Transposée conjuguée = Transposée)
!>

DIAG

!>          DIAG est CHARACTER*1
!>          = 'N':  A est triangulaire non unitaire;
!>          = 'U':  A est triangulaire unitaire.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau REAL, dimension (LDA,N)
!>          La matrice triangulaire A.  Si UPLO = 'U', la partie triangulaire supérieure
!>          supérieure de N x N du tableau A contient la matrice triangulaire supérieure,
!>          et la partie strictement triangulaire inférieure de A n'est pas référencée.
!>          Si UPLO = 'L', la partie triangulaire inférieure
!>          inférieure de N x N du tableau A contient la matrice triangulaire inférieure,
!>          et la partie strictement triangulaire supérieure de A n'est pas
!>          référencée.  Si DIAG = 'U', les éléments diagonaux de A sont
!>          également non référencés et supposés être 1.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau REAL, dimension (LDB,NRHS)
!>          À l'entrée, la matrice du côté droit B.
!>          À la sortie, si INFO = 0, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, le i-ème élément diagonal de A est exactement zéro,
!>               indiquant que la matrice est singulière et que les solutions
!>               X n'ont pas été calculées.
