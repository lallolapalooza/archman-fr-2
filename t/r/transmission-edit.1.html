TRANSMISSION-EDIT(1) Manuel des commandes générales TRANSMISSION-EDIT(1)

NOM

transmission-edit — utilitaire en ligne de commande pour modifier les URLs d'annonce des fichiers .torrent

SYNTAXE

transmission-edit [-h] [-a url] [-d url] [-r recherche remplacement] [-s source] fichier_torrent(s)

DESCRIPTION

transmission-edit est un utilitaire en ligne de commande pour modifier les URLs d'annonce des fichiers .torrent.

OPTIONS

-h --help
Affiche une courte page d'aide et quitte.
-a --add URL
Ajoute une URL d'annonce à la liste d'annonce du torrent si elle n'est pas déjà dans la liste.
-d --delete URL
Supprime une URL d'annonce de la liste d'annonce du torrent.
-r --replace recherche remplacement
Recherche et remplace une sous-chaîne dans les URLs d'annonce d'un torrent. Ceci peut être utilisé pour changer une URL d'annonce lorsque le tracker déménage ou que votre code d'accès change.
-s --source source
Définit la balise source à l'intérieur d'un torrent.

EXEMPLES

Mise à jour d'un code d'accès de tracker dans tous vos torrents :

$ transmission-edit -r ancien-code nouveau-code ~/.config/transmission/torrents/*\.torrent
