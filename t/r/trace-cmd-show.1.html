NOM

trace-cmd-show - afficher le contenu du tampon de traçage du noyau Ftrace

SYNTAXE

trace-cmd show [OPTIONS]

DESCRIPTION

Le trace-cmd(1) show affiche le contenu de l'un des fichiers de traçage du noyau Linux Ftrace : trace, snapshot ou trace_pipe. C'est essentiellement l'équivalent de faire :

cat /sys/kernel/debug/tracing/trace

OPTIONS

-p

Au lieu d'afficher le contenu du fichier "trace", utiliser le fichier "trace_pipe". La différence entre les deux est que le fichier "trace" est statique. C'est-à-dire, si le traçage est arrêté, le fichier "trace" affichera le même contenu à chaque fois. 
Le fichier "trace_pipe" est une lecture consommatrice, où une lecture du fichier consommera la sortie de ce qui a été lu et ne lira pas la même chose une seconde fois, même si le traçage est arrêté. Ce fichier se bloquera également. Si aucune donnée n'est disponible, trace-cmd show s'arrêtera et attendra l'apparition de données.

-s

Au lieu de lire le fichier "trace", lire le fichier snapshot. Le snapshot est créé par une application qui écrit dedans et le noyau effectuera un échange entre le tampon actif actuel et le tampon snapshot actuel. Si plus aucun échange n'est effectué, le snapshot restera statique. Ce n'est pas une lecture consommatrice.

-c cpu

Lire uniquement le fichier trace pour un CPU spécifié.

-f

Afficher le nom de chemin complet du fichier qui est affiché.

-B buf

Si une instance de tampon a été créée, alors l'option -B accédera aux fichiers associés au tampon donné.

--tracing_on

Indiquer si le traçage est activé pour l'instance donnée.

--current_tracer

Indiquer quel est le traceur actuel.

--buffer_size

Afficher la taille actuelle du tampon (par CPU)

--buffer_total_size

Afficher la taille totale de tous les tampons.

--buffer_subbuf_size

Afficher la taille en kilo-octets des sous-tampons du tampon circulaire. Le tampon circulaire est divisé en sous-tampons de taille égale où un événement ne peut pas être plus grand que la section de données du sous-tampon (la taille moins ses métadonnées).

--buffer_percent

Indiquer le pourcentage du tampon qui doit être rempli avant qu'un lecteur bloqué sur le fichier trace_pipe_raw ne soit réveillé. 
0       : réveiller immédiatement à toute nouvelle donnée
1 - 99  : réveiller à ce pourcentage de sous-tampons pleins
100     : réveiller après que le tampon soit plein et que l'écrivain soit sur le dernier sous-tampon

--ftrace_filter

Afficher les filtres de fonctions qui sont définis.

--ftrace_notrace

Afficher les filtres de fonctions désactivées qui sont définis.

--ftrace_pid

Afficher les PID auxquels le traceur de fonctions est limité (le cas échéant).

--graph_function

Afficher les fonctions qui seront représentées graphiquement.

--graph_notrace

Afficher les fonctions qui ne seront pas représentées graphiquement.

--hist [system:]event

Afficher le contenu d'un fichier "hist" d'histogramme pour un événement donné

--trigger [system:]event

Afficher le contenu du fichier "trigger" pour un événement donné

--cpumask

Afficher le masque des CPUs que le traçage suivra.
