tracefs_instance_set_subbuf_size(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_instance_get_subbuf_size, tracefs_instance_set_subbuf_size - Fonctions d'aide pour travailler avec les sous-tampons d'anneau.

SYNTAXE

#include <tracefs.h>
size_t tracefs_instance_get_subbuf_size(struct tracefs_instance *instance);
int tracefs_instance_set_subbuf_size(struct tracefs_instance *instance, size_t size);

DESCRIPTION

Fonctions d'aide pour travailler avec les sous-tampons du tampon d'anneau de traçage. Le tampon d'anneau de traçage est divisé en **sous-tampons**. Un événement ne peut pas être plus grand que la section de données du sous-tampon (voir tep_get_sub_buffer_data_size(3)). Par défaut, le tampon d'anneau utilise la **taille de page** de l'architecture comme taille par défaut du sous-tampon, mais cela peut être limitant s'il y a un besoin d'événements volumineux, par exemple, si l'application veut écrire de grandes chaînes dans le fichier trace_marker.

La fonction tracefs_instance_get_subbuf_size() renvoie la taille actuelle en kilo-octets des sous-tampons du tampon d'anneau.

La fonction tracefs_instance_set_subbuf_size() écrira la taille en kilo-octets de ce que devrait être la nouvelle taille du sous-tampon. Notez que ce n'est qu'une indication de la taille minimale du sous-tampon. Elle ne prend pas en compte les métadonnées utilisées par le sous-tampon, donc la taille écrite ne doit pas être inférieure de 16 octets à la taille maximale de l'événement qui sera utilisée. Le noyau rendra probablement la taille du sous-tampon plus grande que spécifié, car il peut avoir besoin d'aligner la taille pour des raisons d'implémentation.

VALEUR DE RETOUR

La fonction tracefs_instance_get_subbuf_size() renvoie la taille du sous-tampon actuel pour le tampon d'anneau instance donné ou -1 en cas d'erreur.

La fonction tracefs_instance_set_subbuf_size() renverra 0 si elle a correctement défini la taille du sous-tampon en kilo-octets du tampon d'anneau instance, ou -1 en cas d'erreur.

EXEMPLE

#include <stdlib.h>
#include <tracefs.h>
#include <errno.h>
int main(int argc, char **argv)
{
        struct tep_handle *tep;
        ssize_t save_subsize;
        ssize_t subsize;
        char *trace;
        char buf[3000];
        int meta_size;
        int ret;
        int i;
        tep = tep_alloc();
        ret = tracefs_load_headers(NULL, tep);
        tep_free(tep);
        if (ret < 0) {
                perror("lecture des en-têtes");
                exit(-1);
        }
        meta_size = tep_get_sub_buffer_size(tep) - tep_get_sub_buffer_data_size(tep);
        save_subsize = tracefs_instance_get_subbuf_size(NULL);
        if (save_subsize < 0) {
                printf("Modification de la taille du sous-tampon non disponible\n");
                exit(-1);
        }
        subsize = save_subsize * 1024;
        /* Au moins 4 écritures sur un sous-tampon */
        if (subsize - meta_size < sizeof(buf) *4 ) {
                subsize = ((sizeof(buf) * 4 + meta_size) + 1023) / 1024;
                tracefs_instance_set_subbuf_size(NULL, subsize);
        }
        for (i = 0; i < sizeof(buf) - 1; i++) {
                buf[i] = '0' + i % 10;
        }
        buf[i] = '\0';
        tracefs_instance_clear(NULL);
        for (i = 0; i < 4; i++) {
                ret = tracefs_printf(NULL, "%s\n", buf);
                if (ret < 0)
                        perror("écriture");
        }
        trace = tracefs_instance_file_read(NULL, "trace", NULL);
        printf("%s\n", trace);
        free(trace);
        printf("La taille du tampon était : %zd * 1024\n",
               tracefs_instance_get_subbuf_size(NULL));
        tracefs_instance_set_subbuf_size(NULL, save_subsize);
}
