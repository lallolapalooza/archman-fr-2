NOM

tracefs_file_exists, tracefs_dir_exists, tracefs_instance_get_file, tracefs_instance_get_dir - Travailler avec les fichiers et répertoires dans les instances de traçage.

SYNOPSIS

#include <tracefs.h>
bool tracefs_file_exists(struct tracefs_instance *instance, char *name);
bool tracefs_dir_exists(struct tracefs_instance *instance, char *name);
char *tracefs_instance_get_file(struct tracefs_instance *instance, const char *file);
char *tracefs_instance_get_dir(struct tracefs_instance *instance);

DESCRIPTION

Cet ensemble d'API peut être utilisé pour travailler avec les fichiers de traçage dans toutes les instances de traçage. Chacune de ces API prend un argument instance, qui peut être NULL pour agir sur l'instance de niveau supérieur. Sinon, elle agit sur une instance créée avec tracefs_insance_create(3)

La fonction tracefs_file_exists() vérifie si un fichier nommé name existe dans instance.

La fonction tracefs_dir_exists() vérifie si un répertoire nommé name existe dans instance.

La fonction tracefs_instance_get_file() renvoie le chemin complet du fichier portant le nom name dans instance. Notez qu'elle ne vérifie pas si le fichier existe dans l'instance.

La fonction tracefs_instance_get_dir() renvoie le chemin complet du répertoire portant le nom name dans instance. Notez qu'elle ne vérifie pas si le répertoire existe dans l'instance.

VALEUR RENVOYÉE

Les fonctions tracefs_file_exists() et tracefs_dir_exists() renvoient true si le fichier / répertoire existe dans l'instance donnée, ou false s'il n'existe pas.

Les fonctions tracefs_instance_get_file() et tracefs_instance_get_dir() renvoient une chaîne de caractères ou NULL en cas d'erreur. La chaîne renvoyée doit être libérée avec tracefs_put_tracing_file().

EXEMPLE

#include <tracefs.h>
struct tracefs_instance *inst = tracefs_instance_create("foo");
        if (!inst) {
                /* Erreur lors de la création d'une nouvelle instance de traçage */
                ...
        }
        if (tracefs_file_exists(inst,"trace_clock")) {
                /* L'instance foo supporte le trace clock */
                char *path, *clock;
                int size;
                path =  = tracefs_instance_get_file(inst, "trace_clock")
                if (!path) {
                        /* Erreur lors de l'obtention du chemin du fichier trace_clock dans l'instance foo */
                        ...
                }
                ...
                tracefs_put_tracing_file(path);
                clock = tracefs_instance_file_read(inst, "trace_clock", &size);
                if (!clock) {
                        /* Échec de la lecture du fichier trace_clock dans l'instance foo */
                        ...
                }
                ...
                free(clock);
                if (tracefs_instance_file_write(inst, "trace_clock", "global") != strlen("global")) {
                        /* Échec de la définition du trace clock global dans l'instance foo */
                        ...
                }
        } else {
                /* L'instance foo ne supporte pas le trace clock */
        }
        if (tracefs_dir_exists(inst,"options")) {
                /* L'instance foo supporte les options de traçage */
                char *path = tracefs_instance_get_file(inst, "options");
                if (!path) {
                        /* Erreur lors de l'obtention du chemin du répertoire options dans l'instance foo */
                        ...
                }
                tracefs_put_tracing_file(path);
        } else {
                /* L'instance foo ne supporte pas les options de traçage */
        }
        ...
        if (tracefs_instance_is_new(inst))
                tracefs_instance_destroy(inst);
        else
                tracefs_instance_free(inst);
        ...
        long long int res;
        if (tracefs_instance_file_read_number(NULL, "tracing_on", &res) == 0) {
                if (res == 0) {
                        /* Le traçage est désactivé dans l'instance principale */
                } else if (res == 1) {
                        /* Le traçage est activé dans l'instance principale */
                } else {
                        /* État de traçage inconnu de l'instance principale */
                }
        } else {
                /* Échec de la lecture de l'entier depuis le fichier tracing_on */
        }
        ...
        int fd;
        fd = tracefs_instance_file_open(NULL, "tracing_on", O_WRONLY);
        if (fd >= 0) {
                /* Obtention du descripteur de fichier pour le fichier tracing_on de l'instance principale pour écriture */
                ...
                close(fd);
        }

NAME

tracefs_dir_exists - check if a tracefs directory exists

LIBRARY

tracefs (part of libtracefs, -ltracefs)

SYNOPSIS

#include <tracefs.h>

int tracefs_dir_exists(const char *dirname);

DESCRIPTION

The tracefs_dir_exists() function checks if the directory specified by dirname exists within the tracefs filesystem mount point. The dirname is the base name of the directory, without any leading path components. For example, to check if the "events" directory exists, you would call tracefs_dir_exists("events").

RETURN VALUE

Returns 1 if the directory exists, 0 if it does not exist, and -1 on error (e.g., if tracefs is not mounted or an invalid argument is passed).

EXAMPLE

#include <stdio.h>
#include <tracefs.h>

int main(int argc, char **argv) {
    const char *dir = "events";
    int ret;

    ret = tracefs_dir_exists(dir);
    if (ret == 1) {
        printf("Tracefs directory '%s' exists.\n", dir);
    } else if (ret == 0) {
        printf("Tracefs directory '%s' does not exist.\n", dir);
    } else {
        perror("tracefs_dir_exists");
        return 1;
    }

    return 0;
}

NOTES

This function relies on the tracefs filesystem being mounted. If tracefs is not mounted, the function will return -1 and set errno accordingly.

SEE ALSO

tracefs(8), tracefs_mounted(3)

NOM

tracefs_dir_exists - vérifier si un répertoire tracefs existe

BIBLIOTHÈQUE

tracefs (partie de libtracefs, -ltracefs)

SYNOPSIS

#include <tracefs.h>

int tracefs_dir_exists(const char *dirname);

DESCRIPTION

La fonction tracefs_dir_exists() vérifie si le répertoire spécifié par dirname existe dans le point de montage du système de fichiers tracefs. dirname est le nom de base du répertoire, sans aucun composant de chemin précédent. Par exemple, pour vérifier si le répertoire "events" existe, vous appelleriez tracefs_dir_exists("events").

VALEUR DE RETOUR

Retourne 1 si le répertoire existe, 0 s'il n'existe pas, et -1 en cas d'erreur (par exemple, si tracefs n'est pas monté ou si un argument invalide est passé).

EXEMPLE

#include <stdio.h>
#include <tracefs.h>

int main(int argc, char **argv) {
    const char *dir = "events";
    int ret;

    ret = tracefs_dir_exists(dir);
    if (ret == 1) {
        printf("Le répertoire tracefs '%s' existe.\n", dir);
    } else if (ret == 0) {
        printf("Le répertoire tracefs '%s' n'existe pas.\n", dir);
    } else {
        perror("tracefs_dir_exists");
        return 1;
    }

    return 0;
}

NOTES

Cette fonction repose sur le montage du système de fichiers tracefs. Si tracefs n'est pas monté, la fonction retournera -1 et définira errno en conséquence.
