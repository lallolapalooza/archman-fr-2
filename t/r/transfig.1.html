TRANSFIG(1) Manuel des commandes générales TRANSFIG(1)

NOM

transfig - crée un makefile pour des figures LaTeX portables

SYNTAXE

transfig [ -L langage ] [ -M makefile ] [ -T fichiertex ] [ -I fichiermacros ] [ -V ] [ specs_controle fichier_fig ... ]

DESCRIPTION

Transfig crée un makefile pour traduire des figures décrites en code Fig ou PIC dans un langage graphique LaTeX spécifié. Les fichiers PIC sont identifiés par le suffixe ".pic"; les fichiers Fig peuvent être spécifiés avec ou sans le suffixe ".fig". Transfig crée également un fichier de macros TeX approprié au langage cible.

OPTIONS

Le spécificateur de langage doit être l'un des suivants : box, cgm, eepic, eepicemu, emf, epic, eps, ge, gif, ibmgl, jpeg, latex, map, mf, mmp, mp, pcx, pdf, pdftex, pdftex_t, pic, pictex, png, ppm, ps, psfig, pstex, pstex_t, ptk, sld, textyl, tiff, tk, tpic, xbm, xpm ou null. Le spécificateur psfig est comme le spécificateur ps, sauf qu'il utilise le paquet de macros psfig. Le spécificateur pstex est comme psfig, sauf qu'il utilise LaTeX pour traiter le texte formaté (spécial). Le spécificateur null entraîne le remplacement des figures par des boîtes vides de la taille appropriée. Si aucun langage n'est spécifié, epic est le langage par défaut.

Les noms du makefile et du fichier de macros TeX peuvent être définis avec les options -M et -T. Les noms par défaut sont "Makefile" et "transfig.tex", respectivement. S'il existe déjà un makefile dans le répertoire, transfig le renomme d'abord en makefile~. Il en va de même pour tout fichier de macros TeX existant. Si l'option -I est spécifiée, une commande pour lire fichiermacros est insérée dans le fichier de macros TeX. Si l'option -V est spécifiée, le numéro de version du programme est uniquement imprimé.

Les spécificateurs de contrôle sont

-m mag
définit le grossissement auquel la figure est rendue (par défaut 1.0).
-f police
définit la famille de polices par défaut utilisée pour les objets texte (par défaut "rm").
-s taille_police
définit la taille de police par défaut (en points) pour les objets texte (par défaut 11*mag).
-o option
transmet la chaîne d'option spécifiée à fig2dev.

S'il n'y a pas de mise à l'échelle, la police par défaut est une police romaine de onze points. Les spécificateurs de langage et de contrôle peuvent apparaître plus d'une fois ; ils affectent la traduction des fichiers qui leur succèdent dans la liste des arguments. S'il n'y a pas de fichiers spécifiés, "*.fig" est supposé.
