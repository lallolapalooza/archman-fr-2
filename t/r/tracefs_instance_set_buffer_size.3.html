NOM

tracefs_instance_get_name, tracefs_instance_get_trace_dir, tracefs_instances_walk, tracefs_instance_exists, tracefs_instance_get_buffer_size, tracefs_instance_set_buffer_size, tracefs_instance_get_buffer_percent, tracefs_instance_set_buffer_percent - Fonctions d'aide pour travailler avec les instances de traçage.

SYNOPIS

#include <tracefs.h>
const char *tracefs_instance_get_name(struct tracefs_instance *instance);
const char *tracefs_instance_get_trace_dir(struct tracefs_instance *instance);
int tracefs_instances_walk(int (*callback)(const char *, void *), void *context);
bool tracefs_instance_exists(const char *name);
size_t tracefs_instance_get_buffer_size(struct tracefs_instance *instance, int cpu);
int tracefs_instance_set_buffer_size(struct tracefs_instance *instance, size_t size, int cpu);
int tracefs_instance_get_buffer_percent(struct tracefs_instance *instance);
int tracefs_instance_set_buffer_percent(struct tracefs_instance *instance, int val);

DESCRIPTION

Fonctions d'aide pour travailler avec les instances de traçage.

La fonction tracefs_instance_get_name() retourne le nom de l'instance donnée. Notez que l'instance supérieure n'a pas de nom, la fonction retourne NULL pour celle-ci.

La fonction tracefs_instance_get_trace_dir() retourne le répertoire de traçage où l'instance donnée est configurée.

La fonction tracefs_instances_walk() parcourt toutes les instances de traçage configurées dans le système et appelle callback pour chacune d'entre elles. L'argument context est passé au callback, avec le nom de l'instance. Si le callback retourne une valeur non nulle, l'itération s'arrête. Notez que le callback n'est pas appelé pour l'instance supérieure.

La fonction tracefs_instance_exists() vérifie si une instance avec le nom name donné existe dans le système.

La fonction tracefs_instace_get_buffer_size() retourne la taille du tampon circulaire. Si cpu est négatif, elle retourne la taille totale de tous les tampons circulaires par CPU, sinon elle retourne la taille du tampon circulaire par CPU pour le cpu spécifié.

La fonction tracefs_instance_set_buffer_size() définit la taille du tampon circulaire. Si cpu est négatif, elle définit tous les tampons circulaires par CPU à size (notez que la taille totale est le nombre de CPU * size). Si cpu est spécifié, elle ne définit que la taille du tampon circulaire par CPU.

La fonction tracefs_instance_set_buffer_percent() définit la valeur du pourcentage du tampon de l'anneau de traçage pour l'instance ou le tampon de niveau supérieur si instance est NULL. Le pourcentage du tampon détermine quand les lecteurs sur tracefs_cpu_read(3), tracefs_cpu_buffered_read(3), tracefs_cpu_write(3) et tracefs_cpu_pipe(3) seront bloqués lorsque O_NONBLOCK n'est pas défini. La valeur de val doit être comprise entre 0 et 100, où :

  0   - bloque jusqu'à ce qu'il y ait des données dans le tampon circulaire
  1   - bloque jusqu'à ce que 1% des sous-tampons du tampon circulaire soient remplis
  50  - bloque jusqu'à ce que 50% des sous-tampons du tampon circulaire soient remplis
  100 - bloque jusqu'à ce que le tampon circulaire entier soit rempli

Notez que tout nombre de 0 à 100 peut être utilisé, représentant le pourcentage du tampon circulaire qui doit être rempli avant qu'un lecteur bloqué ne soit averti qu'il y a des données à récupérer.

La fonction tracefs_instance_get_buffer_percent() récupère le réglage actuel du pourcentage du tampon de l'anneau de traçage pour l'instance ou le tampon de niveau supérieur si instance est NULL.

VALEUR DE RETOUR

La fonction tracefs_instance_get_name() retourne une chaîne ou NULL dans le cas de l'instance supérieure. La chaîne retournée ne doit pas être libérée.

La fonction tracefs_instance_get_trace_dir() retourne une chaîne ou NULL en cas d'erreur. La chaîne retournée ne doit pas être libérée.

La fonction tracefs_instances_walk() retourne 0, si toutes les instances ont été parcourues, 1 si l'itération a été arrêtée par le callback, ou -1 en cas d'erreur.

La fonction tracefs_instance_exists() retourne true si une instance avec le nom donné name existe dans le système, ou false sinon.

La fonction tracefs_instance_get_buffer_size() retourne la taille du tampon circulaire en fonction de la valeur cpu passée, ou -1 en cas d'erreur.

La fonction tracefs_instance_set_buffer_size() retourne zéro en cas de succès et -1 en cas d'erreur.

tracefs_instance_set_buffer_size - set the size of the trace buffer

Library:
libtracefs (libtracefs, -ltracefs)

NAME

tracefs_instance_set_buffer_size - set the size of the trace buffer

SYNOPSIS

#include <tracefs.h>

int tracefs_instance_set_buffer_size(struct tracefs_instance *instance, size_t size);

DESCRIPTION

Sets the size of the trace buffer for the given tracefs instance. The size is given in bytes. If the size is 0, the default size will be used.

RETURN VALUE

On success, 0 is returned. On error, a negative value is returned and errno is set to indicate the error.

EXAMPLE

#include <stdio.h>
#include <stdlib.h>
#include <tracefs.h>

int main(void) {
    struct tracefs_instance *instance;
    int ret;

    instance = tracefs_open(NULL);
    if (instance == NULL) {
        perror("tracefs_open");
        return 1;
    }

    ret = tracefs_instance_set_buffer_size(instance, 1024 * 1024); /* 1MB buffer */
    if (ret < 0) {
        fprintf(stderr, "Failed to set buffer size: %s\n", strerror(-ret));
        tracefs_close(instance);
        return 1;
    }

    tracefs_close(instance);
    return 0;
}
