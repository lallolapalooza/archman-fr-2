Documentation de la fonction

sous-routine ctrtri (caractère uplo, caractère diag, entier n, complexe, dimension( lda, * ) a, entier lda, entier info)

CTRTRI

But:

!>
!> CTRTRI calcule l'inverse d'une matrice triangulaire complexe supérieure ou inférieure
!> A.
!>
!> Ceci est la version de l'algorithme de niveau 3 BLAS.
!>

Paramètres

UPLO 
!>          UPLO est CARACTÈRE*1
!>          = 'U':  A est triangulaire supérieure ;
!>          = 'L':  A est triangulaire inférieure.
!>

DIAG

!>          DIAG est CARACTÈRE*1
!>          = 'N':  A est triangulaire non unitaire ;
!>          = 'U':  A est triangulaire unitaire.
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          À l'entrée, la matrice triangulaire A. Si UPLO = 'U', la
!>          partie supérieure triangulaire de dimension N x N du tableau A contient
!>          la matrice triangulaire supérieure, et la partie strictement inférieure
!>          triangulaire de A n'est pas référencée. Si UPLO = 'L', la
!>          partie inférieure triangulaire de dimension N x N du tableau A contient
!>          la matrice triangulaire inférieure, et la partie strictement supérieure
!>          triangulaire de A n'est pas référencée. Si DIAG = 'U', les
!>          éléments diagonaux de A ne sont pas non plus référencés et sont
!>          supposés être 1.
!>          À la sortie, l'inverse (triangulaire) de la matrice originale, dans
!>          le même format de stockage.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

INFO

!>          INFO est ENTIER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0: si INFO = i, A(i,i) est exactement zéro. La
!>               matrice triangulaire est singulière et son inverse ne peut pas être calculé.
!>
