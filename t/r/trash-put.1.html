NOM

trash-put - Utilitaire de corbeille en ligne de commande.

SYNOPSIS

trash [OPTION] ... [ARGUMENTS] ...
trash-put [OPTION] ... [ARGUMENTS] ...

DESCRIPTION

Le paquet trash-cli fournit une interface en ligne de commande pour une corbeille conforme à la spécification Trash de FreeDesktop.org. Il mémorise le nom, le chemin d'origine, la date de suppression et les permissions de chaque fichier placé dans la corbeille.

Les fichiers placés dans la corbeille à partir de la partition personnelle se trouveront soit dans $XDG_DATA_HOME/Trash, soit dans ~/.local/share/Trash/ (si $XDG_DATA_HOME n'est pas défini ou est vide).

Les fichiers placés dans la corbeille à partir d'autres partitions se trouveront dans l'un des deux emplacements suivants :


- $top_dir/.Trash/$uid
- $top_dir/.Trash-$uid

Où :
- $top_dir est le point de montage du volume contenant le fichier à supprimer.
- $uid est l'identifiant numérique de l'utilisateur qui supprime.

La première option $top_dir/.Trash/$uid ne fonctionne que si le répertoire .Trash a le bit sticky activé. La seconde option est utilisée lorsque la première n'est pas viable.

ARGUMENTS

Noms de fichiers ou de répertoires à déplacer dans la corbeille.

OPTIONS

-f

Ignore silencieusement tous les fichiers ou répertoires inexistants. N'affiche pas de messages d'erreur et ne renvoie pas un statut différent de zéro à l'appelant pour de tels arguments inexistants.
-h, --help
Affiche le message d'aide et quitte.
--trash-dir=TRASHDIR
Utilise TRASHDIR comme dossier de corbeille.
-v, --verbose
Explique ce qui est fait.
--version
Affiche le numéro de version du programme et quitte.

EXEMPLES

$ trash-put foo   # met foo dans la corbeille
