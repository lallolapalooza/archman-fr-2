Documentation de la fonction

sous-routine ctrsv (character uplo, character trans, character diag, integer n, complex, dimension(lda,*) a, integer lda, complex, dimension(*) x, integer incx)

CTRSV

Objectif :

!>
!> CTRSV  résout l'un des systèmes d'équations
!>
!>    A*x = b,   ou   A**T*x = b,   ou   A**H*x = b,
!>
!> où b et x sont des vecteurs de n éléments et A est une matrice triangulaire
!> unitaire ou non unitaire, supérieure ou inférieure, de taille n x n.
!>
!> Aucun test de singularité ou de quasi-singularité n'est inclus dans cette
!> sous-routine. De tels tests doivent être effectués avant d'appeler cette sous-routine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>           À l'entrée, UPLO spécifie si la matrice est supérieure ou
!>           inférieure comme suit :
!>
!>              UPLO = 'U' ou 'u'   A est une matrice triangulaire supérieure.
!>
!>              UPLO = 'L' ou 'l'   A est une matrice triangulaire inférieure.
!>

TRANS

!>          TRANS est CHARACTER*1
!>           À l'entrée, TRANS spécifie les équations à résoudre comme suit :
!>
!>              TRANS = 'N' ou 'n'   A*x = b.
!>
!>              TRANS = 'T' ou 't'   A**T*x = b.
!>
!>              TRANS = 'C' ou 'c'   A**H*x = b.
!>

DIAG

!>          DIAG est CHARACTER*1
!>           À l'entrée, DIAG spécifie si A est unitaire ou non
!>           triangulaire comme suit :
!>
!>              DIAG = 'U' ou 'u'   A est supposée unitaire triangulaire.
!>
!>              DIAG = 'N' ou 'n'   A n'est pas supposée unitaire
!>                                  triangulaire.
!>

N

!>          N est INTEGER
!>           À l'entrée, N spécifie l'ordre de la matrice A.
!>           N doit être supérieur ou égal à zéro.
!>

A

!>          A est un tableau COMPLEX, dimension ( LDA, N )
!>           Avant l'entrée avec UPLO = 'U' ou 'u', la partie supérieure triangulaire
!>           de taille n x n du tableau A doit contenir la matrice triangulaire
!>           supérieure et la partie strictement inférieure triangulaire de
!>           A n'est pas référencée.
!>           Avant l'entrée avec UPLO = 'L' ou 'l', la partie inférieure triangulaire
!>           de taille n x n du tableau A doit contenir la matrice triangulaire
!>           inférieure et la partie strictement supérieure triangulaire de
!>           A n'est pas référencée.
!>           Notez que lorsque DIAG = 'U' ou 'u', les éléments diagonaux de
!>           A ne sont pas non plus référencés, mais sont supposés être l'unité.
!>

LDA

!>          LDA est INTEGER
!>           À l'entrée, LDA spécifie la première dimension de A telle que déclarée
!>           dans le programme appelant (subroutine). LDA doit être au moins
!>           max( 1, n ).
!>

X

!>          X est un tableau COMPLEX, dimension au moins
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Avant l'entrée, le tableau incrémenté X doit contenir le vecteur
!>           du second membre b de n éléments. En sortie, X est écrasé
!>           par le vecteur solution x.
!>

INCX

!>          INCX est INTEGER
!>           À l'entrée, INCX spécifie l'incrément pour les éléments de
!>           X. INCX ne doit pas être nul.
!>

NAME

        
trsv - solves one of the systems of equations A*x = b, or A' * x = b, or A'H * x = b

    


    

        
SYNOPSIS

        

            
subroutine   ctrsv (character uplo, character trans, character diag, integer n, complex,   dimension(lda,*) a, integer lda, complex, dimension(*) x, integer incx)

            
CTRVS

            
Purpose:

            

                
!>
!> CTRSV  solves one of the systems of equations
!>
!>    A*x = b,   or   A**T*x = b,   or   A**H*x = b,
!>
!> where b and x are n element vectors and A is an n by n unit, or
!> non-unit, upper or lower triangular matrix.
!>
!> No test for singularity or near-singularity is included in this
!> routine. Such tests must be performed before calling this routine.
!> 

            

            
Parameters

            

                UPLO
                
!>          UPLO is CHARACTER*1
!>           On entry, UPLO specifies whether the matrix is an upper or
!>           lower triangular matrix as follows:
!>
!>              UPLO = 'U' or 'u'   A is an upper triangular matrix.
!>
!>              UPLO = 'L' or 'l'   A is a lower triangular matrix.
!> 

                
TRANS

                
!>          TRANS is CHARACTER*1
!>           On entry, TRANS specifies the equations to be solved as
!>           follows:
!>
!>              TRANS = 'N' or 'n'   A*x = b.
!>
!>              TRANS = 'T' or 't'   A**T*x = b.
!>
!>              TRANS = 'C' or 'c'   A**H*x = b.
!> 

                
DIAG

                
!>          DIAG is CHARACTER*1
!>           On entry, DIAG specifies whether or not A is unit
!>           triangular as follows:
!>
!>              DIAG = 'U' or 'u'   A is assumed to be unit triangular.
!>
!>              DIAG = 'N' or 'n'   A is not assumed to be unit
!>                                  triangular.
!> 

                
N

                
!>          N is INTEGER
!>           On entry, N specifies the order of the matrix A.
!>           N must be at least zero.
!> 

                
A

                
!>          A is COMPLEX array, dimension ( LDA, N )
!>           Before entry with  UPLO = 'U' or 'u', the leading n by n
!>           upper triangular part of the array A must contain the upper
!>           triangular matrix and the strictly lower triangular part of
!>           A is not referenced.
!>           Before entry with UPLO = 'L' or 'l', the leading n by n
!>           lower triangular part of the array A must contain the lower
!>           triangular matrix and the strictly upper triangular part of
!>           A is not referenced.
!>           Note that when  DIAG = 'U' or 'u', the diagonal elements of
!>           A are not referenced either, but are assumed to be unity.
!> 

                
LDA

                
!>          LDA is INTEGER
!>           On entry, LDA specifies the first dimension of A as declared
!>           in the calling (sub) program. LDA must be at least
!>           max( 1, n ).
!> 

                
X

                
!>          X is COMPLEX array, dimension at least
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Before entry, the incremented array X must contain the n
!>           element right-hand side vector b. On exit, X is overwritten
!>           with the solution vector x.
!> 

                
INCX

                
!>          INCX is INTEGER
!>           On entry, INCX specifies the increment for the elements of
!>           X. INCX must not be zero.
!>
