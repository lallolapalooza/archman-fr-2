tracefs_event_filter_apply(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_filter_string_append, tracefs_filter_string_verify, tracefs_event_filter_apply, tracefs_event_filter_clear - Ajouter, vérifier et appliquer des filtres d'événements

SYNOPSIS

#include <tracefs.h>
int tracefs_filter_string_append(struct tep_event *event, char **filter,
                                 struct tracefs_filter type, const char *field,
                                 enum tracefs_synth_compare compare, const char *val);
int tracefs_filter_string_verify(struct tep_event *event, const char *filter, char **err);
int tracefs_event_filter_apply(struct tracefs_instance *instance, struct tep_event *event, const char *filter);
int tracefs_event_filter_clear(struct tracefs_instance *instance, struct tep_event *event);

DESCRIPTION

tracefs_filter_string_append() est une manière de créer et de vérifier des filtres d'événements pour un événement donné. Il vérifie que le champ appartient à l'événement et que l'option comparaison utilisée est valide pour le type du champ, ainsi que la valeur. Pour les types qui ne sont pas de type TRACEFS_FILTER_COMPARE, il construira la chaîne logique et s'assurera également que la syntaxe est correcte. Par exemple, il n'y a pas plus de parenthèses fermantes que d'ouvrantes. Un AND (&&) ou OR (||) n'est pas mal placé, etc.

tracefs_synth_append_start_filter() crée un filtre ou y ajoute pour l'événement de départ. Selon le type, il construira une chaîne de jetons pour les parenthèses ou les instructions logiques, ou il pourra ajouter une comparaison du champ à la valeur basée sur la comparaison.

Si type est : TRACEFS_FILTER_COMPARE - Voir ci-dessous TRACEFS_FILTER_AND - Ajoute "&&" au filtre TRACEFS_FILTER_OR - Ajoute "||" au filtre TRACEFS_FILTER_NOT - Ajoute "!" au filtre TRACEFS_FILTER_OPEN_PAREN - Ajoute "(" au filtre TRACEFS_FILTER_CLOSE_PAREN - Ajoute ")" au filtre

champ, comparaison, et valeur sont ignorés sauf si type est égal à TRACEFS_FILTER_COMPARE, alors _comparaison sera utilisé pour les éléments suivants :

TRACEFS_COMPARE_EQ - champ == valeur

TRACEFS_COMPARE_NE - champ != valeur

TRACEFS_COMPARE_GT - champ > valeur

TRACEFS_COMPARE_GE - champ >= valeur

TRACEFS_COMPARE_LT - champ < valeur

TRACEFS_COMPARE_LE - champ <= valeur

TRACEFS_COMPARE_RE - champ ~ "valeur" : où champ est une chaîne de caractères.

TRACEFS_COMPARE_AND - champ & valeur : où champ est un champ de drapeaux.

tracefs_filter_string_verify() analyse filtre pour s'assurer que les champs correspondent à l'événement, et que la syntaxe est correcte. S'il y a une erreur de syntaxe, et que err n'est pas NUL, alors il sera alloué avec un message d'erreur indiquant ce qui a été trouvé comme erroné dans le filtre. err doit être libéré avec free().

tracefs_event_filter_apply() applique la chaîne de filtre donnée à l'événement dans l'instance donnée.

tracefs_event_filter_clear() efface tous les filtres sur l'événement dans l'instance donnée.

VALEUR DE RETOUR

tracefs_filter_string_append() retourne 0 en cas de succès et -1 en cas d'erreur.

tracefs_filter_string_verify() retourne 0 en cas de succès et -1 en cas d'erreur. S'il y a une erreur, et que errno n'est pas ENOMEM, alors err est alloué et contiendra une chaîne décrivant ce qui a été trouvé comme erroné dans filtre. err doit être libéré avec free().

tracefs_event_filter_apply() retourne 0 en cas de succès et -1 en cas d'erreur.

tracefs_event_filter_clear() retourne 0 en cas de succès et -1 en cas d'erreur.

EXEMPLE

#include <stdlib.h>
#include <stdio.h>
#include <ctype.h>
#include <tracefs.h>
static void usage(char **argv)
{
        fprintf(stderr, "usage: %s [system] event filter\n", argv[0]);
        exit(-1);
}
int main (int argc, char **argv)
{
        struct tep_handle *tep;
        struct tep_event *event;
        const char *system = NULL;
        const char *event_name;
        const char *filter;
        char *new_filter = NULL;
        char *err = NULL;
        int i;
        if (argc < 3)
                usage(argv);
        if (argc < 4) {
                event_name = argv[1];
                filter = argv[2];
        } else {
                system = argv[1];
                event_name = argv[2];
                filter = argv[3];
        }
        /* Charge tous les événements du système */
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("tep");
                exit(-1);
        }
        event = tep_find_event_by_name(tep, system, event_name);
        if (!event) {
                fprintf(stderr, "Event %s%s%s not found\n",
                        system ? system : "" , system ? " " : "",
                        event_name);
                exit(-1);
        }
        if (tracefs_filter_string_verify(event, filter, &err) < 0) {
                perror("tracecfs_event_verify_filter");
                if (err)
                        fprintf(stderr, "%s", err);
                free(err);
                exit(-1);
        }
        for (i = 0; filter[i]; i++) {
                char buf[strlen(filter)];
                char *field = NULL;
                char *val = NULL;
                enum tracefs_filter type;
                enum tracefs_compare compare = 0;
                int start_i, n;
                int quote;
                bool backslash;
                while (isspace(filter[i]))
                        i++;
                switch(filter[i]) {
                case '(':
                        type = TRACEFS_FILTER_OPEN_PAREN;
                        break;
                case ')':
                        type = TRACEFS_FILTER_CLOSE_PAREN;
                        break;
                case '!':
                        type = TRACEFS_FILTER_NOT;
                        break;
                case '&':
                        type = TRACEFS_FILTER_AND;
                        i++;
                        break;
                case '|':
                        type = TRACEFS_FILTER_OR;
                        i++;
                        break;
                default:
                        type = TRACEFS_FILTER_COMPARE;
                        while (isspace(filter[i]))
                                i++;
                        start_i = i;
                        for (; filter[i]; i++) {
                                switch(filter[i]) {
                                case 'a' ... 'z':
                                case 'A' ... 'Z':
                                case '0' ... '9':
                                case '_':
                                        continue;
                                }
                                break;
                        }
                        n = i - start_i;
                        field = buf;
                        strncpy(field, filter + start_i, n);
                        field[n++] = '\0';
                        val = buf + n;
                        while (isspace(filter[i]))
                                i++;
                        start_i = i;
                        switch(filter[i++]) {
                        case '>':
                                compare = TRACEFS_COMPARE_GT;
                                if (filter[i] == '=') {
                                        i++;
                                        compare = TRACEFS_COMPARE_GE;
                                }
                                break;
                        case '<':
                                compare = TRACEFS_COMPARE_LT;
                                if (filter[i] == '=') {
                                        i++;
                                        compare = TRACEFS_COMPARE_LE;
                                }
                                break;
                        case '=':
                                compare = TRACEFS_COMPARE_EQ;
                                i++;
                                break;
                        case '!':
                                compare = TRACEFS_COMPARE_NE;
                                i++;
                                break;
                        case '~':
                                compare = TRACEFS_COMPARE_RE;
                                break;
                        case '
&:
                                compare = TRACEFS_COMPARE_AND;
                                break;
                        }
                        while (isspace(filter[i]))
                                i++;
                        quote = 0;
                        backslash = false;
                        start_i = i;
                        for (; filter[i]; i++) {
                                if (quote) {
                                        if (backslash)
                                                backslash = false;
                                        else if (filter[i] == '\\')
                                                backslash = true;
                                        else if (filter[i] == quote)
                                                quote = 0;
                                        continue;
                                }
                                switch(filter[i]) {
                                case '"': case '\'':
                                        quote = filter[i];
                                        continue;
                                case 'a' ... 'z':
                                case 'A' ... 'Z':
                                case '0' ... '9':
                                case '_':
                                        continue;
                                }
                                break;
                        }
                        n = i - start_i;
                        strncpy(val, filter + start_i, n);
                        val[n] = '\0';
                        break;
                }
                n = tracefs_filter_string_append(event, &new_filter, type,
                                                field, compare, val);
                if (n < 0) {
                        fprintf(stderr, "Impossible de créer un nouveau filtre :\n'%s'\n",
                                new_filter ? new_filter : "(nul)");
                        exit(-1);
                }
        }
        if (tracefs_event_filter_apply(NULL, event, new_filter))
                fprintf(stderr, "Échec de l'application du filtre sur l'événement");
        tep_free(tep);
        printf("Nouveau filtre créé : '%s'\n", new_filter);
        free(new_filter);
        exit(0);
}
