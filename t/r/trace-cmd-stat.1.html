NOM

trace-cmd-stat - afficher l'état du système de traçage (ftrace)

SYNTAXE

trace-cmd stat [OPTIONS]

DESCRIPTION

trace-cmd(1) stat affiche les différents états du système de traçage (ftrace). Les états affichés sont :

Instances : Liste toutes les instances ftrace configurées.

Traceur : si l'un des traceurs (comme function_graph) est actif. Sinon, rien n'est affiché.

Événements : Liste les événements activés.

Filtres d'événements : Affiche les filtres qui sont définis pour n'importe quels événements.

Filtres de fonctions : Affiche les filtres pour les traceurs de fonctions.

Fonctions graphiques : Affiche les fonctions que le traceur de fonctions graphiques doit tracer.

Tampons : Affiche la taille du tampon de traçage s'il a été agrandi. Par défaut, les tampons de traçage sont dans un format compressé jusqu'à ce qu'ils soient utilisés. S'ils sont compressés, l'affichage du tampon ne sera pas montré.

Horloge de traçage : Si l'horloge de traçage est autre que celle par défaut « local », elle sera affichée.

Masque CPU de traçage : Si tous les CPU disponibles ne sont pas dans le masque CPU de traçage, alors le masque CPU de traçage sera affiché.

Latence max de traçage : Affiche la valeur de la latence max de traçage si elle est autre que zéro.

Kprobes : Affiche les kprobes qui sont définis pour le traçage.

Uprobes : Affiche les uprobes qui sont définis pour le traçage.

Journal d'erreurs : Affiche le contenu du fichier error_log de ftrace.

OPTIONS

-B nom-tampon

Affiche l'état d'une instance de tampon donnée. Peut être spécifié plusieurs fois pour afficher l'état de plusieurs instances.

-t

Si -B est également spécifié, affiche l'état du répertoire de traçage de niveau supérieur ainsi que celui de l'instance (ou des instances).

-o

Affiche toutes les options ainsi que leurs valeurs. Si elles commencent par « no », alors l'option est désactivée.
