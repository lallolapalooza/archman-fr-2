TRUST(1) Commandes utilisateur TRUST(1)

NOM

trust - Outil pour opérer sur le magasin de politiques de confiance

SYNTAXE

trust list

trust extract --filter=<quoi> --format=<type> /chemin/vers/destination

trust anchor /chemin/vers/certificat.crt

trust dump

trust check-format /chemin/vers/fichier.p11-kit...

DESCRIPTION

trust est un outil en ligne de commande pour examiner et modifier le magasin de politiques de confiance partagé.

Voir les différentes sous-commandes ci-dessous. Les options globales suivantes peuvent être utilisées :

-v, --verbose

Exécuter en mode verbeux avec sortie de débogage.

-q, --quiet

Exécuter en mode silencieux sans messages d'avertissement ou d'échec.

LIST

Lister les éléments du magasin de politiques de confiance.

$ trust list

Lister les informations sur les différents éléments du magasin de politiques de confiance. Chaque élément est listé avec son URI PKCS#11 et des informations descriptives.

Vous pouvez spécifier les options suivantes pour contrôler ce qui est listé.

--filter=<quoi>

Spécifie quels certificats extraire. Vous pouvez spécifier les valeurs suivantes :

ca-anchors

Ancres de certificats

trust-policy

Ancres et liste noire (par défaut)

blocklist

Certificats non fiables

certificates

Tous les certificats

pkcs11:object=xx

Un URI PKCS#11 pour filtrer

Si un format de sortie est choisi qui ne peut pas prendre en charge le type spécifié par le filtre, un message sera affiché.

Aucun des formats disponibles ne prend en charge le stockage des entrées de liste noire qui ne contiennent pas un certificat complet. Ainsi, tous les certificats rendus non fiables par leur émetteur et leur numéro de série seuls ne sont pas inclus dans la liste noire extraite.

--purpose=<usage>

Limiter aux certificats utilisables pour l'usage donné. Vous pouvez spécifier l'une des valeurs suivantes :

server-auth

Pour authentifier les serveurs

client-auth

Pour authentifier les clients

email

Pour la protection des e-mails

code-signing

Pour la signature de code authentifiée

1.2.3.4.5...

Un OID de but arbitraire

ANCRE

Stocker ou supprimer des ancres de confiance.

$ trust anchor /chemin/vers/certificat.crt
$ trust anchor --remove /chemin/vers/certificat.crt
$ trust anchor --remove "pkcs11:id=%AA%BB%CC%DD%EE;type=cert"

Stocker ou supprimer des ancres de confiance dans le magasin de politiques de confiance. Ce sont généralement des autorités de certification racines.

Spécifiez soit les opérations --store soit --remove. Si aucune opération n'est spécifiée, --store est supposé.

Lors du stockage, un ou plusieurs fichiers de certificats sont attendus sur la ligne de commande. Ils sont stockés comme ancres, sauf s'ils sont déjà présents.

Lors de la suppression d'une ancre, spécifiez soit des fichiers de certificats, soit des URI PKCS#11 sur la ligne de commande. Les ancres correspondantes seront supprimées.

Il est possible que cette commande doive être exécutée en tant que root pour modifier le magasin de politiques de confiance du système, si aucun magasin spécifique à l'utilisateur n'est disponible.

Vous pouvez spécifier les options suivantes.

--remove

Supprimer une ou plusieurs ancres du magasin de politiques de confiance. Spécifiez des fichiers de certificats ou des URI PKCS#11 sur la ligne de commande.

--store

Stocker une ou plusieurs ancres dans le magasin de politiques de confiance. Spécifiez des fichiers de certificats sur la ligne de commande.

EXTRACT

Extraire la politique de confiance du magasin de politiques de confiance partagé.

$ trust extract --format=x509-directory --filter=ca-anchors /chemin/vers/repertoire

Vous pouvez spécifier les options suivantes pour contrôler ce qui est extrait. Les arguments --filter et --format doivent être spécifiés. Par défaut, cette commande n'écrasera pas le fichier ou le répertoire de destination.

--comment

Ajouter des commentaires d'identification aux fichiers de paquets PEM avant chaque certificat.

--filter=<quoi>

Spécifie quels certificats extraire. Vous pouvez spécifier les valeurs suivantes :

ca-anchors

Ancres de certificats (par défaut)

trust-policy

Ancres et liste noire

blocklist

Certificats non fiables

certificates

Tous les certificats

pkcs11:object=xx

Un URI PKCS#11

Si un format de sortie est choisi qui ne peut pas prendre en charge le type spécifié par le filtre, un message sera affiché.

Aucun des formats disponibles ne prend en charge le stockage des entrées de liste noire qui ne contiennent pas un certificat complet. Ainsi, tous les certificats rendus non fiables par leur émetteur et leur numéro de série seuls ne sont pas inclus dans la liste noire extraite.

--format=<type>

Le format du fichier ou du répertoire de destination. Vous pouvez spécifier l'une des valeurs suivantes :

x509-file

Fichier de certificat DER X.509

x509-directory

Répertoire de certificats X.509

pem-bundle

Fichier contenant un ou plusieurs blocs de certificats PEM

pem-directory

Répertoire de fichiers PEM contenant chacun un certificat

pem-directory-hash

Répertoire de fichiers PEM contenant chacun un certificat, avec des liens symboliques de hachage

openssl-bundle

Paquet de certificats PEM spécifique à OpenSSL

openssl-directory

Répertoire de fichiers PEM spécifiques à OpenSSL

java-cacerts

Paquet de certificats du keystore Java 'cacerts'

--overwrite

Écraser le fichier ou le répertoire de sortie.

--purpose=<usage>

Limiter aux certificats utilisables pour l'usage donné. Vous pouvez spécifier l'une des valeurs suivantes :

server-auth

Pour authentifier les serveurs

client-auth

Pour authentifier les clients

email

Pour la protection des e-mails

code-signing

Pour la signature de code authentifiée

1.2.3.4.5...

Un OID de but arbitraire

EXTRACT COMPAT

Extraire des paquets de certificats de confiance de compatibilité.

$ trust extract-compat

OpenSSL, Java et certaines versions de GnuTLS ne peuvent pas actuellement lire les informations de confiance directement à partir du magasin de politiques de confiance. Cette commande extrait les informations de confiance telles que les ancres de certificats pour être utilisées par ces bibliothèques.

Ce que fait cette commande et où elle extrait les fichiers est spécifique à la distribution ou au site. Les emballeurs ou les administrateurs sont censés personnaliser cette commande.

DUMP

Exporter les éléments PKCS#11 dans les différents jetons.

$ trust dump

Exporter les informations sur les différents éléments PKCS#11 dans les jetons. Chaque élément est exporté avec son URI PKCS#11 et des informations au format de persistance .p11-kit.

Vous pouvez spécifier les options suivantes pour contrôler ce qui est exporté.

--filter=<quoi>

Spécifie quels certificats extraire. Vous pouvez spécifier les valeurs suivantes :

all

Tous les objets. C'est le défaut

pkcs11:object=xx

Un URI PKCS#11 pour filtrer

CHECK-FORMAT

Vérifier que le format des fichiers spécifiés est valide.

$ trust check-format /chemin/vers/fichier.p11-kit
$ trust check-format /chemin/vers/repertoire

Vérifier que le format des fichiers spécifiés est valide. Si un répertoire est spécifié, tous les fichiers du répertoire sont vérifiés.

Vous pouvez spécifier les options suivantes pour contrôler ce qui est vérifié.

--filter=<type>

Le type de fichier à vérifier. Vous pouvez spécifier l'une des valeurs suivantes :

p11-kit

Fichiers de configuration p11-kit

all

Tous les types de fichiers (par défaut)

VÉRIFIER LE FORMAT

Vérifie le format des fichiers .p11-kit.

$ trust check-format /chemin/vers/fichier.p11-kit...

Les administrateurs ont parfois besoin d'écrire un fichier .p11-kit personnalisé pour modifier les informations de confiance. Il s'agit d'un processus sujet aux erreurs car le format du fichier est principalement destiné au traitement par machine. Les administrateurs peuvent utiliser cette commande pour vérifier si un fichier a un format .p11-kit correct.

Cette commande prend un nombre arbitraire de fichiers en entrée. Chaque fichier est ensuite analysé et toute divergence avec le format .p11-kit est signalée sur la sortie d'erreur standard. Après le traitement du fichier, un résultat de vérification est imprimé sur la sortie standard.
