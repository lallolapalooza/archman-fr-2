NOM

trace-cmd split - diviser un fichier trace.dat en fichiers plus petits

SYNTAXE

trace-cmd split [OPTIONS] [heure-début [heure-fin]]

DESCRIPTION

La commande trace-cmd split est utilisée pour diviser un fichier trace.dat en petits fichiers. heure-début spécifie où le nouveau fichier commencera. Utiliser trace-cmd-report(1) et copier l'horodatage donné à un événement particulier peut être utilisé comme entrée pour heure-début ou heure-fin. La division s'arrêtera de créer des fichiers lorsqu'elle atteindra un événement après heure-fin. Si seule l'heure de fin est nécessaire, utilisez 0.0 comme heure de début.

Si heure-début est omis, la division commencera au début du fichier. Si heure-fin est omis, la division continuera jusqu'à la fin à moins qu'elle ne respecte l'une des exigences spécifiées par les options.

OPTIONS

-i fichier

Si cette option n'est pas spécifiée, la commande split recherchera le fichier nommé trace.dat. Cette option permet la lecture d'un fichier autre que trace.dat.

-o fichier

Par défaut, la commande split utilisera le nom du fichier d'entrée comme base pour écrire les fichiers divisés. Le fichier de sortie sera le fichier d'entrée avec un '.#\' joint à la fin : trace.dat.1, trace.dat.2, etc. 
Cette option modifiera le nom du fichier de base utilisé.
-o fichier créera fichier.1, fichier.2, etc.

-s secondes

Ceci spécifie combien de secondes doivent être enregistrées avant que le nouveau fichier ne s'arrête.

-m millisecondes

Ceci spécifie combien de millisecondes doivent être enregistrées avant que le nouveau fichier ne s'arrête.

-u microsecondes

Ceci spécifie combien de microsecondes doivent être enregistrées avant que le nouveau fichier ne s'arrête.

-e événements

Ceci spécifie combien d'événements doivent être enregistrés avant que le nouveau fichier ne s'arrête.

-p pages

Ceci spécifie le nombre de pages qui doivent être enregistrées avant que le nouveau fichier ne s'arrête. 
Note : une seule des options *-p*, *-e*, *-u*, *-m*, *-s* peut être spécifiée à la fois.
Si *-p* est spécifié, alors *-c* est automatiquement défini.

-r

Cette option fait que la division se répète jusqu'à ce que l'heure de fin soit atteinte (ou la fin de l'entrée si l'heure de fin n'est pas spécifiée). 
trace-cmd split -r -e 10000
Ceci divisera trace.dat en plusieurs fichiers plus petits, chacun contenant au
maximum 10 000 événements.

-c

Cette option fait que la division ci-dessus se fait par CPU. 
trace-cmd split -c -p 10
Ceci créera un fichier contenant 10 pages par CPU de l'entrée.

-C cpu

Cette option divisera pour un seul CPU. Seuls les événements du CPU nommé seront extraits du fichier. 
trace-cmd split -C 1
Ceci séparera tous les événements du CPU 1 dans le fichier.

--top

Ceci permet de conserver le tampon supérieur. Le tampon supérieur peut être renommé en utilisant l'option -b. 
trace-cmd split --top
Ceci ne conservera que le tampon supérieur.
trace-cmd split --top -b ancien_top
Ceci ne conservera que le tampon supérieur et le renommera 'ancien_top'.

-B tampon

Ceci permet de conserver le tampon sélectionné. Un tampon peut être promu au tampon supérieur en utilisant l'option -t. 
trace-cmd split -B timer -B sched
Ceci conservera les tampons 'timer' et 'sched'.
trace-cmd split -B timer -t -B sched
Ceci conservera les tampons 'timer' et 'sched', avec les événements
du tampon 'timer' promus à l'instance supérieure.
