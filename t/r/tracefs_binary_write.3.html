tracefs_binary_write(3)

Paquet: libtracefs

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_binary_init, tracefs_binary_close, tracefs_binary_write - Ouvrir, fermer et écrire des données binaires dans le tampon de trace.

SYNOPSIS

#include <tracefs.h>
int tracefs_binary_init(struct tracefs_instance *instance);
int tracefs_binary_write(struct tracefs_instance *instance, void *data, int len);
void tracefs_binary_close(struct tracefs_instance *instance);

DESCRIPTION

Ensemble de fonctions pour écrire des données binaires dans le tampon de trace. Voir Documentation/trace/ftrace.rst dans l'arborescence du noyau Linux pour plus d'informations sur l'écriture de données depuis l'espace utilisateur dans le tampon de trace. Toutes ces API ont instance comme premier argument. Si NULL est passé comme instance, l'instance de trace principale est utilisée.

La fonction tracefs_binary_init() initialise la bibliothèque pour écrire dans le tampon de trace de l'instance sélectionnée instance. Il n'est pas obligatoire d'appeler cette API avant d'écrire des données, tracefs_binary_write() l'appellera automatiquement si la bibliothèque n'est pas encore initialisée. Mais appeler tracefs_binary_init() à l'avance accélérera l'écriture.

La fonction tracefs_binary_write() écrit des données binaires dans le tampon de trace de l'instance sélectionnée instance. data pointe vers les données d'une longueur len, qui vont être écrites dans le tampon de trace.

La fonction tracefs_binary_close() ferme les ressources utilisées par la bibliothèque pour écrire dans le tampon de trace de l'instance sélectionnée.

VALEUR DE RETOUR

Les fonctions tracefs_binary_init() et tracefs_binary_write() retournent 0 si l'opération réussit, ou -1 en cas d'erreur.

EXEMPLE

#include <tracefs.h>
if (tracefs_binary_init(NULL) < 0) {
 /* Échec de l'initialisation de la bibliothèque pour écrire dans le tampon de trace de l'instance de trace principale */
}
unsigned int data = 0xdeadbeef;
        if (tracefs_binary_write(NULL, &data, sizeof(data)) < 0) {
                /* Échec de l'écriture dans le tampon de trace */
        }
tracefs_binary_close();
