Paquet: trace-cmd

LIBTRACECMD(3) Manuel libtracefs LIBTRACECMD(3)

NOM

tracecmd_open, tracecmd_open_fd, tracecmd_open_head, tracecmd_init_data, tracecmd_close, tracecmd_set_private, tracecmd_get_private - Ouvrir et fermer un fichier de trace.

SYNTAXE

#include <trace-cmd.h>
struct tracecmd_input *tracecmd_open(const char *file, int flags);
struct tracecmd_input *tracecmd_open_fd(int fd, int flags);
struct tracecmd_input *tracecmd_open_head(const char *file, int flags);
int tracecmd_init_data(struct tracecmd_input *handle);
void tracecmd_close(struct tracecmd_input *handle);
void tracecmd_set_private(struct tracecmd_input *handle, void *data);
void *tracecmd_get_private(struct tracecmd_input *handle);

DESCRIPTION

Cet ensemble d'API peut être utilisé pour ouvrir et fermer un fichier de trace enregistré par trace-cmd(1) et contenant des informations de traçage de ftrace, le traçeur officiel du noyau Linux. Le fichier ouvert est représenté par une structure tracecmd_input, toutes les autres API de la bibliothèque qui fonctionnent avec le fichier nécessitent un pointeur vers cette structure. Les API pour ouvrir un fichier de trace ont un paramètre d'entrée flag, qui contrôle comment le fichier sera ouvert et analysé. Le flag est une combinaison de ces options :

TRACECMD_FL_LOAD_NO_PLUGINS - Ne pas charger de plugins
TRACECMD_FL_LOAD_NO_SYSTEM_PLUGINS - Ne pas charger les plugins système, charger uniquement les plugins "locaux"
                                       depuis le répertoire personnel de l'utilisateur.

La fonction tracecmd_open() ouvre un fichier de trace spécifié par file, analyse les métadonnées de l'en-tête à partir du fichier, alloue et initialise une structure de gestionnaire tracecmd_input représentant le fichier. Elle initialise également le gestionnaire pour la lecture des données de trace depuis le fichier. Le gestionnaire retourné est prêt à être utilisé avec les API tracecmd_read_.

La fonction tracecmd_open_fd() fait la même chose que tracecmd_open(), mais travaille avec un descripteur de fichier vers un fichier de trace, ouvert en lecture.

La fonction tracecmd_open_head() est identique à tracecmd_open(), mais n'initialise pas le gestionnaire pour la lecture des données de trace. Elle lit et analyse uniquement les métadonnées de l'en-tête. La fonction tracecmd_init_data() doit être utilisée avant d'utiliser les API tracecmd_read_.

La fonction tracecmd_init_data() initialise un handle, alloué avec tracecmd_open_head(), pour la lecture des données de trace du fichier qui y est associé. Cette API doit être appelée avant toute des API tracecmd_read_.

La fonction tracecmd_close() libère un handle, pointeur vers la structure tracecmd_input, précédemment alloué avec les API tracecmd_open(), tracecmd_open_fd() ou tracecmd_open_head().

La fonction tracecmd_set_private() permet d'ajouter des données spécifiques au handle qui pourront être récupérées plus tard.

La fonction tracecmd_get_private() récupérera les données définies par tracecmd_set_private() pour le handle donné.

VALEUR DE RETOUR

Les fonctions tracecmd_open(), tracecmd_open_fd() et tracecmd_open_head() retournent un pointeur vers la structure tracecmd_input ou NULL en cas d'erreur. La structure retournée doit être libérée avec tracecmd_close(). Notez que si tracecmd_open_fd() est utilisé pour allouer un gestionnaire tracecmd_input, lorsque tracecmd_close() est appelé pour le fermer, ce descripteur de fichier sera également fermé.

La fonction tracecmd_init_data() retourne -1 en cas d'erreur ou 0 sinon.

La fonction tracecmd_get_private() retourne les données définies par tracecmd_set_private().

EXEMPLE

Il existe deux modes d'utilisation différents pour ouvrir et lire les données de trace
depuis un fichier de trace, qui peuvent être utilisés en fonction du cas d'utilisation.
1. Ouvrir et initialiser le fichier de trace en une seule étape :
#include <stdlib.h>
#include <trace-cmd.h>
static int print_events(struct tracecmd_input *handle, struct tep_record *record, int cpu, void *data)
{
        static struct trace_seq seq;
        struct tep_handle *tep = tracecmd_get_tep(handle);
        const char *file = tracecmd_get_private(handle);
        if (!seq.buffer)
                trace_seq_init(&seq);
        trace_seq_reset(&seq);
        trace_seq_printf(&seq, "%s: ", file);
        trace_seq_printf(&seq, "%6.1000d [%03d] %s-%d %s: %s\n",
                        TEP_PRINT_TIME, TEP_PRINT_CPU, TEP_PRINT_COMM, TEP_PRINT_PID,
                        TEP_PRINT_NAME, TEP_PRINT_INFO);
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
        return 0;
}
int main(int argc, char **argv)
{
        struct tracecmd_input *handle;
        if (argc < 2) {
                printf("usage: %s trace.dat\n", argv[0]);
                exit(-1);
        }
        handle = tracecmd_open(argv[i], 0);
        if (!handle)
                exit(-1);
        tracecmd_set_private(handle, argv[i]);
        tracecmd_iterate_events(handle, NULL, 0, print_events, NULL);
        tracecmd_close(handle);
}
2. Ouvrir et initialiser le fichier de trace en deux étapes. Cela permet d'effectuer
certains traitements basés sur les métadonnées, lues depuis le fichier, avant d'initialiser
les données de trace pour la lecture. Un exemple d'un tel cas d'utilisation est l'ouverture de plusieurs
fichiers de trace enregistrés dans la même session de trace. Dans ce cas, les horodatages de tous les
événements de trace doivent être ajustés en fonction des informations provenant des métadonnées du
fichier et avant la lecture des données de trace.
#include <trace-cmd.h>
...
struct tracecmd_input *handle = tracecmd_open_head("trace.dat");
        if (!handle) {
                /* Échec de l'ouverture du fichier trace.dat */
        }
...
        /* effectuer un traitement, avant d'initialiser les données de trace pour la lecture */
...
        if (tracecmd_init_data(handle) < 0) {
                /* Échec de l'initialisation du handle pour la lecture des données de trace */
        }
...
        /* Lire les données de traçage depuis le fichier, en utilisant le handle */
...
        tracecmd_close(handle);
...
