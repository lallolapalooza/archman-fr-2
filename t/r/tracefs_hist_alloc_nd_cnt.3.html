tracefs_hist_alloc_nd_cnt(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_hist_alloc, tracefs_hist_alloc_2d, tracefs_hist_alloc_nd, tracefs_hist_alloc_nd_cnt, tracefs_hist_free, tracefs_hist_add_key, tracefs_hist_add_key_cnt, tracefs_hist_add_value - Créer et détruire des histogrammes d'événements

SYNOPSIS

#include <tracefs.h>
enum tracefs_hist_key_type {
        TRACEFS_HIST_KEY_NORMAL = 0,
        TRACEFS_HIST_KEY_HEX,
        TRACEFS_HIST_KEY_SYM,
        TRACEFS_HIST_KEY_SYM_OFFSET,
        TRACEFS_HIST_KEY_SYSCALL,
        TRACEFS_HIST_KEY_EXECNAME,
        TRACEFS_HIST_KEY_LOG,
        TRACEFS_HIST_KEY_USECS,
        TRACEFS_HIST_KEY_MAX
};
struct tracefs_hist_axis {
        const char *key;
        enum tracefs_hist_key_type type;
};
struct tracefs_hist *tracefs_hist_alloc(struct tracefs_tep * tep,
                        const char *system, const char *event,
                        const char *key, enum tracefs_hist_key_type type);
struct tracefs_hist *tracefs_hist_alloc_2d(struct tracefs_tep * tep,
                        const char *system, const char *event,
                        const char *key1, enum tracefs_hist_key_type type1,
                        const char *key2, enum tracefs_hist_key_type type2));
struct tracefs_hist *tracefs_hist_alloc_nd(struct tracefs_tep * tep,
                        const char *system, const char *event,
                        struct tracefs_hist_axis *axes);
struct tracefs_hist *tracefs_hist_alloc_nd_cnt(struct tep_handle *tep,
                          const char *system, const char *event_name,
                          struct tracefs_hist_axis_cnt *axes);
void tracefs_hist_free(struct tracefs_hist *hist);
int tracefs_hist_add_key(struct tracefs_hist *hist, const char *key,
                         enum tracefs_hist_key_type type);
int tracefs_hist_add_key_cnt(struct tracefs_hist *hist, const char *key,
                         enum tracefs_hist_key_type type, int cnt);
int tracefs_hist_add_value(struct tracefs_hist *hist, const char *value);

DESCRIPTION

Les histogrammes d'événements sont créés par le fichier de déclenchement dans le répertoire de l'événement. La syntaxe peut être complexe et difficile à écrire correctement. Cette API gère la syntaxe et facilite la création et l'interaction avec les histogrammes d'événements. Voir https://www.kernel.org/doc/html/latest/trace/histogram.html pour plus d'informations.

tracefs_hist_alloc() alloue un descripteur « struct tracefs_hist » d'un histogramme unidimensionnel et retourne son adresse. Ce descripteur doit être libéré par tracefs_hist_free(). Le paramètre tep est un descripteur d'événement de trace (voir tracefs_local_events(3)), qui contient le system et l'event auxquels l'histogramme sera attaché. Le system est le système ou le groupe de l'événement. L'event est l'événement auquel l'histogramme sera attaché. La key est un champ de l'événement qui sera utilisé comme clé (dimension) de l'histogramme. Le type est le type de la key. Voir TYPES DE CLÉS ci-dessous.

tracefs_hist_alloc_2d() alloue un descripteur « struct tracefs_hist » d'un histogramme bidimensionnel et retourne son adresse. Ce descripteur doit être libéré par tracefs_hist_free(). Le paramètre tep est un descripteur d'événement de trace (voir tracefs_local_events(3)), qui contient le system et l'event auxquels l'histogramme sera attaché. Le system est le système ou le groupe de l'événement. L'event est l'événement auquel l'histogramme sera attaché. La key1 est le premier champ de l'événement qui sera utilisé comme clé (dimension) de l'histogramme. Le type1 est le type de la key1. Voir TYPES DE CLÉS ci-dessous. La key2 est le deuxième champ de l'événement qui sera utilisé comme clé (dimension) de l'histogramme. Le type2 est le type de la key2. Voir TYPES DE CLÉS ci-dessous.

tracefs_hist_alloc_nd() alloue un descripteur « struct tracefs_hist » d'un histogramme N-dimensionnel et retourne son adresse. Ce descripteur doit être libéré par tracefs_hist_free(). Le paramètre tep est un descripteur d'événement de trace (voir tracefs_local_events(3)), qui contient le system et l'event auxquels l'histogramme sera attaché. Le system est le système ou le groupe de l'événement. L'event est l'événement auquel l'histogramme sera attaché. Les axes est un tableau de paires clé / type, définissant les dimensions de l'histogramme.

tracefs_hist_alloc_nd_cnt() initialisera un descripteur d'histogramme qui sera attaché au system/event. Cela initialise uniquement le descripteur avec les clés d'axes données comme primaires. Cela initialise uniquement le descripteur, cela ne démarre pas l'histogramme dans le noyau. La différence entre cela et tracefs_hist_alloc_nd() est que le paramètre axes est de type struct tracefs_hist_axis_cnt et non struct tracefs_hist_axis.

tracefs_hist_free() libère le descripteur tracefs_hist. Notez qu'il n'arrête ni ne désactive l'histogramme en cours d'exécution s'il a été démarré. tracefs_hist_destroy() doit être appelé pour ce faire.

tracefs_hist_add_key() ajoute une clé secondaire ou tertiaire à l'histogramme. La clé passée à tracefs_hist_alloc_nd() est la clé primaire de l'histogramme. La première fois que cette fonction est appelée, elle ajoutera une clé secondaire (ou un histogramme bidimensionnel). Si cette fonction est appelée à nouveau sur le même histogramme, elle ajoutera une clé tertiaire (ou un histogramme tridimensionnel). Le paramètre hist est le descripteur d'histogramme auquel ajouter la key. Le type est le type de clé à ajouter (Voir TYPES DE CLÉS ci-dessous).

tracefs_hist_add_key_cnt() est identique à tracefs_hist_add_key() à l'exception qu'elle permet d'ajouter un compteur pour le type donné. Actuellement, seul le type buckets nécessite un compteur. Lors de l'ajout d'une clé de type buckets, tracefs_hist_add_key() n'est pas suffisant, car le type buckets nécessite un compteur ou une taille de bucket. Utilisez tracefs_hist_add_key_cnt() lorsque vous spécifiez une clé décomposée en buckets, et passez la taille de ces buckets dans cnt.

tracefs_hist_add_value() ajoutera une valeur à enregistrer. Par défaut, la valeur est simplement le « hitcount », c'est-à-dire le nombre de fois qu'une instance de la clé de l'histogramme a été rencontrée. Le paramètre hist est le descripteur d'histogramme auquel ajouter la valeur. Le paramètre value est un champ de l'histogramme auquel ajouter lorsque qu'une instance de la clé est rencontrée.

TYPES DE CLÉS

tracefs_hist_alloc_nd() et tracefs_hist_add_key() ajoutent tous deux une clé et exigent que cette clé ait un type. Les types peuvent être :

TRACEFS_HIST_KEY_NORMAL ou zéro (0) pour ne pas modifier le type.

TRACEFS_HIST_KEY_HEX pour afficher la clé en hexadécimal.

TRACEFS_HIST_KEY_SYM pour afficher la clé comme un symbole du noyau (si trouvé). Si la clé est une adresse, ceci est utile car cela affichera les noms de fonctions au lieu d'un simple nombre.

TRACEFS_HIST_KEY_SYM_OFFSET similaire à TRACEFS_HIST_KEY_SYM mais inclura également le décalage de la fonction pour correspondre à l'adresse exacte.

TRACEFS_HIST_KEY_SYSCALL Si la clé est un « id » d'appel système (le numéro passé de l'espace utilisateur au noyau pour lui indiquer quel appel système il est en train d'effectuer), alors le nom de l'appel système sera affiché.

TRACEFS_HIST_KEY_EXECNAME Si « common_pid » est la clé (le pid de la tâche en cours d'exécution), au lieu d'afficher le numéro, afficher le nom de la tâche en cours d'exécution.

TRACEFS_HIST_KEY_LOG affichera la clé sur une échelle logarithmique binaire.

TRACEFS_HIST_KEY_USECS à utiliser avec « common_timestamp » ou TRACEFS_HIST_TIMESTAMP, auquel cas il affichera l'horodatage en microsecondes au lieu de nanosecondes.

VALEUR DE RETOUR

tracefs_hist_alloc_nd() retourne un descripteur d'histogramme alloué qui doit être libéré par tracefs_hist_free() ou NULL en cas d'erreur.

Toutes les autres fonctions retournent zéro en cas de succès et -1 en cas d'erreur.

Si tracefs_hist_start() retourne une erreur, un message peut être affiché dans le noyau et récupéré par tracefs_error_last().

Voir également tracefs_hist_start(3), tracefs_hist_destroy(3), tracefs_error_last(3).

EXEMPLE

#include <stdlib.h>
#include <ctype.h>
#include <unistd.h>
#include <tracefs.h>
enum commands {
        START,
        PAUSE,
        CONT,
        RESET,
        DELETE,
        SHOW,
};
static void parse_system_event(char *group, char **system, char **event)
{
        *system = strtok(group, "/");
        *event = strtok(NULL, "/");
        if (!*event) {
                *event = *system;
                *system = NULL;
        }
}
static int parse_keys(char *keys, struct tracefs_hist_axis_cnt **axes)
{
        char *sav = NULL;
        char *key;
        int cnt = 0;
        for (key = strtok_r(keys, ",", &sav); key; key = strtok_r(NULL, ",", &sav)) {
                struct tracefs_hist_axis_cnt *ax;
                char *att;
                ax = realloc(*axes, sizeof(*ax) * (cnt + 2));
                if (!ax) {
                        perror("Échec de l'allocation des axes");
                        exit(-1);
                }
                ax[cnt].key = key;
                ax[cnt].type = 0;
                ax[cnt + 1].key = NULL;
                ax[cnt + 1].type = 0;
                *axes = ax;
                att = strchr(key, '.');
                if (att) {
                        *att++ = '\0';
                        if (strcmp(att, "hex") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_HEX;
                        else if (strcmp(att, "sym") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM;
                        else if (strcmp(att, "sym_offset") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM_OFFSET;
                        else if (strcmp(att, "syscall") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYSCALL;
                        else if (strcmp(att, "exec") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_EXECNAME;
                        else if (strcmp(att, "log") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_LOG;
                        else if (strcmp(att, "usecs") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_USECS;
                        else if (strncmp(att, "buckets", 7) == 0) {
                                if (att[7] != '=' && !isdigit(att[8])) {
                                        fprintf(stderr, "Le type de clé 'buckets' nécessite '=<taille>'\n");
                                        exit(-1);
                                }
                                ax[cnt].type = TRACEFS_HIST_KEY_BUCKETS;
                                ax[cnt].cnt = atoi(&att[8]);
                        } else {
                                fprintf(stderr, "Attribut indéfini '%s'\n", att);
                                fprintf(stderr,"  Attributs acceptables:\n");
                                fprintf(stderr,"    hex, sym, sym_offset, syscall, exe, log, usecs\n");
                                exit(-1);
                        }
                }
                cnt++;
        }
        return cnt;
}
static void process_hist(enum commands cmd, const char *instance_name,
                         char *group, char *keys, char *vals, char *sort,
                         char *ascend, char *desc)
{
        struct tracefs_instance *instance = NULL;
        struct tracefs_hist *hist;
        struct tep_handle *tep;
        struct tracefs_hist_axis_cnt *axes = NULL;
        char *system;
        char *event;
        char *sav;
        char *val;
        int ret;
        int cnt;
        if (instance_name) {
                instance = tracefs_instance_create(instance_name);
                if (!instance) {
                        fprintf(stderr, "Échec de la création de l'instance\n");
                        exit(-1);
                }
        }
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("Impossible de lire les événements");
                exit(-1);
        }
        parse_system_event(group, &system, &event);
        if (cmd == SHOW) {
                char *content;
                content = tracefs_event_file_read(instance, system, event,
                                                  "hist", NULL);
                if (!content) {
                        perror("Lecture du fichier hist");
                        exit(-1);
                }
                printf("%s\n", content);
                free(content);
                return;
        }
        if (!keys) {
                fprintf(stderr, "La commande nécessite l'option -k\n");
                exit(-1);
        }
        cnt = parse_keys(keys, &axes);
        if (!cnt) {
                fprintf(stderr, "Pas de clés ??\n");
                exit(-1);
        }
        /* les buckets nécessitent la fonction nd_cnt */
        switch (cnt) {
        case 2:
                if (axes[1].type == TRACEFS_HIST_KEY_BUCKETS)
                        cnt = -1;
                /* tomber en cascade */
        case 1:
                if (axes[0].type == TRACEFS_HIST_KEY_BUCKETS)
                        cnt = -1;
        }
        /* Afficher des exemples de hist1d et hist2d */
        switch (cnt) {
        case 1:
                hist = tracefs_hist_alloc(tep, system, event,
                                          axes[0].key, axes[0].type);
                break;
        case 2:
                hist = tracefs_hist_alloc_2d(tep, system, event,
                                             axes[0].key, axes[0].type,
                                             axes[1].key, axes[1].type);
                break;
        default:
                /* Vraiment, 1 et 2 pourraient aussi utiliser ceci */
                hist = tracefs_hist_alloc_nd_cnt(tep, system, event, axes);
        }
        if (!hist) {
                fprintf(stderr, "Échec de la création de hist\n");
                exit(-1);
        }
        if (vals) {
                sav = NULL;
                for (val = strtok_r(vals, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_value(hist, val);
                        if (ret) {
                                fprintf(stderr, "Échec de l'ajout de la valeur %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (sort) {
                sav = NULL;
                for (val = strtok_r(sort, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_sort_key(hist, val);
                        if (ret) {
                                fprintf(stderr, "Échec de l'ajout de la clé/valeur de tri %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (ascend) {
                sav = NULL;
                for (val = strtok_r(ascend, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_ASCENDING);
                        if (ret) {
                                fprintf(stderr, "Échec de l'ajout de la clé/valeur ascendante %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (desc) {
                sav = NULL;
                for (val = strtok_r(desc, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_DESCENDING);
                        if (ret) {
                                fprintf(stderr, "Échec de l'ajout de la clé/valeur descendante %s\n", val);
                                exit(-1);
                        }
                }
        }
        tracefs_error_clear(instance);
        switch (cmd) {
        case START:
                ret = tracefs_hist_start(instance, hist);
                if (ret) {
                        char *err = tracefs_error_last(instance);
                        if (err)
                                fprintf(stderr, "\n%s\n", err);
                }
                break;
        case PAUSE:
                ret = tracefs_hist_pause(instance, hist);
                break;
        case CONT:
                ret = tracefs_hist_continue(instance, hist);
                break;
        case RESET:
                ret = tracefs_hist_reset(instance, hist);
                break;
        case DELETE:
                ret = tracefs_hist_destroy(instance, hist);
                break;
        case SHOW:
                /* SHOW a déjà été fait */
                break;
        }
        if (ret)
                fprintf(stderr, "Échec : commande\n");
        exit(ret);
}
int main (int argc, char **argv, char **env)
{
        enum commands cmd;
        char *instance = NULL;
        char *cmd_str;
        char *event = NULL;
        char *keys = NULL;
        char *vals = NULL;
        char *sort = NULL;
        char *desc = NULL;
        char *ascend = NULL;
        if (argc < 2) {
                fprintf(stderr, "usage: %s commande [-B instance][-e [system/]événement][-k clés][-v valeurs][-s tri]\n", argv[0]);
                fprintf(stderr, "      [-a ascendant][-d descendant]\n");
                exit(-1);
        }
        cmd_str = argv[1];
        if (!strcmp(cmd_str, "start"))
                cmd = START;
        else if (!strcmp(cmd_str, "pause"))
                cmd = PAUSE;
        else if (!strcmp(cmd_str, "cont"))
                cmd = CONT;
        else if (!strcmp(cmd_str, "reset"))
                cmd = RESET;
        else if (!strcmp(cmd_str, "delete"))
                cmd = DELETE;
        else if (!strcmp(cmd_str, "show"))
                cmd = SHOW;
        else {
                fprintf(stderr, "Commande inconnue %s\n", cmd_str);
                exit(-1);
        }
        for (;;) {
                int c;
                c = getopt(argc - 1, argv + 1, "e:k:v:B:s:d:a:");
                if (c == -1)
                        break;
                switch (c) {
                case 'e':
                        event = optarg;
                        break;
                case 'k':
                        keys = optarg;
                        break;
                case 'v':
                        vals = optarg;
                        break;
                case 'B':
                        instance = optarg;
                        break;
                case 's':
                        sort = optarg;
                        break;
                case 'd':
                        desc = optarg;
                        break;
                case 'a':
                        ascend = optarg;
                        break;
                }
        }
        if (!event) {
                event = "kmem/kmalloc";
                if (!keys)
                        keys = "call_site.sym,bytes_req";
                if (!vals)
                        vals = "bytes_alloc";
                if (!sort)
                        sort = "bytes_req,bytes_alloc";
                if (!desc)
                        desc = "bytes_alloc";
        }
        process_hist(cmd, instance, event, keys, vals, sort, ascend, desc);
}

NOM

tracefs_hist_alloc_nd_cnt, tracefs_hist_alloc_nd_cnt_per_cpu — allouer un nouveau compteur de nombres de différents types pour l'historique de trace

SYNTAXIS

#include <tracefs.h>
struct tracefs_hist_entry *tracefs_hist_alloc_nd_cnt(struct tracefs_hist *hist,
    const char *name, unsigned int type, unsigned int size);
struct tracefs_hist_entry *tracefs_hist_alloc_nd_cnt_per_cpu(struct tracefs_hist *hist,
    const char *name, unsigned int type, unsigned int size);

DESCRIPTION

Les fonctions tracefs_hist_alloc_nd_cnt et tracefs_hist_alloc_nd_cnt_per_cpu allouent un nouveau compteur de nombres de différents types (ND - Number of Different) pour un historique de trace hist.

Le type de données du compteur est défini par type. Les types disponibles sont définis dans <tracefs.h>.

TRACEFS_HIST_ND_TYPE_STRING
Les chaînes de caractères sont collectées.
TRACEFS_HIST_ND_TYPE_UINT8
Les entiers non signés de 8 bits sont collectés.
TRACEFS_HIST_ND_TYPE_UINT16
Les entiers non signés de 16 bits sont collectés.
TRACEFS_HIST_ND_TYPE_UINT32
Les entiers non signés de 32 bits sont collectés.
TRACEFS_HIST_ND_TYPE_UINT64
Les entiers non signés de 64 bits sont collectés.
TRACEFS_HIST_ND_TYPE_SINT8
Les entiers signés de 8 bits sont collectés.
TRACEFS_HIST_ND_TYPE_SINT16
Les entiers signés de 16 bits sont collectés.
TRACEFS_HIST_ND_TYPE_SINT32
Les entiers signés de 32 bits sont collectés.
TRACEFS_HIST_ND_TYPE_SINT64
Les entiers signés de 64 bits sont collectés.

La taille des données à collecter est définie par size. Si type est TRACEFS_HIST_ND_TYPE_STRING, size spécifie la taille maximale de la chaîne de caractères (y compris le caractère nul final).

tracefs_hist_alloc_nd_cnt_per_cpu crée un compteur distinct pour chaque CPU.

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient un pointeur vers la structure struct tracefs_hist_entry nouvellement créée. En cas d'échec, elles renvoient NULL.

EXEMPLE

Pour allouer un compteur de chaînes de caractères appelé "nom_chaine" avec une taille maximale de 32 octets :

struct tracefs_hist_entry *entry;
entry = tracefs_hist_alloc_nd_cnt(hist, "nom_chaine",
                                TRACEFS_HIST_ND_TYPE_STRING, 32);
if (!entry) {
    /* Gérer l'erreur */
}

Pour allouer un compteur d'entiers non signés de 64 bits appelé "mon_compteur" :

struct tracefs_hist_entry *entry;
entry = tracefs_hist_alloc_nd_cnt(hist, "mon_compteur",
                                TRACEFS_HIST_ND_TYPE_UINT64, 0);
if (!entry) {
    /* Gérer l'erreur */
}
