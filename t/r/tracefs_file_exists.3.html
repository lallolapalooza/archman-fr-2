NOM

tracefs_file_exists, tracefs_dir_exists, tracefs_instance_get_file, tracefs_instance_get_dir - Travailler avec des fichiers et répertoires dans les instances de traçage.

SYNTAXE

#include <tracefs.h>
bool tracefs_file_exists(struct tracefs_instance *instance, char *name);
bool tracefs_dir_exists(struct tracefs_instance *instance, char *name);
char *tracefs_instance_get_file(struct tracefs_instance *instance, const char *file);
char *tracefs_instance_get_dir(struct tracefs_instance *instance);

DESCRIPTION

Cet ensemble d'API peut être utilisé pour travailler avec des fichiers de traçage dans toutes les instances de traçage. Chacune de ces API prend un argument instance, qui peut être NULL pour agir sur l'instance de niveau supérieur. Sinon, elle agit sur une instance créée avec tracefs_insance_create(3)

La fonction tracefs_file_exists() vérifie si un fichier nommé name existe dans l'instance instance.

La fonction tracefs_dir_exists() vérifie si un répertoire nommé name existe dans l'instance instance.

La fonction tracefs_instance_get_file() renvoie le chemin complet du fichier nommé file dans l'instance instance. Notez qu'elle ne vérifie pas si le fichier existe dans l'instance.

La fonction tracefs_instance_get_dir() renvoie le chemin complet du répertoire nommé name dans l'instance instance. Notez qu'elle ne vérifie pas si le répertoire existe dans l'instance.

VALEUR DE RETOUR

Les fonctions tracefs_file_exists() et tracefs_dir_exists() renvoient true si le fichier / répertoire existe dans l'instance donnée ou false s'il n'existe pas.

Les fonctions tracefs_instance_get_file() et tracefs_instance_get_dir() renvoient une chaîne de caractères ou NULL en cas d'erreur. La chaîne renvoyée doit être libérée avec tracefs_put_tracing_file().

EXEMPLE

                }

                if (tracefs_instance_file_write(inst, "trace_clock", "global") != strlen("global")) {
                        /* Échec de la définition de l'horloge de traçage globale dans l'instance foo */
                        ...
                }
        } else {
                /* L'instance foo ne supporte pas l'horloge de traçage */
        }
        if (tracefs_dir_exists(inst,"options")) {
                /* L'instance foo supporte les options de traçage */
                char *path = tracefs_instance_get_file(inst, "options");

                        /* Erreur lors de l'obtention du chemin vers le répertoire options dans l'instance foo */

                if (res == 0) {
                        /* Le traçage est désactivé dans l'instance principale */
                } else if (res == 1) {
                        /* Le traçage est activé dans l'instance principale */
                } else {
                        /* État de traçage inconnu de l'instance principale */
                }
        } else {
                /* Échec de la lecture de l'entier depuis le fichier tracing_on */
        }
        ...
        int fd;
        fd = tracefs_instance_file_open(NULL, "tracing_on", O_WRONLY);
        if (fd >= 0) {
                /* Descripteur de fichier obtenu vers le fichier tracing_on de l'instance principale pour écriture */
                ...

tracefs — tracing filesystem library

NAME

tracefs_file_exists — check if a file exists in tracefs

SYNOPSIS

#include <tracefs.h>

int tracefs_file_exists(const char *path);

DESCRIPTION

The tracefs_file_exists() function checks if a file or directory named path exists within the mounted tracefs filesystem.

The path argument is a relative path from the root of the tracefs mount point. It can be a file name or a directory name.

This function is useful for checking the existence of specific tracefs files before attempting to read from or write to them.

RETURN VALUE

Returns 1 if the file or directory exists, 0 if it does not exist, and -1 on error (e.g., if tracefs is not mounted or if there is a permission issue).

EXAMPLES

#include <stdio.h>
#include <tracefs.h>

int main(void) {
    if (tracefs_file_exists("events/sched/sched_switch")) {
        printf("sched_switch event exists.\n");
    } else {
        printf("sched_switch event does not exist.\n");
    }

    if (tracefs_file_exists("nonexistent_file")) {
        printf("nonexistent_file exists.\n");
    } else {
        printf("nonexistent_file does not exist.\n");
    }

    return 0;
}

SEE ALSO

tracefs_enabled(3), tracefs_mountpoint(3), tracefs_get_event_format(3)

RESOURCES

The tracefs library is part of the kernel trace-cmd project. For more information, please refer to the kernel trace-cmd website.

NOTES

This function relies on the tracefs filesystem being mounted. If tracefs is not mounted, the function will likely return -1.

tracefs_file_exists(3)
tracefs — bibliothèque du système de fichiers de traçage

NOM

tracefs_file_exists — vérifier si un fichier existe dans tracefs

SYNTAXE

#include <tracefs.h>

int tracefs_file_exists(const char *path);

DESCRIPTION

La fonction tracefs_file_exists() vérifie si un fichier ou un répertoire nommé path existe dans le système de fichiers tracefs monté.

L'argument path est un chemin relatif à partir de la racine du point de montage tracefs. Il peut s'agir d'un nom de fichier ou d'un nom de répertoire.

Cette fonction est utile pour vérifier l'existence de fichiers tracefs spécifiques avant de tenter de les lire ou d'y écrire.

VALEUR DE RETOUR

Retourne 1 si le fichier ou le répertoire existe, 0 s'il n'existe pas, et -1 en cas d'erreur (par exemple, si tracefs n'est pas monté ou s'il y a un problème de permission).

EXEMPLES

#include <stdio.h>
#include <tracefs.h>

int main(void) {
    if (tracefs_file_exists("events/sched/sched_switch")) {
        printf("L'événement sched_switch existe.\n");
    } else {
        printf("L'événement sched_switch n'existe pas.\n");
    }

    if (tracefs_file_exists("fichier_inexistant")) {
        printf("Le fichier_inexistant existe.\n");
    } else {
        printf("Le fichier_inexistant n'existe pas.\n");
    }

    return 0;
}
