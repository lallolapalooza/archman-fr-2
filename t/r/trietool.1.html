TRIETOOL(1) Manuel des commandes générales TRIETOOL(1)

NOM

trietool - outil de manipulation de tries

SYNTAXE

trietool [ options ] trie commande argument ...

DESCRIPTION

trietool est l'outil en ligne de commande pour manipuler les données de tries à double tableau. Il peut être utilisé pour interroger, ajouter et supprimer des mots dans un trie.

Le Trie

L'argument trie spécifie le nom du trie à manipuler. Un trie est stocké dans un fichier avec l'extension `.tri'. Cependant, pour créer un nouveau trie, il faut préparer un fichier avec l'extension `.abm', décrivant les plages Unicode de l'ensemble d'alphabets du trie. L'ABM définit un ensemble de vecteurs qui mappent les caractères Unicode dans une plage continue d'entiers. Les entiers mappés seront utilisés comme alphabet interne pour le trie. Un tel mappage peut améliorer l'allocation d'espace dans les données du trie, quelle que soit la non-continuité de l'ensemble de caractères utilisé, car la plage mappée est toujours continue.

Le fichier ABM est un fichier texte brut, chaque ligne listant une plage d'Unicode 32 bits à ajouter à l'ensemble d'alphabets, sous la forme :

[0xSSSS,0xTTTT]

où `0xSSSS' et `0xTTTT' sont les valeurs hexadécimales du code de caractère de début et de fin de la plage, respectivement.

Par exemple, pour un dictionnaire ne contenant que des mots anglais sans ponctuation, on peut préparer `trie.abm' comme suit :

[0x0041,0x005a]
[0x0061,0x007a]

La première ligne liste les codes ASCII de A-Z, et la seconde pour a-z.

Pas plus de 255 alphabets ne sont autorisés dans un trie.

Le fichier `.tri' créé incorporera les données ABM. Ainsi, le fichier `.abm' n'est pas requis après la première création et sera ignoré.

COMMANDES

Les commandes disponibles sont :

ajouter mot donnée ...
Ajoute mot au trie, associé à la donnée entière donnée. Un nombre arbitraire de paires mot-donnée peut être fourni. Deux arguments seront lus à la fois, le premier sera traité comme mot et le second comme donnée.
ajouter-liste [ options ] fichier-liste
Ajoute les mots avec les données associées listées dans fichier-liste au trie. Le fichier-liste doit être un fichier texte listant un mot par ligne. La donnée associée peut être placée après le mot sur la même ligne, séparée par un caractère de tabulation (`\t'). Si le champ de donnée est omis, une valeur par défaut (-1) sera utilisée à la place.
Options disponibles pour cette commande :
-e, --encodage enc
Spécifie le codage de caractères du contenu du fichier-liste, tel que `UTF-8'. S'il est omis, le jeu de codes de la locale actuelle est supposé.
supprimer mot ...
Supprime mot du trie. Un nombre arbitraire de mots à supprimer peut être fourni.
supprimer-liste [ options ] fichier-liste
Supprime les mots listés dans fichier-liste du trie. Le fichier-liste doit être un fichier texte listant un mot par ligne.
Options disponibles pour cette commande :
-e, --encodage enc
Spécifie le codage de caractères du contenu du fichier-liste, tel que `UTF-8'. S'il est omis, le jeu de codes de la locale actuelle est supposé.
interroger mot
Recherche mot dans le trie. Si mot existe, sa donnée associée est imprimée sur la sortie standard. Sinon, un message d'erreur est imprimé sur la sortie d'erreur standard, et rien n'est imprimé sur la sortie standard.
lister
Liste tous les mots du trie sur la sortie standard. La sortie liste une paire mot-donnée par ligne, séparée par un caractère de tabulation (`\t'), le format approprié pour être un fichier-liste pour la commande ajouter-liste.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux tirets (`--'). Un résumé des options est inclus ci-dessous.

-p, --chemin rep
Définit le répertoire du trie à rep [défaut=`.']
-h, --aide
Affiche un résumé des options.
-V, --version
Affiche la version du programme.
