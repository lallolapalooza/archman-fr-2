Paquet: libtracefs

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_instance_tracers, tracefs_tracer_set, tracefs_tracer_clear - Activer ou désactiver un traceur dans une instance ou au niveau supérieur

SYNOPSIS

#include <tracefs.h>
char ** tracefs_instance_tracers(struct tracefs_instance *instance);
int tracefs_tracer_set(struct tracefs_instance *instance, enum tracefs_tracers tracer);
int tracefs_tracer_set(struct tracefs_instance *instance, enum tracefs_tracers tracer, const char *name);
int tracefs_tracer_clear(struct tracefs_instance *instance);

DESCRIPTION

tracefs_instance_tracers renverra une liste des traceurs disponibles pour une instance donnée (notez qu'une instance peut ne pas avoir le même ensemble de traceurs disponibles que le niveau supérieur). Si instance est NULL, alors la liste des traceurs disponibles retournée sera pour le niveau supérieur.

tracefs_tracer_set active un traceur dans l'instance donnée, définie par le paramètre instance. Si instance est NULL, alors l'instance de niveau supérieur est modifiée. Si tracer est défini sur TRACFES_TRACER_CUSTOM, alors une chaîne name doit être passée comme troisième paramètre, et celle-ci est écrite dans l'instance pour activer le traceur avec ce nom. Ceci est utile pour les noyaux plus récents ou personnalisés qui contiennent des traceurs qui ne sont pas encore identifiés par l'énumération tracefs_tracers.

tracefs_tracer_clear désactive le traceur pour l'instance donnée définie par la variable instance, ou l'instance de niveau supérieur si elle est NULL. Ceci équivaut à appeler tracefs_tracer_set avec TRACEFS_TRACER_NOP comme paramètre tracer.

ÉNUMÉRATIONS TRACEFS_TRACER

Les énumérations actuellement définies qui sont acceptées sont :

TRACEFS_TRACER_NOP : C'est le traceur inactif, qui ne fait rien et est utilisé pour désactiver tout traceur actif.

TRACEFS_TRACER_FUNCTION : Active le traçage de la plupart des fonctions dans le noyau.

TRACEFS_TRACER_FUNCTION_GRAPH : Active le traçage de la plupart des fonctions dans le noyau, ainsi que le retour de la fonction.

TRACEFS_TRACER_IRQSOFF : Trace la latence lorsque les interruptions sont désactivées.

TRACEFS_TRACER_PREEMPTOFF : Trace la latence lorsque la préemption est désactivée (le temps passé dans le noyau pendant lequel les tâches ne peuvent pas être planifiées depuis le CPU).

TRACEFS_TRACER_PREEMPTIRQSOFF : Trace la latence totale combinée lorsque les interruptions sont désactivées ainsi que lorsque la préemption est désactivée.

TRACEFS_TRACER_WAKEUP : Trace la latence entre le moment où la tâche de plus haute priorité prend pour se réveiller.

TRACEFS_TRACER_WAKEUP_RT : Trace la latence entre le moment où la tâche temps réel de plus haute priorité prend pour se réveiller. Toutes les autres tâches sont ignorées.

TRACEFS_TRACER_WAKEUP_DL : Trace la latence entre le moment où la tâche DEADLINE de plus haute priorité prend pour se réveiller. Toutes les autres tâches sont ignorées.

TRACEFS_TRACER_MMIOTRACE : Trace l'interaction des périphériques avec le noyau.

TRACEFS_TRACER_HWLAT : Détecte la latence causée par le matériel qui est en dehors du champ d'application du noyau.

TRACEFS_TRACER_BRANCH : Trace lorsque des branches probables ou improbables sont prises.

TRACEFS_TRACER_BLOCK : Traceur spécial pour les périphériques de bloc.

Notez que les traceurs ci-dessus peuvent ne pas être disponibles dans le noyau et tracefs_tracer_set() renverra une erreur avec errno défini sur ENODEV, si le noyau ne prend pas en charge l'option tracer, ou celle personnalisée si TRACEFS_TRACER_CUSTOM est utilisé.

VALEUR DE RETOUR

Renvoie 0 en cas de succès, ou -1 en cas d'erreur.

ERREURS

tracefs_tracer_set() peut échouer avec les erreurs suivantes :

EINVAL Le paramètre tracer est en dehors de la portée de ce qui est défini.

ENOMEM Erreur d'allocation de mémoire.

ENOENT Les traceurs ne sont pas pris en charge sur le noyau en cours d'exécution.

ENODEV Le traceur spécifié n'est pas pris en charge sur le noyau en cours d'exécution.

D'autres erreurs peuvent également survenir en raison d'appels système internes.

EXEMPLE

#include <stdlib.h>
#include <stdio.h>
#include <getopt.h>
#include <errno.h>
#include <tracefs.h>
int main(int argc, char *argv[])
{
        struct tracefs_instance *inst = NULL;
        enum tracefs_tracers t = TRACEFS_TRACER_NOP;
        const char *cust = NULL;
        const char *buf = NULL;
        char **tracers;
        int ret;
        int ch;
        int i;
        while ((ch = getopt(argc, argv, "nfgiwdc:B:")) > 0) {
                switch (ch) {
                case 'f': t = TRACEFS_TRACER_FUNCTION; break;
                case 'g': t = TRACEFS_TRACER_FUNCTION_GRAPH; break;
                case 'i': t = TRACEFS_TRACER_PREEMPTIRQSOFF; break;
                case 'w': t = TRACEFS_TRACER_WAKEUP_RT; break;
                case 'd': t = TRACEFS_TRACER_WAKEUP_DL; break;
                case 'c':
                        t = TRACEFS_TRACER_CUSTOM;
                        cust = optarg;
                        break;
                case 'B':
                        buf = optarg;
                        break;
                case 'n':
                        /* nop */
                        break;
                default:
                        printf("Unknow arg %c\n", ch);
                        exit(-1);
                }
        }
        if (buf) {
                inst = tracefs_instance_create(buf);
                if (!inst) {
                        printf("failed to create instance\n");
                        exit(-1);
                }
        }
        if (t == TRACEFS_TRACER_CUSTOM)
                ret = tracefs_tracer_set(inst, t, cust);
        else
                ret = tracefs_tracer_set(inst, t);
        if (ret < 0) {
                if (errno == ENODEV) {
                        if (cust)
                                printf("Tracer '%s' not supported by kernel\n", cust);
                        else
                                printf("Tracer not supported by kernel\n");
                        tracers = tracefs_instance_tracers(inst);
                        printf("Available tracers:");
                        for (i = 0; tracers && tracers[i]; i++)
                                printf(" %s", tracers[i]);
                        tracefs_list_free(tracers);
                        printf("\n");
                } else
                        perror("Error");
                if (inst) {
                        tracefs_instance_destroy(inst);
                        tracefs_instance_free(inst);
                }
                exit(-1);
        }
        tracefs_instance_free(inst);
        exit(0);
}
