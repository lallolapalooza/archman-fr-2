NOM

trace-cmd-stack - lire, activer ou désactiver le traçage de la pile Ftrace sous Linux.

SYNTAXE

trace-cmd stack

DESCRIPTION

Le commande trace-cmd(1) stack active le traçeur de pile Ftrace dans le noyau. Le traçeur de pile active le traçeur de fonctions et, à chaque appel de fonction dans le noyau, la pile est vérifiée. Lorsqu'un nouveau maximum d'utilisation de la pile est découvert, il est enregistré.

Lorsque aucune option n'est utilisée, la pile actuelle est affichée.

Pour activer le traçeur de pile, utilisez l'option --start, et pour désactiver le traçeur de pile, utilisez l'option --stop. La sortie sera la pile maximale trouvée depuis que le démarrage a été activé.

Utilisez --reset pour réinitialiser le compteur de pile à zéro.

Utilisez --verbose[=niveau] pour définir le niveau de journalisation. Les niveaux de journalisation pris en charge sont « none », « critical », « error », « warning », « info », « debug », « all » ou leurs identifiants « 0 », « 1 », « 2 », « 3 », « 4 », « 5 », « 6 ». La définition du niveau de journalisation à une valeur spécifique active tous les journaux à partir de ce niveau et des niveaux précédents. Le niveau par défaut sera « info » s'il n'y en a pas de spécifié.
