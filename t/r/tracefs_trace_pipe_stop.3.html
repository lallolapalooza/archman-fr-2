tracefs_trace_pipe_stop(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_trace_pipe_stream, tracefs_trace_pipe_print, tracefs_trace_pipe_stop - rediriger le flux de données de trace vers une sortie ou stdout.

SYNOPSIS

#include <tracefs.h>
ssize_t tracefs_trace_pipe_stream(int fd, struct tracefs_instance *instance, int flags);
ssize_t tracefs_trace_pipe_print(struct tracefs_instance *instance, int flags);
void tracefs_trace_pipe_stop(struct tracefs_instance *instance);

DESCRIPTION

Si NULL est passé comme instance, l'instance de trace supérieure est utilisée.

La lecture du fichier trace_pipe peut être arrêtée en appelant tracefs_trace_pipe_stop(), qui peut être placée dans un gestionnaire de signaux au cas où l'application voudrait arrêter la lecture, par exemple, lorsque l'utilisateur appuie sur Ctrl-C.

La fonction tracefs_trace_pipe_stream() redirige le flux de données de trace vers un fichier de sortie. L'appel système « splice » est utilisé pour déplacer les données sans copie entre l'espace d'adressage du noyau et l'espace d'adressage utilisateur. Le descripteur de fichier fd est celui du fichier de sortie et flags est un masque de bits d'indicateurs à passer à l'appel système open du fichier trace_pipe (voir open(2)). Si flags contient O_NONBLOCK, alors il est également passé aux appels splice qui peuvent lire le fichier vers le descripteur de fichier de flux de sortie. Notez que O_RDONLY est combiné avec flags par un OU, et seul O_NONBLOCK est utile pour ce paramètre.

La fonction tracefs_trace_pipe_print() est similaire à tracefs_trace_pipe_stream(), mais le flux de données de trace est redirigé vers stdout.

VALEUR DE RETOUR

Les fonctions tracefs_trace_pipe_stream() et tracefs_trace_pipe_print() retournent le nombre d'octets transférés en cas de succès de l'opération, ou -1 en cas d'erreur.

EXEMPLE

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <signal.h>
#include <fcntl.h>
#include <tracefs.h>
void stop(int sig)
{
        tracefs_trace_pipe_stop(NULL);
}
int main(int argc, char **argv)
{
        mode_t mode = S_IRUSR | S_IWUSR | S_IRGRP | S_IROTH;
        const char *filename;
        int fd;
        int ret;
        if (argc < 2) {
                fprintf(stderr, "usage: %s output_file\n", argv[0]);
                exit(-1);
        }
        filename = argv[1];
        fd = creat(filename, mode);
        if (fd < 0) {
                perror(filename);
                exit(-1);
        }
        signal(SIGINT, stop);
        ret = tracefs_trace_pipe_stream(fd, NULL, SPLICE_F_NONBLOCK);
        close(fd);
        return ret;
}
