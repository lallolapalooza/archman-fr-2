tracefs_event_file_append(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel de libtracefs LIBTRACEFS(3)

NOM

tracefs_event_get_file, tracefs_event_file_read, tracefs_event_file_write, tracefs_event_file_append, tracefs_event_file_clear, tracefs_event_file_exists - Travailler avec les fichiers d'événements de trace.

SYNTAXE

#include <tracefs.h>
char *tracefs_event_get_file(struct tracefs_instance *instance, const char *system, const char *event,
                             const char *file);
char *tracefs_event_file_read(struct tracefs_instance *instance, const char *system, const char *event,
                              const char *file, int *psize);
int tracefs_event_file_write(struct tracefs_instance *instance, const char *system, const char *event,
                             const char *file, const char *str);
int tracefs_event_file_append(struct tracefs_instance *instance, const char *system, const char *event,
                              const char *file, const char *str);
int tracefs_event_file_clear(struct tracefs_instance *instance, const char *system, const char *event,
                             const char *file);
bool tracefs_event_file_exists(struct tracefs_instance *instance, const char *system, const char *event,
                               const char *file);

DESCRIPTION

Ce sont des fonctions pour accéder aux fichiers spécifiques aux événements de tracefs. Ces fonctions agissent de manière similaire aux fonctions de fichiers d'instance de tracefs mais sont plus faciles d'accès si le système et les événements sont connus au préalable.

tracefs_event_get_file() renvoie le chemin complet du fichier pour le système et l'événement donnés, qui se trouve dans l'instance donnée. Si instance est NULL, alors le fichier pour l'événement de l'instance de niveau supérieur est renvoyé. Notez qu'il n'y a aucune vérification pour voir si le fichier existe réellement ou même si le système et l'événement existent. Il crée uniquement le nom du chemin pour un tel événement s'il existait. Ceci agit de manière similaire à tracefs_instance_get_file(3), mais est à utiliser pour accéder aux fichiers d'événements si le système et l'événement sont déjà connus.

tracefs_event_file_read() lit le contenu du fichier de l'événement pour l'instance donnée ou l'instance de niveau supérieur si instance est NULL. Le contenu du fichier est renvoyé et psize est défini à la quantité de données qui a été lue. Le contenu renvoyé doit être libéré avec free(3). Ceci agit de manière similaire à tracefs_instance_file_read(3), mais est à utiliser pour lire le fichier d'événement si le système et l'événement sont déjà connus.

tracefs_event_file_write() écrit str dans le fichier de l'événement. Il tronquera tout ce qui se trouve déjà dans ce fichier. Ceci agit de manière similaire à tracefs_instance_file_write(3), mais est à utiliser pour lire le fichier d'événement si le système et l'événement sont déjà connus.

tracefs_event_file_append() ajoute str au fichier de l'événement. Il ne videra pas le fichier lors de l'écriture de la chaîne. Ceci agit de manière similaire à tracefs_instance_file_append(3), mais est à utiliser pour lire le fichier d'événement si le système et l'événement sont déjà connus.

tracefs_event_file_clear() efface le contenu du fichier de l'événement. Ceci agit de manière similaire à tracefs_instance_file_clear(3), mais est à utiliser pour lire le fichier d'événement si le système et l'événement sont déjà connus.

tracefs_event_file_exists() renvoie vrai si le fichier de l'événement existe, et faux sinon. Ceci agit de manière similaire à tracefs_instance_file_exists(3), mais est à utiliser pour lire le fichier d'événement si le système et l'événement sont déjà connus.

VALEUR DE RETOUR

tracefs_event_get_file() renvoie le chemin du fichier donné du système/événement en cas de succès et NULL en cas d'erreur. La valeur de retour doit être libérée avec tracefs_put_tracing_file(3).

tracefs_event_file_read() lit le contenu du fichier de système/événement ou NULL en cas d'erreur. Le pointeur de retour doit être libéré avec free(3).

tracefs_event_file_write() et tracefs_event_file_append() renvoient le nombre d'octets écrits dans le fichier de système/événement ou un nombre négatif en cas d'erreur.

tracefs_event_file_clear() renvoie zéro en cas de succès et -1 en cas d'erreur.

tracefs_event_file_exists() renvoie vrai si le fichier de système/événement existe pour l'instance donnée (ou le niveau supérieur si instance est NULL) ou faux sinon.

EXEMPLE

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <tracefs.h>
int main(int argc, char **argv)
{
        char *system;
        char *event;
        char *file;
        char *cmd = NULL;
        char *buf;
        char *str;
        char ch = 'r';
        int size;
        if (argc < 4) {
                printf("usage: %s sytem event file [(-a|-w) write | -c]\n"
                       "   lit le fichier system/event ou écrit si [write est fourni]\n",
                       argv[0]);
                exit(0);
        }
        system = argv[1];
        event = argv[2];
        file = argv[3];
        if (argc > 4)
                cmd = argv[4];
        if (!tracefs_event_file_exists(NULL, system, event, file)) {
                fprintf(stderr, "Le fichier %s/%s/%s n'existe pas\n",
                                system, event, file);
                exit(-1);
        }
        if (cmd) {
                if (cmd[0] != '-')
                        ch = cmd[0];
                else
                        ch = cmd[1];
                if (!ch)
                        ch = 'c';
        }
        switch (ch) {
        case 'r':
                buf = tracefs_event_file_read(NULL, system, event, file, &size);
                if (buf)
                        printf("%s", buf);
                else
                        fprintf(stderr, "Échec de la lecture de %s/%s/%s\n",
                                system, event, file);
                free(buf);
                break;
        case 'w':
        case 'a':
                if (argc < 6) {
                        fprintf(stderr, "La commande %s nécessite quelque chose à écrire\n",
                                ch == 'w' ? "write" : "append");
                        exit(-1);
                }
                if (ch == 'w')
                        size = tracefs_event_file_write(NULL, system, event, file, argv[5]);
                else
                        size = tracefs_event_file_append(NULL, system, event, file, argv[5]);
                if (size < 0) {
                        fprintf(stderr, "Échec de l'écriture de '%s' dans %s/%s/%s\n",
                                        argv[5], system, event, file);
                        exit(-1);
                }
                break;
        case 'c':
                if (tracefs_event_file_clear(NULL, system, event, file) < 0) {
                        fprintf(stderr, "Échec de l'effacement de %s/%s/%s\n",
                                system, event, file);
                        exit(-1);
                }
                break;
        default:
                fprintf(stderr, "Commande inconnue '%c'\n", ch);
                exit(-1);
        }
        exit(0);
}
