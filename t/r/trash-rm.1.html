TRASH-RM(1) Manuel des commandes générales TRASH-RM(1)

NOM

trash-rm - Supprime du fichier corbeille les fichiers correspondant à un motif

SYNTAXE

trash-rm [MOTIF]

DESCRIPTION

Supprime du fichier corbeille tous les fichiers correspondant au MOTIF.

EXEMPLE

$ trash-rm foo          # Supprime tous les fichiers nommés 'foo' dans la corbeille
$ trash-rm '*.o'        # Supprime tous les fichiers se terminant par '.o' dans la corbeille
$ trash-rm /chemin/complet   # Supprime tous les fichiers avec exactement '/chemin/complet' comme emplacement d'origine
