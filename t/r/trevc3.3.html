CTREVC3

But :

!>
!> CTREVC3 calcule tout ou partie des vecteurs propres droits et/ou gauches
!> d'une matrice triangulaire supérieure complexe T.
!> Les matrices de ce type sont produites par la factorisation de Schur d'une
!> matrice générale complexe : A = Q*T*Q**H, comme calculé par CHSEQR.
!>
!> Le vecteur propre droit x et le vecteur propre gauche y de T correspondant
!> à une valeur propre w sont définis par :
!>
!>              T*x = w*x,     (y**H)*T = w*(y**H)
!>
!> où y**H désigne la transposée conjuguée du vecteur y.
!> Les valeurs propres ne sont pas fournies en entrée de cette routine, mais sont lues directement
!> à partir de la diagonale de T.
!>
!> Cette routine retourne les matrices X et/ou Y des vecteurs propres droits et gauches
!> de T, ou les produits Q*X et/ou Q*Y, où Q est une matrice d'entrée. Si Q est le facteur unitaire qui réduit une matrice A à
!> la forme de Schur T, alors Q*X et Q*Y sont les matrices des vecteurs propres droits et gauches
!> de A.
!>
!> Ceci utilise une version Level 3 BLAS de la transformation inverse.
!>

Paramètres

SIDE 
!>          SIDE est CHARACTER*1
!>          = 'R' : calculer uniquement les vecteurs propres droits ;
!>          = 'L' : calculer uniquement les vecteurs propres gauches ;
!>          = 'B' : calculer les vecteurs propres droits et gauches.
!>

HOWMNY

!>          HOWMNY est CHARACTER*1
!>          = 'A' : calculer tous les vecteurs propres droits et/ou gauches ;
!>          = 'B' : calculer tous les vecteurs propres droits et/ou gauches,
!>                  transformés inversement en utilisant les matrices fournies dans
!>                  VR et/ou VL ;
!>          = 'S' : calculer les vecteurs propres droits et/ou gauches sélectionnés,
!>                  comme indiqué par le tableau logique SELECT.
!>

SELECT

!>          SELECT est un tableau LOGIQUE, de dimension (N)
!>          Si HOWMNY = 'S', SELECT spécifie les vecteurs propres à calculer.
!>          Le vecteur propre correspondant à la j-ième valeur propre
!>          est calculé si SELECT(j) = .VRAI..
!>          Non référencé si HOWMNY = 'A' ou 'B'.
!>

N

!>          L'ordre de la matrice T. N >= 0.
!>

T

!>          T est un tableau COMPLEXE, de dimension (LDT,N)
!>          La matrice triangulaire supérieure T. T est modifiée, mais restaurée
!>          à la sortie.
!>

LDT

!>          LDT est un ENTIER

NAME

strevc3 - computes some or all of the right and/or left eigenvectors of a complex upper triangular matrix.

SYNOPSIS

subroutine strevc3 (character side, character howmny, logical, dimension( * ) select, integer n, real, dimension( ldt, * ) t, integer ldt, real, dimension( ldvl, * ) vl, integer ldvl, real, dimension( ldvr, * ) vr, integer ldvr, integer mm, integer m, real, dimension( * ) work, integer lwork, integer info)

STREVC3 computes some or all of the right and/or left eigenvectors of a complex upper triangular matrix T. Matrices of this type are produced by the Schur factorization of a complex general matrix: A = Q*T*Q**H, as computed by SHSEQR. The right eigenvector x and the left eigenvector y of T corresponding to an eigenvalue w are defined by: T*x = w*x, (y**H)*T = w*(y**H) where y**H denotes the conjugate transpose of the vector y. The eigenvalues are not input to this routine, but are read directly from the diagonal of T. This routine returns the matrices X and/or Y of right and left eigenvectors of T, or the products Q*X and/or Q*Y, where Q is an input matrix. If Q is the unitary factor that reduces a matrix A to Schur form T, then Q*X and Q*Y are the matrices of right and left eigenvectors of A. This uses a Level 3 BLAS version of the back transformation.

PARAMETERS

SIDE
SIDE is CHARACTER*1
= 'R': compute right eigenvectors only;
= 'L': compute left eigenvectors only;
= 'B': compute both right and left eigenvectors.
HOWMNY
HOWMNY is CHARACTER*1
= 'A': compute all right and/or left eigenvectors;
= 'B': compute all right and/or left eigenvectors,
backtransformed using the matrices supplied in
VR and/or VL;
= 'S': compute selected right and/or left eigenvectors,
as indicated by the logical array SELECT.
SELECT
SELECT is LOGICAL array, dimension (N)
If HOWMNY = 'S', SELECT specifies the eigenvectors to be
computed.
The eigenvector corresponding to the j-th eigenvalue is
computed if SELECT(j) = .TRUE..
For a complex conjugate pair of eigenvalues, the selection
of either one is sufficient to indicate that both are
to be processed.
Not referenced if HOWMNY = 'A' or 'B'.
On exit, SELECT(j) is set to .TRUE. if the j-th eigenvector
is computed, and to .FALSE. otherwise.
If HOWMNY = 'A' or 'B', SELECT is set to .TRUE. on exit.
N
N is INTEGER
The order of the matrix T. N >= 0.
T
T is REAL array, dimension (LDT,N)
The upper quasi-triangular matrix T in Schur canonical form.
T is modified, but restored on exit.
LDT
LDT is INTEGER
The leading dimension of the array T. LDT >= max(1,N).
VL
VL is REAL array, dimension (LDVL,MM)
On entry, if SIDE = 'L' or 'B' and HOWMNY = 'B', VL must
contain an N-by-N matrix Q (usually the orthogonal matrix Q
of Schur vectors returned by SHSEQR).
On exit, if SIDE = 'L' or 'B', VL contains:
if HOWMNY = 'A', the matrix Y of left eigenvectors of T;
if HOWMNY = 'B', the matrix Q*Y;
if HOWMNY = 'S', the left eigenvectors of T specified by
SELECT, stored consecutively in the columns
of VL, in the same order as their
eigenvalues.
A complex eigenvector corresponding to a complex eigenvalue
is stored in two consecutive columns, the first holding the
real part, and the second the imaginary part.
Not referenced if SIDE = 'R'.
LDVL
LDVL is INTEGER
The leading dimension of the array VL.
LDVL >= 1, and if SIDE = 'L' or 'B', LDVL >= N.
VR
VR is REAL array, dimension (LDVR,MM)
On entry, if SIDE = 'R' or 'B' and HOWMNY = 'B', VR must
contain an N-by-N matrix Q (usually the orthogonal matrix Q
of Schur vectors returned by SHSEQR).
On exit, if SIDE = 'R' or 'B', VR contains:
if HOWMNY = 'A', the matrix X of right eigenvectors of T;
if HOWMNY = 'B', the matrix Q*X;
if HOWMNY = 'S', the right eigenvectors of T specified by
SELECT, stored consecutively in the columns
of VR, in the same order as their
eigenvalues.
A complex eigenvector corresponding to a complex eigenvalue
is stored in two consecutive columns, the first holding the
real part and the second the imaginary part.
Not referenced if SIDE = 'L'.
LDVR
LDVR is INTEGER
The leading dimension of the array VR.
LDVR >= 1, and if SIDE = 'R' or 'B', LDVR >= N.
MM
MM is INTEGER
The number of columns in the arrays VL and/or VR. MM >= M.
M
M is INTEGER
The number of columns in the arrays VL and/or VR actually
used to store the eigenvectors.
If HOWMNY = 'A' or 'B', M is set to N.
Each selected real eigenvector occupies one column and each
selected complex eigenvector occupies two columns.
If HOWMNY = 'S', M is the number of selected eigenvectors,
and thus is the number of columns of VL and/or VR that are
actually used.
On exit, M is the number of selected eigenvectors, and the
columns of VL and/or VR are specified by the array SELECT.
WORK
WORK is REAL array, dimension (MAX(1,LWORK))
LWORK
LWORK is INTEGER
The dimension of array WORK. LWORK >= max(1,3*N).
For optimum performance, LWORK >= N + 2*N*NB, where NB is
the optimal blocksize.
If LWORK = -1, then a workspace query is assumed; the routine
only calculates the optimal size of the WORK array, returns
this value as the first entry of the WORK array, and no error
message related to LWORK is issued by XERBLA.
INFO

ZTREVC3

Purpose:

ZTREVC3 computes some or all of the right and/or left eigenvectors of
a complex upper triangular matrix T.
Matrices of this type are produced by the Schur factorization of
a complex general matrix:  A = Q*T*Q**H, as computed by ZHSEQR.
The right eigenvector x and the left eigenvector y of T corresponding
to an eigenvalue w are defined by:
T*x = w*x,     (y**H)*T = w*(y**H)
where y**H denotes the conjugate transpose of the vector y.
The eigenvalues are not input to this routine, but are read directly
from the diagonal of T.
This routine returns the matrices X and/or Y of right and left
eigenvectors of T, or the products Q*X and/or Q*Y, where Q is an
input matrix. If Q is the unitary factor that reduces a matrix A to
Schur form T, then Q*X and Q*Y are the matrices of right and left
eigenvectors of A.
This uses a Level 3 BLAS version of the back transformation.
