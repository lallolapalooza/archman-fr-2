NOM

tracefs_event_systems, tracefs_system_events, tracefs_event_enable, tracefs_event_disable, tracefs_event_is_enabled - Travailler avec les systèmes et événements de trace.

SYNTAXE

#include <tracefs.h>
enum tracefs_event_state {
        TRACEFS_ERROR = -1,
        TRACEFS_ALL_DISABLED = 0,
        TRACEFS_ALL_ENABLED = 1,
        TRACEFS_SOME_ENABLED = 2,
};
char **tracefs_event_systems(const char *tracing_dir);
char **tracefs_system_events(const char *tracing_dir, const char *system);
int tracefs_event_enable(struct tracefs_instance *instance, const char *system,
                           const char *event);
int tracefs_event_disable(struct tracefs_instance *instance, const char *system,
                            const char *event);
enum tracefs_enable_state tracefs_event_is_enabled(struct tracefs_instance *instance,
                         const char *system, const char *event);

DESCRIPTION

API liées aux systèmes et événements de trace.

La fonction tracefs_event_systems() renvoie un tableau de chaînes de caractères contenant les noms de tous les systèmes de trace enregistrés, situés dans le répertoire tracing_dir donné. Il peut s'agir de NULL ou de l'emplacement du point de montage tracefs pour les systèmes de trace de la machine locale, ou bien d'un chemin vers une copie du répertoire tracefs provenant d'une autre machine. Le dernier élément du tableau est un pointeur NULL. Le tableau doit être libéré avec l'API tracefs_list_free().

La fonction tracefs_system_events() renvoie un tableau de chaînes de caractères contenant les noms de tous les événements de trace enregistrés pour un système de trace donné, spécifié par system, situés dans le répertoire tracing_dir donné. Il peut s'agir de NULL ou de l'emplacement du point de montage tracefs pour les systèmes de trace de la machine locale, ou bien d'un chemin vers une copie du répertoire tracefs provenant d'une autre machine. Le dernier élément du tableau est un pointeur NULL. Le tableau doit être libéré avec l'API tracefs_list_free().

La fonction tracefs_event_enable() active un événement donné en fonction des paramètres system et event fournis pour l'instance donnée instance. Si instance est NULL, alors le répertoire de trace de haut niveau est utilisé. Si system et event sont tous deux NULL, alors tous les événements sont activés pour l'instance. Si event est NULL, alors tous les événements dans le system sont activés. Si system est NULL, alors tous les systèmes sont recherchés et tout événement dans un système qui correspond à event est activé. Les deux system et event peuvent être des expressions régulières telles que définies dans regex(3).

La fonction tracefs_event_disable() désactive les événements qui correspondent aux paramètres system et event pour l'instance donnée instance. Les événements désactivés suivent les mêmes règles que tracefs_event_enable() pour la correspondance des événements. C'est-à-dire, si instance est NULL, alors le répertoire de trace de haut niveau est utilisé. Si system et event sont tous deux NULL, alors tous les événements sont désactivés pour l'instance donnée, et ainsi de suite.

La fonction tracefs_event_is_enabled() renvoie si un événement est activé, un ensemble d'événements est activé, un système est activé, ou tous les événements sont activés. Si system et event sont tous deux NULL, alors elle renvoie l'état d'activation de tous les événements. Si system n'est pas NULL et event est NULL, alors elle vérifiera si tous les événements dans tous les systèmes correspondant à system et renverra l'état d'activation de ces événements. Si system est NULL et event n'est pas NULL, alors elle fera correspondre tous les événements dans tous les systèmes qui correspondent à event et renverra leur état activé. Si system et event ne sont tous deux pas NULL, alors elle renverra l'état activé de tous les événements correspondants. L'état activé est défini comme suit :

TRACEFS_ERROR - Une erreur s'est produite, y compris aucun événement n'a été trouvé.

TRACEFS_ALL_DISABLED - Tous les événements correspondants sont désactivés.

TRACEFS_ALL_ENABLED - Tous les événements correspondants sont activés.

TRACEFS_SOME_ENABLED - Certains événements correspondants ont été activés tandis que d'autres ne l'ont pas été.

VALEUR DE RETOUR

Les fonctions tracefs_event_systems() et tracefs_system_events() renvoient un tableau de chaînes de caractères. Le dernier élément de ce tableau est un pointeur NULL. Le tableau doit être libéré avec l'API tracefs_list_free(). En cas d'erreur, NULL est renvoyé.

Les deux fonctions tracefs_event_enable() et tracefs_event_disable() renvoient 0 si elles ont trouvé des événements correspondants (Notez qu'elles ne vérifient pas l'état précédent de l'événement. Si tracefs_event_enable() trouve un événement déjà activé, et qu'il n'y a pas d'autres erreurs, alors elle renverra 0). Si une erreur se produit, même si d'autres événements ont été trouvés, elle renverra -1 et errno sera défini. Si aucune erreur ne se produit, mais qu'aucun événement ne correspond aux paramètres system et event, alors -1 est renvoyé et errno n'est pas défini.

La fonction tracefs_event_is_enabled() renvoie l'état activé des événements correspondants ou TRACEFS_ERROR en cas d'erreur.

EXEMPLE

#include <tracefs.h>
char **systems = tracefs_event_systems(NULL);
        if (systems) {
                int i = 0;
                /* Obtenu les systèmes de trace enregistrés depuis l'instance de trace de haut niveau */
                while (systems[i]) {
                        char **events = tracefs_system_events(NULL, systems[i]);
                        if (events) {
                                /* Obtenu les événements enregistrés dans system[i] depuis l'instance de trace de haut niveau */
                                int j = 0;
                                while (events[j]) {
                                        /* Obtenu l'événement events[j] dans system[i] depuis l'instance de trace de haut niveau */
                                        j++;
                                }
                                tracefs_list_free(events);
                        }
                        i++;
                }
                tracefs_list_free(systems);
        }
