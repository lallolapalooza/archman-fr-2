tracefs_dynevent_get_all(3)

Paquet: libtracefs

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_dynevent_create, tracefs_dynevent_destroy, tracefs_dynevent_destroy_all, tracefs_dynevent_free, tracefs_dynevent_list_free, tracefs_dynevent_get, tracefs_dynevent_get_all, tracefs_dynevent_info, tracefs_dynevent_get_event - Créer, détruire, libérer et obtenir des événements dynamiques.

SYNTAXE

#include <tracefs.h>
struct tracefs_dynevent;
enum tracefs_dynevent_type;
int tracefs_dynevent_create(struct tracefs_dynevent *devent);
int tracefs_dynevent_destroy(struct tracefs_dynevent *devent, bool force);
int tracefs_dynevent_destroy_all(unsigned int types, bool force);
void tracefs_dynevent_free(struct tracefs_dynevent *devent);
void tracefs_dynevent_list_free(struct tracefs_dynevent **events);
struct tracefs_dynevent *tracefs_dynevent_get(enum tracefs_dynevent_type type, const char *system, const char *event);
struct tracefs_dynevent **tracefs_dynevent_get_all(unsigned int types, const char *system);
enum tracefs_dynevent_type tracefs_dynevent_info(struct tracefs_dynevent *dynevent, char **system, char **event, char **prefix, char **addr, char **format);
struct tep_event *tracefs_dynevent_get_event(struct tep_handle *tep, struct tracefs_dynevent *dynevent);

DESCRIPTION

La fonction tracefs_dynevent_create() crée l'événement dynamique devent dans le système.

La fonction tracefs_dynevent_destroy() supprime l'événement dynamique devent du système. Si force est vrai, la fonction tentera de désactiver tous les événements dans toutes les instances de trace, avant de supprimer l'événement dynamique. Le contexte devent n'est pas libéré, utilisez tracefs_dynevent_free() pour le libérer.

La fonction tracefs_dynevent_destroy_all() supprime tous les événements dynamiques des types donnés du système. Le paramètre types est un type d'événement dynamique spécifique, ou un masque de bits des types d'événements dynamiques tracefs_dynevent_type, qui seront supprimés. Si types est 0, les événements dynamiques de tous les types seront supprimés. Si force est vrai, la fonction tentera de désactiver tous les événements dans toutes les instances de trace, avant de supprimer les événements dynamiques.

La fonction tracefs_dynevent_get() alloue et retourne une instance unique d'un événement dynamique qui correspond au type, au system et à l'event donnés. NULL est retourné s'il n'y a pas de correspondance. L'événement retourné est celui trouvé dans le système et doit être libéré avec tracefs_dynevent_free(). Si system est NULL, alors le premier event de n'importe quel système du type donné qui a le nom de event sera retourné.

La fonction tracefs_dynevent_get_all() alloue et retourne un tableau de pointeurs vers des événements dynamiques des types donnés qui existent dans le système. Le dernier élément du tableau est un pointeur NULL. Le tableau doit être libéré avec tracefs_dynevent_list_free(). S'il n'y a aucun événement, un pointeur NULL est retourné. Le paramètre types est un type d'événement dynamique spécifique, ou un masque de bits des types d'événements dynamiques tracefs_dynevent_type, qui seront récupérés. Si types est 0, les événements dynamiques de tous les types seront récupérés.

La fonction tracefs_dynevent_free() libère un contexte d'événement dynamique devent.

La fonction tracefs_dynevent_list_free() libère un tableau de pointeurs vers des événements dynamiques, retourné par l'API tracefs_dynevent_get_all().

La fonction tracefs_dynevent_info() retourne le type et les informations d'un événement dynamique donné dynevent. Si l'un des arguments system, event, prefix, addr ou format n'est pas NULL, alors des chaînes sont allouées et retournées via ces arguments. Le system et l'event contiennent le système et le nom de l'événement dynamique. Si prefix n'est pas NULL, il contiendra une chaîne allouée qui contient la partie préfixe de l'événement dynamique (le contenu jusqu'au « : », en l'excluant). Si addr n'est pas NULL, il contiendra l'adresse ou la fonction à laquelle l'événement dynamique est attaché, si cela est pertinent pour ce type d'événement. Si format n'est pas NULL, il contiendra la chaîne de format de l'événement dynamique. Notez que le contenu de group, event, prefix, addr et format doit être libéré avec free(3) s'ils sont définis.

La fonction tracefs_dynevent_get_event() retourne un événement tep, décrivant l'événement dynamique donné. L'API détecte tout événement dynamique nouvellement créé ou supprimé. Le pointeur retourné vers l'événement tep est contrôlé par @tep et ne doit pas être libéré.

VALEUR DE RETOUR

tracefs_dynevent_create() retourne 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur d'analyse survient, tracefs_error_last(3) peut être utilisée pour récupérer le message d'erreur expliquant le problème d'analyse.

tracefs_dynevent_destroy() et tracefs_dynevent_destroy_all() retournent 0 en cas de succès, ou -1 en cas d'erreur. Si force est activé, les fonctions peuvent échouer lors de la désactivation des événements.

La fonction tracefs_dynevent_get() retourne un événement dynamique alloué du système qui correspond au type, au système et à l'événement donnés.

La fonction tracefs_dynevent_get_all() retourne un tableau alloué de pointeurs vers des événements dynamiques, ou NULL en cas d'erreur ou s'il n'y a aucun événement dans le système. Ce tableau doit être libéré par tracefs_dynevent_list_free().

tracefs_dynevent_info() retourne le type de l'événement dynamique donné ou TRACEFS_DYNEVENT_UNKNOWN en cas d'erreur. Si system, event, prefix, addr ou format ne sont pas NULL, ils contiendront des chaînes allouées qui doivent être libérées par free(3).

La fonction tracefs_dynevent_get_event() retourne un pointeur vers un événement tep ou NULL en cas d'erreur ou si l'événement dynamique demandé est manquant. Le pointeur retourné vers l'événement tep est contrôlé par @tep et ne doit pas être libéré.

ERREURS

Les erreurs suivantes s'appliquent à tous les appels ci-dessus :

ENODEV les événements dynamiques du type demandé ne sont pas configurés pour le noyau en cours d'exécution.

ENOMEM Erreur d'allocation de mémoire.

tracefs_dynevent_create() peut échouer avec les erreurs suivantes :

EINVAL Le plus probable est qu'une erreur d'analyse est survenue (utilisez tracefs_error_last(3) pour éventuellement voir quelle était cette erreur).

D'autres erreurs peuvent également survenir en raison d'appels système internes.

#include <stdlib.h>

static struct tep_event *open_event;
static struct tep_format_field *file_field;
static struct tep_event *openret_event;
static struct tep_format_field *ret_field;
static int callback(struct tep_event *event, struct tep_record *record,
                    int cpu, void *data)
{
        struct trace_seq seq;
        trace_seq_init(&seq);
        tep_print_event(event->tep, &seq, record, "%d-%s: ", TEP_PRINT_PID, TEP_PRINT_COMM);
        if (event->id == open_event->id) {
                trace_seq_puts(&seq, "open file='");
                tep_print_field(&seq, record->data, file_field);
                trace_seq_puts(&seq, "'\n");
        } else if (event->id == openret_event->id) {
                unsigned long long ret;
                tep_read_number_field(ret_field, record->data, &ret);
                trace_seq_printf(&seq, "open ret=%lld\n", ret);
        } else {
                goto out;
        }
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
out:
        trace_seq_destroy(&seq);
        return 0;
}

        exit(-1);
}
