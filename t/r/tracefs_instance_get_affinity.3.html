tracefs_instance_get_affinity(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_instance_set_affinity, tracefs_instance_set_affinity_set, tracefs_instance_set_affinity_raw, tracefs_instance_get_affinity, tracefs_instance_get_affinity_set, tracefs_instance_get_affinity_raw - Définit ou récupère l'affinité pour une instance ou le niveau supérieur pour les CPU activant le traçage.

SYNTAXE

#include <tracefs.h>
int tracefs_instance_set_affinity(struct tracefs_instance *instance, const char *cpu_str);
int tracefs_instance_set_affinity_set(struct tracefs_instance *instance, cpu_set_t *set, size_t set_size);
int tracefs_instance_set_affinity_raw(struct tracefs_instance *instance, const char *mask);
char *tracefs_instance_get_affinity(struct tracefs_instance *instance);
int tracefs_instance_get_affinity_set(struct tracefs_instance *instance, cpu_set_t *set, size_t set_size);
char *tracefs_instance_get_affinity_raw(struct tracefs_instance *instance);

DESCRIPTION

Ces fonctions définissent ou récupèrent l'affinité CPU qui limite quels CPU auront le traçage activé pour une instance donnée définie par le paramètre instance. Si instance est NULL, alors l'instance de niveau supérieur est affectée.

La fonction tracefs_instance_set_affinity() prend une chaîne cpu_str qui est une liste de CPU pour lesquels définir l'affinité. Si cpu_str est NULL, alors tous les CPU du système seront définis. Le format de cpu_str est une chaîne de nombres décimaux séparés par des virgules, sans espaces. Une plage peut être spécifiée par un tiret.

Par exemple : "1,4,6-8"

Les nombres n'ont pas besoin d'être dans l'ordre, sauf pour les plages, où le second nombre doit être égal ou supérieur au premier.

La fonction tracefs_instance_set_affinity_set() prend un ensemble de CPU défini par CPU_SET(3). La taille de l'ensemble définie par set_size est la taille en octets de set. Si set est NULL alors tous les CPU du système seront définis, et set_size est ignoré.

La fonction tracefs_instance_set_affinity_raw() prend une chaîne qui contient un masque de bits hexadécimal, où chaque groupe de 32 bits est séparé par une virgule. Pour une machine avec plus de 32 CPU, pour définir les CPU 1-10 et le CPU 40 :

"100,000007fe"

Où ce qui précède est une représentation hexadécimale des bits 1 à 10 et du bit 40 étant définis.

La fonction tracefs_instance_get_affinity() récupérera l'affinité sous une forme lisible par l'homme.

Par exemple : "1,4,6-8"

La chaîne retournée doit être libérée avec free(3).

La fonction tracefs_instance_get_affinity_set() définira tous les bits de l'ensemble CPU passé (de CPU_SET(3)). Notez qu'elle ne supprimera aucun bit qui est déjà défini dans l'ensemble mais dont les CPU ne le sont pas. Si seuls les bits des CPU activés doivent être définis, un CPU_ZERO_S() doit être effectué sur l'ensemble avant d'appeler cette fonction.

La fonction tracefs_instance_get_affinity_raw() lira simplement le masque de CPU (`tracing_cpumask`) de l'instance et retournera cette chaîne. La chaîne retournée doit être libérée avec free(3).

VALEUR DE RETOUR

Toutes les fonctions de définition retournent 0 en cas de succès et -1 en cas d'erreur.

Les fonctions tracefs_instance_get_affinity() et tracefs_instance_get_affinity_raw() retournent une chaîne allouée qui doit être libérée avec free(3), ou NULL en cas d'erreur.

La fonction tracefs_instance_get_affinity_set() retourne le nombre de CPU qui ont été trouvés définis, ou -1 en cas d'erreur.

ERREURS

Les erreurs suivantes s'appliquent à tous les appels ci-dessus :

EFBIG si un CPU est défini et qu'il est supérieur à ce qui existe dans le système.

EINVAL L'un des paramètres était invalide.

Les erreurs suivantes concernent tracefs_instance_set_affinity() et tracefs_instance_set_affinity_set():

ENOMEM Erreur d'allocation de mémoire.

ENODEV les événements dynamiques du type demandé ne sont pas configurés pour le noyau en cours d'exécution.

Les erreurs suivantes concernent uniquement tracefs_instance_set_affinity()

EACCES Le cpu_str a été modifié par un autre thread lors de son traitement.

EXEMPLE

#include <sched.h>
#include <stdio.h>
#include <stdlib.h>
#include <tracefs.h>
int main (int argc, char **argv)
{
        struct trace_seq seq;
        cpu_set_t *set;
        size_t set_size;
        char *c;
        int cpu1;
        int cpu2;
        int i;
        c = tracefs_instance_get_affinity(NULL);
        printf("L'affinité était %s\n", c);
        free(c);
        if (argc < 2) {
                tracefs_instance_set_affinity(NULL, NULL);
                exit(0);
        }
        /* Afficher un exemple utilisant un ensemble */
        if (argc == 2 && !strchr(argv[1],',')) {
                cpu1 = atoi(argv[1]);
                c = strchr(argv[1], '-');
                if (c++)
                        cpu2 = atoi(c);
                else
                        cpu2 = cpu1;
                if (cpu2 < cpu1) {
                        fprintf(stderr, "Plage CPU invalide\n");
                        exit(-1);
                }
                set = CPU_ALLOC(cpu2 + 1);
                set_size = CPU_ALLOC_SIZE(cpu2 + 1);
                CPU_ZERO_S(set_size, set);
                for ( ; cpu1 <= cpu2; cpu1++)
                        CPU_SET(cpu1, set);
                tracefs_instance_set_affinity_set(NULL, set, set_size);
                CPU_FREE(set);
                exit(0);
        }
        trace_seq_init(&seq);
        for (i = 1; i < argc; i++) {
                if (i > 1)
                        trace_seq_putc(&seq, ',');
                trace_seq_puts(&seq, argv[i]);
        }
        trace_seq_terminate(&seq);
        tracefs_instance_set_affinity(NULL, seq.buffer);
        trace_seq_destroy(&seq);
        exit(0);
        return 0;
}
