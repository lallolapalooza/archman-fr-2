NOM

transmission-gtk — un client bittorrent

SYNTAXE

transmission-gtk -?

transmission-gtk [-pqm] [fichier-torrent ...]

DESCRIPTION

transmission-gtk est un client BitTorrent rapide et facile à utiliser.

BitTorrent est un protocole de transfert de fichiers peer-to-peer qui utilise un fichier metainfo (généralement avec l'extension .torrent) et un tracker central pour distribuer les données de fichiers parmi un groupe de pairs. Pour plus d'informations sur le protocole BitTorrent, voir http://www.bittorrent.org/

OPTIONS

-? --help
Afficher les options d'aide
-p --paused
Démarrer avec tous les torrents en pause
-m --minimized
Démarrer minimisé dans la zone de notification
-g --config-dir répertoire
Où rechercher les fichiers de configuration. Ceci peut être utilisé pour basculer entre l'utilisation des clients cli, daemon, gtk et qt. Voir https://github.com/transmission/transmission/blob/main/docs/Configuration-Files.md pour plus d'informations.

Plusieurs fichiers .torrent peuvent être ajoutés au démarrage en les ajoutant sur la ligne de commande. Si transmission-gtk est déjà en cours d'exécution, les torrents seront ajoutés à l'instance en cours d'exécution.

ENVIRONNEMENT

TRANSMISSION_HOME
Définit le répertoire de configuration par défaut.
http_proxy
libcurl utilise cette variable d'environnement lors de l'annonce des trackers. Si elle est définie, elle remplace les préférences de proxy GNOME.

FICHIERS

~/.config/transmission
Le répertoire de configuration utilisé lorsque ni [TRANSMISSION_HOME] ni [-g] n'est spécifié.
