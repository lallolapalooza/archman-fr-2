tracefs_kprobe_destroy(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_kprobe_alloc, tracefs_kretprobe_alloc, tracefs_kprobe_raw, tracefs_kretprobe_raw, tracefs_kprobe_destroy - Allouer, obtenir, créer et supprimer des kprobes

SYNTAXE

#include <tracefs.h>
struct tracefs_dynevent *
tracefs_kprobe_alloc(const char *system, const char *event,
                       const char *addr, const char *format);
struct tracefs_dynevent *
tracefs_kretprobe_alloc(const char *system, const char *event,
                          const char *addr, const char *format, unsigned int max);
int tracefs_kprobe_raw(const char *system, const char *event,
                         const char *addr, const char *format);
int tracefs_kretprobe_raw(const char *system, const char *event,
                            const char *addr, const char *format);
int tracefs_kprobe_destroy(const char *system, const char *event,
                           const char *addr, const char *format, bool force);

DESCRIPTION

tracefs_kprobe_alloc() alloue un nouveau contexte de kprobe. Le kprobe n'est pas configuré dans le système. Le kprobe peut être ajouté au système en passant le descripteur retourné à tracefs_dynevent_create(3). Le nouveau kprobe sera dans le groupe system (ou kprobes si system est NULL) et portera le nom de event (ou addr si event est NULL). Le kprobe sera inséré à addr (nom de fonction, avec ou sans décalage, ou une adresse), et format définira le format du kprobe. Voir le fichier de documentation Linux sous : Documentation/trace/kprobetrace.rst

tracefs_kretprobe_alloc() est identique à tracefs_kprobe_alloc, mais alloue un contexte pour un kretprobe. Il a un paramètre supplémentaire, facultatif, max - le nombre maximal d'activations. Voir la description des kretprobes dans le fichier Documentation/trace/kprobetrace.rst.

tracefs_kprobe_raw() créera un événement kprobe. Si system est NULL, alors le groupe par défaut "kprobes" est utilisé pour le groupe (système d'événements). Sinon, si system est spécifié, le kprobe sera créé sous le groupe portant ce nom. event est le nom de l'événement kprobe à créer. addr peut être une fonction, une fonction avec un décalage, ou une adresse noyau. C'est là que l'emplacement du kprobe sera inséré dans le noyau. format est le format du kprobe tel que spécifié par FETCHARGS dans le code source du noyau Linux dans le document Documentation/trace/kprobetrace.rst.

tracefs_kretprobe_raw() est identique à tracefs_kprobe_raw(), sauf qu'il crée un kretprobe au lieu d'un kprobe. La différence est également décrite dans le code source du noyau Linux dans le fichier Documentation/trace/kprobetrace.rst.

tracefs_kprobe_destroy() détruira un kprobe ou kretprobe spécifique créé par tracefs_kprobe_raw() ou tracefs_kretprobe_raw() avec les mêmes paramètres.

VALEUR DE RETOUR

tracefs_kprobe_raw() et tracefs_kretprobe_raw() retournent 0 en cas de succès, ou -1 en cas d'erreur. Si une erreur d'analyse se produit pour tracefs_kprobe_raw() ou tracefs_kretprobe_raw(), alors tracefs_error_last(3) peut être utilisé pour récupérer le message d'erreur expliquant le problème d'analyse.

Les API tracefs_kprobe_alloc() et tracefs_kretprobe_alloc() retournent un pointeur vers une structure tracefs_dynevent allouée, décrivant la sonde. Ce pointeur doit être libéré par tracefs_dynevent_free(3). Notez que cela alloue seulement un descripteur représentant le kprobe. Cela ne modifie pas le système en cours d'exécution.

tracefs_kprobe_destroy() retourne 0 en cas de succès ou -1 en cas d'erreur s'il n'a pas pu détruire (ou trouver) le kprobe ou le kretprobe avec succès.

ERREURS

Les erreurs suivantes s'appliquent à tous les appels ci-dessus :

EPERM Non exécuté en tant qu'utilisateur root

ENODEV Les événements kprobe ne sont pas configurés pour le noyau en cours d'exécution.

ENOMEM Erreur d'allocation mémoire.

tracefs_kprobe_raw(), tracefs_kretprobe_raw(), tracefs_kprobe_alloc(), et tracefs_kretprobe_alloc() peuvent échouer avec les erreurs suivantes :

EBADMSG si addr est NULL.

EINVAL Très probablement une erreur d'analyse s'est produite (utilisez tracefs_error_last(3) pour éventuellement voir quelle était cette erreur).

D'autres erreurs peuvent également se produire en raison d'appels système internes.

#include <stdlib.h>

static struct tep_event *open_event;
static struct tep_format_field *file_field;
static struct tep_event *openret_event;
static struct tep_format_field *ret_field;
static int callback(struct tep_event *event, struct tep_record *record,
                    int cpu, void *data)
{
        struct trace_seq seq;
        trace_seq_init(&seq);
        tep_print_event(event->tep, &seq, record, "%d-%s: ", TEP_PRINT_PID, TEP_PRINT_COMM);
        if (event->id == open_event->id) {
                trace_seq_puts(&seq, "open file='");
                tep_print_field(&seq, record->data, file_field);
                trace_seq_puts(&seq, "'\n");
        } else if (event->id == openret_event->id) {
                unsigned long long ret;
                tep_read_number_field(ret_field, record->data, &ret);
                trace_seq_printf(&seq, "open ret=%lld\n", ret);
        } else {
                goto out;
        }
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
out:
        trace_seq_destroy(&seq);
        return 0;
}
static pid_t run_exec(char **argv, char **env)
{
        pid_t pid;
        pid = fork();
        if (pid)
                return pid;
        execve(argv[0], argv, env);
        perror("exec");
        exit(-1);
}
const char *mykprobe = "my_kprobes";
enum kprobe_type {
        KPROBE,
        KRETPROBE,
};
static void __kprobe_create(enum kprobe_type type, const char *event,
                            const char *addr, const char *fmt)
{
        char *err;
        int r;
        if (type == KPROBE)
                r = tracefs_kprobe_raw(mykprobe, event, addr, fmt);
        else
                r = tracefs_kretprobe_raw(mykprobe, event, addr, fmt);
        if (r < 0) {
                err = tracefs_error_last(NULL);
                perror("Failed to create kprobe:");
                if (err && strlen(err))
                        fprintf(stderr, "%s\n", err);
        }
}
static void kprobe_create(const char *event, const char *addr,
                          const char *fmt)
{
        __kprobe_create(KPROBE, event, addr, fmt);
}
static void kretprobe_create(const char *event, const char *addr,
                             const char *fmt)
{
        __kprobe_create(KRETPROBE, event, addr, fmt);
}
