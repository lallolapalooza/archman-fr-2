TRAMPOLINE(3) Manuel des fonctions de bibliothèque TRAMPOLINE(3)

NOM

trampoline - fermetures en tant que fonctions C de première classe

SYNTAXE

#include <trampoline.h>

function = alloc_trampoline(address, variable, data);

free_trampoline(function);

is_trampoline(function)
trampoline_address(function)
trampoline_variable(function)
trampoline_data(function)

DESCRIPTION

Ces fonctions implémentent des fermetures (closures) en tant que fonctions C de première classe. Une fermeture est constituée d'une fonction C ordinaire et d'un morceau de données qui est passé à la fonction C lorsque la fermeture est appelée.

Les fermetures en tant que fonctions C de première classe signifient qu'elles tiennent dans un pointeur de fonction et peuvent être appelées exactement comme n'importe quelle autre fonction C. function = alloc_trampoline(address, variable, data) alloue une fermeture. Lorsque function est appelé, il stocke data dans la variable variable et appelle la fonction C à l'adresse address. La fonction à l'adresse address est responsable de récupérer data de variable immédiatement, avant l'exécution de tout autre appel de fonction.

C'est très similaire aux fonctions locales de gcc, à la différence près que les fonctions locales de GNU C ont une étendue dynamique (c'est-à-dire qu'elles sont désallouées lorsque la fonction créatrice retourne), tandis que trampoline fournit des fonctions d'étendue indéfinie : function n'est désalloué que lorsque free_trampoline(function) est appelé.

is_trampoline(function) vérifie si la fonction C function a été produite par un appel à alloc_trampoline. Si cela renvoie vrai, les arguments donnés à alloc_trampoline peuvent être récupérés :

trampoline_address(function) retourne address,

trampoline_variable(function) retourne variable,

trampoline_data(function) retourne data.

VOIR AUSSI

gcc(1), stdarg(3), callback(3)

BOGUES

Le passage des données via une variable globale n'est pas réentrant. N'appelez pas les fonctions trampoline depuis des gestionnaires de signaux. Ceci est corrigé dans le paquet callback(3).

PORTAGE

La manière dont gcc construit les fonctions locales est décrite dans le code source de gcc, fichier gcc-2.6.3/config/cpu/cpu.h.
