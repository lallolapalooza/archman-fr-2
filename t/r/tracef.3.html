TRACEF(3) Manuel LTTng TRACEF(3)

NOM

tracef - Interface de type printf(3) de LTTng-UST

SYNTAXE

#include <lttng/tracef.h>
#define tracef(fmt, ...)

Lier avec -llttng-ust -llttng-ust-common.

DESCRIPTION

La macro tracef() fait partie de la version 0 de l'API LTTng-UST (voir la section « Compatibilité avec les API précédentes » de lttng-ust(3)).

Préférez utiliser lttng_ust_tracef(3) qui fait partie de la version 1 de l'API et possède l'espace de noms lttng_ust_.
