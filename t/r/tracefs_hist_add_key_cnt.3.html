NOM

tracefs_hist_alloc, tracefs_hist_alloc_2d, tracefs_hist_alloc_nd, tracefs_hist_alloc_nd_cnt, tracefs_hist_free, tracefs_hist_add_key, tracefs_hist_add_key_cnt, tracefs_hist_add_value - Créer et détruire des histogrammes d'événements

SYNTAXE

DESCRIPTION

Les histogrammes d'événements sont créés par le fichier trigger dans le répertoire de l'événement. La syntaxe peut être complexe et difficile à maîtriser. Cette API gère la syntaxe et facilite la création et l'interaction avec les histogrammes d'événements. Voir https://www.kernel.org/doc/html/latest/trace/histogram.html pour plus d'informations.

tracefs_hist_alloc() alloue un descripteur "struct tracefs_hist" pour un histogramme unidimensionnel et retourne son adresse. Ce descripteur doit être libéré par tracefs_hist_free(). Le paramètre tep est un handle d'événement de trace (voir tracefs_local_events(3)), qui contient le system et l'event auxquels l'histogramme sera attaché. Le system est le système ou le groupe de l'événement. L'event est l'événement auquel l'histogramme sera attaché. La key est un champ de l'événement qui sera utilisé comme clé (dimension) de l'histogramme. Le type est le type de la key. Voir TYPES DE CLÉS ci-dessous.

tracefs_hist_alloc_2d() alloue un descripteur "struct tracefs_hist" pour un histogramme bidimensionnel et retourne son adresse. Ce descripteur doit être libéré par tracefs_hist_free(). Le paramètre tep est un handle d'événement de trace (voir tracefs_local_events(3)), qui contient le system et l'event auxquels l'histogramme sera attaché. Le system est le système ou le groupe de l'événement. L'event est l'événement auquel l'histogramme sera attaché. La key1 est le premier champ de l'événement qui sera utilisé comme clé (dimension) de l'histogramme. Le type1 est le type de la key1. Voir TYPES DE CLÉS ci-dessous. La key2 est le second champ de l'événement qui sera utilisé comme clé (dimension) de l'histogramme. Le type2 est le type de la key2. Voir TYPES DE CLÉS ci-dessous.

tracefs_hist_alloc_nd() alloue un descripteur "struct tracefs_hist" pour un histogramme N-dimensionnel et retourne son adresse. Ce descripteur doit être libéré par tracefs_hist_free(). Le paramètre tep est un handle d'événement de trace (voir tracefs_local_events(3)), qui contient le system et l'event auxquels l'histogramme sera attaché. Le system est le système ou le groupe de l'événement. L'event est l'événement auquel l'histogramme sera attaché. Les axes sont un tableau de paires key / type, définissant les dimensions de l'histogramme.

tracefs_hist_alloc_nd_cnt() initialisera un descripteur d'histogramme qui sera attaché au system/event. Cela initialise seulement le descripteur avec les clés d'axes données comme primaires. Cela initialise seulement le descripteur, cela ne démarre pas l'histogramme dans le noyau. La différence entre ceci et tracefs_hist_alloc_nd() est que le paramètre axes est de type struct tracefs_hist_axis_cnt et non struct tracefs_hist_axis.

tracefs_hist_free() libère le descripteur tracefs_hist. Notez qu'elle n'arrête ni ne désactive pas l'histogramme en cours s'il était démarré. tracefs_hist_destroy() doit être appelée pour le faire.

tracefs_hist_add_key() ajoute une clé secondaire ou tertiaire à l'histogramme. La clé passée à tracefs_hist_alloc_nd() est la clé primaire de l'histogramme. La première fois que cette fonction est appelée, elle ajoutera une clé secondaire (ou un histogramme bidimensionnel). Si cette fonction est appelée à nouveau sur le même histogramme, elle ajoutera une clé tertiaire (ou un histogramme tridimensionnel). Le paramètre hist est le descripteur d'histogramme auquel ajouter la key. Le type est le type de clé à ajouter (Voir TYPES DE CLÉS ci-dessous).

La fonction tracefs_hist_add_key_cnt() est identique à tracefs_hist_add_key() sauf qu'elle permet d'ajouter un compteur pour le type donné. Actuellement, seul le type buckets nécessite un compteur. Lors de l'ajout d'une clé de type buckets, tracefs_hist_add_key() n'est pas suffisant, car le type buckets nécessite un compteur ou une taille de bucket. Utilisez tracefs_hist_add_key_cnt() lors de la spécification d'une clé qui est divisée en buckets, et passez la taille de ces buckets dans cnt.

tracefs_hist_add_value() ajoutera une valeur à enregistrer. Par défaut, la valeur est simplement le "hitcount", c'est-à-dire le nombre de fois où une instance de la clé de l'histogramme a été rencontrée. Le paramètre hist est le descripteur d'histogramme auquel ajouter la valeur. La value est un champ dans l'histogramme à ajouter lorsqu'une instance de la clé est rencontrée.

TYPES DE CLÉS

tracefs_hist_alloc_nd() et tracefs_hist_add_key() ajoutent tous deux une clé et nécessitent que cette clé ait un type. Les types peuvent être :

TRACEFS_HIST_KEY_NORMAL ou zéro (0) pour ne pas modifier le type.

TRACEFS_HIST_KEY_HEX pour afficher la clé en hexadécimal.

TRACEFS_HIST_KEY_SYM pour afficher la clé comme un symbole du noyau (s'il est trouvé). Si la clé est une adresse, c'est utile car cela affichera les noms de fonctions au lieu d'un simple nombre.

TRACEFS_HIST_KEY_SYM_OFFSET similaire à TRACEFS_HIST_KEY_SYM mais inclura également le décalage de la fonction pour correspondre à l'adresse exacte.

TRACEFS_HIST_KEY_SYSCALL Si la clé est un identifiant d'appel système (le numéro passé de l'espace utilisateur au noyau pour lui indiquer quel appel système il effectue), alors le nom de l'appel système sera affiché.

TRACEFS_HIST_KEY_EXECNAME Si "common_pid" est la clé (le pid de la tâche en cours d'exécution), au lieu d'afficher le nombre, le nom de la tâche en cours d'exécution sera affiché.

TRACEFS_HIST_KEY_LOG affichera la clé sur une échelle logarithmique binaire.

TRACEFS_HIST_KEY_USECS à utiliser avec "common_timestamp" ou TRACEFS_HIST_TIMESTAMP, auquel cas il affichera le timestamp en microsecondes au lieu de nanosecondes.

VALEUR DE RETOUR

tracefs_hist_alloc_nd() retourne un descripteur d'histogramme alloué qui doit être libéré par tracefs_hist_free() ou NULL en cas d'erreur.

Toutes les autres fonctions retournent zéro en cas de succès et -1 en cas d'erreur.

Si tracefs_hist_start() retourne une erreur, un message peut être affiché dans le noyau et récupéré par tracefs_error_last().

Voir aussi tracefs_hist_destroy(3), tracefs_hist_start(3), tracefs_hist_stop(3), tracefs_hist_read(3), tracefs_hist_dump(3), tracefs_hist_name(3), tracefs_hist_id(3), tracefs_hist_trigger(3), tracefs_hist_event(3), tracefs_hist_fields(3), tracefs_hist_keys(3), tracefs_hist_key_(3), tracefs_hist_values(3), tracefs_hist_value_(3).

EXEMPLE

#include <stdlib.h>
#include <ctype.h>
#include <unistd.h>
#include <tracefs.h>
enum commands {
        START,
        PAUSE,
        CONT,
        RESET,
        DELETE,
        SHOW,
};
static void parse_system_event(char *group, char **system, char **event)
{
        *system = strtok(group, "/");
        *event = strtok(NULL, "/");
        if (!*event) {
                *event = *system;
                *system = NULL;
        }
}
static int parse_keys(char *keys, struct tracefs_hist_axis_cnt **axes)
{
        char *sav = NULL;
        char *key;
        int cnt = 0;
        for (key = strtok_r(keys, ",", &sav); key; key = strtok_r(NULL, ",", &sav)) {
                struct tracefs_hist_axis_cnt *ax;
                char *att;
                ax = realloc(*axes, sizeof(*ax) * (cnt + 2));
                if (!ax) {
                        perror("Échec de l'allocation des axes");
                        exit(-1);
                }
                ax[cnt].key = key;
                ax[cnt].type = 0;
                ax[cnt + 1].key = NULL;
                ax[cnt + 1].type = 0;
                *axes = ax;
                att = strchr(key, '.');
                if (att) {
                        *att++ = '\0';
                        if (strcmp(att, "hex") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_HEX;
                        else if (strcmp(att, "sym") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM;
                        else if (strcmp(att, "sym_offset") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM_OFFSET;
                        else if (strcmp(att, "syscall") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYSCALL;
                        else if (strcmp(att, "exec") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_EXECNAME;
                        else if (strcmp(att, "log") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_LOG;
                        else if (strcmp(att, "usecs") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_USECS;
                        else if (strncmp(att, "buckets", 7) == 0) {
                                if (att[7] != '=' && !isdigit(att[8])) {
                                        fprintf(stderr, "Le type de clé 'buckets' nécessite '=<taille>'\n");
                                        exit(-1);
                                }
                                ax[cnt].type = TRACEFS_HIST_KEY_BUCKETS;
                                ax[cnt].cnt = atoi(&att[8]);
                        } else {
                                fprintf(stderr, "Attribute non défini '%s'\n", att);
                                fprintf(stderr,"  Attributs acceptables :\n");
                                fprintf(stderr,"    hex, sym, sym_offset, syscall, exe, log, usecs\n");
                                exit(-1);
                        }
                }
                cnt++;
        }
        return cnt;
}
static void process_hist(enum commands cmd, const char *instance_name,
                         char *group, char *keys, char *vals, char *sort,
                         char *ascend, char *desc)
{
        struct tracefs_instance *instance = NULL;
        struct tracefs_hist *hist;
        struct tep_handle *tep;
        struct tracefs_hist_axis_cnt *axes = NULL;
        char *system;
        char *event;
        char *sav;
        char *val;
        int ret;
        int cnt;
        if (instance_name) {
                instance = tracefs_instance_create(instance_name);
                if (!instance) {
                        fprintf(stderr, "Échec de la création de l'instance\n");
                        exit(-1);
                }
        }
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("Impossible de lire les événements");
                exit(-1);
        }
        parse_system_event(group, &system, &event);
        if (cmd == SHOW) {
                char *content;
                content = tracefs_event_file_read(instance, system, event,
                                                  "hist", NULL);
                if (!content) {
                        perror("Erreur de lecture du fichier hist");
                        exit(-1);
                }
                printf("%s\n", content);
                free(content);
                return;
        }
        if (!keys) {
                fprintf(stderr, "La commande nécessite l'option -k\n");
                exit(-1);
        }
        cnt = parse_keys(keys, &axes);
        if (!cnt) {
                fprintf(stderr, "Aucune clé ??\n");
                exit(-1);
        }
        /* buckets requiert la fonction nd_cnt */
        switch (cnt) {
        case 2:
                if (axes[1].type == TRACEFS_HIST_KEY_BUCKETS)
                        cnt = -1;
                /* fall through */
        case 1:
                if (axes[0].type == TRACEFS_HIST_KEY_BUCKETS)
                        cnt = -1;
        }
        /* Afficher des exemples de hist1d et hist2d */
        switch (cnt) {
        case 1:
                hist = tracefs_hist_alloc(tep, system, event,
                                          axes[0].key, axes[0].type);
                break;
        case 2:
                hist = tracefs_hist_alloc_2d(tep, system, event,
                                             axes[0].key, axes[0].type,
                                             axes[1].key, axes[1].type);
                break;
        default:
                /* Vraiment, 1 et 2 pourraient aussi utiliser ceci */
                hist = tracefs_hist_alloc_nd_cnt(tep, system, event, axes);
        }
        if (!hist) {
                fprintf(stderr, "Échec de la création de l'hist");
                exit(-1);
        }
        if (vals) {
                sav = NULL;
                for (val = strtok_r(vals, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_value(hist, val);
                        if (ret) {
                                fprintf(stderr, "Échec de l'ajout de la valeur %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (sort) {
                sav = NULL;
                for (val = strtok_r(sort, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_sort_key(hist, val);
                        if (ret) {
                                fprintf(stderr, "Échec de l'ajout de la clé/valeur de tri %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (ascend) {
                sav = NULL;
                for (val = strtok_r(ascend, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_ASCENDING);
                        if (ret) {
                                fprintf(stderr, "Échec de l'ajout de la clé/valeur ascendante %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (desc) {
                sav = NULL;
                for (val = strtok_r(desc, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_DESCENDING);
                        if (ret) {
                                fprintf(stderr, "Échec de l'ajout de la clé/valeur descendante %s\n", val);
                                exit(-1);
                        }
                }
        }
        tracefs_error_clear(instance);
        switch (cmd) {
        case START:
                ret = tracefs_hist_start(instance, hist);
                if (ret) {
                        char *err = tracefs_error_last(instance);
                        if (err)
                                fprintf(stderr, "\n%s\n", err);
                }
                break;
        case PAUSE:
                ret = tracefs_hist_pause(instance, hist);
                break;
        case CONT:
                ret = tracefs_hist_continue(instance, hist);
                break;
        case RESET:
                ret = tracefs_hist_reset(instance, hist);
                break;
        case DELETE:
                ret = tracefs_hist_destroy(instance, hist);
                break;
        case SHOW:
                /* SHOW a déjà été traité */
                break;
        }
        if (ret)
                fprintf(stderr, "Échec : commande\n");
        exit(ret);
}
int main (int argc, char **argv, char **env)
{
        enum commands cmd;
        char *instance = NULL;
        char *cmd_str;
        char *event = NULL;
        char *keys = NULL;
        char *vals = NULL;
        char *sort = NULL;
        char *desc = NULL;
        char *ascend = NULL;
        if (argc < 2) {
                fprintf(stderr, "utilisation : %s commande [-B instance][-e [system/]événement][-k clés][-v valeurs][-s tri]\n", argv[0]);
                fprintf(stderr, "      [-a ascendant][-d descendant]\n");
                exit(-1);
        }
        cmd_str = argv[1];
        if (!strcmp(cmd_str, "start"))
                cmd = START;
        else if (!strcmp(cmd_str, "pause"))
                cmd = PAUSE;
        else if (!strcmp(cmd_str, "cont"))
                cmd = CONT;
        else if (!strcmp(cmd_str, "reset"))
                cmd = RESET;
        else if (!strcmp(cmd_str, "delete"))
                cmd = DELETE;
        else if (!strcmp(cmd_str, "show"))
                cmd = SHOW;
        else {
                fprintf(stderr, "Commande inconnue %s\n", cmd_str);
                exit(-1);
        }
        for (;;) {
                int c;
                c = getopt(argc - 1, argv + 1, "e:k:v:B:s:d:a:");
                if (c == -1)
                        break;
                switch (c) {
                case 'e':
                        event = optarg;
                        break;
                case 'k':
                        keys = optarg;
                        break;
                case 'v':
                        vals = optarg;
                        break;
                case 'B':
                        instance = optarg;
                        break;
                case 's':
                        sort = optarg;
                        break;
                case 'd':
                        desc = optarg;
                        break;
                case 'a':
                        ascend = optarg;
                        break;
                }
        }
        if (!event) {
                event = "kmem/kmalloc";
                if (!keys)
                        keys = "call_site.sym,bytes_req";
                if (!vals)
                        vals = "bytes_alloc";
                if (!sort)
                        sort = "bytes_req,bytes_alloc";
                if (!desc)
                        desc = "bytes_alloc";
        }
        process_hist(cmd, instance, event, keys, vals, sort, ascend, desc);
}

NOM

tracefs_hist_add_key_cnt - ajoute une clé à un histogramme

SYNOPIS

#include <tracefs.h>
 int
tracefs_hist_add_key_cnt(const char *name, unsigned int type,
     const void *key, size_t key_size);

DESCRIPTION

La fonction tracefs_hist_add_key_cnt ajoute une clé à un histogramme qui sera écrit dans le fichier spécial /sys/kernel/tracing/trace_events_hist/name.

Le paramètre name est le nom de l'événement d'histogramme.

Le paramètre type spécifie le type de la clé. Les types de clés sont définis dans le fichier tracefs.h.

Le paramètre key est un pointeur vers les données de la clé.

Le paramètre key_size est la taille en octets des données de la clé.

TYPES DE CLÉS

Les types de clés pris en charge sont les suivants :

TRACEFS_HIST_KEY_TYPE_STRING
La clé est une chaîne de caractères se terminant par un octet nul.
TRACEFS_HIST_KEY_TYPE_UINT8
La clé est un entier non signé de 8 bits.
TRACEFS_HIST_KEY_TYPE_UINT16
La clé est un entier non signé de 16 bits.
TRACEFS_HIST_KEY_TYPE_UINT32
La clé est un entier non signé de 32 bits.
TRACEFS_HIST_KEY_TYPE_UINT64
La clé est un entier non signé de 64 bits.

VALEUR DE RETOUR

En cas de succès, tracefs_hist_add_key_cnt retourne 0. En cas d'erreur, elle retourne un code d'erreur négatif.

EXEMPLE

char *key_str = "my_string";
unsigned int key_uint = 123;
int ret;

ret = tracefs_hist_add_key_cnt("my_event", TRACEFS_HIST_KEY_TYPE_STRING,
    key_str, strlen(key_str) + 1);
if (ret < 0) {
    perror("tracefs_hist_add_key_cnt");
    return 1;
}

ret = tracefs_hist_add_key_cnt("my_event", TRACEFS_HIST_KEY_TYPE_UINT32,
    &key_uint, sizeof(key_uint));
if (ret < 0) {
    perror("tracefs_hist_add_key_cnt");
    return 1;
}
