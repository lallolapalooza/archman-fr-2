trace_seq_puts(3)

Paquet: libtraceevent

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) Manuel libtraceevent LIBTRACEEVENT(3)

NOM

trace_seq_init, trace_seq_destroy, trace_seq_reset, trace_seq_terminate, trace_seq_putc, trace_seq_puts, trace_seq_printf, trace_seq_vprintf, trace_seq_do_fprintf, trace_seq_do_printf - Initialise / détruit une séquence de trace.

SYNOPSIS

#include <event-parse.h>
#include <trace-seq.h>
void trace_seq_init(struct trace_seq *s);
void trace_seq_destroy(struct trace_seq *s);
void trace_seq_reset(struct trace_seq *s);
void trace_seq_terminate(struct trace_seq *s);
int trace_seq_putc(struct trace_seq *s, unsigned char c);
int trace_seq_puts(struct trace_seq *s, const char *str);
int trace_seq_printf(struct trace_seq *s, const char *fmt, ...);
int trace_seq_vprintf(struct trace_seq *s, const char *fmt, va_list args);
int trace_seq_do_printf(struct trace_seq *s);
int trace_seq_do_fprintf(struct trace_seq *s, FILE *fp);

DESCRIPTION

Les séquences de trace sont utilisées pour permettre à une fonction d'appeler plusieurs autres fonctions afin de créer une chaîne de données à utiliser.

La fonction trace_seq_init() initialise la séquence de trace s.

La fonction trace_seq_destroy() détruit la séquence de trace s et libère toutes les ressources qu'elle avait utilisées.

La fonction trace_seq_reset() réinitialise la séquence de trace s. Tous les caractères déjà écrits dans s seront supprimés.

La fonction trace_seq_terminate() termine la séquence de trace s. Elle place le caractère nul '\0' à la fin du tampon.

La fonction trace_seq_putc() insère un seul caractère c dans la séquence de trace s.

La fonction trace_seq_puts() insère une chaîne terminée par un caractère nul str dans la séquence de trace s.

La fonction trace_seq_printf() insère une chaîne formatée fmt _avec arguments variables _... dans la séquence de trace s.

La fonction trace_seq_vprintf() insère une chaîne formatée fmt _avec une liste d'arguments _args dans la séquence de trace s.

La fonction trace_seq_do_printf() affiche le tampon de la séquence de trace s sur la sortie standard stdout.

La fonction trace_seq_do_fprintf() affiche le tampon de la séquence de trace s dans le fichier donné fp.

VALEUR DE RETOUR

Les fonctions trace_seq_putc() et trace_seq_puts() renvoient le nombre de caractères insérés dans la séquence de trace, ou 0 en cas d'erreur.

Les fonctions trace_seq_printf() et trace_seq_vprintf() renvoient 0 si la trace dépasse l'espace libre du tampon, le nombre de caractères imprimés, ou une valeur négative en cas d'erreur.

Les fonctions trace_seq_do_printf() et trace_seq_do_fprintf() renvoient le nombre de caractères imprimés, ou -1 en cas d'erreur.

EXEMPLE

#include <event-parse.h>
#include <trace-seq.h>
...
struct trace_seq seq;
trace_seq_init(&seq);
...
void foo_seq_print(struct trace_seq *tseq, char *format, ...)
{
        va_list ap;
        va_start(ap, format);
        if (trace_seq_vprintf(tseq, format, ap) <= 0) {
                /* Échec de l'impression dans la séquence de trace */
        }
        va_end(ap);
}
trace_seq_reset(&seq);
char *str = " Exemple de page man";
if (trace_seq_puts(&seq, str) != strlen(str)) {
        /* Échec de l'insertion de str dans la séquence de trace */
}
if (trace_seq_putc(&seq, ':') != 1) {
        /* Échec de l'insertion de ':' dans la séquence de trace */
}
if (trace_seq_printf(&seq, " séquence de trace: %d", 1) <= 0) {
        /* Échec de l'impression dans la séquence de trace */
}
foo_seq_print( &seq, "  %d\n", 2);
trace_seq_terminate(&seq);
...
if (trace_seq_do_printf(&seq) < 0 ) {
        /* Échec de l'impression du tampon de séquence sur la sortie standard */
}
FILE *fp = fopen("trace.txt", "w");
if (trace_seq_do_fprintf(&seq, fp) < 0 ) [
        /* Échec de l'impression du tampon de séquence dans le fichier trace.txt */
}
trace_seq_destroy(&seq);
...
