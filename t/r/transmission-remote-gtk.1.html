NOM

transmission-remote-gtk - Client RPC pour le client bittorrent Transmission.

SYNTAXE

transmission-remote-gtk [OPTIONS] [fichier torrent|lien magnet|url]

DESCRIPTION

transmission-remote-gtk est une application de gestion à distance du client BitTorrent Transmission utilisant son interface RPC.

OPTIONS

Les options suivantes sont acceptées lors de l'exécution de "transmission-remote-gtk" :

-m, --minimized, /m
Démarrer l'application minimisée.

ENVIRONNEMENT

Les variables d'environnement suivantes peuvent être utilisées lors de l'exécution de "transmission-remote-gtk" :

$TRG_CLIENT_DEBUG
Lorsque cet environnement est défini, des informations HTTP et JSON verbeuses seront enregistrées sur la sortie standard à des fins de débogage.
