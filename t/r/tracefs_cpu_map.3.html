LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_cpu_open_mapped, tracefs_cpu_is_mapped, tracefs_mapped_is_supported, tracefs_cpu_map, tracefs_cpu_unmap - Mappage mémoire du tampon circulaire

SYNOPSIS

#include <tracefs.h>
bool tracefs_cpu_is_mapped(struct tracefs_cpu *tcpu);
bool tracefs_mapped_is_supported(void);
int tracefs_cpu_map(struct tracefs_cpu *tcpu);
void tracefs_cpu_unmap(struct tracefs_cpu *tcpu);
struct tracefs_cpu *tracefs_cpu_open_mapped(struct tracefs_instance *instance,
                                            int cpu, bool nonblock);

DESCRIPTION

Si trace_pipe_raw prend en charge le mappage mémoire, il s'agit généralement d'une méthode plus efficace pour diffuser des données depuis le tampon circulaire du noyau que de les lire, car elle ne nécessite pas la copie de la mémoire qui est lue.

Si le mappage mémoire est pris en charge par le noyau et que l'application demande à utiliser le mappage mémoire via tracefs_cpu_map() ou tracefs_cpu_open_mapped(), alors les fonctions tracefs_cpu_read(3) et tracefs_cpu_read_buf(3) utiliseront directement le mappage au lieu d'appeler l'appel système read.

Notez que le mappage fera agir tracefs_cpu_buffered_read(3) et tracefs_cpu_buffered_read_buf(3) comme tracefs_cpu_read(3) et tracefs_cpu_read_buf(3) respectivement, car il n'est pas judicieux d'utiliser un tuyau splice lorsqu'il est mappé. Le noyau effectuera une copie pour les lectures splice sur le mappage, puis une autre copie dans la fonction lorsqu'il peut éviter les copies si le tampon circulaire est en mémoire mappée.

Si le tcpu est mappé en mémoire, cela forcera également tracefs_cpu_write(3) et tracefs_cpu_pipe(3) à copier depuis le mappage au lieu d'utiliser splice. Il faut donc faire attention lors de la décision de mapper ou non le tampon circulaire, et pourquoi il n'est pas mappé par défaut.

La fonction tracefs_cpu_is_mapped() renverra vrai si tcpu a actuellement son tampon circulaire mappé en mémoire et faux sinon. Cela ne renvoie pas si le noyau prend en charge le mappage mémoire ou non, mais cela peut généralement être déterminé en appelant tracefs_cpu_map().

La fonction tracefs_mapped_is_supported() renvoie vrai si le tampon circulaire peut être mappé en mémoire.

La fonction tracefs_cpu_map() tentera de mapper le tampon circulaire associé à tcpu s'il n'est pas déjà mappé.

La fonction tracefs_cpu_unmap() annulera le mappage du tampon circulaire associé à tcpu s'il est mappé.

La fonction tracefs_cpu_open_mapped() est équivalente à un appel à tracefs_cpu_open(3) suivi d'un appel à tracefs_cpu_map() sur le tcpu retourné par tracefs_cpu_open(3). Notez que cela réussira même si le mappage échoue, auquel cas cela agit de la même manière que tracefs_cpu_open(3). Si l'on veut savoir si le mappage a réussi ou non, il faut appeler tracefs_cpu_is_mapped() sur le tcpu retourné.

VALEUR RETOURNEE

tracefs_cpu_is_mapped() renvoie vrai si le tcpu donné a son tampon circulaire mappé en mémoire ou faux sinon.

tracefs_mapped_is_supported() renvoie vrai si le tampon circulaire de traçage peut être mappé en mémoire, ou faux s'il ne le peut pas ou si une erreur s'est produite.

tracefs_cpu_map() renvoie 0 en cas de succès et -1 en cas d'erreur de mappage. Si 0 est renvoyé, tracefs_cpu_is_mapped() renverra vrai ensuite, ou faux si le mappage a échoué.

tracefs_cpu_open_mapped() renvoie un tracefs_cpu alloué en cas de succès de la création, que le mappage du tampon circulaire ait réussi ou non. Il renvoie NULL pour les mêmes raisons que tracefs_cpu_open(3) renvoie NULL. Si le succès du mappage doit être connu, il est nécessaire d'appeler tracefs_cpu_is_mapped() ensuite.

EXEMPLE

#include <stdlib.h>
#include <ctype.h>
#include <tracefs.h>
static void read_subbuf(struct tep_handle *tep, struct kbuffer *kbuf)
{
        static struct trace_seq seq;
        struct tep_record record;
        int missed_events;
        if (seq.buffer)
                trace_seq_reset(&seq);
        else
                trace_seq_init(&seq);
        while ((record.data = kbuffer_read_event(kbuf, &record.ts))) {
                record.size = kbuffer_event_size(kbuf);
                missed_events = kbuffer_missed_events(kbuf);
                if (missed_events) {
                        printf("[MISSED EVENTS");
                        if (missed_events > 0)
                                printf(": %d]\n", missed_events);
                        else
                                printf("]\n");
                }
                kbuffer_next_event(kbuf, NULL);
                tep_print_event(tep, &seq, &record,
                                "%s-%d %6.1000d\t%s: %s\n",
                                TEP_PRINT_COMM,
                                TEP_PRINT_PID,
                                TEP_PRINT_TIME,
                                TEP_PRINT_NAME,
                                TEP_PRINT_INFO);
                trace_seq_do_printf(&seq);
                trace_seq_reset(&seq);
        }
}
int main (int argc, char **argv)
{
        struct tracefs_cpu *tcpu;
        struct tep_handle *tep;
        struct kbuffer *kbuf;
        bool mapped;
        int cpu;
        if (argc < 2 || !isdigit(argv[1][0])) {
                printf("usage: %s cpu\n\n", argv[0]);
                exit(-1);
        }
        cpu = atoi(argv[1]);
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("Reading trace event formats");
                exit(-1);
        }
        tcpu = tracefs_cpu_open_mapped(NULL, cpu, 0);
        if (!tcpu) {
                perror("Open CPU 0 file");
                exit(-1);
        }
        /*
         * If this kernel supports mapping, use normal read,
         * otherwise use the piped buffer read, although if
         * the mapping succeeded, tracefs_cpu_buffered_read_buf()
         * acts the same as tracefs_cpu_read_buf(). But this is just
         * an example on how to use tracefs_cpu_is_mapped().
         */
        mapped = tracefs_cpu_is_mapped(tcpu);
        if (!mapped)
                printf("Was not able to map, falling back to buffered read\n");
        while ((kbuf = mapped ? tracefs_cpu_read_buf(tcpu, true) :
                        tracefs_cpu_buffered_read_buf(tcpu, true))) {
                read_subbuf(tep, kbuf);
        }
        kbuf = tracefs_cpu_flush_buf(tcpu);
        if (kbuf)
                read_subbuf(tep, kbuf);
        tracefs_cpu_close(tcpu);
        tep_free(tep);
        return 0;
}
