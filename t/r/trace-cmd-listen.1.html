NOM

trace-cmd-listen - écoute les connexions entrantes pour enregistrer le traçage.

SYNTAXE

trace-cmd listen -p port [OPTIONS]

DESCRIPTION

trace-cmd(1) listen configure un port pour écouter les connexions entrantes provenant d'autres hôtes exécutant trace-cmd-record(1) avec l'option -N. Lorsqu'une connexion est établie et que l'hôte distant envoie des données, un fichier nommé trace.HÔTE:PORT.dat sera créé. Où HÔTE est le nom de l'hôte distant et PORT est le port utilisé par l'hôte distant pour se connecter.

OPTIONS

-p port

Cette option spécifie le port sur lequel écouter.

-D

Cette option fait passer trace-cmd listen en mode démon et l'exécute en arrière-plan.

-V

Écoute sur un vsocket à la place. Ceci est utile pour le traçage entre un hôte et des machines virtuelles invitées.

-d répertoire

Cette option spécifie un répertoire dans lequel écrire les fichiers de données.

-o nom_fichier

Cette option remplace le préfixe par défaut trace dans le nom de fichier trace.HÔTE:PORT.dat créé lorsqu'un hôte distant se connecte.

-l nom_fichier

Cette option écrit les messages de sortie dans un fichier journal au lieu de la sortie standard.

--verbose[=niveau]

Définit le niveau de journalisation. Les niveaux de journalisation pris en charge sont "none", "critical", "error", "warning", "info", "debug", "all" ou leurs identifiants "0", "1", "2", "3", "4", "5", "6". La définition du niveau de journalisation à une valeur spécifique active tous les journaux à partir de ce niveau et des niveaux précédents. Le niveau sera par défaut "info" s'il n'est pas spécifié. 
Exemple : activer tous les journaux critiques, d'erreur et d'avertissement
trace-cmd listen --verbose=warning
