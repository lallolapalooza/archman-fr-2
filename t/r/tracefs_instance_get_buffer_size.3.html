LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_instance_get_name, tracefs_instance_get_trace_dir, tracefs_instances_walk, tracefs_instance_exists, tracefs_instance_get_buffer_size, tracefs_instance_set_buffer_size, tracefs_instance_get_buffer_percent, tracefs_instance_set_buffer_percent - Fonctions d'aide pour travailler avec les instances de traçage.

SYNOPIS

#include <tracefs.h>
const char *tracefs_instance_get_name(struct tracefs_instance *instance);
const char *tracefs_instance_get_trace_dir(struct tracefs_instance *instance);
int tracefs_instances_walk(int (*callback)(const char *, void *), void *context);
bool tracefs_instance_exists(const char *name);
size_t tracefs_instance_get_buffer_size(struct tracefs_instance *instance, int cpu);
int tracefs_instance_set_buffer_size(struct tracefs_instance *instance, size_t size, int cpu);
int tracefs_instance_get_buffer_percent(struct tracefs_instance *instance);
int tracefs_instance_set_buffer_percent(struct tracefs_instance *instance, int val);

DESCRIPTION

Fonctions d'aide pour travailler avec les instances de traçage.

La fonction tracefs_instance_get_name() renvoie le nom de l'instance instance donnée. Notez que l'instance supérieure n'a pas de nom, la fonction renvoie NULL pour celle-ci.

La fonction tracefs_instance_get_trace_dir() renvoie le répertoire de traçage, où l'instance instance est configurée.

La fonction tracefs_instances_walk() parcourt toutes les instances de traçage configurées sur le système et appelle callback pour chacune d'elles. L'argument context est passé au callback, avec le nom de l'instance. Si le callback renvoie une valeur non nulle, l'itération s'arrête. Notez que le callback n'est pas appelé pour l'instance supérieure.

La fonction tracefs_instance_exists() vérifie si une instance avec le nom name donné existe sur le système.

La fonction tracefs_instace_get_buffer_size() renvoie la taille du tampon circulaire. Si cpu est négatif, elle renvoie la taille totale de tous les tampons circulaires par CPU, sinon elle renvoie la taille du tampon circulaire par CPU pour le CPU cpu.

La fonction tracefs_instance_set_buffer_size() définit la taille du tampon circulaire. Si cpu est négatif, elle définit tous les tampons circulaires par CPU à size (notez que la taille totale est le nombre de CPU * size). Si cpu est spécifié, elle ne définit que la taille du tampon circulaire par CPU.

La fonction tracefs_instance_set_buffer_percent() définit la valeur du pourcentage du tampon de l'anneau de traçage pour instance ou le tampon de niveau supérieur si instance est NULL. Le pourcentage du tampon décide quand les lecteurs sur tracefs_cpu_read(3), tracefs_cpu_buffered_read(3), tracefs_cpu_write(3) et tracefs_cpu_pipe(3) seront bloqués lorsque O_NONBLOCK n'est pas défini. La valeur de val doit être comprise entre 0 et 100, où :

  0   - blocage jusqu'à ce qu'il y ait des données dans le tampon circulaire
  1   - blocage jusqu'à ce que 1% des sous-tampons du tampon circulaire soient remplis
  50  - blocage jusqu'à ce que 50% des sous-tampons du tampon circulaire soient remplis
  100 - blocage jusqu'à ce que l'intégralité du tampon circulaire soit remplie

Notez que tout nombre de 0 à 100 peut être utilisé, où il représente le pourcentage du tampon circulaire qui doit être rempli avant qu'un lecteur bloqué ne soit averti qu'il y a des données à récupérer.

La fonction tracefs_instance_get_buffer_percent() récupère le réglage actuel du pourcentage du tampon de l'anneau de traçage pour instance ou le tampon de niveau supérieur si instance est NULL.

VALEUR DE RETOUR

La fonction tracefs_instance_get_name() renvoie une chaîne ou NULL dans le cas de l'instance supérieure. La chaîne renvoyée ne doit pas être libérée.

La fonction tracefs_instance_get_trace_dir() renvoie une chaîne ou NULL en cas d'erreur. La chaîne renvoyée ne doit pas être libérée.

La fonction tracefs_instances_walk() renvoie 0 si toutes les instances ont été parcourues, 1 si l'itération a été arrêtée par le callback, ou -1 en cas d'erreur.

La fonction tracefs_instance_exists() renvoie true si une instance avec le nom name donné existe sur le système, ou false sinon.

La fonction tracefs_instance_get_buffer_size() renvoie la taille du tampon circulaire en fonction de la valeur cpu passée, ou -1 en cas d'erreur.

La fonction tracefs_instance_set_buffer_size() renvoie zévo en cas de succès et -1 en cas d'erreur.

tracefs_instance_get_buffer_size.3

NOM

tracefs_instance_get_buffer_size - Obtenir la taille du tampon d'une instance tracefs

SYNTAXE

#include <tracefs.h>

size_t tracefs_instance_get_buffer_size(tracefs_instance_t *instance);

DESCRIPTION

La fonction tracefs_instance_get_buffer_size récupère la taille du tampon d'une instance tracefs donnée.

VALEUR DE RETOUR

En cas de succès, la taille du tampon est retournée en octets. En cas d'erreur, 0 est retourné.

EXEMPLE

#include <stdio.h>
#include <tracefs.h>

int main() {
    tracefs_instance_t *instance;
    size_t buffer_size;

    // Initialiser une instance tracefs
    instance = tracefs_init("my_trace");
    if (!instance) {
        perror("tracefs_init");
        return 1;
    }

    // Obtenir la taille du tampon
    buffer_size = tracefs_instance_get_buffer_size(instance);
    if (buffer_size == 0) {
        fprintf(stderr, "Impossible d'obtenir la taille du tampon.\n");
    } else {
        printf("La taille du tampon est : %zu octets\n", buffer_size);
    }

    // Nettoyer l'instance tracefs
    tracefs_free(instance);

    return 0;
}
