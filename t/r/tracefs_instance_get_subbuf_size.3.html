tracefs_instance_get_subbuf_size(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_instance_get_subbuf_size, tracefs_instance_set_subbuf_size - Fonctions d'aide pour travailler avec les sous-buffers de l'anneau.

SYNOPIS

#include <tracefs.h>
size_t tracefs_instance_get_subbuf_size(struct tracefs_instance *instance);
int tracefs_instance_set_subbuf_size(struct tracefs_instance *instance, size_t size);

DESCRIPTION

Fonctions d'aide pour travailler avec les sous-buffers de l'anneau de traçage. L'anneau de traçage est divisé en sous-buffers. Un événement ne peut pas être plus grand que la section de données du sous-buffer (voir tep_get_sub_buffer_data_size(3)). Par défaut, l'anneau utilise la taille de page de l'architecture comme taille par défaut du sous-buffer, mais cela peut être limitatif s'il y a un besoin pour de grands événements, par exemple, si l'application veut écrire de grandes chaînes dans le fichier trace_marker.

La fonction tracefs_instance_get_subbuf_size() renvoie la taille actuelle en kilo-octets des sous-buffers de l'anneau.

La fonction tracefs_instance_set_subbuf_size() écrira la taille en kilo-octets de ce que devrait être la nouvelle taille du sous-buffer. Notez qu'il ne s'agit que d'une indication de la taille minimale du sous-buffer. Elle ne prend pas non plus en compte les métadonnées utilisées par le sous-buffer, donc la taille écrite ne devrait pas être inférieure de 16 octets à la taille maximale de l'événement qui sera utilisé. Le noyau rendra probablement la taille du sous-buffer plus grande que celle spécifiée, car il pourrait avoir besoin d'aligner la taille pour des raisons d'implémentation.

VALEUR RENVOYÉE

La fonction tracefs_instance_get_subbuf_size() renvoie la taille du sous-buffer courant pour l'anneau donné instance ou -1 en cas d'erreur.

La fonction tracefs_instance_set_subbuf_size() renverra 0 si elle a réussi à définir la taille du sous-buffer de l'anneau instance en kilo-octets, ou -1 en cas d'erreur.

EXEMPLE

#include <stdlib.h>
#include <tracefs.h>
#include <errno.h>
int main(int argc, char **argv)
{
        struct tep_handle *tep;
        ssize_t save_subsize;
        ssize_t subsize;
        char *trace;
        char buf[3000];
        int meta_size;
        int ret;
        int i;
        tep = tep_alloc();
        ret = tracefs_load_headers(NULL, tep);
        tep_free(tep);
        if (ret < 0) {
                perror("reading headers");
                exit(-1);
        }
        meta_size = tep_get_sub_buffer_size(tep) - tep_get_sub_buffer_data_size(tep);
        save_subsize = tracefs_instance_get_subbuf_size(NULL);
        if (save_subsize < 0) {
                printf("Changing sub-buffer size not available\n");
                exit(-1);
        }
        subsize = save_subsize * 1024;
        /* Have at least 4 writes fit on a sub-buffer */
        if (subsize - meta_size < sizeof(buf) *4 ) {
                subsize = ((sizeof(buf) * 4 + meta_size) + 1023) / 1024;
                tracefs_instance_set_subbuf_size(NULL, subsize);
        }
        for (i = 0; i < sizeof(buf) - 1; i++) {
                buf[i] = '0' + i % 10;
        }
        buf[i] = '\0';
        tracefs_instance_clear(NULL);
        for (i = 0; i < 4; i++) {
                ret = tracefs_printf(NULL, "%s\n", buf);
                if (ret < 0)
                        perror("write");
        }
        trace = tracefs_instance_file_read(NULL, "trace", NULL);
        printf("%s\n", trace);
        free(trace);
        printf("Buffer size was: %zd * 1024\n",
               tracefs_instance_get_subbuf_size(NULL));
        tracefs_instance_set_subbuf_size(NULL, save_subsize);
}
