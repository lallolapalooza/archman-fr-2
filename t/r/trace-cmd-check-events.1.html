NOM

trace-cmd-check-events - analyse les formats d'événements sur le système local

SYNOPIS

trace-cmd check-events [OPTIONS]

DESCRIPTION

trace-cmd(1) check-events analyse les chaînes de format de tous les événements présents sur le système local. Il indique si toutes les chaînes de format peuvent être analysées correctement. Il chargera les plugins sauf indication contraire.

Ceci est utile pour vérifier les chaînes de format d'événements de trace qui pourraient contenir des références à des fonctions internes du noyau qui ne peuvent pas être décodées en dehors du noyau. Cela peut signifier que soit les chaînes de format non analysées des événements de trace doivent être modifiées, soit qu'un plugin doit être créé pour les analyser.

OPTIONS

-N - Ne pas charger les plugins

--verbose[=level]

Définit le niveau de journalisation. Les niveaux de journalisation supportés sont "none", "critical", "error", "warning", "info", "debug", "all" ou leurs identifiants "0", "1", "2", "3", "4", "5", "6". La définition du niveau de journalisation à une valeur spécifique active tous les journaux à partir de ce niveau et des niveaux précédents. Le niveau sera par défaut "info" s'il n'y en a pas de spécifié. 
Exemple : activer tous les journaux critiques, d'erreur et d'avertissement
trace-cmd check-events --verbose=warning
