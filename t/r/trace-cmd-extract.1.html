NOM

trace-cmd-extract - extrait les données du traçeur Ftrace Linux.

SYNTAXE

trace-cmd extract [OPTIONS]

DESCRIPTION

La commande trace-cmd(1) extract est généralement utilisée après trace-cmd-start(1) et trace-cmd-stop(1). Elle peut être utilisée après que le traçeur Ftrace a été démarré manuellement via le système de fichiers pseudo Ftrace.

La commande extract crée un fichier trace.dat qui peut être utilisé par trace-cmd-report(1) pour lire les données. Elle lit le tampon circulaire interne du noyau pour produire le fichier trace.dat.

OPTIONS

-p plugin

Bien que extract ne démarre aucun traçage, certains des plugins nécessitent seulement la lecture de la sortie au format ASCII. Ce sont les traçeurs de latence, car les traçeurs de latence ont un tampon interne séparé. L'option plugin n'est donc nécessaire que pour les plugins wakeup, wakeup-rt, irqsoff, preemptoff et preemptirqsoff. 
Sans cette option, la commande extract extraira des tampons
internes de Ftrace.

-O option

Si un traçeur de latence est en cours d'extraction, et que l'option -p est utilisée, alors il existe certaines options Ftrace qui peuvent changer le format. Cela mettra à jour ces options avant l'extraction. Pour voir la liste des options, consultez trace-cmd-list. Pour activer une option, écrivez son nom, pour désactiver l'option, ajoutez les caractères no à celui-ci. Par exemple : noprint-parent désactivera l'option print-parent qui affiche la fonction parente lors de l'impression d'un événement de fonction.

-o fichier_sortie

Par défaut, la commande extract créera un fichier trace.dat. Cette option changera l'emplacement où le fichier sera écrit.

-s

Extrait du tampon snapshot (si le noyau le prend en charge).

--date

Ceci est identique à l'option --date de trace-cmd-record(1), mais cela provoque l'arrêt de tout traçage par la routine d'extraction. C'est-à-dire que la fin de l'extraction effectuera quelque chose de similaire à trace-cmd-reset(1).

-B nom_tampon

Si le noyau prend en charge plusieurs tampons, cela extraira le traçage uniquement pour le tampon donné. Cela n'affecte aucun autre tampon. Ceci peut être utilisé plusieurs fois pour spécifier différents tampons. Lorsque cette option est utilisée, l'instance de niveau supérieur ne sera pas extraite à moins que -t ne soit donné.

-a

Extrait toutes les instances de tampon existantes. Lorsque cette option est utilisée, l'instance de niveau supérieur ne sera pas extraite à moins que -t ne soit donné.

-t

Extrait le tampon de l'instance de niveau supérieur. Sans l'option -B ou -a, c'est identique au comportement par défaut. Mais si -B ou -a est utilisé, ceci est requis si le tampon de l'instance de niveau supérieur doit également être extrait.

--verbose[=niveau]

Définit le niveau de journalisation. Les niveaux de journalisation pris en charge sont "none", "critical", "error", "warning", "info", "debug", "all" ou leurs identifiants "0", "1", "2", "3", "4", "5", "6". La définition du niveau de journalisation à une valeur spécifique active tous les journaux de ce niveau et de tous les niveaux précédents. Le niveau sera par défaut "info" s'il n'y en a pas de spécifié. 
Exemple : activer tous les journaux critiques, d'erreur et d'avertissement
trace-cmd extract --verbose=warning
