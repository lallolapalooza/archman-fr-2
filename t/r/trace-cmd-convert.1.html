NOM

trace-cmd-convert - convertir les fichiers de trace

SYNTAXE

trace-cmd convert [OPTIONS] [fichier-sortie]

DESCRIPTION

La commande trace-cmd(1) convert convertit les fichiers de trace. Elle lit le fichier d'entrée et copie les données dans un fichier de sortie. Le fichier de sortie peut être dans un format différent, selon les arguments de la ligne de commande. La sortie par défaut est en version 7 et compressée (si compilée avec le support de la compression).

OPTIONS

-i fichier-entrée

Par défaut, trace-cmd convert lira le fichier trace.dat. Mais l'option -i ouvrira le fichier-entrée spécifié à la place.

-o fichier-sortie

Le nom du fichier de sortie, ce paramètre est obligatoire. Notez que le fichier de sortie peut également être spécifié comme dernier élément de la ligne de commande.

--file-version

Version souhaitée du fichier de sortie. Les versions supportées sont 6 ou 7.

--compression

Compression du fichier de sortie de trace, une des chaînes suivantes peut être passée : 
'any'  - sélectionne automatiquement le meilleur algorithme de compression disponible
'none' - ne pas compresser le fichier de trace
'name' - le nom de l'algorithme de compression souhaité. Les algorithmes disponibles peuvent être listés avec
trace-cmd list -c

--help

Affiche les informations d'utilisation.

EXEMPLES

# trace-cmd convert --compression any trace_compress.dat
