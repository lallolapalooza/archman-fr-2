NOM

tracefs_instance_tracers, tracefs_tracer_set, tracefs_tracer_clear - Activer ou désactiver un traceur dans une instance ou au niveau supérieur

SYNOPSIS

#include <tracefs.h>
char ** tracefs_instance_tracers(struct tracefs_instance *instance);
int tracefs_tracer_set(struct tracefs_instance *instance, enum tracefs_tracers tracer);
int tracefs_tracer_set(struct tracefs_instance *instance, enum tracefs_tracers tracer, const char *name);
int tracefs_tracer_clear(struct tracefs_instance *instance);

DESCRIPTION

tracefs_instance_tracers retournera une liste des traceurs disponibles pour une instance donnée (notez qu'une instance peut ne pas avoir le même ensemble de traceurs disponibles que le niveau supérieur). Si instance est NULL, alors la liste des traceurs disponibles retournée sera pour le niveau supérieur.

tracefs_tracer_set active un traceur dans l'instance donnée, définie par le paramètre instance. Si instance est NULL, alors l'instance de niveau supérieur est modifiée. Si tracer est défini sur TRACEFS_TRACER_CUSTOM, alors une chaîne de caractères name doit être passée comme troisième paramètre, et elle est écrite dans l'instance pour activer le traceur avec ce nom. Ceci est utile pour les noyaux plus récents ou personnalisés qui contiennent des traceurs qui ne sont pas encore identifiés par l'énumération tracefs_tracers.

tracefs_tracer_clear désactive le traceur pour l'instance donnée définie par la variable instance, ou l'instance de niveau supérieur si elle est NULL. Ceci est équivalent à appeler tracefs_tracer_set avec TRACEFS_TRACER_NOP comme paramètre tracer.

ÉNUMÉRATIONS TRACEFS_TRACER

Les énumérations actuellement définies qui sont acceptées sont :

TRACEFS_TRACER_NOP : C'est le traceur inactif, qui ne fait rien et est utilisé pour effacer tout traceur actif.

TRACEFS_TRACER_FUNCTION : Active la plupart des fonctions du noyau pour le traçage.

TRACEFS_TRACER_FUNCTION_GRAPH : Active la plupart des fonctions du noyau pour le traçage, ainsi que le retour de la fonction.

TRACEFS_TRACER_IRQSOFF : Trace la latence lorsque les interruptions sont désactivées.

TRACEFS_TRACER_PREEMPTOFF : Trace la latence lorsque la préemption est désactivée (le temps passé dans le noyau pendant lequel les tâches ne peuvent pas être planifiées sur le CPU).

TRACEFS_TRACER_PREEMPTIRQSOFF : Trace la latence totale combinée lorsque les interruptions sont désactivées ainsi que lorsque la préemption est désactivée.

TRACEFS_TRACER_WAKEUP : Trace la latence à partir du moment où la tâche de plus haute priorité met à se réveiller.

TRACEFS_TRACER_WAKEUP_RT : Trace la latence à partir du moment où la tâche temps réel de plus haute priorité met à se réveiller. Toutes les autres tâches sont ignorées.

TRACEFS_TRACER_WAKEUP_DL : Trace la latence à partir du moment où la tâche DEADLINE de plus haute priorité met à se réveiller. Toutes les autres tâches sont ignorées.

TRACEFS_TRACER_MMIOTRACE : Trace l'interaction des périphériques avec le noyau.

TRACEFS_TRACER_HWLAT : Détecte la latence causée par le matériel qui est hors de portée du noyau.

TRACEFS_TRACER_BRANCH : Trace lorsque les branches probables ou improbables sont prises.

TRACEFS_TRACER_BLOCK : Traceur spécial pour les périphériques blocs.

Notez que les traceurs ci-dessus peuvent ne pas être disponibles dans le noyau et que tracefs_tracer_set() retournera une erreur avec errno défini à ENODEV, si le noyau ne prend pas en charge l'option tracer, ou celle personnalisée si TRACEFS_TRACER_CUSTOM est utilisée.

VALEUR DE RETOUR

Retourne 0 en cas de succès, ou -1 en cas d'erreur.

ERREURS

tracefs_tracer_set() peut échouer avec les erreurs suivantes :

EINVAL Le paramètre tracer est en dehors de la portée de ce qui est défini.

ENOMEM Erreur d'allocation de mémoire.

ENOENT Les traceurs ne sont pas pris en charge sur le noyau en cours d'exécution.

ENODEV Le traceur spécifié n'est pas pris en charge sur le noyau en cours d'exécution.

D'autres erreurs peuvent également survenir en raison d'appels système internes.

EXEMPLE

#include <stdlib.h>
#include <stdio.h>
#include <getopt.h>
#include <errno.h>
#include <tracefs.h>
int main(int argc, char *argv[])
{
        struct tracefs_instance *inst = NULL;
        enum tracefs_tracers t = TRACEFS_TRACER_NOP;
        const char *cust = NULL;
        const char *buf = NULL;
        char **tracers;
        int ret;
        int ch;
        int i;
        while ((ch = getopt(argc, argv, "nfgiwdc:B:")) > 0) {
                switch (ch) {
                case 'f': t = TRACEFS_TRACER_FUNCTION; break;
                case 'g': t = TRACEFS_TRACER_FUNCTION_GRAPH; break;
                case 'i': t = TRACEFS_TRACER_PREEMPTIRQSOFF; break;
                case 'w': t = TRACEFS_TRACER_WAKEUP_RT; break;
                case 'd': t = TRACEFS_TRACER_WAKEUP_DL; break;
                case 'c':
                        t = TRACEFS_TRACER_CUSTOM;
                        cust = optarg;
                        break;
                case 'B':
                        buf = optarg;
                        break;
                case 'n':
                        /* nop */
                        break;
                default:
                        printf("Argument inconnu %c\n", ch);
                        exit(-1);
                }
        }
        if (buf) {
                inst = tracefs_instance_create(buf);
                if (!inst) {
                        printf("Échec de la création de l'instance\n");
                        exit(-1);
                }
        }
        if (t == TRACEFS_TRACER_CUSTOM)
                ret = tracefs_tracer_set(inst, t, cust);
        else
                ret = tracefs_tracer_set(inst, t);
        if (ret < 0) {
                if (errno == ENODEV) {
                        if (cust)
                                printf("Traceur '%s' non pris en charge par le noyau\n", cust);
                        else
                                printf("Traceur non pris en charge par le noyau\n");
                        tracers = tracefs_instance_tracers(inst);
                        printf("Traceurs disponibles:");
                        for (i = 0; tracers && tracers[i]; i++)
                                printf(" %s", tracers[i]);
                        tracefs_list_free(tracers);
                        printf("\n");
                } else
                        perror("Erreur");
                if (inst) {
                        tracefs_instance_destroy(inst);
                        tracefs_instance_free(inst);
                }
                exit(-1);
        }
        tracefs_instance_free(inst);
        exit(0);
}

NAME

tracefs_tracer_set - Set the enabled tracer

SYNOPSIS

#include <tracefs.h>
int tracefs_tracer_set(struct tracefs_probe_event *event, const char *tracer);

DESCRIPTION

The tracefs_tracer_set() function will set the given tracer to be the enabled tracer.

A tracer is a special type of event that can be enabled. When a tracer is enabled, it will record certain information about the kernel's activities.

The available tracers can be found in the debugfs filesystem at /sys/kernel/debug/tracing/current_tracer. The value of current_tracer indicates the currently enabled tracer. To see all available tracers, check the file /sys/kernel/debug/tracing/available_tracers.

When this function is called, it will write the name of the tracer to /sys/kernel/debug/tracing/current_tracer.

If tracer is NULL, it will disable the current tracer.

TRACEFS TRACER ENUMS

The following is a list of some common tracers:

NOTRACER
No tracer is enabled.
FUNCTION
Trace all function calls.
FUNCTION_GRAPH
Trace function graph.
SCHED_SWITCH
Trace context switches.
SCHED_VIAGNOSTIC
Trace scheduler diagnostics.
HWLAT
Trace hardware latency.
CYCCNT
Trace cycle counter.
MMKSYSCALL
Trace memory management kernel syscalls.
USERLAT
Trace user space latency.
BPF
Trace using BPF programs.

RETURN VALUE

On success, zero is returned. On failure, a negative value is returned and errno is set appropriately.

ERRORS

EBUSY
The trace device is busy.
EINVAL
The specified tracer is not valid or not available.
ENOMEM
Out of memory.
EPERM
Permission denied.

EXAMPLE

#include <tracefs.h>
#include <stdio.h>

int main(void) {
    struct tracefs_probe_event *event;
    int ret;

    event = tracefs_probe_event__new(NULL);
    if (!event) {
        perror("tracefs_probe_event__new");
        return 1;
    }

    // Enable the function tracer
    ret = tracefs_tracer_set(event, "function");
    if (ret < 0) {
        fprintf(stderr, "Failed to set function tracer: %s\n", strerror(-ret));
        tracefs_probe_event__put(event);
        return 1;
    }

    printf("Function tracer enabled.\n");

    // ... do some tracing ...

    // Disable the tracer
    ret = tracefs_tracer_set(event, NULL);
    if (ret < 0) {
        fprintf(stderr, "Failed to disable tracer: %s\n", strerror(-ret));
        tracefs_probe_event__put(event);
        return 1;
    }

    printf("Tracer disabled.\n");

    tracefs_probe_event__put(event);
    return 0;
}

FILES

/sys/kernel/debug/tracing/current_tracer
File to set the current tracer.
/sys/kernel/debug/tracing/available_tracers
File listing available tracers.
