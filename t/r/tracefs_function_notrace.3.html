NOM

tracefs_function_filter, tracefs_function_notrace, tracefs_filter_functions - Fonctions pour modifier les filtres de traçage de fonctions

SYNOPSIS

#include <tracefs.h>
int tracefs_function_filter(struct tracefs_instance *instance, const char *filter, const char *module, int flags);
int tracefs_function_notrace(struct tracefs_instance *instance, const char *filter, const char *module, int flags);
int tracefs_filter_functions(const char *filter, const char *module, char ***list);

DESCRIPTION

tracefs_function_filter et tracefs_function_notrace peuvent être utilisés pour limiter les fonctions du noyau Linux qui seraient tracées par les traceurs de fonctions et de graphes de fonctions. tracefs_function_filter définit une liste de fonctions pouvant être tracées. tracefs_function_notrace définit une liste de fonctions qui ne seront pas tracées. Si une fonction se trouve dans les deux listes, elle ne sera pas tracée.

Ces fonctions prennent une instance , qui peut être NULL pour le traçage de haut niveau, filtre, une chaîne représentant un filtre qui devrait être appliqué pour définir quelles fonctions doivent être tracées, module, pour limiter le filtrage à un module spécifique (ou NULL pour filtrer sur toutes les fonctions), flags qui contient des indicateurs de contrôle sur la manière dont les filtres seront gérés (voir la section FLAGS ci-dessous).

La fonction tracefs_filter_functions renvoie une liste de fonctions pouvant être filtrées via le filtre et le module fournis. Si filtre et module sont tous deux NULL, toutes les fonctions disponibles pouvant être filtrées sont renvoyées. En cas de succès, list doit être libérée avec tracefs_list_free()(3).

Le filtre peut être soit une correspondance directe d'une fonction, une expression glob ou une expression régulière (regex(3)). Un glob est un modèle où * correspond à zéro ou plusieurs caractères, ? correspond à zéro ou un caractère, et . correspond uniquement à un point. Si le filtre est déterminé comme étant une regex (s'il contient autre chose que des caractères alphanumériques, ou ., *, ?), le filtre sera traité comme une regex(3) suivant les règles de regex(3), et . ne sera pas un point, mais correspondra à n'importe quel caractère unique. Pour forcer une expression régulière, préfixez le filtre avec un ^ ou ajoutez-lui un $ car le filtre effectue des correspondances complètes des fonctions de toute façon.

Si module est défini et filtre est NULL, cela implique la même chose que filtre égal à "*". Ce qui activera toutes les fonctions pour un module donné. Sinon, le filtre peut être NULL si un appel précédent à tracefs_function_filter() avec la même instance avait le drapeau TRACEFS_FL_CONTINUE défini et que cet appel ne l'a pas. Ceci est utile pour simplement valider les filtres précédents. Il peut également être NULL si TRACEFS_FL_RESET est défini et que l'appel précédent n'avait pas la même instance et le drapeau TRACEFS_FL_CONTINUE défini. Ceci est utile pour simplement effacer le filtre.

FLAGS

Le paramètre flags peut avoir les valeurs suivantes définies, ou être zéro.

TRACEFS_FL_RESET : Si flags contient TRACEFS_FL_RESET, alors il effacera les filtres actuellement définis avant d'appliquer le filtre. Sinon, le filtre est ajouté à l'ensemble actuel des filtres déjà activés. Si ce drapeau est défini et que l'appel précédent à tracefs_function_filter() avait la même instance et que le drapeau TRACEFS_FL_CONTINUE était défini, alors la fonction échouera avec un retour de -1 et errno défini à EBUSY.

TRACEFS_FL_CONTINUE : Si flags contient TRACEFS_FL_CONTINUE, alors le filtre ne prendra effet qu'après un appel réussi à tracefs_function_filter(). Ceci permet plusieurs appels à tracefs_function_filter() pour mettre à jour la fonction de filtrage, puis un seul appel (un sans le drapeau TRACEFS_FL_CONTINUE défini) pour valider tous les filtres. Il peut être appelé plusieurs fois pour ajouter d'autres filtres. Un appel sans ce drapeau défini validera les changements avant de retourner (si le filtre passé a réussi la correspondance). Un appel à tracefs_function_filter() après un appel qui avait le drapeau TRACEFS_FL_CONTINUE défini pour la même instance échouera si le drapeau TRACEFS_FL_RESET est défini, car le drapeau de réinitialisation n'est applicable que pour le premier filtre à ajouter avant la validation.

TRACEFS_FL_FUTURE : Si flags contient TRACEFS_FL_FUTURE et que module contient une chaîne de module, alors si le module n'est pas chargé, il tentera d'écrire le filtre avec le module dans le fichier de filtre. À partir de Linux v4.13, les fonctions de module pouvaient être ajoutées au filtre avant qu'elles ne soient chargées. Le filtre sera mis en cache, et lorsque le module sera chargé, le filtre sera défini avant que le module n'exécute, permettant de tracer les fonctions d'initialisation d'un module. Cela ne fonctionnera que si le filtre n'est pas une expression régulière.

VALEUR DE RETOUR

Pour tracefs_function_filter() et tracefs_function_notrace(), un retour de 0 signifie succès. S'il y a une erreur mais que le filtrage n'a pas été démarré, alors 1 est renvoyé. Si le filtrage a été démarré mais qu'une erreur survient, alors -1 est renvoyé. L'état du filtrage peut être inconnu.

Si TRACEFS_FL_CONTINUE était défini, et que 0 ou -1 a été renvoyé, alors un autre appel à tracefs_function_filter() doit être effectué sans TRACEFS_FL_CONTINUE défini afin de valider (et fermer) le filtrage.

Pour tracefs_filter_functions(), un retour de 0 signifie succès, et le paramètre list est rempli avec une liste de noms de fonctions qui correspondaient à filtre et module. list est un tableau de chaînes, où le dernier pointeur de chaîne dans le tableau est NULL. Le list doit être libéré avec tracefs_list_free(). En cas d'échec, une valeur négative est renvoyée, et list est ignoré.

ERREURS

tracefs_function_filter() peut échouer avec les erreurs suivantes :

EINVAL Le filtre est invalide ou n'a pas correspondu à des fonctions.

EBUSY L'appel précédent de tracefs_function_filter() a été appelé avec la même instance et TRACEFS_FL_CONTINUE défini, et l'appel actuel avait TRACEFS_FL_RESET défini.

D'autres erreurs peuvent également survenir en raison d'appels système internes.

EXEMPLE

#include <stdio.h>
#include <errno.h>
#include <tracefs.h>
#define INST "dummy"
static const char *filters[] = { "run_init_process", "try_to_run_init_process", "dummy1", NULL };
int main(int argc, char *argv[])
{
        struct tracefs_instance *inst = tracefs_instance_create(INST);
        char **func_list;
        int ret;
        int i;
        if (!inst) {
                /* Erreur lors de la création de la nouvelle instance de trace */
        }
        if (tracefs_filter_functions("*lock*", NULL, &func_list) < 0) {
                printf("Échec de la lecture des fonctions de filtre\n");
                goto out;
        }
        printf("Ignorer les fonctions suivantes :\n");
        for (i = 0; func_list[i]; i++)
                printf("  %s\n", func_list[i]);
        tracefs_list_free(func_list);
        /* Ne tracer aucune fonction contenant le mot "lock" */
        ret = tracefs_function_notrace(inst, "*lock*", NULL, TRACEFS_FL_RESET);
        if (ret) {
                printf("Échec de la définition du filtre notrace\n");
                goto out;
        }
        /* Réinitialiser d'abord le filtre */
        ret = tracefs_function_filter(inst, NULL, NULL,
                                      TRACEFS_FL_RESET | TRACEFS_FL_CONTINUE);
        if (ret) {
                printf("Échec de la réinitialisation du filtre\n");
                /* S'assurer qu'il est fermé, -1 signifie que le filtre a été démarré */
                if (ret < 0)
                        tracefs_function_filter(inst, NULL, NULL, 0);
        }
        for (i = 0; filters[i]; i++) {
                ret = tracefs_function_filter(inst, filters[i], NULL,
                                              TRACEFS_FL_CONTINUE);
                if (ret) {
                        if (errno == EINVAL)
                                printf("Le filtre %s n'a pas correspondu\n", filters[i]);
                        else
                                printf("Échec de l'écriture de %s\n", filters[i]);
                }
        }
        ret = tracefs_function_filter(inst, "*", "ext4", 0);
        if (ret) {
                printf("Échec de la définition des filtres pour ext4\n");
        }
out:
        tracefs_instance_destroy(inst);
        return ret;
}
