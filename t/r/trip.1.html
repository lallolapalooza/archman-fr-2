trip - Un outil de diagnostic réseau

DESCRIPTION

Un outil de diagnostic réseau

OPTIONS

-c, --config-file=FICHIER_CONFIG
Fichier de configuration
-m, --mode=MODE
Mode de sortie [défaut : tui]

Valeurs possibles :

  • tui : Afficher une TUI interactive
  • stream : Afficher un flux continu de données de traçage
  • pretty : Générer un rapport de tableau texte joli pour N cycles
  • markdown : Générer un rapport de tableau texte Markdown pour N cycles
  • csv : Générer un rapport CSV pour N cycles
  • json : Générer un rapport JSON pour N cycles
  • dot : Générer un fichier Graphviz DOT pour N cycles
  • flows : Afficher tous les flux pour N cycles
  • silent : Ne générer aucune sortie de traçage pour N cycles
-u, --unprivileged
Tracer sans nécessiter de privilèges élevés sur les plateformes supportées [défaut : false]
-p, --protocol=PROTOCOLE
Protocole de traçage [défaut : icmp]

Valeurs possibles :

  • icmp : Internet Control Message Protocol
  • udp : User Datagram Protocol
  • tcp : Transmission Control Protocol
--udp
Tracer en utilisant le protocole UDP
--tcp
Tracer en utilisant le protocole TCP
--icmp
Tracer en utilisant le protocole ICMP
-F, --addr-family=FAMILLE_ADDR
La famille d'adresses [défaut : ipv4-puis-ipv6]

Valeurs possibles :

  • ipv4 : IPv4 uniquement
  • ipv6 : IPv6 uniquement
  • ipv6-then-ipv4 : IPv6 avec un repli vers IPv4
  • ipv4-then-ipv6 : IPv4 avec un repli vers IPv6
  • system : Si le résolveur de l'OS est utilisé, utiliser la première adresse IP renvoyée, sinon rechercher IPv6 avec un repli vers IPv4
-4, --ipv4
Utiliser uniquement IPv4
-6, --ipv6
Utiliser uniquement IPv6
-P, --target-port=PORT_CIBLE
Le port cible (TCP & UDP uniquement) [défaut : 80]
-S, --source-port=PORT_SOURCE
Le port source (TCP & UDP uniquement) [défaut : auto]
-A, --source-address=ADRESSE_SOURCE
L'adresse IP source [défaut : auto]
-I, --interface=INTERFACE
L'interface réseau [défaut : auto]
-i, --min-round-duration=DUREE_MIN_TOUR
La durée minimale de chaque tour [défaut : 1s]
-T, --max-round-duration=DUREE_MAX_TOUR
La durée maximale de chaque tour [défaut : 1s]
-g, --grace-duration=DUREE_GRACE
La période pendant laquelle attendre des réponses ICMP supplémentaires après la réponse de la cible [défaut : 100ms]
--initial-sequence=NUMERO_SEQUENCE_INITIAL
Le numéro de séquence initial [défaut : 33434]
-R, --multipath-strategy=STRATEGIE_MULTIPATH
La stratégie de routage de chemins multiples de coût égal (UDP uniquement) [défaut : classic]

Valeurs possibles :

  • classic : Le port source ou destination est utilisé pour stocker le numéro de séquence
  • paris : Le champ `checksum` UDP est utilisé pour stocker le numéro de séquence
  • dublin : Le champ `identifier` IP est utilisé pour stocker le numéro de séquence
-U, --max-inflight=MAX_EN_COURS
Le nombre maximum de requêtes d'écho ICMP en cours [défaut : 24]
-f, --first-ttl=TTL_INITIAL
Le TTL de départ [défaut : 1]
-t, --max-ttl=TTL_MAX
Le nombre maximum de sauts TTL [défaut : 64]
--packet-size=TAILLE_PAQUET
La taille du paquet IP à envoyer (en-tête IP + en-tête ICMP + charge utile) [défaut : 84]
--payload-pattern=MOTIF_CHARGE_UTILE
Le motif répétitif dans la charge utile du paquet ICMP [défaut : 0]
-Q, --tos=TOS
La valeur de l'en-tête IP TOS (c.-à-d. DSCP+ECN) (IPv4 uniquement) [défaut : 0]
-e, --icmp-extensions
Analyser les extensions ICMP
--read-timeout=DELAI_LECTURE
Le délai d'attente de lecture du socket [défaut : 10ms]
-r, --dns-resolve-method=METHODE_RESOL_DNS
Comment effectuer les requêtes DNS [défaut : system]

Valeurs possibles :

  • system : Résoudre en utilisant le résolveur de l'OS
  • resolv : Résoudre en utilisant la configuration DNS de `/etc/resolv.conf`
  • google : Résoudre en utilisant le service DNS de Google `8.8.8.8`
  • cloudflare : Résoudre en utilisant le service DNS de Cloudflare `1.1.1.1`
-y, --dns-resolve-all
Tracer vers toutes les IP résolues à partir de la recherche DNS [défaut : false]
--dns-timeout=DELAI_DNS
Le temps maximum d'attente pour effectuer les requêtes DNS [défaut : 5s]
--dns-ttl=TTL_DNS
La durée de vie (TTL) des entrées DNS [défaut : 300s]
-z, --dns-lookup-as-info
Rechercher les informations du système autonome (AS) lors des requêtes DNS [défaut : false]

NOM

trip — Trace le chemin réseau des paquets avec des informations détaillées sur les sauts

SYNOPSIS

trip [-46AacDhHkKMpPtuv] [-f DELAYS] [-l LOGFILE] [-n NUMERIC] [-Q MAX] [-R RATE] [-s SIZE] [-T TIMEOUT] [-w WAIT] [-I INTERFACE] [--address-ttl=ADDRESS_TTL] [--bandwidth=BANDWIDTH] [--max-flows=MAX_FLOWS] [-a, --tui-address-mode=TUI_ADDRESS_MODE] [--tui-as-mode=TUI_AS_MODE] [--tui-custom-columns=TUI_CUSTOM_COLUMNS] [--tui-icmp-extension-mode=TUI_ICMP_EXTENSION_MODE] [--tui-geoip-mode=TUI_GEOIP_MODE] [-M, --tui-max-addrs=TUI_MAX_ADDRS] [--tui-preserve-screen] [--tui-refresh-rate=TUI_REFRESH_RATE] [--tui-privacy-max-ttl=TUI_PRIVACY_MAX_TTL] [--tui-locale=TUI_LOCALE] [--tui-timezone=TUI_TIMEZONE] [--tui-theme-colors=TUI_THEME_COLORS] [--print-tui-theme-items] [--tui-key-bindings=TUI_KEY_BINDINGS] [--print-tui-binding-commands] [-C, --report-cycles=REPORT_CYCLES] [-G, --geoip-mmdb-file=GEOIP_MMDB_FILE] [--generate=GENERATE] [--generate-man] [--print-config-template] [--print-locales] [--log-format=LOG_FORMAT] [--log-filter=LOG_FILTER] [--log-span-events=LOG_SPAN_EVENTS] [-v, --verbose] [-h, --help] [-V, --version] [CIBLES]

DESCRIPTION

trip est un outil pour tracer le chemin réseau des paquets depuis l'hôte local vers une destination donnée, en fournissant des informations détaillées sur chaque saut (hop) sur le chemin.

Il utilise des messages ICMP Echo Request (ou d'autres types si nécessaire) pour sonder les routeurs sur le chemin et déterminer le chemin réseau emprunté par les paquets. Il affiche des informations telles que le temps de réponse, le TTL, l'adresse IP et le nom d'hôte de chaque saut.

Il offre également une interface utilisateur textuelle (TUI) interactive pour une visualisation en temps réel du trajet réseau.

OPTIONS

-4
Force IPv4 pour la trace.
-6
Force IPv6 pour la trace.
-A
Ne pas faire de résolution DNS inverse pour les adresses IP.
-a, --tui-address-mode=TUI_ADDRESS_MODE
Comment afficher les adresses [défaut: host]

Valeurs possibles :

  • ip: Afficher uniquement l'adresse IP
  • host: Afficher uniquement le nom d'hôte DNS résolu en inverse
  • both: Afficher à la fois l'adresse IP et le nom d'hôte DNS résolu en inverse
-c
Terminer après avoir reçu la réponse du dernier saut.
-C, --report-cycles=REPORT_CYCLES
Le nombre de cycles de rapport à exécuter [défaut: 10]
-D
Activer le débogage de la trace.
-d
Ne pas faire de résolution DNS du nom d'hôte. Afficher uniquement les adresses IP.
-f DELAYS
Délai entre les sondes (en millisecondes). Peut être une liste de délais pour chaque saut.
-G, --geoip-mmdb-file=GEOIP_MMDB_FILE
Le fichier mmdb GeoIp MaxMind ou IPinfo pris en charge
-h, --help
Afficher l'aide (voir un résumé avec '-h')
-H
Activer l'envoi de paquets avec la valeur `Host` (utilisé pour la découverte du chemin et la configuration du réseau). Doit être activé en combinaison avec le protocole TCP.
-I INTERFACE
L'interface réseau à utiliser.
-k
Continuer la trace même si un saut ne répond pas.
-l LOGFILE
Écrire les résultats dans un fichier journal.
--log-format=LOG_FORMAT
Le format du journal de débogage [défaut: pretty]

Valeurs possibles :

  • compact: Afficher les données du journal dans un format compact
  • pretty: Afficher les données du journal dans un format joli
  • json: Afficher les données du journal dans un format json
  • chrome: Afficher les données du journal dans le format de trace Chrome
--log-filter=LOG_FILTER
Le filtre du journal de débogage [défaut: trippy=debug]
--log-span-events=LOG_SPAN_EVENTS
Le format du journal de débogage [défaut: off]

Valeurs possibles :

  • off: Ne pas afficher les portées d'événements
  • active: Afficher les portées d'entrée et de sortie
  • full: Afficher toutes les portées d'événements
-M, --tui-max-addrs=TUI_MAX_ADDRS
Le nombre maximum d'adresses à afficher par saut [défaut: auto]
--max-flows=MAX_FLOWS
Le nombre maximum de flux à enregistrer [défaut: 64]
-n NUMERIC
Ne faire de résolution DNS que pour les adresses IP numériques.
-p
Afficher le TTL de chaque saut.
-P
Ne pas afficher les statistiques de fin de trace.
--print-tui-theme-items
Afficher tous les éléments du thème TUI et quitter
--print-tui-binding-commands
Afficher toutes les commandes TUI qui peuvent être liées et quitter
--print-config-template
Afficher un modèle de fichier de configuration toml et quitter
--print-locales
Afficher toutes les locales TUI disponibles et quitter
-Q MAX
Nombre maximum de sauts à afficher.
-R RATE
Taux de sondage du réseau (en paquets par seconde).
-s SIZE
Taille du paquet à envoyer.
--tui-as-mode=TUI_AS_MODE
Comment afficher les informations de système autonome (AS) [défaut: asn]

Valeurs possibles :

  • asn: Afficher l'ASN
  • prefix: Afficher le préfixe AS
  • country-code: Afficher le code du pays
  • registry: Afficher le nom du registre
  • allocated: Afficher la date d'allocation
  • name: Afficher le nom de l'AS
--tui-custom-columns=TUI_CUSTOM_COLUMNS
Colonnes personnalisées à afficher dans le tableau des sauts TUI [défaut: holsravbwdt]
--tui-icmp-extension-mode=TUI_ICMP_EXTENSION_MODE
Comment afficher les extensions ICMP [défaut: off]

Valeurs possibles :

  • off: Ne pas afficher les extensions `icmp`
  • mpls: Afficher uniquement le(s) label(s) MPLS
  • full: Afficher les données complètes de l'extension `icmp` pour toutes les extensions connues
  • all: Afficher les données complètes de l'extension `icmp` pour toutes les classes
--tui-geoip-mode=TUI_GEOIP_MODE
Comment afficher les informations GeoIp [défaut: short]

Valeurs possibles :

  • off: Ne pas afficher les données GeoIp
  • short: Afficher le format court
  • long: Afficher le format long
  • location: Afficher le format latitude et longitude
--tui-preserve-screen
Préserver l'écran à la sortie [défaut: false]
--tui-refresh-rate=TUI_REFRESH_RATE
Le taux de rafraîchissement de la TUI [défaut: 100ms]
--tui-privacy-max-ttl=TUI_PRIVACY_MAX_TTL
Le TTL maximum des sauts qui seront masqués pour la confidentialité [défaut: none]

Si défini, l'adresse IP source et le nom d'hôte seront également masqués.

--tui-locale=TUI_LOCALE
La locale à utiliser pour la TUI [défaut: auto]
--tui-timezone=TUI_TIMEZONE
Le fuseau horaire à utiliser pour la TUI [défaut: auto]

Le fuseau horaire doit être un identifiant de fuseau horaire IANA valide.

--tui-theme-colors=TUI_THEME_COLORS
Les couleurs du thème TUI [item=color,item=color,..]
--tui-key-bindings=TUI_KEY_BINDINGS
Les raccourcis clavier TUI [command=key,command=key,..]
-T TIMEOUT
Délai d'attente pour chaque réponse (en secondes).
-u
Utiliser le protocole UDP pour la trace (nécessite les privilèges root).
-v, --verbose
Activer la journalisation de débogage détaillée
-V, --version
Afficher la version
-w WAIT
Délai d'attente entre les sondes pour chaque saut (en secondes).
--generate=GENERATE
Générer l'achèvement du shell

[valeurs possibles : bash, elvish, fish, powershell, zsh]

--generate-man
Générer la page de manuel ROFF
[CIBLES]
Une liste d'hôtes et d'adresses IP à tracer, séparés par des espaces.
