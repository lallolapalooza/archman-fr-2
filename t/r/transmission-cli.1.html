TRANSMISSION-CLI(1) Manuel des commandes générales TRANSMISSION-CLI(1)

NOM

transmission-cli — un client bittorrent

SYNTAXE

transmission-cli -h
transmission-cli [-b | -B] [-d nombre | -D] [-er | -ep | -et] [-f script] [-g répertoire] [-h] [-m | -M] [-p port] [--tos tos] [-u nombre | -U] [-v] [-w répertoire] fichier-torrent

DESCRIPTION

Le programme transmission-cli est un client BitTorrent léger en ligne de commande avec des capacités de script.

Les options sont les suivantes :

-b --blocklist
Active les listes noires de pairs. Transmission comprend le format de fichier de liste noire bluetack. De nouvelles listes noires peuvent être ajoutées en les copiant dans le sous-répertoire "blocklists" du répertoire de configuration.
-B --no-blocklist
Désactive les listes noires.
-d --downlimit nombre
Définit la vitesse de téléchargement maximale en Ko/s.
-D --no-downlimit
Ne limite pas la vitesse de téléchargement.
-er --encryption-required
Chiffre toutes les connexions de pairs.
-ep --encryption-preferred
Préfère les connexions de pairs chiffrées.
-et --encryption-tolerated
Préfère les connexions de pairs non chiffrées.
-f --finish script
Définit un script à exécuter lorsque le torrent est terminé.
-g --config-dir répertoire
Où rechercher les fichiers de configuration. Ceci peut être utilisé pour alterner entre l'utilisation des clients cli, daemon, gtk et qt. Voir https://github.com/transmission/transmission/blob/main/docs/Configuration-Files.md pour plus d'informations.
-h --help
Affiche un bref résumé d'utilisation.
-m --portmap
Active le mappage de ports via NAT-PMP ou UPnP.
-M --no-portmap
Désactive le mappage de ports.
-p --port port
Définit le port d'écoute pour les pairs entrants. (Défaut : 51413)
--tos tos
Utilise un nom ToS ou DSCP pour définir le type de service du socket
pair pour le façonnage du trafic basé sur le routeur local. Les valeurs
valides sont une valeur décimale 0-255, ou l'une des chaînes DSCP
suivantes :

“af11”, “af12”, “af13”, “af21”, “af22”, “af23”, “af31”, “af32”, “af33”, “af41”, “af42”, “af43”, “cs0”, “cs1”, “cs2”, “cs3”, “cs4”, “cs5”, “cs6”, “cs7”, “ef”, “le” Ces clés ToS sont obsolètes et seront supprimées à l'avenir : “default”, “lowcost”, “lowdelay,” “reliability”, “throughput”

-u --uplimit nombre
Définit la vitesse d'envoi maximale en Ko/s.
-U --no-uplimit
Ne limite pas la vitesse d'envoi.
-v --verify
Vérifie les données téléchargées du torrent.
-w --download-dir répertoire
Où enregistrer les données téléchargées.

SIGNAUX

En plus de ces options, l'envoi d'un signal SIGHUP à transmission-cli le fera contacter le tracker pour obtenir plus de pairs.

ENVIRONNEMENT

TRANSMISSION_HOME
Définit le répertoire de configuration par défaut.
http_proxy
libcurl utilise cette variable d'environnement lors des annonces au tracker.

FICHIERS

~/.config/transmission
Répertoire où transmission-cli conserve les informations des torrents pour l'ensemencement futur et les opérations de reprise.

AUTEURS
