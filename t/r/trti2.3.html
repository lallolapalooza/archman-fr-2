sous-programme ctrti2 (caractère uplo, caractère diag, entier n, complexe, dimension( lda, * ) a, entier lda, entier info)

CTRTI2 calcule l'inverse d'une matrice triangulaire complexe.

Objectif :

!>
!> CTRTI2 calcule l'inverse d'une matrice triangulaire supérieure ou inférieure complexe.
!>
!> Il s'agit de la version algorithmique de niveau 2 BLAS.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          Spécifie si la matrice A est triangulaire supérieure ou inférieure.
!>          = 'U' : Triangulaire supérieure
!>          = 'L' : Triangulaire inférieure
!>

DIAG

!>          DIAG est CARACTERE*1
!>          Spécifie si la matrice A est triangulaire unitaire ou non.
!>          = 'N' : Triangulaire non unitaire
!>          = 'U' : Triangulaire unitaire
!>

N

!>          N est ENTIER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau de COMPLEXES, de dimension (LDA,N)
!>          En entrée, la matrice triangulaire A. Si UPLO = 'U', la
!>          partie triangulaire supérieure n par n de tête du tableau A contient
!>          la matrice triangulaire supérieure, et la partie strictement
!>          triangulaire inférieure de A n'est pas référencée. Si UPLO = 'L', la
!>          partie triangulaire inférieure n par n de tête du tableau A contient
!>          la matrice triangulaire inférieure, et la partie strictement
!>          triangulaire supérieure de A n'est pas référencée. Si DIAG = 'U', les
!>          éléments diagonaux de A ne sont pas non plus référencés et sont
!>          supposés être égaux à 1.
!>
!>          En sortie, l'inverse (triangulaire) de la matrice originale, dans
!>          le même format de stockage.
!>

LDA

!>          LDA est ENTIER
!>          La dimension de tête du tableau A.  LDA >= max(1,N).
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -k, le k-ième argument avait une valeur illégale
!>

Detailed Description

ZTRTI2 computes the inverse of a triangular matrix.

This is the Level 2 BLAS version of the algorithm.

Purpose:

!>
!> ZTRTI2 computes the inverse of a complex upper or lower triangular
!> matrix.
!>
!> This is the Level 2 BLAS version of the algorithm.
!>

Function Documentation

subroutine ztrti2 (character uplo, character diag, integer n, complex*16, dimension( lda, * ) a, integer lda, integer info)

ZTRTI2 computes the inverse of a triangular matrix (unblocked algorithm).

Purpose:

!>
!> ZTRTI2 computes the inverse of a complex upper or lower triangular
!> matrix.
!>
!> This is the Level 2 BLAS version of the algorithm.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          Specifies whether the matrix A is upper or lower triangular.
!>          = 'U':  Upper triangular
!>          = 'L':  Lower triangular
!>

DIAG

!>          DIAG is CHARACTER*1
!>          Specifies whether or not the matrix A is unit triangular.
!>          = 'N':  Non-unit triangular
!>          = 'U':  Unit triangular
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          On entry, the triangular matrix A.  If UPLO = 'U', the
!>          leading n by n upper triangular part of the array A contains
!>          the upper triangular matrix, and the strictly lower
!>          triangular part of A is not referenced.  If UPLO = 'L', the
!>          leading n by n lower triangular part of the array A contains
!>          the lower triangular matrix, and the strictly upper
!>          triangular part of A is not referenced.  If DIAG = 'U', the
!>          diagonal elements of A are also not referenced and are
!>          assumed to be 1.
!>
!>          On exit, the (triangular) inverse of the original matrix, in
!>          the same storage format.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -k, the k-th argument had an illegal value
!>
