NOM

tracefs_synth_create, tracefs_synth_destroy, tracefs_synth_complete, tracefs_synth_trace, tracefs_synth_snapshot, tracefs_synth_save, tracefs_synth_set_instance, - Création d'événements synthétiques

SYNOPSIS

#include <tracefs.h>
int tracefs_synth_create(struct tracefs_synth *synth);
int tracefs_synth_destroy(struct tracefs_synth *synth);
bool tracefs_synth_complete(struct tracefs_synth *synth);
int tracefs_synth_set_instance(struct tracefs_synth *synth, struct tracefs_instance *instance);
int tracefs_synth_trace(struct tracefs_synth *synth,
                        enum tracefs_synth_handler type, const char *var);
int tracefs_synth_snapshot(struct tracefs_synth *synth,
                           enum tracefs_synth_handler type, const char *var);
int tracefs_synth_save(struct tracefs_synth *synth,
                       enum tracefs_synth_handler type, const char *var,
                       char **save_fields);

DESCRIPTION

Les événements synthétiques sont des événements dynamiques créés en mettant en correspondance deux autres événements qui déclenchent un événement synthétique. Un événement est l'événement de départ dont un champ est enregistré, et lorsque le second événement est exécuté, s'il possède un champ (ou des champs) correspondant au(x) champ(s) de l'événement de départ, il déclenchera l'événement synthétique. Les valeurs des champs autres que les champs correspondants peuvent être transmises de l'événement de départ à l'événement final pour effectuer des calculs, ou simplement transmises en tant que paramètre à l'événement synthétique.

Un cas d'utilisation courant consiste à définir "sched_waking" comme événement de départ. Cet événement est déclenché lorsqu'un processus est réveillé. Ensuite, définir "sched_switch" comme événement de fin. Cet événement est déclenché lorsqu'une nouvelle tâche est planifiée sur le CPU. En définissant le "common_pid" des deux événements comme champs de correspondance, le temps écoulé entre les deux événements est considéré comme la latence de réveil de ce processus. Utilisez TRACEFS_TIMESTAMP comme champ pour les deux événements afin de calculer la différence en nanosecondes, ou utilisez TRACEFS_TIMESTAMP_USECS comme champs de comparaison pour les deux événements afin de calculer la différence en microsecondes. Ceci est utilisé dans l'exemple ci-dessous.

tracefs_synth_create() crée l'événement synthétique dans le système. Par défaut, les déclencheurs d'histogramme sont créés dans l'instance de trace supérieure, car tout événement synthétique peut être utilisé globalement sur toutes les instances. Si une application souhaite exclure les déclencheurs d'histogramme de l'instance de niveau supérieur, elle peut utiliser tracefs_synth_set_instance() pour que les histogrammes soient utilisés pour créer l'événement synthétique dans une instance autre que le niveau supérieur. Un descripteur d'événement synthétique doit être créé avec tracefs_synth_alloc(3) avant que cela puisse être utilisé pour le créer sur le système.

tracefs_synth_destroy() détruit l'événement synthétique. Il tentera d'arrêter son exécution dans son instance (supérieure par défaut), mais s'il s'exécute dans une autre instance, cela peut échouer car elle est occupée.

tracefs_synth_complete() renvoie vrai si l'événement synthétique synth a à la fois un événement de départ et un événement de fin.

tracefs_synth_trace() Au lieu de simplement effectuer une trace lors de la correspondance des événements de début et de fin, effectue le gestionnaire type où TRACEFS_SYNTH_HANDLE_MAX effectuera une trace lorsque la variable var donnée atteint un nouveau maximum pour les clés correspondantes. Ou TRACEFS_SYNTH_HANDLE_CHANGE lorsqu'elle change. var doit être l'un des éléments name utilisés dans tracefs_synth_add_end_field(3).

tracefs_synth_snapshot() Lorsque la variable donnée var représente un nouveau maximum si handler est TRACEFS_SYNTH_HANDLE_MAX ou a simplement changé si TRACEFS_SYNTH_HANDLE_CHANGE, alors prendre un "instantané" du tampon. L'instantané déplace le tampon de "trace" normal dans un tampon de "snapshot", qui peut être accédé via le fichier "snapshot" dans le répertoire tracefs de niveau supérieur, ou l'une des instances. var change. var doit être l'un des éléments name utilisés dans tracefs_synth_add_end_field(3).

tracefs_synth_save() Lorsque la variable donnée var représente un nouveau maximum si handler est TRACEFS_SYNTH_HANDLE_MAX ou a simplement changé si TRACEFS_SYNTH_HANDLE_CHANGE, alors sauvegarder la liste save_fields donnée. Les champs seront stockés dans le fichier "hist" de l'histogramme de l'événement qui peut être récupéré avec tracefs_event_file_read(3). var doit être l'un des éléments name utilisés dans tracefs_synth_add_end_field(3).

tracefs_synth_set_instance() Définit l'instance de trace, où les déclencheurs d'histogramme qui créent l'événement synthétique seront créés. Par défaut, l'instance supérieure est utilisée. Cette API doit être appelée avant l'appel à tracefs_synth_create(), afin d'utiliser la nouvelle instance lors de la création de l'événement. Notez que même si l'événement synthétique est créé dans une instance, il est toujours visible par toutes les autres instances, y compris le niveau supérieur. C'est-à-dire que d'autres instances peuvent activer l'événement synthétique créé et le faire tracer dans les buffers qui appartiennent à l'instance qui l'a activé.

VALEUR DE RETOUR

Toutes les fonctions retournent zéro en cas de succès ou -1 en cas d'erreur.

ERREURS

Les erreurs suivantes s'appliquent à tous les appels ci-dessus :

EPERM Non exécuté en tant qu'utilisateur root lorsque requis.

EINVAL Soit un paramètre n'est pas valide (NULL alors qu'il ne devrait pas l'être) soit un champ non compatible pour les calculs.

ENODEV Un événement ou l'un de ses champs n'est pas trouvé.

EBADE Les champs des événements de départ et de fin ne sont pas compatibles pour la correspondance ou la comparaison.

ENOMEM Pas assez de mémoire disponible.

D'autres erreurs peuvent s'être produites lors des appels système au système.

EXEMPLE

Voir tracefs_sql(3) pour une utilisation plus approfondie de certains de ces codes.

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Charger tous les événements du système */
        tep = tracefs_local_events(NULL);
        /* Initialiser l'événement synthétique */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* Le tep n'est plus nécessaire */
        tep_free(tep);
        /* Sauvegarder le champ "prio" en tant que "prio" de l'événement de départ */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Sauvegarder le champ "next_comm" en tant que "comm" de l'événement de fin */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Sauvegarder le champ "prev_prio" en tant que "prev_prio" de l'événement de fin */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Prendre la différence de temps en microsecondes entre la fin et le début
         * et l'enregistrer sous le nom "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* N'enregistrer que si le champ "prio" de l'événement de départ est inférieur à 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * N'enregistrer que si le champ "next_prio" de l'événement de fin est inférieur à 50
         * ou si le prio de la tâche précédente n'était pas supérieur ou égal à 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);

DESCRIPTION

The libtracefs library provides APIs to interact with the tracefs filesystem, which is the interface for the Linux kernel's tracing subsystem. This man page specifically covers functions related to synthetic events.

Synthetic events are events that can be defined and created by userspace programs, allowing for custom tracing scenarios. These events are based on existing tracepoints but can have their own filtering and aggregation logic.

tracefs_synth_snapshot(): This function takes a name of an event and returns a struct tracefs_synth representing a snapshot of that event. This structure can be used to query or modify the event's properties.

tracefs_synth_append_end_filter() and tracefs_synth_append_start_filter(): These functions append a filter condition to the synthetic event. Filters can be used to specify when an event should be triggered. The `type` parameter specifies the type of filter (e.g., TRACEFS_FILTER_OPEN_PAREN, TRACEFS_FILTER_CLOSE_PAREN, TRACEFS_FILTER_COMPARE). The TRACEFS_FILTER_COMPARE type allows comparing a `field` with a `value` using a specified comparison `op` (e.g., TRACEFS_COMPARE_GE for greater than or equal to).

tracefs_synth_create(): Creates the synthetic event defined by the struct tracefs_synth structure in the tracefs filesystem.

tracefs_synth_destroy(): Deletes a previously created synthetic event from the tracefs filesystem.

tracefs_synth_echo_cmd(): Echos the command string that would be used to create the synthetic event to a struct trace_seq buffer. This is useful for debugging or understanding how the event is represented.

tracefs_synth_free(): Frees the memory associated with a struct tracefs_synth structure.

tracefs_synth_get_event(): Returns a pointer to the struct tracefs_event associated with the synthetic event.

tracefs_synth_get_name(): Returns the name of the synthetic event.

tracefs_synth_get_start_hist(): Returns a pointer to the struct tracefs_hist associated with the start histogram of the synthetic event.

tracefs_synth_raw_fmt(): Formats the raw command string for the synthetic event into a struct trace_seq buffer.

tracefs_synth_show_event(): Displays the synthetic event definition.

tracefs_synth_show_end_hist(): Displays the end histogram definition of the synthetic event.

tracefs_synth_show_start_hist(): Displays the start histogram definition of the synthetic event.

RETURN VALUE

Functions that can fail return non-zero on success and zero on failure. tracefs_synth_snapshot returns a pointer to a struct tracefs_synth on success, and NULL on failure.

ERRORS

The functions may fail for various reasons, including memory allocation failures, invalid arguments, or issues interacting with the tracefs filesystem.

EXAMPLE

/* Example of creating a synthetic event that triggers when next_prio is less than 50
 * or when prev_prio is greater than or equal to 100.
 */
#include <tracefs.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static struct tracefs_synth *synth;

static void make_event(void)
{
        /* Allocate the synthetic event structure */
        synth = tracefs_synth_alloc("my_synthetic_event");
        if (!synth) {
                perror("tracefs_synth_alloc failed");
                exit(-1);
        }

        /* Add filter: next_prio < 50 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");

        /* Add filter: !(prev_prio >= 100) */
        /* Note: the parenthesis will be added when the command is echoed/created */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Note, the above only added: "next_prio < 50 || !(prev_prio >= 100"
         * That's because, when the synth is executed, the remaining close parenthesis
         * will be added. That is, the string will end up being:
         * "next_prio < 50 || !(prev_prio >= 100)" when one of tracefs_sync_create()
         * or tracefs_sync_echo_cmd() is run.
         */
}
/* Display how to create the synthetic event */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Create the synthetic event */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Delete the synthetic event */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}
