!>  CTRSEN commence par collecter les valeurs propres sélectionnées en calculant une transformation unitaire
!>  Z pour les déplacer dans le coin supérieur gauche de T. En d'autres termes, les valeurs propres sélectionnées sont les valeurs propres de T11 dans :
!>
!>          Z**H * T * Z = ( T11 T12 ) n1
!>                         (  0  T22 ) n2
!>                            n1  n2
!>
!>  où N = n1+n2. Les n1 premières
!>  colonnes de Z constituent l'espace vectoriel invariant spécifié de T.
!>
!>  Si T a été obtenu à partir de la factorisation de Schur d'une matrice
!>  A = Q*T*Q**H, alors la factorisation de Schur réordonnée de A est donnée par
!>  A = (Q*Z)*(Z**H*T*Z)*(Q*Z)**H, et les n1 premières colonnes de Q*Z constituent l'espace
!>  vectoriel invariant correspondant de A.
!>
!>  Le nombre de condition réciproque de la moyenne des valeurs propres de
!>  T11 peut être renvoyé dans S. S se situe entre 0 (très mal conditionné)
!>  et 1 (très bien conditionné). Il est calculé comme suit. D'abord, nous
!>  calculons R de telle sorte que
!>
!>                         P = ( I  R ) n1
!>                             ( 0  0 ) n2
!>                               n1 n2
!>
!>  soit le projecteur sur l'espace vectoriel invariant associé à T11.
!>  R est la solution de l'équation de Sylvester :
!>
!>                        T11*R - R*T22 = T12.
!>
!>  Soit F-norm(M) la norme de Frobenius de M et 2-norm(M) la norme 2 de M. Alors S est calculé comme la borne inférieure
!>
!>                      (1 + F-norm(R)**2)**(-1/2)
!>
!>  sur le réciproque de la norme 2 de P, le vrai nombre de condition réciproque.
!>  S ne peut pas sous-estimer 1 / 2-norm(P) de plus d'un facteur
!>  sqrt(N).
!>
!>  Une borne d'erreur approximative pour la moyenne calculée des
!>  valeurs propres de T11 est
!>
!>                         EPS * norm(T) / S
!>
!>  où EPS est la précision machine.
!>
!>  Le nombre de condition réciproque de l'espace vectoriel invariant
!>  formé par les n1 premières colonnes de Z (ou de Q*Z) est renvoyé dans SEP.
!>  SEP est défini comme la séparation de T11 et T22 :
!>
!>                     sep( T11, T22 ) = sigma-min( C )
!>
!>  où sigma-min(C) est la plus petite valeur singulière de la
!>  matrice n1*n2-par-n1*n2
!>
!>     C  = kprod( I(n2), T11 ) - kprod( transpose(T22), I(n1) )
!>
!>  I(m) est une matrice identité m par m, et kprod dénote le produit de Kronecker. Nous estimons
sigma-min(C) par l'inverse d'une estimation de !> la 1-norme de inverse(C). La vraie inverse 1-norme de inverse(C) !> ne peut différer de sigma-min(C) que d'un facteur de sqrt(n1*n2). !> !> Lorsque SEP est petit, de petits changements dans T peuvent causer de grands changements dans !> le sous-espace invariant. Une borne approximative sur l'erreur angulaire maximale dans le sous-espace invariant droit calculé est !> !> EPS * norm(T) / SEP !>

Objectif :

!>
!> DTRSEN réordonne la factorisation de Schur réelle d'une matrice réelle
!> A = Q*T*Q**T, de sorte qu'un cluster sélectionné de valeurs propres apparaisse dans
!> les blocs diagonaux principaux de la matrice quasi-triangulaire supérieure T,
!> et que les colonnes principales de Q forment une base orthonormée du
!> sous-espace invariant droit correspondant.

!> Optionnellement, la routine calcule les nombres de condition réciproques des
!> clusters de valeurs propres (S) ou du sous-espace invariant (SEP).
!>
!> T doit être sous forme canonique de Schur (comme retourné par DHSEQR), c'est-à-dire,
!> bloc triangulaire supérieure avec des blocs diagonaux de 1x1 et 2x2 ; chaque

STRSSQ

    
Purpose:

    

        
!>  This routine is a helper routine for STRRSV. It is used to estimate
!>  the reciprocal of the smallest singular value of a triangular matrix.
!>  Specifically, given an upper triangular matrix R, it computes an
!>  estimate of the reciprocal of the smallest singular value of R.
!>  This is done by finding a vector x such that ||x|| = 1 and
!>  R*x is minimized. The routine returns an estimate of 1/||R*x||.

STRSSQ

    
Purpose:

    

        
!>  STRSSQ estimates the reciprocal of the smallest singular value of a
!>  triangular matrix.
!>
!>  This routine is called by STRRSV to estimate the reciprocal of the
!>  smallest singular value of the triangular matrix A in the equation
!>  A*x = b.
!>
!>  The problem of finding the smallest singular value of A is equivalent
!>  to finding a vector x with norm 1 such that norm(A*x) is minimized.
!>  The routine computes a vector x and an estimate of norm(A*x).
!>
!>  Arguments:
!>
!>  UPLO   - CHARACTER*1.
!>           Specifies whether the matrix A is upper or lower triangular.
!>           = 'U': A is upper triangular.
!>           = 'L': A is lower triangular.
!>
!>  TRANSA - CHARACTER*1.
!>           Specifies the form of the system of equations.
!>           = 'N': A*x = b           (No transpose)
!>           = 'T': A**T*x = b        (Transpose)
!>           = 'C': A**H*x = b        (Conjugate transpose)
!>
!>  DIAG   - CHARACTER*1.
!>           Specifies whether or not the matrix A is unit triangular.
!>           = 'U': A is unit triangular.
!>           = 'N': A is not unit triangular.
!>
!>  N      - INTEGER.
!>           The order of the triangular matrix A. N >= 0.
!>
!>  A      - REAL array of dimension (LDA,N).
!>           On entry, the triangular matrix A.
!>
!>  LDA    - INTEGER.
!>           The leading dimension of the array A. LDA >= max(1,N).
!>
!>  SCALE  - REAL array of dimension (N).
!>           On entry, SCALE(i) contains information to scale the diagonal
!>           element A(i,i). See the NOTES section.
!>           On exit, SCALE(i) contains the scale factor for the diagonal
!>           element A(i,i).
!>
!>  X      - REAL array of dimension (N).
!>           On entry, X(i) contains the i-th element of the right-hand
!>           side vector b.
!>           On exit, X(i) contains the i-th element of the solution
!!>           vector x.
!>
!>  WORK   - REAL array of dimension (N).
!>           This is a working array.
!>
!>  INFO   - INTEGER.
!>           = 0: successful exit
!>           < 0: if INFO = -i, the i-th argument had an illegal value
!>
!>  Notes:
!>  The routine computes a vector x and an estimate of the quantity
!>  norm(A*x).
!>
!>  The algorithm computes the vector x by taking advantage of the
!>  fact that the solution to the equation A*x = b is unique when A is
!>  non-singular.
!>
!>  The scaling of the diagonal elements is done to avoid overflow or
!>  underflow. The vector SCALE is used to keep track of the scaling
!>  factors.
!>
!>  The value returned in SCALE is the reciprocal of the norm of the
!>  smallest singular value of A.
!>
!>  The condition number estimate is then given by SCALE.

ZTRSEN réordonne la factorisation de Schur d'une matrice complexe
    A = Q*T*Q**H, de sorte qu'un cluster sélectionné de valeurs propres apparaisse
    dans les positions de tête sur la diagonale de la matrice triangulaire
    supérieure T, et que les colonnes de tête de Q forment une base orthonormée
    du sous-espace invariant correspondant.


Optionnellement, la routine calcule les nombres conditionnels
    réciproques du cluster de valeurs propres (S) et/ou du sous-espace invariant
    (SEP).

Further Details:




    ZTRSEN collecte d'abord les valeurs propres sélectionnées en calculant une
    transformation unitaire Z pour les déplacer dans le coin supérieur gauche
    de T. Autrement dit, les valeurs propres sélectionnées sont les valeurs propres
    de T11 dans :
    
            Z**H * T * Z = ( T11 T12 ) n1
                           (  0  T22 ) n2
                              n1  n2
    
    où N = n1+n2. Les n1 premières colonnes de Z étendent le sous-espace invariant
    sélectionné de T.
    
    Si T a été obtenu à partir de la factorisation de Schur d'une matrice
    A = Q*T*Q**H, alors la factorisation de Schur réordonnée de A est donnée par
    A = (Q*Z)*(Z**H*T*Z)*(Q*Z)**H, et les n1 premières colonnes de Q*Z étendent le
    sous-espace invariant correspondant de A.
    
    Le nombre conditionnel réciproque de la moyenne des valeurs propres de
    T11 peut être retourné dans S. S se situe entre 0 (très mal conditionné)
    et 1 (très bien conditionné). Il est calculé comme suit. Nous calculons d'abord
    R de sorte que
    
                           P = ( I  R ) n1
                               ( 0  0 ) n2
                                  n1 n2
    
    soit le projecteur sur le sous-espace invariant associé à T11.
    R est la solution de l'équation de Sylvester :
    
                           T11*R - R*T22 = T12.
    
    Soit F-norm(M) la norme de Frobenius de M et 2-norm(M) la norme 2 de M.
    Alors S est calculé comme la borne inférieure
    
                           (1 + F-norm(R)**2)**(-1/2)
    
    sur l'inverse de la norme 2 de P, le nombre conditionnel réciproque vrai.
    S ne peut pas sous-estimer 1 / 2-norm(P) par plus d'un facteur de
    sqrt(N).
    
    Une borne d'erreur approximative pour la moyenne calculée des valeurs propres
    de T11 est
    
                           EPS * norm(T) / S
    
    où EPS est la précision machine.
    
    Le nombre conditionnel réciproque du sous-espace invariant droit
    étendu par les n1 premières colonnes de Z (ou de Q*Z) est retourné dans SEP.
    SEP est défini comme la séparation de T11 et T22 :
    
                     sep( T11, T22 ) = sigma-min( C )
    
    où sigma-min(C) est la plus petite valeur singulière de la matrice
    de taille n1*n2 par n1*n2
    
       C  = kprod( I(n2), T11 ) - kprod( transpose(T22), I(n1) )
    
    I(m) est une matrice identité m par m, et kprod dénote le produit de Kronecker.
    Nous estimons sigma-min(C) par l'inverse d'une estimation de la norme 1 de
    inverse(C). La norme 1 réciproque vraie de inverse(C) ne peut pas différer
    de sigma-min(C) par plus d'un facteur de sqrt(n1*n2).
    
    Lorsque SEP est petit, de petits changements dans T peuvent entraîner de grands
    changements dans le sous-espace invariant. Une borne approximative sur l'erreur
    angulaire maximale dans le sous-espace invariant droit calculé est
    
                      EPS * norm(T) / SEP

    ZTRSEN first collects the selected eigenvalues by computing a unitary
    transformation Z to move them to the top left corner of T. In other
    words, the selected eigenvalues are the eigenvalues of T11 in:
    
            Z**H * T * Z = ( T11 T12 ) n1
                           (  0  T22 ) n2
                              n1  n2
    
    where N = n1+n2. The first
    n1 columns of Z span the specified invariant subspace of T.
    
    If T has been obtained from the Schur factorization of a matrix
    A = Q*T*Q**H, then the reordered Schur factorization of A is given by
    A = (Q*Z)*(Z**H*T*Z)*(Q*Z)**H, and the first n1 columns of Q*Z span the
    corresponding invariant subspace of A.
    
    The reciprocal condition number of the average of the eigenvalues of
    T11 may be returned in S. S lies between 0 (very badly conditioned)
    and 1 (very well conditioned). It is computed as follows. First we
    compute R so that
    
                           P = ( I  R ) n1
                               ( 0  0 ) n2
                                  n1 n2
    
    is the projector on the invariant subspace associated with T11.
    R is the solution of the Sylvester equation:
    
                           T11*R - R*T22 = T12.
    
    Let F-norm(M) denote the Frobenius-norm of M and 2-norm(M) denote
    the two-norm of M. Then S is computed as the lower bound
    
                           (1 + F-norm(R)**2)**(-1/2)
    
    on the reciprocal of 2-norm(P), the true reciprocal condition number.
    S cannot underestimate 1 / 2-norm(P) by more than a factor of
    sqrt(N).
    
    An approximate error bound for the computed average of the
    eigenvalues of T11 is
    
                           EPS * norm(T) / S
    
    where EPS is the machine precision.
    
    The reciprocal condition number of the right invariant subspace
    spanned by the first n1 columns of Z (or of Q*Z) is returned in SEP.
    SEP is defined as the separation of T11 and T22:
    
                     sep( T11, T22 ) = sigma-min( C )
    
    where sigma-min(C) is the smallest singular value of the
    n1*n2-by-n1*n2 matrix
    
       C  = kprod( I(n2), T11 ) - kprod( transpose(T22), I(n1) )
    
    I(m) is an m by m identity matrix, and kprod denotes the Kronecker
    product. We estimate sigma-min(C) by the reciprocal of an estimate of
    the 1-norm of inverse(C). The true reciprocal 1-norm of inverse(C)
    cannot differ from sigma-min(C) by more than a factor of sqrt(n1*n2).
    
    When SEP is small, small changes in T can cause large changes in
    the invariant subspace. An approximate bound on the maximum angular
    error in the computed right invariant subspace is
    
                      EPS * norm(T) / SEP
