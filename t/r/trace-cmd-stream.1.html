NOM

trace-cmd-stream - diffuser une trace vers la sortie standard pendant son exécution

SYNTAXE

trace-cmd stream [OPTIONS] [commande]

DESCRIPTION

La commande trace-cmd stream démarrera le traçage, tout comme trace-cmd-record(1), sauf qu'elle n'enregistrera pas dans un fichier. À la place, elle lira le tampon binaire pendant son exécution, le convertira dans un format lisible par l'homme et l'écrira sur la sortie standard.

C'est fondamentalement la même chose que trace-cmd-start(1) suivi de trace-cmd-show(1) avec l'option -p. trace-cmd-stream n'est pas aussi efficace que la lecture depuis le fichier pipe car la majeure partie du travail de diffusion est effectuée dans l'espace utilisateur. Ceci est utile si le travail doit être effectué principalement dans l'espace utilisateur au lieu du noyau, et stream aide également à déboguer trace-cmd-profile(1) qui utilise le code stream pour effectuer l'analyse des données en direct pour le profil.

OPTIONS

Ce sont les mêmes que trace-cmd-record(1), sauf qu'elle n'accepte pas
l'option *-o*.
