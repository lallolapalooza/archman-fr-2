tracefs_synth_get_name(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_synth_echo_cmd, tracefs_synth_get_start_hist, tracefs_synth_get_name, tracefs_synth_raw_fmt, tracefs_synth_show_event, tracefs_synth_show_start_hist, tracefs_synth_show_end_hist, tracefs_synth_get_event - Récupérer les données d'événements synthétiques.

SYNOPSIS

#include <tracefs.h>
int tracefs_synth_echo_cmd(struct trace_seq *seq, struct tracefs_synth *synth);
struct tracefs_hist *tracefs_synth_get_start_hist(struct tracefs_synth *synth);
const char *tracefs_synth_get_name(struct tracefs_synth *synth);
int tracefs_synth_raw_fmt(struct trace_seq *seq, struct tracefs_synth *synth);
const char *tracefs_synth_show_event(struct tracefs_synth *synth);
const char *tracefs_synth_show_start_hist(struct tracefs_synth *synth);
const char *tracefs_synth_show_end_hist(struct tracefs_synth *synth);
struct tep_event *tracefs_synth_get_event(struct tep_handle *tep, struct tracefs_synth *synth);

DESCRIPTION

Les événements synthétiques sont des événements dynamiques créés en faisant correspondre deux autres événements qui déclenchent un événement synthétique. Un événement est l'événement de départ dont un champ est enregistré, et lorsque le second événement est exécuté, s'il possède un champ (ou des champs) qui correspond au champ (ou aux champs) de l'événement de départ, il déclenchera l'événement synthétique. Les valeurs des champs autres que les champs correspondants peuvent être transmises de l'événement de départ à l'événement de fin pour y effectuer des calculs, ou simplement passées en tant que paramètre à l'événement synthétique.

Un cas d'utilisation courant consiste à définir "sched_waking" comme événement de départ. Cet événement est déclenché lorsqu'un processus est réveillé. Ensuite, définissez "sched_switch" comme événement de fin. Cet événement est déclenché lorsqu'une nouvelle tâche est planifiée sur le CPU. En définissant le "common_pid" des deux événements comme champs de correspondance, le temps écoulé entre les deux événements est considéré comme la latence de réveil de ce processus. Utilisez TRACEFS_TIMESTAMP comme champ pour les deux événements afin de calculer la différence en nanosecondes, ou utilisez TRACEFS_TIMESTAMP_USECS comme champs de comparaison pour les deux événements afin de calculer la différence en microsecondes. Ceci est utilisé comme exemple ci-dessous.

Voir tracefs_synth_alloc(3) pour l'allocation des événements synthétiques, et tracefs_synth_create() pour la création de l'événement synthétique sur le système.

tracefs_synth_echo_cmd() fonctionne comme tracefs_synth_create(), mais au lieu de créer l'événement synthétique dans le système, il écrira les commandes d'écho pour le créer manuellement dans le seq donné.

tracefs_synth_get_start_hist() retourne un descripteur de struct tracefs_hist décrivant l'histogramme utilisé pour créer l'événement synthétique.

enum tracefs_synth_handler {
        TRACEFS_SYNTH_HANDLE_MATCH,
        TRACEFS_SYNTH_HANDLE_MAX,
        TRACEFS_SYNTH_HANDLE_CHANGE,
};

tracefs_synth_get_name() retourne le nom de l'événement synthétique ou NULL en cas d'erreur. La chaîne retournée appartient à l'objet synth event et est libérée avec l'événement par tracefs_synth_free().

tracefs_synth_raw_fmt() écrit les chaînes de format brutes (événement dynamique et histogrammes) de l'événement synthétique dans le seq donné.

tracefs_synth_show_event() retourne le format de l'événement dynamique utilisé par l'événement synthétique ou NULL en cas d'erreur. La chaîne retournée appartient à l'objet synth event et est libérée avec l'événement par tracefs_synth_free().

tracefs_synth_show_start_hist() retourne le format de l'histogramme de départ utilisé par l'événement synthétique ou NULL en cas d'erreur. La chaîne retournée appartient à l'objet synth event et est libérée avec l'événement par tracefs_synth_free().

tracefs_synth_show_end_hist() retourne le format de l'histogramme de fin utilisé par l'événement synthétique ou NULL en cas d'erreur. La chaîne retournée appartient à l'objet synth event et est libérée avec l'événement par tracefs_synth_free().

La fonction tracefs_synth_get_event() retourne un événement tep, décrivant l'événement synthétique donné. L'API détecte tout événement dynamique récemment créé ou supprimé. Le pointeur retourné vers l'événement tep est contrôlé par @tep et ne doit pas être libéré.

VALEUR DE RETOUR

tracefs_synth_get_name(), tracefs_synth_show_event(), tracefs_synth_show_start_hist() et tracefs_synth_show_end_hist() retournent une chaîne appartenant à l'objet synth event.

La fonction tracefs_synth_get_event() retourne un pointeur vers un événement tep ou NULL en cas d'erreur ou si l'événement synthétique demandé est manquant. Le pointeur retourné vers l'événement tep est contrôlé par @tep et ne doit pas être libéré.

Toutes les autres fonctions retournent zéro en cas de succès et -1 en cas d'erreur.

ERREURS

Les erreurs suivantes s'appliquent à tous les appels ci-dessus :

EPERM Non exécuté en tant qu'utilisateur root lorsque requis.

EINVAL Soit un paramètre n'est pas valide (NULL alors qu'il ne devrait pas l'être) soit un champ n'est pas compatible pour les calculs.

ENODEV Un événement ou l'un de ses champs n'est pas trouvé.

EBADE Les champs des événements de départ et de fin ne sont pas compatibles pour la correspondance ou la comparaison.

ENOMEM pas assez de mémoire disponible.

Et d'autres erreurs peuvent s'être produites lors des appels système.

EXEMPLE

Voir tracefs_sql(3) pour une utilisation plus approfondie de ce code.

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Charger tous les événements du système */
        tep = tracefs_local_events(NULL);
        /* Initialiser l'événement synthétique */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* Le tep n'est plus nécessaire */
        tep_free(tep);
        /* Sauvegarder le champ "prio" comme "prio" de l'événement de départ */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Sauvegarder le champ "next_comm" comme "comm" de l'événement de fin */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Sauvegarder le champ "prev_prio" comme "prev_prio" de l'événement de fin */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Calculer la différence en microsecondes entre la fin et le début
         * et l'enregistrer sous le nom "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Enregistrer uniquement si le champ "prio" de l'événement de départ est inférieur à 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Enregistrer uniquement si le champ "next_prio" de l'événement de fin est inférieur à 50
         * OU si le prio de la tâche précédente n'était pas supérieur ou égal à 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Notez que ce qui précède n'a ajouté que : "next_prio < 50 || !(prev_prio >= 100"
         * C'est parce que, lorsque le synthé sera exécuté, la parenthèse fermante restante
         * sera ajoutée. C'est-à-dire que la chaîne finira par être :
         * "next_prio < 50 || !(prev_prio >= 100)" lorsqu'une des fonctions tracefs_sync_create()
         * ou tracefs_sync_echo_cmd() sera exécutée.
         */
}
/* Afficher comment */

NOM

tracefs_synth_get_name - obtenir le nom d'un événement synthétique

SYNTAXIS

#include <tracefs.h>
char *tracefs_synth_get_name(struct tracefs_synth *synth);

DESCRIPTION

La fonction tracefs_synth_get_name récupère le nom de l'événement synthétique spécifié par synth.

VALEUR DE RETOUR

La fonction retourne un pointeur vers une chaîne de caractères contenant le nom de l'événement synthétique. La chaîne retournée est allouée par la bibliothèque et doit être libérée par l'appelant à l'aide de free().

ERREURS

La fonction retourne NULL en cas d'échec, par exemple si synth est NULL ou si une erreur d'allocation mémoire se produit.

EXEMPLE

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <tracefs.h>

/* Variable globale pour l'exemple, à remplacer par une allocation appropriée */
static struct tracefs_synth *synth;

static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}

int main (int argc, char **argv)
{
        /* Initialiser synth - ceci est juste un exemple */
        /* Dans un cas réel, vous alloueriez synth avec tracefs_synth_alloc() */
        /* et le rempliriez avec les champs appropriés */
        synth = malloc(sizeof(*synth));
        if (!synth) {
            perror("Failed to allocate synth");
            return -1;
        }
        /* Remplir synth avec des données pour l'exemple */
        /* Dans un vrai scénario, vous utiliseriez des fonctions comme */
        /* tracefs_synth_add_match_field, etc. */
        /* Ici, on simule un nom pour l'exemple */
        synth->name = strdup("mon_evenement_synthetique");
        if (!synth->name) {
            free(synth);
            perror("Failed to duplicate synth name");
            return -1;
        }


        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Créer l'événement synthétique */
                        /* tracefs_synth_create(synth); */
                        printf("Fonctionnalité de création commentée pour l'exemple.\n");
                } else if (!strcmp(argv[1], "delete")) {
                        /* Supprimer l'événement synthétique */
                        /* tracefs_synth_destroy(synth); */
                        printf("Fonctionnalité de suppression commentée pour l'exemple.\n");
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else {
                /* Obtenir et afficher le nom de l'événement */
                char *event_name = tracefs_synth_get_name(synth);
                if (event_name) {
                    printf("Nom de l'événement synthétique : %s\n", event_name);
                    free(event_name); /* Libérer la mémoire allouée par tracefs_synth_get_name */
                } else {
                    printf("Impossible d'obtenir le nom de l'événement synthétique.\n");
                }
                /* show_event(); */ /* Appel commenté car il nécessite une configuration tracefs valide */
                printf("Fonction show_event commentée pour l'exemple.\n");
        }

        /* Libérer la mémoire allouée pour synth dans cet exemple */
        if (synth) {
             free(synth->name); /* Libérer le nom dupliqué */
             free(synth); /* Libérer la structure synth */
        }

        return 0;
}
