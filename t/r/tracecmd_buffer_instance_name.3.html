NOM

tracecmd_buffer_instances, tracecmd_buffer_instance_name, tracecmd_buffer_instance_handle - Lire les instances de traçage à partir d'un fichier de trace.

SYNOPSIS

#include <trace-cmd.h>
int tracecmd_buffer_instances(struct tracecmd_input *handle);
const char *tracecmd_buffer_instance_name(struct tracecmd_input *handle, int indx);
struct tracecmd_input *tracecmd_buffer_instance_handle(struct tracecmd_input *handle, int indx);

DESCRIPTION

Cet ensemble d'API peut être utilisé pour obtenir des informations et lire les données de traçage des instances de traçage stockées dans un fichier de trace.

La fonction tracecmd_buffer_instances() obtient le nombre d'instances de traçage enregistrées dans un fichier de trace. L'instance principale n'est pas comptée. Le handle est un gestionnaire tracecmd_input renvoyé par tracecmd_open_head().

La fonction tracecmd_buffer_instance_name() obtient le nom de l'instance de traçage avec l'index donné indx, enregistrée dans un fichier de trace. L'indx est un nombre dans l'intervalle [0 .. count-1], où count est le nombre renvoyé par tracecmd_buffer_instances(). Le handle est un gestionnaire tracecmd_input renvoyé par tracecmd_open_head().

La fonction tracecmd_buffer_instance_handle() alloue et initialise un gestionnaire tracecmd_input, associé à l'instance de trace avec l'index indx d'un fichier de trace. Le handle est un gestionnaire tracecmd_input renvoyé par tracecmd_open_head(). L'indx est un nombre dans l'intervalle [0 .. count-1], où count est le nombre renvoyé par tracecmd_buffer_instances().

VALEUR DE RETOUR

La fonction tracecmd_buffer_instances() renvoie le nombre d'instances de traçage enregistrées dans un fichier de trace.

La fonction tracecmd_buffer_instance_name() renvoie une chaîne de caractères, le nom d'une instance de traçage, ou NULL en cas d'erreur. La chaîne ne doit pas être libérée.

La fonction tracecmd_buffer_instance_handle() renvoie un pointeur vers un nouveau gestionnaire tracecmd_input alloué ou NULL en cas d'erreur. Le gestionnaire renvoyé doit être fermé par tracecmd_close()(3)

EXEMPLE

#include <trace-cmd.h>
...
struct tracecmd_input *handle = tracecmd_open_head("trace.dat");
        if (!handle) {
                /* Échec de l'ouverture du fichier trace.dat */
        }
...
int num = tracecmd_buffer_instances(handle);
        while(num) {
                struct tracecmd_input *h;
                char *name;
                name = tracecmd_buffer_instance_name(handle, num);
                if (!name) {
                        /* Échec de l'obtention du nom de l'instance num */
                }
                h = tracecmd_buffer_instance_handle(handle, num);
                if (!h) {
                        /* Échec de l'initialisation du gestionnaire pour l'instance num */
                }
                ...
                tracecmd_close(h);
                num--;
        }
...
        tracecmd_close(handle);
