LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_cpu_open_mapped, tracefs_cpu_is_mapped, tracefs_mapped_is_supported, tracefs_cpu_map, tracefs_cpu_unmap - Mappage mémoire du tampon circulaire

SYNTAXE

#include <tracefs.h>
bool tracefs_cpu_is_mapped(struct tracefs_cpu *tcpu);
bool tracefs_mapped_is_supported(void);
int tracefs_cpu_map(struct tracefs_cpu *tcpu);
void tracefs_cpu_unmap(struct tracefs_cpu *tcpu);
struct tracefs_cpu *tracefs_cpu_open_mapped(struct tracefs_instance *instance,
                                            int cpu, bool nonblock);

DESCRIPTION

Si trace_pipe_raw supporte le mappage mémoire, c'est généralement une méthode plus efficace pour diffuser les données du tampon circulaire du noyau que de les lire, car elle ne nécessite pas de copier la mémoire qui est lue.

Si le mappage mémoire est supporté par le noyau et que l'application demande à utiliser le mappage mémoire via tracefs_cpu_map() ou tracefs_cpu_open_mapped(), alors les fonctions tracefs_cpu_read(3) et tracefs_cpu_read_buf(3) utiliseront directement le mappage au lieu d'appeler l'appel système read.

Notez que le mappage fera que tracefs_cpu_buffered_read(3) et tracefs_cpu_buffered_read_buf(3) agiront comme tracefs_cpu_read(3) et tracefs_cpu_read_buf(3) respectivement, car il n'est pas logique d'utiliser un pipe splice lorsqu'il est mappé. Le noyau effectuera une copie pour les lectures splice sur le mappage, puis une autre copie dans la fonction lorsqu'il peut éviter les copies si le tampon circulaire est mappé en mémoire.

Si le tcpu est mappé en mémoire, cela forcera également tracefs_cpu_write(3) et tracefs_cpu_pipe(3) à copier à partir du mappage au lieu d'utiliser splice. Ainsi, il faut être prudent lors de la décision de mapper ou non le tampon circulaire, et c'est pourquoi il n'est pas mappé par défaut.

La fonction tracefs_cpu_is_mapped() retournera vrai si tcpu a actuellement son tampon circulaire mappé en mémoire et faux sinon. Cela n'indique pas si le noyau supporte ou non le mappage mémoire, mais cela peut généralement être déterminé en appelant tracefs_cpu_map().

La fonction tracefs_mapped_is_supported() retourne vrai si le tampon circulaire peut être mappé en mémoire.

La fonction tracefs_cpu_map() tentera de mapper le tampon circulaire associé à tcpu s'il n'est pas déjà mappé.

La fonction tracefs_cpu_unmap() démappera le tampon circulaire associé à tcpu s'il est mappé.

La fonction tracefs_cpu_open_mapped() est équivalente à appeler tracefs_cpu_open(3) suivi de tracefs_cpu_map() sur le tcpu retourné par tracefs_cpu_open(3). Notez que cela réussira toujours même si le mappage échoue, auquel cas il agit de la même manière que tracefs_cpu_open(3). Si l'on souhaite savoir si le mappage a réussi ou non, il faut appeler tracefs_cpu_is_mapped() sur le tcpu retourné.

VALEUR DE RETOUR

tracefs_cpu_is_mapped() retourne vrai si le tcpu donné a son tampon circulaire mappé en mémoire ou faux sinon.

tracefs_mapped_is_supported() retourne vrai si le tampon circulaire de traçage peut être mappé en mémoire ou faux s'il ne peut pas l'être ou si une erreur s'est produite.

tracefs_cpu_map() retourne 0 en cas de succès et -1 en cas d'erreur lors du mappage. Si 0 est retourné, tracefs_cpu_is_mapped() retournera vrai par la suite, ou faux si le mappage a échoué.

tracefs_cpu_open_mapped() retourne un tracefs_cpu alloué en cas de succès de création, indépendamment du fait que le mappage du tampon circulaire ait réussi ou non. Il retourne NULL pour les mêmes raisons que tracefs_cpu_open(3) retourne NULL. Si le succès du mappage doit être connu, il faut appeler tracefs_cpu_is_mapped() par la suite.

EXEMPLE

#include <stdlib.h>
#include <ctype.h>
#include <tracefs.h>
static void read_subbuf(struct tep_handle *tep, struct kbuffer *kbuf)
{
        static struct trace_seq seq;
        struct tep_record record;
        int missed_events;
        if (seq.buffer)
                trace_seq_reset(&seq);
        else
                trace_seq_init(&seq);
        while ((record.data = kbuffer_read_event(kbuf, &record.ts))) {
                record.size = kbuffer_event_size(kbuf);
                missed_events = kbuffer_missed_events(kbuf);
                if (missed_events) {
                        printf("[MISSED EVENTS");
                        if (missed_events > 0)
                                printf(": %d]\n", missed_events);
                        else
                                printf("]\n");
                }
                kbuffer_next_event(kbuf, NULL);
                tep_print_event(tep, &seq, &record,
                                "%s-%d %6.1000d\t%s: %s\n",
                                TEP_PRINT_COMM,
                                TEP_PRINT_PID,
                                TEP_PRINT_TIME,
                                TEP_PRINT_NAME,
                                TEP_PRINT_INFO);
                trace_seq_do_printf(&seq);
                trace_seq_reset(&seq);
        }
}
int main (int argc, char **argv)
{
        struct tracefs_cpu *tcpu;
        struct tep_handle *tep;
        struct kbuffer *kbuf;
        bool mapped;
        int cpu;
        if (argc < 2 || !isdigit(argv[1][0])) {
                printf("usage: %s cpu\n\n", argv[0]);
                exit(-1);
        }
        cpu = atoi(argv[1]);
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("Reading trace event formats");
                exit(-1);
        }
        tcpu = tracefs_cpu_open_mapped(NULL, cpu, 0);
        if (!tcpu) {
                perror("Open CPU 0 file");
                exit(-1);
        }
        /*
         * If this kernel supports mapping, use normal read,
         * otherwise use the piped buffer read, although if
         * the mapping succeeded, tracefs_cpu_buffered_read_buf()
         * acts the same as tracefs_cpu_read_buf(). But this is just
         * an example on how to use tracefs_cpu_is_mapped().
         */
        mapped = tracefs_cpu_is_mapped(tcpu);
        if (!mapped)
                printf("Was not able to map, falling back to buffered read\n");
        while ((kbuf = mapped ? tracefs_cpu_read_buf(tcpu, true) :
                        tracefs_cpu_buffered_read_buf(tcpu, true))) {
                read_subbuf(tep, kbuf);
        }
        kbuf = tracefs_cpu_flush_buf(tcpu);
        if (kbuf)
                read_subbuf(tep, kbuf);
        tracefs_cpu_close(tcpu);
        tep_free(tep);
        return 0;
}

SYNOPSIS

cc -o tracefs_cpu_is_mapped tracefs_cpu_is_mapped.c

#include <tracefs.h>

int
tracefs_cpu_is_mapped(
    int cpu
    int* mask
    );

DESCRIPTION

La fonction tracefs_cpu_is_mapped vérifie si le CPU spécifié par cpu est présent dans le masque de CPU donné par mask.

VALEUR DE RETOUR

La fonction retourne 1 si le CPU est mappé, 0 sinon.

EXEMPLE

int mask = 0xFF; // Masque de CPU représentant les 8 premiers CPUs
int cpu_num = 3;

if (tracefs_cpu_is_mapped(cpu_num, &mask)) {
    printf("Le CPU %d est mappé.\n", cpu_num);
} else {
    printf("Le CPU %d n'est pas mappé.\n", cpu_num);
}
