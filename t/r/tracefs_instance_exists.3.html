tracefs_instance_exists(3)

Paquet: libtracefs

Licences: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) Manuel libtracefs LIBTRACEFS(3)

NOM

tracefs_instance_get_name, tracefs_instance_get_trace_dir, tracefs_instances_walk, tracefs_instance_exists, tracefs_instance_get_buffer_size, tracefs_instance_set_buffer_size, tracefs_instance_get_buffer_percent, tracefs_instance_set_buffer_percent - Fonctions utilitaires pour travailler avec les instances de traçage.

SYNOPSIS

#include <tracefs.h>
const char *tracefs_instance_get_name(struct tracefs_instance *instance);
const char *tracefs_instance_get_trace_dir(struct tracefs_instance *instance);
int tracefs_instances_walk(int (*callback)(const char *, void *), void *context);
bool tracefs_instance_exists(const char *name);
size_t tracefs_instance_get_buffer_size(struct tracefs_instance *instance, int cpu);
int tracefs_instance_set_buffer_size(struct tracefs_instance *instance, size_t size, int cpu);
int tracefs_instance_get_buffer_percent(struct tracefs_instance *instance);
int tracefs_instance_set_buffer_percent(struct tracefs_instance *instance, int val);

DESCRIPTION

Fonctions utilitaires pour travailler avec les instances de traçage.

La fonction tracefs_instance_get_name() renvoie le nom de l'instance donnée. Notez que l'instance supérieure n'a pas de nom, la fonction renvoie NULL pour celle-ci.

La fonction tracefs_instance_get_trace_dir() renvoie le répertoire de traçage où l'instance donnée est configurée.

La fonction tracefs_instances_walk() parcourt toutes les instances de traçage configurées sur le système et appelle callback pour chacune d'entre elles. L'argument context est passé au callback, avec le nom de l'instance. Si le callback renvoie une valeur non nulle, l'itération s'arrête. Notez que le callback n'est pas appelé pour l'instance supérieure.

La fonction tracefs_instance_exists() vérifie si une instance avec le nom donné existe sur le système.

La fonction tracefs_instace_get_buffer_size() renvoie la taille du tampon circulaire (ring buffer). Si cpu est négatif, elle renvoie la taille totale de tous les tampons circulaires par CPU, sinon elle renvoie la taille du tampon circulaire par CPU pour le cpu donné.

La fonction tracefs_instance_set_buffer_size() définit la taille du tampon circulaire. Si cpu est négatif, elle définit tous les tampons circulaires par CPU à la taille size (notez que la taille totale est le nombre de CPU * size). Si cpu est spécifié, elle ne définit que la taille du tampon circulaire par CPU.

La fonction tracefs_instance_set_buffer_percent() définit le pourcentage du tampon de l'instance de traçage pour l'instance ou le tampon de niveau supérieur si instance est NULL. Le pourcentage du tampon décide quand les lecteurs sur tracefs_cpu_read(3), tracefs_cpu_buffered_read(3), tracefs_cpu_write(3) et tracefs_cpu_pipe(3) seront bloqués lorsque O_NONBLOCK n'est pas défini. La valeur de val doit être comprise entre 0 et 100, où :

  0   - bloquer jusqu'à ce qu'il y ait des données dans le tampon circulaire
  1   - bloquer jusqu'à ce que 1% des sous-tampons du tampon circulaire soient remplis
  50  - bloquer jusqu'à ce que 50% des sous-tampons du tampon circulaire soient remplis
  100 - bloquer jusqu'à ce que le tampon circulaire entier soit rempli

Notez que tout nombre de 0 à 100 peut être utilisé, représentant le pourcentage du tampon circulaire qui doit être rempli avant qu'un lecteur bloqué ne soit averti qu'il y a des données à récupérer.

La fonction tracefs_instance_get_buffer_percent() récupère le réglage actuel du pourcentage du tampon du tampon circulaire de traçage pour l'instance ou le tampon de niveau supérieur si instance est NULL.

VALEUR RETOURNÉE

La fonction tracefs_instance_get_name() renvoie une chaîne ou NULL dans le cas de l'instance supérieure. La chaîne renvoyée ne doit pas être libérée.

La fonction tracefs_instance_get_trace_dir() renvoie une chaîne ou NULL en cas d'erreur. La chaîne renvoyée ne doit pas être libérée.

La fonction tracefs_instances_walk() renvoie 0 si toutes les instances ont été parcourues, 1 si l'itération a été arrêtée par le callback, ou -1 en cas d'erreur.

La fonction tracefs_instance_exists() renvoie true si une instance avec le nom donné existe sur le système, ou false sinon.

La fonction tracefs_instance_get_buffer_size() renvoie la taille du tampon circulaire en fonction de la valeur cpu passée, ou -1 en cas d'erreur.

La fonction tracefs_instance_set_buffer_size() renvoie zéro en cas de succès et -1 en cas d'erreur.

EXEMPLE

#include <tracefs.h>
struct tracefs_instance *inst;
....
char *name = tracefs_instance_get_name(inst);
        if(name) {
                /* Nom de l'instance obtenu */
        }
char *dir = tracefs_instance_get_trace_dir(inst);
        if(dir) {
                /* Répertoire de traçage de l'instance obtenu */
        }
...
static int instance_walk(char *name, void *context)
{
        /* Instance avec le nom obtenu */
        return 0;
}
...
        if (tracefs_instances_walk(instance_walk, NULL) < 0) {
                /* Erreur lors du parcours des instances */
        }
...
        if (tracefs_instance_exists("foo")) {
                /* Il existe une instance nommée foo dans le système */
        } else {
                /* Il n'existe pas d'instance nommée foo dans le système */
        }
