DESCRIPTION

Les événements synthétiques sont des événements dynamiques créés en faisant correspondre deux autres événements qui déclenchent un événement synthétique. Un événement est l'événement de départ dont un champ est enregistré, et lorsque le second événement est exécuté, s'il possède un champ (ou des champs) correspondant au champ (ou aux champs) de l'événement de départ, il déclenche l'événement synthétique. Les valeurs des champs autres que les champs correspondants peuvent être transmises de l'événement de départ à l'événement de fin pour effectuer des calculs, ou simplement pour être transmises en tant que paramètres à l'événement synthétique.

Un cas d'utilisation courant consiste à définir "sched_waking" comme événement de départ. Cet événement est déclenché lorsqu'un processus est réveillé. Ensuite, définir "sched_switch" comme événement de fin. Cet événement est déclenché lorsqu'une nouvelle tâche est planifiée sur le CPU. En définissant le "common_pid" des deux événements comme champs de correspondance, le temps écoulé entre les deux événements est considéré comme la latence de réveil de ce processus. Utilisez TRACEFS_TIMESTAMP comme champ pour les deux événements afin de calculer la différence en nanosecondes, ou utilisez "TRACEFS_TIMESTAMP_USECS" comme champs de comparaison pour les deux événements afin de calculer la différence en microsecondes. Ceci est utilisé comme exemple ci-dessous.

tracefs_synth_alloc() alloue et initialise un événement synthétique. Il ne crée pas l'événement synthétique, mais fournit les informations minimales pour le faire. Voir tracefs_synth_create(3) pour savoir comment créer l'événement synthétique dans le système. Il nécessite un gestionnaire tep qui peut être créé par tracefs_local_events(3) pour plus d'informations. Le name contient le nom de l'événement synthétique qui sera créé. Le start_system est le nom du système pour l'événement de départ. Il peut être NULL et le premier événement portant le nom de start_event sera choisi. Le end_system est le nom du système pour l'événement de fin. Il peut être NULL et le premier événement portant le nom de end_event sera choisi comme événement de fin. Si match_name est fourni, alors ce sera le champ de l'événement synthétique créé qui contiendra les clés correspondantes du start_match_field de l'événement de départ et du end_match_field de l'événement de fin. Si match_name est NULL, alors il ne sera pas enregistré dans l'événement synthétique créé.

tracefs_synth_add_match_field() ajoutera une deuxième clé de correspondance entre l'événement de départ et l'événement de fin. Si name est fourni, alors le contenu du champ correspondant sera sauvegardé sous ce name dans l'événement synthétique. Le start_match_field est le champ de l'événement de départ à faire correspondre avec le end_match_field de l'événement de fin.

tracefs_synth_add_compare_field() est utilisé pour comparer le start_compare_field de l'événement de départ avec le end_compare_field de l'événement de fin. Le name doit être fourni afin que le résultat soit sauvegardé par l'événement synthétique. Il n'a aucun sens de ne pas le transmettre à l'événement synthétique après avoir effectué le travail des champs comparés, car il n'a pas d'autre utilité. Le paramètre calc peut être l'une des valeurs suivantes :

TRACEFS_SYNTH_DELTA_END - Calcule la différence entre le contenu de end_compare_field et le contenu de start_compare_field.

name = end_compare_field - start_compare_field

TRACEFS_SYNTH_DELTA_START - Calcule la différence entre le contenu de start_compare_field et le contenu de end_compare_field.

name = start_compare_field - end_compare_field

TRACEFS_SYNTH_ADD - Ajoute le contenu de start_compare_field au contenu de end_compare_field.

name = start_compare_field + end_compare_field

tracefs_synth_add_start_field() - Enregistre le start_field de l'événement de départ sous le nom de name dans l'événement synthétique. Si name est NULL, alors le nom utilisé sera le même que start_field.

tracefs_synth_add_end_field() - Enregistre le end_field de l'événement de fin sous le nom de name dans l'événement synthétique. Si name est NULL, alors le nom utilisé sera le même que end_field.

tracefs_synth_append_start_filter() crée un filtre ou y ajoute un élément pour l'événement de départ. En fonction de type, il construira une chaîne de jetons pour des parenthèses ou des instructions logiques, ou il ajoutera une comparaison de field à val basée sur compare.

Si type est : TRACEFS_FILTER_COMPARE - Voir ci-dessous TRACEFS_FILTER_AND - Ajoute "&&" au filtre TRACEFS_FILTER_OR - Ajoute "||" au filtre TRACEFS_FILTER_NOT - Ajoute "!" au filtre TRACEFS_FILTER_OPEN_PAREN - Ajoute "(" au filtre TRACEFS_FILTER_CLOSE_PAREN - Ajoute ")" au filtre

field, compare, et val sont ignorés sauf si type est égal à TRACEFS_FILTER_COMPARE, alors _compare sera utilisé pour les éléments suivants :

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ "val" : où field est une chaîne.

TRACEFS_COMPARE_AND - field & val : où field est un champ de drapeaux.

tracefs_synth_append_end_filter() est identique à tracefs_synth_append_start_filter mais filtre sur l'événement de fin.

tracefs_synth_free() libère le descripteur alloué retourné par tracefs_synth_alloc().

DESCRIPTION

Les événements synthétiques permettent de créer de nouveaux événements basés sur des événements existants. Par exemple, vous pourriez vouloir tracer la latence de réveil. Vous pourriez utiliser l'événement sched_waking comme événement de début et l'événement sched_switch comme événement de fin. Vous pouvez alors spécifier un champ (par exemple, pid) qui doit correspondre entre les deux événements.

Le champ start_match est un champ de l'événement de début qui est utilisé pour correspondre à l'événement de fin. Si start_match est spécifié, il doit correspondre au champ end_match de l'événement de fin.

Le champ end_match est un champ de l'événement de fin qui est utilisé pour correspondre à l'événement de début. Si end_match est spécifié, il doit correspondre au champ start_match de l'événement de début.

Le champ match_name est un champ commun aux deux événements qui est utilisé pour la mise en correspondance. Si match_name est spécifié, il doit être présent dans les deux événements.

Les champs peuvent être sélectionnés à partir de l'événement de début et de l'événement de fin pour être inclus dans le nouvel événement synthétique. Leurs noms peuvent également être renommés.

Des filtres peuvent être ajoutés pour ne capturer que les événements qui répondent à certains critères. Les filtres peuvent être appliqués à l'événement de début ou de fin.

Les fonctions retournent les valeurs suivantes :

tracefs_synth_alloc() renvoie un descripteur struct tracefs_synth alloué en cas de succès ou NULL en cas d'erreur.

Toutes les autres fonctions qui renvoient un entier renvoient zéro en cas de succès ou -1 en cas d'erreur.

ERREURS

Les erreurs suivantes s'appliquent à tous les appels ci-dessus :

EPERM Pas exécuté en tant qu'utilisateur root lorsque requis.

EINVAL Soit un paramètre n'est pas valide (NULL alors qu'il ne devrait pas l'être) soit un champ non compatible pour les calculs.

ENODEV Un événement ou l'un de ses champs est introuvable.

EBADE Les champs des événements de début et de fin ne sont pas compatibles pour la mise en correspondance ou la comparaison.

ENOMEM Pas assez de mémoire disponible.

Et d'autres erreurs peuvent être survenues à partir des appels système vers le système.

EXEMPLE

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Charger tous les événements du système */
        tep = tracefs_local_events(NULL);
        /* Initialiser l'événement synthétique */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* Le tep n'est plus nécessaire */
        tep_free(tep);
        /* Enregistrer le champ "prio" comme "prio" à partir de l'événement de début */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Enregistrer le champ "next_comm" comme "comm" à partir de l'événement de fin */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Enregistrer le champ "prev_prio" comme "prev_prio" à partir de l'événement de fin */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Prendre une différence de temps en microsecondes entre la fin et le début
         * et l'enregistrer comme "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Enregistrer uniquement si le champ "prio" de l'événement de début est inférieur à 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Enregistrer uniquement si le champ "next_prio" de l'événement de fin est inférieur à 50
         * ou si la priorité de la tâche précédente n'était pas supérieure ou égale à 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Notez que ce qui précède n'a ajouté que : "next_prio < 50 || !(prev_prio >= 100"
         * C'est parce que lorsque le synthèse sera exécuté, le parenthèse fermante restant
         * sera ajouté. C'est-à-dire que la chaîne finira par être :
         * "next_prio < 50 || !(prev_prio >= 100)" lorsque l'un de tracefs_sync_create()
         * ou tracefs_sync_echo_cmd() sera exécuté.
         */
}
/* Afficher comment créer l'événement synthétique */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Créer l'événement synthétique */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Supprimer l'événement synthétique */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}
