sous-routine ctrexc (caractère compq, entier n, complexe, dimension( ldt, * ) t, entier ldt, complexe, dimension( ldq, * ) q, entier ldq, entier ifst, entier ilst, entier info)

CTREXC

Objectif :

!>
!> CTREXC réorganise la factorisation de Schur d'une matrice complexe
!> A = Q*T*Q**H, de sorte que l'élément diagonal de T d'indice de ligne IFST
!> soit déplacé à la ligne ILST.
!>
!> La forme de Schur T est réorganisée par une transformation unitaire de similarité
!> Z**H*T*Z, et éventuellement la matrice Q des vecteurs de Schur est mise à jour en
!> la post-multipliant par Z.
!>

Paramètres

COMPQ 
!>          COMPQ est CHARACTER*1
!>          = 'V':  met à jour la matrice Q des vecteurs de Schur ;
!>          = 'N':  ne met pas à jour Q.
!>

N

!>          N est un ENTIER
!>          L'ordre de la matrice T. N >= 0.
!>          Si N == 0, les arguments ILST et IFST peuvent avoir n'importe quelle valeur.
!>

T

!>          T est un tableau COMPLEXE, de dimension (LDT,N)
!>          En entrée, la matrice triangulaire supérieure T.
!>          En sortie, la matrice triangulaire supérieure réorganisée.
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

Q

!>          Q est un tableau COMPLEXE, de dimension (LDQ,N)
!>          En entrée, si COMPQ = 'V', la matrice Q des vecteurs de Schur.
!>          En sortie, si COMPQ = 'V', Q a été post-multipliée par la
!>          matrice de transformation unitaire Z qui réorganise T.
!>          Si COMPQ = 'N', Q n'est pas référencée.
!>

LDQ

!>          LDQ est un ENTIER
!>          La dimension principale du tableau Q. LDQ >= 1, et si
!>          COMPQ = 'V', LDQ >= max(1,N).
!>

IFST

!>          IFST est un ENTIER
!>

ILST

!>          ILST est un ENTIER
!>
!>          Spécifient la réorganisation des éléments diagonaux de T :
!>          L'élément d'indice de ligne IFST est déplacé à la ligne ILST par une
!>          séquence de transpositions entre éléments adjacents.
!>          1 <= IFST <= N; 1 <= ILST <= N.
!>

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Auteur

DTREXC

Objectif :

!>
!> DTREXC réorganise la factorisation de Schur réelle d'une matrice réelle
!> A = Q*T*Q**T, de sorte que le bloc diagonal de T d'indice de ligne IFST soit

!> bloc diagonal 2x2 a ses éléments diagonaux égaux et ses
!> éléments hors diagonaux de signe opposé.
!>

Paramètres

COMPQ 
!>          COMPQ est un CARACTERE*1
!>          = 'V':  met à jour la matrice Q des vecteurs de Schur ;
!>          = 'N':  ne met pas à jour Q.

N

!>          N est un ENTIER
!>          L'ordre de la matrice T. N >= 0.

!>

T

!>          T est un tableau DOUBLE PRECISION, de dimension (LDT,N)
!>          En entrée, la matrice quasi-triangulaire supérieure T, sous forme
!>          canonique de Schur.
!>          En sortie, la matrice quasi-triangulaire supérieure réorganisée,
!>          à nouveau sous forme canonique de Schur.
!>

LDT

!>          LDT est un ENTIER
!>          La dimension principale du tableau T. LDT >= max(1,N).
!>

Q

!>          Q est un tableau DOUBLE PRECISION, de dimension (LDQ,N)
!>          En entrée, si COMPQ = 'V', la matrice Q des vecteurs de Schur.
!>          En sortie, si COMPQ = 'V', Q a été post-multipliée par la
!>          matrice de transformation orthogonale Z qui réorganise T.
!>          Si COMPQ = 'N', Q n'est pas référencée.
!>

LDQ

!>          LDQ est un ENTIER
!>          La dimension principale du tableau Q. LDQ >= 1, et si
!>          COMPQ = 'V', LDQ >= max(1,N).
!>

IFST

!>          IFST est un ENTIER
!>

ILST

!>          ILST est un ENTIER
!>
!>          Spécifient la réorganisation des blocs diagonaux de T.
!>          Le bloc d'indice de ligne IFST est déplacé à la ligne ILST, par une
!>          séquence de transpositions entre blocs adjacents.
!>          En sortie, si IFST pointait à l'entrée sur la deuxième ligne d'un bloc
!>          de 2x2, il pointe maintenant vers la première ligne ; ILST pointe
!>          toujours vers la première ligne du bloc dans sa position finale
!>          (qui peut différer de sa valeur d'entrée de +1 ou -1).
!>          1 <= IFST <= N; 1 <= ILST <= N.

WORK

!>          WORK est un tableau DOUBLE PRECISION, de dimension (N)

INFO

!>          INFO est un ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          = 1 : deux blocs adjacents étaient trop proches pour être échangés (le problème
!>                est très mal conditionné) ; T a pu être partiellement
!>                réorganisée, et ILST pointe vers la première ligne de
!>                la position actuelle du bloc déplacé.
!>

NAME

strexc, ztrexc - reorder the Schur factorization of a real or complex matrix

SYNOPSIS

  subroutine strexc (character compq, integer n, real, dimension( ldt, * ) t, integer ldt, real, dimension( ldq, * ) q, integer ldq, integer ifst, integer ilst, integer info)

  subroutine ztrexc (character compq, integer n, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( ldq, * ) q, integer ldq, integer ifst, integer ilst, integer info)

Detailed Description

The purpose of STREXC is to reorder the Schur factorization of a real matrix A = Q*T*Q**T, so that the diagonal block of T with row index IFST is moved to row ILST. The real Schur form T is reordered by an orthogonal similarity transformation Z**T*T*Z, and optionally the matrix Q of Schur vectors is updated by postmultiplying it with Z. T must be in Schur canonical form (as returned by SHSEQR), that is, block upper triangular with 1-by-1 and 2-by-2 diagonal blocks; each 2-by-2 diagonal block has its diagonal elements equal and its off-diagonal elements of opposite sign.

The purpose of ZTREXC is to reorder the Schur factorization of a complex matrix A = Q*T*Q**H, so that the diagonal element of T with row index IFST is moved to row ILST. The Schur form T is reordered by a unitary similarity transformation Z**H*T*Z, and optionally the matrix Q of Schur vectors is updated by postmultiplying it with Z.

subroutine strexc (character compq, integer n, real, dimension( ldt, * ) t, integer ldt, real, dimension( ldq, * ) q, integer ldq, integer ifst, integer ilst, integer info)

STREXC

Purpose:

!>
!> STREXC reorders the real Schur factorization of a real matrix
!> A = Q*T*Q**T, so that the diagonal block of T with row index IFST is
!> moved to row ILST.
!>
!> The real Schur form T is reordered by an orthogonal similarity
!> transformation Z**T*T*Z, and optionally the matrix Q of Schur vectors
!> is updated by postmultiplying it with Z.
!>
!> T must be in Schur canonical form (as returned by SHSEQR), that is,
!> block upper triangular with 1-by-1 and 2-by-2 diagonal blocks; each
!> 2-by-2 diagonal block has its diagonal elements equal and its
!> off-diagonal elements of opposite sign.
!>

Parameters

COMPQ 
!>          COMPQ is CHARACTER*1
!>          = 'V':  update the matrix Q of Schur vectors;
!>          = 'N':  do not update Q.
!>

N

!>          N is INTEGER
!>          The order of the matrix T. N >= 0.
!>          If N == 0 arguments ILST and IFST may be any value.
!>

T

!>          T is REAL array, dimension (LDT,N)
!>          On entry, the upper quasi-triangular matrix T, in Schur
!>          Schur canonical form.
!>          On exit, the reordered upper quasi-triangular matrix, again
!>          in Schur canonical form.
!>

LDT

!>          LDT is INTEGER
!>          The leading dimension of the array T. LDT >= max(1,N).
!>

Q

!>          Q is REAL array, dimension (LDQ,N)
!>          On entry, if COMPQ = 'V', the matrix Q of Schur vectors.
!>          On exit, if COMPQ = 'V', Q has been postmultiplied by the
!>          orthogonal transformation matrix Z which reorders T.
!>          If COMPQ = 'N', Q is not referenced.
!>

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of the array Q.  LDQ >= 1, and if
!>          COMPQ = 'V', LDQ >= max(1,N).
!>

IFST

!>          IFST is INTEGER
!>

ILST

!>          ILST is INTEGER
!>
!>          Specify the reordering of the diagonal blocks of T.
!>          The block with row index IFST is moved to row ILST, by a
!>          sequence of transpositions between adjacent blocks.
!>          On exit, if IFST pointed on entry to the second row of a
!>          2-by-2 block, it is changed to point to the first row; ILST
!>          always points to the first row of the block in its final
!>          position (which may differ from its input value by +1 or -1).
!>          1 <= IFST <= N; 1 <= ILST <= N.
!>

WORK

!>          WORK is REAL array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          = 1:  two adjacent blocks were too close to swap (the problem
!>                is very ill-conditioned); T may have been partially
!>                reordered, and ILST points to the first row of the
!>                current position of the block being moved.
!>
