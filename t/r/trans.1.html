NOM

trans - Traducteur en ligne de commande utilisant Google Translate, Bing Translator, Yandex.Translate, etc.

SYNTAXE

trans [OPTIONS] [SOURCE]:[CIBLES] [TEXTE]...

DESCRIPTION

Cet outil traduit du texte dans n'importe quelle langue depuis la ligne de commande, en utilisant un moteur de traduction tel que Google Translate, Bing Translator et Yandex.Translate.

Chaque argument qui n'est pas une option valide est traité comme TEXTE à traduire.

Si ni TEXTE ni le fichier d'entrée ne sont spécifiés par les arguments de la ligne de commande, le programme lira et traduira depuis l'entrée standard.

OPTIONS

Options d'information

-V, -version
Affiche la version et quitte.
-H, -help
Affiche le message d'aide et quitte.
-M, -man
Affiche la page de manuel et quitte.
-T, -reference
Affiche le tableau de référence de toutes les langues et codes supportés, puis quitte. Les noms des langues sont affichés dans leurs endonymes (nom de la langue dans la langue elle-même).
-R, -reference-english
Affiche le tableau de référence de toutes les langues et codes supportés, puis quitte. Les noms des langues sont affichés en anglais.
-S, -list-engines
Liste les moteurs de traduction disponibles et quitte.
-list-languages
Liste toutes les langues supportées (en endonymes) et quitte.
-list-languages-english
Liste toutes les langues supportées (avec les noms en anglais) et quitte.
-list-codes
Liste tous les codes supportés et quitte.
-list-all
Liste toutes les langues supportées (endonymes et noms anglais) et les codes, puis quitte.
-L CODES, -linguist CODES
Affiche les détails des langues et quitte. Lors de la spécification de deux codes de langue ou plus, concaténez-les avec un signe plus "+".
-U, -upgrade
Vérifie les mises à jour de ce programme.

Options du traducteur

-e ENGINE, -engine ENGINE
Spécifie le moteur de traduction à utiliser. (par défaut : auto)

Options d'affichage

-verbose
Mode verbeux.

Affiche le texte original et sa traduction la plus pertinente, puis sa notation phonétique (le cas échéant), puis ses traductions alternatives (le cas échéant) ou sa définition dans le dictionnaire (s'il s'agit d'un mot).

Cette option est inutile dans la plupart des cas car le mode verbeux est activé par défaut.

-b, -brief
Mode succinct.

Affiche uniquement la traduction la plus pertinente ou sa notation phonétique.

-d, -dictionary
Mode dictionnaire.

Affiche la définition du mot original dans le dictionnaire.

-identify
Identification de la langue.

Affiche la langue identifiée du texte original.

-show-original O/n
Affiche le texte original ou non. (par défaut : oui)
-show-original-phonetics O/n
Affiche la notation phonétique du texte original ou non. (par défaut : oui)
-show-translation O/n
Affiche la traduction ou non. (par défaut : oui)
-show-translation-phonetics O/n
Affiche la notation phonétique de la traduction ou non. (par défaut : oui)
-show-prompt-message O/n
Affiche le message d'invite ou non. (par défaut : oui)
-show-languages O/n
Affiche les langues source et cible ou non. (par défaut : oui)
-show-original-dictionary o/N
Affiche l'entrée du dictionnaire du texte original ou non. (par défaut : non)

Cette option est activée en mode dictionnaire.

-show-dictionary O/n
Affiche l'entrée du dictionnaire de la traduction ou non. (par défaut : oui)
-show-alternatives O/n
Affiche les traductions alternatives ou non. (par défaut : oui)
-w NUM, -width NUM
Spécifie la largeur de l'écran pour le remplissage.

Cette option remplace le paramètre de la variable d'environnement $COLUMNS.

-indent NUM
Spécifie la taille de l'indentation (nombre d'espaces). (par défaut : 4)
-theme NOMFICHIER
Spécifie le thème à utiliser. (par défaut : default)
-no-theme
N'utilise aucun thème autre que le thème par défaut.
-no-ansi
N'utilise pas les codes d'échappement ANSI.
-no-autocorrect
Ne corrige pas automatiquement. (si c'est le défaut du moteur de traduction)
-no-bidi
Ne convertit pas les textes bidirectionnels.
-bidi
Convertit toujours les textes bidirectionnels.
-no-warn
N'écrit pas les messages d'avertissement sur stderr.
-dump
Affiche la réponse brute de l'API à la place.

Options audio

-p, -play
Écouter la traduction.

Vous devez avoir au moins un des lecteurs audio supportés (mplayer, mpv ou mpg123) installé pour diffuser depuis le moteur Google Text-to-Speech. Sinon, un synthétiseur de parole local peut être utilisé à la place (say sur macOS, espeak sur Linux ou d'autres plateformes).

-speak
Écouter le texte original.
-n VOIX, -narrator VOIX
Spécifie le narrateur et écoute la traduction.

Les valeurs courantes pour cette option sont male et female.

-player PROGRAMME
Spécifie le lecteur audio à utiliser et écoute la traduction.

L'option -play essaiera d'utiliser mplayer, mpv ou mpg123 par défaut, car ces lecteurs sont connus pour fonctionner pour

adresses de streaming. Tous les lecteurs audio en ligne de commande ne peuvent pas fonctionner ainsi. Utilisez cette option uniquement lorsque vous avez vos propres préférences.

Cette option remplace le paramètre de la variable d'environnement $PLAYER.

-no-play
Ne pas écouter la traduction.
-no-translate
Ne rien traduire lors de l'utilisation de -speak.
-download-audio
Télécharger l'audio dans le répertoire courant.
-download-audio-as NOMFICHIER
Télécharger l'audio dans le fichier spécifié.

Options de pagination et de navigation dans le terminal

-v, -view
Afficher la traduction dans un paginator de terminal (less, more ou most).
-pager PROGRAMME
Spécifier le paginator de terminal à utiliser et afficher la traduction.

Cette option remplace le paramètre de la variable d'environnement $PAGER.

-no-view, -no-pager
Ne pas afficher la traduction dans un paginator de terminal.
-browser PROGRAMME
Spécifier le navigateur web à utiliser.

Cette option remplace le paramètre de la variable d'environnement $BROWSER.

-no-browser
Ne pas ouvrir le navigateur web.

Options réseau

-x HOTE:PORT, -proxy HOTE:PORT
Utiliser un proxy HTTP sur le port donné.

Cette option remplace les paramètres des variables d'environnement $HTTP_PROXY et $http_proxy.

-u CHAINE, -user-agent CHAINE
Spécifier l'agent utilisateur pour s'identifier.

Cette option remplace le paramètre des variables d'environnement $USER_AGENT.

-4, -ipv4, -inet4-only
Se connecter uniquement aux adresses IPv4.
-6, -ipv6, -inet6-only
Se connecter uniquement aux adresses IPv6.

Options de shell interactif

-I, -interactive, -shell
Démarrer un shell interactif, en invoquant rlwrap si possible (sauf si -no-rlwrap est spécifié).
-E, -emacs
Démarrer le frontal GNU Emacs pour un shell interactif.

Cette option n'a pas besoin, et ne peut pas être utilisée avec -I ou -no-rlwrap.

-no-rlwrap
Ne pas invoquer rlwrap lors du démarrage d'un shell interactif.

Cette option est utile lorsque le type de votre terminal n'est pas pris en charge par rlwrap (par exemple, emacs).

Options d'E/S

-i NOMFICHIER, -input NOMFICHIER
Spécifier le fichier d'entrée.

Le texte source à traduire sera lu depuis le fichier d'entrée, au lieu de l'entrée standard.

-o NOMFICHIER, -output NOMFICHIER
Spécifier le fichier de sortie.

Les traductions seront écrites dans le fichier de sortie, au lieu de la sortie standard.

Options de préférence de langue

-hl CODE, -host CODE
Spécifier votre langue maternelle (la langue dans laquelle vous souhaitez voir les messages d'invite dans la traduction).

Cette option n'affecte que l'affichage en mode détaillé (tout ce qui n'est pas la langue source et la langue cible sera affiché dans votre langue maternelle). Cette option n'a aucun effet en mode bref.

Cette option est facultative. Lorsque son paramètre est omis, l'anglais sera utilisé.

Cette option remplace les paramètres des variables d'environnement $LC_ALL, $LANG et $HOST_LANG.

-s CODES, -sl CODES, -source CODES, -from CODES
Spécifier la ou les langues sources (la ou les langues du texte original). Lors de la spécification de deux codes de langue ou plus, concaténez-les avec un signe plus "+".

Cette option est facultative. Lorsque son paramètre est omis, la langue du texte original sera identifiée automatiquement (avec une possibilité de mauvaise identification).

Cette option remplace le paramètre de la variable d'environnement $SOURCE_LANG.

-t CODES, -tl CODES, -target CODES, -to CODES
Spécifier la ou les langues cibles (la ou les langues du texte traduit). Lors de la spécification de deux codes de langue ou plus, concaténez-les avec un signe plus "+".

Cette option est facultative. Lorsque son paramètre est omis, tout sera traduit en anglais.

Cette option remplace les paramètres des variables d'environnement $LC_ALL, $LANG et $TARGET_LANG.

[SOURCE]:[CIBLES]
Une manière plus simple et alternative de spécifier la langue source et la ou les langues cibles est d'utiliser une chaîne de raccourci formatée :
•
CODE SOURCE:CODE CIBLE
•
CODE SOURCE:CODE CIBLE1+CODE CIBLE2+...
•
CODE SOURCE=CODE CIBLE
•
CODE SOURCE=CODE CIBLE1+CODE CIBLE2+...

Les délimiteurs ":" et "=" peuvent être utilisés indifféremment.

Soit SOURCE, soit CIBLES peut être omis, mais le caractère délimiteur doit être conservé.

Options de prétraitement du texte

-j, -join-sentence
Traiter tous les arguments comme une seule phrase.

Autres options

-no-init
Ne pas charger de script d'initialisation.
--
Fin des options.

Tous les arguments après cette option sont traités comme TEXTE à traduire.

STATUT DE SORTIE

0
Traduction réussie.
1
Erreur.

ENVIRONNEMENT

PAGER
Équivalent au paramètre d'option -pager.
BROWSER
Équivalent au paramètre d'option -browser.
PLAYER
Équivalent au paramètre d'option -player.
HTTP_PROXY
Équivalent au paramètre d'option -proxy.
USER_AGENT
Équivalent au paramètre d'option -user-agent.
HOST_LANG
Équivalent au paramètre d'option -host.
SOURCE_LANG
Équivalent au paramètre d'option -source.
TARGET_LANG
Équivalent au paramètre d'option -target.

FICHIERS

/etc/translate-shell
Script d'initialisation. (système)
$HOME/.translate-shell/init.trans
Script d'initialisation. (spécifique à l'utilisateur)
$XDG_CONFIG_HOME/translate-shell/init.trans
Script d'initialisation. (spécifique à l'utilisateur)
./.trans
Script d'initialisation. (répertoire courant)

trans(1) - Arch Linux Manual Pages

NAME

trans - translate shell

SYNOPSIS

trans [OPTION]... [FROM[:TO]] [TEXT]

DESCRIPTION

Translate Shell is an interactive command-line translation tool that supports multiple translation services.

OPTIONS

-
Interactive mode.
-s, --shell
Interactive shell mode.
-t, --terminal
Translate text from standard input to standard output.
-b, --brief
Brief mode. Output only the translation.
-f, --from FROM
Specify the source language.
-t, --to TO
Specify the target language.
-id
Detect language.
-l
List available languages.
-h, --help
Display help message and exit.
-v, --version
Display version information and exit.

EXIT STATUS

0 on success, non-zero on failure.

ENVIRONMENT

TRANSLATE_SHELL_API_KEY
Set your API key for translation services.

FILES

~/.config/translate-shell/config
User-specific configuration file.

FURTHER DOCUMENTATION

For more detailed information, refer to the online documentation at https://www.soimort.org/translate-shell/.

REPORTING BUGS

Please report bugs to the project's issue tracker at https://github.com/soimort/translate-shell/issues.

AUTHORS
