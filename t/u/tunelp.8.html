TUNELP(8) Administration système TUNELP(8)

NOM

tunelp - définit divers paramètres pour le périphérique lp

SYNTAXE

tunelp [options] périphérique

DESCRIPTION

tunelp définit plusieurs paramètres pour les périphériques /dev/lp?, pour de meilleures performances (ou pour toute performance que ce soit, si votre imprimante ne fonctionne pas sans cela...) Sans paramètres, il indique si le périphérique utilise des interruptions, et si oui, lesquelles. Avec des paramètres, il ajuste les caractéristiques du périphérique en conséquence.

OPTIONS

-i, --irq argument

spécifie l'IRQ à utiliser pour le port parallèle en question. Si ceci est réglé sur quelque chose de non nul, -t et -c n'ont aucun effet. Si votre port n'utilise pas d'interruptions, cette option arrêtera l'impression. La commande tunelp -i 0 rétablit une action non pilotée par interruption (interrogation), et votre imprimante devrait refonctionner. Si votre port parallèle prend en charge les interruptions, l'impression pilotée par interruption devrait être quelque peu plus rapide et efficace, et sera probablement souhaitable.

NOTE : Cette option n'aura aucun effet avec le noyau 2.1.131 ou une version ultérieure car l'IRQ est gérée par le pilote parport. Vous pouvez modifier l'IRQ de parport par exemple via /proc/parport/*/irq. Lisez /usr/src/linux/Documentation/admin-guide/parport.rst pour plus de détails sur parport.

-t, --time millisecondes

est le temps en jiffies pendant lequel le pilote attend si l'imprimante ne prend pas un caractère pour le nombre d'essais dicté par le paramètre -c. 10 est la valeur par défaut. Si vous voulez l'impression la plus rapide possible, et que la charge système ne vous importe pas, vous pouvez régler cette valeur à 0. Si la vitesse de votre imprimante ne vous importe pas, ou si vous imprimez du texte sur une imprimante lente avec un tampon, alors 500 (5 secondes) devrait suffire, et donnera une charge système très faible. Cette valeur devrait généralement être plus faible pour l'impression graphique que pour le texte, par un facteur d'environ 10, pour de meilleures performances.

-c, --chars caractères

est le nombre de fois où l'on essaie de sortir un caractère vers l'imprimante avant de dormir pendant -t TEMPS. C'est le nombre de tours de boucle qui tentent d'envoyer un caractère à l'imprimante. 120 semble être une bonne valeur pour la plupart des imprimantes en mode interrogation. 1000 est la valeur par défaut, car il y a certaines imprimantes qui deviennent saccadées sinon, mais vous devez régler ceci sur '1' pour gérer l'efficacité maximale du CPU si vous utilisez des interruptions. Si vous avez une imprimante très rapide, une valeur de 10 pourrait avoir plus de sens même en mode interrogation. Si vous avez une *très* vieille imprimante, vous pouvez augmenter cette valeur.

Régler -t TEMPS à 0 est équivalent à régler -c CARACTERES à l'infini.

-w, --wait millisecondes

est le nombre d'microsecondes d'attente lors de la manipulation du signal de strobing. Alors que la plupart des imprimantes semblent pouvoir gérer un signal de strobing extrêmement court, certaines imprimantes exigent un signal plus long. Augmenter cela par rapport à la valeur par défaut de 1 peut permettre d'imprimer avec ces imprimantes. Cela peut également permettre d'utiliser des câbles plus longs. Il est également possible de diminuer cette valeur à 0 si votre imprimante est suffisamment rapide ou votre machine est suffisamment lente.

-a, --abort <on|off>

Il s'agit de savoir s'il faut abandonner en cas d'erreur d'imprimante - par défaut, il ne faut pas le faire. Si vous êtes assis devant votre ordinateur, vous voudrez probablement pouvoir voir une erreur et la corriger, et que l'imprimante continue d'imprimer. D'autre part, si vous n'y êtes pas, vous préféreriez peut-être que votre gestionnaire d'impression réalise que l'imprimante n'est pas prête, arrête d'essayer, et vous envoie un e-mail à ce sujet. Le choix vous appartient.

-o, --check-status <on|off>

Cette option est très similaire à -a. Elle fait en sorte que toute ouverture(2) de ce périphérique vérifie que le périphérique est en ligne et ne signale aucune erreur de manque de papier ou autre. C'est le réglage correct pour la plupart des versions de lpd.

-C, --careful <on|off>

Cette option ajoute une vérification d'erreur supplémentaire ("prudente"). Lorsque cette option est activée, le pilote d'imprimante s'assurera que l'imprimante est en ligne et ne signale aucune erreur de manque de papier ou autre avant d'envoyer des données. Ceci est particulièrement utile pour les imprimantes qui semblent normalement accepter des données lorsqu'elles sont éteintes.

NOTE : Cette option est obsolète car elle est par défaut dans le noyau 2.1.131 ou ultérieur.

-s, --status

Cette option renvoie l'état actuel de l'imprimante, à la fois sous forme d'un nombre décimal de 0 à 255, et sous forme d'une liste de flags actifs. Lorsque cette option est spécifiée, -q off, désactivant l'affichage de l'IRQ actuelle, est implicite.

-r, --reset

Cette option réinitialise le port. Elle nécessite un noyau Linux version 1.1.80 ou ultérieure.

-q, --print-irq <on|off>

Cette option active l'impression de l'affichage du réglage IRQ actuel.

FICHIERS

/dev/lp?, /proc/parport/*/*

NOTES

-o, -C, et -s nécessitent une version du noyau Linux 1.1.76 ou ultérieure.

-C nécessite une version Linux antérieure à 2.1.131.
