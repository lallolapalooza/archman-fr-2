NOM

tuned-profiles-sap - description des profils fournis pour SAP NetWeaver

DESCRIPTION

Ces profils fournissent des optimisations de performance pour les applications SAP NetWeaver.

PROFILS

Les profils suivants sont fournis :

sap-netweaver
Un profil optimisé pour la performance des applications SAP NetWeaver. Il est basé sur le profil de performance de débit (throughput-performance). Il ajuste en plus les paramètres sysctl concernant la mémoire partagée, les sémaphores et le nombre maximum de zones de mappage mémoire qu'un processus peut avoir.
