NOM

tuned-profiles-spectrumscale-ece - description des profils fournis pour Spectrum Scale Erasure Code Edition

DESCRIPTION

Ces profils sont fournis pour les serveurs Spectrum Scale Erasure Code Edition.

PROFILS

Les profils suivants sont fournis :

spectrumscale-ece
Profil optimisé pour Spectrum Scale Erasure Code Edition basé sur le profil de performance de débit. Il active en outre l'équilibrage NUMA automatique et modifie d'autres paramètres du noyau liés à la performance.
