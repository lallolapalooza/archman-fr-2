NOM

tuned-profiles-oracle - description des profils fournis pour Oracle

DESCRIPTION

Ces profils sont fournis pour les charges de travail Oracle.

PROFILS

Les profils suivants sont fournis :

oracle
Profil optimisé pour les bases de données Oracle basé sur le profil de performance de débit. Il désactive en plus les énormes pages transparentes et modifie certains autres paramètres du noyau liés à la performance.
