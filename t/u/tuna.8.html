NOM

tuna - programme pour ajuster les processus en cours d'exécution

SYNTAXE

tuna [OPTIONS]

DESCRIPTION

Cette page de manuel explique le programme tuna. Ce programme peut être utilisé pour modifier les attributs des processus applicatifs et des processus du noyau. tuna peut opérer sur les IRQ par nom ou par numéro, et sur les tâches ou fils d'exécution par ID de processus ou ligne de commande. Les CPUs et les ensembles de CPUs peuvent être spécifiés par numéro de CPU ou de socket. Les noms d'IRQ et les lignes de commande des processus peuvent inclure des jokers.

tuna peut modifier la politique de planification, la priorité du planificateur et l'affinité processeur pour les processus et les fils d'exécution des processus. tuna peut également modifier l'affinité processeur pour les interruptions. Lorsque tuna est invoqué sans aucune option, il démarre en mode interface graphique. Cette page de manuel n'explique que les options en ligne de commande de tuna.

OPTIONS GLOBALES

-h, --help
Affiche une liste d'options. tuna quittera après cette action, en ignorant le reste de la ligne de commande.
-v, --version
Affiche la version
-L, --logging=NIVEAU-LOG
Journalise les détails de l'application dans un fichier pour le NIVEAU-LOG donné
-D, --debug
Affiche les détails de journalisation au niveau DEBUG sur la console

COMMANDES

tuna cpu_power
usage: tuna-cmd.py cpu_power [-h] (-c LISTE-CPU)

Définit ou interroge les états d'inactivité (power) de tous les CPUs ou d'une sélection de CPUs dans la LISTE-CPU. Les modificateurs -c peuvent être utilisés pour passer la LISTE-CPU des CPUs sur lesquels effectuer la commande.

arguments optionnels :
-h, --help affiche ce message d'aide et quitte
-i, --idle-info Affiche des informations générales sur l'inactivité pour les CPUs sélectionnés, y compris
les valeurs d'index pour IDLE-STATE.
-s, --status IDLE-STATE
Affiche si IDLE-STATE est activé sur les CPUs sélectionnés.
-d, --disable IDLE-STATE
Désactive IDLE-STATE sur les CPUs sélectionnés.
-e, --enable IDLE-STATE
Active IDLE-STATE sur les CPUs sélectionnés.
-c LISTE-CPU, --cpus LISTE-CPU
LISTE-CPU affectée par les commandes

tuna priority
usage: tuna-cmd.py priority [-h] -t LISTE-THREAD [-C] POLITIQUE:RTPRIO

Définit les paramètres du planificateur de threads : POLITIQUE et RTPRIO. POLITIQUE est l'un des OTHER, FIFO, RR, ou BATCH. Fournissez POLITIQUE, RTPRIO, ou POLITIQUE:RTPRIO séparés par ":". Si seule la POLITIQUE est définie, la priorité RT sera par défaut à 1 si la politique est RT, et 0 sinon. Si seul RTPRIO est spécifié, la politique ne sera pas modifiée.

arguments positionnels :
POLITIQUE:RTPRIO Définit les paramètres du planificateur de threads : POLITIQUE et RTPRIO

arguments optionnels :
-h, --help affiche ce message d'aide et quitte
-t LISTE-THREAD, --threads LISTE-THREAD
LISTE-THREAD affectée par les commandes
-C, --affect_children
L'opération affectera les threads enfants

Modificateurs
-c, --cpus=LISTE-CPU
LISTE-CPU affectée par les commandes. Nécessite un numéro de CPU, une plage, ou une liste de numéros de CPU séparés par des virgules.
-S, --sockets=LISTE-SOCKET-CPU
LISTE-SOCKET-CPU affectée par les commandes. Nécessite un numéro de socket ou une liste de numéros de socket séparés par des virgules.
-t, --threads=LISTE-THREADS
LISTE-THREADS affectée par les commandes. Nécessite un numéro de thread ou un nom de thread, ou une liste de numéros et/ou noms de threads séparés par des virgules. Les noms de threads peuvent contenir des jokers. Assurez-vous de mettre entre guillemets ou d'échapper toute spécification de joker.

EXEMPLES D'UTILISATION

Si, par exemple, les cartes Ethernet ont plusieurs files d'attente pour la réception et la transmission, chacune avec sa propre IRQ, les IRQ Ethernet peuvent être associées à un socket CPU :

tuna isolate -S 2
tuna spread -q 'eth*' -S 2

Déplacer tout hors des CPU du socket 2, puis répartir les IRQ des périphériques Ethernet sur ces mêmes CPU.
