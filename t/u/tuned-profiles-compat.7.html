NOM

tuned-profiles-compat - description des profils fournis pour la compatibilité ascendante

DESCRIPTION

Ces profils sont fournis pour la compatibilité ascendante avec tuned-1x. Ils ne sont plus maintenus et peuvent être supprimés à tout moment dans le futur. Il n'est pas recommandé de les utiliser à d'autres fins que la compatibilité ascendante. Certains d'entre eux ne sont que des alias vers des profils TuneD de base. Veuillez ne pas utiliser les profils de compatibilité dans de nouvelles installations et préférer les profils du paquet tuned de base ou d'autres sous-paquets de tuned.

PROFIL(S)

Les profils suivants sont considérés comme des profils de compatibilité :

défaut
C'est le profil le moins économe en énergie disponible et il active uniquement les plugins CPU et disque de TuneD.
desktop-powersave
Un profil d'économie d'énergie destiné aux systèmes de bureau. Il active l'économie d'énergie ALPM pour les adaptateurs hôtes SATA ainsi que les plugins CPU, ethernet et disque de TuneD.
server-powersave
Un profil d'économie d'énergie destiné aux systèmes serveur. Il active l'économie d'énergie ALPM pour les adaptateurs hôtes SATA et active les plugins CPU et disque de TuneD.
laptop-ac-powersave
Profil d'économie d'énergie moyen destiné aux ordinateurs portables fonctionnant sur secteur. Il active l'économie d'énergie ALPM pour les adaptateurs hôtes SATA, l'économie d'énergie WiFi ainsi que les plugins CPU, ethernet et disque de TuneD.
laptop-battery-powersave
Profil d'économie d'énergie fort destiné aux ordinateurs portables fonctionnant sur batterie. Actuellement, c'est un alias du profil powersave.
spindown-disk
Profil d'économie d'énergie fort destiné aux machines avec des disques durs classiques. Il active un arrêt agressif des disques. Les valeurs de réécriture des disques sont augmentées et la "swappiness" du disque est diminuée. La synchronisation des journaux est désactivée. Toutes les partitions sont remontées avec l'option 'noatime'.
enterprise-storage
Profil serveur pour le réglage de performance de débit disque élevé. Désactive les mécanismes d'économie d'énergie et active les hugepages. Les valeurs de lecture anticipée du disque sont augmentées. Le gouverneur CPU est réglé sur performance.
