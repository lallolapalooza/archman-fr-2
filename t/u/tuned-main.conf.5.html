NOM

tuned-main.conf - Fichier de configuration global de TuneD

SYNTAXE

/etc/tuned/tuned-main.conf

DESCRIPTION

Cette page de manuel décrit le format du fichier de configuration global de TuneD. Le fichier tuned-main.conf utilise le format de fichier ini.

daemon=BOOL
Ceci définit si TuneD utilisera un démon ou non. C'est une valeur booléenne. Elle peut être True ou 1 si le démon est activé et False ou 0 s'il est désactivé. Il n'est pas recommandé de désactiver le démon, car de nombreuses fonctions ne fonctionneront pas sans démon, par exemple, il n'y aura pas de D-Bus, pas de restauration des paramètres, pas de prise en charge du hotplug, pas de réglage dynamique, ...
dynamic_tuning=BOOL
Ceci définit si le réglage dynamique est activé. C'est une valeur booléenne. Elle peut être True ou 1 si le réglage dynamique est activé et False ou 0 s'il est désactivé. Dans ce cas, seul le réglage statique sera utilisé. Veuillez noter que s'il est activé ici, il est toujours possible de le désactiver individuellement dans les plugins. Il n'est applicable que si daemon est activé.
sleep_interval=INT
Le démon TuneD est réveillé périodiquement après INT secondes et vérifie les événements. Par défaut, il est réglé sur 1 seconde. Si vous avez un interpréteur Python 2 avec le correctif du Red Hat Bugzilla #917709, ceci contrôle le temps de réactivité de TuneD aux commandes (c'est-à-dire si vous demandez un changement de profil, il peut s'écouler jusqu'à 1 seconde avant que TuneD ne réagisse). Augmentez ce nombre pour des temps de réactivité plus longs et plus d'économies d'énergie (en raison d'un plus petit nombre de réveils). Si vous avez un interpréteur Python 2 non patché, ce réglage n'aura aucun effet visible, car l'interpréteur interrogera 20 fois par seconde. Il n'est applicable que si daemon est activé.
update_interval=INT
Intervalle de mise à jour pour le réglage dynamique (en secondes). Le démon TuneD est réveillé périodiquement après INT secondes, met à jour ses moniteurs, calcule de nouveaux paramètres de réglage pour les plugins activés et applique les changements. Les plugins qui ont désactivé le réglage dynamique ne sont pas traités. Par défaut, INT est réglé sur 10 secondes. Le démon TuneD ne se réveille pas périodiquement si le réglage dynamique est globalement désactivé (voir dynamic_tuning) ou si ce réglage est défini sur 0. Ceci doit être un multiple de sleep_interval. Il n'est applicable que si daemon est activé.
recommend_command=BOOL
Ceci contrôle si la fonctionnalité de recommandation sera activée ou non. C'est une valeur booléenne. Elle peut être True ou 1 si la commande recommend est activée et False ou 0 si elle est désactivée. Si elle est désactivée, la commande recommend ne sera pas disponible dans l'interface en ligne de commande, TuneD ne parsèrera pas recommend.conf et retournera un profil codé en dur (par défaut balanced). Il n'est applicable que si daemon est activé. Par défaut, il est réglé sur True.
reapply_sysctl=BOOL
Ceci contrôle si les paramètres sysctl de /run/sysctl.d/*.conf, /etc/sysctl.d/*.conf et /etc/sysctl.conf doivent être réappliqués après l'application des paramètres sysctl de TuneD. Ce sont des emplacements pris en charge par sysctl --system, à l'exclusion de ceux qui contiennent des fichiers de configuration sysctl fournis par des paquets système. Ainsi, si reapply_sysctl est défini sur True ou 1, les paramètres sysctl de TuneD ne remplaceront pas les paramètres sysctl fournis par l'utilisateur. S'il est défini sur False ou 0, les paramètres sysctl de TuneD remplaceront les paramètres sysctl système. Par défaut, il est réglé sur True.
default_instance_priority=INT
Priorité par défaut de l'instance (unité). Par défaut, elle est de 0. Chaque unité a une priorité qui est par défaut définie sur INT. Elle peut être surchargée dans le profil TuneD par l'option priority. Les unités TuneD sont traitées dans l'ordre défini par leurs priorités, c'est-à-dire que l'unité avec le plus petit nombre est traitée en premier.

EXEMPLE

  no_daemon = 0
  dynamic_tuning = 1
  sleep_interval = 1
  update_interval = 10
  recommend_command = 0
  reapply_sysctl = 1
  default_instance_priority = 0

FICHIERS

/etc/tuned/tuned-main.conf
