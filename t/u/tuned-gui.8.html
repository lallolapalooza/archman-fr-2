NOM

tuned-gui - interface graphique pour la configuration de TuneD

SYNOPSIS

tuned-gui

DESCRIPTION

tuned-gui est une interface graphique pour la configuration du démon TuneD. L'interface graphique permet à l'utilisateur de créer, supprimer ou mettre à jour facilement des profils TuneD et de charger ces profils dans TuneD. Il est également possible d'explorer tous les plugins disponibles et les informations à leur sujet, comme leur description ou l'aide pour leurs paramètres de configuration.

ONGLETS

RÉSUMÉ
Affiche le profil actif actuel et la configuration des plugins utilisés par celui-ci.
PROFILS
Affiche les profils disponibles et leur origine (Système | Utilisateur). Les profils peuvent être gérés via les boutons « créer un nouveau profil », « Modifier » et « Supprimer ».
PLUGINS
Affiche les plugins disponibles et toutes les informations accessibles à leur sujet.
