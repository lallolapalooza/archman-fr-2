NOM

tuned-profiles - description des profils TuneD de base

DESCRIPTION

Ce sont les profils de base qui sont principalement fournis dans le paquet de base tuned. Ils sont ciblés pour divers objectifs. Principalement, ils fournissent des optimisations de performance, mais il existe également des profils axés sur la faible consommation d'énergie, la faible latence et d'autres.

Vous pouvez largement déduire l'objectif du profil par son nom ou consulter la description complète ci-dessous.

Les profils sont stockés dans des sous-répertoires sous /usr/lib/tuned/profiles/. Si vous avez besoin de personnaliser les profils, vous pouvez les copier dans /etc/tuned/profiles/ et les modifier selon vos besoins. Lors du chargement de profils portant le même nom, /etc/tuned/profiles/ a la priorité. Dans ce cas, vous ne perdrez pas vos profils personnalisés entre les mises à jour de TuneD.

Les profils d'économie d'énergie contiennent des réglages qui ne sont généralement pas activés par défaut car ils auront un impact notable sur la latence/performance de votre système, contrairement aux mécanismes d'économie d'énergie activés par défaut. D'autre part, les profils de performance désactivent les mécanismes d'économie d'énergie supplémentaires de TuneD car ils auraient un impact négatif sur le débit ou la latence.

PROFILS

Pour le moment, nous fournissons les profils prédéfinis suivants :

balanced
C'est le profil par défaut. Il offre un équilibre entre économie d'énergie et performance. Actuellement, il active les plugins CPU et disque de TuneD et s'assure que le gouverneur conservateur est actif (si supporté par le pilote cpufreq actuel). Il active l'économie d'énergie ALPM pour les contrôleurs hôtes SATA et définit la politique de gestion de liaison d'alimentation sur medium_power. Il définit également le biais d'efficacité énergétique du CPU sur normal. Il active également l'économie d'énergie audio AC97 ou (selon votre système) les économies d'énergie HDA-Intel (avec un délai de 10 secondes). Si votre système contient une carte graphique Radeon prise en charge (avec KMS activé), il la configure pour une économie d'énergie automatique.
balanced-battery
Profil principalement utilisé par tuned-ppd si le profil balanced est demandé et que la machine fonctionne sur batterie. Il est basé sur le profil balanced. Il définit en outre energy_performance_preference sur balance_power, active l'amélioration des performances du cœur amd-pstate, et active les économies d'énergie du panneau vidéo.
powersave
Économie d'énergie maximale. Actuellement, il active la suspension automatique de l'USB (si la variable d'environnement USB_AUTOSUSPEND est définie sur 1), active l'économie d'énergie ALPM pour les contrôleurs hôtes SATA et définit la politique de gestion de liaison d'alimentation sur min_power. Il active également l'économie d'énergie WiFi et s'assure que le gouverneur ondemand est actif (si supporté par le pilote cpufreq actuel). Il définit le biais d'efficacité énergétique du CPU sur powersave. Il active également l'économie d'énergie audio AC97 ou (selon votre système) les économies d'énergie HDA-Intel (avec un délai de 10 secondes). Si votre système contient une carte graphique Radeon prise en charge (avec KMS activé), il la configure pour une économie d'énergie automatique. Sur les Asus Eee PCs, le Super Hybrid Engine dynamique est activé.
throughput-performance
Profil pour l'optimisation typique du débit. Désactive les mécanismes d'économie d'énergie et active les paramètres sysctl qui améliorent le débit de votre disque et de votre E/S réseau. Le gouverneur CPU est réglé sur performance et le biais d'efficacité énergétique du CPU est réglé sur performance. Les valeurs de prélecture du disque sont augmentées.
accelerator-performance
Ce profil contient les mêmes réglages que le profil throughput-performance. De plus, il bloque le CPU sur des états C bas afin que la latence soit inférieure à 100 µs. Cela améliore les performances de certains accélérateurs, tels que les GPU.
latency-performance
Profil pour l'optimisation de la faible latence. Désactive les mécanismes d'économie d'énergie. Le gouverneur CPU est réglé sur performance et bloqué sur les états C bas (via PM QoS). Le biais d'efficacité énergétique du CPU est réglé sur performance.
network-throughput
Profil pour l'optimisation du débit réseau. Il est basé sur le profil throughput-performance. Il augmente en outre les tampons réseau du noyau.
network-latency
Profil pour l'optimisation de la faible latence réseau. Il est basé sur le profil latency-performance. Il désactive en outre les pages énormes transparentes, l'équilibrage NUMA et ajuste plusieurs autres paramètres sysctl liés au réseau.
desktop
Profil optimisé pour les bureaux basé sur le profil balanced. Il active en outre les autogroupes de planification pour une meilleure réactivité des applications interactives.
hpc-compute
Profil optimisé pour le calcul haute performance. Il est basé sur le profil latency-performance.
virtual-guest
Profil optimisé pour les invités virtuels basé sur le profil throughput-performance. Il diminue en outre le swappiness de la mémoire virtuelle et augmente les paramètres de dirty_ratio.
virtual-host
Profil optimisé pour les hôtes virtuels basé sur le profil throughput-performance. Il active en outre une écriture plus agressive des pages sales.
intel-sst
Profil optimisé pour les systèmes avec des configurations Intel Speed Select Technology définies par l'utilisateur. Ce profil est destiné à être utilisé comme une superposition sur d'autres profils (par exemple, le profil cpu-partitioning), exemple : tuned-adm profile cpu-partitioning intel-sst
optimize-serial-console
Profil qui réduit l'activité E/S vers la console série en diminuant la valeur de printk. Cela devrait rendre la console série plus réactive. Ce profil est destiné à être utilisé comme une superposition sur d'autres profils (par exemple, le profil throughput-performance), exemple : tuned-adm profile throughput-performance optimize-serial-console
aws
Profil optimisé pour les instances AWS EC2. Il est basé sur le profil throughput-performance.
