INFORMATIONS GÉNÉRALES

turnadmin est un outil d'administration TURN. Cet outil peut être utilisé pour gérer les comptes utilisateurs (ajouter/supprimer des utilisateurs, générer des clés TURN pour les utilisateurs). Pour des raisons de sécurité, nous déconseillons de stocker les mots de passe en clair. La meilleure option est d'utiliser des "clés" pré-traitées qui sont ensuite utilisées pour l'authentification. Ces clés sont générées par turnadmin. Turnadmin est un lien vers l'exécutable turnserver, mais turnadmin effectue des fonctions différentes.

Note sur les options : turnadmin a des noms d'option longs et courts pour la plupart des options. Certaines options n'ont que la forme longue, certaines n'ont que la forme courte. Leur syntaxe est quelque peu différente, si un argument est requis :

La forme courte doit être utilisée comme suit (par exemple) :

  $ turnadmin -u <nom_utilisateur> ...
La forme longue équivalente doit utiliser le caractère "=" : 
  $ turnadmin --user=<nom_utilisateur> ...
S'il s'agit d'une option drapeau (aucun argument requis), alors leur utilisation est la même, par exemple : 
 $ turnadmin -k ...
est équivalent à : 
 $ turnadmin --key ...
Vous devez toujours utiliser l'option -r <domaine> avec les commandes pour les identifiants à long terme - car les données pour plusieurs domaines peuvent être stockées dans la même base de données.

=====================================

NOM

turnadmin - outil d'administration de relais TURN.

SYNOPIS

$ turnadmin [commande] [options]
$ turnadmin [ -h | --help]

DESCRIPTION

Commandes :

-P, --generate-encrypted-password
Génère et affiche sur la sortie standard une forme chiffrée d'un mot de passe (pour l'utilisateur administrateur web ou la ligne de commande). La valeur peut alors être utilisée comme une clé sécurisée pour le stockage du mot de passe sur disque ou dans la base de données. Chaque invocation pour le même mot de passe produit un résultat différent. Le format du mot de passe chiffré est : $5$<...sel...>$<...sha256(sel+mot_de_passe)...>. Le sel fait 16 caractères, la sortie sha256 fait 64 caractères. Le caractère 5 est l'identifiant de l'algorithme (sha256). Seul sha256 est supporté en tant que fonction de hachage.
-k, --key
Génère une clé pour un utilisateur du mécanisme d'authentification à long terme.
-a, --add
Ajoute ou met à jour un utilisateur à long terme.
-A, --add-admin
Ajoute ou met à jour un utilisateur administrateur.
-d, --delete
Supprime un utilisateur à long terme.
-D, --delete-admin
Supprime un utilisateur administrateur.
-l, --list
Liste les utilisateurs à long terme dans la base de données.
-L, --list-admin
Liste les utilisateurs administrateurs dans la base de données.

-s, --set-secret=<valeur> Ajoute un secret partagé pour l'API REST TURN

-S, --show-secret
Affiche les secrets partagés stockés pour l'API REST TURN

-X, --delete-secret=<valeur> Supprime un secret partagé.

--delete-all_secrets
Supprime tous les secrets partagés pour l'API REST.
-O, --add-origin
Ajoute une relation origine-vers-domaine.
-R, --del-origin
Supprime une relation origine-vers-domaine.
-I, --list-origins
Liste les relations origine-vers-domaine.
-g, --set-realm-option
Définit les paramètres du domaine : max-bps, total-quota, user-quota.
-G, --list-realm-options
Liste les paramètres du domaine.
-E, --generate-encrypted-password-aes
Génère et affiche sur la sortie standard une forme chiffrée du mot de passe avec AES-128

Options avec valeurs requises :

-b, --db, --userdb
Nom du fichier de base de données utilisateur SQLite (défaut - /var/db/turndb ou /usr/local/var/db/turndb ou /var/lib/turn/turndb). Voir la même option dans la section turnserver.
-e, --psql-userdb
Chaîne de connexion à la base de données utilisateur PostgreSQL. Voir l'option --psql-userdb dans la section turnserver.
-M, --mysql-userdb
Chaîne de connexion à la base de données utilisateur MySQL. Voir l'option --mysql-userdb dans la section turnserver.
-J, --mongo-userdb
Chaîne de connexion à la base de données utilisateur MongoDB. Voir l'option --mysql-mongo dans la section turnserver.
-N, --redis-userdb
Chaîne de connexion à la base de données utilisateur Redis. Voir l'option --redis-userdb dans la section turnserver.
-u, --user
Nom d'utilisateur.
-r, --realm
Domaine.
-p, --password
Mot de passe.
-x, --key-path
Génère une clé de 128 bits dans le chemin donné.
-f, --file-key-path
Contient une clé de 128 bits dans le chemin donné.
-v, --verify
Vérifie un mot de passe chiffré donné en base64.
-o, --origin
Origine
--max-bps
Définit la valeur du paramètre max-bps du domaine.
--total-quota
Définit la valeur du paramètre total-quota du domaine.
--user-quota
Définit la valeur du paramètre user-quota du domaine.
-h, --help
Aide.

Exemples de commandes :

Générer une forme chiffrée d'un mot de passe :

$ turnadmin -P -p <mot_de_passe>

Générer une clé :

$ turnadmin -k -u <nom_utilisateur> -r <domaine> -p <mot_de_passe>

Ajouter/mettre à jour un utilisateur dans la base de données :

$ turnadmin -a [-b <fichier-db-utilisateurs> | -e <chaîne-connexion-bd> | -M <chaîne-connexion-bd> | -N <chaîne-connexion-bd> ] -u <nom_utilisateur> -r <domaine> -p <mot_de_passe>

Supprimer un utilisateur de la base de données :

$ turnadmin -d [-b <fichier-db-utilisateurs> | -e <chaîne-connexion-bd> | -M <chaîne-connexion-bd> | -N <chaîne-connexion-bd> ] -u <nom_utilisateur> -r <domaine>

Lister tous les utilisateurs à long terme dans la base de données MySQL :

$ turnadmin -l --mysql-userdb="<chaîne-connexion-bd>" -r <domaine>

Lister tous les utilisateurs administrateurs dans la base de données Redis :

$ turnadmin -L --redis-userdb="<chaîne-connexion-bd>"

Définir un secret dans la base de données MySQL :

$ turnadmin -s <secret> --mysql-userdb="<chaîne-connexion-bd>" -r <domaine>

Afficher le secret stocké dans la base de données PostgreSQL :

$ turnadmin -S --psql-userdb="<chaîne-connexion-bd>"

= =====================================

SYNOPSIS


turnadmin [--help] [--version]

Database connection options:


--mysql-userdb="<db-connection-string>"


--psql-userdb="<db-connection-string>"


--redis-userdb="<db-connection-string>"

Database manipulation options:


[-a | --add-user] [-u <username>] [-p <password>] [-e <realm>]


[-d | --del-user] [-u <username>] [-e <realm>]


[-l | --list-users] [-e <realm>]


[-x | --list-all-users]


[-c | --change-password] [-u <username>] [-p <new-password>] [-e <realm>]


[-r | --realm] <realm>


[-o | --origin] <origin>


[-I | --list-all-realms]


[-E | --encrypt]


[--key-path <key-file>]


[--file-key-path <key-file>]


[-v | --verify] <encrypted>

DESCRIPTION

The turnadmin utility is used for managing users and realms in the turn server.

Add user to MySQL DB:

$ turnadmin --mysql-userdb="<db-connection-string>" -a -u <username> -p <password> -e <realm>

Delete user from MySQL DB:

$ turnadmin --mysql-userdb="<db-connection-string>" -d -u <username> -e <realm>

List all users in MySQL DB:

$ turnadmin --mysql-userdb="<db-connection-string>" -x

List users for a specific realm in MySQL DB:

$ turnadmin --mysql-userdb="<db-connection-string>" -l -e <realm>

Change user password in MySQL DB:

$ turnadmin --mysql-userdb="<db-connection-string>" -c -u <username> -p <new-password> -e <realm>

Add realm to MySQL DB:

$ turnadmin --mysql-userdb="<db-connection-string>" -r <realm>

Delete realm from MySQL DB:

$ turnadmin --mysql-userdb="<db-connection-string>" -r <realm>

List all realms in MySQL DB:

$ turnadmin --mysql-userdb="<db-connection-string>" -I

Add user to PostgreSQL DB:

$ turnadmin --psql-userdb="<db-connection-string>" -a -u <username> -p <password> -e <realm>

Delete user from PostgreSQL DB:

$ turnadmin --psql-userdb="<db-connection-string>" -d -u <username> -e <realm>

List users for a specific realm in PostgreSQL DB:

$ turnadmin --psql-userdb="<db-connection-string>" -l -e <realm>

Change user password in PostgreSQL DB:

$ turnadmin --psql-userdb="<db-connection-string>" -c -u <username> -p <new-password> -e <realm>

Add realm to PostgreSQL DB:

$ turnadmin --psql-userdb="<db-connection-string>" -r <realm>

Delete realm from PostgreSQL DB:

$ turnadmin --psql-userdb="<db-connection-string>" -r <realm>

List all realms in PostgreSQL DB:

$ turnadmin --psql-userdb="<db-connection-string>" -I

List the origin-to-realm relations in PostgreSQL DB for a single realm:

$ turnadmin --psql-userdb="<db-connection-string>" -I -r <realm>

Add user to Redis DB:

$ turnadmin --redis-userdb="<db-connection-string>" -a -u <username> -p <password> -e <realm>

Delete user from Redis DB:

$ turnadmin --redis-userdb="<db-connection-string>" -d -u <username> -e <realm>

List users for a specific realm in Redis DB:

$ turnadmin --redis-userdb="<db-connection-string>" -l -e <realm>

Change user password in Redis DB:

$ turnadmin --redis-userdb="<db-connection-string>" -c -u <username> -p <new-password> -e <realm>

Add realm to Redis DB:

$ turnadmin --redis-userdb="<db-connection-string>" -r <realm>

Delete realm from Redis DB:

$ turnadmin --redis-userdb="<db-connection-string>" -r <realm>

Add origin-to-realm relation in MySQL database:

$ turnadmin --mysql-userdb="<db-connection-string>" -r <realm> -o <origin>

Delete origin-to-realm relation from Redis DB:

$ turnadmin --redis-userdb="<db-connection-string>" -o <origin>

List all origin-to-realm relations in Redis DB:

$ turnadmin --redis-userdb="<db-connection-string>" -I

List the origin-to-realm relations in PostgreSQL DB for a single realm:

$ turnadmin --psql-userdb="<db-connection-string>" -I -r <realm>

Create new key file for mysql password encryption:

$ turnadmin -E --key-path <key-file>

Create encrypted mysql password:

$ turnadmin -E --file-key-path <key-file> -p <secret>

Verify/decrypt encrypted password:

$ turnadmin --file-key-path <key-file> -v <encrypted>

Help:

$ turnadmin -h
