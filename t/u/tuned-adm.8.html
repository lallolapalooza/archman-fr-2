NOM

tuned-adm - outil en ligne de commande pour basculer entre différents profils d'optimisation

SYNTAXE

tuned-adm [list | active | profile [profil]... | profile_info [profil]... | off | auto_profile | profile_mode | verify [-i | --ignore-missing] | recommend | instance_acquire_devices appareils instance | get_instances [plugin] | instance_get_devices instance]

DESCRIPTION

Cette utilitaire en ligne de commande vous permet de basculer entre des profils d'optimisation définissables par l'utilisateur. Plusieurs profils prédéfinis sont déjà inclus. Vous pouvez même créer votre propre profil, soit en vous basant sur l'un des profils existants en le copiant, soit en créant un profil entièrement nouveau. Les profils fournis par la distribution sont stockés dans des sous-répertoires sous /usr/lib/tuned/profiles/ et les profils définis par l'utilisateur dans des sous-répertoires sous /etc/tuned/profiles/. S'il existe des profils du même nom aux deux endroits, les profils définis par l'utilisateur ont la priorité.

OPTIONS

list
Lister tous les profils disponibles.
profiles Lister tous les profils disponibles.

plugins Lister tous les plugins disponibles.

-v, --verbose Lister les options de configuration du plugin et leurs indices.

active
Afficher le profil actif actuel.
profile [NOM_DU_PROFIL]...
Bascule vers le profil donné. Si plusieurs profils sont donnés, les profils sont fusionnés (en cas de paramètres conflictuels, le paramètre du dernier profil est utilisé) et le profil résultant est appliqué. Si aucun profil n'est donné, alors tous les profils disponibles sont listés. Si le profil donné n'est pas valide, la commande se termine gracieusement sans effectuer d'opération.
profile_info [NOM_DU_PROFIL]...
Afficher des informations/descriptions du profil donné ou du profil actuel si aucun profil n'est spécifié.
verify [-i | --ignore-missing]
Vérifie le profil actuel par rapport aux paramètres système. Affiche des informations indiquant si les paramètres système correspondent au profil actuel ou non (par exemple, si quelqu'un a modifié une valeur sysfs/sysctl manuellement). Des informations détaillées sur ce qui est vérifié, quelle valeur est définie et quelle valeur est attendue peuvent être trouvées dans le journal. Avec -i ou --ignore-missing, cela ne traite pas l'optimisation manquante (optimisation non supportée par la plateforme) comme une erreur.
recommend
Recommande un profil adapté à votre système. Actuellement, seule la détection statique est implémentée - elle décide en fonction des données de /etc/system-release-cpe et de la sortie de virt-what. Les règles de détection automatique sont définies dans le fichier /usr/lib/tuned/recommend.d/50-tuned.conf. Les règles par défaut recommandent des profils axés sur les meilleures performances, ou le profil équilibré en cas de doute.

Les règles par défaut peuvent être remplacées par l'utilisateur en plaçant un fichier nommé recommend.conf dans /etc/tuned, ou en créant un fichier dans le répertoire /etc/tuned/recommend.d. Le fichier /etc/tuned/recommend.conf est évalué en premier. Si aucune correspondance n'est trouvée, les fichiers du répertoire /etc/tuned/recommend.d sont fusionnés avec les fichiers du répertoire /usr/lib/tuned/recommend.d (s'il existe un fichier du même nom dans les deux répertoires, celui de /etc/tuned/recommend.d est utilisé) et les fichiers sont évalués par ordre alphabétique. La première entrée correspondante est utilisée.

auto_profile
Active le mode de sélection automatique de profil, bascule vers le profil recommandé.
profile_mode
Affiche le mode de sélection de profil actuel.
instance_acquire_devices appareils instance
Déplace tous les appareils fournis sous l'instance du plugin donnée. L'instance du plugin est identifiée par son nom issu du profil TuneD.

Les appareils sont spécifiés à l'aide d'une liste séparée par des virgules. Lors du déplacement d'un ensemble de processeurs, il est possible d'utiliser la syntaxe `cpulist` en incluant le préfixe `cpulist:`. Par exemple, `cpulist:0,2-4` déplacera les appareils cpu0, cpu1, cpu2 et cpu4.

get_instances [plugin]
Liste les instances actives d'un plugin donné ou toutes les instances actives si aucun plugin n'est spécifié.
instance_get_devices instance
Liste les appareils actuellement assignés à une instance donnée.
off
Décharge les optimisations.
