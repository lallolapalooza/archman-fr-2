ttk::scrollbar(n) Tk Themed Widget ttk::scrollbar(n)

NOM

ttk::scrollbar - Contrôler la vue d'un widget défilable

SYNOPSIS

ttk::scrollbar cheminNom ?options...?

DESCRIPTION

Les widgets ttk::scrollbar sont généralement liés à une fenêtre associée qui affiche un document quelconque, tel qu'un fichier en cours d'édition ou un dessin. Une barre de défilement affiche une poignée dans la partie centrale de la barre, dont la position et la taille fournissent des informations sur la portion du document visible dans la fenêtre associée. La poignée peut être déplacée par l'utilisateur pour contrôler la région visible. Selon le thème, deux ou plusieurs boutons fléchés peuvent également être présents ; ceux-ci sont utilisés pour faire défiler la région visible par unités discrètes.

OPTIONS STANDARD

-class	-cursor	-style
-takefocus

Voir l'entrée de manuel ttk::widget pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de ligne de commande : -command
Nom dans la base de données : command
Classe dans la base de données : Command
Un script Tcl préfixe à évaluer pour modifier la vue dans le widget associé à la barre de défilement. Des arguments supplémentaires sont ajoutés à la valeur de cette option, comme décrit dans COMMANDES DE DÉFILEMENT ci-dessous, chaque fois que l'utilisateur demande un changement de vue en manipulant la barre de défilement.

Cette option se compose généralement d'une liste de deux éléments, contenant le nom d'un widget défilable suivi de xview (pour les barres de défilement horizontales) ou yview (pour les barres de défilement verticales).

Nom de ligne de commande : -orient
Nom dans la base de données : orient
Classe dans la base de données : Orient
L'un de horizontal ou vertical. Spécifie l'orientation de la barre de défilement.

COMMANDE DU WIDGET

cheminNom cget option
Retourne la valeur actuelle de l'option spécifiée ; voir ttk::widget(n).
cheminNom configure ?option? ?valeur option valeur ...?
Modifie ou interroge les options du widget ; voir ttk::widget(n).
cheminNom get
Retourne les paramètres de la barre de défilement sous forme d'une liste dont les éléments sont les arguments de la dernière commande set du widget.
cheminNom identify x y
Retourne le nom de l'élément à la position x, y. Voir ttk::widget(n).
cheminNom instate statespec ?script?
Teste l'état du widget ; voir ttk::widget(n).
cheminNom set premier dernier
Cette commande est normalement appelée par le widget associé à la barre de défilement à partir d'une commande de rappel -xscrollcommand ou -yscrollcommand. Elle spécifie la plage visible à afficher. premier et dernier sont des fractions réelles comprises entre 0 et 1.
cheminNom state ?stateSpec?
Modifie ou interroge l'état du widget ; voir ttk::widget(n).

COMMANDES INTERNES

Les commandes de widget suivantes sont utilisées en interne par les liaisons de la classe de widget TScrollbar.

cheminNom delta deltaX deltaY
Retourne un nombre réel indiquant le changement fractionnel du réglage de la barre de défilement qui correspond à un changement donné de la position de la poignée. Par exemple, si la barre de défilement est horizontale, le résultat indique de combien le réglage de la barre de défilement doit changer pour déplacer la poignée de deltaX pixels vers la droite (deltaY est ignoré dans ce cas). Si la barre de défilement est verticale, le résultat indique de combien le réglage de la barre de défilement doit changer pour déplacer la poignée de deltaY pixels vers le bas. Les arguments et le résultat peuvent être nuls ou négatifs.
cheminNom fraction x y
Retourne un nombre réel compris entre 0 et 1 indiquant où le point donné par x et y se situe dans la zone de la gouttière de la barre de défilement, où 0.0 correspond au haut ou à gauche de la gouttière et 1.0 correspond au bas ou à droite. x et y sont des coordonnées en pixels relatives au widget barre de défilement. Si x et y se réfèrent à un point à l'extérieur de la gouttière, le point le plus proche dans la gouttière est utilisé.

COMMANDES DE DÉFILEMENT

Lorsque l'utilisateur interagit avec la barre de défilement, par exemple en faisant glisser la poignée, la barre de défilement notifie au widget associé qu'il doit changer sa vue. La barre de défilement effectue la notification en évaluant une commande Tcl générée à partir de l'option -command de la barre de défilement. La commande peut prendre l'une des formes suivantes. Dans chaque cas, préfixe est le contenu de l'option -command, qui a généralement une forme telle que .t yview

préfixe moveto fraction
Fraction est un nombre réel compris entre 0 et 1. Le widget doit ajuster sa vue de manière à ce que le point donné par fraction apparaisse au début du widget. Si fraction est 0, il fait référence au début du document. 1.0 fait référence à la fin du document, 0.333 fait référence à un point un tiers du chemin dans le document, et ainsi de suite.
préfixe scroll nombre units
Le widget doit ajuster sa vue de nombre unités. Les unités sont définies de la manière qui convient le mieux au widget, comme des caractères ou des lignes dans un widget texte. Nombre est soit 1, ce qui signifie qu'une unité doit sortir du haut ou de la gauche de la fenêtre, soit -1, ce qui signifie qu'une unité doit sortir du bas ou de la droite de la fenêtre.
préfixe scroll nombre pages
Le widget doit ajuster sa vue de nombre pages. Il appartient au widget de définir la signification d'une page ; généralement, c'est légèrement moins que ce qui rentre dans la fenêtre, de sorte qu'il y ait un léger chevauchement entre l'ancienne et la nouvelle vue. Nombre est soit 1, ce qui signifie que la page suivante doit devenir visible, soit -1, ce qui signifie que la page précédente doit devenir visible.

ÉTATS DU WIDGET

La barre de défilement définit automatiquement le bit d'état disabled lorsque toute la plage est visible (la plage est de 0.0 à 1.0), et l'efface sinon. Elle définit également les indicateurs d'état active et pressed des éléments individuels, en fonction de la position et de l'état du pointeur de la souris.

EXEMPLE

set f [frame .f]
ttk::scrollbar $f.hsb -orient horizontal -command [list $f.t xview]
ttk::scrollbar $f.vsb -orient vertical -command [list $f.t yview]
text $f.t -xscrollcommand [list $f.hsb set] -yscrollcommand [list $f.vsb set]
grid $f.t -row 0 -column 0 -sticky nsew
grid $f.vsb -row 0 -column 1 -sticky nsew
grid $f.hsb -row 1 -column 0 -sticky nsew
grid columnconfigure $f 0 -weight 1
grid rowconfigure $f 0 -weight 1
pack $f

OPTIONS DE STYLE

Le nom de la classe pour un ttk::scrollbar est TScrollbar.

États dynamiques : active, disabled.

Les options de style de TScrollbar (ou plus précisément Vertical.TScrollbar et Horizontal.TScrollbar) qui sont configurables avec ttk::style sont :

-arrowcolor couleur
-arrowsize montant
-background couleur
-bordercolor
