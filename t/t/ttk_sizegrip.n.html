ttk::sizegrip(n) Widget Tk Thème ttk::sizegrip(n)

NOM

ttk::sizegrip - Widget de redimensionnement dans le coin inférieur droit

SYNOPSIS

ttk::sizegrip nomChemin ?options?

DESCRIPTION

Un widget ttk::sizegrip (également connu sous le nom de boîte de croissance) permet à l'utilisateur de redimensionner la fenêtre racine parente en cliquant et en faisant glisser la poignée.

OPTIONS STANDARDS

-class	-cursor
-style	-takefocus

Consultez l'entrée de manuel ttk_widget pour plus de détails sur les options standard.

COMMANDE WIDGET

Les widgets Sizegrip prennent en charge les méthodes standard cget, configure, identify, instate et state. Aucune autre méthode de widget n'est utilisée.

NOTES SPÉCIFIQUES À LA PLATEFORME

Sur macOS, les fenêtres racines incluent automatiquement une poignée de redimensionnement intégrée par défaut. L'ajout d'un ttk::sizegrip y est inoffensif, car la poignée intégrée masquera simplement le widget.

EXEMPLES

Utilisation de pack :

pack [ttk::frame $top.statusbar] -side bottom -fill x
pack [ttk::sizegrip $top.statusbar.grip] -side right -anchor se

Utilisation de grid :

grid [ttk::sizegrip $top.statusbar.grip] \
    -row $lastRow -column $lastColumn -sticky se
# ... optionnel : ajouter une barre de défilement verticale dans $lastColumn,
# ... optionnel : ajouter une barre de défilement horizontale dans $lastRow

BOGUES

Si la position de la fenêtre racine parente a été spécifiée par rapport au bord droit ou inférieur de l'écran (par exemple, “wm geometry ... lxh-x-y” au lieu de “wm geometry ... lxh+x+y”), le widget sizegrip ne redimensionnera pas la fenêtre.

Les widgets ttk::sizegrip ne prennent en charge que le redimensionnement « sud-est ».

OPTIONS DE STYLE

Le nom de classe pour un ttk::sizegrip est TSizegrip.

Les options de style TSizegrip configurables avec ttk::style sont :

-background couleur

Certaines options ne sont disponibles que pour des thèmes spécifiques.

Consultez la page de manuel ttk::style pour savoir comment configurer les styles ttk.
