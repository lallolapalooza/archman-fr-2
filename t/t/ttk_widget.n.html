ttk::widget(n) Widget Thème Tk ttk::widget(n)

NOM

ttk::widget - Options et commandes standard supportées par les widgets Thème Tk

DESCRIPTION

Ce manuel décrit les options et commandes courantes des widgets.

OPTIONS STANDARD

Les options suivantes sont supportées par tous les widgets Thème Tk :

Nom en ligne de commande :	-class
Nom en base de données :	undefined
Classe de base de données :	undefined
Spécifie la classe de la fenêtre. La classe est utilisée lors de la consultation de la base de données d'options pour les autres options de la fenêtre, pour déterminer les bindtags par défaut de la fenêtre et pour sélectionner la disposition et le style par défaut du widget. Il s'agit d'une option en lecture seule : elle ne peut être spécifiée que lors de la création de la fenêtre et ne peut pas être modifiée avec la commande de widget configure.
Nom en ligne de commande :	-cursor
Nom en base de données :	cursor
Classe de base de données :	Cursor
Spécifie le curseur de souris à utiliser pour le widget. Voir Tk_GetCursor et cursors(n) dans le manuel de référence Tk pour les valeurs valides. Si défini sur la chaîne vide (par défaut), le curseur est hérité du widget parent.
Nom en ligne de commande :	-takefocus
Nom en base de données :	takeFocus
Classe de base de données :	TakeFocus
Détermine si la fenêtre accepte le focus lors de la traversée du clavier. Soit 0, 1, un préfixe de commande (auquel le chemin du widget est ajouté, et qui doit renvoyer 0 ou 1), soit la chaîne vide. Voir options(n) dans le manuel de référence Tk pour la description complète.
Nom en ligne de commande :	-style
Nom en base de données :	style
Classe de base de données :	Style
Peut être utilisé pour spécifier un style de widget personnalisé.

OPTIONS WIDGET DÉFILABLE

Les options suivantes sont supportées par les widgets contrôlables par une barre de défilement. Voir scrollbar(n) pour plus d'informations.

Nom en ligne de commande :	-xscrollcommand
Nom en base de données :	xScrollCommand
Classe de base de données :	ScrollCommand
Un préfixe de commande, utilisé pour communiquer avec les barres de défilement horizontales.
Lorsque la vue dans la fenêtre du widget change, le widget génère une commande Tcl en concaténant la commande de défilement et deux nombres. Chacun des nombres est une fraction entre 0 et 1 indiquant une position dans le document ; 0 indique le début et 1 indique la fin. La première fraction indique la première information dans le widget qui est visible dans la fenêtre, et la seconde fraction indique l'information juste après la dernière partie visible.

Généralement, l'option -xscrollcommand consiste en le nom de chemin d'un widget scrollbar suivi de “set”, par exemple “.x.scrollbar set”. Cela mettra à jour la barre de défilement chaque fois que la vue dans la fenêtre changera.

Si cette option est définie sur la chaîne vide (par défaut), aucune commande ne sera exécutée.

Nom en ligne de commande :	-yscrollcommand
Nom en base de données :	yScrollCommand
Classe de base de données :	ScrollCommand
Un préfixe de commande, utilisé pour communiquer avec les barres de défilement verticales. Voir la description de -xscrollcommand ci-dessus pour les détails.

OPTIONS LIBELLÉ

Les options suivantes sont supportées par les libellés, boutons et autres widgets de type bouton :

Nom en ligne de commande :	-compound
Nom en base de données :	compound
Classe de base de données :	Compound
Spécifie comment afficher l'image par rapport au texte, si à la fois -text et -image sont présents. Si défini sur la chaîne vide (par défaut), les règles décrites dans la section "Éléments" de ttk::intro(n) expliquent quelle valeur est réellement utilisée. Les autres valeurs valides sont :
texte
Afficher uniquement le texte.
image
Afficher uniquement l'image.
centre
Afficher le texte centré au-dessus de l'image.
dessus
dessous
gauche
droite
Afficher l'image au-dessus, en dessous, à gauche ou à droite du texte, respectivement.
aucun
Afficher l'image si présente, sinon le texte.
Nom en ligne de commande :	-font
Nom en base de données :	font
Classe de base de données :	Font
Police à utiliser pour le texte affiché par le widget.
Nom en ligne de commande :	-foreground
Nom en base de données :	textColor
Classe de base de données :	TextColor
La couleur de premier plan du widget. Si non spécifiée, la valeur par défaut du thème est utilisée.
Nom en ligne de commande :	-image
Nom en base de données :	image
Classe de base de données :	Image
Spécifie une image à afficher. Il s'agit d'une liste d'un ou plusieurs éléments. Le premier élément est le nom de l'image par défaut. Le reste de la liste est une séquence de paires étatspec / valeur comme dans style map, spécifiant différentes images à utiliser lorsque le widget est dans un état particulier ou une combinaison d'états. Toutes les images de la liste doivent avoir la même taille.
Nom en ligne de commande :	-padding
Nom en base de données :	padding
Classe de base de données :	Padding
Spécifie le remplissage interne du widget. Le remplissage est une liste allant jusqu'à quatre spécifications de longueur : gauche haut droite bas. Si moins de quatre éléments sont spécifiés, bas prend par défaut la valeur de haut, droite prend par défaut la valeur de gauche, et haut prend par défaut la valeur de gauche. En d'autres termes, une liste de trois nombres spécifie le remplissage gauche, vertical et droit ; une liste de deux nombres spécifie le remplissage horizontal et vertical ; un seul nombre spécifie le même remplissage tout autour du widget.
Nom en ligne de commande :	-text
Nom en base de données :	text
Classe de base de données :	Text
Spécifie une chaîne de texte à afficher à l'intérieur du widget (sauf si remplacée par -textvariable pour les widgets prenant en charge cette option).
Nom en ligne de commande :	-textvariable
Nom en base de données :	textVariable
Classe de base de données :	Variable
Spécifie le nom d'une variable globale dont la valeur sera utilisée à la place de la ressource -text.
Nom en ligne de commande :	-underline
Nom en base de données :	underline
Classe de base de données :	Underline
Si défini, spécifie l'index entier (base 0) d'un caractère à souligner dans la chaîne de texte. Le caractère souligné est utilisé pour l'activation par mnémonique.
Nom en ligne de commande :	-width
Nom en base de données :	width
Classe de base de données :	Width
Si supérieur à zéro, spécifie l'espace, en largeurs de caractères, à allouer pour le libellé de texte. Si inférieur à zéro, spécifie une largeur minimale. Si zéro ou non spécifié, la largeur naturelle du libellé de texte est utilisée.

OPTIONS COMPATIBILITÉ

Cette option n'est disponible que pour les widgets thèmes qui ont des widgets Tk traditionnels « correspondants ».

Nom en ligne de commande :	-state
Nom en base de données :	state
Classe de base de données :	State
Peut être défini sur normal ou disabled pour contrôler le bit d'état disabled. Il s'agit d'une option en écriture seule : la définir modifie l'état du widget, mais la commande de widget state n'affecte pas l'option -state.

COMMANDES

cheminNom cget option
Retourne la valeur actuelle de l'option de configuration donnée par option.
cheminNom configure ?option? ?valeur option valeur ...?
Configure les options spécifiées du widget. Si aucune option n'est spécifiée, retourne un enregistrement décrivant toutes les options du widget. Si une seule option est spécifiée, retourne la valeur de cette option.
Interroge ou modifie les options de configuration du widget. Si une ou plusieurs paires option-valeur sont spécifiées, alors la commande modifie les options du widget données pour avoir les valeurs données ; dans ce cas, la commande retourne une chaîne vide. Si option est spécifiée sans valeur, alors la commande retourne une liste décrivant l'option nommée : les éléments de la liste sont le nom de l'option, le nom de la base de données, la classe de la base de données, la valeur par défaut et la valeur actuelle. Si aucune option n'est spécifiée, retourne une liste décrivant toutes les options disponibles pour cheminNom.
cheminNom identifier element x y
Retourne le nom de l'élément sous le point donné par x et y, ou une chaîne vide si le point ne se trouve dans aucun élément. x et y sont des coordonnées en pixels relatives au widget. Certains widgets acceptent d'autres sous-commandes identifier décrites dans la documentation de ces widgets.
cheminNom instate etatSpec ?script?
Teste l'état du widget. Si script n'est pas spécifié, retourne 1 si l'état du widget correspond à etatSpec et 0 sinon. Si script est spécifié, équivalent à
if {[cheminNom instate etatSpec]} script
cheminNom etat ?etatSpec?
Modifie ou interroge l'état du widget. Si etatSpec est présent, définit l'état du widget : pour chaque indicateur dans etatSpec, définit l'indicateur correspondant ou l'efface s'il est préfixé par un point d'exclamation.
Retourne une nouvelle spécification d'état indiquant quels indicateurs ont été modifiés : 
set changements [cheminNom etat spec]
cheminNom etat $changements
restaurera cheminNom à l'état d'origine. Si etatSpec n'est pas spécifié, retourne une liste des indicateurs d'état actuellement activés.
cheminNom xview args
Cette commande est utilisée pour interroger et modifier la position horizontale du contenu dans la fenêtre du widget. Elle peut prendre l'une des formes suivantes :
cheminNom xview
Retourne une liste contenant deux éléments. Chaque élément est une fraction réelle comprise entre 0 et 1 ; ensemble, ils décrivent la portée horizontale visible dans la fenêtre. Par exemple, si le premier élément est 0,2 et le second est 0,6, 20% du contenu du widget sont hors écran vers la gauche, les 40% du milieu sont visibles dans la fenêtre, et 40% du contenu sont hors écran vers la droite. Ce sont les mêmes valeurs passées aux barres de défilement via l'option -xscrollcommand.
cheminNom xview index
Ajuste la vue dans la fenêtre de manière à ce que le contenu donné par index soit affiché sur le bord gauche de la fenêtre.
cheminNom xview moveto fraction
Ajuste la vue dans la fenêtre de manière à ce que le caractère à la position fraction du contenu apparaisse sur le bord gauche de la fenêtre. Fraction doit être une fraction comprise entre 0 et 1.
cheminNom xview scroll nombre quoi
Cette commande décale la vue dans la fenêtre vers la gauche ou vers la droite selon nombre et quoi. Nombre doit être un entier. Quoi doit être soit units soit pages. Si quoi est units, la vue s'ajuste vers la gauche ou la droite de nombre caractères de largeur moyenne à l'écran ; si c'est pages, la vue s'ajuste de nombre écrans. Si nombre est négatif, des caractères plus à gauche deviennent visibles ; s'il est positif, des caractères plus à droite deviennent visibles.
cheminNom yview args
Cette commande est utilisée pour interroger et modifier la position verticale du contenu dans la fenêtre du widget. Elle peut prendre l'une des formes suivantes :
cheminNom yview
Retourne une liste contenant deux éléments. Chaque élément est une fraction réelle comprise entre 0 et 1 ; ensemble, ils décrivent la portée verticale visible dans la fenêtre. Par exemple, si le premier élément est 0,2 et le second est 0,6, 20% du contenu du widget sont hors écran vers le haut, les 40% du milieu sont visibles dans la fenêtre, et 40% du contenu sont hors écran vers le bas. Ce sont les mêmes valeurs passées aux barres de défilement via l'option -yscrollcommand.
cheminNom yview index
Ajuste la vue dans la fenêtre de manière à ce que le contenu donné par index soit affiché sur le bord supérieur de la fenêtre.
cheminNom yview moveto fraction
Ajuste la vue dans la fenêtre de manière à ce que l'élément à la position fraction du contenu apparaisse sur le bord supérieur de la fenêtre. Fraction doit être une fraction comprise entre 0 et 1.
cheminNom yview scroll nombre quoi
Cette commande décale la vue dans la fenêtre vers le haut ou vers le bas selon nombre et quoi. Nombre doit être un entier. Quoi doit être soit units soit pages. Si quoi est units, la vue s'ajuste vers le haut ou vers le bas de nombre caractères de largeur moyenne à l'écran ; si c'est pages, la vue s'ajuste de nombre écrans. Si nombre est négatif, des éléments plus haut deviennent visibles ; s'il est positif, des éléments plus bas deviennent visibles.

ÉTATS DES WIDGETS

L'état du widget est un masque de bits d'indicateurs d'état indépendants. Les indicateurs d'état des widgets incluent :

actif
Le curseur de la souris survole le widget et l'appui sur un bouton de souris provoquera une action. (alias “prelight” (Gnome), “hot” (Windows), “hover”).
désactivé
Widget désactivé par contrôle du programme (alias “indisponible”, “inactif”).
focus
Widget a le focus clavier.
appuyé
Le widget est en cours d'appui (alias “armé” dans Motif).
sélectionné
“Activé”, “vrai”, ou “courant” pour des éléments comme les cases à cocher et les boutons radio.
arrière-plan
Windows et Mac ont la notion d'une fenêtre “active” ou de premier plan. L'état arrière-plan est défini pour les widgets dans une fenêtre d'arrière-plan et effacé pour ceux dans la fenêtre de premier plan.
lecture-seule
Le widget ne doit pas autoriser la modification par l'utilisateur.
alternatif
Un format d'affichage alternatif spécifique au widget. Par exemple, utilisé pour les cases à cocher et les boutons radio dans l'état “tristate” ou “mixte”, et pour les boutons avec -defaut actif.
invalide
La valeur du widget est invalide. (Utilisations potentielles : valeur du widget de curseur hors limites, valeur du widget d'entrée n'ayant pas réussi la validation.)
survol
Le curseur de la souris se trouve à l'intérieur du widget. Ceci est similaire à l'état actif ; il est utilisé dans certains thèmes pour les widgets qui fournissent un retour visuel distinct pour le widget actif en plus de l'élément actif à l'intérieur du widget.
utilisateur1-utilisateur3
Librement utilisable à d'autres fins

Une spécification d'état ou etatSpec est une liste de noms d'état, éventuellement préfixée par un point d'exclamation (!) indiquant que le bit est désactivé.

EXEMPLES

set b [ttk::button .b]
# Désactiver le widget :
$b etat desactive
# Invoquer le widget uniquement s'il est actuellement appuyé et activé :
$b instate {appuye !desactive} {.b invoke}
# Réactiver le widget :
$b etat !desactive

    ttk_widget(n)

    2023-09-01

    NOM

    ttk_widget — Module de base pour les widgets thématiques Tkinter

    DESCRIPTION

    Le module ttk_widget est le widget de base de tous les widgets thématiques Tkinter.

    Il gère la configuration des options communes à tous les widgets thématiques, telles que la couleur, la police et le style.

    OPTIONS

    -class nom_classe
    Spécifie la classe du widget. Par défaut, c'est le nom du widget lui-même.
    -colormap carte_couleurs
    Spécifie la carte de couleurs à utiliser pour le widget.
    -container booléen
    Si vrai, le widget peut contenir d'autres widgets.
    -cursor curseur
    Spécifie le curseur à afficher lorsque la souris survole le widget.
    -height hauteur
    Spécifie la hauteur du widget en lignes de texte ou en pixels.
    -menu menu
    Associe un menu au widget.
    -palette palette
    Spécifie la palette de couleurs à utiliser pour le widget.
    -relief type_relief
    Spécifie le type de relief du widget (par exemple, flat, raised, sunken).
    -style style
    Spécifie le style du widget.
    -takefocus booléen
    Indique si le widget doit accepter le focus clavier.
    -width largeur
    Spécifie la largeur du widget en caractères ou en pixels.

    COMMANDES

    cget option
    Retourne la valeur de l'option spécifiée.
    configure ?option? ?valeur?
    Modifie ou interroge les options du widget.
    identify x y
    Retourne l'élément du widget situé aux coordonnées spécifiées.
    instate état ?commande?
    Exécute la commande spécifiée si le widget est dans l'état donné.
    state ?état?
    Retourne ou définit l'état du widget.

    ÉTATS DES WIDGETS

    Les widgets thématiques peuvent avoir plusieurs états, tels que :

    • active : Le widget est actif (par exemple, survolé par la souris).
    • disabled : Le widget est désactivé et ne peut pas être utilisé.
    • normal : L'état par défaut du widget.
    • readonly : Le widget est en lecture seule.
    • selected : Le widget est sélectionné (par exemple, une case à cocher).
    • // : L'état spécifié par l'utilisateur.

    EXEMPLES

    Voici un exemple simple d'utilisation du widget ttk_widget :

    import tkinter as tk
from tkinter import ttk

root = tk.Tk()

# Créer un widget de base
widget = ttk.Widget(root, text="Mon Widget")
widget.pack()

root.mainloop()
