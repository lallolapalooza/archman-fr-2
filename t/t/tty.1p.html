TTY(1P) Manuel du programmeur POSIX TTY(1P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

tty — renvoie le nom du terminal de l'utilisateur

SYNTAXE

tty

DESCRIPTION

L'utilitaire tty écrit sur la sortie standard le nom du terminal ouvert en entrée standard. Le nom utilisé sera équivalent à la chaîne que renverrait la fonction ttyname() définie dans le volume Interfaces Système de POSIX.1‐2017.

OPTIONS

L'utilitaire tty doit être conforme aux directives de syntaxe des utilitaires du volume Définitions de Base de POSIX.1‐2017, Section 12.2.

OPÉRANDES

Aucun.

ENTRÉE STANDARD

Bien qu'aucune entrée ne soit lue de l'entrée standard, celle-ci est examinée pour déterminer si c'est un terminal ou non, et, si c'est le cas, pour déterminer le nom du terminal.

FICHIERS D'ENTRÉE

Aucun.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes affecteront l'exécution de tty :

LANG
Fournit une valeur par défaut pour les variables d'internationalisation non définies ou vides. (Voir le volume Définitions de Base de POSIX.1‐2017, Section 8.2, Variables d'internationalisation pour la précédence des variables d'internationalisation utilisées pour déterminer les valeurs des catégories de locales.)
LC_ALL
Si elle est définie avec une chaîne non vide, remplace les valeurs de toutes les autres variables d'internationalisation.
LC_CTYPE
Détermine la locale pour l'interprétation des séquences d'octets de données textuelles en caractères (par exemple, caractères mono-octet par opposition aux caractères multi-octets dans les arguments).
LC_MESSAGES

Détermine la locale qui devrait être utilisée pour affecter le format et le contenu des messages de diagnostic écrits sur la sortie d'erreur standard et des messages informatifs écrits sur la sortie standard.
NLSPATH
Détermine l'emplacement des catalogues de messages pour le traitement de LC_MESSAGES.

ÉVÉNEMENTS ASYNCHRONES

Défaut.

SORTIE STANDARD

Si l'entrée standard est un périphérique terminal, un chemin du terminal tel que spécifié par la fonction ttyname() définie dans le volume Interfaces Système de POSIX.1‐2017 sera écrit dans le format suivant :

"%s\n", <nom du terminal>

Sinon, un message sera écrit indiquant que l'entrée standard n'est pas connectée à un terminal. Dans la locale POSIX, l'utilitaire tty utilisera le format :

"not a tty\n"

ERREUR STANDARD

La sortie d'erreur standard sera utilisée uniquement pour les messages de diagnostic.

FICHIERS DE SORTIE

Aucun.

DESCRIPTION ÉTENDUE

Aucune.

STATUT DE SORTIE

Les valeurs de sortie suivantes seront retournées :

 0
L'entrée standard est un terminal.
 1
L'entrée standard n'est pas un terminal.
>1
Une erreur s'est produite.

CONSÉQUENCES DES ERREURS

Défaut.

Les sections suivantes sont informatives.

USAGE DES APPLICATIONS

Cet utilitaire vérifie le statut du fichier ouvert en entrée standard par rapport à un ensemble de fichiers défini par l'implémentation. Il est possible qu'aucune correspondance ne soit trouvée, ou que la correspondance trouvée ne corresponde pas au même fichier que celui qui a été ouvert pour l'entrée standard (bien qu'il s'agisse du même périphérique).
