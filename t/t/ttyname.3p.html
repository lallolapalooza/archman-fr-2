TTYNAME(3P) Manuel du programmeur POSIX TTYNAME(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

ttyname, ttyname_r — trouver le chemin d'accès d'un terminal

SYNTAXE

#include <unistd.h>
char *ttyname(int fildes);
int ttyname_r(int fildes, char *name, size_t namesize);

DESCRIPTION

La fonction ttyname() renvoie un pointeur vers une chaîne contenant un chemin d'accès se terminant par un caractère nul du terminal associé au descripteur de fichier fildes. L'application ne doit pas modifier la chaîne renvoyée. Le pointeur renvoyé peut être invalidé ou le contenu de la chaîne peut être écrasé par un appel ultérieur à ttyname(). Le pointeur renvoyé et le contenu de la chaîne peuvent également être invalidés si le thread appelant est terminé.

La fonction ttyname() n'est pas nécessairement thread-safe.

La fonction ttyname_r() stocke le chemin d'accès se terminant par un caractère nul du terminal associé au descripteur de fichier fildes dans le tableau de caractères référencé par name. Le tableau a une taille de namesize caractères et doit avoir de la place pour le nom et le caractère nul de terminaison. La longueur maximale du nom de terminal est {TTY_NAME_MAX}.

VALEUR RENVOYÉE

En cas de succès, ttyname() renvoie un pointeur vers une chaîne. Sinon, un pointeur nul est renvoyé et errno est défini pour indiquer l'erreur.

En cas de succès, la fonction ttyname_r() renvoie zéro. Sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

ERREURS

La fonction ttyname() peut échouer si :

EBADF
L'argument fildes n'est pas un descripteur de fichier valide.
ENOTTY
Le fichier associé à l'argument fildes n'est pas un terminal.

La fonction ttyname_r() peut échouer si :

EBADF
L'argument fildes n'est pas un descripteur de fichier valide.
ENOTTY
Le fichier associé à l'argument fildes n'est pas un terminal.
ERANGE
La valeur de namesize est inférieure à la longueur de la chaîne à renvoyer, y compris le caractère nul de terminaison.

RATIONNELLE

Le terme « terminal » est utilisé à la place du terme historique « périphérique terminal » afin d'éviter une référence à un terme indéfini.

La version thread-safe place le nom du terminal dans un tampon fourni par l'utilisateur et renvoie une valeur non nulle en cas d'échec. La version non thread-safe peut renvoyer le nom dans une zone de données statique qui peut être écrasée à chaque appel.
