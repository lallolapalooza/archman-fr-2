ttk::panedwindow(n) Tk Themed Widget ttk::panedwindow(n)

NOM

ttk::panedwindow - Fenêtre conteneur multi-panneaux

SYNTAXE

ttk::panedwindow chemin ?options?
chemin add fenêtre ?options...?
chemin insert index fenêtre ?options...?

DESCRIPTION

Un widget ttk::panedwindow affiche un certain nombre de sous-fenêtres, empilées verticalement ou horizontalement. L'utilisateur peut ajuster les tailles relatives des sous-fenêtres en faisant glisser le séparateur entre les panneaux.

OPTIONS STANDARD

-class	-cursor	-takefocus
-style

Voir l'entrée du manuel ttk::widget pour les détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de la ligne de commande :	-orient
Nom de la base de données :	orient
Classe de la base de données :	Orient
Spécifie l'orientation de la fenêtre. Si vertical, les sous-panneaux sont empilés de haut en bas ; si horizontal, les sous-panneaux sont empilés de gauche à droite.
Nom de la ligne de commande :	-width
Nom de la base de données :	width
Classe de la base de données :	Width
Si présent et supérieur à zéro, spécifie la largeur souhaitée du widget en pixels. Sinon, la largeur demandée est déterminée par la largeur des fenêtres gérées.
Nom de la ligne de commande :	-height
Nom de la base de données :	height
Classe de la base de données :	Height
Si présent et supérieur à zéro, spécifie la hauteur souhaitée du widget en pixels. Sinon, la hauteur demandée est déterminée par la hauteur des fenêtres gérées.

OPTIONS DE PANNEAU

Les options suivantes peuvent être spécifiées pour chaque panneau :

Nom de la ligne de commande :	-weight
Nom de la base de données :	weight
Classe de la base de données :	Weight
Un entier spécifiant la capacité d'étirement relative du panneau. Lorsque la fenêtre à panneaux est redimensionnée, l'espace supplémentaire est ajouté ou soustrait à chaque panneau proportionnellement à son -weight.

COMMANDE WIDGET

Prend en charge les commandes standard configure, cget, state et instate ; voir le manuel ttk::widget(n) pour les détails. Commandes supplémentaires :

chemin add sous-fenêtre options...
Ajoute un nouveau panneau à la fenêtre. Voir OPTIONS DE PANNEAU pour la liste des options disponibles.
chemin forget panneau
Supprime le sous-panneau spécifié du widget. panneau est soit un index entier, soit le nom d'une sous-fenêtre gérée.
chemin identify composant x y
Retourne le nom de l'élément sous le point donné par x et y, ou la chaîne vide si aucun composant n'est présent à cet endroit. Si composant est omis, il prend par défaut la valeur sash. Les sous-commandes suivantes sont prises en charge :
chemin identify element x y
Retourne le nom de l'élément à l'emplacement spécifié.
chemin identify sash x y
Retourne l'index du séparateur à l'emplacement spécifié.
chemin insert pos sous-fenêtre options...
Insère un panneau à la position spécifiée. pos est soit la chaîne end, un index entier, soit le nom d'une sous-fenêtre gérée. Si sous-fenêtre est déjà gérée par la fenêtre à panneaux, elle est déplacée à la position spécifiée. Voir OPTIONS DE PANNEAU pour la liste des options disponibles.
chemin pane panneau -option ?valeur ?-option valeur...
Interroge ou modifie les options du panneau spécifié, où panneau est soit un index entier, soit le nom d'une sous-fenêtre gérée. Si aucune -option n'est spécifiée, retourne un dictionnaire des valeurs des options du panneau. Si une seule -option est spécifiée, retourne la valeur de cette option. Sinon, définit les -options aux valeurs correspondantes.
chemin panes
Retourne la liste de toutes les fenêtres gérées par le widget, dans l'ordre des indices de leurs panneaux associés.
chemin sashpos index ?newpos?
Si newpos est spécifié, définit la position du séparateur numéro index. Peut ajuster les positions des séparateurs adjacents pour garantir que les positions soient croissantes de manière monotone. Les positions des séparateurs sont en outre contraintes pour être comprises entre 0 et la taille totale du widget. Retourne la nouvelle position du séparateur numéro index.

Le widget panedwindow prend également en charge les sous-commandes génériques de widget ttk::widget suivantes (voir ttk::widget(n) pour les détails) :

cget	configure
instate	state

ÉVÉNEMENTS VIRTUELS

Le widget panedwindow génère un événement virtuel <<EnteredChild>> lors des événements LeaveNotify/NotifyInferior.

OPTIONS DE STYLISATION

Le nom de classe pour un ttk::panedwindow est TPanedwindow. Le séparateur a un nom de classe de Sash.

Les options de stylisation TPanedwindow configurables avec ttk::style sont :

-background couleur

Les options de stylisation Sash configurables avec ttk::style sont :

-background couleur
-bordercolor couleur
-gripcount nombre
-handlepad montant
-handlesize montant
-lightcolor couleur
-sashpad montant
-sashrelief relief
-sashthickness montant

Certaines options ne sont disponibles que pour des thèmes spécifiques.

Voir la page du manuel ttk::style pour des informations sur la façon de configurer les styles ttk.
