ttk::button(n) Tk Themed Widget ttk::button(n)

NOM

ttk::button - Widget qui déclenche une commande lorsqu'il est pressé

SYNOPIS

ttk::button cheminNom ?options?

DESCRIPTION

Un widget ttk::button affiche une étiquette textuelle et/ou une image, et évalue une commande lorsqu'il est pressé.

OPTIONS STANDARDS

-class	-compound	-cursor
-image	-state	-style
-takefocus	-text	-textvariable
-underline	-width

Voir l'entrée du manuel ttk_widget pour plus de détails sur les options standards.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom en ligne de commande:	-command
Nom dans la base de données:	command
Classe dans la base de données:	Command
Un script à évaluer lorsque le widget est invoqué.
Nom en ligne de commande:	-default
Nom dans la base de données:	default
Classe dans la base de données:	Default
Peut être réglé sur l'une des valeurs : normal, active, ou disabled. Dans une boîte de dialogue, un bouton peut être désigné comme bouton « par défaut » (ce qui signifie, grosso modo, « celui qui est appelé lorsque l'utilisateur appuie sur <Entrée> »). active indique que c'est actuellement le bouton par défaut ; normal signifie qu'il peut devenir le bouton par défaut, et disabled signifie qu'il n'est pas sélectionnable par défaut. La valeur par défaut est normal.

Selon le thème, le bouton par défaut peut être affiché avec un anneau de mise en évidence supplémentaire, ou avec une couleur de bordure différente.

COMMANDE DU WIDGET

En plus des commandes standards cget, configure, identify, instate, et state, les boutons supportent les commandes de widget supplémentaires suivantes :

cheminNom invoke
Invoque la commande associée au bouton.

STYLES STANDARDS

Les widgets ttk::button supportent le style Toolbutton dans tous les thèmes standards, ce qui est utile pour créer des widgets pour les barres d'outils.

OPTIONS DE STYLISATION

Le nom de classe pour un ttk::button est TButton.

États dynamiques : active, disabled, pressed, readonly.

Les options de stylisation de TButton configurables avec ttk::style sont :

-anchor ancrage
-background couleur
-bordercolor couleur
-compound composé
-darkcolor couleur
-foreground couleur
-font police
-highlightcolor couleur
-highlightthickness montant
-lightcolor couleur
-padding remplissage
-relief relief
-shiftrelief montant

-shiftrelief spécifie la distance à laquelle le contenu du bouton est décalé vers le bas et vers la droite dans l'état pressed. Cette action fournit un retour visuel ostentatoire supplémentaire.
-width montant

Certaines options ne sont disponibles que pour des thèmes spécifiques.

Voir la page de manuel ttk::style pour des informations sur la façon de configurer les styles ttk.
