ttk::checkbutton(n) Widget Tk Thème ttk::checkbutton(n)

NOM

ttk::checkbutton - Widget d'activation/désactivation

SYNOPSIS

ttk::checkbutton cheminNom ?options?

DESCRIPTION

Un ttk::checkbutton est utilisé pour afficher ou modifier un paramètre. Il possède deux états : sélectionné et non sélectionné. L'état du bouton de sélection peut être lié à une variable Tcl.

OPTIONS STANDARD

-class	-compound	-cursor
-image	-state	-style
-takefocus	-text	-textvariable
-underline	-width

Voir l'entrée man de ttk_widget pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de ligne de commande :	-command
Nom de base de données :	command
Classe de base de données :	Command
Un script Tcl à exécuter chaque fois que le widget est appelé.
Nom de ligne de commande :	-offvalue
Nom de base de données :	offValue
Classe de base de données :	OffValue
La valeur à stocker dans le -variable associé lorsque le widget est désélectionné. Par défaut : 0.
Nom de ligne de commande :	-onvalue
Nom de base de données :	onValue
Classe de base de données :	OnValue
La valeur à stocker dans le -variable associé lorsque le widget est sélectionné. Par défaut : 1.
Nom de ligne de commande :	-variable
Nom de base de données :	variable
Classe de base de données :	Variable
Le nom d'une variable globale dont la valeur est liée au widget. Par défaut : le chemin du widget s'il n'est pas spécifié.

COMMANDE DU WIDGET

En plus des commandes standard cget, configure, identify, instate et state, les boutons de sélection supportent les commandes de widget supplémentaires suivantes :

cheminNom invoke
Commute entre les états sélectionné et non sélectionné et évalue la commande -command associée. Si le widget est actuellement sélectionné, définit la variable -variable à la valeur -offvalue et désélectionne le widget ; sinon, définit la variable -variable à la valeur -onvalue. Retourne le résultat de la commande -command.

ÉTATS DU WIDGET

Le widget ne répond pas aux entrées utilisateur si l'état disabled est défini. Le widget définit l'état selected chaque fois que la variable -variable associée est définie à la valeur -onvalue du widget, et l'efface sinon. Le widget définit l'état alternate chaque fois que la variable -variable associée est désactivée. (L'état alternate peut être utilisé pour indiquer une sélection « à trois états » ou « indéterminée ».)

STYLES STANDARD

Les widgets Ttk::checkbutton prennent en charge le style Toolbutton dans tous les thèmes standard, ce qui est utile pour créer des widgets pour les barres d'outils.

OPTIONS DE STYLISATION

Le nom de la classe pour un ttk::checkbutton est TCheckbutton.

États dynamiques : active, alternate, disabled, pressed, selected, readonly.

Les options de stylisation TCheckbutton configurables avec ttk::style sont :

-background couleur
-compound composé
-foreground couleur
-indicatorbackground couleur
-indicatorcolor couleur
-indicatormargin rembourrage
-indicatorrelief soulagement
-padding rembourrage

Certaines options ne sont disponibles que pour des thèmes spécifiques.

Voir la page man de ttk::style pour plus d'informations sur la configuration des styles ttk.
