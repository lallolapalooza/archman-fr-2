ttk::label(n) Tk Themed Widget ttk::label(n)

NOM

ttk::label - Affiche une chaîne de caractères et/ou une image

SYNTAXE

ttk::label cheminNom ?options?

DESCRIPTION

Un widget ttk::label affiche une étiquette textuelle et/ou une image. L'étiquette peut être liée à une variable Tcl pour modifier automatiquement le texte affiché.

OPTIONS STANDARD

-class	-compound	-cursor
-image	-padding	-state
-style	-takefocus	-text
-textvariable	-underline	-width

Voir la page de manuel de ttk::widget pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de ligne de commande :	-anchor
Nom de base de données :	anchor
Classe de base de données :	Anchor
Spécifie comment les informations dans le widget sont positionnées par rapport aux marges intérieures. Les valeurs légales sont n, ne, e, se, s, sw, w, nw, et center. Voir aussi -justify.
Nom de ligne de commande :	-background
Nom de base de données :	frameColor
Classe de base de données :	FrameColor
La couleur d'arrière-plan du widget. Si non spécifiée, la valeur par défaut du thème est utilisée.
Nom de ligne de commande :	-font
Nom de base de données :	font
Classe de base de données :	Font
Police à utiliser pour le texte de l'étiquette.
Nom de ligne de commande :	-foreground
Nom de base de données :	textColor
Classe de base de données :	TextColor
La couleur d'avant-plan du widget. Si non spécifiée, la valeur par défaut du thème est utilisée.
Nom de ligne de commande :	-justify
Nom de base de données :	justify
Classe de base de données :	Justify
S'il y a plusieurs lignes de texte, spécifie comment les lignes sont disposées les unes par rapport aux autres. L'une des valeurs left, center, ou right. Voir aussi -anchor.
Nom de ligne de commande :	-relief
Nom de base de données :	relief
Classe de base de données :	Relief
Spécifie l'effet 3D désiré pour la bordure du widget. Les valeurs valides sont flat, groove, raised, ridge, solid, et sunken.
Nom de ligne de commande :	-wraplength
Nom de base de données :	wrapLength
Classe de base de données :	WrapLength
Spécifie la longueur maximale de la ligne (en pixels). Si cette option est inférieure ou égale à zéro, alors le retour à la ligne automatique n'est pas effectué ; sinon, le texte est divisé en lignes de telle sorte qu'aucune ligne ne dépasse la valeur spécifiée.

COMMANDE WIDGET

Prend en charge les commandes standard du widget configure, cget, identify, instate, et state ; voir ttk::widget(n).

OPTIONS DE STYLISATION

Le nom de la classe pour un ttk::label est TLabel.

États dynamiques : disabled, readonly.

Les options de stylisation de TLabel configurables avec ttk::style sont :

-background couleur
-compound composé
-foreground couleur
-font police

Certaines options ne sont disponibles que pour des thèmes spécifiques.

Voir la page de manuel de ttk::style pour des informations sur la manière de configurer les styles ttk.
