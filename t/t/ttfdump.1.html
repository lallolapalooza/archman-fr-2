TTFDUMP(1) Manuel des commandes générales TTFDUMP(1)

NOM

ttfdump - Extraire le contenu d'un fichier de police TrueType

SYNTAXE

ttfdump [-h] [-t nomdetable] [-g numerodeglyphe] [-c collection] [-o fichieraextraire] [-i] fichierttf

DESCRIPTION

ttfdump extrait le contenu d'un fichier de police TrueType sous forme ASCII. Un fichier de police TrueType est composé de diverses tables. Ces tables sont divisées en deux catégories : Tables requises et Tables optionnelles. Plusieurs polices TrueType peuvent être fusionnées en une Collection TrueType.

Options

-h
Affiche un message d'aide sur la sortie standard et quitte.
-t nomdetable
Si cette option est spécifiée, extrait la table "nomdetable", sinon extrait toutes les tables du fichierttf. Nomdetable peut être l'une des suivantes :
Tables requises
cmap
table de mappage caractère vers glyphe
glyf
données des glyphes
head
en-tête de police
hhea
en-tête horizontal
hmtx
métriques horizontales
loca
index vers localisation
maxp
profil maximum
name
table de nommage
post
informations PostScript
OS/2
métriques spécifiques OS/2 et Windows
Tables optionnelles
cvt
table de valeurs de contrôle
fpgm
programme de police ; pas encore implémenté.
gasp
procédure de positionnement sur grille et conversion de balayage (niveaux de gris)
hdmx
métriques de périphérique horizontales
kern
table de crénage
LTSH
table de seuil linéaire
prep
programme CVT ; pas encore implémenté
PCLT
table PCL5
VDMX
table de métriques de périphérique verticales
vhea
en-tête de métriques verticales
vmtx
métriques verticales
Tables OpenType supplémentaires
GPOS
table de positionnement de glyphes
GSUB
table de substitution de glyphes
-g numerodeglyphe
Si cette option est spécifiée, extrait le glyphe avec l'indice numerodeglyphe, sinon extrait tous les glyphes du fichierttf.
-c collection
Sélectionne une police TrueType dans une Collection TrueType.
-o fichieraextraire
Sortie de l'extraction. Si cette option n'est pas spécifiée, l'extraction se fait sur la sortie standard.
-i fichierttf
Fichier de police TrueType à extraire.

EXEMPLE

Pour extraire toutes les informations du fichier de police TrueType times.ttf :

ttfdump times.ttf

Pour extraire la table requise cmap du fichier :

ttfdump -t cmap times.ttf

Pour extraire un seul glyphe avec l'indice 50 :

ttfdump -g 50 times.ttf

VOIR AUSSI

TrueType 1.0 Font Files, Technical Specification Revision 1.66 November 1995

NOTE

Le désassembleur d'instructions n'est pas implémenté.
