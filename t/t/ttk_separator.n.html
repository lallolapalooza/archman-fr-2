ttk::separator(n) Widget Tk Thème ttk::separator(n)

NOM

ttk::separator - Barre de séparation

SYNTAXE

ttk::separator cheminNom ?options?

DESCRIPTION

Un widget ttk::separator affiche une barre de séparation horizontale ou verticale.

OPTIONS STANDARDS

-class	-cursor
-style	-takefocus

Voir l'entrée de manuel ttk_widget pour plus de détails sur les options standards.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom en ligne de commande : -orient
Nom dans la base de données :	orient
Classe dans la base de données :	Orient
L'une des valeurs horizontal ou vertical. Spécifie l'orientation du séparateur.

COMMANDE DU WIDGET

Les widgets de séparation prennent en charge les méthodes standards cget, configure, identify, instate et state. Aucune autre méthode de widget n'est utilisée.

OPTIONS DE STYLISATION

Le nom de classe pour un ttk::separator est TSeparator.

Les options de stylisation TSeparator configurables avec ttk::style sont :

-background couleur

Certaines options ne sont disponibles que pour des thèmes spécifiques.

Voir la page de manuel ttk::style pour plus d'informations sur la façon de configurer les styles ttk.
