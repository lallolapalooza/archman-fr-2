ttk::style(n) Tk Thème Widget ttk::style(n)

NOM

ttk::style - Manipuler la base de données des styles

SYNTAXE

ttk::style option ?args?

NOTES

Voir aussi la présentation de la conférence Tcl'2004, disponible à l'adresse https://tktable.sourceforge.net/tile/tile-tcl2004.pdf

DÉFINITIONS

Chaque widget est associé à un style, qui spécifie l'ensemble des éléments qui composent le widget et comment ils sont disposés, ainsi que les paramètres dynamiques et par défaut des options des éléments. Par défaut, le nom du style est identique à la classe du widget ; cela peut être outrepassé par l'option -style.

Un thème est une collection d'éléments et de styles qui contrôle l'apparence générale d'une application.

DESCRIPTION

La commande ttk::style prend les arguments suivants :

ttk::style configure style ?-option ?valeur option valeur...? ?
Définit la valeur par défaut de la ou des options spécifiées dans le style.
ttk::style element args
ttk::style element create nomElement type ?args...?
Crée un nouvel élément dans le thème actuel de type type. Le seul type d'élément intégré multiplateforme est image (voir ttk_image(n)) mais les thèmes peuvent définir d'autres types d'éléments (voir Ttk_RegisterElementFactory). Sur les versions appropriées de Windows, une fabrique d'éléments est enregistrée pour créer des éléments de thème Windows (voir ttk_vsapi(n)).
ttk::style element names
Retourne la liste des éléments définis dans le thème actuel.
ttk::style element options element
Retourne la liste des options de element.
ttk::style layout style ?specLayout?
Définit la disposition du widget pour le style style. Voir DISPOSITIONS ci-dessous pour le format de specLayout. Si specLayout est omis, retourne la spécification de disposition pour le style style.
ttk::style lookup style -option ?état ?défaut??
Retourne la valeur spécifiée pour -option dans le style style dans l'état état, en utilisant les règles de recherche standard pour les options des éléments. état est une liste de noms d'états ; si elle est omise, elle prend par défaut tous les bits désactivés (l'état “normal”). Si l'argument défaut est présent, il est utilisé comme valeur de repli au cas où aucune spécification pour -option ne serait trouvée.
ttk::style map style ?-option { specÉtat valeur... }?
Définit les valeurs dynamiques des options spécifiées dans style. Chaque paire specÉtat / valeur est examinée dans l'ordre ; la valeur correspondant au premier specÉtat correspondant est utilisée.
ttk::style theme args
ttk::style theme create nomThème ?-parent baséSur? ?-settings script... ?
Crée un nouveau thème. C'est une erreur si nomThème existe déjà. Si -parent est spécifié, le nouveau thème héritera des styles, des éléments et des dispositions du thème parent baséSur. Si -settings est présent, script est évalué dans le contexte du nouveau thème, conformément à ttk::style theme settings.
ttk::style theme names
Retourne une liste de tous les thèmes connus.
ttk::style theme settings nomThème script
Définit temporairement le thème actuel sur nomThème, évalue script, puis restaure le thème précédent. Généralement, script définit simplement des styles et des éléments, bien que du code Tcl arbitraire puisse apparaître.
ttk::style theme use ?nomThème?
Sans argument, le résultat est le nom du thème actuel. Sinon, cette commande définit le thème actuel sur nomThème et actualise tous les widgets.

DISPOSITIONS

Une disposition spécifie une liste d'éléments, chacun suivi d'une ou plusieurs options spécifiant comment agencer l'élément. Le mécanisme de disposition utilise une version simplifiée du gestionnaire de géométrie pack : étant donné une cavité initiale, chaque élément se voit allouer une parcelle. Ensuite, la parcelle réellement utilisée par l'élément est ajustée dans la parcelle allouée. Les options valides sont :

-children { sousDisposition... }
Spécifie une liste d'éléments à placer à l'intérieur de l'élément.
-expand booléen
Spécifie si la parcelle allouée est la cavité entière. Si c'est le cas, la spécification simultanée de -side est ignorée. Par défaut : 0.
-side côté
Spécifie de quel côté de la cavité placer l'élément ; l'une des valeurs parmi left, right, top, ou bottom. Par exemple, -side top alloue la parcelle le long du haut de la cavité, avec une largeur et une hauteur respectivement égales à la largeur de la cavité et à la hauteur de l'élément. Si elle est omise, la parcelle allouée est la cavité entière (même effet que -expand 1).
-sticky [nswe]
Spécifie la position et la taille réelles de la parcelle à l'intérieur de la parcelle allouée. Si spécifié comme une chaîne vide, la parcelle réelle est centrée dans la parcelle allouée. Par défaut : nswe.

Par exemple :

ttk::style layout Horizontal.TScrollbar {
    Scrollbar.trough -children {
        Scrollbar.leftarrow -side left
        Scrollbar.rightarrow -side right
        Horizontal.Scrollbar.thumb -side left -sticky ew
    }
}

Nom

ttk_style — Obtenir et modifier les styles du Tk themed widget set (ttk)

Description

La commande ttk_style est utilisée pour interroger et modifier les informations sur les styles, les thèmes et les éléments disponibles dans le Tk themed widget set (ttk).

Syntaxe

ttk_style command ?arg ...?

Utilisation

La commande ttk_style supporte plusieurs sous-commandes pour gérer les styles, les thèmes et les éléments ttk.

Options

Les options dépendent de la sous-commande utilisée.

Méthodes

Les méthodes disponibles sont les suivantes :

  • ttk_style configure style ?option value ...?
  • ttk_style element option ?arg ...?
  • ttk_style theme option ?arg ...?
  • ttk_style lookup style option ?default?
  • ttk_style map style ?option value ...?
  • ttk_style options ?pattern?
  • ttk_style available
  • ttk_style reset ?style?
  • ttk_style tag option ?arg ...?
