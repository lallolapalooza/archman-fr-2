TTDEBUG(1) Manuel des commandes générales TTDEBUG(1)

NOM

ttdebug - un débogueur de bytecode TrueType

SYNTAXE

ttdebug [options] index taille police

DESCRIPTION

ttdebug est un débogueur interactif de bytecode TrueType fonctionnant dans un terminal. Son interface spartiate ressemble vaguement aux débogueurs comme gdb.

Pour la police spécifiée, un glyphe avec l' index et la taille donnés est chargé, permettant de tracer l'exécution du bytecode étape par étape.

Ce programme fait partie du paquet de démonstration FreeType.

OPTIONS

-I ver
Utiliser la version d'interpréteur TrueType ver. Les versions disponibles dépendent des options de compilation de FreeType ; appelez ttdebug sans argument pour obtenir la liste réelle.
-f index_police
Accéder à la police membre index_police (par défaut zéro) dans les TTC.
-d "axe1 axe2 ..."
Spécifier les coordonnées de conception pour chaque axe de variation au démarrage.
-v
Afficher la version.
