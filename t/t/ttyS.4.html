ttyS(4) Manuel des pilotes de périphériques ttyS(4)

NOM

ttyS - lignes de terminaux série

DESCRIPTION

ttyS[0-3] sont des périphériques caractères pour les lignes de terminaux série.

Ils sont typiquement créés par :


mknod -m 660 /dev/ttyS0 c 4 64 # adresse de base 0x3f8
mknod -m 660 /dev/ttyS1 c 4 65 # adresse de base 0x2f8
mknod -m 660 /dev/ttyS2 c 4 66 # adresse de base 0x3e8
mknod -m 660 /dev/ttyS3 c 4 67 # adresse de base 0x2e8
chown root:tty /dev/ttyS[0-3]

FICHIERS

/dev/ttyS[0-3]

VOIR AUSSI

chown(1), mknod(1), tty(4), agetty(8), mingetty(8), setserial(8)
