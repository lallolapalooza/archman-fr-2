FBB::Tty(3bobcat) Contrôle l'écho des caractères FBB::Tty(3bobcat)

NOM

FBB::Tty - Contrôle l'écho des caractères saisis au terminal

SYNOPIS

#include <bobcat/tty>
Option de liaison : -lbobcat

DESCRIPTION

Les objets Tty(3bobcat) peuvent être utilisés pour contrôler l'écho des caractères saisis au terminal (généralement sur /dev/tty). Lire directement depuis /dev/tty permet aux programmes de lire des informations (par exemple, des mots de passe ou des phrases secrètes) même si le flux d'entrée standard est redirigé vers un fichier. Sauf redirection, std::cin est connecté à /dev/tty.

Les objets Tty(3bobcat) peuvent être utilisés comme des objets autonomes ou (généralement anonymes) des objets Tty(3bobcat) peuvent être insérés dans ou extraits de flux. Lors de l'insertion ou de l'extraction d'objets, les flux impliqués ne sont pas affectés ; seul l'écho des caractères saisis sur /dev/tty est manipulé.

Le destructeur de Tty(3bobcat) ne rétablit pas l'état d'écho de /dev/tty à sa valeur d'origine. Si cela est nécessaire, un objet Tty(3bobcat) doit d'abord être créé, en appelant son membre echo(Tty::RESET) au moment approprié.

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

-

ENUM

L'énumération EchoType demande le type de gestion de l'écho :

r
RESET est utilisé pour rétablir l'état de /dev/tty à l'état actuel lors de la construction d'un objet Tty(3bobcat)
r
ON est utilisé pour activer l'écho des caractères saisis sur /dev/tty.
r
OFF est utilisé pour supprimer l'écho des caractères saisis sur /dev/tty.

CONSTRUCTEURS

r
Tty():
L'état actuel de /dev/tty est sauvegardé.
r
Tty(EchoType type):
L'état actuel de /dev/tty est sauvegardé, et le membre echo(type) de l'objet est appelé.

Les constructeurs (et opérateurs d'affectation) par copie et par déplacement sont disponibles.

OPÉRATEURS SOULEVOTÉS

r
std::istream &operator>>(std::istream &in, Tty const &tty):
L'opérateur d'extraction n'affecte pas in, mais l'état de /dev/tty est défini selon la manière dont l'objet tty a été construit.
r
std::ostream &operator<<(std::ostream &out, Tty const &tty):
L'opérateur d'insertion n'affecte pas out, mais l'état de /dev/tty est défini selon la manière dont l'objet tty a été construit.

FONCTION MEMBRE

r
echo(EchoType type):
L'état de /dev/tty est défini selon la valeur EchoType passée à ce membre.

EXEMPLE

#include <iostream>
#include <string>
#include <bobcat/tty>
using namespace std;
using namespace FBB;
int main()
{
    cout << "Entrez du texte (non écho) : " << Tty(Tty::OFF);
    string line;
    getline(cin, line);
    cout << "\n"
            "Vous avez entré : `" << line << "’\n";
    cout << "Entrez du texte (avec écho) : ";
    getline(cin >> Tty(Tty::ON), line);
    cout << "Vous avez entré : `" << line << "’\n";
}
