ttk_vsapi(n) Tk Themed Widget ttk_vsapi(n)

NOM

ttk_vsapi - Définir un élément des styles visuels Microsoft

SYNOPIS

ttk::style element create nom vsapi nomClasse idPartie ?mapEtat? ?options?

DESCRIPTION

L'usine d'éléments vsapi crée un nouvel élément dans le thème actuel dont l'apparence visuelle est dessinée à l'aide de l'API des styles visuels Microsoft, responsable des styles thématiques sous Windows XP et Vista. Cette usine permet de déclarer n'importe quelle partie des styles visuels comme éléments Ttk qui peuvent ensuite être inclus dans une disposition de style pour modifier l'apparence des widgets Ttk.

nomClasse et idPartie sont des paramètres requis et spécifient la classe et la partie des styles visuels tels que donnés dans la documentation Microsoft. Le mapEtat peut être fourni pour mapper les états Ttk aux états de l'API des styles visuels (voir MAP D'ÉTAT).

OPTIONS

Les options valides sont :

-remplissage remplissage
Spécifie le remplissage intérieur de l'élément. remplissage est une liste de quatre entiers au maximum spécifiant les quantités de remplissage gauche, supérieur, droit et inférieur respectivement. Si moins de quatre éléments sont spécifiés, inférieur prend la valeur de supérieur, droit prend la valeur de gauche, et supérieur prend la valeur de gauche. En d'autres termes, une liste de trois nombres spécifie le remplissage gauche, vertical et droit ; une liste de deux nombres spécifie le remplissage horizontal et vertical ; un seul nombre spécifie le même remplissage tout autour du widget. Cette option ne peut pas être mélangée avec d'autres options.
-marges remplissage
Spécifie le remplissage extérieur de l'élément. remplissage est une liste de quatre entiers au maximum spécifiant les quantités de remplissage gauche, supérieur, droit et inférieur respectivement. Cette option ne peut pas être mélangée avec d'autres options.
-largeur largeur
Spécifie la hauteur de l'élément. Si cette option est définie, l'API des styles visuels ne sera pas interrogée pour la taille recommandée ou la partie. Si cette option est définie, -hauteur devrait également l'être. Les options -largeur et -hauteur ne peuvent pas être mélangées avec les options -remplissage ou -marges.
-hauteur hauteur
Spécifie la hauteur de l'élément. Voir les commentaires pour -largeur.

MAP D'ÉTAT

Le paramètre mapEtat est une liste d'états ttk et de la valeur d'état correspondante de l'API des styles visuels. Cela permet à l'apparence de l'élément de répondre aux changements d'état du widget tels que devenir actif ou être pressé. La liste doit être telle que décrite pour la commande ttk::style map, mais notez que la dernière paire de la liste doit être l'état par défaut et est typiquement une liste vide et 1. Malheureusement, toutes les parties des styles visuels ont des valeurs d'état différentes et celles-ci doivent être recherchées soit dans la documentation Microsoft, soit plus probablement dans les fichiers d'en-tête. L'en-tête original à utiliser était tmschema.h, mais dans les versions plus récentes du kit de développement Windows, il s'agit de vssym32.h.

Si aucun paramètre mapEtat n'est fourni, il y a une carte par défaut implicite de {{}} 1}

EXEMPLE

Créez un bouton de fermeture correctement thématique en modifiant la disposition d'un ttk::button(n). Ceci utilise la partie WINDOW WP_SMALLCLOSEBUTTON et, comme documenté, les états CBS_DISABLED, CBS_HOT, CBS_NORMAL et CBS_PUSHED sont mappés à partir des états ttk.

ttk::style element create smallclose vsapi WINDOW 19 \
    {disabled 4 pressed 3 active 2 {} 1}
ttk::style layout CloseButton {CloseButton.smallclose -sticky news}
pack [ttk::button .close -style CloseButton]

Modifiez l'apparence d'un ttk::checkbutton(n) pour utiliser la partie d'en-tête d'explorateur EBP_HEADERPIN.

ttk::style element create pin vsapi EXPLORERBAR 3 {
    {pressed !selected} 3
    {active !selected} 2
    {pressed selected} 6
    {active selected} 5
    {selected} 4
    {} 1
}
ttk::style layout Explorer.Pin {Explorer.Pin.pin -sticky news}
pack [ttk::checkbutton .pin -style Explorer.Pin]
