ttk::progressbar(n) Tk Themed Widget ttk::progressbar(n)

NOM

ttk::progressbar - Fournir un retour d'information sur la progression

SYNOPHIS

ttk::progressbar nomFichier ?options?

DESCRIPTION

Un widget ttk::progressbar affiche le statut d'une opération de longue durée. Ils peuvent fonctionner dans deux modes : le mode déterminé affiche la quantité terminée par rapport à la quantité totale de travail à effectuer, et le mode indéterminé fournit un affichage animé pour informer l'utilisateur que quelque chose se passe.

OPTIONS STANDARDS

-class	-cursor	-takefocus
-style

Voir l'entrée du manuel ttk_widget pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de la ligne de commande :	-length
Nom de la base de données :	length
Classe de la base de données :	Length
Spécifie la longueur du grand axe de la barre de progression (largeur si horizontale, hauteur si verticale).
Nom de la ligne de commande :	-maximum
Nom de la base de données :	maximum
Classe de la base de données :	Maximum
Un nombre à virgule flottante spécifiant la valeur maximale de -value. Par défaut 100.
Nom de la ligne de commande :	-mode
Nom de la base de données :	mode
Classe de la base de données :	Mode
Soit determinate soit indeterminate.
Nom de la ligne de commande :	-orient
Nom de la base de données :	orient
Classe de la base de données :	Orient
Soit horizontal soit vertical. Spécifie l'orientation de la barre de progression.
Nom de la ligne de commande :	-phase
Nom de la base de données :	phase
Classe de la base de données :	Phase
Option en lecture seule. Le widget incrémente périodiquement la valeur de cette option lorsque la valeur de -value est supérieure à 0 et, en mode déterminé, inférieure à -maximum. Cette option peut être utilisée par le thème actuel pour fournir des effets d'animation supplémentaires.
Nom de la ligne de commande :	-value
Nom de la base de données :	value
Classe de la base de données :	Value
La valeur actuelle de la barre de progression. En mode déterminé, elle représente la quantité de travail terminée. En mode indéterminé, elle est interprétée modulo -maximum ; c'est-à-dire, la barre de progression complète un “cycle” lorsque la valeur de -value augmente de -maximum. Si -variable est définie sur une variable existante, la spécification de -value n'a aucun effet (la valeur de la variable a la priorité).
Nom de la ligne de commande :	-variable
Nom de la base de données :	variable
Classe de la base de données :	Variable
Le nom d'une variable Tcl globale liée à la valeur de -value. Si elle est spécifiée à une variable existante, la valeur de -value de la barre de progression est automatiquement définie sur la valeur de la variable chaque fois que celle-ci est modifiée.

COMMANDE DU WIDGET

nomFichier cget option
Retourne la valeur actuelle de l'option spécifiée ; voir ttk::widget(n).
nomFichier configure ?option? ?valeur option valeur ...?
Modifie ou interroge les options du widget ; voir ttk::widget(n).
nomFichier identify x y
Retourne le nom de l'élément à la position x, y. Voir ttk::widget(n).
nomFichier instate stateSpec ?script?
Teste l'état du widget ; voir ttk::widget(n).
nomFichier start ?intervalle?
Commence le mode d'auto-incrémentation : planifie un événement de minuteur récurrent qui appelle step toutes les intervalle millisecondes. Si omis, intervalle vaut par défaut 50 millisecondes (20 pas/seconde).
nomFichier state ?stateSpec?
Modifie ou interroge l'état du widget ; voir ttk::widget(n).
nomFichier step ?montant?
Incrémente la valeur de -value de montant. montant vaut par défaut 1.0 s'il est omis.
nomFichier stop
Arrête le mode d'auto-incrémentation : annule tout événement de minuteur récurrent initié par nomFichier start.

OPTIONS DE STYLISTE

Le nom de la classe pour une ttk::progressbar est TProgressbar.

Les options de stylisme de TProgressbar configurables avec ttk::style sont :

-background couleur
-bordercolor couleur
-darkcolor couleur
-lightcolor couleur
-maxphase

Pour le thème aqua.
-period
Pour le thème aqua.
-troughcolor couleur

Certaines options ne sont disponibles que pour des thèmes spécifiques.

Voir la page du manuel ttk::style pour des informations sur la façon de configurer les styles ttk.
