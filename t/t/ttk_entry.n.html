Paquet: tk

ttk::entry(n) Tk Themed Widget ttk::entry(n)

NOM

ttk::entry - Widget de champ de texte éditable

SYNTAXE

ttk::entry nomChemin ?options?

DESCRIPTION

Un widget ttk::entry affiche une chaîne de caractères sur une ligne et permet à l'utilisateur de la modifier. La valeur de la chaîne peut être liée à une variable Tcl avec l'option -textvariable. Les widgets d'entrée prennent en charge le défilement horizontal avec l'option standard -xscrollcommand et la commande de widget xview.

OPTIONS STANDARD

-class	-cursor
-font	-foreground
-style
-takefocus	-xscrollcommand

Voir l'entrée du manuel ttk_widget pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de ligne de commande :	-exportselection
Nom de base de données :	exportSelection
Classe de base de données :	ExportSelection
Une valeur booléenne spécifiant si une sélection dans le widget doit être liée à la sélection X. Si la sélection est exportée, alors sélectionner dans le widget désélectionne la sélection X actuelle, sélectionner en dehors du widget désélectionne toute sélection de widget, et le widget répondra aux demandes de récupération de sélection lorsqu'il aura une sélection.
Nom de ligne de commande :	-invalidcommand
Nom de base de données :	invalidCommand
Classe de base de données :	InvalidCommand
Un modèle de script à évaluer chaque fois que -validatecommand renvoie 0. Voir VALIDATION ci-dessous pour plus d'informations.
Nom de ligne de commande :	-justify
Nom de base de données :	justify
Classe de base de données :	Justify
Spécifie comment le texte est aligné dans le widget d'entrée. left, center ou right.
Nom de ligne de commande :	-show
Nom de base de données :	show
Classe de base de données :	Show
Si cette option est spécifiée, le contenu réel de l'entrée n'est pas affiché dans la fenêtre. Au lieu de cela, chaque caractère de la valeur de l'entrée sera affiché comme le premier caractère de la valeur de cette option, par exemple “*” ou un point. Ceci est utile, par exemple, si l'entrée doit être utilisée pour saisir un mot de passe. Si des caractères de l'entrée sont sélectionnés et copiés ailleurs, les informations copiées seront ce qui est affiché, pas le contenu réel de l'entrée.
Nom de ligne de commande :	-state
Nom de base de données :	state
Classe de base de données :	State
Option de compatibilité ; voir l'entrée ttk::widget(n) pour plus de détails. Spécifie un des trois états pour l'entrée, normal, disabled, ou readonly. Voir ÉTATS DU WIDGET, ci-dessous.
Nom de ligne de commande :	-textvariable
Nom de base de données :	textVariable
Classe de base de données :	Variable
Spécifie le nom d'une variable globale dont la valeur est liée au contenu du widget d'entrée. Chaque fois que la variable change de valeur, le contenu du widget est mis à jour, et vice versa.
Nom de ligne de commande :	-validate
Nom de base de données :	validate
Classe de base de données :	Validate
Spécifie le mode dans lequel la validation doit fonctionner : none, focus, focusin, focusout, key, ou all. La valeur par défaut est none, ce qui signifie que la validation est désactivée. Voir VALIDATION ci-dessous.
Nom de ligne de commande :	-validatecommand
Nom de base de données :	validateCommand
Classe de base de données :	ValidateCommand
Un modèle de script à évaluer chaque fois que la validation est déclenchée. S'il est défini sur une chaîne vide (par défaut), la validation est désactivée. Le script doit renvoyer une valeur booléenne. Voir VALIDATION ci-dessous.
Nom de ligne de commande :	-width
Nom de base de données :	width
Classe de base de données :	Width
Spécifie une valeur entière indiquant la largeur souhaitée de la fenêtre d'entrée, en caractères de taille moyenne de la police du widget.

NOTES

Une partie de l'entrée peut être sélectionnée comme décrit ci-dessous. Si une entrée exporte sa sélection (voir l'option -exportselection), elle observera les protocoles X11 standard pour la gestion de la sélection; les sélections des entrées sont disponibles sous le type STRING. Les entrées observent également les règles Tk standard pour la gestion du focus d'entrée. Lorsqu'une entrée a le focus d'entrée, elle affiche un curseur d'insertion pour indiquer où les nouveaux caractères seront insérés.

Les entrées sont capables d'afficher des chaînes trop longues pour tenir entièrement dans la fenêtre du widget. Dans ce cas, seule une partie de la chaîne sera affichée ; les commandes décrites ci-dessous peuvent être utilisées pour changer la vue dans la fenêtre. Les entrées utilisent le mécanisme standard -xscrollcommand pour interagir avec les barres de défilement (voir la description de l'option -xscrollcommand pour plus de détails).

INDEX

Plusieurs commandes du widget entry prennent un ou plusieurs indices en argument. Un indice spécifie un caractère particulier dans la chaîne de l'entrée, de l'une des manières suivantes :

nombre
Spécifie le caractère sous forme d'indice numérique, où 0 correspond au premier caractère de la chaîne.
@nombre
Sous cette forme, nombre est traité comme une coordonnée x dans la fenêtre de l'entrée ; le caractère couvrant cette coordonnée x est utilisé. Par exemple, “@0” indique le caractère le plus à gauche de la fenêtre.
end
Indique le caractère juste après le dernier caractère de la chaîne de l'entrée. Ceci est équivalent à spécifier un indice numérique égal à la longueur de la chaîne de l'entrée.
insert
Indique le caractère adjacent et immédiatement suivant le curseur d'insertion.
sel.first
Indique le premier caractère de la sélection. C'est une erreur d'utiliser cette forme si la sélection n'est pas dans la fenêtre d'entrée.
sel.last
Indique le caractère juste après le dernier caractère de la sélection. C'est une erreur d'utiliser cette forme si la sélection n'est pas dans la fenêtre d'entrée.

Des abréviations peuvent être utilisées pour l'une des formes ci-dessus, par ex. “e” ou “sel.l”. En général, les indices hors limites sont automatiquement arrondis à la valeur légale la plus proche.

COMMANDE WIDGET

Les sous-commandes suivantes sont possibles pour les widgets d'entrée :

nomChemin bbox index
Retourne une liste de quatre nombres décrivant la boîte englobante du caractère donné par index. Les deux premiers éléments de la liste donnent les coordonnées x et y du coin supérieur gauche de la zone d'écran couverte par le caractère (en pixels par rapport au widget) et les deux derniers éléments donnent la largeur et la hauteur du caractère, en pixels. La boîte englobante peut faire référence à une zone en dehors de la zone visible de la fenêtre.
nomChemin delete first ?last?
Supprime un ou plusieurs éléments de l'entrée. first est l'indice du premier caractère à supprimer, et last est l'indice du caractère juste après le dernier à supprimer. Si last n'est pas spécifié, il par défaut à first+1, c'est-à-dire qu'un seul caractère est supprimé. Cette commande renvoie la chaîne vide.
nomChemin get
Retourne la chaîne de l'entrée.
nomChemin icursor index
Arrange pour que le curseur d'insertion soit affiché juste avant le caractère donné par index. Renvoie la chaîne vide.
nomChemin index index
Retourne l'indice numérique correspondant à index.
nomChemin insert index string
Insère la chaîne string dans l'entrée juste avant le caractère spécifié par index. Si string est vide, cette commande n'a aucun effet. La commande renvoie la chaîne vide.
nomChemin scan option ?arg arg ...?
Cette commande est utilisée pour implémenter la numérisation à la souris dans les fenêtres. Elle prend en charge les options suivantes :
mark index
Enregistre la position actuelle de la souris (en coordonnées x, y).
dragto index
Calcule la distance entre la position marquée et la position actuelle de la souris (donnée par index, qui doit être une coordonnée x). La distance est retournée en pixels. Le résultat est destiné à être utilisé pour faire défiler la fenêtre.
nomChemin selection option ?arg?
Pour les sélections de texte :
clear
Supprime toute sélection dans le widget.
from minIndex
Définit le début de la sélection au caractère spécifié par minIndex.
range first last
Sélectionne la plage de caractères de first à last (inclusif).
to maxIndex
Définit la fin de la sélection au caractère spécifié par maxIndex.
nomChemin xview args
Cette commande est utilisée pour faire défiler le contenu de l'entrée horizontalement.
moveto x
Définit la position de défilement horizontale afin que le caractère correspondant à la fraction x du contenu total soit visible à l'extrémité gauche de la fenêtre. x peut être une valeur comprise entre 0 et 1.
scroll n [units\|pages]
Fait défiler le contenu de n unités (caractères par défaut) ou pages (si pages est spécifié). Si n est négatif, le défilement se fait vers la gauche.
Cette commande est généralement appelée par un widget de barre de défilement en réponse à une demande de modification de la vue.

VALIDATION

Le widget d'entrée prend en charge la validation des modifications apportées à son contenu. La validation est contrôlée par les options -validate et -validatecommand.

L'option -validate détermine quand la validation se produit. Les valeurs possibles sont :

none
La validation est désactivée.
key
La validation se produit chaque fois qu'une frappe de touche est reçue.
focus
La validation se produit chaque fois que le focus d'entrée quitte ou entre dans le widget.
focusin
La validation se produit chaque fois que le focus d'entrée entre dans le widget.
focusout
La validation se produit chaque fois que le focus d'entrée quitte le widget.
all
La validation se produit pour tous les types d'événements mentionnés précédemment.

Lorsque la validation est déclenchée, le script spécifié par -validatecommand est évalué. Ce script doit renvoyer une valeur booléenne. Si le script renvoie false (ou 0), l'action qui a déclenché la validation est annulée. Si le script renvoie true (ou 1), l'action est autorisée à se poursuivre.

Le script -validatecommand peut utiliser les substitutions suivantes :

%d
Le type d'événement de validation (voir ci-dessus).
%i
L'indice où le changement se produira.
%M
Le mode de validation (voir ci-dessus).
%P
La valeur que l'entrée aura après que le changement ait été appliqué.
%s
La valeur actuelle de l'entrée avant le changement.
%S
Le texte qui est inséré ou supprimé.
%V
Le nom de l'option -validate.
%W
Le nom du widget.

Si l'option -invalidcommand est spécifiée, le script spécifié par cette option sera évalué si le script -validatecommand renvoie false.

ÉTATS DU WIDGET

Le widget d'entrée peut être dans l'un des états suivants : normal, disabled, ou readonly.

normal
L'état par défaut. L'utilisateur peut modifier le contenu de l'entrée.
disabled
L'entrée est désactivée. Elle ne peut pas recevoir le focus et l'utilisateur ne peut pas interagir avec elle. Les modifications de la variable associée ne sont pas reflétées dans le widget.
readonly
L'entrée est active et peut recevoir le focus, mais le contenu ne peut pas être modifié par l'utilisateur. Les modifications de la variable associée sont reflétées dans le widget.

L'état est contrôlé par l'option -state.

EXEMPLE

package require Tk

ttk::entry .e -width 30
.e insert 0 "Hello World!"
.e configure -state readonly
pack .e

="#pathName~6">pathName insert index chaîne
Insère chaîne juste avant le caractère indiqué par index. Retourne la chaîne vide.
pathName selection option argument
Cette commande est utilisée pour ajuster la sélection dans une entrée. Elle a plusieurs formes, en fonction de option :
pathName selection clear
Efface la sélection si elle est actuellement dans ce widget. Si la sélection n'est pas dans ce widget, la commande n'a aucun effet. Retourne la chaîne vide.
pathName selection present
Retourne 1 s'il y a des caractères sélectionnés dans l'entrée, 0 si rien n'est sélectionné.
pathName selection range debut fin
Définit la sélection pour inclure les caractères commençant par celui indexé par debut et se terminant par celui juste avant fin. Si fin fait référence au même caractère que debut ou à un caractère précédent, alors la sélection de l'entrée est effacée.
pathName validate
Force la revalidation, indépendamment des conditions spécifiées par l'option -validate. Retourne 0 si la validation échoue, 1 si elle réussit. Définit ou efface l'état invalid en conséquence. Voir VALIDATION ci-dessous pour plus de détails.

Le widget d'entrée prend également en charge les sous-commandes de widget ttk::widget génériques suivantes (voir ttk::widget(n) pour les détails) :

cget	configure	identify
instate	state	xview

VALIDATION

Les options -validate, -validatecommand et -invalidcommand sont utilisées pour activer la validation du widget d'entrée.

MODES DE VALIDATION

Il existe deux modes de validation principaux : la prévalidation, dans laquelle la commande -validatecommand est évaluée avant chaque modification et la valeur de retour est utilisée pour déterminer si le changement doit être accepté ou rejeté ; et la revalidation, dans laquelle la commande -validatecommand est évaluée pour déterminer si la valeur actuelle est valide.

L'option -validate détermine quand la validation se produit ; elle peut être définie sur l'une des valeurs suivantes :

none
Par défaut. Cela signifie que la validation n'aura lieu que lorsqu'elle sera spécifiquement demandée par la commande de widget validate.
key
L'entrée sera prévalidée avant chaque modification (spécifiquement, chaque fois que les commandes de widget insert ou delete sont appelées). Si la prévalidation échoue, la modification est rejetée.
focus
L'entrée est revalidée lorsque l'entrée reçoit ou perd le focus.
focusin
L'entrée est revalidée lorsque l'entrée reçoit le focus.
focusout
L'entrée est revalidée lorsque l'entrée perd le focus.
all
La validation est effectuée pour toutes les conditions ci-dessus.

La commande -invalidcommand est évaluée chaque fois que la commande -validatecommand retourne une valeur fausse.

Les commandes -validatecommand et -invalidcommand peuvent modifier la valeur du widget d'entrée via les commandes de widget insert ou delete, ou en définissant la variable liée -textvariable. Si l'une d'elles le fait lors de la prévalidation, alors la modification est rejetée quel que soit la valeur retournée par la commande -validatecommand.

Si -validatecommand est vide (par défaut), la validation réussit toujours.

SUBSTITUTIONS DE SCRIPT DE VALIDATION

Il est possible d'effectuer des substitutions de pourcentages sur les commandes -validatecommand et -invalidcommand, comme dans un script bind. Les substitutions suivantes sont reconnues :

%d
Type d'action : 1 pour la prévalidation insert, 0 pour la prévalidation delete, ou -1 pour la revalidation.
%i
Index du caractère à insérer/supprimer, le cas échéant, sinon -1.
%P
En prévalidation, la nouvelle valeur de l'entrée si la modification est acceptée. En revalidation, la valeur actuelle de l'entrée.
%s
La valeur actuelle de l'entrée avant la modification.
%S
La chaîne de texte en cours d'insertion/suppression, le cas échéant, sinon {}.
%v
La valeur actuelle de l'option -validate.
%V
La condition de validation qui a déclenché le rappel (key, focusin, focusout ou forced).
%W
Le nom du widget d'entrée.

DIFFÉRENCES PAR RAPPORT À LA VALIDATION DU WIDGET ENTRY DE TK

Le widget d'entrée Tk standard désactive automatiquement la validation (en définissant -validate sur none) si les commandes -validatecommand ou -invalidcommand modifient la valeur de l'entrée. Le widget d'entrée thématique Tk ne désactive la validation que si l'un des scripts de validation génère une erreur, ou si -validatecommand ne retourne pas une valeur booléenne valide. (Ainsi, il n'est pas nécessaire de réactiver la validation après avoir modifié la valeur de l'entrée dans un script de validation).

De plus, le widget d'entrée standard appelle la validation chaque fois que la variable liée -textvariable est modifiée ; le widget d'entrée thématique Tk ne le fait pas.

LIAISONS PAR DÉFAUT

Les liaisons par défaut du widget d'entrée permettent le comportement suivant. Dans les descriptions ci-dessous, « mot » fait référence à un groupe contigu de lettres, de chiffres ou de caractères « _ », ou à tout caractère unique autre que ceux-ci.

 •
Cliquer sur le bouton de souris 1 positionne le curseur d'insertion juste avant le caractère sous le curseur de la souris, donne le focus d'entrée à ce widget et efface toute sélection dans le widget. Faire glisser avec le bouton de souris 1 enfoncé sélectionne la zone entre le curseur d'insertion et le caractère sous la souris.
 •
Double-cliquer avec le bouton de souris 1 sélectionne le mot sous la souris et positionne le curseur d'insertion à la fin du mot. Faire glisser après un double clic sélectionne des mots entiers.
 •
Triple-cliquer avec le bouton de souris 1 sélectionne tout le texte dans l'entrée et positionne le curseur d'insertion à la fin de la ligne.
 •
Les extrémités de la sélection peuvent être ajustées en faisant glisser avec le bouton de souris 1 tout en maintenant la touche Maj enfoncée. Si le bouton est double-cliqué avant de faire glisser, la sélection sera ajustée par unités de mots entiers.
 •
Cliquer sur le bouton de souris 1 avec la touche Contrôle enfoncée positionnera le curseur d'insertion dans l'entrée sans affecter la sélection.
 •
Si des caractères imprimables normaux sont tapés dans une entrée, ils sont insérés au point du curseur d'insertion.
 •
La vue dans l'entrée peut être ajustée en faisant glisser avec le bouton milieu de la souris (bouton 2, ou bouton 3 sous TkAqua). Si le bouton milieu de la souris est cliqué sans déplacer la souris, la sélection est copiée dans l'entrée à la position du curseur de la souris.
 •
Si la souris est déplacée hors de l'entrée sur les côtés gauche ou droit lorsque le bouton 1 est enfoncé, l'entrée défilera automatiquement pour afficher plus de texte (s'il y a plus de texte hors écran du côté où la souris a quitté la fenêtre).
 •
Les touches Gauche et Droite déplacent le curseur d'insertion d'un caractère vers la gauche ou vers la droite ; elles effacent également toute sélection dans l'entrée. Si Gauche ou Droite est tapé avec la touche Maj enfoncée, alors le curseur d'insertion se déplace et la sélection est étendue pour inclure le nouveau caractère. Contrôle-Gauche et Contrôle-Droite déplacent le curseur d'insertion par mots, et Contrôle-Maj-Gauche et Contrôle-Maj-Droite déplacent le curseur d'insertion par mots et étendent également la sélection. Contrôle-b et Contrôle-f se comportent de la même manière que Gauche et Droite, respectivement.
 •
La touche Début et Contrôle-a déplacent le curseur d'insertion au début de l'entrée et effacent toute sélection dans l'entrée. Maj-Début déplace le curseur d'insertion au début de l'entrée et étend la sélection jusqu'à ce point.
 •
La touche Fin et Contrôle-e déplacent le curseur d'insertion à la fin de l'entrée et effacent toute sélection dans l'entrée. Maj-Fin déplace le curseur à la fin et étend la sélection jusqu'à ce point.
 •
Contrôle-/ sélectionne tout le texte dans l'entrée.
 •
Contrôle-\ efface toute sélection dans l'entrée.
 •
Les événements virtuels standard de Tk <<Cut>>, <<Copy>>, <<Paste>> et <<Clear>> opèrent sur la sélection de la manière attendue.
 •
La touche Suppr supprime la sélection, s'il y en a une dans l'entrée. S'il n'y a pas de sélection, elle supprime le caractère à droite du curseur d'insertion.
 •
La touche Retour Arrière et Contrôle-h suppriment la sélection, s'il y en a une dans l'entrée. S'il n'y a pas de sélection, elle supprime le caractère à gauche du curseur d'insertion.
 •
Contrôle-d supprime le caractère à droite du curseur d'insertion.
 •
Contrôle-k supprime tous les caractères à droite du curseur d'insertion.

ÉTATS DU WIDGET

Dans l'état disabled, l'entrée ne peut pas être modifiée et le texte ne peut pas être sélectionné. Dans l'état readonly, aucun curseur d'insertion n'est affiché et l'entrée ne peut pas être modifiée (spécifiquement : les commandes insert et delete n'ont aucun effet). L'état disabled est identique à readonly, et dans

addition ne peut pas être sélectionné.

Notez que les modifications apportées à la variable liée -textvariable seront toujours reflétées dans le champ de saisie, même s'il est désactivé ou en lecture seule.

En général, le texte est « gris » dans l'état disabled, et un fond différent est utilisé dans l'état readonly.

Le widget d'entrée définit l'état invalid si la revalidation échoue, et le désactive chaque fois que la validation réussit.

OPTIONS DE STYLE

Le nom de la classe pour un ttk::entry est TEntry.

États dynamiques : disabled, focus, readonly.

Les options de style TEntry configurables avec ttk::style sont :

-background couleur

Pour la compatibilité ascendante, lors de l'utilisation du thème aqua (pour macOS), cette option se comporte comme un alias pour -fieldbackground à condition qu'aucune valeur ne soit spécifiée pour -fieldbackground. Sinon, elle est ignorée.
-bordercolor couleur
-darkcolor couleur
-fieldbackground couleur
Certains thèmes utilisent un fond graphique et leurs couleurs de fond de champ ne peuvent pas être modifiées.
-foreground couleur
-insertcolor couleur
-insertwidth quantité
-lightcolor couleur
-padding remplissage
-relief relief
-selectbackground couleur
-selectborderwidth quantité
-selectforeground couleur

Consultez la page de manuel ttk::style pour savoir comment configurer les styles ttk.
