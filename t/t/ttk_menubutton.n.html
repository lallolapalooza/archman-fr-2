ttk::menubutton(n) Tk Themed Widget ttk::menubutton(n)

NOM

ttk::menubutton - Widget qui affiche un menu lors de sa pression

SYNTAXE

ttk::menubutton cheminNom ?options?

DESCRIPTION

Un widget ttk::menubutton affiche une étiquette textuelle et/ou une image, et affiche un menu lors de sa pression.

OPTIONS STANDARD

-class	-compound	-cursor
-image	-state	-style
-takefocus	-text	-textvariable
-underline	-width

Voir l'entrée de manuel ttk_widget pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom en ligne de commande:	-direction
Nom dans la base de données:	direction
Classe dans la base de données:	Direction
Spécifie où le menu doit apparaître par rapport au menubutton. Un des choix : above, below, left, right, ou flush. La valeur par défaut est below. flush affiche le menu directement par-dessus le menubutton.
Nom en ligne de commande:	-menu
Nom dans la base de données:	menu
Classe dans la base de données:	Menu
Spécifie le nom du chemin du menu associé au menubutton. Pour être sûr, le menu devrait être un enfant direct du menubutton.

COMMANDE DU WIDGET

Les widgets Menubutton supportent les méthodes standard cget, configure, identify, instate, et state. Aucune autre méthode de widget n'est utilisée.

STYLES STANDARD

Les widgets ttk::menubutton supportent le style Toolbutton dans tous les thèmes standard, ce qui est utile pour créer des widgets pour les barres d'outils.

OPTIONS DE STYLE

Le nom de la classe pour un ttk::menubutton est TMenubutton.

États dynamiques : active, disabled, readonly.

Les options de style TMenubutton configurables avec ttk::style sont :

-arrowsize montant
-background couleur
-compound compound
-foreground couleur
-font police
-padding rembourrage
-relief relief
-width montant

Certaines options ne sont disponibles que pour des thèmes spécifiques.

Voir la page de manuel ttk::style pour plus d'informations sur la configuration des styles ttk.
