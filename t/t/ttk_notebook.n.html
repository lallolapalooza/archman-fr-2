ttk::notebook(n) Widget Tk Thème ttk::notebook(n)

NOM

ttk::notebook - Widget conteneur multi-fenêtres

SYNOPSIS

ttk::notebook chemin ?options...?
chemin add fenêtre ?options...?
chemin insert index fenêtre ?options...?

DESCRIPTION

Un widget ttk::notebook gère une collection de fenêtres et n'en affiche qu'une seule à la fois. Chaque fenêtre de contenu est associée à un onglet, que l'utilisateur peut sélectionner pour changer la fenêtre affichée actuellement.

OPTIONS STANDARD

-class	-cursor	-takefocus
-style

Voir la page de manuel de ttk::widget pour plus de détails sur les options standards.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de ligne de commande :	-height
Nom de base de données :	height
Classe de base de données :	Height
Si présent et supérieur à zéro, spécifie la hauteur souhaitée de la zone de panneau (sans inclure le remplissage interne ni les onglets). Sinon, la hauteur maximale de tous les panneaux est utilisée.
Nom de ligne de commande :	-padding
Nom de base de données :	padding
Classe de base de données :	Padding
Spécifie la quantité d'espace supplémentaire à ajouter autour du notebook. Le remplissage est une liste de jusqu'à quatre spécifications de longueur gauche haut droite bas. Si moins de quatre éléments sont spécifiés, bas prend par défaut la valeur de haut, droite prend par défaut la valeur de gauche, et haut prend par défaut la valeur de gauche. En d'autres termes, une liste de trois nombres spécifie le remplissage gauche, vertical et droit ; une liste de deux nombres spécifie le remplissage horizontal et vertical ; un seul nombre spécifie le même remplissage tout autour du widget.
Nom de ligne de commande :	-width
Nom de base de données :	width
Classe de base de données :	Width
Si présent et supérieur à zéro, spécifie la largeur souhaitée de la zone de panneau (sans inclure le remplissage interne). Sinon, la largeur maximale de tous les panneaux est utilisée.

OPTIONS DES ONGLET

Les options suivantes peuvent être spécifiées pour les panneaux individuels du notebook :

Nom de ligne de commande :	-state
Nom de base de données :	state
Classe de base de données :	State
Soit normal, disabled ou hidden. Si disabled, l'onglet n'est pas sélectionnable. Si hidden, l'onglet n'est pas affiché.
Nom de ligne de commande :	-sticky
Nom de base de données :	sticky
Classe de base de données :	Sticky
Spécifie comment la fenêtre de contenu est positionnée dans la zone du panneau. La valeur est une chaîne contenant zéro ou plusieurs des caractères n, s, e, ou w. Chaque lettre fait référence à un côté (nord, sud, est ou ouest) auquel la fenêtre de contenu sera « collée », conformément au gestionnaire de géométrie grid.
Nom de ligne de commande :	-padding
Nom de base de données :	padding
Classe de base de données :	Padding
Spécifie la quantité d'espace supplémentaire à ajouter entre le notebook et ce panneau. La syntaxe est la même que pour l'option -padding du widget.
Nom de ligne de commande :	-text
Nom de base de données :	text
Classe de base de données :	Text
Spécifie une chaîne à afficher dans l'onglet.
Nom de ligne de commande :	-image
Nom de base de données :	image
Classe de base de données :	Image
Spécifie une image à afficher dans l'onglet. Voir ttk::widget(n) pour plus de détails.
Nom de ligne de commande :	-compound
Nom de base de données :	compound
Classe de base de données :	Compound
Spécifie comment afficher l'image par rapport au texte, dans le cas où -text et -image sont tous deux présents. Voir label(n) pour les valeurs valides.
Nom de ligne de commande :	-underline
Nom de base de données :	underline
Classe de base de données :	Underline
Spécifie l'index entier (commençant à 0) d'un caractère à souligner dans la chaîne de texte. Le caractère souligné est utilisé pour l'activation par mnémonique si ttk::notebook::enableTraversal est appelé.

IDENTIFIANTS DES ONGLET

L'argument id_onglet des commandes suivantes peut prendre n'importe laquelle des formes suivantes :

  • Un entier compris entre zéro et le nombre d'onglets ;
  • Le nom d'une fenêtre de contenu ;
  • Une spécification positionnelle de la forme “@x,y”, qui identifie l'onglet
  • La chaîne littérale “current”, qui identifie l'onglet actuellement sélectionné ; ou :
  • La chaîne littérale “end”, qui retourne le nombre d'onglets (valide uniquement pour “chemin index”).

COMMANDE DU WIDGET

chemin add fenêtre ?options...?
Ajoute un nouvel onglet au notebook. Voir OPTIONS DES ONGLET pour la liste des options disponibles. Si fenêtre est actuellement gérée par le notebook mais cachée, elle est restaurée à sa position précédente.
chemin configure ?options?
Voir ttk::widget(n).
chemin cget option
Voir ttk::widget(n).
chemin forget id_onglet
Supprime l'onglet spécifié par id_onglet, désactive et retire la gestion de la fenêtre associée.
chemin hide id_onglet
Cache l'onglet spécifié par id_onglet. L'onglet ne sera pas affiché, mais la fenêtre associée reste gérée par le notebook et sa configuration est conservée. Les onglets cachés peuvent être restaurés avec la commande add.
chemin identify composant x y
Retourne le nom de l'élément situé sous le point donné par x et y, ou la chaîne vide si aucun composant n'est présent à cet endroit. Les sous-commandes suivantes sont supportées :
chemin identify element x y
Retourne le nom de l'élément à l'emplacement spécifié.
chemin identify tab x y
Retourne l'index de l'onglet à l'emplacement spécifié.
chemin index id_onglet
Retourne l'index numérique de l'onglet spécifié par id_onglet, ou le nombre total d'onglets si id_onglet est la chaîne “end”.
chemin insert pos sousfenêtre options...
Insère un panneau à la position spécifiée. pos est soit la chaîne end, un index entier, soit le nom d'une sous-fenêtre gérée. Si sousfenêtre est déjà gérée par le notebook, elle est déplacée à la position spécifiée. Voir OPTIONS DES ONGLET pour la liste des options disponibles.
chemin instate spec_etats ?script...?
Voir ttk::widget(n).
chemin select ?id_onglet?
Sélectionne l'onglet spécifié. La fenêtre de contenu associée sera affichée, et la fenêtre précédemment sélectionnée (si différente) est désactivée. Si id_onglet est omis, retourne le nom du widget du panneau actuellement sélectionné.
chemin state ?spec_etats?
Voir ttk::widget(n).
chemin tab id_onglet ?-option ?valeur ...
Interroge ou modifie
les options de l'onglet spécifique. Si aucun -option n'est spécifié, renvoie un dictionnaire des valeurs d'options de l'onglet. Si un seul -option est spécifié, renvoie la valeur de cette option. Sinon, définit les -options aux valeurs correspondantes. Voir OPTIONS DES LONGLETS pour les options disponibles.
chemin_dossier onglets
Renvoie la liste des fenêtres gérées par le bloc-notes, dans l'ordre d'index de leurs onglets associés.

TRAVERSÉE AU CLAVIER

Pour activer la traversée au clavier pour une fenêtre de niveau supérieur contenant un widget bloc-notes $nb, appelez :

ttk::notebook::enableTraversal $nb

Cela étendra les liaisons pour la fenêtre de niveau supérieur contenant le bloc-notes comme suit :

  • Control-Tab sélectionne l'onglet suivant celui actuellement sélectionné.
  • Control-Shift-Tab sélectionne l'onglet précédent celui actuellement sélectionné.
  • Alt-K, où K est le caractère mnémotechnique (souligné) de n'importe quel onglet, sélectionnera cet onglet.

Plusieurs blocs-notes dans une même fenêtre de niveau supérieur peuvent être activés pour la traversée, y compris des blocs-notes imbriqués. Cependant, la traversée de bloc-notes ne fonctionne correctement que si tous les panneaux sont des enfants directs du bloc-notes.

ÉVÉNEMENTS VIRTUELS

Le widget bloc-notes génère un événement virtuel <<NotebookTabChanged>> après qu'un nouvel onglet a été sélectionné.

EXEMPLE

pack [ttk::notebook .nb]
.nb add [frame .nb.f1] -text "Premier onglet"
.nb add [frame .nb.f2] -text "Deuxième onglet"
.nb select .nb.f2
ttk::notebook::enableTraversal .nb

OPTIONS DE STYLE

Le nom de classe pour un ttk::notebook est TNotebook. L'onglet a un nom de classe de TNotebook.Tab

États dynamiques : active, disabled, selected.

Les options de style TNotebook configurables avec ttk::style sont :

-background couleur
-bordercolor couleur
-darkcolor couleur
-foreground couleur
-lightcolor couleur
-padding remplissage
-tabmargins remplissage
-tabposition position

Spécifie la position de la ligne ou de la colonne des onglets sous forme d'une chaîne de 1 ou 2 caractères. Le premier caractère indique le côté comme n, s, w ou e, tandis que le second caractère (s'il est présent) est le bit de maintien (spécifié comme w, e, n ou s) dans la position de l'onglet. La position par défaut est n pour le thème aqua et nw pour tous les autres thèmes intégrés.

Les options de style TNotebook.Tab configurables avec ttk::style sont :

-background couleur
-bordercolor couleur
-compound composé
-expand remplissage

Définit l'ampleur de la croissance de l'onglet. Généralement utilisé avec l'état dynamique selected. -tabmargins doit être réglé de manière appropriée afin qu'il y ait de la place pour la croissance de l'onglet. Par exemple, le fichier de bibliothèque Ttk vistaTheme.tcl contient les lignes 
ttk::style configure TNotebook -tabmargins {2 2 2 0}
ttk::style map TNotebook.Tab -expand {selected {2 2 2 2}}
qui sont valides pour la valeur par défaut nw de l'option de style -tabposition. Pour un style de bloc-notes ttk::notebook nbStyle défini par 
set nbStyle SW.TNotebook
ttk::style configure $nbStyle -tabposition sw
vous devrez adapter les réglages ci-dessus comme suit : 
ttk::style configure $nbStyle -tabmargins {2 0 2 2}
ttk::style map $nbStyle.Tab -expand {selected {2 2 2 2}}
Le moyen le plus simple d'y parvenir est d'invoquer la procédure de bibliothèque ttk::configureNotebookStyle avec $nbStyle comme argument, après avoir défini l'option -tabposition du style.
-font police
-foreground couleur
-padding remplissage
Certains thèmes utilisent un remplissage différent pour l'onglet sélectionné. Par exemple, le fichier de bibliothèque Ttk clamTheme.tcl contient les lignes 
ttk::style configure TNotebook.Tab -padding {6 2 6 2}
ttk::style map TNotebook.Tab -padding {selected {6 4 6 2}}
qui sont valides pour la valeur par défaut nw de l'option de style -tabposition. Pour un style ttk::notebook ayant une position d'onglet différente, vous devrez adapter ces réglages en conséquence. Encore une fois, le moyen le plus simple d'y parvenir est d'invoquer la procédure de bibliothèque ttk::configureNotebookStyle avec le nom du style comme argument, après avoir défini l'option -tabposition du style.

Certaines options ne sont disponibles que pour des thèmes spécifiques.

Voir la page de manuel ttk::style pour des informations sur la configuration des styles ttk.
