ttk::treeview(n) Widget Thème Tk ttk::treeview(n)

NOM

ttk::treeview - widget d'affichage de données hiérarchiques multicolonnes

SYNTAXE

ttk::treeview chemin ?options?

DESCRIPTION

Le widget ttk::treeview affiche une collection hiérarchique d'éléments. Chaque élément possède une étiquette textuelle, une image optionnelle et une liste optionnelle de valeurs de données. Les valeurs de données sont affichées dans des colonnes successives après l'étiquette de l'arbre.

L'ordre dans lequel les valeurs de données sont affichées peut être contrôlé en définissant l'option de widget -displaycolumns. Le widget arbre peut également afficher des en-têtes de colonne. Les colonnes peuvent être accédées par leur numéro ou par des noms symboliques listés dans l'option de widget -columns ; voir IDENTIFIANTS DE COLONNE.

Chaque élément est identifié par un nom unique. Le widget générera des identifiants d'élément s'ils ne sont pas fournis par l'appelant. Il existe un élément racine distinct, nommé {}. L'élément racine lui-même n'est pas affiché ; ses enfants apparaissent au plus haut niveau de la hiérarchie.

Chaque élément possède également une liste d'étiquettes (tags), qui peuvent être utilisées pour associer des liaisons d'événements à des éléments individuels et contrôler l'apparence de l'élément.

Les widgets Treeview prennent en charge le défilement horizontal et vertical avec les options standard -[xy]scrollcommand et les commandes de widget [xy]view.

OPTIONS STANDARD

-class	-cursor	-takefocus
-style	-xscrollcommand	-yscrollcommand
-padding

Voir la page de manuel ttk::widget pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom en ligne de commande :	-columns
Nom dans la base de données :	columns
Classe de base de données :	Columns
Une liste d'identifiants de colonne, spécifiant le nombre de colonnes et leurs noms.
Nom en ligne de commande :	-displaycolumns
Nom dans la base de données :	displayColumns
Classe de base de données :	DisplayColumns
Une liste d'identifiants de colonne (soit des noms symboliques, soit des indices entiers) spécifiant quelles colonnes de données sont affichées et dans quel ordre elles apparaissent, ou la chaîne #all. Si défini sur #all (par défaut), toutes les colonnes sont affichées dans l'ordre donné.
Nom en ligne de commande :	-height
Nom dans la base de données :	height
Classe de base de données :	Height
Spécifie le nombre de lignes qui doivent être visibles. Remarque : la largeur requise est déterminée par la somme des largeurs de colonne.
Nom en ligne de commande :	-selectmode
Nom dans la base de données :	selectMode
Classe de base de données :	SelectMode
Contrôle la façon dont les liaisons de classe intégrées gèrent la sélection. Une des valeurs parmi extended, browse, ou none.

Si défini sur extended (par défaut), plusieurs éléments peuvent être sélectionnés. Si browse, un seul élément sera sélectionné à la fois. Si none, la sélection ne sera pas modifiée.

Notez que le code de l'application et les liaisons d'étiquettes peuvent définir la sélection comme ils le souhaitent, indépendamment de la valeur de -selectmode.

Nom en ligne de commande :	-show
Nom dans la base de données :	show
Classe de base de données :	Show
Une liste ne contenant aucun ou plusieurs des éléments suivants, spécifiant quels éléments de l'arbre doivent être affichés.
tree
Affiche les étiquettes de l'arbre dans la colonne #0.
headings
Affiche la ligne d'en-têtes.

Par défaut, c'est tree headings, c'est-à-dire que tous les éléments sont affichés.

REMARQUE : La colonne #0 fait toujours référence à la colonne de l'arbre, même si -show tree n'est pas spécifié.

COMMANDE WIDGET

chemin bbox item ?colonne?
Retourne la boîte englobante (par rapport à la fenêtre du widget treeview) de l'élément spécifié item sous la forme x y largeur hauteur. Si colonne est spécifié, retourne la boîte englobante de cette cellule. Si l'élément item n'est pas visible (c'est-à-dire s'il est descendant d'un élément fermé ou s'il est hors écran), retourne la liste vide. Si l'élément est partiellement visible, le résultat donne la zone complète de l'élément, y compris les parties non visibles.
chemin cget option
Retourne la valeur actuelle de l'option spécifiée option ; voir ttk::widget(n).
chemin children item ?nouveaux_enfants?
Si nouveaux_enfants n'est pas spécifié, retourne la liste des enfants appartenant à item.

Si nouveaux_enfants est spécifié, remplace la liste des enfants de item par nouveaux_enfants. Les éléments de l'ancienne liste d'enfants non présents dans la nouvelle liste d'enfants sont détachés de l'arbre. Aucun des éléments de nouveaux_enfants ne peut être un ancêtre de item.

chemin column colonne ?-option ?valeur -option valeur...?
Interroge ou modifie les options pour la colonne spécifiée. Si aucune -option n'est spécifiée, retourne un dictionnaire de paires option/valeur. Si une seule -option est spécifiée, retourne la valeur de cette option. Sinon, les options sont mises à jour avec les valeurs spécifiées. Les options suivantes peuvent être définies sur chaque colonne :
-id nom
Le nom de la colonne. C'est une option en lecture seule. Par exemple, [$chemin column #n -id] retourne la colonne de données associée à la colonne d'affichage #n.
-anchor ancrage
Spécifie comment le texte de cette colonne doit être aligné par rapport à la cellule. Ancrage est l'une des valeurs : n, ne, e, se, s, sw, w, nw, ou center.
-minwidth minwidth
La largeur minimale de la colonne en pixels. Le widget treeview ne rendra pas la colonne plus petite que -minwidth lors du redimensionnement du widget ou lorsque l'utilisateur fait glisser un séparateur de colonne. La valeur par défaut est de 20 pixels.
-stretch booléen
Spécifie si la largeur de la colonne doit être ajustée lors du redimensionnement du widget ou lorsque l'utilisateur fait glisser un séparateur de colonne. Booléen peut avoir n'importe quelle forme acceptée par Tcl_GetBoolean. Par défaut, les colonnes sont extensibles.
-width largeur
La largeur de la colonne en pixels. La valeur par défaut est de 200 pixels. La largeur de colonne spécifiée peut être modifiée par Tk afin de respecter -stretch et/ou -minwidth, ou lorsque le widget est redimensionné ou que l'utilisateur fait glisser un séparateur de colonne.

Utilisez chemin column #0 pour configurer la colonne de l'arbre.

chemin configure ?option? ?valeur option valeur ...?
Modifie ou interroge les options du widget ; voir ttk::widget(n).
chemin delete liste_elements
Supprime chacun des éléments de liste_elements ainsi que tous leurs descendants. L'élément racine ne peut pas être supprimé. Voir aussi : detach.
chemin detach liste_elements
Détache tous les éléments spécifiés dans liste_elements de l'arbre. Les éléments et tous leurs descendants sont toujours présents et peuvent être réinsérés à un autre point de l'arbre avec l'opération move, mais ne seront pas affichés tant que cela n'est pas fait. L'élément racine ne peut pas être détaché. Voir aussi : delete.
chemin exists item
Retourne 1 si l'élément spécifié item est présent dans l'arbre, 0 sinon.

pathname focus ?item?
Si item est spécifié, définit l'élément focalisé sur item. Sinon, renvoie l'élément focalisé actuel, ou {} s'il n'y en a pas.
pathname heading column ?-option ?value -option value...?
Interroge ou modifie les options d'en-tête pour la colonne spécifiée column. Les options valides sont :
-text text
Le texte à afficher dans l'en-tête de colonne.
-image imageName
Spécifie une image à afficher à droite de l'en-tête de colonne.
-anchor anchor
Spécifie comment le texte de l'en-tête doit être aligné. Une des valeurs d'ancrage standard de Tk.
-command script
Un script à évaluer lorsque le libellé de l'en-tête est pressé.

Utilisez pathname heading #0 pour configurer l'en-tête de la colonne d'arbre.

pathname identify component x y
Renvoie une description du composant spécifié component sous le point donné par x et y, ou une chaîne vide si aucun composant de ce type n'est présent à cette position. Les valeurs x et y peuvent avoir n'importe quelle forme acceptable par Tk_GetPixels. Les sous-commandes suivantes sont prises en charge :
pathname identify region x y
Renvoie l'une des valeurs suivantes :
heading
Zone d'en-tête d'arbre ; utilisez [pathname identify column x y] pour déterminer le numéro de l'en-tête.
separator
Espace entre deux en-têtes de colonne ; [pathname identify column x y] renverra l'identifiant de colonne d'affichage de l'en-tête à gauche du séparateur.
tree
Zone de l'arbre.
cell
Une cellule de données.
pathname identify item x y Renvoie l'ID de l'élément à la position y.
pathname identify column x y
Renvoie l'identifiant de colonne d'affichage de la cellule à la position x. La colonne d'arbre a l'ID #0.
pathname identify element x y
L'élément à la position x,y.
pathname identify row x y
Synonyme obsolète pour pathname identify item.

Voir IDENTIFIANTS DE COLONNE pour une discussion sur les colonnes d'affichage et les colonnes de données.

pathname index item
Renvoie l'index entier de item dans la liste des enfants de son parent.
pathname insert parent index ?-id id? options...
Crée un nouvel élément. parent est l'ID de l'élément parent, ou la chaîne vide {} pour créer un nouvel élément de niveau supérieur. index est un entier, ou la valeur end, spécifiant où insérer le nouvel élément dans la liste des enfants de parent. Si index est inférieur ou égal à zéro, le nouveau nœud est inséré au début ; si index est supérieur ou égal au nombre actuel d'enfants, il est inséré à la fin. Si -id est spécifié, il est utilisé comme identifiant d'élément ; id ne doit pas exister auparavant dans l'arbre. Sinon, un nouvel identifiant unique est généré.

pathname insert renvoie l'identifiant de l'élément nouvellement créé. Voir OPTIONS DES ÉLÉMENTS pour la liste des options disponibles.

pathname instate statespec ?script?
Teste l'état du widget ; voir ttk::widget(n).
pathname item item ?-option ?value -option value...?
Interroge ou modifie les options pour l'élément spécifié item. Si aucune -option n'est spécifiée, renvoie un dictionnaire de paires option/valeur. Si une seule -option est spécifiée, renvoie la valeur de cette option. Sinon, les options de l'élément sont mises à jour avec les valeurs spécifiées. Voir OPTIONS DES ÉLÉMENTS pour la liste des options disponibles.
pathname move item parent index
Déplace item à la position index dans la liste des enfants de parent. Il est illégal de déplacer un élément sous l'un de ses descendants.

Si index est inférieur ou égal à zéro, item est déplacé au début ; s'il est supérieur ou égal au nombre d'enfants, il est déplacé à la fin.

pathname next item
Renvoie l'identifiant du frère suivant de item, ou {} si item est le dernier enfant de son parent.
pathname parent item
Renvoie l'ID du parent de item, ou {} si item est au niveau supérieur de la hiérarchie.
pathname prev item
Renvoie l'identifiant du frère précédent de item, ou {} si item est le premier enfant de son parent.
pathname see item
Assure que item est visible : définit tous les ancêtres de item sur -open true, et fait défiler le widget si nécessaire pour que item soit dans la partie visible de l'arbre.
pathname selection ?selop itemList?
Si selop n'est pas spécifié, renvoie la liste des éléments sélectionnés. Sinon, selop est l'une des options suivantes :
pathname selection set itemList
itemList devient la nouvelle sélection.
pathname selection add itemList
Ajoute itemList à la sélection
pathname selection remove itemList
Supprime itemList de la sélection
pathname selection toggle itemList
Inverse l'état de sélection de chaque élément de itemList.
pathname set item ?column? ?value?
Avec un argument, renvoie un dictionnaire de paires colonne/valeur pour l'élément spécifié item. Avec deux arguments, renvoie la valeur actuelle de la colonne spécifiée column. Avec trois arguments, définit la valeur de la colonne column dans l'élément item à la valeur spécifiée value. Voir aussi IDENTIFIANTS DE COLONNE.
pathname state ?stateSpec?
Modifie ou interroge l'état du widget ; voir ttk::widget(n).
pathName tag args...
pathName tag bind tagName ?sequence? ?script?
Ajoute un script de liaison Tk pour la séquence d'événements sequence à l'étiquette tagName. Lorsqu'un événement X est délivré à un élément, les scripts de liaison pour chacun des -tags de l'élément sont évalués dans l'ordre selon bindtags(n).

<KeyPress>, <KeyRelease>, et les événements virtuels sont envoyés à l'élément focalisé. Les événements <ButtonPress>, <ButtonRelease>, et <Motion> sont envoyés à l'élément sous le pointeur de la souris. Aucun autre type d'événement n'est pris en charge.

La liaison script subit des substitutions de % avant évaluation ; voir bind(n) pour les détails.

pathName tag configure tagName ?option? ?value option value...?
Interroge ou modifie les options pour l'étiquette spécifiée tagName. Si une ou plusieurs paires option/value sont spécifiées, définit la valeur de ces options pour l'étiquette spécifiée. Si une seule option est spécifiée, renvoie la valeur de cette option (ou une chaîne vide si l'option n'a pas été spécifiée pour tagName). Sans arguments supplémentaires, renvoie un dictionnaire des paramètres d'options pour tagName. Voir OPTIONS DES ÉTIQUETTES pour la liste des options disponibles.
pathName tag has tagName ?item?
Si item est spécifié, renvoie 1 ou 0 selon que l'élément spécifié possède l'étiquette nommée. Sinon, renvoie une liste de tous les éléments qui possèdent l'étiquette spécifiée.
pathName tag names
Renvoie une liste de toutes les étiquettes utilisées par le widget.
pathName tag add tag items
Ajoute l'étiquette spécifiée tag à chacun des items listés. Si tag est déjà présent pour un élément donné, alors les -tags de cet élément restent inchangés.
pathName tag remove tag ?items?
Supprime l'étiquette spécifiée tag de chacun des items listés. Si items est omis, supprime tag de chaque élément de l'arbre. Si tag n'est pas présent pour un élément donné, alors les -tags de cet élément
are unchanged.

Le widget treeview prend également en charge les sous-commandes génériques ttk::widget suivantes (voir ttk::widget(n) pour plus de détails) :

xview	yview

OPTIONS DES ÉLÉMENTS

Les options d'élément suivantes peuvent être spécifiées pour les éléments dans les commandes de widget insert et item.

Nom de la ligne de commande :	-text
Nom de la base de données :	text
Classe de la base de données :	Text
L'étiquette textuelle à afficher pour l'élément.
Nom de la ligne de commande :	-image
Nom de la base de données :	image
Classe de la base de données :	Image
Une image Tk, affichée à gauche de l'étiquette.
Nom de la ligne de commande :	-values
Nom de la base de données :	values
Classe de la base de données :	Values
La liste des valeurs associées à l'élément.

Chaque élément doit avoir le même nombre de valeurs que l'option de widget -columns. S'il y a moins de valeurs que de colonnes, les valeurs restantes sont considérées comme vides. S'il y a plus de valeurs que de colonnes, les valeurs supplémentaires sont ignorées.

Nom de la ligne de commande :	-open
Nom de la base de données :	open
Classe de la base de données :	Open
Une valeur booléenne indiquant si les enfants de l'élément doivent être affichés (-open true) ou masqués (-open false).
Nom de la ligne de commande :	-tags
Nom de la base de données :	tags
Classe de la base de données :	Tags
Une liste de balises associées à cet élément.

OPTIONS DES BALISES

Les options suivantes peuvent être spécifiées sur les balises :

-foreground
Spécifie la couleur du premier plan du texte.
-background
Spécifie la couleur de l'arrière-plan de la cellule ou de l'élément.
-font
Spécifie la police à utiliser lors du dessin du texte.
-image
Spécifie l'image de l'élément, au cas où l'option -image de l'élément serait vide.

La priorité des balises est déterminée par l'ordre de création : les balises créées en premier ont une priorité plus élevée.

IDENTIFIANTS DE COLONNES

Les identifiants de colonnes peuvent prendre l'une des formes suivantes :

  • Un nom symbolique de la liste de -columns.
  • Un entier n, spécifiant la n-ième colonne de données.
  • Une chaîne de caractères de la forme #n, où n est un entier, spécifiant la n-ième colonne d'affichage.

NOTE : Les -values d'un élément peuvent être affichés dans un ordre différent de celui dans lequel ils sont stockés.

NOTE : La colonne #0 fait toujours référence à la colonne arbre, même si -show tree n'est pas spécifié.

Un numéro de colonne de données est un index dans la liste -values d'un élément ; un numéro de colonne d'affichage est le numéro de colonne dans l'arbre où les valeurs sont affichées. Les étiquettes d'arbre sont affichées dans la colonne #0. Si -displaycolumns n'est pas défini, alors la colonne de données n est affichée dans la colonne d'affichage #n+1. Encore une fois, la colonne #0 fait toujours référence à la colonne arbre.

ÉVÉNEMENTS VIRTUELS

Le widget treeview génère les événements virtuels suivants.

<<TreeviewSelect>>
Généré chaque fois que la sélection change. Il peut également être généré lorsque la sélection est affectée mais pas réellement modifiée. De plus, plusieurs changements de sélection peuvent se produire avant que les événements ne puissent être traités, entraînant plusieurs événements avec la même sélection visible.
<<TreeviewOpen>>
Généré juste avant de définir l'élément de focus sur -open true.
<<TreeviewClose>>
Généré juste après avoir défini l'élément de focus sur -open false.

Les commandes de widget focus et selection peuvent être utilisées pour déterminer l'élément ou les éléments affectés.

OPTIONS DE MISE EN FORME

Le nom de classe pour un ttk::treeview est Treeview. Le nom de classe de l'en-tête treeview est Heading. Le nom de classe de l'élément treeview est Item. Le nom de classe de la cellule treeview est Cell.

États dynamiques : disabled, selected.

Les options de style Treeview configurables avec ttk::style sont :

-background couleur
-fieldbackground couleur
-font police
-foreground couleur
-indent montant

Spécifie la distance à laquelle les éléments sont indiqués par rapport à leurs parents. Par défaut, 20 pixels. La valeur peut avoir l'une des formes acceptables par Tk_GetPixels.
-rowheight montant
Il s'agit de la hauteur standard pour un élément. Par défaut, 20 pixels. La valeur peut avoir l'une des formes acceptables par Tk_GetPixels. Si -rowheight n'est pas défini par le style, il est défini en mesurant un élément et une disposition de cellule avec les paramètres du style. Cela prend donc en compte la police et tout anneau de focalisation ou remplissage du thème. Le -rowheight peut devoir être défini pour s'assurer qu'une ligne est suffisamment grande pour contenir des images.

Pour ajuster le -rowheight pour le style Treeview, utilisez le code suivant après que le tk scaling ait été appliqué. Notez que même si vous ne prenez pas en charge ou ne modifiez pas le tk scaling dans votre programme, vos utilisateurs peuvent l'avoir défini dans leur .wishrc.

ttk::style configure Treeview \
     -rowheight [expr {[font metrics police -linespace] + 2}]

Les options de style Heading configurables avec ttk::style sont :

-background couleur
-font police
-relief relief

Les options de style Item configurables avec ttk::style sont :

-foreground couleur
-indicatormargins padding
-indicatorsize montant
-padding padding

Les options de style Cell configurables avec ttk::style sont :

-padding padding

Certaines options ne sont disponibles que pour des thèmes spécifiques.

Voir la page de manuel de ttk::style pour savoir comment configurer les styles ttk.
