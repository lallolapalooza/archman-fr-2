ttytype(5) Manuel des formats de fichiers ttytype(5)

NOM

ttytype - Mappage du périphérique tty au type de terminal par défaut

DESCRIPTION

Le fichier /etc/ttytype associe les noms de types de terminaux termcap(5) et terminfo(5) aux lignes tty. Chaque ligne se compose d'un type de terminal, suivi d'espaces, suivi d'un nom de tty (un nom de périphérique sans le préfixe /dev/).

Cette association est utilisée par le programme tset(1) pour définir la variable d'environnement TERM au nom du terminal par défaut pour le tty actuel de l'utilisateur.

Cette fonctionnalité a été conçue pour un environnement de partage de temps traditionnel, doté de terminaux à cellules de caractères connectés en dur à un mini-ordinateur UNIX. Elle est peu utilisée sur les stations de travail et systèmes UNIX personnels modernes.

FICHIERS

/etc/ttytype
le fichier des définitions tty.

EXEMPLES

Un fichier /etc/ttytype typique est :


con80x25 tty1
vt320 ttys0

VOIR AUSSI

termcap(5), terminfo(5), agetty(8), mingetty(8)
