ttk::combobox(n) Tk Themed Widget ttk::combobox(n)

NOM

ttk::combobox - champ de texte avec liste de sélection déroulante

SYNOPSIS

ttk::combobox cheminNom ?options?

DESCRIPTION

Un ttk::combobox combine un champ de texte avec une liste déroulante de valeurs ; l'utilisateur peut sélectionner la valeur du champ de texte parmi les valeurs de la liste.

OPTIONS STANDARD

-class	-cursor	-takefocus
-style

Voir l'entrée de manuel ttk::widget pour les détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de ligne de commande :	-exportselection
Nom de base de données :	exportSelection
Classe de base de données :	ExportSelection
Valeur booléenne. Si défini, la sélection du widget est liée à la sélection X.
Nom de ligne de commande :	-justify
Nom de base de données :	justify
Classe de base de données :	Justify
Spécifie comment le texte est aligné dans le widget. Doit être l'un de left, center ou right.
Nom de ligne de commande :	-height
Nom de base de données :	height
Classe de base de données :	Height
Spécifie la hauteur de la liste déroulante, en lignes.
Nom de ligne de commande :	-postcommand
Nom de base de données :	postCommand
Classe de base de données :	PostCommand
Un script Tcl à évaluer immédiatement avant d'afficher la liste. Le script -postcommand peut spécifier les -values à afficher.
Nom de ligne de commande :	-state
Nom de base de données :	state
Classe de base de données :	State
L'un de normal, readonly, ou disabled. Dans l'état readonly, la valeur ne peut pas être modifiée directement, et l'utilisateur ne peut sélectionner qu'un des -values dans la liste déroulante. Dans l'état normal, le champ de texte est directement modifiable. Dans l'état disabled, aucune interaction n'est possible.
Nom de ligne de commande :	-textvariable
Nom de base de données :	textVariable
Classe de base de données :	TextVariable
Spécifie le nom d'une variable globale dont la valeur est liée à la valeur du widget. Chaque fois que la variable change de valeur, la valeur du widget est mise à jour, et vice versa.
Nom de ligne de commande :	-values
Nom de base de données :	values
Classe de base de données :	Values
Spécifie la liste des valeurs à afficher dans la liste déroulante.
Nom de ligne de commande :	-width
Nom de base de données :	width
Classe de base de données :	Width
Spécifie une valeur entière indiquant la largeur souhaitée de la fenêtre d'entrée, en caractères de taille moyenne de la police du widget.

COMMANDE DU WIDGET

Les sous-commandes suivantes sont possibles pour les widgets combobox :

cheminNom current ?nouvelIndex?
Si nouvelIndex est fourni, définit la valeur du combobox à l'élément à la position nouvelIndex dans la liste des -values (en plus des entiers, l'index end est pris en charge et indique le dernier élément de la liste). Sinon, renvoie l'index de la valeur actuelle dans la liste des -values ou -1 si la valeur actuelle n'apparaît pas dans la liste.
cheminNom get
Renvoie la valeur actuelle du combobox.
cheminNom set valeur
Définit la valeur du combobox à valeur.

Le widget combobox prend également en charge les sous-commandes suivantes du widget ttk::entry (voir ttk::entry(n) pour les détails) :

bbox	delete	icursor
index	insert	selection
xview

Le widget combobox prend également en charge les sous-commandes génériques suivantes du widget ttk::widget (voir ttk::widget(n) pour les détails) :

cget	configure	identify
instate	state

ÉVÉNEMENTS VIRTUELS

Le widget combobox génère un événement virtuel <<ComboboxSelected>> lorsque l'utilisateur sélectionne un élément dans la liste des valeurs. Si l'action de sélection dépublie la liste, cet événement est délivré après la dépublication de la liste.

OPTIONS DE STYLE

Le nom de classe pour un ttk::combobox est TCombobox. Le ttk::combobox utilise les widgets entry et listbox en interne. Le cadre de la liste a un nom de classe de ComboboxPopdownFrame.

États dynamiques : disabled, focus, pressed, readonly.

Les options de style TCombobox configurables avec ttk::style sont :

-arrowcolor couleur
-arrowsize montant
-background couleur
-bordercolor couleur
-darkcolor couleur
-focusfill couleur
-foreground couleur
-fieldbackground couleur

Ne peut être modifié lors de l'utilisation de thèmes non natifs et non graphiques.
-insertcolor couleur
-insertwidth montant
-lightcolor couleur
-padding rembourrage
-postoffset rembourrage
-selectbackground couleur
Arrière-plan de sélection de l'entrée texte.
-selectforeground couleur
Premier plan de sélection de l'entrée texte.

La liste déroulante du ttk::combobox ne peut pas être configurée à l'aide de ttk::style ni via la commande configure du widget. La liste peut être configurée en utilisant la base d'options.

option add *TCombobox*Listbox.background couleur
option add *TCombobox*Listbox.font police
option add *TCombobox*Listbox.foreground couleur
option add *TCombobox*Listbox.selectBackground couleur
option add *TCombobox*Listbox.selectForeground couleur

Pour configurer une liste spécifique (sujet à des changements futurs) :

set popdown [ttk::combobox::PopdownWindow .mycombobox]
$popdown.f.l configure -font police

Les options de style ComboboxPopdownFrame configurables avec ttk::style sont :

-borderwidth montant
-relief relief

Certaines options ne sont disponibles que pour des thèmes spécifiques.

Voir la page de manuel ttk::style pour des informations sur la façon de configurer les styles ttk.
