NOM

ttx — outil pour manipuler les polices TrueType et OpenType

SYNTAXE

ttx [option ...] fichier ...

DESCRIPTION

ttx est un outil pour manipuler les polices TrueType et OpenType. Il peut convertir les polices TrueType et OpenType à partir et vers un format basé sur XML appelé TTX. Les fichiers TTX ont une extension ‘.ttx’.

Pour chaque argument fichier qui lui est donné, ttx détecte s'il s'agit d'un fichier ‘.ttf’, ‘.otf’ ou ‘.ttx’ et agit en conséquence : s'il s'agit d'un fichier ‘.ttf’ ou ‘.otf’, il génère un fichier ‘.ttx’ ; s'il s'agit d'un fichier ‘.ttx’, il génère un fichier ‘.ttf’ ou ‘.otf’.

Par défaut, chaque fichier de sortie est créé dans le même répertoire que le fichier d'entrée correspondant et avec le même nom, sauf pour l'extension, qui est substituée de manière appropriée. ttx n'écrase jamais les fichiers existants ; si nécessaire, il ajoute un suffixe au nom du fichier de sortie avant l'extension, comme dans Arial#1.ttf.

Options générales

-h
Affiche les informations d'utilisation.
-d rép
Écrit les fichiers de sortie dans le répertoire rép au lieu d'écrire chaque fichier de sortie dans le même répertoire que le fichier d'entrée correspondant.
-o fichier
Écrit la sortie dans fichier au lieu de l'écrire dans le même répertoire que le fichier d'entrée correspondant.
-v
Mode verbeux. Écrit plus de messages sur la sortie standard décrivant ce qui est fait.
-a
Autorise les identifiants de glyphes virtuels lors de la compilation ou de la décompilation.

Options de déchargement (dump)

Les options suivantes contrôlent le processus de déchargement des fichiers de polices (TrueType ou OpenType) vers des fichiers TTX.

-l
Liste les informations sur les tables. Au lieu de décharger la police dans un fichier TTX, affiche des informations minimales sur chaque table.
-t table
Décharge la table table. Cette option peut être donnée plusieurs fois pour décharger plusieurs tables à la fois. Si elle n'est pas spécifiée, toutes les tables sont déchargées.
-x table
Exclut la table table de la liste des tables à décharger. Cette option peut être donnée plusieurs fois pour exclure plusieurs tables du déchargement. Les options -t et -x sont mutuellement exclusives.
-s
Divise les tables. Décharge chaque table dans un fichier TTX séparé et écrit (sous le nom qui aurait été utilisé pour le fichier de sortie si l'option -s n'avait pas été donnée) un petit fichier TTX contenant des références aux fichiers de déchargement de tables individuels. Ce fichier peut être utilisé comme entrée pour ttx tant que les fichiers référencés peuvent être trouvés dans le même répertoire.
-i
Ne désassemble pas les instructions TrueType. Lorsque cette option est spécifiée, tous les programmes TrueType (programmes de glyphes, programme de police et pré-programme) sont écrits dans le fichier TTX sous forme de données hexadécimales au lieu d'instructions en assembleur. Cela permet de gagner du temps et produit des fichiers TTX plus petits.
-y n
Lors de la décompilation d'un fichier TrueType Collection (TTC), décompile la police numéro n, en commençant par 0.

Options de compilation

Les options suivantes contrôlent le processus de compilation des fichiers TTX en fichiers de polices (TrueType ou OpenType) :

-m fichier_police
Fusionne le fichier TTX d'entrée fichier avec fichier_police. Pas plus d'un argument fichier ne peut être spécifié lorsque cette option est utilisée.
-b
Ne recalcule pas les boîtes englobantes des glyphes. Utilise les valeurs du fichier TTX telles quelles.

FORMAT DU FICHIER TTX

Vous pouvez trouver des informations sur le format du fichier TTX dans documentation.html. En particulier, vous trouverez dans ce fichier la liste des tables comprises par ttx et les relations entre les GlyphIDs TrueType et les noms de glyphes utilisés dans les fichiers TTX.

EXEMPLES

Dans les exemples suivants, tous les fichiers sont lus et écrits dans le répertoire courant. De plus, le nom donné pour le fichier de sortie suppose dans tous les cas qu'il n'existait pas avant l'invocation de ttx.

Décharger la police TrueType contenue dans FreeSans.ttf vers FreeSans.ttx :

ttx FreeSans.ttf

Compiler MyFont.ttx en un fichier de police TrueType ou OpenType :

ttx MyFont.ttx

Lister les tables de FreeSans.ttf avec quelques informations :

ttx -l FreeSans.ttf

Décharger la table ‘cmap’ de FreeSans.ttf vers FreeSans.ttx :

ttx -t cmap FreeSans.ttf

NOTES

Sur MS-Windows et MacOS, ttx est disponible en tant qu'application graphique vers laquelle des fichiers peuvent être glissés.

NOM

ttx - convertisseur de polices TrueType vers TTX et vice-versa

SYNTAXE

ttx [options] [fichier.ttf] [fichier.ttx]

DESCRIPTION

ttx est un outil de ligne de commande qui convertit les polices TrueType (.ttf) au format XML (.ttx) et inversement. Ce format XML permet d'inspecter et de modifier facilement les différentes tables d'une police TrueType.

LE FORMAT DE FICHIER TTX

Le format de fichier TTX est une représentation XML des tables d'une police TrueType. Chaque table est représentée par un élément XML, et ses données sont stockées sous forme d'attributs ou d'éléments imbriqués.

EXEMPLES

Pour convertir une police TrueType en fichier TTX : 

    ttx ma_police.ttf

Ceci créera un fichier nommé ma_police.ttx.

Pour reconvertir un fichier TTX en police TrueType : 

    ttx ma_police.ttx

Ceci créera un fichier nommé ma_police.ttf.

NOTES

Le paquet python-fonttools doit être installé pour utiliser cet outil.
