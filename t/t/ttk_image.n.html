ttk_image(n) Tk Themed Widget ttk_image(n)

NOM

ttk_image - Définir un élément basé sur une image

SYNTAXE

ttk::style element create nom image spécImage ?options?

DESCRIPTION

L'usine d'éléments image crée un nouvel élément dans le thème actuel dont l'apparence visuelle est déterminée par les images Tk. spécImage est une liste d'un ou plusieurs éléments. Le premier élément est le nom de l'image par défaut. Le reste de la liste est une séquence de paires spécEtat / valeur spécifiant d'autres images à utiliser lorsque l'élément est dans un état particulier ou une combinaison d'états.

OPTIONS

Les options valides sont :

-bordure remplissage
remplissage est une liste de jusqu'à quatre entiers, spécifiant les bordures gauche, supérieure, droite et inférieure, respectivement. Si moins de quatre éléments sont spécifiés, inférieure prend la valeur de supérieure, droite prend la valeur de gauche, et supérieure prend la valeur de gauche. Autrement dit, une liste de trois nombres spécifie la bordure gauche, verticale et droite ; une liste de deux nombres spécifie la bordure horizontale et verticale ; un seul nombre spécifie la même bordure tout autour de l'élément. Voir ÉTENDUE DE L'IMAGE, ci-dessous.
-hauteur hauteur
Spécifie une hauteur minimale pour l'élément. Si elle est inférieure à zéro, la hauteur de l'image de base est utilisée par défaut.
-remplissage remplissage
Spécifie le remplissage intérieur de l'élément. Le remplissage est une liste de jusqu'à quatre spécifications de longueur gauche haut droite bas. Si moins de quatre éléments sont spécifiés, bas prend la valeur de haut, droite prend la valeur de gauche, et haut prend la valeur de gauche. Autrement dit, une liste de trois nombres spécifie le remplissage gauche, vertical et droit ; une liste de deux nombres spécifie le remplissage horizontal et vertical ; un seul nombre spécifie le même remplissage tout autour du widget. Par défaut, -bordure si non spécifié.
-ancrage spéc
Spécifie comment l'image est placée dans la parcelle finale. spéc contient zéro ou plusieurs caractères “n”, “s”, “w”, ou “e”.
-largeur largeur
Spécifie une largeur minimale pour l'élément. Si elle est inférieure à zéro, la largeur de l'image de base est utilisée par défaut.

ÉTENDUE DE L'IMAGE

Si la parcelle allouée à l'élément est plus grande que l'image, l'image sera placée dans la parcelle en fonction de l'option -ancrage. Si l'image doit s'étendre horizontalement (c'est-à-dire -ancrage ew) ou verticalement (-ancrage ns), des sous-régions de l'image sont répliquées pour remplir la parcelle en fonction de l'option -bordure. La -bordure divise l'image en 9 régions : quatre coins fixes, les bords supérieur et gauche (qui peuvent être carrelés horizontalement), les bords gauche et droit (qui peuvent être carrelés verticalement), et la zone centrale (qui peut être carrelée dans les deux directions).

Une image qui n'est pas destinée à occuper de l'espace (par exemple, comme image d'arrière-plan) doit utiliser -largeur 0 et -hauteur 0.

EXEMPLE

set img1 [image create photo -file button.png]
set img2 [image create photo -file button-pressed.png]
set img3 [image create photo -file button-active.png]
ttk::style element create Button.button image \
    [list $img1  pressed $img2  active $img3] \
    -bordure {2 4} -ancrage we
