ttk::spinbox(n) Widget Tk à thème ttk::spinbox(n)

NOM

ttk::spinbox - Widget de champ de texte sélectionnable

SYNTAXE

ttk::spinbox cheminNom ?options?

DESCRIPTION

Un widget ttk::spinbox est un widget ttk::entry avec des boutons de montée et de descente intégrés qui sont utilisés pour modifier une valeur numérique ou pour sélectionner parmi un ensemble de valeurs. Le widget implémente toutes les fonctionnalités du widget ttk::entry, y compris la prise en charge de l'option -textvariable pour lier la valeur affichée par le widget à une variable Tcl.

OPTIONS STANDARD

-class	-cursor	-state
-style	-takefocus	-xscrollcommand

Voir la page de manuel de ttk_widget pour plus de détails sur les options standard.

OPTIONS STANDARD

-validate	-validatecommand

Voir la page de manuel de ttk::entry pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom en ligne de commande :	-command
Nom dans la base de données :	command
Classe dans la base de données :	Command
Spécifie une commande Tcl à appeler chaque fois qu'un bouton de sélection est utilisé.
Nom en ligne de commande :	-format
Nom dans la base de données :	format
Classe dans la base de données :	Format
Spécifie un format alternatif à utiliser lors de la définition de la valeur de chaîne lorsque les options -from et -to sont utilisées. Il doit s'agir d'un spécificateur de format de la forme %<remplissage>.<remplissage>f, car il formatte un nombre à virgule flottante.
Nom en ligne de commande :	-from
Nom dans la base de données :	from
Classe dans la base de données :	From
Une valeur à virgule flottante spécifiant la plus petite valeur pour le spinbox. Ceci est utilisé conjointement avec -to et -increment pour définir une plage numérique.
Nom en ligne de commande :	-increment
Nom dans la base de données :	increment
Classe dans la base de données :	Increment
Une valeur à virgule flottante spécifiant la variation de valeur à appliquer chaque fois que l'un des boutons du widget est pressé. Le bouton supérieur applique un incrément positif, le bouton inférieur applique un incrément négatif.
Nom en ligne de commande :	-to
Nom dans la base de données :	to
Classe dans la base de données :	To
Une valeur à virgule flottante spécifiant la plus haute valeur permissible pour le widget. Voir aussi -from et -increment. plage.
Nom en ligne de commande :	-values
Nom dans la base de données :	values
Classe dans la base de données :	Values
Ceci doit être une liste Tcl de valeurs. Si cette option est définie, elle remplacera toute plage définie à l'aide des options -from, -to et -increment. Le widget utilisera plutôt les valeurs spécifiées en commençant par la première valeur.
Nom en ligne de commande :	-wrap
Nom dans la base de données :	wrap
Classe dans la base de données :	Wrap
Doit être une valeur booléenne valide. Si activé, le spinbox bouclera à travers les valeurs des données dans le widget.

COMMANDE WIDGET

Les sous-commandes suivantes sont possibles pour les widgets spinbox en plus des commandes décrites pour le widget ttk::entry :

cheminNom get
Retourne la valeur actuelle du spinbox.
cheminNom set valeur
Définit la chaîne du spinbox à valeur. Si une option -format a été configurée, ce format sera appliqué. Si le formatage échoue ou n'est pas défini, ou si l'option -values a été utilisée, la valeur est définie directement.

ÉVÉNEMENTS VIRTUELS

Le widget spinbox génère un événement virtuel <<Increment>> lorsque l'utilisateur appuie sur <Up>, et un événement virtuel <<Decrement>> lorsque l'utilisateur appuie sur <Down>.

OPTIONS DE STYLE

Le nom de classe pour un ttk::spinbox est TSpinbox.

États dynamiques : active, disabled, focus, readonly.

Les options de style TSpinbox configurables avec ttk::style sont :

-arrowcolor couleur
-arrowsize montant
-background couleur

Pour des raisons de compatibilité ascendante, lors de l'utilisation du thème aqua (pour macOS), cette option se comporte comme un alias pour -fieldbackground à condition qu'aucune valeur ne soit spécifiée pour -fieldbackground. Sinon, elle est ignorée.
-bordercolor couleur
-darkcolor couleur
-fieldbackground couleur
-foreground couleur
-insertcolor couleur
-insertwidth montant
-lightcolor couleur
-padding remplissage
-selectbackground couleur
-selectforeground couleur

Certaines options ne sont disponibles que pour des thèmes spécifiques.

Voir la page de manuel de ttk::style pour des informations sur la configuration des styles ttk.
