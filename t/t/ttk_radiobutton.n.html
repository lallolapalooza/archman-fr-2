ttk::radiobutton(n) Widget Thème Tk ttk::radiobutton(n)

NOM

ttk::radiobutton - Widget d'option mutuellement exclusive

SYNOPIS

ttk::radiobutton cheminNom ?options?

DESCRIPTION

Les widgets ttk::radiobutton sont utilisés par groupes pour afficher ou modifier un ensemble d'options mutuellement exclusives. Les boutons radio sont liés à une variable Tcl et ont une valeur associée ; lorsqu'un bouton radio est cliqué, il définit la variable sur sa valeur associée.

OPTIONS STANDARD

-class	-compound	-cursor
-image	-state	-style
-takefocus	-text	-textvariable
-underline	-width

Voir l'entrée de manuel ttk_widget pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom en ligne de commande :	-command
Nom dans la base de données :	command
Classe dans la base de données :	Command
Un script Tcl à évaluer chaque fois que le widget est appelé.
Nom en ligne de commande :	-value
Nom dans la base de données :	Value
Classe dans la base de données :	Value
La valeur à stocker dans le -variable associé lorsque le widget est sélectionné.
Nom en ligne de commande :	-variable
Nom dans la base de données :	variable
Classe dans la base de données :	Variable
Le nom d'une variable globale dont la valeur est liée au widget. La valeur par défaut est ::selectedButton.

COMMANDE DU WIDGET

En plus des commandes standard cget, configure, identify, instate et state, les boutons radio prennent en charge les commandes de widget supplémentaires suivantes :

cheminNom invoke
Définit le -variable sur la valeur -value, sélectionne le widget et évalue le -command associé. Renvoie le résultat du -command, ou une chaîne vide si aucun -command n'est spécifié.

ÉTATS DU WIDGET

Le widget ne répond pas aux entrées utilisateur si l'état disabled est défini. Le widget définit l'état selected chaque fois que la -variable liée est définie sur la -value du widget, et le désactive sinon. Le widget définit l'état alternate chaque fois que la -variable liée est désactivée. (L'état alternate peut être utilisé pour indiquer une sélection « à trois états » ou « indéterminée ».)

STYLES STANDARD

Les widgets ttk::radiobutton prennent en charge le style Toolbutton dans tous les thèmes standards, ce qui est utile pour créer des widgets pour les barres d'outils.

OPTIONS DE STYLE

Le nom de classe pour un ttk::radiobutton est TRadiobutton.

États dynamiques : active, alternate, disabled, pressed, readonly, selected.

Les options de style TRadiobutton configurables avec ttk::style sont :

-background couleur
-compound type de composé
-foreground couleur
-indicatorbackground couleur
-indicatorcolor couleur
-indicatormargin remplissage
-indicatorrelief soulagement
-padding remplissage

Certaines options ne sont disponibles que pour des thèmes spécifiques.

Voir la page de manuel ttk::style pour des informations sur la façon de configurer les styles ttk.
