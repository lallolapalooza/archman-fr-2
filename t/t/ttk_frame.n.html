ttk::frame(n) Widget Thème ttk::frame(n)

NOM

ttk::frame - Widget conteneur simple

SYNOPSIS

ttk::frame cheminNom ?options?

DESCRIPTION

Un ttk::frame est un conteneur, utilisé pour regrouper d'autres widgets.

OPTIONS STANDARD

-class	-cursor	-padding
-style	-takefocus

Voir la page de manuel de ttk::widget pour plus de détails sur les options standards.

OPTIONS SPECIFIQUES AU WIDGET

Nom de ligne de commande :	-borderwidth
Nom dans la base de données :	borderWidth
Classe de base de données :	BorderWidth
La largeur souhaitée pour le bord du widget. Par défaut, 0. Peut être ignoré en fonction du thème utilisé.
Nom de ligne de commande :	-relief
Nom dans la base de données :	relief
Classe de base de données :	Relief
L'un des styles de bordure Tk standard : flat, groove, raised, ridge, solid, ou sunken. Par défaut, flat.
Nom de ligne de commande :	-width
Nom dans la base de données :	width
Classe de base de données :	Width
Si spécifié, la largeur demandée par le widget en pixels.
Nom de ligne de commande :	-height
Nom dans la base de données :	height
Classe de base de données :	Height
Si spécifié, la hauteur demandée par le widget en pixels.

COMMANDE DU WIDGET

Supporte les commandes standards de widget configure, cget, identify, instate, et state ; voir ttk::widget(n).

NOTES

Notez que si les gestionnaires de géométrie pack, grid, ou d'autres sont utilisés pour gérer les enfants du frame, la taille demandée par le GM aura normalement la priorité sur les options -width et -height du widget frame. pack propagate et grid propagate peuvent être utilisés pour changer cela.

OPTIONS DE STYLISATION

Le nom de classe pour un ttk::frame est TFrame.

Les options de stylisation de TFrame configurables avec ttk::style sont :

-background couleur
-relief relief

Certaines options ne sont disponibles que pour des thèmes spécifiques.

Voir la page de manuel de ttk::style pour des informations sur la manière de configurer les styles ttk.

LIAISONS

Lorsqu'un nouveau ttk::frame est créé, il n'a pas de liaisons d'événements par défaut ; les ttk::frame ne sont pas destinés à être interactifs.
