TTF2AFM(1) Manuel des commandes générales TTF2AFM(1)

NOM

ttf2afm - utilitaire pour générer des fichiers AFM pour les polices TrueType

SYNTAXE

ttf2afm [OPTIONS] FICHIERPOLICE

DESCRIPTION

ttf2afm est utilisé pour générer des fichiers Adobe Font Metrics (AFM) pour les polices TrueType (TTF) afin de permettre leur utilisation avec TeX.

ttf2afm prend le nom d'un fichier de police TrueType comme argument obligatoire. Il peut également accepter une ou plusieurs options de la liste ci-dessous (-i et -u s'excluent mutuellement).

OPTIONS

-i
forcer l'impression des noms de glyphes sous la forme `index'numéro décimal
-u
forcer l'impression des noms de glyphes sous la forme `uni'numéro hexadécimal
-c nom
écrire les tables d'encodage dans le fichier nom.eMN, où M est l'identifiant de la plateforme et N est l'identifiant de l'encodage
-v
afficher la version du programme
-e enc
encoder la sortie AFM en utilisant le vecteur d'encodage de enc
-o fichier uscita
écrire dans le fichier fichier uscita au lieu de la sortie standard
-m num
utiliser la table de correspondance Unicode numéro num dans la police

Les numéros de plateforme peuvent être l'un des suivants :

0
Unicode Apple
1
Macintosh
2
ISO
3
Microsoft

Les encodages peuvent être :

0
Roman (si la plateforme est Macintosh)
0
Symbol (si la plateforme est Microsoft)
1
Unicode (si la plateforme est Microsoft)

VOIR AUSSI

afm2tfm(1), afm2pl(1). FontForge (https://fontforge.org). LCDF TypeTools (https://lcdf.org). A closer look at TrueType fonts and pdfTeX, Han The Thanh (https://tug.org/TUGboat/tb30-1/tb94thanh.pdf).
