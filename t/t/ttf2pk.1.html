TTF2PK(1) Manuel des commandes générales TTF2PK(1)

NOM

ttf2pk - convertir une police TrueType au format PK de TeX

SYNTAXE

ttf2pk [-q] [-n] nom-police résolution
ttf2pk -t [-q] nom-police
ttf2pk --version | --help

DESCRIPTION

Ce programme convertit une police TrueType en un fichier PK ; la police créée peut ensuite être utilisée avec TeX ou LaTeX.

Les sous-polices CJKV (chinois/japonais/coréen/vietnamien ancien) telles que créées par ttf2tfm sont également prises en charge.

ttf2pk suppose toujours 10pt comme taille de conception pour la police TeX écrite.

PARAMETRES

-q
Ce commutateur optionnel rend ttf2pk silencieux. Il supprime toute sortie informative sauf les messages d'avertissement et d'erreur.
-n
Utiliser uniquement `.pk' comme extension au lieu de `.<résolution>pk'.
-t
Tester l'existence de nom-police. Renvoie 0 en cas de succès et imprime la ligne correspondante d'un fichier de mappage (par défaut : ttfonts.map), à condition que le commutateur -q ne soit pas activé.
nom-police
Le nom TeX de la police. ttf2pk recherche ce nom dans un fichier de mappage (voir ci-dessous) pour obtenir plus d'informations sur la manière de traiter la police.
résolution
La résolution, donnée en points par pouce. Actuellement, la résolution horizontale est égale à la résolution verticale. La taille de conception est toujours supposée être de 10pt.
--version
Affiche la version actuelle de ttf2pk et la bibliothèque de recherche de fichiers utilisée (par exemple, kpathsea).
--help
Affiche les informations d'utilisation.

Les variables d'environnement pour la recherche de fichiers sont décrites dans la page de manuel de ttf2tfm.

LE FICHIER DE CONFIGURATION

ttf2pk utilise un petit fichier de configuration appelé ttf2pk.cfg ; sur chaque ligne, il contient un mot-clé avec sa valeur, séparés par des espaces. Les lignes de commentaires peuvent commencer par l'un des caractères suivants : `*', `#', `;', et `%'. Les espaces de début sont ignorés.

Actuellement, un seul mot-clé, `map', est reconnu dans ce fichier ; il prend un nom de fichier de mappage comme paramètre. Si aucune extension n'est donnée au nom du fichier de mappage, .map est ajouté. Aucun espace n'est autorisé dans le nom du fichier de mappage. Le mot-clé `map' peut être donné plusieurs fois pour spécifier plusieurs fichiers de mappage ; si le nom du fichier de mappage est précédé d'un signe plus, il est ajouté à la liste des fichiers de mappage à utiliser. Exemple :


map foo
map +bar

Cela fait que ttf2pk lit d'abord foo.map, puis bar.map.

Si le fichier de configuration n'est pas trouvé, ttf2pk essaie d'utiliser ttfonts.map à la place.

FICHIERS DE MAPPAGE

Les paramètres spécifiés à ttf2tfm sont conservés pour ttf2pk dans les fichiers de mappage ; ttf2tfm écrit sur la sortie standard, en tant que dernière ligne, une entrée appropriée pour un fichier de mappage.

Par exemple, un appel à


ttf2tfm arial -p T1.enc -s 0.25 -P 1 -E 0 arials

produira la ligne suivante :


arials arial Slant=0.25 Pid=1 Eid=0 Encoding=T1.enc

Voir ttf2tfm(1) et afm2tfm(1) du paquet dvips pour une description détaillée des fichiers d'encodage.

Voici un tableau répertoriant les différents paramètres de ttf2tfm et les entrées correspondantes dans un fichier de mappage :


-s Slant
-e Extend
-p Encoding
-f Fontindex
-P Pid
-E Eid
-n PS=Yes
-N PS=Only
-R Replacement
-x Rotate=Yes
-y Y-Offset

Les noms de glyphes de remplacement uniques donnés à ttf2tfm avec `-r ancien-nom-glyphe nouveau-nom-glyphe' sont spécifiés directement avec `ancien-nom-glyphe=nouveau-nom-glyphe'. Ils seront ignorés en mode sous-police ou si aucun fichier d'encodage n'est fourni.

Un paramètre supplémentaire dans un fichier de mappage est unique à ttf2pk : `Hinting', qui peut prendre les valeurs `On' ou `Off'. Certaines polices (par exemple, la partie CJK de cyberbit.ttf) sont rendues incorrectement si le hinting est activé. La valeur par défaut est `On' (vous pouvez également utiliser `Yes', `No', `1', et `0').

Pour une description des sous-polices (c'est-à-dire, les entrées de la forme `<nom-racine>@<nom-fichier-sfd>@') veuillez vous référer à ttf2tfm(1).

Le format d'un fichier de mappage est simple. Chaque ligne définit une police ; vient d'abord le nom de la police TeX, puis le nom de son fichier de police TrueType, suivi des paramètres dans n'importe quel ordre. La casse est significative (même pour les noms de paramètres) ; les paramètres sont séparés de leurs valeurs par un signe égal, avec éventuellement des espaces autour. ttf2pk lit tous les fichiers de mappage ligne par ligne dans l'ordre spécifié dans le fichier de configuration, continuant jusqu'à ce que la police TeX spécifiée dans la ligne de commande soit trouvée, sinon le programme se termine avec le code d'erreur 2. Ainsi, vous pouvez utiliser n'importe quel caractère invalide dans un nom de police TeX pour commencer une ligne de commentaire.

Vous pouvez utiliser `\' comme dernier caractère d'une ligne pour indiquer que l'entrée est continuée sur la ligne suivante. La barre oblique inverse et le caractère de nouvelle ligne suivant seront supprimés.

ttf2pk s'arrêtera s'il ne parvient pas à trouver ou à lire le fichier de métriques de police TeX du nom de police TeX donné.

VALEUR DE RETOUR

Si l'appel a réussi, 0 sera renvoyé. En cas d'erreur, la valeur de retour est 1. Enfin, si la police ne peut pas être trouvée dans les fichiers de mappage, 2 est renvoyé. Cela simplifie l'inclusion de ttf2pk dans des scripts comme mktexpk pour la génération automatique de polices.

ttf2pk(1)

Convertit les polices TrueType en polices de caractères PK pour TeX.

SYNTAXE

ttf2pk [options] police.ttf police.pk

DESCRIPTION

ttf2pk est un utilitaire pour convertir les polices TrueType (.ttf) en polices de caractères PK (.pk) qui peuvent être utilisées par les systèmes de composition TeX (comme TeX ou LaTeX).

OPTIONS

  • -v : Affiche la version de ttf2pk et quitte.
  • -h : Affiche un message d'aide et quitte.
  • -s <taille> : Définit la taille de la police en points. La valeur par défaut est 10.
  • -r <résolution> : Définit la résolution de la police PK en points par pouce (dpi). La valeur par défaut est 300.
  • -f <facteur> : Définit un facteur d'agrandissement pour la police.
  • -b <largeur> : Définit la largeur de la bande (bande) pour la génération de la bitmap.
  • -p <paramètres> : Spécifie des paramètres supplémentaires pour la génération de la bitmap.

EXEMPLES

Pour convertir la police TrueType MyFont.ttf en une police PK de taille 12 points avec une résolution de 600 dpi : 

ttf2pk -s 12 -r 600 MyFont.ttf MyFont.pk
