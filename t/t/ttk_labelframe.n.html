ttk::labelframe(n) Tk Themed Widget ttk::labelframe(n)

NOM

ttk::labelframe - Widget conteneur avec étiquette optionnelle

SYNOPSIS

ttk::labelframe cheminNom ?options?

DESCRIPTION

Un widget ttk::labelframe est un conteneur utilisé pour regrouper d'autres widgets. Il possède une étiquette optionnelle, qui peut être une simple chaîne de caractères ou un autre widget.

OPTIONS STANDARD

-class	-cursor	-padding
-style	-takefocus

Voir la page de manuel ttk_widget pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de la ligne de commande : -height
Nom dans la base de données : height
Classe dans la base de données : Height
Si spécifiée, la hauteur demandée du widget en pixels. (Voir ttk::frame(n) pour des notes supplémentaires sur -width et -height).
Nom de la ligne de commande : -labelanchor
Nom dans la base de données : labelAnchor
Classe dans la base de données : LabelAnchor
Spécifie où placer l'étiquette. Les valeurs autorisées sont (dans le sens des aiguilles d'une montre à partir du coin supérieur gauche) : nw, n, ne, en, e, es, se, s,sw, ws, w et wn. La valeur par défaut dépend du thème.
Nom de la ligne de commande : -labelwidget
Nom dans la base de données : labelWidget
Classe dans la base de données : LabelWidget
Le nom d'un widget à utiliser pour l'étiquette. S'il est défini, il remplace l'option -text. Le -labelwidget doit être un enfant du widget labelframe ou l'un de ses ancêtres, et doit appartenir au même widget de niveau supérieur que le labelframe.
Nom de la ligne de commande : -text
Nom dans la base de données : text
Classe dans la base de données : Text
Spécifie le texte de l'étiquette.
Nom de la ligne de commande : -underline
Nom dans la base de données : underline
Classe dans la base de données : Underline
S'il est défini, spécifie l'indice entier (commençant à 0) d'un caractère à souligner dans la chaîne de texte. Le caractère souligné est utilisé pour l'activation par mnémonique. L'activation par mnémonique pour un ttk::labelframe définit le focus clavier sur le premier enfant du widget ttk::labelframe.
Nom de la ligne de commande : -width
Nom dans la base de données : width
Classe dans la base de données : Width
Si spécifiée, la largeur demandée du widget en pixels.

COMMANDE DU WIDGET

Prend en charge les commandes standard des widgets configure, cget, identify, instate et state ; voir ttk::widget(n).

OPTIONS DE STYLISATION

Le nom de classe pour un ttk::labelframe est TLabelframe. L'étiquette de texte a une classe TLabelframe.Label.

États dynamiques : disabled, readonly.

Les options de stylisation TLabelframe configurables avec ttk::style sont :

-background couleur
-bordercolor couleur
-borderwidth montant
-darkcolor couleur
-labelmargins montant
-labeloutside booléen
-lightcolor couleur
-relief relief

Les options de stylisation TLabelframe.Label configurables avec ttk::style sont :

-background couleur
-font police
-foreground couleur

Certaines options ne sont disponibles que pour des thèmes spécifiques.

Voir la page de manuel ttk::style pour savoir comment configurer les styles ttk.
