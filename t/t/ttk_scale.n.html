ttk::scale(n) Tk Themed Widget ttk::scale(n)

NOM

ttk::scale - Créer et manipuler un widget échelle

SYNOPIS

ttk::scale nomChemin ?options...?

DESCRIPTION

Un widget ttk::scale est généralement utilisé pour contrôler la valeur numérique d'une variable liée qui varie uniformément sur une certaine plage. Une échelle affiche un curseur qui peut être déplacé le long d'une gouttière, la position relative du curseur sur la gouttière indiquant la valeur de la variable.

OPTIONS STANDARDES

-class	-cursor	-style
-takefocus

Voir l'entrée du manuel ttk_widget pour les détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de la ligne de commande :	-command
Nom de la base de données :	command
Classe de la base de données :	Command
Spécifie le préfixe d'une commande Tcl à invoquer chaque fois que la valeur de l'échelle est modifiée via une commande de widget. La commande réelle consiste en cette option suivie d'un espace et d'un nombre réel indiquant la nouvelle valeur de l'échelle.
Nom de la ligne de commande :	-from
Nom de la base de données :	from
Classe de la base de données :	From
Une valeur réelle correspondant à l'extrémité gauche ou supérieure de l'échelle.
Nom de la ligne de commande :	-length
Nom de la base de données :	length
Classe de la base de données :	Length
Spécifie la dimension longue souhaitée de l'échelle en unités d'écran (c'est-à-dire toute forme acceptable par Tk_GetPixels). Pour les échelles verticales, il s'agit de la hauteur de l'échelle ; pour les échelles horizontales, il s'agit de la largeur de l'échelle.
Nom de la ligne de commande :	-orient
Nom de la base de données :	orient
Classe de la base de données :	Orient
Spécifie l'orientation, que le widget soit disposé horizontalement ou verticalement. Doit être horizontal ou vertical ou une abréviation de l'un de ceux-ci.
Nom de la ligne de commande :	-to
Nom de la base de données :	to
Classe de la base de données :	To
Spécifie une valeur réelle correspondant à l'extrémité droite ou inférieure de l'échelle. Cette valeur peut être inférieure ou supérieure à l'option -from.
Nom de la ligne de commande :	-value
Nom de la base de données :	value
Classe de la base de données :	Value
Spécifie la valeur flottante actuelle de la variable. Si -variable est défini sur une variable existante, la spécification de -value n'a aucun effet (la valeur de la variable a la priorité).
Nom de la ligne de commande :	-variable
Nom de la base de données :	variable
Classe de la base de données :	Variable
Spécifie le nom d'une variable globale à lier à l'échelle. Chaque fois que la valeur de la variable change, l'échelle se met à jour pour refléter cette valeur. Chaque fois que l'échelle est manipulée interactivement, la variable sera modifiée pour refléter la nouvelle valeur de l'échelle.

COMMANDE DU WIDGET

nomChemin cget option
Retourne la valeur actuelle de l'option spécifiée ; voir ttk::widget(n).
nomChemin configure ?option? ?valeur option valeur ...?
Modifie ou interroge les options du widget ; voir ttk::widget(n).
nomChemin get ?x y?
Obtient la valeur actuelle de l'option -value, ou la valeur correspondant aux coordonnées x,y si elles sont spécifiées. X et y sont des coordonnées en pixels par rapport à l'origine du widget échelle.
nomChemin identify x y
Retourne le nom de l'élément à la position x, y. Voir ttk::widget(n).
nomChemin instate statespec ?script?
Teste l'état du widget ; voir ttk::widget(n).
nomChemin set valeur
Définit la valeur du widget (c'est-à-dire l'option -value) à valeur. La valeur sera limitée à la plage définie par les options -from et -to. Notez que la modification de la variable liée (c'est-à-dire la variable nommée dans l'option -variable) n'entraîne pas un tel plafonnement.
nomChemin state ?stateSpec?
Modifie ou interroge l'état du widget ; voir ttk::widget(n).

COMMANDES INTERNES

nomChemin coords ?valeur?
Obtient les coordonnées correspondant à valeur, ou les coordonnées correspondant à la valeur actuelle de l'option -value si valeur est omise.

OPTIONS DE STYLISATION

Le nom de la classe pour un ttk::scale est TScale.

États dynamiques : active.

Les options de stylisation TScale configurables avec ttk::style sont :

-background couleur
-borderwidth montant
-darkcolor couleur
-groovewidth montant
-lightcolor couleur
-sliderwidth montant
-troughcolor couleur
-troughrelief relief

Certaines options ne sont disponibles que pour des thèmes spécifiques.

Voir la page du manuel ttk::style pour plus d'informations sur la manière de configurer les styles ttk.
