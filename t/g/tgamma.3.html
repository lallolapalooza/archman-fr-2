tgamma(3) Manuel des fonctions de bibliothèque tgamma(3)

NOM

tgamma, tgammaf, tgammal - fonction gamma vraie

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double tgamma(double x);
float tgammaf(float x);
long double tgammal(long double x);
Besoins en macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)) :

tgamma(), tgammaf(), tgammal() :

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

DESCRIPTION

Ces fonctions calculent la fonction Gamma de x.

La fonction Gamma est définie par

Gamma(x) = intégrale de 0 à l'infini de t^(x-1) e^-t dt

Elle est définie pour tout nombre réel sauf les entiers non positifs. Pour un entier non négatif m, on a

Gamma(m+1) = m!

et, plus généralement, pour tout x :

Gamma(x+1) = x * Gamma(x)

De plus, la relation suivante est valide pour toutes les valeurs de x en dehors des pôles :

Gamma(x) * Gamma(1 - x) = PI / sin(PI * x)

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent Gamma(x).

Si x est un NaN, un NaN est retourné.

Si x est l'infini positif, l'infini positif est retourné.

Si x est un entier négatif, ou l'infini négatif, une erreur de domaine se produit, et un NaN est retourné.

Si le résultat dépasse la capacité de représentation (overflow), une erreur de plage se produit, et les fonctions retournent HUGE_VAL, HUGE_VALF, ou HUGE_VALL, respectivement, avec le signe mathématique correct.

Si le résultat est trop petit pour être représenté (underflow), une erreur de plage se produit, et les fonctions retournent 0, avec le signe mathématique correct.

Si x est -0 ou +0, une erreur de pôle se produit, et les fonctions retournent HUGE_VAL, HUGE_VALF, ou HUGE_VALL, respectivement, avec le même signe que le 0.

ERREURS

Voir math_error(7) pour des informations sur la manière de déterminer si une erreur s'est produite lors de l'appel à ces fonctions.

Les erreurs suivantes peuvent se produire :

Erreur de domaine : x est un entier négatif, ou l'infini négatif
errno est mis à EDOM. Une exception de virgule flottante invalide (FE_INVALID) est levée (mais voir BUGS).
Erreur de pôle : x est +0 ou -0
errno est mis à ERANGE. Une exception de virgule flottante de division par zéro (FE_DIVBYZERO) est levée.
Erreur de plage : débordement du résultat
errno est mis à ERANGE. Une exception de virgule flottante de débordement (FE_OVERFLOW) est levée.

glibc donne également l'erreur suivante qui n'est pas spécifiée dans C99 ou POSIX.1-2001.

Erreur de plage : sous-dépassement du résultat
Une exception de virgule flottante de sous-dépassement (FE_UNDERFLOW) est levée, et errno est mis à ERANGE.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
tgamma (), tgammaf (), tgammal () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

glibc 2.1. C99, POSIX.1-2001.

NOTES

Cette fonction a dû être appelée "fonction gamma vraie" car il existe déjà une fonction gamma(3) qui retourne quelque chose d'autre (voir gamma(3) pour les détails).

BOGUES

Avant glibc 2.18, l'implémentation glibc de ces fonctions ne mettait pas errno à EDOM lorsque x est l'infini négatif.

Avant glibc 2.19, l'implémentation glibc de ces fonctions ne mettait pas errno à ERANGE lors d'une erreur de sous-dépassement.

Dans les versions 2.3.3 et antérieures de glibc, un argument de +0 ou -0 produisait incorrectement une erreur de domaine (errno mis à EDOM et une exception FE_INVALID levée), plutôt qu'une erreur de pôle.

VOIR AUSSI
