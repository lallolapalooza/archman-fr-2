!>
!> CTGSJA calcule la décomposition en valeurs singulières généralisée (GSVD)
!> de deux matrices triangulaires (ou trapézoïdales) supérieures complexes A et B.
!>
!> À l'entrée, on suppose que les matrices A et B ont les formes suivantes,
!> qui peuvent être obtenues par la sous-routine de prétraitement CGGSVP
!> à partir d'une matrice générale M-par-N A et d'une matrice P-par-N B :
!>
!>              N-K-L  K    L
!>    A =    K ( 0    A12  A13 ) si M-K-L >= 0 ;
!>           L ( 0     0   A23 )
!>       M-K-L ( 0     0    0  )
!>
!>            N-K-L  K    L
!>    A =  K ( 0    A12  A13 ) si M-K-L < 0 ;
!>       M-K ( 0     0   A23 )
!>
!>            N-K-L  K    L
!>    B =  L ( 0     0   B13 )
!>       P-L ( 0     0    0  )
!>
!> où la matrice K-par-K A12 et la matrice L-par-L B13 sont des matrices
!> triangulaires supérieures inversibles ; A23 est triangulaire supérieure
!> L-par-L si M-K-L >= 0, sinon A23 est trapézoïdale supérieure (M-K)-par-L.
!>
!> À la sortie,
!>
!>        U**H *A*Q = D1*( 0 R ),    V**H *B*Q = D2*( 0 R ),
!>
!> où U, V et Q sont des matrices unitaires.
!> R est une matrice triangulaire supérieure inversible, et D1
!> et D2 sont des matrices ``diagonales'', qui ont les structures suivantes :
!>
!> Si M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                    K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> où
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R est stocké dans A(1:K+L,N-K-L+1:N) à la sortie.
!>
!> Si M-K-L < 0,
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>
!> où
!> C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!> S = diag( BETA(K+1),  ... , BETA(M) ),
!> C**2 + S**2 = I.
!>
!> R = ( R11 R12 R13 ) est stocké dans A(1:M, N-K-L+1:N) et R33 est stocké
!>     (  0  R22 R23 )
!> dans B(M-K+1:L,N+M-K-L+1:N) à la sortie.
!>
!> Le calcul des matrices de transformation unitaires U, V ou Q
!> est optionnel. Ces matrices peuvent être formées explicitement, ou elles
!> peuvent être post-multipliées dans les matrices d'entrée U1, V1, ou Q1.
!>

!> structures:
!>
!> If M-K-L >= 0,
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                    K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> where
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) ),
!>   S = diag( BETA(K+1),  ... , BETA(K+L) ),
!>   C**2 + S**2 = I.
!>
!>   R is stored in A(1:K+L,N-K-L+1:N) on exit.
!>
!> If M-K-L < 0,
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>
!> where
!> C = diag( ALPHA(K+1), ... , ALPHA(M) ),
!> S = diag( BETA(K+1),  ... , BETA(M) ),
!> C**2 + S**2 = I.
!>
!> R = ( R11 R12 R13 ) is stored in A(1:M, N-K-L+1:N) and R33 is stored
!>     (  0  R22 R23 )
!> in B(M-K+1:L,N+M-K-L+1:N) on exit.
!>
!> The computation of the unitary transformation matrices U, V or Q
!> is optional.  These matrices may either be formed explicitly, or they
!> may be postmultiplied into input matrices U1, V1, or Q1.
!>

       Detailed Description
      

      
ZTGSJA and STGSJA compute the generalized singular value
          decomposition (GSVD) of an M-by-N real matrix A and a P-by-N real
          (ZTGSJA) or complex (STGSJA) matrix B, in the form

      
           A = U * S * Q**H
           B = V * T * Q**H
 

      where U, V, and Q are unitary matrices, and S and T are real matrices.
      The intermediate matrices S and T are of the same dimensions as A and B,
      respectively, and are of the form:
      
 S = [    D1   0      0   ]
     [    0   D2     0   ]
     [    0   0      0   ]

 T = [    0   0      0   ]
     [    0   0      0   ]
     [    0   0      I   ]
 

      if M >= N, or
      
 S = [ D1   0    0 ]
     [ 0   D2    0 ]

 T = [ 0    0    0 ]
     [ 0    0    I ]
 

      if M < N.
      D1 is a K-by-K diagonal matrix with real nonnegative diagonal
      entries.
      D2 is an (M-K)-by-(N-K) diagonal matrix with real nonnegative
      diagonal entries.
      I is an L-by-L identity matrix.
      The diagonal entries of D1 and D2 are the generalized singular values
      of A and B.
      The L-by-L diagonal matrix in T is usually an identity matrix, I.
      The computation of GSVD is performed by the subroutine ZTGSVP (or STGSVP).
      This routine computes the diagonal entries of the matrices
      D1, D2, and L, which form the generalized singular values.
      In addition, it can compute the unitary matrices U, V, and Q.

       Further Details
      

      

       
  ZTGSJA essentially uses a variant of Kogbetliantz algorithm to reduce
  min(L,M-K)-by-L triangular (or trapezoidal) matrix A23 and L-by-L
  matrix B13 to the form:
  
           U1**H *A13*Q1 = C1*R1; V1**H *B13*Q1 = S1*R1,
  
  where U1, V1 and Q1 are unitary matrix.
  C1 and S1 are diagonal matrices satisfying
  
                   C1**2 + S1**2 = I,
  
  and R1 is an L-by-L nonsingular upper triangular matrix.
