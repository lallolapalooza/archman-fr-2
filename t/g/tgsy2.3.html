CTGSY2 résout l'équation généralisée de Sylvester (algorithme non bloqué).

Objectif :

!>
!> CTGSY2 résout l'équation généralisée de Sylvester
!>
!>             A * R - L * B = scale *  C               (1)
!>             D * R - L * E = scale * F
!>
!> en utilisant BLAS de niveau 1 et 2, où R et L sont des matrices inconnues de taille M x N,
!> (A, D), (B, E) et (C, F) sont des paires de matrices données de tailles M x M,
!> N x N et M x N, respectivement. A, B, D et E sont triangulaires supérieures
!> (c'est-à-dire (A,D) et (B,E) sont sous forme de Schur généralisée).
!>
!> La solution (R, L) écrase (C, F). 0 <= SCALE <= 1 est un facteur de
!> mise à l'échelle de sortie choisi pour éviter le dépassement.
!>
!> En notation matricielle, la résolution de l'équation (1) correspond à la résolution de
!> Zx = scale * b, où Z est défini comme
!>
!>        Z = [ kron(In, A)  -kron(B**H, Im) ]             (2)
!>            [ kron(In, D)  -kron(E**H, Im) ],
!>
!> Ik est la matrice identité de taille k et X**H est la transposée de X.
!> kron(X, Y) est le produit de Kronecker entre les matrices X et Y.
!>
!> Si TRANS = 'C', y dans le système conjugué transposé Z**H*y = scale*b
!> est résolu, ce qui est équivalent à résoudre pour R et L dans
!>
!>             A**H * R  + D**H * L   = scale * C           (3)
!>             R  * B**H + L  * E**H  = scale * -F
!>
!> Ce cas est utilisé pour calculer une estimation de Dif[(A, D), (B, E)] =
!> = sigma_min(Z) en utilisant une communication inversée avec CLACON.
!>
!> CTGSY2 contribue également (IJOB >= 1) au calcul dans CTGSYL
!> d'une borne supérieure sur la séparation entre deux paires de matrices. Alors
!> les entrées (A, D), (B, E) sont des sous-pennes de deux paires de matrices dans
!> CTGSYL.
!>

!>

!>          IJOB est INTEGER
!>          Spécifie le type de fonctionnalité à effectuer.
!>          = 0 : résoudre uniquement (1).

!>               de la séparation entre deux paires de matrices est calculée. (une stratégie de look ahead est utilisée).

!>          Non référencé si TRANS = 'T'.
!>

!>          NOTE : RDSCAL n'a de sens que lorsque CTGSY2 est appelé par

INFO

!>          En sortie, si INFO est défini à
!>            =0 : Sortie réussie
!>            <0 :

Name

STGSY2 - solde l'équation généralisée de Sylvester (algorithme non bloqué).

Synopsis

SUBROUTINE STGSY2( TRANS, IJOB, M, N, A, LDA, B, LDB, C, LDC, D, LDD, E, LDE, F, LDF, SCALE, RDSUM, RDSCAL, IWORK, PQ, INFO )

CHARACTER(1) TRANS
INTEGER IJOB, M, N, LDA, LDB, LDC, LDD, LDE, LDF, PQ, INFO
REAL A( LDA, * ), B( LDB, * ), C( LDC, * ), D( LDD, * ), E( LDE, * ), F( LDF, * )
REAL SCALE, RDSUM, RDSCAL
INTEGER IWORK( * )

Purpose

STGSY2 résout l'équation généralisée de Sylvester
              A * R - L * B = scale * C                (1)
              D * R - L * E = scale * F,

en utilisant les routines BLAS de niveau 1 et 2. où R et L sont des matrices
inconnues de taille M-par-N, (A, D), (B, E) et (C, F) sont des paires de
matrices données de taille M-par-M, N-par-N et M-par-N, respectivement, avec
des entrées réelles. (A, D) et (B, E) doivent être sous forme canonique
Schur généralisée, c'est-à-dire A, B sont quasi triangulaires supérieures et
D, E sont triangulaires supérieures. La solution (R, L) écrase (C, F).
0 <= SCALE <= 1 est un facteur d'échelle de sortie choisi pour éviter le
débordement.

En notation matricielle, la résolution de l'équation (1) correspond à résoudre
Zx = scale*b, où Z est défini comme
        Z = [ kron(In, A)  -kron(B**T, Im) ]             (2)
            [ kron(In, D)  -kron(E**T, Im) ],
Ik est la matrice identité de taille k et X**T est la transposée de X.
kron(X, Y) est le produit de Kronecker entre les matrices X et Y.
Dans le processus de résolution de (1), nous résolvons un certain nombre de
systèmes de ce type où Dim(In), Dim(In) = 1 ou 2.

Si TRANS = 'T', résolvez le système transposé Z**T*y = scale*b pour y,
ce qui est équivalent à résoudre pour R et L dans
             A**T * R  + D**T * L   = scale * C           (3)
             R  * B**T + L  * E**T  = scale * -F

Ce cas est utilisé pour calculer une estimation de Dif[(A, D), (B, E)] =
sigma_min(Z) en utilisant la communication inverse avec SLACON.

STGSY2 contribue également (IJOB >= 1) au calcul dans STGSYL
d'une borne supérieure de la séparation entre deux paires de matrices. Alors
les paires de matrices entrantes (A, D), (B, E) sont des sous-pencils de la
paire de matrices dans STGSYL. Voir STGSYL pour les détails.

          Non référencé si TRANS = 'T'.

ZTGSY2 résout l'équation généralisée de Sylvester (algorithme non bloqué).

Objectif :

ZTGSY2 résout l'équation généralisée de Sylvester
             A * R - L * B = scale * C               (1)
             D * R - L * E = scale * F

en utilisant les routines BLAS de niveau 1 et 2, où R et L sont des matrices
inconnues de taille M-par-N. A, B, D et E sont des matrices quasi triangulaires
supérieures (c'est-à-dire (A,D) et (B,E) sous forme de Schur généralisée).

La solution (R, L) écrase (C, F). 0 <= SCALE <= 1 est un facteur d'échelle de sortie
choisi pour éviter le débordement.

En notation matricielle, la résolution de l'équation (1) correspond à la résolution de
Zx = scale * b, où Z est défini comme
        Z = [ kron(In, A)  -kron(B**H, Im) ]             (2)
            [ kron(In, D)  -kron(E**H, Im) ],
Ik est la matrice identité de taille k et X**H est la transposée conjuguée de X.
kron(X, Y) est le produit de Kronecker entre les matrices X et Y.

Si TRANS = 'C', y dans le système transposé conjugué Z**H*y = scale*b
est résolu, ce qui est équivalent à résoudre pour R et L dans
             A**H * R  + D**H * L   = scale * C           (3)
             R  * B**H + L  * E**H  = scale * -F

Ce cas est utilisé pour calculer une estimation de Dif[(A, D), (B, E)] =
= sigma_min(Z) en utilisant la communication inverse avec ZLACON.

ZTGSY2 contribue également (IJOB >= 1) au calcul dans ZTGSYL
d'une borne supérieure de la séparation entre deux paires de matrices. Alors
les sous-pencils (A, D), (B, E) sont des sous-pencils de deux paires de matrices dans
ZTGSYL.

ZTGSY2 - Résout le système d'équations matricielles généralisées triangulaires ou triangulaires supérieures.

Description détaillée

ZTGSY2 résout le système d'équations matricielles généralisées triangulaires ou triangulaires supérieures :

          (1)   A X + D Y = C
                B X + E Y = F

où A, B, D et E sont des matrices triangulaires ou triangulaires supérieures, et C et F sont des matrices données. Les solutions X et Y sont retournées dans les matrices C et F.

Par exemple, si TRANS = 'N' (ou 'T'), A, B, D et E sont traités comme des matrices triangulaires supérieures. Si TRANS = 'C', A, B, D et E sont traités comme des matrices triangulaires inférieures.

Si IJOB = 1, le système est résolu sans vérification des valeurs propres communes ou très proches.

Si IJOB = 0, le système est résolu avec une vérification des valeurs propres communes ou très proches.

Si EQUED = 'Y', A, B, D et E sont triangulaires supérieures.

Si EQUED = 'N', le système A X = C et B Y = F est résolu.
