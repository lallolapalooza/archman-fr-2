NOM

tgatoppm - convertir un fichier TrueVision Targa en image PPM

SYNTAXE

tgatoppm [--alphaout={nom-fichier-alpha,-}] [--headerdump] nom-fichier-tga

DESCRIPTION

Ce programme fait partie de Netpbm(1)

tgatoppm lit un fichier TrueVision Targa en entrée et produit une image PPM en sortie.

OPTIONS

Toutes les options peuvent être abrégées à leur préfixe unique le plus court.

--alphaout=nom-fichier-alpha
tgatoppm crée une image PGM contenant les valeurs du canal alpha dans l'image d'entrée. Si l'image d'entrée ne contient pas de canal alpha, le fichier nom-fichier-alpha contient des valeurs alpha toutes à zéro (transparentes). Si vous ne spécifiez pas --alphaout, tgatoppm ne génère pas de fichier alpha, et si l'image d'entrée possède un canal alpha, tgatoppm le jette simplement.

Si vous spécifiez - comme nom de fichier, tgatoppm écrit la sortie alpha sur la sortie standard et jette l'image.

Voir pamcomp(1)
pour une façon d'utiliser le fichier de sortie alpha.

--headerdump
Demande à tgatoppm d'écrire les informations de l'en-tête TGA sur la sortie d'erreur standard.
