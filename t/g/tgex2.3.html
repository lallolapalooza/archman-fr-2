sous-routine ctgex2 (logical wantq, logical wantz, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldq, * ) q, integer ldq, complex, dimension( ldz, * ) z, integer ldz, integer j1, integer info)

CTGEX2 échange des blocs diagonaux adjacents dans une paire de matrices supérieure (quasi) triangulaire par une transformation d'équivalence unitaire.

Objectif :

!>
!> CTGEX2 échange les blocs diagonaux adjacents de taille 1x1 (A11,B11) et (A22,B22)
!> dans une paire de matrices supérieure (quasi) triangulaire (A, B) par une transformation d'équivalence
!> unitaire.
!>
!> (A, B) doit être en forme canonique généralisée de Schur, c'est-à-dire que A et
!> B sont toutes deux triangulaires supérieures.
!>
!> Optionnellement, les matrices Q et Z des vecteurs de Schur généralisés sont
!> mises à jour.
!>
!>        Q(entree) * A(entree) * Z(entree)**H = Q(sortie) * A(sortie) * Z(sortie)**H
!>        Q(entree) * B(entree) * Z(entree)**H = Q(sortie) * B(sortie) * Z(sortie)**H
!>
!>

Paramètres

WANTQ 
!>          WANTQ est LOGICAL
!>          .TRUE. : met à jour la matrice de transformation gauche Q;
!>          .FALSE.: ne met pas à jour Q.
!>

WANTZ

!>          WANTZ est LOGICAL
!>          .TRUE. : met à jour la matrice de transformation droite Z;
!>          .FALSE.: ne met pas à jour Z.
!>

N

!>          N est INTEGER
!>          L'ordre des matrices A et B. N >= 0.
!>

A

!>          A est un tableau COMPLEX, de dimension (LDA,N)
!>          En entrée, la matrice A dans la paire (A, B).
!>          En sortie, la matrice A mise à jour.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX, de dimension (LDB,N)
!>          En entrée, la matrice B dans la paire (A, B).
!>          En sortie, la matrice B mise à jour.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

Q

!>          Q est un tableau COMPLEX, de dimension (LDQ,N)
!>          Si WANTQ = .TRUE, en entrée, la matrice unitaire Q. En sortie,
!>          la matrice Q mise à jour.
!>          Non référencé si WANTQ = .FALSE..
!>

LDQ

!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= 1;
!>          Si WANTQ = .TRUE., LDQ >= N.
!>

Z

!>          Z est un tableau COMPLEX, de dimension (LDZ,N)
!>          Si WANTZ = .TRUE, en entrée, la matrice unitaire Z. En sortie,
!>          la matrice Z mise à jour.
!>          Non référencé si WANTZ = .FALSE..
!>

LDZ

!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1;
!>          Si WANTZ = .TRUE., LDZ >= N.
!>

J1

!>          J1 est INTEGER
!>          L'indice du premier bloc (A11, B11).
!>

INFO

!>          INFO est INTEGER
!>           =0: Sortie réussie.
!>           =1: La paire de matrices transformée (A, B) serait trop éloignée
!>                de la forme de Schur généralisée ; le problème est mal
!>                conditionné.
!>

NAME

ztgex2

swaps adjacent diagonal blocks in an upper (quasi) triangular matrix pair by an unitary equivalence transformation.

SYNOPSIS

subroutine   ztgex2 (logical wantq, logical wantz, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16,   dimension( ldq, * ) q, integer ldq, complex*16, dimension( ldz, * ) z, integer   ldz, integer j1, integer info)

Detailed Description

ZTGEX2 swaps adjacent diagonal blocks in an upper (quasi) triangular matrix pair by an unitary equivalence transformation.

Purpose:

!>
!> ZTGEX2 swaps adjacent diagonal 1 by 1 blocks (A11,B11) and (A22,B22)
!> in an upper triangular matrix pair (A, B) by an unitary equivalence
!> transformation.
!>
!> (A, B) must be in generalized Schur canonical form, that is, A and
!> B are both upper triangular.
!>
!> Optionally, the matrices Q and Z of generalized Schur vectors are
!> updated.
!>
!>        Q(in) * A(in) * Z(in)**H = Q(out) * A(out) * Z(out)**H
!>        Q(in) * B(in) * Z(in)**H = Q(out) * B(out) * Z(out)**H
!>
!>

Parameters

WANTQ 
!>          WANTQ is LOGICAL
!>          .TRUE. : update the left transformation matrix Q;
!>          .FALSE.: do not update Q.
!>

WANTZ

!>          WANTZ is LOGICAL
!>          .TRUE. : update the right transformation matrix Z;
!>          .FALSE.: do not update Z.
!>

N

!>          N is INTEGER
!>          The order of the matrices A and B. N >= 0.
!>

A

!>          A is COMPLEX*16 array, dimensions (LDA,N)
!>          On entry, the matrix A in the pair (A, B).
!>          On exit, the updated matrix A.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).
!>

B

!>          B is COMPLEX*16 array, dimensions (LDB,N)
!>          On entry, the matrix B in the pair (A, B).
!>          On exit, the updated matrix B.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B. LDB >= max(1,N).
!>

Q

!>          Q is COMPLEX*16 array, dimension (LDQ,N)
!>          If WANTQ = .TRUE, on entry, the unitary matrix Q. On exit,
!>          the updated matrix Q.
!>          Not referenced if WANTQ = .FALSE..
!>

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of the array Q. LDQ >= 1;
!>          If WANTQ = .TRUE., LDQ >= N.
!>

Z

!>          Z is COMPLEX*16 array, dimension (LDZ,N)
!>          If WANTZ = .TRUE, on entry, the unitary matrix Z. On exit,
!>          the updated matrix Z.
!>          Not referenced if WANTZ = .FALSE..
!>

LDZ

!>          LDZ is INTEGER
!>          The leading dimension of the array Z. LDZ >= 1;
!>          If WANTZ = .TRUE., LDZ >= N.
!>

J1

!>          J1 is INTEGER
!>          The index to the first block (A11, B11).
!>

INFO

!>          INFO is INTEGER
!>           =0:  Successful exit.
!>           =1:  The transformed matrix pair (A, B) would be too far
!>                from generalized Schur form; the problem is ill-
!>                conditioned.
!>
