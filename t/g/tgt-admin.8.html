NOM

tgt-admin - Outil de configuration du cible SCSI Linux

SYNTAXE

tgt-admin [-e --execute] [--delete <valeur>] [--offline <valeur>] [--ready <valeur>] [-s --show] [-C --control-port <NNNN>] [-c --conf <fichier>] [--ignore-errors] [-f --force] [-p --pretend] [--dump] [-v --verbose] [-h --help]

DESCRIPTION

tgt-admin est un utilitaire qui permet une configuration persistante des cibles et des LUNs. Il utilise les commandes tgtadm pour créer, supprimer et afficher les cibles.

OPTIONS

-e, --execute

Lit /etc/tgt/targets.conf et exécute les commandes tgtadm. Si la cible existe déjà, elle ne sera pas traitée. Voir --update.

-d, --delete <valeur>

Supprime toutes les cibles ou des cibles sélectionnées. La cible ne sera supprimée que si elle n'est pas utilisée (aucun initiateur n'y est connecté).

Si vous souhaitez supprimer des cibles en cours d'utilisation, vous devez ajouter l'indicateur "--force".

Exemple d'utilisation :
    --delete ALL            - supprime toutes les cibles
    --delete tid=4          - supprime la cible 4
                              (cible avec tid 4)
    --delete iqn.2008-08.com.example:some.target
                            - supprime cette cible

--offline

Met toutes les cibles ou des cibles sélectionnées en état hors ligne. 
Exemple d'utilisation :
    --offline ALL           - met toutes les cibles hors ligne
    --offline tid=4         - met la cible 4 hors ligne
                              (cible avec tid 4)
    --offline iqn.2008-08.com.example:some.target
                            - met cette cible hors ligne

--ready

Met toutes les cibles ou des cibles sélectionnées en état prêt. 
Exemple d'utilisation :
    --ready ALL             - met toutes les cibles en état prêt
    --ready tid=4           - met la cible 4 en état prêt
                              (cible avec tid 4)
    --ready iqn.2008-08.com.example:some.target
                            - met cette cible en état prêt

--update <valeur>

Met à jour toutes les cibles ou des cibles sélectionnées. La cible ne sera mise à jour que si elle n'est pas utilisée (aucun initiateur n'y est connecté).

Si vous souhaitez mettre à jour des cibles en cours d'utilisation, vous devez ajouter l'indicateur "--force".

Exemple d'utilisation :
    --update ALL             - met toutes les cibles en état prêt
    --update tid=4           - met la cible 4 en état prêt
                               (cible avec tid 4)
    --update iqn.2008-08.com.example:some.target
                             - met à jour cette cible

-s, --show

Affiche toutes les cibles.

-C, --control-port <NNNN>

Il est possible d'exécuter plusieurs instances concurrentes de tgtd sur un hôte. Cet argument est utilisé pour contrôler sur quelle instance la commande tgt-admin opérera.

-c, --conf <fichier de configuration>

Spécifie un fichier de configuration alternatif au lieu de /etc/tgt/targets.conf, qui est le fichier par défaut.

--ignore-errors

Continue même si tgtadm se termine avec un code non nul.

-f, --force

Force certaines opérations même si la cible est utilisée.

-p, --pretend

Affiche uniquement les options de tgtadm qui seraient utilisées ; n'exécute aucune action. Suppose -v.

--dump

Sauvegarde la configuration actuelle de tgtd. Note : n'inclut pas les paramètres détaillés, comme la mise en cache en écriture.

-v, --verbose

Augmente la verbosité (affiche les commandes tgtadm utilisées).

-h, --help

Affiche la liste des options disponibles et quitte.

FICHIERS

/etc/tgt/targets.conf

Fichier de configuration pour tgt-admin.

/usr/share/doc/tgt/targets.conf.example

Fichier de configuration exemple pour tgt-admin.

VOIR AUSSI
