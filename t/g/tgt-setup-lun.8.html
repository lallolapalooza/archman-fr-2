NOM

tgt-setup-lun - Script d'aide qui crée une cible, ajoute un périphérique à la cible et définit les initiateurs qui peuvent se connecter à la cible

SYNTAXE

tgt-setup-lun -d <périphérique> -n <nom_cible> [-b <nom_blocage>] [-t <transport>] [-C <port_contrôle>] [IP_initiateur...] [-h]

DESCRIPTION

Crée une cible selon le nom_cible fourni. tgtd doit être en cours d'exécution. Le format de l'IQN par défaut généré à partir du nom de la cible est : "iqn.2001-04.com.<nom_hôte>-<nom_cible>", ou un IQN complet peut être donné. Le nom de la cible doit être unique.

Le script ajoute ensuite le périphérique demandé à la cible. Si des adresses IP spécifiques sont définies, elles sont ajoutées à la liste des initiateurs autorisés pour cette cible. Si aucune adresse IP n'est définie, il est considéré que la cible accepte tout initiateur.

EXEMPLES

Créer une cible qui utilise /dev/sdb1 et autorise les connexions uniquement depuis 192.168.10.81 :

      tgt-setup-lun -d /dev/sdb1 -n ma_cible 192.168.10.81

Créer une cible qui utilise /dev/sdb1 et autorise les connexions uniquement depuis 192.168.10.81 et 192.168.10.82 :

      tgt-setup-lun -d /dev/sdb1 -n ma_cible 192.168.10.81 192.168.10.82

Créer une cible qui utilise /dev/sdb1 et autorise les connexions depuis n'importe quel initiateur :

      tgt-setup-lun -d /dev/sdb1 -n ma_cible

Afficher l'aide :

      tgt-setup-lun -h
