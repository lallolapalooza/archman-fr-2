NOM

tgtimg - Utilitaire de fichiers image pour le framework de cible SCSI Linux

SYNTAXE

tgtimg [-o --op <opération>] [-Y --device-type <type-appareil>] [-b --barcode <code-barres>] [-s --size <taille>] [-t --type <type-média>] [-f --file <chemin>] [-T --thin-provisioning]

tgtimg --help

DESCRIPTION

Tgtimg est un utilitaire pour créer et gérer les fichiers image utilisés par l'émulation de périphérique TGTD.

Cette commande est utilisée pour initialiser les fichiers image de périphérique avec les métadonnées supplémentaires, telles que le code-barres, la liste des blocs, la taille totale, etc., dont l'émulation TGTD a besoin.

OPTIONS

-h, --help

Affiche un écran d'aide et quitte.

-o, --op {new|show}

Opération. Peut être `new` pour créer un nouveau fichier image ou `show` pour afficher le contenu d'un fichier image existant.

-Y, --device-type <type>

Ceci spécifie le type de fichier image.
Les types d'appareils pris en charge sont :
    cd   : pour créer un média pour un appareil dvd
    disk : pour créer un média pour un appareil disque
    tape : pour créer un média pour un appareil bande

-t, --type <type-média>

Lors de la création d'une nouvelle image, ceci spécifie le type de média à émuler. Les types de médias disponibles dépendent du type de l'appareil.
Les types de médias pris en charge pour les appareils cd sont :
    dvd+r : créer un DVD+R vierge inscriptible
Les types de médias pris en charge pour les appareils disque sont :
    disk  : créer un disque vide
Les types de médias pris en charge pour les appareils bande sont :
    data  : créer une bande de données normale
    clean : créer une bande de nettoyage
    worm  : créer une bande WORM (Write Once, Read Many)

-b, --barcode <code-barres>

Lors de la création d'une nouvelle image, cet argument spécifie le code-barres à utiliser avec ce fichier image. Les logiciels d'application de sauvegarde utilisent souvent des codes-barres pour identifier des bandes spécifiques. Lors de l'émulation d'une VTL (Virtual Tape Library), assurez-vous que toutes les images de bande utilisent des codes-barres uniques.

-s, --size <taille>

Lors de la création d'une nouvelle image, ceci spécifie la taille en mégaoctets pour l'image de bande virtuelle.

-f, --file <chemin>

Le nom du fichier image.

-T, --thin-provisioning

Cet argument fait que le format de l'image utilise le provisionnement léger (thin-provisioning). Cela signifie que le fichier créé sera un fichier épars qui allouera des blocs à partir du système de fichiers à la demande.

Soyez prudent lors de l'utilisation du provisionnement léger. Si le système de fichiers se remplit, une écriture iSCSI sur un LUN provisionné de manière légère peut échouer. Les initiateurs ne gèrent généralement pas gracieusement les erreurs de type "espace insuffisant".

Le provisionnement léger utilise `FALLOC_FL_PUNCH_HOLE`, qui n'est disponible que sur certains systèmes de fichiers Linux. Le provisionnement léger ne peut être utilisé que pour les images de DISQUE.

EXEMPLES

Pour créer un disque de 100 Mo

      tgtimg --op new --device-type disk --type disk --size 100 --file /data/hd001.raw

Pour créer une nouvelle image de bande

      tgtimg --op new --device-type tape --barcode 12345 --size 100 --type data --file /data/tape001.img

Pour afficher le contenu d'une image existante

      tgtimg --op show --device-type tape --file /data/tape001.img

Pour créer une nouvelle image DVD+R vierge

      tgtimg --op new --device-type cd --type dvd+r --file /data/dvd001.iso
