tkill(2) Manuel des appels système tkill(2)

NOM

tkill, tgkill - envoyer un signal à un thread

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <signal.h>           /* Définition des constantes SIG* */
#include <sys/syscall.h>      /* Définition des constantes SYS_* */
#include <unistd.h>
[[deprecated]] int syscall(SYS_tkill, pid_t tid, int sig);
#include <signal.h>
int tgkill(pid_t tgid, pid_t tid, int sig);

Note : glibc ne fournit pas d'enveloppe pour tkill(), nécessitant l'utilisation de syscall(2).

DESCRIPTION

tgkill() envoie le signal sig au thread ayant l'ID de thread tid dans le groupe de threads tgid. (En comparaison, kill(2) peut être utilisé pour envoyer un signal uniquement à un processus (c'est-à-dire un groupe de threads) dans son ensemble, et le signal sera délivré à un thread arbitraire au sein de ce processus.)

tkill() est un prédécesseur obsolète de tgkill(). Il ne permet de spécifier que l'ID du thread cible, ce qui peut entraîner l'envoi du signal au mauvais thread si un thread se termine et que son ID de thread est recyclé. Évitez d'utiliser cet appel système.

Ce sont les interfaces brutes des appels système, destinées à un usage interne de la bibliothèque de threads.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EAGAIN
La limite de ressources RLIMIT_SIGPENDING a été atteinte et sig est un signal temps réel.
EAGAIN
Mémoire noyau insuffisante disponible et sig est un signal temps réel.
EINVAL
Un ID de thread, un ID de groupe de threads ou un signal invalide a été spécifié.
EPERM
Permission refusée. Pour les permissions requises, voir kill(2).
ESRCH
Aucun processus avec l'ID de thread (et l'ID de groupe de threads) spécifié n'existe.

NORMES

Linux.

HISTORIQUE

tkill()
Linux 2.4.19 / 2.5.4.
tgkill()
Linux 2.5.75, glibc 2.30.

NOTE

Voir la description de CLONE_THREAD dans clone(2) pour une explication des groupes de threads.

VOIR AUSSI

clone(2), gettid(2), kill(2), rt_sigqueueinfo(2)
