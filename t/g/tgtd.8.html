NOM

tgtd - Le démon cible SCSI

SYNOPIS

tgtd

tgtd [-C --control-port <ENTIER>] [-d --debug <ENTIER>] [-f --foregound] [-h --help] [--iscsi <...>]

DESCRIPTION

Tgtd est un démon cible SCSI. Il peut être utilisé pour fournir un service de cible SCSI à un réseau. Le service le plus courant est iSCSI, mais d'autres services sont également pris en charge.

TYPES DE PÉRIPHÉRIQUES

Tgtd prend en charge l'émulation et le passage direct de périphériques réels.

    Tgtd peut émuler les types de périphériques suivants :
    disk       : Périphérique disque normal. Émule un disque dur SCSI.
    tape       : Périphérique bande. Émule un lecteur de bande SCSI.
    cd         : Périphérique CD. Émule un graveur DVD SCSI.
    changer    : Changeur de média. Émule le périphérique changeur pour une bibliothèque de bandes virtuelle ou un jukebox DVD.

OPTIONS

-d --debug <ENTIER>

Définir à une valeur non nulle pour activer la journalisation de messages de débogage supplémentaires.

-f --foreground

Exécuter le démon au premier plan.

-h --help

Afficher le texte d'aide à l'écran.

-C --control-port <ENTIER>

Cette commande est utilisée pour spécifier le port de contrôle à utiliser pour cette instance de tgtd. Cela permet d'exécuter plusieurs instances de TGTD sur un hôte.

TGTADM dispose d'un argument correspondant pour contrôler l'instance à laquelle se connecter.

--iscsi <...>

Options spécifiques à iSCSI. Voir la section ISCSI ci-dessous pour les options spécifiques à ce frontal.

OPTIONS ISCSI

Ces paramètres s'appliquent uniquement au frontal iSCSI.

portal=<adresse-ip[:port]>

Cette option est utilisée pour lier tgtd à une adresse IP/portail et/ou à un port spécifique. Par défaut, tgtd se liera au port 3260 sur l'adresse wildcard. La partie adresse IP (avant le « : ») peut être omise pour désigner l'adresse wildcard avec un port non standard.

Exemple : lier tgtd à une adresse et un port spécifiques

	tgtd --iscsi portal=192.0.2.1:3260

Exemple : lier tgtd à n'importe quelle adresse mais avec un port non standard

	tgtd --iscsi portal=:3251

nop_interval=<entier>

Ceci définit l'intervalle par défaut pour l'envoi de NOP-OUT afin de sonder les initiateurs connectés. Ce paramètre contrôle uniquement la valeur par défaut pour les cibles. Les cibles individuelles peuvent être contrôlées via tgtadm.

La valeur par défaut est 0, ce qui signifie que la fonctionnalité est désactivée. TGTD n'enverra aucune sonde NOP-OUT.

nop_count=<entier>

Ceci définit la valeur par défaut du nombre de sondes échouées après lesquelles TGTD considérera l'initiateur comme mort et terminera la session. Ce paramètre contrôle uniquement la valeur par défaut pour les cibles. Les cibles individuelles peuvent être contrôlées via tgtadm.

La valeur par défaut est 0.

Exemple : envoyer NOP-OUT toutes les 5 secondes et abandonner la session après 6 échecs.

	tgtd --iscsi portal=192.0.2.1:3260,nop_interval=5,nop_count=6

VARIABLES D'ENVIRONNEMENT

TGT_IPC_SOCKET=<chemin>

Lorsqu'elle est définie, tgtd et tgtadm utiliseront le chemin spécifié comme socket IPC au lieu du chemin par défaut « /var/run/tgtd/socket.0 »
