NOM

DTGEXC - La routine DTGEXC réordonne la décomposition de Schur généralisée réelle d'une paire de matrices réelles (A,B) à l'aide d'une transformation d'équivalence orthogonale

SYNOPSIS

SUBROUTINE DTGEXC(WANTQ, WANTZ, N, A, LDA, B, LDB, Q, LDQ, Z, LDZ, IFST, ILST,
                 WORK, LWORK, INFO)
CHARACTER * 1 WANTQ, WANTZ
INTEGER N, LDA, LDB, LDQ, LDZ, IFST, ILST, LWORK, INFO
DOUBLE PRECISION A(LDA, *), B(LDB, *), Q(LDQ, *), Z(LDZ, *), WORK(*)

DESCRIPTION

DTGEXC réordonne la décomposition de Schur généralisée réelle d'une paire de matrices réelles (A,B) à l'aide d'une transformation d'équivalence orthogonale

                 (A, B) = Q * (A, B) * Z**T,

de sorte que le bloc diagonal de (A, B) avec l'indice de ligne IFST soit déplacé à la ligne ILST.

(A, B) doit être dans la forme canonique de Schur généralisée réelle (telle que retournée par SGGES), c'est-à-dire A est triangulaire par blocs supérieurement avec des blocs diagonaux de 1x1 et 2x2. B est triangulaire supérieurement.

Optionnellement, les matrices Q et Z des vecteurs de Schur généralisés sont mises à jour.

        Q(in) * A(in) * Z(in)**T = Q(out) * A(out) * Z(out)**T
        Q(in) * B(in) * Z(in)**T = Q(out) * B(out) * Z(out)**T

PARAMETRES

WANTQ
!>          WANTQ est LOGICAL
!>          .TRUE. : mettre à jour la matrice de transformation gauche Q;
!>          .FALSE.: ne pas mettre à jour Q.
!>
WANTZ
!>          WANTZ est LOGICAL
!>          .TRUE. : mettre à jour la matrice de transformation droite Z;
!>          .FALSE.: ne pas mettre à jour Z.
!>
N
!>          N est INTEGER
!>          L'ordre des matrices A et B. N >= 0.
!>
A
!>          A est DOUBLE PRECISION array, dimension (LDA,N)
!>          En entrée, la matrice A sous forme canonique de Schur généralisée réelle.
!>          En sortie, la matrice A mise à jour, à nouveau sous forme canonique de Schur généralisée réelle.
!>
LDA
!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>
B
!>          B est DOUBLE PRECISION array, dimension (LDB,N)
!>          En entrée, la matrice B sous forme canonique de Schur généralisée réelle (A,B).
!>          En sortie, la matrice B mise à jour, à nouveau sous forme canonique de Schur généralisée réelle (A,B).
!>
LDB
!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>
Q
!>          Q est DOUBLE PRECISION array, dimension (LDQ,N)
!>          En entrée, si WANTQ = .TRUE., la matrice orthogonale Q.
!>          En sortie, la matrice Q mise à jour.
!>          Si WANTQ = .FALSE., Q n'est pas référencé.
!>
LDQ
!>          LDQ est INTEGER
!>          La dimension principale du tableau Q. LDQ >= 1.
!>          Si WANTQ = .TRUE., LDQ >= N.
!>
Z
!>          Z est DOUBLE PRECISION array, dimension (LDZ,N)
!>          En entrée, si WANTZ = .TRUE., la matrice orthogonale Z.
!>          En sortie, la matrice Z mise à jour.
!>          Si WANTZ = .FALSE., Z n'est pas référencé.
!>
LDZ
!>          LDZ est INTEGER
!>          La dimension principale du tableau Z. LDZ >= 1.
!>          Si WANTZ = .TRUE., LDZ >= N.
!>
IFST
!>          IFST est INTEGER
!>
ILST
!>          ILST est INTEGER
!>          Spécifie le réordonnancement des blocs diagonaux de (A, B).
!>          Le bloc avec l'indice de ligne IFST est déplacé à la ligne ILST, par une
!>          séquence d'échanges entre blocs adjacents.
!>          En sortie, si IFST pointait en entrée sur la deuxième ligne d'un
!>          bloc de 2x2, il est modifié pour pointer sur la première ligne ;
!>          ILST pointe toujours sur la première ligne du bloc dans sa
!>          position finale (qui peut différer de sa valeur d'entrée par
!>          +1 ou -1). 1 <= IFST, ILST <= N.
!>
WORK
!>          WORK est DOUBLE PRECISION array, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) retourne le LWORK optimal.
!>
LWORK
!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= 1 quand N <= 1, sinon LWORK >= 4*N + 16.
!>
!>          Si LWORK = -1, alors une requête de mémoire vive est supposée ; la routine
!>          calcule seulement la taille optimale du tableau WORK, retourne
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          lié à LWORK n'est émis par XERBLA.
!>
INFO
!>          INFO est INTEGER
!>           =0:  sortie réussie.
!>           <0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>           =1:  La paire de matrices transformée (A, B) serait trop éloignée
!>                de la forme de Schur généralisée ; le problème est mal
!>                conditionné. (A, B) pourrait avoir été partiellement réordonné,
!>                et ILST pointe sur la première ligne de la position actuelle
!>                du bloc déplacé.
!>

ztgexc(3)

NAME

ztgexc - réordonne la décomposition de Schur généralisée d'une paire de matrices complexes

SYNOPSIS

subroutine ztgexc (wantq, wantz, n, a, lda, b, ldb, q, ldq, z, ldz, ifst, ilst, info)

logical :: wantq
logical :: wantz
integer :: n
complex*16, dimension(lda,*) :: a
integer :: lda
complex*16, dimension(ldb,*) :: b
integer :: ldb
complex*16, dimension(ldq,*) :: q
integer :: ldq
complex*16, dimension(ldz,*) :: z
integer :: ldz
integer :: ifst
integer :: ilst
integer :: info

Detailed Description

ZTGEXC réordonne la décomposition de Schur généralisée d'une paire de matrices complexes (A,B), en utilisant une transformation d'équivalence unitaire (A, B) := Q * (A, B) * Z**H, de sorte que le bloc diagonal de (A, B) avec l'indice de ligne IFST soit déplacé vers la ligne ILST.

(A, B) doit être en forme canonique de Schur généralisée, c'est-à-dire que A et B sont toutes deux triangulaires supérieures.

Optionnellement, les matrices Q et Z des vecteurs de Schur généralisés sont mises à jour.

Q(in) * A(in) * Z(in)**H = Q(out) * A(out) * Z(out)**H

Q(in) * B(in) * Z(in)**H = Q(out) * B(out) * Z(out)**H

Function Documentation

WANTQ

WANTQ est LOGIQUE

.TRUE. : met à jour la matrice de transformation gauche Q;

.FALSE. : ne met pas à jour Q.

WANTZ

WANTZ est LOGIQUE

.TRUE. : met à jour la matrice de transformation droite Z;

.FALSE. : ne met pas à jour Z.

N

N est ENTIER

L'ordre des matrices A et B. N >= 0.

A

A est un tableau COMPLEX*16, dimension (LDA,N)

En entrée, la matrice triangulaire supérieure A dans la paire (A, B).

En sortie, la matrice A mise à jour.

LDA

LDA est ENTIER

La dimension principale du tableau A. LDA >= max(1,N).

B

B est un tableau COMPLEX*16, dimension (LDB,N)

En entrée, la matrice triangulaire supérieure B dans la paire (A, B).

En sortie, la matrice B mise à jour.

LDB

LDB est ENTIER

La dimension principale du tableau B. LDB >= max(1,N).

Q

Q est un tableau COMPLEX*16, dimension (LDQ,N)

En entrée, si WANTQ = .TRUE., la matrice unitaire Q.

En sortie, la matrice Q mise à jour.

Si WANTQ = .FALSE., Q n'est pas référencé.

LDQ

LDQ est ENTIER

La dimension principale du tableau Q. LDQ >= 1;

Si WANTQ = .TRUE., LDQ >= N.

Z

Z est un tableau COMPLEX*16, dimension (LDZ,N)

En entrée, si WANTZ = .TRUE., la matrice unitaire Z.

En sortie, la matrice Z mise à jour.

Si WANTZ = .FALSE., Z n'est pas référencé.

LDZ

LDZ est ENTIER

La dimension principale du tableau Z. LDZ >= 1;

Si WANTZ = .TRUE., LDZ >= N.

IFST

IFST est ENTIER

ILST

ILST est ENTIER

Spécifie le réordonnancement des blocs diagonaux de (A, B).

Le bloc avec l'indice de ligne IFST est déplacé vers la ligne ILST, par une séquence d'échanges entre blocs adjacents.

INFO

INFO est ENTIER

=0: Sortie réussie.

<0: si INFO = -i, le i-ème argument avait une valeur illégale.

=1: La paire de matrices transformée (A, B) serait trop éloignée de la forme de Schur généralisée ; le problème est mal conditionné. (A, B) peut avoir été partiellement réordonnée, et ILST pointe vers la première ligne de la position actuelle du bloc en cours de déplacement.
