NOM

typer - Annotateur de types pour programmes Erlang

DESCRIPTION

TypEr affiche les informations de type pour les modules Erlang. De plus, il peut annoter le code des fichiers avec ces informations de type.

Utilisation de TypEr

TypEr est utilisé depuis la ligne de commande. Cette section fournit une brève description des options. Les mêmes informations peuvent être obtenues en tapant ce qui suit dans un shell :

typer --help

Usage :

typer [--help] [--version] [--plt PLT] [--edoc]
      [--show | --show-exported | --annotate | --annotate-inc-files | --annotate-in-place]
      [-Ddefine]* [-I include_dir]* [-pa dir]* [-pz dir]*
      [-T application]* file* [-r directory*]

NOTE : * indique que plusieurs occurrences de l'option sont possibles.

Options :

-r

Recherche les répertoires récursivement pour trouver des fichiers .erl en dessous d'eux. Si une liste de fichiers est donnée, cette option doit être placée après eux.

--show

Affiche les spécifications de type pour toutes les fonctions sur stdout. (C'est le comportement par défaut ; cette option n'est pas vraiment nécessaire.)

--show-exported (ou show_exported)

Identique à --show, mais affiche les spécifications pour les fonctions exportées uniquement. Les spécifications sont affichées par ordre alphabétique selon le nom de la fonction.

--annotate

Annote les fichiers spécifiés avec des spécifications de type.

--annotate-inc-files

Identique à --annotate, mais annote tous les fichiers -include() ainsi que tous les fichiers .erl. (Utilisez cette option avec précaution — elle n'est pas bien testée.)

--annotate-in-place

Annote directement dans les fichiers source, au lieu de déverser les fichiers annotés dans un répertoire différent. (Utilisez cette option avec précaution — elle n'est pas bien testée.)

--edoc

Affiche les informations de type sous forme de commentaires Edoc @spec, pas sous forme de spécifications de type.

--plt

Utilise le fichier PLT dialyzer spécifié plutôt que le fichier par défaut.

-T fichier*

Les fichiers spécifiés contiennent déjà des spécifications de type et celles-ci doivent être considérées comme fiables pour afficher les spécifications pour le reste des fichiers. (Plusieurs fichiers ou répertoires, séparés par des espaces, peuvent être spécifiés.)

-Dnom (ou -Dnom=valeur)

Passe les noms définis à TypEr. (**)

-I

Passe le répertoire include à TypEr. (**)

-pa dir

Inclut dir dans le chemin pour Erlang. Ceci est utile lors de l'analyse de fichiers qui utilisent des directives -include_lib() ou des transformations d'analyse.

-pz dir

Inclut dir dans le chemin pour Erlang. Ceci est utile lors de l'analyse de fichiers qui utilisent des directives -include_lib() ou des transformations d'analyse.

--version (ou -v)

Affiche la version de TypEr et quelques informations supplémentaires, puis quitte.

NOTE : les options -D et -I fonctionnent de la même manière qu'avec erlc.
