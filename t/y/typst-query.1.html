NOM

typst-query - Traite un fichier d'entrée pour extraire les métadonnées fournies

SYNTAXE

typst-query [--field] [--one] [--format] [--pretty] [--target] [--root] [--input] [--font-path] [--ignore-system-fonts] [--ignore-embedded-fonts] [--package-path] [--package-cache-path] [--creation-timestamp] [-j|--jobs] [--features] [--diagnostic-format] [-h|--help] <ENTREE> <SELECTEUR>

DESCRIPTION

Traite un fichier d'entrée pour extraire les métadonnées fournies

OPTIONS

--field=CHAMP
Extrait un seul champ de tous les éléments récupérés
--one
Attend et récupère exactement un élément
--format=FORMAT [défaut : json]
Le format dans lequel sérialiser

[valeurs possibles : json, yaml]

--pretty
Indique si la sortie sérialisée doit être jolie.

S'applique uniquement au format JSON.

--target=CIBLE [défaut : paged]
La cible pour laquelle compiler

Valeurs possibles :

  • paged : formats PDF et image
  • html : HTML
--root=DIR
Configure la racine du projet (pour les chemins absolus)
Peut également être spécifié via la variable d'environnement TYPST_ROOT.
--input=clé=valeur
Ajoute une paire clé-valeur de chaîne visible via `sys.inputs`
--font-path=DIR
Ajoute des répertoires supplémentaires qui seront recherchés récursivement pour les polices.

Si plusieurs chemins sont spécifiés, ils sont séparés par le séparateur de chemins du système (`:` sur les systèmes de type Unix et `;` sur Windows).

Peut également être spécifié via la variable d'environnement TYPST_FONT_PATHS.
--ignore-system-fonts
Garantit que les polices système ne seront pas recherchées, sauf si elles sont explicitement incluses via `--font-path`
Peut également être spécifié via la variable d'environnement TYPST_IGNORE_SYSTEM_FONTS.
--ignore-embedded-fonts
Garantit que les polices intégrées dans Typst ne seront pas prises en compte
Peut également être spécifié via la variable d'environnement TYPST_IGNORE_EMBEDDED_FONTS.
--package-path=DIR
Chemin personnalisé vers les paquets locaux, par défaut à l'emplacement dépendant du système
Peut également être spécifié via la variable d'environnement TYPST_PACKAGE_PATH.
--package-cache-path=DIR
Chemin personnalisé vers le cache des paquets, par défaut à l'emplacement dépendant du système
Peut également être spécifié via la variable d'environnement TYPST_PACKAGE_CACHE_PATH.
--creation-timestamp=HORODATEUR_UNIX
La date de création du document formatée en horodateur UNIX.

Pour plus d'informations, voir https://reproducible-builds.org/specs/source-date-epoch/.

Peut également être spécifié via la variable d'environnement SOURCE_DATE_EPOCH.
-j, --jobs=JOBS
Nombre de tâches parallèles lancées pendant la compilation. Par défaut au nombre de CPUs. Le régler à 1 désactive le parallélisme
--features=FONCTIONNALITÉS
Active les fonctionnalités en cours de développement qui peuvent être modifiées ou supprimées à tout moment

[valeurs possibles : html, a11y-extras]

Peut également être spécifié via la variable d'environnement TYPST_FEATURES.
--diagnostic-format=FORMAT_DIAGNOSTIC [défaut : human]
Le format dans lequel émettre les diagnostics

[valeurs possibles : human, short]

-h, --help
Affiche l'aide (voir un résumé avec `-h`)
<ENTREE>
Chemin du fichier Typst d'entrée. Utiliser `-` pour lire l'entrée depuis stdin
<SELECTEUR>
Définit les éléments à récupérer
