NOM

typst-fonts - Liste toutes les polices découvertes dans le système et les chemins de polices personnalisés

SYNOPSIS

typst-fonts [--font-path] [--ignore-system-fonts] [--ignore-embedded-fonts] [--variants] [-h|--help]

DESCRIPTION

Liste toutes les polices découvertes dans le système et les chemins de polices personnalisés

OPTIONS

--font-path=DIR
Ajoute des répertoires supplémentaires où les polices sont recherchées de manière récursive.

Si plusieurs chemins sont spécifiés, ils sont séparés par le séparateur de chemin du système (`:` sur les systèmes de type Unix et `;` sur Windows).

Peut également être spécifié avec la variable d'environnement TYPST_FONT_PATHS.
--ignore-system-fonts
Garantit que les polices système ne seront pas recherchées, sauf si elles sont explicitement incluses via `--font-path`
Peut également être spécifié avec la variable d'environnement TYPST_IGNORE_SYSTEM_FONTS.
--ignore-embedded-fonts
Garantit que les polices intégrées dans Typst ne seront pas prises en compte
Peut également être spécifié avec la variable d'environnement TYPST_IGNORE_EMBEDDED_FONTS.
--variants
Liste également les variantes de style de chaque famille de polices
-h, --help
Affiche l'aide (voir un résumé avec '-h')
