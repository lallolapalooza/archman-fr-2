typst(1) Manuel des commandes générales typst(1)

NOM

typst - Le compilateur Typst

SYNTAXE

typst [--color] [--cert] [-h|--help] [-V|--version] <sous-commandes>

DESCRIPTION

Le compilateur Typst

OPTIONS

--color=COULEUR [par défaut : auto]
Si la couleur doit être utilisée. Lorsqu'elle est définie sur `auto`, si le terminal la prend en charge.

[valeurs possibles : auto, always, never]

--cert=CERT
Chemin d'accès à un certificat CA personnalisé à utiliser lors des requêtes réseau.
Peut également être spécifié avec la variable d'environnement TYPST_CERT.
-h, --help
Afficher l'aide.
-V, --version
Afficher la version.

SOUS-COMMANDES

typst-compile(1)
Compile un fichier d'entrée dans un format de sortie pris en charge.
typst-watch(1)
Surveille un fichier d'entrée et recompile en cas de changement.
typst-init(1)
Initialise un nouveau projet à partir d'un modèle.
typst-query(1)
Traite un fichier d'entrée pour extraire les métadonnées fournies.
typst-fonts(1)
Liste toutes les polices découvertes dans le système et les chemins de polices personnalisés.
typst-completions(1)
Génère des scripts d'achèvement de shell.
typst-info(1)
Affiche des informations de débogage sur Typst.
typst-help(1)
Affiche ce message ou l'aide des sous-commandes données.
