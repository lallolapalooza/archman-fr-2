NOM

typog-grep - grep spécialisé pour les éléments typog-inspect dans les fichiers journaux LaTeX

SYNTAXE

typog-grep -a|--all|--any [OPTION...] FICHIER-JOURNAL...
typog-grep [OPTION...] REGEXP FICHIER-JOURNAL...

La première forme, le « mode découverte », affiche tous les IDs des

<typog-inspect id="ID" ...>

éléments dans FICHIER-JOURNAL.

La seconde forme affiche le contenu, DONNEES-JOURNAL, des éléments

<typog-inspect id="ID" ...>
DONNEES-JOURNAL
</typog-inspect>

dont les IDs correspondent à REGEXP dans FICHIER-JOURNAL.

Si aucun FICHIER-JOURNAL n'est spécifié, lecture depuis stdin. Le nom de fichier "-" est synonyme de stdin.

DESCRIPTION

typog-grep est un post-processeur adapté pour les fichiers journal LaTeX et l'environnement "typoginspect" tel que fourni par le paquet LaTeX typog. Il ressemble davantage au vénérable sgrep https://www.cs.helsinki.fi/u/jjaakkol/sgrep.html qu'à grep https://pubs.opengroup.org/onlinepubs/9699919799/utilities/grep.html de POSIX.

Dans le fichier source LaTeX, l'utilisateur encadre son texte ou son code dans un environnement "typoginspect" :

\begin{typoginspect}{ID}
TEXTE-OU-CODE-A-INSPECTER
\end{typoginspect}

où ID est utilisé pour identifier un ou plusieurs extraits encadrés. ID n'a pas besoin d'être unique. Le mécanisme REGEXP facilite la sélection de groupes d'IDs liés s'ils sont nommés en conséquence.

Dans le FICHIER-JOURNAL, le résultat de l'environnement apparaît, empaqueté avec des informations de traçage, comme

<typog-inspect id="ID" job="NOM-TRAVAIL" line="NUMERO-LIGNE" page="NUMERO-PAGE">
DONNEES-JOURNAL
</typog-inspect>

où toutes les séquences de lettres majuscules sont des méta-variables et en particulier NOM-TRAVAIL est l'expansion de "\jobname", NUMERO-LIGNE est le numéro de ligne du fichier source LaTeX du début de l'environnement "typoginspect", et NUMERO-PAGE est la page où se trouve la sortie de "TEXTE-OU-CODE-A-INSPECTER".

typog-grep révèle le contenu de FICHIER-JOURNAL entre "<typog-inspect id="ID" ...>" et "</typog-inspect>" à l'exclusion des balises XML elles-mêmes. Accédez à NOM-TRAVAIL, NUMERO-LIGNE et NUMERO-PAGE avec les options de ligne de commande --job-name, --line-number et --page-number, respectivement. Utilisez --id pour afficher le nom des ID qui correspondent à REGEXP.

Les environnements "typoginspect" peuvent être imbriqués. typog-grep respecte l'imbrication, c'est-à-dire que si l'ID de l'environnement imbriqué ne correspond pas à REGEXP, il ne sera pas inclus dans la sortie du programme.

OPTIONS

La liste des options est triée par les noms des options longues.

-a, --all, --any
Mode découverte d'ID : Découvre tous les éléments "typog-inspect" indépendamment de tout motif correspondant et affiche leurs IDs. Les résultats sont affichés dans leur ordre d'occurrence dans les respective FICHIER-JOURNALs. Pipez la sortie vers sort pour obtenir des IDs triés par ordre alphabétique.

Augmentez avec les options --job-name, --line-number, --log-line-number ou --page-number pour plus d'informations.

--color, --colour QUAND
Colore le contenu du journal spécifique pour les IDs correspondants. L'argument QUAND détermine quand appliquer la couleur : "toujours", "jamais", ou "auto". Le réglage "auto" vérifie si la sortie standard a été redirigée. C'est la valeur par défaut.
-C, --config CLE=VALEUR[:CLE=VALEUR[:...]]
Définit une ou plusieurs paires de CLE de configuration à VALEUR. Voir la section "CONFIGURATION" pour une description de tous les éléments de configuration disponibles. Utilisez l'option --show-config pour afficher la configuration par défaut.
--debug
Active la sortie de débogage sur stderr.
-E, --encoding ENCODAGE
Définit l'ENCODAGE de FICHIER-JOURNAL pour la traduction en UTF-8. La valeur par défaut est non définie.

Utilisez cette option pour vous débarrasser des échappements "<CHIFFRES-HEX>" gênants sur les terminaux UTF-8. Voir l'option --show-encodings pour les encodages connus et Encode::Supported pour un résumé de tous les encodages. Voir également la section "Quelques Encodages Courants".

Appliquez iconv https://pubs.opengroup.org/onlinepubs/9699919799/utilities/iconv.html (POSIX) ou recode https://github.com/rrthomas/recode/ (GNU) sur FICHIER-JOURNAL avant cet outil pour éviter d'avoir à utiliser l'option --encoding.

-h, --help
Affiche une aide brève puis quitte.
-i, --[no-]id
Affiche le nom d'ID réel qui correspond à REGEXP. Contrôle l'apparence de l'ID correspondant avec l'élément de configuration "id-heading".
-y, --[no-]ignore-case
Correspond aux IDs en ignorant les distinctions de casse dans les motifs et les données.
-j, --[no-]job-name
Affiche le "\jobname" que latex a associé au fichier d'entrée.
-n, --[no-]line-number
Affiche le numéro de ligne où l'environnement "typoginspect" a été rencontré dans le fichier source LaTeX.
-N, --[no-]log-line-number
Affiche le numéro de ligne du fichier journal où la ligne actuelle a été rencontrée.
-p, --[no-]page-number
Affiche le numéro de page où le contenu de l'environnement "typoginspect" commence dans le document mis en page.
-P, --[no-]pager
Redirige la sortie de stdout vers le pagineur configuré.
--show-config
Affiche la configuration par défaut et quitte.
--show-encodings
Affiche tous les encodages connus et quitte.
-V, --version
Affiche les informations de version et quitte.
-w, --[no-]word-regexp
Correspond uniquement aux mots entiers.

Choisissez entre l'impression des IDs correspondants avec l'option --id : En ligne (0) ou en-tête avant les données correspondantes (1). Défaut : 0.
"id-heading-format"=FORMAT
Contrôle le FORMAT pour l'impression des IDs correspondants en mode en-tête, où FORMAT est passé à la fonction "printf" de Perl. Défaut : "--> %s <--".
"id-indent"=INDENT
Indentation des balises typog-inspect imbriquées. Utilisé uniquement en mode « découverte » (première forme), c'est-à-dire si --all est actif. Défaut : 8.
"id-max-length"=MAXIMUM-LENGTH
Définit la longueur maximale d'un ID correspondant pour l'impression. Si un ID correspondant dépasse cette longueur, il sera tronqué et les trois derniers caractères (en deçà de MAXIMUM-LENGTH) seront remplacés par des points. Défaut : 40.
"line-number-format"=FORMAT
Contrôle le FORMAT pour l'impression des numéros de ligne source TeX, où FORMAT est passé à la fonction "printf" de Perl. Défaut : %5d.
"log-line-number-format"=FORMAT
Contrôle le FORMAT pour l'impression des numéros de ligne de journal, où FORMAT est passé à la fonction "printf" de Perl. Défaut : %6d.
"page-number-format"=FORMAT
Contrôle le FORMAT pour l'impression des numéros de page, où FORMAT est passé à la fonction "printf" de Perl. Défaut : "[%3d]".
"pager"=PAGER
Nom de l'application de pagination vers laquelle rediriger la sortie si exécuté avec l'option --pager. Défaut : "less".
"pager-flags"=FLAGS
Transmet FLAGS à PAGER. Défaut : "--quit-if-one-screen".

STATUT DE SORTIE

Le statut de sortie est 0 si au moins un ID correspond à REGEXP, 1 si aucun ID ne correspond à REGEXP, et 2 si une erreur s'est produite.

MISE EN GARDE

La balise de fin "</typog-inspect>" est parfois placée trop tôt dans la sortie et la trace semble tronquée. Cependant, LaTeX enregistre de manière fiable les informations de trace demandées, mais les opérations d'écriture pour les données de trace et le code utilisé pour imprimer la balise de fin ne sont pas synchronisés.
