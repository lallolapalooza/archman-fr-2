FBB::TypeTrait(3bobcat) Traits de type FBB::TypeTrait(3bobcat)

NOM

FBB::TypeTrait - Classe de traits de type

SYNTAXE

#include <bobcat/typetrait>

DESCRIPTION

FBB::TypeTrait est une classe de traits. Elle ne définit aucun membre de fonction ni membre de données, mais uniquement des types. Elle peut être utilisée pour déterminer le type de base et d'autres caractéristiques des types (const) simples, (const) pointeur ou (const) référence. Elle a été conçue d'après la classe de modèle TypeTraits d'Alexandrescu (2001).

Le modèle de classe FBB::LpromotesR est utilisé pour déterminer, à la compilation, si son second type de modèle (de droite) peut être promu à son premier type de modèle (de gauche).

Le modèle de classe FBB::Use attend deux noms de type LHS et RHS et définit typename Use<LHS, RHS>::type comme LHS si RHS peut être promu à LHS ou il définit typename Use<LHS, RHS>::type comme RHS.

ESPACE DE NOMMAGE

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de nommage FBB.

HERITE DE

-

TypeTrait<TYPE>

TYPE est le paramètre de type modèle dont les caractéristiques doivent être déterminées.

TypeTrait<TYPE> définit le type Plain : le type simple (le type sans indication de const, pointeur, référence) de tout type de référence simple, pointeur, lvalue ou rvalue, qu'il soit const ou non.

TypeTrait<TYPE> définit les valeurs bool suivantes :

o
isClass : true si l'argument de type modèle représente un type de classe (struct), false sinon.
o
isConst : true si l'argument de type modèle représente un type const, false sinon.
o
isPointer : true si l'argument de type modèle représente un type pointeur, false sinon.
o
isR_Ref : true si l'argument de type modèle représente une référence rvalue, false sinon.
o
isRef : true si l'argument de type modèle représente une référence lvalue, false sinon.

LpromotesR<LeftType, RightType>

LpromotesR<LeftType, RightType> définit la constante d'énumération yes à 1 si un argument de type RightType peut être promu à une valeur ou un objet de type LeftType. La valeur d'énumération yes est définie à 0 si aucun constructeur de ce type n'est disponible ou si un tel constructeur est défini avec le mot-clé explicit.

EXEMPLES

Voici un exemple utilisant LpromotesR :

    int main()
    {
        cout << "string promote char const *: " <<
                LpromotesR<string, char const *>::yes << ’\n’;  // 1
        cout << "string promote string " <<
                LpromotesR<string, string>::yes << ’\n’;        // 1
        cout << "char const * promote string " <<
                LpromotesR<char const *, string>::yes << ’\n’;  // 0
    }
