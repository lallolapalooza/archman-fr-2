Documentation des définitions de macro

#define BROTLI_BOOL int

Un remplacement portable pour « bool ». BROTLI_BOOL est un type de « documentation » : en réalité, c'est un int, mais dans l'API, il désigne un type dont les seules valeurs sont BROTLI_TRUE et BROTLI_FALSE.

Les valeurs de BROTLI_BOOL passées à Brotli doivent être soit BROTLI_TRUE, soit BROTLI_FALSE, soit le résultat des macros TO_BROTLI_BOOL.

Les valeurs de BROTLI_BOOL renvoyées par Brotli ne doivent pas être testées pour l'égalité avec « true », « false », BROTLI_TRUE, BROTLI_FALSE, mais doivent plutôt être évaluées, par exemple :

if (SomeBrotliFunction(encoder, BROTLI_TRUE) &&
    !OtherBrotliFunction(decoder, BROTLI_FALSE)) {
  bool x = !!YetAnotherBrotliFunction(encoder, TO_BROLTI_BOOL(2 * 2 == 4));
  DoSomething(x);
}

typedef void*(* brotli_alloc_func) (void *opaque, size_t size)

Type de pointeur de fonction d'allocation.

Paramètres :

opaque handle du gestionnaire de mémoire personnalisé fourni par le client
size taille de mémoire demandée ; ne peut pas être 0

Retourne :

0 en cas d'échec

un pointeur valide vers une région mémoire d'au moins size octets sinon

Type de pointeur de fonction de désallocation. Cette fonction ne DOIT rien faire si « address » est 0.

Paramètres :

opaque handle du gestionnaire de mémoire personnalisé fourni par le client
address pointeur de la région mémoire renvoyé par brotli_alloc_func, ou 0
