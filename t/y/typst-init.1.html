NOM

typst-init - Initialise un nouveau projet à partir d'un modèle

SYNOPIS

typst-init [--package-path] [--package-cache-path] [-h|--help] <MODELE> [DIR]

DESCRIPTION

Initialise un nouveau projet à partir d'un modèle.

OPTIONS

--package-path=DIR
Chemin personnalisé vers les paquets locaux, par défaut l'emplacement dépendant du système.
Peut également être spécifié avec la variable d'environnement TYPST_PACKAGE_PATH.
--package-cache-path=DIR
Chemin personnalisé vers le cache des paquets, par défaut l'emplacement dépendant du système.
Peut également être spécifié avec la variable d'environnement TYPST_PACKAGE_CACHE_PATH.
-h, --help
Affiche l'aide (voir un résumé avec '-h').
<MODELE>
Le modèle à utiliser, par exemple `@preview/charged-ieee`.

Vous pouvez spécifier la version en ajoutant par exemple `:0.1.0`. Si aucune version n'est spécifiée, Typst utilisera par défaut la dernière version.

Prend en charge les modèles locaux et publiés.

[DIR]
Le répertoire du projet, par défaut le nom du modèle.
