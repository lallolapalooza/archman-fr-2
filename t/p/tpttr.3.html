sous-routine ctpttr (character uplo, integer n, complex, dimension( * ) ap, complex, dimension( lda, * ) a, integer lda, integer info)

CTPTTR copie une matrice triangulaire du format compact standard (TP) vers le format complet standard (TR).

Objectif :

!>
!> CTPTTR copie une matrice triangulaire A du format compact standard (TP)
!> vers le format complet standard (TR).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : A est triangulaire supérieure.
!>          = 'L' : A est triangulaire inférieure.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

AP

!>          AP est un tableau de type COMPLEX, de dimension ( N*(N+1)/2 ),
!>          En entrée, la matrice triangulaire A, compactée
!>          par colonnes dans un tableau linéaire. La j-ème colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>

A

!>          A est un tableau de type COMPLEX, de dimension ( LDA, N )
!>          En sortie, la matrice triangulaire A. Si UPLO = 'U', la partie
!>          supérieure N-par-N de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement inférieure
!>          de A n'est pas référencée. Si UPLO = 'L', la partie
!>          inférieure N-par-N de A contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement supérieure
!>          de A n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

NAME

ztpttr - Copies a triangular matrix from the standard packed format (TP) to the standard full format (TR).

SYNOPSIS

Subroutines

subroutine ztpttr(uplo, n, ap, a, lda, info)
character uplo
integer n
complex*16 ap(*)
complex*16 a(lda, *)
integer lda, info

Detailed Description

Purpose:

!>
!> ZTPTTR copies a triangular matrix A from standard packed format (TP)
!> to standard full format (TR).
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  A is upper triangular.
!>          = 'L':  A is lower triangular.
!>

N

!>          N is INTEGER
!>          The order of the matrix A. N >= 0.
!>

AP

!>          AP is COMPLEX*16 array, dimension ( N*(N+1)/2 ),
!>          On entry, the upper or lower triangular matrix A, packed
!>          columnwise in a linear array. The j-th column of A is stored
!>          in the array AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
!>

A

!>          A is COMPLEX*16 array, dimension ( LDA, N )
!>          On exit, the triangular matrix A.  If UPLO = 'U', the leading
!>          N-by-N upper triangular part of A contains the upper
!>          triangular part of the matrix A, and the strictly lower
!>          triangular part of A is not referenced.  If UPLO = 'L', the
!>          leading N-by-N lower triangular part of A contains the lower
!>          triangular part of the matrix A, and the strictly upper
!>          triangular part of A is not referenced.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
