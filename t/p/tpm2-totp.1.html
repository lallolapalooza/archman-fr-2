tpm2-totp(1) Manuel des commandes générales tpm2-totp(1)

NOM

tpm2-totp(1) – génère ou calcule des TOTP basés sur TPM

SYNOPIS

tpm2-totp [options]

DESCRIPTION

tpm2-totp crée une clé à l'intérieur d'un TPM 2.0 qui peut être utilisée pour générer des mots de passe à usage unique basés sur le temps (TOTP) afin de démontrer à l'utilisateur qu'une plateforme n'a pas été altérée en son absence et qu'elle reste donc digne de confiance.

ARGUMENTS

La commande tpm2-totp attend l'une des cinq commandes et propose un ensemble d'options.

COMMANDES

•
générer : Génère un nouveau secret TOTP. Options possibles : -b, -l, -N, -p, -P, -T
•
calculer : Calcule une valeur TOTP. Options possibles : -N, -t, -T
•
sceller : Scelle le secret TOTP à de nouveaux PCR, banques ou valeurs. Options possibles : -b, -N, -p, -P (obligatoire), -T
•
récupérer : Récupère le secret TOTP et l'affiche à nouveau. Options possibles : -N, -P (obligatoire), -T
•
nettoyer : Supprime l'index NV consommé. Options possibles : -N, -T

OPTIONS

•
-b <banque>[,<banque>[, ...]], --banques <banque>[,<banque>[, ...]]: Banques PCR sélectionnées (par défaut : SHA1,SHA256)
•
-h, --aide : Affiche l'aide
•
-l, --libellé : Libellé à utiliser pour l'affichage dans l'application d'authentification TOTP (par défaut : TPM2-TOTP)
•
-N <indexnv>, --indexnv <indexnv> : Index NV du TPM pour stocker les données (par défaut : 0x018094AF)
•
-p <pcr>[,<pcr>[, ...]], --pcrs <pcr>[,<pcr>[, ...]]: Registres PCR sélectionnés (par défaut : 0,2,4,6)
•
-P <motdepasse>, --motdepasse <motdepasse> : Mot de passe pour le secret (par défaut : aucun) (commandes : générer, récupérer, sceller)
•
-t, --temps : Affiche la date/heure du calcul du TOTP (commandes : calculer)
•
-T <nom-tcti>[:<config-tcti>], --tcti <nom-tcti>[:<config-tcti>] : Sélectionne le TCTI à utiliser. nom-tcti est le nom de la bibliothèque TCTI. Si présent, la chaîne de configuration config-tcti est passée telle quelle à la bibliothèque TCTI choisie.

Le TCTI peut également être spécifié à l'aide de la variable d'environnement TPM2TOTP_TCTI. Si l'option de ligne de commande et la variable d'environnement sont présentes, l'option de ligne de commande est utilisée.

Si aucun TCTI n'est spécifié, le TCTI par défaut configuré sur le système est utilisé.

•
-v, --verbeux : Affiche des messages détaillés

EXEMPLES

Configuration

Le secret TOTP peut être généré avec ou sans mot de passe. Il est recommandé de définir un mot de passe afin de permettre les options de récupération. De plus, les PCR et les banques PCR peuvent être sélectionnées avec -p et -b. Les valeurs par défaut sont les PCR 0,2,4 et les banques SHA1, SHA256.

tpm2-totp générer
tpm2-totp -P trèssecret générer
tpm2-totp -P trèssecret -p 0,1,2,3,4,5,6 générer
tpm2-totp -p 0,1,2,3,4,5,6 -b SHA1,SHA256 générer

Démarrage

Lors du démarrage, la valeur TOTP pour l'heure actuelle, ainsi que l'heure actuelle, devraient être affichées à l'utilisateur, par exemple en utilisant plymouth depuis mkinitrd ou depuis dracut. La commande à exécuter est :

tpm2-totp calculer
tpm2-totp -t calculer

Récupération

Pour récupérer le code QR :

tpm2-totp -P trèssecret récupérer

Pour sceller à nouveau le secret :

tpm2-totp -P trèssecret sceller
tpm2-totp -P trèssecret -p 1,3,5,6 sceller

Suppression

Pour supprimer l'index NV créé :

tpm2-totp nettoyer

Index NV

Toutes les commandes acceptent en outre l'option -N pour spécifier l'index NV à utiliser. Par défaut, 0x018094AF est utilisé et recommandé.

tpm2-totp -N 0x01800001 -P trèssecret générer
tpm2-totp -N 0x01800001 calculer
tpm2-totp -N 0x01800001 -P trèssecret récupérer
tpm2-totp -N 0x01800001 -P trèssecret sceller

Configuration TCTI

Toutes les commandes acceptent l'option -T ou la variable d'environnement TPM2TOTP_TCTI pour spécifier le TCTI à utiliser. Si le TCTI n'est pas spécifié explicitement, le TCTI par défaut configuré sur le système est utilisé. Pour utiliser, par exemple, le simulateur TPM lié à un port donné, utilisez

tpm2-totp -T mssim:port=2321 générer

RETOUR

0 en cas de succès ou 1 en cas d'échec.
