CTPMLQT

Objectif :

!>
!> CTPMLQT applique une matrice unitaire complexe Q obtenue à partir d'un
!>  réflecteur de bloc complexe H à une matrice complexe générale
!> C, qui consiste en deux blocs A et B.
!>

Paramètres

SIDE 
!>          SIDE est de type CHARACTER*1
!>          = 'L': applique Q ou Q**H à Gauche ;
!>          = 'R': applique Q ou Q**H à Droite.
!>

TRANS

!>          TRANS est de type CHARACTER*1
!>          = 'N': Pas de transposée, applique Q ;
!>          = 'C': Transposée conjuguée, applique Q**H.
!>

M

!>          M est un entier (INTEGER)
!>          Le nombre de lignes de la matrice B. M >= 0.
!>

N

!>          N est un entier (INTEGER)
!>          Le nombre de colonnes de la matrice B. N >= 0.
!>

K

!>          K est un entier (INTEGER)
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>

L

!>          L est un entier (INTEGER)
!>          L'ordre de la partie trapézoïdale de V.
!>          K >= L >= 0. Voir Détails supplémentaires.
!>

MB

!>          MB est un entier (INTEGER)
!>          La taille du bloc utilisée pour le stockage de T. K >= MB >= 1.
!>          Doit être la même valeur de MB que celle utilisée pour générer T
!>          dans CTPLQT.
!>

V

!>          V est un tableau de type COMPLEX, de dimension (LDV,K)
!>          La i-ème ligne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          CTPLQT dans B. Voir Détails supplémentaires.
!>

LDV

!>          LDV est un entier (INTEGER)
!>          La dimension principale du tableau V. LDV >= K.
!>

T

!>          T est un tableau de type COMPLEX, de dimension (LDT,K)
!>          Les facteurs triangulaires supérieurs des réflecteurs de bloc
!>          tels que retournés par CTPLQT, stockés sous forme de matrice MBxK.
!>

LDT

!>          LDT est un entier (INTEGER)
!>          La dimension principale du tableau T. LDT >= MB.
!>

A

!>          A est un tableau de type COMPLEX, de dimension
!>          (LDA,N) si SIDE = 'L' ou
!>          (LDA,K) si SIDE = 'R'
!>          À l'entrée, la matrice A de taille KxN ou MxK.
!>          À la sortie, A est écrasé par le bloc correspondant de
!>          Q*C ou Q**H*C ou C*Q ou C*Q**H. Voir Détails supplémentaires.
!>

LDA

!>          LDA est un entier (INTEGER)
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDA >= max(1,K) ;
!>          Si SIDE = 'R', LDA >= max(1,M).
!>

B

!>          B est un tableau de type COMPLEX, de dimension (LDB,N)
!>          À l'entrée, la matrice B de taille MxN.
!>          À la sortie, B est écrasé par le bloc correspondant de
!>          Q*C ou Q**H*C ou C*Q ou C*Q**H. Voir Détails supplémentaires.
!>

LDB

!>          LDB est un entier (INTEGER)
!>          La dimension principale du tableau B.
!>          LDB >= max(1,M).
!>

WORK

!>          WORK est un tableau de type COMPLEX. La dimension de WORK est
!>           N*MB si SIDE = 'L', ou M*MB si SIDE = 'R'.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!>  Les colonnes de la matrice pentagonale V contiennent les réflecteurs
!>  élémentaires H(1), H(2), ..., H(K) ; V est composé d'un bloc rectangulaire V1 et d'un
!>  bloc trapézoïdal V2 :
!>
!>        V = [V1] [V2].
!>
!>
!>  La taille du bloc trapézoïdal V2 est déterminée par le paramètre L,
!>  où 0 <= L <= K ; V2 est trapézoïdale inférieure, composée des L premières
!>  lignes d'une matrice triangulaire supérieure KxK. Si L=K, V2 est triangulaire inférieure ;
!>  si L=0, il n'y a pas de bloc trapézoïdal, donc V = V1 est rectangulaire.
!>
!>  Si SIDE = 'L' : C = [A] où A est KxN, B est MxN et V est KxM.
!>                      [B]
!>
!>  Si SIDE = 'R' : C = [A B] où A est MxK, B est MxN et V est KxN.
!>
!>  La matrice unitaire complexe Q est formée à partir de V et T.
!>
!>  Si TRANS='N' et SIDE='L', C est remplacé à la sortie par Q * C.
!>
!>  Si TRANS='C' et SIDE='L', C est remplacé à la sortie par Q**H * C.
!>
!>  Si TRANS='N' et SIDE='R', C est remplacé à la sortie par C * Q.
!>
!>  Si TRANS='C' et SIDE='R', C est remplacé à la sortie par C * Q**H.
!>

NAME

                        
tpmlqt — applies a triangular matrix Q to a complex
                            matrix.

                    

                    

                        
SYNOPSIS

                        
 SUBROUTINE TPMLQT( SIDE, TRANS, M, N, K, L, MB, V, LDV, T,
         LDT, A, LDA, B, LDB, WORK, INFO )
                        

                        
 CHARACTER * 1 SIDE
 CHARACTER * 1 TRANS
 INTEGER M, N, K, L, MB, LDV, LDT, LDA, LDB, INFO
 COMPLEX*16 V( LDV, K ), T( LDT, K ), A( LDA, * ), B( LDB, * )
 COMPLEX*16 WORK( * ) 

                    

                    

                        
Detailed Description

                        
The routine applies a complex unitary matrix Q which is
                            factorised into a sparse triangular form to a complex
                            matrix C which consists of two blocks A and B.

                    

                    

                        
Function Documentation

!>          = 'R': applique Q ou Q**H depuis la droite.
!>
