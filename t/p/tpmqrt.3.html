CTPMQRT

Objectif :

!>
!> CTPMQRT applique une matrice orthogonale complexe Q obtenue à partir d'un
!>  réflecteur bloc complexe H à une matrice générale
!> complexe C, qui consiste en deux blocs A et B.
!>

Paramètres

SIDE 
!>          SIDE est CARACTÈRE*1
!>          = 'L': applique Q ou Q**H à gauche ;
!>          = 'R': applique Q ou Q**H à droite.
!>

TRANS

!>          TRANS est CARACTÈRE*1
!>          = 'N' : Pas de transposée, applique Q ;
!>          = 'C' : Transposée conjuguée, applique Q**H.
!>

M

!>          M est ENTIER
!>          Le nombre de lignes de la matrice B. M >= 0.
!>

N

!>          N est ENTIER
!>          Le nombre de colonnes de la matrice B. N >= 0.
!>

K

!>          K est ENTIER
!>          Le nombre de réflecteurs élémentaires dont le produit définit
!>          la matrice Q.
!>

L

!>          L est ENTIER
!>          L'ordre de la partie trapézoïdale de V.
!>          K >= L >= 0. Voir Détails supplémentaires.
!>

NB

!>          NB est ENTIER
!>          La taille du bloc utilisée pour le stockage de T. K >= NB >= 1.
!>          Cela doit être la même valeur de NB utilisée pour générer T
!>          dans CTPQRT.
!>

V

!>          V est un tableau COMPLETXE, de dimension (LDV,K)
!>          La i-ème colonne doit contenir le vecteur qui définit le
!>          réflecteur élémentaire H(i), pour i = 1,2,...,k, tel que retourné par
!>          CTPQRT dans B. Voir Détails supplémentaires.
!>

LDV

!>          LDV est ENTIER
!>          La dimension principale du tableau V.
!>          Si SIDE = 'L', LDV >= max(1,M) ;
!>          si SIDE = 'R', LDV >= max(1,N).
!>

T

!>          T est un tableau COMPLETXE, de dimension (LDT,K)
!>          Les facteurs triangulaires supérieurs des réflecteurs blocs
!>          tels que retournés par CTPQRT, stockés sous forme de matrice NB par K.
!>

LDT

!>          LDT est ENTIER
!>          La dimension principale du tableau T. LDT >= NB.
!>

A

!>          A est un tableau COMPLETXE, de dimension
!>          (LDA,N) si SIDE = 'L' ou
!>          (LDA,K) si SIDE = 'R'
!>          À l'entrée, la matrice A de taille K par N ou M par K.
!>          À la sortie, A est écrasé par le bloc correspondant de
!>          Q*C ou Q**H*C ou C*Q ou C*Q**H. Voir Détails supplémentaires.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.
!>          Si SIDE = 'L', LDC >= max(1,K) ;
!>          Si SIDE = 'R', LDC >= max(1,M).
!>

B

!>          B est un tableau COMPLETXE, de dimension (LDB,N)
!>          À l'entrée, la matrice M par N B.
!>          À la sortie, B est écrasé par le bloc correspondant de
!>          Q*C ou Q**H*C ou C*Q ou C*Q**H. Voir Détails supplémentaires.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.
!>          LDB >= max(1,M).
!>

WORK

!>          WORK est un tableau COMPLETXE. La dimension de WORK est
!>           N*NB si SIDE = 'L', ou M*NB si SIDE = 'R'.
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Détails supplémentaires :

!>
!> Les colonnes de la matrice pentagonale V contiennent les réflecteurs
!> élémentaires H(1), H(2), ..., H(K) ; V est composé d'un bloc rectangulaire V1 et d'un
!> bloc trapézoïdal V2 :
!>
!>        V = [V1]
!>            [V2].
!>
!> La taille du bloc trapézoïdal V2 est déterminée par le paramètre L,
!> où 0 <= L <= K ; V2 est trapézoïdal supérieur, composé des L premières
!> lignes d'une matrice triangulaire supérieure K par K. Si L=K, V2 est triangulaire supérieure ;
!> si L=0, il n'y a pas de bloc trapézoïdal, donc V = V1 est rectangulaire.
!>
!> Si SIDE = 'L' : C = [A]  où A est K par N,  B est M par N et V est M par K.
!>                      [B]
!>
!> Si SIDE = 'R' : C = [A B]  où A est M par K, B est M par N et V est N par K.
!>
!> La matrice orthogonale complexe Q est formée à partir de V et T.
!>
!> Si TRANS='N' et SIDE='L', C est remplacé à la sortie par Q * C.
!>
!> Si TRANS='C' et SIDE='L', C est remplacé à la sortie par Q**H * C.
!>
!> Si TRANS='N' et SIDE='R', C est remplacé à la sortie par C * Q.
!>
!> Si TRANS='C' et SIDE='R', C est remplacé à la sortie par C * Q**H.
!>
