sous-routine ctptri (caractère uplo, caractère diag, entier n, complexe, dimension( * ) ap, entier info)

CTPTRI

Objectif :

!>
!> CTPTRI calcule l'inverse d'une matrice triangulaire supérieure ou inférieure complexe
!> stockée au format compacté.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' :  A est triangulaire supérieure ;
!>          = 'L' :  A est triangulaire inférieure.
!>

DIAG

!>          DIAG est CHARACTER*1
!>          = 'N' :  A est triangulaire non unitaire ;
!>          = 'U' :  A est triangulaire unitaire.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau de type COMPLEX, de dimension (N*(N+1)/2)
!>          En entrée, la matrice triangulaire supérieure ou inférieure A, stockée
!>          colonne par colonne dans un tableau linéaire. La j-ème colonne de A est stockée
!>          dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*((2*n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.
!>          En sortie, l'inverse (triangulaire) de la matrice originale, dans
!>          le même format de stockage compacté.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 :  si INFO = i, A(i,i) est exactement zéro. La matrice triangulaire
!>                est singulière et son inverse ne peut être calculé.
!>

Auteur

Univ. du Tennessee

Univ. de Californie Berkeley

Univ. du Colorado Denver

NAG Ltd.

Détails supplémentaires :

!>
!>  Une matrice triangulaire A peut être transférée en stockage compacté à l'aide de l'un
!>  des segments de programme suivants :
!>
!>  UPLO = 'U' :                      UPLO = 'L' :
!>
!>        JC = 1                           JC = 1
!>        DO 2 J = 1, N                    DO 2 J = 1, N
!>           DO 1 I = 1, J                    DO 1 I = J, N
!>              AP(JC+I-1) = A(I,J)              AP(JC+I-J) = A(I,J)
!>      1    CONTINUE                    1    CONTINUE
!>           JC = JC + J                      JC = JC + N - J + 1
!>      2 CONTINUE                       2 CONTINUE
!>

Detailed Description

This routine is part of the LAPACK library.

TPTRI computes the inverse of a real or complex upper or lower triangular matrix stored in packed format.

subroutine stptri (character uplo, character diag, integer n, real ap, dimension( * ) ap, integer info)

STC TRI

Purpose:

!> STPTRI computes the inverse of a real upper or lower triangular
!> matrix A stored in packed format.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  A is upper triangular;
!>          = 'L':  A is lower triangular.
!>

DIAG

!>          DIAG is CHARACTER*1
!>          = 'N':  A is non-unit triangular;
!>          = 'U':  A is unit triangular.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

AP

!>          AP is REAL array, dimension (N*(N+1)/2)
!>          On entry, the upper or lower triangular matrix A, stored
!>          columnwise in a linear array.  The j-th column of A is stored
!>          in the array AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*((2*n-j)/2) = A(i,j) for j<=i<=n.
!>          See below for further details.
!>          On exit, the (triangular) inverse of the original matrix, in
!>          the same packed storage format.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, A(i,i) is exactly zero.  The triangular
!>                matrix is singular and its inverse can not be computed.
!>

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Further Details:

!>
!>  A triangular matrix A can be transferred to packed storage using one
!>  of the following program segments:
!>
!>  UPLO = 'U':                      UPLO = 'L':
!>
!>        JC = 1                           JC = 1
!>        DO 2 J = 1, N                    DO 2 J = 1, N
!>           DO 1 I = 1, J                    DO 1 I = J, N
!>              AP(JC+I-1) = A(I,J)              AP(JC+I-J) = A(I,J)
!>      1    CONTINUE                    1    CONTINUE
!>           JC = JC + J                      JC = JC + N - J + 1
!>      2 CONTINUE                       2 CONTINUE
!>
