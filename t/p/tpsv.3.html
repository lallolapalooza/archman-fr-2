sous-programme ctpsv (character uplo, character trans, character diag, integer n, complex, dimension(*) ap, complex, dimension(*) x, integer incx)

CTPSV

But :

!>
!> CTPSV  résout l'un des systèmes d'équations
!>
!>    A*x = b,   ou   A**T*x = b,   ou   A**H*x = b,
!>
!> où b et x sont des vecteurs de n éléments et A est une matrice triangulaire
!> supérieure ou inférieure de taille n par n, unitaire ou non, fournie sous forme
!> compactée.
!>
!> Aucun test de singularité ou de quasi-singularité n'est inclus dans cette
!> routine. De tels tests doivent être effectués avant d'appeler cette routine.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>           À l'entrée, UPLO spécifie si la matrice est une matrice triangulaire
!>           supérieure ou inférieure comme suit :
!>
!>              UPLO = 'U' ou 'u'   A est une matrice triangulaire supérieure.
!>
!>              UPLO = 'L' ou 'l'   A est une matrice triangulaire inférieure.
!>

TRANS

!>          TRANS est CHARACTER*1
!>           À l'entrée, TRANS spécifie les équations à résoudre comme suit :
!>
!>              TRANS = 'N' ou 'n'   A*x = b.
!>
!>              TRANS = 'T' ou 't'   A**T*x = b.
!>
!>              TRANS = 'C' ou 'c'   A**H*x = b.
!>

DIAG

!>          DIAG est CHARACTER*1
!>           À l'entrée, DIAG spécifie si A est unitaire ou non
!>           triangulaire comme suit :
!>
!>              DIAG = 'U' ou 'u'   A est supposée unitaire triangulaire.
!>
!>              DIAG = 'N' ou 'n'   A n'est pas supposée unitaire
!>                                  triangulaire.
!>

N

!>          N est INTEGER
!>           À l'entrée, N spécifie l'ordre de la matrice A.
!>           N doit être supérieur ou égal à zéro.
!>

AP

!>          AP est un tableau COMPLEX, de dimension au moins
!>           ( ( n*( n + 1 ) )/2 ).
!>           Avant l'entrée avec UPLO = 'U' ou 'u', le tableau AP doit
!>           contenir la matrice triangulaire supérieure compactée séquentiellement,
!>           colonne par colonne, de sorte que AP( 1 ) contienne a( 1, 1 ),
!>           AP( 2 ) et AP( 3 ) contiennent a( 1, 2 ) et a( 2, 2 )
!>           respectivement, et ainsi de suite.
!>           Avant l'entrée avec UPLO = 'L' ou 'l', le tableau AP doit
!>           contenir la matrice triangulaire inférieure compactée séquentiellement,
!>           colonne par colonne, de sorte que AP( 1 ) contienne a( 1, 1 ),
!>           AP( 2 ) et AP( 3 ) contiennent a( 2, 1 ) et a( 3, 1 )
!>           respectivement, et ainsi de suite.
!>           Notez que lorsque DIAG = 'U' ou 'u', les éléments diagonaux de
!>           A ne sont pas référencés, mais sont supposés être l'unité.
!>

X

!>          X est un tableau COMPLEX, de dimension au moins
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Avant l'entrée, le tableau incrémenté X doit contenir le vecteur
!>           colonne de n éléments b. À la sortie, X est écrasé
!>           par le vecteur solution x.
!>

INCX

!>          INCX est INTEGER
!>           À l'entrée, INCX spécifie l'incrément des éléments de
!>           X. INCX ne doit pas être nul.
!>
