tpm2_certifyX509certutil(1) Manuel des commandes générales tpm2_certifyX509certutil(1)

NOM

tpm2_certifyX509certutil(1) - Générer un certificat X509 partiel.

SYNTAXE

tpm2_certifyX509certutil [OPTIONS]

DESCRIPTION

tpm2_certifyX509certutil(1) - Génère un certificat partiel qui convient comme troisième paramètre d'entrée pour la commande TPM2_certifyX509. Les données du certificat sont écrites dans un fichier au format DER et peuvent être examinées à l'aide de l'outil openssl asn1parse comme suit :

openssl asn1parse -in partial_cert.der -inform DER

OPTIONS

Voici les options disponibles :

•
-o, --outcert=CHAÎNE : Le fichier de sortie où le certificat sera écrit. La valeur par défaut est partial_cert.der. Paramètre facultatif.
•
-d, --days=NOMBRE : Le nombre de jours pendant lesquels le certificat sera valide à partir d'aujourd'hui. La valeur par défaut est 3560 (10 ans). Paramètre facultatif.
•
-i, --issuer=CHAÎNE : L'entrée ISSUER pour le certificat dans le format suivant : --issuer="C=US;O=org;OU=Org unit;CN=cname". Les champs pris en charge sont :
•
C - "Country", taille max = 2
•
O - "Org", taille max = 8
•
OU - "Org Unit", taille max = 8
•
CN - "Common Name", taille max = 8. Les champs doivent être séparés par un point-virgule. Au moins un champ pris en charge est requis pour que l'option soit valide. Paramètre facultatif.
•
-s, --subject=CHAÎNE : Le SUJET du certificat dans le format suivant : --subject="C=US;O=org;OU=Org unit;CN=cname". Les champs pris en charge sont :
•
C - "Country", taille max = 2
•
O - "Org", taille max = 8
•
OU - "Org Unit", taille max = 8
•
CN - "Common Name", taille max = 8. Les champs doivent être séparés par un point-virgule. Au moins un champ pris en charge est requis pour que l'option soit valide. Paramètre facultatif.
•
ARGUMENT Aucune argument requis.

Références

OPTIONS COMMUNES

Cette collection d'options est commune à de nombreux programmes et fournit des informations que de nombreux utilisateurs peuvent attendre.

•
-h, --help=[man|no-man] : Affiche la page de manuel de l'outil. Par défaut, il tente d'appeler le programme de pagination de manuel pour l'outil, mais en cas d'échec, il affiche un bref résumé de l'outil. C'est le même comportement si l'argument d'option « man » est spécifié, mais si « man » est explicitement demandé, l'outil fournira des erreurs de man sur stderr. Si l'option « no-man » est spécifiée ou si le programme de pagination de manuel échoue, les options courtes seront affichées sur stdout.

Pour utiliser correctement les fonctionnalités des pages de manuel, celles-ci doivent être installées ou se trouver dans MANPATH. Voir man(1) pour plus de détails.

•
-v, --version : Affiche les informations de version pour cet outil, les tctis pris en charge et quitte.
•
-V, --verbose : Augmente les informations que l'outil imprime sur la console pendant son exécution. Lors de l'utilisation de cette option, le fichier et le numéro de ligne sont affichés.
•
-Q, --quiet : Supprime la sortie normale de l'outil sur stdout.
•
-Z, --enable-errata : Active l'application des corrections d'errata. Utile si une correction d'errata doit être appliquée aux commandes envoyées au TPM. La définition de la variable d'environnement TPM2TOOLS_ENABLE_ERRATA est équivalente.
•
-R, --autoflush : Active le vidage automatique des objets transitoires créés par la commande. Si un objet parent est chargé à partir d'un fichier de contexte, l'objet parent transitoire sera également vidé. Le vidage automatique peut également être activé si la variable d'environnement TPM2TOOLS_AUTOFLUSH est définie sur yes ou true. informations que de nombreux utilisateurs peuvent attendre.

EXEMPLES

tpm2 certifyX509certutil -o partial_cert.der -d 356

Retour

Les outils peuvent retourner l'un des codes suivants :

•
0 - Succès.
•
1 - Erreur générale non spécifique.
•
2 - Erreur de gestion des options.
•
3 - Erreur d'authentification.
•
4 - Erreur liée au TCTI.
•
5 - Schéma non pris en charge. Applicable à tpm2_testparams.
