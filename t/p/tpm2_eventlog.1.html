NOM

tpm2_eventlog(1) - Affiche le journal d'événements tpm2.

SYNTAXE

tpm2_eventlog [ARGUMENT]

DESCRIPTION

tpm2_eventlog(1) - Analyse un journal d'événements TPM2 binaire. Le journal d'événements peut être passé à l'outil en tant que paramètre positionnel final. Si ce paramètre est omis, l'outil renverra une erreur. Le format de ce journal est documenté dans la « TCG PC Client Platform Firmware Profile Specification ».

OPTIONS

•
--eventlog-version=NOMBRE_NATUREL:

Spécifie la version YAML du journal d'événements analysé. Les versions 1 et 2 sont actuellement prises en charge. La valeur par défaut est 1.

•
ARGUMENT L'argument de la ligne de commande est le chemin d'accès à un journal d'événements TPM2 binaire.

Références

OPTIONS COMMUNES

Cette collection d'options est commune à de nombreux programmes et fournit des informations que de nombreux utilisateurs peuvent attendre.

•
-h, --help=[man|no-man] : Affiche le manuel de l'outil. Par défaut, il tente d'appeler le pagemaker du manuel pour l'outil, cependant, en cas d'échec, il affichera un bref résumé de l'outil. C'est le même comportement si l'argument d'option « man » est spécifié, cependant si « man » est explicitement demandé, l'outil fournira les erreurs de man sur la sortie standard. Si l'option « no-man » est spécifiée, ou si le pagemaker échoue, les options courtes seront affichées sur la sortie standard.

Pour utiliser correctement la fonctionnalité des pages de manuel, celles-ci doivent être installées ou présentes dans MANPATH. Voir man(1) pour plus de détails.

•
-v, --version : Affiche les informations de version pour cet outil, les TCTI pris en charge et quitte.
•
-V, --verbose : Augmente les informations que l'outil imprime sur la console pendant son exécution. Lorsque cette option est utilisée, le fichier et le numéro de ligne sont imprimés.
•
-Q, --quiet : Supprime la sortie normale de l'outil vers la sortie standard.
•
-Z, --enable-errata : Active l'application des corrections d'errata. Utile si une correction d'errata doit être appliquée aux commandes envoyées au TPM. La définition de l'environnement TPM2TOOLS_ENABLE_ERRATA est équivalente.
•
-R, --autoflush : Active le vidage automatique des objets transitoires créés par la commande. Si un objet parent est chargé à partir d'un fichier de contexte, l'objet parent transitoire sera également vidé. Le vidage automatique peut également être activé si la variable d'environnement TPM2TOOLS_AUTOFLUSH est définie sur yes ou true. informations que de nombreux utilisateurs peuvent attendre.

EXEMPLES

# affiche le journal d'événements à partir d'un fichier fourni
tpm2_eventlog eventlog.bin

Retour

Les outils peuvent retourner l'un des codes suivants :

•
0 - Succès.
•
1 - Erreur générale non spécifique.
•
2 - Erreur de gestion des options.
•
3 - Erreur d'authentification.
•
4 - Erreur liée au TCTI.
•
5 - Schéma non supporté. Applicable à tpm2_testparams.
