NOM

tpm2-abrmd - Démon d'accès et de gestion des ressources TPM2

SYNTAXE

tpm2-abrmd [-m][-e][-i][-o][-l nom-du-journaliseur][-r][-s][-g /dev/urandom][-t conf]

DESCRIPTION

tpm2-abrmd est un démon qui implémente le courtier d'accès et le gestionnaire de ressources TPM tel que décrit par le Trusted Computing Group (TGC) dans la "TSS System Level API and TPM Command Transmission Interface Specification". Ce démon utilise le bus système DBus et des pipes pour communiquer avec les clients.

OPTIONS

-t, --tcti
Fournit au démon une chaîne qui décrit le TCTI et comment le configurer pour la communication avec le composant suivant dans la pile TSS2. Cette chaîne est formatée comme "nom-tcti:conf-tcti" où :
'nom-tcti'
Le nom du fichier objet partagé de la bibliothèque TCTI. Les bibliothèques sont trouvées en utilisant le même algorithme que dlopen(3). Si le nom du fichier de la bibliothèque TCTI suit la convention de nommage : libtss2-tcti-<nom>.so.0 où <nom> est le nom du TCTI, la valeur de <nom> peut être fournie à la place du nom complet du fichier de la bibliothèque. Voir 'EXEMPLES' ci-dessous.
'conf-tcti'
La chaîne de configuration passée à la bibliothèque TCTI lors de son initialisation.

Si cette option est omise (ou si une chaîne NULL est fournie), un TCTI par défaut est utilisé dans sa configuration par défaut. Si la chaîne ne contient pas de deux-points, elle sera interprétée uniquement comme le 'nom-tcti'. Pour fournir uniquement la chaîne de configuration (en utilisant le TCTI par défaut), le premier caractère de la chaîne passée à cette option doit être un deux-points suivi de la chaîne de configuration. Voir les exemples ci-dessous.

-o, --allow-root
Permet au démon de s'exécuter en tant que root. Si cette option n'est pas fournie, le démon refusera de s'exécuter en tant qu'utilisateur root. L'utilisation de cette option n'est pas recommandée.
-m, --max-connections
Définit une limite supérieure au nombre de connexions clients simultanées autorisées. Une fois ce nombre de connexions clients atteint, les nouvelles connexions seront rejetées avec une erreur. Si l'option n'est pas spécifiée, la valeur par défaut est 27.
-f, --flush-all
Efface tous les objets et sessions lorsque le démon est démarré.
-l, --logger
Dirige la sortie de journalisation vers une cible de journalisation nommée. Les cibles prises en charge sont stdout et syslog. Si l'option de journalisation n'est pas spécifiée, la valeur par défaut est stdout.
-e, --max-sessions
Définit une limite supérieure au nombre de sessions que chaque connexion client est autorisée à créer (chargées ou actives) à un moment donné. Si l'option n'est pas spécifiée, la valeur par défaut est 4.
-r, --max-transients
Définit une limite supérieure au nombre d'objets transitoires que chaque connexion client est autorisée à charger. Une fois ce nombre d'objets atteint, les tentatives de chargement de nouveaux objets transitoires produiront une erreur. Si l'option n'est pas spécifiée, la valeur par défaut est 27.
-n, --dbus-name
Réclame le nom donné sur dbus. Cette option remplace la valeur par défaut de com.intel.tss2.Tabrmd.
-g, --prng-seed-file
Lit la graine pour le générateur de nombres pseudo-aléatoires à partir du fichier fourni.
-s, --session
Connecte le démon au bus de session dbus. Si l'option n'est pas spécifiée, le démon se connecte au bus système.
-v, --version
Affiche la chaîne de version.

EXEMPLES

Exécutez le démon avec le TCTI et les options par défaut :
tpm2-abrmd
Exécutez le démon avec le TCTI par défaut et la chaîne de configuration fournie :
tpm2-abrmd --tcti=":/dev/tpm0"
Ceci est équivalent à :
tpm2-abrmd --tcti="device:/dev/tpm0"
tpm2-abrmd --tcti="libtss2-tcti-device.so.0:/dev/tpm0"
Faites utiliser au démon la bibliothèque TCTI du simulateur TPM2 swtpm
Cela se connecte à un simulateur TPM2 via un swtpm TCP.
tpm2-abrmd --tcti="swtpm"
tpm2-abrmd --tcti="libtss2-tcti-swtpm.so.0"
Faites utiliser au démon la bibliothèque TCTI 'libtss2-tcti-swtpm.so.0' et la chaîne de configuration
tpm2-abrmd --tcti=swtpm:host=127.0.0.1,port=5555"
tpm2-abrmd --tcti="libtss2-tcti-swtpm.so.0:host=127.0.0.1,port=5555"
