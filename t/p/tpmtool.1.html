tpmtool(1) Commandes utilisateur tpmtool(1)

NOM

tpmtool - Outil TPM GnuTLS

SYNTAXE

tpmtool [-options] [-option [valeur]] [--nom-option[[=| ]valeur]]

Tous les arguments doivent être des options.

DESCRIPTION

Programme permettant la gestion des données cryptographiques de la puce TPM.

OPTIONS

-d nombre, --debug=nombre

Active le débogage. Cette option prend un nombre entier comme argument. La valeur de nombre est contrainte à être : 
dans l'intervalle 0 à 9999

Spécifie le niveau de débogage.

--infile=fichier

Fichier d'entrée.
--outfile=str

Fichier de sortie.
--generate-rsa

Génère une paire de clés RSA publique-privée.

Génère une paire de clés RSA publique-privée dans la puce TPM. La clé peut être stockée dans le système de fichiers et protégée par un PIN, ou stockée (enregistrée) dans la mémoire flash de la puce TPM.

--register

Toute clé générée sera enregistrée dans le TPM. Cette option doit apparaître en combinaison avec les options suivantes : generate-rsa.
--signing

Toute clé générée sera une clé de signature. Cette option ne doit pas apparaître en combinaison avec aucune des options suivantes : legacy. Cette option doit apparaître en combinaison avec les options suivantes : generate-rsa.
--legacy

Toute clé générée sera une clé héritée. Cette option ne doit pas apparaître en combinaison avec aucune des options suivantes : signing. Cette option doit apparaître en combinaison avec les options suivantes : generate-rsa.
--user

Toute clé enregistrée sera une clé utilisateur. Cette option ne doit pas apparaître en combinaison avec aucune des options suivantes : system. Cette option doit apparaître en combinaison avec les options suivantes : register.

La clé générée sera stockée dans un stockage persistant spécifique à l'utilisateur.

--system

Toute clé enregistrée sera une clé système. Cette option ne doit pas apparaître en combinaison avec aucune des options suivantes : user. Cette option doit apparaître en combinaison avec les options suivantes : register.

La clé générée sera stockée dans le stockage persistant du système.

--pubkey=url

Affiche la clé publique de la clé fournie.
--list

Liste toutes les clés stockées dans le TPM.
--delete=url

Supprime la clé identifiée par l'URL (UUID) donnée.
--test-sign=url

Teste l'opération de signature de l'objet fourni.

Peut être utilisé pour tester le bon fonctionnement de l'opération de signature. Cette opération signera et vérifiera les données signées.

--sec-param=paramètre de sécurité

Spécifie le niveau de sécurité [low, legacy, medium, high, ultra].

Ceci est une alternative à l'option bits. Notez cependant que les valeurs autorisées par la puce TPM sont quantifiées et les valeurs données peuvent être arrondies à l'entier supérieur.

--bits=nombre

Spécifie le nombre de bits pour la génération de clé. Cette option prend un nombre entier comme argument.
--inder, --no-inder

Utilise le format DER pour les clés. La forme no-inder désactivera l'option.

Les fichiers d'entrée seront supposés être au format DER portable du TPM. Le format par défaut est un format personnalisé utilisé par divers outils TPM.

--outder, --no-outder

Utilise le format DER pour les clés de sortie. La forme no-outder désactivera l'option.

La sortie sera au format DER portable du TPM.

--srk-well-known

SRK a un mot de passe bien connu (20 octets de zéros).
-v arg, --version=arg

Affiche la version du programme et quitte. Le mode par défaut est `v', une version simple. Le mode `c' affichera les informations de copyright et `n' affichera l'avis de copyright complet.
-h, --help

Affiche les informations d'utilisation et quitte.
-!, --more-help

Passe les informations d'utilisation étendues à un pager.

EXEMPLES

Pour générer une clé à stocker dans le système de fichiers, utilisez : 

$ tpmtool --generate-rsa --bits 2048 --outfile tpmkey.pem

Pour générer une clé à stocker dans la mémoire flash du TPM, utilisez : 

$ tpmtool --generate-rsa --bits 2048 --register --user

Pour obtenir la clé publique d'une clé TPM, utilisez : 

$ tpmtool --pubkey tpmkey:uuid=58ad734b-bde6-45c7-89d8-756a55ad1891;storage=user           --outfile pubkey.pem

ou si la clé est stockée dans le système de fichiers : 

$ tpmtool --pubkey tpmkey:file=tmpkey.pem --outfile pubkey.pem

Pour lister toutes les clés stockées dans le TPM, utilisez : 

$ tpmtool --list

STATUT DE SORTIE

L'une des valeurs de sortie suivantes sera retournée :

0 (EXIT_SUCCESS)

Exécution réussie du programme.
1 (EXIT_FAILURE)

L'opération a échoué ou la syntaxe de la commande était invalide.

tpmtool — A manual page for tpmtool

NAME

tpmtool - TPM 2.0 tools

SYNOPSIS

tpmtool [options] [command [command-options]]

DESCRIPTION

The tpmtool utility provides a set of command-line tools for interacting with a TPM (Trusted Platform Module) version 2.0 device.

It allows users to query TPM information, manage keys and objects, and perform other TPM-related operations.

OPTIONS

The tpmtool utility supports various options to control its behavior. Common options include:

  • -h, --help: Display a help message and exit.
  • -v, --version: Print version information and exit.
  • -d, --debug: Enable debug output.
  • -f, --force: Force operation, potentially overwriting existing data.

Refer to the specific command for its associated options.

EXAMPLES

To get information about the TPM device:

$ tpmtool gcgetcap

To create a primary key:

$ tpmtool ckhcreate

To list all loaded objects:

$ tpmtool goall

EXIT STATUS

The exit status of tpmtool indicates the success or failure of the operation. A status of 0 typically means success, while a non-zero status indicates an error.

tpmtool — Une page de manuel pour tpmtool

NOM

tpmtool - Outils TPM 2.0

SYNOPIS

tpmtool [options] [commande [options-commande]]

DESCRIPTION

L'utilitaire tpmtool fournit un ensemble d'outils en ligne de commande pour interagir avec un périphérique TPM (Trusted Platform Module) version 2.0.

Il permet aux utilisateurs d'interroger des informations sur le TPM, de gérer des clés et des objets, et d'effectuer d'autres opérations liées au TPM.

OPTIONS

L'utilitaire tpmtool prend en charge diverses options pour contrôler son comportement. Les options courantes comprennent :

  • -h, --help : Afficher un message d'aide et quitter.
  • -v, --version : Afficher les informations de version et quitter.
  • -d, --debug : Activer la sortie de débogage.
  • -f, --force : Forcer l'opération, potentiellement en écrasant les données existantes.

Référez-vous à la commande spécifique pour ses options associées.

EXEMPLES

Pour obtenir des informations sur le périphérique TPM :

$ tpmtool gcgetcap

Pour créer une clé primaire :

$ tpmtool ckhcreate

Pour lister tous les objets chargés :

$ tpmtool goall

STATUT DE SORTIE

Le statut de sortie de tpmtool indique le succès ou l'échec de l'opération. Un statut de 0 signifie généralement le succès, tandis qu'un statut non nul indique une erreur.
