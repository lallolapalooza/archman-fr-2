sous-routine ctpcon (character norm, character uplo, character diag, integer n, complex, dimension( * ) ap, real rcond, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CTPCON

But :

!>
!> CTPCON estime l'inverse du nombre de condition d'une matrice triangulaire
!> empaquetée A, en norme 1 ou en norme infinie.
!>
!> La norme de A est calculée et une estimation de norm(inv(A)) est obtenue,
!> puis l'inverse du nombre de condition est calculé comme suit :
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Paramètres

NORM 
!>          NORM est CHARACTER*1
!>          Spécifie si le nombre de condition en norme 1 ou en norme infinie
!>          est requis :
!>          = '1' ou 'O':  norme 1 ;
!>          = 'I':         norme infinie.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : A est triangulaire supérieure ;
!>          = 'L' : A est triangulaire inférieure.
!>

DIAG

!>          DIAG est CHARACTER*1
!>          = 'N' : A est une matrice triangulaire non unitaire ;
!>          = 'U' : A est une matrice triangulaire unitaire.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau COMPLEX de dimension (N*(N+1)/2)
!>          La matrice triangulaire supérieure ou inférieure A, empaquetée
!>          par colonnes dans un tableau linéaire. La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Si DIAG = 'U', les éléments diagonaux de A ne sont pas référencés
!>          et sont supposés être 1.
!>

RCOND

!>          RCOND est REAL
!>          L'inverse du nombre de condition de la matrice A,
!>          calculé comme RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK est un tableau COMPLEX de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau REAL de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

NAME

tpcon - estimates the reciprocal of the condition number of a packed triangular matrix.

SYNOPSIS

subroutine spcon(character norm, character uplo, character diag, integer n, real,
                 dimension( * ) ap, real rcond, real, dimension( * ) work,
                 integer info)

subroutine dpcon(character norm, character uplo, character diag, integer n,
                 double precision, dimension( * ) ap, double precision rcond,
                 double precision, dimension( * ) work, integer info)

subroutine ctpcon(character norm, character uplo, character diag, integer n,
                  complex, dimension( * ) ap, real rcond, complex,
                  dimension( * ) work, real, dimension( * ) rwork, integer info)

                  complex*16, dimension( * ) ap, double precision rcond,
                  complex*16, dimension( * ) work, double precision,
                  dimension( * ) rwork, integer info)

Detailed Description

This subroutine estimates the reciprocal of the condition number of a packed triangular matrix A, in either the 1-norm or the infinity-norm.

The norm of A is computed and an estimate is obtained for norm(inv(A)), then the reciprocal of the condition number is computed as RCOND = 1 / ( norm(A) * norm(inv(A)) ).

subroutine spcon (character norm, character uplo, character diag, integer n, real, dimension( * ) ap, real rcond, real, dimension( * ) work, integer info)

SPCON

Purpose:

!>
!> SPCON estimates the reciprocal of the condition number of a packed
!> triangular matrix A, in either the 1-norm or the infinity-norm.
!>
!> The norm of A is computed and an estimate is obtained for
!> norm(inv(A)), then the reciprocal of the condition number is
!> computed as
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

Parameters

NORM 
!>          NORM is CHARACTER*1
!>          Specifies whether the 1-norm condition number or the
!>          infinity-norm condition number is required:
!>          = '1' or 'O':  1-norm;
!>          = 'I':         Infinity-norm.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          = 'U':  A is upper triangular;
!>          = 'L':  A is lower triangular.
!>

DIAG

!>          DIAG is CHARACTER*1
!>          = 'N':  A is non-unit triangular;
!>          = 'U':  A is unit triangular.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

AP

!>          AP is REAL array, dimension (N*(N+1)/2)
!>          The upper or lower triangular matrix A, packed columnwise in
!>          a linear array.  The j-th column of A is stored in the array
!>          AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
!>          If DIAG = 'U', the diagonal elements of A are not referenced
!>          and are assumed to be 1.
!>

RCOND

!>          RCOND is REAL
!>          The reciprocal of the condition number of the matrix A,
!>          computed as RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK is REAL array, dimension (3*N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
