tpm2tss-genkey(1) Manuel des commandes générales tpm2tss-genkey(1)

NOM

tpm2tss-genkey(1) – générer des clés TPM pour le moteur tpm2-tss-engine

SYNTAXE

tpm2tss-genkey [options] <nom_fichier>

DESCRIPTION

tpm2tss-genkey crée une clé à l'intérieur d'un TPM 2.0 connecté via la pile logicielle tpm2tss. Ces clés peuvent être une clé RSA pour le déchiffrement ou la signature, ou une clé ECC pour les signatures ECDSA.

L'outil respecte l'option OPENSSL_CONF pour spécifier les paramètres de contrôle spécifiques au moteur. Voir man(5) config pour les détails sur les fichiers de configuration openssl.

ARGUMENTS

La commande tpm2tss-genkey attend un nom de fichier pour stocker les informations de clé TPM résultantes. Ce fichier peut ensuite être chargé avec OpenSSL en utilisant openssl pkeyutl -engine tpm2tss -keyform engine -inkey <nom_fichier>.

OPTIONS

•
-a <algorithme>, --alg <algorithme>: L'algorithme de clé publique (rsa, ecdsa) (par défaut : rsa)
•
-c <courbe>, --curve <courbe>: Si l'algorithme ecdsa est choisi, la courbe pour ecc (par défaut : nist_p256)
•
-u <fichier>, --public <fichier>: Clé publique (TPM2B_PUBLIC) à importer. Nécessite -r.
•
-r <fichier>, --private <fichier>: La clé privée (chiffrée) (TPM2B_PRIVATE) à importer. Nécessite -u.
•
-e <exposant>, --exponent <exposant>: Si l'algorithme rsa est choisi, l'exposant pour rsa (par défaut : 65537)
•
-h, --help: Afficher l'aide
•
-o <motdepasse>, --ownerpw <motdepasse>: Mot de passe pour la hiérarchie propriétaire (par défaut : aucun) Commande de contrôle de configuration OpenSSL : SET_OWNERAUTH
•
-p <motdepasse>, --password <motdepasse>: Mot de passe pour la clé créée (par défaut : aucun)
•
-P <handle>, --parent <handle>: Handle spécifique pour la clé parente (par défaut : aucun)
•
-s <taille_clé>, --keysize <taille_clé>: Si l'algorithme rsa est choisi, la taille de la clé en bits (par défaut : 2048)
•
-v, --verbose: Afficher les messages détaillés
•
-W <motdepasse>, --parentpw <motdepasse>: Mot de passe pour la clé parente (par défaut : aucun) Commande de contrôle de configuration OpenSSL : SET_PARENTAUTH
•
-t <tcti-conf>, --tcti <tcti-conf>: Chaîne de configuration TCTI (par défaut : aucune) Commande de contrôle de configuration OpenSSL : SET_TCTI

EXEMPLES

Les informations du moteur peuvent être récupérées en utilisant :

$ openssl engine -t -c tpm2tss

La séquence de commandes suivante crée une clé RSA à l'aide du TPM, exporte la clé publique, chiffre un fichier de données et le déchiffre à l'aide du TPM :

$ tpm2tss-genkey -a rsa -s 2048 ma_cle
$ openssl rsa -engine tpm2tss -inform engine -in ma_cle -pubout -outform pem -out ma_cle.pub
$ openssl pkeyutl -pubin -inkey ma_cle.pub -in mes_donnees -encrypt -out mon_chiffrement
$ openssl pkeyutl -engine tpm2tss -keyform engine -inkey ma_cle -decrypt -in mon_chiffrement -out mes_donnees

La séquence de commandes suivante crée une clé RSA à l'aide du TPM, exporte la clé publique, signe un fichier de données à l'aide du TPM et valide la signature :

$ tpm2tss-genkey -a rsa -s 2048 ma_cle
$ openssl rsa -engine tpm2tss -inform engine -in ma_cle -pubout -outform pem -out ma_cle.pub
$ openssl pkeyutl -engine tpm2tss -keyform engine -inkey ma_cle -sign -in mes_donnees -out ma_signature
$ openssl pkeyutl -engine tpm2tss -keyform engine -inkey ma_cle -verify -in mes_donnees -sigfile ma_signature

La séquence de commandes suivante crée une clé ECDSA à l'aide du TPM, exporte la clé publique, signe un fichier de données à l'aide du TPM et valide la signature :

$ tpm2tss-genkey -a ecdsa -c nist_p256 ma_cle
$ openssl pkeyutl -engine tpm2tss -keyform engine -inkey ma_cle -sign -in mes_donnees -out ma_signature
$ openssl pkeyutl -engine tpm2tss -keyform engine -inkey ma_cle -verify -in mes_donnees -sigfile ma_signature

RETOUR

0 en cas de succès, 1 en cas d'échec.
