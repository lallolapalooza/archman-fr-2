NOM

tpqrt - série de routines pour le calcul de la factorisation QR triangulaire par blocs.

DESCRIPTION

La routine DTPQRT calcule la factorisation QR triangulaire par blocs d'une matrice composée.

Cette routine est présentée dans le cadre de LAPACK, une bibliothèque de sous-programmes Fortran pour l'algèbre linéaire numérique.

Paramètres

N
Un entier, la dimension de la matrice carrée.
M
Un entier, le nombre de lignes.
L
Un entier, la dimension de la partie triangulaire supérieure de B.
NB
Un entier, la taille des blocs.
A
Un tableau de réels/complexes, la matrice carrée N-by-N.
LDA
Un entier, la première dimension de A.
B
Un tableau de réels/complexes, la matrice pentagonale M-by-N.
LDB
Un entier, la première dimension de B.
C
Un tableau de réels/complexes, la matrice composée (N+M)-by-N.
LDC
Un entier, la première dimension de C.
T
Un tableau de réels/complexes, la matrice triangulaire des réflecteurs.
LDT
Un entier, la première dimension de T.
WORK
Un tableau de réels/complexes, un espace de travail.
INFO
Un entier, la sortie d'information.

DETAILS

La matrice d'entrée C est une matrice (N+M)-par-N.

               C = [ A ]
                   [ B ]

où A est une matrice triangulaire supérieure N-par-N, et B est une matrice pentagonale M-par-N composée d'une matrice rectangulaire M-L par N B1 au-dessus d'une matrice trapézoïdale supérieure L-par-N B2 :

               B = [ B1 ]  <- M-L par N rectangulaire
                   [ B2 ]  <- L par N trapézoïdale supérieure.

La matrice trapézoïdale supérieure B2 est composée des L premières lignes d'une matrice triangulaire supérieure N-par-N, où 0 ≤ L ≤ MIN(M,N). Si L=0, B est rectangulaire M-par-N ; si M=L=N, B est triangulaire supérieure.

La matrice W stocke les réflecteurs élémentaires H(i) dans la i-ème colonne sous la diagonale (de A) dans la matrice d'entrée (N+M)-par-N C.

               C = [ A ]  <- triangulaire supérieure N-par-N
                   [ B ]  <- pentagonale M-par-N

de sorte que W peut être représentée comme

               W = [ I ]  <- identité, N-par-N
                   [ V ]  <- M-par-N, même forme que B.

Ainsi, toutes les informations nécessaires pour W sont contenues à la sortie dans B, que nous appelons V ci-dessus. Notez que V a la même forme que B ; c'est-à-dire,

               V = [ V1 ] <- M-L par N rectangulaire
                   [ V2 ] <- L par N trapézoïdale supérieure.

Les colonnes de V représentent les vecteurs qui définissent les H(i).

Le nombre de blocs est B = plafond(N/NB), où chaque bloc est d'ordre NB sauf le dernier bloc, qui est d'ordre IB = N - (B-1)*NB. Pour chacun des B blocs, un facteur de réflecteur bloc triangulaire supérieur est calculé : T1, T2, ..., TB. Les TB de taille NB-par-NB (et IB-par-IB pour le dernier bloc) sont stockés dans la matrice NB-par-N T comme

               T = [T1 T2 ... TB].
