NOM

tpm2_send(1) - Envoie un tampon de commande brut au TPM.

SYNTAXE

tpm2_send [OPTIONS] [STDIN]

DESCRIPTION

tpm2_send(1) - Envoie une commande TPM au TPM. La commande est lue à partir d'un fichier sous forme de flux binaire et transmise au TPM en utilisant le TCTI spécifié par l'appelant. La réponse reçue du TPM est écrite dans le fichier de sortie.

Il est probable que l'appelant souhaite rediriger ceci vers un fichier ou dans un programme pour décoder et afficher la réponse de manière lisible par l'homme.

OPTIONS

•
-o, --output=FICHIER:

Fichier de sortie vers lequel envoyer le tampon de réponse. Par défaut, il s'agit de la sortie standard.

•
**_STDIN** le fichier contenant la commande TPM2.

Références

OPTIONS COMMUNES

Cette collection d'options est commune à de nombreux programmes et fournit des informations que de nombreux utilisateurs peuvent attendre.

•

Configuration TCTI

Le TCTI ou « Transmission Interface » est le mécanisme de communication avec le TPM. Les TCTI peuvent être modifiés pour communiquer avec des TPM via différents supports.

Pour contrôler le TCTI, les outils respectent :

1.
L'option de ligne de commande -T ou --tcti
2.
La variable d'environnement : TPM2TOOLS_TCTI.

Remarque : L'option de ligne de commande remplace toujours la variable d'environnement.

Les TCTI actuellement connus sont :

•
tabrmd - Le gestionnaire de ressources, appelé tabrmd. Notez que tabrmd et abrmd en tant que nom tcti sont synonymes.
•
mssim - Généralement utilisé pour communiquer avec le simulateur logiciel du TPM.
•
device - Utilisé lors de la communication directe avec un fichier de périphérique TPM.
•
none - N'initialise pas de connexion avec le TPM. Certains outils permettent des options hors TPM et supportent donc de ne pas utiliser de TCTI. Les outils qui ne le supportent pas généreront une erreur lorsqu'ils seront utilisés sans connexion TCTI. Ne supporte AUCUNE option et DOIT être présenté comme le texte exact de «none».

Les arguments de l'option de ligne de commande ou de la variable d'environnement sont sous la forme :

<nom-tcti>:<config-option-tcti>

Spécifier une chaîne vide pour le <nom-tcti> ou la <config-option-tcti> entraîne l'utilisation de la valeur par défaut pour cette partie respectivement.

Défauts TCTI

Lorsqu'un TCTI n'est pas spécifié, le TCTI par défaut est recherché en utilisant la sémantique de dlopen(3). Les outils rechercheront les TCTI tabrmd, device et mssim DANS CET ORDRE et UTILISERONT LE PREMIER TROUVÉ. Vous pouvez interroger quel TCTI sera choisi par défaut en utilisant l'option -v pour afficher les informations de version. La paire clé-valeur «default-tcti» indiquera lequel des TCTI susmentionnés est le défaut.

TCTIs Personnalisés

Tout TCTI implémentant l'interface TCTI dynamique peut être chargé. Les outils utilisent en interne dlopen(3), et la valeur brute nom-tcti est utilisée pour la recherche. Ainsi, cela pourrait être un chemin vers la bibliothèque partagée, ou un nom de bibliothèque tel qu'entendu par la sémantique de dlopen(3).

OPTIONS TCTI

Cette collection d'options est utilisée pour configurer les différents modules TCTI connus disponibles :

•
device: Pour le TCTI device, le fichier de périphérique caractère TPM à utiliser par le TCTI device peut être spécifié. La valeur par défaut est /dev/tpm0.

Exemple : -T device:/dev/tpm0 ou export TPM2TOOLS_TCTI=“device:/dev/tpm0”

•
mssim: Pour le TCTI mssim, le nom de domaine ou l'adresse IP et le numéro de port utilisés par le simulateur peuvent être spécifiés. Les valeurs par défaut sont 127.0.0.1 et 2321.

Exemple : -T mssim:host=localhost,port=2321 ou export TPM2TOOLS_TCTI=“mssim:host=localhost,port=2321”

•
abrmd: Pour le TCTI abrmd, le format de la chaîne de configuration est une série de paires clé-valeur simples séparées par un caractère `,'. Chaque clé et valeur sont séparées par un caractère `=.
•
Le TCTI abrmd prend en charge deux clés :
1.
`bus_name' : Le nom du service tabrmd sur le bus (une chaîne de caractères).
2.
`bus_type' : Le type de l'instance dbus (une chaîne de caractères) limitée à `session' et `system'.

Spécifier le nom tcti tabrmd et une chaîne de configuration de bus_name=com.example.FooBar :

\--tcti=tabrmd:bus_name=com.example.FooBar

Spécifier le tcti par défaut (abrmd) et une chaîne de configuration de bus_type=session :

\--tcti:bus_type=session

NOTE : abrmd et tabrmd sont synonymes. les différents modules TCTI connus.

EXEMPLES

Envoyer et recevoir des commandes brutes au TPM

Envoie le contenu de tpm2-command.bin à un appareil et collecte la réponse sous le nom tpm2-response.bin.

tpm2_send < tpm2-command.bin > tpm2-response.bin
tpm2_send < tpm2-command.bin -o tpm2-response.bin
