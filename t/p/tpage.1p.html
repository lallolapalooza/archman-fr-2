NOM

Template::Tools::tpage - Traiter des modèles depuis la ligne de commande

UTILISATION

tpage [ --define var=valeur ] fichier(s)

DESCRIPTION

Le script tpage est un simple wrapper autour du processeur Template Toolkit. Les fichiers spécifiés par leur nom sur la ligne de commande sont traités tour à tour par le processeur de modèles et la sortie résultante est envoyée à STDOUT et peut être redirigée en conséquence. Par exemple :

tpage monfichier > monfichier.out
tpage en_tete monfichier pied_de_page > monfichier.html

Si aucun nom de fichier n'est spécifié sur la ligne de commande, tpage lira STDIN pour l'entrée.

L'option "--define" peut être utilisée pour définir les valeurs des variables de modèle. Par exemple :

tpage --define auteur="Andy Wardley" squelette.pm > MonModule.pm

Le fichier de configuration .tpagerc

Vous pouvez utiliser un fichier .tpagerc dans votre répertoire personnel.

Le but de ce fichier est de définir toutes les options de configuration globales que vous souhaitez appliquer chaque fois que tpage est exécuté. Par exemple, vous pouvez utiliser "include_path" pour utiliser des fichiers de modèles à partir d'un répertoire de modèles générique.

Exécutez "tpage -h" pour un résumé des options disponibles.

Voir Template pour des informations générales sur le Perl Template Toolkit ainsi que sur le langage et les fonctionnalités de modèle.
