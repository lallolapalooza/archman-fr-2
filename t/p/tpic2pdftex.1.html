NOM

tpic2pdftex - convertir les \specials tpic pour une utilisation par pdftex

SYNTAXE

pic -t quelquechose.pic | tpic2pdftex > quelquechose.tex

Traiter quelquechose.tex par pdftex/pdflatex.

DESCRIPTION

Script awk expérimental pour la conversion des \specials tpic produits par (groff-)pic en sections \pdfliteral de pdfTeX pour un traitement ultérieur par pdftex.

NOTES

Version actuelle : 1.97.

Description des \special tpic, voir par exemple : Goossens, Rahtz, Mittelbach : The LaTeX Graphics Companion, Addison-Wesley, 1997, pp. 464.

BOGUES

Les formes de courbes splines ne sont pas totalement authentiques (algorithme inconnu). La boîte englobante ne tient pas compte de l'épaisseur du trait (fonction de groff pic). Les splines peuvent être en dehors de la boîte englobante. La couleur de remplissage ne fonctionne pas correctement pour les têtes de flèches (limitation de pic).

VOIR AUSSI

pic(1), grap(1), groff(1), awk(1), pdftex(1).
