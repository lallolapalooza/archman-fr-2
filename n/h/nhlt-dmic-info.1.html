NOM

nhlt-dmic-info - décharger les informations du réseau de microphones à partir de la table ACPI NHLT

SYNTAXE

nhlt-dmic-info [-option]

DESCRIPTION

nhlt-dmic-info décharge les informations du réseau de microphones à partir de la table ACPI NHLT au format JSON.

OPTIONS

-h | --help

Affiche les informations d'aide.

-f <fichier> | --file=<fichier>

Fichier d'entrée contenant la table binaire ACPI NHLT (par défaut /sys/firmware/acpi/tables/NHLT).

-o <fichier> | --output=<fichier>

Fichier de sortie JSON (par défaut, la sortie standard : -).

EXEMPLES

nhlt-dmic-info -f nhlt.bin -o dmic.json

BOGUES

Aucun connu.

AUTEUR
