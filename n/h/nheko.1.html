NHEKO(1) Manuel des commandes générales NHEKO(1)

NOM

nheko - Client de bureau pour Matrix utilisant Qt et C++17

SYNOPIS

nheko [OPTIONS]

DESCRIPTION

La motivation derrière le projet est de fournir une application de bureau native pour Matrix qui ressemble davantage à une application de chat grand public (Element, Telegram, etc.) et moins à un client IRC.

OPTIONS

-h, --help

Affiche l'aide sur les options de la ligne de commande.

--help-all

Affiche l'aide, y compris les options spécifiques à Qt.

-v, --version

Affiche les informations sur la version.

--debug

Alias pour --log-level trace.

-l, --log-level <niveau>

Définit le niveau de journalisation global, ou une liste séparée par des virgules de paires <composant>=<niveau>, ou les deux. Par exemple, pour définir le niveau de journalisation par défaut sur warn mais désactiver la journalisation pour le composant ui, passez warn,ui=off.

niveaux : trace debug info warning error critical off

composants : crypto db mtx net qml ui

Les niveaux de journalisation peuvent également être définis dans la variable d'environnement NHEKO_LOG_LEVEL, en utilisant la même syntaxe. Elle sera remplacée par cette option de ligne de commande.

-L, --log-type <type>

Définit le type de sortie de journalisation. Une liste séparée par des virgules est autorisée. Le défaut est file,stderr.

types : file stderr none

Le type de journalisation peut également être défini dans la variable d'environnement NHEKO_LOG_TYPE, qui sera remplacée par cette option de ligne de commande.

-p <profil>, --profile <profil>

Crée un profil unique, qui vous permet de vous connecter à plusieurs comptes en même temps et de lancer plusieurs instances de nheko. Utilisez default pour commencer avec le profil par défaut.

-C, --compact

Permet de réduire la base de données, car les bases de données LMDB ne se réduisent pas automatiquement lorsque des données sont supprimées. Permet éventuellement une certaine récupération en cas de corruption de la base de données.

FAQ

Comment ajouter des autocollants et des emojis personnalisés ?

Les autocollants et les emojis personnalisés sont organisés en packs d'images. Il existe un pack d'images utilisateur auquel seul votre compte a accès et des packs d'images de salon accessibles à tous dans le salon où ils sont définis. Vous pouvez activer un pack d'images de salon globalement pour l'utiliser dans n'importe quel salon.

Pour gérer les packs d'images dans nheko, allez dans les paramètres du salon et entrez les Paramètres d'autocollants et d'émoticônes. Vous verrez le pack Privé (votre pack d'images utilisateur) et pourrez le modifier là. Le Shortcode est un identifiant unique que vous utilisez pour sélectionner l'image et le Body est le texte alternatif affiché sur les clients qui ne prennent pas en charge les images (comme la balise alt dans les images HTML).

Si vous avez les permissions nécessaires, vous pouvez créer de nouveaux packs de salon avec le bouton en bas de la liste des packs d'images. Ils sont identiques au pack utilisateur mais vous pouvez en créer autant que vous le souhaitez et tout le monde dans le salon peut les utiliser. Il peut être judicieux de créer un salon supplémentaire juste pour vos packs d'images afin de faciliter le partage.

COMPLETERS

Les completers font apparaître une fenêtre contextuelle avec des candidats de complétion lorsque vous les tapez dans la ligne de saisie.

@

Ouvre le compléteur de noms d'utilisateur.

#

Ouvre le compléteur de salons.

:

Ouvre le sélecteur d'emojis. Les emojis Unicode sont insérés directement. Les emojis personnalisés inséreront leur code HTML dans la ligne de saisie. Vous pouvez configurer les emojis personnalisés dans les paramètres du salon.

RACCOURCIS CLAVIER

Liste des salons

Ctrl-Flèche Haut/Ctrl-Flèche Bas

Navigue dans la liste des salons.

Ctrl-W

Ferme le salon actuellement ouvert.

Ctrl-K

Recherche et sélectionne des salons dans la liste des salons.

Alt-A, Ctrl-Shift-A

Sélectionne le salon suivant avec une activité.

Timeline/Messagerie

Page Haut/Page Bas

Fait défiler la timeline par page.

Alt-Flèche Haut/Alt-Flèche Bas

Répond à un message.

Flèche Haut/Flèche Bas

Modifie un message.

Ctrl-E

Modifie le message actuellement sélectionné pour répondre.

Alt-F

Fait suivre le message actuellement sélectionné pour répondre.

Ctrl-P/Ctrl-N

Ré-entre le message précédent/suivant.

Ctrl-U

Supprime tout dans la ligne de saisie.

Ctrl-Gauche/Ctrl-Droite

Saute d'un mot vers la gauche/droite dans la ligne de saisie.

Shift-Entrée

Insère un saut de ligne.

Entrée

Soumet le message.

COMMANDES

Les commandes ne fonctionnent que lorsqu'elles sont utilisées au début du texte.

Messages personnalisés

/me <message>

Envoie un message comme une émoticône, où votre nom d'utilisateur est préfixé.

/react <texte>

Envoie un message comme une réaction lorsque vous répondez à un message.

/md <message>

Force Markdown lors de l'envoi du message actuel.

/cmark <message>

Désactive la plupart de nos extensions pour cmark (CommonMark), y compris le comportement nouvelle ligne dans l'entrée = nouvelle ligne dans la sortie, le barré et les spoilers. Vous pouvez toujours forcer les nouvelles lignes avec 2 espaces ou une barre oblique inverse avant la fin de la ligne ou insérer des éléments HTML.

/plain <message>

Force le texte brut lors de l'envoi du message actuel.

/rainbow <message>

Envoie un message en couleurs arc-en-ciel.

/rainbowme <message>

Envoie un message comme une émoticône colorée arc-en-ciel, où votre nom d'utilisateur est préfixé.

/notice <message>

Envoie un message comme une notice.

/rainbownotice <notice>

Envoie un message comme une notice colorée arc-en-ciel.

Gestion des salons

/join <nom_salon> [raison]

Rejoint un salon. raison est facultatif.

/knock <nom_salon> [raison]

Demande à rejoindre un salon. raison est facultatif.

/part, /leave [raison]

Quitte le salon actuel. raison est facultatif.

/invite <nom_utilisateur> [raison]

Invite un utilisateur dans le salon actuel. raison est facultatif.

/kick <nom_utilisateur> [raison]

Expulse un utilisateur du salon actuel. raison est facultatif. Vous pouvez également expulser l'utilisateur auquel vous répondez en omettant nom_utilisateur.

/ban <nom_utilisateur> [raison]

Banni un utilisateur du salon actuel. raison est facultatif. Vous pouvez également bannir l'utilisateur auquel vous répondez en omettant nom_utilisateur.

/unban <nom_utilisateur> [raison]

Débanni un utilisateur. raison est facultatif. Vous pouvez alternativement

COMMANDES

/ban <nom d'utilisateur> [raison]

Bannit l'utilisateur spécifié de la salle.

/unban <nom d'utilisateur>

Annule le bannissement de l'utilisateur spécifié. Laissez l'nom d'utilisateur vide pour annuler le bannissement de l'utilisateur auquel vous répondez.

/redact <nom d'utilisateur> [raison]

Supprime tous les messages visibles de l'utilisateur spécifié. Vous atteindrez rapidement les limites de débit.

/redact <id d'événement> [raison]

Supprime un événement spécifique. Vous pouvez également supprimer l'événement auquel vous répondez en ne spécifiant ni id d'événement ni nom d'utilisateur.

/roomnick <nom de salle>

Change votre pseudonyme dans une salle unique.

/glitch <message>

Applique un effet de glitch au message donné. Attention, cela cassera les mentions, le HTML et certains Markdown dans votre message.

/gradualglitch <message>

Applique un effet de glitch de plus en plus sévère au message. Encore une fois, cela cassera les mentions, le HTML et certains Markdown.

Emoticônes

/shrug [message]

Insère ¯\_(ツ)_/¯ suivi d'un message optionnel.

/fliptable

Insère (╯°□°)╯︵ ┻━┻

/unfliptable

Insère ┯━┯╭( º _ º╭)

/sovietflip

Insère ノ┬─┬ノ ︵ ( \\o°o)\\

Gestion des utilisateurs

/ignore <nom d'utilisateur>

Ignore un utilisateur, les invitations de sa part sont également rejetées.

/unignore <nom d'utilisateur>

Arrête d'ignorer un utilisateur.

Gestion des permissions d'invitation

/blockinvites <nom d'utilisateur>|<id de salle>|<nom de serveur>|all

Bloque toutes les invitations soit par défaut ("all"), soit d'un utilisateur ou d'un serveur spécifique, soit vers une salle spécifique.

/allowinvites <nom d'utilisateur>|<id de salle>|<nom de serveur>|all

Autorise toutes les invitations soit par défaut ("all"), soit d'un utilisateur ou d'un serveur spécifique, soit vers une salle spécifique.

Avancé

/clear-timeline

Supprime tous les messages sauf les plus récents de la chronologie actuellement affichée et la re-récupère auprès du serveur ; peut être utilisé pour corriger certains problèmes de cache.

/reset-state

Récupère à nouveau tous les événements d'état de la salle actuelle ; peut être utilisé pour corriger certains problèmes de cache.

/rotate-megolm-session

Fait pivoter la clé de chiffrement utilisée pour envoyer des messages chiffrés dans une salle.

/goto <adresse>

adresse peut être l'un des éléments suivants :

<ID d'événement>

Saute à l'événement avec l'ID spécifié et le met en surbrillance.

<index de message>

Saute au message avec l'index spécifié et le met en surbrillance.

<URI Matrix>

Gère l'URI Matrix comme si vous aviez cliqué dessus.

/converttodm

Convertit une salle en conversation directe.

/converttoroom

Convertit une conversation directe en salle normale.

EXTENSIONS MARKDOWN

nouvelle ligne (\n)

Une seule nouvelle ligne sera transformée en <br> au lieu d'un espace.

~texte~

Met le texte en barré. Sortie HTML : <del>texte</del>

||avertissement spoiler|texte||

Masque le texte et définit un avertissement spoiler optionnel. Notez que Nheko n'affiche pas actuellement l'avertissement spoiler. Sortie HTML : <span data-mx-spoiler="spoiler">texte</span>

ENVIRONNEMENT

NHEKO_ALLOW_QML_DISK_CACHE

Nheko désactive par défaut le cache disque qml pour éviter les plantages. Cela vous permet de le réactiver à vos risques et périls.

FICHIERS

Cache des médias

${XDG_CACHE_HOME:-~/.cache}/nheko/nheko/media_cache
