fonction real(wp) dnrm2 (integer n, real(wp), dimension(*) x, integer incx)

DNRM2

Objectif :

!>
!> DNRM2 retourne la norme euclidienne d'un vecteur via le nom de la fonction, de sorte que
!>
!>    DNRM2 := sqrt( x'*x )
!>

Paramètres

N 
!>          N est INTEGER
!>         nombre d'éléments dans le(s) vecteur(s) d'entrée
!>

X

!>          X est un tableau DOUBLE PRECISION, de dimension ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX est INTEGER, espacement de stockage entre les éléments de X
!>          Si INCX > 0, X(1+(i-1)*INCX) = x(i) pour 1 <= i <= n
!>          Si INCX < 0, X(1-(n-i)*INCX) = x(i) pour 1 <= i <= n
!>          Si INCX = 0, x n'est pas un vecteur, il n'est donc pas nécessaire d'appeler
!>          cette sous-routine. Si vous l'appelez quand même, elle comptera x(1)
!>          dans la norme du vecteur N fois.
!>
