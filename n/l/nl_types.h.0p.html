nl_types.h(0P) Manuel du programmeur POSIX nl_types.h(0P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

nl_types.h — types de données

SYNOPIS

#include <nl_types.h>

DESCRIPTION

L'en-tête <nl_types.h> doit définir au moins les types suivants :

nl_catd
Utilisé par les fonctions de catalogue de messages catopen(), catgets() et catclose() pour identifier un descripteur de catalogue.
nl_item
Utilisé par nl_langinfo() pour identifier les éléments des données langinfo. Les valeurs des objets de type nl_item sont définies dans <langinfo.h>.

L'en-tête <nl_types.h> doit définir au moins les constantes symboliques suivantes :

NL_SETD
Utilisé par gencat lorsqu'aucune directive $set n'est spécifiée dans un fichier source de texte de message. Cette constante peut être passée comme valeur de set_id lors d'appels ultérieurs à catgets() (c'est-à-dire pour récupérer des messages de l'ensemble de messages par défaut). La valeur de NL_SETD est indéfinie par l'implémentation.
NL_CAT_LOCALE
Valeur qui doit être passée comme argument oflag à catopen() pour garantir que la sélection du catalogue de messages dépend de la catégorie de locale LC_MESSAGES, plutôt que directement de la variable d'environnement LANG.

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme macros. Les prototypes de fonctions seront fournis.

int       catclose(nl_catd);
char     *catgets(nl_catd, int, int, const char *);
nl_catd   catopen(const char *, int);
