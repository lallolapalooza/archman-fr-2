NOM

nl-classid-lookup - Recherche les définitions de classid

SYNTAXE

nl-classid-lookup [-hv] [-r] [--raw] nom

DESCRIPTION

nl-classid-lookup recherche dans la base de données des classid une entrée correspondante. Il est utilisé pour résoudre les noms de qdisc/classe en valeurs de classid et vice-versa.

OPTIONS

-h ou --help
Affiche le texte d'aide sur la console et quitte.
-v ou --version
Affiche les informations de version sur la console et quitte.
-r ou --reverse
Effectue une recherche inversée. Recherche un classid et affiche son nom.
--raw
Affiche le classid brut au format hexadécimal, ne l'affiche pas joliment.

UTILISATION

Résoudre le nom de qdisc/classe "interactive" :

# nl-classid-lookup interactive

Rechercher le nom du classid 1:2 :

# nl-classid-lookup -r 1:2

FICHIERS

/etc/libnl/classid
