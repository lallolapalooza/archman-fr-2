nl_langinfo(3) Manuel des fonctions de bibliothèque nl_langinfo(3)

NOM

nl_langinfo, nl_langinfo_l - interroger les informations linguistiques et locales

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <langinfo.h>
char *nl_langinfo(nl_item item);
char *nl_langinfo_l(nl_item item, locale_t locale);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

nl_langinfo_l():

    Depuis glibc 2.24 :
        _POSIX_C_SOURCE >= 200809L
    glibc 2.23 et antérieur :
        _POSIX_C_SOURCE >= 200112L

DESCRIPTION

Les fonctions nl_langinfo() et nl_langinfo_l() fournissent un accès aux informations de localisation d'une manière plus flexible que localeconv(3). nl_langinfo() renvoie une chaîne qui est la valeur correspondant à item dans la locale globale actuelle du programme. nl_langinfo_l() renvoie une chaîne qui est la valeur correspondant à item pour la locale identifiée par l'objet locale locale, qui a été créé précédemment par newlocale(3). Des éléments individuels et supplémentaires des catégories de locale peuvent être interrogés.

Exemples des éléments de locale qui peuvent être spécifiés dans item en utilisant les constantes définies dans <langinfo.h> sont :

CODESET (LC_CTYPE)
Renvoie une chaîne avec le nom du codage de caractères utilisé dans la locale sélectionnée, comme "UTF-8", "ISO-8859-1", ou "ANSI_X3.4-1968" (mieux connu sous le nom de US-ASCII). C'est la même chaîne que celle que vous obtenez avec "locale charmap". Pour une liste des noms de codage de caractères, essayez "locale -m" (voir locale(1)).
D_T_FMT (LC_TIME)
Renvoie une chaîne qui peut être utilisée comme chaîne de format pour strftime(3) pour représenter l'heure et la date d'une manière spécifique à la locale (spécification de conversion %c).
D_FMT (LC_TIME)
Renvoie une chaîne qui peut être utilisée comme chaîne de format pour strftime(3) pour représenter une date d'une manière spécifique à la locale (spécification de conversion %x).
T_FMT (LC_TIME)
Renvoie une chaîne qui peut être utilisée comme chaîne de format pour strftime(3) pour représenter une heure d'une manière spécifique à la locale (spécification de conversion %X).
AM_STR (LC_TIME)
Renvoie une chaîne qui représente l'affixe pour l'heure ante meridiem (avant midi, "AM"). (Utilisé dans la spécification de conversion %p de strftime(3).)
PM_STR (LC_TIME)
Renvoie une chaîne qui représente l'affixe pour l'heure post meridiem (avant minuit, "PM"). (Utilisé dans la spécification de conversion %p de strftime(3).)
T_FMT_AMPM (LC_TIME)
Renvoie une chaîne qui peut être utilisée comme chaîne de format pour strftime(3) pour représenter une heure en notation a.m. ou p.m. d'une manière spécifique à la locale (spécification de conversion %r).
ERA (LC_TIME)
Renvoie la description de l'ère, qui contient des informations sur la façon dont les années sont comptées et affichées pour chaque ère dans une locale. Chaque segment de description d'ère doit avoir le format :
direction:offset:start_date:end_date:era_name:era_format
selon les définitions ci-dessous :
direction
Soit un caractère "+" soit un caractère "-". Le "+" signifie que les années augmentent de la start_date vers la end_date, "-" signifie le contraire.
offset
L'année d'époque de la start_date.
start_date
Une date sous la forme aaaa/mm/jj, où aaaa, mm, et jj sont respectivement les numéros de l'année, du mois et du jour du début de l'ère.
end_date
La date de fin de l'ère, sous la même forme que la start_date, ou l'une des deux valeurs spéciales "-*" (moins l'infini) ou "+*" (plus l'infini).
era_name
Le nom de l'ère, correspondant à la spécification de conversion %EC de strftime(3).
era_format
Le format de l'année dans l'ère, correspondant à la spécification de conversion %EY de strftime(3).
Les segments de description d'ère sont séparés par des points-virgules. La plupart des locales ne définissent pas cette valeur. Les locales japonaise et thaïlandaise sont des exemples de locales qui définissent cette valeur.
ERA_D_T_FMT (LC_TIME)
Renvoie une chaîne qui peut être utilisée comme chaîne de format pour strftime(3) pour une représentation alternative de l'heure et de la date dans une locale (spécification de conversion %Ec).
ERA_D_FMT (LC_TIME)
Renvoie une chaîne qui peut être utilisée comme chaîne de format pour strftime(3) pour une représentation alternative d'une date dans une locale (spécification de conversion %Ex).
ERA_T_FMT (LC_TIME)
Renvoie une chaîne qui peut être utilisée comme chaîne de format pour strftime(3) pour une représentation alternative d'une heure dans une locale (spécification de conversion %EX).
DAY_{1–7} (LC_TIME)
Renvoie le nom du n-ième jour de la semaine. [Attention : ceci suit la convention américaine DAY_1 = Dimanche, pas la convention internationale (ISO 8601) selon laquelle Lundi est le premier jour de la semaine.] (Utilisé dans la spécification de conversion %A de strftime(3).)
ABDAY_{1–7} (LC_TIME)
Renvoie le nom abrégé du n-ième jour de la semaine. (Utilisé dans la spécification de conversion %a de strftime(3).)
MON_{1–12} (LC_TIME)
Renvoie le nom du n-ième mois. (Utilisé dans la spécification de conversion %B de strftime(3).)
ABMON_{1–12} (LC_TIME)
Renvoie le nom abrégé du n-ième mois. (Utilisé dans la spécification de conversion %b de strftime(3).)
RADIXCHAR (LC_NUMERIC)
Renvoie le caractère radix (point décimal, virgule décimale, etc.).
THOUSEP (LC_NUMERIC)
Renvoie le caractère séparateur des milliers (groupes de trois chiffres).
YESEXPR (LC_MESSAGES)
Renvoie une expression régulière qui peut être utilisée avec la fonction regex(3) pour reconnaître une réponse positive à une question oui/non.
NOEXPR (LC_MESSAGES)
Renvoie une expression régulière qui peut être utilisée avec la fonction regex(3) pour reconnaître une réponse négative à une question oui/non.
CRNCYSTR (LC_MONETARY)
Renvoie le symbole monétaire.

nl_langinfo(3) — manpages

NAME

nl_langinfo, nl_langinfo_l - query information about the current locale

LIBRARY

Standard C library (libc, -lc)

SYNOPSIS

#include <langinfo.h>

char *nl_langinfo(nl_item item);
char *nl_langinfo_l(nl_item item, locale_t locale);

DESCRIPTION

The nl_langinfo() function returns a pointer to a string describing the information corresponding to item in the current locale set by setlocale(3).

The nl_langinfo_l() function is similar to nl_langinfo(), but operates on the specified locale object. The locale argument is a locale object handle created by newlocale(3).

The possible values for item are defined in <langinfo.h> and are constants that start with CODESET, D_FMT, D_MD_ORDER, D_T_FMT, DAY_1, DAY_2, ..., DAY_7, ABDAY_1, ..., ABDAY_7, MON_1, ..., MON_12, ABMON_1, ..., ABMON_12, AM_STR, PM_STR, T_FMT, T_FMT_AMPM, T_12_FMT, T_24_FMT, ERA, ..., **ERA_D_T_FMT**, ERA_D_FMT, **ERA_T_FMT**, ALT_DIGITS, **RADIXCHAR**, **THOUSEP**, **YESEXPR**, **NOEXPR**, **CRNCYSTR**.

CRNCYSTR (LC_MONETARY)
Return the currency symbol, preceded by "-" if the symbol should appear before the value, "+" if the symbol should appear after the value, or "." if the symbol should replace the radix character.

The above list covers just some examples of items that can be requested. For a more detailed list, consult The GNU C Library Reference Manual.

RETURN VALUE

On success, these functions return a pointer to a string which is the value corresponding to item in the specified locale.

If no locale has been selected by setlocale(3) for the appropriate category, nl_langinfo() return a pointer to the corresponding string in the "C" locale. The same is true of nl_langinfo_l() if locale specifies a locale where langinfo data is not defined.

If item is not valid, a pointer to an empty string is returned.

The pointer returned by these functions may point to static data that may be overwritten, or the pointer itself may be invalidated, by a subsequent call to nl_langinfo(), nl_langinfo_l(), or setlocale(3). The same statements apply to nl_langinfo_l() if the locale object referred to by locale is freed or modified by freelocale(3) or newlocale(3).

POSIX specifies that the application may not modify the string returned by these functions.

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7).

Interface Attribute Value
nl_langinfo () Thread safety MT-Safe locale

STANDARDS

POSIX.1-2008.

HISTORY

POSIX.1-2001, SUSv2.

NOTES

The behavior of nl_langinfo_l() is undefined if locale is the special locale object LC_GLOBAL_LOCALE or is not a valid locale object handle.

EXAMPLES

The following program sets the character type and the numeric locale according to the environment and queries the terminal character set and the radix character.

#include <langinfo.h>
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
int
main(void)
{
    setlocale(LC_CTYPE, "");
    setlocale(LC_NUMERIC, "");
    printf("%s\n", nl_langinfo(CODESET));
    printf("%s\n", nl_langinfo(RADIXCHAR));
    exit(EXIT_SUCCESS);
}
