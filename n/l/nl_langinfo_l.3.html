nl_langinfo(3) Manuel des fonctions de bibliothèque nl_langinfo(3)

NOM

nl_langinfo, nl_langinfo_l - interroger les informations linguistiques et locales

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <langinfo.h>
char *nl_langinfo(nl_item item);
char *nl_langinfo_l(nl_item item, locale_t locale);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

nl_langinfo_l():

    Depuis glibc 2.24 :
        _POSIX_C_SOURCE >= 200809L
    glibc 2.23 et versions antérieures :
        _POSIX_C_SOURCE >= 200112L

DESCRIPTION

Les fonctions nl_langinfo() et nl_langinfo_l() donnent accès aux informations locales d'une manière plus flexible que localeconv(3). nl_langinfo() retourne une chaîne qui est la valeur correspondant à item dans la locale globale actuelle du programme. nl_langinfo_l() retourne une chaîne qui est la valeur correspondant à item pour la locale identifiée par l'objet de locale locale, qui a été créé précédemment par newlocale(3). Des éléments individuels et supplémentaires des catégories de locale peuvent être interrogés.

Exemples d'éléments de locale qui peuvent être spécifiés dans item en utilisant les constantes définies dans <langinfo.h> sont :

CODESET (LC_CTYPE)
Retourne une chaîne avec le nom de l'encodage de caractères utilisé dans la locale sélectionnée, tel que "UTF-8", "ISO-8859-1", ou "ANSI_X3.4-1968" (mieux connu sous le nom de US-ASCII). C'est la même chaîne que celle que vous obtenez avec "locale charmap". Pour une liste des noms d'encodage de caractères, essayez "locale -m" (voir locale(1)).
D_T_FMT (LC_TIME)
Retourne une chaîne qui peut être utilisée comme chaîne de format pour strftime(3) pour représenter la date et l'heure d'une manière spécifique à la locale (spécification de conversion %c).
D_FMT (LC_TIME)
Retourne une chaîne qui peut être utilisée comme chaîne de format pour strftime(3) pour représenter une date d'une manière spécifique à la locale (spécification de conversion %x).
T_FMT (LC_TIME)
Retourne une chaîne qui peut être utilisée comme chaîne de format pour strftime(3) pour représenter une heure d'une manière spécifique à la locale (spécification de conversion %X).
AM_STR (LC_TIME)
Retourne une chaîne qui représente l'affixe pour ante meridiem (avant midi, "AM") de l'heure. (Utilisé dans la spécification de conversion %p de strftime(3).)
PM_STR (LC_TIME)
Retourne une chaîne qui représente l'affixe pour post meridiem (avant minuit, "PM") de l'heure. (Utilisé dans la spécification de conversion %p de strftime(3).)
T_FMT_AMPM (LC_TIME)
Retourne une chaîne qui peut être utilisée comme chaîne de format pour strftime(3) pour représenter une heure en notation a.m. ou p.m. d'une manière spécifique à la locale (spécification de conversion %r).
ERA (LC_TIME)
Retourne la description de l'ère, qui contient des informations sur la façon dont les années sont comptées et affichées pour chaque ère dans une locale. Chaque segment de description d'ère doit avoir le format :
direction:offset:start_date:end_date:era_name:era_format
selon les définitions ci-dessous :
direction
Soit un caractère "+" soit "-". Le "+" signifie que les années augmentent de la start_date vers la end_date, "-" signifie l'inverse.
offset
L'année d'époque de la start_date.
start_date
Une date sous la forme yyyy/mm/jj, où yyyy, mm et jj sont respectivement les numéros de l'année, du mois et du jour du début de l'ère.
end_date
La date de fin de l'ère, dans le même format que la start_date, ou l'une des deux valeurs spéciales "-*" (moins l'infini) ou "+*" (plus l'infini).
era_name
Le nom de l'ère, correspondant à la spécification de conversion %EC de strftime(3).
era_format
Le format de l'année dans l'ère, correspondant à la spécification de conversion %EY de strftime(3).
Les segments de description d'ère sont séparés par des points-virgules. La plupart des locales ne définissent pas cette valeur. Les locales japonaise et thaïlandaise sont des exemples de locales qui définissent cette valeur.
ERA_D_T_FMT (LC_TIME)
Retourne une chaîne qui peut être utilisée comme chaîne de format pour strftime(3) pour une représentation alternative de la date et de l'heure d'une manière spécifique à la locale (spécification de conversion %Ec).
ERA_D_FMT (LC_TIME)
Retourne une chaîne qui peut être utilisée comme chaîne de format pour strftime(3) pour une représentation alternative d'une date d'une manière spécifique à la locale (spécification de conversion %Ex).
ERA_T_FMT (LC_TIME)
Retourne une chaîne qui peut être utilisée comme chaîne de format pour strftime(3) pour une représentation alternative d'une heure d'une manière spécifique à la locale (spécification de conversion %EX).
DAY_{1–7} (LC_TIME)
Retourne le nom du n-ième jour de la semaine. [Avertissement : ceci suit la convention américaine DAY_1 = Dimanche, pas la convention internationale (ISO 8601) selon laquelle Lundi est le premier jour de la semaine.] (Utilisé dans la spécification de conversion %A de strftime(3).)
ABDAY_{1–7} (LC_TIME)
Retourne le nom abrégé du n-ième jour de la semaine. (Utilisé dans la spécification de conversion %a de strftime(3).)
MON_{1–12} (LC_TIME)
Retourne le nom du n-ième mois. (Utilisé dans la spécification de conversion %B de strftime(3).)
ABMON_{1–12} (LC_TIME)
Retourne le nom abrégé du n-ième mois. (Utilisé dans la spécification de conversion %b de strftime(3).)
RADIXCHAR (LC_NUMERIC)
Retourne le caractère de radical (point décimal, virgule décimale, etc.).
THOUSEP (LC_NUMERIC)
Retourne le caractère séparateur des milliers (groupes de trois chiffres).
YESEXPR (LC_MESSAGES)
Retourne une expression régulière qui peut être utilisée avec la fonction regex(3) pour reconnaître une réponse positive à une question oui/non.
NOEXPR (LC_MESSAGES)
Retourne une expression régulière qui peut être utilisée avec la fonction regex(3) pour reconnaître une réponse négative à une question oui/non.
CRNCYSTR (LC_MONETARY)
nl_langinfo_l(3) — man pages

NOM

nl_langinfo_l, nl_langinfo, nl_langinfo_stdin, nl_langinfo_stdout, nl_langinfo_stderr - interroger des informations sur les paramètres régionaux spécifiques

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <langinfo.h>
char *nl_langinfo_l(nl_item item, locale_t locale);
char *nl_langinfo(nl_item item);
char *nl_langinfo_stdin(nl_item item);
char *nl_langinfo_stdout(nl_item item);
char *nl_langinfo_stderr(nl_item item);

DESCRIPTION

La fonction nl_langinfo_l renvoie un pointeur vers une chaîne représentant une information spécifique aux paramètres régionaux, comme spécifié par item, dans les paramètres régionaux représentés par l'objet locale.

La fonction nl_langinfo est équivalente à nl_langinfo_l(item, duflt), où duflt est la valeur de la macro duflt définie dans <locale.h>. Le comportement des fonctions nl_langinfo_stdin, nl_langinfo_stdout, et nl_langinfo_stderr est défini pour interroger les paramètres régionaux de la catégorie LC_UNIVERSAL, LC_ALL, LC_CTYPE et LC_NUMERIC qui ont été définis respectivement pour les flux d'entrée standard, de sortie standard et d'erreur standard.

La macro nl_item spécifie l'élément d'information régional à récupérer. Les valeurs possibles pour item incluent:

VALEUR RETOURNÉE

En cas de succès, ces fonctions renvoient un pointeur vers une chaîne qui correspond à la valeur de item dans les paramètres régionaux spécifiés.

Si aucun paramètre régional n'a été sélectionné par setlocale(3) pour la catégorie appropriée, nl_langinfo() renvoie un pointeur vers la chaîne correspondante dans les paramètres régionaux "C". Il en va de même pour nl_langinfo_l() si locale spécifie des paramètres régionaux où les données langinfo ne sont pas définies.

Si item n'est pas valide, un pointeur vers une chaîne vide est renvoyé.

Le pointeur renvoyé par ces fonctions peut pointer vers des données statiques qui peuvent être écrasées, ou le pointeur lui-même peut être invalidé, par un appel ultérieur à nl_langinfo(), nl_langinfo_l(), ou setlocale(3). Les mêmes déclarations s'appliquent à nl_langinfo_l() si l'objet de paramètres régionaux référencé par locale est libéré ou modifié par freelocale(3) ou newlocale(3).

POSIX spécifie que l'application ne doit pas modifier la chaîne renvoyée par ces fonctions.

NOTES

Le comportement de nl_langinfo_l() est indéfini si locale est l'objet de paramètres régionaux spécial LC_GLOBAL_LOCALE ou n'est pas un handle d'objet de paramètres régionaux valide.

EXEMPLES

Le programme suivant définit le type de caractère et les paramètres régionaux numériques en fonction de l'environnement et interroge le jeu de caractères du terminal et le caractère de séparation des décimales.

#include <langinfo.h>
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
int
main(void)
{
    setlocale(LC_CTYPE, "");
    setlocale(LC_NUMERIC, "");
    printf("%s\n", nl_langinfo(CODESET));
    printf("%s\n", nl_langinfo(RADIXCHAR));
    exit(EXIT_SUCCESS);
}
