NOM

nl-pktloc-lookup - Recherche les définitions d'emplacement de paquet

SYNTAXE

nl-pktloc-lookup nom
nl-pktloc-lookup --list

DESCRIPTION

nl-pktloc-lookup recherche dans la base de données des emplacements de paquet une entrée correspondante. Il est utilisé pour résoudre les alias d'emplacement de paquet vers leur définition, c'est-à-dire l'alignement, la couche, le décalage et le masque.

OPTIONS

-h ou --help
Affiche le texte d'aide sur la console et quitte.
-v ou --version
Affiche les informations de version sur la console et quitte.
-l ou --list
Liste toutes les définitions d'emplacement de paquet.
--u32=VALEUR
Affiche la définition de l'emplacement du paquet dans un format spécial compris par l'analyseur de sélecteur u32 de iproute2. Il générera un sélecteur u32 qui comparera la valeur fournie à la valeur spécifiée par l'emplacement du paquet.

Veuillez noter qu'en raison de la limitation de u32, il n'est pas possible d'utiliser les emplacements de paquet basés sur la couche de liaison. nl-pktloc-lookup affichera un message d'erreur dans ce cas.

Exemple :
sélecteur=$(nl-pktloc-lookup --u32 22 tcp.sport)
tc filter add [...] u32 match $(sélecteur) flowid 1:2

FICHIERS

/etc/libnl/pktloc
