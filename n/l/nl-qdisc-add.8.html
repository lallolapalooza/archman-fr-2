nl-qdisc(8) Manuel du gestionnaire système nl-qdisc(8)

NOM

nl-qdisc-{add|list|delete} - Gérer les disciplines de mise en file d'attente

SYNTAXE

nl-qdisc-add --dev dev --parent id [OPTIONS] type-qdisc [QDISC]

nl-qdisc-delete [ --interactive ] [OPTIONS]

nl-qdisc-list [OPTIONS]

DESCRIPTION

Les outils nl-qdisc permettent de gérer et de configurer les disciplines de mise en file d'attente (qdiscs) dans le noyau.

OPTIONS

-h ou --help
Affiche le texte d'aide sur la console et quitte.
-v ou --version
Affiche les informations de version sur la console et quitte.
-q ou --quiet
Ne pas afficher les notifications informelles sur les actions entreprises sur la console. Pour le moment, une courte description de chaque qdisc ajouté/mis à jour/supprimé sera affichée sur la console. Cette option désactive ce comportement.
-d ou --dev=DEV
Périphérique réseau auquel le qdisc est attaché.
-p ou --parent=ID
Identifiant du qdisc parent/classe auquel ce qdisc est attaché. L'identifiant peut être spécifié comme classid, nom ou l'une des valeurs spéciales "root" ou "ingress".
-i ou --id=ID
Identifiant du qdisc. Il peut être spécifié comme classid ou nom.

Options de nl-qdisc-add

--update
Met à jour le qdisc s'il existe déjà, sinon, tenter d'ajouter un qdisc qui existe déjà entraînera une erreur. Cela n'inclut pas la modification du type du qdisc, utilisez --replace si vous souhaitez le faire.
--replace
Remplace ou met à jour le qdisc s'il existe déjà. Comportement identique à --update, mais remplacera complètement le qdisc s'il existe déjà.
--update-only
Met à jour un qdisc existant mais ne le crée pas s'il n'existe pas.
--replace-only
Met à jour ou remplace un qdisc existant mais ne le crée pas s'il n'existe pas.

Options de nl-qdisc-delete

--interactive
Le mode interactif nécessite une confirmation de l'utilisateur pour chaque qdisc supprimé. Il affichera une invite pour chaque qdisc correspondant au filtre fourni et nécessitera que l'utilisateur réponde 'o'ui ou 'n'on.
--yes
Fait en sorte que la réponse par défaut pour les invites interactives soit 'o'ui. Cette option est également nécessaire pour supprimer tous les qdiscs sur tous les périphériques réseau.
-k ou --kind=TYPE
Ne supprime que les qdiscs de ce type.

Options de nl-qdisc-list

--details
Affiche des informations détaillées pour chaque qdisc listé.
--stats
Affiche des informations statistiques pour chaque qdisc listé. Cette option activera également automatiquement les informations détaillées.
-r ou --recursive
Liste tous les objets TC récursivement attachés à tous les qdiscs correspondant au filtre.
-k ou --kind=TYPE
Ne liste que les qdiscs de ce type.

UTILISATION

Ajouter un qdisc racine HTB avec l'identifiant "5:" :

nl-qdisc-add --dev eth0 --parent root --id 5: htb

Lister tous les qdiscs sur eth0 et afficher les données statistiques :

nl-qdisc-list --stats --dev eth0

Supprimer le qdisc "5:" :

nl-qdisc-delete --id 5:
