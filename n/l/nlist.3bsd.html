nlist(3bsd)

Paquet: libbsd

Licences: custom

nlist(3bsd) 3bsd nlist(3bsd)

NOM

nlist — récupérer la liste des noms de la table des symboles d'un fichier exécutable

BIBLIOTHÈQUE

bibliothèque « libbsd »

SYNTAXE

#include <nlist.h> (Voir libbsd(7) pour l'utilisation de l'include.)
int
nlist(const char *filename, struct nlist *nl);

DESCRIPTION

La fonction nlist() récupère les entrées de la liste de noms de la table des symboles d'un fichier exécutable (voir elf(5)). L'argument nl est défini pour référencer le début de la liste. La liste est épurée des données binaires et invalides ; si une entrée de la liste des noms est valide, le n_type et le n_value de l'entrée sont copiés dans la liste référencée par nl. Aucune autre donnée n'est copiée. La dernière entrée de la liste est toujours NULL.

VALEURS DE RETOUR

Le nombre d'entrées invalides est retourné en cas de succès ; sinon, si le fichier filename n'existe pas ou n'est pas exécutable, ou si le pointeur nl est NULL, la valeur retournée est -1.

VOIR AUSSI

elf(5)

HISTORIQUE

Une fonction nlist() est apparue dans Version 6 AT&T UNIX.
