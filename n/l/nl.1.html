NL(1) Commandes utilisateur NL(1)

NOM

nl - numéroter les lignes de fichiers

SYNTAXE

nl [OPTION]... [FICHIER]...

DESCRIPTION

Écrit chaque FICHIER sur la sortie standard, en ajoutant des numéros de ligne.

Sans FICHIER, ou lorsque FICHIER est -, lit l'entrée standard.

Les arguments obligatoires pour les options longues sont aussi obligatoires pour les options courtes.

-b, --numérotation-corps=STYLE
utilise STYLE pour numéroter les lignes du corps
-d, --délimiteur-section=CC
utilise CC pour les délimiteurs de page logique
-f, --numérotation-pied-de-page=STYLE
utilise STYLE pour numéroter les lignes de pied de page
-h, --numérotation-en-tête=STYLE
utilise STYLE pour numéroter les lignes d'en-tête
-i, --incrément-ligne=NOMBRE
incrément de numéro de ligne à chaque ligne
-l, --regrouper-lignes-vides=NOMBRE
regroupe NOMBRE lignes vides comptées comme une seule
-n, --format-numéro=FORMAT
insère les numéros de ligne selon le FORMAT
-p, --pas-renumérotage
ne réinitialise pas les numéros de ligne pour chaque section
-s, --séparateur-numéro=CHAÎNE
ajoute CHAÎNE après le numéro de ligne (possible)
-v, --numéro-ligne-début=NOMBRE
premier numéro de ligne pour chaque section
-w, --largeur-numéro=NOMBRE
utilise NOMBRE colonnes pour les numéros de ligne
--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte

Les options par défaut sont : -bt -d'\:' -fn -hn -i1 -l1 -n'rn' -s<TAB> -v1 -w6

CC sont deux caractères délimiteurs utilisés pour construire les délimiteurs de page logique ; un second caractère manquant implique ':'. En tant qu'extension GNU, on peut spécifier plus de deux caractères, et aussi spécifier la chaîne vide (-d '') désactive la correspondance de section.

STYLE est l'un des suivants :

a
numéroter toutes les lignes
t
numéroter seulement les lignes non vides
n
ne numéroter aucune ligne
pBRE
numéroter seulement les lignes qui contiennent une correspondance avec l'expression régulière de base, BRE

FORMAT est l'un des suivants :

ln
justifié à gauche, sans zéros initiaux
rn
justifié à droite, sans zéros initiaux
rz
justifié à droite, avec zéros initiaux
