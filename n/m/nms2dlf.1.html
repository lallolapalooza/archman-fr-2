NOM

nms2dlf - convertir les fichiers journaux SMTP de Netscape Messaging Server en DLF d'email

SYNTAXE

nms2dlf STDIN STDOUT

DESCRIPTION

Ce programme convertit les fichiers journaux du service SMTP de Netscape Messaging Server au format DLF d'email.

Pour traiter correctement le fichier journal, vous devez activer la journalisation des modules suivants :

- SMTP-Accept
- SMTP-Deliver
- Error-Handler
- Mailbox-Deliver (Doit être activé)

LIMITATIONS

Ce convertisseur DLF a été développé pour Netscape Messaging Server version 4.1. D'autres versions peuvent fonctionner ou non. Contactez les développeurs de LogReport si vous rencontrez des problèmes avec ce convertisseur.

Vous pouvez trouver des informations sur le format des journaux utilisé par Netscape Messaging Server à l'URL suivante :

http://developer.netscape.com/docs/manuals/messaging/41/ag/logging.htm

Tous les messages ne sont pas documentés. Et nous avons trouvé des erreurs dans la documentation. Les champs msgID et mailFrom sont inversés dans SMTP-Accept et SMTP-Deliver par rapport à ce que décrit la documentation.

CONFIGURATION DE LA JOURNALISATION DU MODULE MAILBOX-DELIVER

Nous avons constaté qu'il n'y avait pas de journaux du module Mailbox-Delivery par défaut. Pour résoudre ce problème, assurez-vous de faire ce qui suit :

1.
Accédez au serveur MTA ou Message Store de Netscape Messaging Server 4
2.
Connectez-vous en tant qu'utilisateur du serveur de messagerie (généralement, ce ne devrait pas être root, mais plutôt un utilisateur comme mailsrv ou quel que soit celui défini lors de l'installation, vérifiez par exemple la propriété des fichiers dans votre instance de serveur de messagerie)
3.
Allez au bon endroit, quelque chose comme : server-root/msg-instance

Par exemple, cela pourrait être : /usr/netscape/server4/msg-mymailserver

4.
Exécutez : 
$ ./configutil -o service.smtp.mailbox-deliver.log -v yes
OK SET
5.
Puis devenez root, retournez dans votre répertoire d'instance comme : /usr/netscape/server4/msg-mymailserver et exécutez : 
# ./stop-msg smtp
/usr/netscape/server4: Stopping SMTP daemon 16279 .... done: 16279
# ./start-msg smtp
/usr/netscape/server4: Starting SMTP daemon ..... done: 10820

Et ensuite, vous commencerez à voir des lignes ressemblant à ce qui suit :

[19/Jul/2002:08:31:54 +0200] amail2 smtpd[10820]: \
General Notice: SMTP-Accept:GZHGT501.C01:<200207190632.g6J6W7Y01389@\
esmtp.orangemail.ch>:[192.168.30.2]:192.168.30.2: \
<newsletter@gamezone.com>:19514:1:<hmarmy@orangemail.ch>
[19/Jul/2002:08:31:54 +0200] amail2 smtpd[10820]: General Notice: \
Mailbox-Deliver:GZHGT501.C01:<200207190632.g6J6W7Y01389@\
esmtp.orangemail.ch>:19516:1:hmarmy;

Si cela n'a pas été fait, la ligne avec le motif Mailbox-Deliver ci-dessus ne sera pas présente et le programme donnera des résultats incorrects. Un avertissement sera affiché dans le journal d'erreurs.

EXEMPLES

Pour traiter un journal tel que produit par Netscape Messaging Server :

$ nms2dlf < mail.log

nms2dlf sera rarement utilisé seul, mais sera plus probablement appelé par lr_log2report :

$ lr_log2report nms < /var/log/mail.log
