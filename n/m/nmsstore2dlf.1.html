NOM

nmsstore2dlf - convertir les fichiers de log IMAP ou POP du Netscape Messaging Server au DLF msgstore de Lire

SYNOPSIS

nmsstore2dlf

DESCRIPTION

Ce programme convertit les fichiers de log du Netscape Messaging Server générés par les services IMAP ou POP au format DLF msgstore de Lire.

LIMITATIONS

Pour que ce parseur vous fournisse des informations utiles, il est recommandé de régler les logs NMS 4 au bon niveau. Pour résoudre ce problème, veuillez vous assurer que vous avez fait ce qui suit.

Aller sur le Netscape Messaging Server 4 Message Store

Devenir l'utilisateur du serveur de messagerie (généralement, ce ne devrait pas être root, mais typiquement un utilisateur comme mailsrv ou celui défini lors de l'installation, vérifiez par exemple la propriété des fichiers dans votre instance de serveur de messagerie)

Aller au bon endroit, quelque chose comme :
server-root/msg-instance

Par exemple, cela pourrait être :
/usr/netscape/server4/msg-mymailserver

Faire :

$ ./configutil -o logfile.pop.loglevel -v Informational
OK SET
$ ./configutil -o logfile.imap.loglevel -v Informational
OK SET

Ensuite, devenir root, aller de nouveau dans votre répertoire d'instance comme :
/usr/netscape/server4/msg-mymailserver

et faire :

# ./stop-msg pop
/mailserv1fs/netscape/server4: Stopping POP3 daemon 24789 .... done: 24789
# ./start-msg pop
/mailserv1fs/netscape/server4: Starting POP3 daemon .... done: 17509

EXEMPLES

Pour traiter un log tel que produit par Netscape Messaging Server :

$ nmsstore2dlf < ns-store.log

nmsstore2dlf sera rarement utilisé seul, mais est plus susceptible d'être appelé par lr_log2report :

$ lr_log2report nmsstore < /var/log/ns-store.log > report
