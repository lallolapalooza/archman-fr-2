NOM

nm-online - demander à NetworkManager si le réseau est connecté

SYNTAXE

nm-online [OPTIONS...]

DESCRIPTION

nm-online est un utilitaire pour savoir si nous sommes en ligne. Cela se fait en interrogeant NetworkManager sur son état. Lors de l'exécution, nm-online attend que NetworkManager signale une connexion active ou que le délai spécifié expire. À la sortie, le code de retour doit être vérifié (voir les codes de retour ci-dessous).

Cet outil n'est pas très utile à appeler directement. Il est cependant utilisé par NetworkManager-wait-online.service avec l'argument --wait-for-startup (voir NetworkManager-wait-online.service(8)).

Par défaut, les connexions ont les propriétés ipv4.may-fail et ipv6.may-fail définies sur yes ; cela signifie que NetworkManager attend que l'une des deux familles d'adresses termine sa configuration avant de considérer la connexion comme activée. Si vous avez besoin qu'une famille d'adresses spécifique soit configurée avant que la cible network-online.target ne soit atteinte, définissez la propriété correspondante may-fail sur no.

OPTIONS

-h | --help

Affiche les informations d'aide.

-q | --quiet

Ne rien afficher.

-s | --wait-for-startup

Attend que le démarrage de NetworkManager soit terminé, plutôt que d'attendre spécifiquement la connectivité réseau. Le démarrage est considéré comme terminé une fois que NetworkManager a activé (ou tenté d'activer) toutes les connexions à activation automatique qui sont disponibles compte tenu de l'état actuel du réseau. Cela correspond au moment où NetworkManager enregistre « startup complete ». Ce mode est généralement utile uniquement au démarrage. Une fois le démarrage terminé, nm-online -s se termine immédiatement, quel que soit l'état actuel du réseau.

Il existe plusieurs façons d'influencer le moment où le démarrage est considéré comme terminé. Pour plus de détails, voir NetworkManager-wait-online.service(8).

-t | --timeout secondes

Temps d'attente d'une connexion, en secondes. Si l'option n'est pas fournie, la variable d'environnement NM_ONLINE_TIMEOUT est respectée. Le délai d'attente par défaut est de 30 secondes.

-x | --exit

Quitte immédiatement si NetworkManager ne fonctionne pas ou ne se connecte pas.

STATUT DE SORTIE

nm-online se termine avec le statut 0 en cas de succès, une valeur supérieure à 0 est retournée si une erreur se produit.

0

Succès – déjà en ligne ou connexion établie dans le délai imparti.

1

Hors ligne ou pas en ligne dans le délai imparti.

2

Erreur inconnue ou non spécifiée.

VOIR AUSSI

nmcli(1), NetworkManager(8), NetworkManager-wait-online.service(8).
