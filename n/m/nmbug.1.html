NOM

nmbug - gérer les bugs notmuch avec git

SYNTAXE

notmuch git [-h] [-N] [-C repo] [-p préfixe] [-v] [-l niveau de log] sous-commande

nmbug [-h] [-C repo] [-p préfixe] [-v] [-l niveau de log] sous-commande

DESCRIPTION

Gérer les tags notmuch avec Git.

OPTIONS

Options prises en charge pour notmuch git incluent

-h, --help
afficher le message d'aide et quitter
-N, --nmbug
Définir les valeurs par défaut pour --tag-prefix et --git-dir adaptées au traqueur de bugs notmuch
-C <repo>, --git-dir <repo>
Opérer sur le dépôt git repo. Voir EMPLACEMENT DU RÉPERTOIRE pour les valeurs par défaut.
-p <préfixe>, --tag-prefix <préfixe>
Opérer uniquement sur les tags ayant le préfixe préfixe. Voir VALEUR DU PRÉFIXE pour les valeurs par défaut.
-v, --version
afficher le numéro de version de notmuch-git et quitter
-l <niveau>, --log-level <niveau>
Verbosité du journal, l'un des suivants : critical, error, warning, info, debug. La valeur par défaut est warning.

status

Affiche les mises à jour en attente dans la base de données notmuch ou le dépôt git.

Imprime des lignes de la forme

ng Message-Id tag

où n est un caractère unique représentant l'état de la base de données notmuch

A

Le tag est présent dans la base de données notmuch, mais pas validé dans git (équivalent, le tag a été supprimé dans le dépôt git, par exemple par un pull, mais pas restauré dans la base de données notmuch).

D

Le tag est présent dans le dépôt git, mais pas restauré dans la base de données notmuch (équivalent, le tag a été supprimé dans notmuch).

U

Le message est inconnu (absent de la base de données notmuch locale).

Le second caractère g (s'il est présent) représente une différence entre les branches locales et distantes. Typiquement, notmuch git fetch doit être exécuté pour mettre à jour cela.

a

Le tag est présent dans la branche distante, mais pas dans la branche git locale.

d

Le tag est présent dans la branche git locale, mais pas dans la branche distante.

CONTENU DU RÉPERTOIRE

Les tags sont stockés dans le dépôt git (et exportés) sous forme d'un ensemble de fichiers vides. Ces fichiers vides sont contenus dans un répertoire nommé d'après l'identifiant du message.

Dans ce qui suit, encode() représente un encodage sûr pour le système de fichiers POSIX. L'encodage conserve les alphanumériques et les caractères +-_@=.,:. Tous les autres octets sont remplacés par % suivi d'un nombre hexadécimal à deux chiffres.

Actuellement, notmuch-git peut lire n'importe quelle version de format, mais ne peut créer (via init) que des dépôts de version 1.

Version 0

C'est le format hérité créé par l'outil nmbug avant la version 0.37. Pour un message avec l'identifiant Message-Id id, pour chaque tag tag, il existe un fichier vide avec le chemin

tags/ encode (id) / encode (tag)

Version 1

Dans le format version 1 et ultérieur, la version du format est contenue dans un fichier de premier niveau appelé FORMAT.

Pour un message avec l'identifiant Message-Id id, pour chaque tag tag, il y a un fichier vide avec le chemin

tags/ hash1 (id) / hash2 (id) encode (id) / encode (tag)

Les fonctions de hachage représentent chacune un octet du résumé hexadécimal de blake2b.

Comparé à la version 0, cela réduit le nombre de sous-répertoires dans chaque répertoire.

EMPLACEMENT DU RÉPERTOIRE

notmuch-git utilise le premier des éléments suivants ayant une valeur non vide pour localiser le dépôt git.

  • Option --git-dir.
  • Variable d'environnement NOTMUCH_GIT_DIR.
  • Élément de configuration git.path
  • S'il est appelé comme nmbug ou avec l'option --nmbug, $HOME/.nmbug ; sinon $XDG_DATA_HOME/notmuch/$NOTMUCH_PROFILE/git.

VALEUR DU PRÉFIXE

notmuch-git utilise le premier des éléments suivants ayant une valeur non nulle pour définir le préfixe de tag.

  • Option --tag-prefix.
  • Variable d'environnement NOTMUCH_GIT_PREFIX.
  • Élément de configuration git.tag_prefix.
  • S'il est appelé comme nmbug ou avec l'option --nmbug, notmuch::, sinon la chaîne vide.

ENVIRONNEMENT

La variable NOTMUCH_PROFILE influence l'EMPLACEMENT DU RÉPERTOIRE. Si elle n'est pas définie, 'default' est supposé.

NOTMUCH_GIT_DIR
Emplacement par défaut du dépôt git. Remplacé par --git-dir.
NOTMUCH_GIT_PREFIX
Préfixe de tag par défaut (filtre). Remplacé par --tag-prefix.
