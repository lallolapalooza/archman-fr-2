NOM

nmsmmp2dlf - convertir les fichiers journaux MMP de Netscape Messaging Server au format DLF de Lire

SYNOPIS

nmsmmp2dlf

DESCRIPTION

Ce programme lit les fichiers journaux Netscape Messaging Server Mail Multi Plexor générés par les services IMAP ou POP sur STDIN, et imprime le DLF correspondant du magasin de messages Lire sur STDOUT.

Il prend en charge les champs suivants du schéma du magasin de messages : time, localserver, client_ip, user, session, protocol, prot_cmd et status.

EXEMPLES

Pour traiter un journal tel que produit par Netscape Messaging Server :

$ nmsmmp2dlf < ns-smmp.log

nmsmmp2dlf sera rarement utilisé seul, mais sera plus probablement appelé par lr_log2report :

$ lr_log2report nmsmmp < /var/log/ns-smmp.log > report
