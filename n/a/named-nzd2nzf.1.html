NOM

named-nzd2nzf - convertir une base de données NZD au format texte NZF

SYNTAXE

named-nzd2nzf {nom_fichier}

DESCRIPTION

named-nzd2nzf convertit une base de données NZD au format NZF et l'imprime sur la sortie standard. Ceci peut être utilisé pour examiner la configuration des zones qui ont été ajoutées à named <#std-iscman-named> via rndc addzone <#cmdoption-rndc-arg-addzone>. Il peut aussi être utilisé pour restaurer l'ancien format de fichier lors d'un retour en arrière d'une version plus récente de BIND vers une version plus ancienne.

ARGUMENTS

nom_fichier
C'est le nom du fichier .nzd dont le contenu doit être imprimé.
