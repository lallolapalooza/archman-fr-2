NOM

Run Software - outil d'aide

SYNTAXE

nautilus-autorun-software uri-de-montage

DESCRIPTION

nautilus-autorun-software est un outil d'aide pour le bureau GNOME afin de démarrer des logiciels à partir de médias contenant des fichiers Autostart.

C'est le gestionnaire par défaut pour "x-content/unix-software" pour le bureau GNOME.

VOIR AUSSI

Les fichiers Autostart sont décrits sur https://specifications.freedesktop.org/autostart-spec/autostart-spec-latest.html

BOGUES

Les rapports de bogues peuvent être trouvés et soumis sur https://gitlab.gnome.org/GNOME/nautilus/issues
