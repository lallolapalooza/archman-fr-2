NANORC(5) Manuel des formats de fichiers NANORC(5)

NOM

nanorc - Fichier de configuration de GNU nano

DESCRIPTION

Les fichiers nanorc contiennent les paramètres par défaut de nano, un éditeur de texte petit et convivial. Au démarrage, si --rcfile n'est pas spécifié, nano lit deux fichiers : d'abord les paramètres globaux du système, depuis /etc/nanorc (le chemin exact peut varier sur votre système), puis les paramètres spécifiques à l'utilisateur, soit depuis ~/.nanorc, soit depuis $XDG_CONFIG_HOME/nano/nanorc, soit depuis ~/.config/nano/nanorc, selon l'ordre de rencontre. Si --rcfile est spécifié, nano ne lit que le fichier de paramètres indiqué.

REMARQUE

Depuis la version 8.0, afin d'être plus convivial pour les nouveaux venus, ^F démarre une recherche avant, ^B démarre une recherche arrière, M-F recherche l'occurrence suivante en avant, et M-B recherche l'occurrence suivante en arrière. Si vous souhaitez que ces combinaisons de touches fassent ce qu'elles faisaient avant la version 8.0, ajoutez les lignes suivantes à la fin de votre fichier nanorc :

bind ^F forward main
bind ^B back main
bind M-F formatter main
bind M-B linter main

OPTIONS

Le fichier de configuration accepte une série de commandes set et unset, qui peuvent être utilisées pour configurer nano au démarrage sans utiliser les options de ligne de commande. De plus, il existe des commandes pour définir la coloration syntaxique et pour reconfigurer les touches — voir les deux sections distinctes à ce sujet. nano lit une commande par ligne. Toutes les commandes et mots-clés doivent être écrits en minuscules.

Les options dans les fichiers nanorc ont priorité sur les paramètres par défaut de nano, et les options de ligne de commande outrepassent les paramètres nanorc. De plus, les options qui ne prennent pas d'argument sont désactivées par défaut. Ainsi, l'utilisation de la commande unset n'est nécessaire que lorsque vous souhaitez outrepasser un paramètre du fichier nanorc du système dans votre propre fichier nanorc. Les options qui prennent un argument ne peuvent pas être désactivées.

Les guillemets dans les paramètres characters ci-dessous ne doivent pas être échappés. Le dernier guillemet double sur la ligne sera considéré comme le guillemet fermant.

Les commandes et arguments supportés sont :

set afterends
Fait en sorte que Ctrl+Droite et Ctrl+Suppr s'arrêtent à la fin des mots au lieu de leur début.
set allow_insecure_backup
Lors de la sauvegarde de fichiers, autorise la sauvegarde à réussir même si ses permissions ne peuvent pas être (re)définies en raison de considérations spécifiques au système d'exploitation. Vous ne devriez PAS activer cette option sauf si vous êtes sûr d'en avoir besoin.
set atblanks
Lorsque le retour à la ligne automatique est activé, fait le retour à la ligne sur les caractères d'espacement (tabulations et espaces) au lieu de toujours au bord de l'écran.
set autoindent
Indente automatiquement une nouvelle ligne créée avec le même nombre de tabulations et/ou d'espaces que la ligne précédente (ou que la ligne suivante si la ligne précédente est le début d'un paragraphe).
set backup
Lors de la sauvegarde d'un fichier, crée un fichier de sauvegarde en ajoutant un tilde (~) au nom du fichier.
set backupdir directory
Crée et conserve non pas un seul fichier de sauvegarde, mais un fichier uniquement numéroté à chaque fois qu'un fichier est sauvegardé — lorsque les sauvegardes sont activées avec set backup ou --backup ou -B. Les fichiers numérotés de manière unique sont stockés dans le répertoire spécifié.
set boldtext
Utilise le gras au lieu de la vidéo inversée pour la barre de titre, la barre de statut, la barre d'invite, la mini-barre, les combinaisons de touches, les numéros de ligne et le texte sélectionné. Ceci peut être outrepassé en définissant les options titlecolor, statuscolor, promptcolor, minicolor, keycolor, numbercolor, et/ou selectedcolor.
set bookstyle
Lors de la justification, traite toute ligne commençant par un espace comme le début d'un paragraphe (sauf si l'indentation automatique est activée).
set brackets "characters"
Définit les caractères traités comme des parenthèses fermantes lors de la justification des paragraphes. Cela peut ne pas inclure les caractères d'espacement. Seule la ponctuation fermante (voir set punct), éventuellement suivie des parenthèses fermantes spécifiées, peut terminer les phrases. La valeur par défaut est ""')>]}".
set breaklonglines
Retourne automatiquement à la ligne le texte courant lorsqu'il dépasse une certaine longueur.
set casesensitive
Effectue les recherches en tenant compte de la casse par défaut.
set colonparsing
Lorsqu'un nom de fichier donné sur la ligne de commande se termine par un deux-points suivi de chiffres et que ce nom de fichier n'existe pas, alors on coupe le deux-points suivi des chiffres et on considère les chiffres comme un numéro de ligne. Si le nom de fichier tronqué n'existe pas non plus, alors on répète le processus et on considère les deux nombres obtenus comme numéro de ligne et de colonne. Mais si le nom de fichier doublement tronqué n'existe pas non plus, alors on oublie le tronquage et on accepte le nom de fichier original tel quel. Pour désactiver ce passage par deux-points pour un fichier donné, utiliser +1 ou similaire avant le nom de fichier pertinent.
set constantshow
Rapporte constamment la position du curseur sur la barre de statut. Ceci outrepasse l'option quickblank.
set cutfromcursor
Utilise par défaut la coupure du curseur à la fin de la ligne, au lieu de couper la ligne entière.
set emptyline
N'utilise pas la ligne sous la barre de titre, la laissant entièrement vide.
set errorcolor [bold,][italic,]fgcolor,bgcolor
Utilise cette combinaison de couleurs pour la barre de statut lorsqu'un message d'erreur est affiché. La valeur par défaut est bold,white,red. Voir set titlecolor pour les noms de couleurs valides.
set fill number
Définit la largeur cible pour la justification et le retour automatique à la ligne à ce nombre de colonnes. Si la valeur est 0 ou moins, le retour à la ligne se produit à la largeur de l'écran moins nombre de colonnes, permettant au point de retour de varier avec la largeur de l'écran si celui-ci est redimensionné. La valeur par défaut est -8.
set functioncolor [bold,][italic,]fgcolor,bgcolor
Utilise cette combinaison de couleurs pour les descriptions concises de fonctions dans les deux lignes d'aide en bas de l'écran. Voir set titlecolor pour plus de détails.
set guidestripe number
Dessine une bande verticale à la colonne donnée, pour aider à juger de la largeur du texte. (La couleur de la bande peut être modifiée avec set stripecolor.)
set historylog
Enregistre les cent dernières chaînes de recherche et de remplacement ainsi que les commandes exécutées, afin qu'elles puissent être facilement réutilisées dans les sessions ultérieures.
set indicator
Affiche un "ascenseur" sur le côté droit de la fenêtre d'édition. Il indique la position de la vue dans le tampon et la quantité de tampon couverte par la vue.
set jumpyscrolling
Fait défiler le contenu du tampon par demi-écran au lieu de par ligne.
set keycolor [bold,][italic,]fgcolor,bgcolor
Utilise cette combinaison de couleurs pour les combinaisons de touches de raccourci dans les deux lignes d'aide en bas de l'écran. Voir set titlecolor pour plus de détails.
set linenumbers
Affiche les numéros de ligne à gauche
de la zone de texte. (Toute ligne avec une ancre reçoit également une marque dans la marge.)
set locking
Active les fichiers de verrouillage de style vim lors de l'édition de fichiers.
set magic
Lorsque ni le nom du fichier ni sa première ligne ne donnent un indice, essaie d'utiliser libmagic pour déterminer la syntaxe applicable. (L'appel à libmagic peut être relativement long. Il n'est donc pas effectué par défaut.)
set matchbrackets "caractères"
Spécifie les parenthèses ouvrantes et fermantes qui peuvent être trouvées par les recherches de parenthèses. Cela peut ne pas inclure les caractères d'espacement. L'ensemble ouvrant doit précéder l'ensemble fermant, et les deux ensembles doivent être dans le même ordre. La valeur par défaut est "(<[{)>]}".
set minibar
Supprime la barre de titre et affiche à la place des informations sur le tampon actuel en bas de l'écran, dans l'espace réservé à la barre d'état. Dans cette « mini barre », le nom de fichier est affiché à gauche, suivi d'un astérisque si le tampon a été modifié. À droite sont affichés le numéro de ligne et de colonne actuels, le code du caractère sous le curseur (en format Unicode : U+xxxx), les mêmes indicateurs que ceux affichés par set stateflags, et un pourcentage qui exprime la distance du curseur dans le fichier (par ligne). Lorsqu'un fichier est chargé ou sauvegardé, et également lors du passage d'un tampon à l'autre, le nombre de lignes du tampon est affiché après le nom du fichier. Ce nombre est effacé lors de la prochaine frappe, ou remplacé par un compteur [i/n] lorsque plusieurs tampons sont ouverts. Les numéros de ligne et de colonne et le code de caractère ne sont affichés que lorsque set constantshow est utilisé, et peuvent être activés et désactivés avec M-C. Les indicateurs d'état ne sont affichés que lorsque set stateflags est utilisé.
set minicolor [bold,][italic,]couleur_avant,couleur_arrière
Utilise cette combinaison de couleurs pour la mini barre. (Lorsque cette option n'est pas spécifiée, les couleurs de la barre de titre sont utilisées.) Voir set titlecolor pour plus de détails.
set mouse
Active la prise en charge de la souris, si elle est disponible pour votre système. Lorsqu'elle est activée, les clics de souris peuvent être utilisés pour placer le curseur, définir la marque (avec deux clics) et exécuter des raccourcis. La souris fonctionne dans le système X Window, et sur la console lorsque gpm est en cours d'exécution. Le texte peut toujours être sélectionné par glisser-déposer en maintenant la touche Maj enfoncée.
set multibuffer
Lors de la lecture d'un fichier avec ^R, l'insère dans un nouveau tampon par défaut.
set noconvert
Ne convertit pas les fichiers du format DOS/Mac.
set nohelp
N'affiche pas les deux lignes d'aide en bas de l'écran.
set nonewlines
N'ajoute pas automatiquement de nouvelle ligne lorsqu'un texte ne se termine pas par une. (Cela peut vous amener à sauvegarder des fichiers texte non-POSIX.)
set nowrap
Option obsolète car elle est devenue le réglage par défaut. Si nécessaire, utilisez unset breaklonglines à la place.
set numbercolor [bold,][italic,]couleur_avant,couleur_arrière
Utilise cette combinaison de couleurs pour les numéros de ligne. Voir set titlecolor pour plus de détails.
set operatingdir répertoire
Au démarrage, fait en sorte que nano change pour le répertoire donné, et autorise la lecture et l'écriture de fichiers uniquement dans ce répertoire et ses sous-répertoires.
set positionlog
Sauvegarde les positions du curseur et des ancres entre les sessions d'édition. Ces positions sont mémorisées pour les 200 fichiers les plus récemment édités.
set preserve
Préserve les séquences XOFF et XON (^S et ^Q) afin qu'elles soient interceptées par le terminal (arrêt et reprise de la sortie).
set promptcolor [bold,][italic,]couleur_avant,couleur_arrière
Utilise cette combinaison de couleurs pour la barre d'invite. (Lorsque cette option n'est pas spécifiée, les couleurs de la barre de titre sont utilisées.) Voir set titlecolor pour plus de détails.
set punct "caractères"
Définit les caractères traités comme des ponctuations de fin lors de la justification des paragraphes. Cela peut ne pas inclure les caractères d'espacement. Seule la ponctuation de fin spécifiée, éventuellement suivie de parenthèses fermantes (voir set brackets), peut terminer les phrases. La valeur par défaut est "!.?".
set quickblank
Fait disparaître les messages de la barre d'état après 1 frappe au lieu de 20. Notez que l'option constantshow a priorité. Lorsque l'option minibar ou zero est activée, quickblank fait disparaître un message après 0,8 seconde au lieu de 1,5 seconde par défaut.
set quotestr "regex"
Définit l'expression régulière pour faire correspondre la partie de citation d'une ligne. La valeur par défaut est "^([ \t]*([!#%:;>|}]|//))+". (Notez que \t représente un caractère Tab réel.) Cela permet de réjustifier des blocs de texte cité lors de la composition d'e-mails, et de reformater des blocs de commentaires de ligne lors de l'écriture de code source.
set rawsequences
Interprète directement les séquences d'échappement, au lieu de demander à ncurses de les traduire. (Si vous avez besoin de cette option pour que certaines touches fonctionnent correctement, cela signifie que la description de terminal terminfo utilisée ne correspond pas entièrement au comportement réel de votre terminal. Cela peut arriver lorsque vous vous connectez via ssh à une machine BSD, par exemple.) L'utilisation de cette option désactive la prise en charge de la souris par nano.
set rebinddelete
Interprète les touches Suppr et Retour arrière différemment afin que Retour arrière et Suppr fonctionnent correctement. Vous ne devriez utiliser cette option que lorsque sur votre système, soit Retour arrière agit comme Suppr, soit Suppr agit comme Retour arrière.
set regexp
Effectue des recherches d'expressions régulières par défaut. Les expressions régulières dans nano sont de type étendu (ERE).
set saveonexit
Sauvegarde automatiquement un tampon modifié à la sortie (^X) ; ne demande pas.
set scrollercolor couleur_avant,couleur_arrière
Utilise cette combinaison de couleurs pour l'alias de l'indicateur « barre de défilement ». Voir set titlecolor pour plus de détails.
set selectedcolor [bold,][italic,]couleur_avant,couleur_arrière
Utilise cette combinaison de couleurs pour le texte sélectionné. Voir set titlecolor pour plus de détails.
set showcursor
Place le curseur sur l'élément mis en surbrillance dans le navigateur de fichiers, et affiche le curseur dans le visualiseur d'aide, pour aider les utilisateurs de braille et les personnes ayant une mauvaise vue.
set smarthome
Rend la touche Début plus intelligente. Lorsque Début est pressée n'importe où sauf au tout début des caractères non-espacés d'une ligne, le curseur saute à ce début (vers l'avant ou vers l'arrière). Si le curseur est déjà à cette position, il saute au vrai début de la ligne.
set softwrap
Affiche les lignes qui dépassent la largeur de l'écran sur plusieurs lignes d'écran. (Vous pouvez faire en sorte que ce retour à la ligne douce se produise aux espaces blancs au lieu de rudement au bord de l'écran, en utilisant également set atblanks.)
set speller "programme [argument ...]"
Utilise le programme donné pour la vérification orthographique et la correction, au lieu d'utiliser le correcteur intégré qui appelle hunspell(1) ou spell(1).
set spotlightcolor [bold,][italic,]couleur_avant,couleur_arrière
Utilise cette combinaison de couleurs pour mettre en surbrillance une correspondance de recherche. La valeur par défaut est black,lightyellow. Voir set titlecolor pour les noms de couleurs valides.
set stateflags
Utilise le coin supérieur droit de l'écran pour afficher certains indicateurs d'état : I lorsque l'indentation automatique est activée, M lorsque la marque est activée, L lorsque le retour à la ligne forcé (coupure des lignes longues) est activé, R lorsque l'enregistrement d'une macro est en cours, et S lorsque le retour à la ligne doux est activé. Lorsque le tampon est modifié, une étoile (*) est affichée après le nom du fichier au centre de la barre de titre.
set statuscolor [bold,][italic,]couleur_avant,couleur_arrière
Utilise cette combinaison de couleurs pour la barre d'état. Voir set titlecolor pour plus de détails.
set stripecolor [bold,][italic,]couleur_avant,couleur_arrière
Utilise cette combinaison de couleurs pour la bande de guidage verticale. Voir set titlecolor pour plus de détails.
set tabsize nombre
Utilise une taille de tabulation de nombre colonnes. La valeur de nombre doit être supérieure à 0. La valeur par défaut est 8.
set tabstospaces
Convertit chaque tabulation tapée en espaces — au nombre d'espaces qu'une tabulation à cette position occuperait. (Note : les tabulations collées ne sont pas converties.)
set titlecolor [bold,][italic,]couleur_avant,couleur_arrière
Utilise cette combinaison de couleurs pour la barre de titre. Les noms valides pour les couleurs de premier plan et d'arrière-plan sont : red, green, blue, magenta, yellow, cyan, white, et black. Chacun de ces huit noms peut être préfixé par le mot light pour obtenir une version plus lumineuse de cette couleur. Le mot <

Le mot grey ou gray peut être utilisé comme synonyme de lightblack. Sur une console Linux, light n'a aucun effet sur la couleur de fond. Sur les émulateurs de terminaux capables d'au moins 256 couleurs, d'autres noms de couleurs valides (mais non préfixables) sont : pink, purple, mauve, lagoon, mint, lime, peach, orange, latte, rosy, beet, plum, sea, sky, slate, teal, sage, brown, ocher, sand, tawny, brick, crimson et normal — où normal signifie la couleur de premier plan ou d'arrière-plan par défaut. Sur de tels émulateurs, la couleur peut également être spécifiée sous forme d'un nombre hexadécimal à trois chiffres préfixé par #, les chiffres représentant respectivement les quantités de rouge, de vert et de bleu. Ceci dit à nano de sélectionner dans la palette disponible la couleur qui s'approche des valeurs données.

Soit "fgcolor" soit ",bgcolor" peut être omis, et la paire peut être précédée de bold et/ou italic (séparés par des virgules) pour obtenir une graisse et/ou une police penchée, si votre terminal le supporte.

set trimblanks
Supprimer les espaces blancs de fin de ligne lors du retour à la ligne automatique ou lors de la justification du texte.
set unix
Enregistrer un fichier par défaut au format Unix. Ceci remplace le comportement par défaut de nano qui est d'enregistrer un fichier dans le format qu'il avait. (Cette option n'a aucun effet lorsque vous utilisez aussi set noconvert.)
set whitespace "caractères"
Définir les deux caractères utilisés pour indiquer la présence de tabulations et d'espaces. Ils doivent être des caractères sur une seule colonne. La paire par défaut pour une locale UTF-8 est "»⋅", et pour les autres locales ">.".
set wordbounds
Détecter les frontières de mots différemment en traitant les caractères de ponctuation comme faisant partie des mots.
set wordchars "caractères"
Spécifier quels autres caractères (outre les caractères alphanumériques normaux) doivent être considérés comme faisant partie des mots. Lorsque vous utilisez cette option, vous voudrez probablement désactiver wordbounds.
set zap
Laisser une touche Retour arrière ou Suppr non modifiée effacer la région marquée (au lieu d'un seul caractère, et sans affecter le presse-papiers).
set zero
Masquer tous les éléments de l'interface (barre de titre, barre d'état et lignes d'aide) et utiliser toutes les lignes du terminal pour afficher le contenu du tampon. La barre d'état n'apparaît que lorsqu'il y a un message significatif, et disparaît après 1,5 seconde ou après la prochaine frappe. Avec M-Z, la barre de titre plus la barre d'état peuvent être activées/désactivées. Avec M-X, les lignes d'aide.

MISE EN ÉVIDENCE DE LA SYNTAXE

La coloration des différents éléments syntaxiques d'un fichier se fait via des expressions régulières (voir la commande color ci-dessous). Ceci est intrinsèquement imparfait, car les expressions régulières ne sont pas assez puissantes pour analyser complètement un fichier. Néanmoins, les expressions régulières peuvent faire beaucoup et sont faciles à créer, elles conviennent donc bien à un petit éditeur comme nano.

Toutes les expressions régulières dans nano sont des expressions régulières étendues POSIX. Cela signifie que ., ?, *, +, ^, $, et plusieurs autres caractères sont spéciaux. Le point . correspond à n'importe quel caractère unique, ? signifie que l'élément précédent est facultatif, * signifie que l'élément précédent peut être trouvé zéro fois ou plus, + signifie que l'élément précédent doit être trouvé une fois ou plus, ^ correspond au début d'une ligne, et $ à la fin, \< correspond au début d'un mot, et \> à la fin, et \s correspond à un espace blanc. Cela signifie également que les lookaheads et lookbehinds ne sont pas possibles. Une explication complète peut être trouvée dans la page de manuel de GNU grep : man grep.

Chaque expression régulière dans un fichier nanorc doit être entourée de guillemets doubles (""). Plusieurs expressions régulières peuvent se suivre sur une ligne en les séparant par des espaces. Cela signifie qu'une expression régulière ne peut pas contenir un guillemet double suivi d'un espace. Lorsque vous avez besoin de cette combinaison à l'intérieur d'une expression régulière, soit le guillemet double soit l'espace doit être placé entre crochets ([]).

Pour chaque type de fichier, une syntaxe distincte peut être définie via les commandes suivantes :

syntax nom ["fileregex" ...]
Commencer la définition d'une syntaxe avec ce nom. Toutes les commandes color et autres commandes similaires qui suivent sont ajoutées à cette syntaxe, jusqu'à ce qu'une nouvelle commande syntax soit rencontrée.

Lorsque nano est exécuté, cette syntaxe est automatiquement activée (pour le tampon concerné) si le nom de fichier absolu correspond à l'expression régulière étendue fileregex. Ou bien la syntaxe peut être explicitement activée (pour tous les tampons) en utilisant l'option de ligne de commande -Y ou --syntax suivie du nom.

La syntaxe default est spéciale : elle ne prend pas de fileregex et s'applique aux fichiers qui ne correspondent à aucune des expressions régulières d'une syntaxe. La syntaxe none est réservée ; la spécifier sur la ligne de commande équivaut à ne pas avoir de syntaxe du tout.

header "regex" ...
Si aucune fileregex parmi toutes les syntaxes définies n'a correspond, alors comparer cette regex (ou ces regex) à la première ligne du fichier actuel, pour déterminer si cette syntaxe doit être utilisée pour lui.
magic "regex" ...
Si aucune fileregex n'a correspondu et qu'aucune regex header n'a non plus correspondu, alors comparer cette regex (ou ces regex) au résultat de la requête à la base de données magic concernant le fichier actuel, pour déterminer si cette syntaxe doit être utilisée pour lui. (Cette requête n'est effectuée que si libmagic est effectivement installé sur le système et que --magic ou set magic a été spécifié.)
formatter programme [argument ...]
Exécuter le programme donné sur le contenu complet du tampon actuel.
linter programme [argument ...]
Utiliser le programme donné pour effectuer une vérification de la syntaxe sur le tampon actuel.
comment "chaîne"
Utiliser la chaîne donnée pour commenter et décommenter des lignes. Si la chaîne contient un caractère de barre verticale ou pipe (|), cela définit des commentaires de type "parenthèses" ; par exemple, "/*|*/" pour les fichiers CSS. Les caractères avant le pipe sont ajoutés au début de la ligne et les caractères après le pipe sont ajoutés à la fin de la ligne. S'il n'y a pas de caractère pipe, la chaîne entière est ajoutée ; par exemple, "#" pour les fichiers Python. Si des guillemets doubles vides sont spécifiés, la fonction de commentaire/décommentage est désactivée ; par exemple, "" pour JSON. Les commentaires sont basés sur les premiers caractères de la ligne. La valeur par défaut est "#".
tabgives "chaîne"
Faire en sorte que la touche <Tab> produise la chaîne donnée. Utile pour les langages comme Python qui veulent voir uniquement des espaces pour l'indentation. Ceci remplace le paramètre de l'option tabstospaces.
color [bold,][italic,]couleur_premier_plan,couleur_fond "regex" ...
Peindre tous les morceaux de texte qui correspondent à l'expression régulière étendue regex avec les couleurs de premier plan et d'arrière-plan données, dont au moins une doit être spécifiée. Les noms de couleurs valides sont : red, green, blue, magenta, yellow, cyan, white et black. Chacun de ces huit noms peut être préfixé par le mot light pour obtenir une version plus brillante de cette couleur. Le mot grey ou gray peut être utilisé comme synonyme de lightblack. Sur une console Linux, light n'a aucun effet sur la couleur d'arrière-plan. Sur les émulateurs de terminaux capables d'au moins 256 couleurs, d'autres noms de couleurs valides (mais non préfixables) sont : pink, purple, mauve, lagoon, mint, lime, peach, orange, latte, rosy, beet, plum, sea, sky, slate, teal, sage, brown, ocher, sand, tawny, brick, crimson et normal — où normal signifie la couleur de premier plan ou d'arrière-plan par défaut. Sur de tels émulateurs, la couleur peut également être spécifiée sous forme d'un nombre hexadécimal à trois chiffres préfixé par #, les chiffres représentant respectivement les quantités de rouge, de vert et de bleu. Ceci dit à nano de sélectionner dans la palette disponible la couleur qui s'approche des valeurs données.

La paire de couleurs peut être précédée de bold et/ou italic (séparés par des virgules) pour obtenir une graisse et/ou une police penchée, si votre terminal le supporte.

Toutes les commandes de coloration sont appliquées dans l'ordre dans lequel elles sont spécifiées, ce qui signifie que les commandes ultérieures peuvent recolorer des éléments colorés précédemment.

icolor [bold,][italic,]couleur_premier_plan,couleur_fond "regex" ...
Identique à ci-dessus, sauf que la correspondance est insensible à la casse.
color [bold,][italic,]couleur_premier_plan,couleur_fond start="fromrx" end="torx"
Peindre tous les morceaux de texte dont le début correspond à l'expression régulière étendue fromrx et dont la fin correspond à l'expression régulière étendue torx avec les couleurs de premier plan et d'arrière-plan données, dont au moins une doit être spécifiée. Cela signifie qu'après une instance initiale de fromrx, tout le texte jusqu'à la première instance de torx est coloré. Ceci permet à la mise en évidence de la syntaxe de s'étendre sur plusieurs lignes.
icolor [bold,][italic,]couleur_premier_plan,couleur_fond
color,bgcolor start="fromrx" end="torx"
Identique à ci-dessus, sauf que la correspondance ne tient pas compte de la casse.
include "fichier_syntaxe"
Lire des syntaxes de couleur autonomes à partir de fichier_syntaxe. Notez que fichier_syntaxe peut contenir uniquement les commandes ci-dessus, de syntax à icolor.
extendsyntax nom commande argument ...
Étendre la syntaxe précédemment définie sous le nom nom avec une autre commande. Cela permet d'ajouter une nouvelle commande color, icolor, header, magic, formatter, linter, comment ou tabgives à une syntaxe déjà définie — utile lorsque vous souhaitez améliorer légèrement une syntaxe définie dans l'un des fichiers installés par le système (qui ne sont normalement pas modifiables).

RÉASSOCIATION DES TOUCHES

Les associations de touches peuvent être modifiées via les trois commandes suivantes :

bind touche fonction menu
Réassocie la touche donnée à la fonction donnée dans le menu donné (ou dans tous les menus où la fonction existe lorsque all est utilisé).
bind touche "chaîne" menu
Fait en sorte que la touche donnée produise la chaîne donnée dans le menu donné (ou dans tous les menus où la touche existe lorsque all est utilisé). Outre le texte littéral et/ou les codes de contrôle, la chaîne peut contenir des noms de fonctions entre accolades. Ces fonctions sont appelées lorsque la touche est tapée. Pour inclure une accolade ouvrante littérale, utilisez {{}.
unbind touche menu
Supprime l'association de la touche donnée avec le menu donné (ou avec tous les menus où la touche existe lorsque all est utilisé).

Notez que bind touche "{fonction}" menu équivaut à bind touche fonction menu, sauf que pour cette dernière forme nano vérifie la disponibilité de la fonction dans le menu donné au démarrage (et signale une erreur si elle n'existe pas là), tandis que pour la première forme, nano vérifie à l'exécution que la fonction existe mais pas si elle a un sens dans le menu actuel. L'utilisateur doit veiller à ce qu'un nom de fonction entre accolades (ou une séquence d'entre eux) soit approprié. Un comportement étrange, voire un plantage, peut en résulter lorsque le nom entre accolades est inapproprié.

Le format de touche doit être l'un des suivants :
^X
où X est une lettre latine, ou l'un des plusieurs caractères ASCII (@, ], \, ^, _), ou le mot "Space". Exemple : ^C.
M-X
où X est un caractère ASCII quelconque sauf [, ou le mot "Space". Exemple : M-8.
Sh-M-X
où X est une lettre latine. Exemple : Sh-M-U. Par défaut, chaque frappe Meta+lettre fait la même chose que la combinaison Shift+Meta+lettre correspondante. Mais lorsqu'une association Shift+Meta est faite, ce ne sera plus le cas, pour toutes les lettres.
FN
où N est une valeur numérique de 1 à 24. Exemple : F10. (Souvent, F13 à F24 peuvent être tapés comme F1 à F12 avec Shift.)
Ins ou Del.

Il est probablement déconseillé de réassocier ^M (Entrée) ou ^I (Tab). Il n'est pas possible de réassocier ^[ (Échap), car son code de touche est l'octet de départ des frappes Meta et des séquences d'échappement. Il n'est pas possible de réassocier les touches dédiées au déplacement du curseur (les flèches, Début, Fin, Page précédente et Page suivante). Sur certains terminaux, il n'est pas possible de réassocier ^H (sauf si --raw est utilisé) car son code de touche est identique à celui de la touche Retour arrière.

Les noms de fonction valides à associer sont :

savefile

insert

whereis
Démarre une recherche avant dans le tampon actuel — ou des noms de fichiers correspondant à une chaîne dans la liste actuelle du navigateur de fichiers.
wherewas
Démarre une recherche arrière dans le tampon actuel — ou des noms de fichiers correspondant à une chaîne dans la liste actuelle du navigateur de fichiers.
findprevious
Recherche l'occurrence suivante dans la direction arrière.
findnext
Recherche l'occurrence suivante dans la direction avant.
replace
Remplace interactivement du texte dans le tampon actuel.
cut

copy

paste

chopwordleft
Supprime depuis la position du curseur jusqu'au début du mot précédent. (Cette fonction est associée par défaut à <Shift+Ctrl+Delete>. chopwordright
Supprime depuis la position du curseur jusqu'au début du mot suivant. (Cette fonction est associée par défaut à <Ctrl+Delete>.)
cutrestoffile
Coupe tout le texte depuis la position du curseur jusqu'à la fin du tampon.
mark
Définit la marque à la position actuelle, pour commencer à sélectionner du texte. Ou, lorsqu'elle est définie, la désélectionne.
location
Rapporte la position actuelle du curseur dans le tampon : la ligne, la colonne et les positions de caractères.
wordcount
Compte et rapporte dans la barre d'état le nombre de lignes, de mots et de caractères dans le tampon actuel (ou dans la région marquée).
execute
Demande un programme à exécuter. La sortie du programme est insérée dans le tampon actuel — ou dans un nouveau tampon lorsque M-F est activé. Lorsque le nom du programme est précédé d'un symbole pipe (|), alors le tampon actuel (ou la région marquée) est envoyé au programme via pipe, et la sortie du programme remplace le tampon (ou la région marquée).
speller
Appelle un programme de vérification orthographique, soit le programme par défaut hunspell(1), soit GNU spell(1), soit celui défini par --speller ou set speller.
formatter
Appelle un programme de traitement de tampon complet (si la syntaxe active en définit un). (Le tampon actuel est écrit dans un fichier temporaire, le programme est exécuté dessus, puis le fichier temporaire est relu, remplaçant le contenu du tampon.)
linter
Appelle un programme de vérification de syntaxe (si la syntaxe active en définit un). Si ce programme produit des lignes de la forme "nomfichier:numéro_ligne:numéro_colonne: message", alors le curseur est placé à la position indiquée dans le fichier mentionné tout en affichant "message" sur la barre d'état. Vous pouvez passer d'un message à l'autre avec <PgUp> et <PgDn>, et quitter le mode linting avec ^C ou <Entrée>.
justify
Justifie le paragraphe actuel (ou la région marquée). Un paragraphe est un groupe de lignes contiguës qui, à l'exception peut-être de la première ligne, ont toutes la même indentation. Le début d'un paragraphe est détecté soit par cette ligne seule ayant une indentation différente, soit par une ligne vide précédente.
fulljustify
Justifie l'intégralité du tampon actuel (ou la région marquée).
indent
Indente (déplace vers la droite) la ligne actuelle ou les lignes marquées.
unindent
Désindente (déplace vers la gauche) la ligne actuelle ou les lignes marquées.
comment
Commente ou décommente la ligne actuelle ou les lignes marquées, en utilisant le style de commentaire spécifié dans la syntaxe active.
complete
Complète (quand c'est possible) le fragment avant le curseur en un mot entier trouvé ailleurs dans le tampon actuel.
gauche
Se déplace d'une position vers la gauche (dans l'éditeur ou le navigateur).
droite
Se déplace d'une position vers la droite (dans l'éditeur ou le navigateur).
haut
Se déplace d'une ligne vers le haut (dans l'éditeur ou le navigateur).
bas
Se déplace d'une ligne vers le bas (dans l'éditeur ou le navigateur).
scrollup
Fait défiler la fenêtre d'affichage d'une ligne vers le haut (ce qui signifie que le texte glisse vers le bas) tout en gardant le curseur dans la même position textuelle, si possible. scrolldown
Fait défiler la fenêtre d'affichage d'une ligne vers le bas (ce qui signifie que le texte glisse vers le haut) tout en gardant le curseur dans la même position textuelle, si possible. (Cette fonction est liée par défaut à <Alt+Bas>.)
center
Fait défiler la ligne contenant le curseur au milieu de la fenêtre d'affichage.
cycle
Fait défiler la ligne contenant le curseur d'abord au milieu de la fenêtre d'affichage, puis en haut, puis en bas.
prevword
Déplace le curseur au début du mot précédent.
nextword
Déplace le curseur au début du mot suivant.
home
Déplace le curseur au début de la ligne actuelle.
end
Déplace le curseur à la fin de la ligne actuelle.
beginpara
Déplace le curseur au début du paragraphe actuel.
endpara
Déplace le curseur à la fin du paragraphe actuel.
prevblock
Déplace le curseur au début du bloc de texte actuel ou précédent. (Les blocs sont séparés par une ou plusieurs lignes vides.)
nextblock
Déplace le curseur au début du bloc de texte suivant.
toprow
Déplace le curseur à la première ligne de la fenêtre d'affichage.
bottomrow
Déplace le curseur à la dernière ligne de la fenêtre d'affichage.
pageup
Remonte d'un écran.
pagedown
Descend d'un écran.
firstline
Se déplace à la première ligne du fichier.
lastline
Se déplace à la dernière ligne du fichier.
gotoline
Se déplace à une ligne spécifique (et colonne si spécifiée). Un nombre négatif compte à partir de la fin du tampon (et de la fin de la ligne). Placer ++ ou -- avant le premier nombre sautera le nombre de lignes indiqué vers l'avant ou vers l'arrière.
findbracket
Déplace le curseur vers le caractère (crochet, accolade, parenthèse, etc.) qui correspond (apparie) celui sous le curseur. Voir set matchbrackets.
anchor
Place une ancre à la ligne actuelle, ou la supprime si elle est déjà présente. (Une ancre est visible lorsque les numéros de ligne sont activés.)
prevanchor
Se déplace à la première ancre avant la ligne actuelle.
nextanchor
Se déplace à la première ancre après la ligne actuelle.
prevbuf
Passe à l'édition/visualisation du tampon précédent lorsque plusieurs tampons sont ouverts.
nextbuf
Passe à l'édition/visualisation du tampon suivant lorsque plusieurs tampons sont ouverts.
verbatim
Insère la prochaine combinaison de touches telle quelle dans le fichier, ou commence la saisie Unicode lorsqu'un chiffre hexadécimal est tapé.
tab
Insère une tabulation à l'emplacement actuel du curseur.
enter
Insère une nouvelle ligne sous la ligne actuelle.
delete
Supprime le caractère sous le curseur.
backspace
Supprime le caractère avant le curseur.
recordmacro
Démarre l'enregistrement des frappes – les frappes sont stockées sous forme de macro. Si l'enregistrement est déjà en cours, il s'arrête.

Rejoue les frappes de la dernière macro enregistrée.
undo
Annule la dernière action de texte effectuée (ajout de texte, suppression de texte, etc.).
redo
Rétablit la dernière action annulée (c'est-à-dire qu'il annule une annulation).

Commute entre la recherche/remplacement ignorant ou respectant la casse des caractères donnés.
regexp
Commute entre la recherche/remplacement utilisant des chaînes littérales ou des expressions régulières.
backwards
Commute entre la recherche/remplacement allant vers l'avant ou vers l'arrière.
older
Récupère l'entrée précédente (plus ancienne) à une invite.
newer

flipreplace
Commute entre la recherche de quelque chose et le remplacement de quelque chose.
flipgoto
Commute entre la recherche de texte et le ciblage d'un numéro de ligne.

Passe de l'insertion d'un fichier à l'exécution d'une commande.

Lors de l'exécution d'une commande, commute si le tampon actuel (ou la région marquée) est envoyé en flux vers la commande.

EXEMPLES

Pour que Ctrl+Z suspende nano :

bind ^Z suspend main

Pour que Shift+Alt+C copie la région marquée dans le presse-papiers du système :

bind Sh-M-C "{execute}| xsel -ib {enter}{undo}" main
