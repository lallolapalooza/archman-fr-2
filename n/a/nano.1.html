NANO(1) Manuel des commandes générales NANO(1)

NOM

nano - L'AUTre éditeur de texte de Nano, inspiré par Pico

SYNTAXE

nano [options] [[+ligne[,colonne]] fichier]...

nano [options] [[+[crCR]{/|?}chaîne] fichier]...

AVIS

Depuis la version 8.0, pour être convivial pour les nouveaux arrivants, ^F lance une recherche avant, ^B lance une recherche arrière, M-F recherche l'occurrence suivante vers l'avant, et M-B recherche l'occurrence suivante vers l'arrière. Si vous souhaitez que ces combinaisons de touches fassent ce qu'elles faisaient avant la version 8.0, ajoutez les lignes suivantes à la fin de votre fichier nanorc :

bind ^F forward main
bind ^B back main
bind M-F formatter main
bind M-B linter main

DESCRIPTION

nano est un éditeur de texte petit et convivial. Il copie l'apparence de Pico, mais est un logiciel libre et implémente plusieurs fonctionnalités qui manquent à Pico, telles que : l'ouverture de plusieurs fichiers, le défilement par ligne, l'annulation/rétablissement, la coloration syntaxique, la numérotation des lignes et le retour à la ligne automatique des lignes trop longues.

Lorsqu'un nom de fichier est donné sur la ligne de commande, le curseur peut être placé sur une ligne spécifique en ajoutant le numéro de ligne avec un signe plus (+) avant le nom de fichier, et même dans une colonne spécifique en l'ajoutant avec une virgule. Les nombres négatifs sont comptés à partir de la fin du fichier ou de la ligne.

Le curseur peut être placé sur la première ou la dernière occurrence d'une chaîne spécifique en spécifiant cette chaîne après +/ ou +? avant le nom de fichier. La chaîne peut être sensible à la casse et/ou interprétée comme une expression régulière en insérant c et/ou r après le signe +. Ces modes de recherche peuvent être explicitement désactivés en utilisant la variante majuscule de ces lettres : C et/ou R. Lorsque la chaîne contient des espaces, elle doit être entourée de guillemets. Pour donner un exemple : pour ouvrir un fichier à la première occurrence du mot "Foo", vous feriez :

nano +c/Foo fichier

Cas particulier : si un tiret (-) est donné à la place d'un nom de fichier, nano lira les données de l'entrée standard.

ÉDITION

La saisie de texte et le déplacement dans un fichier sont simples : tapez les lettres et utilisez les touches de déplacement habituelles. Les commandes sont saisies en utilisant les touches Control (^) et Alt ou Meta (M-). Taper ^K supprime la ligne actuelle et la place dans le presse-papiers. Des ^K consécutifs placent toutes les lignes supprimées ensemble dans le presse-papiers. Tout déplacement du curseur ou l'exécution de toute autre commande entraîne l'écrasement du presse-papiers par le prochain ^K. Un ^U colle le contenu actuel du presse-papiers à la position actuelle du curseur.

Lorsqu'un bloc de texte plus précis doit être coupé ou copié, vous pouvez marquer son début avec ^6, déplacer le curseur jusqu'à sa fin (le texte marqué est mis en surbrillance), puis utiliser ^K pour le couper, ou M-6 pour le copier dans le presse-papiers. Vous pouvez également enregistrer le texte marqué dans un fichier avec ^O, ou le vérifier avec ^T^T.

Sur certains terminaux, le texte peut également être sélectionné en maintenant la touche Shift enfoncée tout en utilisant les touches fléchées. Maintenir la touche Ctrl ou Alt enfoncée augmente le pas. Tout déplacement du curseur sans la touche Shift enfoncée annule une telle sélection.

Tout point de code Unicode valide peut être inséré dans le buffer en tapant M-V suivi des chiffres hexadécimaux du point de code (conclu par <Espace> ou <Entrée> si moins de six chiffres). Un code de contrôle littéral (sauf ^J) peut être inséré en tapant M-V suivi de la touche pertinente.

Les deux lignes en bas de l'écran affichent certaines commandes importantes ; l'aide intégrée (^G) liste toutes les commandes disponibles. Les raccourcis clavier par défaut peuvent être modifiés via un fichier nanorc ; voir nanorc(5).

OPTIONS

-A, --smarthome
Rend la touche Home plus intelligente. Lorsque Home est pressée n'importe où sauf au tout début des caractères non-espaces sur une ligne, le curseur saute à ce début (vers l'avant ou vers l'arrière). Si le curseur est déjà à cette position, il saute au vrai début de la ligne.
-B, --backup
Lors de l'enregistrement d'un fichier, sauvegarde la version précédente de celui-ci, en utilisant le nom de fichier actuel suffixé par un tilde (~).
-C répertoire, --backupdir=répertoire
Crée et conserve non seulement une seule sauvegarde, mais en crée et conserve une numérotée de manière unique à chaque fois qu'un fichier est enregistré (lorsque les sauvegardes sont activées (-B)). Les fichiers numérotés de manière unique sont stockés dans le répertoire spécifié.
-D, --boldtext
Pour l'interface, utilise le gras au lieu de la vidéo inversée. Ceci peut être outrepassé pour des éléments spécifiques en définissant les options titlecolor, statuscolor, promptcolor, minicolor, keycolor, numbercolor, et/ou selectedcolor dans votre fichier nanorc. Voir nanorc(5).
-E, --tabstospaces
Convertit chaque tabulation tapée en espaces (selon le nombre d'espaces qu'une tabulation prendrait à cette position. (Note : les tabulations collées ne sont pas converties.))
-F, --multibuffer
Lit un fichier dans un nouveau buffer par défaut.
-G, --locking
Utilise le verrouillage de fichier de type vim lors de l'édition de fichiers.
-H, --historylog
Enregistre les cent dernières chaînes de recherche et de remplacement ainsi que les commandes exécutées, afin qu'elles puissent être facilement réutilisées lors des sessions ultérieures.
-I, --ignorercfiles
N'examine pas le nanorc du système ni le nanorc de l'utilisateur.
-J nombre, --guidestripe=nombre
Dessine une ligne verticale à la colonne donnée, pour aider à juger la largeur du texte. (La couleur de la ligne peut être changée avec set stripecolor dans votre fichier nanorc.)
-K, --rawsequences
Interprète les séquences d'échappement directement, au lieu de demander à ncurses de les traduire. (Si vous avez besoin de cette option pour que certaines touches fonctionnent correctement, cela signifie que la description du terminal terminfo utilisée ne correspond pas entièrement au comportement réel de votre terminal. Cela peut arriver lorsque vous vous connectez en ssh à une machine BSD, par exemple.) L'utilisation de cette option désactive le support de la souris de nano.
-L, --nonewlines
N'ajoute pas automatiquement de nouvelle ligne lorsqu'un texte ne se termine pas par une. (Cela peut vous amener à enregistrer des fichiers texte non-POSIX.)
-M, --trimblanks
Supprime les espaces blancs de fin de ligne lors du retour à la ligne automatique ou lors de la justification du texte.
-N, --noconvert
Désactive la conversion automatique des fichiers des formats DOS/Mac.
-O, --bookstyle
Lors de la justification, traite toute ligne commençant par un espace comme le début d'un paragraphe (sauf si l'indentation automatique est activée).
-P, --positionlog
Pour les 200 fichiers les plus récents, enregistre la dernière position du curseur et le replace à cette position lors de la réouverture de tels fichiers. Enregistre et restaure également les positions de toutes les ancres.
-Q

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

"expression régulière", --quotestr="expression régulière"
Définit l'expression régulière pour faire correspondre la partie citation d'une ligne. La valeur par défaut est "^([ \t]*([!#%:;>|}]|//))+". (Notez que \t représente une tabulation réelle.) Cela permet de réajuster des blocs de texte cités lors de la composition d'e-mails, et de reformater des blocs de commentaires de ligne lors de l'écriture de code source.
-R, --restricted
Mode restreint : ne lit ni n'écrit aucun fichier non spécifié dans la ligne de commande. Cela signifie : ne pas lire ni écrire les fichiers d'historique ; ne pas autoriser la mise en veille ; ne pas autoriser la vérification orthographique ; ne pas autoriser l'ajout ou le prepend à un fichier, ni sa sauvegarde sous un nom différent s'il en a déjà un ; et ne pas créer de fichiers de sauvegarde. Le mode restreint peut également être activé en invoquant nano avec un nom commençant par 'r' (par exemple, "rnano").
-S, --softwrap
Affiche sur plusieurs lignes d'écran les lignes qui dépassent la largeur de l'écran. (Vous pouvez faire en sorte que ce retour à la ligne automatique se produise aux espaces blancs au lieu de rudement au bord de l'écran, en utilisant également --atblanks.)
-T nombre, --tabsize=nombre
Définit la taille (largeur) d'une tabulation à nombre colonnes. La valeur de nombre doit être supérieure à 0. La valeur par défaut est 8.
-U, --quickblank
Fait disparaître les messages de la barre d'état après 1 frappe au lieu de 20. Notez que l'option -c (--constantshow) remplace celle-ci. Lorsque l'option --minibar ou --zero est activée, --quickblank fait disparaître un message après 0,8 seconde au lieu des 1,5 seconde par défaut.
-V, --version
Affiche le numéro de version actuel et quitte.
-W, --wordbounds
Détecte les limites de mots différemment en traitant les caractères de ponctuation comme faisant partie d'un mot.
-X "caractères", --wordchars="caractères"
Spécifie quels autres caractères (en plus des caractères alphanumériques normaux) doivent être considérés comme faisant partie d'un mot. Lorsque vous utilisez cette option, vous voulez probablement omettre -W (--wordbounds).
-Y nom, --syntax=nom
Spécifie le nom de la coloration syntaxique à utiliser parmi ceux définis dans les fichiers nanorc.
-Z, --zap
Laisse une touche Retour arrière ou Suppr non modifiée effacer la région marquée (au lieu d'un caractère unique, et sans affecter le buffer de coupe).
-a, --atblanks
Lors de l'habillage de ligne automatique, retourne les lignes aux espaces blancs au lieu de toujours au bord de l'écran.
-b, --breaklonglines
Retourne automatiquement la ligne actuelle lorsqu'elle devient trop longue. (Cette option est l'inverse de -w (--nowrap) — la dernière donnée prend effet.)
-c, --constantshow
Rapporte constamment la position du curseur sur la barre d'état. Notez que cela remplace l'option -U (--quickblank).
-d, --rebinddelete
Interprète les touches Suppr et Retour arrière différemment afin que Retour arrière et Suppr fonctionnent correctement. Vous ne devriez utiliser cette option que lorsque, sur votre système, Retour arrière agit comme Suppr ou Suppr agit comme Retour arrière.
-e, --emptyline
N'utilise pas la ligne sous la barre de titre, la laissant entièrement vide.
-f fichier, --rcfile=fichier
Lit uniquement ce fichier pour définir les options de nano, au lieu de lire les fichiers nanorc système et utilisateur.
-g, --showcursor
Rend le curseur visible dans le navigateur de fichiers (le plaçant sur l'élément mis en surbrillance) et dans le visualiseur d'aide. Utile pour les utilisateurs de braille et les personnes malvoyantes.
-h, --help
Affiche un résumé des options de ligne de commande disponibles et quitte.
-i, --autoindent
Indente automatiquement une nouvelle ligne avec le même nombre de tabulations et/ou d'espaces que la ligne précédente (ou que la ligne suivante si la ligne précédente est le début d'un paragraphe).
-j, --jumpyscrolling
Fait défiler le contenu du buffer par demi-écran au lieu de par ligne.
-k, --cutfromcursor
Fait en sorte que la commande 'Couper le texte' (normalement ^K) coupe de la position actuelle du curseur jusqu'à la fin de la ligne, au lieu de couper la ligne entière.
-l, --linenumbers
Affiche les numéros de ligne à gauche de la zone de texte. (Toute ligne comportant une ancre reçoit en plus une marque dans la marge.)
-m, --mouse
Active la prise en charge de la souris, si disponible pour votre système. Lorsqu'elle est activée, les clics de souris peuvent être utilisés pour placer le curseur, définir la marque (avec un double clic) et exécuter des raccourcis. La souris fonctionne dans le système X Window, et sur la console lorsque gpm est en cours d'exécution. Le texte peut toujours être sélectionné par glisser-déposer en maintenant la touche Maj enfoncée.
-n, --noread
Traite tout nom donné dans la ligne de commande comme un nouveau fichier. Cela permet à nano d'écrire dans des tubes nommés : il commence avec un buffer vide et écrit dans le tube lorsque l'utilisateur sauvegarde le "fichier". De cette façon, nano peut être utilisé comme éditeur en combinaison avec, par exemple, gpg, sans avoir à écrire d'abord des données sensibles sur disque.
-o répertoire, --operatingdir=répertoire
Change pour le répertoire donné, et permet de lire et écrire des fichiers uniquement dans ce répertoire et ses sous-répertoires.
-p, --preserve
Conserve les séquences XOFF et XON (^S et ^Q) afin qu'elles soient interceptées par le terminal (arrêt et reprise de la sortie). Notez que l'option -/ (--modernbindings) remplace celle-ci.
-q, --indicator
Affiche une "barre de défilement" sur le côté droit de la fenêtre d'édition. Elle indique la position de la vue dans le buffer et la quantité de buffer couverte par la vue.
-r nombre, --fill=nombre
Définit la largeur cible pour la justification et le retour à la ligne automatique à ce nombre de colonnes. Si la valeur est 0 ou moins, le retour à la ligne se produit à la largeur de l'écran moins nombre colonnes, permettant au point de retour à la ligne de varier avec la largeur de l'écran si l'écran est redimensionné. La valeur par défaut est -8.
-s "programme [argument ...]", --speller="programme [argument ...]"
Utilise cette commande pour effectuer la vérification et la correction orthographique, au lieu d'utiliser le correcteur intégré qui appelle hunspell(1) ou spell(1).
-t, --saveonexit
Sauvegarde un buffer modifié sans demander confirmation (en quittant avec ^X).
-u, --unix
Sauvegarde un fichier par défaut au format Unix. Ceci remplace le comportement par défaut de nano qui est de sauvegarder un fichier dans le format qu'il avait. (Cette option n'a aucun effet lorsque vous utilisez également --noconvert.)
-v, --view
Affiche uniquement le fichier et désactive l'édition : mode lecture seule. Ce mode permet à l'utilisateur d'ouvrir également d'autres fichiers pour visualisation, sauf si --restricted est également donné.
-w, --nowrap
Ne pas retourner automatiquement la ligne actuelle lorsqu'elle devient trop longue. C'est le comportement par défaut. (Cette option est l'inverse de -b (--breaklonglines) — la dernière donnée prend effet.)
-x, --nohelp
N'affiche pas les deux lignes d'aide en bas de l'écran.
-y, --afterends
Fait en sorte que Ctrl+Droite et Ctrl+Suppr s'arrêtent aux fins de mot au lieu de débuts.
-z, --listsyntaxes
Liste les noms des syntaxes disponibles et quitte.
-!, --magic
Lorsque ni le nom du fichier ni sa première ligne ne donnent d'indice, essaie d'utiliser libmagic pour déterminer la syntaxe applicable.
-@, --colonparsing
Lorsqu'un nom de fichier donné dans la ligne de commande se termine par un deux-points suivi de chiffres et que ce nom de fichier n'existe pas, alors supprime les deux-points suivis des chiffres et comprend les chiffres comme un numéro de ligne. Si le nom de fichier tronqué n'existe pas non plus, alors répète le processus et comprend les deux nombres obtenus comme numéro de ligne et de colonne. Mais si le nom de fichier doublement tronqué n'existe pas non plus, alors oublie le tronquage et accepte le nom de fichier original tel quel. Pour désactiver ce traitement des deux-points pour un fichier donné, utilisez +1 ou similaire avant le nom de fichier pertinent.
-%, --stateflags
Utilise le coin supérieur droit de l'écran pour afficher certains indicateurs d'état : I pour l'indentation automatique, M lorsque la marque est activée, L lors du retour à la ligne automatique (rupture des lignes longues), R lors de l'enregistrement d'une macro, et S lors du retour à la ligne doux. Lorsque le buffer est modifié, une étoile (*) est affichée après le nom du fichier au centre de la barre de titre.
-_, --minibar
Supprime la barre de titre et affiche à la place des informations sur le buffer actuel en bas de l'écran, dans l'espace réservé à la barre d'état. Dans cette "mini barre", le nom du fichier est affiché à gauche, suivi d'un astérisque si le buffer a été modifié. À droite sont affichés la ligne et la colonne actuelles, le code du caractère sous le curseur (en format Unicode : U+xxxx), les mêmes indicateurs que ceux affichés par --stateflags, et un pourcentage qui exprime l'avancement du curseur dans le fichier (en lignes). OPTIONS

In addition to the command-line options described above, the following options are also available:

-c, --constantshow
When --zero is used, the status bar normally does not appear, except when there is a significant message. When --constantshow is used, the status bar is always shown. This is useful for seeing line and column numbers, and the character code, when editing text.
-C, --chop
When --constantshow is used, the line plus column numbers and the character code are displayed only when --constantshow is used, and can be toggled on and off with M-C. The state flags are displayed only when --stateflags is used.
-i, --autoindent
Enable auto-indentation. When this is enabled, the text you type is indented to the same level as the previous line. Use M-I to toggle this.
-l, --linenumbers
Display the line number of the current line, plus the total number of lines in the file. The line number is displayed after the filename when the file is loaded, or when switching between buffers, and is cleared upon the next keystroke, or replaced with an [i/n] counter when multiple buffers are open. The line number display can be toggled on and off with M-N. When the file is not saved, or edited, the number of lines in the buffer is displayed after the filename. This number is cleared upon the next keystroke, or replaced with an [i/n] counter when multiple buffers are open. The line plus column numbers and the character code are displayed only when --constantshow is used, and can be toggled on and off with M-C. The state flags are displayed only when --stateflags is used.
-m, --mouse
Enable mouse support. With mouse support enabled, you can use the mouse to position the cursor, select text, and trigger function keys. Use M-M to toggle this.
-p, --preserve
When nano is invoked with this option, and it crashes or is killed by a signal, it will attempt to save the current contents of the buffer to an emergency file. The emergency file is named nano.save if the buffer has no name, or adds a ".save" suffix to the current filename. If an emergency file with that name already exists, it adds ".save.1", ".save.2", etc., to make the name unique. In multibuffer mode, nano writes all open buffers to their respective emergency files. See also the NOTES section.
-q, --quiet
Suppresses the display of the version number and the startup messages. Use this option if you find the startup messages annoying.
-r, --remainder
When nano is invoked with this option, and it crashes or is killed by a signal, it will attempt to save the current contents of the buffer to an emergency file. The emergency file is named nano.save if the buffer has no name, or adds a ".save" suffix to the current filename. If an emergency file with that name already exists, it adds ".save.1", ".save.2", etc., to make the name unique. In multibuffer mode, nano writes all open buffers to their respective emergency files. Note that this option is overridden by -/ (--modernbindings). See also the NOTES section.
-S, --stateflags
Display the state flags (e.g., modified status, undo status) in the status bar. Use M-S to toggle this.
-V, --version
Print version information and exit.
-w, --nowrap
Disable automatic line wrapping. Long lines will not be wrapped, and will scroll horizontally. Use M-L to toggle this.
-x, --help
Display the help text. Use M-X to toggle this.
-Z, --suspend
Enable suspension of nano with ^Z. Default is enabled, reachable via ^T^Z. If you want a plain ^Z to suspend nano, add bind ^Z suspend main to your nanorc.
-0, --zero
Hide all elements of the interface (title bar, status bar, and help lines) and use all rows of the terminal for showing the contents of the buffer. The status bar appears only when there is a significant message, and disappears after 1.5 seconds or upon the next keystroke. With M-Z the title bar plus status bar can be toggled. With M-X the help lines.
-/, --modernbindings
Use key bindings similar to the ones that most modern programs use: ^X cuts, ^C copies, ^V pastes, ^Z undoes, ^Y redoes, ^F searches forward, ^G searches next, ^S saves, ^O opens a file, ^Q quits, and (when the terminal permits) ^H shows help. Furthermore, ^A sets the mark, ^R makes replacements, ^D searches previous, ^P shows the position, ^T goes to a line, ^W writes out a file, and ^E executes a command. Note that this overrides option -p (--preserve).

TOGGLES

Several of the above options can be switched on and off also while nano is running. For example, M-L toggles the hard-wrapping of long lines, M-S toggles soft-wrapping, M-N toggles line numbers, M-M toggles the mouse, M-I auto-indentation, and M-X the help lines. See at the end of the ^G help text for a complete list.

The M-X toggle is special: it works in all menus except the help viewer and the linter. All other toggles work in the main menu only.

FILES

When --rcfile is given, nano reads just the specified file for setting its options and syntaxes and key bindings. Without that option, nano reads two configuration files: first the system's nanorc (if it exists), and then the user's nanorc (if it exists), either ~/.nanorc or $XDG_CONFIG_HOME/nano/nanorc or ~/.config/nano/nanorc, whichever is encountered first. See nanorc(5) for more information on the possible contents of those files.

See /usr/share/nano/ and /usr/share/nano/extra/ for available syntax-coloring definitions.

NOTES

Suspension is enabled by default, reachable via ^T^Z. (If you want a plain ^Z to suspend nano, add bind ^Z suspend main to your nanorc.)

At a Yes-No prompt, ^Y can be used for "Yes", ^N for "No", and ^A for "All". These unlisted bindings work in any locale.

When you want to copy marked text from nano to the system's clipboard, see one of the examples in the nanorc(5) man page.

If no alternative spell checker command is specified on the command line nor in one of the nanorc files, nano checks the SPELL environment variable for one.

In some cases nano tries to dump the buffer into an emergency file. This happens mainly if nano receives a SIGHUP or SIGTERM or runs out of memory. It writes the buffer into a file named nano.save if the buffer didn't have a name already, or adds a ".save" suffix to the current filename. If an emergency file with that name already exists in the current directory, it adds ".save" plus a number (e.g. ".save.1") to the current filename in order to make it unique. In multibuffer mode, nano writes all open buffers to their respective emergency files.

If you have any question about how to use nano in some specific situation, you can ask on help-nano@gnu.org.

BUGS

The recording and playback of keyboard macros works correctly only on a terminal emulator, not on a Linux console (VT), because the latter does not by default distinguish modified from unmodified arrow keys.

Please report any other bugs that you encounter via:
https://savannah.gnu.org/bugs/?group=nano.

When nano crashes, it saves any modified buffers to emergency .save files. If you are able to reproduce the crash and you want to get a backtrace, define the environment variable NANO_NOCATCH.
