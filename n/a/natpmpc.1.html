natpmpc(1) Manuel des commandes générales natpmpc(1)

NOM

natpmpc - Client de test et définisseur de mappage pour la librairie NAT-PMP.

SYNTAXE

Afficher l'adresse IP publique :
natpmpc

Ajouter un mappage de port :
natpmpc -a <port public> <port privé> <protocole> [durée de vie]

DESCRIPTION

Pour supprimer un mappage, définissez-le avec une durée de vie de 0 secondes. Pour supprimer tous les mappages de votre machine, utilisez 0 comme port privé et durée de vie.
