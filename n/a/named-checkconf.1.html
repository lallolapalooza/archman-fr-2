NOM

named-checkconf - outil de vérification de la syntaxe du fichier de configuration de named

SYNOPSIS

named-checkconf [-achjklvz] [-p [-x ]] [-t répertoire] {fichier}

DESCRIPTION

named-checkconf vérifie la syntaxe, mais pas la sémantique, d'un fichier de configuration de named <#std-iscman-named>. Le fichier, ainsi que tous les fichiers qu'il inclut, sont analysés et vérifiés pour détecter les erreurs de syntaxe. Si aucun fichier n'est spécifié, /etc/named.conf est lu par défaut.

Note : les fichiers que named <#std-iscman-named> lit dans des contextes d'analyse séparés, tels que rndc.conf ou rndc.key, ne sont pas automatiquement lus par named-checkconf. Les erreurs de configuration dans ces fichiers peuvent empêcher named <#std-iscman-named> de démarrer, même si named-checkconf a réussi. Cependant, named-checkconf peut être exécuté sur ces fichiers explicitement.

OPTIONS

-a
Ne vérifie pas les algorithmes de clé DNSSEC de dnssec-policy par rapport à ceux pris en charge par le fournisseur de cryptographie. Ceci est utile lors de la vérification d'un named.conf destiné à être exécuté sur une autre machine avec potentiellement un ensemble différent d'algorithmes de clé DNSSEC pris en charge.
-h
Cette option affiche le résumé d'utilisation et quitte.
-j
Lors du chargement d'un fichier de zone, cette option demande à named <#std-iscman-named> de lire le journal s'il existe.
-k
Vérifie les clés DNSSEC de dnssec-policy par rapport aux fichiers de clé dans le key-directory. Ceci est utile lors de la vérification d'un named.conf pour s'assurer qu'une politique DNSSEC correspond aux clés existantes.
-l
Cette option liste toutes les zones configurées. Chaque ligne de sortie contient le nom de la zone, la classe (par exemple IN), la vue et le type (par exemple primaire ou secondaire).
-c
Cette option spécifie que seule la configuration « de base » doit être vérifiée. Cela supprime le chargement des modules plugins et ignore tous les paramètres des instructions plugin.
-i
Cette option ignore les avertissements sur les options obsolètes.
-p
Cette option affiche le fichier named.conf <#std-iscman-named.conf> et les fichiers inclus sous forme canonique si aucune erreur n'est détectée. Voir aussi l'option -x.
-t répertoire
Cette option demande à named <#std-iscman-named> de faire un chroot dans le répertoire, de sorte que les directives include dans le fichier de configuration soient traitées comme si elles étaient exécutées par un named <#std-iscman-named> chrooté de manière similaire.
-v
Cette option affiche la version du programme named-checkconf et quitte.
-x
Lors de l'affichage des fichiers de configuration sous forme canonique, cette option masque les secrets partagés en les remplaçant par des chaînes de points d'interrogation (?). Cela permet de partager le contenu de named.conf <#std-iscman-named.conf> et des fichiers associés - par exemple, lors de la soumission de rapports de bugs - sans compromettre les données privées. Cette option ne peut pas être utilisée sans -p.
-z
Cette option effectue un chargement de test de toutes les zones de type primary trouvées dans named.conf <#std-iscman-named.conf>.
fichier
Ceci indique le nom du fichier de configuration à vérifier. S'il n'est pas spécifié, il utilise /etc/named.conf par défaut.

VALEURS DE RETOUR

named-checkconf retourne un statut de sortie de 1 si des erreurs ont été détectées et 0 sinon.

VOIR AUSSI
