NOM

naptime.bt - Trace les appels de sommeil volontaires. Utilise bpftrace/eBPF.

SYNOPSIS

naptime.bt

DESCRIPTION

Cet outil trace les périodes de sommeil des applications et peut être utilisé pour déboguer une latence élevée qui pourrait être causée par des sommeils délibérés placés dans des routines d'application, en particulier des scripts d'administration.

Cet outil fonctionne en traçant l'appel système nanosleep(2) à l'aide des points de trace d'appel système.

Étant donné que cela utilise BPF, seul l'utilisateur root peut utiliser cet outil.

EXIGENCES

CONFIG_BPF et bpftrace.

EXEMPLES

Traquer les périodes de sommeil des applications via nanosleep(2) :
# naptime.bt

CHAMPS

HEURE
Un horodatage au format HH:MM:SS.
PPID
Identifiant du processus parent.
PCOMM
Nom du processus parent.
PID
L'identifiant du processus en sommeil.
COMM
Le nom du processus en sommeil.
SECONDES
La durée demandée du sommeil.

SURCHARGE

Les appels à nanosleep(2) sont censés être de faible fréquence (<< 100/s), donc la surcharge de cet outil devrait être négligeable.

SOURCE

Cet outil est issu du livre "BPF Performance Tools", publié par Addison Wesley (2019) :

http://www.brendangregg.com/bpf-performance-tools-book.html

Voir le livre pour plus de documentation sur cet outil.

Cette version se trouve dans le dépôt bpftrace :

https://github.com/bpftrace/bpftrace

Recherchez également dans la distribution bpftrace un fichier _examples.txt accompagnant contenant des exemples d'utilisation, de sortie et des commentaires pour cet outil.
