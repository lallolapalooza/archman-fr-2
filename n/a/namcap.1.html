namcap(1) Commandes utilisateur namcap(1)

NOM

namcap - utilitaire d'analyse de paquets

SYNTAXE

namcap [options] <paquet|PKGBUILD> [paquet|PKGBUILD] ...

DESCRIPTION

namcap est un utilitaire d'analyse de paquets qui recherche des problèmes dans les paquets Arch Linux ou leurs fichiers PKGBUILD. Il peut appliquer des règles à la liste des fichiers, aux fichiers eux-mêmes, ou aux fichiers PKGBUILD individuels.

Les règles renvoient des listes de messages. Chaque message peut être de l'un des trois types suivants : erreur, avertissement ou information (considérez-les comme des notes ou des commentaires). Les erreurs (désignées par 'E :') sont des choses dont namcap est très sûr qu'elles sont incorrectes et doivent être corrigées. Les avertissements (désignés par 'W :') sont des choses que namcap pense devoir être modifiées, mais si vous savez ce que vous faites, vous pouvez les laisser. Les informations (désignées par 'I :') ne sont affichées que lorsque vous utilisez l'argument info. Les messages d'information fournissent des informations qui pourraient être utiles mais qui ne nécessitent pas de modification.

OPTIONS

-e LISTE_REGLES, --exclude=LISTE_REGLES
Ne pas exécuter les règles de LISTE_REGLES sur le paquet.
-i, --info
Afficher les messages d'information.
-L, --list
Retourner une liste des règles valides et leurs descriptions.
-m, --machine-readable
Affiche des balises namcap facilement analysables au lieu de la description lisible par l'homme normale ; par exemple, utilise non-fhs-man-page au lieu de « Page de manuel non-FHS (%s) trouvée. Utilisez plutôt /usr/share/man ». Une liste complète des balises namcap ainsi que leurs descriptions lisibles par l'homme se trouve dans /usr/share/namcap/tags.
-r LISTE_REGLES, --rules=LISTE_REGLES
Appliquer uniquement les règles de LISTE_REGLES au paquet.
LISTE_REGLES est une liste de noms de règles séparés par des virgules.
-v, --version
Afficher la version et quitter.

RÈGLES

arrays
Vérifie que les variables tableau sont bien des tableaux et non des chaînes.
badbackups
Vérifie que les entrées de sauvegarde ne commencent pas par /.
carch
Recherche les références à i686 et i586 et vous indique d'utiliser $CARCH à la place.
capsnames
Vérifie un PKGBUILD pour s'assurer que le nom du paquet ne contient pas de caractères majuscules.
capsnamespkg
Vérifie un paquet pour s'assurer que le nom du paquet ne contient pas de caractères majuscules.
checksums
S'assure qu'un PKGBUILD inclut des sommes de contrôle valides.
depends
Ce module exécute ldd sur tous les exécutables, obtient les dépendances au niveau du lien, trouve le plus petit sous-ensemble de dépendances qui couvrent les dépendances au niveau du lien, et compare cette liste aux dépendances du paquet. Il renvoie des messages dans trois cas : dépendance détectée et non incluse, dépendance incluse mais déjà satisfaite, et dépendance incluse et non nécessaire. Ces suggestions ne sont que des lignes directrices et tous les constructeurs de paquets doivent en tenir compte (c'est-à-dire que vous êtes plus intelligent que namcap).

Certains cas où namcap échoue sont dlopen() et les liens obscurs. Les bibliothèques chargées via dlopen() n'apparaissent pas car elles sont chargées au moment de l'exécution : dans le cas d'un programme qui charge des plugins. Les liens obscurs sont les cas où seule une petite partie du paquet a besoin de quelque chose pour fonctionner ; généralement, la petite partie ne sera pas accédée à moins que cette chose ne soit installée (par exemple, un plugin Java pour Mozilla inclus dans le paquet Java).

directoryname
Vérifie les noms de répertoires dans la liste des fichiers du paquet pour les répertoires standard (par exemple, /etc, /usr/bin, /usr/lib). Tous les fichiers dans des répertoires non standard sont renvoyés.
elffiles
Génère une erreur s'il trouve des fichiers ELF (binaires) en dehors des chemins standards (/bin, /usr/bin, etc.).
emptydir
Recherche des répertoires dans un paquet qui ne contiennent aucun fichier.
extravars
Vérifie que les variables supplémentaires commencent par un underscore.
fhsinfopages
Vérifie l'installation correcte des pages info.
fhsmanpages
Vérifie l'installation correcte des pages de manuel.
fileownership
Vérifie que tous les fichiers appartiennent à root:root et non à un autre utilisateur ou groupe.
gnomemime
Vérifie les fichiers mime GNOME générés.
hicoloricons
Vérifie si le cache d'icônes hicolor est mis à jour lorsqu'un paquet installe des fichiers dans /usr/share/icons/hicolor.
infodirectory
Vérifie qu'un paquet ne contient pas le fichier d'annuaire d'informations (/usr/share/info/dir).
invalidstartdir
Tous les PKGBUILD qui font référence à des fichiers dans $startdir sont incorrects.
libtool
Avertit si des fichiers libtool (*.la) sont présents.
license
Vérifie que la variable licenses a été renseignée dans un PKGBUILD.
licensepkg
Vérifie que la variable licenses a été renseignée dans un paquet. Pour les paquets avec une licence personnalisée, il vérifie si le fichier de licence a été installé dans /usr/share/licenses/$pkgname/.
perllocal
Recherche perllocal.pod. perllocal.pod est un fichier gênant inclus lors de la plupart des installations de modules Perl.
permissions
Vérifie les permissions de base des fichiers et des répertoires. Il renvoie des avertissements concernant les bits lisibles par tous qui ne sont pas définis, les bits inscriptibles par tous qui sont définis, et les bits exécutables par tous qui ne sont pas définis pour les répertoires.
rpath
Génère une erreur si un binaire a RPATH défini sur autre chose que /usr/lib.
runpath
Génère une erreur si un binaire a RUNPATH défini sur autre chose que /usr/lib, /usr/lib32.
scrollkeeper
Vérifie qu'il n'y a pas de répertoires scrollkeeper.
sfurl
Avertit si un PKGBUILD télécharge depuis un miroir SourceForge spécifique au lieu du générique downloads.sourceforge.net.
symlink
Détecte les liens symboliques et les liens physiques qui ne pointent pas vers un chemin valide dans le paquet.
tags
Pour les mainteneurs de paquets, ce module vérifie que nous avons pensé à ajouter un commentaire Maintainer et Contributor.
url
Vérifie que nous avons la variable url définie dans le PKGBUILD.
urlpkg
Vérifie que nous avons la variable url définie dans le fichier du paquet.

EXEMPLES

namcap foo.pkg.tar.gz
Appliquer toutes les règles à foo.pkg.tar.gz.
namcap(1) - Arch Linux man pages

OPTIONS

namcap --check file
check the specified package file for common packaging errors
namcap -r depends,symlink foo.pkg.tar.gz
apply the depends and symlink rules to foo.pkg.tar.gz
namcap PKGBUILD
apply all PKGBUILD based rules to the file PKGBUILD
namcap --list
list all of the available rules
