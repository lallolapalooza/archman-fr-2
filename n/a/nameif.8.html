NOM

nameif - nommer les interfaces réseau en fonction des adresses MAC

SYNTAXE

nameif [-c fichier_config] [-s]
nameif [-c fichier_config] [-s] {interface adresse_mac}

DESCRIPTION

nameif renomme les interfaces réseau en fonction des adresses MAC. Lorsqu'aucun argument n'est donné, /etc/mactab est lu. Chaque ligne de ce fichier contient un nom d'interface et une adresse MAC Ethernet. Les commentaires sont autorisés en commençant par #. Sinon, les interfaces spécifiées sur la ligne de commande sont traitées. nameif recherche l'interface avec l'adresse MAC donnée et la renomme avec le nom fourni.

Lorsque l'argument -s est donné, tous les messages d'erreur sont envoyés à syslog.

Lorsque l'argument -c est donné avec un nom de fichier, ce fichier est lu à la place de /etc/mactab.

NOTES

nameif doit être exécuté avant que l'interface ne soit activée, sinon il échouera.

FICHIERS

/etc/mactab

BOGUES

Ne fonctionne actuellement qu'avec Ethernet.
