native2ascii(1) Outils d'internationalisation native2ascii(1)

NOM

native2ascii - Crée des applications localisables en convertissant un fichier avec des caractères dans n'importe quel encodage supporté vers un fichier contenant des échappements ASCII et/ou Unicode, ou vice versa.

SYNOPSIS

native2ascii [ fichier_entree ] [ fichier_sortie ]
fichier_entree
Le fichier encodé à convertir en ASCII.
fichier_sortie
Le fichier ASCII converti.

DESCRIPTION

La commande native2ascii convertit les fichiers encodés supportés par l'environnement d'exécution Java (JRE) en fichiers encodés en ASCII, en utilisant la notation d'échappements Unicode (\uxxxx) pour tous les caractères qui ne font pas partie de l'ensemble de caractères ASCII. Ce processus est nécessaire pour les fichiers de propriétés qui contiennent des caractères qui ne sont pas dans les jeux de caractères ISO-8859-1. L'outil peut également effectuer la conversion inverse.

Si la valeur de fichier_sortie est omise, la sortie standard est utilisée pour la sortie. Si, en plus, la valeur de fichier_entree est omise, l'entrée standard est utilisée pour l'entrée.

OPTIONS

-reverse

Effectue l'opération inverse : Convertit un fichier encodé en ISO-8859-1 avec des échappements Unicode vers un fichier dans n'importe quel encodage de caractères supporté par le JRE.
-encoding nom_encodage

Spécifie le nom de l'encodage de caractères à utiliser par la procédure de conversion. Si cette option n'est pas présente, l'encodage de caractères par défaut (tel que déterminé par la méthode java.nio.charset.Charset.defaultCharset) est utilisé. La chaîne nom_encodage doit être le nom d'un encodage de caractères supporté par le JRE. Voir Encodages supportés sur http://docs.oracle.com/javase/8/docs/technotes/guides/intl/encoding.doc.html
-Joption

Transmet option à la machine virtuelle Java (JVM), où option est l'une des options décrites dans la page de référence du lanceur d'applications Java. Par exemple, -J-Xms48m définit la mémoire de démarrage à 48 Mo. Voir java(1).
