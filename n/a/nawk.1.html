NAWK(1) Manuel des commandes générales NAWK(1)

NOM

nawk - langage d'analyse et de traitement dirigé par des motifs

SYNTAXE

nawk [ -F fs | --csv ] [ -v var=valeur ] [ 'prog' | -f fichierprog ] [ fichier ... ]

DESCRIPTION

Nawk analyse chaque fichier d'entrée à la recherche de lignes qui correspondent à l'un des ensembles de motifs spécifiés littéralement dans prog ou dans un ou plusieurs fichiers spécifiés comme -f fichierprog. Avec chaque motif, il peut y avoir une action associée qui sera exécutée lorsqu'une ligne d'un fichier correspond au motif. Chaque ligne est comparée à la partie motif de chaque instruction motif-action ; l'action associée est exécutée pour chaque motif correspondant. Le nom de fichier - signifie l'entrée standard. Tout fichier de la forme var=valeur est traité comme une affectation, pas comme un nom de fichier, et est exécuté au moment où il aurait été ouvert s'il avait été un nom de fichier. L'option -v suivie de var=valeur est une affectation à faire avant l'exécution de prog ; un nombre quelconque d'options -v peut être présent. L'option -F fs définit le séparateur de champs d'entrée comme étant l'expression régulière fs. L'option --csv fait que awk traite les enregistrements en utilisant le format (plus ou moins) standard de valeurs séparées par des virgules (CSV).

Une ligne d'entrée est normalement composée de champs séparés par des espaces blancs, ou par l'expression régulière FS. Les champs sont désignés par $1, $2, ..., tandis que $0 fait référence à la ligne entière. Si FS est vide, la ligne d'entrée est divisée en un champ par caractère.

Une instruction motif-action a la forme :

motif { action }

Une action { action } manquante signifie imprimer la ligne ; un motif manquant correspond toujours. Les instructions motif-action sont séparées par des sauts de ligne ou des points-virgules.

Une action est une séquence d'instructions. Une instruction peut être l'une des suivantes :

if( expression ) instruction [ else instruction ]
while( expression ) instruction
for( expression ; expression ; expression ) instruction
for( var in tableau ) instruction
do instruction while( expression )
break
continue
{ [ instruction ... ] }
expression	# communément var = expression
print [ liste-expression ] [ > expression ]
printf format [ , liste-expression ] [ > expression ]
return [ expression ]
next	# ignorer les motifs restants sur cette ligne d'entrée
nextfile	# ignorer le reste de ce fichier, ouvrir le suivant, commencer par le début
delete tableau[ expression ]	# supprimer un élément de tableau
delete tableau	# supprimer tous les éléments du tableau
exit [ expression ]	# sortir immédiatement ; le statut est expression

Les instructions sont terminées par des points-virgules, des sauts de ligne ou des accolades droites. Une liste-expression vide représente $0. Les constantes de chaîne sont mises entre guillemets " ", avec les échappements C habituels reconnus à l'intérieur. Les expressions prennent des valeurs de chaîne ou numériques selon le cas, et sont construites en utilisant les opérateurs + - * / % ^ (exponentiation), et la concaténation (indiquée par des espaces blancs). Les opérateurs ! ++ -- += -= *= /= %= ^= > >= < <= == != ?: sont également disponibles dans les expressions. Les variables peuvent être des scalaires, des éléments de tableau (désignés par x[i]) ou des champs. Les variables sont initialisées à la chaîne vide. Les indices de tableau peuvent être n'importe quelle chaîne, pas nécessairement numérique ; cela permet une forme de mémoire associative. Des indices multiples tels que [i,j,k] sont autorisés ; les constituants sont concaténés, séparés par la valeur de SUBSEP.

L'instruction print affiche ses arguments sur la sortie standard (ou dans un fichier si >fichier ou >>fichier est présent ou dans un tuyau si |cmd est présent), séparés par le séparateur de champs de sortie actuel, et terminés par le séparateur d'enregistrements de sortie. fichier et cmd peuvent être des noms littéraux ou des expressions entre parenthèses ; des valeurs de chaîne identiques dans différentes instructions dénotent le même fichier ouvert. L'instruction printf formate sa liste d'expressions selon le format (voir printf(3)). La fonction intégrée close(expr) ferme le fichier ou le tuyau expr. La fonction intégrée fflush(expr) vide tout tampon de sortie pour le fichier ou le tuyau expr.

Les fonctions mathématiques atan2, cos, exp, log, sin et sqrt sont intégrées. Autres fonctions intégrées :

length([v])
la longueur de son argument pris comme chaîne, le nombre d'éléments d'un tableau pour un argument tableau, ou la longueur de $0 si aucun argument.
rand()
nombre aléatoire dans [0,1).
srand([s])
définit la graine pour rand et renvoie la graine précédente.
int(x)
tronque à une valeur entière.
substr(s, m [, n])
la sous-chaîne de n caractères de s qui commence à la position m comptée à partir de 1. Si n est absent, utilise le reste de la chaîne.
index(s, t)
la position dans s où la chaîne t se produit, ou 0 si elle ne se produit pas.
match(s, r)
la position dans s où l'expression régulière r se produit, ou 0 si elle ne se produit pas. Les variables RSTART et RLENGTH sont définies sur la position et la longueur de la chaîne correspondante.
split(s, a [, fs])
divise la chaîne s en éléments de tableau a[1], a[2], ..., a[n], et renvoie n. La division est effectuée avec l'expression régulière fs ou avec le séparateur de champs FS si fs n'est pas donné. Une chaîne vide comme séparateur de champs divise la chaîne en un élément de tableau par caractère.
sub(r, t [, s])
remplace t pour la première occurrence de l'expression régulière r dans la chaîne s. Si s est omis, $0 est utilisé.
gsub(r, t [, s])
identique à sub sauf que toutes les occurrences de l'expression régulière sont remplacées ; sub et gsub renvoient le nombre de remplacements.

system(cmd)
exécute cmd et renvoie son statut de sortie. Ce sera -1 en cas d'erreur, le statut de sortie de cmd en cas de sortie normale, 256 + sig en cas de mort par signal, où sig est le numéro du signal responsable, ou 512 + sig en cas de vidage du cœur.

La « fonction » getline met à jour $0 avec le prochain enregistrement d'entrée du fichier d'entrée courant ; getline < fichier met à jour $0 avec le prochain enregistrement du fichier fichier. getline x met à jour la variable x à la place. Enfin, cmd | getline canalise la sortie de cmd vers getline ; chaque appel de getline renvoie la prochaine ligne de sortie de cmd. Dans tous les cas, getline renvoie 1 pour une entrée réussie, 0 pour la fin du fichier, et -1 pour une erreur.

Les motifs sont des combinaisons booléennes arbitraires (avec ! || &&) d'expressions régulières et d'expressions relationnelles. Les expressions régulières sont comme dans egrep ; voir grep(1). Les expressions régulières isolées dans un motif s'appliquent à la ligne entière. Les expressions régulières peuvent également apparaître dans des expressions relationnelles, en utilisant les opérateurs ~ et !~. /re/ est une expression régulière constante ; toute chaîne (constante ou variable) peut être utilisée comme expression régulière, sauf dans la position d'une expression régulière isolée dans un motif.

Un motif peut être constitué de deux motifs séparés par une virgule ; dans ce cas, l'action est effectuée pour toutes les lignes depuis une occurrence du premier motif jusqu'à une occurrence du second, inclus.

Une expression relationnelle est l'une des suivantes :

expression matchop expression régulière
expression op-relationnel expression
expression in nom-tableau
(expr,expr,...) in nom-tableau

où un op-relationnel est l'un des six opérateurs relationnels de C, et un matchop est soit ~ (correspond) soit !~ (ne correspond pas). Une condition est une expression arithmétique, une expression relationnelle, ou une combinaison booléenne de celles-ci.

Les motifs spéciaux BEGIN et END peuvent être utilisés pour capturer le contrôle avant la lecture de la première ligne d'entrée et après la dernière. BEGIN et END ne se combinent pas avec d'autres motifs. Ils peuvent apparaître plusieurs fois dans un programme et s'exécutent dans l'ordre où ils sont lus par nawk.

Noms de variables ayant une signification spéciale :

ARGC
nombre d'arguments, assignable.
ARGV
tableau d'arguments, assignable ; les membres non nuls sont considérés comme des noms de fichiers.
CONVFMT
format de conversion utilisé lors de la conversion de nombres (par défaut %.6g).
ENVIRON
tableau des variables d'environnement ; les indices sont des noms.
FILENAME
le nom du fichier d'entrée courant.
FNR
numéro ordinal de l'enregistrement courant dans le fichier courant.
FS
expression régulière utilisée pour séparer les champs ; peut aussi être définie par l'option -Ffs.
NF
nombre de champs dans l'enregistrement courant.
NR
numéro ordinal de l'enregistrement courant.
OFMT
format de sortie pour les nombres (par défaut %.6g).
OFS
séparateur de champs de sortie (par défaut espace).
ORS
séparateur d'enregistrements de sortie (par défaut saut de ligne).
RLENGTH
la longueur d'une chaîne correspondant à match.
RS
séparateur d'enregistrements d'entrée (par défaut saut de ligne). S'il est vide, les lignes blanches séparent les enregistrements. S'il a plus d'un caractère, RS est traité comme une expression régulière, et les enregistrements sont séparés par du texte correspondant à l'expression.
RSTART
la position de départ d'une chaîne correspondant à match.
SUBSEP
sépare plusieurs sous-indices (par défaut 034).

Les fonctions peuvent être définies (à la position d'une instruction motif-action) ainsi :

function foo(a, b, c) { ... }

Les paramètres sont passés par valeur s'ils sont scalaires et par référence s'ils sont des noms de tableaux ; les fonctions peuvent être appelées récursivement. Les paramètres sont locaux à la fonction ; toutes les autres variables sont globales. Ainsi, des variables locales peuvent être créées en fournissant des paramètres excédentaires dans la définition de la fonction.

VARIABLES D'ENVIRONNEMENT

Si POSIXLY_CORRECT est définie dans l'environnement, alors awk suit les règles POSIX pour sub et gsub concernant les barres obliques inverses et les ampersands consécutifs.

EXEMPLES

length($0) > 72

Imprimer les lignes de plus de 72 caractères.

{ print $2, $1 }

Imprimer les deux premiers champs dans l'ordre inverse.

BEGIN { FS = ",[ \t]*|[ \t]+" }
      { print $2, $1 }
Idem, avec des champs d'entrée séparés par une virgule et/ou des espaces et des tabulations.
	{ s += $1 }
END	{ print "somme est", s, " moyenne est", s/NR }
Additionner la première colonne, imprimer la somme et la moyenne.
/debut/, /fin/

Imprimer toutes les lignes entre les paires debut/fin.

BEGIN	{	# Simuler echo(1)
	for (i = 1; i < ARGC; i++) printf "%s ", ARGV[i]
	printf "\n"
	exit }

BOGUES

Il n'y a pas de conversions explicites entre nombres et chaînes. Pour forcer une expression à être traitée comme un nombre, ajoutez-lui 0 ; pour la forcer à être traitée comme une chaîne, concaténez-lui "".

Les règles de portée des variables dans les fonctions sont un bricolage ; la syntaxe est pire.

L'entrée est attendue en encodage UTF-8. D'autres jeux de caractères multibytes ne sont pas gérés. Cependant, dans les locales sur huit bits, awk traite chaque octet d'entrée comme un caractère séparé.

VALEURS EN VIRGULE FLOTTANTE INHABITUELLES

Awk a été conçu avant que l'arithmétique IEEE 754 ne définisse les valeurs Non-un-Nombre (NaN) et Infini, qui sont prises en charge par tout le matériel de virgule flottante moderne.

Parce qu'awk utilise strtod(3) et atof(3) pour convertir les valeurs de chaînes en valeurs à virgule flottante double précision, les bibliothèques C modernes convertissent également les chaînes commençant par inf et nan en valeurs infini et NaN respectivement. Cela a conduit à des résultats étranges, avec quelque chose comme ceci :

echo nancy | awk '{ print $1 + 0 }'

affichant nan au lieu de zéro.

Awk suit maintenant GNU AWK, et préfiltre les valeurs de chaînes avant de tenter de les convertir en nombres, comme suit :

Valeurs hexadécimales
Les valeurs hexadécimales (autorisées depuis C99) se convertissent en zéro, comme elles le faisaient avant C99.
Valeurs NaN
Les deux chaînes +nan et -nan (insensible à la casse) se convertissent en NaN. Aucune autre ne le fait. (Les NaN peuvent avoir des signes.)
Valeurs Infini
Les deux chaînes +inf et -inf (insensible à la casse) se convertissent respectivement en infini positif et négatif. Aucune autre ne le fait.
