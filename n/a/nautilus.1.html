NOM

nautilus - gestionnaire de fichiers pour GNOME

SYNTAXE

nautilus [options] URIs...

DESCRIPTION

nautilus est un gestionnaire de fichiers, conçu pour le bureau GNOME.

--version
Affiche la version du programme.
-w, --new-window
Ouvre toujours une nouvelle fenêtre pour parcourir les URIs spécifiés.
-q, --quit
Quitte Nautilus.
-s, --select
Sélectionne l'URI spécifié dans le dossier parent.
-h, --help
Affiche un résumé des options.
D'autres options GNOME standard non listées ici sont également supportées.

VOIR AUSSI

La documentation peut être consultée en appuyant sur F1 dans l'application ou via le menu de l'application.

Pour plus d'informations, visitez le site web https://apps.gnome.org/Nautilus

BOGUES

Les rapports de bogues peuvent être trouvés et soumis sur https://gitlab.gnome.org/GNOME/nautilus/issues
