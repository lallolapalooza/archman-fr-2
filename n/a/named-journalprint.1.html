NOM

named-journalprint - imprimer le journal de zone sous forme lisible par l'homme

SYNTAXE

named-journalprint [-c serial] [-dux] {journal}

DESCRIPTION

named-journalprint analyse le contenu d'un fichier journal de zone, l'imprime sous une forme lisible par l'homme, ou, facultativement, le convertit dans un autre format de fichier journal.

Les fichiers journaux sont automatiquement créés par named <#std-iscman-named> lorsque des modifications sont apportées aux zones dynamiques (par exemple, par nsupdate <#std-iscman-nsupdate>). Ils enregistrent chaque ajout ou suppression d'un enregistrement de ressource, au format binaire, permettant de réappliquer les modifications à la zone lors du redémarrage du serveur après un arrêt ou un crash. Par défaut, le nom du fichier journal est formé en ajoutant l'extension .jnl au nom du fichier de zone correspondant.

named-journalprint convertit le contenu d'un fichier journal donné dans un format texte lisible par l'homme. Chaque ligne commence par add ou del, pour indiquer si l'enregistrement a été ajouté ou supprimé, et se poursuit avec l'enregistrement de ressource au format fichier maître.

L'option -c (compact) fournit un mécanisme pour réduire la taille d'un journal en supprimant (la plupart/toutes) les transactions antérieures au numéro de série spécifié. Attention : cette option ne doit pas être utilisée pendant que named <#std-iscman-named> est en cours d'exécution, et peut entraîner une perte de données si le fichier de zone n'a pas été mis à jour pour contenir les données supprimées du journal. Utiliser avec une extrême prudence.

L'option -x provoque l'impression de données supplémentaires sur le fichier journal au début de la sortie et avant chaque groupe de modifications.

Les options -u (mettre à jour) et -d (mettre à niveau) recréent le fichier journal avec une version de format modifiée. Le fichier journal existant est remplacé. -d écrit le journal dans le format utilisé par les versions de BIND jusqu'à 9.16.11 ; -u l'écrit dans le format utilisé par les versions depuis 9.16.13. (9.16.12 est omis en raison d'un bug de formatage de journal dans cette version.) Notez que ces options ne doivent pas être utilisées pendant que named <#std-iscman-named> est en cours d'exécution.

VOIR AUSSI

named(8) <#std-iscman-named>, nsupdate(1) <#std-iscman-nsupdate>, Manuel de l'administrateur BIND 9.
