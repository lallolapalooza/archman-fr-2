NOM

named.conf - fichier de configuration de **named**

SYNTAXE

named.conf

DESCRIPTION

named.conf est le fichier de configuration de named <#std-iscman-named>.

Pour une documentation complète sur les instructions de configuration, veuillez vous référer à la section Référence de configuration du Manuel de l'administrateur BIND 9.

Les instructions sont entourées d'accolades et se terminent par un point-virgule. Les clauses des instructions sont également terminées par un point-virgule. Les styles de commentaires habituels sont pris en charge :

Style C : /* */

Style C++ : // jusqu'à la fin de la ligne

Style Unix : # jusqu'à la fin de la ligne

NOM

named.conf - configuration du démon DNS BIND

SYNOPIS

// Fichier de configuration général pour le démon DNS BIND.

DESCRIPTION

Le fichier named.conf est le fichier de configuration principal pour le démon DNS BIND. Il est utilisé pour définir les options globales du serveur DNS, les zones qu'il gère, et d'autres paramètres de configuration.

La syntaxe de named.conf est basée sur des blocs de configuration et des déclarations. Voici un aperçu des directives courantes :

options {
	directory "<string>";
	allow-query { <acl-name> | <ipv4_address> | <ipv6_address> | none; ... };
	// autres options globales
};

acl "nom-acl" {
	<ipv4_address>;
	<ipv6_address>;
	// ...
};

key "nom-cle" {
	algorithm <string>;
	secret "<string>";
};

server <ipv4_address> | <ipv6_address> {
	keys { "nom-cle"; ... };
	// autres paramètres du serveur
};

logging {
	channel nom-canal {
		file "<string>";
		severity <level>;
		// ...
	};
	category nom-categorie { nom-canal; ... };
	// ...
};

zone "<nom-zone>" [ class <string> ] {
	type master | slave | forward | hint | delegation-only;
	file "<string>";
	allow-transfer { <server-list> | <ipv4_address> [ port <integer> ] | <ipv6_address> [ port <integer> ] ) [ key <string> ] [ tls <string> ]; ... };
	transfer-source ( <ipv4_address> | * );
	transfer-source-v6 ( <ipv6_address> | * );
	zone-statistics ( full | terse | none | <boolean> );
};

zone "<string>" [ <class> ] {
	in-view "<string>";
};

Explication des directives courantes :

  • options : Définit les options globales pour le serveur DNS, telles que le répertoire de travail, les adresses IP autorisées à interroger, etc.
  • acl : Définit une liste de contrôle d'accès (ACL) qui regroupe des adresses IP.
  • key : Définit une clé TSIG utilisée pour l'authentification des transactions DNS.
  • server : Définit les paramètres pour un serveur DNS spécifique avec lequel ce serveur peut communiquer.
  • logging : Configure la journalisation des messages du serveur DNS.
  • zone : Définit une zone DNS que le serveur gère. Cela inclut le type de zone (maître, esclave, etc.), le fichier contenant les enregistrements DNS, et les politiques de transfert de zone.
