namespace::autoclean(3) Documentation Perl fournie par l'utilisateur namespace::autoclean(3)

NOM

namespace::autoclean - Empêcher les imports d'envahir votre espace de noms

VERSION

version 0.31

SYNOPSIS

package Foo;
use namespace::autoclean;
use Some::Package qw/imported_function/;
sub bar { imported_function('stuff') }
# plus tard :
Foo->bar;               # fonctionne
Foo->imported_function; # échouera. imported_function a été nettoyé après la compilation

DESCRIPTION

Lorsque vous importez une fonction dans un paquet Perl, elle sera naturellement disponible en tant que méthode.

Le pragma "namespace::autoclean" supprimera tous les symboles importés à la fin du cycle de compilation du paquet actuel. Les fonctions appelées dans le paquet lui-même seront toujours liées par leur nom, mais elles n'apparaîtront pas comme méthodes sur votre classe ou vos instances.

Ce module est très similaire à namespace::clean, sauf qu'il nettoiera toutes les fonctions importées, qu'elles aient été importées avant ou après avoir utilisé le pragma. Il ne touchera pas non plus à ce qui ressemble à une méthode.

Si vous écrivez un exportateur et que vous souhaitez nettoyer après vous (et vos pairs), vous pouvez utiliser le commutateur "-cleanee" pour spécifier quel paquet nettoyer :

package My::MooseX::namespace::autoclean;
use strict;
use namespace::autoclean (); # pas de nettoyage, juste chargement
sub import {
    namespace::autoclean->import(
      -cleanee => scalar(caller),
    );
}

CE QUI EST NETTOYÉ ET CE QUI NE L'EST PAS

"namespace::autoclean" laissera derrière lui tout ce qu'il considère comme une méthode. Pour les classes Moose, cela se base sur la méthode "get_method_list" de Class::MOP::Class. Pour les classes non-Moose, tout ce qui est défini dans le paquet sera identifié comme une méthode. Cela devrait correspondre à la définition de méthode de Moose. De plus, les sous-programmes magiques installés par overload ne seront pas nettoyés.

PARAMÈTRES

-also => [ ÉLÉMENT | EXPRESSION_RÉGULIÈRE | SOUS-PROGRAMME, .. ]

-also => ÉLÉMENT

-also => EXPRESSION_RÉGULIÈRE

-also => SOUS-PROGRAMME

Parfois, vous ne voulez pas seulement nettoyer les imports, mais aussi les fonctions d'aide que vous utilisez dans vos méthodes. Le commutateur "-also" peut être utilisé pour déclarer une liste de fonctions qui doivent être supprimées en plus des imports :

use namespace::autoclean -also => ['some_function', 'another_function'];

Si une seule fonction doit être nettoyée en plus, le commutateur "-also" accepte également une chaîne de caractères simple :

use namespace::autoclean -also => 'some_function';

Dans certaines situations, vous souhaiterez peut-être une solution de nettoyage plus puissante.

Le commutateur "-also" peut accepter une expression régulière ou une référence de code pour correspondre aux noms de fonctions locales à nettoyer.

use namespace::autoclean -also => qr/^_/
use namespace::autoclean -also => sub { $_ =~ m{^_} };
use namespace::autoclean -also => [qr/^_/ , qr/^hidden_/ ];
use namespace::autoclean -also => [sub { $_ =~ m/^_/ or $_ =~ m/^hidden/ }, sub { uc($_) == $_ } ];

-except => [ ÉLÉMENT | EXPRESSION_RÉGULIÈRE | SOUS-PROGRAMME, .. ]

-except => ÉLÉMENT

-except => EXPRESSION_RÉGULIÈRE

-except => SOUS-PROGRAMME

Cela prend exactement les mêmes options que "-also" sauf que tout ce qui correspond *ne sera pas* nettoyé.

AVERTISSEMENTS

Lorsqu'il est utilisé avec des classes Moo, l'heuristique utilisée pour vérifier les méthodes ne fonctionnera pas correctement pour les méthodes des rôles consommés au moment de la compilation.

package My::Class;
use Moo;
use namespace::autoclean;
# Mauvais, toutes les méthodes consommées seront nettoyées
BEGIN { with 'Some::Role' }
# Bon, les méthodes du rôle seront conservées
with 'Some::Role';

De plus, la détection de méthodes peut ne pas fonctionner correctement dans les classes Mouse dans les versions de Perl antérieures à 5.10.
