NAMEI(1) Commandes utilisateur NAMEI(1)

NOM

namei - suit un nom de chemin jusqu'à trouver un point terminal

SYNTAXE

namei [options] nom_de_chemin...

DESCRIPTION

namei interprète ses arguments comme des noms de chemin vers tout type de fichier Unix (liens symboliques, fichiers, répertoires, etc.). namei suit ensuite chaque nom de chemin jusqu'à trouver un point terminal (un fichier, un répertoire, un nœud de périphérique, etc.). S'il trouve un lien symbolique, il affiche le lien et commence à le suivre, en indentant la sortie pour montrer le contexte.

Ce programme est utile pour trouver les problèmes de type "trop de niveaux de liens symboliques".

Pour chaque ligne de sortie, namei utilise les caractères suivants pour identifier le type de fichier trouvé :

   f: = le nom de chemin en cours de résolution
    d = répertoire
    l = lien symbolique (le lien et son contenu sont affichés)
    s = socket
    b = périphérique bloc
    c = périphérique caractère
    p = FIFO (tube nommé)
    - = fichier régulier
    ? = une erreur quelconque

namei affiche un message informatif lorsque le nombre maximum de liens symboliques que ce système peut avoir est dépassé.

OPTIONS

-l, --long

Utilise le format de liste long (identique à -m -o -v).

-m, --modes

Affiche les bits de mode de chaque type de fichier dans le style de ls(1), par exemple 'rwxr-xr-x'.

-n, --nosymlinks

Ne pas suivre les liens symboliques.

-o, --owners

Affiche le nom du propriétaire et du groupe de chaque fichier.

-v, --vertical

Aligne verticalement les modes et les propriétaires.

-x, --mountpoints

Affiche les répertoires de point de montage avec un 'D' plutôt qu'un 'd'.

-Z, --context

Affiche le contexte de sécurité du fichier ou "?" s'il n'est pas disponible. Le support des contextes de sécurité est facultatif et ne doit pas nécessairement être compilé dans le binaire namei.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.
