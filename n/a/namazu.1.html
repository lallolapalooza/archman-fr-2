NOM

namazu - un programme de recherche de Namazu

SYNTAXE

namazu [options] <requête> [index]...

DESCRIPTION

namazu 2.0.21, un programme de recherche de Namazu.

-n, --max=NB
définit le nombre de documents affichés à NB.
-w, --whence=NB
définit le premier numéro des documents affichés à NB.
-l, --list
affiche les résultats au format liste.
-s, --short
affiche les résultats en format court.
--result=EXT
définit NMZ.result.EXT pour l'affichage des résultats.
--late
trie les documents par ordre chronologique inverse (du plus récent au plus ancien).
--early
trie les documents par ordre chronologique (du plus ancien au plus récent).
--sort=METHODE
définit une METHODE de tri (score, date, champ:nom)
--ascending
trie par ordre croissant (par défaut: décroissant)
-a, --all
affiche tous les résultats.
-c, --count
affiche uniquement le nombre de correspondances.
-h, --html
affiche au format HTML.
-r, --no-references
n'affiche pas les décomptes de références.
-H, --page
affiche les liens vers les résultats supplémentaires. (Ceci est presque dénué de sens)
-F, --form
force l'affichage de la région <form> ... </form>.
-R, --no-replace
ne remplace pas la chaîne d'URI.
-U, --no-decode-uri
ne décode pas l'URI lors de l'affichage en format texte brut.
-o, --output=FICHIER
définit le nom du fichier de sortie à FICHIER.
-f, --config=FICHIER
définit le nom du fichier de configuration à FICHIER.
-C, --show-config
affiche la configuration actuelle.
-q, --quiet
n'affiche pas de messages supplémentaires sauf les résultats de recherche.
-d, --debug
active le mode débogage.
-v, --version
affiche la version de namazu et quitte.
--help
affiche cette aide et quitte.
--norc
ne lit pas les fichiers d'initialisation personnels.
--
termine la liste des options.
