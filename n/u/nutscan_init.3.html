NOM

nutscan_init - Initialise la bibliothèque nutscan.

SYNTAXE

        #include <nut-scan.h>
        void nutscan_init(void);

DESCRIPTION

La fonction nutscan_init() doit être appelée au moins une fois avant d'utiliser toute autre fonction de la bibliothèque nutscan.

Elle met à jour les variables globales suivantes qui peuvent être utilisées par l'utilisateur de la bibliothèque nutscan pour connaître les méthodes de scan disponibles à l'exécution.

Cela dépend des bibliothèques supplémentaires installées sur le système :

•nutscan_avail_avahi = 1 : Le scan AVAHI NUT est disponible
•nutscan_avail_ipmi = 1 : Le scan IPMI est disponible
•nutscan_avail_nut = 1 : La méthode NUT "ancienne" est disponible
•nutscan_avail_nut_simulation = 1 : La méthode des périphériques de simulation NUT est disponible
•nutscan_avail_snmp = 1 : La méthode SNMP est disponible
•nutscan_avail_usb = 1 : La méthode USB est disponible
•nutscan_avail_xml_http = 1 : La méthode XML HTTP est disponible

Notez que si une méthode est signalée comme indisponible par ces variables, l'appel à la fonction nutscan_scan_* correspondante retournera toujours NULL.

NOTES

Techniquement, la fonction est actuellement définie dans le fichier nutscan-init.h.
