LIBNUTCLIENT_TCP(3) Manuel NUT LIBNUTCLIENT_TCP(3)

NOM

libnutclient_tcp, nutclient_tcp_create_client, nutclient_tcp_is_connected, nutclient_tcp_disconnect, nutclient_tcp_reconnect, nutclient_tcp_set_timeout, nutclient_tcp_get_timeout - Fonctions relatives au protocole TCP pour la bibliothèque d'accès client de haut niveau de Network UPS Tools

SYNTAXE

        #include <nutclient.h>
        #include <cstdint> /* uint16_t */
        #include <ctime> /* time_t */
        typedef NUTCLIENT_t NUTCLIENT_TCP_t;
        NUTCLIENT_TCP_t nutclient_tcp_create_client(
                const char* host, uint16_t port);
        int nutclient_tcp_is_connected(NUTCLIENT_TCP_t client);
        void nutclient_tcp_disconnect(NUTCLIENT_TCP_t client);
        int nutclient_tcp_reconnect(NUTCLIENT_TCP_t client);
        void nutclient_tcp_set_timeout(NUTCLIENT_TCP_t client, time_t timeout);
        time_t nutclient_tcp_get_timeout(NUTCLIENT_TCP_t client);

DESCRIPTION

Ces fonctions permettent de gérer les connexions à upsd(8) en utilisant le protocole TCP de NUT.

•La fonction nutclient_tcp_create_client() crée le contexte NUTCLIENT_TCP_t et tente de se connecter à upsd à l'adresse host et sur le port port.

Le contexte doit être libéré par nutclient_destroy().

•host peut être un nom de serveur ou une adresse IPv4 ou IPv6 valide comme "localhost", "127.0.0.1" ou "::1".
•port est un port TCP valide, généralement 3493.
•La fonction nutclient_tcp_is_connected() vérifie si la connexion est valide.
•La fonction nutclient_tcp_disconnect() force la déconnexion spécifiée.
•La fonction nutclient_tcp_reconnect() force la reconnexion d'une connexion, en la déconnectant si nécessaire.
•La fonction nutclient_tcp_set_timeout() définit la durée du délai d'attente pour les opérations d'E/S.
•La fonction nutclient_tcp_get_timeout() récupère la durée du délai d'attente pour les opérations d'E/S.

Les valeurs de timeout sont spécifiées en secondes, utilisez des valeurs négatives pour le blocage.
