NOM

nutscan_display_sanity_check - Affiche les avertissements de vérification de cohérence concernant la structure `nutscan_device_t` spécifiée sur la sortie standard.

SYNTAXE

        #include <nut-scan.h>
        void nutscan_display_sanity_check(nutscan_device_t * device);

DESCRIPTION

La fonction nutscan_display_sanity_check() appelle tous les analyseurs de vérification de cohérence contre les périphériques NUT affichés dans device, et ils peuvent imprimer des commentaires sur la sortie standard. Elle les affiche d'une manière qui peut être directement copiée dans le fichier ups.conf.

Elle est appelée par nutscan_display_ups_conf_with_sanity_check() pour fournir un contenu agrégé pour le fichier ups.conf en une seule fois.
