NOM

nullmailer - Aperçu de la documentation de nullmailer

INTRODUCTION

nullmailer est un agent de transfert de courrier simple et sécurisé, uniquement relais.

La documentation sur la manière dont les messages sont reformatés et injectés dans la file d'attente se trouve dans nullmailer-inject(1). La documentation sur la manière dont les messages sont réellement insérés dans la file d'attente se trouve dans nullmailer-queue(8). Le processus d'envoi des messages mis en file d'attente est décrit dans nullmailer-send(8).

Le tableau suivant liste tous les fichiers de contrôle utilisés par nullmailer.
