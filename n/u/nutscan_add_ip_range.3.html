NUTSCAN_ADD_IP_RANGE(3) Manuel NUT NUTSCAN_ADD_IP_RANGE(3)

NOM

nutscan_add_ip_range - Ajoute une entrée avec une plage d'adresses IP (adresses de début et de fin) à une structure `nutscan_ip_range_list_t`.

SYNOPSIS

        #include <nut-scan.h>
        /* Une plage d'adresses IP : */
        typedef struct nutscan_ip_range_s {
                char * start_ip;
                char * end_ip;
                struct nutscan_ip_range_s * next;
        } nutscan_ip_range_t;
        /* Liste de plages d'adresses IP et données d'aide : */
        typedef struct nutscan_ip_range_list_s {
                nutscan_ip_range_t * ip_ranges;         /* Liste chaînée réelle des entrées, première entrée */
                nutscan_ip_range_t * ip_ranges_last;    /* Pointeur vers la fin de la liste pour des ajouts plus rapides */
                size_t ip_ranges_count;                 /* Compteur des entrées ajoutées */
        } nutscan_ip_range_list_t;
        size_t nutscan_add_ip_range(
                nutscan_ip_range_list_t *irl,
                char * start_ip,
                char * end_ip);

DESCRIPTION

La fonction nutscan_add_ip_range() peut créer et ajouter une entrée nutscan_ip_range_t basée sur les entrées fournies à la structure nutscan_ip_range_list_t spécifiée. Le nombre résultant d'entrées dans la structure est renvoyé, ou 0 en cas d'erreurs non fatales.

Cette fonction ne fait rien si :

•le pointeur de structure est NULL (0 est renvoyé) ;
•ni start_ip ni end_ip n'ont été fournis, c'est-à-dire qu'ils ont tous deux des valeurs NULL (la longueur actuelle de la liste à partir de la structure est renvoyée) ;
•l'allocation de l'entrée a échoué (fatale).

Si une seule des valeurs start_ip ou end_ip a été fournie (non NULL), une plage d'une seule adresse est créée avec les deux adresses définies sur la même valeur de pointeur.

La structure doit être initialisée avant utilisation par nutscan_init_ip_ranges().

L'appelant doit libérer le contenu de la structure une fois son utilisation terminée en appelant nutscan_free_ip_ranges() (après quoi la structure peut être réutilisée pour une nouvelle liste), et libérer explicitement l'objet structure lui-même s'il a été alloué dynamiquement (par exemple en appelant nutscan_init_ip_ranges(NULL)).

NOTES

Techniquement, la fonction est actuellement définie dans le fichier nutscan-ip.h.

Actuellement, il n'y a pas de vérification des entrées en double ou chevauchantes, de sorte que les mêmes adresses IP et plages d'adresses IP entières peuvent être ajoutées à la liste (et seraient éventuellement scannées) plusieurs fois.
