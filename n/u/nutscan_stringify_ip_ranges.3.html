NUTSCAN_STRINGIFY_IP(3) Manuel NUT NUTSCAN_STRINGIFY_IP(3)

NOM

nutscan_stringify_ip_ranges - Collecte le contenu d'une structure `nutscan_ip_range_list_t` dans un tampon de chaîne qui peut être ultérieurement imprimé dans les journaux.

SYNTAXE

        #include <nut-scan.h>
        const char * nutscan_stringify_ip_ranges(nutscan_ip_range_list_t *irl);

DESCRIPTION

La fonction nutscan_stringify_ip_ranges() peut parcourir une structure nutscan_ip_range_list_t pour rapporter son contenu : le nombre d'éléments dans la liste, et une liste séparée par des virgules où chaque élément est un jeton unique (si start_ip==end_ip dans cette plage) ou une plage comme start_ip .. end_ip.

Retourne un pointeur vers un tampon interne alloué statiquement qui sera écrasé par les appels ultérieurs, mais qui n'a pas besoin d'être libéré par l'appelant.


Attention

Les appelants doivent utiliser des sémaphores s'ils accèdent à cette fonction dans un contexte multi-thread !

NOTES

Techniquement, la fonction est actuellement définie dans le fichier nutscan-ip.h.

VOIR AUSSI
