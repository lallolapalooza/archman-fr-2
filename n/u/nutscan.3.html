NOM

nutscan - Bibliothèque de découverte des outils Network UPS Tools (NUT)

DESCRIPTION

La bibliothèque nutscan des Network UPS Tools (NUT) offre les mêmes fonctionnalités de découverte que celles proposées par nut-scanner(8).

Elle permet de découvrir les périphériques NUT compatibles (USB, SNMP, Eaton XML/HTTP et IPMI) et les serveurs NUT (utilisant Avahi ou la méthode de connexion classique).

FONCTIONS DE DÉCOUVERTE

Tout d'abord, incluez le fichier d'en-tête requis :

#include <nut-scan.h>

Ensuite, pour découvrir de nouveaux périphériques, utilisez la fonction appropriée :

•nutscan_scan_usb(3) pour les périphériques USB compatibles,
•nutscan_scan_snmp(3) pour les agents SNMP compatibles,
•nutscan_scan_xml_http_range(3) pour la carte de gestion réseau Eaton,
•nutscan_scan_nut(3) pour les serveurs NUT (upsd), en utilisant la méthode classique (recherche de port),
•nutscan_scan_avahi(3) pour les serveurs NUT (upsd), en utilisant la méthode mDNS (Avahi),
•nutscan_scan_ipmi(3) pour les alimentations IPMI compatibles.

Toutes ces fonctions renvoient une liste de périphériques trouvés, en utilisant la structure nutscan_device_t. Cette structure est décrite dans nutscan_add_device_to_device(3).

Des fonctions utilitaires sont également fournies pour afficher les données dans des formats standard :

•nutscan_display_parsable(3) pour une sortie analysable,
•nutscan_display_ups_conf(3) pour le style ups.conf,
•nutscan_display_ups_conf_with_sanity_check(3) pour le style ups.conf avec des commentaires pour les avertissements concernant d'éventuels problèmes de configuration (le cas échéant).

GESTION DES ERREURS

Il n'existe actuellement aucun mécanisme spécifique de gestion des erreurs.
