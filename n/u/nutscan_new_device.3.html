NUTSCAN_NEW_DEVICE(3) Manuel NUT NUTSCAN_NEW_DEVICE(3)

NOM

nutscan_new_device - Crée une nouvelle structure nutscan_device_t.

SYNTAXE

        #include <nut-scan.h>
        nutscan_device_t * nutscan_new_device(void);

DESCRIPTION

La fonction nutscan_new_device() alloue une nouvelle structure nutscan_device_type_t.

VALEUR RENVOYÉE

La fonction nutscan_new_device() renvoie la structure nutscan_device_type_t nouvellement allouée.

NOTES

Techniquement, la fonction est actuellement définie dans le fichier nutscan-device.h.
