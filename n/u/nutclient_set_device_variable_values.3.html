LIBNUTCLIENT_VARIABL(3) Manuel NUT LIBNUTCLIENT_VARIABL(3)

NOM

libnutclient_variables, nutclient_get_device_variables, nutclient_get_device_rw_variables, nutclient_has_device_variable, nutclient_get_device_variable_description, nutclient_get_device_variable_values, nutclient_set_device_variable_value, nutclient_set_device_variable_values - Fonctions relatives aux variables dans la bibliothèque d'accès client de haut niveau de Network UPS Tools

SYNTAXE

        #include <nutclient.h>
        typedef void* NUTCLIENT_t;
        typedef char** strarr;
        strarr nutclient_get_device_variables(NUTCLIENT_t client,
                const char* dev);
        strarr nutclient_get_device_rw_variables(NUTCLIENT_t client,
                const char* dev);
        int nutclient_has_device_variable(NUTCLIENT_t client,
                const char* dev, const char* var);
        char* nutclient_get_device_variable_description(NUTCLIENT_t client,
                const char* dev, const char* var);
        strarr nutclient_get_device_variable_values(NUTCLIENT_t client,
                const char* dev, const char* var);
        void nutclient_set_device_variable_value(NUTCLIENT_t client,
                const char* dev, const char* var, const char* value);
        void nutclient_set_device_variable_values(NUTCLIENT_t client,
                const char* dev, const char* var, const strarr values);

DESCRIPTION

Ces fonctions permettent de gérer les variables des périphériques.

•La fonction nutclient_get_device_variables() récupère la liste des noms de variables pour un périphérique.

Le strarr retourné doit être libéré par strarr_free (voir libnutclient_general(3)).

•La fonction nutclient_get_device_rw_variables récupère la liste des noms de variables en lecture-écriture pour un périphérique.

Le strarr retourné doit être libéré par strarr_free (voir libnutclient_general(3)).

•La fonction nutclient_has_device_variable teste si la variable spécifiée est prise en charge par le périphérique.

Retourne 1 si prise en charge et 0 sinon.

•La fonction nutclient_get_device_variable_description récupère la description de la variable, le cas échéant.

La chaîne retournée doit être libérée par free(3).

•La fonction nutclient_get_device_variable_values renvoie les valeurs des variables (généralement une seule).

Le strarr retourné doit être libéré par strarr_free (voir libnutclient_general(3)).

•La fonction nutclient_set_device_variable_value vise à définir la valeur de la variable spécifiée.
•La fonction nutclient_set_device_variable_values vise à définir plusieurs valeurs de la variable spécifiée.

Arguments communs :

•dev est le nom du périphérique.
•var est le nom de la variable.
•value est la valeur de la variable.
•values est le tableau de valeurs de la variable.
