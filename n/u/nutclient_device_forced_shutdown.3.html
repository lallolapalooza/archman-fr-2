LIBNUTCLIENT_MISC(3) Manuel NUT LIBNUTCLIENT_MISC(3)

NOM

libnutclient_misc, nutclient_authenticate, nutclient_logout, nutclient_device_login, nutclient_get_device_num_logins, nutclient_device_master, nutclient_device_forced_shutdown - Fonctions diverses dans la bibliothèque d'accès client de haut niveau de Network UPS Tools

SYNOPIS

        #include <nutclient.h>
        typedef void* NUTCLIENT_t;
        void nutclient_authenticate(
                NUTCLIENT_t client,
                const char* login, const char* passwd);
        void nutclient_logout(NUTCLIENT_t client);
        void nutclient_device_login(NUTCLIENT_t client, const char* dev);
        int nutclient_get_device_num_logins(NUTCLIENT_t client, const char* dev);
        void nutclient_device_primary(NUTCLIENT_t client, const char* dev);
        /* Nom OBSOLÈTE : */
        void nutclient_device_master(NUTCLIENT_t client, const char* dev);
        void nutclient_device_forced_shutdown(NUTCLIENT_t client, const char* dev);

DESCRIPTION

•La fonction nutclient_authenticate() authentifie l'utilisateur.
•login est le nom d'utilisateur.
•passwd est le mot de passe de l'utilisateur.
•La fonction nutclient_logout() se déconnecte proprement du serveur.
•La fonction nutclient_device_login() enregistre le fait qu'un système consomme de l'énergie de cet onduleur.
•La fonction nutclient_get_device_num_logins() récupère le nombre de clients qui ont été enregistrés pour cet appareil.
•Les fonctions nutclient_device_master() et nutclient_device_primary() (notez que la première est obsolète depuis NUT v2.8.0 au profit de la seconde) s'assurent que les fonctions en mode primaire comme FSD sont disponibles si nécessaire.
•La fonction nutclient_device_forced_shutdown() définit le drapeau "arrêt forcé" (FSD) sur l'appareil.

Arguments communs :

•dev est le nom de l'appareil.
