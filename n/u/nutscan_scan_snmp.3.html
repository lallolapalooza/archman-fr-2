NUTSCAN_SCAN_SNMP(3) Manuel NUT NUTSCAN_SCAN_SNMP(3)

NOM

nutscan_scan_snmp - Scanner le réseau à la recherche d'appareils SNMP.

SYNTAXE

        #include <nut-scan.h>
        #include <unistd.h> /* useconds_t */
        nutscan_device_t * nutscan_scan_snmp(
                const char * start_ip,
                const char * stop_ip,
                useconds_t timeout,
                nutscan_snmp_t * sec);
        nutscan_device_t * nutscan_scan_ip_range_snmp(
                nutscan_ip_range_list_t * irl,
                useconds_t usec_timeout,
                nutscan_snmp_t * sec);

DESCRIPTION

Les fonctions nutscan_scan_snmp() et nutscan_scan_ip_range_snmp() tentent de détecter des appareils SNMP compatibles avec NUT. La première effectue des requêtes SNMP sur chaque adresse IP comprise entre start_ip et stop_ip, où startIP est obligatoire et stopIP est optionnel (une seule adresse startIP est scannée si stopIP est NULL) ; tandis que la seconde peut parcourir plusieurs plages d'adresses IP représentées par une structure nutscan_ip_range_list_t.

Ces arguments IP peuvent être des adresses IPv4 ou IPv6 ou des noms d'hôte.

Vous DEVEZ appeler nutscan_init(3) avant d'utiliser cette fonction.

Cette fonction attend jusqu'à timeout microsecondes avant de considérer qu'une adresse IP ne répond pas aux requêtes SNMP.

Une structure nutscan_snmp_t valide doit être passée à cette fonction.

La structure nutscan_snmp_t contient les membres suivants qui doivent être remplis comme décrit ci-dessous :

char * 'community';
char * 'secLevel';
char * 'secName';
char * 'authPassword';
char * 'privPassword';
char * 'authProtocol';
char * 'privProtocol';

Si community n'est pas NULL, les requêtes SNMP v1 sont envoyées en utilisant cette community.

Si community est NULL et secLevel est NULL, SNMP v1 est sélectionné et community est défini à "public".

Dans les autres cas, SNMP v3 est utilisé. secLevel peut être l'une des valeurs SNMP_SEC_LEVEL_NOAUTH, SNMP_SEC_LEVEL_AUTHNOPRIV ou SNMP_SEC_LEVEL_AUTHPRIV. secName est le nom de sécurité et doit être non NULL.

Si secLevel est défini à SNMP_SEC_LEVEL_AUTHNOPRIV, authPassword doit être non NULL.

Si secLevel est défini à SNMP_SEC_LEVEL_AUTHPRIV, authPassword et privPassword doivent être non NULL.

Si authProtocol est NULL, le protocole MD5 est utilisé. Sinon, vous pouvez définir authProtocol à "MD5" ou "SHA".

Si privProtocol est NULL, le protocole DES est utilisé. Sinon, vous pouvez définir privProtocol à "AES" ou "DES".

peername et handle sont utilisés en interne et n'ont pas besoin d'initialisation.

VALEUR DE RETOUR

La fonction nutscan_scan_snmp() renvoie un pointeur vers une structure nutscan_device_t contenant tous les appareils trouvés ou NULL si une erreur se produit ou si aucun appareil n'est trouvé.
