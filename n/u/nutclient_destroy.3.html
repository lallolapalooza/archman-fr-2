nutclient_destroy(3)

LIBNUTCLIENT_GENERAL(3) Manuel NUT LIBNUTCLIENT_GENERAL(3)

NOM

libnutclient_general, nutclient_destroy, strarr_alloc, strarr_free - Fonctions générales et utilitaires de la bibliothèque d'accès client de haut niveau de Network UPS Tools

SYNTAXE

        #include <nutclient.h>
        typedef void* NUTCLIENT_t;
        void nutclient_destroy(NUTCLIENT_t client);
        typedef char** strarr;
        strarr strarr_alloc(unsigned short count);
        void strarr_free(strarr arr);

DESCRIPTION

La fonction nutclient_destroy() détruit un objet de connexion NUTCLIENT_t ou dérivé (tel que NUTCLIENT_TCP_t) et libère la mémoire allouée.

•Le type strarr représente un tableau de chaînes C (tableau de pointeurs char). Le tableau doit toujours être terminé par un pointeur NULL.

Les chaînes pointées doivent être allouées par (x)calloc ou (x)strdup.

•La fonction strarr_alloc() alloue un tableau strarr avec le nombre spécifié de pointeurs de chaînes (non initialisés).

Un pointeur supplémentaire défini sur NULL est ajouté à la fin du tableau.

•La fonction strarr_free libère un tableau strarr. Elle libère également toutes les chaînes pointées.

Arguments courants :

•dev est le nom de l'appareil.
