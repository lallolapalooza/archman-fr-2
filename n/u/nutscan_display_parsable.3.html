NUTSCAN_DISPLAY_PARS(3) Manuel NUT NUTSCAN_DISPLAY_PARS(3)

NOM

nutscan_display_parsable - Affiche la structure `nutscan_device_t` spécifiée sur stdout.

SYNTAXE

        #include <nut-scan.h>
        void nutscan_display_parsable(nutscan_device_t * device);

DESCRIPTION

La fonction nutscan_display_parsable() affiche tous les périphériques NUT dans device sur stdout. Elle les affiche d'une manière qui peut être facilement analysée, c'est-à-dire :

<type de pilote>:driver="<nom du pilote>",port="<type de port>"[,<paramètre optionnel 1>="<donnée optionnelle 1>",<paramètre optionnel 2>="<donnée optionnelle 2>",...]
•<type de pilote> peut être l'un de USB, SNMP, XML, NUT, IPMI ou AVAHI.
•<nom du pilote> est le nom du binaire du pilote correspondant à ce périphérique.
•<type de port> et <paramètre optionnel X> dépendent du <nom du pilote>, voir la page man du pilote correspondant.

Notez que ce format est destiné à une consommation par machine, il n'est donc pas associé aux vérifications de cohérence qui peuvent être utilisées avec la méthode d'affichage du format de fichier ups.conf.
