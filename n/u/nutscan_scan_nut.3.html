NOM

nutscan_scan_nut - Analyse le réseau pour les services NUT disponibles.

SYNTAXE

        #include <nut-scan.h>
        #include <unistd.h> /* useconds_t */
        nutscan_device_t * nutscan_scan_nut(
                const char * startIP,
                const char * stopIP,
                const char * port,
                useconds_t usec_timeout);
        nutscan_device_t * nutscan_scan_ip_range_nut(
                nutscan_ip_range_list_t * irl,
                const char * port,
                useconds_t usec_timeout);

DESCRIPTION

Les fonctions nutscan_scan_nut() et nutscan_scan_ip_range_nut() tentent de détecter les services NUT disponibles et les périphériques associés. La première émet une requête NUT sur chaque IP allant de startIP à stopIP, où startIP est obligatoire et stopIP est optionnel (une adresse startIP est analysée si stopIP est NULL) ; tandis que la seconde peut parcourir plusieurs plages d'adresses IP représentées par une structure nutscan_ip_range_list_t.

Ces arguments IP peuvent être des adresses IPv4 ou IPv6 ou des noms d'hôtes.

Vous DEVEZ appeler nutscan_init(3) avant d'utiliser cette fonction.

Un numéro de port spécifique peut être passé, ou NULL pour utiliser le port NUT par défaut.

Cette fonction attend jusqu'à usec_timeout microsecondes avant de considérer qu'une adresse IP ne répond pas aux requêtes NUT.

VALEUR DE RETOUR

La fonction nutscan_scan_nut() retourne un pointeur vers une structure nutscan_device_t contenant tous les périphériques trouvés ou NULL si une erreur se produit ou si aucun périphérique n'est trouvé.
