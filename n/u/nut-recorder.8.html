NOM

nut-recorder - Utilitaires pour enregistrer le statut et les changements de valeur des périphériques

SYNTAXE

nut-recorder nom-périphérique [fichier-sortie] [intervalle]

DESCRIPTION

nut-recorder est un utilitaire permettant d'enregistrer les séquences des périphériques en fonctionnement (comme les coupures de courant, ou tout autre changement de valeur) à partir du serveur de données upsd(8), et de les exporter dans un format .seq.

Le fichier .seq peut ensuite être utilisé par le pilote dummy-ups(8) pour rejouer la séquence.

OPTIONS

nom-périphérique

Enregistre les changements de ce périphérique. Le format pour cette option est nomdev[@nomhote[:port]]. Le nom d'hôte par défaut est "localhost".

fichier-sortie

Optionnel. Les données seront sauvegardées dans ce fichier. Le nom par défaut est dummy-device.seq.

intervalle

Optionnel. Le statut du périphérique sera vérifié toutes les intervalles. L'intervalle par défaut est de 5 secondes.

EXEMPLES

Pour enregistrer les données de ups1@host1 toutes les 10 secondes :

:; nut-recorder ups1@host1' ups1-output.seq 10
. . .
battery.charge: 100.0
battery.voltage: 13.9
battery.voltage.nominal: 13.6
ups.status: OL
. . .
battery.charge: 90.0
ups.status: OB
. . .

Vous pouvez ensuite définir un périphérique factice dans ups.conf(5) :

[ups-test]
        driver = dummy-ups
        port = ups1-output.seq
