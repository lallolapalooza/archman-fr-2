NOM

nutscan_add_device_to_device - Concaténer deux structures de périphériques.

SYNTAXE

        #include <nut-scan.h>
        nutscan_device_t * nutscan_add_device_to_device(
                nutscan_device_t * first,
                nutscan_device_t * second);

DESCRIPTION

La structure nutscan_device_t contient les variables suivantes :

nutscan_device_type_t   type;
char *          driver;
char *          alt_driver_names;
char *          port;
nutscan_options_t       opt;
struct nutscan_device * prev;
struct nutscan_device * next;

C'est une liste doublement chaînée de périphériques. Chaque périphérique est décrit par son type, le nom de son pilote, son port et toute donnée optionnelle.

La fonction nutscan_add_device_to_device() concaténe les périphériques first et second en un unique périphérique. Aucun nouveau périphérique n'est créé, les deux listes chaînées sont simplement liées l'une à l'autre. Ainsi, les périphériques first et second sont susceptibles d'être modifiés par cette fonction.

VALEUR DE RETOUR

La fonction nutscan_add_device_to_device() retourne un pointeur vers un périphérique contenant les deux périphériques passés en argument. Notez qu'il ne s'agit pas d'un nouveau périphérique, donc c'est soit first soit second qui est retourné.

NOTES

Techniquement, la fonction est actuellement définie dans le fichier nutscan-device.h.
