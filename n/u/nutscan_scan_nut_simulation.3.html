NOM

nutscan_scan_nut_simulation - Scanne votre répertoire sysconfig à la recherche d'appareils de simulation NUT.

SYNOPSIS

        #include <nut-scan.h>
        #include <unistd.h> /* useconds_t */
        nutscan_device_t * nutscan_scan_nut_simulation();

DESCRIPTION

La fonction nutscan_scan_nut_simulation() essaie de détecter les appareils de simulation NUT disponibles, en recherchant les fichiers *.dev et *.seq dans votre répertoire "sysconfig".

Vous DEVEZ appeler nutscan_init(3) avant d'utiliser cette fonction.

BOGUES

Cette fonction utilise actuellement l'emplacement intégré du répertoire "sysconfig", et ne prend pas en compte une substitution avec la variable d'environnement NUT_CONFPATH acceptée par la plupart du code de NUT.

VALEUR DE RETOUR

La fonction nutscan_scan_nut_simulation() renvoie un pointeur vers une structure nutscan_device_t contenant tous les appareils trouvés ou NULL si une erreur se produit ou si aucun appareil n'est trouvé.
