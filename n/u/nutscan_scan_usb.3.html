NUTSCAN_SCAN_USB(3) Manuel NUT NUTSCAN_SCAN_USB(3)

NOM

nutscan_scan_usb - Scan des périphériques USB compatibles NUT.

SYNTAXE

        #include <nut-scan.h>
        nutscan_device_t * nutscan_scan_usb(nutscan_usb_t * scanopts);

Note

Avant la version 2.5.0 de libnutscan, il n'y avait pas d'argument :

nutscan_device_t * nutscan_scan_usb(void);

Après la mise à jour de l'API pour avoir un argument, une activité par défaut équivalente peut être obtenue en passant NULL comme valeur pour l'argument.

DESCRIPTION

La fonction nutscan_scan_usb() tente de détecter les périphériques USB compatibles NUT.

L'argument scanopts contient des commutateurs concernant les valeurs qui seraient rapportées dans la section de périphérique générée. Actuellement, ils concernent les détails de la liaison physique qui peuvent changer au fil du temps (par exemple, la ré-énumération USB due à des reconnexions logicielles ou matérielles) ; voir nut-scan.h pour les détails actuels :

/* Structure des options de scan USB */
typedef struct nutscan_usb {
    /* Les valeurs relatives à la liaison matérielle ci-dessous ne sont pas fiables pour la correspondance à l'exécution
     * (elles peuvent changer au fil du temps) mais peuvent être utiles si, par exemple,
     * le "serial" n'est pas disponible ou unique */
    int report_bus;
    int report_busport;
    int report_device;
    /* La valeur n'est actuellement pas utilisée pour la correspondance des périphériques, mais pourrait l'être
     * plus tard, et elle est disponible à partir de la découverte */
    int report_bcdDevice;
} nutscan_usb_t;

Vous DEVEZ appeler nutscan_init(3) avant d'utiliser cette fonction.

VALEUR DE RETOUR

La fonction nutscan_scan_usb() retourne un pointeur vers une structure nutscan_device_t contenant tous les périphériques trouvés ou NULL si une erreur se produit ou si aucun périphérique n'est trouvé.
