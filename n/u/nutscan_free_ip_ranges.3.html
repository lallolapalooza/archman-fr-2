NUTSCAN_FREE_IP_RANG(3) Manuel NUT NUTSCAN_FREE_IP_RANG(3)

NOM

nutscan_free_ip_ranges - Libère le contenu d'une structure `nutscan_ip_range_list_t` peuplée (et optionnellement créée) par `nutscan_init_ip_ranges()` et, plus important, remplie par une série d'appels à `nutscan_add_ip_range()`.

SYNTAXE

        #include <nut-scan.h>
        void nutscan_free_ip_ranges(nutscan_ip_range_list_t *irl);

DESCRIPTION

La fonction nutscan_free_ip_ranges() peut libérer une structure nutscan_ip_range_list_t. Ce faisant, elle libère toute la liste chaînée des entrées nutscan_ip_range_t et met à zéro les propriétés auxiliaires.

La structure elle-même n'est pas libérée (car il peut s'agir d'une variable allouée statiquement sur la pile) et peut être réutilisée pour une nouvelle liste si nécessaire.

L'appelant doit finalement libérer l'objet structure s'il a été alloué dynamiquement (par exemple, en appelant initialement nutscan_init_ip_ranges(NULL)).

NOTES

Techniquement, la fonction est actuellement définie dans le fichier nutscan-ip.h.
