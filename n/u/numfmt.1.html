NUMFMT(1) Commandes utilisateur NUMFMT(1)

NOM

numfmt - Convertit les nombres de/vers des chaînes lisibles par l'homme

SYNTAXE

numfmt [OPTION]... [NOMBRE]...

DESCRIPTION

Reformate NUMBER(s), ou les nombres depuis l'entrée standard si aucun n'est spécifié.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

--debug
affiche les avertissements sur les entrées invalides
-d, --delimiter=X
utilise X au lieu d'un espace blanc comme délimiteur de champ
--field=CHAMPS
remplace les nombres dans ces champs d'entrée (par défaut=1) ; voir CHAMPS ci-dessous
--format=FORMAT
utilise le format d'impression au format flottant; voir FORMAT ci-dessous pour plus de détails
--from=UNITÉ
met à l'échelle automatiquement les nombres d'entrée en UNITÉS ; par défaut 'none' ; voir UNITÉ ci-dessous
--from-unit=N
spécifie la taille de l'unité d'entrée (au lieu de 1 par défaut)
--grouping
utilise le regroupement des chiffres défini par la locale, par exemple 1 000 000 (ce qui signifie qu'il n'a aucun effet dans la locale C/POSIX)
--header[=N]
affiche (sans convertir) les N premières lignes d'en-tête ; N est par défaut 1 si non spécifié
--invalid=MODE
mode d'échec pour les nombres invalides : MODE peut être : abort (défaut), fail, warn, ignore
--padding=N
remplit la sortie sur N caractères ; N positif alignera à droite ; N négatif alignera à gauche ; le remplissage est ignoré si la sortie est plus large que N ; par défaut, le remplissage est automatique si un espace blanc est trouvé
--round=MÉTHODE
utilise MÉTHODE pour l'arrondi lors de la mise à l'échelle ; MÉTHODE peut être : up, down, from-zero (défaut), towards-zero, nearest
--suffix=SUFFIXE
ajoute SUFFIXE aux nombres de sortie, et accepte un SUFFIXE optionnel dans les nombres d'entrée
--unit-separator=SEP
insère SEP entre le nombre et l'unité en sortie, et accepte un SEP optionnel dans les nombres d'entrée
--to=UNITÉ
met à l'échelle automatiquement les nombres de sortie en UNITÉS ; voir UNITÉ ci-dessous
--to-unit=N
la taille de l'unité de sortie (au lieu de 1 par défaut)
-z, --zero-terminated
le délimiteur de ligne est NUL, pas un saut de ligne
--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte

Options UNITÉ :

none
aucune mise à l'échelle automatique n'est effectuée ; les suffixes déclenchent une erreur
auto
accepte un suffixe optionnel d'une ou deux lettres : 1K = 1000, 1k = 1000, 1Ki = 1024, 1M = 1000000, 1Mi = 1048576,
si
accepte un suffixe optionnel d'une lettre : 1k = 1000, 1K = 1000, 1M = 1000000, ...
iec
accepte un suffixe optionnel d'une lettre : 1K = 1024, 1k = 1024, 1M = 1048576, ...
iec-i
accepte un suffixe optionnel de deux lettres : 1Ki = 1024, 1ki = 1024, 1Mi = 1048576, ...

CHAMPS supporte les plages de champs style cut(1) :

N
N-ième champ, compté à partir de 1
N-
du N-ième champ jusqu'à la fin de la ligne
N-M
du N-ième au M-ième champ (inclus)
-M
du premier au M-ième champ (inclus)
-
tous les champs

Plusieurs champs/plages peuvent être séparés par des virgules

FORMAT doit être adapté pour afficher un argument flottant '%f'. Le guillemet optionnel ('%f) activera --grouping (si supporté par la locale actuelle). Une largeur optionnelle (%10f) remplira la sortie. La largeur optionnelle zéro (%010f) remplira le nombre de zéros. Les valeurs négatives optionnelles (%-10f) aligneront à gauche. La précision optionnelle (%.1f) remplacera la précision déterminée par l'entrée.

Le statut de sortie est 0 si tous les nombres d'entrée ont été convertis avec succès. Par défaut, numfmt s'arrêtera à la première erreur de conversion avec le statut de sortie 2. Avec --invalid='fail', un avertissement est affiché pour chaque erreur de conversion et le statut de sortie est 2. Avec --invalid='warn', chaque erreur de conversion est diagnostiquée, mais le statut de sortie est 0. Avec --invalid='ignore', les erreurs de conversion ne sont pas diagnostiquées et le statut de sortie est 0.

EXEMPLES

$ numfmt --to=si 1000
-> "1.0k"
$ numfmt --to=iec 2048
-> "2.0K"
$ numfmt --to=iec-i 4096
-> "4.0Ki"
$ echo 1K | numfmt --from=si
-> "1000"
$ echo 1K | numfmt --from=iec
-> "1024"
$ df -B1 | numfmt --header --field 2-4 --to=si
$ ls -l | numfmt --header --field 5 --to=iec
$ ls -lh | numfmt --header --field 5 --from=iec --padding=10
$ ls -lh | numfmt --header --field 5 --from=iec --format %10f
