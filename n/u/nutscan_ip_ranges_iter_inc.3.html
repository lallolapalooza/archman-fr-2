NOM

nutscan_ip_ranges_iter_inc - Procéder à l'itération d'une plage d'adresses IP à l'aide d'une structure `nutscan_ip_range_list_iter_t`.

SYNOPIS

        #include <nut-scan.h>
        char * nutscan_ip_ranges_iter_inc(nutscan_ip_range_list_iter_t *irliter);

DESCRIPTION

La fonction nutscan_ip_ranges_iter_inc() permet de parcourir un itérateur à partir de l'objet d'aide nutscan_ip_range_list_iter_t spécifié, préparé par nutscan_ip_ranges_iter_init(3) à partir d'une structure nutscan_ip_range_list_t.

Cette fonction saute l'opération si :

•le pointeur de structure est NULL (NULL est renvoyé) ;
•la liste d'adresses IP de la structure pointée est NULL (NULL est renvoyé),
•le pointeur de l'itérateur d'adresses IP de la structure est NULL (NULL est renvoyé).

Renvoie la prochaine adresse IP de la plage d'adresses IP enregistrée actuellement itérée, ou passe à l'itération de la plage suivante si plus aucune adresse n'est disponible dans celle en cours. L'appelant NE DEVRAIT PAS libérer cette chaîne pendant l'itération.

NOTES

Techniquement, la fonction est actuellement définie dans le fichier nutscan-ip.h.
