nutscan_ip_ranges_iter_init(3)

NUTSCAN_IP_RANGES_IT(3) Manuel NUT NUTSCAN_IP_RANGES_IT(3)

NOM

nutscan_ip_ranges_iter_init - Commence l'itération d'une plage d'adresses IP en utilisant une structure `nutscan_ip_range_list_iter_t`.

SYNTAXE

        #include <nut-scan.h>
        char * nutscan_ip_ranges_iter_init(
                nutscan_ip_range_list_iter_t *irliter,
                const nutscan_ip_range_list_t *irl);

DESCRIPTION

La fonction nutscan_ip_ranges_iter_init() peut préparer un itérateur à partir de la structure nutscan_ip_range_list_t spécifiée, en l'enregistrant dans l'objet auxiliaire nutscan_ip_range_list_iter_t fourni par l'appelant.

Différents itérateurs peuvent être créés pour parcourir la même liste nutscan_ip_range_list_t à partir de différents scans indépendamment, mais la liste et son contenu ne doivent pas être libérés tant que quelqu'un y fait référence.

Cette fonction ignore le travail si :

•le pointeur de structure est NULL (NULL est retourné) ;
•la liste d'adresses IP de la structure pointeur est NULL (NULL est retourné).

Retourne la première adresse IP de la première plage d'adresses IP enregistrée. Les adresses ultérieures peuvent être retournées par nutscan_ip_ranges_iter_inc(). L'appelant NE DOIT PAS libérer cette chaîne pendant l'itération.

NOTES

Techniquement, la fonction est actuellement définie dans le fichier nutscan-ip.h.
