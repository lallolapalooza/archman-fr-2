NOM

nutscan_cidr_to_ip - Convertir une IP CIDR en une plage d'adresses IP.

SYNTAXE

        #include <nut-scan.h>
        int nutscan_cidr_to_ip(const char * cidr, char ** start_ip, char ** stop_ip);

DESCRIPTION

La fonction nutscan_cidr_to_ip() convertit une plage d'adresses IP au format CIDR, donnée sous forme de chaîne dans cidr, en deux adresses IP sous forme de chaînes pointées par start_ip et stop_ip qui peuvent être utilisées comme paramètres d'entrée dans les fonctions de scan de l'API libnutscan.

Il incombe à l'appelant de libérer(3) les chaînes start_ip et stop_ip.

VALEUR DE RETOUR

La fonction nutscan_cidr_to_ip() renvoie 0 si une erreur s'est produite (adresse cidr invalide) ou 1 en cas de succès.

NOTES

Techniquement, la fonction est actuellement définie dans le fichier nutscan-ip.h.
