nullmailer-dsn(1) Manuel général des commandes nullmailer-dsn(1)

NOM

nullmailer-dsn - Reformate un message mis en file d'attente en une notification de statut de livraison (DSN)

SYNTAXE

nullmailer-dsn [ options ] code-de-statut < message

DESCRIPTION

Ce programme lit un message de la file d'attente nullmailer depuis l'entrée standard, le transforme en une notification de statut de livraison et écrit le résultat sur la sortie standard. La sortie est formatée pour être utilisée par nullmailer-queue.

Toutes les heures dans les options sont exprimées en secondes depuis minuit GMT le 1er janvier 1970 (l'époque UNIX).

OPTIONS

--diagnostic-code=CHAÎNE
Définit le code de diagnostic réel émis par le transport de messagerie. Doit être sous la forme "type; texte", où type serait typiquement le nom du protocole, tel que SMTP. Cela ajoute un en-tête Diagnostic-Code pour chaque destinataire.
--envelope-id=CHAÎNE
Identifiant d'enveloppe d'origine. Définir ceci ajoute un en-tête Original-Envelope-Id à la section de statut de livraison.
--last-attempt=TEMPS
Définit l'heure de la dernière tentative de livraison. Par défaut, utilise l'heure d'accès du message d'entrée. Ceci définit la date dans l'en-tête Last-Attempt-Date pour chaque destinataire.
--max-lines=NOMBRE
Définit le nombre maximum de lignes du message original à copier dans le message généré. Une valeur de zéro copie uniquement l'en-tête original. Les valeurs négatives copient le message entier. Par défaut, utilise bouncelines ci-dessous, ou zéro si celui-ci est vide.
--orig-timestamp=TEMPS
Définit l'heure du message original. Par défaut, utilise l'heure de modification du message d'entrée. Ceci définit la date dans l'en-tête Arrival-Date dans la section de statut de livraison.
--remote=CHAÎNE
Définit le nom du serveur MTA distant. Cela ajoute un en-tête Remote-MTA pour chaque destinataire.
--retry-until=TEMPS
Définit l'heure de la (future) dernière tentative de livraison. Pas de valeur par défaut. Ceci ajoute un en-tête Will-Retry-Until pour chaque destinataire.

VALEUR DE RETOUR

Se termine avec le code 0 si l'opération a réussi, sinon imprime un message de diagnostic sur la sortie d'erreur standard et se termine avec le code 1.

FICHIERS DE CONTRÔLE

adminaddr
Si doublebounceto est vide, les doubles rejets sont livrés à cette adresse à la place. Si aucune adresse n'est configurée, aucun double rejet n'est généré.
bouncelines
Définit le nombre maximum de lignes du message original à copier. Peut être remplacé par --max-lines ci-dessus.
bounceto
L'adresse à laquelle tous les rejets doivent être envoyés. Si elle est vide, l'adresse de l'expéditeur original est utilisée.
defaultdomain
Le contenu de ce fichier est ajouté à tout nom d'hôte qui ne contient pas de point (sauf localhost), y compris defaulthost et idhost. Par défaut, utilise la valeur du fichier de contrôle me, s'il existe, sinon le nom littéral defaultdomain.
defaulthost
Le contenu de ce fichier est ajouté à toute adresse à laquelle il manque un nom d'hôte. Par défaut, utilise la valeur du fichier de contrôle me, s'il existe, sinon le nom littéral defaulthost.
doublebounceto
Si l'expéditeur original était vide (le message original était une notification de statut de livraison ou de disposition), le double rejet est envoyé à l'adresse dans ce fichier.
idhost
Le contenu de ce fichier est utilisé lors de la construction de la chaîne message-id pour le message. Par défaut, utilise la valeur canonisée de defaulthost.
me
Le nom d'hôte complètement qualifié de l'ordinateur exécutant nullmailer. Par défaut, utilise le nom littéral me.
