nullmailer-inject(1) Manuel des commandes générales nullmailer-inject(1)

NOM

nullmailer-inject - Reformate et injecte un message dans la file d'attente.

SYNTAXE

nullmailer-inject [-a] [-b] [-e] [-f expéditeur] [-h] [destinataire [destinataire ...]]

DESCRIPTION

Ce programme lit un message électronique depuis l'entrée standard, reformate son en-tête pour être conforme à la RFC822, et envoie le message résultant à la file d'attente.

CHAMPS D'EN-TÊTE

Les lignes suivantes sont analysées pour trouver les adresses de destinataires : To, Cc, Bcc, Apparently-To, Resent-To, Resent-Cc, et Resent-Bcc.

Les lignes d'adresse d'expéditeur suivantes sont analysées et réécrites : Sender, From, Reply-To, Return-Path, Return-Receipt-To, Errors-To, Resent-Sender, Resent-From, et Resent-Reply-To. Si le champ d'en-tête Return-Path est présent et contient une seule adresse, son contenu sera utilisé pour définir l'adresse de l'expéditeur de l'enveloppe.

Si le message contient l'un des champs suivants, il est traité comme un message renvoyé : Resent-Sender, Resent-From, Resent-Reply-To, Resent-To, Resent-Cc, Resent-Bcc, Resent-Date, Resent-Message-ID. Si le message est renvoyé, seuls les champs de destinataires préfixés par Resent- sont examinés pour trouver les adresses.

Toutes les occurrences de Bcc, Resent-Bcc, Return-Path, ou Content-Length sont supprimées après avoir été analysées (si nécessaire).

Si l'en-tête manque du champ Message-Id, une chaîne unique est générée et ajoutée au message. Si l'en-tête manque du champ Date, la date et l'heure locales actuelles au format RFC822 sont ajoutées au message. Si le message n'a pas de champs To ou Cc, la ligne suivante est ajoutée au message :

Cc: liste des destinataires non affichée : ;

LISTES D'ADRESSES

Les listes d'adresses doivent suivre la syntaxe définie dans la RFC822. Voici une explication simplifiée de la syntaxe.

Une liste d'adresses est une liste d'adresses séparées par des virgules. Une adresse individuelle peut avoir l'une des trois formes suivantes : utilisateur@nom.domaine.com, commentaire<utilisateur@nom.domaine.com>, ou phrase:liste-adresses;. L'une des deux premières formes peut être utilisée dans la liste d'adresses de la troisième forme. Tout mot contenant des caractères spéciaux doit être placé entre guillemets doubles et les caractères spéciaux doivent être précédés d'une barre oblique inverse. Les commentaires peuvent être placés entre parenthèses entre les adresses. Tous les commentaires sont ignorés.

Les listes d'adresses sont reformatées lors de leur analyse pour faciliter une analyse ultérieure lorsque le message atteint la (ou les) destination(s). Si une adresse manque d'un nom de domaine complet (fqdn), nullmailer-inject en ajoute un.

OPTIONS

-a
Utiliser uniquement les arguments de la ligne de commande comme adresses de destinataires. Ignorer les lignes d'en-tête des destinataires.
-b
Utiliser à la fois les arguments de la ligne de commande et les données de l'en-tête du message comme adresses de destinataires.
-e
Utiliser soit les arguments de la ligne de commande (s'il y en a), soit les données de l'en-tête du message (s'il n'y a pas d'arguments) comme adresses de destinataires.
-f expéditeur
Définir l'adresse de l'expéditeur de l'enveloppe sur expéditeur.
-h
Utiliser uniquement les données de l'en-tête du message comme adresses de destinataires.
-n
Ne pas mettre le message en file d'attente, mais imprimer le contenu reformaté sur la sortie standard.
-v
Afficher l'enveloppe (adresses de l'expéditeur et des destinataires) précédant le message lors de l'impression du message sur la sortie standard.

VALEUR DE RETOUR

Retourne 0 en cas de succès, sinon affiche un message diagnostique sur la sortie d'erreur standard et quitte avec 1.

ENVIRONNEMENT

La variable d'environnement NULLMAILER_FLAGS est analysée et le comportement de nullmailer-inject est modifié si l'une des lettres suivantes est présente :

c
Utiliser le style "adresse (commentaire)" dans le champ From généré au lieu du style par défaut "commentaire <adresse>".
f
Ignorer et supprimer toutes les lignes d'en-tête From et en insérer toujours une générée.
i
Ignorer et supprimer toutes les lignes d'en-tête Message-Id.
s
Ignorer et supprimer toutes les lignes d'en-tête Return-Path.
t
Insérer une ligne To contenant une liste des destinataires si l'en-tête ne contient ni de champ To ni de champ Cc. Si le message est déterminé comme étant un message renvoyé (voir ci-dessus), un champ Resent-To est ajouté si l'en-tête ne contient ni de champ Resent-To ni de champ Resent-Cc.

Le nom d'utilisateur est défini par NULLMAILER_USER, MAILUSER, USER, ou LOGNAME, selon le premier trouvé. Si aucun de ceux-ci n'est défini, le nom est pris dans le fichier de mots de passe, ou défini sur unknown si cela échoue.

Le nom d'hôte est défini par la valeur canonicalisée de NULLMAILER_HOST, MAILHOST, ou HOSTNAME, selon le premier trouvé, ou le fichier de configuration defaulthost si aucun des éléments ci-dessus n'est défini (voir ci-dessous).

Le nom complet de l'utilisateur est défini par NULLMAILER_NAME, MAILNAME, NAME, ou le nom d'utilisateur ci-dessus, selon le premier trouvé.

L'utilisateur et le nom d'hôte de l'expéditeur de l'enveloppe sont par défaut l'utilisateur et le nom d'hôte définis ci-dessus, mais peuvent être remplacés par NULLMAILER_SUSER et NULLMAILER_SHOST.

Si NULLMAILER_QUEUE est défini, le programme nommé est utilisé à la place de nullmailer-queue pour mettre en file d'attente le message formaté.

FICHIERS DE CONTRÔLE

Lors de la lecture des fichiers suivants, une seule ligne est lue et débarrassée de tous les espaces blancs de début et de fin.

defaultdomain
Le contenu de ce fichier est ajouté à tout nom d'hôte qui ne contient pas de point (sauf localhost), y compris defaulthost et idhost. Par défaut, la valeur du fichier de contrôle me, s'il existe, sinon le nom littéral defaultdomain.
defaulthost
Le contenu de ce fichier est ajouté à toute adresse à laquelle il manque un nom d'hôte. Par défaut, la valeur du fichier de contrôle me, s'il existe, sinon le nom littéral defaulthost.
idhost
Le contenu de ce fichier est utilisé lors de la construction de la chaîne message-id pour le message. Par défaut, la valeur canonicalisée de defaulthost.
me
Le nom d'hôte qualifié complet de l'ordinateur exécutant nullmailer. Par défaut, le nom littéral me.
