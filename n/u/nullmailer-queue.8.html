NOM

nullmailer-queue - insère des messages électroniques dans la file d'attente

SYNTAXE

nullmailer-queue

DESCRIPTION

Ce programme lit un message électronique formaté depuis l'entrée standard et l'injecte en toute sécurité dans la file d'attente d'envoi des courriels.

Les données envoyées à l'entrée standard sont censées avoir le format suivant : une ligne contenant l'expéditeur de l'enveloppe, une ou plusieurs lignes contenant les destinataires, une seule ligne vide, puis le contenu du message exactement tel qu'il doit être transmis à la destination. Toutes les lignes se terminent par un seul caractère de saut de ligne. Toutes les adresses doivent contenir un nom de domaine entièrement qualifié.

VALEUR DE RETOUR

Se termine avec le code 0 s'il a réussi à mettre le message en file d'attente. S'il a échoué à mettre le message en file d'attente, il se termine avec le code 1 et affiche un message d'erreur sur la sortie standard.

FICHIERS DE CONTRÔLE

adminaddr
Si ce fichier n'est pas vide, tous les destinataires pour des utilisateurs à "localhost" (la chaîne littérale) ou le nom d'hôte canonique (provenant du fichier de contrôle me) sont redirigés vers cette adresse. Ceci est fourni pour permettre aux démons locaux d'envoyer des e-mails à "quelqu'un@localhost" et pour qu'ils aillent quelque part de sensé au lieu d'être rejetés par votre hôte relais. Pour envoyer à plusieurs adresses, mettez-les toutes sur une seule ligne séparées par une virgule.
allmailfrom
Si ce fichier n'est pas vide, son contenu remplacera l'expéditeur de l'enveloppe sur tous les messages.

AUTRES FICHIERS

/var/spool/nullmailer/queue
Le répertoire dans lequel les messages terminés sont déplacés.
/var/spool/nullmailer/tmp
Le répertoire dans lequel les messages sont temporairement formés.
/var/spool/nullmailer/trigger
Un tube utilisé pour déclencher nullmailer-send afin qu'il commence immédiatement à envoyer le message depuis la file d'attente.

VOIR AUSSI

nullmailer-inject(1), nullmailer-send(8)

LIMITATIONS

Ce programme devrait appliquer des limites de longueur de message configurables à l'échelle du système.
