NOM

nyx - Moniteur d'état de Tor en terminal

SYNTAXE

nyx [OPTION]

DESCRIPTION

Nyx est une interface en ligne de commande pour Tor (https://www.torproject.org/), fournissant des informations détaillées sur le relais en temps réel pour...


* utilisation de la bande passante, du processeur et de la mémoire
* informations de connexion
* configuration de tor
* journaux d'événements
* etc

En tant qu'interface curses, Nyx est particulièrement bien adapté aux connexions SSH, aux terminaux tty et aux amateurs de ligne de commande pour vérifier l'état de Tor.

Nyx peut être personnalisé via un fichier de configuration situé à ~/.nyx/config. Pour les options, voir https://nyx.torproject.org/#configuration.

OPTIONS

-i, --interface [ADRESSE:]PORT
Port de contrôle de Tor auquel se connecter (par défaut 127.0.0.1:9051)
-s, --socket CHEMIN_SOCKET
Socket de contrôle de Tor auquel se connecter (par défaut /var/run/tor/control)
-c, --config CHEMIN_CONFIG
Préférences de configuration utilisateur (par défaut ~/.nyx/config)
-d, --debug CHEMIN_JOURNAL
Écrit tous les journaux de nyx dans l'emplacement donné
-l, --log EVENEMENTS
Liste séparée par des virgules des événements à journaliser
-v, --version
Fournit les informations sur la version
-h, --help
Fournit les informations d'utilisation

FICHIERS

~/.nyx/config
Votre fichier de configuration personnel nyx
/usr/share/doc/nyx/nyxrc.sample
Exemple de fichier de configuration nyxrc qui documente toutes les options
