NPROXY(1) Serveur Autoritatif PowerDNS NPROXY(1)

NOM

nproxy - proxy de notification DNS

SYNTAXE

nproxy --powerdns-address ADRESSE [OPTION]... ADRESSE...

DESCRIPTION

nproxy est un démon simple qui lit les requêtes DNS NOTIFY sur une adresse et les transfère à un serveur de noms 'interne' qui traitera la notification.

Son cas d'utilisation est, par exemple, un serveur autoritatif privé à l'intérieur d'un réseau local NAT ou derrière un pare-feu, où nproxy est déployé dans la DMZ.

Le serveur autoritatif PowerDNS possède l'option trusted-notification-proxy qui doit être définie à l'adresse spécifiée avec --origin-address pour accepter ces notifications proxiées.

nproxy intègre également une option de vérification de l'état. Une requête pour 'pdns.nproxy.' avec le type de requête 'TXT' recevra en réponse une réponse "OK" (à l'intérieur de l'enregistrement TXT). Lorsque la requête concerne un enregistrement A, '1.2.3.4.' est retourné.

OPTIONS

--powerdns-address <ADRESSE>
Adresse IP du serveur PowerDNS vers lequel transférer les notifications.
--chroot <CHEMIN>
chroot vers CHEMIN pour une sécurité supplémentaire.
--setuid <UID>
setuid vers cet UID numérique.
--setgid <GID>
setgid vers ce GID numérique.
--origin-address <ADRESSE>
Définit la source des notifications envoyées à PowerDNS comme étant ADRESSE. Par défaut, la meilleure adresse correspondante (choix du noyau) est utilisée.
--listen-address <ADRESSE>
Adresses IP sur lesquelles écouter.
--listen-port <PORT>
Port source sur lequel écouter, 53 par défaut.
-d,--daemon <ARG>
Définir ARG à 0 pour désactiver l'exécution en arrière-plan.
-v, --verbose
Être verbeux
