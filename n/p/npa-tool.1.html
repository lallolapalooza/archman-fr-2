NOM

npa-tool - affiche des informations sur la carte d'identité électronique allemande (neuer Personalausweis, nPA).

SYNTAXE

npa-tool [OPTIONS]

DESCRIPTION

L'utilitaire npa-tool est utilisé pour afficher les informations stockées sur la carte d'identité électronique allemande (neuer Personalausweis, nPA), et pour effectuer certaines opérations d'écriture et de vérification.

Le contrôle d'accès étendu version 2 est effectué conformément au document ICAO 9303 ou BSI TR-03110, de sorte que d'autres cartes d'identité et documents de voyage lisibles par machine (MRTD) puissent également être lus.

OPTIONS

--help, -h

Affiche l'aide et quitte.

--version, -V

Affiche la version et quitte.

--reader arg, -r arg

Numéro du lecteur à utiliser. Par défaut, le premier lecteur avec une carte présente est utilisé. Si arg est une ATR, le lecteur avec une carte correspondante sera choisi.

--verbose, -v

Rend npa-tool plus verbeux. Spécifiez ce drapeau plusieurs fois pour être plus verbeux.

Établissement de connexion authentifiée par mot de passe (PACE)

--pin [CHAÎNE], -p [CHAÎNE]

Exécute PACE avec le PIN (de transport) de la carte d'identité électronique.

--puk [CHAÎNE], -u [CHAÎNE]

Exécute PACE avec le PUK.

--can [CHAÎNE], -c [CHAÎNE]

Exécute PACE avec le numéro d'accès à la carte (CAN).

--mrz [CHAÎNE], -m [CHAÎNE]

Exécute PACE avec la zone lisible par machine (MRZ). Entrez la MRZ sans sauts de ligne.

--env

Spécifie si les variables d'environnement PIN, PUK, CAN, MRZ et NEWPIN doivent être utilisées. Vous voudrez peut-être nettoyer votre environnement avant d'activer cette option. (par défaut=désactivé)

Gestion du PIN

--new-pin [CHAÎNE], -N [CHAÎNE]

Installe un nouveau PIN.

--resume, -R

Reprend le PIN de la carte d'identité électronique (utilise le CAN pour activer la dernière tentative). (par défaut=désactivé)

--unblock, -U

Débloque le PIN (utilise le PUK pour activer trois tentatives supplémentaires). (par défaut=désactivé)

Authentification de terminal (TA) et Authentification de puce (CA)

--cv-certificate NOM FICHIER, -C NOM FICHIER

Spécifie le certificat vérifiable par carte (CV) pour créer une chaîne de certificats. L'option peut être donnée plusieurs fois, auquel cas l'ordre est important.

--cert-desc CHAINE_HEX

Description du certificat à afficher pour l'authentification de terminal.

--chat CHAINE_HEX

Spécifie le modèle d'autorisation du titulaire de la carte (CHAT) à utiliser. S'il n'est pas fourni, il prend par défaut le CHAT du terminal. Utilisez 7F4C0E060904007F000703010203530103 pour déclencher l'EAC sur le CAT-C (Komfortleser).

--auxiliary-data CHAINE_HEX, -A CHAINE_HEX

Spécifie les données auxiliaires du terminal. S'il n'est pas fourni, la valeur par défaut est déterminée par la vérification de la validité, de l'âge et de l'identifiant communautaire.

--private-key NOM FICHIER, -P NOM FICHIER

Spécifie la clé privée du terminal.

--cvc-dir RÉPERTOIRE

Spécifie où rechercher le certificat de l'autorité de certification vérificatrice du pays (CVCA). S'il n'est pas fourni, le chemin par défaut est /home/fm/.local/etc/eac/cvc.

--x509-dir RÉPERTOIRE

Spécifie où rechercher le certificat X.509. S'il n'est pas fourni, le chemin par défaut est /home/fm/.local/etc/eac/x509.

--disable-ta-checks

Désactive la vérification de la période de validité des certificats CV. (par défaut=désactivé)

--disable-ca-checks

Désactive l'authentification passive. (par défaut=désactivé)

Lecture et écriture des groupes de données

--read-dg1

Lit le groupe de données 1 : Type de document.

--read-dg2

Lit le groupe de données 2 : État émetteur.

--read-dg3

Lit le groupe de données 3 : Date d'expiration.

--read-dg4

Lit le groupe de données 4 : Prénom(s).

--read-dg5

Lit le groupe de données 5 : Nom de famille.

--read-dg6

Lit le groupe de données 6 : Nom religieux/artistique.

--read-dg7

Lit le groupe de données 7 : Titre académique.

--read-dg8

Lit le groupe de données 8 : Date de naissance.

--read-dg9

Lit le groupe de données 9 : Lieu de naissance.

--read-dg10

Lit le groupe de données 10 : Nationalité.

--read-dg11

Lit le groupe de données 11 : Sexe.

--read-dg12

Lit le groupe de données 12 : Données facultatives.

--read-dg13

Lit le groupe de données 13 : Nom de naissance.

--read-dg14

Lit le groupe de données 14.

--read-dg15

Lit le groupe de données 15.

--read-dg16

Lit le groupe de données 16.

--read-dg17

Lit le groupe de données 17 : Lieu de résidence normal.

--read-dg18

Lit le groupe de données 18 : Identifiant communautaire.

--read-dg19

Lit le groupe de données 19 : Permis de séjour I.

--read-dg20

Lit le groupe de données 20 : Permis de séjour II.

--read-dg21

Lit le groupe de données 21 : Données facultatives.

--write-dg17 CHAINE_HEX

Écrit le groupe de données 17 : Lieu de résidence normal.

--write-dg18 CHAINE_HEX

Écrit le groupe de données 18 : Identifiant communautaire.

--write-dg19 CHAINE_HEX

Écrit le groupe de données 19 : Permis de séjour I.

--write-dg20 CHAINE_HEX

Écrit le groupe de données 20 : Permis de séjour II.

--write-dg21 CHAINE_HEX

Écrit le groupe de données 21 : Données facultatives.

Vérification de la validité, de l'âge et de l'identifiant communautaire

--verify-validity AAAA MM JJ

Vérifie la validité de la puce avec une date de référence.

--older-than AAAA MM JJ

Vérifie l'âge avec une date de référence.

--verify-community CHAINE_HEX

Vérifie l'identifiant communautaire avec un ID de référence.

Options spéciales, pas toujours utiles

--break, -b

Force le PIN, le CAN ou le PUK. Utiliser conjointement avec les options -p, -a ou -u. (par défaut=désactivé)

--translate NOM FICHIER, -t NOM FICHIER

Spécifie le fichier contenant des chaînes HEX d'APDU à envoyer via le canal sécurisé. (par défaut=`stdin')

--tr-03110v201

Force la conformité à BSI TR-03110 version 2.01. (par défaut=désactivé)

--disable-all-checks

Désactive toutes les vérifications des données en vol. (par défaut=désactivé)
