NOM

ne_token, ne_qtoken - découpeurs de chaînes

SYNTAXE

#include <ne_string.h>

char *ne_token(char **str, char sep);

char *ne_qtoken(char **str, char sep, const char *quotes);

DESCRIPTION

ne_token et ne_qtoken découpent la chaîne à l'emplacement pointé par str. Chaque fois que la fonction est appelée, elle renvoie le prochain jeton (token) et modifie le pointeur str pour qu'il pointe vers le reste de la chaîne, ou vers NULL s'il n'y a plus de jetons dans la chaîne. Un jeton est délimité par le caractère séparateur sep ; si ne_qtoken est utilisé, les segments de chaîne entre guillemets sont ignorés lors de la recherche d'un séparateur. Un segment entre guillemets est délimité par une paire de caractères parmi ceux spécifiés dans la chaîne quotes.

La chaîne découpée est modifiée à chaque appel de la fonction de découpage ; le prochain caractère séparateur est remplacé par un terminateur NUL.

EXEMPLES

La fonction suivante affiche chaque jeton dans une chaîne list séparée par des virgules, qui est modifiée sur place :

static void splitter(char *list)
{
  do {
    printf("Jeton: %s\n", ne_token(&list, ','));
  while (list);
}
