NOM

ne_ssl_readable_dname, ne_ssl_dname_cmp - gestion des noms distinctifs SSL

SYNTAXE

#include <ne_ssl.h>

const char *ne_ssl_readable_dname(const ne_ssl_dname *dname);

int ne_ssl_dname_cmp(const ne_ssl_dname *dn1, const ne_ssl_dname *dn2);

DESCRIPTION

La fonction ne_ssl_readable_dname crée une chaîne de caractères lisible par l'homme, sur une seule ligne, à partir d'un objet ne_ssl_dname. La chaîne retournée est allouée par malloc() et doit être libérée par l'appelant avec free().

La fonction ne_ssl_dname_cmp compare deux noms distinctifs et retourne zéro s'ils sont égaux, ou une valeur non nulle sinon.

VALEUR DE RETOUR

ne_ssl_readable_dname retourne une chaîne allouée par malloc et ne retourne jamais NULL.

EXEMPLES

Voir ne_ssl_cert_subject pour un exemple d'utilisation de ne_ssl_readable_dname.
