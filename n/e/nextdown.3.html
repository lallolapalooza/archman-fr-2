nextup(3) Manuel des fonctions de bibliothèque nextup(3)

NOM

nextup(3), nextupf(3), nextupl(3), nextdown(3), nextdownf(3), nextdownl(3) - renvoie le prochain nombre à virgule flottante vers l'infini positif/négatif

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#define _GNU_SOURCE     /* Voir feature_test_macros(7) */
#include <math.h>
double nextup(double x);
float nextupf(float x);
long double nextupl(long double x);
double nextdown(double x);
float nextdownf(float x);
long double nextdownl(long double x);

DESCRIPTION

Les fonctions nextup(), nextupf() et nextupl() renvoient le prochain nombre flottant représentable supérieur à x.

Si x est le plus petit nombre négatif représentable dans le type correspondant, ces fonctions renvoient -0. Si x est +0 ou -0, la valeur renvoyée est le plus petit nombre positif représentable du type correspondant.

Si x est l'infini positif, la valeur renvoyée est l'infini positif. Si x est l'infini négatif, la valeur renvoyée est le plus grand nombre négatif fini représentable du type correspondant.

Si x est NaN, la valeur renvoyée est NaN.

La valeur renvoyée par nextdown(x) est -nextup(-x), et de manière similaire pour les autres types.

VALEUR DE RETOUR

Voir DESCRIPTION.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
nextup (), nextupf (), nextupl (), nextdown (), nextdownf (), nextdownl () Sécurité des threads MT-Safe

NORMES

Ces fonctions sont décrites dans IEEE Std 754-2008 - Standard for Floating-Point Arithmetic et ISO/IEC TS 18661.
