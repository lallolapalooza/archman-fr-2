Paquet: neon

NE_SET_SERVER_AUTH(3) Référence API neon NE_SET_SERVER_AUTH(3)

NOM

ne_set_server_auth, ne_set_proxy_auth, ne_forget_auth - enregistrer les rappels d'authentification

SYNOPSIS

#include <ne_auth.h>

typedef int (*ne_auth_creds)(void *userdata, const char *realm, int attempt, char *username, char *password);

void ne_set_server_auth(ne_session *session, ne_auth_creds callback, void *userdata);

void ne_set_proxy_auth(ne_session *session, ne_auth_creds callback, void *userdata);

void ne_forget_auth(ne_session *session);

DESCRIPTION

Le type ne_auth_creds définit un rappel qui est appelé lorsqu'un serveur ou un proxy requiert une authentification utilisateur pour une requête particulière. La chaîne realm est fournie par le serveur. L'argument attempt est un compteur indiquant le nombre de fois où la requête a été retentée avec différentes informations d'identification d'authentification. La première fois que le rappel est appelé pour une requête particulière, attempt sera égal à zéro.

Pour retenter la requête en utilisant de nouvelles informations d'identification d'authentification, le rappel doit retourner zéro, et les buffers username et password doivent contenir des chaînes se terminant par NUL. La constante NE_ABUFSIZ donne la taille de ces buffers.


Astuce

Si vous souhaitez uniquement accorder à l'utilisateur une seule tentative pour saisir les informations d'identification, utilisez la valeur du paramètre attempt comme valeur de retour du rappel.

Pour annuler la requête, le rappel doit retourner une valeur non nulle ; dans ce cas, le contenu des buffers username et password est ignoré.

La fonction ne_forget_auth peut être utilisée pour supprimer les informations d'identification d'authentification mises en cache.

EXEMPLES

/* Fonction qui demande une ligne d'entrée utilisateur : */
extern char *prompt_for(const char *prompt);
static int
my_auth(void *userdata, const char *realm, int attempts,
        char *username, char *password)
{
   strncpy(username, prompt_for("Nom d'utilisateur : "), NE_ABUFSIZ);
   strncpy(password, prompt_for("Mot de passe : "), NE_ABUFSIZ);
   return attempts;
}
int main(...)
{
   ne_session *sess = ne_session_create(...);
   ne_set_server_auth(sess, my_auth, NULL);
   /* ... */
}
