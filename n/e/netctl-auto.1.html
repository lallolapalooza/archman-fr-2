NOM

netctl-auto - Contrôler la sélection automatique des profils netctl sans fil

SYNTAXE

netctl-auto {COMMANDE} ...

netctl-auto [--help | --version]

DESCRIPTION

netctl-auto peut être utilisé pour contrôler la sélection automatique de profils réseau offerte par le fichier netctl-auto@.service. Voir netctl.special(7) pour les détails concernant le fichier de service.

OPTIONS

Les commandes suivantes sont comprises :

list

Lister tous les profils actuellement disponibles pour la sélection automatique. Les profils actifs seront marqués par un ‘*’, les profils désactivés par un ‘!’.

switch-to [PROFIL]

Basculer vers le profil réseau spécifié sur la ligne de commande. Le profil spécifié sera activé si nécessaire, l'état de tous les autres profils n'est pas modifié. Cette commande ne force pas netctl-auto à utiliser le profil spécifié. Si une déconnexion se produit, netctl-auto peut sélectionner un profil alternatif.

is-active [PROFIL]

Vérifier si le profil réseau spécifié sur la ligne de commande est actif. Affiche l'état actuel.

enable [PROFIL]

Activer un profil réseau précédemment désactivé pour la sélection automatique. À chaque démarrage du service netctl-auto, tous les profils disponibles sont activés par défaut.

disable [PROFIL]

Désactiver le profil spécifié pour la sélection automatique. Ceci n'aura d'effet que jusqu'à l'arrêt du service netctl-auto. Pour exclure définitivement un profil de la sélection automatique, utiliser l'option ExcludeAuto=yes dans le profil.

enable-all

Activer tous les profils pour la sélection automatique.

disable-all

Désactiver tous les profils pour la sélection automatique.

is-enabled [PROFIL]

Vérifier si le profil spécifié est activé pour le service netctl-auto en cours d'exécution. Affiche l'état d'activation actuel.

start [INTERFACE]

Démarrer la sélection automatique de profils sur l'interface spécifiée.

Cette commande ne doit pas être invoquée directement, utiliser la commande suivante à la place :

    systemctl start netctl-auto@<interface>

stop [INTERFACE]

Arrêter la sélection automatique de profils sur l'interface spécifiée. Ceci déconnectera le profil actuellement actif sur l'interface.

Cette commande ne doit pas être invoquée directement, utiliser la commande suivante à la place :

    systemctl stop netctl-auto@<interface>

STATUT DE SORTIE

En cas de succès, 0 est retourné, sinon un code d'échec non nul.

ENVIRONNEMENT

$NETCTL_DEBUG

Si défini sur "yes", des sorties de débogage sont générées.

VOIR AUSSI

netctl(1), netctl.profile(5), netctl.special(7)
