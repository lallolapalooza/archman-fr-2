NOM

nethsm-metrics - Obtenir des métriques

SYNTAXE

nethsm metrics [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help]

DESCRIPTION

Obtenir des métriques

Les métriques du périphérique cible sont retournées au format JSON.

Requiert l'authentification d'un utilisateur système dans le rôle "Métriques".

OPTIONS

-a, --auth-passphrase-file <FICHIER_PHRASE_IDENTIFICATION>
Le chemin vers un fichier contenant une phrase d'identification pour l'authentification

La phrase d'identification fournie dans le fichier doit être celle de l'utilisateur choisi pour la commande.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes nécessitant plusieurs rôles simultanément. Avec plusieurs fichiers de phrases d'identification, l'ordre est important, car les fichiers sont assignés à l'utilisateur respectif fourni par l'option "--user".

Peut également être spécifiée avec la variable d'environnement NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIG>
Le chemin vers un fichier de configuration personnalisé

Si spécifié, le fichier de configuration personnalisé est utilisé à la place de l'emplacement par défaut du fichier de configuration.

Peut également être spécifiée avec la variable d'environnement NETHSM_CONFIG.
-l, --label <ETIQUETTE>
Une étiquette identifiant de manière unique un périphérique dans le fichier de configuration

Doit être fournie si plus d'un périphérique est configuré dans le fichier de configuration.

Peut également être spécifiée avec la variable d'environnement NETHSM_LABEL.
-u, --user <UTILISATEUR>
Un nom d'utilisateur qui est utilisé pour une commande

Peut être fourni si aucun nom d'utilisateur n'est configuré dans le fichier de configuration pour un périphérique. Doit être fourni si plusieurs noms d'utilisateurs du même rôle cible sont configurés dans le fichier de configuration pour un périphérique.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles simultanément.

Peut également être spécifiée avec la variable d'environnement NETHSM_USER.
-h, --help
Afficher l'aide (voir un résumé avec '-h')
nethsm-metrics
