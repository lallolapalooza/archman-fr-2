NAME

net-snmp-config - renvoie des informations sur les bibliothèques et binaires net-snmp installés

SYNOPSIS

net-snmp-config [OPTIONS]

DESCRIPTION

Le script shell net-snmp-config est conçu pour récupérer les informations de configuration sur les bibliothèques et les binaires gérant le protocole SNMP (Simple Network Management Protocol), construits à partir du paquet source net-snmp. Ces informations sont particulièrement utiles pour les applications qui doivent se lier aux bibliothèques SNMP et doivent donc connaître toutes les autres bibliothèques qui doivent également être liées.

OPTIONS

--version
affiche le numéro de version de net-snmp
--indent-options
affiche les options d'indentation du style de codage
--debug-tokens
affiche une commande exemple pour rechercher dans le code source la liste des jetons de débogage disponibles

Commandes de configuration SNMP :

--create-snmpv3-user [-ro] [-a authpass] [-x privpass]
[-X DES|AES] [-A MD5|SHA|SHA-512|SHA-384|SHA-256|SHA-224] [nom_utilisateur]

Ces options produisent les différents indicateurs de compilation nécessaires lors de la construction d'applications SNMP externes :

--base-cflags
liste les indicateurs de compilation supplémentaires nécessaires pour les applications externes (exclut -I. et les indicateurs d'avertissement développeur supplémentaires, le cas échéant)
--cflags
liste les indicateurs de compilation supplémentaires nécessaires
--libs
liste les bibliothèques nécessaires à la construction d'applications
--agent-libs
liste les bibliothèques nécessaires à la construction de sous-agents
--netsnmp-libs
liste les bibliothèques spécifiques à netsnmp
--external-libs
liste les bibliothèques nécessaires aux bibliothèques netsnmp
--netsnmp-agent-libs
liste les bibliothèques d'agents spécifiques à netsnmp

--external-agent-libs liste les bibliothèques nécessaires aux bibliothèques netsnmp

Construction automatisée de sous-agents (produit un fichier binaire OUTPUTNAME) : [Cette fonctionnalité n'a pas été testée de manière approfondie, utilisez à vos risques et périls.]

--compile-subagent NOM_SORTIE [--norm] [--cflags indicateurs]
[--ldflags indicateurs] mibmodule1.c [...]]
--norm
laisse le fichier .c généré disponible pour lecture.
--cflags indicateurs
indicateurs cflags supplémentaires à utiliser (par ex. -I...).
--ldflags indicateurs
indicateurs ld supplémentaires à utiliser (par ex. -L... -l...).
Détails sur la façon dont le paquet net-snmp a été compilé :
--configure-options
Affiche les arguments de configuration d'origine
--snmpd-module-list
Affiche les modules compilés dans l'agent
--prefix
Affiche le préfixe d'installation
