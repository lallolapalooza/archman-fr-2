neochat

NOM

neochat - Client pour interagir avec le protocole de messagerie matrix

SYNTAXE

neochat [URI]

DESCRIPTION

neochat est une application de chat pour le protocole matrix qui fonctionne sur ordinateur et sur mobile.

OPTIONS

URI

L'URI matrix pour un utilisateur ou une salle. Par exemple matrix:u/user:example.org et matrix:r/root:example.org. Cela tentera d'ouvrir la salle ou la conversation donnée dans NeoChat.
