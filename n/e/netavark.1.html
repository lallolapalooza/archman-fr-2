NOM

netavark - Configurer un espace de noms réseau donné pour l'utilisation par un conteneur

SYNTAXE

netavark [options] commande chemin de l'espace de noms réseau

DESCRIPTION

Netavark configure un espace de noms réseau selon une configuration lue depuis STDIN. La configuration est au format JSON.

OPTIONS GLOBALES

--file, -f

Au lieu de lire depuis STDIN, lire la configuration à appliquer depuis le fichier donné. -f - peut également être utilisé pour indiquer la lecture depuis STDIN.

COMMANDES

netavark setup

La commande setup configure l'espace de noms réseau donné avec la configuration donnée, en créant toutes les interfaces et règles de pare-feu nécessaires.

netavark teardown

La commande teardown est l'inverse de la commande setup, annulant toute configuration appliquée. Certaines interfaces peuvent ne pas être supprimées (les interfaces de pont, par exemple, ne seront pas supprimées).

FORMAT DE LA CONFIGURATION

La configuration acceptée est la même pour setup et teardown. Elle est au format JSON.

Le format est https://github.com/containers/podman/blob/cd7b48198c38c5028540e85dc72dd3406f4318f0/libpod/network/types/network.go#L164-L173 mais nous enverrons également un tableau Networks incluant toutes les définitions de réseau (https://github.com/containers/podman/blob/cd7b48198c38c5028540e85dc72dd3406f4318f0/libpod/network/types/network.go#L32-L62) TODO : Transcrire la configuration ici dans un format tabulaire agréable

EXEMPLE

netavark setup /run/user/1000/podman/netns/d11d1f9c499d

netavark -f /run/podman/828b0508ae64.conf teardown /run/podman/netns/828b0508ae64
