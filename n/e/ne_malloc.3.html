NE_MALLOC(3) Référence de l'API neon NE_MALLOC(3)

NOM

ne_malloc, ne_calloc, ne_realloc, ne_strdup, ne_strndup, ne_oom_callback - wrappers d'allocation mémoire

SYNOPIS

#include <ne_alloc.h>

void *ne_malloc(size_t size);

void *ne_calloc(size_t size);

void *ne_realloc(void *size, size_t len);

char *ne_strdup(const char *s);

char *ne_strndup(const char *s, size_t size);

void ne_oom_callback(void (*callback)(void));

DESCRIPTION

Les fonctions ne_malloc, ne_calloc, ne_realloc, ne_strdup et ne_strdnup fournissent des wrappers pour les fonctions équivalentes de la bibliothèque C standard. Les wrappers offrent la garantie supplémentaire que si l'équivalent de la bibliothèque C renvoie NULL lorsqu'aucune mémoire n'est disponible, une fonction de rappel facultative sera appelée, et la bibliothèque appellera alors abort().

ne_oom_callback enregistre une fonction de rappel qui sera invoquée si une erreur de manque de mémoire est détectée.

NOTES

Si le système d'exploitation utilise une allocation de mémoire optimiste, les routines d'allocation de mémoire de la bibliothèque C ne renverront pas NULL, il n'est donc pas possible de gérer gracieusement les échecs d'allocation mémoire.
