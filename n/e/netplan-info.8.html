NOM

netplan-info - afficher les fonctionnalités disponibles

SYNTAXE

netplan [--debug] info -h|--help

netplan [--debug] info [--json|--yaml]

DESCRIPTION

netplan info affiche les fonctionnalités prises en charge.

OPTIONS

-h, --help
Afficher l'aide de base.
--debug
Afficher la sortie de débogage pendant le processus.
--json
Afficher la version et les fonctionnalités au format JSON.
--yaml
Afficher la version et les fonctionnalités au format YAML (par défaut).
