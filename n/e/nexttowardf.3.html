nextafter(3) Manuel des fonctions de bibliothèque nextafter(3)

NOM

nextafter, nextafterf, nextafterl, nexttoward, nexttowardf, nexttowardl - manipulation de nombres à virgule flottante

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double nextafter(double x, double y);
float nextafterf(float x, float y);
long double nextafterl(long double x, long double y);
double nexttoward(double x, long double y);
float nexttowardf(float x, long double y);
long double nexttowardl(long double x, long double y);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

nextafter():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || _XOPEN_SOURCE >= 500
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

nextafterf(), nextafterl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

nexttoward(), nexttowardf(), nexttowardl():

    _XOPEN_SOURCE >= 600 || _ISOC99_SOURCE
        || _POSIX_C_SOURCE >= 200112L

DESCRIPTION

Les fonctions nextafter(), nextafterf() et nextafterl() retournent la prochaine valeur flottante représentable suivant x dans la direction de y. Si y est plus petit que x, ces fonctions retournent le plus grand nombre représentable inférieur à x.

Si x est égal à y, les fonctions retournent y.

Les fonctions nexttoward(), nexttowardf() et nexttowardl() font la même chose que les fonctions nextafter() correspondantes, à l'exception qu'elles ont un second argument de type long double.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent la prochaine valeur flottante représentable après x dans la direction de y.

Si x est égal à y, alors y (converti vers le même type que x) est retourné.

Si x ou y est un NaN, un NaN est retourné.

Si x est fini, et que le résultat serait un dépassement (overflow), une erreur de plage se produit, et les fonctions retournent HUGE_VAL, HUGE_VALF, ou HUGE_VALL, respectivement, avec le signe mathématique correct.

Si x n'est pas égal à y, et que le résultat correct serait sous-normal, zéro, ou sous-dépassement (underflow), une erreur de plage se produit, et soit la valeur correcte (si elle peut être représentée), soit 0.0, est retournée.

ERREURS

Voir math_error(7) pour des informations sur la façon de déterminer si une erreur s'est produite lors de l'appel de ces fonctions.

Les erreurs suivantes peuvent se produire :

Erreur de plage : dépassement de capacité du résultat
errno est défini à ERANGE. Une exception flottante de dépassement (FE_OVERFLOW) est levée.
Erreur de plage : le résultat est sous-normal ou en sous-dépassement
errno est défini à ERANGE. Une exception flottante de sous-dépassement (FE_UNDERFLOW) est levée.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
nextafter (), nextafterf (), nextafterl (), nexttoward (), nexttowardf (), nexttowardl () Sécurité des threads MT-Safe

NORMES

C11, POSIX.1-2008.

Cette fonction est définie dans IEC 559 (et l'annexe avec les fonctions recommandées dans IEEE 754/IEEE 854).

HISTORIQUE

C99, POSIX.1-2001.

BOGUES

Dans glibc 2.5 et versions antérieures, ces fonctions ne lèvent pas d'exception de sous-dépassement flottant (FE_UNDERFLOW) lorsqu'un sous-dépassement se produit.

Avant glibc 2.23, ces fonctions ne définissaient pas errno.
