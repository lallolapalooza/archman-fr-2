ne_get_response_location(3)

Paquet: neon

NE_GET_STATUS(3) Référence de l'API neon NE_GET_STATUS(3)

NOM

ne_get_status, ne_get_response_location, ne_get_response_retry_after - récupérer les propriétés de la réponse HTTP

SYNTAXE

#include <ne_request.h>

const ne_status *ne_get_status(const ne_request *request);

ne_uri *ne_get_response_location(ne_request *request);

time_t ne_get_response_retry_after(ne_request *request);

DESCRIPTION

La fonction ne_get_status renvoie un pointeur vers l'objet de statut HTTP donnant le résultat d'une requête. L'objet renvoyé n'est valide qu'une fois que la requête a été *envoyée avec succès* (la valeur de retour de ne_request_dispatch ou ne_begin_request était zéro).

Si la réponse inclut un en-tête Location, la fonction ne_get_response_location analyse et résout l'URI-référence par rapport à la cible de la requête. Si un fragment ("#fragment") est applicable à la cible de la requête, il peut être passé comme argument pour permettre une résolution relative appropriée.

La fonction ne_get_response_retry_after analyse tout en-tête Retry-After inclus dans la réponse. Si la valeur de l'en-tête utilise un temps relatif, elle est interprétée par rapport au moment où la fonction a été appelée, plutôt qu'au moment où la réponse a été reçue, donc la fonction doit être utilisée directement après l'envoi de la requête.

VALEUR DE RETOUR

ne_get_status renvoie un pointeur vers l'objet de statut HTTP donnant le résultat d'une requête. Ce pointeur est valide jusqu'à ce que l'objet de requête associé soit détruit.

ne_get_response_location renvoie un objet ne_uri alloué par malloc, ou NULL si soit l'URI dans l'en-tête Location n'a pas pu être analysé, soit l'en-tête Location était absent.

ne_get_response_retry_after renvoie une valeur time_t, ou zéro si soit aucun en-tête Retry-After n'était inclus, soit la valeur de l'en-tête n'a pas pu être analysée.

EXEMPLES

Afficher le code de statut de la réponse lors de l'application de la méthode HEAD à une ressource.

ne_request *req = ne_request_create(sess, "HEAD", "/foo/bar");
if (ne_request_dispatch(req))
   /* gérer les erreurs... */
else
   printf("Le code de statut de la réponse était %d\n", ne_get_status(req)->code);
ne_request_destroy(req);

HISTORIQUE

ne_get_response_location est disponible dans neon 0.34.0 et versions ultérieures.

VOIR AUSSI

ne_status, ne_request_create
