newapkbuild(1) Manuel des commandes générales newapkbuild(1)

NOM

newapkbuild - générer un nouveau fichier APKBUILD

SYNTAXE

newapkbuild options... [nom_paquet[-ver_paquet] | url_source]

DESCRIPTION

newapkbuild génère un nouveau fichier APKBUILD à utiliser avec abuild(1). nom_paquet spécifie le nom du paquet, s'il n'est pas déjà spécifié avec -n. S'il est suivi d'un trait d'union (-) et d'une chaîne de version valide ver_paquet, il spécifie en plus la version du paquet.

newapkbuild essaiera de détecter automatiquement le système de compilation en inspectant le répertoire source si url_source est spécifié, et écrira les instructions de compilation typiques pour ce système de compilation. Si vous ne spécifiez pas l'URL source, ou si vous souhaitez remplacer la détection automatique, vous pouvez spécifier le système de compilation avec l'option appropriée. Si ni url_source ni aucune option ne sont spécifiées, le fichier APKBUILD généré ne contiendra aucune instruction de compilation.

OPTIONS

-a

Spécifie que le paquet utilise autotools.

-C

Spécifie que le paquet utilise CMake. CMake sera ajouté aux dépendances de compilation (makedepends).

-c

Force newapkbuild à copier également un script init.d, un fichier conf.d et des exemples de scripts pre- et post-installation dans le répertoire APKBUILD. Cela vous permet de démarrer rapidement pour les paquets de démons. Voir la section FICHIERS pour plus de détails.

-d DESC

Spécifie la description (pkgdesc=) pour le nouveau paquet.

-e, -y

Spécifie que le paquet utilise un système de compilation Python PEP517. gpep517, setuptools et wheel de Python seront ajoutés aux dépendances de compilation (makedepends).

-f

Force newapkbuild à écraser un APKBUILD existant, s'il y en a déjà un dans le répertoire du paquet.

-h

Affiche les informations d'utilisation.

-l LICENCE

Spécifie la licence sous laquelle le nouveau paquet est distribué. Ceci doit correspondre à un identifiant SPDX.

-m

Spécifie que le paquet utilise Meson. Meson sera ajouté aux dépendances de compilation (makedepends).

-n NOM

Spécifie le nom du nouveau paquet. Un nouveau répertoire nommé NOM sera créé dans le répertoire courant, avec le fichier APKBUILD.

-p

Spécifie que le paquet utilise un fichier Perl Makefile.PL. Le template CPAN sera utilisé et Perl sera ajouté aux dépendances (depends).

-r

Spécifie que le paquet utilise Cargo. Cargo sera ajouté aux dépendances de compilation (makedepends).

-s

Crée une URL SourceForge automatique pour le paquet en basant sur son nom et sa version. Ceci n'est valide que si nom_paquet-ver_paquet est spécifié sur la ligne de commande.

-u URL

Spécifie la page Web (url=) pour le nouveau paquet. Ceci ne doit *pas* être l'URL du paquet source ; ce doit être la page Web principale du projet.

FICHIERS

Tous les fichiers générés seront placés dans un répertoire nom_paquet à l'intérieur du répertoire de travail courant, nom_paquet étant créé s'il n'existe pas.

APKBUILD

newapkbuild créera un APKBUILD avec les détails recueillis à partir de l'invocation de newapkbuild, et l'introspection de la source du paquet téléchargé si url_source est fourni. Pour plus d'informations sur APKBUILD et son format, voir APKBUILD(5).

nom_paquet.initd

Si -c est donné, newapkbuild créera nom_paquet.initd avec des données d'exemple pour aider à la création d'un script init.d pour un démon.

nom_paquet.confd

Si -c est donné, newapkbuild créera nom_paquet.confd pour aider à la création d'un fichier conf.d pour un démon, utilisé par les scripts init.d. Les fichiers conf.d sont utilisés pour configurer les scripts init.d ; pour plus d'informations, voir openrc(8) et rc_config(3).

nom_paquet.pre-install

Si -c est donné, newapkbuild créera nom_paquet.pre-install, dont le contenu sera exécuté par apk(8) avant l'installation du paquet.

nom_paquet.post-install

Si -c est donné, newapkbuild créera nom_paquet.post-install, dont le contenu sera exécuté par apk(8) après que le paquet ait été installé avec succès. Pour plus d'informations sur les hooks d'installation apk, consultez le manuel de apk(8).

EXEMPLES

newapkbuild \
	-n sharutils \
	-d "Utilitaires pour manipuler les archives shell" \
	-l "GPL-3.0+" \
	-u "https://www.gnu.org/software/sharutils/" \
	-a \
	"https://ftp.gnu.org/gnu/sharutils/sharutils-4.15.2.tar.xz"
