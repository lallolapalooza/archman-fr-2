NETSTAT(8) Manuel de l'administrateur système Linux NETSTAT(8)

NOM

netstat - Afficher les connexions réseau, les tables de routage, les statistiques d'interface, les connexions masquées et les adhésions multicast.

SYNTAXE

netstat [options_famille_adresse] [--tcp|-t] [--udp|-u] [--udplite|-U] [--sctp|-S] [--raw|-w] [--l2cap|-2] [--rfcomm|-f] [--listening|-l] [--all|-a] [--numeric|-n] [--numeric-hosts] [--numeric-ports] [--numeric-users] [--symbolic|-N] [--extend|-e[--extend|-e]] [--timers|-o] [--program|-p] [--verbose|-v] [--continuous|-c] [--wide|-W]

netstat {--route|-r} [options_famille_adresse] [--extend|-e[--extend|-e]] [--verbose|-v] [--numeric|-n] [--numeric-hosts] [--numeric-ports] [--numeric-users] [--continuous|-c]

netstat {--interfaces|-i} [--all|-a] [--extend|-e[--extend|-e]] [--verbose|-v] [--program|-p] [--numeric|-n] [--numeric-hosts] [--numeric-ports] [--numeric-users] [--continuous|-c]

netstat {--groups|-g} [--numeric|-n] [--numeric-hosts] [--numeric-ports] [--numeric-users] [--continuous|-c]

netstat {--masquerade|-M} [--extend|-e] [--numeric|-n] [--numeric-hosts] [--numeric-ports] [--numeric-users] [--continuous|-c]

netstat {--statistics|-s} [--tcp|-t] [--udp|-u] [--udplite|-U] [--sctp|-S] [--raw|-w]

netstat {--version|-V}

netstat {--help|-h}

options_famille_adresse:

[-4|--inet] [-6|--inet6] [--protocol={inet,inet6,unix,ipx,ax25,netrom,ddp,bluetooth, ... } ] [--unix|-x] [--inet|--ip|--tcpip] [--ax25] [--x25] [--rose] [--ash] [--bluetooth] [--ipx] [--netrom] [--ddp|--appletalk] [--econet|--ec]

NOTES

Ce programme est largement obsolète. Le remplacement pour netstat est ss. Le remplacement pour netstat -r est ip route. Le remplacement pour netstat -i est ip -s link. Le remplacement pour netstat -g est ip maddr.

DESCRIPTION

Netstat affiche des informations sur le sous-système réseau de Linux. Le type d'informations affichées est contrôlé par le premier argument, comme suit :

(aucun)

Par défaut, netstat affiche une liste des sockets ouverts. Si vous ne spécifiez aucune famille d'adresse, alors les sockets actifs de toutes les familles d'adresses configurées seront affichés.

--route, -r

Affiche les tables de routage du noyau. Voir la description dans route(8) pour les détails. netstat -r et route -e produisent le même résultat.

--groups, -g

Affiche les informations d'adhésion aux groupes multicast pour IPv4 et IPv6.

--interfaces, -i

Affiche un tableau de toutes les interfaces réseau.

--masquerade, -M

Affiche une liste des connexions masquées.

--statistics, -s

Affiche des statistiques récapitulatives pour chaque protocole.

OPTIONS

--verbose, -v

Indique à l'utilisateur ce qui se passe en étant verbeux. Affiche notamment des informations utiles sur les familles d'adresses non configurées.

--wide, -W

Ne tronque pas les adresses IP en utilisant une sortie aussi large que nécessaire. Ceci est facultatif pour le moment afin de ne pas casser les scripts existants.

--numeric, -n

Affiche les adresses numériques au lieu d'essayer de déterminer les noms symboliques d'hôtes, de ports ou d'utilisateurs.

--numeric-hosts

Affiche les adresses hôtes numériques mais n'affecte pas la résolution des noms de ports ou d'utilisateurs.

--numeric-ports

Affiche les numéros de ports numériques mais n'affecte pas la résolution des noms d'hôtes ou d'utilisateurs.

--numeric-users

Affiche les identifiants d'utilisateurs numériques mais n'affecte pas la résolution des noms d'hôtes ou de ports.

--protocol=famille, -A

Spécifie les familles d'adresses (peut-être mieux décrites comme des protocoles de bas niveau) pour lesquelles les connexions doivent être affichées. famille est une liste séparée par des virgules (',') de mots-clés de famille d'adresses tels que inet, inet6, unix, ipx, ax25, netrom, econet, ddp et bluetooth. Ceci a le même effet que l'utilisation des options --inet|-4, --inet6|-6, --unix|-x, --ipx, --ax25, --netrom, --ddp et --bluetooth.

La famille d'adresses inet (IPv4) inclut les sockets de protocole raw, udp, udplite et tcp.

La famille d'adresses bluetooth (IPv4) inclut les sockets de protocole l2cap et rfcomm.

-c, --continuous

Cela fera en sorte que netstat affiche les informations sélectionnées toutes les secondes en continu.

-e, --extend

Affiche des informations supplémentaires. Utilisez cette option deux fois pour un maximum de détails.

-o, --timers

Inclut des informations relatives aux temporisateurs réseau.

-p, --program

Affiche le PID et le nom du programme auquel appartient chaque socket. Un tiret est affiché si le socket appartient au noyau (par exemple, un service noyau, ou si le processus est sorti mais que le socket n'a pas encore fini de se fermer).

-l, --listening

Affiche uniquement les sockets en écoute. (Ceux-ci sont omis par défaut.)

-a, --all

Affiche les sockets en écoute et ceux qui ne le sont pas. Avec l'option --interfaces, affiche les interfaces qui ne sont pas actives.

-F

Affiche les informations de routage à partir du FIB. (C'est le comportement par défaut.)

-C

Affiche les informations de routage à partir du cache de routage.

SORTIE

Connexions Internet actives (TCP, UDP, UDPLite, raw)

Proto

Le protocole (tcp, udp, udpl, raw) utilisé par le socket.

Recv-Q

Établi : Le nombre d'octets non copiés par le programme utilisateur connecté à ce socket. En écoute : Depuis le noyau 2.6.18, cette colonne contient la file d'attente syn courante.

Sen

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

d-Q

Établi : Le nombre d'octets non acquittés par l'hôte distant. Écoute : Depuis le noyau 2.6.18, cette colonne contient la taille maximale de la file d'attente des synchronisations.

Adresse Locale

Adresse et numéro de port de l'extrémité locale de la prise. Sauf si l'option --numeric (-n) est spécifiée, l'adresse de la prise est résolue en son nom d'hôte canonique (FQDN), et le numéro de port est traduit en nom de service correspondant.

Adresse Étrangère

Adresse et numéro de port de l'extrémité distante de la prise. Analogue à "Adresse Locale".

État

L'état de la prise. Comme il n'y a pas d'états en mode brut et généralement pas d'états utilisés en UDP et UDPLite, cette colonne peut être laissée vide. Normalement, cela peut être l'une des valeurs suivantes :

ÉTABLI
La prise a une connexion établie.
SYN_SENT
La prise tente activement d'établir une connexion.
SYN_RECV
Une requête de connexion a été reçue du réseau.
FIN_WAIT1
La prise est fermée et la connexion est en train d'être interrompue.
FIN_WAIT2
La connexion est fermée et la prise attend une interruption de l'extrémité distante.
TIME_WAIT
La prise attend après la fermeture pour traiter les paquets encore dans le réseau.
CLOSE
La prise n'est pas utilisée.
CLOSE_WAIT
L'extrémité distante a été interrompue, en attendant que la prise se ferme.
LAST_ACK
L'extrémité distante a été interrompue et la prise est fermée. En attente d'accusé de réception.
LISTEN
La prise écoute les connexions entrantes. De telles prises ne sont pas incluses dans la sortie, sauf si vous spécifiez l'option --listening (-l) ou --all (-a).
CLOSING
Les deux prises sont fermées mais nous n'avons pas encore tout notre envoi de données.
INCONNU
L'état de la prise est inconnu.

Utilisateur

Le nom d'utilisateur ou l'identifiant d'utilisateur (UID) du propriétaire de la prise.

PID/Nom du programme

Paire séparée par des barres obliques de l'identifiant de processus (PID) et du nom du processus qui possède la prise. --program provoque l'inclusion de cette colonne. Vous aurez également besoin des privilèges de superutilisateur pour voir ces informations sur les prises qui ne vous appartiennent pas. Ces informations d'identification ne sont pas encore disponibles pour les prises IPX.

Minuterie

Minuterie TCP associée à cette prise. Le format est minuterie(a/b/c). La minuterie est l'une des valeurs suivantes :

off
Aucune minuterie n'est définie pour cette prise.
on
La minuterie de retransmission est active pour la prise.
keepalive
La minuterie de maintien en vie est active pour la prise.
timewait
La connexion se ferme et la minuterie de temporisation est active pour la prise.

Les valeurs entre crochets :

a
Valeur de la minuterie.
b
Nombre de retransmissions envoyées.
c
Nombre de keepalives envoyées.

Prises de domaine UNIX Actives

Proto

Le protocole (généralement unix) utilisé par la prise.

RefCnt

Le nombre de références (c'est-à-dire les processus attachés via cette prise).

Indicateurs

Les indicateurs affichés sont SO_ACCEPTON (affiché comme ACC), SO_WAITDATA (W) ou SO_NOSPACE (N). SO_ACCECPTON est utilisé sur les prises non connectées si leurs processus correspondants attendent une requête de connexion. Les autres indicateurs ne présentent généralement pas d'intérêt.

Type

Il existe plusieurs types d'accès aux prises :

SOCK_DGRAM
La prise est utilisée en mode datagramme (sans connexion).
SOCK_STREAM
Il s'agit d'une prise de flux (connexion).
SOCK_RAW
La prise est utilisée comme une prise brute.
SOCK_RDM
Celle-ci sert des messages livrés de manière fiable.
SOCK_SEQPACKET
Il s'agit d'une prise de paquets séquentiels.
SOCK_PACKET
Prise d'accès à l'interface brute.
INCONNU
Qui sait ce que l'avenir nous réserve - juste rempli ici :-)

État

Ce champ contiendra l'un des mots-clés suivants :

FREE
La prise n'est pas allouée
LISTENING
La prise écoute une demande de connexion. De telles prises ne sont incluses dans la sortie que si vous spécifiez l'option --listening (-l) ou --all (-a).
CONNECTING
La prise est sur le point d'établir une connexion.
CONNECTED
La prise est connectée.
DISCONNECTING
La prise est en train de se déconnecter.
(vide)
La prise n'est pas connectée à une autre.
INCONNU
Cet état ne devrait jamais se produire.

PID/Nom du programme

Identifiant de processus (PID) et nom du processus qui a la prise ouverte. Plus d'informations disponibles dans la section Connexions Internet Actives écrite ci-dessus.

Chemin

C'est le nom du chemin auquel les processus correspondants se sont attachés à la prise.
