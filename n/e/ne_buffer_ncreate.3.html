NE_BUFFER_CREATE(3) Référence API neon NE_BUFFER_CREATE(3)

NOM

ne_buffer_create, ne_buffer_ncreate - créer un tampon de chaîne

SYNTAXE

#include <ne_alloc.h>

ne_buffer *ne_buffer_create(void);

ne_buffer *ne_buffer_ncreate(size_t taille);

DESCRIPTION

ne_buffer_create crée un nouvel objet tampon, avec une taille initiale définie par l'implémentation. ne_buffer_ncreate crée un ne_buffer où la taille initiale minimale est donnée par le paramètre taille. Le tampon créé contiendra la chaîne vide ("").

VALEUR DE RETOUR

Les deux fonctions retournent un pointeur vers un nouvel objet tampon, et jamais NULL.
