NOM

nethsm - Un CLI pour le Nitrokey NetHSM

SYNTAXE

nethsm [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] [-V|--version] <sous-commandes>

DESCRIPTION

Un CLI pour le Nitrokey NetHSM

OPTIONS

-a, --auth-passphrase-file <FICHIER_PHRASE_SECRETTE>
Le chemin vers un fichier contenant une phrase secrète pour l'authentification

La phrase secrète fournie dans le fichier doit être celle de l'utilisateur choisi pour la commande.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois. Avec plusieurs fichiers de phrase secrète, l'ordre est important, car les fichiers sont attribués à l'utilisateur respectif fourni par l'option "--user".

Peut également être spécifié avec la variable d'environnement NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIG>
Le chemin vers un fichier de configuration personnalisé

S'il est spécifié, le fichier de configuration personnalisé est utilisé à la place de l'emplacement par défaut du fichier de configuration.

Peut également être spécifié avec la variable d'environnement NETHSM_CONFIG.
-l, --label <ETIQUETTE>
Une étiquette identifiant de manière unique un appareil dans le fichier de configuration

Doit être fournie si plus d'un appareil est configuré dans le fichier de configuration.

Peut également être spécifié avec la variable d'environnement NETHSM_LABEL.
-u, --user <UTILISATEUR>
Un nom d'utilisateur utilisé pour une commande

Peut être fourni si aucun nom d'utilisateur n'est configuré dans le fichier de configuration pour un appareil. Doit être fourni si plusieurs noms d'utilisateurs du même rôle cible sont configurés dans le fichier de configuration pour un appareil.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois.

Peut également être spécifié avec la variable d'environnement NETHSM_USER.
-h, --help
Afficher l'aide (voir un résumé avec '-h')
-V, --version
Afficher la version
