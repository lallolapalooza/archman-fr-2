NE_SET_SESSION_FLAG(3) Référence API neon NE_SET_SESSION_FLAG(3)

NOM

ne_set_session_flag, ne_get_session_flag - définir et récupérer les indicateurs de session

SYNTAXE

#include <ne_request.h>

void ne_set_session_flag(ne_session *sess, ne_session_flag flag, int value);

int ne_get_session_flag(ne_session *sess, ne_session_flag flag);

DESCRIPTION

La fonction ne_set_session_flag active ou désactive un indicateur de session. Passer un argument value non nul active l'indicateur, et zéro le désactive.

Les indicateurs suivants sont définis :

NE_SESSFLAG_PERSIST (activé par défaut)

désactivez cet indicateur pour empêcher l'utilisation de connexions persistantes

NE_SESSFLAG_ICYPROTO (désactivé par défaut)

activez cet indicateur pour activer le support des réponses non HTTP de type "ICY" ShoutCast

NE_SESSFLAG_SSLv2

cet indicateur est ignoré

NE_SESSFLAG_RFC4918 (désactivé par défaut)

activez cet indicateur pour activer le support des fonctionnalités WebDAV uniquement RFC4918 ; perd la compatibilité ascendante avec les serveurs RFC2518

NE_SESSFLAG_CONNAUTH (désactivé par défaut)

activez cet indicateur si un schéma d'authentification HTTP basé sur la connexion, non conforme à la RFC, est utilisé

NE_SESSFLAG_TLS_SNI (activé par défaut)

désactivez cet indicateur si un serveur est utilisé qui ne supporte pas correctement l'extension SNI TLS

NE_SESSFLAG_EXPECT100 (désactivé par défaut)

activez cet indicateur pour activer l'indicateur de requête NE_REQFLAG_EXPECT100 pour les nouvelles requêtes

NE_SESSFLAG_SHAREPOINT (désactivé par défaut)

activez cet indicateur pour utiliser diverses solutions de contournement afin d'améliorer l'interopérabilité avec SharePoint

NE_SESSFLAG_STRICT (activé par défaut)

désactivez cet indicateur pour analyser les messages HTTP/1.1 sans les exigences strictes introduites dans la RFC 7230 et les versions ultérieures

VALEUR DE RETOUR

La fonction ne_get_session_flag renvoie zéro si un indicateur est désactivé, une valeur inférieure à zéro si l'indicateur n'est pas supporté, ou une valeur supérieure à zéro si l'indicateur est activé.
