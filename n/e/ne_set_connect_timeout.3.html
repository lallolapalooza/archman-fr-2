ne_set_connect_timeout(3)

Paquet: neon

Licences: LGPL-2.0-or-later

NE_SET_USERAGENT(3) Référence API neon NE_SET_USERAGENT(3)

NOM

ne_set_useragent, ne_set_read_timeout, ne_set_connect_timeout, ne_get_scheme, ne_get_server_hostport - propriétés communes pour les sessions HTTP

SYNTAXE

#include <ne_session.h>

void ne_set_useragent(ne_session *session, const char *product);

void ne_set_read_timeout(ne_session *session, int timeout);

void ne_set_connect_timeout(ne_session *session, int timeout);

const char *ne_get_scheme(ne_sesssion *session);

const char *ne_get_server_hostport(ne_sesssion *session);

DESCRIPTION

L'en-tête de requête User-Agent est utilisé pour identifier le logiciel qui a généré la requête à des fins statistiques ou de débogage. neon n'envoie pas d'en-tête User-Agent à moins qu'un appel à la fonction ne_set_useragent ne soit effectué. ne_set_useragent doit recevoir une chaîne de produit conforme à la grammaire des jetons de produit de la RFC2616 ; sous la forme "Produit/Version".

Lorsque neon lit depuis une socket, par défaut, l'opération de lecture expire après 60 secondes, et la requête échoue en donnant une erreur NE_TIMEOUT. Pour configurer cet intervalle de délai, appelez ne_set_read_timeout en fournissant le nombre de secondes désiré comme paramètre timeout.

Lorsqu'une connexion est en cours d'établissement avec un serveur, normalement seul le gestionnaire de délai d'attente TCP du système s'applique. Pour configurer un délai d'attente spécifique (et probablement plus court), la fonction ne_set_connect_timeout peut être utilisée, en fournissant le nombre de secondes désiré comme paramètre timeout. Si 0 est passé, alors le comportement par défaut consistant à utiliser le délai d'attente TCP du système sera utilisé.

Le schéma utilisé pour créer initialement la session sera retourné par ne_get_scheme.

La paire hôte:port à laquelle la session est associée sera retournée par la fonction ne_get_server_hostport ; par exemple www.example.com:8080. Notez que le port : sera omis si le port par défaut pour le schéma est utilisé.

EXEMPLES

Définir une chaîne user-agent :

ne_session *sess = ne_session_create(...);
ne_set_useragent(sess, "MonApplication/2.1");

Définir un délai de lecture de 30 secondes :

ne_session *sess = ne_session_create(...);
ne_set_read_timeout(sess, 30);
