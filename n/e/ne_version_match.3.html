NE_VERSION_MATCH(3) Référence API neon NE_VERSION_MATCH(3)

NOM

ne_version_match, ne_version_string - versionnement de la bibliothèque

SYNTAXE

#include <ne_utils.h>

int ne_version_match(int major, int minor);

const char *ne_version_string(void);

DESCRIPTION

La fonction ne_version_match retourne une valeur non nulle si la version de la bibliothèque n'est pas de version majeure major, ou si la version mineure est inférieure à minor. Pour les versions de neon 0.x, chaque version mineure est supposée être incompatible avec toutes les autres versions mineures.

La fonction ne_version_string retourne une chaîne indiquant la version de la bibliothèque.

EXEMPLES

Pour exiger neon 1.x, version 1.2 ou ultérieure :

if (ne_version_match(1, 2)) {
    printf("Version de la bibliothèque obsolète : 1.2 requise, trouvé %s.",
           ne_version_string());
    exit(1);
}
