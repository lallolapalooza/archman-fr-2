NOM

netctl - Contrôler le gestionnaire de profils réseau netctl

SYNTAXE

netctl {COMMANDE} [PROFIL]

netctl [--help | --version]

DESCRIPTION

netctl peut être utilisé pour introspecter et contrôler l'état des services systemd pour le gestionnaire de profils réseau.

OPTIONS

Les commandes suivantes sont comprises :

list

Liste tous les profils disponibles. Les profils en ligne seront marqués d'un ‘*’, sinon les profils actifs seront marqués d'un ‘+’.

store

Enregistre les profils actuellement actifs.

restore

Charge les profils qui étaient actifs lors de la dernière invocation de ‘store’.

stop-all

Arrête tous les profils réseau actifs.

start [PROFIL]

Démarre le profil réseau spécifié sur la ligne de commande.

stop [PROFIL]

Arrête le profil réseau spécifié sur la ligne de commande.

restart [PROFIL]

Redémarre le profil réseau spécifié sur la ligne de commande. S'il n'est pas déjà démarré, il sera démarré.

switch-to [PROFIL]

Démarre le profil réseau spécifié sur la ligne de commande après avoir arrêté tous les profils qui font référence à la même interface.

is-active [PROFIL]

Vérifie si le profil réseau spécifié sur la ligne de commande est actif. Affiche l'état actuel.

status [PROFIL]

Affiche des informations d'état d'exécution concises sur un profil, suivies de ses données de journal les plus récentes.

enable [PROFIL]

Active l'unité systemd pour le profil spécifié. Cela créera un fichier de configuration d'unité. Si le fichier existe déjà, la commande échoue. Aucun autre profil que celui spécifié ne sera activé. Les modifications apportées aux options générales dans une spécification de profil ne seront pas automatiquement propagées au fichier de configuration d'unité. Après de telles modifications, il est nécessaire de ‘reenable’ le profil.

disable [PROFIL]

Désactive l'unité systemd pour le profil spécifié. Cela supprimera le fichier créé par ‘enable’ même s'il a été personnalisé, alors soyez prudent.

reenable [PROFIL]

Réactive l'unité systemd pour le profil spécifié. Ceci est essentiellement une combinaison de ‘disable’ et ‘enable’.

is-enabled [PROFIL]

Vérifie si l'unité systemd pour le profil spécifié est activée. Affiche l'état d'activation actuel.

edit [PROFIL]

Ouvre le fichier du profil spécifié dans un éditeur. Cela ne réactive, ne redémarre ni ne vérifie aucun profil.

verify [PROFIL]

Vérifie le fichier du profil spécifié pour les erreurs de syntaxe. Si aucune erreur n'est trouvée, aucune sortie n'est produite.

wait-online [PROFIL]

Attend jusqu'à ce que l'interface du profil ait une adresse IP routable de quelque type que ce soit.

STATUT DE SORTIE

En cas de succès, 0 est retourné, sinon un code d'échec non nul.

ENVIRONNEMENT

$NETCTL_DEBUG

Si défini sur "yes", une sortie de débogage est générée.

La valeur de cette variable est indépendante de la valeur de la variable du même nom dans les profils.

$NETCTL_STATE_FILE

L'emplacement du fichier d'état. Par défaut, /var/lib/netctl/netctl.state.

VOIR AUSSI

netctl-auto(1), netctl.profile(5), netctl.special(7), systemctl(1)
