NEXTCLOUD(1) Manuel du client Nextcloud NEXTCLOUD(1)

NOM

nextcloud - Utilitaire de bureau de synchronisation de fichiers.

SYNOPSIS

nextcloud [OPTIONS...]

DESCRIPTION

Le client nextCloud est un utilitaire de bureau de synchronisation de fichiers. Il synchronise les fichiers sur votre ordinateur local, tablette ou appareil mobile avec un serveur nextCloud. Si vous modifiez des fichiers sur un appareil, la modification est propagée à tous les autres appareils synchronisés utilisant les clients de synchronisation de bureau.

Normalement, vous démarrez le client en cliquant sur l'icône du bureau ou en le lançant depuis le menu des applications du client. Après le lancement, une icône nextCloud apparaît dans la barre d'état système de l'ordinateur ou sur votre tablette ou appareil mobile.

OPTIONS

Vous avez la possibilité de lancer votre client de bureau Nextcloud avec la commande nextcloud. Les options suivantes sont prises en charge :

nextcloud -h ou nextcloud --help
Affiche toutes les options de commande.

Les autres options sont :

--logwindow
Ouvre une fenêtre affichant la sortie des journaux.
--logfile <nom_fichier>
Écrit la sortie des journaux dans le fichier spécifié. Pour écrire sur la sortie standard, spécifiez - comme nom de fichier.
--logdir <nom>
Écrit la sortie de chaque journal de synchronisation dans un nouveau fichier dans le répertoire spécifié.
--logexpire <heures>
Supprime les journaux plus anciens que la valeur spécifiée (en heures). Cette commande est utilisée avec --logdir.
--logflush
Efface (vide) le fichier journal après chaque action d'écriture.
--logdebug
Affiche également les messages de niveau débogage dans le journal (équivalent à définir la variable d'environnement QT_LOGGING_RULES="qt.*=true;*.debug=true").
--confdir <nom_répertoire>
Utilise le répertoire de configuration spécifié.
--background
Lance l'application en arrière-plan (c'est-à-dire sans ouvrir la fenêtre principale).

FICHIER DE CONFIGURATION

Le client Nextcloud lit un fichier de configuration. Vous pouvez localiser ce fichier de configuration comme suit :

Sur les distributions Linux :
$HOME/.config/Nextcloud/nextcloud.cfg
Sur les systèmes Microsoft Windows :
%APPDATA%\Nextcloud\nextcloud.cfg
Sur les systèmes macOS :
$HOME/Library/Preferences/Nextcloud/nextcloud.cfg

Le fichier de configuration contient des paramètres utilisant le format de fichier .ini de Microsoft Windows. Vous pouvez remplacer les modifications à l'aide de la boîte de dialogue de configuration de Nextcloud.

NOTE :

Soyez prudent lorsque vous apportez des modifications au fichier de configuration du client Nextcloud. Des paramètres incorrects peuvent entraîner des résultats indésirables.

Certaines valeurs intéressantes pouvant être définies dans le fichier de configuration sont :

nextcloud.1.en

NAME

nextcloud-client - A client for the Nextcloud service.

SYNOPSIS

nextcloudcmd [options] <source> <destination>
nextcloudcmd [options] --sync <source>
nextcloudcmd [options] --list-remote <host> [<path>]
nextcloudcmd [options] --ping <host>
nextcloudcmd [options] --get-folder-id <host> <path>
nextcloudcmd [options] --mkdir <host> <path>
nextcloudcmd [options] --rmdir <host> <path>
nextcloudcmd [options] --rm <host> <path>
nextcloudcmd [options] --mv <host> <source_path> <dest_path>
nextcloudcmd [options] --upload-folder-id <host> <folder_id> <local_path>
nextcloudcmd [options] --download-folder-id <host> <folder_id> <local_path>

DESCRIPTION

The nextcloudcmd program is a command-line client for the Nextcloud service. It allows you to synchronize local directories with Nextcloud, upload and download files, and perform other operations.

OPTIONS

The following options are available:

--all-users
Enable sync for all users. Requires administrator privileges.
--background
Run in the background.
--conf path
Path to the configuration file.
--daemon
Run as a daemon.
--daemon-timeout seconds
Timeout for the daemon in seconds.
--exclude pattern
Exclude files matching the given pattern.
--exclude-from file
Read exclusion patterns from a file.
--help
Show help message.
--list-remote host [<path>]
List remote files.
--mkdir host path
Create a remote directory.
--move host <source_path> <dest_path>
Move a remote file or directory.
--ping host
Ping the Nextcloud server.
--poll interval
Poll for changes at the given interval.
--remove host path
Remove a remote file or directory.
--remove-dir host path
Remove a remote directory.
--skip-updater
Skip the update check.
--status
Show status.
--sync source
Synchronize the source directory.
--update-interval seconds
Set the update interval in seconds.
--version
Show version information.
--width width
Set the output width.

CONFIG FILE

The configuration file is typically located at ~/.config/Nextcloud/nextcloud.cfg. The following settings can be configured:

Option Default Meaning
host 127.0.0.1 The address of the proxy server.
port 8080 The port were the proxy is listening.
type 2 0 for System Proxy.
1 for SOCKS5 Proxy.
2 for No Proxy.
3 for HTTP(S) Proxy.
