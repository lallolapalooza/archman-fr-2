NOM

netplan-get - lire la configuration Netplan fusionnée en YAML

SYNOPSIS

netplan [--debug] get -h|--help

netplan [--debug] get [--root-dir=ROOT_DIR] [clé]

DESCRIPTION

netplan get clé lit tous les fichiers YAML de /{etc,lib,run}/netplan/*.yaml et retourne une vue fusionnée de la configuration actuelle.

Vous pouvez spécifier all comme clé (par défaut) pour obtenir l'arbre YAML complet ou extraire un sous-arbre en spécifiant une clé imbriquée comme : [network.]ethernets.eth0.

Pour les détails du format du fichier de configuration, voir netplan(5).

OPTIONS

-h, --help
Affiche une aide de base.
--debug
Affiche la sortie de débogage pendant le processus.
--root-dir
Lit les fichiers YAML depuis cette racine au lieu de /.

VOIR AUSSI

netplan(5), netplan-set(8), netplan-dbus(8)
