NOM

nemo-desktop - Fournisseur de bureau pour Nemo

SYNTAXE

nemo-desktop [options] URIs...

DESCRIPTION

Cette page de manuel documente brièvement la commande nemo-desktop.

Nemo est le gestionnaire de fichiers pour le bureau Cinnamon.

OPTIONS

Nemo-desktop suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

--debug
Active le code de débogage. Exemple d'utilisation : 'NEMO_DEBUG=Desktop,Actions nemo-desktop --debug'. Utilisez NEMO_DEBUG=all pour plus de sujets.
--quit
Quitte Nemo.
--help
Affiche un résumé des options.
--version
Affiche la version de Nemo.
Les autres options GNOME standard non listées ici sont également prises en charge.

NOTE SUR L'UTILISATEUR ROOT

Normalement, nemo et nemo-desktop considèrent l'exécution en tant qu'utilisateur root comme spéciale, avec certaines restrictions et modifications de l'interface utilisateur. Ce comportement peut être contourné via une clé gsettings. Vous pouvez utiliser la commande suivante pour activer/désactiver ce remplacement :

gsettings set org.nemo.preferences treat-root-as-normal true|false
