NE_SET_USERAGENT(3) Référence API neon NE_SET_USERAGENT(3)

NOM

ne_set_useragent, ne_set_read_timeout, ne_set_connect_timeout, ne_get_scheme, ne_get_server_hostport - propriétés communes des sessions HTTP

SYNTAXE

#include <ne_session.h>

void ne_set_useragent(ne_session *session, const char *produit);

void ne_set_read_timeout(ne_session *session, int délai);

void ne_set_connect_timeout(ne_session *session, int délai);

const char *ne_get_scheme(ne_sesssion *session);

const char *ne_get_server_hostport(ne_sesssion *session);

DESCRIPTION

L'en-tête de requête User-Agent est utilisé pour identifier le logiciel qui a généré la requête à des fins statistiques ou de débogage. neon n'envoie pas d'en-tête User-Agent à moins qu'un appel à ne_set_useragent ne soit effectué. ne_set_useragent doit recevoir une chaîne de produit conforme à la grammaire des jetons de produit de la RFC2616 ; de la forme "Produit/Version".

Lorsque neon lit à partir d'une socket, par défaut l'opération de lecture expirera après 60 secondes, et la requête échouera en retournant une erreur NE_TIMEOUT. Pour configurer cet intervalle de délai, appelez ne_set_read_timeout en passant le nombre de secondes désiré comme paramètre délai.

Lorsqu'une connexion est établie à un serveur, normalement seule la gestion du délai TCP du système s'applique. Pour configurer un délai spécifique (et probablement plus court), ne_set_connect_timeout peut être utilisé, en passant le nombre de secondes désiré comme paramètre délai. Si 0 est passé, le comportement par défaut consistant à utiliser le délai TCP du système sera utilisé.

Le schéma utilisé pour créer initialement la session sera retourné par ne_get_scheme.

La paire hôte:port à laquelle la session est associée sera retournée par ne_get_server_hostport ; par exemple www.example.com:8080. Notez que le :port sera omis si le port par défaut pour le schéma est utilisé.

EXEMPLES

Définir une chaîne user-agent :

ne_session *sess = ne_session_create(...);
ne_set_useragent(sess, "MonApplication/2.1");

Définir un délai de lecture de 30 secondes :

ne_session *sess = ne_session_create(...);
ne_set_read_timeout(sess, 30);

ne_session_create, ne_set_session_flag.
