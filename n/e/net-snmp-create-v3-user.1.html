NOM

net-snmp-create-v3-user - créer un utilisateur SNMPv3 dans le fichier de configuration net-snmp

SYNOPSIS

net-snmp-create-v3-user [-ro] [-a authpass] [-x privpass] [-X DES|AES] [nom_utilisateur]

DESCRIPTION

Le script shell net-snmp-create-v3-user est conçu pour créer un nouvel utilisateur dans le fichier de configuration net-snmp (/var/net-snmp/snmpd.conf par défaut).

OPTIONS

--version
affiche le numéro de version de net-snmp
-ro
créer un utilisateur avec des permissions de lecture seule
-a authpass
spécifier le mot de passe d'authentification
-x privpass
spécifier le mot de passe de chiffrement
-X DES|AES
spécifier l'algorithme de chiffrement
