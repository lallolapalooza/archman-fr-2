NOM

ne_status - structure de statut HTTP

SYNTAXE

#include <ne_utils.h>
typedef struct {
    int major_version;
    int minor_version;
    int code;
    int klass;
    char *reason_phrase;
} ne_status;

DESCRIPTION

Le type ne_status représente un statut de réponse HTTP ; il est utilisé dans les messages de réponse donnant le résultat d'une requête. Les champs major_version et minor_version indiquent la version du protocole supportée par le serveur émettant la réponse. Le champ code indique le code de statut du résultat (compris entre 100 et 599 inclus), et le champ klass indique la classe, qui est égale au chiffre le plus significatif du statut. Le champ reason_phrase donne une chaîne de caractères lisible par l'homme décrivant le statut, qui est purement informative (et facultative) - toute interprétation du statut de réponse doit être effectuée à l'aide des champs klass et/ou code.

Il existe cinq classes de codes de statut de réponse définies pour HTTP/1.1 (voir RFC 9110 ẞ15[1]):

1xx

Réponse informative.

2xx

Succès : l'opération s'est déroulée avec succès

3xx

Redirection

4xx

Erreur côté client : la requête effectuée était incorrecte d'une manière ou d'une autre.

5xx

Erreur côté serveur

NOTES

Le champ klass est nommé « klass » et non « class » afin que l'en-tête puisse être utilisé depuis un programme C++, dans lequel « class » est un mot réservé.
