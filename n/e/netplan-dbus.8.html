NOM

netplan-dbus - démon pour accéder aux fonctionnalités de Netplan via une API D-Bus

SYNTAXE

netplan-dbus

DESCRIPTION

netplan-dbus est un démon D-Bus, fournissant io.netplan.Netplan sur le bus système. L'objet /io/netplan/Netplan fournit une interface io.netplan.Netplan, offrant les méthodes suivantes :

•
Apply() -> b : appelle netplan apply et retourne un statut de succès ou d'échec.
•
Generate() -> b : appelle netplan generate et retourne un statut de succès ou d'échec.
•
Info() -> a(sv) : retourne un dictionnaire "Features -> as", contenant un tableau de tous les indicateurs de fonctionnalités disponibles.
•
Config() -> o : prépare un nouvel objet de configuration comme /io/netplan/Netplan/config/<ID>, en copiant l'état actuel depuis /{etc,run,lib}/netplan/*.yaml.

Les objets /io/netplan/Netplan/config/<ID> fournissent une interface io.netplan.Netplan.Config, offrant les méthodes suivantes :

•
Get() -> s : appelle netplan get --root-dir=/run/netplan/config-ID all et retourne la configuration YAML fusionnée de l'état de l'objet de configuration donné.
•
Set(s:CONFIG_DELTA, s:ORIGIN_HINT) -> b : appelle netplan set --root-dir=/run/netplan/config-ID --origin-hint=ORIGIN_HINT CONFIG_DELTA

CONFIG_DELTA peut être quelque chose comme : network.ethernets.eth0.dhcp4=true et ORIGIN_HINT peut être quelque chose comme : 70-snapd (il écrira alors la configuration dans 70-snapd.yaml). Une fois que Set() est appelé sur un objet de configuration, tous les autres objets de configuration actuels et futurs sont invalidés et ne peuvent plus Set() ou Try()/Apply(), en raison de cet état modifié en attente. Après que l'objet de configuration modifié est rejeté via Cancel(), les autres objets de configuration redeviennent valides. Si l'objet de configuration modifié est accepté via Apply(), les nouveaux objets de configuration créés seront valides, tandis que les anciens états resteront invalides.

•
Try(u:TIMEOUT_SEC) -> b : remplace la configuration Netplan principale par l'état de cet objet de configuration et appelle netplan try --timeout=TIMEOUT_SEC.
•
Cancel() -> b : rejette une tentative Try() en cours sur cet objet de configuration et/ou rejette l'objet de configuration.
•
Apply() -> b : remplace la configuration Netplan principale par l'état de cet objet de configuration et appelle netplan apply.

Pour des informations sur les fonctionnalités Apply()/Try()/Get()/Set(), voir netplan-apply(8)/netplan-try(8)/netplan-get(8)/netplan-set(8) respectivement. Pour les détails du format des fichiers de configuration, voir netplan(5).

VOIR AUSSI

netplan(5), netplan-apply(8), netplan-try(8), netplan-get(8), netplan-set(8)
