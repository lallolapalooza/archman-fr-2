NOM

nethsm-system-restore - Restaure le périphérique à partir d'une sauvegarde

SYNOPSIS

nethsm system restore [-b|--backup-passphrase-file] [-s|--system-time] [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <ENTRÉE>

DESCRIPTION

Restaure le périphérique à partir d'une sauvegarde

Le périphérique peut être dans l'état "Opérationnel" ou "Non provisionné". Dans les deux cas, les utilisateurs et les clés de la sauvegarde remplacent ceux du périphérique (s'il y en a).

Si le périphérique est dans l'état "Non provisionné", les informations d'identification fournies pour l'authentification sont ignorées, la configuration système (par exemple, certificat TLS, mot de passe de déverrouillage, etc.) de la sauvegarde est utilisée, le périphérique redémarre et se retrouve dans l'état "Verrouillé".

Si aucune nouvelle heure système n'est fournie, elle est dérivée de l'heure système de l'appelant. Si aucune phrase de passe de sauvegarde n'est fournie spécifiquement, elle est demandée de manière interactive.

Nécessite l'authentification d'un utilisateur système dans le rôle "Administrateur" uniquement si le périphérique est dans l'état "Opérationnel".

OPTIONS

-b, --backup-passphrase-file <FICHIER_PHRASE_PASSE_SAUVEGARDE>
Le chemin d'accès à un fichier contenant la phrase de passe de la sauvegarde
Peut également être spécifié avec la variable d'environnement NETHSM_BACKUP_PASSPHRASE_FILE.
-s, --system-time <HEURE_SYSTEME>
La nouvelle heure système pour le périphérique

Doit être fournie sous forme d'horodatage UTC au format ISO 8601.

Peut également être spécifié avec la variable d'environnement NETHSM_SYSTEM_TIME.
-a, --auth-passphrase-file <FICHIER_PHRASE_PASSE_AUTH>
Le chemin d'accès à un fichier contenant une phrase de passe pour l'authentification

La phrase de passe fournie dans le fichier doit être celle de l'utilisateur choisi pour la commande.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois. Avec plusieurs fichiers de phrases de passe, l'ordre compte, car les fichiers sont attribués aux utilisateurs respectifs fournis par l'option "--user".

Peut également être spécifié avec la variable d'environnement NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIG>
Le chemin d'accès à un fichier de configuration personnalisé

Si spécifié, le fichier de configuration personnalisé est utilisé à la place de l'emplacement du fichier de configuration par défaut.

Peut également être spécifié avec la variable d'environnement NETHSM_CONFIG.
-l, --label <ETIQUETTE>
Une étiquette identifiant de manière unique un périphérique dans le fichier de configuration

Doit être fournie si plus d'un périphérique est configuré dans le fichier de configuration.

Peut également être spécifié avec la variable d'environnement NETHSM_LABEL.
-u, --user <UTILISATEUR>
Un nom d'utilisateur qui est utilisé pour une commande

Peut être fourni si aucun nom d'utilisateur n'est configuré dans le fichier de configuration pour un périphérique. Doit être fourni si plusieurs noms d'utilisateur du même rôle cible sont configurés dans le fichier de configuration pour un périphérique.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois.

Peut également être spécifié avec la variable d'environnement NETHSM_USER.
-h, --help
Affiche l'aide (voir un résumé avec '-h')
<ENTRÉE>
Le chemin d'accès à un fichier de sauvegarde NetHSM valide
Peut également être spécifié avec la variable d'environnement NETHSM_BACKUP_FILE.
