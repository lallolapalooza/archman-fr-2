NOM

netkey-tool - utilitaire administratif pour les cartes Netkey E4

SYNTAXE

netkey-tool [OPTIONS] [COMMANDE]

DESCRIPTION

L'utilitaire netkey-tool peut être utilisé depuis la ligne de commande pour effectuer certaines opérations de carte à puce avec les cartes NetKey E4 qui ne peuvent pas être réalisées facilement avec d'autres outils OpenSC, telles que la modification des codes PIN locaux, le stockage de certificats dans des fichiers de certificat NetKey E4 vides ou l'affichage de la valeur initiale du PUK.

OPTIONS

--help, -h

Affiche un court message d'aide.

--pin pin, -p pin

Spécifie la valeur actuelle du code PIN global.

--puk pin, -u pin

Spécifie la valeur actuelle du PUK global.

--pin0 pin, -0 pin

Spécifie la valeur actuelle du PIN0 local (également appelé PIN local).

--pin1 pin, -1 pin

Spécifie la valeur actuelle du PUK1 local (également appelé PUK local).

--reader arg, -r arg

Numéro du lecteur à utiliser. Par défaut, le premier lecteur avec une carte présente est utilisé. Si arg est un ATR, le lecteur avec une carte correspondante sera choisi.

-v

Rend netkey-tool plus verbeux. Cette option peut être spécifiée plusieurs fois pour augmenter la verbosité.

FORMAT DU PIN

Avec -p, -u, -0 ou -1, l'un des codes PIN des cartes peut être spécifié. Vous pouvez utiliser des chaînes ASCII simples (par exemple, 123456) ou une chaîne hexadécimale (par exemple, 31:32:33:34:35:36). Une chaîne hexadécimale doit se composer exactement de n nombres hexadécimaux à 2 chiffres séparés par n-1 deux-points. Sinon, elle sera interprétée comme une chaîne ASCII. Par exemple :12:34: et 1:2:3:4 sont des codes PIN de longueur 7, tandis que 12:34 et 01:02:03:04 sont des codes PIN de longueur 2 et 4.

COMMANDES

Lorsqu'il est utilisé sans options ni commandes, netkey-tool affichera des informations sur les codes PIN et les certificats des cartes à puce. Cela ne modifiera aucun aspect de votre carte (en supposant qu'il n'y ait pas de bugs dans netkey-tool). En particulier, les compteurs d'essais restants des codes PIN sont examinés sans effectuer de vérifications réelles des codes PIN.

Si vous spécifiez le code PIN global via l'option --pin, netkey-tool affichera également la valeur initiale du PUK global de la carte. Si votre PUK global a été modifié, netkey-tool affichera toujours sa valeur initiale. Il n'y a aucun moyen de récupérer un PUK global perdu une fois qu'il a été modifié. Il n'y a pas non plus de moyen d'afficher la valeur initiale de votre PUK global sans connaître la valeur actuelle de votre code PIN global.

Pour la plupart des commandes que netkey-tool peut exécuter, vous devez spécifier un code PIN. Une exception notable est la commande nullpin, mais cette commande ne peut être exécutée qu'une seule fois dans la durée de vie d'une carte NetKey E4.

cert nombre nom_fichier

Cette commande lira l'un de vos certificats de carte (tel que spécifié par nombre) et enregistrera ce certificat dans le fichier nom_fichier au format PEM. Les certificats sur une carte NetKey E4 sont lisibles sans code PIN, vous n'avez donc pas besoin d'en spécifier un.

cert nom_fichier nombre

Cette commande lira le premier certificat encodé en PEM à partir du fichier nom_fichier et le stockera dans le fichier de certificat nombre de votre carte à puce. Certains de vos fichiers de certificat de carte à puce peuvent être en lecture seule, donc cela ne fonctionnera pas avec toutes les valeurs de nombre. Si un fichier de certificat est inscriptible, vous devez spécifier un code PIN pour le modifier. Si vous essayez d'utiliser cette commande sans spécifier de code PIN, netkey-tool vous indiquera lequel est nécessaire.

change {pin | puk | pin0 | pin1} nouveau_pin

Cela modifie la valeur du code PIN spécifié par la nouvelle valeur donnée. Vous devez spécifier soit la valeur actuelle du code PIN, soit un autre code PIN pour pouvoir le faire, et si vous ne spécifiez pas le bon, netkey-tool vous indiquera lequel est nécessaire.

nullpin pin_initial

Cette commande ne peut être exécutée que si le code PIN global de votre carte est dans l'état nullpin. Il n'y a aucun moyen de revenir à l'état nullpin une fois que vous avez modifié votre code PIN global. Vous n'avez pas besoin de code PIN pour exécuter la commande nullpin. Après une commande nullpin réussie, netkey-tool affichera la valeur PUK initiale de votre carte.

unblock {pin | pin0 | pin1}

Cela débloque le code PIN spécifié. Vous devez spécifier un autre code PIN pour pouvoir le faire, et si vous ne spécifiez pas le bon, netkey-tool vous indiquera lequel est nécessaire.
