netsnmp_agent_api(3)

Paquet: net-snmp

Licences: BSD

NETSNMP_AGENT_API(3) Net-SNMP NETSNMP_AGENT_API(3)

NOM

netsnmp_agent_api - intégrer un agent dans une application externe

SYNTAXE

#include <net-snmp/net-snmp-config.h>
#include <net-snmp/net-snmp-includes.h>
#include <net-snmp/agent/net-snmp-agent-includes.h>
int
main (int argc, char *argv[])
{
  int agentx_subagent = 1;  /* Changez ceci si vous êtes un agent maître.  */
  snmp_enable_stderrlog();
  /*  Si nous sommes un sous-agent AgentX...  */
  if (agentx_subagent) {
      /* ...faisons de nous un client AgentX.  */
      netsnmp_ds_set_boolean(NETSNMP_DS_APPLICATION_ID,
                             NETSNMP_DS_AGENT_ROLE, 1);
  }
  init_agent("nomdevotresuperapplication");
  /*  Initialisez votre code MIB ici.  */
  init_mon_code_mib();
  /*  `nomdevotresuperapplication' sera utilisé pour lire les fichiers nomdevotresuperapplication.conf.  */
  init_snmp("nomdevotresuperapplication");
  /*  Si nous devons être un agent maître SNMP...  */
  if (!agentx_subagent)
      init_master_agent();  /*  Écoute sur le port par défaut (161).  */
  /*  Votre boucle principale ici...  */
  while (quelquechose) {
      /* si vous utilisez select(), voir snmp_api(3) */
      /*     --- OU ---  */
      agent_check_and_process(0); /* 0 == ne pas bloquer */
  }
  /*  Au moment de l'arrêt :  */
  snmp_shutdown("nomdevotresuperapplication");
}
Puis :
$(CC) ... `net-snmp-config --agent-libs`

DESCRIPTION

Notre objectif est de créer une interface facile à utiliser pour le package Net-SNMP afin que vous puissiez prendre du code que vous avez écrit et qui a été conçu pour être un module MIB Net-SNMP et l'intégrer dans une application externe où vous pouvez choisir d'être un agent maître SNMP ou un sous-agent AgentX en utilisant le même code de module MIB. Notre suggestion est que vous utilisiez notre agent SNMP (ou un autre) comme agent maître AgentX et que vous choisissiez de devenir un sous-agent AgentX qui s'attache ensuite au maître.

Le package Net-SNMP fournit une paire de bibliothèques qui permet une intégration facile d'un agent SNMP ou AgentX dans un package logiciel externe. AgentX est un protocole extensible conçu pour permettre à plusieurs sous-agents SNMP de s'exécuter sur une seule machine sous un seul agent maître SNMP. Il est défini dans la RFC 2741.

Vous devrez effectuer quelques tâches pour y parvenir. Tout d'abord, vous devrez initialiser à la fois la bibliothèque SNMP et la bibliothèque de l'agent SNMP. Comme indiqué ci-dessus, cela se fait légèrement différemment selon que vous allez vous comporter en tant qu'agent maître ou en tant que sous-agent AgentX.

CONFIGURATION

Si vous avez l'intention de fonctionner en tant que sous-agent AgentX, vous devrez avoir configuré le package Net-SNMP avec le support d'agentx (qui est activé par défaut, donc ne le désactivez pas)

De plus, vous devrez lier les bibliothèques Net-SNMP (utilisez la sortie de "net-snmp-config --agent-libs" pour obtenir une liste de bibliothèques) et appeler subagent_pre_init() comme indiqué ci-dessus.

COMPILATION

Pour utiliser l'une des API ci-dessus, vous devrez lier au moins les quatre bibliothèques listées ci-dessus.

FONCTIONS

où trouver plus d'informations à leur sujet. Ce n'est certainement pas une liste complète de ce qui est disponible dans toutes les bibliothèques Net-SNMP.

snmp_enable_stderrlog()
Journalise la sortie d'erreur de l'agent SNMP sur le flux d'erreurs standard.
netsnmp_ds_set_boolean()
Veuillez consulter la page du manuel default_store(3) pour plus d'informations sur cette API.
init_agent(char *nom)
Initialise l'agent intégré. Cela doit être appelé avant l'appel à init_snmp(). nom est utilisé pour indiquer quel fichier .conf lire lorsque init_snmp() est appelé plus tard.
init_snmp(char *nom)
Initialise la bibliothèque SNMP. Notez qu'une des choses qu'elle fera sera de lire les fichiers de configuration dans le but de configurer votre application. Elle tentera de lire les fichiers de configuration nommés par la chaîne nom que vous avez passée. Elle peut être utilisée pour configurer le contrôle d'accès, par exemple. Veuillez consulter les pages du manuel netsnmp_config_api(3), snmp_config(5) et snmpd.conf(5) pour plus de détails sur ce sujet.
init_master_agent(void)
Initialise l'agent maître et le fait écouter les requêtes SNMP sur son port UDP par défaut de 161.
agent_check_and_process(int bloquer)
Ceci vérifie l'arrivée de paquets sur le port SNMP et les traite s'il en trouve. Si bloquer est différent de zéro, l'appel de fonction bloquera jusqu'à l'arrivée d'un paquet ou jusqu'à ce qu'une alarme doive être déclenchée (voir snmp_alarm(3)). La valeur de retour de cette fonction est un entier positif si des paquets ont été traités, zéro si une alarme s'est produite et -1 si une erreur s'est produite.
snmp_shutdown(char *nom);
Ceci arrête l'agent, sauvegardant tout stockage persistant nécessaire, etc.
