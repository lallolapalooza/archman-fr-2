ne_xml_create(3)

Paquet: neon

Licences: LGPL-2.0-or-later

NE_XML_CREATE(3) Référence API neon NE_XML_CREATE(3)

NOM

ne_xml_create, ne_xml_destroy - créer et détruire un analyseur XML

SYNTAXE

#include <ne_xml.h>

ne_xml_parser *ne_xml_create(void);

void ne_xml_destroy(ne_xml_parser *parser);

DESCRIPTION

La fonction ne_xml_create crée un objet analyseur XML, qui peut être utilisé pour analyser des documents XML à l'aide de gestionnaires SAX empilés.

VALEUR DE RETOUR

ne_xml_create retourne un pointeur vers un objet analyseur XML, et jamais NULL.

VOIR AUSSI

ne_xml_parse_response
