NOM

netplan-try - essaie une configuration, en la rétablissant éventuellement

SYNTAXE

netplan [--debug] try -h|--help

netplan [--debug] try [--config-file CONFIG_FILE] [--timeout TIMEOUT]

DESCRIPTION

netplan try prend une configuration netplan(5), l'applique, et la rétablit automatiquement si l'utilisateur ne confirme pas la configuration dans un délai imparti.

Une configuration peut être confirmée ou rejetée interactivement ou en envoyant les signaux SIGUSR1 ou SIGINT.

Ceci peut être particulièrement utile sur des systèmes distants, pour éviter qu'un administrateur ne se retrouve définitivement exclu des systèmes en cas d'erreur de configuration réseau.

OPTIONS

-h, --help
Affiche l'aide de base.
--debug
Affiche les messages de débogage pendant le processus.
--config-file FICHIER_CONFIG
En plus de la configuration habituelle, applique FICHIER_CONFIG. Ce doit être un fichier YAML au format netplan(5).
--timeout TEMPS_LIMITE
Attend pendant TEMPS_LIMITE secondes avant de rétablir. Par défaut, 120 secondes. Notez que certaines configurations réseau (comme le STP) peuvent prendre plus d'une minute pour se stabiliser.

PROBLÈMES CONNUS

netplan try utilise des procédures similaires à netplan apply, donc certaines des mêmes mises en garde s'appliquent concernant les périphériques virtuels.

Il existe également des bugs connus : si netplan try expire ou est annulé, assurez-vous de vérifier si la configuration réseau a bien été rétablie.

Comme avec netplan apply, un redémarrage devrait résoudre tous les problèmes. Cependant, assurez-vous de vérifier que la configuration sur le disque est bien dans l'état attendu avant de redémarrer !

VOIR AUSSI

netplan(5), netplan-generate(8), netplan-apply(8)
