NOM

neon-config - script fournissant des informations sur la copie installée de la bibliothèque neon

SYNTAXE

neon-config [--prefix] [[--cflags] | [--libs] | [--la-file] | [--support feature] | [--help] | [--version]]

DESCRIPTION

Le script neon-config fournit des informations sur une copie installée de la bibliothèque neon. Les options --cflags et --libs indiquent comment compiler et lier une application contre la bibliothèque ; les options --version et --support peuvent aider à déterminer si la bibliothèque répond aux exigences de l'application.

OPTIONS

--cflags

Affiche les drapeaux qui doivent être passés au compilateur C lors de la compilation de fichiers objets, lorsque les fichiers objets utilisent les fichiers d'en-tête neon.

--libs

Affiche les drapeaux qui doivent être passés à l'éditeur de liens lors de la liaison d'une application qui utilise la bibliothèque neon.

--la-file

Affiche l'emplacement du script de bibliothèque libtool, libneon.la, qui peut être utilisé pour lier contre neon par les applications utilisant libtool.

--version

Affiche la version de la bibliothèque.

--prefix dir

Si dir est donné, relocalise la sortie de --cflags et --libs comme si neon était installé dans le répertoire préfixe donné. Sinon, affiche le préfixe d'installation de la bibliothèque.

--support feature

Le script se termine avec succès si feature est prise en charge par la bibliothèque.

--help

Affiche le message d'aide ; inclut la liste des fonctionnalités connues et indique si elles sont prises en charge ou non.

EXEMPLE

Ci-dessous se trouve un fragment de Makefile qui pourrait être utilisé pour construire une application contre une bibliothèque neon installée, lorsque le script neon-config peut être trouvé dans $PATH.

CFLAGS = `neon-config --cflags`
LIBS = `neon-config --libs`
OBJECTS = myapp.o
TARGET = myapp
$(TARGET): $(OBJECTS)
	$(CC) $(LDFLAGS) -o $(TARGET) $(OBJECTS) $(LIBS)
myapp.o: myapp.c
	$(CC) $(CFLAGS) -c myapp.c -o myapp.o
