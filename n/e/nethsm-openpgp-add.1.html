NOM

nethsm-openpgp-add - Ajouter un certificat OpenPGP pour une clé

SYNTAXE

nethsm openpgp add [-t|--time] [-v|--version] [--can-sign] [--cannot-sign] [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <ID_CLE> <ID_UTILISATEUR>

DESCRIPTION

Ajouter un certificat OpenPGP pour une clé

Crée un certificat OpenPGP pour une clé existante. Le certificat créé est ensuite ajouté comme certificat de la clé (voir « nethsm key cert import »).

Les utilisateurs système dans les rôles « Administrateur » et « Opérateur » ne peuvent ajouter des certificats OpenPGP que pour les clés système. Les utilisateurs de l'espace de noms dans les rôles « Administrateur » et « Opérateur » ne peuvent ajouter des certificats OpenPGP que pour les clés de leur propre espace de noms.

Nécessite l'authentification d'un utilisateur dans le rôle « Opérateur », qui a accès à la clé ciblée (voir « nethsm key tag » et « nethsm user tag »). De plus, l'authentification d'un utilisateur dans le rôle « Administrateur » est nécessaire pour importer le certificat.

OPTIONS

-t, --time <TEMPS>
L'heure de création optionnelle du certificat (par défaut, maintenant)
Peut également être spécifié avec la variable d'environnement NETHSM_OPENPGP_CREATED_AT.
-v, --version <VERSION>
La version OpenPGP avec laquelle le certificat est créé (par défaut « 4 »)

L'un des éléments suivants : ["4", "6"].

Peut également être spécifié avec la variable d'environnement NETHSM_OPENPGP_VERSION.
--can-sign
Définit l'indicateur de clé de signature (défaut : défini)

Si cette option est utilisée, la clé est créée avec une clé composante qui a l'indicateur de clé de signature défini.

Peut également être spécifié avec la variable d'environnement NETHSM_OPENPGP_CERT_GENERATE_CAN_SIGN.
--cannot-sign
Efface l'indicateur de clé de signature

Si cette option est utilisée, la clé est créée sans clé composante ayant l'indicateur de clé de signature défini.

Peut également être spécifié avec la variable d'environnement NETHSM_OPENPGP_CERT_GENERATE_CANNOT_SIGN.
-a, --auth-passphrase-file <FICHIER_PASSPHRASE_AUTH>
Le chemin d'accès à un fichier contenant une phrase secrète pour l'authentification

La phrase secrète fournie dans le fichier doit être celle de l'utilisateur choisi pour la commande.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois. Avec plusieurs fichiers de phrases secrètes, l'ordre est important, car les fichiers sont attribués à l'utilisateur respectif fourni par l'option « --user ».

Peut également être spécifié avec la variable d'environnement NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIG>
Le chemin d'accès à un fichier de configuration personnalisé

S'il est spécifié, le fichier de configuration personnalisé est utilisé à la place de l'emplacement du fichier de configuration par défaut.

Peut également être spécifié avec la variable d'environnement NETHSM_CONFIG.
-l, --label <ETIQUETTE>
Une étiquette identifiant de manière unique un périphérique dans le fichier de configuration

Doit être fourni si plusieurs périphériques sont configurés dans le fichier de configuration.

Peut également être spécifié avec la variable d'environnement NETHSM_LABEL.
-u, --user <UTILISATEUR>
Un nom d'utilisateur qui est utilisé pour une commande

Peut être fourni si aucun nom d'utilisateur n'est configuré dans le fichier de configuration pour un périphérique. Doit être fourni si plusieurs noms d'utilisateur du même rôle cible sont configurés dans le fichier de configuration pour un périphérique.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois.

Peut également être spécifié avec la variable d'environnement NETHSM_USER.
-h, --help
Imprimer l'aide (voir un résumé avec '-h')
<ID_CLE>
L'ID de la clé à utiliser
Peut également être spécifié avec la variable d'environnement NETHSM_KEY_ID.
<ID_UTILISATEUR>
L'ID utilisateur à utiliser pour la clé
Peut également être spécifié avec la variable d'environnement NETHSM_OPENPGP_USERID.
