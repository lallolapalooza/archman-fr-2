NOM

ne_get_request_target - récupérer la cible de la requête

SYNOPSIS

#include <ne_request.h>

const ne_uri *ne_get_request_target(ne_request *req);

DESCRIPTION

La fonction ne_get_request_target renvoie l'URI cible de la requête sous la forme d'un pointeur vers un objet ne_uri. La "ressource cible" d'une requête est définie par la Section 7.1 de la RFC 9110[1] et est dérivée des paramètres utilisés pour créer la requête avec ne_request_create et des paramètres utilisés pour créer la session avec ne_session_create.

VALEUR DE RETOUR

La fonction ne_get_request_target renvoie un ne_uri, ou NULL s'il n'a pas été possible de créer l'URI cible. Ce dernier cas peut uniquement se produire si le chemin utilisé pour créer l'objet de requête n'était pas un chemin d'URI valide. Notez que le champ path de l'objet renvoyé peut être une chaîne vide si la forme autorité de l'URI est utilisée.

HISTORIQUE

ne_get_request_target est disponible dans neon 0.34.0 et versions ultérieures.

VOIR AUSSI

ne_request_create, ne_session_create.
