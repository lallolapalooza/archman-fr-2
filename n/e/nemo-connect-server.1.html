NOM

nemo-connect-server - Pour accéder à un serveur distant

SYNTAXE

nemo-connect-server [options] [URI]

DESCRIPTION

Cette page de manuel documente brièvement la commande nemo-connect-server.

Nemo Connect Server est le gestionnaire de connexion pour le bureau GNOME.

Vous pouvez utiliser le gestionnaire de fichiers pour accéder à un serveur distant, qu'il s'agisse d'un site FTP, d'un partage Windows, d'un serveur WebDav ou d'un serveur SSH.

OPTIONS

Nemo suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

--help
Afficher un résumé des options.
--version
Afficher la version.
D'autres options GNOME standard non listées ici sont également prises en charge.

VOIR AUSSI

La documentation de Nemo Connect Server peut être trouvée dans le menu "Aide", ou en appuyant sur la touche F1. Nemo a également un site web à http://www.gnome.org/projects/nemo/
