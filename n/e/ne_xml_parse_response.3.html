NE_XML_PARSE_RESPONS(3) Référence API neon NE_XML_PARSE_RESPONS(3)

NOM

ne_xml_parse_response, ne_xml_dispatch_request, ne_xml_dispatchif_request - fonctions d'assistance pour l'analyse des réponses XML

SYNTAXE

#include <ne_xmlreq.h>

int ne_xml_parse_response(ne_request *req, ne_xml_parser *parser);

int ne_xml_dispatch_request(ne_request *req, ne_xml_parser *parser);

int ne_xml_dispatchif_request(ne_request *req, ne_xml_parser *parser, ne_accept_response acceptor, void *userdata);

DESCRIPTION

La fonction ne_xml_parse_response lit le corps d'une réponse HTTP et le traite à l'aide de l'analyseur XML fourni. La fonction doit être appelée après que ne_begin_request a retourné un succès pour la requête, puis elle appelle ne_read_response_block jusqu'à ce que le corps entier de la réponse ait été lu. En cas de retour réussi, ne_end_request doit être appelé pour finaliser le traitement de la réponse.

Les fonctions ne_xml_dispatch_request et ne_xml_dispatchif_request sont équivalentes à l'appel de ne_request_dispatch pour envoyer une requête HTTP et traiter la réponse, en analysant le corps de la réponse à l'aide de l'analyseur XML fourni sous certaines conditions :

•Pour ne_xml_dispatch_request, toute réponse de classe 2xx avec un type de contenu XML.
•Pour ne_xml_dispatchif_request, si la fonction de rappel acceptor retourne une valeur non nulle, et que la réponse utilise un type de contenu XML.

Dans les deux cas, les règles de la RFC 7303[1] sont suivies pour identifier les types de contenu XML, c'est-à-dire text/xml, application/xml, ou tout autre type de contenu se terminant par un suffixe +xml. Le paramètre userdata est passé à la fonction acceptor.

Pour les trois fonctions :

•l'analyseur XML est appelé de manière répétée jusqu'à atteindre la fin du document.
•si une erreur se produit pendant l'analyse XML, la chaîne d'erreur de la session est définie pour décrire l'erreur d'analyse, et la connexion est terminée sans poursuivre le traitement de la réponse.

VALEUR DE RETOUR

Toutes les fonctions documentées ici retournent zéro en cas de succès, ou un code d'erreur NE_* en cas d'échec.

HISTORIQUE

ne_xml_dispatchif_request est disponible dans neon 0.36.0 et plus récent.

VOIR AUSSI

ne_xml_create, ne_request_dispatch
