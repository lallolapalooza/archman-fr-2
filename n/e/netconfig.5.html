NETCONFIG(5) Manuel des formats de fichiers NETCONFIG(5)

NOM

netconfig — base de données de configuration réseau

SYNOPSIS

/etc/netconfig

DESCRIPTION

Le fichier netconfig définit une liste de « noms de transport », décrivant leur sémantique et leur protocole. Dans FreeBSD, ce fichier n'est utilisé que par le code de la bibliothèque RPC.

Les entrées ont le format suivant :

id_réseau sémantique drapeaux famille nom_protocole périphérique bibliothèques

Les entrées se composent des champs suivants :

id_réseau
Le nom du transport décrit.
sémantique
Décrit la sémantique du transport. Peut être l'une des suivantes :
tpi_clts
Transport sans connexion.
tpi_cots
Transport orienté connexion.
tpi_cots_ord
Transport orienté connexion, ordonné.
tpi_raw
Une connexion brute.
drapeaux
Ce champ est soit vide (spécifié par « - »), soit contient un « v », signifiant visible par la fonction getnetconfig(3).
famille
La famille de protocoles du transport. Actuellement, peut être :
inet6
La famille de protocoles IPv6 (PF_INET6).
inet
La famille de protocoles IPv4 (PF_INET).
loopback
La famille de protocoles PF_LOCAL.
nom_protocole
Le nom du protocole utilisé pour ce transport. Peut actuellement être udp, tcp ou vide.
périphérique
Ce champ est toujours vide dans FreeBSD.
bibliothèques
Ce champ est toujours vide dans FreeBSD.

L'ordre des entrées dans ce fichier déterminera quel transport sera préféré par le code de la bibliothèque RPC, étant donné une correspondance sur un type de réseau spécifié. Par exemple, si un exemple de fichier de configuration réseau ressemblait à ceci :

udp6       tpi_clts      v     inet6    udp     -       -
tcp6       tpi_cots_ord  v     inet6    tcp     -       -
udp        tpi_clts      v     inet     udp     -       -
tcp        tpi_cots_ord  v     inet     tcp     -       -
rawip      tpi_raw       -     inet      -      -       -
local      tpi_cots_ord  -     loopback  -      -       -

alors l'utilisation du type de réseau udp dans les appels à la fonction de la bibliothèque RPC (voir rpc(3)) amènera le code à essayer d'abord udp6, puis udp.

getnetconfig(3) et les fonctions associées analyseront ce fichier et retourneront des structures du format suivant :

struct netconfig {
    char *nc_netid;              /* ID réseau */
    unsigned long nc_semantics;  /* Sémantique (voir ci-dessous) */
    unsigned long nc_flag;       /* Indicateurs (voir ci-dessous) */
    char *nc_protofmly;          /* Famille de protocoles */
    char *nc_proto;              /* Nom du protocole */
    char *nc_device;             /* Chemin d'accès du périphérique réseau (non utilisé) */
    unsigned long nc_nlookups;   /* Nombre de bibliothèques de recherche (non utilisé) */
    char **nc_lookups;           /* Noms des bibliothèques (non utilisé) */
    unsigned long nc_unused[9];  /* réservé */
};

FICHIERS

/etc/netconfig
 

VOIR AUSSI

getnetconfig(3), getnetpath(3)
