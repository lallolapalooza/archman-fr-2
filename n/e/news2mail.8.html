NOM

news2mail - Script de canal pour transférer les news dans des e-mails

SYNTAXE

news2mail

DESCRIPTION

news2mail s'exécute comme un processus de canal sous innd. Il est configuré comme un flux de canal dans newsfeeds, avec différentes listes de diffusion comme entrées de entonnoir qui pointent vers lui (voir ci-dessous) ; news2mail attend le jeton d'un article suivi d'une séquence de noms de listes.

news2mail utilise le fichier de configuration pathetc/news2mail.cf pour mapper les noms des listes de diffusion aux adresses e-mail. news2mail fait en sorte que l'agent de transport de courrier (généralement sendmail, tel que défini dans le paramètre mta de inn.conf) mette en file d'attente les messages pour une livraison ultérieure (afin d'éviter les attaques par déni de service par des publications massives). Vous devez exécuter "sendmail -q" périodiquement pour que la file d'attente soit traitée.

FICHIER DE CONFIGURATION

Le format du fichier de configuration est simple : les commentaires (commençant par un signe dièse "#") et les lignes vides sont ignorés. Toutes les autres lignes contiennent deux ou trois champs. Le premier est le nom de la liste et est celui que innd utilise (c'est-à-dire le champ site de l'entrée dans le fichier newsfeeds). Le deuxième champ est l'adresse e-mail réelle vers laquelle envoyer l'article. Le troisième champ est optionnel : il définit l'adresse de l'expéditeur de l'enveloppe (par exemple, l'adresse d'un membre de la liste ; s'il n'est pas défini, il prend par défaut l'utilisateur "news").

Dans les messages électroniques, le champ d'en-tête To aura l'adresse de la liste de diffusion (c'est-à-dire le deuxième champ). De plus, news2mail supprime la plupart des champs d'en-tête de l'article avant l'envoi.

Dans newsfeeds, le flux de canal devrait ressembler à ceci :

news2mail!:!*:Ac,Tc,Wn*:<pathbin>/news2mail

et pour chaque liste de diffusion, il suffit d'ajouter à newsfeeds une entrée de liste comme celle-ci :

list-big-red-ants/lists.ucsd.edu\
    :!*,rec.pets.red-ants\
    :Ap,Tm:news2mail!

Notez l'utilisation de "Ap" et l'exclusion du domaine du propriétaire de la liste pour protéger la liste de la réception de nouveaux articles de la liste. Le nom du site utilisé dans l'entrée newfeeds pour une liste de diffusion (ci-dessus "list-big-red-ants") doit être le même que le premier champ d'une entrée dans news2mail.cf. Par exemple :

# nom-newsfeeds   adresse-liste-destinataire      [adresse-expediteur-liste]
list-big-red-ants  ants@lists.ucsd.edu  news+ants@news.server.org

FICHIERS

pathbin/news2mail
Le programme Perl lui-même utilisé pour transférer les news dans des e-mails.
pathetc/news2mail.cf
Le fichier de configuration qui spécifie le mappage à utiliser pour le transfert.

BOGUES

Le programme news2mail est configuré comme un canal filtré dans newsfeeds, ce qui implique que plusieurs correspondances doivent être traitées comme une seule - et plusieurs flux filtrés correspondants entraîneront un seul appel au script. Par conséquent, comme un seul courrier est envoyé, les multipostages ne sont actuellement pas correctement gérés en ce qui concerne l'adresse de l'expéditeur de l'enveloppe (qui prend alors par défaut l'utilisateur "news").
