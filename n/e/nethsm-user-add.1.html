NOM

nethsm-user-add - Ajouter un utilisateur

SYNTAXE

nethsm user add [-p|--passphrase-file] [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <VRAI_NOM> [ROLE] [NOM]

DESCRIPTION

Ajouter un utilisateur

Ajoute un nouvel utilisateur en fournissant un vrai nom et un rôle d'utilisateur. Si aucun nom d'utilisateur n'est fourni spécifiquement, un nom aléatoire est généré automatiquement par l'appareil cible. Si aucune phrase de passe n'est fournie, elle sera demandée de manière interactive.

Les nouveaux utilisateurs héritent de la portée de l'utilisateur qui les a créés. Si un utilisateur à l'échelle du système dans le rôle "Administrateur" crée un nouvel utilisateur (par exemple, "utilisateur1"), alors ce nouvel utilisateur est également un utilisateur à l'échelle du système. À titre d'exception à cette règle, un utilisateur à l'échelle du système dans le rôle "Administrateur" peut créer des utilisateurs nommés en fournissant spécifiquement un nom d'utilisateur (par exemple, "espace_nom1~utilisateur1"), mais seulement si l'espace de noms cible (c'est-à-dire "espace_nom1") n'existe pas encore (voir "nethsm namespace add"). Si un utilisateur nommé dans le rôle "Administrateur" crée un nouvel utilisateur, alors ce nouvel utilisateur est également un utilisateur dans cet espace de noms. Si un utilisateur nommé dans le rôle "Administrateur" (par exemple, "espace_nom1~admin1") fournit un nom d'utilisateur spécifique, il doit appartenir au même espace de noms (par exemple, "espace_nom1~utilisateur1", pas "espace_nom2~utilisateur1") !

L'appareil doit être en état "Opérationnel".

Nécessite l'authentification d'un utilisateur dans le rôle "Administrateur".

OPTIONS

-p, --passphrase-file <FICHIER_PHRASE_PASSE>
Le chemin vers un fichier contenant la phrase de passe du nouvel utilisateur

La phrase de passe doit avoir une longueur supérieure ou égale à 10 et inférieure ou égale à 200 caractères.

Peut également être spécifié avec la variable d'environnement NETHSM_PASSPHRASE_FILE.
-a, --auth-passphrase-file <FICHIER_PHRASE_PASSE_AUTH>
Le chemin vers un fichier contenant une phrase de passe pour l'authentification

La phrase de passe fournie dans le fichier doit être celle de l'utilisateur choisi pour la commande.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois. Avec plusieurs fichiers de phrases de passe, l'ordre est important, car les fichiers sont attribués à l'utilisateur respectif fourni par l'option "--user".

Peut également être spécifié avec la variable d'environnement NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIG>
Le chemin vers un fichier de configuration personnalisé

S'il est spécifié, le fichier de configuration personnalisé est utilisé à la place de l'emplacement par défaut du fichier de configuration.

Peut également être spécifié avec la variable d'environnement NETHSM_CONFIG.
-l, --label <ETIQUETTE>
Une étiquette identifiant de manière unique un appareil dans le fichier de configuration

Doit être fournie si plus d'un appareil est configuré dans le fichier de configuration.

Peut également être spécifié avec la variable d'environnement NETHSM_LABEL.
-u, --user <UTILISATEUR>
Un nom d'utilisateur utilisé pour une commande

Peut être fourni si aucun nom d'utilisateur n'est configuré dans le fichier de configuration pour un appareil. Doit être fourni si plusieurs noms d'utilisateur du même rôle cible sont configurés dans le fichier de configuration pour un appareil.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois.

Peut également être spécifié avec la variable d'environnement NETHSM_USER.
-h, --help
Afficher l'aide (voir un résumé avec '-h')
<VRAI_NOM>
Le vrai nom de l'utilisateur qui est créé

Ce nom est uniquement utilisé pour une identification ultérieure, mais pas pour l'authentification !

Peut également être spécifié avec la variable d'environnement NETHSM_REAL_NAME.
[ROLE]
Le rôle de l'utilisateur qui est créé

L'un des suivants : ["Administrateur", "Sauvegarde", "Métriques", "Opérateur"] (par défaut "Opérateur").

Peut également être spécifié avec la variable d'environnement NETHSM_USER_ROLE.
[NOM]
Un nom unique pour l'utilisateur qui est créé

Ce nom doit être unique car il est utilisé pour l'authentification !

Peut également être spécifié avec la variable d'environnement NETHSM_USER_NAME.
