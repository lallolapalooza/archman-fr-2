NE_ADD_REQUEST_HEADE(3) Référence de l'API neon NE_ADD_REQUEST_HEADE(3)

NOM

ne_add_request_header, ne_print_request_header - ajouter des en-têtes à une requête

SYNTAXE

#include <ne_request.h>

void ne_add_request_header(ne_request *request, const char *name, const char *value);

void ne_print_request_header(ne_request *request, const char *name, const char *format, ...);

DESCRIPTION

Les fonctions ne_add_request_header et ne_print_request_header peuvent être utilisées pour ajouter des en-têtes à une requête, avant qu'elle ne soit envoyée.

ne_add_request_header ajoute simplement un en-tête du nom donné (name) avec la valeur donnée (value).

ne_print_request_header ajoute un en-tête du nom donné (name), en prenant la valeur à partir de la chaîne de format format similaire à printf et des arguments de longueur variable suivants.
