NOM

nemo-seahorse-tool - Chiffrement de fichiers PGP/GnuPG pour Nemo

SYNTAXE

nemo-seahorse-tool [ OPTION... ]

DESCRIPTION

Seahorse est une application GNOME pour la gestion des clés de chiffrement. seahorse-tool vous permet de chiffrer, déchiffrer ou signer des fichiers. Il est intégré au menu contextuel de Nemo, mais peut également être utilisé depuis la ligne de commande.

OPTIONS

Options de secours

-?, --help
Affiche le résumé de toutes les options et quitte.
--usage
Affiche un bref message d'utilisation et quitte.

Options de l'application

-i FICHIER, --import FICHIER
Importe les clés depuis le FICHIER.
-e FICHIER, --encrypt FICHIER
Chiffre le FICHIER.
-s FICHIER, --sign FICHIER
Signe le FICHIER avec la clé par défaut.
-n FICHIER, --encrypt-sign FICHIER
Chiffre et signe le FICHIER avec la clé par défaut.
-d FICHIER, --decrypt FICHIER
Déchiffre le FICHIER chiffré.
-v FICHIER, --verify FICHIER
Vérifie la signature du FICHIER.
-T, --uri-list
Lit une liste d'URI sur l'entrée standard.
--version
Affiche les informations de version et quitte.
-h, --help
Affiche les options d'aide.

Options supplémentaires

En outre, les options de ligne de commande habituelles de GTK+ et GNOME s'appliquent. Consultez la sortie de --help pour plus de détails.
