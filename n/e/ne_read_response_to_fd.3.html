NE_READ_RESPONSE_TO_(3) Référence de l'API neon NE_READ_RESPONSE_TO_(3)

NOM

ne_read_response_to_fd, ne_read_response_to_buffer - lire le corps d'une réponse

SYNTAXE

#include <ne_request.h>

int ne_read_response_to_fd(ne_request *req, int fd);

int ne_read_response_to_buffer(ne_request *req, char *data, size_t *buflen);

DESCRIPTION

Pour lire le corps d'une réponse HTTP, les fonctions ne_read_response_to_fd et ne_read_response_to_buffer peuvent être utilisées. Ces fonctions sont des wrappers pour ne_read_response_block et ne doivent être appelées qu'après que ne_begin_request ait été appelée avec succès pour la requête.

La fonction ne_read_response_to_fd écrit le contenu du corps de la réponse dans le descripteur de fichier passé en tant que paramètre fd.

La fonction ne_read_response_to_buffer écrit le contenu du corps de la réponse dans le tampon passé en tant que paramètre buf, dont la longueur est passée via le paramètre *buflen. En cas de succès, *buflen est mis à jour avec le nombre d'octets écrits dans le tampon.

Une fois que le corps de la réponse a été lu avec succès, ne_end_request doit être appelée. Si une erreur survient lors de la lecture du corps de la réponse, la connexion doit être fermée en utilisant ne_close_connection.

VALEUR DE RETOUR

Les deux fonctions retournent zéro en cas de succès, ou un code d'erreur NE_* en cas d'échec. La fonction ne_read_response_to_buffer retourne NE_FAILED si la longueur du message de réponse est supérieure à la longueur du tampon.

HISTORIQUE

ne_read_response_to_buffer est disponible dans neon 0.36.0 et versions ultérieures.
