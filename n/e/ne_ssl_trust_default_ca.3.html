NE_SSL_TRUST_CERT(3) Référence API neon NE_SSL_TRUST_CERT(3)

NOM

ne_ssl_trust_cert, ne_ssl_trust_default_ca - fonctions pour indiquer que les certificats sont approuvés

SYNTAXE

#include <ne_session.h>

void ne_ssl_trust_cert(ne_session *session, const ne_ssl_certificate *cert);

void ne_ssl_trust_default_ca(ne_session *session);

DESCRIPTION

Pour indiquer qu'un certificat donné est approuvé par l'utilisateur, l'objet certificat peut être passé à ne_ssl_trust_cert. L'objet certificat est dupliqué en interne et peut ensuite être détruit.

La bibliothèque SSL utilisée par neon peut inclure un ensemble par défaut de certificats d'autorité de certification ; appeler la fonction ne_ssl_trust_default_ca indiquera que ces autorités de certification sont approuvées par l'utilisateur.

EXEMPLES

Charger le certificat d'autorité de certification stocké dans /path/to/cacert.pem :

ne_session *sess = ne_session_create(...);
ne_ssl_certificate *cert = ne_ssl_cert_read("/path/to/cacert.pem");
if (cert) {
   ne_ssl_trust_cert(sess, cert);
   ne_ssl_cert_free(cert);
} else {
   printf("Impossible de charger le certificat CA : %s\n", ne_get_error(sess));
}

HISTORIQUE

ne_ssl_trust_default_ca n'est pas sûr à appeler pour les sessions non-SSL des versions de neon antérieures à 0.33.0. Dans les versions 0.33.0 et ultérieures, cette fonction ne fait rien pour les sessions non-SSL.

VOIR AUSSI

ne_session_create, ne_ssl_cert_read, ne_ssl_cert_import, ne_ssl_cert_free
