NOM

ne_ssl_set_protovers - définit la version minimale ou maximale du protocole SSL/TLS de la session

SYNTAXE

#include <ne_session.h>

int ne_ssl_set_protovers(ne_session *sess, enum ne_ssl_protocol min, enum ne_ssl_protocol max);

DESCRIPTION

La fonction ne_ssl_set_protovers définit la version minimale et/ou maximale SSL/TLS. Le minimum et/ou le maximum peuvent être spécifiés comme NE_SSL_PROTO_UNSPEC, auquel cas aucune limite n'est imposée.

VALEUR DE RETOUR

La fonction ne_ssl_set_protovers retourne zéro en cas de succès et une valeur non nulle en cas d'erreur. Les erreurs incluent une plage invalide (minimum supérieur au maximum), ou si la version du protocole n'est pas prise en charge par la boîte à outils SSL/TLS utilisée, ou si SSL/TLS n'est pas utilisé pour la session.

HISTORIQUE

ne_ssl_set_protovers est disponible dans neon 0.34.0 et versions ultérieures.

VOIR AUSSI

ne_ssl_proto_name, ne_session_create.
