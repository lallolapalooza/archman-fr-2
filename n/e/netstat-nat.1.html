NOM

netstat-nat - Afficher les connexions NAT sur un pare-feu Linux iptable

SYNTAXE

netstat-nat [options]

DESCRIPTION

netstat-nat Affiche les connexions NAT gérées par netfilter/iptables, inclus dans les noyaux Linux > 2.4.x.

Le programme lit ses informations depuis '/proc/net/ip_conntrack' ou '/proc/net/nf_conntrack', qui est le stockage temporaire des connexions de netfilter.

OPTIONS

-h
affiche l'aide
-n
ne pas résoudre les IPs/numéros de port en noms d'hôtes/ports
-p <protocole>
afficher les connexions NAT avec sélection du protocole (voir /etc/protocols)
-s <hôte-source>
afficher les connexions par IP/nom d'hôte source
-d <hôte-destination>
afficher les connexions par IP/nom d'hôte de destination
-S
afficher les connexions SNAT
-D
afficher les connexions DNAT
-L
afficher uniquement les connexions vers la box NAT elle-même (n'affiche pas SNAT & DNAT)
-R
afficher uniquement les connexions routées à travers la box NAT (n'affiche pas SNAT & DNAT)
-x
vue étendue des noms d'hôtes
-r <src|dst|src-port|dst-port|state>
trier les connexions
-o
pas d'en-tête de sortie
-N
afficher les informations de connexion de la box NAT (uniquement valide avec SNAT & DNAT)
-v
affiche la version

FICHIERS

/proc/net/ip_conntrack ou /proc/net/nf_conntrack
