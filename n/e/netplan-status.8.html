NOM

netplan-status - interroger l'état du réseau du système en cours d'exécution

SYNTAXE

netplan [--debug] status -h|--help

netplan [--debug] status [interface]

DESCRIPTION

netplan status [interface] interroge la configuration réseau actuelle et l'affiche dans un format lisible par l'homme.

Vous pouvez spécifier interface pour afficher l'état d'une interface spécifique.

Actuellement, netplan status dépend de systemd-networkd comme source de données et essaiera de le démarrer s'il n'est pas masqué.

OPTIONS

-h, --help
Imprimer une aide de base.
--debug
Imprimer une sortie de débogage pendant le processus.
-a, --all
Afficher toutes les données d'interface, y compris les inactives.
--diff
Analyser et afficher les différences entre la configuration système actuelle et les définitions réseau présentes dans les fichiers YAML. La configuration analysée inclut les adresses IP, les routes, les adresses MAC, les adresses DNS, les domaines de recherche et les interfaces réseau manquantes.

Le format de sortie est similaire aux outils de différence populaires comme diff et git diff. La configuration présente uniquement dans le système (et donc manquante dans le YAML Netplan) sera affichée avec un signe + et sera mise en surbrillance en vert. La configuration présente uniquement dans Netplan (et donc manquante dans le système) sera affichée avec un signe - et mise en surbrillance en rouge. Il en va de même pour les interfaces réseau.

--diff-only
Identique à --diff mais omet toutes les informations qui ne sont pas une différence.
--root-dir
Lire les fichiers YAML à partir de cette racine au lieu de /.
--verbose
Afficher des informations supplémentaires.
-f FORMAT, --format FORMAT
Sortie au format lisible par machine json ou yaml.

VOIR AUSSI
