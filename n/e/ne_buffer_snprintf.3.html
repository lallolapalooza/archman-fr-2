NE_BUFFER_APPEND(3) Référence API neon NE_BUFFER_APPEND(3)

NOM

ne_buffer_append, ne_buffer_zappend, ne_buffer_qappend, ne_buffer_concat, ne_buffer_snprintf - ajouter des données à un tampon de chaîne

SYNTAXE

#include <ne_string.h>

void ne_buffer_append(ne_buffer *buf, const char *string, size_t len);

void ne_buffer_zappend(ne_buffer *buf, const char *string);

void ne_buffer_qappend(ne_buffer *buf, const char *string, size_t len);

void ne_buffer_concat(ne_buffer *buf, ...);

size_t ne_buffer_snprintf(ne_buffer *buf, size_t max, const char *format, ...);

DESCRIPTION

Les fonctions ne_buffer_append et ne_buffer_zappend ajoutent une chaîne à la fin d'un tampon, en l'agrandissant si nécessaire. La valeur len passée à ne_buffer_append spécifie la longueur de la chaîne à ajouter ; il ne doit pas y avoir de terminateur NUL dans les premiers len octets de la chaîne. ne_buffer_zappend doit se voir passer une chaîne terminée par NUL.

La fonction ne_buffer_qappend se comporte de manière similaire à ne_buffer_append, sauf que tous les caractères non ASCII ou les caractères de contrôle ASCII sont échappés à l'aide d'échappements hexadécimaux de style C. Par exemple, la chaîne C « foo<TAB>bar », où TAB représente le caractère ASCII 9, serait ajoutée comme « foo\x09bar ». Tous les octets NUL dans la longueur spécifiée sont également échappés. Cette fonction est utile pour rendre les chaînes provenant de sources non fiables sûres pour la journalisation ou l'affichage dans une interface utilisateur.

La fonction ne_buffer_concat prend une liste d'arguments de longueur variable ; chaque argument doit être un pointeur char * vers une chaîne terminée par NUL. Un pointeur NULL doit être donné comme dernier argument pour marquer la fin de la liste. Les chaînes sont ajoutées au tampon dans l'ordre donné. Aucune des chaînes passées à ne_buffer_concat n'est modifiée.

La fonction ne_buffer_snprintf se comporte comme snprintf, ajoutant la chaîne de sortie formatée selon le paramètre format. Au plus max octets sont écrits, y compris le terminateur NUL final.

VALEUR RENVOYÉE

La fonction ne_buffer_snprintf renvoie le nombre d'octets ajoutés *à l'exclusion* du terminateur NUL final.

EXEMPLES

Le code suivant affichera « Hello, world. And goodbye. ».

ne_buffer *buf = ne_buffer_create();
ne_buffer_zappend(buf, "Hello");
ne_buffer_concat(buf, ", world. ", "And ", NULL);
ne_buffer_snprintf(buf, 10, "%s.", "goodbye");
puts(buf->data);
ne_buffer_destroy(buf);

VOIR AUSSI

ne_buffer, ne_buffer_create, ne_buffer_destroy
