NOM

netplan-ip - récupérer des informations IP (comme les baux DHCP) depuis le système

SYNTAXE

netplan [--debug] ip -h|--help

netplan [--debug] ip COMMANDE [--root-dir=ROOT_DIR] ARGUMENTS

DESCRIPTION

netplan ip récupère des informations IP (comme les baux DHCP) depuis le système.

COMMANDES DHCP

baux INTERFACE
Affiche les baux IP DHCP.

Exemple : netplan ip baux enp5s0

OPTIONS

-h, --help
Imprime une aide basique.
--debug
Imprime une sortie de débogage pendant le processus.
--root-dir
Lit les fichiers YAML depuis cette racine au lieu de /.

VOIR AUSSI

netplan(5), netplan-get(8), netplan-status(8)
