NOM

nethsm-key-sign - Signer un message à l'aide d'une clé

SYNTAXE

nethsm key sign [-f|--force] [-o|--output] [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <ID_CLÉ> <TYPE_SIGNATURE> <MESSAGE>

DESCRIPTION

Signer un message à l'aide d'une clé

La clé ciblée doit être équipée des mécanismes de clé pertinents pour la signature. Le type de signature choisi doit correspondre au type de clé cible et aux mécanismes de clé.

Si aucun fichier de sortie spécifique n'est choisi, la signature est écrite sur la sortie standard.

Les utilisateurs système dans le rôle « Opérateur » ne peuvent créer des signatures pour des messages qu'à l'aide de clés système. Les utilisateurs à espace de noms dans le rôle « Opérateur » ne peuvent créer des signatures pour des messages qu'à l'aide de clés dans leur propre espace de noms.

Nécessite l'authentification d'un utilisateur dans le rôle « Opérateur » avec accès (voir « nethsm key tag » et « nethsm user tag ») à la clé cible.

OPTIONS

-f, --force
Écrire dans le fichier de sortie même s'il existe déjà
Peut également être spécifié avec la variable d'environnement NETHSM_FORCE.
-o, --output <SORTIE>
Le chemin facultatif vers un fichier spécifique où la signature est écrite
Peut également être spécifié avec la variable d'environnement NETHSM_KEY_SIGNATURE_OUTPUT_FILE.
-a, --auth-passphrase-file <FICHIER_PHRASE_IDENTIFICATION>
Le chemin vers un fichier contenant une phrase d'identification pour l'authentification

La phrase d'identification fournie dans le fichier doit être celle de l'utilisateur choisi pour la commande.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois. Avec plusieurs fichiers de phrase d'identification, l'ordre compte, car les fichiers sont attribués aux utilisateurs respectifs fournis par l'option « --user ».

Peut également être spécifié avec la variable d'environnement NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIG>
Le chemin vers un fichier de configuration personnalisé

S'il est spécifié, le fichier de configuration personnalisé est utilisé à la place de l'emplacement par défaut du fichier de configuration.

Peut également être spécifié avec la variable d'environnement NETHSM_CONFIG.
-l, --label <ÉTATS>
Une étiquette identifiant de manière unique un appareil dans le fichier de configuration

Doit être fournie si plusieurs appareils sont configurés dans le fichier de configuration.

Peut également être spécifié avec la variable d'environnement NETHSM_LABEL.
-u, --user <UTILISATEUR>
Un nom d'utilisateur utilisé pour une commande

Peut être fourni si aucun nom d'utilisateur n'est configuré dans le fichier de configuration pour un appareil. Doit être fourni si plusieurs noms d'utilisateur du même rôle cible sont configurés dans le fichier de configuration pour un appareil.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois.

Peut également être spécifié avec la variable d'environnement NETHSM_USER.
-h, --help
Afficher l'aide (voir un résumé avec '-h')
<ID_CLÉ>
L'ID de la clé à utiliser pour signer le message
Peut également être spécifié avec la variable d'environnement NETHSM_KEY_ID.
<TYPE_SIGNATURE>
Le type de signature à utiliser pour la signature

Un parmi ["EcdsaP256", "EcdsaP384", "EcdsaP521", "EdDsa", "Pkcs1", "PssMd5", "PssSha1", "PssSha224", "PssSha256", "PssSha384", "PssSha512"]

Peut également être spécifié avec la variable d'environnement NETHSM_KEY_SIGNATURE_TYPE.
<MESSAGE>
Le chemin vers un message pour lequel créer une signature
Peut également être spécifié avec la variable d'environnement NETHSM_KEY_SIGNATURE_MESSAGE.
