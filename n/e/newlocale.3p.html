NEWLOCALE(3P) Manuel du programmeur POSIX NEWLOCALE(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

newlocale — créer ou modifier un objet locale

SYNTAXE

#include <locale.h>
locale_t newlocale(int category_mask, const char *locale,
    locale_t base);

DESCRIPTION

La fonction newlocale() crée un nouvel objet locale ou modifie un objet existant. Si l'argument base est (locale_t)0, un nouvel objet locale est créé. Il n'est pas spécifié si l'objet locale pointé par base doit être modifié, ou libéré et un nouvel objet locale créé.

L'argument category_mask spécifie les catégories de locale à définir ou modifier. Les valeurs pour category_mask sont construites par un OU-inclusif de bits des constantes symboliques LC_CTYPE_MASK, LC_NUMERIC_MASK, LC_TIME_MASK, LC_COLLATE_MASK, LC_MONETARY_MASK et LC_MESSAGES_MASK, ou toute autre valeur de masque définie par l'implémentation dans <locale.h>.

Pour chaque catégorie dont le bit correspondant est défini dans category_mask, les données de la locale nommée par locale sont utilisées. Dans le cas de modification d'un objet locale existant, les données de la locale nommée par locale remplacent les données existantes dans l'objet locale. Si un objet locale entièrement nouveau est créé, les données pour toutes les sections non demandées par category_mask proviennent de la locale par défaut.

Les valeurs prédéfinies suivantes de locale sont définies pour tous les réglages de category_mask :

"POSIX"
Spécifie l'environnement minimal pour la traduction en langage C appelé la locale POSIX.
"C"
Équivalent à "POSIX".
""
Spécifie un environnement natif défini par l'implémentation. Ceci correspond à la valeur des variables d'environnement associées, LC_* et LANG ; voir le volume des Définitions de base de POSIX.1‐2017, Chapitre 7, Locale et Chapitre 8, Variables d'environnement.

Si l'argument base n'est pas (locale_t)0 et que l'appel de fonction newlocale() réussit, le contenu de base est non spécifié. Les applications doivent s'assurer qu'elles arrêtent d'utiliser base comme objet locale avant d'appeler newlocale(). Si l'appel de fonction échoue et que l'argument base n'est pas (locale_t)0, le contenu de base reste valide et inchangé.

Le comportement est indéfini si l'argument base est l'objet locale spécial LC_GLOBAL_LOCALE, ou s'il n'est pas un descripteur d'objet locale valide et n'est pas (locale_t)0.

VALEUR RETOUR

En cas de succès, la fonction newlocale() renvoie un descripteur que l'appelant peut utiliser lors d'appels ultérieurs à duplocale(), freelocale() et d'autres fonctions acceptant un argument locale_t.

En cas d'échec, la fonction newlocale() renvoie (locale_t)0 et définit errno pour indiquer l'erreur.

ERREURS

La fonction newlocale() échoue si :

ENOMEM
Il n'y a pas assez de mémoire disponible pour créer l'objet locale ou charger les données de la locale.
EINVAL
Le category_mask contient un bit qui ne correspond à aucune catégorie valide.
ENOENT
Pour l'une des catégories du category_mask, les données de la locale ne sont pas disponibles.

La fonction newlocale() peut échouer si :

EINVAL
L'argument locale n'est pas un pointeur de chaîne valide.

Les sections suivantes sont informatives.

EXEMPLES

Construction d'un objet locale à partir de différentes locales

L'exemple suivant montre la construction d'une locale où les données de la catégorie LC_CTYPE proviennent d'une locale loc1 et les données de la catégorie LC_TIME d'une locale loc2 :

#include <locale.h>
...
locale_t loc, new_loc;
/* Obtenir les données de "loc1". */
loc = newlocale (LC_CTYPE_MASK, "loc1", (locale_t)0);
if (loc == (locale_t) 0)
    abort ();
/* Obtenir les données de "loc2". */
new_loc = newlocale (LC_TIME_MASK, "loc2", loc);
if (new_loc != (locale_t) 0)
    /* Nous n'abortons pas si cela échoue. Dans ce cas, il est
       simplement utilisé pour laisser l'objet locale inchangé. */
    loc = new_loc;
...

Libération d'un objet locale

L'exemple suivant montre un fragment de code pour libérer un objet locale créé par newlocale() :

#include <locale.h>
...
/* Chaque objet locale alloué avec newlocale() doit être
 * libéré en utilisant freelocale() :
 */
locale_t loc;
/* Obtenir la locale. */
loc = newlocale (LC_CTYPE_MASK | LC_TIME_MASK, "locname", (locale_t)0);
/* ... Utiliser l'objet locale ... */
...
/* Libérer les ressources de l'objet locale. */
freelocale (loc);

UTILISATION APPLICATIVE

Les descripteurs d'objets locale créés par la fonction newlocale() doivent être soit libérés par un appel correspondant à freelocale(), soit utilisés comme locale de base pour un autre appel à newlocale().

L'objet locale spécial LC_GLOBAL_LOCALE ne doit pas être passé pour l'argument base, même lorsqu'il est retourné par la fonction uselocale().
