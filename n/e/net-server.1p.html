NOM

net-server - Module de base de démarrage Net::Server

SYNOPSIS

net-server [type de base] [arguments du serveur net]
net-server PreFork ipv '*'
net-server HTTP
net-server HTTP app foo.cgi
net-server HTTP app foo.cgi app /=bar.cgi
net-server HTTP port 8080 port 8443/ssl ipv '*' server_type PreFork --SSL_key_file=my.key --SSL_cert_file=my.crt access_log_file STDERR

DESCRIPTION

Le programme net-server offre un moyen simple de tester du code et d'essayer les paramètres de connexion des ports. Bien que le serveur en cours d'exécution puisse être suffisamment robuste pour la production, il est prévu que ce binaire soit simplement utilisé pour des tests basiques des ports net-server, agissant comme un simple serveur d'écho, ou pour exécuter des scripts de développement en tant que CGI.

OPTIONS

"type de base"
Le tout premier argument peut être une variante de Net::Server. Ceci est donné en raccourci pour écrire server_type "ServerFlavor". De plus, cela permet à des types tels que HTTP et PSGI, qui ne sont pas de véritables types de base de Net::Server, de sous-classer d'autres types de serveur via un argument server_type supplémentaire. 
net-server PreFork
net-server HTTP  # devient un serveur HTTP dans la variante Fork
net-server HTTP server_type PreFork  # serveur HTTP pré-fork
"port"
Port sur lequel se lier. Le défaut est 80 si un serveur HTTP est exécuté en tant que root, 8080 si un serveur HTTP est exécuté en tant que non-root, ou 20203 sinon.

Plusieurs valeurs peuvent être données pour se lier à plusieurs ports. Toutes les méthodes de spécification des attributs de port énumérées dans Net::Server et Net::Server::Proto sont disponibles ici.

net-server port 20201
net-server port 20202
net-server port 20203/IPv6
"hôte"
Hôte auquel se lier. Le défaut est *. Se liera à une socket IPv4 si une adresse IPv4 est donnée. Se liera à une socket IPv6 si une adresse IPv6 est donnée (nécessite l'installation de IO::Socket::INET6).

Si un nom d'hôte est donné et que "ipv" est toujours défini sur 4, une socket IPv4 sera créée. Si un nom d'hôte est donné et que "ipv" est défini sur 6, une socket IPv6 sera créée. Si un nom d'hôte est donné et que "ipv" est défini sur * (défaut), une recherche sera effectuée et toutes les adresses IPv4 ou IPv6 disponibles seront liées. Le paramètre "ipv" peut être défini directement, ou passé dans le port, ou en outre peut être passé dans le nom d'hôte.

net-server host localhost
net-server host localhost/IPv4

Il y a beaucoup plus d'options disponibles. Veuillez consulter la documentation de Net::Server.
