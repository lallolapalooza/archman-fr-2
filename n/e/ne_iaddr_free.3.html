ne_iaddr_free(3)

Paquet: neon

NE_IADDR_MAKE(3) Référence de l'API neon NE_IADDR_MAKE(3)

NOM

ne_iaddr_make, ne_iaddr_cmp, ne_iaddr_print, ne_iaddr_typeof, ne_iaddr_parse, ne_iaddr_raw, ne_iaddr_reverse, ne_iaddr_free - fonctions pour manipuler les adresses réseau

SYNTAXE

#include <ne_socket.h>
typedef enum {
    ne_iaddr_ipv4 = 0,
    ne_iaddr_ipv6
} ne_iaddr_type;

ne_inet_addr *ne_iaddr_make(ne_iaddr_type type, const unsigned char *raw);

int ne_iaddr_cmp(const ne_inet_addr *ia1, const ne_inet_addr *ia2);

char *ne_iaddr_print(const ne_inet_addr *ia, char *buffer, size_t bufsiz);

ne_iaddr_type ne_iaddr_typeof(const ne_inet_addr *ia);

ne_inet_addr *ne_iaddr_parse(const char *address, ne_iaddr_type type);

unsigned char *ne_iaddr_raw(const ne_inet_addr *ia, unsigned char *buffer);

int ne_iaddr_reverse(const ne_inet_addr *ia, char *buffer, size_t buflen);

void ne_iaddr_free(const ne_inet_addr *ia);

DESCRIPTION

ne_iaddr_make crée un objet ne_inet_addr à partir d'une adresse réseau binaire brute ; par exemple, les quatre octets 0x7f 0x00 0x00 0x01 représentent l'adresse IPv4 127.0.0.1. L'objet retourné est approprié pour être passé à ne_sock_connect. Une adresse IPv4 binaire contient quatre octets ; une adresse IPv6 binaire contient seize octets ; les adresses passées doivent être en ordre d'octets réseau.

ne_iaddr_cmp compare deux objets d'adresses réseau ; il retourne zéro seulement s'ils sont identiques. Les objets n'ont pas besoin d'avoir le même type d'adresse ; si les adresses ne sont pas du même type, la valeur de retour est garantie d'être non nulle.

ne_iaddr_print imprime une représentation textuelle lisible par l'homme d'une adresse réseau dans un tampon, par exemple la chaîne de caractères « 127.0.0.1 ».

ne_iaddr_typeof retourne le type de l'objet d'adresse réseau donné.

ne_iaddr_parse analyse une représentation textuelle d'une adresse réseau (comme « 127.0.0.1 » et crée un objet d'adresse réseau pour représenter l'adresse analysée.

ne_iaddr_raw écrit la représentation binaire brute d'une adresse réseau dans le tampon fourni. Les octets sont écrits dans l'ordre des octets réseau ; le tampon doit avoir une longueur appropriée pour le type d'adresse (4 octets pour une adresse IPv4, 16 octets pour une adresse IPv6).

ne_iaddr_reverse effectue une recherche inversée de nom sur l'objet d'adresse, écrivant le (premier) nom d'hôte associé à l'adresse IP dans le tampon fourni. Si le nom d'hôte est plus long que le tampon, il sera tronqué silencieusement ; en cas de succès, la chaîne écrite dans le tampon est toujours terminée par un caractère nul.

ne_iaddr_free libère la mémoire associée à un objet d'adresse réseau.

VALEUR DE RETOUR

ne_iaddr_make retourne NULL si le type d'adresse passé n'est pas pris en charge (par exemple sur une plateforme qui ne prend pas en charge l'IPv6).

ne_iaddr_print retourne le pointeur buffer, et jamais NULL.

ne_iaddr_parse retourne un objet d'adresse réseau en cas de succès, ou NULL en cas d'échec de l'analyse du paramètre address.

ne_iaddr_reverse retourne zéro en cas de succès ou une valeur non nulle si aucun nom d'hôte n'est associé à l'adresse.

ne_iaddr_raw retourne le paramètre buffer, et jamais NULL.

EXEMPLES

L'exemple suivant connecte un socket au port 80 à l'adresse 127.0.0.1.

unsigned char addr[] = "\0x7f\0x00\0x00\0x01";
ne_inet_addr *ia;
ia = ne_iaddr_make(ne_iaddr_ipv4, addr);
if (ia != NULL) {
    ne_socket *sock = ne_sock_connect(ia, 80);
    ne_iaddr_free(ia);
    /* ... */
} else {
    /* ... */
}
