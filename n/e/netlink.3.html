netlink(3) Manuel des fonctions de bibliothèque netlink(3)

NOM

netlink - Macros Netlink

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <asm/types.h>
#include <linux/netlink.h>
int NLMSG_ALIGN(size_t size);
int NLMSG_LENGTH(size_t size);
int NLMSG_SPACE(size_t size);
void *NLMSG_DATA(struct nlmsghdr *nlh);
struct nlmsghdr *NLMSG_NEXT(struct nlmsghdr *nlh, int size);
int NLMSG_OK(struct nlmsghdr *nlh, int size);
int NLMSG_PAYLOAD(struct nlmsghdr *nlh, int size);

DESCRIPTION

<linux/netlink.h> définit plusieurs macros standard pour accéder à ou créer un datagramme netlink. Elles sont similaires dans l'esprit aux macros définies dans cmsg(3) pour les données auxiliaires. Le tampon passé vers et depuis une socket netlink ne doit être accédé qu'à l'aide de ces macros.

NLMSG_ALIGN()
Arrondit la taille d'un message netlink vers le haut pour un alignement correct.
NLMSG_LENGTH()
Étant donné la taille de la charge utile, size, cette macro retourne la taille alignée à stocker dans le champ nlmsg_len du nlmsghdr.
NLMSG_SPACE()
Retourne le nombre d'octets qu'occuperait un message netlink avec une charge utile de taille size.
NLMSG_DATA()
Retourne un pointeur vers la charge utile associée au nlmsghdr passé.
NLMSG_NEXT()
Obtient le nlmsghdr suivant dans un message multipart. L'appelant doit vérifier si le nlmsghdr actuel n'avait pas le drapeau NLMSG_DONE défini — cette fonction ne retourne pas NULL à la fin. L'argument size est une lvalue contenant la taille restante du tampon de message. Cette macro la décrémente de la taille de l'en-tête du message.
NLMSG_OK()
Retourne vrai si le message netlink n'est pas tronqué et est sous une forme adaptée à l'analyse.
NLMSG_PAYLOAD()
Retourne la taille de la charge utile associée au nlmsghdr.

VERSIONS

Il est souvent préférable d'utiliser netlink via libnetlink plutôt que via l'interface noyau de bas niveau.

NORMES

Linux.

VOIR AUSSI

libnetlink(3), netlink(7)
