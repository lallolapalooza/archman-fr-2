NOM

alloc_pair, find_pair, free_pair - allouer dynamiquement des paires de couleurs curses

SYNTAXE

#include <curses.h>
int alloc_pair(int fg, int bg);
int find_pair(int fg, int bg);
int free_pair(int pair);

DESCRIPTION

Ces fonctions sont une extension de la bibliothèque curses. Elles permettent à une application d'allouer dynamiquement une paire de couleurs en utilisant les couleurs de premier plan/arrière-plan plutôt que d'assigner un numéro de paire de couleurs fixe, et de rendre une paire non utilisée au pool.

Le nombre de couleurs peut être lié au nombre de paires de couleurs possibles pour un terminal donné, ou pas :

  • Bien que presque tous les terminaux permettent de définir les attributs de couleur indépendamment, il est peu probable que votre terminal vous permette de modifier les attributs d'une cellule de caractère donnée sans la réécrire. C'est-à-dire que les couleurs de premier plan et d'arrière-plan sont appliquées par paire.
  • Les paires de couleurs sont le moyen utilisé par la bibliothèque curses pour gérer une palette de couleurs sur un terminal. Si la bibliothèque ne garde pas trace des combinaisons de couleurs qui sont affichées, ce sera inefficace.
  • Pour les émulateurs de terminaux simples avec seulement quelques dizaines de combinaisons de couleurs, il est pratique d'utiliser le nombre maximum de combinaisons comme limite pour les paires de couleurs :
COLORS * COLORS
•
Les terminaux qui prennent en charge les couleurs par défaut distinctes des couleurs “ANSI” augmentent les combinaisons possibles, produisant ce total :
( COLORS + 1 ) * ( COLORS + 1 )
•
Une application pourrait utiliser jusqu'à quelques dizaines de paires de couleurs pour implémenter un schéma de couleurs prédéfini.
Au-delà, on entre dans le domaine des programmes utilisant les couleurs de premier plan et d'arrière-plan pour de l'“art ASCII” (ou une autre application non textuelle).
Également au-delà de ces quelques dizaines de paires, la taille requise pour une table représentant les combinaisons augmente rapidement avec un nombre croissant de couleurs.
Ces fonctions permettent à un développeur de laisser la bibliothèque d'écran gérer les paires de couleurs.

alloc_pair

La fonction alloc_pair accepte les paramètres pour la couleur de premier plan et d'arrière-plan, et vérifie si cette combinaison de couleurs est déjà associée à une paire de couleurs.

  • Si la combinaison existe déjà, alloc_pair retourne la paire existante.
  • Si la combinaison n'existe pas, alloc_pair alloue une nouvelle paire de couleurs et la retourne.
  • Si la table se remplit, alloc_pair écarte la dernière entrée allouée en utilisant free_pair et alloue une nouvelle paire de couleurs.

Toutes les paires de couleurs sont allouées à partir d'une table de paires de couleurs possibles. La taille de la table est déterminée par la capacité pairs de terminfo. La table est partagée avec init_pair ; en fait, alloc_pair appelle init_pair après avoir mis à jour l'index rapide de la bibliothèque ncurses vers les couleurs par rapport aux paires de couleurs.

find_pair

La fonction find_pair accepte les paramètres pour la couleur de premier plan et d'arrière-plan, et vérifie si cette combinaison de couleurs est déjà associée à une paire de couleurs, retournant le numéro de la paire si elle a été allouée. Sinon, elle retourne -1.

free_pair

Marque la paire de couleurs donnée comme inutilisée, c'est-à-dire, comme la paire de couleurs 0.

VALEUR DE RETOUR

La fonction alloc_pair retourne un numéro de paire de couleurs dans la plage 1 à COLOR_PAIRS-1, à moins qu'elle ne rencontre une erreur lors de la mise à jour de son index rapide des valeurs des paires de couleurs, l'empêchant d'allouer une paire de couleurs. Dans ce cas, elle retourne -1.

La fonction find_pair retourne un numéro de paire de couleurs si la combinaison de couleurs donnée a été associée à une paire de couleurs, ou -1 sinon.

De même, free_pair retourne OK à moins qu'elle ne rencontre une erreur lors de la mise à jour de l'index rapide ou si aucune paire de couleurs de ce type n'est utilisée.

PORTABILITÉ

Ces routines sont spécifiques à ncurses. Elles n'étaient pas supportées sur les implémentations des versions 7, BSD ou System V. Il est recommandé que tout code qui en dépend soit conditionné en utilisant NCURSES_VERSION.
