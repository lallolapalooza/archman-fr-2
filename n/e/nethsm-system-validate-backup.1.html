NOM

nethsm-system-validate-backup - Valider un fichier de sauvegarde

SYNTAXE

nethsm system validate-backup [-b|--backup-passphrase-file] [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <ENTRÉE>

DESCRIPTION

Valider un fichier de sauvegarde

Analyse un fichier de sauvegarde chiffré pour s'assurer de ses propriétés générales. Si une phrase de passe est fournie, le déchiffrement du fichier de sauvegarde et la validation de son numéro de version sont tentés. Cette commande se termine avec un code de sortie non nul si le fichier est corrompu, ou si le déchiffrement ou la validation échoue.

Note : Les sauvegardes sont créées à l'aide de "nethsm system backup"

OPTIONS

-b, --backup-passphrase-file <FICHIER_PHRASE_DE_PASSE_SAUVEGARDE>
Le chemin vers un fichier contenant la phrase de passe de sauvegarde
Peut également être spécifié avec la variable d'environnement NETHSM_VALIDATE_BACKUP_PASSPHRASE_FILE.
-a, --auth-passphrase-file <FICHIER_PHRASE_DE_PASSE_AUTH>
Le chemin vers un fichier contenant une phrase de passe pour l'authentification

La phrase de passe fournie dans le fichier doit être celle de l'utilisateur choisi pour la commande.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois. Avec plusieurs fichiers de phrases de passe, l'ordre est important, car les fichiers sont assignés à l'utilisateur respectif fourni par l'option "--user".

Peut également être spécifié avec la variable d'environnement NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIG>
Le chemin vers un fichier de configuration personnalisé

S'il est spécifié, le fichier de configuration personnalisé est utilisé à la place de l'emplacement par défaut du fichier de configuration.

Peut également être spécifié avec la variable d'environnement NETHSM_CONFIG.
-l, --label <ETIQUETTE>
Une étiquette identifiant de manière unique un appareil dans le fichier de configuration

Doit être fournie si plus d'un appareil est configuré dans le fichier de configuration.

Peut également être spécifié avec la variable d'environnement NETHSM_LABEL.
-u, --user <UTILISATEUR>
Un nom d'utilisateur qui est utilisé pour une commande

Peut être fourni si aucun nom d'utilisateur n'est configuré dans le fichier de configuration pour un appareil. Doit être fourni si plusieurs noms d'utilisateurs du même rôle cible sont configurés dans le fichier de configuration pour un appareil.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois.

Peut également être spécifié avec la variable d'environnement NETHSM_USER.
-h, --help
Afficher l'aide (voir un résumé avec '-h')
<ENTRÉE>
Le chemin vers le fichier de sauvegarde à valider
Peut également être spécifié avec la variable d'environnement NETHSM_VALIDATE_BACKUP_FILE.
