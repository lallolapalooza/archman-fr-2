NE_MALLOC(3) Référence de l'API neon NE_MALLOC(3)

NOM

ne_malloc, ne_calloc, ne_realloc, ne_strdup, ne_strndup, ne_oom_callback - enveloppes d'allocation mémoire

SYNTAXE

#include <ne_alloc.h>

void *ne_malloc(size_t size);

void *ne_calloc(size_t size);

void *ne_realloc(void *ptr, size_t len);

char *ne_strdup(const char *s);

char *ne_strndup(const char *s, size_t size);

void ne_oom_callback(void (*callback)(void));

DESCRIPTION

Les fonctions ne_malloc, ne_calloc, ne_realloc, ne_strdup et ne_strdnup fournissent des enveloppes pour les fonctions équivalentes de la bibliothèque C standard. Ces enveloppes fournissent la garantie supplémentaire que si l'équivalent de la bibliothèque C retourne NULL lorsqu'aucune mémoire n'est disponible, un rappel optionnel sera appelé, et la bibliothèque appellera alors abort().

ne_oom_callback enregistre une fonction de rappel qui sera invoquée si une erreur de manque de mémoire est détectée.

NOTES

Si le système d'exploitation utilise une allocation mémoire optimiste, les routines d'allocation mémoire de la bibliothèque C ne retourneront pas NULL, il n'est donc pas possible de gérer gracieusement les échecs d'allocation mémoire.
