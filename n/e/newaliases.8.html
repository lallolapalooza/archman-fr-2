NOM

newaliases — reconstruire les alias de courrier

SYNTAXE

newaliases [-f fichier]

DESCRIPTION

L'utilitaire newaliases rend les modifications apportées au fichier d'alias de courrier visibles pour smtpd(8). Il doit être exécuté chaque fois que le fichier aliases(5) est modifié. L'emplacement du fichier d'alias est défini dans smtpd.conf(5) et est par défaut /etc/smtpd/aliases.

Les options sont les suivantes :

-f fichier
Utiliser fichier comme fichier de configuration, au lieu du fichier par défaut /etc/smtpd/smtpd.conf.

Si vous utilisez des fichiers de base de données (db), newaliases est équivalent à l'exécution de makemap(8) comme suit :

# makemap -t aliases /etc/smtpd/aliases

Si vous utilisez des fichiers texte brut, newaliases est équivalent à l'exécution de smtpctl(8) comme suit :

# smtpctl update table aliases

FICHIERS

/etc/smtpd/aliases
Liste des alias de courrier des utilisateurs locaux.
/etc/smtpd/virtual
Liste des alias des hôtes virtuels.

VALEUR DE RETOUR

L'utilitaire newaliases se termine avec 0 en cas de succès, et avec >0 si une erreur survient.

VOIR AUSSI

smtpd.conf(5), makemap(8), smtpctl(8), smtpd(8)

HISTORIQUE

La commande newaliases est apparue pour la première fois dans OpenBSD 4.6 en remplacement de la commande équivalente fournie avec sendmail.
