NOM

nethsm-random - Obtenir des octets aléatoires d'un périphérique

SYNTAXE

nethsm random [-f|--force] [-o|--output] [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <LONGUEUR>

DESCRIPTION

Obtenir des octets aléatoires d'un périphérique

Sauf si un fichier de sortie spécifique est choisi, écrit un nombre donné d'octets aléatoires sur la sortie standard.

Requiert l'authentification d'un utilisateur dans le rôle « Opérateur ».

OPTIONS

-f, --force
Écrire dans le fichier de sortie même s'il existe déjà
Peut également être spécifié avec la variable d'environnement NETHSM_FORCE.
-o, --output <SORTIE>
Le chemin optionnel vers un fichier de sortie spécifique
Peut également être spécifié avec la variable d'environnement NETHSM_RANDOM_OUTPUT_FILE.
-a, --auth-passphrase-file <FICHIER_PHRASE_IDENTIFICATION>
Le chemin vers un fichier contenant une phrase d'identification pour l'authentification

La phrase d'identification fournie dans le fichier doit être celle de l'utilisateur choisi pour la commande.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois. Avec plusieurs fichiers de phrase d'identification, l'ordre est important, car les fichiers sont attribués à l'utilisateur respectif fourni par l'option « --user ».

Peut également être spécifié avec la variable d'environnement NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIG>
Le chemin vers un fichier de configuration personnalisé

Si spécifié, le fichier de configuration personnalisé est utilisé à la place de l'emplacement du fichier de configuration par défaut.

Peut également être spécifié avec la variable d'environnement NETHSM_CONFIG.
-l, --label <ETIQUETTE>
Une étiquette identifiant de manière unique un périphérique dans le fichier de configuration

Doit être fournie si plus d'un périphérique est configuré dans le fichier de configuration.

Peut également être spécifié avec la variable d'environnement NETHSM_LABEL.
-u, --user <UTILISATEUR>
Un nom d'utilisateur utilisé pour une commande

Peut être fourni si aucun nom d'utilisateur n'est configuré dans le fichier de configuration pour un périphérique. Doit être fourni si plusieurs noms d'utilisateurs du même rôle cible sont configurés dans le fichier de configuration pour un périphérique.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois.

Peut également être spécifié avec la variable d'environnement NETHSM_USER.
-h, --help
Afficher l'aide (voir un résumé avec '-h')
<LONGUEUR>
Le nombre d'octets aléatoires à retourner
Peut également être spécifié avec la variable d'environnement NETHSM_RANDOM_LENGTH.
