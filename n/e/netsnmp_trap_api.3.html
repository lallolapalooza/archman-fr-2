netsnmp_trap_api(3)

Paquet: net-snmp

Licences: BSD

NETSNMP_TRAP_API(3) Net-SNMP NETSNMP_TRAP_API(3)

NOM

send_easy_trap, send_trap_vars, send_v2trap - envoyer des TRAPs ou des INFORMs depuis un module MIB Net-SNMP

SYNTAXE

#include <net-snmp/agent/agent_trap.h>

void send_easy_trap(int trap, int specific);

void send_trap_vars(int trap, int specific, struct variable_list *vars);

void send_v2trap(struct variable_list *vars);

DESCRIPTION

Ces trois routines peuvent être utilisées pour envoyer des traps depuis un module MIB au sein de l'agent Net-SNMP (y compris un sous-agent AgentX).

send_easy_trap() envoie un trap SNMPv1 (ou son équivalent SNMPv2) à la liste des destinations de traps configurées (ou "sinks"), en utilisant les valeurs fournies pour le type de trap générique et la valeur spécifique du trap.

send_trap_vars() est similaire, mais ajoute la liste fournie de liaisons de variables aux traps envoyés.

send_v2trap() utilise la liste fournie de liaisons de variables pour former un trap SNMPv2, qui est envoyé aux sinks capables de gérer SNMPv2 dans la liste configurée. Un INFORM équivalent est envoyé à la liste configurée des sinks d'inform. Les sinks qui ne peuvent gérer que les traps SNMPv1 sont ignorés.

Les différentes appels "send_trap()" vous permettent de spécifier des traps dans différents formats. Et les différentes directives "trapsink" vous permettent de spécifier des destinations pour recevoir différents formats. Mais *tous* les traps sont envoyés à *toutes* les destinations, indépendamment de la manière dont ils ont été spécifiés.

C'est-à-dire
                                         ___  trapsink
                                        /
    send_easy_trap ___  [  Trap      ] ____  trap2sink
                    ___  [ Générateur ]
    send_v2trap    /     [            ] ----- informsink
                                        ____
                                              trapsess
*Pas*
     send_easy_trap  ------------------->  trapsink
     send_v2trap     ------------------->  trap2sink
     ????            ------------------->  informsink
     ????            ------------------->  trapsess

AVERTISSEMENTS

Ces routines sont utilisées pour envoyer les traps immédiatement lors de leur appel. L'invocation au moment approprié est laissée au programmeur du module MIB.

VOIR AUSSI

snmpd.conf(5), snmptrapd(8)
