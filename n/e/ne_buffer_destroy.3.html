ne_buffer_destroy(3)

Paquet: neon

NE_BUFFER_DESTROY(3) Référence de l'API neon NE_BUFFER_DESTROY(3)

NOM

ne_buffer_destroy, ne_buffer_finish - détruire un objet tampon

SYNTAXE

#include <ne_string.h>

void ne_buffer_destroy(ne_buffer *buf);

char *ne_buffer_finish(ne_buffer *buf);

DESCRIPTION

ne_buffer_destroy libère toute la mémoire associée au tampon. ne_buffer_finish libère la structure du tampon, mais pas la chaîne de caractères réelle stockée dans le tampon, qui est retournée et doit être libérée avec free() par l'appelant.

Toute utilisation de l'objet tampon après l'appel de l'une ou l'autre de ces fonctions entraîne un comportement indéfini.

VALEUR DE RETOUR

ne_buffer_finish retourne la chaîne de caractères allouée par malloc stockée dans le tampon.

EXEMPLES

Un exemple d'utilisation de ne_buffer_finish ; la fonction duplicate retourne une chaîne composée de n copies de str :

static char *duplicate(int n, const char *str)
{
  ne_buffer *buf = ne_buffer_create();
  while (n--) {
    ne_buffer_zappend(buf, str);
  }
  return ne_buffer_finish(buf);
}

VOIR AUSSI

ne_buffer, ne_buffer_create, ne_buffer_zappend
