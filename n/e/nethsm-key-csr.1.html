nethsm-key-csr(1) Manuel des commandes générales nethsm-key-csr(1)

NOM

nethsm-key-csr - Obtenir une demande de signature de certificat pour une clé

SYNTAXE

nethsm key csr [-f|--force] [-o|--output] [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <ID_CLE> <NOM_COMMUN> [NOM_ORG] [UNITE_ORG] [LOCALITE] [ETAT] [PAYS] [EMAIL]

DESCRIPTION

Obtenir une demande de signature de certificat pour une clé

La demande de signature de certificat (CSR) PKCS#10 est retournée au format Privacy-enhanced Electronic Mail (PEM). Sauf si un fichier de sortie spécifique est choisi, le certificat est renvoyé sur stdout.

Au minimum, l'attribut « Nom commun » (CN) de la CSR doit être fourni.

Les utilisateurs système dans le rôle « Administrateur » ou « Opérateur » ne peuvent créer des CSR que pour des clés système. Les utilisateurs avec espace de noms dans le rôle « Administrateur » ou « Opérateur » ne peuvent créer des CSR que pour des clés de leur propre espace de noms.

Nécessite l'authentification d'un utilisateur dans le rôle « Administrateur » ou « Opérateur » (avec accès à la clé - voir « nethsm key tag » et « nethsm user tag »).

OPTIONS

-f, --force
Écrire dans le fichier de sortie même s'il existe déjà
Peut également être spécifié avec la variable d'environnement NETHSM_FORCE.
-o, --output <SORTIE>
Le chemin optionnel vers un fichier de sortie spécifique
Peut également être spécifié avec la variable d'environnement NETHSM_KEY_CSR_OUTPUT_FILE.
-a, --auth-passphrase-file <FICHIER_PHRASE_SECRETTE>
Le chemin vers un fichier contenant une phrase secrète pour l'authentification

La phrase secrète fournie dans le fichier doit être celle de l'utilisateur choisi pour la commande.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois. Avec plusieurs fichiers de phrase secrète, l'ordre est important, car les fichiers sont attribués à l'utilisateur respectif fourni par l'option « --user ».

Peut également être spécifié avec la variable d'environnement NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIG>
Le chemin vers un fichier de configuration personnalisé

S'il est spécifié, le fichier de configuration personnalisé est utilisé à la place de l'emplacement par défaut du fichier de configuration.

Peut également être spécifié avec la variable d'environnement NETHSM_CONFIG.
-l, --label <ETIQUETTE>
Une étiquette identifiant de manière unique un appareil dans le fichier de configuration

Doit être fourni si plusieurs appareils sont configurés dans le fichier de configuration.

Peut également être spécifié avec la variable d'environnement NETHSM_LABEL.
-u, --user <UTILISATEUR>
Un nom d'utilisateur utilisé pour une commande

Peut être fourni si aucun nom d'utilisateur n'est configuré dans le fichier de configuration pour un appareil. Doit être fourni si plusieurs noms d'utilisateurs du même rôle cible sont configurés dans le fichier de configuration pour un appareil.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois.

Peut également être spécifié avec la variable d'environnement NETHSM_USER.
-h, --help
Afficher l'aide (voir un résumé avec '-h')
<ID_CLE>
L'ID de la clé pour laquelle créer une CSR
Peut également être spécifié avec la variable d'environnement NETHSM_KEY_ID.
<NOM_COMMUN>
L'attribut obligatoire « Nom commun » (CN) pour la CSR

Un nom de domaine complet (FQDN) qui doit être sécurisé à l'aide de la CSR.

Peut également être spécifié avec la variable d'environnement NETHSM_KEY_CSR_COMMON_NAME.
[NOM_ORG]
L'attribut optionnel « Nom de l'organisation » (O) pour la CSR

Généralement le nom légal d'une entreprise ou d'une entité et devrait inclure tous les suffixes tels que S.A., S.A.R.L., Inc., ou Corp.

Peut également être spécifié avec la variable d'environnement NETHSM_KEY_CSR_ORG_NAME.
[UNITE_ORG]
L'attribut optionnel « Unité organisationnelle » (OU) pour la CSR

Nom du département/division interne de l'organisation.

Peut également être spécifié avec la variable d'environnement NETHSM_KEY_CSR_ORG_UNIT.
[LOCALITE]
L'attribut optionnel « Localité » (L) pour la CSR

Nom de la ville, village, etc.

Peut également être spécifié avec la variable d'environnement NETHSM_KEY_CSR_LOCALITY.
[ETAT]
L'attribut optionnel « État » (ST) pour la CSR

Province, région, comté ou état.

Peut également être spécifié avec la variable d'environnement NETHSM_KEY_CSR_STATE.
[PAYS]
L'attribut optionnel « Pays » (C) pour la CSR

Le code ISO à deux lettres du pays où est située l'« Organisation » (O).

Peut également être spécifié avec la variable d'environnement NETHSM_KEY_CSR_COUNTRY.
[EMAIL]
L'attribut optionnel « Adresse e-mail » (EMAIL) pour la CSR

Le contact de l'organisation, généralement l'administrateur du certificat ou le département informatique.

Peut également être spécifié avec la variable d'environnement NETHSM_KEY_CSR_EMAIL.
