NOM

ne_buffer - gestion du tampon de chaîne

SYNTAXE

#include <ne_string.h>
typedef struct {
    char *data;
    size_t used;
    size_t length;
} ne_buffer;

DESCRIPTION

Le type ne_buffer représente un tampon mémoire extensible pour contenir des chaînes terminées par NUL. Le champ data pointe vers le début de la chaîne, dont la longueur est donnée par le champ used. La taille actuelle de la mémoire allouée est donnée par le champ length. Il n'est pas recommandé de manipuler directement les champs d'un tampon. Le pointeur data peut changer lorsque le tampon est modifié.

Un tampon est créé en utilisant ne_buffer_create ou ne_buffer_ncreate, et détruit en utilisant ne_buffer_destroy ou ne_buffer_finish. Les fonctions ne_buffer_append, ne_buffer_zappend et ne_buffer_concat sont utilisées pour ajouter des données à un tampon.

Si la chaîne référencée par le pointeur data est modifiée directement (plutôt qu'en utilisant l'une des fonctions listées ci-dessus), ne_buffer_altered doit être appelé.
