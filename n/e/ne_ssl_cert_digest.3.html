ne_ssl_cert_digest(3)

Paquet: neon

Licences: LGPL-2.0-or-later

NE_SSL_CERT_CMP(3) Référence de l'API neon NE_SSL_CERT_CMP(3)

NOM

ne_ssl_cert_cmp, ne_ssl_cert_free, ne_ssl_cert_digest, ne_ssl_cert_hdigest, ne_ssl_cert_validity, ne_ssl_cert_validity_time - fonctions pour opérer sur les objets certificats

SYNOPIS

#include <ne_header.h>

int ne_ssl_cert_cmp(const ne_ssl_certificate *c1, const ne_ssl_certificate *c2);

void ne_ssl_cert_free(ne_ssl_certificate *cert);

int ne_ssl_cert_digest(const ne_ssl_certificate *c1, char *digest);

char *ne_ssl_cert_hdigest(const ne_ssl_certificate *c1, unsigned int flags);

void ne_ssl_cert_validity_time(const ne_ssl_certificate *cert, time_t *from, time_t *until);

void ne_ssl_cert_validity(const ne_ssl_certificate *cert, char *from, char *until);

DESCRIPTION

La fonction ne_ssl_cert_cmp peut être utilisée pour comparer deux objets certificats ; elle renvoie zéro s'ils font référence au même certificat, et non-zéro sinon.

La fonction ne_ssl_cert_free peut être utilisée pour détruire un objet certificat lorsqu'il n'est plus nécessaire.

La fonction ne_ssl_cert_digest écrit une empreinte digitale lisible par l'homme sous forme de chaîne terminée par NUL dans le tampon digest fourni, au format « aa:bb...:ff ». Le tampon digest doit avoir une taille d'au moins NE_SSL_DIGESTLEN octets.

La fonction ne_ssl_cert_hdigest renvoie une empreinte digitale lisible par l'homme pour l'objet certificat. Le paramètre flags spécifie les options de formatage du hachage comme si elles étaient passées à ne_strhash. La chaîne renvoyée est allouée par malloc et doit être libérée après utilisation.

La fonction ne_ssl_cert_validity_time récupère à la fois la date à partir de laquelle le certificat est valide et la date jusqu'à laquelle il est valide. Chaque date est renvoyée via les paramètres from et until, qui sont écrits comme (time_t)-1 si l'une ou l'autre date ne peut pas être représentée sous forme de valeur time_t. La fonction ne_ssl_cert_validity écrit de manière similaire les dates de validité dans les tampons de chaîne fournis, en utilisant le format de date de style RFC 1123 (non localisé). Les paramètres de sortie doivent avoir une taille d'au moins NE_SSL_VDATELEN octets. L'un ou l'autre paramètre peut être passé comme NULL.

VALEUR DE RETOUR

ne_ssl_cert_cmp renvoie 0 si les certificats sont identiques, et non-zéro sinon. ne_ssl_cert_digest renvoie 0 en cas de succès ou non-zéro en cas d'erreur. La valeur de retour de ne_ssl_cert_hdigest est une chaîne allouée par malloc et terminée par NUL, ou NULL si le hachage ne peut pas être créé.

HISTORIQUE

ne_ssl_cert_hdigest est disponible dans neon 0.32.0 et versions ultérieures.
