NOM

netplan-apply - appliquer la configuration des fichiers YAML Netplan à un système en cours d'exécution

SYNTAXE

netplan [--debug] apply -h|--help

netplan [--debug] apply

DESCRIPTION

netplan apply applique la configuration Netplan actuelle à un système en cours d'exécution.

Le processus se déroule comme suit :

1.
La configuration du backend est générée à partir des fichiers YAML Netplan.
2.
Les backends appropriés (systemd-networkd(8) ou NetworkManager(8)) sont invoqués pour activer les interfaces configurées.
3.
netplan apply itère sur les interfaces qui sont toujours désactivées, les désappariant de leurs pilotes et les réappariant. Cela donne à udev(7) la possibilité d'exécuter les règles de renommage.
4.
Si des périphériques ont été réappariés, les backends appropriés sont réinvoqués au cas où davantage de correspondances pourraient être effectuées.

Pour des informations sur l'étape de génération, voir netplan-generate(8). Pour des détails sur le format du fichier de configuration, voir netplan(5).

OPTIONS

-h, --help
Imprimer une aide de base.
--debug
Imprimer une sortie de débogage pendant le processus.

PROBLÈMES CONNUS

netplan apply ne supprimera pas les périphériques virtuels tels que les ponts et les liaisons qui ont été créés, même s'ils ne sont plus décrits dans la configuration Netplan. Cela est dû au fait que Netplan fonctionne sans état et n'est pas conscient des périphériques virtuels précédemment définis.

Cela peut être résolu en supprimant manuellement le périphérique virtuel (par exemple ip link delete dev bond0) puis en exécutant netplan apply, en redémarrant, ou en créant une sauvegarde temporaire de l'état YAML dans /etc/netplan avant de modifier la configuration et en passant cet état à Netplan (par exemple mkdir -p /tmp/netplan_state_backup/etc && cp -r /etc/netplan /tmp/netplan_state_backup/etc/ puis en exécutant netplan apply --state /tmp/netplan_state_backup).

VOIR AUSSI

netplan(5), netplan-generate(8), netplan-try(8), udev(7), systemd-networkd.service(8), NetworkManager(8)
