NOM

nethsm-user-untag - Supprimer une étiquette d'un utilisateur

SYNTAXE

nethsm user untag [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <NOM> <ETIQUETTE>

DESCRIPTION

Supprimer une étiquette d'un utilisateur

Les étiquettes fournissent un accès aux clés pour les utilisateurs. La suppression d'une étiquette d'un utilisateur retire son accès aux clés qui portent des étiquettes identiques.

Les utilisateurs système dans le rôle d'« Administrateur » ne peuvent supprimer des étiquettes que pour les utilisateurs système dans le rôle d'« Opérateur ». Les utilisateurs nommés dans le rôle d'« Administrateur » ne peuvent supprimer des étiquettes que pour les utilisateurs dans le rôle d'« Opérateur » du même espace de noms.

L'appareil doit être dans l'état « Opérationnel ».

Nécessite l'authentification d'un utilisateur dans le rôle d'« Administrateur ».

OPTIONS

-a, --auth-passphrase-file <FICHIER_PASSPHRASE_AUTH>
Le chemin vers un fichier contenant une phrase secrète pour l'authentification

La phrase secrète fournie dans le fichier doit être celle de l'utilisateur choisi pour la commande.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois. Avec plusieurs fichiers de phrase secrète, l'ordre compte, car les fichiers sont attribués à l'utilisateur respectif fourni par l'option « --user ».

Peut également être spécifié avec la variable d'environnement NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIG>
Le chemin vers un fichier de configuration personnalisé

S'il est spécifié, le fichier de configuration personnalisé est utilisé à la place de l'emplacement du fichier de configuration par défaut.

Peut également être spécifié avec la variable d'environnement NETHSM_CONFIG.
-l, --label <ETIQUETTE>
Une étiquette identifiant de manière unique un appareil dans le fichier de configuration

Doit être fourni si plus d'un appareil est configuré dans le fichier de configuration.

Peut également être spécifié avec la variable d'environnement NETHSM_LABEL.
-u, --user <UTILISATEUR>
Un nom d'utilisateur utilisé pour une commande

Peut être fourni si aucun nom d'utilisateur n'est configuré dans le fichier de configuration pour un appareil. Doit être fourni si plusieurs noms d'utilisateur du même rôle cible sont configurés dans le fichier de configuration pour un appareil.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois.

Peut également être spécifié avec la variable d'environnement NETHSM_USER.
-h, --help
Afficher l'aide (voir un résumé avec '-h')
<NOM>
Le nom de l'utilisateur à partir duquel supprimer une étiquette
Peut également être spécifié avec la variable d'environnement NETHSM_USER_NAME.
<ETIQUETTE>
L'étiquette à supprimer d'un utilisateur
Peut également être spécifié avec la variable d'environnement NETHSM_USER_TAG.
