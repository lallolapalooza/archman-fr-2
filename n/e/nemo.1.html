Nemo(1) Manuel des commandes générales Nemo(1)

NOM

nemo - le gestionnaire de fichiers de Cinnamon

SYNTAXE

nemo [options] URIs...

DESCRIPTION

Cette page de manuel documente brièvement la commande nemo.

Nemo est le gestionnaire de fichiers de l'environnement de bureau Cinnamon.

OPTIONS

Nemo suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux traits d'union (`-'). Un résumé des options est inclus ci-dessous.

-g
--geometry=GEOMETRY
Crée la fenêtre initiale avec la géométrie spécifiée.
-t
--tabs
Ouvre les URIs dans des onglets.
--existing-window
Ouvre les URIs dans une fenêtre existante.
-n
--no-default-window
Crée des fenêtres uniquement pour les URIs explicitement spécifiés.
--fix-cache
Répare le cache des miniatures de l'utilisateur - cela peut être utile si vous rencontrez des problèmes avec les miniatures de fichiers. Doit être exécuté en tant que root.
--debug
Active le code de débogage. Exemple d'utilisation : 'NEMO_DEBUG=Actions nemo --debug'. Utilisez NEMO_DEBUG=all pour plus de sujets.
-q
--quit
Quitte Nemo.
--help
Affiche un résumé des options.
--version
Affiche la version de Nemo.
Les autres options GNOME standard non listées ici sont également prises en charge.

NOTE CONCERNANT L'UTILISATEUR ROOT

Normalement, nemo et nemo-desktop considèrent l'exécution en tant qu'utilisateur root comme spéciale, avec certaines restrictions et des changements d'interface utilisateur. Ce comportement peut être contourné via une clé gsettings. Vous pouvez utiliser la commande suivante pour activer/désactiver cette substitution :

gsettings set org.nemo.preferences treat-root-as-normal true|false
