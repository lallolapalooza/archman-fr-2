NOM

netplan-set - écrire des fragments de configuration YAML Netplan dans un fichier

SYNTAXE

netplan [--debug] set -h|--help

netplan [--debug] set [--root-dir=ROOT_DIR] [--origin-hint=ORIGIN_HINT] [clé=valeur]

DESCRIPTION

netplan set [clé=valeur] écrit une paire clé/valeur donnée ou un sous-arbre YAML dans un fichier YAML dans /etc/netplan/ et valide son format.

Vous pouvez spécifier une valeur unique comme : "[network.]ethernets.eth0.addresses=[1.2.3.4/24, 5.6.7.8/24]" ou un sous-arbre complet comme : "[network.]ethernets.eth0={dhcp4: true, dhcp6: true}".

Pour les détails sur le format du fichier de configuration, voir netplan(5).

OPTIONS

-h, --help
Imprime l'aide de base.
--debug
Imprime les sorties de débogage pendant le processus.
--root-dir
Écrit les fichiers YAML dans cette racine au lieu de /.
--origin-hint
Spécifie un nom pour le fichier de configuration, par exemple : 70-netplan-set => /etc/netplan/70-netplan-set.yaml.

VOIR AUSSI

netplan(5), netplan-get(8), netplan-dbus(8)
