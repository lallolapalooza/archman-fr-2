NOM

network_namespaces - aperçu des espaces de noms réseau Linux

DESCRIPTION

Les espaces de noms réseau isolent les ressources système associées au réseau : périphériques réseau, piles de protocoles IPv4 et IPv6, tables de routage IP, règles de pare-feu, le répertoire /proc/net (qui est un lien symbolique vers /proc/pid/net), le répertoire /sys/class/net, divers fichiers sous /proc/sys/net, numéros de port (sockets), etc. De plus, les espaces de noms réseau isolent l'espace de noms des sockets abstraits du domaine UNIX (voir unix(7)).

Un périphérique réseau physique ne peut résider que dans un seul espace de noms réseau. Lorsqu'un espace de noms réseau est libéré (c'est-à-dire lorsque le dernier processus de l'espace de noms se termine), ses périphériques réseau physiques sont déplacés vers l'espace de noms réseau initial (pas vers l'espace de noms du parent du processus).

Un périphérique réseau virtuel (veth(4)) paire fournit une abstraction de type "tuyau" qui peut être utilisée pour créer des tunnels entre des espaces de noms réseau, et peut être utilisée pour créer un pont vers un périphérique réseau physique dans un autre espace de noms. Lorsqu'un espace de noms est libéré, les périphériques veth(4) qu'il contient sont détruits.

L'utilisation des espaces de noms réseau nécessite un noyau configuré avec l'option CONFIG_NET_NS.
