NOM

neomutt - L'agent de messagerie NeoMutt (MUA)

SYNTAXE

neomutt [-Enx] [-e commande] [-F config] [-H brouillon] [-i inclure] [-b adresse] [-c adresse] [-s sujet] [-a fichier] ... [--] adresse ...
neomutt [-nx] [-e commande] [-F config] [-b adresse] [-c adresse] [-s sujet] [-a fichier] ... [--] adresse ... < message
neomutt [-nRy] [-e commande] [-F config] [-f boite aux lettres] [-m type]
neomutt [-n] [-e commande] [-F config] -A alias
neomutt [-n] [-e commande] [-F config] -B
neomutt [-n] [-e commande] [-F config] -D [-S] [-O]
neomutt [-n] [-e commande] [-F config] -d niveau -l fichier
neomutt [-n] [-e commande] [-F config] -G
neomutt [-n] [-e commande] [-F config] -g serveur
neomutt [-n] [-e commande] [-F config] -p
neomutt [-n] [-e commande] [-F config] -Q variable [-O]
neomutt [-n] [-e commande] [-F config] -Z
neomutt [-n] [-e commande] [-F config] -z [-f boite aux lettres]
neomutt -v[v]

DESCRIPTION

NeoMutt est un programme petit mais très puissant basé sur texte pour lire et envoyer des courriels sous les systèmes d'exploitation Unix, incluant le support pour les terminaux couleur, MIME, OpenPGP, et un mode de tri par fils de discussion.

Note: Cette page de manuel donne un bref aperçu des options de ligne de commande de NeoMutt. Vous devriez trouver une copie du manuel complet dans /usr/share/doc/neomutt, en format texte brut, HTML et/ou PDF.

OPTIONS

--
Argument spécial forçant NeoMutt à arrêter l'analyse des options et à traiter les arguments restants comme des adresses même s'ils commencent par un tiret
-A alias
Affiche une version développée de l'alias donné sur la sortie standard et quitte
-a fichier
Attache un ou plusieurs fichiers à un message (doit être la dernière option). Ajoutez toute adresse après l'argument '--', par exemple :
neomutt -a image.jpg -- adresse1 
neomutt -a image.jpg *.png -- adresse1 adresse2
-b adresse
Spécifie un destinataire en copie carbone invisible (Cci)
-C
Active les opérations cryptographiques dans les cas où elles sont désactivées par défaut. Celles-ci incluent :
  • Mode batch.
  • Envoi d'un message différé.
  • Renvoi d'un message.
-c adresse
Spécifie un destinataire en copie carbone (Cc)
-D
Affiche toutes les variables de configuration sous forme de paires 'nom=valeur' sur la sortie standard
-D -D
-DD Similaire à -D, mais n'affiche que la configuration qui a changé
-D -O
Similaire à -D, mais affiche la documentation en une ligne
-D -S
Similaire à -D, mais masque la valeur des variables sensibles
-d niveau
Enregistre la sortie de débogage dans un fichier (par défaut "~/.neomuttdebug0"). Le niveau peut aller de 1 à 5 et affecte la verbosité (une valeur de 2 est recommandée)
L'utilisation de cette option avec -l est utile pour enregistrer le processus de démarrage précoce (avant de lire toute configuration et donc $debug_level et $debug_file)
-E
Édite le brouillon (-H) ou le fichier d'inclusion (-i) lors de la composition d'un message
-e commande
Spécifie une commande à exécuter après la lecture des fichiers de configuration
-F config
Spécifie un fichier d'initialisation alternatif à lire, voir la section FICHIERS ci-dessous pour une liste des fichiers de configuration réguliers
-f boite aux lettres
Spécifie une boîte aux lettres (telle que définie avec la commande mailboxes) à charger
-G
Démarre NeoMutt avec une liste des groupes de discussion auxquels on est abonné
-g serveur
Similaire à -G, mais démarre sur le serveur de news spécifié
-H brouillon
Spécifie un fichier de brouillon contenant l'en-tête et le corps à utiliser pour envoyer un message. Si brouillon est "-", alors les données sont lues depuis l'entrée standard. Le fichier brouillon est censé contenir uniquement un email RFC822 — en-têtes et corps. Bien que ce ne soit pas un fichier mbox, si une ligne mbox "From " est présente, elle sera ignorée silencieusement. Les fichiers brouillons sont traités de la même manière en mode interactif et batch ; ils ne sont pas transmis intacts. Par exemple, les fichiers brouillons chiffrés seront déchiffrés.
-h
Affiche ce message d'aide et quitte
-i inclure
Spécifie un fichier d'inclusion à intégrer dans le corps d'un message
-l fichier
Spécifie un fichier pour la sortie de débogage (par défaut "~/.neomuttdebug0")
Ceci supplante le paramètre $debug_file et NeoMutt conserve jusqu'à cinq journaux de débogage ({ fichier | $debug_file | ~/.neomuttdebug }[0-4]) avant d'écraser le fichier le plus ancien
-m type
Spécifie un format de boîte aux lettres par défaut type pour les nouveaux dossiers créés
Le type est MH, MMDF, Maildir ou mbox (insensible à la casse)
-n
Ne lit pas le fichier de configuration système
-p
Reprend un message précédemment différé, le cas échéant
-Q variable
Met en file d'attente

VOIR AUSSI

La documentation complète de NeoMutt est disponible dans le manuel complet, généralement situé dans /usr/share/doc/neomutt/.

ENVIRONNEMENT

EDITOR
Spécifie l'éditeur à utiliser si VISUAL n'est pas défini. Par défaut, l'éditeur Vi s'il n'est pas défini.
EGDSOCKET
Pour OpenSSL depuis la version 0.9.5, les fichiers mentionnés dans RANDFILE ci-dessous peuvent être des sockets d'Entropy Gathering Daemon (EGD). De plus, si ~/.entropy et /tmp/entropy existent, ils seront utilisés pour initialiser les fonctions de la bibliothèque SSL. Les sockets spécifiés doivent appartenir à l'utilisateur et avoir une permission de 600 (nombre octal représentant).
EMAIL
L'adresse e-mail de l'utilisateur.
HOME
Chemin complet du répertoire personnel de l'utilisateur.
MAIL
Chemin complet de la boîte aux lettres du spool de l'utilisateur.
MAILCAPS
Chemin de recherche des fichiers mailcap. S'il n'est pas défini, un chemin de recherche conforme à RFC1524, étendu avec des chemins relatifs à NeoMutt (aux positions deux et trois), sera utilisé à la place : "$HOME/.mailcap:/usr/share/neomutt/mailcap:/etc/mailcap:/etc/mailcap:/usr/etc/mailcap:/usr/local/etc/mailcap" sera utilisé à la place.
MAILDIR
Chemin complet de la boîte aux lettres du spool de l'utilisateur si MAIL n'est pas défini. Couramment utilisé lorsque la boîte aux lettres du spool est un dossier maildir(5).
MM_NOASK
Si cette variable est définie, les mailcaps sont toujours utilisés sans demander d'abord.
NNTPSERVER
Similaire à la variable de configuration $news_server, spécifie le nom de domaine ou l'adresse du serveur NNTP par défaut auquel se connecter. S'il n'est pas défini, /etc/nntpserver est utilisé mais peut être remplacé par l'option de ligne de commande -g.
RANDFILE
Comme la variable de configuration $entropy_file, définit un chemin vers un fichier contenant des données aléatoires utilisées pour initialiser les fonctions de la bibliothèque SSL. S'il n'est pas défini, ~/.rnd est utilisé. NE PAS stocker de données importantes dans le fichier spécifié.
REPLYTO
Lorsqu'elle est définie, spécifie l'adresse de réponse par défaut.
TEXTDOMAINDIR
Définit un chemin absolu correspondant à /usr/share/locale qui sera reconnu par GNU gettext(1) et utilisé pour le support de la langue native (NLS) si activé.
TMPDIR
Répertoire dans lequel les fichiers temporaires sont créés. Par défaut, /tmp s'il n'est pas défini. La variable de configuration $tmp_dir a la priorité sur celle-ci.
VISUAL
Spécifie l'éditeur à utiliser lors de la composition des messages.
XDG_CONFIG_DIRS
Spécifie un emplacement conforme à X Desktop Group (XDG) pour le fichier de configuration système, comme décrit dans la section FICHIERS ci-dessous. Cette variable vaut par défaut /etc/xdg. Permet de contourner le chargement avec l'option de ligne de commande -n.
XDG_CONFIG_HOME
Spécifie un emplacement conforme à XDG pour le fichier de configuration spécifique à l'utilisateur, comme décrit dans la section FICHIERS ci-dessous. Cette variable vaut par défaut $HOME/.config. Peut être remplacée par l'option de ligne de commande -F.

FICHIERS

Fichiers de configuration

NeoMutt lira seulement le premier fichier de configuration trouvé de catégorie système et spécifique à l'utilisateur, parmi la liste ci-dessous et dans cet ordre.

Mais il permet de construire une configuration récursive en utilisant la commande source.

 #N système spécifique utilisateur
1 $XDG_CONFIG_DIRS/neomutt/neomuttrc $XDG_CONFIG_HOME/neomutt/neomuttrc
2 $XDG_CONFIG_DIRS/neomutt/Muttrc *) $XDG_CONFIG_HOME/neomutt/muttrc
3 /etc/neomuttrc $XDG_CONFIG_HOME/mutt/neomuttrc
4 /etc/Muttrc *) $XDG_CONFIG_HOME/mutt/muttrc
5 /usr/share/neomutt/neomuttrc ~/.neomutt/neomuttrc
6 /usr/share/neomutt/Muttrc *) ~/.neomutt/muttrc
7 — ~/.mutt/neomuttrc
8 — ~/.mutt/muttrc
9 — ~/.neomuttrc
10 — ~/.muttrc
 *) Notez la casse du nom de fichier

Autres fichiers pertinents

Sauf indication contraire, NeoMutt traitera tous les fichiers groupés dans l'ordre (de haut en bas) tels qu'ils sont spécifiés dans cette liste.

~/.mailcap
/etc/mailcap
Définitions spécifiques à l'utilisateur et au système pour gérer les types MIME non textuels, consultez la variable d'environnement MAILCAPS ci-dessus pour des emplacements de recherche supplémentaires.
~/.neomuttdebug0
Fichier de journal de débogage par défaut de l'utilisateur. Pour plus de détails ou pour personnaliser le chemin du fichier, consultez les options de ligne de commande -d et -l ci-dessus.
/etc/mime.types
/etc/mime.types
/usr/share/neomutt/mime.types
~/.mime.types
Fichiers de description pour une cartographie texte brut simple entre les types MIME et les extensions de nom de fichier. NeoMutt analyse ces fichiers dans l'ordre spécifié lors du traitement des pièces jointes pour déterminer leur type MIME.
/usr/share/doc/neomutt/manual.{html,pdf,txt}
Le manuel complet de NeoMutt au format HTML, PDF ou texte brut.
/tmp/neomutt-XXXX-XXXX-XXXX
Fichiers temporaires créés par NeoMutt. Pour des emplacements personnalisés, consultez la description de la variable d'environnement TMPDIR ci-dessus. Notez que le suffixe -XXXX-XXXX-XXXX est juste un espace réservé pour, par exemple, le nom de l'hôte, le nom/ID de l'utilisateur, l'ID du processus et/ou d'autres données aléatoires.

    NOM

    neomutt - client de messagerie électronique interactif basé sur Mutt

    SYNOPSIS

    neomutt [-A <compte>] [-a <attachement>] [-d <niveau_de_débogage>] [-e <commande>] [-F <fichier_de_profil>] [-f <fichier_de_boîte_aux_lettres>] [-h] [-i <fichier_d'identifiants>] [-k] [-l <fichier_journal>] [-m <type_de_boîte_aux_lettres>] [-n] [-p <nom_de_l'imprimante>] [-R] [-r <nom_du_repertoire>] [-s <sujet>] [-T <type_de_corps>] [-u <compte_imap>] [-v] [-x] [<fichier_de_message> ...]

    DESCRIPTION

    neomutt est un client de messagerie électronique interactif basé sur le code de Mutt, conçu pour être personnalisable et puissant. Il offre une interface en ligne de commande pour lire, gérer et envoyer des courriels. Il prend en charge une variété de protocoles, notamment IMAP, POP3 et NNTP.

    OPTIONS

    -A <compte>
    Spécifie le compte de messagerie à utiliser.
    -a <attachement>
    Ajoute un fichier comme pièce jointe à un nouveau message.
    -d <niveau_de_débogage>
    Définit le niveau de détail pour le journal de débogage.
    -e <commande>
    Exécute une commande neomutt avant de charger le profil.
    -F <fichier_de_profil>
    Spécifie un fichier de configuration alternatif.
    -f <fichier_de_boîte_aux_lettres>
    Ouvre une boîte aux lettres spécifique au démarrage.
    -h
    Affiche un message d'aide et quitte.
    -i <fichier_d'identifiants>
    Spécifie un fichier contenant les identifiants pour l'authentification.
    -k
    Désactive le saut de ligne automatique dans le corps des messages.
    -l <fichier_journal>
    Joue un rôle dans la journalisation des événements.
    -m <type_de_boîte_aux_lettres>
    Spécifie le type de boîte aux lettres à utiliser (par exemple, mbox, maildir).
    -n
    Force neomutt à lire les en-têtes de tous les messages d'une boîte aux lettres, même si elle est vide.
    -p <nom_de_l'imprimante>
    Définit la commande d'impression par défaut.
    -R
    Ignore les fichiers de configuration personnalisés et utilise uniquement les valeurs par défaut.
    -r <nom_du_repertoire>
    Spécifie le répertoire où se trouvent les boîtes aux lettres.
    -s <sujet>
    Définit le sujet d'un nouveau message.
    -T <type_de_corps>
    Spécifie le type de contenu du corps du message.
    -u <compte_imap>
    Spécifie le compte IMAP à utiliser.
    -v
    Affiche la version de neomutt et quitte.
    -x
    Force neomutt à demander une confirmation avant d'écraser un fichier.
    <fichier_de_message> ...
    Spécifie un ou plusieurs fichiers de messages à afficher ou à traiter.

    FICHIERS

    ~/.config/neomutt/neomuttrc
    Fichier de configuration principal de neomutt.
    ~/.cache/neomutt/
    Répertoire pour les fichiers de cache et temporaires.

    ENVIRONNEMENT

    Les variables d'environnement suivantes peuvent affecter le comportement de neomutt :

    HOME
    Répertoire personnel de l'utilisateur.
    TMPDIR
    Répertoire temporaire.
