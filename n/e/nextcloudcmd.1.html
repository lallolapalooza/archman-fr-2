NEXTCLOUDCMD(1) Manuel du client Nextcloud NEXTCLOUDCMD(1)

NOM

nextcloudcmd - Outil client Nextcloud en ligne de commande.

SYNTAXE

nextcloudcmd [OPTIONS...] sourcedir url-nextcloud

DESCRIPTION

nextcloudcmd est l'outil en ligne de commande utilisé pour l'utilitaire de bureau de synchronisation de fichiers de Nextcloud.

Contrairement au client graphique nextcloud(1), nextcloudcmd effectue une seule passe de synchronisation puis se termine. Ce faisant, nextcloudcmd remplace le binaire ocsync utilisé dans le même but dans les versions antérieures.

Une passe de synchronisation synchronise un répertoire local unique à l'aide d'un partage WebDAV sur un serveur Nextcloud distant.

Pour invoquer le client en ligne de commande, fournissez le répertoire local et le répertoire distant : Le premier paramètre est le répertoire local. Le second paramètre est l'URL du serveur.

NOTE :

Avant la version 1.6 de nextcloudcmd, l'outil n'acceptait que owncloud:// ou ownclouds:// à la place de http:// et https:// comme schéma. Voir les Exemples pour plus de détails.

OPTIONS

--path
Remplace le dossier racine distant par défaut par un sous-dossier spécifique sur le serveur (par ex. : /Documents synchronisera le sous-dossier Documents sur le serveur)
--user, -u <utilisateur>
Utiliser utilisateur comme nom de connexion.
--password, -p <mot de passe>
Utiliser mot de passe comme mot de passe.
-n
Utiliser netrc(5) pour la connexion.
--non-interactive
Ne pas poser de questions.
--silent, --s
Empêche la sortie verbale des logs.
--trust
Faire confiance à n'importe quel certificat SSL, y compris les certificats invalides.
--httpproxy http://[utilisateur@motdepasse:]<serveur>:<port>
Utilise serveur comme proxy HTTP.
--exclude <fichier>
Fichier de liste d'exclusion
--unsyncedfolders <fichier>
Fichier contenant la liste des dossiers non synchronisés (synchronisation sélective)
--max-sync-retries <n>
Réessaye au maximum n fois (par défaut 3)
-h
Synchronise les fichiers cachés, ne pas les ignorer

EXEMPLE

Pour synchroniser le répertoire Nextcloud Music avec le répertoire local media/music via un proxy écoutant sur le port 8080 sur la machine passerelle 192.168.178.1, la ligne de commande serait :

$ nextcloudcmd --httpproxy http://192.168.178.1:8080 --path /Music \
              $HOME/media/music \
              https://serveur/nextcloud

nextcloudcmd demandera le nom d'utilisateur et le mot de passe, sauf s'ils ont été spécifiés sur la ligne de commande ou si -n (voir netrc(5)) a été passé.
