ne_addr_error(3)

Paquet: neon

Licences: LGPL-2.0-or-later

NE_ADDR_RESOLVE(3) référence de l'API neon NE_ADDR_RESOLVE(3)

NOM

ne_addr_resolve, ne_addr_result, ne_addr_first, ne_addr_next, ne_addr_error, ne_addr_canonical, ne_addr_destroy - fonctions pour résoudre les noms d'hôte en adresses

SYNTAXE

#include <ne_socket.h>

ne_sock_addr *ne_addr_resolve(const char *hostname, int flags);

int ne_addr_result(const ne_sock_addr *addr);

const ne_inet_addr *ne_addr_first(ne_sock_addr *addr);

const ne_inet_addr *ne_addr_next(ne_sock_addr *addr);

char *ne_addr_error(const ne_sock_addr *addr, char *buffer, size_t bufsiz);

const char *ne_addr_canonical(const ne_sock_addr *addr);

void ne_addr_destroy(ne_sock_addr *addr);

DESCRIPTION

La fonction ne_addr_resolve résout le nom d'hôte hostname donné, retournant un objet ne_sock_addr représentant l'adresse (ou les adresses) associée au nom d'hôte. Le paramètre flags doit être zéro, ou si NE_ADDR_CANON est utilisé, le nom canonique du nom d'hôte sera déterminé.

Le nom d'hôte passé à ne_addr_resolve peut être un nom d'hôte DNS (par exemple "www.example.com") ou un quad quadrilatère IPv4 (par exemple "192.0.34.72") ; ou, sur les systèmes qui supportent IPv6, une adresse hexadécimale IPv6, qui peut être entourée de crochets, par exemple "[::1]".

Pour déterminer si le nom d'hôte a été résolu avec succès, la fonction ne_addr_result est utilisée, qui retourne une valeur non nulle si une erreur s'est produite. Si une erreur s'est produite, la fonction ne_addr_error peut être utilisée, qui copiera la chaîne d'erreur dans un buffer donné (de taille bufsiz).

Les fonctions ne_addr_first et ne_addr_next sont utilisées pour récupérer les adresses Internet associées à un objet adresse qui a été résolu avec succès. ne_addr_first retourne la première adresse ; ne_addr_next retourne l'adresse suivante après le dernier appel à ne_addr_next ou ne_addr_first, ou NULL s'il n'y a plus d'adresses. Le pointeur ne_inet_addr retourné par ces fonctions peut être passé à ne_sock_connect pour connecter un socket.

Si le drapeau NE_ADDR_CANON a été utilisé avec ne_addr_resolve, le nom d'hôte canonique peut être récupéré en utilisant ne_addr_canonical.

Une fois que l'objet adresse a été utilisé, il doit être détruit en utilisant ne_addr_destroy.

VALEUR RETOURNÉE

ne_addr_resolve retourne un pointeur vers un objet adresse, et jamais NULL. ne_addr_error retourne le paramètre buffer.

EXEMPLES

Le code ci-dessous imprime l'ensemble des adresses associées au nom d'hôte www.google.com.

ne_sock_addr *addr;
char buf[256];
addr = ne_addr_resolve("www.google.com", 0);
if (ne_addr_result(addr)) {
    printf("Impossible de résoudre www.google.com : %s\n",
           ne_addr_error(addr, buf, sizeof buf));
} else {
    const ne_inet_addr *ia;
    printf("www.google.com:");
    for (ia = ne_addr_first(addr); ia != NULL; ia = ne_addr_next(addr)) {
        printf(" %s", ne_iaddr_print(ia, buf, sizeof buf));
    }
    putchar('\n');
}
ne_addr_destroy(addr);
