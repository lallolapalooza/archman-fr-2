NOM

ne_strparam - Encodage de valeur de paramètre étendu HTTP

SYNTAXE

#include <ne_string.h>

char *ne_strparam(const char *charset, const char *lang, const char *value);

DESCRIPTION

La fonction ne_strparam peut être utilisée pour encoder une valeur de paramètre étendue pour un en-tête HTTP, telle que définie dans la RFC 5987. La fonction prend comme arguments la valeur à encoder, en utilisant un jeu de caractères MIME spécifié charset, et une balise de langue lang. L'encodage de paramètre étendu est utilisé dans les spécifications du protocole HTTP pour permettre l'intégration facile de caractères spéciaux (tels que les guillemets, les séparateurs ou les caractères non-ASCII) dans les valeurs d'en-tête.

Conformément à la RFC 5987, l'argument charset doit être soit "UTF-8", soit "IS0-8859-1", mais l'argument lang peut être NULL.

VALEUR DE RETOUR

La valeur de retour est soit :

NULL

si le paramètre value est un "paramètre régulier" et ne nécessite pas d'encodage étendu

non-NULL

l'encodage de la valeur d'entrée en tant que paramètre étendu sous forme de chaîne allouée par malloc et terminée par NUL

HISTORIQUE

ne_strparam est disponible dans neon 0.32.0 et versions ultérieures.

VOIR AUSSI

https://www.rfc-editor.org/rfc/rfc5987.html
