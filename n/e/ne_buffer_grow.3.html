NE_BUFFER_CLEAR(3) Référence API neon NE_BUFFER_CLEAR(3)

NOM

ne_buffer_clear, ne_buffer_grow, ne_buffer_altered - effacer, agrandir, ou marquer comme modifié un tampon de chaîne

SYNTAXE

#include <ne_string.h>

void ne_buffer_clear(ne_buffer *buf);

void ne_buffer_altered(ne_buffer *buf);

void ne_buffer_grow(ne_buffer *buf, size_t size);

DESCRIPTION

La fonction ne_buffer_clear définit la chaîne stockée dans buf comme étant la chaîne vide ("").

La fonction ne_buffer_altered doit être utilisée après que la chaîne stockée dans le tampon buf est modifiée directement plutôt qu'en utilisant ne_buffer_append, ne_buffer_zappend ou ne_buffer_concat.

La fonction ne_buffer_grow assure qu'au moins size octets sont alloués pour la chaîne ; cela peut être utilisé si une grande quantité de données va être ajoutée au tampon et peut aboutir à une allocation mémoire plus efficace.
