NOM

ne_i18n_init - fonctions pour initialiser le support de l'internationalisation

SYNTAXE

#include <ne_i18n.h>

void ne_i18n_init(const char *encoding);

DESCRIPTION

La fonction ne_i18n_init peut être utilisée pour activer le support des messages traduits dans la bibliothèque neon. Le paramètre encoding, s'il n'est pas NULL, spécifie l'encodage de caractères requis pour les chaînes traduites générées. S'il est NULL, l'encodage de caractères approprié pour la locale du processus sera utilisé.

Cet appel n'est strictement nécessaire que si soit :

1. neon a été installé dans un préfixe différent de l'implémentation gettext dont il dépend à des fins d'i18n, ou
2. l'appelant requiert que les messages traduits soient dans un encodage de caractères particulier.

Si ne_i18n_init n'est jamais appelé, les catalogues de messages ne seront pas trouvés si le cas (a) s'applique (et donc les messages d'erreur en anglais seront utilisés), et utiliseront l'encodage de caractères par défaut spécifié par la locale du processus. La bibliothèque fonctionnera sinon correctement.

Notez que l'encodage utilisé est un paramètre global du processus et donc les résultats peuvent être inattendus si d'autres utilisateurs de neon au sein du processus appellent ne_i18n_init avec un paramètre d'encodage différent.
