Paquet: neon

Licences: LGPL-2.0-or-later

NE_SET_REQUEST_BODY_(3) Référence API neon NE_SET_REQUEST_BODY_(3)

NOM

ne_set_request_body_buffer, ne_set_request_body_fd, ne_set_request_body_provider - inclure un corps de message avec une requête

SYNTAXE

#include <ne_request.h>

void ne_set_request_body_buffer(ne_request *req, const char *buf, size_t count);

int ne_set_request_body_fd(ne_request *req, int fd, ne_off_t begin, ne_off_t length);

typedef ssize_t (*ne_provide_body)(void *userdata, char *data, size_t buflen);

int ne_set_request_body_provider(ne_request *req, ne_off_t length, ne_provide_body provider, void *userdata);

DESCRIPTION

La fonction ne_set_request_body_buffer spécifie qu'un corps de message doit être inclus dans la requête, celui-ci étant stocké dans le tampon count octets buf.

La fonction ne_set_request_body_fd peut être utilisée pour inclure un corps de message dans une requête qui est lue à partir d'un descripteur de fichier. Le corps est lu à partir du descripteur de fichier fd, qui doit être associé à un fichier accessible en déplacement (pas un tuyau, une socket ou un FIFO). count octets sont lus, à partir du décalage begin (par conséquent, passer begin à zéro signifie que le corps est lu depuis le début du fichier).

Pour les deux fonctions ci-dessus, la source du corps de la requête doit survivre jusqu'à ce que la requête ait été envoyée ; ni le tampon mémoire passé à ne_set_request_body_buffer ni le descripteur de fichier passé à ne_set_request_body_fd ne sont copiés en interne.

La fonction ne_set_request_body_provider peut être utilisée pour inclure un corps de message dans une requête fournie par une fonction de rappel. La longueur du corps passée dans le paramètre length doit être positive, ou si un corps de requête en morceaux est requis, comme décrit ci-dessous, -1 peut être utilisé.

Avant d'envoyer le corps, la fonction de rappel est appelée une fois avec le paramètre buflen à 0. Le corps est ensuite lu en appelant la fonction de rappel de manière répétée jusqu'à ce qu'elle retourne 0, indiquant la fin du corps. La valeur de retour de la fonction de rappel doit être la suivante :

inférieure à 0

Une erreur ; la requête sera abandonnée. La chaîne d'erreur de session doit être définie via ne_set_error.

0

Fin du corps.

entre 0 et buflen

Nombre d'octets de données du corps de la requête.

Corps de requête en morceaux

Les corps de requête en morceaux ne sont envoyés que lorsque ne_set_request_body_provider est utilisé et que -1 est passé comme length. Dans ce cas, la longueur du corps de la requête n'a pas besoin d'être déterminée à l'avance. La fin du corps de la requête est indiquée par le retour de 0 de la fonction de rappel.

Avant d'utiliser un corps de requête en morceaux, l'appelant doit déterminer si HTTP/1.1 est pris en charge (par le serveur d'origine et tout serveur proxy HTTP configuré). Cela peut être fait en vérifiant que ne_version_pre_http11 retourne zéro après avoir effectué une requête OPTIONS ou HEAD.

ne_request_create, ne_set_error
