NOM

netctl.special - Unités systemd spéciales de netctl

SYNTAXE

netctl.service, netctl-auto.service, netctl-ifplugd.service, netctl-wait-online.service

DESCRIPTION

Livré avec netctl, il existe quelques unités systemd qui ne sont pas contrôlées par la commande netctl. Elles peuvent être utilisées via l'utilitaire systemctl de systemd.

UNITÉS SPÉCIALES

netctl.service

Lorsqu'elle est démarrée, cette unité essaie de démarrer les profils qui étaient actifs lorsque l'unité a été arrêtée pour la dernière fois. Dans certains cas, l'interface à laquelle un profil est lié pourrait ne pas être encore disponible lorsque netctl.service essaie de lancer un profil. Une solution simple et "bricolée" consiste à faire :
echo "[[ -t 0 ]] || sleep 3" > /etc/netctl/interfaces/<interface>
chmod 755 /etc/netctl/interfaces/<interface>
Une solution plus concise consiste à d'abord activer un profil via netctl
puis à le désactiver à nouveau via systemctl :
netctl enable <profil>
systemctl disable netctl@<profil>
De cette façon, le fichier de configuration de l'unité pour le profil reste
en existence, tandis que le profil n'est pas activé.

netctl-sleep.service

Lorsqu'elle est activée, cette unité enregistre et arrête les profils réseau actifs avant que la machine ne soit mise en veille. Après la reprise du système, les profils précédemment enregistrés sont redémarrés.

netctl-auto@<interface>.service

Cette unité émet une analyse sur l'interface pour laquelle elle est utilisée et essaie de démarrer un profil pour un réseau qu'elle trouve. Elle est destinée aux interfaces sans fil. Les valeurs spécifiques au profil pour WPADriver sont ignorées, mais il est possible de spécifier WPADriver= dans un hook d'interface (/etc/netctl/interfaces/<interface>).

Utilisez netctl-auto(1) au lieu de netctl(1) pour contrôler la sélection automatique des profils lors de l'utilisation de cette unité.

netctl-ifplugd@<interface>.service

Cette unité démarre ifplugd sur l'interface pour laquelle elle est utilisée. Elle essaiera de démarrer un profil netctl chaque fois qu'un câble est branché à l'interface et arrêtera le profil lorsque le câble sera débranché. Notez que cette unité ne fournit pas network.target.

netctl-wait-online.service

Lorsqu'elle est activée, cette unité attend que tous les profils netctl activés soient en ligne. L'activation de cette unité fait que network-online.target n'est atteint qu'une fois que tous les profils netctl activés sont entièrement connectés. Le temps maximum, en secondes, à attendre pour les profils peut être passé à cette unité via TIMEOUT_ONLINE=. La valeur par défaut est 120. Si un délai d'attente se produit, le service entre dans un état d'échec.

VOIR AUSSI

netctl(1), netctl-auto(1), netctl.profile(5)
