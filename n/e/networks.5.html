networks(5) Manuel des formats de fichiers networks(5)

NOM

networks - informations sur les noms de réseaux

DESCRIPTION

Le fichier /etc/networks est un fichier texte ASCII brut qui décrit les réseaux DARPA connus et les noms symboliques de ces réseaux. Chaque ligne représente un réseau et a la structure suivante :

nom numéro alias ...

où les champs sont délimités par des espaces ou des tabulations. Les lignes vides sont ignorées. Le caractère dièse (#) indique le début d'un commentaire : ce caractère, ainsi que les caractères restants jusqu'à la fin de la ligne courante, sont ignorés par les fonctions bibliothèque qui traitent le fichier.

Les descriptions des champs sont :

nom
Le nom symbolique du réseau. Les noms de réseau peuvent contenir n'importe quel caractère imprimable sauf les caractères d'espacement ou le caractère de commentaire.
numéro
Le numéro officiel de ce réseau en notation nombres-et-points (voir inet(3)). Le ".0" final (pour le composant hôte de l'adresse du réseau) peut être omis.
alias
Des alias optionnels pour le réseau.

Ce fichier est lu par les utilitaires route(8) et netstat(8). Seuls les réseaux de classe A, B ou C sont pris en charge, les réseaux partitionnés (c'est-à-dire network/26 ou network/28) ne sont pas pris en charge par ce fichier.

FICHIERS

/etc/networks
Le fichier de définition des réseaux.

VOIR AUSSI

getnetbyaddr(3), getnetbyname(3), getnetent(3), netstat(8), route(8)
