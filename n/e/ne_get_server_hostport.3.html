ne_get_server_hostport(3)

Paquet: neon

Licences: LGPL-2.0-or-later

NE_SET_USERAGENT(3) Référence de l'API neon NE_SET_USERAGENT(3)

NOM

ne_set_useragent, ne_set_read_timeout, ne_set_connect_timeout, ne_get_scheme, ne_get_server_hostport - propriétés communes pour les sessions HTTP

SYNOPIS

#include <ne_session.h>

void ne_set_useragent(ne_session *session, const char *product);

void ne_set_read_timeout(ne_session *session, int timeout);

void ne_set_connect_timeout(ne_session *session, int timeout);

const char *ne_get_scheme(ne_sesssion *session);

const char *ne_get_server_hostport(ne_sesssion *session);

DESCRIPTION

L'en-tête de requête User-Agent est utilisé pour identifier le logiciel qui a généré la requête à des fins statistiques ou de débogage. neon n'envoie pas d'en-tête User-Agent à moins qu'un appel à ne_set_useragent ne soit effectué. ne_set_useragent doit recevoir une chaîne de produit conforme à la grammaire des tokens de produit de RFC2616 ; de la forme "Produit/Version".

Lorsque neon lit à partir d'une socket, par défaut l'opération de lecture expire après 60 secondes, et la requête échoue en donnant une erreur NE_TIMEOUT. Pour configurer cet intervalle de temps d'attente, appelez ne_set_read_timeout en donnant le nombre de secondes désiré comme paramètre timeout.

Lorsqu'une connexion est établie avec un serveur, normalement seule la gestion des délais d'attente TCP du système s'applique. Pour configurer un délai d'attente spécifique (et probablement plus court), ne_set_connect_timeout peut être utilisé, en donnant le nombre de secondes désiré comme paramètre timeout. Si 0 est passé, alors le comportement par défaut d'utilisation du délai d'attente TCP du système sera utilisé.

Le schéma utilisé pour créer initialement la session sera retourné par ne_get_scheme.

La paire hôte:port associée à la session sera retournée par ne_get_server_hostport ; par exemple www.example.com:8080. Notez que le :port sera omis si le port par défaut pour le schéma est utilisé.

EXEMPLES

Définir une chaîne de user-agent :

ne_session *sess = ne_session_create(...);
ne_set_useragent(sess, "MonApplication/2.1");

Définir un délai d'attente de lecture de 30 secondes :

ne_session *sess = ne_session_create(...);
ne_set_read_timeout(sess, 30);

VOIR AUSSI

ne_session_create, ne_set_session_flag.
