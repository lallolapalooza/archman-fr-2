NOM

Netwatch - Moniteur de Protocole Internet Ethernet

SYNOPSIS

netwatch [ -h ] [-b] [-i dd.dd.dd.dd] [-m dd.dd.dd.dd] [-n] [ - t] [ -e ethnum ] [ -c netconfigfile ]

DESCRIPTION

Netwatch examine tous les paquets circulant sur un réseau Ethernet et analyse les paquets IP. Les informations sont classées par hôtes source et destination. Un affichage ncurses indique un statut à double liste pour tous les hôtes. L'affichage de gauche concerne les hôtes LOCAUX. La liste de droite concerne les hôtes DISTANTS. Il est possible d'examiner les statistiques (comptes) sur le nombre de paquets, d'octets, le type de service IP et le dernier hôte de communication pour chaque hôte. Utilisez les touches fléchées (gauche et droite) pour modifier l'affichage.

OPTIONS

-e ethnum
ethnum est le nom du périphérique Ethernet à utiliser avec netwatch. (par exemple, -e eth1 sélectionne le périphérique eth1 plutôt que le périphérique par défaut eth0.
-c confignetfile
sélectionne le nom du fichier contenant les informations ifconfig. Notez que ce n'est pas nécessaire car netwatch utilisera les informations de routage de /proc/net pour construire toutes les informations nécessaires (sans utiliser AUCUN fichier de configuration).
-b
Pour un pont transparent, ignorer un paquet sur deux... (anciens noyaux)
-i dd.dd.dd.dd
Falsifier une adresse Internet locale pour la machine "actuelle"... (utile pour créer un faux réseau local pour la surveillance en combinaison avec l'option -m)
-m dd.dd.dd.dd
Falsifier le masque de réseau utilisé pour l'évaluation du réseau local
-n
Ne pas résoudre les noms (afficher uniquement les adresses)
-h
Informations d'aide simples
-t
Démarrer Netwatch en mode TOP (délai de démarrage de 30 sec.)

COMMANDES UTILISATEUR

La description suivante tentera de clarifier les touches que netwatch comprend. Il est important de savoir que le programme dépend du mode. Cela signifie que les commandes peuvent changer en fonction du mode actuel. Le mode principal est le mode double liste. Dans ce mode, utilisez

<tab>
touche - changer l'affichage de défilement vers l'autre liste (double liste). Regardez TOUCHE.
<gauche>
touche - changer les options d'affichage (se déplacer vers la gauche parmi les options)
<droite>
touche - changer les options d'affichage (se déplacer vers la droite parmi les options)
<haut>
touche - faire défiler vers la page d'hôte précédente dans la liste actuelle (voir TOUCHE) Changer les options d'affichage (se déplacer vers la droite parmi les options)
<bas>
touche - faire défiler vers la page d'hôte suivante dans la liste actuelle (voir TOUCHE)

h
touche - affiche l'écran d'aide
t
touche - basculer le mode TOP (où mise à jour toutes les 30 secondes sur les hôtes les plus actifs)
c
touche - effacer les comptes pour tous les hôtes
n
touche - nettoyer les tables d'hôtes distants et locaux
N
touche - nettoyer les tables d'hôtes distants OU locaux (dépend de celle qui est active)
L
touche - produire un LOG des entrées d'affichage actuelles (DISTANT ou LOCAL)
b
touche - basculer l'affichage des entrées BLEUES (ANCIENNES)
d
touche - basculer l'affichage des entrées DOMAIN (Requêtes Serveur de Noms)
w
touche - entrer en mode WATCH pour visualiser les statistiques de ROUTAGE et les paquets d'HÔTES
<F10>, <END>
ou touche q - Quitte le programme
