NE_REDIRECT_REGISTER(3) Référence de l'API neon NE_REDIRECT_REGISTER(3)

NOM

ne_redirect_register, ne_redirect_location - Gestion des redirections de requêtes HTTP

SYNTAXE

#include <ne_redirect.h>

void ne_redirect_register(ne_session *sess);

const ne_uri *ne_redirect_location(ne_session *sess);

DESCRIPTION

La fonction ne_redirect_register enregistre la gestion des redirections pour la session. Si une réponse de redirection valide (avec un code d'état 3xx) est traitée, la requête échouera avec le code d'erreur NE_REDIRECT. La destination de la redirection peut alors être récupérée à l'aide de ne_redirect_location.

Si une redirection a été traitée, la fonction ne_redirect_location renvoie l'URI de destination de la redirection.

VALEUR DE RETOUR

ne_redirect_location renvoie NULL si aucune requête n'a encore été traitée, si la requête actuelle n'était pas une redirection, ou si la destination de la redirection n'a pas pu être analysée ou résolue. Sinon, elle renvoie un pointeur vers un objet ne_uri, qui reste valide jusqu'à ce qu'une autre requête soit créée pour la session.
