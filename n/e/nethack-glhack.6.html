NETHACK(6) Manuel des Jeux NETHACK(6)

NOM

nethack - Explorer les Labyrinthes de la Menace

SYNTAXE

nethack [ -d répertoire ] [ -n ] [ -p profession (rôle) ] [ -r race ] [ -[DX] ] [ -u nomjoueur ] [ -dec ] [ -ibm ]

nethack [ -d répertoire ] -s [ -v ] [ -p profession (rôle) ] [ -r race ] [ nomsjoueurs ]

DESCRIPTION

NetHack est un jeu graphique orienté affichage, dans le style Dungeons & Dragons(tm). L'affichage et la structure de commandes standard en mode texte ressemblent à ceux de rogue.

D'autres options d'affichage plus graphiques existent si vous utilisez soit un PC, soit une interface X11.

Pour commencer, vous n'avez réellement besoin de connaître que deux commandes. La commande ? vous donnera une liste des commandes disponibles (ainsi que d'autres informations) et la commande / identifiera les objets que vous voyez à l'écran.

Pour gagner le jeu (par opposition à simplement jouer pour battre les meilleurs scores des autres), vous devez localiser l'Amulette de Yendor qui se trouve quelque part sous le 20ème niveau du donjon et la ramener. Personne n'y est encore parvenu ; quiconque y arrivera sera probablement gravé dans l'histoire comme un héros parmi les héros.

Lorsque le jeu se termine, que ce soit par votre mort, votre démission, ou votre évasion des grottes, NetHack vous donnera (un fragment de) la liste des meilleurs scores. Le scoring est basé sur de nombreux aspects de votre comportement, mais une estimation grossière est obtenue en prenant la quantité d'or que vous avez trouvée dans la grotte plus quatre fois votre expérience (réelle). Les pierres précieuses peuvent valoir beaucoup d'or une fois rapportées à la sortie. Il y a une pénalité de 10% pour s'être fait tuer.

La variable d'environnement NETHACKOPTIONS peut être utilisée pour initialiser de nombreuses options d'exécution. La commande ? fournit une description de ces options et de leur syntaxe. (Les options de ligne de commande -dec et -ibm sont équivalentes aux options d'exécution decgraphics et ibmgraphics décrites là, et sont fournies purement pour la commodité sur les systèmes supportant plusieurs types de terminaux.)

Étant donné que la liste des options peut être très longue (en particulier lors de la spécification des caractères graphiques), les options peuvent également être incluses dans un fichier de configuration. Le fichier par défaut est situé dans votre répertoire personnel et nommé .nethackrc sur les systèmes Unix. Sur d'autres systèmes, le nom par défaut peut être différent, généralement NetHack.cnf. Sur DOS ou Windows, le nom est defaults.nh, tandis que sur Macintosh ou BeOS, il s'agit de NetHack Defaults. L'emplacement du fichier de configuration peut être spécifié en réglant NETHACKOPTIONS à une chaîne de caractères consistant en un caractère @ suivi du nom de fichier.

L'option -u nomjoueur fournit la réponse à la question "Qui êtes-vous ?". Elle remplace tout nom provenant des options ou du fichier de configuration, USER, LOGNAME, ou getlogin(), qui seront sinon essayés dans cet ordre. Si aucun de ceux-ci ne fournit un nom utile, le joueur sera invité à en fournir un. Les noms de joueurs (en conjonction avec les uid) sont utilisés pour identifier les fichiers de sauvegarde, vous pouvez donc avoir plusieurs parties sauvegardées sous des noms différents. Inversement, vous devez utiliser le nom de joueur approprié pour restaurer une partie sauvegardée.

Un suffixe nomjoueur peut être utilisé pour spécifier la profession, la race, l'alignement et/ou le genre du personnage. La syntaxe complète du nom de joueur incluant un suffixe est "nom-ppp-rrr-aaa-ggg". "ppp" sont au moins les trois premières lettres de la profession (cela peut aussi être spécifié via une option séparée -p profession). "rrr" sont au moins les trois premières lettres de la race du personnage (cela peut aussi être spécifié via une option séparée -r race). "aaa" sont au moins les trois premières lettres de l'alignement du personnage, et "ggg" sont au moins les trois premières lettres du genre du personnage. N'importe laquelle des parties du suffixe peut être omise.

-p profession peut être utilisé pour déterminer le rôle du personnage. Vous pouvez spécifier le nom masculin ou féminin du rôle, ou les trois premiers caractères du rôle comme abréviation. -p @ a été conservé pour demander explicitement qu'un rôle aléatoire soit choisi. Il peut être nécessaire de le mettre entre guillemets avec une barre oblique inverse (\@) si @ est le caractère "tuer" (voir "stty") pour le terminal, afin d'éviter que la ligne de saisie courante ne soit effacée.

De même, -r race peut être utilisé pour demander explicitement qu'une race soit choisie.

Omettre l'une de ces caractéristiques vous amènera à être invité pendant le démarrage du jeu pour obtenir les informations.

L'option -s seule affichera la liste de vos meilleurs scores pour la version actuelle. Un -v immédiatement suivant rendra compte de toutes les versions présentes dans le fichier de scores. Le -s peut également être suivi des arguments -p et -r pour n'afficher que les scores de rôles et de races particuliers. Il peut également être suivi d'un ou plusieurs noms de joueurs pour afficher les scores des joueurs mentionnés, de 'all' pour afficher tous les scores, ou d'un nombre pour afficher ce nombre de meilleurs scores.

L'option -n supprime l'affichage de toute actualité de l'administrateur du jeu.

L'option -D ou -X lancera le jeu dans un mode de découverte spécial sans scoring. -D lancera, si le joueur est l'administrateur du jeu, en mode de débogage (sorcier) à la place.

L'option -d, qui doit être le premier argument s'il apparaît, fournit un répertoire qui servira de terrain de jeu. Elle remplace la valeur de NETHACKDIR, HACKDIR, ou du répertoire spécifié par l'administrateur du jeu lors de la compilation (habituellement /usr/games/lib/nethackdir). Cette option est généralement utile uniquement à l'administrateur du jeu. Le terrain de jeu doit contenir plusieurs fichiers auxiliaires tels que des fichiers d'aide, la liste des meilleurs scores, et un sous-répertoire save où les parties sont sauvegardées.

AUTEURS

Jay Fenlason (+ Kenny Woodland, Mike Thome et Jon Payne) a écrit hack, très similaire à rogue (mais plein de bugs).

Andries Brouwer a continuellement déformé leurs sources pour en faire un jeu entièrement différent.

Mike Stephenson a continué la perversion des sources, ajoutant diverses classes de personnages tordues et des pièges sadiques avec l'aide de nombreuses personnes étranges qui résident dans cet endroit entre les mondes, la Zone Usenet. Un certain nombre de ces mécréants sont immortalisés dans le panthéon historique de la déshonneur et dans divers autres endroits.

Le résultat est maintenant appelé NetHack, pour désigner son développement par Usenet. Andries Brouwer a fait cette demande de distinction, car il pourrait éventuellement publier une nouvelle version de son propre travail.

FICHIERS

Tous les fichiers sont dans le terrain de jeu, normalement /usr/games/lib/nethackdir. Si DLB a été défini lors de la compilation, les fichiers de données et les niveaux spéciaux seront à l'intérieur d'un fichier plus grand, normalement nhdat, au lieu d'être des fichiers séparés.
nethack Le programme lui-même.
data, oracles, rumors Fichiers de données utilisés par NetHack.
options, quest.dat Plus de fichiers de données.
help, hh Fichiers d'aide.
cmdhelp, opthelp, wizhelp Plus de fichiers d'aide.
*.lev Niveaux spéciaux prédéfinis.
dungeon Fichier de contrôle pour les niveaux spéciaux.
history Une brève histoire de NetHack.
license Règles régissant la redistribution.
record La liste des meilleurs scores.
logfile Une liste étendue des parties
jouées.
xlock.nnn Description d'un niveau de donjon.
perm Fichier de verrouillage pour xlock.dd.
bonesDD.nn Descriptions du fantôme et
des biens d'un aventurier
décédé.
save Un sous-répertoire contenant les
parties sauvegardées.

ENVIRONNEMENT

USER ou LOGNAME Votre nom de connexion.
HOME Votre répertoire personnel.
SHELL Votre shell.
TERM Le type de votre terminal.
HACKPAGER ou PAGER Remplacement du paginator par défaut.
MAIL Fichier de boîte aux lettres.
MAILREADER Remplacement du lecteur par défaut
(probablement /bin/mail ou /usr/ucb/mail).
NETHACKDIR Terrain de jeu.
NETHACKOPTIONS Chaîne pré-définissant plusieurs options
NetHack.

De plus, SHOPTYPE est utilisé en mode débogage (sorcier).
