NOM

ne_ssl_cert_identity, ne_ssl_cert_signedby, ne_ssl_cert_issuer, ne_ssl_cert_subject - fonctions pour accéder aux propriétés du certificat

SYNTAXE

#include <ne_ssl.h>

const char *ne_ssl_cert_identity(const ne_ssl_certificate *cert);

const ne_ssl_certificate *ne_ssl_cert_signedby(const ne_ssl_certificate *cert);

const ne_ssl_dname *ne_ssl_cert_subject(const ne_ssl_certificate *cert);

const ne_ssl_dname *ne_ssl_cert_issuer(const ne_ssl_certificate *cert);

DESCRIPTION

La fonction ne_ssl_cert_identity récupère l’“identité” d’un certificat ; pour un certificat de serveur SSL, il s’agira du nom d’hôte pour lequel le certificat a été émis. Dans le jargon de l’infrastructure à clés publiques (PKI), l’identité est l𠆚ttribut du nom commun du nom distinctif du sujet du certificat.

Les fonctions ne_ssl_cert_subject et ne_ssl_cert_issuer peuvent être utilisées pour accéder aux objets représentant le nom distinctif du sujet et de l’émetteur d’un certificat, respectivement.

Si un objet certificat fait partie d’une chaîne de certificats, alors ne_ssl_cert_signedby peut être utilisé pour trouver le certificat qui a signé un certificat particulier. Pour un certificat auto-signé ou un certificat pour lequel la chaîne complète n𠆞st pas disponible, cette fonction retournera NULL.

VALEUR DE RETOUR

ne_ssl_cert_issuer et ne_ssl_cert_subject sont garantis de ne jamais retourner NULL. ne_ssl_cert_identity peut retourner NULL si le certificat n𠆚 pas d’“identité” spécifique. ne_ssl_cert_signedby peut retourner NULL comme mentionné ci-dessus.

EXEMPLES

La fonction suivante pourrait être utilisée pour afficher des informations sur un certificat donné :

void dump_cert(const ne_ssl_certificate *cert) {
  const char *id = ne_ssl_cert_identity(cert);
  char *dn;
  if (id) 
    printf("Le certificat a été émis pour '%s'.\n", id);
  dn = ne_ssl_readable_dname(ne_ssl_cert_subject(cert));
  printf("Sujet : %s\n", dn);
  free(dn);
  dn = ne_ssl_readable_dname(ne_ssl_cert_issuer(cert));
  printf("Émetteur : %s\n", dn);
  free(dn);
}
