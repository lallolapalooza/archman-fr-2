NOM

nethsm-key-tag - Marquer une clé

SYNTAXE

nethsm key tag [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <ID_CLE> <TAG>

DESCRIPTION

Marquer une clé.

Les étiquettes (tags) sont utilisées pour accorder l'accès aux clés aux utilisateurs dans le rôle "Opérateur". Si un utilisateur et une clé partagent la même étiquette, l'utilisateur obtient l'accès à cette clé. Les clés existant soit au niveau du système, soit dans un espace de noms, les utilisateurs du rôle "Opérateur" doivent se trouver dans le même contexte que la clé pour que cela ait un effet !

Note : Les étiquettes sur les clés doivent être créées avant de créer des étiquettes sur les utilisateurs.

Les utilisateurs système dans le rôle "Administrateur" ne peuvent marquer que les clés système. Les utilisateurs d'espace de noms dans le rôle "Administrateur" ne peuvent marquer que les clés de leur propre espace de noms.

Nécessite l'authentification d'un utilisateur dans le rôle "Administrateur".

OPTIONS

-a, --auth-passphrase-file <FICHIER_PHRASE_SECRETTE>
Le chemin vers un fichier contenant une phrase secrète pour l'authentification

La phrase secrète fournie dans le fichier doit être celle de l'utilisateur choisi pour la commande.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui exigent plusieurs rôles à la fois. Avec plusieurs fichiers de phrases secrètes, l'ordre est important, car les fichiers sont attribués à l'utilisateur respectif fourni par l'option "--user".

Peut également être spécifiée avec la variable d'environnement NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIG>
Le chemin vers un fichier de configuration personnalisé

Si spécifié, le fichier de configuration personnalisé est utilisé à la place de l'emplacement par défaut du fichier de configuration.

Peut également être spécifiée avec la variable d'environnement NETHSM_CONFIG.
-l, --label <ETIQUETTE>
Une étiquette identifiant de manière unique un appareil dans le fichier de configuration

Doit être fournie si plus d'un appareil est configuré dans le fichier de configuration.

Peut également être spécifiée avec la variable d'environnement NETHSM_LABEL.
-u, --user <UTILISATEUR>
Un nom d'utilisateur qui est utilisé pour une commande

Peut être fourni si aucun nom d'utilisateur n'est configuré dans le fichier de configuration pour un appareil. Doit être fourni si plusieurs noms d'utilisateurs du même rôle cible sont configurés dans le fichier de configuration pour un appareil.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui exigent plusieurs rôles à la fois.

Peut également être spécifiée avec la variable d'environnement NETHSM_USER.
-h, --help
Affiche l'aide (voir un résumé avec '-h')
<ID_CLE>
L'identifiant de la clé à laquelle une étiquette est ajoutée
Peut également être spécifié avec la variable d'environnement NETHSM_KEY_ID.
<TAG>
L'étiquette à ajouter à la clé
Peut également être spécifiée avec la variable d'environnement NETHSM_KEY_TAG.
