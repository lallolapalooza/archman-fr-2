ne_response_header_iterate(3)

Paquet: neon

Licences: LGPL-2.0-or-later

NE_GET_RESPONSE_HEAD(3) Référence API neon NE_GET_RESPONSE_HEAD(3)

NOM

ne_get_response_header, ne_response_header_iterate - fonctions pour accéder aux en-têtes de réponse

SYNTAXE

#include <ne_request.h>

const char *ne_get_response_header(ne_request *request, const char *name);

void *ne_response_header_iterate(ne_request *request, void *cursor, const char **name, const char **value);

DESCRIPTION

Pour récupérer la valeur d'un champ d'en-tête de réponse, la fonction ne_get_response_header peut être utilisée, et se voit passer le nom de l'en-tête à retourner.

Pour itérer sur tous les en-têtes de réponse retournés, la fonction ne_response_header_iterate peut être utilisée. Cette fonction prend un paramètre cursor qui doit être NULL pour récupérer le premier en-tête. La fonction stocke le nom et la valeur de l'en-tête suivant dans les paramètres name et value, et retourne un nouveau pointeur curseur qui peut être passé à ne_response_header_iterate pour récupérer l'en-tête suivant.

VALEUR DE RETOUR

ne_get_response_header retourne une chaîne de caractères, ou NULL si aucun en-tête de ce nom n'a été donné. Si utilisé pendant le traitement d'une requête, le pointeur de la valeur de retour n'est valide que jusqu'au prochain appel à ne_begin_request, ou sinon, jusqu'à ce que l'objet requête soit détruit.

De même, le curseur, les noms et les valeurs retournés par ne_response_header_iterate ne sont valides que jusqu'au prochain appel à ne_begin_request ou jusqu'à ce que l'objet requête soit détruit.

EXEMPLES

Le code suivant affichera la valeur de l'en-tête Last-Modified pour une ressource :

ne_request *req = ne_request_create(sess, "GET", "/foo.txt");
if (ne_request_dispatch(req) == NE_OK) {
    const char *mtime = ne_get_response_header(req, "Last-Modified");
    if (mtime) {
        printf("/foo.txt a pour dernière modification la valeur %s\n", mtime);
    }
}
ne_request_destroy(req);

VOIR AUSSI

ne_request_create, ne_request_destroy.
