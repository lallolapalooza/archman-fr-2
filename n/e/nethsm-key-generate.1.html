nethsm-key-generate(1) Manuel des commandes générales nethsm-key-generate(1)

NOM

nethsm-key-generate - Générer une nouvelle clé

SYNTAXE

nethsm key generate [-L|--length] [-k|--key-id] [-t|--tags] [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] [TYPE_CLE] [MECANISMES_CLE]

DESCRIPTION

Générer une nouvelle clé

Le type de clé et la liste des mécanismes de clé fournis doivent correspondre : * "Rsa" requiert l'un des [RsaDecryptionRaw, RsaDecryptionPkcs1, RsaDecryptionOaepMd5, RsaDecryptionOaepSha1, RsaDecryptionOaepSha224, RsaDecryptionOaepSha256, RsaDecryptionOaepSha384, RsaDecryptionOaepSha512, RsaSignaturePkcs1, RsaSignaturePssMd5, RsaSignaturePssSha1, RsaSignaturePssSha224, RsaSignaturePssSha256, RsaSignaturePssSha384, RsaSignaturePssSha512] * "Curve25519" requiert l'un des [EdDsaSignature] * "EcP256", "EcP384" et "EcP521" requièrent l'un des [EcdsaSignature] * "Generic" requiert au moins l'un des [AesDecryptionCbc, AesEncryptionCbc]

Les utilisateurs à l'échelle du système dans le rôle "Administrateur" génèrent des clés à l'échelle du système. Les utilisateurs dans un espace de noms dans le rôle "Administrateur" génèrent des clés dans leur propre espace de noms.

Note : Bien que l'attribution d'étiquettes à la nouvelle clé soit facultative, elle est fortement recommandée car ne pas le faire signifie que tous les utilisateurs du même périmètre y ont accès !

Nécessite l'authentification d'un utilisateur dans le rôle "Administrateur".

OPTIONS

-L, --length <LONGUEUR>
La longueur optionnelle en bits de la clé générée

Si aucune n'est fournie, une valeur par défaut est choisie.

Peut également être spécifiée avec la variable d'environnement NETHSM_KEY_BIT_LENGTH.
-k, --key-id <ID_CLE>
Un identifiant unique optionnel attribué à la clé générée

Si aucun n'est fourni, un identifiant générique est généré pour la clé.

Peut également être spécifiée avec la variable d'environnement NETHSM_KEY_ID.
-t, --tags <ETIQUETTES>
Une liste optionnelle d'étiquettes attribuées à la clé générée

Les étiquettes sur les clés sont utilisées pour accorder l'accès à ces clés aux utilisateurs qui portent les mêmes étiquettes.

Peut également être spécifiée avec la variable d'environnement NETHSM_KEY_TAGS.
-a, --auth-passphrase-file <FICHIER_PHRASE_IDENTIFICATION>
Le chemin d'accès à un fichier contenant une phrase d'identification pour l'authentification

La phrase d'identification fournie dans le fichier doit être celle de l'utilisateur choisi pour la commande.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois. Avec plusieurs fichiers de phrase d'identification, l'ordre compte, car les fichiers sont attribués à l'utilisateur respectif fourni par l'option "--user".

Peut également être spécifiée avec la variable d'environnement NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIG>
Le chemin d'accès à un fichier de configuration personnalisé

Si spécifié, le fichier de configuration personnalisé est utilisé à la place de l'emplacement du fichier de configuration par défaut.

Peut également être spécifiée avec la variable d'environnement NETHSM_CONFIG.
-l, --label <ETIQUETTE>
Une étiquette identifiant de manière unique un appareil dans le fichier de configuration

Doit être fournie si plusieurs appareils sont configurés dans le fichier de configuration.

Peut également être spécifiée avec la variable d'environnement NETHSM_LABEL.
-u, --user <UTILISATEUR>
Un nom d'utilisateur utilisé pour une commande

Peut être fourni si aucun nom d'utilisateur n'est configuré dans le fichier de configuration pour un appareil. Doit être fourni si plusieurs noms d'utilisateurs du même rôle cible sont configurés dans le fichier de configuration pour un appareil.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois.

Peut également être spécifiée avec la variable d'environnement NETHSM_USER.
-h, --help
Afficher l'aide (voir un résumé avec '-h')
[TYPE_CLE]
Le type de clé optionnel à générer

Le type de clé doit correspondre aux mécanismes de clé choisis !

L'un des éléments suivants : ["Curve25519", "EcP256", "EcP384", "EcP521", "Generic", "Rsa"] (par défaut "Curve25519").

Peut également être spécifiée avec la variable d'environnement NETHSM_KEY_TYPE.
[MECANISMES_CLE]
Les mécanismes fournis par la clé générée

Les mécanismes de clé doivent correspondre au type de clé choisi !

Au moins l'un des éléments suivants : ["AesDecryptionCbc", "AesEncryptionCbc", "EcdsaSignature", "EdDsaSignature", "RsaDecryptionOaepMd5", "RsaDecryptionOaepSha1", "RsaDecryptionOaepSha224", "RsaDecryptionOaepSha256", "RsaDecryptionOaepSha384", "RsaDecryptionOaepSha512", "RsaDecryptionPkcs1", "RsaDecryptionRaw", "RsaSignaturePkcs1", "RsaSignaturePssMd5", "RsaSignaturePssSha1", "RsaSignaturePssSha224", "RsaSignaturePssSha256", "RsaSignaturePssSha384", "RsaSignaturePssSha512"] (par défaut "EdDsaSignature").

Peut également être spécifiée avec la variable d'environnement NETHSM_KEY_MECHANISMS.
