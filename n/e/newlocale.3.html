newlocale(3) Manuel des fonctions de bibliothèque newlocale(3)

NOM

newlocale, freelocale - créer, modifier et libérer un objet locale

BIBLIOTHEQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <locale.h>
locale_t newlocale(int category_mask, const char *locale,
                   locale_t base);
void freelocale(locale_t locobj);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

newlocale(), freelocale():

    Depuis glibc 2.10 :
        _XOPEN_SOURCE >= 700
    Avant glibc 2.10 :
        _GNU_SOURCE

DESCRIPTION

La fonction newlocale() crée un nouvel objet locale, ou modifie un objet existant, renvoyant une référence vers le nouvel objet ou l'objet modifié sous forme de résultat de fonction. La création d'un nouvel objet ou la modification d'un objet existant est déterminée par la valeur de base :

•
Si base est (locale_t) 0, un nouvel objet est créé.
•
Si base fait référence à un objet locale valide existant (c'est-à-dire un objet renvoyé par un appel précédent à newlocale() ou duplocale(3)), alors cet objet est modifié par l'appel. Si l'appel réussit, le contenu de base est indéfini (en particulier, l'objet auquel base fait référence peut être libéré, et un nouvel objet créé). Par conséquent, l'appelant doit s'assurer qu'il cesse d'utiliser base avant l'appel à newlocale(), et doit ensuite faire référence à l'objet modifié via la référence renvoyée en résultat de fonction. Si l'appel échoue, le contenu de base reste valide et inchangé.

Si base est l'objet locale spécial LC_GLOBAL_LOCALE (voir duplocale(3)), ou n'est pas (locale_t) 0 et n'est pas un descripteur d'objet locale valide, le comportement est indéfini.

L'argument category_mask est un masque de bits qui spécifie les catégories de locale à définir dans un nouvel objet locale ou à modifier dans un objet existant. Le masque est construit par un OU binaire des constantes LC_ADDRESS_MASK, LC_CTYPE_MASK, LC_COLLATE_MASK, LC_IDENTIFICATION_MASK, LC_MEASUREMENT_MASK, LC_MESSAGES_MASK, LC_MONETARY_MASK, LC_NUMERIC_MASK, LC_NAME_MASK, LC_PAPER_MASK, LC_TELEPHONE_MASK et LC_TIME_MASK. Alternativement, le masque peut être spécifié comme LC_ALL_MASK, ce qui équivaut à un OU binaire de toutes les constantes précédentes.

Pour chaque catégorie spécifiée dans category_mask, les données de locale de locale seront utilisées dans l'objet renvoyé par newlocale(). Si un nouvel objet locale est créé, les données de toutes les catégories non spécifiées dans category_mask sont tirées de la locale par défaut ("POSIX").

Les valeurs prédéfinies suivantes de locale sont définies pour toutes les catégories pouvant être spécifiées dans category_mask :

"POSIX"
Un environnement locale minimal pour les programmes en langage C.
"C"
Équivalent à "POSIX".
""
Un environnement natif défini par l'implémentation correspondant aux valeurs des variables d'environnement LC_* et LANG (voir locale(7)).

freelocale()

La fonction freelocale() désalloue les ressources associées à locobj, un objet locale précédemment renvoyé par un appel à newlocale() ou duplocale(3). Si locobj est LC_GLOBAL_LOCALE ou n'est pas un descripteur d'objet locale valide, les résultats sont indéfinis.

Une fois qu'un objet locale a été libéré, le programme ne doit plus l'utiliser.

VALEUR DE RETOUR

En cas de succès, newlocale() renvoie un descripteur qui peut être utilisé dans les appels à duplocale(3), freelocale(), et d'autres fonctions prenant un argument locale_t. En cas d'erreur, newlocale() renvoie (locale_t) 0, et définit errno pour indiquer l'erreur.

ERREURS

EINVAL
Un ou plusieurs bits dans category_mask ne correspondent pas à une catégorie locale valide.
EINVAL
locale est NULL.
ENOENT
locale n'est pas un pointeur de chaîne faisant référence à une locale valide.
ENOMEM
Mémoire insuffisante pour créer un objet locale.

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.3.

NOTES

Chaque objet locale créé par newlocale() doit être désalloué en utilisant freelocale().

EXEMPLES

Le programme ci-dessous prend jusqu'à deux arguments de ligne de commande, qui identifient chacun des locales. Le premier argument est requis, et est utilisé pour définir la catégorie LC_NUMERIC dans un objet locale créé à l'aide de newlocale(). Le deuxième argument de ligne de commande est facultatif ; s'il est présent, il est utilisé pour définir la catégorie LC_TIME de l'objet locale.

Après avoir créé et initialisé l'objet locale, le programme l'applique à l'aide de uselocale(3), puis teste l'effet des modifications de locale en :

(1)
Affichant un nombre à virgule flottante avec une partie fractionnaire. Cette sortie sera affectée par le réglage LC_NUMERIC. Dans de nombreuses locales européennes, la partie fractionnaire du nombre est séparée de la partie entière par une virgule, plutôt qu'un point.
(2)
Affichant la date. Le format et la langue de la sortie seront affectés par le réglage LC_TIME.

Les sessions shell suivantes montrent quelques exemples d'exécution de ce programme.

Définit la catégorie LC_NUMERIC à fr_FR (français) :


$ ./a.out fr_FR;
123456,789
Fri Mar  7 00:25:08 2014

Définit la catégorie LC_NUMERIC à fr_FR (français), et la catégorie LC_TIME à it_IT (italien) :


$ ./a.out fr_FR it_IT;
123456,789
ven 07 mar 2014 00:26:01 CET

Spécifie le réglage LC_TIME comme une chaîne vide, ce qui entraîne la prise de la valeur à partir des paramètres des variables d'environnement (qui, ici, spécifient mi_NZ, le maori de Nouvelle-Zélande) :


$ LC_ALL=mi_NZ ./a.out fr_FR ""
123456,789
Te Paraire, te 07 o Poutū-te-rangi, 2014 00:38:44 CET

Source du programme

#define _XOPEN_SOURCE 700
#include <err.h>
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
int
main(int argc, char *argv[])
{
    char buf[100];
    time_t t;
    size_t s;
    struct tm *tm;
    locale_t loc, nloc;
    if (argc < 2) {
        fprintf(stderr, "Usage: %s locale1 [locale2]\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    /* Create a new locale object, taking the LC_NUMERIC settings
       from the locale specified in argv[1].  */
    loc = newlocale(LC_NUMERIC_MASK, argv[1], (locale_t) 0);
    if (loc == (locale_t) 0)
        err(EXIT_FAILURE, "newlocale");
    /* If a second command-line argument was specified, modify the
       locale object to take the LC_TIME settings from the locale
       specified in argv[2].  We assign the result of this newlocale()
       call to 'nloc' rather than 'loc', since in some cases, we might
       want to preserve 'loc
' si cet appel échoue. */ if (argc > 2) { nloc = newlocale(LC_TIME_MASK, argv[2], loc); if (nloc == (locale_t) 0) err(EXIT_FAILURE, "newlocale"); loc = nloc; } /* Applique la locale nouvellement créée à ce thread. */ uselocale(loc); /* Teste l'effet de LC_NUMERIC. */ printf("%8.3f\n", 123456.789); /* Teste l'effet de LC_TIME. */ t = time(NULL); tm = localtime(&t); if (tm == NULL) err(EXIT_FAILURE, "time"); s = strftime(buf, sizeof(buf), "%c", tm); if (s == 0) err(EXIT_FAILURE, "strftime"); printf("%s\n", buf); /* Libère l'objet locale. */ uselocale(LC_GLOBAL_LOCALE); /* Donc 'loc' n'est plus utilisé */ freelocale(loc); exit(EXIT_SUCCESS); }
