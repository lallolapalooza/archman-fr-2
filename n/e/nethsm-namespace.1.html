NOM

nethsm-namespace - Opérer sur les espaces de noms d'un appareil

SYNTAXE

nethsm namespace [-a|--auth-passphrase-file] [-c|--config] [-l|--label] [-u|--user] [-h|--help] <sous-commandes>

DESCRIPTION

Opérer sur les espaces de noms d'un appareil

Permet d'ajouter, de lister et de supprimer des espaces de noms.

Les espaces de noms sont un moyen de séparer les utilisateurs et les clés. Les utilisateurs d'un espace de noms n'ont accès qu'aux clés de leur propre espace de noms.

OPTIONS

-a, --auth-passphrase-file <FICHIER_PHRASE_IDENTIFICATION>
Le chemin vers un fichier contenant une phrase d'identification pour l'authentification

La phrase d'identification fournie dans le fichier doit être celle de l'utilisateur choisi pour la commande.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois. Avec plusieurs fichiers de phrases d'identification, l'ordre est important, car les fichiers sont attribués à l'utilisateur respectif fourni par l'option « --user ».

Peut également être spécifiée avec la variable d'environnement NETHSM_AUTH_PASSPHRASE_FILE.
-c, --config <CONFIG>
Le chemin vers un fichier de configuration personnalisé

Si spécifié, le fichier de configuration personnalisé est utilisé à la place de l'emplacement du fichier de configuration par défaut.

Peut également être spécifiée avec la variable d'environnement NETHSM_CONFIG.
-l, --label <ETIQUETTE>
Une étiquette identifiant de manière unique un appareil dans le fichier de configuration

Doit être fournie si plus d'un appareil est configuré dans le fichier de configuration.

Peut également être spécifiée avec la variable d'environnement NETHSM_LABEL.
-u, --user <UTILISATEUR>
Un nom d'utilisateur utilisé pour une commande

Peut être fourni si aucun nom d'utilisateur n'est configuré dans le fichier de configuration pour un appareil. Doit être fourni si plusieurs noms d'utilisateur du même rôle cible sont configurés dans le fichier de configuration pour un appareil.

Cette option peut être fournie plusieurs fois, ce qui est nécessaire pour les commandes qui nécessitent plusieurs rôles à la fois.

Peut également être spécifiée avec la variable d'environnement NETHSM_USER.
-h, --help
Afficher l'aide (voir un résumé avec '-h')

SOUS-COMMANDES

nethsm-namespace-add(1)
Ajouter un espace de noms
nethsm-namespace-list(1)
Lister tous les noms d'espaces de noms
nethsm-namespace-remove(1)
Supprimer un espace de noms
