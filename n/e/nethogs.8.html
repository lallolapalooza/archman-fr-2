NETHOGS(8) Manuel de l'administrateur système NETHOGS(8)

NOM

nethogs - Outil Net top groupant la bande passante par processus

SYNTAXE

nethogs [-V] [-h] [-x] [-d secondes] [-v mode] [-c compte] [-t] [-p] [-s] [-a] [-l] [-f filtre] [-C] [-b] [-g période] [-P pid] [périphérique(s)]

DESCRIPTION

NetHogs est un petit outil de type 'net top'. Au lieu de décomposer le trafic par protocole ou par sous-réseau, comme la plupart des outils de ce type le font, il regroupe la bande passante par processus - et ne nécessite pas qu'un module noyau spécial soit chargé. Donc, s'il y a soudainement beaucoup de trafic réseau, vous pouvez lancer NetHogs et voir immédiatement quel PID en est la cause, et s'il s'agit d'un processus qui s'emballe, le tuer.

Options

-V
affiche la version.
-h
affiche l'aide sur les commandes disponibles.
-x
mode débogage - implique le mode trace.
-d
délai pour le taux de rafraîchissement en secondes. la valeur par défaut est 1.
-v
mode d'affichage (0 = Ko/s, 1 = Ko total, 2 = octets totaux, 3 = Mo total, 4 = Mo/s, 5 = Go/s). la valeur par défaut est 0.

Ko: 2e10 octets, Mo: 2e20 octets, Go: 2e30 octets

-c
nombre de mises à jour. la valeur par défaut est 0 (illimité).
-t
mode trace.
-p
écouter en mode promiscueux (non recommandé).
-s
trie la sortie par la colonne envoyée.
-l
affiche la ligne de commande.
-a
surveille tous les périphériques, y compris la boucle locale/les périphériques arrêtés.
-C
capture TCP et UDP.
-b
Affiche le nom de base du programme.
-g
période de nettoyage de la mémoire (garbage collection) en nombre de rafraîchissements. la valeur par défaut est 50.
-P
Affiche uniquement les processus avec le(s) pid spécifié(s).
-f
EXPÉRIMENTAL : spécifie un filtre pcap sous forme de chaîne (comme tcpdump). Ceci pourrait être supprimé ou modifié dans une version future.

périphérique(s) à surveiller. la valeur par défaut est toutes les interfaces actives et opérationnelles, à l'exclusion de la boucle locale.

CONTRÔLE INTERACTIF

q
quitter
s
trier par trafic ENVOYÉ
r
trier par trafic REÇU
l
afficher la ligne de commande
b
afficher le nom de base du programme
m
basculer entre le mode total (Ko, o, Mo) et le mode débit (Ko/s, Mo/s, Go/s)

EXÉCUTION SANS ROOT

Afin d'être exécuté par un utilisateur non privilégié, nethogs nécessite les capacités cap_net_admin et cap_net_raw. De plus, pour afficher les noms des processus, les capacités cap_dac_read_search et cap_sys_ptrace sont requises. Celles-ci peuvent être définies sur l'exécutable en utilisant la commande setcap(8), comme suit :


sudo setcap "cap_net_admin,cap_net_raw,cap_dac_read_search,cap_sys_ptrace+pe" /usr/local/sbin/nethogs

Notes

1. Lorsque vous utilisez l'option -P <pid>, dans le cas où un processus se termine (normalement ou brusquement), Nethogs ne suit pas sa fin. Ainsi, le système d'exploitation peut créer un nouveau processus (pour un autre programme) avec le même pid. Dans ce cas, ce nouveau processus sera affiché par Nethogs.
