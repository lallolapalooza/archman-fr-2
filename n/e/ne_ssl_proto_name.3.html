NOM

ne_ssl_proto_name - Association version de protocole SSL/TLS vers nom

SYNTAXE

#include <ne_ssl.h>

const char *ne_ssl_proto_name(enum ne_ssl_protocol proto);

DESCRIPTION

La fonction ne_ssl_proto_name retourne un nom lisible par l'homme pour une constante de version SSL/TLS. L'ensemble des versions est actuellement le suivant :

NE_SSL_PROTO_UNSPEC

version non spécifiée/inconnue

NE_SSL_PROTO_SSL3

SSL v3

NE_SSL_PROTO_TLS_1_0

TLS v1.0

NE_SSL_PROTO_TLS_1_1

TLS v1.1

NE_SSL_PROTO_TLS_1_2

TLS v1.2

NE_SSL_PROTO_TLS_1_3

TLS v1.3

VALEUR DE RETOUR

La fonction ne_ssl_proto_name retourne toujours une chaîne non NULL même si la constante de version n'est pas valide.

HISTORIQUE

ne_ssl_proto_name est disponible dans neon 0.34.0 et versions ultérieures.
