net_if.h(0P) Manuel du programmeur POSIX net_if.h(0P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

net/if.h — interfaces locales de sockets

SYNOPIS

#include <net/if.h>

DESCRIPTION

L'en-tête <net/if.h> définira la structure if_nameindex, qui contiendra au moins les membres suivants :

unsigned  if_index  Indice numérique de l'interface.
char     *if_name   Nom de l'interface terminé par NULL.

L'en-tête <net/if.h> définira la constante symbolique suivante pour la longueur d'un tampon contenant un nom d'interface (y compris le caractère NULL de fin) :

IF_NAMESIZE
Longueur du nom d'interface.

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme des macros. Des prototypes de fonction seront fournis.

void                  if_freenameindex(struct if_nameindex *);
char                 *if_indextoname(unsigned, char *);
struct if_nameindex  *if_nameindex(void);
unsigned              if_nametoindex(const char *);
