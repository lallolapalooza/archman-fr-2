NOM

nbd_get_handshake_flags - consulter les indicateurs de poignée de main supportés

SYNOPSIS

#include <libnbd.h>
uint32_t nbd_get_handshake_flags (
           struct nbd_handle *h
         );

DESCRIPTION

Retourne l'état des indicateurs de poignée de main sur cette poignée. Lorsque la poignée n'a pas encore établi de connexion (voir nbd_aio_is_created(3)), ceci retourne les indicateurs que le client est prêt à utiliser, à condition que le serveur annonce également ces indicateurs. Une fois la connexion prête (voir nbd_aio_is_ready(3)), ceci retourne les indicateurs qui ont été réellement convenus entre le serveur et le client. Si le protocole NBD définit de nouveaux indicateurs de poignée de main, alors la valeur de retour d'une version plus récente de la bibliothèque peut inclure des bits qui étaient indéfinis au moment de la compilation.

VALEUR DE RETOUR

Cet appel retourne un masque de bits des valeurs LIBNBD_HANDSHAKE_FLAG_*.

ERREURS

Cette fonction ne peut pas échouer.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.2.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_GET_HANDSHAKE_FLAGS 1

VOIR AUSSI
