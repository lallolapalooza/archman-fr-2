NOM

nbd_get_socket_activation_name - obtenir le nom d'activation de socket

SYNTAXE

#include <libnbd.h>
char * nbd_get_socket_activation_name (
         struct nbd_handle *h
       );

DESCRIPTION

Retourne le nom du socket utilisé lorsque vous appelez nbd_connect_systemd_socket_activation(3) sur le même descripteur. Par défaut, cela retourne une chaîne vide, ce qui signifie que le serveur verra le nom "unknown".

VALEUR DE RETOUR

Cet appel retourne une chaîne de caractères. L'appelant doit libérer la chaîne retournée pour éviter une fuite de mémoire.

ERREURS

En cas d'erreur, "NULL" est retourné.

Reportez-vous à "GESTION DES ERREURS" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.16.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_GET_SOCKET_ACTIVATION_NAME 1

VOIR AUSSI

nbd_connect_systemd_socket_activation(3), nbd_create(3), nbd_set_socket_activation_name(3), libnbd(3).
