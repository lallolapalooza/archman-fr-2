nbd_get_error(3)

Paquet: libnbd

nbd_create(3) LIBNBD nbd_create(3)

NOM

nbd_create, nbd_close, nbd_get_error, nbd_get_errno - créer des descripteurs libnbd et récupérer les erreurs

SYNOPSIS

#include <libnbd.h>
struct nbd_handle *nbd;
struct nbd_handle *nbd_create (void);
void nbd_close (struct nbd_handle *nbd);
const char *nbd_get_error (void);
int nbd_get_errno (void);

DESCRIPTION

struct nbd_handle est une structure opaque qui décrit un descripteur client NBD et la connexion à un serveur NBD.

Création d'un descripteur libnbd

nbd_create crée un nouveau descripteur. Il retourne un pointeur vers la structure de descripteur opaque.

En cas d'erreur, il retourne "NULL". Voir "GESTION DES ERREURS" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Fermeture d'un descripteur

nbd_close ferme le descripteur, libérant ainsi toutes les ressources associées.

Le statut final de toute commande qui n'a pas été retirée (soit par nbd_aio_command_completed(3), soit par une fonction de rappel de complétion de bas niveau retournant 1) est perdu.

Cette fonction ne doit pas être appelée pendant qu'un autre thread utilise une API "nbd_*" sur le même descripteur. Cette fonction peut bloquer si elle attend qu'un sous-processus (par exemple, un créé avec nbd_connect_command(3)) se termine.

Obtenir le dernier message d'erreur dans le thread

nbd_get_error retourne le message d'erreur le plus récent dans le thread courant. Le message d'erreur n'est valide que s'il est appelé immédiatement après l'appel échoué, depuis le même thread. La chaîne d'erreur retournée sera libérée lors du prochain appel à une API libnbd depuis le même thread, donc si vous devez la conserver, vous devez en faire une copie.

Cette fonction ne devrait jamais retourner "NULL" à condition qu'une erreur ait été retournée par l'appel libnbd immédiatement précédent dans le thread courant.

nbd_get_errno retourne le dernier "errno" dans le thread courant. Toutes les erreurs n'ont pas d'errno correspondant, donc même s'il y a eu une erreur, cela peut retourner 0. Les codes d'erreur sont les codes standards de "<errno.h>".

Voir "GESTION DES ERREURS" dans libnbd(3) pour une discussion plus approfondie sur le fonctionnement de la gestion des erreurs dans libnbd.

EXEMPLE

#include <libnbd.h>
main ()
{
  struct nbd_handle *nbd;
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    nbd_close (nbd);
    exit (EXIT_FAILURE);
  }
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

VERSION

Toutes ces fonctions étaient présentes dans libnbd 1.0.
