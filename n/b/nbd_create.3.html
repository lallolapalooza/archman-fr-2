nbd_create(3)

Paquet: libnbd

Licences: LGPL-2.1-or-later

nbd_create(3) LIBNBD nbd_create(3)

NOM

nbd_create, nbd_close, nbd_get_error, nbd_get_errno - créer des descripteurs libnbd et récupérer les erreurs

SYNTAXE

#include <libnbd.h>
struct nbd_handle *nbd;
struct nbd_handle *nbd_create (void);
void nbd_close (struct nbd_handle *nbd);
const char *nbd_get_error (void);
int nbd_get_errno (void);

DESCRIPTION

struct nbd_handle est une structure opaque qui décrit un descripteur client NBD et la connexion à un serveur NBD.

Création d'un descripteur libnbd

nbd_create crée un nouveau descripteur. Il renvoie un pointeur vers la structure opaque du descripteur.

En cas d'erreur, il renvoie "NULL". Voir "GESTION DES ERREURS" dans libnbd(3) pour savoir comment obtenir des détails supplémentaires sur l'erreur.

Fermeture d'un descripteur

nbd_close ferme le descripteur, libérant et fermant toutes les ressources associées.

Le statut final de toute commande qui n'a pas été finalisée (que ce soit par nbd_aio_command_completed(3) ou par une fonction de rappel de complétion de bas niveau renvoyant 1) est perdu.

Il n'est pas sûr d'appeler cette fonction pendant qu'un autre thread utilise encore une API "nbd_*" sur le même descripteur. Cette fonction peut bloquer si nous attendons un sous-processus (par exemple, un créé avec nbd_connect_command(3)).

Obtention du dernier message d'erreur dans le thread

nbd_get_error renvoie le message d'erreur le plus récent dans le thread actuel. Le message d'erreur n'est valide que s'il est appelé immédiatement après l'appel échoué, à partir du même thread. La chaîne d'erreur renvoyée sera libérée lors du prochain appel à une API libnbd depuis le même thread, donc si vous devez la conserver, vous devez en faire une copie.

Cette fonction ne devrait jamais renvoyer "NULL" à condition qu'une erreur ait été renvoyée par l'appel libnbd immédiatement précédent dans le thread actuel.

nbd_get_errno renvoie le dernier "errno" dans le thread actuel. Toutes les erreurs n'ont pas d'errnos correspondants, donc même s'il y a eu une erreur, cette fonction peut renvoyer 0. Les codes d'erreur sont ceux standard de "<errno.h>".

Voir "GESTION DES ERREURS" dans libnbd(3) pour une discussion plus approfondie sur le fonctionnement de la gestion des erreurs dans libnbd.

EXEMPLE

#include <libnbd.h>
main ()
{
  struct nbd_handle *nbd;
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    nbd_close (nbd);
    exit (EXIT_FAILURE);
  }
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

VERSION

Ces fonctions étaient toutes présentes dans libnbd 1.0.
