nbd_aio_connect(3) LIBNBD nbd_aio_connect(3)

NOM

nbd_aio_connect - se connecter au serveur NBD

SYNTAXE

#include <libnbd.h>
int nbd_aio_connect (
      struct nbd_handle *h, const struct sockaddr *addr,
      socklen_t addrlen
    );

DESCRIPTION

Démarre la connexion au serveur NBD. Les paramètres "addr" et "addrlen" spécifient l'adresse du socket auquel se connecter.

Vous pouvez vérifier si la tentative de connexion est toujours en cours en appelant nbd_aio_is_connecting(3). Si nbd_set_opt_mode(3) est activé, la connexion est prête pour une négociation manuelle des options une fois que nbd_aio_is_negotiating(3) renvoie vrai ; sinon, la tentative de connexion inclura la poignée de main NBD, et sera prête à être utilisée une fois que nbd_aio_is_ready(3) renverra vrai.

VALEUR DE RETOUR

En cas de succès, la fonction renvoie 0.

ERREURS

En cas d'erreur, -1 est renvoyé.

Consultez "GESTION DES ERREURS" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h", "addr". Pour plus d'informations, voir "Paramètres non NULL" dans libnbd(3).

ETAT DU HANDLE

nbd_aio_connect peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion       │ ✅ autorisé           │
│ Connexion en cours                 │ ❌ erreur              │
│ Connexion & poignée de main (opt_mode) │ ❌ erreur              │
│ Connecté au serveur              │ ❌ erreur              │
│ Connexion fermée                 │ ❌ erreur              │
│ Handle mort                        │ ❌ erreur              │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de vérifier si cette fonction est disponible au moment de la compilation, vérifiez si le macro suivant est défini :

#define LIBNBD_HAVE_NBD_AIO_CONNECT 1

VOIR AUSSI

nbd_aio_is_connecting(3), nbd_aio_is_negotiating(3), nbd_aio_is_ready(3), nbd_create(3), nbd_set_opt_mode(3), libnbd(3).
