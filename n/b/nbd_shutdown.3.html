Paquet: libnbd

nbd_shutdown(3) LIBNBD nbd_shutdown(3)

NOM

nbd_shutdown - déconnecter du serveur NBD

SYNOPIS

#include <libnbd.h>
int nbd_shutdown (
      struct nbd_handle *h, uint32_t flags
    );

DESCRIPTION

Émettre la commande de déconnexion au serveur NBD. C'est une façon polie de dire au serveur que nous partons, mais du point de vue du client, cela n'a aucun avantage par rapport à la fermeture abrupte de la connexion (voir nbd_close(3)).

Cette fonction fonctionne que le descripteur soit prêt pour la transmission des commandes ou non. Si un contrôle plus fin est nécessaire, voir nbd_aio_opt_abort(3) et nbd_aio_disconnect(3).

L'argument "flags" est un masque de bits, incluant zéro ou plusieurs des drapeaux de fermeture suivants :

"LIBNBD_SHUTDOWN_ABANDON_PENDING" = 0x10000
S'il y a des requêtes en attente qui n'ont pas encore été envoyées au serveur (voir nbd_aio_in_flight(3)), les abandonner sans les envoyer au serveur, plutôt que la pratique habituelle d'émettre ces commandes avant d'informer le serveur de l'intention de déconnecter.

Par commodité, la constante "LIBNBD_SHUTDOWN_MASK" est disponible pour décrire tous les drapeaux de fermeture reconnus par cette construction de libnbd. Une future version de la bibliothèque pourrait ajouter de nouveaux drapeaux.

VALEUR RENVOYÉE

Si l'appel réussit, la fonction renvoie 0.

ERREURS

En cas d'erreur, -1 est renvoyé.

Se référer à "ERROR HANDLING" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ÉTAT DU DESCRIPTEUR

nbd_shutdown peut être appelé lorsque le descripteur est dans les états suivants :

┌─────────────────────────────────────┬─────────────────────────┐
│ Descripteur créé, avant connexion   │ ❌ erreur                │
│ Connexion en cours                     │ ❌ erreur                │
│ Connexion et négociation (opt_mode) │ ✅ autorisé            │
│ Connecté au serveur                 │ ✅ autorisé            │
│ Connexion fermée                     │ ❌ erreur                │
│ Descripteur mort                     │ ❌ erreur                │
└───────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de tester la disponibilité de cette fonction au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_SHUTDOWN 1

EXEMPLE

Cet exemple est également disponible sous le nom examples/reads-and-writes.c dans le code source de libnbd.

/* Cet exemple montre comment effectuer des lectures
 * et des écritures synchrones aléatoirement sur le premier mégaoctet d'un
 * serveur NBD. Notez que cela détruira tout contenu existant
 * sur le serveur NBD.
 *
 * Pour le tester avec nbdkit et un disque en mémoire :
 *
 * nbdkit -U - memory 1M \
 *     --run './simple-reads-and-writes $unixsocket'
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <inttypes.h>
#include <assert.h>
#include <time.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char buf[512];
  size_t i;
  int64_t exportsize;
  uint64_t offset;
  srand (time (NULL));
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Créer le descripteur libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Se connecter au serveur NBD via un
   * socket de domaine Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Obtenir la taille du disque et vérifier
   * qu'elle est suffisante.
   */
  exportsize = nbd_get_size (nbd);
  if (exportsize == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  assert (exportsize >= sizeof buf);
  /* Vérifier que le serveur est accessible en écriture. */
  if (nbd_is_read_only (nbd) == 1) {
    fprintf (stderr, "%s: "
             "erreur: cet export NBD est en lecture seule\n",
             argv[0]);
    exit (EXIT_FAILURE);
  }
  for (i = 0; i < sizeof buf; ++i)
    buf[i] = rand ();
  /* 1000 écritures. */
  for (i = 0; i < 1000; ++i) {
    offset = rand () % (exportsize - sizeof buf);
    if (nbd_pwrite (nbd, buf, sizeof buf,
                    offset, 0) == -1) {
      fprintf (stderr, "%s\n", nbd_get_error ());
      exit (EXIT_FAILURE);
    }
  }
  /* 1000 lectures et écritures. */
  for (i = 0; i < 1000; ++i) {
    offset = rand () % (exportsize - sizeof buf);
    if (nbd_pread (nbd, buf, sizeof buf,
                   offset, 0) == -1) {
      fprintf (stderr, "%s\n", nbd_get_error ());
      exit (EXIT_FAILURE);
    }
    offset = rand () % (exportsize - sizeof buf);
    if (nbd_pwrite (nbd, buf, sizeof buf,
                    offset, 0) == -1) {
      fprintf (stderr, "%s\n", nbd_get_error ());
      exit (EXIT_FAILURE);
    }
  }
  /* Envoie une fermeture gracieuse au serveur. */
  if (nbd_shutdown (nbd, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

nbd_shutdown(3)

NOM

nbd_shutdown — Arrêter la connexion NBD.

SYNTAXIS

#include <libnbd.h>

void nbd_shutdown (NBDClient *client);

DESCRIPTION

Appelez nbd_shutdown pour fermer la connexion NBD représentée par client. Toutes les ressources associées à la connexion seront libérées.

Après avoir appelé nbd_shutdown, le descripteur de fichier associé au client sera fermé et le client ne pourra plus être utilisé pour des opérations NBD. Si la connexion NBD a été établie de manière non bloquante, ceci est la seule façon d'y mettre fin propre.

VALEUR DE RETOUR

Aucune.

ERREURS

Aucune erreur ne peut survenir en appelant cette fonction, car elle ne fait que fermer les ressources. Il n'y a aucune opération d'E/S impliquée.

ÉTAT DU MANIPULATEUR

Le manipulateur client passe dans un état "fermé" après cet appel.

VERSION

Cette fonction est disponible depuis la version 1.2 du client libnbd.

EXEMPLE

Pour l'exemple, voir nbd_connect_disk(3).

VOIR AUSSI

nbd_connect_disk(3), nbd_connect_socket(3), nbd_connect_uri(3).
