nbd_set_request_extended_headers(3) LIBNBD nbd_set_request_extended_headers(3)

NOM

nbd_set_request_extended_headers - contrôler l'utilisation des en-têtes étendus

SYNTAXE

#include <libnbd.h>
int nbd_set_request_extended_headers (
      struct nbd_handle *h, bool request
    );

DESCRIPTION

Par défaut, libnbd tente de négocier des en-têtes étendus avec le serveur, car cette extension de protocole permet l'utilisation des actions 64 bits zero, trim et block status. Cependant, pour les tests d'intégration, il peut être utile de désactiver ce drapeau plutôt que de trouver un moyen de modifier le serveur pour échouer la demande de négociation.

Par souci de compatibilité ascendante, le réglage de ce paramètre est ignoré si nbd_set_request_structured_replies(3) est également réglé sur false, car l'utilisation des en-têtes étendus implique des réponses structurées.

VALEUR DE RETOUR

Si l'appel réussit, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Se référer à "ERROR HANDLING" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Non-NULL parameters" dans libnbd(3).

ÉTAT DU HANDLE

nbd_set_request_extended_headers peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion   │ ✅ autorisé             │
│ Connexion en cours              │ ❌ erreur               │
│ Connexion et handshake (opt_mode) │ ❌ erreur               │
│ Connecté au serveur             │ ❌ erreur               │
│ Connexion fermée                │ ❌ erreur               │
│ Handle mort                       │ ❌ erreur               │
└────────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.18.

Si vous avez besoin de vérifier si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_SET_REQUEST_EXTENDED_HEADERS 1
