nbd_set_tls_psk_file(3)

Paquet: libnbd

Licences: LGPL-2.1-or-later

nbd_set_tls_psk_file(3) LIBNBD nbd_set_tls_psk_file(3)

NOM

nbd_set_tls_psk_file - définir le nom du fichier des clés pré-partagées (PSK) TLS

SYNTAXE

#include <libnbd.h>
int nbd_set_tls_psk_file (
      struct nbd_handle *h, const char *filename
    );

DESCRIPTION

Définit le nom du fichier des clés pré-partagées (PSK) TLS. Ceci est utilisé si l'on tente de s'authentifier auprès du serveur à l'aide d'une clé pré-partagée. Il n'y a pas de valeur par défaut, donc si ceci n'est pas défini, l'authentification PSK ne pourra pas être utilisée pour se connecter au serveur.

Cette fonction peut être appelée que TLS soit supporté ou non, mais n'aura aucun effet à moins que nbd_set_tls(3) ne soit également utilisé pour demander ou exiger TLS.

VALEUR DE RETOUR

Si l'appel réussit, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Se référer à "ERROR HANDLING" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h", "filename". Pour plus d'informations, voir "Non-NULL parameters" dans libnbd(3).

ETAT DU HANDLE

nbd_set_tls_psk_file peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion        │ ✅ autorisé              │
│ Connexion en cours                  │ ❌ erreur                │
│ Connexion & handshake (opt_mode)  │ ❌ erreur                │
│ Connecté au serveur                │ ❌ erreur                │
│ Connexion fermée                   │ ❌ erreur                │
│ Handle mort                        │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_SET_TLS_PSK_FILE 1

EXEMPLE

Cet exemple est également disponible sous le nom examples/encryption.c dans le code source de libnbd.

/* Un exemple montrant comment se connecter à un serveur qui utilise
 * le chiffrement TLS.
 *
 * Ceci nécessite nbdkit, et psktool de gnutls.
 *
 * Libnbd et nbdkit prennent tous deux en charge TLS-PSK, qui est une
 * forme de chiffrement plus facile à déployer. (Bien sûr, le
 * chiffrement basé sur les certificats est également pris en charge,
 * mais il est plus difficile de créer un exemple autonome).
 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <libnbd.h>
#define TMPDIR "/tmp/XXXXXX"
#define KEYS "keys.psk"
#define USERNAME "alice"
static char dir[] = TMPDIR;
static char keys[] = TMPDIR "/" KEYS;
static char cmd[] =
  "psktool -u " USERNAME " -p " TMPDIR "/" KEYS;
/* Supprime le fichier de clés temporaire lorsque le programme
 * se termine.
 */
static void
cleanup_keys (void)
{
  unlink (keys);
  rmdir (dir);
}
/* Crée le fichier de clés temporaire à partager avec le
 * serveur.
 */
static void
create_keys (void)
{
  size_t i;
  if (mkdtemp (dir) == NULL) {
    perror ("mkdtemp");
    exit (EXIT_FAILURE);
  }
  i = strlen (cmd) - strlen (TMPDIR) - strlen (KEYS) - 1;
  memcpy (&cmd[i], dir, strlen (TMPDIR));
  memcpy (keys, dir, strlen (TMPDIR));
  if (system (cmd) != 0) {
    fprintf (stderr, "la commande psktool a échoué\n");
    exit (EXIT_FAILURE);
  }
  atexit (cleanup_keys);
}
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char buf[512];
  create_keys ();
  /* Crée le handle libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Active TLS dans le client. */
  if (nbd_set_tls (nbd, LIBNBD_TLS_REQUIRE) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Active TLS-PSK et passe le nom du fichier de clés. */
  if (nbd_set_tls_psk_file (nbd, keys) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Définit le nom d'utilisateur local pour l'authentification. */
  if (nbd_set_tls_username (nbd, USERNAME) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Exécute nbdkit en tant que sous-processus, activant et exigeant
   * le chiffrement TLS-PSK.
   */
  char *args[] = {
    "nbdkit", "-s", "--exit-with-parent",
    "--tls", "require", "--tls-psk", keys,
    "pattern", "size=1M", NULL
  };
  if (nbd_connect_command (nbd, args) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Lit le premier secteur. */
  if (nbd_pread (nbd, buf, sizeof buf, 0, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Les connexions TLS doivent être fermées. */
  if (nbd_shutdown (nbd, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Ferme le handle libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

VOIR AUSSI

nbd_create(3), nbd_set_tls(3), libnbd(3).
