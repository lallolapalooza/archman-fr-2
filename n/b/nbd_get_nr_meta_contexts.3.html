NOM

nbd_get_nr_meta_contexts - renvoie le nombre actuel de contextes méta demandés

SYNTAXE

#include <libnbd.h>
ssize_t nbd_get_nr_meta_contexts (
          struct nbd_handle *h
        );

DESCRIPTION

Lors de la connexion, libnbd peut négocier zéro ou plusieurs contextes méta avec le serveur. Les contextes méta sont des fonctionnalités (telles que "base:allocation") qui décrivent les informations renvoyées par la commande nbd_block_status_64(3) (pour "base:allocation", il s'agit de savoir si les blocs de données sont alloués, nuls ou épars).

Cette commande renvoie le nombre de contextes méta qui ont été ajoutés à la liste à demander au serveur via nbd_add_meta_context(3). Le serveur n'est pas obligé de répondre favorablement à toutes les demandes ; pour voir ce qu'il prend réellement en charge, consultez nbd_can_meta_context(3).

VALEUR DE RETOUR

Cet appel renvoie un entier de taille ≥ 0.

ERREURS

En cas d'erreur, -1 est renvoyé.

Reportez-vous à "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, consultez "Paramètres non NULL" dans libnbd(3).

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.6.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_GET_NR_META_CONTEXTS 1
