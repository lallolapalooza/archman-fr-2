Paquet: libnbd

nbd_pwrite(3) LIBNBD nbd_pwrite(3)

NOM

nbd_pwrite - écrire sur le serveur NBD

SYNOPSIS

#include <libnbd.h>
int nbd_pwrite (
      struct nbd_handle *h, const void *buf, size_t count,
      uint64_t offset, uint32_t flags
    );

DESCRIPTION

Émet une commande d'écriture vers le serveur NBD, écrivant les données dans "buf" dans la plage commençant à "offset" et se terminant à "offset" + "count" - 1. NBD ne peut écrire que tout ou rien en utilisant cet appel. L'appel retourne lorsque la commande a été accusée de réception par le serveur, ou en cas d'erreur. Notez que cela retournera généralement une erreur si nbd_is_read_only(3) est vrai.

Notez que libnbd limite par défaut la taille maximale du tampon d'écriture au moindre de 64 MiB ou de toute taille de charge utile maximale annoncée par le serveur ; les tentatives de dépassement entraîneront généralement une erreur "ERANGE" du côté client, plutôt qu'une déconnexion du côté serveur. La limite réelle peut être obtenue avec nbd_get_block_size(3).

Le paramètre "flags" peut être 0 pour aucun drapeau, ou peut contenir "LIBNBD_CMD_FLAG_FUA", signifiant que le serveur ne doit pas retourner tant que les données n'ont pas été validées dans le stockage permanent (si cela est pris en charge - certains serveurs ne peuvent pas le faire, voir nbd_can_fua(3)). Pour plus de commodité, sauf si nbd_set_strict_flags(3) a été utilisé pour désactiver "LIBNBD_STRICT_AUTO_FLAG", libnbd ignore la présence ou l'absence du drapeau "LIBNBD_CMD_FLAG_PAYLOAD_LEN" dans "flags", tout en utilisant correctement le drapeau sur le réseau selon que des en-têtes étendus ont été négociés.

Par défaut, libnbd rejettera les tentatives d'utilisation de cette fonction avec des paramètres susceptibles de provoquer une défaillance du serveur, comme la demande d'un drapeau de commande inconnu. La fonction nbd_set_strict_mode(3) peut être utilisée pour modifier les scénarios qui doivent attendre une réponse du serveur au lieu d'échouer rapidement.

VALEUR DE RETOUR

Si l'appel réussit, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Reportez-vous à « GESTION DES ERREURS » dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h", "buf". Pour plus d'informations, voir « Paramètres non-NULL » dans libnbd(3).

ÉTAT DU HANDLE

nbd_pwrite peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion        │ ❌ erreur                │
│ Connexion en cours                    │ ❌ erreur                │
│ Connexion et handshake (opt_mode) │ ❌ erreur                │
│ Connecté au serveur               │ ✅ autorisé            │
│ Connexion fermée                  │ ❌ erreur                │
│ Handle mort                         │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous devez tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_PWRITE 1

EXEMPLE

Cet exemple est également disponible sous forme de examples/reads-and-writes.c dans le code source de libnbd.

/* Cet exemple montre comment effectuer des lectures
 * et écritures synchrones aléatoires sur le premier mégaoctet d'un
 * serveur NBD. Notez que cela détruira tout contenu existant
 * sur le serveur NBD.
 *
 * Pour le tester avec nbdkit et un disque RAM :
 *
 * nbdkit -U - memory 1M \
 *     --run './simple-reads-and-writes $unixsocket'
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <inttypes.h>
#include <assert.h>
#include <time.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char buf[512];
  size_t i;
  int64_t exportsize;
  uint64_t offset;
  srand (time (NULL));
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Crée le handle libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Se connecte au serveur NBD via un
   * socket de domaine Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Obtient la taille du disque et vérifie
   * qu'elle est suffisamment grande.
   */
  exportsize = nbd_get_size (nbd);
  if (exportsize == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  assert (exportsize >= sizeof buf);
  /* Vérifie que le serveur est accessible en écriture. */
  if (nbd_is_read_only (nbd) == 1) {
    fprintf (stderr, "%s: "
             "erreur : cet export NBD est en lecture seule\n",
             argv[0]);
    exit (EXIT_FAILURE);
  }
  for (i = 0; i < sizeof buf; ++i)
    buf[i] = rand ();
  /* 1000 écritures. */
  for (i = 0; i < 1000; ++i) {
    offset = rand () % (exportsize - sizeof buf);
    if (nbd_pwrite (nbd, buf, sizeof buf,
                    offset, 0) == -1) {
      fprintf (stderr, "%s\n", nbd_get_error ());
      exit (EXIT_FAILURE);
    }
  }
  /* 1000 lectures et écritures. */
  for (i = 0; i < 1000; ++i) {
    offset = rand () % (exportsize - sizeof buf);
    if (nbd_pread (nbd, buf, sizeof buf,
                   offset, 0) == -1) {
      fprintf (stderr, "%s\n", nbd_get_error ());
      exit (EXIT_FAILURE);
    }
    offset = rand () % (exportsize - sizeof buf);
    if (nbd_pwrite (nbd, buf, sizeof buf,
                    offset, 0) == -1) {
      fprintf (stderr, "%s\n", nbd_get_error ());
      exit (EXIT_FAILURE);
    }
  }
  /* Envoie un arrêt gracieux au serveur. */
  if (nbd_shutdown (nbd, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

nbd_pwrite(3)

NAME

nbd_pwrite - Écrit des données dans un périphérique NBD à une position spécifiée.

SYNOPSIS

#include <libnbd.h>
int nbd_pwrite(NBD_CONTEXT *ctx, uint64_t offset,
                const void *buf, size_t count, uint64_t *bytes_written,
                int flags, Error **err);

DESCRIPTION

La fonction nbd_pwrite écrit jusqu'à count octets de données à partir du tampon buf à l'offset spécifié dans le périphérique NBD connecté à ctx.

Si l'opération réussit, le nombre d'octets réellement écrits est retourné dans bytes_written, et la fonction retourne 0. Sinon, la fonction retourne une valeur négative et un message d'erreur est stocké dans err.

Les flags peuvent être utilisés pour modifier le comportement de l'opération d'écriture. Actuellement, aucun drapeau n'est défini.

Cette fonction est asynchrone. Elle démarre l'opération d'écriture et retourne immédiatement. L'appelant doit ensuite attendre la fin de l'opération en appelant nbd_poll_events ou nbd_wait_event.

RETURN VALUE

La fonction retourne 0 en cas de succès, ou une valeur négative en cas d'échec.

ERRORS

Les erreurs possibles incluent, sans s'y limiter :

  • Erreur de connexion au serveur NBD.
  • Erreur de négociation du protocole NBD.
  • Erreur lors de l'opération d'écriture sur le serveur.
  • Erreur de mémoire.

HANDLE STATE

Après un appel réussi à nbd_pwrite, l'état du handle NBD reste le même. Aucune nouvelle opération ne peut être lancée tant que l'opération précédente n'est pas terminée.

VERSION

Cette fonction a été introduite dans la version 1.1.0 de libnbd.

EXAMPLE

#include <stdio.h>
#include <stdlib.h>
#include <libnbd.h>

int main() {
    NBD_CONTEXT *ctx;
    char data[] = "Hello, world!";
    uint64_t bytes_written;
    int ret;

    // Initialiser le contexte NBD
    ctx = nbd_context_new();
    if (!ctx) {
        fprintf(stderr, "Erreur lors de la création du contexte NBD\n");
        return 1;
    }

    // Connecter au périphérique NBD (remplacez par votre URI)
    ret = nbd_connect_uri(ctx, "nbd:unix:/tmp/mydisk.sock", NULL, NULL);
    if (ret < 0) {
        fprintf(stderr, "Erreur de connexion: %s\n", nbd_strerror(ret));
        nbd_context_destroy(ctx);
        return 1;
    }

    // Écrire des données au décalage 0
    ret = nbd_pwrite(ctx, 0, data, sizeof(data), &bytes_written, 0, NULL);
    if (ret < 0) {
        fprintf(stderr, "Erreur d'écriture: %s\n", nbd_strerror(ret));
        nbd_context_destroy(ctx);
        return 1;
    }

    printf("Écrit %llu octets avec succès.\n", (unsigned long long)bytes_written);

    // Nettoyer
    nbd_shutdown(ctx, NULL);
    nbd_context_destroy(ctx);

    return 0;
}
