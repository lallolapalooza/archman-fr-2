NOM

nbd_set_uri_allow_tls - définir les paramètres TLS autorisés dans les URI NBD

SYNTAXE

#include <libnbd.h>
int nbd_set_uri_allow_tls (
      struct nbd_handle *h, int tls
    );

DESCRIPTION

Définit les paramètres TLS autorisés à apparaître dans les URI NBD. Par défaut, les URI sans TLS ou avec TLS sont autorisés.

Le paramètre "tls" peut être :

"LIBNBD_TLS_DISABLE"
Les URI TLS ne sont pas autorisés, c'est-à-dire qu'une URI telle que "nbds://..." sera rejetée.
"LIBNBD_TLS_ALLOW"
C'est la valeur par défaut. Le TLS peut être utilisé ou non, selon que l'URI utilise "nbds" ou "nbd".
"LIBNBD_TLS_REQUIRE"
Les URI TLS sont obligatoires. Toutes les URI doivent utiliser "nbds".

VALEUR DE RETOUR

En cas de succès, la fonction retourne 0.

ERREURS

En cas d'erreur, la valeur -1 est retournée.

Consultez "ERROR HANDLING" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, consultez "Non-NULL parameters" dans libnbd(3).

ÉTAT DU HANDLE

nbd_set_uri_allow_tls peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion       │ ✅ autorisé             │
│ Connexion en cours                │ ❌ erreur               │
│ Connexion & handshake (opt_mode)│ ❌ erreur               │
│ Connecté au serveur               │ ❌ erreur               │
│ Connexion fermée                  │ ❌ erreur               │
│ Handle mort                       │ ❌ erreur               │
└────────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.2.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_SET_URI_ALLOW_TLS 1

VOIR AUSSI

nbd_connect_uri(3), nbd_create(3), nbd_set_uri_allow_transports(3), libnbd(3).
