NOM

nbd_clear_debug_callback - effacer la fonction de rappel de débogage

SYNOPIS

#include <libnbd.h>
int nbd_clear_debug_callback (
      struct nbd_handle *h
    );

DESCRIPTION

Supprime la fonction de rappel de débogage si une a été précédemment associée au descripteur (avec nbd_set_debug_callback(3)). Si aucune fonction de rappel n'était associée, cette fonction ne fait rien.

VALEUR DE RETOUR

Si l'appel réussit, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Voir "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous devez tester si cette fonction est disponible au moment de la compilation, vérifiez si le macro suivant est défini :

#define LIBNBD_HAVE_NBD_CLEAR_DEBUG_CALLBACK 1

VOIR AUSSI

nbd_create(3), nbd_set_debug_callback(3), libnbd(3).
