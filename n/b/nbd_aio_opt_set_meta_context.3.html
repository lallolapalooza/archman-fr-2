NOM

nbd_aio_opt_set_meta_context - sélectionner des contextes méta spécifiques, avec liste de requêtes implicite

SYNOPSIS

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, const char *name);
  void *user_data;
  void (*free) (void *user_data);
} nbd_context_callback;
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int nbd_aio_opt_set_meta_context (
      struct nbd_handle *h,
      nbd_context_callback context_callback,
      nbd_completion_callback completion_callback
    );

DESCRIPTION

Demande au serveur de fournir tous les contextes méta reconnus, enregistrés via des appels antérieurs à nbd_add_meta_context(3), en conjonction avec l'export précédemment spécifié par le dernier appel à nbd_set_export_name(3) ou nbd_connect_uri(3). Ceci ne peut être utilisé que si nbd_set_opt_mode(3) a activé le mode d'option. Normalement, cette fonction est redondante, car nbd_opt_go(3) effectue automatiquement la même tâche si des réponses structurées ou des en-têtes étendus ont déjà été négociés. Cependant, le contrôle manuel des requêtes de contexte méta peut être utile pour des tests granulaires sur la façon dont un serveur gère des séquences de négociation inhabituelles. Souvent, l'utilisation de cette fonction est couplée avec nbd_set_request_meta_context(3) pour contourner la requête de contexte automatique normalement effectuée par nbd_opt_go(3).

Pour déterminer quand la requête est terminée, attendez que nbd_aio_is_connecting(3) retourne false. Ou fournissez le "completion_callback" optionnel qui sera appelé comme décrit dans "Callbacks d'achèvement" dans libnbd(3), sauf qu'il est automatiquement retiré quelle que soit la valeur de retour. Notez que la détection si le serveur renvoie une erreur (comme c'est le cas avec la valeur de retour de l'homologue synchrone) n'est possible qu'avec un callback d'achèvement.

VALEUR RENVOYÉE

Cet appel renvoie un entier ≥ 0.

ERREURS

En cas d'erreur, -1 est renvoyé.

Reportez-vous à "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non NULL" dans libnbd(3).

ÉTAT DU HANDLE

nbd_aio_opt_set_meta_context peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion     │ ❌ erreur                │
│ Connexion en cours                 │ ❌ erreur                │
│ Connexion & handshake (opt_mode) │ ✅ autorisé             │
│ Connecté au serveur              │ ❌ erreur                │
│ Connexion fermée                 │ ❌ erreur                │
│ Handle mort                      │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.16.

Si vous avez besoin de vérifier si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_AIO_OPT_SET_META_CONTEXT 1
