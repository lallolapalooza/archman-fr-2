nbd_set_request_meta_context(3) LIBNBD nbd_set_request_meta_context(3)

NOM

nbd_set_request_meta_context - contrôler si la connexion demande automatiquement les contextes méta

SYNOPSIS

#include <libnbd.h>
int nbd_set_request_meta_context (
      struct nbd_handle *h, bool request
    );

DESCRIPTION

Cette fonction contrôle si l'acte de connexion à une exportation (tous les appels "nbd_connect_*" lorsque nbd_set_opt_mode(3) est faux, ou nbd_opt_go(3) et nbd_opt_info(3) lorsque le mode option est activé) essaiera également d'émettre NBD_OPT_SET_META_CONTEXT lorsque le serveur prend en charge les réponses structurées ou les en-têtes étendus et que des contextes ont été enregistrés par nbd_add_meta_context(3). Le réglage par défaut est vrai ; cependant, l'étape supplémentaire de négociation des contextes méta n'est pas toujours souhaitable : effectuer à la fois info et go sur la même exportation fonctionne sans avoir besoin de renégocier les contextes lors du second appel ; les tests d'intégration d'autres serveurs peuvent bénéficier d'une invocation manuelle de nbd_opt_set_meta_context(3) à d'autres moments de la séquence de négociation ; et même en utilisant uniquement nbd_opt_info(3), il peut être plus rapide de collecter les résultats du serveur en s'appuyant sur la fonction de rappel passée à nbd_opt_list_meta_context(3) que sur une série d'appels post-traitement à nbd_can_meta_context(3).

Notez que ce contrôle n'a aucun effet si le serveur ne négocie pas de réponses structurées ou d'en-têtes étendus, ou si le client n'a demandé aucun contexte via nbd_add_meta_context(3). Définir ce contrôle à faux peut entraîner l'échec de nbd_block_status(3).

VALEUR RENVOYÉE

Si l'appel réussit, la fonction renvoie 0.

ERREURS

En cas d'erreur, -1 est renvoyé.

Se référer à "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non NULL" dans libnbd(3).

ÉTAT DU HANDLE

nbd_set_request_meta_context peut être appelé lorsque le handle est dans les états suivants :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion      │ ✅ autorisé             │
│ Connexion en cours                  │ ❌ erreur               │
│ Connexion & handshake (opt_mode) │ ✅ autorisé             │
│ Connecté au serveur               │ ❌ erreur               │
│ Connexion interrompue             │ ❌ erreur               │
│ Handle mort                       │ ❌ erreur               │
└───────────────────────────────────────┴────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.16.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_SET_REQUEST_META_CONTEXT 1
