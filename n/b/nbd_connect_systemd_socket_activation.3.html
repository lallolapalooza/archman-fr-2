nbd_connect_systemd_socket_activation(3)

Paquet: libnbd

Licences: LGPL-2.1-or-later

nbd_connect_systemd_socket_activation(3) LIBNBD nbd_connect_systemd_socket_activation(3)

NOM

nbd_connect_systemd_socket_activation - se connecter en utilisant l'activation de socket systemd

SYNOPSIS

#include <libnbd.h>
int nbd_connect_systemd_socket_activation (
      struct nbd_handle *h, char **argv
    );

DESCRIPTION

Exécute la commande comme sous-processus et s'y connecte en utilisant l'activation de socket systemd.

Ceci est particulièrement utile pour exécuter qemu-nbd(1) comme sous-processus de libnbd, par exemple pour l'utiliser afin d'ouvrir des fichiers qcow2.

Pour exécuter nbdkit comme sous-processus, cette fonction peut être utilisée, ou nbd_connect_command(3).

Pour exécuter nbd-server(1) comme sous-processus, cette fonction ne peut pas être utilisée, vous devez utiliser nbd_connect_command(3).

Activation de socket

Libnbd va forker la commande "argv" et lui passer un socket NBD en utilisant des variables d'environnement spéciales "LISTEN_*" (telles que définies par le protocole d'activation de socket systemd).

┌─────────┬─────────┐    ┌───────────────┐
│ programme │ libnbd  │    │  qemu-nbd ou  │
│         │         │    │  autre serveur │
│         │ socket ╍╍╍╍╍╍╍╍▶             │
└─────────┴─────────┘    └───────────────┘

Lorsque le handle NBD est fermé, le sous-processus serveur est tué.

Nom du socket

Le protocole d'activation de socket vous permet de donner éventuellement un nom au socket. S'il est utilisé, le nom est passé au serveur NBD via la variable d'environnement "LISTEN_FDNAMES". Pour fournir un nom de socket, appelez nbd_set_socket_activation_name(3) avant d'appeler la fonction de connexion.

Cet appel retourne lorsque la connexion a été établie. Par défaut, cela procède jusqu'à la phase de transmission, mais nbd_set_opt_mode(3) peut être utilisé pour un contrôle manuel de la négociation des options effectuée avant la phase de transmission.

VALEUR DE RETOUR

En cas de succès, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Consultez "GESTION DES ERREURS" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h", "argv". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ÉTAT DU HANDLE

nbd_connect_systemd_socket_activation peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant la connexion   │ ✅ autorisé             │
│ Connexion en cours                  │ ❌ erreur                │
│ Connexion & handshake (opt_mode) │ ❌ erreur                │
│ Connecté au serveur               │ ❌ erreur                │
│ Connexion interrompue              │ ❌ erreur                │
│ Handle mort                       │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.2.

Si vous devez vérifier si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_CONNECT_SYSTEMD_SOCKET_ACTIVATION 1

EXEMPLE

Cet exemple est également disponible sous le nom examples/open-qcow2.c dans le code source de libnbd.

/* Cet exemple montre comment utiliser qemu-nbd
 * pour ouvrir un fichier qcow2 local.
 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <libnbd.h>
int
main (int argc, const char *argv[])
{
  const char *filename;
  struct nbd_handle *nbd;
  char buf[512];
  FILE *fp;
  if (argc != 2) {
    fprintf (stderr, "open-qcow2 fichier.qcow2\n");
    exit (EXIT_FAILURE);
  }
  filename = argv[1];
  /* Créer le handle libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Exécuter qemu-nbd en tant que sous-processus en utilisant
   * l'activation de socket systemd.
   */
  char *args[] = {
    "qemu-nbd", "-f", "qcow2",
    (char *)filename,
    NULL
  };
  if (nbd_connect_systemd_socket_activation (nbd,
                                             args) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Lire le premier secteur et l'afficher. */
  if (nbd_pread (nbd, buf, sizeof buf, 0, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  fp = popen ("hexdump -C", "w");
  if (fp == NULL) {
    perror ("popen: hexdump");
    exit (EXIT_FAILURE);
  }
  fwrite (buf, sizeof buf, 1, fp);
  pclose (fp);
  /* Fermer le handle libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}
