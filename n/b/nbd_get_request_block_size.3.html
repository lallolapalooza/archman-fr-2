NAME

nbd_get_request_block_size - voir si NBD_OPT_GO demande la taille du bloc

SYNOPSIS

#include <libnbd.h>
int nbd_get_request_block_size (
      struct nbd_handle *h
    );

DESCRIPTION

Retourne l'état du drapeau de demande de taille de bloc sur cette poignée.

VALEUR DE RETOUR

Cet appel retourne une valeur booléenne.

ERREURS

En cas d'erreur, -1 est retourné.

Reportez-vous à « ERREUR HANDLING » dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir « Paramètres non-NULL » dans libnbd(3).

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.12.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_GET_REQUEST_BLOCK_SIZE 1

VOIR AUSSI

nbd_create(3), nbd_set_request_block_size(3), libnbd(3).
