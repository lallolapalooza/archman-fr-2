NOM

bibutils - utilitaires de conversion bibliographique

SYNTAXE

format2xml [OPTIONS] [fichier.format]

xml2format [OPTIONS] [fichier.xml]

DESCRIPTION

La suite de programmes bibutils permet la conversion entre divers formats bibliographiques en utilisant le schéma Metadata Object Description Schema (MODS)[2] version 3.1 de la Library of Congress[1]. Par exemple, il est possible de convertir des fichiers au format RIS en Bibtex en effectuant deux transformations : RIS->MODS->Bibtex.

CONVERTIR VERS MODS

Aperçu

Commande Description
bib2xml convertir bibtex en MODS
biblatex2xml convertir biblatex en MODS
copac2xml convertir des références au format COPAC[3] en MODS
ebi2xml convertir EBI XML en MODS
end2xml convertir EndNote (format Refer) en MODS
endx2xml convertir EndNote XML en MODS
isi2xml convertir ISI web of science en MODS
med2xml convertir des références PubMed XML en MODS
nbib2xml convertir des références au format nbib PubMed en MODS
modsclean un convertisseur MODS vers MODS
ris2xml convertir le format RIS en MODS
wordbib2xml convertir la bibliographie XML de Word2007 en MODS

Options communes pour la conversion vers MODS

Plusieurs drapeaux sont disponibles pour les programmes end2xml, endx2xml, bib2xml, ris2xml, med2xml, et copac2xml. La plupart des options ont une version courte et une version longue.

-h --help afficher l'aide
-v --version afficher la version
-a --add-refcount ajouter "_#" où # est le nombre de références à l'identifiant de la référence
-s --single-refperfile mettre une seule référence par fichier, nommé d'après le numéro de la référence
-i --input-encoding interpréter le fichier d'entrée comme utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères sur www.kostis.net[4]) unicode est maintenant une option de jeu de caractères
-u --unicode-characters encoder les caractères unicode directement dans le fichier plutôt que comme des entités XML
-un --unicode-no-bom comme -u, mais sans inclure de marque d'ordre des octets
-x --xml-entities encoder les caractères unicode comme des entités XML (l'opposé de -u)
-nl --no-latex ne pas convertir les combinaisons de caractères de style latex
-s --single-refperfile une référence par fichier de sortie
-d --drop-key ne pas mettre la clé de citation dans le champ id mods
-c --corporation-file avec un argument spécifiant un fichier contenant une liste de noms d'entreprises à placer dans <name type="corporate"></name> au lieu de type="personal" et éliminer la manipulation des noms
-a --asis avec un argument spécifiant un fichier contenant une liste de noms à traiter tels quels
-nt --nosplit-title ne pas diviser les titres en paires TITRE/SOUS-TITRE
--verbose sortie verbeuse
--debug sortie très verbeuse (principalement pour le débogage)

bib2xml

bib2xml convertit un fichier de références au format bibtex en un fichier bibliographique intermédiaire XML. Spécifiez les fichiers à convertir sur la ligne de commande. Les fichiers contenant des chaînes de substitution bibtex doivent être spécifiés avant les fichiers où les substitutions sont spécifiées (ou dans le même fichier avant leur utilisation). Si aucun fichier n'est spécifié, les informations bibtex seront lues depuis l'entrée standard.

bib2xml fichier.bib > fichier_sortie.xml

biblatex2xml

biblatex2xml convertit un fichier de références au format biblatex (à ne pas confondre avec bibtex) en un fichier bibliographique intermédiaire XML MODS.

biblatex2xml fichier.bib > fichier_sortie.xml

copac2xml

copac2xml convertit un fichier de références au format COPAC en un fichier bibliographique intermédiaire XML MODS.

end2xml

end2xml convertit un fichier de références au format texte EndNote en un fichier bibliographique intermédiaire XML. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté. Les formats étiquetés EndNote (export au format "Refer") ressemblent à l'Exemple 1, « Fichier au format refer d'exemple ». Il existe de très bonnes instructions pour s'assurer que vous exportez correctement ceci à l'adresse http://www.sonnysoftware.com/endnoteimport.html[5]

L'utilisation de end2xml est la même que celle de bib2xml.

end2xml fichier.end > fichier_sortie.xml

ebi2xml

ebi2xml convertit un fichier XML EBI en un fichier bibliographique intermédiaire XML MODS.

endx2xml

endx2xml convertit un fichier de références exporté au format EndNote-XML en un fichier bibliographique intermédiaire XML MODS. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté.

isi2xml

isi2xml convertit un fichier de références au format ISI-web-of-science en un fichier bibliographique intermédiaire XML.

L'utilisation de isi2xml est la même que celle de bib2xml.

isi2xml fichier_entree.isi > fichier_sortie.xml

ris2xml

ris2xml convertit un fichier de références au format RIS en un fichier bibliographique intermédiaire XML. L'utilisation de ris2xml est comme celle de end2xml et bib2xml.

ris2xml fichier.ris >	fichier_sortie.xml

wordbib2xml

wordbib2xml convertit un fichier de références au format Word2007 en un fichier bibliographique intermédiaire XML.

Options communes pour la conversion depuis MODS

La plupart des programmes ci-dessous ont des options similaires.

-h --help afficher l'aide
-v --version afficher la version
-i --input-encoding interpréter le fichier d'entrée comme utilisant le jeu de caractères demandé
-u --unicode-characters encoder les caractères unicode directement dans le fichier plutôt que comme des entités XML
-x --xml-entities encoder les caractères unicode comme des entités XML (par défaut)
-nl --no-latex ne pas convertir les caractères spéciaux latex en leurs équivalents unicode
-o --output-encoding utiliser le jeu de caractères spécifié pour la sortie
-p --padding remplir les années avec un nombre spécifié de zéros (par défaut 4)
-f --force-encoding utiliser le jeu de caractères spécifié pour la sortie même si un autre jeu de caractères est détecté
-n --no-convert ne pas convertir l'entrée ; la considérer comme étant au format bibtex
--verbose sortie verbeuse
--debug sortie très verbeuse (principalement pour le débogage)

xml2bib

Convertit un fichier XML MODS en un fichier Bibtex.

xml2bib input.xml > output.bib

xml2biblatex

Convertit un fichier XML MODS en un fichier Biblatex.

xml2biblatex input.xml > output.bib

xml2end

Convertit un fichier XML MODS en un fichier pour EndNote.

xml2end input.xml > output.end

xml2ris

Convertit un fichier XML MODS en un fichier RIS.

xml2ris input.xml > output.ris

xml2wordbib

Convertit un fichier XML MODS au format de bibliographie Word 2007.

xml2wordbib input.xml > output.xml

Options communes de conversion depuis MODS

Notez que --output-encoding fait référence au fichier d'entrée.

-h --help afficher l'aide
-v --version afficher la version
-o --output-encoding interpréter le fichier d'entrée comme utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères sur www.kostis.net[4]) unicode est maintenant une option de jeu de caractères
-s --single-refperfile mettre une référence par nom de fichier selon le numéro de référence
-nb --no-bom ne pas écrire de Byte Order Mark si l'on écrit en UTF8

xml2bib

xml2bib convertit la bibliographie XML MODS en un fichier de référence au format bibtex. L'utilisation de xml2bib est la même que pour les autres outils.

xml2bib xml_file.xml > output_file.bib

Étant donné que le format de référence BibTeX est assez flexible et semble avoir le plus grand nombre de préférences personnelles, il a également accumulé un certain nombre d'options spécifiques qui ne sont pas disponibles pour d'autres formats.

À partir de la version 3.24, la sortie de xml2bib utilise des balises en minuscules et des types de référence en casse mixte pour une meilleure interaction avec d'autres logiciels. Le comportement précédent avec toutes les balises/types de référence en majuscules peut toujours être généré en utilisant l'option de ligne de commande -U/--uppercase.

Options spécifiques à xml2bib :

-fc --finalcomma ajouter une virgule finale dans la sortie bibtex pour ceux qui le souhaitent
-sd --singledash utiliser un trait d'union au lieu de deux (trait d'union plus long en latex) entre les numéros dans la sortie de pages
-b --brackets utiliser des crochets au lieu de guillemets autour des données de champ
-w --whitespace ajouter des espaces blancs d'embellissement à la sortie
-U --uppercase utiliser toutes les majuscules pour les balises (noms de champs) et les types de référence (comportement avant la version 3.24)
-sk --strictkey utiliser uniquement des caractères alphanumériques pour les clés de citation bibtex

xml2ads

xml2ads convertit la bibliographie XML MODS au format de référence du Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) Astrophyics Data System ou ADS[6] (qui est très similaire au style Endnote balisé). L'utilisation de xml2ads est la même que pour les autres outils.

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convertit la bibliographie XML MODS en un fichier bibliographique au format RIS. L'utilisation de xml2ris est la même que pour les autres outils.

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convertit la bibliographie XML MODS en un fichier bibliographique Endnote balisé (format refer). L'utilisation de xml2end est la même que pour les autres outils.

xml2end xml_file.xml > output_file.end

xml2wordbib

xml2wordbib convertit la bibliographie XML MODS en un fichier bibliographique XML au format Word 2007. L'utilisation de xml2wordbib est la même que pour les autres outils.

xml2wordbib xml_file.xml > output_file.word.xml

xml2wordbib s'appelait xml2word dans les versions de bibutils antérieures à la version 3.40. Il a été renommé pour éviter toute confusion avec d'autres outils. Espérons que cela ne cassera pas trop de scripts déjà en cours d'utilisation.
