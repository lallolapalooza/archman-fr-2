NOM

nbdsh - shell pour périphérique de bloc réseau (NBD)

SYNTAXE

$ nbdsh
Bienvenue dans nbdsh, le shell pour interagir avec
les serveurs de périphérique de bloc réseau (NBD).
Le module 'nbd' a déjà été importé et il y a
une poignée NBD ouverte appelée 'h'.
nbd> h.connect_command(["nbdkit", "-s", "memory", "1G"])
nbd> h.get_size()
1073741824
nbd> buf = b"hello, world"
nbd> h.pwrite(buf, 0)
nbd> exit()

DESCRIPTION

nbdsh est un shell client basé sur Python pour accéder aux serveurs de périphérique de bloc réseau (NBD).

Pour la documentation sur l'API libnbd, ouvrez le shell et tapez :

help(nbd)

EXEMPLES

Afficher la taille d'une exportation NBD

L'option -u se connecte à une URI NBD. L'option -c vous permet d'exécuter des instructions Python uniques depuis la ligne de commande. La combinaison de ces deux options vous permet d'afficher la taille en octets d'une exportation NBD :

$ nbdsh -u nbd://localhost -c 'print(h.get_size())'
1073741824

Hexdump du secteur de boot d'une exportation NBD

En utilisant -c -, vous pouvez fournir un programme Python complet à l'entrée standard de nbdsh :

nbdsh -c - <<'EOF'
from subprocess import *
h.connect_uri("nbd://localhost")
bootsect = h.pread(512, 0)
p = Popen("hexdump -C", shell=True, stdin=PIPE)
p.stdin.write(bootsect)
EOF

OPTIONS

-h
--help
Affiche une brève aide de ligne de commande et quitte.
--base-allocation
Demande l'utilisation du contexte méta « base:allocation », qui est le contexte le plus courant utilisé avec nbd_block_status_64(3). Ceci est équivalent à l'appel "h.set_meta_context(nbd.CONTEXT_BASE_ALLOCATION)" dans le shell avant la connexion, et fonctionne même lorsqu'il est combiné avec "--uri" (tandis qu'essayer la même chose avec "-c" serait trop tard).
-c 'COMMANDE ...'
--command 'COMMANDE ...'
Au lieu de démarrer un shell interactif, exécute une commande. Cette option peut être spécifiée plusieurs fois pour exécuter plusieurs commandes.
-c -
--command -
Lit l'entrée standard et l'exécute comme une commande.
-n
Ne crée pas la poignée implicite "h".
--opt-mode
Demande l'activation du mode d'options, qui permet un contrôle fin de la négociation des options après le contact initial avec le serveur mais avant d'utiliser réellement l'exportation. Ceci est équivalent à l'appel "h.set_opt_mode(True)" dans le shell avant la connexion, et fonctionne même lorsqu'il est combiné avec "--uri" (tandis qu'essayer la même chose avec "-c" serait trop tard).
-u URI
--uri URI
Se connecte à l'URI NBD donnée. Ceci est équivalent à la commande "h.connect_uri(URI)" dans le shell.

Notez que la connexion est créée avant le traitement de toute commande "-c", ce qui empêche l'utilisation de commandes de configuration telles que "h.add_meta_context("NOM")" depuis la ligne de commande lorsqu'elle est mélangée avec cette option. Les options "--opt-mode" et "--base-allocation" peuvent être utilisées pour rendre cette situation plus facile à gérer.

-v
--verbose
Active les messages détaillés de libnbd. Ceci a le même effet que la définition de la variable d'environnement "LIBNBD_DEBUG=1"
-V
--version
Affiche le nom et la version du paquet et quitte.

NOTES

Exemples nbdsh

Il existe quelques scripts nbdsh d'exemple dans le dépôt source de libnbd sous sh/examples ou voir https://gitlab.com/nbdkit/libnbd/tree/master/sh/examples.

Utilisation de libnbd directement depuis Python

nbdsh est pratique pour le scripting en ligne de commande, mais vous n'êtes pas obligé de l'utiliser. Au lieu de cela, vous pouvez écrire un programme ou un module Python ordinaire qui importe le module "nbd" :

#!/usr/bin/python3
import nbd
h = nbd.NBD()
h.connect_uri("nbd://localhost")

Il existe quelques scripts Python d'exemple dans le dépôt source de libnbd sous python/examples ou voir https://gitlab.com/nbdkit/libnbd/tree/master/python/examples.

NOM

nbdsh — shell pour nbd

SYNTAXE

nbdsh [OPTIONS] [NBD-URL...]

DESCRIPTION

nbdsh est un interpréteur de commandes interactif (shell) pour le protocole NBD (Network Block Device). Il vous permet de connecter des périphériques NBD, d'effectuer des opérations de bas niveau sur eux, puis de les déconnecter.

Vous pouvez vous connecter à un ou plusieurs périphériques NBD en spécifiant leurs URL sur la ligne de commande. Si aucun argument n'est donné, nbdsh lance un shell vide.

L'interpréteur de commandes prend en charge les commandes suivantes :

  • connect NBD-URL : Connecte un nouveau périphérique NBD.
  • disconnect [CONNEXION-ID] : Déconnecte un périphérique NBD. Si CONNEXION-ID est omis, tous les périphériques sont déconnectés.
  • list : Liste tous les périphériques NBD connectés.
  • help [COMMANDE] : Affiche l'aide pour une commande spécifique ou la liste de toutes les commandes disponibles.
  • quit : Quitte nbdsh.
  • read CONNEXION-ID OFFSET TAILLE : Lit des données depuis un périphérique NBD.
  • write CONNEXION-ID OFFSET TAILLE : Écrit des données sur un périphérique NBD. Les données sont lues depuis l'entrée standard.
  • trim CONNEXION-ID OFFSET TAILLE : Effectue une opération de TRIM sur une plage de données d'un périphérique NBD.
  • zero CONNEXION-ID OFFSET TAILLE : Effectue une opération de ZERO sur une plage de données d'un périphérique NBD.
  • cache CONNEXION-ID OFFSET TAILLE TYPE : Effectue une opération de CACHE sur une plage de données d'un périphérique NBD. TYPE peut être flush, invalidate.
  • export_info CONNEXION-ID : Affiche des informations sur les exportations du périphérique NBD.
  • info [CONNEXION-ID] : Affiche des informations sur les périphériques NBD connectés. Si CONNEXION-ID est omis, les informations sur tous les périphériques sont affichées.

Les URL NBD doivent être au format nbd://HÔTE:PORT/EXPORT ou nbd+ssh://UTILISATEUR@HÔTE:PORT/EXPORT.

EXEMPLES

Lancer un shell interactif : 

$ nbdsh

Se connecter à un serveur NBD à l'adresse 192.168.1.100, port 10809, export "mon_disque" : 

$ nbdsh nbd://192.168.1.100:10809/mon_disque

Dans le shell, lire les 1024 premiers octets du périphérique connecté : 

nbdsh> read 0 0 1024

Écrire des données dans le périphérique : 

nbdsh> write 0 512 1024

(ensuite, tapez les données à écrire et appuyez sur Ctrl+D)

OPTIONS

nbdsh n'a pas d'options de ligne de commande spécifiques. Toutes les options sont gérées via les commandes interactives du shell.

NOTES

Les opérations de lecture et d'écriture peuvent être lentes pour de grandes quantités de données. Il est recommandé d'utiliser les outils appropriés comme dd via le périphérique NBD s'ils sont montés.

La commande write lit les données depuis l'entrée standard jusqu'à ce que la quantité spécifiée soit atteinte ou que la fin de l'entrée soit atteinte.
