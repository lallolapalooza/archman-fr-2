NOM

nbd_get_protocol - renvoie la variante du protocole NBD

SYNOPSIS

#include <libnbd.h>
const char * nbd_get_protocol (
               struct nbd_handle *h
             );

DESCRIPTION

Renvoie la variante du protocole NBD utilisée sur la connexion. À l'heure actuelle, cela renvoie l'une des chaînes "oldstyle", "newstyle" ou "newstyle-fixed". D'autres chaînes pourraient être retournées à l'avenir. La plupart des serveurs NBD modernes utilisent "newstyle-fixed".

Cet appel ne bloque pas, car il renvoie des données sauvegardées dans le handle à partir de la négociation du protocole NBD.

VALEUR RENVOYÉE

Cet appel renvoie une chaîne allouée statiquement, valide pour la durée de vie du processus ou jusqu'à ce que libnbd soit déchargée par dlclose(3). Vous ne devez pas essayer de libérer la chaîne.

ERREURS

En cas d'erreur, "NULL" est renvoyé.

Reportez-vous à « GESTION DES ERREURS » dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir « Paramètres non NULL » dans libnbd(3).

ÉTAT DU HANDLE

nbd_get_protocol peut être appelé lorsque le handle est dans les états suivants :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion       │ ❌ erreur                │
│ Connexion en cours                    │ ❌ erreur                │
│ Connexion & négociation (opt_mode) │ ✅ autorisé             │
│ Connecté au serveur               │ ✅ autorisé             │
│ Connexion fermée                  │ ✅ autorisé             │
│ Handle mort                       │ ❌ erreur                │
└───────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.2.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_GET_PROTOCOL 1

VOIR AUSSI
