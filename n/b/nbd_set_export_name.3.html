nbd_set_export_name(3) LIBNBD nbd_set_export_name(3)

NOM

nbd_set_export_name - définir le nom de l'exportation

SYNTAXE

#include <libnbd.h>
int nbd_set_export_name (
      struct nbd_handle *h, const char *export_name
    );

DESCRIPTION

Certains serveurs NBD peuvent servir plusieurs images disque ("exportations"). L'exportation est choisie par le client, en demandant un nom d'exportation pendant la phase de négociation. L'exportation par défaut est la chaîne vide "".

Certains serveurs NBD ignorent cela et servent le même contenu indépendamment. Ceci n'est pertinent que lors de la connexion à des serveurs utilisant le protocole newstyle, car le protocole oldstyle ne prenait pas en charge les noms d'exportation.

Le protocole NBD limite les noms d'exportation à 4096 octets, mais les serveurs peuvent ne pas supporter la longueur complète. L'encodage des noms d'exportation est toujours UTF-8.

Lorsque le mode option n'est pas utilisé, le nom de l'exportation doit être défini avant de commencer une connexion. Cependant, lorsque nbd_set_opt_mode(3) a activé le mode option, il est possible de changer le nom de l'exportation avant nbd_opt_go(3). En particulier, l'utilisation de nbd_opt_list(3) pendant la négociation peut être utilisée pour déterminer un nom que le serveur est susceptible d'accepter, et nbd_opt_info(3) peut être utilisé pour obtenir des détails sur une exportation avant de se connecter.

Cet appel peut être ignoré si vous utilisez nbd_connect_uri(3) pour vous connecter à une URI qui inclut un nom d'exportation.

VALEUR DE RETOUR

Si l'appel réussit, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Reportez-vous à "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h", "export_name". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ETAT DU HANDLE

nbd_set_export_name peut être appelé lorsque le handle est dans les états suivants :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion     │ ✅ autorisé             │
│ Connexion en cours                  │ ❌ erreur               │
│ Connexion & handshake (opt_mode) │ ✅ autorisé             │
│ Connecté au serveur               │ ❌ erreur               │
│ Connexion fermée                  │ ❌ erreur               │
│ Handle mort                       │ ❌ erreur               │
└───────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_SET_EXPORT_NAME 1
