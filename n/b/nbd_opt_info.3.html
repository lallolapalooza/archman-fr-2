NOM

nbd_opt_info - demander au serveur des informations sur un export

SYNTAXE

#include <libnbd.h>
int nbd_opt_info (
      struct nbd_handle *h
    );

DESCRIPTION

Demande au serveur de fournir des informations sur le nom d'export précédemment spécifié par le plus récent appel à nbd_set_export_name(3) ou nbd_connect_uri(3). Ceci ne peut être utilisé que si nbd_set_opt_mode(3) a activé le mode optionnel.

En cas de succès, les fonctions comme nbd_is_read_only(3) et nbd_get_size(3) rapporteront des détails sur cet export. Si nbd_set_request_meta_context(3) est défini (par défaut) et que des réponses structurées ou des en-têtes étendus ont été négociés, il est également valide d'utiliser nbd_can_meta_context(3) après cet appel. Cependant, il peut être plus efficace de désactiver ce paramètre et d'utiliser manuellement nbd_opt_list_meta_context(3) avec son approche de rappel, pour savoir quels contextes un export prend en charge. En général, si nbd_opt_go(3) est appelé ensuite, cet appel réussira probablement avec les détails restant les mêmes, bien que cela ne soit pas garanti par tous les serveurs.

Tous les serveurs ne comprennent pas cette requête, et même lorsqu'elle est comprise, le serveur peut échouer la requête même lorsqu'un appel correspondant à nbd_opt_go(3) réussirait.

VALEUR DE RETOUR

Si l'appel réussit, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Reportez-vous à "GESTION DES ERREURS" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ETAT DU HANDLE

nbd_opt_info peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion   │ ❌ erreur                │
│ Connexion en cours              │ ❌ erreur                │
│ Connexion & handshake (opt_mode) │ ✅ autorisé             │
│ Connecté au serveur             │ ❌ erreur                │
│ Connexion fermée                │ ❌ erreur                │
│ Handle mort                     │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.4.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_OPT_INFO 1
