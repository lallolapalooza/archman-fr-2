NOM

nbd_set_handshake_flags - contrôler l'utilisation des indicateurs de négociation

SYNOPSIS

#include <libnbd.h>
int nbd_set_handshake_flags (
      struct nbd_handle *h, uint32_t flags
    );

DESCRIPTION

Par défaut, libnbd essaie de négocier tous les indicateurs de négociation possibles également pris en charge par le serveur, car omettre un indicateur de négociation peut empêcher l'utilisation d'autres fonctionnalités telles que le chiffrement TLS ou les réponses structurées. Cependant, pour les tests d'intégration, il peut être utile de réduire l'ensemble des indicateurs pris en charge par le client afin de tester qu'un serveur particulier peut gérer divers clients conformes aux versions plus anciennes de la spécification NBD.

L'argument "flags" est un masque de bits, incluant zéro ou plusieurs des indicateurs de négociation suivants:

"LIBNBD_HANDSHAKE_FLAG_FIXED_NEWSTYLE" = 1
Le serveur gère gracieusement les requêtes d'options inconnues du client, plutôt que de se déconnecter. Sans cet indicateur, un client ne peut pas demander en toute sécurité l'utilisation d'extensions telles que le chiffrement TLS ou les réponses structurées, car la requête peut amener un serveur plus ancien à abandonner la connexion.
"LIBNBD_HANDSHAKE_FLAG_NO_ZEROES" = 2
Si le client est forcé d'utiliser "NBD_OPT_EXPORT_NAME" au lieu de "NBD_OPT_GO", cet indicateur permet au serveur d'envoyer moins d'octets de remplissage tous à zéro sur la connexion.

Par commodité, la constante "LIBNBD_HANDSHAKE_FLAG_MASK" est disponible pour décrire tous les indicateurs pris en charge par cette compilation de libnbd. Les futures extensions NBD peuvent ajouter d'autres indicateurs, qui à leur tour peuvent être activés par défaut dans les versions plus récentes de libnbd. Ainsi, lors de la tentative de désactivation d'un seul bit spécifique, il est plus sage d'appeler d'abord nbd_get_handshake_flags(3) et de modifier cette valeur, plutôt que de définir aveuglément une valeur constante.

VALEUR DE RETOUR

En cas de succès, la fonction renvoie 0.

ERREURS

En cas d'erreur, -1 est renvoyé.

Se référer à "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non NULL" dans libnbd(3).

ETAT DU HANDLE

nbd_set_handshake_flags peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant la connexion  │ ✅ autorisé             │
│ Connexion en cours                 │ ❌ erreur               │
│ Connexion & négociation (opt_mode) │ ❌ erreur               │
│ Connecté au serveur              │ ❌ erreur               │
│ Connexion fermée                 │ ❌ erreur               │
│ Handle mort                      │ ❌ erreur               │
└───────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.2.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_SET_HANDSHAKE_FLAGS 1

VOIR AUSSI

nbd_create(3), nbd_get_handshake_flags(3), nbd_set_request_structured_replies(3), libnbd(3).
