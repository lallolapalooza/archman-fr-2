nbd_get_size(3) LIBNBD nbd_get_size(3)

NOM

nbd_get_size - retourne la taille de l'export

SYNOPSIS

#include <libnbd.h>
int64_t nbd_get_size (
          struct nbd_handle *h
        );

DESCRIPTION

Retourne la taille en octets de l'export NBD.

Notez que cet appel échoue avec "EOVERFLOW" pour un serveur improbable qui annonce une taille qui ne peut pas tenir dans un entier signé 64 bits.

L'option --size de nbdinfo(1) est un moyen d'accéder à cette API depuis les scripts shell.

Cet appel ne bloque pas, car il retourne des données qui sont enregistrées dans le handle lors de la négociation du protocole NBD.

VALEUR DE RETOUR

Cet appel retourne un entier signé 64 bits ≥ 0.

ERREURS

En cas d'erreur, -1 est retourné.

Reportez-vous à "Gestion des erreurs" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ÉTAT DU HANDLE

nbd_get_size peut être appelé lorsque le handle est dans les états suivants :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant la connexion   │ ❌ erreur                │
│ Connexion en cours                 │ ❌ erreur                │
│ Connexion et négociation (opt_mode)│ ✅ autorisé             │
│ Connecté au serveur                │ ✅ autorisé             │
│ Connexion fermée                   │ ✅ autorisé             │
│ Handle mort                        │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de vérifier si cette fonction est disponible lors de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_GET_SIZE 1

EXEMPLE

Cet exemple est également disponible sous le nom examples/get-size.c dans le code source de libnbd.

/* Cet exemple montre comment se connecter à un serveur NBD
 * et lire la taille du disque.
 *
 * Vous pouvez le tester avec nbdkit comme suit :
 *
 * nbdkit -U - memory 1M \
 *   --run './get-size $unixsocket'
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdint.h>
#include <inttypes.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  int64_t size;
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Créer le handle libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Se connecter au serveur NBD via un
   * socket de domaine Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Lire la taille en octets et l'afficher. */
  size = nbd_get_size (nbd);
  if (size == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  printf ("%s: size = %" PRIi64 " bytes\n",
          argv[1], size);
  /* Fermer le handle libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

VOIR AUSSI

nbd_create(3), nbd_opt_info(3), "Taille de l'export" dans libnbd(3), libnbd(3), nbdinfo(1).
