nbd_aio_opt_list(3) LIBNBD nbd_aio_opt_list(3)

NOM

nbd_aio_opt_list - demande au serveur de lister toutes les exportations pendant la négociation

SYNTAXE

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, const char *name,
                   const char *description);
  void *user_data;
  void (*free) (void *user_data);
} nbd_list_callback;
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int nbd_aio_opt_list (
      struct nbd_handle *h,
      nbd_list_callback list_callback,
      nbd_completion_callback completion_callback
    );

DESCRIPTION

Demande au serveur de lister toutes les exportations qu'il prend en charge. Ceci ne peut être utilisé que si nbd_set_opt_mode(3) a activé le mode d'option.

Pour déterminer quand la requête est terminée, attendez que nbd_aio_is_connecting(3) retourne false. Ou fournissez le « completion_callback » optionnel qui sera appelé comme décrit dans « Callbacks d'achèvement » dans libnbd(3), sauf qu'il est automatiquement retiré quelle que soit la valeur de retour. Notez que la détection si le serveur retourne une erreur (comme le fait la valeur de retour de son homologue synchrone) n'est possible qu'avec un callback d'achèvement.

VALEUR DE RETOUR

Si l'appel réussit, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Consultez « GESTION DES ERREURS » dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : « h ». Pour plus d'informations, voir « Paramètres non-NULL » dans libnbd(3).

ETAT DU HANDLE

nbd_aio_opt_list peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion       │ ❌ erreur                │
│ Connexion en cours                 │ ❌ erreur                │
│ Connexion & handshake (opt_mode) │ ✅ autorisé             │
│ Connecté au serveur                │ ❌ erreur                │
│ Connexion fermée                   │ ❌ erreur                │
│ Handle mort                        │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.4.

Si vous avez besoin de tester si cette fonction est disponible à la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_AIO_OPT_LIST 1

VOIR AUSSI

nbd_aio_is_connecting(3), nbd_create(3), nbd_opt_list(3), nbd_set_opt_mode(3), libnbd(3).
