nbd_aio_opt_starttls(3) LIBNBD nbd_aio_opt_starttls(3)

NOM

nbd_aio_opt_starttls - demande au serveur d'initier une connexion TLS

SYNOPIS

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int nbd_aio_opt_starttls (
      struct nbd_handle *h,
      nbd_completion_callback completion_callback
    );

DESCRIPTION

Demande au serveur d'initier une connexion TLS sécurisée en envoyant "NBD_OPT_STARTTLS". Ceci se comporte comme son homologue synchrone nbd_opt_starttls(3), à la différence qu'il n'attend pas la réponse du serveur.

Pour déterminer quand la demande est terminée, attendez que nbd_aio_is_connecting(3) retourne false. Ou fournissez le "completion_callback" optionnel qui sera invoqué comme décrit dans "Callbacks d'achèvement" dans libnbd(3), à la différence qu'il est automatiquement retenté quelle que soit la valeur de retour. Notez que la détection si le serveur retourne une erreur (comme le fait la valeur de retour de son homologue synchrone) n'est possible qu'avec un callback d'achèvement.

VALEUR DE RETOUR

Si l'appel réussit, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Consultez "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, consultez "Paramètres non NULL" dans libnbd(3).

ÉTAT DU HANDLE

nbd_aio_opt_starttls peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion       │ ❌ erreur                │
│ Connexion en cours                     │ ❌ erreur                │
│ Connexion & handshake (opt_mode) │ ✅ autorisé              │
│ Connecté au serveur             │ ❌ erreur                │
│ Connexion fermée                │ ❌ erreur                │
│ Handle mort                         │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.16.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_AIO_OPT_STARTTLS 1

VOIR AUSSI

nbd_aio_is_connecting(3), nbd_create(3), nbd_opt_starttls(3), nbd_set_opt_mode(3), libnbd(3).
