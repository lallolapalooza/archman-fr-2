NOM

nbd_aio_peek_command_completed - vérifier si une commande est terminée

SYNTAXE

#include <libnbd.h>
int64_t nbd_aio_peek_command_completed (
          struct nbd_handle *h
        );

DESCRIPTION

Retourne le cookie unique de 64 bits positif de la première commande non retirée mais terminée, 0 s'il y a des commandes en cours mais qu'aucune n'attend d'être retirée, ou -1 en cas d'erreur, y compris lorsqu'il n'y a aucune commande en cours. Tout cookie retourné par cette fonction doit toujours être passé à nbd_aio_command_completed(3) pour réellement retirer la commande et savoir si elle a réussi.

VALEUR DE RETOUR

Cet appel retourne un entier signé de 64 bits ≥ 0.

ERREURS

En cas d'erreur, -1 est retourné.

Se référer à "ERROR HANDLING" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Non-NULL parameters" dans libnbd(3).

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de vérifier si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_AIO_PEEK_COMMAND_COMPLETED 1

VOIR AUSSI

nbd_aio_command_completed(3), nbd_create(3), libnbd(3).
