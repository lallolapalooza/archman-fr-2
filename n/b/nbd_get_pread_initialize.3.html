nbd_get_pread_initialize(3) LIBNBD nbd_get_pread_initialize(3)

NOM

nbd_get_pread_initialize - vérifie si libnbd pré-initialise les tampons de lecture

SYNTAXE

#include <libnbd.h>
int nbd_get_pread_initialize (
      struct nbd_handle *h
    );

DESCRIPTION

Retourne si libnbd effectue une pré-initialisation d'un tampon passé à nbd_pread(3) et similaire à zéro, tel que défini par nbd_set_pread_initialize(3).

VALEUR DE RETOUR

Cet appel retourne une valeur booléenne.

ERREURS

Cette fonction ne peut pas échouer.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.12.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_GET_PREAD_INITIALIZE 1

VOIR AUSSI

nbd_aio_pread(3), nbd_aio_pread_structured(3), nbd_create(3), nbd_pread(3), nbd_pread_structured(3), nbd_set_pread_initialize(3), nbd_set_strict_mode(3), libnbd(3).
