nbd_set_private_data(3) LIBNBD nbd_set_private_data(3)

NOM

nbd_set_private_data - définir les données privées par handle

SYNTAXE

#include <libnbd.h>
uintptr_t nbd_set_private_data (
            struct nbd_handle *h, uintptr_t private_data
          );

DESCRIPTION

Les handles contiennent un champ de données privées que les applications peuvent utiliser à leurs propres fins. Cette fonction définit la valeur de ce champ et retourne l'ancienne valeur (ou 0 s'il n'était pas défini auparavant).

Lors de l'appel à libnbd depuis C, le type de ce champ est "uintptr_t" afin qu'il puisse être utilisé pour stocker un entier non signé ou un pointeur.

Dans les liaisons non-C, il peut être utilisé pour stocker un entier non signé.

Libnbd n'utilise ni n'interprète la valeur d'aucune manière (sauf pour la retourner lorsque vous appelez nbd_get_private_data(3)). En particulier, si la valeur est un pointeur, elle n'est pas libérée lorsque le handle est fermé.

VALEUR DE RETOUR

Cet appel retourne un "uintptr_t".

ERREURS

Cette fonction ne retourne pas d'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.8.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_SET_PRIVATE_DATA 1

VOIR AUSSI

nbd_create(3), nbd_get_private_data(3), libnbd(3).
