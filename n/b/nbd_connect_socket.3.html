nbd_connect_socket(3)

Paquet: libnbd

nbd_connect_socket(3) LIBNBD nbd_connect_socket(3)

NOM

nbd_connect_socket - se connecter directement à un socket connecté

SYNTAXE

#include <libnbd.h>
int nbd_connect_socket (
      struct nbd_handle *h, int sock
    );

DESCRIPTION

Passe un socket connecté "sock" à travers lequel libnbd communiquera avec le serveur NBD.

L'appelant est responsable de la création et de la connexion de ce socket par quelque méthode que ce soit, avant de le passer à libnbd.

Si cet appel réussit sans erreur, la propriété du socket est transférée à libnbd. Libnbd fermera le socket lorsque le handle sera fermé. L'appelant ne doit en aucun cas utiliser le socket.

Cet appel retourne lorsque la connexion a été établie. Par défaut, cela progresse jusqu'à la phase de transmission, mais nbd_set_opt_mode(3) peut être utilisé pour un contrôle manuel sur la négociation des options effectuée avant la phase de transmission.

VALEUR RENVOYÉE

Si l'appel réussit, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Consultez "GESTION DES ERREURS" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non NULL" dans libnbd(3).

ÉTAT DU HANDLE

nbd_connect_socket peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant la connexion      │ ✅ autorisé             │
│ Connexion en cours                  │ ❌ erreur               │
│ Connexion et handshake (opt_mode) │ ❌ erreur               │
│ Connecté au serveur                 │ ❌ erreur               │
│ Connexion fermée                    │ ❌ erreur               │
│ Handle mort                         │ ❌ erreur               │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.2.

Si vous avez besoin de tester si cette fonction est disponible à la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_CONNECT_SOCKET 1

VOIR AUSSI
