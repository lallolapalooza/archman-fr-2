nbd_is_rotational(3)

Paquet: libnbd

Licences: LGPL-2.1-or-later

nbd_is_rotational(3) LIBNBD nbd_is_rotational(3)

NOM

nbd_is_rotational - le disque NBD est-il rotationnel (comme un disque) ?

SYNTAXE

#include <libnbd.h>
int nbd_is_rotational (
      struct nbd_handle *h
    );

DESCRIPTION

Retourne vrai si le disque exposé via NBD est rotationnel (comme une disquette ou un disque dur traditionnel). Retourne faux si le disque n'a pas de pénalité pour l'accès aléatoire (comme un SSD ou un disque RAM).

Cet appel ne bloque pas, car il renvoie des données qui sont sauvegardées dans le descripteur lors de la négociation du protocole NBD.

VALEUR DE RETOUR

Cet appel renvoie une valeur booléenne.

ERREURS

En cas d'erreur, -1 est retourné.

Consultez "ERROR HANDLING" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, consultez "Non-NULL parameters" dans libnbd(3).

ÉTAT DU DESCRIPTEUR

nbd_is_rotational peut être appelé lorsque le descripteur est dans les états suivants :

┌─────────────────────────────────────┬─────────────────────────┐
│ Descripteur créé, avant connexion    │ ❌ erreur                │
│ Connexion en cours                     │ ❌ erreur                │
│ Connexion & négociation (opt_mode) │ ✅ autorisé            │
│ Connecté au serveur                │ ✅ autorisé            │
│ Connexion terminée                  │ ✅ autorisé            │
│ Descripteur mort                    │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_IS_ROTATIONAL 1

EXEMPLE

Cet exemple est également disponible sous le nom examples/server-flags.c dans le code source de libnbd.

/* Cet exemple montre comment se connecter à un serveur NBD
 * et afficher les drapeaux d'exportation.
 *
 * Vous pouvez le tester avec nbdkit comme suit :
 *
 * nbdkit -U - memory 1M \
 *   --run './server-flags $unixsocket'
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char *str;
  int flag;
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Créer le descripteur libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Demander toutes les informations. */
#if LIBNBD_HAVE_NBD_SET_FULL_INFO /* Ajouté en 1.4 */
  if (nbd_set_full_info (nbd, true) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
#endif
  /* Se connecter au serveur NBD via un
   * socket de domaine Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Voir si le serveur a fourni des détails supplémentaires,
   * en utilisant les fonctions ajoutées en 1.4
   */
#if LIBNBD_HAVE_NBD_GET_EXPORT_DESCRIPTION
  str = nbd_get_canonical_export_name (nbd);
  if (str)
    printf ("canonical_name = %s\n", str);
  free (str);
  str = nbd_get_export_description (nbd);
  if (str)
    printf ("description = %s\n", str);
  free (str);
#endif
  /* Lire et afficher les drapeaux. */
#define PRINT_FLAG(flag_fn)                     \
  flag = flag_fn (nbd);                         \
  if (flag == -1) {                             \
    fprintf (stderr, "%s\n", nbd_get_error ()); \
    exit (EXIT_FAILURE);                        \
  }                                             \
  printf (#flag_fn " = %s\n",                   \
          flag ? "true" : "false");
  PRINT_FLAG (nbd_can_cache);
  PRINT_FLAG (nbd_can_df);
  PRINT_FLAG (nbd_can_flush);
  PRINT_FLAG (nbd_can_fua);
  PRINT_FLAG (nbd_can_multi_conn);
  PRINT_FLAG (nbd_can_trim);
  PRINT_FLAG (nbd_can_zero);
#if LIBNBD_HAVE_NBD_CAN_FAST_ZERO
  /* Ajouté en 1.2 */
  PRINT_FLAG (nbd_can_fast_zero);
#endif
#if LIBNBD_HAVE_NBD_CAN_BLOCK_STATUS_PAYLOAD
  /* Ajouté en 1.18 */
  PRINT_FLAG (nbd_can_block_status_payload);
#endif
  PRINT_FLAG (nbd_is_read_only);
  PRINT_FLAG (nbd_is_rotational);
  /* Fermer le descripteur libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}
