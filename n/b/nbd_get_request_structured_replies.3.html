NOM

nbd_get_request_structured_replies - vérifier si les réponses structurées sont tentées

SYNTAXE

#include <libnbd.h>
int nbd_get_request_structured_replies (
      struct nbd_handle *h
    );

DESCRIPTION

Retourne l'état du drapeau de requêtes de réponses structurées sur cette poignée.

Note : Si vous voulez savoir si des réponses structurées ont été effectivement négociées sur une connexion particulière, utilisez plutôt nbd_get_structured_replies_negotiated(3).

VALEUR DE RETOUR

Cet appel retourne une valeur booléenne.

ERREURS

Cette fonction ne peut pas échouer.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.2.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_GET_REQUEST_STRUCTURED_REPLIES 1

VOIR AUSSI

nbd_create(3), nbd_get_request_extended_headers(3), nbd_get_structured_replies_negotiated(3), nbd_set_request_structured_replies(3), libnbd(3).
