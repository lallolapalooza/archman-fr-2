NOM

nbd_opt_starttls - demander au serveur d'initier TLS

SYNTAXE

#include <libnbd.h>
int nbd_opt_starttls (
      struct nbd_handle *h
    );

DESCRIPTION

Demande au serveur d'initier une connexion TLS sécurisée, en envoyant "NBD_OPT_STARTTLS". Ceci ne peut être utilisé que si nbd_set_opt_mode(3) a activé le mode options ; de plus, si vous utilisez nbd_set_tls(3) pour demander autre chose que la valeur par défaut de "LIBNBD_TLS_DISABLE", alors libnbd aura déjà tenté une connexion TLS avant de vous donner le contrôle de la négociation des options. Cette commande est désactivée si nbd_supports_tls(3) renvoie faux.

Cette fonction est principalement utile pour les tests d'intégration des cas limites de la gestion du serveur ; en particulier, une mauvaise utilisation de cette fonction combinée avec un serveur qui ne fait pas attention à réinitialiser les commandes d'état comme nbd_opt_structured_reply(3) pourrait entraîner une faille de sécurité (voir CVE-2021-3716 contre nbdkit, par exemple). Ainsi, lorsque la sécurité est une préoccupation, vous devriez plutôt préférer utiliser nbd_set_tls(3) avec "LIBNBD_TLS_REQUIRE" et laisser libnbd négocier TLS automatiquement.

Cette fonction renvoie vrai si le serveur répond avec succès, faux si le serveur répond avec une erreur, et échoue uniquement si le serveur ne répond pas (par exemple, en cas de perte de connexion, ce qui peut inclure le cas où le serveur rejette les identifiants fournis pendant la négociation TLS). Notez que le protocole NBD stipule que demander TLS après qu'il soit déjà activé est une erreur côté client ; la plupart des serveurs échoueront gracieusement une deuxième demande, mais cela ne rétrograde pas une session TLS qui a déjà été établie, comme indiqué par nbd_get_tls_negotiated(3).

VALEUR DE RETOUR

Cet appel renvoie une valeur booléenne.

ERREURS

En cas d'erreur, -1 est renvoyé.

Se référer à « GESTION DES ERREURS » dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir « Paramètres non NULL » dans libnbd(3).

ETAT DU HANDLE

nbd_opt_starttls peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant la connexion   │ ❌ erreur                │
│ Connexion en cours                  │ ❌ erreur                │
│ Connexion et handshake (opt_mode) │ ✅ autorisé            │
│ Connecté au serveur             │ ❌ erreur                │
│ Connexion fermée                │ ❌ erreur                │
│ Handle mort                         │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.16.

Si vous devez vérifier si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_OPT_STARTTLS 1
