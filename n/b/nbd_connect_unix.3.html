nbd_connect_unix(3)

Paquet: libnbd

Licences: LGPL-2.1-or-later

nbd_connect_unix(3) LIBNBD nbd_connect_unix(3)

NOM

nbd_connect_unix - se connecter à un serveur NBD via une socket de domaine Unix

SYNTAXE

#include <libnbd.h>
int nbd_connect_unix (
      struct nbd_handle *h, const char *unixsocket
    );

DESCRIPTION

Se connecte (synchrone) via la socket de domaine Unix nommée ("unixsocket") à un serveur NBD fonctionnant sur la même machine.

Cet appel retourne lorsque la connexion a été établie. Par défaut, cela progresse jusqu'à la phase de transmission, mais nbd_set_opt_mode(3) peut être utilisé pour un contrôle manuel de la négociation des options effectuée avant la phase de transmission.

VALEUR DE RETOUR

Si l'appel réussit, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Reportez-vous à "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h", "unixsocket". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ÉTAT DU HANDLE

nbd_connect_unix peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion     │ ✅ autorisé            │
│ Connexion en cours                │ ❌ erreur              │
│ Connexion & handshake (opt_mode)│ ❌ erreur              │
│ Connecté au serveur             │ ❌ erreur              │
│ Connexion fermée                │ ❌ erreur              │
│ Handle mort                     │ ❌ erreur              │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de tester la disponibilité de cette fonction au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_CONNECT_UNIX 1

EXEMPLE

Cet exemple est également disponible sous le nom examples/fetch-first-sector.c dans le code source de libnbd.

/* Cet exemple montre comment se connecter à un serveur NBD
 * et récupérer et afficher le premier secteur (généralement le
 * secteur de démarrage ou la table de partitions ou le superblock
 * du système de fichiers).
 *
 * Vous pouvez le tester avec nbdkit comme suit :
 *
 * nbdkit -U - floppy . \
 *   --run './fetch-first-sector $unixsocket'
 *
 * Le plugin floppy de nbdkit crée un disque MBR, donc le
 * premier secteur est la table de partitions.
 */
#include <stdio.h>
#include <stdlib.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char buf[512];
  FILE *pp;
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Créez le handle libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Connectez-vous au serveur NBD via une
   * socket de domaine Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Lisez le premier secteur de manière synchrone. */
  if (nbd_pread (nbd, buf, sizeof buf, 0, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Fermez le handle libnbd. */
  nbd_close (nbd);
  /* Affichez le premier secteur. */
  pp = popen ("hexdump -C", "w");
  if (pp == NULL) {
    perror ("popen: hexdump");
    exit (EXIT_FAILURE);
  }
  fwrite (buf, sizeof buf, 1, pp);
  pclose (pp);
  exit (EXIT_SUCCESS);
}
