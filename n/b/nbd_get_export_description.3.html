nbd_get_export_description(3)

Paquet: libnbd

Licences: LGPL-2.1-or-later

nbd_get_export_description(3) LIBNBD nbd_get_export_description(3)

NOM

nbd_get_export_description - renvoyer la description de l'exportation, si le serveur en a une

SYNTAXE

#include <libnbd.h>
char * nbd_get_export_description (
         struct nbd_handle *h
       );

DESCRIPTION

Le protocole NBD permet à un serveur de signaler une description d'exportation facultative. Cette fonction signale toute description renvoyée par le serveur.

Il est peu probable que certains serveurs signalent une description, à moins que le client n'ait spécifiquement indiqué qu'il en souhaitait une, via nbd_set_full_info(3). Pour qemu-nbd(8), une description est définie avec -D.

VALEUR DE RETOUR

Cet appel renvoie une chaîne de caractères. L'appelant doit libérer la chaîne renvoyée pour éviter une fuite de mémoire.

ERREURS

En cas d'erreur, "NULL" est renvoyé.

Se référer à "GESTION DES ERREURS" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ETAT DU HANDLE

nbd_get_export_description peut être appelé lorsque le handle est dans les états suivants :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion       │ ❌ erreur                │
│ Connexion en cours                  │ ❌ erreur                │
│ Connexion & handshake (opt_mode) │ ✅ autorisé            │
│ Connecté au serveur               │ ✅ autorisé            │
│ Connexion fermée                  │ ✅ autorisé            │
│ Handle mort                       │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.4.

Si vous avez besoin de vérifier si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_GET_EXPORT_DESCRIPTION 1

EXEMPLE

Cet exemple est également disponible sous le nom examples/server-flags.c dans le code source de libnbd.

/* Cet exemple montre comment se connecter à un serveur NBD
 * et afficher les indicateurs d'exportation.
 *
 * Vous pouvez le tester avec nbdkit comme suit :
 *
 * nbdkit -U - memory 1M \
 *   --run './server-flags $unixsocket'
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char *str;
  int flag;
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Créer le handle libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Demander des informations complètes. */
#if LIBNBD_HAVE_NBD_SET_FULL_INFO /* Ajouté en 1.4 */
  if (nbd_set_full_info (nbd, true) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
#endif
  /* Se connecter au serveur NBD via un
   * socket de domaine Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Voir si le serveur a fourni des détails supplémentaires,
   * en utilisant les fonctions ajoutées en 1.4
   */
#if LIBNBD_HAVE_NBD_GET_EXPORT_DESCRIPTION
  str = nbd_get_canonical_export_name (nbd);
  if (str)
    printf ("canonical_name = %s\n", str);
  free (str);
  str = nbd_get_export_description (nbd);
  if (str)
    printf ("description = %s\n", str);
  free (str);
#endif
  /* Lire et afficher les indicateurs. */
#define PRINT_FLAG(flag_fn)                     \
  flag = flag_fn (nbd);                         \
  if (flag == -1) {                             \
    fprintf (stderr, "%s\n", nbd_get_error ()); \
    exit (EXIT_FAILURE);                        \
  }                                             \
  printf (#flag_fn " = %s\n",                   \
          flag ? "true" : "false");
  PRINT_FLAG (nbd_can_cache);
  PRINT_FLAG (nbd_can_df);
  PRINT_FLAG (nbd_can_flush);
  PRINT_FLAG (nbd_can_fua);
  PRINT_FLAG (nbd_can_multi_conn);
  PRINT_FLAG (nbd_can_trim);
  PRINT_FLAG (nbd_can_zero);
#if LIBNBD_HAVE_NBD_CAN_FAST_ZERO
  /* Ajouté en 1.2 */
  PRINT_FLAG (nbd_can_fast_zero);
#endif
#if LIBNBD_HAVE_NBD_CAN_BLOCK_STATUS_PAYLOAD
  /* Ajouté en 1.18 */
  PRINT_FLAG (nbd_can_block_status_payload);
#endif
  PRINT_FLAG (nbd_is_read_only);
  PRINT_FLAG (nbd_is_rotational);
  /* Fermer le handle libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

nbd_get_export_description(3)

Bibliothèque nbd — Manuel Linux

NOM

nbd_get_export_description — Obtenir une description d'une exportation NBD.

SYNTAXE

#include <libnbd-1/nbd.h>

int nbd_get_export_description(NBDClient *client,
    const char *uri,
    char **description,
    char **error);

DESCRIPTION

La fonction nbd_get_export_description tente d'obtenir une chaîne de caractères décrivant l'exportation NBD spécifiée par uri. Cette chaîne est généralement retournée par le serveur NBD et peut contenir des informations utiles sur l'exportation. Si la récupération réussit, la description est stockée dans la mémoire allouée par nbd_get_export_description et le pointeur est assigné à description. Si une erreur se produit, un message d'erreur est stocké dans la mémoire allouée par nbd_get_export_description et le pointeur est assigné à error. Dans tous les cas, si nbd_get_export_description réussit, la valeur de retour sera 0. En cas d'échec, la valeur de retour sera non nulle. La mémoire allouée pour description ou error doit être libérée par l'appelant à l'aide de free. Si uri est NULL, la dernière exportation utilisée est utilisée.

PARAMÈTRES

  • client : Un pointeur vers une structure NBDClient initialisée.
  • uri : L'URI de l'exportation NBD à décrire. Peut être NULL pour utiliser la dernière exportation.
  • description : Un pointeur vers un pointeur de caractère où sera stockée la description de l'exportation.
  • error : Un pointeur vers un pointeur de caractère où sera stocké un message d'erreur en cas d'échec.

VALEUR DE RETOUR

Renvoie 0 en cas de succès, et une valeur non nulle en cas d'erreur.

ERREURS

En cas d'échec, un message d'erreur est stocké dans error.

EXEMPLE

#include <libnbd-1/nbd.h>
#include <stdio.h>
#include <stdlib.h>

int main() {
    NBDClient *client = NULL;
    char *description = NULL;
    char *error = NULL;
    int ret;

    client = nbd_connect("nbd:example.com:10809");
    if (!client) {
        fprintf(stderr, "Erreur de connexion à NBD.\n");
        return 1;
    }

    ret = nbd_get_export_description(client, NULL, &description, &error);
    if (ret == 0) {
        printf("Description de l'exportation : %s\n", description);
        free(description);
    } else {
        fprintf(stderr, "Erreur lors de l'obtention de la description de l'exportation : %s\n", error);
        free(error);
    }

    nbd_disconnect(client);
    return 0;
}

nbd_connect(3), nbd_disconnect(3)
