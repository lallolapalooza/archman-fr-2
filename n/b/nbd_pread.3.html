nbd_pread(3)

Paquet: libnbd

Licences: LGPL-2.1-or-later

nbd_pread(3) LIBNBD nbd_pread(3)

NOM

nbd_pread - lire depuis le serveur NBD

SYNTAXE

#include <libnbd.h>
int nbd_pread (
      struct nbd_handle *h, void *buf, size_t count,
      uint64_t offset, uint32_t flags
    );

DESCRIPTION

Émet une commande de lecture vers le serveur NBD pour la plage commençant à "offset" et se terminant à "offset" + "count" - 1. NBD ne peut lire que tout ou rien avec cet appel. L'appel retourne lorsque les données ont été entièrement lues dans "buf" ou qu'une erreur s'est produite. Voir aussi nbd_pread_structured(3), si une visibilité plus fine est requise dans les réponses du serveur, ou si vous souhaitez utiliser "LIBNBD_CMD_FLAG_DF".

Notez que libnbd impose actuellement une taille maximale de tampon de lecture de 64MiB, même si le serveur autoriserait un tampon plus grand dans une seule transaction ; les tentatives pour dépasser cette limite entraîneront une erreur "ERANGE". Le serveur peut imposer une limite plus petite, qui peut être obtenue avec nbd_get_block_size(3).

Le paramètre "flags" doit être 0 pour l'instant (il existe pour de futures extensions du protocole NBD).

Notez que si cette commande échoue, et que nbd_get_pread_initialize(3) retourne vrai, alors libnbd a nettoyé "buf", mais il n'est pas spécifié si le contenu de "buf" sera lu comme zéro ou comme des résultats partiels du serveur. Si nbd_get_pread_initialize(3) retourne faux, alors libnbd n'a pas nettoyé "buf", et son contenu est indéfini en cas d'échec.

Par défaut, libnbd rejettera les tentatives d'utilisation de cette fonction avec des paramètres susceptibles d'entraîner un échec du serveur, comme la demande d'un drapeau de commande inconnu. La fonction nbd_set_strict_mode(3) peut être utilisée pour modifier les scénarios qui doivent attendre une réponse du serveur plutôt que de retourner une erreur rapide.

VALEUR RENVOYÉE

Si l'appel réussit, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Reportez-vous à "GESTION DES ERREURS" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h", "buf". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ÉTAT DU MANIPULATEUR

nbd_pread peut être appelé lorsque le manipulateur est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Manipulateur créé, avant connexion    │ ❌ erreur                │
│ Connexion en cours                      │ ❌ erreur                │
│ Connexion et handshake (opt_mode) │ ❌ erreur                │
│ Connecté au serveur             │ ✅ autorisé              │
│ Connexion fermée                │ ❌ erreur                │
│ Manipulateur mort                         │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous devez tester la disponibilité de cette fonction au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_PREAD 1

EXEMPLE

Cet exemple est également disponible sous le nom examples/fetch-first-sector.c dans le code source de libnbd.

/* Cet exemple montre comment se connecter à un serveur NBD
 * et récupérer et afficher le premier secteur (généralement le
 * secteur d'amorçage ou la table de partitions ou le
 * superbloc du système de fichiers).
 *
 * Vous pouvez le tester avec nbdkit comme ceci :
 *
 * nbdkit -U - floppy . \
 *   --run './fetch-first-sector $unixsocket'
 *
 * Le plugin floppy de nbdkit crée un disque MBR, donc le
 * premier secteur est la table de partitions.
 */
#include <stdio.h>
#include <stdlib.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char buf[512];
  FILE *pp;
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Créer le manipulateur libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Se connecter au serveur NBD via un
   * socket de domaine Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Lire le premier secteur de manière synchrone. */
  if (nbd_pread (nbd, buf, sizeof buf, 0, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Fermer le manipulateur libnbd. */
  nbd_close (nbd);
  /* Afficher le premier secteur. */
  pp = popen ("hexdump -C", "w");
  if (pp == NULL) {
    perror ("popen: hexdump");
    exit (EXIT_FAILURE);
  }
  fwrite (buf, sizeof buf, 1, pp);
  pclose (pp);
  exit (EXIT_SUCCESS);
}
