nbd_connect_vsock(3) LIBNBD nbd_connect_vsock(3)

NOM

nbd_connect_vsock - se connecter à un serveur NBD via le protocole AF_VSOCK

SYNTAXE

#include <libnbd.h>
int nbd_connect_vsock (
      struct nbd_handle *h, uint32_t cid, uint32_t port
    );

DESCRIPTION

Se connecter (synchrone) via le protocole "AF_VSOCK" depuis une machine virtuelle vers un serveur NBD, généralement exécuté sur l'hôte. Les paramètres "cid" et "port" spécifient l'adresse du serveur. Habituellement, "cid" devrait être 2 (pour se connecter à l'hôte), et "port" peut être 10809 ou un autre numéro de port qui vous est attribué par l'administrateur de l'hôte.

Tous les systèmes ne prennent pas en charge "AF_VSOCK" ; pour déterminer si libnbd a été compilé sur un système avec prise en charge de vsock, consultez nbd_supports_vsock(3).

Cet appel retourne lorsque la connexion a été établie. Par défaut, cela se poursuit jusqu'à la phase de transmission, mais nbd_set_opt_mode(3) peut être utilisé pour un contrôle manuel de la négociation d'options effectuée avant la phase de transmission.

VALEUR DE RETOUR

Si l'appel réussit, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Consultez "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, consultez "Paramètres non NULL" dans libnbd(3).

ETAT DU HANDLE

nbd_connect_vsock peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion        │ ✅ autorisé             │
│ Connexion en cours                   │ ❌ erreur               │
│ Connexion & handshake (opt_mode) │ ❌ erreur               │
│ Connecté au serveur                │ ❌ erreur               │
│ Connexion fermée                   │ ❌ erreur               │
│ Handle mort                        │ ❌ erreur               │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.2.

Si vous avez besoin de tester la disponibilité de cette fonction au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_CONNECT_VSOCK 1

VOIR AUSSI

nbd_aio_connect_vsock(3), nbd_create(3), nbd_set_opt_mode(3), nbd_supports_vsock(3), libnbd(3), vsock(7).
