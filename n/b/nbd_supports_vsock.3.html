nbd_supports_vsock(3)

Paquet: libnbd

nbd_supports_vsock(3) LIBNBD nbd_supports_vsock(3)

NOM

nbd_supports_vsock - true si libnbd a été compilé avec le support pour AF_VSOCK

SYNTAXE

#include <libnbd.h>
int nbd_supports_vsock (
      struct nbd_handle *h
    );

DESCRIPTION

Retourne vrai si libnbd a été compilé avec le support pour la famille de sockets "AF_VSOCK", ou faux sinon.

Notez que sur le système d'exploitation Linux, ceci retourne vrai s'il y a un support à la compilation, mais vous pourriez toujours avoir besoin de support à l'exécution pour certains aspects de l'utilisation d'AF_VSOCK ; par exemple, l'utilisation de "VMADDR_CID_LOCAL" comme nom de serveur nécessite que le module du noyau vsock_loopback soit chargé.

VALEUR DE RETOUR

Cet appel retourne une valeur booléenne.

ERREURS

Cette fonction ne peut pas échouer.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, consultez "Paramètres non-NULL" dans libnbd(3).

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.16.

Si vous devez tester si cette fonction est disponible à la compilation, vérifiez si le macro suivant est défini :

#define LIBNBD_HAVE_NBD_SUPPORTS_VSOCK 1

VOIR AUSSI

nbd_connect_uri(3), nbd_connect_vsock(3), nbd_create(3), libnbd(3).
