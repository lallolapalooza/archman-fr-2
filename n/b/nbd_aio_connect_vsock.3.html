NOM

nbd_aio_connect_vsock - se connecter au serveur NBD via un socket AF_VSOCK

SYNOPIS

#include <libnbd.h>
int nbd_aio_connect_vsock (
      struct nbd_handle *h, uint32_t cid, uint32_t port
    );

DESCRIPTION

Démarre la connexion au serveur NBD via le protocole "AF_VSOCK" au serveur "cid:port". Les paramètres se comportent comme documenté dans nbd_connect_vsock(3).

Vous pouvez vérifier si la tentative de connexion est toujours en cours en appelant nbd_aio_is_connecting(3). Si nbd_set_opt_mode(3) est activé, la connexion est prête pour une négociation manuelle des options une fois que nbd_aio_is_negotiating(3) renvoie vrai ; sinon, la tentative de connexion inclura la poignée de main NBD, et sera prête à être utilisée une fois que nbd_aio_is_ready(3) renverra vrai.

VALEUR RENVOYÉE

Si l'appel réussit, la fonction renvoie 0.

ERREURS

En cas d'erreur, -1 est renvoyé.

Se référer à "GESTION DES ERREURS" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non NULL" dans libnbd(3).

ÉTAT DU HANDLE

nbd_aio_connect_vsock peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion       │ ✅ autorisé             │
│ Connexion en cours                │ ❌ erreur               │
│ Connexion & handshake (opt_mode) │ ❌ erreur               │
│ Connecté au serveur             │ ❌ erreur               │
│ Connexion fermée                │ ❌ erreur               │
│ Handle mort                       │ ❌ erreur               │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.2.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_AIO_CONNECT_VSOCK 1
