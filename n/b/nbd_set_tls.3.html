Paquet: libnbd

nbd_set_tls(3) LIBNBD nbd_set_tls(3)

NOM

nbd_set_tls - activer ou exiger TLS (authentification et chiffrement)

SYNTAXE

#include <libnbd.h>
int nbd_set_tls (
      struct nbd_handle *h, int tls
    );

DESCRIPTION

Active ou exige TLS (connexions authentifiées et chiffrées) vers le serveur NBD. Les paramètres possibles sont :

"LIBNBD_TLS_DISABLE"
Désactiver TLS. (Le paramètre par défaut, sauf si vous utilisez nbd_connect_uri(3) avec une URI qui exige TLS).

Ce paramètre est également nécessaire si vous utilisez nbd_set_opt_mode(3) et que vous souhaitez interagir en clair avec un serveur qui implémente le mode "SELECTIVETLS" du protocole NBD, avant d'activer TLS avec nbd_opt_starttls(3). La plupart des serveurs NBD prenant en charge TLS préfèrent le mode "FORCEDTLS" du protocole NBD, de sorte que ce type d'interaction manuelle a tendance à être utile principalement lors des tests d'intégration.

"LIBNBD_TLS_ALLOW"
Activer TLS si possible.

Cette option est non sécurisée (ou au mieux, elle fait de son mieux) en ce sens que dans certains cas, elle se rabattra sur une connexion non chiffrée et/ou non authentifiée si TLS n'a pas pu être établi. Utilisez "LIBNBD_TLS_REQUIRE" ci-dessous si la connexion doit être chiffrée.

Certains serveurs abandonneront la connexion si TLS échoue, donc le rabattement peut ne pas être possible.

"LIBNBD_TLS_REQUIRE"
Exiger une connexion TLS chiffrée et authentifiée. Échouer systématiquement à se connecter si la connexion n'est pas chiffrée et authentifiée.

En plus d'appeler cette fonction, vous pourriez également avoir besoin de fournir le chemin d'accès au répertoire des certificats (nbd_set_tls_certificates(3)), le nom d'utilisateur (nbd_set_tls_username(3)) et/ou le fichier des clés pré-partagées (PSK) (nbd_set_tls_psk_file(3)). Pour l'instant, lors de l'utilisation de nbd_connect_uri(3), les paramètres de requête d'URI liés à TLS ne sont pas gérés automatiquement. Définir le niveau à une valeur supérieure à zéro échouera si libnbd n'a pas été compilé avec gnutls ; vous pouvez vérifier si c'est le cas avec nbd_supports_tls(3).

VALEUR DE RETOUR

Si l'appel réussit, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Se référer à "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ETAT DU HANDLE

nbd_set_tls peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion        │ ✅ autorisé             │
│ Connexion en cours                   │ ❌ erreur               │
│ Connexion et handshake (opt_mode) │ ❌ erreur               │
│ Connecté au serveur                │ ❌ erreur               │
│ Connexion arrêtée                   │ ❌ erreur               │
│ Handle mort                        │ ❌ erreur               │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de vérifier si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_SET_TLS 1

EXEMPLE

Cet exemple est également disponible sous le nom examples/encryption.c dans le code source de libnbd.

/* Un exemple montrant comment se connecter à un serveur qui utilise
 * le chiffrement TLS.
 *
 * Cela nécessite nbdkit, et psktool de gnutls.
 *
 * Libnbd et nbdkit prennent en charge TLS-PSK, qui est une forme de
 * chiffrement plus simple à déployer. (Bien sûr, le chiffrement basé sur des
 * certificats est également pris en charge, mais il est plus difficile de
 * créer un exemple autonome).
 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <libnbd.h>
#define TMPDIR "/tmp/XXXXXX"
#define KEYS "keys.psk"
#define USERNAME "alice"
static char dir[] = TMPDIR;
static char keys[] = TMPDIR "/" KEYS;
static char cmd[] =
  "psktool -u " USERNAME " -p " TMPDIR "/" KEYS;
/* Supprime le fichier de clés temporaire lorsque le programme
 * se termine.
 */
static void
cleanup_keys (void)
{
  unlink (keys);
  rmdir (dir);
}
/* Crée le fichier de clés temporaire à partager avec le
 * serveur.
 */
static void
create_keys (void)
{
  size_t i;
  if (mkdtemp (dir) == NULL) {
    perror ("mkdtemp");
    exit (EXIT_FAILURE);
  }
  i = strlen (cmd) - strlen (TMPDIR) - strlen (KEYS) - 1;
  memcpy (&cmd[i], dir, strlen (TMPDIR));
  memcpy (keys, dir, strlen (TMPDIR));
  if (system (cmd) != 0) {
    fprintf (stderr, "La commande psktool a échoué\n");
    exit (EXIT_FAILURE);
  }
  atexit (cleanup_keys);
}
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char buf[512];
  create_keys ();
  /* Crée le handle libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Active TLS dans le client. */
  if (nbd_set_tls (nbd, LIBNBD_TLS_REQUIRE) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Active TLS-PSK et passe le nom du fichier de clés. */
  if (nbd_set_tls_psk_file (nbd, keys) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Définit le nom d'utilisateur local pour l'authentification. */
  if (nbd_set_tls_username (nbd, USERNAME) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Exécute nbdkit comme sous-processus, en activant et en exigeant
   * le chiffrement TLS-PSK.
   */
  char *args[] = {
    "nbdkit", "-s", "--exit-with-parent",
    "--tls", "require", "--tls-psk", keys,
    "pattern", "size=1M", NULL
  };
  if (nbd_connect_command (nbd, args) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Lit le premier secteur. */
  if (nbd_pread (nbd, buf, sizeof buf, 0, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Les connexions TLS doivent être fermées. */
  if (nbd_shutdown (nbd, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Ferme le handle libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}
