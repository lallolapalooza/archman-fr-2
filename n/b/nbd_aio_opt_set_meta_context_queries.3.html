NOM

nbd_aio_opt_set_meta_context_queries - sélectionner des contextes méta spécifiques, avec liste de requêtes explicite

SYNTAXE

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, const char *name);
  void *user_data;
  void (*free) (void *user_data);
} nbd_context_callback;
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int nbd_aio_opt_set_meta_context_queries (
      struct nbd_handle *h, char **queries,
      nbd_context_callback context_callback,
      nbd_completion_callback completion_callback
    );

DESCRIPTION

Demande au serveur de fournir tous les contextes méta reconnus passés via "queries", en conjonction avec l'export précédemment spécifié par le plus récent nbd_set_export_name(3) ou nbd_connect_uri(3). Ceci ne peut être utilisé que si nbd_set_opt_mode(3) a activé le mode option. Normalement, cette fonction est redondante, car nbd_opt_go(3) effectue automatiquement la même tâche si les réponses structurées ou les en-têtes étendus ont déjà été négociés. Mais le contrôle manuel des requêtes de contexte méta peut être utile pour tester de manière granulaire comment un serveur gère des séquences de négociation inhabituelles. Souvent, l'utilisation de cette fonction est couplée avec nbd_set_request_meta_context(3) pour contourner la requête automatique de contexte normalement effectuée par nbd_opt_go(3).

Pour déterminer quand la requête se termine, attendez que nbd_aio_is_connecting(3) retourne faux. Ou fournissez le "completion_callback" optionnel qui sera appelé comme décrit dans "Callbacks de complétion" dans libnbd(3), sauf qu'il est automatiquement retiré quelle que soit la valeur de retour. Notez que la détection si le serveur renvoie une erreur (comme fait par la valeur de retour de son homologue synchrone) n'est possible qu'avec un callback de complétion.

VALEUR DE RETOUR

Cet appel retourne un entier ≥ 0.

ERREURS

En cas d'erreur, -1 est retourné.

Reportez-vous à "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h", "queries". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ETAT DU HANDLE

nbd_aio_opt_set_meta_context_queries peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion      │ ❌ erreur                │
│ Connexion en cours                 │ ❌ erreur                │
│ Connexion & handshake (opt_mode) │ ✅ autorisé             │
│ Connecté au serveur                │ ❌ erreur                │
│ Connexion fermée                   │ ❌ erreur                │
│ Handle mort                        │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.16.

Si vous avez besoin de tester si cette fonction est disponible à la compilation, vérifiez si le macro suivant est défini :

#define LIBNBD_HAVE_NBD_AIO_OPT_SET_META_CONTEXT_QUERIES 1
