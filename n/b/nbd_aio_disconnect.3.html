NOM

nbd_aio_disconnect - se déconnecter du serveur NBD

SYNOPSIS

#include <libnbd.h>
int nbd_aio_disconnect (
      struct nbd_handle *h, uint32_t flags
    );

DESCRIPTION

Émet la commande de déconnexion vers le serveur NBD. Ce n'est pas une commande normale car les serveurs NBD ne sont pas obligés d'envoyer une réponse. Vous devriez plutôt attendre que nbd_aio_is_closed(3) devienne vrai sur la connexion. Une fois cette commande émise, vous ne pourrez plus émettre d'autres commandes.

Bien que libnbd ne vous empêche pas d'émettre cette commande tout en attendant les réponses des commandes précédentes, le protocole NBD recommande d'attendre qu'il n'y ait plus d'autres commandes en cours (voir nbd_aio_in_flight(3)), pour donner au serveur une meilleure chance de terminer proprement.

Le paramètre "flags" doit être 0 pour l'instant (il existe pour de futures extensions du protocole NBD). Il n'y a pas d'équivalent synchrone direct ; cependant, nbd_shutdown(3) appellera cette fonction si approprié.

VALEUR RENVOYÉE

Si l'appel réussit, la fonction renvoie 0.

ERREURS

En cas d'erreur, -1 est renvoyé.

Consultez "ERROR HANDLING" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Non-NULL parameters" dans libnbd(3).

ÉTAT DU HANDLE

nbd_aio_disconnect peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion      │ ❌ erreur                │
│ Connexion en cours                 │ ❌ erreur                │
│ Connexion et handshake (opt_mode) │ ❌ erreur                │
│ Connecté au serveur              │ ✅ autorisé             │
│ Connexion fermée                  │ ❌ erreur                │
│ Handle mort                        │ ❌ erreur                │
└──────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si le macro suivant est défini :

#define LIBNBD_HAVE_NBD_AIO_DISCONNECT 1

VOIR AUSSI

nbd_aio_in_flight(3), nbd_aio_is_closed(3), nbd_create(3), nbd_shutdown(3), libnbd(3).
