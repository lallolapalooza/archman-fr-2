NOM

nbd_aio_trim - envoie une commande trim au serveur NBD

SYNOPSIS

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int64_t nbd_aio_trim (
          struct nbd_handle *h, uint64_t count,
          uint64_t offset,
          nbd_completion_callback completion_callback,
          uint32_t flags
        );

DESCRIPTION

Émet une commande trim au serveur NBD.

Pour vérifier si la commande s'est terminée, appelez nbd_aio_command_completed(3). Ou fournissez le paramètre optionnel "completion_callback" qui sera appelé comme décrit dans "Callbacks de complétion" dans libnbd(3).

Les autres paramètres se comportent comme documenté dans nbd_trim(3).

Par défaut, libnbd rejettera les tentatives d'utilisation de cette fonction avec des paramètres susceptibles d'entraîner une défaillance du serveur, comme la demande d'un drapeau de commande inconnu. La fonction nbd_set_strict_mode(3) peut être utilisée pour modifier les scénarios qui doivent attendre une réponse du serveur plutôt que d'échouer rapidement.

VALEUR DE RETOUR

Cet appel retourne le cookie de 64 bits de la commande. Le cookie est ≥ 1. Les cookies sont uniques (par handle libnbd, pas globalement).

ERREURS

En cas d'erreur, -1 est retourné.

Reportez-vous à "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ÉTAT DU HANDLE

nbd_aio_trim peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion     │ ❌ erreur                │
│ Connexion en cours                      │ ❌ erreur                │
│ Connexion et handshake (opt_mode) │ ❌ erreur                │
│ Connecté au serveur             │ ✅ autorisé            │
│ Connexion interrompue                │ ❌ erreur                │
│ Handle mort                         │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de tester la disponibilité de cette fonction au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_AIO_TRIM 1
