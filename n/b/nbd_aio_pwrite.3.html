NOM

nbd_aio_pwrite - écrire sur le serveur NBD

SYNOPIS

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int64_t nbd_aio_pwrite (
          struct nbd_handle *h, const void *buf,
          size_t count, uint64_t offset,
          nbd_completion_callback completion_callback,
          uint32_t flags
        );

DESCRIPTION

Émettre une commande d'écriture sur le serveur NBD.

Pour vérifier si la commande est terminée, appelez nbd_aio_command_completed(3). Ou fournissez le paramètre optionnel "completion_callback" qui sera invoqué comme décrit dans "Callbacks d'achèvement" dans libnbd(3).

Notez que vous devez vous assurer que "buf" est valide jusqu'à ce que la commande soit terminée. Les autres paramètres se comportent comme documenté dans nbd_pwrite(3).

Par défaut, libnbd rejettera les tentatives d'utilisation de cette fonction avec des paramètres susceptibles d'entraîner une défaillance du serveur, tels que la demande d'un drapeau de commande inconnu. La fonction nbd_set_strict_mode(3) peut être utilisée pour modifier les scénarios qui doivent attendre une réponse du serveur plutôt que de réussir rapidement.

VALEUR DE RETOUR

Cet appel retourne le cookie de 64 bits de la commande. Le cookie est ≥ 1. Les cookies sont uniques (par handle libnbd, pas globalement).

ERREURS

En cas d'erreur, -1 est retourné.

Référez-vous à "GESTION DES ERREURS" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h", "buf". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ÉTAT DU HANDLE

nbd_aio_pwrite peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion   │ ❌ erreur                │
│ Connexion en cours                 │ ❌ erreur                │
│ Connexion en cours & handshake (opt_mode) │ ❌ erreur                │
│ Connecté au serveur             │ ✅ autorisé             │
│ Connexion fermée                │ ❌ erreur                │
│ Handle mort                         │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_AIO_PWRITE 1
