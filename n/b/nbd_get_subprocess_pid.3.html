NOM

nbd_get_subprocess_pid - obtenir l'identifiant du processus du sous-processus

SYNTAXE

#include <libnbd.h>
int64_t nbd_get_subprocess_pid (
          struct nbd_handle *h
        );

DESCRIPTION

Pour les connexions qui créent un sous-processus tel que nbd_connect_command(3), ceci renvoie l'identifiant du processus (PID) du sous-processus. Ceci n'est pris en charge que sur certaines plateformes.

Ceci est principalement utile dans des cas de débogage. Par exemple, ceci pourrait être utilisé pour savoir où attacher gdb(1) pour diagnostiquer un crash dans le sous-processus du serveur NBD.

VALEUR DE RETOUR

Cet appel renvoie un entier signé de 64 bits ≥ 0.

ERREURS

En cas d'erreur, -1 est renvoyé.

Reportez-vous à "GESTION DES ERREURS" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.22.

Si vous devez tester la disponibilité de cette fonction au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_GET_SUBPROCESS_PID 1

VOIR AUSSI

nbd_connect_command(3), nbd_create(3), nbd_kill_subprocess(3), libnbd(3), fork(2), gdb(1).
