Paquet: libnbd

Licences: LGPL-2.1-or-later

nbd_supports_uri(3) LIBNBD nbd_supports_uri(3)

NOM

nbd_supports_uri - vrai si libnbd a été compilé avec le support des URI NBD

SYNTAXE

#include <libnbd.h>
int nbd_supports_uri (
      struct nbd_handle *h
    );

DESCRIPTION

Retourne vrai si libnbd a été compilé avec libxml2, ce qui est requis pour supporter les URI NBD, ou faux sinon.

VALEUR DE RETOUR

Cet appel retourne une valeur booléenne.

ERREURS

Cette fonction ne peut pas échouer.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de vérifier si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_SUPPORTS_URI 1

VOIR AUSSI

nbd_aio_connect_uri(3), nbd_connect_uri(3), nbd_create(3), nbd_get_uri(3), nbd_is_uri(3), libnbd(3).
