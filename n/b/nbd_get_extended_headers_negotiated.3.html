NOM

nbd_get_extended_headers_negotiated - vérifier si les en-têtes étendus sont en cours d'utilisation

SYNTAXE

#include <libnbd.h>
int nbd_get_extended_headers_negotiated (
      struct nbd_handle *h
    );

DESCRIPTION

Après la connexion, vous pouvez appeler cette fonction pour savoir si la connexion utilise des en-têtes étendus. Notez que ce paramètre est collant ; il peut renvoyer vrai même après qu'un deuxième appel à nbd_opt_extended_headers(3) renvoie faux parce que le serveur a détecté une demande dupliquée.

Lorsque les en-têtes étendus ne sont pas utilisés, les commandes sont limitées à une longueur de 32 bits, même lorsque l'API libnbd utilise un paramètre de 64 bits pour exprimer la longueur. Mais même lorsque les en-têtes étendus sont pris en charge, le serveur peut appliquer d'autres limites, visibles via nbd_get_block_size(3).

Notez que lorsque les en-têtes étendus sont négociés, vous devriez préférer l'utilisation de nbd_block_status_64(3) plutôt que nbd_block_status(3) si l'un des méta-contextes que vous avez demandés via nbd_add_meta_context(3) pourrait renvoyer des valeurs de statut de 64 bits ; cependant, tous les méta-contextes connus couverts par les constantes actuelles de "LIBNBD_CONTEXT_*" ne renvoient que des statuts de 32 bits.

VALEUR DE RETOUR

Cet appel renvoie une valeur booléenne.

ERREURS

En cas d'erreur, -1 est renvoyé.

Consultez "GESTION DES ERREURS" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ETAT DU HANDLE

nbd_get_extended_headers_negotiated peut être appelé lorsque le handle est dans les états suivants :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion      │ ❌ erreur                │
│ Connexion en cours                │ ❌ erreur                │
│ Connexion & négociation (opt_mode) │ ✅ autorisé             │
│ Connecté au serveur               │ ✅ autorisé             │
│ Connexion fermée                  │ ✅ autorisé             │
│ Handle mort                       │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.18.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_GET_EXTENDED_HEADERS_NEGOTIATED 1
