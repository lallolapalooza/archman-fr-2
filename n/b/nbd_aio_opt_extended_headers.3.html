nbd_aio_opt_extended_headers(3)

Paquet: libnbd

nbd_aio_opt_extended_headers(3) LIBNBD nbd_aio_opt_extended_headers(3)

NOM

nbd_aio_opt_extended_headers - demande au serveur d'activer les en-têtes étendus

SYNTAXE

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int nbd_aio_opt_extended_headers (
      struct nbd_handle *h,
      nbd_completion_callback completion_callback
    );

DESCRIPTION

Demande au serveur d'utiliser des en-têtes étendus, en envoyant "NBD_OPT_EXTENDED_HEADERS". Cela se comporte comme la contrepartie synchrone nbd_opt_extended_headers(3), sauf que elle n'attend pas la réponse du serveur.

Pour déterminer quand la requête se termine, attendez que nbd_aio_is_connecting(3) retourne false. Ou fournissez le "completion_callback" optionnel qui sera appelé comme décrit dans « Callbacks d'achèvement » dans libnbd(3), sauf qu'il est automatiquement retiré quel que soit la valeur de retour. Notez que la détection si le serveur renvoie une erreur (comme le fait la valeur de retour de la contrepartie synchrone) n'est possible qu'avec un callback d'achèvement.

VALEUR DE RETOUR

Si l'appel réussit, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Reportez-vous à « GESTION DES ERREURS » dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir « Paramètres non NULL » dans libnbd(3).

ÉTAT DU HANDLE

nbd_aio_opt_extended_headers peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion   │ ❌ erreur                │
│ Connexion en cours              │ ❌ erreur                │
│ Connexion & handshake (opt_mode) │ ✅ autorisé             │
│ Connecté au serveur             │ ❌ erreur                │
│ Connexion fermée                │ ❌ erreur                │
│ Handle mort                       │ ❌ erreur                │
└───────────────────────────────────────┴────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.18.

Si vous avez besoin de vérifier si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_AIO_OPT_EXTENDED_HEADERS 1

VOIR AUSSI

nbd_aio_is_connecting(3), nbd_create(3), nbd_opt_extended_headers(3), nbd_set_opt_mode(3), libnbd(3).
