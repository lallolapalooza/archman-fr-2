NOM

nbd_get_meta_context - retourne la i-ème requête de contexte méta

SYNTAXE

#include <libnbd.h>
char * nbd_get_meta_context (
         struct nbd_handle *h, size_t i
       );

DESCRIPTION

Lors de la connexion, libnbd peut négocier zéro ou plusieurs contextes méta avec le serveur. Les contextes méta sont des fonctionnalités (telles que "base:allocation") qui décrivent les informations retournées par la commande nbd_block_status_64(3) (pour "base:allocation", il s'agit de savoir si les blocs de données sont alloués, nuls ou épars).

Cette commande retourne la i-ème requête de contexte méta, telle qu'ajoutée par nbd_add_meta_context(3), et bornée par nbd_get_nr_meta_contexts(3).

VALEUR DE RETOUR

Cet appel retourne une chaîne de caractères. L'appelant doit libérer la chaîne retournée pour éviter une fuite de mémoire.

ERREURS

En cas d'erreur, "NULL" est retourné.

Reportez-vous à "GESTION DES ERREURS" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.6.

Si vous avez besoin de vérifier si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_GET_META_CONTEXT 1

VOIR AUSSI

nbd_add_meta_context(3), nbd_block_status_64(3), nbd_can_meta_context(3), nbd_clear_meta_contexts(3), nbd_create(3), nbd_get_nr_meta_contexts(3), libnbd(3).
