nbd_set_debug_callback(3) LIBNBD nbd_set_debug_callback(3)

NOM

nbd_set_debug_callback - définir la fonction de rappel de débogage

SYNOPSIS

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, const char *context,
                   const char *msg);
  void *user_data;
  void (*free) (void *user_data);
} nbd_debug_callback;
int nbd_set_debug_callback (
      struct nbd_handle *h,
      nbd_debug_callback debug_callback
    );

DESCRIPTION

Définit la fonction de rappel de débogage. Cette fonction est appelée lorsque la bibliothèque émet des messages de débogage, lorsque le débogage est activé sur une poignée. Les paramètres de la fonction de rappel sont "user_data" passé à cette fonction, le nom de la fonction libnbd émettant le message de débogage ("context"), et le message lui-même ("msg"). Si aucune fonction de rappel de débogage n'est définie sur une poignée, les messages sont imprimés sur "stderr".

La fonction de rappel ne doit pas appeler les API "nbd_*" sur la même poignée car elle peut être appelée tout en détenant le verrou de la poignée et provoquera une impasse.

VALEUR DE RETOUR

En cas de succès, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Consultez "GESTION DES ERREURS" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non NULL" dans libnbd(3).

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_SET_DEBUG_CALLBACK 1

VOIR AUSSI

nbd_create(3), libnbd(3).
