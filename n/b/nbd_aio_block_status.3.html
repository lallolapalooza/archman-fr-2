NOM

nbd_aio_block_status - envoyer une commande d'état de bloc, avec rappel 32 bits

SYNOPSIS

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data,
                   const char *metacontext,
                   uint64_t offset, uint32_t *entries,
                   size_t nr_entries, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_extent_callback;
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int64_t nbd_aio_block_status (
          struct nbd_handle *h, uint64_t count,
          uint64_t offset,
          nbd_extent_callback extent_callback,
          nbd_completion_callback completion_callback,
          uint32_t flags
        );

DESCRIPTION

Envoie la commande d'état de bloc au serveur NBD.

Pour vérifier si la commande s'est terminée, appelez nbd_aio_command_completed(3). Ou fournissez le "completion_callback" optionnel qui sera invoqué comme décrit dans "Callbacks d'achèvement" dans libnbd(3).

Les autres paramètres se comportent comme documenté dans nbd_block_status(3).

Cette fonction est intrinsèquement limitée aux valeurs 32 bits. Si le serveur répond avec une étendue plus grande, la longueur de cette étendue sera tronquée juste en dessous de 32 bits et toutes les autres étendues du serveur seront ignorées. Si le serveur répond avec une valeur d'état supérieure à 32 bits (uniquement possible lorsque des en-têtes étendus sont utilisés), la fonction de rappel recevra une erreur "EOVERFLOW". Pour obtenir les informations complètes sur l'étendue d'un serveur qui prend en charge les étendues 64 bits, vous devez utiliser nbd_aio_block_status_64(3).

Par défaut, libnbd rejettera les tentatives d'utilisation de cette fonction avec des paramètres susceptibles d'entraîner une défaillance du serveur, tels que la demande d'un drapeau de commande inconnu. La fonction nbd_set_strict_mode(3) peut être utilisée pour modifier les scénarios qui doivent attendre une réponse du serveur plutôt que de se terminer rapidement.

VALEUR DE RETOUR

Cet appel retourne le cookie 64 bits de la commande. Le cookie est ≥ 1. Les cookies sont uniques (par handle libnbd, pas globalement).

ERREURS

En cas d'erreur, -1 est retourné.

Se référer à "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NUL : "h". Pour plus d'informations, voir "Paramètres non nuls" dans libnbd(3).

ÉTAT DU HANDLE

nbd_aio_block_status peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion       │ ❌ erreur               │
│ Connexion en cours                │ ❌ erreur               │
│ Connexion & négociation (opt_mode) │ ❌ erreur               │
│ Connecté au serveur               │ ✅ autorisé             │
│ Connexion fermée                  │ ❌ erreur               │
│ Handle mort                       │ ❌ erreur               │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous devez tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_AIO_BLOCK_STATUS 1
