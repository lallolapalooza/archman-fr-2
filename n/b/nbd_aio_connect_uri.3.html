NOM

nbd_aio_connect_uri - se connecter à une URI NBD

SYNTAXE

#include <libnbd.h>
int nbd_aio_connect_uri (
      struct nbd_handle *h, const char *uri
    );

DESCRIPTION

Commence la connexion à l'URI NBD "uri". Les paramètres se comportent comme documenté dans nbd_connect_uri(3).

Vous pouvez vérifier si la tentative de connexion est toujours en cours en appelant nbd_aio_is_connecting(3). Si nbd_set_opt_mode(3) est activé, la connexion est prête pour la négociation manuelle des options une fois que nbd_aio_is_negotiating(3) renvoie vrai ; sinon, la tentative de connexion inclura la poignée de main NBD, et sera prête à être utilisée une fois que nbd_aio_is_ready(3) renvoie vrai.

VALEUR DE RETOUR

Si l'appel réussit, la fonction renvoie 0.

ERREURS

En cas d'erreur, -1 est renvoyé.

Se référer à "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h", "uri". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ETAT DU HANDLE

nbd_aio_connect_uri peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion       │ ✅ autorisé             │
│ Connexion en cours                  │ ❌ erreur               │
│ Connexion & poignée de main (opt_mode) │ ❌ erreur               │
│ Connecté au serveur             │ ❌ erreur               │
│ Connexion fermée                │ ❌ erreur               │
│ Handle mort                         │ ❌ erreur               │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de vérifier si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_AIO_CONNECT_URI 1

VOIR AUSSI

nbd_aio_is_connecting(3), nbd_aio_is_negotiating(3), nbd_aio_is_ready(3), nbd_connect_uri(3), nbd_create(3), nbd_set_opt_mode(3), libnbd(3), https://github.com/NetworkBlockDevice/nbd/blob/master/doc/uri.md.
