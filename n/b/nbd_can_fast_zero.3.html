nbd_can_fast_zero(3) LIBNBD nbd_can_fast_zero(3)

NOM

nbd_can_fast_zero - le serveur prend en charge le drapeau zero rapide ?

SYNTAXE

#include <libnbd.h>
int nbd_can_fast_zero (
      struct nbd_handle *h
    );

DESCRIPTION

Retourne vrai si le serveur prend en charge l'utilisation du drapeau "LIBNBD_CMD_FLAG_FAST_ZERO" avec la commande zero (voir nbd_zero(3), nbd_aio_zero(3)). Retourne faux si le serveur ne le prend pas en charge.

Cet appel ne bloque pas, car il renvoie des informations qui sont enregistrées dans le descripteur lors de la négociation du protocole NBD.

VALEUR DE RETOUR

Cet appel renvoie une valeur booléenne.

ERREURS

En cas d'erreur, -1 est retourné.

Se référer à "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ETAT DU DESCRIPTEUR

nbd_can_fast_zero peut être appelé lorsque le descripteur est dans les états suivants :

┌─────────────────────────────────────┬─────────────────────────┐
│ Descripteur créé, avant connexion  │ ❌ erreur                │
│ Connexion en cours                  │ ❌ erreur                │
│ Connexion & négociation (opt_mode)│ ✅ autorisé            │
│ Connecté au serveur             │ ✅ autorisé            │
│ Connexion fermée                  │ ✅ autorisé            │
│ Descripteur mort                  │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.2.

Si vous avez besoin de vérifier si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_CAN_FAST_ZERO 1

EXEMPLE

Cet exemple est également disponible sous le nom examples/server-flags.c dans le code source de libnbd.

/* Cet exemple montre comment se connecter à un serveur NBD
 * et afficher les drapeaux d'export.
 *
 * Vous pouvez le tester avec nbdkit comme suit :
 *
 * nbdkit -U - memory 1M \
 *   --run './server-flags $unixsocket'
 */
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char *str;
  int flag;
  if (argc != 2) {
    fprintf (stderr, "%s socket\n", argv[0]);
    exit (EXIT_FAILURE);
  }
  /* Créer le descripteur libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Demander des informations complètes. */
#if LIBNBD_HAVE_NBD_SET_FULL_INFO /* Ajouté en 1.4 */
  if (nbd_set_full_info (nbd, true) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
#endif
  /* Se connecter au serveur NBD via un
   * socket de domaine Unix.
   */
  if (nbd_connect_unix (nbd, argv[1]) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Voir si le serveur a fourni des détails supplémentaires,
   * en utilisant les fonctions ajoutées en 1.4
   */
#if LIBNBD_HAVE_NBD_GET_EXPORT_DESCRIPTION
  str = nbd_get_canonical_export_name (nbd);
  if (str)
    printf ("canonical_name = %s\n", str);
  free (str);
  str = nbd_get_export_description (nbd);
  if (str)
    printf ("description = %s\n", str);
  free (str);
#endif
  /* Lire et afficher les drapeaux. */
#define PRINT_FLAG(flag_fn)                     \
  flag = flag_fn (nbd);                         \
  if (flag == -1) {                             \
    fprintf (stderr, "%s\n", nbd_get_error ()); \
    exit (EXIT_FAILURE);                        \
  }                                             \
  printf (#flag_fn " = %s\n",                   \
          flag ? "true" : "false");
  PRINT_FLAG (nbd_can_cache);
  PRINT_FLAG (nbd_can_df);
  PRINT_FLAG (nbd_can_flush);
  PRINT_FLAG (nbd_can_fua);
  PRINT_FLAG (nbd_can_multi_conn);
  PRINT_FLAG (nbd_can_trim);
  PRINT_FLAG (nbd_can_zero);
#if LIBNBD_HAVE_NBD_CAN_FAST_ZERO
  /* Ajouté en 1.2 */
  PRINT_FLAG (nbd_can_fast_zero);
#endif
#if LIBNBD_HAVE_NBD_CAN_BLOCK_STATUS_PAYLOAD
  /* Ajouté en 1.18 */
  PRINT_FLAG (nbd_can_block_status_payload);
#endif
  PRINT_FLAG (nbd_is_read_only);
  PRINT_FLAG (nbd_is_rotational);
  /* Fermer le descripteur libnbd. */
  nbd_close (nbd);
  exit (EXIT_SUCCESS);
}

NOM

nbd_can_fast_zero - Vérifie si le périphérique NBD peut renvoyer des zéros rapidement.

SYNOPSIS

#include <libnbd.h>

int nbd_can_fast_zero(NBDClient *client, bool *can_zero);

DESCRIPTION

La fonction nbd_can_fast_zero interroge le serveur NBD connecté via client pour savoir s'il prend en charge le renvoi rapide de zéros. Cela est utile pour les opérations d'allocation de blocs qui nécessitent de renvoyer rapidement des zéros, comme fallocate ou lseek avec SEEK_DATA.

Le résultat est stocké dans la variable booléenne pointée par can_zero.

VALEUR DE RETOUR

En cas de succès, nbd_can_fast_zero retourne 0. En cas d'erreur, elle retourne un code d'erreur négatif :

  • -ENOENT: Le client NBD n'est pas connecté.
  • -ENOTSUP: Le serveur NBD ne prend pas en charge cette fonctionnalité.
  • -EIO: Une erreur d'entrée/sortie s'est produite lors de la communication avec le serveur.

ÉTAT DE LA GESTION

Cette fonction doit être appelée après que la connexion au serveur NBD a été établie et avant que les opérations de lecture/écriture sur le périphérique ne soient effectuées.

VERSION

Cette fonction est disponible depuis la version 1.14 de libnbd.

EXEMPLE

#include <stdio.h>
#include <stdlib.h>
#include <libnbd.h>

int main() {
    NBDClient *client = NULL;
    int ret;
    bool can_zero;

    // Connexion au serveur NBD (remplacer par votre adresse)
    client = nbd_connect("127.0.0.1");
    if (client == NULL) {
        fprintf(stderr, "Erreur de connexion au serveur NBD.\n");
        return 1;
    }

    // Vérification si le serveur peut renvoyer des zéros rapidement
    ret = nbd_can_fast_zero(client, &can_zero);
    if (ret == 0) {
        if (can_zero) {
            printf("Le serveur NBD prend en charge le renvoi rapide de zéros.\n");
        } else {
            printf("Le serveur NBD ne prend pas en charge le renvoi rapide de zéros.\n");
        }
    } else {
        fprintf(stderr, "Erreur lors de la vérification du renvoi rapide de zéros: %d\n", ret);
    }

    // Déconnexion
    nbd_shutdown(client);
    nbd_disconnect(client);

    return 0;
}

nbd_connect(3), nbd_disconnect(3), nbd_shutdown(3)
