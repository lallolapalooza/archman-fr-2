NOM

nbd_get_uri - construire une URI NBD pour une connexion

SYNOPSIS

#include <libnbd.h>
char * nbd_get_uri (
         struct nbd_handle *h
       );

DESCRIPTION

Ceci fait un effort pour construire une URI NBD qui pourrait être utilisée pour se reconnecter au même serveur (en utilisant nbd_connect_uri(3)).

Dans certains cas, il n'y a pas assez d'informations dans le handle pour créer une URI avec succès (par exemple, si vous vous êtes connecté avec nbd_connect_socket(3)). Dans de tels cas, l'appel retourne "NULL" et des informations diagnostiques supplémentaires sont disponibles via nbd_get_errno(3) et nbd_get_error(3) comme d'habitude.

Même si une URI est retournée, il n'est pas garanti qu'elle fonctionne, et elle pourrait ne pas être optimale.

L'option nbdinfo --uri est un moyen d'accéder à cette API depuis des scripts shell.

VALEUR DE RETOUR

Cet appel retourne une chaîne de caractères. L'appelant doit libérer la chaîne retournée pour éviter une fuite de mémoire.

ERREURS

En cas d'erreur, "NULL" est retourné.

Voir la section "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ÉTAT DU HANDLE

nbd_get_uri peut être appelé lorsque le handle est dans les états suivants :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion      │ ❌ erreur                │
│ Connexion en cours                │ ✅ autorisé             │
│ Connexion et handshake (opt_mode) │ ✅ autorisé             │
│ Connecté au serveur               │ ✅ autorisé             │
│ Connexion interrompue             │ ✅ autorisé             │
│ Handle mort                       │ ✅ autorisé             │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.8.

Si vous avez besoin de tester si cette fonction est disponible à la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_GET_URI 1
