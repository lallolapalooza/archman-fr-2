nbd_set_debug(3) LIBNBD nbd_set_debug(3)

NOM

nbd_set_debug - activer ou désactiver le drapeau de débogage

SYNTAXE

#include <libnbd.h>
int nbd_set_debug (
      struct nbd_handle *h, bool debug
    );

DESCRIPTION

Active ou désactive le drapeau de débogage. Lorsque le débogage est activé, les messages de débogage de la bibliothèque sont imprimés sur stderr, à moins qu'un rappel de débogage n'ait également été défini (voir nbd_set_debug_callback(3)) auquel cas ils sont envoyés à cette fonction. Ce drapeau est désactivé par défaut sur les nouvelles poignées créées, sauf si "LIBNBD_DEBUG=1" est défini dans l'environnement, auquel cas il est activé par défaut.

VALEUR DE RETOUR

Si l'appel réussit, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Se référer à "GESTION DES ERREURS" dans libnbd(3) pour obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non NULL" dans libnbd(3).

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de vérifier si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_SET_DEBUG 1

VOIR AUSSI

nbd_create(3), nbd_set_debug_callback(3), nbd_set_handle_name(3), libnbd(3).
