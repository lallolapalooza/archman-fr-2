nbd_connect_command(3) LIBNBD nbd_connect_command(3)

NOM

nbd_connect_command - se connecter à une commande serveur NBD

SYNOPSIS

#include <libnbd.h>
int nbd_connect_command (
      struct nbd_handle *h, char **argv
    );

DESCRIPTION

Exécute la commande en tant que sous-processus et s'y connecte via stdin/stdout. Ceci est destiné à être utilisé avec des serveurs NBD qui peuvent se comporter comme des clients inetd, tels que nbdkit(1) utilisant l'option -s/--single, et nbd-server(1) avec le numéro de port réglé sur 0.

Pour exécuter qemu-nbd(1), utilisez plutôt nbd_connect_systemd_socket_activation(3).

Sous-processus

Libnbd va forker la commande "argv" et lui passer le socket NBD en utilisant les descripteurs de fichiers 0 et 1 (stdin/stdout) :

┌─────────┬─────────┐    ┌────────────────┐
│ program │ libnbd  │    │   serveur NBD  │
│         │         │    │       (argv)   │
│         │ socket ╍╍╍╍╍╍╍╍▶ stdin/stdout │
└─────────┴─────────┘    └────────────────┘

Lorsque le handle NBD est fermé, le sous-processus serveur est tué.

Cet appel retourne lorsque la connexion a été établie. Par défaut, cela va jusqu'à la phase de transmission, mais nbd_set_opt_mode(3) peut être utilisé pour un contrôle manuel de la négociation des options effectuée avant la phase de transmission.

VALEUR RENVOYÉE

Si l'appel réussit, la fonction retourne 0.

ERREURS

En cas d'erreur, -1 est retourné.

Consultez "ERROR HANDLING" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h", "argv". Pour plus d'informations, voir "Non-NULL parameters" dans libnbd(3).

ÉTAT DU HANDLE

nbd_connect_command peut être appelé lorsque le handle est dans l'état suivant :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant la connexion      │ ✅ autorisé             │
│ Connexion en cours                      │ ❌ erreur               │
│ Connexion & handshake (opt_mode) │ ❌ erreur               │
│ Connecté au serveur                 │ ❌ erreur               │
│ Connexion fermée                    │ ❌ erreur               │
│ Handle mort                         │ ❌ erreur               │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.0.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_CONNECT_COMMAND 1

EXEMPLE

Cet exemple est également disponible sous forme de examples/connect-command.c dans le code source de libnbd.

/* Cet exemple montre comment exécuter un serveur NBD
 * (nbdkit) en tant que sous-processus de libnbd.
 */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <libnbd.h>
int
main (int argc, char *argv[])
{
  struct nbd_handle *nbd;
  char wbuf[512], rbuf[512];
  size_t i;
  /* Créez le handle libnbd. */
  nbd = nbd_create ();
  if (nbd == NULL) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Lancez nbdkit en tant que sous-processus. */
  char *args[] = {
    "nbdkit",
    /* Vous devez utiliser ‘-s’ (qui indique à nbdkit de servir
     * une connexion unique sur stdin/stdout).
     */
    "-s",
    /* Il est recommandé d'utiliser ‘--exit-with-parent’
     * pour s'assurer que nbdkit est toujours nettoyé même
     * si le programme principal plante.
     */
    "--exit-with-parent",
    /* Utilisez ceci pour activer le débogage de nbdkit. */
    "-v",
    /* Le nom du plugin nbdkit - c'est un disque RAM. */
    "memory", "size=1M",
    /* Utilisez NULL pour terminer la liste des arguments. */
    NULL
  };
  if (nbd_connect_command (nbd, args) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Écrivez des données aléatoires dans le premier secteur. */
  for (i = 0; i < sizeof wbuf; ++i)
    wbuf[i] = i % 13;
  if (nbd_pwrite (nbd, wbuf, sizeof wbuf, 0, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Lisez le premier secteur. */
  if (nbd_pread (nbd, rbuf, sizeof rbuf, 0, 0) == -1) {
    fprintf (stderr, "%s\n", nbd_get_error ());
    exit (EXIT_FAILURE);
  }
  /* Fermez le handle libnbd. */
  nbd_close (nbd);
  /* Ce qui a été lu doit être exactement identique à ce qui
   * a été écrit.
   */
  if (memcmp (rbuf, wbuf, sizeof rbuf) != 0) {
    fprintf (stderr, "ÉCHEC : "
             "les données lues ne correspondent pas aux données écrites\n");
    exit (EXIT_FAILURE);
  }
  exit (EXIT_SUCCESS);
}
