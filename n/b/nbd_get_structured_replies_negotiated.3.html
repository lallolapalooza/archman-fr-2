NOM

nbd_get_structured_replies_negotiated - vérifier si les réponses structurées sont utilisées

SYNOPSIS

#include <libnbd.h>
int nbd_get_structured_replies_negotiated (
      struct nbd_handle *h
    );

DESCRIPTION

Après la connexion, vous pouvez appeler cette fonction pour savoir si la connexion utilise des réponses structurées. Notez que ce paramètre est persistant ; il peut renvoyer vrai même après qu'un deuxième appel à nbd_opt_structured_reply(3) ait renvoyé faux, car le serveur a détecté une requête dupliquée.

Notez que si la connexion négocie des en-têtes étendus, cette fonction renvoie vrai (car les en-têtes étendus impliquent des réponses structurées) même si aucune requête explicite pour des réponses structurées n'a été tentée.

VALEUR DE RETOUR

Cet appel renvoie une valeur booléenne.

ERREURS

En cas d'erreur, -1 est renvoyé.

Consultez "GESTION DES ERREURS" dans libnbd(3) pour savoir comment obtenir plus de détails sur l'erreur.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

ÉTAT DU HANDLE

nbd_get_structured_replies_negotiated peut être appelée lorsque le handle est dans les états suivants :

┌─────────────────────────────────────┬─────────────────────────┐
│ Handle créé, avant connexion     │ ❌ erreur                │
│ Connexion en cours                  │ ❌ erreur                │
│ Connexion & handshake (opt_mode) │ ✅ autorisé             │
│ Connecté au serveur             │ ✅ autorisé             │
│ Connexion interrompue            │ ✅ autorisé             │
│ Handle mort                         │ ❌ erreur                │
└─────────────────────────────────────┴─────────────────────────┘

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.2.

Si vous avez besoin de tester si cette fonction est disponible au moment de la compilation, vérifiez si le macro suivant est défini :

#define LIBNBD_HAVE_NBD_GET_STRUCTURED_REPLIES_NEGOTIATED 1

VOIR AUSSI
