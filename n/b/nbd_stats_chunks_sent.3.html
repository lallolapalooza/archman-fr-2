NOM

nbd_stats_chunks_sent - statistiques des morceaux envoyés sur la connexion jusqu'à présent

SYNOPIS

#include <libnbd.h>
uint64_t nbd_stats_chunks_sent (
           struct nbd_handle *h
         );

DESCRIPTION

Retourne le nombre de morceaux que le client a envoyés au serveur, où un morceau est un groupe d'octets délimité par un nombre magique qui ne peut pas être subdivisé davantage sans enfreindre le protocole.

Ce nombre n'est pas nécessairement lié au nombre d'appels API effectués, ni au nombre de paquets TCP envoyés sur la connexion.

VALEUR DE RETOUR

Cet appel retourne un compteur.

ERREURS

Cette fonction n'échoue pas.

Les paramètres suivants ne doivent pas être NULL : "h". Pour plus d'informations, voir "Paramètres non-NULL" dans libnbd(3).

VERSION

Cette fonction est apparue pour la première fois dans libnbd 1.16.

Si vous avez besoin de vérifier si cette fonction est disponible au moment de la compilation, vérifiez si la macro suivante est définie :

#define LIBNBD_HAVE_NBD_STATS_CHUNKS_SENT 1

VOIR AUSSI

nbd_create(3), nbd_set_strict_mode(3), nbd_stats_bytes_received(3), nbd_stats_bytes_sent(3), nbd_stats_chunks_received(3), libnbd(3).
