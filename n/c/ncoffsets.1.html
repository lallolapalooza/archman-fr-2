NOM

ncoffsets - affiche les décalages de fichiers de début/fin pour les variables netCDF

SYNTAXE

ncoffsets [-h] | [-x] | [-sgr] [-v var1[,...]] fichier

DESCRIPTION

ncoffsets affiche les informations de décalage de fichier des variables définies dans un fichier netCDF donné. Le décalage de fin signalé est un décalage exclusif, c'est-à-dire 1 octet de plus que le dernier octet occupé par la variable. En d'autres termes, le décalage de fin est égal à la somme du décalage de début et de la taille de la variable. Pour les variables d'enregistrement, seuls les décalages du premier enregistrement sont affichés. Ajoutez l'option -r pour afficher les décalages de tous les enregistrements.

Si aucun argument n'est donné, les informations d'utilisation de la commande sont affichées.

OPTIONS

-v var1[,...]
La sortie n'affichera les informations de décalage que pour les variables spécifiées. Les noms d'une ou plusieurs variables doivent être fournis dans la liste délimitée par des virgules, qui ne doit pas contenir d'espaces ou d'autres caractères d'espacement blanc. Les variables nommées doivent être des variables netCDF valides dans le fichier d'entrée. Par défaut, c'est-à-dire sans cette option, les informations de décalage seront affichées pour toutes les variables stockées dans le fichier d'entrée.
-s
Affiche la taille de la variable en octets. Pour les variables d'enregistrement, seule la taille d'un enregistrement est affichée.
-g
Affiche l'espace réservé en octets par rapport à la variable précédente. Pour la première variable définie, affiche l'espace réservé à partir de la fin de l'en-tête du fichier. Pour les variables d'enregistrement, il n'y a pas d'espace réservé entre les enregistrements.
-r
Affiche les informations de décalage pour tous les enregistrements des variables d'enregistrement sélectionnées. Sans cette option, seuls les décalages du premier enregistrement sont affichés.
-x
Vérifie toutes les variables de taille fixe pour les espaces réservés dans le fichier entre deux variables adjacentes immédiatement. Affiche "1" sur stdout si des espaces réservés sont trouvés, "0" sinon. Cette option désactive toutes les autres options.
-h
Affiche les options de ligne de commande disponibles

EXEMPLES

Affiche les informations de décalage de fichier pour toutes les variables dans un fichier netCDF.

% ncoffsets -sg testfile.nc

netcdf testfile.nc {
// Format de fichier : CDF-1
// Nombre de dimensions : 4
// Nombre de variables : 4
// Nombre d'attributs globaux : 0
en-tête de fichier :
    taille   = 256 octets
    étendue = 512 octets
dimensions :
    time = ILLIMITÉ // (101 actuellement)
    Z = 100
    Y = 100
    X = 100
variables de taille fixe :
    float  square(Y, X):
           début décalage fichier =         512
           fin décalage fichier =       40512
           taille en octets     =       40000
           espace réservé depuis var précédente =         256
    double cube(Z, Y, X):
           début décalage fichier =       40512
           fin décalage fichier =     8040512
           taille en octets     =     8000000
           espace réservé depuis var précédente =           0
variables d'enregistrement :
    double time(time):
           début décalage fichier =     8040512    (0e enregistrement)
           fin décalage fichier =     8040520    (0e enregistrement)
           taille en octets     =           8    (d'un enregistrement)
           espace réservé depuis var précédente =           0
    float  rec_var(time, Z, Y, X):
           début décalage fichier =     8040520    (0e enregistrement)
           fin décalage fichier =    12040520    (0e enregistrement)
           taille en octets     =     4000000    (d'un enregistrement)
           espace réservé depuis var précédente =           0
}
Vérifie s'il y a des espaces réservés entre deux variables de taille fixe adjacentes.
% ncoffsets -x testfile.nc
0
