ncls(1) Manuel des commandes générales ncls(1)

NOM

ncls - Lister des chemins avec rendu multimédia

SYNTAXE

ncls [-h|--help] [-V|--version] [-d] [-l] [-L] [-R] [-a|--align type] [-b|--blitter blitter] [-s|--scale scale] [ chemins ]

DESCRIPTION

ncls utilise un Notcurses multimédia pour lister des chemins, similairement à la commande ls(1), en rendant des images et des vidéos dans un terminal.

OPTIONS

-d : lister les répertoires eux-mêmes, pas leur contenu.

-l : utiliser un format de liste long.

-L : suivre les liens symboliques

-R : lister les sous-répertoires récursivement.

-V|--version : Afficher les informations de version et quitter avec succès.

-h|--help : Afficher les informations d'aide et quitter avec succès.

-a|--align type : Aligner les images sur la gauche, au centre ou à la droite.

-b|--blitter blitter : Blitter, l'un de ascii, half, quad, sex, braille ou pixel. Par défaut, c'est pixel. Si le blitter choisi n'est pas disponible, ncls se dégradera (voir notcurses_visual(3)).

-s|--scale scalemode : Mode de mise à l'échelle, l'un de none, hires, scale, scalehi ou stretch.

chemins : Exécuter sur les chemins spécifiés. S'il n'y en a aucun, exécuter sur le répertoire courant.

Si aucune mise à l'échelle n'est spécifiée, hires sera utilisé avec le blitter pixel, et scalehi sera utilisé sinon.

NOTES

Un affichage optimal nécessite un terminal annonçant la capacité rgb de terminfo(5), ou que la variable d'environnement COLORTERM est définie à 24bit (et que le terminal respecte cette variable), ainsi qu'une police à chasse fixe avec une bonne couverture des caractères de dessin de bloc Unicode.

VOIR AUSSI

notcurses(3), notcurses_visual(3), terminfo(5), unicode(7)
