NOM

ncmpc - Documentation ncmpc

DESCRIPTION

Par défaut, ncmpc se connecte à l'instance MPD locale. Une autre instance MPD peut être sélectionnée en utilisant les options de ligne de commande --host et --port, ou en définissant les variables d'environnement MPD_HOST et MPD_PORT :

ncmpc --host=musicserver --port=44000

Vous pouvez vous connecter à un socket "local" en définissant l'hôte vers un chemin de fichier (par exemple, "/run/mpd/socket"). Les sockets abstraits peuvent être utilisés avec un préfixe "@" (par exemple, "@mpd").

Pour utiliser un mot de passe avec MPD, définissez MPD_HOST vers motdepasse@hote ou utilisez l'option de ligne de commande --password. Les valeurs de la ligne de commande remplacent celles de l'environnement.

SYNTAXE

ncmpc [options]

OPTIONS

-?, --help
Afficher l'aide.
-V, --version
Afficher les informations sur la version et la configuration au moment de la compilation.
-c, --colors
Activer les couleurs.
-C, --no-colors
Désactiver les couleurs.
-m, --mouse
Activer la souris.
--host=HOST
L'hôte MPD auquel se connecter.
--port=PORT, -p PORT
Le port auquel se connecter.
-P, --password=PASSWORD
Utiliser un mot de passe lors de la connexion.
-f, --config=FICHIER
Lire la configuration depuis le fichier.
-k, --key-file=FICHIER
Lire les raccourcis clavier depuis le fichier.

CONFIGURATION

Lors du démarrage, ncmpc tente de lire le fichier de configuration de l'utilisateur, $XDG_CONFIG_HOME/ncmpc/config (généralement ~/.config/ncmpc/config). Si aucun fichier de configuration utilisateur n'est trouvé, ncmpc tente de charger les paramètres globaux depuis $SYSCONFDIR/ncmpc/config (le chemin réel est affiché dans la sortie de l'option --version). Un exemple de fichier de configuration (config.sample) est fourni avec ncmpc.

Connexion

host = HOTE - L'hôte MPD auquel se connecter.

port = PORT - Le port auquel se connecter.

password = MOTDEPASSE - Utiliser un mot de passe lors de la connexion.

timeout = DELAI - Tenter de se reconnecter à mpd si une réponse à une commande n'est pas reçue dans le délai DELAI secondes. Spécifier une valeur dans le fichier de configuration remplace la variable d'environnement "MPD_TIMEOUT". Si aucun délai n'est spécifié dans le fichier de configuration ou dans l'environnement, la valeur par défaut est de 5 secondes.

Interface

show-title-bar = oui|non - "non" permet de masquer la barre de titre.

show-server-address = oui|non - "oui" affiche l'adresse du serveur dans la barre de titre. Ceci est désactivé par défaut car la plupart des utilisateurs n'utilisent qu'une seule instance MPD.

enable-mouse = oui|non - Activer la prise en charge de la souris (si activée à la compilation).

screen-list = ECRAN1 ECRAN2... - Une liste d'écrans à parcourir lors de l'utilisation des commandes screen-next (associée par défaut à "Tab") et screen-prev ("Shift+Tab"). Les choix valides, s'ils sont activés à la compilation, sont :

help, playlist, browse, library, search, lyrics, outputs, chat, song, keydef

La valeur par défaut est playlist browser, c'est-à-dire que la touche "Tab" ne fait que parcourir ces deux pages.

library-page-tags = TAG1 TAG2 ... - Une liste de tags pour regrouper la page de la bibliothèque. La valeur par défaut est artist album.

search-mode = MODE - Mode de recherche par défaut pour l'écran de recherche. MODE doit être l'un des suivants : title, artist, album, filename, et artist+title, ou un index entier (0 pour title, 1 pour artist, etc.).

auto-center = oui|non - Activer/désactiver le mode de centrage automatique. Lorsque le mode de centrage automatique est activé, ncmpc centre la piste actuelle dans la fenêtre de la playlist.

scroll-offset = NUM - Conserver au moins NUM lignes au-dessus et en dessous du curseur dans les fenêtres de liste, si possible.

find-show-last = oui|non - Afficher la requête la plus récente au lieu d'une ligne vide pour une recherche.

find-wrap = oui|non - Mode de recherche avec retour à la ligne.

wrap-around = oui|non - Mouvement du curseur avec retour à la ligne.

bell-on-wrap = oui|non - Faire sonner la cloche lors du retour à la ligne de la recherche.

audible-bell = oui|non - Sonner la cloche audible pour les alertes.

visible-bell = oui|non - Cloche visible pour les alertes.

crossfade-time = TEMPS CROSSFADE - Durée de fondu enchaîné par défaut en secondes.

seek-time = NUM - Rechercher en avant/arrière par NUM secondes.

lyrics-timeout = NUM - Arrête le téléchargement des paroles d'une chanson après que le délai de NUM secondes soit atteint, si NUM est supérieur à zéro.

jump-prefix-only = oui|non - Lors de l'utilisation de la commande jump, rechercher le préfixe d'une entrée. Cela signifie que taper "m" commencera à la première entrée commençant par "m".

lyrics-autosave = oui|non - Sauvegarder automatiquement les paroles après les avoir reçues.

lyrics-show-plugin = oui|non - Afficher le nom du plugin utilisé pour recevoir les paroles sur l'écran des paroles.

text-editor = EDITEUR - L'éditeur de texte utilisé pour éditer les paroles.

chat-prefix = PREFIXE - Préfixer les messages envoyés avec l'écran de chat avec PREFIXE. Par défaut, ils sont préfixés avec le nom d'utilisateur actuel entre < et > et un espace (c'est-à-dire "<nom> ").

second-column = oui|non - Afficher la durée de la chanson dans une deuxième colonne.

Affichage

welcome-screen-list = oui|non - Afficher une liste des écrans dans la ligne du haut.

wide-cursor = oui|non - Rendre le curseur aussi large que l'écran.

hardware-cursor = oui|non - Utiliser le curseur matériel du terminal au lieu des couleurs inversées.

hide-cursor = NUM - Masquer le curseur de la playlist après NUM secondes d'inactivité.

scroll = oui|non - Faire défiler le titre s'il est trop long pour l'écran.

scroll-sep = CHAINE - Le séparateur à afficher à la fin du titre défilant.

list-format = FORMAT CHANSON - Le format utilisé pour afficher les chansons dans la fenêtre principale.

search-format = FORMAT CHANSON - Le format utilisé pour afficher les chansons dans la fenêtre de recherche. Par défaut, il utilise list-format.

status-format = FORMAT CHANSON - Le format utilisé pour afficher les chansons sur la ligne de statut.

status-message-time = TEMPS - Le temps, en secondes, pendant lequel les messages d'état seront affichés.

display-time = oui|non - Afficher l'heure dans la barre de statut lorsque le système est inactif.

timedisplay-type = elapsed|remaining|none - Définit si l'heure restante ou écoulée doit être affichée dans la fenêtre de statut. La valeur par défaut est elapsed. none n'affiche pas l'heure du tout.

visible-bitrate = oui|non - Afficher le débit binaire dans la barre de statut lors de la lecture d'un flux.

set-xterm-title = oui|non - Modifier le titre XTerm (ncmpc ne restaurera pas le titre)

.

xterm-title-format = FORMAT DE CHANSON - Le format utilisé pour le titre xterm lorsque ncmpc est en cours de lecture.

Couleurs

enable-colors = oui|non - Activer/désactiver les couleurs. Par défaut à oui.

black, red, green, yellow, blue, magenta, cyan, white

Exemple :

color list = cyan

Les terminaux modernes prennent en charge jusqu'à 256 couleurs, mais elles ne sont pas standardisées. Vous pouvez les sélectionner en spécifiant leur numéro. Exemple :

color title = 42

La couleur d'arrière-plan peut être spécifiée après la couleur du texte, séparée par une barre oblique. Vous pouvez omettre la couleur du texte si vous souhaitez modifier uniquement la couleur d'arrière-plan :

color title = white/blue
color title = /blue

La couleur none utilise la couleur par défaut du terminal.

standout, underline, reverse, blink, dim, bold

Exemple :

color alert = red blink

color background = COULEUR - Définit la couleur d'arrière-plan par défaut.

color title = COULEUR[,ATTRIBUTE]... - Définit la couleur du texte et les attributs pour la ligne de titre, qui affiche les noms des pages.

color title-bold = COULEUR[,ATTRIBUTE]... - Similaire à title, mais fait référence aux parties accentuées de la ligne de titre, c'est-à-dire les touches d'accès rapide pour passer à une page spécifique.

color line = COULEUR - Définit la couleur de la ligne sur la deuxième ligne.

color line-flags = COULEUR[,ATTRIBUTE]... - Définit la couleur du texte utilisée pour indiquer les drapeaux mpd sur la deuxième ligne.

color list = COULEUR[,ATTRIBUTE]... - Définit la couleur du texte dans la zone principale de ncmpc.

color list-bold = COULEUR[,ATTRIBUTE]... - Définit la couleur du texte en gras dans la zone principale de ncmpc.

color browser-directory = COULEUR[,ATTRIBUTE]... - Définit la couleur du texte utilisée pour afficher les répertoires dans la fenêtre du navigateur.

color browser-playlist = COULEUR[,ATTRIBUTE]... - Définit la couleur du texte utilisée pour afficher les listes de lecture dans la fenêtre du navigateur.

color progressbar = COULEUR[,ATTRIBUTE]... - Définit la couleur de l'indicateur de progression.

color progressbar-background = COULEUR[,ATTRIBUTE]... - Définit la couleur de l'arrière-plan de l'indicateur de progression.

color status-state = COULEUR[,ATTRIBUTE]... - Définit la couleur du texte utilisée pour afficher l'état mpd dans la fenêtre d'état.

color status-song = COULEUR[,ATTRIBUTE]... - Définit la couleur du texte utilisée pour afficher les noms de chansons dans la fenêtre d'état.

color status-time = COULEUR[,ATTRIBUTE]... - Définit la couleur du texte utilisée pour afficher l'heure dans la fenêtre d'état.

color alert = COULEUR[,ATTRIBUTE]... - Définit la couleur du texte utilisée pour afficher les alertes dans la fenêtre d'état.

color input = COULEUR[,ATTRIBUTE]... - Définit la couleur du texte des contrôles de saisie de texte.

colordef COULEUR = R, G, B - Redéfinit l'une des couleurs de base. Les valeurs RVB doivent être des entiers compris entre 0 et 1000. Note : Seuls certains terminaux permettent de redéfinir les couleurs !

CLÉS

Lorsque ncmpc démarre, il essaie de lire les raccourcis clavier définis par l'utilisateur à partir du fichier $XDG_CONFIG_HOME/ncmpc/keys (généralement ~/.config/ncmpc/keys). Si aucun raccourci clavier défini par l'utilisateur n'est trouvé, ncmpc essaie de charger les raccourcis clavier globaux à partir de $SYSCONFDIR/ncmpc/keys (le chemin réel est affiché sur l'écran d'aide).

Vous pouvez afficher les raccourcis clavier de ncmpc en appuyant sur '1' (aide) lorsque ncmpc est en cours d'exécution. Pour modifier les raccourcis clavier, appuyez sur 'K' et utilisez l'éditeur de raccourcis dans ncmpc.

FORMAT DE CHANSON

Format d'affichage des chansons pour le statut et la fenêtre de liste. Les délimiteurs de métadonnées sont : %artist%, %albumartist%, %composer%, %performer%, %title%, %album%, %shortalbum%, %track%, %disc, %genre%, %name%, %time%, %date%, %file%, %shortfile%.

Les opérateurs [] sont utilisés pour regrouper la sortie de sorte que si aucun des délimiteurs de métadonnées entre [ et ] ne correspond, alors aucun des caractères entre [ et ] ne sera affiché ; le texte littéral est toujours affiché. & et | sont des opérateurs logiques pour et et ou. # est utilisé pour échapper les caractères.

Quelques exemples utiles pour le format sont :

"%file%"

et :

"[[%artist% - ]%title%]|%file%"

Un autre exemple est :

"[%artist%|(artiste inexistant)] - [%title%|(titre inexistant)]"

TABLES

En tant que fonctionnalité expérimentale, la file d'attente peut être affichée sous forme de tableau. Attention, cette fonctionnalité est très expérimentale et les futures versions pourraient apporter des changements incompatibles.

Pour configurer cela, ajoutez des colonnes au fichier de configuration, par exemple :

song-table-column = "Artiste" "%artist%|%name%|%file%" min=20 fraction=2
song-table-column = "Titre" "%title%" min=20 fraction=2
song-table-column = "Album" "%album%" min=10 fraction=1
song-table-column = "Temps" "%time%" min=8 fraction=0

Chaque colonne a une légende, une chaîne de format spécifiant ce qui est affiché, une largeur minimale (en cellules de terminal) et une fraction spécifiant quelle partie de la largeur excédentaire sera attribuée à cette colonne.

Dans l'exemple ci-dessus, la colonne "Temps" aura une largeur fixe de 8 car fraction=0.

PROTOCOLE DE CHAT

Si ncmpc a été compilé avec le support "chat", il utilise le protocole client-à-client disponible dans MPD 0.17 ou supérieur pour communiquer avec d'autres clients. Afin de recevoir des messages, il s'abonne au canal nommé "chat" et affiche tout message envoyé là-bas tel quel. Lorsque l'utilisateur entre un message, il est d'abord préfixé par le préfixe spécifié par l'option chat-prefix (ou le préfixe par défaut), puis envoyé au canal "chat" pour que d'autres puissent le lire.

BOGUES

Remarque ---

Comme MPD utilise UTF-8, ncmpc doit convertir les caractères dans le jeu de caractères utilisé par le système local. Si vous rencontrez des erreurs de conversion de caractères lors de l'exécution de ncmpc, vous devrez probablement configurer votre locale. Cela se fait en définissant l'une des variables d'environnement LC_CTYPE, LANG ou LC_ALL (LC_CTYPE n'affecte que la gestion des caractères).
