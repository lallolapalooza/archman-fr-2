ncftpbatch(1) Manuel des commandes générales ncftpbatch(1)

NOM

ncftpbatch - Traitement des tâches FTP en tâche de fond individuelle

SYNTAXE

ncftpbatch -d

ncftpbatch -l

ncftpbatch -D

OPTIONS

Drapeaux de ligne de commande :

-d
Commence le traitement en tâche de fond des tâches FTP dans le répertoire $HOME/.ncftp/spool de l'utilisateur courant. Ceci retourne immédiatement, car un processus démon est lancé et s'exécute en arrière-plan.
-l
Liste le contenu de la file d'attente des tâches de l'utilisateur.
-D
Ceci est similaire à -d, sauf que le processus ne devient pas un démon.

DESCRIPTION

Ce programme est responsable du traitement des requêtes FTP en tâche de fond. Il est normalement uniquement exécuté par ncftp et non manuellement par un être humain, cependant vous pouvez l'exécuter pour traiter manuellement la file d'attente des tâches FTP.

Les tâches sont des fichiers de mise en file d'attente écrits dans le répertoire $HOME/.ncftp/spool d'un utilisateur et ont un format spécial et une convention de nommage de fichier (qui contient quand la tâche doit être exécutée). ncftp exécute ce programme lorsqu'il en a besoin, mais si le démon ncftpbatch meurt de manière inattendue, les tâches restantes dans la file d'attente ne seront pas traitées tant qu'une autre instance de ncftpbatch n'est pas exécutée.

ncftpget et ncftpput peuvent également être utilisés pour soumettre des tâches pour le traitement par lots, en utilisant le drapeau de ligne de commande -b de ces utilitaires. Si vous le souhaitez, vous pouvez également créer manuellement les fichiers de mise en file d'attente bien que cette procédure ne soit pas documentée ici (voir la page de manuel de ncftpspooler pour plus d'informations sur la façon de le faire).

DIAGNOSTICS

ncftpbatch écrit dans son propre fichier journal, le fichier $HOME/.ncftp/spool/log. Ce fichier doit être examiné pour déterminer si des processus ncftpbatch travaillent activement sur des tâches.

AUTEUR

Mike Gleason, NcFTP Software (http://www.ncftp.com).

VOIR AUSSI

ncftp(1), ncftpput(1), ncftpget(1).
