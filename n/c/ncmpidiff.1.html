NOM

ncmpidiff - compare deux fichiers netCDF en parallèle

SYNTAXE

mpiexec -n np ncmpidiff [-b] [-q] [-h] [-v var1,...,varn] [-t diff,ratio] fichier1 fichier2

DESCRIPTION

ncmpidiff s'exécute en parallèle sur np processus MPI pour comparer le contenu des deux fichiers et rapporte la première différence à la sortie standard.

Pour les variables et les attributs, il rapporte les indices du tableau du premier élément trouvé différent lorsque l'option -t n'est pas utilisée. Lorsque l'option -t est utilisée, il rapporte l'élément avec la plus grande différence qui ne satisfait pas les exigences de tolérance.

Si aucun argument -v ni -h n'est donné en plus des deux noms de fichiers, les fichiers entiers sont comparés.

Lors de la comparaison de deux fichiers entièrement, la différence entre ncmpidiff et la commande Unix diff est que ncmpidiff ignore les espaces entre les variables. Les espaces peuvent survenir lorsque la fonctionnalité d'alignement est utilisée pour créer un nouveau fichier. Cet alignement permet d'allouer un espace plus grand pour l'en-tête du fichier et d'aligner les décalages de fichier de départ des variables de taille fixe (voir l'API ncmpi__enddef et les indices PnetCDF). Souvent, le contenu des espaces sont des octets arbitraires non nuls. Ainsi, deux fichiers netCDF (de tailles identiques ou différentes) peuvent être rapportés comme identiques par ncmpidiff mais pas par diff.

OPTIONS

-b
Mode verbeux - affiche les résultats (identiques ou différents) pour tous les composants (fichier, en-tête ou variables) de la comparaison
-q
Mode silencieux - n'affiche rien dans la sortie de la ligne de commande. Ceci désactive également le mode verbeux. En mode silencieux, les utilisateurs doivent vérifier le statut de sortie. Voir ci-dessous dans "STATUT DE SORTIE".
-h
Comparer uniquement l'en-tête du fichier
-v var1,...,varn
Comparer uniquement la liste donnée de variables (noms séparés par des virgules sans espace).
-t diff,ratio
Comparer les variables élément par élément avec tolérance (diff et ratio séparés par une virgule sans espace). diff est la valeur absolue de la différence élément par élément de deux variables portant le même nom mais stockées dans les deux fichiers d'entrée. ratio est le ratio de différence relatif élément par élément défini comme |x - y|/max(|x|, |y|), où x est un élément de tableau d'une variable dans le premier fichier et y est l'élément de tableau correspondant de la même variable dans le second fichier. |x| représente la valeur absolue de x. Notez que lorsque cette option est utilisée, la sortie rapporte uniquement le premier élément de tableau qui ne satisfait pas aux deux exigences de tolérance.

STATUT DE SORTIE

Un statut de sortie de 0 signifie qu'aucune différence n'a été trouvée, et 1 signifie que des différences ont été trouvées. Notez sur les systèmes basés sur VMS, les valeurs du statut de sortie sont inversées.
