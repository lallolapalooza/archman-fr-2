ncmpcpp(1) Manuel des commandes générales ncmpcpp(1)

NOM

ncmpcpp - Un client ncurses pour Music Player Daemon (MPD).

SYNTAXE

ncmpcpp [options]

DESCRIPTION

ncmpcpp est un client ncurses pour MPD (Music Player Daemon), inspiré par ncmpc.

Pour en savoir plus sur MPD, visitez http://www.musicpd.org

OPTIONS

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

-h, --host=HOTE
Se connecter au serveur sur l'hôte [localhost]
-p, --port=PORT
Se connecter au serveur sur le port [6600]
--current-song[=FORMAT]
Afficher la chanson actuelle en utilisant le format donné et quitter
-c, --config=FICHIER
Spécifier le(s) fichier(s) de configuration
--ignore-config-errors
Ignorer les options inconnues et invalides dans les fichiers de configuration
-b, --bindings=FICHIER
Spécifier le(s) fichier(s) de raccourcis clavier
-s, --screen <nom>
Spécifier l'écran de démarrage (<nom> peut être : aide, playlist, navigateur, moteur_recherche, bibliotheque_musicale, editeur_playlist, editeur_tags, sorties, visualiseur, horloge)
-S, --slave-screen <nom>
Spécifier l'écran esclave de démarrage (<nom> peut être : aide, playlist, navigateur, moteur_recherche, bibliotheque_musicale, editeur_playlist, editeur_tags, sorties, visualiseur, horloge)
-q, --quiet
Supprimer les journaux et la sortie excessive
-?, --help
Afficher l'aide.
-v, --version
Afficher les informations sur la version.

CONFIGURATION

Au démarrage, ncmpcpp essaie de lire les paramètres depuis les fichiers $XDG_CONFIG_HOME/ncmpcpp/config et $HOME/.ncmpcpp/config. Si aucune configuration n'est trouvée, ncmpcpp utilise sa configuration par défaut. Un exemple de fichier de configuration contenant toutes les valeurs par défaut est fourni avec ncmpcpp et peut généralement être trouvé dans /usr/share/doc/ncmpcpp (l'emplacement exact peut dépendre de votre système d'exploitation ou du préfixe de compilation).

Note : Les valeurs des options de configuration peuvent être entourées de guillemets ou non.
- Si elles sont entourées, les guillemets les plus à gauche et les plus à droite sont traités comme des délimiteurs, il n'est donc pas nécessaire d'échapper les guillemets que vous utilisez dans la valeur elle-même.
- Si elles ne le sont pas, tous les caractères d'espacement entre = et le premier caractère imprimable de la valeur, ainsi que les caractères d'espacement après le dernier caractère imprimable de la valeur sont tronqués.

Par conséquent, la règle générale est : si vous avez besoin d'espaces au début ou à la fin de la valeur, entourez-la de guillemets. Sinon, ne le faites pas.

Note : COLOR doit être le nom (pas un numéro) d'une des couleurs 1-8 de la section FORMAT DE CHANSON.

RACCOURCIS

Au démarrage de ncmpcpp, il essaie de lire les raccourcis depuis les fichiers $XDG_CONFIG_HOME/ncmpcpp/bindings et ~/.ncmpcpp/bindings. Si aucun fichier de raccourcis n'est trouvé, ncmpcpp utilise les valeurs par défaut. Un exemple de fichier de raccourcis avec les valeurs par défaut se trouve généralement dans /usr/share/doc/ncmpcpp (l'emplacement exact peut dépendre de votre système d'exploitation ou du préfixe de configuration).

Vous pouvez voir les raccourcis clavier actuels en appuyant sur F1.

FORMAT DE CHANSON

Pour le format des chansons, vous pouvez utiliser :


%l - durée
%f - nom de fichier
%F - chemin d'accès complet au fichier
%D - répertoire
%a - artiste
%A - artiste de l'album
%t - titre
%b - album
%y - date
%n - numéro de piste (01/12 -> 01)
%N - informations complètes de la piste (01/12 -> 01/12)
%g - genre
%c - compositeur
%p - interprète
%d - disque
%C - commentaire
%P - priorité
$R - commencer l'alignement à droite

Vous pouvez également les placer entre crochets { } et ils ne seront alors affichés que si toutes les valeurs demandées sont disponibles et/ou définir une valeur alternative avec { }|{ } par exemple, {%a - %t}|{%f} vérifiera si les balises d'artiste et de titre sont disponibles et si c'est le cas, les affichera. Sinon, il affichera le nom du fichier.

Note : Si vous souhaitez limiter la longueur maximale d'une balise, il suffit de placer le nombre approprié entre % et le caractère qui définit le type de balise, par exemple, pour que l'album prenne un maximum de 20 cellules de terminal, utilisez '%20b'.

Note : Un format similaire à "%a - %t" (c'est-à-dire sans accolades supplémentaires) est égal à "{%a - %t}", donc si l'une des balises est manquante, vous n'obtiendrez rien.

Le texte peut avoir une couleur différente de celle de la fenêtre principale, par exemple, si vous voulez que la durée soit verte, écrivez $3%l$9.

Valeurs disponibles pour les couleurs :


- 0 - couleur de fenêtre par défaut (ignore toutes les autres couleurs)
- 1 - noir
- 2 - rouge
- 3 - vert
- 4 - jaune
- 5 - bleu
- 6 - magenta
- 7 - cyan
- 8 - blanc
- 9 - fin de la couleur actuelle

Note : les couleurs peuvent être imbriquées, donc si vous écrivez $2certains$5texte$9, cela désactivera uniquement l'utilisation de la couleur bleue et fera du rouge la couleur actuelle.

NOTE

Comme MPD utilise UTF-8, ncmpcpp doit convertir les caractères en l'encodage utilisé par le système local. Si vous obtenez des erreurs de conversion de caractères lorsque vous exécutez ncmpcpp, vous devrez probablement configurer votre locale. Cela se fait en définissant les variables d'environnement LANG et LC_ALL/LC_CTYPE (LC_CTYPE n'affecte que la gestion des caractères).
