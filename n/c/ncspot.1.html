  Un client Spotify ncurses écrit en Rust utilisant librespot

Crates.io] Gitter]

ncspot est un client Spotify ncurses écrit en Rust utilisant librespot. Il est fortement inspiré par les clients MPD ncurses, tels que ncmpc. Ma motivation était de fournir une alternative simple et économe en ressources au client officiel, ainsi que de supporter les plateformes qui n'ont pas actuellement de client Spotify, comme les *BSD.

ncspot ne fonctionne qu'avec un compte Spotify premium car il offre des fonctionnalités qui ne sont pas disponibles pour les comptes gratuits.

Fonctionnalités

•
Support des pistes, albums, playlists, genres, recherche...
•
Faible empreinte de ressources
•
Support pour de nombreuses plateformes
•
Raccourcis clavier Vim prêts à l'emploi
•
Socket IPC pour le contrôle à distance

Installation

ncspot est disponible sur macOS (Homebrew), Windows (Scoop, WinGet), Linux (paquet natif, Flathub et Snapcraft) et les BSD. Des instructions d'installation détaillées pour chaque plateforme peuvent être trouvées ici.

Configuration

Un fichier de configuration peut être fourni. L'emplacement par défaut est ~/.config/ncspot. Des informations de configuration détaillées peuvent être trouvées ici.

Compilation

La compilation de ncspot nécessite une installation de Rust fonctionnelle et une installation de Python 3. Pour compiler ncspot, exécutez cargo build. Pour des instructions détaillées sur la compilation de ncspot, plus d'informations sont disponibles ici.
