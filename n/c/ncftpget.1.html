ncftpget(1) Manuel des commandes générales ncftpget(1)

NOM

ncftpget - Programme de transfert de fichiers Internet pour les scripts

SYNTAXE

ncftpget [options] hôte-distant répertoire-local fichiers-distants...

ncftpget [options] nom-favori répertoire-local fichiers-distants...

ncftpget -f login.cfg [options] répertoire-local fichiers-distants...

ncftpget [options] ftp://url.style.hôte/chemin/nom

ncftpget -c [options] hôte-distant fichier-distant > stdout

ncftpget -C [options] hôte-distant fichier-distant chemin-local

ncftpget -c [options] ftp://url.style.hôte/chemin/nom > stdout

OPTIONS

Options de ligne de commande :

-u XX
Utiliser le nom d'utilisateur XX au lieu d'anonymous.
-p XX
Utiliser le mot de passe XX avec le nom d'utilisateur.
-P XX
Utiliser le numéro de port XX au lieu du port de service FTP par défaut (21).
-j XX
Utiliser le compte XX en supplément du nom d'utilisateur et du mot de passe (obsolète).
-d XX
Utiliser le fichier XX pour l'enregistrement du débogage.
-a
Utiliser le type de transfert ASCII au lieu de binaire.
-t XX
Expiration après XX secondes.
-v/-V
Afficher (ne pas afficher) les indicateurs de progression. Par défaut, les indicateurs de progression sont utilisés si le flux de sortie est un TTY.
-f XX
Lire le fichier XX pour les informations d'hôte, d'utilisateur et de mot de passe.
-c
Lire depuis l'hôte distant et écrire localement sur la sortie standard.
-C
Lire depuis l'hôte distant et écrire localement sur le chemin spécifié.
-A
Ajouter aux fichiers locaux, au lieu de les écraser.
-z/-Z
Essayer (ne pas essayer) de reprendre les transferts. Par défaut, on essaie de reprendre (-z).
-E
Utiliser des connexions de données régulières (PORT).
-F
Utiliser des connexions de données passives (PASV). Par défaut, utiliser le mode passif, mais revenir au mode régulier si la connexion passive échoue ou expire.
-DD
Supprimer le fichier distant après l'avoir téléchargé avec succès.
-R
Mode récursif ; copier des arborescences de répertoires entières.
-T
Ne pas utiliser le mode TAR automatique à la volée pour télécharger des arborescences de répertoires entières. ncftpget utilise TAR chaque fois que possible car cela préserve généralement les liens symboliques et les permissions de fichiers. Le mode TAR peut également entraîner des transferts plus rapides pour les répertoires contenant de nombreux petits fichiers, car une seule connexion de données peut être utilisée au lieu d'une connexion de données FTP pour chaque petit fichier. L'inconvénient de l'utilisation de TAR est qu'il force le téléchargement de tout le répertoire, même si vous en aviez déjà téléchargé une partie auparavant. Vous pourriez donc vouloir utiliser cette option si vous souhaitez reprendre le téléchargement d'un répertoire.
-r XX
Recomposer un maximum de XX fois jusqu'à connexion au serveur FTP distant.
-b
Exécuter en arrière-plan (en soumettant un travail par lots, puis en lançant ncftpbatch).
-bb
Similaire à l'option -b, mais soumet uniquement le travail par lots. Vous devrez exécuter ncftpbatch pour que le travail par lots soit traité. Ceci est utile si vous avez déjà un processus ncftpbatch en cours d'exécution, ou si vous souhaitez mieux contrôler le moment où les travaux par lots sont traités.
Par exemple, si vous vouliez traiter trois fichiers en arrière-plan, tous sur le même serveur distant, il est plus poli d'utiliser un seul processus ncftpbatch pour traiter les trois travaux séquentiellement, plutôt que d'avoir trois processus ncftpbatch ouvrant trois sessions FTP simultanées sur le même serveur.
-B XX
Essayer de définir la taille du tampon de socket TCP/IP à XX octets.
-W XX
Envoyer la commande FTP brute XX après la connexion.
-X XX
Envoyer la commande FTP brute XX après chaque transfert de fichier.
-Y XX
Envoyer la commande FTP brute XX avant de se déconnecter.
Les options -W, -X et -Y sont utiles pour les utilisateurs avancés qui ont besoin d'ajuster le comportement sur certains serveurs. Par exemple, les utilisateurs accédant à des mainframes pourraient avoir besoin d'envoyer des commandes SITE spéciales pour définir les informations de taille de bloc et de format d'enregistrement.
Pour ces options, vous pouvez les utiliser plusieurs fois chacune si vous devez envoyer plusieurs commandes. Pour l'option -X, vous pouvez utiliser le cookie %s pour l'étendre au nom du fichier qui a été transféré.
-o XX
Définir l'option avancée XX.
Cette option est principalement utilisée pour le débogage. Elle définit la valeur d'une variable interne à une valeur entière. Un exemple d'utilisation serait : -o useFEAT=0,useCLNT=1 qui, dans ce cas, désactive l'utilisation de la commande FEAT et active la commande CLNT. Les variables disponibles incluent : usePASV, useSIZE, useMDTM, useREST, useNLST_a, useNLST_d, useFEAT, useMLSD, useMLST, useCLNT, useHELP_SITE, useSITE_UTIME, STATfileParamWorks, NLSTfileParamWorks, require20, allowProxyForPORT, doNotGetStartCWD.

DESCRIPTION

Le but de ncftpget est d'effectuer des transferts de fichiers depuis la ligne de commande sans entrer dans un shell interactif. Cela vous permet d'écrire des scripts shell ou d'autres processus non surveillés qui peuvent effectuer du FTP. Il est également utile pour les utilisateurs avancés qui souhaitent récupérer des fichiers depuis la ligne de commande du shell sans entrer dans un programme FTP interactif tel que ncftp.

Une fonctionnalité particulièrement utile de ce programme est que vous pouvez lui donner un uniform resource locator comme seul argument et le programme téléchargera ce fichier. Vous pouvez ensuite copier-coller depuis votre navigateur web ou votre lecteur de news et utiliser cette URL. Exemple :

$ cd /tmp
$ ncftpget ftp://ftp.ncftp.com/pub/ncftp/ncftp.tar.Z
$ zcat ncftp.tar.Z | tar xf -

Par défaut, le programme essaie d'ouvrir l'hôte distant et de se connecter anonymement, mais vous pouvez spécifier un nom d'utilisateur et des informations de mot de passe. L'option -u est utilisée pour spécifier le nom d'utilisateur avec lequel se connecter, et l'option -p est utilisée pour spécifier le mot de passe. Si vous exécutez le programme depuis le shell, vous pouvez omettre l'option -p et le programme vous demandera le mot de passe.

L'utilisation des options -u et -p n'est pas recommandée, car vos informations de compte sont exposées à toute personne pouvant voir votre script shell ou les informations de votre processus. Par exemple, quelqu'un utilisant le programme ps pourrait voir votre mot de passe pendant l'exécution du programme.

Vous pouvez utiliser l'option -f à la place pour spécifier un fichier contenant les informations de compte. Cependant, ce n'est toujours pas sécurisé car toute personne ayant un accès en lecture au fichier d'informations peut voir les informations de compte. Néanmoins, si vous choisissez d'utiliser l'option -f, le fichier doit ressembler à ceci :

host sphygmomanometer.ncftp.com
user gleason
pass mypasswd

N'oubliez pas de modifier les permissions de ce fichier afin que personne d'autre ne puisse les lire.

L'option -d est très utile lorsque vous essayez de diagnostiquer pourquoi un transfert de fichier échoue. Elle imprime toute la conversation FTP dans le fichier que vous spécifiez, afin que vous puissiez obtenir

t une idée de ce qui s'est mal passé. Si vous spécifiez le nom spécial stdout comme nom du fichier de sortie de débogage, la sortie s'affichera à l'écran. Exemple :

$ ncftpget -d stdout bowser.nintendo.co.jp . /pub/README
220 : Serveur FTP prêt.
Connecté à bowser.nintendo.co.jp.
Cmd : USER anonymous
331 : Connexion invité autorisée, utilisez votre adresse e-mail complète comme mot de passe.
Cmd : PASS xxxxxxxx
230 : Bienvenue !
Connecté à bowser.nintendo.co.jp en tant qu'anonymous.
Cmd : TYPE I
200 : Type défini sur I.
Cmd : PORT 192,168,9,37,6,76
200 : Commande PORT réussie.
Cmd : RETR /pub/README
550 : /pub/README : Fichier en cours d'utilisation.
Cmd : QUIT
221 : Au revoir.

L'utilisation du mode ASCII est utile lorsque le format texte de votre hôte diffère de celui de l'hôte distant. Par exemple, si vous récupérez un fichier .TXT d'un hôte basé sur Windows vers un système UNIX, vous pouvez utiliser l'indicateur -a qui utiliserait le mode de transfert ASCII afin que le fichier créé sur le système UNIX soit au format texte UNIX au lieu du format texte MS-DOS.

Vous pouvez récupérer un arbre de répertoires entier de fichiers en utilisant l'indicateur -R. Cependant, cela ne fonctionnera que si le serveur FTP distant est un serveur UNIX, ou émule la sortie de liste de UNIX. Exemple :

$ ncftpget -R ftp.ncftp.com /tmp /pub/ncftp

Cela créerait une hiérarchie /tmp/ncftp.

DIAGNOSTICS

ncftpget renvoie les valeurs de sortie suivantes :

0
Succès.
1
Impossible de se connecter à l'hôte distant.
2
Impossible de se connecter à l'hôte distant - délai dépassé.
3
Transfert échoué.
4
Transfert échoué - délai dépassé.
5
Changement de répertoire échoué.
6
Changement de répertoire échoué - délai dépassé.
7
URL mal formée.
8
Erreur d'utilisation.
9
Erreur dans le fichier de configuration de connexion.
10
Initialisation de la bibliothèque échouée.
11
Initialisation de la session échouée.
