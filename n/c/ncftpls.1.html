ncftpls(1) Manuel des commandes générales ncftpls(1)

NOM

ncftpls - programme de transfert de fichiers Internet pour scripts

SYNTAXE

ncftpls [options] ftp://url.style/hôte/chemin/nom/

OPTIONS

Drapeaux de ligne de commande :

-m
Utiliser un format de liste lisible par machine, si le serveur le supporte. Cela nécessite que le logiciel serveur supporte les extensions MLSD, et de nombreuses implémentations ne disposent pas de ces fonctionnalités.
-1
Format le plus basique, un élément par ligne.
-l
Format de liste long.
-C
Format de liste en colonnes. C'est le format de liste par défaut.
-R
Récursion dans tous les sous-répertoires lors de la liste.
-a
Afficher tous les fichiers, si le serveur le permet (comme dans « /bin/ls -a »).
-i XX
Filtrer la liste (si le serveur le supporte) avec le caractère générique XX.
-x -XX
Définir les drapeaux ls à utiliser sur le serveur.
-u XX
Utiliser le nom d'utilisateur XX au lieu d'anonyme.
-p XX
Utiliser le mot de passe XX avec le nom d'utilisateur.
-P XX
Utiliser le numéro de port XX au lieu du port de service FTP par défaut (21).
-d XX
Utiliser le fichier XX pour la journalisation de débogage.
-t XX
Expiration après XX secondes.
-E
Utiliser des connexions de données régulières (PORT).
-F
Utiliser des connexions de données passives (PASV). Par défaut, on utilise le mode passif, mais on se rabat sur le mode régulier si la connexion passive échoue ou expire.
-r XX
Recomposer un maximum de XX fois jusqu'à connexion au serveur FTP distant.
-W XX
Envoyer la commande FTP brute XX après la connexion.
-X XX
Envoyer la commande FTP brute XX après chaque transfert de fichier.
-Y XX
Envoyer la commande FTP brute XX avant de se déconnecter.
Les options -W, -X et -Y sont utiles pour les utilisateurs avancés qui ont besoin d'affiner le comportement sur certains serveurs. Par exemple, les utilisateurs accédant à des mainframes peuvent avoir besoin d'envoyer des commandes SITE spéciales pour définir les informations de taille de bloc et de format d'enregistrement.
Pour ces options, vous pouvez les utiliser plusieurs fois chacune si vous devez envoyer plusieurs commandes. Pour l'option -X, vous pouvez utiliser le marqueur %s pour l'étendre au nom du fichier qui a été transféré.
-o XX
Définir l'option avancée XX.
Cette option est principalement utilisée pour le débogage. Elle définit la valeur d'une variable interne à une valeur entière. Un exemple d'utilisation serait : -o useFEAT=0,useCLNT=1 ce qui, dans ce cas, désactive l'utilisation de la commande FEAT et active la commande CLNT. Les variables disponibles incluent : usePASV, useSIZE, useMDTM, useREST, useNLST_a, useNLST_d, useFEAT, useMLSD, useMLST, useCLNT, useHELP_SITE, useSITE_UTIME, STATfileParamWorks, NLSTfileParamWorks, require20, allowProxyForPORT, doNotGetStartCWD.

DESCRIPTION

Le but de ncftpls est de lister des répertoires distants en utilisant le protocole de transfert de fichiers (FTP) sans entrer dans un shell interactif. Cela vous permet d'écrire des scripts shell ou d'autres processus non supervisés qui peuvent faire du FTP.

Le comportement par défaut est d'afficher la liste du répertoire au format en colonnes (c'est-à-dire ls -CF), mais ce n'est pas très utile pour les scripts. Cet exemple utilise le drapeau -1, pour afficher un fichier par ligne :

$ ncftpls -1 ftp://ftp.ncftp.com/pub/ncftp/

Vous pouvez également faire un « ls -l » distant, en utilisant « ncftpls -l ». Si vous souhaitez essayer d'autres drapeaux, vous devez les utiliser avec le drapeau -x. Par exemple, si vous vouliez faire un « ls -lrt » distant, vous pourriez faire ceci :

$ ncftpls -x "-lrt" ftp://ftp.ncftp.com/pub/ncftp/

Par défaut, le programme essaie d'ouvrir l'hôte distant et de se connecter anonymement, mais vous pouvez spécifier un nom d'utilisateur et un mot de passe comme vous pouvez le faire avec ncftpget ou ncftpput.

Notez que la norme spécifie que les noms de chemin d'URL sont des noms de chemin relatifs. Pour FTP, cela signifie que les URL spécifient des noms de chemin relatifs à partir du répertoire de départ, qui pour les connexions utilisateur, est généralement le répertoire personnel de l'utilisateur. Si vous souhaitez utiliser des noms de chemin absolus, vous devez inclure une barre oblique littérale, en utilisant le code « %2F » pour un caractère « / ». Exemples :

$ ncftpls -u linus ftp://ftp.kernel.org/%2Fusr/src/
$ ncftpls ftp://steve@ftp.apple.com/%2Fetc/

DIAGNOSTICS

ncftpls retourne les valeurs de sortie suivantes :

0
Succès.
1
Impossible de se connecter à l'hôte distant.
2
Impossible de se connecter à l'hôte distant - délai d'attente dépassé.
3
Transfert échoué.
4
Transfert échoué - délai d'attente dépassé.
5
Changement de répertoire échoué.
6
Changement de répertoire échoué - délai d'attente dépassé.
7
URL malformée.
8
Erreur d'utilisation.
9
Erreur dans le fichier de configuration de connexion.
10
Échec de l'initialisation de la bibliothèque.
11
Échec de l'initialisation de la session.
