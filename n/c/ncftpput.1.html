ncftpput(1) Manuel des commandes générales ncftpput(1)

NOM

ncftpput - programme de transfert de fichiers Internet pour scripts

SYNTAXE

ncftpput [options] hote-distant repertoire-distant fichiers-locaux...

ncftpput [options] nom-marque-page repertoire-distant fichiers-locaux...

ncftpput -f login.cfg [options] repertoire-distant fichiers-locaux...

ncftpput -c hote-distant nom-chemin-distant < stdin

ncftpput -C hote-distant nom-chemin-local nom-chemin-distant

OPTIONS

Options de ligne de commande :

-u XX
Utiliser le nom d'utilisateur XX au lieu d'anonyme.
-p XX
Utiliser le mot de passe XX avec le nom d'utilisateur.
-P XX
Utiliser le numéro de port XX au lieu du port de service FTP par défaut (21).
-j XX
Utiliser le compte XX en supplément du nom d'utilisateur et du mot de passe (obsolète).
-d XX
Utiliser le fichier XX pour la journalisation de débogage.
-a
Utiliser le mode de transfert ASCII au lieu de binaire.
-m
Tenter de créer le répertoire de destination distant avant la copie.
-t XX
Temps d'attente après XX secondes.
-U XX
Utiliser la valeur XX pour l'umask.
-v/-V
Afficher (ne pas afficher) les barres de progression. Par défaut, les barres de progression sont utilisées si le flux de sortie est un TTY.
-f XX
Lire le fichier XX pour les informations sur l'hôte, l'utilisateur et le mot de passe.
-c
Lire localement depuis l'entrée standard et écrire à distance vers le chemin spécifié.
-C
Similaire à -c, mais un chemin local est spécifié.
-A
Ajouter aux fichiers distants, au lieu de les écraser.
-T XX
Téléverser dans des fichiers temporaires préfixés par XX.
-S XX
Téléverser dans des fichiers temporaires suffixés par XX.
-R
Mode récursif ; copier des arborescences de répertoires entières.
-r XX
Rappeler un maximum de XX fois jusqu'à connexion au serveur FTP distant.
-z/-Z
Essayer (ne pas essayer) de reprendre les transferts. Par défaut, on n'essaie pas de reprendre (-Z).
-E
Utiliser des connexions de données régulières (PORT).
-F
Utiliser des connexions de données passives (PASV). Par défaut, le mode passif est utilisé, mais il revient au mode régulier si la connexion passive échoue ou expire.
-DD
Supprimer le fichier local après l'avoir téléchargé avec succès.
-y
Essayer d'utiliser "SITE UTIME" pour préserver les horodatages sur l'hôte distant. Peu de serveurs FTP distants supportent cela, donc cela peut ne pas fonctionner.
-b
Exécuter en arrière-plan (en soumettant un travail par lots puis en lançant ncftpbatch).
-bb
Similaire à l'option -b, mais soumet uniquement le travail par lots. Vous devrez exécuter ncftpbatch pour que le travail par lots soit traité. Ceci est utile si vous avez déjà un processus ncftpbatch en cours d'exécution, ou si vous souhaitez mieux contrôler quand les travaux par lots sont traités.
Par exemple, si vous vouliez traiter trois fichiers en arrière-plan sur le même serveur distant, il est plus courtois d'utiliser un seul processus ncftpbatch pour traiter les trois travaux séquentiellement, plutôt que d'avoir trois processus ncftpbatch ouvrant trois sessions FTP simultanées sur le même serveur.
-B XX
Essayer de régler la taille du tampon du socket TCP/IP à XX octets.
-W XX
Envoyer la commande FTP brute XX après la connexion.
-X XX
Envoyer la commande FTP brute XX après chaque fichier transféré.
-Y XX
Envoyer la commande FTP brute XX avant la déconnexion.
Les options -W, -X et -Y sont utiles pour les utilisateurs avancés qui ont besoin d'ajuster le comportement sur certains serveurs. Par exemple, les utilisateurs accédant à des mainframes pourraient avoir besoin d'envoyer des commandes SITE spéciales pour définir la taille des blocs et les informations de format d'enregistrement.
Pour ces options, vous pouvez les utiliser plusieurs fois chacune si vous avez besoin d'envoyer plusieurs commandes. Pour l'option -X, vous pouvez utiliser le cookie %s pour le remplacer par le nom du fichier qui a été transféré.
-o XX
Définir l'option avancée XX.
Cette option est principalement utilisée pour le débogage. Elle définit la valeur d'une variable interne à une valeur entière. Un exemple d'utilisation serait : -o useFEAT=0,useCLNT=1 qui, dans ce cas, désactive l'utilisation de la commande FEAT et active la commande CLNT. Les variables disponibles incluent : usePASV, useSIZE, useMDTM, useREST, useNLST_a, useNLST_d, useFEAT, useMLSD, useMLST, useCLNT, useHELP_SITE, useSITE_UTIME, STATfileParamWorks, NLSTfileParamWorks, require20, allowProxyForPORT, doNotGetStartCWD.

DESCRIPTION

Le but de ncftpput est d'effectuer des transferts de fichiers depuis la ligne de commande sans entrer dans un shell interactif. Cela vous permet d'écrire des scripts shell ou d'autres processus non surveillés qui peuvent effectuer du FTP. Il est également utile pour les utilisateurs avancés qui souhaitent envoyer des fichiers depuis la ligne de commande sans entrer dans un programme FTP interactif tel que ncftp.

Par défaut, le programme tente d'ouvrir l'hôte distant et de se connecter anonymement, mais vous pouvez spécifier des informations de nom d'utilisateur et de mot de passe. L'option -u est utilisée pour spécifier le nom d'utilisateur avec lequel se connecter, et l'option -p est utilisée pour spécifier le mot de passe. Si vous exécutez le programme depuis le shell, vous pouvez omettre l'option -p et le programme vous demandera le mot de passe.

L'utilisation des options -u et -p n'est pas recommandée, car vos informations de compte sont exposées à quiconque peut voir votre script shell ou les informations de votre processus. Par exemple, quelqu'un utilisant le programme ps pourrait voir votre mot de passe pendant l'exécution du programme.

Vous pouvez utiliser l'option -f à la place pour spécifier un fichier contenant les informations du compte. Cependant, ce n'est toujours pas sécurisé car quiconque a un accès en lecture au fichier d'informations peut voir les informations du compte. Néanmoins, si vous choisissez d'utiliser l'option -f, le fichier devrait ressembler à ceci :

host sphygmomanometer.ncftp.com
user gleason
pass mypassword

N'oubliez pas de modifier les permissions de ce fichier afin que personne d'autre ne puisse les lire.

L'option -d est très utile lorsque vous essayez de diagnostiquer pourquoi un transfert de fichier échoue. Elle imprime toute la conversation FTP dans le fichier que vous spécifiez, de sorte que vous puissiez avoir une idée de ce qui s'est mal passé. Si vous spécifiez le nom spécial stdout comme nom du fichier de sortie de débogage, la sortie sera plutôt affichée sur l'écran.

L'utilisation du mode ASCII est utile lorsque le format texte de votre hôte diffère de celui de l'hôte distant. Par exemple, si vous envoyez un fichier texte d'un système UNIX vers un hôte basé sur Windows, vous pouvez utiliser l'indicateur -a qui utilisera le mode de transfert ASCII afin que le fichier créé sur la machine Windows soit dans son format texte natif au lieu du format texte UNIX.

-R drapeau

pour télécharger récursivement des arborescences de fichiers. Exemple :

$ ncftpput -R pikachu.nintendo.co.jp /incoming /tmp/stuff

Cela créerait une hiérarchie /incoming/stuff sur l'hôte distant.

Les options -T et -S sont utiles lorsque vous souhaitez télécharger un fichier sur l'hôte distant, mais que vous ne souhaitez pas utiliser le chemin du fichier de destination tant que le fichier n'est pas terminé. En utilisant ces options, vous ne détruirez pas un fichier distant portant le même nom tant que votre fichier ne sera pas terminé. Ces options sont également utiles lorsqu'un processus distant sur l'hôte distant interroge un nom de fichier spécifique, et que vous ne souhaitez pas que ce processus voie ce fichier tant que vous ne savez pas que le fichier est complètement envoyé. Voici un exemple qui télécharge sur le fichier /pub/incoming/README, en utilisant le nom de fichier temporaire /pub/incoming/README.tmp :

$ ncftpput -S .tmp bowser.nintendo.co.jp /pub/incoming /a/README

Une manière astucieuse de rediriger la sortie de n'importe quelle commande locale vers un fichier distant est d'utiliser l'option -c, qui indique que vous utilisez stdin comme entrée. L'exemple suivant montre comment effectuer une sauvegarde et la stocker sur une machine distante :

$ tar cf - / | ncftpput -c sonic.sega.co.jp /usr/local/backup.tar

DIAGNOSTICS

ncftpput retourne les valeurs de sortie suivantes :

0
Succès.
1
Impossible de se connecter à l'hôte distant.
2
Impossible de se connecter à l'hôte distant - délai d'attente dépassé.
3
Échec du transfert.
4
Échec du transfert - délai d'attente dépassé.
5
Échec du changement de répertoire.
6
Échec du changement de répertoire - délai d'attente dépassé.
7
URL malformée.
8
Erreur d'utilisation.
9
Erreur dans le fichier de configuration de connexion.
10
Échec de l'initialisation de la bibliothèque.
11
Échec de l'initialisation de la session.
