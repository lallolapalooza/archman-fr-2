ncursesw6-config(1) Commandes utilisateur ncursesw6-config(1)

NOM

ncursesw6-config - aide à la configuration pour les bibliothèques ncurses

SYNTAXE

ncursesw6-config option ...

ncursesw6-config --version

ncursesw6-config --help

DESCRIPTION

Ce programme est une aide au développement qui simplifie le processus de configuration d'applications par rapport à un ensemble particulier de bibliothèques ncurses.

OPTIONS

--prefix
signale le préfixe du paquet de ncurses.
--exec-prefix
signale le préfixe exécutable de ncurses.
--cflags
signale les options du compilateur C nécessaires pour compiler avec ncurses.
--libs
signale les bibliothèques nécessaires pour lier avec ncurses.
--abi-version
signale la version ABI de ncurses.
--mouse-version
signale la version de l'interface souris de ncurses.
--bindir
signale le répertoire contenant les programmes ncurses.
--datadir
signale le répertoire contenant les données ncurses.
--includedir
signale le répertoire contenant les fichiers d'en-tête ncurses.
--libdir
signale le répertoire contenant les bibliothèques ncurses.
--mandir
signale le répertoire contenant les pages de manuel ncurses.
--terminfo
signale le chemin de la base de données TERMINFO terminfo, par exemple /usr/share/terminfo.
--terminfo-dirs
signale le chemin de recherche supplémentaire TERMINFO_DIRS pour la base de données terminfo, par exemple /usr/share/terminfo.
--termpath
signale le chemin de recherche supplémentaire TERMPATH pour la base de données termcap, si le support de termcap est configuré.

Les options suivantes font que toutes les autres sont ignorées.

--help
affiche un message d'utilisation et se termine avec succès.
--version
affiche les informations de version et de date de correctif de ncurses et se termine avec succès.
