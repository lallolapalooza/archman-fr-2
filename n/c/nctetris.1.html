NOM

nctetris - Тетрис dans le terminal

SYNTAXE

nctetris [-h|--help] [-l loglevel]

DESCRIPTION

nctetris implémente un clone de Tetris utilisant Notcurses.

Le but est de compléter des lignes horizontales, sans laisser les tétrominos atteindre le haut de l'écran. Le tétromino qui tombe peut être tourné dans le sens antihoraire avec la touche 'z', et dans le sens horaire avec la touche 'x'. Le tétromino peut être déplacé vers la gauche et la droite avec 'h' et 'l', respectivement. Il peut être déplacé vers le bas avec 'j'. Les touches fléchées peuvent également être utilisées. Quitter avec 'q'.

OPTIONS

-h : Afficher l'aide et quitter.

-l loglevel : Journaliser tout (niveau de journalisation élevé) ou rien (niveau de journalisation 0) vers stderr.

NOTES

Un affichage optimal nécessite un terminal qui annonce la capacité rgb de terminfo(5), ou que la variable d'environnement COLORTERM soit définie à 24bit (et que le terminal respecte les échappements RGB), ainsi qu'une bonne police à chasse fixe avec une bonne couverture des caractères de dessin de blocs Unicode.
