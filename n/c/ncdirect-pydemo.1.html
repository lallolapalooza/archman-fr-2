NOM

ncdirect-pydemo - Vérifie que les wrappers Python ncdirect fonctionnent

SYNTAXE

ncdirect-pydemo

DESCRIPTION

ncdirect-pydemo affiche une sortie stylisée sur le terminal connecté en utilisant la capacité de « mode direct » du module Python notcurses (voir notcurses_direct(3). Cette sortie est un moyen minimal de vérifier que le module est correctement installé et peut être utilisé dans l'environnement actuel.

Pour une démonstration plus complète, voir notcurses-demo(1).

OPTIONS

NOTES

Notcurses ne prend en charge que Python 3.
