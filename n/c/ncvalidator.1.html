NOM

ncvalidator - valide un fichier netCDF classique par rapport aux formats de fichier CDF

SYNTAXE

ncvalidator [-x] [-t] [-q] [-h] fichier

DESCRIPTION

ncvalidator vérifie l'en-tête d'un fichier netCDF pour déterminer s'il est conforme aux formats de fichier CDF classiques. Si le fichier d'entrée est un fichier NetCDF valide, un message de validation réussie est affiché dans la sortie de la ligne de commande, par exemple, Fichier « testfile.nc » est un fichier NetCDF valide. Sinon, un message d'erreur NetCDF est affiché.

OPTIONS

-x
Répare le remplissage par des octets nuls dans l'en-tête du fichier. Le remplissage par des octets nuls est requis par les spécifications du format NetCDF classique. PnetCDF impose cette exigence, mais NetCDF ne l'a jamais fait. Cette option vérifie l'en-tête pour les emplacements où des octets nuls sont attendus et les remplace par des octets nuls si des octets non nuls sont trouvés. Le fichier réparé est alors conforme à la spécification et permet aux bibliothèques PnetCDF et NetCDF de lire le fichier sans signaler d'erreur NC_ENOTNC ou NC_ENULLPAD. Notons que cette réparation se fait sur place et les utilisateurs peuvent vouloir sauvegarder le fichier d'entrée au préalable. Une fois le fichier réparé, on peut exécuter la commande ncmpidiff pour comparer le contenu de deux fichiers.
-t
Active le mode de traçage, affichant la progression de toutes les validations de métadonnées réussies. Lorsqu'une erreur est détectée, le traçage s'arrête à l'emplacement de l'erreur trouvée.
-q
Mode silencieux - n'affiche rien dans la sortie de la ligne de commande. En mode silencieux, les utilisateurs doivent vérifier le code de sortie. Voir ci-dessous dans « CODE DE SORTIE ».
-h
Affiche les options de ligne de commande disponibles

CODE DE SORTIE

Un code de sortie de 0 signifie que le fichier est conforme au format de fichier CDF classique, et 1 signifie le contraire. Notez que sur les systèmes basés sur VMS, les valeurs des codes de sortie sont inversées.

VOIR AUSSI

ncmpidump(1), pnetcdf(3)
