NOM

ndctl-monitor - Surveiller les événements intelligents des objets nvdimm

SYNTAXE

ndctl monitor [<options>]

DESCRIPTION

Ndctl monitor est utilisé pour surveiller les événements intelligents des objets nvdimm et pour exporter les notifications au format json vers syslog, la sortie standard ou un fichier journal.

Les objets à surveiller et les événements intelligents à notifier peuvent être sélectionnés en définissant des options et/ou des fichiers de configuration avec le suffixe .conf sous /etc/ndctl.conf.d

Les valeurs dans le fichier de configuration et dans les options fonctionneront. En cas de conflit, les valeurs des options remplaceront celles du fichier de configuration. Toute modification des valeurs dans le fichier de configuration ne prendra effet qu'après le redémarrage du processus de surveillance.

EXEMPLES

Exécuter un moniteur en mode démon pour surveiller les DIMMs sur le bus "nfit_test.1"

ndctl monitor --bus=nfit_test.1 --daemon

Exécuter un moniteur en tant que commande unique et exporter les notifications dans /var/log/ndctl.log

ndctl monitor --log=/var/log/ndctl.log

Exécuter un démon moniteur en tant que service système

systemctl start ndctl-monitor.service

OPTIONS

-b, --bus=

Un numéro d'identification de bus, ou une chaîne de fournisseur (par exemple, "ACPI.NFIT"). Restreint l'opération aux bus spécifiés. Le mot-clé all peut être spécifié pour indiquer l'absence de restriction, cependant cela équivaut à ne pas fournir d'option --bus du tout.

-d, --dimm=

Un nom de périphérique nmemX, ou un numéro d'identification de dimm. Restreint l'opération aux dimms spécifiés. Le mot-clé all peut être spécifié pour indiquer l'absence de restriction, cependant cela équivaut à ne pas fournir d'option --dimm du tout.

-r, --region=

Un nom de périphérique regionX, ou un numéro d'identification de région. Restreint l'opération aux régions spécifiées. Le mot-clé all peut être spécifié pour indiquer l'absence de restriction, cependant cela équivaut à ne pas fournir d'option --region du tout.

-n, --namespace=

Un nom de périphérique namespaceX.Y, ou une paire région et id de namespace X.Y.

-l, --log=

Envoie les messages du journal à la destination spécifiée.
•"<fichier>": Envoie les messages du journal au <fichier> spécifié. Lorsque fopen() ne parvient pas à ouvrir <fichier>, les messages du journal sont redirigés vers syslog.
•"syslog": Envoie les messages à syslog.
•"standard": Envoie les messages à la sortie standard.

La destination par défaut du journal est syslog si "--daemon" est spécifié, sinon c'est standard. Notez que les chemins standard et relatifs pour <fichier> ne fonctionneront pas si "--daemon" est spécifié.

-c, --config-file=

Fournit les fichiers de configuration à utiliser. Ceci remplace la configuration par défaut généralement trouvée dans /etc/ndctl.conf.d

--daemon

Exécute un moniteur en tant que démon.

-D, --dimm-event=

Nom d'un événement de santé intelligente parmi les suivants :
•"dimm-spares-remaining": La valeur des blocs de secours restants est passée en dessous du seuil préprogrammé.
•"dimm-media-temperature": La valeur de la température du média NVDIMM a dépassé le seuil préprogrammé.
•"dimm-controller-temperature": La valeur de la température du contrôleur NVDIMM a dépassé le seuil préprogrammé.
•"dimm-health-state": L'état de santé normal du NVDIMM a changé.
•"dimm-unclean-shutdown": Le statut du dernier arrêt du NVDIMM était un arrêt non propre.

Le moniteur tentera d'activer les bits de contrôle d'alarme pour tous les événements spécifiés.

-p, --poll=

Interroge et signale l'état/l'événement toutes les <n> secondes.

-u, --human

Exporte la notification du moniteur au format json lisible par l'homme au lieu du format json lisible par la machine par défaut.

-v, --verbose

Émet des messages de débogage supplémentaires dans le journal.
