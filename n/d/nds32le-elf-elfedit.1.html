ELFEDIT(1) Outils de développement GNU ELFEDIT(1)

NOM

elfedit - met à jour l'en-tête ELF et la propriété du programme des fichiers ELF

SYNTAXE

elfedit [--input-mach=machine]
[--input-type=type]
[--input-osabi=osabi]
[--input-abiversion=version]
--output-mach=machine
--output-type=type
--output-osabi=osabi
--output-abiversion=version
--enable-x86-feature=feature
--disable-x86-feature=feature
[-v|--version]
[-h|--help]
fichier_elf...

DESCRIPTION

elfedit met à jour l'en-tête ELF et la propriété du programme des fichiers ELF qui correspondent aux types de machine et de fichier ELF spécifiés. Les options contrôlent comment et quels champs dans l'en-tête ELF et la propriété du programme doivent être mis à jour.

fichier_elf... sont les fichiers ELF à mettre à jour. Les fichiers ELF 32 bits et 64 bits sont supportés, ainsi que les archives contenant des fichiers ELF.

OPTIONS

Les formes longues et courtes des options, présentées ici comme alternatives, sont équivalentes. Au moins une des options --output-mach, --output-type, --output-osabi, --output-abiversion, --enable-x86-feature et --disable-x86-feature doit être fournie.

--input-mach=machine
Définit le type de machine ELF d'entrée correspondant à machine. Si --input-mach n'est pas spécifié, il correspondra à tous les types de machine ELF.
Les types de machine ELF supportés sont, i386, IAMCU, L1OM, K1OM et x86-64.
--output-mach=machine
Change le type de machine ELF dans l'en-tête ELF à machine. Les types de machine ELF supportés sont les mêmes que --input-mach.
--input-type=type
Définit le type de fichier ELF d'entrée correspondant à type. Si --input-type n'est pas spécifié, il correspondra à tous les types de fichier ELF.
Les types de fichier ELF supportés sont, rel, exec et dyn.
--output-type=type
Change le type de fichier ELF dans l'en-tête ELF à type. Les types ELF supportés sont les mêmes que --input-type.
--input-osabi=osabi
Définit l'OSABI du fichier ELF d'entrée correspondant à osabi. Si --input-osabi n'est pas spécifié, il correspondra à tous les OSABI ELF.
Les OSABI ELF supportés sont, none, HPUX, NetBSD, GNU, Linux (alias pour GNU), Solaris, AIX, Irix, FreeBSD, TRU64, Modesto, OpenBSD, OpenVMS, NSK, AROS et FenixOS.
--output-osabi=osabi
Change l'OSABI ELF dans l'en-tête ELF à osabi. Les OSABI ELF supportés sont les mêmes que --input-osabi.
--input-abiversion=version
Définit l'ABIVERSION du fichier ELF d'entrée correspondant à version. version doit être compris entre 0 et 255. Si --input-abiversion n'est pas spécifié, il correspondra à tous les ABIVERSIONs ELF.
--output-abiversion=version
Change l'ABIVERSION ELF dans l'en-tête ELF à version. version doit être compris entre 0 et 255.
--enable-x86-feature=feature
Définit le bit de feature dans la propriété du programme dans les fichiers ELF exec ou dyn avec les types de machine i386 ou x86-64. Les fonctionnalités supportées sont, ibt, shstk, lam_u48 et lam_u57.
--disable-x86-feature=feature
Efface le bit de feature dans la propriété du programme dans les fichiers ELF exec ou dyn avec les types de machine i386 ou x86-64. Les fonctionnalités supportées sont les mêmes que --enable-x86-feature.

Note : --enable-x86-feature et --disable-x86-feature ne sont disponibles que sur les hôtes avec support mmap.

-v
--version
Affiche le numéro de version de elfedit.
-h
--help
Affiche les options de ligne de commande comprises par elfedit.
@fichier
Lit les options de ligne de commande à partir de fichier. Les options lues sont insérées à la place de l'option @fichier d'origine. Si fichier n'existe pas, ou ne peut être lu, alors l'option sera traitée littéralement, et non supprimée.

Les options dans fichier sont séparées par des espaces. Un caractère d'espace blanc peut être inclus dans une option en entourant l'option entière soit de guillemets simples soit de guillemets doubles. Tout caractère (y compris un antislash) peut être inclus en faisant précéder le caractère à inclure par un antislash. Le fichier peut lui-même contenir d'autres options @fichier ; toutes ces options seront traitées récursivement.
