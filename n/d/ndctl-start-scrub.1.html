NOM

ndctl-start-scrub - démarre une opération de nettoyage de plage d'adresses (ARS)

SYNTAXE

ndctl start-scrub [<id-bus> <id-bus2> ... <id-busN>] [<options>]

DESCRIPTION

Le nettoyage de plage d'adresses NVDIMM (NVDIMM Address Range Scrub - ARS) est une capacité fournie par le firmware de la plateforme qui permet au logiciel système de découvrir les erreurs de mémoire. Il permet au logiciel système d'éviter préventivement les accès susceptibles d'entraîner des événements de gestion d'erreurs de mémoire non corrigeables, et il permet par ailleurs de répertorier les erreurs de mémoire.

Le noyau fournit un fichier sysfs (scrub) qui, lorsqu'il est écrit avec la chaîne de caractères « 1\n », initie une opération ARS. L'opération ndctl start-scrub démarre une ARS sur tous les bus spécifiés, et le noyau procède ensuite au nettoyage de chaque région de mémoire persistante sur les bus spécifiés.

EXEMPLE

Démarre un nettoyage sur tous les bus nvdimm du système. Le rapport de liste JSON n'inclut que les bus qui prennent en charge les opérations ARS.

# ndctl start-scrub
[
  {
    "provider":"nfit_test.1",
    "dev":"ndbus3",
    "scrub_state":"active"
  },
  {
    "provider":"nfit_test.0",
    "dev":"ndbus2",
    "scrub_state":"active"
  }
]

Lors de la spécification d'un bus individuel, ou s'il n'y a qu'un seul bus dans le système, la commande indique si la prise en charge de l'ARS est disponible.

# ndctl start-scrub e820
error starting scrub: Operation not supported

OPTIONS

-v, --verbose

Émet des messages de débogage pour le processus de démarrage de l'ARS
