ADDR2LINE(1) Outils de développement GNU ADDR2LINE(1)

NOM

addr2line - convertir des adresses ou des symboles+décalages en noms de fichiers et numéros de ligne

SYNTAXE

addr2line [-a|--addresses]
[-b nom_bfd|--target=nom_bfd]
[-C|--demangle[=style]]
[-r|--no-recurse-limit]
[-R|--recurse-limit]
[-e nom_fichier|--exe=nom_fichier]
[-f|--functions] [-s|--basename]
[-i|--inlines]
[-p|--pretty-print]
[-j|--section=nom]
[-H|--help] [-V|--version]
[addr addr ...]

DESCRIPTION

addr2line traduit des adresses ou des symboles+décalages en noms de fichiers et numéros de ligne. Étant donné une adresse ou un symbole+décalage dans un exécutable ou un décalage dans une section d'un objet relocable, il utilise les informations de débogage pour déterminer le nom de fichier et le numéro de ligne qui leur sont associés.

L'exécutable ou l'objet relocable à utiliser est spécifié avec l'option -e. La valeur par défaut est le fichier a.out. La section de l'objet relocable à utiliser est spécifiée avec l'option -j.

addr2line a deux modes de fonctionnement.

Dans le premier, des adresses hexadécimales ou des symboles+décalages sont spécifiés sur la ligne de commande, et addr2line affiche le nom du fichier et le numéro de ligne pour chaque adresse.

Dans le second, addr2line lit des adresses hexadécimales ou des symboles+décalages depuis l'entrée standard, et imprime le nom du fichier et le numéro de ligne pour chaque adresse sur la sortie standard. Dans ce mode, addr2line peut être utilisé dans un tube pour convertir des adresses choisies dynamiquement.

Le format de sortie est NOM_FICHIER:NUMERO_LIGNE. Par défaut, chaque adresse d'entrée génère une ligne de sortie.

Deux options peuvent générer des lignes supplémentaires avant chaque ligne NOM_FICHIER:NUMERO_LIGNE (dans cet ordre).

Si l'option -a est utilisée, alors une ligne contenant l'adresse d'entrée est affichée.

Si l'option -f est utilisée, alors une ligne contenant le NOM_FONCTION est affichée. C'est le nom de la fonction contenant l'adresse.

Une option peut générer des lignes supplémentaires après la ligne NOM_FICHIER:NUMERO_LIGNE.

Si l'option -i est utilisée et que le code à l'adresse donnée est présent en raison de l'inlining par le compilateur, alors des lignes supplémentaires sont affichées par la suite. Une ou deux lignes supplémentaires (si l'option -f est utilisée) sont affichées pour chaque fonction inlinée.

Alternativement, si l'option -p est utilisée, alors chaque adresse d'entrée génère une seule longue ligne de sortie contenant l'adresse, le nom de la fonction, le nom du fichier et le numéro de ligne. Si l'option -i a également été utilisée, alors les fonctions inlinées seront affichées de la même manière, mais sur des lignes séparées, et préfixées par le texte (inlined par).

Si le nom de fichier ou le nom de fonction ne peuvent être déterminés, addr2line affichera deux points d'interrogation à leur place. Si le numéro de ligne ne peut être déterminé, addr2line affichera 0.

Lorsque symbole+décalage est utilisé, +décalage est optionnel, sauf lorsque le symbole est ambigu avec un nombre hexadécimal. Les symboles résolus peuvent être manglés ou non manglés, mais les symboles non manglés avec + ne sont pas autorisés.

OPTIONS

Les formes longues et courtes des options, présentées ici comme alternatives, sont équivalentes.

-a
--addresses
Affiche l'adresse avant les informations sur le nom de la fonction, le fichier et le numéro de ligne. L'adresse est imprimée avec un préfixe 0x pour l'identifier facilement.
-b nom_bfd
--target=nom_bfd
Spécifie que le format du code objet pour les fichiers objet est nom_bfd.
-C
--demangle[=style]
Décode (demangle) les noms de symboles de bas niveau en noms de niveau utilisateur. En plus de supprimer le trait de soulignement initial ajouté par le système, cela rend les noms de fonctions C++ lisibles. Différents compilateurs ont différents styles de mangling. L'argument optionnel de style de décompilation peut être utilisé pour choisir un style de décompilation approprié pour votre compilateur.
-e nom_fichier
--exe=nom_fichier
Spécifie le nom de l'exécutable pour lequel les adresses doivent être traduites. Le fichier par défaut est a.out.
-f
--functions
Affiche les noms de fonctions ainsi que les informations sur le fichier et le numéro de ligne.
-s
--basenames
Affiche uniquement la base de chaque nom de fichier.
-i
--inlines
Si l'adresse appartient à une fonction qui a été inlinée, les informations source pour tous les scopes englobants jusqu'à la première fonction non inlinée seront également imprimées. Par exemple, si "main" inlinise "callee1" qui inlinise "callee2", et que l'adresse provient de "callee2", les informations source pour "callee1" et "main" seront également imprimées.
-j
--section
Lit les décalages par rapport à la section spécifiée au lieu des adresses absolues.
-p
--pretty-print
Rend la sortie plus conviviale : chaque emplacement est imprimé sur une ligne. Si l'option -i est spécifiée, les lignes pour tous les scopes englobants sont préfixées par (inlined par).
-r
-R
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Active ou désactive une limite sur la quantité de récursion effectuée lors de la décompilation des chaînes. Comme les formats de mangling de noms permettent un niveau infini de récursion, il est possible de créer des chaînes dont le décodage épuiserait l'espace de pile disponible sur la machine hôte, déclenchant une faute de mémoire. La limite essaie d'éviter que cela ne se produise en restreignant la récursion à 2048 niveaux d'imbrication.

Par défaut, cette limite est activée, mais sa désactivation peut être nécessaire pour décompiler des noms véritablement compliqués. Notez cependant que si la limite de récursion est désactivée, un épuisement de la pile est possible et tout rapport de bug concernant un tel événement sera rejeté.

L'option -r est un synonyme de l'option --no-recurse-limit. L'option -R est un synonyme de l'option --recurse-limit.

NAME

addr2line - convert program addresses to file names and line numbers

SYNOPSIS

addr2line [-a|--all] [-e objfile] [-f|--functions] [-i|--inlines] [-j|--section section] [-p|--pretty-print] [-q|--quiet] [-r|--radix=radix] [-s|--basename] [-C|--demangle[=style]] [-S|--source] [-l|--line-numbers] [-e objfile] [-V|--version] [--help] [address...] [address...]

DESCRIPTION

The addr2line utility can be used to translate program address into file names and line numbers. It can also be used to find out what the addresses represent in terms of functions.

This program is part of the GNU Binutils package.

The input addresses are read from the standard input by default, unless an address is specified on the command line.

The default behaviour is to print the file name and line number for each address.

If the input is coming from a pipe, the program will not exit until the input is exhausted.

If the program cannot find a symbol or line number information, it will print "??" for the parts it cannot find.

If the program cannot find symbol information for an address, it will print the address in hexadecimal form.

-a, --all
Print the file name and line number, then the function name, then the inlined function name for each address.
-e objfile
This option specifies the input object file. The default is the file named a.out.
-f, --functions
Print the function name for each address. This is the default behaviour.
-i, --inlines
Print the inlined function name for each address. If the address is not part of an inlined function, then the normal function name is printed. This option is only useful if the executable was compiled with debug information.
-j, --section section
Print address information only for addresses within the specified section.
-p, --pretty-print
Print the file name and line number in a pretty-printed format. This is the default behavior.
-q, --quiet
Do not print any warning or diagnostic messages.
-r, --radix=radix
The radix used for reading addresses. This option is only useful when reading addresses from standard input.
-s, --basename
Strip the directory name from file names. This is useful when you want to print the names of the source files without their paths.
-C[=style], --demangle[=style]
Decode in the output the C++ encoded C function names into human readable names. Optionally you may specify a demangling style, such as java. The default C++ demangling style is auto.
-S, --source
Try to guess the original source file name. This is useful when you only have the object file and not the source files.
-l, --line-numbers
Print the file name and line number for each address. This is the default behavior.
-V, --version
Display the version of addr2line and exit.
--help
Display the help message and exit.

OPTIONS

The address arguments are the addresses to look up. If no addresses are given, then they are read from standard input.

addr2line - convertir les adresses de programme en noms de fichiers et numéros de ligne

L'utilitaire addr2line peut être utilisé pour traduire les adresses de programme en noms de fichiers et numéros de ligne. Il peut également être utilisé pour déterminer ce que représentent les adresses en termes de fonctions.

Ce programme fait partie du paquet GNU Binutils.

Les adresses d'entrée sont lues depuis l'entrée standard par défaut, sauf si une adresse est spécifiée sur la ligne de commande.

Le comportement par défaut est d'afficher le nom du fichier et le numéro de ligne pour chaque adresse.

Si l'entrée provient d'un pipe, le programme ne se terminera pas avant que l'entrée ne soit épuisée.

Si le programme ne trouve pas d'informations sur les symboles ou les numéros de ligne, il affichera "??" pour les parties qu'il ne peut pas trouver.

Si le programme ne trouve pas d'informations sur les symboles pour une adresse, il affichera l'adresse sous forme hexadécimale.

-a, --all

-e fichier_objet
Cette option spécifie le fichier objet d'entrée. Par défaut, il s'agit du fichier nommé a.out.
-f, --functions
Affiche le nom de la fonction pour chaque adresse. C'est le comportement par défaut.
-i, --inlines
Affiche le nom de la fonction intégrée pour chaque adresse. Si l'adresse ne fait pas partie d'une fonction intégrée, le nom normal de la fonction est affiché. Cette option n'est utile que si l'exécutable a été compilé avec des informations de débogage.
-j, --section section
Affiche les informations d'adresse uniquement pour les adresses situées dans la section spécifiée.
-p, --pretty-print
Affiche le nom du fichier et le numéro de ligne dans un format lisible. C'est le comportement par défaut.
-q, --quiet
N'affiche aucun message d'avertissement ou de diagnostic.
-r, --radix=radix
La base utilisée pour lire les adresses. Cette option n'est utile que lors de la lecture des adresses depuis l'entrée standard.
-s, --basename
Supprime le nom du répertoire des noms de fichiers. Ceci est utile lorsque vous souhaitez afficher les noms des fichiers source sans leurs chemins.
-C[=style], --demangle[=style]

-S, --source
Essayer de deviner le nom du fichier source d'origine. Ceci est utile lorsque vous n'avez que le fichier objet et pas les fichiers source.
-l, --line-numbers
Affiche le nom du fichier et le numéro de ligne pour chaque adresse. C'est le comportement par défaut.
-V, --version
Affiche la version de addr2line et quitte.
--help
Affiche le message d'aide et quitte.

Les arguments adresse sont les adresses à rechercher. Si aucune adresse n'est fournie, elles sont lues depuis l'entrée standard.
