PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

ndbm.h — définitions pour les opérations sur les bases de données ndbm

SYNOPIS

#include <ndbm.h>

DESCRIPTION

L'en-tête <ndbm.h> doit définir le type datum comme une structure, qui doit inclure au moins les membres suivants :

void   *dptr  Un pointeur vers les données de l'application.
size_t  dsize La taille de l'objet pointé par dptr.

L'en-tête <ndbm.h> doit définir le type size_t tel que décrit dans <stddef.h>.

L'en-tête <ndbm.h> doit définir le type DBM.

L'en-tête <ndbm.h> doit définir les constantes symboliques suivantes comme valeurs possibles pour l'argument store_mode de dbm_store():

DBM_INSERT
Insertion de nouvelles entrées uniquement.
DBM_REPLACE
Autoriser le remplacement des entrées existantes.

Les éléments suivants doivent être déclarés comme fonctions et peuvent également être définis comme macros. Les prototypes de fonctions doivent être fournis.

int     dbm_clearerr(DBM *);
void    dbm_close(DBM *);
int     dbm_delete(DBM *, datum);
int     dbm_error(DBM *);
datum   dbm_fetch(DBM *, datum);
datum   dbm_firstkey(DBM *);
datum   dbm_nextkey(DBM *);
DBM    *dbm_open(const char *, int, mode_t);
int     dbm_store(DBM *, datum, datum, int);

L'en-tête <ndbm.h> doit définir le type mode_t via typedef, tel que décrit dans <sys/types.h>.
