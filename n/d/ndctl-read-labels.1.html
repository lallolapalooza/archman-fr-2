NOM

ndctl-read-labels - lire la zone d'étiquette sur un dimm ou un ensemble de dimms

SYNTAXE

ndctl read-labels <nmem0> [<nmem1>..<nmemN>] [<options>]

DESCRIPTION

La zone d'étiquette d'espace de noms est une petite partition persistante de capacité disponible sur certains périphériques NVDIMM. La zone d'étiquette est utilisée pour approvisionner un ou plusieurs espaces de noms à partir de régions. Cette commande déverse les données binaires brutes de la zone d'étiquette d'un dimm vers la sortie standard ou un fichier. Dans le cas de plusieurs dimms, les données sont concaténées.

OPTIONS

<périphérique(s) mémoire>

Un nom de périphérique nmemX, ou un numéro d'identifiant de dimm. Restreindre l'opération aux dimms spécifiés. Le mot-clé all peut être spécifié pour indiquer l'absence de restriction, cependant, cela équivaut à ne pas fournir d'option --dimm du tout.

-s, --size=

Limiter l'opération au nombre donné d'octets. Une taille de 0 indique d'opérer sur toute la capacité de l'étiquette.

-O, --offset=

Commencer l'opération au décalage donné dans la zone d'étiquette.

-b, --bus=

Un numéro d'identifiant de bus, ou une chaîne de fournisseur (par exemple "ACPI.NFIT"). Restreindre l'opération aux bus spécifiés. Le mot-clé all peut être spécifié pour indiquer l'absence de restriction, cependant, cela équivaut à ne pas fournir d'option --bus du tout.

-v

Activer les messages de débogage dans la bibliothèque (si ndctl a été compilé avec la journalisation et le débogage activés).

-I, --index

Restreindre la portée de l'opération d'étiquette uniquement à la zone d'index. Ceci est utile pour déterminer si la zone d'étiquette du dimm est initialisée. Notez que cette option et --size/--offset sont mutuellement exclusives.

-o, --output

fichier de sortie

-j, --json

analyser les données de l'étiquette en json en supposant le format de la Spécification d'espace de noms NVDIMM.

-u, --human

activer la sortie json et convertir les formats numériques en chaînes lisibles par l'homme, par exemple afficher la taille en termes de "KB", "MB", "GB", etc. au lieu de nombres signés sur 64 bits selon le format d'échange JSON (implique --json).
