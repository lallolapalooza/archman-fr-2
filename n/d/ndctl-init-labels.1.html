NOM

ndctl-init-labels - initialise la zone d'étiquettes de noms d'espace sur une dimm ou un ensemble de dimms

SYNTAXE

ndctl init-labels <nmem0> [<nmem1>..<nmemN>] [<options>]

DESCRIPTION

La zone d'étiquettes de noms d'espace est une petite partition persistante de capacité disponible sur certains périphériques NVDIMM. La zone d'étiquettes est utilisée pour provisionner un ou plusieurs noms d'espace à partir de régions. À partir de la version 4.10, le noyau respecte les étiquettes pour subdiviser la mémoire PMEM si toutes les DIMM d'un ensemble d'entrelacement / région ont un bloc d'indice de nom d'espace valide.

Cette commande peut être utilisée pour initialiser le bloc d'indice d'étiquettes s'il est manquant ou le réinitialiser s'il est endommagé. Notez que la réinitialisation détruit effectivement toutes les étiquettes de noms d'espace existantes sur la DIMM.

EXEMPLE

Trouver les DIMM qui composent une région donnée :

# ndctl list -RD --region=region1
{
  "dimms":[
    {
      "dev":"nmem0",
      "id":"8680-56341200"
    }
  ],
  "regions":[
    {
      "dev":"region1",
      "size":268435456,
      "available_size":0,
      "type":"pmem",
      "mappings":[
        {
          "dimm":"nmem0",
          "offset":13958643712,
          "length":268435456
        }
      ]
    }
  ]
}

Désactiver cette région afin que la zone d'étiquettes de la DIMM puisse être écrite depuis l'espace utilisateur :

# ndctl disable-region region1

Initialiser les étiquettes :

# ndctl init-labels nmem0

Réactiver la région :

# ndctl enable-region region1

Créer un nom d'espace dans cette région :

# ndctl create-namespace --region=region1

OPTIONS

<périphérique(s) mémoire>

Un nom de périphérique nmemX, ou un numéro d'identifiant de dimm. Restreint l'opération aux dimm spécifiées. Le mot-clé all peut être spécifié pour indiquer l'absence de restriction, mais cela équivaut à ne pas fournir d'option --dimm du tout.

-s, --size=

Limite l'opération au nombre d'octets donné. Une taille de 0 indique d'opérer sur la capacité totale de l'étiquette.

-O, --offset=

Commence l'opération au décalage donné dans la zone d'étiquette.

-b, --bus=

Un numéro d'identifiant de bus, ou une chaîne de fournisseur (par exemple, "ACPI.NFIT"). Restreint l'opération aux bus spécifiés. Le mot-clé all peut être spécifié pour indiquer l'absence de restriction, mais cela équivaut à ne pas fournir d'option --bus du tout.

-v

Active les messages de débogage verbeux dans la bibliothèque (si ndctl a été compilé avec la journalisation et le débogage activés).

-f, --force

Force l'initialisation de l'espace d'étiquettes même s'il semble y avoir un indice de nom d'espace existant / valide. Attention, cela détruira tous les noms d'espace définis sur la dimm.

-V, --label-version

Initialise avec une version spécifique d'étiquettes provenant de la spécification d'étiquettes de noms d'espace. Par défaut, version 1.1.
