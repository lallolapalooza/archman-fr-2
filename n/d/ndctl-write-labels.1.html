NOM

ndctl-write-labels - écrire des données dans la zone d'étiquette d'un dimm

SYNOPIS

ndctl write-labels <nmem> [-i <nom_fichier>]

DESCRIPTION

La zone d'étiquette de l'espace de noms est une petite partition persistante de capacité disponible sur certains périphériques NVDIMM. La zone d'étiquette est utilisée pour provisionner un ou plusieurs espaces de noms à partir de régions. Lire les données depuis le nom de fichier d'entrée, ou depuis stdin, et les écrire dans le périphérique <nmem> donné. Notez que le périphérique ne doit pas être actif dans une région, sinon le noyau n'autorisera pas l'accès en écriture à la zone de données d'étiquette du périphérique.

OPTIONS

<périphérique(s) de mémoire>

Un nom de périphérique nmemX, ou un numéro d'identifiant de dimm. Restreindre l'opération aux dimms spécifiés. Le mot-clé all peut être spécifié pour indiquer l'absence de restriction, cependant cela revient à ne pas fournir d'option --dimm du tout.

-s, --size=

Limiter l'opération au nombre d'octets donné. Une taille de 0 indique d'opérer sur toute la capacité de l'étiquette.

-O, --offset=

Commencer l'opération au décalage donné dans la zone d'étiquette.

-b, --bus=

Un numéro d'identifiant de bus, ou une chaîne de fournisseur (par exemple, "ACPI.NFIT"). Restreindre l'opération aux bus spécifiés. Le mot-clé all peut être spécifié pour indiquer l'absence de restriction, cependant cela revient à ne pas fournir d'option --bus du tout.

-v

Activer les messages de débogage détaillés dans la bibliothèque (si ndctl a été compilé avec la journalisation et le débogage activés).

-i, --input

fichier d'entrée
