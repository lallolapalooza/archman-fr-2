NOM

ndptool — Outil du protocole de découverte de voisins

SYNTAXE

ndptool -h

ndptool [OPTIONS] COMMANDE

DESCRIPTION

ndptool est un outil qui fournit un wrapper autour des messages du protocole de découverte de voisins.

OPTIONS

-h, --help
Imprime le texte d'aide sur la console et quitte.
-v, --verbose
Augmente le niveau de verbosité de la sortie.
-t type, --msg-type type
Type de message spécifié. Les types suivants sont pris en charge :

rs — Router Solicitation (Requête de routeur).

ra — Router Advertisement (Annonce de routeur).

ns — Neighbor Solicitation (Requête de voisin).

na — Neighbor Advertisement (Annonce de voisin).

-i ifname, --ifname ifname
Nom de l'interface spécifié.
-D dest, --dest dest
Adresse de destination spécifiée dans l'en-tête IPv6 pour les messages NS/NA.
-T target, --target target
Adresse cible spécifiée dans l'en-tête ICMPv6 pour les messages NS/NA.
-U, --unsolicited
Envoyer une NA non sollicitée.

COMMANDE

monitor
Surveille les messages NDP entrants et les affiche.
send
Envoie un message NDP du type spécifié.

AUTEUR

Jiri Pirko est l'auteur original et le mainteneur actuel de libndp.
