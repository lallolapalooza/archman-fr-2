NOM

ndpexhaust26

SYNTAXE

ndpexhaust26 [-acpPTUrRm] [-s adresse_ip6_source] interface reseau-cible

OPTIONS

 -a      ajoute un en-tête hop-by-hop avec alerte de routeur
 -c      ne calcule pas la somme de contrôle pour gagner du temps
 -p      envoie des requêtes d'écho ICMPv6
 -P      envoie une réponse d'écho ICMPv6
 -T      envoie une exceedance de durée de vie ICMPv6
 -U      envoie un ICMPv6 inaccessible (pas de route)
 -r      randomise la source depuis votre préfixe /64
 -R      randomise entièrement la source
 -m      génère un paquet de taille maximale
 -s adresse_ip6_source  utilise cette adresse IPv6 source
Inonde le réseau /64 cible avec des messages d'erreur ICMPv6 TooBig.
Cette version de l'outil est beaucoup plus efficace que ndpexhaust6.
