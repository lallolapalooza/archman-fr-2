NOM

ndctl-write-infoblock - générer et écrire un bloc d'information

SYNTAXE

ndctl write-infoblock [<namespaceX.Y> | -o <fichier> | --stdout] [<options>]

DESCRIPTION

Comme décrit dans la section théorie de fonctionnement de ndctl-create-namespace(1), la capacité brute d'un espace de noms peut encapsuler une personnalité, ou mode de fonctionnement. Spécifiquement, le mode peut être réglé sur l'un de ceux-ci : "sector", "fsdax", et "devdax". Chacun de ces modes est défini par un format de bloc d'information qui identifie uniquement le mode de fonctionnement. La commande write-infoblock sait générer un bloc d'information "fsdax" ou "devdax" par rapport à la taille d'image spécifiée.

Le bloc généré peut être écrit dans un espace de noms existant (à condition que cet espace de noms ne soit pas actuellement actif), écrit dans un fichier, ou redirigé vers la sortie standard.


Attention

Cette commande est une fonctionnalité de débogage qui peut générer des fichiers d'image avec des blocs d'information valides, mais aussi des blocs d'information invalides pour tester le noyau. Utilisez les options --offset et --align avec précaution. Notamment, --offset doit correspondre au décalage d'adresse physique réel de l'espace de noms auquel il est appliqué, et --align doit être l'une des tailles de page prises en charge par l'architecture.

OPTIONS

<namespace(s)>

Un ou plusieurs noms de périphériques namespaceX.Y. Le mot-clé all peut être spécifié pour opérer sur tous les espaces de noms du système, éventuellement filtrés par ID de bus (voir l'option --bus=) ou par ID de région (voir l'option --region=).

-c, --stdout

Écrire le bloc d'information sur la sortie standard.

-o, --output=

Écrire le bloc d'information dans le fichier donné (mutuellement exclusif avec --stdout).

-m, --mode=

Sélectionner le mode du bloc d'information entre fsdax et devdax. Voir ndctl-create-namespace(1) pour les détails sur --mode.

-s, --size=

Remplacer la taille par défaut déterminée à partir de la taille du fichier spécifié à --output. Dans le cas --stdout, cette option est obligatoire.

-a, --align=

Spécifier la valeur "align" dans le bloc d'information. Dans le cas --mode=devdax, "align" désigne une taille de mappage de page. Aucune validation de cette valeur par rapport aux capacités de mappage de page de la plateforme n'est effectuée.

-u, --uuid=

Remplacer l'UUID généré automatiquement par défaut par la valeur donnée.

-M, --map=

Sélectionner si le tableau de mappage de pages est alloué depuis le périphérique ou depuis la "Mémoire vive système". Par défaut, c'est le périphérique. Voir ndctl-create-namespace(1) pour plus de détails.

-p, --parent-uuid=

Lorsque le bloc d'information est stocké sur un espace de noms étiqueté, l'UUID de l'espace de noms doit correspondre à l'attribut "parent uuid" dans le bloc d'information. Cette option est par défaut l'UUID de l'espace de noms lorsque --output et --stdout ne sont pas utilisés, sinon elle est par défaut un UUID NULL (tous zéros).

-O, --offset=

Par défaut, on suppose que le bloc d'information est écrit dans un espace de noms ou une image d'espace de noms aligné à sa taille. Spécifier cette option EXPERT/DEBUG pour expérimenter / tester la gestion par le noyau des espaces de noms qui violent cette hypothèse.

-r, --region=

Un nom de périphérique regionX, ou un numéro d'ID de région. Restreindre l'opération aux régions spécifiées. Le mot-clé all peut être spécifié pour indiquer l'absence de restriction, cependant c'est la même chose que de ne pas fournir d'option --region du tout.
