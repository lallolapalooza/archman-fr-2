NOM

ndisc6 - outil de découverte de voisins ICMPv6

SYNOPSIS

ndisc6 [-1mnqv] [-r tentatives] [-s ip_source] [-w delai_ms] <adresse IPv6> <interface>

DESCRIPTION

NDisc6 est un programme Unix qui implémente la découverte de voisins ICMPv6 en espace utilisateur (elle est normalement effectuée par le noyau). Il est utilisé pour rechercher l'adresse de liaison de couche 2 (adresse MAC dans le cas d'Ethernet) de tout nœud IPv6 sur le lien.

L'adresse IPv6 du nœud doit être spécifiée, ainsi que l'interface réseau sur laquelle effectuer la recherche.

OPTIONS

-1 ou --single
Quitter dès la réception de la première annonce (par défaut).
-h ou --help
Afficher une aide et quitter.
-m ou --multiple
Attendre d'éventuelles annonces dupliquées et les afficher toutes.
-n ou --numeric
Si le premier paramètre n'est pas une adresse IPv6 valide, ne pas essayer de la résoudre comme un nom d'hôte DNS.
-q ou --quiet
Afficher uniquement l'adresse de liaison de couche 2. Ne rien afficher en cas d'échec. Ceci est principalement utile lors de l'appel du programme depuis un script shell.
-r tentatives ou --retry tentatives
Envoyer la découverte de voisins ICMPv6 autant de fois que spécifié jusqu'à réception d'une réponse, ou abandonner. Par défaut, ndisc6 essaie 3 fois avant d'abandonner (MAX_MULTICAST_SOLICIT et MAX_UNICAST_SOLICIT de la RFC2461).
-s ip_source ou --source ip_source
Spécifier l'adresse IPv6 à utiliser comme source pour les paquets de sollicitation de voisins.
-V ou --version
Afficher la version du programme et sa licence, puis quitter.
-v ou --verbose
Afficher des informations détaillées. C'est le comportement par défaut.
-w delai_ms ou --wait delai_ms
Attendre delai_ms millisecondes pour une réponse avant de réessayer. Par défaut, ndisc6 attend 1 seconde entre chaque tentative (RETRANS_TIMER de la RFC2461).

Si ndisc6 ne reçoit aucune réponse après le nombre spécifié de tentatives en attendant delai_ms millisecondes à chaque fois, il se terminera avec le code 2. En cas d'erreur, il se terminera avec le code 1. Sinon, il se terminera avec le code 0. Cela permet d'utiliser le code de sortie pour voir si un hôte est sur le lien ou non.

DIAGNOSTICS

Si vous n'obtenez aucune réponse alors que vous savez que l'hôte distant est actif, il est très probable qu'il ne soit pas sur le lien, c'est-à-dire qu'il faille traverser un ou plusieurs routeurs pour l'atteindre. Par conception, les nœuds IPv6 ignorent les paquets de découverte de voisins ICMPv6 reçus de nœuds qui ne sont pas sur le même lien (segment Ethernet), par mesure de sécurité. Techniquement, cela est fait en s'assurant que le compteur de sauts (TTL) est de 255.

Notez que vous ne pouvez pas utiliser ndisc6 pour rechercher l'adresse de liaison locale de l'hôte.

SÉCURITÉ

ndisc6 devrait être setuid root pour permettre son utilisation par des utilisateurs non privilégiés. Il abandonnera ses privilèges root avant toute tentative d'envoi ou de réception de données depuis le réseau afin de réduire l'impact potentiel d'une vulnérabilité de sécurité.
