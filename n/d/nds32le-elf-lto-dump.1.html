NOM

lto-dump - Outil pour exporter les fichiers objet d'optimisation en temps de lien (LTO)

SYNTAXE

lto-dump [-list]
[-demangle]
[-defined-only]
[-print-value]
[-name-sort]
[-size-sort]
[-reverse-sort]
[-no-sort]
[-symbol=]
[-objects]
[-type-stats]
[-tree-stats]
[-gimple-stats]
[-dump-level=]
[-dump-body=]
[-help] lto-dump

DESCRIPTION

lto-dump est un outil que vous pouvez utiliser en conjonction avec GCC pour exporter les fichiers objet d'optimisation en temps de lien (LTO).

OPTIONS

-list
Exporte la liste des détails des fonctions et variables.
-demangle
Exporte la sortie démêlée.
-defined-only
Exporte uniquement les symboles définis.
-print-value
Exporte les valeurs initiales des variables.
-name-sort
Trie les symboles par ordre alphabétique.
-size-sort
Trie les symboles par taille.
-reverse-sort
Exporte les symboles dans l'ordre inverse.
-no-sort
Exporte les symboles dans l'ordre d'apparition.
-symbol=
Exporte les détails d'un symbole spécifique.
-objects
Exporte les détails des objets LTO.
-type-stats
Exporte les statistiques des types d'arbres.
-tree-stats
Exporte les statistiques des arbres.
-gimple-stats
Exporte les statistiques des instructions gimple.
-dump-level=
Pour décider du niveau d'optimisation du corps.
-dump-body=
Exporte le corps gimple spécifique.
-help
Affiche l'aide de l'outil d'exportation.
