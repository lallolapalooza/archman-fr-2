NDISASM(1) Le projet Netwide Assembler NDISASM(1)

NOM

ndisasm - Le désassembleur Netwide, un désassembleur de fichiers binaires 80x86

SYNTAXE

ndisasm [ -o origine ] [ -s point-de-synchronisation [...]] [ -a | -i ] [ -b bits ] [ -u ] [ -e longueur-en-tête ] [ -p vendeur ] [ -k décalage,longueur [...]] fichier-entree

DESCRIPTION

La commande ndisasm génère une liste de désassemblage du fichier binaire fichier-entree et la dirige vers la sortie standard.

OPTIONS

-h

Demande à ndisasm de se terminer immédiatement, après avoir affiché un résumé de ses options d'invocation.

-r|-v

Demande à ndisasm de se terminer immédiatement, après avoir affiché son numéro de version.

-o origine

Spécifie l'adresse de chargement notionnelle pour le fichier. Cette option permet à ndisasm d'aligner correctement les adresses listées en marge gauche, ainsi que les adresses cibles des sauts et appels relatifs au PC.

-s point-de-synchronisation

Spécifie manuellement une adresse de synchronisation, de sorte que ndisasm n'émettra aucune instruction machine qui englobe des octets des deux côtés de l'adresse. Ainsi, l'instruction qui commence à cette adresse sera correctement désassemblée.

-e longueur-en-tête

Spécifie un nombre d'octets à ignorer depuis le début du fichier avant de commencer le désassemblage. Cela ne compte pas dans le calcul du décalage de désassemblage : la première instruction désassemblée sera affichée en commençant à l'adresse de chargement donnée.

-k décalage,longueur

Spécifie que longueur octets, commençant au décalage de désassemblage décalage, doivent être ignorés sans générer aucune sortie. Les octets ignorés comptent toujours dans le calcul du décalage de désassemblage.

-a|-i

Active le mode de synchronisation automatique (ou intelligent), dans lequel ndisasm tentera de deviner où la synchronisation doit être effectuée, en examinant les adresses cibles des sauts et appels relatifs qu'il désassemble.

-b bits

Spécifie le mode 16, 32 ou 64 bits. Le mode par défaut est le mode 16 bits.

-u

Spécifie le mode 32 bits, de manière plus concise qu'en utilisant ‘-b 32’.

-p vendeur

Préfère les instructions telles que définies par vendeur en cas de conflit. Les noms de vendeur connus incluent intel, amd, cyrix, et idt. La valeur par défaut est intel.

RESTRICTIONS

ndisasm ne désassemble que les fichiers binaires : il n'a aucune compréhension des informations d'en-tête présentes dans les fichiers objets ou exécutables. Si vous souhaitez désassembler un fichier objet, vous devriez probablement utiliser objdump(1).

Le mode de synchronisation automatique ne résoudra pas nécessairement tous vos problèmes de synchronisation : un marqueur de synchronisation ne peut être placé automatiquement que si une instruction de saut ou d'appel est trouvée pour y faire référence avant que ndisasm ne désassemble cette partie du code. De plus, si des sauts ou des appels erronés résultent du désassemblage de données non-code machine, des marqueurs de synchronisation peuvent être placés à des endroits étranges. N'hésitez pas à désactiver la synchronisation automatique et à revenir à la méthode manuelle si nécessaire.
