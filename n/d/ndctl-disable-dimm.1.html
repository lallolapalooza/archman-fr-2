NOM

ndctl-disable-dimm - désactive un ou plusieurs DIMM inactifs

SYNTAXE

ndctl disable-dimm <dimm> [<options>]

DESCRIPTION

Un objet de périphérique DIMM générique, nommé /dev/nmemX, est enregistré pour chaque périphérique mémoire indiqué dans la table NFIT de l'ACPI, ou un autre mécanisme de découverte de ressources NVDIMM de la plateforme. Le noyau LIBNVDIMM fournit un pilote intégré pour ces périphériques DIMM. Le pilote est responsable de déterminer si le DIMM implémente une zone d'étiquette de namespace, et d'initialiser la copie en mémoire du noyau de ces données d'étiquette.

Le noyau effectue des modifications à l'exécution de ces données lorsque des actions de provisionnement de namespace sont effectuées, et bloque activement l'espace utilisateur pour initier des changements de données d'étiquette pendant que le DIMM est actif dans une région quelconque. La désactivation d'un DIMM, après que toutes les régions dont il est membre aient été désactivées, permet à l'espace utilisateur de mettre à jour manuellement les données d'étiquette à consommer lors de la prochaine activation du DIMM.

OPTIONS

<dimm>

Un nom de périphérique nmemX, ou un identifiant de dimm. Restreint l'opération aux dimm spécifié(s). Le mot-clé all peut être spécifié pour indiquer l'absence de restriction, cependant cela est identique à ne pas fournir d'option --dimm du tout.

-b, --bus=

Un numéro d'identifiant de bus, ou une chaîne de fournisseur (par exemple, "ACPI.NFIT"). Restreint l'opération au(x) bus spécifié(s). Le mot-clé all peut être spécifié pour indiquer l'absence de restriction, cependant cela est identique à ne pas fournir d'option --bus du tout.
