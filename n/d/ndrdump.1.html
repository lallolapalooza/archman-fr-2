NOM

ndrdump - Analyseur et dumpfile de paquets DCE/RPC

SYNTAXE

ndrdump [-c contexte] {canal} {format} {in|out|struct} {fichier}

ndrdump [canal]

ndrdump

DESCRIPTION

ndrdump tente d'analyser le fichier spécifié en utilisant l'analyseur de Samba pour le canal et le format spécifiés. Le troisième argument doit être soit in, out ou struct, selon que les données doivent être analysées comme une requête, une réponse ou une structure publique.

Lancer ndrdump sans arguments listera les canaux pour lesquels des analyseurs sont disponibles.

Lancer ndrdump avec un seul argument listera les fonctions et les structures publiques que Samba peut analyser pour le canal spécifié.

La fonction principale de ndrdump est de déboguer les fonctions internes d'analyse DCE/RPC de Samba. Le fichier analysé est généralement un fichier exporté par la fonction « Exporter les octets de paquet sélectionnés » de wireshark.

L'argument de contexte peut être utilisé pour charger des données de contexte à partir du paquet de requête lors de l'analyse des paquets de réponse (tels que les longueurs de tableau).

VERSION
