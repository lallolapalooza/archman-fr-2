nix3-profile-upgrade(1) Manuel des commandes générales nix3-profile-upgrade(1)

Attention
Ce programme est expérimental et son interface est susceptible de changer.

Nom

nix profile upgrade - met à jour les paquets en utilisant leur flake la plus récente

Synopsis

nix profile upgrade [option…] éléments…

Exemples

•
Mettre à jour tous les paquets qui ont été installés à l'aide d'une référence de flake déverrouillée :
# nix profile upgrade --all
•
Mettre à jour un paquet spécifique par son nom :
# nix profile upgrade hello
•
Mettre à jour tous les paquets qui contiennent « vim » dans leur nom :
# nix profile upgrade --regex '.*vim.*'

Description

Cette commande met à jour un paquet précédemment installé dans un profil Nix, en téléchargeant et en évaluant la dernière version du flake à partir duquel le paquet a été installé.

Attention

Cela ne fonctionne que si vous avez utilisé une référence de flake *déverrouillée* au moment de l'installation, par exemple nixpkgs#hello. Cela ne fonctionne pas si vous avez utilisé une référence de flake *verrouillée* (par exemple, github:NixOS/nixpkgs/13d0c311e3ae923a00f734b43fd1d35b47d8943a#hello), car dans ce cas, la « dernière version » est toujours la même.

Options

•
--all
Correspond à tous les paquets du profil.
•
--profile chemin
Le profil sur lequel opérer.
•
--regex modèle
Une expression régulière pour correspondre à un ou plusieurs paquets du profil.

Options communes d'évaluation

•
--arg nom expr
Passe la valeur expr comme argument nom aux fonctions Nix.
•
--arg-from-file nom chemin
Passe le contenu du fichier chemin comme argument nom aux fonctions Nix.
•
--arg-from-stdin nom
Passe le contenu de stdin comme argument nom aux fonctions Nix.
•
--argstr nom chaîne
Passe la chaîne chaîne comme argument nom aux fonctions Nix.
•
--debugger
Démarre un environnement interactif si l'évaluation échoue.
•
--eval-store url-du-magasin
L' URL du magasin Nix à utiliser pour l'évaluation, c'est-à-dire pour stocker les dérivations (.drv) et les entrées référencées par celles-ci.
•
--impure
Autorise l'accès aux chemins et dépôts mutables.
•
--include / -I chemin
Ajoute chemin aux entrées du chemin de recherche utilisées pour résoudre les chemins de recherche
Cette option peut être donnée plusieurs fois.
Les chemins ajoutés via -I ont priorité sur le paramètre de configuration nix-path et la variable d'environnement NIX_PATH.
•
--override-flake ref-originale ref-résolue
Remplace les registres de flakes, redirigeant ref-originale vers ref-résolue.

Options communes liées aux flakes

•
--commit-lock-file
Valide les modifications dans le fichier de verrouillage du flake.
•
--inputs-from flake-url
Utilise les entrées du flake spécifié comme entrées de registre.
•
--no-registries
Ne permet pas les recherches dans les registres de flakes.
OBSOLÈTE
Utilisez --no-use-registries à la place.
•
--no-update-lock-file
Ne permet aucune mise à jour du fichier de verrouillage du flake.
•
--no-write-lock-file
N'écrit pas le nouveau fichier de verrouillage généré du flake.
•
--output-lock-file chemin-verrouillage-flake
Écrit le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--override-input chemin-entree flake-url
Remplace une entrée de flake spécifique (par exemple, dwarffs/nixpkgs). Ceci implique --no-write-lock-file.
•
--recreate-lock-file
Recrée le fichier de verrouillage du flake à partir de zéro.
OBSOLÈTE
Utilisez nix flake update à la place.
•
--reference-lock-file chemin-verrouillage-flake
Lit le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--update-input chemin-entree
Met à jour une entrée de flake spécifique

Name

nix3-profile-upgrade - Upgrade a profile to a new generation.

Synopsis

nix3-profile upgrade [--help | -?] [--version] [-f | --file file] [--offline] [--option name value] [--refresh] [--repair] [-v | --verbose] [-L | --print-build-logs] [--log-format format] [--quiet] [--debug] [installables…]

Examples

Upgrade the current profile to use the latest generation of the Nixpkgs channel:

$ nix3-profile upgrade

Upgrade a profile with a specific package to a new version from the Nixpkgs channel:

$ nix3-profile upgrade nixpkgs#legacyPackages.x86_64-linux.hello

Upgrade a profile using a flake:

$ nix3-profile upgrade --flake .#my-package

Description

This command installs a new generation of the profile by evaluating the specified installables.

If no installables are specified, this command attempts to upgrade the profile to the latest generation of the default Nixpkgs channel.

This command adds a new generation to the profile, containing the specified installables. The previous generation is kept, allowing you to roll back.

Options that start with -- are options, i.e. they override a Nix configuration value present in nix.conf. For example, --option name value is equivalent to setting name = value; in nix.conf.

The set of installables can be specified either on the command line or in a file.

Note
This command is deprecated and will be removed in a future release. Use nix profile upgrade instead.
Installables are Nix derivations or attribute paths that are evaluated and installed into the profile. They can be specified in several ways:
  • A flake reference, e.g. flake#attribute or path/to/flake#attribute. This installs the specified attribute from the flake registry or the specified flake file.
  • A Nix expression, e.g. <nixpkgs>#legacyPackages.x86_64-linux.hello. This installs the specified attribute from the evaluation of the Nix expression. The Nix expression can be specified using the --expr option.
  • A path to a Nix derivation file (ending in .nix). This installs the derivation from the specified file.

Options

•
--help / -?
Show usage information.
•
--version
Show version information.
•
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.
This option is ignored if --flake is passed, and evaluates installables from the lock file instead of ignoring its previous entry in the lock file.
DEPRECATED
Use nix flake update instead.

Logging-related options

•
--debug
Set the logging verbosity level to ‘debug’.
•
--log-format format
Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
•
--print-build-logs / -L
Print full build logs on standard error.
•
--quiet
Decrease the logging verbosity level.
•
--verbose / -v
Increase the logging verbosity level.

Miscellaneous global options

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

Options that change the interpretation of installables

•
--expr expr
Interpret installables as attribute paths relative to the Nix expression expr.
•
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.

Note

See man nix.conf for overriding configuration settings with command line flags.
