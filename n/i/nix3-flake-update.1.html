nix3-flake-update(1) Manuel des commandes générales nix3-flake-update(1)

Avertissement
Ce programme est expérimental et son interface est susceptible de changer.

Nom

nix flake update - mettre à jour le fichier de verrouillage de flake

Synopsis

nix flake update [option…] entrées…

Exemples

•
Mettre à jour toutes les entrées (c.-à-d. recréer le fichier de verrouillage à partir de zéro) :
# nix flake update
warning: updating lock file '/home/myself/repos/testflake/flake.lock':
• Updated input 'nix':
  'github:NixOS/nix/9fab14adbc3810d5cc1f88672fde1eee4358405c' (2023-06-28)
→ 'github:NixOS/nix/8927cba62f5afb33b01016d5c4f7f8b7d0adde3c' (2023-07-11)
• Updated input 'nixpkgs':
  'github:NixOS/nixpkgs/3d2d8f281a27d466fa54b469b5993f7dde198375' (2023-06-30)
→ 'github:NixOS/nixpkgs/a3a3dda3bacf61e8a39258a0ed9c924eeca8e293' (2023-07-05)
•
Mettre à jour une seule entrée :
# nix flake update nixpkgs
warning: updating lock file '/home/myself/repos/testflake/flake.lock':
• Updated input 'nixpkgs':
  'github:NixOS/nixpkgs/3d2d8f281a27d466fa54b469b5993f7dde198375' (2023-06-30)
→ 'github:NixOS/nixpkgs/a3a3dda3bacf61e8a39258a0ed9c924eeca8e293' (2023-07-05)
•
Mettre à jour une seule entrée d'un flake dans un répertoire différent :
# nix flake update nixpkgs --flake ~/repos/another
warning: updating lock file '/home/myself/repos/another/flake.lock':
• Updated input 'nixpkgs':
  'github:NixOS/nixpkgs/3d2d8f281a27d466fa54b469b5993f7dde198375' (2023-06-30)
→ 'github:NixOS/nixpkgs/a3a3dda3bacf61e8a39258a0ed9c924eeca8e293' (2023-07-05)
Note
Lorsque vous essayez de faire référence à un flake dans un sous-répertoire, écrivez ./another au lieu de another. Sinon, Nix essaiera de rechercher le flake dans le registre.

Description

Cette commande met à jour les entrées dans un fichier de verrouillage (flake.lock). Par défaut, toutes les entrées sont mises à jour. Si le fichier de verrouillage n'existe pas encore, il sera créé. Si des entrées ne sont pas encore dans le fichier de verrouillage, elles seront ajoutées.

Contrairement aux autres commandes nix flake, nix flake update prend une liste de noms d'entrées à mettre à jour comme arguments positionnels et opère sur le flake dans le répertoire courant. Vous pouvez passer un différent flake-url avec --flake pour remplacer la valeur par défaut.

La commande associée nix flake lock crée également des fichiers de verrouillage et ajoute les entrées manquantes, mais est plus sûre car elle ne mettra jamais à jour les entrées déjà présentes dans le fichier de verrouillage.

NAME

nix-store--update-input - Update flake inputs

SYNOPSIS

nix store update-input [--help] [--option name value] [--reference-lock-file flake-lock-path] [--update-input input-path]

DESCRIPTION

This command is a sub-command of nix store, not intended for direct use. It is used to update a specific flake input. The command updates the given flake input by fetching the latest revision of that input and writing the result into the lock file.

OPTIONS

•
--reference-lock-file flake-lock-path
Read the given lock file instead of flake.lock within the top-level flake.
•
--update-input input-path
Update a specific flake input (ignoring its previous entry in the lock file).
DEPRECATED
Use nix flake update instead.

Set the logging verbosity level to ‘debug’.
•

Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
•
--print-build-logs / -L
Print full build logs on standard error.
•
--quiet
Decrease the logging verbosity level.
•
--verbose / -v
Increase the logging verbosity level.

Miscellaneous global options

•

Show usage information.

Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).

•

During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
