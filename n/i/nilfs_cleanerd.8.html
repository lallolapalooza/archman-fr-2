NOM

nilfs_cleanerd - Ramasse-miettes de NILFS2

SYNOPSIS

nilfs_cleanerd [-hV]

nilfs_cleanerd [options] périphérique [répertoire]

DESCRIPTION

nilfs_cleanerd est un démon système qui récupère l'espace disque d'un système de fichiers NILFS2 trouvé dans périphérique.

L'argument optionnel répertoire spécifie le point de montage où le démon opère. Il doit s'agir d'un montage r/w.

Ce programme peut être appelé soit automatiquement par mount.nilfs2(8), soit manuellement par un administrateur. Cependant, il est recommandé aux utilisateurs d'appeler nilfs_cleanerd via mount.nilfs2(8) ou mount(8) et de l'arrêter via umount.nilfs2(8) ou umount(8) afin d'éviter les incohérences d'état entre les outils d'administration.

nilfs_cleanerd affiche son identifiant de processus (pid) sur la sortie standard au démarrage.

OPTIONS

-V, --version
Affiche la version et quitte.
-h, --help
Affiche le message d'aide et quitte.
-c fichier, --conf=fichier
Spécifie le fichier de configuration.
-p intervalle, --protection-period=intervalle
Remplace la période de protection par le nombre de secondes spécifié.

SIGNALS

nilfs_cleanerd réagit à un ensemble de signaux. Vous pouvez envoyer un signal à nilfs_cleanerd en utilisant le PID affiché par la commande mount (ou dans /etc/mtab) :

# mount -t nilfs2

/dev/sdb1 sur /nilfs type nilfs2 (rw,gcpid=PID)
# kill -SIGNAL PID
SIGHUP
Ceci permet à nilfs_cleanerd de procéder à une réinitialisation. Le fichier de configuration (par défaut /etc/nilfs_cleanerd.conf) sera relu.
SIGTERM
nilfs_cleanerd se terminera proprement.
SIGUSR1, SIGUSR2
Réservé pour une utilisation future. Ces signaux font actuellement mourir nilfs_cleanerd.

FICHIERS

/etc/nilfs_cleanerd.conf
Fichier de configuration pour nilfs_cleanerd. Voir nilfs_cleanerd.conf(5) pour les détails.

AUTEUR

Koji Sato

DISPONIBILITÉ

nilfs_cleanerd fait partie du paquet nilfs-utils et est disponible sur https://nilfs.sourceforge.io.
