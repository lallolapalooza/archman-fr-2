nix3-fmt(1) Manuel des commandes générales nix3-fmt(1)

Attention
Ce programme est expérimental et son interface est sujette à modification.

Nom

nix fmt - reformatez votre code dans le style standard

Synopsis

nix fmt [option…] arguments…

Exemples

Avec nixpkgs-fmt:

# flake.nix
{
  outputs = { nixpkgs, self }: {
    formatter.x86_64-linux = nixpkgs.legacyPackages.x86_64-linux.nixpkgs-fmt;
  };
}
  • Formater le flake courant : $ nix fmt
  • Formater un dossier ou un fichier spécifique : $ nix fmt ./dossier ./fichier.nix

Avec nixfmt:

# flake.nix
{
  outputs = { nixpkgs, self }: {
    formatter.x86_64-linux = nixpkgs.legacyPackages.x86_64-linux.nixfmt;
  };
}
•
Formater des fichiers spécifiques : $ nix fmt ./fichier1.nix ./fichier2.nix

Avec Alejandra:

# flake.nix
{
  outputs = { nixpkgs, self }: {
    formatter.x86_64-linux = nixpkgs.legacyPackages.x86_64-linux.alejandra;
  };
}
  • Formater le flake courant : $ nix fmt
  • Formater un dossier ou un fichier spécifique : $ nix fmt ./dossier ./fichier.nix

Description

nix fmt réécrira tous les fichiers Nix (*.nix) dans un format canonique en utilisant le formateur spécifié dans votre flake.

Options

Options courantes d'évaluation

•
--arg nom expression
Passe la valeur expression comme argument nom aux fonctions Nix.
•
--arg-from-file nom chemin
Passe le contenu du fichier chemin comme argument nom aux fonctions Nix.
•
--arg-from-stdin nom
Passe le contenu de stdin comme argument nom aux fonctions Nix.
•
--argstr nom chaine
Passe la chaîne chaine comme argument nom aux fonctions Nix.
•
--debugger
Démarre un environnement interactif si l'évaluation échoue.
•
--eval-store url-store
L'URL du magasin Nix à utiliser pour l'évaluation, c'est-à-dire pour stocker les dérivations (.drv) et les entrées référencées par celles-ci.
•
--impure
Autorise l'accès aux chemins et dépôts modifiables.
•
--include / -I chemin
Ajoute chemin aux entrées du chemin de recherche utilisées pour résoudre les chemins de recherche.
Cette option peut être donnée plusieurs fois.
Les chemins ajoutés via -I ont priorité sur le paramètre de configuration nix-path et la variable d'environnement NIX_PATH .
•
--override-flake ref-originale ref-resolue
Remplace les registres de flakes, redirigeant ref-originale vers ref-resolue.

Options courantes liées aux flakes

•
--commit-lock-file
Valide les changements dans le fichier de verrouillage du flake.
•
--inputs-from url-flake
Utilise les entrées du flake spécifié comme entrées de registre.
•
--no-registries
N'autorise pas les recherches dans les registres de flakes.
OBSOLÈTE
Utilisez --no-use-registries à la place.
•
--no-update-lock-file
Ne pas autoriser de mises à jour du fichier de verrouillage du flake.
•
--no-write-lock-file
Ne pas écrire le nouveau fichier de verrouillage généré du flake.
•
--output-lock-file chemin-verrou-flake
Écrit le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--override-input chemin-entrée url-flake
Remplace une entrée de flake spécifique (par ex. dwarffs/nixpkgs). Cela implique --no-write-lock-file.
•
--recreate-lock-file
Recrée le fichier de verrouillage du flake à partir de zéro.
OBSOLÈTE
Utilisez nix flake update à la place.
•
--reference-lock-file chemin-verrou-flake
Lit le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--update-input chemin-entrée
Met à jour une entrée de flake spécifique (ignorant son entrée précédente dans le fichier de verrouillage).
OBSOLÈTE
Utilisez nix flake update à la place.

Options liées à la journalisation

•
--log-format format
Format de sortie des messages de journal.
Formats possibles : raw, json.
•
-v / -vv / -vvv
Augmente le niveau de verbosité de la sortie.
•
-q / -qq
Diminue le niveau de verbosité de la sortie.

Voir aussi

nix eval(1), nix flake(1), nix(1).

Options liées au journalisation

•
--debug
Définir le niveau de verbosité de la journalisation à « debug ».
•
--log-format format
Définir le format de la sortie du journal ; l'un des raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Imprimer les journaux de construction complets sur la sortie d'erreur standard.
•
--quiet
Diminuer le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmenter le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Afficher les informations d'utilisation.
•
--offline
Désactiver les substituts et considérer tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définir le paramètre de configuration Nix nom à valeur (en remplaçant nix.conf).
•
--refresh
Considérer tous les fichiers précédemment téléchargés comme obsolètes.
•
--repair
Pendant l'évaluation, réécrire les fichiers manquants ou corrompus dans le Nix store. Pendant la construction, reconstruire les chemins de store manquants ou corrompus.
•
--version
Afficher les informations de version.

Options qui modifient l'interprétation des installables

•
--expr expr
Interpréter les installables comme des chemins d'attributs relatifs à l'expression Nix expr.
•
--file / -f fichier
Interpréter les installables comme des chemins d'attributs relatifs à l'expression Nix stockée dans fichier. Si fichier est le caractère -, alors une expression Nix sera lue depuis l'entrée standard. Implique --impure.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec des indicateurs de ligne de commande.
