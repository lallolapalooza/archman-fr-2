nix3-flake-archive(1) Manuel des commandes générales nix3-flake-archive(1)

Attention
Ce programme est expérimental et son interface est susceptible de changer.

Nom

nix flake archive - copie une flake et toutes ses entrées dans un magasin

Synopsis

nix flake archive [option…] url-flake

Exemples

•
Copier la flake dwarffs et ses dépendances vers un cache binaire :
# nix flake archive --to file:///tmp/my-cache dwarffs
•
Récupérer la flake dwarffs et ses dépendances dans le magasin Nix local :
# nix flake archive dwarffs
•
Afficher les chemins du magasin des sources de la flake NixOps sans les récupérer :
# nix flake archive --json --dry-run nixops

Description

À COMPLÉTER

Options

•
--dry-run
Montrer ce que cette commande ferait sans le faire.
•
--json
Produire la sortie au format JSON, adaptée à la consommation par un autre programme.
•
--to uri-magasin
URI du magasin Nix de destination

Options communes d'évaluation

•
--arg nom expr
Passer la valeur expr comme argument nom aux fonctions Nix.
•
--arg-from-file nom chemin
Passer le contenu du fichier chemin comme argument nom aux fonctions Nix.
•
--arg-from-stdin nom
Passer le contenu de l'entrée standard comme argument nom aux fonctions Nix.
•
--argstr nom chaîne
Passer la chaîne chaîne comme argument nom aux fonctions Nix.
•
--debugger
Démarrer un environnement interactif si l'évaluation échoue.
•
--eval-store url-magasin
L'URL du magasin Nix à utiliser pour l'évaluation, c'est-à-dire pour stocker les dérivations (.drv) et les entrées référencées par celles-ci.
•
--impure
Autoriser l'accès aux chemins et dépôts modifiables.
•
--include / -I chemin
Ajouter chemin aux entrées du chemin de recherche utilisées pour résoudre les chemins de recherche
Cette option peut être donnée plusieurs fois.
Les chemins ajoutés via -I ont la priorité sur le paramètre de configuration nix-path et la variable d'environnement NIX_PATH.
•
--override-flake ref-original ref-resolue
Remplacer les registres de flakes, redirigeant ref-original vers ref-resolue.

Options communes liées aux flakes

•
--commit-lock-file
Valider les modifications dans le fichier de verrouillage de la flake.
•
--inputs-from url-flake
Utiliser les entrées de la flake spécifiée comme entrées de registre.
•
--no-registries
Ne pas autoriser les recherches dans les registres de flakes.
OBSOLÈTE
Utilisez plutôt --no-use-registries.
•
--no-update-lock-file
Ne pas autoriser de mises à jour du fichier de verrouillage de la flake.
•
--no-write-lock-file
Ne pas écrire le nouveau fichier de verrouillage de la flake généré.
•
--output-lock-file chemin-verrou-flake
Écrire le fichier de verrouillage donné au lieu de flake.lock dans la flake de niveau supérieur.
•
--override-input chemin-entrée url-flake
Remplacer une entrée de flake spécifique (par ex. dwarffs/nixpkgs). Ceci implique --no-write-lock-file.
•
--recreate-lock-file
Recréer le fichier de verrouillage de la flake à partir de zéro.
OBSOLÈTE
Utilisez plutôt nix flake update.
•
--reference-lock-file chemin-verrou-flake
Lire le fichier de verrouillage donné au lieu de flake.lock dans la flake de niveau supérieur.
•
--update-input chemin-entrée
Mettre à jour une entrée de flake spécifique (en ignorant son entrée précédente dans le fichier de verrouillage).
OBSOLÈTE
Utilisez plutôt nix flake update.

Options liées à la journalisation

">
•
--debug
Définit le niveau de verbosité de la journalisation sur ‘debug’.
•
--log-format format
Définit le format de la sortie de journalisation ; l'un des raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Affiche les journaux de construction complets sur l'erreur standard.
•
--quiet
Diminue le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmente le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Affiche les informations d'utilisation.
•
--offline
Désactive les substituts et considère tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définit le paramètre de configuration Nix nom sur valeur (remplaçant nix.conf).
•
--refresh
Considère tous les fichiers précédemment téléchargés comme obsolètes.
•
--repair
Pendant l'évaluation, réécrit les fichiers manquants ou corrompus dans le Nix store. Pendant la construction, reconstruit les chemins de magasin manquants ou corrompus.
•
--version
Affiche les informations de version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec les indicateurs de ligne de commande.
