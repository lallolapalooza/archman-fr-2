nix3-hash-convert(1)

Paquet: nix

Licences: LGPL-2.1-only

nix3-hash-convert(1) Manuel des commandes générales nix3-hash-convert(1)

Avertissement
Ce programme est expérimental et son interface est susceptible de changer.

Nom

nix hash convert - convertir entre les formats de hachage

Synopsis

nix hash convert [option…] hachages…

Exemples

•
Convertir un hachage en nix32 (un encodage en base 32 avec un ensemble de caractères spécifique à Nix).
$ nix hash convert --hash-algo sha1 --to nix32 800d59cfcd3c05e900cb4e214be48f6b886a08df
vw46m23bizj4n8afrc0fj19wrp7mj3c0
•
Convertir un hachage au format sri qui inclut une spécification d'algorithme :
# nix hash convert --hash-algo sha1 800d59cfcd3c05e900cb4e214be48f6b886a08df
sha1-gA1Zz808BekAy04hS+SPa4hqCN8=
ou avec un format --to explicite :
# nix hash convert --hash-algo sha1 --to sri 800d59cfcd3c05e900cb4e214be48f6b886a08df
sha1-gA1Zz808BekAy04hS+SPa4hqCN8=
•
Vérifier le format d'entrée du hachage :
# nix hash convert --hash-algo sha256 --from nix32 ungWv48Bz+pBQUDeXa4iI7ADYaOWF3qctBD/YfIAFa0=
error: input hash 'ungWv48Bz+pBQUDeXa4iI7ADYaOWF3qctBD/YfIAFa0=' does not have the expected format '--from nix32'
# nix hash convert --hash-algo sha256 --from nix32 1b8m03r63zqhnjf7l5wnldhh7c134ap5vpj0850ymkq1iyzicy5s
sha256-ungWv48Bz+pBQUDeXa4iI7ADYaOWF3qctBD/YfIAFa0=

Description

nix hash convert convertit les hachages d'un encodage à un autre.

Options

•
--from format-hachage
Format de hachage (base16, nix32, base64, sri).
•
--hash-algo algo-hachage
Algorithme de hachage (md5, sha1, sha256, ou sha512). Peut être omis pour les hachages SRI.
•
--to format-hachage
Format de hachage (base16, nix32, base64, sri). Par défaut : sri.

Options liées à la journalisation

•
--debug
Définit le niveau de verbosité de la journalisation sur « debug ».
•
--log-format format
Définit le format de la sortie des logs ; l'un parmi raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Affiche les logs de construction complets sur la sortie d'erreur standard.
•
--quiet
Diminue le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmente le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Affiche les informations d'utilisation.
•
--offline
Désactive les substituts et considère tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définit le paramètre de configuration Nix nom à valeur (remplaçant nix.conf).
•
--refresh
Considère tous les fichiers précédemment téléchargés comme non à jour.
•
--version
Affiche les informations sur la version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec des options de ligne de commande.
