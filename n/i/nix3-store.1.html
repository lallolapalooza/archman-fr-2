nix3-store(1) Manuel des commandes générales nix3-store(1)

Attention
Ce programme est expérimental et son interface est susceptible d'être modifiée.

Nom

nix store - manipuler un magasin Nix

Synopsis

nix store [option…] sous-commande

où sous-commande est l'une des suivantes :

  • nix store add - Ajouter un fichier ou un répertoire au magasin Nix
  • nix store add-file - Obsolète. Utilisez plutôt nix store add --mode flat.
  • nix store add-path - Alias obsolète vers nix store add.
  • nix store cat - afficher le contenu d'un fichier du magasin Nix sur stdout
  • nix store copy-log - copier les journaux de build entre les magasins Nix
  • nix store copy-sigs - copier les signatures des chemins du magasin depuis les substituts
  • nix store delete - supprimer des chemins du magasin Nix
  • nix store diff-closures - montrer quels paquets et quelles versions ont été ajoutés et supprimés entre deux fermetures
  • nix store dump-path - sérialiser un chemin du magasin vers stdout au format NAR
  • nix store gc - effectuer une récupération de place sur un magasin Nix
  • nix store info - tester si un magasin est accessible
  • nix store ls - afficher des informations sur un chemin dans le magasin Nix
  • nix store make-content-addressed - réécrire un chemin ou une fermeture sous forme adressée par contenu
  • nix store optimise - remplacer les fichiers identiques dans le magasin par des liens physiques
  • nix store path-from-hash-part - obtenir un chemin du magasin à partir de sa partie de hachage
  • nix store ping - tester si un magasin est accessible
  • nix store prefetch-file - télécharger un fichier dans le magasin Nix
  • nix store repair - réparer les chemins du magasin
  • nix store sign - signer les chemins du magasin avec une clé locale
  • nix store verify - vérifier l'intégrité des chemins du magasin

Options

Options liées aux journaux

•
--debug
Définir le niveau de verbosité des journaux sur ‘debug’.
•
--log-format format
Définir le format de la sortie des journaux ; l'un parmi raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Afficher les journaux de build complets sur l'erreur standard.
•
--quiet
Diminuer le niveau de verbosité des journaux.
•
--verbose / -v
Augmenter le niveau de verbosité des journaux.

Options globales diverses

•
--help
Afficher les informations d'utilisation.
•
--offline
Désactiver les substituts et considérer tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définir le paramètre de configuration Nix nom sur valeur (en remplaçant nix.conf).
•
--refresh
Considérer tous les fichiers précédemment téléchargés comme non à jour.
•
--version
Afficher les informations de version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec les options de la ligne de commande.
