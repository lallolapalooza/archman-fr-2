nix3-profile-wipe-history(1) Manuel des commandes générales nix3-profile-wipe-history(1)

Avertissement
Ce programme est expérimental et son interface est sujette à modification.

Nom

nix profile wipe-history - supprimer les versions non actuelles d'un profil

Synopsis

nix profile wipe-history [option…]

Exemples

•
Supprimer toutes les versions du profil par défaut plus anciennes que 100 jours :
# nix profile wipe-history --profile /tmp/profile --older-than 100d
removing profile version 515
removing profile version 514

Description

Cette commande supprime les versions non actuelles d'un profil, rendant impossible le retour à ces versions. Par défaut, toutes les versions non actuelles sont supprimées. Avec --older-than Nd, toutes les versions non actuelles plus anciennes que N jours sont supprimées.

Options

•
--dry-run
Affiche ce que cette commande ferait sans réellement l'exécuter.
•
--older-than age
Supprime les versions plus anciennes que l'âge spécifié. age doit être au format Nd, où N représente un nombre de jours.
•
--profile chemin
Le profil sur lequel opérer.

Options liées à la journalisation

•
--debug
Définit le niveau de verbosité de la journalisation sur 'debug'.
•
--log-format format
Définit le format de la sortie de journalisation ; l'un des formats suivants : raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Affiche les journaux de construction complets sur la sortie standard d'erreur.
•
--quiet
Diminue le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmente le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Affiche les informations d'utilisation.
•
--offline
Désactive les substituts et considère tous les fichiers téléchargés précédemment comme à jour.
•
--option nom valeur
Définit le paramètre de configuration Nix nom à valeur (remplaçant nix.conf).
•
--refresh
Considère tous les fichiers téléchargés précédemment comme obsolètes.
•
--version
Affiche les informations de version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec des indicateurs de ligne de commande.
