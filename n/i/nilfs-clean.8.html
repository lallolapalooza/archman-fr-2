NOM

nilfs-clean - exécute le collecteur de déchets sur le système de fichiers NILFS

SYNTAXE

nilfs-clean [options] [périphérique]

DESCRIPTION

Le programme nilfs-clean communique avec le programme nilfs_cleanerd(8) et contrôle l'exécution du ramasse-miettes (GC) sur les systèmes de fichiers NILFS2. Il peut être utilisé pour exécuter manuellement le ramasse-miettes d'un système de fichiers monté sur périphérique afin d'augmenter l'espace libre.

Si une commande GC est spécifiée par l'une des options suivantes (c'est-à-dire les options ´-c´, ´-s´, ´-r´, et ´-l´), la commande est envoyée et exécutée sur le programme nilfs_cleanerd(8). Si aucune commande n'est spécifiée, nilfs-clean déclenche simplement un nettoyage en une seule passe.

Lorsque périphérique est omis, nilfs-clean sélectionne un système de fichiers NILFS2 actif dans le système.

Cette commande n'est valide que pour les systèmes de fichiers NILFS2 montés, et échouera si le périphérique n'a pas de montages actifs.

OPTIONS

-b, --break, --stop
Arrête le ramasse-miettes.
-c, --reload[=fichier_config]
Demande le rechargement du fichier de configuration pour le processus de nettoyage. Si un fichier de configuration optionnel est donné, le fichier est lu par le programme nilfs_cleanerd(8) et la configuration du nettoyeur est réinitialisée aux informations. Si aucun argument n'est donné, un fichier de configuration sélectionné par nilfs_cleanerd(8) sera rechargé.
-l, --status
Affiche le statut du nettoyeur.
-h, --help
Affiche le message d'aide et quitte.
-m, --min-reclaimable-blocks=NOMBRE[%]
Spécifie le nombre minimum de blocs récupérables dans un segment avant qu'il ne puisse être nettoyé. Si l'argument est suivi d'un signe de pourcentage, il représente le ratio de blocs dans un segment. Cet argument n'aura d'effet que si le drapeau use_set_suinfo est défini dans le fichier de configuration.
-p, --protection-period=intervalle
Définit la période de protection pour une exécution du nettoyeur. Le paramètre intervalle est une valeur entière et spécifie le temps minimum pendant lequel les données supprimées ou remplacées seront conservées dans le système de fichiers. Des valeurs plus petites augmenteront l'espace libre créé par le ramasse-miettes. Optionnellement, le paramètre intervalle peut être suffixé par l'un des descripteurs d'unité suivants : ´s´, ´m´, ´h´, ´d´,´w´,´M´, ou ´Y´, pour secondes, minutes, heures, jours, semaines, mois ou années, respectivement.
-q, --quit
Arrête le démon nettoyeur.
-r, --resume
Reprend le ramasse-miettes.
-s, --suspend
Suspend le ramasse-miettes. Notez que si les utilisateurs suspendent manuellement le ramasse-miettes avec cette option, il ne redémarrera pas automatiquement tant que l'utilisateur n'aura pas repris le ramasse-miettes.
-S, --speed=NOMBRE[/SECONDES]
Définit la vitesse du ramasse-miettes pour une exécution du nettoyeur.
-v, --verbose
Mode verbeux.
-V, --version
Affiche la version et quitte.
