nix3-edit(1) Manuel des commandes générales nix3-edit(1)

Attention
Ce programme est expérimental et son interface est sujette à modification.

Nom

nix edit - ouvre l'expression Nix d'un paquet Nix dans $EDITOR

Synopsis

nix edit [option…] installable

Exemples

•
Ouvre l'expression Nix du paquet GNU Hello :
# nix edit nixpkgs#hello
•
Obtient le nom de fichier et le numéro de ligne utilisés par nix edit :
# nix eval --raw nixpkgs#hello.meta.position
/nix/store/fvafw0gvwayzdan642wrv84pzm5bgpmy-source/pkgs/applications/misc/hello/default.nix:15

Description

Cette commande ouvre l'expression Nix d'une dérivation dans un éditeur. Le nom de fichier et le numéro de ligne de la dérivation sont tirés de son attribut meta.position. stdenv.mkDerivation de Nixpkgs définit cet attribut à l'emplacement de la définition des attributs de dérivation meta.description, version ou name.

L'éditeur à invoquer est spécifié par la variable d'environnement EDITOR. Par défaut, il s'agit de cat. Si l'éditeur est emacs, nano, vim ou kak, il reçoit le numéro de ligne de la dérivation à l'aide de l'argument +<lineno>.

Options

Options communes d'évaluation

•
--arg name expr
Passe la valeur expr comme argument name aux fonctions Nix.
•
--arg-from-file name path
Passe le contenu du fichier path comme argument name aux fonctions Nix.
•
--arg-from-stdin name
Passe le contenu de stdin comme argument name aux fonctions Nix.
•
--argstr name string
Passe la chaîne string comme argument name aux fonctions Nix.
•
--debugger
Démarre un environnement interactif si l'évaluation échoue.
•
--eval-store store-url
L'URL du store Nix à utiliser pour l'évaluation, c'est-à-dire pour stocker les dérivations (.drv) et les entrées référencées par celles-ci.
•
--impure
Autorise l'accès aux chemins et dépôts mutables.
•
--include / -I path
Ajoute path aux entrées du chemin de recherche utilisées pour résoudre les chemins de recherche
Cette option peut être donnée plusieurs fois.
Les chemins ajoutés via -I ont la priorité sur le paramètre de configuration nix-path et la variable d'environnement NIX_PATH .
•
--override-flake original-ref resolved-ref
Remplace les registres de flake, redirigeant original-ref vers resolved-ref.

Options communes liées aux flakes

•
--commit-lock-file
Valide les modifications dans le fichier de verrouillage du flake.
•
--inputs-from flake-url
Utilise les entrées du flake spécifié comme entrées du registre.
•
--no-registries
Ne permet pas les recherches dans les registres de flakes.
OBSOLÈTE
Utiliser --no-use-registries à la place.
•
--no-update-lock-file
Ne permet aucune mise à jour du fichier de verrouillage du flake.
•
--no-write-lock-file
N'écrit pas le nouveau fichier de verrouillage généré du flake.
•
--output-lock-file flake-lock-path
Écrit le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--override-input input-path flake-url
Remplace une entrée de flake spécifique (par exemple dwarffs/nixpkgs). Ceci implique --no-write-lock-file.
•
--recreate-lock-file
Recrée le fichier de verrouillage du flake à partir de zéro.
OBSOLÈTE
Utiliser nix flake update à la place.
•
--reference-lock-file flake-lock-path
Lit le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--update-input input-path
Met à jour une entrée de flake spécifique (en ignorant son entrée précédente dans le fichier de verrouillage).
OBSOLÈTE
Utiliser nix flake update à la place.

Options liées à la journalisation

•
--debug
Régler le niveau de verbosité des journaux sur ‘debug’.
•
--log-format format
Définir le format de sortie des journaux ; l'un des choix est raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Afficher les journaux de construction complets sur la sortie d'erreur standard.
•
--quiet
Diminuer le niveau de verbosité des journaux.
•
--verbose / -v
Augmenter le niveau de verbosité des journaux.

Options globales diverses

•
--help
Afficher les informations d'utilisation.
•
--offline
Désactiver les substituts et considérer tous les fichiers téléchargés précédemment comme à jour.
•
--option name value
Définir le paramètre de configuration Nix name à la valeur value (en remplaçant nix.conf).
•
--refresh
Considérer tous les fichiers précédemment téléchargés comme obsolètes.
•
--repair
Pendant l'évaluation, réécrire les fichiers manquants ou corrompus dans le Nix store. Pendant la construction, reconstruire les chemins de magasin manquants ou corrompus.
•
--version
Afficher les informations de version.

Options qui modifient l'interprétation des installables

•
--expr expr
Interpréter les installables comme des chemins d'attributs relatifs à l'expression Nix expr.
•
--file / -f file
Interpréter les installables comme des chemins d'attributs relatifs à l'expression Nix stockée dans file. Si file est le caractère -, alors une expression Nix sera lue depuis l'entrée standard. Implique --impure.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec des indicateurs de ligne de commande.
