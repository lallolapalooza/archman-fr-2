nix3-profile(1) Manuel des commandes générales nix3-profile(1)

Avertissement
Ce programme est expérimental et son interface est susceptible de changer.

Nom

nix profile - gérer les profils Nix

Synopsis

nix profile [option…] sous-commande

où sous-commande est l'une des suivantes :

  • nix profile diff-closures - afficher la différence de fermeture entre chaque version d'un profil
  • nix profile history - afficher toutes les versions d'un profil
  • nix profile install - installer un paquet dans un profil
  • nix profile list - lister les paquets installés
  • nix profile remove - supprimer des paquets d'un profil
  • nix profile rollback - revenir à la version précédente ou à une version spécifiée d'un profil
  • nix profile upgrade - mettre à jour des paquets en utilisant leur flake la plus récente
  • nix profile wipe-history - supprimer les versions non courantes d'un profil

Description

nix profile vous permet de créer et de gérer des profils Nix. Un profil Nix est un ensemble de paquets qui peuvent être installés et mis à jour indépendamment les uns des autres. Les profils Nix sont versionnés, ce qui permet de revenir facilement en arrière.

Fichiers

Profils

Un répertoire qui contient des liens vers les profils gérés par nix-env et nix profile :

  • $XDG_STATE_HOME/nix/profiles pour les utilisateurs réguliers
  • $NIX_STATE_DIR/profiles/per-user/root si l'utilisateur est root

Un profil est un répertoire de liens symboliques vers des fichiers dans le magasin Nix.

Structure du système de fichiers

Les profils sont versionnés comme suit. Lors de l'utilisation d'un profil nommé chemin, chemin est un lien symbolique vers chemin-N-link, où N est le numéro de version du profil. À son tour, chemin-N-link est un lien symbolique vers un chemin dans le magasin Nix. Par exemple :

$ ls -l ~alice/.local/state/nix/profiles/profile*
lrwxrwxrwx 1 alice users 14 Nov 25 14:35 /home/alice/.local/state/nix/profiles/profile -> profile-7-link
lrwxrwxrwx 1 alice users 51 Oct 28 16:18 /home/alice/.local/state/nix/profiles/profile-5-link -> /nix/store/q69xad13ghpf7ir87h0b2gd28lafjj1j-profile
lrwxrwxrwx 1 alice users 51 Oct 29 13:20 /home/alice/.local/state/nix/profiles/profile-6-link -> /nix/store/6bvhpysd7vwz7k3b0pndn7ifi5xr32dg-profile
lrwxrwxrwx 1 alice users 51 Nov 25 14:35 /home/alice/.local/state/nix/profiles/profile-7-link -> /nix/store/mp0x6xnsg0b8qhswy6riqvimai4gm677-profile

Chacun de ces liens symboliques est une racine pour le collecteur de goût de Nix.

Chaque version de profil contient un fichier manifeste : - manifest.nix utilisé par nix-env. - manifest.json utilisé par nix profile (expérimental).

Lien de profil utilisateur

Un lien symbolique vers le profil actuel de l'utilisateur :

  • ~/.nix-profile
  • $XDG_STATE_HOME/nix/profile si use-xdg-base-directories est défini sur true.

Par défaut, ce lien symbolique pointe vers :

  • $XDG_STATE_HOME/nix/profiles/profile pour les utilisateurs réguliers
  • $NIX_STATE_DIR/profiles/per-user/root/profile pour root

La variable d'environnement PATH doit inclure le sous-répertoire /bin du lien de profil (par ex. ~/.nix-profile/bin) pour que l'environnement de l'utilisateur soit visible par l'utilisateur. Le programme d'installation configure cela par défaut, sauf si vous activez use-xdg-base-directories.

Compatibilité des profils

Avertissement

Une fois que vous avez utilisé nix profile, vous ne pouvez plus utiliser nix-env sans d'abord supprimer $XDG_STATE_HOME/nix/profiles/profile

Une fois qu'un paquet a été installé avec nix profile, vous recevez le message d'erreur suivant lors de l'utilisation de nix-env :

$ nix-env -f '<nixpkgs>' -iA 'hello'
error: nix-env
profile '/home/alice/.local/state/nix/profiles/profile' is incompatible with 'nix-env'; please use 'nix profile' instead

Pour migrer vers nix-env, vous pouvez supprimer votre profil actuel :

Avertissement

Cela supprimera les paquets qui ont été installés auparavant, vous voudrez peut-être sauvegarder ces informations avant d'exécuter la commande.

 $ rm -rf "${XDG_STATE_HOME-$HOME/.local/state}/nix/profiles/profile"

Options

Options liées à la journalisation

<

Options

The following options are available:

•
--debug
Définir le niveau de verbosité des journaux sur ‘debug’.
•
--log-format format
Définir le format de la sortie des journaux ; l'un de raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Afficher les journaux de construction complets sur l'erreur standard.
•
--quiet
Diminuer le niveau de verbosité des journaux.
•
--verbose / -v
Augmenter le niveau de verbosité des journaux.

Options globales diverses

•
--help
Afficher les informations d'utilisation.
•
--offline
Désactiver les substituts et considérer tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définir le paramètre de configuration Nix nom à valeur (remplaçant nix.conf).
•
--refresh
Considérer tous les fichiers précédemment téléchargés comme obsolètes.
•
--version
Afficher les informations de version.

Remarque

Voir man nix.conf pour remplacer les paramètres de configuration avec des indicateurs de ligne de commande.
