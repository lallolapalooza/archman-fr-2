Nom

nix-store - manipuler ou interroger le magasin Nix

Synopsis

nix-store operation [options…] [arguments…] [--option nom valeur] [--add-root chemin]

Description

La commande nix-store effectue des opérations primitives sur le magasin Nix. Vous n'avez généralement pas besoin d'exécuter cette commande manuellement.

nix-store prend exactement un drapeau d'opération qui indique la sous-commande à effectuer. Les opérations suivantes sont disponibles :

  • --realise
  • --serve
  • --gc
  • --delete
  • --query
  • --add
  • --add-fixed
  • --verify
  • --verify-path
  • --repair-path
  • --dump
  • --restore
  • --export
  • --import
  • --optimise
  • --read-log
  • --dump-db
  • --load-db
  • --print-env
  • --generate-binary-cache-key

Ces pages peuvent être consultées hors ligne :

•
man nix-store-<operation>.
Exemple : man nix-store-realise
•
nix-store --help --<operation>
Exemple : nix-store --help --realise
