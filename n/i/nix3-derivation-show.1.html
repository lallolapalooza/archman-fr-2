nix3-derivation-show(1) Manuel des commandes générales nix3-derivation-show(1)

Avertissement
Ce programme est expérimental et son interface est susceptible de changer.

Nom

nix derivation show - affiche le contenu d'une dérivation du store

Synopsis

nix derivation show [option…] installables…

Exemples

•
Affiche la dérivation du store résultant de l'évaluation du paquet Hello :
# nix derivation show nixpkgs#hello
{
"/nix/store/s6rn4jz1sin56rf4qj5b5v8jxjm32hlk-hello-2.10.drv": {
  …
}
}
•
Affiche le graphe de dérivation complet (si disponible) qui a produit votre système NixOS :
# nix derivation show -r /run/current-system
•
Imprime tous les fichiers récupérés à l'aide de fetchurl par le graphe de dépendances de Firefox :
# nix derivation show -r nixpkgs#firefox \
| jq -r '.[] | select(.outputs.out.hash and .env.urls) | .env.urls' \
| uniq | sort
Notez que .outputs.out.hash sélectionne les dérivations à sortie fixe (dérivations qui produisent une sortie avec un hachage de contenu spécifié), tandis que .env.urls sélectionne les dérivations avec un attribut urls.

Description

Cette commande affiche sur la sortie standard une représentation JSON des dérivations du store auxquelles les installables s'évaluent.

Les dérivations du store sont utilisées en interne par Nix. Ce sont des chemins du store avec l'extension .drv qui représentent le graphe de dépendances de construction auquel une expression Nix s'évalue.

Par défaut, cette commande n'affiche que les dérivations de niveau supérieur, mais avec --recursive, elle affiche également leurs dépendances.

nix derivation show génère une carte JSON des chemins du store vers les dérivations dans le format suivant :

{{#include ../../protocols/json/derivation.md}}

Options

•
--recursive / -r
Inclure les dépendances des dérivations spécifiées.
•
--stdin
Lire les installables depuis l'entrée standard. Aucun installable par défaut n'est appliqué.

Options d'évaluation communes

•
--arg name expr
Passe la valeur expr comme argument name aux fonctions Nix.
•
--arg-from-file name path
Passe le contenu du fichier path comme argument name aux fonctions Nix.
•
--arg-from-stdin name
Passe le contenu de stdin comme argument name aux fonctions Nix.
•
--argstr name string
Passe la chaîne string comme argument name aux fonctions Nix.
•
--debugger
Démarre un environnement interactif si l'évaluation échoue.
•
--eval-store store-url
L'URL du store Nix à utiliser pour l'évaluation, c'est-à-dire pour stocker les dérivations (.drv files) et les entrées référencées par celles-ci.
•
--impure
Permet l'accès aux chemins et dépôts mutables.
•
--include / -I path
Ajoute path aux entrées du chemin de recherche utilisées pour résoudre les chemins de recherche
Cette option peut être donnée plusieurs fois.
Les chemins ajoutés via -I ont priorité sur le paramètre de configuration nix-path et sur la variable d'environnement NIX_PATH.
•
--override-flake original-ref resolved-ref
Remplace les registres de flake, redirigeant original-ref vers resolved-ref.

Options communes relatives aux flakes

•
--commit-lock-file
Commite les modifications dans le fichier de verrouillage du flake.
•
--inputs-from flake-url
Utilise les entrées du flake spécifié comme entrées de registre.
•
--no-registries
Ne permet pas les recherches dans les registres de flakes.
OBSOLÈTE
Utilisez plutôt --no-use-registries.
•
--no-update-lock-file
N'autorise aucune mise à jour du fichier de verrouillage du flake.
•
--no-write-lock-file
N'écrit pas le nouveau fichier de verrouillage généré du flake.
•
--output-lock-file flake-lock-path
Écrit le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--override-input input-path flake-url
Remplace une entrée de flake spécifique (par exemple, dwarffs/nixpkgs). Ceci implique --no-write-lock-file.
•
--recreate-lock-file
Recrée le fichier de verrouillage du flake à partir de zéro.
nix3-derivation-show

Name

nix derivation show - show derivation

Synopsis

nix derivation show [option...] substitutable...

Examples

Examples:

$ nix derivation show /nix/store/...?
/nix/store/4k9y1g6kwhh3v1k59gq2r2v4b936s30z-bash-5.1-patch5.drv
  <your-nix-path>/bash/5.1-patch5

Description

Show information about derivations.

The output is a list of derivation paths, followed by the corresponding attribute paths in the Nix expression that produced them.

The term substitutable refers to any value that can be turned into a derivation.

This command is intended to be used from the command line. It is not intended for use by other Nix expressions.

Options

Options:

•
--impure
Allow impure derivations.
•
--json
Print derivation information in JSON format.
•
--legacy-raw
Produce output compatible with Nix 2.x.
•
--no-build-output
Do not print build output.
•
--no-eval-cache
Do not use the Nix evaluation cache.
•
--no-link
Do not build derivations.
•
--raw
Produce a terse, machine-readable output.
•
--rebuild
Rebuild derivations if they are already available.
•
--substitute / -s
Try to download derivations from substituters.
DEPRECATED
Use nix flake update instead.
•
--reference-lock-file flake-lock-path
Read the given lock file instead of flake.lock within the top-level flake.
•
--update-input input-path
Update a specific flake input (ignoring its previous entry in the lock file).
DEPRECATED
Use nix flake update instead.

Logging-related options

•
--debug
Set the logging verbosity level to ‘debug’.
•
--log-format format
Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
•
--print-build-logs / -L
Print full build logs on standard error.
•
--quiet
Decrease the logging verbosity level.
•
--verbose / -v
Increase the logging verbosity level.

Miscellaneous global options

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

Options that change the interpretation of installables

•
--expr expr
Interpret installables as attribute paths relative to the Nix expression expr.
•
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.

Note

See man nix.conf for overriding configuration settings with command line flags.
