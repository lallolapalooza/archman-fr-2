NIKOLA(1) Commandes utilisateur NIKOLA(1)

NOM

Nikola - Générateur de sites statiques et de blogs

SYNOPSIS

Créer un site vide (avec un assistant de configuration) :

nikola init mysite

(Vous pouvez créer un site avec des fichiers de démonstration avec nikola init --demo mysite)

Créer un article (à l'intérieur du répertoire mysite) :

nikola new_post

Construire le site :

nikola build

Démarrer le serveur de test et ouvrir un navigateur :

nikola serve -b

DESCRIPTION

Nikola est un générateur de sites web et de blogs statiques. L'explication la plus courte est qu'il prend des textes que vous avez écrits et les utilise pour créer un dossier rempli de fichiers HTML. Si vous téléchargez ce dossier sur un serveur, vous aurez un site web assez complet, créé avec peu d'efforts.

Son objectif initial est de créer des blogs, mais il prend en charge la plupart des types de sites et peut être utilisé comme un CMS, tant que ce que vous présentez à l'utilisateur est votre propre contenu au lieu de quelque chose que l'utilisateur génère.

Nikola peut faire :

  • Un blog
  • Le site de votre entreprise
  • Votre site personnel
  • Le site d'un projet logiciel
  • Le site d'un livre

Comme les sites basés sur Nikola n'exécutent aucun code sur le serveur, il n'y a aucun moyen de traiter les entrées utilisateur dans les formulaires.

Nikola ne peut pas faire :

  • Twitter
  • Facebook
  • Un traqueur de problèmes
  • N'importe quoi avec des formulaires, en fait (sauf les commentaires !)

Gardez à l'esprit que « statique » ne signifie pas ennuyeux. Vous pouvez avoir des animations, des diapositives ou tout autre truc CSS/HTML5 fantaisiste que vous aimez. Cela signifie seulement que tout ce HTML est déjà généré avant d'être téléchargé. D'autre part, les sites Nikola auront tendance à être riches en contenu. Ce pour quoi Nikola est bon, c'est de diffuser ce que vous écrivez.

COMMANDES

Les commandes les plus basiques nécessaires pour s'en sortir sont :

nikola help
obtenir une liste des commandes, ou de l'aide pour une commande
nikola version [--check]
afficher le numéro de version
nikola init [-d|--demo] [-q|--quiet] dossier
initialiser un nouveau site
nikola build
construire un site
nikola new_post
créer un nouvel article
nikola new_page
créer une nouvelle page
nikola status [--list-drafts] [--list-modified] [--list-scheduled]
afficher l'état du site et du déploiement
nikola check [-v] (-l [--find-sources] [-r] | -f [--clean-files])
vérifier les liens cassés ou les fichiers inconnus
nikola deploy [[preset [preset...]]
déployer le site en utilisant le réglage DEPLOY_COMMANDS
nikola github_deploy [-m MESSAGE_COMMIT]`
déployer le site sur GitHub Pages
nikola serve [-p PORT] [-a ADRESSE] [-d|--detach] [-b|--browser] [-6|--ipv6]
démarrer le serveur web de développement
nikola auto [-p PORT] [-a ADRESSE] [-b|--browser] [-6|--ipv6]
démarrer le serveur web de développement avec reconstructions et rechargements automatisés
nikola plugin [options]
gérer les plugins de l'Index des Plugins ( https://plugins.getnikola.com/ )
nikola theme [options]
gérer les thèmes de l'Index des Thèmes ( https://themes.getnikola.com/ )

Utilisez nikola help pour obtenir une liste de toutes les commandes.
