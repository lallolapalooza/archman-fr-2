nix3-store-copy-log(1)

Paquet: nix

Licences: LGPL-2.1-only

nix3-store-copy-log(1) Manuel des commandes générales nix3-store-copy-log(1)

Avertissement
Ce programme est expérimental et son interface est sujette à modification.

Nom

nix store copy-log - copier les journaux de compilation entre les magasins Nix

Synopsis

nix store copy-log [option…] installables…

Exemples

•
Pour copier le journal de compilation du paquet hello depuis https://cache.nixos.org vers le magasin local :
# nix store copy-log --from https://cache.nixos.org --eval-store auto nixpkgs#hello
Vous pouvez vérifier que le journal est disponible localement :
# nix log --substituters '' nixpkgs#hello
(L'option --substituters '' évite d'interroger https://cache.nixos.org pour le journal.)
•
Pour copier le journal d'une dérivation de magasin spécifique via SSH :
# nix store copy-log --to ssh-ng://machine /nix/store/ilgm50plpmcgjhcp33z6n4qbnpqfhxym-glibc-2.33-59.drv

Description

nix store copy-log copie les journaux de compilation entre deux magasins Nix. Le magasin source est spécifié en utilisant --from et la destination en utilisant --to. Si l'un d'eux est omis, il utilise par défaut le magasin local.

Options

•
--from store-uri
URL du magasin Nix source.
•
--stdin
Lit les installables depuis l'entrée standard. Aucun installable par défaut n'est appliqué.
•
--to store-uri
URL du magasin Nix de destination.

Options courantes d'évaluation

•
--arg name expr
Passe la valeur expr comme argument name aux fonctions Nix.
•
--arg-from-file name path
Passe le contenu du fichier path comme argument name aux fonctions Nix.
•
--arg-from-stdin name
Passe le contenu de l'entrée standard comme argument name aux fonctions Nix.
•
--argstr name string
Passe la chaîne string comme argument name aux fonctions Nix.
•
--debugger
Lance un environnement interactif si l'évaluation échoue.
•
--eval-store store-url
L'URL du magasin Nix à utiliser pour l'évaluation, c'est-à-dire pour stocker les dérivations (.drv) et les entrées référencées par celles-ci.
•
--impure
Autorise l'accès aux chemins et dépôts modifiables.
•
--include / -I path
Ajoute path aux entrées du chemin de recherche utilisées pour résoudre les chemins de recherche.
Cette option peut être donnée plusieurs fois.
Les chemins ajoutés via -I ont la priorité sur le paramètre de configuration nix-path et la variable d'environnement NIX_PATH.
•
--override-flake original-ref resolved-ref
Remplace les registres de flake, redirigeant original-ref vers resolved-ref.

Options courantes liées aux flakes

•
--commit-lock-file
Valide les modifications dans le fichier de verrouillage du flake.
•
--inputs-from flake-url
Utilise les entrées du flake spécifié comme entrées de registre.
•
--no-registries
N'autorise pas les recherches dans les registres de flakes.
OBSOLÈTE
Utilisez --no-use-registries à la place.
•
--no-update-lock-file
Ne permet aucune mise à jour du fichier de verrouillage du flake.
•
--no-write-lock-file
N'écrit pas le fichier de verrouillage du flake nouvellement généré.
•
--output-lock-file flake-lock-path
Écrit le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--override-input input-path flake-url
Remplace une entrée de flake spécifique (par exemple dwarffs/nixpkgs). Ceci implique --no-write-lock-file.
•
--recreate-lock-file
Recrée le fichier de verrouillage du flake à partir de zéro.
OBSOLÈTE
Utilisez nix flake update à la place.
•
--reference-lock-file flake-lock-path
Lit le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--update-input input-path
Met à jour une entrée spécifique d'un flake (en ignorant son entrée précédente dans le fichier de verrouillage).
OBSOLÈTE
Utilisez nix flake update à la place.

Options liées à la journalisation

•
--debug
Définit le niveau de verbosité de la journalisation sur « debug ».
•
--log-format format
Définit le format de la sortie des logs ; l'un des choix possibles est raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Affiche les journaux de compilation complets sur la sortie d'erreur standard.
•
--quiet
Diminue le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmente le niveau de verbosité de la journalisation.

Options diverses globales

•
--help
Affiche les informations d'utilisation.
•
--offline
Désactive les substituts et considère tous les fichiers précédemment téléchargés comme étant à jour.
•
--option name value
Définit le paramètre de configuration Nix name à la valeur value (remplaçant nix.conf).
•
--refresh
Considère tous les fichiers précédemment téléchargés comme étant obsolètes.
•
--repair
Lors de l'évaluation, réécrit les fichiers manquants ou corrompus dans le magasin Nix. Lors de la compilation, recompilie les chemins de magasin manquants ou corrompus.
•
--version
Affiche les informations de version.

Options qui changent l'interprétation des installables

•
--expr expr
Interprète les installables comme des chemins d'attributs relatifs à l'expression Nix expr.
•
--file / -f file
Interprète les installables comme des chemins d'attributs relatifs à l'expression Nix stockée dans file. Si file est le caractère -, alors une expression Nix sera lue depuis l'entrée standard. Implique --impure.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec des options en ligne de commande.
