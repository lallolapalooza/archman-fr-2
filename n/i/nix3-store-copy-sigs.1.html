Attention
Ce programme est expérimental et son interface est susceptible de changer.

Nom

nix store copy-sigs - copie les signatures de chemins de store depuis les substituts

Synopsis

nix store copy-sigs [option…] installables…

Options

•
--stdin
Lit les installables depuis l'entrée standard. Aucune installable par défaut n'est appliquée.
•
--substituter / -s uri-de-store
Copie les signatures depuis le store spécifié.

Options communes d'évaluation

•
--arg nom expr
Passe la valeur expr comme argument nom aux fonctions Nix.
•
--arg-from-file nom chemin
Passe le contenu du fichier chemin comme argument nom aux fonctions Nix.
•
--arg-from-stdin nom
Passe le contenu de l'entrée standard comme argument nom aux fonctions Nix.
•
--argstr nom chaîne
Passe la chaîne chaîne comme argument nom aux fonctions Nix.
•
--debugger
Démarre un environnement interactif si l'évaluation échoue.
•
--eval-store url-du-store
L'URL du store Nix à utiliser pour l'évaluation, c'est-à-dire pour stocker les dérivations (.drv) et les entrées référencées par celles-ci.
•
--impure
Autorise l'accès aux chemins et dépôts modifiables.
•
--include / -I chemin
Ajoute chemin aux entrées du chemin de recherche utilisées pour résoudre les chemins de recherche
Cette option peut être donnée plusieurs fois.
Les chemins ajoutés via -I ont la priorité sur le paramètre de configuration nix-path et la variable d'environnement NIX_PATH.
•
--override-flake ref-originale ref-résolue
Remplace les registres de flakes, redirigeant ref-originale vers ref-résolue.

Options communes liées aux flakes

•
--commit-lock-file
Commite les changements dans le fichier de verrouillage du flake.
•
--inputs-from flake-url
Utilise les entrées du flake spécifié comme entrées de registre.
•
--no-registries
N'autorise pas les recherches dans les registres de flakes.
OBSOLÈTE
Utilisez plutôt --no-use-registries.
•
--no-update-lock-file
N'autorise aucune mise à jour du fichier de verrouillage du flake.
•
--no-write-lock-file
N'écrit pas le nouveau fichier de verrouillage généré du flake.
•
--output-lock-file chemin-verrou-flake
Écrit le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--override-input chemin-entrée flake-url
Remplace une entrée de flake spécifique (par exemple dwarffs/nixpkgs). Ceci implique --no-write-lock-file.
•
--recreate-lock-file
Recrée le fichier de verrouillage du flake à partir de zéro.
OBSOLÈTE
Utilisez plutôt nix flake update.
•
--reference-lock-file chemin-verrou-flake
Lit le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--update-input chemin-entrée
Met à jour une entrée de flake spécifique (ignorant son entrée précédente dans le fichier de verrouillage).
OBSOLÈTE
Utilisez plutôt nix flake update.

Options liées à la journalisation

•
--debug
Définit le niveau de verbosité de la journalisation sur ‘debug’.
•
--log-format format
Définit le format de la sortie de journalisation ; l'un des suivants : raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Imprime les journaux de construction complets sur l'erreur standard.
•
--quiet
Définit le niveau de verbosité de la journalisation sur ‘critical’.
•
--show-trace
Affiche une trace complète en cas d'erreur.
•
--verbose / -v
Augmente le niveau de verbosité de la journalisation. Peut être utilisé plusieurs fois.

Description

Cette commande recherche les chemins de store spécifiés dans les substituts et copie leurs signatures dans le store local.

Cela peut être utile pour garantir que les composants de build d'un système de build de confiance sont disponibles localement.

Les chemins de store sont résolus en fonction des dépendances de chaque installable donné.

Exemples

Pour copier les signatures de nixpkgs dans votre store local depuis un substitut donné :

$ nix store copy-sigs nixpkgs --substituter https://cache.nixos.org

Voir aussi

nix-store-optimise(1), nix-store-path(1), nix-substitute(1).

Options that change the interpretation of installables

•
--derivation

•

•
--file / -f file

--recursive / -r
Appliquer l'opération à la fermeture des chemins spécifiés.
