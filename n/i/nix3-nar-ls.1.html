nix3-nar-ls(1) Manuel des commandes générales nix3-nar-ls(1)

Attention
Ce programme est expérimental et son interface est sujette à modification.

Nom

nix nar ls - afficher des informations sur un chemin à l'intérieur d'un fichier NAR

Synopsis

nix nar ls [option…] nar chemin

Exemples

•
Pour lister un fichier spécifique dans une archive NAR :
# nix nar ls --long ./hello.nar /bin/hello
-r-xr-xr-x                38184 hello
•
Pour lister récursivement le contenu d'un répertoire à l'intérieur d'un NAR, en format JSON :
# nix nar ls --json --recursive ./hello.nar /bin
{"type":"directory","entries":{"hello":{"type":"regular","size":38184,"executable":true,"narOffset":400}}}

Description

Cette commande affiche des informations sur un chemin à l'intérieur du fichier Nix Archive (NAR) nar.

Options

•
--directory / -d
Afficher les répertoires plutôt que leur contenu.
•
--json
Produire la sortie au format JSON, adaptée à la consommation par un autre programme.
•
--long / -l
Afficher des informations détaillées sur les fichiers.
•
--recursive / -R
Lister les sous-répertoires récursivement.

Options liées à la journalisation

•
--debug
Définir le niveau de verbosité de la journalisation sur « debug ».
•
--log-format format
Définir le format de la sortie de journalisation ; l'un de raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Afficher les journaux de construction complets sur la sortie d'erreur standard.
•
--quiet
Diminuer le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmenter le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Afficher les informations d'utilisation.
•
--offline
Désactiver les substituts et considérer tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définir le paramètre de configuration Nix nom sur valeur (en remplaçant nix.conf).
•
--refresh
Considérer tous les fichiers précédemment téléchargés comme obsolètes.
•
--version
Afficher les informations de version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec des indicateurs de ligne de commande.
