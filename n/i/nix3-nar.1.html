nix3-nar(1) Manuel des commandes générales nix3-nar(1)

Avertissement
Ce programme est expérimental et son interface est sujette à modification.

Nom

nix nar - créer ou inspecter des fichiers NAR

Synopsis

nix nar [option…] sous-commande

où sous-commande est l'une des suivantes :

  • nix nar cat - afficher le contenu d'un fichier dans un fichier NAR sur la sortie standard
  • nix nar dump-path - sérialiser un chemin vers la sortie standard au format NAR
  • nix nar ls - afficher des informations sur un chemin dans un fichier NAR
  • nix nar pack - sérialiser un chemin vers la sortie standard au format NAR

Description

nix nar fournit plusieurs sous-commandes pour créer et inspecter des Archives Nix (NARs).

Format de fichier

Pour la définition du format de fichier d'Archive Nix, voir dans le chapitre des protocoles du manuel.

Options

Options liées à la journalisation

•
--debug
Définir le niveau de verbosité de la journalisation sur « debug ».
•
--log-format format
Définir le format de sortie des journaux ; l'un de raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Afficher les journaux de construction complets sur l'erreur standard.
•
--quiet
Diminuer le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmenter le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Afficher les informations d'utilisation.
•
--offline
Désactiver les substituts et considérer tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définir le paramètre de configuration Nix nom à valeur (remplaçant nix.conf).
•
--refresh
Considérer tous les fichiers précédemment téléchargés comme obsolètes.
•
--version
Afficher les informations sur la version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec des indicateurs de ligne de commande.
