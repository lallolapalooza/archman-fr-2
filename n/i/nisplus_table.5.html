NISPLUS_TABLE(5) Formats de fichier NISPLUS_TABLE(5)

NOM

nisplus_table - Client NIS+ de Postfix

SYNTAXE

postmap -q "chaîne" "nisplus:[nom=%s];nom.nom."
postmap -q - "nisplus:[nom=%s];nom.nom." <fichier_entrée

DESCRIPTION


Le système de messagerie Postfix utilise des tables de correspondance optionnelles. Ces tables sont généralement au format dbm ou db. Alternativement, les tables de correspondance peuvent être spécifiées comme des bases de données NIS+.

Pour savoir quels types de tables de correspondance votre système Postfix prend en charge, utilisez la commande "postconf -m".

Pour tester les tables de correspondance NIS+ de Postfix, utilisez la commande "postmap -q" comme décrit dans la SYNTAXE ci-dessus.

SYNTAXE DE LA REQUÊTE

La majeure partie de la requête NIS+ est spécifiée via le nom de la carte NIS+. Le format général d'un nom de carte NIS+ Postfix est le suivant :



nisplus:[nom=%s];nom.nom.nom.:colonne

Les noms de cartes NIS+ de Postfix diffèrent de ce que l'on utiliserait normalement avec des commandes telles que niscat :

  • Avec chaque correspondance de table NIS+, "%s" est remplacé par une version de la chaîne de correspondance. Il ne peut y avoir qu'une seule instance de "%s" dans un nom de carte NIS+ Postfix.
  • Les noms de cartes NIS+ Postfix utilisent ";" à la place de ",", car ce dernier caractère est spécial dans le fichier main.cf de Postfix. Postfix remplace les caractères ";" dans le nom de la carte par des caractères "," avant d'effectuer les requêtes NIS+.
  • La partie ":colonne" dans le nom de la carte NIS+ ne fait pas partie de la requête NIS+ réelle. Au lieu de cela, elle spécifie le numéro de la colonne de la table qui fournit le résultat de la correspondance. Si aucun ":colonne" n'est spécifié, la première colonne (1) est utilisée.

EXEMPLE

Une carte d'alias NIS+ pourrait être interrogée comme suit :

    alias_maps = dbm:/etc/mail/aliases,
        nisplus:[alias=%s];mail_aliases.org_dir.$mydomain.:1

Ceci interroge d'abord le fichier d'alias local avant le fichier NIS+.
