Nom

nix flake show - afficher les sorties fournies par une flake

Synopsis

nix flake show [option…] url-flake

Description

Cette commande affiche les attributs de sortie fournis par la flake spécifiée par la référence de flake url-flake. Ce sont les attributs de plus haut niveau dans les outputs de la flake, ainsi que des attributs de niveau inférieur pour certaines sorties standard (par exemple, packages ou checks).

Avec --json, la sortie est dans une représentation JSON appropriée pour un traitement automatique par d'autres outils.

Options

•
--all-systems
Afficher le contenu des sorties pour tous les systèmes.
•
--json
Produire une sortie au format JSON, adaptée à la consommation par un autre programme.
•
--legacy
Afficher le contenu de la sortie legacyPackages.

Options communes d'évaluation

•
--arg nom expr
Passer la valeur expr comme argument nom aux fonctions Nix.
•
--arg-from-file nom chemin
Passer le contenu du fichier chemin comme argument nom aux fonctions Nix.
•
--arg-from-stdin nom
Passer le contenu de stdin comme argument nom aux fonctions Nix.
•
--argstr nom chaîne
Passer la chaîne chaîne comme argument nom aux fonctions Nix.
•
--debugger
Démarrer un environnement interactif en cas d'échec de l'évaluation.
•
--eval-store url-magasin
L'URL du magasin Nix à utiliser pour l'évaluation, c'est-à-dire pour stocker les dérivations (.drv files) et les entrées référencées par celles-ci.
•
--impure
Autoriser l'accès aux chemins et dépôts modifiables.
•
--include / -I chemin
Ajouter chemin aux entrées du chemin de recherche utilisées pour résoudre les chemins de recherche
Cette option peut être donnée plusieurs fois.
Les chemins ajoutés via -I ont priorité sur le paramètre de configuration nix-path et la variable d'environnement NIX_PATH.
•
--override-flake ref-originale ref-résolue
Remplacer les registres de flakes, redirigeant ref-originale vers ref-résolue.

Options communes liées aux flakes

•
--commit-lock-file
Valider les changements dans le fichier de verrouillage de la flake.
•
--inputs-from url-flake
Utiliser les entrées de la flake spécifiée comme entrées de registre.
•
--no-registries
Ne pas autoriser les recherches dans les registres de flakes.
OBSOLÈTE
Utilisez plutôt --no-use-registries.
•
--no-update-lock-file
Ne pas autoriser de mises à jour du fichier de verrouillage de la flake.
•
--no-write-lock-file
Ne pas écrire le nouveau fichier de verrouillage généré de la flake.
•
--output-lock-file chemin-verrouillage-flake
Écrire le fichier de verrouillage donné au lieu de flake.lock dans la flake de plus haut niveau.
•
--override-input-attr ref-originale attribut ref-résolue
Override an input of the specified flake, redirecting original-ref to resolved-ref.
•
--rebuild-lock-file
Rebuild the lock file.
•
--flake-registry flake-registry-path
Use the specified flake registry file instead of the default one.
•
--no-use-registries
Don’t use the flake registries.
•
--update-lock-file
Update the flake’s lock file.
•
--use-dry-run
Use the dry-run store.
•
--write-lock-file
Write the flake’s newly generated lock file.

Options liées à la journalisation

•
--debug
Définit le niveau de verbosité de la journalisation sur « debug ».
•
--log-format format
Définit le format de la sortie du journal ; l'un des choix suivants : raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Affiche les journaux de construction complets sur la sortie standard d'erreur.
•
--quiet
Diminue le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmente le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Affiche les informations d'utilisation.
•
--offline
Désactive les substituts et considère tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définit le paramètre de configuration Nix nom à valeur (en remplaçant nix.conf).
•
--refresh
Considère tous les fichiers précédemment téléchargés comme obsolètes.
•
--repair
Pendant l'évaluation, réécrit les fichiers manquants ou corrompus dans le magasin Nix. Pendant la construction, reconstruit les chemins de magasin manquants ou corrompus.
•
--version
Affiche les informations de version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec des options de ligne de commande.
