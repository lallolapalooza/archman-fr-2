nix3-hash-to-base64(1) Manuel des commandes générales nix3-hash-to-base64(1)

Avertissement
Ce programme est expérimental et son interface est susceptible de changer.

Nom

nix hash to-base64 - convertir un hash en représentation base-64 (déprécié, utiliser nix hash convert à la place)

Synopsis

nix hash to-base64 [option…] chaînes…

Options

•
--type algo-hash
Algorithme de hachage (md5, sha1, sha256 ou sha512). Peut être omis pour les hashes SRI.

Options liées à la journalisation

•
--debug
Régler le niveau de verbosité de la journalisation sur « debug ».
•
--log-format format
Régler le format de la sortie des logs ; l'un des éléments suivants : raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Afficher les logs de construction complets sur la sortie d'erreur standard.
•
--quiet
Diminuer le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmenter le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Afficher les informations d'utilisation.
•
--offline
Désactiver les substituts et considérer tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définir le paramètre de configuration Nix nom sur valeur (en remplaçant nix.conf).
•
--refresh
Considérer tous les fichiers précédemment téléchargés comme obsolètes.
•
--version
Afficher les informations de version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec des indicateurs de ligne de commande.
