nix3-store-sign(1) Manuel des commandes générales nix3-store-sign(1)

Avertissement
Ce programme est expérimental et son interface est susceptible de changer.

Nom

nix store sign - signer des chemins de magasin avec une clé locale

Synopsis

nix store sign [option…] installables…

Options

•
--key-file / -k fichier
Fichier contenant la clé de signature secrète.
•
--stdin
Lire les installables depuis l'entrée standard. Aucune installable par défaut n'est appliquée.

Options communes d'évaluation

•
--arg nom expr
Passer la valeur expr comme argument nom aux fonctions Nix.
•
--arg-from-file nom chemin
Passer le contenu du fichier chemin comme argument nom aux fonctions Nix.
•
--arg-from-stdin nom
Passer le contenu de stdin comme argument nom aux fonctions Nix.
•
--argstr nom chaîne
Passer la chaîne chaîne comme argument nom aux fonctions Nix.
•
--debugger
Démarrer un environnement interactif si l'évaluation échoue.
•
--eval-store url-magasin
L'URL du magasin Nix à utiliser pour l'évaluation, c'est-à-dire pour stocker les dérivations (.drv) et les entrées référencées par celles-ci.
•
--impure
Autoriser l'accès aux chemins et dépôts modifiables.
•
--include / -I chemin
Ajouter chemin aux entrées du chemin de recherche utilisées pour résoudre les chemins de recherche.
Cette option peut être donnée plusieurs fois.
Les chemins ajoutés via -I ont priorité sur le paramètre de configuration nix-path et la variable d'environnement NIX_PATH.
•
--override-flake ref-original ref-résolu
Remplacer les registres de flakes, redirigeant ref-original vers ref-résolu.

Options communes liées aux flakes

•
--commit-lock-file
Valider les modifications dans le fichier de verrouillage du flake.
•
--inputs-from url-flake
Utiliser les entrées du flake spécifié comme entrées de registre.
•
--no-registries
Ne pas autoriser les recherches dans les registres de flakes.
OBSOLÈTE
Utiliser --no-use-registries à la place.
•
--no-update-lock-file
Ne pas autoriser de mises à jour du fichier de verrouillage du flake.
•
--no-write-lock-file
Ne pas écrire le nouveau fichier de verrouillage généré du flake.
•
--output-lock-file chemin-verrouillage-flake
Écrire le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--override-input chemin-entrée url-flake
Remplacer une entrée de flake spécifique (par ex. dwarffs/nixpkgs). Cela implique --no-write-lock-file.
•
--recreate-lock-file
Recréer le fichier de verrouillage du flake à partir de zéro.
OBSOLÈTE
Utiliser nix flake update à la place.
•
--reference-lock-file chemin-verrouillage-flake
Lire le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--update-input chemin-entrée
Mettre à jour une entrée de flake spécifique (en ignorant son entrée précédente dans le fichier de verrouillage).
OBSOLÈTE
Utiliser nix flake update à la place.

Options liées à la journalisation

•
--debug
Définir le niveau de verbosité de la journalisation sur ‘debug’.
•
--log-format format
Définir le format de la sortie du journal ; l'un de raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Imprimer les journaux de construction complets sur la sortie standard d'erreur.
•
--quiet
Diminuer la verbosité de la journalisation.

NIX3-STORE-SIGN(1)

Nix reference manual

Name

nix3-store --sign

Sign one or more paths in the Nix store.

Synopsis

nix3 store sign [options] <installables>...

Options

•
--key key-id
The secret key to use for signing. Defaults to the configured signing-key in nix.conf. For example, `~/.ssh/id_ed25519`.
•
--output-file / -o file
Write the signature to file instead of the default (i.e. `.sig`).
•
--substitute
Also substitute the specified paths after signing.
•
--verbose / -v
Increase the logging verbosity level.

Miscellaneous global options

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

Options that change the interpretation of installables

•
--all
Apply the operation to every store path.
•
--derivation
Operate on the store derivation rather than its outputs.
•
--expr expr
Interpret installables as attribute paths relative to the Nix expression expr.
•
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.
•
--recursive / -r
Apply operation to closure of the specified paths.

Note

See man nix.conf for overriding configuration settings with command line flags.
