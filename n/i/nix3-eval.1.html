nix eval(1) Manuel des commandes générales nix eval(1)

Avertissement
Ce programme est expérimental et son interface est sujette à modification.

Nom

nix eval - évaluer une expression Nix

Synopsis

nix eval [option…] installable

Exemples

•
Évaluer une expression Nix donnée sur la ligne de commande :
# nix eval --expr '1 + 2'
•
Évaluer une expression Nix en JSON :
# nix eval --json --expr '{ x = 1; }'
{"x":1}
•
Évaluer une expression Nix à partir d'un fichier :
# nix eval --file ./mon-nixpkgs hello.name
•
Obtenir la version actuelle du flake nixpkgs :
# nix eval --raw nixpkgs#lib.version
•
Imprimer le chemin du magasin du paquet Hello :
# nix eval --raw nixpkgs#hello
•
Obtenir une liste des vérifications dans le flake nix :
# nix eval nix#checks.x86_64-linux --apply builtins.attrNames
•
Générer un répertoire avec le contenu spécifié :
# nix eval --write-to ./out --expr '{ foo = "bar"; subdir.bla = "123"; }'
# cat ./out/foo
bar
# cat ./out/subdir/bla
123

Description

Cette commande évalue l'expression Nix donnée et imprime le résultat sur la sortie standard.

Format de sortie

nix eval peut produire des sorties dans plusieurs formats :

  • Par défaut, le résultat de l'évaluation est imprimé comme une expression Nix.
  • Avec --json, le résultat de l'évaluation est imprimé au format JSON. Notez que cela échoue si le résultat contient des valeurs qui ne peuvent pas être représentées en JSON, comme des fonctions.
  • Avec --raw, le résultat de l'évaluation doit être une chaîne de caractères, qui est imprimée telle quelle, sans guillemets ni échappement.
  • Avec --write-to chemin, le résultat de l'évaluation doit être une chaîne de caractères ou un ensemble d'attributs imbriqués dont les valeurs feuilles sont des chaînes de caractères. Ces chaînes sont écrites dans des fichiers nommés chemin/chemin-attribut. chemin ne doit pas exister.

Options

•
--apply expr
Applique la fonction expr à chaque argument.
•
--json
Produit une sortie au format JSON, adaptée à la consommation par un autre programme.
•
--raw
Imprime les chaînes sans guillemets ni échappement.
•
--read-only
N'instancie pas chaque dérivation évaluée. Cela améliore les performances, mais peut causer des erreurs lors de l'accès aux chemins du magasin des dérivations pendant l'évaluation.
•
--write-to chemin
Écrit une chaîne ou un ensemble d'attributs de chaînes vers chemin.

Options communes d'évaluation

•
--arg nom expr
Passe la valeur expr comme argument nom aux fonctions Nix.
•
--arg-from-file nom chemin
Passe le contenu du fichier chemin comme argument nom aux fonctions Nix.
•
--arg-from-stdin nom
Passe le contenu de stdin comme argument nom aux fonctions Nix.
•
--argstr nom chaîne
Passe la chaîne chaîne comme argument nom aux fonctions Nix.
•
--debugger
Démarre un environnement interactif si l'évaluation échoue.
•
--eval-store url-magasin
L'URL du magasin Nix à utiliser pour l'évaluation, c'est-à-dire pour stocker les dérivations (.drv) et les entrées référencées par celles-ci.
•
--impure
Autorise l'accès aux chemins et dépôts modifiables.
•
--include / -I chemin
Ajoute chemin aux entrées du chemin de recherche utilisées pour résoudre les chemins de recherche
Cette option peut être donnée plusieurs fois.
Les chemins ajoutés via -I ont la priorité sur le paramètre de configuration nix-path et la variable d'environnement NIX_PATH.
•
--override-flake ref-original ref-résolu
Remplace les registres de flakes, redirigeant ref-original vers ref-résolu.

Options communes liées aux flakes

•
--commit-lock-file
Valide les modifications apportées au fichier de verrouillage du flake.
•
--inputs-from url-flake
Utilise les entrées du flake spécifié comme entrées de registre.
•
--no-registries
Ne permet pas les recherches dans les registres de flakes.
OBSOLÈTE
Utilisez --no-use-registries à la place.
•
--no-update-lock-file
N'autorise aucune mise à jour du fichier de verrouillage du flake.
•
--no-write-lock-file
N'écrit pas le fichier de verrouillage nouvellement généré du flake.
•
--output-lock-file
Imprime le contenu du fichier de verrouillage du flake mis à jour sur la sortie standard.
•
--rebuild-lock-file
Reconstruit le fichier de verrouillage du flake.
•
--use-lock-file / -L
Utilise le fichier de verrouillage du flake pour résoudre les entrées.
•
--use-registries
Permet les recherches dans les registres de flakes.
Ceci est le comportement par défaut.
•
--work-dir chemin
Répertoire de travail pour évaluer le flake.

Options related to flake locking

•
--commit-lock-file
Commit the lock file to the flake repository.
•
--lock-file flake-lock-path
Write the given lock file instead of flake.lock within the top-level flake.
•
--override-input input-path flake-url
Override a specific flake input (e.g. dwarffs/nixpkgs). This implies --no-write-lock-file.
•
--recreate-lock-file
Recreate the flake’s lock file from scratch.
DEPRECATED
Use nix flake update instead.
•
--reference-lock-file flake-lock-path
Read the given lock file instead of flake.lock within the top-level flake.
•
--update-input input-path
Update a specific flake input (ignoring its previous entry in the lock file).
DEPRECATED
Use nix flake update instead.

Options related to logging

•
--debug
Set the logging verbosity level to ‘debug’.
•
--log-format format
Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
•
--print-build-logs / -L
Print full build logs on standard error.
•
--quiet
Decrease the logging verbosity level.
•
--verbose / -v
Increase the logging verbosity level.

Options globales diverses

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

Options qui modifient l'interprétation des installables

•
--expr expr
Interprète les installables comme des chemins d'attributs relatifs à l'expression Nix expr.
•
--file / -f file
Interprète les installables comme des chemins d'attributs relatifs à l'expression Nix stockée dans file. Si file est le caractère -, alors une expression Nix sera lue depuis l'entrée standard. Implique --impure.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec les options de ligne de commande.
