nix3-flake-clone(1) Manuel des commandes générales nix3-flake-clone(1)

Avertissement
Ce programme est expérimental et son interface est susceptible de changer.

Nom

nix flake clone - cloner un dépôt de flake

Synopsis

nix flake clone [option…] url-du-flake

Exemples

•
Récupérer le code source du flake dwarffs et le compiler :
# nix flake clone dwarffs --dest dwarffs
# cd dwarffs
# nix build

Description

Cette commande effectue un clone Git ou Mercurial du dépôt contenant le code source du flake url-du-flake.

Options

•
--dest / -f chemin
Cloner le flake vers le chemin dest.

Options communes d'évaluation

•
--arg nom expr
Passer la valeur expr comme argument nom aux fonctions Nix.
•
--arg-from-file nom chemin
Passer le contenu du fichier chemin comme argument nom aux fonctions Nix.
•
--arg-from-stdin nom
Passer le contenu de l'entrée standard comme argument nom aux fonctions Nix.
•
--argstr nom chaîne
Passer la chaîne chaîne comme argument nom aux fonctions Nix.
•
--debugger
Démarrer un environnement interactif si l'évaluation échoue.
•
--eval-store url-du-store
L' URL du magasin Nix à utiliser pour l'évaluation, c'est-à-dire pour stocker les dérivations (.drv) et les entrées référencées par celles-ci.
•
--impure
Autoriser l'accès aux chemins et dépôts modifiables.
•
--include / -I chemin
Ajouter chemin aux entrées du chemin de recherche utilisées pour résoudre les chemins de recherche
Cette option peut être donnée plusieurs fois.
Les chemins ajoutés via -I ont la priorité sur le paramètre de configuration nix-path et la variable d'environnement NIX_PATH.
•
--override-flake ref-originale ref-résolue
Remplacer les registres de flakes, redirigeant ref-originale vers ref-résolue.

Options communes liées aux flakes

•
--commit-lock-file
Valider les changements dans le fichier de verrouillage du flake.
•
--inputs-from url-du-flake
Utiliser les entrées du flake spécifié comme entrées de registre.
•
--no-registries
Ne pas autoriser les recherches dans les registres de flakes.
OBSOLÈTE
Utiliser --no-use-registries à la place.
•
--no-update-lock-file
Ne pas autoriser les mises à jour du fichier de verrouillage du flake.
•
--no-write-lock-file
Ne pas écrire le fichier de verrouillage nouvellement généré du flake.
•
--output-lock-file chemin-du-verrou-flake
Écrire le fichier de verrouillage spécifié au lieu de flake.lock dans le flake de niveau supérieur.
•
--override-input chemin-entrée url-du-flake
Remplacer une entrée de flake spécifique (par exemple dwarffs/nixpkgs). Cela implique --no-write-lock-file.
•
--recreate-lock-file
Recréer le fichier de verrouillage du flake à partir de zéro.
OBSOLÈTE
Utiliser nix flake update à la place.
•
--reference-lock-file chemin-du-verrou-flake
Lire le fichier de verrouillage spécifié au lieu de flake.lock dans le flake de niveau supérieur.
•
--update-input chemin-entrée
Mettre à jour une entrée de flake spécifique (en ignorant son entrée précédente dans le fichier de verrouillage).
OBSOLÈTE
Utiliser nix flake update à la place.

Options liées à la journalisation

•
--debug
Définir le niveau de verbosité de la journalisation à « debug ».
•
--log-format format
Définir le format de la sortie de journalisation ; l'un des choix : raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

/ -L
Imprime les journaux de compilation complets sur l'erreur standard.
•
--quiet
Diminue le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmente le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Affiche les informations d'utilisation.
•
--offline
Désactive les substituts et considère tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définit le paramètre de configuration Nix nom à valeur (en remplaçant nix.conf).
•
--refresh
Considère tous les fichiers précédemment téléchargés comme obsolètes.
•
--repair
Lors de l'évaluation, réécrit les fichiers manquants ou corrompus dans le magasin Nix. Lors de la construction, reconstruit les chemins de magasin manquants ou corrompus.
•
--version
Affiche les informations de version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec les options de ligne de commande.
