nix3-profile-remove(1) Manuel des commandes générales nix3-profile-remove(1)

Attention
Ce programme est expérimental et son interface est sujette à modification.

Nom

nix profile remove - supprimer des paquets d'un profil

Synopsis

nix profile remove [option…] éléments…

Exemples

•
Supprimer un paquet par son nom :
# nix profile remove hello
•
Supprimer tous les paquets :
# nix profile remove --all
•
Supprimer des paquets par expression régulière :
# nix profile remove --regex '.*vim.*'
•
Supprimer un paquet par son chemin de stockage :
# nix profile remove /nix/store/rr3y0c6zyk7kjjl8y19s4lsrhn4aiq1z-hello-2.10

Description

Cette commande supprime un paquet d'un profil.

Options

•
--all
Correspondre à tous les paquets du profil.
•
--profile chemin
Le profil sur lequel opérer.
•
--regex modèle
Une expression régulière pour correspondre à un ou plusieurs paquets du profil.

Options communes d'évaluation

•
--arg nom expr
Passe la valeur expr comme argument nom aux fonctions Nix.
•
--arg-from-file nom chemin
Passe le contenu du fichier chemin comme argument nom aux fonctions Nix.
•
--arg-from-stdin nom
Passe le contenu de l'entrée standard comme argument nom aux fonctions Nix.
•
--argstr nom chaîne
Passe la chaîne chaîne comme argument nom aux fonctions Nix.
•
--debugger
Démarre un environnement interactif si l'évaluation échoue.
•
--eval-store url-magasin
L'URL du magasin Nix à utiliser pour l'évaluation, c'est-à-dire pour stocker les dérivations (.drv) et les entrées auxquelles elles font référence.
•
--impure
Autorise l'accès aux chemins et dépôts modifiables.
•
--include / -I chemin
Ajoute chemin aux entrées du chemin de recherche utilisées pour résoudre les chemins de recherche
Cette option peut être donnée plusieurs fois.
Les chemins ajoutés via -I ont la priorité sur le paramètre de configuration nix-path et la variable d'environnement NIX_PATH .
•
--override-flake ref-original ref-résolue
Remplace les registres de flocons, redirigeant ref-original vers ref-résolue.

Options liées à la journalisation

•
--debug
Définit le niveau de verbosité de la journalisation sur « debug ».
•
--log-format format
Définit le format de la sortie du journal ; l'un des choix est raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Affiche les journaux de construction complets sur la sortie d'erreur standard.
•
--quiet
Diminue le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmente le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Affiche les informations d'utilisation.
•
--offline
Désactive les substituts et considère tous les fichiers téléchargés précédemment comme à jour.
•
--option nom valeur
Définit le paramètre de configuration Nix nom à valeur (en remplacement de nix.conf).
•
--refresh
Considère tous les fichiers téléchargés précédemment comme obsolètes.
•
--repair
Pendant l'évaluation, réécrit les fichiers manquants ou corrompus dans le magasin Nix. Pendant la construction, reconstruit les chemins de magasin manquants ou corrompus.
•
--version
Affiche les informations sur la version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec des indicateurs de ligne de commande.
