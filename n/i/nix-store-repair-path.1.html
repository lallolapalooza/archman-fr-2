Nom

nix --repair-path - redownload chemin depuis le substituteur

Synopsis

nix-store --repair-path chemins…

Description

L'opération --repair-path tente de « réparer » les chemins spécifiés en les redownloadant en utilisant les substituteurs disponibles. Si aucun substitut n'est disponible, la réparation n'est pas possible.

Attention

Pendant la réparation, il existe une très courte fenêtre temporelle pendant laquelle l'ancien chemin (s'il existe) est déplacé pour être remplacé par le nouveau chemin. Si la réparation est interrompue entre-temps, le système peut se retrouver dans un état cassé (par exemple, si le chemin contient un composant critique du système tel que la bibliothèque C GNU).

Exemple

$ nix-store --verify-path /nix/store/dj7a81wsm1ijwwpkks3725661h3263p5-glibc-2.13
chemin `/nix/store/dj7a81wsm1ijwwpkks3725661h3263p5-glibc-2.13' a été modifié !
  hash attendu `2db57715ae90b7e31ff1f2ecb8c12ec1cc43da920efcbe3b22763f36a1861588',
  obtenu `481c5aa5483ebc97c20457bb8bca24deea56550d3985cda0027f67fe54b808e4'
$ nix-store --repair-path /nix/store/dj7a81wsm1ijwwpkks3725661h3263p5-glibc-2.13
téléchargement du chemin `/nix/store/d7a81wsm1ijwwpkks3725661h3263p5-glibc-2.13'...
…
