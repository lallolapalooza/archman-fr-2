Avertissement
Ce programme est expérimental et son interface est sujette à changement.

Nom

nix profile list - lister les paquets installés

Synopsis

nix profile list [option…]

Exemples

•
Afficher les paquets installés dans le profil par défaut :
# nix profile list
Nom :               gdb
Attribut de flake : legacyPackages.x86_64-linux.gdb
URL de flake d'origine : flake:nixpkgs
URL de flake verrouillé : github:NixOS/nixpkgs/7b38b03d76ab71bdc8dc325e3f6338d984cc35ca
Chemins de magasin :        /nix/store/indzcw5wvlhx6vwk7k4iq29q15chvr3d-gdb-11.1
Nom :               blender-bin
Attribut de flake : packages.x86_64-linux.default
URL de flake d'origine : flake:blender-bin
URL de flake verrouillé : github:edolstra/nix-warez/91f2ffee657bf834e4475865ae336e2379282d34?dir=blender
Chemins de magasin :        /nix/store/i798sxl3j40wpdi1rgf391id1b5klw7g-blender-bin-3.1.2
Notez que vous pouvez reconstruire sans ambiguïté un paquet à partir d'un profil via son URL de flake verrouillée et son attribut de flake, par exemple :
# nix build github:edolstra/nix-warez/91f2ffee657bf834e4475865ae336e2379282d34?dir=blender#packages.x86_64-linux.default
reconstruira le paquet blender-bin affiché ci-dessus.

Description

Cette commande affiche les paquets actuellement installés dans un profil. Pour chaque paquet installé, elle affiche les informations suivantes :

  • Nom : Un nom unique utilisé pour identifier sans ambiguïté le paquet dans les invocations de nix profile remove et nix profile upgrade.
  • Index : Un entier qui peut être utilisé pour identifier sans ambiguïté le paquet dans les invocations de nix profile remove et nix profile upgrade. (Obsolète, sera supprimé dans une future version au profit de Nom.)
  • Attribut de flake : Le chemin d'attribut de sortie de flake qui fournit le paquet (par exemple packages.x86_64-linux.hello).
  • URL de flake d'origine : La référence de flake d'origine (“non verrouillée”) spécifiée par l'utilisateur lorsque le paquet a été installé pour la première fois via nix profile install.
  • URL de flake verrouillée : La référence de flake verrouillée vers laquelle la référence de flake d'origine a été résolue.
  • Chemins de magasin : Le(s) chemin(s) de magasin du paquet.

Options

•
--json
Produire une sortie au format JSON, adaptée à la consommation par un autre programme.
•
--profile chemin
Le profil sur lequel opérer.

Options communes d'évaluation

•
--arg nom expr
Passer la valeur expr comme argument nom aux fonctions Nix.
•
--arg-from-file nom chemin
Passer le contenu du fichier chemin comme argument nom aux fonctions Nix.
•
--arg-from-stdin nom
Passer le contenu de l'entrée standard comme argument nom aux fonctions Nix.
•
--argstr nom chaîne
Passer la chaîne chaîne comme argument nom aux fonctions Nix.
•
--debugger
Démarrer un environnement interactif si l'évaluation échoue.
•
--eval-store url-magasin
L'URL du magasin Nix à utiliser pour l'évaluation, c'est-à-dire pour stocker les dérivations (.drv) et les entrées auxquelles elles font référence.
•
--impure
Autoriser l'accès aux chemins et dépôts mutables.
•
--include / -I chemin
Ajouter chemin aux entrées du chemin de recherche utilisées pour résoudre les chemins de recherche
Cette option peut être donnée plusieurs fois.
Les chemins ajoutés via -I ont la priorité sur le paramètre de configuration nix-path et la variable d'environnement NIX_PATH .
•
--override-flake ref-origine ref-résolue
Remplace les registres de flakes, redirigeant ref-origine vers ref-résolue.

Options liées à la journalisation

•
--debug
Règle le niveau de verbosité de la journalisation sur « debug ».
•
--log-format format
Règle le format de la sortie du journal ; l'un parmi raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Affiche les journaux de construction complets sur l'erreur standard.
•
--quiet
Diminue le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmente le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Affiche les informations d'utilisation.
•
--offline
Désactive les substituts et considère tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définit la valeur d'une option Nix.
Cette option peut être donnée plusieurs fois.
La valeur sera interprétée comme une chaîne (et échappée en tant que telle).
•
--version
Affiche la version de Nix.
Et sort.
