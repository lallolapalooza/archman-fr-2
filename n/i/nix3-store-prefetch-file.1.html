nix3-store-prefetch-file(1) Manuel des commandes générales nix3-store-prefetch-file(1)

Attention
Ce programme est expérimental et son interface est sujette à modification.

Nom

nix store prefetch-file - télécharger un fichier dans le store Nix

Synopsis

nix store prefetch-file [option…] url

Exemples

•
Télécharger un fichier dans le store Nix :
# nix store prefetch-file https://releases.nixos.org/nix/nix-2.3.10/nix-2.3.10.tar.xz
Téléchargé 'https://releases.nixos.org/nix/nix-2.3.10/nix-2.3.10.tar.xz' vers
'/nix/store/vbdbi42hgnc4h7pyqzp6h2yf77kw93aw-source' (hash
'sha256-qKheVd5D0BervxMDbt+1hnTKE2aRWC8XCAwc0SeHt6s=').
•
Télécharger un fichier et obtenir son hash SHA-512 :
# nix store prefetch-file --json --hash-type sha512 \
  https://releases.nixos.org/nix/nix-2.3.10/nix-2.3.10.tar.xz \
| jq -r .hash
sha512-6XJxfym0TNH9knxeH4ZOvns6wElFy3uahunl2hJgovACCMEMXSy42s69zWVyGJALXTI+86tpDJGlIcAySEKBbA==

Description

Cette commande télécharge le fichier url dans le store Nix. Elle affiche le chemin de store résultant et le hash cryptographique du contenu du fichier.

Le composant nom du chemin de store est par défaut le dernier composant de url, mais cela peut être remplacé en utilisant --name.

Options

•
--executable
Rendre le fichier résultant exécutable. Notez que cela provoque un hash NAR plutôt qu'un hash de fichier plat.
•
--expected-hash hash
Le hash attendu du fichier.
•
--hash-type hash-algo
Algorithme de hash (md5, sha1, sha256, ou sha512).
•
--json
Produire la sortie au format JSON, adaptée à la consommation par un autre programme.
•
--name nom
Remplacer le composant nom du chemin de store résultant. Il s'agit par défaut du nom de base de url.
•
--unpack
Décompresser l'archive (qui doit être une archive tar ou zip) et ajouter le résultat au store Nix.

Options liées à la journalisation

•
--debug
Définir le niveau de verbosité de la journalisation à « debug ».
•
--log-format format
Définir le format de la sortie de journalisation ; l'un des raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Imprimer les journaux de construction complets sur la sortie d'erreur standard.
•
--quiet
Diminuer le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmenter le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Afficher les informations d'utilisation.
•
--offline
Désactiver les substituts et considérer tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définir le paramètre de configuration Nix nom à valeur (en remplaçant nix.conf).
•
--refresh
Considérer tous les fichiers précédemment téléchargés comme obsolètes.
•
--version
Afficher les informations de version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec des indicateurs de ligne de commande.
