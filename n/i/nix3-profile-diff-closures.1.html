nix3-profile-diff-closures(1) Manuel des commandes générales nix3-profile-diff-closures(1)

Avertissement
Ce programme est expérimental et son interface est susceptible de changer.

Nom

nix profile diff-closures - afficher la différence de fermeture entre chaque version d'un profil

Synopsis

nix profile diff-closures [option…]

Exemples

•
Afficher ce qui a changé entre chaque version du profil système NixOS :
# nix profile diff-closures --profile /nix/var/nix/profiles/system
Version 13 -> 14:
acpi-call: 2020-04-07-5.8.13 → 2020-04-07-5.8.14
aws-sdk-cpp: -6723.1 KiB
…
Version 14 -> 15:
acpi-call: 2020-04-07-5.8.14 → 2020-04-07-5.8.16
attica: -996.2 KiB
breeze-icons: -78713.5 KiB
brotli: 1.0.7 → 1.0.9, +44.2 KiB

Description

Cette commande affiche la différence entre les fermetures des versions successives d'un profil. Voir nix store diff-closures pour plus de détails.

Options

•
--profile chemin
Le profil sur lequel opérer.

Options liées à la journalisation

•
--debug
Définit le niveau de verbosité de la journalisation à « debug ».
•
--log-format format
Définit le format de la sortie de journalisation ; l'un parmi raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Affiche les journaux de construction complets sur la sortie standard d'erreur.
•
--quiet
Diminue le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmente le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Affiche les informations d'utilisation.
•
--offline
Désactive les substituts et considère tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définit le paramètre de configuration Nix nom à valeur (remplaçant nix.conf).
•
--refresh
Considère tous les fichiers précédemment téléchargés comme obsolètes.
•
--version
Affiche les informations de version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec des indicateurs de ligne de commande.
