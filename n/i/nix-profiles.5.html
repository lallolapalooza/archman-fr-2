Profils

Un répertoire qui contient des liens symboliques vers les profils gérés par nix-env et nix profile:

  • $XDG_STATE_HOME/nix/profiles pour les utilisateurs réguliers
  • $NIX_STATE_DIR/profiles/per-user/root si l'utilisateur est root

Un profil est un répertoire de liens symboliques vers des fichiers dans le store Nix.

Disposition du système de fichiers

Les profils sont versionnés comme suit. Lors de l'utilisation d'un profil nommé chemin, chemin est un lien symbolique vers chemin-N-link, où N est la version du profil. À son tour, chemin-N-link est un lien symbolique vers un chemin dans le store Nix. Par exemple :

$ ls -l ~alice/.local/state/nix/profiles/profile*
lrwxrwxrwx 1 alice users 14 Nov 25 14:35 /home/alice/.local/state/nix/profiles/profile -> profile-7-link
lrwxrwxrwx 1 alice users 51 Oct 28 16:18 /home/alice/.local/state/nix/profiles/profile-5-link -> /nix/store/q69xad13ghpf7ir87h0b2gd28lafjj1j-profile
lrwxrwxrwx 1 alice users 51 Oct 29 13:20 /home/alice/.local/state/nix/profiles/profile-6-link -> /nix/store/6bvhpysd7vwz7k3b0pndn7ifi5xr32dg-profile
lrwxrwxrwx 1 alice users 51 Nov 25 14:35 /home/alice/.local/state/nix/profiles/profile-7-link -> /nix/store/mp0x6xnsg0b8qhswy6riqvimai4gm677-profile

Chacun de ces liens symboliques est une racine pour le collecteur de miettes Nix.

Chaque version de profil contient un fichier manifeste : - manifest.nix utilisé par nix-env. - manifest.json utilisé par nix profile (expérimental).

Lien du profil utilisateur

Un lien symbolique vers le profil actuel de l'utilisateur :

  • ~/.nix-profile
  • $XDG_STATE_HOME/nix/profile si use-xdg-base-directories est défini sur true.

Par défaut, ce lien symbolique pointe vers :

  • $XDG_STATE_HOME/nix/profiles/profile pour les utilisateurs réguliers
  • $NIX_STATE_DIR/profiles/per-user/root/profile pour root

La variable d'environnement PATH doit inclure le sous-répertoire /bin du lien du profil (par exemple, ~/.nix-profile/bin) pour que l'environnement de l'utilisateur soit visible par l'utilisateur. Le programme d'installation configure cela par défaut, sauf si vous activez use-xdg-base-directories.
