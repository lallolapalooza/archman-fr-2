nix3-key-generate-secret(1) Manuel des commandes générales nix3-key-generate-secret(1)

Attention
Ce programme est expérimental et son interface est susceptible de changer.

Nom

nix key generate-secret - générer une clé secrète pour signer les chemins du store

Synopsis

nix key generate-secret [option…]

Exemples

•
Générer une nouvelle clé secrète :
# nix key generate-secret --key-name cache.example.org-1 > ./secret-key
Nous pouvons ensuite utiliser cette clé pour signer la fermeture du paquet Hello :
# nix build nixpkgs#hello
# nix store sign --key-file ./secret-key --recursive ./result
Enfin, nous pouvons vérifier les chemins du store avec la clé publique correspondante :
# nix store verify --trusted-public-keys $(nix key convert-secret-to-public < ./secret-key) ./result

Description

Cette commande génère une nouvelle clé secrète Ed25519 pour signer les chemins du store et l'affiche sur la sortie standard. Utilisez nix key convert-secret-to-public pour obtenir la clé publique correspondante pour vérifier les chemins du store signés.

L'argument obligatoire --key-name spécifie un nom de clé (tel que cache.example.org-1). Il est utilisé pour rechercher les clés côté client lors de la vérification des signatures. Il peut s'agir de n'importe quoi, mais il est suggéré d'utiliser le nom d'hôte de votre cache (par exemple cache.example.org) avec un suffixe indiquant le numéro de la clé (à incrémenter chaque fois que vous devez révoquer une clé).

Format

Les clés secrètes et publiques sont représentées par le nom de la clé suivi d'un encodage base-64 des données de la clé Ed25519, par exemple :

cache.example.org-0:E7lAO+MsPwTFfPXsdPtW8GKui/5ho4KQHVcAGnX+Tti1V4dUxoVoqLyWJ4YESuZJwQ67GVIksDt47og+tPVUZw==
