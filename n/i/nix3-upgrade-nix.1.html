nix3-upgrade-nix(1) Manuel des commandes générales nix3-upgrade-nix(1)

Avertissement
Ce programme est expérimental et son interface est sujette à modification.

Nom

nix upgrade-nix - mettre à niveau Nix vers la dernière version stable

Synopsis

nix upgrade-nix [option…]

Exemples

•
Mettre à niveau Nix vers la version stable déclarée dans Nixpkgs :
# nix upgrade-nix
•
Mettre à niveau Nix dans un profil spécifique :
# nix upgrade-nix --profile ~alice/.local/state/nix/profiles/profile

Description

Cette commande met à niveau Nix vers la version stable.

Par défaut, la dernière version stable est définie par Nixpkgs, dans nix-fallback-paths.nix et mise à jour manuellement. Elle ne correspond pas toujours à la dernière version étiquetée.

Par défaut, elle recherche le répertoire contenant le binaire nix dans la variable d'environnement $PATH. Si ce répertoire est un profil Nix, elle mettra à niveau le paquet nix dans ce profil vers la dernière version binaire stable.

Vous ne pouvez pas utiliser cette commande pour mettre à niveau Nix dans le profil système d'un système NixOS (c'est-à-dire si nix se trouve dans /run/current-system).

Options

•
--dry-run
Affiche ce que cette commande ferait sans le faire.
•
--nix-store-paths-url url
L'URL du fichier contenant les chemins du magasin de la dernière version de Nix.
•
--profile / -p profile-dir
Le chemin du profil Nix à mettre à niveau.

Options liées à la journalisation

•
--debug
Définit le niveau de verbosité de la journalisation sur ‘debug’.
•
--log-format format
Définit le format de la sortie du journal ; l'un des choix possibles est raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Affiche les journaux de construction complets sur la sortie d'erreur standard.
•
--quiet
Diminue le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmente le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Affiche les informations d'utilisation.
•
--offline
Désactive les substituts et considère tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définit le paramètre de configuration Nix nom sur valeur (remplaçant nix.conf).
•
--refresh
Considère tous les fichiers précédemment téléchargés comme obsolètes.
•
--version
Affiche les informations de version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec des options en ligne de commande.
