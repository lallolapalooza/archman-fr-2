nix3-derivation(1) Manuel des commandes générales nix3-derivation(1)

Attention
Ce programme est expérimental et son interface est sujette à modification.

Nom

nix derivation - Gérer les dérivations, la notion de plan de construction de Nix.

Synopsis

nix derivation [option…] sous-commande

où sous-commande est l'une des suivantes :

  • nix derivation add - Ajouter une dérivation de magasin
  • nix derivation show - afficher le contenu d'une dérivation de magasin

Options

Options liées à la journalisation

•
--debug
Définit le niveau de verbosité de la journalisation sur « debug ».
•
--log-format format
Définit le format de la sortie des journaux ; l'un des choix : raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Imprime les journaux de construction complets sur la sortie d'erreur standard.
•
--quiet
Diminue le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmente le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Affiche les informations d'utilisation.
•
--offline
Désactive les substituts et considère tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définit le paramètre de configuration Nix nom à valeur (en remplaçant nix.conf).
•
--refresh
Considère tous les fichiers précédemment téléchargés comme obsolètes.
•
--version
Affiche les informations de version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec des options de ligne de commande.
