NICE(3P) Manuel du programmeur POSIX NICE(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

nice — modifier la valeur de nice d'un processus

SYNTAXE

#include <unistd.h>
int nice(int incr);

DESCRIPTION

La fonction nice() ajoute la valeur de incr à la valeur de nice du processus appelant. Une valeur de nice d'un processus est un nombre non négatif pour lequel une valeur plus positive entraîne une planification moins favorable.

Une valeur de nice maximale de 2*{NZERO}-1 et une valeur de nice minimale de 0 sont imposées par le système. Les requêtes de valeurs supérieures ou inférieures à ces limites entraînent la définition de la valeur de nice à la limite correspondante. Seul un processus disposant des privilèges appropriés peut abaisser la valeur de nice.

L'appel à la fonction nice() n'a aucun effet sur la priorité des processus ou threads avec la politique SCHED_FIFO ou SCHED_RR. L'effet sur les processus ou threads avec d'autres politiques de planification est défini par l'implémentation.

La valeur de nice définie avec nice() est appliquée au processus. Si le processus est multi-threadé, la valeur de nice affectera tous les threads de portée système du processus.

Comme -1 est une valeur de retour permissible dans une situation réussie, une application souhaitant vérifier les situations d'erreur doit définir errno à 0, puis appeler nice(), et si elle renvoie -1, vérifier si errno est non nul.

VALEUR RENVOYÉE

En cas de succès, nice() renvoie la nouvelle valeur de nice -{NZERO}. Sinon, -1 est renvoyé, la valeur de nice du processus n'est pas modifiée, et errno est défini pour indiquer l'erreur.

ERREURS

La fonction nice() échoue si :

EPERM
L'argument incr est négatif et le processus appelant ne possède pas les privilèges appropriés.

EXEMPLES

Modification de la valeur de nice

L'exemple suivant ajoute la valeur de l'argument incr, -20, à la valeur de nice du processus appelant.

#include <unistd.h>
...
int incr = -20;
int ret;
ret = nice(incr);
