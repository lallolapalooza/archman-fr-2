nix3-daemon(1) Manuel des commandes générales nix3-daemon(1)

Attention
Ce programme est expérimental et son interface est susceptible d'être modifiée.

Nom

nix daemon - démon pour effectuer des opérations sur le magasin au nom de clients non-root

Synopsis

nix daemon [option…]

Exemples

•
Exécuter le démon :
# nix daemon
•
Exécuter le démon et écouter sur l'entrée/sortie standard au lieu de se connecter à un socket UNIX :
# nix daemon --stdio
•
Exécuter le démon et forcer toutes les connexions à être considérées comme fiables :
# nix daemon --force-trusted
•
Exécuter le démon et forcer toutes les connexions à être considérées comme non fiables :
# nix daemon --force-untrusted
•
Exécuter le démon, écouter sur l'entrée/sortie standard et forcer toutes les connexions à utiliser la confiance par défaut de Nix :
# nix daemon --stdio --default-trust

Description

Cette commande exécute le démon Nix, qui est un composant requis dans les installations Nix multi-utilisateurs. Il exécute les tâches de construction et d'autres opérations sur le magasin Nix au nom des utilisateurs non-root. Habituellement, vous n'exécutez pas le démon directement ; il est plutôt géré par un cadre de gestion de service tel que systemd sous Linux, ou launchctl sous Darwin.

Notez que ce démon ne se détache pas en arrière-plan.

Options

•
--default-trust
Utiliser la confiance par défaut de Nix.
•
--force-trusted
Forcer le démon à faire confiance aux clients connectés.
•
--force-untrusted
Forcer le démon à ne pas faire confiance aux clients connectés. La connexion sera traitée par le démon récepteur avant de transmettre les commandes.
•
--process-ops
Force le démon à traiter lui-même les commandes reçues plutôt que de transmettre les commandes directement au magasin distant.
      Ceci est utile pour le magasin `mounted-ssh://` où certaines actions doivent être effectuées côté distant mais en tant qu'utilisateur connecté, et non en tant qu'utilisateur du démon sous-jacent côté distant.
•
--stdio
Se connecter à l'entrée/sortie standard, au lieu d'essayer de se connecter à un socket UNIX.

Options liées à la journalisation

•
--debug
Définir le niveau de verbosité de la journalisation sur 'debug'.
•
--log-format format
Définir le format de la sortie du journal ; l'un des éléments suivants : raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Afficher les journaux de construction complets sur la sortie d'erreur standard.
•
--quiet
Diminuer le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmenter le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Afficher les informations d'utilisation.
•
--offline
Désactiver les substituts et considérer tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définir le paramètre de configuration Nix nom sur valeur (en remplaçant nix.conf).
•
--refresh
Considérer tous les fichiers précédemment téléchargés comme obsolètes.
•
--version
Afficher les informations sur la version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec des indicateurs de ligne de commande.
