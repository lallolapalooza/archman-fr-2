nix3-flake-lock(1) Manuel des commandes générales nix3-flake-lock(1)

Avertissement
Ce programme est expérimental et son interface est susceptible d'être modifiée.

Nom

nix flake lock - créer les entrées manquantes du fichier de verrouillage

Synopsis

nix flake lock [option…] url-flake

Exemples

•
Créer le fichier de verrouillage pour le flake dans le répertoire courant :
# nix flake lock
warning: creating lock file '/home/myself/repos/testflake/flake.lock':
• Added input 'nix':
  'github:NixOS/nix/9fab14adbc3810d5cc1f88672fde1eee4358405c' (2023-06-28)
• Added input 'nixpkgs':
  'github:NixOS/nixpkgs/3d2d8f281a27d466fa54b469b5993f7dde198375' (2023-06-30)
•
Ajouter les entrées manquantes au fichier de verrouillage pour un flake dans un autre répertoire :
# nix flake lock ~/repos/another
warning: updating lock file '/home/myself/repos/another/flake.lock':
• Added input 'nixpkgs':
  'github:NixOS/nixpkgs/3d2d8f281a27d466fa54b469b5993f7dde198375' (2023-06-30)
Note
Lorsque vous essayez de référencer un flake dans un sous-répertoire, écrivez ./another au lieu de another. Sinon, Nix essaiera de rechercher le flake dans le registre.

Description

Cette commande ajoute des entrées au fichier de verrouillage d'un flake (flake.lock) afin qu'il contienne un verrou pour chaque entrée de flake spécifiée dans flake.nix. Les entrées existantes du fichier de verrouillage ne sont pas mises à jour.

Si vous souhaitez mettre à jour les entrées de verrouillage existantes, utilisez nix flake update

Options

Options communes d'évaluation

•
--arg nom expr
Passe la valeur expr comme argument nom aux fonctions Nix.
•
--arg-from-file nom chemin
Passe le contenu du fichier chemin comme argument nom aux fonctions Nix.
•
--arg-from-stdin nom
Passe le contenu de l'entrée standard comme argument nom aux fonctions Nix.
•
--argstr nom chaîne
Passe la chaîne chaîne comme argument nom aux fonctions Nix.
•
--debugger
Démarre un environnement interactif si l'évaluation échoue.
•
--eval-store url-store
L'URL du magasin Nix à utiliser pour l'évaluation, c'est-à-dire pour stocker les dérivations (.drv) et les entrées référencées par celles-ci.
•
--impure
Autorise l'accès aux dépôts et chemins modifiables.
•
--include / -I chemin
Ajoute chemin aux entrées du chemin de recherche utilisées pour résoudre les chemins de recherche
Cette option peut être donnée plusieurs fois.
Les chemins ajoutés via -I ont la priorité sur le paramètre de configuration nix-path et la variable d'environnement NIX_PATH.
•
--override-flake ref-original ref-résolu
Remplace les registres de flakes, redirigeant ref-original vers ref-résolu.

Options communes liées aux flakes

•
--commit-lock-file
Valide les modifications dans le fichier de verrouillage du flake.
•
--inputs-from url-flake
Utilise les entrées du flake spécifié comme entrées du registre.
•
--no-registries
Ne permet pas les recherches dans les registres de flakes.
OBSOLÈTE
Utilisez plutôt --no-use-registries.
•
--no-update-lock-file
Ne permet aucune mise à jour du fichier de verrouillage du flake.
•
--output-lock-file chemin-verrou-flake
Écrit le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--override-input chemin-entrée url-flake
Remplace une entrée de flake spécifique (par exemple dwarffs/nixpkgs). Ceci implique --no-write-lock-file.
•
--recreate-lock-file
Recrée le fichier de verrouillage du flake à partir de zéro.
OBSOLÈTE
Utilisez plutôt nix flake update.
•
--reference-lock-file chemin-verrou-flake
Lit le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--update-input chemin-entrée
Met à jour une entrée de flake spécifique (en ignorant son entrée précédente dans le fichier de verrouillage).
OBSOLÈTE
Utilisez plutôt nix flake update.

Options liées à la journalisation

•
--debug
Active la journalisation de débogage.
•
--log-format format
Spécifie le format des journaux. Les formats possibles sont json, raw, carbo, et human.
•
-v / --verbose niveau
Augmente le niveau de verbosité. Voir aussi --no-update-lock-file.

Autres options

•
--help
Affiche un message d'aide et quitte.
•
--show-trace
Affiche un trace de débogage en cas d'échec.
•
--version
Affiche la version de Nix et quitte.
•
--no-write-lock-file
N'écrit pas le fichier de verrouillage.

Voir aussi

nix-flake(1), nix-flake-update(1)

Options

--debug
Définit le niveau de verbosité de la journalisation sur ‘debug’.
•
--log-format format
Définit le format de la sortie du journal ; l'un des formats raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Affiche les journaux de construction complets sur la sortie d'erreur standard.
•
--quiet
Diminue le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmente le niveau de verbosité de la journalisation.

Options diverses globales

•
--help
Affiche les informations d'utilisation.
•
--offline
Désactive les substituts et considère tous les fichiers téléchargés précédemment comme à jour.
•
--option name value
Définit le paramètre de configuration Nix name à value (remplaçant nix.conf).
•
--refresh
Considère tous les fichiers téléchargés précédemment comme obsolètes.
•
--repair
Pendant l'évaluation, réécrit les fichiers manquants ou corrompus dans le Nix store. Pendant la construction, reconstruit les chemins de store manquants ou corrompus.
•
--version
Affiche les informations de version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec des indicateurs de ligne de commande.
