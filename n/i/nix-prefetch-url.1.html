nix-prefetch-url(1) Manuel des commandes générales nix-prefetch-url(1)

Nom

nix-prefetch-url - copier un fichier depuis une URL dans le store et imprimer son hachage

Synopsis

nix-prefetch-url url [hash] [--type hashAlgo] [--print-path] [--unpack] [--name name]

Description

La commande nix-prefetch-url télécharge le fichier référencé par l'URL url, imprime son hachage cryptographique, et le copie dans le store Nix. Le nom du fichier dans le store est hash-baseName, où baseName est tout ce qui suit la dernière barre oblique dans url.

Cette commande est juste une commodité pour les rédacteurs d'expressions Nix. Souvent, une expression Nix récupère une distribution source du réseau en utilisant l'expression fetchurl contenue dans Nixpkgs. Cependant, fetchurl nécessite un hachage cryptographique. Si vous ne connaissez pas le hachage, vous devriez d'abord télécharger le fichier, et ensuite fetchurl le téléchargerait à nouveau lorsque vous construiriez votre expression Nix. Puisque fetchurl utilise le même nom pour le fichier téléchargé que nix-prefetch-url, le téléchargement redondant peut être évité.

Si hash est spécifié, alors un téléchargement n'est pas effectué si le store Nix contient déjà un fichier avec le même hachage et nom de base. Sinon, le fichier est téléchargé, et une erreur est signalée si le hachage réel du fichier ne correspond pas au hachage spécifié.

Cette commande imprime le hachage sur la sortie standard. Le hachage est imprimé en base 32 sauf si --type md5 est spécifié, auquel cas il est imprimé en base 16. De plus, si l'option --print-path est utilisée, le chemin du fichier téléchargé dans le store Nix est également imprimé.

Options

•
--type hashAlgo
Utilise l'algorithme de hachage cryptographique spécifié, qui peut être l'un de md5, sha1, sha256, et sha512. La valeur par défaut est sha256.
•
--print-path
Imprime le chemin de stockage du fichier téléchargé sur la sortie standard.
•
--unpack
Désarchive le fichier (qui doit être une archive tar ou un fichier zip) et ajoute le résultat au store Nix. Le hachage résultant peut être utilisé avec des fonctions telles que fetchzip de Nixpkgs ou fetchFromGitHub.
•
--executable
Définit le bit exécutable sur le fichier téléchargé.
•
--name name
Remplace le nom du fichier dans le store Nix. Par défaut, c'est hash-basename, où basename est le dernier composant de url. Remplacer le nom est nécessaire lorsque basename contient des caractères qui ne sont pas autorisés dans les chemins du store Nix.

Exemples

$ nix-prefetch-url ftp://ftp.gnu.org/pub/gnu/hello/hello-2.10.tar.gz
0ssi1wpaf7plaswqqjwigppsg5fyh99vdlb9kzl7c9lng89ndq1i
$ nix-prefetch-url --print-path mirror://gnu/hello/hello-2.10.tar.gz
0ssi1wpaf7plaswqqjwigppsg5fyh99vdlb9kzl7c9lng89ndq1i
/nix/store/3x7dwzq014bblazs7kq20p9hyzz0qh8g-hello-2.10.tar.gz
$ nix-prefetch-url --unpack --print-path https://github.com/NixOS/patchelf/archive/0.8.tar.gz
079agjlv0hrv7fxnx9ngipx14gyncbkllxrp9cccnh3a50fxcmy7
/nix/store/19zrmhm3m40xxaw81c8cqm6aljgrnwj2-0.8.tar.gz
