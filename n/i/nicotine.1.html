NICOTINE+(1) Manuel des commandes générales NICOTINE+(1)

NOM

nicotine - client graphique pour le réseau peer-to-peer Soulseek

SYNOPIS

nicotine [options]

DESCRIPTION

Nicotine+ est une application graphique qui permet aux utilisateurs d'interagir avec le réseau peer-to-peer Soulseek.

OPTIONS

-c <fichier>, --config=<fichier>
Utiliser <fichier> comme fichier de configuration. Si <fichier> n'existe pas, un nouveau fichier de configuration vide sera créé.
-u <rép>, --user-data=<rép>
Utiliser <rép> comme répertoire pour les données utilisateur et les plugins. Si <rép> n'existe pas, un nouveau répertoire vide sera créé.
-h, --help
Afficher l'aide de la commande et quitter.
-s, --hidden
Démarrer le programme sans afficher la fenêtre.
-b <ip>, --bindip=<ip>
Lier les sockets à l'<ip> donnée (utile pour les VPN).
-l <port>, --port=<port>
Écouter sur le <port> donné. Remplace la configuration de la plage de ports.
-r, --rescan
Scanner à nouveau les fichiers partagés.
-n, --headless
Démarrer le programme en mode sans tête (pas d'interface graphique).
-v, --version
Afficher le numéro de version et quitter.

STATUT DE SORTIE

Le statut de sortie normal du programme est 0.
Si les dépendances requises ne sont pas présentes, le statut de sortie est 1.
Si la liste d'arguments donnée ne peut pas être analysée, le statut de sortie est 2.

FICHIERS

~/.config/nicotine/config
Le fichier de configuration.
~/.local/share/nicotine/
Autres fichiers personnels tels que les téléchargements, partages et journaux.

ENVIRONNEMENT

Les variables d'environnement suivantes sont disponibles lors de l'exécution du programme.

NICOTINE_GTK_VERSION
La version majeure de GTK à utiliser, si installée. Les valeurs possibles sont 4 ou 3.
NICOTINE_LIBADWAITA
Indique s'il faut activer libadwaita (thème GNOME), si installée. Les valeurs possibles sont 1 ou 0.
