nix3-flake-info(1) Manuel des commandes générales nix3-flake-info(1)

Attention
Ce programme est expérimental et son interface est susceptible de changer.

Nom

nix flake info - afficher les métadonnées de flake

Synopsis

nix flake info [option…] url-flake

Exemples

•
Afficher à quoi dwarffs se résout :
# nix flake metadata dwarffs
URL résolue :  github:edolstra/dwarffs

Révision :      f691e2c991e75edb22836f1dbe632c40324215c5
Dernière modification : 2021-01-21 15:41:26
Entrées :
├───nix: github:NixOS/nix/6254b1f5d298ff73127d7b0f0da48f142bdc753c

Description

Cette commande affiche des informations sur le flake spécifié par la référence de flake url-flake. Elle résout la référence de flake en utilisant le registre des flakes, le télécharge, et affiche des métadonnées. Cela inclut :

  • URL résolue : Si url-flake est un identifiant de flake, il s'agit de la référence de flake qui spécifie son emplacement réel, recherchée dans le registre des flakes.
  • URL verrouillée : Une référence de flake qui contient un commit ou un hash de contenu et identifie ainsi de manière unique une version spécifique du flake.
  • Description : Une description du flake en une ligne, extraite du champ description dans flake.nix.
  • Chemin : Le chemin dans le store contenant le code source du flake.
  • Révision : Le hash du commit Git ou Mercurial du flake verrouillé.
  • Révisions : Le nombre d'ancêtres du commit Git ou Mercurial du flake verrouillé. Notez que ce n'est pas disponible pour les flakes github.
  • Dernière modification : Pour les flakes Git ou Mercurial, il s'agit du temps de commit du commit du flake verrouillé ; pour les flakes tarball, il s'agit de l'horodatage le plus récent de n'importe quel fichier à l'intérieur du tarball.
  • Entrées : Les entrées du flake avec leurs entrées correspondantes dans le fichier de verrouillage.

Avec --json, la sortie est un objet JSON avec les champs suivants :

  • original et originalUrl : La référence de flake spécifiée par l'utilisateur (url-flake) en représentation d'ensemble d'attributs et d'URL.
  • resolved et resolvedUrl : La référence de flake résolue (voir ci-dessus) en représentation d'ensemble d'attributs et d'URL.
  • locked et lockedUrl : La référence de flake verrouillée (voir ci-dessus) en représentation d'ensemble d'attributs et d'URL.
  • description : Voir Description ci-dessus.
  • path : Voir Chemin ci-dessus.
  • revision : Voir Révision ci-dessus.
  • revCount : Voir Révisions ci-dessus.
  • lastModified : Voir Dernière modification ci-dessus.
  • locks : Le contenu de flake.lock.

Options

•
--json
Produire une sortie au format JSON, adaptée à une utilisation par un autre programme.

Options communes d'évaluation

•
--arg nom expr
Transmettre la valeur expr comme argument nom aux fonctions Nix.
•
--arg-from-file nom chemin
Transmettre le contenu du fichier chemin comme argument nom aux fonctions Nix.
•
--arg-from-stdin nom
Transmettre le contenu de stdin comme argument nom aux fonctions Nix.
•
--argstr nom chaine
Transmettre la chaîne chaine comme argument nom aux fonctions Nix.
•
--debugger
Démarrer un environnement interactif si l'évaluation échoue.
•
--eval-store url-magasin
L'URL du magasin Nix à utiliser pour l'évaluation, c'est-à-dire pour stocker les dérivations (.drv) et les entrées référencées par celles-ci.
•
--impure
Autoriser l'accès aux chemins et dépôts modifiables.
•
--include / -I chemin
Ajouter chemin aux entrées du chemin de recherche utilisées pour résoudre les chemins de recherche
Cette option peut être donnée plusieurs fois.
Les chemins ajoutés via -I ont la priorité sur le paramètre de configuration nix-path et la variable d'environnement NIX_PATH.
•
--override-flake ref-original ref-résolue
Remplacer les registres de flakes, redirigeant ref-original vers ref-résolue.

Options communes relatives aux "flakes"

•
--commit-lock-file
Valide les modifications du fichier de verrouillage du flake.
•
--inputs-from url-du-flake
Utilise les entrées du flake spécifié comme entrées de registre.
•
--no-registries
N'autorise pas les recherches dans les registres de flakes.
OBSOLÈTE
Utilisez plutôt --no-use-registries.
•
--no-update-lock-file
N'autorise aucune mise à jour du fichier de verrouillage du flake.
•
--no-write-lock-file
N'écrit pas le nouveau fichier de verrouillage généré pour le flake.
•
--output-lock-file chemin-du-verrou-du-flake
Écrit le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--override-input chemin-d-entree url-du-flake
Remplace une entrée de flake spécifique (par exemple, dwarffs/nixpkgs). Ceci implique --no-write-lock-file.
•
--recreate-lock-file
Recrée le fichier de verrouillage du flake à partir de zéro.
OBSOLÈTE
Utilisez plutôt nix flake update.
•
--reference-lock-file chemin-du-verrou-du-flake
Lit le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--update-input chemin-d-entree
Met à jour une entrée de flake spécifique (en ignorant son entrée précédente dans le fichier de verrouillage).
OBSOLÈTE
Utilisez plutôt nix flake update.

Options relatives à la journalisation

•
--debug
Définit le niveau de verbosité de la journalisation sur "debug".
•
--log-format format
Définit le format de la sortie de journalisation ; l'un des éléments suivants : raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Affiche les journaux de construction complets sur la sortie standard d'erreur.
•
--quiet
Diminue le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmente le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Affiche les informations d'utilisation.
•
--offline
Désactive les substituts et considère tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définit le paramètre de configuration Nix nom sur valeur (en remplaçant nix.conf).
•
--refresh
Considère tous les fichiers précédemment téléchargés comme obsolètes.
•
--repair
Lors de l'évaluation, réécrit les fichiers manquants ou corrompus dans le Nix store. Lors de la construction, reconstruit les chemins du store manquants ou corrompus.
•
--version
Affiche les informations sur la version.

Note

Voir man nix.conf pour remplacer les paramètres de configuration avec les drapeaux de la ligne de commande.
