nix3-repl(1) Manuel des commandes générales nix3-repl(1)

Avertissement
Ce programme est expérimental et son interface est susceptible de changer.

Nom

nix repl - démarre un environnement interactif pour évaluer des expressions Nix

Synopsis

nix repl [option…] installables…

Exemples

•
Afficher toutes les commandes spéciales dans le REPL :
# nix repl
nix-repl> :?
•
Évaluer quelques expressions Nix simples :
# nix repl
nix-repl> 1 + 2
3
nix-repl> map (x: x * 2) [1 2 3]
[ 2 4 6 ]
•
Interagir avec Nixpkgs dans le REPL :
# nix repl --file example.nix
Chargement de l'installable ''...
3 variables ajoutées.
# nix repl --expr '{a={b=3;c=4;};}'
Chargement de l'installable ''...
1 variable ajoutée.
# nix repl --expr '{a={b=3;c=4;};}' a
Chargement de l'installable ''...
1 variable ajoutée.
# nix repl --extra-experimental-features 'flakes' nixpkgs
Chargement de l'installable 'flake:nixpkgs#'...
5 variables ajoutées.
nix-repl> legacyPackages.x86_64-linux.emacs.name
"emacs-27.1"
nix-repl> :q
# nix repl --expr 'import <nixpkgs>{}'
Chargement de l'installable ''...
12439 variables ajoutées.
nix-repl> emacs.name
"emacs-27.1"
nix-repl> emacs.drvPath
"/nix/store/lp0sjrhgg03y2n0l10n70rg0k7hhyz0l-emacs-27.1.drv"
nix-repl> drv = runCommand "hello" { buildInputs = [ hello ]; } "hello; hello > $out"
nix-repl> :b drv
Ce dérivé a produit les sorties suivantes :
out -> /nix/store/0njwbgwmkwls0w5dv9mpc1pq5fj39q0l-hello
nix-repl> builtins.readFile drv
"Hello, world!\n"
nix-repl> :log drv
Hello, world!

Description

Cette commande fournit un environnement interactif pour évaluer des expressions Nix. (REPL signifie 'read–eval–print loop'.)

Au démarrage, elle charge les expressions Nix nommées fichiers et les ajoute à la portée lexicale. Vous pouvez charger des fichiers supplémentaires en utilisant la commande :l <nom_de_fichier>, ou recharger tous les fichiers en utilisant :r.

Options

•
--stdin
Lire les installables depuis l'entrée standard. Aucune installable par défaut n'est appliquée.

Options communes d'évaluation

•
--arg nom expr
Passer la valeur expr comme argument nom aux fonctions Nix.
•
--arg-from-file nom chemin
Passer le contenu du fichier chemin comme argument nom aux fonctions Nix.
•
--arg-from-stdin nom
Passer le contenu de stdin comme argument nom aux fonctions Nix.
•
--argstr nom chaîne
Passer la chaîne chaîne comme argument nom aux fonctions Nix.
•
--debugger
Démarrer un environnement interactif si l'évaluation échoue.
•
--eval-store url-du-magasin
L'URL du magasin Nix à utiliser pour l'évaluation, c'est-à-dire pour stocker les dérivations (.drv) et les entrées référencées par celles-ci.
•
--impure
Autoriser l'accès aux chemins et dépôts modifiables.
•
--include / -I chemin
Ajouter chemin aux entrées du chemin de recherche utilisées pour résoudre les chemins de recherche
Cette option peut être donnée plusieurs fois.
Les chemins ajoutés via -I ont priorité sur le paramètre de configuration nix-path et la variable d'environnement NIX_PATH.
•
--override-flake ref-originale ref-résolue
Remplacer les registres de flake, redirigeant ref-originale vers ref-résolue.

Options communes liées aux flakes

•
--commit-lock-file
Valider les changements dans le fichier de verrouillage du flake.
•
--inputs-from url-du-flake
Utiliser les entrées du flake spécifié comme entrées de registre.
•
--no-registries
Ne pas autoriser les recherches dans les registres de flakes.
OBSOLÈTE
Utiliser --no-use-registries à la place.
•
--no-update-lock-file
Ne pas autoriser de mises à jour du fichier de verrouillage du flake.
•
--no-write-lock-file
Ne pas écrire le nouveau fichier de verrouillage généré du flake.
•
--output-lock-file chemin-verrouillage-flake
Écrire le fichier de verrouillage donné au lieu de flake.lock dans le flake de niveau supérieur.
•
--override-input chemin-entrée url-du-flake
Remplacer une entrée de flake spécifique (par exemple dwarffs/nixpkgs). Cela implique --no-write-lock-file.
•
--recreate-lock-file
Recréer le fichier de verrouillage du flake à partir de zéro.
OBSOLÈTE
Utiliser nix flake update à la place.
•
--reference-lock-file chemin-verrouillage-flake
Lire le fichier de verrouillage donné inst
nix(1) — The Nix package manager

NAME

nix - package manager for Linux and other Unix-like systems

SYNOPSIS

nix command [options...]

nix --help

nix --version

DESCRIPTION

The nix command is the primary interface to the Nix package manager. It provides a wide range of subcommands for managing packages, environments, and system configurations.

This manual page provides an overview of the most common global options and specific subcommands. For detailed documentation on each subcommand, refer to its own manual page (e.g., nix build, nix shell, etc.) or the online documentation.

General options

•
--help
Show usage information and exit.
•
--version
Show version information and exit.

Common options

•
--accept-flake-conf
Permit Nix to write to ~/.config/nix/nix.conf if it doesn't exist or is empty.
•
--agree-to-substitutes
Allow downloading binary substitutes from the internet.
•
--impure
Allow the evaluation of impure Nix expressions. Such expressions may depend on the state of the user's system, and may include side effects.
•
--json
Format the output as JSON.
•
--log-format format
Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
•
--no-call-function
Do not allow Nix expressions to call functions.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--print-derivations
Print all derivations that will be built.
•
--print-flame-graph
Print a flame graph of the evaluation.
•
--print-output-path
Print the output path of the derivation.
•
--quiet
Decrease the logging verbosity level.
•
--refresh
Consider all previously downloaded files out-of-date.
•
--reproducible
Make the evaluation of Nix expressions more reproducible.
•
--store-path path
Use the Nix store specified by path.
•
--substituters urls
Set the list of substituter URLs to use.
•
--system system
Use the specified system architecture instead of the host system.
•
--trusted-public-keys keys
Set the list of trusted public keys for substitutes.
•
--verbose / -v
Increase the logging verbosity level.
•
--warn-invalid-escapes
Warn about invalid escape sequences in strings.

Flake options

•
--commit-lockfile
Commit the updated flake.lock file to Git.
•
--debug
Set the logging verbosity level to ‘debug’.
•
--experimental-features features
Enable experimental features separated by commas.
•
--force-reinstall
Reinstall all outputs, even if they are already installed.
•
--impure
Allow the evaluation of impure Nix expressions. Such expressions may depend on the state of the user's system, and may include side effects.
•
--include-flake-outputs
Include all flake outputs in the evaluation.
•
--input-from-git-commit commit
Use the flake inputs from the specified Git commit.
•
--input-from-flake flake-url
Use the flake inputs from the specified flake URL.
•
--lock-file lock-file
Use the specified flake lock file.
•
--log-format format
Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
•
--no-update-lock-file
Do not update the flake.lock file.
•
--override-input input-name input-value
Override a flake input with a new value.
•
--override-flake-output output-name output-value
Override a flake output with a new value.
•
--pretty-print
Print the output in a human-readable format.
•
--print-build-logs / -L
Print full build logs on standard error.
†
--read-only-flake-lock
Read-only mode for the flake.lock file.
•
--rebuild
Rebuild all outputs, even if they are already built.
•
--show-trace
Show the Nix evaluation trace.
•
--system system
Use the specified system architecture instead of the host system.
•
--tarball-path path
Use the specified tarball path.
•
--update-input input-path
Update a specific flake input (ignoring its previous entry in the lock file).
DEPRECATED
Use nix flake update instead.

Logging-related options

•
--debug
Set the logging verbosity level to ‘debug’.
•
--log-format format
Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
•
--print-build-logs / -L
Print full build logs on standard error.
•
--quiet
Decrease the logging verbosity level.
•
--verbose / -v
Increase the logging verbosity level.

Miscellaneous global options

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

Options that change the interpretation of installables

•
--expr expr
Interpret installables as attribute paths relative to the Nix expression expr.
•
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.

Note

See man nix.conf for overriding configuration settings with command line flags.
