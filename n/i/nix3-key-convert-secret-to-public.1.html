Nom

nix key convert-secret-to-public - génère une clé publique pour vérifier les chemins de magasin à partir d'une clé secrète lue depuis l'entrée standard

Synopsis

nix key convert-secret-to-public [option•]

Exemples

•
Convertir une clé secrète en clé publique :
# echo cache.example.org-0:E7lAO+MsPwTFfPXsdPtW8GKui/5ho4KQHVcAGnX+Tti1V4dUxoVoqLyWJ4YESuZJwQ67GVIksDt47og+tPVUZw== \
| nix key convert-secret-to-public
cache.example.org-0:tVeHVMaFaKi8lieGBErmScEOuxlSJLA7eO6IPrT1VGc=

Description

Cette commande lit une clé secrète Ed25519 depuis l'entrée standard, et écrit la clé publique correspondante sur la sortie standard. Pour plus de détails, voir nix key generate-secret.

Options

Options liées à la journalisation

•
--debug
Définit le niveau de verbosité de la journalisation à ‘debug’.
•
--log-format format
Définit le format de la sortie des logs ; l'un parmi raw, internal-json, bar ou bar-with-logs.
•
--print-build-logs / -L
Affiche les logs de construction complets sur l'erreur standard.
•
--quiet
Diminue le niveau de verbosité de la journalisation.
•
--verbose / -v
Augmente le niveau de verbosité de la journalisation.

Options globales diverses

•
--help
Affiche les informations d'utilisation.
•
--offline
Désactive les substituts et considère tous les fichiers précédemment téléchargés comme à jour.
•
--option nom valeur
Définit le paramètre de configuration Nix nom à valeur (remplaçant nix.conf).
•
--refresh
Considère tous les fichiers précédemment téléchargés comme obsolètes.
•
--version
Affiche les informations sur la version.

Note

Voir man nix.conf pour les options de surcharge de configuration en ligne de commande.
