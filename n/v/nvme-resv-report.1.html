NOM

nvme-resv-report - Envoyer un rapport de réservation NVMe, analyser le résultat

SYNTAXE

nvme resv-report <périphérique> [--namespace-id=<nsid> | -n <nsid>]
                        [--numd=<nombre-dwords> | -d <nombre-dwords>] [--eds | -e]
                        [--raw-binary | -b]
                        [--output-format=<format> | -o <format>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPTION

La commande de rapport de réservation renvoie une structure de données d'état de réservation dans la mémoire hôte qui décrit l'état d'enregistrement et de réservation d'un espace de noms.

La taille de la structure de données d'état de réservation est une fonction du nombre de contrôleurs dans le sous-système NVM associés aux hôtes qui sont des enregistrants de l'espace de noms (c'est-à-dire qu'il existe une structure de données de contrôleur enregistré pour chaque contrôleur concerné).

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Récupère la structure du rapport de réservation pour le nsid donné. Ceci est requis pour les périphériques caractères, ou remplace le nsid de bloc s'il est spécifié.

-d <nombre-dwords>, --numd=<nombre-dwords>

Spécifie le nombre de Dwords de la structure d'état de réservation à transférer. La valeur par défaut est 4k.

-e, --eds

Demander une structure de données étendue : si ce bit est réglé sur 1, le contrôleur renvoie la structure de données étendue.

-b, --raw-binary

Imprime le tampon brut sur la sortie standard. La structure n'est pas analysée par le programme.

-o <format>, --output-format=<format>

Définit le format de rapport sur normal, json ou binaire. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

-t <timeout>, --timeout=<timeout>

Remplace la valeur de délai d'attente par défaut. En millisecondes.
