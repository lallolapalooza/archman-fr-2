NOM

nvme-wdc-cloud-boot-SSD-version - Afficher la version du SSD de démarrage Cloud du plugin WDC

SYNOPIS

nvme wdc cloud-boot-SSD-version <périphérique>

DESCRIPTION

Pour le périphérique NVMe donné, cette commande affiche la version actuelle du démarrage Cloud Hyperscale (si elle est prise en charge par le périphérique).

Le paramètre <périphérique> est un périphérique caractère NVMe obligatoire (ex: /dev/nvme0).

En cas de succès, renvoie 0, sinon le code d'erreur.

EXEMPLES

•Affiche la version du SSD de démarrage cloud pour le périphérique: 
# nvme wdc cloud-boot-SSD-version /dev/nvme0

NVME

Fait partie de la suite nvme-user.
