NOM

nvme-sndk-set-latency-monitor-feature - Configure les options de la fonctionnalité de surveillance de latence NVMe sndk

SYNTAXE

nvme sndk set-latency-monitor-feature <périphérique>
                        [--active_bucket_timer_threshold=<NB> | -t <NB>]
                        [--active_threshold_a=<NB> | -a <NB>]
                        [--active_threshold_b=<NB> | -b <NB>]
                        [--active_threshold_c=<NB> | -c <NB>]
                        [--active_threshold_d=<NB> | -d <NB>]
                        [--active_latency_config=<NB> | -f <NB>]
                        [--active_latency_minimum_window=<NB> | -w <NB>]
                        [--debug_log_trigger_enable=<NB> | -r <NB>]
                        [--discard_debug_log=<NB> | -l <NB>]
                        [--latency_monitor_feature_enable=<NB> | -e <NB>]

DESCRIPTION

Pour le périphérique NVMe spécifié, cette commande configure les options de la fonctionnalité de surveillance de latence (si elle est prise en charge par le périphérique).

Le paramètre <périphérique> est le périphérique caractère NVMe obligatoire (ex: /dev/nvme0).

Les résultats de la configuration peuvent être vérifiés avec la commande get-latency-monitor-log.

En cas de succès, retourne 0, sinon un code d'erreur.

OPTIONS

-t <NB>, --active_bucket_timer_threshold=<NB>

La valeur qui charge le Seuil du minuteur de compartiment actif ; la valeur par défaut est 07E0h.

-a <NB>, --active_threshold_a=<NB>

La valeur chargée dans le Seuil Actif A ; la valeur par défaut est 05h.

-b <NB>, --active_threshold_b=<NB>

La valeur chargée dans le Seuil Actif B ; la valeur par défaut est 13h.

-c <NB>, --active_threshold_c=<NB>

La valeur chargée dans le Seuil Actif C ; la valeur par défaut est 1Eh.

-d <NB>, --active_threshold_d=<NB>

La valeur chargée dans le Seuil Actif D ; la valeur par défaut est 2Eh.

-f <NB>, --active_latency_config=<NB>

La valeur chargée dans la Configuration de Latence Active. Elle configure comment l'Estampille de Latence Active et les champs de Latence Mesurée Active sont mis à jour sur la base du compteur par commande I/O (Lecture, Écriture, Désallocation) ; la valeur par défaut est 0FFFh.

-w <NB>, --active_latency_minimum_window=<NB>

La valeur chargée dans la Fenêtre Minimale de Latence Active ; la valeur par défaut est 0Ah.

-r <NB>, --debug_log_trigger_enable=<NB>

La valeur chargée dans l'Activation du Déclenchement du Journal de Débogage ; lorsqu'il est défini à 1b, la première fois que la combinaison compartiment/compteur est incrémentée, un journal de débogage est déclenché. Lorsqu'il est remis à 0b, un journal de débogage ne sera pas déclenché lorsque la combinaison compartiment/compteur est incrémentée.

-l <NB>, --discard_debug_log=<NB>

Ignorer le Journal de Débogage. Lorsqu'il est remis à 00h, le journal de débogage, s'il existe, ne sera pas effacé. Lorsqu'il est défini à 01h, le journal de débogage sera ignoré afin qu'un autre journal puisse être déclenché. Tous les champs de la structure de Données Set Features sont valides. Lorsqu'il est défini à 02h, le journal de débogage sera ignoré afin qu'un autre journal puisse être déclenché. Aucun des autres champs de la structure de Données Set Features n'est valide.

-e <NB>, --latency_monitor_feature_enable=<NB>

Activation de la Fonctionnalité de Surveillance de Latence ; lorsqu'elle est définie à 01h, la Fonctionnalité de Surveillance de Latence est activée. Lorsqu'elle est remise à 00h, la Fonctionnalité de Surveillance de Latence est désactivée.

EXEMPLES

•Configurer les options de la fonctionnalité de surveillance de latence NVMe sndk activées avec les valeurs par défaut : 
# nvme sndk set-latency-monitor-feature /dev/nvme0 -e 1
•Configurer les options de la fonctionnalité de surveillance de latence NVMe sndk désactivées avec les valeurs par défaut : 
# nvme sndk set-latency-monitor-feature /dev/nvme0 -e 0
•Configurer les options de la fonctionnalité de surveillance de latence NVMe sndk activées avec des valeurs spécifiques : 
# nvme sndk set-latency-monitor-feature /dev/nvme0 --active_bucket_timer_threshold=1 \
            --active_threshold_a=0x0 \
            --active_threshold_b=0x1 \
            --active_threshold_c=0x2 \
            --active_threshold_d=0x3 \
            --active_latency_config=0xfff \
            --active_latency_minimum_window=0 \
            --debug_log_trigger_enable=0 \
            --discard_debug_log=0 \
            --latency_monitor_feature_enable=0x1
