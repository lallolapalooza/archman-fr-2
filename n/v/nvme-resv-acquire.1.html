NOM

nvme-resv-acquire - Acquérir une réservation nvme

SYNTAXE

nvme resv-acquire <périphérique> [--namespace-id=<nsid> | -n <nsid>]
                        [--crkey=<crkey> | -c <crkey>]
                        [--prkey=<prkey> | -p <prkey>]
                        [--rtype=<rtype> | -t <rtype>]
                        [--racqa=<racqa> | -a <racqa>] [--iekey | -i]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout>]

DESCRIPTION

La commande Reservation Acquire (Acquisition de réservation) est utilisée pour acquérir une réservation sur un espace de noms, pour préempter une réservation détenue sur un espace de noms, et pour annuler une réservation détenue sur un espace de noms.

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Remplace le champ nsid. Si vous utilisez le périphérique caractère d'administration, ce paramètre est obligatoire.

-c <crkey>, --crkey=<crkey>

Clé de réservation actuelle : Ce champ spécifie la clé de réservation actuelle associée à l'hôte. Si le bit IEKEY est défini sur ‘1’ dans la commande, la vérification CRKEY réussit quel que soit la valeur de ce champ.

-p <prkey>, --prkey=<prkey>

Clé de préemption de réservation : Si l'action d'acquisition de réservation est définie sur 001b (c'est-à-dire Preempt) ou 010b (c'est-à-dire Preempt and Abort), alors ce champ spécifie la clé de réservation à désenregistrer de l'espace de noms. Pour toutes les autres valeurs de l'action d'acquisition de réservation, ce champ est réservé.

-t <rtype>, --rtype=<rtype>

Type de réservation : Ce champ spécifie le type de réservation à créer.
Valeur Définition
0h Réservé
1h Réservation en écriture exclusive
2h Réservation d'accès exclusif
3h Réservation en écriture exclusive - Réservataires uniquement
4h Réservation d'accès exclusif - Réservataires uniquement
5h Réservation en écriture exclusive - Tous les résérvataires
6h Réservation d'accès exclusif - Tous les résérvataires
07h-FFh Réservé

-a <racqa>, --racqa=<racqa>

Action d'acquisition de réservation : Ce champ spécifie l'action effectuée par la commande.
Valeur Définition
0 Acquérir
1 Préempter
2 Préempter et annuler
3-7 Réservé

-i, --iekey

Ignorer la clé existante : Si ce bit est défini sur 1, la vérification de la Clé de Réservation Actuelle (CRKEY) est désactivée et la commande doit réussir quelle que soit la valeur du champ CRKEY.

Option indicateur, par défaut à 0.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

--timeout=<timeout>

Remplace la valeur de délai d'attente par défaut. En millisecondes.
