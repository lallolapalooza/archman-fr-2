NOM

nvme-admin-passthru - Soumettre une commande d'administration arbitraire, retourner les résultats

SYNTAXE

nvme-admin-passthru <périphérique> [--opcode=<code_op> | -O <code_op>]
                        [--flags=<flags> | -f <flags>] [--rsvd=<rsvd> | -R <rsvd>]
                        [--namespace-id=<nsid> | -n <nsid>] [--cdw2=<cdw2> | -2 <cdw2>]
                        [--cdw3=<cdw3> | -3 <cdw3>] [--cdw10=<cdw10> | -4 <cdw10>]
                        [--cdw11=<cdw11> | -5 <cdw11>] [--cdw12=<cdw12> | -6 <cdw12>]
                        [--cdw13=<cdw13> | -7 <cdw13>] [--cdw14=<cdw14> | -8 <cdw14>]
                        [--cdw15=<cdw15> | -9 <cdw15>]
                        [--data-len=<longueur_données> | -l <longueur_données>]
                        [--metadata-len=<longueur> | -m <longueur>]
                        [--input-file=<fichier> | -i <fichier>]
                        [--read | -r] [--write | -w]
                        [--timeout=<délai> | -t <délai>]
                        [--show-command | -s]
                        [--dry-run | -d]
                        [--raw-binary | -b]
                        [--prefill=<préremplissage> | -p <préremplissage>]
                        [--latency | -T]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Soumet une commande d'administration NVMe arbitraire et retourne les résultats applicables. Il peut s'agir simplement du résultat et du statut de la commande, ou il peut également inclure un tampon si la commande en renvoie un. Cette commande n'interprète pas les codes d'opération ni les options.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de l'espace de noms (ex: /dev/nvme0n1).

En cas de succès, la structure retournée (si applicable) peut être renvoyée de plusieurs manières selon les options ; la structure peut être imprimée par le programme sous forme de vidage hexadécimal, ou peut être renvoyée sous forme de tampon brut imprimé sur la sortie standard pour qu'un autre programme puisse l'analyser.

OPTIONS

-O <code_op>, --opcode=<code_op>

Le code d'opération NVMe à envoyer au périphérique dans la commande. Argument obligatoire car ce paramètre est obligatoire.

-f <flags>, --flags=<flags>

Les indicateurs de commande NVMe à envoyer au périphérique dans la commande.

-R <rsvd>, --rsvd=<rsvd>

La valeur du champ réservé dans la commande.

-n <nsid>, --namespace-id=<nsid>

La valeur du ns-id dans la commande.

-[2-9] <cdw>, --cdw[2-3,10-15]=<cdw>

Spécifie la valeur du mot de commande pour cette entrée spécifiée dans la commande.

-r, --read, -w, --write

Utilisé pour la direction des données de la commande et obligatoire pour les commandes envoyant/recevant des données. N'utilisez pas read et write en même temps.

-i <fichier>, --input-file=<fichier>

Si la commande est une commande data-out (écriture), utilisez ce fichier pour remplir le tampon envoyé au périphérique. Si aucun fichier n'est donné, on suppose l'utilisation de STDIN.

-l <longueur_données>, --data-len=<longueur_données>

La longueur des données pour le tampon utilisé pour cette commande.

-m <longueur_données>, --metadata-len=<longueur_données>

La longueur des métadonnées pour le tampon utilisé pour cette commande.

-s, --show-cmd

Afficher la commande à envoyer.

-d, --dry-run

N'envoyez pas réellement la commande. Si vous souhaitez utiliser l'option --dry-run, l'option --show-cmd doit être définie. Sinon, l'option --dry-run sera ignorée.

-b, --raw-binary

Afficher le tampon retourné brut sur la sortie standard si la commande retourne une structure.

-p, --prefill

Préremplit le tampon avec une valeur d'octet prédéterminée. Par défaut à 0. Cela peut être utile si les données que vous écrivez sont plus courtes que le tampon requis, et que vous devez les compléter avec une valeur connue. Cela peut également être utile si vous devez confirmer si un périphérique écrase un tampon pour une commande data-in.

-T, --latency

Afficher la latence de l'IOCTL (en µs).

-o <fmt>, --output-format=<fmt>

Définir le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmenter le niveau de détail des informations dans la sortie.

-t <délai>, --timeout=<délai>

Remplace la valeur de délai par défaut. En millisecondes.

EXEMPLES

•Ce qui suit exécutera la commande d'administration avec le code d'opération=6 et cdw10=1, ce qui correspond à une commande d'identification du contrôleur. Cet exemple nécessite que le paramètre data-len soit 4096, ce qui est la taille de la structure retournée. L'option -r est utilisée car il s'agit d'une commande data-in. 
# nvme admin-passthru /dev/nvme0 --opcode=06 --data-len=4096 --cdw10=1 -r
•Ou si vous voulez enregistrer cette structure dans un fichier : 
# nvme admin-passthru /dev/nvme0 --opcode=06 --data-len=4096 --cdw10=1 -r -b > id_ns.raw
