NOM

nvme-toshiba-vs-internal-log - Récupère le journal interne spécifique au vendeur d'un périphérique Toshiba et l'enregistre dans un fichier ou affiche son contenu.

SYNTAXE

'nvme toshiba vs-internal-log ' <périphérique>
                [--output-file=<FICHIER>, -o <FICHIER>] (optionnel)
                [--saved-log, -s] (optionnel)

DESCRIPTION

Pour le périphérique NVMe donné, envoie la requête de journal interne spécifique au vendeur Toshiba et enregistre le résultat dans un fichier ou affiche le contenu sur la sortie standard.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

Le journal est associé au contrôleur plutôt qu'à aucun namespace.

Deux journaux existent, le journal courant et le journal précédent.

Ceci ne fonctionnera que sur les périphériques Toshiba prenant en charge cette fonctionnalité.

Remarque : Les journaux sont assez volumineux - typiquement des centaines de Mo. Cette commande peut prendre plusieurs minutes à se terminer. Une barre de progression est incluse lors de l'écriture des données dans le fichier et un nombre de pages est inclus dans l'affichage sur la sortie standard.

OPTIONS

-o <FICHIER>, --output-file=<FICHIER>

Fichier binaire de sortie. Par défaut, affichage formaté texte sur la sortie standard

-p, --prev-log

Utilise le contenu du journal précédent. Par défaut, utilise le contenu du journal courant.

EXEMPLES

•Obtenir le journal courant du périphérique et l'afficher sur la sortie standard : 
# nvme toshiba internal-log /dev/nvme0
•Obtenir le journal précédent du périphérique et l'enregistrer dans un fichier binaire : 
# nvme toshiba internal-log /dev/nvme0 --output-file=log.bin --prev-log
