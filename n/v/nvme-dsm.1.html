NOM

nvme-dsm - Envoie des données de gestion de jeu de données NVMe, retourne les résultats

SYNOPIS

nvme dsm <périphérique> [--namespace-id=<nsid> | -n <nsid>]
                        [--ctx-attrs=<liste-attributs,> | -a <liste-attributs,>]
                        [--blocks=<liste-nlb,> | -b <liste-nlb,>]
                        [--slbs=<liste-slba,> | -s <liste-slba,>]
                        [--ad=<désallocation> | -d <désallocation>]
                        [--idw=<écriture> | -w <écriture>] [--idr=<lecture> | -r <lecture>]
                        [--cdw11=<cdw11> | -c <cdw11>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<délai> | -t <délai>]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande de gestion de jeu de données et fournit le résultat et la structure retournée.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique de caractère NVMe (par ex : /dev/nvme0), soit un périphérique bloc de l'espace de noms (par ex : /dev/nvme0n1). Si le périphérique de caractère est donné, l'option '--namespace-id' est obligatoire, sinon il utilisera l'identifiant d'espace de noms du périphérique bloc que vous avez ouvert. Pour les périphériques blocs, l'identifiant d'espace de noms utilisé peut être remplacé avec la même option.

Vous devez spécifier au moins une des valeurs pour la liste des plages. Si les listes de plages fournies ne listent pas le même nombre d'éléments, les valeurs par défaut pour les éléments restants dans la plage seront définies à 0.

Le mot de commande 11 peut être fourni en ligne de commande. Pour plus de commodité, les attributs actuellement définis (déchargement, lecture/écriture intégrale) pour une gestion de jeu de données ont des indicateurs. Si cdw11 est spécifié, cela remplacera tous les paramètres que les indicateurs auraient pu fournir.

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Envoie la commande avec le nsid demandé. Ceci est requis pour les périphériques de caractère, ou remplace le nsid du bloc s'il est donné.

-a <liste-attributs,>, --ctx-attrs=<liste-attributs>

Liste séparée par des virgules des attributs de contexte dans chaque plage

-b <liste-nlb,>, --blocks=<liste-nlb,>

Liste séparée par des virgules du nombre de blocs dans chaque plage

-s <liste-slba,>, --slbs=<liste-slba,>

Liste séparée par des virgules du bloc de départ dans chaque plage

-d <désallocation>, --ad=<désallocation>

Désallocation d'attribut.

-w <écriture>, --idw=<écriture>

Attribut de jeu de données intégral pour l'écriture.

-r <lecture>, --idr=<lecture>

Attribut de jeu de données intégral pour la lecture.

-c <cdw11>, --cdw11=<cdw11>

Tous les attributs du mot de commande 11. Utiliser exclusivement en spécifiant des attributs individuels

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binaire. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le détail des informations dans la sortie.

-t <délai>, --timeout=<délai>

Remplace la valeur de délai par défaut. En millisecondes.
