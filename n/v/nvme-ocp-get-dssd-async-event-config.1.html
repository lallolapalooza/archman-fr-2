NOM

nvme-ocp-get-dssd-async-event-config - Obtenir la valeur de dssd-async-event-config

SYNTAXE

nvme ocp get-dssd-async-event-config <périphérique> [--sel=<sélection> | -s <sélection>]

DESCRIPTION

Obtenir la configuration d'événement asynchrone dssd. dssd-async-event-config.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (par ex : /dev/nvme0) soit le périphérique bloc (par ex : /dev/nvme0n1).

Ceci ne fonctionnera que sur les périphériques conformes OCP supportant cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, renvoie 0, sinon un code d'erreur.

OPTIONS

-s <sélection>, --sel=<sélection>

Sélection (SEL) : Ce champ spécifie quelle valeur des attributs retourner dans les données fournies :
Sélection Description
0 Courante
1 Par défaut
2 Sauvegardée
3 Capacités supportées
4-7 Réservé

EXEMPLES

•Faire en sorte que le programme émette une commande get-dssd-async-event-config pour récupérer les caractéristiques 0xC9 sauvegardées. 
# nvme ocp get-dssd-async-event-config /dev/nvme0 -s 2
