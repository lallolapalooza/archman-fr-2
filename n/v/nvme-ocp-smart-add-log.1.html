NOM

nvme-ocp-smart-add-log - Récupère les informations SMART étendues d'un périphérique conforme OCP donné

SYNTAXE

nvme ocp smart-add-log <périphérique> [--output-format=<fmt> | -o <fmt>] [--output-format-version=<version>]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande smart-add-log et fournit le journal intelligent supplémentaire.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0) soit le périphérique bloc (ex: /dev/nvme0n1).

Cela ne fonctionnera que sur les périphériques conformes OCP prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

EXPÉRIMENTAL. --output-format-version peut être défini à 2 pour générer des noms de champs pour les sorties plus faciles à traiter par les scripts. Notez que c'est expérimental et que les noms de champs sont sujets à modification.

En cas de succès, renvoie 0, sinon le code d'erreur.

OPTIONS

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal ou json. Un seul format de sortie peut être utilisé à la fois. La valeur par défaut est normal.

--output-format-version=<version>

Définit les étiquettes de champs dans le format de rapport sur 1 (l'original) ou 2. La valeur par défaut est 1. Notez que c'est expérimental.

EXEMPLES

•Demande au programme d'émettre une commande smart-add-log pour récupérer la page de journal 0xC0. 
# nvme ocp smart-add-log /dev/nvme0
