NOM

nvme-list-ns - Envoyer la commande NVMe Identify List Namespaces, retourner le résultat et la structure

SYNTAXE

nvme list-ns <périphérique> [--namespace-id=<nsid> | -n <nsid>]
                        [--csi=<command_set_identifier> | -y <command_set_identifier>]
                        [--all | -a]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande d'identification pour la liste des espaces de noms et fournit le résultat et la structure retournée.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc d'espace de noms (ex: /dev/nvme0n1). Si l'espace de noms de départ dans la liste commence toujours par 0 à moins que l'option '--namespace-id' ne soit donnée pour le remplacer.

En cas de succès, le tableau des espaces de noms est imprimé pour chaque indice et nsid pour un nsid valide.

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Récupère la structure de la liste d'identification à partir du nsid donné.

-y <identifiant_jeu_de_commandes>, --csi=<identifiant_jeu_de_commandes>

Si cette valeur est donnée, récupère la structure de la liste d'identification associée à l'ensemble de commandes d'E/S spécifié.

-a, --all

Récupère la structure de la liste d'identification pour tous les espaces de noms du sous-système, qu'ils soient attachés ou inactifs.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

-t <timeout>, --timeout=<timeout>

Remplace la valeur de timeout par défaut. En millisecondes.

EXEMPLES

•Imprimer les espaces de noms présents pour le jeu de commandes zoné au format JSON 
# nvme list-ns /dev/nvme0 -y 2 -a -o json
•Imprimer les espaces de noms présents pour le jeu de commandes NVM au format normal 
# nvme list-ns /dev/nvme0
