NOM

nvme-sndk-vs-smart-add-log - Envoie une commande unique par le fournisseur sndk vs-smart-add-log, renvoie le résultat

SYNTAXE

nvme sndk vs-smart-add-log <périphérique> [--interval=<NUM>, -i <NUM>]
                        [--output-format=<normal|json> -o <normal|json>]
                        [--log-page-version=<NUM>, -l <NUM>]
                        [--log-page-mask=<LIST>, -p <LIST>]
                        [--namespace-id=<nsid> | -n <nsid>]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande unique par le fournisseur sndk vs-smart-add-log et fournit le log intelligent supplémentaire.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex : /dev/nvme0) soit le périphérique bloc (ex : /dev/nvme0n1).

Cela ne fonctionnera que sur les périphériques Sandisk prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, renvoie 0, sinon le code d'erreur.

OPTIONS

-i <NUM>, --interval=<NUM>

Renvoie les statistiques d'un intervalle spécifique, par défaut 14. Ce paramètre n'est valide que pour la page de log 0xC1 et est ignoré pour toutes les autres pages de log.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal ou json. Un seul format de sortie peut être utilisé à la fois. Le défaut est normal.

-l <NUM>, --log-page-version=<NUM>

Version de la page de log : 0 = fournisseur, 1 = sndk. Ce paramètre n'est valide que pour la page de log 0xC0 et est ignoré pour toutes les autres pages de log.

-p <LIST>, --log-page-mask=<LIST>

Fournit une liste de pages de log désirées, séparées par des virgules. Les valeurs possibles sont 0xc0, 0xc1, 0xca, 0xd0. Remarque : Toutes les pages ne sont pas prises en charge sur tous les disques. Le défaut est d'afficher toutes les pages de log prises en charge.

-n <nsid>, --namespace-id=<nsid>

Définit la valeur nsid de la commande à la nsid donnée. La valeur par défaut est 0xffffffff si elle n'est pas fournie. Cette option peut ne rien affecter en fonction de la page de log, qui peut ou peut ne pas être spécifique à un espace de noms.

Valeurs valides pour Interval et description :-

Valeur Description
1 Ensemble accumulé le plus récent de cinq (5) minutes.
2-12 Ensembles accumulés des cinq (5) minutes précédentes.
13 L'ensemble total accumulé des ensembles 1 à 12 qui contiennent l'heure précédente de statistiques accumulées.
14 L'ensemble de statistiques accumulé depuis la mise sous tension.
15 L'ensemble de statistiques accumulé pendant toute la durée de vie du périphérique.

EXEMPLES

•Demande au programme d'émettre la commande unique par le fournisseur sndk vs-smart-add-log avec l'intervalle par défaut (14) : 
# nvme sndk vs-smart-add-log /dev/nvme0
•Demande au programme d'émettre la commande unique par le fournisseur sndk vs-smart-add-log uniquement pour la page de log 0xCA : 
# nvme sndk vs-smart-add-log /dev/nvme0 -p 0xCA
•Demande au programme d'émettre la commande unique par le fournisseur sndk vs-smart-add-log pour les pages de log 0xC0 et 0xCA : 
# nvme sndk vs-smart-add-log /dev/nvme0 -p 0xCA,0xC0
