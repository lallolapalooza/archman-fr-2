NOM

nvme-dir-receive - Envoie une commande de réception de directive, retourne les résultats applicables

SYNTAXE

nvme dir-receive <périphérique> [--namespace-id=<nsid> | -n <nsid>]
                        [--data-len=<longueur-données> | -l <longueur-données>]
                        [--dir-type=<type-dir> | -D <type-dir>]
                        [--dir-spec=<spéc-dir> | -S <spéc-dir>]
                        [--dir-oper=<op-dir> | -O <op-dir>]
                        [--req-resource=<ressource-ns> | -r <ressource-ns>]
                        [--human-readable | -H] [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPTION

Soumet une commande d'administration NVMe Directive Receive et retourne les résultats applicables. Il peut s'agir de la combinaison du type de directive et de l'opération, ainsi que du nombre de ressources demandées si une opération spécifique l'exige.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

En cas de succès, la structure de paramètres de la directive retournée (si applicable) est renvoyée d'une des manières suivantes selon les options ; la structure peut être analysée par le programme et imprimée dans un format lisible si c'est une structure connue, affichée en hexadécimal, ou le tampon brut peut être imprimé sur stdout pour qu'un autre programme l'analyse.

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Récupère la fonctionnalité pour le nsid donné. Ceci est optionnel et la plupart des fonctionnalités n'utilisent pas cette valeur.

-D <type-dir>, --dir-type=<type-dir>

Type de directive

-S <spéc-dir>, --dir-spec=<spéc-dir>

Spécificité de la directive

-O <op-dir>, --dir-oper=<op-dir>

Opération de directive

-r <ressource-ns>, --req-resource=<ressource-ns>

Nombre de ressources demandées par la directive
Sélectionner Description
0 Courant
1 Par défaut
2 Sauvegardé
3 Capacités supportées
4–7 Réservé

-l <longueur-données>, --data-len=<longueur-données>

La longueur des données pour le tampon retourné pour cette fonctionnalité. La plupart des fonctionnalités connues n'utilisent pas cette valeur. L'exception est le Type de Plage LBA.

-b, --raw-binary

Imprime le tampon de réception brut sur stdout si la commande retourne une structure.

-H, --human-readable

Imprime le tampon de réception décodé sur stdout si la commande retourne une structure.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail de l'information dans la sortie.

-t <timeout>, --timeout=<timeout>

Remplace la valeur de délai d'attente par défaut. En millisecondes.

EXEMPLES

•Identifier les types de directive supportés : 
# nvme dir-receive /dev/nvme0 --dir-type 0 --dir-oper 1 --human-readable
•Obtenir les paramètres de la directive de flux : 
# nvme dir-receive /dev/nvme0 --dir-type 1 --dir-oper 1 --human-readable
•Allouer 3 flux pour le namespace 1 
# nvme dir-receive /dev/nvme0n1 --dir-type 1 --dir-oper 3 --req-resource 3 --human-readable
•Obtenir le statut de la directive de flux : 
# nvme dir-receive /dev/nvme0 --dir-type 1 --dir-oper 2 --human-readable

Il est probablement déconseillé de ne pas rediriger stdout lors de l'utilisation de ce mode.
