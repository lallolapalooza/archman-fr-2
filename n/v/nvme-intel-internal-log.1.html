NOM

nvme-intel-internal-log - Récupérer le journal interne d'un périphérique Intel et l'enregistrer dans un fichier.

SYNTAXE

'nvme intel internal-log ' <périphérique> [--log=<NUM>, -l <NUM>]
                [--region=<NUM>, r <NUM>]
                [--nlognum=<NUM>, m <NUM>]
                [--namespace-id=<NUM>, -n <NUM>]
                [--output-file=<FICHIER>, -o <FICHIER>]

DESCRIPTION

Pour le périphérique NVMe donné, envoie la requête de journal de périphérique spécifique au vendeur Intel et enregistre le résultat dans un fichier.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1). Si vous utilisez le périphérique caractère, le paramètre d'ID de namespace est obligatoire.

Ceci ne fonctionnera que sur les périphériques Intel supportant cette fonctionnalité, incluant (mais sans s'y limiter) tous les contrôleurs de la famille Intel DC P3xxx. Les résultats pour tout autre périphérique sont indéfinis.

OPTIONS

-l <NUM>, --log=<NUM>

Type de journal : 0, 1 ou 2 pour le journal nlog, le journal d'événements et le journal d'assertion, respectivement.

-n <NUM>, --namespace-id=<NUM>

Namespace à utiliser.

-o <FICHIER>, --output-file=<FICHIER>

Fichier de sortie ; par défaut, le nom du périphérique fourni

-r <NUM>, --region=<NUM>

Sélectionne la région de base à partir de laquelle récupérer le journal. -1 pour toutes les régions disponibles, si supporté par le périphérique.

-m <NUM>, --nlognum=<NUM>

Lorsqu'il est utilisé avec nlog, spécifie quel nlog lire. -1 pour tous, si supporté par le périphérique.

EXEMPLES

•Récupère le nlog du périphérique et l'enregistre dans le fichier par défaut : 
# nvme intel internal-log /dev/nvme0 --namespace-id=1 --log=0
•Récupère le journal d'événements du périphérique et l'enregistre dans un fichier défini : 
# nvme intel internal-log /dev/nvme0 --namespace-id=1 --log=1 --output-file=MonSuperJournalDEvenements
