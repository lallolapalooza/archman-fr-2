NOM

nvme-netapp-ontapdevices - Afficher les informations sur les périphériques ONTAP

SYNTAXE

nvme netapp ontapdevices [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Affiche les informations sur les périphériques ONTAP sur l'hôte. Les périphériques ONTAP sont identifiés à l'aide des données d'identification du contrôleur.

OPTIONS

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal (par défaut), column (colonne), ou json. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Affiche des informations supplémentaires sur les périphériques ONTAP sur l'hôte.

EXEMPLES

•Affiche les informations, dans un format basé sur des colonnes, pour les périphériques ONTAP. 
# nvme netapp ontapdevices -o column
