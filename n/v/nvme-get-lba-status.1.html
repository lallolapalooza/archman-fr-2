NOM

nvme-get-lba-status - Obtenir le statut LBA du périphérique NVMe

SYNOPIS

nvme get-lba-status <périphérique> [--namespace-id=<nsid> | -n <nsid>]
                        [--start-lba=<slba> | -s <slba>]
                        [--max-dw=<max-dw> | -m <max-dw>]
                        [--action=<action-type> | -a <action-type>]
                        [--range-len=<range-len> | -l <range-len>]
                        [--timeout=<timeout> | -t <timeout>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande admin nvme Get LBA Status et fournit les résultats.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

En cas de succès, la structure de données get lba retournée peut être renvoyée de plusieurs manières selon les indicateurs d'options ; la structure peut être analysée par le programme et affichée dans un format lisible ou le tampon brut peut être affiché sur stdout pour être analysé par un autre programme.

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Envoie la commande Get LBA Status pour le nsid spécifié. Ceci peut être utilisé pour outrepasser la valeur par défaut pour le périphérique caractère (non spécifié) ou le périphérique bloc (résultat de NVME_IOCTL_ID).

-s <slba>, --start-lba=<slba>

Adresse LBA de départ (SLBA) sur 64 bits du premier bloc logique adressé

-m <max-dw>, --max-dw=<max-dw>

Nombre maximum de Dwords (MNDW) spécifie le nombre maximum de dwords à retourner

-a <action-type>, --action=<action-type>

Type d'action (ATYPE) spécifie le mécanisme utilisé pour déterminer les descripteurs de statut LBA.

-l <range-len>, --range-len=<range-len>

Longueur de la plage (RL) spécifie la longueur de la plage de LBAs contigus commençant à SLBA

-t <timeout>, --timeout=<timeout>

Remplace la valeur de délai d'attente par défaut. En millisecondes.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport à normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

•Obtenir le statut LBA du périphérique en utilisant tous les paramètres par défaut : 
# nvme get-lba-status /dev/nvme0n1
•Obtenir le statut LBA du namespace 1 à partir du SLBA 10 pour le nombre maximum de Dwords de 0x1000 : 
# nvme get-lba-status /dev/nvme0 --namespace-id=1 --start-lba=10 --max-dw=0x1000
