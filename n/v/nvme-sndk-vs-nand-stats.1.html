NOM

nvme-sndk-vs-nand-stats - Envoie une commande spécifique au vendeur NVMe sndk vs-nand-stats, renvoie le résultat

SYNTAXE

nvme sndk vs-nand-stats <périphérique> [--output-format=<normal|json> -o <normal|json>]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande spécifique au vendeur sndk vs-nand-stats et affiche les statistiques NAND. L'option --output-format formate la sortie comme spécifié.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (par ex. : /dev/nvme0).

Ceci ne fonctionnera que sur les périphériques Sandisk prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, renvoie les statistiques NAND, sinon un code d'erreur.

OPTIONS

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal ou json. Un seul format de sortie peut être utilisé à la fois. Le défaut est normal.

EXEMPLES

•Faire exécuter au programme la commande spécifique au vendeur sndk vs-nand-stats : 
# nvme sndk vs-nand-stats /dev/nvme0
