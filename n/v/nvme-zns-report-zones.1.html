NOM

nvme-zns-report-zones - Récupérer et afficher la structure de données Report Zones

SYNTAXE

nvme zns report-zones <périphérique> [--namespace-id=<NOMBRE> | -n <NOMBRE>]
                                 [--start-lba=<IONOMBRE> | -s <IONOMBRE>]
                                 [--descs=<NOMBRE> | -d <NOMBRE>]
                                 [--state=<NOMBRE> | -S <NOMBRE>]
                                 [--extended | -e]
                                 [--partial | -p]
                                 [--verbose | -v]
                                 [--output-format=<fmt> | -o <fmt>]

DESCRIPTION

Pour le périphérique NVMe donné, envoie la commande Zone Management Receive avec l'action Zone Receive définie sur soit Report Zones, soit Extended Report Zones, en fonction de l'option extended.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

En cas de succès, la structure de données retournée par le périphérique sera décodée et affichée de l'une des manières suivantes.

OPTIONS

-n <NOMBRE>, --namespace-id=<NOMBRE>

Utilise l'ID de namespace fourni pour la commande. S'il n'est pas fourni, l'ID de namespace du périphérique bloc sera utilisé. Si la commande est émise vers un périphérique non bloc, le paramètre est requis.

-s <lba>, --start-lba=<lba>

Le LBA de départ de la zone pour commencer le rapport

-d <NOMBRE>, --descs=<NOMBRE>

Le nombre de descripteurs à demander dans le rapport.

-S <NOMBRE>, --state=<NOMBRE>

L'état des zones à demander dans le rapport. Les valeurs connues incluent :
Valeur Définition
0 Liste toutes les zones (par défaut)
1 État Vide
2 État Ouvert Implicitement
3 État Ouvert Explicitement
4 État Fermé
5 État Plein
6 État Lecture Seule
7 État Hors Ligne

-e, --extended

Demande d'utiliser l'option Extended Report Zones. Les données étendues ne sont pas décodées.

-p, --partial

Si défini, le périphérique retournera le nombre de zones qui correspondent à l'état plutôt que le nombre de zones retournées dans le rapport.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json, ou binary. Un seul format de sortie peut être utilisé à la fois.

EXEMPLES

•Fait interpréter au programme le rapport pour 16 zones, et affiche les champs connus dans un format lisible par l'homme : 
# nvme zns report-zones /dev/nvme0 -n 1 -d 16
•Affiche la sortie en format JSON avec des détails supplémentaires 
# nvme zns report-zones /dev/nvme0 -n 1 -d 16 -o json
