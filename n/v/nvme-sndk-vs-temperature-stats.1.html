NOM

nvme-sndk-vs-temperature-stats - Affiche les statistiques liées à la température

SYNTAXE

nvme sndk vs-temperature-stats <périphérique>

DESCRIPTION

Pour le périphérique NVMe donné, affiche les statistiques de température.

Le paramètre <périphérique> est un périphérique caractère NVMe obligatoire (par ex. : /dev/nvme0).

Cela ne fonctionnera que sur les périphériques Sandisk prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

Statut et description attendus :

Statistique Description
Température composite actuelle température du périphérique
Seuil d'alerte de température composite température de surchauffe
Seuil de température composite critique température de surchauffe critique
Statut de prise en charge de l'étranglement thermique initié par le périphérique 0 = non pris en charge, 1 = pris en charge
Prise en charge de la gestion thermique contrôlée par l'hôte 0 = non pris en charge, 1 = pris en charge
Température de gestion thermique 1 (étranglement léger) température pour démarrer l'étranglement léger
Compteur de transitions de température de gestion thermique 1 # de passages en étranglement léger
Temps total de température de gestion thermique 1 # secondes passées en étranglement léger
Température de gestion thermique 2 (étranglement lourd) température pour démarrer l'étranglement lourd
Compteur de transitions de température de gestion thermique 2 # de passages en étranglement lourd
Temps total de température de gestion thermique 2 # secondes passées en étranglement lourd
Seuil d'arrêt thermique température d'arrêt du périphérique

En cas de succès, renvoie 0, sinon un code d'erreur.

EXEMPLES

•Affiche les statistiques de température pour le périphérique : 
# nvme sndk vs-temperature-stats /dev/nvme0
