NOM

nvme-show-hostnqn - Afficher le NQN hôte configuré pour le système

SYNTAXE

nvme show-hostnqn [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Affiche le NQN hôte configuré pour le système. Si /etc/nvme/hostnqn n'est pas présent et que les identifiants de machine spécifiques à l'application systemd sont disponibles, cela affichera le NQN hôte généré par systemd pour le système.

OPTIONS

-o <fmt>, --output-format=<fmt>

Définit le format de rapport à normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

nvme show-hostnqn
