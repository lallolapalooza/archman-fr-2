NOM

nvme-wdc-vs-fw-activate-history - Exécute la commande propriétaire WDC vs-fw-activate-history NVMe, retourne le résultat

SYNTAXE

nvme wdc vs-fw-activate-history <périphérique> [--output-format=<normal|json> -o <normal|json>]

DESCRIPTION

Pour le périphérique NVMe donné, lit une page de journal propriétaire WDC qui retourne l'historique d'activation du firmware.

Le paramètre <périphérique> est obligatoire et doit être le périphérique caractère NVMe (ex: /dev/nvme0).

Ceci ne fonctionnera que sur les périphériques WDC supportant cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, retourne 0, sinon un code d'erreur.

OPTIONS

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal ou json. Un seul format de sortie peut être utilisé à la fois. Le défaut est normal.

EXPLICATION DES DONNÉES DE LA PAGE DE JOURNAL D'HISTORIQUE D'ACTIVATION DU FIRMWARE

Champ Description
Numéro d'entrée Le numéro d'entrée d'activation du firmware. Les 20 entrées les plus récentes seront affichées.
Heure de mise sous tension Le temps depuis la mise sous tension en heures:minutes:secondes.
Nombre de cycles de mise sous tension Le nombre de cycles de mise sous tension au moment où l'activation du firmware s'est produite.
Firmware actuel Le niveau de firmware actuellement en cours d'exécution sur le SSD avant l'activation.
Nouveau firmware Le nouveau niveau de firmware en cours d'exécution sur le SSD après l'activation.
Numéro d'emplacement L'emplacement à partir duquel le firmware est activé.
Type d'action d'engagement Le type d'action d'engagement associé à l'événement d'activation du firmware.
Résultat Le résultat de l'événement d'activation du firmware. La sortie doit être au format : Réussite ou Échec + code d'erreur.

EXEMPLES

•Demande au programme d'émettre la commande propriétaire WDC vs-fw-activate-history : 
# nvme wdc vs-fw-activate-history /dev/nvme0
