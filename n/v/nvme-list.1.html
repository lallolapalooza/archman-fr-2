NOM

nvme-list - Lister tous les périphériques NVMe reconnus

SYNTAXE

nvme list [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Scanne l'arborescence sysfs pour les périphériques NVM Express et renvoie le nœud /dev pour ces périphériques ainsi que certaines informations pertinentes à leur sujet. L'utilisation des espaces de noms est imprimée par puissances de 1 000 avec des préfixes SI. (par exemple, 1,02 To)

OPTIONS

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente les informations dans la sortie, montrant séparément les sous-systèmes, les contrôleurs et les espaces de noms nvme et comment ils sont liés les uns aux autres.

ENVIRONNEMENT

PCI_IDS_PATH - Chemin complet du fichier pci.ids si nvme ne parvient pas à le trouver dans les emplacements courants.

EXEMPLES

•Demande au programme d'émettre une liste 
# nvme list
Node                  Generic               SN                   Model                                    Namespace  Usage                      Format           FW Rev
--------------------- --------------------- -------------------- ---------------------------------------- ---------- -------------------------- ---------------- --------

# nvme list -v
