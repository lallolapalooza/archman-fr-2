NOM

nvme-sed-discover - Découvrir les fonctionnalités de verrouillage Opal SED

SYNTAXE

nvme sed discover [--verbose | -v] [--udev | -u]  <périphérique>

DESCRIPTION

Interroge le périphérique NVMe donné pour déterminer ses capacités Opal SED.

OPTIONS

-v, --verbose

Affiche des informations étendues sur la découverte des fonctionnalités.

-u, --udev

Affiche les informations de verrouillage dans un format adapté aux règles udev.

EXEMPLES

nvme sed discover /dev/nvme5n1 Fonctionnalités de verrouillage : Verrouillage pris en charge : oui Fonctionnalité de verrouillage activée : oui Verrouillé : non Chiffrement des médias : oui MBR activé : non MBR terminé : non
