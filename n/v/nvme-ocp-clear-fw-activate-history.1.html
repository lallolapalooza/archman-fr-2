NOM

nvme-ocp-clear-fw-activate-history - Effacer le journal de l'historique des mises à jour du firmware OCP

SYNTAXE

nvme ocp clear-fw-activate-history <périphérique> [--no-uuid | -n]

DESCRIPTION

Pour le périphérique NVMe donné, efface le journal de l'historique des mises à jour du firmware OCP.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0) soit le périphérique bloc (ex: /dev/nvme0n1).

Cette commande sans aucune option ajoutée essaiera de détecter automatiquement les paramètres de la commande. Cela fonctionnera avec succès ou échouera correctement pour les périphériques prenant en charge les UUID pour les informations spécifiques au fournisseur (NVMe 1.4 ou ultérieur, OCP 2.0 nécessite NVMe 1.4b). Pour les périphériques ne prenant pas en charge OCP 2.0, la commande échouera avec élégance, à moins que l'option --no-uuid ne soit fournie.

Pour les périphériques OCP 1.0 (avant NVMe 1.4), l'option --no-uuid est requise. Lorsque l'option --no-uuid est fournie, les résultats pour les périphériques avant NVMe 1.4 sans prise en charge OCP sont indéfinis.

En cas de succès, retourne 0, sinon un code d'erreur.

OPTIONS

-n, --no-uuid

Ne pas tenter de détecter automatiquement l'index UUID pour cette commande (requis pour la prise en charge de l'ancien OCP 1.0)

EXEMPLES

•Efface le journal de l'historique d'activation du firmware OCP pour le périphérique : 
# nvme ocp clear-fw-activate-history /dev/nvme0
