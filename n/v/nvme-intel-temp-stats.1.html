NOM

nvme-intel-temp-stats - Envoie une requête de page de journal SMART NVMe, renvoie le résultat et le journal

SYNTAXE

nvme intel temp-stats <périphérique> [--raw-binary | -b]

DESCRIPTION

Récupère la page de journal supplémentaire SMART Intel NVMe depuis le périphérique et fournit la structure renvoyée.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

En cas de succès, la structure de journal SMART renvoyée peut l'être de plusieurs façons selon les indicateurs d'options ; la structure peut être analysée par le programme et affichée dans un format lisible ou le tampon brut peut être affiché sur la sortie standard pour qu'un autre programme l'analyse.

OPTIONS

-b, --raw-binary

Affiche le tampon brut du journal des statistiques de température sur la sortie standard.

EXEMPLES

• Affiche la page de journal des statistiques de température dans un format lisible par l'homme :

# nvme intel temp-stats /dev/nvme0

• Affiche le journal SMART brut dans un fichier :

# nvme intel temp-stats /dev/nvme0 --raw-binary > temp_stats_log.raw

Il est probablement déconseillé de ne pas rediriger la sortie standard lors de l'utilisation de ce mode.
