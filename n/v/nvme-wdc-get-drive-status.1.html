NOM

nvme-wdc-get-drive-status - Envoie la commande NVMe WDC get-drive-status, retourne le résultat

SYNTAXE

nvme wdc get-drive-status <périphérique>

DESCRIPTION

Pour le périphérique NVMe donné, envoie la commande unique WDC get-drive-status et fournit des informations supplémentaires sur l'état du périphérique.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (par exemple : /dev/nvme0).

Cela ne fonctionnera que sur les périphériques WDC prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, retourne 0, sinon un code d'erreur.

EXPLICATION DU SORTIE

Champ Description
Pourcentage de vie utilisé. Le pourcentage de fonction du disque utilisé.
Statut EOL (Fin de Vie) Les 3 états possibles sont : Normal, Lecture Seule, ou Fin de Vie.
Statut Dump Assert Les 2 états possibles sont : Présent ou Non Présent.
Statut de limitation thermique Les 3 états possibles sont : Désactivé, Activé, ou Indisponible.
Raison de corruption du format Les 3 états possibles sont : Non corrompu, Corrompu en raison d'un assert FW, ou Corrompu pour une raison inconnue.

EXEMPLES

•Fait émettre la commande WDC get-drive-status au programme : 
# nvme wdc get-drive-status /dev/nvme0
