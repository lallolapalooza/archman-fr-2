NOM

nvme-solidigm-vs-drive-info - Récupérer les informations du lecteur

SYNTAXE

nvme solidigm vs-drive-info <périphérique> [--output-format=<fmt> | -o <fmt>]

DESCRIPTION

Récupère et affiche les informations spécifiques au vendeur pour le lecteur NVMe Solidigm donné. Cette commande fournit des détails supplémentaires sur le lecteur qui pourraient ne pas être disponibles via les commandes NVMe standard.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (par ex. : /dev/nvme0), soit un périphérique bloc d'espace de noms (par ex. : /dev/nvme0n1).

OPTIONS

-o <fmt>, --output-format=<fmt>

Définit le format de rapport à normal ou json. Un seul format de sortie peut être utilisé à la fois.

EXEMPLES

•Récupérer et afficher les informations du lecteur : 
# nvme solidigm vs-drive-info /dev/nvme0
•Récupérer les informations du lecteur au format JSON : 
# nvme solidigm vs-drive-info /dev/nvme0 -o json
