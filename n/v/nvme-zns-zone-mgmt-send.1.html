NOM

nvme-zns-zone-mgmt-send - Commande de gestion de zone

SYNTAXE

nvme zns zone-mgmt-send <périphérique> [--namespace-id=<NUM> | -n <NUM>]
                        [--start-lba=<NUMÉO> | -s <NUMÉO>] [--zsaso, -o]
                        [--select-all, -a] [--zsa=<NUM>, -z <NUM>]
                        [--data-len=<NUMÉO>, -l <NUMÉO>]
                        [--data=<FICHIER>, -d <FICHIER>]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPTION

Pour le périphérique NVMe donné, exécute la commande Zone Management Send avec l'action d'envoi demandée. Si l'envoi nécessite des données supplémentaires, vous pouvez spécifier la longueur des données. Si des données sont requises, l'entrée proviendra par défaut de stdin. Alternativement, les données peuvent provenir d'un fichier qui peut être spécifié.

OPTIONS

-n <NUM>, --namespace-id=<NUM>

Utilise l'identifiant de l'espace de noms fourni pour la commande. S'il n'est pas fourni, l'identifiant de l'espace de noms du périphérique bloc sera utilisé. Si la commande est émise vers un périphérique qui n'est pas un périphérique bloc, le paramètre est requis.

-s <lba>, --start-lba=<lba>

Le LBA de départ de la zone à gérer pour l'envoi.

-l <NUM>, --data-len=<NUM>

Longueur du tampon de données à envoyer.

-o, --zsaso

Option spécifique à l'action d'envoi de zone.

-a, --select-all

Envoie la commande à toutes les zones.

-z <NUM>, --zsa=<NUM>

Action d'envoi de zone.

-l <NUMÉO>, --data-len=<NUMÉO>

Longueur du tampon si des données sont requises.

-d <FICHIER>, --data=<FICHIER>

Fichier optionnel pour les données (stdin par défaut).

-t <timeout>, --timeout=<timeout>

Remplace la valeur de délai d'attente par défaut. En millisecondes.

EXEMPLES

•Envoie une commande de gestion de zone avec l'action définie sur 1 (fermer la zone) à la première zone de l'espace de noms 1 : 
# nvme zns zone-mgmt-send /dev/nvme0 -n 1 -s 0 -z 1
•Écrit "hello world" dans le descripteur de zone pour la première zone de l'espace de noms 1 (nécessite que le périphérique prenne en charge une donnée étendue de zone suffisamment grande) 
# echo "hello world" | nvme zns zone-mgmt-send /dev/nvme0 -n 1 -s 0 -z 0x10
