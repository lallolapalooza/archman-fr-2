NOM

nvme-fdp-status - Obtenir le statut du handle d'unité de récupération

SYNTAXE

nvme fdp status <périphérique> [--namespace-id=<NUM> | -n <NUM>] [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>]

DESCRIPTION

Pour le périphérique NVMe donné, fournir des informations sur les handles d'unités de récupération accessibles par l'espace de noms spécifié.

OPTIONS

-n <NUM>, --namespace-id=<NUM>

Identifiant de l'espace de noms.

-b, --raw-binary

Imprimer le tampon brut sur le flux de sortie standard.

-o <fmt>, --output-format=<fmt>

Définir le format de rapport sur normal, json, ou binary. Un seul format de sortie peut être utilisé à la fois.
