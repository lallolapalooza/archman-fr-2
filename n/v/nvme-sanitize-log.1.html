NOM

nvme-sanitize-log - Envoyer la commande NVMe sanitize-log, retourner le résultat

SYNTAXE

nvme sanitize-log <périphérique> [--rae | -r] [--human-readable | -H]
                        [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Récupère la page de journalisation NVMe Sanitize d'un périphérique NVMe et fournit le statut de la commande de nettoyage.

Le paramètre <périphérique> est un périphérique caractère NVMe obligatoire (ex: /dev/nvme0).

Statut et description attendus :-

Code d'état Description
0x0000 Le sous-système NVM n'a jamais été nettoyé.
0x0001 L'opération de nettoyage la plus récente s'est terminée avec succès.
0x0002 Une opération de nettoyage est actuellement en cours.
0x0003 L'opération de nettoyage la plus récente a échoué.
0x0100 Bit Global Data Erased. Si mis à 1, le stockage non volatile dans le sous-système NVM n'a pas été écrit : a) depuis sa fabrication et le sous-système NVM n'a jamais été nettoyé ; ou b) depuis la dernière opération de nettoyage réussie. S'il est mis à 0, le stockage non volatile dans le sous-système NVM a été écrit : a) depuis sa fabrication et le sous-système NVM n'a jamais été nettoyé ; ou b) depuis la dernière opération de nettoyage réussie du sous-système NVM.

Progression du nettoyage - pourcentage d'achèvement

En cas de succès, retourne 0, sinon retourne un code d'erreur.

OPTIONS

-r, --rae

Conserver un événement asynchrone.

-H, --human-readable

Cette option analysera et formatera plusieurs champs binaires dans des formats lisibles par l'homme.

-b, --raw-binary

Imprimer le tampon brut sur stdout. La structure n'est pas analysée par le programme. Cela remplace les options spécifiques au fournisseur et lisibles par l'homme.

-o <fmt>, --output-format=<fmt>

Définir le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmenter le niveau de détail des informations dans la sortie.

EXEMPLES

•Faire émettre la commande Sanitize-log par le programme : 
# nvme sanitize-log /dev/nvme0
