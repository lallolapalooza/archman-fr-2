NOM

nvme-device-self-test - Exécute les tests nécessaires pour observer les performances et les paramètres

SYNTAXE

nvme device-self-test <périphérique> [--namespace-id=<NUM> | -n <NUM>]
                        [--self-test-code=<NUM> | -s <NUM>] [--wait | -w]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPTION

Démarre le test requis basé sur l'entrée de l'utilisateur.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de l'espace de noms (ex: /dev/nvme0n1).

En cas de succès, le test correspondant est démarré.

Les résultats de ce test peuvent être interrogés via nvme self-test-log <périphérique>.

OPTIONS

-n <NUM>, --namespace-id=<NUM>

Indique l'espace de noms dans lequel le test d'auto-diagnostic du périphérique doit être effectué.

-s <NUM>, --self-test-code=<NUM>

Ce champ spécifie l'action entreprise par la commande de test d'auto-diagnostic du périphérique : 0h : Afficher l'état actuel de l'opération de test d'auto-diagnostic du périphérique 1h : Démarrer une opération de test d'auto-diagnostic courte du périphérique 2h : Démarrer une opération de test d'auto-diagnostic étendue du périphérique eh : Démarrer une opération de test d'auto-diagnostic spécifique au vendeur fh : Arrêter l'opération de test d'auto-diagnostic du périphérique La valeur par défaut est 0h.

-w, --wait

Attend que le test d'auto-diagnostic du périphérique soit terminé avant de quitter. Le test d'auto-diagnostic du périphérique est interrompu par un signal SIGINT pour l'attente. L'option est ignorée si l'option de code de test d'auto-diagnostic d'arrêt est spécifiée.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le détail des informations dans la sortie.

-t <timeout>, --timeout=<timeout>

Remplace la valeur de délai d'attente par défaut. En millisecondes.

EXEMPLES

•Démarrer un test d'auto-diagnostic court du périphérique dans l'espace de noms 1 : 
# nvme device-self-test /dev/nvme0 -n 1 -s 1
•Arrêter l'opération de test d'auto-diagnostic du périphérique dans l'espace de noms 1 : 
# nvme device-self-test /dev/nvme0 -n 1 -s 0xf
