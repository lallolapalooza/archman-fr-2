NOM

nvme-solidigm-clear-fw-activate-history - Efface l'historique des mises à jour du firmware

SYNTAXE

nvme solidigm clear-fw-activate-history <périphérique> [--no-uuid | -n]

DESCRIPTION

Cette commande est une redirection vers la commande du plugin OCP qui efface l'historique des mises à jour du firmware. Pour une utilisation détaillée et les options, veuillez vous référer à la documentation de nvme ocp clear-fw-activate-history.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0) soit le périphérique bloc (ex: /dev/nvme0n1).

OPTIONS

-n, --no-uuid

N'essaie pas de détecter automatiquement l'index UUID pour cette commande (requis pour la prise en charge de l'ancien OCP 1.0)

EXEMPLES

•Effacer l'historique des mises à jour du firmware pour le périphérique : 
# nvme solidigm clear-fw-activate-history /dev/nvme0
•Effacer l'historique des mises à jour du firmware pour un périphérique OCP 1.0 : 
# nvme solidigm clear-fw-activate-history /dev/nvme0 --no-uuid
