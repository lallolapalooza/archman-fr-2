NOM

nvme-sndk-get-error-recovery-log - Envoie la commande du plugin NVMe sndk get-error-recovery-log, retourne le log analysé.

SYNTAXE

nvme sndk get-error-recovery-log <périphérique> [--output-format=<normal|json>
-o <normal|json>]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande de plugin sndk get-error-recovery-log et affiche les données du journal de récupération d'erreurs. L'option --output-format formatera la sortie comme spécifié.

Le paramètre <périphérique> est obligatoire et peut être le périphérique caractère NVMe (ex: /dev/nvme0).

Ceci ne fonctionnera que sur les périphériques Sandisk supportant cette page de log. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, retourne les données analysées de la page de log de récupération d'erreurs, sinon retourne un code d'erreur.

OPTIONS

-o <fmt>, --output-format=<fmt>

Définit le format de rapport à normal ou json. Un seul format de sortie peut être utilisé à la fois. Le défaut est normal.

EXEMPLES

•Fait en sorte que le programme émette la commande du plugin sndk get-error-recovery-log : 
# nvme sndk get-error-recovery-log /dev/nvme0
