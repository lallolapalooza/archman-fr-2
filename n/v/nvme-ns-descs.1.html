NOM

nvme-ns-descs - Envoyer une commande NVMe Identify pour une liste de structures de descripteurs d'identification d'espace de noms, retourner le résultat et la structure

SYNTAXE

nvme ns-descs <périphérique> [--namespace-id=<nsid> | -n <nsid>] [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande Identify pour une liste de structures de descripteurs d'identification d'espace de noms et fournit le résultat et la structure retournée.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc d'espace de noms (ex: /dev/nvme0n1). Si le périphérique caractère est donné, l'option '--namespace-id' est obligatoire, sinon il utilisera l'identifiant d'espace de noms du périphérique bloc que vous avez ouvert. Pour les périphériques bloc, l'identifiant d'espace de noms utilisé peut être remplacé avec la même option.

En cas de succès, la structure peut être retournée de plusieurs manières selon les indicateurs d'option ; la structure peut être analysée par le programme ou le tampon brut peut être affiché sur la sortie standard.

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Récupère la structure d'identification de l'espace de noms pour l'identifiant d'espace de noms donné. Ceci est requis pour les périphériques caractère, ou remplace l'identifiant d'espace de noms du périphérique bloc s'il est donné.

-b, --raw-binary

Affiche le tampon brut sur la sortie standard. La structure n'est pas analysée par le programme.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le détail des informations dans la sortie.

EXEMPLES

•Si vous utilisez le périphérique caractère ou si vous remplacez l'espace de noms #2: 
# nvme ns-descs /dev/nvme0 -n 1
# nvme ns-descs /dev/nvme0n1 -n 2
# nvme ns-descs /dev/nvme0 --namespace-id=1
•Faire en sorte que le programme retourne la structure brute en binaire: 
# nvme ns-descs /dev/nvme0n1 --raw-binary > ns_descs.raw
# nvme ns-descs /dev/nvme0n1 -b > ns_descs.raw

Il est probablement déconseillé de ne pas rediriger la sortie standard en utilisant ce mode.
