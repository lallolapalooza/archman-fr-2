NOM

nvme-ns-rescan - Ré-analyse les espaces de noms nvme.

SYNTAXE

nvme ns-rescan <device> [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Demande au contrôleur NVMe de ré-analyser les espaces de noms. Le paramètre <device> est obligatoire et doit être un périphérique caractère NVMe (ex: /dev/nvme0).

OPTIONS

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

•Ré-analyse les espaces de noms nvme. 
# nvme ns-rescan /dev/nvme0
