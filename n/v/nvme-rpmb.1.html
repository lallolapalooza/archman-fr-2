NOM

nvme-rpmb - Envoie des commandes RPMB à un périphérique NVMe

SYNTAXE

nvme rpmb <périphérique> [--cmd=<commande> | -c <commande>]
                        [--msgfile=<fichier-données> | -f <fichier-données>]
                        [--keyfile=<fichier-clé> | -g <fichier-clé>]
                        [--key=<clé> | -k <clé>] [--msg=<données> | -d <données>]
                        [--address=<décalage> | -o <décalage>]
                        [--blocks=<secteurs de 512 octets> | -b <secteurs>]
                        [--target=<id-cible> | -t <id>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande nvme rpmb et fournit les résultats.

Le paramètre <périphérique> est obligatoire et le périphérique caractère NVMe (ex: /dev/nvme0) doit être spécifié. Si le périphérique donné prend en charge les cibles RPMB, la commande fournie avec l'option --cmd ou -c sera envoyée au contrôleur. Si le périphérique NVMe donné ne prend pas en charge les cibles RPMB, un message indiquant cela sera imprimé avec les valeurs des registres du contrôleur relatives à RPMB.

OPTIONS

-c <commande>, --cmd=<commande>

Commande RPMB à envoyer au périphérique. Il peut s'agir de l'une des suivantes : 
info          - affiche des informations sur les cibles RPMB prises en charge,
                l'accès et les tailles totales. Aucun argument supplémentaire n'est
                requis
program-key   - programme la 'clé' spécifiée avec l'option -k ou la clé lue depuis
                le fichier spécifié avec l'option --keyfile sur la cible RPMB
                spécifiée avec les options --target ou -t. Conformément à la
                spécification, il s'agit d'une action unique qui ne peut être annulée.
read-counter  - Lit le 'compteur d'écritures' de la cible RPMB spécifiée. La
                valeur du compteur lue est imprimée sur STDOUT
read-config   - Lit 512 octets du bloc de données de configuration du périphérique
                de la cible RPMB spécifiée du périphérique NVMe. Les données lues
                sont écrites dans le fichier d'entrée spécifié avec l'option --msgfile
                ou -f.
write-config  - Écrit 512 octets de données du bloc de configuration du
                périphérique à partir du fichier spécifié par les options --msgfile
                ou -f sur la cible RPMB spécifiée avec les options --target ou -t.
read-data     - Prend en charge la lecture de données authentifiées à partir de la
                cible RPMB spécifiée (option --target ou -t) à l'adresse spécifiée
                avec l'option --address ou -o, en utilisant la clé spécifiée via
                les options --keyfile ou -k. Les options --blocks ou -o doivent
                être fournies pour lire la quantité de données à lire en blocs de
                512 octets.
write-data    - Prend en charge l'écriture de données authentifiées sur la cible
                RPMB spécifiée (option --target ou -t) à l'adresse spécifiée avec
                l'option --address ou -o, en utilisant la clé spécifiée via les
                options --keyfile ou -k. Les options --blocks ou -o doivent être
                fournies pour indiquer la quantité de données à écrire en blocs de
                512 octets.
Pour les commandes de transfert de données (lecture/écriture), si la taille
spécifiée n'est pas dans la taille totale prise en charge par une cible, la
requête échoue. nvme-rpmb sans l'envoyer au périphérique. La cible RPMB 0 est
utilisée par défaut si --target ou -t n'est pas spécifié. 0x0 est utilisé comme
décalage par défaut si aucune option -address ou -o n'est spécifiée.

-t <cible>, --target=<cible>

ID de la cible RPMB. Il doit s'agir de l'une des cibles RPMB supportées signalées par la commande info. Si rien n'est spécifié, la valeur par défaut 0 est utilisée comme cible RPMB.

-k <clé>, --key=<clé>, -g <fichier-clé>, --keyfile=<fichier-clé>

Clé d'authentification à utiliser pour les commandes de lecture/écriture. Elle doit avoir été préalablement programmée par la commande program-key pour la cible donnée. La clé peut être spécifiée en ligne de commande via les options --key ou -k. La clé peut également être spécifiée via le fichier fourni avec les options --keyfile ou -g.

-f <fichier-données>, --msgfile=<fichier-données>

Nom du fichier à utiliser pour les commandes de transfert de données (lecture ou écriture). Pour une commande de lecture, si un fichier existant est spécifié, il sera ajouté.

-d <données>, --msg=<données>

Ces options fournissent les données directement sur la ligne de commande.

-o <décalage>, --address=<décalage>

L'adresse (en décalage de secteur de 512 octets à partir de 0) à utiliser pour les commandes de transfert de données (lecture ou écriture) pour une cible RPMB spécifiée.

-b, --blocks=<secteurs>

La taille en secteurs de 512 octets à utiliser pour les commandes de transfert de données (lecture ou écriture) pour une cible RPMB spécifiée.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

•Affiche les informations de support RPMB d'un périphérique NVMe : 
# nvme rpmb /dev/nvme0 --cmd=info
•Programme SecretKey comme clé d'authentification pour la cible 1 : 
# nvme rpmb /dev/nvme0 --cmd=program-key -key='SecretKey' --target=1
•Lit le compteur d'écritures actuel de la cible RPMB 0 : 
# nvme rpmb /dev/nvme0 --cmd=read-counter --target=0
•Lit le bloc de données de configuration de la cible 2 dans le fichier config.bin : 
# nvme rpmb /dev/nvme0 --cmd=read-config --target=2 -f config.bin
•Écrit 200 blocs (de 512 octets) du fichier input.bin sur la cible 0 : 
# nvme rpmb /dev/nvme0 -c write-data -t 0 -f input.bin -b 200 -k 'SecretKey'
•Lit 200 blocs (de 512 octets) de la cible 2, à partir du décalage 0x100 et enregistre les données dans out.bin : 
# nvme rpmb /dev/nvme0 -c read-data -t 2 -f out.bin -b 200 -o 0x100
