NOM

nvme-attach-ns - Envoie la commande NVMe attach namespace, retourne le résultat.

SYNTAXE

nvme attach-ns <périphérique> [--namespace-id=<nsid> | -n <nsid>]
                        [--controllers=<liste-contrôleurs,> | -c <liste-contrôleurs,>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Pour le périphérique NVMe donné, envoie la commande nvme namespace attach pour l'identifiant de namespace fourni, en s'attachant à la liste des identifiants de contrôleurs fournis.

Le paramètre <périphérique> est un périphérique caractère NVMe obligatoire (ex : /dev/nvme0) mais pas un périphérique bloc de namespace (ex : /dev/nvme0n1).

OPTIONS

-n <nsid>, --namespace-id=<nsid>

L'identifiant de namespace à attacher mais non déjà attaché.

-c <liste-contrôleurs,>, --controllers=<liste-contrôleurs,>

La liste des identifiants de contrôleurs, séparés par des virgules, auxquels attacher le namespace. Si aucune liste n'est fournie, le namespace sera attaché au contrôleur <périphérique> utilisé pour cette commande.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

Attacher le namespace 2 aux contrôleurs avec les id 0x21 et 0x22 :
# nvme attach-ns /dev/nvme1 -n 0x2 -c 0x21,0x22
Attacher le namespace 3 à nvme0 :
# nvme attach-ns /dev/nvme0 -n 3
