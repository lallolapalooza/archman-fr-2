NOM

nvme-boot-part-log - Récupère une page de journalisation de partition de démarrage d'un périphérique NVMe

SYNTAXE

nvme boot-part-log <périphérique> [--lsp=<champ> | -s <champ>]
                        [--output-file=<fichier> | -f <fichier>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Récupère une page de journalisation de partition de démarrage d'un périphérique NVMe et fournit la structure retournée.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc d'espace de noms (ex: /dev/nvme0n1).

En cas de succès, la structure de journalisation retournée sera au format binaire brut *uniquement* avec l'option --output-file qui est obligatoire.

OPTIONS

-s <champ>, --lsp=<champ>

Le champ spécifié du LID du journal.

-f <fichier>, --output-file=<fichier>

Nom du fichier dans lequel les données binaires brutes seront enregistrées.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binaire. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

•Récupérer les données de la partition de démarrage dans boot_part_log.bin 
# nvme boot-part-log /dev/nvme0 --output-file=boot_part_log.bin
