NOM

nvme-fdp-set-events - Activer ou désactiver les événements FDP

SYNTAXE

nvme fdp set-events <périphérique> [--namespace-id=<NUM> | -n <NUM>]
                        [--placement-handle=<NUM> | -p <NUM>] [--enable | -e]
                        [--event-types=<NUM,> | -t <NUM,>]

DESCRIPTION

Pour le périphérique NVMe spécifié, active ou désactive une liste de types d'événements pour être générée pour l'Unité de Récupération Référencée par le Handle de Placement spécifié.

OPTIONS

-n <NUM>, --namespace-id=<NUM>

Identifiant de l'espace de noms.

-b, --raw-binary

Imprimer le tampon brut sur le flux de sortie standard.

-o <fmt>, --output-format=<fmt>

Définir le format de rapport à normal, json, ou binary. Un seul format de sortie peut être utilisé à la fois.
