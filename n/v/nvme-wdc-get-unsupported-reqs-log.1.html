NOM

nvme-wdc-get-unsupported-reqs-log - Envoie la commande du plugin WDC NVMe get-unsupported-reqs-log, retourne la sortie analysée du journal

SYNTAXE

nvme wdc get-unsupported-reqs-log <périphérique> [--output-format=<normal|json>
-o <normal|json>]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande de journal get-unsupported-reqs-log du plugin WDC et affiche les données du journal des exigences non prises en charge. L'option --output-format formate la sortie comme spécifié.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex : /dev/nvme0).

Ceci ne fonctionnera que sur les périphériques WDC prenant en charge cette page de journal. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, il retourne les données analysées de la page de journal des exigences non prises en charge, sinon un code d'erreur.

OPTIONS

-o <fmt>, --output-format=<fmt>

Définit le format de rapport à normal ou json. Un seul format de sortie peut être utilisé à la fois. La valeur par défaut est normal.

EXEMPLES

•Fait émettre au programme la commande du plugin WDC get-unsupported-reqs-log : 
# nvme wdc get-unsupported-reqs-log /dev/nvme0
