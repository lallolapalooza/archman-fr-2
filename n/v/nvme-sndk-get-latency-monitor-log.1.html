NOM

nvme-sndk-get-latency-monitor-log - Affiche les données de la page du journal du moniteur de latence dans un format lisible par l'homme

SYNOPSIS

nvme sndk get-latency-monitor-log <périphérique> [--output-format=<normal|json> -o <normal|json>]

DESCRIPTION

Pour le périphérique NVMe donné, les données de la page du journal du moniteur de latence.

Le paramètre <périphérique> est un périphérique caractère NVMe obligatoire (par exemple : /dev/nvme0).

Cela ne fonctionnera qu'avec les périphériques Sandisk prenant en charge cette page de journal. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, retourne 0, sinon un code d'erreur.

OPTIONS

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal ou json. Un seul format de sortie peut être utilisé à la fois. La valeur par défaut est normal.

EXEMPLES

• Affiche le journal du moniteur de latence du périphérique : 
# nvme sndk get-latency-monitor-log /dev/nvme0
