NOM

nvme-ocp-clear-pcie-correctable-error-counters - Effacer les compteurs d'erreurs corrigeables PCIe

SYNOPSIS

nvme ocp clear-pcie-correctable-error-counters <périphérique> [--no-uuid | -n]

DESCRIPTION

Pour le périphérique NVMe donné, efface les compteurs d'erreurs corrigeables PCIe.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0) soit le périphérique bloc (ex: /dev/nvme0n1).

Cette commande sans option ajoutée, tentera de détecter automatiquement les paramètres de la commande. Cela fonctionnera avec succès ou échouera gracieusement pour les périphériques supportant l'UUID pour les informations spécifiques au fournisseur (NVMe 1.4 ou plus récent, OCP 2.0 nécessite NVMe 1.4b). Pour les périphériques qui ne supportent pas OCP 2.0 la commande échouera gracieusement, sauf si l'option --no-uuid est fournie.

Pour les périphériques OCP 1.0 (avant NVMe 1.4) l'option --no-uuid est requise. Lorsque l'option --no-uuid est fournie, les résultats pour les périphériques avant NVMe 1.4 sans support OCP sont indéfinis.

En cas de succès, retourne 0, un code d'erreur sinon.

OPTIONS

-n, --no-uuid

N'essayez pas de détecter automatiquement l'index UUID pour cette commande (requis pour l'ancien support OCP 1.0)

EXEMPLES

• Efface le journal des compteurs d'erreurs corrigeables PCIe pour le périphérique : 
# nvme ocp clear-pcie-correctable-error-counters /dev/nvme0
