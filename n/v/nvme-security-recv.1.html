NOM

nvme-security-recv - Commande Security Recv

SYNTAXE

nvme security-recv <périphérique> [--size=<taille> | -x <taille>]
                        [--secp=<protocole-sécurité> | -p <protocole-sécurité>]
                        [--spsp=<protocole-spécifique> | -s <protocole-spécifique>]
                        [--nssf=<nvme-spécifique> | -N <nvme-spécifique>]
                        [--al=<longueur-allocation> | -t <longueur-allocation>]
                        [--namespace-id=<nsid> | -n <nsid>] [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<délai>]

DESCRIPTION

La commande Security Receive transfère l'état et le résultat des données d'une ou plusieurs commandes Security Send précédemment soumises au contrôleur.

L'association entre une commande Security Receive et les commandes Security Send précédentes dépend du protocole de sécurité. Le format des données à transférer dépend du protocole de sécurité. Se référer à SPC-4 pour les détails du protocole de sécurité.

Chaque commande Security Receive renvoie les données appropriées correspondant à une commande Security Send, telles que définies par les règles du protocole de sécurité. Les données de la commande Security Receive peuvent ne pas être conservées en cas de perte de communication entre le contrôleur et l'hôte, ou en cas de réinitialisation du contrôleur.

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Cible un espace de noms spécifique pour cette commande de sécurité.

-N <nssf>, --nssf=<nssf>

Champ NVMe Security Specific. Si vous utilisez le protocole de sécurité EAh assigné pour l'utilisation NVMe, le champ NVMe security specific indique quelle mémoire tampon de réponse est ciblée.

-x <taille>, --size=<taille>

Taille du tampon à allouer. En cas de succès, elle sera affichée sur STDOUT.

-p <protocole-sécurité>, --secp=<protocole-sécurité>

Protocole de sécurité : Ce champ spécifie le protocole de sécurité tel que défini dans SPC-4. Le contrôleur échouera la commande avec un paramètre invalide indiqué si une valeur réservée du protocole de sécurité est spécifiée.

-s <protocole-spécifique-sécurité>, --spsp=<protocole-spécifique-sécurité>

SP Specific : La valeur de ce champ est spécifique au protocole de sécurité tel que défini dans SPC-4.

-t <longueur-allocation>, --al=<longueur-allocation>

Longueur d'allocation : La valeur de ce champ est spécifique au protocole de sécurité tel que défini dans SPC-4.

-b, --raw-binary

Affiche le tampon brut sur stdout. Par défaut, affiche en hexadécimal.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport à normal, json ou binaire. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

--timeout=<délai>

Remplace la valeur de délai par défaut. En millisecondes.
