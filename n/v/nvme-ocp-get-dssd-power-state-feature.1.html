NOM

nvme-ocp-get-dssd-power-state-feature - Obtenir l'état d'alimentation DSSD

SYNTAXE

nvme ocp get-dssd-power-state-feature <périphérique>
                        [--sel=<sélection> | -S <sélection>] [--all | -a]
                        [--no-uuid | -n]

DESCRIPTION

Pour le périphérique NVMe donné, récupère l'état d'alimentation DSSD OCP. Passer --all appelle NVMe Get Feature trois fois, renvoyant les trois valeurs actuelles, par défaut et sauvegardées.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0) soit le périphérique bloc (ex: /dev/nvme0n1).

Ceci ne fonctionnera que sur les périphériques conformes OCP prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, renvoie 0, sinon un code d'erreur.

OPTIONS

-S <sélection>, --sel=<sélection>

Sélection (SEL) : Ce champ spécifie quelle valeur des attributs renvoyer dans les données fournies :
Sélection Description
0 Courant
1 Par défaut
2 Sauvegardé
3 Capacités supportées
4-7 Réservé

-a, --all

Affiche les 3 valeurs en même temps - État d'alimentation DSSD Courant, État d'alimentation DSSD par défaut, et État d'alimentation DSSD Sauvegardé

-n, --no-uuid

N'essaie pas de détecter automatiquement l'index UUID pour cette commande (requis pour la prise en charge de l'ancien OCP 1.0)

EXEMPLES

•Demande au programme d'émettre une commande get-dssd-power-state-feature pour obtenir l'état d'alimentation DSSD Courant en watts. 
# nvme ocp get-dssd-power-state-feature /dev/nvme0 -S 0
•Demande au programme d'émettre une commande get-dssd-power-state-feature pour obtenir les trois états d'alimentation DSSD en watts. 
# nvme ocp get-dssd-power-state-feature /dev/nvme0 -a
