NOM

nvme-virtium-save-smart-to-vtview-log - Sauvegarde périodiquement les attributs SMART dans un fichier journal (format csv).

SYNOPIS

nvme virtium save-smart-to-vtview-log <périphérique> [--run-time=<NUM> | -r <NUM>]
                        [--freq=<NUM> | -f <NUM>]
                        [--output-file=<FICHIER> | -o <FICHIER>]
                        [--test-name=<NOM> | -n <NOM>]

DESCRIPTION

Cette commande automatise le processus de collecte périodique des données SMART et de sauvegarde des données dans un format prêt à être analysé. Chaque entrée est sauvegardée avec un horodatage et au format csv. Les utilisateurs peuvent utiliser Excel pour analyser les données. Quelques exemples d'utilisation incluent la collecte de données SMART pour la caractérisation de la température, des données pour calculer l'endurance, ou la collecte de données SMART pendant un test ou pendant le fonctionnement normal.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

En cas de succès, la commande génère un fichier journal, qui contient une entrée pour l'identification du périphérique (fonctionnalités et paramètres actuels) et des entrées périodiques de données SMART.

Cette commande s'exécute pendant la durée spécifiée par l'option <run-time>, et collecte les données SMART à la fréquence spécifiée par l'option <freq>. Si le nom du fichier de sortie n'est pas spécifié, cette commande générera un nom de fichier incluant la chaîne du modèle et le numéro de série du périphérique.

Si l'option test-name est spécifiée, elle sera enregistrée dans le fichier journal et utilisée dans le nom du fichier journal.

OPTIONS

-r <NUM>, --run-time=<NUM>

(optionnel) Nombre d'heures pour enregistrer les données (par défaut = 20 heures)

-f <NUM>, --freq=<NUM>

(optionnel) Fréquence d'enregistrement des données SMART (0.25 = 15 min, 0.5 = 30 min, 1 = 1 heure, 2 = 2 heures, etc.). Par défaut = 10 heures.

-o <FICHIER>, --output-file=<FICHIER>

(optionnel) Nom du fichier journal (donnez-lui un nom facile à retenir pour savoir de quel test il s'agit). Vous pouvez également le laisser vide, le nom du fichier sera généré comme <chaîne du modèle>-<numéro de série>-<nom du test>.txt.

-n <NOM>, --test-name=<NOM>

(optionnel) Nom du test effectué. Nous utilisons cette chaîne comme partie du nom du fichier journal.

EXEMPLES

• Caractérisation de la température : 
# nvme virtium save-smart-to-vtview-log /dev/votrePériphérique --run-time=100 --record-frequency=0.25 --test-name=burn-in-à-(-40)
• Test d'endurance : 
# nvme virtium save-smart-to-vtview-log /dev/votrePériphérique --run-time=100 --record-frequency=1 --test-name=test-endurance-charge-de-travail-JEDEG-219
• Enregistrement simple : L'enregistrement par défaut dure 20 heures et enregistre toutes les 10 heures. 
# nvme virtium save-smart-to-vtview-log /dev/votrePériphérique
