NOM

nvme-ocp-eol-plp-failure-mode - Définir et afficher le mode de défaillance du circuit EOL ou PLP

SYNTAXE

nvme ocp eol-plp-failure-mode <périphérique> [--mode=<mode> | -m <mode>]
                        [--no-uuid | -n] [--save | -s]
                        [--sel=<sélection> | -S <sélection>]

DESCRIPTION

Définit le mode de défaillance du circuit EOL ou PLP. Aucune argument n'affiche le mode actuel.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex : /dev/nvme0) soit le périphérique bloc (ex : /dev/nvme0n1).

Ceci ne fonctionnera que sur les périphériques compatibles OCP prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, retourne 0, sinon retourne un code d'erreur.

OPTIONS

-m <mode>, --mode=<mode>

Définit le mode de défaillance du circuit EOL ou PLP à [0-3] (0 : par défaut, 1 : rom, 2 : wtm ou 3 : normal). Un seul mode peut être utilisé à la fois. La valeur par défaut est rom.

-n, --no-uuid

N'essaie pas de détecter automatiquement l'index UUID pour cette commande (requis pour la prise en charge de l'ancienne version 1.0 d'OCP)

-s, --save

Sauvegarde l'attribut afin qu'il persiste lors de tous les états d'alimentation et réinitialisations.

-s <sélection>, --sel=<sélection>

Sélectionner (SEL) : Ce champ spécifie quelle valeur des attributs renvoyer dans les données fournies :
Sélection Description
0 Actuel
1 Par défaut
2 Sauvegardé
3 Capacités supportées
4-7 Réservé

EXEMPLES

• Fait émettre au programme une commande eol-plp-failure-mode pour récupérer les fonctionnalités 0xC2. 
# nvme ocp eol-plp-failure-mode /dev/nvme0
