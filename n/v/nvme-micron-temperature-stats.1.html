NOM

nvme-micron-temperature-stats - Récupère les informations de température du périphérique micron donné

SYNOPIS

nvme micron vs-temperature-stats <périphérique>

DESCRIPTION

Cette commande affiche les informations de température (température composite et nombre de capteurs de température actifs) pour le périphérique micron donné.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex : /dev/nvme0), soit un périphérique bloc d'espace de noms (ex : /dev/nvme0n1).

Ceci ne fonctionnera que sur les périphériques Micron des modèles 54XX. Le support de nouveaux périphériques peut être ajouté ultérieurement.

OPTIONS

Aucune

EXEMPLES

•Récupérer les informations de température 
# nvme micron vs-temperature-stats /dev/nvme0
