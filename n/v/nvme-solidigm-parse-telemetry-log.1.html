NOM

nvme-solidigm-parse-telemetry-log - Analyse et affiche le journal de télémétrie Solidigm

SYNTAXE

nvme solidigm parse-telemetry-log <périphérique> [OPTIONS]

DESCRIPTION

Récupère, analyse et affiche le journal de télémétrie pour le périphérique NVMe Solidigm donné. Cette commande fournit des informations détaillées sur les données de télémétrie du périphérique, ce qui peut être utile pour le diagnostic et l'analyse des performances.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de l'espace de noms (ex: /dev/nvme0n1).

OPTIONS

-g <num>, --host-generate=<num>

Contrôle le moment de la génération d'un nouveau rapport initié par l'hôte. La valeur par défaut 1 génère un nouveau rapport initié par l'hôte, la valeur 0 entraîne la récupération d'un journal existant. Les valeurs valides sont 0 et 1.

-c, --controller-init

Collecte le rapport généré par le contrôleur.

-d <num>, --data-area=<num>

Choisit la zone de données de télémétrie à rapporter. La valeur par défaut est 1, ou 3 si un fichier de configuration est spécifié. Les options valides sont 1, 2, 3, 4.

-j <fichier>, --config-file=<fichier>

Spécifie un fichier de configuration JSON pour l'analyse personnalisée du journal de télémétrie.

-s <fichier>, --source-file=<fichier>

Spécifie un fichier binaire contenant une sauvegarde du journal de télémétrie à analyser au lieu de récupérer le journal à partir d'un périphérique. Lorsque cette option est utilisée, aucun argument de périphérique ne doit être fourni.

EXEMPLES

•Récupérer et analyser le journal de télémétrie avec les options par défaut : 
# nvme solidigm parse-telemetry-log /dev/nvme0
•Récupérer un journal de télémétrie existant sans en générer un nouveau : 
# nvme solidigm parse-telemetry-log /dev/nvme0 -g 0
•Analyser une zone de données spécifique du journal de télémétrie : 
# nvme solidigm parse-telemetry-log /dev/nvme0 -d 2
•Utiliser un fichier de configuration personnalisé pour l'analyse : 
# nvme solidigm parse-telemetry-log /dev/nvme0 -j config.json
•Analyser un journal de télémétrie à partir d'un fichier binaire : 
# nvme solidigm parse-telemetry-log -s telemetry_dump.bin

SORTIE

La commande affiche le journal de télémétrie analysé au format JSON sur la sortie standard.
