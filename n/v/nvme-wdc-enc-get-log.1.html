NOM

nvme-wdc-enc-get-log - Envoie une commande de vendeur unique NVMe wdc enc-get-log, retourne le résultat.

SYNTAXE

nvme wdc enc-get-log <périphérique> [--log-id=<NOMBRE>, -l <NOMBRE>]
                        [--output-file=<FICHIER>, -o <FICHIER>]
                        [--transfer-size=<TAILLE>, -s <TAILLE>]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande de vendeur unique WDC enc-get-log et affiche les journaux de l'enceinte.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex : /dev/nvme0).

Le paramètre --log-id=<NOMBRE>, -l <NOMBRE> est obligatoire et peut être 0xd1, 0xd2, 0xd3, 0xd4, 0xe2 et 0xe4.

Cela ne fonctionnera que sur les périphériques WDC prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, il retourne les données du journal de l'enceinte, sinon un code d'erreur.

OPTIONS

-o <FICHIER>, --output-file=<FICHIER>

Chemin du fichier de sortie

-s <TAILLE>, --transfer-size=<NOMBRE>

Taille de transfert de récupération des données, la taille de transfert maximale doit être de 0x2000 (décimal 8192)

EXEMPLES

•Récupère le journal de l'enceinte depuis le périphérique en se basant sur l'identifiant du journal (0xd1) avec une taille de transfert (0x2000) et sauvegarde dans un fichier défini dans le répertoire courant : 
# nvme wdc enc-get-log /dev/nvme0 -l 0xd1 -o d1_log.bin -s 0x2000
•Récupère le journal de l'enceinte depuis le périphérique en se basant sur l'identifiant du journal (0xd2) avec une taille de transfert par défaut (0x1000) et sauvegarde dans un fichier défini dans le répertoire courant : 
# nvme wdc enc-get-log /dev/nvme0 -l 0xd2 -o d1_log.bin
