NOM

nvme-id-iocs - Envoie la commande NVMe Identify I/O Command Set, retourne le résultat et la structure

SYNTAXE

nvme id-iocs <périphérique> [--controller-id=<cntid> | -c <cntid>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande d'identification et retourne la structure de données du jeu de commandes d'E/S d'identification.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

OPTIONS

-c <cntid>, --controller-id=<cntid>

Récupère la structure de données du jeu de commandes d'E/S d'identification pour le cntid donné. Si cette valeur n'est pas fournie, cntid sera 0xffff.

-H, --human-readable

Cette option analysera et formatera plusieurs champs binaires dans un format lisible par l'homme.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

•Demander au programme d'interpréter le tampon renvoyé et d'afficher les champs connus dans un format lisible par l'homme : 
# nvme id-iocs /dev/nvme0
•Afficher les champs dans un format lisible par l'homme 
# nvme id-iocs /dev/nvme0 -H
