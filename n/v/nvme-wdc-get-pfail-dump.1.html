NOM

nvme-wdc-get-pfail-dump - Récupérer la vidage de crash pfail du périphérique WDC.

SYNTAXE

nvme wdc get-pfail-dump <périphérique> [--output-file=<FICHIER>, -o <FICHIER>]

DESCRIPTION

Pour le périphérique NVMe donné, envoie la requête de vidage de crash pfail unique du fournisseur WDC et enregistre le résultat dans un fichier. Dans l'implémentation actuelle, le vidage de crash pfail est capturé s'il est présent. En cas de succès, il enregistrera le vidage dans un fichier avec le suffixe approprié. Notez que cette commande effacera le vidage disponible du périphérique en cas de succès.

Le paramètre <périphérique> est un périphérique caractère NVMe obligatoire (ex : /dev/nvme0).

Cela ne fonctionnera que sur les périphériques WDC prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique ne sont pas définis.

OPTIONS

-o <FICHIER>, --output-file=<FICHIER>

Fichier de sortie ; par défaut, le numéro de série du périphérique suivi du suffixe « pfail_dump »

EXEMPLES

•Récupère le vidage de crash pfail du périphérique et l'enregistre dans le fichier par défaut dans le répertoire courant (ex: STM00019F3F9_pfail_dump.bin) : 
# nvme wdc get-pfail-dump /dev/nvme0
•Récupère le vidage de crash pfail du périphérique et l'enregistre dans le fichier défini dans le répertoire courant (ex: testSTM00019F3F9_pfail_dump.bin) : 
# nvme wdc get-pfail-dump /dev/nvme0 -o test
•Récupère le vidage de crash pfail du périphérique et l'enregistre dans le fichier défini avec le chemin (ex: /tmp/testSTM00019F3F9_pfail_dump.bin) : 
# nvme wdc get-pfail-dump /dev/nvme0 -o /tmp/test
