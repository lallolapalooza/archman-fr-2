NOM

nvme-copy - Envoyer une commande NVMe Simple Copy, fournir les résultats

SYNTAXE

nvme-copy <périphérique> [--sdlba=<sdlba> | -d <sdlba>]
                        [--blocks=<nlb-liste,> | -b <nlb-liste,>]
                        [--slbs=<slbas,> | -s <slbas,>]
                        [--snsids=<snsids,> | -N <snsids,>]
                        [--sopts=<sopts,> | -O <sopts,>]
                        [--limited-retry | -l]
                        [--force-unit-access | -f]
                        [--prinfow=<prinfow> | -p <prinfow>]
                        [--prinfor=<prinfor> | -P <prinfor>]
                        [--ref-tag=<reftag> | -r <reftag>]
                        [--expected-ref-tags=<reftag,> | -R <reftag,>]
                        [--app-tag=<apptag> | -a <apptag>]
                        [--expected-app-tags=<apptag,> | -A <apptag,>]
                        [--app-mask=<appmask> | -m <appmask>]
                        [--expected-app-masks=<appmask,> | -M <appmask,>]
                        [--dir-type=<type> | -T <type>]
                        [--dir-spec=<spec> | -S <spec>]
                        [--format=<format-entrée> | -F <format-entrée>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPTION

La commande Copy est utilisée par l'hôte pour copier des données à partir d'une ou plusieurs plages de blocs logiques sources vers une seule plage de blocs logiques consécutive.

OPTIONS

-d <sdlba>, --sdlba=<sdlba>

Adresse 64 bits du premier bloc logique de destination

-b <nlb-liste,>, --blocks=<nlb-liste,>

Liste séparée par des virgules du nombre de blocs dans chaque plage

-s <slbas,>, --slbs=<slbas,>

Liste séparée par des virgules des blocs de départ dans chaque plage

--snsids=<snsids,>, -N <snsids,>

Liste séparée par des virgules des identifiants d'espace de noms sources dans chaque plage

--sopts=<sopts,>, -O <sopts,>

Liste séparée par des virgules des options sources dans chaque plage

-l, --limited-retry

Définit le drapeau de tentative limitée.

-f, --force-unit-access

Définit le drapeau de forçage de l'accès à l'unité.

-p <prinfow>, --prinfow=<prinfow>

Définition d'écriture du champ Information de Protection.

-P <prinfor>, --prinfor=<prinfor>

Définition de lecture du champ Information de Protection.

-r <reftag>, --ref-tag=<reftag>

Tag de référence LBA initial.

-R <reftag,>, --expected-ref-tags=<reftag,>

Tags de référence LBA attendus (liste séparée par des virgules).

-a <apptag>, --app-tag=<apptag>

Tag applicatif LBA.

-A <apptag,>, --expected-app-tags=<apptag,>

Tags applicatifs LBA attendus (liste séparée par des virgules).

-m <appmask>, --app-mask=<appmask>

Masque de tag LBA.

-M <appmask,>, --expected-app-masks=<appmask,>

Masques de tag LBA attendus (liste séparée par des virgules).

-T <type>, --dir-type=<type>

Type de directive optionnel. nvme-cli vérifie uniquement que la valeur est dans la plage définie pour le type de directive, bien que la spécification NVMe (1.3a) ne définisse qu'une seule directive, 01h, pour les identifiants de flux d'écriture.

-S <spec>, --dir-spec=<spec>

Champ optionnel pour les spécificités de directive. Utilisé avec les flux d'écriture, cette valeur est définie comme l'identifiant de flux d'écriture. nvme-cli ne validera pas si le flux demandé est dans les capacités du contrôleur.

-F <format-entrée>, --format=<format-entrée>

Format d'entrée de la plage source.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport à normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail de l'information dans la sortie.

-t <timeout>, --timeout=<timeout>

Remplace la valeur de délai d'attente par défaut. En millisecondes.
