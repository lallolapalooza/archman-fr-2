NOM

nvme-id-ns - Envoie une commande NVMe Identify Namespace, renvoie le résultat et la structure

SYNTAXE

nvme id-ns <périphérique> [--vendor-specific | -v] [--raw-binary | -b]
                        [--namespace-id=<nsid> | -n <nsid>] [--force]
                        [--human-readable | -H]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande d'identification d'espace de noms et fournit le résultat et la structure renvoyée.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc d'espace de noms (ex: /dev/nvme0n1). Si le périphérique caractère est donné, l'option '--namespace-id' est obligatoire, sinon il utilisera l'id d'espace de noms du périphérique bloc que vous avez ouvert. Pour les périphériques blocs, l'id d'espace de noms utilisé peut être remplacé avec la même option.

En cas de succès, la structure peut être renvoyée d'une des manières suivantes en fonction des indicateurs d'option ; la structure peut être analysée par le programme ou le tampon brut peut être imprimé sur la sortie standard.

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Récupère la structure d'identification d'espace de noms pour le nsid donné. Ceci est requis pour les périphériques caractère, ou remplace l'id d'espace de noms du bloc s'il est donné. Si le contrôleur prend en charge la capacité de gestion d'espace de noms et que 0xFFFFFFFF est donné, alors le contrôleur renvoie la structure d'identification d'espace de noms qui spécifie les capacités communes à travers les espaces de noms pour le contrôleur.

--force

Demande au contrôleur de renvoyer la structure d'identification d'espace de noms même si l'espace de noms n'est pas attaché au contrôleur. Ceci est valide uniquement pour les contrôleurs de révision 1.2 ou plus récente. Les contrôleurs de révision inférieure peuvent interpréter la commande incorrectement.

-b, --raw-binary

Imprime le tampon brut sur la sortie standard. La structure n'est pas analysée par le programme. Cela remplace les options spécifiques au vendeur et lisibles par l'homme.

-V, --vendor-specific

En plus d'analyser les champs connus, cette option affichera la région spécifique au vendeur de la structure en hexadécimal avec interprétation ASCII.

-H, --human-readable

Cette option analysera et formatera plusieurs champs de bits en formats lisibles par l'homme.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail de l'information dans la sortie.

EXEMPLES

•Faire interpréter le tampon renvoyé par le programme et afficher les champs connus dans un format lisible par l'homme : 
# nvme id-ns /dev/nvme0n1
•Si vous utilisez le périphérique caractère ou remplacez l'identifiant de l'espace de noms : 
# nvme id-ns /dev/nvme0 -n 1
# nvme id-ns /dev/nvme0n1 -n 1
# nvme id-ns /dev/nvme0 --namespace-id=1
•En plus d'afficher les champs connus, demander au programme d'afficher le champ spécifique au vendeur : 
# nvme id-ns /dev/nvme0n1 --vendor-specific
# nvme id-ns /dev/nvme0n1 -V

Ce qui précède affichera le tampon 'vs' en hexadécimal car il ne sait pas comment l'interpréter.

•Demander au programme de renvoyer la structure brute en binaire : 
# nvme id-ns /dev/nvme0n1 --raw-binary > id_ns.raw
# nvme id-ns /dev/nvme0n1 -b > id_ns.raw

Il est probablement déconseillé de ne pas rediriger la sortie standard en utilisant ce mode.

•Alternativement, vous pourriez vouloir envoyer les données à un autre programme capable d'analyser le tampon brut. 
# nvme id-ns /dev/nvme0n1 --raw-binary | nvme_parse_id_ns

Le programme d'analyse dans l'exemple ci-dessus peut être un programme qui affiche la structure de la manière dont vous le souhaitez. Le programme suivant en est un exemple qui l'analysera et peut accepter la sortie via un pipe, '|', comme montré dans l'exemple ci-dessus, ou vous pouvez 'cat' un tampon de sortie sauvegardé pour lui.

/* Fichier: nvme_parse_id_ns.c */
#include <linux/nvme.h>
#include <stdio.h>
#include <unistd.h>
int main(int argc, char **argv)
{
        unsigned char buf[sizeof(struct nvme_id_ns)];
        struct nvme_id_ns *ns = (struct nvme_id_ns *)buf;
        if (read(STDIN_FILENO, buf, sizeof(buf)))
                return 1;
        printf("nsze : %#llx\n", ns->nsze);
        printf("ncap : %#llx\n", ns->ncap);
        return 0;
}
