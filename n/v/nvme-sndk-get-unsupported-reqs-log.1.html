NOM

nvme-sndk-get-unsupported-reqs-log - Commande de plugin sndk nvme get-unsupported-reqs-log, renvoie la sortie du log analysée

SYNTAXE

nvme sndk get-unsupported-reqs-log <périphérique> [--format-sortie=<normal|json>
-o <normal|json>]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande de plugin sndk get-unsupported-reqs-log et affiche les données du log des exigences non prises en charge. L'option --format-sortie formate la sortie comme spécifié.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (par ex: /dev/nvme0).

Cela ne fonctionnera que sur les périphériques Sandisk prenant en charge cette page de log. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, il renvoie les données analysées de la page de log des exigences non prises en charge, sinon le code d'erreur.

OPTIONS

-o <fmt>, --format-sortie=<fmt>

Définit le format de rapport sur normal ou json. Un seul format de sortie peut être utilisé à la fois. Le défaut est normal.

EXEMPLES

•Fait exécuter au programme la commande du plugin sndk get-unsupported-reqs-log : 
# nvme sndk get-unsupported-reqs-log /dev/nvme0
