NOM

nvme-sndk-drive-resize - Envoie une commande NVMe sndk Resize spécifique au vendeur, renvoie le résultat.

SYNOPSIS

nvme sndk drive-resize <périphérique> [--size=<sz> | -s <sz>]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande de redimensionnement sndk spécifique au vendeur.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc d'espace de noms (ex: /dev/nvme0n1).

Ceci ne fonctionnera que sur les périphériques Sandisk prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, renvoie 0, sinon le code d'erreur.

OPTIONS

-s <sz>, --size=<sz>

La nouvelle taille (en Go) à laquelle redimensionner le lecteur.

EXEMPLES

•Demande au programme d'émettre la commande spécifique au vendeur sndk Resize : 
# nvme sndk drive-resize /dev/nvme0n1 --size=100
