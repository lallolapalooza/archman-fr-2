NOM

nvme-ocp-telemetry-string-log - Récupérer la page de journal de télémétrie OCP

SYNOPSIS

nvme ocp telemetry-string-log <périphérique>
                        [--output-format=<fmt> | -o <fmt>]
                        [--output-file=<fichier> | -f <fichier>]

DESCRIPTION

Pour le périphérique NVMe donné, récupérer la page de journal de télémétrie OCP

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0) soit le périphérique bloc (ex: /dev/nvme0n1).

Cela ne fonctionnera que sur les périphériques conformes OCP prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, retourne 0, sinon un code d'erreur.

OPTIONS

-o <fmt>, --output-format=<fmt>

Cette option définit le format de rapport sur normal, json ou binaire. Un seul format de sortie peut être utilisé à la fois.

-f <fichier>, --output-file=<fichier>

Nom du chemin du fichier où les données de sortie binaires seront enregistrées.

EXEMPLES

•Demande au programme d'émettre une commande telemetry-string-log pour obtenir les données du journal à partir d'un fichier binaire. 
# nvme ocp telemetry-string-log /dev/nvme0n1
