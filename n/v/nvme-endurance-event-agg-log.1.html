NOM

nvme-endurance-event-agg-log - Envoie une requête de page de journal d'endurance NVMe, retourne le résultat et le journal

SYNOPIS

nvme endurance-event-agg-log <périphérique> [--log-entries=<entrées_journal> | -e <entrées_journal>]
                        [--rae | -r] [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Récupère la page de journal agrégée des événements d'endurance NVMe d'un périphérique NVMe et fournit la structure retournée.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc d'espace de noms (ex: /dev/nvme0n1).

En cas de succès, la structure de journal agrégée des événements d'endurance retournée peut l'être de plusieurs manières selon les indicateurs d'options ; la structure peut être analysée par le programme et imprimée dans un format lisible, le tampon brut peut être imprimé sur stdout pour qu'un autre programme l'analyse, ou rapportée au format json.

OPTIONS

-e <entrées_journal>, --log-entries=<entrées_journal>

Récupère les entrées en attente du journal agrégé des événements du groupe d'endurance. Cet argument est obligatoire et son succès peut dépendre des statistiques du périphérique pour fournir ce journal. Pour plus de détails, voir la spécification NVM Express 1.4, section 5.14.1.15. Le nombre maximum d'entrées de journal prises en charge est de 2044 pour le périphérique.

-r, --rae

Conserver un événement asynchrone.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

• Imprime la page de journal d'endurance dans un format lisible par l'homme : 
# nvme endurance-event-agg-log /dev/nvme0
• Imprime le journal d'endurance brut dans un fichier : 
# nvme endurance-event-agg-log /dev/nvme0 --output=binary > endurance_event_agg_log.raw

Il est probablement déconseillé de ne pas rediriger stdout lors de l'utilisation de ce mode.
