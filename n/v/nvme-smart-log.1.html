NOM

nvme-smart-log - Envoyer une requête de page de journal SMART NVMe, retourne le résultat et le journal

SYNOPIS

nvme smart-log <périphérique> [--namespace-id=<nsid> | -n <nsid>]
                        [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Récupère la page de journal SMART NVMe d'un périphérique NVMe et fournit la structure retournée.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

En cas de succès, la structure de journal SMART retournée peut être renvoyée de plusieurs manières selon les options ; la structure peut être analysée par le programme et imprimée dans un format lisible, ou le tampon brut peut être imprimé sur la sortie standard pour être analysé par un autre programme.

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Récupère le journal SMART pour le nsid donné. Ceci est facultatif et son succès peut dépendre des capacités du périphérique à fournir ce journal sur une base par namespace (voir Identify Controller NVMe pour cette capacité). Le nsid par défaut à utiliser est 0xffffffff pour le journal SMART global du périphérique.

-b, --raw-binary

Imprime le tampon brut du journal SMART sur la sortie standard.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport à normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail de l'information dans la sortie.

EXEMPLES

•Imprimer la page de journal SMART dans un format lisible par l'homme : 
# nvme smart-log /dev/nvme0
•Imprimer le journal SMART brut dans un fichier : 
# nvme smart-log /dev/nvme0 --raw-binary > smart_log.raw

Il est probablement déconseillé de ne pas rediriger la sortie standard lorsque vous utilisez ce mode.
