NOM

nvme io-mgmt-recv - Commande de réception de gestion d'E/S

SYNTAXE

nvme io-mgmt-recv <périphérique> [--namespace-id=<NUM> | -n <NUM>]
                        [--mos=<NUM> | -s <NUM>] [--mo=<NUM> | -m <NUM>]
                        [--data=<FICHIER> | -d <FICHIER>]
                        [--data-len=<NUM> | -l <NUM>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPTION

Pour le périphérique NVMe donné, exécute la commande de réception de gestion d'E/S avec l'opération de gestion (mo) et le paramètre spécifique à l'opération de gestion (mos) demandés. Ceci est l'interface générique fournie pour une compatibilité ascendante à mesure que de nouvelles opérations sont ajoutées dont ce programme n'a pas connaissance au moment de son développement. En tant que tel, il s'agit d'une commande générique qui ne fait aucun décodage supplémentaire pour les types spécifiques de données reçues. Elle ne présentera les données que sous forme de vidage hexadécimal, ou binaire.

OPTIONS

-n <NUM>, --namespace-id=<NUM>

Utilise l'identifiant de namespace fourni pour la commande. S'il n'est pas fourni, l'identifiant de namespace du périphérique bloc sera utilisé. Si la commande est émise vers un périphérique non-bloc, le paramètre est requis.

-d <FICHIER>, --data=<FICHIER>

Fichier dans lequel écrire les données reçues. Si non spécifié, les données reçues seront vidées en hexadécimal sur le flux de sortie standard.

-l <NUM>, --data-len=<NUM>

Longueur du tampon de données reçues.

-m <NUM>, --mo <NUM>

Opération de gestion à effectuer.

-s <NUM>, --mos=<NUM>

Paramètre spécifique de l'opération de gestion.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

-t <timeout>, --timeout=<timeout>

Remplace la valeur de délai d'attente par défaut. En millisecondes.
