NOM

nvme-dapustor-smart-log-add - Envoie une requête de page de journalisation SMART supplémentaire NVMe DapuStor, renvoie le résultat et le journal.

SYNTAXE

nvme dapustor smart-log-add <périphérique> [--namespace-id=<nsid> | -n <nsid>]
                        [--raw-binary | -b] [--json | -j]

DESCRIPTION

Récupère la page de journalisation SMART supplémentaire NVMe DapuStor du périphérique et fournit la structure renvoyée.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (par exemple, /dev/nvme0), soit un périphérique bloc de namespace (par exemple, /dev/nvme0n1).

En cas de succès, la structure de journalisation SMART renvoyée peut être renvoyée de plusieurs manières en fonction des indicateurs d'option ; la structure peut être analysée par le programme et affichée dans un format lisible, ou le tampon brut peut être affiché sur la sortie standard pour qu'un autre programme l'analyse.

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Récupère le journal SMART supplémentaire pour le nsid donné. Ceci est facultatif et son succès peut dépendre des capacités du périphérique à fournir ce journal par namespace (voir l'identification du contrôleur NVMe pour cette capacité). Le nsid par défaut à utiliser est 0xffffffff pour le journal SMART global du périphérique.

-b, --raw-binary

Affiche le tampon brut du journal SMART supplémentaire DapuStor sur la sortie standard.

-j, --json

Affiche la sortie au format json.

EXEMPLES

•Affiche la page de journalisation SMART supplémentaire DapuStor dans un format lisible par l'homme : 
# nvme dapustor smart-log-add /dev/nvme0
•Affiche le journal SMART supplémentaire DapuStor brut dans un fichier : 
# nvme dapustor smart-log-add /dev/nvme0 --raw-binary > smart_log.raw

Il est probablement déconseillé de ne pas rediriger la sortie standard lorsque vous utilisez ce mode.
