NOM

nvme-io-passthru - Soumettre une commande io arbitraire, retourner les résultats

SYNTAXE

nvme-io-passthru <périphérique> [--opcode=<opcode> | -O <opcode>]
                        [--flags=<flags> | -f <flags>] [-rsvd=<rsvd> | -R <rsvd>]
                        [--namespace-id=<nsid> | -n <nsid>] [--cdw2=<cdw2> | -2 <cdw2>]
                        [--cdw3=<cdw3> | -3 <cdw3>] [--cdw10=<cdw10> | -4 <cdw10>]
                        [--cdw11=<cdw11> | -5 <cdw11>] [--cdw12=<cdw12> | -6 <cdw12>]
                        [--cdw13=<cdw13> | -7 <cdw13>] [--cdw14=<cdw14> | -8 <cdw14>]
                        [--cdw15=<cdw15> | -9 <cdw15>]
                        [--data-len=<data-len> | -l <data-len>]
                        [--metadata-len=<len> | -m <len>]
                        [--read | -r] [--write | -w]
                        [--input-file=<file> | -i <file>]
                        [--metadata=<file> | -M <file>]
                        [--timeout=<timeout> | -t <timeout>] [--show-command | -s]
                        [--dry-run | -d] [--raw-binary | -b]
                        [--prefill=<prefill> | -p <prefill>]
                        [--latency | -T]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Soumet une commande IO NVMe arbitraire et retourne les résultats applicables. Il peut s'agir simplement du résultat et de l'état de la commande, ou cela peut également inclure un tampon si la commande en retourne un. Cette commande n'interprète pas les opcodes ou les options.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (par exemple, /dev/nvme0), soit un périphérique bloc de namespace (par exemple, /dev/nvme0n1).

En cas de succès, la structure retournée (si applicable) peut être retournée de plusieurs manières selon les indicateurs d'option ; la structure peut être imprimée par le programme sous forme de dump hexadécimal, ou peut être retournée sous forme de tampon brut imprimé sur la sortie standard pour qu'un autre programme puisse l'analyser.

OPTIONS

-O <opcode>, --opcode=<opcode>

L'opcode NVMe à envoyer au périphérique dans la commande. Argument obligatoire car ce paramètre est obligatoire.

-f <flags>, --flags=<flags>

Les indicateurs de commande NVMe à envoyer au périphérique dans la commande.

-R <rsvd>, --rsvd=<rsvd>

La valeur du champ réservé dans la commande.

-n <nsid>, --namespace-id=<nsid>

La valeur du ns-id dans la commande. La valeur par défaut est 0.

-[2-9] <cdw>, --cdw[2-3,10-15]=<cdw>

Spécifie la valeur du mot de commande pour cette entrée spécifiée dans la commande.

-r, --read, -w, --write

Utilisé pour la direction des données de la commande et requis pour les commandes envoyant/recevant des données. N'utilisez pas read et write en même temps.

-i <file>, --input-file=<file>

Si la commande est une commande de sortie de données (écriture), utilisez ce fichier pour remplir le tampon envoyé au périphérique. Si aucun fichier n'est donné, il est supposé utiliser STDIN. Si la commande est une commande d'entrée de données (lecture), les données renvoyées par le périphérique y seront enregistrées.

-M <file>, --metadata=<file>

Si la commande est une commande de sortie de données (écriture), utilisez ce fichier pour remplir le tampon de métadonnées envoyé au périphérique. Si aucun fichier n'est donné, il est supposé utiliser STDIN. Si la commande est une commande d'entrée de données (lecture), les métadonnées renvoyées par le périphérique y seront enregistrées.

-l <data-len>, --data-len=<data-len>

La longueur des données pour le tampon utilisé pour cette commande.

-m <data-len>, --metadata-len=<data-len>

La longueur des métadonnées pour le tampon utilisé pour cette commande.

-s, --show-cmd

Imprime la commande à envoyer.

-d, --dry-run

N'envoie pas réellement la commande. Si vous souhaitez utiliser l'option --dry-run, l'option --show-cmd doit être définie. Sinon, l'option --dry-run sera ignorée.

-b, --raw-binary

Imprime le tampon retourné brut sur la sortie standard si la commande retourne des données ou une structure.

-p <prefill>, --prefill <prefill>

Preremplit le tampon avec une valeur d'octet prédéterminée. La valeur par défaut est 0. Cela peut être utile si les données que vous écrivez sont plus courtes que le tampon requis, et que vous devez les compléter avec une valeur connue. Cela peut également être utile si vous devez confirmer si un périphérique écrase un tampon sur une commande d'entrée de données.

-T, --latency

Imprime la latence de l'appel IOCTL (en µs).

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

-t <timeout>, --timeout=<timeout>

Remplace la valeur de délai d'attente par défaut. En millisecondes.

EXEMPLES

nvme io-passthru /dev/nvme0n1 --opcode=2 --namespace-id=1 --data-len=4096 --read --cdw10=0 --cdw11=0 --cdw12=0x70000 --raw-binary
