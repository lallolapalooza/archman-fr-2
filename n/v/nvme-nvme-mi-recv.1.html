NOM

nvme-nvme-mi-recv - Envoie une commande NVMe-MI Receive au périphérique spécifié

SYNTAXE

nvme nvme-mi-recv <périphérique> [--opcode=<opcode> | -O <opcode>]
                        [--namespace-id=<nsid> | -n <nsid>]
                        [--data-len=<data-len> | -l <data-len>]
                        [--nmimt=<nmimt> | -m <nmimt>]
                        [--nmd0=<nmd0> | -0 <nmd0>] [--nmd1=<nmd1> | -1 <nmd1>]
                        [--input-file=<fichier> | -i <fichier>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Envoie une commande NVMe-MI Receive au périphérique spécifié, renvoie les résultats.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0) soit le périphérique bloc (ex: /dev/nvme0n1).

En cas de succès, renvoie 0, sinon renvoie un code d'erreur.

OPTIONS

-O <opcode>, --opcode=<opcode>

L'opcode NVMe-MI à envoyer au périphérique dans la commande. Argument requis car ce paramètre est obligatoire.

-n <nsid>, --namespace-id=<nsid>

La valeur pour l'ID d'espace de noms (ns-id) dans la commande.

-l <data-len>, --data-len=<data-len>

La longueur des données pour le tampon utilisé pour cette commande.

-m <nmimt>, --nmimt=<nmimt>

La valeur pour le type de message NVMe-MI dans la commande.

-0 <nmd0>, --nmd0=<nmd0>

La valeur pour le DWORD 0 de la requête de gestion NVMe dans la commande.

-1 <nmd1>, --nmd1=<nmd1>

La valeur pour le DWORD 1 de la requête de gestion NVMe dans la commande.

-i <fichier>, --input-file=<fichier>

Si la commande est une commande de sortie de données (écriture), utilisez ce fichier pour remplir le tampon envoyé au périphérique. Si aucun fichier n'est spécifié, il est supposé utiliser STDIN.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport à normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

•Demander au programme d'exécuter un nvme-mi-recv pour exécuter la lecture VPD. 
# nvme nvme-mi-recv /dev/nvme0n1 -O 5 -m 1 -0 0 -1 0x100 -l 256
