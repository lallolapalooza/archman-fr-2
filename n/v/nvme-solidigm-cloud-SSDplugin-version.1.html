NOM

nvme-solidigm-cloud-SSDplugin-version - Affiche la version du plugin OCP

SYNTAXE

nvme solidigm cloud-SSDplugin-version

DESCRIPTION

Affiche la version OCP (Open Compute Project) du plugin SSD cloud Solidigm.

EXEMPLES

•Afficher la version du plugin OCP : 
# nvme solidigm cloud-SSDplugin-version
