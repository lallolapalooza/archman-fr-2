NOM

nvme-security-send - Commande d'envoi de sécurité

SYNTAXE

nvme security-send <périphérique> [--file=<fichier> | -f <fichier>]
                        [--secp=<protocole-sécurité> | -p <protocole-sécurité>]
                        [--spsp=<protocole-spécifique> | -s <protocole-spécifique>]
                        [--tl=<longueur-transfert> | -t <longueur-transfert>]
                        [--nssf=<nvme-spécifique> | -N <nvme-spécifique>]
                        [--namespace-id=<nsid> | -n <nsid>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout>]

DESCRIPTION

La commande Security Send est utilisée pour transférer des données de protocole de sécurité vers le contrôleur. La structure de données transférée au contrôleur dans le cadre de cette commande contient des commandes spécifiques au protocole de sécurité à exécuter par le contrôleur. La structure de données transférée peut également contenir des données ou des paramètres associés aux commandes de protocole de sécurité. Le statut et les données à retourner à l'hôte pour les commandes de protocole de sécurité soumises par une commande Security Send sont récupérés avec la commande Security Receive.

L'association entre une commande Security Send et une commande Security Receive subséquente dépend du champ Security Protocol, tel que défini dans SPC-4.

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Cible un espace de noms spécifique pour cette commande de sécurité.

-N <nssf>, --nssf=<nssf>

Champ NVMe Security Specific. Si vous utilisez le protocole de sécurité EAh attribué à l'utilisation NVMe, le champ NVMe Security Specific indique la cible du tampon mémoire de réponse.

-f <fichier>, --file=<fichier>

Chemin vers le fichier utilisé comme charge utile du protocole de sécurité. Argument requis.

-p <protocole-sécurité>, --secp=<protocole-sécurité>

Protocole de Sécurité : Ce champ spécifie le protocole de sécurité tel que défini dans SPC-4. Le contrôleur échouera la commande avec Invalid Parameter indiqué si une valeur réservée du Protocole de Sécurité est spécifiée.

-s <protocole-spécifique-sécurité>, --spsp=<protocole-spécifique-sécurité>

SP Specific : La valeur de ce champ est spécifique au Protocole de Sécurité tel que défini dans SPC-4.

-t <longueur-transfert>, --tl=<longueur-transfert>

Longueur de Transfert : La valeur de ce champ est spécifique au Protocole de Sécurité tel que défini dans SPC-4.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

--timeout=<timeout>

Remplace la valeur de délai d'attente par défaut. En millisecondes.
