NOM

nvme-wdc-log-page-directory - Récupère la liste des identifiants de journal pris en charge par le disque

SYNOPSIS

nvme wdc log-page-directory <périphérique> [--output-format=<normal|json|binary> -o <normal|json|binary>]

DESCRIPTION

Pour le périphérique NVMe donné, récupère le répertoire de pages de journal qui contient la liste des identifiants de page de journal pris en charge par le disque. L'option --output-format formatera la sortie comme spécifié.

Le paramètre <périphérique> est obligatoire et doit être le périphérique caractère NVMe (ex: /dev/nvme0).

Ceci ne fonctionnera que sur les périphériques WDC prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, il retourne les informations du répertoire de pages de journal, sinon le code d'erreur.

OPTIONS

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json, ou binary. Un seul format de sortie peut être utilisé à la fois. La valeur par défaut est normal.

EXEMPLES

• Commande d'exemple pour le répertoire de pages de journal WDC : 
# nvme wdc log-page-directory /dev/nvme0
