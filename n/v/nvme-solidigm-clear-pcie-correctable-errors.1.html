NOM

nvme-solidigm-clear-pcie-correctable-errors - Effacer les compteurs d'erreurs PCIe corrigeables

SYNTAXE

nvme solidigm clear-pcie-correctable-errors <périphérique> [--no-uuid | -n]

DESCRIPTION

Cette commande est une redirection vers la commande du plugin OCP pour effacer les compteurs d'erreurs PCIe corrigeables. Pour une utilisation et des options détaillées, veuillez vous référer à la documentation de nvme ocp clear-pcie-correctable-error-counters.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0) soit le périphérique bloc (ex: /dev/nvme0n1).

OPTIONS

-n, --no-uuid

N'essayez pas de détecter automatiquement l'index UUID pour cette commande (requis pour la prise en charge de l'ancienne version OCP 1.0). Cette option est nécessaire pour les périphériques qui ne prennent pas en charge OCP 2.0 ou NVMe 1.4.

EXEMPLES

• Effacer les compteurs d'erreurs PCIe corrigeables pour le périphérique : 
# nvme solidigm clear-pcie-correctable-errors /dev/nvme0
• Effacer les compteurs d'erreurs PCIe corrigeables pour un périphérique OCP 1.0 : 
# nvme solidigm clear-pcie-correctable-errors /dev/nvme0 --no-uuid
