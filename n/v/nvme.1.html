NOM

nvme - utilitaire d'interface de ligne de commande pour le stockage NVMe (nvme-cli)

SYNTAXE

plugin intégré :

nvme <commande> <périphérique> [<arguments>]

plugins d'extension :

nvme <plugin> <commande> <périphérique> [<arguments>]

DESCRIPTION

NVM-Express est une interface de contrôleur hôte rapide et évolutive, conçue pour répondre aux besoins non seulement des disques SSD basés sur PCI Express, mais aussi des NVMe-oF (over fabrics).

Ce programme nvme est un utilitaire en espace utilisateur pour fournir des outils conformes aux normes pour les disques NVM-Express. Il a été créé spécifiquement pour Linux car il repose sur les IOCTL définis par le pilote du noyau principal.

COMMANDES NVME

L'utilitaire dispose de sous-commandes pour toutes les commandes d'administration et d'E/S définies dans la spécification, ainsi que pour l'affichage des registres du contrôleur. Il existe également une option pour soumettre des commandes complètement arbitraires. Pour une liste des commandes disponibles, exécutez "nvme help".
