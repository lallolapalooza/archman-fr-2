NOM

nvme-write-zeroes - Envoie une commande NVMe write zeroes, retourne les résultats

SYNTAXE

nvme-write-zeroes <périphérique> [--start-block=<slba> | -s <slba>]
                        [--block-count=<nlb> | -c <nlb>]
                        [--ref-tag=<reftag> | -r <reftag>]
                        [--prinfo=<prinfo> | -p <prinfo>]
                        [--app-tag-mask=<appmask> | -m <appmask>]
                        [--app-tag=<apptag> | -a <apptag>] [--deac | -d]
                        [--limited-retry | -l] [--force-unit-access | -f]
                        [--namespace-id=<nsid> | -n <nsid>]
                        [--storage-tag<storage-tag> | -S <storage-tag>]
                        [--storage-tag-check<storage-tag-check> | -C <storage-tag-check>]
                        [--dir-type=<dtype> | -T <dtype>]
                        [--dir-spec=<dspec> | -D <dspec>] [--namespace-zeroes | -Z]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPTION

La commande Write Zeroes est utilisée pour mettre une plage de blocs logiques à 0.

OPTIONS

-s <slba>, --start-block=<slba>

Bloc de départ.

-c <nlb>, --block-count=<nlb>

Nombre de blocs logiques auxquels écrire des zéros.

-p <prinfo>, --prinfo=<prinfo>

Définition du champ Information de Protection.
Bit Description
3 PRACT: Action d'Information de Protection. Lorsqu'il est défini à 1, le PI est retiré/inséré lors de la lecture/écriture si la taille des métadonnées du format de bloc est de 8. Lorsqu'il est défini à 0, les métadonnées sont transmises.
2:0 PRCHK: Vérification de l'Information de Protection :
2 Défini à 1 active la vérification du garde tag
1 Défini à 1 active la vérification du tag d'application
0 Défini à 1 active la vérification du tag de référence

-r <reftag>, --ref-tag=<reftag>

Tag de référence optionnel lorsqu'il est utilisé avec l'information de protection.

-m <appmask>, --app-tag-mask=<appmask>

Masque de tag d'application optionnel lorsqu'il est utilisé avec l'information de protection.

-a <apptag>, --app-tag=<apptag>

Tag d'application optionnel lorsqu'il est utilisé avec l'information de protection.

-l, --limited-retry

Définit le drapeau de nouvelle tentative limitée.

-d, --deac

Définit le bit DEAC, demandant au contrôleur de désallouer les blocs logiques.

-f, --force-unit-access

Définit le drapeau force-unit-access.

-n <nsid>, --namespace-id=<nsid>

ID de l'espace de noms utilisé dans la commande.

-S <storage-tag>, --storage-tag=<storage-tag>

Tag de stockage de bloc logique de taille variable (LBST).

-C <storage-tag-check>, --storage-tag-check=<storage-tag-check>

Ce bit spécifie que le champ Storage Tag doit être vérifié dans le cadre du traitement de protection de données de bout en bout.

-T <dtype>, --dir-type=<dtype>

Type de directive

-D <dspec>, --dir-spec=<dspec>

Spécification de la directive

-Z, --namespace-zeroes

Si défini, le contrôleur efface tous les blocs logiques à zéro dans l'espace de noms entier.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport à normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

-t <timeout>, --timeout=<timeout>

Remplace la valeur de délai d'attente par défaut. En millisecondes.
