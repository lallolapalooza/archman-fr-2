nvme-ocp-set-plp-health-check-interval(1)

NOM

nvme-ocp-set-plp-health-check-interval - Définir l'intervalle de vérification de l'état PLP

SYNTAXE

nvme ocp set-plp-health-check-interval <périphérique> [--plp_health_interval=<plp_health_interval> | -p <plp_health_interval>] [--save | -s] [--no-uuid | -n]

DESCRIPTION

Définit l'intervalle de vérification de l'état PLP. Aucune option n'affiche le mode actuel.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0) soit le périphérique bloc (ex: /dev/nvme0n1).

Cela ne fonctionnera que sur les périphériques conformes à OCP prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, renvoie 0, sinon un code d'erreur.

OPTIONS

-p <plp_health_interval>, --plp_health_interval=<plp_health_interval>

Définit l'intervalle de vérification de l'état PLP [31:16]

-n, --no-uuid

N'essaie pas de détecter automatiquement l'index UUID pour cette commande (requis pour la prise en charge d'anciennes versions d'OCP 1.0)

-s, --save

Sauvegarde l'attribut afin qu'il persiste à travers tous les états d'alimentation et les réinitialisations.

EXEMPLES

•Demande au programme d'émettre une commande set-plp-health-check-interval pour récupérer les fonctionnalités définies 0xC6. 
# nvme ocp eol-plp-failure-mode /dev/nvme0
