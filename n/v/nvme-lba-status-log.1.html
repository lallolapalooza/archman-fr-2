NOM

nvme-lba-status-log - Envoie une requête de page de journal de statut LBA et retourne le résultat et le journal

SYNTAXE

nvme lba-status-log <périphérique> [--rae | -r]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Récupère la page de journal de statut LBA NVMe d'un périphérique NVMe et fournit la structure retournée.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex : /dev/nvme0), soit un périphérique bloc de l'espace de noms (ex : /dev/nvme0n1).

En cas de succès, la structure de la page de journal de statut LBA retournée peut être renvoyée de plusieurs manières en fonction des indicateurs d'options ; la structure peut être analysée par le programme et affichée dans un format lisible, ou le tampon brut peut être affiché sur la sortie standard pour qu'un autre programme l'analyse.

OPTIONS

-r, --rae

Conserver un événement asynchrone.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binaire. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

• Affiche la page de journal de statut LBA dans un format lisible normal : 
# nvme lba-status-log /dev/nvme0
• Affiche la sortie au format JSON 
# nvme lba-status-log /dev/nvme0 -o json
