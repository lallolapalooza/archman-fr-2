NOM

nvme-wdc-purge-monitor - Envoie la commande propre unique au vendeur NVMe WDC Purge-Monitor, renvoie le résultat

SYNTAXE

nvme wdc purge-monitor <périphérique>

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande propre unique au vendeur WDC Purge-Monitor et fournit l'état de la commande propre.

État et description attendus :

Code d'état Description
0x00 État de nettoyage inactif.
0x01 État de nettoyage terminé.
0x02 État de nettoyage occupé.
0x03 Erreur d'état de nettoyage : l'opération de nettoyage a entraîné une erreur, cycle d'alimentation requis.
0x04 Erreur d'état de nettoyage : opération de nettoyage interrompue par un cycle d'alimentation ou une réinitialisation.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (par exemple, /dev/nvme0), soit un périphérique bloc de l'espace de noms (par exemple, /dev/nvme0n1).

Cela ne fonctionnera qu'avec les périphériques WDC prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique ne sont pas définis.

En cas de succès, renvoie 0, sinon un code d'erreur.

OPTIONS

Aucune option pour le moment.

EXEMPLES

•Fait émettre au programme la commande propre unique au vendeur WDC Purge-Monitor : 
# nvme wdc purge-monitor /dev/nvme0

NVME

Fait partie de la suite nvme-user.
