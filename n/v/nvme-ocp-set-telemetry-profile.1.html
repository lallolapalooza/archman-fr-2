NOM

nvme-ocp-set-telemetry-profile - Définir le profil de télémétrie

SYNTAXE

nvme ocp set-telemetry-profile <périphérique>
                        [--telemetry-profile-select=<tps> | -t <tps>]

DESCRIPTION

Pour le périphérique NVMe donné, définit la fonctionnalité OCP Set Telemetry Profile.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (par ex : /dev/nvme0) soit le périphérique bloc (par ex : /dev/nvme0n1).

Cela ne fonctionnera que sur les périphériques compatibles OCP prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, retourne 0, sinon un code d'erreur.

OPTIONS

-t <tps>, --tps=<tps>

Sélection du profil de télémétrie. Le périphérique doit collecter des données de débogage selon le numéro de profil spécifié.

EXEMPLES

• Demande au programme d'émettre une commande set-telemetry-profile pour utiliser le profil cinq. 
# nvme ocp set-telemetry-profile /dev/nvme0 -t 5
