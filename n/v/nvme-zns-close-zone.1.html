NOM

nvme-zns-close-zone - Ferme une ou toutes les zones

SYNTAXE

nvme zns close-zone <périphérique> [--namespace-id=<NOMBRE> | -n <NOMBRE>]
                                                [--start-lba=<LBA> | -s <LBA>]
                                                [--select-all | -a]
                                                [--timeout=<timeout> | -t <timeout>]

DESCRIPTION

Pour le périphérique NVMe donné, émet la commande Zone Management Send avec l'action "Close Zone". Ceci transitionnera la zone à l'état fermé.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

OPTIONS

-n <NOMBRE>, --namespace-id=<NOMBRE>

Utilise l'identifiant de namespace fourni pour la commande. Si non fourni, l'identifiant de namespace du périphérique bloc sera utilisé. Si la commande est émise à un périphérique non bloc, le paramètre est requis.

-s <lba>, --start-lba=<lba>

Le LBA de départ de la zone à fermer.

-a, --select-all

Sélectionne toutes les zones pour cette action.

-t <timeout>, --timeout=<timeout>

Remplace la valeur de délai d'attente par défaut. En millisecondes.

EXEMPLES

•Fermer toutes les zones sur le namespace 1 : 
# nvme zns close-zone /dev/nvme0 -a -n 1
