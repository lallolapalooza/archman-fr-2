NOM

nvme-primary-ctrl-caps - Envoie la commande Identify Primary Controller Caps, retourne le résultat et la structure

SYNTAXE

nvme primary-ctrl-caps <périphérique> [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande Identify Primary Controller Caps et fournit le résultat et la structure retournée.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

En cas de succès, la structure peut être retournée de plusieurs façons selon les options choisies ; la structure peut être analysée par le programme ou le tampon brut peut être imprimé sur la sortie standard.

OPTIONS

-H, --human-readable

Cette option analysera et formatera plusieurs champs binaires dans un format lisible par l'homme.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport à normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

•Obtenir les Capacités du Contrôleur Primaire du périphérique dans le format par défaut 
# nvme primary-ctrl-caps /dev/nvme0
•Demander au programme d'interpréter le tampon retourné et d'afficher les champs connus dans un format lisible par l'homme : 
# nvme primary-ctrl-caps /dev/nvme0 --human-readable
# nvme primary-ctrl-caps /dev/nvme0 -H

NVME

Fait partie de la suite nvme-user
