nvidia-modprobe(1) Manuel des commandes générales nvidia-modprobe(1)

NOM

nvidia-modprobe - Charge le module noyau NVIDIA et crée les fichiers de périphérique NVIDIA.

SYNTAXE

nvidia-modprobe [options]
nvidia-modprobe [options] --create-nvidia-device-file=NUMÉRO_MINEUR
nvidia-modprobe [options] --module-instance=INSTANCE_MODULE

DESCRIPTION

L'utilitaire nvidia-modprobe est utilisé par les composants du pilote NVIDIA en espace utilisateur pour s'assurer que le module noyau NVIDIA est chargé, que les fichiers de périphérique NVIDIA sont présents et pour configurer certains paramètres d'exécution dans le noyau. Ces fonctionnalités sont normalement fournies par les systèmes de configuration des distributions Linux tels que udev. Lorsque possible, il est recommandé d'utiliser les mécanismes natifs de votre distribution Linux pour gérer le chargement des modules noyau, la création de fichiers de périphérique et les paramètres de configuration d'exécution du noyau. Cet utilitaire est fourni comme solution de repli pour fonctionner immédiatement, indépendamment de la distribution.

Lorsqu'il est installé par nvidia-installer, nvidia-modprobe est installé setuid root.

Les utilisateurs ne devraient normalement pas avoir besoin d'exécuter nvidia-modprobe manuellement : les composants du pilote NVIDIA en espace utilisateur l'appelleront (fork(2)/exec(3)) lorsqu'ils en auront besoin.

Lorsqu'il est exécuté sans aucune option, nvidia-modprobe chargera le module noyau NVIDIA puis se terminera. Lorsque l'option --module-instance est spécifiée sur les systèmes avec plusieurs modules noyau NVIDIA, nvidia-modprobe chargera le module noyau NVIDIA correspondant puis se terminera. Lorsque l'option --create-nvidia-device-file est spécifiée, nvidia-modprobe créera également le fichier de périphérique demandé.

Le code source de nvidia-modprobe est disponible ici :
⟨ https://download.nvidia.com/XFree86/nvidia-modprobe/ ⟩

OPTIONS

-v, --version
Affiche la version de l'utilitaire et quitte.
-h, --help
Affiche les informations d'utilisation pour les options de ligne de commande et quitte.
-c NUMÉRO_MINEUR, --create-nvidia-device-file=NUMÉRO_MINEUR
Crée le fichier de périphérique NVIDIA avec le numéro mineur donné ; cette option peut être spécifiée plusieurs fois pour créer plusieurs fichiers de périphérique NVIDIA.

OPTIONS AVANCÉES

-u, --unified-memory
Charge le module noyau NVIDIA Unified Memory ou crée les fichiers de périphérique pour celui-ci, au lieu du module noyau NVIDIA.
-m, --modeset
Charge le module noyau NVIDIA modeset et crée son fichier de périphérique.
-s, --nvswitch
Charge le module noyau NVIDIA et crée les fichiers de périphérique NVSwitch pour chaque numéro mineur spécifié à l'aide de l'indicateur -c.
-l, --nvlink
Charge le module noyau NVIDIA et crée le fichier de périphérique de contrôle NVLink.
-f FICHIER_PÉRIPHÉRIQUE_CAPACITÉ_NVIDIA, --nvidia-capability-device-file=FICHIER_PÉRIPHÉRIQUE_CAPACITÉ_NVIDIA
Crée les fichiers de périphérique de capacité NVIDIA avec le chemin de fichier /proc de capacité donné. Cette option peut être spécifiée plusieurs fois pour créer plusieurs fichiers de périphérique de capacité NVIDIA.
-a, --auto-online-movable
Active le paramètre du noyau `online_movable` pour les plateformes (comme Grace Hopper) qui ajoutent et activent la mémoire GPU dans le noyau.

EXEMPLES

nvidia-modprobe
Exécute `/sbin/modprobe nvidia`
nvidia-modprobe -c 0 -c 1
Exécute `/sbin/modprobe nvidia` et crée /dev/nvidia0 et /dev/nvidia1
nvidia-modprobe -i 0
Exécute `/sbin/modprobe nvidia0`
