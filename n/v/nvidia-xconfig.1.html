nvidia-xconfig(1) Manuel des commandes générales nvidia-xconfig(1)

NOM

nvidia-xconfig - manipule les fichiers de configuration X pour le pilote NVIDIA

SYNTAXE

nvidia-xconfig [ options ]

DESCRIPTION

nvidia-xconfig est un outil destiné à fournir un contrôle de base sur les options de configuration disponibles dans le pilote X NVIDIA.

nvidia-xconfig effectue ses opérations en plusieurs étapes :

1)
Le fichier de configuration X du système est trouvé et lu en mémoire. Si aucun fichier de configuration ne peut être trouvé, nvidia-xconfig en génère un à partir de zéro en utilisant les paramètres par défaut ; dans ce cas, nvidia-xconfig écrira la configuration dans /etc/X11/xorg.conf.
2)
La configuration en mémoire est modifiée pour prendre en charge le pilote NVIDIA. Cela consiste à changer le pilote d'affichage en « nvidia », à supprimer les commandes de chargement des modules « GLcore » et « dri », et à ajouter la commande de chargement du module « glx ».
3)
La configuration en mémoire est modifiée selon les options spécifiées sur la ligne de commande. Veuillez consulter le README NVIDIA pour une description des options de configuration X du pilote NVIDIA. Notez que nvidia-xconfig n'effectue aucune validation des options de configuration X demandées sur la ligne de commande ; la validation des options de configuration X est laissée au pilote X NVIDIA.
4)
La configuration est réécrite dans le fichier d'où elle a été lue. Une sauvegarde de la configuration originale est créée en ajoutant « .backup ». Par exemple, si votre configuration X est /etc/X11/xorg.conf, alors nvidia-xconfig la copiera dans /etc/X11/xorg.conf.backup avant d'écrire la nouvelle configuration. L'option --post-tree (-T) peut être utilisée pour imprimer la nouvelle configuration en sortie standard sous forme d'arbre. Cette option est utile pour voir ce que nvidia-xconfig va faire tout en laissant la configuration originale intacte.

⟨ https://download.nvidia.com/XFree86/nvidia-xconfig/ ⟩

Les correctifs sont les bienvenus.

OPTIONS

-c XCONFIG, --xconfig=XCONFIG
Utilise XCONFIG comme fichier de configuration X d'entrée ; si cette option n'est pas spécifiée, alors le même chemin de recherche utilisé par le serveur X sera utilisé pour trouver le fichier de configuration X.
-o OUTPUT-XCONFIG, --output-xconfig=OUTPUT-XCONFIG
Utilise OUTPUT-XCONFIG comme fichier de configuration X de sortie ; si cette option n'est pas spécifiée, alors le nom du fichier de configuration X d'entrée sera également utilisé comme nom de fichier de configuration X de sortie.
-s, --silent
Exécute silencieusement ; aucun message ne sera imprimé sur stdout, à l'exception des messages d'avertissement et d'erreur sur stderr.
-t, --tree
Lit le fichier de configuration X, imprime les données de configuration X en sortie standard sous forme d'arbre, puis quitte.
-v, --version
Affiche la version de nvidia-xconfig et quitte.
-h, --help
Affiche les informations d'utilisation pour les options courantes de la ligne de commande et quitte.
-A, --advanced-help
Affiche les informations d'utilisation pour les options courantes de la ligne de commande ainsi que les options avancées, puis quitte.

OPTIONS AVANCÉES

--acpid-socket-path=CHEMIN_SOCKET_ACPID, --no-acpid-socket-path
Définit cette option pour spécifier un chemin alternatif vers le socket du démon ACPI Linux (acpid), que le pilote X NVIDIA utilisera pour se connecter à acpid.
--add-argb-glx-visuals, --no-add-argb-glx-visuals
Active ou désactive la prise en charge du rendu OpenGL dans les fenêtres et pixmaps ARGB 32 bits.
--allow-glx-with-composite, --no-allow-glx-with-composite
Active ou désactive l'option de configuration X « AllowGLXWithComposite ».
--busid=IDBUS, --no-busid
Cette option écrit l'ID de bus spécifié dans la section de périphérique du fichier de configuration X. S'il y a plusieurs sections de périphérique, elle ajoute le champ BusID à chacune d'elles. Pour ajouter l'ID de bus à un périphérique ou une section d'écran spécifique, utilisez les options '--device' ou '--screen'.
--preserve-busid, --no-preserve-busid
Par défaut, nvidia-xconfig conserve l'ID de bus existant dans le fichier de configuration X uniquement s'il y a plusieurs écrans X configurés pour le serveur X. Utilisez '--preserve-busid' ou '--no-preserve-busid' pour forcer la conservation ou non de l'ID de bus, remplaçant le comportement par défaut.
--cool-bits=COOL-BITS, --no-cool-bits
Active ou désactive l'option de configuration X « Coolbits ». La définition de cette option activera la prise en charge dans l'extension X NV-CONTROL pour la manipulation des paramètres d'horloge GPU et de contrôle de ventilateur GPU. La valeur par défaut est 0. Pour le contrôle du ventilateur, réglez-la sur 4. ATTENTION : cela peut endommager le système et annuler les garanties.
--composite, --no-composite
Active ou désactive l'extension X « Composite ».
--connected-monitor=MONITEUR-CONNECTÉ, --no-connected-monitor
Active ou désactive l'option de configuration X « ConnectedMonitor » ; la définition de cette option force le pilote X à se comporter comme si les périphériques d'affichage spécifiés étaient connectés au GPU.
--connect-to-acpid, --no-connect-to-acpid
Active ou désactive l'option de configuration X « ConnectToAcpid ». Si cette option est activée, le pilote X NVIDIA tentera de se connecter au démon ACPI Linux (acpid). Désactivez cette option pour empêcher le pilote X de tenter de se connecter à acpid.
--constant-dpi, --no-constant-dpi
Active ou désactive l'option de configuration X « ConstantDPI », qui contrôle si le pilote X NVIDIA maintient une valeur constante de points par pouce (DPI) en recalculant la taille rapportée en millimètres de l'écran X lorsque XRandR modifie la taille en pixels de l'écran X.
--custom-edid=EDID-PERSONNALISÉ, --no-custom-edid
Active ou désactive l'option de configuration X « CustomEDID » ; la définition de cette option force le pilote X à utiliser l'EDID spécifié. Cette option est une liste séparée par des points-virgules de paires de noms de périphériques d'affichage et de noms de fichiers ; par exemple « CRT-0:mp\did.bin ». Notez qu'un nom de périphérique d'affichage doit toujours être spécifié, même si un seul EDID est spécifié.
--dac-8bit, --no-dac-8bit
La plupart des cartes Quadro utilisent par défaut une table de consultation de couleurs (LUT) de 10 bits ; la définition de cette option sur TRUE force ces puces graphiques à utiliser une (LUT) de 8 bits.
-d PROFONDEUR, --depth=PROFONDEUR
Définit la profondeur par défaut sur PROFONDEUR ; les valeurs valides pour PROFONDEUR sont 8, 15, 16, 24 et 30.
--device=PÉRIPHÉRIQUE
L'utilitaire nvidia-xconfig opère sur un ou plusieurs périphériques dans le fichier de configuration X. Si cette option est spécifiée, le périphérique nommé PÉRIPHÉRIQUE dans le fichier de configuration X sera utilisé. Si cette option n'est pas spécifiée, tous les périphériques du fichier de configuration X seront utilisés.
--disable-glx-root-clipping, --no-disable-glx-root-clipping
Désactive ou active le rognage racine GLX.

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

Désactive ou active le rognage du rendu OpenGL sur la fenêtre racine via l'option de configuration X "DisableGLXRootClipping".
--damage-events, --no-damage-events
Utilise les événements du système d'exploitation pour notifier le serveur X lorsqu'un client de rendu direct a effectué un rendu qui doit être composé à l'écran. Améliore les performances lors de l'utilisation de GLX avec l'extension composite.
--preserve-driver-name
Par défaut, nvidia-xconfig change le pilote d'affichage en "nvidia" pour tous les écrans X configurés ; cette option préserve le nom de pilote existant de chaque écran X.
--egpu, --no-egpu
Active ou désactive l'option de configuration X "AllowExternalGpus".
-a, --enable-all-gpus
Supprime tous les écrans X existants dans la configuration actuelle, puis configure un écran X sur chaque GPU de votre système.
--exact-mode-timings-dvi, --no-exact-mode-timings-dvi
Force l'initialisation du serveur X avec les temporisations exactes spécifiées dans la Ligne de Mode (ModeLine).
-E FICHIER, --extract-edids-from-file=FICHIER
Extrait tous les blocs d'octets EDID bruts contenus dans le fichier log X spécifié LOG ; les octets EDID bruts sont imprimés par le pilote X NVIDIA dans le log X en hexadécimal lorsque la journalisation détaillée est activée avec l'option de ligne de commande du serveur X "-logverbose 6". Les EDID extraits sont ensuite écrits sous forme de données binaires dans des fichiers individuels. Ces fichiers peuvent ensuite être utilisés par le pilote X NVIDIA via l'option de configuration X "CustomEDID".
--extract-edids-output-file=NOMFICHIER
Lorsque l'option '--extract-edids-from-file' est utilisée, nvidia-xconfig écrit tout EDID extrait dans un fichier, typiquement "edid.bin" dans le répertoire courant. Utilisez cette option pour spécifier un nom de fichier alternatif. Notez que nvidia-xconfig, si nécessaire, ajoutera un numéro unique au nom du fichier EDID, pour éviter d'écraser les fichiers existants (par exemple, "edid.bin.1" si "edid.bin" existe déjà).
--flatpanel-properties=PROPRIETES-PANNEAUPLAT, --no-flatpanel-properties
Définit les propriétés du panneau plat. Les propriétés prises en charge sont 'dithering' et 'ditheringmode'. Veuillez consulter le README NVIDIA 'Annexe B. Options de configuration X' pour plus de détails sur les valeurs possibles et la syntaxe.
--flip, --no-flip
Active ou désactive le retournement OpenGL (OpenGL flipping)
--force-generate
Force la génération d'un nouveau fichier de configuration X, en ignorant tout fichier de configuration X système existant. Ceci n'est généralement pas recommandé, car des éléments tels que le protocole de la souris, la disposition du clavier, les chemins de polices, etc., sont configurés par votre distribution Unix. Bien que nvidia-xconfig puisse tenter d'inférer ces valeurs, il est préférable d'utiliser le fichier de configuration X de votre distribution Unix comme base pour tout ce que nvidia-xconfig crée.
--force-stereo-flipping, --no-force-stereo-flipping
Normalement, le retournement stéréo n'est effectué que lorsqu'un objet visuel stéréo est visible. Cette option force le retournement stéréo même lorsqu'aucun objet visuel stéréo n'est visible.
--handle-special-keys=QUAND, --no-handle-special-keys
Spécifie quand le serveur X doit utiliser le gestionnaire de clavier intégré pour traiter les combinaisons de touches spéciales (telles que Ctrl+Alt+Retour arrière) ; voir la page de manuel de configuration X pour les détails. La valeur de QUAND peut être 'Always', 'Never', ou 'WhenNeeded'.
--include-implicit-metamodes, --no-include-implicit-metamodes
Active ou désactive l'option de configuration X "IncludeImplicitMetaModes".
--keyboard=CLAVIER
Lors de la génération d'un nouveau fichier de configuration X (ce qui se produit lorsqu'aucun fichier de configuration X système n'est trouvé, ou que l'option '--force-generate' est spécifiée), utilise CLAVIER comme type de clavier, plutôt que d'essayer de sonder le système pour connaître le type de clavier. Pour une liste des types de clavier possibles, voir l'option '--keyboard-list'.
--keyboard-driver=PILOTE
Dans la plupart des cas, nvidia-xconfig peut déterminer automatiquement le pilote de clavier correct à utiliser (soit 'kbd' soit 'keyboard'). Utilisez cette option pour remplacer ce que nvidia-xconfig détecte. Généralement, si vous utilisez un serveur X.Org, utilisez 'kdb' ; si vous utilisez un serveur XFree86, utilisez 'keyboard'.
--keyboard-list
Imprime sur la sortie standard les types de clavier disponibles reconnus par l'option '--keyboard', puis quitte.
--layout=AGENCEMENT
L'utilitaire nvidia-xconfig opère sur un Server Layout dans le fichier de configuration X. Si cette option est spécifiée, l'agencement nommé AGENCEMENT dans le fichier de configuration X sera utilisé. Si cette option n'est pas spécifiée, le premier Server Layout dans le fichier de configuration X est utilisé.
--mode=MODE
Ajoute le mode spécifié à la liste des modes.
--mode-debug, --no-mode-debug
Active ou désactive l'option de configuration X "ModeDebug" ; lorsqu'elle est activée, cette option fait en sorte que le pilote X imprime des détails détaillés sur la validation du mode dans le fichier log X.
--mode-list=LISTE-MODES
Supprime tous les modes existants de la liste des modes de la configuration X et ajoute celui ou ceux spécifiés dans la chaîne LISTE-MODES.
--remove-mode=MODE
Supprime le mode spécifié de la liste des modes.
--metamodes=META-MODES
Ajoute l'option de configuration X MetaMode avec la valeur META-MODES, ce qui remplacera toute option MetaMode existante déjà dans le fichier de configuration X.
--mouse=SOURIS
Lors de la génération d'un nouveau fichier de configuration X (ce qui se produit lorsqu'aucun fichier de configuration X système n'est trouvé, ou que l'option '--force-generate' est spécifiée), utilise SOURIS comme type de souris, plutôt que d'essayer de sonder le système pour connaître le type de souris. Pour une liste des types de souris possibles, voir l'option '--mouse-list'.
--mouse-list
Imprime sur la sortie standard les types de souris disponibles reconnus par l'option '--mouse', puis quitte.
--multisample-compatibility, --no-multisample-compatibility
Active ou désactive l'utilisation de tampons multisamples avant et arrière distincts.
--nvidia-cfg-path=CHEMIN
La bibliothèque nvidia-cfg est utilisée pour communiquer avec le module noyau NVIDIA afin d'interroger les propriétés de base de chaque GPU du système. Cette bibliothèque n'est généralement utilisée par nvidia-xconfig que lors de la configuration de plusieurs écrans X. Cette option indique à nvidia-xconfig où chercher cette bibliothèque (au cas où il ne la trouverait pas par lui-même). Cette option ne devrait normalement pas être nécessaire.
--only-one-x-screen
Désactive tous les écrans X sauf un.
--overlay, --no-overlay
Active ou désactive l'option de configuration X "Overlay".
--cioverlay, --no-cioverlay
Active ou désactive l'overlay d'index de couleur.
--overlay-default-visual, --no-overlay-default-visual
Active ou désactive l'option de configuration X "OverlayDefaultVisual".
--transparent-index=INDEX, --no-transparent-index
Pixel à utiliser comme transparent lors de l'utilisation des overlays d'index de couleur. Les valeurs valides pour INDEX-TRANSPARENT sont de 0 à 255.
-T, --post-tree
Semblable à l'option '--tree', mais passe par le processus complet d'application de toutes les mises à jour demandées par l'utilisateur à la configuration X, avant d'imprimer la configuration finale sur la sortie standard sous forme d'arbre. En fait, cette option provoque simplement l'impression de la configuration sur la sortie standard sous forme d'arbre au lieu d'écrire les résultats dans un fichier.
--power-connector-check, --no-power-connector-check
Désactive ou active l'option de configuration X "NoPowerConnectorCheck".
--probe-all-gpus, --no-probe-all-gpus
Désactive ou active l'option de configuration X "ProbeAllGpus".
--query-gpu-info
Imprime des informations sur tous les GPU NVIDIA reconnus dans le système.
--registry-dwords=DWORDS-REGISTRE, --no-registry-dwords
Active ou désactive l'option de configuration X "RegistryDwords".
--render-accel, --no-render-accel
Active ou désactive l'option de configuration X "RenderAccel".
--render-extension, --no-render-extension
Désactive ou active l'option de configuration X "NoRenderExtension".

--allow-hmd=ALLOW-HMD, --no-allow-hmd
Active ou désactive l'option de configuration X "AllowHMD".
--prime, --no-prime
Active PRIME pour le fichier de configuration X généré. Ne peut pas être exécuté avec --no-busid ou --no-allow-empty-initial-configuration. Sur un système avec plus d'un GPU, spécifiez le GPU à utiliser pour PRIME avec --busid ou le premier GPU disponible sera choisi. Notez qu'il est nécessaire d'exécuter "xrandr --setprovideroutputsource modesetting NVIDIA-0" et "xrandr --auto" après l'achèvement pour activer PRIME.

EXEMPLES

nvidia-xconfig
Lit un fichier de configuration X existant et l'adapte pour utiliser le pilote NVIDIA. Si aucun fichier de configuration X ne peut être trouvé, un nouveau est créé à /etc/X11/xorg.conf avec les paramètres par défaut.
nvidia-xconfig --post-tree --metamode-orientation=clone
Lit le fichier de configuration X existant, ajoute l'option MetaModeOrientation et imprime ensuite le fichier de configuration résultant sur la sortie standard sous forme d'arbre. Le fichier de configuration n'est pas modifié.
nvidia-xconfig --enable-all-gpus
Examine le système et configure un écran X pour chaque périphérique d'affichage qu'il trouve.
nvidia-xconfig --mode=1600x1200
Ajoute un mode 1600x1200 à une configuration X existante.
nvidia-xconfig --mode-list=1600x1200 1280x1024
Supprime tous les modes existants du fichier de configuration X, en les remplaçant par "1600x1200" et "1280x1024".
nvidia-xconfig --metamodes=1024x768 +0+0, 1024x768 +1024+0
Ajoute le MetaMode "1024x768 +0+0, 1024x768 +1024+0" à la configuration X existante, en remplaçant toute option de configuration X MetaModes existante.
nvidia-xconfig --only-one-x-screen --sli=Auto
Configure le serveur X pour qu'il ait un seul écran X qui utilisera SLI lorsqu'il sera disponible.
