NOM

nvme-wdc-cap-diag - Récupérer le journal de diagnostic du périphérique WDC et l'enregistrer dans un fichier.

SYNOPIS

nvme wdc cap-diag <périphérique> [--output-file=<FICHIER>, -o <FICHIER>] [--transfer-size=<TAILLE>, -s <TAILLE>]

DESCRIPTION

Pour le périphérique NVMe donné, envoie la requête WDC Vendor Unique Capture-Diagnostics et enregistre le résultat dans un fichier.

Le paramètre <périphérique> est le périphérique caractère NVMe obligatoire (ex : /dev/nvme0).

Cela ne fonctionnera que sur les périphériques WDC prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

OPTIONS

-o <FICHIER>, --output-file=<FICHIER>

Fichier de sortie ; par défaut, le numéro de série du périphérique suivi du suffixe "cap_diag"

-s <TAILLE>, --transfer-size=<TAILLE>

Taille de transfert ; par défaut, 0x10000 (65536 décimal) octets

EXEMPLES

• Obtient le journal de diagnostic de capture du périphérique et l'enregistre dans un fichier par défaut dans le répertoire courant (par ex. STM00019F3F9cap_diag.bin) : 
# nvme wdc cap-diag /dev/nvme0
• Obtient le journal de diagnostic de capture du périphérique et l'enregistre dans un fichier défini dans le répertoire courant (par ex. testSTM00019F3F9cap_diag.bin) : 
# nvme wdc cap-diag /dev/nvme0 -o test
• Obtient le journal de diagnostic de capture du périphérique et l'enregistre dans un fichier défini avec un chemin (par ex. /tmp/testSTM00019F3F9cap_diag.bin) : 
# nvme wdc cap-diag /dev/nvme0 -o /tmp/test
• Obtient le journal de diagnostic de capture du périphérique en transférant les données par blocs de 64 Ko et l'enregistre dans un fichier par défaut dans le répertoire courant (par ex. STM00019F3F9internal_fw_log.bin) : 
# nvme wdc cap-diag /dev/nvme0 -s 0x10000
• Obtient le journal de diagnostic de capture du périphérique en transférant les données par blocs de 16 Ko et l'enregistre dans un fichier par défaut dans le répertoire courant (par ex. STM00019F3F9internal_fw_log.bin) : 
# nvme wdc cap-diag /dev/nvme0 -s 16384
