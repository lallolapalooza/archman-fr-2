NOM

nvme-resv-release - Libérer une réservation nvme

SYNTAXE

nvme resv-release <périphérique> [--namespace-id=<nsid> | -n <nsid>]
                        [--crkey=<crkey> | -c <crkey>]
                        [--rtype=<rtype> | -t <rtype>]
                        [--rrela=<rrela> | -a <rrela>] [--iekey | -i]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout>]

DESCRIPTION

La commande de libération de réservation est utilisée pour libérer ou effacer une réservation détenue sur un espace de noms.

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Remplace le champ nsid. Si vous utilisez le périphérique caractère admin, ce paramètre est obligatoire.

-c <crkey>, --crkey=<crkey>

Clé de Réservation Actuelle : Si l'Action d'Enregistrement de Réservation est 001b (c'est-à-dire, Clé de Réservation Non Enregistrée) ou 010b (c'est-à-dire, Remplacer Clé de Réservation), alors ce champ contient la clé de réservation actuelle associée à l'hôte. Pour toutes les autres valeurs d'Action d'Enregistrement de Réservation, ce champ est réservé. Le contrôleur ignore la valeur de ce champ lorsque le bit Ignorer Clé Existante (IEKEY) est défini à ‘1’.

-t <rtype>, --rtype=<rtype>

Type de Réservation : Ce champ spécifie le type de réservation à créer.
Valeur Définition
0h Réservé
1h Réservation d'Écriture Exclusive
2h Réservation d'Accès Exclusif
3h Réservation d'Écriture Exclusive - Enregistrants Seulement
4h Réservation d'Accès Exclusif - Enregistrants Seulement
5h Réservation d'Écriture Exclusive - Tous les Enregistrants
6h Réservation d'Accès Exclusif - Tous les Enregistrants
07h-FFh Réservé

-a <rrela>, --rrela=<rrela>

Action de Libération de Réservation : Ce champ spécifie l'action d'enregistrement effectuée par la commande.
Valeur Définition
0 Libérer
1 Effacer
2-7 Réservé

-i, --iekey

Ignorer Clé Existante : Si ce bit est défini à 1, alors la vérification de la Clé de Réservation Actuelle (CRKEY) est désactivée et la commande réussira indépendamment de la valeur du champ CRKEY.

Option indicateur, par défaut à 0.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport à normal, json ou binaire. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le détail de l'information dans la sortie.

--timeout=<timeout>

Remplace la valeur de délai d'attente par défaut. En millisecondes.
