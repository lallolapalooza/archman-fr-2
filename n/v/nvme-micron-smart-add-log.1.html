NOM

nvme-micron-smart-add-log - Récupère les statistiques NAND (disques modèle 2200) ou les informations SMART étendues (modèles conformes OCP) du périphérique micron donné

SYNTAXE

nvme micron vs-smart-add-log <périphérique> -f <json|normal>

DESCRIPTION

Cette commande affiche les informations NAND (Octets totaux écrits, Nombre de blocs défectueux et Échecs d'effacement, etc.) pour le périphérique micron donné s'il s'agit d'un contrôleur de modèle 2200. Pour les contrôleurs conformes OCP, cette commande affiche les données de santé SMART étendues ainsi que les informations NAND (si disponibles).

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (par ex. : /dev/nvme0), soit un périphérique bloc de l'espace de noms (par ex. : /dev/nvme0n1).

L'option -f contrôle le format de sortie des données affichées en fonction de la valeur de l'option. Si la valeur de l'option est json (activée par défaut), les données de sortie sont affichées au format JSON. Si la valeur de l'option est normal, la sortie est affichée au format non-JSON.

Ceci ne fonctionnera que sur les périphériques Micron des numéros de modèle 54XX et les contrôleurs conformes OCP. Le support pour de nouveaux périphériques peut être ajouté ultérieurement.

OPTIONS

-f <json|normal>

Contrôle le format de la sortie affichée.

EXEMPLES

•Récupère les données NAND/SMART étendues et les affiche au format json 
# nvme micron vs-nand-stats /dev/nvme0
* Récupère les données NAND/SMART étendues et les affiche au format non-json
+

# nvme micron vs-nand-stats /dev/nvme0 -f normal
