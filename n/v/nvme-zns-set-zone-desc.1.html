NOM

nvme-zns-set-zone-desc - Définir les données du descripteur étendu pour une zone

SYNOPIS

nvme zns set-zone-desc <périphérique> [--namespace-id=<NUM> | -n <NUM>]
                        [--start-lba=<IONUM>, -s <IONUM>]
                        [--zrwaa | -r]
                        [--data=<FICHIER>, -d <FICHIER>]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPTION

Pour le périphérique NVMe donné, émet la commande Zone Management Send avec l'action Set Zone Descriptor Extensions. Les données d'entrée proviendront par défaut de stdin. Alternativement, les données peuvent provenir d'un fichier qui peut être spécifié. La longueur des données sera automatiquement calculée à partir de l'espace de noms zns identify.

OPTIONS

-n <NUM>, --namespace-id=<NUM>

Utilise l'identifiant d'espace de noms fourni pour la commande. S'il n'est pas fourni, l'identifiant d'espace de noms du périphérique bloc sera utilisé. Si la commande est émise vers un périphérique non bloc, le paramètre est requis.

-s <lba>, --start-lba=<lba>

Le LBA de départ de la zone à gérer par send.

-r, --zrwaa

Alloue la zone d'écriture aléatoire (Zone Random Write Area) à la zone.

-d <FICHIER>, --data=<FICHIER>

Fichier optionnel pour les données (stdin par défaut)

-t <timeout>, --timeout=<timeout>

Remplace la valeur de délai d'attente par défaut. En millisecondes.

EXEMPLES

•Écrit "hello world" dans le descripteur de zone pour la première zone de l'espace de noms 1 (nécessite que le périphérique supporte des données étendues de zone suffisamment grandes) 
# echo "hello world" | nvme zns set-zone-desc /dev/nvme0 -n 1 -s 0
