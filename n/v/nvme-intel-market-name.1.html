NOM

nvme-intel-market-name - Envoie la commande NVMe Identify Controller, retourne le résultat et la structure

SYNTAXE

nvme intel market-name <périphérique> [--raw-binary | -b]

DESCRIPTION

Pour le périphérique NVMe donné, récupère la page de journal spécifique au fournisseur Intel pour le nom commercial et fournit le résultat et la structure retournée. La sortie est simplement le nom commercial utilisé pour identifier le type de périphérique.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

En cas de succès, la structure peut être retournée de plusieurs manières selon les indicateurs d'options ; la structure peut être analysée par le programme ou le tampon brut peut être imprimé sur la sortie standard.

OPTIONS

-b, --raw-binary

Imprime le tampon brut sur la sortie standard. La structure n'est pas analysée par le programme. Ceci remplace les options spécifiques au fournisseur et lisibles par l'homme.

EXEMPLES

•Obtenir le nom commercial 
# nvme intel market-name /dev/nvme0
