NOM

nvme-sndk-vs-internal-log - Récupérer le journal interne du firmware du périphérique sndk et l'enregistrer dans un fichier.

SYNTAXE

nvme sndk vs-internal-log <périphérique> [--output-file=<FICHIER>, -o <FICHIER>]
                        [--transfer-size=<TAILLE>, -s <TAILLE>]
                        [--data-area=<ZONE DE DONNÉES>, -d <ZONE_DE_DONNÉES>]
                        [--file-size=<TAILLE FICHIER>, -f <TAILLE_FICHIER>]
                        [--offset=<DÉCALAGE>, -e <DÉCALAGE>]
                        [--type=<TYPE>, -t <type>] [--verbose, -v]

DESCRIPTION

Pour le périphérique NVMe donné, envoie la requête de journal interne spécifique au vendeur sndk et enregistre le résultat dans un fichier.

Le paramètre <périphérique> est un périphérique caractère NVMe obligatoire (ex: /dev/nvme0).

Ceci ne fonctionnera que sur les périphériques Sandisk prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

OPTIONS

-o <FICHIER>, --output-file=<FICHIER>

Fichier de sortie ; par défaut, le numéro de série du périphérique suivi du suffixe « internal_fw_log<date>_<heure>.bin »

-s <TAILLE>, --transfer-size=<TAILLE>

Taille de transfert ; par défaut, 0x10000 (65536 décimal) octets

-d <ZONE DE DONNÉES>, --data-area=<ZONE DE DONNÉES>

Zone de données DUI à récupérer. Les zones de données DUI de 1 à <ZONE DE DONNÉES> seront récupérées. Ce paramètre n'est actuellement pris en charge que sur les périphériques SN340, SN640, SN730 et SN840.

-f <TAILLE FICHIER>, --file-size=<TAILLE FICHIER>

Spécifie la taille souhaitée du fichier de données commençant au décalage fourni. Ceci permet à l'utilisateur de récupérer les données en plusieurs petits fichiers de la taille spécifiée. Ce paramètre n'est actuellement pris en charge que sur le périphérique SN340.

-e <DÉCALAGE>, --offset=<DÉCALAGE>

Spécifie le décalage de données à partir duquel commencer la récupération des données. Ce paramètre est utilisé en combinaison avec le paramètre de taille de fichier pour récupérer les données en plusieurs petits fichiers. Ce paramètre n'est actuellement pris en charge que sur le périphérique SN340.

-t <TYPE>, --type=<TYPE>

Spécifie le type de télémétrie - NONE, HOST, ou CONTROLLER. Ce paramètre est utilisé pour obtenir la page de journal de télémétrie générée par l'hôte ou initiée par le contrôleur. S'il n'est pas spécifié ou si 'none' est spécifié, la commande retournera les données du journal E6 par défaut. Ce paramètre n'est actuellement pris en charge que sur les périphériques SN640 et SN840.

-v <VERBEUX>, --verbose=<VERBEUX>

Fournit des messages de débogage supplémentaires pour certains disques.

EXEMPLES

• Obtient le journal interne du firmware du périphérique et l'enregistre dans un fichier par défaut dans le répertoire courant (par exemple STM00019F3F9_internal_fw_log_20171127_095704.bin) : 
# nvme sndk vs-internal-log /dev/nvme0
• Obtient le journal interne du firmware du périphérique et l'enregistre dans un fichier défini dans le répertoire courant (par exemple test.bin) : 
# nvme sndk vs-internal-log /dev/nvme0 -o test.bin
• Obtient le journal interne du firmware du périphérique et l'enregistre dans un fichier avec chemin d'accès (par exemple /tmp/test) : 
# nvme sndk vs-internal-log /dev/nvme0 -o /tmp/test
• Obtient le journal interne du firmware du périphérique en transférant les données par blocs de 64 Ko et l'enregistre dans un fichier par défaut dans le répertoire courant (par exemple STM00019F3F9_internal_fw_log_20171127_100754.bin) : 
# nvme sndk vs-internal-log /dev/nvme0 -s 0x10000
• Obtient le journal interne du firmware du périphérique en transférant les données par blocs de 16 Ko et l'enregistre dans un fichier par défaut dans le répertoire courant (par exemple STM00019F3F9_internal_fw_log_20171127_100950.bin) : 
# nvme sndk vs-internal-log /dev/nvme0 -s 16384
• Obtient le journal interne du firmware jusqu'à la zone de données 3 du périphérique en 3 fichiers de 0x1000000 octets : 
# nvme sndk vs-internal-log /dev/nvme0 -d 3 -f 0x1000000 -t 0x0000000 -o /tmp/sn340_dui_data_1.bin
# nvme sndk vs-internal-log /dev/nvme0 -d 3 -f 0x1000000 -t 0x1000000 -o /tmp/sn340_dui_data_2.bin
# nvme sndk vs-internal-log /dev/nvme0 -d 3 -f 0x1000000 -t 0x2000000 -o /tmp/sn340_dui_data_3.bin
• Obtient la page de journal de télémétrie de l'hôte jusqu'à la zone de données 3 du périphérique et la stocke dans le fichier host-telem-log-da3.bin : 
# nvme sndk vs-internal-log /dev/nvme1 -t host -o host-telem-log-da3.bin -d 3
• Obtient la page de journal de télémétrie du contrôleur jusqu'à la zone de données 3 du périphérique et la stocke dans le fichier ctlr-telem-log-da3.bin : 
# nvme sndk vs-internal-log /dev/nvme1 -t controller -o ctlr-telem-log-da3.bin -d 3
