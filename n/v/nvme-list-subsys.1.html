NOM

nvme-list-subsys - Lister tous les sous-systèmes NVMe

SYNTAXE

nvme list-subsys <appareil> [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Analyse l'arborescence sysfs pour les sous-systèmes NVM Express et renvoie les contrôleurs de ces sous-systèmes ainsi que des informations pertinentes à leur sujet. Si un appareil est spécifié, n'afficher que les valeurs pour les contrôleurs et les sous-systèmes menant à l'appareil.

OPTIONS

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

root@host[1]# nvme list-subsys
nvme-subsys0 - NQN=nvmf-test
\
 +- nvme0 rdma traddr=1.1.1.3,trsvcid=4420,host_traddr=1.1.1.1
 +- nvme1 rdma traddr=1.1.1.3,trsvcid=4420,host_traddr=1.1.1.2
nvme-subsys1 - NQN=nvmf-test2
\
 +- nvme2 rdma traddr=1.1.1.3,trsvcid=4420,host_traddr=1.1.1.2
 +- nvme3 rdma traddr=1.1.1.3,trsvcid=4420,host_traddr=1.1.1.1
