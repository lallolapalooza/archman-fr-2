NOM

nvme-id-ctrl - Envoie une commande NVMe Identify Controller, renvoie le résultat et la structure.

SYNTAXE

nvme id-ctrl <périphérique> [--vendor-specific | -V] [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande identify controller et fournit le résultat et la structure renvoyée.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

En cas de succès, la structure peut être renvoyée de plusieurs manières selon les options ; la structure peut être analysée par le programme ou le tampon brut peut être imprimé sur stdout.

OPTIONS

-b, --raw-binary

Imprime le tampon brut sur stdout. La structure n'est pas analysée par le programme. Ceci remplace les options vendor specific et human readable.

-V, --vendor-specific

En plus de l'analyse des champs connus, cette option affiche la région spécifique au vendeur de la structure en hexadécimal avec interprétation ASCII.

-H, --human-readable

Cette option analyse et formate plusieurs champs de bits en formats lisibles par l'homme.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport à normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

•Demande au programme d'interpréter le tampon renvoyé et d'afficher les champs connus dans un format lisible par l'homme : 
# nvme id-ctrl /dev/nvme0
•En plus d'afficher les champs connus, demande au programme d'afficher le champ spécifique au vendeur : 
# nvme id-ctrl /dev/nvme0 --vendor-specific
# nvme id-ctrl /dev/nvme0 -V

Ce qui précède affichera le tampon vs en hexadécimal car il ne sait pas comment l'interpréter.

•Demande au programme de renvoyer la structure brute en binaire : 
# nvme id-ctrl /dev/nvme0 --raw-binary > id_ctrl.raw
# nvme id-ctrl /dev/nvme0 -b > id_ctrl.raw

Il est probablement déconseillé de ne pas rediriger stdout lors de l'utilisation de ce mode.

•Alternativement, vous pourriez vouloir envoyer les données à un autre programme capable d'analyser le tampon brut. 
# nvme id-ctrl /dev/nvme0 --raw-binary | nvme_parse_id_ctrl

Le programme d'analyse dans l'exemple ci-dessus peut être un programme qui affiche la structure de la manière que vous souhaitez. Le programme suivant en est un exemple qui l'analysera et peut accepter la sortie via un pipe, '|', comme indiqué dans l'exemple ci-dessus, ou vous pouvez 'cat' un tampon de sortie enregistré vers celui-ci.

/* Fichier : nvme_parse_id_ctrl.c */
#include <linux/nvme.h>
#include <stdio.h>
#include <unistd.h>
int main(int argc, char **argv)
{
        unsigned char buf[sizeof(struct nvme_id_ctrl)];
        struct nvme_id_ctrl *ctrl = (struct nvme_id_ctrl *)buf;
        if (read(STDIN_FILENO, buf, sizeof(buf)))
                return 1;
        printf("vid   : %#x\n", ctrl->vid);
        printf("ssvid : %#x\n", ctrl->ssvid);
        return 0;
}
