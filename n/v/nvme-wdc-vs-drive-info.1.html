NOM

nvme-wdc-vs-drive-info - Envoie la commande NVMe WDC vs-drive-info, retourne le résultat

SYNTAXE

nvme wdc vs-drive-info <périphérique>

DESCRIPTION

Pour le périphérique NVMe donné, envoie la commande WDC vs-drive-info unique et fournit les informations supplémentaires sur le disque.

Le paramètre <périphérique> est obligatoire et doit être le périphérique caractère NVMe (ex: /dev/nvme0).

Cela ne fonctionnera que sur les périphériques WDC supportant cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, retourne 0, sinon un code d'erreur.

EXPLICATION DES SORTIES

Il y a plusieurs champs différents retournés par cette commande en fonction du disque :

Révision matérielle du disque

Taille de l'unité FTL

Numéro de série client

Version du démarrage HyperScale

Propriété de l'appareil TCG

EXEMPLE

# nvme wdc vs-drive-info /dev/nvme0

NVME

Fait partie de la suite nvme-user.
