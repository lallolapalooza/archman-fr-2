NOM

nvme-zns-zone-append - Envoie une commande d'écriture NVMe, fournit les résultats

SYNTAXE

nvme-zns-zone-append <périphérique> [--namespace-id=<NOMBRE> | -n <NOMBRE>]
                                [--zslba=<NOMBRE_IO> | -s <NOMBRE_IO>]
                                [--data-size=<NOMBRE_IO> | -z <NOMBRE_IO>]
                                [--metadata-size=<NOMBRE_IO> | -y <NOMBRE_IO>]
                                [--data=<FICHIER> | -d <FICHIER>]
                                [--metadata=<FICHIER> | -M <FICHIER>]
                                [--limited-retry | -l]
                                [--force-unit-access | -f]
                                [--ref-tag=<NOMBRE> | -r <NOMBRE>]
                                [--app-tag-mask=<NOMBRE> | -m <NOMBRE>]
                                [--app-tag=<NOMBRE> | -a <NOMBRE>]
                                [--prinfo=<NOMBRE> | -p <NOMBRE>]

DESCRIPTION

La commande zone append écrit les blocs logiques spécifiés par la commande dans le support à partir du tampon de données fourni. Elle utilisera l'entrée standard par défaut si vous ne fournissez pas de fichier.

En cas de succès, le programme rapportera le LBA qui a été attribué aux données pour l'opération d'ajout.

OPTIONS

-n <NOMBRE>, --namespace-id=<NOMBRE>

Utilise l'identifiant de namespace fourni pour la commande. Si non fourni, l'identifiant de namespace du périphérique bloc sera utilisé. Si la commande est émise vers un périphérique autre qu'un périphérique bloc, le paramètre est requis.

-s <NOMBRE_IO>, --zslba=<NOMBRE_IO>, -z <NOMBRE_IO>, --data-size=<NOMBRE_IO>

Taille des données, en octets.

-y <NOMBRE_IO>, --metadata-size=<NOMBRE_IO>

Taille des métadonnées en octets.

-d <FICHIER>, --data=<FICHIER>

Fichier de données fournissant les données à écrire. Si aucun n'est fourni, le contenu est envoyé depuis STDIN.

-M <FICHIER>, --metadata=<FICHIER>

Fichier de métadonnées, si nécessaire.

-l, --limited-retry

Définit le drapeau de nouvelle tentative limitée.

-f, --force-unit-access

Définit le drapeau de forçage d'accès à l'unité.

-r <NOMBRE>, --ref-tag=<NOMBRE>

Reftag optionnel lors de l'utilisation des informations de protection.

-m <NOMBRE>, --app-tag-mask=<NOMBRE>

Masque de balise d'application optionnel lors de l'utilisation des informations de protection.

-a <NOMBRE>, --app-tag=<NOMBRE>

Balise d'application optionnelle lors de l'utilisation des informations de protection.

-p <NOMBRE>, --prinfo=<NOMBRE>

Définition du champ Protection Information.

EXEMPLES

•Ajouter les données "hello world" dans 4 Ko de blocs dans la zone commençant au bloc 0 pour le namespace 1 : 
# echo "hello world" | nvme zns zone-append /dev/nvme0 -n 1 -s 0 -z 4k
