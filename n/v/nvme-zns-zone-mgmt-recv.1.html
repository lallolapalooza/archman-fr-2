NOM

nvme-zns-zone-mgmt-recv - Commande de réception de gestion de zone

SYNTAXE

nvme zns zone-mgmt-recv <périphérique> [--namespace-id=<NUM> | -n <NUM>]
                        [--start-lba=<LBA> | -s <LBA>]
                        [--data-len=<NUM_IO> | -l <NUM_IO>]
                        [--zra=<NUM> | -z <NUM>] [--zrasf=<NUM> | -a <NUM>]
                        [--zra-spec-feat | -f] [--output-format=<fmt> | -o <fmt>]

DESCRIPTION

Pour le périphérique NVMe donné, émet la commande de réception de gestion de zone avec l'action de réception demandée et les paramètres supplémentaires spécifiques à l'action. Il s'agit de l'interface générique fournie pour une compatibilité ascendante à mesure que de nouvelles actions sont créées et dont ce programme n'est pas conscient au moment de son développement. En tant que tel, il s'agit d'une commande générique qui ne procède à aucun décodage supplémentaire pour des types spécifiques de données reçues. Elle ne fera que rapporter les données sous forme de vidage hexadécimal ou binaire.

OPTIONS

-n <NUM>, --namespace-id=<NUM>

Utilise l'identifiant de l'espace de noms fourni pour la commande. S'il n'est pas fourni, l'identifiant de l'espace de noms du périphérique bloc sera utilisé. Si la commande est émise vers un périphérique non bloc, le paramètre est requis.

-s <lba>, --start-lba=<lba>

Le LBA de départ de la zone à gérer pour la réception.

-l <NUM> --data-len=<NUM> Longueur du tampon de données reçues.

-z <NUM>, --zra=<NUM>

Action de réception de zone.

-a <NUM> --zrasf=<NUM> Champ spécifique de l'action de réception de zone.

-f, --zra-spec-feat

Active les fonctionnalités spécifiques à l'action de réception de zone.

-o <fmt>, --output-format=<fmt>

Format de sortie : normal|json|binary.

EXEMPLES

• Vidage hexadécimal de tous les rapports de zones 
# nvme zns zone-mgmt-recv /dev/nvme0 -n 1 -s 0 -z 0 -a 0 -l 4k
• Vidage binaire de tous les rapports de zones 
# nvme zns zone-mgmt-recv /dev/nvme0 -n 1 -s 0 -z 0 -a 0 -o -l 4k binary > report.out
