NOM

nvme-toshiba-clear-pcie-correctable-errors - Réinitialise à zéro le compteur d'erreurs corrigeables PCIe.

SYNTAXE

'nvme toshiba clear-pcie-correctable-errors ' <périphérique>

DESCRIPTION

Pour le périphérique NVMe donné, envoie la requête Toshiba de réinitialisation des erreurs corrigeables PCIe.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de l'espace de noms (ex: /dev/nvme0n1).

EXEMPLES

•Réinitialise le compteur d'erreurs corrigeables PCIe : 
# nvme toshiba clear-pcie-correctable-errors /dev/nvme0
