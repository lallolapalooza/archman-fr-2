NOM

nvme-micron-pcie-stats - Récupère les statistiques d'erreurs pcie pour un appareil micron donné

SYNOPIS

nvme micron vs-pcie-stats <appareil>

DESCRIPTION

Cette commande affiche les informations sur les erreurs corrigeables et incorrigibles pcie pour l'appareil micron donné.

Le paramètre <appareil> est obligatoire et peut être soit le périphérique caractère NVMe (ex : /dev/nvme0), soit un périphérique bloc de namespace (ex : /dev/nvme0n1).

Ceci ne fonctionnera que sur les appareils Micron des numéros de modèle 54XX. Le support pour de nouveaux appareils pourrait être ajouté ultérieurement.

OPTIONS

Aucune

EXEMPLES

•Récupérer les informations d'erreur PCIe 
# nvme micron vs-pcie-stats /dev/nvme0
