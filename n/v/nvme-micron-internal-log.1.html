NOM

nvme-micron-internal-log - Récupérer les journaux internes du périphérique Micron et les enregistrer dans un fichier zip donné.

SYNTAXE

nvme micron vs-internal-log <périphérique> [--package=<FICHIER>, -p <FICHIER>]

DESCRIPTION

Pour le périphérique NVMe donné, envoie les commandes spécifiques au vendeur Micron pour récupérer divers journaux (au format binaire), les compresse et les enregistre dans le fichier zip spécifié. Ces journaux uniques au vendeur peuvent être analysés par l'équipe de support technique Micron pour tout problème spécifique au périphérique.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

Ceci ne fonctionnera que sur les périphériques Micron dont les numéros de modèle sont 9200 et 54XX. Le support pour de nouveaux périphériques pourra être ajouté ultérieurement. Les résultats pour tout autre périphérique sont indéfinis.

OPTIONS

-l <FICHIER>, --package=<FICHIER>

nom du fichier (avec extension .zip) où enregistrer les journaux du périphérique

EXEMPLES

• Récupère les journaux du périphérique et les enregistre dans le fichier micron_logs.zip 
# nvme micron vs-internal-log /dev/nvme0 --package=micron_logs.zip
