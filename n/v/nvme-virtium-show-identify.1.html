NOM

nvme-virtium-show-identify - Afficher des détails complets sur les informations d'identification du périphérique au format json.

SYNOPIS

nvme virtium show-identify <périphérique>

DESCRIPTION

Cette commande affiche les détails complets des informations d'identification du périphérique. Les détails incluent les paramètres et la description de chaque fonctionnalité. Les descriptions sont basées sur la spécification NVM Express Révision 1.3c.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (par ex. : /dev/nvme0), soit un périphérique bloc d'espace de noms (par ex. : /dev/nvme0n1).

En cas de succès, la commande affiche l'identification du périphérique dans un format lisible par l'homme.

OPTIONS

aucune

EXEMPLES

•Afficher l'identification du périphérique : 
# nvme virtium show-identify /dev/nvme0n1

NVME

Fait partie de la suite nvme-user
