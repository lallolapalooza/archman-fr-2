NOM

nvme-fdp-feature - Afficher ou modifier la fonctionnalité Flexible Data Placement (FDP)

SYNTAXE

nvme fdp <périphérique> [--endgrp-id=<NUM> | -e <NUM>]
                [--enable-conf-idx=<NUM> | -c <NUM>]
                [--disable | -d]
                [--verbose | -v]

DESCRIPTION

Pour le périphérique NVMe donné, configurez et gérez la fonctionnalité Flexible Data Placement (FDP).

Cette commande peut être utilisée pour afficher la configuration actuelle de la fonctionnalité FDP ou pour la modifier.

 Si aucune option `--enable-conf-idx` ou `--disable` n'est fournie, la configuration actuelle est
 affichée.

Si les options `--enable-conf-idx` ou `--disable` sont fournies, la configuration est modifiée en conséquence. Le périphérique peut refuser le changement s'il existe un espace de noms.

Le paramètre <périphérique> est obligatoire et doit être un périphérique caractère NVMe (ex: /dev/nvme0).

OPTIONS

-e <NUM>, --endgrp-id=<NUM>

Spécifie l'ID du groupe d'endurance. Cette option est obligatoire si le périphérique prend en charge les groupes d'endurance.

-c <NUM>, --enable-conf-idx=<NUM>

Active la fonctionnalité FDP avec la configuration spécifiée. L'index de configuration correspond à la position indiquée par nvme-fdp-config(1).

-d, --disable

Désactive la configuration actuelle de la fonctionnalité FDP.

-v, --verbose

Augmente le niveau de verbosité de la sortie.

VOIR AUSSI

nvme-list-endgrp(1) nvme-fdp-config(1)
