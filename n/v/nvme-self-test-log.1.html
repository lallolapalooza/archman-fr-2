NOM

nvme-self-test-log - Récupère les informations de journal initiées par le test d'auto-diagnostic du périphérique et les affiche.

SYNTAXE

nvme self-test-log <périphérique> [--log-entries=<entrées> | -e <entrées>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Récupère les pages de journalisation d'un périphérique NVMe correspondant au test d'auto-diagnostic demandé par l'utilisateur et fournit les 20 structures de résultats les plus récentes.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc d'espace de noms (ex: /dev/nvme0n1).

En cas de succès, la structure de journalisation retournée peut être renvoyée de plusieurs manières selon les options ; la structure peut être analysée par le programme et imprimée dans un format lisible, ou le tampon brut, ou le format JSON.

Par défaut, le journal est imprimé dans le format lisible normal.

OPTION

-e <entrées>, --log-entries=<entrées>

Spécifie combien d'entrées de journal DST le programme doit demander au périphérique. Ce nombre doit être au moins de un et ne doit pas dépasser 20 entrées. Par défaut, 20 entrées de journal DST.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport à normal, json ou binaire. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le détail des informations dans la sortie.

EXEMPLES

•Obtenir le journal d'auto-diagnostic et l'imprimer dans un format lisible par l'homme : 
# nvme self-test-log /dev/nvme0
•Imprimer la sortie brute dans un fichier : 
# nvme self-test-log /dev/nvme0 -o "binaire"
•Obtenir le journal d'auto-diagnostic et l'imprimer au format JSON : 
# nvme self-test-log /dev/nvme0 -o "json"
