NOM

nvme-tls-key - Gérer les clés PSK NVMe TLS

SYNTAXE

nvme tls-key [--keyring=<nom> | -k <nom>]
                        [--keytype=<type> | -t <type>]
                        [--keyfile=<fichier> | -f <fichier>]
                        [--import | -i] [--export | -e]
                        [--revoke=<description>| -r <description>]
                        [--verbose | -v]

DESCRIPTION

Importe, exporte ou supprime les clés pré-partagées (PSK) NVMe TLS du magasin de clés système. Lorsque l'option --export est spécifiée, toutes les clés PSK NVMe TLS sont exportées sous la forme

<descriptions> <psk>

où <description> est la description de la clé exportée et <psk> est la donnée de clé au format d'échange PSK NVMeTLSkey-1:01:<donnée encodée en base64>:. Chaque clé est exportée sur une seule ligne. Lorsque l'option --import est spécifiée, les données de clé sont lues dans le même format et importées dans le magasin de clés du noyau.

OPTIONS

-k <nom>, --keyring=<nom>

Nom du keyring dans lequel la clé TLS conservée doit être stockée. La valeur par défaut est .nvme.

-t <type>, --keytype=<type>

Type de la clé pour la clé TLS résultante. La valeur par défaut est psk.

-f <fichier>, --keyfile=<fichier>

Fichier à lire les clés depuis ou à écrire les clés vers au lieu de stdin / stdout.

-i, --import

Lit les données de clé depuis le fichier spécifié par --keyfile ou depuis stdin si absent.

-e, --export

Écrit les données de clé dans le fichier spécifié par --keyfile ou sur stdout si absent.

-r <description>, --revoke=<description>

Révoque une clé d'un keyring.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

•Crée une nouvelle clé TLS et l'insère directement dans le keyring .nvme: 
# nvme gen-tls-key -i -n hostnqn0 -c subsys0
NVMeTLSkey-1:01:/b9tVz2OXJVISnoFgrPAygyS86XYJWkAapQeULns6PMpM8wv:
Inserted TLS key 26b3260e
•Exporte la clé précédemment créée depuis le keyring du noyau et la stocke dans un fichier 
# nvme tls-key -e -f nvme-tls-keys.txt
•Exporte/liste toutes les clés du keyring .nvme en utilisant nvme et keyctl 
# nvme tls-key --export
NVMe0R01 hostnqn0 subsys0 NVMeTLSkey-1:01:/b9tVz2OXJVISnoFgrPAygyS86XYJWkAapQeULns6PMpM8wv:
# keyctl show
Session Keyring
 573249525 --alswrv      0     0  keyring: _ses
 353599402 --alswrv      0 65534   \_ keyring: _uid.0
 475911922 ---lswrv      0     0   \_ keyring: .nvme
 649274894 --als-rv      0     0       \_ psk: NVMe0R01 hostnqn0 subsys0
•Révoque une clé en utilisant sa description et vérifie l'opération avec keyctl 
# nvme tls-key --revoke="NVMe0R01 hostnqn0 subsys0"
# keyctl show
Session Keyring
 573249525 --alswrv      0     0  keyring: _ses
 353599402 --alswrv      0 65534   \_ keyring: _uid.0
 475911922 ---lswrv      0     0   \_ keyring: .nvme
649274894: key inaccessible (Key has been revoked)
•Importe à nouveau la clé générée précédemment depuis un fichier et vérifie avec keyctl 
# nvme tls-key --import -f nvme-tls-keys.txt
# keyctl show
Session Keyring

 353599402 --alswrv      0 65534   \_ keyring: _uid.0
 475911922 ---lswrv      0     0   \_ keyring: .nvme
