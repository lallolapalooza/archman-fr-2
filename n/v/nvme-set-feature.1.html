NVME-SET-FEATURE(1) Manuel NVMe NVME-SET-FEATURE(1)

NOM

nvme-set-feature - Définit une fonctionnalité NVMe, retourne les résultats applicables

SYNTAXE

nvme set-feature <périphérique> [--namespace-id=<nsid> | -n <nsid>]
                        [--feature-id=<fid> | -f <fid>] [--value=<valeur> | -V <valeur>]
                        [--uuid-index=<index-uuid> | -U <index_uuid>]
                        [--data-len=<longueur-donnees> | -l <longueur-donnees>]
                        [--data=<fichier-donnees> | -d <fichier-donnees>] [--save | -s]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--cdw12=<cdw12> | -c <cdw12>]
                        [--timeout=<délai> | -t <délai>]

DESCRIPTION

Soumet une commande d'administration NVMe Set Feature et retourne les résultats applicables. Il peut s'agir de la valeur de la fonctionnalité, ou peut également inclure une structure de fonctionnalité si la fonctionnalité l'exige (par ex : Type de plage LBA).

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (par ex. /dev/nvme0), soit un périphérique bloc de l'espace de noms (par ex. /dev/nvme0n1).

En cas de succès, la valeur envoyée au périphérique est affichée.

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Définit la fonctionnalité pour le nsid donné. Ceci est facultatif et la plupart des fonctionnalités n'utilisent pas cette valeur.

-f <fid>, --feature-id=<fid>

L'identifiant de fonctionnalité à envoyer avec la commande. La valeur fournie doit être en hexadécimal.

-l <longueur-donnees>, --data-len=<longueur-donnees>

La longueur des données pour le tampon soumis pour cette fonctionnalité. La plupart des fonctionnalités connues n'utilisent pas cette valeur. Les exceptions sont le Type de plage LBA et l'identifiant de l'hôte.

-d <fichier-donnees>, --data=<fichier-donnees>

Le fichier de données pour le tampon soumis pour cette fonctionnalité. La plupart des fonctionnalités connues n'utilisent pas cette valeur. Les exceptions sont le Type de plage LBA et l'identifiant de l'hôte. Ceci est par défaut STDIN, donc les fichiers et les commandes echo peuvent être pipés.

-V <valeur>, --value=<valeur>

La valeur pour le mot de commande 11, la valeur à laquelle vous souhaitez définir la fonctionnalité.

-s, --save

Enregistre l'attribut afin qu'il persiste à travers tous les états d'alimentation et les réinitialisations.

nvme-set-feature(1) — Arch Linux

NOM

nvme-set-feature — Interroger ou définir une caractéristique d'un contrôleur NVMe

SYNOPIS

DESCRIPTION

La commande nvme set-feature est utilisée pour configurer des caractéristiques spécifiques sur un contrôleur NVMe.

Certaines caractéristiques sont spécifiques au fournisseur. Pour une liste complète des caractéristiques supportées, consultez la documentation de votre matériel.

OPTIONS

-f <fid>, --feature-id=<fid>

L'identifiant de la caractéristique à définir. Peut être une valeur décimale ou hexadécimale.

-v <value>, --value=<value>

La valeur à définir pour la caractéristique. Doit être une valeur hexadécimale.

-l <length>, --length=<length>

La longueur de la valeur à définir pour la caractéristique. Doit être une valeur décimale.

-i <id>, --id=<id>

L'identifiant du namespace. Par défaut, il s'agit de tous les namespaces.

-u <id>, --uuid=<id>

L'identifiant UUID.

-o <fmt>, --output-format=<fmt>

Définir le format du rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmenter le niveau de détail des informations dans la sortie.

-c <cdw12>, --cdw12=<cdw12>

La valeur pour le registre de commande 12, si applicable.

-t <timeout>, --timeout=<timeout>

Remplacer la valeur de délai d'attente par défaut. En millisecondes.

EXEMPLES

•Définit l'état d'alimentation (PS) à 1 pour l'ID de caractéristique 2 : 
# nvme set-feature /dev/nvme0 -f 2 /dev/nvme0n1 -V 0x1
•Définit l'ID d'hôte sur la chaîne ASCII. 
# echo "abcdefgh" | nvme set-feature /dev/nvme0 -f 0x81 -l 8

nvme set-feature /dev/nvme0 -f 0x81 -l 8 -U 0x1
