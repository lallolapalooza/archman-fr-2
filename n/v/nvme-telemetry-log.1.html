NOM

nvme-telemetry-log - Récupère une page de journal de télémétrie initiée par l'hôte depuis un périphérique NVMe

SYNTAXE

nvme telemetry-log <périphérique> [--output-file=<fichier> | -O <fichier>]
                        [--host-generate=<gen> | -g <gen>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Récupère une page de journal de télémétrie initiée par l'hôte depuis un périphérique NVMe et fournit la structure retournée.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc d'espace de noms (ex: /dev/nvme0n1).

En cas de succès, la structure de journal retournée sera au format binaire brut *uniquement* avec l'option --output-file qui est obligatoire.

OPTIONS

-O <fichier>, --output-file=<fichier>

Nom du fichier dans lequel les données binaires brutes seront enregistrées.

-g <gen>, --host-generate=<gen>

Si défini à 1, le contrôleur capturera les données de télémétrie initiées par l'hôte représentant l'état interne du contrôleur au moment où la commande Get Log Page associée est traitée. Si défini à 0, le contrôleur ne mettra *pas* à jour ces données.

-d <da>, --data-area=<da>

Récupère la zone de données spécifique demandée. Les entrées valides sont 1, 2, 3, 4. Si cette option n'est pas spécifiée, la valeur par défaut est 3, car la zone de données 4 peut ne pas être prise en charge.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

•Récupérer les données de télémétrie initiées par l'hôte dans telemetry_log.bin 
# nvme telemetry-log /dev/nvme0 --output-file=telemetry_log.bin
