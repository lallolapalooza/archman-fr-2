NOM

nvme-get-feature - Obtient une fonctionnalité NVMe, retourne les résultats applicables

SYNOPSIS

nvme get-feature <appareil> [--namespace-id=<nsid> | -n <nsid>]
                        [--feature-id=<fid> | -f <fid>]
                        [--uuid-index=<uuid-index> | -U <uuid_index>]
                        [--data-len=<data-len> | -l <data-len>]
                        [--sel=<select> | -s <select>]
                        [--raw-binary | -b] [--cdw11=<cdw11> | -c <cdw11>]
                        [--human-readable | -H] [--changed | -C]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPTION

Soumet une commande d'administration NVMe Get Feature et retourne les résultats applicables. Il peut s'agir de la valeur de la fonctionnalité, ou peut également inclure une structure de fonctionnalité si la fonctionnalité l'exige (par exemple, LBA Range Type).

Le paramètre <appareil> est obligatoire et peut être soit le périphérique caractère NVMe (par exemple, /dev/nvme0), soit un périphérique bloc de l'espace de noms (par exemple, /dev/nvme0n1).

En cas de succès, la structure de la fonctionnalité retournée (si applicable) peut être retournée de plusieurs manières selon les indicateurs d'option ; la structure peut être analysée par le programme et affichée dans un format lisible si c'est une structure connue, affichée en hexadécimal, ou le tampon brut peut être imprimé sur stdout pour qu'un autre programme l'analyse.

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Récupère la fonctionnalité pour le nsid donné. Ceci est optionnel et la plupart des fonctionnalités n'utilisent pas cette valeur.

NAME

nvme-get-feature - Retrieve a NVMe feature value

SYNOPSIS

nvme get-feature <device> [-f <feature-id>] [-i <uuid-index>] [-l <data-len>] [-c <cdw11>] [-b] [-H] [-C] [-o <fmt>] [-v] [-t <timeout>]

DESCRIPTION

Retrieves a value from a NVMe device's feature. Features are identified by a feature identifier and optionally an UUID index. Not all features are associated with an UUID index.

The command requires the device path and a feature identifier. The feature identifier can be given as a decimal or hexadecimal number. Feature identifier -f requires a number, while -i can take an index for features that support UUID indexes.

The following is a list of known feature identifiers:

1 Arbitration
2 Timeouts
3 Number of Queues
4 Interrupt Coalescing
5 Interrupt Moderation
6 Features Enable/Disable
7 Volatile Write Cache
8 Device Self-test
9 Error Recovery
10 Log Page
11 Firmware Commit
12 Log Quotas
13 Namespace Management
14 Endurance Group/Group Management
15 Telemetries
16 Persistent Events
17 Reserved
18 Write Atomicity and Power Loss Notification
19 Async Event Configuration
20 SATA/SAS Product Receive Control
21 Block Multipath
22 SMC Support
23 Host Memory Buffer Settings
24 Sanitize
25 Rebuild Optimize
26 Performance Enhancement
27 Secure Save/Load
28 Streaming Data
29 Rebuild Assist
30 Zoned Management
31 Device Buffer Properties
32 Block Device Characteristics
33 Host Supported Functions
34 Device Supported Functions
35 Format NVM Settings
36 NVMe-oF Security
37 NVMe-oF Configuration
38 Dual-Port Configuration
39 Host Identifier
40 LBA Range Type
41 VS / Vendor Specific
42 UUID
43 Saved Features
44 Supported capabilities
74-127 Reserved
128-255 Device Specific

OPTIONS

-f <feature-id>, --feature-id=<feature-id>

The feature identifier to retrieve.

-i <uuid-index>, --uuid-index=<uuid-index>

The UUID index of the feature.

-l <data-len>, --data-len=<data-len>

The data length for the buffer returned for this feature. Most known features do not use this value. The exception is LBA Range Type

-c <cdw11>, --cdw11=<cdw11>

The value for command dword 11, if applicable.

-b, --raw-binary

Print the raw feature buffer to stdout if the feature returns a structure.

-H, --human-readable

This option will parse and format many of the bit fields into human-readable formats.

-C, --changed

This option will show feature changed.

-o <fmt>, --output-format=<fmt>

Set the reporting format to normal, json or binary. Only one output format can be used at a time.

-v, --verbose

Increase the information detail in the output.

-t <timeout>, --timeout=<timeout>

Override default timeout value. In milliseconds.

EXAMPLES

•Retrieves the feature for Number of Queues, or feature id 3: 
# nvme get-feature /dev/nvme0 -f 3
•The following retrieves the feature for the LBA Range Type, which implicitly requires a buffer and will be printed to the screen in human readable format: 
# nvme get-feature /dev/nvme0 -f 40 -H
•Retrieves the feature for the some vendor specific feature and specifically requesting a buffer be allocate for this feature, which will be displayed to the user in as a hex dump: 
# nvme get-feature /dev/nvme0 -f 0x41 -l 512 -b

Get feature with UUID index

# nvme get-feature /dev/nvme0 -f 0x41 -l 512 -i 0x1
•The following retrieves the feature for the LBA Range Type, which implicitly requires a buffer and will be saved to a file in its raw format: 
# nvme get-feature /dev/nvme0 -f 40 --raw-binary > lba_range.raw

It is probably a bad idea to not redirect stdout when using this mode.
