NOM

nvme-create-ns - Envoie une commande de gestion de namespace NVMe pour créer un namespace, renvoie les résultats.

SYNTAXE

nvme create-ns <périphérique> [--nsze=<nsze> | -s <nsze>]
                        [--ncap=<ncap> | -c <ncap>]
                        [--flbas=<flbas> | -f <flbas>]
                        [--dps=<dps> | -d <dps>]
                        [--nmic=<nmic> | -m <nmic>]
                        [--anagrp-id=<anagrpid> | -a <anagrpid>]
                        [--nvmset-id=<nvmsetid> | -i <nvmsetid>]
                        [--endg-id=<endgid> | -e <endgid>]
                        [--csi=<identifiant_ensemble_commande> | -y <identifiant_ensemble_commande>]
                        [--lbstm=<lbstm> | -l <lbstm>]
                        [--nphndls=<nphndls> | -n <nphndls>]
                        [--block-size=<taille-bloc> | -b <taille-bloc>]
                        [--timeout=<timeout> | -t <timeout>]
                        [--nsze-si=<nsze-si> | -S <nsze-si>]
                        [--ncap-si=<ncap-si> | -C <ncap-si>]
                        [--azr | -z]
                        [--rar=<rar> | -r <rar>]
                        [--ror=<ror> | -O <ror>]
                        [--rnumzrwa=<rnumzrwa> | -u <rnumzrwa>]
                        [--phndls=<liste-poignées-placement,> | -p <liste-poignées-placement,>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Pour le périphérique NVMe donné, envoie une commande de gestion de namespace pour créer le namespace avec les paramètres demandés. En cas de succès, l'identifiant de namespace assigné par le contrôleur est renvoyé.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

OPTIONS

-s, --nsze

La taille du namespace.

-c, --ncap

La capacité du namespace.

-f, --flbas

Le paramètre de taille de bloc logique formaté du namespace. En conflit avec l'argument --block-size.

-d, --dps

Les paramètres de protection des données.

-m, --nmic

Capacités multipath et de partage du namespace.

-a, --anagrp-id

Identifiant du groupe ANA. Si cette valeur est 0h, cela spécifie que le contrôleur détermine la valeur à utiliser.

-i <nvmsetid>, --nvmset-id=<nvmsetid>

Ce champ spécifie l'identifiant de l'ensemble NVM.

-e <endgid>, --endg-id=<endgid>

Ce champ spécifie l'identifiant du groupe d'endurance.

-y <identifiant_ensemble_commande>, --csi=<identifiant_ensemble_commande>

Ce champ spécifie l'identifiant de l'ensemble de commandes. Si non émis, l'ensemble de commandes NVM sera sélectionné.

-l <lbstm>, --lbstm=<lbstm>

Masque de balise de stockage de bloc logique pour la protection de bout en bout.

-n <nphndls>, --nphndls=<nphndls>

Nombre de poignées de placement incluses dans la liste des poignées de placement. Si la capacité de placement de données flexible n'est pas prise en charge ou n'est pas activée dans le groupe d'endurance spécifié, alors le contrôleur ignorera ce champ.

-b, --block-size

Taille de bloc cible à laquelle le nouveau namespace doit être formaté. Les valeurs FLBAS potentielles seront parcourues et la valeur numériquement la plus basse sera sélectionnée pour l'opération create-ns. En conflit avec l'argument --flbas.

-S, --nsze-si

La taille du namespace (NSZE) en unités SI standard (alignée sur des blocs de 1 Mio, sauf si le contrôleur recommande une valeur différente, voir la granularité du namespace). La valeur suffixée SI est divisée par la taille de LBA du namespace pour être définie comme NSZE. Si la valeur n'a pas de suffixe, elle est définie comme la même que l'option nsze.

-C, --ncap-si

La capacité du namespace (NCAP) en unités SI standard (alignée sur des blocs de 1 Mio, sauf si le contrôleur recommande une valeur différente, voir la granularité du namespace). La valeur suffixée SI est divisée par la taille de LBA du namespace pour être définie comme NCAP. Si la valeur n'a pas de suffixe, elle est définie comme la même que l'option ncap.

-z, --azr

Allouer des ressources ZRWA. Si défini à 1, alors le namespace doit être créé avec le nombre de ressources ZRWA spécifiées dans le champ RNUMZRWA de cette structure de données. Si effacé à 0, alors aucune ressource ZRWA n'est allouée au namespace à créer.

-r <rar>, --rar=<rar>

Ressources Actives Demandées. Ce champ spécifie le nombre de ressources actives à allouer au namespace créé.

-O <ror>, --ror=<ror>

Ressources Ouvertes Demandées. Ce champ spécifie le nombre de ressources ouvertes à allouer au namespace créé.

-u <rnumzrwa>, --rnumzrwa=<rnumzrwa>

Nombre de Ressources ZRWA Demandées. Ce champ spécifie le nombre de ressources ZRWA à allouer au namespace créé.

-p <liste-poignées-placement,>, --phndls=<liste-poignées-placement,>

La liste séparée par des virgules des identifiants de poignées d'unité de récupération à associer à chaque poignée de placement.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

-t <timeout>, --timeout=<timeout>

Remplace la valeur de timeout par défaut de 120 000. En millisecondes.

EXEMPLES

•Créer un namespace: 
# nvme create-ns /dev/nvme0 --nsze 11995709440 --ncap 1199570940 --flbas 0 --dps 0 --nmic 0
# nvme create-ns /dev/nvme0 --nsze-si 6.14T --ncap 1199570940 --flbas 0 --dps 0 --nmic 0
