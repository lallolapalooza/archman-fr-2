NOM

nvme-get-log - Récupère une page de journal à partir d'un périphérique NVMe

SYNTAXE

nvme get-log <périphérique> [--log-id=<log-id> | -i <log-id>]
                        [--log-len=<log-len> | -l <log-len>]
                        [--aen=<aen> | -a <aen>]
                        [--namespace-id=<nsid> | -n <nsid>]
                        [--raw-binary | -b]
                        [--lpo=<offset> | -L <offset>]
                        [--lsp=<champ> | -s <champ>]
                        [--lsi=<champ> | -S <champ>]
                        [--rae | -r]
                        [--csi=<command_set_identifier> | -y <command_set_identifier>]
                        [--ot=<offset_type> | -O <offset_type>]
                        [--xfer-len=<longueur> | -x <longueur>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Récupère une page de journal NVMe arbitraire à partir d'un périphérique NVMe et fournit la structure retournée.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (par ex. : /dev/nvme0), soit un périphérique bloc de namespace (par ex. : /dev/nvme0n1).

En cas de succès, la structure de journal retournée peut être renvoyée de plusieurs manières en fonction des indicateurs d'options ; la structure peut être affichée en hexadécimal par le programme ou le tampon brut peut être imprimé sur la sortie standard pour qu'un autre programme puisse l'analyser.

OPTIONS

-l <log-len>, --log-len=<log-len>

Alloue un tampon de <log-len> octets et demande que ce nombre d'octets soit retourné dans la commande NVMe construite. Ce paramètre est obligatoire.

-i <log-id>, --log-id=<log-id>

Définit l'ID de journal demandé par la commande à <log-id>. La valeur par défaut est 0.

-a <aen>, --aen=<aen>

Champ de commodité pour extraire les informations du journal basées sur un résultat de notification d'événement asynchrone. Cela remplacera log-id et log-len, s'ils sont définis.

-n <nsid>, --namespace-id=<nsid>

Définit la valeur nsid de la commande au nsid donné. La valeur par défaut est 0xffffffff si non spécifié. Cette option peut ne pas avoir d'effet en fonction de la page de journal, qui peut ou peut ne pas être spécifique à un namespace.

-b, --raw-binary

Affiche le tampon de journal brut sur la sortie standard.

-L <offset>, --lpo=<offset>

L'offset de la page de journal spécifie l'emplacement à partir duquel commencer à retourner les données dans une page de journal. Il est aligné sur Dword et fait 64 bits.

-s <champ>, --lsp=<champ>

Le champ spécifié du journal LID.

-S <champ>, --lsi=<champ>

Le champ spécifié du journal LSI.

-r, --rae

Récupère les informations de journal associées à un événement asynchrone.

-y <command_set_identifier>, --csi=<command_set_identifier>

Définit l'identificateur du jeu de commandes. La valeur par défaut est 0.

-O <offset_type>, --ot=<offset_type>

Définit le type d'offset pour les journaux qui prennent en charge les données de journal segmentées.

-x <longueur>, --xfer-len=<longueur>

Définit la longueur de transfert pour les données de journal.

-o <fmt>, --output-format=<fmt>

L'indicateur `output-format` peut être utilisé pour changer le format de sortie. Les valeurs valides pour `fmt` sont : "json", "binary", "yaml", "pretty".

-v, --verbose

Activer les informations de débogage détaillées.

EXEMPLES

    * Afficher le journal SMART pour /dev/nvme0n1:
    $ nvme get-log /dev/nvme0n1 --log-id=2 --log-len=4096

    * Afficher le journal d'erreurs pour /dev/nvme0:
    $ nvme get-log /dev/nvme0 -i 1 -l 1024

    * Afficher le tampon brut du journal des pages de journal prises en charge pour /dev/nvme0:
    $ nvme get-log /dev/nvme0 --log-id=0 --log-len=256 -b

NOM

nvme-get-log - Récupérer une page de journal.

SYNTAXE

nvme get-log [OPTIONS] <dispositif>

DESCRIPTION

L'outil nvme get-log est utilisé pour lire les pages de journal de la commande NVM de l'interface NVMe.

OPTIONS

-i <log_id>, --log-id=<log_id>
L'identifiant de la page de journal à récupérer. Les identifiants de journal sont définis dans la spécification NVMe.
-l <length>, --log-len=<length>
La longueur de la page de journal à récupérer. La longueur maximale est limitée par le contrôleur.
-b, --raw-binary
Sortie de la page de journal brute au format binaire.
-f <field>, --lsid=<field>
Le champ spécifié de l'identifiant d'enregistrement de journal.
-r, --rae
Conserver un événement asynchrone.
-y <<command_set_identifier>, --csi=<command_set_identifier>
Ce champ spécifie l'identifiant de l'ensemble de commandes. S'il n'est pas émis, l'ensemble de commandes NVM sera sélectionné.
-O, --ot
Ce champ spécifie le type de décalage. S'il est réglé sur false, les champs Log Page Offset Lower et Log Page Offset Upper spécifient le décalage en octets dans la page de journal à retourner. S'il est réglé sur true, les champs Log Page Offset Lower et Log Page Offset Upper spécifient l'index dans la liste des structures de données dans la page de journal à retourner. La valeur par défaut est le décalage en octets. Si l'option est spécifiée, le mode d'index est utilisé.
-x <length>
--xfer-len <length> : Spécifie la taille du bloc de lecture. La longueur de l'argument est censée être un multiple de 4096. La taille par défaut est 4096.
-o <fmt>, --output-format=<fmt>
Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.
-v, --verbose
Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

•Obtenir 512 octets de la page de journal 2 
# nvme get-log /dev/nvme0 --log-id=2 --log-len=512

L'exemple ci-dessus obtiendra la page de journal 2 (SMART) et demandera 512 octets. En cas de succès, le journal retourné sera affiché en hexadécimal et ne sera pas interprété par le programme.

•Demander au programme de retourner la page de journal brute en binaire : 
# nvme get-log /dev/nvme0 -log-id=2 --log-len=512 --raw-binary > log_page_2.raw
# nvme get-log /dev/nvme0 -i 2 -l 512 -b > log_page_2.raw

Il n'est pas conseillé de ne pas rediriger la sortie standard lors de l'utilisation de ce mode.
