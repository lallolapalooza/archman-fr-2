NOM

nvme-seagate-vs-temperature-stats - Récupérer les statistiques de température spécifiques au vendeur Seagate

SYNOPSIS

nvme seagate vs-temperature-stats <périphérique> [OPTIONS]

DESCRIPTION

Cette commande ne fonctionnera que sur les périphériques Seagate prenant en charge cette fonctionnalité. Toutes les commandes ne fonctionnent pas sur toutes les familles de produits.

Le paramètre '<périphérique>' est obligatoire et peut être soit un périphérique caractère NVMe (par exemple, /dev/nvme0) soit un périphérique bloc nvme (par exemple, /dev/nvme0n1).

OPTIONS

-o <fmt>, --output-format=<fmt>

Sortie en format binaire

EXEMPLES

Obtenir les statistiques de température spécifiques au vendeur pour le périphérique spécifié.

# nvme seagate vs-temperature-stats /dev/nvme0
