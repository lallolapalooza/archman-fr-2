NOM

nvme-dir-send - Envoie une commande de directive, retourne les résultats applicables

SYNTAXE

nvme dir-send <périphérique> [--namespace-id=<nsid> | -n <nsid>]
                        [--data-len=<longueur-données> | -l <longueur-données>]
                        [--dir-type=<type-dir> | -D <type-dir>]
                        [--dir-spec=<spec-dir> | -S <spec-dir>]
                        [--dir-oper=<op-dir> | -O <op-dir>]
                        [--endir=<dir-activation> | -e <dir-activation>]
                        [--target-dir=<dir-cible> | -T <dir-cible>]
                        [--human-readable | -H] [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<délai> | -t <délai>]

DESCRIPTION

Soumet une commande d'administration NVMe Directive Send et retourne les résultats applicables. Cela peut être la combinaison du type de directive et de l'opération, ainsi que la directive cible et son statut d'activation/désactivation de l'opération, si une opération spécifique en a besoin.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de l'espace de noms (ex: /dev/nvme0n1).

En cas de succès, la structure des paramètres de la directive retournée (si applicable) est retournée d'une des manières suivantes en fonction des indicateurs d'options ; la structure peut être analysée par le programme et affichée en hexadécimal, ou le tampon brut peut être imprimé sur la sortie standard pour qu'un autre programme l'analyse.

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Récupère la fonctionnalité pour le nsid donné. Ceci est optionnel et la plupart des fonctionnalités n'utilisent pas cette valeur.

-D <type-dir>, --dir-type=<type-dir>

Type de directive

-S <spec-dir>, --dir-spec=<spec-dir>

Spécifique à la directive

-O <op-dir>, --dir-oper=<op-dir>

Opération de directive

-T <dir-cible>, --target-dir=<dir-cible>

Directive cible de l'opération

-e <dir-activation>, --endir=<dir-activation>

Activation (1) ou désactivation (0) de la directive cible
Sélectionner Description
0 Courant
1 Par défaut
2 Sauvegardé
3 Capacités supportées
4–7 Réservé

-l <longueur-données>, --data-len=<longueur-données>

La longueur des données pour le tampon retourné pour cette fonctionnalité. La plupart des fonctionnalités connues n'utilisent pas cette valeur. L'exception est le Type de Plage LBA

-b, --raw-binary

Imprime le tampon de réception brut sur la sortie standard si la commande retourne une structure.

-H, --human-readable

obsolète ; ne fait rien, utilisez donc l'indicateur --verbose à la place.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binaire. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

-t <délai>, --timeout=<délai>

Remplace la valeur de délai par défaut. En millisecondes.

EXEMPLES

•Activer la directive de flux : 
# nvme dir-send /dev/nvme0n1 --dir-type 0 --dir-oper 1 --target-dir 1 --endir 1
•Désactiver la directive de flux : 
# nvme dir-send /dev/nvme0n1 --dir-type 0 --dir-oper 1 --target-dir 1 --endir 0
•Libérer toutes les ressources de flux allouées : 
# nvme dir-send /dev/nvme0n1 --dir-type 1 --dir-oper 2
•Libérer le flux ID 3 : 
# nvme dir-send /dev/nvme0 --dir-type 1 --dir-oper 1 --dir-spec 3

Il est probablement déconseillé de ne pas rediriger stdout lors de l'utilisation de ce mode.
