NOM

nvme-solidigm-latency-tracking-log - Activer/Récupérer le journal de suivi de latence

SYNTAXE

nvme solidigm latency-tracking-log <périphérique> [--enable | -e] [--disable | -d]
                                              [--read | -r] [--write | -w]
                                              [--type <valeur> | -t <valeur>]
                                              [--output-format=<fmt> | -o <fmt>]

DESCRIPTION

Active, désactive ou récupère le journal de suivi de latence Solidigm pour le périphérique NVMe donné. Ce journal fournit des informations détaillées sur les latences des E/S.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

OPTIONS

-e, --enable

Active le suivi de latence avant de récupérer le journal.

-d, --disable

Désactive le suivi de latence après avoir récupéré le journal.

-r, --read

Récupère les statistiques de latence de lecture (par défaut si ni --read ni --write n'est spécifié).

-w, --write

Récupère les statistiques de latence d'écriture.

-t <valeur>, --type <valeur>

Spécifie le type de journal à récupérer. Les valeurs valides dépendent des capacités du périphérique.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json, ou binary. Un seul format de sortie peut être utilisé à la fois.

EXEMPLES

• Active le suivi de latence et récupère le journal de latence de lecture : 
# nvme solidigm latency-tracking-log /dev/nvme0 --enable --read
• Récupère le journal de latence d'écriture au format JSON : 
# nvme solidigm latency-tracking-log /dev/nvme0 --write -o json
• Désactive le suivi de latence après avoir récupéré le journal : 
# nvme solidigm latency-tracking-log /dev/nvme0 --disable
• Spécifie un type de journal lors de la récupération des statistiques de latence : 
# nvme solidigm latency-tracking-log /dev/nvme0 --type 1 --read
