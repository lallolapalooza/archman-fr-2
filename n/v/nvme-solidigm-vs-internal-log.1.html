NOM

nvme-solidigm-vs-internal-log - Récupérer les binaires du journal de débogage interne

SYNOPIS

nvme solidigm vs-internal-log <périphérique> [--log-type=<type> | -t <type>]
                                          [--output-dir=<dir> | -d <dir>]
                                          [--verbose | -v]

DESCRIPTION

Pour le périphérique NVMe donné, récupère les binaires du journal de débogage interne spécifiques au vendeur Solidigm et les enregistre dans le répertoire de sortie spécifié.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

OPTIONS

-t <type>, --log-type=<type>

Spécifie le type de journal à récupérer. Les options valides sont ALL, CIT, HIT, NLOG, ASSERT, EVENT et EXTENDED. Par défaut : ALL. L'option EXTENDED génère des journaux qui peuvent prendre plus de temps ou affecter les performances du disque, mais fournit des informations de débogage plus complètes.

-d <dir>, --output-dir=<dir>

Spécifie le répertoire de sortie pour les fichiers journaux. Par défaut : le répertoire de travail actuel.

-v, --verbose

Active la sortie verbeuse pour des informations supplémentaires pendant le processus de récupération des journaux.

EXEMPLES

•Récupérer tous les journaux internes et les enregistrer dans le répertoire courant : 
# nvme solidigm vs-internal-log /dev/nvme0
•Récupérer un type de journal spécifique et l'enregistrer dans un répertoire personnalisé : 
# nvme solidigm vs-internal-log /dev/nvme0 -t NLOG -d /tmp/logs
•Récupérer les journaux avec une sortie verbeuse : 
# nvme solidigm vs-internal-log /dev/nvme0 -v
•Récupérer les journaux étendus : 
# nvme solidigm vs-internal-log /dev/nvme0 -t EXTENDED
