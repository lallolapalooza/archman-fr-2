NOM

nvme-wdc-get-crash-dump - Récupérer la vidange de crash du périphérique WDC.

SYNTAXE

nvme wdc get-crash-dump <périphérique> [--output-file=<FICHIER>, -o <FICHIER>]

DESCRIPTION

Pour le périphérique NVMe donné, envoie la demande unique de vidange de crash du fournisseur WDC et enregistre le résultat dans un fichier. Dans l'implémentation actuelle, la vidange de crash est capturée si elle est présente. En cas de succès, elle enregistre la vidange dans un fichier avec le suffixe approprié. Notez que cette commande effacera la vidange disponible du périphérique en cas de succès.

Le paramètre <périphérique> est le périphérique caractère NVMe obligatoire (ex: /dev/nvme0).

Ceci ne fonctionnera que sur les périphériques WDC prenant en charge cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

OPTIONS

-o <FICHIER>, --output-file=<FICHIER>

Fichier de sortie ; par défaut, le numéro de série du périphérique suivi du suffixe "crash_dump"

EXEMPLES

• Récupère la vidange de crash du périphérique et l'enregistre dans le fichier par défaut dans le répertoire courant (par exemple, STM00019F3F9crash_dump.bin) : 
# nvme wdc get-crash-dump /dev/nvme0
• Récupère la vidange de crash du périphérique et l'enregistre dans le fichier défini dans le répertoire courant (par exemple, testSTM00019F3F9crash_dump.bin) : 
# nvme wdc get-crash-dump /dev/nvme0 -o test
• Récupère la vidange de crash du périphérique et l'enregistre dans le fichier défini avec le chemin d'accès (par exemple, /tmp/testSTM00019F3F9crash_dump.bin) : 
# nvme wdc get-crash-dump /dev/nvme0 -o /tmp/test
