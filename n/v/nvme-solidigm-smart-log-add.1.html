NOM

nvme-solidigm-smart-log-add - Récupérer le journal SMART de Solidigm

SYNOPSIS

nvme solidigm smart-log-add <périphérique> [--namespace-id=<nsid> | -n <nsid>]
                                       [--output-format=<fmt> | -o <fmt>]

DESCRIPTION

Récupère le journal SMART spécifique au vendeur Solidigm pour le périphérique NVMe donné et éventuellement le namespace spécifié, puis affiche le journal.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

OPTIONS

-n <nsid>, --namespace-id=<nsid>

Récupère le journal pour le nsid donné. Si non spécifié, le journal sera récupéré pour tous les namespaces.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json, ou binary. Un seul format de sortie peut être utilisé à la fois.

EXEMPLES

•Récupérer le journal SMART de Solidigm pour tous les namespaces: 
# nvme solidigm smart-log-add /dev/nvme0
•Récupérer le journal SMART de Solidigm pour le namespace 1: 
# nvme solidigm smart-log-add /dev/nvme0 -n 1
•Récupérer le journal SMART de Solidigm en format JSON: 
# nvme solidigm smart-log-add /dev/nvme0 -o json
