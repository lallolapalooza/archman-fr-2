NOM

nvme-lockdown - Envoyer une commande NVMe Lockdown pour interdire ou autoriser l'exécution d'une commande

SYNTAXE

nvme-lockdown <périphérique> [--ofi=<ofi> | -O <ofi>]
                        [--ifc=<ifc> | -f <ifc>]
                        [--prhbt=<prhbt> | -p <prhbt>]
                        [--scp=<scp> | -s <scp>]
                        [--uuid=<UUID_Index> | -U <UUID_Index>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPTION

La commande Lockdown est utilisée pour contrôler la capacité de verrouillage de commande et de fonctionnalité qui configure l'interdiction ou l'autorisation de l'exécution de la commande spécifiée ou de la commande Set Features ciblant un identifiant de fonctionnalité spécifique.

OPTIONS

-O <ofi>, --ofi=<ofi>

L'Opcode ou l'Identifiant de Fonctionnalité (OFI) spécifie l'opcode de la commande ou l'Identifiant de Fonctionnalité de Set Features identifié par le champ Scope.

-f <ifc>, --ifc=<ifc>

Le champ Interface (INF) identifie les interfaces affectées par cette commande.

-p <prhbt>, --prhbt=<prhbt>

Le bit Interdire (PRHBT) spécifie si la commande opcode ou l'Identifiant de Fonctionnalité de Set Features spécifié par cette commande doit être interdit ou autorisé.

-s <scp>, --scp=<scp>

Le champ Portée (SCP) spécifie le contenu du champ Opcode ou Identifiant de Fonctionnalité.

-U <UUID_Index>, --uuid=<UUID_Index>

Index UUID - Si ce champ est défini sur une valeur non nulle, alors la valeur de ce champ est l'index d'un UUID dans la liste UUID utilisée par la commande. Si ce champ est effacé à 0h, alors aucun index UUID n'est spécifié.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binaire. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

-t <timeout>, --timeout=<timeout>

Remplace la valeur de délai d'attente par défaut. En millisecondes.
