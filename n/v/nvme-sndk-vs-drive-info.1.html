NOM

nvme-sndk-vs-drive-info - Envoie la commande NVMe sndk vs-drive-info, renvoie le résultat

SYNTAXE

nvme sndk vs-drive-info <périphérique>

DESCRIPTION

Pour le périphérique NVMe donné, envoie la commande unique sndk vs-drive-info et fournit les informations supplémentaires du disque.

Le paramètre <périphérique> est obligatoire et doit être le périphérique caractère NVMe (ex: /dev/nvme0).

Cela ne fonctionnera que sur les périphériques Sandisk supportant cette fonctionnalité. Les résultats pour tout autre périphérique sont indéfinis.

En cas de succès, renvoie 0, sinon un code d'erreur.

EXPLICATION DES SORTIES

Il y a plusieurs champs différents renvoyés par cette commande en fonction du disque :

Version matérielle du disque

Taille de l'unité FTL

Numéro de série du client

Version de démarrage HyperScale

Propriété de l'appareil TCG

EXEMPLE

# nvme sndk vs-drive-info /dev/nvme0

NVME

Fait partie de la suite nvme-user.
