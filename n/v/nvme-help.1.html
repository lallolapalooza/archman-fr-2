NOM

nvme-help - Informations d'aide.

SYNTAXE

nvme help [<commande>]

DESCRIPTION

Fournit des informations d'aide, avec des informations détaillées sur la commande donnée si elle est fournie.

OPTIONS

Pas d'options

EXEMPLES

•Afficher l'aide pour le journal des erreurs nvme : 
# nvme help smart-log

Il n'y a pas grand-chose de plus
