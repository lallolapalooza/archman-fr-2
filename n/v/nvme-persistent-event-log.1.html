NOM

nvme-persistent-event-log - Envoie une requête de page de journal d'événements persistants NVMe, renvoie le résultat et le journal

SYNTAXE

nvme persistent-event-log <périphérique> [--action=<action> | -a <action>]
                        [--log-len=<longueur-log> | -l <longueur-log>] [--raw-binary | -b]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

Récupère la page de journal d'événements persistants NVMe à partir d'un périphérique NVMe et fournit la structure renvoyée.

Le paramètre <périphérique> est obligatoire et peut être soit le périphérique caractère NVMe (ex: /dev/nvme0), soit un périphérique bloc de namespace (ex: /dev/nvme0n1).

En cas de succès, la structure de journal d'événements persistants renvoyée peut être renvoyée de plusieurs manières selon les indicateurs d'options ; la structure peut être analysée par le programme et imprimée dans un format lisible ou le tampon brut peut être imprimé sur la sortie standard pour qu'un autre programme l'analyse.

OPTIONS

-a <action>, --action=<action>

Lors de la tentative de récupération de ce journal, l'action que le contrôleur doit entreprendre pendant le traitement de cette commande de journal d'événements persistants. Ce champ obligatoire, en fonction de la valeur émise, peut entraîner une lecture des données du journal, l'établissement d'un contexte et la lecture des données du journal, ou la libération du contexte. Pour plus de détails, voir la spécification NVM Express 1.4, section 5.14.1.13 Persistent Event Log (Identifiant de journal 0Dh).

-l <longueur-log>, --log-len=<longueur-log>

Alloue un tampon d'une taille de <longueur-log> octets et demande que ce nombre d'octets soit renvoyé dans la commande NVMe construite. Ce paramètre est obligatoire. Si <longueur-log> est donné à 0 et que l'action est 0, il lira la longueur totale du journal (TLL) de la page.

-b, --raw-binary

Imprime le tampon brut du journal d'événements persistants sur la sortie standard.

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

EXEMPLES

• Imprime la page de journal d'événements persistants dans un format lisible par l'homme : 
# nvme persistent-event-log /dev/nvme0
• Imprime le journal d'événements persistants brut dans un fichier : 
# nvme persistent-event-log /dev/nvme0 --raw-binary > persistent_log.raw

Il est probablement déconseillé de ne pas rediriger la sortie standard lors de l'utilisation de ce mode.
