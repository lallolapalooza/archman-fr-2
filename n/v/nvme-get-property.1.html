NOM

nvme-get-property - Lit et affiche la propriété de contrôleur NVMe définie pour NVMe sur Fabric

SYNTAXE

nvme get-property <périphérique> [--offset=<offset> | -O <offset>]
                        [--human-readable | -H]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

DESCRIPTION

Lit et affiche la propriété de contrôleur NVMe définie pour NVMe sur Fabric.

OPTIONS

-O <offset>, --offset=<offset>

L'offset de la propriété. Un des éléments suivants : CAP=0x0, VS=0x8, CC=0x14, CSTS=0x1c, NSSR=0x20

-H

--human-readable : Affiche les champs empaquetés dans la propriété

-o <fmt>, --output-format=<fmt>

Définit le format de rapport sur normal, json ou binary. Un seul format de sortie peut être utilisé à la fois.

-v, --verbose

Augmente le niveau de détail des informations dans la sortie.

-t <timeout>, --timeout=<timeout>

Remplace la valeur de délai d'attente par défaut. En millisecondes.

EXEMPLES

•La commande suivante exécute la commande get-property avec l'offset 0 
# nvme get-property /dev/nvme0 --offset=0x0 --human-readable

BOGUES

Actuellement, la valeur CAP est tronquée à 32 bits en raison d'une limitation de l'interface ioctl.

Dans un noyau suffisamment récent, la valeur de 64 bits est affichée dans les traces du noyau.

•Activez d'abord les traces avec cette commande 
# echo 1 > /sys/kernel/debug/tracing/events/nvme/enable
•Recherchez ensuite la commande NVMe Fabrics (0x7f) dans la trace 
/sys/kernel/debug/tracing/trace
