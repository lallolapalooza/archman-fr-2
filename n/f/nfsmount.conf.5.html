NFSMOUNT.CONF(5) Manuel des formats de fichiers NFSMOUNT.CONF(5)

NOM

nfsmount.conf - Fichier de configuration pour les montages NFS

SYNOPIS

Fichier de configuration pour les montages NFS qui permet de définir des options globalement, par serveur ou par point de montage.

DESCRIPTION

Le fichier de configuration est composé de plusieurs en-têtes de section suivis d'attributions de variables associées à cette section. Un en-tête de section est défini par une chaîne de caractères entourée par des crochets [ et ]. Les attributions de variables sont des instructions d'assignation qui attribuent des valeurs à des variables particulières en utilisant l'opérateur =, comme dans Proto=Tcp. Les variables qui peuvent être assignées sont l'ensemble des options de montage spécifiques à NFS listées dans nfs(5) ainsi que les options de montage indépendantes du système de fichiers listées dans mount(8) et trois ajouts : Sloppy=True a le même effet que l'option -s de mount, et Foreground=True et Background=True ont le même effet que bg et fg.

Les options du fichier de configuration peuvent être en majuscules, minuscules ou mixtes et seront converties en minuscules avant d'être passées au système de fichiers.

Les options de montage booléennes qui n'ont pas besoin d'un signe égal doivent être fournies sous la forme "option=True". Au lieu de faire précéder une telle option de "no", sa négation doit être fournie sous la forme "option=False".

Les sections sont divisées en trois catégories de base : Options globales, Options serveur et Options point de montage.

[ NFSMount_Global_Options ] - Cette section nommée de manière statique définit toutes les options de montage globales qui peuvent être appliquées à chaque montage NFS.

[ Server "Nom_Serveur" ] - Cette section définit toutes les options de montage qui doivent être utilisées pour les montages vers un serveur NFS particulier. La chaîne de caractères "Nom_Serveur" doit être entourée de '"' et correspondre exactement (en ignorant la casse) au nom du serveur utilisé dans la commande mount.

[ MountPoint "Point_de_Montage" ] - Cette section définit toutes les options de montage qui doivent être utilisées sur un point de montage particulier. La chaîne de caractères "Point_de_Montage" doit être entourée de '"' et correspondre exactement au point de montage utilisé dans la commande mount. Bien que les noms de chemin soient généralement sensibles à la casse, le nom du Point_de_Montage est comparé sans tenir compte de la casse.

Les sections sont traitées dans l'ordre inverse de celui listé ci-dessus, et toutes les options déjà vues, que ce soit dans une section précédente ou sur la ligne de commande, seront ignorées lorsqu'elles seront rencontrées à nouveau.

EXEMPLES

Voici quelques lignes d'exemple montrant comment les sections et les variables sont définies dans le fichier de configuration.

[ NFSMount_Global_Options ]
Proto=Tcp

Le protocole TCP/IPv4 sera utilisé sur chaque montage NFS.

[ Server "nfsserver.foo.com" ]
rsize=32k
wsize=32k
proto=udp6

Une taille de bloc de 32k (32768 octets) sera utilisée comme taille de lecture et d'écriture sur tous les montages vers le serveur 'nfsserver.foo.com'. UDP/IPv6 est le protocole à utiliser.

[ MountPoint "/export/home" ]
Background=True

Tous les montages vers l'exportation '/export/home' seront effectués en arrière-plan (c'est-à-dire de manière asynchrone).

FICHIERS

/usr/etc/nfsmount.conf
/usr/etc/nfsmount.conf.d/*.conf
/etc/nfsmount.conf
/etc/nfsmount.conf.d/*.conf

Fichiers de configuration par défaut pour les montages NFS, les variables définies dans le dernier fichier remplacent celles du fichier précédent.
