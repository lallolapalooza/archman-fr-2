NOM

nfsdclddb - Outil pour manipuler la base de données sqlite de nfsdcld

SYNTAXE

nfsdclddb [-h|--help]

nfsdclddb [-p|--path chemin-db] fix-table-names [-h|--help]

nfsdclddb [-p|--path chemin-db] downgrade-schema [-h|--help] [-v|--version vers-la-version]

nfsdclddb [-p|--path chemin-db] print [-h|--help] [-s|--summary]

DESCRIPTION

La commande nfsdclddb est fournie pour effectuer certaines manipulations du schéma de la base de données sqlite nfsdcld et pour afficher le contenu de la base de données.

Sous-commandes

Les sous-commandes valides pour nfsdclddb sont :

fix-table-names
Une version précédente de nfsdcld(8) contenait un bug qui a corrompu les noms des tables d'époques de redémarrage. Cette sous-commande corrigera ces noms de tables.
downgrade-schema
Rétrograder le schéma de la base de données. Actuellement, le schéma ne peut être rétrogradé que de la version 4 à la version 3.
print
Afficher le contenu de la base de données. Affiche la version du schéma et les valeurs des époques courante et de récupération. Si l'option -s|--summary n'est pas donnée, affiche également les clients dans les tables d'époques de redémarrage.

OPTIONS

Options valides pour toutes les sous-commandes

-h, --help
Afficher le message d'aide et quitter.
-p chemin-db, --path chemin-db
Ouvrir la base de données sqlite située à chemin-db au lieu de /var/lib/nfs/nfsdcld/main.sqlite. Ceci est principalement à des fins de test.

Options spécifiques à la sous-commande downgrade-schema

-v vers-la-version, --version vers-la-version
La version du schéma vers laquelle rétrograder. Actuellement, le schéma ne peut être rétrogradé qu'à la version 3.

Options spécifiques à la sous-commande print

-s, --summary
Ne pas lister les clients dans les tables d'époques de redémarrage dans la sortie.

NOTES

La commande nfsdclddb ne permettra pas d'utiliser les sous-commandes fix-table-names ou downgrade-schema si nfsdcld(8) est en cours d'exécution.

FICHIERS

/var/lib/nfs/nfsdcld/main.sqlite
