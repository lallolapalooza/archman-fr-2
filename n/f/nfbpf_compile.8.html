NOM

nfbpf_compile — générer du bytecode pour utilisation avec xt_bpf

SYNTAXE


nfbpf_compile [ LLTYPE ] PROGRAM

LLTYPE := { EN10MB | RAW | SLIP | ... }

DESCRIPTION

L'utilitaire nfbpf_compile aide à générer du bytecode BPF adapté pour être passé à la correspondance bpf d'iptables.

OPTIONS

LLTYPE
Type d'en-tête de couche de liaison sur lequel opérer. Il s'agit d'un nom tel que défini dans <pcap/dlt.h> mais sans le préfixe DLT_. Pour une utilisation avec iptables, RAW devrait être le bon choix (c'est aussi la valeur par défaut si elle n'est pas spécifiée).
PROGRAM
L'expression BPF à compiler, voir pcap-filter(7) pour une description du langage.

STATUT DE SORTIE

Le programme retourne 0 en cas de succès, 1 sinon.

EXEMPLE

Correspondance des paquets TCP entrants d'une taille supérieure à 100 octets :


bpf=$(nfbpf_compile 'tcp and greater 100')
iptables -A INPUT -m bpf --bytecode "$bpf" -j ACCEPT

La description de la correspondance bpf dans iptables-extensions(8) liste quelques exemples supplémentaires.

VOIR AUSSI
