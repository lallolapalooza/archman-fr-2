NAME

nfc-mfultralight - Outil en ligne de commande pour MIFARE Ultralight

SYNOPSIS

nfc-mfultralight r|w DUMP

DESCRIPTION

nfc-mfultralight est un outil MIFARE Ultralight qui permet de lire ou d'écrire des données de carte vers/depuis un fichier DUMP.

La carte MIFARE Ultralight est l'une des cartes RFID les plus utilisées pour les applications de billetterie. Elle utilise un fichier binaire Mifare Dump (MFD) pour stocker les données de tous les secteurs.

Soyez prudent car certaines parties de la mémoire Ultralight ne peuvent être écrites qu'une seule fois et certaines parties sont utilisées comme bits de verrouillage, veuillez donc lire la documentation de la carte avant d'expérimenter trop !

Pour définir l'UID d'une carte spéciale à UID inscriptible, modifiez les 7 premiers octets d'un fichier dump, puis réécrivez-le en répondant 'Y' à la question 'Écrire les octets UID ?'.

OPTIONS

r | w Effectue une lecture depuis ( r ) ou une écriture vers ( w ) la carte.

DUMP
MiFare Dump (MFD) utilisé pour écrire (carte vers MFD) ou (MFD vers carte)
