NOM

nfsrahead - Configurer la lecture anticipée (readahead) pour les montages NFS

SYNTAXE

nfsrahead [-F] [-d] <périphérique>

DESCRIPTION

nfsrahead est un outil destiné à être utilisé avec udev pour définir le paramètre read_ahead_kb des montages NFS, conformément au fichier de configuration (voir CONFIGURATION). périphérique est le numéro de périphérique pour le périphérique sous-jacent NFS tel que fourni par le noyau.

OPTIONS

-F
Envoyer des messages à stderr au lieu de syslog
-d
Augmenter le niveau de débogage.

CONFIGURATION

nfsrahead est configuré dans /etc/nfs.conf, dans la section intitulée nfsrahead. Il accepte les configurations suivantes.

nfs=<valeur>
La valeur de lecture anticipée appliquée aux montages NFSv3.
nfs4=<valeur>
La valeur de lecture anticipée appliquée aux montages NFSv4.
défaut=<valeur>
La configuration par défaut lorsque aucune des configurations ci-dessus n'est définie.

EXEMPLE CONFIGURATION

[nfsrahead]
nfs=15000 # lecture anticipée de 15000 pour les montages NFSv3
nfs4=16000 # lecture anticipée de 16000 pour les montages NFSv4
défaut=128 # par défaut est 128

VOIR AUSSI

mount.nfs(8), nfs(5), nfs.conf(5), udev(7), bcc-readahead(8)
