NOM

nfct - outil en ligne de commande pour configurer le système de suivi de connexion

SYNTAXE

nfct commande sous-système [paramètres]

DESCRIPTION

nfct est l'outil en ligne de commande qui vous permet de configurer le système de suivi de connexion.

COMMANDES

lister
Liste les objets existants.
ajouter
Ajoute un nouvel objet.
supprimer
Supprime un objet.
obtenir
Obtient un objet existant.
vider
Vide la table des objets de comptabilité.
désactiver
Cette commande est pour le sous-système des assistants. Elle vous permet de désactiver l'envoi de paquets vers l'espace utilisateur pour l'inspection par les assistants.
définir-par-défaut
Cette commande est pour le sous-système des délais d'attente. Elle vous permet de définir des délais d'attente par défaut pour les protocoles.
obtenir-par-défaut
Cette commande est pour le sous-système des délais d'attente. Elle vous permet d'obtenir les délais d'attente par défaut pour les protocoles.

SOUS-SYSTÈMES

Au moment de la rédaction de cette page de manuel, les sous-systèmes pris en charge sont timeout (délai d'attente) et helper (assistant).

timeout
Le sous-système de délai d'attente vous permet de définir des politiques de délai d'attente fines.
helper
Le sous-système d'assistants vous permet de configurer les assistants en espace utilisateur.
version
Affiche les informations de version.
aide
Affiche le message d'aide.

EXEMPLE

nfct ajouter timeout test-tcp inet tcp établi 100 fermé 10 close_wait 10
Ceci crée une politique de délai d'attente pour tcp en utilisant 100 secondes pour l'état ÉTABLI, 10 secondes pour l'état FERMÉ et 10 secondes pour l'état CLOSE_WAIT.
Ensuite, vous pouvez attacher la politique de délai d'attente avec la cible CT d'iptables :
iptables -I PREROUTING -t raw -p tcp -j CT --timeout test-tcp
iptables -I OUTPUT -t raw -p tcp -j CT --timeout test-tcp
Vous pouvez tester la politique de délai d'attente avec :
conntrack -E -p tcp
Il devrait afficher :
[MISE À JOUR] tcp 6 100 ESTABLISHED src=192.168.39.100 dst=57.126.1.20 sport=56463 dport=80 src=57.126.1.20 dst=192.168.39.100 sport=80 dport=56463 [ASSURED]
