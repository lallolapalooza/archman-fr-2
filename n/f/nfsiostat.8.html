nfsiostat(8) Manuel de l'administrateur système nfsiostat(8)

NOM

nfsiostat - Émuler iostat pour les points de montage NFS en utilisant /proc/self/mountstats

SYNTAXE

nfsiostat [[<intervalle>] [<compte>]] [<options>][<point_de_montage>]

DESCRIPTION

La commande nfsiostat affiche les statistiques par point de montage du client NFS.

<intervalle>
spécifie la durée en secondes entre chaque rapport. Le premier rapport contient les statistiques depuis le montage de chaque système de fichiers. Chaque rapport subséquent contient les statistiques collectées pendant l'intervalle depuis le rapport précédent.
<compte>
Si le paramètre <compte> est spécifié, la valeur de <compte> détermine le nombre de rapports générés à <intervalle> secondes d'intervalle. Si le paramètre d'intervalle est spécifié sans le paramètre <compte>, la commande génère des rapports en continu.
<options>
Définir ci-dessous
<point_de_montage>
Si un ou plusieurs noms de <point de montage> sont spécifiés, seules les statistiques pour ces points de montage seront affichées. Sinon, tous les points de montage NFS sur le client sont listés.
La signification de chaque colonne de la sortie de nfsiostat est la suivante :
- op/s
C'est le nombre d'opérations par seconde.
- rpc bklog
C'est la longueur de la file d'attente.
- kB/s
C'est le nombre de ko écrits/lus par seconde.
- kB/op
C'est le nombre de ko écrits/lus par opération.
- retrans
C'est le nombre de retransmissions.
- RTT moyen (ms)
C'est la durée entre le moment où le noyau du client envoie la requête RPC et le moment où il reçoit la réponse.
- exe moyen (ms)
C'est la durée entre le moment où le client NFS effectue la requête RPC à son noyau et le moment où la requête RPC est terminée, cela inclut le temps RTT mentionné ci-dessus.
- queue moyen (ms)
C'est la durée entre le moment où le client NFS a créé la tâche de requête RPC et le moment où la requête est transmise.
- erreurs
C'est le nombre d'opérations qui se sont terminées avec un statut d'erreur (statut < 0). Ce compteur n'est disponible que sur les noyaux avec la version 1.1 ou supérieure des statistiques RPC iostats.
Notez que si un intervalle est utilisé comme argument pour nfsiostat, alors la différence par rapport à l'intervalle précédent sera affichée, sinon les résultats seront ceux depuis le montage du partage.

OPTIONS

-a ou --attr
affiche les statistiques relatives au cache d'attributs
-d ou --dir
affiche les statistiques relatives aux opérations sur les répertoires
-h ou --help
affiche le message d'aide et quitte
-l LISTE ou --list=LISTE
n'affiche les statistiques que pour les LISTE premiers points de montage
-p ou --page
affiche les statistiques relatives au cache de pages
-s ou --sort
Trie les points de montage NFS par ops/seconde
--version
affiche le numéro de version du programme et quitte

FICHIERS

/proc/self/mountstats

VOIR AUSSI

iostat(8), mountstats(8), nfsstat(8)
