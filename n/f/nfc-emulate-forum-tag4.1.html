NOM

nfc-emulate-forum-tag4 — outil de démonstration en ligne de commande pour l'émulation de tag NFC Forum type 4

SYNOPIS

nfc-emulate-forum-tag4 [-1] [infile [outfile]]

DESCRIPTION

nfc-emulate-forum-tag4 est un outil de démonstration qui émule un tag NFC Forum type 4 v2.0 (ou v1.0) avec un contenu NDEF.

-1 peut être fourni pour forcer le comportement de l'ancienne version 1.0 du Tag Type 4.

infile est le fichier qui contient le message NDEF que vous souhaitez partager avec le périphérique initiateur conforme au NFC-Forum (par exemple, Nokia 6212 Classic pour un tag v1.0).

Si vous souhaitez enregistrer un contenu partagé par le périphérique initiateur, nous devons fournir l'argument outfile pour indiquer où le message NDEF sera enregistré.

Cet exemple utilise la capacité matérielle du PN532 pour gérer les trames de bas niveau ISO/IEC 14443-4 telles que RATS/ATS, WTX, etc.

Tous les périphériques conformes au NFC-Forum Tag Type 4 (Version 2.0 ou 1.0) peuvent être utilisés avec cet exemple en mode lecture-écriture.

Si aucun argument n'est donné, un fichier NDEF par défaut est disponible.

NOTES D'IMPLÉMENTATION

Vous pouvez spécifier le même fichier pour infile et outfile.

IMPORTANT

Seuls les périphériques équipés de PN532 peuvent utiliser cet exemple. (par exemple, carte d'extension PN532).

Les périphériques ACR122 (comme touchatag, etc.) peuvent être utilisés par cet exemple, mais si quelque chose tourne mal, vous devrez débrancher/rebrancher votre périphérique. Ce n'est pas un bug de libnfc, ce problème est dû au MCU interne de l'ACR122 devant la puce NFC (PN532).
