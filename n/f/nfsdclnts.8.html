NOM

nfsdclnts - affiche diverses informations sur les clients NFS pour le serveur knfsd.

SYNTAXE

nfsdclnts [-h] [-t type] [--clientinfo] [--hostname] [-q]

DESCRIPTION

La commande nfsdclnts(8) analyse le contenu présent dans les répertoires /proc/fs/nfsd/clients/. nfsdclnts(8) affiche les fichiers qui sont ouverts, verrouillés, délégués par le client NFS. Elle affiche également des informations utiles sur le client telles que le nom d'hôte, l'ID du client, la version NFS montée par le client NFS.

OPTIONS

-t, --type=TYPE

Spécifie le type de fichier à afficher. N'accepte qu'un seul TYPE à la fois.

open, lock, deleg, layout, ou all

open : affiche les fichiers ouverts par le(s) client(s) NFS.

lock : affiche les fichiers verrouillés par le(s) client(s) NFS.

layout : affiche les fichiers pour lesquels une disposition est fournie.

deleg : affiche les informations sur les fichiers délégués et le type de délégation.

all : affiche tous les types ci-dessus.

--clientinfo

affiche divers champs d'informations sur le client NFS tels que la version de NFS montée par le client NFS et l'ID du client.

--hostname

Affiche le nom d'hôte du client NFS au lieu de l'adresse IP.

-q, --quiet

Masque les informations d'en-tête.

-v, --verbose

Fonctionnement détaillé, affiche les messages de débogage.

-f, --file

Au lieu de traiter tous les répertoires clients sous /proc/fs/nfsd/clients/, on peut fournir un fichier d'états spécifique à traiter. Il faut s'assurer que le fichier d'informations réside dans le même répertoire que le fichier d'états. Si le fichier d'informations n'est pas valide ou présent, les champs seront marqués comme « N/A ».

-h, --help

Affiche l'aide expliquant les options de la ligne de commande.

EXEMPLES

nfsdclnts --type open

Liste tous les fichiers avec le type d'ouverture uniquement.
Numéro d'inode | Type   | Accès | Refus | adresse IP            | Nom de fichier
33823232     | open   | r-    | --    | [::1]:757             | testfile

nfsdclnts --type deleg

Liste tous les fichiers avec le type de délégation uniquement.
Numéro d'inode | Type   | Accès | adresse IP            | Nom de fichier
33823232     | deleg  | r     | [::1]:757             | testfile

nfsdclnts --hostname

Affiche le nom d'hôte au lieu de l'adresse IP.
Numéro d'inode | Type   | Accès | Refus | Nom d'hôte            | Nom de fichier
33823232     | open   | r-    | --    | nfs-server            | testfile
33823232     | deleg  | r     |       | nfs-server            | testfile

nfsdclnts --clientinfo

Affiche les informations du client.
Numéro d'inode | Type   | Accès | Refus | adresse IP            | ID du client        | vers | Nom de fichier
33823232     | open   | r-    | --    | [::1]:757             | 0xc79a009f5eb65e84  | 4.2  | testfile
33823232     | deleg  | r     |       | [::1]:757             | 0xc79a009f5eb65e84  | 4.2  | testfile

nfsdclnts --file /proc/fs/nfsd/clients/3/states -t open

Traite un fichier d'états spécifique.
Numéro d'inode | Type   | Accès | Refus | adresse IP            | ID du client        | vers | Nom de fichier
33823232     | open   | r-    | --    | [::1]:757             | 0xc79a009f5eb65e84  | 4.2  | testfile

nfsdclnts --quiet --hostname

Masque les informations d'en-tête.
33823232     | open   | r-    | --    | nfs-server            | testfile
33823232     | deleg  | r     |       | nfs-server            | testfile

FICHIERS

/proc/fs/nfsd/clients/

Affiche des informations de base sur chaque client NFSv4.

/proc/fs/nfsd/clients/#/info

Affiche des informations sur toutes les ouvertures détenues par le client donné, y compris les modes d'ouverture, les numéros de périphérique, les numéros d'inode et les propriétaires des ouvertures.

/proc/fs/nfsd/clients/#/states

NOTES

Le support de /proc/fs/nfsd/clients/ a été initialement introduit dans le noyau 5.3 et n'est implémenté que pour les points de montage utilisant NFSv4.
