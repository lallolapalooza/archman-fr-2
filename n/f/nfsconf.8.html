NOM

nfsconf - Interroger divers paramètres de configuration NFS

SYNTAXE

nfsconf --dump [-v|--verbose] [-f|--file infile.conf] [outfile]

nfsconf --entry [--arg sous-section] section tag

nfsconf --get [-v|--verbose] [-f|--file infile.conf] [-a|--arg sous-section] section tag

nfsconf --isset [-v|--verbose] [-f|--file infile.conf] [-a|--arg sous-section] section tag

nfsconf --set [-v|--verbose] [-m|--modified Texte de modification] [-f|--file infile.conf] [-a|--arg sous-section] section tag valeur

nfsconf --unset [-v|--verbose] [-f|--file infile.conf] [-a|--arg sous-section] section tag

DESCRIPTION

La commande nfsconf peut être utilisée pour tester et récupérer les paramètres de configuration d'une gamme de fichiers de configuration nfs-utils.

Modes

Les modes suivants sont disponibles :

-d, --dump
Affiche un vidage trié alphabétiquement de la configuration actuelle au format fichier de configuration. Accepte un nom de fichier optionnel dans lequel écrire la sortie.
-e, --entry
récupère l'entrée de configuration plutôt que sa valeur développée actuelle
-i, --isset
Teste si une balise spécifique a une valeur définie.
-g, --get
Affiche la valeur actuelle de la balise spécifiée.
-s, --set
Met à jour ou ajoute une balise et une valeur au fichier de configuration dans une section spécifiée, créant la balise, la section et le fichier si nécessaire. Si la section est définie comme '#' alors un commentaire est ajouté au fichier. Si un commentaire est défini avec un nom de balise, tout commentaire tagué existant avec un nom correspondant est remplacé.
-u, --unset
Supprime la balise spécifiée et sa valeur du fichier de configuration.

OPTIONS

Options valides dans tous les modes

-v, --verbose
Augmente la verbosité et affiche des informations de débogage.
-f, --file infile
Sélectionne un fichier de configuration différent pour opérer, par défaut c'est /etc/nfs.conf

Options uniquement valides dans les modes --entry, --get et --isset.

-a, --arg sous-section
Sélectionne une sous-section spécifique.

Options uniquement valides en mode --set.

-m, --modified "Modifié par nfsconf" Définit le texte sur le commentaire de date de modification dans le fichier. Défini sur vide pour supprimer.

STATUT DE SORTIE

Mode --isset

Dans ce mode, la commande retournera succès (0) si la balise sélectionnée a une valeur. Tout autre code de sortie indique que la valeur n'est pas définie ou qu'une autre erreur s'est produite.

Tous les autres modes

Le succès est indiqué par un statut de sortie de zéro. Tout autre statut indique une erreur. Les messages d'erreur sont affichés sur stderr, et une verbosité accrue donnera des explications plus détaillées si disponibles.

EXEMPLES

nfsconf -v --dump --file /tmp/testconf.conf sorted.conf
Vérifie un nouveau fichier de configuration pour les erreurs de syntaxe et affiche une version triée pour faciliter la comparaison avec les paramètres existants.
if ! nfsconf --isset gssd preferred-realm ; then echo 'Aucun realm préféré configuré pour gss'; fi
L'outil permet de tester facilement les valeurs de configuration depuis des scripts shell. Ici, nous testons si une valeur spécifique a été définie.
nfsconf --file /etc/nfsmount.conf --get --arg /home MountPoint background
Affiche la valeur par défaut pour l'option background pour les montages NFS du chemin /home.
nfsconf --file /etc/nfs.conf --set nfsd debug 1
Active le débogage dans nfsd.
