NFSVIS(1) Manuel des commandes générales NFSVIS(1)

NOM

nfsvis - visualiser les performances des statistiques NFS

SYNTAXE

nfsvis [-V] [-c version] [-m maxrate] [-s version] [options pmview]

DESCRIPTION

nfsvis affiche un graphique en barres tridimensionnel des statistiques de requêtes NFS. L'affichage est mis à jour avec de nouvelles valeurs récupérées de l'hôte cible ou de l'archive toutes les intervalles secondes (par défaut 2 secondes).

Deux blocs de statistiques sont affichés : un pour le serveur NFS et un pour les requêtes client NFS. La hauteur des barres est proportionnelle au taux auquel les différents types de requêtes sont traités.

nfsvis génère un fichier de configuration pmview(1) et transmet la plupart des options de ligne de commande à pmview(1). Par conséquent, les options de ligne de commande -A, -a, -C, -h, -n, -O, -p, -S, -t, -T, -Z et -z, ainsi que l'interface utilisateur, sont décrites dans la page de manuel pmview(1).

OPTIONS DE LIGNE DE COMMANDE

Les options spécifiques à nfsvis sont :

-c
Surveiller les métriques client NFS de version 2 ou 3. La valeur par défaut est la version 2.
-m
Utiliser maxrate comme taux maximum de requêtes NFS sur toutes les classes de requêtes, à partir duquel la hauteur des barres est calculée. Ceci spécifie effectivement la hauteur à laquelle les barres seront coupées.
-s
Surveiller les métriques serveur NFS de version 2 ou 3. La valeur par défaut est la version 2.
-V
Mode verbeux - afficher le fichier de configuration pmview(1) généré.

FICHIERS

$PCP_VAR_DIR/config/pmlogger/config.nfsvis
Un fichier de configuration pmlogger(1) pour les métriques nfsvis.
$PCP_SHARE_DIR/lib/pmview-args
Procédures shell pour l'analyse des options de ligne de commande de pmview(1).

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(4).
