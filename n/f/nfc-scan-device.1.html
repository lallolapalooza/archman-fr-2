NOM

nfc-scan-device - Scanner les périphériques NFC

SYNTAXE

nfc-scan-device [ options ]

DESCRIPTION

nfc-scan-device est un utilitaire permettant de lister tous les périphériques disponibles conformes à libnfc. Il peut éventuellement afficher les capacités du périphérique.

OPTIONS

-v
Indique à nfc-scan-device d'être verbeux et d'afficher des informations détaillées sur les périphériques trouvés.
-i
Indique à nfc-scan-device d'autoriser un scan intrusif (par exemple, scan des ports série). Ceci est équivalent à définir la variable d'environnement LIBNFC_INTRUSIVE_SCAN à "yes".

EXEMPLE

Pour un périphérique SCL3711 (en mode verbeux) :


- SCM Micro / SCL3711-NFC&RW:
pn53x_usb:002:017
puce: PN533 v2.7
modulations en mode initiateur : ISO/IEC 14443A (106 kbps), FeliCa (424 kbps, 212 kbps), ISO/IEC 14443-4B (847 kbps, 424 kbps, 212 kbps, 106 kbps), Innovision Jewel (106 kbps), D.E.P. (424 kbps, 212 kbps, 106 kbps)
modulations en mode cible : ISO/IEC 14443A (106 kbps), FeliCa (424 kbps, 212 kbps), D.E.P. (424 kbps, 212 kbps, 106 kbps)
