NOM

nfc-emulate-forum-tag2 — outil de démonstration en ligne de commande pour l'émulation de tag NFC Forum type 2

SYNTAXE

nfc-emulate-forum-tag2

DESCRIPTION

nfc-emulate-forum-tag2 est un outil de démonstration qui émule un tag NFC Forum de type 2 avec un contenu NDEF.

Certains appareils compatibles avec le NFC Forum Tag Type 2 peuvent être utilisés avec cet exemple, en mode lecture seule.

IMPORTANT

Cet exemple a été développé en utilisant le matériel USB PN533 comme cible et un téléphone Google Nexus S comme initiateur.

Il est connu pour NE PAS fonctionner avec le Nokia 6212 Classic et pourrait échouer avec plusieurs appareils compatibles NFC Forum pour les raisons suivantes :

- La cible émulée n'a qu'un UID de 4 octets, tandis que la plupart des appareils supposent qu'un tag de type 2 a toujours un UID de 7 octets (comme un vrai tag Mifare Ultralight) ;

- La puce émule un tag ISO/IEC 14443-3, sans aucune aide matérielle. Si l'initiateur a des délais d'attente trop stricts pour l'émulation logicielle (ce qui est généralement le cas), cet exemple échouera. Ce n'est pas un bug et nous ne pouvons rien faire avec ce matériel (PN531/PN533).

Les appareils ACR122 (comme touchatag, etc.) peuvent être utilisés par cet exemple, mais si quelque chose ne va pas, vous devrez débrancher/rebrancher votre appareil. Ce n'est pas un bug de libnfc, ce problème est dû au MCU interne de l'ACR122 placé devant la puce NFC (PN532).
