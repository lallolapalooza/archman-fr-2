NOM

nfc-jewel - Outil en ligne de commande Jewel

SYNTAXE

nfc-jewel r|w DUMP

DESCRIPTION

nfc-jewel est un outil Jewel qui permet de lire ou d'écrire les données d'une étiquette vers/depuis un fichier DUMP.

L'étiquette Jewel de Broadcom, anciennement Innovision, utilise un fichier binaire Dump pour stocker les données de tous les secteurs.

Soyez prudent, certaines parties de la mémoire Jewel ne peuvent être écrites qu'une seule fois et certaines parties sont utilisées comme bits de verrouillage. Veuillez donc lire la documentation de l'étiquette avant d'expérimenter trop !

OPTIONS

r | w Effectuer une lecture depuis ( r ) ou une écriture vers ( w ) la carte.

DUMP
Dump JeWel (JWD) utilisé pour écrire (carte vers JWD) ou (JWD vers carte)
