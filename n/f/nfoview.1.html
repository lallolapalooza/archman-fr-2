NOM

nfoview - visionneuse pour fichiers NFO

SYNOPSIS

nfoview [FICHIER...]

DESCRIPTION

nfoview est une visionneuse simple pour les fichiers NFO, qui sont de l'art ASCII dans la page de code CP437. Les avantages d'utiliser nfoview au lieu d'un éditeur de texte sont les préréglages de police et d'encodage, la taille automatique de la fenêtre et les hyperliens cliquables.
