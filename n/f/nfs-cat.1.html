NOM

nfs-cat - Utilitaire pour lire un fichier depuis NFS

SYNTAXE

nfs-cat <URL_NFS>

DESCRIPTION

nfs-cat est un utilitaire pour lire un fichier depuis un serveur NFS.

Exemple : Afficher le contenu d'un fichier :

$ nfs-cat nfs://127.0.0.1/data/tmp/foo.c
