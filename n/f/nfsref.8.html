NFSREF(8) Manuel de l'administrateur système NFSREF(8)

NOM

nfsref - gérer les référencements NFS

SYNTAXE

nfsref [-?d] [-t type] add chemin_fichier serveur export [ serveur export ... ]

nfsref [-?d] [-t type] remove chemin_fichier

nfsref [-?d] [-t type] lookup chemin_fichier

INTRODUCTION

La version 4 de NFS introduit le concept de référencements de systèmes de fichiers à NFS.

Un référencement de système de fichiers est similaire à un lien symbolique (ou symlink) vers un partage de système de fichiers différent, typiquement sur un autre serveur de fichiers. Un client NFS, sous la direction du serveur, monte l'exportation NFS référencée automatiquement lorsqu'une application y accède pour la première fois.

Les référencements NFSv4 peuvent être utilisés pour rediriger transparencement les clients vers des systèmes de fichiers qui ont été déplacés ailleurs, ou pour construire un espace de noms de fichiers unique à travers plusieurs serveurs de fichiers. Étant donné que les serveurs de fichiers contrôlent la forme de l'ensemble de l'espace de noms de fichiers, aucune configuration client n'est requise.

DESCRIPTION

Une jonction est un objet du système de fichiers sur un serveur NFS qui, lorsqu'un client NFS la rencontre, déclenche un référencement. Similaire à un lien symbolique, une jonction contient un ou plusieurs emplacements cibles que le serveur envoie aux clients sous la forme d'un référencement NFSv4.

Sous Linux, un répertoire existant peut être converti en jonction et inversement de manière atomique et sans perte de contenu du répertoire. Lorsqu'un répertoire agit comme une jonction, son contenu local est caché des clients NFSv4.

La commande nfsref(8) est un moyen simple de commencer à gérer les jonctions et leur contenu.

Sous-commandes

Les sous-commandes valides de nfsref(8) sont :

add
Ajoute des informations de jonction au répertoire nommé par chemin_fichier. Le répertoire nommé doit déjà exister et ne doit pas contenir d'informations de jonction. Le contenu régulier du répertoire est obscurci pour les clients NFS par cette opération.
Une liste d'une ou plusieurs paires serveur/chemin d'exportation est également spécifiée sur la ligne de commande. Lors de la création d'une jonction NFS de base, cette liste est stockée dans un attribut étendu du répertoire.
Si la création de la jonction réussit, la commande nfsref(8) vide le cache d'exportation du noyau pour supprimer les informations de jonction précédemment mises en cache.
remove
Supprime les informations de jonction du répertoire nommé par chemin_fichier. Le répertoire nommé doit exister et contenir des informations de jonction. Le contenu régulier du répertoire est rendu à nouveau visible pour les clients NFS par cette opération.
Si la suppression de la jonction réussit, la commande nfsref(8) vide le cache d'exportation du noyau pour supprimer les informations de jonction précédemment mises en cache.
lookup
Affiche les informations de jonction stockées dans le répertoire nommé par chemin_fichier. Le répertoire nommé doit exister et contenir des informations de jonction.
Lors de la recherche d'une jonction NFS de base, les informations de jonction dans le répertoire sont listées sur stdout.

Options de ligne de commande

-d, --debug
Active les messages de débogage pendant l'opération.
-t, --type=type-de-jonction
Spécifie le type de jonction pour l'opération. Les valeurs valides pour type-de-jonction sont nfs-basic ou nfs-fedfs.
Pour la sous-commande add, la valeur par défaut si cette option n'est pas spécifiée est nfs-basic. Le type nfs-fedfs n'est pas utilisé dans cette implémentation.
Pour les sous-commandes remove et lookup, l'option --type n'est pas requise. La commande nfsref(8) opère sur les contenus de jonction disponibles.

EXEMPLES

Supposons que vous ayez deux serveurs de fichiers, top.example.net et home.example.net. Vous souhaitez que tous vos clients montent top.example.net:/, puis voient automatiquement les fichiers sous home.example.net:/ dans top:/home.

Sur top.example.net, vous pourriez exécuter cette commande en tant que root :

# mkdir /home
# nfsref add /home home.example.net /
Créé la jonction /home.
