NOM

nfnl_osf — utilitaire de chargement des empreintes de systèmes d'exploitation

SYNTAXE


nfnl_osf -f empreintes [ -d ]

DESCRIPTION

L'utilitaire nfnl_osf permet de charger un ensemble de signatures de systèmes d'exploitation dans le noyau pour une correspondance ultérieure à l'aide de la correspondance osf d'iptables.

OPTIONS

-f empreintes
Lire les signatures à partir du fichier empreintes.
-d
Au lieu d'ajouter les signatures de empreintes dans le noyau, les supprimer.

STATUT DE SORTIE

Le statut de sortie est 0 si la commande a réussi, sinon un code de retour négatif indique le type d'erreur qui s'est produit :

-1
Arguments illégaux passés, fichier d'empreintes illisible ou échec de la communication netlink.
-ENOENT
Fichier d'empreintes non spécifié.
-EINVAL
Initialisation du descripteur Netlink échouée ou format de fichier d'empreintes invalide.

FICHIERS

Un ensemble à jour de signatures de systèmes d'exploitation peut être téléchargé depuis http://www.openbsd.org/cgi-bin/cvsweb/src/etc/pf.os .

VOIR AUSSI

La description de la correspondance osf dans iptables-extensions(8) contient plus d'informations sur le sujet ainsi que des exemples d'invocations de nfnl_osf.
