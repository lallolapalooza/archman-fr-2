NOM

nfc-list - lister les cibles NFC

SYNTAXE

nfc-list [ options ]

DESCRIPTION

nfc-list est un utilitaire pour lister toutes les étiquettes disponibles telles que ISO14443-A, FeliCa, Jewel ou ISO14443-B (selon les capacités de l'appareil). Il peut détecter plusieurs étiquettes à la fois grâce à un mécanisme appelé anti-collision, mais tous les types d'étiquettes ne supportent pas l'anti-collision et il existe des limitations physiques au nombre d'étiquettes que le lecteur peut découvrir.

Cet outil affiche toutes les informations disponibles au moment de la sélection.

OPTIONS

-v
Indique à nfc-list d'être verbeux et d'afficher des informations détaillées sur les cibles affichées. Cela inclut le décodage SAK et l'empreinte digitale si disponible.
-t X
Sonde uniquement pour les types selon la valeur du champ de bits de X :


1: ISO14443A
2: FeliCa (212 kbps)
4: FeliCa (424 kbps)
8: ISO14443B
16: ISO14443B'
32: ISO14443B-2 ST SRx
64: ISO14443B-2 ASK CTx
128: ISO14443B iClass
256: ISO14443A-3 Jewel
512: ISO14443A-2 NFC Barcode

Donc 1023 (par défaut) sonde pour tous les types. Notez que si 16, 32, 64 ou 128 sont sélectionnés, 8 est également sélectionné.

EXEMPLE

Pour une étiquette ISO/IEC 14443-A (par exemple, Mifare DESFire) :


ATQA (SENS_RES): 03 44
UID (NFCID1): 04 45 35 01 db 24 80
SAK (SEL_RES): 20
ATS (ATR): 75 77 81 02 80
