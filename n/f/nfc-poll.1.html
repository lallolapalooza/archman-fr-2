NOM

nfc-poll - interroger la première cible NFC disponible

SYNTAXE

nfc-poll

DESCRIPTION

nfc-poll est un utilitaire pour interroger n'importe quelle cible disponible (étiquettes mais aussi cibles NFCIP) en utilisant les modulations ISO14443-A, FeliCa, Jewel et ISO14443-B.

Cet outil utilise la fonction d'interrogation matérielle si elle est disponible (par exemple, PN532) ou se rabat sur l'interrogation logicielle. Il affichera les informations disponibles récupérées de l'étiquette.

OPTIONS

-v
Indique à nfc-poll d'être disert et d'afficher des informations détaillées sur les cibles présentées. Cela inclut le décodage SAK et l'empreinte digitale si elle est disponible.

IMPORTANT

Il existe certaines limites bien connues avec cet exemple :
- Même avec NDO_AUTO_14443_4A activé (par défaut), nfc-poll peut manquer des ATS. Cela est dû à la manière dont le PN532 interroge les cibles ISO14443 de type A. Il tentera de trouver les cibles ISO14443-4 uniquement, puis les ISO14443-3. Si votre cible ISO14443-4 est présente lorsque le PN532 recherche les ISO14443-4 uniquement, l'ATS sera récupéré. Mais si votre cible entre dans le champ pendant l'ISO14443-3, RATS ne sera pas envoyé et ATS ne sera pas récupéré.
- nfc-poll peut n'afficher qu'une seule carte alors que deux sont dans le champ. Cela est dû, encore une fois, à la manière dont le PN532 interroge les cibles. Il arrêtera l'interrogation lorsqu'une modulation a obtenu un résultat. Ainsi, si vous avez, par exemple, une ISO14443-3 (par ex. Mifare Ultralight) et une ISO14443-4 (par ex. Mifare DESFire), il renverra probablement uniquement l'ISO14443-4.
