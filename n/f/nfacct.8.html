NOM

nfacct - outil en ligne de commande pour créer/récupérer/supprimer des objets de comptabilité

SYNTAXE

nfacct commande [nom] [options]

DESCRIPTION

nfacct est l'outil en ligne de commande qui permet de manipuler l'infrastructure de comptabilité étendue de Netfilter.

COMMANDES

Ces commandes spécifient l'action que nfacct effectue. Une seule d'entre elles peut être spécifiée à la fois.

lister
Lister les objets de comptabilité existants dans la table.
restaurer
Restaurer la table des objets de comptabilité en lisant depuis l'entrée standard. Le format d'entrée est celui utilisé en sortie par la commande lister.
ajouter
Ajouter un nouvel objet de comptabilité.
supprimer
Supprimer un objet de comptabilité.
obtenir
Obtenir un objet de comptabilité existant.
vider
Supprimer tous les objets de comptabilité inutilisés.
version
Afficher les informations de version.
aide
Afficher le message d'aide.

OPTIONS

Cet outil autorise également quelques options avec les commandes obtenir et lister, qui sont :
réinitialiser
Qui obtient et réinitialise atomiquement les compteurs.
xml
Qui affiche la sortie au format XML. json Qui affiche la sortie au format JSON.
