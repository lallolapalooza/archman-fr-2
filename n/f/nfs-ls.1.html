NOM

nfs-ls - Utilitaire pour lister les serveurs NFS, les exportations et les répertoires

SYNTAXE

nfs-ls [ OPTIONS ] <URL_NFS>

nfs-ls [-R --recursive] [-s --summary] [-D --discovery] [-? --help] [--usage]

DESCRIPTION

nfs-ls est un utilitaire pour lister les serveurs NFS, les exportations ou les répertoires.

Exemple : Lister le contenu d'un répertoire sur le serveur NFS

$ nfs-ls nfs://127.0.0.1/data/tmp
-rwxrwxr-x  1  1000  1000      1190802 a.out
-rwxr-xr-x  1  1000  1000           13 foo123.copy
-rwxrwxrwx  1  1000  1000            8 foo123.writtenx

OPTIONS

-s --summary

Affiche une ligne de résumé à la fin de la sortie.

-R --recursive

Listage récursif de l'URL spécifiée.

-D --discovery;

Cette option est utilisée pour découvrir les serveurs NFS locaux et pour lister les exportations pour des serveurs spécifiques.

Lorsqu'elle est utilisée avec l'URL 'nfs://', la commande tentera de détecter tous les serveurs NFS locaux et affichera leurs adresses IP.

Lorsqu'elle est utilisée avec un 'nfs://serveur', la commande listera toutes les exportations sur le serveur spécifié.

Exemple : Découvrir et lister tous les serveurs NFS locaux

$ nfs-ls -D nfs://
nfs://10.10.10.10
nfs://10.0.0.10

Exemple : Lister les exportations d'un serveur

$ nfs-ls -D nfs://10.10.10.10
nfs://10.10.10.10/foo
nfs://10.10.10.10/bar

-? --help

Affiche une aide basique.

--usage

Affiche un texte d'utilisation basique.
