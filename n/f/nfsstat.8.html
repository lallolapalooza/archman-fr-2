NOM

nfsstat - lister les statistiques NFS

SYNTAXE

nfsstat [OPTION]...

DESCRIPTION

La commande nfsstat affiche les statistiques conservées sur l'activité du client et du serveur NFS.

OPTIONS

-s, --server
Affiche uniquement les statistiques côté serveur. Par défaut, affiche les statistiques serveur et client.
-c, --client
Affiche uniquement les statistiques côté client.
-n, --nfs
Affiche uniquement les statistiques NFS. Par défaut, affiche les informations NFS et RPC.
-2
Affiche uniquement les statistiques NFS v2. Par défaut, affiche seulement les informations sur les versions de NFS qui ont des comptes non nuls.
-3
Affiche uniquement les statistiques NFS v3. Par défaut, affiche seulement les informations sur les versions de NFS qui ont des comptes non nuls.
-4
Affiche uniquement les statistiques NFS v4. Par défaut, affiche seulement les informations sur les versions de NFS qui ont des comptes non nuls.
-m, --mounts
Affiche les informations concernant chaque système de fichiers NFS monté.

Si cette option est utilisée, toutes les autres options sont ignorées.

-r, --rpc
Affiche uniquement les statistiques RPC.
-o facilité
Affiche les statistiques pour la facilité spécifiée, qui doit être l'une des suivantes :
nfs
Informations sur le protocole NFS, ventilées par appel RPC.
rpc
Informations générales sur RPC.
net
Statistiques de la couche réseau, comme le nombre de paquets reçus, le nombre de connexions TCP, etc.
fh
Informations d'utilisation du cache de descripteurs de fichiers du serveur, y compris le nombre total de recherches, ainsi que le nombre de succès et d'échecs.
rc
Informations d'utilisation du cache de réponses aux requêtes du serveur, y compris le nombre total de recherches, ainsi que le nombre de succès et d'échecs.
io
Informations d'utilisation des statistiques d'E/S du serveur ; octets lus et écrits.
ra
Informations d'utilisation du cache de pré-lecture du serveur, y compris la taille du cache ra, la profondeur des succès et des échecs du cache ra.
all
Affiche toutes les facilités ci-dessus.
-v, --verbose
C'est l'équivalent de -o all.
-l, --list
Affiche les informations sous forme de liste.
-S, --since fichier
Au lieu d'afficher les statistiques actuelles, nfsstat importe les statistiques du fichier et affiche la différence entre celles-ci et les statistiques actuelles. Les fichiers d'entrée valides peuvent être sous la forme /proc/net/rpc/nfs (statistiques brutes du client), /proc/net/rpc/nfsd (statistiques brutes du serveur), ou une sortie sauvegardée de nfsstat elle-même (statistiques client et/ou serveur). Toutes les statistiques manquantes dans un fichier de sortie nfsstat sauvegardé sont considérées comme nulles.
-Z[interval], --sleep=[interval]
Au lieu d'afficher les statistiques actuelles et de quitter immédiatement, nfsstat prend un instantané des statistiques actuelles et fait une pause jusqu'à ce qu'il reçoive SIGINT (généralement depuis Ctrl-C), moment auquel il prend un autre instantané et affiche la différence entre les deux. Si interval est spécifié, nfsstat affichera le nombre d'appels NFS effectués depuis le dernier rapport. Les statistiques seront affichées de manière répétée toutes les interval secondes.

EXEMPLES

nfsstat -o all -234
Affiche toutes les informations pour toutes les versions de NFS.
nfsstat --verbose -234
Identique à ci-dessus.
nfsstat -o all
Affiche toutes les informations pour les versions actives de NFS.
nfsstat --nfs --server -3
Affiche les statistiques du serveur NFS version 3.
nfsstat -m
Affiche les informations sur les systèmes de fichiers NFS montés.

AFFICHAGE

La sortie des Drapeaux de l'option -m est identique aux drapeaux donnés à la commande mount.

FICHIERS

/proc/net/rpc/nfsd
Interface basée sur procfs pour les statistiques du serveur NFS du noyau.
/proc/net/rpc/nfs
Interface basée sur procfs pour les statistiques du client NFS du noyau.
/proc/mounts
Interface basée sur procfs pour les systèmes de fichiers montés.

VOIR AUSSI

rpc.nfsd(8). nfs(5).

BOGUES

La sortie par défaut a été modifiée. Pour obtenir l'ancienne sortie par défaut, vous devez exécuter nfsstat --auto -2.

La fonction des options -v et -a a changé. L'option -a est désormais réservée pour une utilisation future. L'option -v fait ce que faisait l'option -a, et les nouvelles options -[234] remplacent l'option -v.

La section Affichage devrait être plus complète.

D'autres bogues peuvent être trouvés ou signalés sur http://nfs.sf.net/.

NAME

nfsstat — display network file system statistics

SYNOPSIS

nfsstat [options]

DESCRIPTION

The nfsstat program provides statistics about NFS (Network File System) operations. It can be used to display client and server statistics for both NFSv2, NFSv3, NFSv4, RPC (Remote Procedure Call), and related protocols.

When run without any options, nfsstat displays statistics for both the NFS client and server. The statistics are reset after the program is run, unless the -n option is used.

OPTIONS

-c, --client
Display only NFS client statistics.
-s, --server
Display only NFS server statistics.
-n, --noreset
Do not reset the statistics after displaying them. This is useful for monitoring statistics over time.
-r, --rpc
Display RPC statistics.
-m, --mounts
Display statistics per mounted file system. This option is only available for the NFS client.
-3, --nfs3
Display only NFSv3 statistics.
-4, --nfs4
Display only NFSv4 statistics.
-v, --verbose
Display more detailed statistics.
-h, --human-readable
Print sizes in human-readable format (e.g., 1K, 234M, 2G).
-t, --tcp
Display statistics for NFS over TCP.
-u, --udp
Display statistics for NFS over UDP.
-a, --all
Display all available statistics, including RPC and protocol-specific information.
-w, --width <width>
Specify the output width in characters.
--help
Display a help message and exit.
--version
Display version information and exit.

SEE ALSO

nfs(5), rpc.statd(8)

NOM

nfsstat — afficher les statistiques du système de fichiers réseau

SYNTAXE

nfsstat [options]

DESCRIPTION

Le programme nfsstat fournit des statistiques sur les opérations du NFS (Network File System). Il peut être utilisé pour afficher les statistiques du client et du serveur pour les protocoles NFSv2, NFSv3, NFSv4, RPC (Remote Procedure Call) et les protocoles associés.

Lorsqu'il est exécuté sans aucune option, nfsstat affiche les statistiques du client et du serveur NFS. Les statistiques sont réinitialisées après l'exécution du programme, sauf si l'option -n est utilisée.

OPTIONS

-c, --client
Afficher uniquement les statistiques du client NFS.
-s, --server
Afficher uniquement les statistiques du serveur NFS.
-n, --noreset
Ne pas réinitialiser les statistiques après leur affichage. Ceci est utile pour surveiller les statistiques au fil du temps.
-r, --rpc
Afficher les statistiques RPC.
-m, --mounts
Afficher les statistiques par système de fichiers monté. Cette option n'est disponible que pour le client NFS.
-3, --nfs3
Afficher uniquement les statistiques NFSv3.
-4, --nfs4
Afficher uniquement les statistiques NFSv4.
-v, --verbose
Afficher des statistiques plus détaillées.
-h, --human-readable
Afficher les tailles dans un format lisible par l'homme (par exemple, 1K, 234M, 2G).
-t, --tcp
Afficher les statistiques pour NFS sur TCP.
-u, --udp
Afficher les statistiques pour NFS sur UDP.
-a, --all
Afficher toutes les statistiques disponibles, y compris les informations RPC et spécifiques au protocole.
-w, --width <largeur>
Spécifier la largeur de sortie en caractères.
--help
Afficher un message d'aide et quitter.
--version
Afficher les informations de version et quitter.

VOIR AUSSI

nfs(5), rpc.statd(8)
