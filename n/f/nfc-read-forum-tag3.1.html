NOM

nfc-read-forum-tag3 - Extraire un message NDEF d'une balise NFC Forum Type 3

SYNTAXE

nfc-read-forum-tag3 [ -q ] -o FICHIER

DESCRIPTION

nfc-read-forum-tag3 Cet utilitaire extrait (si disponible) les messages NDEF contenus dans une balise NFC Forum Type 3 vers FICHIER.

OPTIONS

-o FICHIER : exporter le message NDEF extrait vers FICHIER (utiliser -o - pour exporter vers la sortie standard)

-q : mode silencieux, n'afficher pas les informations d'analyse des blocs d'attributs

BOGUES

Veuillez signaler tout bogue sur le traqueur de problèmes de libnfc à l'adresse :
https://github.com/nfc-tools/libnfc/issues
