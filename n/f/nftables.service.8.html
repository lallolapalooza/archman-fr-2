Nom

nftables.service — Configuration statique du pare-feu avec nftables.service

Description

Un service systemd pour nftables est fourni, permettant de configurer des règles de pare-feu statiques basées sur un fichier de configuration.

Pour utiliser ce service, vous devez créer le fichier de configuration principal dans /etc/nftables/rules/main.nft. Un modèle pour cela peut être copié depuis /usr/share/doc/nftables/main.nft. Alternativement, `nft list ruleset >main.nft` peut être utilisé pour enregistrer la configuration active (le cas échéant) dans le fichier.

Une fois la configuration statique de pare-feu souhaitée en place, elle peut être testée en exécutant `systemctl start nftables.service`. Pour activer le service au démarrage, exécutez `systemctl enable nftables.service`.
