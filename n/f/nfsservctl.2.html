nfsservctl(2) Manuel des appels système nfsservctl(2)

NOM

nfsservctl - interface d'appel système pour le démon nfs du noyau

BIBLIOTH&EGRAVEQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/nfsd/syscall.h>
long nfsservctl(int cmd, struct nfsctl_arg *argp,
                union nfsctl_res *resp);

DESCRIPTION

Note : Depuis Linux 3.1, cet appel système n'existe plus. Il a été remplacé par un ensemble de fichiers dans le système de fichiers nfsd ; voir nfsd(7).


/*
 * Ce sont les commandes comprises par nfsctl().
 */
#define NFSCTL_SVC        0  /* C'est un processus serveur.  */
#define NFSCTL_ADDCLIENT  1  /* Ajouter un client NFS.  */
#define NFSCTL_DELCLIENT  2  /* Supprimer un client NFS.  */
#define NFSCTL_EXPORT     3  /* Exporter un système de fichiers.  */
#define NFSCTL_UNEXPORT   4  /* Dé-exporter un système de fichiers.  */
#define NFSCTL_UGIDUPDATE 5  /* Mettre à jour la carte UID/GID d'un client
                                (uniquement sous Linux 2.4.x et antérieur).  */
#define NFSCTL_GETFH      6  /* Obtenir un descripteur de fichier (utilisé par
                                mountd(8)) (uniquement sous Linux 2.4.x et
                                antérieur).  */
struct nfsctl_arg {
    int                       ca_version;     /* garde */
    union {
        struct nfsctl_svc     u_svc;
        struct nfsctl_client  u_client;
        struct nfsctl_export  u_export;
        struct nfsctl_uidmap  u_umap;
        struct nfsctl_fhparm  u_getfh;
        unsigned int          u_debug;
    } u;
}
union nfsctl_res {
        struct knfs_fh          cr_getfh;
        unsigned int            cr_debug;
};

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné, et errno est défini pour indiquer l'erreur.

NORMES

Linux.

HISTORIQUE

Supprimé dans Linux 3.1. Supprimé dans glibc 2.28.

VOIR AUSSI

nfsd(7)
