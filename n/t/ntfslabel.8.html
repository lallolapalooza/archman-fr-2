NOM

ntfslabel - afficher/modifier l'étiquette d'un système de fichiers ntfs

SYNTAXE

ntfslabel [options] périphérique [nouvelle-étiquette]

DESCRIPTION

ntfslabel affichera ou modifiera l'étiquette du système de fichiers ntfs situé sur périphérique. Il peut également modifier le numéro de série du périphérique.

Si l'argument optionnel nouvelle-étiquette n'est pas présent, et qu'aucune option n'est présente, ntfslabel affichera simplement l'étiquette actuelle du système de fichiers.

Si l'argument optionnel nouvelle-étiquette est présent, alors ntfslabel définira l'étiquette du système de fichiers à nouvelle-étiquette. Les étiquettes de systèmes de fichiers NTFS peuvent avoir jusqu'à 128 caractères Unicode ; si nouvelle-étiquette est plus long que 128 caractères Unicode, ntfslabel la tronquera et affichera un message d'avertissement.

Il est également possible de définir l'étiquette du système de fichiers en utilisant l'option -L de mkntfs(8) lors de la création du système de fichiers.

OPTIONS

Ci-dessous un résumé de toutes les options que ntfslabel accepte. Presque toutes les options ont deux noms équivalents. Le nom court est précédé de - et le nom long est précédé de --. Toutes les options à une seule lettre, qui ne prennent pas d'argument, peuvent être combinées en une seule commande, par exemple -fv est équivalent à -f -v. Les options nommées longues peuvent être abrégées en n'importe quel préfixe unique de leur nom.

-f, --force
Ceci remplacera certains paramètres par défaut raisonnables, comme ne pas travailler sur un volume monté. Utilisez cette option avec prudence.
-h, --help
Affiche une liste des options avec une brève description de chacune.
--new-serial[=ssssssssssssssss], ou
--new-half-serial[=ssssssss]
Définit un nouveau numéro de série pour le périphérique, soit la valeur fournie en argument, soit une valeur aléatoire si aucun argument n'est donné. Le numéro de série est un nombre de 64 bits, représenté par un nombre hexadécimal de seize chiffres, utilisé pour identifier le périphérique pendant le processus de montage. Par conséquent, deux périphériques avec le même numéro de série ne peuvent pas être montés simultanément sur le même ordinateur. Ce n'est pas l'UUID du volume utilisé par Windows pour localiser les fichiers qui ont été déplacés vers un autre volume.

L'option --new-half-serial ne modifie que la partie supérieure du numéro de série, en conservant la partie inférieure qui est utilisée par Windows inchangée. Dans ce cas, l'argument optionnel est un nombre hexadécimal de huit chiffres.

-n, --no-action
N'écrit pas réellement sur le disque.
-q, --quiet
Réduit au minimum la quantité de sortie.
-v, --verbose
Augmente la quantité de sortie que ntfslabel imprime. L'étiquette et le numéro de série sont affichés.
-V, --version
Affiche le numéro de version, le copyright et la licence de ntfslabel.
