ntptrace(1) Commandes utilisateur ntptrace(1)

NOM

ntptrace - Tracer les pairs d'un serveur NTP

SYNOPIS

ntptrace [-flags] [-flag [valeur]] [--nom-option[[=| ]valeur]] [hôte]

DESCRIPTION

ntptrace est un script perl qui utilise l'utilitaire ntpq pour suivre la chaîne des serveurs NTP à partir d'un hôte donné jusqu'à la source de temps primaire. Pour que ntptrace fonctionne correctement, chacun de ces serveurs doit implémenter le protocole NTP de contrôle et de surveillance spécifié dans la RFC 1305 et activer les paquets NTP de mode 6.

Si aucun argument n'est donné, ntptrace commence avec localhost. Voici un exemple de sortie de ntptrace :


% ntptrace localhost: stratum 4, offset 0.0019529, synch distance 0.144135
server2ozo.com: stratum 2, offset 0.0124263, synch distance 0.115784 usndh.edu:
stratum 1, offset 0.0019298, synch distance 0.011993, refid 'WWVB'

Sur chaque ligne, les champs sont (de gauche à droite) : le nom de l'hôte, le stratum de l'hôte, le décalage temporel entre cet hôte et l'hôte local (tel que mesuré par ntptrace ; c'est pourquoi il n'est pas toujours zéro pour "localhost"), la distance de synchronisation de l'hôte, et (uniquement pour les serveurs de stratum 1) l'identifiant de l'horloge de référence. Tous les temps sont donnés en secondes. Notez que le stratum est le nombre de sauts du serveur jusqu'à la source primaire, tandis que la distance de synchronisation est l'erreur estimée par rapport à la source primaire. Ces termes sont précisément définis dans la RFC-1305.

OPTIONS

-n, --numerique

Afficher les adresses IP au lieu des noms d'hôtes.

Affiche les hôtes au format numérique point-quad plutôt que de les convertir en noms d'hôtes canoniques.

-m nombre, --max-hotes=nombre

Nombre maximum de pairs à tracer. Cette option prend un nombre entier comme argument. Le nombre par défaut pour cette option est :
99

Cette option n'a pas été entièrement documentée.

-r chaîne, --hote=chaîne

Hôte distant unique. La chaîne par défaut pour cette option est :
127.0.0.1

Cette option n'a pas été entièrement documentée.

-?, --aide

Afficher les informations d'utilisation et quitter.
-!, --plus-aide

Faire passer les informations d'utilisation étendues par un paginator.
-v [{v|c|n --version [{v|c|n}]}]

Afficher la version du programme et quitter. Le mode par défaut est `v', une simple version. Le mode `c' affichera les informations de copyright et `n' affichera la notice de copyright complète.
