NTFSSECAUDIT(8) Manuel du responsable système NTFSSECAUDIT(8)

NOM

ntfssecaudit - Audit de sécurité NTFS

SYNTAXE

ntfssecaudit [options] arguments

Où options est une combinaison de :

-a audit complet des données de sécurité (Linux uniquement)
-b sauvegarder les ACL
-e réglage des paramètres supplémentaires sauvegardés (en conjonction avec -s)
-h affichage des descripteurs de sécurité hexadécimaux sauvegardés dans un fichier
-r récursivité dans un répertoire
-s réglage des ACL sauvegardées
-u obtenir une proposition de mappage utilisateur
-v verbeux (très verbeux si défini deux fois)

et arguments définissent les paramètres et l'ensemble des fichiers concernés.

Taper secaudit sans arguments affichera un résumé des options disponibles.

DESCRIPTION

ntfssecaudit affiche la propriété et les permissions d'un ensemble de fichiers sur un système de fichiers NTFS, et vérifie leur cohérence. Il ne peut être lancé qu'en mode terminal (aucune interface graphique n'est disponible).

Lorsqu'un volume est requis, il doit être démonté, et la commande doit être exécutée en tant que root. Le volume peut être soit un périphérique bloc (c'est-à-dire une partition de disque), soit un fichier image.

Lors de l'action sur un répertoire ou un volume, la commande peut produire beaucoup d'informations. Il est donc conseillé de rediriger la sortie vers un fichier ou de la transmettre à un éditeur de texte pour examen.

OPTIONS

Ci-dessous se trouvent les combinaisons valides d'options et d'arguments que ntfssecaudit accepte. Tous les arguments indiqués sont obligatoires et doivent être uniques (si des caractères génériques sont utilisés, ils doivent résoudre en un seul nom).

-h fichier
Affiche sous une forme lisible par l'homme les descripteurs de sécurité hexadécimaux sauvegardés dans fichier. Ceci peut être utilisé pour transformer une sortie verbeuse en une sortie très verbeuse.
-a[rv] volume
Audite le volume : toutes les données de sécurité globales sur volume sont analysées et les erreurs sont affichées. Si l'option -r est présente, tous les fichiers et répertoires sont également analysés et leurs relations avec les données de sécurité globales sont vérifiées. Cela peut produire une grande quantité de données.

Cette option n'est pas efficace sur les volumes formatés pour les anciennes versions de NTFS (avant NTFS 3.0). Ces volumes n'ont pas de données de sécurité globales.

Lorsque des erreurs sont signalées, il est conseillé de réparer le volume avec un outil approprié (tel que chkdsk sous Windows).

[-v] volume fichier
Affiche les paramètres de sécurité de fichier : son mode Linux interprété (indicateurs rwx en octal) et son ACL Posix[1], sa clé de sécurité le cas échéant, et son descripteur de sécurité en cas de sortie verbeuse.
-r[v] volume répertoire
Affiche les paramètres de sécurité de tous les fichiers et sous-répertoires dans répertoire : leur mode Linux interprété (indicateurs rwx en octal) et leur ACL Posix[1], leur clé de sécurité le cas échéant, et leur descripteur de sécurité en cas de sortie verbeuse.
-b[v] volume [répertoire]
Extrait récursivement vers la sortie standard les ACL NTFS des fichiers dans volume et répertoire.
-s[ev] volume [fichier-sauvegarde]
Définit les ACL NTFS comme indiqué dans fichier-sauvegarde ou l'entrée standard. Les données d'entrée doivent avoir été créées sous Linux. Avec l'option -e, définit également des paramètres supplémentaires (actuellement les attributs Windows).
volume permissions fichier
Définit les paramètres de sécurité du fichier aux permissions. Permissions est le mode Linux demandé (indicateurs rwx, exprimés en forme octale comme dans chmod) ou une ACL Posix[1] (exprimée comme dans setfacl -m). Ceci définit une nouvelle ACL qui est effective pour Linux et Windows.
-r[v] volume permissions répertoire
Définit les paramètres de sécurité de tous les fichiers et sous-répertoires dans répertoire aux permissions. Permissions est le mode Linux demandé (indicateurs rwx, exprimés en forme octale comme dans chmod), ou une ACL Posix[1] (exprimée comme dans setfacl -m). Ceci définit de nouvelles ACL qui sont effectives pour Linux et Windows.
[-v] fichier-monté
Affiche les paramètres de sécurité de fichier-monté : son mode Linux interprété (indicateurs rwx en octal) et son ACL Posix[1], sa clé de sécurité le cas échéant, et son descripteur de sécurité en cas de sortie verbeuse. Ceci est un cas spécial qui agit sur un fichier (ou répertoire) monté et ne nécessite pas d'être root. L'interprétation de l'ACL Posix ne peut être affichée que si le chemin complet vers fichier-monté à partir de la racine de l'arborescence globale des fichiers est fourni.
-u[v] fichier-monté
Affiche le contenu proposé pour un fichier de mappage utilisateur, basé sur les paramètres de propriété définis par Windows sur fichier-monté, en supposant que ce fichier a été créé sous Windows par l'utilisateur qui devrait être mappé à l'utilisateur Linux actuel. Les informations affichées doivent être copiées dans le fichier .NTFS-3G/UserMapping où .NTFS-3G est un sous-répertoire caché de la racine de la partition pour laquelle le mappage doit être défini. Cela aura pour effet que la propriété des fichiers créés sur cette partition sera la même que celle du fichier-monté d'origine.

NOTE

[1] à condition que l'option ACL POSIX ait été sélectionnée au moment de la compilation. Une spécification d'ACL Posix ressemble à "[d:]{ugmo}:[id]:[perms],..." où id est un identifiant utilisateur ou groupe numérique, et perms un chiffre octal ou un ensemble des lettres r, w et x.

Exemple : "u::7,g::5,o:0,u:510:rwx,g:500:5,d:u:510:7"

EXEMPLES

Auditer les données de sécurité globales sur /dev/sda1

ntfssecaudit -ar /dev/sda1

Afficher les paramètres de propriété et de permissions pour les fichiers du répertoire /audio/music sur le périphérique /dev/sda5, sans les sous-répertoires :

ntfssecaudit /dev/sda5 /audio/music

Définir tous les fichiers du répertoire /audio/music sur le périphérique /dev/sda5 comme inscriptibles par le propriétaire et en lecture seule pour tout le monde :

ntfssecaudit -r /dev/sda5 644 /audio/music

CODES DE SORTIE

ntfssecaudit se termine avec une valeur de 0 lorsqu'aucune erreur n'a été détectée, et avec une valeur de 1 lorsqu'une erreur a été détectée.

ntfssecaudit(8)

NOM

ntfssecaudit - auditer les permissions de sécurité NTFS.

SYNTAXE

ntfssecaudit [options] fichier

DESCRIPTION

ntfssecaudit audite les permissions de sécurité NTFS sur le fichier spécifié.

OPTIONS

-v, --verbose
Mode verbeux.
-h, --help
Afficher un message d'aide et quitter.
-V, --version
Afficher les informations de version et quitter.

NOTE

Cette commande nécessite que le système de fichiers NTFS soit monté avec les permissions activées.

EXEMPLES

Auditer les permissions du fichier /mnt/windows/document.txt:

ntfssecaudit /mnt/windows/document.txt

Auditer les permissions du fichier /mnt/windows/document.txt en mode verbeux:

ntfssecaudit -v /mnt/windows/document.txt

CODES DE RETOUR

0
Succès.
1
Erreur.

PROBLÈMES CONNUS

Aucun problème connu pour le moment.
