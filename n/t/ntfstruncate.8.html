NTFSTRUNCATE(8) Manuel de l'administrateur système NTFSTRUNCATE(8)

NOM

ntfstruncate - tronquer un fichier sur un volume NTFS

SYNTAXE

ntfstruncate [options] périphérique fichier [type-attribut [nom-attribut]] nouvelle-longueur

DESCRIPTION

ntfstruncate tronque (ou étend) un attribut spécifié appartenant à un fichier ou un répertoire, à une longueur spécifiée.

OPTIONS

Ci-dessous un résumé de toutes les options que ntfstruncate accepte. Presque toutes les options ont deux noms équivalents. Le nom court est précédé de - et le nom long est précédé de --. Toutes les options à une seule lettre, qui ne prennent pas d'argument, peuvent être combinées en une seule commande, par ex. -fv est équivalent à -f -v. Les options nommées longues peuvent être abrégées en n'importe quel préfixe unique de leur nom.

-f, --force
Ceci remplacera certains paramètres par défaut raisonnables, comme ne pas utiliser un volume monté. Utilisez cette option avec prudence.
-h, --help
Affiche une liste d'options avec une brève description de chacune.
-l
Affiche les informations de licence.
-n, --no-action
Simule la troncature sans écrire réellement sur le périphérique.
-q, --quiet
Supprime certains messages de débogage/avertissement/erreur.
-v, --verbose
Affiche plus de messages de débogage/avertissement/erreur.
-V, --version
Affiche le numéro de version, le copyright et la licence de ntfstruncate.
type-attribut
Définit un type d'attribut particulier à tronquer (usage avancé uniquement). Par défaut, l'attribut $DATA sans nom (le contenu d'un fichier simple) sera tronqué. L'attribut doit être spécifié par un nombre en décimal ou hexadécimal :
Hex Décimal Nom
0x10 16 "$STANDARD_INFORMATION"
0x20 32 "$ATTRIBUTE_LIST"
0x30 48 "$FILE_NAME"
0x40 64 "$OBJECT_ID"
0x50 80 "$SECURITY_DESCRIPTOR"
0x60 96 "$VOLUME_NAME"
0x70 112 "$VOLUME_INFORMATION"
0x80 128 "$DATA"
0x90 144 "$INDEX_ROOT"
0xA0 160 "$INDEX_ALLOCATION"
0xB0 176 "$BITMAP"
0xC0 192 "$REPARSE_POINT"
0xD0 208 "$EA_INFORMATION"
0xE0 224 "$EA"
0xF0 240 "$PROPERTY_SET"
0x100 256 "$LOGGED_UTILITY_STREAM"
nom-attribut
Définit le nom de l'attribut particulier à tronquer (usage avancé uniquement).
nouvelle-longueur
Spécifie la taille cible du fichier. Elle sera arrondie au multiple de la taille du cluster. Un suffixe K, M, G, T, P ou E peut être ajouté pour indiquer un facteur multiplicateur de puissance de 1000. De même, un suffixe Ki, Mi, Gi, Ti, Pi ou Ei peut être ajouté pour indiquer un facteur multiplicateur de puissance de 1024.

EXEMPLES

Redimensionner à 100 Mo le fichier database.db situé dans le répertoire Data à la racine d'un système de fichiers NTFS.

ntfstruncate /dev/sda1 Data/database.db 100M

BOGUES

Il n'y a aucun problème connu avec ntfstruncate. Si vous trouvez un bogue, veuillez envoyer un e-mail décrivant le problème à l'équipe de développement :
ntfs-3g-devel@lists.sf.net
