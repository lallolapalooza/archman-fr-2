NOM

ntfswipe - écraser l'espace inutilisé sur un volume NTFS

SYNTAXE

ntfswipe [options] périphérique

DESCRIPTION

ntfswipe efface tout ou partie de l'espace inutilisé sur un volume NTFS en l'écrasant avec des zéros ou des octets aléatoires.

OPTIONS

Ci-dessous un résumé de toutes les options que ntfswipe accepte. Presque toutes les options ont deux noms équivalents. Le nom court est précédé de - et le nom long est précédé de --. Les options à lettre unique, qui ne prennent pas d'argument, peuvent être combinées en une seule commande, par exemple -fv est équivalent à -f -v. Les options nommées longues peuvent être abrégées en n'importe quel préfixe unique de leur nom.

-a, --all
Écrase tout l'espace inutilisé. Cela peut prendre un temps considérable. Si l'option --unused-fast (ou -U) est également présente, la méthode d'écrasement la plus rapide est utilisée.
-b, --bytes LISTE-D'OCTETS
Définit les octets de remplacement autorisés qui sont tirés au hasard pour écraser l'espace inutilisé. LISTE-D'OCTETS est une liste séparée par des virgules de valeurs dans la plage 0-255 exprimées en base octale, décimale ou hexadécimale.
-c, --count NOMBRE
Définit le nombre de fois où l'espace inutilisé doit être écrasé. Si les options --bytes et --count sont définies, l'espace est écrasé de manière répétée ce nombre de fois par chacune des valeurs de la liste.
-d, --directory
Écrase tous les index de répertoires, qui peuvent contenir les noms de fichiers supprimés.
-f, --force
Cela remplacera certains paramètres par défaut raisonnables, comme ne pas utiliser un volume monté. Utilisez cette option avec prudence.
-h, --help
Affiche une liste d'options avec une brève description de chacune.
-i, --info
Affiche des détails sur l'espace inutilisé, sans rien écraser.
-l, --logfile
Écrase le fichier journal (met à jour le journal).
-m, --mft
Écrase l'espace inutilisé dans le MFT (table principale des fichiers, qui contient les noms de fichiers et le contenu des fichiers courts).
-n, --no-action
Exécute le processus d'écrasement sans écrire sur le périphérique.
-p, --pagefile
Écrase l'espace d'échange de Windows.
-q, --quiet
Supprime certains messages de débogage/avertissement/erreur.
-s, --undel
Écrase l'espace qui était alloué à un fichier qui a été supprimé récemment et qui est toujours récupérable. Cette option n'est pas compatible avec --bytes et les octets de remplacement sont aléatoires ou tirés d'une liste standard.
-t, --tails
Écrase l'espace à la fin des fichiers qui est inutilisé, mais alloué car les allocations se font toujours par clusters entiers.
-u, --unused
Écrase l'espace qui n'est actuellement alloué à aucun fichier (mais qui peut avoir été utilisé dans le passé).
-U, --unused-fast
Écrase l'espace qui n'est actuellement alloué à aucun fichier, en essayant de ne pas écraser l'espace qui n'a pas été écrit depuis le dernier écrasement.
-v, --verbose
Affiche plus de messages de débogage/avertissement/erreur. Cette option peut être utilisée deux fois pour afficher encore plus de messages.
-V, --version
Affiche le numéro de version, le copyright et la licence de ntfswipe.

EXEMPLES

Écraser tout l'espace inutilisé dans un volume NTFS.

ntfswipe -a /dev/sda1

Écraser tous les noms de fichiers supprimés d'un volume NTFS.

ntfswipe -dms /dev/sda1

BOGUES

Il n'y a pas de problèmes connus avec ntfswipe. Si vous trouvez un bogue, veuillez envoyer un e-mail décrivant le problème à l'équipe de développement :
ntfs-3g-devel@lists.sf.net
