NOM

ntp-ctl - client de gestion pour le processus ntp-daemon ntpd-rs

SYNTAXE

ntp-ctl validate [-c chemin]

ntp-ctl status [-f format] [-c chemin]

ntp-ctl force-sync [-c chemin]

ntp-ctl -h

ntp-ctl -v

DESCRIPTION

Le client de gestion ntp-ctl permet la gestion de certains aspects du démon ntpd-rs. Actuellement, le client de gestion permet uniquement d'afficher l'état actuel du démon et de valider un fichier de configuration pour son utilisation avec le démon.

OPTIONS

-c chemin, --config=chemin
Chemin vers le fichier de configuration à partir duquel l'adresse du socket d'observation sera récupérée. Si non spécifié, la valeur par défaut est /etc/ntpd-rs/ntp.toml.
-f format, --format=format
Le format de sortie pour la commande status. Si non spécifié, la valeur par défaut est plain. Alternativement, le format prometheus est disponible pour afficher la sortie dans un format compatible OpenMetrics/Prometheus.
-h, --help
Affiche les instructions d'utilisation.
-v, --version
Affiche les informations de version.

COMMANDES

validate
Vérifie si la configuration spécifiée (ou /etc/ntpd-rs/ntp.toml par défaut) est valide.
status
Retourne des informations d'état sur l'état actuel du ntp-daemon auquel le client se connecte.
force-sync
Exécute interactivement une synchronisation unique de votre horloge. Cette commande peut être utilisée pour effectuer une synchronisation ponctuelle avec les sources de temps configurées dans votre fichier de configuration. Cette commande ne doit jamais être utilisée sans validation par un opérateur humain.
