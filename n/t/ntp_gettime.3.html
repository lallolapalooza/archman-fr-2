ntp_gettime(3) Manuel des fonctions de bibliothèque ntp_gettime(3)

NOM

ntp_gettime, ntp_gettimex - obtenir les paramètres de temps (interface du démon NTP)

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/timex.h>
int ntp_gettime(struct ntptimeval *ntv);
int ntp_gettimex(struct ntptimeval *ntv);

DESCRIPTION

Ces deux API renvoient des informations à l'appelant via l'argument ntv, une structure du type suivant :


struct ntptimeval {
    struct timeval time;    /* Temps actuel */
    long maxerror;          /* Erreur maximale */
    long esterror;          /* Erreur estimée */
    long tai;               /* Décalage TAI */
    /* Octets de remplissage supplémentaires permettant une expansion future */
};

Les champs de cette structure sont les suivants :

time
Le temps actuel, exprimé sous forme de structure timeval :

struct timeval {
    time_t      tv_sec;   /* Secondes depuis l'Époque */
    suseconds_t tv_usec;  /* Microsecondes */
};

maxerror
Erreur maximale, en microsecondes. Cette valeur peut être initialisée par ntp_adjtime(3), et est augmentée périodiquement (sur Linux : chaque seconde), mais est plafonnée à une limite supérieure (la constante du noyau NTP_PHASE_MAX, d'une valeur de 16 000).
esterror
Erreur estimée, en microsecondes. Cette valeur peut être définie via ntp_adjtime(3) pour contenir une estimation de la différence entre l'horloge système et l'heure réelle. Cette valeur n'est pas utilisée dans le noyau.
tai
Décalage TAI (Temps Atomique International).

ntp_gettime() renvoie une structure ntptimeval dans laquelle les champs time, maxerror, et esterror sont remplis.

ntp_gettimex() effectue la même tâche que ntp_gettime(), mais renvoie également des informations dans le champ tai.

VALEUR RENVOYÉE

Les valeurs renvoyées par ntp_gettime() et ntp_gettimex() sont les mêmes que pour adjtimex(2). Étant donné un pointeur d'argument correct, ces fonctions réussissent toujours.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

NORMES
