NTFSCMP(8) Manuel du gestionnaire système NTFSCMP(8)

NOM

ntfscmp - compare deux systèmes de fichiers NTFS et indique les différences

SYNTAXE

ntfscmp [OPTIONS] PÉRIPHÉRIQUE1 PÉRIPHÉRIQUE2

DESCRIPTION

Le programme ntfscmp effectue une comparaison complète entre deux systèmes de fichiers NTFS et rapporte toutes les variances qu'il trouve. Les systèmes de fichiers peuvent être sur des périphériques de blocs ou des fichiers images. Ntfscmp peut être utilisé pour la vérification de volumes, cependant son objectif principal était d'être un outil de développement efficace, utilisé pour localiser, identifier et vérifier rapidement l'exactitude des modifications de métadonnées apportées à NTFS.

Si l'on s'intéresse uniquement aux changements de métadonnées NTFS, il peut être utile de comparer les images de métadonnées créées en utilisant l'option --metadata de ntfsclone(8) pour éliminer les changements de timestamps généralement peu intéressants.

La sortie concise de ntfscmp est intentionnelle car les informations fournies sont suffisantes dans chaque cas pour déterminer les différences exactes. Ceci peut être réalisé, par exemple, en comparant les sorties détaillées de ntfsinfo(8) pour chaque inode signalé par l'utilitaire diff(1).

OPTIONS

Ci-dessous un résumé des options que ntfscmp accepte.

-P, --no-progress-bar
Ne pas afficher de barres de progression.
-v, --verbose
Sortie plus informative.
-h, --help
Afficher l'aide et quitter.

CODES DE SORTIE

Le code de sortie est 0 en cas de succès, non nul sinon.

PROBLÈMES CONNUS

Aucun problème connu. Si vous en trouviez, veuillez envoyer votre rapport à l'équipe de développement : ntfs-3g-devel@lists.sf.net
