NOM

ntfsinfo - exporter les attributs d'un fichier

SYNTAXE

ntfsinfo [options] périphérique

DESCRIPTION

ntfsinfo exportera les attributs de l'inode numéro-inode ou du fichier chemin-nom-fichier et/ou des informations sur le mft ( option -m ). Exécutez ntfsinfo sans arguments pour une liste complète des options.

OPTIONS

Ci-dessous se trouve un résumé de toutes les options que ntfsinfo accepte. Presque toutes les options ont deux noms équivalents. Le nom court est précédé de - et le nom long est précédé de --. Toutes les options à une seule lettre, qui ne prennent pas d'argument, peuvent être combinées en une seule commande, par ex. -fv est équivalent à -f -v. Les options à nom long peuvent être abrégées en n'importe quel préfixe unique de leur nom.

-F, --file FICHIER
Afficher des informations sur ce fichier
-f, --force
Ceci outrepassera certains paramètres par défaut raisonnables, tels que ne pas écraser un fichier existant. Utilisez cette option avec prudence.
-h, --help
Afficher une liste d'options avec une brève description de chacune.
-i, --inode NUM
Afficher des informations sur cet inode.
-m, --mft
Afficher des informations sur le volume.
-q, --quiet
Produire moins de sortie.
-t, --notime
Ne pas afficher les horodatages dans la sortie.
-v, --verbose
Augmenter la quantité de sortie que ntfsinfo imprime.
-V, --version
Afficher le numéro de version, le copyright et la licence.

BOGUES

Il n'y a pas de problèmes connus avec ntfsinfo. Si vous trouvez un bogage, veuillez envoyer un courriel décrivant le problème à l'équipe de développement :
ntfs-3g-devel@lists.sf.net
