NTFSCAT(8) Manuel de l'administrateur système NTFSCAT(8)

NOM

ntfscat - affiche des fichiers et des flux NTFS sur la sortie standard

SYNTAXE

[options] périphérique [fichier]

DESCRIPTION

ntfscat lira un fichier ou un flux d'un volume NTFS et affichera son contenu sur la sortie standard.

La casse du nom de fichier passé à ntfscat est ignorée.

OPTIONS

Ci-dessous un résumé de toutes les options que ntfscat accepte. Presque toutes les options ont deux noms équivalents. Le nom court est précédé de - et le nom long est précédé de --. Toutes les options à lettre unique, qui ne prennent pas d'argument, peuvent être combinées en une seule commande, par exemple -fv est équivalent à -f -v. Les options nommées longuement peuvent être abrégées en n'importe quel préfixe unique de leur nom.

-a, --attribute TYPE
Affiche le contenu d'un type d'attribut particulier. Par défaut, l'attribut $DATA sans nom sera affiché. L'attribut peut être spécifié par un numéro en décimal ou hexadécimal, ou par son nom.
Hex Décimal Nom
0x10 16 "$STANDARD_INFORMATION"
0x20 32 "$ATTRIBUTE_LIST"
0x30 48 "$FILE_NAME"
0x40 64 "$OBJECT_ID"
0x50 80 "$SECURITY_DESCRIPTOR"
0x60 96 "$VOLUME_NAME"
0x70 112 "$VOLUME_INFORMATION"
0x80 128 "$DATA"
0x90 144 "$INDEX_ROOT"
0xA0 160 "$INDEX_ALLOCATION"
0xB0 176 "$BITMAP"
0xC0 192 "$REPARSE_POINT"
0xD0 208 "$EA_INFORMATION"
0xE0 224 "$EA"
0xF0 240 "$PROPERTY_SET"
0x100 256 "$LOGGED_UTILITY_STREAM"

Notes Les noms d'attributs peuvent être donnés sans le symbole $ préfixé.
Si vous utilisez le symbole $, vous devez mettre le nom entre guillemets pour empêcher le shell d'interpréter le nom.

-n, --attribute-name NOM
Affiche cet attribut nommé, ce flux.
-i, --inode NUM
Spécifie un fichier par son numéro d'inode au lieu de son nom.
-f, --force
Ceci remplacera certains paramètres par défaut raisonnables, comme ne pas utiliser un volume monté. Utilisez cette option avec prudence.
-h, --help
Affiche une liste d'options avec une brève description de chacune.
-q, --quiet
Supprime certains messages de débogage/avertissement/erreur.
-V, --version
Affiche le numéro de version, le copyright et la licence de ntfscat.
-v, --verbose
Affiche plus de messages de débogage/avertissement/erreur.

EXEMPLES

Affiche le contenu d'un fichier dans la racine d'un volume NTFS.

ntfscat /dev/hda1 boot.ini

Affiche le contenu d'un fichier dans un sous-répertoire d'un volume NTFS.

ntfscat /dev/hda1 /winnt/system32/drivers/etc/hosts

Affiche le contenu de l'attribut $INDEX_ROOT du répertoire racine (inode 5).

ntfscat /dev/hda1 -a INDEX_ROOT -i 5 | hexdump -C

BOGUES

Il n'y a pas de problèmes connus avec ntfscat. Si vous trouvez un bogue, veuillez envoyer un e-mail décrivant le problème à l'équipe de développement :
ntfs-3g-devel@lists.sf.net
