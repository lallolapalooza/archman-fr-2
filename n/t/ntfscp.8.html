NTFSCP(8) Manuel de l'administrateur système NTFSCP(8)

NOM

ntfscp - copier un fichier vers un volume NTFS.

SYNTAXE

ntfscp [options] périphérique fichier_source destination

DESCRIPTION

ntfscp copiera un fichier vers un volume NTFS. La destination peut être un fichier ou un répertoire. Si la destination est un répertoire spécifié par son nom, alors fichier_source est copié dans ce répertoire. Si la destination est un répertoire spécifié par son numéro d'inode, alors un attribut de données sans nom est créé pour cet inode et fichier_source y est copié (ATTENTION : il est inhabituel d'avoir des flux de données sans nom dans les répertoires, réfléchissez bien avant de spécifier un répertoire par son numéro d'inode).

OPTIONS

Ci-dessous se trouve un résumé de toutes les options que ntfscp accepte. Presque toutes les options ont deux noms équivalents. Le nom court est précédé de - et le nom long est précédé de --. Toutes les options à une seule lettre, qui ne prennent pas d'argument, peuvent être combinées en une seule commande, par exemple -fv est équivalent à -f -v. Les options à nom long peuvent être abrégiées en n'importe quel préfixe unique de leur nom.

-a, --attribute NUM
Écrire dans cet attribut.
-i, --inode
Traiter la destination comme un numéro d'inode.
-m, --min-fragments
Minimiser la fragmentation lors de l'allocation d'espace à l'attribut. Ceci est surtout utile lors de la création de gros fichiers.
-N, --attr-name NOM
Écrire dans l'attribut avec ce nom.
-n, --no-action
Utilisez cette option pour faire un essai avant de procéder à la copie réelle. Le volume sera ouvert en lecture seule et aucune écriture ne sera effectuée.
-f, --force
Ceci outrepassera certains paramètres par défaut raisonnables, tels que ne pas travailler avec un volume monté. Utilisez cette option avec précaution.
-h, --help
Afficher une liste d'options avec une brève description de chacune.
-q, --quiet
Supprimer certains messages de débogage/avertissement/erreur.
-t, --timestamp
Copier l'heure de modification de fichier_source vers destination. Ceci n'est pas compatible avec --attr-name et --attribute.
-V, --version
Afficher le numéro de version, le copyright et la licence de ntfscp.
-v, --verbose
Afficher plus de messages de débogage/avertissement/erreur.

FLUX DE DONNÉES

Toutes les données sur NTFS sont stockées dans des flux, qui peuvent avoir des noms. Un fichier peut avoir plusieurs flux de données, mais un seul doit ne pas avoir de nom. La taille d'un fichier est la taille de son flux de données sans nom. Habituellement, lorsque vous ne spécifiez pas de nom de flux, vous accédez au flux de données sans nom. Si vous voulez accéder à un flux de données nommé, vous devez ajouter ":nom_du_flux" au nom du fichier. Par exemple : en ouvrant "quelquechose.mp3:artiste", vous ouvrirez le flux "artiste" dans "quelquechose.mp3". Mais Windows vous empêche généralement d'accéder aux flux de données nommés, vous devez donc utiliser un programme comme FAR ou les utilitaires de Cygwin pour accéder aux flux de données nommés.

EXEMPLES

Copier new_boot.ini depuis /home/user en tant que boot.ini à la racine d'un volume NTFS /dev/hda1 :

ntfscp /dev/hda1 /home/user/new_boot.ini boot.ini

Copier monfichier vers C:\quelque\chemin\monfichier:flux (en supposant que la lettre de /dev/hda1 sous Windows est C) :

ntfscp -N flux /dev/hda1 monfichier /quelque/chemin

BOGUES

Il n'y a aucun problème connu avec ntfscp. Si vous trouvez un bogue, veuillez envoyer un e-mail décrivant le problème à l'équipe de développement :
ntfs-3g-devel@lists.sf.net
