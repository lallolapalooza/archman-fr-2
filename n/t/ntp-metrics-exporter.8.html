NOM

ntp-metrics-exporter - Exportateur Prometheus/OpenMetrics pour le démon ntpd-rs

SYNTAXE

ntp-metrics-exporter [-c chemin]

ntp-metrics-exporter -h

ntp-metrics-exporter -v

DESCRIPTION

Export l'état des métriques du démon ntpd-rs sous forme de Prometheus/OpenMetrics via une socket HTTP.

OPTIONS

-c chemin, --config=chemin
Chemin du fichier de configuration où est spécifié le chemin de la socket d'observation pour se connecter au démon ntp. Par défaut, il s'agit de /etc/ntpd-rs/ntp.toml si non spécifié.
-h, --help
Affiche les instructions d'utilisation.
-v, --version
Affiche les informations de version.

VOIR AUSSI

ntp-daemon(8), ntp-ctl(8), ntp.toml(5)
