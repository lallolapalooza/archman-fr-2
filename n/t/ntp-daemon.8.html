NOM

ntp-daemon - service de démon du protocole NTP ntpd-rs

SYNTAXE

ntp-daemon [-c chemin] [-l niveau_log]

ntp-daemon -h

ntp-daemon -v

DESCRIPTION

ntp-daemon est le démon de service du protocole NTP (Network Time Protocol) pour ntpd-rs, une implémentation NTP axée sur la sécurité et la stabilité. Le ntp-daemon peut être configuré comme client NTP et serveur NTP. Le démon fonctionne également avec le protocole Network Time Security (NTS). Les détails de la configuration du démon et de son implémentation se trouvent dans ntp.toml(5), où plusieurs concepts du ntp-daemon sont également expliqués.

OPTIONS

-c chemin, --config=chemin
Le chemin du fichier de configuration pour le ntp-daemon où sont stockés les paramètres de configuration de ntpd-rs. Si non spécifié, le fichier de configuration par défaut est /etc/ntpd-rs/ntp.toml.
-h, --help
Affiche les instructions d'utilisation.
-l niveau_log, --log-level=niveau_log
Change les messages de journalisation qui sont envoyés à la sortie standard. Les niveaux de journalisation disponibles sont trace, debug, info, warn et error (du moins prioritaire au plus prioritaire). Seuls les messages ayant la priorité donnée et supérieure seront affichés. Le niveau de journalisation par défaut est info.
-v, --version
Affiche les informations de version.
