NOM

ntfscluster - identifier les fichiers dans une région spécifiée d'un volume NTFS.

SYNTAXE

ntfscluster [options] périphérique

DESCRIPTION

ntfscluster a trois modes de fonctionnement : info, sector et cluster.

Info

Le mode par défaut, info, n'est actuellement pas implémenté. Il affichera des informations générales sur le volume NTFS lorsqu'il fonctionnera.

Sector

Le mode sector affichera une liste des fichiers qui ont des données dans la plage spécifiée de secteurs.

Cluster

Le mode cluster affichera une liste des fichiers qui ont des données dans la plage spécifiée de clusters. Lorsque la taille du cluster est d'un secteur, cela sera équivalent au mode de fonctionnement sector.

OPTIONS

Ci-dessous un résumé de toutes les options que ntfscluster accepte. Presque toutes les options ont deux noms équivalents. Le nom court est précédé de - et le nom long est précédé de --. Toutes les options à une seule lettre, qui ne prennent pas d'argument, peuvent être combinées en une seule commande, par exemple -fv est équivalent à -f -v. Les options nommées longues peuvent être abrégées en tout préfixe unique de leur nom.

-c, --cluster PLAGE
Tous les fichiers dont les données se trouvent dans cette plage de clusters seront affichés.
-F, --filename NOM
Afficher les informations sur ce fichier.
-f, --force
Cela outrepassera certains paramètres par défaut raisonnables, tels que ne pas travailler avec un volume monté. Utilisez cette option avec prudence.
-h, --help
Afficher une liste d'options avec une brève description de chacune.
-I, --inode NUM
Afficher les informations sur cet inode.
-i, --info
Cette option n'est pas encore implémentée.
-q, --quiet
Réduire la quantité de sortie au minimum. Naturellement, il n'est pas logique de combiner cette option avec --verbose
-s, --sector PLAGE
Tous les fichiers dont les données se trouvent dans cette plage de secteurs seront affichés.
-v, --verbose
Augmenter la quantité de sortie que ntfscluster imprime.
-V, --version
Afficher le numéro de version, le copyright et la licence de ntfscluster.

EXEMPLES

Obtenir des informations sur le volume /dev/hda1.

ntfscluster /dev/hda1

Rechercher des fichiers dans les 500 premiers clusters de /dev/hda1.

ntfscluster -c 0-500 /dev/hda1

BOGUES

Le mode info n'est pas encore implémenté. ntfscluster est assez limité, mais il n'a pas de bugs connus. Si vous trouvez un bug, veuillez envoyer un e-mail décrivant le problème à l'équipe de développement :
ntfs-3g-devel@lists.sf.net
