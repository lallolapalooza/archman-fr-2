NOM

ntfsfix - corriger les erreurs courantes et forcer Windows à vérifier NTFS

SYNOPSIS

ntfsfix [options] périphérique

DESCRIPTION

ntfsfix est un utilitaire qui corrige certains problèmes NTFS fondamentaux. ntfsfix N'EST PAS une version Linux de chkdsk. Il ne répare que certaines incohérences NTFS fondamentales, réinitialise le journal NTFS et planifie une vérification de la cohérence NTFS pour le premier démarrage sous Windows.

Vous pouvez exécuter ntfsfix sur un volume NTFS si vous pensez qu'il a été endommagé par Windows ou par une autre cause et qu'il ne peut pas être monté.

OPTIONS

Ci-dessous se trouve un résumé de toutes les options que ntfsfix accepte. Presque toutes les options ont deux noms équivalents. Le nom court est précédé de - et le nom long est précédé de --. Les options à une seule lettre qui ne prennent pas d'argument peuvent être combinées en une seule commande, par exemple -fv est équivalent à -f -v. Les options avec nom long peuvent être abrégées en tout préfixe unique de leur nom.

-b, --clear-bad-sectors
Efface la liste des secteurs défectueux. Ceci est utile après le clonage d'un ancien disque avec des secteurs défectueux vers un nouveau disque.
-d, --clear-dirty
Efface l'indicateur « dirty » du volume si le volume peut être corrigé et monté. Si l'option n'est pas présente ou si le volume ne peut pas être corrigé, l'indicateur « dirty » est défini pour demander une vérification du volume lors du prochain montage.
-h, --help
Affiche une liste d'options avec une brève description de chacune.
-n, --no-action
N'écrit rien, affiche seulement ce qui aurait été fait.
-V, --version
Affiche le numéro de version, le copyright et la licence.

BOGUES

Il n'y a pas de problèmes connus avec ntfsfix. Si vous trouvez un bug, veuillez envoyer un e-mail décrivant le problème à l'équipe de développement :
ntfs-3g-devel@lists.sf.net
