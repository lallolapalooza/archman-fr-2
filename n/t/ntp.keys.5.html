NOM

ntp.keys - Fichier de clés NTP format de configuration

SYNTAXE

[--nom-option] [--nom-option valeur]

Tous les arguments doivent être des options.

DESCRIPTION

Ce document décrit le format d'un fichier de clés NTP symétriques. Pour une description de l'utilisation de ce type de fichier, voir la section « Support d'authentification » de la page ntp.conf(5).

ntpd(8) lit ses clés à partir d'un fichier spécifié en utilisant l'option de ligne de commande -k ou l'instruction keys dans le fichier de configuration. Bien que la clé numéro 0 soit fixe par la norme NTP (comme 56 bits nuls) et ne puisse pas être modifiée, une ou plusieurs clés numérotées entre 1 et 65535 peuvent être arbitrairement définies dans le fichier de clés.

Le fichier de clés utilise les mêmes conventions de commentaires que le fichier de configuration. Les entrées de clé utilisent un format fixe de la forme


cle_no type cle liste_IP_opt

où cle_no est un entier positif (entre 1 et 65535), type est l'algorithme de résumé de message, cle est la clé elle-même, et liste_IP_opt est une liste facultative séparée par des virgules d'adresses IP pour lesquelles la cle_no sera considérée comme fiable. Chaque IP de liste_IP_opt peut contenir une spécification facultative ** /bits_sous_reseau** qui identifie le nombre de bits pour le sous-réseau de confiance souhaité. Si liste_IP_opt est vide, tout message correctement authentifié sera accepté.

La cle peut être donnée dans un format contrôlé par le champ type. Le type MD5 est toujours pris en charge. Si ntpd a été compilé avec la bibliothèque OpenSSL, tout digest supporté par cette bibliothèque peut être spécifié. Cependant, si la conformité avec FIPS 140-2 est requise, le type doit être soit SHA soit SHA1.

Voici quelques types de clés et leurs formats correspondants :

MD5

La clé est de 1 à 16 caractères imprimables terminés par un retour à la ligne, un espace ou un # (qui est le caractère « début de commentaire »).
SHA

SHA1

RMD160

La clé est une chaîne ASCII encodée en hexadécimal de 40 caractères, qui est tronquée si nécessaire.

Notez que les clés utilisées par les programmes ntpq(8) et ntpdc(8) sont vérifiées par rapport aux mots de passe demandés par les programmes et saisis manuellement, il est donc généralement approprié de spécifier ces clés au format ASCII.
