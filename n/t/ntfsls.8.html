Paquet: ntfs-3g

Licences: GPL2

NTFSLS(8) Manuel du gestionnaire système NTFSLS(8)

NOM

ntfsls - lister le contenu d'un répertoire sur un système de fichiers NTFS

SYNTAXE

ntfsls [options] périphérique

ntfsls [ -a | --all ] [ -F | --classify ] [ -f | --force ] [ -h | --help ] [ -i | --inode ] [ -l | --long ] [ -p | --path CHEMIN ] [ -q | --quiet ] [ -s | --system ] [ -V | --version ] [ -v | --verbose ] [ -x | --dos ] périphérique

DESCRIPTION

ntfsls est utilisé pour lister des informations sur les fichiers spécifiés par l'option PATH (le répertoire racine par défaut). PÉRIPHÉRIQUE est le fichier spécial correspondant au périphérique (par exemple /dev/hdXX) ou un fichier image NTFS.

OPTIONS

Ci-dessous un résumé de toutes les options que ntfsls accepte. Presque toutes les options ont deux noms équivalents. Le nom court est précédé de - et le nom long est précédé de --. Toutes les options à une seule lettre, qui ne prennent pas d'argument, peuvent être combinées en une seule commande, par exemple -fv est équivalent à -f -v. Les options à nom long peuvent être abrégées en n'importe quel préfixe unique de leur nom.

-a, --all
Affiche tous les fichiers. Si cette option n'est pas spécifiée, les noms de fichiers dans l'espace de noms POSIX ne seront pas affichés.
-F, --classify
Ajoute un indicateur (un parmi */=@|) aux entrées.
-f, --force
Force l'exécution. Par exemple, nécessaire pour exécuter sur une partition NTFS stockée dans un fichier normal.
-h, --help
Affiche les informations d'utilisation de ntfsls et quitte.
-i, --inode
Affiche le numéro d'inode de chaque fichier. Il s'agit du numéro de référence MFT en terminologie NTFS.
-l, --long
Utilise un format de liste long.
-p, --path CHEMIN
Le répertoire dont le contenu doit être listé ou le fichier (y compris le chemin) pour lequel afficher des informations.
-q, --quiet
Supprime certains messages de débogage/avertissement/erreur.
-R, --recursive
Affiche le contenu de tous les répertoires sous le répertoire spécifié.
-s, --system
Sauf si cette option est spécifiée, tous les fichiers commençant par un caractère dollar ne seront pas listés car ce sont généralement des fichiers système.
-v, --verbose
Affiche plus de messages de débogage/avertissement/erreur.
-V, --version
Affiche le numéro de version de ntfsls et quitte.
-x, --dos
Affiche les noms de fichiers courts, c'est-à-dire les fichiers dans l'espace de noms DOS, au lieu des noms de fichiers longs, c'est-à-dire les fichiers dans l'espace de noms WIN32.

BOGUES

Il n'y a pas de problèmes connus avec ntfsls. Si vous trouvez un bug, veuillez envoyer un e-mail décrivant le problème à l'équipe de développement :
