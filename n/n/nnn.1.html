NNN(1) Manuel des commandes générales NNN(1)

NOM

nnn — Le gestionnaire de fichiers terminal non conventionnel.

SYNOPIS

nnn [-aAcCdDeEfgHJKnQrRSuUVxh] [-b clé] [-F val] [-l val] [-p fichier] [-P clé] [-s nom] [-t secs] [-T clé] [CHEMIN]

DESCRIPTION

nnn (Nnn's Not Noice) est un fork de noice http://git.2f30.org/noice/ optimisé pour les performances, riche en fonctionnalités, avec une intégration de bureau transparente, une navigation simplifiée, un mode type-to-nav avec entrée automatique de répertoire, un mode analyseur d'utilisation du disque, des signets, des contextes, un lanceur d'applications, des raccourcis de navigation familiers, la création de sous-shells et bien plus encore. Il reste un gestionnaire de fichiers simple et efficace qui ne vous gêne pas.

nnn ouvre le répertoire de travail courant si CHEMIN n'est pas spécifié. Si CHEMIN est spécifié et qu'il existe, nnn l'ouvrira. Si le CHEMIN n'existe pas et se termine par un /, nnn tentera de créer l'arborescence du répertoire et de l'ouvrir. Sinon, CHEMIN est considéré comme un chemin vers un fichier ordinaire et nnn tente de créer l'arborescence complète du répertoire vers le fichier, ouvre le répertoire parent et invite à créer le nouveau fichier dans celui-ci avec le nom de fichier de base.

RACCCOURCIS CLAVIER

Appuyez sur ‘?’ dans nnn pour voir la liste des raccourcis clavier.

OPTIONS

nnn prend en charge les options suivantes :

-a
met en place automatiquement NNN_FIFO temporaire (voir la section ENVIRONNEMENT)

-A
désactive l'entrée automatique de répertoire en cas de correspondance unique avec le filtre

-b clé
spécifie la clé de signet à ouvrir

-B
utilise bsdtar pour les archives (par défaut : atool)

-c
indique que l'ouvreur est un ouvreur en ligne de commande uniquement (annule -e)

-C
schéma 8 couleurs — colore les répertoires par contexte, désactive les couleurs des fichiers

-d
mode détail

-D
affiche les répertoires en couleur de contexte avec NNN_FCOLORS défini

-e
ouvre les fichiers texte dans $VISUAL (sinon $EDITOR, fallback vi) [de préférence CLI]

-E
utilise $EDITOR pour les modifications internes non détachées

-f
utilise le fichier d'historique readline

-F val
mode de notification fifo
0 : notifier en tant que prévisualiseur, 1 : notifier en tant qu'explorateur

-g
utilise des filtres regex au lieu d'une correspondance de sous-chaîne

-H
affiche les fichiers cachés

-i
affiche les informations du fichier courant dans la barre d'informations (peut être lent)

-J
désactive l'avancement automatique sur la sélection
(par exemple, la sélection d'une entrée ne déplacera plus le curseur vers l'entrée suivante)

-K
teste les collisions de raccourcis clavier et quitte

-l val
nombre de lignes à déplacer par défilement de la molette de la souris

-n
démarre en mode type-to-nav

-o
ouvre les fichiers uniquement sur la touche Entrée

-p fichier
copie (ou *sélectionne*) la sélection dans le fichier, ou stdout si fichier='-'

-P clé
spécifie la clé du plugin à exécuter

-Q
désactive la confirmation lors de la sortie avec plusieurs contextes actifs

-r
affiche la progression de cp, mv
(Linux uniquement, nécessite advcpmv ; ^T affiche la progression sur BSD/macOS)

-R
désactive le roulement aux bords (par exemple, appuyer sur bas alors que le curseur est sur la dernière
entrée ne déplacera plus le curseur vers la première entrée et vice versa)

-s nom
charge une session par nom

-S
session persistante

-t secs
délai d'inactivité en secondes pour verrouiller le terminal

-T clé
ordre de tri (voir la section TRI)
clés : usage disque 'a'pparent / usage 'd'isque / 'e'xtension / 'r'everse / 's'ize / 't'emps / 'v'ersion
majuscule pour inverser (sauf 'r')

-u
utilise la sélection si disponible, ne demande pas de choisir entre la sélection et l'entrée survolée

-U
affiche les noms d'utilisateur et de groupe dans la barre d'état

-V
affiche la version et quitte

-x
affiche les notifications à la fin de la copie, du déplacement, de la suppression de sélection (nécessite le plugin .ntfy)
copie le chemin dans le presse-papiers système lors de la sélection (nécessite le plugin .cbcp)
affiche le titre xterm (si en mode non-picker)

-0
utilise le séparateur nul (au lieu d'une nouvelle ligne) pour séparer les chemins de fichiers dans la sortie du mode picker

-h
affiche l'aide du programme et quitte

CONFIGURATION

Il n'y a pas de fichier de configuration. Les fichiers associés sont à

${XDG_CONFIG_HOME:-$HOME/.config}/nnn/

La configuration se fait à l'aide de quelques variables d'environnement optionnelles (définissez-les si nécessaire). Voir la section ENVIRONNEMENT.

nnn utilise xdg-open (sur Linux), open(1) (sur macOS), cygstart sur (Cygwin) et open sur (Haiku) comme ouvreur de bureau. Il est également possible de spécifier un ouvreur personnalisé. Voir la section ENVIRONNEMENT.

CONTEXTES

Ouvre plusieurs emplacements avec 4 contextes. L'état est affiché en haut à gauche :

- le contexte actuel est en vidéo inversée
- les autres contextes actifs sont soulignés
- le reste est inactif

Un nouveau contexte copie l'état du contexte précédent. Chaque contexte peut avoir sa propre couleur. Voir la section ENVIRONNEMENT.

SESSIONS

Les sessions sont un moyen de sauvegarder et de restaurer les états de travail. Une session stocke les paramètres et les contextes. Les sessions peuvent être chargées à l'exécution ou avec une option du programme.

- Lorsqu'une session est chargée à l'exécution, le dernier état de travail est automatiquement sauvegardé dans un fichier de session dédié « session auto ». L'option de session restore restaurera la « session auto ».
- L'option de session persistante est globale. Si elle est utilisée, la dernière session active sera mise à jour avec l'état final à la sortie du programme.
- La « session auto » est utilisée en mode session persistante si aucune session n'est active.
- Le flux d'entrée de liste et l'ouverture d'un signet par clé ont une priorité plus élevée que les options de session (-s/-S).

Tous les fichiers de session sont situés par nom de session dans le répertoire

${XDG_CONFIG_HOME:-$HOME/.config}/nnn/sessions

« @ » est le fichier de « session auto ».

Touches spéciales à l'invite de filtre :

-------- + ---------------------------------------
  Touche   |                Fonction
-------- + ---------------------------------------

Touches spéciales à l'invite de filtre vide :

------ + ---------------------------------------
  Touche  |                Fonction
------ + ---------------------------------------
   ?   | Afficher l'aide et l'écran de configuration
   /   | Basculer entre chaîne et regex

Cas d'utilisation courants des expressions régulières :

(1) Pour lister toutes les correspondances commençant par l'expression de filtre,
commencez l'expression par un symbole '^' (caret).
(2) Tapez '\.mkv' pour lister tous les fichiers MKV.
(3) Utilisez '.*' pour faire correspondre n'importe quel caractère (recherche *assez* floue).
(4) Exclure les noms de fichiers contenant 'nnn' (compilé avec la bibliothèque PCRE) : '^(?!nnn)'

TRI

nnn affichera toujours les répertoires en premier, suivis des fichiers. L'ordre des chaînes est toujours insensible à la casse.

La clé de tri peut être définie soit avec l'option de programme -T, soit interactivement en utilisant t ou ^T. Les options suivantes sont disponibles :

a
utilisation disque apparente, taille du fichier telle qu'elle apparaît, peut être supérieure à l'utilisation disque réelle pour les fichiers épars.
d
utilisation disque, quantité de données occupée sur le disque, multiple de la taille du bloc.
e
extension du fichier.
r
inverser l'ordre actuel (non disponible avec -T).
s
taille du fichier, quantité de données stockées dans le fichier.
t
temps, dépend du type de temps actuellement sélectionné qui peut être changé en utilisant la touche T. Les options sont :
a
accès, dernière fois que le fichier a été accédé.
c
changement, dernière fois que les métadonnées du fichier ont été modifiées (par exemple, permissions).
m
modifié, dernière fois que le contenu du fichier a été modifié (par défaut).
v
version, trie par nom de fichier tout en traitant les caractères numériques numériquement. Par exemple : j1.png, j02.png, j3.png.
c
effacer, revenir à l'ordre des noms de fichiers (non disponible avec -T).
^T
cycle entre l'ordre nom de fichier/taille/temps (non disponible avec -T).

La version majuscule de l'option (sauf r) inverse l'ordre par défaut. Par défaut, les clés de tri par temps et par taille sont ordonnées en ordre décroissant, et les champs alphabétiques sont ordonnés en ordre croissant. Par exemple, en utilisant l'option e, les entrées seront ordonnées par extension, en ordre croissant. L'utilisation de E résulterait en un ordre décroissant des extensions. Cela signifie que e suivi de r est identique à E.

SELECTION

nnn permet la sélection de fichiers à travers les répertoires et les contextes !

Il existe 3 groupes de raccourcis clavier pour ajouter des fichiers à la sélection :

(1) basculement de sélection du fichier survolé
- désélectionne si '+' est visible avant l'entrée, sinon ajoute à la sélection
(2) ajouter une plage de fichiers à la sélection
- répétez la touche de plage sur la même entrée deux fois pour effacer complètement la sélection
(3) ajouter tous les fichiers du répertoire actuel à la sélection

Une sélection peut être modifiée, copiée, déplacée, supprimée, archivée ou liée.

Les chemins absolus des fichiers sélectionnés sont copiés dans le fichier .selection dans le répertoire de configuration. Le fichier de sélection est partagé entre plusieurs instances du programme. Les sélections de plusieurs instances ne sont pas fusionnées. La dernière instance écrivant dans le fichier écrase le contenu précédent. Si vous avez 2 instances de nnn *ouvertes* dans 2 panneaux d'un multiplexeur de terminal, vous pouvez sélectionner dans un panneau et utiliser la sélection dans l'autre panneau. La sélection est effacée dans l'instance nnn où la sélection a été effectuée lors de mv/rm (mais pas lors de cp).

nnn efface la sélection après une opération réussie avec la sélection. Les plugins sont autorisés à définir le comportement individuellement.

Pour modifier la sélection, utilisez la touche _modifier la sélection_. La modification ne termine pas le mode de sélection. Vous pouvez ajouter d'autres fichiers à la sélection et modifier la liste à nouveau. Si aucun fichier n'est sélectionné dans la session actuelle, cette option tente d'afficher le fichier de sélection.

nnn peut afficher la taille totale des fichiers non filtrés sélectionnés listés dans un répertoire. Pour les répertoires, seule la taille du répertoire est ajoutée par défaut. Pour ajouter la taille du contenu d'un répertoire, triez par utilisation disque (alias mode du).

RECHERCHE ET LISTE

Il y a deux façons de rechercher et de lister :

- alimenter une liste de chemins de fichiers en entrée
- rechercher à l'aide d'un plugin (par exemple, finder) et lister les résultats

Les chemins de fichiers doivent être séparés par NUL ('\0'). Les chemins peuvent être relatifs au répertoire courant ou absolus. Les chemins invalides dans l'entrée sont ignorés. La limite de traitement de l'entrée est de 16 384 chemins ou 64 MiB (max_chemins x max_longueur_chemin) de données.

Pour lister le flux d'entrée, démarrez nnn en écrivant dans son entrée standard. Par exemple, pour lister les fichiers du répertoire courant de plus de 1 Mo :

find -maxdepth 1 -size +1M -print0 | nnn

ou rediriger une liste depuis un fichier :

nnn < files.txt

Fonction shell bash/zsh pratique pour lister les fichiers par type mime dans le répertoire courant :

# pour afficher les fichiers vidéo, exécutez : list video

list ()
{
    find . -maxdepth 1 | file -if- | grep "$1" | awk -F: '{printf "%s%c", $1, 0}' | nnn
}

Un répertoire temporaire sera créé contenant des liens symboliques vers les chemins donnés. Toute action effectuée sur ces liens symboliques sera effectuée uniquement sur leurs cibles, après quoi ils pourraient devenir invalides.

> ou l sur un lien symbolique dans le répertoire de liste mène au fichier cible. Appuyez sur - pour revenir au répertoire de liste. Appuyez sur Entrée pour ouvrir le lien symbolique.

Le flux d'entrée de liste peut être scripté. Il peut être étendu pour sélectionner (option -p) les entrées sélectionnées parmi les résultats listés.

MARQUE-PAGES

Il existe 2 façons (peuvent être utilisées ensemble) pour gérer les marque-pages.

(1) Clés de marque-page : Voir NNN_BMS dans la section ENVIRONNEMENT pour savoir comment définir
les clés de marque-page.


La touche de sélection de marque-page b liste toutes les clés de marque-page définies dans NNN_BMS
dans l'invite des marque-pages.

(2) Marque-pages liés par symlink : Un marque-page lié par symlink vers le répertoire courant peut
être créé avec la touche B (ou manuellement sous ~/.config/nnn/bookmarks).


Appuyer sur Entrée à l'invite des marque-pages mène à ce répertoire.
Si NNN_BMS n'est pas défini, la touche de sélection de marque-page l'ouvre directement.

En entrant dans un marque-page, le répertoire où la touche de sélection de marque-page a été pressée est défini comme répertoire précédent. Appuyez sur - pour y revenir.

UNITES

L'unité de taille de fichier minimale est l'octet (B). Les autres sont K, M, G, T, P, E, Z, Y (puissances de 1024), identiques aux unités par défaut dans ls.

ENVIRONNEMENT

Les variables d'environnement SHELL, VISUAL (sinon EDITOR) et PAGER sont utilisées. Une seule combinaison d'arguments est prise en charge pour SHELL et PAGER.

NNN_OPTS : options binaires pour nnn

export NNN_OPTS="cEnrx"

NNN_OPENER : spécifier un ouvreur de fichier personnalisé.

export NNN_OPENER=nuke

NOTE : nuke est un ouvreur de fichier disponible dans le dépôt de plugins.

NNN_BMS : chaîne de marque-pages sous forme de paires *clé_caractère:emplacement* séparées par ; :

export NNN_BMS="d:$HOME/Docs;u:/home/user/Cam Uploads;D:$HOME/Downloads/"

Ces marque-pages sont listés dans l'écran d'aide et de configuration (touche ?).

NNN_PLUG : plugins directement exécutables sous forme de paires *clé_caractère:plugin* séparées par ; :

export NNN_PLUG='f:finder;o:fzopen;p:mocplay;d:diffs;t:nmount;v:imgview'

NOTES :
1. Pour exécuter un plugin directement, appuyez sur ; suivi de la clé.
2. Alternativement, combinez avec Alt (c'est-à-dire Alt+clé).

NAME

nnn — fast and feature-rich terminal file manager

SYNOPSIS

nnn [OPTIONS] [PATH]

DESCRIPTION

nnn is a highly optimized file manager with an excellent learning curve. It is minimalistic, but packs many features to satisfy users. It is designed for the terminal and has minimal dependencies.

nnn supports context-aware navigation, bookmarking, file type specific colors, disk usage analysis, shell spawn, customizable plugins, advanced search, fuzzy finding, file handling (copy, move, delete, rename), and much more.

KEYBINDS

nnn keybindings are context-sensitive. Keybinds are grouped into sections:

Navigations
Navigation in the current directory, parent directory, and sub-directories. Most commonly used keys.
File Operations
Copy, move, rename, delete, create directory, create file, extract, archive, etc.
Selection
Select files and directories. Can be used for batch operations.
Search
Find files and directories. Supports regex, case-sensitivity, and fuzzy finding.
Bookmarks
Bookmark current directory, navigate to bookmarked directories.
Plugins
Run external commands as plugins. Supports user-defined plugins and built-in commands.
Shell Spawn
Spawn a shell in the current directory.
Help
Show help page and keybindings.

See the internal help page (Press ? inside nnn) for details.

OPTIONS

-c
Use at most 1 color for non-dirs.
-C
Use at most 1 color for all.
-d
Use at most 2 colors for file types.
-e
Edit hovered file.
-E
Edit hovered file as root.
-f
Show disk usage of hovered file.
-F
Show disk usage of current directory.
-g
Show disk usage of hovered file in decimal.
-G
Show disk usage of current directory in decimal.
-h
Show help page.
-H
Show help page and exit.
-i
Do not change directory.
-l
Use long listing format.
-m
Show hoverd file size in decimal.
-M
Show current directory size in decimal.
-n
Show non-hidden files.
-N
Show hidden files.
-p
Read file paths from stdin, process each line.
-P plugin_key
Run plugin at startup.
-r
Read file paths from stdin, process selected.
-R
Read file paths from stdin, process all.
-s
Show file size.
-S
Show file size in human-readable format.
-t
Show modification time.
-T
Show modification time in human-readable format.
-u
Show file type.
-v
Show version.
-V

-x
Run external command.
-X

-z

-Z

--help

CONFIGURATION

nnn can be configured via environment variables.

CONTEXTS

nnn supports context-aware commands and filters. Contexts are defined by a key and a command.

export NNN_PLUG='y:-!sync*'

To pick and run an unassigned plugin, press Enter at the plugin prompt.

To run a plugin at startup, use the option -P followed by the plugin key.

NOTES:

  1. Place $nnn (or exported variables) in double quotes ("$nnn")
  2. Use single quotes for $NNN_PLUG so "$nnn" is not interpreted
  3. (Again) add ! before the command
  4. To disable directory refresh after running a command as plugin, prefix with -!
  5. To skip user confirmation after command execution, suffix with * Note: Do not use * with programs those run and exit e.g. cat
  6. To run a GUI app as plugin, add a & after !. 
    export NNN_PLUG='m:-!&mousepad "$nnn"'
  7. To show the output of run-and-exit commands which do not need user input, add | (pipe) after ! Note: This option is incompatible with & (terminal output is masked for GUI programs) and ignores * (output is already paged for user). 
    export NNN_PLUG='m:-!|mediainfo "$nnn";t:-!|tree -ps;l:-!|ls -lah --group-directories-first'

EXAMPLES:

------------------------------------ + -------------------------------------------------
            Key:Command              |                   Description
------------------------------------ + -------------------------------------------------
c:!convert "$nnn" png:- | xclip      | Copy image to clipboard
   -sel clipboard -t image/png*      |
C:!cp -rv "$nnn" "$nnn".cp*          | Create a copy of the hovered file
e:-!sudo -E vim "$nnn"*              | Edit file as root in vim
g:-!git diff                         | Show git diff
h:-!hx "$nnn"*                       | Open hovered file in hx hex editor
k:-!fuser -kiv "$nnn"*               | Interactively kill process(es) using hovered file
l:-!git log                          | Show git log
n:-!vi /home/user/Dropbox/dir/note*  | Take quick notes in a synced file/dir of notes
p:-!less -iR "$nnn"*                 | Page through hovered file in less
s:-!&smplayer -minigui "$nnn"        | Play hovered media file, even unfinished download
x:!chmod +x "$nnn"                   | Make the hovered file executable
y:-!sync*                            | Flush cached writes
------------------------------------ + -------------------------------------------------

Online docs: https://github.com/jarun/nnn/tree/master/plugins

NNN_ORDER:

directory-specific sort key.

export NNN_ORDER='t:/home/user/Downloads;S:/tmp'

NOTE: Sort keys can be a/d/e/r/s/t/v (refer to the SORTING section).
      Path must be absolute.

      Timestamps for entries modified/created within 5 minutes are shown in reverse.

NNN_COLORS:

string of color numbers for each context, e.g.:

# 8 color numbers:
# 0-black, 1-red, 2-green, 3-yellow, 4-blue (default), 5-magenta, 6-cyan, 7-white
export NNN_COLORS='1234'

# xterm 256 color numbers (converted to hex, 2 symbols per context):
# see https://user-images.githubusercontent.com/1482942/93023823-46a6ba80-f5e1-11ea-9ea3-6a3c757704f4.png
export NNN_COLORS='#0a1b2c3d'

# both (256 followed by 8 as fallback, separated by ';')
export NNN_COLORS='#0a1b2c3d;1234'

NOTE: If only 256 colors are specified and the terminal doesn't support, default is used.

NNN_FCOLORS:

specify file-type specific colors:

export NNN_FCOLORS='c1e2272e006033f7c6d6abc4'

Specify file-specific colors in xterm 256 color hex numbers (2 symbols per color).
Order is strict, use 00 to omit/use default terminal color. Defaults:

------------------------- + --- + -------------
          Order           | Hex |    Color
------------------------- + --- + -------------
Block device              | c1  | DarkSeaGreen1
Char device               | e2  | Yellow1
Directory                 | 27  | DeepSkyBlue1
Executable                | 2e  | Green1
Regular                   | 00  | Normal
Hard link                 | 60  | Plum4
Symbolic link             | 33  | Cyan1
Missing OR file details   | f7  | Grey62
Orphaned symbolic link    | c6  | DeepPink1
FIFO                      | d6  | Orange1
Socket                    | ab  | MediumOrchid1
Unknown OR 0B regular/exe | c4  | Red1
------------------------- + --- + -------------

If the terminal supports xterm 256 colors or more, file-specific colors will be rendered.
To force the 8-color scheme use option -C.
If xterm 256 colors aren't supported, 8-color scheme will be used.

NNN_ARCHIVE:

archive extensions to be handled silently (default: bzip2, (g)zip, tar).

export NNN_ARCHIVE="\\.(7z|bz2|gz|tar|tgz|zip)$"

NOTE: Non-default formats may require a third-party utility.

NNN_ARCHMNT:

optional archive mounter utility (default: archivemount).

export NNN_ARCHIVE='fuse-archive'

NNN_SSHFS:

specify custom sshfs command with options:

export NNN_SSHFS='sshfs -o reconnect,idmap=user,cache_timeout=3600'

NOTE: The options must be comma-separated without any space between them.

NNN_RCLONE:

pass additional options to rclone command:

export NNN_RCLONE='rclone mount --read-only --no-checksum'

NOTE: The options must be preceded by "rclone" and max 5 flags are supported.

NNN_TRASH:

trash (instead of rm -rf) files to desktop Trash.

export NNN_TRASH=cmd

NOTES:
1. cmd is the name/path of the binary that nnn will call for
   trashing files. E.g to use macOS's native `trash' command:
   export NNN_TRASH="trash"
2. Special value "1" and "2" for cmd will use trash-cli and
   gio trash respectively.

NNN_SEL:

absolute path to custom selection file.

export NNN_SEL='/tmp/.sel'

NNN_FIFO:

path of a named pipe to write the hovered file path:

export NNN_FIFO='/tmp/nnn.fifo'

NOTES:
1. Overridden by a temporary path with -a option.
2. If the FIFO file doesn't exist it will be created,
   but not removed (unless it is generated by -a option).

Online docs: https://github.com/jarun/nnn/wiki/Live-previews

NNN_LOCKER:

terminal locker program.

export NNN_LOCKER='bmon -p wlp1s0'
export NNN_LOCKER='cmatrix'

NNN_TMPFILE:

always cd on quit and write the command in the file specified.

export NNN_TMPFILE='/tmp/.lastd'

NNN_HELP:

run a program and show the output on top of the program help page.

export NNN_HELP='fortune'

NNN_MCLICK:

key emulated by a middle mouse click.

export NNN_MCLICK='^R'

NOTE: Only the first character is considered if not a Ctrl+key combo.

nnn:

this is a special variable.

Set to the hovered file name before starting the command prompt or spawning a shell.

NO_COLOR:

disable ANSI color output (overridden by NNN_COLORS).
