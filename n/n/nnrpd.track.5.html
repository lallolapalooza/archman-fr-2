NOM

nnrpd.track - Spécifier les hôtes à suivre par nnrpd

DESCRIPTION

Ce fichier, situé dans pathetc, spécifie quels hôtes doivent voir leurs activités enregistrées pendant une session nnrpd. Le serveur nnrpd le lit lors de son premier démarrage par innd, à condition que readertrack dans inn.conf soit vrai ; sinon, ce fichier n'est pas utilisé.

Les entrées consistent en une spécification d'hôte par ligne, chaque ligne ayant deux champs, séparés par un deux-points :

hôte:identité

Le premier champ est soit l'un des FQDN (Fully Qualified Domain Name) d'un hôte, soit un nom de domaine (sous la forme "*.domaine.com").

Le second champ est simplement un segment de texte qui peut être utilisé pour identifier plus facilement le client, typiquement une adresse e-mail ou une autre marque d'identification. Chaque publication des hôtes suivis aura une entrée associée à identité dans le message de journal enregistré dans le répertoire pathlog/tracklogs, et chaque article publié sera sauvegardé dans le répertoire pathlog/trackposts.

Un exemple de fichier nnrpd.track est :

nasty.foo.com:nasty@foo.com
*.bar.com:VeryNastyClient
