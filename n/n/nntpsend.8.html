NOM

nntpsend - Envoyer des articles Usenet à des sites distants

SYNTAXE

nntpsend [-acDdlNnpr] [-P portnum] [-s size] [-T timelimit] [-t timeout] [-w delay] [nomdutype fqdn] ...

DESCRIPTION

nntpsend est une interface qui invoque innxmit pour envoyer des articles Usenet à un site NNTP distant. Les sites à alimenter peuvent être spécifiés en donnant des paires nomdutype fqdn sur la ligne de commande. Si aucune de ces paires n'est donnée, nntpsend utilise par défaut les informations fournies dans le fichier de configuration nntpsend.ctl. Le nomdutype doit être le nom du site tel que spécifié dans le fichier newsfeeds. Le fqdn doit être le nom d'hôte ou l'adresse IP du site distant. Un processus innxmit est lancé pour les sites ayant des nouvelles en file d'attente. Tous les processus innxmit sont lancés en arrière-plan et le script attend qu'ils aient tous terminé avant de retourner. La sortie est envoyée au fichier nntpsend.log dans pathlog. Pour éviter de surcharger le système local, nntpsend attend cinq secondes avant de lancer chaque processus enfant.

nntpsend s'attend à ce que le fichier de traitement par lots pour un site soit nommé nomdutype dans pathoutgoing. Pour éviter la corruption des fichiers de traitement par lots, shlock est utilisé pour "verrouiller" ces fichiers. Lorsque des paires nomdutype fqdn sont données sur la ligne de commande, tous les indicateurs donnés sur la ligne de commande décrivent complètement comment innxmit et shrinkfile fonctionnent. Lorsque aucune paire de ce type n'est donnée sur la ligne de commande, les informations trouvées dans nntpsend.ctl deviennent les indicateurs par défaut pour ce site. Tous les indicateurs donnés sur la ligne de commande remplacent les indicateurs par défaut pour le site.

Une alternative à nntpsend peut être innduct, mentionné dans la page de manuel innfeed(8).

OPTIONS

-D, -d
L'indicateur -D fait que nntpsend envoie la sortie vers stdout plutôt que vers le fichier journal nntpsend.log dans pathlog. L'indicateur -d fait la même chose et passe -d à toutes les invocations d'innxmit, ce qui à son tour fait passer innxmit en mode débogage.
-n
Si l'indicateur -n est utilisé, alors nntpsend n'utilise pas shlock pour verrouiller l'utilisation de nntpsend. Les fichiers de traitement par lots seront toujours verrouillés.
-s taille
Si l'indicateur -s est utilisé, alors shrinkfile sera invoqué pour effectuer une troncature d'en-tête de taille octets sur le fichier de traitement par lots et l'indicateur lui sera passé.
-w delai
Si l'indicateur -w est utilisé, alors nntpsend attend delai secondes après avoir vidé le site avant de lancer innxmit.
-a, -c, -l, -N, -P portnum, -p, -r, -T limitetemps, -t delai
Les indicateurs -a, -c, -l, -P portnum, -p, -r, -T limitetemps et -t delai sont passés au programme enfant innxmit. L'indicateur -N est passé comme indicateur -s au programme enfant innxmit. Voir innxmit(8) pour plus de détails.

Notez que si l'indicateur -p est utilisé, aucune connexion n'est établie et aucun article n'est envoyé au site distant. Il est utile de faire invoquer nntpsend par cron(8) avec cet indicateur au cas où un site ne serait pas joignable pendant une période prolongée.

EXEMPLES

Avec le fichier de configuration nntpsend.ctl suivant :

nsavax:erehwon.nsavax.gov::-t60
group70:group70.org::
walldrug:walldrug.com:4m-1m:-T1800 -t300
kremvax:kremvax.cis:2m:

La commande "nntpsend" entraînera ce qui suit :

Nomdutype       Troncature      indicateurs innxmit
nsavax          (aucun)          -a -t60
group70         (aucun)          -a -t180
walldrug        1m si >4m       -T1800 -t300
kremvax         2m              -t180

La commande "nntpsend -d -T1200" entraînera ce qui suit :

Nomdutype       Troncature      indicateurs innxmit
nsavax          (aucun)          -a -d -T1200 -t60
group70         (aucun)          -a -d -T1200 -t180
walldrug        1m si >4m       -d -T1200 -t300
kremvax         2m              -d -T1200 -t180

La commande "nntpsend -s 5m -T1200 nsavax erehwon.nsavax.gov group70 group70.org" entraînera ce qui suit :

Nomdutype       Troncature      indicateurs innxmit
nsavax          5m              -T1200 -t180
group70         5m              -T1200 -t180

Rappelez-vous que -a est toujours donné lorsqu'il n'y a pas de limite de taille, et -t est par défaut à 180.
