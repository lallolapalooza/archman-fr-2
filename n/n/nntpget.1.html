NOM

nntpget - Récupérer des articles Usenet depuis un serveur NNTP distant

SYNTAXE

nntpget [-ov] [-f fichier] [-n groupes_de_nouvelles] [-t chaîne_temporelle] [-u fichier] hôte

DESCRIPTION

nntpget se connecte au serveur NNTP à l'adresse hôte spécifiée et en récupère les articles. Les Message-IDs des articles désirés sont lus depuis l'entrée standard. Les articles sont envoyés vers la sortie standard.

Au lieu de lire les Message-IDs depuis la sortie standard, les options -f, -n, -t et -u utilisent la commande "NEWNEWS", qui peut ne pas être disponible sur le serveur distant. Une seule des options -f, -t ou -u peut être donnée en même temps ; -n ne peut être spécifiée que si l'une des trois autres options est utilisée.

Si des identifiants d'authentification sont présents pour le serveur distant dans le fichier passwd.nntp du répertoire pathetc, alors nntpget les utilisera pour s'authentifier.

OPTIONS

-f fichier
La liste des Message-IDs des articles est normalement lue depuis l'entrée standard. Si cette option est utilisée, alors une commande "NEWNEWS" est utilisée pour récupérer tous les articles plus récents que la date de modification du fichier spécifié.
-n groupes_de_nouvelles
Si les options -f, -t ou -u sont utilisées, alors cette option peut être utilisée pour limiter les réponses aux seuls groupes de nouvelles (le cas échéant) dont les noms correspondent à la liste. La valeur par défaut est "*", c'est-à-dire que tous les groupes de nouvelles sont désirés.

La liste groupes_de_nouvelles peut contenir plusieurs motifs et caractères de joket (wildmat). Par exemple "misc.*,!*.test" est une liste valide qui sera donnée à la commande "NEWNEWS".

-o
Cette option ne peut être utilisée que si la commande est exécutée sur l'hôte où le serveur innd est en cours d'exécution. Si cette option est utilisée, nntpget se connecte à l'hôte distant spécifié pour récupérer les articles. Tout article non présent dans la base de données history locale est alors récupéré depuis le site distant et proposé au serveur local.

Les articles ne sont pas écrits sur la sortie standard. Seuls les Message-IDs traités le sont, si l'option -v est également utilisée.

-t chaîne_temporelle
Si cette option est utilisée, alors la chaîne_temporelle spécifiée est utilisée comme paramètre de date et d'heure pour la commande "NEWNEWS". Seuls les articles arrivés sur le serveur distant depuis ce timestamp sont récupérés.

La chaîne_temporelle est spécifiée comme "aaaammjj hhmmss GMT" où "aaaa" est l'année, "mm" le mois, "jj" le jour du mois, "hh" les heures sur l'horloge de 24 heures, "mm" les minutes, et "ss" les secondes. Le jeton "GMT" spécifie que la date et l'heure sont données en temps universel coordonné.

-u fichier
Cette option est similaire à -f, sauf que si le transfert réussit, le fichier sera mis à jour avec une ligne de statistiques, modifiant son horodatage de manière à pouvoir être utilisé lors d'invocations ultérieures.
-v
Si cette option est utilisée avec -o, alors le Message-ID de chaque article sera envoyé à la sortie standard au fur et à mesure de son traitement.
