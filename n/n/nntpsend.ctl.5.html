NOM

nntpsend.ctl - Liste des sites à alimenter via nntpsend

DESCRIPTION

Le fichier pathetc/nntpsend.ctl spécifie la liste par défaut des sites à alimenter par nntpsend. Les commentaires commencent par un signe numéro ("#") et se poursuivent jusqu'à la fin de la ligne. Les lignes vides et les commentaires sont ignorés. Toutes les autres lignes doivent consister en quatre champs séparés par un deux-points.

Le premier champ est le nom du site tel que spécifié dans le fichier newsfeeds.

Le deuxième champ doit être le nom d'hôte ou l'adresse IP du site distant.

Le troisième champ, s'il n'est pas vide, spécifie la taille de troncature par défaut de l'en-tête du fichier batch. Si ce champ est vide, aucune troncature n'est effectuée. Ce champ peut être de la forme "maxsize-truncsize", auquel cas il est passé à shrinkfile sous la forme "-m maxsize -s truncsize" ; sinon, il est de la forme "truncsize", auquel cas il est passé sous la forme "-s truncsize".

Le quatrième champ spécifie certains indicateurs par défaut passés à innxmit. Notez que l'indicateur -a est toujours donné à innxmit et n'a pas besoin d'apparaître ici. Si aucun indicateur -t n'est donné dans ce champ ou sur la ligne de commande nntpsend, "-t 180" sera donné à innxmit.

Voir nntpsend(8) pour un exemple de fichier de configuration nntpsend.ctl.
