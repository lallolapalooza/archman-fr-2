NOM

nsd-checkconf - Vérificateur de fichier de configuration NSD.

SYNTAXE

nsd-checkconf [-v] [-f] [-h] [-o option] [-z nomzone] [-p modèle] [-s nomclé] [-t nomdomaineauth] fichierconfig

DESCRIPTION

nsd-checkconf lit un fichier de configuration. Il imprime les erreurs d'analyse sur la sortie d'erreur standard et effectue des vérifications supplémentaires sur le contenu. Le format du fichier de configuration est décrit dans nsd.conf(5).

L'utilité de ce programme est de vérifier un fichier de configuration pour détecter les erreurs avant de l'utiliser dans nsd(8). Ce programme peut également être utilisé pour les scripts shell afin d'accéder au fichier de configuration nsd, en utilisant les options -o et -z.

OPTIONS

-v
Après lecture, imprime les options sur la sortie standard au format fichier de configuration. Sans cette option, seuls le succès ou les erreurs d'analyse sont signalés.
-f
Imprime le chemin d'accès complet lorsqu'il est utilisé avec des fichiers, comme avec -o pidfile. Cela inclut le chroot tel qu'il est appliqué au fichier pid.
-h
Imprime l'aide d'utilisation et quitte.
-o option
Retourne uniquement cette option du fichier de configuration. Cette option peut être utilisée conjointement avec les options -z et -p, ou sans elles pour interroger la section server. La valeur spéciale zones imprime une liste des zones configurées. La valeur spéciale patterns imprime une liste des modèles configurés.

Cette option peut être utilisée pour analyser le fichier de configuration depuis le shell. Si l'option -z est donnée, mais que l'option -o n'est pas donnée, rien n'est imprimé.

-s nomclé
Imprime le secret de la clé (blob base64) configuré pour cette clé dans le fichier de configuration. Utilisé pour aider les scripts shell à analyser le fichier de configuration.
-t tls-auth
Imprime le nom de domaine d'authentification configuré pour cette clause tls-auth dans le fichier de configuration. Utilisé pour aider les scripts shell à analyser le fichier de configuration.
-p modèle
Retourne l'option spécifiée avec -o pour le nom du modèle donné.
-z nomzone
Retourne l'option spécifiée avec -o pour la zone 'nomzone'.

Si cette option n'est pas donnée, la section serveur du fichier de configuration est utilisée.

Les options -o, -s et -z impriment les options du fichier de configuration sur la sortie standard.

FICHIERS

//etc/nsd/nsd.conf
Fichier de configuration NSD par défaut.
