NOM

nsm-proxy - page de manuel pour nsm-proxy Version 1.6.1

DESCRIPTION

nsm-proxy - Wrapper pour exécutables sans support NSM direct.

C'est un module pour le « New Session Manager » et il communique uniquement via OSC dans une session NSM et n'a aucune fonctionnalité autonome.

Usage :

nsm-proxy --help

OPTIONS

--help
