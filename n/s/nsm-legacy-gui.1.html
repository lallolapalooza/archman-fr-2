NOM

nsm-legacy-gui - page de manuel pour nsm-legacy-gui Version 1.6.1

DESCRIPTION

nsm-legacy-gui - Interface graphique FLTK pour le 'New Session Manager'

Utilisation :

nsm-legacy-gui nsm-legacy-gui --help

OPTIONS

--help
Afficher cet écran
--nsm-url url
Se connecter à un nsmd en cours d'exécution [Exemple : osc.udp://monordinateur.localdomain:38356/].
--
Tout ce qui suit -- sera transmis à nsmd en tant qu'options serveur. Voir nsmd --help .

Pour des raisons de compatibilité ascendante, cet exécutable existe également sous forme de lien symbolique 'non-session-manager'
