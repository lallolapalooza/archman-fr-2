NSXIV(1) Manuel des commandes générales NSXIV(1)

NOM

nsxiv - Visionneuse d'images Neo Simple X

SYNTAXE

nsxiv [-abcfhiopqrtvZ0] [-A TAUXDEFRA] [-e WID] [-G GAMMA] [-g GEOMETRIE] [-N NOM] [-n NUM] [-S DELAI] [-s MODE] [-z ZOOM] FICHIER...

DESCRIPTION

nsxiv est une visionneuse d'images simple pour X.

Elle dispose de deux modes de fonctionnement : le mode image et le mode miniature. Le mode par défaut est le mode image, dans lequel seule l'image actuelle est affichée. En mode miniature, une grille de petites aperçus est affichée, ce qui permet de choisir facilement une image à ouvrir.

Veuillez noter que le mode plein écran nécessite un gestionnaire de fenêtres compatible EWMH/NetWM.

OPTIONS

-A, --framerate TAUXDEFRA
Lit les animations avec un taux de trame constant défini sur TAUXDEFRA. Si TAUXDEFRA est défini sur 0, la lecture des animations est désactivée.
-a, --animate
Lit les animations d'images multi-images.
-b
N'affiche pas la barre d'état.
--bar, --no-bar
Active ou désactive la barre d'état. --no-bar est équivalent à -b.
-c, --clean-cache
Supprime tous les fichiers de cache orphelins du répertoire de cache des miniatures et quitte.
-e, --embed WID
Intègre la fenêtre de nsxiv dans la fenêtre dont l'ID est WID.
-f, --fullscreen
Démarre en mode plein écran.
-G, --gamma GAMMA
Définit le gamma de l'image sur GAMMA (-32..32).
-g, --geometry GEOMETRIE
Définit la position et la taille de la fenêtre. Voir la section SPÉCIFICATIONS DE GÉOMÉTRIE de X(7) pour plus d'informations sur l'argument GEOMETRY.
-h, --help
Affiche un bref résumé d'utilisation sur la sortie standard et quitte.
-i, --stdin
Lit les noms des fichiers à ouvrir depuis l'entrée standard. Cela est également fait si FICHIER est `-'.
-N, --name NOM
Définit le nom de la fenêtre (c'est-à-dire le nom "Instance" de WM_CLASS tel que décrit dans ICCCM) sur NOM.
-n, --start-at NUM
Démarre à l'image numéro NUM.
-o, --stdout
Écrit la liste de tous les fichiers marqués sur la sortie standard lors de la quitter. En combinaison avec -i, --stdin, nsxiv peut être utilisé comme un filtre/pipe visuel.
-p, --private
Active le mode privé, dans lequel nsxiv n'écrit aucun fichier cache ou temporaire.
-q, --quiet
Soit silencieux, et désactive les avertissements sur le flux d'erreur standard.
-r, --recursive
Recherche les répertoires donnés récursivement pour les images à visionner.
-S, --ss-delay DELAI
Démarre en mode diaporama. Définit le délai entre les images sur DELAI secondes. DELAI peut être un nombre à virgule flottante.
-s, --scale-mode MODE
Définit le mode de mise à l'échelle selon le caractère MODE. Les modes supportés sont : [d]own (vers le bas), [f]it (ajuster), [F]ill (remplir), [w]idth (largeur), [h]eight (hauteur).
-t, --thumbnail[=no]
Démarre en mode miniature. L'option longue accepte un "no" optionnel pour la désactiver.
-v, --version
Affiche les informations de version sur la sortie standard et quitte.
-Z, --zoom-100
Identique à `-z 100'.
-z, --zoom ZOOM
Définit le niveau de zoom sur ZOOM pour cent.
-0, --null
Utilise un séparateur NULL. Avec cette option, la sortie de -o et la liste des fichiers envoyée au gestionnaire de touches et l'entrée de -i seront séparées par un caractère NULL.
--anti-alias[=no]
Active l'anti-aliasing, lorsque no est donné comme argument, le désactive à la place.
--alpha-layer[=no]
Active un arrière-plan en damier pour la couche alpha, lorsque no est donné comme argument, le désactive à la place.
--cache-allow, --cache-deny CHEMINSCACHE
Liste des répertoires à autoriser ou refuser pour la mise en cache des miniatures. Voir la section MISE EN CACHE DES MINIATURES pour plus d'informations sur le format de l'argument. Ces options sont mutuellement exclusives, si elles sont spécifiées plus d'une fois, seule la dernière prendra effet.

CONFIGURATION

Les ressources X suivantes sont prises en charge sous "Nsxiv" (par exemple, Nsxiv.bar.font) :

window.background
Couleur de fond de la fenêtre
window.foreground
Couleur de premier plan de la fenêtre
bar.font
Nom de la police Xft pour la barre
bar.background
Couleur de fond de la barre. Par défaut : window.background
bar.foreground
Couleur de premier plan de la barre. Par défaut : window.foreground
mark.foreground
Couleur de premier plan de la marque. Par défaut : window.foreground
Veuillez consulter xrdb(1) pour savoir comment les modifier.

Une entrée de ressources X avec une valeur vide signifie que la valeur par défaut (définie dans config.h) sera utilisée.

TITRE FENÊTRE

Le titre de la fenêtre peut être remplacé par la sortie d'un script fourni par l'utilisateur, qui est appelé par nsxiv chaque fois que l'une des informations pertinentes change. Le chemin de ce script est $XDG_CONFIG_HOME/nsxiv/exec/win-title et les arguments qui lui sont passés (où les arguments "Optionnels" peuvent être vides) sont :

$1
chemin absolu résolu du fichier courant
$2
numéro du fichier courant
$3
nombre total de fichiers
$4
largeur de l'image (Optionnel : désactivé en mode miniature)
$5
hauteur de l'image (Optionnel : désactivé en mode miniature)
$6
zoom actuel (Optionnel : désactivé en mode miniature)

Le terme fichier est utilisé à la place d'image car nsxiv ne vérifie pas au préalable que les fichiers d'entrée sont des images valides. Le nombre total de fichiers peut être différent du nombre réel d'images valides.

Il existe également un script d'exemple installé avec nsxiv sous /usr/share/doc/nsxiv/examples/win-title.

BARRE STATUT

Les informations affichées sur le côté gauche de la barre de statut peuvent être remplacées par la sortie d'un script fourni par l'utilisateur.

Le script appelé par nsxiv chaque fois qu'une image est chargée est situé à $XDG_CONFIG_HOME/nsxiv/exec/image-info et les arguments qui lui sont passés sont :

$1
chemin vers le fichier image (tel que fourni par l'utilisateur)
$2
largeur de l'image
$3
hauteur de l'image
$4
chemin entièrement résolu vers le fichier image

En mode miniature, le script appelé est situé à $XDG_CONFIG_HOME/nsxiv/exec/thumb-info et les arguments qui lui sont passés sont :

$1
chemin vers le fichier image (tel que fourni par l'utilisateur)
$2
vide
$3
vide
$4
chemin entièrement résolu vers le fichier image

Il existe également des scripts d'exemple installés avec nsxiv sous /usr/share/doc/nsxiv/examples/image-info et /usr/share/doc/nsxiv/examples/thumb-info.

GESTIONNAIRE CLAVIER EXTERNE

Des commandes clavier externes supplémentaires peuvent être définies à l'aide d'un programme gestionnaire situé dans $XDG_CONFIG_HOME/nsxiv/exec/key-handler. Le gestionnaire est appelé en appuyant sur Ctrl-x. La combinaison de touches suivante lui est passée comme premier argument. Les images sur lesquelles agir sont passées via stdin : toutes les images marquées, si en mode miniature et au moins une image a été marquée, sinon l'image courante. nsxiv(1) bloquera jusqu'à ce que le gestionnaire se termine. Il vérifie ensuite quelles images ont été modifiées et les recharge.

Par défaut, nsxiv(1) envoie une image par ligne à stdin, cependant, lors de l'utilisation de

-0 la liste des images sera séparée par NULL et la variable d'environnement "$NSXIV_USING_NULL" sera définie à 1.

L'argument de combinaison de touches a la forme suivante : "[C-][M-][S-]CLE", où C/M/S indiquent les états des modificateurs Ctrl/Meta(Alt)/Shift et CLE est le keysym X tel qu'il apparaît dans /usr/include/X11/keysymdef.h sans le préfixe "XK_". Si CLE a un équivalent en majuscule, S-CLE est résolu en celui-ci. Par exemple, K remplace S-k et Scedilla remplace S-scedilla, mais S-Delete est envoyé tel quel.

Il y a également un script d'exemple installé avec nsxiv, nommé /usr/share/doc/nsxiv/examples/key-handler.

CACHAGE DES MINIATURES

nsxiv stocke toutes les miniatures sous $XDG_CACHE_HOME/nsxiv/.

Utilisez l'option de ligne de commande -c pour supprimer tous les fichiers de cache orphelins. De plus, exécutez la commande suivante après coup dans le répertoire de cache pour supprimer les sous-répertoires vides :

find . -depth -type d -empty ! -name '.' -exec rmdir {} \;

L'option --cache-allow ou --cache-deny peut être utilisée pour autoriser ou interdire la mise en cache de certains répertoires. L'argument est une liste de chemins séparés par :. Un * au début du chemin indique que le chemin doit être mis en correspondance récursivement.

Par exemple : --cache-allow "/user/pictures:*/media/pictures" autorise le répertoire "/user/pictures" de manière non récursive et le répertoire "/media/pictures" de manière récursive. Rien en dehors de ces deux répertoires ne sera mis en cache. Et --cache-deny "*/secret" activera le mode de liste noire et ne mettra en cache rien à l'intérieur de "/secret" ou de ses sous-répertoires.
