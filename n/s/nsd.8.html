NOM

nsd - Name Server Daemon (NSD) version 4.12.0.

SYNTAXE

nsd [-4] [-6] [-a adresse-ip[@port]] [-c fichier-config] [-d] [-h] [-i identite] [-I nsid] [-l fichier-log] [-N nombre-serveurs] [-n nombre-tcp-non-courants] [-P fichier-pid] [-p port] [-s secondes] [-t repertoire-chroot] [-u nom-utilisateur] [-V niveau] [-v]

DESCRIPTION

NSD est une implémentation complète d'un serveur de noms DNS faisant autorité. Au démarrage, NSD lit le fichier de configuration et se met en arrière-plan pour répondre aux requêtes sur le port 53 ou sur un autre port spécifié avec l'option -p port. Par défaut, NSD se connecte à toutes les interfaces locales disponibles. Utilisez l'option -a adresse-ip[@port] pour spécifier une seule adresse d'interface particulière à laquelle se connecter. Si cette option est donnée plus d'une fois, NSD connectera ses sockets UDP et TCP à toutes les adresses IP spécifiées séparément. Si IPv6 est activé lors de la compilation de NSD, une adresse IPv6 peut également être spécifiée.

OPTIONS

Toutes les options peuvent être spécifiées dans le fichier de configuration (argument -c), à l'exception des options -v et -h. Si les options sont spécifiées en ligne de commande, celles-ci priment sur les options du fichier de configuration.

Normalement, NSD devrait être démarré avec la commande `nsd-control(8) start` invoquée à partir d'un script /etc/rc.d/nsd.sh ou similaire au démarrage du système d'exploitation.

-4
Écouter uniquement les connexions IPv4.
-6
Écouter uniquement les connexions IPv6.
-a adresse-ip[@port]
Écouter sur l'adresse-ip spécifiée. L'adresse-ip doit être spécifiée au format numérique (en utilisant la notation standard IPv4 ou IPv6). Optionnellement, un numéro de port peut être donné. Ce drapeau peut être spécifié plusieurs fois pour écouter sur plusieurs adresses IP. Si ce drapeau n'est pas spécifié, NSD écoute sur l'interface générique.
-c fichier-config
Lire le fichier-config spécifié au lieu du fichier par défaut //etc/nsd/nsd.conf. Pour la description du format, voir nsd.conf(5).
-d
Ne pas se mettre en arrière-plan, rester au premier plan.
-h
Afficher les informations d'aide et quitter.
-i identite
Retourner l'identite spécifiée lorsqu'on interroge pour CH TXT ID.SERVER (Cette option est utilisée pour déterminer quel serveur répond aux requêtes lorsqu'elles sont en anycast). La valeur par défaut est le nom retourné par gethostname(3).
-I nsid
Ajouter le nsid spécifié à la section EDNS de la réponse lorsqu'on interroge avec un paquet activé NSID EDNS. Sous forme de séquence de caractères hexadécimaux ou avec le préfixe ascii_ suivi d'une chaîne ascii.
-l fichier-log
Enregistrer les messages dans le fichier-log spécifié. Par défaut, les messages sont enregistrés dans stderr et syslog. Si un champ zonesdir: est spécifié dans le fichier de configuration, ce chemin peut être relatif à ce répertoire.
-N nombre
Démarrer nombre serveurs NSD. La valeur par défaut est 1. Démarrer plus d'un serveur n'est utile que sur des machines avec plusieurs processeurs et/ou plusieurs cartes réseau.
-n nombre
Le nombre maximum de connexions TCP simultanées qui peuvent être gérées par chaque serveur. La valeur par défaut est 100.
-P fichier-pid
Utiliser le fichier-pid spécifié au lieu du fichier par défaut spécifique à la plateforme, qui est le plus souvent /run/nsd/nsd.pid. Si un champ zonesdir: est spécifié dans le fichier de configuration, ce chemin peut être relatif à ce répertoire.
-p port
Répondre aux requêtes sur le port spécifié. Normalement, c'est le port 53.
-s secondes
Produire un vidage des statistiques toutes les secondes. Cela équivaut à envoyer périodiquement SIGUSR1 au démon.
-t chroot
Spécifie un répertoire dans lequel effectuer un chroot au démarrage. Cette option vous oblige à vous assurer qu'une socket syslogd(8) appropriée (par exemple, chrootdir /dev/log) est disponible, sinon NSD ne produira aucune sortie de journal.
-u nom-utilisateur
Abandonner les privilèges utilisateur et groupe au profit de ceux de nom-utilisateur après avoir connecté la socket. Le nom-utilisateur doit être l'un des suivants : nom d'utilisateur, id, ou id.gid. Par exemple : nsd, 80, ou 80.80.
-V niveau
Cette valeur spécifie le niveau de verbosité pour la journalisation (non-débogage). La valeur par défaut est 0.
-v
Afficher le numéro de version de NSD sur la sortie d'erreur standard et quitter.

NSD réagit aux signaux suivants :

SIGTERM

Arrêter de répondre aux requêtes, s'arrêter et quitter normalement.
SIGHUP

Rouvrir le fichier journal (aide à la rotation) et éventuellement mettre à jour les clés TSIG et les zones.
SIGUSR1

Dumps des statistiques au format BIND8 dans le journal. Ignoré sinon.

FICHIERS

/run/nsd/nsd.pid
l'identifiant de processus du serveur de noms.
//etc/nsd/nsd.conf
fichier de configuration par défaut de NSD

DIAGNOSTICS

NSD enregistrera tous les problèmes via le service syslog(8) standard daemon, sauf si l'option -d est spécifiée.

VOIR AUSSI

nsd.conf(5), nsd-checkconf(8), nsd-control(8)
