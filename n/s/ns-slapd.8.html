NOM

ns‐slapd - Le démon principal du serveur d'annuaire

SYNOPIS

ns-slapd -D dirconfig [-d niveau_debug] [-i fichier_pid] [-v] [-V]

DESCRIPTION

ns‐slapd lance le serveur d'annuaire LDAP

OPTIONS

Un résumé des options est inclus ci-dessous :

-v
Afficher la version du programme.
-D dirconfig
Spécifie le répertoire de configuration pointant vers l'instance à démarrer (par exemple, /etc/dirsrv/slapd‐localhost)
-d niveau_debug
Spécifie le niveau de débogage à utiliser
-i fichier_pid
Spécifie le fichier où le PID du processus sera stocké
