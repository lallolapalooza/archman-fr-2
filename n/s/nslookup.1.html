NOM

nslookup - interroger interactivement les serveurs de noms Internet

SYNTAXE

nslookup [-option] [nom | -] [serveur]

DESCRIPTION

nslookup est un programme permettant d'interroger les serveurs de noms de domaine Internet. nslookup a deux modes : interactif et non interactif. Le mode interactif permet à l'utilisateur d'interroger les serveurs de noms pour obtenir des informations sur divers hôtes et domaines, ou d'afficher une liste d'hôtes dans un domaine. Le mode non interactif affiche uniquement le nom et les informations demandées pour un hôte ou un domaine.

ARGUMENTS

Le mode interactif est entré dans les cas suivants :

a.
aucun argument n'est donné (le serveur de noms par défaut est utilisé) ;
b.
le premier argument est un tiret (-) et le second argument est le nom d'hôte ou l'adresse Internet d'un serveur de noms.

Le mode non interactif est utilisé lorsque le nom ou l'adresse Internet de l'hôte à rechercher est donné comme premier argument. L'argument optionnel suivant spécifie le nom d'hôte ou l'adresse d'un serveur de noms.

Les options peuvent également être spécifiées sur la ligne de commande si elles précèdent les arguments et sont précédées d'un tiret. Par exemple, pour modifier le type de requête par défaut en informations sur l'hôte, avec un délai d'attente initial de 10 secondes, tapez :

nslookup -query=hinfo  -timeout=10

L'option -version fait afficher à nslookup le numéro de version et le quitte immédiatement.

COMMANDES INTERACTIVES

hôte [serveur]
Cette commande recherche les informations pour hôte <#std-iscman-host> en utilisant le serveur par défaut actuel ou en utilisant serveur, s'il est spécifié. Si hôte <#std-iscman-host> est une adresse Internet et que le type de requête est A ou PTR, le nom de l'hôte est renvoyé. Si hôte <#std-iscman-host> est un nom et n'a pas de point final (.), la liste de recherche est utilisée pour qualifier le nom.

Pour rechercher un hôte qui n'est pas dans le domaine actuel, ajoutez un point au nom.

serveur domaine | lserver domaine
Ces commandes changent le serveur par défaut en domaine ; lserver utilise le serveur initial pour rechercher des informations sur domaine, tandis que serveur utilise le serveur par défaut actuel. Si une réponse faisant autorité ne peut être trouvée, les noms des serveurs susceptibles de contenir la réponse sont renvoyés.
root
Cette commande n'est pas implémentée.
finger
Cette commande n'est pas implémentée.
ls
Cette commande n'est pas implémentée.
view
Cette commande n'est pas implémentée.
help
Cette commande n'est pas implémentée.
?
Cette commande n'est pas implémentée.
exit
Cette commande quitte le programme.
set mot-clé[=valeur]
Cette commande est utilisée pour modifier les informations d'état qui affectent les recherches. Les mots-clés valides sont :
all
Ce mot-clé affiche les valeurs actuelles des options fréquemment utilisées de set. Les informations sur le serveur et l'hôte par défaut actuels sont également affichées.
class=valeur
Ce mot-clé change la classe de requête en l'une des suivantes :
IN
la classe Internet
CH
la classe Chaos
HS
la classe Hesiod
ANY
caractère générique

La classe spécifie le groupe de protocoles des informations. La valeur par défaut est IN ; l'abréviation pour ce mot-clé est cl.

nodebug
Ce mot-clé active ou désactive l'affichage du paquet de réponse complet, et de tout paquet de réponse intermédiaire, lors de la recherche. La valeur par défaut de ce mot-clé est nodebug ; l'abréviation pour ce mot-clé est [no]deb.
nod2
Ce mot-clé active ou désactive le mode débogage. Cela affiche davantage sur ce que fait nslookup. La valeur par défaut est nod2.
domaine=nom
Ce mot-clé définit la liste de recherche sur nom.
nosearch
Si la requête de recherche contient au moins un point, mais ne se termine pas par un point final, ce mot-clé ajoute les noms de domaine de la liste de recherche à la requête jusqu'à ce qu'une réponse soit reçue. La valeur par défaut est search.
port=valeur
Ce mot-clé change le port par défaut du serveur de noms TCP/UDP à valeur à partir de son port par défaut, 53. L'abréviation pour ce mot-clé est po.
querytype=valeur | type=valeur
Ce mot-clé change le type de la requête d'informations à valeur. Les valeurs par défaut sont A et AAAA ; les abréviations pour ces mots-clés sont q et ty.

Veuillez noter qu'il n'est possible de spécifier qu'un seul type de requête. Seul le comportement par défaut recherche les deux lorsqu'une alternative n'est pas spécifiée.

norecurse
Ce mot-clé indique au serveur de noms d'interroger d'autres serveurs s'il ne dispose pas des informations. La valeur par défaut est recurse ; l'abréviation pour ce mot-clé est [no]rec.
ndots=nombre
Ce mot-clé définit le nombre de points (séparateurs d'étiquettes) dans un domaine qui désactive la recherche. Les noms absolus arrêtent toujours la recherche.
retry=nombre
Ce mot-clé définit le nombre de nouvelles tentatives à nombre.
timeout=nombre
Ce mot-clé modifie l'intervalle de délai d'attente initial pour attendre une réponse à nombre, en secondes.
novc
Ce mot-clé indique qu'un circuit virtuel doit toujours être utilisé lors de l'envoi de requêtes au serveur. novc est la valeur par défaut.
nofail
Ce mot-clé essaie le serveur de noms suivant si un serveur de noms répond avec SERVFAIL ou une référence (nofail), ou termine la requête (fail) lors d'une telle réponse. La valeur par défaut est nofail.

VALEURS DE RETOUR

nslookup se termine avec un statut de sortie de 1 si une requête a échoué, et 0 sinon.

PRISE EN CHARGE DES IDN

Si nslookup a été compilé avec la prise en charge des IDN (noms de domaine internationalisés), il peut accepter et afficher des noms de domaine non ASCII. nslookup convertit correctement le codage des caractères d'un nom de domaine avant d'envoyer une requête à un serveur DNS ou d'afficher une réponse du serveur. Pour désactiver la prise en charge des IDN, définissez la variable d'environnement IDN_DISABLE. La prise en charge des IDN est désactivée si la variable est définie lorsque nslookup s'exécute, ou lorsque la sortie standard n'est pas un tty.
