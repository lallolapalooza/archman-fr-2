NSMD(1) Commandes utilisateur NSMD(1)

NOM

nsmd - page de manuel pour nsmd Version 1.6.1

DESCRIPTION

nsmd - Daemon et serveur pour le 'New Session Manager'

Usage :

nsmd nsmd --help nsmd --version

OPTIONS

--help
Afficher cet écran
--version
Afficher la version
--osc-port portnum
Numéro de port OSC [Défaut : fourni par le système].
--session-root chemin
Chemin de base pour les sessions [Défaut : $XDG_DATA_HOME/nsm/].
--load-session nom
Charger une session existante [Exemple : « Ma Chanson »].
--gui-url url
Se connecter à un gui legacy en cours d'exécution [Exemple : osc.udp://monordinateur.localdomain:38356/].
--detach
Se détacher de la console.
--quiet
Supprimer les messages sauf les avertissements et les erreurs.

nsmd peut être exécuté sans interface graphique avec des sessions existantes. Pour en créer de nouvelles, il est recommandé d'utiliser une interface graphique telle que nsm-legacy-gui (incluse) ou Agordejo (paquet séparé)
