NOM

nsd-checkzone - Vérificateur de syntaxe de fichier de zone NSD.

SYNOPSIS

nsd-checkzone [-h] nomzone fichierzone

DESCRIPTION

nsd-checkzone lit un fichier de zone DNS et vérifie les erreurs. Il affiche les erreurs sur stderr. En cas d'échec, il renvoie un statut de sortie non nul.

Ceci est utilisé pour vérifier les fichiers avant de les fournir au démon nsd(8).

OPTIONS

-h
Affiche l'aide et quitte.
nomzone
Le nom de la zone à vérifier, par exemple « example.com ».
fichierzone
Le fichier à lire, par exemple « zones/example.com.zone.signed ». Utilisez « - » pour lire depuis stdin.
-p
Affiche le contenu de la zone sur stdout si la zone est correcte. Cela affiche le contenu tel qu'il a été analysé, pas littéralement une copie de l'entrée, mais tel qu'affiché par les routines de formatage de NSD, un peu comme le fait la commande nsd-control write.
-i <ancienfichierzone>
Crée un IXFR à partir des différences entre l'ancien fichier de zone et le nouveau fichier de zone. L'argument de l'option -i est l'ancien fichier de zone, l'autre argument fichierzone passé est le nouveau fichier de zone.

La différence est calculée entre les deux fichiers de zone en conservant une version de la zone en mémoire et une autre version dans un fichier temporaire. Le fichier temporaire est situé dans le répertoire des fichiers de zone. C'est là que le résultat est également écrit, dans un fichier portant le nom du fichier de zone, se terminant par « .ixfr ». C'est là que NSD le lit également lorsque les IXFR sont configurés pour la zone.

Les autres fichiers ixfr existants sont renommés pour devenir des contenus IXFR plus anciens pour la zone, si de tels fichiers existent. Si le fichier de sortie existe déjà avec le contenu correct, aucun nouveau fichier n'est créé. Le contenu de l'en-tête du fichier de sortie est vérifié à cet effet, s'il existe déjà.

-n <nombreixfr>
Le nombre de versions IXFR à stocker, au maximum. Par défaut 5. C'est le nombre de fichiers créés avec le contenu ixfr pour la zone. Les versions IXFR stockées plus anciennes sont supprimées lorsque le nombre est dépassé.
-s <tailleixfr>
Le nombre d'octets de stockage à utiliser pour les IXFR. Par défaut 1048576. Si un IXFR est plus grand, il n'est pas créé, et si la somme du stockage IXFR le dépasse, les versions IXFR plus anciennes sont supprimées.
