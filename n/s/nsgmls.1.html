NOM

onsgmls - Un analyseur et validateur SGML/XML

SYNTAXE

onsgmls [-BCdeghlnpRrsuvx] [-atype_lien] [-Aarchitecture] [-bbctf] [-csysid...] [-Drépertoire] [-Eerreurs_max] [-ffichier] [-inom] [-ooption_sortie...] [-tfichier] [-wtype_avertissement...] [sysid...]

DESCRIPTION

onsgmls analyse et valide le document SGML dont l'entité document est spécifiée par les identificateurs système

et imprime sur la sortie standard une représentation textuelle simple de son jeu d'informations de structure d'éléments. (C'est le jeu d'informations sur lequel une application SGML conforme et contrôlée par la structure devrait agir.) Si plusieurs identificateurs système sont spécifiés, les entités correspondantes seront concaténées pour former l'entité document. Ainsi, l'entité document peut être répartie sur plusieurs fichiers ; par exemple, la déclaration SGML, le prolog et l'instance du document peuvent chacun être dans un fichier séparé. Si aucun identificateur système n'est spécifié, onsgmls lira l'entité document depuis l'entrée standard. Un identificateur système de - sur la ligne de commande peut être utilisé pour faire référence à l'entrée standard. (Normalement, dans un identificateur système, <OSFD>0 est utilisé pour faire référence à l'entrée standard.)

Fait partie d'un Système SGML Conforme à la Norme Internationale ISO 8879 -- Standard Generalized Markup Language. Un système SGML à extensions conformes à l'Annexe A de la Norme Internationale ISO/IEC 10744 -- Hypermedia/Time-based Structuring Language

Les options suivantes sont disponibles :

-atype_lien, --activate=type_lien

Rend le type de lien type_lien actif. Toutes les informations ESIS ne sont pas générées dans ce cas : les LPD actifs ne sont pas signalés explicitement, bien que chaque attribut de lien soit qualifié avec le nom de son type de lien ; il n'y a pas d'informations sur les éléments résultants ; lorsqu'il existe plusieurs règles de lien applicables à l'élément courant, onsgmls choisit toujours la première.

-Aarchitecture, --architecture=architecture

Analyse par rapport à l'architecture architecture.

-bbctf, --bctf=bctf, -bencodage, --encoding=encodage

Ceci détermine l'encodage utilisé pour la sortie. S'il est en mode jeu de caractères fixe, il spécifie le nom d'un encodage ; sinon, il spécifie le nom d'un BCTF.

-B, --batch_mode

Mode batch. Analyse chaque

spécifié sur la ligne de commande séparément, plutôt que de les concaténer. Ceci est principalement utile avec -s.

Si -tnom_fichier est également spécifié, alors le nom de fichier spécifié sera ajouté au préfixe de sysid pour créer le nom de fichier du résultat RAST pour chaque sysid.

-csysid, --catalog=sysid

Mappe les identificateurs publics et les noms d'entités vers des identificateurs système en utilisant le fichier d'entrée de catalogue dont l'identificateur système est sysid. Plusieurs options -c sont autorisées. S'il existe un fichier d'entrée de catalogue nommé catalog au même endroit que l'entité document, il sera recherché immédiatement après ceux spécifiés par -c.

-C, --catalogs

Les

arguments spécifient des fichiers de catalogue plutôt que l'entité document. L'entité document est spécifiée par la première entrée DOCUMENT dans les fichiers de catalogue.

-Drépertoire, --directory=répertoire

Recherche dans le répertoire les fichiers spécifiés dans les identificateurs système. Plusieurs options -D sont autorisées. Voir la description du gestionnaire de fichiers osfile pour plus d'informations sur la recherche de fichiers.

-e, --open-entities

Décrit les entités ouvertes dans les messages d'erreur. Les messages d'erreur incluent toujours la position de l'entité externe la plus récemment ouverte.

-Eerreurs_max, --max-errors=erreurs_max

onsgmls s'arrêtera après erreurs_max erreurs. Si erreurs_max est 0, il n'y a pas de limite au nombre d'erreurs. La valeur par défaut est 200.

-ffichier, --error-file=fichier

Redirige les erreurs vers fichier. Ceci est principalement utile avec les shells qui ne prennent pas en charge la redirection de stderr.

-g, --open-elements

Affiche les identificateurs génériques des éléments ouverts dans les messages d'erreur.

-h, --help

Affiche un message d'aide et quitte.

-inom, --include=nom

Suppose que

<!ENTITY % nom "INCLUDE">

se trouve au début de la sous-section de déclaration de type de document dans l'entité document SGML. Comme les définitions répétées d'une entité sont ignorées, cette définition aura la priorité sur toute autre définition de cette entité dans la déclaration de type de document. Plusieurs options -i sont autorisées. Si la déclaration SGML remplace le nom réservé INCLUDE, le nouveau nom réservé sera le texte de remplacement de l'entité. Typiquement, la déclaration de type de document contiendra

<!ENTITY % nom "IGNORE">

et utilisera %nom; dans la spécification du mot-clé de statut d'une déclaration de section marquée. Dans ce cas, l'effet de l'option sera de faire en sorte que la section marquée ne soit pas ignorée.

-n, --error-numbers

Affiche les numéros de message dans les messages d'erreur.

-ooption_sortie, --option=option_sortie

Génère des informations supplémentaires selon option_sortie :

entity Génère les définitions de toutes les entités générales, pas seulement celles des entités de données ou de sous-document qui sont référencées ou nommées dans un attribut ENTITY ou ENTITIES.

id Différencie les attributs dont la valeur déclarée est ID.

line Génère des commandes L indiquant le numéro de ligne courant et le nom du fichier.

included Génère une commande i pour les sous-éléments inclus.

empty Génère une commande e pour les éléments qui ne sont pas autorisés à avoir une balise de fin, c'est-à-dire ceux dont le contenu déclaré est vide ou qui ont un attribut de référence de contenu.

notation-sysid Génère une commande f avant une commande N, si un identificateur système peut être généré pour cette notation.

nonsgml En mode jeu de caractères fixe, génère des séquences d'échappement \% pour les caractères de données non SGML. Les caractères de données non SGML peuvent résulter de références de caractères numériques.

data-attribute Génère le nom de la notation et les attributs pour les attributs DATA. Sinon, les attributs DATA sont traités comme des attributs CDATA. Pour plus de détails, voir la clause 4.4.3 de l'Annexe K de ISO 8879.

comment Génère une commande _ avec le contenu d'un commentaire. Plusieurs commentaires dans une seule déclaration de commentaire entraîneront plusieurs commandes _ distinctes, comme si les commentaires étaient chacun dans une déclaration de commentaire séparée.

omitted Génère une commande o avant une commande qui a été implicite à partir du document d'entrée, mais omise dans le balisage réel. Cela affecte actuellement les commandes (,), et A.

tagomit Comme omitted, mais seulement pour les commandes ( et ).

attromit Comme omitted, mais seulement pour les commandes A.

Plusieurs options -o sont autorisées.

-p, --only-prolog

Analyse uniquement le prolog. onsgmls s'arrêtera après avoir analysé la déclaration de type de document. Implique -s.

-R, --restricted

Restreint la lecture de fichiers. Cette option est destinée à être utilisée avec des outils Web basés sur onsgmls (par exemple, des scripts CGI) pour empêcher la lecture de fichiers arbitraires sur le serveur Web. Avec cette option activée, onsgmls ne lira aucun fichier local à moins qu'il ne soit situé dans un répertoire (ou sous-répertoire) spécifié par l'option -D ou inclus dans la variable d'environnement SGML_SEARCH_PATH. Par mesure de sécurité supplémentaire, cette option limite les noms de fichiers aux caractères A-Z, a-z, 0-9, '?', '.', '_' et '-' et n'autorise pas les noms de fichiers contenant "..". Sur les systèmes avec des noms de fichiers MS-DOS, ':' et '\' sont également autorisés.

-s, --no-output

Supprime la sortie. Les messages d'erreur seront toujours imprimés

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

d.

-tfichier, --rast-file=fichier

Sortie dans le fichier du résultat RAST tel que défini par ISO/IEC 13673:1995 (en fait, ce n'est pas encore tout à fait une norme internationale ; ceci implémente le Projet d'éditeur intermédiaire de 1994/08/29, avec des modifications pour implémenter ISO/IEC JTC1/SC18/WG8 N1777). La sortie normale n'est pas produite.

-v, --version

Afficher le numéro de version.

-wtype, --warning=type

Contrôler les avertissements et les erreurs. Plusieurs options -w sont autorisées. Les valeurs suivantes de type activent les avertissements :

xml Avertir des constructions qui ne sont pas autorisées par XML.

mixed Avertir des modèles de contenu mixtes qui n'autorisent pas #PCDATA n'importe où.

sgmldecl Avertir de diverses constructions douteuses dans la déclaration SGML.

should Avertir des diverses recommandations faites dans ISO 8879 auxquelles le document n'est pas conforme. (Les recommandations sont exprimées avec "should", par opposition aux exigences qui sont généralement exprimées avec "shall".)

default Avertir des références par défaut.

duplicate Avertir des déclarations d'entités dupliquées.

undefined Avertir des éléments non définis : éléments utilisés dans la DTD mais non définis.

unclosed Avertir des balises ouvrantes et fermantes non fermées.

empty Avertir des balises ouvrantes et fermantes vides.

net Avertir des balises ouvrantes et fermantes nulles.

min-tag Avertir des balises ouvrantes et fermantes minimisées. Équivalent à la combinaison des avertissements unclosed, empty et net.

unused-map Avertir des cartes de référence courte inutilisées : cartes déclarées avec une déclaration de mappage de référence courte mais jamais utilisées dans une déclaration d'utilisation de référence courte dans la DTD.

unused-param Avertir des entités paramétriques qui sont définies mais non utilisées dans une DTD. Les entités paramétriques internes inutilisées dont le texte est INCLUDE ou IGNORE ne déclencheront pas l'avertissement.

notation-sysid Avertir des notations pour lesquelles aucun identifiant système n'a pu être généré.

all Avertir des conditions qui devraient généralement être évitées (de l'avis de l'auteur). Équivalent à : mixed, should, default, undefined, sgmldecl, unused-map, unused-param, empty et unclosed.

immediate-recursion Avertir des éléments immédiatement récursifs. Pour plus de détails, voir la clause 2.2.5 de l'Annexe K de ISO 8879.

fully-declared Avertir si l'instance du document n'est pas entièrement déclarée. Ceci a pour effet de modifier la déclaration SGML pour spécifier IMPLYDEF ATTLIST NO ELEMENT NO ENTITY NO NOTATION NO. Pour plus de détails, voir la clause 2.2.1 de l'Annexe K de ISO 8879.

fully-tagged Avertir si l'instance du document n'est pas entièrement balisée. Ceci a pour effet de modifier la déclaration SGML pour spécifier DATATAG NO, RANK NO, OMITTAG NO, SHORTTAG STARTTAG EMPTY NO et SHORTTAG ATTRIB OMITNAME NO. Pour plus de détails, voir la clause 2.2.2 de l'Annexe K de ISO 8879.

amply-tagged, amply-tagged-recursive Avertir si l'instance du document n'est pas suffisamment balisée. Les éléments définis implicitement peuvent être immédiatement récursifs si amply-tagged-recursive est spécifié. Ceci a pour effet de modifier la déclaration SGML pour spécifier DATATAG NO, RANK NO, OMITTAG NO, SHORTTAG ATTRIB OMITNAME NO et soit IMPLYDEF ELEMENT ANYOTHER soit IMPLYDEF ELEMENT YES. Pour plus de détails, voir la clause 2.2.4 de l'Annexe K de ISO 8879.

type-valid Avertir si l'instance du document n'est pas valide par type. Ceci a pour effet de modifier la déclaration SGML pour spécifier VALIDITY YES. Pour plus de détails, voir la clause 2.2.3 de l'Annexe K de ISO 8879.

entity-ref Avertir des références à des entités non prédéfinies. Ceci a pour effet de modifier la déclaration SGML pour spécifier ENTITIES REF NONE. Pour plus de détails, voir la clause 2.3.2 de l'Annexe K de ISO 8879.

external-entity-ref Avertir des références à des entités externes. Ceci inclut les références à un sous-ensemble DTD externe. Ceci a pour effet de modifier la déclaration SGML pour spécifier ENTITIES REF INTERNAL. Pour plus de détails, voir la clause 2.3.3 de l'Annexe K de ISO 8879.

integral Avertir si l'instance du document n'est pas stockée de manière intégrale. Ceci a pour effet de modifier la déclaration SGML pour spécifier ENTITIES INTEGRAL YES. Pour plus de détails, voir la clause 2.3.1 de l'Annexe K de ISO 8879.

Un avertissement peut être désactivé en utilisant son nom préfixé par no-. Ainsi, -wall -wno-duplicate activera tous les avertissements sauf ceux concernant les déclarations d'entités dupliquées.

Les valeurs suivantes pour type_avertissement désactivent les erreurs :

no-idref Ne pas signaler d'erreur pour une valeur de référence ID pour laquelle aucun élément n'a son ID. L'effet sera comme si chaque attribut déclaré comme valeur de référence ID avait été déclaré comme nom.

no-significant Ne pas signaler d'erreur lorsqu'un caractère qui n'est pas un caractère significatif dans la syntaxe concrète de référence se produit dans une littérale de la déclaration SGML. Ceci peut être utile en conjonction avec certaines suites de tests boguées.

no-valid Ne pas exiger que le document soit valide par type. Ceci a pour effet de modifier la déclaration SGML pour spécifier VALIDITY NOASSERT et IMPLYDEF ATTLIST YES ELEMENT YES. Une option -wvalid a pour effet de modifier la déclaration SGML pour spécifier VALIDITY TYPE et IMPLYDEF ATTLIST NO ELEMENT NO. Si ni -wvalid ni -wno-valid ne sont spécifiés, alors les VALIDITY et IMPLYDEF spécifiés dans la déclaration SGML seront utilisés.

no-afdr Ne pas signaler d'erreurs lorsque des fonctionnalités de notation AFDR meta-DTD sont utilisées dans la DTD. Ces erreurs sont normalement produites lors de l'analyse de la DTD, mais supprimées lors de l'analyse des meta-DTDs.

-x, --references

Afficher des informations sur les clauses pertinentes (de ISO 8879:1986) dans les messages d'erreur.

Les options suivantes sont également prises en charge pour des raisons de compatibilité ascendante avec sgmls :

-d

Identique à -wduplicate.

-l

Identique à -oline.

-msysid

Identique à -c.

-r

Identique à -wdefault.

-u

Identique à -wundef.
