NOM

nsec3hash - générer un hachage NSEC3

SYNTAXE

nsec3hash {sel} {algorithme} {itérations} {domaine}

nsec3hash -r {algorithme} {indicateurs} {itérations} {sel} {domaine}

DESCRIPTION

nsec3hash génère un hachage NSEC3 basé sur un ensemble de paramètres NSEC3. Ceci peut être utilisé pour vérifier la validité des enregistrements NSEC3 dans une zone signée.

Si cette commande est invoquée en tant que nsec3hash -r, elle prend les arguments dans l'ordre, correspondant aux quatre premiers champs d'un enregistrement NSEC3 suivi du nom de domaine : algorithme, indicateurs, itérations, sel, domaine. Cela permet de copier et coller facilement une partie d'un enregistrement NSEC3 ou NSEC3PARAM pour confirmer l'exactitude d'un hachage NSEC3.

ARGUMENTS

sel
Ceci est le sel fourni à l'algorithme de hachage.
algorithme
Ceci est un nombre indiquant l'algorithme de hachage. Actuellement, le seul algorithme de hachage pris en charge pour NSEC3 est SHA-1, qui est indiqué par le nombre 1 ; par conséquent, « 1 » est la seule valeur utile pour cet argument.
indicateurs
Ceci est fourni pour la compatibilité avec le format de présentation des enregistrements NSEC3, mais est ignoré car les indicateurs n'affectent pas le hachage.
itérations
Ceci est le nombre de fois supplémentaires où le hachage doit être effectué.
domaine
Ceci est le nom de domaine à hacher.
