NOTIFY-SEND(1) Commandes utilisateur NOTIFY-SEND(1)

NOM

notify-send - un programme pour envoyer des notifications de bureau

SYNTAXE

notify-send [OPTIONS] {résumé} [corps]

DESCRIPTION

Avec notify-send, vous pouvez envoyer des notifications de bureau à l'utilisateur via un démon de notification depuis la ligne de commande. Ces notifications peuvent être utilisées pour informer l'utilisateur d'un événement ou afficher une forme d'information sans le gêner.

OPTIONS

-?, --help

Affiche l'aide et quitte.

-a, --app-name=NOM_APP

Spécifie le nom de l'application pour la notification.

-A, --action=[NOM=]Texte...

Spécifie les actions à afficher à l'utilisateur. Implique --wait pour attendre l'entrée utilisateur. Peut être définie plusieurs fois. Le NOM de l'action est envoyé à la sortie standard. Si NOM n'est pas spécifié, l'index numérique de l'option est utilisé (en commençant par 1).

-u, --urgency=NIVEAU

Spécifie le niveau d'urgence (faible, normal, critique).

-t, --expire-time=TEMPS

La durée, en millisecondes, pendant laquelle la notification doit apparaître à l'écran.

Toutes les implémentations n'utilisent pas ce paramètre. GNOME Shell et Notify OSD l'ignorent toujours, tandis que Plasma l'ignore pour les notifications avec le niveau d'urgence critique.

-i, --icon=ICONE

Spécifie un nom de fichier d'icône ou une icône prédéfinie à afficher.

-c, --category=TYPE[,TYPE...]

Spécifie la catégorie de la notification.

-h, --hint=TYPE:NOM:VALEUR

Spécifie des données supplémentaires de base à passer. Les types valides sont BOOLEAN, INT, DOUBLE, STRING, BYTE et VARIANT.

-p, --print-id

Affiche l'ID de la notification.

-r, --replace-id=ID_REMPLACER

L'ID de la notification à remplacer.

-w, --wait

Attend que la notification soit fermée avant de quitter. Si l'expire-time est défini, il sera utilisé comme temps d'attente maximal.

-e, --transient

Affiche une notification transitoire. Les notifications transitoires contournent la capacité de persistance du serveur, le cas échéant. Elles ne seront donc pas conservées jusqu'à ce que l'utilisateur les confirme.

VOIR AUSSI

La spécification de notification de bureau sur https://specifications.freedesktop.org/notification-spec/.
