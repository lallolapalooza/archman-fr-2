NOM

notmuch-restore - restaure les étiquettes à partir du fichier donné (voir notmuch dump)

SYNOPSIS

notmuch restore [--accumulate] [--format=(auto|batch-tag|sup)] [--input=<nom_fichier>]

DESCRIPTION

Restaure les étiquettes à partir du fichier donné (voir notmuch-dump).

L'entrée est lue à partir du nom de fichier donné, le cas échéant, ou à partir de la entrée standard.

Les options prises en charge pour restore incluent

--accumulate
L'union des étiquettes existantes et nouvelles est appliquée, au lieu de remplacer les étiquettes de chaque message au fur et à mesure de leur lecture dans le fichier de vidage.
--format=(sup|batch-tag|auto)
Notmuch restore prend en charge deux formats de vidage texte brut, chaque ligne spécifiant un identifiant de message et un ensemble d'étiquettes. Pour plus de détails sur les formats réels, voir notmuch-dump.
sup
Le format de fichier de vidage sup est spécifiquement choisi pour être compatible avec le format des fichiers produits par sup-dump. Donc si vous utilisiez auparavant sup pour les emails, alors la commande notmuch restore vous offre un moyen d'importer toutes vos étiquettes (ou labels comme les appelle sup).
batch-tag
Le format de vidage batch-tag est destiné à être plus robuste contre les identifiants de messages malformés et les étiquettes contenant des espaces ou des caractères non-ascii(7). Voir notmuch-dump pour les détails sur ce format.

notmuch restore met à jour les indicateurs maildir en fonction des changements d'étiquettes si l'option de configuration maildir.synchronize_flags est activée. Voir notmuch-config pour les détails.

auto
Cette option (par défaut) tente de deviner le format à partir de l'entrée. Pour une entrée correctement formée dans l'un ou l'autre des formats pris en charge, cette heuristique, basée sur le fait que le format batch-tag ne contient pas de parenthèses, devrait être précise.
--include=(config|properties|tags)
Contrôle quel type de métadonnées est restauré.
config
Restaure les données de configuration dans la base de données. Chaque ligne de configuration commence par "#@ ", suivie d'une paire clé-valeur séparée par des espaces. La clé et la valeur sont encodées en hexadécimal si nécessaire.
properties
Restaure les métadonnées (clé, valeur) par message. Chaque ligne commence par "#= ", suivie d'un identifiant de message, et d'une liste de paires clé=valeur séparées par des espaces. Les identifiants, clés et valeurs sont encodés en hexadécimal si nécessaire. Voir notmuch-properties pour plus de détails.
tags
Restaure les métadonnées par message, à savoir les étiquettes. Voir format ci-dessus pour plus de détails.

Par défaut, toutes les sortes de données disponibles sont restaurées. L'option peut être spécifiée plusieurs fois pour sélectionner un sous-ensemble.

--input=<nom_fichier>
Lit l'entrée depuis le fichier donné au lieu de l'entrée standard.
