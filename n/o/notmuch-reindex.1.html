NOM

notmuch-reindex - réindexer les messages correspondants

SYNTAXE

notmuch reindex [option ...] <terme-de-recherche> ...

DESCRIPTION

Réindexe tous les messages correspondant aux termes de recherche.

Consulter notmuch-search-terms pour les détails sur la syntaxe supportée pour <terme-de-recherche>.

La commande reindex recherche tous les messages correspondant aux termes de recherche fournis, et recrée l'index plein texte de ces messages en utilisant les options fournies.

Les options supportées pour reindex incluent

--decrypt=(vrai|nostash|auto|faux)
Si vrai, lors de la rencontre d'un message chiffré, tentez de le déchiffrer pendant la réindexation, en sauvegardant toutes les clés de session découvertes. Si auto, et que notmuch connaît déjà une clé de session pour le message, il tentera de le déchiffrer en utilisant cette clé de session, mais n'essaiera pas d'accéder aux clés secrètes de l'utilisateur. Si le déchiffrement réussit, indexe le texte clair lui-même.

nostash est identique à vrai sauf qu'il ne sauvegardera pas les clés de session nouvellement découvertes dans la base de données.

Si faux, notmuch reindex supprimera également toutes les clés de session sauvegardées pour tous les messages correspondant aux termes de recherche.

Soyez conscient que l'index est probablement suffisant (et qu'une clé de session sauvegardée est certainement suffisante) pour reconstruire le texte clair du message lui-même, veuillez donc vous assurer que l'index des messages de notmuch est adéquatement protégé. N'UTILISEZ PAS --decrypt=vrai ou --decrypt=nostash sans considérer la sécurité de votre index.

Voir également index.decrypt dans notmuch-config.

EXEMPLES

Un utilisateur vient de recevoir un message chiffré sans indexer son texte clair. Après l'avoir lu (via notmuch show --decrypt=vrai), il décide qu'il souhaite indexer son texte clair afin de pouvoir le retrouver facilement plus tard et le lire sans avoir accès à ses clés secrètes :

notmuch reindex --decrypt=vrai id:1234567@example.com

Un utilisateur souhaite modifier sa politique à l'avenir pour commencer à indexer le texte clair. Mais il souhaite également un accès indexé au texte clair de tous les messages précédemment reçus. Certains messages ont peut-être déjà été indexés en clair (comme dans l'exemple ci-dessus). Il peut demander à notmuch de simplement réindexer les messages non encore indexés :

notmuch config set index.decrypt faux
notmuch reindex property:index.decryption=success
notmuch compact
