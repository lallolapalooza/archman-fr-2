DESCRIPTION

Les cellules constituent le framebuffer associé à chaque plan, avec une cellule par coordonnée adressable. Vous n'avez généralement pas besoin d'interagir directement avec les nccells.

Chaque nccell contient exactement un cluster de graphèmes étendu. Si le EGC est encodé en UTF-8 avec quatre octets ou moins (tous les points de code Unicode depuis Unicode 13 peuvent être encodés en quatre octets UTF-8 au maximum), il est encodé directement dans le champ gcluster du nccell, et aucun stockage supplémentaire n'est nécessaire. Sinon, le EGC est stocké sous forme de chaîne UTF-8 terminée par un nul dans un certain egcpool de support. Les egcpools sont associés aux ncplanes, donc les nccells doivent être considérés comme associés aux ncplanes. En effet, ncplane_erase détruit le stockage de support pour toutes les cellules d'un plan, les invalidant. Cette association est formée au moment de nccell_load, nccell_prime, ou nccell_duplicate. Toutes ces fonctions appellent d'abord nccell_release, tout comme nccell_load_egc32, nccell_load_char, et nccell_load_ucs32. Lorsque vous avez terminé d'utiliser un nccell, appelez nccell_release. ncplane_destroy libérera la mémoire utilisée par le nccell, mais l'egcpool de support a une taille maximale de 16 Mio, et l'échec de la libération des nccells peut éventuellement bloquer de nouvelles sorties. Écrire sur les cellules d'un ncplane les libère automatiquement.

nccell_extended_gcluster fournit un handle terminé par un nul vers le EGC. Celui-ci doit être considéré comme invalidé par des modifications du nccell ou de l'egcpool. Le handle n'est pas alloué sur le tas ; n'essayez pas de le free(3). Une copie allouée sur le tas peut être obtenue avec nccell_strdup.

ncstrwidth_valid retourne le nombre de colonnes occupées par une chaîne UTF-8 valide, ou -1 si une erreur est rencontrée. Dans les deux cas, le nombre d'octets et de colonnes valides, respectivement, consommés avant l'erreur, est placé dans validbytes et validwidth (en supposant qu'ils ne soient pas NULL).

nccell_fg_palindex extrait l'index de palette du canal de premier plan d'une cellule. Le canal doit être palet

DESCRIPTION

A nccell_t represents a single cell of output. It contains a graphical character (the EGC), and a foreground and background channel. The channel is a structure containing color and style information. This man page covers the manipulation of nccell_t objects.

Colors can be specified in one of three ways: palette-indexed, RGB8, or the default. The default is a special value, distinct from any palette index or RGB8 value. A palette index refers to a color in the current palette. RGB8 specifies a color using 8 bits each of red, green, and blue.

The functions beginning with nccell_set_fg_ operate on the foreground channel, and those beginning with nccell_set_bg_ operate on the background channel. The functions returning a value operate on the channel specified by the name, and those taking two nccell_t* arguments perform a copy from the second to the first. Replace fg with bg to operate on the background channel. All functions operating on channels return 0 on success and -1 on failure. For RGB8 colors, the values must be in the range [0, 255].

Palette indices must be less than NCPALETTESIZE. The functions nccell_fg_palindex and nccell_bg_palindex return the palette index for the foreground and background channels, respectively. If the channel is not palette-indexed, the return value is meaningless. Verify palette indexing with nccell_fg_palindex. A cell's foreground channel can be set to palette-indexed mode (and have the index set) with nccell_set_fg_palindex. The index must be less than NCPALETTESIZE. Replace fg with bg to operate on the background channel.

RETURN VALUES

nccell_load and similar functions return the number of bytes loaded from the EGC, or -1 on failure. They can fail due to either an invalid UTF-8 input, or the backing egcpool reaching its maximum size.

nccell_set_fg_rgb8 and similar functions will return -1 if provided invalid inputs, and 0 otherwise.

nccellcmp returns a negative integer, 0, or a positive integer if c1 is less than, equal to, or more than c2, respectively.

nccell_extended_gcluster returns NULL if called on a sprixel (see notcurses_visual(3).

nccell_cols returns the number of columns occupied by c, according to wcwidth(3)*. ncstrwidth is an equivalent for strings. ncstrwidth_valid returns the same value as ncstrwidth.

NOTES

cell was renamed to nccell in Notcurses 2.2.0, so as not to bleed such a common term into the (single, global) C namespace. cell will be retained as an alias until Notcurses 3.0. Likewise, many functions prefixed with cell have been renamed to start with nccell.
