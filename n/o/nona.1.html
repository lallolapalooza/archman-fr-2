NOM

nona - Assembler une image panoramique

SYNOPIS

nona [options] -o sortie fichier_projet (fichiers images)

DESCRIPTION

nona utilise la fonction de transformation de PanoTools, l'assemblage lui-même est assez simple, aucun mélange de bords n'est effectué.

Seuls les interpolateurs sans anticrénelage de PanoTools sont supportés.

Les formats de sortie suivants (option n de la ligne de script p de PanoTools) sont supportés :

JPEG, TIFF, PNG : Formats d'image unique sans mélange de bords
JPEG_m, TIFF_m, PNG_m : fichiers tiff multiples
TIFF_multilayer : Fichiers tiff multi-calques, lisibles par The Gimp 2.0

OPTIONS

Options générales :

-c
Créer des images de coordonnées (uniquement pour la sortie TIFF_m)
-v
Silencieux, ne pas afficher les indicateurs de progression
-d
Afficher des informations détaillées pour le traitement GPU
-g
Effectuer le remappage de l'image sur le GPU

Les options suivantes peuvent être utilisées pour remplacer les paramètres du fichier projet :

-i num
Remapper uniquement l'image avec le numéro num (peut être spécifié plusieurs fois)
-m str
Définir le format du fichier de sortie (TIFF, TIFF_m, TIFF_multilayer, EXR, EXR_m, JPEG, JPEG_m, PNG, PNG_m)
-r ldr/hdr
Définir le mode de sortie :
ldr - conserver la profondeur de bits et la réponse d'origine
hdr - fusionner en hdr
-e exposition
Définir l'exposition pour le mode ldr
-p TYPE
Type de pixel de la sortie. Peut être l'un des suivants :
UINT8 entier non signé 8 bits
UINT16 entier non signé 16 bits
INT16 entier signé 16 bits
UINT32 entier non signé 32 bits
INT32 entier signé 32 bits
FLOAT virgule flottante 32 bits
-z|--compression
Définir le type de compression. Options possibles pour la sortie tiff :
NONE aucune compression
PACKBITS compression packbits
LZW compression LZW
DEFLATE compression deflate
Pour la sortie JPEG, définir le numéro de qualité
--ignore-exposure
Ne pas corriger l'exposition. (Cela ne fonctionne pas avec le commutateur -e)
--save-intermediate-images
Sauvegarde également les images intermédiaires (uniquement lorsque la sortie est TIFF, PNG ou JPEG)
--intermediate-suffix=SUFFIX
Suffixe pour les images intermédiaires
--create-exposure-layers
Créer toutes les couches d'exposition (cela utilisera toujours TIFF)
--clip-exposure[=seuil inférieur:seuil supérieur]
Masquer automatiquement tous les pixels sombres et lumineux. Optionnellement, vous pouvez spécifier les limites pour le seuil inférieur et supérieur (spécifier dans la plage 0...1, par rapport à la plage complète)
