NOM

notmuch-emacs-mua - envoyer des e-mails avec notmuch et emacs

SYNTAXE

notmuch emacs-mua [options ...] [<adresse-destinataire> ... | <url-mailto>]

DESCRIPTION

Lance la composition d'un e-mail dans l'interface Emacs de Notmuch avec le sujet, les destinataires et le corps du message spécifiés, ou une URL mailto:.

Les options prises en charge pour emacs-mua incluent :

-h, --help
Affiche l'aide.
-s, --subject=<sujet>
Spécifie le sujet du message.
--to=<adresse-destinataire>
Spécifie un destinataire (À).
-c, --cc=<adresse-cc>
Spécifie un destinataire en copie carbone (Cc).
-b, --bcc=<adresse-cci>
Spécifie un destinataire en copie carbone invisible (Cci).
-i, --body=<fichier>
Spécifie un fichier à inclure dans le corps du message.
--hello
Aller à l'écran d'accueil Notmuch au lieu de la fenêtre de composition si aucun paramètre de composition de message n'est donné.
--no-window-system
Même si un système graphique est disponible, utiliser le terminal actuel.
--client
Utiliser emacsclient(1), plutôt que emacs(1). Pour que emacsclient(1) fonctionne, vous avez besoin d'un Emacs déjà en cours d'exécution avec un serveur, ou utilisez --auto-daemon.
--auto-daemon
Démarrer automatiquement Emacs en mode démon si le serveur Emacs n'est pas en cours d'exécution. Applicable avec --client. Implique --create-frame.
--create-frame
Créer une nouvelle fenêtre (frame) au lieu d'essayer d'utiliser la fenêtre Emacs actuelle. Applicable avec --client. Ceci sera nécessaire si Emacs est en cours d'exécution (ou démarré automatiquement avec --auto-daemon) en mode démon.
--print
Afficher le code elisp résultant sur stdout au lieu de l'évaluer.

Les options peuvent être spécifiées plusieurs fois.

VARIABLES D'ENVIRONNEMENT

EMACS
Nom de la commande emacs à invoquer. Par défaut, c'est "emacs".
EMACSCLIENT
Nom de la commande emacsclient à invoquer. Par défaut, c'est "emacsclient".
