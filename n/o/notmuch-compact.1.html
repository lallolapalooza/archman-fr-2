NOM

notmuch-compact - compacter la base de données notmuch

SYNOPIS

notmuch compact [--quiet] [--backup=<répertoire>]

DESCRIPTION

La commande compact peut être utilisée pour compacter la base de données notmuch. Cela peut réduire l'espace requis par la base de données et améliorer les performances de recherche.

La base de données compactée est construite dans un répertoire temporaire et est ensuite déplacée à la place de la base de données d'origine. La base de données non compactée d'origine est supprimée, sauf si l'option --backup=<répertoire> est utilisée.

Notez que le verrou d'écriture de la base de données sera détenu pendant le processus de compactage (qui peut être assez long) pour protéger l'intégrité des données.

Les options prises en charge pour compact incluent

--backup=<répertoire>
Sauvegarder la base de données actuelle dans le répertoire spécifié avant de la remplacer par la base de données compactée. Le répertoire de sauvegarde ne doit pas exister et il doit résider sur le même système de fichiers monté que la base de données actuelle.
--quiet
Ne pas signaler la progression du compactage de la base de données sur la sortie standard.
