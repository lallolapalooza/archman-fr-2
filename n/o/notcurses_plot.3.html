Paquet: notcurses

notcurses_plot(3) Manuel des fonctions de bibliothèque notcurses_plot(3)

NOM

notcurses_plot - widget de haut niveau pour le traçage

SYNOPSIS

#include <notcurses/notcurses.h>

#define NCPLOT_OPTION_LABELTICKSD   0x0001u
#define NCPLOT_OPTION_EXPONENTIALD  0x0002u
#define NCPLOT_OPTION_VERTICALI     0x0004u
#define NCPLOT_OPTION_NODEGRADE     0x0008u
#define NCPLOT_OPTION_DETECTMAXONLY 0x0010u
#define NCPLOT_OPTION_PRINTSAMPLE   0x0020u
typedef struct ncplot_options {
  // canaux pour les niveaux maximum et minimum.
  // interpolation linéaire entre ces deux valeurs.
  uint64_t maxchannels;
  uint64_t minchannels;
  // style utilisé pour les étiquettes (NCPLOT_OPTION_LABELTICKSD)
  uint16_t legendstyle;
  // passer NCBLIT_DEFAULT correspond à NCBLIT_8x1 (en supposant
  // UTF8) ou NCBLIT_1x1 (dans un environnement ASCII)
  ncblitter_e gridtype;
  // la variable indépendante peut être une plage contiguë,
  // ou un ensemble fini de clés. pour une plage de temps, disons l'heure
  // précédente échantillonnée à la résolution de la seconde, la
  // variable indépendante serait la plage [0..3600) : 3600.
  // si rangex est 0, il est défini dynamiquement sur le nombre
  // de colonnes.
  int rangex;
  const char* title;   // titre optionnel
  uint64_t flags;      // champ de bits sur NCPLOT_OPTION_*
} ncplot_options;

struct ncuplot* ncuplot_create(struct ncplane* n, const ncplot_options* opts, uint64_t miny, uint64_t maxy);

struct ncdplot* ncdplot_create(struct ncplane* n, const ncplot_options* opts, double miny, double maxy);

struct ncplane* ncuplot_plane(struct ncuplot* n);

struct ncplane* ncdplot_plane(struct ncdplot* n);

int ncuplot_add_sample(struct ncuplot* n, uint64_t x, uint64_t y);

int ncdplot_add_sample(struct ncdplot* n, uint64_t x, double y);

int ncuplot_set_sample(struct ncuplot* n, uint64_t x, uint64_t y);

int ncdplot_set_sample(struct ncdplot* n, uint64_t x, double y);

int ncuplot_sample(const struct ncuplot* n, uint64_t x, uint64_t* y);

int ncdplot_sample(const struct ncdplot* n, uint64_t x, double* y);

void ncuplot_destroy(struct ncuplot* n);

void ncdplot_destroy(struct ncdplot* n);

DESCRIPTION

Ces fonctions prennent en charge les histogrammes. La variable indépendante est toujours un uint64_t. Les échantillons sont soit des uint64_t (ncuplot), soit des double (ncdplot). Seule une fenêtre sur les échantillons est conservée à tout moment, et cette fenêtre ne peut que se déplacer vers des valeurs plus grandes de la variable indépendante. La fenêtre est déplacée vers l'avant chaque fois qu'un x supérieur au maximum actuel de la fenêtre est fourni à add_sample ou set_sample.

add_sample incrémente la valeur actuelle correspondant à cet x de y. set_sample remplace la valeur actuelle correspondant à cet x.

Si rangex est 0, ou plus grand que le plan lié ne peut supporter, il est plafonné à l'espace disponible. Le domaine peut être spécifié par miny et maxy, ou la détection automatique du domaine peut être activée en définissant les deux à 0. Si le domaine est spécifié, les échantillons en dehors du domaine constituent une erreur et ne contribuent pas au tracé. Fournir un x inférieur à la fenêtre actuelle constitue une erreur et n'a aucun effet.

Des glyphes de bloc plus granulaires signifient une plus grande résolution dans vos graphiques, mais ils peuvent être difficiles à différencier à de petites tailles de texte. Les octants, sextants et le Braille permettent plus de résolution sur la variable indépendante. Il peut être difficile de prédire comment les glyphes Braille apparaîtront dans une police donnée.

La même structure ncplot_options peut être utilisée avec tous les types ncplot. Le champ flags est un masque de bits composé de :

•
NCPLOT_OPTION_LABELTICKSD : Étiqueter les graduations de l'axe dépendant
•
NCPLOT_OPTION_EXPONENTIALD : Utiliser un axe dépendant exponentiel
•
NCPLOT_OPTION_VERTICALI : Axe indépendant vertical
•
NCPLOT_OPTION_NODEGRADE : Échouer plutôt que de dégrader le blitter
•
NCPLOT_OPTION_DETECTMAXONLY : Détecter uniquement le domaine maximum, pas le minimum
•
NCPLOT_OPTION_PRINTSAMPLE : Afficher l'échantillon le plus récent

Si NCPLOT_OPTION_LABELTICKSD ou NCPLOT_OPTION_PRINTSAMPLE est fourni, le champ legendstyle sera utilisé pour styliser les étiquettes. Il est sinon ignoré.

L' étiquette est imprimée en haut à gauche, immédiatement à droite de la graduation de l'axe la plus haute (si NCPLOT_OPTION_LABELTICKSD a été utilisé). L'échantillon le plus récent est imprimé en face de l'étiquette le long de l'axe indépendant (si NCPLOT_OPTION_PRINTSAMPLE a été utilisé).

NOTES

NCPLOT_OPTION_VERTICALI n'est pas encore implémenté.

VALEURS DE RETOUR

create renverra une erreur si miny est égal à maxy, mais qu'ils sont non nuls. Il renverra également une erreur si maxy < miny. Un gridtype invalide entraînera une erreur.

plane renvoie le ncplane sur lequel le graphique est dessiné. Cela ne peut pas échouer.
