NOM

notmuch - indexation, recherche et marquage d'e-mails par fil de discussion

SYNTAXE

notmuch [option ...] commande [arg ...]

DESCRIPTION

Notmuch est un programme en ligne de commande pour indexer, rechercher, lire et marquer de grandes collections de messages électroniques.

Cette page décrit comment commencer à utiliser notmuch en ligne de commande et donne un bref aperçu des commandes disponibles. Pour plus d'informations sur par exemple notmuch show, consultez la page de manuel notmuch-show, également accessible via notmuch help show

La manière la plus rapide de commencer avec Notmuch est d'invoquer simplement la commande notmuch sans aucun argument, ce qui vous guidera interactivement à travers le processus d'indexation de vos e-mails.

NOTE

OPTIONS

Les options globales prises en charge pour notmuch incluent

--help [nom-de-commande]
Affiche une synthèse des commandes disponibles et quitte. Avec un nom de commande optionnel, affiche la page de manuel de cette sous-commande.
--version
Affiche la version installée de notmuch et quitte.
--config=FICHIER
Spécifie le fichier de configuration à utiliser. Cela remplace tout fichier de configuration spécifié par NOTMUCH_CONFIG. La chaîne vide est une valeur permise et parfois utile pour FICHIER, ce qui indique à notmuch d'utiliser uniquement les métadonnées de configuration de la base de données.
--uuid=HEX
Force le UUID de la base de données (un identifiant unique qui persiste jusqu'à ce que la base de données soit compactée, par exemple) à être HEX ; quitte avec une erreur si ce n'est pas le cas. Ceci est utile pour détecter le basculement des décomptes de modifications sur les messages. Vous pouvez trouver ce UUID en utilisant par exemple notmuch count --lastmod

Toutes les options globales sauf --config peuvent également être spécifiées après la commande. Par exemple, notmuch subcommand --uuid=HEX est équivalent à notmuch --uuid=HEX subcommand.

COMMANDES

CONFIGURATION

La commande notmuch setup est utilisée pour configurer Notmuch pour la première utilisation, (ou pour le reconfigurer plus tard).

La commande de configuration vous demandera votre nom complet, votre adresse e-mail principale, toute adresse e-mail alternative que vous utilisez et le répertoire contenant vos archives d'e-mails. Vos réponses seront écrites dans un fichier de configuration dans NOTMUCH_CONFIG (si défini) ou dans ${HOME}/.notmuch-config. Ce fichier de configuration sera créé avec des commentaires descriptifs, le rendant facile à modifier manuellement plus tard pour changer la configuration. Ou vous pouvez exécuter à nouveau notmuch setup pour modifier la configuration.

Le répertoire de courrier que vous spécifiez peut contenir n'importe quel nombre de sous-répertoires et devrait principalement contenir uniquement des fichiers avec des messages e-mail individuels (par exemple, des archives maildir ou mh sont parfaites). S'il y a d'autres fichiers non-e-mail (tels que des index maintenus par d'autres programmes de messagerie), notmuch fera de son mieux pour les détecter et les ignorer.

L'invocation de notmuch sans argument de commande exécutera setup si la commande de configuration n'a pas été complétée précédemment.

AUTRES COMMANDES

Plusieurs des commandes notmuch acceptent des termes de recherche avec une syntaxe commune. Voir notmuch-search-terms pour plus de détails sur la syntaxe prise en charge.

Les commandes notmuch-search, notmuch-show, notmuch-address et notmuch-count sont utilisées pour interroger la base de données d'e-mails.

La commande notmuch-reply est utile pour préparer un modèle de réponse d'e-mail.

La commande notmuch-tag est la seule commande disponible pour manipuler le contenu de la base de données.

Les commandes notmuch-dump et notmuch-restore peuvent être utilisées pour créer une sauvegarde textuelle des étiquettes d'e-mails à des fins de sauvegarde, et pour restaurer à partir de cette sauvegarde.

La commande notmuch-config peut être utilisée pour obtenir ou définir des paramètres dans le fichier de configuration notmuch.

COMMANDES EXTERNES

Si la commande donnée n'est pas reconnue par notmuch, notmuch essaie d'exécuter la commande externe notmuch-<sous-commande> dans PATH à la place. Cela permet aux utilisateurs d'avoir leurs propres outils liés à notmuch à exécuter via la commande notmuch. Par conception, cela ne permet pas de remplacer les propres commandes de notmuch à l'aide de commandes externes. La variable d'environnement NOTMUCH_CONFIG sera définie en fonction de --config, si cette dernière est présente.

ENVIRONNEMENT

Les variables d'environnement suivantes peuvent être utilisées pour contrôler le comportement de notmuch.

NOTMUCH_CONFIG
Spécifie l'emplacement du fichier de configuration notmuch. Voir notmuch-config pour les détails.
NOTMUCH_DATABASE
Spécifie l'emplacement de la base de données notmuch. Voir notmuch-config pour les détails.
NOTMUCH_PROFILE
Sélectionne parmi les configurations notmuch. Voir notmuch-config pour les détails.
NOTMUCH_TALLOC_REPORT
Emplacement où écrire un rapport d'utilisation de la mémoire talloc. Voir talloc_enable_leak_report_full dans talloc(3) pour plus d'informations.
NOTMUCH_DEBUG_QUERY
Si défini à une valeur non vide, la bibliothèque notmuch imprimera (sur stderr) les requêtes Xapian qu'elle construit.
