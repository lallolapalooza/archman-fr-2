NOM

noof - dessine des motifs rotatifs

SYNTAXE

dangerball [--display hôte:écran.numéro] [--visual visuel] [--window] [--root] [--window-id numéro] [--delay numéro] [--fps]

DESCRIPTION

Dessine quelques motifs rotatifs, en utilisant OpenGL.

OPTIONS

--visual visuel
Spécifie quel visuel utiliser. Les valeurs légales sont le nom d'une classe de visuel, ou l'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--window
Dessiner dans une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--delay numéro
Délai par image, en microsecondes. Par défaut : 10000 (0.01 secondes).
--fps
Afficher la fréquence d'images actuelle, la charge CPU et le nombre de polygones.

ENVIRONNEMENT

DISPLAY
pour obtenir le nom d'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de la fenêtre à utiliser avec --root.

VOIR AUSSI

X(1), xscreensaver(1)
