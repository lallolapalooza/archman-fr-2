notcurses_util(3) Manuel des fonctions de bibliothèque notcurses_util(3)

NOM

notcurses_util - fonctions utilitaires portables

SYNTAXE

#include <notcurses/notcurses.h>

char* notcurses_accountname(void);

char* notcurses_hostname(void);

char* notcurses_osversion(void);

DESCRIPTION

Notcurses fournit quelques fonctions utilitaires, généralement pour abstraire les différences dépendantes de la plateforme.

notcurses_accountname retourne une copie allouée sur le tas du nom du compte sous lequel le programme s'exécute. notcurses_hostname retourne une copie allouée sur le tas du nom d'hôte local. notcurses_osversion retourne une représentation lisible par l'homme, allouée sur le tas, du système d'exploitation et de sa version.

NOTES

VALEURS DE RETOUR

Toutes les fonctions retournent NULL en cas d'erreur.

VOIR AUSSI

hostname(1), notcurses(3)
