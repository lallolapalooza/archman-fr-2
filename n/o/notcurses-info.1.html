notcurses-info(1) Manuel des commandes générales notcurses-info(1)

NOM

notcurses-info - Affiche des informations sur l'environnement du terminal

SYNTAXE

notcurses-info [-v]

DESCRIPTION

notcurses-info affiche toutes les informations qu'il connaît sur l'environnement du terminal actuel, y compris le matériel chargé depuis terminfo(5) (basé sur la variable d'environnement TERM), les réponses du terminal à nos requêtes, et les heuristiques intégrées.

Les glyphes Unicode demi-bloc, quadrant, sextant, octant et Braille sont tous inclus dans la sortie. Si leur apparence est irrégulière, il pourrait être judicieux de choisir une autre police.

Les cinq premières lignes (la bannière d'initialisation Notcurses ; voir notcurses_init(3)) fournissent :

•
La version de Notcurses et le nom dérivé du terminal, pouvant inclure la version du terminal. Si Notcurses a pu interroger sans ambiguïté le terminal connecté, le nom interne du terminal sera affiché. Sinon, le terminal décrit par la variable d'environnement TERM sera affiché. La version du terminal n'est acquise que par interrogation.
•
La géométrie de cellule actuelle, la géométrie cellule-pixel, et la géométrie fenêtre-pixel dérivée, la taille de la structure crender, le nombre de couleurs dans la palette, et si TrueColor RVB est pris en charge.
•
Le nom et la version du compilateur utilisés pour construire Notcurses, la taille de la structure nccell, et l'endianness avec lequel Notcurses a été compilé. Cet endianness à la compilation doit correspondre à l'endianness à l'exécution.
•
La version de libterminfo par rapport à laquelle Notcurses a été compilé.
•
La version et le nom du backend multimédia.

Les cinq lignes suivantes décrivent les propriétés de l'environnement du terminal :

•
La première ligne indique qu'une capacité donnée est présente avec un signe plus ('+') ou non présente/détectée avec un signe moins ('-') :
•
af : La couleur de premier plan peut être définie
•
ab : La couleur d'arrière-plan peut être définie
•
sum : Le mode de mise à jour synchronisée est pris en charge
•
vpa : Le curseur peut être déplacé vers une coordonnée verticale absolue
•
hpa : Le curseur peut être déplacé vers une coordonnée horizontale absolue
•
sgr0 : Le style peut être réinitialisé via une seule échappée
•
op : Les couleurs peuvent être réinitialisées via une seule échappée
•
fgop : Le premier plan peut être réinitialisé via une seule échappée
•
bgop : L'arrière-plan peut être réinitialisé via une seule échappée
•
bce : La propriété d'effacement de la couleur d'arrière-plan est en jeu
•
rect : L'édition rectangulaire est disponible
•
La deuxième ligne est plus de la même chose :
•
bold : Le gras est disponible
•
ital : L'italique est disponible
•
struck : Le barré est disponible
•
ucurl : Les soulignements bouclés sont disponibles
•
uline : Les soulignements droits sont disponibles
•
u7 : Rapports de position du curseur
•
ccc : La palette peut être reprogrammée
•
rgb : Les couleurs peuvent être spécifiées en RVB avec huit bits par canal
•
el : L'effacement peut être effectué jusqu'à la fin de la ligne
•
La troisième ligne couvre également les capacités UTF8 et de décodage :
•
utf8 : C'est un environnement UTF8
•
2x1 : Les demi-blocs supérieurs et inférieurs sont disponibles
•
2x2 : Les blocs quadrants sont disponibles
•
3x2 : Les blocs sextants sont disponibles
•
4x2 : Les blocs octants sont disponibles
•
4x2 : Les caractères Braille sont disponibles
•
img : Les images peuvent être décodées
•
vid : La vidéo peut être décodée
•
indn : Le défilement sur plusieurs lignes est disponible
•
gpm : La connexion au serveur GPM est établie
•
kbd : Le protocole de clavier Kitty est utilisé
•
La quatrième ligne indique la couleur d'arrière-plan par défaut, et si cette couleur est traitée comme transparente par le terminal (seul kitty est connu pour faire cela), et la couleur de premier plan par défaut. pmouse indique si les événements de souris précis en pixels sont pris en charge.
•
La cinquième ligne décrit les graphiques bitmap disponibles. Si les Sixels sont disponibles, le nombre maximum de registres de couleur et la géométrie Sixel maximale sont rapportés. Si les graphiques du framebuffer Linux sont disponibles, cela est rapporté. Si le protocole graphique Kitty est détecté, cela sera rapporté avec « rgba graphics are available » ; si le support d'animation de Kitty est également présent, cela sera rapporté avec « rgba pixel animation support ».

À droite de ce matériel se trouve l'URI de la page d'accueil de Notcurses, et le logo Notcurses (ce dernier uniquement si des graphiques bitmap sont disponibles).

Les onze dernières lignes, imprimées uniquement dans une locale UTF8, affichent divers glyphes Unicode. Les quatre premières lignes incluent les caractères quadrants, sextants, octants et de dessin de boîtes. Les quatre lignes suivantes incluent l'ensemble des caractères Braille. Les deux lignes suivantes incluent de nombreux Symboles pour l'Informatique Héritée introduits dans Unicode 13. La dernière ligne inclut de nombreux émojis.

OPTIONS

-v : Être verbeux.

NOTES

Le comportement de notcurses-info (et en fait de tout Notcurses) dépend des variables d'environnement TERM et LANG, des locales POSIX installées et des bases de données terminfo(5) installées.

VOIR AUSSI

tack(1), notcurses(3), terminfo(5)
