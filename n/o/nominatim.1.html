NOM

nominatim

SYNOPSIS

nominatim [-h] [--version] {import,freeze,replication,special-phrases,add-data,index,refresh,admin,export,convert,serve,search,reverse,lookup,details,status} ...

DESCRIPTION

Outils en ligne de commande pour importer, mettre à jour, administrer et interroger la base de données Nominatim.

sys.args sera utilisé.

Configuration de Nominatim. Lorsque None, l'environnement os.environ est hérité.

OPTIONS

--version
Affiche la version de Nominatim et quitte

COMMANDES DISPONIBLES

nominatim import
Crée une nouvelle base de données Nominatim à partir d'un fichier OSM.
nominatim freeze
Rend la base de données en lecture seule.
nominatim replication
Met à jour la base de données en utilisant un service de réplication en ligne.
nominatim special-phrases
Importe des phrases spéciales.
nominatim add-data
Ajoute des données supplémentaires à partir d'un fichier ou d'une source en ligne.
nominatim index
Réindexe toutes les données nouvelles et modifiées.
nominatim refresh
Recalcule les données auxiliaires utilisées par le processus d'indexation.
nominatim admin
Analyse et maintient la base de données.
nominatim export
Exporte les lieux sous forme de fichier CSV depuis la base de données.
nominatim convert
Convertit une base de données existante dans un format différent. (EXPÉRIMENTAL)
nominatim serve
Démarre un serveur web simple pour servir l'API.
nominatim search
Exécute une requête de recherche.
nominatim reverse
Exécute une requête inversée de l'API.
nominatim lookup
Exécute une requête de recherche de l'API.
nominatim details
Exécute une requête de détails de l'API.
nominatim status

COMMANDE 'nominatim freeze'

usage: nominatim freeze [-h] [-q] [-v] [--project-dir DIR] [-j NUM]

Rend la base de données en lecture seule.

Environ la moitié des données de la base de données Nominatim sont conservées uniquement pour permettre la mise à jour des données avec les nouveaux changements apportés dans OpenStreetMap. Cette commande supprime toutes ces données et ne conserve que la partie nécessaire à la géocodification elle-même.

Cette commande a le même effet que l'option `--no-updates` lors des importations.

COMMANDE 'nominatim replication'

usage: nominatim replication [-h] [-q] [-v] [--project-dir DIR] [-j NUM]
[--init] [--no-update-functions]
[--check-for-updates] [--once] [--catch-up]
[--no-index] [--osm2pgsql-cache TAILLE]
[--socket-timeout DELAI_CONNEXION]

Met à jour la base de données en utilisant un service de réplication en ligne.

Un service de réplication OSM est

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

une service en ligne qui fournit des mises à jour régulières (fichiers de diff OSM) pour la planète ou les mises à jour qu'ils fournissent. L'OSMF fournit le service de réplication principal pour la planète entière à https://planet.osm.org/replication/ mais d'autres fournisseurs d'extraits de données OSM proposent également un tel service.

Cette sous-commande permet de configurer un tel service de réplication et de télécharger et d'importer les mises à jour à intervalles réguliers. Vous devez appeler '--init' une fois pour configurer le processus ou chaque fois que vous modifiez les paramètres de configuration de la réplication. Sans aucun argument, la sous-commande entrera dans une boucle et appliquera continuellement les mises à jour dès qu'elles seront disponibles. Donner `--once` ne fait que télécharger et importer le prochain lot de mises à jour.

COMMANDE 'nominatim special-phrases'

usage : nominatim special-phrases [-h] [-q] [-v] [--project-dir DIR] [-j NUM]
[--import-from-wiki] [--import-from-csv FILE]
[--no-replace] [--min MIN]

Importer des phrases spéciales.

Les phrases spéciales sont des termes de recherche qui affinent le type d'objet recherché. Par exemple, vous pourriez vouloir rechercher dans de nombreuses langues, ce qui peut être importé avec cette commande.

Vous pouvez également fournir vos propres phrases dans un fichier CSV. Le fichier doit comporter les cinq colonnes suivantes :
* phrase - le terme attendu pour la recherche
* class - la clé de balise OSM du type d'objet
* type - la valeur de balise OSM du type d'objet
* operator - le type de recherche à effectuer (l'un des suivants : in, near, name, -)
* plural - si le terme est au pluriel ou non (O/N)

Un exemple de fichier se trouve dans les sources de Nominatim à

L'importation peut être davantage configurée pour ignorer des paires clé/valeur spécifiques. Ceci est particulièrement utile lors de l'importation de phrases depuis le wiki. La configuration par défaut exclut certaines balises très courantes comme `building=yes`. La configuration peut être personnalisée en plaçant un fichier `phrase-settings.json` avec des règles personnalisées dans le répertoire du projet ou en utilisant l'option `--config` pour pointer vers un autre fichier de configuration.

ARGUMENTS PAR DÉFAUT 'nominatim special-phrases'

-q, --quiet
Afficher uniquement les messages d'erreur
-v, --verbose
Augmenter la verbosité de la sortie
--project-dir DIR
Répertoire de base de l'installation Nominatim (par défaut : /var/lib/nominatim/)
-j NUM, --threads NUM
Nombre de threads parallèles à utiliser

ARGUMENTS D'ENTRÉE 'nominatim special-phrases'

--import-from-wiki
Importer des phrases spéciales du wiki OSM dans la base de données
--import-from-csv FILE
Importer des phrases spéciales à partir d'un fichier CSV
--no-replace

--min MIN
Restreindre les phrases spéciales par occurrence minimale

COMMANDE 'nominatim add-data'

usage : nominatim add-data [-h] [-q] [-v] [--project-dir DIR] [-j NUM]
(--file FILE | --diff FILE | --node ID | --way ID |
--relation ID | --tiger-data DIR) [--use-main-api]
[--osm2pgsql-cache SIZE]
[--socket-timeout SOCKET_TIMEOUT]

Ajouter des données supplémentaires à partir d'un fichier ou d'une source en ligne.

Cette commande permet d'ajouter ou de mettre à jour les données de recherche dans la base de données. Les données peuvent provenir d'un fichier OSM ou des objets OSM individuels peuvent être directement téléchargés depuis l'API OSM. Cette fonction charge uniquement les données dans la base de données. Ensuite, elles doivent encore être intégrées dans l'index de recherche. Utilisez la commande `nominatim index` pour cela.

La commande peut également être utilisée pour ajouter des données externes non-OSM à la base de données. Actuellement, le seul format pris en charge est les données de numéros de maison TIGER. Voir la documentation en ligne à https://nominatim.org/release-docs/latest/customize/Tiger/ pour plus d'informations.

COMMANDE 'nominatim index'

usage : nominatim index [-h] [-q] [-v] [--project-dir DIR] [-j NUM]
[--boundaries-only] [--no-boundaries] [--minrank RANK]
[--maxrank RANK]

Réindexer toutes les données nouvelles et modifiées.

L'indexation est le processus de calcul de l'adresse et des termes de recherche pour les lieux de la base de données. Chaque fois que des données sont ajoutées ou modifiées, l'indexation doit être exécutée. Les importations et les mises à jour de réplication s'occupent automatiquement de l'indexation. Pour les autres cas, cette fonction permet d'exécuter l'indexation manuellement.

ARGUMENTS PAR DÉFAUT '

nominatim index'
-q, --quiet

-v, --verbose

Répertoire de base de l'installation de Nominatim (défaut : /var/lib/nominatim/)
-j NUM, --threads NUM
Nombre de threads parallèles à utiliser

ARGUMENTS DE FILTRE 'nominatim index'

--boundaries-only
Indexer uniquement les limites administratives.
--no-boundaries
Indexer tout sauf les limites administratives.
--minrank RANK, -r RANK
Rang minimum/de départ
--maxrank RANK, -R RANK
Rang maximum/de fin

--word-counts

COMMANDE 'nominatim serve'

[--server SERVER] [--engine {falcon,starlette}]

Démarrer un serveur web simple pour servir l'API.

Cette commande démarre un serveur web intégré pour servir le site web à partir du répertoire de projet actuel. Ce serveur web convient uniquement aux tests et au développement. Ne l'utilisez pas dans des configurations de production !

EXEMPLE

Pour rechercher des adresses pour la Tour Eiffel :

nominatim search --query "Tour Eiffel"

Pour trouver l'adresse correspondante aux coordonnées 48.8584, 2.2945 :

nominatim reverse --lat 48.8584 --lon 2.2945

Pour rechercher les détails de l'objet OSM avec l'ID way/12345 :

nominatim lookup --id way/12345

Pour rechercher les détails du nœud OSM avec l'ID 12345 :

nominatim details --node 12345
