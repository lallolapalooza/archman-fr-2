NOHUP(1) Commandes utilisateur NOHUP(1)

NOM

nohup - exécuter une commande insensible aux signaux de déconnexion, avec sortie vers un fichier non-tty

SYNTAXE

nohup COMMANDE [ARG]...
nohup OPTION

DESCRIPTION

Exécute COMMANDE, en ignorant les signaux de déconnexion.

--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter

Si l'entrée standard est un terminal, la rediriger depuis un fichier illisible. Si la sortie standard est un terminal, l'ajouter au fichier 'nohup.out' si possible, sinon à '$HOME/nohup.out'. Si la sortie d'erreur est un terminal, la rediriger vers la sortie standard. Pour sauvegarder la sortie dans FICHIER, utilisez 'nohup COMMANDE > FICHIER'.

Votre shell peut avoir sa propre version de nohup, qui remplace généralement la version décrite ici. Veuillez vous référer à la documentation de votre shell pour connaître les options qu'il prend en charge.

Statut de sortie :

125
si la commande nohup elle-même échoue
126
si COMMANDE est trouvée mais ne peut pas être invoquée
127
si COMMANDE ne peut pas être trouvée
-
le statut de sortie de COMMANDE sinon
