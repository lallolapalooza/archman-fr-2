NOM

notcurses-tester - Tests unitaires de Notcurses

SYNTAXE

notcurses-tester [-p datadir] [-lN]

DESCRIPTION

notcurses-tester exécute les plusieurs centaines de tests unitaires inclus avec Notcurses. Il nécessite plusieurs fichiers de données installés avec Notcurses ; si ceux-ci se trouvent à un emplacement irrégulier, fournissez -p.

OPTIONS

-p chemin : Rechercher dans le chemin spécifié les fichiers de données.

-lN : Activer les diagnostics/journalisation au niveau N. N doit être compris entre -1 et 7.

NOTES

Les variables d'environnement TERM et LANG valides sont nécessaires au bon fonctionnement de notcurses-tester.
