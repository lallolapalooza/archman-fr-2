NOM

notmuch-hooks - hooks pour notmuch

SYNTAXE

<hook_dir>/{pre-new, post-new, post-insert}

DESCRIPTION

Les hooks sont des scripts (ou des exécutables arbitraires ou des liens symboliques vers ceux-ci) que notmuch invoque avant et après certaines actions. Ces scripts résident dans un répertoire défini comme décrit dans notmuch-config. Ils doivent avoir les permissions d'exécution.

Les hooks actuellement disponibles sont décrits ci-dessous.

pre-new
Ce hook est invoqué par la commande notmuch-new avant de scanner ou d'importer de nouveaux messages dans la base de données. Si ce hook se termine avec un statut non nul, notmuch abandonnera le traitement ultérieur de la commande notmuch-new.

Généralement, ce hook est utilisé pour récupérer ou livrer de nouveaux e-mails à importer dans la base de données.

post-new
Ce hook est invoqué par la commande notmuch-new après que tout nouveau message a été importé dans la base de données et que les étiquettes initiales ont été appliquées. Le hook ne sera pas exécuté s'il y a eu des erreurs lors du scan ou de l'importation.

Généralement, ce hook est utilisé pour effectuer un étiquetage supplémentaire basé sur des requêtes sur les messages importés.

post-insert
Ce hook est invoqué par la commande notmuch-insert après que le message a été livré, ajouté à la base de données et que les étiquettes initiales ont été appliquées. Le hook ne sera pas exécuté s'il y a eu des erreurs lors de la livraison du message ; ce qui est considéré comme une livraison réussie dépend de l'option --keep.

Généralement, ce hook est utilisé pour effectuer un étiquetage supplémentaire basé sur des requêtes sur les messages livrés.
