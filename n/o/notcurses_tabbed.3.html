notcurses_tabbed – widget d'interface à onglets

SYNOPSIS

DESCRIPTION

Un nctabbed est un widget avec une zone d'affichage de données et une barre avec les noms des onglets. Sauf s'il n'y a pas d'onglets, exactement un onglet est "sélectionné" et exactement un onglet est "le plus à gauche". L'onglet sélectionné est celui qui contrôle le plan de contenu de l'onglet. L'onglet le plus à gauche est celui dont l'en-tête est visible le plus à gauche. N'importe quel onglet peut être déplacé vers et depuis n'importe où dans la liste. Les onglets peuvent être "rotatifs", ce qui signifie en réalité que l'onglet le plus à gauche est décalé. Le widget n'est dessiné que lorsque nctabbed_redraw ou ntabbed_create sont appelés.

MISE EN PAGE

Le widget a une liste d'onglets soit en haut, soit en bas, épaisse d'une ligne. La liste des onglets contient les en-têtes d'onglets (c'est-à-dire leurs noms), séparés par le séparateur spécifié dans nctabbed_create ou nctabbed_set_separator. Les canaux pour l'en-tête de l'onglet sélectionné, les autres en-têtes d'onglets et le séparateur peuvent être définis indépendamment les uns des autres. Le séparateur d'onglets peut avoir une longueur de 0, ou être NULL, auquel cas il n'y a pas de séparateur visible entre les en-têtes d'onglets. L'onglet sélectionné peut être rendu visible (en changeant l'onglet le plus à gauche) en appelant la fonction nommée très longuement nctabbed_ensure_selected_header_visible. Le reste du widget est un ncplane hébergeant le contenu de l'onglet sélectionné (le cas échéant).

LA FONCTION DE RAPPEL D'ONGLET

La fonction de rappel d'onglet (de type tabcb) prend un onglet, le plan de contenu de l'onglet et le pointeur opaque donné à nctabbed_add ou nctabbed_set_userptr. Elle est appelée lorsque le contenu de l'onglet doit être dessiné, c'est-à-dire lorsque le widget entier est redessiné. Elle doit dessiner le contenu de l'onglet et éventuellement effectuer d'autres actions, mais elle ne doit faire aucune supposition sur l'état actuel du plan de contenu de l'onglet, ni modifier l'état du widget ou de l'onglet.

VALEURS DE RETOUR

nctabbed_create retourne le widget nouvellement créé, ou NULL lorsque le widget n'a pas pu être créé. Cela détruit le ncplane qui lui est donné, même en cas d'échec.

nctabbed_selected et nctabbed_leftmost retournent les onglets sélectionné et le plus à gauche, respectivement. S'il n'y a pas d'onglets, ils retournent NULL.

nctab_name retourne le nom de l'onglet. Ce n'est pas une copie, et il ne doit pas être stocké, car il est libéré lorsque le nom de l'onglet est modifié ou que l'onglet est supprimé.

nctabbed_next, nctabbed_prev et nctabbed_select retournent le nouvel onglet sélectionné.

nctabbed_separator retourne le séparateur d'onglets. Ce n'est pas une copie, et il ne doit pas être stocké, car il est libéré lorsque le séparateur est modifié ou que le widget est supprimé.

Les fonctions retournant un int retournent -1 en cas d'échec.

VOIR AUSSI

notcurses(3), notcurses_channels(3), notcurses_plane(3)

NOM

notcurses_tabbed - structure des tables d'onglets

SYNTAXE

#include <notcurses/notcurses.h>

typedef struct ncplane_tabbed {
  ncplane_t *plane;
  int id;
  int focusedid;
  struct ncplane_tabbed *prev;
  struct ncplane_tabbed *next;
} ncplane_tabbed_t;

ncplane_tabbed_t *notcurses_tabbed_create(ncplane_t *parent, const void *opts);
int notcurses_tabbed_destroy(ncplane_tabbed_t *nt);
ncplane_t *notcurses_tabbed_plane(const ncplane_tabbed_t *nt);
int notcurses_tabbed_select(ncplane_tabbed_t *nt, int id);
int notcurses_tabbed_add(ncplane_tabbed_t *nt, int id, const char *name);
int notcurses_tabbed_remove(ncplane_tabbed_t *nt, int id);
int notcurses_tabbed_focus_set(ncplane_tabbed_t *nt, int id);
int notcurses_tabbed_focus_next(ncplane_tabbed_t *nt);
int notcurses_tabbed_focus_prev(ncplane_tabbed_t *nt);
int notcurses_tabbed_set_name(ncplane_tabbed_t *nt, int id, const char *name);
const char *notcurses_tabbed_get_name(ncplane_tabbed_t *nt, int id);
int notcurses_tabbed_get_focused_id(const ncplane_tabbed_t *nt);
const char *notcurses_tabbed_get_focused_name(const ncplane_tabbed_t *nt);
```

DESCRIPTION


La structure ncplane_tabbed_t est une table d'onglets. Un onglet est un plan ncplane_t identifié par un entier. Cet entier est appelé l'ID de l'onglet. Les plans d'onglets sont organisés en liste doublement chaînée. L'ID de l'onglet 0 est réservé au plan de l'onglet lui-même, et tous les autres IDs sont supposés être attribués par l'utilisateur. La nomenclature est un peu vague sur ce point, mais le comportement réel est le suivant : tous les plans d'onglets sont créés dans le même plan parent, et ils sont tous de même taille. La liste chaînée est chaînée dans l'ordre dans lequel les plans sont créés. Le plan parent est le plan dont le comportement sera celui de la table d'onglets.


notcurses_tabbed_create() crée une nouvelle table d'onglets dans le parent. Les opts ne sont pas actuellement utilisés. L'ID 0 est automatiquement attribué à la table d'onglets elle-même.


notcurses_tabbed_destroy() détruit une table d'onglets, libérant toutes les ressources associées. Notez que la destruction de la table d'onglets ne détruit pas le plan parent.


notcurses_tabbed_plane() renvoie le plan racine de la table d'onglets.


notcurses_tabbed_select() sélectionne l'onglet avec l'ID donné. Cela fait en sorte que le plan racine de la table d'onglets affiche l'onglet spécifié. La valeur renvoyée est 0 en cas de succès, et -1 en cas d'échec.


notcurses_tabbed_add() ajoute un nouvel onglet à la table d'onglets. L'onglet est identifié par id. Il est créé dans le parent et se voit attribuer un name. Tous les plans d'onglets ajoutés sont de la même taille que le plan parent. L'ID 0 est réservé à la table d'onglets elle-même. La valeur renvoyée est 0 en cas de succès, et -1 en cas d'échec.


notcurses_tabbed_remove() supprime un onglet de la table d'onglets. La valeur renvoyée est 0 en cas de succès, et -1 en cas d'échec.


notcurses_tabbed_focus_set() définit l'onglet actuellement sélectionné comme étant celui avec l'ID donné. La valeur renvoyée est 0 en cas de succès, et -1 en cas d'échec.


notcurses_tabbed_focus_next() déplace le focus vers l'onglet suivant dans la liste chaînée. La valeur renvoyée est 0 en cas de succès, et -1 en cas d'échec.


notcurses_tabbed_focus_prev() déplace le focus vers l'onglet précédent dans la liste chaînée. La valeur renvoyée est 0 en cas de succès, et -1 en cas d'échec.


notcurses_tabbed_set_name() définit le nom de l'onglet avec l'ID donné. La valeur renvoyée est 0 en cas de succès, et -1 en cas d'échec.


notcurses_tabbed_get_name() renvoie le nom de l'onglet avec l'ID donné.


notcurses_tabbed_get_focused_id() renvoie l'ID de l'onglet actuellement sélectionné.


notcurses_tabbed_get_focused_name() renvoie le nom de l'onglet actuellement sélectionné.


VALEURS DE RETOUR


Les fonctions renvoient 0 en cas de succès et -1 en cas d'échec.
