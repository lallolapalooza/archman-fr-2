NOM

notcurses-input - Lire et afficher les événements d'entrée

SYNTAXE

notcurses-input [-v] [-m]

DESCRIPTION

notcurses-input lit depuis l'entrée standard et décode les entrées vers la sortie standard, y compris les événements synthétisés et les événements de souris. Pour quitter, générer EOF (généralement Ctrl+'d').

Chaque événement sera imprimé sur une seule ligne. Devant cette ligne se trouve une série d'indicateurs de modificateurs :

•
'A'/'a' : Alt a été pressé ou non.
•
'C'/'c' : Ctrl a été pressé ou non.
•
'S'/'s' : Shift a été pressé ou non.
•
'U'/'u' : Super a été pressé ou non.
•
'M'/'m' : Meta a été pressé ou non.
•
'H'/'h' : Hyper a été pressé ou non.
•
'X'/'x' : Verrouillage majuscule (CapsLock) a été pressé ou non.
•
'#'/'.' : Verrouillage numérique (NumLock) a été pressé ou non.
•
'L'/'R'/'P'/'u' : Touche de relâchement, de répétition, d'appui, ou de type inconnu.

Par défaut, les événements de souris sont activés.

OPTIONS

-v : Augmenter la verbosité. -m : Inhiber les événements de souris.

NOTES

Les événements de souris ne sont générés que pour les appuis et relâchements de boutons, et pour les mouvements pendant qu'un bouton est maintenu enfoncé.
