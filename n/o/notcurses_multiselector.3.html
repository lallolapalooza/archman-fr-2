notcurses_multiselector(3) Manuel des fonctions de la bibliothèque notcurses_multiselector(3)

NOM

notcurses_multiselector - Widget de haut niveau pour la sélection parmi un ensemble

SYNTAXE

#include <notcurses/notcurses.h>

struct ncplane;
struct notcurses;
struct ncmultiselector;
struct ncmselector_item {
  const char* option;
  const char* desc;
};
typedef struct ncmultiselector_options {
  const char* title; // le titre peut être NULL, ce qui inhibe le rehausseur
  const char* secondary; // le secondaire peut être NULL
  const char* footer; // le pied de page peut être NULL
  struct ncmselector_item* items; // éléments initiaux, statuts
  // élément par défaut (sélectionné au démarrage)
  unsigned defidx;
  // nombre maximum d'options à afficher à la fois
  unsigned maxdisplay;
  // options de style exhaustives
  uint64_t opchannels;   // canaux d'options
  uint64_t descchannels; // canaux de description
  uint64_t titlechannels;// canaux de titre
  uint64_t footchannels; // canaux secondaires et de pied de page
  uint64_t boxchannels;  // canaux de bordure
  uint64_t flags;        // champ de bits sur NCMULTISELECTOR_OPTION_*
} ncmultiselector_options;

struct ncmultiselector* ncmultiselector_create(struct ncplane* n, const ncmultiselector_options* opts);

int ncmultiselector_selected(bool* selected, unsigned n);

struct ncplane* ncmultiselector_plane(struct ncmultiselector* n);

bool ncmultiselector_offer_input(struct ncmultiselector* n, const ncinput* nc);

void ncmultiselector_destroy(struct ncmultiselector* n);

DESCRIPTION

Un widget de sélection multiple présente une liste d'éléments (éventuellement plus que ce qui peut être affiché à la fois). Il facilite le choix de zéro, un ou plusieurs éléments de la liste. Les éléments peuvent être sélectionnés et désélectionnés avant qu'un choix final ne soit fait.

NOTES

Le ncplane n fourni à ncmultiselector_create ne doit pas être NULL. Il sera redimensionné librement par le nouveau ncmultiselector.

ncmultiselector_selected renvoie l'indice de l'option actuellement mise en surbrillance. Il écrit dans le bitmap n-ième pointé par selected en fonction des options actuellement sélectionnées.

ncmultiselector_plane renverra le ncplane sur lequel le widget est dessiné.

Les entrées doivent passer par ncmultiselector_offer_input pour tirer parti des contrôles courants. Il gérera les flèches haut et bas, ainsi que PageUp et PageDown. Si la souris est activée, la molette de la souris et les clics de souris sur les flèches de défilement seront gérés.

ncmultiselector_destroy détruit le ncplane sous-jacent, tout comme ncmultiselector_create en cas d'erreur.

Comme il n'existe pas de drapeaux, l'option flags doit toujours être 0.

VALEURS DE RETOUR

ncmultiselector_create renvoie NULL en cas d'erreur, auquel cas le ncplane passé est détruit.

ncmultiselector_selected renvoie -1 s'il n'y a pas d'éléments, ou si n n'est pas égal au nombre d'éléments. Sinon, il renvoie l'indice de l'option actuellement mise en surbrillance et écrit un bitmap dans selected basé sur les éléments sélectionnés.

VOIR AUSSI

notcurses(3), notcurses_input(3), notcurses_plane(3) notcurses_selector(3)
