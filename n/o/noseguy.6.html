NOM

noseguy - un petit bonhomme avec un grand nez erre en faisant preuve d'esprit

SYNTAXE

noseguy [--display hôte:écran.sous-écran] [--foreground couleur] [--background couleur] [--text-foreground couleur] [--text-background couleur] [--font police] [--window] [--root] [--window-id numéro] [--install] [--visual visuel] [--mode mode] [--program programme] [--filename fichier] [--text texte] [--fps]

DESCRIPTION

Un petit homme avec un grand nez et un chapeau court en diffusant des messages à l'écran. Ce code (et ses bitmaps) ont été extraits du programme xnlock.

OPTIONS

noseguy accepte les options suivantes :

--window
Dessine sur une fenêtre nouvellement créée. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id numéro
Dessine sur la fenêtre spécifiée.
--install
Installe une carte de couleurs privée pour la fenêtre.
--visual visuel
Spécifie quel visuel utiliser. Les valeurs valides sont le nom d'une classe visuelle, ou le numéro d'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--font police
La police utilisée pour les messages.
--program programme
Ce programme sera exécuté périodiquement, et sa sortie sera le texte des messages. Par défaut :


xscreensaver-text --cols 40 | head -n15

Vous pouvez configurer le texte imprimé via l'onglet "Avancé" de xscreensaver-settings(1), ou en modifiant votre fichier ~/.xscreensaver.

--filename fichier
Si mode est file, alors le contenu de ce fichier sera utilisé pour tous les messages.
--text chaîne
Si mode est string, alors ce texte sera utilisé pour tous les messages.
--fps
Affiche le taux d'images par seconde actuel et la charge du processeur.

ENVIRONNEMENT

DISPLAY
pour obtenir le nom d'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de la fenêtre à utiliser avec --root.
