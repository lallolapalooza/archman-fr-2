nologin(5) Manuel des formats de fichiers nologin(5)

NOM

nologin - empêcher les utilisateurs non privilégiés de se connecter au système

DESCRIPTION

Si le fichier /etc/nologin existe et est lisible, login(1) n'autorisera l'accès qu'à root. Les autres utilisateurs verront le contenu de ce fichier et leurs connexions seront refusées. Cela fournit un moyen simple de désactiver temporairement toutes les connexions non privilégiées.

FICHIERS

/etc/nologin

VOIR AUSSI

login(1), shutdown(8)
