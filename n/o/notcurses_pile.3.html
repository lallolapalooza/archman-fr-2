NOM

notcurses_pile - opérations sur les piles Notcurses

SYNTAXE

struct ncplane* notcurses_top(struct notcurses* n);

struct ncplane* notcurses_bottom(struct notcurses* n);

struct ncplane* ncpile_top(struct ncplane* n);

struct ncplane* ncpile_bottom(struct ncplane* n);

DESCRIPTION

Notcurses n'exporte pas le type ncpile, ni aucune fonctionnalité qui l'utilise directement. Les piles sont néanmoins un concept important dans Notcurses. Les fonctions qui opèrent sur les piles (par exemple, ncpile_render(3)) sont appelées avec n'importe quel ncplane de cette pile.

Les piles sont des collections d'ncplanes, indépendantes les unes des autres pour le rendu et la sécurité des threads. Bien qu'une seule pile puisse être tracée (écrite sur l'écran) à la fois, des actions concurrentes arbitraires peuvent être effectuées en toute sécurité sur des piles distinctes. Les piles ne se composent pas : le rendu d'une pile détruit tout matériel qui se chevauche.

Une pile est créée de l'une des trois manières suivantes :

•
ncpile_create(3) est appelé,
•
ncvisual_blit(3) est appelé avec un plan cible n `NULL`, ou
•
ncplane_reparent(3) est appelé avec n égal à newparent, et n n'est pas déjà un plan racine.

Une pile est détruite lorsque son dernier ncplane est détruit, ou est re-parenté dans une autre pile.

Les plans d'une pile sont totalement ordonnés le long de l'axe z. ncpile_top et ncpile_bottom renvoient les plans les plus hauts et les plus bas, respectivement, de la pile contenant leur argument. notcurses_top et notcurses_bottom font de même pour la pile standard.
