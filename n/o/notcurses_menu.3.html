notcurses_menu(3) Manuel des fonctions de bibliothèque notcurses_menu(3)

NOM

notcurses_menu - opérations sur les objets ncmenu

SYNTAXE

#include <notcurses/notcurses.h>

struct ncmenu;
struct ncplane;
struct notcurses;
struct ncmenu_section {
  const char* name;   // chaîne utf-8
  struct ncmenu_item {
    const char* desc; // élément de menu utf-8, NULL pour un séparateur horizontal
    ncinput shortcut; // raccourci, tous doivent être distincts
  }* items;
  int itemcount;
};
#define NCMENU_OPTION_BOTTOM 0x0001 // rangée du bas (par opposition à la rangée du haut)
#define NCMENU_OPTION_HIDING 0x0002 // cacher le menu lorsqu'il n'est pas déplié
typedef struct ncmenu_options {
  struct ncmenu_section* sections; // 'sectioncount' menu_sections
  int sectioncount;         // doit être positif
  uint64_t headerchannels;  // style pour l'en-tête
  uint64_t sectionchannels; // style pour les sections
  uint64_t flags;           // champ de bits sur NCMENU_OPTION_*
} ncmenu_options;

struct ncmenu* ncmenu_create(struct notcurses* nc, const menu_options* opts);

int ncmenu_unroll(struct ncmenu* n, int sectionidx);

int ncmenu_rollup(struct ncmenu* n);

int ncmenu_nextsection(struct ncmenu* n);

int ncmenu_prevsection(struct ncmenu* n);

int ncmenu_nextitem(struct ncmenu* n);

int ncmenu_previtem(struct ncmenu* n);

int ncmenu_item_set_status(struct ncmenu* n, const char* section, const char* item, bool enabled);

const char* ncmenu_selected(const struct ncmenu* n, ncinput* ni);

const char* ncmenu_mouse_selected(const struct ncmenu* n, const ncinput* click, ncinput* ni);

struct ncplane* ncmenu_plane(struct ncmenu* n);

bool ncmenu_offer_input(struct ncmenu* n, const ncinput* nc);

void ncmenu_destroy(struct ncmenu* n);

DESCRIPTION

Une instance notcurses prend en charge les barres de menu sur la rangée supérieure ou inférieure d'un plan. Un menu est composé de sections, qui sont elles-mêmes composées d'éléments. Soit aucune section n'est visible, et le menu est replié, soit exactement une section est dépliée. ncmenu_rollup place un ncmenu dans l'état replié. ncmenu_unroll replie toute section dépliée et déplie celle spécifiée. ncmenu_destroy supprime une barre de menu et libère toutes les ressources associées.

ncmenu_selected renvoie la description de l'élément sélectionné, ou NULL si aucune section n'est dépliée, ou si aucun élément valide n'est sélectionné. ncmenu_mouse_selected renvoie l'élément sélectionné par un clic de souris (décrit dans click), qui doit se trouver sur la section activement dépliée. Dans les deux cas, s'il y a un raccourci pour l'élément et que ni n'est pas NULL, ni sera rempli avec le raccourci.

Le menu peut être piloté entièrement par l'application, via des appels directs à ncmenu_previtem, ncmenu_prevsection, et similaires, ou des objets ncinput peuvent être passés à ncmenu_offer_input. Dans ce dernier cas, le menu se gérera en grande partie lui-même. L'application doit gérer la sélection des éléments (généralement via la touche Entrée et/ou un clic de souris) elle-même, car le menu ne peut pas appeler arbitrairement l'application. ncmenu_offer_input gérera les clics pour déplier les sections de menu, les clics pour fermer le menu, Échap pour fermer le menu, gauche et droite pour changer de section de menu, et haut et bas pour changer d'élément de menu (ces derniers ne sont consommés que s'il y a une section activement dépliée).

Les éléments peuvent être désactivés avec ncmenu_item_set_status. Passez false pour désactiver l'élément, ou true pour l'activer. Tous les éléments sont activés par défaut. Un élément désactivé ne sera pas renvoyé avec ncmenu_mouse_selected, ni atteint avec ncmenu_nextsection ni ncmenu_prevsection.

VALEURS DE RETOUR

ncmenu_create renvoie NULL en cas d'erreur, ou un pointeur vers un nouvel ncmenu valide. Les autres fonctions renvoient une valeur non nulle en cas d'erreur, ou zéro en cas de succès. Presque toutes les erreurs sont dues à des paramètres invalides.

ncmenu_offer_input renvoie true si le menu a "consommé" l'entrée, c'est-à-dire s'il l'a trouvée pertinente et a effectué une action. Sinon, false est renvoyé, et le ncinput doit être considéré comme non pertinent pour le menu.
