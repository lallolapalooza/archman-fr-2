NOLOGIN(8) Administration système NOLOGIN(8)

NOM

nologin - refuser poliment une connexion

SYNTAXE

nologin [-V] [-h]

DESCRIPTION

nologin affiche un message indiquant qu'un compte n'est pas disponible et se termine avec un code non nul. Il est destiné à être utilisé dans le champ du shell pour refuser l'accès à la connexion d'un compte.

Si le fichier /etc/nologin.txt existe, nologin en affiche le contenu à l'utilisateur au lieu du message par défaut.

Le code de sortie renvoyé par nologin est toujours 1.

OPTIONS

-c, --command commande

--init-file

-i, --interactive

--init-file fichier

-i, --interactive

-l, --login

--noprofile

--norc

--posix

--rcfile fichier

-r, --restricted

Ces options de ligne de commande du shell sont ignorées pour éviter une erreur de nologin.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

NOTES

nologin est un moyen par compte de désactiver la connexion (généralement utilisé pour les comptes système comme http ou ftp). nologin utilise /etc/nologin.txt comme source optionnelle pour un message non par défaut, l'accès à la connexion est toujours refusé indépendamment du fichier.

pam_nologin(8) Le module PAM empêche généralement tous les utilisateurs non root de se connecter au système. La fonctionnalité de pam_nologin(8) est contrôlée par /var/run/nologin ou le fichier /etc/nologin.

HISTORIQUE

La commande nologin est apparue dans 4.4BSD.
