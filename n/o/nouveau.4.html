NOM

nouveau - Pilote vidéo NVIDIA

SYNTAXE

Section "Device"
  Identifier "nomdev"
  Driver "nouveau"
  ...
EndSection

DESCRIPTION

nouveau est un pilote Xorg pour les cartes vidéo NVIDIA. Le pilote prend en charge l'accélération 2D et offre un support pour les profondeurs de trame suivantes : (15,) 16 et 24. Les vues TrueColor sont supportées pour ces profondeurs.

DETAILS DE CONFIGURATION

Veuillez vous référer à xorg.conf(5) pour les détails de configuration généraux. Cette section ne couvre que les détails de configuration spécifiques à ce pilote.

Le pilote détecte automatiquement le type de chipset et la quantité de mémoire vidéo présente pour toutes les puces.

Les Options de pilote suivantes sont prises en charge :

Option "HWCursor" "booléen"
Active ou désactive le curseur matériel. Par défaut : activé.
Option "AccelMethod" "chaîne"
Spécifie la méthode d'accélération. L'une des valeurs : "none", ou "exa". Par défaut : exa.
Option "NoAccel" "booléen"
Désactive ou active l'accélération. Par défaut : l'accélération est activée.
Option "ShadowFB" "booléen"
Active ou désactive l'utilisation de la couche de trame fantôme. Par défaut : désactivé.
Option "WrappedFB" "booléen"
Active ou désactive wfb, n'affecte que nv50+. Utile pour certaines configurations héritées où une latence de rendu élevée est perçue. Par défaut : wfb est désactivé.
Option "GLXVBlank" "booléen"
Synchronise les clients GLX avec VBlank. Utile lorsque le déchirement est un problème, nuisible si le GPU n'est pas assez rapide pour suivre le taux de rafraîchissement du moniteur. Par défaut : activé.
Option "ZaphodHeads" "chaîne"
Spécifie la ou les sorties randr à utiliser avec le mode zaphod pour une instance de pilote donnée. Si vous utilisez cette option, vous devez utiliser cette option pour toutes les instances du pilote.
Par exemple : Option "ZaphodHeads" "LVDS,VGA-0" attribuera les sorties xrandr LVDS et VGA-0 à cette instance du pilote.
Option "PageFlip" "booléen"
Active le retournement de page DRI2. Par défaut : activé.
Option "SwapLimit" "entier"
Définit le nombre maximum autorisé d'échanges de double tampon OpenGL en attente pour une drawable avant qu'un client ne soit bloqué.
Une valeur de 1 correspond à la double mise en mémoire tampon. Une valeur de 2 correspond à la triple mise en mémoire tampon. Des valeurs plus élevées peuvent permettre une fréquence d'images plus élevée, mais augmentent également le temps de réponse pour les applications interactives, par exemple les jeux. Nouveau prend actuellement en charge de manière fiable une valeur maximale de 2 sur XOrg 1.12+. Un réglage maximal de 2 sur les anciens serveurs x est autorisé, mais il viendra rompre la conformité avec la spécification OML_sync_control d'OpenML et provoquera l'échec des logiciels qui dépendent d'un comportement de synchronisation correct tel que défini dans cette spécification.
Par défaut : 1.
Option "DRI" "entier"
Définit le niveau maximum de DRI à activer. Les valeurs valides sont 2 ou 3. L'accélération exa respectera le niveau maximum s'il est pris en charge. Par défaut : 2.

NOM
nouveau — pilote d'accélérateur graphique Xorg pour les GPU NVIDIA

SYNTAXE
/etc/X11/xorg.conf, xorg.conf

DESCRIPTION
Le pilote nouveau est un pilote d'accélérateur graphique pour les GPU NVIDIA. Il fournit une accélération 2D et 3D via le système X Window. Le pilote est en développement actif et les performances et la compatibilité s'améliorent continuellement.

Ce pilote peut être configuré en utilisant les options standard du pilote de périphérique et les options spécifiques au pilote. Les options sont généralement spécifiées dans le fichier de configuration xorg.conf sous la section Device.

MATÉRIEL SUPPORTÉ
Le pilote nouveau prend en charge une large gamme de GPU NVIDIA, y compris les séries GeForce, Quadro et Tesla. Pour une liste détaillée du matériel pris en charge, veuillez consulter la documentation du projet nouveau.

DÉTAILS DE CONFIGURATION
Les options de configuration du pilote nouveau peuvent être spécifiées dans la section Device du fichier xorg.conf. Voici quelques options courantes :

  • Option "AccelMethod" "sna" | "uxa" : Spécifie la méthode d'accélération à utiliser. "sna" est généralement plus performant.
  • Option "SWcursor" "boolean" : Active ou désactive le curseur logiciel. Par défaut, le curseur matériel est utilisé.
  • Option "DRI" "boolean" : Active ou désactive le rendu direct. Par défaut, il est activé si le matériel le prend en charge.
  • Option "TearFree" "boolean" : Active ou désactive la suppression de l'effet de déchirement de l'image (tearing).

Pour plus d'informations sur les options de configuration, consultez la page de manuel de xorg.conf et la documentation du projet nouveau.
