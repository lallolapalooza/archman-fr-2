NOM

notcurses_reel - widget de haut niveau pour les données hiérarchiques

SYNOPIS

#include <notcurses/notcurses.h>

#define NCREEL_OPTION_INFINITESCROLL 0x0001
#define NCREEL_OPTION_CIRCULAR       0x0002
struct ncreel;
struct ncplane;
struct nctablet;
typedef struct ncreel_options {
  // notcurses peut dessiner une bordure autour du ncreel, et aussi
  // autour des tablettes composantes. Inhiber les bordures en définissant tous
  // les bits valides dans les masques. Inhiber partiellement les bordures en définissant
  // des bits individuels dans les masques. Les attributs et paires appropriés
  // seront utilisés pour styliser les bordures. Les tablettes centrées et
  // non centrées peuvent avoir des styles différents. Vous pouvez à la place
  // dessiner vos propres bordures, ou renoncer aux bordures entièrement.
  unsigned bordermask; // champ binaire ; les 1 ne seront pas dessinés
  uint64_t borderchan; // attributs utilisés pour la bordure ncreel
  unsigned tabletmask; // champ binaire pour les bordures de tablette
  uint64_t tabletchan; // canal de style de bordure de tablette
  uint64_t focusedchan;// canal de style de bordure de tablette centrée
  uint64_t flags;      // champ binaire sur NCREEL_OPTION_*
} ncreel_options;

struct ncreel* ncreel_create(struct ncplane* nc, const ncreel_options* popts);

struct ncplane* ncreel_plane(struct ncreel* nr);

typedef int (tabletcb)(struct nctablet t, bool cliptop);

struct nctablet* ncreel_add(struct ncreel* nr, struct nctablet* after, struct nctablet* before, tabletcb cb, void* opaque);

int ncreel_tabletcount(const struct ncreel* nr);

int ncreel_del(struct ncreel* nr, struct nctablet* t);

int ncreel_redraw(struct ncreel* nr);

struct nctablet* ncreel_focused(struct ncreel* nr);

struct nctablet* ncreel_next(struct ncreel* nr);

struct nctablet* ncreel_prev(struct ncreel* nr);

bool ncreel_offer_input(struct ncreel* nr, const ncinput* ni);

void ncreel_destroy(struct ncreel* nr);

void* nctablet_userptr(struct nctablet* t);

struct ncplane* nctablet_plane(struct nctablet* t);

DESCRIPTION

Un ncreel est un widget pour l'affichage et la manipulation de données hiérarchiques, destiné à une utilisation efficace de la zone d'affichage tout en prenant en charge les claviers, les souris et les interfaces haptiques. Une série de nctablets sont ordonnés sur un cylindre virtuel ; les tablettes peuvent croître et rétrécir librement. Se déplacer entre les tablettes fait "tourner" le cylindre. Les ncreels prennent en charge des bordures optionnelles autour du reel et/ou des tablettes.

ncreel_redraw organise les tablettes, en appelant le tabletcb défini par chacune. Il appellera les callbacks des seules tablettes actuellement visibles. Cette fonction doit être appelée chaque fois que les données d'une tablette doivent être rafraîchies. La valeur de retour de ce callback est le nombre de lignes dessinées dans le ncplane. La tablette sera agrandie ou rétrécie si nécessaire pour refléter cette valeur de retour.

Sauf si le reel est dépourvu de tablettes, il y a toujours une tablette "centrée" (la première tablette ajoutée à un reel vide devient centrée). La tablette centrée peut changer via ncreel_next et ncreel_prev. Si ncreel_del est appelé sur la tablette centrée, et qu'au moins une autre tablette subsiste, une tablette reçoit le focus.

L'appel de fonctions qui modifient le reel, y compris ncreel_next, ncreel_prev, ncreel_del et ncreel_add, appelle implicitement ncreel_redraw. Ce comportement ne doit pas être exploité, car il est probable qu'il disparaisse.

MISE EN PAGE

Lorsque l'utilisateur appelle ncreel_redraw, Notcurses ne peut pas présumer connaître la taille d'une tablette quelconque - une ou plusieurs peuvent avoir changé depuis le dernier dessin. Ce n'est qu'après un callback que ncreel_redraw connaît le nombre de lignes qu'une tablette occupera.

Une opération de redessin commence par la tablette centrée. Son callback est appelé avec un plan aussi grand que le reel, c'est-à-dire que la tablette centrée peut occuper tout le reel, à l'exclusion de toute autre tablette. La tablette centrée sera maintenue là où elle était, si possible ; sa croissance pourrait la forcer à se déplacer. Il y a maintenant une tablette verrouillée en place, et zéro, une ou deux zones vides. Les tablettes sont successivement placées dans ces espaces jusqu'à ce que le reel soit rempli.

En général, si le reel n'est pas plein, les tablettes seront dessinées vers le haut, mais cela ne doit pas être exploité.

LE CALLBACK DE TABLETTE

Le callback de tablette (de type tabletcb) est appelé avec un ncplane et un bool. La fonction de callback ne doit pas se baser sur la position absolue du plan, car il pourrait être déplacé. Le bool indique si le plan doit être rempli par le bas, ou par le haut (ce n'est significatif que si le plan est insuffisamment grand pour contenir toutes les données disponibles de la tablette). Le callback ne doit pas redimensionner le plan (il sera redimensionné après le retour). Le callback doit retourner le nombre de lignes utilisées (il est parfaitement valide d'utiliser zéro ligne), ou un nombre négatif en cas d'erreur.

Retourner plus de lignes que le plan n'en a disponibles est une erreur.

VALEURS DE RETOUR

ncreel_focused, ncreel_prev et ncreel_next retournent tous la tablette centrée, sauf si aucune tablette n'existe, auquel cas ils retournent NULL.

ncreel_add retourne la nctablet nouvellement ajoutée.

BOGUES

Je n'arrive pas à décider s'il faut obliger l'utilisateur à appeler explicitement ncreel_redraw. Le faire signifie que les changements peuvent être groupés sans redessin, mais cela complique également les choses pour moi et pour l'utilisateur.
