NOM

notmuch-setup - mise en route avec notmuch

SYNTAXE

notmuch [option ...] commande [arg ...]

DESCRIPTION

Notmuch est un programme en ligne de commande pour indexer, rechercher, lire et étiqueter de grandes collections de messages électroniques.

Cette page décrit comment commencer à utiliser notmuch depuis la ligne de commande et donne un bref aperçu des commandes disponibles. Pour plus d'informations sur, par exemple, notmuch show, consultez la page de manuel notmuch-show, également accessible via notmuch help show.

La manière la plus rapide de commencer avec Notmuch est simplement d'appeler la commande notmuch sans arguments, ce qui vous guidera interactivement à travers le processus d'indexation de votre courrier.

NOTE

OPTIONS

Les options globales prises en charge pour notmuch incluent :

--help [nom-de-la-commande]
Affiche un synopsis des commandes disponibles et quitte. Avec un nom de commande optionnel, affiche la page de manuel de cette sous-commande.
--version
Affiche la version installée de notmuch et quitte.
--config=FICHIER
Spécifie le fichier de configuration à utiliser. Cela remplace tout fichier de configuration spécifié par NOTMUCH_CONFIG. La chaîne vide est une valeur permise et parfois utile pour FICHIER, ce qui indique à notmuch d'utiliser uniquement les métadonnées de configuration de la base de données.
--uuid=HEX
Force l'UUID de la base de données (un identifiant unique qui persiste jusqu'à, par exemple, la compaction de la base de données) à être HEX ; quitte avec une erreur si ce n'est pas le cas. Ceci est utile pour détecter le basculement des compteurs de modification sur les messages. Vous pouvez trouver cet UUID en utilisant, par exemple, notmuch count --lastmod.

Toutes les options globales sauf --config peuvent également être spécifiées après la commande. Par exemple, notmuch subcommand --uuid=HEX est équivalent à notmuch --uuid=HEX subcommand.

COMMANDES

SETUP

La commande notmuch setup est utilisée pour configurer Notmuch pour une première utilisation, (ou pour le reconfigurer plus tard).

La commande de configuration demandera votre nom complet, votre adresse e-mail principale, toute adresse e-mail alternative que vous utilisez, et le répertoire contenant vos archives d'e-mails. Vos réponses seront écrites dans un fichier de configuration dans NOTMUCH_CONFIG (s'il est défini) ou ${HOME}/.notmuch-config. Ce fichier de configuration sera créé avec des commentaires descriptifs, ce qui le rendra facile à éditer manuellement plus tard pour modifier la configuration. Ou vous pouvez exécuter notmuch setup à nouveau pour changer la configuration.

Le répertoire de messagerie que vous spécifiez peut contenir un nombre quelconque de sous-répertoires et doit principalement contenir uniquement des fichiers avec des messages électroniques individuels (par exemple, les archives Maildir ou MH sont parfaites). S'il y a d'autres fichiers non-courriels (tels que des index maintenus par d'autres programmes de messagerie), notmuch fera de son mieux pour les détecter et les ignorer.

Appeler notmuch sans argument de commande exécutera setup si la commande de configuration n'a pas été terminée précédemment.

AUTRES COMMANDES

Plusieurs des commandes notmuch acceptent des termes de recherche avec une syntaxe commune. Voir notmuch-search-terms pour plus de détails sur la syntaxe prise en charge.

Les commandes notmuch-search, notmuch-show, notmuch-address et notmuch-count sont utilisées pour interroger la base de données d'e-mails.

La commande notmuch-reply est utile pour préparer un modèle de réponse à un e-mail.

La commande notmuch-tag est la seule commande disponible pour manipuler le contenu de la base de données.

Les commandes notmuch-dump et notmuch-restore peuvent être utilisées pour créer une sauvegarde textuelle des tags d'e-mails à des fins de sauvegarde, et pour restaurer à partir de cette sauvegarde.

La commande notmuch-config peut être utilisée pour obtenir ou définir des paramètres dans le fichier de configuration notmuch.

COMMANDES EXTERNES

Si la commande donnée n'est pas reconnue par notmuch, notmuch essaie d'exécuter l'utilitaire externe notmuch-<sous-commande> présent dans le PATH. Cela permet aux utilisateurs d'avoir leurs propres outils liés à notmuch exécutés via la commande notmuch. Par conception, cela ne permet pas de remplacer les propres commandes de notmuch par des commandes externes. La variable d'environnement NOTMUCH_CONFIG sera définie conformément à --config, si ce dernier est présent.

ENVIRONNEMENT

Les variables d'environnement suivantes peuvent être utilisées pour contrôler le comportement de notmuch.

NOTMUCH_CONFIG
Spécifie l'emplacement du fichier de configuration notmuch. Voir notmuch-config pour les détails.
NOTMUCH_DATABASE
Spécifie l'emplacement de la base de données notmuch. Voir notmuch-config pour les détails.
NOTMUCH_PROFILE
Permet de sélectionner parmi les configurations notmuch. Voir notmuch-config pour les détails.
NOTMUCH_TALLOC_REPORT
Emplacement pour écrire un rapport d'utilisation de la mémoire talloc. Voir talloc_enable_leak_report_full dans talloc(3) pour plus d'informations.
NOTMUCH_DEBUG_QUERY
S'il est défini sur une valeur non vide, la bibliothèque notmuch affichera (sur stderr) les requêtes Xapian qu'elle construit.
