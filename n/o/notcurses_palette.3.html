NOM

notcurses_palette - opérations sur les palettes notcurses

SYNOPIS

#include <notcurses/notcurses.h>

typedef struct ncpalette {
  // Nous stockons les valeurs RVB comme un canal ordinaire
  uint32_t chans[NCPALETTESIZE];
} ncpalette;

bool notcurses_cantruecolor(const struct notcurses* nc);

ncpalette* ncpalette_new(struct notcurses* nc);

int ncpalette_use(struct notcurses* nc, const ncpalette* p);

int ncpalette_set_rgb8(ncpalette* p, int idx, int r, int g, int b);

int ncpalette_set(ncpalette* p, int idx, unsigned rgb);

int ncpalette_get(const ncpalette* p, int idx, uint32_t* palent);

int ncpalette_get_rgb8(const ncpalette* p, int idx, int* restrict r, int* restrict g, int* restrict b);

void ncpalette_free(ncpalette* p);

bool notcurses_canchangecolors(const struct notcurses* nc);

DESCRIPTION

Certains terminaux ne prennent en charge que 256 couleurs, mais permettent de spécifier la palette complète avec des couleurs RVB arbitraires. Dans tous les cas, il est plus performant d'utiliser des couleurs indexées, car il y a beaucoup moins de données à écrire dans le terminal. Si vous pouvez vous limiter à 256 couleurs, c'est probablement mieux.

De plus, la palette de couleurs permet des effets de cyclage de couleurs très rapides, car une seule commande peut affecter de nombreuses cellules à l'écran.

VALEUR DE RETOUR

Les fonctions retournant un int renvoient -1 en cas d'échec, ou 0 en cas de succès. L'échec est toujours dû à des entrées invalides. Les fonctions retournant un bool sont des prédicats et renvoient la valeur demandée. Les fonctions retournant un type unsigned renvoient l'entrée, modifiée comme demandé.
