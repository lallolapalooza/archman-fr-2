NOM

notcurses_stdplane - acquérir le ncplane standard

SYNTAXE

#include <notcurses/notcurses.h>

struct ncplane* notcurses_stdplane(struct notcurses* nc);

const struct ncplane* notcurses_stdplane_const(const struct notcurses* nc);

static inline struct ncplane* notcurses_stddim_yx(struct notcurses* nc, unsigned* restrict y, unsigned* restrict x);

static inline const struct ncplane* notcurses_stddim_yx_const(const struct notcurses* nc, unsigned* restrict y, unsigned* restrict x);

int notcurses_enter_alternate_screen(struct notcurses* nc);

int notcurses_leave_alternate_screen(struct notcurses* nc);

DESCRIPTION

notcurses_stdplane renvoie un handle vers le ncplane standard pour le contexte nc. Le plan standard existe toujours et a toujours la même taille que l'écran. Il est erroné d'appeler ncplane_destroy(3), ncplane_resize(3), ou ncplane_move(3) sur le plan standard, mais il peut être déplacé librement le long de l'axe z.

Le curseur virtuel du plan standard est initialisé à sa cellule la plus en haut et la plus à gauche, sauf si NCOPTION_PRESERVE_CURSOR est fourni (voir notcurses_init(3)), auquel cas il est placé là où se trouvait le curseur réel du terminal au démarrage.

notcurses_stddim_yx fournit la même fonction, mais écrit également les dimensions du plan standard (et donc la zone dessinable réelle) dans tous les paramètres non NULL parmi y et x.

notcurses_stdplane_const permet d'utiliser un const notcurses en toute sécurité.

Un événement de redimensionnement n'invalide pas ces références. Elles peuvent être utilisées jusqu'à ce que notcurses_stop(3) soit appelé sur le nc associé.

notcurses_enter_alternate_screen et notcurses_leave_alternate_screen n'ont de sens que si le terminal implémente « l'écran alternatif » via les capacités smcup et rmcup de terminfo(5) (voir la discussion de NCOPTION_NO_ALTERNATE_SCREEN dans notcurses_init(3)). Si l'écran alternatif n'est pas actuellement utilisé, et en supposant qu'il est pris en charge, notcurses_enter_alternate_screen passera à l'écran alternatif. Cela redessine le contenu, repositionne le curseur et rend généralement le défilement impossible. Le plan standard aura le défilement désactivé lors du passage à l'écran alternatif.

VALEURS DE RETOUR

notcurses_enter_alternate_screen retournera -1 si l'écran alternatif n'est pas disponible. Lui et notcurses_leave_alternate_screen retourneront -1 en cas d'échec d'E/S.

Les autres fonctions ne peuvent pas échouer lorsqu'elles reçoivent un struct notcurses valide. Elles renverront toujours un pointeur valide vers le plan standard.

VOIR AUSSI

notcurses(3), notcurses_init(3), notcurses_plane(3), notcurses_stop(3), terminfo(5)
