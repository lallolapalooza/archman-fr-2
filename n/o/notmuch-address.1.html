NOM

notmuch-address - affiche les adresses des messages correspondants

SYNTAXE

notmuch address [option ...] <terme de recherche> ...

DESCRIPTION

Recherche les messages correspondant aux termes de recherche donnés, et affiche les adresses qui s'y trouvent. Les adresses dupliquées sont filtrées.

Voir notmuch-search-terms pour les détails de la syntaxe supportée pour les <termes de recherche>.

Les options supportées pour address incluent :

--format=(json|sexp|text|text0)
Présente les résultats en JSON, S-Expressions, texte brut séparé par des retours à la ligne (par défaut), ou texte brut séparé par des caractères nuls (compatible avec l'option xargs(1) -0 quand elle est disponible).
--format-version=N
Utilise la version spécifiée du format de sortie structuré. Ceci est destiné aux programmes qui invoquent notmuch en interne. Si omis, la dernière version supportée sera utilisée.
--output=(sender|recipients|count|address)
Contrôle quelles informations apparaissent dans la sortie. Cette option peut être donnée plusieurs fois pour combiner différentes sorties. Quand ni --output=sender ni --output=recipients n'est donné, --output=sender est implicite.
sender
Affiche toutes les adresses de l'en-tête From.

Note : La recherche de sender devrait être beaucoup plus rapide que la recherche de recipients, car les adresses de l'expéditeur sont mises en cache directement dans la base de données tandis que les autres adresses doivent être récupérées à partir des fichiers de messages.

recipients
Affiche toutes les adresses des en-têtes To, Cc et Bcc.
count
Affiche le nombre de fois où l'adresse a été rencontrée pendant la recherche.

Note : Avec cette option, les adresses ne sont affichées qu'après la fin de la recherche. Cela peut prendre beaucoup de temps.

address
Affiche uniquement les adresses email au lieu des boîtes aux lettres complètes avec les noms et les adresses email. Cette option n'a aucun effet sur les formats de sortie JSON ou S-Expression.
--deduplicate=(no|mailbox|address)
Contrôle la déduplication des résultats.
no
Affiche toutes les occurrences d'adresses dans les messages correspondants. Ceci n'est pas applicable avec --output=count.
mailbox
Déduplique les adresses en se basant sur le nom complet sensible à la casse et l'adresse email, ou la boîte aux lettres. C'est effectivement la même chose que de rediriger la sortie de --deduplicate=no vers sort | uniq, sauf pour l'ordre des résultats. C'est le comportement par défaut.
address
Déduplique les adresses en se basant sur la partie adresse insensible à la casse de la boîte aux lettres. Parmi toutes les variantes (avec des noms ou des cas différents), affiche celle qui apparaît le plus fréquemment parmi les messages correspondants. Si --output=count est spécifié, inclut toutes les variantes dans le comptage.
--sort=(newest-first|oldest-first)
Cette option peut être utilisée pour présenter les résultats soit dans l'ordre chronologique inversé (newest-first) soit dans l'ordre chronologique (oldest-first).

Par défaut, les résultats seront affichés dans l'ordre chronologique inversé (c'est-à-dire que les résultats les plus récents seront affichés en premier).

Cependant, si --output=count ou --deduplicate=address est spécifié, cette option est ignorée et l'ordre des résultats n'est pas spécifié.

--exclude=(true|false)
Un message est dit "exclu" s'il correspond à au moins une étiquette dans search.exclude_tags qui n'apparaît pas explicitement dans les termes de recherche. Cette option spécifie si les messages exclus doivent être omis dans le processus de recherche.

La valeur par défaut, true, empêche les messages exclus de correspondre aux termes de recherche.

false permet aux messages exclus de correspondre aux termes de recherche et d'apparaître dans les résultats affichés.

STATUS DE SORTIE

Cette commande supporte les codes de statut de sortie spéciaux suivants :

20
La version du format demandée est trop ancienne.
21
La version du format demandée est trop récente.
