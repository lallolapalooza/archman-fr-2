notcurses_fade(3) Manuel des fonctions de bibliothèque notcurses_fade(3)

NOM

notcurses_fade - estomper les ncplanes

SYNOPSIS

#include <notcurses/notcurses.h>

struct ncfadectx;
// Appelée pour chaque delta effectué dans un estompage sur ncp. Si autre chose que 0
// est retourné, l'opération d'estompage cesse immédiatement, et cette valeur est
// propagée. Si fourni et non NULL, les estompeurs n'appelleront pas eux-mêmes
// notcurses_render().
typedef int (*fadecb)(struct notcurses* nc, struct ncplane* ncp,
                      const struct timespec*, void* curry);

bool notcurses_canfade(const struct notcurses* nc);

int ncplane_fadeout(struct ncplane* n, const struct timespec* ts, fadecb fader, void* curry);

int ncplane_fadein(struct ncplane* n, const struct timespec* ts, fadecb fader, void* curry);

int ncplane_pulse(struct ncplane* n, const struct timespec* ts, fadecb fader, void* curry);

struct ncfadectx* ncfadectx_setup(struct ncplane* n);

int ncfadectx_iterations(const struct ncfadectx* nctx);

int ncplane_fadeout_iteration(struct ncplane* n, struct ncfadectx* nctx, int iter, fadecb fader, void* curry);

int ncplane_fadein_iteration(struct ncplane* n, struct ncfadectx* nctx, int iter, fadecb fader, void* curry);

void ncfadectx_free(struct ncfadectx* nctx);

DESCRIPTION

ncplane_fadeout, ncplane_fadein et ncplane_pulse sont des API simples pour estomper les plans. Les estompages nécessitent soit un support RVB, soit un support de reprogrammation de palette du terminal (la méthode RVB est préférée et sera utilisée autant que possible). Le paramètre ts spécifie le temps total pour l'opération d'estompage. L'opération elle-même est adaptative au temps (c'est-à-dire que si elle constate qu'elle prend du retard, elle sautera des itérations ; si elle progresse trop rapidement, elle dormira).

Ce sont des wrappers autour de l'API plus flexible ncfadectx. Créez un ncfadectx avec ncfadectx_setup. Le nombre de changements d'état possibles (itérations) est accessible avec ncfadectx_iterations. Un état peut être atteint avec ncplane_fadeout_iteration ou ncplane_fadein_iteration. Enfin, détruisez le ncfadectx avec ncfadectx_free.

VALEURS DE RETOUR

ncplane_fadeout_iteration et ncplane_fadein_iteration propageront toute valeur de retour non nulle de la fonction de rappel fader.

BOGUES

La reprogrammation de palette peut affecter d'autres contenus du terminal de manière complexe. Ce n'est pas un problème lorsque la méthode RVB est utilisée.

VOIR AUSSI

clock_nanosleep(2), notcurses(3), notcurses_plane(3)
