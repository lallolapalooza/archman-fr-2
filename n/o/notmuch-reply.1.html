NOM

notmuch-reply - construit un modèle de réponse pour un ensemble de messages

SYNTAXE

notmuch reply [option ...] <terme-de-recherche> ...

DESCRIPTION

Construit un modèle de réponse pour un ensemble de messages.

Pour faciliter la réponse aux courriels, notmuch reply prend un ensemble de messages existants et construit un modèle de courriel approprié. Son adresse To : est définie selon le courriel d'origine de la manière suivante : si l'en-tête Reply-to : est présent et différent de toute adresse To:/Cc :, il est utilisé, sinon l'en-tête From est utilisé. Sauf si --reply-to=sender est spécifié, les valeurs des en-têtes To et Cc sont copiées, mais sans inclure aucune des adresses électroniques de l'utilisateur courant (telles que configurées dans primary_mail ou other_email dans le fichier .notmuch-config) dans la liste des destinataires.

Il construit également un nouvel objet approprié, incluant Re : au début (s'il n'est pas déjà présent), et ajoutant les identifiants de message des messages auxquels on répond à la liste References et en définissant correctement le champ In-Reply-To :.

Enfin, les contenus originaux des courriels sont cités en préfixant chaque ligne avec « > » et inclus dans le corps.

Le modèle de message résultant est affiché sur stdout.

Les options prises en charge pour reply incluent :

--duplicate=N
Répondre au duplicata numéro N. La numérotation commence à 1 et correspond à l'ordre utilisé par show --duplicate et search --output=files.
--format=(default|json|sexp|headers-only)
default
Inclut l'objet et le corps du message cité sous forme de message RFC 2822.
json
Produit une sortie JSON contenant les en-têtes pour un message de réponse et le contenu du message original. Cette sortie peut être utilisée par un client pour créer intelligemment un message de réponse.
sexp
Produit une sortie S-Expression contenant les en-têtes pour un message de réponse et le contenu du message original. Cette sortie peut être utilisée par un client pour créer intelligemment un message de réponse.
headers-only
Produit uniquement les en-têtes In-Reply-To, References, To, Cc et Bcc.
--format-version=N
Utilise la version spécifiée du format de sortie structurée. Ceci est destiné aux programmes qui invoquent notmuch en interne. Si omis, la dernière version prise en charge sera utilisée.
--reply-to=(all|sender)
all (par défaut)
Répond à toutes les adresses.
sender
Répond uniquement à l'expéditeur. Si on répond au propre message de l'utilisateur (l'en-tête Reply-to: ou From: est une des adresses électroniques configurées de l'utilisateur), essaie les en-têtes To:, Cc:, et Bcc: dans cet ordre, et copie les valeurs du premier qui contient quelque chose d'autre que seulement les adresses de l'utilisateur.
--decrypt=(false|auto|true)
Si true, déchiffre toutes les parties chiffrées MIME trouvées dans le contenu sélectionné (c'est-à-dire les parties « multipart/encrypted »). L'état du déchiffrement sera rapporté (actuellement pris en charge uniquement avec --format=json et --format=sexp), et en cas de déchiffrement réussi, la partie multipart/encrypted sera remplacée par le contenu déchiffré.

Si auto, et qu'une clé de session est déjà connue pour le message, alors il sera déchiffré, mais notmuch n'essaiera pas d'accéder aux clés secrètes de l'utilisateur.

Utiliser false pour éviter même le déchiffrement automatique.

Par défaut : auto

Voir notmuch-search-terms pour les détails de la syntaxe prise en charge pour <termes-de-recherche>.

Remarque : Il est plus courant d'utiliser notmuch reply avec une chaîne de recherche correspondant à un seul message (tel que id:<message-id>), mais il peut être utile de répondre à plusieurs messages à la fois. Par exemple, lorsqu'une série de correctifs sont envoyés dans un seul fil, répondre à l'ensemble du fil permet à la réponse de commenter les problèmes trouvés dans plusieurs correctifs. Le format par défaut prend en charge la réponse à plusieurs messages à la fois, mais les formats JSON et S-Expression ne le font pas.

STATUT DE SORTIE

Cette commande prend en charge les codes de statut de sortie spéciaux suivants :

20
La version de format demandée est trop ancienne.
21
La version de format demandée est trop récente.
