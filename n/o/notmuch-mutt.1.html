NOM

notmuch-mutt - assistant (pas si) encombrant pour Mutt

SYNTAXE

notmuch-mutt [OPTION]... recherche [TERME-DE-RECHERCHE]...
notmuch-mutt [OPTION]... thread < MAIL
notmuch-mutt [OPTION]... tag [TAGS]... < MAIL

DESCRIPTION

notmuch-mutt est une interface pour l'indexeur de courriels notmuch capable de remplir un maildir avec des résultats de recherche.

OPTIONS

-o DIR
--output-dir DIR
Stocke les résultats de recherche sous forme de messages (liens symboliques) dans le maildir DIR. Attention : DIR sera écrasé. (Par défaut : ~/.cache/notmuch/mutt/results/)
-p
--prompt
Au lieu d'utiliser les termes de recherche de la ligne de commande, invite l'utilisateur à les saisir (uniquement pour « recherche »).
-r
--remove-dups
Supprime les courriels avec des identifiants de message dupliqués des résultats de recherche. (Passe --duplicate=1 à la commande notmuch search.) Notez que cela peut masquer des résultats de recherche si un courriel utilise accidentellement ou malicieusement le même identifiant de message qu'un autre courriel.
-h
--help
Affiche les informations d'utilisation et quitte.

INTÉGRATION AVEC MUTT

notmuch-mutt peut être utilisé pour intégrer notmuch avec l'agent utilisateur de messagerie Mutt (sans surprise, étant donné le nom). À cette fin, vous devriez définir des macros comme celles ci-dessous dans votre configuration Mutt (généralement l'une de : ~/.muttrc, /etc/Muttrc, ou un extrait de configuration sous /etc/Muttrc.d/) :

macro index <F8> \
"<enter-command>set my_old_pipe_decode=\$pipe_decode my_old_wait_key=\$wait_key nopipe_decode nowait_key<enter>\
<shell-escape>notmuch-mutt -r --prompt search<enter>\
<change-folder-readonly>`echo ${XDG_CACHE_HOME:-$HOME/.cache}/notmuch/mutt/results`<enter>\
<enter-command>set pipe_decode=\$my_old_pipe_decode wait_key=\$my_old_wait_key<enter>" \
      "notmuch: rechercher courriel"
macro index <F9> \
"<enter-command>set my_old_pipe_decode=\$pipe_decode my_old_wait_key=\$wait_key nopipe_decode nowait_key<enter>\
<pipe-message>notmuch-mutt -r thread<enter>\
<change-folder-readonly>`echo ${XDG_CACHE_HOME:-$HOME/.cache}/notmuch/mutt/results`<enter>\
<enter-command>set pipe_decode=\$my_old_pipe_decode wait_key=\$my_old_wait_key<enter>" \
      "notmuch: reconstruire thread"
macro index <F6> \
"<enter-command>set my_old_pipe_decode=\$pipe_decode my_old_wait_key=\$wait_key nopipe_decode nowait_key<enter>\
<pipe-message>notmuch-mutt tag -- -inbox<enter>\
<enter-command>set pipe_decode=\$my_old_pipe_decode wait_key=\$my_old_wait_key<enter>" \
      "notmuch: retirer courriel de la boîte de réception"

La première macro (activée par <F8>) invite l'utilisateur à saisir des termes de recherche notmuch, puis saute vers un maildir temporaire affichant les résultats de la recherche. La deuxième macro (activée par <F9>) reconstruit le thread correspondant au courriel actuel et l'affiche comme résultats de recherche. La troisième macro (activée par <F6>) supprime le tag « inbox » du message actuel ; en modifiant « -inbox », cette macro peut être personnalisée pour ajouter ou supprimer des tags appropriés au flux de travail notmuch de l'utilisateur.

Pour maintenir l'index notmuch à jour, vous devriez alors exécuter périodiquement « notmuch new ». Selon votre configuration de messagerie locale, vous pourriez vouloir le faire via cron, comme un hook déclenché par la récupération des courriels, etc.
