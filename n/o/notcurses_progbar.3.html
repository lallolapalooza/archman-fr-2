NOM

notcurses_progbar - widget de haut niveau pour les barres de progression

SYNOPSIS

#include <notcurses/notcurses.h>

struct ncprogbar;
#define NCPROGBAR_OPTION_RETROGRADE        0x0001u // procéder à gauche/en bas
typedef struct ncprogbar_options {
  uint32_t ulchannel; // canal supérieur gauche. dans le contexte d'une barre de progression,
  uint32_t urchannel; // « haut » est la direction vers laquelle nous progressons, et
  uint32_t blchannel; // « bas » est la direction d'origine. pour une barre monochromatique
  uint32_t brchannel; // , les quatre canaux devraient être identiques.
  uint64_t flags;
} ncprogbar_options;

struct ncprogbar* ncprogbar_create(struct ncplane* n, const ncprogbar_options* opts)

struct ncplane* ncprogbar_plane(struct ncprogbar* n)

int ncprogbar_set_progress(struct ncprogbar* n, double p)

double ncprogbar_progress(const struct ncprogbar* n)

void ncprogbar_destroy(struct ncprogbar* n)

DESCRIPTION

Ces fonctions dessinent des barres de progression dans n'importe laquelle des quatre directions. La mesure de progression est un double compris entre zéro et un, inclus, fourni à ncprogbar_set_progress. Ceci sera mis à l'échelle de la taille du ncplane fourni n. L'axe de progression est l'élément le plus long de la géométrie du plan. Les barres horizontales progressent vers la droite par défaut, et les barres verticales progressent vers le haut. Ceci peut être modifié avec NCPROGBAR_OPTION_RETROGRADE.

NOTES

ncprogbar_create prend possession de n dans tous les cas. En cas d'échec, n sera détruit immédiatement. Il est par ailleurs détruit par ncprogbar_destroy.

VALEUR DE RETOUR

ncprogbar_plane renvoie le ncplane sur lequel la barre de progression est dessinée. ncprogbar_progress renvoie la progression actuelle, une valeur comprise entre zéro et un, inclus. Elles ne peuvent pas échouer.

ncprogbar_set_progress renvoie -1 si p est inférieur à zéro ou supérieur à un, ou s'il y a une erreur interne de redessin de la barre de progression. Elle renvoie 0 sinon.

BOGUES

Que la progression soit vers la gauche ou vers la droite par défaut devrait probablement être un aspect de la locale actuelle.

VOIR AUSSI

notcurses(3), notcurses_plane(3), notcurses_visual(3)
