NOM

notmuch-count - compte les messages correspondant aux termes de recherche donnés

SYNTAXE

notmuch count [option ...] <terme-de-recherche> ...

DESCRIPTION

Compte les messages correspondant aux termes de recherche.

Le nombre de messages (ou de fils) correspondants est affiché sur la sortie standard.

En l'absence de termes de recherche, un décompte de tous les messages (ou fils) de la base de données sera affiché.

Voir notmuch-search-terms pour les détails de la syntaxe prise en charge pour les <termes-de-recherche>.

Les options prises en charge pour count incluent :

--output=(messages|threads|files)
messages
Affiche le nombre de messages correspondants. C'est le comportement par défaut.
threads
Affiche le nombre de fils correspondants.
files
Affiche le nombre de fichiers associés aux messages correspondants. Ce nombre peut être supérieur au nombre de messages correspondants en raison des doublons (c'est-à-dire que plusieurs fichiers ont le même message-id).
--exclude=(true|false)
Spécifie s'il faut omettre les messages correspondant à search.exclude_tags du décompte (par défaut) ou non.
--batch
Lit les requêtes à partir d'un fichier (stdin par défaut), une par ligne, et affiche le nombre de messages (ou de fils) correspondants sur stdout, une par ligne. Sur une ligne d'entrée vide, le décompte de tous les messages (ou fils) de la base de données sera affiché. Cette option n'est pas compatible avec la spécification de termes de recherche sur la ligne de commande.
--lastmod
Ajoute lastmod (compteur pour le nombre de mises à jour de la base de données) et UUID à la sortie. Les valeurs de lastmod ne sont comparables qu'entre des bases de données ayant le même UUID.
--input=<nom_fichier>
Lit l'entrée à partir du fichier donné, au lieu de stdin. Implique --batch.
