NGETTEXT(3) Manuel des fonctions de bibliothèque NGETTEXT(3)

NOM

ngettext, dngettext, dcngettext - traduire un message et choisir la forme plurielle

SYNOPIS

#include <libintl.h>

char * ngettext (const char * msgid, const char * msgid_plural,
                 unsigned long int n);
char * dngettext (const char * domainname,
                  const char * msgid, const char * msgid_plural,
                  unsigned long int n);
char * dcngettext (const char * domainname,
                   const char * msgid, const char * msgid_plural,
                   unsigned long int n, int category);

DESCRIPTION

Les fonctions ngettext, dngettext et dcngettext tentent de traduire une chaîne de caractères dans la langue maternelle de l'utilisateur, en recherchant la forme plurielle appropriée de la traduction dans un catalogue de messages.

Les formes plurielles sont des variantes grammaticales dépendant d'un nombre. Certaines langues ont deux formes, appelées singulier et pluriel. D'autres langues ont trois formes, appelées singulier, duel et pluriel. Il existe également des langues avec quatre formes.

Les fonctions ngettext, dngettext et dcngettext fonctionnent respectivement comme les fonctions gettext, dgettext et dcgettext. De plus, elles choisissent la forme plurielle appropriée, qui dépend du nombre n et de la langue du catalogue de messages où la traduction a été trouvée.

Dans la locale « C », ou si aucun des catalogues utilisés ne contient une traduction pour msgid, les fonctions ngettext, dngettext et dcngettext retournent msgid si n == 1, ou msgid_plural si n != 1.

VALEUR DE RETOUR

Si une traduction a été trouvée dans l'un des catalogues spécifiés, la forme plurielle appropriée est convertie dans le jeu de caractères de la locale et retournée. La chaîne résultante est allouée statiquement et ne doit pas être modifiée ou libérée. Sinon, msgid ou msgid_plural est retourné, comme décrit ci-dessus.

ERREURS

errno n'est pas modifié.

BOGUES

Le type de retour devrait être const char *, mais est char * pour éviter les avertissements dans le code C antérieur à ANSI C.

VOIR AUSSI

gettext(3), dgettext(3), dcgettext(3)
