NGETTEXT(1) Commandes utilisateur NGETTEXT(1)

NOM

ngettext - traduire un message et choisir la forme plurielle

SYNTAXE

ngettext [OPTION] [TEXTDOMAIN] MSGID MSGID-PLURAL COUNT

DESCRIPTION

Le programme ngettext traduit un message en langue naturelle dans la langue de l'utilisateur, en recherchant la traduction dans un catalogue de messages, et choisit la forme plurielle appropriée, qui dépend du nombre COUNT et de la langue du catalogue de messages où la traduction a été trouvée.

Affiche la traduction en langue native d'un message textuel dont la forme grammaticale dépend d'un nombre.

Options et arguments :

-d, --domain=TEXTDOMAIN
récupérer le message traduit du TEXTDOMAIN
-c, --context=CONTEXT
spécifier le contexte pour MSGID
-e
activer l'expansion de certaines séquences d'échappement
-E
(ignoré pour des raisons de compatibilité)
[TEXTDOMAIN]
récupérer le message traduit du TEXTDOMAIN
MSGID MSGID-PLURAL
traduire MSGID (singulier) / MSGID-PLURAL (pluriel)
COUNT
choisir la forme singulier/pluriel en fonction de cette valeur

Sortie informative :

-h, --help
afficher cette aide et quitter
-V, --version
afficher les informations sur la version et quitter

Si le paramètre TEXTDOMAIN n'est pas donné, le domaine est déterminé à partir de la variable d'environnement TEXTDOMAIN. Si le catalogue de messages n'est pas trouvé dans le répertoire habituel, un autre emplacement peut être spécifié avec la variable d'environnement TEXTDOMAINDIR. Répertoire de recherche standard : /usr/share/locale
