NGSPICE(1) Manuel des commandes générales NGSPICE(1)

NOM

ngspice - simulateur de circuits dérivé de SPICE3f5

SYNTAXE

ngspice [options] [fichier ...]

DESCRIPTION

Cette page de manuel est juste un bref aperçu. La documentation principale de ngspice se trouve dans le Manuel de l'utilisateur ngspice, disponible sous forme de fichier pdf ou html.

OPTIONS

-n ou --no-spiceinit
Ne pas essayer de sourcer le fichier ".spiceinit" au démarrage. Normalement, ngspice essaie de trouver le fichier dans le répertoire courant, et s'il n'y est pas trouvé, alors dans le répertoire personnel de l'utilisateur.
-t term ou --term=term
Le programme est exécuté sur un terminal avec le nom mfb term.
-b ou --batch
Exécuter en mode batch. ngspice lira l'entrée standard ou le fichier d'entrée spécifié et effectuera la simulation. Notez que si l'entrée standard n'est pas un terminal, ngspice passera par défaut en mode batch, sauf si le drapeau -i est donné.
-s ou --server
Exécuter en mode serveur. C'est comme le mode batch, sauf qu'un fichier brut temporaire est utilisé puis écrit sur la sortie standard, précédé d'une ligne contenant un seul "@", après la fin de la simulation. Ce mode est utilisé par le démon ngspice.
-i ou --interactive
Exécuter en mode interactif. C'est utile si l'entrée standard n'est pas un terminal mais que le mode interactif est souhaité. La complétion des commandes n'est pas disponible sauf si l'entrée standard est un terminal, cependant.
-r rawfile ou --rawfile=fichier
Utiliser rawfile comme fichier par défaut dans lequel les résultats de la simulation sont sauvegardés.
-c circuitfile ou --circuitfile=circuitfile
Utiliser circuitfile comme jeu de circuits d'entrée par défaut.
-h ou --help
Afficher une aide détaillée sur les arguments disponibles pour le programme.
-v ou --version
Afficher le numéro de version et les informations de copyright du programme.
-a ou --autorun
FIXME
-o outfile ou --output=outfile
Tous les journaux générés pendant une exécution en mode batch (-b) seront sauvegardés dans outfile.
-p ou --pipe
Permettre à un programme (par exemple, xcircuit) d'agir comme une interface graphique pour ngspice via un tube. Ainsi, ngspice supposera que le tube est un tty et permettra de s'exécuter en mode interactif.

Les arguments supplémentaires sont considérés comme des jeux de circuits SPICE, qui sont lus et sauvegardés. (Si le mode batch est demandé, ils sont exécutés immédiatement.)

ENVIRONNEMENT

SPICE_LIB_DIR
SPICE_EXEC_DIR
SPICE_HOST
SPICE_BUGADDR
SPICE_EDITOR
SPICE_ASCIIRAWFILE par défaut 0
Format du fichier brut. 0 pour binaire, et 1 pour ascii.
SPICE_NEWS par défaut $SPICE_LIB_DIR/news
Un fichier qui est copié tel quel sur la sortie standard lorsque ngspice démarre en mode interactif.
SPICE_MFBCAP par défaut $SPICE_LIB_DIR/mfbcap
SPICE_HELP_DIR par défaut $SPICE_LIB_DIR/helpdir
SPICE_SCRIPTS par défaut $SPICE_LIB_DIR/scripts
Dans ce répertoire, le fichier spinit sera recherché.
SPICE_PATH par défaut $SPICE_EXEC_DIR/ngspice

Diverses variables d'environnement spécifiques à ngspice, non documentées :

NGSPICE_MEAS_PRECISION
SPICE_NO_DATASEG_CHECK

Variables d'environnement courantes :

TERM LINES COLS DISPLAY HOME PATH EDITOR SHELL
POSIXLY_CORRECT

FICHIERS

$SPICE_LIB_DIR/scripts/spinit
Fichier d'initialisation système.
.spiceinit ou $HOME/.spiceinit
Fichier d'initialisation utilisateur.
