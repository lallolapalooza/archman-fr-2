DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_selinux_get_device_context_cookie_t. Les erreurs doivent être gérées lors de l'appel de la fonction de réponse xcb_selinux_get_device_context_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_selinux_get_device_context_unchecked. Voir xcb-requests(3) pour les détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
