DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_alloc_named_color_cookie_t. Les erreurs doivent être gérées lors de l'appel à la fonction de réponse xcb_alloc_named_color_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_alloc_named_color_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
