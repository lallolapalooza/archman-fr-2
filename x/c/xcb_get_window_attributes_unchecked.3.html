DESCRIPTION

La fonction xcb_get_window_attributes récupère les attributs associés à la fenêtre spécifiée par window.

Les attributs retournés sont les suivants :

  • backing_store
  • visual
  • _class
  • bit_gravity
  • win_gravity
  • backing_planes
  • backing_pixel
  • save_under
  • map_is_installed
  • map_state
  • override_redirect
  • colormap
  • all_event_masks
  • your_event_mask
  • do_not_propagate_mask

Après avoir appelé xcb_get_window_attributes, vous devez appeler xcb_get_window_attributes_reply pour obtenir la réponse.

Le champ all_event_masks est un masque de tous les événements qui seront générés par le serveur pour cette fenêtre. Le champ your_event_mask est une copie de ce que vous avez défini dans le masque d'événements lorsque vous avez créé la fenêtre.

Le champ do_not_propagate_mask est un masque d'événements qui ne seront pas propagés vers les fenêtres parentes.

VALEUR DE RETOUR

Une structure xcb_get_window_attributes_cookie_t.

La fonction xcb_get_window_attributes_reply retourne une structure xcb_get_window_attributes_reply_t. En cas d'erreur, elle retourne NULL et définit le pointeur e.

Les erreurs possibles sont :

BadWindow
La valeur window n'est pas une fenêtre valide.

EXEMPLE

xcb_get_window_attributes_cookie_t cookie;
xcb_get_window_attributes_reply_t *reply;
xcb_connection_t *conn = xcb_connect (NULL, NULL);

/* Get attributes of the root window */
cookie = xcb_get_window_attributes (conn, xcb_setup_roots_iterator (xcb_get_setup (conn)).data->root);
reply = xcb_get_window_attributes_reply (conn, cookie, NULL);

if (reply) {
    printf ("Map state: %d\n", reply->map_state);
    free (reply);
}

xcb_disconnect (conn);
