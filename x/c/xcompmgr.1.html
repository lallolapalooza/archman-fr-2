xcompmgr(1) Manuel des commandes générales xcompmgr(1)

NOM

xcompmgr - gestionnaire de composition X d'exemple

SYNTAXE

xcompmgr [-d affichage] [-r rayon] [-o opacité] [-l décalage-gauche] [-t décalage-haut] [-acCfFnsS]

DESCRIPTION

xcompmgr est un gestionnaire de composition d'exemple pour les serveurs X prenant en charge les extensions XFIXES, DAMAGE et COMPOSITE. Il permet des effets visuels basiques.

OPTIONS

-d affichage
Spécifie l'affichage à gérer.
-r rayon
Spécifie le rayon du flou pour les ombres côté client.
-o opacité
Spécifie l'opacité pour les ombres côté client.
-l décalage-gauche
Spécifie le décalage gauche pour les ombres côté client.
-t décalage-haut
Spécifie le décalage haut pour les ombres côté client.
-I pas-fondu-entree
Spécifie le changement d'opacité entre les étapes lors du fondu en entrée.
-O pas-fondu-sortie
Spécifie le changement d'opacité entre les étapes lors du fondu en sortie.
-D delta-fondu
Spécifie le temps (en millisecondes) entre les étapes d'un fondu.
-a
Composition côté serveur automatique. Ceci demande au serveur d'utiliser les règles de composition standard. Utile pour le débogage.
-c
Composition côté client avec ombres douces et prise en charge de la translucidité.
-f
Lorsque -c est spécifié, active un effet de fondu fluide pour les fenêtres transitoires comme les menus, et pour toutes les fenêtres lors des événements de masquage et de restauration.
-n
Composition côté client simple. C'est le mode par défaut.
-s
Composition côté serveur avec ombres à bords nets.
-C
Lorsque -c est spécifié, tente d'éviter de peindre des ombres sur les panneaux et les docks.
-F
Lorsque -f est spécifié, active également l'effet de fondu lorsque les fenêtres changent leur opacité, comme avec transset(1).
-S
Active le fonctionnement synchrone. Utile pour le débogage.

BOGUES

Probablement. Veuillez signaler tout bogue trouvé à https://gitlab.freedesktop.org/xorg/app/xcompmgr/.
