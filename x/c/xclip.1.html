XCLIP(1) Manuel des commandes générales XCLIP(1)

NOM

xclip - interface en ligne de commande pour les sélections X (presse-papiers)

SYNTAXE

xclip [OPTION] [FICHIER]...

DESCRIPTION

Lit depuis l'entrée standard ou depuis un ou plusieurs fichiers et rend les données disponibles en tant que sélection X pour le collage dans des applications X. Affiche la sélection X actuelle sur la sortie standard.

-i, -in
lit le texte dans la sélection X depuis l'entrée standard ou les fichiers (par défaut)
-o, -out
affiche la sélection sur la sortie standard (généralement pour rediriger vers un fichier ou un programme)
-f, -filter
lorsque xclip est appelé en mode d'entrée avec le niveau de sortie en mode silencieux (par défaut), l'option filtre provoque l'affichage par xclip du texte transmis à l'entrée standard, inchangé, sur la sortie standard
-r, -rmlastnl
lorsque le dernier caractère de la sélection est un caractère de nouvelle ligne, le supprime. Les caractères de nouvelle ligne qui ne sont pas le dernier caractère de la sélection ne sont pas affectés. Si la sélection ne se termine pas par un caractère de nouvelle ligne, cette option n'a aucun effet. Cette option est utile pour copier la sortie sur une seule ligne de programmes comme pwd dans le presse-papiers afin de la coller à nouveau dans l'invite de commande sans exécuter la ligne immédiatement en raison du caractère de nouvelle ligne que pwd ajoute.
-l, -loops
nombre de requêtes de sélection X (collages dans des applications X) à attendre avant de quitter, avec une valeur de 0 (par défaut) faisant attendre à xclip un nombre illimité de requêtes jusqu'à ce qu'une autre application (éventuellement une autre invocation de xclip) prenne possession de la sélection
-t, -target
spécifie un format de données particulier en utilisant l'atome cible donné. Avec -o, l'atome cible spécial "TARGETS" peut être utilisé pour obtenir une liste des atomes cibles valides pour cette sélection. Pour plus d'informations sur les atomes cibles, référez-vous à la section 2.6.2 de l'ICCCM
-d, -display
affichage X à utiliser (par exemple, "localhost:0"), xclip utilise par défaut la valeur de $DISPLAY si cette option est omise
-h, -help
affiche un résumé rapide des options
-selection
spécifie quelle sélection X utiliser, les options sont "primary" pour utiliser XA_PRIMARY (par défaut), "secondary" pour XA_SECONDARY ou "clipboard" pour XA_CLIPBOARD
-version
affiche les informations de version
-silent
se détache en arrière-plan pour attendre les requêtes, aucune sortie informative, uniquement les erreurs (par défaut)
-quiet
affiche les messages informatifs sur le terminal et s'exécute au premier plan
-verbose
fournit un commentaire détaillé sur ce que fait xclip
-noutf8
fonctionne en mode hérité (c'est-à-dire non UTF-8) pour la compatibilité ascendante (Utilisez cette option uniquement lorsque cela est vraiment nécessaire, car le comportement précédent était défectueux)

xclip lit du texte depuis l'entrée standard ou des fichiers et le rend disponible pour d'autres applications X afin de le coller en tant que sélection X (traditionnellement avec le bouton du milieu de la souris). Il lit à partir de tous les fichiers spécifiés, ou de l'entrée standard si aucun fichier n'est spécifié. xclip peut également afficher le contenu d'une sélection sur la sortie standard avec l'option -o.

xclip a été conçu pour permettre une intégration plus étroite des applications X et des programmes en ligne de commande. L'action par défaut est d'attendre silencieusement en arrière-plan les requêtes de sélection X (collages) jusqu'à ce qu'une autre application X place des données dans le presse-papiers, auquel cas xclip se termine silencieusement. Vous pouvez utiliser l'option -verbose pour voir si et quand xclip reçoit effectivement des requêtes de sélection d'autres applications X.

Les options peuvent être abrégées tant qu'elles restent non ambiguës. Par exemple, il est possible d'utiliser -d ou -disp au lieu de -display. Cependant, -v ne pourrait pas être utilisé car il est ambigu (il pourrait être court pour -verbose ou -version), il serait donc interprété comme un nom de fichier.

Notez que seul le premier caractère de la sélection spécifiée avec l'option -selection est important. Cela signifie que "p", "sec" et "clip" auraient le même effet que d'utiliser "primary", "secondary" ou "clipboard" respectivement.

EXEMPLES

Je déteste les pages de manuel sans exemples !

uptime | xclip

Met votre temps de disponibilité dans la sélection X. Ensuite, faites un clic du milieu dans une application X pour coller.

xclip -loops 10 -verbose /etc/motd

Se termine après que /etc/motd (message du jour) ait été collé 10 fois. Affiche le nombre de requêtes de sélection (collages) traitées.

xclip -o > helloworld.c

Met le contenu de la sélection dans un fichier.

xclip -t text/html index.html

Faites un clic du milieu dans une application X prenant en charge le HTML pour coller le contenu du fichier donné en tant que HTML.

ENVIRONNEMENT

DISPLAY
Affichage X à utiliser si aucun n'est spécifié avec l'option -display.
