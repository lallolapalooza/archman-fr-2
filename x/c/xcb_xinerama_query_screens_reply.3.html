ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.

CHAMP DE LA RÉPONSE

response_type
Le type de cette réponse, dans ce cas XCB_XINERAMA_QUERY_SCREENS. Ce champ est également présent dans le xcb_generic_reply_t et peut être utilisé pour différencier les réponses les unes des autres.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
length
La longueur de la réponse, en mots (un mot fait 4 octets).
number

DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_xinerama_query_screens_cookie_t. Les erreurs doivent être gérées lors de l'appel à la fonction de réponse xcb_xinerama_query_screens_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_xinerama_query_screens_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS

Cette requête ne génère jamais d'erreurs.

VOIR AUSSI

AUTEUR

Généré à partir de xinerama.xml. Contactez xcb@lists.freedesktop.org pour les corrections et améliorations.
