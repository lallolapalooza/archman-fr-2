VALEUR DE RETOUR

Retourne un xcb_void_cookie_t. Les erreurs éventuelles doivent être gérées dans la boucle d'événements.

Si vous souhaitez gérer les erreurs directement avec xcb_request_check à la place, utilisez xcb_glx_set_client_info_arb_checked. Voir xcb-requests(3) pour plus de détails.
