Structure de données d'événement

typedef struct xcb_xkb_extension_device_notify_event_t {
    uint8_t         response_type;
    uint8_t         xkbType;
    uint16_t        sequence;
    xcb_timestamp_t time;
    uint8_t         deviceID;
    uint8_t         pad0;
    uint16_t        reason;
    uint16_t        ledClass;
    uint16_t        ledID;
    uint32_t        ledsDefined;
    uint32_t        ledState;
    uint8_t         firstButton;
    uint8_t         nButtons;
    uint16_t        supported;
    uint16_t        unsupported;
    uint8_t         pad1[2];
} xcb_xkb_extension_device_notify_event_t;

CHAMPS D'ÉVÉNEMENT

response_type
Le type de cet événement, dans ce cas XCB_XKB_EXTENSION_DEVICE_NOTIFY. Ce champ est également présent dans le xcb_generic_event_t et peut être utilisé pour différencier les événements.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
