XCONSOLE(1) Manuel des commandes générales XCONSOLE(1)

NOM

xconsole - surveiller les messages de la console système avec X

SYNTAXE

xconsole [-option-toolkit ...] [-fichier nom-fichier]
         [-notify|-nonotify] [-daemon] [-verbose]
         [-exitOnFail] [-stripNonprint] [-saveLines nombre]
xconsole -help
xconsole -version

DESCRIPTION

Le programme xconsole affiche les messages qui sont généralement envoyés à /dev/console.

OPTIONS

Xconsole accepte toutes les options de ligne de commande standard du X Toolkit ainsi que les options supplémentaires listées ci-dessous :

-fichier nom-fichier
Pour surveiller un autre périphérique, utilisez cette option pour spécifier le nom du périphérique. Cela ne fonctionne pas sur les fichiers ordinaires car ils sont toujours prêts à être lus.
-notify -nonotify
Lorsque de nouvelles données sont reçues de la console et que l'option notify est activée, le nom de l'icône de l'application se voit ajouter " *", de sorte qu'il soit visible même lorsque l'application est iconifiée. -notify est l'option par défaut.
-daemon
Cette option fait que xconsole se place en arrière-plan, en utilisant fork/exit.
-verbose
Lorsqu'elle est activée, cette option dirige xconsole pour afficher un message informatif sur la première ligne du tampon de texte.
-exitOnFail
Lorsqu'elle est activée, cette option dirige xconsole pour quitter lorsqu'il est incapable de rediriger la sortie de la console.
-stripNonprint
Lorsqu'elle est activée, cette option dirige xconsole pour ne pas inclure de caractères non imprimables dans la locale actuelle dans la sortie affichée.
-saveLines nombre
Lorsqu'elle est activée, xconsole ne conserve que nombre lignes de l'historique des messages au lieu d'augmenter le tampon de texte sans limite (un nombre de zéro - par défaut - est traité comme l'absence de limite sur l'historique).
-help
Cette option indique que xconsole doit afficher un message d'utilisation et quitter.
-version
Cette option indique que xconsole doit afficher sa version et quitter.

X PARAMÈTRES PAR DÉFAUT

Ce programme utilise le widget Athena Text, consultez la documentation Athena Widget Set pour le contrôler.

Xconsole accepte par ailleurs des ressources des mêmes noms que les options de ligne de commande (sans le tiret initial). "fichier" est de type string, "saveLines" un entier, et les autres options sont des booléens.

WIDGETS

Pour spécifier des ressources, il est utile de connaître la hiérarchie des widgets qui composent xconsole. Dans la notation ci-dessous, l'indentation indique la structure hiérarchique. Le nom de la classe du widget est donné en premier, suivi du nom de l'instance du widget.

XConsole  xconsole
     XConsole  text

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'affichage par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.

FICHIERS

/usr/share/X11/app-defaults/XConsole
spécifie les ressources requises

VOIR AUSSI

X(7), xrdb(1), widget Athena Text
