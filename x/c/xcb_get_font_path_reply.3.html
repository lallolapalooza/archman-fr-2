ARGUMENTS DE LA REQUÊTE

La connexion XCB à X11.

CHAMP DE RÉPONSE

response_type
Le type de cette réponse, dans ce cas XCB_GET_FONT_PATH. Ce champ est également présent dans le xcb_generic_reply_t et peut être utilisé pour distinguer les réponses les unes des autres.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.

DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_get_font_path_cookie_t. Les erreurs doivent être gérées lors de l'appel à la fonction de réponse xcb_get_font_path_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_get_font_path_unchecked. Voir xcb-requests(3) pour les détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
