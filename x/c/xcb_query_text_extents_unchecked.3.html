xcb_query_text_extents - obtenir les extensions de texte

DESCRIPTION

Interroge les extensions de texte auprès du serveur X11. Cette requête retourne la boîte englobante de la chaîne de caractères 16 bits spécifiée dans la police spécifiée ou dans la police contenue dans le contexte graphique spécifié.

font_ascent est réglé sur le maximum des métriques d'ascendance de tous les caractères de la chaîne. font_descent est réglé sur le maximum des métriques de descendance. overall_width est réglé sur la somme des métriques de largeur de caractère de tous les caractères de la chaîne. Pour chaque caractère de la chaîne, soit W la somme des métriques de largeur de caractère de tous les caractères qui le précèdent dans la chaîne. Soit L la métrique du portant gauche (left-side-bearing) du caractère plus W. Soit R la métrique du portant droit (right-side-bearing) du caractère plus W. Le membre lbearing est réglé sur le minimum de L pour tous les caractères de la chaîne. Le membre rbearing est réglé sur le maximum de R.

Pour les polices définies avec un indexation linéaire plutôt qu'une indexation matricielle 2 octets, chaque structure xcb_char2b_t est interprétée comme un nombre 16 bits où l'octet 1 est l'octet le plus significatif. Si la police n'a pas de caractère par défaut défini, les caractères non définis dans la chaîne ont des métriques nulles.

Les caractères avec des métriques toutes nulles sont ignorés. Si la police n'a pas de caractère par défaut défini, les caractères non définis dans la chaîne sont également ignorés.

VALEUR DE RETOUR

Retourne un xcb_query_text_extents_cookie_t. Les erreurs doivent être gérées lors de l'appel à la fonction de réponse xcb_query_text_extents_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_query_text_extents_unchecked. Voir xcb-requests(3) pour les détails.
