DESCRIPTION

The function xcb_xkb_get_map retrieves the keyboard mapping for the specified device.

The device_spec argument specifies the keyboard device. It can be XCB_XKB_ID_USE_CORE_KBD for the core keyboard, or a device ID.

The xkb_group argument specifies the group for which the mapping should be retrieved. Use XCB_XKB_GROUP_CURRENT to get the mapping for the current group.

The xkb_map_mask argument is a bitmask that specifies which parts of the map to retrieve. Possible values are:

XCB_XKB_MAP_PART_KEYCODES
Retrieve the keycode-to-keysym mapping.
XCB_XKB_MAP_PART_SYMBOLS
Retrieve the symbols mapping.
XCB_XKB_MAP_PART_IMPLICIT_SYMBOLS
Retrieve the implicit symbols mapping.
XCB_XKB_MAP_PART_GEOMETRY
Retrieve the geometry mapping.

The full argument, if non-zero, requests the entire map for the specified mask. If zero, only the parts explicitly requested by the mask are returned.

VALEUR DE RETOUR

Renvoie un xcb_xkb_get_map_cookie_t. Les erreurs doivent être gérées lors de l'appel de la fonction de réponse xcb_xkb_get_map_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_xkb_get_map_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
