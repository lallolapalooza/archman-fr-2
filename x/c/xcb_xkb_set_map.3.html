DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_void_cookie_t. Les erreurs éventuelles doivent être gérées dans la boucle d'événements.

Si vous souhaitez gérer les erreurs directement avec xcb_request_check au lieu de cela, utilisez xcb_xkb_set_map_checked. Voir xcb-requests(3) pour les détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
