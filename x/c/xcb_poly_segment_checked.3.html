NOM

xcb_poly_segment - dessiner des segments de droite

SYNTAXE

#include <xcb/xproto.h>

Fonction de requête

xcb_void_cookie_t xcb_poly_segment(xcb_connection_t *conn, xcb_drawable_t drawable, xcb_gcontext_t gc, uint32_t segments_len, const xcb_segment_t *segments);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
drawable
Un objet dessinable (fenêtre ou pixmap) sur lequel dessiner.
gc
Le contexte graphique à utiliser.

segments_len
Le nombre de structures xcb_segment_t dans segments.
segments
Un tableau de structures xcb_segment_t.

DESCRIPTION

Dessine plusieurs lignes non connectées. Pour chaque segment, une ligne est dessinée entre (x1, y1) et (x2, y2). Les lignes sont dessinées dans l'ordre indiqué dans le tableau de structures xcb_segment_t et ne réalisent pas de jonction aux extrémités coïncidentes. Pour une ligne donnée, un pixel n'est pas dessiné plus d'une fois. Si des lignes s'intersectent, les pixels d'intersection sont dessinés plusieurs fois.

VALEUR DE RETOUR

Retourne un xcb_void_cookie_t. Les erreurs (s'il y en a) doivent être gérées dans la boucle d'événements.

Si vous souhaitez gérer les erreurs directement avec xcb_request_check, utilisez xcb_poly_segment_checked. Voir xcb-requests(3) pour plus de détails.
