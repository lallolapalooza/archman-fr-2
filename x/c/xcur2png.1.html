XCUR2PNG(1) Manuel des commandes générales XCUR2PNG(1)

NOM

xcur2png - extrait des images PNG du fichier Xcursor et génère un fichier de configuration pour xcursorgen

SYNTAXE

xcur2png [ -V ] [ --version ]

xcur2png [ -h ] [ --help ]

xcur2png [ -c chemin-conf ] [ --conf=chemin-conf ] [ -d chemin-rep ] [ --directory=chemin-rep ] [ -i suffixe ] [ --initial-suffix=suffixe ] [ -q ] [ --quiet ] [ -n ] [ --dry-run ] fichier-Xcursor

DESCRIPTION

Xcur2png extrait des images PNG du fichier fichier-Xcursor et génère un fichier de configuration réutilisable par xcursorgen(1). Pour le dire simplement, c'est un convertisseur de curseur X en image PNG.

fichier-Xcursor est le chemin vers un fichier Xcursor existant. L'utilisation de plusieurs fichier-Xcursor n'est pas supportée. Les images PNG générées sont enregistrées dans le répertoire courant.

OPTIONS

-V, --version
Affiche le numéro de version et quitte avec le statut 0.
-h, --help
Affiche le message d'utilisation et quitte avec le statut 0.
-c chemin-conf, --conf=chemin-conf
Définit le chemin de sortie du fichier de configuration. Si "-" est spécifié, la sortie standard (stdout(3)) est utilisée. Si non spécifié, [nom du fichier de fichier-Xcursor].conf est utilisé. Si "chemin-conf" est un répertoire, le fichier de configuration est enregistré sous le répertoire spécifié sous le nom [nom du fichier de fichier-Xcursor].conf.
-d chemin-rep, --directory=chemin-rep
Définit le chemin d'un répertoire dans lequel les images PNG sont enregistrées. Si non spécifié, le répertoire courant est utilisé.
-i suffixe, --initial-suffix=suffixe
Définit le suffixe initial des images PNG à suffixe. suffixe doit être un entier positif et ne pas dépasser 999. Si le suffixe atteint 999, xcur2png quitte avec un statut négatif.
-q, --quiet
Supprime les messages de progression.
-n, --dry-run
Ne génère pas les images PNG ni les données de configuration dans des fichiers. Les données de configuration sont envoyées vers la sortie standard et les messages de progression sont supprimés.

STATUT DE SORTIE

xcur2png retourne le nombre d'images PNG générées si la conversion s'est terminée avec succès et que le fichier de configuration a été créé. En cas d'erreur, xcur2png retourne une valeur négative.
