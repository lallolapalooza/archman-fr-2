NOM

xcalib - Petit chargeur de calibration d'écran pour Xorg et Windows.

SYNTAXE

xcalib [-options] PROFILICC

DESCRIPTION

xcalib charge la balise 'vcgt' des profils ICC sur le serveur en utilisant l'extension XRandR/XVidMode/GDI afin de charger les courbes de calibration sur votre affichage.

OPTIONS

-d, -display <hote:dpy>
-s, -screen <ecran-#>
-c, -clear
-n, -noaction
-v, -verbose
-p, -printramps
-l, -loss
-i, -invert
-gc, -gammacor <gamma>
-b, -brightness <pourcentage>
-co, -contrast <pourcentage>
-red <gamma> <pourcentage-luminosite> <pourcentage-contraste>
-green <gamma> <pourcentage-luminosite> <pourcentage-contraste>
-blue <gamma> <pourcentage-luminosite> <pourcentage-contraste>
-a, -alter
-h, -help
-version

Le dernier paramètre DOIT être un profil ICC contenant une balise vcgt ou mLUT, ou être vide si le paramètre "-a" ou "-alter" est utilisé, ou si la LUT doit être effacée avec le paramètre "-c".

EXEMPLES

Assigner les courbes VCGT d'un profil ICC à un écran :
xcalib -d :0 -s 0 -v profil_avec_balise_vcgt.icc
Réinitialiser la LUT matérielle d'un écran pour effectuer une calibration :
xcalib -d :0 -s 0 -c
