ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
owner_events
Si 1, la grab_window recevra toujours les événements du pointeur. Si 0, les événements ne sont pas rapportés à la grab_window.
grab_window
Spécifie la fenêtre sur laquelle le pointeur doit être saisi.
event_mask
Spécifie quels événements du pointeur sont rapportés au client.

XCB_GRAB_MODE_ASYNC
Le traitement des événements du clavier continue normalement.
confine_to
Spécifie la fenêtre dans laquelle le pointeur doit être confiné (l'utilisateur ne pourra pas déplacer le pointeur hors de cette fenêtre).

La valeur spéciale XCB_NONE signifie ne pas confiner le pointeur.

cursor
Spécifie le curseur qui doit être affiché ou XCB_NONE pour ne pas changer le curseur.
time
L'argument de temps permet d'éviter certaines circonstances qui surviennent si les applications mettent du temps à répondre ou s'il y a de longs délais réseau. Considérons une situation où vous avez deux applications, qui saisissent toutes deux le pointeur lorsqu'on clique dessus. Si les deux applications spécifient le timestamp de l'événement, la seconde application peut se réveiller plus rapidement et réussir à saisir le pointeur avant la première application. La première application recevra alors une indication que l'autre application a saisi le pointeur avant que sa requête ne soit traitée.

La valeur spéciale XCB_CURRENT_TIME sera remplacée par l'heure actuelle du serveur.

DESCRIPTION

Saisit activement le contrôle du pointeur. Les événements du pointeur ultérieurs ne sont rapportés qu'au client saisissant. Remplace toute saisie de pointeur active par ce client.

VALEUR DE RETOUR

Retourne un xcb_grab_pointer_cookie_t. Les erreurs doivent être gérées lors de l'appel de la fonction de réponse xcb_grab_pointer_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements plutôt, utilisez xcb_grab_pointer_unchecked. Voir xcb-requests(3) pour les détails.

EXEMPLE

/*
 * Saisit activement le pointeur
 *
 */
void my_example(xcb_connection_t *conn, xcb_screen_t *screen, xcb_cursor_t cursor) {
    xcb_grab_pointer_cookie_t cookie;
    xcb_grab_pointer_reply_t *reply;
    cookie = xcb_grab_pointer(
        conn,
        false,               /* obtenir tous les événements du pointeur spécifiés par le masque suivant */
        screen->root,        /* saisir la fenêtre racine */
        XCB_NONE,            /* quels événements laisser passer */
        XCB_GRAB_MODE_ASYNC, /* les événements du pointeur doivent continuer normalement */
        XCB_GRAB_MODE_ASYNC, /* mode clavier */
        XCB_NONE,            /* confine_to = dans quelle fenêtre le curseur doit rester */
        cursor,              /* nous changeons le curseur pour celui souhaité par l'utilisateur */
        XCB_CURRENT_TIME
    );
    if ((reply = xcb_grab_pointer_reply(conn, cookie, NULL))) {
        if (reply->status == XCB_GRAB_STATUS_SUCCESS)
            printf("pointeur saisi avec succès\n");
        free(reply);
    }
}

NAME

xcb_grab_pointer – grab pointer

SYNOPSIS

DESCRIPTION

The xcb_grab_pointer function grabs control of the pointer. The pointer is a physical pointer device such as a mouse. Grabbing control means that all pointer events are reported to the grabbing client. The grab continues until the pointer is grabbed by another client, the grabbed client exits, or the grab is released. While the pointer is grabbed, events are reported according to the ownerEvents and event_mask parameters. The grab is automatically released when the grabbing client terminates. The grab is passive if d is set to XCB_NONE.

ownerEvents determines if the grabbing client gets pointer events. If ownerEvents is true, the grabbing client receives pointer events. If ownerEvents is false, pointer events are reported to other clients according to the event propagation rules and the event_mask parameter. However, if ownerEvents is false, pointer events are still sent to the grabbing client if the grabbing client is the owner of the grabbed window. In essence, pointer events are always sent to the client that owns the grabbed window.

d is the window that will be the grab window. If d is XCB_NONE, then the grab is passive. In a passive grab, the pointer events are reported to the clients that have selected for those events and are the owners of the grabbed window. The grab is active only when the pointer enters the grabbed window.

event_mask specifies which pointer events are reported to the grabbing client. This parameter is ignored if ownerEvents is true. See the X Protocol Reference Manual for a full list of events.

pointer_mode and keyboard_mode determine how pointer and keyboard events are reported to other clients. If pointer_mode is XCB_GRAB_MODE_GRAB, all pointer events are sent to the grabbing client. If pointer_mode is XCB_GRAB_MODE_ASYNC, pointer events are reported normally. If keyboard_mode is XCB_GRAB_MODE_GRAB, all keyboard events are sent to the grabbing client. If keyboard_mode is XCB_GRAB_MODE_ASYNC, keyboard events are reported normally. Note that the grabbing client may still not receive all events even if pointer_mode or keyboard_mode is XCB_GRAB_MODE_GRAB. This is because the grabbing client may not own the grabbed window.

confine_to is a window that restricts the pointer's movement. If confine_to is XCB_NONE, the pointer's movement is not restricted. The confine_to window must be on the same screen as the grab window d.

cursor is the cursor that is displayed while the pointer is grabbed. If cursor is XCB_NONE, the cursor does not change. The specified cursor must be a valid cursor resource ID.

time is the timestamp of the grab request. If time is XCB_CURRENT_TIME, the current server time is used.

The xcb_grab_pointer_reply function retrieves the reply to the xcb_grab_pointer request.

The xcb_grab_pointer_end function releases the pointer grab.

The xcb_grab_pointer_check_eintr function checks if the grab was interrupted by a signal.

RETURN VALUE

Returns a xcb_grab_pointer_cookie_t cookie. Use xcb_grab_pointer_reply to get the reply.

The xcb_grab_pointer_reply function returns a pointer to a xcb_grab_pointer_reply_t structure, or NULL if an error occurred.

The xcb_grab_pointer_end function returns 0 on success, or a negative value if an error occurred.

The xcb_grab_pointer_check_eintr function returns 1 if the grab was interrupted by a signal, 0 otherwise.

ERRORS

See xcb_grab_pointer_reply(3).

EXAMPLE

Grab the pointer for window my_window.

#include <xcb/xcb.h>

xcb_connection_t *c;
xcb_window_t my_window = XCB_NONE; // Replace with your window
xcb_cursor_t cursor;
xcb_grab_pointer_cookie_t cookie;
xcb_grab_pointer_reply_t *reply;
xcb_generic_error_t *error;

// Connect to the X server
c = xcb_connect(NULL, NULL);
if (xcb_connection_has_error(c)) {
    // Handle connection error
    return 1;
}

// Create a cursor (replace with a valid cursor ID)
// cursor = xcb_generate_id(c);
// xcb_create_glyph_cursor(c, cursor, ...)

// Grab the pointer
cookie = xcb_grab_pointer(c, 1, my_window, XCB_EVENT_MASK_BUTTON_PRESS | XCB_EVENT_MASK_POINTER_MOTION,
                          XCB_GRAB_MODE_ASYNC, XCB_GRAB_MODE_ASYNC, XCB_NONE, cursor, XCB_CURRENT_TIME);

// Get the reply
reply = xcb_grab_pointer_reply(c, cookie, &error);

if (reply) {
    if (reply->same_screen) {
        // Pointer grabbed successfully on the same screen
    } else {
        // Pointer grabbed on a different screen
    }
    free(reply);
} else {
    // Handle error
    if (error) {
        // Print error details
        free(error);
    }
}

// Release the grab
xcb_ungrab_pointer(c, XCB_CURRENT_TIME);

// Close the connection
xcb_disconnect(c);
