NOM

xcb_change_property - Change une propriété de fenêtre

SYNTAXE

#include <xcb/xproto.h>

Fonction de requête

xcb_void_cookie_t xcb_change_property(xcb_connection_t *conn, uint8_t mode, xcb_window_t window, xcb_atom_t property, xcb_atom_t type, uint8_t format, uint32_t data_len, const void *data);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
mode
Une des valeurs suivantes :
XCB_PROP_MODE_REPLACE
Supprime la valeur précédente de la propriété et stocke les nouvelles données.
XCB_PROP_MODE_PREPEND
Insère les nouvelles données avant le début des données existantes. Le format doit correspondre à la valeur de la propriété existante. Si la propriété n'est pas définie, elle est traitée comme définie avec le type et le format corrects et des données de longueur nulle.
XCB_PROP_MODE_APPEND
Insère les nouvelles données après le début des données existantes. Le format doit correspondre à la valeur de la propriété existante. Si la propriété n'est pas définie, elle est traitée comme définie avec le type et le format corrects et des données de longueur nulle.
window
La fenêtre dont vous voulez changer la propriété.
property
La propriété que vous voulez changer (un atome).
type
Le type de la propriété que vous voulez changer (un atome).
format
Spécifie si les données doivent être considérées comme une liste d'éléments de 8, 16 ou 32 bits. Les valeurs possibles sont 8, 16 et 32. Ces informations permettent au serveur X d'effectuer correctement les opérations de permutation d'octets si nécessaire.
data_len
Spécifie le nombre d'éléments (voir format).
data
Les données de la propriété.

DESCRIPTION

Définit ou met à jour une propriété sur la window spécifiée. Les propriétés sont par exemple le titre de la fenêtre (WM_NAME) ou sa taille minimale (WM_NORMAL_HINTS). Les protocoles tels qu'EWMH utilisent également des propriétés - par exemple, EWMH définit le titre de la fenêtre, encodé en chaîne UTF-8, dans la propriété _NET_WM_NAME.

VALEUR DE RETOUR

Retourne un xcb_void_cookie_t. Les erreurs (le cas échéant) doivent être gérées dans la boucle d'événements.

Si vous souhaitez gérer les erreurs directement avec xcb_request_check à la place, utilisez xcb_change_property_checked. Voir xcb-requests(3) pour les détails.

ERREURS

xcb_alloc_error_t
Le serveur X n'a pas pu stocker la propriété (pas de mémoire ?).
xcb_atom_error_t
property ou type ne font pas référence à un atome valide.
xcb_match_error_t
TODO : raisons ?
xcb_value_error_t
TODO : raisons ?
xcb_window_error_t
La window spécifiée n'existe pas.

EXEMPLE

/*
 * Définit la propriété WM_NAME de la fenêtre à "XCB Example".
 *
 */
void my_example(xcb_connection_t *conn, xcb_window_t window) {
    xcb_change_property(conn,
        XCB_PROP_MODE_REPLACE,
        window,
        XCB_ATOM_WM_NAME,
        XCB_ATOM_STRING,
        8,
        strlen("XCB Example"),
        "XCB Example");
    xcb_flush(conn);
}
