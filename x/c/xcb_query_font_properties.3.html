NOM

xcb_query_font - interroger les métriques de police

SYNOPSIS

#include <xcb/xproto.h>

Fonction de requête

xcb_query_font_cookie_t xcb_query_font(xcb_connection_t *conn, xcb_fontable_t font);

Structure de données de réponse

typedef struct xcb_query_font_reply_t {
    uint8_t        response_type;
    uint8_t        pad0;
    uint16_t       sequence;
    uint32_t       length;
    xcb_charinfo_t min_bounds;
    uint8_t        pad1[4];
    xcb_charinfo_t max_bounds;
    uint8_t        pad2[4];
    uint16_t       min_char_or_byte2;
    uint16_t       max_char_or_byte2;
    uint16_t       default_char;
    uint16_t       properties_len;
    uint8_t        draw_direction;
    uint8_t        min_byte1;
    uint8_t        max_byte1;
    uint8_t        all_chars_exist;
    int16_t        font_ascent;
    int16_t        font_descent;
    uint32_t       char_infos_len;
} xcb_query_font_reply_t;

Fonction de réponse

xcb_query_font_reply_t *xcb_query_font_reply(xcb_connection_t *conn, xcb_query_font_cookie_t cookie, xcb_generic_error_t **e);

Accesseurs de réponse

xcb_fontprop_t *xcb_query_font_properties(const xcb_query_font_request_t *reply);

int xcb_query_font_properties_length(const xcb_query_font_reply_t *reply);

xcb_fontprop_iterator_t xcb_query_font_properties_iterator(const xcb_query_font_reply_t *reply);

xcb_charinfo_t *xcb_query_font_char_infos(const xcb_query_font_request_t *reply);

int xcb_query_font_char_infos_length(const xcb_query_font_reply_t *reply);

xcb_charinfo_iterator_t xcb_query_font_char_infos_iterator(const xcb_query_font_reply_t *reply);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
font
La police (Font ou Graphics Context) à interroger.

CHAMPS DE RÉPONSE

response_type
Le type de cette réponse, dans ce cas XCB_QUERY_FONT. Ce champ est également présent dans xcb_generic_reply_t et peut être utilisé pour distinguer les réponses les unes des autres.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
length
La longueur de la réponse, en mots (un mot fait 4 octets).
min_bounds
limites minimales pour tous les caractères existants
max_bounds
limites maximales pour tous les caractères existants
min_char_or_byte2
premier caractère
max_char_or_byte2
dernier caractère
default_char
caractère à imprimer pour un caractère indéfini
properties_len
nombre de propriétés
draw_direction

DESCRIPTION

Interroge les informations associées à la police.

VALEUR DE RETOUR

Retourne un xcb_query_font_cookie_t. Les erreurs doivent être gérées lors de l'appel à la fonction de réponse xcb_query_font_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_query_font_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
