XCLIP-COPYFILE(1) Manuel des commandes générales XCLIP-COPYFILE(1)

NOM

xclip-copyfile, xclip-cutfile, xclip-pastefile - copier et déplacer des fichiers via le presse-papiers X

SYNTAXE

xclip-copyfile [-p] FICHIERS...

xclip-cutfile [-p] FICHIERS...

xclip-pastefile

DESCRIPTION

xclip-copyfile copie les fichiers dans le presse-papiers X, en parcourant les répertoires de manière récursive.

xclip-cutfile copie les fichiers, mais les supprime aussi ensuite.

-p
préserver la formation du chemin

xclip-pastefile colle les fichiers depuis le presse-papiers

EXEMPLES

Copier un fichier vers un hôte distant

[maggie.lkpg.cendio.se ~]$ echo "Un fichier créé sur ${HOSTNAME}" > fichier1
[maggie.lkpg.cendio.se ~]$ xclip-copyfile fichier1
[sofie.homeip.net ~/doc]$ xclip-pastefile
fichier1
[sofie.homeip.net ~/doc]$ cat fichier1
Un fichier créé sur maggie.lkpg.cendio.se
Copier une structure d'arborescence entière
[sofie.homeip.net ~]$ xclip-copyfile doc
[maggie.lkpg.cendio.se ~/tmp]$ xclip-pastefile
doc/
doc/lettre-maman-avril.txt
doc/fichier1
doc/lettre-papa-mars.txt
Copier des fichiers en préservant les informations de chemin
[maggie.lkpg.cendio.se ~]$ xclip-copyfile -p /etc/sysconfig/grub
tar: Suppression des préfixes de chemin `/` des noms de membres
[sofie.homeip.net ~/tmp]$ xclip-pastefile
etc/sysconfig/grub
[sofie.homeip.net ~/tmp]$ ls etc/sysconfig/grub
etc/sysconfig/grub
Déplacer des fichiers
[sofie.homeip.net ~]$ ls lettre-frere-mai.txt
lettre-frere-mai.txt
[sofie.homeip.net ~]$ xclip-cutfile lettre-frere-mai.txt
[sofie.homeip.net ~]$ ls lettre-frere-mai.txt
ls: impossible d'accéder à lettre-frere-mai.txt: Aucun fichier ou dossier de ce type
[sofie.homeip.net ~]$ cd doc
[sofie.homeip.net ~/doc]$ xclip-pastefile
lettre-frere-mai.txt
