xcb_randr_set_crtc_config_cookie_t xcb_randr_set_crtc_config(xcb_connection_t *conn, xcb_randr_crtc_t crtc, xcb_timestamp_t timestamp, xcb_timestamp_t config_timestamp, int16_t x, int16_t y, xcb_randr_mode_t mode, uint16_t rotation, uint32_t outputs_len, const xcb_randr_output_t *outputs);

DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_randr_set_crtc_config_cookie_t. Les erreurs doivent être gérées lors de l'appel de la fonction de réponse xcb_randr_set_crtc_config_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_randr_set_crtc_config_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
