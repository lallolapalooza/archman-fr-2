NOM

xcmsdb - Utilitaire de caractérisation des couleurs de périphérique pour le système de gestion des couleurs X (X Color Management System)

SYNTAXE

xcmsdb [ -query ] [ -remove ] [ -format 32|16|8 ] [ -help ] [ -version ] [ nom_fichier ]

DESCRIPTION

xcmsdb est utilisé pour charger, interroger ou supprimer les données de caractérisation des couleurs de périphérique stockées dans des propriétés sur la fenêtre racine de l'écran, comme spécifié dans la section 7, Caractérisation des couleurs de périphérique, de l'ICCCM. Les données de caractérisation des couleurs de périphérique (également appelées Profil de périphérique) sont une partie intégrante du système de gestion des couleurs X (Xcms) de Xlib, nécessaires à la conversion appropriée des spécifications de couleur entre les formes indépendantes et dépendantes du périphérique. Xcms utilise des matrices 3x3 stockées dans la propriété XDCCC_LINEAR_RGB_MATRICES pour convertir les spécifications de couleur entre CIEXYZ et l'intensité RVB (XcmsRGBi, également appelée RVB linéaire). Xcms utilise ensuite les informations de gamma d'affichage stockées dans la propriété XDCCC_LINEAR_RGB_CORRECTION pour convertir les spécifications de couleur entre RVBi et le RVB du périphérique (XcmsRGB, également appelé RVB du périphérique).

Notez que Xcms permet aux clients d'enregistrer des ensembles de fonctions en plus de son ensemble de fonctions intégré pour les moniteurs couleur CRT. Des ensembles de fonctions supplémentaires peuvent stocker leurs informations de profil de périphérique dans d'autres propriétés au format spécifique à l'ensemble de fonctions. Cet utilitaire n'est pas conscient de ces propriétés non standard.

Le contenu lisible en ASCII de nom_fichier (ou l'entrée standard si aucun fichier d'entrée n'est donné) est correctement transformé pour être stocké dans des propriétés, à condition que les options -query ou -remove ne soient pas spécifiées.

OPTIONS

Le programme xcmsdb accepte les options suivantes :

-query
Cette option tente de lire les propriétés XDCCC de la fenêtre racine de l'écran. En cas de succès, elle transforme les données dans un format plus lisible, puis envoie les données vers la sortie standard.
-remove
Cette option tente de supprimer les propriétés XDCCC sur la fenêtre racine de l'écran.
-format 32|16|8
Spécifie le format de la propriété (32, 16 ou 8 bits par entrée) pour la propriété XDCCC_LINEAR_RGB_CORRECTION. La précision des valeurs flottantes encodées augmente avec l'augmentation du nombre de bits par entrée. La valeur par défaut est 32 bits par entrée.
-help
Cette option affiche un résumé des options disponibles et quitte.
-version
Cette option affiche la version du programme et quitte.
