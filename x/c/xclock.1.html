XCLOCK(1) Manuel des commandes générales XCLOCK(1)

NOM

xclock - horloge analogique / numérique pour X

SYNOPSIS

xclock [ -help ] [ -analog | -digital ] [ -brief ] [ -chime ] [ -hd couleur ] [ -hl couleur ] [ -update secondes ] [ -strftime format ] [ -twelve | -twentyfour | -utime ] [ -padding nombre ] [ -norender ] [ -render ] [ -sharp ] [ -face motif ]

DESCRIPTION

Le programme xclock affiche l'heure sous forme analogique ou numérique. L'heure est mise à jour en continu à une fréquence spécifiable par l'utilisateur.

OPTIONS

Xclock accepte toutes les options standard de la ligne de commande X Toolkit ainsi que les options supplémentaires listées ci-dessous :

-help
Cette option indique qu'un résumé bref des options autorisées doit être imprimé sur la sortie d'erreur standard.
-analog
Cette option indique qu'un cadran d'horloge conventionnel de 12 heures avec des repères et des aiguilles doit être utilisé. C'est le défaut.
-digital ou -d
Cette option indique qu'une horloge numérique de 24 heures doit être utilisée.
-brief
Cette option indique que l'horloge numérique ne doit afficher que les champs des heures et des minutes. Le défaut est d'afficher l'heure complète et les informations de date.
-utime
Cette option indique qu'une horloge numérique doit afficher les secondes depuis l'Époque (au format « 970012340 secondes depuis l'Époque » au lieu d'une heure standard de 24 heures).
-strftime format
Cette option permet de spécifier une chaîne de format strftime(3) pour l'affichage de l'horloge numérique.
-twelve
Cette option indique qu'une horloge numérique doit afficher l'heure au format 12 heures. Ceci n'est effectif que pour l'affichage abrégé.
-twentyfour
Cette option indique qu'une horloge numérique doit afficher l'heure au format 24 heures. Ceci n'est effectif que pour l'affichage abrégé. C'est le défaut lorsqu'une horloge numérique est utilisée.
-chime
Cette option indique que l'horloge doit sonner une fois à la demi-heure et deux fois à l'heure.
-hands couleur (ou -hd couleur)
Cette option spécifie la couleur des aiguilles d'une horloge analogique. Le défaut est noir. Cette option est effectivement ignorée lorsque Xrender est utilisé.
-highlight couleur (ou -hl couleur)
Cette option spécifie la couleur des bords des aiguilles d'une horloge analogique, et n'est utile que sur les écrans couleur. Le défaut est noir. Cette option est effectivement ignorée lorsque Xrender est utilisé.
-update secondes
Cette option spécifie la fréquence en secondes à laquelle xclock doit mettre à jour son affichage. Si l'horloge est obstruée puis réexposée, elle sera mise à jour immédiatement. Une valeur de 30 secondes ou moins activera une trotteuse sur une horloge analogique. Le défaut est 60 secondes.
-padding nombre
Cette option spécifie la largeur en pixels de la marge entre le bord de la fenêtre et le texte ou l'image de l'horloge. Le défaut est 10 pour une horloge numérique et 8 pour une horloge analogique.
-render
Cette option indique à xclock d'utiliser l'extension Xrender pour dessiner un cadran anti-aliassé. C'est le défaut si xclock a été compilé avec le support Xrender. Notez que les options de sélection de couleur et les ressources utilisées lorsque Xrender est actif diffèrent des options standard.
-norender
Cette option désactive l'utilisation de Xrender pour dessiner l'horloge.
-sharp
Cette option indique à xclock d'utiliser des bords plus nets lorsqu'il dessine avec l'extension Xrender.
-face motif
Cette option spécifie la police à utiliser en mode numérique lorsque l'extension Xrender est utilisée. Les motifs sont spécifiés en utilisant le format de police de fontconfig décrit dans la section Noms de polices de fonts.conf(5).

DÉFAUTS X

Ce programme utilise le widget Clock. Il comprend toutes les appellations et classes de ressources de base ainsi que :

width (classe Width)
Spécifie la largeur de l'horloge. Le défaut pour les horloges analogiques est de 164 pixels ; le défaut pour les horloges numériques est ce qui est nécessaire pour contenir l'horloge lorsqu'elle est affichée dans la police choisie.
height (classe Height)
Spécifie la hauteur de l'horloge. Le défaut pour les horloges analogiques est de 164 pixels ; le défaut pour les horloges numériques est ce qui est nécessaire pour contenir l'horloge lorsqu'elle est affichée dans la police choisie.
update (classe Interval)
Spécifie la fréquence en secondes à laquelle l'heure doit être réaffichée.
foreground (classe Foreground)
Spécifie la couleur des repères. Le défaut dépend de si reverseVideo est spécifié. Si reverseVideo est spécifié, le défaut est lwhite, sinon le défaut est noir.
hands (classe Foreground)
Spécifie la couleur de l'intérieur des aiguilles de l'horloge. Le défaut dépend de si reverseVideo est spécifié. Si reverseVideo est spécifié, le défaut est lwhite, sinon le défaut est noir. Notez que cette ressource n'est pas utilisée lorsque Xrender est actif.
highlight (classe Foreground)
Spécifie la couleur utilisée pour mettre en évidence les aiguilles de l'horloge. Le défaut dépend de si reverseVideo est spécifié. Si reverseVideo est spécifié, le défaut est lwhite, sinon le défaut est noir. Notez que cette ressource n'est pas utilisée lorsque Xrender est actif.
analog (classe Boolean)
Spécifie si une horloge analogique doit être utilisée à la place d'une horloge numérique. Le défaut est Vrai.
twentyfour (classe Boolean)
Spécifie si une horloge numérique doit afficher l'heure au format 24 heures. Le défaut est Vrai.
chime (classe Boolean)
Spécifie si une sonnerie doit être utilisée à l'heure et à la demi-heure.
padding (classe Margin)
Spécifie la quantité de marge intérieure en pixels à utiliser. Le défaut est 8.
font (classe Font)
Spécifie la police à utiliser pour l'horloge numérique. Notez que les polices à largeur variable ne s'affichent actuellement pas toujours correctement. Cette police n'est utilisée que lorsque Xrender n'est pas actif.
render (classe Boolean)
Spécifie si l'extension Xrender doit être utilisée pour l'affichage. Le défaut est Vrai si xclock a été compilé avec le support Xrender.

Lorsque Xrender est actif, les ressources supplémentaires suivantes sont comprises :

face (classe FaceName)
Spécifie le motif de la police à utiliser pour l'horloge numérique lorsque Xrender est utilisé. Les motifs sont spécifiés en utilisant le format de police fontconfig décrit dans la section Noms de polices de fonts.conf(5).

OPTIONS

The following options are available for xclock:

-analog
Use analog clock display. This is the default.
-digital
Use digital clock display.
-chime
Causes the clock to chime on the hour.
-dials
Causes the clock to draw small tick marks for each minute.
-help
Print a usage message and exit.
-nftime
Use the specified time instead of the current system time. This option is intended for debugging and testing. The time should be specified in the format specified by the ctime(3) function. For example, “--nftime 'Tue Feb 17 10:51:17 1998'”.
-padding number
Sets the amount of padding around the clock to number pixels. Defaults to 10.
-render
Causes the clock to be rendered using 2-bit per pixel anti-aliased glyphs. This requires that the font being used has anti-aliased glyphs. It also requires that the Xft library be installed. See fonts.conf(5).
-sharp
Specifies if sharp edges should be used when rendering the clock. The default is False.
-buffer
Specifies that the updates of the image are drawn to a pixmap before copied into the window instead drawing them into the window directly.
-update number
Specifies the update frequency in seconds. The default is 60 seconds.
-rv
Use reverse video. This reverses the foreground and background colors.
-background color
Specifies the background color of the clock. Defaults to White.
-bw color
Specifies the color of the window border. Defaults to Black.
-fg color
Specifies the foreground color of the clock. Defaults to Black.
-fn fontname
Specifies the font to use for the clock display. Defaults to *-medium-r-*-120-*. The font must have the same number of pixels as the size of the clock. See fonts.conf(5).
-font fontname
Same as -fn.
-iconic
Start xclock in iconified (minimized) state.
-name name
Specifies the application name under which resources are obtained for xclock. Defaults to the name of the executable. This is useful for having multiple, differently configured clocks run simultaneously.
-geometry geometry
Specifies the desired shape and location of the window. See X(7).
-display display
Specifies the X server to use.
-overline color
Specifies the color of the overline for the digits.
-underline color
Specifies the color of the underline for the digits.
-justify justify
Specifies the justification of the text in digital mode. Valid values are left, right, or center.

X DEFAULTS

This program uses the standard X Input Method (XIM) and X Toolkit Intrinsics (XT) properties. See fonts.conf(5).

sharp (class Boolean)
Specifies if sharp edges should be used when rendering the clock. The default is False.
buffer (class Boolean)
Specifies that the updates of the image are drawn to a pixmap before copied into the window instead drawing them into the window directly.

The defaults of the following color resources depend on whether reverseVideo is specified. If reverseVideo is specified the default is lwhite, otherwise the default is black.

hourColor (class Foreground)
The color of the hour hand.
minuteColor (class Foreground)
The color of the minute hand.
secondColor (class Foreground)
The color of the second hand.
majorColor (class Foreground)
The color of the major scale ticks (i. e. each five minutes).
minorColor (class Foreground)
The color of the minor scale ticks (between major ticks).

WIDGETS

In order to specify resources, it is useful to know the hierarchy of the widgets which compose xclock. In the notation below, indentation indicates hierarchical structure. The widget class name is given first, followed by the widget instance name.

XClock  xclock
        Clock  clock

ENVIRONMENT

DISPLAY
to get the default host and display number.
XENVIRONMENT
to get the name of a resource file that overrides the global resources stored in the RESOURCE_MANAGER property.

FILES

/usr/share/X11/app-defaults/XClock
specifies required resources

SEE ALSO

X(7), xrdb(1), time(3), fonts.conf (5).

BUGS

Xclock believes the system clock.

When in digital mode, the string should be centered automatically.

-analog

-bw couleur

Identique à -fn.
-iconic
Démarre xclock dans un état icônifié (minimisé).

sharp (classe Booléen)
