DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_glx_get_query_objectuiv_arb_cookie_t. Les erreurs doivent être gérées lors de l'appel à la fonction de réponse xcb_glx_get_query_objectuiv_arb_reply.
