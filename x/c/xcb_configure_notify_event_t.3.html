NOM

xcb_configure_notify_event_t - PAS ENCORE DOCUMENTÉ

SYNOPSIS

#include <xcb/xproto.h>

Structure de données de l'événement

typedef struct xcb_configure_notify_event_t {
    uint8_t      response_type;
    uint8_t      pad0;
    uint16_t     sequence;
    xcb_window_t event;
    xcb_window_t window;
    xcb_window_t above_sibling;
    int16_t      x;
    int16_t      y;
    uint16_t     width;
    uint16_t     height;
    uint16_t     border_width;
    uint8_t      override_redirect;
    uint8_t      pad1;
} xcb_configure_notify_event_t;

CHAMPS DE L'ÉVÈNEMENT

response_type
Le type de cet événement, dans ce cas XCB_CONFIGURE_NOTIFY. Ce champ est également présent dans xcb_generic_event_t et peut être utilisé pour distinguer les événements les uns des autres.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
event
La fenêtre reconfigurée ou son parent, selon que StructureNotify ou SubstructureNotify a été sélectionné.
window
La fenêtre dont la taille, la position, la bordure et/ou l'ordre d'empilement a été modifié(e).
above_sibling
Si XCB_NONE, la window est en bas de la pile par rapport aux fenêtres sœurs. Cependant, si elle est définie sur une fenêtre sœur, la window est placée au-dessus de cette fenêtre sœur.
x
La coordonnée X du coin supérieur gauche extérieur de window, par rapport à l'origine de la fenêtre parente.
y
La coordonnée Y du coin supérieur gauche extérieur de window, par rapport à l'origine de la fenêtre parente.
width
La largeur intérieure de window, sans inclure la bordure.
height
La hauteur intérieure de window, sans inclure la bordure.
border_width
La largeur de la bordure de window.
override_redirect
Les gestionnaires de fenêtres doivent ignorer cette fenêtre si override_redirect vaut 1.
