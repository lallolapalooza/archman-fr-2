NOM

xcb_poly_line - dessiner des lignes

SYNTAXE

#include <xcb/xproto.h>

Fonction de requête

xcb_void_cookie_t xcb_poly_line(xcb_connection_t *conn, uint8_t coordinate_mode, xcb_drawable_t drawable, xcb_gcontext_t gc, uint32_t points_len, const xcb_point_t *points);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
coordinate_mode
Une des valeurs suivantes :
XCB_COORD_MODE_ORIGIN
Traite toutes les coordonnées comme relatives à l'origine.
XCB_COORD_MODE_PREVIOUS
Traite toutes les coordonnées après la première comme relatives à la coordonnée précédente.
drawable
L'élément dessinable sur lequel dessiner la ou les lignes.
gc
Le contexte graphique à utiliser.
points_len
Le nombre de structures xcb_point_t dans points.
points
Un tableau de points.

DESCRIPTION

Dessine points_len-1 lignes entre chaque paire de points (point[i], point[i+1]) dans le tableau points. Les lignes sont dessinées dans l'ordre indiqué dans le tableau. Elles se rejoignent correctement à tous les points intermédiaires, et si le premier et le dernier point coïncident, les première et dernière lignes se rejoignent également correctement. Pour une ligne donnée, un pixel n'est pas dessiné plus d'une fois. Si des lignes fines (largeur de ligne zéro) s'intersectent, les pixels d'intersection sont dessinés plusieurs fois. Si des lignes épaisses s'intersectent, les pixels d'intersection ne sont dessinés qu'une seule fois, comme si la requête entière était une forme unique et remplie.

VALEUR DE RETOUR

Retourne un xcb_void_cookie_t. Les erreurs (le cas échéant) doivent être gérées dans la boucle d'événements.

Si vous souhaitez gérer les erreurs directement avec xcb_request_check à la place, utilisez xcb_poly_line_checked. Voir xcb-requests(3) pour plus de détails.

EXEMPLE

/*
 * Dessiner une ligne droite.
 *
 */
void my_example(xcb_connection_t *conn, xcb_drawable_t drawable, xcb_gcontext_t gc) {
    xcb_poly_line(conn, XCB_COORD_MODE_ORIGIN, drawable, gc, 2,
                  (xcb_point_t[]) { {10, 10}, {100, 10} });
    xcb_flush(conn);
}
