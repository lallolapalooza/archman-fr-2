DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_test_get_version_cookie_t. Les erreurs doivent être gérées lors de l'appel de la fonction de réponse xcb_test_get_version_reply.

Si vous préférez gérer les erreurs dans la boucle d'événements, utilisez xcb_test_get_version_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
