NOM

xcb_grab_keyboard - Saisir le clavier

SYNOPSIS

#include <xcb/xproto.h>

Fonction de requête

xcb_grab_keyboard_cookie_t xcb_grab_keyboard(xcb_connection_t *conn, uint8_t owner_events, xcb_window_t grab_window, xcb_timestamp_t time, uint8_t pointer_mode, uint8_t keyboard_mode);

Structure de données de réponse

typedef struct xcb_grab_keyboard_reply_t {
    uint8_t  response_type;
    uint8_t  status;
    uint16_t sequence;
    uint32_t length;
} xcb_grab_keyboard_reply_t;

Fonction de réponse

xcb_grab_keyboard_reply_t *xcb_grab_keyboard_reply(xcb_connection_t *conn, xcb_grab_keyboard_cookie_t cookie, xcb_generic_error_t **e);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
owner_events
Si 1, la grab_window recevra toujours les événements du pointeur. Si 0, les événements ne sont pas rapportés à la grab_window.
grab_window
Spécifie la fenêtre sur laquelle le pointeur doit être saisi.
time
Horodatage pour éviter les conditions de concurrence lors de l'exécution de X sur le réseau.

La valeur spéciale XCB_CURRENT_TIME sera remplacée par l'heure actuelle du serveur.

pointer_mode
Une des valeurs suivantes :
XCB_GRAB_MODE_SYNC
L'état du clavier semble se figer : Aucune autre événement clavier n'est généré par le serveur jusqu'à ce que le client saisissant émette une requête AllowEvents de libération ou jusqu'à ce que la saisie du clavier soit relâchée.
XCB_GRAB_MODE_ASYNC
Le traitement des événements clavier continue normalement.
keyboard_mode
Une des valeurs suivantes :
XCB_GRAB_MODE_SYNC
L'état du clavier semble se figer : Aucune autre événement clavier n'est généré par le serveur jusqu'à ce que le client saisissant émette une requête AllowEvents de libération ou jusqu'à ce que la saisie du clavier soit relâchée.
XCB_GRAB_MODE_ASYNC
Le traitement des événements clavier continue normalement.

Le type de cette réponse, dans ce cas XCB_GRAB_KEYBOARD. Ce champ est également présent dans le xcb_generic_reply_t et peut être utilisé pour différencier les réponses.
sequence

length
La longueur de la réponse, en mots (un mot fait 4 octets).

DESCRIPTION

Saisit activement le contrôle du clavier et génère les événements FocusIn et FocusOut. Les événements clavier ultérieurs ne sont rapportés qu'au client saisissant.

Toute saisie de clavier active par ce client est remplacée. Si le clavier est activement saisi par un autre client, AlreadyGrabbed est renvoyé. Si grab_window n'est pas visible, GrabNotViewable est renvoyé. Si le clavier est gelé par une saisie active d'un autre client, GrabFrozen est renvoyé. Si l'heure spécifiée est antérieure à la dernière heure de saisie du clavier ou ultérieure à l'heure actuelle du serveur X, GrabInvalidTime est renvoyé. Sinon, la dernière heure de saisie du clavier est définie à l'heure spécifiée.

VALEUR DE RETOUR

Retourne un xcb_grab_keyboard_cookie_t. Les erreurs doivent être gérées lors de l'appel de la fonction de réponse xcb_grab_keyboard_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_grab_keyboard_unchecked. Voir xcb-requests(3) pour les détails.

EXEMPLE

/*
 * Saisit activement le clavier
 *
 */
void my_example(xcb_connection_t *conn, xcb_screen_t *screen) {
    xcb_grab_keyboard_cookie_t cookie;
    xcb_grab_keyboard_reply_t *reply;
    cookie = xcb_grab_keyboard(
        conn,
        true,                /* rapporter les événements */
        screen->root,        /* saisir la fenêtre racine */
        XCB_CURRENT_TIME,
        XCB_GRAB_MODE_ASYNC, /* traiter les événements normalement, ne pas exiger de synchronisation */
        XCB_GRAB_MODE_ASYNC
    );
    if ((reply = xcb_grab_keyboard_reply(conn, cookie, NULL))) {
        if (reply->status == XCB_GRAB_STATUS_SUCCESS)
            printf("clavier saisi avec succès\n");
        free(reply);
    }
}
