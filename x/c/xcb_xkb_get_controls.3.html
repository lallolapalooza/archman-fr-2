SYNTAXE

Fonction de requête

Structure de données de réponse

    uint32_t length;

    uint8_t  ignoreLockModsRealMods;
    uint8_t  pad0;
    uint16_t internalModsVmods;
    uint16_t ignoreLockModsVmods;
    uint16_t repeatDelay;
    uint16_t repeatInterval;
    uint16_t slowKeysDelay;
    uint16_t debounceDelay;

DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_xkb_get_controls_cookie_t. Les erreurs doivent être gérées lors de l'appel à la fonction de réponse xcb_xkb_get_controls_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_xkb_get_controls_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
