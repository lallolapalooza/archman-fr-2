NOM

xcb_copy_area - copier des zones

SYNTAXE

#include <xcb/xproto.h>

Fonction de requête

xcb_void_cookie_t xcb_copy_area(xcb_connection_t *conn, xcb_drawable_t src_drawable, xcb_drawable_t dst_drawable, xcb_gcontext_t gc, int16_t src_x, int16_t src_y, int16_t dst_x, int16_t dst_y, uint16_t width, uint16_t height);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
src_drawable
Le drawable source (Fenêtre ou Pixmap).
dst_drawable
Le drawable destination (Fenêtre ou Pixmap).
gc
Le contexte graphique à utiliser.
src_x
La coordonnée X source.
src_y
La coordonnée Y source.
dst_x
La coordonnée X destination.
dst_y
La coordonnée Y destination.
width
La largeur de la zone à copier (en pixels).
height
La hauteur de la zone à copier (en pixels).

DESCRIPTION

Copie le rectangle spécifié de src_drawable vers dst_drawable.

VALEUR DE RETOUR

Retourne un xcb_void_cookie_t. Les erreurs (le cas échéant) doivent être gérées dans la boucle d'événements.

Si vous souhaitez gérer les erreurs directement avec xcb_request_check à la place, utilisez xcb_copy_area_checked. Voir xcb-requests(3) pour les détails.

ERREURS

xcb_drawable_error_t
Le drawable spécifié (Fenêtre ou Pixmap) n'existe pas.
xcb_g_context_error_t
Le contexte graphique spécifié n'existe pas.
xcb_match_error_t
src_drawable a une racine ou une profondeur différente de dst_drawable.

VOIR AUSSI

xcb-requests(3)

AUTEUR

Généré à partir de xproto.xml. Contactez xcb@lists.freedesktop.org pour les corrections et améliorations.
