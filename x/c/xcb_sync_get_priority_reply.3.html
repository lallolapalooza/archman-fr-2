NOM

xcb_sync_get_priority -

SYNTAXE

#include <xcb/sync.h>

Fonction de requête

xcb_sync_get_priority_cookie_t xcb_sync_get_priority(xcb_connection_t *conn, uint32_t id);

Structure de données de réponse

typedef struct xcb_sync_get_priority_reply_t {
    uint8_t  response_type;
    uint8_t  pad0;
    uint16_t sequence;
    uint32_t length;
    int32_t  priority;
} xcb_sync_get_priority_reply_t;

Fonction de réponse

xcb_sync_get_priority_reply_t *xcb_sync_get_priority_reply(xcb_connection_t *conn, xcb_sync_get_priority_cookie_t cookie, xcb_generic_error_t **e);

ARGUMENTS DE LA REQUÊTE

CHAMPS DE LA RÉPONSE

response_type
Le type de cette réponse, dans ce cas XCB_SYNC_GET_PRIORITY. Ce champ est également présent dans le xcb_generic_reply_t et peut être utilisé pour distinguer les réponses les unes des autres.

Le numéro de séquence de la dernière requête traitée par le serveur X11.

DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_sync_get_priority_cookie_t. Les erreurs doivent être gérées lors de l'appel de la fonction de réponse xcb_sync_get_priority_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_sync_get_priority_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
