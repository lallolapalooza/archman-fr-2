NOM

xcb_unmap_notify_event_t - une fenêtre est démappée

SYNTAXE

#include <xcb/xproto.h>

Structure d'événement

typedef struct xcb_unmap_notify_event_t {
    uint8_t      response_type;
    uint8_t      pad0;
    uint16_t     sequence;
    xcb_window_t event;
    xcb_window_t window;
    uint8_t      from_configure;
    uint8_t      pad1[3];
} xcb_unmap_notify_event_t;

CHAMP DE L'ÉVÉNEMENT

response_type
Le type de cet événement, dans ce cas XCB_UNMAP_NOTIFY. Ce champ est également présent dans le xcb_generic_event_t et peut être utilisé pour distinguer les événements les uns des autres.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
event
La fenêtre reconfigurée ou son parent, selon que StructureNotify ou SubstructureNotify a été sélectionné.
window
La fenêtre qui a été démappée.
from_configure
Mis à 1 si l'événement a été généré suite au redimensionnement du parent de la fenêtre lorsque window avait un win_gravity de UnmapGravity.
