NOM

xcb_list_fonts_with_info - obtenir les noms de polices correspondants et les informations

SYNTAXE

#include <xcb/xproto.h>

Fonction de requête

xcb_list_fonts_with_info_cookie_t xcb_list_fonts_with_info(xcb_connection_t *conn, uint16_t max_names, uint16_t pattern_len, const char *pattern);

Structure de données de réponse

typedef struct xcb_list_fonts_with_info_reply_t {
    uint8_t        response_type;
    uint8_t        name_len;
    uint16_t       sequence;
    uint32_t       length;
    xcb_charinfo_t min_bounds;
    uint8_t        pad0[4];
    xcb_charinfo_t max_bounds;
    uint8_t        pad1[4];
    uint16_t       min_char_or_byte2;
    uint16_t       max_char_or_byte2;
    uint16_t       default_char;
    uint16_t       properties_len;
    uint8_t        draw_direction;
    uint8_t        min_byte1;
    uint8_t        max_byte1;
    uint8_t        all_chars_exist;
    int16_t        font_ascent;
    int16_t        font_descent;
    uint32_t       replies_hint;
} xcb_list_fonts_with_info_reply_t;

Fonction de réponse

xcb_list_fonts_with_info_reply_t *xcb_list_fonts_with_info_reply(xcb_connection_t *conn, xcb_list_fonts_with_info_cookie_t cookie, xcb_generic_error_t **e);

xcb_generic_iterator_t xcb_list_fonts_with_info_name_end(const xcb_list_fonts_with_info_reply_t *reply);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
max_names
Le nombre maximum de polices à retourner.
pattern_len
La longueur (en octets) de pattern.
pattern
Un modèle de police, par exemple "-misc-fixed-*".

L'astérisque (*) est un caractère générique pour un nombre quelconque de caractères. Le point d'interrogation (?) est un caractère générique pour un seul caractère. L'utilisation de majuscules ou de minuscules n'a pas d'importance.

CHAMPS DE RÉPONSE

response_type
Le type de cette réponse, dans ce cas XCB_LIST_FONTS_WITH_INFO. Ce champ est également présent dans xcb_generic_reply_t et peut être utilisé pour distinguer les réponses.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
length
La longueur de la réponse, en mots (un mot fait 4 octets).
name_len
Le nombre de noms de polices correspondants.
min_bounds
bornes minimales sur tous les caractères existants
max_bounds
bornes maximales sur tous les caractères existants
min_char_or_byte2
premier caractère
max_char_or_byte2
dernier caractère
default_char
caractère à imprimer pour les caractères indéfinis
properties_len
nombre de propriétés
draw_direction
L'une des valeurs suivantes :
XCB_FONT_DRAW_LEFT_TO_RIGHT
TODO : PAS ENCORE DOCUMENTÉ.
XCB_FONT_DRAW_RIGHT_TO_LEFT
TODO : PAS ENCORE DOCUMENTÉ.
min_byte1
TODO : PAS ENCORE DOCUMENTÉ.
max_byte1
TODO : PAS ENCORE DOCUMENTÉ.
all_chars_exist
indicateur si tous les caractères ont une taille non nulle
font_ascent
ligne de base vers le bord supérieur de l'image raster
font_descent
ligne de base vers le bord inférieur de l'image raster
replies_hint
Une indication du nombre de polices supplémentaires qui seront retournées. Ce n'est qu'un indice et il peut être supérieur ou inférieur au nombre de polices réellement retournées. Une valeur nulle ne garantit pas qu'aucune autre police ne sera retournée.

DESCRIPTION

Obtient une liste des noms de polices disponibles qui correspondent au pattern donné.

VALEUR DE RETOUR

Retourne un xcb_list_fonts_with_info_cookie_t. Les erreurs doivent être gérées lors de l'appel de la fonction de réponse xcb_list_fonts_with_info_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_list_fonts_with_info_unchecked. Voir xcb-requests(3) pour les détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
