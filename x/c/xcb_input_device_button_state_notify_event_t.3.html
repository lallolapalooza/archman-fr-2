SYNTAXE

#include <xcb/xinput.h>

Structure de données de l'événement

typedef struct xcb_input_device_button_state_notify_event_t {
    uint8_t  response_type;
    uint8_t  device_id;
    uint16_t sequence;
    uint8_t  buttons[28];
} xcb_input_device_button_state_notify_event_t;

CHAMP DE L'ÉVÉNEMENT

response_type
Le type de cet événement, ici XCB_INPUT_DEVICE_BUTTON_STATE_NOTIFY. Ce champ est également présent dans le xcb_generic_event_t et peut être utilisé pour distinguer les événements les uns des autres.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
device_id
NON ENCORE DOCUMENTÉ.
buttons
NON ENCORE DOCUMENTÉ.
