DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_query_best_size_cookie_t. Les erreurs doivent être gérées lors de l'appel de la fonction de réponse xcb_query_best_size_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_query_best_size_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
