NOM

xcb_set_input_focus - Définit le focus d'entrée

SYNTAXE

#include <xcb/xproto.h>

Fonction de requête

xcb_void_cookie_t xcb_set_input_focus(xcb_connection_t *conn, uint8_t revert_to, xcb_window_t focus, xcb_timestamp_t time);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
revert_to
Une des valeurs suivantes :
XCB_INPUT_FOCUS_NONE
Le focus est restauré à XCB_NONE, donc aucune fenêtre n'aura le focus d'entrée.
XCB_INPUT_FOCUS_POINTER_ROOT
Le focus est restauré respectivement à XCB_POINTER_ROOT. Lorsque le focus est restauré, des événements FocusIn et FocusOut sont générés, mais le temps du dernier changement de focus n'est pas modifié.
XCB_INPUT_FOCUS_PARENT
Le focus est restauré au parent (ou à l'ancêtre visible le plus proche) et la nouvelle valeur de revert_to est XCB_INPUT_FOCUS_NONE.
XCB_INPUT_FOCUS_FOLLOW_KEYBOARD
PAS ENCORE DOCUMENTÉ. Uniquement pertinent pour l'extension xinput.

Spécifie ce qui se passe lorsque la fenêtre de focus devient non visible (si focus n'est ni XCB_NONE ni XCB_POINTER_ROOT).

focus
La fenêtre à mettre en focus. Tous les événements clavier seront rapportés à cette fenêtre. La fenêtre doit être visible (TODO), sinon une erreur xcb_match_error_t survient (TODO).

Si focus est XCB_NONE (TODO), tous les événements clavier sont ignorés jusqu'à ce qu'une nouvelle fenêtre de focus soit définie.

Si focus est XCB_POINTER_ROOT (TODO), le focus est sur la fenêtre racine de l'écran sur lequel le pointeur se trouve actuellement.

time
Horodatage pour éviter les conditions de concurrence lors de l'exécution de X sur le réseau.

La valeur spéciale XCB_CURRENT_TIME sera remplacée par l'heure actuelle du serveur.

DESCRIPTION

Change le focus d'entrée et l'heure du dernier changement de focus. Si l'horodatage spécifié est antérieur à l'heure actuelle du dernier changement de focus, la requête est ignorée (pour éviter les conditions de concurrence lors de l'exécution de X sur le réseau).

Un événement FocusIn et FocusOut est généré lorsque le focus est changé.

VALEUR DE RETOUR

Retourne un xcb_void_cookie_t. Les erreurs (s'il y en a) doivent être gérées dans la boucle d'événements.

Si vous souhaitez gérer les erreurs directement avec xcb_request_check à la place, utilisez xcb_set_input_focus_checked. Voir xcb-requests(3) pour les détails.

ERREURS

xcb_match_error_t
La fenêtre de focus spécifiée n'est pas visible.
xcb_value_error_t
TODO : Raisons ?
xcb_window_error_t
La fenêtre de focus spécifiée n'existe pas.
