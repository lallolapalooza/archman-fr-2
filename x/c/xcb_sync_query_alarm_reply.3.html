VALEUR DE RETOUR

Retourne une xcb_sync_query_alarm_cookie_t. Les erreurs doivent être gérées lors de l'appel à la fonction de réponse xcb_sync_query_alarm_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_sync_query_alarm_unchecked. Voir xcb-requests(3) pour plus de détails.
