xcb_shm_completion_event_t(3) Événements XCB xcb_shm_completion_event_t(3)

NOM

xcb_shm_completion_event_t - Rapporte qu'une requête XCB_SHM_PUT_IMAGE est terminée

SYNTAXE

#include <xcb/shm.h>

Structure de données de l'événement

typedef struct xcb_shm_completion_event_t {
    uint8_t        response_type;
    uint8_t        pad0;
    uint16_t       sequence;
    xcb_drawable_t drawable;
    uint16_t       minor_event;
    uint8_t        major_event;
    uint8_t        pad1;
    xcb_shm_seg_t  shmseg;
    uint32_t       offset;
} xcb_shm_completion_event_t;

CHAMP DE L'ÉVÉNEMENT

response_type
Le type de cet événement, dans ce cas XCB_SHM_COMPLETION. Ce champ est également présent dans le xcb_generic_event_t et peut être utilisé pour différencier les événements entre eux.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
drawable
Le drawable utilisé dans la requête XCB_SHM_PUT_IMAGE.
minor_event
Le sous-code d'événement utilisé dans la requête. Toujours XCB_SHM_PUT_IMAGE.
major_event
Le code d'événement principal utilisé dans la requête. Toujours le code d'événement de l'extension MIT-SHM.
shmseg
Le segment de mémoire partagée utilisé dans la requête.
offset
L'offset dans le segment de mémoire partagée utilisé dans la requête.

DESCRIPTION

Ceci est généré par le serveur X pour signaler qu'une requête XCB_SHM_PUT_IMAGE a été traitée avec succès.

VOIR AUSSI

xcb_generic_event_t(3)

AUTEUR

Généré à partir de shm.xml. Contactez xcb@lists.freedesktop.org pour les corrections et améliorations.
