XCOLOR(1) Manuel des commandes générales XCOLOR(1)

NOM

xcolor - sélecteur de couleurs léger pour X11

SYNTAXE

xcolor [-f NOM | -c FORMAT] [-s [SÉLECTION]] [-S ÉCHELLE] [-P TAILLE_PRÉVISUALISATION] [-v] [-h]

DESCRIPTION

xcolor est un sélecteur de couleurs léger pour X11. Utilisez la souris pour sélectionner les couleurs visibles n'importe où sur l'écran afin d'obtenir leur représentation RVB.

Par défaut, la couleur sélectionnée est imprimée sur la sortie standard.

OPTIONS

-f NOM, --format NOM
Spécifier le format de sortie. Les valeurs possibles pour NOM sont hex, HEX, hex!, HEX!, rgb, et plain. Voir la section FORMATAGE pour une explication des différentes options de formatage. Entre en conflit avec --custom.
-c FORMAT, --custom FORMAT
Spécifier un modèle pour le format de sortie personnalisé. Voir la section FORMATAGE PERSONNALISÉ pour une explication de la syntaxe des modèles. Entre en conflit avec --format.
-s [SÉLECTION], --selection [SÉLECTION]
Sauvegarder la sortie dans une sélection X11. Les valeurs possibles pour SÉLECTION sont clipboard, primary et secondary. Si SÉLECTION n'est pas fournie, clipboard est utilisée.
-S, --scale
Facteur d'échelle de grossissement du sélecteur, par défaut 8
-P, --preview-size
Taille en pixels du sélecteur, par défaut 255
-v, --version
Afficher les informations de version et quitter.
-h, --help
Afficher le message d'aide et quitter.

FORMATAGE

Par défaut, les valeurs de couleur sont imprimées au format hexadécimal en minuscules. Le format de sortie peut être modifié en utilisant l'option --format NOM. Les valeurs possibles pour NOM sont :

hex
Hexadécimal en minuscules (par défaut)
HEX
Hexadécimal en majuscules
hex!
Hexadécimal compact en minuscules
HEX!
Hexadécimal compact en majuscules
rgb
RVB décimal
plain
Décimal avec des séparateurs point-virgule

La forme compacte fait référence aux codes de couleur CSS à trois lettres tels que spécifiés par le module CSS Color Module Level 3. Si la couleur n'est pas exprimable sous la forme à trois lettres, la forme régulière à six lettres sera utilisée.

FORMATAGE PERSONNALISÉ

L'option --format offre un accès rapide à certaines options de formatage couramment utilisées. Cependant, si un format de sortie personnalisé est désiré, cela peut être réalisé en utilisant l'option --custom FORMAT. Le paramètre FORMAT spécifie un modèle pour la sortie et prend en charge un langage de modèle simple. Les modèles FORMAT peuvent contenir des expansions spéciales écrites entre des blocs %{...}. Ces blocs seront étendus en valeurs de couleur selon les spécificateurs définis à l'intérieur du bloc. Voici des exemples de chaînes de format valides et ce à quoi elles pourraient correspondre :

Chaîne de format Exemple de sortie
%{r}, %{g}, %{b} 255, 0, 100
Green: %{-4g} Green: ---7
#%{02hr}%{02hg}%{02hb} #00ff00
%{016Br} 0000000000000011

Les blocs d'expansion dans les chaînes de format contiennent toujours un spécificateur de canal (r pour rouge, g pour vert, et b pour bleu). De plus, ils peuvent contenir un spécificateur de format de nombre optionnel (h pour hexadécimal en minuscules, H pour hexadécimal en majuscules, o pour octal, B pour binaire, et d pour décimal) et un spécificateur de remplissage optionnel consistant en un caractère à utiliser pour le remplissage et la longueur à laquelle la chaîne doit être remplie. Le schéma ci-dessous illustre comment nous pouvons utiliser ces règles pour décoder un modèle de formatage :

%{016Br}
  | |||
  | ||`- Canal (rouge)
  | |`-- Spécificateur de format de nombre (binaire)
  | `--- Longueur de remplissage (16)
  `----- Caractère à utiliser pour le remplissage (0)

La sortie est le contenu du canal de couleur rouge formaté en binaire et rempli avec des zéros pour avoir une longueur de seize caractères.

ENVIRONNEMENT

XCOLOR_FOREGROUND
Désactive le mode démon. En raison de la manière dont les sélections fonctionnent dans X11, xcolor se détache en arrière-plan lorsque le mode --selection est utilisé. Ce comportement peut être désactivé en définissant la variable d'environnement XCOLOR_FOREGROUND.
