NOM

xcb_damage_notify_event_t - le contenu du dessin surveillé a changé

SYNTAXE

#include <xcb/damage.h>

Structure de données de l'événement

typedef struct xcb_damage_notify_event_t {
    uint8_t             response_type;
    uint8_t             level;
    uint16_t            sequence;
    xcb_drawable_t      drawable;
    xcb_damage_damage_t damage;
    xcb_timestamp_t     timestamp;
    xcb_rectangle_t     area;
    xcb_rectangle_t     geometry;
} xcb_damage_notify_event_t;

CHAMP DE L'ÉVÉNEMENT

response_type
Le type de cet événement, ici XCB_DAMAGE_NOTIFY. Ce champ est également présent dans le xcb_generic_event_t et peut être utilisé pour différencier les événements les uns des autres.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
level
Le niveau des dommages signalés. Si le bit 0x80 est défini, cela indique qu'il y a des événements de dommages subséquents livrés immédiatement dans le cadre d'une région de dommages plus grande.
drawable
Le dessin pour lequel des dommages sont signalés.
damage
L'objet de dommages utilisé pour suivre les dommages.
timestamp
Heure de génération de l'événement (en millisecondes).
area
Zone endommagée du dessin.
geometry
Zone totale du dessin.
