NOM

xchm - Visionneuse de fichiers Compiled HTML Help (CHM) pour X.

SYNTAXE

xchm [OPTIONS] [FICHIER]

DESCRIPTION

xchm est une visionneuse de fichiers Compiled HTML Help (CHM). Elle peut afficher l'arbre des contenus s'il est disponible, imprimer la page actuelle et effectuer les manipulations habituelles de l'historique. Elle vous permet de changer les polices et de rechercher du texte dans toutes les pages du fichier, ou dans les titres des pages.

xchm ne gère pas Javascript dans le livre.

OPTIONS

-c, --contextid=<num>
ID de contexte à ouvrir dans le fichier, nécessite qu'un fichier soit spécifié.
-h, --help
affiche le message d'aide et quitte.
