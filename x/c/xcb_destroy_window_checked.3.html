NOM

xcb_destroy_window - Détruit une fenêtre

SYNOPSIS

#include <xcb/xproto.h>

Fonction de requête

xcb_void_cookie_t xcb_destroy_window(xcb_connection_t *conn, xcb_window_t window);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
window
La fenêtre à détruire.

DESCRIPTION

Détruit la fenêtre spécifiée et toutes ses sous-fenêtres. Un événement DestroyNotify est généré pour chaque fenêtre détruite (un événement DestroyNotify est d'abord généré pour les inférieurs d'une fenêtre donnée). Si la fenêtre était visible, elle sera automatiquement masquée avant d'être détruite.

Appeler DestroyWindow sur la fenêtre racine ne fera rien.

VALEUR DE RETOUR

Retourne un xcb_void_cookie_t. Les erreurs (le cas échéant) doivent être gérées dans la boucle d'événements.

Si vous souhaitez gérer les erreurs directement avec xcb_request_check à la place, utilisez xcb_destroy_window_checked. Voir xcb-requests(3) pour les détails.

ERREURS

xcb_window_error_t
La fenêtre spécifiée n'existe pas.

VOIR AUSSI
