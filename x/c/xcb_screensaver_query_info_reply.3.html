SYNOPSIS

DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_screensaver_query_info_cookie_t. Les erreurs doivent être gérées lors de l'appel de la fonction de réponse xcb_screensaver_query_info_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_screensaver_query_info_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
