DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_get_image_cookie_t. Les erreurs doivent être gérées lors de l'appel de la fonction de réponse xcb_get_image_reply.

Si vous préférez gérer les erreurs dans la boucle d'événements, utilisez xcb_get_image_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
