NOM

xcb_get_geometry - Obtenir la géométrie actuelle d'une fenêtre

SYNTAXE

#include <xcb/xproto.h>

Fonction de requête

xcb_get_geometry_cookie_t xcb_get_geometry(xcb_connection_t *conn, xcb_drawable_t drawable);

Structure de données de réponse

typedef struct xcb_get_geometry_reply_t {
    uint8_t      response_type;
    uint8_t      depth;
    uint16_t     sequence;
    uint32_t     length;
    xcb_window_t root;
    int16_t      x;
    int16_t      y;
    uint16_t     width;
    uint16_t     height;
    uint16_t     border_width;
    uint8_t      pad0[2];
} xcb_get_geometry_reply_t;

Fonction de réponse

xcb_get_geometry_reply_t *xcb_get_geometry_reply(xcb_connection_t *conn, xcb_get_geometry_cookie_t cookie, xcb_generic_error_t **e);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
drawable
L'objet dessinable (fenêtre ou pixmap) dont la géométrie sera reçue.

CHAMPS DE LA RÉPONSE

response_type
Le type de cette réponse, ici XCB_GET_GEOMETRY. Ce champ est aussi présent dans le xcb_generic_reply_t et peut être utilisé pour distinguer les réponses les unes des autres.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
length
La longueur de la réponse, en mots (un mot fait 4 octets).
depth
La profondeur de l'objet dessinable (bits par pixel de l'objet).
root
La fenêtre racine de l'écran contenant drawable.
x
La coordonnée X de drawable. Si drawable est une fenêtre, la coordonnée spécifie le coin extérieur supérieur gauche par rapport à l'origine de son parent. Si drawable est un pixmap, la coordonnée X est toujours 0.
y
La coordonnée Y de drawable. Si drawable est une fenêtre, la coordonnée spécifie le coin extérieur supérieur gauche par rapport à l'origine de son parent. Si drawable est un pixmap, la coordonnée Y est toujours 0.
width
La largeur de drawable.
height
La hauteur de drawable.
border_width
La largeur de la bordure (en pixels).

DESCRIPTION

Obtient la géométrie actuelle de l'objet dessinable spécifié (soit une fenêtre, soit un pixmap).

VALEUR DE RETOUR

Retourne un xcb_get_geometry_cookie_t. Les erreurs doivent être gérées lors de l'appel à la fonction de réponse xcb_get_geometry_reply.

Si vous préférez gérer les erreurs dans la boucle d'événements, utilisez xcb_get_geometry_unchecked. Voir xcb-requests(3) pour plus de détails.

EXEMPLE

/*
 * Affiche la position x et y de la fenêtre donnée.
 *
 */
void my_example(xcb_connection_t *c, xcb_window_t window) {
    xcb_get_geometry_cookie_t cookie;
    xcb_get_geometry_reply_t *reply;
    cookie = xcb_get_geometry(c, window);
    /* ... faites d'autres tâches ici si possible ... */
    if ((reply = xcb_get_geometry_reply(c, cookie, NULL))) {
        printf("Cette fenêtre est à %d, %d\n", reply->x, reply->y);
    }
    free(reply);
}
