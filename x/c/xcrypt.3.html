XCRYPT(3) Manuel des fonctions de bibliothèque XCRYPT(3)

NOM

xencrypt, xdecrypt, passwd2des - chiffrement de mot de passe RFS

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <rpc/des_crypt.h>
void passwd2des(char *passwd, char *key);
int xencrypt(char *secret, char *passwd);
int xdecrypt(char *secret, char *passwd);

DESCRIPTION

AVERTISSEMENT : N'utilisez pas ces fonctions dans du nouveau code. Elles n'offrent aucune garantie de sécurité cryptographique acceptable.

La fonction passwd2des() prend une chaîne de caractères passwd de longueur arbitraire et remplit un tableau de caractères key de longueur 8. Le tableau key est adapté à une utilisation comme clé DES. Il a la parité impaire définie dans le bit 0 de chaque octet. Les deux autres fonctions décrites ici utilisent cette fonction pour transformer leur argument passwd en une clé DES.

La fonction xencrypt() prend la chaîne de caractères ASCII secret donnée en hexadécimal, qui doit avoir une longueur multiple de 16, la chiffre en utilisant la clé DES dérivée de passwd par passwd2des(), et renvoie le résultat à nouveau dans secret sous forme d'une chaîne hexadécimale de même longueur.

La fonction xdecrypt() effectue l'opération inverse.

VALEUR DE RETOUR

Les fonctions xencrypt() et xdecrypt() retournent 1 en cas de succès et 0 en cas d'erreur.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
passwd2des (), xencrypt (), xdecrypt () Thread safety MT-Safe

VERSIONS

Ces fonctions sont disponibles depuis glibc 2.1.

Les prototypes sont manquants dans le fichier d'en-tête mentionné ci-dessus.
