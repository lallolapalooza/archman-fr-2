DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_set_modifier_mapping_cookie_t. Les erreurs doivent être gérées lors de l'appel à la fonction de réponse xcb_set_modifier_mapping_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_set_modifier_mapping_unchecked. Voir xcb-requests(3) pour les détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
