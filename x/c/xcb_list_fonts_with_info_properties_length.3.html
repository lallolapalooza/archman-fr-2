ARGUMENTS DE LA REQUÊTE

La longueur (en octets) de pattern.
pattern
Un modèle de police, par exemple "-misc-fixed-*".

L'astérisque (*) est un joker pour un nombre quelconque de caractères. Le point d'interrogation (?) est un joker pour un seul caractère. L'utilisation de majuscules ou de minuscules n'a pas d'importance.

DESCRIPTION

Obtient une liste des noms de polices disponibles qui correspondent au pattern donné.

Retourne un xcb_list_fonts_with_info_cookie_t. Les erreurs doivent être gérées lors de l'appel de la fonction de réponse xcb_list_fonts_with_info_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_list_fonts_with_info_unchecked. Voir xcb-requests(3) pour plus de détails.

xcb_list_fonts_with_info_length(3)

NAME

xcb_list_fonts_with_info — list fonts with information

SYNOPSIS

#include <xcb/xcb.h>

int xcb_list_fonts_with_info (xcb_connection_t *connection, uint16_t max_names, uint16_t max_bytes, const char *pattern);

REQUEST ARGUMENTS

connection
The XCB connection to the X server.
max_names
The maximum number of font names to return.
max_bytes
The maximum number of bytes for the font names to return.
pattern
A pattern string to match font names against.

REPLY FIELDS

type
The XCB structure type for the reply.
sequence
The sequence number of the request.
length
The length of the reply.
names_len
The number of font names returned.
min_bounds
A structure containing the minimum bounds of the returned fonts.
max_bounds
A structure containing the maximum bounds of the returned fonts.
left_side_bearing
The left side bearing of the returned fonts.
right_side_bearing
The right side bearing of the returned fonts.
width
The width of the returned fonts.
height
The height of the returned fonts.
font_ascent
The font ascent of the returned fonts.
font_descent
The font descent of the returned fonts.

DESCRIPTION

The xcb_list_fonts_with_info function requests a list of fonts from the X server that match the given pattern. It also retrieves information about each font, such as its bounding box, advance width, and ascent/descent.

The connection parameter is the XCB connection to the X server. The max_names and max_bytes parameters limit the number of font names and the total number of bytes to return, respectively. The pattern parameter is a string that can contain wildcards (`*` and `?`) to match font names.

RETURN VALUE

Returns an xcb_list_fonts_with_info_reply_t *. The caller must free this reply using free. If there is an error, NULL is returned.

ERRORS

XCB_MATCH font pattern does not match any fonts.
