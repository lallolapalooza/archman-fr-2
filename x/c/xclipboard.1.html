NOM

xclipboard - client du presse-papiers X

SYNTAXE

xclipboard [ -option-toolkit ... ] [ -w ] [ -nw ]

DESCRIPTION

Le programme xclipboard est utilisé pour collecter et afficher les sélections de texte envoyées au CLIPBOARD par d'autres clients. Il est généralement utilisé pour sauvegarder les sélections CLIPBOARD pour une utilisation ultérieure. Il stocke chaque sélection CLIPBOARD comme une chaîne distincte, chacune pouvant être sélectionnée. Chaque fois que le CLIPBOARD est asserté par une autre application, xclipboard transfère le contenu de cette sélection vers un nouveau tampon et l'affiche dans la fenêtre de texte. Les tampons ne sont jamais supprimés automatiquement, vous voudrez donc utiliser le bouton de suppression pour vous débarrasser des éléments inutiles.

Étant donné que xclipboard utilise un widget Texte pour afficher le contenu du presse-papiers, le texte envoyé au CLIPBOARD peut être re-sélectionné pour être utilisé dans d'autres applications. xclipboard répond également aux requêtes de sélection CLIPBOARD d'autres clients en envoyant le contenu complet du tampon actuellement affiché.

Une fenêtre xclipboard a les boutons suivants en haut :

quitter
Lorsque ce bouton est pressé, xclipboard se termine.
supprimer
Lorsque ce bouton est pressé, le tampon courant est supprimé et le suivant est affiché.
nouveau
Crée un nouveau tampon sans contenu. Utile pour construire manuellement une nouvelle sélection CLIPBOARD.
sauvegarder
Affiche une boîte de dialogue de sauvegarde de fichier. Appuyer sur le bouton Accepter sauvegarde le tampon actuellement affiché dans le fichier spécifié dans le champ texte.
suivant
Affiche le tampon suivant dans la liste.
precedent
Affiche le tampon précédent.

OPTIONS

Le programme xclipboard accepte toutes les options de ligne de commande standard de X Toolkit ainsi que les suivantes :

-w
Cette option indique que les lignes de texte trop longues pour être affichées sur une seule ligne dans le presse-papiers doivent passer à la ligne suivante.
-nw
Cette option indique que les longues lignes de texte ne doivent pas passer à la ligne. C'est le comportement par défaut.

ENVOI/RÉCUPÉRATION DU CONTENU DU PRESSE-PAPIERS

Le texte est copié dans le presse-papiers chaque fois qu'un client affirme la propriété de la sélection CLIPBOARD. Le texte est copié depuis le presse-papiers chaque fois qu'un client demande le contenu de la sélection CLIPBOARD. Des exemples de liaisons d'événements qu'un utilisateur pourrait vouloir inclure dans un fichier de configuration de ressources pour utiliser le presse-papiers sont :

*VT100.Translations: #override \
        <Btn3Up>:       select-end(CLIPBOARD) \n\
        <Btn2Up>:       insert-selection(PRIMARY,CLIPBOARD) \n\
        <Btn2Down>:     ignore ()

VOIR AUSSI

X(7), xcutsel(1), xterm(1), la documentation du client individuel pour savoir comment faire une sélection et l'envoyer au CLIPBOARD.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'affichage par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.

FICHIERS
