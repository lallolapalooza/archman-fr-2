NOM

xcb_grab_pointer - Saisir le pointeur

SYNOPSIS

#include <xcb/xproto.h>

Fonction de requête

xcb_grab_pointer_cookie_t xcb_grab_pointer(xcb_connection_t *conn, uint8_t owner_events, xcb_window_t grab_window, uint16_t event_mask, uint8_t pointer_mode, uint8_t keyboard_mode, xcb_window_t confine_to, xcb_cursor_t cursor, xcb_timestamp_t time);

Structure de données de réponse

typedef struct xcb_grab_pointer_reply_t {
    uint8_t  response_type;
    uint8_t  status;
    uint16_t sequence;
    uint32_t length;
} xcb_grab_pointer_reply_t;

Fonction de réponse

xcb_grab_pointer_reply_t *xcb_grab_pointer_reply(xcb_connection_t *conn, xcb_grab_pointer_cookie_t cookie, xcb_generic_error_t **e);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
owner_events
Si 1, la grab_window recevra toujours les événements du pointeur. Si 0, les événements ne sont pas rapportés à la grab_window.
grab_window
Spécifie la fenêtre sur laquelle le pointeur doit être saisi.
event_mask
Spécifie quels événements du pointeur sont rapportés au client.

pointer_mode
Une des valeurs suivantes :
XCB_GRAB_MODE_SYNC
L'état du clavier semble se figer : aucun événement clavier supplémentaire n'est généré par le serveur jusqu'à ce que le client saisissant émette une requête AllowEvents de libération ou jusqu'à ce que la saisie clavier soit libérée.
XCB_GRAB_MODE_ASYNC
Le traitement des événements clavier continue normalement.
keyboard_mode
Une des valeurs suivantes :
XCB_GRAB_MODE_SYNC
L'état du clavier semble se figer : aucun événement clavier supplémentaire n'est généré par le serveur jusqu'à ce que le client saisissant émette une requête AllowEvents de libération ou jusqu'à ce que la saisie clavier soit libérée.
XCB_GRAB_MODE_ASYNC
Le traitement des événements clavier continue normalement.
confine_to
Spécifie la fenêtre dans laquelle confiner le pointeur (l'utilisateur ne pourra pas déplacer le pointeur en dehors de cette fenêtre).

La valeur spéciale XCB_NONE signifie de ne pas confiner le pointeur.

cursor
Spécifie le curseur qui doit être affiché ou XCB_NONE pour ne pas changer le curseur.
time
L'argument time vous permet d'éviter certaines circonstances qui surviennent si les applications répondent lentement ou s'il y a des délais réseau importants. Considérez une situation où vous avez deux applications, toutes deux saisissent généralement le pointeur lorsqu'elles sont cliquées. Si les deux applications spécifient l'horodatage de l'événement, la deuxième application peut se réveiller plus rapidement et réussir à saisir le pointeur avant la première application. La première application recevra alors une indication que l'autre application a saisi le pointeur avant que sa requête ne soit traitée.

La valeur spéciale XCB_CURRENT_TIME sera remplacée par l'heure actuelle du serveur.

sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
length
La longueur de la réponse, en mots (un mot fait 4 octets).

DESCRIPTION

Saisit activement le contrôle du pointeur. Les événements de pointeur ultérieurs ne sont rapportés qu'au client saisissant. Remplace toute saisie de pointeur active par ce client.

VALEUR DE RETOUR

Retourne un xcb_grab_pointer_cookie_t. Les erreurs doivent être gérées lors de l'appel à la fonction de réponse xcb_grab_pointer_reply.

Si vous préférez gérer les erreurs dans la boucle d'événements, utilisez xcb_grab_pointer_unchecked. Voir xcb-requests(3) pour plus de détails.

EXEMPLE

/*
 * Saisit activement le pointeur
 *
 */
void my_example(xcb_connection_t *conn, xcb_screen_t *screen, xcb_cursor_t cursor) {
    xcb_grab_pointer_cookie_t cookie;
    xcb_grab_pointer_reply_t *reply;
    cookie = xcb_grab_pointer(
        conn,
        false,               /* obtenir tous les événements du pointeur spécifiés par le masque suivant */
        screen->root,        /* saisir la fenêtre racine */
        XCB_NONE,            /* quels événements laisser passer */
        XCB_GRAB_MODE_ASYNC, /* les événements du pointeur doivent continuer normalement */
        XCB_GRAB_MODE_ASYNC, /* mode clavier */
        XCB_NONE,            /* confine_to = dans quelle fenêtre le curseur doit rester */
        cursor,              /* nous changeons le curseur pour celui souhaité par l'utilisateur */
        XCB_CURRENT_TIME
    );
    if ((reply = xcb_grab_pointer_reply(conn, cookie, NULL))) {
        if (reply->status == XCB_GRAB_STATUS_SUCCESS)
            printf("pointeur saisi avec succès\n");
        free(reply);
    }
}

NAME

xcb_grab_keyboard — grab keyboard

SYNOPSIS

xcb_grab_keyboard(
    xcb_connection_t *conn,
    xcb_window_tgrab_window,
    xcb_timestamp_ttime
);

REQUEST ARGUMENTS

conn
The XCB connection to the X server.
grab_window
The window on which to grab the keyboard.
time
The time parameter is a timestamp.

REPLY FIELDS

None

DESCRIPTION

Grabs the keyboard, effective until the grab is released. The pointer is also grabbed, as if this thread also specified the pointer window, time, and the XCB_GRAB_MODE_GRAB mode for the pointer.

RETURN VALUE

Returns an xcb_grab_keyboard_cookie_t. The actual value of the reply needs to be retrieved by calling xcb_grab_keyboard_reply.

ERRORS

The grab can fail if the keyboard is already grabbed, or if the window specified by grab_window is not valid.

EXAMPLE

This is an example of how to grab the keyboard.

    xcb_grab_keyboard_cookie_t
    xcb_grab_keyboard_checked(xcb_connection_t *conn, xcb_window_t grab_window,
                              xcb_timestamp_t time);
