NOM

xcb_create_glyph_cursor - créer un curseur

SYNTAXE

#include <xcb/xproto.h>

Fonction de requête

xcb_void_cookie_t xcb_create_glyph_cursor(xcb_connection_t *conn, xcb_cursor_t cid, xcb_font_t source_font, xcb_font_t mask_font, uint16_t source_char, uint16_t mask_char, uint16_t fore_red, uint16_t fore_green, uint16_t fore_blue, uint16_t back_red, uint16_t back_green, uint16_t back_blue);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
cid
L'identifiant auquel vous ferez référence pour le curseur, créé par xcb_generate_id.
source_font
Dans quelle police rechercher le glyphe du curseur.
mask_font
Dans quelle police rechercher le glyphe du masque.
source_char
Le glyphe de source_font à utiliser.
mask_char
Le glyphe de mask_font à utiliser comme masque : les pixels qui sont à 1 définissent quels pixels sources sont affichés. Tous les pixels qui sont à 0 ne sont pas affichés.
fore_red
La valeur rouge de la couleur de premier plan.
fore_green
La valeur verte de la couleur de premier plan.
fore_blue
La valeur bleue de la couleur de premier plan.
back_red
La valeur rouge de la couleur d'arrière-plan.
back_green
La valeur verte de la couleur d'arrière-plan.
back_blue
La valeur bleue de la couleur d'arrière-plan.

DESCRIPTION

Crée un curseur à partir d'un glyphe de police. X fournit un ensemble de formes de curseurs standard dans une police spéciale nommée cursor. Les applications sont encouragées à utiliser cette interface pour leurs curseurs car la police peut être personnalisée pour le type d'affichage individuel.

Tous les pixels qui sont à 1 dans la source utiliseront la couleur de premier plan (spécifiée par fore_red, fore_green et fore_blue). Tous les pixels à 0 utiliseront la couleur d'arrière-plan (spécifiée par back_red, back_green et back_blue).

VALEUR DE RETOUR

Retourne un xcb_void_cookie_t. Les erreurs (s'il y en a) doivent être gérées dans la boucle d'événements.

Si vous souhaitez gérer les erreurs directement avec xcb_request_check à la place, utilisez xcb_create_glyph_cursor_checked. Voir xcb-requests(3) pour les détails.

ERREURS

xcb_alloc_error_t
Le serveur X n'a pas pu allouer les ressources demandées (pas assez de mémoire?).
xcb_font_error_t
Les polices source_font ou mask_font spécifiées n'existent pas.
xcb_value_error_t
Soit source_char, soit mask_char ne sont pas définis dans source_font ou mask_font, respectivement.

VOIR AUSSI
