CHAMP DE L'ÉVÉNEMENT

response_type
Le type de cet événement, dans ce cas XCB_CONFIGURE_REQUEST. Ce champ est également présent dans le xcb_generic_event_t et peut être utilisé pour distinguer les événements les uns des autres.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
