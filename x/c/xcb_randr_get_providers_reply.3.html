NOM

xcb_randr_get_providers -

SYNTAXE

#include <xcb/randr.h>

Fonction de requête

xcb_randr_get_providers_cookie_t xcb_randr_get_providers(xcb_connection_t *conn, xcb_window_t window);

Structure de données de réponse

typedef struct xcb_randr_get_providers_reply_t {
    uint8_t         response_type;
    uint8_t         pad0;
    uint16_t        sequence;
    uint32_t        length;
    xcb_timestamp_t timestamp;
    uint16_t        num_providers;
    uint8_t         pad1[18];
} xcb_randr_get_providers_reply_t;

DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_randr_get_providers_cookie_t. Les erreurs doivent être gérées lors de l'appel de la fonction de réponse xcb_randr_get_providers_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_randr_get_providers_unchecked. Voir xcb-requests(3) pour les détails.

ERREURS

Cette requête ne génère jamais d'erreurs.

AUTEUR
