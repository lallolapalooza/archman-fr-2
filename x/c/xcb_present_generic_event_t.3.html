NOM

xcb_present_generic_event_t -

SYNTAXE

#include <xcb/present.h>

Structure de données de l'événement

typedef struct xcb_present_generic_event_t {
    uint8_t             response_type;
    uint8_t             extension;
    uint16_t            sequence;
    uint32_t            length;
    uint16_t            evtype;
    uint8_t             pad0[2];
    xcb_present_event_t event;
} xcb_present_generic_event_t;

CHAMP DE L'ÉVÉNEMENT

response_type
Le type de cet événement, dans ce cas XCB_PRESENT_GENERIC. Ce champ est également présent dans xcb_generic_event_t et peut être utilisé pour distinguer les événements les uns des autres.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
extension
NON ENCORE DOCUMENTÉ.

NON ENCORE DOCUMENTÉ.

NON ENCORE DOCUMENTÉ.

NON ENCORE DOCUMENTÉ.
