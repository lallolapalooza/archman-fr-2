DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_xkb_get_map_cookie_t. Les erreurs doivent être gérées lors de l'appel à la fonction de réponse xcb_xkb_get_map_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_xkb_get_map_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS

Cette requête ne génère jamais d'erreurs.

VOIR AUSSI

AUTEUR

Généré à partir de xkb.xml. Contactez xcb@lists.freedesktop.org pour les corrections et améliorations.
