xcb_get_property(3) Requêtes XCB xcb_get_property(3)

NOM

xcb_get_property - Obtient une propriété de fenêtre

SYNTAXE

#include <xcb/xproto.h>

Fonction de requête

xcb_get_property_cookie_t xcb_get_property(xcb_connection_t *conn, uint8_t _delete, xcb_window_t window, xcb_atom_t property, xcb_atom_t type, uint32_t long_offset, uint32_t long_length);

Structure de données de réponse

typedef struct xcb_get_property_reply_t {
    uint8_t    response_type;
    uint8_t    format;
    uint16_t   sequence;
    uint32_t   length;
    xcb_atom_t type;
    uint32_t   bytes_after;
    uint32_t   value_len;
    uint8_t    pad0[12];
} xcb_get_property_reply_t;

Fonction de réponse

xcb_get_property_reply_t *xcb_get_property_reply(xcb_connection_t *conn, xcb_get_property_cookie_t cookie, xcb_generic_error_t **e);

Accesseurs de réponse

void *xcb_get_property_value(const xcb_get_property_request_t *reply);

int xcb_get_property_value_length(const xcb_get_property_reply_t *reply);

xcb_generic_iterator_t xcb_get_property_value_end(const xcb_get_property_reply_t *reply);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
_delete
Indique si la propriété doit effectivement être supprimée. Pour supprimer une propriété, le type spécifié doit correspondre au type réel de la propriété.
window
La fenêtre dont vous souhaitez obtenir la propriété.
property
La propriété que vous souhaitez obtenir (un atome).
type
Le type de la propriété que vous souhaitez obtenir (un atome).
long_offset
Spécifie le décalage (en multiples de 32 bits) dans la propriété spécifiée où les données doivent être récupérées.
long_length
Spécifie combien de multiples de 32 bits de données doivent être récupérés (par exemple, si vous définissez long_length à 4, vous recevrez 16 octets de données).

CHAMP DE LA RÉPONSE

response_type
Le type de cette réponse, dans ce cas XCB_GET_PROPERTY. Ce champ est également présent dans xcb_generic_reply_t et peut être utilisé pour distinguer les réponses entre elles.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
length
La longueur de la réponse, en mots (un mot fait 4 octets).
format
Spécifie si les données doivent être vues comme une liste d'éléments de 8, 16 ou 32 bits. Les valeurs possibles sont 8, 16 et 32. Ces informations permettent au serveur X d'effectuer correctement les opérations d'échange d'octets si nécessaire.
type
Le type réel de la propriété (un atome).
bytes_after
Le nombre d'octets restants à lire dans la propriété si une lecture partielle a été effectuée.
value_len
La longueur de la valeur. Vous devriez utiliser l'accesseur correspondant à la place de ce champ.

DESCRIPTION

Obtient la propriété spécifiée de la window spécifiée. Les propriétés sont, par exemple, le titre de la fenêtre (WM_NAME) ou sa taille minimale (WM_NORMAL_HINTS). Les protocoles tels que EWMH utilisent également des propriétés - par exemple, EWMH définit le titre de la fenêtre, codé en chaîne UTF-8, dans la propriété _NET_WM_NAME.

VALEUR DE RETOUR

Retourne un xcb_get_property_cookie_t. Les erreurs doivent être gérées lors de l'appel à la fonction de réponse xcb_get_property_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_get_property_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS

xcb_atom_error_t
property ou type ne font pas référence à un atome valide.
xcb_value_error_t
Le long_offset spécifié est au-delà de la longueur réelle de la propriété (par exemple, la propriété a une longueur de 3 octets et vous définissez long_offset à 1, résultant en un décalage d'octets de 4).
xcb_window_error_t
La window spécifiée n'existe pas.

EXEMPLE

/*
 * Affiche la propriété WM_NAME de la fenêtre.
 *
 */
void my_example(xcb_connection_t *c, xcb_window_t window) {
    xcb_get_property_cookie_t cookie;
    xcb_get_property_reply_t *reply;
    /* Ces atomes sont prédéfinis dans le protocole X11. */
    xcb_atom_t property = XCB_ATOM_WM_NAME;
    xcb_atom_t type = XCB_ATOM_STRING;
    // TODO: un long_length raisonnable pour WM_NAME ?
    cookie = xcb_get_property(c, 0, window, property, type, 0, 0);
    if ((reply = xcb_get_property_reply(c, cookie, NULL))) {
        int len = xcb_get_property_value_length(reply);
        if (len == 0) {
            printf("TODO\n");
            free(reply);
            return;
        }
        printf("WM_NAME est %.*s\n", len,
               (char*)xcb_get_property_value(reply));
    }
    free(reply);
}

xcb_get_property_value_length

GET PROPERTY VALUE LENGTH

NAME

xcb_get_property_value_length - get the length of the property value

SYNOPSIS

#include <xcb_render.h>

ARGUMENTS

  • xcb_connection_t *c
  • xcb_render_query_pict_formats_cookie_t *cookie

DESCRIPTION

Retrieve the length of the property value. This function is used to get the length of the property value after a call to xcb_get_property.

RETURN VALUE

Returns the length of the property value as a uint32_t.

ERRORS

This function does not generate any errors.

EXAMPLE

uint32_t len = xcb_get_property_value_length(c, &cookie);
