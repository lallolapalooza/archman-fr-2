NOM

xcb_shm_put_image - Copie les données de la mémoire partagée vers le tracé spécifié.

SYNTAXE

#include <xcb/shm.h>

Fonction de requête

xcb_void_cookie_t xcb_shm_put_image(xcb_connection_t *conn, xcb_drawable_t drawable, xcb_gcontext_t gc, uint16_t total_width, uint16_t total_height, uint16_t src_x, uint16_t src_y, uint16_t src_width, uint16_t src_height, int16_t dst_x, int16_t dst_y, uint8_t depth, uint8_t format, uint8_t send_event, xcb_shm_seg_t shmseg, uint32_t offset);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
drawable
Le tracé de destination pour le dessin.
gc
Le contexte graphique à utiliser.
total_width
La largeur totale de l'image source.
total_height
La hauteur totale de l'image source.
src_x
La coordonnée X source de la sous-image à copier.
src_y
La coordonnée Y source de la sous-image à copier.
src_width
La largeur, en coordonnées d'image source, des données à copier depuis la source. Le serveur X utilisera cela pour déterminer la quantité de données à copier. La quantité de l'image de destination qui est écrasée est déterminée automatiquement.
src_height
La hauteur, en coordonnées d'image source, des données à copier depuis la source. Le serveur X utilisera cela pour déterminer la quantité de données à copier. La quantité de l'image de destination qui est écrasée est déterminée automatiquement.
dst_x
La coordonnée X sur le tracé de destination où copier.
dst_y
La coordonnée Y sur le tracé de destination où copier.
depth
La profondeur à utiliser.
format
Le format de l'image dessinée. Si c'est XYBitmap, la profondeur doit être 1, ou une erreur "BadMatch" se produit. Le pixel de premier plan dans le GC détermine la source pour les bits un de l'image, et le pixel d'arrière-plan détermine la source pour les bits zéro. Pour XYPixmap et ZPixmap, la profondeur doit correspondre à la profondeur du tracé, ou une erreur "BadMatch" se produit.
send_event
Vrai si le serveur doit envoyer un événement XCB_SHM_COMPLETION lorsque le blocage est terminé.
shmseg
TODO : PAS ENCORE DOCUMENTÉ.
offset
Le décalage où commence l'image source.

DESCRIPTION

Copie les données de la mémoire partagée vers le tracé spécifié. La quantité d'octets écrits dans l'image de destination est toujours égale à la quantité d'octets lus depuis le segment de mémoire partagée.

VALEUR DE RETOUR

Retourne un xcb_void_cookie_t. Les erreurs (s'il y en a) doivent être gérées dans la boucle d'événements.

Si vous souhaitez gérer les erreurs directement avec xcb_request_check à la place, utilisez xcb_shm_put_image_checked. Voir xcb-requests(3) pour les détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
