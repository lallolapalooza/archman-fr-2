    xcb_xkb_get_device_info_name

    xcb_xkb_get_device_info_name - Obtient le nom d'un périphérique XKB.

    SYNTAXE

    xcb_xkb_get_device_info_name(
        xcb_connection_t *மையான,
        xcb_xkb_device_id_t device_id
    );

    DESCRIPTION

    La fonction xcb_xkb_get_device_info_name demande des informations sur un périphérique XKB spécifié par device_id. Cette requête récupère le nom du périphérique.

    VALEUR DE RETOUR

    La fonction renvoie une structure xcb_xkb_get_device_info_reply_t *. Cette structure contient les informations demandées. Il est important de libérer la mémoire allouée pour la réponse lorsque vous n'en avez plus besoin en utilisant free().

    ERREURS

    Aucune erreur spécifique n'est documentée pour cette fonction. Cependant, les erreurs générales de connexion XCB peuvent survenir.
