DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_xf86dri_create_drawable_cookie_t. Les erreurs doivent être gérées lors de l'appel à la fonction de réponse xcb_xf86dri_create_drawable_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_xf86dri_create_drawable_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
