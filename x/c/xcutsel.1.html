XCUTSEL(1) Manuel des commandes générales XCUTSEL(1)

NOM

xcutsel - échange entre le tampon de coupe et la sélection

SYNTAXE

xcutsel [ -option-toolkit ...] [-selection sélection] [-cutbuffer numéro]

DESCRIPTION

Le programme xcutsel est utilisé pour copier la sélection courante dans un tampon de coupe et pour créer une sélection qui contient le contenu courant du tampon de coupe. Il agit comme un pont entre les applications qui ne prennent pas en charge les sélections et celles qui le font.

Par défaut, xcutsel utilisera la sélection nommée PRIMARY et le tampon de coupe CUT_BUFFER0. L'une ou l'autre, voire les deux, peuvent être remplacées par des arguments de ligne de commande ou par des ressources.

Une fenêtre xcutsel comporte les boutons suivants :

quitter
Lorsque ce bouton est pressé, xcutsel se termine. Toutes les sélections détenues par xcutsel sont automatiquement relâchées.
copier PRIMARY dans 0
Lorsque ce bouton est pressé, xcutsel copie la sélection courante dans le tampon de coupe.
copier 0 dans PRIMARY
Lorsque ce bouton est pressé, xcutsel convertit le contenu courant du tampon de coupe en la sélection.

Les étiquettes des boutons reflètent la sélection et le tampon de coupe sélectionnés par les options de ligne de commande ou via la base de données de ressources.

Lorsque le bouton « copier 0 dans PRIMARY » est activé, le bouton reste inversé tant que xcutsel est le propriétaire de la sélection. Cela sert à vous rappeler quel client possède la sélection courante. Notez que la valeur de la sélection reste constante ; si le tampon de coupe est modifié, vous devez réactiver le bouton de copie pour récupérer la nouvelle valeur lorsque vous le souhaitez.

OPTIONS

Xcutsel accepte toutes les options de ligne de commande standard du X Toolkit ainsi que les suivantes :

-selection nom
Cette option spécifie le nom de la sélection à utiliser. La valeur par défaut est PRIMARY. Les seules abréviations prises en charge pour cette option sont « -select », « -sel » et « -s », car l'option standard du toolkit « -selectionTimeout » a un nom similaire.
-cutbuffer numéro
Cette option spécifie le tampon de coupe à utiliser. La valeur par défaut est le tampon de coupe 0.

DÉFAUTS X

Ce programme accepte tous les noms de ressources et classes standard du X Toolkit ainsi que :

selection (classe Selection)
Cette ressource spécifie le nom de la sélection à utiliser. La valeur par défaut est PRIMARY.
cutBuffer (classe CutBuffer)
Cette ressource spécifie le numéro du tampon de coupe à utiliser. La valeur par défaut est 0.

NOMS DE WIDGETS

Les noms d'instance suivants peuvent être utilisés lorsque la configuration utilisateur des étiquettes est souhaitée :

sel-cut (classe Command)
Ceci est le bouton « copier SELECTION dans BUFFER ».
cut-sel (classe Command)
Ceci est le bouton « copier BUFFER dans SELECTION ».
quit (classe Command)
Ceci est le bouton « quitter ».

VOIR AUSSI

X(7), xclipboard(1), xterm(1), documentation du widget texte, documentation individuelle du client expliquant comment effectuer une sélection.

BOGUES

Il n'y a aucun moyen de changer le nom de la sélection ou le numéro du tampon de coupe pendant que le programme s'exécute.
