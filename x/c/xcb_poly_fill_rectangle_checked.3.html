NOM

xcb_poly_fill_rectangle - Remplit des rectangles

SYNTAXE

#include <xcb/xproto.h>

Fonction de requête

xcb_void_cookie_t xcb_poly_fill_rectangle(xcb_connection_t *conn, xcb_drawable_t drawable, xcb_gcontext_t gc, uint32_t rectangles_len, const xcb_rectangle_t *rectangles);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
drawable
Le drawable (Fenêtre ou Pixmap) sur lequel dessiner.
gc
Le contexte graphique à utiliser.

Les composants du contexte graphique suivants sont utilisés : fonction, masque de plan, style de remplissage, mode sous-fenêtre, origine x du clip, origine y du clip, et masque du clip.

Les composants suivants du contexte graphique dépendant du mode sont utilisés : premier plan, arrière-plan, tuile, motif, origine x de la tuile/motif, et origine y de la tuile/motif.

rectangles_len
Le nombre de structures xcb_rectangle_t dans rectangles.
rectangles
Les rectangles à remplir.

DESCRIPTION

Remplit les rectangles spécifiés dans l'ordre où ils apparaissent dans le tableau. Pour tout rectangle donné, chaque pixel n'est pas dessiné plus d'une fois. Si des rectangles s'intersectent, les pixels qui s'intersectent sont dessinés plusieurs fois.

VALEUR DE RETOUR

Retourne un xcb_void_cookie_t. Les erreurs (le cas échéant) doivent être gérées dans la boucle d'événements.

Si vous préférez gérer les erreurs directement avec xcb_request_check, utilisez xcb_poly_fill_rectangle_checked. Voir xcb-requests(3) pour plus de détails.

ERREURS

xcb_drawable_error_t
Le drawable spécifié (Fenêtre ou Pixmap) n'existe pas.
xcb_g_context_error_t
Le contexte graphique spécifié n'existe pas.
