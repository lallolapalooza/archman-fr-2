Structure de données de l'Événement

typedef struct xcb_focus_in_event_t {
    uint8_t      response_type;
    uint8_t      detail;
    uint16_t     sequence;
    xcb_window_t event;
    uint8_t      mode;
    uint8_t      pad0[3];
} xcb_focus_in_event_t;

CHAMPS DE L'ÉVÉNEMENT

response_type
Le type de cet événement, dans ce cas XCB_FOCUS_OUT. Ce champ est également présent dans le xcb_generic_event_t et peut être utilisé pour distinguer les événements les uns des autres.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
detail
event
La fenêtre sur laquelle l'événement de focus a été généré. C'est la fenêtre utilisée par le serveur X pour rapporter l'événement.
mode
