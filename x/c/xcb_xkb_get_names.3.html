DESCRIPTION

VALEUR RENVOYÉE

Renvoie un xcb_xkb_get_names_cookie_t. Les erreurs doivent être gérées lors de l'appel de la fonction de réponse xcb_xkb_get_names_reply.

Si vous préférez gérer les erreurs dans la boucle d'événements, utilisez xcb_xkb_get_names_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS

Cette requête ne génère jamais d'erreurs.
