DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_randr_get_crtc_transform_cookie_t. Les erreurs doivent être gérées lors de l'appel à la fonction de réponse xcb_randr_get_crtc_transform_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_randr_get_crtc_transform_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS
