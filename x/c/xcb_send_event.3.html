NOM

xcb_send_event - envoyer un événement

SYNOPSIS

#include <xcb/xproto.h>

Fonction de requête

xcb_void_cookie_t xcb_send_event(xcb_connection_t *conn, uint8_t propagate, xcb_window_t destination, uint32_t event_mask, const char *event);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
propagate
Si propagate est vrai et qu'aucun client n'a sélectionné d'événement sur destination, la destination est remplacée par l'ancêtre le plus proche de destination pour lequel un client a sélectionné un type dans event_mask et pour lequel aucune fenêtre intermédiaire n'a ce type dans son masque do-not-propagate-mask. Si aucune fenêtre de ce type n'existe ou si la fenêtre est un ancêtre de la fenêtre de focus et que InputFocus a été initialement spécifié comme destination, l'événement n'est envoyé à aucun client. Sinon, l'événement est rapporté à chaque client sélectionnant sur la destination finale tout type spécifié dans event_mask.
destination
La fenêtre à laquelle cet événement doit être envoyé. Chaque client qui sélectionne un événement dans event_mask sur destination recevra l'événement.

La valeur spéciale XCB_SEND_EVENT_DEST_POINTER_WINDOW fait référence à la fenêtre qui contient le pointeur de la souris.

La valeur spéciale XCB_SEND_EVENT_DEST_ITEM_FOCUS fait référence à la fenêtre qui a le focus du clavier.

event_mask
Masque d'événements pour déterminer quels clients doivent recevoir l'événement spécifié. Voir destination et propagate.
event
L'événement à envoyer à la destination spécifiée.

DESCRIPTION

Identifie la fenêtre de destination, détermine quels clients doivent recevoir l'événement spécifié et ignore toutes les saisies actives.

L'event doit être l'un des événements de base ou un événement défini par une extension, afin que le serveur X puisse correctement échanger les octets du contenu si nécessaire. Le contenu de event est sinon inchangé et non vérifié, à l'exception du champ send_event qui est forcé à 'true'.

VALEUR DE RETOUR

Retourne un xcb_void_cookie_t. Les erreurs (le cas échéant) doivent être gérées dans la boucle d'événements.

Si vous souhaitez gérer les erreurs directement avec xcb_request_check, utilisez xcb_send_event_checked. Voir xcb-requests(3) pour les détails.

ERREURS

xcb_value_error_t
L'event donné n'est ni un événement de base ni un événement défini par une extension.
xcb_window_error_t
La fenêtre de destination spécifiée n'existe pas.

EXEMPLE

/*
 * Indiquer à la fenêtre donnée qu'elle a été configurée à une taille de 800x600 pixels.
 *
 */
void my_example(xcb_connection_t *conn, xcb_window_t window) {
    /* Chaque événement X11 fait 32 octets de long. Par conséquent, XCB copiera 32 octets.
     * Afin d'initialiser correctement ces octets, nous allouons 32 octets même
     * si nous n'en avons besoin que de moins pour un xcb_configure_notify_event_t */
    xcb_configure_notify_event_t *event = calloc(32, 1);
    event->event = window;
    event->window = window;
    event->response_type = XCB_CONFIGURE_NOTIFY;
    event->x = 0;
    event->y = 0;
    event->width = 800;
    event->height = 600;
    event->border_width = 0;
    event->above_sibling = XCB_NONE;
    event->override_redirect = false;
    xcb_send_event(conn, false, window, XCB_EVENT_MASK_STRUCTURE_NOTIFY,
                   (char*)event);
    xcb_flush(conn);
    free(event);
}
