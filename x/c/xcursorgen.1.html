XCURSORGEN(1) Manuel des commandes générales XCURSORGEN(1)

NOM

xcursorgen - créer un fichier de curseur X à partir d'une collection d'images PNG

SYNTAXE

xcursorgen [ -p rép ] [ --prefix rép ] [ fichier-config [ fichier-sortie ] ]
xcursorgen -V | --version | -? | --help

DESCRIPTION

Xcursorgen lit le fichier-config pour trouver la liste des images de curseurs ainsi que leurs informations de point d'ancrage et de taille nominale. Xcursorgen convertit toutes les images au format Xcursor et les écrit dans le fichier-sortie.

Chaque ligne du fichier de configuration est de la forme :
<taille> <xhot> <yhot> <nom-fichier> <delai-ms>

Plusieurs images avec la même <taille> sont utilisées pour créer des curseurs animés, la valeur <delai-ms> sur chaque ligne indique combien de temps chaque image doit être affichée avant de passer à la suivante. <delai-ms> peut être omis pour les curseurs statiques.

Si fichier-config n'est pas spécifié, ou est spécifié comme "-", l'entrée standard est utilisée pour le fichier de configuration. Si fichier-sortie n'est pas spécifié, ou est spécifié comme "-", la sortie standard est utilisée pour le fichier de sortie.

OPTIONS

-V, --version
Affiche le numéro de version et quitte.
-?, --help
Affiche le message d'utilisation et quitte.
-p rép, --prefix rép
Recherche les images de curseurs dans le répertoire spécifié par rép. Si non spécifié, le répertoire courant est utilisé.
