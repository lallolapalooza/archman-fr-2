NOM

xcb_warp_pointer - déplace le pointeur de la souris

SYNTAXE

#include <xcb/xproto.h>

Fonction de requête

xcb_void_cookie_t xcb_warp_pointer(xcb_connection_t *conn, xcb_window_t src_window, xcb_window_t dst_window, int16_t src_x, int16_t src_y, uint16_t src_width, uint16_t src_height, int16_t dst_x, int16_t dst_y);

DESCRIPTION

Déplace le pointeur de la souris vers la position spécifiée.

Si src_window n'est pas XCB_NONE (TODO), le déplacement n'aura lieu que si le pointeur se trouve à l'intérieur de src_window et dans le rectangle spécifié par (src_x, src_y, src_width, src_height). Les coordonnées du rectangle sont relatives à src_window.

Si dst_window n'est pas XCB_NONE (TODO), le pointeur sera déplacé aux offsets (dst_x, dst_y) par rapport à dst_window. Si dst_window est XCB_NONE (TODO), le pointeur sera déplacé des offsets (dst_x, dst_y) par rapport à la position actuelle du pointeur.

VALEUR DE RETOUR

Retourne un xcb_void_cookie_t. Les erreurs (s'il y en a) doivent être gérées dans la boucle d'événements.

Si vous souhaitez gérer les erreurs directement avec xcb_request_check à la place, utilisez xcb_warp_pointer_checked. Voir xcb-requests(3) pour les détails.
