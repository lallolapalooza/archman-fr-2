DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_xv_grab_port_cookie_t. Les erreurs doivent être gérées lors de l'appel de la fonction de réponse xcb_xv_grab_port_reply.

Si vous souhaitez gérer les erreurs dans la boucle d'événements à la place, utilisez xcb_xv_grab_port_unchecked. Voir xcb-requests(3) pour plus de détails.

ERREURS
