Structure de données de l'événement

typedef struct xcb_randr_screen_change_notify_event_t {
    uint8_t         response_type;
    uint8_t         rotation;
    uint16_t        sequence;
    xcb_timestamp_t timestamp;
    xcb_timestamp_t config_timestamp;
    xcb_window_t    root;
    xcb_window_t    request_window;
    uint16_t        sizeID;
    uint16_t        subpixel_order;
    uint16_t        width;
    uint16_t        height;
    uint16_t        mwidth;
    uint16_t        mheight;
} xcb_randr_screen_change_notify_event_t;

CHAMPS DE L'ÉVÉNEMENT

response_type
Le type de cet événement, dans ce cas XCB_RANDR_SCREEN_CHANGE_NOTIFY. Ce champ est également présent dans le xcb_generic_event_t et peut être utilisé pour distinguer les événements les uns des autres.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
