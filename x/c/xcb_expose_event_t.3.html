NOM

xcb_expose_event_t - PAS ENCORE DOCUMENTÉ

SYNTAXE

#include <xcb/xproto.h>

Structure événement

typedef struct xcb_expose_event_t {
    uint8_t      response_type;
    uint8_t      pad0;
    uint16_t     sequence;
    xcb_window_t window;
    uint16_t     x;
    uint16_t     y;
    uint16_t     width;
    uint16_t     height;
    uint16_t     count;
    uint8_t      pad1[2];
} xcb_expose_event_t;

CHAMP ÉVÉNEMENT

response_type
Le type de cet événement, dans ce cas XCB_EXPOSE. Ce champ est aussi présent dans le xcb_generic_event_t et peut être utilisé pour distinguer les événements les uns des autres.
sequence
Le numéro de séquence de la dernière requête traitée par le serveur X11.
window
La fenêtre exposée (endommagée).
x
La coordonnée X du coin supérieur gauche du rectangle exposé, relativement à l'origine de la window.
y
La coordonnée Y du coin supérieur gauche du rectangle exposé, relativement à l'origine de la window.
width
La largeur du rectangle exposé.
height
La hauteur du rectangle exposé.
count
La quantité d'événements Expose suivant celui-ci. Les applications simples qui ne souhaitent pas optimiser le réaffichage en distinguant les sous-zones de leur fenêtre peuvent simplement ignorer tous les événements Expose avec des comptes non nuls et effectuer des réaffichages complets sur les événements avec des comptes nuls.
