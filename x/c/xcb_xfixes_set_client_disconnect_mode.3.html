NOM

xcb_xfixes_set_client_disconnect_mode - Définit le mode de déconnexion pour le client.

SYNTAXE

#include <xcb/xfixes.h>

Fonction de requête

xcb_void_cookie_t xcb_xfixes_set_client_disconnect_mode(xcb_connection_t *conn, uint32_t disconnect_mode);

ARGUMENTS DE LA REQUÊTE

conn
La connexion XCB à X11.
disconnect_mode
Le nouveau mode de déconnexion.

DESCRIPTION

VALEUR DE RETOUR

Retourne un xcb_void_cookie_t. Les erreurs (s'il y en a) doivent être gérées dans la boucle d'événements.

Si vous souhaitez gérer les erreurs directement avec xcb_request_check, utilisez xcb_xfixes_set_client_disconnect_mode_checked. Voir xcb-requests(3) pour les détails.

ERREURS

Cette requête ne génère jamais d'erreurs.

VOIR AUSSI

xcb-requests(3)
