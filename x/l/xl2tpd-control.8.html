NOM

xl2tpd-control - utilitaire de contrôle de xl2tpd.

DESCRIPTION

xl2tpd est une implémentation du protocole de tunnelisation de couche 2 (RFC 2661). L2TP permet de tunneliser PPP sur UDP. Certains FAI utilisent L2TP pour tunneliser les sessions utilisateur depuis des serveurs d'accès distant (banques de modems, DSLAM ADSL) vers des serveurs PPP back-end. Une autre application importante est les réseaux privés virtuels où le protocole IPsec est utilisé pour sécuriser la connexion L2TP (L2TP/IPsec, RFC 3193).

xl2tpd fonctionne en ouvrant un pseudo-tty pour communiquer avec pppd. Il s'exécute entièrement dans l'espace utilisateur mais prend en charge L2TP en mode noyau.

xl2tpd prend en charge le suivi de référence des SA IPsec pour permettre des adresses IP internes NATées qui se chevauchent par différents clients (par exemple, tous les clients se connectant depuis leur adresse IP interne Linksys 192.168.1.101) ainsi que plusieurs clients derrière le même routeur NAT.

SYNTAXE

xl2tpd-control [-c CHEMIN] <COMMANDE> <NOM_DU_TUNNEL> [OPTIONS]

OPTIONS

-c
Cette option spécifie le fichier de contrôle de xl2tpd.
-d
Cette option active le mode de débogage.

COMMANDES

add-lac
Ajoute ou modifie la configuration d'un LAC (Concentrateur d'accès L2TP) existant. La configuration doit être spécifiée sous forme d'options de commande sous forme de paires <clé>=<valeur>. Voir les options disponibles dans xl2tpd.conf(5).
connect-lac
Établit une nouvelle connexion à un LAC. Le nom d'utilisateur et le secret pour le tunnel peuvent être passés comme options de commande.
disconnect-lac
Déconnecte le tunnel.
remove-lac
Supprime la configuration d'un LAC existant. xl2tpd déconnecte le tunnel avant de le supprimer.
add-lns
Ajoute ou modifie la configuration d'un LNS (Serveur réseau L2TP) existant.
remove-lns
Supprime la configuration d'un LNS existant.
status-lns
Vérifie l'état du LNS.
available
Vérifie la disponibilité.
