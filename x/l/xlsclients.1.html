NOM

xlsclients - lister les applications clientes exécutées sur un écran

SYNTAXE

xlsclients [-display nom_ecran] [-a] [-l] [-m longueur_max_cmd] [-version]

DESCRIPTION

Xlsclients est un utilitaire permettant de lister des informations sur les applications clientes exécutées sur un écran. Il peut être utilisé pour générer des scripts représentant un instantané de la session actuelle de l'utilisateur.

OPTIONS

-display nom_ecran
Cette option spécifie le serveur X à contacter.
-a
Cette option indique que les clients sur tous les écrans doivent être listés. Par défaut, seuls les clients de l'écran par défaut sont listés.
-l
Lister au format long, donnant le nom de la fenêtre, le nom de l'icône et les indices de classe en plus du nom de la machine et de la chaîne de commande affichés dans le format par défaut.
-m longueur_max_cmd
Cette option spécifie le nombre maximum de caractères d'une commande à imprimer. La valeur par défaut est 10000.
-version
Affiche la version du programme et quitte.

ENVIRONNEMENT

DISPLAY
Pour obtenir l'hôte par défaut, le numéro d'écran et l'écran.

VOIR AUSSI

X(7), xwininfo(1), xprop(1)
