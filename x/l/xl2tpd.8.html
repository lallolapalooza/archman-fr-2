NOM

xl2tpd - Daemon du protocole de tunnelisation de niveau 2.

DESCRIPTION

xl2tpd est une implémentation du protocole de tunnelisation de niveau 2 (RFC 2661). L2TP permet de tunneliser PPP sur UDP. Certains FAI utilisent L2TP pour tunneliser les sessions utilisateur depuis des serveurs d'accès distant (groupes de modems, DSLAM ADSL) vers des serveurs PPP en backend. Une autre application importante est les Réseaux Privés Virtuels (VPN) où le protocole IPsec est utilisé pour sécuriser la connexion L2TP (L2TP/IPsec, RFC 3193).

xl2tpd fonctionne en ouvrant un pseudo-tty pour communiquer avec pppd. Il s'exécute entièrement en espace utilisateur mais prend en charge le L2TP en mode noyau.

xl2tpd prend en charge le suivi des références SA IPsec pour permettre des adresses IP internes NATées chevauchantes par différents clients (par exemple, tous les clients se connectant depuis leur adresse IP interne Linksys 192.168.1.101) ainsi que plusieurs clients derrière le même routeur NAT.

Cette implémentation est basée sur L2TPd 0.61 de http://www.marko.net/l2tp et des correctifs collectés par Jacco de Leeuw à l'adresse http://www.jacco2.dds.nl/networking/openswan-l2tp.html.

OPTIONS

-D
Cette option empêche xl2tpd de se détacher du terminal et de devenir un daemon.
-l
Cette option indique à xl2tpd d'utiliser syslog pour la journalisation, même lorsque -D a été spécifié.
-c <fichier_config>
Définit un fichier de configuration alternatif. Le fichier de configuration de secours est /etc/l2tpd/l2tpd.conf.
-s <fichier_secrets>
Indique à xl2tpd d'utiliser un fichier "secrets" alternatif.
-p <fichier_pid>
Définit un fichier pid alternatif. Par défaut : /var/run/xl2tpd/xl2tpd.pid.
-C <fichier_controle>
Définit un fichier de contrôle alternatif.

FICHIERS

/etc/xl2tpd/xl2tpd.conf
Fichier de configuration de xl2tpd, utilisé par défaut.
/etc/xl2tpd/l2tp-secrets
Fichier de secrets, utilisé par défaut.
/var/run/xl2tpd/l2tp-control
Fichier de contrôle, utilisé par défaut.
