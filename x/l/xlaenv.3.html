Documentation de la fonction/sous-programme

sous-programme xlaenv (entier ispec, entier nvalue)

XLAENV

Objectif :

!>
!> XLAENV définit certaines quantités dépendantes de la machine et du problème
!> qui seront récupérées plus tard par ILAENV.
!>

Paramètres

ISPEC 
!>          ISPEC est un ENTIER
!>          Spécifie le paramètre à définir dans le tableau COMMON IPARMS.
!>          = 1 : la taille de bloc optimale ; si cette valeur est 1, un algorithme
!>               non bloqué donnera les meilleures performances.
!>          = 2 : la taille de bloc minimale pour laquelle la routine bloquée
!>               doit être utilisée ; si la taille de bloc utilisable est inférieure
!>               à cette valeur, une routine non bloquée doit être utilisée.
!>          = 3 : le point de croisement (dans une routine bloquée, pour N inférieur
!>               à cette valeur, une routine non bloquée doit être utilisée)
!>          = 4 : le nombre de décalages, utilisé dans les routines de valeurs propres
!>               non symétriques
!>          = 5 : la dimension minimale de colonne pour que le blocage soit utilisé ;
!>               les blocs rectangulaires doivent avoir une dimension d'au moins k par m,
!>               où k est donné par ILAENV(2,...) et m par ILAENV(5,...)
!>          = 6 : le point de croisement pour la SVD (lors de la réduction d'une
!>               matrice m par n en une forme bidiagonale, si max(m,n)/min(m,n)
!>               dépasse cette valeur, une factorisation QR est d'abord utilisée pour
!>               réduire la matrice à une forme triangulaire)
!>          = 7 : le nombre de processeurs
!>          = 8 : un autre point de croisement, pour les méthodes QR et QZ multi-décalages
!>               pour les problèmes de valeurs propres non symétriques.
!>          = 9 : taille maximale des sous-problèmes au bas de l'arbre de calcul
!>               dans l'algorithme diviser pour régner (utilisé par xGELSD et xGESDD)
!>          =10 : l'arithmétique NaN ieee peut être utilisée en toute confiance sans
!>               déclencher d'interruption.
!>          =11 : l'arithmétique de l'infini peut être utilisée en toute confiance sans
!>               déclencher d'interruption.
!>

NVALUE

!>          NVALUE est un ENTIER
!>          La valeur du paramètre spécifié par ISPEC.
!>
