xls2csv(1) Manuel des commandes générales xls2csv(1)

NOM

xls2csv - lit les fichiers MS-Excel et affiche leur contenu sous forme de données séparées par des virgules sur la sortie standard

SYNTAXE

xls2csv [-xlV] [-f format ] [-b chaîne ] [-s jeu_de_caractères ] [-d jeu_de_caractères ] [-q nombre ] [-c caractère] fichiers

DESCRIPTION

xls2csv lit les feuilles de calcul MS-Excel et affiche leur contenu sous forme de valeurs séparées par des virgules sur la sortie standard. Les nombres sont affichés sans délimiteurs, les chaînes sont entourées de guillemets doubles. Les guillemets doubles à l'intérieur d'une chaîne sont doublés.

OPTIONS

-x
affiche les caractères Unicode inconnus sous la forme \xNNNN, plutôt que des points d'interrogation
-l
liste les jeux de caractères connus et quitte avec succès
-ccaractère
caractère séparateur de cellule. Par défaut, la virgule.
-bchaîne
chaîne de séparation de feuille. Cette chaîne (par défaut, saut de page) sera affichée à la fin de chaque page du classeur. Cette chaîne est affichée au début d'une ligne, mais aucune fin de ligne ne sera automatiquement ajoutée après la chaîne. Incluez un saut de ligne à la fin du séparateur de feuille si vous voulez qu'il apparaisse sur une ligne séparée.
-gnombre
nombre de chiffres décimaux dans les nombres. Par défaut, la précision maximale des doubles (macro DBL_DIG dépendante du système) est utilisée.
-qnombre
définit le mode de guillemets. En mode 0, le contenu des cellules n'est jamais entre guillemets. En mode 1, seules les cellules contenant des espaces, des guillemets doubles ou des virgules sont mises entre guillemets. En mode 2 (par défaut), toutes les cellules de type chaîne sont mises entre guillemets. En mode 3, toutes les cellules sont mises entre guillemets.
-djeu_de_caractères
- spécifie le nom du jeu de caractères de destination. Le fichier de jeu de caractères a le format décrit dans la section CHARACTER SETS de la page de manuel de catdoc(1). Par défaut, le jeu de caractères local actuel serait utilisé si le support langinfo a été activé au moment de la compilation.
-sjeu_de_caractères
- spécifie le jeu de caractères source. Généralement, les fichiers Excel ont un enregistrement CODE PAGE, qui indique le jeu de caractères d'entrée, mais pour une raison quelconque, vous pourriez vouloir le remplacer.
-fformat
- spécifie le format de date/heure à utiliser pour l'affichage de toutes les valeurs de date et d'heure Excel. Si cette option n'est pas spécifiée, le format spécifié dans la feuille de calcul est utilisé. Sur les systèmes POSIX, tout format autorisé par strftime(3) peut être utilisé comme valeur de cette option. Sous MS-DOS, xls2csv implémente un ensemble limité de formats strftime, à savoir m, d, y, Y, b, l, p, H, M, S.
-V
affiche le numéro de version

FICHIERS

${HOME}/.catdocrc, fichiers de jeux de caractères catdoc et fichiers de masques de substitution (voir la page de manuel de catdoc(1) pour plus de détails).

VOIR AUSSI
