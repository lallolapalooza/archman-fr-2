XLOCK(1) Manuel des commandes générales XLOCK(1)

NOM

DESCRIPTION

xlock verrouille le serveur X jusqu'à ce que l'utilisateur entre son mot de passe au clavier. Pendant que xlock est en cours d'exécution, toutes les nouvelles connexions serveur sont refusées. Le économiseur d'écran est désactivé. Le curseur de la souris est désactivé. L'écran est mis en veille et un motif changeant est affiché à l'écran. Si une touche ou un bouton de la souris est pressé, l'utilisateur est invité à entrer le mot de passe de l'utilisateur qui a lancé xlock.

Si le mot de passe correct est tapé, l'écran est déverrouillé et le serveur X est restauré. Pendant la saisie du mot de passe, Control-U et Control-H sont actifs respectivement pour effacer et supprimer.

Pour revenir à l'écran verrouillé, cliquez sur la petite icône représentant le motif changeant.

Dans la partie inférieure de l'écran de mot de passe, un texte est affiché. Ce message est pris du premier fichier suivant qui existe : $HOME/.xlocktext, $HOME/.plan, ou $HOME/.signature.

Sur les systèmes qui prennent en charge l'authentification de style nouveau BSD, le mot de passe peut être précédé d'un style d'authentification suivi d'un deux-points (par exemple, "style:motdepasse"). Voir login.conf(5) pour plus d'informations sur les styles d'authentification.

NOTE SUR L'ÉTIQUETTE

Xlock ne devrait pas être utilisé sur des terminaux publics lorsqu'il y a une forte demande pour ceux-ci.

Si vous trouvez un terminal public qui a été verrouillé par un autre utilisateur et qu'il n'y a pas d'autres terminaux disponibles, et que le terminal semble avoir été laissé inactif pendant un certain temps (normalement plus de 15 minutes), il est acceptable d'essayer de réinitialiser la session d'une manière ou d'une autre.

-delay usecs
L'option delay définit la vitesse à laquelle un mode fonctionnera. Elle définit simplement le nombre de microsecondes à retarder entre les lots d'animations. En mode blank, il est important de définir un petit nombre de secondes, car le clavier et la souris ne sont vérifiés qu'après chaque délai, vous ne pouvez donc pas définir un délai trop élevé, mais un délai nul consommerait inutilement du CPU pour vérifier les entrées de la souris et du clavier dans une boucle serrée, car le mode blank n'a aucun travail à faire.

Cette option doit être utilisée avec prudence et est principalement destinée à verrouiller les terminaux X11 qui ne peuvent pas exécuter xlock localement. EXEMPLES

The following examples demonstrate some of the capabilities of xlock:

  • Lock the screen and run a screensaver until unlocked:

    xlock

  • Lock the screen and run a screensaver for 5 minutes before locking (if not already locked):

    xlock -timeout 5

  • Lock the screen with a specific message and font:

    xlock -msg "My personal lock screen" -font -*-*-*-r-normal-*-*-120-*-*-*-*-*-*

  • Lock the screen and execute a command when unlocked:

    xlock -endCmd "echo 'Screen unlocked at %T' | wall"

  • Lock the screen and pipe the password to a command when unlocked:

    xlock -pipepassCmd "/usr/local/bin/process_password"

  • Lock the screen and execute a command upon logout:

    xlock -logoutCmd "pkill -HUP my_process"

  • Lock the screen and check for mail every 60 seconds:

    xlock -mailCmd "check_mail" -mailDelay 60

  • Lock the screen and use custom bitmaps for mail notification:

    xlock -mailIcon /path/to/mail.xbm -nomailIcon /path/to/nomail.xbm

  • Configure DPMS settings for monitor power management:

    xlock -dpmsstandby 300 -dpmssuspend 600 -dpmsoff 1800

  • Use the "life" screensaver with 4 neighbors:

    xlock -mode life -neighbors 4

  • Use the "life" screensaver with Conway's rule:

    xlock -mode life -rule B3/S23

  • Use the "ant" screensaver with Truchet lines enabled:

    xlock -mode ant -/+truchet

  • Use the "crystal" screensaver with color cycling enabled:

    xlock -mode crystal -/+cycle

  • Use the "fire" screensaver with fog and shadows:

    xlock -mode fire -/+fog -/+shadows

  • Use the "glplanet" screensaver with a specific texture file:

    xlock -mode glplanet -pimage /path/to/planet_texture.xpm

  • Use the "dclock" screensaver with binary and LED modes enabled:

    xlock -mode dclock -/+binary -/+led

AVERTISSEMENT

xlock peut sembler bloqué s'il est en concurrence avec un processus de haute priorité pour le CPU. Par exemple, si xlock est démarré après un processus avec 'nice -20' (haute priorité), xlock prendra beaucoup de temps à répondre.

MOTS DE PASSE SHADOW

Si la machine utilise un système de mots de passe shadow, alors xlock peut ne pas être configuré pour obtenir le vrai mot de passe et doit donc en recevoir un propre. Cela peut être fait en ligne de commande, via l'option -cpasswd, ou dans le fichier $HOME/.xlockrc, la première option ayant la priorité. Dans les deux cas, un mot de passe chiffré est attendu (voir makekey(8)). Si aucun n'est donné, alors xlock demandera un mot de passe et l'utilisera, en stockant également une version chiffrée dans $HOME/.xlockrc pour une utilisation future.

XLOCK ET SSH-AGENT

Si vous utilisez ssh-agent(1) pour éviter d'entrer une phrase secrète à chaque fois que vous utilisez une de vos clés privées ssh(1), c'est une bonne pratique de sécurité de faire en sorte que ssh-agent oublie les clés avant de laisser votre terminal sans surveillance. De cette façon, un attaquant qui prend le contrôle de votre terminal ne pourra pas utiliser vos clés ssh privées pour se connecter à d'autres systèmes. Une fois de retour à votre terminal, vous pouvez entrer la phrase secrète et réajouter les clés à ssh-agent. xlock peut aider à automatiser ce processus de plusieurs manières. Premièrement, l'option startCmd permet à xlock d'être configuré pour exécuter 'ssh-add -D' à chaque fois que vous verrouillez l'écran, de sorte que vos clés soient automatiquement supprimées de ssh-agent. Si la phrase secrète de vos clés ssh est la même que votre mot de passe, alors xlock peut également être configuré pour réajouter les clés à ssh-agent lorsque vous déverrouillez l'écran, via l'option pipepassCmd. Cela nécessite un peu de script, car la commande doit lire votre mot de passe depuis l'entrée standard, puis automatiser l'interaction avec ssh-add pour réajouter les clés. Il existe un exemple de script de ce type dans la distribution xlock - voir etc/xlockssh*

BOGUES

"kill -KILL xlock " rend le serveur verrouillé inutilisable, car tous les hôtes (y compris localhost) ont été retirés de la liste de contrôle d'accès pour bloquer les nouveaux clients X, et comme xlock n'a pas pu intercepter SIGKILL, il s'est terminé avant de restaurer la liste de contrôle d'accès. Cela laissera le serveur X dans un état où "vous ne pouvez plus vous connecter à ce serveur, et cette opération ne peut être inversée sans réinitialiser le serveur." -Extrait de la documentation Xlib de X11R4, chapitre 7.
Les terminaux NCD ne permettent pas à xlock de supprimer tous les hôtes de la liste de contrôle d'accès. Par conséquent, vous devrez utiliser les options "-remote" et "-allowaccess". Si vous exécutez sans "-allowaccess" sur un terminal NCD, xlock ne fonctionnera pas et vous devrez redémarrer le terminal, ou simplement aller dans les menus SETUP, sous 'Network Parameters', et désactiver le contrôle d'accès TCP/IP.

    XLOCK(1) Utilitaire de verrouillage X XLOCK(1)

    NOM

    xlock - verrouille le terminal X.

    SYNOPSIS

    xlock [options]

    DESCRIPTION

    xlock est un utilitaire de verrouillage d'écran pour le système X Window. Il remplace le fond d'écran par un motif ou une couleur, puis attend une entrée du clavier ou de la souris pour être déverrouillé.

    OPTIONS

    xlock accepte les options standard de X, ainsi que les options spécifiques suivantes :

    -mode mode
    Spécifie le mode de verrouillage. Les modes disponibles sont :
    • random : choisit un mode aléatoirement.
    • blank : affiche un écran noir.
    • color : affiche un écran d'une couleur unie.
    • picture : affiche une image (dépend de la configuration).
    • message : affiche un message (dépend de la configuration).
    • clock : affiche une horloge analogique.
    • matrix : affiche un effet matriciel (dépend de la configuration).
    -colors couleur1,couleur2
    Spécifie deux couleurs à utiliser pour les modes color et random.
    -delay secondes
    Spécifie le délai en secondes avant que l'écran ne soit verrouillé.
    -message message
    Spécifie le message à afficher dans le mode message.
    -name nom
    Spécifie le nom de la fenêtre.
    -font police
    Spécifie la police à utiliser pour le texte.

    INVOCATION

    Pour verrouiller votre écran, exécutez simplement xlock dans un terminal. Pour le déverrouiller, tapez votre mot de passe lorsque le prompt apparaît.

    BOGUES

    Aucun bogues connus pour le moment.
