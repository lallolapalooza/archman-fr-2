xlsfonts(1) Manuel des commandes générales xlsfonts(1)

NOM

xlsfonts - lister les polices disponibles pour le serveur X

SYNTAXE

xlsfonts [-display hote:dpy] [-l] [-ll] [-lll] [-m] [-C] [-1] [-w largeur] [-n colonnes] [-u] [-o] [-fn motif] [-v]

DESCRIPTION

xlsfonts liste les polices disponibles sur un serveur X qui correspondent au motif donné. Le caractère générique "*" peut être utilisé pour correspondre à n'importe quelle séquence de caractères (y compris aucune), et "?" pour correspondre à n'importe quel caractère unique. Si aucun motif n'est donné, "*" est supposé.

Les caractères "*" et "?" doivent être mis entre guillemets pour éviter qu'ils ne soient développés par le shell.

OPTIONS

-display hote:dpy
Cette option spécifie le serveur X à contacter.
-d hote:dpy
Identique à -display hote:dpy.
-l
Liste certains attributs de la police sur une seule ligne en plus de son nom.
-ll
Liste les propriétés de la police en plus de la sortie -l.
-lll
Liste les métriques de caractères en plus de la sortie -ll.
-m
Cette option indique que les listages longs doivent également afficher les limites minimale et maximale de chaque police.
-C
Cette option indique que les listages doivent utiliser plusieurs colonnes. Ceci est identique à -n 0.
-1
Cette option indique que les listages doivent utiliser une seule colonne. Ceci est identique à -n 1.
-w largeur
Cette option spécifie la largeur en caractères qui doit être utilisée pour déterminer le nombre de colonnes à imprimer. La valeur par défaut est 79.
-n colonnes
Cette option spécifie le nombre de colonnes à utiliser pour afficher la sortie. Par défaut, il tentera d'insérer autant de colonnes de noms de polices que possible dans la largeur spécifiée par la valeur de -w.
-u
Cette option indique que la sortie doit rester non triée.
-o
Cette option indique que xlsfonts doit effectuer une opération OpenFont (et QueryFont, si approprié) plutôt qu'une opération ListFonts. Ceci est utile si ListFonts ou ListFontsWithInfo ne parviennent pas à lister une police connue (comme c'est le cas avec certains systèmes de polices mises à l'échelle).
-fn motif
Cette option spécifie le motif du nom de la police à faire correspondre.
-v
Cette option indique que xlsfonts doit imprimer la version du programme et quitter.

VOIR AUSSI

X(7), Xserver(1), xset(1), xfd(1), Conventions de description des polices logiques X

ENVIRONNEMENT

DISPLAY
DISPLAY doit être défini pour obtenir l'hôte et le périphérique d'affichage par défaut à utiliser.

BOGUES

L'exécution de « xlsfonts -l » peut bloquer votre serveur X pendant très longtemps. Ceci est réellement un bug des serveurs non préemptifs mono-thread, pas de ce programme.
