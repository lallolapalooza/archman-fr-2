XLSATOMS(1) Manuel des commandes générales XLSATOMS(1)

NOM

xlsatoms - liste les atomes internalisés définis sur le serveur

SYNTAXE

xlsatoms [-options ...]

DESCRIPTION

Xlsatoms liste les atomes internalisés. Par défaut, tous les atomes à partir de 1 (la plus petite valeur d'atome définie par le protocole) sont listés jusqu'à ce qu'un atome inconnu soit trouvé. Si une plage explicite est donnée, xlsatoms essaiera tous les atomes dans la plage, peu importe s'ils sont définis ou non.

OPTIONS

-display dpy
Cette option spécifie le serveur X auquel se connecter.
-format chaîne
Cette option spécifie une chaîne de caractères de style printf utilisée pour lister chaque paire d'atomes <valeur,nom>, imprimée dans cet ordre (valeur est un unsigned long et nom est un char *). Xlsatoms ajoutera un saut de ligne à la fin de chaque ligne. La valeur par défaut est %lu\t%s.
-range [min]-[max]
Cette option spécifie la plage des valeurs d'atomes à vérifier. Si min n'est pas donné, la valeur 1 est supposée. Si max n'est pas donné, xlsatoms s'arrêtera au premier atome indéfini égal ou supérieur à min.
-name chaîne
Cette option spécifie le nom d'un atome à lister. Si l'atome n'existe pas, un message sera imprimé sur la sortie standard d'erreur.
-version
Affiche la version du programme et quitte.

VOIR AUSSI

X(7), Xserver(1), xprop(1)

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le périphérique d'affichage par défaut à utiliser.

AUTEUR
