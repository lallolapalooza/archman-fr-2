Paramètres

ISPEC 
!>          ISPEC est un ENTIER
!>          Spécifie le paramètre à définir dans le tableau commun IPARMS.
!>          = 1 : la taille de bloc optimale ; si cette valeur est 1, un
!>               algorithme non-bloc donne la meilleure performance.
!>          = 2 : la taille de bloc minimale pour laquelle la routine par blocs
!>               doit être utilisée ; si la taille de bloc utilisable est inférieure
!>               à cette valeur, une routine non-bloc doit être utilisée.
!>          = 3 : le point de croisement (dans une routine par blocs, pour N inférieur
!>               à cette valeur, une routine non-bloc doit être utilisée)
!>          = 4 : le nombre de décalages, utilisé dans les routines de valeurs propres
!>               non symétriques
!>          = 5 : la dimension minimale de colonne pour le blocage ;
!>               les blocs rectangulaires doivent avoir une dimension d'au moins k par m,
!>               où k est donné par ILAENV(2,...) et m par ILAENV(5,...)
!>          = 6 : le point de croisement pour la SVD (lors de la réduction d'une
!>               matrice m par n en forme bidiagonale, si max(m,n)/min(m,n) dépasse
!>               cette valeur, une factorisation QR est utilisée d'abord pour réduire
!>               la matrice en forme triangulaire)
!>          = 7 : le nombre de processeurs
!>          = 8 : un autre point de croisement, pour les méthodes QR et QZ à décalages multiples
!>               pour les problèmes de valeurs propres non symétriques.
!>          = 9 : taille maximale des sous-problèmes au bas de l'arbre de calcul
!>               dans l'algorithme diviser pour régner
!>               (utilisé par xGELSD et xGESDD)
!>          =10 : l'arithmétique NaN ieee peut être utilisée sans générer de piège
!>          =11 : l'arithmétique de l'infini peut être utilisée sans générer de piège
!>

NVALUE

!>          NVALUE est un ENTIER
!>          La valeur du paramètre spécifié par ISPEC.
!>
