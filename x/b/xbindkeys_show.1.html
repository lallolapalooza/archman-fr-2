NOM

xbindkeys_show - un programme pour afficher les touches capturées utilisées dans xbindkeys

SYNTAXE

xbindkeys_show

DESCRIPTION

XbindKeys_Show est un programme qui affiche les touches capturées utilisées par xbindkeys.

OPTIONS DE LA LIGNE DE COMMANDE

Les options de la ligne de commande disponibles sont les suivantes :

-f, --file
Utiliser un fichier rc alternatif
-h, --help
Aide rapide sur les options plus informations sur la version/auteur.
