NOM

xb-tool - utilitaire XMLb autonome

SYNOPSIS

xb-tool [CMD]

DESCRIPTION

Cet outil permet de créer, vider et interroger des blobs XML binaires.

De plus, xb-tool peut être utilisé pour profiler des requêtes tokenisées spécifiques.

OPTIONS

La commande xb-tool prend diverses options en fonction de l'action. Exécutez xb-tool --help pour la liste complète.

STATUT DE SORTIE

Les commandes qui s'exécutent avec succès renverront "0", sinon "1".

BOGUES

Aucun bogue connu.
