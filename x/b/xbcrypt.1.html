NOM

xbcrypt - Documentation de Percona xbcrypt

Pour prendre en charge le chiffrement et le déchiffrement des sauvegardes, un nouvel outil xbcrypt a été introduit dans Percona XtraBackup.

Percona XtraBackup 8.0.28-20 implémente la variable d'environnement XBCRYPT_ENCRYPTION_KEY. La variable est uniquement utilisée à la place de l'option --encrypt_key=name. Vous pouvez utiliser la variable d'environnement ou l'option de ligne de commande. Si vous utilisez les deux, l'option de ligne de commande a la priorité sur la valeur spécifiée dans la variable d'environnement.

Cet utilitaire a été modélisé d'après xbstream_binary pour effectuer le chiffrement et le déchiffrement en dehors de Percona XtraBackup. xbcrypt a les options de ligne de commande suivantes :

-d, --decrypt
Déchiffre les données d'entrée en sortie.
-i, --input=name
Fichier d'entrée optionnel. S'il n'est pas spécifié, l'entrée sera lue depuis l'entrée standard.
-o, --output=name
Fichier de sortie optionnel. S'il n'est pas spécifié, la sortie sera écrite sur la sortie standard.
-a, --encrypt-algo=name
Algorithme de chiffrement.
-k, --encrypt-key=name
Clé de chiffrement.
-f, --encrypt-key-file=name
Fichier contenant la clé de chiffrement.
-s, --encrypt-chunk-size=#
Taille du tampon de travail pour le chiffrement en octets. La valeur par défaut est 64K.
--encrypt-threads=#
Cette option spécifie le nombre de threads de travail qui seront utilisés pour le chiffrement/déchiffrement parallèle.
-v, --verbose
Affiche les informations de statut détaillées.
