XPRINTIDLE(1) Manuel des commandes générales XPRINTIDLE(1)

NOM

xprintidle - utilitaire affichant le temps d'inactivité de l'utilisateur dans X

SYNTAXE

xprintidle [OPTION...]

DESCRIPTION

xprintidle est un utilitaire qui interroge le serveur X sur le temps d'inactivité de l'utilisateur et l'affiche sur la sortie standard (en millisecondes).

OPTIONS

Informations générales sur le programme

-h , --help
Affiche un message d'utilisation et quitte.
-H , --human-readable
Affiche le temps d'inactivité dans un format lisible par l'homme.
-v , --version
Affiche le numéro de version et quitte.

BOGUES

Veuillez utiliser le traqueur de bogues GitHub pour signaler les bogues.
