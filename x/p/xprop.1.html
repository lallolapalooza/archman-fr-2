XPROP(1) Manuel des commandes générales XPROP(1)

NOM

xprop - afficheur de propriétés pour X

SYNOPIS

xprop [-aide] [-grammaire] [-id id] [-racine] [-nom nom] [-cadre] [-police police] [-affichage affichage] [-longueur n] [-sans_type] [-fs fichier] [-retirer nom-propriete] [-definir nom-propriete valeur] [-espionner] [-version] [-f atome format [format_d]]* [format [format_d] atome]*

RESUME

L'utilitaire xprop sert à afficher les propriétés de fenêtres et de polices dans un serveur X. Une fenêtre ou une police est sélectionnée à l'aide des arguments de la ligne de commande ou, dans le cas d'une fenêtre, en cliquant sur la fenêtre désirée. Une liste de propriétés est alors fournie, éventuellement avec des informations de formatage.

OPTIONS

-aide
Affiche un résumé des options de la ligne de commande.
-grammaire
Affiche une grammaire détaillée pour toutes les options de la ligne de commande.
-id id
Cet argument permet à l'utilisateur de sélectionner la fenêtre d'identifiant id sur la ligne de commande au lieu d'utiliser le pointeur pour sélectionner la fenêtre cible. Ceci est très utile pour le débogage d'applications X où la fenêtre cible n'est pas mappée à l'écran ou où l'utilisation du pointeur pourrait être impossible ou interférer avec l'application.
-nom nom
Cet argument permet à l'utilisateur de spécifier que la fenêtre nommée nom est la fenêtre cible sur la ligne de commande au lieu d'utiliser le pointeur pour sélectionner la fenêtre cible.
-police police
Cet argument permet à l'utilisateur de spécifier que les propriétés de la police police doivent être affichées.
-racine
Cet argument spécifie que la fenêtre racine de X est la fenêtre cible. Ceci est utile dans les situations où la fenêtre racine est complètement obstruée.
-affichage affichage
Cet argument vous permet de spécifier le serveur auquel se connecter ; voir X(7).
-longueur n
Spécifie qu'au plus n octets de toute propriété doivent être lus ou affichés.
-sans_type
Spécifie que le type de chaque propriété ne doit pas être affiché.
-fs fichier
Spécifie que le fichier fichier doit être utilisé comme source de formats supplémentaires pour les propriétés.
-cadre
Spécifie que lors de la sélection manuelle d'une fenêtre (c'est-à-dire si aucun des arguments -nom, -racine ou -id n'est donné), il faut regarder le cadre du gestionnaire de fenêtres (s'il existe) au lieu de chercher la fenêtre cliente.
-retirer nom-propriete
Spécifie le nom d'une propriété à retirer de la fenêtre indiquée.
-definir nom-propriete valeur
Spécifie le nom d'une propriété et une valeur de propriété, à définir sur la fenêtre indiquée.
-espionner
Examine les propriétés de la fenêtre indéfiniment, en recherchant les événements de changement de propriété.
-version
Affiche les informations de version du programme et quitte.
-f nom format [format_d]
Spécifie que le format pour nom doit être format et que le format_d pour nom doit être format_d. Si format_d est manquant, " = $0+\n" est supposé.

DESCRIPTION

Pour chacune de ces propriétés, sa valeur sur la fenêtre ou la police sélectionnée est affichée en utilisant les informations de formatage fournies le cas échéant. Si aucune information de formatage n'est fournie, les défauts internes sont utilisés. Si une propriété n'est pas définie sur la fenêtre ou la police sélectionnée, "non définie" est affiché comme valeur pour cette propriété. Si aucune liste de propriétés n'est donnée, toutes les propriétés possédées par la fenêtre ou la police sélectionnée sont affichées.

Une fenêtre peut être sélectionnée de quatre manières. Premièrement, si la fenêtre désirée est la fenêtre racine, l'argument -racine peut être utilisé. Si la fenêtre désirée n'est pas la fenêtre racine, elle peut être sélectionnée de deux manières sur la ligne de commande, soit par son numéro d'identifiant tel qu'obtenu par xwininfo, soit par son nom si la fenêtre possède un nom. L'argument -id sélectionne une fenêtre par son numéro d'identifiant, en décimal ou en hexadécimal (doit commencer par 0x), tandis que l'argument -nom sélectionne une fenêtre par son nom.

La dernière façon de sélectionner une fenêtre n'implique pas du tout la ligne de commande. Si aucun des arguments -police, -id, -nom et -racine n'est spécifié, un curseur en forme de réticule est affiché et l'utilisateur peut choisir n'importe quelle fenêtre visible en appuyant sur n'importe quel bouton de la souris dans la fenêtre désirée. S'il est désiré d'afficher les propriétés d'une police plutôt que celles d'une fenêtre, l'argument -police doit être utilisé.

Outre les quatre arguments ci-dessus et l'argument -aide pour obtenir de l'aide, et l'argument -grammaire pour lister la grammaire complète de la ligne de commande, tous les autres arguments de la ligne de commande sont utilisés pour spécifier à la fois le format des propriétés à afficher et comment les afficher. L'argument -longueur n spécifie qu'au plus n octets de toute propriété donnée seront lus et affichés. Ceci est utile par exemple lors de l'affichage du presse-papiers sur la fenêtre racine, ce qui pourrait s'étendre sur plusieurs pages si affiché en totalité.

Normalement, chaque nom de propriété est affiché en imprimant d'abord le nom de la propriété, puis son type (s'il en a un) entre parenthèses, suivi de sa valeur. L'argument -sans_type spécifie que les types de propriétés ne doivent pas être affichés. L'argument -fs est utilisé pour spécifier un fichier contenant une liste de formats pour les propriétés, tandis que l'argument -f est utilisé pour spécifier le format d'une seule propriété.

Les informations de formatage pour une propriété consistent en fait en deux parties, un format et un format_d. Le format spécifie le formatage réel de la propriété (c'est-à-dire s'il est composé de mots, d'octets ou de longs ?, etc.) tandis que le format_d spécifie comment la propriété doit être affichée.

Les paragraphes suivants décrivent comment construire les formats et les format_d. Cependant, pour la grande majorité des utilisateurs et des usages, cela ne devrait pas être nécessaire car les défauts intégrés contiennent les formats et les format_d nécessaires pour afficher toutes les propriétés standard. Il ne devrait être nécessaire de spécifier des formats et des format_d que si une nouvelle propriété est traitée ou si l'utilisateur n'aime pas le format d'affichage standard. Il est particulièrement conseillé aux nouveaux utilisateurs de sauter cette partie.

Un format se compose de 0, 8, 16 ou 32 suivi d'une séquence d'un ou plusieurs caractères de format. Le 0, 8, 16 ou 32 spécifie le nombre de bits par champ dans la propriété. Zéro est un cas spécial signifiant qu'il faut utiliser les informations de taille de champ associées à la propriété elle-même. (Ceci n'est nécessaire que pour des cas spéciaux comme le type INTEGER qui est en fait trois types différents selon la taille des champs de la propriété.)

Une valeur de 8 signifie que la propriété est une séquence d'octets, tandis qu'une valeur de 16 signifierait que la propriété est une séquence de mots. La différence entre ces deux réside dans le fait que la séquence de mots sera échangée en octets tandis que la séquence d'octets ne le sera pas lors de la lecture par une machine de l'ordre des octets opposé à la machine qui a initialement écrit la propriété. Pour plus d'informations sur la façon dont les propriétés sont formatées et stockées, consultez le manuel Xlib.

Une fois la taille des champs spécifiée, il est nécessaire de spécifier le type de chaque champ (c'est-à-dire est-ce un entier, une chaîne, un atome, ou quoi ?) Ceci est fait en utilisant un caractère de format par champ. S'il y a plus de champs dans la propriété que de caractères de format fournis, le dernier caractère sera répété autant de fois que nécessaire pour les champs supplémentaires. Les caractères de format et leur signification sont les suivants :

a
Le champ contient un numéro d'atome. Un champ de ce type doit être de taille 32.
b
Le champ est un booléen. Un 0 signifie faux tandis que tout autre chose signifie vrai.

xprop(1) - Arch manual pages

NAME

xprop - property display for X

SYNOPSIS

xprop [-options] [atom ...]

SUMMARY

The xprop utility is a client for X Window System which allows a user to interactively display or set properties on the X server. When run without any arguments, xprop will select a window chosen by the user (by clicking on it or pressing Enter after selecting it with the mouse) and display the values of all properties that are owned by that window. If you specify one or more atoms on the command line, then only those properties will be displayed.

OPTIONS

The following options are available:

-display display
Specifies the X server to contact.
-root
Use the root window instead of the current selection.
-id id
Specify the window id instead of the current selection.
-name name
Specify the name of the window instead of the current selection.
-font font
Specify the font instead of the current selection.
-len number
Limit the display of properties to the first number characters.
-format format
Specify the format to use when setting a property. This option must be used with the -set option.
-set atom
Set the specified property to the value specified on the command line. The value is given in a format that matches the -format option. This option must be used with the -format option.
-fs filename
Read formats from the specified file.
-remove
Remove the specified property. This option must be used with the -id, -name, or -root options. The property to be removed must be specified as an argument.
-removeall
Remove all properties from the specified window. This option must be used with the -id, -name, or -root options.

DESCRIPTION

When xprop is run, it will require you to select a window. You can select a window by moving the mouse pointer to it and pressing any mouse button, or by typing Return or Space after you have entered the program from the command line. Once a window is selected, xprop will display the properties of that window. If you supplied one or more atoms on the command line, then only those properties will be displayed.

If you want to specify a window by its id, or by its name, or the root window, you can use the -id, -name, or -root options respectively.

If you want to set a property, you can use the -set option. The property to be set is given as the argument to -set. The value of the property is given on the command line following the property name. The format of the value must match the format specified by the -format option. The format string is a sequence of characters that specify the type and size of the fields within the property. The format string is described in more detail below.

If you want to remove a property, you can use the -remove option. The property to be removed is given as an argument on the command line.

If you want to remove all properties from a window, you can use the -removeall option.

The following format characters are available:

c
Le champ est un nombre non signé, un cardinal.
i
Le champ est un entier signé.
m
Le champ est un ensemble d'indicateurs de bits, 1 signifiant activé.
o
Le champ est un tableau d'icônes, empaqueté sous forme d'une séquence de nombres de 32 bits comprenant la largeur, la hauteur et les valeurs de pixels ARGB, telles que définies pour la propriété _NET_WM_ICON dans la spécification des Extended Window Manager Hints. Un champ de ce type doit être de taille 32.
s
Ce champ et les suivants jusqu'à un 0 ou la fin de la propriété représentent une séquence d'octets. Ce caractère de format n'est utilisable qu'avec une taille de champ de 8 et est le plus souvent utilisé pour représenter une chaîne de caractères.
t
Ce champ et les suivants jusqu'à un 0 ou la fin de la propriété représentent une chaîne de texte internationalisée. Ce caractère de format n'est utilisable qu'avec une taille de champ de 8. La chaîne est supposée être dans un encodage conforme à l'ICCCM et est convertie dans l'encodage de la locale actuelle avant d'être sortie.
u
Ce champ et les suivants jusqu'à un 0 ou la fin de la propriété représentent une chaîne unicode encodée en UTF-8. Ce caractère de format n'est utilisable qu'avec une taille de champ de 8. Si la chaîne contient un caractère invalide, le type de violation d'encodage est affiché, suivi de la chaîne formatée en utilisant 's'. Dans un environnement incapable d'afficher des chaînes encodées en UTF-8, le comportement est identique à celui de 's'.
x
Le champ est un nombre hexadécimal (comme 'c' mais affiché en hexadécimal - le plus utile pour afficher les identifiants de fenêtres et similaires)

Un exemple de format est 32ica, ce qui correspond au format d'une propriété de trois champs de 32 bits chacun, le premier contenant un entier signé, le second un entier non signé et le troisième un atome.

Le format d'un dformat, contrairement à celui d'un format, n'est pas si rigide. Les seules limitations d'un dformat sont qu'on ne peut pas commencer par une lettre ou un tiret. Ceci afin qu'il puisse être distingué d'un nom de propriété ou d'un argument. Un dformat est une chaîne de texte contenant des caractères spéciaux indiquant que divers champs doivent être imprimés à divers endroits, de manière similaire à la chaîne de formatage utilisée par printf. Par exemple, le dformat " est ( $0, $1 \)\n" rendrait le POINT 3, -4, qui a un format de 32ii, en " est ( 3, -4 )\n".

Tout caractère autre qu'un $, ?, \, ou ( dans un dformat s'imprime tel quel. Pour imprimer un $, ?, \, ou ( , faites-le précéder d'un \. Par exemple, pour imprimer un $, utilisez \$. Plusieurs séquences d'échappement spéciales sont fournies comme raccourcis. \n provoquera un saut de ligne tandis que \t provoquera une tabulation. \o où o est un nombre octal affichera le caractère numéro o.

Un $ suivi d'un nombre n provoque l'affichage du champ numéro n. Le format d'affichage du champ dépend du caractère de formatage utilisé pour le décrire dans le format correspondant. C'est-à-dire, si un cardinal est décrit par 'c', il sera affiché en décimal, tandis que s'il est décrit par 'x', il sera affiché en hexadécimal.

Si le champ n'est pas présent dans la propriété (ce qui est possible avec certaines propriétés), <champ non disponible> s'affichera à la place. $n+ affiche le champ numéro n, puis une virgule, puis le champ numéro n+1, puis une autre virgule, etc., jusqu'au dernier champ défini. Si le champ n n'est pas défini, rien ne s'affiche. Ceci est utile pour une propriété qui est une liste de valeurs.

Un ? est utilisé pour commencer une expression conditionnelle, une sorte d'instruction if-then. ?exp(text) affichera text si et seulement si exp est évalué à non nul. Ceci est utile pour deux choses. Premièrement, cela permet d'afficher des champs si et seulement si un indicateur est activé. Et deuxièmement, cela permet à une valeur telle qu'un numéro d'état d'être affichée sous forme de nom plutôt que comme un simple nombre. La syntaxe de exp est la suivante :

exp
::= term | term=exp | !exp
term
::= n | $n | mn

L'opérateur ! est un ``not'' logique, changeant 0 en 1 et toute valeur non nulle en 0. = est un opérateur d'égalité. Notez qu'en interne, toutes les expressions sont évaluées comme des nombres de 32 bits, donc -1 n'est pas égal à 65535. = renvoie 1 si les deux valeurs sont égales et 0 sinon. n représente la valeur constante n tandis que $n représente la valeur du champ numéro n. mn vaut 1 si l'indicateur numéro n dans le premier champ ayant le caractère de format 'm' dans le format correspondant est 1, 0 sinon.

Exemples : ?m3(compte: $3\n) affiche le champ 3 avec l'étiquette compte si et seulement si l'indicateur numéro 3 (le comptage commence à 0 !) est activé. ?$2=0(Vrai)?!$2=0(Faux) affiche la valeur inversée du champ 2 comme un booléen.

Pour afficher une propriété, xprop a besoin à la fois d'un format et d'un dformat. Avant que xprop n'utilise ses valeurs par défaut d'un format de 32x et d'un dformat de " = { $0+ }\n", il recherche plusieurs emplacements pour tenter de trouver des formats plus spécifiques. D'abord, une recherche est effectuée en utilisant le nom de la propriété. Si cela échoue, une recherche est effectuée en utilisant le type de la propriété. Cela permet de définir le type STRING avec un ensemble de formats, tout en permettant à la propriété WM_NAME, qui est de type STRING, d'être définie avec un format différent. De cette manière, les formats d'affichage pour un type donné peuvent être remplacés pour des propriétés spécifiques.

Les emplacements recherchés sont, dans l'ordre : le format s'il est spécifié avec le nom de la propriété (comme dans 8x WM_NAME), les formats définis par les options -f du dernier au premier, le contenu du fichier spécifié par l'option -fs le cas échéant, le contenu du fichier spécifié par la variable d'environnement XPROPFORMATS le cas échéant, et enfin le fichier intégré de formats de xprop.

Le format des fichiers auxquels font référence l'argument -fs et la variable XPROPFORMATS est constitué d'une ou plusieurs lignes de la forme suivante :

nom format [dformat]

Où nom est soit le nom d'une propriété, soit le nom d'un type, format est le format à utiliser avec nom et dformat est le dformat à utiliser avec nom. Si dformat est absent, " = $0+\n" est supposé.

EXAMPLES

Pour afficher le nom de la fenêtre racine : xprop -root WM_NAME

Pour afficher les indications du gestionnaire de fenêtres pour l'horloge : xprop -name xclock WM_HINTS

Pour afficher le début du tampon de coupe : xprop -root -len 100 CUT_BUFFER0

Pour afficher la taille de point de la police fixe : xprop -font fixed POINT_SIZE

Pour afficher toutes les propriétés de la fenêtre # 0x200007 : xprop -id 0x200007

Pour définir une propriété de chaîne simple : xprop -root -format MY_ATOM_NAME 8s -set MY_ATOM_NAME "ma_valeur"

ENVIRONMENT

DISPLAY
Pour obtenir l'affichage par défaut.
XPROPFORMATS
Spécifie le nom d'un fichier à partir duquel des formats supplémentaires doivent être obtenus.
