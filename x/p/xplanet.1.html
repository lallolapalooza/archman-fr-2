XPLANET(1) Manuel des commandes générales XPLANET(1)

NOM

xplanet - rendu d'une image d'une planète dans une fenêtre X ou un fichier

SYNTAXE

xplanet [options]

DESCRIPTION

Xplanet est similaire à Xearth, qui rend une image de la Terre dans une fenêtre X. Toutes les planètes majeures et la plupart des satellites peuvent être dessinés. Un certain nombre de projections cartographiques différentes sont également prises en charge, notamment azimutale, Mercator, Mollweide, orthographique et rectangulaire. La dernière version est toujours disponible sur http://xplanet.sourceforge.net.

OPTIONS

Les options n'ont besoin d'être spécifiées qu'avec suffisamment de caractères pour être sans ambiguïté. Les options valides pour Xplanet sont :

-fichier_arc
Spécifie un fichier d'arcs à tracer sur l'arrière-plan des étoiles. Chaque ligne du fichier doit respecter la syntaxe suivante : 
dec1 asc1 dec2 asc2
où la déclinaison est en degrés et l'ascension droite en heures. Cette option n'a aucun effet si -projection est spécifié.
-espacement_arc espacement
Lors du dessin d'un arc, dessine des segments de ligne espacés de spacing degrés. La valeur par défaut est de 0,1 degrés. Les segments de ligne plus courts que spacing ne seront pas dessinés.
-epaisseur_arc epaisseur
Spécifie l'épaisseur des arcs. La valeur par défaut est de 1 pixel. Lors du dessin d'arcs sur une planète en utilisant l'option fichier_arc dans le fichier de configuration, utilisez également l'option epaisseur_arc là-bas.
-fond fichier_fond
Utilise fichier_fond comme image de fond, sur laquelle la planète sera superposée. Une couleur peut également être fournie (par exemple, -fond « bleu marine » ou -fond 0xff00ff).
-magnitude_base magnitude
Une étoile de magnitude spécifiée aura une luminosité d'un pixel de 1. La valeur par défaut est 10. Les étoiles seront dessinées plus brillamment si ce nombre est plus grand.
-corps corps
Rendre une image de la planète ou du satellite spécifié. Les valeurs valides pour corps sont soleil, mercure, vénus, terre, lune, mars, phobos, deimos, jupiter, io, europa, ganymede, callisto, saturne, mimas, encelade, tethys, dione, rhea, titan, hyperion, iapetus, phoebe, uranus, miranda, ariel, umbriel, titania, oberon, neptune, triton, nereid, pluton, charon, aléatoire et majeur.

Le champ de vision peut également être centré sur une position de satellite en utilisant « naif » ou « norad », ainsi que l'identifiant du satellite. Par exemple, « -corps naif-82 » centrera le champ de vision sur l'ID NAIF -82, qui est la sonde Cassini. Xplanet doit être compilé avec le support SPICE et les noyaux requis doivent être présents. Voir le README dans le sous-répertoire spice pour plus de détails. L'utilisation de « -corps norad20580 » centrera le champ de vision sur l'ID NORAD 20580, qui est le télescope spatial Hubble. Les fichiers TLE appropriés doivent être présents dans ce cas. Voir le README dans le sous-répertoire satellites pour plus d'informations.

Utiliser « chemin » centrera le champ de vision sur la direction du mouvement de l'origine. Cette direction est relative à la direction du mouvement du corps spécifié par -chemin_relatif_à.

La Terre est le corps par défaut. Cette option est la même que -cible.

-centre +x+y
Place le centre du corps rendu aux coordonnées pixel (x, y). Le coin supérieur gauche de l'écran est à (0,0). x ou y peut être négatif. La valeur par défaut est le centre de l'écran.
-couleur couleur
Définit la couleur de l'étiquette. La valeur par défaut est « rouge ». Toute couleur du fichier rgb.txt peut être utilisée. Les couleurs peuvent également être spécifiées par des valeurs hexadécimales RVB ; par exemple -couleur 0xff et -couleur bleu signifient la même chose, tout comme -couleur 0xff0000 et -couleur rouge.
-config fichier_config
Utilise le fichier de configuration fichier_config. Le format de fichier_config est décrit dans README.config. Voir la description de -recherche_rep pour voir où xplanet recherche pour trouver le fichier de configuration.
-creer_tables_dispersion fichier_dispersion
Crée des tables de recherche pour la dispersion de Rayleigh. Voir le README dans le répertoire dispersion pour plus d'informations.
-date AAAA MM JJ.HHMMSS
Utilise la date spécifiée au lieu de l'heure locale actuelle. La date est supposée être en GMT.
-format_date chaine
Spécifie le format de l'étiquette de date/heure. Cette chaîne de format est passée à strftime(3). La valeur par défaut est « %c %Z », qui affiche la date, l'heure et le fuseau horaire dans la représentation appropriée de la date et de l'heure de la locale.
-origine_dynamique fichier
Spécifie un emplacement d'observateur. L'emplacement est relatif au corps spécifié avec -origine (par défaut, c'est le Soleil). La dernière ligne du fichier doit être de la forme 
AAAA MM JJ.HHMMSS plage lat lon heure_locale
Par exemple, 
19951207.120000     10.328   -3.018   97.709    9.595
L'heure spécifiée est ignorée et l'heure actuelle est utilisée. La plage est en rayons planétaires, et lat et lon sont en degrés. L'heure locale (en heures) est facultative, mais si elle est présente, elle sera utilisée à la place de la longitude. Seule la dernière ligne du fichier est utilisée. Ce fichier peut être mis à jour entre les rendus à l'aide d'un script exécuté avec les options -commande_precedente ou -commande_suivante.
-fichier_ephémérides nom_fichier
Spécifie un fichier d'éphémérides numériques JPL (DE200, DE405 ou DE406) à utiliser pour calculer les positions planétaires. Xplanet utilise le code de Bill Gray (http://www.projectpluto.com/jpl_eph.htm), qui lit les fichiers binaires en big et little endian. Les fichiers d'éphémérides trouvés sur ftp://ssd.jpl.nasa.gov/pub/eph/export/unix sont des fichiers big endian, mais vous n'avez pas besoin de faire d'échange d'octets supplémentaire pour les utiliser. Voir la description de -recherche_rep pour voir où xplanet recherche pour trouver le fichier d'éphémérides.
-police nom_police
Définit la police pour l'étiquette. Seules les polices TrueType sont prises en charge. Si l'option -pango est utilisée, nom_police est pris comme nom de famille de police (par exemple, « Arial »).
-taille_police taille
Spécifie la taille en points. La valeur par défaut est 12.
-fork
Détache du terminal de contrôle. Ceci est utile sous MS Windows pour exécuter xplanet à partir d'un fichier batch sans avoir à garder une fenêtre DOS ouverte. Soyez prudent lorsque vous utilisez cette option ; il est facile d'avoir plusieurs processus en cours d'exécution en même temps sans le savoir - vérifiez le Gestionnaire des tâches. Sur les systèmes Unix, cela revient à peu près à exécuter xplanet en arrière-plan.
-fov
Spécifie le champ de vision, en degrés. Cette option et l'option -rayon sont mutuellement exclusives. Cette option n'a aucun effet si l'option -projection est utilisée.
-geometrie chaine
Spécifie la géométrie de l'image en utilisant la syntaxe standard de géométrie des fenêtres X, [<largeur>{xX}<hauteur>][{+-}<offset_x>{+-}<offset_y>] (par exemple, 256x256-10+10 place une fenêtre de 256x256 pixels à 10 pixels du bord droit et 10 pixels du bord supérieur de la fenêtre racine). La fenêtre racine à l'extérieur de l'image sera noire. Cette option peut être utilisée avec -fenetre ou -sortie.
-eclat rayon
Dessine un éclat autour du soleil avec un rayon du rayon spécifié plus grand que le soleil. La valeur par défaut est 28.
-etiquette_gmt
Identique à l'option -etiquette, mais affiche l'heure GMT au lieu de l'heure locale.
-grs_longitude lon
La longitude de la Grande Tache Rouge (GRS) de Jupiter. Une valeur typique est de 94 degrés. Si cette option est spécifiée, les longitudes sur Jupiter seront calculées selon les coordonnées du Système II. Par défaut, les longitudes sont calculées selon les coordonnées du Système III. Lorsque vous utilisez cette option, utilisez une carte d'image pour Jupiter où le centre de la GRS se trouve à la colonne de pixels 0, ou sur le bord gauche de l'image.
-hibernate secondes
Après que l'écran soit resté inactif pendant le nombre spécifié de secondes, xplanet entrera en veille. Cette option nécessite que xplanet ait été compilé avec l'extension X Screensaver.
-idlewait secondes
Ne pas exécuter Xplanet à moins que l'écran ne soit resté inactif pendant le nombre spécifié de secondes. Cette option nécessite que xplanet ait été compilé avec l'extension X Screensaver.
-interpolate_origin_file
Cette option n'est utile qu'en conjonction avec -origin_file. Elle calcule la position de l'observateur au moment présent en interpolant entre les valeurs spécifiées dans le fichier d'origine. Ceci est utile si vous avez les positions de sondes spatiales tabulées dans un fichier d'origine, mais que vous souhaitez une vue en temps réel.
-jdate date julienne
Utiliser la date julienne spécifiée au lieu de l'heure locale actuelle.
-label
Afficher une étiquette dans le coin supérieur droit.
-labelpos
Spécifier l'emplacement de l'étiquette en utilisant la syntaxe standard de géométrie des fenêtres X. La position par défaut est « -15+15 », c'est-à-dire 15 pixels à gauche et en dessous du coin supérieur droit de l'affichage. Cette option implique -label.
-label_altitude
Afficher l'altitude au-dessus de la surface au lieu de la distance par rapport au centre du corps dans l'étiquette.
-label_body corps
Utiliser le corps spécifié pour calculer les valeurs de sous-observateur, sous-solaire et d'illumination dans l'étiquette. Ceci est utile avec l'option -separation.
-label_string
Spécifier le texte de la première ligne de l'étiquette. Par défaut, il indique quelque chose comme « Regarder la Terre ». Toutes les occurrences de %t seront remplacées par le nom de la cible, et toutes les occurrences de %o seront remplacées par le nom de l'origine.
-latitude latitude
Rendre le corps cible tel que vu depuis au-dessus de la latitude spécifiée (en degrés). La valeur par défaut est 0.
-light_time
Tenir compte du temps nécessaire à la lumière pour voyager du corps cible à l'observateur. Par défaut, les effets du temps de trajet de la lumière sont ignorés.
-localtime heure locale
Placer l'observateur au-dessus de la longitude où l'heure locale est la valeur spécifiée. 0 est minuit et 12 est midi.
-log_magstep pas
Augmenter la luminosité d'une étoile de 10^step pour chaque diminution entière de magnitude. La valeur par défaut est 0.4. Cela signifie qu'une étoile de magnitude 2 est 10^0.4 (environ 2,5) fois plus brillante qu'une étoile de magnitude 3. Un nombre plus grand rend les étoiles plus lumineuses.
-longitude longitude
Placer l'observateur au-dessus de la longitude spécifiée (en degrés). La longitude est positive vers l'est, négative vers l'ouest (pour la Terre et la Lune), donc par exemple Los Angeles est à -118 ou 242. La valeur par défaut est 0.
-make_cloud_maps
S'il existe une entrée dans le fichier de configuration pour cloud_map, xplanet générera une image de jour et une image de nuit avec les nuages superposés, puis se terminera. Les images seront créées dans le répertoire spécifié par -tmpdir, ou dans le répertoire actuel si -tmpdir n'est pas utilisé. Les noms des images de sortie sont par défaut day_clouds.jpg et night_clouds.jpg, mais peuvent être modifiés par l'option -output. Si « -output filename.extension » est spécifié, les images de sortie seront nommées « day_filename.extension » et « night_filename.extension ». Les dimensions des images de sortie sont les mêmes que celles de l'image de jour.
-marker_file
Spécifier un fichier contenant des données de marqueurs définies par l'utilisateur à afficher contre les étoiles d'arrière-plan. Le format de chaque ligne est généralement déclinaison, ascension droite, chaîne de caractères, comme dans l'exemple ci-dessous : 
-16.7161 6.7525 « Sirius »
Pour des options supplémentaires qui peuvent être spécifiées, voir l'entrée marker_file dans README.config. Cette option n'a aucun effet si -projection est spécifié. Cette option n'est pas destinée aux marqueurs de villes ; pour cela, utilisez l'option marker_file dans le fichier de configuration.
-markerbounds nom de fichier
Écrire les coordonnées de la boîte englobante pour chaque marqueur dans le fichier. Ceci pourrait être utile si vous utilisez xplanet pour créer des imagemaps pour des pages Web. Chaque ligne ressemble à ceci : 
204,312 277,324 Los Angeles
où les coordonnées sont pour les coins supérieur gauche et inférieur droit de la boîte. Ce fichier est réécrit chaque fois que xplanet rend son image.
-north type_nord
Cette option fait pivoter l'image de sorte que le haut pointe vers north_type. Les valeurs valides pour north_type sont : 
corps :       pôle nord du corps
galactique :    pôle nord galactique
orbite :       pôle nord orbital du corps (perpendiculaire au plan de l'orbite)
trajectoire :  vecteur de vitesse de l'origine (voir aussi l'option -path_relative_to)
séparation :   perpendiculaire à la ligne de visée et à la
             ligne cible-séparation cible (voir l'option -separation)
La valeur par défaut est « corps ».
-num_times nombre_de_fois
Exécuter num_times avant de se terminer. Par défaut, l'exécution est indéfinie.
-origin corps
Placer l'observateur au centre du corps spécifié. Les valeurs valides sont les mêmes que pour -target. De plus, « above », « below » ou « system » peuvent être spécifiés. Utiliser « above » ou « below » centre la vue sur le primaire du corps et le champ de vision est suffisamment grand pour montrer l'orbite du corps. Utiliser « system » place l'observateur au centre d'un corps aléatoire dans le même système que le corps cible. Deux corps sont dans le même système si l'un des éléments suivants est vrai : 
 1) cible et origine ont le même primaire
 2) cible est le primaire de l'origine
 3) origine est le primaire de la cible
Si le nom du corps est précédé d'un tiret, l'observateur est placé du côté opposé de la cible par rapport au corps spécifié, à une distance égale à la distance entre la cible et le corps. Par exemple, -target earth -origin sun place l'observateur au centre du soleil. Si -target earth -origin -sun est utilisé, l'observateur est placé sur une ligne reliant les centres de la Terre et du Soleil à une distance de 1 UA plus loin du Soleil que la Terre.
-origin_file fichier d'origine
Spécifier une liste de positions d'observateur dans origin_file. Les positions sont relatives au corps spécifié avec -origin (par défaut, c'est le Soleil). Chaque ligne doit être de la forme 
AAAAMMJJ.HHMMSS portée lat lon heure locale
Par exemple, 
19951207.120000     10.328   -3.018   97.709    9.595
La portée est en rayons planétaires, et lat et lon sont en degrés. La date est la seule valeur requise. Si l'heure locale (en heures) est fournie, elle sera utilisée à la place de la longitude. Pour chaque ligne du fichier d'origine, l'observateur est placé à la position spécifiée, par rapport au corps spécifié avec -origin. Cette option est utile pour montrer des survolages de sondes spatiales ou des orbites autour d'une planète. Toute ligne commençant par # est ignorée.
-output nom de fichier
Sortir dans un fichier au lieu de rendre dans une fenêtre. Le format du fichier est déterminé par l'extension. Actuellement, des images .gif, .jpg, .ppm, .png et .tiff peuvent être créées, si xplanet a été compilé avec les bibliothèques appropriées. La taille de l'image par défaut est de 512 par 512 pixels, mais cela peut être changé par le drapeau -geometry. Si utilisée avec l'option -num_times, chaque fichier de sortie sera numéroté séquentiellement.
-output_map nom de fichier
Sortir la carte rectangulaire intermédiaire créée lors du rendu de l'image finale. Elle aura les mêmes dimensions que la carte de jour par défaut.
-output_start_index index
Commencer la numérotation des fichiers de sortie à l'index. La valeur par défaut est 0.
-pango
Utiliser la bibliothèque Pango (http://www.pango.org) pour le rendu de texte internationalisé. Pango utilise Unicode pour tout son encodage, et supportera à terme la sortie dans toutes les principales langues du monde. Si xplanet n'a pas été compilé avec cette bibliothèque, cette option sera ignorée. Il semble y avoir des fuites de mémoire dans la bibliothèque pango, donc je ne recommande pas de laisser xplanet fonctionner indéfiniment avec cette option.
-path_relative_to corps
Uniquement utilisé avec -north path ou -target path. Le vecteur de vitesse de l'origine est calculé par rapport au corps spécifié. Par défaut, il s'agit du Soleil.
-post_command commande
-prev_command commande
Exécuter une commande avant ou après chaque rendu d'image par xplanet. Sur MS Windows, vous devrez peut-être utiliser des chemins de style Unix. Par exemple : 
xplanet.exe -prev_command ./prev.bat
-print_ephemeris
Imprimer les coordonnées équatoriales rectangulaires héliocentriques (J2000) pour chaque corps connu de xplanet, puis se terminer.
-projection projection_type
Le type de projection peut être l'un des suivants : ancient, azimuthal, bonne, equal_area, gnomonic, hemisphere, lambert, mercator, mollweide, orthographic, peters, polyconic, rectangular, ou tsc. La valeur par défaut est aucune projection. Plusieurs corps ne seront pas affichés si cette option est spécifiée, bien que les ombres soient toujours dessinées.
-proj_param value
Transmet des paramètres supplémentaires pour certaines projections. Les seules projections qui utilisent actuellement cette option sont les projections de Bonne, Gnomonique et Mercator. La projection de Bonne est conforme à la latitude spécifiée. Des valeurs plus élevées conduisent à une forme de cœur plus mince. La valeur par défaut est de 50 degrés. Les projections Gnomonique et Mercator utilisent la latitude spécifiée comme limites de la projection. Les valeurs par défaut sont respectivement de 45 et 80 degrés. Cette option peut être utilisée plusieurs fois pour des projections futures qui nécessitent des paramètres supplémentaires. Seule la première valeur est utilisée actuellement.
-quality qualité
Cette option n'est utilisée que lors de la création d'images JPEG. La qualité peut varier de 0 à 100. La valeur par défaut est 80.
-radius rayon
Spécifie le rayon du globe en pourcentage de la hauteur de l'écran. La valeur par défaut est 45 % de la hauteur de l'écran. Lors du dessin de Saturne, la valeur du rayon s'applique au rayon de l'anneau extérieur.
-random
Place l'observateur à une latitude et une longitude aléatoires.
-range portée
Rend le globe tel que vu à une distance `portée` du centre de la planète, en unités du rayon planétaire. La valeur par défaut est 1000. Notez que si vous utilisez des portées très courtes, le champ de vision de l'écran peut dépasser 180 degrés ! Si vous voulez une image rapprochée, utilisez l'option -radius.
-rotate angle
Fait pivoter le globe de `angle` degrés dans le sens inverse des aiguilles d'une montre, de sorte que le nord (tel que défini par l'argument -north) ne soit pas en haut. La valeur par défaut est 0. Mes amis de l'hémisphère sud peuvent utiliser -rotate 180 pour que la Terre ressemble à ce qu'elle devrait être ! Pour les projections non orthographiques, le globe est tourné puis projeté, si cela peut vous aider à visualiser ce à quoi vous attendre.
-save_desktop_file
Sur Microsoft Windows et Mac OS X, xplanet crée un fichier image intermédiaire utilisé pour définir le bureau. Ce fichier sera créé dans le répertoire -tmpdir. Par défaut, cette image est supprimée après la définition du bureau. La spécification de cette option laissera le fichier en place.
-searchdir répertoire
Tous les fichiers utilisés par xplanet doivent être placés dans l'un des répertoires suivants en fonction de leur type : "arcs", "config", "ephemeris", "fonts", "images", "markers", "origin", "satellites", ou "stars". Par défaut, xplanet recherchera un fichier dans l'ordre suivant : 
Le répertoire courant
répertoire de recherche
sous-répertoires du répertoire de recherche
sous-répertoires de xplanet (s'il existe dans le répertoire courant)
sous-répertoires de ${HOME}/.xplanet sur X11
sous-répertoires de ${HOME}/Library/Xplanet sur Mac OS X
sous-répertoires de DATADIR/xplanet
DATADIR est défini lors de la compilation et vaut par défaut /usr/local/share.
-separation corps:dist
Place l'observateur à un endroit où le corps cible et le corps de séparation sont séparés de `dist` degrés. Par exemple, "-target earth -separation moon:-3" signifie placer l'observateur à un endroit où la lune apparaît 3 degrés à gauche de la Terre.
-spice_ephemeris indice
Utilise les noyaux SPICE pour calculer la position du corps nommé. L'indice est le code d'identification naif (par exemple, 599 pour Jupiter). L'option -spice_file doit être utilisée pour fournir les noms des fichiers noyaux. Cette option peut être utilisée plusieurs fois pour différents corps.
-spice_file fichier_spice
Spécifie un fichier contenant une liste d'objets à afficher. Un fichier contenant une liste de noyaux SPICE à lire, nommé spice_file.krn, doit exister avec spice_file. Voir le README dans le sous-répertoire "spice" pour plus d'informations.
-starfreq fréquence
Fraction des pixels d'arrière-plan qui seront colorés en blanc. La valeur par défaut est 0.001. Cette option n'est significative qu'avec les projections azimuthal, mollweide, orthographic et peters.
-starmap carte_étoiles
Utilise `carte_étoiles` pour dessiner les étoiles d'arrière-plan. Ce fichier doit être un fichier texte où chaque ligne a le format suivant : 
Déclinaison, Ascension droite, Magnitude
où la Déclinaison est en degrés décimaux et l'Ascension droite est en heures décimales. Par exemple, l'entrée pour Sirius est 
-16.7161  6.7525 -1.46
Voir la description de -searchdir pour savoir où xplanet recherche pour trouver la carte des étoiles.
-target cible
Identique à -body.
-tt
Utilise le temps terrestre au lieu du temps universel. Les deux diffèrent légèrement en raison de la rotation non uniforme de la Terre. La valeur par défaut est d'utiliser le temps universel.
-timewarp
Comme dans xearth, multiplie le taux apparent auquel le temps progresse par un facteur. La valeur par défaut est 1.
-tmpdir tmpdir
Spécifie un répertoire que xplanet utilisera pour placer les images créées avec -make_cloud_maps. Sur Microsoft Windows, xplanet écrira un fichier bitmap nommé xplanet.bmp dans le répertoire spécifié. La valeur par défaut est le résultat de l'appel GetWindowsDirectory (C:WINDOWS sur Win95). Sur Mac OS X, xplanet créera un fichier PNG intermédiaire pour définir l'arrière-plan. La valeur par défaut est /tmp. Sur Windows et Mac OS X, le fichier intermédiaire sera supprimé à moins que l'option -save_desktop_file ne soit spécifiée.
-transparency
Met à jour le pixmap d'arrière-plan pour les termes et atomes transparents. Cette option ne fonctionne que sous X11.
-transpng nom_fichier
Identique à l'option -output, sauf que l'arrière-plan est rendu transparent lors de l'écriture d'un fichier PNG.
-utclabel
Identique à -gmtlabel.
-verbosity niveau
niveau      sortie
< 0        uniquement les messages d'erreur fatals
0          messages d'avertissement non fatals
1          informations de base
2          diagnostics de base
3          diagnostics plus détaillés
4          diagnostics très détaillés
La valeur par défaut est 0.
-version
Affiche les informations sur la version actuelle, ainsi qu'une liste des options de compilation prises en charge par xplanet.
-vroot
Rend l'image dans la fenêtre racine virtuelle. Certains gestionnaires de fenêtres utilisent une grande fenêtre qui se superpose à la fenêtre racine réelle comme fenêtre d'arrière-plan. Xscreensaver utilise également une fenêtre racine virtuelle pour couvrir l'écran.
-wait attente
Met à jour toutes les `attente` secondes.
-window
Rend l'image dans sa propre fenêtre X. La taille par défaut est de 512 par 512 pixels, mais cela peut être défini par le drapeau -geometry.
-window-id ID
Lors de l'utilisation du système de fenêtrage X11, dessine dans la fenêtre avec l'ID spécifié.
-window_title titre
Définit le titre de la fenêtre à `titre`. Cette option implique -window.
-XID ID
Identique à -window-id.
-xscreensaver
Identique à -vroot.
