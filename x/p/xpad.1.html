NOM

xpad - Une application de notes autocollantes pour GTK+ 3.0

SYNTAXE

xpad [OPTIONS]

DESCRIPTION

Une application de notes autocollantes pour GTK+ 3.0.

OPTIONS

-v, --version
Affiche les informations de version.
-?, --help
Affiche les informations d'utilisation.
-h, --hide
Masque les notes existantes au démarrage. Toutes les notes seront masquées, donc à moins que l'icône dans la barre système ne soit présente ou que vous ne spécifiiez également --new, xpad se fermera immédiatement.
-s, --show
Affiche les notes existantes au démarrage.
-t, --toggle
Bascule entre l'affichage et le masquage de chaque note existante au démarrage.
-n, --new
Ouvre une nouvelle note.
-N, --no-new
Empêche xpad de créer une nouvelle note au démarrage. Une nouvelle note serait créée si xpad est déjà en cours d'exécution et est relancé, ou s'il n'y a pas d'anciennes notes à charger.
-f, --new-from-file=FICHIER
Crée une nouvelle note avec le contenu d'un fichier
-q, --quit
Ferme toutes les notes ouvertes et termine le processus xpad.
