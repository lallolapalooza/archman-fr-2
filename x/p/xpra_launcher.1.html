NOM

xpra_launcher - Interface utilisateur pour se connecter à une session Xpra

SYNTAXE

xpra_launcher [NOMFICHIER]

DESCRIPTION

xpra_launcher est un outil qui vous permet de vous connecter à une session xpra(1) distante à l'aide d'une interface utilisateur graphique. Il est capable de lire un fichier de session préconfiguré.

Lorsqu'il est appelé sans NOMFICHIER, xpra_launcher lancera une fenêtre GTK vous permettant de définir facilement les paramètres de connexion. Si NOMFICHIER est spécifié, les paramètres de l'interface graphique seront définis selon les valeurs spécifiées dans le fichier de session. De plus, si le fichier de session contient le paramètre spécial "autoconnect", xpra_launcher ignorera l'affichage de la fenêtre des paramètres et établira la connexion directement.

FICHIER DE SESSION

Le format du fichier de session passé à xpra_launcher en tant que paramètre est une série de lignes paramètre = valeur. La plupart des options disponibles via la ligne de commande xpra sont également disponibles dans le fichier de session. Par exemple :

hote
Spécifie l'hôte distant auquel se connecter.
port
Spécifie le port distant auquel se connecter.
encodage
Spécifie le type d'encodage à utiliser : h264, jpeg, png, ... Voir xpra --help pour la liste complète des encodages disponibles.
qualite
Définit la qualité de l'image lors de l'utilisation d'encodages avec perte. Les valeurs sont comprises entre 1 et 100.
mode
Mode de connexion : tcp ou ssh.
autoconnect
Spécifie s'il faut établir la connexion immédiatement (True) ou simplement pré-remplir les paramètres pour que l'utilisateur les examine (False, par défaut).
