FBB::Xpointer(3bobcat) Définit le pointeur X FBB::Xpointer(3bobcat)

NOM

FBB::Xpointer - Définit l'emplacement du pointeur X-windows

SYNOPIS

#include <bobcat/xpointer>

Option de liaison : -lbobcat -lX11

DESCRIPTION

Cette classe permet aux programmes s'exécutant dans l'environnement graphique X de définir et de récupérer l'emplacement du pointeur X-windows.

ESPACE NOMINAL

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

-

CONSTRUCTEURS

o
Xpointer():
Le constructeur par défaut. Se connecte au Display. Lance une exception Exception si le display ne peut pas être ouvert. Avec plusieurs objets Xpointer, la connexion au display n'est ouverte qu'une seule fois.
Ce constructeur lance une exception Exception s'il n'a pas pu se connecter au Display.

Les constructeurs et opérateurs de copie et de déplacement sont disponibles.

FONCTIONS MEMBRES

o
bool get(int *x, int *y) const:
Retourne dans ses arguments les coordonnées actuelles du pointeur relatives à la fenêtre racine. En cas de succès, true est retourné ; false est retourné si le pointeur n'a pas pu être déplacé.
o
bool set(int x, int y) const:
Définit le pointeur à un emplacement dont les coordonnées pixel sont données par rapport à la fenêtre racine. Une coordonnée x négative est mesurée à partir de la marge droite de l'écran de la fenêtre racine (en allant vers la gauche), une coordonnée y négative est mesurée à partir de la marge inférieure de l'écran de la fenêtre racine (en allant vers le haut). En cas de succès, true est retourné ; false est retourné si le pointeur n'a pas pu être déplacé.

EXEMPLE

#include <iostream>
#include <string>
#include <bobcat/xpointer>
using namespace FBB;
int main()
try
{
    Xpointer xpointer;
    xpointer.verify();
    if (!xpointer.set(100, 200))
        throw string("Échec de la définition du pointeur");
    int x;
    int y;
    if (!xpointer.get(&x, &y))
        throw string("Échec de la récupération du pointeur");
    cout << "Le pointeur est maintenant à " << x << ", " << y << ’\n’;
}
catch (string msg)
{
    cout << msg << ’\n’;
    return 1;
}
