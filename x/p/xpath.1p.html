NOM

xpath - un script pour interroger des instructions XPath dans des documents XML.

SYNTAXE

xpath [-s suffixe] [-p préfixe] [-n] [-q] -e requête [-e requête] ... [fichier] ...

DESCRIPTION

xpath utilise le module Perl XML::XPath pour effectuer des requêtes XPath sur n'importe quel document XML. Le module XML::XPath vise à se conformer exactement à la spécification XPath à l'adresse "http://www.w3.org/TR/xpath" et permet néanmoins d'ajouter des extensions sous forme de fonctions.

Le script prend un nombre quelconque de pointeurs XPath et tente de les appliquer à chaque document XML donné sur la ligne de commande. Si aucun argument de fichier n'est donné, la requête est effectuée en utilisant "STDIN" comme document XML.

Lorsque plusieurs requêtes existent, le résultat de la dernière requête est utilisé comme contexte pour la requête suivante et seul le résultat de la dernière est affiché. Le contexte de la première requête est toujours la racine du document courant.

OPTIONS

-q

Soyez silencieux. Affichez uniquement les erreurs (et aucun séparateur) sur stderr.

-n

N'utilisez jamais de DTD externe, c'est-à-dire instanciez le module XML::Parser avec 'ParseParamEnt => 0'.

-s suffixe

Placez "suffixe" à la fin de chaque entrée. Par défaut, il s'agit d'un retour à la ligne.

-p préfixe

Placez "préfixe" avant chaque entrée. Par défaut, il n'y a rien.
