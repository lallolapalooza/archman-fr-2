xpdf(1) Manuel des commandes générales xpdf(1)

NOM

xpdf - visualiseur de fichiers au format Portable Document Format (PDF) (version 4.05)

SYNTAXE

xpdf [options] [fichier-PDF [:page | +destination]] ...

xpdf [options] -remote nom-distant [commande ...]

xpdf [options] -open [fichier-PDF]

DESCRIPTION

Xpdf est un visualiseur de fichiers au format Portable Document Format (PDF). (Ils sont aussi parfois appelés fichiers ´Acrobat', du nom du logiciel PDF d'Adobe.) Xpdf utilise la boîte à outils graphique Qt et fonctionne sous Unix, OS X et Windows.

Pour exécuter xpdf, tapez :

xpdf fichier.pdf

où fichier.pdf est votre fichier PDF. Le nom du fichier peut être suivi d'un numéro de page à afficher, préfixé par un deux-points :

xpdf fichier.pdf :18

ou par une destination nommée, préfixée par ´+' (ceci n'est utile qu'avec des fichiers PDF qui fournissent des cibles de destination nommées) :

xpdf fichier.pdf +destinationA

Si vous spécifiez plusieurs fichiers, chacun sera ouvert dans un onglet séparé :

xpdf fichier1.pdf fichier2.pdf :18 fichier3.pdf

Vous pouvez aussi lancer xpdf sans ouvrir de fichier :

xpdf

FICHIER DE CONFIGURATION

Xpdf lit un fichier de configuration au démarrage. Il essaie d'abord de trouver le fichier de configuration privé de l'utilisateur, ~/.xpdfrc. S'il n'existe pas, il cherche un fichier de configuration à l'échelle du système, typiquement /etc/xpdfrc (mais cet emplacement peut être modifié lors de la compilation de xpdf). Voir la page de manuel xpdfrc(5) pour plus de détails.

OPTIONS

Les options de ligne de commande suivantes sont disponibles. Toutes les options de ligne de commande doivent précéder les fichiers PDF à ouvrir.

Beaucoup des options peuvent être définies avec des commandes de fichier de configuration. Celles-ci sont listées entre crochets avec la description de l'option de commande correspondante.

-geometry geometrie
Définit la géométrie initiale de la fenêtre.
-title titre
Définit le titre de la fenêtre. Par défaut, le titre sera "xpdf: foo.pdf".
-open [fichier-PDF]
Cette option configure un serveur distant par défaut. Si Xpdf est déjà en exécution (avec le commutateur « -open »), le fichier PDF (le cas échéant) est ouvert dans un nouvel onglet. Si Xpdf (avec le commutateur « -open ») n'est pas déjà en cours d'exécution, démarre Xpdf et ouvre le fichier PDF (le cas échéant). Ceci est utile pour les environnements de bureau graphiques, par exemple, le double-clic typique sur un fichier PDF.
-rv
Mode vidéo inversé. Inverse les couleurs de tout, sauf des images. Cela peut ne pas toujours produire d'excellents résultats pour les fichiers PDF qui utilisent des couleurs de manière inhabituelle. Cela fait également que la couleur du papier est noire par défaut.
-papercolor couleur
Définit la couleur du "papier", c'est-à-dire l'arrière-plan de l'affichage de la page. La couleur peut être #RRGGBB (hexadécimale) ou une couleur nommée. Cette option ne fonctionnera pas bien avec les fichiers PDF qui font des choses comme remplir de blanc derrière le texte. [fichier de config : paperColor]
-mattecolor couleur
Définit la couleur du tapis, c'est-à-dire la couleur utilisée pour l'arrière-plan en dehors de la zone de page réelle. La couleur peut être #RRGGBB (hexadécimale) ou une couleur nommée. [fichier de config : matteColor]
-fsmattecolor couleur
Définit la couleur du tapis pour le mode plein écran. La couleur peut être #RRGGBB (hexadécimale) ou une couleur nommée. [fichier de config : fullScreenMatteColor]
-z zoom
Définit le facteur de zoom initial. Un nombre spécifie un pourcentage de zoom, où 100 signifie 72 dpi. Vous pouvez également spécifier ´page', pour adapter la page à la taille de la fenêtre, ou ´width', pour adapter la largeur de la page à la largeur de la fenêtre. [fichier de config : initialZoom]
-rot angle
Fait pivoter les pages de 0 (par défaut), 90, 180 ou 270 degrés.
-aa oui | non
Active ou désactive l'anti-crénelage des polices. Par défaut, c'est "oui". [fichier de config : antialias]
-aaVector oui | non
Active ou désactive l'anti-crénelage vectoriel. Par défaut, c'est "oui". [fichier de config : vectorAntialias]
-enc nom-encodage
Définit l'encodage à utiliser pour la sortie texte. Le nom-encodage doit être défini avec la commande unicodeMap (voir xpdfrc(5)). Par défaut, c'est "Latin1" (qui est un encodage intégré). [fichier de config : textEncoding]
-pw mot-de-passe
Spécifie le mot de passe pour le fichier PDF. Il peut s'agir du mot de passe du propriétaire (qui contournera toutes les restrictions de sécurité) ou du mot de passe utilisateur.
-fullscreen
Ouvre xpdf en mode plein écran, utile pour les présentations.
-remote nom-distant
Démarre Xpdf en mode serveur distant. Voir la section MODE SERVEUR DISTANT.
-display affichage
Définit l'affichage X (uniquement disponible avec X11).
-cmd
Affiche les commandes au fur et à mesure de leur exécution (utile pour le débogage). [fichier de config : printCommands]
-tabstate fichier-statut-onglet
Définit le fichier utilisé par les commandes loadTabState et saveTabState. [fichier de config : tabStateFile]
-cfg fichier-config
Lit fichier-config à la place de ~/.xpdfrc ou du fichier de configuration système.
-v
Affiche les informations de copyright et de version.
-h
Affiche les informations d'utilisation. (-help et --help sont équivalents.)

Barre des menus

La barre des menus est située au-dessus de la barre d'outils. Les éléments du menu devraient être explicites.

Liste des onglets

La liste des onglets se trouve à gauche, juste en dessous de la barre d'outils. Elle répertorie tous les onglets ouverts.

Volet plan/calques/pièces jointes

Ce volet se trouve à gauche, sous la liste des onglets. Le menu contextuel vous permet de choisir entre plan, calques ou pièces jointes.

Le plan est une structure arborescente de signets qui permet de se déplacer dans le fichier PDF. Tous les fichiers PDF n'ont pas de plan.

Les calques (également appelés contenu optionnel) permettent d'afficher ou de masquer des parties du contenu du PDF. Tous les fichiers PDF n'ont pas de calques.

Les pièces jointes sont d'autres fichiers intégrés dans le fichier PDF. Il y a un bouton 'enregistrer' pour chaque fichier joint. Tous les fichiers PDF n'ont pas de pièces jointes.

Sélection de texte

En mode de sélection rectangulaire, faire glisser la souris avec le bouton gauche enfoncé mettra en surbrillance un rectangle arbitraire. Un clic avec Maj étendra la sélection.

En mode de sélection linéaire, faire glisser avec le bouton gauche mettra en surbrillance le texte dans l'ordre de lecture. Un double-clic ou un triple-clic sélectionnera un mot ou une ligne, respectivement. Un clic avec Maj étendra la sélection.

Le texte sélectionné peut être copié dans le presse-papiers (avec l'élément de menu édition/copier). Sur X11, le texte sélectionné sera disponible dans le tampon de sélection X.

Liens

Lorsque la souris survole un hyperlien, la cible du lien s'affiche dans une fenêtre contextuelle près du bas de la fenêtre.

Cliquer sur un hyperlien vous amènera à la destination du lien. Un lien vers un autre document PDF fera charger ce document par xpdf. Un lien de type 'lancer' vers un programme exécutable affichera une boîte de dialogue, et si vous cliquez sur 'ok', exécutera le programme. Les liens d'URL sont ouverts d'une manière dépendante du système. (Sur UNIX, Qt utilise la variable d'environnement $BROWSER.)

Associations de souris

Le bouton gauche de la souris est utilisé pour sélectionner du texte (voir ci-dessus).

Cliquer sur un lien avec le bouton du milieu ouvre le lien dans un nouvel onglet.

Faire glisser la souris avec le bouton du milieu enfoncé déplace la fenêtre.

Le bouton droit de la souris ouvre un menu contextuel (voir popupMenuCmd dans xpdfrc(5)).

Mode plein écran

Xpdf peut être placé en mode plein écran via l'option de ligne de commande -fullscreen, l'élément de menu 'plein écran', ou une association à la commande fullScreenMode ou toggleFullScreenMode.

L'entrée en mode plein écran bascule automatiquement en mode d'affichage d'une seule page et au facteur de zoom d'adaptation de la page.

Le mode plein écran peut être quitté via l'association de touches <esc> par défaut, ou via une association à la commande windowMode ou toggleFullScreenMode.

COMMANDES

Les associations de touches et de souris de Xpdf sont configurables par l'utilisateur, en utilisant les commandes bind et unbind dans le fichier de configuration (voir xpdfrc(5)). La commande bind permet d'associer une touche ou un bouton de souris à une séquence d'une ou plusieurs commandes.

Dans les commandes qui prennent des arguments (entre parenthèses), les caractères spéciaux (notamment '(', ')', ',' et '\x01') peuvent être échappés en les faisant précéder d'un caractère '\x01'. Ceci est surtout utile dans des choses comme les scripts qui doivent pouvoir ouvrir des fichiers PDF arbitraires, en utilisant la commande 'openFile'.

run(external-command-string)
Exécute une commande externe. Les échappements suivants sont autorisés dans la chaîne de commande : 
    %f => Nom du fichier PDF (ou une chaîne vide si aucun
          fichier n'est ouvert)
    %b => Nom de base du fichier PDF
    %f => nom de fichier, c'est-à-dire le nom du fichier sans
          l'extension (ou une chaîne vide si aucun
          fichier n'est ouvert)
    %u => URL du lien (ou une chaîne vide si pas sur un
          lien URL)
    %p => numéro de page actuel (ou une chaîne vide si
          aucun fichier n'est ouvert)
    %x => coordonnée x du coin supérieur gauche de la sélection
          (ou 0 s'il n'y a pas de sélection)
    %y => coordonnée y du coin supérieur gauche de la sélection
          (ou 0 s'il n'y a pas de sélection)
    %X => coordonnée x du coin inférieur droit de la sélection
          (ou 0 s'il n'y a pas de sélection)
    %Y => coordonnée y du coin inférieur droit de la sélection
          (ou 0 s'il n'y a pas de sélection)
    %i => page contenant le pointeur de la souris
    %j => coordonnée x du pointeur de la souris
    %k => coordonnée y du pointeur de la souris
    %% => %
La chaîne de commande externe contiendra souvent des espaces, donc la commande entière doit être mise entre guillemets dans le fichier xpdfrc : 
    bind x "run(ls -l)"
La chaîne de commande ne sera pas exécutée par un shell. Il est recommandé de garder la commande simple, afin qu'elle ne dépende pas de fonctionnalités spécifiques du shell. Pour des choses complexes, vous pouvez faire en sorte que la chaîne de commande exécute un script shell.

MODE SERVEUR À DISTANCE

Lancer xpdf avec l'option « -remote » le met en mode serveur à distance. Toutes les options de ligne de commande restantes sont des commandes (voir la section COMMANDES). Les invocations ultérieures de « xpdf -remote » avec le même nom de serveur à distance enverront des commandes à l'instance déjà en cours d'exécution de xpdf. Les commandes « checkOpenFile » sont utiles ici pour des actions comme changer de page. Par exemple :


# Lance xpdf, et ouvre quelquechose.pdf.
xpdf -remote foo 'openFile(quelquechose.pdf)'


# Passe à la page 7 dans le fichier quelquechose.pdf déjà ouvert. Si l'utilisateur
# a fermé xpdf entre-temps, cela le redémarrera et rouvrira
# le fichier.
xpdf -remote foo 'checkOpenFileAtPage(quelquechose.pdf, 7)'
