FBB::X2a(3bobcat) Conversions X vers ASCII FBB::X2a(3bobcat)

NOM

FBB::X2a - Objets effectuant des conversions x vers Ascii

SYNTAXE

#include <bobcat/x2a>
Option de liaison : -lbobcat

DESCRIPTION

Les objets FBB::X2a convertissent des valeurs de n'importe quel type (insérable) en texte. Le texte retourné est automatiquement rendu disponible sous forme de chaîne C++ standard.

X2a a été développé bien avant que la fonction std::to_string ne soit disponible. Dans de nombreux cas, cette dernière fonction peut souvent être utilisée à la place de X2a : elle est disponible pour les types standard. Cependant, si un autre type doit être utilisé, X2a peut toujours être utile.

ESPACE DE NOMS

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de noms FBB.

HERITE DE

std::ostringstream

CONSTRUCTEURS

o
X2a(T const &value) :
Dans ce constructeur, T peut être n'importe quel type qui peut être inséré dans un o[string]stream.
o
X2a(double value, size_t behind) :
La valeur double est tronquée à behind chiffres après la virgule. Si une valeur n'occupe pas behind chiffres après la virgule, des zéros sont ajoutés. Par exemple, une valeur de 7.1 sera affichée comme 7.10 si deux chiffres après la virgule sont demandés. Une valeur de 7 sera affichée comme 7.00.
o
X2a(double value, size_t width, size_t behind, std::ios::fmtflags flags = std::ios::right) :
La valeur est affichée sur width positions de caractères, étendant la largeur si la valeur l'exige. La valeur convertie est alignée à droite dans le champ de width caractères.

Le constructeur de copie et l'opérateur d'affectation de copie sont disponibles.

FONCTION MEMBRE STATIQUE

o
bool lastFail() :
Ce membre retourne true si la dernière conversion a échoué (c'est-à-dire que le membre fail() de l'objet a retourné true et retourne false sinon). Ce membre permet de vérifier le succès de l'extraction/conversion à l'aide d'objets A2x anonymes. Le membre retourne également true lorsqu'aucune conversion n'a encore été effectuée.
Notez que ce membre est un membre statique non sûr pour les threads : dans un programme multithread, des verrous peuvent être nécessaires pour garantir que le bon résultat de conversion est inspecté.

FONCTIONS MEMBRES

Tous les membres de std::ostringstream sont disponibles, car FBB::X2a hérite de cette classe. En particulier, ostringstream::str() peut être utilisé pour obtenir le contenu du tampon de texte d'un objet X2a.

OPÉRATEURS SURCHARGÉS

o
operator std::ostream &operator<<(std::ostream &ostr, X2a const &x2a) :
Cet opérateur de conversion insère la représentation textuelle de la valeur du paramètre x2a dans l'ostream fourni.
o
operator std::string const() const :
Cet opérateur de conversion retourne les informations stockées dans l'objet FBB::X2a.

EXEMPLE

    string is(X2a(5));      // initialise `is’ avec "5"
    string ds(X2a(5.25));   // initialise `ds’ avec "5.25"
    cout << X2a(7.0 / 3, 4) << endl;
                            // affiche une valeur utilisant 4 chiffres aprés la
                            // virgule.
    cout << X2a(7.0 / 3, 8, 4) << endl;
                            // affiche une valeur sur 8 positions, alignée à
                            // droite, 4 chiffres aprés la virgule.
    cout << X2a(7.0 / 3, 8, 4, std::ios::left) << endl;
                            // affiche une valeur sur 8 positions, alignée à
                            // gauche, 4 chiffres aprés la virgule.
