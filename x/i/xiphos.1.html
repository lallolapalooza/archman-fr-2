NOM

xiphos - Un outil de recherche biblique

SYNTAXE

xiphos [OPTION...]

DESCRIPTION

Xiphos est une application d'étude de la Bible pour les environnements GTK+, un ensemble de widgets disponible pour plusieurs saveurs Unix et Linux. Il est basé sur Sword par la CrossWire Bible Society, un framework offrant la possibilité d'étudier la Bible et des informations supplémentaires comme des commentaires, des dictionnaires et d'autres textes à l'aide de votre ordinateur. Affichez plusieurs traductions dans la fenêtre interlinéaire. Recherchez des passages dans n'importe quelle traduction par mot, phrase ou expression régulière.

Le programme peut être lancé depuis la ligne de commande en tant que xiphos ou à partir de l'un des menus fournis par la plateforme sous-jacente.

Lorsqu'il est lancé sur la ligne de commande, xiphos peut être suivi des options listées ci-dessous.

OPTIONS

Options d'aide :

-h, --help
Afficher les options d'aide
--help-all
Afficher toutes les options d'aide
--help-gtk
Afficher les options GTK+

Options de l'application :

--display=AFFICHAGE
Affichage X à utiliser
