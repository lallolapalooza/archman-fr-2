NOM

xine-config - script pour obtenir des informations sur la version installée de libxine

SYNTAXE

xine-config [--prefix[=DIR]] [--exec-prefix[=DIR]] [--version] [--libs] [--cflags] [--objcflags] [--plugindir] [--datadir] [--scriptdir] [--localedir]

DESCRIPTION

xine-config est DÉPRÉCIÉ. Utilisez pkg-config à la place.

xine-config est un outil qui est utilisé pour déterminer les indicateurs du compilateur et de l'éditeur de liens qui devraient être utilisés pour compiler et lier des programmes qui utilisent libxine. Il peut également être utilisé pour déterminer les répertoires où libxine attend les plugins.

OPTIONS

xine-config accepte les options suivantes, les passant (éventuellement modifiées) à pkg-config libxine :

--version
--modversion
Affiche la version actuellement installée de libxine sur la sortie standard.
--libs
--cflags
--objcflags
Passé sans modification.
Affiche les indicateurs du compilateur (pour C et Objective C, respectivement) qui sont nécessaires pour compiler un programme utilisant libxine.
--bindir
--plugindir
--datadir
--scriptdir
--localedir
--variable=...
Affiche le répertoire où, respectivement, les binaires, plugins, fichiers de données, scripts et données locales de libxine sont stockés/attendus.
--prefix=PREFIX
--define-variable=prefix=PREFIX
Si spécifié, utilise PREFIX à la place du préfixe d'installation avec lequel xine-lib a été construit. Cette option est également utilisée pour le préfixe d'exécution si --exec-prefix n'a pas été spécifié.
--exec-prefix=PREFIX
--define-variable=exec_prefix=PREFIX
Si spécifié, utilise PREFIX à la place du préfixe d'exécution d'installation avec lequel xine-lib a été construit.
