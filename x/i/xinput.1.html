xinput(1) Manuel des commandes générales xinput(1)

NOM

xinput - utilitaire pour configurer et tester les périphériques d'entrée X

SYNTAXE

xinput [COMMANDE] [OPTIONS] [PÉRIPHÉRIQUE]

DESCRIPTION

xinput est un utilitaire permettant de lister les périphériques d'entrée disponibles, d'interroger des informations sur un périphérique et de modifier les paramètres des périphériques d'entrée.

COMMANDES

--version
Teste si l'extension X Input est disponible et retourne le numéro de version du programme et la version prise en charge par le serveur. Cette option ne nécessite pas de nom de périphérique.
list [--short || --long || --name-only || --id-only] [périphérique]
Si aucun argument n'est fourni, liste tous les périphériques d'entrée. Si un argument est fourni, affiche toutes les fonctionnalités de périphérique. Si --long est spécifié, la sortie inclut des informations détaillées sur les capacités de chaque périphérique. Sinon, ou si --short est spécifié, seuls les noms des périphériques et quelques informations minimales sont listés. Si --name-only est spécifié, la sortie est limitée aux noms des périphériques. Un nom de périphérique est listé par ligne. Notez que l'ordre de liste des périphériques est indéfini. Si --id-only est spécifié, la sortie est limitée aux identifiants des périphériques. Un identifiant de périphérique est listé par ligne. Notez que l'ordre de liste des périphériques est indéfini.
get-feedbacks périphérique
Affiche les retours (feedbacks) de périphérique.
set-pointer périphérique
Commute périphérique en pointeur principal (core pointer). Cette option ne fait rien sur les serveurs X 1.5 et ultérieurs.
set-mode périphérique ABSOLUTE|RELATIVE
Change le mode de périphérique.
set-ptr-feedback périphérique seuil num den
Change les paramètres d'accélération du pointeur (ou de retour) de périphérique. La page de manuel de xset(1) contient plus de détails. Pour les serveurs X.Org 1.7 et supérieurs, il existe des propriétés de périphérique supplémentaires relatives à l'accélération du pointeur. Celles-ci ne remplacent pas, mais complètent le réglage du retour du pointeur.
set-integer-feedback périphérique index valeur
Modifie la valeur d'un retour entier de périphérique.
set-button-map périphérique bouton_1 [bouton_2 [...]]
Change le mappage des boutons de périphérique. Les boutons sont spécifiés dans l'ordre physique (en commençant par le bouton 1) et sont mappés au bouton logique fourni. 0 désactive un bouton. Le mappage par défaut des boutons pour un périphérique est 1 2 3 4 5 6 etc.
query-state périphérique
Interroge l'état du périphérique.
list-props périphérique [périphérique [...]]
Liste les propriétés qui peuvent être définies pour le(s) périphérique(s) donné(s).
set-int-prop périphérique propriété format valeur
Définit une propriété entière pour le périphérique. Les valeurs appropriées pour format sont 8, 16 ou 32, en fonction de la propriété. Obsolète, utilisez set-prop à la place.
set-float-prop périphérique propriété valeur
Définit une propriété flottante pour le périphérique. Obsolète, utilisez set-prop à la place.
set-prop [--type=atome|float|int] [--format=8|16|32] périphérique propriété valeur [...]
Définit la propriété avec la ou les valeurs données. Si non spécifiés, le format et le type de la propriété sont laissés tels quels. Les arguments sont interprétés selon le type de la propriété. Voir la section MODIFICATION DES PROPRIÉTÉS.
watch-props périphérique
Imprime sur la sortie standard lorsque des changements de propriétés surviennent.
delete-prop périphérique propriété
Supprime la propriété du périphérique.
test [-proximity] périphérique
Enregistre tous les événements étendus du périphérique et entre dans une boucle infinie affichant les événements reçus. Si -proximity est spécifié, ProximityIn et ProximityOut sont enregistrés.
test-xi2 [--root] [périphérique]
S'enregistre pour un certain nombre d'événements XI2 et les affiche. Si un périphérique est spécifié, seuls les événements de ce périphérique sont affichés. Si --root est spécifié, les événements sont sélectionnés uniquement sur la fenêtre racine. Sinon, une nouvelle fenêtre client est créée (similaire à xev).
create-master préfixe [sendCore] [enable]
Crée une nouvelle paire de périphériques maîtres sur un serveur activé XI2 avec le préfixe donné. Le serveur créera un pointeur maître nommé « préfixe pointeur » et un clavier maître nommé « préfixe clavier ». Si sendCore est 1, cette paire de périphériques maîtres est configurée pour envoyer des événements principaux (par défaut). Si enable est 1, cette paire de périphériques maîtres sera activée immédiatement (par défaut).
remove-master maître [Floating|AttachToMaster] [returnPointer] [returnKeyboard]
Supprime maître et son périphérique maître associé. Les périphériques esclaves attachés sont mis en mode flottant si Floating est spécifié ou si l'argument est omis. Si le deuxième argument est AttachToMaster, returnPointer spécifie le pointeur maître auquel attacher tous les pointeurs esclaves et returnKeyboard spécifie le clavier maître auquel attacher tous les claviers esclaves.
reattach esclave maître
Réattache esclave à maître.
float esclave
Retire esclave de son périphérique maître actuel.
set-cp fenêtre maître
Définit le ClientPointer pour le client propriétaire de fenêtre à maître. maître doit spécifier un pointeur maître.
map-to-output périphérique crtc
Restreint les mouvements du périphérique absolu au crtc RandR. Le nom de sortie doit correspondre à une sortie actuellement connectée (voir xrandr(1)). Si le pilote binaire NVIDIA est détecté ou si RandR 1.2 ou ultérieur n'est pas disponible, une sortie Xinerama peut être spécifiée comme « HEAD-N », où N est le numéro de l'écran Xinerama. Cette option n'a aucun effet sur les périphériques relatifs. Si crtc est défini sur « all », le comportement par défaut est appliqué.
enable périphérique
Active le périphérique. Cet appel est équivalent à xinput --set-prop périphérique « Périphérique activé » 1
disable périphérique
Désactive le périphérique. Cet appel est équivalent à xinput --set-prop périphérique « Périphérique activé » 0

périphérique peut être le nom du périphérique sous forme de chaîne de caractères ou l'ID X du périphérique.

esclave peut être le nom du périphérique sous forme de chaîne de caractères ou l'ID X d'un périphérique esclave.

maître peut être le nom du périphérique sous forme de chaîne de caractères ou l'ID X d'un périphérique maître.

propriété peut être la propriété sous forme de chaîne de caractères ou la valeur Atom.

MODIFICATION DES PROPRIÉTÉS

Lorsque xinput doit modifier la valeur d'une propriété de pilote existante, il suffit de fournir le nom du périphérique et le nom de la propriété sous forme de chaîne, suivis de la ou des nouvelles valeurs de la propriété. Par exemple :

xinput set-prop « mon périphérique » « ma propriété » 1 2 3

xinput(1) - manuel d'une page

NOM

xinput - utilitaire de configuration et de test pour les périphériques d'entrée X.

SYNOPSIS

xinput [-a|--list] [-q|--query] [--long-list] [--short-list] [-t|--test] [-w|--watch] [-v|--verbose] [-f|--flat] [-h|--help] [-v|--version] [appareil]

xinput [-set-prop appareil propriété [valeur...]]

xinput [-set-key appareil code_touche valeur]

xinput [-set-scroll-method appareil méthode [valeur...]]

xinput [--set-int-prop appareil propriété valeur]

x -set-pointer-accel valeur_accel_x valeur_accel_y

x -set-button-map mappage_boutons...

x -set-pmod modificateur valeur_modificateur

DESCRIPTION

xinput est un utilitaire pour configurer et tester les périphériques d'entrée X. Il permet de voir les périphériques connectés, de modifier leurs propriétés et de modifier certains paramètres globaux.

COMMANDES

Les commandes suivantes sont disponibles :

-a, --list
Liste tous les périphériques d'entrée connectés.
-q, --query
Affiche des informations détaillées sur les propriétés d'un périphérique spécifié. Par défaut, liste tous les périphériques.
--long-list
Affiche des informations détaillées sur tous les périphériques.
--short-list
Affiche une liste courte de tous les périphériques.
-t, --test
Teste le périphérique spécifié en affichant les événements générés.
-w, --watch
Observe les événements d'entrée pour un périphérique spécifié.
-v, --verbose
Mode verbeux pour afficher plus d'informations.
-f, --flat
Affiche la sortie sous forme plate.
-h, --help
Affiche un message d'aide.
-v, --version
Affiche les informations de version.
--set-prop appareil propriété [valeur...]
Définit la valeur d'une propriété pour un périphérique spécifié.
--set-key appareil code_touche valeur
Définit la valeur d'une touche pour un périphérique spécifié.
--set-scroll-method appareil méthode [valeur...]
Définit la méthode de défilement pour un périphérique spécifié.
--set-int-prop appareil propriété valeur
Définit la valeur entière d'une propriété pour un périphérique spécifié.
-set-pointer-accel valeur_accel_x valeur_accel_y
Définit l'accélération du pointeur.
-set-button-map mappage_boutons...
Définit le mappage des boutons de la souris.
-set-pmod modificateur valeur_modificateur
Définit la valeur d'un modificateur.

MODIFICATION DES PROPRIÉTÉS

L'utilitaire xinput permet de modifier diverses propriétés des périphériques d'entrée. Ces propriétés peuvent inclure la sensibilité, le mappage des boutons, les touches de raccourci, etc. L'option --set-prop est la plus couramment utilisée pour cela.

XWAYLAND

Xwayland est une couche de traduction qui permet aux applications X11 de fonctionner sur un serveur utilisant un compositeur Wayland en tant que backend. Xwayland agit comme une couche de traduction entre le protocole X et le protocole Wayland, mais n'a pas d'accès direct au matériel. Les périphériques d'entrée X créés par Xwayland (« xwayland-pointer », « xwayland-keyboard », etc.) sont mappés aux périphériques du protocole Wayland, et non aux périphériques physiques.

Ces périphériques d'entrée X ne sont visibles que par les autres clients X connectés au même processus Xwayland. La modification des propriétés de ces périphériques n'affecte que le comportement de ces clients. Par exemple, désactiver un périphérique Xwayland avec xinput ne désactive pas le périphérique dans les applications natives Wayland. D'autres modifications peuvent ne pas avoir d'effet du tout.

Dans la plupart des cas, l'utilisation de xinput avec un périphérique Xwayland indique un bug dans un script shell et xinput affichera un avertissement. Utilisez plutôt les méthodes de configuration des périphériques natives du compositeur Wayland.
