NOM

xiccd - démon de gestion des couleurs X

SYNTAXE

xiccd [OPTION...]

DESCRIPTION

xiccd est un pont simple entre colord et X. Il effectue les tâches suivantes :


* Énumération des affichages et enregistrement dans colord ;
* Création de profils ICC par défaut basés sur les données EDID ;
* Application des profils ICC fournis par colord ;
* Maintien du répertoire de stockage ICC privé de l'utilisateur.

Il ne dépend d'aucun environnement de bureau ni d'aucune boîte à outils spécifique et ne doit pas être utilisé dans des environnements de bureau qui gèrent la couleur nativement, comme le font GNOME et KDE.

xiccd est généralement appelé automatiquement par votre environnement de bureau via /etc/xdg/autostart et il ne devrait pas être nécessaire d'invoquer ce binaire manuellement.

Options d'aide :

-h, --help
Afficher les options d'aide

Options d'application :

-V, --version
Afficher la version
-d DISPLAY, --display DISPLAY
Serveur X auquel se connecter
-e, --edid
Générer des profils à partir de l'EDID du moniteur
