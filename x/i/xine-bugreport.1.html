NOM

xine-check - un vérificateur pour le lecteur vidéo xine

SYNTAXE

xine-check [-q] [-v] [-B] [-b]
xine-bugreport [-q] [-v] [-B]

DESCRIPTION

Cette page de manuel explique le programme xine-checker. xine-check est un programme qui teste l'installation du lecteur vidéo xine pour détecter les problèmes courants.

Si vous rencontrez un problème avec ou lors de l'exécution de xine, l'exécution de xine-check peut fournir des indices utiles pour le suivi des problèmes.

xine-check teste les paramètres du système d'exploitation, l'installation des plugins, les paramètres du lecteur CD/DVD et les paramètres de support vidéo.

S'il est exécuté en tant que xine-bugreport, il produira une description succincte du système et vous guidera dans le processus de signalement d'un bogue. C'est la manière préférée de signaler les bogues de xine, car elle est plus facile pour vous et fournit aux développeurs un rapport de bogue plus complet.

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous. Pour une description complète, voir README et FAQ dans /usr/share/doc/xine-ui ou sur la page d'accueil de xine.

-h, --help
Affiche un résumé des options et le numéro de version.

Les options restantes, étiquetées XINE-CHECK options: lorsqu'elles sont listées avec « xine-check --help », sont expliquées ici.

-q, --quiet
Ne fournit qu'un seul message sur une ligne, même si des problèmes sont trouvés. Normalement, xine-check fournit des indices pour chaque problème trouvé afin d'aider à le résoudre.
-v, --verbose
Active une sortie étendue décrivant chaque vérification en détail, ce qui produit une sorte de liste de questions fréquemment posées (FAQ).
-B, --batch
Désactive la pause après les messages longs. Normalement, xine-check attend une confirmation après qu'un problème ait été trouvé ou qu'un long message ait été affiché.
-b, --bug
Produire un rapport de bogue. C'est la même chose que d'appeler xine-bugreport directement.

BOGUES

aucun, bien sûr ;-) Eh bien, il y en a sûrement quelques-uns. Vous pouvez probablement demander le support (et signaler les bogues) sur notre liste de diffusion à l'adresse <xine-user@lists.sf.net>.
