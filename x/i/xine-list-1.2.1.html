NOM

xine-list-1.2 - obtenir des informations sur les types de fichiers pris en charge à partir de xine-lib

SYNTAXE

xine-list-1.2 [options...]

DESCRIPTION

xine-list-1.2 est un outil utilisé pour lister les informations sur les types MIME et les extensions de nom de fichier que la bibliothèque installée xine-lib connaît et prend en charge. Il est utile pour renseigner les informations MIME dans les fichiers de bureau des interfaces graphiques.

OPTIONS

xine-list-1.2 accepte les options suivantes :

-m
--mime-types Liste les types MIME connus par xine-lib. (C'est l'action par défaut.)
-e
--extensions Liste les types de fichiers (extensions de nom de fichier) connus par xine-lib.
-a
--all Liste les types MIME connus par xine-lib, ainsi que leurs extensions de nom de fichier et descriptions.
-p
--pretty-print Ajoute des sauts de ligne ; imprime chaque élément sur sa propre ligne.
