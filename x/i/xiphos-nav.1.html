NOM

xiphos-nav - Naviguer dans Xiphos vers une référence de verset

SYNOPSIS

xiphos-nav URL

DESCRIPTION

xiphos-nav est un utilitaire en ligne de commande qui induit Xiphos à réagir à une requête d'URL via dbus. Invoquez-le par exemple avec 'xiphos-nav sword://ESV/Gen.1.1'. Son utilisation normale est qu'il sert de gestionnaire pour les URL sword:// de votre environnement de bureau. Si la tentative d'accès à dbus échoue, il conclut que Xiphos n'est pas en cours d'exécution et démarre une nouvelle instance de Xiphos avec cette URL. Avec cela, vous pouvez cliquer sur des URL de ce type dans des pages Web, etc., et Xiphos sera navigué pour vous. L'interface dbus prend également en charge une interface de recherche, utilisée par bibledit.
