XWUD(1) Manuel des commandes générales XWUD(1)

NOM

xwud - afficheur d'images pour X

SYNTAXE

xwud [-in fichier] [-noclick] [-geometry geom] [-display affichage] [-new] [-std <typedemappe>] [-raw] [-vis <typedevisualouid>] [-scale] [-help] [-rv] [-plane nombre] [-fg couleur] [-bg couleur] [-dumpheader] [-version]

DESCRIPTION

Xwud est un utilitaire de décompression d'images pour le système de fenêtrage X. Xwud permet aux utilisateurs X d'afficher dans une fenêtre une image sauvegardée dans un fichier de vidage formaté de manière spéciale, tel que ceux produits par xwd(1).

OPTIONS

-bg couleur
Si une image bitmap (ou un seul plan d'une image) est affichée, cette option peut être utilisée pour spécifier la couleur à afficher pour les bits "0" de l'image.
-display affichage
Cette option vous permet de spécifier le serveur auquel se connecter ; voir X(7).
-dumpheader
Cette option affiche uniquement les informations de l'en-tête XWD. Rien n'est affiché.
-fg couleur
Si une image bitmap (ou un seul plan d'une image) est affichée, cette option peut être utilisée pour spécifier la couleur à afficher pour les bits "1" de l'image.
-geometry geom
Cette option vous permet de spécifier la taille et la position de la fenêtre. Généralement, vous ne voudrez spécifier que la position, et laisser la taille prendre par défaut la taille réelle de l'image.
-help
Affiche une courte description des options autorisées.
-in fichier
Cette option permet à l'utilisateur de spécifier explicitement le fichier d'entrée sur la ligne de commande. Si aucun fichier d'entrée n'est fourni, l'entrée standard est supposée.
-new
Cette option force la création d'une nouvelle carte de couleurs pour l'affichage de l'image. Si les caractéristiques de l'image correspondent à celles de l'affichage, cela peut afficher l'image plus rapidement, mais au prix de l'utilisation d'une nouvelle carte de couleurs (ce qui, sur la plupart des affichages, fera que les autres fenêtres prendront des couleurs fantaisistes).
-noclick
Cliquer sur n'importe quel bouton de la fenêtre terminera l'application, à moins que cette option ne soit spécifiée. La terminaison peut toujours être obtenue en tapant 'q', 'Q', ou ctrl-c.
-plane nombre
Vous pouvez sélectionner un seul plan de bits de l'image à afficher avec cette option. Les plans sont numérotés, zéro étant le bit de poids faible.
-raw
Cette option force l'affichage de l'image avec les valeurs de couleur qui existent actuellement sur l'écran. Cette option est surtout utile lors de la décompression d'une image sur le même écran d'où l'image provenait à l'origine, tant que les fenêtres d'origine sont toujours à l'écran, et permet d'afficher l'image plus rapidement.
-rv
Si une image bitmap (ou un seul plan d'une image) est affichée, cette option force l'inversion des couleurs de premier plan et d'arrière-plan. Cela peut être nécessaire lors de l'affichage d'une image bitmap dont les valeurs de pixels "0" et "1" ont un sens de couleur inversé par rapport à ceux de votre affichage.
-scale
Permet de redimensionner la fenêtre et de mettre l'image à l'échelle de la taille de la fenêtre.
-std typedemappe
Cette option provoque l'affichage de l'image en utilisant la carte de couleurs standard spécifiée. Le nom de la propriété est obtenu en convertissant le type en majuscules, en ajoutant "RGB_" au début, et en ajoutant "_MAP" à la fin. Les types typiques sont "best", "default", et "gray". Voir xstdcmap(1) pour une façon de créer des cartes de couleurs standard.
-version
Cette option fait que xwd affiche ses informations de version et quitte.
-vis <typedevisualouid>
Cette option vous permet de spécifier un visual ou une classe de visual particulière. Par défaut, il choisit le meilleur. Une classe particulière peut être spécifiée : "StaticGray", "GrayScale", "StaticColor", "PseudoColor", "DirectColor", ou "TrueColor". Ou "Match" peut être spécifié, ce qui signifie utiliser la même classe que l'image source. Alternativement, un identifiant de visual exact (spécifique au serveur) peut être spécifié, soit sous forme de nombre hexadécimal (précédé de "0x"), soit sous forme de nombre décimal. Enfin, "default" peut être spécifié, ce qui signifie utiliser la même classe que la carte de couleurs de la fenêtre racine. La casse n'est pas significative dans aucune de ces chaînes.

ENVIRONNEMENT

DISPLAY
Pour obtenir l'affichage par défaut.

FICHIERS

XWDFile.h
Fichier de définition du format de fichier de vidage X Window.

BOGUES

xwud ne gère pas très bien les images grandes/profondes sur les serveurs qui ne disposent pas de l'extension BIG-REQUESTS.

VOIR AUSSI

xwd(1), xstdcmap(1), X(7)
