XWAX(1) Manuel des commandes générales XWAX(1)

NOM

xwax - Vinyle numérique sous Linux

SYNTAXE

xwax [options]

DESCRIPTION

xwax est un logiciel d'émulation de vinyle pour Linux. Il permet aux DJs et aux turntablists de lire des fichiers audio numériques (MP3, Ogg Vorbis, FLAC, AAC et plus), contrôlés par une paire de platines normales via des vinyles codés en temps.

OPTIONS

L'ordre des options est important. La plupart des options s'appliquent aux bibliothèques musicales ou aux platines suivantes, qui peuvent être spécifiées plusieurs fois. Voir les EXEMPLES ci-dessous.

-l chemin
Analyse la bibliothèque musicale ou la liste de lecture au chemin donné.
-t nom
Utilise le code temporel nommé pour les platines suivantes. Voir -h pour une liste des codes temporels valides. Vous aurez besoin du signal codé en temps correspondant sur vinyle pour contrôler la lecture.
-33
Définit la vitesse de lecture de référence pour les platines suivantes à 33 et un tiers tours par minute. C'est la valeur par défaut.
-45
Définit la vitesse de lecture de référence pour les platines suivantes à 45 tours par minute.
-c
Protège les platines suivantes contre certaines opérations pendant la lecture.
-u
Autorise toutes les opérations sur une platine pendant la lecture. C'est l'inverse de l'option -c, et c'est la valeur par défaut.
--phono
Ajuste les seuils de bruit des platines suivantes pour tolérer un signal au niveau cartouche connecté à une interface audio au niveau ligne. C'est un "préampli logiciel". Sauf si votre chemin audio a un faible bruit, cela donnera de moins bons résultats ou pourrait ne pas fonctionner du tout ; un vrai préamplificateur phono est toujours préférable.
--line
Définit les seuils de bruit des platines suivantes à des niveaux audio standards. Ceci annule l'effet de l'option --phono, et c'est la valeur par défaut.
-i chemin
Utilise l'exécutable d'importation donné pour les platines suivantes.
-s chemin
Utilise l'exécutable de scan donné pour scanner les bibliothèques musicales suivantes.
--dummy
Crée une platine non connectée à aucun périphérique audio, utilisée pour les tests.
-k
Verrouille en RAM toute mémoire requise pour une utilisation en temps réel. Cela inclut les pistes audio conservées en mémoire, qui peuvent être volumineuses. Utilisez ulimit -l pour augmenter la limite de mémoire du noyau afin de permettre cela.
-q n
Change la priorité temps réel du processus. Une priorité de 0 ne donne aucune priorité au processus, et est utilisée uniquement pour les tests.
-g [nxn][+n+n][/f]
Change la géométrie de l'affichage en taille, position et échelle (zoom) respectivement. La taille et la position sont passées à SDL, qui peut les utiliser pour définir le mode d'affichage ou la taille d'une fenêtre X. Voir les EXEMPLES.
--no-decor
Demande au gestionnaire de fenêtres de créer une fenêtre "sans cadre" qui n'a pas les contrôles habituels comme les barres de titre et les boutons. Ceci peut être utile en conjonction avec l'indicateur -g pour les installations dédiées de xwax.
-h
Affiche le message d'aide et les valeurs par défaut.

OPTIONS DE PÉRIPHÉRIQUE ALSA

Les options suivantes ne sont disponibles que lorsque xwax est compilé avec le support ALSA.

-a périphérique
Crée une platine qui utilise le périphérique ALSA donné (par ex. plughw:0).
--rate hz
Définit le taux d'échantillonnage pour les platines suivantes. La valeur par défaut est de préférer 48000 Hz, mais d'utiliser 44100 Hz si ce n'est pas disponible. Pour maintenir les meilleures performances, seuls les taux d'échantillonnage implémentés par le matériel sont disponibles.
--buffer échantillons
Définit la taille du tampon ALSA pour les platines suivantes. Une taille plus petite est préférable pour des latences plus faibles et une meilleure réactivité. Si elle est trop basse, des glitches audibles se produiront, avec des rapports d'underruns sur la console.

OPTIONS DE PÉRIPHÉRIQUE JACK

Les options suivantes ne sont disponibles que lorsque xwax est compilé avec le support JACK.

-j nom
Crée une platine qui se connecte à JACK et s'enregistre sous le nom donné.

xwax ne définit pas le taux d'échantillonnage pour les périphériques JACK ; il utilise le taux d'échantillonnage spécifié dans la configuration JACK globale.

OPTIONS DE PÉRIPHÉRIQUE OSS

Les options suivantes ne sont disponibles que lorsque xwax est compilé avec le support OSS.

-d chemin_nom
Crée une platine qui utilise le périphérique OSS donné (par ex. /dev/dsp).
--rate hz
Définit le taux d'échantillonnage pour les platines suivantes. La valeur par défaut pour les périphériques OSS est de 48000 Hz.
-b n
Définit le nombre de tampons OSS pour les platines suivantes.
-f n
Définit la taille du tampon OSS (2^n octets).

OPTIONS DE CONTRÔLEUR MATÉRIEL

Les options suivantes ne sont disponibles que lorsque xwax est compilé avec le support ALSA.

--dicer périphérique
Utilise un ou deux contrôleurs Dicer connectés en tant que périphérique ALSA donné (par ex. hw:Dicer). Voir la section COMMANDES NOVATION DICER pour plus d'informations.

L'ajout d'un contrôleur matériel entraîne le contrôle des platines suivantes, jusqu'à la limite du matériel.

COMMANDES CLAVIER

La lecture de chaque platine (direction, vitesse et position) est contrôlée via le signal de code temporel entrant des platines. Le clavier fournit des contrôles supplémentaires.

"C-" et "S-" signifient qu'une pression de touche est combinée avec la touche 'Control' ou 'Shift', respectivement.

Commandes de sélection de morceau :

flèche haut, flèche bas
Déplace le morceau sélectionné vers le haut/bas d'une unité.
page précédente, page suivante
Fait défiler la liste des morceaux vers le haut/bas d'une page.
flèche gauche, flèche droite
Passe à la caisse de morceaux précédente/suivante.
tabulation
Bascule entre la caisse actuelle et la caisse "Tous les morceaux".
C-tabulation
Bascule le mode de tri entre : artiste/nom du morceau, BPM et ordre de "playlist". L'ordre de la playlist est l'ordre dans lequel les morceaux ont été retournés par le scanner.
C-S-tabulation
Ré-analyse la caisse actuellement sélectionnée.

Pour filtrer la liste actuelle des morceaux, tapez une partie d'un nom de morceau. Séparez plusieurs recherches par un espace et utilisez la touche retour arrière pour supprimer.

Commandes spécifiques à la platine :

r>
Platine 0 Platine 1 Platine 2
F1 F5 F9 Charge le morceau actuellement sélectionné sur cette platine
F2 F6 F10 Réinitialise le début du morceau à la position actuelle
F3 F7 F11 Active/désactive le contrôle par code temporel
C-F3 C-F7 C-F11 Cycle entre les codes temporels disponibles

Les « timecodes disponibles » sont ceux qui ont fait l'objet d'un indicateur -t sur la ligne de commande.

Commandes de contrôle audio :

+, -
Zoom avant/arrière sur les mètres audio rapprochés de tous les decks.

COMMANDES NOVATION DICER

Le Novation Dicer offre un contrôle matériel des points de repère. Les commandes sont :

mode cue : bouton dice (1-5)
Sauter au point de repère spécifié, ou le définir s'il n'est pas défini.
mode loop-roll : bouton dice (1-5)
« Punch » sur le point de repère spécifié, ou le définir s'il n'est pas défini. Ramène la lecture à la normale lorsque le bouton est relâché.
bouton mode + bouton dice (1-5)
Effacer le point de repère spécifié.

Les boutons dice sont éclairés pour indiquer que le point de repère correspondant est défini.

EXEMPLES

Configuration à 2 decks utilisant un répertoire de musique et des périphériques OSS :

xwax -l ~/music -d /dev/dsp -d /dev/dsp1

Comme ci-dessus, mais en utilisant des périphériques ALSA :

xwax -l ~/music -a hw:0 -a hw:1

Configuration à 2 decks utilisant un timecode différent sur chaque deck :

xwax -l ~/music -t serato_2a -a hw:0 -t mixvibes_v2 -a hw:1

Comme ci-dessus, mais avec le deuxième deck à 45 tours/minute :

xwax -l ~/music -t serato_2a -a hw:0 -t mixvibes_v2 -45 -a hw:1

Utiliser par défaut le même timecode, mais permettre le changement en cours d'exécution :

xwax -l ~/music -t serato_2a -t mixvibes_v2 -a hw:0 -a hw:1

Configuration à 3 decks avec le troisième deck à une fréquence d'échantillonnage plus élevée :

xwax -l ~/music --rate 48000 -a hw:0 -a hw:1 --rate 96000 -a hw:2

Utilisation simultanée des trois types de périphériques, un deck sur chacun :

xwax -l ~/music -a hw:0 -d /dev/dsp1 -j jack0

Analyser plusieurs bibliothèques musicales :

xwax -l ~/music -l ~/sounds -l ~/mixes -a hw:0

Analyser une deuxième bibliothèque musicale à l'aide d'un script personnalisé :

xwax -l ~/music -i ./custom-scan -l ~/sounds -a hw:0

Contrôler deux decks avec le matériel Dicer :

xwax --dicer hw:Dicer -a hw:0 -a hw:1

Utiliser une haute résolution et agrandir l'interface utilisateur :

xwax -g 1920x1200/1.8 -a hw:0
