NOM

x0vncserver - serveur TigerVNC pour les affichages X

SYNTAXE

x0vncserver [options]
x0vncserver -version

DESCRIPTION

x0vncserver est un serveur TigerVNC qui rend tout affichage X accessible à distance via VNC, TigerVNC ou des visualiseurs compatibles. Contrairement à Xvnc(1), il ne crée pas d'affichage virtuel. Au lieu de cela, il partage simplement un serveur X existant (typiquement, celui connecté à l'écran physique).

XDamage sera utilisé si le serveur X existant le prend en charge. Sinon, x0vncserver utilisera un sondage de l'écran pour détecter les changements.

OPTIONS

x0vncserver interprète la ligne de commande comme une liste de paramètres avec des valeurs optionnelles. L'exécution de x0vncserver -h affichera une liste de tous les paramètres valides avec de courtes descriptions. Tous les paramètres sont optionnels, mais normalement vous devrez utiliser le paramètre PasswordFile (voir sa description ci-dessous).

Il existe plusieurs formes pour spécifier les paramètres dans la ligne de commande (nous utilisons ici `NomParametre' comme exemple de nom de paramètre) :

-NomParametre
Active le paramètre, active la fonctionnalité. Cette forme peut être utilisée avec des paramètres qui activent ou désactivent simplement une fonctionnalité.
-NomParametre=0
Désactive le paramètre, désactive la fonctionnalité.
-NomParametre=valeur
Assigne la valeur spécifiée au paramètre. Le tiret initial peut être omis, ou il peut être doublé si désiré (comme dans les options longues de style GNU).

Les noms de paramètres ne sont pas sensibles à la casse, leur ordre dans la ligne de commande peut être arbitraire.

PARAMETRES

-AcceptKeyEvents
Accepte les événements de pression et de relâchement de touche des clients. Par défaut, c'est activé.
-AcceptPointerEvents
Accepte les événements de mouvement et de bouton du pointeur des clients. Par défaut, c'est activé.
-AcceptSetDesktopSize
Accepte les requêtes pour redimensionner le bureau. Par défaut, c'est activé.
-AlwaysShared
Traite toujours les connexions entrantes comme partagées, indépendamment du réglage spécifié par le client. Par défaut, c'est désactivé.
-BlacklistThreshold nombre
Le nombre de tentatives de connexion non authentifiées autorisées depuis un hôte individuel avant que cet hôte ne soit mis sur liste noire. Par défaut, 5.
-BlacklistTimeout secondes
Le délai d'attente initial appliqué lorsqu'un hôte est mis sur liste noire pour la première fois. L'hôte ne peut pas retenter une connexion avant l'expiration du délai. Par défaut, 10.
-CompareFB mode
Effectue une comparaison de pixels sur le framebuffer pour réduire les mises à jour inutiles. Peut être 0 (désactivé), 1 (toujours) ou 2 (automatique). Par défaut, 2.
-desktop nom-bureau
Chaque bureau a un nom qui peut être affiché par le visualiseur. Il est par défaut "<utilisateur>@<nom-hôte>".
-DisconnectClients
Déconnecte les clients existants si une connexion entrante n'est pas partagée. Par défaut, c'est activé. Si DisconnectClients est faux, alors une nouvelle connexion non partagée sera refusée pendant qu'un client est actif. Lorsqu'elle est combinée avec NeverShared, cela signifie qu'un seul client est autorisé à la fois.
-display affichage
Le nom de l'affichage X. S'il n'est pas spécifié, il prend la valeur de la variable d'environnement DISPLAY.
-FrameRate fps
Le nombre maximum de mises à jour par seconde envoyées à chaque client. Si l'écran se met à jour plus rapidement, ces changements seront agrégés et envoyés dans une seule mise à jour au client. Notez que cela contrôle uniquement le taux maximum et qu'un client peut obtenir un taux inférieur lorsque les ressources sont limitées. Par défaut, 60.
-Geometry geometrie
Cette option spécifie la zone de l'écran qui sera montrée aux clients VNC. Le format est largeurxhauteur+offset-x+offset-y , où les signes '+' peuvent être remplacés par des signes '-' pour spécifier des décalages par rapport au bord droit et/ou inférieur de l'écran. Les décalages sont optionnels, +0+0 est supposé par défaut (coin supérieur gauche). Si l'argument est vide, l'écran entier est montré aux clients VNC (c'est le défaut).
-GnuTLSPriority priorite
Chaîne de priorité GnuTLS qui contrôle les algorithmes de négociation de la session TLS. Voir le manuel GnuTLS pour les valeurs possibles. Par défaut, NORMAL.
-HostsFile nom-fichier
Ce paramètre permet de spécifier un nom de fichier avec des règles de contrôle d'accès IP. Le fichier doit inclure une règle par ligne, et le format de la règle est l'un des suivants : +adresse/prefixe (accepter les connexions du groupe d'adresses spécifié), -adresse/prefixe (rejeter les connexions) ou ?adresse/prefixe (interroger l'utilisateur local). La première règle correspondant à l'adresse IP détermine l'action à effectuer. Les règles qui incluent uniquement un signe d'action (+, - ou ?) correspondent à n'importe quelle adresse IP. Le prefixe est optionnel et spécifié par un nombre de bits (par exemple, /24). Par défaut, les connexions sont acceptées depuis n'importe quelle adresse IP.
-IdleTimeout secondes
Le nombre de secondes après lesquelles une connexion VNC inactive sera abandonnée. Par défaut, 0, ce qui signifie que les connexions inactives ne seront jamais abandonnées.
-ImprovedHextile
Utilise un algorithme de compression amélioré pour l'encodage Hextile, qui atteint de meilleurs ratios de compression au prix d'une utilisation légèrement plus importante du temps CPU. Par défaut, c'est activé.
-interface adresse-IP
Écoute sur l'interface. Par défaut, x0vncserver écoute sur toutes les interfaces disponibles.
-localhost
N'autorise que les connexions provenant de la même machine. Utile si vous utilisez SSH et que vous voulez empêcher les connexions non-SSH depuis d'autres hôtes.
-Log nom-log:destination:niveau[, ...]
Configure les paramètres du journal de débogage. La destination peut actuellement être stderr, stdout ou syslog, et le niveau est compris entre 0 et 100, 100 signifiant une sortie la plus verbeuse. Le nom-log est généralement * ce qui signifie tout, mais vous pouvez cibler un fichier source spécifique si vous connaissez le nom de son "LogWriter". Par défaut, *:stderr:30.
-MaxConnectionTime secondes
Se termine lorsqu'un client est connecté depuis N secondes. Par défaut, 0.
-MaxDisconnectionTime secondes
Se termine lorsqu'aucun client n'est connecté depuis N secondes. Par défaut, 0.
-MaxIdleTime secondes
Se termine après N secondes d'inactivité de l'utilisateur. Par défaut, 0.
-MaxProcessorUsage pourcentage
Pourcentage maximum de temps CPU à consommer lors du sondage de l'écran. Par défaut, 35.
-NeverShared
Ne traite jamais les connexions entrantes comme partagées, indépendamment du réglage spécifié par le client. Par défaut, c'est désactivé.
-PasswordFile nom-fichier
Spécifie le fichier contenant le mot de passe à utiliser pour l'authentification du client. Ce mot de passe doit être préalablement créé avec l'utilitaire vncpasswd(1). Si ce paramètre n'est pas spécifié, l'authentification par mot de passe est désactivée et tout client peut se connecter.
-QueryConnect
Demande une confirmation de l'utilisateur local avant d'autoriser une connexion. Par défaut, c'est désactivé.
-QuerySetDesktopSize
Demande une confirmation de l'utilisateur local avant d'accepter un changement de taille du bureau. Par défaut, c'est activé.
-QueryTerminate
Demande une confirmation de l'utilisateur local avant de terminer le serveur. Par défaut, c'est activé.
-RateLimitInterval secondes
Intervalle de temps pour la limitation du taux de connexion. Par défaut, 10.
-RateLimitNumConnections nombre
Nombre maximum de connexions autorisées par intervalle de temps. Par défaut, 30.
-rfbport port
Le port TCP sur lequel écouter. Par défaut, 5900.
-select_timeout secondes
Délai d'attente du descripteur de fichier. Utile pour les systèmes qui ne gèrent pas le délai d'attente du sélecteur correctement. Par défaut, 10.
-Shared
Traite toujours les connexions entrantes comme partagées, quelle que soit la configuration du client. Par défaut, c'est désactivé.
-shutter_speed vitesse
Temps de pose de l'obturateur en microsecondes pour la détection des changements de framebuffer. Par défaut, 10000.
-StripHeuristic mode
Comment réduire le nombre de mises à jour lors de l'utilisation du codage Hextile. Peut être 0 (désactivé), 1 (seulement les lignes) ou 2 (lignes et colonnes). Par défaut, 1.
-TCPListenQueue taille
Taille de la file d'attente d'écoute TCP. Par défaut, 5.
-TLS
Active les connexions TLS uniquement. Par défaut, c'est désactivé.
-TLSAllowInsecure
Autorise les connexions TLS même si la configuration du serveur n'est pas valide (par exemple, certificats auto-signés). Par défaut, c'est désactivé.
-TLSCertificateFile nom-fichier
Fichier contenant le certificat du serveur X509. Par défaut, /etc/ssl/certs/tigervnc.pem.
-TLSCertificateKeyFile nom-fichier
Fichier contenant la clé privée du certificat du serveur. Par défaut, /etc/ssl/private/tigervnc.pem.
-TLSVerifyClient
Exige que les clients fournissent un certificat X509 valide lors de la négociation TLS. Par défaut, c'est désactivé.
-TLSCACertificateFile nom-fichier
Fichier contenant les certificats des autorités de certification pour la vérification des certificats clients. Par défaut, /etc/ssl/certs/tigervnc.pem.
-Verbosity niveau
Niveau de verbosité pour la sortie de débogage. Par défaut, 0.
-version
Affiche des informations sur la version et quitte.
-wmShape
Utilise la forme de fenêtre pour le codage Hextile. Par défaut, c'est activé.
-x0-geometry geometrie
Similaire à l'option Geometry, mais spécifie la zone de l'écran qui sera capturée et affichée aux clients VNC. Par défaut, l'écran entier est utilisé.

EXEMPLES

Pour démarrer un serveur VNC qui partage votre affichage actuel et nécessite un mot de passe (créé via vncpasswd(1)) :

x0vncserver -PasswordFile ~/.vnc/passwd

Pour écouter uniquement sur l'interface localhost et utiliser le port 5901 :

x0vncserver -localhost -rfbport 5901

Pour spécifier une zone de l'écran à partager (par exemple, 800x600 pixels, en commençant à l'offset x=100, y=50) :

x0vncserver -Geometry 800x600+100+50

Pour activer le chiffrement TLS et exiger une authentification client :

x0vncserver -TLS -TLSVerifyClient

OPTIONS

-pam_service nom, -PAMService nom
Nom du service PAM à utiliser lors de l'authentification des utilisateurs via l'un des types de sécurité "Plain". La valeur par défaut est vnc.
-Password mot-de-passe
Encodage binaire obfusqué du mot de passe que les clients doivent fournir pour accéder au serveur. L'utilisation de ce paramètre est non sécurisée, utilisez plutôt le paramètre PasswordFile.
-PasswordFile fichier-mdp, -rfbauth fichier-mdp
Fichier de mots de passe pour l'authentification VNC. Il n'y a pas de valeur par défaut, vous devez spécifier le fichier de mots de passe explicitement. Le fichier de mots de passe doit être créé avec l'utilitaire vncpasswd(1). Le fichier est accédé à chaque connexion entrante, il peut donc être modifié à la volée.
-PlainUsers liste-utilisateurs
Une liste d'utilisateurs séparés par des virgules autorisés à s'authentifier via l'un des types de sécurité "Plain" (Plain, TLSPlain, etc.). Spécifiez \* pour autoriser n'importe quel utilisateur à s'authentifier en utilisant ce type de sécurité. Spécifiez %u pour autoriser l'utilisateur du processus serveur. Par défaut, tous les utilisateurs sont refusés.
-PollingCycle millisecondes
Millisecondes par cycle de scrutation. L'intervalle réel peut être ajusté dynamiquement pour satisfaire le réglage MaxProcessorUsage. La valeur par défaut est 30.
-Protocol3.3
Utiliser toujours la version de protocole 3.3 pour la compatibilité ascendante avec les clients mal comportés. Désactivé par défaut.
-QueryConnect
Demande à l'utilisateur du bureau d'accepter ou de refuser explicitement les connexions entrantes. Désactivé par défaut.
-QueryConnectTimeout secondes
Nombre de secondes pendant lesquelles la boîte de dialogue d'acceptation de connexion est affichée avant de refuser la connexion. La valeur par défaut est 10.
-RawKeyboard
Envoie les événements clavier directement sans les mapper à la disposition du clavier actuelle. Cela fait effectivement que le clavier se comporte selon la disposition configurée sur le serveur au lieu de la disposition configurée sur le client. Désactivé par défaut.
-AcceptCutText
Accepte les mises à jour du presse-papiers provenant des clients. Activé par défaut.
-SetPrimary
Définit la sélection PRIMARY ainsi que CLIPBOARD. Activé par défaut.
-MaxCutText octets
Taille maximale autorisée d'une mise à jour entrante du presse-papiers. La valeur par défaut est 262144.
-SendCutText
Envoie les changements du presse-papiers aux clients. Activé par défaut.
-SendPrimary
Envoie la sélection PRIMARY ainsi que CLIPBOARD aux clients. Activé par défaut.
-RemapKeys mappage
Configure un mappage de clavier. mappage est une chaîne de caractères séparée par des virgules de mappages de caractères, chacun sous la forme caractère->caractère, ou caractère<>caractère, où caractère est un keysym hexadécimal. Par exemple, pour échanger les symboles " et @, vous spécifieriez ce qui suit :
RemapKeys=0x22<>0x40
-RequireUsername
Exige un nom d'utilisateur pour les types de sécurité RSA-AES. Désactivé par défaut.
-rfbport port
Spécifie le port TCP sur lequel x0vncserver écoute les connexions des visualiseurs (le protocole utilisé dans VNC s'appelle RFB - "remote framebuffer"). Spécifiez -1 pour désactiver l'écoute sur un port TCP. Le port par défaut est 5900 lors du démarrage direct, et -1 lors de l'activation par un socket systemd.
-rfbunixmode mode
Spécifie le mode du socket de domaine Unix. La valeur par défaut est 0600.
-rfbunixpath chemin
Spécifie le chemin d'un socket de domaine Unix sur lequel x0vncserver écoute les connexions des visualiseurs. Par défaut, il n'écoute sur aucun socket de domaine Unix.
-RSAKey chemin
Chemin vers la clé RSA pour les types de sécurité RSA-AES (RA2, RA2ne, RA2_256 et RA2ne_256) au format PEM.
-SecurityTypes types-sec
Spécifie le schéma de sécurité à utiliser pour les connexions entrantes. Les valeurs valides sont une liste séparée par des virgules de None, VncAuth, Plain, TLSNone, TLSVnc, TLSPlain, X509None, X509Vnc, X509Plain, RA2, RA2ne, RA2_256 et RA2ne_256. La valeur par défaut est TLSVnc,VncAuth.
-UseBlacklist
Rejette temporairement les connexions d'un hôte s'il échoue à s'authentifier de manière répétée. Activé par défaut.
-UseIPv4
Utilise IPv4 pour les connexions entrantes et sortantes. Activé par défaut.
-UseIPv6
Utilise IPv6 pour les connexions entrantes et sortantes. Activé par défaut.
-UseSHM
Utilise l'extension MIT-SHM si disponible. L'utilisation de cette extension accélère la lecture de l'écran. Activé par défaut.
-X509Cert chemin
Chemin vers un certificat X509 au format PEM à utiliser pour tous les types de sécurité basés sur X509 (X509None, X509Vnc, etc.).
-X509Key chemin
La clé privée correspondante au certificat donné dans X509Cert. Doit également être au format PEM.
