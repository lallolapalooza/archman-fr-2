NOM

xfs_info - afficher les informations de géométrie du système de fichiers XFS

SYNOPSIS

xfs_info [ -t mtab ] [ point-de-montage | périphérique-bloc | image-de-fichier ]
xfs_info -V

DESCRIPTION

xfs_info affiche les informations de géométrie d'un système de fichiers XFS existant. L'argument point-de-montage est le chemin d'accès à un répertoire où le système de fichiers est monté. Le périphérique-bloc ou l'image-de-fichier contiennent un système de fichiers XFS brut. Le contenu existant du système de fichiers n'est pas modifié.

OPTIONS

-t
Spécifie un fichier de table de montage alternatif (par défaut /proc/mounts s'il existe, sinon /etc/mtab). Ceci est utilisé lors du traitement de systèmes de fichiers montés sans écrire dans le fichier /etc/mtab - se référer à mount(8) pour plus de détails. Cette option n'a aucun effet avec les paramètres périphérique-bloc ou image-de-fichier.
-V
Affiche le numéro de version et quitte. L'argument point-de-montage n'est pas requis avec -V.

EXEMPLES

Comprendre la sortie de xfs_info.

Supposons que l'on ait la sortie suivante de « xfs_info /dev/sda » :

meta-data=/dev/pmem0             isize=512    agcount=8, agsize=5974144 blks
         =                       sectsz=512   attr=2, projid32bit=1
         =                       crc=1        finobt=1, sparse=1, rmapbt=1
         =                       reflink=1
data     =                       bsize=4096   blocks=47793152, imaxpct=25
         =                       sunit=32     swidth=128 blks
naming   =version 2              bsize=4096   ascii-ci=0, ftype=1
log      =internal log           bsize=4096   blocks=23336, version=2
         =                       sectsz=512   sunit=0 blks, lazy-count=1
realtime =none                   extsz=4096   blocks=0, rtextents=0

Ici, la section data de la sortie indique « bsize=4096 », ce qui signifie que la taille des blocs de données pour ce système de fichiers est de 4096 octets. Cette section montre également « sunit=32 swidth=128 blks », ce qui signifie que l'unité de stripe est de 32*4096 octets = 128 kibibytes et que la largeur de stripe est de 128*4096 octets = 512 kibibytes. Une seule bande de ce système de fichiers est donc constituée de quatre unités de stripe (128 blocs / 32 blocs par unité).
