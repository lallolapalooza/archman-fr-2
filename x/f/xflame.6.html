NOM

xflame - dessine des flammes animées

SYNTAXE

xflame [--display hôte:écran.numéro] [--window] [--root] [--window-id numéro][--install] [--visual visuel] [--foreground couleur] [--hspread entier] [--vspread entier] [--residual entier] [--variance entier] [--vartrend entier] [--bloom --no-bloom] [--bitmap fichier-xbm] [--baseline entier] [--fps]

DESCRIPTION

Le programme xflame dessine des flammes animées en bas de l'écran. Les flammes s'embrasent occasionnellement. Si une image bitmap est spécifiée, cette image flottera au-dessus des flammes, en combustion.

OPTIONS

xflame accepte les options suivantes :

--window
Dessiner dans une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--install
Installer une colormap privée pour la fenêtre.
--visual visuel
Spécifier quel visuel utiliser. Les valeurs valides sont le nom d'une classe de visuel, ou l'ID (décimal ou hexadécimal) d'un visuel spécifique.
--foreground couleur ou --fg couleur
La couleur des flammes ; par défaut rouge. (La couleur d'arrière-plan est toujours noire.)
--bitmap nom-fichier
Spécifie le fichier bitmap à utiliser (un fichier XBM monochrome). Le nom "none" signifie de ne pas utiliser de bitmap du tout. Si non spécifié, une image intégrée sera utilisée.

Les autres options sont ésotériques. Si quelqu'un voulait bien les documenter, ce serait formidable.

--fps
Afficher le taux d'images par seconde actuel et la charge CPU.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui surcharge les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de la fenêtre à utiliser avec --root.
