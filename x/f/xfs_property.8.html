NOM

xfs_property - examiner et modifier les propriétés d'un système de fichiers XFS

SYNOPSIS

xfs_property cible get nom...
xfs_property cible list [ -v ]
xfs_property cible set nom=valeur...
xfs_property cible remove nom...
xfs_property -V

DESCRIPTION

xfs_property récupère, liste, définit ou supprime les propriétés d'un système de fichiers XFS. Les propriétés du système de fichiers sont des attributs contrôlés par root définis sur le répertoire racine du système de fichiers afin de permettre à l'administrateur système de coordonner avec les programmes de l'espace utilisateur.

cible est l'un des éléments suivants : le répertoire racine d'un système de fichiers monté ; un périphérique bloc contenant un système de fichiers XFS ; ou un fichier régulier contenant un système de fichiers XFS.

OPTIONS

-V
Affiche le numéro de version et quitte.

COMMANDES

get
nom... Affiche les valeurs des propriétés données du système de fichiers.
list
Liste les noms de toutes les propriétés du système de fichiers. Si l'indicateur -v est spécifié, affiche également les valeurs.
set
nom=valeur... Définit les propriétés données du système de fichiers aux valeurs spécifiées et affiche ce qui a été défini.
remove
nom... Annule la définition des propriétés données du système de fichiers.

PROPRIÉTÉS DU SYSTÈME DE FICHIERS

Les propriétés connues pour XFS sont :

autofsck Voir xfs_scrub(8) pour plus d'informations.
