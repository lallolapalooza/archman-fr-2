NOM

xfce4-popup-whiskermenu - affiche le menu Whisker

SYNTAXE

xfce4-popup-whiskermenu [OPTION]

DESCRIPTION

xfce4-popup-whiskermenu affiche le menu Whisker s'il y a au moins un applet de menu Whisker présent sur l'un de vos panneaux.

Le comportement par défaut est d'afficher le menu Whisker près du bouton de l'applet. Si vous avez plusieurs applets de menu Whisker, seul le premier que vous avez configuré apparaîtra, sauf si vous le remplacez avec instance.

OPTIONS

-h, --help
Affiche les options d'aide.
-p, --pointer
Affiche le menu à la position actuelle de la souris.
-c, --center
Affiche le menu au centre de l'écran.
-l, --list
Imprime les identifiants d'instance de menu disponibles.
-i, --instance=instance
Choisit quel menu afficher par identifiant d'instance.
-V, --version
Imprime les informations de version et quitte.
