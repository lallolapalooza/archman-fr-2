XFBURN(1) Commandes utilisateur XFBURN(1)

NOM

xfburn - Une application de gravure facile à utiliser

SYNTAXE

xfburn --burn-image [IMAGE]

xfburn [options] --data-composition | --audio-composition [[FICHIER]...]

xfburn --blank

xfburn --transcoder list | basic | gst

DESCRIPTION

xfburn est une application de gravure facile à utiliser basée sur les bibliothèques libburnia. Jusqu'à présent, elle permet de graver sur CD et DVD, ainsi que d'effacer les disques réinscriptibles. Des compositions de données et audio peuvent être créées à partir de zéro. Les images au format .iso peuvent être gravées ou créées.

APPEL

xfburn peut être appelé avec --burn-image pour afficher immédiatement la boîte de dialogue de gravure d'image. Optionnellement, le fichier image peut être présélectionné en l'ajoutant à la ligne de commande.

Lorsque les options --data-composition ou --audio-composition sont spécifiées, la fenêtre principale de xfburn s'ouvre avec le type de composition sélectionné au lieu de l'onglet de bienvenue. Les noms de fichiers du contenu de la composition peuvent suivre l'option de composition.

Options

-?, --help

Affiche une aide brève et quitte.

-V, --version

Affiche les informations de version et quitte.

-i, --burn-image [IMAGE]

Ouvre la boîte de dialogue de gravure d'image. Optionnellement, l'image est donnée comme IMAGE.

-b, --blank

Ouvre la boîte de dialogue d'effacement de disque.

-d, --data-composition [FICHIER(S)]

Ouvre xfburn avec une nouvelle composition de données. Optionnellement, les FICHIER(S) à ajouter à la composition suivent.

-a, --audio-composition [FICHIER(S) MUSIQUE]

Ouvre xfburn avec une nouvelle composition audio. Optionnellement, les FICHIER(S) MUSIQUE à ajouter à la composition suivent.

-t, --transcoder [TRANSCODEUR]

Sélectionne le transcoder à utiliser lors de la création de compositions audio. Spécifiez list pour voir toutes les options disponibles. Actuellement implémentés sont le transcoder gst et le transcoder basic. gst utilise gstreamer et permet l'utilisation de tout fichier média supporté par gstreamer. basic permet uniquement l'utilisation de fichiers audio déjà au format CD : fichiers WAV 48 kHz non compressés.

-m, --main

Lorsque l'option --burn-image ou --blank est sélectionnée, xfburn se ferme après la sortie de la boîte de dialogue, sauf si l'option --main est donnée. Dans ce cas, la fenêtre principale de xfburn est affichée après la fermeture de la boîte de dialogue.

--display=DISPLAY

Utilise le DISPLAY X spécifié pour l'interface utilisateur.
