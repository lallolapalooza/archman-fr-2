NOM

xfs_logprint - imprime le journal d'un système de fichiers XFS

SYNTAXE

xfs_logprint [ options ] périphérique

DESCRIPTION

xfs_logprint imprime le journal d'un système de fichiers XFS (voir xfs(5)). L'argument périphérique est le chemin d'accès à la partition ou au volume logique contenant le système de fichiers. Le périphérique peut être un fichier régulier si l'option -f est utilisée. Le contenu du système de fichiers reste inchangé. Il existe deux modes de fonctionnement principaux pour xfs_logprint.

Un mode est préférable pour le débogage du fonctionnement du système de fichiers. Il est appelé la vue transactionnelle et est activé via l'option -t. La vue transactionnelle n'imprime que la partie du journal qui concerne la récupération. Autrement dit, elle imprime les transactions complètes entre la queue et la tête. Cette vue essaie d'afficher chaque transaction sans tenir compte de la façon dont elles sont réparties entre les enregistrements du journal.

Le second mode commence à imprimer des informations depuis le début du journal. Certains blocs d'erreur peuvent être imprimés au début car le dernier enregistrement du journal se chevauche généralement avec l'enregistrement du journal le plus ancien. Un message est affiché lorsque la fin physique du journal est atteinte et lorsque la fin logique du journal est atteinte. Une vue des enregistrements du journal est affichée enregistrement par enregistrement. Les transactions qui s'étendent sur plusieurs enregistrements du journal peuvent ne pas être décodées entièrement.

OPTIONS

-b
Extrait et imprime les informations des tampons. Utilisé uniquement en mode transactionnel.
-c
Tente de continuer en cas de détection d'erreur.
-C nomfichier
Copie le journal du système de fichiers dans le fichier nomfichier. Le journal lui-même n'est pas imprimé.
-d
Extrait le journal du début à la fin, en imprimant l'emplacement de chaque enregistrement du journal sur le disque.
-D
Ne décode rien ; imprime seulement les données.
-e
Quitte lorsqu'une erreur est trouvée dans le journal. Normalement, xfs_logprint essaie de continuer et de se remettre de journaux corrompus. Cependant, parfois cela provoque des plantages. L'utilisation de cette option empêche les vidages de cœur.
-f
Spécifie que l'image du système de fichiers à traiter est stockée dans un fichier régulier à l'emplacement périphérique (voir l'option -d fichier de mkfs.xfs(8)). Cela peut se produire si une copie image d'un système de fichiers a été réalisée dans un fichier ordinaire avec xfs_copy(8).
-l p_journal
Périphérique de journal externe. Uniquement pour les systèmes de fichiers qui utilisent un journal externe.
-i
Extrait et imprime les informations des inodes. Utilisé uniquement en mode transactionnel.
-q
Extrait et imprime les informations des quotas. Utilisé uniquement en mode transactionnel.
-n
N'essaie pas d'interpréter les données du journal ; interprète seulement les informations d'en-tête du journal.
-o
Imprime également les données du tampon en hexadécimal. Normalement, les données des tampons sont seulement décodées, de sorte que des informations meilleures peuvent être imprimées.
-s bloc-début
Ignore toute notion d'emplacement de début d'impression.
-t
Imprime la vue transactionnelle.
-v
Imprime les données de "remplacement".
-V
Imprime le numéro de version et quitte.
