NOM

xfce4-power-manager-settings - Dialogue de configuration pour le gestionnaire d'alimentation Xfce 4

SYNOPIS

xfce4-power-manager-settings [options]

DESCRIPTION

xfce4-power-manager-settings est un utilitaire qui accompagne le gestionnaire d'alimentation Xfce4 pour accéder/modifier sa configuration. C'est un programme séparé qui utilise xfconf pour charger/sauvegarder les paramètres selon les choix de l'utilisateur. xfce4-power-manager-settings nécessite que le gestionnaire d'alimentation Xfce4 soit en cours d'exécution car il s'y connecte via DBus et obtient des informations sur les paramètres qui doivent ou ne doivent pas être affichés; par exemple, l'utilitaire xfce4-power-manager-settings n'affichera pas les paramètres de luminosité de l'écran LCD si aucun périphérique n'a été détecté par l'instance en cours d'exécution du gestionnaire d'alimentation Xfce4.
Vous pouvez exécuter xfce4-power-manager-settings depuis la ligne de commande sans spécifier d'arguments supplémentaires.

OPTIONS

--debug
Fait en sorte que le gestionnaire d'alimentation affiche des messages de débogage dans la console; utile si vous devez envoyer un rapport de bug.
--socket-id=SOCKET ID
Socket du gestionnaire de paramètres, utilisé lorsque xfce4-power-manager-settings est intégré dans le gestionnaire de paramètres.
--device-id=UpDevice chemin d'objet
Affiche un périphérique spécifique par un chemin d'objet UPower UpDevice spécifique.
