NOM

xfce4-dict - page de manuel pour xfce4-dict 0.8.7git-6f10536 (Xfce 4.18)

DESCRIPTION

Utilisation :

xfce4-dict [OPTION?] [TEXTE]

Options d'aide :

-h, --help
Afficher les options d'aide
--help-all
Afficher toutes les options d'aide
--help-gtk
Afficher les options GTK+

Options de l'application :

-d, --dict
Rechercher le texte donné en utilisant un serveur Dict (RFC 2229)
-w, --web
Rechercher le texte donné en utilisant un moteur de recherche basé sur le web
-s, --spell
Vérifier le texte donné avec un correcteur orthographique
-t, --text-field
Focaliser le champ de texte dans le panneau
-i, --ignore-plugin
Démarrer l'application autonome même si le plugin du panneau est chargé
-c, --clipboard
Récupère le contenu de la sélection PRIMARY et l'utilise comme texte de recherche
-v, --verbose
Être verbeux
-V, --version
Afficher les informations de version
--display=AFFICHAGE
Affichage X à utiliser

VOIR AUSSI

La documentation complète de xfce4-dict est maintenue sous forme de manuel Texinfo. Si les programmes info et xfce4-dict sont correctement installés sur votre site, la commande

info xfce4-dict

devrait vous donner accès au manuel complet.
