xfce4-session(1) Manuel des commandes générales xfce4-session(1)

NOM

xfce4-session - Lance l'environnement de bureau Xfce

SYNTAXE

xfce4-session

DESCRIPTION

Cette page de manuel décrit brièvement la commande xfce4-session.

Le programme xfce4-session lance l'environnement de bureau Xfce et est généralement exécuté par votre gestionnaire de connexion (par exemple, xdm, gdm, kdm, wdm ou à partir de vos scripts de démarrage X). Il chargera votre dernière session ou une session par défaut incluant les programmes Xfce standards si aucune session sauvegardée n'est disponible.

xfce4-session est un gestionnaire de session standard X11R6 qui peut gérer tout programme conforme à SM X11R6, y compris les programmes GNOME et KDE.

xfce4-session utilise le contenu du répertoire ~/.cache/sessions/ pour démarrer les sessions précédemment sauvegardées.

OPTIONS

xfce4-session accepte les options de ligne de commande suivantes :

--disable-tcp
Désactive la liaison aux ports TCP dans la couche ICE. Ce n'est pas possible sur toutes les plateformes. Si vous utilisez cette option sur une plateforme qui ne la prend pas en charge, xfce4-session affichera un message d'avertissement et ignorera le paramètre.
--help
Affiche un écran d'aide et quitte.
--version
Affiche les informations de version et quitte.

ENVIRONNEMENT

Le comportement de xfce4-session est affecté par les variables d'environnement suivantes.

XDG_CONFIG_HOME
Spécifie la racine de tous les fichiers de configuration spécifiques à l'utilisateur. Si cette variable d'environnement n'est pas définie, elle prend par défaut ~/.config/
XDG_CONFIG_DIRS
Ensemble de répertoires de base ordonnés par préférence, par rapport auxquels les fichiers de configuration doivent être recherchés en plus du répertoire de base $XDG_CONFIG_HOME. Les répertoires doivent être séparés par un deux-points.
XDG_CACHE_HOME
Spécifie la racine de toutes les données de cache spécifiques à l'utilisateur. Si cette variable d'environnement n'est pas définie, elle prend par défaut ~/.cache/
XFSM_VERBOSE
Lorsqu'elle est définie, cette variable d'environnement active l'enregistrement des messages de débogage dans ~/.xfce4-session.verbose-log Le fichier journal de la dernière session exécutée avec cette variable d'environnement définie est conservé dans ~/.xfce4-session.verbose-log.last Ces messages de débogage sont utiles pour le dépannage et le développement.

FICHIERS

xfce4-session lit sa configuration depuis Xfconf. xfce4-session stocke ses données de session dans $XDG_CACHE_HOME/sessions/.
