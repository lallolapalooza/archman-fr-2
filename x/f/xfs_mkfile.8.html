NOM

xfs_mkfile - créer un fichier XFS

SYNTAXE

xfs_mkfile [ -v ] [ -n ] [ -p ] taille[k|b|m|g] nom_fichier ...
xfs_mkfile -V

DESCRIPTION

xfs_mkfile crée un ou plusieurs fichiers. Le fichier est rempli de zéros par défaut. La taille par défaut est en octets, mais elle peut être indiquée comme kilooctets, blocs, mégaoctets ou gigaoctets avec les suffixes k, b, m ou g, respectivement.

OPTIONS

-v
Verbeux. Rapporte les noms et les tailles des fichiers créés.
-n
Aucun octet. Crée un fichier troué (holey file) - c'est-à-dire, n'écrit aucune donnée, effectue simplement un seek jusqu'à la fin du fichier et écrit un bloc.
-p
Pré-allouer. Le fichier est pré-alloué, puis écrasé avec des zéros, puis tronqué à la taille désirée.
-V
Affiche le numéro de version et quitte.
