NOM

xfce4-terminal - Émulateur de terminal pour X

SYNTAXE

xfce4-terminal [OPTION...]

DESCRIPTION

xfce4-terminal est ce qu'on appelle un émulateur de terminal X, souvent appelé terminal ou shell. Il fournit un équivalent à l'écran texte de style ancien sur votre bureau, mais qui peut facilement partager l'écran avec d'autres applications graphiques. Les utilisateurs de Windows sont peut-être déjà familiers avec l'utilitaire Invite de commandes MS-DOS, qui a la fonction analogue d'offrir une ligne de commande DOS sous Windows, bien qu'il faille noter que l'interface en ligne de commande UNIX offre beaucoup plus de puissance et de facilité d'utilisation que DOS.

xfce4-terminal émule l'application xterm développée par le Consortium X. À son tour, l'application xterm émule le terminal DEC VT102 et prend également en charge les séquences d'échappement DEC VT220. Une séquence d'échappement est une série de caractères qui commence par le caractère Esc. xfce4-terminal accepte toutes les séquences d'échappement utilisées par les terminaux VT102 et VT220 pour des fonctions telles que le positionnement du curseur et l'effacement de l'écran.

OPTIONS

Résumé des options

Voici un résumé de toutes les options, regroupées par type. Les explications se trouvent dans les sections suivantes.

Options générales

-h, --help ; -V, --version ; --disable-server ; --color-table ; --preferences ; --default-display=display ; --default-working-directory=directory

Séparateurs de fenêtre ou d'onglet

--tab ; --window

Options d'onglet

-x, --execute ; -e, --command=command ; -T, --title=title ; --dynamic-title-mode=mode ; --initial-title=title ; --working-directory=directory ; -H, --hold ; --active-tab ; --color-text=color ; --color-bg=color

Options de fenêtre

--display=display ; --drop-down ; --geometry=geometry ; --role=role ; --startup-id=string ; -I, --icon=icon ; --fullscreen ; --maximize ; --minimize ; --show-menubar, --hide-menubar ; --show-borders, --hide-borders ; --show-toolbar, --hide-toolbar ; --show-scrollbar, --hide-scrollbar ; --font=font ; --zoom=zoom ; --class=class

Options générales

-h, --help

Liste les différentes options en ligne de commande prises en charge par xfce4-terminal et quitte.

-V, --version

Affiche les informations de version et quitte.

--disable-server

N'enregistre pas le terminal auprès du bus de messages de session D-BUS. Exécute ce terminal dans son propre processus.

--color-table

Écrit les codes de couleur.

--preferences

Ouvre la fenêtre des préférences de xfce4-terminal.

--default-display=display

Affichage X par défaut à utiliser.

--default-working-directory=directory

Définit directory comme répertoire de travail par défaut pour le terminal.

Séparateurs de fenêtre ou d'onglet

--tab

Ouvre un nouvel onglet dans la dernière fenêtre spécifiée. Plus d'une de ces options peut être fournie, chacune ouvrant un onglet supplémentaire.

--window

Ouvre une nouvelle fenêtre contenant un onglet. Plus d'une de ces options peut être fournie.

S'il y a une fenêtre active, la dernière fenêtre spécifiée est cette fenêtre jusqu'à ce qu'une option --window soit rencontrée, auquel cas cette nouvelle fenêtre est la dernière fenêtre spécifiée.

S'il n'y a pas de fenêtre active, la dernière fenêtre spécifiée est la fenêtre créée par xfce4-terminal jusqu'à ce qu'une option --window soit rencontrée, auquel cas cette nouvelle fenêtre est la dernière fenêtre spécifiée.

Ces options peuvent être combinées avec --drop-down.

Options d'onglet

-x, --execute

Exécute le reste de la ligne de commande dans le terminal.

-e, --command=command

Exécute command dans le terminal.

-T, --title=title

Définit title comme titre de fenêtre pour le terminal (ignore le titre défini dynamiquement).

--dynamic-title-mode=mode

Définit mode comme mode de titre défini dynamiquement pour le terminal, l'une des valeurs suivantes : 'replace', 'before', 'after', 'none'.

--initial-title=title

Définit title comme titre de fenêtre initial pour le terminal (respecte le titre défini dynamiquement).

--working-directory=directory

Définit directory comme répertoire de travail pour le terminal.

-H, --hold

Permet de conserver le terminal après la fin de la commande enfant.

--active-tab

Rend le terminal actif : utile lorsqu'une fenêtre de terminal contient plusieurs onglets.

--color-text=color

Définit color comme couleur du texte pour le terminal selon la spécification suivante : https://docs.gtk.org/gdk3/method.RGBA.parse.html

--color-bg=color

Définit color comme couleur d'arrière-plan pour le terminal selon la spécification suivante : https://docs.gtk.org/gdk3/method.RGBA.parse.html

Options de fenêtre

--display=display

Affichage X à utiliser pour la dernière fenêtre spécifiée.

--drop-down

Démarrera la fenêtre en mode déroulant (également appelé terminal de type Quake). Cela ne s'appliquera qu'à la première fenêtre démarrée avec cette option. Il est conseillé de lier ceci à un raccourci dans les préférences du clavier.

--geometry=geometry

Définit la géométrie de la dernière fenêtre spécifiée sur geometry. Lisez X(7) pour plus d'informations sur la manière de spécifier les géométries de fenêtre.

--role=role

Définit le rôle de la fenêtre de la dernière fenêtre spécifiée sur role. S'applique à une seule fenêtre et peut être spécifié une fois pour chaque fenêtre que vous créez à partir de la ligne de commande. Le role est un identifiant unique pour la fenêtre à utiliser lors de la restauration d'une session.

--startup-id=string

Spécifie l'identifiant de notification de démarrage pour la dernière fenêtre spécifiée. Utilisé en interne pour transmettre l'identifiant de notification de démarrage lors de l'utilisation du service D-BUS.

-I, --icon=icon

Définit l'icône du terminal comme nom d'icône ou nom de fichier.

--fullscreen

Met la dernière fenêtre spécifiée en mode plein écran ; s'applique à une seule fenêtre ; peut être spécifié une fois pour chaque fenêtre que vous créez à partir de la ligne de commande.

--maximize

Met la dernière fenêtre spécifiée en mode maximisé ; s'applique à une seule fenêtre ; peut être spécifié une fois pour chaque fenêtre que vous créez à partir de la ligne de commande.

--minimize

Met la dernière fenêtre spécifiée en mode minimisé ; s'applique à une seule fenêtre ; peut être spécifié une fois pour chaque fenêtre que vous créez à partir de la ligne de commande.

--show-menubar

Active la barre de menu pour la dernière fenêtre spécifiée. Peut être spécifié une fois pour chaque fenêtre que vous créez à partir de la ligne de commande.

--hide-menubar

Désactive la barre de menu

NAME

xfce4-terminal

Terminal Emulator for the Xfce Desktop Environment

SYNOPSIS

xfce4-terminal [ OPTIONS ] [ --command COMMAND ] [ --working-directory DIRECTORY ]

DESCRIPTION

The xfce4-terminal program is a terminal emulator application for the Xfce desktop environment. It provides a convenient and user-friendly way to interact with the command-line interface. This manual page documents the various command-line options available for xfce4-terminal.

OPTIONS

--help

Show help message and exit.

--version

Show version information and exit.

--disable-server

Disable the option to connect to an existing server process. This will force xfce4-terminal to create a new server process.

--enable-server

Enable the option to connect to an existing server process. This is the default behavior.

--geometry=GEOMETRY

Set the initial window size and position. For example, --geometry=80x25+100+200 sets the window size to 80 columns and 25 rows, and its position to 100 pixels from the left and 200 pixels from the top.

--role=ROLE

Set the window manager role for the terminal window.

--startup-id=ID

Set the startup notification ID.

--maximize

Maximize the terminal window.

--fullscreen

Start the terminal window in fullscreen mode.

--tab

Open a new tab in the last-specified window. If no window is specified, a new window is created.

--window

Open a new terminal window.

--command=COMMAND

Execute the specified command in the terminal.

--working-directory=DIRECTORY

Set the working directory for the terminal.

--title=TITLE

Set the window title for the last-specified window. Can be specified once for each window you create from the command line.

--show-menubar

Turn on the menubar for the last-specified window. Can be specified once for each window you create from the command line.

--hide-menubar

Turn off the menubar for the last-specified window. Can be specified once for each window you create from the command line.

--show-borders

Turn on the window decorations for the last-specified window. Applies to only one window. Can be specified once for each window you create from the command line.

--hide-borders

Turn off the window decorations for the last-specified window. Applies to only one window. Can be specified once for each window you create from the command line.

--show-toolbar

Turn on the toolbar for the last-specified window. Applies to only one window. Can be specified once for each window you create from the command line.

--hide-toolbar

Turn off the toolbar for the last-specified window. Applies to only one window. Can be specified once for each window you create from the command line.

--show-scrollbar

Turn on the scrollbar for the last-specified window. Scrollbar position is taken from the settings; if position is None, the default position is Right side. Applies to only one window. Can be specified once for each window you create from the command line.

--hide-scrollbar

Turn off the scrollbar for the last-specified window. Applies to only one window. Can be specified once for each window you create from the command line.

--font=font

Set the terminal font.

--zoom=zoom

Set the zoom level: the font size will be multiplied by this level. The range is from -7 to 7, default is 0. Each step multiplies the size by 1.2, i.e. level 7 is 3.5831808 (1.2^7) times larger than the default size.

--class=class

Set the window manager class of all terminal windows. Controls window grouping in the panel. If a terminal instance is already open, requires --disable-server to be set.

EXAMPLES

xfce4-terminal --geometry 80x40 --command mutt --tab --command mc

Ouvre une nouvelle fenêtre de terminal avec une géométrie de 80 colonnes et 40 lignes, et deux onglets, où le premier onglet exécute mutt et le second onglet exécute mc.

ENVIRONMENT

xfce4-terminal uses the Basedir Specification as defined on Freedesktop.org[1] to locate its data and configuration files. This means that file locations will be specified as a path relative to the directories described in the specification.

${XDG_CONFIG_HOME}

The first base directory to look for configuration files. By default this is set to ~/.config/.

${XDG_CONFIG_DIRS}

A colon separated list of base directories that contain configuration data. By default the application will look in ${sysconfdir}/xdg/. The value of ${sysconfdir} depends on how the program was build and will often be /etc/ for binary packages.

${XDG_DATA_HOME}

The root for all user-specific data files. By default this is set to ~/.local/share/.

${XDG_DATA_DIRS}

A set of preference ordered base directories relative to which data files should be searched in addition to the ${XDG_DATA_HOME} base directory. The directories should be separated with a colon.

FILES

${XDG_CONFIG_HOME}/xfce4/terminal/accels.scm

This is the location of the keyboard shortcuts configuration file for xfce4-terminal. Editing this file allows one to modify or disable shortcuts for the supported actions.
