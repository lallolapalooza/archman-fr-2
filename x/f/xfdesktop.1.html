NOM

xfdesktop - le gestionnaire de bureau de l'environnement de bureau Xfce 4

SYNTAXE

xfdesktop
xfdesktop [options]

DESCRIPTION

xfdesktop gère le bureau lui-même dans l'environnement de bureau Xfce 4. Cela inclut le dessin de l'arrière-plan du bureau, la fourniture d'un menu d'applications au clic droit et d'un menu de liste de fenêtres au clic du milieu, ainsi que le dessin des icônes sur le bureau. Une seule instance de xfdesktop peut être en cours d'exécution à la fois, et devrait être démarrée en exécutant xfdesktop sans aucun argument.

OPTIONS

OPTIONS D'AIDE :

-h, --help
Afficher les options d'aide
--help-all
Afficher toutes les options d'aide
--help-gtk
Afficher les options GTK+
--help-sm-client
Afficher les options de gestion de session

OPTIONS DE L'APPLICATION :

-V, --version
Afficher les informations sur la version
-R, --reload
Force une instance déjà en cours d'exécution de xfdesktop à recharger tous ses paramètres et à redessiner l'arrière-plan du bureau.
-N, --next
Force une instance déjà en cours d'exécution de xfdesktop à passer au fond d'écran suivant sur l'espace de travail actuel.
-M, --menu
Force une instance déjà en cours d'exécution de xfdesktop à afficher le menu des applications à la position actuelle du curseur de la souris.
-W, --windowlist
Force une instance déjà en cours d'exécution de xfdesktop à afficher le menu de la liste des fenêtres à la position actuelle du curseur de la souris.
-A, --arrange
Organiser automatiquement toutes les icônes sur le bureau
-D, --disable-wm-check
Ne pas attendre un gestionnaire de fenêtres au démarrage
-e, --enable-debug
Activer les messages de débogage
-d, --disable-debug
Désactiver les messages de débogage
-Q, --quit
Force xfdesktop à quitter
--display=[DISPLAY]
Affichage X à utiliser

ENVIRONNEMENT

Le comportement de xfdesktop est affecté par les variables d'environnement suivantes.

XDG_CONFIG_HOME
Spécifie la racine de tous les fichiers de configuration spécifiques à l'utilisateur. Si cette variable d'environnement n'est pas présente, elle prend par défaut la valeur ~/.config
XDG_CONFIG_DIRS
Spécifie une liste séparée par des deux-points de répertoires système dans lesquels rechercher les données de configuration. Si cette variable d'environnement n'est pas présente, elle prend par défaut la valeur /etc/xdg

FICHIERS

xfdesktop recherche un fichier de description de menu dans $XDG_CONFIG_DIRS/menus/xfce-applications.menu. xfdesktop peut également utiliser un menu personnalisé par l'utilisateur dans $XDG_CONFIG_HOME/menus/.
