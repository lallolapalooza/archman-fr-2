NOM

xfs_growfs - agrandir un système de fichiers XFS

SYNTAXE

xfs_growfs [ -dilnrx ] [ -D taille ] [ -e taille_extents_rt ] [ -L taille ] [ -m pourcentage_max ] [ -t mtab ] [ -R taille ] [ point_de_montage | périphérique_bloc ]

xfs_growfs -V

DESCRIPTION

xfs_growfs agrandit un système de fichiers XFS existant (voir xfs(5)). L'argument point_de_montage est le chemin d'accès du répertoire où le système de fichiers est monté. L'argument périphérique_bloc est le nom du périphérique d'un système de fichiers XFS monté. Le système de fichiers doit être monté pour être agrandi (voir mount(8)). Le contenu existant du système de fichiers n'est pas modifié, et l'espace ajouté devient disponible pour le stockage de fichiers supplémentaires.

OPTIONS

-d | -D taille
Spécifie que la section de données du système de fichiers doit être redimensionnée. Si l'option -D taille est donnée, la section de données est changée à cette taille, sinon la section de données est agrandie à la taille la plus grande possible avec l'option -d. La taille est exprimée en blocs de système de fichiers. Un système de fichiers avec un seul AG ne peut plus être réduit, et un système de fichiers ne peut pas être réduit au point de n'avoir qu'un seul AG. [NOTE : Seule la réduction du dernier AG sans le supprimer est implémentée]
-e
Permet de spécifier une nouvelle taille d'extent pour la section temps réel. Dans mkfs.xfs(8), cela est spécifié avec -r extsize=nnnn.
-i
Le nouveau journal est un journal interne (à l'intérieur de la section de données). [NOTE : Cette option n'est pas implémentée]
-l | -L taille
Spécifie que la section journal du système de fichiers doit être agrandie, réduite ou déplacée. Si l'option -L taille est donnée, la section journal est changée à cette taille, si possible. La taille est exprimée en blocs de système de fichiers. La taille d'un journal interne doit être inférieure à la taille d'un groupe d'allocation (cette valeur est affichée lors de l'exécution de mkfs(8)). Si ni -i ni -x n'est donné avec -l, le journal continue d'être interne ou externe comme il l'était auparavant. [NOTE : Ces options ne sont pas implémentées]
-m
Spécifie une nouvelle valeur pour le pourcentage maximum d'espace dans le système de fichiers qui peut être alloué aux inodes. Dans mkfs.xfs(8), cela est spécifié avec -i maxpct=nn.
-n
Spécifie qu'aucun changement ne doit être apporté au système de fichiers. La géométrie du système de fichiers est affichée, et la vérification des arguments est effectuée, mais aucune croissance n'a lieu. Voir les exemples de sortie ci-dessous.
-r | -R taille
Spécifie que la section temps réel du système de fichiers doit être agrandie. Si l'option -R taille est donnée, la section temps réel est agrandie à cette taille, sinon la section temps réel est agrandie à la taille la plus grande possible avec l'option -r. La taille est exprimée en blocs de système de fichiers. Le système de fichiers n'avait pas besoin de contenir une section temps réel avant l'opération xfs_growfs.
-t
Spécifie un fichier de table de montage alternatif (par défaut, /proc/mounts s'il existe, sinon /etc/mtab). Ceci est utilisé lorsque l'on travaille avec des systèmes de fichiers montés sans écrire dans le fichier /etc/mtab - se référer à mount(8) pour plus de détails.
-V
Affiche le numéro de version et quitte. L'argument point_de_montage n'est pas requis avec -V.

xfs_growfs est le plus souvent utilisé en conjonction avec des volumes logiques (voir md(4) et lvm(8) sous Linux). Cependant, il peut également être utilisé sur une partition de disque ordinaire, par exemple si une partition a été agrandie tout en conservant le même bloc de départ.

UTILISATION PRATIQUE

Les systèmes de fichiers occupent normalement tout l'espace sur le périphérique où ils résident. Pour agrandir un système de fichiers, il est nécessaire de lui fournir de l'espace supplémentaire à occuper. Par conséquent, il doit y avoir au moins une nouvelle partition de disque de secours disponible. L'ajout d'espace se fait souvent par l'utilisation d'un gestionnaire de volume logique.
