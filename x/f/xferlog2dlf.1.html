NOM

xferlog2dlf - convertit les journaux FTP au format xferlog en format DLF

SYNTAXE

xferlog2dlf

DESCRIPTION

Ce script lit un fichier journal FTP au format xferlog. La plupart des serveurs FTP utilisent ce format, parmi lesquels ProFTPD, WU-FTPD.

EXEMPLES

Pour traiter un journal tel que produit au format xferlog :

$ xferlog2dlf < ftp.log

xferlog2dlf sera rarement utilisé seul, mais est plus susceptible d'être appelé par lr_log2report :

$ lr_log2report xferlog < /var/log/ftp.log

VOIR AUSSI

xferlog(5)

Une liste de serveurs FTP peut être trouvée à http://linuxmafia.com/pub/linux/security/ftp-daemons.
