Nom

xfce4-panel-profiles - Une application simple pour gérer les présentations du panneau Xfce

SYNTAXE

xfce4-panel-profiles [ COMMANDE ] nom_fichier

DESCRIPTION

xfce4-panel-profiles est une application simple pour gérer les présentations du panneau Xfce. Elle vous permet d’appliquer, sauvegarder, supprimer, exporter, importer une présentation de panneau sous forme de profil. Vous pouvez, par exemple, sauvegarder la présentation actuelle du panneau, ou importer un profil de panneau précédemment exporté.

xfce4-panel-profiles est une application graphique, mais elle peut également être utilisée en ligne de commande avec des fonctionnalités limitées.

COMMANDES

charger nom_fichier
Charge et applique un profil de panneau précédemment exporté sous forme de nom_fichier.
sauvegarder nom_fichier
Sauvegarde la présentation actuelle du panneau sous le nom de nom_fichier. Le nom du profil doit se terminer par tar.bz2 pour plus de clarté.

FICHIERS

~/.local/share/xfce4-panel-profiles
Répertoire de stockage des profils de panneaux personnalisés de l'utilisateur.
/usr/share/xfce4-panel-profiles/layouts
Répertoire de stockage des profils de panneaux fournis par le système.

EXEMPLES

xfce4-panel-profiles sauvegarder sauvegarde.tar.bz2
Crée une sauvegarde de la présentation actuelle du panneau.
xfce4-panel-profiles charger sauvegarde.tar.bz2
Charge et applique la présentation du panneau précédemment exportée.
