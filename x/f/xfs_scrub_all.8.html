NOM

xfs_scrub_all - Vérifie tous les systèmes de fichiers XFS montés

SYNOPSIS

xfs_scrub_all [ -hxV ]

DESCRIPTION

xfs_scrub_all tente de lire et de vérifier toutes les métadonnées de tous les systèmes de fichiers XFS montés. La vérification en ligne est effectuée via l'outil xfs_scrub, soit en l'exécutant directement, soit en utilisant systemd pour le démarrer de manière restreinte. Les systèmes de fichiers montés sont associés à des périphériques de stockage physiques afin que les opérations de vérification puissent être exécutées en parallèle tant que aucun autre vérificateur n'accède simultanément au même périphérique.

OPTIONS

--auto-media-scan-interval
Active automatiquement la vérification des données de fichiers (c'est-à-dire le drapeau -x) si elle n'a pas été exécutée dans l'intervalle spécifié. L'intervalle doit être un nombre à virgule flottante avec un suffixe d'unité facultatif. Les suffixes d'unité pris en charge sont y, q, mo, w, d, h, m et s pour les années, les trimestres de 90 jours, les mois de 30 jours, les semaines, les jours, les heures, les minutes et les secondes, respectivement. Si aucune unité n'est spécifiée, la valeur par défaut est les secondes.
--auto-media-scan-stamp
Chemin d'accès à un fichier qui enregistrera la dernière fois que le balayage du support a été exécuté. Par défaut, il s'agit de /var/lib/xfsprogs/xfs_scrub_all_media.stamp.
-h
Afficher l'aide.
-x
Lire toutes les extentions de données de fichiers pour rechercher les erreurs de disque.
-V
Affiche le numéro de version et quitte.

CODE DE SORTIE

Le code de sortie retourné par xfs_scrub_all est la somme des conditions suivantes :
0 - Aucune erreur
4 - Erreurs du système de fichiers laissées sans correction
8 - Erreur opérationnelle
16 - Erreur d'utilisation ou de syntaxe

Ce sont les mêmes codes d'erreur retournés par xfs_scrub.
