NOM

Xfce 4 Sensors - visualiseur de capteurs pour Xfce 4

SYNTAXE

xfce4-sensors [option]

DESCRIPTION

xfce4-sensors est un visualiseur de capteurs pour le projet Xfce 4 et le plugin de panneau pour les capteurs.

OPTIONS

-h, --help
affiche un bref texte d'aide
-l, --license
affiche les informations de licence
-V, --version
affiche les informations de version
