NOM

xfs_mdrestore - restaure une image metadump XFS dans une image de système de fichiers

SYNTAXE

xfs_mdrestore [ -gi ] [ -l périph_log ] [ -r périph_rt ] source cible
xfs_mdrestore -i [ -l périph_log ] [ -r périph_rt ] source
xfs_mdrestore -V

DESCRIPTION

xfs_mdrestore est un outil de débogage qui restaure une image de métadonnées générée par xfs_metadump(8) dans un système de fichiers. L'argument source spécifie l'emplacement de l'image metadump et l'argument cible spécifie la destination de l'image du système de fichiers. Si la source est -, alors l'image de métadonnées est lue depuis l'entrée standard. Ceci permet que la sortie d'un autre programme, tel qu'une application de compression, soit redirigée vers xfs_mdrestore. La cible peut être un fichier ou un périphérique.

xfs_mdrestore ne doit pas être utilisé pour restaurer des métadonnées sur un système de fichiers existant, sauf si vous êtes absolument certain que la cible peut être détruite.

OPTIONS

-g
Affiche la progression de la restauration sur la sortie standard.
-i
Affiche les informations du metadump sur la sortie standard. Si aucune cible n'est spécifiée, se termine après l'affichage des informations. Les metadumps plus anciens peuvent ne pas inclure d'informations descriptives.
-lpériph_log
Le metadump au format v2 peut contenir des métadonnées extraites d'un log externe. Dans un tel scénario, l'utilisateur doit fournir un périphérique vers lequel le contenu du périphérique log du fichier metadump est copié.
-rpériph_rt
Restaure les métadonnées du périphérique temps réel sur ce périphérique. Ceci n'est requis que pour un metadump au format v2.
-V
Affiche le numéro de version et se termine.

DIAGNOSTICS

xfs_mdrestore retourne un code de sortie de 0 si toutes les métadonnées sont restaurées avec succès, ou 1 si une erreur se produit.

VOIR AUSSI

xfs_metadump(8), xfs_repair(8), xfs(5)

Envoyez les rapports de bogues par e-mail à linux-xfs@vger.kernel.org.
