NOM

xfs_spaceman - afficher des informations sur l'espace libre d'un système de fichiers XFS

SYNOPIS

xfs_spaceman [ -c cmd ] fichier
xfs_spaceman -V

DESCRIPTION

xfs_spaceman signale et contrôle l'utilisation de l'espace libre dans un système de fichiers XFS.

OPTIONS

-c cmd
Les commandes xfs_spaceman peuvent être exécutées de manière interactive (par défaut) ou comme arguments sur la ligne de commande. Plusieurs arguments -c peuvent être donnés. Les commandes sont exécutées dans l'ordre spécifié, puis le programme se termine.

COMMANDES

freesp [ -dgrs ] [-a agno]... [ -b | -e bsize | -h bsize | -m factor ]
Sans arguments, freesp affiche un histogramme de tous les extents d'espace libre dans le système de fichiers. La commande accepte les options suivantes :
-a agno
Collecte des informations sur l'espace libre de ce groupe d'allocation. Cette option peut être spécifiée plusieurs fois pour collecter à partir de plusieurs groupes.
-b
Cet argument établit que les tailles des classes de l'histogramme sont des puissances successives de deux. C'est le comportement par défaut et il est mutuellement exclusif avec les options -e, -h et -m.
-d
Affiche des informations de débogage telles que les informations brutes sur les extents d'espace libre.
-g
Affiche les comptes de blocs d'espace libre et d'extents pour chaque AG.
-e bsize
Définit toutes les tailles de classes de l'histogramme à une valeur spécifique. Cette option est mutuellement exclusive avec les options -b, -h et -m.
-h bsize
Crée une classe d'histogramme avec une borne inférieure de cette valeur. La borne supérieure de cette classe sera un de moins que la borne inférieure de la classe d'histogramme la plus élevée suivante. Cette option peut être donnée plusieurs fois pour contrôler les tailles exactes des classes. Cette option est mutuellement exclusive avec les options -b, -e et -m.
-m factor
Crée chaque classe d'histogramme avec une taille qui est ce nombre de fois la taille de la classe précédente créée. Cette option est mutuellement exclusive avec les options -b, -e et -h.
-r
Interroge le périphérique temps réel pour obtenir des informations sur l'espace libre.
-s
Affiche un résumé des informations sur l'espace libre trouvées.
info
Affiche des informations de géométrie sélectionnées sur le système de fichiers. Le fichier ouvert doit être un point de montage d'un système de fichiers XFS. La sortie aura le même format que celui que xfs_info(8) affiche lors de l'interrogation d'un système de fichiers.
health [ -a agno] [ -c ] [ -f ] [ -i inum ] [ -n ] [ -q ] [ -r rgno ] [ chemins ]
Signale l'état de santé des métadonnées du groupe de systèmes de fichiers donné.
-a agno
Signale l'état de santé du groupe d'allocation donné.
-c
Analyse tous les inodes du système de fichiers et signale l'état de santé de chaque fichier. Si l'option -a est donnée, analyse uniquement les inodes de cet AG.
-f
Signale l'état de santé des métadonnées qui affectent l'ensemble du système de fichiers.
-i inum
Signale l'état de santé d'un inode spécifique.
-n
Lors du signalement de l'état de santé d'un fichier, essaie d'afficher le chemin complet du fichier, si possible. Cette option est désactivée par défaut pour minimiser le temps d'exécution.
-q
Signale uniquement les métadonnées non saines.
-r
Signale l'état de santé du groupe temps réel donné.
chemins
Signale l'état de santé des fichiers aux chemins donnés.
help [ commande ]
Affiche une brève description d'une ou toutes les commandes.
prealloc [ -u id ] [ -g id ] [ -p id ] [ -m minlen ] [ -s ]
Supprime la préallocation spéculative. Si aucune option -u, -g ou -p n'est donnée, cette commande agit sur tous les fichiers. La commande accepte les options suivantes :
-u uid
Efface toutes les préallocations spéculatives pour les fichiers ayant cet identifiant utilisateur. Cette option peut être donnée en combinaison avec les options -g et -p.
-g gid
Efface toutes les préallocations spéculatives pour les fichiers ayant cet identifiant de groupe. Cette option peut être donnée en combinaison avec les options -u et -p.
-p pid
Efface toutes les préallocations spéculatives pour les fichiers ayant cet identifiant de projet. Cette option peut être donnée en combinaison avec les options -u et -g.
-m minlen
Ignore tous les fichiers plus petits que cette taille. Des unités peuvent être fournies pour cet argument.
-s
Attend la fin de la suppression.
print
Affiche une liste de tous les fichiers ouverts.
quit
Quitte xfs_spaceman.
trim ( -a agno | -f | offset longueur ) [ -m minlen ]
Demande au périphérique de stockage sous-jacent de libérer tout le stockage qui pourrait supporter l'espace libre dans le système de fichiers. La commande accepte les options suivantes : (L'une des options -a, -f, ou la paire offset/longueur est requise.)
-a agno
Élague les extents d'espace libre dans le groupe d'allocation donné. Cette option est mutuellement exclusive avec l'option -f et les options offset/longueur.
-f
Élague tout l'espace libre dans le système de fichiers. Cette option est mutuellement exclusive avec l'option -a et les options offset/longueur.
option, longueur
Élague tout l'espace libre dans la plage physique définie par l'offset et la longueur de ce système de fichiers. Des unités peuvent être ajoutées à ces arguments. Cette option est mutuellement exclusive avec les options -a et -f.
-m minlen
Ne pas élaguer les extents d'espace libre plus courts que cette longueur. Des unités peuvent être ajoutées à cet argument.
