NOM

xfce4-power-manager - Le gestionnaire d'alimentation Xfce 4

SYNTAXE

xfce4-power-manager [options]

DESCRIPTION

xfce4-power-manager gère les sources d'alimentation de l'ordinateur et les périphériques qui peuvent être contrôlés pour réduire leur consommation d'énergie (tels que le niveau de luminosité de l'écran LCD, la mise en veille du moniteur). De plus, xfce4-power-manager fournit un ensemble d'interfaces DBus conformes à freedesktop pour informer les autres applications du niveau d'alimentation actuel afin qu'elles puissent ajuster leur consommation d'énergie, et il fournit l'interface d'inhibition qui permet aux applications d'empêcher les actions de veille automatique via le gestionnaire d'alimentation ; par exemple, le gestionnaire de paquets du système d'exploitation devrait utiliser cette interface pendant qu'il effectue des opérations de mise à jour.
Vous pouvez exécuter xfce4-power-manager depuis la ligne de commande sans spécifier d'arguments supplémentaires.

OPTIONS

--daemon
Démarre le gestionnaire d'alimentation en mode démon.
--debug
Demande au gestionnaire d'alimentation d'afficher des messages de débogage sur la console ; utile si vous devez envoyer un rapport de bug.
--dump
Demande au gestionnaire d'alimentation d'afficher les informations de configuration sur la console.
--restart
Redémarre le gestionnaire d'alimentation en cours d'exécution.
--customize
Affiche la boîte de dialogue de configuration.
--quit
Fait en sorte que toute instance en cours d'exécution de xfce4-power-manager se quitte.
--version
Affiche les informations sur la version.
