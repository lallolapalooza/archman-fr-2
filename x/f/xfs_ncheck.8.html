NOM

xfs_ncheck - génère des chemins à partir des numéros d'inode pour XFS

SYNTAXE

xfs_ncheck [ -i ino ] ... [ -f ] [ -s ] [ -l logdev ] périphérique
xfs_ncheck -V

DESCRIPTION

xfs_ncheck sans arguments -i génère une liste de numéros d'inode et de chemins de tous les fichiers du système de fichiers donné. Les noms des fichiers répertoire sont suivis de /.. La sortie n'est triée dans aucun ordre particulier. Le système de fichiers à examiner est spécifié par l'argument périphérique, qui doit être le périphérique de disque ou de volume pour le système de fichiers. Les systèmes de fichiers stockés dans des fichiers peuvent également être vérifiés en utilisant l'option -f.

OPTIONS

-f
Spécifie que l'image du système de fichiers à traiter est stockée dans un fichier régulier à l'adresse périphérique (voir l'option mkfs.xfs -d fichier). Cela peut se produire si une copie d'image d'un système de fichiers a été faite dans un fichier ordinaire.
-l logdev
Spécifie le périphérique où se trouve le journal externe du système de fichiers. Uniquement pour les systèmes de fichiers qui utilisent un journal externe. Voir l'option mkfs.xfs -l, et référez-vous à xfs(5) pour une description détaillée du journal XFS.
-s
Limite le rapport aux fichiers spéciaux et aux fichiers avec le bit setuid activé. Cette option peut être utilisée pour détecter des violations de politique de sécurité.
-i ino
Limite le rapport aux seuls fichiers dont les numéros d'inode suivent. Peut être utilisé plusieurs fois pour sélectionner plusieurs numéros d'inode.
-V
Affiche le numéro de version et quitte.

Si le système de fichiers est gravement corrompu, ou très occupé et semble corrompu, un message de la forme qui serait généré par la commande "check" de xfs_db(8) peut apparaître.

xfs_ncheck n'est utile qu'avec les systèmes de fichiers XFS.

VOIR AUSSI

mkfs.xfs(8), xfs(5).
