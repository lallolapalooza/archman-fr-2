NOM

xfce4-notifyd-config - interface graphique de configuration pour xfce4-notifyd

SYNTAXE

xfce4-notifyd-config [-?] [-V] [-s ID_SOCKET] [--display=AFFICHAGE]

DESCRIPTION

xfce4-notifyd-config lance l'interface graphique de configuration pour xfce4-notifyd.

OPTIONS

-?, --help
Afficher l'aide
-V, --version
Afficher les informations de version
-s, --socket-id=ID_SOCKET
Socket du gestionnaire de paramètres
--display=AFFICHAGE
Affichage X à utiliser
