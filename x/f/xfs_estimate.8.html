xfs_estimate(8) Manuel du gestionnaire système xfs_estimate(8)

NOM

xfs_estimate - estimer l'espace qu'un système de fichiers XFS occupera

SYNOPSIS

xfs_estimate [ -h ] [ -b taille_bloc ] [ -i taille_journal ]
		   [ -e taille_journal ] [ -v ] répertoire ...
xfs_estimate -V

DESCRIPTION

Pour chaque argument répertoire, xfs_estimate estime l'espace que ce répertoire occuperait s'il était copié sur un système de fichiers XFS. xfs_estimate ne traverse pas les points de montage. Les définitions suivantes sont utilisées :

Ko = *1024
Mo = *1024*1024
Go = *1024*1024*1024

Les options de xfs_estimate sont :

-b taille_bloc
Utilise taille_bloc au lieu de la taille de bloc par défaut de 4096 octets. Le modificateur k peut être utilisé après le nombre pour indiquer une multiplication par 1024. Par exemple,
xfs_estimate -b 64k /
demande une estimation de l'espace requis par le répertoire / sur un système de fichiers XFS utilisant une taille de bloc de 64K (65536) octets.
-v
Affiche plus d'informations, formatées.
-h
Affiche le message d'utilisation.
-i, -e taille_journal
Utilise taille_journal au lieu de la taille de journal par défaut de 1000 blocs. -i fait référence à un journal interne, tandis que -e fait référence à un journal externe. Les modificateurs k ou m peuvent être utilisés après le nombre pour indiquer une multiplication par 1024 ou 1048576, respectivement.
Par exemple,
xfs_estimate -i 1m /
demande une estimation de l'espace requis par le répertoire / sur un système de fichiers XFS utilisant un journal interne de 1 mégaoctet.
-V
Affiche le numéro de version et quitte.

EXEMPLES

% xfs_estimate -e 10m /var/tmp
/var/tmp prendra environ 4.2 mégaoctets
        avec le journal externe utilisant 2560 blocs ou environ 10.0 mégaoctets
% xfs_estimate -v -e 10m /var/tmp
répertoire                    taille_bloc   blocs    mégaoctets    taille_journal
/var/tmp                       4096      792        4.0Mo   10485760
% xfs_estimate -v /var/tmp
répertoire                    taille_bloc   blocs    mégaoctets    taille_journal
/var/tmp                       4096     3352       14.0Mo   10485760
% xfs_estimate /var/tmp
/var/tmp prendra environ 14.0 mégaoctets
