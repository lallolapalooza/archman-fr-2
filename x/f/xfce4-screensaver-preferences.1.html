XFCE-SCREENSAVER-PREFERENCES(1) Manuel des commandes générales XFCE-SCREENSAVER-PREFERENCES(1)

NOM

xfce4-screensaver-preferences - Configurer Xfce Screensaver

SYNTAXE

xfce4-screensaver-preferences [ OPTIONS]

DESCRIPTION

Gère les préférences du Xfce Screensaver.

OPTIONS

Ce programme n'accepte que les options GTK standard.

BOGUES
