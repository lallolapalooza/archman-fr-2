NOM

xfce4-screensaver-command - contrôle l'économiseur d'écran Xfce

SYNTAXE

xfce4-screensaver-command [OPTION...]

DESCRIPTION

xfce4-screensaver-command est un outil pour contrôler une instance déjà en cours d'exécution de xfce4-screensaver.

OPTIONS

--exit
Demande à l'économiseur d'écran de se terminer proprement
-q, --query
Interroge l'état de l'économiseur d'écran
-t, --time
Interroge la durée pendant laquelle l'économiseur d'écran a été actif
-l, --lock
Demande au processus de l'économiseur d'écran en cours de verrouiller l'écran immédiatement
-c, --cycle
Si l'économiseur d'écran est actif, bascule vers une autre démo graphique
-a, --activate
Active l'économiseur d'écran (écran noir)
-d, --deactivate
Si l'économiseur d'écran est actif, le désactive (écran non noir)
-p, --poke
Pique l'économiseur d'écran en cours pour simuler une activité utilisateur
-i, --inhibit
Empêche l'activation de l'économiseur d'écran. La commande est bloquée tant que l'inhibition est active.
-n, --application-name
Le nom de l'application appelante qui empêche l'économiseur d'écran d'agir
-r, --reason
La raison pour laquelle l'économiseur d'écran est empêché d'agir
-V, --version
Version de cette application
