NOM

xfs_protofile - créer un fichier proto pour utilisation avec mkfs.xfs

SYNTAXE

xfs_protofile chemin [ chemins... ]
xfs_protofile -V

DESCRIPTION

xfs_protofile parcourt une arborescence de répertoires pour générer un fichier proto. Le format du fichier proto est spécifié dans la page de manuel mkfs.xfs(8) et est dérivé de la 3ème édition d'Unix.

OPTIONS

chemin
Créer des directives de fichier proto pour copier ce chemin dans le répertoire racine. Si le chemin est un répertoire, des directives de fichier proto seront émises pour reproduire l'arborescence entière comme une sous-arborescence du répertoire racine. Si le chemin n'est pas un répertoire, des directives de fichier proto seront émises pour créer le fichier comme une entrée dans le répertoire racine. Le premier chemin doit correspondre à un répertoire.

BOGUES

Les noms de fichiers ne peuvent pas contenir d'espaces. Les attributs étendus ne sont pas copiés dans le système de fichiers.
