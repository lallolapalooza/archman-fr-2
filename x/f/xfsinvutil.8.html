xfsinvutil(8) Manuel du gestionnaire système xfsinvutil(8)

NOM

xfsinvutil - utilitaire de vérification et de purge de la base de données d'inventaire xfsdump

SYNTAXE

xfsinvutil [-F|-i] [-m étiquette_média] -M point_montage jj/mm/aaaa
xfsinvutil [-F|-i] [-m étiquette_média] -u UUID jj/mm/aaaa
xfsinvutil [-F] -s ID_SESSION
xfsinvutil -i
xfsinvutil -C

DESCRIPTION

xfsdump maintient un inventaire de sauvegarde en ligne dans /var/lib/xfsdump/inventory. L'option -I de xfsdump affiche le contenu de l'inventaire de manière hiérarchique. Les niveaux de la hiérarchie sont : système de fichiers, session de sauvegarde, flux, et fichier média.

xfsinvutil est un utilitaire pour vérifier la cohérence de cette base de données d'inventaire, pour supprimer les entrées des sessions de sauvegarde qui ne sont peut-être plus pertinentes, et pour parcourir le contenu de l'inventaire.

Les options de ligne de commande suivantes sont disponibles :

-F
Ne pas demander à l'opérateur. Lorsque xfsinvutil rencontre une session de sauvegarde correspondante, xfsinvutil demande normalement la permission à l'opérateur de supprimer l'entrée. Avec cette option, la suppression est effectuée, sans poser de questions.
-i
Mode interactif. Fait fonctionner xfsinvutil dans un mode qui permet à l'opérateur de parcourir et de modifier le contenu de l'inventaire. Se référer à la section Mode Interactif ci-dessous pour plus d'informations.
-M point_montage jj/mm/aaaa
Purger les sessions de sauvegarde identifiées par le point de montage donné qui ont été créées avant la date spécifiée. Optionnellement, -m peut être spécifié pour limiter davantage les sessions de sauvegarde correspondantes par étiquette média. xfsinvutil demandera à l'opérateur avant de purger une session de sauvegarde, sauf si les options -F ou -i sont données.
-u UUID jj/mm/aaaa
Comme -M, sauf que le système de fichiers correspondant est spécifié en utilisant son identifiant unique universel (UUID) au lieu de son point de montage.
-m étiquette_média
Si spécifié, seules les sessions ayant au moins un fichier média dont l'étiquette correspond à cette valeur seront éligibles à la purge. Cette restriction s'ajoute à celles imposées par la date et les options -M ou -u. Cette option permet la purge de toutes les références d'inventaire à des médias qui auraient pu être écrasés ou perdus. Noter que cette option ne s'applique pas aux sessions sans fichiers média.
-s ID_SESSION
Purger la session de sauvegarde identifiée par l'ID de session donné. xfsinvutil demandera à l'opérateur avant de purger une session de sauvegarde, sauf si l'option -F est donnée.
-C
Avec cette option, xfsinvutil effectue des vérifications de cohérence pour toutes les entrées de la base de données d'inventaire. Il corrige tous les problèmes trouvés. Si aucune entrée cohérente n'est trouvée, le fichier de base de données d'inventaire correspondant est supprimé.

Mode Interactif

Lorsqu'il est exécuté avec -i, xfsinvutil présente à l'opérateur une représentation hiérarchique de l'inventaire xfsdump. Dans ce mode, l'opérateur peut utiliser les touches fléchées (ou les touches h j k l) pour naviguer dans l'inventaire et utiliser également les touches et fonctionnalités suivantes :

+
Développer une branche de l'arbre.
-
Réduire une branche de l'arbre.
*
Développer complètement une branche de l'arbre.
%
Réduire complètement une branche de l'arbre.
h
Déplacer la sélection vers l'entrée parente.
l
Déplacer la sélection vers l'entrée enfant.
j
Déplacer la sélection vers l'entrée suivante.
k
Déplacer la sélection vers l'entrée précédente.
d
Marquer l'enregistrement actuel, et tous les sous-enregistrements, pour être supprimés.
u
Annuler le marquage de suppression de l'enregistrement actuel et de tous les enregistrements parents.
i
Importer un autre inventaire xfsdump.
?
Afficher la fenêtre d'aide.
x
Valider toutes les modifications apportées à l'inventaire et quitter le programme.
q
Quitter le programme sans valider les modifications apportées à l'inventaire.

Les inventaires d'autres hôtes peuvent être importés pour créer un inventaire commun plus large. Il est recommandé de copier le contenu de /var/lib/xfsdump/inventory sur l'hôte distant dans un répertoire local temporaire avant d'exécuter xfsinvutil. Lorsque xfsinvutil est exécuté en mode interactif, et que l'opérateur appuie sur i, il sera invité à entrer le chemin vers l'inventaire à importer. xfsinvutil ajoutera alors le contenu de l'inventaire importé à la fenêtre principale, et toutes les entrées seront marquées comme importées. L'opérateur peut alors supprimer toutes les entrées qui ne doivent pas être importées. Lorsque l'opérateur valide les modifications, xfsinvutil importera toutes les entrées qui n'ont pas été marquées comme supprimées. Les entrées supprimées ne sont pas réellement supprimées de l'inventaire importé d'origine.

NOTES

Inventaire

Chaque session de sauvegarde met à jour une base de données d'inventaire dans /var/lib/xfsdump/inventory. xfsdump utilise l'inventaire pour déterminer la base des sauvegardes incrémentielles et reprises.

Cette base de données peut être affichée en invoquant xfsdump avec l'option -I. L'affichage utilise une indentation tabulée pour présenter l'inventaire hiérarchiquement. Le premier niveau est le système de fichiers. Le deuxième niveau est la session. Le troisième niveau est le flux média (actuellement, un seul flux est pris en charge). Le quatrième niveau liste les fichiers médias composant séquentiellement le flux.

base de données d'inventaire de sauvegarde
