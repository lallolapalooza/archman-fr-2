NOM

xfce4-mixer - ajuster les niveaux de volume

SYNOPSIS

xfce4-mixer [-dhV?]

DESCRIPTION

xfce4-mixer est un mélangeur audio qui vous permet d'ajuster les niveaux de volume d'entrée et de sortie de vos cartes son.

OPTIONS

Les options suivantes sont prises en charge :

-d, --debug
Imprimer les messages de diagnostic utiles au débogage sur stderr.
-h, -?, --help
Afficher un résumé de toutes les options de ligne de commande et quitter.
-V, --version
Afficher le numéro de version et quitter.

STATUT DE SORTIE

0

>0
