NOM

xfce4-session-logout - Se déconnecter de Xfce

SYNTAXE

xfce4-session-logout

DESCRIPTION

Cette page de manuel documente brièvement la commande xfce4-session-logout.

La commande xfce4-session-logout vous permet de vous déconnecter programmatiquement de votre session Xfce. Elle demande au gestionnaire de session d'afficher l'écran de confirmation de déconnexion, ou, si l'une des options de ligne de commande ci-dessous est fournie, elle demande au gestionnaire de session d'exécuter immédiatement l'action demandée.

OPTIONS

xfce4-session-logout accepte les options de ligne de commande suivantes :

--logout
Se déconnecter sans afficher la boîte de dialogue de déconnexion.
--halt
Arrêter sans afficher la boîte de dialogue de déconnexion.
--reboot
Redémarrer sans afficher la boîte de dialogue de déconnexion.
--suspend
Suspendre sans afficher la boîte de dialogue de déconnexion.
--hibernate
Mettre en veille prolongée sans afficher la boîte de dialogue de déconnexion.
--hybrid-sleep
Veille hybride sans afficher la boîte de dialogue de déconnexion.
--fast
Effectuer un arrêt rapide. Ceci indique au gestionnaire de session de ne pas sauvegarder la session, mais plutôt de quitter tout rapidement.
--help
Afficher un écran d'aide et quitter.
--version
Afficher les informations sur la version et quitter.
