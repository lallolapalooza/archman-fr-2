XFD(1) Manuel des commandes générales XFD(1)

NOM

xfd - afficher tous les caractères d'une police X

SYNTAXE

xfd [-options ...] -fn nom_police

xfd [-options ...] -fa nom_police

DESCRIPTION

L'utilitaire xfd crée une fenêtre contenant le nom de la police affichée, une rangée de boutons de commande, plusieurs lignes de texte pour afficher les métriques de caractères, et une grille contenant un glyphe par cellule. Les caractères sont affichés dans l'ordre croissant de gauche à droite, de haut en bas. Le premier caractère affiché en haut à gauche est le caractère numéro 0, sauf si l'option -start a été fournie, auquel cas le caractère portant le numéro spécifié dans l'option -start est utilisé.

Les caractères sont affichés dans une grille de cases, chacune étant assez grande pour contenir n'importe quel caractère de la police. Chaque glyphe de caractère est dessiné en utilisant la requête PolyText16 (utilisée par la routine Xlib XDrawString16) ou la routine XftDrawString32, selon que l'option -fn ou -fa a été donnée. Si l'option -box est fournie, un rectangle sera dessiné autour de chaque caractère, montrant où une requête ImageText16 (utilisée par la routine Xlib XDrawImageString16) afficherait une couleur de fond.

L'origine de chaque glyphe est normalement réglée de telle sorte que le caractère soit dessiné dans le coin supérieur gauche de la cellule de la grille. Cependant, si un glyphe a une marge gauche négative ou une ascention, descente ou marge droite inhabituellement grande (comme c'est le cas avec la police cursor), certains caractères peuvent ne pas apparaître dans leurs propres cellules de grille. L'option -center peut être utilisée pour forcer tous les glyphes à être centrés dans leurs cellules respectives.

Tous les caractères de la police peuvent ne pas tenir dans la fenêtre en même temps. Pour voir la page suivante de glyphes, appuyez sur le bouton Next en haut de la fenêtre. Pour voir la page précédente, appuyez sur Prev. Pour quitter xfd, appuyez sur Quit.

Les métriques de caractères individuels (index, largeur, marges, ascention et descente) peuvent être affichées en haut de la fenêtre en cliquant sur le caractère désiré.

Le nom de la police affiché en haut de la fenêtre est le nom complet de la police, tel que déterminé par le serveur. Voir xlsfonts et fc-list pour des moyens de générer des listes de polices, ainsi que des résumés plus détaillés de leurs métriques et propriétés.

OPTIONS

xfd accepte toutes les options de ligne de commande standard du toolkit ainsi que les options supplémentaires listées ci-dessous :

-fn police
Cette option spécifie la police côté serveur X à afficher. Ceci peut aussi être défini par la ressource font de FontGrid. Une police doit être spécifiée.
-fa police
Cette option spécifie une police Xft à afficher. Ceci peut aussi être défini par la ressource face de FontGrid. Un modèle de police doit être spécifié.
-box
Cette option indique qu'une boîte doit être dessinée entourant la zone qui serait remplie de couleur de fond par une requête ImageText. Ceci peut aussi être défini par la ressource boxChars de FontGrid. La valeur par défaut est False.
-center
Cette option indique que chaque glyphe doit être centré dans sa grille. Ceci peut aussi être défini par la ressource centerChars de FontGrid. La valeur par défaut est False.
-start nombre
Cette option spécifie l'index du glyphe du coin supérieur gauche de la grille. Ceci est utilisé pour visualiser les caractères à des emplacements arbitraires dans la police. Ceci peut aussi être défini par la ressource startChar de FontGrid. La valeur par défaut est 0.
-bc couleur
Cette option spécifie la couleur à utiliser si des boîtes ImageText sont dessinées. Ceci peut aussi être défini par la ressource boxColor de FontGrid.
-rows nombre_lignes
Cette option spécifie le nombre de lignes dans la grille. Ceci peut aussi être défini par la ressource cellRows de FontGrid.
-columns nombre_colonnes
Cette option spécifie le nombre de colonnes dans la grille. Ceci peut aussi être défini par la ressource cellColumns de FontGrid.

WIDGETS

Pour spécifier des ressources, il est utile de connaître les widgets qui composent xfd. Dans la notation ci-dessous, l'indentation indique la structure hiérarchique. Le nom de la classe du widget est donné en premier, suivi du nom de l'instance du widget. Le nom de la classe de l'application est Xfd.

Xfd  xfd
	Paned  pane
		Label  fontname
		Box  box
			Command  quit
			Command  prev
			Command  next
		Label  select
		Label  metrics
		Label  range
		Label  start
		Form  form
			FontGrid  grid

RESSOURCES FONTGRID

Le widget FontGrid est un widget spécifique à l'application, et une sous-classe du widget Simple dans l'ensemble de widgets Athena. Les effets et les noms d'instance des ressources de ce widget sont donnés dans la section OPTIONS. Mettez en majuscule la première lettre du nom de l'instance de ressource pour obtenir le nom de classe correspondant.

RESSOURCES SPÉCIFIQUES APPLICATION

Les noms d'instance des ressources spécifiques à l'application sont donnés ci-dessous. Mettez en majuscule la première lettre du nom de l'instance de ressource pour obtenir le nom de classe correspondant. Ces ressources sont probablement peu intéressantes à moins que vous ne localisiez xfd pour une autre langue.

selectFormat
Spécifie une chaîne de format de style printf utilisée pour afficher des informations sur le caractère sélectionné. La valeur par défaut est "caractère 0x%02x%02x (%u,%u) (%#o,%#o)". Les arguments qui suivront la chaîne de format sont char.byte1, char.byte2, char.byte1, char.byte2, char.byte1, char.byte2. char.byte1 est l'octet 1 du caractère sélectionné. char.byte2 est l'octet 2 du caractère sélectionné.
metricsFormat
Spécifie une chaîne de format de style printf utilisée pour afficher les métriques des caractères. La valeur par défaut est "largeur %d; gauche %d, droite %d; ascention %d, descente %d (police %d, %d)". Les arguments qui suivront la chaîne de format sont les métriques du caractère largeur, lbearing, rbearing, ascention du caractère, descente du caractère, ascention de la police et descente de la police.
rangeFormat
Spécifie une chaîne de format de style printf utilisée pour afficher la plage de caractères actuellement affichée. La valeur par défaut est "plage : 0x%02x%02x (%u,%u) à 0x%02x%02x (%u,%u)". Les arguments qui suivront la chaîne de format sont les champs suivants de la structure XFontStruct renvoyée par l'ouverture de la police : min_byte1, min_char_or_byte2, min_byte1, min_char_or_byte2, max_byte1, max_char_or_byte2, max_byte1, max_char_or_byte2.
startFormat
Spécifie une chaîne de format de style printf utilisée pour afficher des informations sur le caractère dans le coin supérieur gauche de la grille de police. La valeur par défaut est "coin supérieur gauche : 0x%04x (%d,%d)". Les arguments qui suivront la chaîne de format sont le nouveau caractère, l'octet de poids fort du nouveau caractère et l'octet de poids faible du nouveau caractère.
nocharFormat
Spécifie une chaîne de format de style printf à afficher lorsque le caractère sélectionné n'existe pas. La valeur par défaut est "aucun tel caractère 0x%02x%02x (%u,%u) (%#o,%#o)". Les arguments qui suivront la chaîne de format sont les mêmes que pour la ressource selectFormat.
