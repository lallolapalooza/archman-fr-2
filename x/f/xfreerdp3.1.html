NOM

xfreerdp3 - Client X11 du protocole RDP (Remote Desktop Protocol)

SYNTAXE

xfreerdp3 [fichier] [options] [/v:serveur[:port]]

DESCRIPTION

xfreerdp3 est un client X11 du protocole RDP (Remote Desktop Protocol) qui fait partie du projet FreeRDP. Un serveur RDP est intégré à de nombreuses éditions de Windows. D'autres serveurs incluent ogon, gnome-remote-desktop, xrdp et VRDP (VirtualBox).

RACCOURCIS CLAVIER

<CTRL DROIT>

libère la capture du clavier et de la souris.
Si le clavier est capturé, les raccourcis locaux ne fonctionnent plus et sont envoyés au système distant.
Si la souris est capturée (facultatif), la détection de gestes locaux ne fonctionne pas et la souris pourrait ne pas pouvoir quitter la fenêtre RDP. Les événements de souris ne sont pas modifiés.

<CTRL>+<ALT>+<Retour>

bascule l'état plein écran de l'application

<CTRL>+<ALT>+<m>

Minimise l'application

<CTRL>+<ALT>+c

bascule le contrôle à distance dans une session d'assistance à distance

<CTRL>+<ALT>+<d>

Déconnecte la session et termine l'application

Script d'action

exécute un script prédéfini à la pression d'une touche. Si le script n'existe pas, il est ignoré. Les scripts peuvent être fournis à l'emplacement par défaut $XDG_CONFIG_HOME/freerdp/action.sh ou comme argument de ligne de commande /action:script:<chemin>. Le script recevra la combinaison de touches actuelle comme argument. La sortie du script est analysée pour key-local, ce qui indique que le script a utilisé la combinaison de touches, sinon la combinaison est transmise à la partie distante.

Booléen JSON

Booléen JSON

Si les vérifications dans la configuration globale n'acceptent pas le certificat, ne pas demander à l'utilisateur

EXEMPLES

#!/bin/bash
# nous avons reçu une combinaison de touches
if [ "$1" = "key" ];
then
	# nous n'avons qu'un seul argument 'key'
	# listez toutes les combinaisons prises en charge avec echo
	if [ $# -eq 1 ];
	then
		echo "ctrl+alt+f1"
		echo "ctrl+alt+f2"
	else
		# Nous voulons l'action pour une seule combinaison
		# utilisez 'key-local' pour ne pas transférer vers la session RDP
		if [ "$2" = "ctrl+alt+f1" ];
		then
			echo "key-local"
		fi
		if [ "$2" = "ctrl+alt+f2" ];
		then
				echo "/usr/local/bin/somescript.sh"
		fi
	fi
fi
if [ "$1" = "xevent" ];
	then
		if [ $# -eq 1 ];
		then
			echo "FocusIn"
			echo "SelectionClear"
		else
			if [ "$2" = "SelectionNotify" ];
			then
				echo "/usr/local/bin/someprogram"
			fi
		fi
	fi
Exemple de script d'action pour les événements clavier, listant ctrl+alt+f1 à gérer par le gestionnaire de fenêtres local et ctrl+alt+f2 exécutant un script

La valeur de retour du programme détermine si la touche est traitée localement ou à distance (0 pour local, > 0 pour distant, < 0 pour les erreurs)

xfreerdp3 connection.rdp /p:Pwd123! /f

Connectez-vous en mode plein écran en utilisant une configuration stockée connection.rdp et le mot de passe Pwd123!

xfreerdp3 /u:USER /size:50%h /v:rdp.contoso.com

Connectez-vous à l'hôte rdp.contoso.com avec l'utilisateur USER et une taille de 50 % de la hauteur. Si la largeur (w) est définie au lieu de la hauteur (h) comme /size:50%w. 50 % de la largeur est utilisé.

xfreerdp3 /u:CONTOSO\\JohnDoe /p:Pwd123! /v:rdp.contoso.com

Connectez-vous à l'hôte rdp.contoso.com avec l'utilisateur CONTOSO\\JohnDoe et le mot de passe Pwd123!

xfreerdp3 /u:JohnDoe /p:Pwd123! /w:1366 /h:768 /v:192.168.1.100:4489

Connectez-vous à l'hôte 192.168.1.100 sur le port 4489 avec l'utilisateur JohnDoe, le mot de passe Pwd123!. La largeur de l'écran est définie sur 1366 et la hauteur sur 768

xfreerdp3 /u:JohnDoe /p:Pwd123! /vmconnect:C824F53E-95D2-46C6-9A18-23A5BB403532 /v:192.168.1.100

Établissez une connexion à l'hôte 192.168.1.100 avec l'utilisateur JohnDoe, le mot de passe Pwd123! et connectez-vous à la console Hyper-V (utilise le port 2179, désactive la négociation) avec l'ID de VM C824F53E-95D2-46C6-9A18-23A5BB403532
