NOM

xrootd - démon eXtended ROOT

SYNTAXE

xrootd [options] [exportations]

DESCRIPTION

Le démon xrootd fournit un accès LAN/WAN aux données dans des nœuds autonomes, des nœuds regroupés (cluster), ainsi que des clusters globalement fédérés. La syntaxe d'utilisation peut être affichée en tapant "xrootd -h". La documentation HTML complète se trouve à


https://xrootd.web.cern.ch/doc/dev57/xrd_config.htm

NOTES

La documentation de tous les composants associés à xrootd peut être trouvée à l'adresse https://xrootd.org/docs.html

DIAGNOSTICS

Les erreurs de configuration génèrent un message d'erreur et un statut de sortie non nul. Le programme ne se termine jamais en cas de succès. Utilisez la commande kill ou "/etc/init.d/xrootd stop" pour terminer le programme.

LICENCE

Les termes de la licence peuvent être affichés en tapant "xrootd -H".

NIVEAU DE SUPPORT

Le démon xrootd est pris en charge par la collaboration xrootd. Les informations de contact se trouvent à
https://xrootd.org/contact.html
