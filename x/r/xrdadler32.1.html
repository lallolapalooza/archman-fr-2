NOM

xrdadler32 - calculer et afficher une somme de contrôle adler32

SYNTAXE

xrdadler32 [fichier]

DESCRIPTION

L'utilitaire xrdadler32 calcule et affiche une valeur de somme de contrôle adler32 pour un fichier. La syntaxe d'utilisation peut être affichée en tapant "xrdadler32 -h". Actuellement, seule la synopsis d'utilisation est disponible en tant que documentation.

NOTES

La documentation de tous les composants associés à xrdadler32 peut être trouvée sur https://xrootd.org/docs.html
La commande xrdadler32 utilise l'infrastructure XRootD pour enregistrer la somme de contrôle calculée dans les attributs étendus du fichier. Les requêtes ultérieures utilisent la somme de contrôle stockée dans les attributs du fichier.

DIAGNOSTICS

Les erreurs produisent un message d'erreur et un statut de sortie non nul.

LICENCE

Les conditions de licence peuvent être affichées en tapant "xrootd -H".

NIVEAU DE SUPPORT

La commande xrdadler32 est prise en charge par la collaboration xrootd. Les informations de contact peuvent être trouvées sur
https://xrootd.org/contact.html
