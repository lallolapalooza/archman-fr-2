NOM

xrdgsiproxy - générer un certificat proxy X.509

SYNTAXE

xrdgsiproxy [-h] [mode] [-debug] [-f [-out] fichier]

DESCRIPTION

L'utilitaire xrdgsiproxy affiche, crée et détruit des certificats proxy d'utilisateur X.509 utilisés par le protocole de sécurité (gsi) de l'infrastructure de sécurité de grille.

OPÉRANDES

mode

init créer un certificat proxy et le fichier proxy associé
info afficher le contenu du fichier proxy existant
destroy supprimer le fichier proxy existant

OPTIONS

-h afficher l'aide

-f [-out] fichier
Emplacement non standard du fichier proxy
init mode uniquement:
-certdir rép
Emplacement non standard du répertoire contenant les informations sur les AC connus
-cert fichier
Emplacement non standard du certificat pour lequel les proxies sont désirés
-key fichier
Emplacement non standard de la clé privée à utiliser pour signer le proxy
-bits n
Force en bits de la clé [par défaut 2048]
-valid hh:mm
Validité temporelle du certificat proxy [par défaut 12:00]
-path-length len
Nombre maximum de niveaux descendants sous ce proxy [par défaut 0]

NOTES

La documentation HTML complète peut être trouvée à
https://xrootd.web.cern.ch/doc/dev56/sec_config.htm

La documentation pour tous les composants associés à xrdgsiproxy peut être trouvée à https://xrootd.org/docs.html

DIAGNOSTICS

Les erreurs génèrent un message d'erreur et un statut de sortie non nul.

LICENCE

NIVEAU DE SUPPORT

https://xrootd.org/contact.html
