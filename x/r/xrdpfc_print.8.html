NOM

xrdpfc_print - affiche le contenu des métadonnées du cache de fichier XRootd ProxyFileCache

SYNTAXE

xrdpfc_print [options] chemin ...
options: [-config fichier] [-unit B|kB|MB] [-json] [-indent caractères] [-verbose] [-help]

DESCRIPTION

xrdpfc_print affiche l'état des blocs de fichiers téléchargés et les statistiques d'accès aux fichiers mis en cache.

OPTIONS

-c | -config <nom-fichier>

Fichier de configuration Xrootd. Utilisé pour charger un système de fichiers non par défaut (directive ofs.osslib) et le préfixe pour l'emplacement des fichiers mis en cache (directive oss.localroot).
-v | -verbose
Affiche le bit d'état pour chaque bloc de fichier.
-u | -unit <B|kB|MB>
Spécifie l'unité pour la taille de fichier et les octets d'accès; la taille du tampon/bloc est affichée au maximum en kB. Arrondi à l'inférieur pour kB et MB. kB est la valeur par défaut.
Cette option ne s'applique PAS au format de sortie JSON, où l'unité est toujours B.
-j | -json
Affiche la sortie au format JSON.
-i | -indent <entier>
Spécifie l'alignement pour le format JSON. La valeur par défaut est -1 : une seule ligne sans aucun espace blanc.
-h | -help
Affiche les informations d'utilisation.

OPÉRANDES

chemin

Chemin vers un fichier cinfo ou un répertoire pour lequel les informations doivent être affichées. Le chemin peut être relatif ou absolu. Si le chemin commence par root:/, il est supposé être un LFN et est traduit via les règles OSS standard (au minimum, il est préfixé par oss.localroot). Dans ce cas, l'option -config est obligatoire.

NOTES

La documentation de tous les composants associés à xrdpfc_print se trouve sur https://xrootd.org/docs.html

DIAGNOSTICS

Les erreurs génèrent un message d'erreur et un statut de sortie non nul.

LICENCE

Les conditions de licence peuvent être affichées en tapant "xrdpfc_print -H".

NIVEAU SUPPORT

La commande xrdpfc_print est prise en charge par la collaboration xrootd. Les informations de contact peuvent être trouvées sur
