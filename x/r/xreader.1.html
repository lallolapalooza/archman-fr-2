XREADER(1) Manuel des commandes générales XREADER(1)

NOM

Xreader - Un visualiseur de documents

SYNTAXE

xreader [OPTIONS...] [FICHIERS...]

DESCRIPTION

Xreader est un visualiseur simple de documents multipages. Il peut afficher et imprimer des fichiers PostScript (PS), Encapsulated PostScript (EPS), DJVU, DVI, XPS et Portable Document Format (PDF).

Lorsque le document le supporte, il permet également la recherche de texte, la copie de texte vers le presse-papiers, la navigation hypertextuelle et les signets de table des matières.
Cette page de manuel documente brièvement la commande xreader.

OPTIONS

nom-fichier(s)...
Spécifie le fichier à ouvrir au démarrage de xreader. Si cela n'est pas spécifié, xreader démarrera avec une fenêtre vide et vous pourrez ouvrir un fichier depuis le menu ou en utilisant le raccourci CTRL+O. Plusieurs fichiers peuvent être chargés s'ils sont séparés par des espaces. xreader prend également en charge la gestion des fichiers distants.
-p, --etiquette-page=PAGE
Vous pouvez spécifier ici une étiquette de page, cette page sera sélectionnée dans le document si elle existe.
-i, --index-page=NOMBRE
Vous pouvez spécifier ici un numéro de page, cette page sera sélectionnée dans le document si elle existe.
-f, --plein-ecran
Démarre xreader en mode plein écran. Vous devez spécifier un document pour démarrer en mode plein écran.
-s, --presentation
Démarre xreader en mode présentation. Vous devez spécifier un document pour démarrer en mode présentation.
-w, --apercu
Démarre xreader en mode aperçu. Vous devez spécifier un document pour démarrer en mode aperçu.
--affichage=AFFICHAGE
Affichage X à utiliser.
--version
Affiche les informations de version et quitte.
-?, -h, --aide
Imprime les options de ligne de commande standard.
--aide-tout
Imprime toutes les options de ligne de commande.

Ce programme accepte également les options GTK standard.

EXEMPLES

xreader --apercu ~/Bureau/trucs.ps

Ouvre stuff.ps depuis le bureau de l'utilisateur actuel, en mode aperçu.

xreader -i 2 -s ./document.pdf

Ouvre document.pdf depuis le répertoire de travail actuel, à la page 2 en mode présentation.

BOGUES

Si vous rencontrez des bogues, ils peuvent être rapportés à :

http://github.com/linuxmint/xreader/issues

VOIR AUSSI

La documentation de Xreader peut être trouvée dans le menu "Aide", ou en appuyant sur la touche F1.
