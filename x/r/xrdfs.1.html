xrdfs(1) Manuel des commandes générales xrdfs(1)

NOM

xrdfs - utilitaire de métadonnées de fichiers et répertoires xrootd

SYNTAXE

xrdfs [--no-cwd] hote[:port] [commande [arguments]]
commande: help, chmod, ls, locate, mkdir, mv, stat, statvfs, query, rm, rmdir,
           truncate, prepare, cat, tail, spaceinfo

DESCRIPTION

L'utilitaire xrdfs exécute des opérations orientées métadonnées (par ex., ls, mv, rm, etc.) sur un ou plusieurs serveurs xrootd. L'aide de la commande est disponible en appelant xrdfs sans options ou paramètres en ligne de commande, puis en tapant "help" en réponse à l'invite de saisie.

OPTIONS

--no-cwd

Aucun répertoire courant (CWD) n'est pré-défini en mode interactif.

COMMANDES

chmod chemin <utilisateur><groupe><autre>

Modifie les permissions du chemin. Exemple de chaîne de permissions : rwxr-x--x
ls [-l] [-u] [-R] [-D] [-Z] [-C] [nom_répertoire]
Obtient la liste du répertoire.
-l effectue un stat sur chaque entrée et affiche une liste détaillée
-u affiche les chemins sous forme d'URL
-R liste les sous-répertoires récursivement
-D affiche les entrées dupliquées
-Z vérifie si le fichier est une archive ZIP et si oui, liste son contenu
-C calcule la somme de contrôle de chaque entrée
locate [-n] [-r] [-d] [-m] [-i] [-p] <chemin>
Obtient les emplacements du chemin.
-r rafraîchir, ne pas utiliser les emplacements mis en cache
-n fait en sorte que le serveur renvoie la réponse immédiatement bien qu'elle puisse être incomplète
-d effectue une localisation profonde récursive pour trouver les serveurs de données
-m préférer les noms d'hôtes aux adresses IP
-i ignorer les dépendances réseau (IPv6/IPv4)
-p être passif : ignorer les informations opaques CGI essayées/essayéesrc
mkdir [-p] [-m<utilisateur><groupe><autre>] <nom_répertoire>
Crée un répertoire/arborescence de répertoires.
-p crée toute l'arborescence de répertoires récursivement
-m<utilisateur><groupe><autre> permissions pour les répertoires nouvellement créés
mv <chemin1> <chemin2>
Déplace chemin1 vers chemin2 localement sur le même serveur.
stat <chemin> [<chemins>]
Obtient des informations sur le(s) fichier(s) ou le(s) répertoire(s).
-q <indicateurs> Fait en sorte que xrdfs retourne le code d'erreur 55 au shell si la combinaison d'indicateurs demandée n'est pas présente ; les indicateurs peuvent être combinés en utilisant '|' ou '&'
Indicateurs disponibles : XBitSet, IsDir, Other, Offline, POSCPending, IsReadable, IsWriteable, BackUpExists
statvfs <chemin>
Obtient des informations sur un système de fichiers virtuel.
query <code> <params>
Obtient des informations sur le serveur. Codes de requête :
config <quoi> Configuration du serveur ; <quoi> est l'un des éléments suivants :
bind_max - le nombre maximum de flux parallèles
chksum - la somme de contrôle prise en charge
pio_max - le nombre maximum de requêtes d'E/S parallèles
readv_ior_max - la taille maximale d'un élément readv
readv_iov_max - le nombre maximum d'entrées readv
tpc - la prise en charge des copies tierces
wan_port - le port à utiliser pour les copies wan
wan_window - la taille de la fenêtre wan_port
window - la taille de la fenêtre tcp
cms - l'état du cmsd
role - le rôle dans un cluster
sitename - le nom du site
version - la version du serveur
checksumcancel <chemin> Annulation de la somme de contrôle du fichier
checksum <chemin> Somme de contrôle du fichier
opaque <arg> Dépendant de l'implémentation
opaquefile <arg> Dépendant de l'implémentation
space <espace> Statistiques d'espace logique
stats <quoi> Statistiques du serveur ; <quoi> est une liste de lettres indiquant les informations à retourner :
a - toutes les statistiques
p - statistiques du protocole
b - statistiques d'utilisation des tampons
s - statistiques de planification
d - statistiques d'interrogation des périphériques
u - statistiques d'utilisation
i - identification du serveur
z - statistiques synchronisées
l - statistiques de connexion
xattr <chemin> Attributs étendus
prepare <reqid> [noms_fichiers] État de la requête de préparation
rm <nom_fichier> [<noms_fichiers>]
Supprime un fichier.
rmdir <nom_répertoire>
Supprime un répertoire.
truncate <nom_fichier> <longueur>
Tronque un fichier.
prepare [-c] [-f] [-s] [-w] [-e] [-p priorité] [-a id_requête] noms_fichiers
Prépare un ou plusieurs fichiers pour l'accès.
-c co-localise les fichiers mis en scène si possible
-f rafraîchit l'heure d'accès au fichier même si l'emplacement est connu
-s met en scène les fichiers sur disque s'ils ne sont pas en ligne
-w lorsque les fichiers seront accédés en modification
-p priorité de la requête, 0 (la plus basse) - 3 (la plus haute)
-a abandonne la requête
-e évince le fichier du cache disque
cat [-o fichier_local] fichiers
Affiche le contenu d'un ou plusieurs fichiers sur la sortie standard
-o affiche dans le fichier local spécifié
tail [-c octets] [-f] fichier
Affiche la dernière partie des fichiers sur la sortie standard.
-c nombre_octets affiche les derniers nombre_octets
-f affiche les données ajoutées au fur et à mesure que le fichier grandit
spaceinfo chemin
Obtient les statistiques d'espace pour le chemin donné.
xattr <chemin> <code> <params>
Opération sur les attributs étendus. Codes :
set <attr> Définit un attribut étendu ;
<attr> est une chaîne de la forme nom=valeur
get <nom> Obtient un attribut étendu.
del <nom> Supprime un attribut étendu.
list Liste les attributs étendus.

CODES DE RETOUR

50 : erreur générique (par ex. config, interne, données, OS)

51 : erreur liée au socket

52 : erreur liée au postmaster

53 : erreur liée à XRootD

54 : erreur de redirection

55 : la réponse à la requête était négative (ce n'est pas une erreur)

NOTES

Pour la liste des variables d'environnement disponibles, veuillez vous référer à xrdcopy(1)

DIAGNOSTICS

Les erreurs produisent un message d'erreur et un statut de sortie non nul.

NOM

xrdfs - Outil de ligne de commande pour interagir avec le système de fichiers distribué ROOT (RFIO)

SYNTAXE

xrdfs [OPTIONS] [COMMANDE] [ARGUMENTS]...

DESCRIPTION

xrdfs est un utilitaire qui permet d'interagir avec le système de fichiers distribué ROOT (RFIO). Il prend en charge une variété de commandes pour manipuler des fichiers et des répertoires, ainsi que pour obtenir des informations sur le système de fichiers.

OPTIONS

-h, --help : Afficher l'aide et quitter.

-V, --version : Afficher les informations sur la version et quitter.

-v, --verbose : Activer la sortie détaillée.

-u, --url URL : Spécifier l'URL du serveur RFIO.

-P, --port PORT : Spécifier le port du serveur RFIO.

-t, --timeout TIMEOUT : Spécifier le délai d'attente en secondes.

COMMANDES

ls [CHEMIN] : Lister le contenu d'un répertoire.

stat [CHEMIN] : Afficher des informations sur un fichier ou un répertoire.

cp SOURCE DESTINATION : Copier un fichier ou un répertoire.

mv SOURCE DESTINATION : Déplacer un fichier ou un répertoire.

rm [CHEMIN] : Supprimer un fichier.

rmdir [CHEMIN] : Supprimer un répertoire vide.

mkdir [CHEMIN] : Créer un répertoire.

get [CHEMIN_DISTANT] [CHEMIN_LOCAL] : Télécharger un fichier depuis le serveur RFIO.

put [CHEMIN_LOCAL] [CHEMIN_DISTANT] : Envoyer un fichier vers le serveur RFIO.

ping : Tester la connectivité avec le serveur RFIO.

CODES DE RETOUR

0 : Succès.

1 : Erreur générale.

2 : Argument invalide.

3 : Commande inconnue.

4 : Échec de la connexion au serveur.

NOTES

Cette page de manuel décrit la syntaxe et les options de xrdfs. Pour plus de détails sur l'utilisation spécifique des commandes, veuillez consulter la documentation officielle du RFIO.

DIAGNOSTICS

Les messages d'erreur sont affichés sur la sortie d'erreur standard (stderr).
