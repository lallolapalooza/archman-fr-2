NOM

xrdpwdadmin - administrer les mots de passe du protocole de sécurité pwd

SYNTAXE

xrdpwdadmin [-m mode] commande [options]

DESCRIPTION

L'utilitaire xrdpwdadmin affiche et maintient les fichiers de mots de passe et de connexion automatique utilisés par le protocole de sécurité de mot de passe (pwd). La documentation HTML complète se trouve à l'adresse :


https://xrootd.web.cern.ch/doc/dev56/sec_config.htm

NOTES

La documentation de tous les composants associés à xrdpwdadmin se trouve à l'adresse https://xrootd.org/docs.html

DIAGNOSTICS

Les erreurs produisent un message d'erreur et un code de sortie non nul.

LICENCE

Les conditions de licence peuvent être affichées en tapant "xrdpwdadmin -H".

NIVEAU DE SUPPORT

La commande xrdpwdadmin est prise en charge par la collaboration xrootd. Les informations de contact se trouvent à l'adresse :
https://xrootd.org/contact.html
