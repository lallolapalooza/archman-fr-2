NOM

xrdsssadmin - administrer les tables de clés à secret partagé simple

SYNOPSIS

xrdsssadmin [options] commande [fichier]

DESCRIPTION

L'utilitaire xrdsssadmin affiche et maintient les tables de clés pour le protocole de sécurité à secret partagé simple (sss). La documentation HTML complète est disponible à l'adresse


https://xrootd.web.cern.ch/doc/dev56/sec_config.htm

NOTES

La documentation pour tous les composants associés à xrdsssadmin se trouve à l'adresse https://xrootd.org/docs.html

DIAGNOSTICS

Les erreurs génèrent un message d'erreur et un statut de sortie non nul.

LICENCE

Les conditions de licence peuvent être affichées en tapant « xrootd -H ».

NIVEAU DE SUPPORT

La commande xrdsssadmin est prise en charge par la collaboration xrootd. Les informations de contact se trouvent à l'adresse
https://xrootd.org/contact.html
