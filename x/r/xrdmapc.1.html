NOM

xrdmapc - interroger le réducteur XRootD (état/abonnés/chemins)

SYNTAXE

xrdmapc [options] hôte:port [chemin]
options: [--help] [--list args] [--quiet] [--verify]

DESCRIPTION

L'utilitaire xrdmapc interroge le réducteur XRootD (état/abonnés/chemins). Le chemin, lorsqu'il est spécifié, utilise <hôte>:<port> pour déterminer les emplacements du chemin et effectue une vérification optionnelle.

OPTIONS

-l | --list [all|m|s]

'all' liste les gestionnaires et les serveurs (par défaut), 'm' liste uniquement les gestionnaires et 's' liste uniquement les serveurs.
-q | --quiet
Ne pas imprimer les messages d'erreur à cerr ; les erreurs apparaissent en ligne.
-r | --refresh
N'utilise pas les informations mises en cache mais rafraîchit le cache.
-v | --verify
Vérifie le statut d'existence du <chemin> sur chaque serveur.

NOTES

La documentation pour tous les composants associés à xrdcp se trouve sur https://xrootd.org/docs.html

DIAGNOSTICS

Les erreurs génèrent un message d'erreur et un statut de sortie non nul.
