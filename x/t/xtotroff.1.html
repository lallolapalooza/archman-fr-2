xtotroff(1) Manuel des commandes générales xtotroff(1)

Nom

xtotroff - convertir les métriques de polices X en métriques de polices groff

Synopsis

xtotroff [-d répertoire-destination] [-r résolution] [-s taille-type] map-de-polices
xtotroff --help
xtotroff -v
xtotroff --version

Description

xtotroff utilise map-de-polices pour créer des fichiers de description de polices groff(1) à partir des polices X11. Chaque ligne dans map-de-polices consiste en une série de lignes associant des noms de polices groff et des noms de polices X sous forme de motifs de description de polices logiques X (XLFD), les membres de la paire étant séparés par des espaces et/ou des tabulations. Par exemple, un fichier map-de-polices d'entrée contenant la ligne

TB -adobe-times-bold-r-normal--*-*-*-*-p-*-iso8859-1
associe la XLFD de droite au nom de police groff TB, conventionnellement « Times gras ».

xtotroff ouvre une connexion au serveur X en cours d'exécution pour interroger son catalogue de polices, et échoue s'il ne peut pas. Si nécessaire, les caractères génériques dans les motifs XLFD sont remplis avec les arguments des options -r et -s. Si un nom de police est encore ambigu, xtotroff abandonne. Pour chaque correspondance réussie, xtotroff crée un fichier de description de police groff dans le répertoire de travail courant (ou celui spécifié par l'option -d) nommé d'après chaque police groff, et rapporte la correspondance au flux de sortie standard.

Options

--help affiche un message d'utilisation, tandis que -v et --version affichent les informations de version ; tous quittent ensuite.

-d répertoire-destination
Écrit les descriptions de polices dans répertoire-destination plutôt que dans le répertoire de travail courant.
-r résolution
Définit la résolution pour tous les motifs de polices dans map-de-polices. La valeur est utilisée pour les quanta de mouvement horizontal et vertical. Si non spécifié, une résolution de 75 dpi est supposée.
-s taille-type
Définit la taille de type en points pour tous les motifs de polices dans map-de-polices. Si non spécifié, une taille de 10 points est supposée.

Fichiers

/usr/share/groff/1.23.0/font/FontMap-X11
est le fichier de mappage de polices utilisé pour produire les fichiers de description de polices pré-générés, fournis avec groff, des polices de base X11 correspondant aux 13 polices de base Type 1 pour le niveau PostScript 1.

Bugs

Les seuls encodages de polices pris en charge sont « iso8859-1 » et « adobe-fontspecific ».

Voir aussi

“Conventions de description des polices logiques X ”, par Jim Flowers et Stephen Gildea.

X(7), groff(1), gxditview(1), troff(1), groff_font(5)
