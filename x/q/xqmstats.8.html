NOM

xqmstats - Afficher les statistiques du gestionnaire de quotas XFS depuis /proc

SYNTAXE

/usr/sbin/xqmstats

DESCRIPTION

xqmstat interroge le noyau pour obtenir les statistiques dquot du gestionnaire de quotas XFS. Il affiche :

•
Récupérations
•
Récupérations manquées
•
Doublons de dquot
•
Manques dans le cache
•
Succès dans le cache
•
Demandes de dquot
•
Récupérations par "shake"
•
Récupérations inactives

OPTIONS

Aucune.

VOIR AUSSI

quotastats(1), quota(1).
