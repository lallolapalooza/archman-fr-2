X42-FAT1(1) Commandes utilisateur X42-FAT1(1)

NOM

x42-fat1 - Autotune JACK x42

SYNOPIS

x42-fat1 [ OPTIONS ] [ ID de plugin ou URI ]

DESCRIPTION

x42-fat1 - Autotune JACK

Ceci est une application JACK autonome d'une collection de plugins LV2. Utilisez l'ID -1, -l ou --list pour une liste dédiée des plugins inclus. Par défaut, le premier plugin listé (ID 0) est utilisé.

Liste des plugins disponibles : (ID "Nom" URI)

0
"Autotune (microtonal)" http://gareus.org/oss/lv2/fat1#microtonal
1
"Autotune" http://gareus.org/oss/lv2/fat1
2
"x42-Autotune (scales)" http://gareus.org/oss/lv2/fat1#scales

Utilisation : Tous les éléments de contrôle sont manipulés à la souris :

Clic+Glisser
gauche/bas : diminuer, droite/haut : augmenter la valeur. Maintenez la touche Ctrl enfoncée pour augmenter la sensibilité.
Maj+Clic
réinitialiser à la valeur par défaut
Molette de défilement
haut/bas par 1 étape (ajustement le plus petit possible pour le réglage donné). Un défilement continu rapide augmente la taille du pas.

L'application peut être fermée en envoyant un SIGTERM (CTRL+C) depuis la ligne de commande ou en fermant la fenêtre.

OPTIONS

-h, --help
Afficher cette aide et quitter
-j, --jack-name <nom>
Définir le nom du client JACK (par défaut : nom du plugin)
-G, --nogui
exécuter sans interface graphique, utile pour le contrôle à distance OSC.
-l, --list
Imprimer la liste des plugins disponibles et quitter
-O <port>, --osc <port>
Écouter les messages OSC sur le port UDP donné
-p <idx>:<val>, --port <idx>:<val>
Définir la valeur initiale pour le port de contrôle donné
-P, --portlist
Imprimer la liste des ports de contrôle au démarrage
--osc-doc
Imprimer les commandes OSC disponibles et quitter
-V, --version
Imprimer les informations de version et quitter

Voir aussi : http://gareus.org/oss/lv2/fat1 Site web : http://x42-plugins.com/
