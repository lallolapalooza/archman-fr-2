NOM

x42-meter - Collection de mètres audio JACK

SYNTAXE

x42-meter [ OPTIONS ] [ ID ou URI de plugin ]

DESCRIPTION

x42-meter - Collection de mètres JACK

Ceci est une application autonome JACK d'une collection de plugins LV2. Utilisez l'ID -1, -l ou --list pour obtenir une liste dédiée des plugins inclus. Par défaut, le premier plugin listé (ID 0) est utilisé.

Utilisation : Tous les éléments de contrôle sont manipulés à l'aide de la souris :

Clic+Glisser
gauche/bas : diminuer, droite/haut : augmenter la valeur. Maintenez la touche Ctrl enfoncée pour augmenter la sensibilité.
Maj+Clic
réinitialiser à la valeur par défaut
Molette de défilement
haut/bas par 1 pas (ajustement le plus petit possible pour le réglage donné). Un défilement continu rapide augmente la taille du pas.

L'application peut être fermée en envoyant un SIGTERM (CTRL+C) depuis la ligne de commande ou en fermant la fenêtre.

OPTIONS

-h, --help
Affiche cette aide et quitte
-j, --jack-name <nom>
Définit le nom du client JACK (par défaut : nom du plugin)
-G, --nogui
fonctionne sans interface graphique, utile pour le contrôle à distance OSC.
-l, --list
Affiche la liste des plugins disponibles et quitte
-O <port>, --osc <port>
Écoute les messages OSC sur le port UDP donné
-p <idx>:<val>, --port <idx>:<val>
Définit la valeur initiale pour le port de contrôle donné
-P, --portlist
Affiche la liste des ports de contrôle au démarrage
--osc-doc
Affiche les commandes OSC disponibles et quitte
-V, --version
Affiche les informations de version et quitte
