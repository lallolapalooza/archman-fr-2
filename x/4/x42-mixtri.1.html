X42-MIXTRI(1) Commandes utilisateur X42-MIXTRI(1)

NOM

x42-mixtri - JACK Mixer'n'Trigger

SYNTAXE

x42-mixtri [ OPTIONS ]

DESCRIPTION

x42-mixtri - JACK Mixer'n'Trigger

Ceci est une application JACK autonome du plugin LV2 : "Mixer'n'Trigger".

Utilisation : Tous les éléments de contrôle sont manipulés à la souris :

Clic+Faire Glisser
gauche/bas : diminue la valeur, droite/haut : augmente la valeur. Maintenez la touche Ctrl enfoncée pour augmenter la sensibilité.
Maj+Clic
réinitialise à la valeur par défaut
Molette de défilement
haut/bas par 1 pas (ajustement le plus fin possible pour le paramètre donné). Le défilement continu rapide augmente la taille du pas.

L'application peut être fermée en envoyant un SIGTERM (CTRL+C) dans la ligne de commande ou en fermant la fenêtre.

OPTIONS

-h, --help
Affiche cette aide et quitte
-j, --jack-name <nom>
Définit le nom du client JACK (par défaut : nom du plugin)
-G, --nogui
Exécute sans interface graphique, utile pour le contrôle à distance OSC.
-O <port>, --osc <port>
Écoute les messages OSC sur le port UDP donné
-p <idx>:<val>, --port <idx>:<val>
Définit la valeur initiale pour le port de contrôle donné
-P, --portlist
Affiche la liste des ports de contrôle au démarrage
--osc-doc
Affiche les commandes OSC disponibles et quitte
-V, --version
Affiche les informations de version et quitte

Voir aussi : http://gareus.org/oss/lv2/mixtri#lv2 Site web : http://x42-plugins.com/
