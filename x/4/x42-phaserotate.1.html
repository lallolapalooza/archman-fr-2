X42-PHASEROTATE(1) Commandes utilisateur X42-PHASEROTATE(1)

NOM

x42-phaserotate - Rotation de phase audio JACK x42-phaserotate

SYNTAXE

x42-phaserotate [ OPTIONS ] [ ID de plugin ou URI ]

DESCRIPTION

x42-phaserotate - Rotation de phase JACK

Ceci est une application JACK autonome d'une collection de plugins LV2. Utilisez l'ID -1, -l ou --list pour une liste dédiée des plugins inclus. Par défaut, le premier plugin listé (ID 0) est utilisé.

Liste des plugins disponibles : (ID "Nom" URI)

0
"Phaserotate" http://gareus.org/oss/lv2/phaserotate
1
"Phaserotate Stereo" http://gareus.org/oss/lv2/phaserotate#stereo

Utilisation : Tous les éléments de contrôle sont manipulés à l'aide de la souris :

Clic+Glisser
gauche/bas : diminuer la valeur, droite/haut : augmenter la valeur. Maintenez la touche Ctrl enfoncée pour augmenter la sensibilité.
Maj+Clic
réinitialiser à la valeur par défaut
Molette de la souris
haut/bas par 1 pas (ajustement le plus petit possible pour le paramètre donné). Faire défiler rapidement en continu augmente la taille du pas.

L'application peut être fermée en envoyant un SIGTERM (CTRL+C) dans la ligne de commande ou en fermant la fenêtre.

OPTIONS

-h, --help
Afficher cette aide et quitter
-j, --jack-name <nom>
Définir le nom du client JACK (par défaut : nom du plugin)
-G, --nogui
exécuter sans interface graphique, utile pour le contrôle à distance OSC.
-l, --list
Afficher la liste des plugins disponibles et quitter
-O <port>, --osc <port>
Écouter les messages OSC sur le port UDP donné
-p <idx>:<val>, --port <idx>:<val>
Définir la valeur initiale pour le port de contrôle donné
-P, --portlist
Afficher la liste des ports de contrôle au démarrage
--osc-doc
Afficher les commandes OSC disponibles et quitter
-V, --version
Afficher les informations sur la version et quitter

Voir aussi : http://gareus.org/oss/lv2/phaserotate Site web : http://x42-plugins.com/
