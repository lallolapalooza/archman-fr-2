NOM

x42-tuna - Accordeur d'instruments pour la musique avec JACK

SYNTAXE

x42-tuna [ OPTIONS ] [ Identifiant ou URI de plugin ]

DESCRIPTION

x42-tuna - Accordeur d'instruments pour la musique avec JACK

Ceci est une application JACK autonome d'une collection de plugins LV2. Utilisez l'identifiant -1, -l ou --list pour une liste dédiée des plugins inclus. Par défaut, le premier plugin listé (ID 0) est utilisé.

Liste des plugins disponibles : (ID "Nom" URI)

0
"x42 Instrument Tuner" http://gareus.org/oss/lv2/tuna#one
1
"x42 Instrument Tuner[Spectrum]" http://gareus.org/oss/lv2/tuna#two

Utilisation : Tous les éléments de contrôle sont manipulés à l'aide de la souris :

Cliquer+Glisser
gauche/bas : diminue la valeur, droite/haut : augmente la valeur. Maintenez la touche Ctrl enfoncée pour augmenter la sensibilité.
Maj+Cliquer
réinitialise à la valeur par défaut
Molette de la souris
haut/bas par 1 pas (ajustement le plus fin possible pour le réglage donné). Un défilement continu et rapide augmente la taille du pas.

L'application peut être fermée en envoyant un SIGTERM (CTRL+C) depuis la ligne de commande ou en fermant la fenêtre.

OPTIONS

-h, --help
Affiche cette aide et quitte
-j, --jack-name <nom>
Définit le nom du client JACK (par défaut : nom du plugin)
-G, --nogui
s'exécute sans interface graphique, utile pour le contrôle à distance OSC.
-l, --list
Affiche la liste des plugins disponibles et quitte
-O <port>, --osc <port>
Écoute les messages OSC sur le port UDP donné
-p <idx>:<val>, --port <idx>:<val>
Définit la valeur initiale pour le port de contrôle donné
-P, --portlist
Affiche la liste des ports de contrôle au démarrage
--osc-doc
Affiche les commandes OSC disponibles et quitte
-V, --version
Affiche les informations de version et quitte

Voir aussi : http://gareus.org/oss/lv2/tuna Site web : http://x42-plugins.com/
