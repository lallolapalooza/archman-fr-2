NOM

x42-dpl - Limiteur de crête JACK x42-dpl

SYNTAXE

x42-dpl [ OPTIONS ] [ ID de plugin ou URI ]

DESCRIPTION

x42-dpl - Limiteur de crête JACK

Ceci est une application autonome JACK d'une collection de plugins LV2. Utilisez l'ID -1, -l ou --list pour une liste dédiée des plugins inclus. Par défaut, le premier plugin listé (ID 0) est utilisé.

Liste des plugins disponibles : (ID « Nom » URI)

0
« x42-dpl - Limiteur de crête numérique stéréo » http://gareus.org/oss/lv2/dpl#stereo
1
« x42-dpl - Limiteur de crête numérique mono » http://gareus.org/oss/lv2/dpl#mono

Utilisation : tous les éléments de contrôle sont manipulés à l'aide de la souris :

Clic+Glisser
gauche/bas : diminuer la valeur, droite/haut : augmenter la valeur. Maintenez la touche Ctrl enfoncée pour augmenter la sensibilité.
Maj+Clic
réinitialiser à la valeur par défaut
Molette de la souris
haut/bas par 1 étape (ajustement le plus petit possible pour le paramètre donné). Le défilement continu rapide augmente la taille du pas.

L'application peut être fermée en envoyant un signal SIGTERM (CTRL+C) depuis la ligne de commande ou en fermant la fenêtre.

OPTIONS

-h, --help
Afficher cette aide et quitter
-j, --jack-name <nom>
Définir le nom du client JACK (par défaut : nom du plugin)
-G, --nogui
exécuter sans interface graphique, utile pour le contrôle à distance OSC.
-l, --list
Afficher la liste des plugins disponibles et quitter
-O <port>, --osc <port>
Écouter les messages OSC sur le port UDP donné
-p <idx>:<val>, --port <idx>:<val>
Définir la valeur initiale pour le port de contrôle donné
-P, --portlist
Afficher la liste des ports de contrôle au démarrage
--osc-doc
Afficher les commandes OSC disponibles et quitter
-V, --version
Afficher les informations de version et quitter

Voir aussi : http://gareus.org/oss/lv2/dpl Site web : http://x42-plugins.com/
