NOM

x42-whirl - Le haut-parleur rotatif B Whirl

SYNTAXE

x42-whirl [ OPTIONS ]

DESCRIPTION

x42-whirl - JACK x42 Whirl - Haut-parleur rotatif

Ceci est une application JACK autonome du plugin LV2 : "x42 Whirl - Rotary Speaker".

Utilisation : Tous les éléments de contrôle sont manipulés à la souris :

Cliquer+Glisser
gauche/bas : diminuer la valeur, droite/haut : augmenter la valeur. Maintenez la touche Ctrl enfoncée pour augmenter la sensibilité.
Maj+Cliquer
réinitialiser à la valeur par défaut
Molette
haut/bas par 1 cran (ajustement le plus petit possible pour le réglage donné). Un défilement continu rapide augmente la taille du cran.

L'application peut être fermée en envoyant un SIGTERM (CTRL+C) dans la ligne de commande ou en fermant la fenêtre.

OPTIONS

-h, --help
Afficher cette aide et quitter
-j, --jack-name <nom>
Définir le nom du client JACK (par défaut : nom du plugin)
-G, --nogui
Exécuter sans interface graphique, utile pour le contrôle à distance OSC.
-O <port>, --osc <port>
Écouter les messages OSC sur le port UDP donné
-p <idx>:<val>, --port <idx>:<val>
Définir la valeur initiale pour le port de contrôle donné
-P, --portlist
Afficher la liste des ports de contrôle au démarrage
--osc-doc
Afficher les commandes OSC disponibles et quitter
-V, --version
Afficher les informations de version et quitter

Voir aussi : http://gareus.org/oss/lv2/b_whirl#extended Site web : http://x42-plugins.com/
