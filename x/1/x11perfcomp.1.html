NOM

x11perfcomp - Programme de comparaison des performances du serveur X11

SYNTAXE

x11perfcomp [ -r | -ro ] [ -l fichier_etiquettes ] fichiers

DESCRIPTION

Le programme x11perfcomp fusionne les sorties de plusieurs exécutions de x11perf(1) dans un format tabulaire agréable. Il prend les résultats de chaque fichier, remplit les résultats de tests manquants si nécessaire, et pour chaque test, il affiche le taux d'objets par seconde de chaque serveur. S'il est appelé avec les options -r ou -ro, il affiche les performances relatives de chaque serveur par rapport au premier serveur.

Normalement, x11perfcomp utilise le premier fichier spécifié pour déterminer quels tests spécifiques il doit rapporter. Certains serveurs (pas ceux de DEC :) peuvent échouer à effectuer tous les tests. Dans ce cas, x11perfcomp substitue automatiquement un taux de 0,0 objets/seconde. Étant donné que le premier fichier détermine quels tests rapporter, ce fichier doit contenir un sur-ensemble des tests rapportés dans les autres fichiers, sinon x11perfcomp échouera.

Vous pouvez fournir une liste explicite de tests à rapporter en utilisant le commutateur -l pour spécifier un fichier d'étiquettes. Vous pouvez créer un fichier d'étiquettes en utilisant l'option -label dans x11perf.

OPTIONS

x11perfcomp accepte les options listées ci-dessous :

-r
Spécifie que la sortie doit également inclure les performances relatives du serveur.
-ro
Spécifie que la sortie doit inclure uniquement les performances relatives du serveur.
-l fichier_etiquettes
Spécifie un fichier d'étiquettes à utiliser.

VALEURS PAR DÉFAUT X

Aucune valeur par défaut X n'est utilisée par ce programme.
