NOM

x11-ssh-askpass — une boîte de dialogue de phrase secrète basée sur X11 pour une utilisation avec OpenSSH

SYNTAXE

x11-ssh-askpass [options] [étiquette]

DESCRIPTION

x11-ssh-askpass est une boîte de dialogue de phrase secrète basée sur X11 pour une utilisation avec OpenSSH. Elle est destinée à être appelée par le programme ssh-add(1) et non invoquée directement.

x11-ssh-askpass prend en charge la plupart des arguments de ligne de commande standard de Toolkit, à l'exception de -geometry, -borderwidth, -iconic, -rv, et -title. Voir X(1).

Si un seul argument non-optionnel est fourni sur la ligne de commande, il est affiché dans la boîte de dialogue au lieu de l'étiquette par défaut. Si l'argument contient des caractères de nouvelle ligne ('\n'), chaque ligne de texte est affichée sur une ligne séparée dans la boîte de dialogue.

Les fonctionnalités de x11-ssh-askpass sont les suivantes :

  • Configurable via les mécanismes de ressources X standard /usr/X11R6/lib/X11/app-defaults, ~/.Xdefaults, xrdb(1), etc.
  • Nécessite uniquement des bibliothèques X11 standard (libXt, libX11, libSM, libICE).
  • Peut être configuré pour saisir le clavier et/ou le pointeur (saisit le clavier par défaut, pas le pointeur).

L'interface utilisateur est quelque peu différente de la plupart des boîtes de dialogue de mot de passe/phrase secrète et plus similaire à la boîte de dialogue de phrase secrète basée sur X11 qui accompagne la distribution SSH régulière. Au lieu d'un champ de texte qui se remplit d'astérisques ou d'un autre caractère à mesure que l'utilisateur saisit la phrase secrète, une série de zones semblables à des LED s'allument une par une à chaque caractère de phrase secrète entré, en commençant par le bord gauche de la boîte de dialogue. Lorsqu'elles atteignent le bord droit, elles s'éteignent une par une à nouveau, et ainsi de suite. Cela donne à l'utilisateur un retour d'information sur les caractères de phrase secrète saisis, mais ne fournit pas aux spectateurs un indice quant à la longueur de la phrase secrète.

Appuyer sur le bouton 'OK' accepte la phrase secrète (même si elle est vide), qui est imprimée sur la sortie standard, et la boîte de dialogue se termine avec un statut de zéro (succès). Appuyer sur le bouton 'Annuler' abandonne la phrase secrète, et la boîte de dialogue se termine avec un statut non nul.

Les frappes suivantes fonctionnent comme prévu :

[Retour arrière]
 
[Suppr]
Effacer le caractère précédent
[Ctrl+U]
 
[Ctrl+X]
Effacer toute la phrase secrète
[Entrée]
 
[Ctrl+M]
 
[Ctrl+J]
Accepter la phrase secrète (OK)
[Échap]
Abandonner la phrase secrète (Annuler)

Les valeurs valides sont les mêmes que pour defaultXResolution.
Valeur par défaut :
“75/in” (75 pixels par pouce).

NAME

x11-ssh-askpass — SSH password and passphrase dialog

SYNOPSIS

x11-ssh-askpass [‑display‑option ...]

DESCRIPTION

This program is intended to be used with the SSH protocol to prompt for a password or passphrase. It is designed to be run from a graphical environment, and will display a dialog box to obtain the necessary information.

When OpenSSH is configured to use an external program to prompt for passphrases (e.g., via the SSH_ASKPASS environment variable), x11-ssh-askpass is a candidate for that program.

The dialog is displayed on the screen specified by the DISPLAY environment variable, or on the screen specified with the ‑display option.

The program reads the prompt string from standard input and writes the user's response to standard output. It then exits with a status of 0 if a response was obtained, or non-zero if the dialog was cancelled or an error occurred.

WIDGETS

The program uses the Athena widget set. The main window consists of a dialog box, a label, a text entry field, and two buttons (OK and Cancel).

RESOURCES

The x11-ssh-askpass program recognizes the following X resources, which can be set in the application defaults file (e.g., /usr/X11R6/lib/X11/app-defaults/SshAskpass) or via the xrdb command.

allowShellOption (class AllowShellOption)
This resource controls whether the ‑iconic command line option is allowed. The default value is true.
bell (class Bell)
This resource controls whether the widget should ring the bell when the user presses Enter in the text field. The default value is true.
cancelLabel (class CancelLabel)
The text to display on the Cancel button. Default: "Cancel".
dialogTitle (class DialogTitle)
The title of the dialog window. Default: "SSH AskPass".
font (class Font)
The font to be used for displaying text within the dialog. Default: fixed.
iconName (class IconName)
The name to be used for the window icon. Default: "ssh-askpass".
labelFont (class LabelFont)
The font to be used for the label widget. Default: font.
okLabel (class OkLabel)
The text to display on the OK button. Default: "OK".
textTranslation (class TextTranslation)
This resource specifies the resolution of text. For example, “20/in” (20 pixels per inch). Default value: “75/in” (75 pixels per inch).
translation (class Translation)
This resource specifies the resolution of text. For example, “20/in” (20 pixels per inch).

The following resources are recognized by the Dialog widget:

title (class Title)
The title of the application as specified to the window manager.
label (class Label)
The label displayed above the led indicators.
font (class Font)
The font to be used to display the label.

The following Resources are recognized by the dialog, button, and indicator widgets and the main widget to customize the 3D appearance (all measurements are in pixels):

foreground (class Foreground)
The foreground color of the widget. This is the text color of the label for buttons and dialog and the color of the active led for the indicator.
background (class Background)
The background color of the widget. In the case of the indicator this is the color of the inactive led.
topShadowColor (class TopShadowColor)
The color used by the sides of the widget exposed to the light (top and left).
bottomShadowColor (class BottomShadowColor)
The color used by the sides of the widget in the shadow (right and bottom).
shadowThickness (class ShadowTickness)
The thickness of the 3D border of the widget.
borderColor (class BorderColor)
The color of the border around the widget.
borderWidth (class BorderWidth)
The width of the border around the widget.
horizontalSpacing (class HorizontalSpacing)
The space to leave on left and right sides of the widget.
verticalSpacing (class VerticalSpacing)
The space to leave on top and bottom sides of the widget.

The following resources are recognized by the indicator widgets:

minimumCount (class MinimumCount)
The minimum number of indicators to display in the dialog.
maximumCount (class MaximumCount)
The maximum number of indicators to display in the dialog.

Each button uses the following resources to customize its label:

label (class Label)
the string to display on the button.
font (class Font)
the font to use for this button label.
