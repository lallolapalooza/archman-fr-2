NOM

x11perf - programme de test de performance de serveur X11

SYNTAXE

x11perf [ -option ... ]

DESCRIPTION

Le programme x11perf exécute un ou plusieurs tests de performance et rapporte la rapidité avec laquelle un serveur X exécute les tests.

De nombreux benchmarks graphiques supposent que le périphérique graphique est utilisé pour afficher la sortie d'une seule application graphique sophistiquée, et que l'utilisateur effectue son travail sur un autre périphérique, comme un terminal. Ces benchmarks mesurent généralement la vitesse de dessin pour les lignes, les polygones, le texte, etc.

Comme les stations de travail ne sont pas utilisées comme des moteurs graphiques autonomes, mais comme des super-terminaux, x11perf mesure la performance de la gestion des fenêtres ainsi que la performance graphique traditionnelle. x11perf inclut des benchmarks pour le temps nécessaire à la création et au mappage des fenêtres (comme lorsque vous lancez une application) ; au mappage d'un ensemble de fenêtres préexistantes à l'écran (comme lorsque vous dés-icônez une application ou ouvrez un menu) ; et à la réorganisation des fenêtres (comme lorsque vous déplacez des fenêtres d'avant en arrière en essayant de trouver celle que vous voulez).

x11perf mesure également la performance graphique pour des opérations normalement utilisées dans les affichages graphiques autonomes, mais qui sont néanmoins fréquemment utilisées par les applications X. Ces opérations incluent CopyPlane (utilisé pour mapper des bitmaps en pixels), le défilement (utilisé dans les fenêtres de texte) et divers stipples et tuiles (utilisés respectivement pour la CAO et le tramage couleur).

x11perf devrait être utilisé pour analyser les forces et faiblesses particulières des serveurs, et est surtout utile à un écrivain de serveurs qui souhaite analyser et améliorer un serveur. x11perf est conçu pour exercer de manière exhaustive pratiquement toutes les opérations X11 que vous pouvez effectuer ; il ne prétend pas être un échantillon représentatif des opérations qu'utilisent réellement les applications X11. Bien qu'il puisse être utilisé comme un benchmark, il a été écrit et est destiné à être un outil de test de performance.

En tant que tel, x11perf NE réduit PAS les mesures à un unique nombre « HeXStones » ou « MeXops ». Nous considérons que de tels nombres sont au mieux peu informatifs et au pire trompeurs. Certains serveurs qui sont très rapides pour certaines applications peuvent être très lents pour d'autres. Aucun nombre unique ou petit ensemble de nombres n'est suffisant pour caractériser les performances d'une implémentation X sur toutes les applications. Cependant, en connaissant votre application préférée, vous pourriez être en mesure d'utiliser les nombres rapportés par x11perf pour prédire ses performances sur une implémentation X donnée.

Cela dit, vous pourriez également vouloir consulter x11perfcomp(1), un programme pour comparer les résultats de différentes exécutions de x11perf. Vous fournissez une liste de fichiers contenant les résultats de x11perf, et il les présente dans un joli format tabulaire.

Pour des résultats reproductibles, x11perf doit être exécuté en utilisant une connexion locale sur un serveur fraîchement démarré. La configuration par défaut exécute chaque test 5 fois, afin de voir si chaque essai prend approximativement le même temps. Des glitchs étranges devraient être examinés ; s'ils ne sont pas reproductibles, on pourrait les attribuer à des démons et au trafic réseau. Chaque essai est exécuté pendant 5 secondes, afin de réduire les différences de temps aléatoires. Le nombre d'objets traités par seconde est affiché à 3 chiffres significatifs, mais vous aurez de la chance sur la plupart des systèmes UNIX si les nombres sont effectivement cohérents à 2 chiffres. x11perf déplace le curseur hors de la fenêtre de test ; vous devez faire attention à ne pas heurter la souris et à ne pas la remettre dans la fenêtre. (Un prix aux personnes qui expliquent correctement pourquoi !!).

Avant d'exécuter un test, x11perf détermine quel est le temps aller-retour vers le serveur, et en déduit le timing final rapporté. Il s'assure que le serveur a réellement effectué le travail demandé en récupérant un pixel de la fenêtre de test, ce qui signifie que les serveurs communiquant avec des accélérateurs graphiques ne peuvent pas prétendre qu'ils ont terminé, pendant que l'accélérateur peint frénétiquement.

Par défaut, x11perf calibre automatiquement le nombre de répétitions de chaque test, de sorte que chacun devrait prendre approximativement la même durée d'exécution sur des serveurs aux vitesses très différentes. Cependant, comme chaque test doit être exécuté jusqu'à sa fin au moins une fois, certains serveurs lents peuvent prendre très longtemps, en particulier pour les tests de déplacement et de redimensionnement de fenêtres, et pour les tests de dessin d'arcs.

Tous les rapports de chronométrage concernent le plus petit objet impliqué. Par exemple, les tests de ligne utilisent une requête PolyLine pour peindre plusieurs lignes à la fois, mais rapportent combien de lignes par seconde le serveur peut peindre, pas combien de requêtes PolyLine par seconde. Les tests de texte peignent une ligne de caractères, mais rapportent le nombre de caractères par seconde. Certains tests de fenêtre mappent, démappent ou déplacent une seule fenêtre parente, mais rapportent combien d'enfants par seconde le serveur peut mapper, démapper ou déplacer.

Le programme actuel est principalement la responsabilité de Joel McCormack. Il est basé sur le x11perf développé par Phil Karlton, Susan Angebranndt, Chris Kent, Mary Walker et Todd Newman, qui voulaient évaluer les différences de performance entre divers serveurs. Plusieurs tests ont été ajoutés pour écrire et régler les serveurs PMAX (DECStation 3100). Pour une version générale pour le monde, x11perf a été réécrit pour faciliter les comparaisons entre machines très différentes, pour couvrir la plupart des fonctionnalités importantes (et non importantes) de X, et pour exercer les opérations graphiques dans autant d'orientations et d'alignements que possible.

OPTIONS

x11perf est basé uniquement sur Xlib et accepte les options listées ci-dessous :

-display hote:dpy
Spécifie quel écran utiliser.
-sync
Exécute les tests en mode synchrone. Normalement utile uniquement pour déboguer x11perf.
-pack
Exécute les tests de rectangles de manière à ce qu'ils empaquent les rectangles juste à côté les uns des autres. Cela facilite le débogage du code serveur pour les stipples et les tuiles... si le motif est laid, vous avez des problèmes d'alignement.
-repeat <n>
Répète chaque test n fois (par défaut, chaque test est exécuté 5 fois).
-time <s>
Spécifie combien de secondes chaque test doit être exécuté (par défaut 5 secondes).
-pause <s>
Spécifie combien de secondes faire une pause entre chaque exécution.
-all
Exécute tous les tests. Cela peut prendre un certain temps.
-range <test1>[,<test2>]
Exécute tous les tests à partir du nom spécifié test1 jusqu'au nom test2, incluant les deux tests spécifiés. Les noms de test doivent être l'une des options commençant par -dot. (par ex.) -range line100 exécutera les tests à partir du test de ligne de 100 pixels, et ira jusqu'au dernier test, -range line100,dline10 fera les tests de line100 à dline10.
-labels
Génère uniquement les étiquettes descriptives pour chaque test spécifié. Voir x11perfcomp pour plus de détails.
-fg couleur-ou-pixel
Spécifie la couleur de premier plan ou la valeur de pixel à utiliser.
-bg couleur-ou-pixel
Spécifie la couleur d'arrière-plan ou la valeur de pixel à utiliser.
-clips défaut
Nombre par défaut de fenêtres de découpage.
-ddbg couleur-ou-pixel
Spécifie la couleur ou la valeur de pixel à utiliser pour dessiner les segments impairs d'une ligne ou d'un arc DoubleDashed. Cela prendra par défaut la couleur bg.
-rop <rop0 rop1 ...>
Utilise les ops raster spécifiés (par défaut GXcopy). Cette option n'affecte que les benchmarks graphiques dans lesquels la fonction graphique est effectivement utilisée.
-pm <pm0 pm1 ...>
Utilise les planemasks spécifiés (par défaut ~0). Cette option n'affecte que les benchmarks graphiques dans lesquels le planemask est effectivement utilisé.
-depth <profondeur>
Utilise une visualisation avec <profondeur> plans par pixel (par défaut, la visualisation par défaut).
-vclass <vclass>
Utilise une visualisation avec

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

-reps <n>
Spécifie le nombre de répétitions (Par défaut, le nombre qui prend environ 5 secondes)
-subs <s0 s1 ...>
Spécifie le nombre de sous-fenêtres à utiliser dans les tests de Fenêtre. La valeur par défaut est 4, 16, 25, 50, 75, 100 et 200.
-v1.2
Exécute uniquement les tests x11perf Version 1.2 en utilisant la sémantique de la Version 1.2.
-v1.3
Exécute uniquement les tests x11perf Version 1.3 en utilisant la sémantique de la Version 1.3.
-v1.4
Exécute uniquement les tests x11perf Version 1.4 en utilisant la sémantique de la Version 1.4.
-v1.5
Exécute uniquement les tests x11perf Version 1.5 en utilisant la sémantique de la Version 1.5.
-v1.6
Exécute uniquement les tests x11perf Version 1.6 en utilisant la sémantique de la Version 1.6.
-v1.7
Exécute uniquement les tests x11perf Version 1.7 en utilisant la sémantique de la Version 1.7.
-version
Affiche la version du programme et quitte.
-su
Définit l'attribut de fenêtre save_under sur True pour toutes les fenêtres créées par x11perf. La valeur par défaut est False.
-bs <backing_store_hint>
Définit l'attribut de fenêtre backing_store à la valeur donnée sur toutes les fenêtres créées par x11perf. <backing_store_hint> peut être WhenMapped ou Always. La valeur par défaut est NotUseful.
-help [options|tests|all]
Affiche les informations sur les options disponibles et quitte. Si aucun argument n'est spécifié, ou si options est spécifié, affiche uniquement les informations sur les options générales, mais n'inclut pas la longue liste d'options pour exécuter des tests spécifiques. Si tests est spécifié, affiche uniquement la longue liste d'options pour exécuter des tests spécifiques. Si all est spécifié, affiche des informations sur les deux ensembles d'options. Si -vversion est également spécifié, la liste des options pour exécuter des tests spécifiques sera limitée aux tests de cette version.

x11perf(1) - x11perf - X Window System performance testing tool

NAME

x11perf - X Window System performance testing tool

SYNTAX

x11perf [ -options ] [ test ... ]

DESCRIPTION

The x11perf program measures the performance of various X Window System operations. It is intended to be used for testing the performance of X servers, graphics drivers, and the X protocol itself.

The program can run a predefined set of tests, or you can specify individual tests to run.

OPTIONS

-move
Déplacer la fenêtre.
-umove
Fenêtre non mappée déplacée.
-movetree
Déplacer la fenêtre via MoveWindow sur le parent.
-resize
Redimensionner la fenêtre.
-uresize
Redimensionner la fenêtre non mappée.
-circulate
Circuler la fenêtre la plus basse vers le haut.
-ucirculate
Circuler la fenêtre non mappée vers le haut.

X PARAMÈTRES PAR DÉFAUT

Il n'y a pas de paramètres par défaut X utilisés par ce programme.
