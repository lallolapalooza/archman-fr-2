NOM

x509 - Gestion des certificats X.509

SYNTAXE

#include <openssl/x509.h>

DESCRIPTION

Un certificat X.509 est un groupement structuré d'informations sur un individu, un appareil, ou tout ce que l'on peut imaginer. Une CRL (liste de révocation de certificats) X.509 est un outil pour aider à déterminer si un certificat est toujours valide. La définition exacte de ceux-ci peut être trouvée dans le document X.509 de l'UIT-T, ou dans le RFC3280 de PKIX. Dans OpenSSL, le type X509 est utilisé pour représenter un tel certificat, et le type X509_CRL pour représenter une CRL.

Une structure apparentée est une demande de certificat, définie dans PKCS#10 de RSA Security, Inc, également reflétée dans le RFC2896. Dans OpenSSL, le type X509_REQ est utilisé pour représenter une telle demande de certificat.

Pour gérer certaines parties complexes d'un certificat, il existe les types X509_NAME (pour représenter un nom de certificat), X509_ATTRIBUTE (pour représenter un attribut de certificat), X509_EXTENSION (pour représenter une extension de certificat) et quelques autres.

Enfin, il y a le supertype X509_INFO, qui peut contenir une CRL, un certificat et la clé privée correspondante.

Les fonctions X509_XXX, d2i_X509_XXX, et i2d_X509_XXX gèrent les certificats X.509, à quelques exceptions près, montrées ci-dessous.

Les fonctions X509_CRL_XXX, d2i_X509_CRL_XXX, et i2d_X509_CRL_XXX gèrent les CRL X.509.

Les fonctions X509_REQ_XXX, d2i_X509_REQ_XXX, et i2d_X509_REQ_XXX gèrent les demandes de certificats PKCS#10.

Les fonctions X509_NAME_XXX gèrent les noms de certificats.

Les fonctions X509_ATTRIBUTE_XXX gèrent les attributs de certificats.

Les fonctions X509_EXTENSION_XXX gèrent les extensions de certificats.
