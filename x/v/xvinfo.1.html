NOM

xvinfo - Afficher les informations de l'adaptateur d'extension X-Video

SYNTAXE

xvinfo [-display nom_affichage]

DESCRIPTION

xvinfo affiche les capacités de tout adaptateur vidéo associé à l'affichage, accessibles via l'extension X-Video.

OPTIONS

-display affichage
Cet argument vous permet de spécifier le serveur à interroger ; voir X(7).
-short
Afficher moins de détails, pour réduire la quantité de texte.
-version
Afficher la version du programme, puis quitter.

ENVIRONNEMENT

DISPLAY
Cette variable peut être utilisée pour spécifier le serveur à interroger.

VOIR AUSSI

X(7), xdpyinfo(1), xwininfo(1), xdriinfo(1), glxinfo(1), xprop(1)
