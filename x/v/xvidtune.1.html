xvidtune(1) Manuel des commandes générales xvidtune(1)

NOM

xvidtune - accordeur de mode vidéo pour Xorg

SYNTAXE

xvidtune [ -show | -prev | -next | -unlock | -timeout sec ] [ option_toolkit ... ]

DESCRIPTION

Xvidtune est une interface client pour l'extension du mode vidéo du serveur X (XFree86-VidModeExtension).

Lorsqu'on lui donne l'une des options autres que celles du toolkit, xvidtune fournit une interface en ligne de commande pour imprimer ou changer le mode vidéo.

Sans aucune option (ou avec seulement des options du toolkit), il présente à l'utilisateur divers boutons et curseurs qui peuvent être utilisés pour ajuster interactivement les modes vidéo existants. Il imprimera également les paramètres dans un format approprié pour être inclus dans un fichier xorg.conf.

Normalement, les serveurs Xorg X ne permettent des modifications avec l'extension XFree86-VidModeExtension que par des clients connectés via un type de connexion local.

Note : Les paramètres du mode d'origine peuvent être restaurés en appuyant sur la touche `R', ce qui peut être utilisé pour restaurer un écran stable dans les situations où l'écran devient illisible.

Les boutons disponibles sont :

Gauche
Droite
Haut
Bas
Ajuste le mode vidéo de manière à déplacer l'affichage dans la direction appropriée.
PlusLarge
PlusEtroit
PlusCourt
PlusGrand
Ajuste le mode vidéo de manière à modifier la taille de l'affichage en conséquence.
Quitter
Quitte le programme.
Appliquer
Applique le mode vidéo actuel aux paramètres sélectionnés.
Auto
Applique immédiatement les boutons Haut/Bas/Droite/Gauche, PlusLarge/PlusEtroit/PlusCourt/PlusGrand, Restaurer, et les boutons spéciaux S3. Ce bouton peut être activé/désactivé.
Tester
Commute temporairement vers les paramètres sélectionnés.
Restaurer
Restaure les paramètres à leurs valeurs d'origine.
Recuperer
Interroge le serveur pour connaître ses paramètres actuels.
Afficher
Imprime les paramètres actuellement sélectionnés sur stdout au format "Modeline" de xorg.conf. La sélection principale est également définie.
Suivant
Commute le Xserver vers le mode vidéo suivant.
Precedent
Commute le Xserver vers le mode vidéo précédent.

Pour certaines cartes basées sur S3 (964 et 968), les options suivantes sont également disponibles :

InverserVCLK
Change l'état d'inversion/non-inversion du VCLK.
DebutSC
Change l'état de début SC. Ceci affecte le défilement de l'écran.
RetardBlanc1
RetardBlanc2
Définit les valeurs de délai de blanc. Ceci affecte le défilement de l'écran. Les valeurs acceptables sont comprises entre 0 et 7. Les valeurs peuvent être incrémentées ou décrémentées avec les boutons `+' et `-' , ou en appuyant sur les touches `+' ou `-' dans le champ de texte.

Pour les cartes basées sur S3-864/868, InverserVCLK et RetardBlanc1 peuvent être utiles. Pour les cartes S3 Trio32/Trio64 seule InverserVCLK est disponible. Pour le moment, il n'y a pas de paramètres par défaut disponibles pour ces puces dans l'extension du mode vidéo et donc cette fonctionnalité est désactivée dans xvidtune. Elle peut être activée en définissant l'une des commandes S3 optionnelles dans la section screen de xorg.conf, par exemple en utilisant

retard_blanc "∗" 0

OPTIONS

xvidtune accepte les options de ligne de commande standard du X Toolkit ainsi que les suivantes :

-show
Imprime les paramètres actuels sur stdout au format "Modeline" de xorg.conf et quitte.
-prev
Commute le Xserver vers le mode vidéo précédent.
-next
Commute le Xserver vers le mode vidéo suivant.
-unlock
Normalement, xvidtune désactive le changement de modes vidéo via les raccourcis clavier pendant son exécution. Si pour une raison quelconque le programme ne s'est pas terminé proprement et qu'ils sont toujours désactivés, le programme peut être relancé avec cette option pour réactiver les combinaisons de touches de changement de mode.
-timeout sec
Définit le délai du mode test en secondes.

VOIR AUSSI

xrandr(1), Xorg(1), xorg.conf(5).

AUTEURS

BOGUES

La gestion des erreurs X, c'est-à-dire lorsque le serveur ne permet pas aux clients xvidtune d'écrire de nouveaux modes, pourrait être meilleure.
