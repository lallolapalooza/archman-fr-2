ADDR2LINE(1) Outils de développement GNU ADDR2LINE(1)

NOM

addr2line - convertir les adresses ou le symbole+décalage en noms de fichiers et numéros de lignes

SYNTAXE

addr2line [-a|--addresses]
[-b bfdname|--target=bfdname]
[-C|--demangle[=style]]
[-r|--no-recurse-limit]
[-R|--recurse-limit]
[-e nomfichier|--exe=nomfichier]
[-f|--functions] [-s|--basename]
[-i|--inlines]
[-p|--pretty-print]
[-j|--section=nom]
[-H|--help] [-V|--version]
[adresse adresse ...]

DESCRIPTION

addr2line traduit les adresses ou le symbole+décalage en noms de fichiers et numéros de lignes. Étant donné une adresse ou un symbole+décalage dans un exécutable ou un décalage dans une section d'un objet relocable, il utilise les informations de débogage pour déterminer le nom de fichier et le numéro de ligne qui y sont associés.

L'exécutable ou l'objet relocable à utiliser est spécifié avec l'option -e. Le fichier par défaut est a.out. La section de l'objet relocable à utiliser est spécifiée avec l'option -j.

addr2line a deux modes de fonctionnement.

Dans le premier, des adresses hexadécimales ou symbole+décalage sont spécifiées sur la ligne de commande, et addr2line affiche le nom du fichier et le numéro de ligne pour chaque adresse.

Dans le second, addr2line lit des adresses hexadécimales ou symbole+décalage depuis l'entrée standard, et imprime le nom du fichier et le numéro de ligne pour chaque adresse sur la sortie standard. Dans ce mode, addr2line peut être utilisé dans un pipe pour convertir des adresses choisies dynamiquement.

Le format de la sortie est NOMFICHIER:NUMERO_LIGNE. Par défaut, chaque adresse d'entrée génère une ligne de sortie.

Deux options peuvent générer des lignes supplémentaires avant chaque ligne NOMFICHIER:NUMERO_LIGNE (dans cet ordre).

Si l'option -a est utilisée, alors une ligne avec l'adresse d'entrée est affichée.

Si l'option -f est utilisée, alors une ligne avec le NOMFONCTION est affichée. C'est le nom de la fonction contenant l'adresse.

Une option peut générer des lignes supplémentaires après la ligne NOMFICHIER:NUMERO_LIGNE.

Si l'option -i est utilisée et que le code à l'adresse donnée est présent en raison de l'inlining par le compilateur, des lignes supplémentaires sont affichées ensuite. Une ou deux lignes supplémentaires (si l'option -f est utilisée) sont affichées pour chaque fonction inlinée.

Alternativement, si l'option -p est utilisée, chaque adresse d'entrée génère une seule longue ligne de sortie contenant l'adresse, le nom de la fonction, le nom du fichier et le numéro de ligne. Si l'option -i a également été utilisée, les fonctions inlinées seront affichées de la même manière, mais sur des lignes séparées, et précédées du texte (inlined by).

Si le nom de fichier ou le nom de fonction ne peuvent pas être déterminés, addr2line imprimera deux points d'interrogation à leur place. Si le numéro de ligne ne peut pas être déterminé, addr2line imprimera 0.

Lorsqu'un symbole+décalage est utilisé, +décalage est facultatif, sauf lorsque le symbole est ambigu avec un nombre hexadécimal. Les symboles résolus peuvent être manglés ou non manglés, sauf que les symboles non manglés avec + ne sont pas autorisés.

OPTIONS

Les formes longues et courtes des options, présentées ici comme alternatives, sont équivalentes.

-a
--addresses
Affiche l'adresse avant le nom de la fonction, le nom du fichier et les informations de ligne. L'adresse est imprimée avec un préfixe 0x pour l'identifier facilement.
-b nombfd
--target=nombfd
Spécifie que le format du code objet pour les fichiers objets est nombfd.
-C
--demangle[=style]
Décode (demangle) les noms de symboles de bas niveau en noms de niveau utilisateur. En plus de supprimer l'underscore initial ajouté par le système, cela rend les noms de fonctions C++ lisibles. Différents compilateurs ont différents styles de mangling. L'argument facultatif de style de déchiffrage peut être utilisé pour choisir un style de déchiffrage approprié pour votre compilateur.
-e nomfichier
--exe=nomfichier
Spécifie le nom de l'exécutable pour lequel les adresses doivent être traduites. Le fichier par défaut est a.out.
-f
--functions
Affiche les noms des fonctions ainsi que le nom du fichier et les informations de ligne.
-s
--basenames
Affiche uniquement la partie base de chaque nom de fichier.
-i
--inlines
Si l'adresse appartient à une fonction qui a été inlinée, les informations source pour tous les scopes englobants jusqu'à la première fonction non inlinée seront également imprimées. Par exemple, si "main" inliné "callee1" qui inliné "callee2", et que l'adresse provient de "callee2", les informations source pour "callee1" et "main" seront également imprimées.
-j
--section
Lit les décalages relatifs à la section spécifiée au lieu des adresses absolues.
-p
--pretty-print
Rend la sortie plus lisible par l'homme : chaque emplacement est imprimé sur une ligne. Si l'option -i est spécifiée, les lignes pour tous les scopes englobants sont préfixées par (inlined by).
-r
-R
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Active ou désactive une limite sur la quantité de récursion effectuée lors du déchiffrage des chaînes. Étant donné que les formats de mangling de noms permettent un niveau infini de récursion, il est possible de créer des chaînes dont le décodage épuisera l'espace de pile disponible sur la machine hôte, déclenchant une faute de mémoire. La limite essaie d'éviter cela en restreignant la récursion à 2048 niveaux d'imbrication.

Par défaut, cette limite est activée, mais sa désactivation peut être nécessaire pour déchiffrer des noms vraiment compliqués. Notez cependant que si la limite de récursion est désactivée, un épuisement de la pile est possible et tout rapport de bogue concernant un tel événement sera rejeté.

L'option -r est un synonyme de l'option --no-recurse-limit. L'option -R est un synonyme de l'option --recurse-limit.

Notez que cette option n'est efficace que si l'option -C ou --demangle a été activée.

@fichier
Lit les options de la ligne de commande à partir de fichier. Les options lues sont insérées à la place de l'option @fichier d'origine. Si fichier n'existe pas ou ne peut pas être lu, alors l'option sera traitée littéralement et ne sera pas supprimée.

Les options dans fichier sont séparées par des espaces blancs. Un caractère d'espace blanc peut être inclus dans une option en entourant l'option entière entre guillemets simples ou doubles. N'importe quel caractère (y compris un antislash) peut être inclus en faisant précéder le caractère à inclure d'un antislash. Le fichier peut lui-même contenir d'autres options @fichier ; toutes ces options seront traitées récursivement.

addr2line(1) - archlinux.org

NOM

addr2line - convertir les adresses en noms de fichiers et numéros de ligne.

SYNTAXE

addr2line [OPTIONS]... [ADRESSE]...

DESCRIPTION

addr2line convertit les adresses de code en noms de fichiers et numéros de ligne, et vice-versa. Il lit une liste d'adresses à partir de l'entrée standard ou des arguments de ligne de commande, et il écrit les noms de fichiers et numéros de ligne correspondants à la sortie standard.

Ceci est utile pour déboguer les programmes qui ont planté. Par exemple, si un programme plante et produit un message d'erreur contenant des adresses de code, vous pouvez utiliser addr2line pour trouver les noms de fichiers et numéros de ligne correspondants, ce qui vous aidera à identifier la source du problème.

OPTIONS

/
Affiche un message d'aide.
-a, --addresses
Affiche les adresses en plus des noms de fichiers et numéros de ligne.
-e fichier_executable
Spécifie le fichier exécutable à utiliser pour la recherche des symboles et des informations de débogage. Si cette option n'est pas spécifiée, addr2line utilisera le fichier exécutable par défaut (généralement a.out).
-i, --inlines
Affiche les informations sur les fonctions dans lesquelles l'adresse est en ligne, en plus des informations sur la fonction principale.
-p, --pretty-print
Affiche les noms de fichiers et numéros de ligne de manière plus lisible.
-r, --read-chunks
Lit les adresses par blocs. Ceci est utile lorsque vous travaillez avec de grands fichiers exécutables.
-s, --string
Affiche les adresses sous forme de chaînes de caractères.
-v, --version
Affiche les informations de version de addr2line.

EXEMPLE

Supposons que votre programme ait planté et que vous ayez les adresses suivantes dans le message d'erreur :

  0x08048450
  0x0804847c

Pour trouver les noms de fichiers et numéros de ligne correspondants, vous pouvez utiliser la commande suivante :

  addr2line -e mon_programme 0x08048450 0x0804847c

Cela produira une sortie similaire à celle-ci :

  /home/utilisateur/projet/main.c:15
  /home/utilisateur/projet/utils.c:32

Vous pouvez également lire les adresses à partir de l'entrée standard :

  echo "0x08048450
  0x0804847c" | addr2line -e mon_programme

Si vous souhaitez également afficher les adresses, utilisez l'option -a :

  addr2line -a -e mon_programme 0x08048450 0x0804847c

La sortie sera alors :

  0x08048450:
  /home/utilisateur/projet/main.c:15
  0x0804847c:
  /home/utilisateur/projet/utils.c:32

Si l'adresse correspond à une fonction dans laquelle une autre fonction est en ligne, l'option -i affichera les deux :

  addr2line -i -e mon_programme 0x08048450

La sortie pourrait ressembler à ceci :

  /home/utilisateur/projet/main.c:15
  in foo at /home/utilisateur/projet/main.c:10

Cela indique que l'adresse 0x08048450 se trouve dans le fichier main.c à la ligne 15, qui est une fonction nommée foo, et que cette ligne est elle-même en ligne à partir de la ligne 10 du même fichier.
