NOM

xosd_uninit - Détruit une fenêtre XOSD

SYNOPSIS

#include <xosd.h>

int xosd_uninit (xosd* osd);

DESCRIPTION

xosd_uninit détruit une fenêtre xosd existante, libérant la mémoire.

ARGUMENTS

osd
L'objet d'affichage à l'écran sur lequel agir.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné.

VOIR AUSSI
