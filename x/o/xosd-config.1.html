NOM

xosd-config - script pour obtenir des informations sur la version installée de libxosd

SYNOPSIS

xosd-config [--prefix[=DIR]] [--exec-prefix[=DIR]] [--version] [--libs] [--cflags]

DESCRIPTION

xosd-config est un outil utilisé pour configurer et déterminer les indicateurs du compilateur et de l'éditeur de liens qui devraient être utilisés pour compiler et lier les programmes utilisant libxosd. Il est également utilisé en interne par les macros .m4 pour GNU autoconf qui sont incluses avec libxosd.

OPTIONS

xosd-config accepte les options suivantes :

--version
Affiche la version actuellement installée de libxosd sur la sortie standard.
--libs
Affiche les indicateurs de l'éditeur de liens qui sont nécessaires pour lier un programme libxosd.
--cflags
Affiche les indicateurs du compilateur qui sont nécessaires pour compiler un programme libxosd.
--prefix=PREFIX
Si spécifié, utilise PREFIX au lieu du préfixe d'installation avec lequel libxosd a été construit lors du calcul de la sortie pour les options --cflags et --libs. Cette option est également utilisée pour le préfixe d'exécution si --exec-prefix n'a pas été spécifié. Cette option doit être spécifiée avant toute option --libs ou --cflags.
--exec-prefix=PREFIX
Si spécifié, utilise PREFIX au lieu du préfixe d'exécution d'installation avec lequel libxosd a été construit lors du calcul de la sortie pour les options --cflags et --libs. Cette option doit être spécifiée avant toute option --libs ou --cflags.
