NOM

xosd_is_onscreen - Retourne si la fenêtre XOSD est affichée

SYNTAXE

#include <xosd.h>

xosd *xosd_is_onscreen (xosd *osd);

DESCRIPTION

osd_is_onscreen détermine si une fenêtre XOSD est actuellement affichée (est mappée sur l'affichage X). Comme XOSD affiche les données de manière asynchrone (voir xosd_display(3) pour plus de détails), il peut être difficile de savoir si des données sont affichées. xosd_is_onscreen résout ce problème.

Appelez xosd_show(3) ou xosd_hide(3) pour modifier la visibilité de la fenêtre XOSD.

ARGUMENTS

osd
La fenêtre XOSD à interroger.

VALEUR DE RETOUR

Un 1 est retourné si la fenêtre est affichée (mappée), ou 0 si elle est cachée (non mappée). En cas d'erreur, -1 est retourné et xosd_error est défini pour indiquer la raison de l'erreur.

ENVIRONNEMENT

char *xosd_error
Une chaîne de caractères décrivant l'erreur, si une s'est produite.

HISTORIQUE

La fonction xosd_is_onscreen est apparue pour la première fois dans la version 2.1 de la bibliothèque XOSD.

AUTEURS

La bibliothèque XOSD a été écrite à l'origine par André Renaud et est actuellement maintenue par Tim Wright, qui a également écrit la fonction xosd_is_onscreen. BOGUES

Il n'y a pas de bogues connus avec xosd_is_onscreen. Les rapports de bogues peuvent être envoyés à <xosd@ignavus.net>.

VOIR AUSSI
