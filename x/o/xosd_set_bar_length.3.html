XOSD_SET_BAR_LENGTH(3) XOSD_SET_BAR_LENGTH(3)

NOM

xosd_set_bar_length - Changer la longueur de la barre de pourcentage ou du curseur

SYNOPSIS

#include <xosd.h>

int xosd_set_bar_length (xosd *osd, int displayPercentage);

DESCRIPTION

xosd_set_bar_length change le pourcentage de l'affichage utilisé par un curseur ou une barre de pourcentage. Normalement, XOSD choisit une longueur raisonnable pour la barre, mais vous pourriez vouloir changer le comportement par défaut s'il n'y a qu'un petit nombre de valeurs possibles à afficher.

ARGUMENTS

osd
La fenêtre XOSD à modifier.
displayPercentage
Le pourcentage de l'affichage à utiliser par le curseur ou la barre de pourcentage, sous forme d'un entier entre 0 et 100. Définir displayPercentage à -1 rétablit le comportement par défaut.

VALEUR DE RETOUR

En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné et xosd_error est défini pour indiquer la raison de l'erreur.

ENVIRONNEMENT

char *xosd_error
Une chaîne décrivant l'erreur, si une s'est produite.

BOGUES

Il n'y a pas de bogues connus avec xosd_set_bar_length. Les rapports de bogues peuvent être envoyés à <xosd@ignavus.net>.
