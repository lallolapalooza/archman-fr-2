NOM

xosd_create - Créer un nouvel objet XOSD

SYNOPSIS

#include <xosd.h>

xosd *xosd_create (int nombre_lignes);

DESCRIPTION

xosd_init crée une nouvelle fenêtre xosd qui peut être utilisée pour afficher des données textuelles ou numériques sur un écran X11 dans une fenêtre non gérée et façonnée, qui semble transparente. Elle offre un effet similaire à l'affichage à l'écran de nombreux téléviseurs et magnétoscopes.

ARGUMENTS

nombre_lignes
Le nombre maximum de lignes de texte que la fenêtre peut afficher. Cette valeur ne peut pas être modifiée.

VALEUR DE RETOUR

En cas de succès, un pointeur vers un nouvel objet xosd est retourné, sinon NULL est retourné.

ENVIRONNEMENT

DISPLAY
La variable d'environnement qui détermine sur quel écran X11 la fenêtre XOSD apparaît.
char *xosd_error
Une chaîne de caractères décrivant l'erreur.

HISTORIQUE

La fonction xosd_create est apparue pour la première fois dans la version 2.0 de la bibliothèque XOSD, remplaçant la fonction maintenant obsolète xosd_init.

AUTEURS

La bibliothèque XOSD a été initialement écrite par André Renaud, et est actuellement maintenue par Tim Wright. Ce document a été écrit par Michael JasonSmith.

BOGUES

Il n'y a pas de bogues connus avec xosd_create. Les rapports de bogues peuvent être envoyés à <xosd@ignavus.net>.
