Paquet: xosd

XOSD_DISPLAY(3) XOSD_DISPLAY(3)

NOM

xosd_display - Affiche des données dans une fenêtre XOSD

SYNTAXE

#include <xosd.h>

int xosd_display (xosd *osd, int line, xosd_command command, ...);

DESCRIPTION

xosd_display affiche une chaîne de caractères, une barre de pourcentage (comme une barre de progression) ou un curseur sur un écran X. Les données sont affichées dans une fenêtre sans bordure, de forme spéciale, de sorte qu'elles semblent flotter au-dessus des autres fenêtres, comme les affichages à l'écran que l'on trouve dans de nombreux téléviseurs. Les utilisateurs ne peuvent pas interagir avec l'affichage de quelque manière que ce soit.

Les données sont affichées jusqu'à ce que la limite de temps, définie en appelant xosd_set_timeout(3), soit atteinte, mais xosd_display retourne immédiatement. Si un blocage est nécessaire, il faut appeler xosd_wait_until_no_display(3) après xosd_display. Une fenêtre qui affiche des données peut être cachée en appelant xosd_hide(3).

Le type de données affiché est déterminé par l'argument command. Il existe deux types de données qui peuvent être affichées : du texte ou des entiers.

Affichage de données textuelles

Le texte est normalement affiché en passant XOSD_string comme argument à command, suivi d'une chaîne de caractères au format UTF-8. Si du texte formaté est désiré, passez XOSD_printf comme argument à command, suivi d'une chaîne de caractères ayant le même format que printf(3), et autant d'arguments supplémentaires que nécessaire par la chaîne de format.

Affichage de valeurs entières

Les valeurs entières (qui doivent être comprises entre 0 et 100) peuvent être affichées de deux manières : une barre de pourcentage ou un curseur. Une barre de pourcentage ressemble à un affichage de volume sur un téléviseur, et est créée en passant XOSD_percentage comme argument à command. Un curseur (voir le plugin XOSD pour xmms(1) pour un exemple) est créé en passant XOSD_slider comme argument à command. Un int entre 0 et 100 est attendu comme dernier argument lorsque XOSD_percentage ou XOSD_slider est passé comme argument à command.

ARGUMENTS

osd
La fenêtre XOSD à utiliser comme affichage.
line
La ligne de l'affichage à modifier. La valeur de line doit être inférieure à number_lines, définie dans l'appel à xosd_create(3).
command
L'un des éléments suivants : XOSD_percentage, XOSD_slider ou XOSD_string. Si la valeur de command est XOSD_string, alors l'argument suivant doit être une chaîne de caractères au format UTF-8. Si XOSD_percentage ou XOSD_slider est donné, alors un int entre 1 et 100 est attendu comme argument suivant.

VALEUR DE RETOUR

Si la commande est soit XOSD_percentage soit XOSD_slider, alors la valeur entière de la barre ou du curseur est renvoyée (entre 1 et 100). Pour XOSD_string et XOSD_printf, le nombre de caractères écrits sur l'affichage est renvoyé.

En cas d'erreur, -1 est renvoyé et xosd_error est défini pour indiquer la raison de l'erreur.

ENVIRONNEMENT

char *xosd_error
Une chaîne de caractères décrivant l'erreur, si une s'est produite.
enum xosd_command
Le type d'informations qui peuvent être affichées, défini comme un type énuméré. Quatre valeurs sont définies : XOSD_percentage, XOSD_string, XOSD_printf, et XOSD_slider.

AUTEURS

BOGUES

Il n'y a pas de bogues connus avec xosd_display. Les rapports de bogues peuvent être envoyés à <xosd@ignavus.net>.
