XAPIAN-REPLICATE(1) Commandes utilisateur XAPIAN-REPLICATE(1)

NOM

xapian-replicate - Réplique une base de données à partir d'un serveur maître vers une copie locale

SYNTAXE

xapian-replicate [OPTIONS] BASE_DE_DONNÉES

DESCRIPTION

xapian-replicate - Réplique une base de données à partir d'un serveur maître vers une copie locale

OPTIONS

-h, --host=HOTE
hôte auquel se connecter (requis)
-p, --port=PORT
port auquel se connecter (requis)
-m, --master=DB
répliquer la base de données DB depuis le maître (par défaut : BASE_DE_DONNÉES)
-i, --interval=N
attendre N secondes entre chaque connexion au maître (par défaut : 60)
-r, --reader-time=N attendre N secondes pour laisser le temps aux lecteurs de se fermer avant d'appliquer les ensembles de modifications répétés.
par défaut : 30)
-t, --timeout=N
définir les timeouts de socket (si supporté) à N secondes ; N=0 pour aucun timeout (par défaut : 0)
-f, --force-copy
forcer l'envoi d'une copie complète de la base de données (puis répliquer normalement)
-o, --one-shot
répliquer une seule fois et quitter
-q, --quiet
ne signaler que les erreurs
-v, --verbose
être plus verbeux
--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter
