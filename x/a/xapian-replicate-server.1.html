XAPIAN-REPLICATE-SERVER(1) Commandes utilisateur XAPIAN-REPLICATE-SERVER(1)

NOM

xapian-replicate-server - Servir les requêtes de réplication de base de données des clients

SYNTAXE

xapian-replicate-server [OPTIONS] RÉPERTOIRE_PARENT_BASE_DE_DONNÉES

DESCRIPTION

xapian-replicate-server - Servir les requêtes de réplication de base de données des clients

OPTIONS

-I, --interface=ADRESSE
écouter sur l'interface ADRESSE
-p, --port=PORT
port d'écoute
-o, --one-shot
servir une seule connexion et quitter
--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter
