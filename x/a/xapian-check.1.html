NOM

xapian-check - Vérifier la cohérence d'une base de données ou d'une table

SYNOPSIS

xapian-check RÉPERTOIRE_BASE_DE_DONNÉES|CHEMIN_VERS_BTREE [[F][t][f][b][v][+]]

DESCRIPTION

xapian-check - Vérifier la cohérence d'une base de données ou d'une table

Si une base de données entière est vérifiée, des vérifications croisées supplémentaires entre les tables sont effectuées.

L(es) btree(s) est/sont toujours vérifié(s) - contrôler la verbosité de la sortie avec :

F = tenter de réparer une base de données corrompue (implémenté pour chert actuellement) t = affichage court de l'arbre f = affichage complet de l'arbre b = afficher les blocs libres v = afficher les statistiques sur l'arbre B (par défaut) + = identique à tbv par ex. xapian-check /var/lib/xapian/data/default
xapian-check /var/lib/xapian/data/default/postlist fbv
