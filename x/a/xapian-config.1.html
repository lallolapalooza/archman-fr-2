XAPIAN-CONFIG(1) Commandes utilisateur XAPIAN-CONFIG(1)

NOM

xapian-config - signaler des informations sur la version installée de xapian

SYNTAXE

xapian-config OPTION...

DESCRIPTION

xapian-config - signaler des informations sur la version installée de xapian

OPTIONS

--cxxflags
afficher toutes les options du préprocesseur et du compilateur C++
--libs
afficher toutes les options de l'éditeur de liens
--ltlibs
afficher les options de l'éditeur de liens pour une liaison utilisant GNU libtool
--static
faire en sorte que les autres options rapportent les valeurs pour la liaison statique
--swigflags
afficher les options du préprocesseur à utiliser avec SWIG
--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter

SIGNALER LES BOGUES

Signaler les bogues à https://xapian.org/bugs.
