XADUMP(1) Manuel des commandes générales XADUMP(1)

NOM

xadump - accès de bas niveau à un index Xapian de Recoll.

SYNTAXE

xadump [ -d <dbdir> ] [ -e <outputencoding> ] -i <docid> -D
xadump [ -d <dbdir> ] [ -e <outputencoding> ] -i <docid> -X
xadump [ -d <dbdir> ] [ -e <outputencoding> ] -i <docid> [ -x ] -T
xadump [ -d <dbdir> ] [ -e <outputencoding> ] -i <docid> [ -x ] -r

xadump [ -d <dbdir> ] [ -e <outputencoding> ] -t <term> -E
xadump [ -d <dbdir> ] [ -e <outputencoding> ] -t <term> -F
xadump [ -d <dbdir> ] [ -e <outputencoding> ] -t <term> -P

xadump -T [ -f ] [ -n ] [ -l ]

xadump -q terme [terme ...]

DESCRIPTION

La commande xadump est un outil d'accès et de diagnostic de bas niveau pour un index Xapian tel qu'organisé par l'indexeur Recoll. Le répertoire de l'index à utiliser est spécifié avec l'option -d.

Les options -D, -X, -T et -r prennent un seul argument docid spécifié avec l'option -i. -D affiche l'enregistrement des données du document. -X supprime toutes les données d'index pour le document. -T imprime la liste des termes pour le document. Sans argument docid, cette option listera la liste entière des termes de l'index. -f peut être activé pour précéder chaque terme de son compte d'occurrences (uniquement si aucun docid n'est spécifié). -n peut être activé pour omettre les crochets englobants. -l peut être activé pour sauter les termes préfixés. -r imprime le texte du document tel que reconstruit à partir des données d'index.

Lorsque l'option -x est activée, les termes sont imprimés avec chaque caractère séparé par un espace, ce qui peut être utile pour vérifier certains problèmes d'encodage.

Les options -E, -F et -P nécessitent toutes un argument de terme, spécifié avec -t <term>. -E effectue un test d'existence de terme. -F récupère la fréquence du terme pour le terme donné. -P affiche les postings pour le terme donné.

Avec l'option -q, xadump effectue une requête ET simple sur l'index, en utilisant les arguments de terme donnés.
