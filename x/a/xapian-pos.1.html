XAPIAN-POS(1) Commandes utilisateur XAPIAN-POS(1)

NOM

xapian-pos - Débogue les données positionnelles dans une base de données Xapian

SYNTAXE

xapian-pos [OPTIONS] BASE_DE_DONNÉES

DESCRIPTION

xapian-pos - Débogue les données positionnelles dans une base de données Xapian

OPTIONS

-d, --doc=ID_DOC
affiche les positions pour le document ID_DOC
-s, --start=POS
spécifie la première position à afficher
-e, --end=POS
spécifie la dernière position à afficher
--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte
