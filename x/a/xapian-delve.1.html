DELVE(1) Commandes utilisateur DELVE(1)

NOM

delve - Inspecter le contenu d'une base de données Xapian

SYNTAXE

delve [OPTIONS] BASE...

DESCRIPTION

delve - Inspecter le contenu d'une base de données Xapian

OPTIONS

-a
afficher tous les termes de la base de données
-A <prefix>
afficher tous les termes de la base de données avec le préfixe donné
-r <numrec>
pour la/les liste(s) de termes
-t <terme>
pour la/les liste(s) de postings
-t <terme> -r <numrec>
pour la/les liste(s) de positions
-s, --stemmer=LANG
définir la langue de lemmatisation, la valeur par défaut est 'none'
-1
afficher une entrée de liste par ligne
-V[<type>]<numval>
afficher la valeur <numval> pour chaque document référencé (ou chaque document de la base de données si aucune option -r n'est spécifiée). <type> peut être : E : échapper de manière similaire à C (par défaut) I : décoder comme un entier compacté R : afficher la valeur brute (qui peut contenir des données binaires,
nouvelles lignes, UTF-8 invalide, etc)
S : décoder en utilisant Xapian::sortable_unserialise()
-V[<type>]
afficher toutes les valeurs pour chaque document référencé. <type> est comme ci-dessus.
-d
afficher les données du document pour chaque document référencé
-z
pour la base de données, compter les documents de longueur 0
-v
informations supplémentaires (wdf et len pour la liste de postings ; wdf et termfreq pour la liste de termes ; nombre de termes pour la base de données ; termfreq lors de l'affichage de tous les termes ; bornes de valeur et fréquence lors de l'affichage de toutes les valeurs dans un champ)
-vv
encore plus d'informations (afficher également la fréquence de collection et la borne supérieure wdf pour les termes)
--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter
