NOM

asy - langage de graphisme vectoriel basé sur des scripts

SYNTAXE

xasy [-x magnification] [nom_fichier]

DESCRIPTION

Asymptote est un langage de graphisme vectoriel descriptif puissant pour le dessin technique, inspiré par MetaPost mais avec une syntaxe améliorée similaire à C++. Asymptote offre aux figures le même niveau de composition typographique de haute qualité que LaTeX offre au texte scientifique.

xasy est une interface graphique pour Asymptote qui permet des ajustements finaux des figures.

OPTIONS

-x magnification
Zoom initial.

VOIR AUSSI

Asymptote et xasy sont documentés en détail dans la page d'information Asymptote.

AUTEUR
