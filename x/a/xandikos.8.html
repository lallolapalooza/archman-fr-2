NOM

xandikos - serveur CalDAV/CardDAV basé sur git

DESCRIPTION

utilisation : ./bin/xandikos -d REPERTOIRE_RACINE [OPTIONS]

arguments optionnels :

-h, --help
afficher ce message d'aide et quitter
--version
afficher le numéro de version du programme et quitter
-d REPERTOIRE, --directory REPERTOIRE
Répertoire à servir.
--current-user-principal PRINCIPAL_UTILISATEUR_COURANT
Chemin vers le principal de l'utilisateur courant. [/user/]
--autocreate
Créer automatiquement les répertoires nécessaires.
--defaults
Créer un calendrier et un carnet d'adresses initiaux. Implique --autocreate.
--dump-dav-xml
Afficher les requêtes/réponses DAV XML.
--avahi
Annoncer les services avec avahi.
--no-strict
Activer les solutions de contournement pour les implémentations de clients CalDAV/CardDAV boguées.

Options d'accès :

-l ADRESSE_ECOUTE, --listen-address ADRESSE_ECOUTE
Se lier à cette adresse. Passer le chemin pour un socket de domaine Unix. [localhost]
-p PORT, --port PORT
Port d'écoute. [8080]
--route-prefix PREFIXE_ROUTE
Chemin vers Xandikos. (utile lorsque Xandikos est derrière un proxy inverse) [/]
