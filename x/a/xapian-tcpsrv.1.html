XAPIAN-TCPSRV(1) Commandes utilisateur XAPIAN-TCPSRV(1)

NOM

xapian-tcpsrv - démon TCP à utiliser avec le backend distant de Xapian

SYNTAXE

xapian-tcpsrv [OPTIONS] CHEMIN_BASE_DE_DONNÉES...

DESCRIPTION

xapian-tcpsrv - démon TCP à utiliser avec le backend distant de Xapian

OPTIONS

--port NUMPORT
écouter sur le port NUMPORT pour les connexions (pas de valeur par défaut)
--interface ADRESSE
écouter sur l'interface associée au nom ou à l'adresse ADRESSE (par défaut, toutes les interfaces)
--idle-timeout MSECS
définir le délai d'attente pour les connexions inactives (par défaut : 60000ms)
--active-timeout MSECS
définir le délai d'attente pour les connexions actives (par défaut : 15000ms)
--timeout MSECS
définir les deux valeurs de délai d'attente
--one-shot
traiter une seule connexion et quitter
--quiet
désactiver les messages d'information sur la sortie standard
--writable
autoriser les mises à jour
--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter
