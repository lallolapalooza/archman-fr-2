NOM

asy - langage de graphiques vectoriels basé sur des scripts

SYNTAXE

xasy [-x magnification] [nom_fichier]

DESCRIPTION

Asymptote est un langage puissant de graphiques vectoriels descriptifs pour le dessin technique, inspiré de MetaPost mais avec une syntaxe améliorée semblable à C++. Asymptote offre aux figures le même niveau de composition de haute qualité que LaTeX offre au texte scientifique.

xasy est une interface graphique pour Asymptote qui permet des ajustements finaux des figures.

OPTIONS

-x magnification
Zoom initial.

VOIR AUSSI

Asymptote et xasy sont documentés de manière exhaustive dans la page info d'Asymptote.

AUTEUR
