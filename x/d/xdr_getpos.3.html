xdr(3) Manuel des fonctions de bibliothèque xdr(3)

NOM

xdr — routines de bibliothèque pour la représentation externe des données

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE ET DESCRIPTION

Ces routines permettent aux programmeurs C de décrire des structures de données arbitraires d'une manière indépendante de la machine. Les données pour les appels de procédure distante sont transmises à l'aide de ces routines.

Les prototypes ci-dessous sont déclarés dans <rpc/xdr.h> et utilisent les types suivants :

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Pour la déclaration du type XDR, voir <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Une primitive de filtre qui traduit entre les tableaux de taille variable et leurs représentations externes correspondantes. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que sizep est l'adresse du compteur d'éléments du tableau ; ce compteur ne peut pas dépasser maxsize. L'argument elsize est le sizeof de chacun des éléments du tableau, et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Une primitive de filtre qui traduit entre les booléens (entiers C) et leurs représentations externes. Lors de l'encodage des données, ce filtre produit des valeurs de un ou zéro. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Une primitive de filtre qui traduit entre les chaînes d'octets comptées et leurs représentations externes. L'argument sp est l'adresse du pointeur de la chaîne. La longueur de la chaîne se trouve à l'adresse sizep ; les chaînes ne peuvent pas être plus longues que maxsize. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_char(XDR *xdrs, char *cp);
Une primitive de filtre qui traduit entre les caractères C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon. Remarque : les caractères encodés ne sont pas compactés et occupent 4 octets chacun. Pour les tableaux de caractères, il est judicieux de considérer xdr_bytes(), xdr_opaque(), ou xdr_string().
void xdr_destroy(XDR *xdrs);
Une macro qui appelle la routine de destruction associée au flux XDR, xdrs. La destruction implique généralement la libération des structures de données privées associées au flux. L'utilisation de xdrs après l'appel de xdr_destroy() n'est pas définie.
bool_t xdr_double(XDR *xdrs, double *dp);
Une primitive de filtre qui traduit entre les nombres à double précision C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Une primitive de filtre qui traduit entre les énumérations C (en fait, des entiers) et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_float(XDR *xdrs, float *fp);
Une primitive de filtre qui traduit entre les flottants C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
void xdr_free(xdrproc_t proc, char *objp);
Routine de libération générique. Le premier argument est la routine XDR pour l'objet à libérer. Le second argument est un pointeur vers l'objet lui-même. Remarque : le pointeur passé à cette routine n'est pas libéré, mais ce à quoi il pointe est libéré (récursivement).
unsigned int xdr_getpos(XDR *xdrs);
Une macro qui appelle la routine d'obtention de position associée au flux XDR, xdrs. La routine retourne un entier non signé, qui indique la position du flux d'octets XDR. Une caractéristique souhaitable des flux XDR est que l'arithmétique simple fonctionne avec ce nombre, bien que les instances de flux XDR n'aient pas à garantir cela.
long *xdr_inline(XDR *xdrs, int len);
Une macro qui appelle la routine inline associée au flux XDR, xdrs. La routine retourne un pointeur vers un bloc contigu du tampon du flux ; len est la longueur en octets du tampon désiré. Remarque : le pointeur est converti en long *.
Avertissement : xdr_inline() peut retourner NULL (0) s'il ne peut pas allouer un bloc contigu d'un tampon. Par conséquent, le comportement peut varier entre les instances de flux ; il existe pour des raisons d'efficacité.
bool_t xdr_int(XDR *xdrs, int *ip);
Une primitive de filtre qui traduit entre les entiers C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_long(XDR *xdrs, long *lp);
Une primitive de filtre qui traduit entre les entiers long C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Cette routine initialise l'objet flux XDR pointé par xdrs. Les données du flux sont écrites ou lues à partir d'un bloc de mémoire à l'emplacement addr dont la longueur ne dépasse pas size octets. L'argument op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, ou XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Une primitive de filtre qui traduit entre des données opaques de taille fixe et leur représentation externe. L'argument cp est l'adresse de l'objet opaque, et cnt est sa taille en octets. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similaire à xdr_reference() sauf qu'elle sérialise les pointeurs nuls, tandis que xdr_reference() ne le fait pas. Par conséquent, xdr_pointer() peut représenter des structures de données récursives, telles que des arbres binaires ou des listes chaînées.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Cette routine initialise l'objet flux XDR pointé par xdrs. Les données du flux sont écrites dans un tampon de taille sendsize ; une valeur nulle indique que le système doit utiliser une valeur par défaut appropriée. Les données du flux sont lues à partir d'un tampon de taille recvsize ; celui-ci peut également être défini sur une valeur par défaut appropriée en passant une valeur nulle. Lorsqu'un tampon de sortie du flux est plein, writeit est appelé. De même, lorsque le tampon d'entrée d'un flux est vide, readit est appelé. Le comportement de ces deux routines est similaire aux appels système read(2) et write(2), sauf que handle est passé aux premières routines comme premier argument. Remarque : le champ op du flux XDR doit être défini par l'appelant.
Avertissement : pour lire à partir d'un flux XDR créé par cette API, vous devrez appeler xdrrec_skiprecord() avant d'appeler toute autre API XDR. Cela insère des octets supplémentaires dans le flux pour fournir une limite d'enregistrement.
bool_t xdr_reference(XDR *xdrs, char **objpp,
                     unsigned int objsize, xdrproc_t xdrobj);
Une primitive de filtre qui agit comme un filtre pour les structures de données et les pointeurs. L'argument objpp est l'adresse du pointeur vers l'objet à sérialiser ou désérialiser. L'argument objsize est la taille de l'objet en octets. L'argument xdrobj est le filtre XDR pour l'objet. Cette routine est généralement utilisée pour les structures de données imbriquées et permet de traduire entre les structures de données et leurs représentations externes. Elle ne gère pas les pointeurs nuls et ne peut donc pas être utilisée pour représenter des structures de données récursives. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Une macro qui appelle la routine de positionnement du flux XDR, xdrs. La routine ajuste la position du flux XDR à l'octet spécifié par pos. Le retour de cette fonction indique la réussite.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Une primitive de filtre qui traduit entre les chaînes de caractères C et leurs représentations externes. L'argument sp est l'adresse du pointeur de chaîne. La longueur de la chaîne ne peut pas dépasser maxsize. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Une primitive de filtre qui traduit entre les entiers non signés C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Une primitive de filtre qui traduit entre les entiers long non signés C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_void(void);
Une primitive de filtre qui ne fait rien et retourne toujours un. Elle est utile pour les structures de données qui n'ont pas de représentation externe ou lorsque la structure ne nécessite aucune opération XDR.
bool_t xdr_union(XDR *xdrs, enum_t *discr, char *handle,
                 const struct xdr_discunion *table,
                 typeof(bool_t (XDR *, void *, void *)) *defaultops);
Une primitive de filtre qui traduit entre les unions C et leurs représentations externes. L'argument discr est un pointeur vers le discriminateur de l'union. L'argument handle est un pointeur vers les données de l'union. L'argument table est un tableau de structures xdr_discunion qui mappe les valeurs du discriminateur aux routines XDR appropriées pour sérialiser ou désérialiser les différents membres de l'union. L'argument defaultops est un pointeur vers une routine XDR qui sera appelée si le discriminateur ne correspond à aucune entrée de la table. Cette routine retourne un si elle réussit, zéro sinon.
void xdr_wrapstring(char *buf, const char *fmt, ...);
Cette fonction est une primitive de formatage de chaîne qui s'apparente à sprintf(3), mais elle est conçue pour être utilisée avec des tampons de taille fixe. Elle prend un tampon de sortie buf, une chaîne de format fmt, et un nombre variable d'arguments. Elle formate les arguments selon la chaîne de format et place le résultat dans le tampon buf. La fonction tronquera la sortie si elle dépasse la taille du tampon buf, garantissant ainsi qu'aucun débordement de tampon ne se produit. La longueur du tampon de sortie est implicitement déterminée par la taille de buf.

BIBLIOTHÈQUE

Libnsl, libtirpc (Sun Remote Procedure Call library)

SYNTAXE ET DESCRIPTION

Les routines XDR sont des filtres qui traduisent entre les structures de données C et leur représentation externe sur un réseau. Les routines XDR sont des primitives qui peuvent être combinées pour créer des routines XDR complexes pour des structures de données plus grandes.

bool_t xdr_array(XDR *xdrs, char **cpp, unsigned int *size, unsigned int maxsize, xdrproc_t xdr_proc, char *dummy);
Une primitive qui traduit entre un tableau C et sa représentation externe. Le tableau est situé à l'adresse *cpp. L'argument size est un pointeur vers le nombre d'éléments du tableau. Cet argument est utilisé pour les tableaux de taille fixe et pour définir la taille des tableaux de taille variable. L'argument maxsize spécifie la taille maximale autorisée pour un tableau de taille variable. L'argument xdr_proc est une routine XDR qui sera utilisée pour filtrer chaque élément du tableau. L'argument dummy est réservé à un usage futur et doit être NULL. Cette routine renvoie 1 si elle réussit, 0 sinon.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Une primitive de filtre qui traduit entre des entiers booléens C et leur représentation externe. Cette routine renvoie 1 si elle réussit, 0 sinon.
bool_t xdr_bytes(XDR *xdrs, char **pp, unsigned int *length, unsigned int maxlength);
Une primitive qui traduit entre des tableaux d'octets C et leur représentation externe. Le tableau est situé à l'adresse *pp. L'argument length est un pointeur vers la longueur du tableau. L'argument maxlength spécifie la longueur maximale autorisée pour le tableau. Cette routine renvoie 1 si elle réussit, 0 sinon.
bool_t xdr_char(XDR *xdrs, char *c);
Une primitive de filtre qui traduit entre des caractères C et leur représentation externe. Cette routine renvoie 1 si elle réussit, 0 sinon.
void xdr_create(XDR *xdrs, xdrproc_t read_proc, xdrproc_t write_proc, xdrproc_t control_proc);
Cette routine est utilisée pour créer des flux XDR personnalisés. Les arguments read_proc, write_proc et control_proc sont des pointeurs vers des routines qui gèrent la lecture, l'écriture et le contrôle du flux XDR, respectivement. Cette routine n'est généralement pas utilisée directement, mais plutôt via des routines comme xdrmem_create(), xdrrec_create() et xdrstdio_create().
void xdr_destroy(XDR *xdrs);
Cette routine détruit le flux XDR xdrs et libère toutes les ressources associées.
bool_t xdr_double(XDR *xdrs, double *dp);
Une primitive de filtre qui traduit entre des nombres à virgule flottante double précision C et leur représentation externe. Cette routine renvoie 1 si elle réussit, 0 sinon.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Une primitive de filtre qui traduit entre des énumérations C et leur représentation externe. Cette routine renvoie 1 si elle réussit, 0 sinon.
bool_t xdr_float(XDR *xdrs, float *fp);
Une primitive de filtre qui traduit entre des nombres à virgule flottante simple précision C et leur représentation externe. Cette routine renvoie 1 si elle réussit, 0 sinon.
void xdr_free(xdrproc_t proc, char *ptr);
Cette routine libère la mémoire allouée pour une structure XDR traduite. L'argument proc est la routine XDR utilisée pour traduire la structure, et ptr est un pointeur vers la structure à libérer.
unsigned int xdr_getpos(XDR *xdrs);
Une macro qui renvoie la position actuelle dans le flux XDR xdrs. Cette position peut être utilisée plus tard avec xdr_setpos() pour repositionner le flux. Si le flux ne peut pas être repositionné, cette routine renvoie 0.
Attention : Il est difficile de repositionner certains types de flux XDR, donc cette routine peut échouer avec un type de flux et réussir avec un autre.
bool_t xdr_inline(XDR *xdrs, unsigned int len);
Cette routine tente de renvoyer un pointeur vers un tampon interne contenant len octets de données XDR. Si un tel tampon est disponible, la routine renvoie un pointeur vers celui-ci ; sinon, elle renvoie NULL. Cette routine est principalement utilisée par les implémentations XDR pour optimiser le transfert de données. Les flux XDR créés avec différentes API xdr_*_create ne sont pas compatibles pour la même raison.
bool_t xdr_int(XDR *xdrs, int *ip);
Une primitive de filtre qui traduit entre des entiers int C et leur représentation externe. Cette routine renvoie 1 si elle réussit, 0 sinon.
bool_t xdr_long(XDR *xdrs, long *lp);
Une primitive de filtre qui traduit entre des entiers long C et leur représentation externe. Cette routine renvoie 1 si elle réussit, 0 sinon.
void xdrmem_create(XDR *xdrs, const char *addr, unsigned int len, enum xdr_op op);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux XDR sont écrites, ou lues, à partir d'un tampon mémoire situé à l'adresse addr et ayant une longueur len. L'argument op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, ou XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, const char *cp, unsigned int size);
Une primitive qui traduit entre des blocs d'octets C de taille fixe et leur représentation externe. L'argument cp est un pointeur vers le bloc d'octets, et size est la taille du bloc en octets. Cette routine renvoie 1 si elle réussit, 0 sinon.
bool_t xdr_pointer(XDR *xdrs, char **pp, unsigned int size, xdrproc_t proc);
Une primitive qui gère la sérialisation et la désérialisation des pointeurs. L'argument pp est l'adresse du pointeur. L'argument size est la taille de l'objet pointé. L'argument proc est la routine XDR à utiliser pour filtrer l'objet pointé. Cette routine gère correctement les pointeurs NULL. Elle renvoie 1 si elle réussit, 0 sinon.
bool_t xdrrec_create(XDR *xdrs, unsigned int sendsize, unsigned int recvsize, char *handle, int (*readit)(char *, char *, int), int (*writeit)(char *, char *, int));
Cette routine initialise le flux XDR xdrs pour une transmission basée sur des enregistrements. Les arguments sendsize et recvsize spécifient les tailles des tampons d'envoi et de réception. L'argument handle est un pointeur vers une structure qui contient les informations spécifiques au pilote de périphérique pour la lecture et l'écriture. Les pointeurs de fonction readit et writeit spécifient les routines à utiliser pour lire et écrire des données depuis et vers le périphérique sous-jacent. Les flux XDR créés avec différentes API xdr_*_create ne sont pas compatibles pour la même raison.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
Cette routine ne peut être invoquée que sur des flux créés par xdrrec_create(). Les données dans le tampon de sortie sont marquées comme un enregistrement complet, et le tampon de sortie est éventuellement vidé si sendnow est différent de zéro. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdrrec_eof(XDR *xdrs);
Cette routine ne peut être invoquée que sur des flux créés par xdrrec_create(). Après avoir consommé le reste de l'enregistrement actuel dans le flux, cette routine renvoie un si le flux n'a plus d'entrée, zéro sinon.
bool_t xdrrec_skiprecord(XDR *xdrs);
Cette routine ne peut être invoquée que sur des flux créés par xdrrec_create(). Elle indique à l'implémentation XDR que le reste de l'enregistrement actuel dans le tampon d'entrée du flux doit être ignoré. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Une primitive qui fournit le suivi de pointeurs dans les structures. L'argument pp est l'adresse du pointeur ; size est la taille de la structure vers laquelle *pp pointe ; et proc est une procédure XDR qui filtre la structure entre sa forme C et sa représentation externe. Cette routine renvoie 1 si elle réussit, 0 sinon.
Attention : cette routine ne comprend pas les pointeurs NULL. Utilisez plutôt xdr_pointer().
xdr_setpos(XDR *xdrs, unsigned int pos);
Une macro qui invoque la routine de positionnement associée au flux XDR xdrs. L'argument pos est une valeur de position obtenue à partir de xdr_getpos(). Cette routine renvoie 1 si le flux XDR a pu être repositionné, et 0 sinon.
Attention : il est difficile de repositionner certains types de flux XDR, donc cette routine peut échouer avec un type de flux et réussir avec un autre.
bool_t xdr_short(XDR *xdrs, short *sp);
Une primitive de filtre qui traduit entre des entiers short C et leur représentation externe. Cette routine renvoie 1 si elle réussit, 0 sinon.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux XDR sont écrites, ou lues, à partir du flux stdio file. L'argument op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, ou XDR_FREE).
Attention : la routine de destruction associée à de tels flux XDR appelle fflush(3) sur le flux file, mais jamais fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Une primitive de filtre qui traduit entre des chaînes de caractères C et leur représentation externe correspondante. Les chaînes ne peuvent pas être plus longues que maxsize. Note : sp est l'adresse du pointeur de la chaîne. Cette routine renvoie 1 si elle réussit, 0 sinon.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Une primitive de filtre qui traduit entre des caractères C non signés et leur représentation externe. Cette routine renvoie 1 si elle réussit, 0 sinon.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Une primitive de filtre qui traduit entre des entiers unsigned int C et leur représentation externe. Cette routine renvoie 1 si elle réussit, 0 sinon.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Une primitive de filtre qui traduit entre des entiers unsigned long C et leur représentation externe. Cette routine renvoie 1 si elle réussit, 0 sinon.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Une primitive de filtre qui traduit entre des entiers unsigned short C et leur représentation externe. Cette routine renvoie 1 si elle réussit, 0 sinon.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* peut être égal à NULL */
Une primitive de filtre qui traduit entre une union C discriminée et sa représentation externe correspondante. Elle traduit d'abord le discriminant de l'union situé à dscmp. Ce discriminant est toujours un enum_t. Ensuite, l'union située à unp est traduite. L'argument choices est un pointeur vers un tableau de structures xdr_discrim(). Chaque structure contient une paire ordonnée [valeur,proc]. Si le discriminant de l'union est égal à la valeur associée, alors la proc est appelée pour traduire l'union. La fin du tableau de structures xdr_discrim() est marquée par une routine de valeur NULL. Si le discriminant n'est pas trouvé dans le tableau choices, alors la procédure defaultarm est appelée (si elle n'est pas NULL). Renvoie 1 si elle réussit, 0 sinon.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Une primitive de filtre qui traduit entre des tableaux de longueur fixe et leur représentation externe correspondante. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que size est le nombre d'éléments du tableau. L'argument elsize est la taille de chacun des éléments du tableau, et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine renvoie 1 si elle réussit, 0 sinon.
bool_t xdr_void(void);
Cette routine renvoie toujours 1. Elle peut être passée à des routines RPC qui nécessitent un argument fonctionnel, où rien ne doit être fait.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Une primitive qui appelle xdr_string(xdrs, sp,MAXUN.UNSIGNED ); où MAXUN.UNSIGNED est la valeur maximale d'un entier non signé. xdr_wrapstring() est pratique car le package RPC passe un maximum de deux routines XDR comme arguments, et xdr_string(), l'une des primitives les plus fréquemment utilisées, en nécessite trois. Renvoie 1 si elle réussit, 0 sinon.
