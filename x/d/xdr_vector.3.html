xdr(3) Manuel des fonctions de bibliothèque xdr(3)

NOM

xdr — routines de bibliothèque pour la représentation externe des données

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYN。
OPSIS ET DESCRIPTION

Ces routines permettent aux programmeurs C de décrire des structures de données arbitraires d'une manière indépendante de la machine. Les données pour les appels de procédure distante sont transmises à l'aide de ces routines.

Les prototypes ci-dessous sont déclarés dans <rpc/xdr.h> et utilisent les types suivants :

typedef int bool_t ;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t ;

Pour la déclaration du type XDR, voir <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc) ;
Une primitive de filtre qui traduit entre les tableaux de longueur variable et leurs représentations externes correspondantes. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que sizep est l'adresse du compteur d'éléments du tableau ; ce compteur d'éléments ne peut pas dépasser maxsize. L'argument elsize est le sizeof de chacun des éléments du tableau, et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_bool(XDR *xdrs, bool_t *bp) ;
Une primitive de filtre qui traduit entre les booléens (entiers C) et leurs représentations externes. Lors de l'encodage des données, ce filtre produit des valeurs de un ou zéro. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize) ;
Une primitive de filtre qui traduit entre les chaînes d'octets comptées et leurs représentations externes. L'argument sp est l'adresse du pointeur de chaîne. La longueur de la chaîne se trouve à l'adresse sizep ; les chaînes ne peuvent pas être plus longues que maxsize. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_char(XDR *xdrs, char *cp) ;
Une primitive de filtre qui traduit entre les caractères C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon. Note : les caractères encodés ne sont pas compactés et occupent 4 octets chacun. Pour les tableaux de caractères, il est utile d'envisager xdr_bytes(), xdr_opaque() ou xdr_string().
void xdr_destroy(XDR *xdrs) ;
Une macro qui appelle la routine de destruction associée au flux XDR, xdrs. La destruction implique généralement la libération des structures de données privées associées au flux. L'utilisation de xdrs après avoir appelé xdr_destroy() n'est pas définie.
bool_t xdr_double(XDR *xdrs, double *dp) ;
Une primitive de filtre qui traduit entre les nombres C de précision double et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_enum(XDR *xdrs, enum_t *ep) ;
Une primitive de filtre qui traduit entre les enums C (en fait des entiers) et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_float(XDR *xdrs, float *fp) ;
Une primitive de filtre qui traduit entre les floats C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
void xdr_free(xdrproc_t proc, char *objp) ;
Routine de libération générique. Le premier argument est la routine XDR pour l'objet en cours de libération. Le second argument est un pointeur vers l'objet lui-même. Note : le pointeur passé à cette routine n'est *pas* libéré, mais ce à quoi il pointe *est* libéré (récursivement).
unsigned int xdr_getpos(XDR *xdrs) ;
Une macro qui appelle la routine d'obtention de position associée au flux XDR, xdrs. La routine renvoie un entier non signé, qui indique la position du flux d'octets XDR. Une caractéristique souhaitable des flux XDR est que l'arithmétique simple fonctionne avec ce nombre, bien que les instances de flux XDR n'aient pas à garantir cela.
long *xdr_inline(XDR *xdrs, int len) ;
Une macro qui appelle la routine inline associée au flux XDR, xdrs. La routine renvoie un pointeur vers un morceau contigu du tampon du flux ; len est la longueur en octets du tampon souhaité. Note : le pointeur est converti en long *.
Avertissement : xdr_inline() peut renvoyer NULL (0) s'il ne peut pas allouer un morceau contigu d'un tampon. Par conséquent, le comportement peut varier selon les instances de flux ; il existe pour des raisons d'efficacité.
bool_t xdr_int(XDR *xdrs, int *ip) ;
Une primitive de filtre qui traduit entre les entiers C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_long(XDR *xdrs, long *lp) ;
Une primitive de filtre qui traduit entre les entiers C long et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op) ;
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux sont écrites, ou lues, à partir d'un bloc de mémoire à l'emplacement addr dont la longueur ne dépasse pas size octets. L'indicateur op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, soit XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt) ;
Une primitive de filtre qui traduit entre des données opaques de taille fixe et leur représentation externe. L'argument cp est l'adresse de l'objet opaque, et cnt est sa taille en octets. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj) ;
Similaire à xdr_reference() sauf qu'elle sérialise les pointeurs nuls, tandis que xdr_reference() ne le fait pas. Par conséquent, xdr_pointer() peut représenter des structures de données récursives, telles que des arbres binaires ou des listes chaînées.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit) ;
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux sont écrites dans un tampon de taille sendsize ; une valeur de zéro indique que le système doit utiliser une valeur par défaut appropriée. Les données du flux sont lues à partir d'un tampon de taille recvsize ; celui-ci peut également être défini sur une valeur par défaut appropriée en passant une valeur zéro. Lorsque le tampon de sortie d'un flux est plein, writeit est appelé. De même, lorsque le tampon d'entrée d'un flux est vide, readit est appelé. Le comportement de ces deux routines est similaire aux appels système read(2) et write(2), sauf que handle est passé aux premières routines en tant que premier argument. Note : le champ op du flux XDR doit être défini par l'appelant.
Avertissement : pour lire à partir d'un flux XDR créé par cette API, vous devrez appeler xdrrec_skiprecord() avant d'appeler toute autre API XDR. Cela insère des octets supplémentaires dans le flux pour fournir une limite d'enregistrement.

SYNOPSIS AND DESCRIPTION

bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *len, unsigned int maxlen);
A filter primitive that translates between C strings and their corresponding external representations. Strings cannot be longer than maxlen. Note: sp is the address of the string's pointer. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_char(XDR *xdrs, char *cp);
A filter primitive that translates between C characters and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_destroy(XDR *xdrs);
A routine that destroys the XDR stream structure pointed to by xdrs. This routine frees any dynamically allocated memory associated with the stream. It returns one if it succeeds, zero otherwise.
bool_t xdr_double(XDR *xdrs, double *dp);
A filter primitive that translates between C double precision floating-point numbers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
A filter primitive that translates between C enumeration constants and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_float(XDR *xdrs, float *fp);
A filter primitive that translates between C float precision floating-point numbers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_free(xdrproc_t proc, char *ptr);
A routine that frees the memory that was allocated by an XDR encode or decode routine. The argument proc is the XDR routine that encoded or decoded the data structure pointed to by ptr. This routine returns one if it succeeds, zero otherwise.
unsigned int xdr_getpos(XDR *xdrs);
A macro that invokes the get position routine associated with the XDR stream xdrs. This routine returns the current stream position.
Warning: not all XDR streams support the get position operation.
void *xdr_inline(XDR *xdrs, unsigned int len);
A routine that returns a pointer to a buffer of len bytes. This buffer may be used to perform optimized XDR filtering. If the XDR stream does not support inline filtering, this routine returns NULL.
bool_t xdr_int(XDR *xdrs, int *ip);
A filter primitive that translates between C int integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_long(XDR *xdrs, long *lp);
A filter primitive that translates between C long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_longlong_register(XDR *xdrs, long long *llp);
A filter primitive that translates between C long long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_hyper(XDR *xdrs, quad_t *qp);
A filter primitive that translates between C quad_t integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_longlong_register(XDR *xdrs, unsigned long long *ullp);
A filter primitive that translates between C unsigned long long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_hyper(XDR *xdrs, u_quad_t *uqp);
A filter primitive that translates between C u_quad_t integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_quadruple(XDR *xdrs, long double *ldp);
A filter primitive that translates between C long double precision floating-point numbers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_quadruple(XDR *xdrs, unsigned long double *uldp);
A filter primitive that translates between C unsigned long double precision floating-point numbers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdrrec_create(XDR *xdrs, unsigned int sendsize,
                     unsigned int recvsize, char *opaque_auth,
                     int (*readit)(char *, char *, unsigned int),
                     int (*writeit)(char *, char *, unsigned int));
This routine creates a record-oriented XDR stream. The stream is associated with the XDR structure pointed to by xdrs. The arguments sendsize and recvsize specify the size of the send and receive buffers, respectively. The argument opaque_auth is used for authentication information. The arguments readit and writeit are pointers to functions that handle reading from and writing to the underlying transport mechanism. This routine returns one if it succeeds, zero otherwise.
Warning: The buffer sizes must be multiples of four. Also, XDR streams created with different xdrrec_create() calls are not compatible, even if the buffer sizes are the same, due to internal state differences. Furthermore, XDR streams created with different xdr*_create() APIs are not compatible for the same reason.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
This routine can be invoked only on streams created by xdrrec_create(). The data in the output buffer is marked as a completed record, and the output buffer is optionally written out if sendnow is nonzero. This routine returns one if it succeeds, zero otherwise.
bool_t xdrrec_eof(XDR *xdrs);
This routine can be invoked only on streams created by xdrrec_create(). After consuming the rest of the current record in the stream, this routine returns one if the stream has no more input, zero otherwise.
bool_t xdrrec_skiprecord(XDR *xdrs);
This routine can be invoked only on streams created by xdrrec_create(). It tells the XDR implementation that the rest of the current record in the stream's input buffer should be discarded. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
A primitive that provides pointer chasing within structures. The argument pp is the address of the pointer; size is the sizeof the structure that *pp points to; and proc is an XDR procedure that filters the structure between its C form and its external representation. This routine returns one if it succeeds, zero otherwise.
Warning: this routine does not understand null pointers. Use xdr_pointer() instead.
xdr_setpos(XDR *xdrs, unsigned int pos);
A macro that invokes the set position routine associated with the XDR stream xdrs. The argument pos is a position value obtained from xdr_getpos(). This routine returns one if the XDR stream could be repositioned, and zero otherwise.
Warning: it is difficult to reposition some types of XDR streams, so this routine may fail with one type of stream and succeed with another.
bool_t xdr_short(XDR *xdrs, short *sp);
A filter primitive that translates between C short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
This routine initializes the XDR stream object pointed to by xdrs. The XDR stream data is written to, or read from, the stdio stream file. The argument op determines the direction of the XDR stream (either XDR_ENCODE, XDR_DECODE, or XDR_FREE).
Warning: the destroy routine associated with such XDR streams calls fflush(3) on the file stream, but never fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
A filter primitive that translates between C strings and their corresponding external representations. Strings cannot be longer than maxsize. Note: sp is the address of the string's pointer. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
A filter primitive that translates between unsigned C characters and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
A filter primitive that translates between C unsigned integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
A filter primitive that translates between C unsigned long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
A filter primitive that translates between C unsigned short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* may equal NULL */
A filter primitive that translates between a discriminated C union and its corresponding external representation. It first translates the discriminant of the union located at dscmp. This discriminant is always an enum_t. Next the union located at unp is translated. The argument choices is a pointer to an array of xdr_discrim() structures. Each structure contains an ordered pair of [value,proc]. If the union's discriminant is equal to the associated value, then the proc is called to translate the union. The end of the xdr_discrim() structure array is denoted by a routine of value NULL. If the discriminant is not found in the choices array, then the defaultarm procedure is called (if it is not NULL). Returns one if it succeeds, zero otherwise.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
A filter primitive that translates between fixed-length arrays and their corresponding external representations. The argument arrp is the address of the pointer to the array, while size is the element count of the array. The argument elsize is the sizeof each of the array's elements, and elproc is an XDR filter that translates between the array elements' C form, and their external representation. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_void(void);
This routine always returns one. It may be passed to RPC routines that require a function argument, where nothing is to be done.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
A primitive that calls xdr_string(xdrs, sp,MAXUN.UNSIGNED ); where MAXUN.UNSIGNED is the maximum value of an unsigned integer. xdr_wrapstring() is handy because the RPC package passes a maximum of two XDR routines as arguments, and xdr_string(), one of the most frequently used primitives, requires three. Returns one if it succeeds, zero otherwise.
