NOM

xdg-desktop-icon - outil en ligne de commande pour (dé)installer des icônes sur le bureau

SYNOPIS

xdg-desktop-icon install [--novendor] FICHIER

xdg-desktop-icon uninstall FICHIER

xdg-desktop-icon {--help | --manual | --version}

DESCRIPTION

Le programme xdg-desktop-icon peut être utilisé pour installer un lanceur d'application ou un autre fichier sur le bureau de l'utilisateur actuel.

Un lanceur d'application est représenté par un fichier *.desktop. Les fichiers de bureau sont définis par la spécification de fichier d'entrée de bureau freedesktop.org. Les aspects les plus importants des fichiers *.desktop sont résumés ci-dessous.

COMMANDES

install

Installe FICHIER sur le bureau de l'utilisateur actuel. FICHIER peut être un fichier *.desktop ou tout autre type de fichier.

uninstall

Supprime FICHIER du bureau de l'utilisateur actuel.

OPTIONS

--novendor

Normalement, xdg-desktop-icon vérifie qu'un fichier *.desktop à installer possède un préfixe vendeur. Cette option peut être utilisée pour désactiver cette vérification.

Un préfixe vendeur est constitué de caractères alphabétiques ([a-zA-Z]) et se termine par un tiret ("-"). Les entreprises et organisations sont encouragées à utiliser un mot ou une phrase, de préférence le nom de l'organisation, pour lequel elles détiennent une marque commerciale, comme préfixe vendeur. Le but du préfixe vendeur est d'éviter les conflits de noms.

--help

Affiche la synopsis de la commande.

--manual

Affiche cette page de manuel.

--version

Affiche les informations de version de xdg-utils.

FICHIERS DE BUREAU

Un lanceur d'application peut être ajouté au bureau en installant un fichier *.desktop. Un fichier *.desktop est constitué d'un en-tête [Desktop Entry] suivi de plusieurs lignes Clé=Valeur.

Un fichier *.desktop peut fournir un nom et une description pour une application dans plusieurs langues différentes. Ceci est fait en ajoutant un code de langue tel qu'utilisé par LC_MESSAGES entre crochets après la Clé. De cette façon, on peut spécifier différentes valeurs pour la même Clé en fonction de la langue actuellement sélectionnée.

Les clés suivantes sont souvent utilisées :

Type=Application

Ceci est un champ obligatoire qui indique que le fichier *.desktop décrit un lanceur d'application.

Name=Nom de l'application

Le nom de l'application. Par exemple Mozilla

GenericName=Nom générique

Une description générique de l'application. Par exemple Navigateur Web

Comment=Commentaire

Champ optionnel pour spécifier une info-bulle pour l'application. Par exemple Visiter des sites web sur Internet

Icon=Fichier Icône

L'icône à utiliser pour l'application. Il peut s'agir d'un chemin absolu vers un fichier image ou d'un nom d'icône. Si un nom d'icône est fourni, une recherche d'image par nom est effectuée dans le thème d'icônes actuel de l'utilisateur. La commande xdg-icon-resource peut être utilisée pour installer des fichiers image dans les thèmes d'icônes. L'avantage d'utiliser un nom d'icône plutôt qu'un chemin absolu est qu'avec un nom d'icône, l'icône de l'application peut être fournie dans plusieurs tailles différentes ainsi que dans plusieurs styles thématiques.

Exec=Ligne de commande

La ligne de commande pour démarrer l'application. Si l'application peut ouvrir des fichiers, le placeholder %f doit être spécifié. Lorsqu'un fichier est glissé sur le lanceur d'application, %f est remplacé par le chemin du fichier déposé. Si plusieurs fichiers peuvent être spécifiés sur la ligne de commande, le placeholder %F doit être utilisé à la place de %f. Si l'application est capable d'ouvrir des URLs en plus des fichiers locaux, alors %u ou %U peuvent être utilisés à la place de %f ou %F.

Pour un aperçu complet du format des fichiers *.desktop, veuillez consulter http://www.freedesktop.org/wiki/Specifications/desktop-entry-spec

VARIABLES D'ENVIRONNEMENT

xdg-desktop-icon respecte les variables d'environnement suivantes :

XDG_UTILS_DEBUG_LEVEL

Définir cette variable d'environnement à une valeur numérique non nulle permet à xdg-desktop-icon de fournir des rapports plus détaillés sur stderr. Définir une valeur plus élevée augmente la verbosité.

CODES DE SORTIE

Un code de sortie de 0 indique le succès, tandis qu'un code de sortie non nul indique un échec. Les codes d'échec suivants peuvent être retournés :

1

Erreur de syntaxe de la ligne de commande.

2

Un des fichiers passés en ligne de commande n'existait pas.

3

Un outil requis n'a pas pu être trouvé.

4

L'action a échoué.

5

Aucune permission pour lire l'un des fichiers passés en ligne de commande.

VOIR AUSSI

xdg-icon-resource(1)

EXEMPLES

La société ShinyThings Inc. a développé une application nommée "WebMirror" et souhaite y ajouter un lanceur sur le bureau. L'entreprise utilisera "shinythings" comme identifiant vendeur. Afin d'ajouter l'application au bureau, un fichier .desktop est nécessaire pour l'application :

shinythings-webmirror.desktop:
  [Desktop Entry]
  Encoding=UTF-8
  Type=Application
  Exec=webmirror
  Icon=shinythings-webmirror
  Name=WebMirror
  Name[nl]=WebSpiegel

Maintenant, l'outil xdg-desktop-icon peut être utilisé pour ajouter le fichier webmirror.desktop au bureau :

xdg-desktop-icon install ./shinythings-webmirror.desktop

Pour ajouter également un fichier README au bureau, la commande suivante peut être utilisée :

xdg-desktop-icon install ./shinythings-README

13 mai 2016

NOM

xdg-desktop-icon — créer, modifier et supprimer des fichiers .desktop

SYNTAXE

xdg-desktop-icon [OPTIONS]... FICHIER

DESCRIPTION

xdg-desktop-icon est un outil permettant de créer, modifier et supprimer des fichiers .desktop qui sont utilisés pour représenter des applications et des liens sur le bureau.

OPTIONS

-n, --new
Crée un nouveau fichier .desktop.
-e, --edit
Modifie un fichier .desktop existant.
-d, --delete
Supprime un fichier .desktop existant.
-h, --help
Affiche l'aide et quitte.
-v, --version
Affiche les informations de version et quitte.

CODES DE SORTIE

0 si succès, une valeur non nulle en cas d'erreur.

VOIR AUSSI

xdg-mime(1), xdg-icon-resource(1)

EXEMPLES

Pour créer un nouveau fichier .desktop pour une application :

xdg-desktop-icon --new mon-application.desktop

Pour modifier un fichier .desktop existant :

xdg-desktop-icon --edit mon-application.desktop

Pour supprimer un fichier .desktop :

xdg-desktop-icon --delete mon-application.desktop
