NOM

xdg-desktop-portal-wlr - un backend xdg-desktop-portal pour les compositeurs wlroots

DESCRIPTION

xdg-desktop-portal-wlr (ou xdpw en abrégé) permet aux applications de demander des captures d'écran et des flux d'écran via xdg-desktop-portal dans les compositeurs Wayland basés sur wlroots.

xdpw essaiera de charger le fichier de configuration depuis ces emplacements :

  • $XDG_CONFIG_HOME/xdg-desktop-portal-wlr/$XDG_CURRENT_DESKTOP
  • $XDG_CONFIG_HOME/xdg-desktop-portal-wlr/config
  • /etc/xdg/xdg-desktop-portal-wlr/$XDG_CURRENT_DESKTOP
  • /etc/xdg/xdg-desktop-portal-wlr/config

$XDG_CONFIG_HOME vaut par défaut ~/.config. $XDG_CURRENT_DESKTOP peut être une liste séparée par des deux-points. Chaque élément de cette liste sera essayé.

Les fichiers de configuration utilisent le format de fichier INI. Exemple :

[screencast]
output_name=HDMI-A-1
max_fps=30
exec_before=disable_notifications.sh
exec_after=enable_notifications.sh
chooser_type=simple
chooser_cmd=slurp -f %o -or

OPTIONS DE FLUX ÉCRAN

Ces options doivent être placées sous la section [screencast].

output_name = nom

Sélectionne quel écran sera capturé.

Cette option est utilisée avec chooser_type = none. La liste des écrans disponibles peut être obtenue via wayland-info(1) (sous la section wl_output).

max_fps = limite

Limite le nombre d'images par seconde au taux fourni.

Ceci est utile pour réduire l'utilisation du processeur lors de la capture d'images lorsque le taux de rafraîchissement de l'écran n'est pas nécessaire.

exec_before = commande

Exécute la commande avant de démarrer un flux d'écran. La commande sera exécutée dans sh.

exec_after = commande

Exécute la commande après avoir terminé tous les flux d'écran. La commande sera exécutée dans sh.

chooser_cmd = commande

Exécute cette commande pour sélectionner un écran.

Pour plus de détails, voir CHOIX_DE_L_ECRAN.

chooser_type = type

Spécifie l'entrée envoyée au choix.

Les types supportés sont :

  • default: xdpw essaiera d'utiliser le premier choix trouvé dans la liste des choix prédéfinis (slurp, wmenu, wofi, rofi, bemenu) et se rabattra sur un écran arbitraire si aucun de ceux-ci n'est trouvé.
  • none: xdpw permettra la capture d'écran soit sur l'écran donné par output_name, soit, si vide, sur un écran arbitraire sans autre interaction.
  • simple, dmenu: xdpw lancera le choix donné par chooser_cmd. Pour plus de détails, voir CHOIX_DE_L_ECRAN.

force_mod_linear = bool

Force les buffers avec des modificateurs implicites à être linéaires (expérimental)

Définir cette option à 1 forcera xdpw à allouer des dma-bufs avec un modificateur implicite comme linéaire. Cette option ne devrait pas être requise sur les configurations à GPU unique, mais peut améliorer la compatibilité, en particulier sur les configurations avec plusieurs GPU.

Cette option est expérimentale et peut être supprimée ou remplacée dans les versions futures.

CHOIX DE L'ECRAN

Le choix peut être n'importe quel programme ou script avec le comportement suivant :

  • Il renvoie un code d'erreur autre que 127. Le code d'erreur 127 est utilisé en interne pour signaler qu'aucune commande n'a pu être trouvée et toute sortie de celle-ci sera ignorée.
  • Il renvoie le nom d'un écran valide sur stdout tel que donné par wayland-info(1). Tout le reste sera traité comme un refus de l'utilisateur.
  • Pour signaler que l'utilisateur a refusé la capture d'écran, le choix doit se terminer sans rien sur stdout.

Types de choix supportés via l'option chooser_type :

  • simple: le choix est simplement appelé sans rien d'autre sur stdin.
  • dmenu: le choix reçoit une liste d'écrans séparés par des sauts de ligne (style dmenu) sur stdin.
