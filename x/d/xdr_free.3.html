xdr(3) Manuel des fonctions de bibliothèque xdr(3)

NOM

xdr — routines de bibliothèque pour la représentation externe des données

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE ET DESCRIPTION

Ces routines permettent aux programmeurs C de décrire des structures de données arbitraires de manière indépendante de la machine. Les données pour les appels de procédure distante sont transmises à l'aide de ces routines.

Les prototypes ci-dessous sont déclarés dans <rpc/xdr.h> et utilisent les types suivants :

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Pour la déclaration du type XDR, voir <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Un filtre primitif qui traduit entre des tableaux de taille variable et leur représentation externe correspondante. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que sizep est l'adresse du compteur d'éléments du tableau ; ce compteur d'éléments ne peut pas dépasser maxsize. L'argument elsize est la taille (sizeof) de chacun des éléments du tableau, et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Un filtre primitif qui traduit entre des booléens (entiers C) et leur représentation externe. Lors de l'encodage des données, ce filtre produit les valeurs un ou zéro. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Un filtre primitif qui traduit entre des chaînes d'octets comptées et leur représentation externe. L'argument sp est l'adresse du pointeur de chaîne. La longueur de la chaîne se trouve à l'adresse sizep ; les chaînes ne peuvent pas être plus longues que maxsize. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_char(XDR *xdrs, char *cp);
Un filtre primitif qui traduit entre des caractères C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon. Remarque : les caractères encodés ne sont pas compactés et occupent 4 octets chacun. Pour les tableaux de caractères, il est judicieux d'envisager xdr_bytes(), xdr_opaque(), ou xdr_string().
void xdr_destroy(XDR *xdrs);
Une macro qui appelle la routine de destruction associée au flux XDR, xdrs. La destruction implique généralement la libération des structures de données privées associées au flux. L'utilisation de xdrs après l'appel de xdr_destroy() est indéfinie.
bool_t xdr_double(XDR *xdrs, double *dp);
Un filtre primitif qui traduit entre des nombres C de type double (double précision) et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Un filtre primitif qui traduit entre des énumérations C (en fait, des entiers) et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_float(XDR *xdrs, float *fp);
Un filtre primitif qui traduit entre des nombres C de type float et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
void xdr_free(xdrproc_t proc, char *objp);
Routine de libération générique. Le premier argument est la routine XDR pour l'objet en cours de libération. Le second argument est un pointeur vers l'objet lui-même. Remarque : le pointeur passé à cette routine n'est *pas* libéré, mais ce à quoi il pointe *est* libéré (récursivement).
unsigned int xdr_getpos(XDR *xdrs);
Une macro qui appelle la routine d'obtention de position associée au flux XDR, xdrs. La routine renvoie un entier non signé, qui indique la position du flux d'octets XDR. Une caractéristique souhaitable des flux XDR est que l'arithmétique simple fonctionne avec ce nombre, bien que les instances de flux XDR n'aient pas à garantir cela.
long *xdr_inline(XDR *xdrs, int len);
Une macro qui appelle la routine d'insertion (inline) associée au flux XDR, xdrs. La routine renvoie un pointeur vers un morceau contigu du tampon du flux ; len est la longueur en octets du tampon désiré. Remarque : le pointeur est converti en long *.
Attention : xdr_inline() peut renvoyer NULL (0) s'il ne peut pas allouer un morceau contigu de tampon. Par conséquent, le comportement peut varier selon les instances de flux ; elle existe pour des raisons d'efficacité.
bool_t xdr_int(XDR *xdrs, int *ip);
Un filtre primitif qui traduit entre des entiers C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_long(XDR *xdrs, long *lp);
Un filtre primitif qui traduit entre des entiers C de type long et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux sont écrites dans, ou lues à partir, d'un bloc de mémoire à l'emplacement addr dont la longueur ne dépasse pas size octets. Le paramètre op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, soit XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Un filtre primitif qui traduit entre des données opaques de taille fixe et leur représentation externe. L'argument cp est l'adresse de l'objet opaque, et cnt est sa taille en octets. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similaire à xdr_reference() sauf qu'elle sérialise les pointeurs NULL, tandis que xdr_reference() ne le fait pas. Ainsi, xdr_pointer() peut représenter des structures de données récursives, telles que des arbres binaires ou des listes chaînées.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux sont écrites dans un tampon de taille sendsize ; une valeur nulle indique que le système doit utiliser une valeur par défaut appropriée. Les données du flux sont lues à partir d'un tampon de taille recvsize ; celui-ci peut également être défini sur une valeur par défaut appropriée en passant une valeur nulle. Lorsque le tampon de sortie d'un flux est plein, writeit est appelé. De même, lorsque le tampon d'entrée d'un flux est vide, readit est appelé. Le comportement de ces deux routines est similaire aux appels système read(2) et write(2), sauf que handle est passé aux routines précédentes comme premier argument. Remarque : le champ op du flux XDR doit être défini par l'appelant.
Attention : pour lire à partir d'un flux XDR créé par cette API, vous devrez d'abord appeler xdrrec_skiprecord() avant d'appeler toute autre API XDR. Cela insère des octets supplémentaires dans le flux pour fournir des limites d'enregistrement.
bool_t xdrrec_endofrecord(XDR *xdrs, bool_t send كافة);
Cette routine est utilisée pour signaler la fin d'un enregistrement. Si send كافة est vrai, cela signifie que l'enregistrement doit être envoyé sur le flux. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdrrec_skiprecord(XDR *xdrs);
Cette routine saute le reste de l'enregistrement courant et positionne le flux XDR au début du prochain enregistrement. Cela est utile lorsque vous lisez des données et que vous souhaitez ignorer le reste de l'enregistrement actuel. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Un filtre primitif qui traduit entre une référence à un objet et sa représentation externe. L'argument pp est l'adresse du pointeur vers l'objet. L'argument size est la taille de l'objet, et proc est le filtre XDR pour l'objet. Cette routine ne gère pas les pointeurs NULL et est donc moins flexible que xdr_pointer(). Elle renvoie un si elle réussit, zéro sinon.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Une macro qui appelle la routine de positionnement associée au flux XDR, xdrs. Elle définit la position du flux XDR à pos. Notez que cette opération peut être coûteuse en termes de performances.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Un filtre primitif qui traduit entre des chaînes de caractères C terminées par un octet nul et leur représentation externe. L'argument sp est l'adresse du pointeur vers la chaîne. La chaîne ne peut pas être plus longue que maxsize octets, y compris le caractère nul de fin. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_char(XDR *xdrs, unsigned char *cp);
Un filtre primitif qui traduit entre des caractères non signés C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Un filtre primitif qui traduit entre des entiers non signés C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Un filtre primitif qui traduit entre des entiers long non signés C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_uint64_t(XDR *xdrs, uint64_t *uip);
Un filtre primitif qui traduit entre des entiers uint64_t C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_vector(XDR *xdrs, char *kp, unsigned int k,
                  unsigned int maxsize, xdrproc_t elementproc);
Une routine de base qui gère les tableaux de taille fixe (vecteurs). L'argument kp est l'adresse du tampon du vecteur, k est le nombre d'éléments à sérialiser, maxsize est la taille maximale autorisée pour le vecteur, et elementproc est le filtre XDR pour chaque élément du vecteur.
bool_t xdr_void(void);
Cette routine ne fait rien et est principalement utilisée comme marqueur pour les appels de procédure qui n'ont ni arguments ni valeurs de retour. Elle renvoie toujours un.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Identique à xdr_string() avec maxsize défini à INT_MAX.

DESCRIPTION DU FILTRE XDR

Les routines xdr_* sont des filtres qui traduisent entre les structures de données C et leur représentation externe. Chaque filtre prend un pointeur vers une structure XDR comme premier argument. Cette structure encapsule le mécanisme d'encodage/décodage, tel qu'un flux de mémoire, un fichier réseau, etc.

L'énumération xdr_op contrôle l'opération effectuée : XDR_ENCODE pour encoder (sérialiser) des données, XDR_DECODE pour décoder (désérialiser) des données, et XDR_FREE pour libérer des données allouées par XDR.

Les routines de filtrage retournent un si l'opération a réussi, et zéro si elle a échoué.

Les types de données de base pris en charge incluent les entiers (signés et non signés, de différentes tailles), les flottants, les booléens, les chaînes de caractères et les tableaux.

Les routines xdr_create, xdrmem_create, xdrrec_create sont utilisées pour initialiser un flux XDR. La première est une routine générique qui peut créer différents types de flux XDR en fonction de ses arguments. xdrmem_create crée un flux XDR qui opère sur un bloc de mémoire. xdrrec_create crée un flux XDR orienté enregistrement qui peut être utilisé pour des communications réseau.

Les routines xdr_destroy, xdr_getpos, xdr_setpos et xdr_inline fournissent des fonctionnalités supplémentaires pour la gestion des flux XDR, telles que la destruction du flux, l'obtention et la définition de la position dans le flux, et l'accès direct à des blocs de mémoire contigus dans le flux.

La routine xdr_free est utilisée pour libérer la mémoire allouée par les routines XDR lors du décodage. Elle nécessite un pointeur vers la routine XDR appropriée pour l'objet à libérer.

BIBLIOTHÈQUE

Bibliothèque de protocoles RPC (libtirpc)

SYNOPIS ET DESCRIPTION

Les routines de bibliothèque XDR (eXternal Data Representation) fournissent une manière indépendante de la machine de sérialiser des structures de données complexes. Le package RPC utilise XDR pour décrire des données qui transitent sur un réseau. XDR est également utilisé pour le stockage et le transfert de données à travers des machines qui peuvent avoir des représentations internes différentes.

bool_t xdr_array(XDR *xdrs, char **cpp, unsigned int *svp,
               unsigned int maxsize, unsigned int elsize,
               xdrproc_t elproc);
Une primitive qui traduit entre des tableaux de taille fixe et leur représentation externe correspondante. Le tableau est représenté par *cpp et sa taille est donnée par *svp. La taille maximale du tableau est maxsize. elsize est la taille de chaque élément du tableau, et elproc est une routine XDR qui filtre les éléments du tableau entre leur forme C et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Une primitive qui traduit entre un entier booléen C (typiquement 0 ou 1) et sa représentation externe.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *lenp,
                 unsigned int maxsize);
Une primitive qui traduit entre une séquence de caractères de longueur variable et sa représentation externe. La séquence est donnée par *sp, et sa longueur par *lenp. La taille maximale de la séquence est maxsize. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_char(XDR *xdrs, char *cp);
Une primitive qui traduit entre des caractères C et leur représentation externe.
void xdr_destroy(XDR *xdrs);
Libère les ressources associées à un flux XDR.
bool_t xdr_double(XDR *xdrs, double *dp);
Une primitive qui traduit entre des nombres à virgule flottante doubles C et leur représentation externe.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Une primitive qui traduit entre des énumérations C et leur représentation externe.
bool_t xdr_float(XDR *xdrs, float *fp);
Une primitive qui traduit entre des nombres à virgule flottante simples C et leur représentation externe.
void xdr_free(xdrproc_t proc, char *objp);
Libère la mémoire allouée par une routine XDR d'encodage ou de décodage. proc est la routine XDR qui a été utilisée pour encoder ou décoder l'objet pointé par objp.
unsigned int xdr_getpos(XDR *xdrs);
Retourne la position actuelle dans le flux XDR. Un retour de (unsigned int) -1 indique une erreur. Notez qu'il est difficile de repositionner certains types de flux XDR.
char *(*xdr_inline(XDR *xdrs, unsigned int len));
Tente de retourner un pointeur vers un tampon de longueur len. Cette routine est utilisée pour les transferts rapides de données lorsqu'elles sont dans un format natif. La routine retourne le pointeur si le transfert rapide est possible, sinon elle retourne NULL.
bool_t xdr_int(XDR *xdrs, int *ip);
Une primitive qui traduit entre des entiers signés C et leur représentation externe.
bool_t xdr_long(XDR *xdrs, long *lp);
Une primitive qui traduit entre des entiers longs signés C et leur représentation externe.
void xdrmem_create(XDR *xdrs, const char *addr, unsigned int len,
                   enum xdr_op op);
Initialise le flux XDR xdrs pour lire ou écrire à partir d'un tampon de mémoire. L'adresse du tampon est addr, et sa longueur est len. L'opération est spécifiée par op.
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int size);
Une primitive qui traduit entre des blocs de données opaques de taille fixe et leur représentation externe. La taille du bloc est size. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_pointer(XDR *xdrs, char **pp, unsigned int size,
                   xdrproc_t proc);
Une primitive qui fournit le suivi de pointeur pour les structures. Elle gère correctement les pointeurs NULL. L'argument pp est l'adresse du pointeur ; size est la taille de la structure pointée par *pp ; et proc est une procédure XDR qui filtre la structure entre sa forme C et sa représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdrrec_create(XDR *xdrs, unsigned int buflen, FILE *io_file,
                     char *int_buf, unsigned int int_size);
Initialise le flux XDR xdrs pour la mise en mémoire tampon des enregistrements. Lorsque le flux est créé, les données sont lues à partir de ou écrites dans io_file. Les tampons d'entrée et de sortie sont gérés par le mécanisme d'enregistrement XDR. buflen est la taille du tampon de sortie. int_buf est le tampon d'entrée et int_size est sa taille. Si io_file est NULL, alors la lecture ou l'écriture se fait à partir de la mémoire. Si le même type de tampon XDR n'est pas utilisé sur les deux côtés de la communication, cela peut entraîner des problèmes d'interprétation des données. Par exemple, si un côté utilise xdr_create(3) et l'autre utilise xdrrec_create, les enregistrements XDR ne seront pas compatibles pour la même raison. De plus, les flux XDR créés avec différentes API xdr*_create ne sont pas compatibles pour la même raison.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
Cette routine ne peut être appelée que sur des flux créés par xdrrec_create(). Les données du tampon de sortie sont marquées comme un enregistrement complet, et le tampon de sortie est éventuellement écrit si sendnow est non nul. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdrrec_eof(XDR *xdrs);
Cette routine ne peut être appelée que sur des flux créés par xdrrec_create(). Après avoir consommé le reste de l'enregistrement actuel dans le flux, cette routine retourne un si le flux n'a plus d'entrée, zéro sinon.
bool_t xdrrec_skiprecord(XDR *xdrs);
Cette routine ne peut être appelée que sur des flux créés par xdrrec_create(). Elle indique à l'implémentation XDR que le reste de l'enregistrement actuel dans le tampon d'entrée du flux doit être ignoré. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Une primitive qui fournit le suivi de pointeur au sein des structures. L'argument pp est l'adresse du pointeur ; size est le sizeof de la structure vers laquelle pointe *pp ; et proc est une procédure XDR qui filtre la structure entre sa forme C et sa représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
Avertissement : cette routine ne comprend pas les pointeurs NULL. Utilisez plutôt xdr_pointer().
xdr_setpos(XDR *xdrs, unsigned int pos);
Une macro qui appelle la routine de positionnement associée au flux XDR xdrs. L'argument pos est une valeur de position obtenue à partir de xdr_getpos(). Cette routine retourne un si le flux XDR a pu être repositionné, et zéro sinon.
Avertissement : il est difficile de repositionner certains types de flux XDR, cette routine peut donc échouer avec un type de flux et réussir avec un autre.
bool_t xdr_short(XDR *xdrs, short *sp);
Une primitive de filtre qui traduit entre les entiers short C et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux XDR sont écrites ou lues à partir du flux stdio file. L'argument op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, ou XDR_FREE).
Avertissement : la routine de destruction associée à de tels flux XDR appelle fflush(3) sur le flux file, mais jamais fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Une primitive qui traduit entre les chaînes C et leurs représentations externes correspondantes. Les chaînes ne peuvent pas dépasser maxsize. Note : sp est l'adresse du pointeur de la chaîne. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Une primitive de filtre qui traduit entre les caractères C non signés et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Une primitive de filtre qui traduit entre les entiers non signés C et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Une primitive de filtre qui traduit entre les entiers longs non signés C et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Une primitive de filtre qui traduit entre les entiers courts non signés C et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* peut être NULL */
Une primitive de filtre qui traduit entre une union C discriminée et sa représentation externe correspondante. Elle traduit d'abord le discriminant de l'union situé à dscmp. Ce discriminant est toujours un enum_t. Ensuite, l'union située à unp est traduite. L'argument choices est un pointeur vers un tableau de structures xdr_discrim(). Chaque structure contient une paire ordonnée de [valeur,proc]. Si le discriminant de l'union est égal à la valeur associée, alors la proc est appelée pour traduire l'union. La fin du tableau de structures xdr_discrim() est marquée par une routine de valeur NULL. Si le discriminant n'est pas trouvé dans le tableau choices, alors la procédure defaultarm est appelée (si elle n'est pas NULL). Retourne un si elle réussit, zéro sinon.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Une primitive de filtre qui traduit entre des tableaux de taille fixe et leurs représentations externes correspondantes. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que size est le nombre d'éléments du tableau. L'argument elsize est le sizeof de chacun des éléments du tableau, et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_void(void);
Cette routine retourne toujours un. Elle peut être passée aux routines RPC qui nécessitent un argument de fonction, où rien ne doit être fait.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Une primitive qui appelle xdr_string(xdrs, sp, MAXUN.UNSIGNED); où MAXUN.UNSIGNED est la valeur maximale d'un entier non signé. xdr_wrapstring() est pratique car le package RPC passe un maximum de deux routines XDR comme arguments, et xdr_string(), l'une des primitives les plus fréquemment utilisées, en nécessite trois. Retourne un si elle réussit, zéro sinon.
