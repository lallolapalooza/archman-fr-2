NOM

libxdot - analyse et décomposition des opérations xdot

SYNTAXE

#include <graphviz/xdot.h>
typedef enum {
    xd_none,
    xd_linear,
    xd_radial
} xdot_grad_type;
typedef struct {
    float frac;
    char* color;
} xdot_color_stop;
typedef struct {
    double x0, y0;
    double x1, y1;
    int n_stops;
    xdot_color_stop* stops;
} xdot_linear_grad;
typedef struct {
    double x0, y0, r0;
    double x1, y1, r1;
    int n_stops;
    xdot_color_stop* stops;
} xdot_radial_grad;
typedef struct {
    xdot_grad_type type;
    union {
	char* clr;
	xdot_linear_grad ling;
	xdot_radial_grad ring;
    } u;
} xdot_color;
typedef enum {
    xd_left, xd_center, xd_right
} xdot_align;
typedef struct {
    double x, y, z;
} xdot_point;
typedef struct {
    double x, y, w, h;
} xdot_rect;
typedef struct {
    int cnt;
    xdot_point* pts;
} xdot_polyline;
typedef struct {
  double x, y;
  xdot_align align;
  double width;
  char* text;
} xdot_text;
typedef struct {
    xdot_rect pos;
    char* name;
} xdot_image;
typedef struct {
    double size;
    char* name;
} xdot_font;
typedef enum {
    xd_filled_ellipse, xd_unfilled_ellipse,
    xd_filled_polygon, xd_unfilled_polygon,
    xd_filled_bezier,  xd_unfilled_bezier,
    xd_polyline,       xd_text,
    xd_fill_color,     xd_pen_color, xd_font, xd_style, xd_image,
    xd_grad_fill_color,     xd_grad_pen_color,
    xd_fontchar
} xdot_kind; 
typedef enum {
    xop_ellipse,
    xop_polygon,
    xop_bezier,
    xop_polyline,       xop_text,
    xop_fill_color,     xop_pen_color, xop_font, xop_style, xop_image,
    xop_grad_color,
    xop_fontchar
} xop_kind; 
typedef struct _xdot_op xdot_op;
typedef void (*drawfunc_t)(xdot_op*, int);
typedef void (*freefunc_t)(xdot_op*);
struct _xdot_op {
    xdot_kind kind;
    union {
      xdot_rect ellipse;       /* xd_filled_ellipse, xd_unfilled_ellipse */
      xdot_polyline polygon;   /* xd_filled_polygon, xd_unfilled_polygon */
      xdot_polyline polyline;  /* xd_polyline */
      xdot_polyline bezier;    /* xd_filled_bezier,  xd_unfilled_bezier */
      xdot_text text;          /* xd_text */
      xdot_image image;        /* xd_image */
      char* color;             /* xd_fill_color, xd_pen_color */
      xdot_color grad_color;   /* xd_grad_fill_color, xd_grad_pen_color */
      xdot_font font;          /* xd_font */
      char* style;             /* xd_style */
      unsigned int fontchar;   /* xd_fontchar */
    } u;
    drawfunc_t drawfunc;
};
#define XDOT_PARSE_ERROR 1
typedef struct {
    int cnt;
    int sz;
    xdot_op* ops;
    freefunc_t freefunc;
    int flags;
} xdot;
typedef struct {
    int cnt;  /* no. of xdot ops */
    int n_ellipse;
    int n_polygon;
    int n_polygon_pts;
    int n_polyline;
    int n_polyline_pts;
    int n_bezier;
    int n_bezier_pts;
    int n_text;
    int n_font;
    int n_style;
    int n_color;
    int n_image;
    int n_gradcolor;
    int n_fontchar;
} xdot_stats;
xdot* parseXDotF (char*, drawfunc_t opfns[], int sz);
xdot* parseXDotFOn (char*, drawfunc_t opfns[], int sz, xdot*);
xdot* parseXDot (char*);
char* sprintXDot (xdot*);
void fprintXDot (FILE*, xdot*);
void jsonXDot (FILE*, xdot*);
void freeXDot (xdot*);
int statXDot (xdot*, xdot_stats*);
xdot_grad_type colorType (char*);
xdot_color* parseXDotColor (char*);
void freeXDotColor (xdot_color*);

DESCRIPTION

libxdot fournit un support pour l'analyse et la décomposition des opérations graphiques spécifiées par le langage xdot.

Types

xdot

Ceci encapsule une série de cnt opérations xdot, stockées dans le tableau pointé par ops. Le champ sz indique la taille de chaque élément stocké dans ops. Si l'utilisateur définit le champ freefunc, cette fonction sera appelée sur chaque élément de ops lors de freeXDot avant que la bibliothèque ne procède à son propre nettoyage. Cela permet à l'utilisateur de libérer toutes les ressources stockées dans l'élément en utilisant une extension de la structure xdot_op.

xdot_op

Une valeur de ce type représente une opération xdot. L'opération est spécifiée par le champ kind. Les données correspondantes sont stockées dans l'union u, le sous-champ associé à un kind donné étant indiqué par les commentaires.

Le champ drawfunc permet à l'utilisateur d'attacher une fonction spécifique au dessin à l'opération, fournissant une interface orientée objet. Ces fonctions peuvent être automatiquement attachées lors de l'analyse en fournissant un argument non NULL comme deuxième argument à parseXDotF.

xop_kind

Ce type fournit une énumération des opérations xdot autorisées. Voir
https://graphviz.org/docs/outputs/canon/#xdot
pour la sémantique spécifique associée à chaque opération.

xdot_rect

Représente un rectangle. Pour les ellipses, les champs x et y représentent le centre du rectangle, et w et h donnent respectivement la demi-largeur et la demi-hauteur. Pour les images, (x,y) donne le coin inférieur gauche du rectangle, et w et h donnent respectivement la largeur et la hauteur.

xdot_polyline

Ce type encapsule une série de cnt points.

xdot_text

Une valeur de ce type correspond à l'impression de la chaîne text en utilisant le point de base (x,y). Le champ width donne une approximation de la largeur de la chaîne imprimée en utilisant la police et la taille de police actuelles. Le champ align indique comment le texte doit être aligné horizontalement par rapport au point (x,y).

xdot_image

Ceci désigne l'insertion d'une image. La source de l'image est donnée par name. L'image doit être placée dans le rectangle pos.

xdot_font

Les champs donnent le nom et la taille, en points, d'une police de caractères.

xdot_align

Ce type d'énumération correspond aux valeurs d'alignement xdot -1, 0 et 1 utilisées avec l'opérateur texte, ou '\l', '\n' et '\r' utilisés dans le texte dot.

Fonctions

xdot* parseXDotF (char *str, drawfunc_t* opfns, int sz)

Analyse la chaîne str comme une séquence d'opérations xdot et retourne un pointeur vers la structure xdot résultante. La fonction analyse autant d'opérations xdot qu'elle le peut. Si une entrée inconnue ou incorrecte a été rencontrée dans str, les champs ops et cnt refléteront les opérations analysées avant l'erreur, et le bit XDOT_PARSE_ERROR sera défini dans le champ flags. La fonction retourne NULL si elle ne peut rien analyser.

Si sz est non nul, il est supposé être la taille d'un type de structure contenant xdot_op comme préfixe. Dans ce cas, les éléments du tableau pointé par ops auront chacun une taille de sz.

Si opfns est non nul, il est considéré comme un tableau de fonctions indexées par xop_kind. Pendant l'analyse, le membre drawfunc de xop_op sera défini à la fonction correspondante dans opfns.

xdot* parseXDotFOn (char *str, drawfunc_t* opfns, int sz, xdot* x)

Identique à parseXDotF, mais ajoute à l'objet xdot donné x.

xdot* parseXDot (char *str)

Ceci est équivalent à parseXDotF(str, 0, 0) .

void freeXDot (xdot* xp)

Libère la mémoire allouée pour la structure xdot pointée par xp.

int statXDot (xdot* xp, xdot_stats* sp)

Remplie la structure xdot_stats pointée par sp avec des statistiques sur les opérations contenues dans la structure xdot pointée par xp. Retourne 0 en cas de succès, et -1 si sp est NULL.

char* sprintXDot (xdot* xp)

Produit une chaîne représentant la séquence d'opérations xdot dans xp. La chaîne retournée doit être libérée par l'appelant en utilisant free().

void fprintXDot (FILE* fp, xdot* xp)

Écrit une chaîne représentant la séquence d'opérations xdot dans xp au flux de fichier fp.

void jsonXDot (FILE* fp, xdot* xp)

Écrit une représentation JSON de la séquence d'opérations xdot dans xp au flux de fichier fp.

xdot_grad_type colorType (char* clr)

Retourne le type de dégradé (linéaire ou radial) représenté par la chaîne clr.

xdot_color* parseXDotColor (char* clr)

Analyse la chaîne clr comme une couleur (simple ou dégradé) et retourne une structure xdot_color. La structure retournée doit être libérée par l'appelant en utilisant freeXDotColor.

void freeXDotColor (xdot_color* cp)

Libère la mémoire allouée pour la structure xdot_color pointée par cp.

Erreurs

Les fonctions d'analyse (parseXDotF, parseXDotFOn, parseXDot) définissent le bit XDOT_PARSE_ERROR dans le champ flags de la structure xdot retournée si une erreur d'analyse se produit. Le champ cnt indiquera le nombre d'opérations valides qui ont été analysées avant que l'erreur ne se produise.

xdot(3)

NAME

xdot

Xdot graph parsing and rendering

SYNOPSIS

#include <graphviz/xdot.h>

int
parseXDotF (FILE *fp, xdot_op **opp, size_t sz,
    void (*opfns)(xdot_op *op), void (*errfn)(char *err),
    void *obj);
int
parseXDot (const char *str, xdot_op **opp, size_t sz,
    void (*opfns)(xdot_op *op), void (*errfn)(char *err),
    void *obj);
void
freeXDot (xdot_op *op);
char*
sprintXDot (xdot *xp);
void
fprintXDot (FILE* fp, xdot* xp);
void
jsonXDot(FILE * fp, xdot * x);
xdot_grad_type
colorTypeXDot (char *str);
char*
parseXDotColor (char *str, xdot_color* clr);
void
freeXDotColor (xdot_color* cp);
int
statXDot (xdot *x, xdot_stats *sp);

DESCRIPTION

The xdot object format provides a way of representing a graph structure with associated attributes in a compact binary or textual format. It is intended to be used as an intermediate representation for rendering engines.

The library provides functions to parse and emit graphs in this format. These include:

parseXDotF
Parses an xdot representation from the C stdio stream fp. The parsed operations are returned in opp. The sz argument should be the size of the structure containing xdot_op as its first field. opfns is a callback function used to process each operation (for instance, to build the graph data structure). errfn is a callback function to report errors encountered during parsing. obj is a pointer to application-specific data that will be passed to opfns and errfn.
parseXDot
Similar to parseXDotF, but parses from a NUL-terminated string str instead of a FILE*.
freeXDot
This frees the resources associated with the argument xdot operation structure. If op is NULL, nothing happens.

extern char* sprintXDot (xdot* xp)

extern void fprintXDot (FILE* fp, xdot* xp)

Ces deux fonctions dé-serialisent la structure xdot de l'argument, produisant une représentation textuelle. fprintXDot écrit la sortie sur le flux ouvert fp ; sprintXDot retourne une chaîne allouée sur le tas.

The color string with fill and draw operations can encode linear and radial gradients. These values are parsed automatically by parseXDotF or parseXDot, with xdot_op having kind xd_grad_pen_color or xd_grad_fill_color and the value is stored in grad_color.

For an application that handles its own parsing of xdot, the library provides three helper functions.

void jsonXDot(FILE * fp, xdot * x)

Translate a given xdot object to a JSON representation. This functionality is currently considered experimental and the format of the JSON output may not be stable across Graphviz releases.

xdot_grad_type colorTypeXDot (char *str)

returns the color type described by the input string.

char* parseXDotColor (char *str, xdot_color* clr)

attempts to parse the string str as a color value, storing the result in clr. It returns NULL on failure.

void freeXDotColor (xdot_color* cp)

This frees the resources associated with a value of type xdot_color.

int statXDot (xdot *x, xdot_stats *sp)

This function is provided for retrieving various statistics about an xdot object. Returns 0 on success and populates the output parameter sp with counts of various entities in the xdot object.

BUGS

Although some small checking is done on the sz argument to parseXDotF, it is assumed it is a valid value from sizeof applied to some structure type containing xdot_op as its first field. There can be no validation of the opfns argument.
