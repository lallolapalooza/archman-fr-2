NOM

xdt-csource - utilitaire de génération de code C pour données arbitraires

SYNTAXE

xdt-csource [options] [fichier]

xdt-csource [options] --build-list [[nom] [fichier]...]

DESCRIPTION

xdt-csource est un petit utilitaire qui génère du code C contenant des données arbitraires, utile pour compiler des textes ou d'autres données directement dans des programmes. Il remplace exo-csource.

EMPLOI

xdt-csource prend en entrée soit un nom de fichier pour lequel générer du code, soit, en utilisant l'option --build-list, une liste de paires (nom, fichier) pour générer du code pour une liste d'images dans des variables nommées.

Options

-h, --help

Affiche une aide brève et quitte.

-V, --version

Affiche les informations de version et quitte.

--extern

Génère des symboles externes.

--static

Génère des symboles statiques (par défaut).

--name=identificateur

Spécifie le nom d'identificateur (préfixe) pour les variables générées (utilisé seulement si --build-list n'a pas été spécifié également).

--build-list

Active le mode d'analyse par paires (nom, fichier).

--strip-comments

Supprime les commentaires des fichiers XML

--strip-content

Supprime le contenu des nœuds des fichiers XML

--output=identificateur

Imprime la sortie vers identificateur au lieu de stdout (utilisé seulement si --build-list n'a pas été spécifié également).

VOIR AUSSI

L'utilitaire gdk-pixbuf-csource qui est livré avec la distribution Gtk+, disponible sur www.gtk.org[1].

AUTEUR
