xdr(3) Manuel des fonctions de bibliothèque xdr(3)

NOM

xdr - routines de bibliothèque pour la représentation externe des données

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE ET DESCRIPTION

Ces routines permettent aux programmeurs C de décrire des structures de données arbitraires de manière indépendante de la machine. Les données pour les appels de procédure distante sont transmises en utilisant ces routines.

Les prototypes ci-dessous sont déclarés dans <rpc/xdr.h> et utilisent les types suivants :

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Pour la déclaration du type XDR, voir <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Une primitive de filtre qui traduit entre les tableaux de longueur variable et leurs représentations externes correspondantes. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que sizep est l'adresse du compteur d'éléments du tableau ; ce compteur ne peut pas dépasser maxsize. L'argument elsize est la taille (sizeof) de chacun des éléments du tableau, et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Une primitive de filtre qui traduit entre les booléens (entiers C) et leurs représentations externes. Lors de l'encodage des données, ce filtre produit des valeurs de un ou zéro. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Une primitive de filtre qui traduit entre les chaînes d'octets comptées et leurs représentations externes. L'argument sp est l'adresse du pointeur de chaîne. La longueur de la chaîne se trouve à l'adresse sizep ; les chaînes ne peuvent pas être plus longues que maxsize. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_char(XDR *xdrs, char *cp);
Une primitive de filtre qui traduit entre les caractères C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon. Remarque : les caractères encodés ne sont pas compactés et occupent 4 octets chacun. Pour les tableaux de caractères, il est préférable d'envisager xdr_bytes(), xdr_opaque(), ou xdr_string().
void xdr_destroy(XDR *xdrs);
Une macro qui appelle la routine de destruction associée au flux XDR, xdrs. La destruction implique généralement la libération des structures de données privées associées au flux. L'utilisation de xdrs après l'appel de xdr_destroy() est indéfinie.
bool_t xdr_double(XDR *xdrs, double *dp);
Une primitive de filtre qui traduit entre les nombres en virgule flottante de précision double en C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Une primitive de filtre qui traduit entre les énumérations enum en C (en fait des entiers) et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_float(XDR *xdrs, float *fp);
Une primitive de filtre qui traduit entre les nombres flottants float en C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
void xdr_free(xdrproc_t proc, char *objp);
Routine générique de libération. Le premier argument est la routine XDR pour l'objet à libérer. Le second argument est un pointeur vers l'objet lui-même. Remarque : le pointeur passé à cette routine n'est *pas* libéré, mais ce qu'il pointe *est* libéré (de manière récursive).
unsigned int xdr_getpos(XDR *xdrs);
Une macro qui appelle la routine d'obtention de position associée au flux XDR, xdrs. La routine renvoie un entier non signé qui indique la position du flux d'octets XDR. Une caractéristique souhaitable des flux XDR est que l'arithmétique simple fonctionne avec ce nombre, bien que les instances de flux XDR n'aient pas nécessairement à garantir cela.
long *xdr_inline(XDR *xdrs, int len);
Une macro qui appelle la routine inline associée au flux XDR, xdrs. La routine renvoie un pointeur vers un bloc contigu du tampon du flux ; len est la longueur en octets du tampon désiré. Remarque : le pointeur est converti en long *.
Avertissement : xdr_inline() peut renvoyer NULL (0) s'il ne parvient pas à allouer un bloc contigu d'un tampon. Par conséquent, le comportement peut varier entre les instances de flux ; elle existe pour des raisons d'efficacité.
bool_t xdr_int(XDR *xdrs, int *ip);
Une primitive de filtre qui traduit entre les entiers C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_long(XDR *xdrs, long *lp);
Une primitive de filtre qui traduit entre les entiers C long et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Cette routine initialise l'objet flux XDR pointé par xdrs. Les données du flux sont écrites ou lues à partir d'un bloc de mémoire à l'emplacement addr dont la longueur ne dépasse pas size octets. Le paramètre op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, ou XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Une primitive de filtre qui traduit entre des données opaques de taille fixe et leur représentation externe. L'argument cp est l'adresse de l'objet opaque, et cnt est sa taille en octets. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similaire à xdr_reference() sauf qu'elle sérialise les pointeurs nuls, alors que xdr_reference() ne le fait pas. Ainsi, xdr_pointer() peut représenter des structures de données récursives, telles que des arbres binaires ou des listes chaînées.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Cette routine initialise l'objet flux XDR pointé par xdrs. Les données du flux sont écrites dans un tampon de taille sendsize ; une valeur de zéro indique que le système doit utiliser une valeur par défaut appropriée. Les données du flux sont lues à partir d'un tampon de taille recvsize ; celui-ci peut également être défini sur une valeur par défaut en passant zéro. Lorsqu'un tampon de sortie de flux est plein, writeit est appelé. De même, lorsqu'un tampon d'entrée de flux est vide, readit est appelé. Le comportement de ces deux routines est similaire aux appels système read(2) et write(2), sauf que handle est passé aux routines précédentes comme premier argument. Remarque : le champ op du flux XDR doit être défini par l'appelant.
Avertissement : pour lire depuis un flux XDR créé par cette API, vous devrez appeler xdrrec_skiprecord() avant d'appeler toute autre API XDR. Cela insère des octets supplémentaires dans le flux pour fournir une limite d'enregistrement.

NOM

xdr_void, xdr_short, xdr_u_short, xdr_long, xdr_u_long, xdr_int, xdr_u_int, xdr_char, xdr_u_char, xdr_bool, xdr_enum, xdr_opaque, xdr_bytes, xdr_string, xdr_wrapstring, xdr_reference, xdr_pointer, xdr_getpos, xdr_setpos, xdr_inline, xdr_destroy, xdr_free, xdr_op, xdr_array, xdr_vector, xdr_union, xdrmem_create, xdrrec_create, xdrrec_endofrecord, xdrrec_eof, xdrrec_skiprecord, xdrstdio_create, xdr_double, xdr_float, xdr_longlong_helper, xdr_hyper_helper, xdr_longlong, xdr_hyper, xdr_u_longlong_helper, xdr_u_hyper_helper, xdr_u_longlong, xdr_u_hyper - routines de codage/décodage XDR

BIBLIOTHÉQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE ET DESCRIPTION

Ces routines fournissent la capacité de sérialiser et de désérialiser des structures de données C pour le transport réseau, à l'aide du système eXternal Data Representation (XDR). Le protocole XDR est décrit dans la section Standards.

Les routines XDR sont généralement divisées en deux catégories : des primitives et des filtres.

Les primitives XDR gèrent les types de données simples qui n'ont pas de sous-composants. Les types de données suivants sont pris en charge :

bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Primitive de filtrage qui traduit entre les booléens C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_bytes(XDR *xdrs, char **pp, unsigned int *lp,
                 unsigned int maxsize);
Primitive de filtrage qui traduit entre des tableaux de caractères de longueur variable (octets) et leur représentation externe. L'argument pp est l'adresse du pointeur vers le tampon d'octets ; lp est l'adresse d'un entier non signé qui contient la longueur du tampon ; et maxsize est la taille maximale autorisée du tampon. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_char(XDR *xdrs, char *cp);
Primitive de filtrage qui traduit entre des caractères C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
void xdr_destroy(XDR *xdrs);
Cette routine libère toutes les ressources associées à l'objet de flux XDR xdrs. Elle doit être appelée sur tous les flux XDR lorsque vous avez terminé.
bool_t xdr_double(XDR *xdrs, double *dp);
Primitive de filtrage qui traduit entre des entiers C double et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Primitive de filtrage qui traduit entre des énumérations C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_float(XDR *xdrs, float *fp);
Primitive de filtrage qui traduit entre des nombres flottants C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
void xdr_free(xdrproc_t proc, char *ptr);
Cette routine appelle la routine de libération XDR associée à la procédure XDR proc pour libérer la mémoire allouée pour les données à l'adresse ptr. La routine de libération XDR est généralement celle qui a été utilisée pour décoder les données.
unsigned int xdr_getpos(XDR *xdrs);
Macro qui invoque la routine d'obtention de position associée au flux XDR xdrs. Elle renvoie la position actuelle dans le flux XDR. Cette valeur de position peut être utilisée plus tard avec la macro xdr_setpos().
char *(*xdr_inline(XDR *xdrs, unsigned int len));
Cette routine tente de renvoyer un pointeur vers un tampon de longueur len dans le flux XDR. Si cela réussit, le tampon peut être utilisé directement pour la sérialisation ou la désérialisation. Si cela échoue, il faut utiliser les routines XDR normales. La valeur de retour est le pointeur vers le tampon interne ou NULL si le tampon n'est pas disponible.
bool_t xdr_int(XDR *xdrs, int *ip);
Primitive de filtrage qui traduit entre les entiers C int et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_long(XDR *xdrs, long *lp);
Primitive de filtrage qui traduit entre les entiers C long et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
void xdrmem_create(XDR *xdrs, const char *addr, unsigned int len,
                   enum xdr_op op);
Cette routine initialise l'objet de flux XDR pointé par xdrs pour opérer sur une zone mémoire. Les données XDR sont copiées dans, ou lues depuis, la zone mémoire commençant à l'adresse addr et ayant une longueur de len octets. L'argument op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, ou XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, const char *cp, unsigned int size);
Primitive de filtrage qui traduit entre des tableaux de caractères de longueur fixe (opaques) et leur représentation externe. L'argument cp est le pointeur vers les données, et size est le nombre d'octets à traduire. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_pointer(XDR *xdrs, char **pp, unsigned int size,
                   xdrproc_t proc);
Primitive qui fournit le suivi de pointeurs au sein des structures. L'argument pp est l'adresse du pointeur ; size est la taille de la structure vers laquelle pointe *pp ; et proc est une procédure XDR qui filtre la structure entre sa forme C et sa représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
Note : cette routine gère les pointeurs nuls. Elle est généralement utilisée pour la sérialisation de structures auto-référentielles ou de listes chaînées.
void xdrrec_create(XDR *xdrs, unsigned int ahiresize,
                   unsigned int alowsizesize, char *rdbuf,
                   int (*readit)(char *, int),
                   int (*writeit)(char *, int));
Cette routine initialise l'objet de flux XDR xdrs pour une communication orientée enregistrement. Elle utilise des tampons de lecture et d'écriture pour gérer les enregistrements. Les arguments ahiresize et alowsizesize spécifient les tailles des tampons d'enregistrement et des tampons de plus petite taille, respectivement. rdbuf est un tampon d'entrée pré-alloué (facultatif). Les routines readit et writeit sont des fonctions de rappel utilisées pour lire et écrire des données sur le périphérique sous-jacent. Si rdbuf est NULL, des tampons seront alloués interne.
Note : les flux XDR créés avec différentes API xdr_*_create ne sont pas compatibles pour la même raison.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
Cette routine ne peut être invoquée que sur les flux créés par xdrrec_create(). Les données dans le tampon de sortie sont marquées comme un enregistrement terminé, et le tampon de sortie est éventuellement vidé si sendnow est différent de zéro. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdrrec_eof(XDR *xdrs);
Cette routine ne peut être invoquée que sur les flux créés par xdrrec_create(). Après avoir consommé le reste de l'enregistrement actuel dans le flux, cette routine renvoie un si le flux n'a plus d'entrée, zéro sinon.
bool_t xdrrec_skiprecord(XDR *xdrs);
Cette routine ne peut être invoquée que sur les flux créés par xdrrec_create(). Elle indique à l'implémentation XDR que le reste de l'enregistrement actuel dans le tampon d'entrée du flux doit être ignoré. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Primitive qui fournit le suivi de pointeurs au sein des structures. L'argument pp est l'adresse du pointeur ; size est la taille de la structure vers laquelle pointe *pp ; et proc est une procédure XDR qui filtre la structure entre sa forme C et sa représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
Attention : cette routine ne gère pas les pointeurs nuls. Utilisez xdr_pointer() à la place.
xdr_setpos(XDR *xdrs, unsigned int pos);
Macro qui invoque la routine de définition de position associée au flux XDR xdrs. L'argument pos est une valeur de position obtenue à partir de xdr_getpos(). Cette routine renvoie un si le flux XDR a pu être repositionné, et zéro sinon.
Attention : il est difficile de repositionner certains types de flux XDR, donc cette routine peut échouer avec un type de flux et réussir avec un autre.
bool_t xdr_short(XDR *xdrs, short *sp);
Primitive de filtrage qui traduit entre les entiers C short et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux XDR sont écrites dans, ou lues depuis, le flux stdio file. L'argument op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, ou XDR_FREE).
Attention : la routine de destruction associée à de tels flux XDR appelle fflush(3) sur le flux file, mais jamais fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Primitive de filtrage qui traduit entre les chaînes de caractères C et leurs représentations externes correspondantes. Les chaînes ne peuvent pas être plus longues que maxsize. Note : sp est l'adresse du pointeur de la chaîne. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Primitive de filtrage qui traduit entre des caractères C unsigned et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Primitive de filtrage qui traduit entre des entiers C unsigned et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Primitive de filtrage qui traduit entre des entiers C unsigned long et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Primitive de filtrage qui traduit entre des entiers C unsigned short et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* peut être NULL */
Primitive de filtrage qui traduit entre une union C discriminée et sa représentation externe correspondante. Elle traduit d'abord le discriminant de l'union situé à dscmp. Ce discriminant est toujours un enum_t. Ensuite, l'union située à unp est traduite. L'argument choices est un pointeur vers un tableau de structures xdr_discrim(). Chaque structure contient une paire ordonnée de [valeur,proc]. Si le discriminant de l'union est égal à la valeur associée, alors la procédure proc est appelée pour traduire l'union. La fin du tableau de structures xdr_discrim() est indiquée par une procédure de valeur NULL. Si le discriminant n'est pas trouvé dans le tableau choices, alors la procédure defaultarm est appelée (si elle n'est pas NULL). Renvoie un si elle réussit, zéro sinon.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Primitive de filtrage qui traduit entre des tableaux de longueur fixe et leurs représentations externes correspondantes. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que size est le nombre d'éléments du tableau. L'argument elsize est la taille de chacun des éléments du tableau, et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_void(void);
Cette routine renvoie toujours un. Elle peut être passée aux routines RPC qui nécessitent un argument de fonction, lorsqu'il n'y a rien à faire.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Primitive qui appelle xdr_string(xdrs, sp, MAXUN.UNSIGNED ); où MAXUN.UNSIGNED est la valeur maximale d'un entier non signé. xdr_wrapstring() est pratique car le package RPC passe au maximum deux routines XDR comme arguments, et xdr_string(), l'une des primitives les plus fréquemment utilisées, en nécessite trois. Renvoie un si elle réussit, zéro sinon.
