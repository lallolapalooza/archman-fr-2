XDG-USER-DIR(1) Commandes utilisateur XDG-USER-DIR(1)

NOM

xdg-user-dir - Trouver un répertoire utilisateur XDG

SYNTAXE

xdg-user-dir [NOM]

DESCRIPTION

xdg-user-dir recherche le chemin actuel de l'un des répertoires spéciaux d'utilisateur XDG.

Cette commande attend le nom d'un répertoire utilisateur XDG en argument. Les noms possibles sont :

DESKTOP
DOWNLOAD
TEMPLATES
PUBLICSHARE
DOCUMENTS
MUSIC
PICTURES
VIDEOS

FICHIERS

Les valeurs sont recherchées dans le fichier user-dirs.dirs. Ce fichier est créé par l'utilitaire xdg-user-dirs-update.

ENVIRONNEMENT

La variable d'environnement XDG_CONFIG_HOME détermine où se trouve le fichier user-dirs.dirs.

VOIR AUSSI

xdg-user-dirs-update(1)
