XDELTA3(1) Manuel des commandes générales XDELTA3(1)

NOM

xdelta3 - Outil de diff binaire VCDIFF (RFC 3284)

SYNOPIS

xdelta3 [commande] [options] [entrée [sortie]]

DESCRIPTION

xdelta3 est un outil de diff binaire qui utilise le format VCDIFF (RFC 3284) et la compression.

COMMANDES

config
affiche la configuration de xdelta3
decode
décompresse l'entrée, également défini par -d
encode
compresse l'entrée, également défini par -e (par défaut)
test
exécute les tests intégrés
printdelta
affiche des informations sur le delta entier
printhdr
affiche des informations sur la première fenêtre
printhdrs
affiche des informations sur toutes les fenêtres
recode
encode avec de nouveaux paramètres d'application/secondaires

OPTIONS

options standard :

-0 .. -9
niveau de compression
-c
utilise stdout
-d
décompresser
-e
compresser
-f
forcer l'écrasement
-h
afficher l'aide
-q
être silencieux
-v
être verbeux (max 2)
-V
afficher la version
options de mémoire :
-B
taille de la fenêtre source en octets
-W
taille de la fenêtre d'entrée en octets
-P
taille de la fenêtre des doublons de compression
-I
taille du tampon d'instructions (0 = illimité)
options de compression :
-s
fichier source à copier (s'il y en a un)
-S [djw|fgk]
activer/désactiver la compression secondaire
-N
désactiver la compression de petites chaînes
-D
désactiver la décompression externe (encode/decode)
-R
désactiver la recompresion externe (decode)
-n
désactiver la somme de contrôle (encode/decode)
-C
configuration logicielle (encode, non documenté)
-A [apphead]
désactiver/fournir un en-tête d'application (encode)
-J
désactiver la sortie (vérification/calcul seulement)
-T
utiliser une table de code alternative (test)

NOTES

La variable d'environnement XDELTA peut contenir des arguments supplémentaires :

XDELTA="-s source-x.y.tar.gz" \
tar --use-compress-program=xdelta3 -cf \
target-x.z.tar.gz.vcdiff target-x.y/

EXEMPLES

Compresser les différences entre SOURCE et TARGET, générant OUT, en utilisant la compression secondaire "djw" :

xdelta3 -S djw -s SOURCE TARGET OUT

Faire de même, en utilisant l'entrée et la sortie standard :

xdelta3 -S djw -s SOURCE < TARGET > OUT

Pour décompresser OUT, en utilisant SOURCE, générant TARGET :

xdelta3 -d -s SOURCE OUT TARGET
