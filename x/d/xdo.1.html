NOM

xdo - Effectuer des actions sur les fenêtres

SYNOPIS

xdo ACTION [OPTIONS] [WID ...]

DESCRIPTION

Appliquer l'action donnée aux fenêtres données.

Si aucun identifiant de fenêtre et aucune option ne sont fournis, l'action s'applique à la fenêtre focalisée.

ACTIONS

close

Fermer la fenêtre.

kill

Terminer le client.

hide

Dés mapper la fenêtre.

show

Mapper la fenêtre.

raise

Lever la fenêtre.

lower

Abaisser la fenêtre.

below

Placer la fenêtre sous la cible (voir -t).

above

Placer la fenêtre au-dessus de la cible (voir -t).

move

Déplacer la fenêtre.

resize

Redimensionner la fenêtre.

activate

Activer la fenêtre.

id

Afficher l'ID de la fenêtre.

pid

Afficher le PID de la fenêtre.

key_press, key_release

Simuler un événement de pression/relâchement de touche.

button_press, button_release

Simuler un événement de pression/relâchement de bouton.

pointer_motion

Simuler un événement de mouvement du pointeur.

-h

Afficher la synopsis et quitter.

-v

Afficher la version et quitter.

OPTIONS

Lorsque des options sont fournies, l'action s'applique à tous les enfants de la fenêtre racine qui correspondent aux comparaisons impliquées par les options par rapport à la fenêtre focalisée.

-r

ID distinct.

-c

Même classe.

-C

Classe distincte.

-d

Même bureau.

-D

Bureau distinct.

-n INSTANCE_NAME

La fenêtre a le nom d'instance donné.

-N CLASS_NAME

La fenêtre a le nom de classe donné.

-a WM_NAME

La fenêtre a le nom wm donné.

-t WID

La fenêtre cible pour les actions below et above.

-p PID

La fenêtre a le PID donné.

-k CODE

Utiliser le code donné pour les actions key_press, key_release, button_press et button_release.

-x [±]PIXELS

Coordonnée x de la fenêtre (ou delta) pour l'action move et pointer_motion.

-y [±]PIXELS

Coordonnée y de la fenêtre (ou delta) pour l'action move et pointer_motion.

-w [±]PIXELS

Largeur de la fenêtre (ou delta) pour l'action resize.

-h [±]PIXELS

Hauteur de la fenêtre (ou delta) pour l'action resize.

-m

Attendre l'existence d'une fenêtre correspondante.

-s

Gérer les numéros de bureau symboliques.

EXEMPLES

Fermer la fenêtre focalisée :

xdo close

Fermer toutes les fenêtres ayant la même classe que la fenêtre focalisée :

xdo close -c

Masquer toutes les fenêtres du bureau courant sauf la fenêtre focalisée :

xdo hide -dr

Activer la fenêtre dont l'ID est 0x00800109 :

xdo activate 0x00800109

Envoyer des événements simulés de pression/relâchement de touche avec le code 46 à la fenêtre focalisée :

xdo key_press -k 46; sleep 0.2; xdo key_release -k 46
