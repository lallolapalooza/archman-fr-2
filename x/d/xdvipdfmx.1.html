DVIPDFMX(1) Manuel des commandes générales DVIPDFMX(1)

NOM

dvipdfmx, xdvipdfmx, dvipdfm - produire des fichiers PDF directement à partir de fichiers DVI

SYNTAXE

dvipdfmx ou dvipdfm [options] fichier[.dvi]

DESCRIPTION

Le programme dvipdfmx génère un fichier PDF à partir d'un fichier DVI. Les fichiers DVI sont la sortie produite par TeX. groff peut également générer des fichiers DVI en utilisant grodvi(-Tdvi).

Dans TeX Live, dvipdfm est une autre incarnation de dvipdfmx plutôt qu'un programme distinct. La compatibilité est tentée autant que possible.

xdvipdfmx est une autre incarnation. Il est utilisé comme backend pour xetex(1) et n'est pas destiné à être appelé directement.

dvipdfmx reconnaît plusieurs commandes \special couramment utilisées, qui sont des extensions au format DVI. Notamment, il comprend les spécificités de couleur, de papier, les spécificités tpic (ce qui lui permet d'être utilisé avec pic), les spécificités hypertex, et certaines spécificités PostScript. Ces extensions permettent aux documents de contenir de la couleur, des figures et des hyperliens. Le programme essaie d'imiter le comportement de dvips lorsque possible, de sorte que de nombreux packages de macros produits pour être utilisés avec dvips fonctionneront également avec dvipdfmx. De plus, dvipdfmx comprend ses propres commandes \special spécifiques pour permettre l'accès aux fonctionnalités PDF telles que les annotations et les signets.

Depuis décembre 2018, une de ces spécificités propre à dvipdfmx est pdf:trailerid, qui spécifie le /ID dans la bande-annonce PDF. Elle est utilisée comme ceci (depuis le niveau TeX):
\special{pdf:trailerid [ (0123456789abcdef) (01234567890abcdef) ]}
C'est-à-dire, la spécificité prend un tableau (les crochets) de deux chaînes PDF de 16 octets (les parenthèses). C'est la même syntaxe que celle de LuaTeX \pdfvariable trailerid, tout en étant différente de celle de pdfTeX \pdftrailerid. Elle doit apparaître sur la première page de sortie, sinon elle est ignorée.

Les spécificités non reconnues généreront des messages d'avertissement. Les packages qui pourraient nécessiter une option de pilote dvipdfm ou dvipdfmx incluent geometry, hyperref, bookmark, graphicx, et xcolor.

Pour les problèmes liés aux cadres de délimitation (et donc aux tailles d'images), voir extractbb(1).

OPTIONS

Contrairement à de nombreux autres programmes, les valeurs des arguments doivent être séparées des noms d'options par un espace, et non par un signe = ; les noms d'options ne peuvent pas être abrégés ; et - et -- ne peuvent pas être utilisés indifféremment.

-c
Ignore (ou accepte) les \specials de couleur. Par défaut, les \special de couleur sont interprétés normalement (modifiable dans le fichier de configuration). L'option -c peut être utilisée pour produire un document en noir et blanc à partir d'un document contenant des commandes \special TeX en couleur.
--dvipdfm
Active le mode d'émulation dvipdfm. C'est le mode par défaut si le nom de l'exécutable est `dvipdfm'.
-d nombre
Spécifie le nombre de chiffres décimaux dans la sortie PDF ; doit être compris entre 0 et 5, la valeur par défaut est 2.
-e
Ignoré, pour une compatibilité (semi-)avec dvipdfm.
-f fichier_carte
Lit le fichier de carte des polices donné par fichier_carte. Le fichier de carte par défaut dans TeX Live est pdftex.map, tel que défini dans le fichier de configuration.
--aide
Affiche un message d'aide et quitte avec succès.
-i fichier_cfg
Lit fichier_cfg comme un autre fichier inclus, après avoir lu le fichier par défaut dvipdfmx.cfg.
--kpathsea-debug nombre
Demande à Kpathsea d'afficher des informations de débogage ; `-1' pour tout (volumineux).
-l
Sélectionne le mode paysage. Autrement dit, échange les dimensions x et y du papier.
-m mag
Agrandit le document d'entrée par le facteur mag.
-o nom_fichier
Définit le nom du fichier de sortie PDF ; utiliser `-' pour stdout. Par défaut, le nom du fichier de sortie est dérivé de l'entrée, c'est-à-dire fichier.pdf.
-p papier
Sélectionne le format du papier par son nom (par exemple, letter, legal, ledger, tabloid, a3, a4, ou a5 )
--pdfm-str-utf8
Suppose que les chaînes PDFMark dans les commandes \special sont encodées en UTF-8.
-q
Mode silencieux.
-r taille
Définit la résolution des polices bitmap à taille points par pouce. Les polices bitmap sont générées par la bibliothèque Kpathsea, qui utilise Metafont. Les polices bitmap sont incluses en tant que polices de Type 3 dans le fichier de sortie PDF. La valeur par défaut est 600.
-s specifications_page
Sélectionne les pages du fichier DVI à traiter ; la valeur par défaut est `-' , ce qui signifie toutes les pages. Les specifications_page consistent en une liste séparée par des virgules de plages_de_pages : 
specifications_page := specification_page[,specifications_page]
où 
specification_page := page_unique|plage_de_pages
plage_de_pages := [page_debut]-[page_fin]
Une page_debut vide est traitée comme la première page du fichier DVI, et une page_fin vide est traitée comme la dernière page du fichier DVI.

Exemples :

-s 1,3,5
inclut les pages 1, 3 et 5 ;
-s -
inclut toutes les pages ;
-s -,-
inclut deux copies de toutes les pages du fichier DVI ; et
-s 1-10
inclut les dix premières pages du fichier DVI.
-t
Recherche des images miniatures de chaque page dans le répertoire nommé par la variable d'environnement TMPDIR. Les images miniatures doivent être nommées selon un format spécifique : le même nom de base que le fichier DVI et le numéro de page comme extension du nom de fichier. dvipdfmx ne génère pas ces miniatures lui-même, mais il est distribué avec un programme wrapper nommé dvipdft qui le fait.
--version
Affiche un message d'aide et quitte avec succès.
-v
Augmente la verbosité. Les résultats de l'option -v sont cumulatifs (par exemple, -vv augmente la verbosité de deux incréments). La verbosité maximale est de quatre.
-x décalage_x
Définit la marge gauche à décalage_x. La marge gauche par défaut est 1.0in. La dimension peut être spécifiée dans n'importe quelle unité comprise par TeX (par exemple, bp, pt, in, cm).
-y décalage_y
Définit la marge supérieure à décalage_y. La marge supérieure par défaut est 1.0in. La dimension peut être spécifiée dans n'importe quelle unité comprise par TeX (par exemple, bpt, pt, in, cm).
-z nombre
Définit le niveau de compression à niveau_compression. Les niveaux de compression vont de 0 (pas de compression) à 9 (compression maximale) et correspondent aux valeurs comprises par zlib ; la valeur par défaut est 9.
-C nombre
Indicateurs d'options divers ; voir la sortie de --aide pour les détails.
-D modèle
Modèle de commande de conversion PostScript vers PDF ; la valeur par défaut est prise dans le fichier de configuration, qui donne également tous les détails et mentionne plusieurs possibilités.
-E
Essayer toujours d'intégrer les polices, en ignorant les indicateurs de licence, etc.
-I nombre
Durée de vie du cache d'images en heures ; la valeur par défaut est -2, ce qui signifie de ne pas mettre en cache les images du tout. Une valeur de -1 signifie d'effacer toutes les anciennes images et

xdvipdfmx(1) — Arch Linux

NOM

xdvipdfmx — convertir un fichier DVI en PDF

SYNTHÈSE

xdvipdfmx [-v] [-V] [-d] [-c] [-e] [-f] [-i] [-l] [-m] [-o] [-p] [-q] [-r] [-s] [-t] [-u] [-z] [-K nombre] [-O nombre] [-P nombre] [-S] [-V nombre] [-x nombre] [-X nombre] [-F nombre] [-Y nombre] [-Z nombre] [-b] [-n] [-N] [-x] [-a] [-E] [-F] [-G] [-H] [-I] [-J] [-L] [-M] [-P] [-Q] [-R] [-T] [-U] [-W] [-X] [-Y] [-Z] [-f fichier_police] [-p fichier_config] [-r nom_fichier_rapport] [-s nom_fichier_ps] [-t fichier_temp] [-u fichier_log] [-W nom_fichier_ps] [-Y fichier_paramètres] [-Z fichier_log] [fichier_dvi]

DESCRIPTION

xdvipdfmx est un convertisseur DVI vers PDF. Il est basé sur dvipdfmx, mais avec des fonctionnalités supplémentaires pour l'intégration dans des environnements de compilation plus larges tels que XeTeX et LuaTeX. Il prend en charge les polices OpenType et TrueType, ainsi que les polices PostScript, et permet l'inclusion de graphiques et d'images dans divers formats.

OPTIONS

-v
Affiche la version du programme et quitte.
-V
Mode verbeux.
-d
Supprime la génération de miniatures.
-c
Active la suppression des caractères non ASCII.
-e
Évite de traiter les polices avec des noms de police longs.
-f fichier_police
Utilise le fichier de police spécifié.
-i
Ignore les caractères non imprimables.
-l
Utilise la mise en page en paysage.
-m
Traite les PostScript MetaPost.
-o
Écrase les fichiers existants.
-p fichier_config
Utilise le fichier de configuration spécifié.
-q
Mode silencieux.
-r nom_fichier_rapport
Écrit les informations de rapport dans le fichier spécifié.
-s
Supprime les commentaires PostScript.
-t fichier_temp
Utilise le fichier temporaire spécifié.
-u
Tente de mettre à jour les polices.
-z
Supprime le traitement des polices.
-b
Génère un PDF compact.
-n
N'inclut pas les informations de licence.
-N
Convertit uniquement les nouvelles images ; la valeur 0 signifie d'effacer toutes les anciennes images mais de laisser les nouvelles images.
-K nombre
Longueur de la clé de chiffrement ; par défaut 40.
-M
Traite la sortie PostScript MetaPost.
-O nombre
Définit la profondeur maximale des éléments de signet ouverts ; par défaut 0.
-P nombre
Définit les indicateurs d'autorisation pour le chiffrement PDF ; par défaut 0x003C.
-S
Active le chiffrement PDF.
-V nombre
Définit la version mineure du PDF ; par défaut 5 (du fichier de configuration).

BOÎTES ENGlobANTES D'IMAGE

Lors de l'inclusion d'images avec dvipdfmx, leurs boîtes englobantes doivent être générées en exécutant extractbb. Le résultat sera dans un fichier .xbb ; les informations xbb sont les mêmes que pour le format PDF.

ENVIRONNEMENT

xdvipdfmx utilise la bibliothèque kpathsea pour localiser les fichiers qu'il ouvre. Par conséquent, les variables d'environnement documentées dans la documentation de la bibliothèque Kpathsea influencent xdvipdfmx. Il utilise également la valeur de la variable d'environnement TMPDIR comme répertoire pour rechercher les miniatures de chaque page.

FICHIERS

L'emplacement précis des fichiers suivants est déterminé par la configuration de la bibliothèque Kpathsea. L'emplacement peut être déterminé en utilisant kpsewhich, par exemple,

kpsewhich -progname=dvipdfmx -format='other text files' dvipdfmx.cfg
dvipdfmx.cfg
Fichier de configuration par défaut
dvipdfmx-unsafe.cfg
Fichier de configuration qui exécute Ghostscript sans vérifications de sécurité ; à utiliser uniquement pour les fichiers sources fiables. Il est actuellement requis pour utiliser PSTricks avec XeTeX : xetex -output-driver="xdvipdfmx -i dvipdfmx-unsafe.cfg -q -E" ...
pdftex.map
Le fichier de mappage de polices par défaut (peut être modifié dans le fichier de configuration).
*.tfm
Métriques de polices TeX
*.vf
Fichiers de polices virtuelles TeX
*.pfb
Fichiers de polices PostScript Type 1
texmf.cnf
Le fichier de configuration de la bibliothèque Kpathsea. L'emplacement de ce fichier peut être trouvé en tapant 
kpsewhich texmf.cnf
