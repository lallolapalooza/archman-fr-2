NOM

xdpyinfo - utilitaire d'affichage d'informations pour X

SYNTAXE

xdpyinfo [-display nom_affichage] [-queryExtensions] [-ext nom_extension]
         [-help | -version]

DESCRIPTION

Xdpyinfo est un utilitaire permettant d'afficher des informations sur un serveur X. Il est utilisé pour examiner les capacités d'un serveur, les valeurs prédéfinies pour divers paramètres utilisés dans la communication entre les clients et le serveur, ainsi que les différents types d'écrans et de visuels disponibles.

Par défaut, les informations numériques (opcode, événement de base, erreur de base) concernant les extensions de protocole ne sont pas affichées. Ces informations peuvent être obtenues avec l'option -queryExtensions. L'utilisation de cette option sur des serveurs qui chargent dynamiquement des extensions entraînera probablement le chargement de toutes les extensions possibles, ce qui peut être lent et consommer des ressources serveur importantes.

Des informations détaillées sur une extension particulière sont affichées avec l'option -ext nom_extension. Si nom_extension est all, les informations sur toutes les extensions prises en charge par xdpyinfo et le serveur sont affichées.

Si -help est spécifié, xdpyinfo affiche son message d'utilisation et se termine, sans contacter le serveur X.

Si -version est spécifié, xdpyinfo affiche sa version et se termine, sans contacter le serveur X.

ENVIRONNEMENT

DISPLAY
Pour obtenir l'hôte par défaut, le numéro d'affichage et l'écran.

VOIR AUSSI

X(7), xprop(1), xrdb(1), xwininfo(1), xrandr(1), xdriinfo(1), xvinfo(1), glxinfo(1)
