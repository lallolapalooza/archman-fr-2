rpc(3) Manuel des fonctions de bibliothèque rpc(3)

NOM

rpc - routines de bibliothèque pour les appels de procédure distante

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS ET DESCRIPTION

Ces routines permettent aux programmes C d'effectuer des appels de procédure sur d'autres machines à travers le réseau. D'abord, le client appelle une procédure pour envoyer un paquet de données au serveur. À la réception du paquet, le serveur appelle une routine de dispatch pour effectuer le service demandé, puis renvoie une réponse. Finalement, l'appel de procédure retourne au client.

Pour utiliser ces routines, incluez le fichier d'en-tête <rpc/rpc.h>.

Les prototypes ci-dessous utilisent les types suivants :

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;
typedef typeof(bool_t (caddr_t resp, struct sockaddr_in *raddr)
    *resultproc_t;

Consultez les fichiers d'en-tête pour les déclarations des types AUTH, CLIENT, SVCXPRT et XDR.

BIBLIOTHQUE

Bibliothèque de support RPC (libtirpc), sans librt

SYNTAXE ET DESCRIPTION

bool_t xdr_accepted_reply(XDR *xdrs, struct rpc_msg *cmsg);
Utilisé pour décrire les messages de réponse RPC. Cette routine est utile pour les utilisateurs qui souhaitent générer des messages de style RPC sans utiliser le package RPC.
bool_t xdr_authunix_parms(XDR *xdrs, struct authunix_parms *aup);
Utilisé pour décrire les paramètres d'authentification RPC.
bool_t xdr_callhdr(XDR *xdrs, struct rpc_msg *chdr);
Utilisé pour décrire les en-têtes de message d'appel RPC.
bool_t xdr_callmsg(XDR *xdrs, struct rpc_msg *cmsg);
Utilisé pour décrire les messages d'appel RPC. Cette routine est utile pour les utilisateurs qui souhaitent générer des messages de style RPC sans utiliser le package RPC.
bool_t xdr_opaque_auth(XDR *xdrs, struct opaque_auth *ap);
Utilisé pour décrire les messages d'informations d'authentification RPC. Cette routine est utile pour les utilisateurs qui souhaitent générer des messages de style RPC sans utiliser le package RPC.
bool_t xdr_pmap(XDR *xdrs, struct pmap *regs);
Utilisé pour décrire les paramètres de diverses procédures portmap, extérieurement. Cette routine est utile pour les utilisateurs qui souhaitent générer ces paramètres sans utiliser l'interface pmap.
bool_t xdr_pmaplist(XDR *xdrs, struct pmaplist **rp);
Utilisé pour décrire une liste de mappages de ports, extérieurement. Cette routine est utile pour les utilisateurs qui souhaitent générer ces paramètres sans utiliser l'interface pmap.
bool_t xdr_rejected_reply(XDR *xdrs, struct rejected_reply *rr);
Utilisé pour décrire les messages de réponse RPC. Cette routine est utile pour les utilisateurs qui souhaitent générer des messages de style RPC sans utiliser le package RPC.
bool_t xdr_replymsg(XDR *xdrs, struct rpc_msg *rmsg);
Utilisé pour décrire les messages de réponse RPC. Cette routine est utile pour les utilisateurs qui souhaitent générer des messages de style RPC sans utiliser le package RPC.
void xprt_register(SVCXPRT *xprt);
Une fois les descripteurs de transport de service RPC créés, ils doivent s'enregistrer auprès du package de service RPC. Cette routine modifie la variable globale svc_fds. Les implémenteurs de services n'ont généralement pas besoin de cette routine.
void xprt_unregister(SVCXPRT *xprt);
Avant qu'un descripteur de transport de service RPC ne soit détruit, il doit se désenregistrer auprès du package de service RPC. Cette routine modifie la variable globale svc_fds. Les implémenteurs de services n'ont généralement pas besoin de cette routine.
