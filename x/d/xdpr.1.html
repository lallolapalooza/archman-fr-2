NOM

xdpr - exporter une fenêtre X directement vers une imprimante

SYNTAXE

xdpr [ nom_fichier ] [ -display hote:affichage ] [ -Pimprimante ] [ -device type_appareil ] [ option ... ]

DESCRIPTION

Xdpr utilise les commandes xwd, xpr, et lpr ou lp pour exporter une fenêtre X, la traiter pour un type d'imprimante particulier, et l'imprimer sur l'imprimante de votre choix. C'est la manière la plus simple d'obtenir une impression d'une fenêtre. Xdpr imprimera par défaut la plus grande représentation possible de la fenêtre sur la page de sortie.

Les options pour xdpr sont les mêmes que celles pour xpr, xwd, et lpr ou lp. Les options les plus couramment utilisées sont décrites ci-dessous ; consultez les pages de manuel de ces commandes pour des descriptions plus détaillées des nombreuses options disponibles.

OPTIONS

nom_fichier
Spécifie un fichier contenant une exportation de fenêtre (créée par xwd) à imprimer au lieu de sélectionner une fenêtre X.
-Pimprimante
Spécifie une imprimante à laquelle envoyer la sortie. Si un nom d'imprimante n'est pas spécifié ici, xdpr (en fait, lpr ou lp) enverra votre sortie à l'imprimante spécifiée par la variable d'environnement PRINTER. Assurez-vous que le type de l'imprimante correspond au type spécifié avec l'option -device.
-display hote:affichage[.ecran]
Normalement, xdpr obtient l'hôte et le numéro d'affichage à utiliser à partir de la variable d'environnement « DISPLAY ». On peut cependant les spécifier explicitement ; voir X(7).
-device type_appareil
Spécifie l'appareil sur lequel le fichier sera imprimé. Actuellement pris en charge :
ljet
HP LaserJet series et autres appareils PCL monochromes tels que les imprimantes ThinkJet, QuietJet, RuggedWriter, HP2560 series, et HP 2930 series
pjet
HP PaintJet (mode couleur)
pjetxl
Imprimante couleur HP PaintJet XL Color Graphics Printer (mode couleur)
pp
IBM PP3812
ps
Imprimante PostScript
La valeur par défaut est PostScript. -device lw (LaserWriter) est équivalent à -device ps et n'est fourni que pour des raisons de compatibilité ascendante.
-help
Cette option affiche la liste des options connues de xdpr.

Tous les autres arguments seront passés aux commandes xwd, xpr, et lpr ou lp de manière appropriée pour chacune d'elles.

VOIR AUSSI

xwd(1), xpr(1), lpr(1), lp(1), xwud(1), X(7)

ENVIRONNEMENT

DISPLAY
quel affichage utiliser par défaut.
PRINTER
quelle imprimante utiliser par défaut.
