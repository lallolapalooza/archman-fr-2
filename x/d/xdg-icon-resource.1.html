NOM

xdg-icon-resource - outil en ligne de commande pour (dés)installer des ressources d'icônes

SYNTAXE

xdg-icon-resource install [--noupdate] [--novendor] [--theme thème] [--context contexte] [--mode mode] --size taille fichier-icone [nom-icone]

xdg-icon-resource uninstall [--noupdate] [--theme thème] [--context contexte] [--mode mode] --size taille nom-icone

xdg-icon-resource forceupdate [--theme thème] [--mode mode]

xdg-icon-resource {--help | --manual | --version}

DESCRIPTION

Le programme xdg-icon-resource peut être utilisé pour installer des ressources d'icônes dans le système d'icônes du bureau afin d'illustrer les entrées de menu, de représenter les icônes du bureau ou de représenter graphiquement les types de fichiers.

Le système d'icônes du bureau identifie les icônes par leur nom. En fonction de la taille requise, du choix du thème d'icônes et du contexte dans lequel l'icône est utilisée, le système d'icônes du bureau localise une ressource d'icône appropriée pour représenter une icône. Les ressources d'icônes peuvent être des fichiers XPM ou PNG.

Le système d'icônes du bureau fonctionne conformément à la spécification des thèmes d'icônes XDG à l'adresse http://www.freedesktop.org/wiki/Specifications/icon-theme-spec

COMMANDES

install

Installe le fichier icône indiqué par fichier-icone dans le système d'icônes du bureau sous le nom nom-icone. Les noms d'icônes n'ont pas d'extension. Si nom-icone n'est pas fourni, le nom est dérivé de fichier-icone. Le fichier icône doit avoir l'extension .png ou .xpm. Si un fichier .icon correspondant existe au même endroit que fichier-icone, il sera également installé.

uninstall

Supprime l'icône indiquée par nom-icone du système d'icônes du bureau. Notez que les noms d'icônes n'ont pas d'extension.

forceupdate

Force une mise à jour du système d'icônes du bureau. Ceci n'est utile que si le dernier appel à xdg-icon-resource incluait l'option --noupdate.

OPTIONS

--noupdate

Reporte la mise à jour du système d'icônes du bureau. Si plusieurs icônes sont ajoutées séquentiellement, ce drapeau peut être utilisé pour indiquer que des modifications supplémentaires suivront et qu'il n'est pas nécessaire de mettre à jour le système d'icônes du bureau immédiatement.

--novendor

Normalement, xdg-icon-resource vérifie qu'un fichier icône à installer dans le contexte apps a un préfixe fournisseur approprié. Cette option peut être utilisée pour désactiver cette vérification.

Un préfixe fournisseur se compose de caractères alphabétiques ([a-zA-Z]) et est terminé par un tiret ("-"). Il est encouragé aux entreprises et organisations d'utiliser un mot ou une phrase, de préférence le nom de l'organisation, pour lequel elles détiennent une marque déposée, comme préfixe fournisseur. Le but du préfixe fournisseur est d'éviter les conflits de noms.

--theme thème

Installe ou supprime le fichier icône dans le cadre du thème. Si aucun thème n'est spécifié, les icônes seront installées dans le cadre du thème par défaut hicolor. Les applications peuvent installer des icônes sous plusieurs thèmes, mais devraient au moins installer des icônes pour le thème par défaut hicolor.

--context contexte

Spécifie le contexte de l'icône. Les icônes à utiliser dans le menu des applications et comme icônes de bureau doivent utiliser apps comme contexte, ce qui est le contexte par défaut. Les icônes à utiliser comme icônes de fichiers doivent utiliser mimetypes comme contexte. D'autres contextes courants sont actions, devices, emblems, filesystems et stock.

--size taille

Spécifie la taille de l'icône. Toutes les icônes doivent être carrées. Les tailles courantes pour les icônes dans le contexte apps sont : 16, 22, 32, 48, 64 et 128. Les tailles courantes pour les icônes dans le contexte mimetypes sont : 16, 22, 32, 48, 64 et 128.

--mode mode

mode peut être user ou system. En mode utilisateur, le fichier est (dés)installé pour l'utilisateur actuel uniquement. En mode système, le fichier est (dés)installé pour tous les utilisateurs du système. Habituellement, seul root est autorisé à installer en mode système.

La valeur par défaut est d'utiliser le mode système lorsqu'il est appelé par root et le mode utilisateur lorsqu'il est appelé par un utilisateur non root.

--help

Affiche la synopsis de la commande.

--manual

Affiche cette page de manuel.

--version

Affiche les informations de version de xdg-utils.

VARIABLES ENVIRONNEMENT

xdg-icon-resource respecte les variables d'environnement suivantes :

XDG_UTILS_DEBUG_LEVEL

Définir cette variable d'environnement à une valeur numérique non nulle fait en sorte que xdg-icon-resource fournisse des rapports plus détaillés sur stderr. Définir une valeur plus élevée augmente la verbosité.

XDG_UTILS_INSTALL_MODE

Cette variable d'environnement peut être utilisée par l'utilisateur ou l'administrateur pour remplacer le mode d'installation. Les valeurs valides sont user et system.

CODES DE SORTIE

Un code de sortie de 0 indique le succès, tandis qu'un code de sortie non nul indique un échec. Les codes d'échec suivants peuvent être retournés :

1

Erreur de syntaxe de la ligne de commande.

2

Un des fichiers passés en ligne de commande n'existait pas.

3

Un outil requis n'a pas pu être trouvé.

4

L'action a échoué.

5

Aucune permission pour lire un des fichiers passés en ligne de commande.

VOIR AUSSI

xdg-desktop-icon(1), xdg-desktop-menu(1), xdg-mime(1), Spécification du thème d'icônes[1]

EXEMPLES

Pour installer une ressource d'icône afin de représenter un lanceur pour l'application myfoobar, la société ShinyThings Inc. peut utiliser :

xdg-icon-resource install --size 64 shinythings-myfoobar.png

Pour installer une icône pour un nouveau type de fichier application/x-foobar, on peut utiliser :

xdg-icon-resource install --context mimetypes --size 48 ./mime-foobar-48.png application-x-foobar
xdg-icon-resource install --context mimetypes --size 64 ./mime-foobar-64.png application-x-foobar

Ceci installera deux icônes nommées application-x-foobar mais avec des tailles différentes.
