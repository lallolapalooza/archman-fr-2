xdr(3) Manuel des fonctions de bibliothèque xdr(3)

NOM

xdr - routines de bibliothèque pour la représentation externe des données

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS ET DESCRIPTION

Ces routines permettent aux programmeurs C de décrire des structures de données arbitraires de manière indépendante de la machine. Les données pour les appels de procédure distante sont transmises à l'aide de ces routines.

Les prototypes ci-dessous sont déclarés dans <rpc/xdr.h> et utilisent les types suivants :

typedef int bool_t ;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t ;

Pour la déclaration du type XDR, voir <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc) ;
Un filtre primitif qui traduit entre les tableaux de longueur variable et leurs représentations externes correspondantes. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que sizep est l'adresse du compteur d'éléments du tableau ; ce compteur ne peut pas dépasser maxsize. L'argument elsize est la taille (sizeof) de chacun des éléments du tableau, et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_bool(XDR *xdrs, bool_t *bp) ;
Un filtre primitif qui traduit entre les booléens (entiers C) et leurs représentations externes. Lors de l'encodage des données, ce filtre produit les valeurs un ou zéro. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize) ;
Un filtre primitif qui traduit entre les chaînes d'octets comptées et leurs représentations externes. L'argument sp est l'adresse du pointeur de chaîne. La longueur de la chaîne se trouve à l'adresse sizep ; les chaînes ne peuvent pas dépasser maxsize. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_char(XDR *xdrs, char *cp) ;
Un filtre primitif qui traduit entre les caractères C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon. Note : les caractères encodés ne sont pas compactés et occupent 4 octets chacun. Pour les tableaux de caractères, il est intéressant de considérer xdr_bytes(), xdr_opaque() ou xdr_string().
void xdr_destroy(XDR *xdrs) ;
Une macro qui appelle la routine de destruction associée au flux XDR, xdrs. La destruction implique généralement la libération des structures de données privées associées au flux. L'utilisation de xdrs après avoir appelé xdr_destroy() est indéfinie.
bool_t xdr_double(XDR *xdrs, double *dp) ;
Un filtre primitif qui traduit entre les nombres en virgule flottante double précision C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_enum(XDR *xdrs, enum_t *ep) ;
Un filtre primitif qui traduit entre les énumérations C (en fait des entiers) et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_float(XDR *xdrs, float *fp) ;
Un filtre primitif qui traduit entre les flottants C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
void xdr_free(xdrproc_t proc, char *objp) ;
Routine de libération générique. Le premier argument est la routine XDR pour l'objet à libérer. Le second argument est un pointeur vers l'objet lui-même. Note : le pointeur passé à cette routine n'est *pas* libéré, mais ce à quoi il pointe est libéré (récursivement).
unsigned int xdr_getpos(XDR *xdrs) ;
Une macro qui appelle la routine d'obtention de position associée au flux XDR, xdrs. La routine renvoie un entier non signé, qui indique la position du flux d'octets XDR. Une caractéristique souhaitable des flux XDR est que l'arithmétique simple fonctionne avec ce nombre, bien que les instances de flux XDR n'aient pas à garantir cela.
long *xdr_inline(XDR *xdrs, int len) ;
Une macro qui appelle la routine en ligne associée au flux XDR, xdrs. La routine renvoie un pointeur vers un bloc contigu du tampon du flux ; len est la longueur en octets du tampon souhaité. Note : le pointeur est transtypé en long *.
Avertissement : xdr_inline() peut renvoyer NULL (0) s'il ne parvient pas à allouer un bloc contigu d'un tampon. Par conséquent, le comportement peut varier entre les instances de flux ; il existe pour des raisons d'efficacité.
bool_t xdr_int(XDR *xdrs, int *ip) ;
Un filtre primitif qui traduit entre les entiers C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_long(XDR *xdrs, long *lp) ;
Un filtre primitif qui traduit entre les entiers longs C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op) ;
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux sont écrites ou lues à partir d'un bloc de mémoire à l'emplacement addr dont la longueur ne dépasse pas size octets. Le paramètre op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, soit XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt) ;
Un filtre primitif qui traduit entre des données opaques de taille fixe et leur représentation externe. L'argument cp est l'adresse de l'objet opaque, et cnt est sa taille en octets. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj) ;
Comme xdr_reference() sauf qu'il sérialise les pointeurs NULL, alors que xdr_reference() ne le fait pas. Ainsi, xdr_pointer() peut représenter des structures de données récursives, telles que des arbres binaires ou des listes chaînées.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit) ;
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux sont écrites dans un tampon de taille sendsize ; une valeur de zéro indique au système d'utiliser une valeur par défaut appropriée. Les données du flux sont lues à partir d'un tampon de taille recvsize ; celui-ci peut également être défini à une valeur par défaut appropriée en passant une valeur zéro. Lorsqu'un tampon de sortie de flux est plein, writeit est appelé. De même, lorsqu'un tampon d'entrée de flux est vide, readit est appelé. Le comportement de ces deux routines est similaire aux appels système read(2) et write(2), à la différence près que handle est passé aux anciennes routines comme premier argument. Note : le champ op du flux XDR doit être défini par l'appelant.
Avertissement : pour lire à partir d'un flux XDR créé par cette API, vous devrez appeler xdrrec_skiprecord() avant d'appeler toute autre API XDR. Cela insère des octets supplémentaires dans le flux pour fournir des délimiteurs d'enregistrement i

NOM

xdr_int, xdr_u_int, xdr_short, xdr_u_short, xdr_long, xdr_u_long, xdr_float, xdr_double, xdr_enum, xdr_bool, xdr_char, xdr_u_char, xdr_string, xdr_wrapstring, xdr_opaque, xdr_bytes, xdr_union, xdr_reference, xdr_pointer, xdr_vector, xdr_register, xdr_create, xdr_destroy, xdr_getpos, xdr_setpos, xdrrec_create, xdrrec_endofrecord, xdrrec_eof, xdrrec_skiprecord, xdrstdio_create, xdrmem_create, xdrfile_create, xdr_inline, xdr_free, xdr_void - filtre XDR pour les types de données C

BIBLIOTHQUE

Bibliothèque RPC (librpc, -lrpc)

SYNTAXE ET DESCRIPTION

Toutes les routines XDR listées ici sont des filtres qui traduisent entre les types de données C et leur représentation externe pour RPC. Les filtres XDR sont généralement utilisés comme arguments pour les routines RPC. Les routines qui prennent un argument XDR *xdrs sont des filtres XDR. La plupart des routines XDR retournent 1 si elles réussissent et 0 en cas d'échec.

Les routines suivantes sont disponibles :

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *size,
                 unsigned int maxsize, xdrproc_t elproc);
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
bool_t xdr_bytes(XDR *xdrs, char **cpp, unsigned int *sp, unsigned int maxsize);
bool_t xdr_char(XDR *xdrs, char *cp);
void xdr_destroy(XDR *xdrs);
bool_t xdr_double(XDR *xdrs, double *dp);
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
bool_t xdr_float(XDR *xdrs, float *fp);
void xdr_free(xdrproc_t proc, char *datap);
unsigned int xdr_getpos(XDR *xdrs);
char *(*xdr_inline(XDR *xdrs, unsigned int len)) (XDR *);
bool_t xdr_int(XDR *xdrs, int *ip);
bool_t xdr_long(XDR *xdrs, long *lp);
void xdrmem_create(XDR *xdrs, const char *addr, unsigned int len,
                   enum xdr_op op);
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
bool_t xdr_pointer(XDR *xdrs, char **pp, unsigned int size,
                   xdrproc_t proc);
XDR *xdrrec_create(XDR *xdrs, unsigned int sendsize, unsigned int recvsizes,
                   char *handle, int (*readit)(), int (*writeit)());
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
bool_t xdrrec_eof(XDR *xdrs);
bool_t xdrrec_skiprecord(XDR *xdrs);
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
bool_t xdr_short(XDR *xdrs, short *sp);
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* may equal NULL */
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
bool_t xdr_void(void);
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
xdr_array() traduit un tableau de données. Le tableau est pointé par arrp, sa taille actuelle est stockée dans size, et sa taille maximale est spécifiée par maxsize. Le filtre pour les éléments individuels du tableau est fourni par elproc. Notez que size est l'adresse d'un pointeur vers le tableau, et elproc est un filtre XDR utilisé pour traduire les éléments du tableau entre leur forme C et leur représentation externe.
xdr_bool() traduit entre un C bool_t et sa représentation externe.
xdr_bytes() traduit entre un tableau de données en mémoire et sa représentation externe. Le tableau est pointé par cpp, sa taille actuelle est stockée dans sp, et sa taille maximale est spécifiée par maxsize. Ce filtre est similaire à xdr_opaque(), mais il encode la taille du tableau avant les données du tableau.
xdr_char() traduit entre un C char et sa représentation externe.
xdr_destroy() détruit un flux XDR.
xdr_double() traduit entre un C double et sa représentation externe.
xdr_enum() traduit entre un C enum_t et sa représentation externe.
xdr_float() traduit entre un C float et sa représentation externe.
xdr_free() est utilisé pour libérer la mémoire allouée par un filtre XDR. proc est le filtre XDR qui a été utilisé pour encoder ou décoder les données situées à datap.
xdr_getpos() retourne la position actuelle dans le flux XDR.
xdr_inline() tente de retourner un pointeur vers les données dans le tampon XDR pour une copie efficace. Si la longueur demandée (len) n'est pas disponible en ligne, il retourne NULL. La routine XDR principale qui a appelé xdr_inline() est responsable de la copie effective des données si xdr_inline() retourne NULL.
xdr_int() traduit entre un C int et sa représentation externe.
xdr_long() traduit entre un C long et sa représentation externe.
xdrmem_create() initialise un flux XDR pour opérer sur un tampon en mémoire. L'adresse du tampon est addr, sa longueur est len, et op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, ou XDR_FREE).
xdr_opaque() traduit entre un bloc de données arbitraires et sa représentation externe. Le pointeur vers les données est cp et la taille du bloc est cnt.
xdr_pointer() traduit un pointeur C vers sa représentation externe. pp est l'adresse du pointeur, size est la taille de la structure vers laquelle pointe *pp, et proc est un filtre XDR qui traduit la structure entre sa forme C et sa représentation externe. Cette routine prend en charge les pointeurs nuls.
xdrrec_create() initialise un flux XDR pour la communication par enregistrements. Il utilise les routines de lecture et d'écriture fournies dans handle pour gérer les opérations d'E/S sous-jacentes. Les tailles des tampons d'envoi et de réception sont spécifiées par sendsize et recvsizes, respectivement. Les routines de lecture et d'écriture doivent avoir la signature int (*readit)(char *buf, unsigned int len) et int (*writeit)(char *buf, unsigned int len). Ces routines retournent le nombre d'octets lus ou écrits, ou 0 en cas de fin de fichier ou d'erreur. Les flux XDR créés avec différentes API xdr_*_create ne sont pas compatibles pour la même raison.
xdrrec_endofrecord() ne peut être appelée que sur les flux créés par xdrrec_create(). Les données du tampon de sortie sont marquées comme un enregistrement terminé, et le tampon de sortie est éventuellement écrit si sendnow est différent de zéro. Cette routine retourne un si elle réussit, zéro sinon.
xdrrec_eof() ne peut être appelée que sur les flux créés par xdrrec_create(). Après avoir consommé le reste de l'enregistrement actuel dans le flux, cette routine retourne un si le flux n'a plus d'entrée, zéro sinon.
xdrrec_skiprecord() ne peut être appelée que sur les flux créés par xdrrec_create(). Elle indique à l'implémentation XDR que le reste de l'enregistrement actuel dans le tampon d'entrée du flux doit être supprimé. Cette routine retourne un si elle réussit, zéro sinon.
xdr_reference() est une primitive qui fournit une traque de pointeurs au sein des structures. L'argument pp est l'adresse du pointeur ; size est le sizeof de la structure vers laquelle pointe *pp ; et proc est une procédure XDR qui filtre la structure entre sa forme C et sa représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
Avertissement : cette routine ne comprend pas les pointeurs nuls. Utilisez xdr_pointer() à la place.
xdr_setpos() est une macro qui appelle la routine de définition de position associée au flux XDR xdrs. L'argument pos est une valeur de position obtenue depuis xdr_getpos(). Cette routine retourne un si le flux XDR a pu être repositionné, et zéro sinon.
Avertissement : il est difficile de repositionner certains types de flux XDR, donc cette routine peut échouer avec un type de flux et réussir avec un autre.
xdr_short() est une primitive de filtrage qui traduit entre les entiers C short et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
xdrstdio_create() initialise l'objet flux XDR pointé par xdrs. Les données du flux XDR sont écrites ou lues depuis le flux stdio file. L'argument op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, ou XDR_FREE).
Avertissement : la routine de destruction associée à de tels flux XDR appelle fflush(3) sur le flux file, mais jamais fclose(3).
xdr_string() est une primitive de filtrage qui traduit entre les chaînes C et leurs représentations externes correspondantes. Les chaînes ne peuvent pas être plus longues que maxsize. Note : sp est l'adresse du pointeur de la chaîne. Cette routine retourne un si elle réussit, zéro sinon.
xdr_u_char() est une primitive de filtrage qui traduit entre les caractères C unsigned et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
xdr_u_int() est une primitive de filtrage qui traduit entre les entiers C unsigned et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
xdr_u_long() est une primitive de filtrage qui traduit entre les entiers C unsigned long et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
xdr_u_short() est une primitive de filtrage qui traduit entre les entiers C unsigned short et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
xdr_union() est une primitive de filtrage qui traduit entre une union C discriminée et sa représentation externe correspondante. Elle traduit d'abord le discriminant de l'union situé à dscmp. Ce discriminant est toujours un enum_t. Ensuite, l'union située à unp est traduite. L'argument choices est un pointeur vers un tableau de structures xdr_discrim(). Chaque structure contient une paire ordonnée de [valeur,proc]. Si le discriminant de l'union est égal à la valeur associée, alors la proc est appelée pour traduire l'union. La fin du tableau de structures xdr_discrim() est dénotée par une routine de valeur NULL. Si le discriminant n'est pas trouvé dans le tableau choices, alors la procédure defaultarm est appelée (si elle n'est pas NULL). Retourne un si elle réussit, zéro sinon.
xdr_vector() est une primitive de filtrage qui traduit entre les tableaux de longueur fixe et leurs représentations externes correspondantes. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que size est le nombre d'éléments du tableau. L'argument elsize est le sizeof de chacun des éléments du tableau, et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
xdr_void() est une routine qui retourne toujours un. Elle peut être passée aux routines RPC qui nécessitent un argument de fonction, où rien ne doit être fait.
xdr_wrapstring() est une primitive qui appelle xdr_string(xdrs, sp,MAXUN.UNSIGNED ); où MAXUN.UNSIGNED est la valeur maximale d'un entier non signé. xdr_wrapstring() est pratique car le package RPC passe au maximum deux routines XDR comme arguments, et xdr_string(), l'une des primitives les plus fréquemment utilisées, en nécessite trois. Retourne un si elle réussit, zéro sinon.
