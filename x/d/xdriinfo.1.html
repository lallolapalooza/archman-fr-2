NOM

xdriinfo - interroger les informations de configuration des pilotes DRI

SYNTAXE

xdriinfo [-display nom_affichage] [-help|-version] [commande]

DESCRIPTION

xdriinfo peut être utilisé pour interroger les informations de configuration des pilotes de rendu direct. Si aucun argument de commande n'est spécifié, il liste les noms des pilotes de rendu direct pour tous les écrans.

Les options valides sont :

-display
Spécifie le serveur X auquel se connecter.
-help
Affiche l'utilisation du programme et quitte.
-version
Affiche la version du programme et quitte.

Les commandes valides sont :

nscreens
Affiche le nombre d'écrans.
driver ecran
Affiche le nom du pilote de rendu direct pour ecran.
options ecran|pilote
Affiche le document XML décrivant les options de configuration d'un pilote. Le pilote peut être spécifié directement par son nom pilote ou indirectement par son numéro d'ecran. Si le nom du pilote est spécifié directement, aucune connexion X n'est nécessaire.

ENVIRONNEMENT

DISPLAY
L'affichage par défaut.

VOIR AUSSI
