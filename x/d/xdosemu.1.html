DOSEMU(1) Émulation DOS DOSEMU(1)

NOM

dosemu, xdosemu - exécuter DOS et des programmes DOS sous Linux

SYNTAXE

dosemu [ -dumb ] [ -quiet ] [ -input chaîne-de-frappes ] [ -s ] [ -install [ bootdir ] ] [ arguments ]

xdosemu [ -dumb ] [ -quiet ] [ -input chaîne-de-frappes ] [ -s ] [ -install [ bootdir ] ] [ arguments ]

DESCRIPTION

dosemu est le script d'enveloppement pour dosemu.bin (1) qui invoque l'émulateur DOS Linux, également connu sous le nom de DOSEMU. Le script d'enveloppement prend également en charge l'installation (éventuellement) de l'instance privée de DOSEMU dans le $HOME de l'utilisateur, si celle-ci n'existe pas.

OPTIONS

arguments
un nombre quelconque d'options décrites dans dosemu.bin (1), veuillez vous référer à cette page de manuel pour plus de détails. Cependant, veillez à utiliser les guillemets et l'échappement correctement afin que bash ne modifie pas les arguments contenant des espaces et des barres obliques inverses.
-dumb
utilise le mode terminal `dumb'. Ceci ne fonctionnera que pour les applications DOS qui produisent une sortie texte simple vers stdout, mais présente l'avantage que (A) la sortie de l'application DOS s'accumule dans le tampon de défilement de votre xterm et (B) vous pouvez la rediriger vers un fichier tel que
$ dosemu -dumb dir > listing

Notez que l'éditeur/historique de ligne de commande de command.com de DOSEMU fonctionnera également ici, cependant, l'édition est limitée à l'utilisation de BACKSPACE.

-quiet
ne pas imprimer le commentaire de démarrage et ne pas s'arrêter pour demander
-input
simule des frappes telles que données par la chaîne-de-frappes juste après le démarrage de DOS. Ceci peut être utilisé pour lancer automatiquement des applications, contourner des menus de démarrage nécessaires ou quelque chose de similaire. Pour les détails sur le format de la chaîne, regardez README.txt.
-s
invoque dosemu via sudo. Ceci est nécessaire pour accéder à certains ports d'E/S et pour obtenir des graphiques sur la console Linux. Veuillez vous référer à la documentation (INSTALL et README.txt) pour voir quels fichiers doivent être ajustés avant de tenter ceci.
-install [ bootdir ]
lancé dans le cadre d'une installation système, cette option (ré)installe un DOS qui est utilisé dans DOSEMU (ceci peut être le FreeDOS distribué par DOSEMU ou tout autre DOS propriétaire, démarrable via fatfs). bootdir est le nom de base d'un répertoire. Le lien symbolique ~/.dosemu/drives/c sera modifié pour pointer vers ce répertoire. La réinstallation est rarement nécessaire, car en pratique les liens symboliques pointeront automatiquement vers des fichiers mis à jour.
--version
imprime la version de dosemu et la liste des options disponibles.

AUTEUR

DOSEMU (composé des fichiers dosemu.bin et dosemu) est basé sur la version 0.4 du programme original écrit par Matthias Lautner (pas d'adresse actuelle que je connaisse).

Robert Sanders <gt8134b@prism.gatech.edu> maintenait et améliorait l'incarnation de DOSEMU avec laquelle cette page de manuel a été initialement distribuée. Pendant environ 4 ans, James B. MacLean <macleajb@ednet.ns.ca> a été le chef de file sans relâche de l'équipe dosemu, l'implémentation de DPMI (qui a permis de faire tourner Windows-3.1, dos4gw, djgpp, etc.) a eu lieu pendant son 'mandat' et a rapproché le projet de l'état Beta. Hans Lermen <lermen@fgan.de> a repris et publié la première version 1.0. Maintenant, Bart Oldeman <bart@dosemu.org> maintient ce logiciel amusant.
