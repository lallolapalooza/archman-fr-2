xdr(3) Manuel des fonctions de bibliothèque xdr(3)

NOM

xdr — routines de bibliothèque pour la représentation externe des données

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS ET DESCRIPTION

Ces routines permettent aux programmeurs C de décrire des structures de données arbitraires d'une manière indépendante de la machine. Les données pour les appels de procédure distante sont transmises à l'aide de ces routines.

Les prototypes ci-dessous sont déclarés dans <rpc/xdr.h> et utilisent les types suivants :

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Pour la déclaration du type XDR, voir <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Une primitive de filtre qui traduit entre les tableaux de longueur variable et leurs représentations externes correspondantes. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que sizep est l'adresse du compteur d'éléments du tableau ; ce compteur d'éléments ne peut pas dépasser maxsize. L'argument elsize est la taille de chaque élément du tableau (sizeof), et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Une primitive de filtre qui traduit entre les booléens (entiers C) et leurs représentations externes. Lors de l'encodage des données, ce filtre produit des valeurs de un ou zéro. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Une primitive de filtre qui traduit entre les chaînes d'octets comptées et leurs représentations externes. L'argument sp est l'adresse du pointeur de la chaîne. La longueur de la chaîne se trouve à l'adresse sizep ; les chaînes ne peuvent pas être plus longues que maxsize. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_char(XDR *xdrs, char *cp);
Une primitive de filtre qui traduit entre les caractères C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon. Note : les caractères encodés ne sont pas compactés et occupent 4 octets chacun. Pour les tableaux de caractères, il est conseillé d'envisager xdr_bytes(), xdr_opaque() ou xdr_string().
void xdr_destroy(XDR *xdrs);
Une macro qui appelle la routine de destruction associée au flux XDR, xdrs. La destruction implique généralement la libération des structures de données privées associées au flux. L'utilisation de xdrs après l'appel de xdr_destroy() n'est pas définie.
bool_t xdr_double(XDR *xdrs, double *dp);
Une primitive de filtre qui traduit entre les nombres à virgule flottante de précision double en C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Une primitive de filtre qui traduit entre les enum C (en fait, des entiers) et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_float(XDR *xdrs, float *fp);
Une primitive de filtre qui traduit entre les float en C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
void xdr_free(xdrproc_t proc, char *objp);
Routine de libération générique. Le premier argument est la routine XDR de l'objet à libérer. Le second argument est un pointeur vers l'objet lui-même. Note : le pointeur passé à cette routine n'est pas libéré, mais ce qu'il pointe est libéré (récursivement).
unsigned int xdr_getpos(XDR *xdrs);
Une macro qui appelle la routine d'obtention de position associée au flux XDR, xdrs. La routine retourne un entier non signé, qui indique la position du flux d'octets XDR. Une caractéristique souhaitable des flux XDR est que l'arithmétique simple fonctionne avec ce nombre, bien que les instances de flux XDR n'aient pas à garantir cela.
long *xdr_inline(XDR *xdrs, int len);
Une macro qui appelle la routine inline associée au flux XDR, xdrs. La routine retourne un pointeur vers une partie contiguë du tampon du flux ; len est la longueur en octets du tampon désiré. Note : le pointeur est converti en long *.
Avertissement : xdr_inline() peut retourner NULL (0) s'il ne parvient pas à allouer une partie contiguë d'un tampon. Par conséquent, le comportement peut varier selon les instances de flux ; il existe pour des raisons d'efficacité.
bool_t xdr_int(XDR *xdrs, int *ip);
Une primitive de filtre qui traduit entre les entiers C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_long(XDR *xdrs, long *lp);
Une primitive de filtre qui traduit entre les entiers long C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux sont écrites ou lues à partir d'un bloc de mémoire à l'emplacement addr dont la longueur ne dépasse pas size octets. Le paramètre op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, soit XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Une primitive de filtre qui traduit entre des données opaques de taille fixe et leur représentation externe. L'argument cp est l'adresse de l'objet opaque, et cnt est sa taille en octets. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similaire à xdr_reference() sauf qu'elle sérialise les pointeurs nuls, tandis que xdr_reference() ne le fait pas. Ainsi, xdr_pointer() peut représenter des structures de données récursives, telles que des arbres binaires ou des listes chaînées.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux sont écrites dans un tampon de taille sendsize ; une valeur de zéro indique que le système doit utiliser une valeur par défaut appropriée. Les données du flux sont lues à partir d'un tampon de taille recvsize ; celui-ci peut également être défini sur une valeur par défaut appropriée en passant une valeur nulle. Lorsqu'un tampon de sortie de flux est plein, writeit est appelé. De même, lorsqu'un tampon d'entrée de flux est vide, readit est appelé. Le comportement de ces deux routines est similaire aux appels système read(2) et write(2), sauf que handle est passé aux routines précédentes comme premier argument. Note : le champ op du flux XDR doit être défini par l'appelant.

NOM

xdr - bibliothèque XDR (eXternal Data Representation)

BIBLIOTHÃ¤QUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS ET DESCRIPTION

La bibliothèque XDR fournit une manière indépendante de la machine de sérialiser et désérialiser des structures de données C. La bibliothèque XDR est également utilisée par le système d'appel de procédures distantes (RPC) de Sun.

bool_t xdr_array(XDR *xdrs, char **pp, unsigned int *sizep,
                 unsigned int maxsize, xdrproc_t proc,
                 xdrproc_t destructor);
Une primitive qui traduit entre des tableaux de taille fixe ou variable et leurs représentations externes. Les arguments pp et sizep sont respectivement les adresses du pointeur vers le tableau et de la taille du tableau. L'argument maxsize est la taille maximale autorisée pour le tableau. L'argument proc est une procédure XDR qui traduit les éléments du tableau entre leur forme C et leur représentation externe. L'argument destructor est une procédure XDR qui libère mémoire allouée par proc. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Une primitive qui traduit entre des booléens C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *lenp,
                 unsigned int maxsize);
Une primitive qui traduit entre des tableaux de bytes de longueur variable et leurs représentations externes. L'argument sp est l'adresse du pointeur vers le tableau de bytes, et lenp est l'adresse de la longueur du tableau. L'argument maxsize est la longueur maximale autorisée pour le tableau. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_char(XDR *xdrs, char *cp);
Une primitive qui traduit entre des caractères C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
void xdr_destroy(XDR *xdrs);
Détruit le flux XDR spécifié par xdrs et libère toutes les ressources associées.
bool_t xdr_double(XDR *xdrs, double *dp);
Une primitive qui traduit entre des entiers double C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Une primitive qui traduit entre une enumeration C et sa représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_float(XDR *xdrs, float *fp);
Une primitive qui traduit entre des nombres à virgule flottante C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
void xdr_free(xdrproc_t proc, char *ptr);
Libère la mémoire allouée pour la structure XDR spécifiée par ptr, en utilisant la procédure XDR proc. La procédure XDR utilisée doit être la même que celle utilisée pour encoder ou décoder la structure.
unsigned int xdr_getpos(XDR *xdrs);
Une macro qui invoque la routine d'obtention de position associée au flux XDR xdrs. Renvoie la position actuelle dans le flux.
Attention : certains types de flux XDR ne peuvent pas être repositionnés, donc cette routine peut échouer avec un type de flux et réussir avec un autre.
int xdr_inline(XDR *xdrs, unsigned int len);
Tente de retourner un pointeur vers un buffer contenant len octets de données XDR. Peut être utilisé pour des transferts de données rapides. La procédure XDR correspondante doit être appelée pour traiter les données après leur transfert. Renvoie un pointeur vers les données s'il y a lieu, ou NULL sinon.
bool_t xdr_int(XDR *xdrs, int *ip);
Une primitive qui traduit entre des entiers int C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_long(XDR *xdrs, long *lp);
Une primitive qui traduit entre des entiers long C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int len,
                   enum xdr_op op);
Initialise le flux XDR xdrs pour opérer sur la mémoire.
Les données sont écrites ou lues à partir du buffer mémoire pointé par addr, d'une longueur de len octets. L'argument op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, ou XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int size);
Une primitive qui traduit entre des données binaires de taille fixe et leurs représentations externes. L'argument cp est l'adresse des données et size est la taille en octets des données. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_pointer(XDR *xdrs, char **pp, unsigned int size,
                   xdrproc_t proc);
Similaire à xdr_reference(), mais gère correctement les pointeurs NULL. L'argument pp est l'adresse du pointeur; size est la taille de la structure vers laquelle *pp pointe; et proc est une procédure XDR qui filtre la structure entre sa forme C et sa représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
XDR * xdrrec_create(XDR *xdrs, unsigned int buflen, xdr_createfn_t readit,
                    xdr_createfn_t writeit, xdr_createfn_t seekit);
Créé un flux XDR qui utilise des enregistrements. Le flux est initialisé pour être utilisé avec des opérations de lecture et d'écriture fournies par les routines readit et writeit. L'argument buflen spécifie la taille du buffer interne. La routine seekit est utilisée pour les opérations de déplacement dans le flux. Si un flux XDR enregistré est créé par cette API, vous devrez appeler xdrrec_skiprecord() avant d'appeler toute autre API XDR. Cela insère des octets supplémentaires dans le flux pour fournir des informations sur les limites d'enregistrement. Les flux XDR créés avec différentes API xdr*_create ne sont pas compatibles pour la même raison.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
Cette routine ne peut être invoquée que sur les flux créés par xdrrec_create(). Les données dans le buffer de sortie sont marquées comme un enregistrement terminé, et le buffer de sortie est optionnellement écrit si sendnow est non nul. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdrrec_eof(XDR *xdrs);
Cette routine ne peut être invoquée que sur les flux créés par xdrrec_create(). Après avoir consommé le reste de l'enregistrement courant dans le flux, cette routine renvoie un si le flux n'a plus d'entrée, zéro sinon.
bool_t xdrrec_skiprecord(XDR *xdrs);
Cette routine ne peut être invoquée que sur les flux créés par xdrrec_create(). Elle indique à l'implémentation XDR que le reste de l'enregistrement courant dans le buffer d'entrée du flux doit être ignoré. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Une primitive qui permet de suivre les pointeurs à l'intérieur des structures. L'argument pp est l'adresse du pointeur ; size est la taille sizeof de la structure vers laquelle pointe *pp ; et proc est une procédure XDR qui filtre la structure entre sa forme C et sa représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
Attention : cette routine ne comprend pas les pointeurs NULL. Utilisez xdr_pointer() à la place.
xdr_setpos(XDR *xdrs, unsigned int pos);
Une macro qui invoque la routine d'obtention de position associée au flux XDR xdrs. L'argument pos est une valeur de position obtenue de xdr_getpos(). Cette routine renvoie un si le flux XDR a pu être repositionné, et zéro sinon.
Attention : il est difficile de repositionner certains types de flux XDR, donc cette routine peut échouer avec un type de flux et réussir avec un autre.
bool_t xdr_short(XDR *xdrs, short *sp);
Une primitive de filtrage qui traduit entre des entiers short C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
Cette routine initialise l'objet flux XDR pointé par xdrs. Les données du flux XDR sont écrites ou lues depuis le flux stdio file. L'argument op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, ou XDR_FREE).
Attention : la routine de destruction associée à de tels flux XDR appelle fflush(3) sur le flux file, mais jamais fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Une primitive de filtrage qui traduit entre des chaînes C et leurs représentations externes correspondantes. Les chaînes ne peuvent pas dépasser maxsize. Remarque : sp est l'adresse du pointeur de la chaîne. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Une primitive de filtrage qui traduit entre des caractères unsigned C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Une primitive de filtrage qui traduit entre des entiers unsigned C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Une primitive de filtrage qui traduit entre des entiers unsigned long C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Une primitive de filtrage qui traduit entre des entiers unsigned short C et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* peut être NULL */
Une primitive de filtrage qui traduit entre une union C discriminée et sa représentation externe correspondante. Elle traduit d'abord le discriminant de l'union situé à dscmp. Ce discriminant est toujours un enum_t. Ensuite, l'union située à unp est traduite. L'argument choices est un pointeur vers un tableau de structures xdr_discrim(). Chaque structure contient une paire ordonnée de [value,proc]. Si le discriminant de l'union est égal à la value associée, alors la proc est appelée pour traduire l'union. La fin du tableau de structures xdr_discrim() est marquée par une routine de valeur NULL. Si le discriminant n'est pas trouvé dans le tableau choices, alors la procédure defaultarm est appelée (si elle n'est pas NULL). Renvoie un si elle réussit, zéro sinon.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Une primitive de filtrage qui traduit entre des tableaux de longueur fixe et leurs représentations externes correspondantes. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que size est le nombre d'éléments du tableau. L'argument elsize est la taille sizeof de chacun des éléments du tableau, et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_void(void);
Cette routine renvoie toujours un. Elle peut être passée aux routines RPC qui nécessitent un argument de fonction, lorsqu'il n'y a rien à faire.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Une primitive qui appelle xdr_string(xdrs, sp, MAXUN.UNSIGNED); où MAXUN.UNSIGNED est la valeur maximale d'un entier non signé. xdr_wrapstring() est pratique car le package RPC passe au maximum deux routines XDR comme arguments, et xdr_string(), l'une des primitives les plus fréquemment utilisées, en requiert trois. Renvoie un si elle réussit, zéro sinon.
