xdr(3) Manuel des fonctions de bibliothèque xdr(3)

NOM

xdr - routines de bibliothèque pour la représentation externe des données

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS ET DESCRIPTION

Ces routines permettent aux programmeurs C de décrire des structures de données arbitraires d'une manière indépendante de la machine. Les données pour les appels de procédure distante sont transmises à l'aide de ces routines.

Les prototypes ci-dessous sont déclarés dans <rpc/xdr.h> et utilisent les types suivants :

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Pour la déclaration du type XDR, voir <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Un filtre primitif qui traduit entre les tableaux de longueur variable et leurs représentations externes correspondantes. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que sizep est l'adresse du nombre d'éléments du tableau ; ce nombre d'éléments ne peut pas dépasser maxsize. L'argument elsize est le sizeof de chacun des éléments du tableau, et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Un filtre primitif qui traduit entre les booléens (entiers C) et leurs représentations externes. Lors de l'encodage des données, ce filtre produit des valeurs de un ou zéro. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Un filtre primitif qui traduit entre les chaînes d'octets comptées et leurs représentations externes. L'argument sp est l'adresse du pointeur de chaîne. La longueur de la chaîne se trouve à l'adresse sizep ; les chaînes ne peuvent pas être plus longues que maxsize. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_char(XDR *xdrs, char *cp);
Un filtre primitif qui traduit entre les caractères C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon. Note : les caractères encodés ne sont pas compactés et occupent 4 octets chacun. Pour les tableaux de caractères, il est conseillé d'envisager xdr_bytes(), xdr_opaque(), ou xdr_string().
void xdr_destroy(XDR *xdrs);
Une macro qui invoque la routine de destruction associée au flux XDR, xdrs. La destruction implique généralement la libération des structures de données privées associées au flux. Utiliser xdrs après avoir invoqué xdr_destroy() est indéfini.
bool_t xdr_double(XDR *xdrs, double *dp);
Un filtre primitif qui traduit entre les nombres double de précision C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Un filtre primitif qui traduit entre les énumérations C (en fait des entiers) et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_float(XDR *xdrs, float *fp);
Un filtre primitif qui traduit entre les flottants C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
void xdr_free(xdrproc_t proc, char *objp);
Routine de libération générique. Le premier argument est la routine XDR pour l'objet à libérer. Le second argument est un pointeur vers l'objet lui-même. Note : le pointeur passé à cette routine n'est pas libéré, mais ce qu'il pointe est libéré (récursivement).
unsigned int xdr_getpos(XDR *xdrs);
Une macro qui invoque la routine d'obtention de position associée au flux XDR, xdrs. La routine renvoie un entier non signé, qui indique la position du flux d'octets XDR. Une caractéristique souhaitable des flux XDR est que l'arithmétique simple fonctionne avec ce nombre, bien que les instances de flux XDR n'aient pas à garantir cela.
long *xdr_inline(XDR *xdrs, int len);
Une macro qui invoque la routine inline associée au flux XDR, xdrs. La routine renvoie un pointeur vers un morceau contigu du tampon du flux ; len est la longueur en octets du tampon désiré. Note : le pointeur est converti en long *.
Avertissement : xdr_inline() peut renvoyer NULL (0) s'il ne peut pas allouer un morceau contigu de tampon. Par conséquent, le comportement peut varier entre les instances de flux ; il existe pour des raisons d'efficacité.
bool_t xdr_int(XDR *xdrs, int *ip);
Un filtre primitif qui traduit entre les entiers C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_long(XDR *xdrs, long *lp);
Un filtre primitif qui traduit entre les entiers long C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux sont écrites, ou lues, à partir d'un bloc de mémoire à l'emplacement addr dont la longueur ne dépasse pas size octets. L'opérande op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, soit XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Un filtre primitif qui traduit entre des données opaques de taille fixe et leur représentation externe. L'argument cp est l'adresse de l'objet opaque, et cnt est sa taille en octets. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Comme xdr_reference() sauf qu'il sérialise les pointeurs nuls, tandis que xdr_reference() ne le fait pas. Ainsi, xdr_pointer() peut représenter des structures de données récursives, telles que des arbres binaires ou des listes chaînées.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux sont écrites dans un tampon de taille sendsize ; une valeur nulle indique que le système doit utiliser une valeur par défaut appropriée. Les données du flux sont lues à partir d'un tampon de taille recvsize ; il peut également être défini à une valeur par défaut appropriée en passant une valeur nulle. Lorsqu'un tampon de sortie de flux est plein, writeit est appelé. De même, lorsqu'un tampon d'entrée de flux est vide, readit est appelé. Le comportement de ces deux routines est similaire aux appels système read(2) et write(2), sauf que handle est passé aux routines précédentes comme premier argument. Note : le champ op du flux XDR doit être défini par l'appelant.
Avertissement : pour lire à partir d'un flux XDR créé par cette API, vous devrez appeler xdrrec_skiprecord() avant d'appeler toute autre API XDR. Cela insère des octets supplémentaires dans le flux pour fournir une limite d'enregistrement

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE ET DESCRIPTION

Les routines de filtrage XDR sont des routines de service qui traduisent entre les structures C et leur représentation externe. Les routines d'encodage XDR peuvent être classées en deux catégories : primitives et routines de création de flux. Les primitives sont généralement utilisées dans les macros XDR, tandis que les routines de création de flux initialisent une structure XDR.

bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Une primitive qui traduit entre les énumérations C et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_float(XDR *xdrs, float *fp);
Une primitive qui traduit entre les flottants C et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
void xdr_free(xdrproc_t proc, char *objp);
Libère l'espace alloué par une routine d'encodage XDR. L'argument proc est la routine d'encodage XDR qui a été utilisée pour allouer l'objet pointé par objp. Une valeur NULL peut être passée pour proc afin de libérer la mémoire pour des types simples tels que les chaînes de caractères et les opaque XDR.
unsigned int xdr_getpos(XDR *xdrs);
Une macro qui appelle la routine d'obtention de position associée au flux XDR xdrs. La valeur de retour est la position actuelle dans le flux XDR. Cette valeur peut ensuite être passée à la macro xdr_setpos(). Notez que tous les flux XDR ne supportent pas la définition de position.
char *xdr_inline(XDR *xdrs, unsigned int len);
Retourne un pointeur vers un tampon de longueur len octets. Cette routine est utilisée pour l'encodage/décodage de données dans le tampon directement sans avoir à effectuer une copie de données. La routine d'encodage XDR doit utiliser ce tampon pour sa représentation externe. Ceci est utile pour les champs de longueur fixe. Si l'encodage XDR ne peut pas fournir un tampon en ligne, elle retourne NULL. Notez que si une routine d'encodage XDR retourne non-NULL, elle doit compléter le transfert de données avant que le tampon ne soit réutilisé par une autre routine d'encodage XDR.
bool_t xdr_int(XDR *xdrs, int *ip);
Une primitive qui traduit entre les entiers C et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_long(XDR *xdrs, long *lp);
Une primitive qui traduit entre les entiers longs C et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
void xdrmem_create(XDR *xdrs, const char *addr, unsigned int len,
                   enum xdr_op op);
Initialise le flux XDR pour fonctionner sur un tampon mémoire statique. L'argument addr est l'adresse du tampon, et len est la longueur du tampon. L'argument op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, ou XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, const char *cp, unsigned int len);
Une primitive qui traduit entre des tableaux opaques de longueur fixe et leur représentation externe. L'argument cp est l'adresse de la donnée, et len est la longueur en octets de la donnée. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_pointer(XDR *xdrs, char **pp, unsigned int size,
                   xdrproc_t proc);
Similaire à xdr_reference, mais gère correctement les pointeurs NULL.
bool_t xdrrec_create(XDR *xdrs, unsigned int hwm,
                     char *rlimit, char *(*readit)(XDR *, char *, unsigned int),
                     void (*writeit)(XDR *, char *, unsigned int),
                     void (*destroyit)(XDR *));
Initialise un flux XDR pour l'encodage/décodage de données par enregistrement. L'argument hwm est la taille de fenêtre haute de tampon. L'argument rlimit est une valeur qui limite la taille d'un enregistrement d'entrée. Les arguments readit, writeit et destroyit sont des routines de rappel pour lire, écrire et détruire le flux, respectivement. Notez que l'utilisation de ces routines nécessite une bonne compréhension de l'implémentation XDR.
Notez que les flux XDR créés avec différentes API xdr*_create ne sont pas compatibles pour la même raison.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
Cette routine ne peut être invoquée que sur des flux créés par xdrrec_create(). Les données dans le tampon de sortie sont marquées comme un enregistrement terminé, et le tampon de sortie est optionnellement vidé si sendnow est différent de zéro. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdrrec_eof(XDR *xdrs);
Cette routine ne peut être invoquée que sur des flux créés par xdrrec_create(). Après avoir consommé le reste de l'enregistrement courant dans le flux, cette routine retourne un si le flux n'a plus d'entrée, zéro sinon.
bool_t xdrrec_skiprecord(XDR *xdrs);
Cette routine ne peut être invoquée que sur des flux créés par xdrrec_create(). Elle indique à l'implémentation XDR que le reste de l'enregistrement courant dans le tampon d'entrée du flux doit être ignoré. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Une primitive qui permet de suivre les pointeurs au sein des structures. L'argument pp est l'adresse du pointeur ; size est le sizeof de la structure vers laquelle pointe *pp ; et proc est une procédure XDR qui filtre la structure entre sa forme C et sa représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
Avertissement : cette routine ne gère pas les pointeurs NULL. Utilisez plutôt xdr_pointer().
xdr_setpos(XDR *xdrs, unsigned int pos);
Une macro qui appelle la routine de définition de position associée au flux XDR xdrs. L'argument pos est une valeur de position obtenue à partir de xdr_getpos(). Cette routine retourne un si le flux XDR a pu être repositionné, et zéro sinon.
Avertissement : il est difficile de repositionner certains types de flux XDR, donc cette routine peut échouer avec un type de flux et réussir avec un autre.
bool_t xdr_short(XDR *xdrs, short *sp);
Une primitive de filtrage qui traduit entre les entiers short C et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux XDR sont écrites, ou lues à partir, du flux stdio file. L'argument op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, ou XDR_FREE).
Avertissement : la routine de destruction associée à de tels flux XDR appelle fflush(3) sur le flux file, mais jamais fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Une primitive qui traduit entre les chaînes C et leur représentation externe correspondante. Les chaînes ne peuvent pas être plus longues que maxsize. Remarque : sp est l'adresse du pointeur de la chaîne. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Une primitive de filtrage qui traduit entre les caractères C unsigned et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Une primitive de filtrage qui traduit entre les entiers C unsigned et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Une primitive de filtrage qui traduit entre les entiers longs C unsigned et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Une primitive de filtrage qui traduit entre les entiers short C unsigned et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* peut être NULL */
Une primitive de filtrage qui traduit entre une union C discriminée et sa représentation externe correspondante. Elle traduit d'abord le discriminant de l'union situé à dscmp. Ce discriminant est toujours un enum_t. Ensuite, l'union située à unp est traduite. L'argument choices est un pointeur vers un tableau de structures xdr_discrim(). Chaque structure contient une paire ordonnée de [valeur,proc]. Si le discriminant de l'union est égal à la valeur associée, alors proc est appelée pour traduire l'union. La fin du tableau de structures xdr_discrim() est dénotée par une routine de valeur NULL. Si le discriminant n'est pas trouvé dans le tableau choices, alors la procédure defaultarm est appelée (si elle n'est pas NULL). Retourne un si elle réussit, zéro sinon.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Une primitive de filtrage qui traduit entre les tableaux de longueur fixe et leur représentation externe correspondante. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que size est le nombre d'éléments du tableau. L'argument elsize est le sizeof de chacun des éléments du tableau, et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_void(void);
Cette routine retourne toujours un. Elle peut être passée à des routines RPC qui nécessitent un argument de fonction, où rien ne doit être fait.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Une primitive qui appelle xdr_string(xdrs, sp,MAXUN.UNSIGNED ); où MAXUN.UNSIGNED est la valeur maximale d'un entier non signé. xdr_wrapstring() est pratique car le package RPC passe un maximum de deux routines XDR comme arguments, et xdr_string(), l'une des primitives les plus fréquemment utilisées, en nécessite trois. Retourne un si elle réussit, zéro sinon.
