NOM

xdg-user-dirs-update - Mettre à jour la configuration des répertoires utilisateur XDG

SYNTAXE

xdg-user-dirs-update [OPTION...] [--set NOM CHEMIN...]

DESCRIPTION

xdg-user-dirs-update met à jour l'état actuel du fichier user-dirs.dirs de l'utilisateur. S'il n'en existait aucun auparavant, un est créé en se basant sur les valeurs par défaut du système, ou en utilisant les anciens noms de fichiers non traduits si de tels répertoires existent. La liste des anciens répertoires utilisés est : ~/Desktop, ~/Templates et ~/Public.

Si une configuration existante est trouvée, elle est mise à jour avec tous les nouveaux répertoires par défaut. De plus, tous les répertoires configurés qui pointent vers des emplacements inexistants sont réinitialisés en les faisant pointer vers le répertoire personnel de l'utilisateur. Cela se produit généralement lorsque l'utilisateur a supprimé le répertoire, il ne souhaite donc probablement plus l'utiliser.

Lors de la première exécution, un fichier user-dirs.locale est créé contenant la locale qui a été utilisée pour la traduction. Ceci est utilisé plus tard par des outils graphiques comme xdg-user-dirs-gtk-update pour détecter si la locale a changé, vous permettant de migrer depuis les anciens noms.

xdg-user-dirs-update est normalement exécuté automatiquement au début d'une session utilisateur pour mettre à jour les répertoires utilisateur XDG en fonction de la locale de l'utilisateur.

OPTIONS

Les options suivantes sont comprises :

--help

Affiche l'aide et quitte.

--force

Met à jour le fichier user-dirs.dirs existant, mais force une réinitialisation complète. Cela signifie : Ne pas réinitialiser les répertoires inexistants à HOME, mais plutôt recréer le répertoire. Ne jamais utiliser les noms non traduits rétrocompatibles. Toujours recréer user-dirs.locale.

--dummy-output CHEMIN

Écrit la configuration dans CHEMIN au lieu du fichier de configuration par défaut. De plus, aucun répertoire n'est créé.

--set NOM CHEMIN

Définit le répertoire utilisateur XDG avec le nom donné.

NOM doit être l'un des suivants :

DESKTOP
DOWNLOAD
TEMPLATES
PUBLICSHARE
DOCUMENTS
MUSIC
PICTURES
VIDEOS

CHEMIN doit être un chemin absolu, par exemple $HOME/Some/Directory.

FICHIERS

La configuration des répertoires utilisateur XDG est stockée dans le fichier user-dirs.dirs à l'emplacement indiqué par la variable d'environnement XDG_CONFIG_HOME.

ENVIRONNEMENT

La variable d'environnement XDG_CONFIG_HOME détermine où se trouve le fichier user-dirs.dirs.

VOIR AUSSI

xdg-user-dir(1), user-dirs.dirs(5), user-dirs.defaults(5), user-dirs.conf(5).
