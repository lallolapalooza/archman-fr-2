xdr(3) Manuel des fonctions de bibliothèque xdr(3)

NOM

xdr — routines de bibliothèque pour la représentation externe des données

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS ET DESCRIPTION

Ces routines permettent aux programmeurs C de décrire des structures de données arbitraires de manière indépendante de la machine. Les données pour les appels de procédure distante sont transmises en utilisant ces routines.

Les prototypes ci-dessous sont déclarés dans <rpc/xdr.h> et utilisent les types suivants :

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Pour la déclaration du type XDR, voir <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Une primitive de filtrage qui traduit entre les tableaux de longueur variable et leurs représentations externes correspondantes. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que sizep est l'adresse du compteur d'éléments du tableau ; ce compteur d'éléments ne peut pas dépasser maxsize. L'argument elsize est la taille en octets de chaque élément du tableau, et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Une primitive de filtrage qui traduit entre les booléens (entiers C) et leurs représentations externes. Lors de l'encodage des données, ce filtre produit les valeurs un ou zéro. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Une primitive de filtrage qui traduit entre les chaînes d'octets comptées et leurs représentations externes. L'argument sp est l'adresse du pointeur de chaîne. La longueur de la chaîne est située à l'adresse sizep ; les chaînes ne peuvent pas être plus longues que maxsize. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_char(XDR *xdrs, char *cp);
Une primitive de filtrage qui traduit entre les caractères C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon. Note : les caractères encodés ne sont pas compactés et occupent 4 octets chacun. Pour les tableaux de caractères, il est judicieux d'envisager xdr_bytes(), xdr_opaque(), ou xdr_string().
void xdr_destroy(XDR *xdrs);
Une macro qui appelle la routine de destruction associée au flux XDR, xdrs. La destruction implique généralement la libération des structures de données privées associées au flux. L'utilisation de xdrs après l'appel de xdr_destroy() n'est pas définie.
bool_t xdr_double(XDR *xdrs, double *dp);
Une primitive de filtrage qui traduit entre les nombres à virgule flottante double précision C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Une primitive de filtrage qui traduit entre les énumérations C (en fait, des entiers) et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_float(XDR *xdrs, float *fp);
Une primitive de filtrage qui traduit entre les nombres flottants simples précision C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
void xdr_free(xdrproc_t proc, char *objp);
Routine de libération générique. Le premier argument est la routine XDR pour l'objet à libérer. Le second argument est un pointeur vers l'objet lui-même. Note : le pointeur passé à cette routine n'est *pas* libéré, mais ce qu'il pointe *est* libéré (récursivement).
unsigned int xdr_getpos(XDR *xdrs);
Une macro qui appelle la routine d'obtention de position associée au flux XDR, xdrs. La routine retourne un entier non signé, qui indique la position du flux d'octets XDR. Une caractéristique souhaitable des flux XDR est que l'arithmétique simple fonctionne avec ce nombre, bien que les instances de flux XDR n'aient pas l'obligation de garantir cela.
long *xdr_inline(XDR *xdrs, int len);
Une macro qui appelle la routine en ligne associée au flux XDR, xdrs. La routine retourne un pointeur vers un bloc contigu du tampon du flux ; len est la longueur en octets du tampon désiré. Note : le pointeur est converti en long *.
Attention : xdr_inline() peut retourner NULL (0) s'il ne parvient pas à allouer un bloc contigu de tampon. Par conséquent, le comportement peut varier selon les instances de flux ; elle existe pour des raisons d'efficacité.
bool_t xdr_int(XDR *xdrs, int *ip);
Une primitive de filtrage qui traduit entre les entiers C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_long(XDR *xdrs, long *lp);
Une primitive de filtrage qui traduit entre les entiers long C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux sont écrites ou lues à partir d'un bloc de mémoire à l'emplacement addr dont la longueur ne dépasse pas size octets. L'opérateur op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, soit XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Une primitive de filtrage qui traduit entre des données opaques de taille fixe et leur représentation externe. L'argument cp est l'adresse de l'objet opaque, et cnt est sa taille en octets. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Comme xdr_reference() sauf qu'elle sérialise les pointeurs nuls, alors que xdr_reference() ne le fait pas. Ainsi, xdr_pointer() peut représenter des structures de données récursives, telles que des arbres binaires ou des listes chaînées.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux sont écrites dans un tampon de taille sendsize ; une valeur zéro indique que le système doit utiliser une valeur par défaut appropriée. Les données du flux sont lues à partir d'un tampon de taille recvsize ; celui-ci peut également être défini sur une valeur par défaut appropriée en passant une valeur zéro. Lorsqu'un tampon de sortie du flux est plein, writeit est appelé. De même, lorsqu'un tampon d'entrée du flux est vide, readit est appelé. Le comportement de ces deux routines est similaire aux appels système read(2) et write(2), sauf que handle est passé aux routines précédentes comme premier argument. Note : le champ op du flux XDR doit être défini par l'appelant.
Attention : pour lire à partir d'un flux XDR créé par cette API, vous devrez d'abord appeler xdrrec_skiprecord() avant d'appeler toute autre API XDR. Cela insère des octets supplémentaires dans le flux pour fournir des limites d'enregistrement.
bool_t xdr_reference(XDR *xdrs, char **objpp,
                     unsigned int objsize, xdrproc_t xdrobj);
Cette routine filtre une référence à un objet, où objpp est l'adresse du pointeur vers l'objet, objsize est la taille de l'objet en octets, et xdrobj est la routine XDR pour cet objet. Si le pointeur est NULL, cette routine ne fait rien. Pour les flux XDR d'encodage et de décodage, la valeur de la référence n'est pas modifiée. Cette routine est utile pour encoder des structures de données dans lesquelles la même donnée peut être référencée plusieurs fois.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Une macro qui appelle la routine de définition de position associée au flux XDR, xdrs. La routine définit la position du flux d'octets XDR à pos. Note : cette routine n'est pas disponible pour tous les types de flux XDR.
bool_t xdr_short(XDR *xdrs, short *sp);
Une primitive de filtrage qui traduit entre les entiers short C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_sizeof(XDR *xdrs, unsigned int *sizep);
Cette routine calcule la taille en octets d'un objet C lors de sa traduction selon le filtre XDR spécifié.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Une primitive de filtrage qui traduit entre des chaînes de caractères C null-terminated et leur représentation externe. L'argument sp est l'adresse du pointeur de chaîne. La longueur de la chaîne ne peut pas dépasser maxsize. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_u_char(XDR *xdrs, unsigned char *cp);
Identique à xdr_char() mais pour les caractères non signés.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Une primitive de filtrage qui traduit entre les entiers C non signés et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Une primitive de filtrage qui traduit entre les entiers long non signé C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_vector(XDR *xdrs, char *cp, unsigned int size,
                  unsigned int maxsize, xdrproc_t xdr);
Il s'agit d'un alias pour xdr_bytes().
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Comme xdr_string() mais sans limite de taille.

SYNTAXIS ET DESCRIPTION

#include <rpc/xdr.h>
void xdr_destroy(XDR *xdrs);
Libère les ressources associées au flux XDR xdrs. La routine de destruction associée au flux XDR est appelée.
bool_t xdr_free(char *addr);
Libère la mémoire allouée par une opération XDR. Le programmeur est responsable de l'allocation de mémoire pour la structure de données avant de la décoder. Pour les structures qui contiennent des pointeurs, il peut être nécessaire d'appeler xdr_free() pour libérer la mémoire allouée par le système RPC lors du décodage. Pour appeler xdr_free(), il faut connaître la procédure XDR appropriée pour la structure de données.
bool_t xdr_getpos(XDR *xdrs, unsigned int *pos);
Renvoie la position actuelle dans le flux XDR xdrs, stockée dans la variable pointée par pos. Cette routine est utile pour les flux qui peuvent être repositionnés, tels que les flux XDR créés avec xdrmem_create(). Elle renvoie 1 si elle réussit, 0 sinon.
bool_t xdr_inline(XDR *xdrs, unsigned int len);
Demande un bloc contigu de len octets du flux XDR xdrs. La routine XDR doit renvoyer un pointeur vers ce bloc. Cette routine est la principale méthode d'optimisation des performances dans le système XDR, car elle permet d'éviter la copie de données. Elle renvoie un pointeur vers le bloc si une telle allocation est possible, et NULL sinon. Le programmeur doit utiliser la valeur renvoyée avec précaution, car elle peut ne pas être valide après l'opération XDR suivante.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Définit la position dans le flux XDR xdrs à pos. La valeur de pos doit avoir été précédemment obtenue à l'aide de xdr_getpos(). Cette routine est utile pour les flux qui peuvent être repositionnés, tels que les flux XDR créés avec xdrmem_create(). Elle renvoie 1 si elle réussit, 0 sinon.
Note : La repositionnement n'est pas garanti pour tous les types de flux XDR.
void xdrmem_create(XDR *xdrs, const char *addr, unsigned int size,
                   enum xdr_op op);
Initialise le flux XDR xdrs pour opérer sur un tampon mémoire. Le tampon mémoire est spécifié par addr et size. L'argument op détermine la direction du flux XDR (XDR_ENCODE, XDR_DECODE, ou XDR_FREE).
bool_t xdrrec_create(XDR *xdrs, unsigned int sendsize, unsigned int recsz,
                     char *handle, int (*readit)(), int (*writeit)());
Initialise le flux XDR xdrs pour utiliser un codage par enregistrements. Cela permet d'envoyer et de recevoir des données dans des enregistrements de taille arbitraire, même si le protocole de transport sous-jacent ne le prend pas en charge. Les enregistrements sont séparés par un indicateur de fin d'enregistrement. Les arguments sendsize et recsz spécifient les tailles des tampons d'envoi et de réception. L'argument handle est un pointeur vers des données définies par l'utilisateur qui sont passées aux routines readit et writeit. Les routines readit et writeit sont des routines de rappel pour lire et écrire des données depuis et vers le flux sous-jacent.
Note : L'utilisation de ce constructeur est généralement moins efficace que l'utilisation des constructeurs XDR standards. En général, tous les flux XDR créés avec la même routine xdr_*_create sont compatibles. Cependant, les flux XDR créés avec différentes routines xdr_*_create ne sont pas compatibles pour la même raison.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
Cette routine ne peut être appelée que sur des flux créés par xdrrec_create(). Les données dans le tampon de sortie sont marquées comme un enregistrement terminé, et le tampon de sortie est éventuellement écrit si sendnow est différent de zéro. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdrrec_eof(XDR *xdrs);
Cette routine ne peut être appelée que sur des flux créés par xdrrec_create(). Après avoir consommé le reste de l'enregistrement courant dans le flux, cette routine renvoie un si le flux n'a plus d'entrée, zéro sinon.
bool_t xdrrec_skiprecord(XDR *xdrs);
Cette routine ne peut être appelée que sur des flux créés par xdrrec_create(). Elle indique à l'implémentation XDR que le reste de l'enregistrement courant dans le tampon d'entrée du flux doit être ignoré. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Une primitive qui permet de suivre des pointeurs dans des structures. L'argument pp est l'adresse du pointeur ; size est la taille en octets de la structure vers laquelle pointe *pp ; et proc est une procédure XDR qui filtre la structure entre sa forme C et sa représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
Attention : cette routine ne gère pas les pointeurs NULL. Utilisez plutôt xdr_pointer().
xdr_setpos(XDR *xdrs, unsigned int pos);
Une macro qui appelle la routine de définition de position associée au flux XDR xdrs. L'argument pos est une valeur de position obtenue à partir de xdr_getpos(). Cette routine renvoie un si le flux XDR a pu être repositionné, et zéro sinon.
Attention : il est difficile de repositionner certains types de flux XDR, donc cette routine peut échouer avec un type de flux et réussir avec un autre.
bool_t xdr_short(XDR *xdrs, short *sp);
Une primitive de filtrage qui traduit entre les entiers courts C (short) et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux XDR sont écrites dans, ou lues depuis, le flux stdio file. L'argument op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, ou XDR_FREE).
Attention : la routine de destruction associée à de tels flux XDR appelle fflush(3) sur le flux file, mais jamais fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Une primitive de filtrage qui traduit entre les chaînes C et leurs représentations externes correspondantes. Les chaînes ne peuvent pas être plus longues que maxsize. Note : sp est l'adresse du pointeur de la chaîne. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Une primitive de filtrage qui traduit entre les caractères C non signés (unsigned) et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Une primitive de filtrage qui traduit entre les entiers C non signés (unsigned) et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Une primitive de filtrage qui traduit entre les entiers longs C non signés (unsigned long) et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Une primitive de filtrage qui traduit entre les entiers courts C non signés (unsigned short) et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* peut être NULL */
Une primitive de filtrage qui traduit entre un C union discriminé et sa représentation externe correspondante. Elle traduit d'abord le discriminant de l'union situé à dscmp. Ce discriminant est toujours un enum_t. Ensuite, l'union située à unp est traduite. L'argument choices est un pointeur vers un tableau de structures xdr_discrim(). Chaque structure contient une paire ordonnée [value,proc]. Si le discriminant de l'union est égal à la value associée, alors la proc est appelée pour traduire l'union. La fin du tableau de structures xdr_discrim() est dénotée par une routine de valeur NULL. Si le discriminant n'est pas trouvé dans le tableau choices, alors la procédure defaultarm est appelée (si elle n'est pas NULL). Renvoie un si elle réussit, zéro sinon.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Une primitive de filtrage qui traduit entre les tableaux de longueur fixe et leurs représentations externes correspondantes. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que size est le nombre d'éléments du tableau. L'argument elsize est la taille en octets de chaque élément du tableau, et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_void(void);
Cette routine renvoie toujours un. Elle peut être passée à des routines RPC qui nécessitent un argument de fonction, où rien ne doit être fait.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Une primitive qui appelle xdr_string(xdrs, sp, MAXUN.UNSIGNED); où MAXUN.UNSIGNED est la valeur maximale d'un entier non signé. xdr_wrapstring() est pratique car le package RPC passe un maximum de deux routines XDR en tant qu'arguments, et xdr_string(), l'une des primitives les plus fréquemment utilisées, en nécessite trois. Renvoie un si elle réussit, zéro sinon.
