xdr(3) Manuel des fonctions de bibliothèque xdr(3)

NOM

xdr — routines de bibliothèque pour la représentation externe des données

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS ET DESCRIPTION

Ces routines permettent aux programmeurs C de décrire des structures de données arbitraires d'une manière indépendante de la machine. Les données pour les appels de procédure distante sont transmises en utilisant ces routines.

Les prototypes ci-dessous sont déclarés dans <rpc/xdr.h> et utilisent les types suivants :

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Pour la déclaration du type XDR, voir <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Une primitive de filtre qui traduit entre les tableaux de longueur variable et leurs représentations externes correspondantes. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que sizep est l'adresse du compteur d'éléments du tableau ; ce compteur ne peut pas dépasser maxsize. L'argument elsize est le sizeof de chacun des éléments du tableau, et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Une primitive de filtre qui traduit entre les booléens (entiers C) et leurs représentations externes. Lors de l'encodage des données, ce filtre produit les valeurs un ou zéro. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Une primitive de filtre qui traduit entre les chaînes d'octets comptées et leurs représentations externes. L'argument sp est l'adresse du pointeur de chaîne. La longueur de la chaîne se trouve à l'adresse sizep ; les chaînes ne peuvent pas être plus longues que maxsize. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_char(XDR *xdrs, char *cp);
Une primitive de filtre qui traduit entre les caractères C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon. Note : les caractères encodés ne sont pas compressés et occupent 4 octets chacun. Pour les tableaux de caractères, il est intéressant de considérer xdr_bytes(), xdr_opaque(), ou xdr_string().
void xdr_destroy(XDR *xdrs);
Une macro qui appelle la routine de destruction associée au flux XDR, xdrs. La destruction implique généralement la libération des structures de données privées associées au flux. L'utilisation de xdrs après l'appel de xdr_destroy() est indéfinie.
bool_t xdr_double(XDR *xdrs, double *dp);
Une primitive de filtre qui traduit entre les nombres C de type double et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Une primitive de filtre qui traduit entre les énumérations C (en fait des entiers) et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_float(XDR *xdrs, float *fp);
Une primitive de filtre qui traduit entre les nombres C de type float et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
void xdr_free(xdrproc_t proc, char *objp);
Routine de libération générique. Le premier argument est la routine XDR pour l'objet à libérer. Le second argument est un pointeur vers l'objet lui-même. Note : le pointeur passé à cette routine n'est pas libéré, mais ce à quoi il pointe est libéré (récursivement).
unsigned int xdr_getpos(XDR *xdrs);
Une macro qui appelle la routine d'obtention de position associée au flux XDR, xdrs. La routine retourne un entier non signé, qui indique la position du flux d'octets XDR. Une caractéristique souhaitable des flux XDR est que l'arithmétique simple fonctionne avec ce nombre, bien que les instances de flux XDR n'aient pas à garantir cela.
long *xdr_inline(XDR *xdrs, int len);
Une macro qui appelle la routine inline associée au flux XDR, xdrs. La routine retourne un pointeur vers une portion contiguë du tampon du flux ; len est la longueur en octets du tampon désiré. Note : le pointeur est transtypé en long *.
Avertissement : xdr_inline() peut retourner NULL (0) s'il ne peut pas allouer une portion contiguë d'un tampon. Par conséquent, le comportement peut varier selon les instances de flux ; elle existe pour des raisons d'efficacité.
bool_t xdr_int(XDR *xdrs, int *ip);
Une primitive de filtre qui traduit entre les entiers C et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_long(XDR *xdrs, long *lp);
Une primitive de filtre qui traduit entre les entiers C de type long et leurs représentations externes. Cette routine retourne un si elle réussit, zéro sinon.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux sont écrites dans, ou lues à partir, d'un bloc de mémoire à l'emplacement addr dont la longueur ne dépasse pas size octets. L'argument op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, soit XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Une primitive de filtre qui traduit entre des données opaques de taille fixe et leur représentation externe. L'argument cp est l'adresse de l'objet opaque, et cnt est sa taille en octets. Cette routine retourne un si elle réussit, zéro sinon.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similaire à xdr_reference() sauf qu'elle sérialise les pointeurs nuls, tandis que xdr_reference() ne le fait pas. Ainsi, xdr_pointer() peut représenter des structures de données récursives, comme des arbres binaires ou des listes chaînées.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux sont écrites dans un tampon de taille sendsize ; une valeur de zéro indique que le système doit utiliser une valeur par défaut appropriée. Les données du flux sont lues à partir d'un tampon de taille recvsize ; celui-ci peut également être défini sur une valeur par défaut appropriée en passant une valeur zéro. Lorsqu'un tampon de sortie du flux est plein, writeit est appelé. De même, lorsqu'un tampon d'entrée du flux est vide, readit est appelé. Le comportement de ces deux routines est similaire aux appels système read(2) et write(2), sauf que handle est passé aux premières routines comme premier argument. Note : le champ op du flux XDR doit être défini par l'appelant.
Avertissement : pour lire à partir d'un flux XDR créé par cette API, vous devrez d'abord appeler xdrrec_skiprecord() avant d'appeler toute autre API XDR. Cela insère des octets supplémentaires dans le flux pour fournir la frontière d'enregistrement.

BIBLIOTHQUE

Bibliothèque C standard (libucb, libc)

SYNTHSE ET DESCRIPTION

Ces routines fournissent l'interface d'une bibliothèque pour la représentation externe des données (XDR). Elles sont utilisées pour encoder et décoder des structures de données C pour la transmission sur un réseau. Les routines peuvent être divisées en trois catégories : les routines de création de flux XDR, les routines de filtrage XDR et les routines d'interface XDR.

Les routines de création de flux XDR sont :

        bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *size,
                         unsigned int maxsize, xdrproc_t elproc);
        bool_t xdr_bool(XDR *xdrs, bool_t *bp);
        bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *size,
                         unsigned int maxsize);
        bool_t xdr_char(XDR *xdrs, char *cp);
        void xdr_create(XDR *xdrs, xdr_op_t op, xdr_ops_t *ops);
        void xdr_destroy(XDR *xdrs);
        bool_t xdr_double(XDR *xdrs, double *dp);
        bool_t xdr_enum(XDR *xdrs, enum_t *ep);
        bool_t xdr_float(XDR *xdrs, float *fp);
        void xdr_free(xdrproc_t proc, char *ptr);
        unsigned int xdr_getpos(XDR *xdrs);
        bool_t xdr_inline(XDR *xdrs, unsigned int len);
        bool_t xdr_int(XDR *xdrs, int *ip);

        bool_t xdrrec_create(XDR *xdrs, unsigned int sendsize,

        bool_t xdr_short(XDR *xdrs, short *sp);
        void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);

        bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
        bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);

                         const struct xdr_discrim *choices,
                         xdrproc_t defaultarm);
        bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                          unsigned int elsize, xdrproc_t elproc);
        bool_t xdr_void(void);
        bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Les routines de création de flux XDR sont utilisées pour initialiser un objet XDR. Les routines xdrrec_create, xdrmem_create et xdrstdio_create initialisent des flux XDR pour des opérations d'enregistrement, de mémoire et de fichier standard, respectivement. La routine xdr_create est une routine de bas niveau pour créer un flux XDR à partir d'une structure d'opérations XDR fournie par l'utilisateur.
Notez que les flux XDR créés par différentes routines de création ne sont pas compatibles. Par exemple, un flux créé par xdrrec_create ne peut pas être utilisé avec xdrstdio_create et vice-versa. De même, les flux XDR créés avec différentes API xdr*_create ne sont pas compatibles pour la même raison.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
Cette routine ne peut être invoquée que sur les flux créés par xdrrec_create(). Les données dans le tampon de sortie sont marquées comme un enregistrement terminé, et le tampon de sortie est facultativement écrit si sendnow sendnow est non nul. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdrrec_eof(XDR *xdrs);
Cette routine ne peut être invoquée que sur les flux créés par xdrrec_create(). Après avoir consommé le reste de l'enregistrement courant dans le flux, cette routine renvoie un si le flux n'a plus d'entrée, zéro sinon.
bool_t xdrrec_skiprecord(XDR *xdrs);
Cette routine ne peut être invoquée que sur les flux créés par xdrrec_create(). Elle indique à l'implémentation XDR que le reste de l'enregistrement courant dans le tampon d'entrée du flux doit être supprimé. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
Un primitif qui fournit un suivi de pointeur au sein des structures. L'argument pp pp est l'adresse du pointeur ; size size est la taille (sizeof) de la structure vers laquelle pointe *pp ; et proc proc est une procédure XDR qui filtre la structure entre sa forme C et sa représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
Attention : cette routine ne comprend pas les pointeurs nuls. Utilisez xdr_pointer() à la place.
xdr_setpos(XDR *xdrs, unsigned int pos);
Une macro qui invoque la routine de définition de position associée au flux XDR xdrs xdrs . L'argument pos pos est une valeur de position obtenue à partir de xdr_getpos(). Cette routine renvoie un si le flux XDR a pu être repositionné, et zéro sinon.
Attention : il est difficile de repositionner certains types de flux XDR, donc cette routine peut échouer avec un type de flux et réussir avec un autre.
bool_t xdr_short(XDR *xdrs, short *sp);
Un primitif de filtrage qui traduit entre les entiers courts (short) C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
Cette routine initialise l'objet de flux XDR pointé par xdrs xdrs . Les données du flux XDR sont écrites, ou lues, dans le flux stdio stdio file file . L'argument op op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, ou XDR_FREE).
Attention : la routine de destruction associée à de tels flux XDR appelle fflush(3) sur le flux file file , mais jamais fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Un primitif de filtrage qui traduit entre les chaînes C et leurs représentations externes correspondantes. Les chaînes ne peuvent pas être plus longues que maxsize maxsize . Note : sp sp est l'adresse du pointeur de la chaîne. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
Un primitif de filtrage qui traduit entre les caractères C non signés (unsigned) et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Un primitif de filtrage qui traduit entre les entiers C non signés (unsigned) et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
Un primitif de filtrage qui traduit entre les entiers longs non signés (unsigned long) C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
Un primitif de filtrage qui traduit entre les entiers courts non signés (unsigned short) C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* peut être NULL */
Un primitif de filtrage qui traduit entre une union C discriminée et sa représentation externe correspondante. Il traduit d'abord le discriminant de l'union situé à dscmp dscmp . Ce discriminant est toujours un enum_t. Ensuite, l'union située à unp unp est traduite. L'argument choices choices est un pointeur vers un tableau de structures xdr_discrim. Chaque structure contient une paire ordonnée de [ value value , proc proc ]. Si le discriminant de l'union est égal à la value value associée, alors la procédure proc proc est appelée pour traduire l'union. La fin du tableau de structures xdr_discrim est marquée par une procédure de valeur NULL. Si le discriminant n'est pas trouvé dans le tableau choices choices , alors la procédure defaultarm est appelée (si elle n'est pas NULL). Renvoie un si elle réussit, zéro sinon.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
Un primitif de filtrage qui traduit entre les tableaux de longueur fixe et leurs représentations externes correspondantes. L'argument arrp arrp est l'adresse du pointeur vers le tableau, tandis que size size est le nombre d'éléments du tableau. L'argument elsize elsize est la taille (sizeof) de chacun des éléments du tableau, et elproc elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_void(void);
Cette routine renvoie toujours un. Elle peut être passée à des routines RPC qui nécessitent un argument de fonction, où rien ne doit être fait.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Un primitif qui appelle xdr_string(xdrs, sp, MAXUN.UNSIGNED); où MAXUN.UNSIGNED est la valeur maximale d'un entier non signé. xdr_wrapstring() est pratique car le package RPC passe un maximum de deux routines XDR comme arguments, et xdr_string(), l'un des primitifs les plus fréquemment utilisés, en nécessite trois. Renvoie un si elle réussit, zéro sinon.
