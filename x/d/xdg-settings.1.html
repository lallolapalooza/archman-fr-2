NOM

xdg-settings - obtenir divers paramètres de l'environnement de bureau

SYNTAXE

xdg-settings {get | check | set} {propriété} [sous-propriété] [valeur]

xdg-settings {--help | --list | --manual | --version}

DESCRIPTION

xdg-settings obtient divers paramètres de l'environnement de bureau. Par exemple, les environnements de bureau fournissent souvent des configurations de proxy et les paramètres du navigateur web par défaut. En utilisant xdg-settings, ces paramètres peuvent être extraits pour être utilisés par des applications qui n'utilisent pas les bibliothèques de l'environnement de bureau (qui utiliseraient les paramètres nativement).

xdg-settings est destiné à être utilisé uniquement à l'intérieur d'une session de bureau. Il n'est pas recommandé d'utiliser xdg-settings en tant que root.

OPTIONS

--help

Affiche la syntaxe de la commande.

--list

Liste toutes les propriétés que xdg-settings connaît.

--manual

Affiche cette page de manuel.

--version

Affiche les informations de version de xdg-utils.

PROPRIÉTÉS

Lors de l'utilisation de xdg-settings pour obtenir, vérifier ou définir un paramètre de bureau, les propriétés et éventuellement les sous-propriétés sont utilisées pour spécifier le paramètre à modifier.

Certaines propriétés (comme default-web-browser) décrivent entièrement le paramètre à modifier. D'autres propriétés (comme default-url-scheme-handler) nécessitent des informations supplémentaires (dans ce cas, le schéma réel pour lequel définir le gestionnaire par défaut) qui doivent être fournies dans une sous-propriété.

CODES DE RETOUR

Un code de retour de 0 indique le succès, tandis qu'un code de retour non nul indique un échec. Les codes d'échec suivants peuvent être retournés :

1

Erreur de syntaxe dans la ligne de commande.

2

Un des fichiers passés en ligne de commande n'existe pas.

3

Un outil requis n'a pas pu être trouvé.

4

L'action a échoué.

VOIR AUSSI

xdg-mime(1), xdg-open(1), Spécification des associations d'applications MIME[1]

EXEMPLES

Obtenir le nom du fichier de bureau du navigateur web par défaut actuel

        xdg-settings get default-web-browser

Vérifier si le navigateur web par défaut est firefox.desktop, ce qui peut être faux même si "get default-web-browser" indique que c'est la valeur actuelle (si seulement certains des paramètres sous-jacents reflètent réellement cette valeur)

        xdg-settings check default-web-browser firefox.desktop

Définir le navigateur web par défaut sur google-chrome.desktop

        xdg-settings set default-web-browser google-chrome.desktop

Définir le gestionnaire d'URL par défaut pour le schéma mailto sur evolution.desktop

        xdg-settings set default-url-scheme-handler mailto evolution.desktop
