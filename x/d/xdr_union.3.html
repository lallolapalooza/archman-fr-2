xdr(3) Manuel des fonctions de bibliothèque xdr(3)

NOM

xdr — routines de bibliothèque pour la représentation externe des données

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS ET DESCRIPTION

Ces routines permettent aux programmeurs C de décrire des structures de données arbitraires d'une manière indépendante de la machine. Les données pour les appels de procédure distante sont transmises en utilisant ces routines.

Les prototypes ci-dessous sont déclarés dans <rpc/xdr.h> et utilisent les types suivants :

typedef int bool_t;
typedef typeof(bool_t (XDR *, void *, ...))  *xdrproc_t;

Pour la déclaration du type XDR, voir <rpc/xdr.h>.

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *sizep,
                 unsigned int maxsize, unsigned int elsize,
                 xdrproc_t elproc);
Un filtre primitif qui traduit entre les tableaux de longueur variable et leurs représentations externes correspondantes. L'argument arrp est l'adresse du pointeur vers le tableau, tandis que sizep est l'adresse du compteur d'éléments du tableau ; ce compteur d'éléments ne peut pas dépasser maxsize. L'argument elsize est la taille (sizeof) de chaque élément du tableau, et elproc est un filtre XDR qui traduit entre la forme C des éléments du tableau et leur représentation externe. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
Un filtre primitif qui traduit entre les booléens (entiers C) et leurs représentations externes. Lors de l'encodage des données, ce filtre produit des valeurs de un ou zéro. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *sizep,
                 unsigned int maxsize);
Un filtre primitif qui traduit entre des chaînes d'octets comptées et leurs représentations externes. L'argument sp est l'adresse du pointeur de chaîne. La longueur de la chaîne se trouve à l'adresse sizep ; les chaînes ne peuvent pas être plus longues que maxsize. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_char(XDR *xdrs, char *cp);
Un filtre primitif qui traduit entre des caractères C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon. Remarque : les caractères encodés ne sont pas compactés et occupent 4 octets chacun. Pour les tableaux de caractères, il est judicieux d'envisager xdr_bytes(), xdr_opaque(), ou xdr_string().
void xdr_destroy(XDR *xdrs);
Une macro qui appelle la routine de destruction associée au flux XDR, xdrs. La destruction implique généralement la libération des structures de données privées associées au flux. L'utilisation de xdrs après l'appel à xdr_destroy() est indéfinie.
bool_t xdr_double(XDR *xdrs, double *dp);
Un filtre primitif qui traduit entre les nombres C de type double (double précision) et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
Un filtre primitif qui traduit entre les énumérations C (en fait, des entiers) et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_float(XDR *xdrs, float *fp);
Un filtre primitif qui traduit entre les nombres C de type float et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
void xdr_free(xdrproc_t proc, char *objp);
Routine de libération générique. Le premier argument est la routine XDR pour l'objet en cours de libération. Le second argument est un pointeur vers l'objet lui-même. Remarque : le pointeur passé à cette routine n'est pas libéré, mais ce qu'il pointe est libéré (récursivement).
unsigned int xdr_getpos(XDR *xdrs);
Une macro qui appelle la routine d'obtention de position associée au flux XDR, xdrs. La routine renvoie un entier non signé, qui indique la position du flux d'octets XDR. Une caractéristique souhaitable des flux XDR est que l'arithmétique simple fonctionne avec ce nombre, bien que les instances de flux XDR n'aient pas à garantir cela.
long *xdr_inline(XDR *xdrs, int len);
Une macro qui appelle la routine en ligne associée au flux XDR, xdrs. La routine renvoie un pointeur vers un bloc contigu du tampon du flux ; len est la longueur en octets du tampon désiré. Remarque : le pointeur est converti en long *.
Attention : xdr_inline() peut renvoyer NULL (0) s'il ne peut pas allouer un bloc contigu d'un tampon. Par conséquent, le comportement peut varier entre les instances de flux ; elle existe pour des raisons d'efficacité.
bool_t xdr_int(XDR *xdrs, int *ip);
Un filtre primitif qui traduit entre les entiers C et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_long(XDR *xdrs, long *lp);
Un filtre primitif qui traduit entre les entiers C de type long et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
void xdrmem_create(XDR *xdrs, char *addr, unsigned int size,
                   enum xdr_op op);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux sont écrites, ou lues, à partir d'un bloc de mémoire à l'emplacement addr dont la longueur ne dépasse pas size octets. L'opérateur op détermine la direction du flux XDR (soit XDR_ENCODE, XDR_DECODE, soit XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, char *cp, unsigned int cnt);
Un filtre primitif qui traduit entre des données opaques de taille fixe et leur représentation externe. L'argument cp est l'adresse de l'objet opaque, et cnt est sa taille en octets. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_pointer(XDR *xdrs, char **objpp,
                   unsigned int objsize, xdrproc_t xdrobj);
Similaire à xdr_reference() sauf qu'elle sérialise les pointeurs NULL, alors que xdr_reference() ne le fait pas. Ainsi, xdr_pointer() peut représenter des structures de données récursives, telles que des arbres binaires ou des listes chaînées.
void xdrrec_create(XDR *xdrs, unsigned int sendsize,
                   unsigned int recvsize, char *handle,
                   typeof(int (char *, char *, int)) *readit,
                   typeof(int (char *, char *, int)) *writeit);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Les données du flux sont écrites dans un tampon de taille sendsize ; une valeur de zéro indique que le système doit utiliser une valeur par défaut appropriée. Les données du flux sont lues à partir d'un tampon de taille recvsize ; celui-ci peut également être réglé sur une valeur par défaut appropriée en passant une valeur zéro. Lorsqu'un tampon de sortie de flux est plein, writeit est appelé. De même, lorsqu'un tampon d'entrée de flux est vide, readit est appelé. Le comportement de ces deux routines est similaire aux appels système read(2) et write(2), à la différence près que handle est passé aux premières routines en tant que premier argument. Remarque : le champ op du flux XDR doit être défini par l'appelant.
Attention : pour lire à partir d'un flux XDR créé par cette API, vous devrez d'abord appeler xdrrec_skiprecord() avant d'appeler toute autre API XDR. Cela insère des octets supplémentaires dans le flux pour fournir la délimitation des enregistrements.
bool_t xdr_reference(XDR *xdrs, char **objpp,
                    unsigned int objsize, xdrproc_t xdrobj);
Un filtre primitif qui transmet un pointeur vers un objet donné. L'argument objpp est l'adresse du pointeur. L'argument objsize est la taille de l'objet pointé, et xdrobj est la routine XDR pour cet objet. Cette routine est utile pour la transmission de structures de données arbitraires contenant des pointeurs.
bool_t xdr_setpos(XDR *xdrs, unsigned int pos);
Une macro qui appelle la routine de définition de position associée au flux XDR, xdrs. La routine définit la position du flux XDR à pos.
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
Un filtre primitif qui traduit entre des chaînes de caractères C (terminées par un octet nul) et leur représentation externe. L'argument sp est l'adresse du pointeur vers la chaîne. La longueur maximale de la chaîne est maxsize. Notez que la chaîne peut être plus courte que maxsize. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_char(XDR *xdrs, unsigned char *cp);
Un filtre primitif qui traduit entre des caractères C non signés et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
Un filtre primitif qui traduit entre les entiers C non signés et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ul);
Un filtre primitif qui traduit entre les entiers C non signés de type long et leurs représentations externes. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_union(XDR *xdrs, enum_t *dest, char *anys,
                xdrproc_t xdr_results[], xdrproc_t xdr_default);
Un filtre primitif qui traduisant entre des unions discriminées et leur représentation externe. L'union discriminateur doit être un entier C, et est désigné par dest. Le pointeur vers les données de l'union est anys. La liste des routines XDR pour chaque cas de l'union est donnée par xdr_results. La dernière entrée de cette liste doit être une routine XDR pour le cas par défaut. Cette routine renvoie un si elle réussit, zéro sinon.
bool_t xdr_vector(XDR *xdrs, char *arr, unsigned int len,
                 unsigned int maxsize, xdrproc_t elproc);
Similaire à xdr_array(), mais pour les tableaux de taille fixe.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
Une primitive de filtre qui traduit entre des chaînes de caractères (string) et leur représentation externe. Voir xdr_string(). Cette primitive est conçue pour être utilisée comme un filtre XDR générique.

La routine xdr_union() est la clé de la sérialisation de structures de données complexes. L'argument dest pointe vers la variable discriminante de l'union. Le premier élément du tableau xdr_results est la routine XDR pour la valeur de discriminant 0, le second pour la valeur 1, et ainsi de suite. La dernière entrée du tableau xdr_results doit être une routine XDR générique qui gère tous les autres cas (par exemple, lorsque le discriminant n'est pas 0 ou 1). L'argument anys pointe vers la structure de données qui sera effectivement sérialisée. L'argument xdr_default est un pointeur vers la routine XDR par défaut à utiliser si la valeur du discriminant n'est pas reconnue.

Les routines suivantes sont disponibles pour gérer les flux XDR :

void xdrstdio_create(XDR *xdrs, FILE *f, enum xdr_op op);
Cette routine initialise l'objet de flux XDR pointé par xdrs. Le flux XDR est lié au flux de fichier f. L'argument op détermine la direction du flux XDR (XDR_ENCODE, XDR_DECODE, ou XDR_FREE).

DIAGNOSTICS

Toutes les routines XDR renvoient un booléen indiquant le succès (1) ou l'échec (0).

SYNOPSIS AND DESCRIPTION

bool_t xdr_array(XDR *xdrs, char **arrp, unsigned int *size,
                 unsigned int maxsize, xdrproc_t element_proc,
                 size_t element_size);
A filter primitive that translates between C arrays and their external representation. The argument arrp is the address of the pointer to the array, and size is the address of the array's size. The argument maxsize is the maximum number of elements the array can contain. The argument element_proc is an XDR filter that translates the array elements between their C form and their external representation. The argument element_size is the size of each array element. This routine returns one if it succeeds, zero otherwise.
The arguments size and maxsize are used to encode variable length arrays. The actual size of the array is encoded first, followed by the elements themselves. The maximum size is used only for decode to limit the maximum number of elements that can be allocated.
Note: This routine allocates memory for the array elements when decoding.
bool_t xdr_bool(XDR *xdrs, bool_t *bp);
A filter primitive that translates between C bool_t values and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_bytes(XDR *xdrs, char **sp, unsigned int *size,
                 unsigned int maxsize);
A filter primitive that translates between arbitrary byte sequences and their external representations. The argument sp is the address of the pointer to the byte sequence. The argument size is the address of the size of the byte sequence. The argument maxsize is the maximum number of bytes that can be handled. This routine returns one if it succeeds, zero otherwise.
Note: This routine allocates memory for the byte sequence when decoding.
bool_t xdr_char(XDR *xdrs, char *c);
A filter primitive that translates between C characters and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdr_destroy(XDR *xdrs);
This routine destroys the XDR stream specified by xdrs, freeing any associated resources.
bool_t xdr_double(XDR *xdrs, double *dp);
A filter primitive that translates between C double precision floating-point numbers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_enum(XDR *xdrs, enum_t *ep);
A filter primitive that translates between C enumerated types (enum_t) and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_float(XDR *xdrs, float *fp);
A filter primitive that translates between C float precision floating-point numbers and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdr_free(xdrproc_t proc, char *ptr);
This routine frees the memory associated with the XDR structure pointed to by ptr, using the specified XDR filter routine proc. This routine is typically used to free memory that was allocated by an XDR decode routine.
unsigned int xdr_getpos(XDR *xdrs);
This routine returns the current position within the XDR stream xdrs. This position can be used later with xdr_setpos() to reposition the stream.
Warning: not all XDR streams support positioning.
char *(*xdr_inline(XDR *xdrs, unsigned int len));
This routine returns a pointer to a buffer of length len within the XDR stream xdrs. This buffer may be used to perform an in-line translation of data. If the data cannot be provided in-line, this routine returns NULL.
Note: The buffer returned by xdr_inline() is only valid until the next XDR operation on the stream.
bool_t xdr_int(XDR *xdrs, int *ip);
A filter primitive that translates between C int integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_long(XDR *xdrs, long *lp);
A filter primitive that translates between C long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdrmem_create(XDR *xdrs, const char *addr, unsigned int len,
                   enum xdr_op op);
This routine initializes the XDR stream object pointed to by xdrs. The XDR stream data is read from, or written to, a memory buffer starting at addr with length len. The argument op determines the direction of the XDR stream (either XDR_ENCODE, XDR_DECODE, or XDR_FREE).
bool_t xdr_opaque(XDR *xdrs, const char *cp, unsigned int size);
A filter primitive that translates between arbitrary data buffers and their external representations. The argument cp is the pointer to the buffer, and size is the size of the buffer in bytes. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_pointer(XDR *xdrs, char **pp, unsigned int size,
                   xdrproc_t proc);
A primitive that provides pointer chasing within structures. The argument pp is the address of the pointer; size is the sizeof the structure that *pp points to; and proc is an XDR procedure that filters the structure between its C form and its external representation. This routine returns one if it succeeds, zero otherwise.
Warning: this routine understands null pointers. Use xdr_reference() if you do not need to support null pointers.
XDR *xdrrec_create(XDR *xdrs, unsigned int sendsize, unsigned int recvsize,
                   char *shmhandle,
                   int (*readit)(char *,&char*, unsigned int),
                   int (*writeit)(char *,&char*, unsigned int));
This routine initializes the XDR stream object pointed to by xdrs for record-oriented XDR. The arguments sendsize and recvsize specify the size of the buffers to be used for sending and receiving records, respectively. The argument shmhandle is a handle used for shared memory transport, and is otherwise ignored. The arguments readit and writeit are callback routines used to read from and write to the underlying transport. The routine returns a pointer to the initialized XDR stream, or NULL on failure. The underlying transport must be able to provide or accept records of arbitrary length. Streams created by xdrrec_create() are not compatible with streams created by other XDR creation routines (e.g., xdrstdio_create(), xdrmem_create()). This incompatibility arises because the record-oriented XDR implementation adds header and trailer information to each record. This information is interpreted by routines that are specific to record-oriented XDR. For example, the xdrrec_endofrecord() routine adds a record trailer. The xdrrec_skiprecord() routine skips over a record trailer. The xdrrec_eof() routine checks for the end of the stream. Other XDR routines that do not understand this record information will likely fail.
bool_t xdrrec_endofrecord(XDR *xdrs, int sendnow);
This routine can be invoked only on streams created by xdrrec_create(). The data in the output buffer is marked as a completed record, and the output buffer is optionally written out if sendnow is nonzero. This routine returns one if it succeeds, zero otherwise.
bool_t xdrrec_eof(XDR *xdrs);
This routine can be invoked only on streams created by xdrrec_create(). After consuming the rest of the current record in the stream, this routine returns one if the stream has no more input, zero otherwise.
bool_t xdrrec_skiprecord(XDR *xdrs);
This routine can be invoked only on streams created by xdrrec_create(). It tells the XDR implementation that the rest of the current record in the stream's input buffer should be discarded. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_reference(XDR *xdrs, char **pp, unsigned int size,
                     xdrproc_t proc);
A primitive that provides pointer chasing within structures. The argument pp is the address of the pointer; size is the sizeof the structure that *pp points to; and proc is an XDR procedure that filters the structure between its C form and its external representation. This routine returns one if it succeeds, zero otherwise.
Warning: this routine does not understand null pointers. Use xdr_pointer() instead.
xdr_setpos(XDR *xdrs, unsigned int pos);
A macro that invokes the set position routine associated with the XDR stream xdrs. The argument pos is a position value obtained from xdr_getpos(). This routine returns one if the XDR stream could be repositioned, and zero otherwise.
Warning: it is difficult to reposition some types of XDR streams, so this routine may fail with one type of stream and succeed with another.
bool_t xdr_short(XDR *xdrs, short *sp);
A filter primitive that translates between C short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
void xdrstdio_create(XDR *xdrs, FILE *file, enum xdr_op op);
This routine initializes the XDR stream object pointed to by xdrs. The XDR stream data is written to, or read from, the stdio stream file. The argument op determines the direction of the XDR stream (either XDR_ENCODE, XDR_DECODE, or XDR_FREE).
Warning: the destroy routine associated with such XDR streams calls fflush(3) on the file stream, but never fclose(3).
bool_t xdr_string(XDR *xdrs, char **sp, unsigned int maxsize);
A filter primitive that translates between C strings and their corresponding external representations. Strings cannot be longer than maxsize. Note: sp is the address of the string's pointer. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_char(XDR *xdrs, unsigned char *ucp);
A filter primitive that translates between unsigned C characters and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_int(XDR *xdrs, unsigned int *up);
A filter primitive that translates between C unsigned integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_long(XDR *xdrs, unsigned long *ulp);
A filter primitive that translates between C unsigned long integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_u_short(XDR *xdrs, unsigned short *usp);
A filter primitive that translates between C unsigned short integers and their external representations. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_union(XDR *xdrs, enum_t *dscmp, char *unp,
                 const struct xdr_discrim *choices,
                 xdrproc_t defaultarm);     /* may equal NULL */
A filter primitive that translates between a discriminated C union and its corresponding external representation. It first translates the discriminant of the union located at dscmp. This discriminant is always an enum_t. Next the union located at unp is translated. The argument choices is a pointer to an array of xdr_discrim() structures. Each structure contains an ordered pair of [value,proc]. If the union's discriminant is equal to the associated value, then the proc is called to translate the union. The end of the xdr_discrim() structure array is denoted by a routine of value NULL. If the discriminant is not found in the choices array, then the defaultarm procedure is called (if it is not NULL). Returns one if it succeeds, zero otherwise.
bool_t xdr_vector(XDR *xdrs, char *arrp, unsigned int size,
                  unsigned int elsize, xdrproc_t elproc);
A filter primitive that translates between fixed-length arrays and their corresponding external representations. The argument arrp is the address of the pointer to the array, while size is the element count of the array. The argument elsize is the sizeof each of the array's elements, and elproc is an XDR filter that translates between the array elements' C form, and their external representation. This routine returns one if it succeeds, zero otherwise.
bool_t xdr_void(void);
This routine always returns one. It may be passed to RPC routines that require a function argument, where nothing is to be done.
bool_t xdr_wrapstring(XDR *xdrs, char **sp);
A primitive that calls xdr_string(xdrs, sp,MAXUN.UNSIGNED ); where MAXUN.UNSIGNED is the maximum value of an unsigned integer. xdr_wrapstring() is handy because the RPC package passes a maximum of two XDR routines as arguments, and xdr_string(), one of the most frequently used primitives, requires three. Returns one if it succeeds, zero otherwise.
