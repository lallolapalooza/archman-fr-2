XED(1) Manuel des commandes générales XED(1)

NOM

Xed - L'éditeur de texte

SYNOPSIS

xed [OPTIONS...] [FICHIERS...]

DESCRIPTION

Xed est l'éditeur de texte officiel du projet X-APPS, qui vise à fournir des applications aux environnements de bureau Cinnamon, MATE et Xfce. Tout en visant la simplicité et la facilité d'utilisation, Xed est un éditeur de texte puissant à usage général. Il peut être utilisé pour créer et éditer toutes sortes de fichiers texte.

Xed dispose d'un système de plugins flexible qui peut être utilisé pour ajouter dynamiquement de nouvelles fonctionnalités avancées à Xed lui-même.

Cette page de manuel documente brièvement la commande xed.

OPTIONS

nom_du_fichier(s)...
Spécifie le fichier à ouvrir lorsque xed démarre. Si ce n'est pas spécifié, xed démarrera un nouveau fichier vierge avec une étiquette "Document non sauvegardé". Plusieurs fichiers peuvent être chargés s'ils sont séparés par des espaces. xed supporte également la gestion des fichiers distants.
--display=AFFICHER
Affichage X à utiliser.
--encoding
Définit le codage de caractères à utiliser pour ouvrir les fichiers listés dans la ligne de commande.
--new-window
Crée une nouvelle fenêtre de niveau supérieur dans une instance existante de xed.
--new-document
Crée un nouveau document dans une instance existante de xed, sur la dernière fenêtre Xed qui avait le focus.
+[num]
Pour le premier fichier, aller à la ligne spécifiée par "num" (ne pas insérer d'espace entre le signe "+" et le numéro). Si "num" est absent, aller à la dernière ligne.
--list-encodings
Affiche la liste des valeurs possibles pour l'option encoding et quitte
--version
Affiche les informations de version et quitte
-?, -h, --help
Affiche les options standard de la ligne de commande.
-w, --wait
Ouvre les fichiers et bloque le processus xed.
--help-all
Affiche toutes les options de la ligne de commande.

Ce programme accepte également les options GTK standard.

EXEMPLES

xed --encoding WINDOWS-1252 ftp://ftp.kernel.org/pub/linux/kernel/README

Ouvre le fichier README du noyau Linux depuis le serveur FTP de kernel.org en utilisant le codage de caractères Windows-1252.

xed +156 http://www.some-website.com/

Ouvre la page web principale de some-website.com et saute à la ligne 156.

xed --new-window ~/.bashrc ~/.bash_history

Ouvre les fichiers .bashrc et .bash_history de l'utilisateur actuel dans une nouvelle fenêtre.
