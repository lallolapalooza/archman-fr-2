XEDIT(1) Manuel des commandes générales XEDIT(1)

NOM

xedit - éditeur de texte simple pour X

SYNTAXE

xedit [ -optiontoolkit ... ] [ nomfichier ... ]

DESCRIPTION

Xedit fournit une fenêtre composée des quatre zones suivantes :

Section Commandes
Un ensemble de commandes qui vous permettent de quitter xedit, d'enregistrer le fichier, ou de charger un nouveau fichier dans la fenêtre d'édition.
Fenêtre Message
Affiche les messages de xedit. De plus, cette fenêtre peut également être utilisée comme bloc-notes.
Affichage Nom de fichier
Affiche le nom du fichier en cours d'édition, et si ce fichier est en lecture-écriture ou en lecture seule.
Fenêtre Édition
Affiche le texte du fichier que vous éditez ou créez.

OPTIONS

Xedit accepte toutes les options de ligne de commande standard du X Toolkit (voir X(7)). L'ordre des options de ligne de commande n'a pas d'importance.

nomfichier
Spécifie le(s) fichier(s) à charger au démarrage. C'est le fichier qui sera édité. Si aucun fichier n'est spécifié, xedit vous permet de charger des fichiers ou de créer de nouveaux fichiers après son démarrage.

MODE ÉDITION LIGNE

Le mode d'édition de ligne active plusieurs commandes de raccourci pour rechercher et remplacer du texte dans un tampon xedit. Les commandes du mode d'édition de ligne ont le format : 

[numéro-ligne[,numéro-ligne]]commande[paramètres]

Numéro de ligne peut être spécifié comme :

.
La ligne de texte actuelle.
$
La dernière ligne du fichier.
nombre
Le numéro de ligne littéral.
- ou ^
La ligne précédente. Équivalent à -1.
-nombre ou ^nombre
La ligne actuelle moins nombre.
+
La ligne suivante. Équivalent à +1.
+nombre
La ligne actuelle plus nombre.
, ou %
De la première à la dernière ligne. Équivalent à 1,$.
;
De la ligne actuelle à la dernière ligne. Équivalent à .,$.

Commande peut être spécifiée comme :

s
Remplace le texte dans les lignes spécifiées.
/re/
Recherche vers l'avant le motif d'expression régulière re.
?re?
Recherche vers l'arrière le motif d'expression régulière re.

Paramètres peuvent être spécifiés comme :

/re/
Fonctionne comme paramètre pour i ou comme commande.
/re/texte/
Recherche vers l'avant re et remplace par texte.

Options peuvent suivre ou être des paramètres, les valeurs connues sont :

i
Recherche insensible à la casse.
g
Correspondance globale lors du remplacement de texte. Sauf indication contraire, seule la n-ième correspondance, par défaut 1, sera remplacée.
c
Confirmer avant de remplacer le texte.
nombre
Remplace uniquement l'occurrence référencée par nombre.

Les commandes acceptent certaines variations, exemples : 

/motif/i
i/motif/
i/motif
Recherche vers l'avant de motif. 
,sc/motif/texte
,sc/motif/texte/
,s/motif/texte/c
Recherche dans tout le tampon et demande confirmation pour remplacer motif par texte. 
,s/motif/texte/nombre
Remplace la correspondance nombre dans la ligne de texte. Si non spécifié, par défaut la première occurrence.

Lors de la recherche de texte, tapez <Retour> pour passer à la correspondance suivante. Lors du remplacement interactif de texte, tapez y ou Y pour accepter la modification, et n ou N pour l'ignorer et passer à la correspondance suivante.

COMMANDES

Quitter
Quitte la session d'édition en cours. Si des modifications n'ont pas été enregistrées, xedit affiche un message d'avertissement, permettant à l'utilisateur de les sauvegarder.

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

ermalink" href="#Save">Sauvegarder
Si les sauvegardes de fichiers sont activées (voir RESSOURCES, ci-dessous), xedit stocke une copie du fichier original, non édité, dans <préfixe>fichier<suffixe>, puis écrase le fichier avec le contenu de la fenêtre d'édition. Le nom du fichier est récupéré du widget Texte situé juste à droite du bouton Charger.
Charger
Charge le fichier nommé dans le widget texte immédiatement à droite de ce bouton et l'affiche dans la fenêtre d'édition.

RESSOURCES

Pour xedit, les ressources disponibles sont :

tagsName (Classe TagsName)
Spécifie le nom du fichier de tags à rechercher lors du chargement d'un nouveau fichier. La valeur par défaut est tags.
loadTags (Classe LoadTags)
Valeur booléenne pour activer ou désactiver la recherche de fichiers de tags. La valeur par défaut est True.
enableBackups (Classe EnableBackups)
Spécifie que, lors de la sauvegarde des modifications apportées à un fichier existant, xedit doit copier la version originale de ce fichier dans <préfixe>fichier<suffixe> avant de sauvegarder les modifications. La valeur par défaut pour cette ressource est « on », indiquant que des sauvegardes doivent être créées.
backupNamePrefix (Classe BackupNamePrefix)
Spécifie une chaîne de caractères à ajouter avant le nom du fichier de sauvegarde. La valeur par défaut est qu'aucune chaîne ne doit être ajoutée.
backupNameSuffix (Classe BackupNameSuffix)
Spécifie une chaîne de caractères à ajouter après le nom du fichier de sauvegarde. La valeur par défaut est d'utiliser « ~ » comme suffixe.
positionFormat (Classe Format)
Spécifie une chaîne de formatage utilisée pour afficher la position du curseur. Cette chaîne utilise une notation similaire à printf(3), où %l imprime le numéro de ligne, %c imprime le numéro de colonne, %p imprime le décalage de la position d'insertion, et %s imprime la taille actuelle du fichier. Il est également possible de spécifier des largeurs de champ, avec la notation %-?[0-9]+ . La chaîne de formatage par défaut est « L%l », qui affiche le caractère « L » suivi du numéro de ligne.
hints (Classe Hints)
Spécifie une liste de chaînes de caractères, séparées par des sauts de ligne, qui seront affichées dans la fenêtre bc_label.
hintsInterval (Classe Interval)
Spécifie l'intervalle en secondes auquel la chaîne d'indice dans la fenêtre bc_label changera.
changedBitmap (Classe Bitmap)
Spécifie le nom du Bitmap qui sera affiché dans le fileMenu, lorsque le fichier en cours d'édition est modifié.
autoReplace (Classe Replace)
Cette ressource est utile pour corriger automatiquement les fautes d'orthographe courantes, mais peut également être utilisée pour créer des macros simples. Le format est {non-espaces}{espaces}[{chaîne}]. Les champs sont séparés par des sauts de ligne. Exemple d'utilisation : 
nto	  pas\n\
/macro une longue chaîne avec \\\n de nouveaux sauts de ligne \\\n

Remplacera automatiquement le mot nto par pas, et /macro par une longue chaîne avec
de nouveaux sauts de ligne lorsque vous tapez ces mots.

ispell.dictionaries (Classe ispell.Dictionary)
Spécifie une liste de noms de dictionnaires, séparés par des espaces, disponibles pour le programme ispell. La valeur par défaut est "american americamed+ english".
ispell.dictionary (Classe ispell.Dictionary)
Spécifie le dictionnaire par défaut à utiliser.
ispell*<DICTIONNAIRE>.wordChars (Classe ispell*Chars)
Spécifie un ensemble de caractères qui peuvent faire partie d'un mot légal. Le champ <DICTIONNAIRE> est l'un des dictionnaires spécifiés dans la ressource dictionaries.
ispell.ispellCommand (Classe ispell.CommandLine)
Le chemin d'accès au programme ispell, et éventuellement, des arguments supplémentaires. Vous n'avez pas besoin de spécifier l'option « -w », ni l'option « -a ». Reportez-vous à la page de manuel ispell(1) pour plus d'informations sur les options d'ispell.
ispell.formatting (Classe ispell.TextFormat)
Spécifie quel format de texte utiliser lors de la vérification orthographique du fichier. Les formats disponibles sont text et html.
ispell*text.skipLines (Classe ispell*text.Skip)
Les lignes commençant par l'un des caractères de cette chaîne ne seront pas vérifiées orthographiquement. Cette ressource est uniquement utilisée en mode text.
ispell.terseMode (Classe ispell.Terse)
Lorsqu'il est activé, exécute ispell en mode succinct, sans demander d'interaction utilisateur pour les mots générés par formation de composés (lors de l'utilisation de l'option ispell « -C »), ou les mots générés par suppression d'affixes. La valeur par défaut est False.
ispell.lookCommand (Classe ispell.CommandLine)
Le chemin d'accès au programme de recherche de mots alternatifs, et éventuellement, des arguments supplémentaires. Le programme par défaut utilisé est /usr/bin/egrep.
ispell.wordsFile (Classe ispell.Words)
Le chemin d'accès au(x) fichier(s) à rechercher pour trouver des mots alternatifs. Le fichier par défaut est /usr/share/dict/words.
ispell.guessLabel (Classe ispell.Status)
Chaîne affichée dans la barre d'état ispell lorsqu'ispell renvoie une liste de suggestions d'un ou plusieurs mots. La valeur par défaut est Guess.
ispell.missLabel (Classe ispell.Status)
Chaîne affichée dans la barre d'état ispell lorsqu'ispell renvoie une liste d'un ou plusieurs mots pour correspondre à un mot mal orthographié. La valeur par défaut est Miss.
ispell.rootLabel (Classe ispell.Status)
Chaîne affichée dans la barre d'état ispell lorsque le mot n'est pas dans le dictionnaire, mais qu'il peut être formé à partir d'un mot racine. La valeur par défaut est Root:, suivie d'un espace et du mot racine.
ispell.noneLabel (Classe ispell.Status)
Chaîne affichée dans la barre d'état ispell lorsqu'il n'y a pas de correspondances proches. La valeur par défaut est None.
ispell.compoundLabel (Classe ispell.Status)
Chaîne affichée dans la barre d'état ispell lorsque le mot vérifié est formé par la concaténation de deux mots. La valeur par défaut est Compound.
ispell.okLabel (Classe ispell.Status)
Chaîne affichée dans la barre d'état ispell lorsque le mot vérifié est dans le dictionnaire. Cette chaîne n'est affichée que lors de l'utilisation du bouton check dans l'interface ispell de xedit. La valeur par défaut est Ok.
ispell.eofLabel (Classe ispell.Status)
La chaîne affichée dans la barre d'état ispell lorsque la fin du fichier est atteinte. La valeur par défaut est End Of File.
ispell.repeatLabel (Classe ispell.Status)
La chaîne affichée dans la barre d'état ispell lorsque deux mots identiques sont trouvés consécutivement dans le fichier. La valeur par défaut est Repeat.
ispell.lookLabel (Classe ispell.Status)
La chaîne affichée dans la barre d'état ispell après l'affichage des résultats de la commande Look. Si aucun résultat n'est trouvé, la valeur de la ressource ispell.noneLabel est affichée.
ispell.workingLabel (Classe ispell.Status)
La chaîne affichée dans la barre d'état ispell pendant que xedit communique avec ispell. La valeur par défaut est ....
