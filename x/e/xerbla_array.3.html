Documentation de la fonction

sous-routine xerbla_array (character(1), dimension(srname_len) srname_array, integer srname_len, integer info)

XERBLA_ARRAY

Objectif :

!>
!> XERBLA_ARRAY aide d'autres langages à appeler XERBLA, le gestionnaire d'erreurs
!> de LAPACK et BLAS. Au lieu de prendre un argument de chaîne Fortran comme
!> nom de la fonction, XERBLA_ARRAY prend un tableau de caractères simples
!> ainsi que la longueur du tableau. XERBLA_ARRAY copie ensuite jusqu'à 32
!> caractères de ce tableau dans une chaîne Fortran et la passe à XERBLA.
!> Si appelée avec un SRNAME_LEN non positif, XERBLA_ARRAY appellera XERBLA
!> avec une chaîne de caractères blancs.
!>
!> Supposons qu'une macro ou un autre dispositif rende XERBLA_ARRAY disponible
!> pour C99 sous le nom lapack_xerbla et avec une convention d'appel Fortran
!> courante. Alors un programme C99 pourrait invoquer XERBLA via :
!>    {
!>      int flen = strlen(__func__);
!>      lapack_xerbla(__func__, &flen, &info);
!>    }
!>
!> Fournir XERBLA_ARRAY n'est pas nécessaire pour intercepter les erreurs LAPACK.
!> XERBLA_ARRAY appelle XERBLA.
!>

Paramètres

SRNAME_ARRAY 
!>          SRNAME_ARRAY est un tableau de type CHARACTER(1), dimension (SRNAME_LEN)
!>          Le nom de la routine qui a appelé XERBLA_ARRAY.
!>

SRNAME_LEN

!>          SRNAME_LEN est un entier (INTEGER)
!>          La longueur du nom dans SRNAME_ARRAY.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          La position du paramètre invalide dans la liste des paramètres
!>          de la routine appelante.
!>
