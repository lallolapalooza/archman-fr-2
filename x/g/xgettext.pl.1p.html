NOM

xgettext.pl - Extraire les chaînes traduisibles à partir de la source

VERSION

version 1.00

SYNTAXE

xgettext.pl [OPTION] [FICHIERENTREE]...

DESCRIPTION

Ce programme extrait les chaînes traduisibles des fichiers d'entrée spécifiés, ou de STDIN si aucun n'est donné.

Veuillez consulter Locale::Maketext::Extract pour une liste des formats de fichiers d'entrée pris en charge.

OPTIONS

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes. De même pour les arguments optionnels.

Emplacement des fichiers d'entrée :

FICHIERENTREE...
Fichiers à partir desquels extraire les messages. Si non spécifié, STDIN est supposé.
-f, --files-from=FICHIER
Récupère la liste des fichiers d'entrée depuis FICHIER.
-D, --directory=REPERTOIRE
Ajoute REPERTOIRE à la liste pour la recherche des fichiers d'entrée.

Format du fichier d'entrée :

-u, --use-gettext-style
Spécifie que les programmes sources utilisent le style Gettext (par exemple %1) au lieu du style Maketext (par exemple "[_1]") dans leurs appels de localisation.

Emplacement de la sortie :

-d, --default-domain=NOM
Utilise NOM.po pour la sortie, au lieu de "messages.po".
-o, --output=FICHIER
Nom du fichier PO à écrire ou à mettre à jour de manière incrémentielle ; "-" signifie écrire vers STDOUT.
-p, --output-dir=DIR
Les fichiers de sortie seront placés dans le répertoire DIR.

Détails de la sortie :

-g, --gnu-gettext
Active l'interopérabilité GNU gettext en imprimant "#, perl-maketext-format" avant chaque entrée qui possède des variables de type "%".
-W, --wrap
Si l'enroulement est activé, alors, pour les entrées avec plusieurs emplacements de fichiers, chaque emplacement est listé sur une ligne séparée. Par défaut, ils sont tous mis sur une seule ligne.

Les autres commentaires ne sont pas affectés.

Plugins :

Par défaut, tous les plugins d'analyse intégrés sont activés pour tous les types de fichiers, avec les avertissements désactivés.

Si un plugin est spécifié sur la ligne de commande, les avertissements sont activés par défaut - vous pouvez les désactiver avec "-now"

-P|--plugin nomplugin
Utilise le plugin spécifié pour les types de fichiers par défaut reconnus par
ce plugin.
-P|--plugin 'nomplugin=*'
Utilise le plugin spécifié pour tous les types de fichiers.
-P|--plugin nomplugin=ext,ext2
Utilise le plugin spécifié pour tous les fichiers se terminant par C<.ext> ou C<.ext2>
-P|--plugin Mon::Module::Nom='*'
Utilise votre module plugin personnalisé pour tous les types de fichiers

Plusieurs plugins peuvent être spécifiés sur la ligne de commande.

Plugins disponibles :

"perl" : Locale::Maketext::Extract::Plugin::Perl
Pour un analyseur Perl légèrement plus précis mais beaucoup plus lent, vous pouvez utiliser le plugin PPI. Il n'a pas de nom court, mais doit être spécifié en entier, par exemple : 
xgettext.pl -P Locale::Maketext::Extract::Plugin::PPI
"tt2" : Locale::Maketext::Extract::Plugin::TT2
"yaml" : Locale::Maketext::Extract::Plugin::YAML
"formfu" : Locale::Maketext::Extract::Plugin::FormFu
"mason" : Locale::Maketext::Extract::Plugin::Mason
"text" : Locale::Maketext::Extract::Plugin::TextTemplate
"generic" : Locale::Maketext::Extract::Plugin::Generic

Avertissements :

Si un plugin d'analyse rencontre une erreur de syntaxe lors de l'analyse, il abandonnera l'analyse et passera au plugin d'analyse suivant. Si les avertissements sont activés, l'erreur sera renvoyée vers STDERR.

Désactivé par défaut, à moins qu'un plugin n'ait été spécifié sur la ligne de commande.

-w|--warnings
-now|--nowarnings

Verbeux :

Si vous souhaitez voir quels fichiers ont été traités, quels plugins ont été utilisés et quelles chaînes ont été extraites, activez "verbose". Si aucun plugin acceptable n'a été trouvé, ou si aucune chaîne n'a été extraite, le fichier n'est pas listé :

-v|--verbose
Liste les fichiers traités.
-v -v|--verbose --verbose :
Liste les fichiers traités et les plugins qui ont réussi à extraire des chaînes.
-v -v|--verbose --verbose :
Liste les fichiers traités, les plugins qui ont réussi à extraire des chaînes, ainsi que les chaînes extraites, la ligne où elles ont été trouvées et leurs variables.
