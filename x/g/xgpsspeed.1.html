NOM

xgpsspeed - Tachymètre GPS pour gpsd

SYNTAXE

xgpsspeed [OPTIONS] [service[:port[:périphérique]]]

xgpsspeed -h

xgpsspeed -V

DESCRIPTION

xgpsspeed est un tachymètre qui utilise les informations de position de gpsd.

Le mode d'affichage par défaut est une présentation de vitesse et de cap modélisée d'après un écran de navigation maritime ; pour des raisons de compatibilité ascendante, l'option --nautical force ce mode. L'option --landspeed produit un simple tachymètre.

L'option --speedunits peut être utilisée pour définir les unités de vitesse pour l'affichage ; suivez le mot-clé avec « knots » pour les milles nautiques par heure, « kmh » pour les kilomètres par heure, ou « mph » pour les miles par heure. L'unité par défaut est le mile par heure.

En mode nautique uniquement, --maxspeed définit la vitesse maximale sur le tachymètre.

xgpsspeed fonctionnera correctement en tant qu'utilisateur normal, et correctement en tant que root. L'exécution de xgpsspeed sous sudo entraînera une perte de certaines fonctionnalités.

OPTIONS

-?, -h, --help

Fait en sorte que le client émette un résumé de ses options puis se termine.

-device PÉRIPHÉRIQUE

Le périphérique sur l'hôte auquel se connecter. La valeur par défaut est vide (quelconque).

-D LVL, --debug LVL

Définit le niveau de débogage, il est principalement destiné aux développeurs de GPSD. Il active divers messages de progression vers la sortie standard d'erreur.

--host HÔTE

L'hôte (serveur) auquel se connecter. La valeur par défaut est localhost.

-p PORT, --port PORT

Le port auquel se connecter. La valeur par défaut est 2947.

-V, --version

Cette option fait en sorte que chaque client dépose la version du paquet et se termine.

ARGUMENTS

Par défaut, les clients collectent des données du démon local gpsd s'exécutant sur localhost, en utilisant le port GPSD par défaut 2947. L'argument optionnel de n'importe quel client peut modifier ce comportement : [serveur[:port[:périphérique]]]

Pour plus d'explications et d'exemples, consultez la section ARGUMENTS de la page de manuel gps(1)

ENVIRONNEMENT

La variable d'environnement GPSD_UNITS est vérifiée si aucun système d'unités n'est spécifié sur la ligne de commande. Elle peut être définie sur 'i', 'imperial', 'm', 'metric', ou 'n', 'nautical'.

LC_MEASUREMENT puis LANG sont vérifiés si aucun système d'unités n'a été spécifié sur la ligne de commande, ou dans GPSD_UNITS. Si la valeur est 'C', 'POSIX', ou commence par 'en_US', le système d'unités est défini sur impérial. La valeur par défaut si aucun système n'a été sélectionné est métrique.

VALEURS DE RETOUR

0

en cas de succès.

1

en cas d'échec
