NOM

xgamma - Modifier la correction gamma d'un moniteur via le serveur X

SYNTAXE

xgamma [-display affichage] [-screen écran] [-quiet] [-help|-version]
       [-gamma f.f | [[-rgamma f.f] [-ggamma f.f] [-bgamma f.f]]]

DESCRIPTION

xgamma permet aux utilisateurs X de consulter et de modifier la correction gamma d'un moniteur via l'extension X du mode vidéo (XFree86-VidModeExtension).

Notez que l'utilitaire xgamma est obsolète et limité ; xrandr(1) devrait être utilisé avec les pilotes qui supportent l'extension XRandr.

Si aucune valeur pour la correction gamma n'est fournie via les options -gamma ou -rgamma/-ggamma/-bgamma, xgamma affiche la correction gamma actuelle de l'écran.

OPTIONS

-display affichage
Cet argument vous permet de spécifier le serveur auquel se connecter ; voir X(7).
-screen écran
Lorsque plusieurs écrans sont configurés comme un seul écran logique, cette option vous permet de sélectionner l'écran que vous souhaitez modifier.
-quiet
Silence la sortie normale de xgamma
-help
Affiche le résumé de la syntaxe de commande `Usage:'.
-version
Affiche la version du programme et quitte.
-gamma f.f
La correction gamma peut être définie soit comme une seule valeur, soit séparément pour les composantes rouge, verte et bleue. Cet argument spécifie la correction gamma comme une seule valeur.
-rgamma f.f
Cet argument spécifie la composante rouge de la correction gamma.
-ggamma f.f
Cet argument spécifie la composante verte de la correction gamma.
-bgamma f.f
Cet argument spécifie la composante bleue de la correction gamma.

ENVIRONNEMENT

DISPLAY
Pour obtenir l'hôte et le numéro d'affichage par défaut.

BOGUES

Ce client modifie les valeurs internes de la correction gamma pour le serveur X. Le respect de ces valeurs dépend des pilotes vidéo.

Les valeurs gamma sont transmises au serveur X avec une précision de 3 décimales.

VOIR AUSSI

xvidtune(1), xrandr(1)
