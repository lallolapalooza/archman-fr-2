XKBCLI(1) Manuel des commandes générales XKBCLI(1)

NOM

xkbcli — outil pour interagir avec les mappages de clavier XKB

SYNTAXE

xkbcli commande [arguments]

xkbcli [--help | --version]

DESCRIPTION

xkbcli est un outil en ligne de commande pour interroger, compiler et tester les mappages de clavier XKB, les dispositions et autres éléments.

--help
Afficher l'aide et quitter
--version
Afficher la version et quitter

COMMANDES

compile-keymap
Compiler un mappage de clavier XKB, voir xkbcli-compile-keymap(1)
compile-compose
Compiler un fichier compose, voir xkbcli-compile-compose(1)
how-to-type
Afficher comment taper un point de code Unicode donné, voir xkbcli-how-to-type(1)
interactive
Débogueur interactif pour les mappages de clavier XKB qui sélectionne automatiquement parmi les backends suivants, s'ils sont disponibles : Wayland, X11 et evdev. Voir les entrées correspondantes ci-après.
interactive-evdev
Débogueur interactif pour les mappages de clavier XKB pour evdev, voir xkbcli-interactive-evdev(1)
interactive-wayland
Débogueur interactif pour les mappages de clavier XKB pour Wayland, voir xkbcli-interactive-wayland(1)
interactive-x11
Débogueur interactif pour les mappages de clavier XKB pour X11, voir xkbcli-interactive-x11(1)
dump-keymap
Sauvegarder un mappage XKB depuis un compositeur Wayland ou X11, voir les entrées correspondantes ci-après.
dump-keymap-wayland
Sauvegarder un mappage de clavier XKB depuis un compositeur Wayland, voir xkbcli-dump-keymap-wayland(1)
dump-keymap-x11
Sauvegarder un mappage de clavier XKB depuis un serveur X, voir xkbcli-dump-keymap-x11(1)
list
Lister les dispositions et autres disponibles, voir xkbcli-list(1)

Notez que tous les outils ne sont peut-être pas disponibles sur votre système.
