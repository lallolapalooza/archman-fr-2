NOM

xkbsel - Fichiers de l'outil de sélection de clavier XKB

DESCRIPTION

xkbsel est un framework pour définir, sélectionner et indiquer les mappages de clavier XKB. Il permet d'attacher des données supplémentaires aux fichiers sources XKB et de sélectionner (par système et par utilisateur) le sous-ensemble des mappages présentés à l'utilisateur dans une interface graphique ou en ligne de commande.

Cette page de manuel décrit la syntaxe des fichiers de configuration et les extensions de la syntaxe XKB utilisées pour attacher les données supplémentaires.

FICHIERS DE CONFIGURATION

Les fichiers de configuration sont nommés xkbsel.conf et contiennent des entrées de configuration divisées en sections. Les noms de section sont entourés de crochets et les entrées peuvent être qualifiées par un qualificateur optionnel. Une entrée peut avoir zéro ou plusieurs valeurs :

# commentaire
// commentaire
[section]
entree1 = valeur
entree2[qualif] = val1 "valeur-speciale2" val3

Les noms de section, les noms d'entrée, les qualificateurs et les valeurs non citées commencent par une lettre, une barre oblique ou un underscore ; les caractères restants peuvent inclure des chiffres et des parenthèses. Tout le reste dans la partie valeur doit être cité (il n'y a pas encore de possibilité d'obtenir les guillemets doubles dans la valeur elle-même). Les fichiers sont généralement sensibles à la casse et l'ordre des sections est important.

Si le fichier de configuration de l'utilisateur existe, il est utilisé dans son intégralité - aucune fusion avec le fichier de configuration du système ne se produit.

Actuellement, il y a deux sections :

RACCOURCI

Les raccourcis définissent un mappage entre les noms courts utilisés pour la dénomination pratique des cartes dans les outils en ligne de commande et les outils graphiques, et les noms complets des cartes de clavier XKB. Le nom complet de la carte de clavier XKB se compose d'un chemin relatif vers un fichier (souvent sans partie répertoire) et d'un nom de carte dans ce fichier particulier entre parenthèses.

Voici un exemple de section de raccourcis définissant les claviers américain, allemand et français (de la distribution X11) et slovaque (de la distribution xkbsel) :

[raccourci]
us = xfree86(us)
de = xfree86(de)
fr = xfree86(fr)
sk = czsk(sk)

ENSEMBLE DE CARTES

Les raccourcis définis dans la section précédente sont utilisés pour construire une liste de sélection ordonnée, utilisée par les sélecteurs graphiques pour présenter un menu de choix à l'utilisateur. Il est possible de définir des listes en fonction de la partie langue de la définition locale (en minuscules), de la partie territoire (en majuscules) et/ou d'une liste par défaut lorsque aucune liste spécifique ne correspond. Un exemple :

[ensemble-de-cartes]
carte[sk] = sk us
carte[de] = de us
carte[fr] = fr us
carte = us sk de fr

DONNÉES XKB ADDITIONNELLES

Il est supposé que vous savez comment créer un mappage de clavier XKB. Cette section explique seulement comment ajouter les données xkbsel aux nouveaux mappages et aux mappages déjà présents dans la distribution X.

Le paquet xkbsel reflète la structure des répertoires XKB (résidant normalement dans /usr/X11R6/lib/X11/xkb) dans le répertoire système de xkbsel (normalement /usr/share/xkbsel) et éventuellement dans le répertoire utilisateur (~/.xkbsel).

Le seul répertoire de la structure XKB d'origine qui compte pour xkbsel est le sous-répertoire keymap. C'est le point de départ où le paquet recherche les mappages et les transmet pour compilation et installation à xkbcomp(1).

xkbsel ajoute deux répertoires supplémentaires à la hiérarchie. redef contient les fichiers qui ajoutent des données xkbsel supplémentaires aux mappages déjà définis, sans avoir besoin de modifier les mappages eux-mêmes. pixmap contient de petites icônes qui peuvent être référencées par les outils graphiques (ce n'est pas encore implémenté).

Lorsqu'il y a des données conflictuelles, la priorité, de la plus haute à la plus basse, est :

1. répertoire redef dans la hiérarchie utilisateur
2. fichiers de la hiérarchie utilisateur
3. répertoire redef dans la hiérarchie xkbsel
4. fichiers de la hiérarchie xkbsel
5. distribution X11 originale
Les fichiers des répertoires utilisateur autres que keymap ou redef (par exemple, symbols) ne sont utilisés que lorsque le mappage lui-même est mentionné dans un fichier de ces deux répertoires - sinon xkbsel n'en a pas connaissance.

Les données pour xkbsel sont ajoutées aux fichiers XKB en utilisant des commentaires spécialement formatés dans la portée de la définition de carte de clavier particulière. Le format du commentaire est

%xkb_mot-clé% "valeur"
Actuellement, il y a deux telles entrées de données :
description
définit une description du mappage du clavier dans les outils graphiques
pixmap
définit une pixmap pour les outils graphiques (pas encore implémenté)

Voici un exemple d'une telle définition de carte de clavier :

xkb_keymap "sk" {
// %xkb_description% "Clavier slovaque"
// %xkb_pixmap% "slovak.xpm"
xkb_keycodes { include "xfree86" };
xkb_types { include "default" };
xkb_compatibility { include "default" };
xkb_symbols { include "czsk_ibm(sk)" };
xkb_geometry { include "pc" };
};
Les descriptions peuvent utiliser des caractères dans un encodage local, mais rappelez-vous qu'un outil graphique s'exécute dans une locale spécifique et n'affichera pas nécessairement correctement toutes les descriptions de cartes sélectionnées.

Il est possible d'ajouter ces données aux mappages existants. Comme il est pratique de le faire uniquement dans plusieurs fichiers au lieu de faire correspondre les fichiers de redéfinition aux fichiers de mappage, il est possible de définir un nom de fichier pour les définitions suivantes. Cela ne fonctionne que pour les fichiers dans les répertoires redef et est spécifié comme

%xkb_file% "valeur"
en dehors des définitions de carte de clavier. Vous pouvez donc faire quelque chose comme ceci :
// %xkb_file% "xfree86"
xkb_keymap "us"
{
// %xkb_description% "Disposition US"
// %xkb_pixmap% "us.xpm"
};

// %xkb_file% "sun/xfree86"
xkb_keymap "type4_us"
{
// %xkb_description% "Disposition US pour Sun"
// %xkb_pixmap% "us.xpm"
};

    NOM

    xkbsel - Description d'une combinaison de touches XKB

    DESCRIPTION

    Ce manuel décrit comment les combinaisons de touches sont représentées dans XKB. Il s'agit d'une référence pour les développeurs travaillant avec XKB, qui souhaitent comprendre ou modifier les fichiers de configuration XKB.

    FICHIERS DE CONFIGURATION

    Les fichiers de configuration XKB sont généralement situés dans /usr/share/X11/xkb/. Ils comprennent des descriptions de dispositions de clavier, de groupes de touches, de types de touches, de symboles, etc.

    FICHIERS

    Ce manuel ne fait pas référence à des fichiers spécifiques directement utilisés par l'utilisateur, mais plutôt aux fichiers de configuration sous-jacents utilisés par le système XKB.
