NOM

xkbsel - sélectionner la disposition du clavier

SYNTAXE

xkbsel [-v] [--debug] [-s] MAP
xkbsel [-v] [--debug] {-n,-p}
xkbsel {--help,--version}

DESCRIPTION

xkbsel est une interface en ligne de commande pour sélectionner les claviers, adaptée à une installation en tant qu'action liée à une combinaison de touches dans un gestionnaire de fenêtres, à inclure dans des scripts ou à une utilisation en ligne de commande simple. xkbsel supporte les options suivantes :

-s MAP, --select=MAP
sélectionne la MAP nommée
-n, --next
sélectionne la carte suivante dans l'ordre défini par le fichier de configuration
-p, --previous
sélectionne la carte précédente dans l'ordre défini par le fichier de configuration
-v, --verbose
soyez verbeux
--debug
soyez très verbeux
--help
affiche les instructions d'utilisation brèves
--version
affiche la version du programme

La MAP peut être spécifiée soit par son nom XKB complet (par exemple, xfree86(us) ou sun/de(type4_de)), soit par un raccourci défini dans le fichier de configuration. Les options -n et -p ne fonctionnent que lorsque le mappage actuel a été spécifié sous forme de raccourci - sinon, elles sélectionnent respectivement la première et la dernière carte.

FICHIERS

/etc/xkbsel.conf
fichier de configuration système
~/.xkbsel/xkbsel.conf
fichier de configuration de l'utilisateur
