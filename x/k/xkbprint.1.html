XKBPRINT(1) Manuel des commandes générales XKBPRINT(1)

NOM

xkbprint - imprimer une description de clavier XKB

SYNOPSIS

xkbprint [options] source [ fichier_sortie ]

DESCRIPTION

La commande xkbprint génère une description PostScript imprimable ou encapsulée du clavier XKB spécifié par source. La source peut être un fichier de mappage de clés compilé (.xkm) qui inclut une description de géométrie ou une spécification d'affichage X. Si un fichier_sortie est spécifié, xkbprint y écrit. Si aucun fichier de sortie n'est spécifié, xkbprint remplace l'extension du fichier source par .ps ou .eps selon le format demandé. Si la source est un affichage X non local (par exemple, :0), xkbprint ajoute le préfixe approprié à la spécification de l'affichage, remplaçant le deux-points par un trait d'union. Pour un affichage local, xkprint utilise server-n où n est le numéro de l'affichage.

OPTIONS

-?, -help
Imprime un message d'utilisation.
-color
Imprime en utilisant les couleurs spécifiées dans le fichier de géométrie ; par défaut, xkbprint imprime une image en noir et blanc du clavier.
-dflts
Tente de calculer des noms par défaut pour les composants manquants, tels que les touches.
-diffs
Affiche les symboles uniquement là où ils sont explicitement liés.
-eps
Génère un fichier PostScript encapsulé.
-fit
Ajuste l'image du clavier à la page (par défaut).
-full
Imprime le clavier en taille réelle.
-grid res
Imprime une grille avec une résolution de res mm sur le clavier.
-if nom_police
Spécifie une police PostScript de type 1 interne à décharger dans le fichier de sortie spécifié ou dans nom_police.pfa, si aucun fichier de sortie n'est spécifié. Aucune description de clavier n'est imprimée si une police interne est déchargée.
-label type
Spécifie les étiquettes à imprimer sur les touches ; les types valides sont : none, name, code, et symbols.
-lc <locale>
Spécifie une locale dans laquelle les KeySyms doivent être résolus.
-level1
Génère du PostScript de niveau 1.
-level2
Génère du PostScript de niveau 2.
-lg groupe
Imprime les symboles des groupes de claviers à partir de groupe.
-ll niveau
Imprime les symboles à partir du niveau de décalage niveau.
-mono
Génère une image en noir et blanc du clavier (par défaut).
-n num
Imprime num copies.
-nkg num
Imprime les symboles dans num groupes de claviers.
-npk num
Nombre d'images de clavier à imprimer sur chaque page ; pour les fichiers EPS, cela spécifie le nombre total d'images de clavier à imprimer.
-o fichier
Écrit la sortie dans fichier.
-Rrépertoire
Utilise répertoire comme répertoire racine ; tous les noms de chemin sont interprétés par rapport à répertoire.
-pict lequel
Contrôle l'utilisation de pictographes au lieu de noms de keysym lorsqu'ils sont disponibles. lequel peut être n'importe lequel de all, none, ou common (par défaut).
-synch
Force la synchronisation pour les requêtes X.
-version
Affiche la version du programme et quitte.
-w niveau
Définit le niveau d'avertissement (0 pour aucun avertissement, 10 pour tous les avertissements).
