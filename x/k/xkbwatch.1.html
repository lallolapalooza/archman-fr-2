NOM

xkbwatch - utilitaire utilisateur de l'extension XKB

DESCRIPTION

Ce programme signale les changements dans les composants fondamentaux de l'état du clavier XKB ainsi que dans l'état de compatibilité effectif.

OPTIONS

Xkbwatch accepte toutes les options de ligne de commande standard de X Toolkit ainsi que les options supplémentaires listées ci-dessous :

-version
Cette option indique que la version du programme doit être affichée, après quoi le programme se termine.
