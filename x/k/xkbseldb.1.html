NOM

xkbseldb - maintenir les bases de données xkbsel

SYNTAXE

xkbseldb [-rRmMlLc] [-b] [-x] [-v] [--debug]
xkbseldb {--help,--version}

DESCRIPTION

Le paquet xkbsel stocke ses définitions de disposition de clavier dans les hiérarchies de répertoires système et utilisateur et fournit un accès à celles-ci basé sur les fichiers de configuration système et utilisateur. Comme il s'agit de nombreuses données dispersées et que le processus de sélection des mappages doit être rapide, les définitions sont hachées et les mappages mentionnés dans les fichiers de configuration sont précompilés dans une forme interne rapide à lire.

xkbseldb est utilisé pour maintenir ces données internes. Les options disponibles sont :

-R, --rebuild-system
reconstruire la base de données système
-r, --rebuild-user
reconstruire la base de données de l'utilisateur
-M, --missing-system
afficher un modèle couvrant les métadonnées xkbsel manquantes pour les mappages X11 et système
-m, --missing-user
afficher un modèle couvrant les métadonnées utilisateur manquantes
-L, --list-system
lister le contenu de la base de données système
-l, --list-user
lister le contenu des bases de données du point de vue de l'utilisateur
-b, --brief
lorsque le contenu est listé, afficher uniquement les noms des mappages
-x, --explicit
lorsque le contenu est listé, exclure les mappages qui sont pris de la distribution X11 sans modification
-c, --check
afficher la configuration actuelle
-v, --verbose
être verbeux
--debug
être très verbeux
--help
afficher des instructions d'utilisation brèves
--version
afficher la version du programme

Vous devez reconstruire la base de données système chaque fois que vous ajoutez ou supprimez un mappage de clavier inclus dans les répertoires système X11 ou du paquet, lorsque vous modifiez des métadonnées décrivant le mappage (voir xkbsel(5) pour les formats) ou lorsque vous modifiez le contenu des définitions XKB de telle sorte que le mappage résultant soit différent. Il est fortement conseillé de reconstruire la base de données lorsque vous ajoutez de nouvelles définitions de raccourcis dans le fichier de configuration système afin qu'elles soient précompilées par le système (sinon, elles seront compilées à chaque fois qu'un utilisateur les sélectionnera).

La situation pour les bases de données utilisateur est similaire - si le répertoire xkbsel de l'utilisateur n'est pas vide, une reconstruction est nécessaire après chaque modification de ces données. En bref : en cas de doute, effectuez les reconstructions.

Les options --missing-system et --missing-user sont destinées aux personnes souhaitant définir elles-mêmes les mappages. La sortie doit être remplie et installée comme fichier de redéfinition. Ne vous en occupez pas si vous souhaitez uniquement utiliser le paquet.

L'utilisation de --check et --list-user --brief peut souvent aider à déboguer les problèmes de configuration.

FICHIERS

/usr/X11R6/lib/X11/xkb
hiérarchie XKB de la distribution X11
/usr/share/xkbsel
répertoire des données système
/etc/xkbsel.conf
fichier de configuration système
/var/xkbsel
répertoire système pour la base de données de hachage et les dispositions de clavier précompilées
~/.xkbsel
répertoire des données utilisateur
~/.xkbsel/xkbsel.conf
fichier de configuration de l'utilisateur

VOIR AUSSI

xkbsel(1), xkbsel-aw(1), xkbsel(5)

BOGUES

Devrait déterminer automatiquement quand la base de données utilisateur a besoin d'une reconstruction.
