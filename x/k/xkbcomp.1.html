XKBCOMP(1) Version X11 XKBCOMP(1)

NOM

xkbcomp - compiler la description du clavier XKB

SYNTAXE

xkbcomp [option] source [destination]

DESCRIPTION

Le compilateur de configuration de clavier xkbcomp convertit une description de configuration de clavier XKB dans l'un des formats de sortie suivants. L'utilisation la plus courante de xkbcomp est de créer un fichier de configuration de clavier compilé (extension .xkm) qui peut être lu directement par les serveurs X ou les utilitaires compatibles XKB. Le compilateur de configuration de clavier peut également produire des fichiers d'en-tête C ou des fichiers source XKB. Les fichiers d'en-tête C produits par xkbcomp peuvent être inclus par les serveurs X ou les utilitaires qui ont besoin d'une configuration de clavier par défaut intégrée. Les fichiers source XKB produits par xkbcomp sont entièrement résolus et peuvent être utilisés pour vérifier que les fichiers qui composent généralement une configuration de clavier XKB sont fusionnés correctement ou pour créer un seul fichier contenant une description complète de la configuration de clavier.

La source peut spécifier un affichage X, ou un fichier .xkb ou .xkm ; sauf indication contraire, le format de la destination dépend du format de la source. La compilation d'un fichier .xkb (source de configuration de clavier) génère un fichier .xkm (fichier de configuration de clavier compilé) par défaut. Si la source est un fichier .xkm ou un affichage X, xkbcomp génère un fichier source de configuration de clavier par défaut.

Si la destination est un affichage X, la configuration du clavier pour cet affichage est mise à jour avec la configuration compilée.

Le nom de la destination est généralement calculé à partir du nom de la source, avec l'extension remplacée de manière appropriée. Lors de la compilation d'une seule carte à partir d'un fichier contenant plusieurs cartes, xkbcomp construit le nom du fichier de destination en ajoutant une extension appropriée au nom de la carte à utiliser.

OPTIONS

-a
Affiche toutes les informations du clavier, rapportant les informations implicites ou dérivées sous forme de commentaire. N'affecte que la sortie au format .xkb.
-C
Produire un fichier d'en-tête C en sortie (extension .h).
-dflts
Calculer les valeurs par défaut pour les composants manquants, tels que les noms de touches.
-em1 msg
Affiche msg avant d'afficher le premier message d'erreur.
-emp msg
Affiche msg au début de chaque ligne de message.
-eml msg
En cas d'erreurs, affiche msg avant de quitter.
-help, -?
Afficher les options disponibles.
-Idir
Spécifie les répertoires de haut niveau à rechercher pour les fichiers inclus par la description de la configuration du clavier. Après la recherche de tous les répertoires spécifiés par les options -I, le répertoire courant et enfin le répertoire xkb par défaut /usr/share/X11/xkb seront recherchés.

Pour empêcher la recherche dans les répertoires courant et par défaut, utilisez l'option -I seule (c'est-à-dire sans répertoire), avant toute option -I spécifiant les répertoires que vous souhaitez rechercher.

-i deviceid
Si source ou destination est un affichage X valide, charge la configuration du clavier depuis/vers le périphérique avec l'ID spécifié (pas le nom).
-l
Lister les cartes qui spécifient le motif map dans tous les fichiers listés sur la ligne de commande (non encore implémenté).
-m name
Spécifie une carte à compiler à partir d'un fichier contenant plusieurs entrées.
-merge
Fusionner les informations compilées avec la carte du serveur (non encore implémenté).
-o name
Spécifie un nom pour le fichier de sortie généré. Par défaut, c'est le nom du fichier source avec une extension appropriée au format de sortie.
-opt parts
Spécifie une liste de parties optionnelles. Les erreurs de compilation dans les parties optionnelles ne sont pas fatales. Les parties peuvent être composées de n'importe quelle combinaison des lettres c, g, k, s et t, qui spécifient respectivement la carte de compatibilité, la géométrie, les codes de touches, les symboles et les types.
-Rdir
Spécifie le répertoire racine pour les noms de chemins relatifs.
-synch
Forcer la synchronisation pour les requêtes X.
-version
Afficher le numéro de version.
-w lvl
Contrôle le rapport des avertissements pendant la compilation. Un niveau d'avertissement de 0 désactive tous les avertissements ; un niveau d'avertissement de 10 les active tous.
-xkb
Générer une description source du clavier en sortie (extension .xkb).
-xkm
Générer un fichier de configuration de clavier compilé en sortie (extension .xkm).

VOIR AUSSI
