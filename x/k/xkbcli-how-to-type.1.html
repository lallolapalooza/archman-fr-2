XKBCLI-HOW-TO-TYPE(1) Manuel des commandes générales XKBCLI-HOW-TO-TYPE(1)

NOM

xkbcli-how-to-type — interroger comment taper un point de code Unicode ou une touche donnés

SYNTAXE

xkbcli-how-to-type [options] caractère/point de code/touche

DESCRIPTION

xkbcli-how-to-type imprime les combinaisons de touches (code de touche + modificateurs) dans les dispositions du keymap qui produiraient le point de code Unicode ou la touche donnée.

point de code/touche est soit :

  • un seul caractère (nécessite un terminal qui utilise l'encodage de caractères UTF-8) ;
  • un point de code Unicode, interprété comme hexadécimal s'il est précédé de 0x ou U+, sinon comme décimal ;
  • une touche si les interprétations précédentes ont échoué ou si --keysym est utilisé. Le paramètre est alors soit un nom de touche, soit une valeur numérique (hexadécimale si précédée de 0x, sinon décimale). Notez que les valeurs 0 à 9 sont spéciales : elles sont à la fois des noms et des valeurs numériques. L'interprétation par défaut est les noms ; utilisez la forme hexadécimale 0x0 à 0x9 pour interpréter comme des valeurs numériques.

EXEMPLES

xkbcli-how-to-type --layout us 97
 
xkbcli-how-to-type --layout us 0x61
 
xkbcli-how-to-type --layout us U+0061
 
xkbcli-how-to-type --layout us a
Imprime les combinaisons de touches qui produisent la lettre « a » (point de code décimal : 97, point de code hexadécimal : 61) dans la disposition us par défaut.
xkbcli-how-to-type --layout us --keysym 97
 
xkbcli-how-to-type --layout us --keysym 0x61
 
xkbcli-how-to-type --layout us --keysym a
Imprime les combinaisons de touches qui produisent la touche « a » (code décimal : 97, code hexadécimal : 61) dans la disposition us par défaut.

OPTIONS

--keysym
Traite l'argument uniquement comme une touche
--disable-compose
Désactive le support Compose
--format format_keymap
Spécifie le format du keymap (numérique ou étiquette, par ex. « v1 »)
--keymap [= CHEMIN]
Charge le keymap XKB depuis un fichier, ignore les options RMLVO. Si CHEMIN est vide ou « - », lit depuis l'entrée standard.
--rules règles
Le jeu de règles XKB
--model modèle
Le modèle XKB
--layout disposition
La disposition XKB
--variant variante
La variante de la disposition XKB
--options options
Les options XKB
--enable-environment-names
Permet de définir les valeurs RMLVO par défaut via les variables d'environnement suivantes :
  • XKB_DEFAULT_RULES
  • XKB_DEFAULT_MODEL
  • XKB_DEFAULT_LAYOUT
  • XKB_DEFAULT_VARIANT
  • XKB_DEFAULT_OPTIONS
Notez que cette option peut affecter les valeurs par défaut des options précédentes.
--verbose
Active la sortie de débogage détaillée
--help
Imprime un message d'aide et quitte.
