NOM

xkbcli-compile-compose — compile un fichier Compose X Keyboard

SYNTAXE

xkbcli-compile-compose [options] [FICHIER_COMPOSE]

DESCRIPTION

xkbcli-compile-compose compile et affiche un fichier Compose basé sur les options données

FICHIER_COMPOSE
Chemin vers le fichier compose à charger, ou « - » pour lire l'entrée standard
--help
Affiche l'aide et quitte
--verbose
Active la sortie de débogage verbeuse
--file FICHIER
Spécifie un fichier Compose à charger, ou « - » pour lire l'entrée standard.

OBSOLÈTE : ajoutez le chemin du fichier sans le drapeau.

--locale LOCALISATION
Spécifie directement la localisation, au lieu de s'appuyer sur les variables d'environnement LC_ALL, LC_TYPE et LANG.
--test
Teste la compilation mais n'affiche pas le fichier Compose

VOIR AUSSI
