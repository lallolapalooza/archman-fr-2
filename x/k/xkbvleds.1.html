xkbvleds(1) Manuel des commandes générales xkbvleds(1)

NOM

xkbvleds - utilitaire utilisateur d'extension XKB

SYNTAXE

xkbvleds [-indpy <nom>] [-watch <leds>] [[-+]automatique] [[-+]explicite] [[-+]nom] [[-+]reel] [[-+]virtuel] [-intersection] [-union]

DESCRIPTION

Ce programme est utilisé pour afficher l'état des LED d'un clavier XKB. Il signale les changements dans les composants fondamentaux de l'état XKB, y compris l'état de compatibilité effectif. L'ensemble par défaut de LED est -union +nom +automatique +reel.

OPTIONS

-indpy <nom>
Masque des LED à surveiller
-watch <leds>
activer la synchronisation
∓automatique
(Ne pas) surveiller les LED automatiques
∓explicite
(Ne pas) surveiller les LED explicites
∓nom
(Ne pas) surveiller les LED nommées
∓reel
(Ne pas) surveiller les LED réelles
∓virtuel
(Ne pas) surveiller les LED virtuelles
-intersection
Surveiller uniquement les LED dans tous les ensembles souhaités
-union
Surveiller les LED dans n'importe quel ensemble souhaité
-aide
afficher la liste des options et quitter
-version
afficher la version du programme et quitter
xkbutils 1.0.6 X Version 11
