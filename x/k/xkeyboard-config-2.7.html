NOM

xkeyboard-config - Fichiers de description des données XKB

DESCRIPTION

xkeyboard-config fournit les fichiers de description pour l'extension X Keyboard (XKB) et pour libxkbcommon. Généralement, c'est le rôle de l'environnement de bureau d'appliquer la configuration demandée. Les utilisateurs exécutant un serveur X peuvent également utiliser l'outil setxkbmap(1) pour appliquer la configuration du clavier au moment de l'exécution ou configurer les paramètres XKB dans xorg.conf(5).

CHEMINS DE CHARGEMENT DES FICHIERS DE DONNÉES XKB

xkeyboard-config fournit les fichiers de données XKB installés dans /usr/share/xkeyboard-config-2. Les fichiers de données spécifiques à l'utilisateur peuvent se trouver ailleurs, mais cela dépend de l'outil si ces fichiers sont chargés. Par exemple, la bibliothèque libxkbcommon chargera par défaut les fichiers de données XKB du répertoire personnel de l'utilisateur. Voir la documentation de libxkbcommon pour plus de détails.

LA DISPOSITION PERSONNALISÉE

La disposition "custom" est une disposition répertoriée comme disponible pour les outils lisant les fichiers de données mais qui n'est pas réellement fournie par xkeyboard-config. Un utilisateur peut enregistrer une spécification de disposition dans le fichier /usr/share/xkeyboard-config-2/symbols/custom et cette disposition sera disponible pour la plupart des outils interagissant avec les fichiers de données xkeyboard-config. Ceci est principalement destiné aux systèmes exécutant X où des chemins de recherche supplémentaires ne peuvent pas être facilement ajoutés.

Étant donné que la disposition "custom" est simplement listée comme disponible mais non fournie par xkeyboard-config, la disposition ne sera pas écrasée lors des mises à jour.

xkeyboard-config(7)

X Keyboard Extension (XKB) configuration files

DESCRIPTION

The X Keyboard Extension (XKB) extends the X Window System's keyboard management capabilities. It allows for complex keyboard layouts, keyboard switching, multiple keymaps, and other features that were difficult or impossible with the older X Keyboard Extension (XKB). XKB is implemented as a set of extensions to the X server and a set of libraries and data files.

This manual page describes the XKB configuration files. These files define the various components of the XKB extension. The files are usually located in the directory /usr/share/X11/xkb/. The actual location may vary depending on the system configuration.

The XKB configuration consists of several types of files:

  • Compat files: define compatibility settings for various keyboard models.
  • Keycodes files: map physical keycodes to symbolic names.
  • Types files: define how modifier keys and groups interact.
  • Compatibility files: define how modifier keys and groups interact.
  • Symbols files: define the meaning of keys (symbols) for different layouts and levels.
  • Geometry files: describe the physical layout of keyboards.
  • Rules files: provide a high-level description of how to combine the other components to create a complete keyboard map.

The setxkbmap command is used to load and configure XKB settings. The xkbcomp command can be used to compile and validate XKB configuration files.

XKB DATA FILES LOAD PATHS

The X server and associated utilities look for XKB data files in a set of directories. The primary search path is defined by the XKB_CONFIG_ROOT environment variable, which defaults to /usr/share/X11/xkb. Additional search paths can be specified using the XKB_CONFIG_PATH environment variable.

THE CUSTOM LAYOUT

In addition to the standard layouts, XKB allows users to define custom layouts. These custom layouts are typically stored in the user's home directory or in a system-wide directory. The xkbcomp command can be used to compile custom layouts into a format that the X server can load.

MODELS

The models directory contains files that describe the physical characteristics of various keyboards. These files are used by XKB to determine how to interpret the keycodes generated by the keyboard.

Some common models include:

evdev
The default model for most modern Linux systems using the evdev input driver.
pc105
A generic 105-key PC keyboard layout.
applealuminum
Layout for the Apple Aluminum keyboard.

LAYOUTS

The symbols directory contains files that define the mapping between keycodes and the symbols (characters, functions, etc.) that are generated when the keys are pressed. These files are organized by layout and variant.

Some common layouts include:

us
US English layout.
gb
British English layout.
de
German layout.
fr
French layout.
es
Spanish layout.
ru
Russian layout.

Each layout may have several variants, such as:

dvorak
Dvorak keyboard layout.
colemak
Colemak keyboard layout.
intl
International layout with dead keys.

OPTIONS

The rules directory contains files that define various options that can be used to modify the behavior of the keyboard. These options can be enabled or disabled using the setxkbmap command.
