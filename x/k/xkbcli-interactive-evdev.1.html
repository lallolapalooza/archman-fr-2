NOM

xkbcli-interactive-evdev — débogueur interactif pour les dispositions de clavier XKB

SYNOPIS

xkbcli-interactive-evdev [options] [CHEMIN_DISPOSITION]

DESCRIPTION

xkbcli-interactive-evdev est un outil en ligne de commande pour déboguer interactivement les dispositions de clavier XKB en écoutant les périphériques evdev de /dev/input/eventX.

xkbcli-interactive-evdev nécessite l'autorisation d'ouvrir les nœuds de périphérique evdev. Cela nécessite généralement d'être l'utilisateur « root » ou d'appartenir au groupe « input ».

Appuyez sur la touche Échap pour quitter.

Ceci est un outil de débogage, son comportement ou sa sortie ne sont pas garantis d'être stables.

CHEMIN_DISPOSITION
Chemin vers un fichier de disposition de clavier, ou « - » pour lire l'entrée standard
--help
Afficher l'aide et quitter
--verbose
Activer la sortie de débogage détaillée
--include CHEMIN
Ajouter le chemin donné à la liste des chemins d'inclusion. Cette option dépend de l'ordre, les chemins d'inclusion donnés en premier sont recherchés en premier. Si un chemin d'inclusion est donné, la liste par défaut des chemins d'inclusion n'est pas utilisée. Utilisez --include-defaults pour ajouter les chemins d'inclusion par défaut.
--include-defaults
Ajouter l'ensemble par défaut des répertoires d'inclusion. Cette option dépend de l'ordre, les chemins d'inclusion donnés en premier sont recherchés en premier.
--format format_disposition
Spécifier le format de la disposition de clavier (numérique ou libellé, par ex. « v1 »)
--rules règles
Le jeu de règles XKB
--model modèle
Le modèle XKB
--layout disposition
La disposition XKB
--variant variante
La variante de disposition XKB
--option options
Les options XKB
--enable-environment-names
Permettre de définir les valeurs RMLVO par défaut via les variables d'environnement suivantes :
  • XKB_DEFAULT_RULES
  • XKB_DEFAULT_MODEL
  • XKB_DEFAULT_LAYOUT
  • XKB_DEFAULT_VARIANT
  • XKB_DEFAULT_OPTIONS
Notez que cette option peut affecter les valeurs par défaut des options précédentes.
--keymap fichier
Spécifier un chemin de disposition de clavier. Cette option est mutuellement exclusive avec les options RMLVO.
--enable-compose
Activer la fonctionnalité Compose
--consumed-mode {xkb|gtk}
Définir le mode des modificateurs consommés (par défaut : xkb)
--without-x11-offset
Ne pas ajouter de décalage de 8 lors de la conversion d'un code de touche evdev en code de touche XKB. Vous ne voudrez probablement pas de cette option.
--report-state-changes
Signaler les changements d'état du clavier
-1, --uniline
Activer la sortie d'événements sur une seule ligne.
--multiline
Activer la sortie d'événements sur plusieurs lignes.
--short
Afficher une sortie d'événement plus courte.
