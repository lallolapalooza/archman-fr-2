NOM

xkbsel-aw - sélectionne la disposition du clavier à l'aide d'une interface graphique Xaw

SYNTAXE

xkbsel-aw [OPTION]

DESCRIPTION

xkbsel-aw est une interface graphique simple pour sélectionner les claviers et indiquer la sélection actuelle. Il affiche une fenêtre où la sélection actuelle est indiquée. En cliquant sur cette fenêtre, un menu des raccourcis de carte configurés avec leurs descriptions apparaît, permettant d'en sélectionner un. installe la première carte configurée au démarrage.

OPTIONS

xkbsel-aw n'a pas ses propres options, mais il accepte les options Xt communes telles que -display, -geometry, -bg ou -fg. Comme les descriptions des cartes sont normalement écrites dans la langue locale, xkbsel-aw utilise des jeux de polices au lieu de polices pour permettre la sélection automatique du codage basée sur la locale actuelle. Cela signifie que -fn ne fonctionnera pas. Utilisez fontSet à cet effet, soit en ligne de commande en utilisant par exemple
-xrm '*fontSet: -*-courier-medium-r-*-*-*-100-*-*-m-*-*-*'
soit en utilisant le fichier de défaut de l'application.

EXEMPLES

Configuration Fvwm2

Les lignes suivantes ajoutées à .fvwm2rc démarreront automatiquement le sélecteur à la connexion :

Style "xkbsel-aw" NoTitle, Sticky, WindowListSkip

AddToFunc "InitFunction" "I" ...
[...éléments originaux...]
+ "I" Exec exec xkbsel-aw -geometry 48x24-0-0 &

Si vous utilisez les modules FvwmWharf ou FvwmButtons, au lieu de démarrer et de positionner explicitement xkbsel-aw dans InitFunction, vous pouvez intégrer l'application dans ces modules en utilisant le répertoire Swallow, par exemple en ajoutant la ligne suivante à votre configuration FvwmButtons dans .fvwm2rc (doit être écrite sur une seule ligne) :

*FvwmButtons(Swallow (NoHints) "xkbsel-aw"
'Exec xkbsel-aw -geometry 48x24')

Pour changer de clavier avec Ctrl+F1, -F2 etc., ajoutez quelque chose comme ceci à votre .fvwm2rc :

Key F1 A C Exec exec xkbsel us
Key F2 A C Exec exec xkbsel sk
Key F3 A C Exec exec xkbsel cs
