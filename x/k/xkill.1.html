XKILL(1) Manuel des commandes générales XKILL(1)

NOM

xkill - tuer un client par sa ressource X

SYNTAXE

xkill [-display nom_affichage] [-id ressource] [-button nombre] [-frame] [-all] [-version]

DESCRIPTION

Xkill est un utilitaire pour forcer le serveur X à fermer les connexions avec les clients. Ce programme est très dangereux, mais utile pour interrompre des programmes qui ont affiché des fenêtres indésirables sur l'écran d'un utilisateur. Si aucun identifiant de ressource n'est donné avec -id, xkill affichera un curseur spécial comme invite pour que l'utilisateur sélectionne une fenêtre à tuer. Si un bouton du pointeur est pressé sur une fenêtre non-racine, le serveur fermera sa connexion avec le client qui a créé la fenêtre.

OPTIONS

-display nom_affichage
Cette option spécifie le nom du serveur X à contacter.
-id ressource
Cette option spécifie l'identifiant X de la ressource dont le créateur doit être interrompu. Si aucune ressource n'est spécifiée, xkill affichera un curseur spécial avec lequel vous devriez sélectionner une fenêtre à tuer.
-button nombre
Cette option spécifie le numéro du bouton du pointeur qui doit être utilisé pour sélectionner une fenêtre à tuer. Si le mot "any" est spécifié, n'importe quel bouton du pointeur peut être utilisé. Par défaut, le premier bouton de la table du pointeur (qui est généralement le bouton le plus à gauche) est utilisé.
-all
Cette option indique que tous les clients ayant des fenêtres de niveau supérieur à l'écran doivent être tués. Xkill vous demandera de sélectionner la fenêtre racine avec chacun des boutons actuellement définis pour vous donner plusieurs chances d'interrompre. L'utilisation de cette option est fortement déconseillée.
-frame
Cette option indique que xkill doit ignorer les conventions standard pour trouver les fenêtres clients de niveau supérieur (qui sont généralement imbriquées dans une fenêtre de gestionnaire de fenêtres), et croire simplement que vous voulez tuer les enfants directs de la racine.
-version
Cette option fait afficher à xkill sa version et sortir sans tuer quoi que ce soit.

ATTENTION

Cette commande ne fournit aucune garantie que l'application dont la connexion au serveur X est fermée s'interrompra proprement, ni même qu'elle s'interrompra tout court. Tout ce que fait cette commande est de fermer la connexion au serveur X. De nombreuses applications existantes s'interrompent effectivement lorsque leur connexion au serveur X est fermée, mais certaines peuvent choisir de continuer.

XDEFAULTS

Button
Spécifie un numéro de bouton de pointeur spécifique ou le mot "any" à utiliser lors de la sélection des fenêtres.

VOIR AUSSI

X(7), xwininfo(1), XKillClient(3), XGetPointerMapping(3), KillClient dans la spécification du protocole X
