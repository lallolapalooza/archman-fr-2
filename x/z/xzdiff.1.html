XZDIFF(1) Utilitaires XZ XZDIFF(1)

NOM

xzcmp, xzdiff, lzcmp, lzdiff - comparer des fichiers compressés

SYNTAXE

xzcmp [option...] fichier1 [fichier2]
xzdiff ...
lzcmp ... (OBSOLÈTE)
lzdiff ... (OBSOLÈTE)

DESCRIPTION

xzcmp et xzdiff comparent le contenu décompressé de deux fichiers. Les données décompressées et les options sont passées à cmp(1) ou diff(1) sauf si --help ou --version est spécifié.

Si fichier1 et fichier2 sont tous deux spécifiés, ils peuvent être des fichiers non compressés ou des fichiers dans des formats que xz(1), gzip(1), bzip2(1), lzop(1), zstd(1), ou lz4(1) peuvent décompresser. Les commandes de décompression nécessaires sont déterminées à partir des suffixes de nom de fichier de fichier1 et fichier2. Un fichier avec un suffixe inconnu est supposé être soit non compressé, soit dans un format que xz(1) peut décompresser.

Si un seul nom de fichier est fourni, fichier1 doit avoir un suffixe d'un format de compression pris en charge et le nom de fichier2 est supposé être fichier1 avec le suffixe du format de compression supprimé.

Les commandes lzcmp et lzdiff sont fournies pour la compatibilité descendante avec LZMA Utils. Elles sont obsolètes et seront supprimées dans une future version.

CODE DE SORTIE

Si une erreur de décompression survient, le code de sortie est 2. Sinon, le code de sortie de cmp(1) ou diff(1) est utilisé.

VOIR AUSSI

cmp(1), diff(1), xz(1), gzip(1), bzip2(1), lzop(1), zstd(1), lz4(1)
