XMMS2D(1) Manuel des commandes générales XMMS2D(1)

NOM

xmms2d - démon XMMS2 qui gère la lecture de musique et le stockage des métadonnées musicales

SYNTAXE

xmms2d [-v|-q] [-p dir] [-o plugin] [-i url] [-c fichier] [-s fd] [--yes-run-as-root]
xmms2d -?
xmms2d -V

DESCRIPTION

XMMS2 est une refonte du lecteur de musique XMMS (https://en.wikipedia.org/wiki/XMMS). Il utilise un modèle client-serveur, permettant plusieurs interfaces utilisateur (même simultanées !), textuelles et graphiques. Tous les formats audio courants sont pris en charge à l'aide de plugins. De plus, il dispose d'une bibliothèque multimédia flexible pour organiser votre musique.

xmms2d est le démon par lequel les clients XMMS2 lisent et gèrent la musique. Une bibliothèque client fournie permet à des tiers d'écrire facilement des clients XMMS2, notamment à l'aide des liaisons Python et Ruby.

xmms2d utilise une méthode en trois parties pour la lecture de musique. La musique est accédée depuis le disque ou le réseau à l'aide d'un plugin de transport, les données sont ensuite transmises à un plugin de décodage qui décode l'audio dans un format jouable par un plugin de sortie.

OPTIONS

Options générales

-v, --verbose
Augmente la verbosité.
-q, --quiet
Diminue la verbosité.
-p dir, --plugindir=dir
Utilise le répertoire de plugins dir.
-o plugin, --output=plugin
Utilise le plugin de sortie plugin.
-i url, --ipc-socket=url
Écoute sur le socket à l'adresse url. Plusieurs sockets peuvent être spécifiés séparés par des caractères ;. Voir la section SOCKET_IPC.
-c fichier, --conf=fichier
Utilise le fichier de configuration fichier.
-s fd, --status-fd=fd
Écrit dans le descripteur de fichier fd au démarrage. Ceci peut être utilisé pour attendre que la communication inter-processus (IPC) soit opérationnelle, comme le fait par exemple xmms2-launcher(1).
--yes-run-as-root
Permet à xmms2d d'être exécuté en tant que root.

Obtenir de l'aide

-h, -?, --help
Affiche les informations d'aide de base et quitte.
-V, --version
Affiche les informations de version.

SOCKET IPC

Les clients XMMS2 utilisent des sockets IPC pour communiquer avec xmms2d. Ces sockets IPC sont spécifiés dans un format basé sur des URL avec trois méthodes de transport possibles : unix, tcp et tcp6.

Les méthodes TCP permettent aux clients de se connecter via IPv4 et IPv6 à xmms2d et donc de contrôler XMMS2 à distance. Une URL de socket IPC typique utilisant TCP est tcp://127.0.0.1:9667.

La méthode de transport UNIX est réservée aux clients locaux et crée un fichier via lequel les clients XMMS2 peuvent accéder à xmms2d. Un chemin de socket IPC typique utilisant le transport UNIX est unix:///tmp/xmms-ipc-foobar.

FICHIERS

Ci-dessous, CONFDIR est $XDG_CONFIG_HOME/xmms2 sur UNIX si la variable d'environnement XDG_CONFIG_HOME est définie. Sinon, c'est $HOME/.config/xmms2 (UNIX sauf Darwin), ou $HOME/Library/xmms2 (Darwin). Sur Win32, c'est %APPDATA%/xmms2.

CONFDIR/xmms2.conf
Un fichier de configuration au format XML qui permet de modifier les paramètres de xmms2d.
CONFDIR/startup.d/
Un répertoire contenant des programmes qui sont exécutés lorsque xmms2d est lancé. Un emplacement alternatif peut être spécifié dans le fichier de configuration.
CONFDIR/shutdown.d/
Un répertoire contenant des programmes qui sont exécutés lorsque xmms2d est arrêté correctement. Un emplacement alternatif peut être spécifié dans le fichier de configuration.
CONFDIR/medialib.db
Une base de données sqlite3(1) qui contient des informations sur chaque chanson ajoutée à la bibliothèque multimédia XMMS2. Un emplacement alternatif peut être spécifié dans le fichier de configuration.
CONFDIR/bindata/
Un répertoire contenant des fichiers avec des données binaires confiées à la bibliothèque multimédia XMMS2, comme des pochettes d'album. Un emplacement alternatif peut être spécifié dans le fichier de configuration.
/tmp/xmms-ipc-USER
L'emplacement typique pour le socket IPC UNIX. Ici, USER est le nom de l'utilisateur qui a exécuté xmms2d.

ENVIRONNEMENT

XDG_CONFIG_HOME
Le chemin où se trouvent les fichiers de configuration et les ressources XMMS2.
XMMS_PATH
L'URL du premier socket sur lequel xmms2d écoute. Cette variable d'environnement est définie pour les programmes dans les répertoires de démarrage et d'arrêt.
XMMS_PATH_FULL
Une liste séparée par des ; des chemins sur lesquels xmms2d écoute. Cette variable d'environnement est définie pour les programmes dans les répertoires de démarrage et d'arrêt.

    NOM

    xmms2d - Processeur de musique XMMS2

    SYNTAXE

    xmms2d [OPTIONS]

    DESCRIPTION

    xmms2d est le démon du système de lecture audio XMMS2. Il gère le noyau de lecture, la base de données, les flux audio et les plugins.

    OPTIONS

    -d, --daemon
    S'exécute en tant que démon (arrière-plan).
    -p, --pidfile FICHIER
    Écrit l'ID du processus dans FICHIER.
    -l, --logfile FICHIER
    Écrit les messages de journalisation dans FICHIER.
    -f, --configfile FICHIER
    Charge la configuration à partir de FICHIER.
    -h, --help
    Affiche un message d'aide et quitte.
    -v, --version
    Affiche les informations de version et quitte.

    FICHIERS

    ~/.config/xmms2/config
    Fichier de configuration par défaut pour le client.
    /etc/xmms2/xmms2d.conf
    Fichier de configuration du démon.

    ENVIRONNEMENT

    XMMS_CONFIG_DIR
    Définit le répertoire de configuration.

    VOIR AUSSI

    xmms2(1), xmms2-playlist(5)
