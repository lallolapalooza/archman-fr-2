XMMS2-ET(1) Manuel des commandes générales XMMS2-ET(1)

NOM

xmms2-et - transmet un paquet d'informations anonymes à l'équipe XMMS2 à chaque changement de chanson

SYNTAXE

xmms2-et

DESCRIPTION

XMMS2 est une refonte du lecteur de musique XMMS (https://github.com/xmms2). Il dispose d'un modèle client-serveur, permettant plusieurs interfaces utilisateur (même simultanées !), textuelles et graphiques. Tous les formats audio courants sont pris en charge à l'aide de plugins. En plus de cela, il existe une bibliothèque multimédia flexible pour organiser votre musique.

xmms2-et est le client ET Phone Home pour XMMS2. xmms2-et est conçu pour transmettre un paquet d'informations à l'équipe XMMS2 chaque fois qu'une nouvelle chanson est jouée. Le paquet est anonyme et ne contient pas de métadonnées sur la chanson en cours de lecture. Les spécificités des données transmises à l'équipe XMMS2 peuvent être trouvées dans la section PAQUET ET de cette page de manuel.

xmms2-et est utilisé pour l'ingénierie de publication par l'équipe XMMS2. Au cours d'un cycle de publication, l'utilisation de divers plugins, systèmes d'exploitation et composants XMMS2 est collectée à partir des données transmises par le client xmms2-et. Une publication est effectuée lorsque des tests suffisants ont eu lieu, tels que déterminés par le nombre de paquets xmms2-et associés que l'équipe XMMS2 a reçus.

PAQUET ET

Les données suivantes sont transmises à chaque paquet transmis par xmms2-et:

statut XMMS2-ET
Démarre les paquets XMMS2-ET ; statut donne un message descriptif indiquant la raison de ce paquet. (par exemple, Arrêt propre, Arrêt impropre, Nouveau média)
version=version
contient la version du démon XMMS2
system=os
contient le nom et la version du système d'exploitation sur lequel xmms2d s'exécute
output=output_plugin
contient le plugin de sortie utilisé pour la lecture audio par xmms2d
starttime=start_time
contient l'heure à laquelle le client xmms2-et a été démarré
uptime=xmms2d_uptime
contient le temps de fonctionnement du client xmms2-et
playlistloads=times
contient le nombre de fois qu'une playlist a été chargée depuis la Bibliothèque Multimédia
mlibresolves=times
contient le nombre de fois que les métadonnées ont été résolues pour les médias dans la Bibliothèque Multimédia

Les données suivantes sont différentes pour chaque chanson jouée :

decoder=plugin
contient le plugin décodeur utilisé pour lire la dernière chanson jouée
transport=plugin
contient le plugin de transport utilisé pour lire la dernière chanson jouée
samplefmt:in=in_fmt
contient le format d'échantillon du fichier audio original de la dernière chanson jouée
samplefmt:out=out_fmt
contient le format d'échantillon qui a été envoyé au plugin de sortie pour la dernière chanson jouée
samplerate:in=in_rate
contient le taux d'échantillonnage du fichier audio original de la dernière chanson jouée
samplerate:out=out_rate
contient le taux d'échantillonnage qui a été envoyé au plugin de sortie pour la dernière chanson jouée
channels:in=number_in
contient le nombre de canaux du fichier audio original de la dernière chanson jouée
channels:out=number_out
contient le nombre de canaux qui ont été envoyés au plugin de sortie pour la dernière chanson jouée

VARIABLES D'ENVIRONNEMENT

XMMS_PATH
Le chemin d'URL vers xmms2d. Voir SOCKET IPC dans xmms2d(8) pour les détails sur les valeurs possibles pour cette variable
