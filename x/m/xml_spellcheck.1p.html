NOM

xml_spellcheck - vérification orthographique des fichiers XML

SYNTAXE

xml_spellcheck [options] <fichiers>

DESCRIPTION

xml_spellcheck vous permet de vérifier l'orthographe du contenu d'un fichier XML. Il extrait le texte (le contenu des éléments et éventuellement des attributs), le soumet à un correcteur orthographique, puis recrée le document XML.

OPTIONS

Notez que toutes les options peuvent être abrégées à la première lettre.

--conf <fichier_configuration>
Récupère les options à partir d'un fichier de configuration. PAS ENCORE IMPLÉMENTÉ.
--correcteur <correcteur>
La commande à utiliser pour la vérification orthographique, y compris toute option.

Par défaut, "aspell -c" est utilisé.

--extension-sauvegarde <extension>
Par défaut, le fichier original est sauvegardé avec l'extension ".bak". Cette option change l'extension.
--attributs
Vérifie l'orthographe du contenu des attributs. Par défaut, les valeurs des attributs NE SONT PAS vérifiées. PAS ENCORE IMPLÉMENTÉ.
--elements-exclus <liste_elements_exclus>
Une liste d'éléments qui ne doivent pas être vérifiés orthographiquement.
--elements-inclus <liste_elements_inclus>
Une liste d'éléments qui doivent être vérifiés orthographiquement (par défaut, tous les éléments sont vérifiés).

"--elements-exclus" et "--elements-inclus" sont mutuellement exclusifs.

--joli-impression <style_joli_impression_optionnel>
Un style de mise en forme agréable pour le document, tel que défini dans XML::Twig. Si l'option est fournie sans valeur, le style "indented" est utilisé.
--version
Affiche la version de l'outil et quitte.
--aide
Affiche le message d'aide et quitte.
--man
Affiche un message d'aide plus long et quitte.
