NOM

xml_merge - fusionne les fichiers XML préalablement séparés avec C<xml_split>

DESCRIPTION

"xml_merge" prend plusieurs fichiers xml qui ont été séparés à l'aide de "xml_split" et recrée un fichier unique.

OPTIONS

-o <fichier_sortie>
sauf si cette option est utilisée, la sortie du programme va vers STDOUT
-i
les fichiers utilisent XInclude au lieu des instructions de traitement (ils ont été créés en utilisant l'option "-i" dans "xml_split")
-v
sortie verbeuse
-V
affiche la version et quitte
-h
aide courte
-m
man (nécessite que pod2text soit dans le PATH)

EXEMPLES

xml_merge foo-00.xml             # sortie vers stdout
xml_merge -o foo.xml foo-00.xml  # sortie vers foo.xml

VOIR AUSSI
