NOM

xml2-config - script pour obtenir des informations sur la version installée de libxml2

SYNTAXE

xml2-config [--prefix[=DIR]] [--libs] [--cflags] [--version] [--help]

DESCRIPTION

xml2-config est un outil utilisé pour déterminer les indicateurs de compilation et de liaison qui devraient être utilisés pour compiler et lier des programmes qui utilisent libxml2.

OPTIONS

xml2-config accepte les options suivantes :

--version
Affiche la version actuellement installée de libxml2 sur la sortie standard.
--libs
Affiche les indicateurs de liaison qui sont nécessaires pour lier un programme libxml2. Ajoutez --dynamic après --libs pour n'afficher que les informations de liaison de bibliothèque partagée.
--cflags
Affiche les indicateurs du compilateur qui sont nécessaires pour compiler un programme libxml2.
--prefix=PREFIX
Si spécifié, utilise PREFIX à la place du préfixe d'installation avec lequel libxml2 a été construit lors du calcul de la sortie pour les options --cflags et --libs. Cette option doit être spécifiée avant toute option --libs ou --cflags.
