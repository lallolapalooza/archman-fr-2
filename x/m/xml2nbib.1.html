bibutils - utilitaires de conversion de bibliographie

SYNTAXE

format2xml [OPTIONS] [fichier.format]

xml2format [OPTIONS] [fichier.xml]

DESCRIPTION

Le jeu de programmes bibutils permet d'inter-convertir divers formats de bibliographie en utilisant le schéma Metadata Object Description Schema (MODS)[2] version 3.1 de la Library of Congress[1]. Par exemple, on peut convertir des fichiers au format RIS en Bibtex en effectuant deux transformations : RIS->MODS->Bibtex.

Options communes pour la conversion vers MODS

Plusieurs indicateurs sont disponibles pour les programmes end2xml, endx2xml, bib2xml, ris2xml, med2xml, et copac2xml. La plupart des options ont une version courte et une version longue.

-h --help affiche l'aide
-v --version affiche la version
-a --add-refcount ajoute "_#", où # est le nombre de références, à l'identifiant de référence
-s --single-refperfile met une référence par fichier nommé d'après le numéro de référence
-i --input-encoding interprète le fichier d'entrée comme utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères sur www.kostis.net[4]) unicode est maintenant une option de jeu de caractères
-u --unicode-characters encode les caractères unicode directement dans le fichier plutôt que sous forme d'entités XML
-un --unicode-no-bom comme -u, mais n'inclut pas de marque d'ordre des octets
-x --xml-entities encode les caractères unicode sous forme d'entités XML (l'opposé de -u)
-nl --no-latex ne convertit pas les combinaisons de caractères de style latex
-s --single-refperfile une référence par fichier de sortie
-d --drop-key ne met pas la clé de citation dans le champ id de mods
-c --corporation-file avec un argument spécifiant un fichier contenant une liste de noms de sociétés à placer dans <name type="corporate"></name> au lieu de type="personal" et à éliminer le déchiffrement des noms
-a --asis avec un argument spécifiant un fichier contenant une liste de noms à traiter tels quels
-nt --nosplit-title ne sépare pas les titres en paires TITRE/SOUS-TITRE
--verbose sortie verbeuse
--debug sortie très verbeuse (principalement pour le débogage)

bib2xml

bib2xml convertit un fichier de références au format bibtex en un fichier bibliographique intermédiaire XML. Spécifiez les fichiers à convertir sur la ligne de commande. Les fichiers contenant des chaînes de substitutions bibtex doivent être spécifiés avant les fichiers où les substitutions sont spécifiées (ou dans le même fichier avant leur utilisation). Si aucun fichier n'est spécifié, les informations bibtex seront lues depuis l'entrée standard.

bib2xml bibtex_file.bib > output_file.xml

biblatex2xml

biblatex2xml convertit un fichier de références au format biblatex (à ne pas confondre avec bibtex) en un fichier bibliographique intermédiaire MODS XML.

biblatex2xml biblatex_file.bib > outputfile.xml

copac2xml

copac2xml convertit un fichier de références au format COPAC en un fichier bibliographique intermédiaire MODS XML.

end2xml

end2xml convertit un fichier de références au format texte EndNote en un fichier bibliographique intermédiaire XML. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté. Les formats étiquetés Endnote ("Refer" format export) ressemblent à l'Exemple 1, « Exemple de fichier au format refer ». Il y a de très bonnes instructions pour s'assurer que vous exportez correctement ceci à http://www.sonnysoftware.com/endnoteimport.html[5]

L'utilisation de end2xml est la même que celle de bib2xml.

end2xml endnote_file.end > output_file.xml

ebi2xml

ebi2xml convertit un fichier EBI XML en un fichier bibliographique intermédiaire MODS XML.

endx2xml

endx2xml convertit un fichier de références exporté au format EndNote-XML en un fichier bibliographique intermédiaire MODS XML. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté.

isi2xml

isi2xml convertit un fichier de références au format ISI-web-of-science en un fichier bibliographique intermédiaire XML.

L'utilisation de isi2xml est la même que celle de bib2xml.

isi2xml input_file.isi > output_file.xml

ris2xml

ris2xml convertit un fichier de références au format RIS en un fichier bibliographique intermédiaire XML. L'utilisation de ris2xml est comme celle de end2xml et bib2xml.

ris2xml ris_file.ris >	output_file.xml

wordbib2xml

wordbib2xml convertit un fichier de références au format Word2007 en un fichier bibliographique intermédiaire XML.

Notez que --output-encoding fait référence au fichier d'entrée

-h --help afficher l'aide
-v --version afficher la version
-o --output-encoding interpréter le fichier d'entrée comme utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères sur www.kostis.net[4]) unicode est maintenant une option de jeu de caractères
-s --single-refperfile mettre une référence par nom de fichier, par numéro de référence
-nb --no-bom ne pas écrire de marque d'ordre des octets (BOM) lors de l'écriture en UTF8

xml2bib

xml2bib convertit la bibliographie XML MODS en un fichier de référence formaté en bibtex. L'utilisation de xml2bib est la même que pour les autres outils

xml2bib xml_file.xml > output_file.bib

Étant donné que le format de référence BibTeX est assez flexible et semble avoir le plus grand nombre de préférences personnelles, il a également accumulé un certain nombre d'options spécifiques qui ne sont pas disponibles pour d'autres formats.

À partir de la version 3.24, la sortie de xml2bib utilise des balises en minuscules et des types de référence en casse mixte pour une meilleure interaction avec d'autres logiciels. Le comportement précédent avec toutes les balises/types de référence en majuscules peut toujours être généré en utilisant le commutateur de ligne de commande -U/--uppercase.

Options spécifiques à xml2bib :

-fc --finalcomma ajouter une virgule finale dans la sortie bibtex pour ceux qui la souhaitent
-sd --singledash utiliser un trait au lieu de deux (trait plus long en latex) entre les numéros dans la sortie des pages
-b --brackets utiliser des crochets au lieu de guillemets autour des données des champs
-w --whitespace ajouter des espaces blancs d'embellissement à la sortie
-U --uppercase utiliser toutes les majuscules pour les balises (noms de champs) et les types de référence (comportement pré-3.24)
-sk --strictkey utiliser uniquement des caractères alphanumériques pour les clés de citation bibtex

xml2ads

xml2ads convertit la bibliographie XML MODS au format de référence du Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) Astrophyics Data System ou ADS[6] (qui est très similaire au style Endnote balisé). L'utilisation de xml2ads est la même que pour les autres outils

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convertit la bibliographie XML MODS en un fichier de bibliographie formaté en RIS. L'utilisation de xml2ris est la même que pour les autres outils

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convertit la bibliographie XML MODS en un fichier de bibliographie Endnote balisé (format refer). L'utilisation de xml2end est la même que pour les autres outils

xml2end xml_file.xml > output_file.end

xml2wordbib

xml2wordbib convertit la bibliographie XML MODS en un fichier de bibliographie XML formaté pour Word 2007. L'utilisation de xml2wordbib est la même que pour les autres outils

xml2wordbib xml_file.xml > output_file.word.xml

xml2wordbib s'appelait xml2word dans les versions de bibutils antérieures à la 3.40. Il a été renommé pour éviter toute confusion avec d'autres outils. Espérons que cela ne cassera pas trop de scripts déjà en usage.

xml2nbib(1)

NOM

xml2nbib - Convertir des fichiers XML BibTeX en format nbib.

SYNTAXE

xml2nbib [OPTIONS] FICHIER_XML...

DESCRIPTION

xml2nbib est un utilitaire qui convertit des fichiers XML au format BibTeX en format nbib, utilisé couramment dans certains domaines de recherche et systèmes de gestion bibliographique.

CONVERSION VERS MODS

Ce programme ne traite pas de la conversion vers le format MODS. Il est spécifiquement conçu pour la conversion de XML BibTeX vers nbib.

CONVERSION DEPUIS MODS

Ce programme ne traite pas de la conversion depuis le format MODS. Il est spécifiquement conçu pour la conversion de XML BibTeX vers nbib.

EXEMPLES

Pour convertir un fichier references.xml en references.nbib :

xml2nbib references.xml > references.nbib

Pour convertir plusieurs fichiers XML et concaténer leur sortie nbib :

xml2nbib file1.xml file2.xml > all_references.nbib

LICENCE

Le programme xml2nbib est généralement distribué sous une licence libre, souvent la licence GPL.
