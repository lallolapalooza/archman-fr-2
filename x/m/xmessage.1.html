XMESSAGE(1) Manuel des commandes générales XMESSAGE(1)

NOM

xmessage - affiche un message ou une requête dans une fenêtre (basé sur X /bin/echo)

SYNTAXE

xmessage [ -buttons label1[:valeur1],label2[:valeur2], ... ] [ options ] -file nom_fichier
xmessage [ -buttons label1[:valeur1],label2[:valeur2], ... ] [ options ] message ...
xmessage [ -help | -version ]

DESCRIPTION

Le programme xmessage affiche une fenêtre contenant un message provenant de la ligne de commande, d'un fichier, ou de l'entrée standard. Le long du bord inférieur du message se trouve une rangée de boutons ; cliquer avec le bouton gauche de la souris sur l'un de ces boutons provoque la sortie de xmessage. Le bouton pressé est retourné dans le code de sortie et, optionnellement, en écrivant le label du bouton sur la sortie standard.

Le programme est typiquement utilisé par les scripts shell pour afficher des informations à l'utilisateur ou pour demander à l'utilisateur de faire un choix.

Sauf si une taille est spécifiée, xmessage s'adapte à la taille du message, jusqu'à une taille maximale. Si le message est trop grand pour la fenêtre, xmessage affichera des barres de défilement.

OPTIONS

Voici les options de ligne de commande que xmessage comprend, en plus de celles standard listées dans X(7).

-buttons bouton,bouton,...
Cette option fera en sorte que xmessage crée un bouton pour chaque argument bouton séparé par des virgules. La ressource correspondante est buttons. Chaque bouton se compose d'un label éventuellement suivi d'un deux-points et d'une valeur de sortie. Le label est le nom du widget Command créé et sera le texte par défaut affiché à l'utilisateur. Puisque c'est le nom du widget, il peut être utilisé pour changer n'importe laquelle des ressources associées à ce bouton. La valeur de sortie sera retournée par xmessage si ce bouton est sélectionné. La valeur de sortie par défaut est 100 plus le numéro du bouton. Les boutons sont numérotés de gauche à droite en commençant par un. La chaîne de caractères par défaut si aucune option -buttons n'est fournie est okay:0.
-default label
Définit le bouton avec un label correspondant comme étant le bouton par défaut. S'il n'est pas spécifié, il n'y a pas de bouton par défaut. La ressource correspondante est defaultButton. Appuyer sur Entrée n'importe où dans la fenêtre xmessage activera le bouton par défaut. Le bouton par défaut a une bordure plus large que les autres.
-file nom_fichier
Fichier à afficher. La ressource correspondante est file. Un nom_fichier de `-' lit depuis l'entrée standard. Si cette option n'est pas fournie, xmessage affichera tous les arguments qui ne sont pas des options, dans le style de echo. Soit -file, soit un message sur la ligne de commande doit être fourni, mais pas les deux.
-print
Ceci fera en sorte que le programme écrive le label du bouton pressé sur la sortie standard. Équivalent à définir la ressource printValue à TRUE. C'est une façon d'obtenir un retour sur le bouton qui a été pressé.
-center
Affiche la fenêtre au centre de l'écran. Équivalent à définir la ressource center à TRUE.
-nearmouse
Affiche la fenêtre près du curseur de la souris. Équivalent à définir la ressource nearMouse à TRUE.
-timeout sec
Sort avec le statut 0 après sec secondes si l'utilisateur n'a pas encore cliqué sur un bouton. La ressource correspondante est timeout.
-help
Affiche un message d'utilisation et quitte.
-version
Affiche les informations de version et quitte.

RESSOURCES

Le programme possède quelques ressources d'application de haut niveau qui permettent des personnalisations spécifiques à xmessage.

file
Une chaîne spécifiant le fichier à afficher.
buttons
Une chaîne spécifiant les boutons à afficher. Voir l'option de ligne de commande -buttons.
defaultButton
Une chaîne spécifiant un bouton par défaut par son label.
printValue
Une valeur booléenne spécifiant si le label du bouton pressé pour quitter le programme est écrit sur la sortie standard. La valeur par défaut est FALSE.
center
Une valeur booléenne spécifiant si la fenêtre doit apparaître au centre de l'écran. La valeur par défaut est FALSE.
nearMouse
Une valeur booléenne spécifiant si la fenêtre doit apparaître près du curseur de la souris. La valeur par défaut est FALSE.
timeout
Le nombre de secondes après lesquelles quitter avec le statut 0. La valeur par défaut est 0, ce qui signifie jamais expirer.
maxHeight (Classe Maximum)
La hauteur maximale de la partie texte de la fenêtre en pixels, utilisée si aucune taille n'a été spécifiée dans la géométrie. La valeur par défaut est 0, ce qui signifie utiliser 70% de la hauteur de l'écran.
maxWidth (Classe Maximum)
La largeur maximale de la partie texte de la fenêtre en pixels, utilisée si aucune taille n'a été spécifiée dans la géométrie. La valeur par défaut est 0, ce qui signifie utiliser 70% de la largeur de l'écran.

ACTIONS

exit(valeur)
quitte immédiatement avec un code de sortie de valeur (par défaut 0). Cette action peut être utilisée avec des traductions pour fournir des moyens alternatifs de quitter xmessage.
default-exit()
quitte immédiatement avec le code de sortie spécifié par le bouton par défaut. S'il n'y a pas de bouton par défaut, cette action n'a aucun effet.

STATUT DE SORTIE

S'il détecte une erreur, xmessage retourne 1, donc cette valeur ne doit pas être utilisée avec un bouton.
