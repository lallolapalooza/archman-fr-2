bibutils - utilitaires de conversion bibliographique

SYNOPSIS

format2xml [OPTIONS] [fichier.format]

xml2format [OPTIONS] [fichier.xml]

DESCRIPTION

Le programme bibutils convertit entre divers formats bibliographiques en utilisant le schéma de description des objets de métadonnées (MODS) version 3.1 de la Library of Congress[1]. Par exemple, on peut convertir des fichiers au format RIS en Bibtex en effectuant deux transformations : RIS->MODS->Bibtex.

Options communes pour la conversion en MODS

Plusieurs options sont disponibles pour les programmes end2xml, endx2xml, bib2xml, ris2xml, med2xml et copac2xml. La plupart des options ont une version courte et une version longue.

-h --help afficher l'aide
-v --version afficher la version
-a --add-refcount ajouter "_#" où # est le nombre de références à l'identifiant de référence
-s --single-refperfile mettre une référence par nom de fichier selon le numéro de référence
-i --input-encoding interpréter le fichier d'entrée en utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères sur www.kostis.net[4]) unicode est maintenant une option de jeu de caractères
-u --unicode-characters encoder les caractères unicode directement dans le fichier plutôt que sous forme d'entités XML
-un --unicode-no-bom comme -u, mais sans inclure de BOM (Byte Order Mark)
-x --xml-entities encoder les caractères unicode sous forme d'entités XML (opposé de -u)
-nl --no-latex ne pas convertir les combinaisons de caractères de style latex
-s --single-refperfile une référence par fichier de sortie
-d --drop-key ne pas mettre la clé de citation dans le champ id mods
-c --corporation-file avec un argument spécifiant un fichier contenant une liste de noms de sociétés à placer dans <name type="corporate"></name> au lieu de type="personal" et supprimer le renommage des noms
-a --asis avec un argument spécifiant un fichier contenant une liste de noms à traiter tels quels
-nt --nosplit-title ne pas diviser les titres en paires TITRE/SOUS-TITRE
--verbose sortie détaillée
--debug sortie très détaillée (principalement pour le débogage)

bib2xml

bib2xml convertit un fichier de références formaté en bibtex en un fichier bibliographique intermédiaire XML. Spécifiez les fichiers à convertir sur la ligne de commande. Les fichiers contenant des chaînes de substitution bibtex doivent être spécifiés avant les fichiers où les substitutions sont spécifiées (ou dans le même fichier avant leur utilisation). Si aucun fichier n'est spécifié, les informations bibtex seront lues depuis l'entrée standard.

bib2xml fichier_bibtex.bib > fichier_sortie.xml

biblatex2xml

biblatex2xml convertit un fichier de références formaté en biblatex (à ne pas confondre avec bibtex) en un fichier bibliographique intermédiaire XML MODS.

biblatex2xml fichier_biblatex.bib > fichier_sortie.xml

copac2xml

copac2xml convertit un fichier de références au format COPAC en un fichier bibliographique intermédiaire XML MODS.

end2xml

end2xml convertit un fichier de références au format texte EndNote en un fichier bibliographique intermédiaire XML. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté. Les formats étiquetés Endnote (exportation au format "Refer") ressemblent à l'Exemple 1, « Fichier au format Refer exemple ». Il existe de très bonnes instructions pour s'assurer que vous exportez correctement ceci à http://www.sonnysoftware.com/endnoteimport.html[5]

L'utilisation de end2xml est la même que celle de bib2xml.

end2xml fichier_endnote.end > fichier_sortie.xml

ebi2xml

ebi2xml convertit un fichier XML EBI en un fichier bibliographique intermédiaire XML MODS.

endx2xml

endx2xml convertit un fichier de références exporté au format EndNote-XML en un fichier bibliographique intermédiaire XML MODS. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté.

isi2xml

isi2xml convertit un fichier de références au format ISI-web-of-science en un fichier bibliographique intermédiaire XML.

L'utilisation de isi2xml est la même que celle de bib2xml.

isi2xml fichier_entree.isi > fichier_sortie.xml

ris2xml

ris2xml convertit un fichier de références au format RIS en un fichier bibliographique intermédiaire XML. L'utilisation de ris2xml est la même que pour end2xml et bib2xml.

ris2xml fichier_ris.ris >	fichier_sortie.xml

wordbib2xml

wordbib2xml convertit un fichier de références au format Word2007 en un fichier bibliographique intermédiaire XML.

Options communes pour la conversion depuis MODS

Several flags are available for the xml2end, xml2ris, xml2bib, xml2isi, xml2ads, and xml2wordbib programs. Most options have both a short and a long version.

-h --help display help
-v --version display version
-i --input-encoding The encoding of the input file (MODS). Defaults to UTF-8. Use --input-encoding list to get a list of supported encodings.
-u --unicode-characters Encode unicode characters directly in the output file rather than as XML entities.
-x --xml-entities Encode unicode characters as XML entities (opposite of -u).
-nl --no-latex Do not convert LaTeX-style character combinations (e.g. \\'e) to unicode characters.
-a --asis Do not process the text in the relevant fields, but pass it through asis. This is useful if the text has already been formatted and you don't want it to be mangled.
-e --entity-subst Replace XML entities with their corresponding characters.
-nt --nosplit-title Don't split titles into TITLE/SUBTITLE pairs.
--verbose Verbose output.
--debug Very verbose output (mostly for debugging).

xml2format programs may be given a list of files on the command line. If no files are specified, then the MODS XML information will be read from standard input.

xml2bib input_file.xml > output_file.bib

BIBUTILS UTILITIES

These utilities are wrappers for the java programs which do the heavy lifting. They provide a simpler interface for common operations.

modsclean

modsclean takes a MODS XML file as input and outputs a cleaned up MODS XML file. It performs operations such as removing empty elements, normalizing whitespace, and reordering elements according to the MODS specification.

modsclean input_file.xml > output_file.xml

PROGRAMMES CONVERTISSANT VERS BIBELOT

The bibutils package also includes programs to convert biblio data into the BibElot format. BibElot is a generalized bibliographical data format used by the BibElot citation manager.

bibtex2bbltx

Converts a bibtex file to BibElot format.

bibtex2bbltx input_file.bib > output_file.bbltx

ris2bbltx

Converts a RIS file to BibElot format.

ris2bbltx input_file.ris > output_file.bbltx

CONVERTIR DEPUIS BIBELOT

These programs convert BibElot formatted files to other bibliography formats.

bbltx2bibtex

Converts a BibElot file to bibtex format.

bbltx2bibtex input_file.bbltx > output_file.bib

bbltx2ris

Converts a BibElot file to RIS format.

bbltx2ris input_file.bbltx > output_file.ris

FICHIERS

Many of the programs accept a list of bibtex substitution files. These are files containing definitions of macros (e.g. \newcommand{\textit}[1]{\emph{#1}}). These files should be specified on the command line before the main bibtex file(s). The order of these files matters, as the programs read them in the order specified.

Note that bib2xml and biblatex2xml create MODS XML output.

PROBLÈMES CONNUS

Some conversions may not be perfect. In particular, complex BibTeX entries or entries with unusual fields may not be converted correctly. It is always recommended to check the output of the conversion process.

NAME

bibutils — tools for converting bibliographic data between formats

SYNOPSIS

bib2xml [-h|-v] [-o <encoding>] [-s] [-n] [-u] [-c] [-f] [-a] [-l] [-t] [-r] [-N] [-x] [-p<pattern>] [-P<pattern>] [-m] [bibtex file] [> xml file]

bibtex [-h|-v] [-o <encoding>] [-s] [-f] [-a] [-u] [-p<pattern>] [-P<pattern>] [-m] [xml file] [> bibtex file]

xml2bib [-h|-v] [-o <encoding>] [-s] [-f] [-a] [-u] [-p<pattern>] [-P<pattern>] [-m] [xml file] [> bibtex file]

xml2ads [-h|-v] [-o <encoding>] [-s] [-f] [-a] [-u] [-p<pattern>] [-P<pattern>] [-m] [xml file] [> ads file]

xml2ris [-h|-v] [-o <encoding>] [-s] [-f] [-a] [-u] [-p<pattern>] [-P<pattern>] [-m] [xml file] [> ris file]

xml2end [-h|-v] [-o <encoding>] [-s] [-f] [-a] [-u] [-p<pattern>] [-P<pattern>] [-m] [xml file] [> endnote file]

xml2wordbib [-h|-v] [-o <encoding>] [-s] [-f] [-a] [-u] [-p<pattern>] [-P<pattern>] [-m] [xml file] [> word xml file]

DESCRIPTION

The bibutils package is a suite of command-line tools that convert bibliographies between various formats. The default input format is MODS XML, although the bib2xml tool can convert from BibTeX format as well. The output formats supported are BibTeX, RIS, Endnote Tagged, and ADS Abstract Service tagged format.

The tools are designed to be as simple as possible to use. In most cases, you will simply pipe the input to the desired tool and redirect the output to the desired file.

xml2bib < input.xml > output.bib

The default input format for all tools, except bib2xml, is MODS XML. bib2xml converts BibTeX format files to MODS XML.

The following formats are supported:

MODS XML

This is the default input format for all tools except bib2xml. It is also the output format of bib2xml.

MODS is a descriptive schema for bibliographic records. It is an XML-based standard from the Library of Congress[1].

For more information on MODS, see http://www.loc.gov/standards/mods/[2].

BibTeX

bib2xml, xml2bib, and bibtex all support BibTeX format. BibTeX is a bibliography file format used by the BibTeX program, a bibliography tool for LaTeX.

There are a number of BibTeX styles, but the most common are plain, abbrv, and alpha. The bibtex tool supports all three, and also the unrelated style.

For more information on BibTeX, see http://www.bibtex.org.

RIS

RIS is a tag-based reference format developed by Research Information Systems.

For more information on RIS, see http://www.elsevier.com/solutions/elsevier-biomedical/reference-management/red-refman.

Endnote Tagged Format

Endnote is a proprietary reference management software. The tagged format is a plain text format used for importing and exporting references.

For more information on the Endnote tagged format, see http://www.sonnysoftware.com/endnoteimport.html[5].

ADS Abstract Service Format

This is a tagged format used by the Smithsonian Astrophysical Observatory (SAO) / National Aeronautics and Space Administration (NASA) Astrophysics Data System (ADS).

For more information, see http://doc.adsabs.harvard.edu/abs_doc/help_pages/taggedformat.html[6].

Word 2007 XML Bibliography

This is an XML format used by Microsoft Word 2007 for bibliographies.

Note that versions of bibutils prior to 3.40 used the name xml2word. This was renamed to xml2wordbib to avoid confusion with other tools.

COMMON OPTIONS

The following options are common to all bibutils tools:

-h --help Display help message and exit.
-v --version Display version information and exit.
-o --output-encoding <encoding> Specify the character encoding of the output file. If not specified, UTF-8 is used. Common encodings include UTF-8, ISO-8859-1, ASCII. If no argument is given, a list of available character sets derived from character sets at www.kostis.net[4] is displayed.
-s --single-refperfile Write each reference to a separate file. The filenames will be based on the reference key.
-nb --no-bom Do not write a Byte Order Mark (BOM) when writing UTF-8 encoded files.

BibTeX Input Options for bib2xml

bib2xml has several options specific to handling BibTeX input:

-c --complete Include all fields, even those not normally output by BibTeX.
-f --field-order Specify the order of fields in the output XML. See xmllint(1) for details.
-a --author-order Specify the order of authors in the output XML.
-l --language Specify the language of the bibliography.
-t --title-order Specify the order of titles in the output XML.
-r --remove-empty Remove empty fields from the output XML.
-N --no-numeric-field Do not output numeric fields.
-x --xml-declaration Include the XML declaration in the output.
-p --pattern=<pattern> Extract records matching the given BibTeX key pattern.
-P --record-pattern=<pattern> Extract records matching the given BibTeX entry type pattern (e.g., "@article").
-m --merge-fields Merge fields with the same name into a single field.

BibTeX Output Options for xml2bib and bibtex

xml2bib and bibtex have several options specific to BibTeX output:

-fc --finalcomma Add a final comma after each entry.
-sd --singledash Use a single hyphen (-) for page ranges instead of an en-dash (--) or em-dash (—).
-b --brackets Use curly braces {} around field data instead of quotation marks "".
-w --whitespace Add beautifying whitespace to the output.
-U --uppercase Output all tags (field names) and entry types in uppercase. This is the default behavior prior to version 3.24.
-sk --strictkey Only use alphanumeric characters for BibTeX citation keys. Invalid characters will be removed.
-a --author-order Attempt to order authors correctly in the output.
-f --field-order Specify the order of fields in the output.
-m --merge-fields Merge fields with the same name into a single field.

MODS Input Options for xml2xxx tools

The following options are common to all xml2xxx tools when processing MODS XML input:

-o --output-encoding <encoding> Interpret the input file as using the requested character set. Use without an argument to get a list derived from character sets at www.kostis.net[4]. Unicode is now a character set option.
-s --single-refperfile Put one reference per file name by the reference number.
-nb --no-bom Do not write Byte Order Mark if writing UTF8.
-p --pattern=<pattern> Extract records matching the given MODS ID pattern.
-P --record-pattern=<pattern> Extract records matching the given MODS record type pattern (e.g., "Personal Name").
-m --merge-fields Merge fields with the same name into a single field.

Common Options Converting from MODS

Note that --output-encoding refers to the input file

-h --help display help
-v --version display version
-o --output-encoding interpret the input file as using the requested character set (use w/o argument for current list derived from character sets at www.kostis.net[4]) unicode is now a character set option
-s --single-refperfile put one reference per file name by the reference number
-nb --no-bom do not write Byte Order Mark if writing UTF8

xml2bib

xml2bib converts the MODS XML bibliography into a bibtex-formatted reference file. xml2bib usage is as for other tools

xml2bib xml_file.xml > output_file.bib

Since the BibTeX reference format is fairly flexible and seems to have the greatest number of personal preferences, it has also accumulated a number of specific options that are not available for other formats.

Starting with 3.24, xml2bib output uses lowercase tags and mixed case reference types for better interaction with other software. The older behavior with all uppercase tags/reference types can still be generated using the command-line switch -U/--uppercase.

xml2bib-specific Options:

-fc --finalcomma add final comma in the bibtex output for those that want it
-sd --singledash use one dash instead of two (longer dash in latex) between numbers in page output
-b --brackets use brackets instead of quotation marks around field data
-w --whitespace add beautifying whitespace to output
-U --uppercase use all uppercase for tags (field names) and reference types (pre-3.24 behavior)
-sk --strictkey only use alphanumeric characters for bibtex citation keys

xml2ads

xml2ads converts the MODS XML bibliography to the Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) Astrophyics Data System or ADS reference format[6] (which is very similar to the tagged Endnote style). xml2ads usage is as for other tools

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris converts the MODS XML bibliography to RIS-formatted bibliography file. xml2ris usage is as for other tools

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end converts the MODS XML bibliography to tagged Endnote (refer-format) bibliography file. xml2end usage is as for other tools

xml2end xml_file.xml >  output_file.end

xml2wordbib

xml2wordbib converts the MODS XML bibliography to Word 2007-formatted XML bibliography file. xml2wordbib usage is as for other tools

xml2wordbib xml_file.xml >  output_file.word.xml

xml2wordbib was called xml2word in versions of bibutils prior to 3.40. It was renamed to avoid confusion with other tools. Hopefully this will not break too many scripts already in use.
