XMLSEC1-CONFIG(1) Commandes utilisateur XMLSEC1-CONFIG(1)

NOM

xmlsec1-config - détaille la version installée de la bibliothèque xmlsec

SYNTAXE

xmlsec1-config [OPTION]...

DESCRIPTION

Valeurs connues pour OPTION :

--cflags
affiche les indicateurs du préprocesseur et du compilateur
--libs
affiche les informations de liaison de la bibliothèque
--prefix
affiche le dossier de préfixe XMLSEC par défaut
--exec-prefix
affiche le dossier de préfixe des exécutables XMLSEC par défaut
--libdir
affiche le dossier des bibliothèques XMLSEC par défaut
--crypto
affiche le nom de la bibliothèque cryptographique par défaut
--prefix=DIR
modifie le dossier de préfixe XMLSEC
--exec-prefix=DIR
modifie le dossier de préfixe des exécutables XMLSEC
--libdir=DIR
modifie le dossier des bibliothèques XMLSEC
--crypto=LIB
configure avec la bibliothèque cryptographique XMLSEC (l'une des suivantes : none default openssl nss gnutls gcrypt)
--help
affiche cette aide et quitte
--version
affiche les informations de version
