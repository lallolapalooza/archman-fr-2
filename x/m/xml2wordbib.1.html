bibutils - utilitaires de conversion bibliographique

SYNTAXE

format2xml [OPTIONS] [fichier.format]

xml2format [OPTIONS] [fichier.xml]

DESCRIPTION

L'ensemble de programmes bibutils interconvertit entre divers formats bibliographiques en utilisant le Metadata Object Description Schema (MODS)[2] version 3.1 de la Library of Congress[1]. Par exemple, on peut convertir des fichiers au format RIS en Bibtex en effectuant deux transformations : RIS>MODS>Bibtex.

Options communes pour la conversion vers MODS

Plusieurs indicateurs sont disponibles pour les programmes end2xml, endx2xml, bib2xml, ris2xml, med2xml, et copac2xml. La plupart des options ont une version courte et une version longue.

-h --help afficher l'aide
-v --version afficher la version
-a --add-refcount ajouter "_#" où # est le nombre de références à l'identifiant de la référence
-s --single-refperfile mettre une référence par fichier nommé d'après le numéro de référence
-i --input-encoding interpréter le fichier d'entrée en utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères de www.kostis.net[4]) unicode est maintenant une option de jeu de caractères
-u --unicode-characters encoder les caractères unicode directement dans le fichier plutôt qu'en entités XML
-un --unicode-no-bom comme -u, mais n'inclure pas de marque d'ordre des octets (BOM)
-x --xml-entities encoder les caractères unicode en entités XML (l'opposé de -u)
-nl --no-latex ne pas convertir les combinaisons de caractères de style latex
-s --single-refperfile une référence par fichier de sortie
-d --drop-key ne pas placer la clé de citation dans le champ d'identifiant MODS
-c --corporation-file avec un argument spécifiant un fichier contenant une liste de noms de corporations à placer dans <name type="corporate"></name> au lieu de type="personal" et éliminer le“manglage” des noms
-a --asis avec un argument spécifiant un fichier contenant une liste de noms à traiter tels quels
-nt --nosplit-title ne pas diviser les titres en paires TITRE/SOUS-TITRE
--verbose sortie verbeuse
--debug sortie très verbeuse (principalement pour le débogage)

bib2xml

bib2xml convertit un fichier de références au format bibtex en un fichier bibliographique intermédiaire au format XML. Spécifiez les fichiers à convertir sur la ligne de commande. Les fichiers contenant des chaînes de substitution bibtex doivent être spécifiés avant les fichiers où les substitutions sont spécifiées (ou dans le même fichier avant leur utilisation). Si aucun fichier n'est spécifié, les informations bibtex seront lues depuis l'entrée standard.

bib2xml fichier_bibtex.bib > fichier_sortie.xml

biblatex2xml

biblatex2xml convertit un fichier de références au format biblatex (à ne pas confondre avec bibtex) en un fichier bibliographique intermédiaire au format MODS XML.

biblatex2xml fichier_biblatex.bib > fichier_sortie.xml

copac2xml

copac2xml convertit un fichier de références au format COPAC en un fichier bibliographique intermédiaire au format MODS XML.

end2xml

end2xml convertit un fichier de références au format texte endnote en un fichier bibliographique intermédiaire au format XML. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté. Les formats étiquetés Endnote (export au format "Refer") ressemblent à l'Exemple 1, « Fichier au format refer d'exemple ». Il y a d'excellentes instructions pour s'assurer que vous exportez correctement à http://www.sonnysoftware.com/endnoteimport.html[5]

L'utilisation de end2xml est la même que celle de bib2xml.

end2xml fichier_endnote.end > fichier_sortie.xml

ebi2xml

ebi2xml convertit un fichier EBI XML en un fichier bibliographique intermédiaire au format MODS XML.

endx2xml

endx2xml convertit un fichier de références exporté au format EndNote-XML en un fichier bibliographique intermédiaire au format MODS XML. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté.

isi2xml

isi2xml convertit un fichier de références au format ISI-web-of-science en un fichier bibliographique intermédiaire au format XML.

L'utilisation de isi2xml est la même que celle de bib2xml.

isi2xml fichier_entree.isi > fichier_sortie.xml

ris2xml

ris2xml convertit un fichier de références au format RIS en un fichier bibliographique intermédiaire au format XML. L'utilisation de ris2xml est similaire à celle de end2xml et bib2xml

ris2xml fichier_ris.ris >	fichier_sortie.xml

wordbib2xml

wordbib2xml convertit un fichier de références au format Word2007 en un fichier bibliographique intermédiaire au format XML.

Options communes pour la conversion depuis MODS

Ces utilitaires implémentent beaucoup d'options communes.

-h, --help display help
-v, --version display version
-o, --output-encoding Specify output encoding for the resulting file (e.g. utf-8, iso-8859-1) default is utf-8.
-utf8-ncr Output unicode characters as utf8 numeric character references.
-l, --language Specify language to help disambiguate translations. Default is english. Can be useful for languages where translations of terms are not standard.
-s, --style Specify style to help disambiguate translations. Default is empty. Can be useful for languages where translations of terms are not standard.
--verbose verbose output
--debug very verbose output (mostly for debugging)

Pour la plupart des convertisseurs, vous pouvez spécifier un fichier d'entrée, et la sortie sera envoyée sur la sortie standard. Vous pouvez également spécifier plusieurs fichiers d'entrée qui seront tous concaténés.

xml2bib *.xml > output.bib

modsclean nettoie et valide les fichiers MODS, en essayant de corriger les erreurs courantes. Il peut également convertir certains des éléments MODS pour une meilleure interopérabilité.

xml2ads

Convertit un fichier MODS au format de métadonnées utilisé par le SAO/NASA ADS (Astrophysics Data System).

xml2bib

Convertit un fichier MODS au format bibtex.

xml2end

Convertit un fichier MODS au format texte utilisé par EndNote.

xml2isi

Convertit un fichier MODS au format utilisé par ISI Web of Science.

xml2ris

Convertit un fichier MODS au format RIS.

xml2wordbib

Convertit un fichier MODS au format bibliographie utilisé par Word 2007.

MODS VERS MODS

modsclean

Le programme modsclean permet de nettoyer et de valider les fichiers MODS. Il tente également de corriger les erreurs courantes dans les fichiers MODS et de convertir certains éléments MODS pour une meilleure interopérabilité.

Il peut être utilisé pour standardiser les fichiers MODS avant de les convertir dans d'autres formats ou pour vérifier la conformité avec le schéma MODS.

modsclean input.xml > cleaned_output.xml

Des options supplémentaires peuvent être disponibles pour contrôler le processus de nettoyage et de conversion. Utilisez l'option --help pour les voir.

xml2bib

xml2bib convertit la bibliographie XML MODS en un fichier de références au format bibtex. L'utilisation de xml2bib est comme pour les autres outils

xml2bib xml_file.xml > output_file.bib

Comme le format de référence BibTeX est assez flexible et semble avoir le plus grand nombre de préférences personnelles, il a également accumulé un certain nombre d'options spécifiques qui ne sont pas disponibles pour d'autres formats.

À partir de la version 3.24, la sortie de xml2bib utilise des balises en minuscules et des types de références en casse mixte pour une meilleure interaction avec d'autres logiciels. Le comportement précédent avec toutes les balises/types de références en majuscules peut toujours être généré en utilisant le commutateur de ligne de commande -U/--uppercase.

Options spécifiques à xml2bib :

-fc --finalcomma ajouter une virgule finale dans la sortie bibtex pour ceux qui la souhaitent
-sd --singledash utiliser un tiret au lieu de deux (tiret plus long en latex) entre les nombres dans la sortie des pages
-b --brackets utiliser des crochets au lieu de guillemets autour des données de champ
-w --whitespace ajouter des espaces blancs pour l'embellissement de la sortie
-U --uppercase utiliser des majuscules pour les balises (noms de champs) et les types de références (comportement avant la version 3.24)
-sk --strictkey utiliser uniquement des caractères alphanumériques pour les clés de citation bibtex

xml2ads

xml2ads convertit la bibliographie XML MODS au format de référence du Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) Astrophyics Data System ou ADS[6] (qui est très similaire au style Endnote étiqueté). L'utilisation de xml2ads est comme pour les autres outils

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convertit la bibliographie XML MODS en un fichier bibliographique au format RIS. L'utilisation de xml2ris est comme pour les autres outils

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convertit la bibliographie XML MODS en un fichier bibliographique Endnote étiqueté (format refer). L'utilisation de xml2end est comme pour les autres outils

xml2end xml_file.xml > output_file.end

xml2wordbib

xml2wordbib convertit la bibliographie XML MODS en un fichier bibliographique XML au format Word 2007. L'utilisation de xml2wordbib est comme pour les autres outils

xml2wordbib xml_file.xml > output_file.word.xml

xml2wordbib s'appelait xml2word dans les versions de bibutils antérieures à 3.40. Il a été renommé pour éviter toute confusion avec d'autres outils. Espérons que cela ne cassera pas trop de scripts déjà en usage.
