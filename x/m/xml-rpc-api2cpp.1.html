XML-RPC-API2CPP(1) Manuel des commandes générales XML-RPC-API2CPP(1)

NOM

xml-rpc-api2cpp - Créer une classe wrapper C++ pour une API XML-RPC

SYNTAXE

xml-rpc-api2cpp url-serveur prefixe-methode-distante nom-classe-c++

DESCRIPTION

xml-rpc-api2cpp interroge un serveur XML-RPC en utilisant l'API d'introspection XML-RPC conçue par Edd Dumbill. Il imprime ensuite une classe wrapper C++ sur la sortie standard. Cette classe peut être utilisée avec l'API C++ de xmlrpc-c.

Vous pouvez trouver une liste des bibliothèques de serveurs XML-RPC prises en charge (et des correctifs pour de nombreuses autres) sur http://xmlrpc-c.sourceforge.net/hacks.php.

OPTIONS

url-serveur
Le nom du serveur à interroger. Essayez http://xmlrpc-c.sourceforge.net/cgi-bin/interop.cgi.
prefixe-methode-distante
Le préfixe des méthodes à encapsuler. Par exemple, pour encapsuler tous les appels system.*, vous pouvez spécifier « system ».
nom-classe-c++
Le nom de la classe C++ à générer. Essayez « SystemProxy ».

BOGUES

xml-rpc-api2cpp ne peut pas communiquer avec certains serveurs PHP basés sur la bibliothèque PHP d'Edd Dumbill, car les octets finaux du message XML-RPC sont tronqués en mode pipelining HTTP. Il n'est pas clair s'il s'agit d'un bug PHP, Apache ou w3c-libwww.

xml-rpc-api2cpp suppose que les descriptions de méthodes sont du texte ASCII, et non du HTML comme spécifié dans la norme. (En pratique, les deux conventions sont souvent observées.) Il peut également avoir des problèmes si les descriptions de méthodes contiennent « */ ».

En général, les messages d'erreur et les diagnostics sont encore assez médiocres.

VOIR AUSSI

xmlrpc-c(7), xml-rpc-api2txt(1).

Ce programme fait partie de xmlrpc-c.
