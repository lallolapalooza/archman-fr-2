NOM

xmlparse - vérifie les erreurs et valide les documents XML

SYNTAXE

xmlparse
nom_de_fichier

DESCRIPTION

Analyse le fichier donné, le validant par rapport à sa DTD si trouvée. Affiche des messages sur les erreurs, sinon retourne silencieusement. (La valeur 0 est toujours retournée dans tous les cas.) L'analyse du fichier est rejetée.

HISTORIQUE

Écrit en 2003.

Cette page de manuel est apparue pour la première fois dans gnustep-base 1.9.2 (mars 2004).
