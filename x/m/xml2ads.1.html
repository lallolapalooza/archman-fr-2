bibutils - utilitaires de conversion de bibliographies

SYNTAXE

format2xml [OPTIONS] [fichier.format]

xml2format [OPTIONS] [fichier.xml]

DESCRIPTION

Le programme bibutils permet la conversion entre divers formats de bibliographies en utilisant le schéma MODS (Metadata Object Description Schema)[2] version 3.1 de la Library of Congress[1]. Par exemple, on peut convertir des fichiers au format RIS en Bibtex en effectuant deux transformations : RIS>MODS>Bibtex.

CONVERTIR VERS MODS

Options communes pour la conversion vers MODS

Plusieurs drapeaux sont disponibles pour les programmes end2xml, endx2xml, bib2xml, ris2xml, med2xml, et copac2xml. La plupart des options ont une version courte et une version longue.

-h --help afficher l'aide
-v --version afficher la version
-a --add-refcount ajouter "_#", où # est le nombre de références, à l'identifiant de la référence
-s --single-refperfile mettre une référence par nom de fichier, basé sur le numéro de référence
-i --input-encoding interpréter le fichier d'entrée comme utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères sur www.kostis.net[4]) unicode est maintenant une option de jeu de caractères
-u --unicode-characters encoder les caractères unicode directement dans le fichier plutôt que sous forme d'entités XML
-un --unicode-no-bom comme -u, mais n'inclure pas de BOM (Byte Order Mark)
-x --xml-entities encoder les caractères unicode comme des entités XML (opposé de -u)
-nl --no-latex ne pas convertir les combinaisons de caractères de style latex
-s --single-refperfile une référence par fichier de sortie
-d --drop-key ne pas placer la clé de citation dans le champ id de mods
-c --corporation-file avec un argument spécifiant un fichier contenant une liste de noms de sociétés à placer dans <name type="corporate"></name> au lieu de type="personal" et éliminer le déchiffrage des noms
-a --asis avec un argument spécifiant un fichier contenant une liste de noms à traiter tels quels
-nt --nosplit-title ne pas diviser les titres en paires TITRE/SOUS-TITRE
--verbose sortie verbeuse
--debug sortie très verbeuse (principalement pour le débogage)

bib2xml

bib2xml convertit un fichier de références au format bibtex en un fichier bibliographique intermédiaire XML. Spécifiez les fichiers à convertir sur la ligne de commande. Les fichiers contenant les chaînes de substitution bibtex doivent être spécifiés avant les fichiers où les substitutions sont spécifiées (ou dans le même fichier avant leur utilisation). Si aucun fichier n'est spécifié, les informations bibtex seront lues depuis l'entrée standard.

bib2xml fichier_bibtex.bib > fichier_sortie.xml

biblatex2xml

biblatex2xml convertit un fichier de références au format biblatex (à ne pas confondre avec bibtex) en un fichier bibliographique intermédiaire MODS XML.

biblatex2xml fichier_biblatex.bib > fichier_sortie.xml

copac2xml

copac2xml convertit un fichier de références au format COPAC en un fichier bibliographique intermédiaire MODS XML.

end2xml

end2xml convertit un fichier de références au format texte EndNote en un fichier bibliographique intermédiaire XML. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté. Les formats étiquetés EndNote (export au format "Refer") ressemblent à l'Exemple 1, « Exemple de fichier au format refer ». Il existe de très bonnes instructions pour s'assurer que vous exportez correctement à l'adresse http://www.sonnysoftware.com/endnoteimport.html[5]

L'utilisation de end2xml est la même que celle de bib2xml.

end2xml fichier_endnote.end > fichier_sortie.xml

ebi2xml

ebi2xml convertit un fichier XML EBI en un fichier bibliographique intermédiaire MODS XML.

endx2xml

endx2xml convertit un fichier de références exporté EndNote-XML en un fichier bibliographique intermédiaire MODS XML. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté.

isi2xml

isi2xml convertit un fichier de références au format ISI-web-of-science en un fichier bibliographique intermédiaire XML.

L'utilisation de isi2xml est la même que celle de bib2xml.

isi2xml fichier_entree.isi > fichier_sortie.xml

ris2xml

ris2xml convertit un fichier de références au format RIS en un fichier bibliographique intermédiaire XML. L'utilisation de ris2xml est comme celle de end2xml et bib2xml

ris2xml fichier_ris.ris >	fichier_sortie.xml

wordbib2xml

wordbib2xml convertit un fichier de références au format Word2007 en un fichier bibliographique intermédiaire XML.

xml2bib

xml2bib convertit la bibliographie XML MODS en un fichier de références au format bibtex. L'utilisation de xml2bib est comme pour les autres outils.

xml2bib xml_file.xml > output_file.bib

Étant donné que le format de référence BibTeX est assez flexible et semble avoir le plus grand nombre de préférences personnelles, il a également accumulé un certain nombre d'options spécifiques qui ne sont pas disponibles pour d'autres formats.

À partir de la version 3.24, la sortie de xml2bib utilise des balises en minuscules et des types de référence en casse mixte pour une meilleure interaction avec d'autres logiciels. Le comportement précédent avec des balises/types de référence entièrement en majuscules peut toujours être généré en utilisant le commutateur de ligne de commande -U/--uppercase.

Options spécifiques à xml2bib :

-fc --finalcomma ajouter une virgule finale dans la sortie bibtex pour ceux qui le souhaitent
-sd --singledash utiliser un trait d'union au lieu de deux (trait d'union plus long en latex) entre les nombres dans la sortie de page
-b --brackets utiliser des crochets au lieu de guillemets autour des données de champ
-w --whitespace ajouter des espaces blancs pour l'esthétique à la sortie
-U --uppercase utiliser toutes les majuscules pour les balises (noms de champs) et les types de référence (comportement avant la version 3.24)
-sk --strictkey utiliser uniquement des caractères alphanumériques pour les clés de citation bibtex

xml2ads

xml2ads convertit la bibliographie XML MODS au format de référence du Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) Astrophyics Data System ou ADS[6] (qui est très similaire au style Endnote balisé). L'utilisation de xml2ads est comme pour les autres outils.

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convertit la bibliographie XML MODS en un fichier bibliographique au format RIS. L'utilisation de xml2ris est comme pour les autres outils.

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convertit la bibliographie XML MODS en un fichier bibliographique Endnote balisé (format refer). L'utilisation de xml2end est comme pour les autres outils.

xml2end xml_file.xml > output_file.end

xml2wordbib

xml2wordbib convertit la bibliographie XML MODS en un fichier bibliographique XML au format Word 2007. L'utilisation de xml2wordbib est comme pour les autres outils.

xml2wordbib xml_file.xml > output_file.word.xml

xml2wordbib s'appelait xml2word dans les versions de bibutils antérieures à la 3.40. Il a été renommé pour éviter la confusion avec d'autres outils. Espérons que cela ne cassera pas trop de scripts déjà en cours d'utilisation.

NAME

xml2ads - convert XML to AD&D 2nd Edition character sheets

SYNOPSIS

xml2ads xmlfile

DESCRIPTION

xml2ads converts a character sheet from XML format to the older AD&D 2nd Edition format. The AD&D 2nd Edition format is a plain text file with a specific structure that can be read by older programs or imported into other systems.

CONVERTING TO MODS

If you have a character sheet in the AD&D 2nd Edition format, you can convert it to XML using the ads2xml command.

CONVERTING FROM MODS

To convert from XML to the AD&D 2nd Edition format, use the xml2ads command.

EXAMPLES

To convert a character sheet named my_character.xml to the AD&D 2nd Edition format:

xml2ads my_character.xml

This will create a file named my_character.ads in the same directory.

NOM

xml2ads - convertir XML en feuilles de personnage AD&D 2ème édition

SYNTAXE

xml2ads fichierxml

DESCRIPTION

xml2ads convertit une feuille de personnage du format XML vers le format plus ancien de l'AD&D 2ème édition. Le format de l'AD&D 2ème édition est un fichier texte brut avec une structure spécifique qui peut être lu par des programmes plus anciens ou importé dans d'autres systèmes.

CONVERSION VERS MODS

Si vous avez une feuille de personnage au format AD&D 2ème édition, vous pouvez la convertir en XML en utilisant la commande ads2xml.

CONVERSION DEPUIS MODS

Pour convertir du XML vers le format AD&D 2ème édition, utilisez la commande xml2ads.

EXEMPLES

Pour convertir une feuille de personnage nommée mon_personnage.xml au format AD&D 2ème édition :

xml2ads mon_personnage.xml

Cela créera un fichier nommé mon_personnage.ads dans le même répertoire.
