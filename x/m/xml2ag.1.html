xml2ag(1) Commandes utilisateur xml2ag(1)

NOM

xml2ag - Convertisseur XML vers définitions AutoGen

SYNOPSIS

xml2ag [-indicateurs] [-indicateur [valeur]] [--nom-option[[=| ]valeur]] [ <fichier-def> ]

Ce programme convertira n'importe quel fichier XML arbitraire en définitions AutoGen équivalentes, et invoquera AutoGen.

DESCRIPTION

Le modèle sera dérivé de :
* l'option de ligne de commande --override-tpl
* un attribut XML de niveau supérieur nommé "template"
L'un ou l'autre doit être fourni, sinon le programme se terminera avec un message d'échec.

Le “nom de base” pour la sortie sera de même soit :
* l'option de ligne de commande --base-name
* le nom de base du fichier .xml

OPTIONS

Toutes les autres options sont dérivées d'autogen

-O fichier, --output=fichier

Fichier de sortie à la place du traitement AutoGen.

Par défaut, la sortie est transmise à AutoGen pour traitement. Cependant, vous pouvez enregistrer les définitions dans un fichier à la place.

Toutes les autres options

Ces options sont principalement juste passées à autogen. La seule exception est --override-tpl qui remplace le modèle par défaut dans les définitions de sortie. Elle n'est pas transmise en ligne de commande.

-L rép, --templ-dirs=rép

Rechercher les modèles dans RÉP. Cette option peut apparaître un nombre illimité de fois.

Argument AutoGen transmis

-T fichier-tpl, --override-tpl=fichier-tpl

Utiliser FICHIER-TPL pour le modèle.

Argument AutoGen transmis

--definitions=fichier

Lire les définitions à partir de FICHIER.

Argument AutoGen transmis

--shell=shell

Nom ou chemin d'accès du shell à utiliser.

Argument AutoGen transmis

-m, --no-fmemopen

Ne pas utiliser les flux en mémoire.

Argument AutoGen transmis

--equate=liste-car

caractères considérés comme équivalents.

Argument AutoGen transmis

-b nom, --base-name=nom

Spécifier NOM comme nom de base pour la sortie.

Argument AutoGen transmis

--source-time

définir les heures de modification à la dernière source.

Argument AutoGen transmis

--writable, --not-writable

Autoriser les fichiers de sortie à être modifiables. La forme not-writable désactivera l'option.

Argument AutoGen transmis

--loop-limit=lim

Limite sur les boucles d'incrémentation. Cette option prend un nombre entier comme argument. La valeur de lim est contrainte à être : 
exactement -1, ou
dans la plage  1 à 0x1000000

La valeur par défaut de lim pour cette option est :
256

Argument AutoGen transmis

-t secondes, --timeout=secondes

Limiter les opérations du shell serveur à SECONDES. Cette option prend un nombre entier comme argument. La valeur de secondes est contrainte à être : 
dans la plage  0 à 3600

Argument AutoGen transmis

--trace=niveau

niveau de détail du traçage. Cette option prend un mot-clé comme argument. L'argument définit une valeur d'énumération qui peut être testée en la comparant à la macro de valeur de l'option. Les mots-clés disponibles sont : 
nothing       debug-message server-shell
templates     block-macros  expressions
everything
ou leur équivalent numérique.

Le niveau par défaut pour cette option est :
nothing

Argument AutoGen transmis

--trace-out=fichier

fichier ou filtre de sortie de traçage.

Argument AutoGen transmis

--show-defs

Afficher l'arbre des définitions.

Argument AutoGen transmis

--used-defines

Afficher les définitions utilisées.

Argument AutoGen transmis

-C, --core

Laisser un core dump en cas de sortie d'échec.

De nombreux systèmes limitent par défaut la taille des core dumps à zéro. Si le système possède l'en-tête sys/resource.h et si cette option est fournie, alors lors du chemin de sortie d'échec, autogen tentera de définir la limite souple de core à la limite dure. Si cela ne fonctionne pas, un administrateur devra augmenter la limite dure de taille de core.

-s suffixe, --skip-suffix=suffixe

Ignorer le fichier avec ce SUFFIXE. Cette option peut apparaître un nombre illimité de fois. Cette option ne doit pas apparaître en combinaison avec l'une des options suivantes : select-suffix.

Argument AutoGen transmis

-o suffixe, --select-suffix=suffixe

spécifier ce suffixe de sortie. Cette option peut apparaître un nombre illimité de fois.

Argument AutoGen transmis

-D valeur, --define=valeur

nom à ajouter à la liste de définitions. Cette option peut apparaître un nombre illimité de fois.

Argument AutoGen transmis

-U motif-nom, --undefine=motif-nom

motif de suppression de la liste de définitions. Cette option peut apparaître un nombre illimité de fois.

Argument AutoGen transmis

-M type, --make-dep [type]

émettre un fichier de dépendances make. Cette option peut apparaître un nombre illimité de fois.

Argument AutoGen transmis

-?, --help

Afficher les informations d'utilisation et quitter.
-!, --more-help

Transmettre les informations d'utilisation étendues à un paginator.
-v [{v|c|n --version [{v|c|n}]}]

Afficher la version du programme et quitter. Le mode par défaut est `v', une simple version. Le mode `c' affichera les informations de copyright et `n' affichera l'avis de copyright complet.

STATUT DE SORTIE

L'une des valeurs de sortie suivantes sera retournée :

0 (EXIT_SUCCESS)

Exécution réussie du programme.
1 (EXIT_FAILURE)

L'opération a échoué ou la syntaxe de la commande n'était pas valide.
70 (EX_SOFTWARE)

libopts a eu une erreur opérationnelle interne. Veuillez la signaler à autogen-users@lists.sourceforge.net. Merci.
