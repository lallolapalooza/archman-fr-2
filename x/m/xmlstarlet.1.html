NOM

xmlstarlet - toolkit en ligne de commande pour XML/XSLT

SYNOPIS

xml [options...] {commande} [options-cmd...]

INTRODUCTION

XMLStarlet est un ensemble d'utilitaires en ligne de commande (outils) qui peuvent être utilisés pour transformer, interroger, valider et éditer des documents et fichiers XML en utilisant un ensemble simple de commandes shell, de manière similaire à ce qui est fait pour les fichiers texte avec les commandes UNIX grep, sed, awk, diff, patch, join, etc. Cet ensemble d'utilitaires en ligne de commande peut être utilisé par ceux qui traitent de nombreux documents XML sur l'invite de commande shell UNIX, ainsi que pour le traitement XML automatisé avec des scripts shell.

OPTIONS

--version

Affiche la version de xmlstarlet.

--help

Affiche l'aide.

COMMANDES

xml commande --help pour obtenir de l'aide spécifique à la commande

Les commandes disponibles incluent :

ed (ou edit)

Édite/met à jour des documents XML.

sel (ou select)

Sélectionne des données ou interroge des documents XML (XPATH, etc.).

tr (ou transform)

Transforme des documents XML en utilisant XSLT.

val (ou validate)

Valide des documents XML (bien formé/DTD/XSD/RelaxNG).

fo (ou format)

Met en forme des documents XML.

el (ou elements)

Affiche la structure des éléments d'un document XML.

c14n (ou canonic)

Canonicalisation XML.

ls (ou list)

Liste un répertoire au format XML.

esc (ou escape)

Échappe les caractères XML spéciaux.

unesc (ou unescape)

Déséchappe les caractères XML spéciaux.

pyx (ou xmln)

Convertit le XML au format PYX (basé sur ESIS - ISO 8879).

p2x (ou depyx)

Convertit PYX en XML.

RÉFÉRENCES

XMLStarlet est un toolkit en ligne de commande pour interroger/éditer/vérifier/transformer des documents XML (pour plus d'informations, voir http://xmlstar.sourceforge.net/).
