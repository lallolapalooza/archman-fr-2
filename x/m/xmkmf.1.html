NOM

xmkmf - créer un Makefile à partir d'un Imakefile

SYNOPSIS

xmkmf [ -a ] [ topdir [ curdir ] ]

DESCRIPTION

La commande xmkmf est la manière normale de créer un Makefile à partir d'un Imakefile livré avec des logiciels tiers.

Lorsqu'elle est invoquée sans arguments dans un répertoire contenant un Imakefile, le programme imake est exécuté avec des arguments appropriés pour votre système (configurés dans imake lors de sa compilation) et génère un Makefile.

Lorsqu'elle est invoquée avec l'option -a, xmkmf construit le Makefile dans le répertoire courant, puis exécute automatiquement ``make Makefiles'' (au cas où il y aurait des sous-répertoires), ``make includes'', et ``make depend'' pour vous.

Si un topdir est donné, xmkmf suppose que rien n'est installé sur votre système et recherche les fichiers dans l'arborescence de construction au lieu d'utiliser les versions installées. Optionnellement, curdir peut être spécifié comme un chemin relatif depuis le sommet de l'arborescence de construction jusqu'au répertoire courant. Il est nécessaire de fournir curdir si le répertoire courant a des sous-répertoires, sinon le Makefile ne pourra pas construire les sous-répertoires.
