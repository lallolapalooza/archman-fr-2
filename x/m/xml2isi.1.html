bibutils - utilitaires de conversion de bibliographies

SYNTAXE

format2xml [OPTIONS] [fichier.format]

xml2format [OPTIONS] [fichier.xml]

DESCRIPTION

L'ensemble de programmes bibutils permet la conversion entre divers formats de bibliographie en utilisant le Metadata Object Description Schema (MODS)[2]version 3.1 de la Library of Congress[1]. Par exemple, on peut convertir des fichiers au format RIS en Bibtex en effectuant deux transformations : RIS>MODS>Bibtex.

CONVERSION VERS MODS

Aperçu

Commande Description

biblatex2xml convertir biblatex en MODS

endx2xml convertir EndNote XML en MODS
isi2xml convertir ISI web of science en MODS
med2xml convertir des références PubMed XML en MODS
nbib2xml convertir des références au format Pubmed nbib en MODS

Options communes pour la conversion vers MODS

Plusieurs indicateurs sont disponibles pour les programmes end2xml, endx2xml, bib2xml, ris2xml, med2xml et copac2xml. La plupart des options ont une version courte et une version longue.

-h --help afficher l'aide
-v --version afficher la version
-a --add-refcount ajouter "_#" où # est le nombre de références à l'identifiant de référence
-s --single-refperfile mettre une référence par fichier nommé d'après le numéro de référence
-i --input-encoding interpréter le fichier d'entrée comme utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères sur www.kostis.net[4]) unicode est maintenant une option de jeu de caractères
-u --unicode-characters encoder directement les caractères unicode dans le fichier plutôt qu'en tant qu'entités XML
-un --unicode-no-bom comme -u, mais n'inclut pas de marque d'ordre des octets (BOM)
-x --xml-entities encoder les caractères unicode en tant qu'entités XML (l'opposé de -u)
-nl --no-latex ne pas convertir les combinaisons de caractères de style latex
-s --single-refperfile une référence par fichier de sortie
-d --drop-key ne pas placer la clé de citation dans le champ d'identifiant MODS
-c --corporation-file avec un argument spécifiant un fichier contenant une liste de noms de sociétés à placer dans <name type="corporate"></name> au lieu de type="personal" et éliminer le détournement de nom
-a --asis avec un argument spécifiant un fichier contenant une liste de noms à traiter tels quels
-nt --nosplit-title ne pas diviser les titres en paires TITRE/SOUS-TITRE
--verbose sortie verbeuse
--debug sortie très verbeuse (principalement pour le débogage)

bib2xml

bib2xml convertit un fichier de références au format bibtex en un fichier de bibliographie intermédiaire XML. Spécifiez les fichiers à convertir sur la ligne de commande. Les fichiers contenant des chaînes de substitution bibtex doivent être spécifiés avant les fichiers où les substitutions sont spécifiées (ou dans le même fichier avant leur utilisation). Si aucun fichier n'est spécifié, les informations bibtex seront lues depuis l'entrée standard.

bib2xml bibtex_file.bib > output_file.xml

biblatex2xml

biblatex2xml convertit un fichier de références au format biblatex (à ne pas confondre avec bibtex) en un fichier de bibliographie intermédiaire MODS XML.

biblatex2xml biblatex_file.bib > outputfile.xml

copac2xml

copac2xml convertit un fichier de références au format COPAC en un fichier de bibliographie intermédiaire MODS XML.

end2xml

end2xml convertit un fichier de références au format EndNote (texte) en un fichier de bibliographie intermédiaire XML. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté. Les formats étiquetés EndNote (export au format "Refer") ressemblent à l'Exemple 1, « Exemple de fichier au format refer ». Il existe de très bonnes instructions pour s'assurer que vous exportez correctement à l'adresse http://www.sonnysoftware.com/endnoteimport.html[5]

L'utilisation de end2xml est la même que celle de bib2xml.

end2xml endnote_file.end > output_file.xml

ebi2xml

ebi2xml convertit un fichier XML EBI en un fichier de bibliographie intermédiaire MODS XML.

endx2xml

endx2xml convertit un fichier de références exporté au format EndNote-XML en un fichier de bibliographie intermédiaire MODS XML. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté.

isi2xml

isi2xml convertit un fichier de références au format ISI-web-of-science en un fichier de bibliographie intermédiaire XML.

L'utilisation de isi2xml est la même que celle de bib2xml.

isi2xml input_file.isi > output_file.xml

ris2xml

ris2xml convertit un fichier de références au format RIS en un fichier de bibliographie intermédiaire XML. L'utilisation de ris2xml est la même que celle de end2xml et bib2xml

ris2xml ris_file.ris >	output_file.xml

wordbib2xml

wordbib2xml convertit un fichier de références au format Word2007 en un fichier de bibliographie intermédiaire XML.

Options communes de conversion à partir de MODS

Notez que --output-encoding fait référence au fichier d'entrée

-h --help afficher l'aide
-v --version afficher la version
-o --output-encoding interpréter le fichier d'entrée comme utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères à www.kostis.net[4]) Unicode est maintenant une option de jeu de caractères
-s --single-refperfile mettre une référence par nom de fichier par le numéro de référence
-nb --no-bom ne pas écrire de marque d'ordre des octets lors de l'écriture en UTF8

xml2bib

xml2bib convertit la bibliographie XML MODS en un fichier de références formaté en bibtex. L'utilisation de xml2bib est la même que pour les autres outils

xml2bib xml_file.xml > output_file.bib

Étant donné que le format de référence BibTeX est assez flexible et semble avoir le plus grand nombre de préférences personnelles, il a également accumulé un certain nombre d'options spécifiques qui ne sont pas disponibles pour d'autres formats.

À partir de la version 3.24, la sortie de xml2bib utilise des balises en minuscules et des types de référence en casse mixte pour une meilleure interaction avec d'autres logiciels. Le comportement précédent avec des balises/types de référence entièrement en majuscules peut toujours être généré à l'aide de l'option de ligne de commande -U/--uppercase.

Options spécifiques à xml2bib :

-fc --finalcomma ajouter une virgule finale dans la sortie bibtex pour ceux qui le souhaitent
-sd --singledash utiliser un trait d'union au lieu de deux (trait d'union plus long en latex) entre les nombres dans la sortie de pages
-b --brackets utiliser des crochets au lieu de guillemets autour des données de champ
-w --whitespace ajouter des espaces blancs pour l'esthétique de la sortie
-U --uppercase utiliser toutes les majuscules pour les balises (noms de champ) et les types de référence (comportement avant la v3.24)
-sk --strictkey utiliser uniquement des caractères alphanumériques pour les clés de citation bibtex

xml2ads

xml2ads convertit la bibliographie XML MODS au format de référence du Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) Astrophyics Data System ou format de référence ADS[6] (qui est très similaire au style Endnote étiqueté). L'utilisation de xml2ads est la même que pour les autres outils

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convertit la bibliographie XML MODS en un fichier bibliographique formaté en RIS. L'utilisation de xml2ris est la même que pour les autres outils

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convertit la bibliographie XML MODS en un fichier bibliographique Endnote (format refer) étiqueté. L'utilisation de xml2end est la même que pour les autres outils

xml2end xml_file.xml > output_file.end

xml2wordbib

xml2wordbib convertit la bibliographie XML MODS en un fichier bibliographique XML formaté pour Word 2007. L'utilisation de xml2wordbib est la même que pour les autres outils

xml2wordbib xml_file.xml > output_file.word.xml

xml2wordbib s'appelait xml2word dans les versions de bibutils antérieures à la 3.40. Il a été renommé pour éviter toute confusion avec d'autres outils. Espérons que cela ne cassera pas trop de scripts déjà en cours d'utilisation.

NOM

xml2isi - Convertit un document XML du format "DocBook XML" au format "ISI XML" et vice-versa.

SYNOPSIS

xml2isi [options] [fichier_entree...]

DESCRIPTION

xml2isi est un utilitaire en ligne de commande conçu pour convertir des documents entre le format DocBook XML et le format ISI XML.

Le format DocBook XML est largement utilisé pour la documentation technique, tandis que le format ISI XML est utilisé dans certains contextes spécifiques, notamment au sein du projet Arch Linux pour la génération de pages de manuel.

CONVERTIR VERS MODS

Lorsque xml2isi est utilisé pour convertir un document du format DocBook XML vers le format ISI XML, il traite les éléments et attributs appropriés pour produire une structure conforme aux spécifications de l'ISI XML.

Les commandes typiques incluent :

  • La conversion d'une section de titre en élément <title>.
  • La conversion des paragraphes en éléments <para>.
  • Le traitement des listes, des tables et d'autres structures documentaires.

CONVERTIR DEPUIS MODS

La conversion du format ISI XML vers le format DocBook XML implique une transformation inverse, où la structure et les éléments spécifiques à l'ISI XML sont mappés aux éléments correspondants du DocBook XML.

Ce processus peut être utile pour intégrer du contenu initialement généré en ISI XML dans des projets utilisant DocBook comme format de documentation principal.

EXEMPLES

Convertir un fichier DocBook XML en ISI XML :

xml2isi mon_document.xml > mon_document.isi.xml

Convertir un fichier ISI XML en DocBook XML :

xml2isi -d mon_document.isi.xml > mon_document.docbook.xml

Note : L'option -d (ou une option similaire) doit être spécifiée pour indiquer une conversion depuis l'ISI XML.
