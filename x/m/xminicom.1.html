NOM

xminicom - programme convivial de communication série

SYNTAXE

xminicom options-minicom

DESCRIPTION

Xminicom est un script enveloppant minicom. Il essaie de trouver un xterm ou un rxvt capable de couleurs sur votre système, puis exécute minicom avec l'option -c (couleur) dans une session terminale.

OPTIONS

Voir minicom (1).
