bibutils - utilitaires de conversion de bibliographie

SYNTAXE

format2xml [OPTIONS] [fichier.format]

xml2format [OPTIONS] [fichier.xml]

DESCRIPTION

La suite de programmes bibutils permet l'inter-conversion entre divers formats de bibliographie en utilisant le schéma MODS (Metadata Object Description Schema)[2] version 3.1 de la Library of Congress[1]. Par exemple, on peut convertir des fichiers au format RIS en Bibtex en effectuant deux transformations : RIS->MODS->Bibtex.

Options communes pour la conversion vers MODS

Plusieurs drapeaux sont disponibles pour les programmes end2xml, endx2xml, bib2xml, ris2xml, med2xml, et copac2xml. La plupart des options ont une version courte et une version longue.

-h --help affiche l'aide
-v --version affiche la version
-a --add-refcount ajoute "_#", où # est le nombre de références, à l'identifiant de la référence
-s --single-refperfile met une référence par nom de fichier selon le numéro de référence
-i --input-encoding interprète le fichier d'entrée comme utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères de www.kostis.net[4]) unicode est maintenant une option de jeu de caractères
-u --unicode-characters encode les caractères unicode directement dans le fichier plutôt que sous forme d'entités XML
-un --unicode-no-bom comme -u, mais n'inclut pas de marque d'ordre des octets (BOM)
-x --xml-entities encode les caractères unicode sous forme d'entités XML (inverse de -u)
-nl --no-latex ne convertit pas les combinaisons de caractères de style latex
-s --single-refperfile une référence par fichier de sortie
-d --drop-key ne met pas la clé de citation dans le champ id de mods
-c --corporation-file avec un argument spécifiant un fichier contenant une liste de noms de sociétés à placer dans <name type="corporate"></name> au lieu de type="personal" et élimine la manipulation des noms
-a --asis avec un argument spécifiant un fichier contenant une liste de noms à traiter verbatim
-nt --nosplit-title ne divise pas les titres en paires TITRE/SOUS-TITRE
--verbose sortie verbeuse
--debug sortie très verbeuse (principalement pour le débogage)

bib2xml

bib2xml convertit un fichier de références au format bibtex en un fichier bibliographique intermédiaire XML. Spécifiez les fichiers à convertir sur la ligne de commande. Les fichiers contenant des chaînes de substitutions bibtex doivent être spécifiés avant les fichiers où les substitutions sont spécifiées (ou dans le même fichier avant leur utilisation). Si aucun fichier n'est spécifié, les informations bibtex seront lues depuis l'entrée standard.

bib2xml bibtex_file.bib > output_file.xml

biblatex2xml

biblatex2xml convertit un fichier de références au format biblatex (à ne pas confondre avec bibtex) en un fichier bibliographique intermédiaire MODS XML.

biblatex2xml biblatex_file.bib > outputfile.xml

copac2xml

copac2xml convertit un fichier de références au format COPAC en un fichier bibliographique intermédiaire MODS XML.

end2xml

end2xml convertit un fichier de références au format textuel EndNote en un fichier bibliographique intermédiaire XML. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté. Les formats étiquetés Endnote (exportation au format "Refer") ressemblent à l'Exemple 1, "Exemple de fichier au format refer". Il y a de très bonnes instructions pour s'assurer que vous exportez correctement ceci à http://www.sonnysoftware.com/endnoteimport.html[5]

L'utilisation de end2xml est la même que celle de bib2xml.

end2xml endnote_file.end > output_file.xml

ebi2xml

ebi2xml convertit un fichier XML EBI en un fichier bibliographique intermédiaire MODS XML.

endx2xml

endx2xml convertit un fichier de références exporté au format XML EndNote en un fichier bibliographique intermédiaire MODS XML. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté.

isi2xml

isi2xml convertit un fichier de références au format ISI-web-of-science en un fichier bibliographique intermédiaire XML.

L'utilisation de isi2xml est la même que celle de bib2xml.

isi2xml input_file.isi > output_file.xml

ris2xml

ris2xml convertit un fichier de références au format RIS en un fichier bibliographique intermédiaire XML. L'utilisation de ris2xml est la même que celle de end2xml et bib2xml

ris2xml ris_file.ris >	output_file.xml

wordbib2xml

wordbib2xml convertit un fichier de références au format Word2007 en un fichier bibliographique intermédiaire XML.

xml2bib

xml2bib convertit la bibliographie XML MODS en un fichier de références formaté en bibtex. L'utilisation de xml2bib est la même que pour les autres outils.

xml2bib xml_file.xml > output_file.bib

Comme le format de référence BibTeX est assez flexible et semble avoir le plus grand nombre de préférences personnelles, il a également accumulé un certain nombre d'options spécifiques qui ne sont pas disponibles pour d'autres formats.

À partir de la version 3.24, la sortie de xml2bib utilise des balises en minuscules et des types de référence en casse mixte pour une meilleure interaction avec d'autres logiciels. Le comportement précédent avec toutes les balises/types de référence en majuscules peut toujours être généré en utilisant le commutateur en ligne de commande -U/--uppercase.

Options spécifiques à xml2bib :

-fc --finalcomma ajouter une virgule finale dans la sortie bibtex pour ceux qui la souhaitent
-sd --singledash utiliser un trait d'union au lieu de deux (trait d'union plus long en latex) entre les numéros dans la sortie de pages
-b --brackets utiliser des crochets au lieu de guillemets autour des données de champ
-w --whitespace ajouter des espaces blancs pour l'embellissement de la sortie
-U --uppercase utiliser toutes les majuscules pour les balises (noms de champs) et les types de référence (comportement avant la version 3.24)
-sk --strictkey utiliser uniquement des caractères alphanumériques pour les clés de citation bibtex

xml2ads

xml2ads convertit la bibliographie XML MODS au format de référence du Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) Astrophyics Data System ou ADS[6] (qui est très similaire au style Endnote balisé). L'utilisation de xml2ads est la même que pour les autres outils.

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convertit la bibliographie XML MODS en un fichier bibliographique formaté en RIS. L'utilisation de xml2ris est la même que pour les autres outils.

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convertit la bibliographie XML MODS en un fichier bibliographique Endnote balisé (format refer). L'utilisation de xml2end est la même que pour les autres outils.

xml2end xml_file.xml > output_file.end

xml2wordbib

xml2wordbib convertit la bibliographie XML MODS en un fichier bibliographique XML formaté pour Word 2007. L'utilisation de xml2wordbib est la même que pour les autres outils.

xml2wordbib xml_file.xml > output_file.word.xml

xml2wordbib s'appelait xml2word dans les versions de bibutils antérieures à 3.40. Il a été renommé pour éviter la confusion avec d'autres outils. Espérons que cela ne cassera pas trop de scripts déjà en cours d'utilisation.

SYNOPSIS

xml2bib [-h|--help] [-V|--version] [-i|--input INFILE] [-o|--output OUTFILE] [-f|--format IN_FORMAT] [-t|--target TARGET_FORMAT] [-x|--xslt XSLT_FILE] [-p|--parameter NAME=VALUE] [-d|--debug] [-v|--verbose] [-s|--style STYLE]

DESCRIPTION

xml2bib is a command-line tool for converting bibliographic data between various formats, primarily focusing on XML-based formats and BibTeX.

It leverages XSLT transformations to achieve flexibility in handling different input and output formats.

CONVERTING TO MODS

To convert data to MODS (Metadata Object Description Schema) format, you typically use an XSLT stylesheet specifically designed for this purpose. The tool can apply such stylesheets using the -x option.

CONVERTING FROM MODS

Similarly, converting from MODS involves using an appropriate XSLT stylesheet to parse the MODS XML and transform it into the desired output format, such as BibTeX.

EXAMPLES

1. Convert an XML file to BibTeX:

xml2bib -i input.xml -o output.bib

2. Convert a specific XML format to BibTeX using a custom XSLT:

xml2bib -i data.xml -o references.bib -x transform_to_bibtex.xsl

3. Convert a BibTeX file to XML (using a hypothetical XSLT):

xml2bib -i references.bib -o output.xml -f bibtex -t xml -x bibtex_to_xml.xsl

4. Convert to MODS format with debugging enabled:

xml2bib -i source.xml -o mods.xml -x xml_to_mods.xsl -d

NOTES

The effectiveness of xml2bib relies heavily on the quality and appropriateness of the XSLT stylesheets used for the transformations. Ensure that your XSLT files correctly map the elements and attributes of your source XML to the structure of the target format.

For complex conversions, consider breaking down the transformation process into multiple steps or using more specialized tools if necessary.
