NOM

xml-pretty - imprimer joliment le XML sur STDOUT

SYNTAXE

xml-pretty FICHIER_ENTREE

cat FICHIER_ENTREE | xml-pretty

DESCRIPTION

xml-pretty lit le XML à partir d'un fichier d'entrée ou de STDIN, le formate en utilisant XML::LibXML::PrettyPrint avec ses paramètres par défaut, et l'imprime sur STDOUT.
