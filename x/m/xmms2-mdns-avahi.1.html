NOM

xmms2-mdns-avahi - annonce XMMS2 via mDNS

SYNTAXE

xmms2-mdns-avahi

DESCRIPTION

XMMS2 est une refonte du lecteur de musique XMMS (https://github.com/xmms2). Il dispose d'un modèle client-serveur, permettant plusieurs interfaces utilisateur (même simultanées !), tant textuelles que graphiques. Tous les formats audio courants sont pris en charge à l'aide de plugins. En plus de cela, il existe une bibliothèque multimédia flexible pour organiser votre musique.

xmms2-mdns-avahi est le client d'annonce Avahi mDNS pour XMMS2. xmms2-mdns-avahi est conçu pour annoncer la présence d'une socket TCP XMMS2 accessible si elle est disponible.

xmms2-mdns-avahi offre un service _xmms2._tcp si, et seulement si, la variable d'environnement XMMS_PATH_FULL contient une socket TCP. Cela permet aux clients qui prennent en charge la découverte mDNS de localiser et de se connecter facilement à cette instance de xmms2d(1).

VARIABLES ENVIRONNEMENTALES

XMMS_PATH_FULL
Une liste complète de chemins d'URL séparés par ';' pointant vers xmms2d(1). Voir IPC SOCKET dans xmms2d(1) pour les détails des valeurs possibles pour cette variable

VOIR AUSSI

xmms2(1), xmms2d(1), https://github.com/xmms2
