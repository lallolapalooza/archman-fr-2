bibutils - utilitaires de conversion de bibliographie

SYNTAXE

format2xml [OPTIONS] [fichier.format]

xml2format [OPTIONS] [fichier.xml]

DESCRIPTION

La suite de programmes bibutils permet l'inter-conversion entre divers formats de bibliographie en utilisant le schéma de description des objets méta-données (MODS) version 3.1 de la Library of Congress[1]. Par exemple, on peut convertir des fichiers au format RIS en Bibtex en effectuant deux transformations : RIS->MODS->Bibtex.

CONVERSION VERS MODS

Aperçu

Commande Description
bib2xml convertit bibtex en MODS
biblatex2xml convertit biblatex en MODS
copac2xml convertit les références au format COPAC[3] en MODS
ebi2xml convertit EBI XML en MODS
end2xml convertit EndNote (format Refer) en MODS
endx2xml convertit EndNote XML en MODS
isi2xml convertit ISI web of science en MODS
med2xml convertit les références PubMed XML en MODS
nbib2xml convertit les références au format nbib de PubMed en MODS
modsclean un convertisseur MODS vers MODS
ris2xml convertit le format RIS en MODS
wordbib2xml convertit les références XML de Word2007 en MODS

Options communes pour la conversion vers MODS

Plusieurs indicateurs sont disponibles pour les programmes end2xml, endx2xml, bib2xml, ris2xml, med2xml et copac2xml. La plupart des options ont une version courte et une version longue.

-h --help affiche l'aide
-v --version affiche la version
-a --add-refcount ajoute "_#", où # est le nombre de références, à l'identifiant de la référence
-s --single-refperfile met une référence par nom de fichier selon le numéro de référence
-i --input-encoding interprète le fichier d'entrée comme utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères sur www.kostis.net[4]) unicode est maintenant une option de jeu de caractères
-u --unicode-characters encode les caractères unicode directement dans le fichier plutôt que sous forme d'entités XML
-un --unicode-no-bom comme -u, mais n'inclut pas d'octet d'ordre des bits (BOM)
-x --xml-entities encode les caractères unicode sous forme d'entités XML (opposé de -u)
-nl --no-latex ne convertit pas les combinaisons de caractères de style latex
-s --single-refperfile une référence par fichier de sortie
-d --drop-key ne met pas la clé de citation dans le champ d'identifiant mods
-c --corporation-file avec un argument spécifiant un fichier contenant une liste de noms de sociétés à placer dans <name type="corporate"></name> au lieu de type="personal" et à éliminer la manipulation des noms
-a --asis avec un argument spécifiant un fichier contenant une liste de noms à traiter tels quels
-nt --nosplit-title ne divise pas les titres en paires TITRE/SOUS-TITRE
--verbose sortie détaillée
--debug sortie très détaillée (principalement pour le débogage)

bib2xml

bib2xml convertit un fichier de références au format bibtex en un fichier de bibliographie intermédiaire XML. Spécifiez les fichiers à convertir sur la ligne de commande. Les fichiers contenant des chaînes de substitution bibtex doivent être spécifiés avant les fichiers où les substitutions sont spécifiées (ou dans le même fichier avant leur utilisation). Si aucun fichier n'est spécifié, alors les informations bibtex seront lues depuis l'entrée standard.

bib2xml bibtex_file.bib > fichier_sortie.xml

biblatex2xml

biblatex2xml convertit un fichier de références au format biblatex (à ne pas confondre avec bibtex) en un fichier de bibliographie intermédiaire XML MODS.

biblatex2xml biblatex_file.bib > fichier_sortie.xml

copac2xml

copac2xml convertit un fichier de références au format COPAC en un fichier de bibliographie intermédiaire XML MODS.

end2xml

end2xml convertit un fichier de références au format texte EndNote en un fichier de bibliographie intermédiaire XML. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté. Les formats étiquetés Endnote (exportation au format "Refer") ressemblent à l'Exemple 1, « Exemple de fichier au format refer ». Il existe de très bonnes instructions pour s'assurer que vous exportez correctement ceci sur http://www.sonnysoftware.com/endnoteimport.html[5]

L'utilisation de end2xml est la même que celle de bib2xml.

end2xml fichier_endnote.end > fichier_sortie.xml

ebi2xml

ebi2xml convertit un fichier XML EBI en un fichier de bibliographie intermédiaire XML MODS.

endx2xml

endx2xml convertit un fichier de références exporté en EndNote-XML en un fichier de bibliographie intermédiaire XML MODS. Ce programme ne fonctionnera pas sur la bibliothèque binaire ; le fichier doit d'abord être exporté.

isi2xml

isi2xml convertit un fichier de références au format ISI-web-of-science en un fichier de bibliographie intermédiaire XML.

L'utilisation de isi2xml est la même que celle de bib2xml.

isi2xml fichier_entree.isi > fichier_sortie.xml

ris2xml

ris2xml convertit un fichier de références au format RIS en un fichier de bibliographie intermédiaire XML. L'utilisation de ris2xml est la même que celle de end2xml et bib2xml.

ris2xml fichier_ris.ris >	fichier_sortie.xml

wordbib2xml

wordbib2xml convertit un fichier de références au format Word2007 en un fichier de bibliographie intermédiaire XML.

Options communes pour la conversion depuis MODS

Notez que --output-encoding fait référence au fichier d'entrée

-h --help afficher l'aide
-v --version afficher la version
-o --output-encoding interpréter le fichier d'entrée comme utilisant le jeu de caractères demandé (utiliser sans argument pour la liste actuelle dérivée des jeux de caractères sur www.kostis.net[4]) unicode est maintenant une option de jeu de caractères
-s --single-refperfile mettre une référence par nom de fichier, par numéro de référence
-nb --no-bom ne pas écrire de marque d'ordre des octets (BOM) lors de l'écriture en UTF8

xml2bib

xml2bib convertit la bibliographie XML MODS en un fichier de références formaté en bibtex. L'utilisation de xml2bib est similaire à celle des autres outils.

xml2bib xml_file.xml > output_file.bib

Comme le format de référence BibTeX est assez flexible et semble avoir le plus grand nombre de préférences personnelles, il a également accumulé un certain nombre d'options spécifiques qui ne sont pas disponibles pour d'autres formats.

À partir de la version 3.24, la sortie de xml2bib utilise des étiquettes en minuscules et des types de référence en casse mixte pour une meilleure interaction avec d'autres logiciels. Le comportement précédent avec toutes les étiquettes/types de référence en majuscules peut toujours être généré en utilisant le commutateur de ligne de commande -U/--uppercase.

Options spécifiques à xml2bib :

-fc --finalcomma ajouter une virgule finale dans la sortie bibtex pour ceux qui la souhaitent
-sd --singledash utiliser un trait d'union au lieu de deux (trait d'union plus long en latex) entre les nombres dans la sortie des pages
-b --brackets utiliser des crochets au lieu de guillemets autour des données de champ
-w --whitespace ajouter des espaces pour l'esthétique de la sortie
-U --uppercase utiliser toutes les majuscules pour les étiquettes (noms de champs) et les types de référence (comportement avant la v3.24)
-sk --strictkey utiliser uniquement des caractères alphanumériques pour les clés de citation bibtex

xml2ads

xml2ads convertit la bibliographie XML MODS au format de référence du Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) Astrophyics Data System ou ADS[6] (qui est très similaire au style Endnote étiqueté). L'utilisation de xml2ads est comme pour les autres outils.

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris convertit la bibliographie XML MODS en un fichier bibliographique au format RIS. L'utilisation de xml2ris est comme pour les autres outils.

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end convertit la bibliographie XML MODS en un fichier bibliographique Endnote étiqueté (format refer). L'utilisation de xml2end est comme pour les autres outils.

xml2end xml_file.xml >  output_file.end

xml2wordbib

xml2wordbib convertit la bibliographie XML MODS en un fichier bibliographique XML au format Word 2007. L'utilisation de xml2wordbib est comme pour les autres outils.

xml2wordbib xml_file.xml >  output_file.word.xml

xml2wordbib s'appelait xml2word dans les versions de bibutils antérieures à 3.40. Il a été renommé pour éviter toute confusion avec d'autres outils. Espérons que cela ne cassera pas trop de scripts déjà en usage.

xml2ris

xml2ris - Convertit les fichiers XML BibTeX en format RIS

SYNOPIS

xml2ris [OPTIONS] [FICHIER_XML]

DESCRIPTION

xml2ris est un outil en ligne de commande qui convertit les fichiers XML BibTeX en format RIS (Research Information Systems). Ce format est couramment utilisé par les gestionnaires de références bibliographiques tels que EndNote, Zotero et Mendeley.

Le programme lit un fichier XML BibTeX en entrée et produit une sortie au format RIS. Si aucun fichier n'est spécifié, il lit depuis l'entrée standard.

CONVERSION VERS MODS

Le format MODS (Metadata Object Description Schema) est un schéma XML utilisé pour décrire des ressources bibliographiques. xml2ris ne convertit pas directement vers le format MODS. Cependant, certains outils peuvent être utilisés pour convertir entre BibTeX XML et MODS.

CONVERSION DEPUIS MODS

xml2ris ne convertit pas directement depuis le format MODS. Si vous avez des données au format MODS, vous devrez d'abord les convertir dans un format intermédiaire (comme BibTeX) avant de pouvoir utiliser xml2ris pour les transformer en RIS.

EXEMPLES

Pour convertir un fichier XML BibTeX nommé references.xml en un fichier RIS nommé references.ris :

xml2ris references.xml > references.ris

Pour convertir des données XML BibTeX depuis l'entrée standard et afficher le résultat RIS sur la sortie standard :

cat references.xml | xml2ris

Ce programme est un outil simple pour la conversion de format. Les spécificités de mappage entre les champs XML BibTeX et RIS peuvent varier. Il est conseillé de vérifier la sortie pour s'assurer que la conversion est correcte pour vos besoins.
