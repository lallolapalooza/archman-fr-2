NOM

xml2pot - Crée un fichier modèle PO à partir d'un fichier XML DocBook.

SYNOPSIS

xml2pot [XML-original]

DESCRIPTION

xml2pot est un outil en ligne de commande qui produit un fichier modèle de messages gettext à partir du fichier XML DocBook XML-original. Le fichier modèle est envoyé à la sortie standard.

Le fichier modèle résultant peut être utilisé pour créer des fichiers de messages gettext (fichiers PO) pour une variété de langues. Ceux-ci peuvent ensuite être utilisés en conjonction avec po2xml(1) pour traduire le fichier XML original dans ces autres langues.

Cet utilitaire fait partie du Kit de développement logiciel KDE.

VOIR AUSSI

po2xml(1), split2po(1), swappo(1)
