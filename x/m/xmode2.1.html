MODE2(1) Commandes utilisateur MODE2(1)

NOM

xmode2 - Affiche la durée des impulsions/espaces des signaux infrarouges

SYNTAXE

xmode2 [options]

DESCRIPTION

Le but principal de xmode2 est de vérifier le fonctionnement de votre matériel récepteur LIRC fait maison et de visualiser la forme d'onde IR de la télécommande sans oscilloscope coûteux. Très utile pour le débogage. Bien sûr, ce programme ne fonctionnera pas avec du matériel qui décode les signaux lui-même comme par exemple les cartes TV ou l'Irman, c'est-à-dire qu'il ne fonctionne qu'avec les pilotes de type LIRC_MODE_MODE2.

xmode2 affiche graphiquement la durée des impulsions/espaces. Il accepte quelques commandes, y compris des changements d'échelle de temps ; voir la sortie de xmode2 -h.

lirc-lsplugins(1) permet de vérifier si un pilote est de type LIRC_MODE2.

OPTIONS

-h --help
affiche le résumé d'utilisation
-v --version
affiche la version
-d --device=périphérique
lire depuis le périphérique donné
-H --driver=pilote
utiliser le pilote donné
-m --mode
activer le mode d'affichage alternatif
-r --raw
accéder directement au périphérique

EXÉCUTER EN ROOT

Dans de nombreux cas, xmode2 doit être exécuté en tant que root pour accéder aux périphériques non disponibles pour les utilisateurs réguliers. D'un autre côté, exécuter en tant que root crée des problèmes tels que des fichiers journaux appartenant à root, des préoccupations de sécurité, etc.

Afin de gérer cela, xmode2 abandonne par défaut les privilèges root après avoir ouvert le périphérique d'entrée. Ce support est basé sur le fait que les permissions root sont acquises en utilisant sudo(1), par exemple, en utilisant

        $ sudo xmode2 --driver default --device /dev/lirc0
Si vous n'utilisez pas sudo, le même comportement pourrait être obtenu en utilisant la variable d'environnement SUDO_USER, par exemple 
        # SUDO_USER=$LOGNAME xmode2 --raw /dev/lirc0
L'option --keep-root fera en sorte que xmode2 conserve ses privilèges root pendant toute son exécution.

CHARGEMENT DES PILOTES

Les pilotes sont chargés dynamiquement. Le chemin de recherche utilisé à cet effet est déterminé par (priorité décroissante) :

  • L'option --plugindir.
  • L'entrée 'plugindir' dans la section [lircd] du fichier lirc_options.conf.
  • La variable d'environnement LIRC_PLUGINDIR.
  • Un chemin par défaut codé en dur (généralement /usr/lib[64]/lirc/plugins).

FICHIERS

~/.cache/xmode2.log
Sortie de débogage. La définition de la variable d'environnement XDG_CACHE_HOME déplace ce fichier vers $XDG_CACHE_HOME/mode2.log
