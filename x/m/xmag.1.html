NOM

xmag - agrandir des parties de l'écran

SYNTAXE

xmag [ -mag facteuragrandissement ] [ -source geom ] [ -optionoutil ... ]
xmag [ -help | -version ]

DESCRIPTION

Le programme xmag vous permet d'agrandir des portions d'un écran X. Si aucune région explicite n'est spécifiée, un carré avec le pointeur dans le coin supérieur gauche est affiché, indiquant la zone à agrandir. La zone peut être redimensionnée par glisser-déposer en appuyant sur le Bouton 2. Une fois qu'une région a été sélectionnée, une fenêtre apparaît, montrant une version agrandie de la région où chaque pixel de l'image source est représenté par un petit carré de la même couleur. Appuyer sur le Bouton 1 dans la fenêtre d'agrandissement affiche la position et la valeur RVB du pixel sous le pointeur jusqu'à ce que le bouton soit relâché. Taper « Q » ou « ^C » dans la fenêtre d'agrandissement quitte le programme. L'application dispose de 5 boutons en haut. Close supprime cette instance d'agrandissement particulière. Replace fait réapparaître le sélecteur de bande élastique pour choisir une autre région pour cette instance d'agrandissement. New fait apparaître le sélecteur de bande élastique pour créer une nouvelle instance d'agrandissement. Select place l'image d'agrandissement dans la sélection principale. Paste copie le tampon de sélection principale dans xmag. Notez que vous pouvez couper et coller entre xmag et le programme bitmap. Redimensionner xmag redimensionne la zone d'agrandissement. xmag préserve la palette de couleurs, la visualisation et la profondeur de fenêtre de la source.

WIDGETS

xmag utilise le X Toolkit et l'Athena Widget Set. L'image agrandie est affichée dans le widget Scale. Pour plus d'informations, consultez la documentation de l'Athena Widget Set. Ci-dessous se trouve la structure des widgets de l'application xmag. L'indentation indique la structure hiérarchique. Le nom de la classe du widget est donné en premier, suivi du nom de l'instance du widget.

OPTIONS

-source geom
Cette option spécifie la taille et/ou l'emplacement de la région source sur l'écran. Par défaut, un carré de 64x64 est fourni à l'utilisateur pour sélectionner une zone de l'écran.
-mag entier
Cette option indique le facteur d'agrandissement à utiliser. 5 est la valeur par défaut.
-help
Cette option indique que xmag doit afficher un message d'utilisation et se quitter.
-version
Cette option indique que xmag doit afficher des informations de version et se quitter.
