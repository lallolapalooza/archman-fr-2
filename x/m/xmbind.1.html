NOM

xmbind — Configure les liaisons de touches virtuelles

SYNTAXE

xmbind [options ] [fichier ]

DESCRIPTION

xmbind est un client du système de fenêtrage X qui configure les liaisons de touches virtuelles pour les applications Motif. Cette action est effectuée par mwm lors de son démarrage, donc le client xmbind n'est nécessaire que lorsque mwm n'est pas utilisé, ou lorsque vous souhaitez modifier les liaisons sans redémarrer mwm. Si un fichier est spécifié, son contenu est utilisé comme liaisons de touches virtuelles. Si aucun fichier n'est spécifié, le fichier .motifbind dans le répertoire personnel de l'utilisateur est utilisé. Si ce fichier n'est pas trouvé, xmbind charge les liaisons de touches virtuelles par défaut, comme décrit dans VirtualBindings(3).

Options

-display
Cette option spécifie l'affichage à utiliser ; voir X(1).

VOIR AUSSI

VirtualBindings(3) et X(1).
