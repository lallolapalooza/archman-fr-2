NOM

xscreensaver-text - imprime du texte sur stdout, pour être utilisé par les économiseurs d'écran.

SYNTAXE

xscreensaver-text [--verbose] [--columns N] [--lines N] [--latin1] [--date] [--text CHAINE] [--file CHEMIN] [--program CMD] [--url URL]

DESCRIPTION

Le script xscreensaver-text affiche du texte pour être utilisé par divers économiseurs d'écran, selon les options définies dans le fichier ~/.xscreensaver. Il peut afficher le contenu d'un fichier, exécuter un programme ou charger une URL. Le texte est reformaté et renvoyé à la ligne si nécessaire.

OPTIONS

xscreensaver-text accepte les options suivantes :

--verbose ou --v
Affiche des diagnostics sur stderr. Plusieurs options -v augmentent le niveau de sortie.
--columns N ou --cols N
Nombre de colonnes pour renvoyer les lignes à la ligne ; par défaut 72 colonnes.
--lines N
Limite la sortie à ce nombre maximum de lignes. Par défaut : illimité.
--latin1
Convertit les caractères UTF-8 de l'entrée en leur équivalent Latin1 le plus proche pour la sortie.

Les options en ligne de commande peuvent être utilisées pour remplacer les paramètres du fichier ~/.xscreensaver :

--date
Affiche le nom de l'hôte et l'heure actuelle.
--text CHAINE
Affiche le texte donné. Il peut contenir des séquences d'échappement % conformément à strftime(2).
--file CHEMIN
Affiche le contenu du fichier donné, en le reformatant selon les autres options.
--program CMD
Exécute le programme donné et affiche sa sortie, en le reformatant selon les autres options.
--url URL
Télécharge et affiche le contenu de la page Web. Si elle contient du HTML, du RSS ou de l'Atom, elle sera convertie en texte brut. Cela re-télécharge le document à chaque exécution.

ENVIRONNEMENT

HTTP_PROXY, HTTPS_PROXY, http_proxy, ou https_proxy
pour obtenir l'hôte et le port du proxy par défaut.

BOGUES

Les URL devraient être mises en cache, utiliser "If-Modified-Since" et respecter "Expires".
