NOM

xsd - Utilitaire de Mono pour générer des schémas ou des fichiers de classes

SYNTAXE

xsd <schema.xsd> /classes [options]

xsd <schema.xsd> /dataset [options]

xsd <assembly>.dll|<assembly>.exe [options]

xsd <instance.xml> [<instance.xml> ...] [options]

DESCRIPTION

xsd est un outil destiné à compléter le support de sérialisation XML de Mono. Il peut effectuer les tâches suivantes :

Générer des classes sérialisables
À partir d'un schéma XML donné, générer une classe qui peut être utilisée pour lire et écrire des documents XML conformes à ce schéma (option /classes).
Générer des jeux de données typés
À partir d'un schéma XML donné, générer une classe DataSet typée qui peut être utilisée pour lire et écrire des documents XML conformes à ce schéma (option /dataset).
Générer des schémas XML
À partir d'une assembly donnée et d'un nom de type optionnel, générer un schéma XML qui peut être utilisé pour valider les documents XML qui peuvent être obtenus en sérialisant des objets de ce type. Si aucun type n'est fourni, xsd génère un schéma pour tous les types de l'assembly. Lors de la spécification du nom de l'assembly, n'incluez pas l'extension de fichier (.dll ou .exe). xsd recherchera l'assembly en utilisant les règles standard de chargement des assemblies.
Inférez des schémas XML
À partir d'un ensemble de documents XML donné, inférez le schéma XML qui peut être utilisé pour valider ces documents.

OPTIONS

Les options suivantes sont disponibles :

/element:nom /e:nom
Spécifie le nom de l'élément du schéma XML pour lequel une classe ou un jeu de données doit être généré.
/namespace:nom /n:nom
Spécifie l'espace de noms de l'élément du schéma XML pour lequel une classe ou un jeu de données doit être généré.
/language:nom /l:nom
Spécifie le langage de programmation à utiliser pour le code généré. Les seuls langages pris en charge sont CS (C#) et VB (Visual Basic.NET).
/generator:type,assembly /g:type,assembly
Indique à xsd.exe d'utiliser un CodeDomProvider personnalisé pour générer du code. Le nom du type doit être le nom complet. Le nom de l'assembly est un nom de fichier local qui sera chargé. Le Type spécifié doit avoir le constructeur par défaut.
/outputdir:chemin /o:chemin
Spécifie le répertoire où générer le code ou les schémas.
/type:nom /t:nom
Spécifie le nom complet du type (y compris l'espace de noms) pour lequel générer le schéma XML.
/help /h
Afficher l'aide d'utilisation.
