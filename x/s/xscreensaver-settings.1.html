Paquet: xscreensaver

XScreenSaver(1) Manuel des commandes générales XScreenSaver(1)

NOM

xscreensaver-settings - configurer et contrôler le démon xscreensaver

SYNTAXE

xscreensaver-settings [--display hôte:écran.display] [--debug]

DESCRIPTION

Le programme xscreensaver-settings est une interface graphique pour configurer les paramètres utilisés par le démon xscreensaver(1). C'est un outil pour éditer le fichier ~/.xscreensaver et pour tester les différents modes d'affichage.

La fenêtre principale est composée d'une barre de menu et de deux onglets. Le premier onglet est destiné à l'édition de la liste des démos, et le second à l'édition de divers autres paramètres du protège-écran.

COMMANDES DU MENU

Toutes ces commandes se trouvent soit dans le menu Fichier, soit dans le menu Aide :

Écran noir maintenant
Active le démon xscreensaver en arrière-plan, qui exécutera alors une démo aléatoirement. C'est la même chose que d'exécuter xscreensaver-command(1) avec l'option --activate.
Verrouiller l'écran maintenant
Tout comme Écran noir maintenant, sauf que l'écran sera également verrouillé (même s'il n'est pas configuré pour se verrouiller en permanence). C'est la même chose que d'exécuter xscreensaver-command(1) avec l'option --lock.
Arrêter le démon
Si le démon xscreensaver est en cours d'exécution sur cet écran, arrêtez-le. C'est la même chose que d'exécuter xscreensaver-command(1) avec l'option --exit.
Redémarrer le démon
Si le démon xscreensaver est en cours d'exécution sur cet écran, arrêtez-le. Lancez-le ensuite à nouveau. C'est la même chose que d'exécuter « xscreensaver-command --exit » suivi de « xscreensaver ».

Notez que ce n'est pas la même chose que d'exécuter « xscreensaver-command --restart ».

Quitter
Ferme le programme xscreensaver-settings (ce programme) sans affecter le démon xscreensaver en arrière-plan, le cas échéant.
À propos...
Affiche le numéro de version de ce programme, xscreensaver-settings.
Documentation...
Ouvre un navigateur web pointant vers la page web de XScreenSaver, où vous pouvez trouver des copies en ligne des manuels xscreensaver(1), xscreensaver-settings(1) et xscreensaver-command(1).

ONGLET MODES D'AFFICHAGE

Cet onglet contient une liste des noms des différents modes d'affichage, une zone de prévisualisation et quelques champs qui vous permettent de configurer le comportement du protège-écran.

Mode

Ce menu d'options contrôle le comportement d'activation du protège-écran. Les options sont :

Désactiver le protège-écran
Ne jamais mettre l'écran en noir et ne jamais permettre à l'écran de s'éteindre.
Écran noir uniquement
Lors de la mise en noir de l'écran, il devient simplement noir : aucune animation graphique n'est exécutée.
Un seul protège-écran
Lors de la mise en noir de l'écran, n'utiliser qu'un mode d'affichage particulier (celui sélectionné dans la liste).
Protège-écran aléatoire
Lors de la mise en noir de l'écran, sélectionner un mode d'affichage aléatoire parmi ceux qui sont activés et applicables. S'il y a plusieurs écrans connectés, exécuter un mode d'affichage différent sur chacun. C'est le comportement par défaut.
Même protège-écran aléatoire
C'est exactement comme Protège-écran aléatoire, sauf que le même mode d'affichage choisi aléatoirement sera exécuté sur tous les écrans, au lieu d'un différent sur chacun.

Liste des démos

Double-cliquer dans la liste de gauche vous permettra d'essayer la démo indiquée. L'écran deviendra noir, et le programme s'exécutera en mode plein écran, tout comme si le démon xscreensaver l'avait lancé. Cliquer avec la souris à nouveau arrêtera la démo et rétablira l'écran.

Un simple clic dans la liste l'exécutera dans la petite fenêtre de prévisualisation à droite. (Mais attention : plusieurs modes d'affichage se comportent différemment en mode plein écran, donc la vue réduite pourrait ne pas donner une impression exacte.)

Lorsque le Mode est réglé sur Protège-écran aléatoire, chaque nom dans la liste a une case à cocher à côté : cela contrôle si ce mode d'affichage est activé. S'il est décoché, ce mode ne sera pas choisi. (Bien que vous puissiez toujours l'exécuter explicitement en double-cliquant sur son nom.)

Si la liste a le focus, vous pouvez taper n'importe quel caractère pour la rechercher.

Boutons Fléchés

Sous la liste se trouvent une paire de flèches, haut et bas. Cliquer sur la flèche vers le bas sélectionnera l'élément suivant dans la liste, puis l'exécutera en mode plein écran, comme si vous aviez double-cliqué dessus. La flèche vers le haut fait l'inverse. C'est juste un raccourci pour essayer tous les modes d'affichage à tour de rôle.

Mise en noir après

Après que l'utilisateur soit inactif pendant ce laps de temps, le démon xscreensaver mettra l'écran en noir.

Rotation après

Une fois le protège-écran actif pendant cette durée, la démo graphique en cours sera arrêtée et une nouvelle démarrera. Si ce champ est à 0, alors la démo graphique ne changera jamais : une seule démo s'exécutera jusqu'à ce que le protège-écran soit désactivé par une activité utilisateur.

S'il y a plusieurs écrans, les protège-écrans sont légèrement décalés de sorte que, bien qu'ils changent tous toutes les cycle minutes, ils ne changent pas tous en même temps.

Verrouiller l'écran

Lorsque cette option est cochée, l'écran sera verrouillé lorsqu'il s'activera.

Verrouiller l'écran après

Ceci contrôle la durée de la « période de grâce » entre le moment où le protège-écran s'active et le moment où l'écran est verrouillé. Par exemple, si ce champ est réglé sur 5 minutes et Mise en noir après sur 10 minutes, alors après 10 minutes, l'écran deviendrait noir. S'il y avait une activité utilisateur à 12 minutes, aucun mot de passe ne serait requis pour rétablir l'écran. Mais, s'il y avait une activité utilisateur à 15 minutes ou plus tard (c'est-à-dire, Verrouiller l'écran après minutes après l'activation), alors un mot de passe serait requis. La valeur par défaut est 0, ce qui signifie que si le verrouillage est activé, un mot de passe sera requis dès que l'écran deviendra noir.

Prévisualisation

Ce bouton, situé sous la petite fenêtre de prévisualisation, exécute la démo en mode plein écran afin que vous puissiez l'essayer. C'est la même chose que ce qui se passe lorsque vous double-cliquez sur un élément de la liste. Cliquez avec la souris pour fermer la prévisualisation plein écran.

Paramètres

Ce bouton fera apparaître une boîte de dialogue où vous pourrez configurer les paramètres spécifiques au mode d'affichage sélectionné dans la liste.

BOÎTE DE DIALOGUE DES PARAMÈTRES

Lorsque vous cliquez sur le bouton Paramètres dans l'onglet Modes d'affichage, une boîte de dialogue de configuration apparaîtra, vous permettant de personnaliser les paramètres du mode d'affichage sélectionné. Chaque mode d'affichage a son propre ensemble personnalisé de réglages de configuration.

ONGLETS AVANCÉS

Cet onglet vous permet de modifier divers paramètres utilisés par le démon xscreensaver lui-même, ainsi que certaines options globales partagées par tous les modes d'affichage.

Manipulation des images

Certains des effets graphiques manipulent des images. Ces paramètres contrôlent la provenance de ces images sources. Les économiseurs chargent les images en exécutant les programmes xscreensaver-getimage(6) et xscreensaver-getimage-file(6).

Capturer les images du bureau
Si cette option est sélectionnée, les économiseurs sont autorisés à manipuler l'image du bureau, c'est-à-dire qu'un mode d'affichage peut afficher une image de votre bureau en train de fondre, ou d'être déformée d'une manière ou d'une autre. Les paranoïaques de la sécurité pourraient vouloir désactiver cette option, car si elle est activée, cela signifie que les fenêtres de votre bureau seront occasionnellement visibles pendant que votre écran est verrouillé. Les autres ne pourront rien faire, mais ils pourront voir tout ce que vous avez laissé sur votre écran.
Capturer les images vidéo
Si votre système dispose d'une caméra ou d'une autre entrée vidéo, la sélection de cette option peut permettre aux modes de manipulation d'images de capturer une image fixe vidéo pour opérer dessus.
Choisir une image aléatoire
Si cette option est sélectionnée, les modes de manipulation d'images choisiront un fichier image aléatoire sur lequel opérer, à partir de la source spécifiée. Cette source peut être un répertoire local, qui sera recherché récursivement pour y trouver des images. Ou, cela peut être l'URL d'un flux RSS ou Atom (par exemple, une galerie Flickr), auquel cas une image aléatoire de ce flux sera sélectionnée à la place. Le contenu du flux sera mis en cache localement et rafraîchi périodiquement au besoin.

Si plusieurs des options liées aux images ci-dessus sont sélectionnées, l'une d'entre elles sera choisie au hasard. Si aucune d'entre elles n'est sélectionnée, une image de barres de couleurs vidéo sera utilisée à la place.

Manipulation du texte

Certains des modes d'affichage affichent et manipulent du texte. Les options suivantes contrôlent la façon dont ce texte est généré. Les économiseurs chargent le texte en exécutant le programme xscreensaver-text(6).

Nom d'hôte et heure
Si cette case est cochée, le texte utilisé par les économiseurs d'écran sera le nom d'hôte local, la version du système d'exploitation, la date, l'heure et la charge du système.
Texte
Si cette case est cochée, le texte littéral tapé dans le champ à sa droite sera utilisé. S'il contient des séquences d'échappement %, elles seront développées conformément à strftime(2).
Fichier texte
Si cette case est cochée, le contenu du fichier correspondant sera affiché.
Programme
Si cette case est cochée, le programme donné sera exécuté, de manière répétée, et sa sortie sera affichée.
URL
Si cette case est cochée, la page web donnée sera téléchargée et affichée de manière répétée. Si le document contient du HTML, RSS ou Atom, il sera d'abord converti en texte brut.

Note : cela re-télécharge le document à chaque fois que l'économiseur d'écran manque de texte, donc il frappera probablement ce serveur web plusieurs fois par minute.

Paramètres de gestion d'alimentation

Ces paramètres contrôlent si, et quand, votre moniteur s'éteint.

Gestion d'alimentation activée
Si le moniteur doit s'éteindre après une période d'inactivité.

Si cette option est grisée, cela signifie que votre serveur X ne prend pas en charge l'extension XDPMS, et donc le contrôle de l'état d'alimentation du moniteur n'est pas disponible.

Veille après
Si Gestion d'alimentation activée est sélectionnée, le moniteur deviendra noir après ce temps d'inactivité. (Les démos graphiques s'arrêteront également.)
Suspension après
Si Gestion d'alimentation activée est sélectionnée, le moniteur passera en mode d'économie d'énergie après ce temps d'inactivité. Cette durée doit être supérieure ou égale à Veille.
Éteint après
Si Gestion d'alimentation activée est sélectionnée, le moniteur s'éteindra complètement après ce temps d'inactivité. Cette durée doit être supérieure ou égale à Suspension.
Extinction rapide en mode écran noir uniquement
Si le mode d'affichage est réglé sur Écran noir uniquement et que cette option est cochée, le moniteur sera éteint immédiatement lors de la mise en noir, quelles que soient les autres options de gestion d'alimentation. De cette façon, les minuteries d'inactivité de gestion d'alimentation peuvent être complètement désactivées, mais l'écran sera éteint lorsqu'il est noir.

Fondu au noir

Ces options contrôlent la façon dont l'écran passe au noir ou en revient lorsqu'un économiseur d'écran démarre ou se termine.

Fondu au noir lors de l'extinction
Si sélectionné, lorsque l'économiseur d'écran s'active, le contenu actuel de l'écran fondra au noir au lieu de disparaître simplement.
Fondu depuis le noir lors du réveil
Le contraire : si sélectionné, lorsque l'économiseur d'écran se désactive, le contenu original de l'écran apparaîtra progressivement depuis le noir au lieu d'apparaître immédiatement. Ceci n'est fait que si Fondu au noir est également sélectionné.
Durée du fondu
Lorsque le fondu ou le défondu sont sélectionnés, cela contrôle la durée du fondu.

Thème

Ce menu d'options liste les schémas de couleurs disponibles pour la boîte de dialogue de déverrouillage.

Il existe plus de paramètres que ceux-ci, mais ce sont les plus couramment utilisés ; consultez le manuel de xscreensaver(1) pour d'autres paramètres qui peuvent être définis en éditant le fichier ~/.xscreensaver, ou la base de données des ressources X.

OPTIONS DE LIGNE DE COMMANDE

xscreensaver-settings accepte les options de ligne de commande suivantes.

--display hôte:affichage.écran
L'affichage X à utiliser. Le programme xscreensaver-settings ouvrira sa fenêtre sur cet affichage, et contrôlera également le démon xscreensaver qui gère ce même affichage.
--debug
Provoque l'affichage de nombreux diagnostics sur stderr.

Les processus xscreensaver et xscreensaver-settings doivent s'exécuter sur la même machine, ou du moins, sur deux machines qui partagent un système de fichiers. Lorsque xscreensaver-settings écrit une nouvelle version du fichier ~/.xscreensaver, xscreensaver doit voir ce même fichier, sinon cela ne fonctionnera pas.

ENVIRONNEMENT

DISPLAY
pour obtenir le nom d'hôte et le numéro d'affichage par défaut.
PATH
pour trouver les sous-programmes à exécuter. Cependant, notez que les sous-programmes sont lancés par xscreensaver-settings pour l'affichage dans le volet de prévisualisation en ligne, mais par le démon xscreensaver lorsqu'il est exécuté en plein écran, donc le paramètre $PATH dans les deux processus est important.
HOME
pour le répertoire dans lequel lire et écrire le fichier .xscreensaver.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
HTTP_PROXY, HTTPS_PROXY, http_proxy, ou https_proxy
pour obtenir le nom d'hôte et le port du proxy par défaut.

xscreensaver-settings, xscreensaver(6)

NAME

xscreensaver-settings, xscreensaver — Configure the XScreenSaver module.

SYNOPSIS

xscreensaver-settings [ -display host:display.screen ] [ -choices ] [ -gl ] [ -no-gl ] [ -no-splash ] [ -no-verbose ] [ -prefs ] [ -no-prefs ] [ -root ] [ -no-root ] [ -a ] [ -no-a ] [ -d ] [ -no-d ] [ -i ] [ -no-i ] [ -s ] [ -no-s ] [ -w ] [ -no-w ] [ -v ] [ -no-v ] [ -p ] [ -no-p ] [ -f ] [ -no-f ] [ -r ] [ -no-r ] [ -x ] [ -no-x ] [ -backdrop ] [ -no-backdrop ] [ -lock ] [ -no-lock ] [ -embed window ] [ -watch pid ] [ -visual name ] [ -depth n ] [ -gamma g ] [ -delay n ] [ -timeout n ] [ -cycle n ] [ -fps ] [ -no-fps ] [ -text string ] [ -geom geometry ] [ -icon geom geometry ] [ -mod name ] [ -moddir path ] [ -no-moddir ] [ -just-dpms ] [ -capture-screens ] [ -no-capture-screens ] [ -inactivity seconds ] [ -locktime seconds ] [ -standby seconds ] [ -suspend seconds ] [ -off seconds ] [ -dpms-on ] [ -dpms-off ] [ -dpms-cycle seconds ] [ -setup ] [ -h ] [ -- args ... ]

DESCRIPTION

The xscreensaver program is a system for managing screen blanking and locking. It consists of a daemon, xscreensaver, and a settings program, xscreensaver-settings. The daemon runs in the background, monitoring mouse and keyboard activity. When the screen has been idle for a certain amount of time (the timeout parameter), the daemon blanks the screen and runs a screensaver module. If the screen is locked, the user will be prompted for a password before the screen saver can be dismissed.

The xscreensaver-settings program allows the user to configure the behavior of the xscreensaver daemon. It provides tabs for controlling:

  • Screen saver selection and configuration
  • DPMS (Display Power Management Signaling) settings
  • Lock screen behavior
  • Advanced settings

MENU COMMANDS

Right-clicking on the root window background when xscreensaver is running will bring up a menu. This menu allows you to:

  • Change the current screen saver
  • Select from a list of available screen savers
  • Run the xscreensaver-settings program
  • Disable/Enable the screen saver
  • Lock the screen
  • Exit the xscreensaver daemon

DISPLAY MODES TAB

This tab allows you to select which screen saver will be used, and to configure its specific settings. You can also set the delay before the screen saver activates, and the amount of time between screen saver changes.

SETTINGS DIALOG

The main settings dialog allows you to control the overall behavior of xscreensaver, including:

  • Blank After: The amount of time (in minutes) of inactivity before the screen blanks.
  • Cycle After: The amount of time (in minutes) between screen saver changes.
  • Chosen Timeout: Enable this to use the "Blank After" setting for the timeout.
  • Chosen Cycle: Enable this to use the "Cycle After" setting for the cycle time.
  • Lock Screen After: Enable this to activate the screen locker when the screen saver activates.
  • Show Clock: Display a clock on the screen saver window.
  • Show Greetings: Display a "Welcome" message with your username.
  • Demo Mode: Enable this to cycle through all available screen savers without changing the default.

ADVANCED TAB

This tab provides access to more advanced settings, including:

  • CapturegetRootWindow: Captures the root window content for the screen saver.
  • Use the GL screen savers: Enables the use of OpenGL-based screen savers.
  • Show all screen savers: Shows all available screen savers, including those that might not be compatible with your system.
  • Run password command: Specify a custom command for password entry.
  • Login window command: Specify a custom command for the login window.
  • Exit editor command: Specify a custom command for exiting the editor.
  • Program name for display: Set the program name displayed in the taskbar.
  • Program name for splash: Set the program name displayed in the splash screen.
  • Modularity directory: Specify a directory for custom screen saver modules.
  • Verbose: Enable verbose logging.
  • Sleeptime: The amount of time (in seconds) before DPMS enters standby mode.
  • Suspendtime: The amount of time (in seconds) before DPMS enters suspend mode.
  • Offtime: The amount of time (in seconds) before DPMS turns off the display.

COMMAND-LINE OPTIONS

The following command-line options are available for xscreensaver-settings:

  • -display host:display.screen: Specifies the X display to connect to.
  • -choices: Show only the list of available screen savers.
  • -gl: Force the use of GL screen savers.
  • -no-gl: Disable the use of GL screen savers.
  • -no-splash: Do not show the splash screen.
  • -no-verbose: Disable verbose logging.
  • -prefs: Show the Preferences dialog.
  • -no-prefs: Do not show the Preferences dialog.
  • -root: Make the screen saver run directly on the root window.
  • -no-root: Do not make the screen saver run directly on the root window.
  • -a: Enable screen locking.
  • -no-a: Disable screen locking.
  • -d: Enable screen blanking.
  • -no-d: Disable screen blanking.
  • -i: Enable DPMS.
  • -no-i: Disable DPMS.
  • -s: Enable screen saver activation.
  • -no-s: Disable screen saver activation.
  • -w: Watch for the exit of a process.
  • -no-w: Do not watch for the exit of a process.
  • -v: Enable verbose logging.
  • -no-v: Disable verbose logging.
  • -p: Show the password dialog.
  • -no-p: Do not show the password dialog.
  • -f: Enable fast screen saver switching.
  • -no-f: Disable fast screen saver switching.
  • -r: Enable root window replacement.
  • -no-r: Disable root window replacement.
  • -x: Enable X screen saver extension.
  • -no-x: Disable X screen saver extension.
  • -backdrop: Use a backdrop image.
  • -no-backdrop: Do not use a backdrop image.
  • -lock: Lock the screen.
  • -no-lock: Do not lock the screen.
  • -embed window: Embed the screen saver in the specified window.
  • -watch pid: Watch for the specified process ID to exit.
  • -visual name: Specify the visual to use.
  • -depth n: Specify the color depth.
  • -gamma g: Specify the gamma correction.
  • -delay n: Set the delay before the screen saver starts (in milliseconds).
  • -timeout n: Set the timeout before the screen saver starts (in seconds).
  • -cycle n: Set the cycle time between screen savers (in seconds).
  • -fps: Show the frames per second.
  • -no-fps: Do not show the frames per second.
  • -text string: Display the specified text.
  • -geom geometry: Set the window geometry.
  • -icon geom geometry: Set the icon geometry.
  • -mod name: Load the specified module.
  • -moddir path: Specify the directory for modules.
  • -no-moddir: Do not use the module directory.
  • -just-dpms: Only configure DPMS settings.
  • -capture-screens: Capture all screens.
  • -no-capture-screens: Do not capture all screens.
  • -inactivity seconds: Set the inactivity timeout in seconds.
  • -locktime seconds: Set the lock timeout in seconds.
  • -standby seconds: Set the DPMS standby timeout in seconds.
  • -suspend seconds: Set the DPMS suspend timeout in seconds.
  • -off seconds: Set the DPMS off timeout in seconds.
  • -dpms-on: Enable DPMS.
  • -dpms-off: Disable DPMS.
  • -dpms-cycle seconds: Set the DPMS cycle time in seconds.
  • -setup: Show the setup dialog.
  • -h: Show help message.
  • -- args ...: Pass arguments to the screen saver module.

ENVIRONMENT

The following environment variables affect xscreensaver:

  • DISPLAY: The X display to use.
  • XSCREENSAVER_PATH: The path to the xscreensaver executable.
  • XSCREENSAVER_MODULEDIR: The directory containing screen saver modules.

UPGRADES

If you are upgrading from a previous version of xscreensaver, you may need to delete your old configuration file, ~/.xscreensaver, to ensure that the new settings are applied correctly.
