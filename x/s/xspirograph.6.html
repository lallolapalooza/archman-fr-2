NOM

xspirograph - simule la rotation d'un disque à l'intérieur d'un anneau circulaire

SYNOPSIS

xspirograph [--display hôte:écran.numéro] [--window] [--root] [--window-id numéro][--install] [--visual visuel] [--delay secondes] [--subdelay microsecondes] [--layers entier] [--alwaysfinish] [--noalwaysfinish] [--fps]

DESCRIPTION

xspirograph dessine des motifs tels que ceux réalisés par un spirographe, c'est-à-dire la courbe tracée par un point sur un disque circulaire en rotation à l'intérieur d'un anneau circulaire creux.

OPTIONS

xspirograph accepte les options suivantes :

--window
Dessiner dans une nouvelle fenêtre créée. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--install
Installer une palette de couleurs privée pour la fenêtre.
--visual visuel
Spécifier quel visuel utiliser. Les valeurs légales sont le nom d'une classe visuelle, ou le numéro (décimal ou hexadécimal) d'un visuel spécifique.
--delay sec
Le délai entre la fin d'un dessin et le début du suivant. Par défaut : 5 secondes.
--subdelay microsec
Le temps de délai entre chaque centaine de tracés de lignes. Utilisez cette option si vous voulez voir le motif se former. Par défaut : 0.
--alwaysfinish --noalwaysfinish
Si vous voulez que chaque motif soit dessiné jusqu'à sa complétion, spécifiez le premier. Sinon, ils s'arrêteront après un nombre défini d'itérations. Par défaut : non.
--layers entier
Nombre de paires de motifs à dessiner entre chaque effacement.

ENVIRONNEMENT

DISPLAY
pour obtenir le nom d'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui surcharge les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de fenêtre à utiliser avec --root.
