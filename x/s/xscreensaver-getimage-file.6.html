NOM

xscreensaver-getimage-file - sélectionne un fichier image aléatoire pour l'utilisation par les économiseurs d'écran

SYNTAXE

xscreensaver-getimage-file [--verbose] [--no-cache] [--flush-caches] répertoire-ou-URL

DESCRIPTION

Le programme xscreensaver-getimage-file est un programme d'aide pour les hacks de xscreensaver qui manipulent des images. Il est invoqué par xscreensaver-getimage(6) si nécessaire.

Il imprime le nom d'un fichier image sélectionné aléatoirement. Le répertoire est recherché récursivement. Les fichiers non-image et les images plus petites que 500x500 sont exclus.

Le répertoire peut également être l'URL d'un flux RSS/Atom. Les images incluses seront téléchargées et mises en cache localement.

Le contenu du répertoire est mis en cache pour des raisons de performance. Le cache est régénéré si 3 heures se sont écoulées.

OPTIONS

xscreensaver-getimage-file accepte les options suivantes :

--verbose
Imprime les diagnostics.
--no-cache
Ignore le cache lors de la recherche d'images. Cela peut être lent.
--flush-cache
Supprime immédiatement tous les caches. Ils seront régénérés au besoin.
répertoire-ou-URL
S'il s'agit d'un chemin d'accès, il sera recherché récursivement pour des images.

S'il s'agit d'une URL, ce doit être un flux RSS ou Atom, ou une page HTML dont les métadonnées renvoient à son flux. Toutes les images du flux seront téléchargées dans un cache local. L'URL sera régulièrement interrogée, téléchargeant les nouvelles images et supprimant celles qui ont expiré.

FICHIERS

Selon votre système d'exploitation, le cache des noms de fichiers sera l'un des suivants :

        $HOME/.cache/xscreensaver/xscreensaver-getimage.cache
        $HOME/tmp/.xscreensaver-getimage.cache
        $HOME/.xscreensaver-getimage.cache
        $HOME/Library/Caches/org.jwz.xscreensaver.getimage.cache

Les images des flux seront téléchargées et mises en cache à l'un des emplacements suivants :

        $HOME/.cache/xscreensaver/SOUS-RÉPERTOIRE/
        $HOME/tmp/.xscreensaver-feeds/SOUS-RÉPERTOIRE/
        $HOME/.xscreensaver-feeds/SOUS-RÉPERTOIRE/
        $HOME/Library/Caches/org.jwz.xscreensaver.feeds/SOUS-RÉPERTOIRE/
