NAME

xscreensaver-gl-visual - déterminer le visuel X à utiliser pour les programmes GL

SYNOPSIS

xscreensaver-gl-visual [--display hôte:écran.sous-écran]

DESCRIPTION

Ce programme affiche l'ID du visuel qui doit être utilisé pour le bon fonctionnement des programmes OpenGL. Ce programme existe uniquement pour que le démon xscreensaver(1) n'ait pas besoin de se lier à la bibliothèque OpenGL.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte, l'écran et le numéro de sous-écran par défaut.

VOIR AUSSI

X(1), xdpyinfo(1), xglinfo(1), glxinfo(1), glxdpyinfo(1), xscreensaver(1), xscreensaver-settings(1), xscreensaver-command(1)
