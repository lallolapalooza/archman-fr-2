XSENSORS(1) Commandes utilisateur XSENSORS(1)

NOM

xsensors - affiche les informations des capteurs matériels sous forme graphique.

SYNTAXE

xsensors [OPTION]...

DESCRIPTION

Visualise la sortie de la bibliothèque libsensors concernant l'état du matériel dans un affichage graphique.

OPTIONS

-f
affiche toutes les températures en Fahrenheit.
-c nom_fichier
spécifie le fichier de configuration de libsensors.
-i
spécifie le fichier image à utiliser comme thème graphique.
-t temps
spécifie l'intervalle de mise à jour en secondes.
-v
affiche le numéro de version.

CONFIGURATION

Pour trouver les modules du noyau nécessaires au bon fonctionnement de xsensors, veuillez exécuter la commande sensors-detect en tant que superutilisateur et suivre les instructions à l'écran ; un redémarrage peut être nécessaire. La commande sensors-detect est fournie par le paquet lm-sensors.

FICHIERS

/usr/share/xsensors/theme.tiff : le thème graphique par défaut.

/etc/sensors3.conf : le fichier de configuration par défaut.
