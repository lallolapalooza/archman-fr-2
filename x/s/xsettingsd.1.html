NOM

xsettingsd - fournit des paramètres aux applications X11

SYNOPSIS

xsettingsd [options]

DESCRIPTION

xsettingsd est un démon qui implémente la spécification XSETTINGS. L'invocation typique se fait depuis le fichier ~/.xsession de l'utilisateur.

Il est conçu pour être petit, rapide et avec un minimum de dépendances sur d'autres bibliothèques. Il peut servir d'alternative à gnome-settings-daemon pour les utilisateurs qui n'utilisent pas l'environnement de bureau GNOME mais qui exécutent des applications GTK+ et souhaitent configurer des éléments tels que les thèmes, l'anti-crénelage/l'anti-aliasing des polices et les effets sonores de l'interface utilisateur.

Une documentation supplémentaire est disponible sur le site web du projet : https://github.com/derat/xsettingsd

OPTIONS

-c, --config=FICHIER
Charge les paramètres depuis FICHIER (par défaut ~/.xsettingsd).
-h, --help
Affiche un message d'aide et quitte.
-s, --screen=ECRAN
Utilise l'écran X numéroté ECRAN (la valeur par défaut de -1 signifie tous les écrans).

BOGUES

https://github.com/derat/xsettingsd/issues

EXEMPLE

L'exécution de dump_xsettings(1) lorsqu'un autre démon XSETTINGS, tel que gnome-settings-daemon, est déjà en cours d'exécution, affichera vos paramètres actuels dans le format de fichier de configuration de xsettingsd.

Voici un court exemple de fichier ~/.xsettingsd :

Net/ThemeName "Human"
Xft/Antialias 1
Xft/DPI 100352
Xft/HintStyle "hintfull"
Xft/Hinting 1
Xft/RGBA "none"
Xft/lcdfilter "none"
