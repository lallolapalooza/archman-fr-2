PERLAMIGA(1perl) Guide de référence des programmeurs Perl PERLAMIGA(1perl)

NOM

perlamiga - Perl sous AmigaOS 4.1

NOTE

Ceci est un port de Perl 5.22.1, c'est un port récent et il n'est en aucun cas compatible avec mes ports précédents de Perl 5.8 et 5.16.3. Cela signifie que vous devrez réinstaller / reconstruire tous les modules tiers que vous avez installés.

newlib.library version 53.28 ou supérieure est requis.

SYNTAXE

Une fois perl installé, vous pouvez lire ce document de la manière suivante

sh -c "perldoc perlamiga"

ou vous pouvez le lire *tel quel* : soit comme README.amiga, soit comme pod/perlamiga.pod.

DESCRIPTION

Prérequis pour l'exécution de Perl 5.22.1 sous AmigaOS 4.1

AmigaOS 4.1 update 6 avec toutes les mises à jour appliquées au 9 octobre 2013
La plus importante d'entre elles est :
newlib.library version 53.28 ou supérieure
SDK AmigaOS
Perl s'installe dans la structure de répertoires du SDK et s'attend à ce que de nombreux outils de compilation présents dans le SDK soient disponibles. Donc, pour de meilleurs résultats, installez le SDK en premier.
abc-shell
Si vous n'avez pas le SDK installé, vous devez au moins avoir abc-shell installé ou un autre port sh approprié. Ceci est requis pour exécuter des commandes externes et doit être disponible sous le nom 'sh' dans votre path.

Lancement des programmes Perl sous AmigaOS 4.1

Perl peut être exécuté depuis le shell AmigaOS mais pour de meilleurs résultats, il devrait être exécuté sous abc-shell. (abc-shell gère le globbing de fichiers, l'expansion de motifs, et configure les variables d'environnement de manière UN*Xy comme Perl s'y attend.)

Par exemple :

New Shell process 10
10.AmigaOS4:> sh
/AmigaOS4>perl chemin:vers/monprog arg1 arrg2 arg3

Abc-shell peut également lancer des programmes via la syntaxe #! au début du fichier programme, il est préférable d'utiliser la forme #!SDK:Local/C/perl afin que le shell AmigaOS puisse également trouver perl de la même manière. AmigaOS nécessite que le bit d'exécution du script soit défini pour que cela fonctionne.

10.AmigaOS4:> sh
/AmigaOS4>monprog arg1 arrg2 arg3

Limitations de Perl sous AmigaOS 4.1

Les programmes pipés imbriqués peuvent planter lorsqu'ils sont exécutés à partir d'anciens abc-shells
La version 53.2 d'abc-shell a un bug qui peut causer des plantages dans les sous-processus utilisés pour exécuter des programmes pipés, si une version ultérieure est disponible, vous devriez l'installer à la place.
Déséchappement de ligne de commande incorrect ou inattendu
newlib.library 53.30 et versions antérieures déséchappent incorrectement les séquences d'échappement avec barre oblique inverse, par exemple \" \n \t etc., nécessitant un échappement supplémentaire inhabituel.
Le lancement de sous-processus via open a des limitations
open FH, "commande |"

Les sous-processus démarrés avec open utilisent une routine popen() minimale et par conséquent, ils ne renvoient pas de pids utilisables avec waitpid etc.

Si vous trouvez d'autres limitations ou bugs, faites-le moi savoir.
Veuillez signaler les bugs dans cette version de perl à andy@broad.ology.org.uk en premier lieu.

INSTALLATION

Ce guide suppose que vous avez obtenu une archive précompilée depuis os4depot.net.

Décompressez l'archive principale dans un emplacement temporaire (RAM: convient).

Exécutez le script d'installation fourni depuis le shell ou via son icône.

Vous **ne devez pas** tenter d'installer manuellement.

Une fois installé, vous pouvez supprimer l'archive temporaire.

Cette approche préservera les liens dans l'installation sans créer de binaires dupliqués.

Si vous avez les versions antérieures de perl 5.16 ou 5.8 installées, vous pourriez vouloir renommer votre exécutable perl en perl516 ou perl58 ou quelque chose de similaire avant l'installation de 5.22.1, cela vous permettra d'utiliser les deux versions en même temps.

Modules spécifiques à Amiga

Amiga::ARexx

Le module Amiga::ARexx vous permet de créer facilement un hôte ARexx basé sur perl ou d'envoyer des commandes ARexx à d'autres programmes.

Essayez "perldoc Amiga::ARexx" pour plus d'informations.

Amiga::Exec

Le module Amiga::Exec introduit le support de Wait().

Essayez "perldoc Amiga::Exec" pour plus d'informations.

COMPILATION

Pour compiler perl sous AmigaOS à partir des sources patchées, vous devrez disposer d'une version récente du SDK. La version 53.29 est recommandée, les versions antérieures fonctionneront probablement aussi.

Avec l'aide de Jarkko Hietaniemi, le système Configure a été modifié pour fonctionner sous abc-shell, le processus de compilation recommandé est donc le suivant.

stack 2000000
sh Configure -de
gmake

Cela compilera la configuration par défaut qui s'installe sous SDK:local/newlib/lib/

CHANGEMENTS

Août 2015
Port vers Perl 5.22
Ajout de la gestion de NIL: à afstat()
Correction de l'héritage des variables d'environnement par les sous-processus.
Correction de exec, et exit dans les sous-processus "forkés".
Correction d'un problème avec unlink de newlib, qui pouvait causer des boucles infinies.
Ajout de l'émulation de flock() utilisant IDOS->LockRecord grâce à la suggestion de Tony Cook.
Correction d'un problème où kill utilisait le mauvais type d'identifiant de processus
27 novembre 2013
Création d'un nouveau système d'installation basé sur des liens installperl et les bits de protection Amiga maintenant correctement définis.
Pod utilise maintenant texte par défaut.
File::Spec devrait maintenant reconnaître un chemin absolu de style Amiga ainsi qu'un style Unix. Les chemins relatifs doivent toujours être de style Unix.
20 novembre 2013
Configuré pour utiliser SDK:Local/C/perl pour démarrer les scripts standard
Ajout du module Amiga::Exec avec support pour Wait() et les numéros de signal AmigaOS.
10 octobre 13
Première version du port vers 5.16.3.

NAME

perlamiga - Un langage de script interprété et portable.

NOTE

Ceci n'est pas la documentation officielle de Perl. Elle a été générée à partir des pages de manuel du paquet perl et ne fait que les résumer.

SYNOPSIS

perl [options] [-c] [-Mmodule...] [-m[+-]module...] [programfile] [argument...]
perl [options] -e program [argument...]
perl [options] -e 'program' [argument...]
perl [options] [-Mmodule...] [-m[+-]module...] -n [-e] program [argument...]
perl [options] [-Mmodule...] [-m[+-]module...] -p [-e] program [argument...]
perl [options] [-Mmodule...] [-m[+-]module...] -s [-e] program [argument...]
perl [options] [-Mmodule...] [-m[+-]module...] -x [-c] [-b] programfile [argument...]

DESCRIPTION

Perl est un langage de programmation de haut niveau, généraliste, interprété et dynamique. Il est souvent décrit comme un "langage de script" et est utilisé pour une grande variété de tâches, y compris l'administration système, le développement web, le traitement de texte, la gestion de bases de données, le développement de jeux et l'automatisation.

Les caractéristiques notables de Perl incluent :

  • Puissance et flexibilité : Perl offre un large éventail de fonctionnalités pour manipuler des chaînes de caractères, des expressions régulières et des structures de données complexes.
  • Portabilité : Perl est disponible sur de nombreuses plateformes et systèmes d'exploitation, ce qui le rend adapté au développement d'applications multiplateformes.
  • Large communauté et écosystème : Il existe une vaste communauté d'utilisateurs et une riche collection de modules (appelés CPAN - Comprehensive Perl Archive Network) qui étendent les capacités de Perl.

INSTALLATION

Pour installer Perl sur Arch Linux, vous pouvez utiliser le gestionnaire de paquets Pacman :

sudo pacman -S perl

Amiga Specific Modules

Il existe des modules spécifiques pour l'environnement Amiga. Ceux-ci peuvent être trouvés dans la distribution du paquet Perl et sont utilisés pour interagir avec le système d'exploitation Amiga, ses bibliothèques et ses API.

BUILDING

La construction de Perl à partir des sources est généralement une tâche pour les développeurs ou les administrateurs système avancés. Les instructions de compilation peuvent être trouvées dans la documentation source de Perl ou dans les scripts de construction du paquet Arch Linux.

Pour une utilisation générale, il est fortement recommandé d'installer Perl via Pacman, car cela garantit que le logiciel est correctement configuré pour votre système Arch Linux.

CHANGES

Les modifications apportées à Perl sont suivies dans les notes de version officielles de Perl et dans l'historique du paquet Arch Linux. Vous pouvez trouver l'historique des paquets sur le site web d'Arch Linux.
