NOM

perltex - active la définition des macros LaTeX par du code Perl

SYNTAXE

perltex [--help] [--latex=programme] [--[no]safe] [--permit=fonctionnalité] [--makesty] [options latex]

DESCRIPTION

LaTeX -- via le système de composition TeX sous-jacent -- produit des documents magnifiquement composés mais dispose d'un langage de macro difficile à programmer. En particulier, le support pour la manipulation complexe de chaînes est largement absent. Perl est un langage de programmation généraliste populaire dont la spécialité est la manipulation de chaînes. Cependant, il n'a aucune capacité de composition.

Clairement, la programmabilité de Perl pourrait compléter les forces de composition de LaTeX. perltex est l'outil qui permet une symbiose entre les deux systèmes. Tout ce qu'un utilisateur doit faire est de compiler un document LaTeX en utilisant perltex au lieu de latex. (perltex est en fait un wrapper pour latex, donc aucune fonctionnalité de latex n'est perdue.) Si le document inclut un "\usepackage{perltex}" dans son préambule, alors les macros "\perlnewcommand" et "\perlrenewcommand" seront disponibles. Celles-ci se comportent juste comme les "\newcommand" et "\renewcommand" de LaTeX, sauf que le corps de la macro contient du code Perl au lieu du code LaTeX.

OPTIONS

perltex accepte les options de ligne de commande suivantes :

--help
Affiche les informations d'utilisation de base.
--latex=programme
Spécifie un programme à utiliser à la place de latex. Par exemple, "--latex=pdflatex" composerait le document donné en utilisant pdflatex au lieu de latex ordinaire.
--[no]safe
Active ou désactive l'environnement sécurisé (sandbox). Avec la valeur par défaut --safe, perltex exécute le code d'une macro "\perlnewcommand" ou "\perlrenewcommand" dans un environnement protégé qui interdit les opérations « dangereuses » telles que l'accès aux fichiers ou l'exécution de programmes externes. Spécifier --nosafe donne au document LaTeX carte blanche pour exécuter tout code Perl arbitraire, y compris celui qui peut endommager les fichiers de l'utilisateur. Voir Safe pour plus d'informations.
--permit=fonctionnalité
Permet l'exécution de certaines opérations Perl. L'option --permit, qui peut être spécifiée plusieurs fois sur la ligne de commande, permet un contrôle plus fin du sandbox de perltex. Voir Opcode pour plus d'informations.
--makesty
Génère un fichier de style LaTeX appelé noperltex.sty. Remplacer la ligne "\usepackage{perltex}" du document par "\usepackage{noperltex}" produit le même résultat mais ne nécessite pas PerlTeX, rendant le document adapté à la distribution aux personnes qui n'ont pas PerlTeX installé. Le désavantage est que noperltex.sty est spécifique au document qui l'a produit. Tout changement dans les définitions de macros PerlTeX ou les invocations de macros du document nécessite de réexécuter perltex avec l'option --makesty.

Ces options sont ensuite suivies par les options normalement passées à latex (ou au programme spécifié avec "--latex"), y compris, par exemple, le nom du fichier .tex à compiler.

EXEMPLES

Dans sa forme la plus simple, perltex s'exécute comme latex :

perltex myfile.tex

Pour utiliser pdflatex à la place de latex ordinaire, utilisez l'option --latex :

perltex --latex=pdflatex myfile.tex

Si LaTeX donne une erreur « "trapped by operation mask" » et que vous faites confiance au fichier .tex que vous essayez de compiler pour ne pas exécuter de code Perl malveillant (par exemple, parce que vous l'avez écrit vous-même), vous pouvez désactiver les mécanismes de sécurité de perltex avec --nosafe :

perltex --nosafe myfile.tex

La commande suivante donne aux documents uniquement les permissions par défaut de perltex (":browse") plus la capacité d'ouvrir des fichiers et d'invoquer la commande "time" :

perltex --permit=:browse --permit=:filesys_open
  --permit=time myfile.tex

ENVIRONNEMENT

perltex prend en compte les variables d'environnement suivantes :

PERLTEX
Spécifie le nom du fichier du compilateur LaTeX. Le compilateur LaTeX est par défaut « "latex" ». La variable d'environnement "PERLTEX" remplace cette valeur par défaut, et l'option de ligne de commande --latex (voir "OPTIONS") la supplante.

FICHIERS

Lors de la compilation de jobname.tex, perltex utilise les fichiers suivants :

jobname.lgpl
fichier journal écrit par Perl ; utile pour le débogage des macros Perl
jobname.topl
informations envoyées de LaTeX à Perl
jobname.frpl
informations envoyées de Perl à LaTeX
jobname.tfpl
fichier « drapeau » dont l'existence indique que jobname.topl contient des données valides
jobname.ffpl
fichier « drapeau » dont l'existence indique que jobname.frpl contient des données valides
jobname.dfpl
fichier « drapeau » dont l'existence indique que jobname.ffpl a été supprimé
noperltex-#.tex
fichier généré par noperltex.sty pour chaque invocation de macro PerlTeX

NOTES

Le sandbox de perltex utilise par défaut ce qu'Opcode appelle « ":browse" ».

    NOM

    perltex - Développeur de programmes Perl pour LaTeX

    DESCRIPTION

    Le programme perltex est un utilitaire pour le développement de programmes Perl qui génèrent du code LaTeX. Il agit comme un préprocesseur, permettant aux utilisateurs d'écrire du code Perl dans des fichiers .tex et de le compiler en fichiers .tex normaux. Cela facilite l'intégration de la puissance de Perl dans la création de documents complexes avec LaTeX.

    OPTIONS

    -o fichier_sortie
    Spécifie le nom du fichier de sortie. Si cette option n'est pas spécifiée, la sortie sera envoyée à la sortie standard.
    -I chemin
    Ajoute un répertoire au chemin de recherche des modules Perl.
    -M module
    Charge un module Perl avant l'exécution du script.
    -v
    Affiche des informations de version et quitte.
    -h
    Affiche un message d'aide et quitte.

    EXEMPLES

    perltex mon_document.tex -o sortie.tex

    Compile le fichier mon_document.tex et enregistre le résultat dans sortie.tex.

    perltex <<EOF > document.tex
print "\\documentclass{article}\n";
print "\\begin{document}\n";
print "Bonjour, monde de LaTeX et Perl !\n";
print "\\end{document}\n";
EOF

    Génère un document LaTeX simple en utilisant une here-document Perl.

    ENVIRONNEMENT

    Aucune variable d'environnement spécifique n'est requise pour le fonctionnement de base de perltex.

    FICHIERS

    Aucun fichier système spécifique n'est utilisé par perltex en dehors des fichiers d'entrée et de sortie spécifiés par l'utilisateur.

    NOTES

    Ce programme est une interface pratique pour exécuter du code Perl au sein de fichiers LaTeX. Assurez-vous que Perl est installé sur votre système.

    VOIR AUSSI

    perl(1), latex(1)
