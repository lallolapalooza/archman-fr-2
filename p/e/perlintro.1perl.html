PERLINTRO(1perl) Guide du programmeur Perl PERLINTRO(1perl)

NOM

perlintro - une brève introduction et présentation de Perl

DESCRIPTION

Ce document est destiné à vous donner un aperçu rapide du langage de programmation Perl, ainsi que des pistes pour approfondir la documentation. Il est conçu comme un guide de "démarrage" pour ceux qui sont nouveaux dans ce langage, et fournit juste assez d'informations pour que vous puissiez lire le code Perl d'autres personnes et comprendre grossièrement ce qu'il fait, ou écrire vos propres scripts simples.

Ce document d'introduction ne vise pas à être complet. Il ne vise même pas à être entièrement exact. Dans certains cas, la perfection a été sacrifiée dans le but de transmettre l'idée générale. Il est *fortement* conseillé de compléter cette introduction avec des informations plus complètes provenant du manuel Perl complet, dont la table des matières se trouve dans perltoc.

Tout au long de ce document, vous verrez des références à d'autres parties de la documentation Perl. Vous pouvez lire cette documentation en utilisant la commande "perldoc" ou la méthode que vous utilisez pour lire ce document.

Dans toute la documentation Perl, vous trouverez de nombreux exemples destinés à aider à expliquer les fonctionnalités discutées. Veuillez garder à l'esprit que beaucoup d'entre eux sont des fragments de code plutôt que des programmes complets.

Ces exemples reflètent souvent le style et les préférences de l'auteur de cette partie de la documentation, et peuvent être plus concis qu'une ligne de code correspondante dans un programme réel. Sauf indication contraire, vous devez supposer que les instructions "use strict" et "use warnings" apparaissent plus tôt dans le "programme", et que toutes les variables utilisées ont déjà été déclarées, même si ces déclarations ont été omises pour faciliter la lecture de l'exemple.

Notez que les exemples ont été écrits par de nombreux auteurs différents sur plusieurs décennies. Les styles et les techniques varieront donc, bien que des efforts aient été faits pour ne pas trop faire varier les styles au sein des mêmes sections. Ne considérez pas un style comme meilleur qu'un autre — "Il y a plus d'une façon de faire" est l'une des devise de Perl. Après tout, dans votre parcours de programmeur, vous rencontrerez probablement différents styles.

Qu'est-ce que Perl ?

Perl est un langage de programmation généraliste initialement développé pour la manipulation de texte et maintenant utilisé pour une large gamme de tâches, y compris l'administration système, le développement web, la programmation réseau, le développement d'interfaces graphiques, et plus encore.

Le langage est conçu pour être pratique (facile à utiliser, efficace, complet) plutôt que beau (minuscule, élégant, minimaliste). Ses principales caractéristiques sont sa facilité d'utilisation, son support de la programmation procédurale et orientée objet (OO), son puissant support intégré pour le traitement de texte, et sa collection impressionnante de modules tiers.

Différentes définitions de Perl sont données dans perl, perlfaq1 et sans doute d'autres endroits. De cela, nous pouvons déterminer que Perl est différentes choses pour différentes personnes, mais que beaucoup de gens pensent qu'il vaut au moins la peine d'en parler.

Exécution des programmes Perl

Pour exécuter un programme Perl depuis la ligne de commande Unix :

perl progname.pl

Alternativement, placez ceci comme première ligne de votre script :

#!/usr/bin/env perl

... et exécutez le script comme /chemin/vers/script.pl. Bien sûr, il devra d'abord être exécutable, donc "chmod 755 script.pl" (sous Unix).

(Cette ligne de début suppose que vous avez le programme env. Vous pouvez aussi directement placer le chemin vers votre exécutable perl, comme dans "#!/usr/bin/perl").

Pour plus d'informations, y compris des instructions pour d'autres plateformes comme Windows, lisez perlrun.

Filet de sécurité

Perl est par défaut très tolérant. Afin de le rendre plus robuste, il est recommandé de commencer chaque programme avec les lignes suivantes :

#!/usr/bin/perl
use strict;
use warnings;

Les deux lignes supplémentaires demandent à Perl de détecter divers problèmes courants dans votre code. Elles vérifient différentes choses, vous avez donc besoin des deux. Un problème potentiel détecté par "use strict;" entraînera l'arrêt immédiat de votre code lorsqu'il sera rencontré, tandis que "use warnings;" produira simplement un avertissement (comme le commutateur de ligne de commande -w) et laissera votre code s'exécuter. Pour en savoir plus à leur sujet, consultez leurs pages de manuel respectives : strict et warnings.

Une déclaration "use v5.35" (ou supérieure) activera à la fois "strict" et "warnings" :

#!/usr/bin/perl
use v5.35;

En plus d'activer les pragmas "strict" et "warnings", cette déclaration activera également un "bundle de fonctionnalités" ; une collection de fonctionnalités nommées qui activent bon nombre des ajouts et modifications les plus récents du langage, tout en supprimant occasionnellement d'anciennes fonctionnalités jugées être des erreurs de conception et déconseillées.

Aperçu de la syntaxe de base

Un script ou un programme Perl consiste en une ou plusieurs instructions. Ces instructions sont simplement écrites dans le script de manière directe. Il n'est pas nécessaire d'avoir une fonction main() ou quelque chose de similaire.

Les instructions Perl se terminent par un point-virgule :

print "Hello, world";

Les commentaires commencent par un symbole dièse et vont jusqu'à la fin de la ligne

# Ceci est un commentaire

Les espaces blancs sont sans importance :

print
    "Hello, world"
    ;

... sauf à l'intérieur des chaînes entre guillemets :

# ceci imprimerait avec un saut de ligne au milieu
print "Hello
world";

Des guillemets doubles ou simples peuvent être utilisés autour des chaînes littérales :

print "Hello, world";
print 'Hello, world';

Cependant, seuls les guillemets doubles "interpolent" les variables et les caractères spéciaux comme les sauts de ligne ("\n") :

print "Hello, $name\n";     # fonctionne bien
print 'Hello, $name\n';     # imprime $name\n littéralement

Les nombres n'ont pas besoin d'être entre guillemets :

print 42;

Vous pouvez utiliser des parenthèses pour les arguments des fonctions ou les omettre selon vos goûts personnels. Elles ne sont requises qu'occasionnellement pour clarifier les problèmes de précédence.

print("Hello, world\n");
print "Hello, world\n";

Des informations plus détaillées sur la syntaxe Perl se trouvent dans perlsyn.

Types de variables Perl

Vous avez peut-être remarqué la chaîne de caractères étrange <$name> ci-dessus. Cela désigne une variable, qui est généralement prononcée "name". Le signe dollar est appelé un "sigil", et indique que "name" est une variable. Contrairement à de nombreux autres langages informatiques où les variables sont simplement des chaînes de caractères typiquement composées uniquement de lettres et de chiffres, toutes les variables Perl sont précédées d'un sigil.

Perl a trois types principaux de variables : les scalaires, les tableaux et les hachages. Le sigil particulier utilisé pour un nom de variable indique le type de cette variable. Nous avons déjà vu le signe dollar utilisé comme sigil, $name. Le signe dollar indique que cette variable est un scalaire.

Scalaires
Un scalaire représente une seule valeur : 
my $animal = "camel";
my $answer = 42;

Les valeurs scalaires peuvent être des chaînes de caractères, des entiers ou des nombres à virgule flottante, et Perl les convertira automatiquement entre eux si nécessaire. Vous devez les déclarer en utilisant le mot-clé "my" la première fois que vous les utilisez. (C'est l'une des exigences de "use strict;".)

Les valeurs scalaires peuvent être utilisées de différentes manières :

print $animal;
print "L'animal est $animal\n";
print "Le carré de $answer est ", $answer * $answer, "\n";

Perl définit un certain nombre de scalaires spéciaux avec des noms courts, souvent des signes de ponctuation uniques ou des chiffres. Ces variables sont utilisées à toutes sortes de fins et sont documentées dans perlvar. T

le seul dont vous ayez besoin de connaître pour l'instant est $_, qui est la "variable par défaut". Elle est utilisée comme argument par défaut pour un certain nombre de fonctions en Perl, et elle est définie implicitement par certaines constructions de boucles.

print;          # affiche le contenu de $_ par défaut
Tableaux
Un tableau représente une liste de valeurs. Un "@" sigil indique qu'une variable est un tableau : 
my @animaux = ("chameau", "llama", "hibou");
my @nombres = (23, 42, 69);
my @mixtes   = ("chameau", 42, 1.23);

Chacun de ces tableaux est une agrégation de valeurs individuelles. Et chaque valeur est en fait un scalaire.

Les tableaux sont indexés à partir de zéro. Voici comment accéder aux éléments scalaires individuels d'un tableau :

print $animaux[0];              # affiche "chameau"
print $animaux[1];              # affiche "llama"

En Perl, les scalaires sont toujours référencés avec le "$" sigil. Ainsi, nous avons écrit $animaux[0] ci-dessus pour obtenir la variable scalaire 0 dans le tableau @animaux. Les crochets "[...]" indiquent qu'il s'agit d'un tableau dont nous obtenons la valeur. C'est un point de confusion majeur pour les nouveaux venus en Perl. Lorsque vous regardez une seule valeur, vous devez utiliser "$", même si cette valeur fait partie d'une agrégation plus grande.

La variable spéciale $#tableau indique l'indice du dernier élément d'un tableau :

print $mixtes[$#mixtes];       # dernier élément, affiche 1.23

Vous pourriez être tenté d'utiliser "$#tableau + 1" pour savoir combien d'éléments il y a dans un tableau. Ne vous embêtez pas. Il se trouve qu'utiliser @tableau là où Perl s'attend à trouver une valeur scalaire ("dans un contexte scalaire") vous donnera le nombre d'éléments dans le tableau :

if (@animaux < 5) { ... }

Les éléments que nous obtenons du tableau commencent par un "$" car nous obtenons une seule valeur du tableau ; vous demandez un scalaire, vous obtenez un scalaire.

Pour obtenir plusieurs valeurs d'un tableau :

@animaux[0,1];                 # donne ("chameau", "llama");
@animaux[0..2];                # donne ("chameau", "llama", "hibou");
@animaux[1..$#animaux];        # donne tous les éléments sauf le premier

Ceci est appelé une "tranche de tableau". Nous avons utilisé le "@" sigil ici car nous voulons plusieurs valeurs ; "$" est réservé à la référence des valeurs uniques.

Vous pouvez faire diverses choses utiles avec des listes :

my @tries    = sort @animaux;
my @inverses = reverse @nombres;

Il existe également quelques tableaux spéciaux, tels que @ARGV (les arguments de la ligne de commande de votre script) et @_ (les arguments passés à une sous-routine). Ceux-ci sont documentés dans perlvar.

Hachages
Un hachage représente un ensemble de paires clé/valeur. Un "%" sigil indique qu'une variable est un hachage : 
my %couleur_fruit = ("pomme", "rouge", "banane", "jaune");

Vous pouvez utiliser des espaces blancs et l'opérateur "=>" pour les présenter plus joliment :

my %couleur_fruit = (
    pomme  => "rouge",
    banane => "jaune",
    citron => "vert",
);

Pour accéder aux éléments d'un hachage :

$couleur_fruit{"pomme"};           # donne "rouge"

Notez encore l'utilisation du "$" sigil pour accéder à un seul élément d'hachage. Les accolades "{...}" indiquent qu'il s'agit d'un hachage dont nous obtenons la valeur.

Et nous pouvons obtenir plusieurs valeurs en utilisant une tranche

my @non_rouges = @couleur_fruit{"banane", "citron"};
print $non_rouges[0], "\n";    # jaune
print $non_rouges[1], "\n";    # vert

Notez encore que plusieurs valeurs utilisent le sigil "@", et les valeurs uniques utilisent "$".

Vous pouvez obtenir les listes de clés et de valeurs avec keys() et values().

my @fruits = keys %couleur_fruit;
my @couleurs = values %couleur_fruit;

Les hachages n'ont pas d'ordre interne particulier, bien que vous puissiez trier les clés et les parcourir.

Tout comme les scalaires et les tableaux spéciaux, il existe également des hachages spéciaux. Le plus connu est %ENV qui contient les variables d'environnement. Lisez tout à son sujet (et sur d'autres variables spéciales) dans perlvar.

Les scalaires, les tableaux et les hachages sont documentés plus en détail dans perldata.

Notez que $nom, @nom, et %nom sont trois variables différentes. Il peut être déroutant d'utiliser les mêmes alphanumériques pour représenter différentes variables, mais dans certaines situations, cela pourrait clarifier les choses ; l'une d'elles pourrait être d'utiliser $nom pour représenter l'élément particulier actuellement d'intérêt au sein du tableau @nom. Le choix du nom vous appartient ; l'interpréteur Perl s'en fiche. Lorsque plusieurs variables portent le même nom, l'utilisation de crochets par opposition à des accolades indique à l'interpréteur laquelle est visée.

Des types de données plus complexes peuvent être construits à l'aide de références, qui vous permettent de construire des listes et des hachages au sein de listes et de hachages.

Une référence est une valeur scalaire et peut pointer vers tout autre type de données Perl. Ainsi, en stockant une référence comme valeur d'un élément de tableau ou de hachage, vous pouvez facilement créer des listes et des hachages au sein de listes et de hachages. L'exemple suivant montre une structure de hachage de hachage à 2 niveaux à l'aide de références de hachage anonymes.

my $variables = {
    scalaire  =>  {
                 description => "élément unique",
                 sigil => '$',
                },
    tableau   =>  {
                 description => "liste ordonnée d'éléments",
                 sigil => '@',
                },
    hachage    =>  {
                 description => "paires clé/valeur",
                 sigil => '%',
                },
};
print "Les scalaires commencent par un $variables->{'scalaire'}->{'sigil'}\n";

Vous trouverez des informations exhaustives sur le sujet des références dans perlreftut, perllol, perlref et perldsc.

Portée des variables

Tout au long de la section précédente, tous les exemples ont utilisé la syntaxe :

my $var = "valeur";

Le "my" n'est en fait pas obligatoire ; vous pourriez simplement utiliser :

$var = "valeur";

Cependant, l'utilisation ci-dessus créera des variables globales dans tout votre programme, ce qui est une mauvaise pratique de programmation. "my" crée plutôt des variables à portée lexicale. Les variables sont limitées au bloc (c'est-à-dire un ensemble d'instructions entourées d'accolades) dans lequel elles sont définies.

my $x = "foo";
my $condition_quelconque = 1;
if ($condition_quelconque) {
    my $y = "bar";
    print $x;           # affiche "foo"
    print $y;           # affiche "bar"
}
print $x;               # affiche "foo"
print $y;               # n'affiche rien ; $y est sorti de la portée

L'utilisation de "my" en combinaison avec "use strict;" en haut de vos scripts Perl signifie que l'interpréteur détectera certaines erreurs de programmation courantes. Par exemple, dans l'exemple ci-dessus, le dernier "print $y" provoquerait une erreur de compilation et vous empêcherait d'exécuter le programme. L'utilisation de "strict" est fortement recommandée.

Constructions conditionnelles et de boucle

Perl possède la plupart des constructions conditionnelles et de boucle habituelles.

Les conditions peuvent être n'importe quelle expression Perl. Voir la liste des opérateurs dans la section suivante pour des informations sur les opérateurs de comparaison et de logique booléenne, qui sont couramment utilisés dans les instructions conditionnelles.

if
if ( condition ) {
    ...
} elsif ( autre condition ) {
    ...
} else {
    ...
}

Il existe également une version négative :

unless ( condition ) {
    ...
}

Ceci est fourni comme une version plus lisible de "if (!condition)".

Notez que les accolades sont requises en Perl, même si vous n'avez qu'une seule ligne dans le bloc. Cependant, il existe un moyen astucieux de rendre vos blocs conditionnels d'une seule ligne plus semblables à l'anglais :

# la façon traditionnelle
if ($zippy) {
    print "Yow!";
}
# la façon post-conditionnelle à la Perle
print "Yow!" if $zippy;
print "Nous n'avons pas de bananes" unless $bananes;
while
while ( condition ) {
    ...
}

Il existe également une version négative, pour la même raison que nous avons "unless" :

until ( condition ) {
    ...
}

Vous pouvez également utiliser "while" dans une post-condition :

print "LA LA LA\n" while 1;          # boucle indéfiniment
for
Exactement comme en C : 
for ($i = 0; $i <= $max; $i++) {
    ...
}

La boucle for de style C est rarement nécessaire en Perl car Perl fournit la boucle "foreach" plus conviviale de balayage de liste.

foreach
foreach (@tableau) {
    print "Cet élément est $_\n";
}
print $liste[$_] foreach 0 .. $max;
# vous n'êtes pas obligé d'utiliser le $_ par défaut non plus...
foreach my $cle (keys %hachage) {
    print "La valeur de $cle est $hachage{$cle}\n";
}

Le mot-clé "foreach" est en fait un synonyme du "for" mot-clé. Voir ""Boucles Foreach" dans perlsyn".

Pour plus de détails sur les structures de boucles (et certaines qui n'ont pas été mentionnées dans cet aperçu), consultez perlsyn.

Opérateurs et fonctions intégrés

Perl est livré avec une large sélection de fonctions intégrées. Certaines de celles que nous avons déjà vues incluent "print", "sort" et "reverse". Une liste d'entre elles est donnée au début de perlfunc et vous pouvez facilement lire sur n'importe quelle fonction donnée en utilisant "perldoc -f nomfonction".

Les opérateurs Perl sont entièrement documentés dans perlop, mais voici quelques-uns des plus courants :

Arithmétique
+   addition
-   soustraction
*   multiplication
/   division
Comparaison numérique
==  égalité
!=  inégalité
<   inférieur à
>   supérieur à
<=  inférieur ou égal à
>=  supérieur ou égal à
Comparaison de chaînes
eq  égalité
ne  inégalité
lt  inférieur à
gt  supérieur à
le  inférieur ou égal à
ge  supérieur ou égal à

(Pourquoi avons-nous des comparaisons numériques et de chaînes distinctes ? Parce que nous n'avons pas de types de variables spéciaux, et Perl doit savoir s'il faut trier numériquement (où 99 est inférieur à 100) ou alphabétiquement (où 100 vient avant 99).)

Logique booléenne
&&  et
||  ou
!   non

("et", "ou" et "non" ne sont pas seulement dans le tableau ci-dessus comme descriptions des opérateurs. Ils sont également pris en charge en tant qu'opérateurs à part entière. Ils sont plus lisibles que les opérateurs de style C, mais ont une précédence différente de "&&" et ses semblables. Consultez perlop pour plus de détails.)

Divers
=   affectation
.   concaténation de chaînes
x   multiplication de chaînes (répète des chaînes)
..  opérateur de plage (crée une liste de nombres ou de chaînes)

De nombreux opérateurs peuvent être combinés avec un « = » comme suit :

$x += 1;        # équivalent à $x = $x + 1
$x -= 1;        # équivalent à $x = $x - 1
$x .= "\n";     # équivalent à $x = $x . "\n";

Fichiers et E/S

Vous pouvez ouvrir un fichier en lecture ou en écriture à l'aide de la fonction open(). Elle est documentée en détail dans perlfunc et perlopentut, mais en bref :

open(my $in,  "<",  "input.txt")  or die "Impossible d'ouvrir input.txt : $!";
open(my $out, ">",  "output.txt") or die "Impossible d'ouvrir output.txt : $!";
open(my $log, ">>", "my.log")     or die "Impossible d'ouvrir my.log : $!";

Vous pouvez lire à partir d'un handle de fichier ouvert à l'aide de l'opérateur "<>". En contexte scalaire, il lit une seule ligne du handle de fichier, et en contexte de liste, il lit tout le fichier, attribuant chaque ligne à un élément de la liste :

my $line  = <$in>;
my @lines = <$in>;

Lire tout le fichier en une seule fois s'appelle "slurping". Cela peut être utile mais peut consommer beaucoup de mémoire. La plupart des traitements de fichiers texte peuvent être effectués ligne par ligne avec les structures de boucles de Perl.

L'opérateur "<>" est le plus souvent vu dans une boucle "while" :

while (<$in>) {     # attribue chaque ligne tour à tour à $_
    print "Je viens de lire cette ligne : $_";
}

Nous avons déjà vu comment imprimer sur la sortie standard à l'aide de print(). Cependant, print() peut également prendre un premier argument facultatif spécifiant le handle de fichier sur lequel imprimer :

print STDERR "Ceci est votre dernier avertissement.\n";
print $out $record;
print $log $logmessage;

Lorsque vous avez terminé avec vos handles de fichier, vous devez les close() (bien que, pour être honnête, Perl s'occupera du nettoyage si vous oubliez) :

close $in or die "$in : $!";

Expressions régulières

Le support des expressions régulières de Perl est à la fois large et profond, et fait l'objet d'une documentation détaillée dans perlrequick, perlretut et ailleurs. Cependant, en bref :

Correspondance simple
if (/foo/)       { ... }  # vrai si $_ contient "foo"
if ($x =~ /foo/) { ... }  # vrai si $x contient "foo"

L'opérateur de correspondance "//" est documenté dans perlop. Il opère sur $_ par défaut, ou peut être lié à une autre variable en utilisant l'opérateur de liaison "=~" (également documenté dans perlop).

Substitution simple
s/foo/bar/;               # remplace foo par bar dans $_
$x =~ s/foo/bar/;         # remplace foo par bar dans $x
$x =~ s/foo/bar/g;        # remplace TOUTES LES INSTANCES de foo par bar
                          # dans $x

L'opérateur de substitution "s///" est documenté dans perlop.

Expressions régulières plus complexes
Vous n'avez pas seulement à faire correspondre des chaînes fixes. En fait, vous pouvez faire correspondre à peu près tout ce dont vous pourriez rêver en utilisant des expressions régulières plus complexes. Celles-ci sont documentées en détail dans perlre, mais pour l'instant, voici une aide-mémoire rapide : 
.                   un seul caractère
\s                  un caractère d'espacement (espace, tabulation, nouvelle ligne, ...)
\S                  caractère non-espacement
\d                  un chiffre (0-9)
\D                  un non-chiffre
\w                  un caractère de mot (a-z, A-Z, 0-9, _)
\W                  un caractère non-mot
[aeiou]             correspond à un seul caractère de l'ensemble donné
[^aeiou]            correspond à un seul caractère en dehors de l'ensemble
                    donné
(foo|bar|baz)       correspond à l'une des alternatives spécifiées
^                   début de la chaîne
$                   fin de la chaîne

Notez que dans ce qui précède, "$" ne correspond pas à un signe dollar. De même, ".", "\", "[", "]", "(", ")" et "^" ne correspondent pas aux caractères que vous pourriez attendre. Ce sont des "méta-caractères". En revanche, les caractères "a", "e", "i", "o" et "u", par exemple, ne sont pas des méta-caractères. Ils correspondent à eux-mêmes littéralement. Il existe quelques méta-caractères de plus que ceux ci-dessus. Certains quantificateurs sont donnés ci-dessous, et la liste complète se trouve dans "Metacharacters" dans perlre.

Pour qu'un méta-caractère corresponde à sa valeur littérale, vous l'"échappez" (ou le "quotez") en le faisant précéder d'une barre oblique inverse. Ainsi, "\$" correspond bien à un signe dollar, et "\\" correspond à une barre oblique inverse littérale.

Notez également que ci-dessus, la chaîne "\s", par exemple, ne correspond pas à une barre oblique inverse suivie de la lettre "s". Dans ce cas, faire précéder le caractère non-méta "s" d'une barre oblique inverse en fait quelque chose qui ne correspond pas à sa valeur littérale. Une telle séquence est appelée une "séquence d'échappement". perlrebackslash documente toutes les séquences actuelles.

Un avertissement est émis si vous échappez un caractère qui n'est pas un méta-caractère et qui ne fait pas partie d'une séquence d'échappement actuellement définie.

Vous pouvez spécifier combien de l'élément précédent vous souhaitez faire correspondre en utilisant des quantificateurs (où "élément" signifie : un caractère littéral, l'une des constructions listées ci-dessus, ou un groupe de l'un ou l'autre dans des parenthèses).

*                   zéro ou plusieurs de l'élément précédent
+                   un ou plusieurs de l'élément précédent
?                   zéro ou un de l'élément précédent
{3}                 correspond exactement à 3 de l'élément précédent
{3,6}               correspond entre 3 et 6 de l'élément précédent
{3,}                correspond à 3 ou plus de l'élément précédent

Quelques exemples rapides :

/^\d+/              la chaîne commence par un ou plusieurs chiffres
/^$/                rien dans la chaîne (début et fin sont
                    adjacents)
/(\d\s){3}/         trois chiffres, chacun suivi d'un caractère d'espacement
                    (par exemple "3 4 5 ")
/(a.)+/             correspond à une chaîne dans laquelle chaque lettre impaire est un a (par exemple "abacadaf")
# Cette boucle lit depuis STDIN et affiche les lignes non vides :
while (<>) {
    next if /^$/;
    print;
}
Parenthèses pour la capture
En plus de grouper, les parenthèses servent à une seconde fin. Elles peuvent être utilisées pour capturer les résultats de parties de la correspondance d'expression régulière pour une utilisation ultérieure. Les résultats se retrouvent dans $1, $2 et ainsi de suite. 
# une façon bon marché et médiocre de diviser une adresse e-mail en parties
if ($email =~ /([^@]+)@(.+)/) {
    print "Le nom d'utilisateur est $1\n";
    print "Le nom d'hôte est $2\n";
}
Autres fonctionnalités des expressions régulières
Les expressions régulières Perl prennent également en charge les références arrière, les lookaheads et toutes sortes d'autres détails complexes. Lisez tout à leur sujet dans perlrequick, perlretut et perlre.

perlintro — Introduction à la programmation Perl

DESCRIPTION

Ce document est une introduction aux concepts de base de la programmation Perl. Il est destiné aux débutants et couvre les sujets suivants :

  • Syntaxe de base
  • Variables
  • Opérateurs
  • Structures de contrôle
  • Sous-routines
  • Programmation orientée objet (OO) en Perl
  • Utilisation de modules Perl

Pour des informations plus détaillées, veuillez consulter les documents Perl correspondants (par exemple, perlvar, perlsyn, perlfunc, perlsub, perlootut, perlobj, perlmod, etc.).

Syntaxe de base

Chaque instruction Perl doit se terminer par un point-virgule (;).

Les commentaires sont introduits par le symbole dièse (#).

# Ceci est un commentaire

Les chaînes de caractères peuvent être délimitées par des guillemets simples (') ou doubles (").

my $string1 = 'Ceci est une chaîne avec guillemets simples.';
my $string2 = "Ceci est une chaîne avec guillemets doubles.";

Les variables scalaires commencent par un signe dollar ($).

my $variable = 42;

Les tableaux commencent par un signe arobase (@).

my @tableau = (1, 2, 3, 4);

Les hachages commencent par un signe de pourcentage (%).

my %hash = (cle1 => valeur1, cle2 => valeur2);

Variables

Il existe trois types principaux de variables en Perl :

Scalaires
Contiennent une seule valeur (nombre, chaîne de caractères, référence).
Tableaux
Contiennent une liste ordonnée de valeurs.
Hachages
Contiennent des paires clé-valeur.

Utilisez le mot-clé my pour déclarer des variables locales.

my $scalaire = "Bonjour";
my @tableau = (10, 20, 30);
my %hash = (un => 1, deux => 2);

Les variables globales sont déclarées avec our (ou sans déclaration, mais ce n'est pas recommandé).

Opérateurs

Perl prend en charge les opérateurs arithmétiques, de chaîne, logiques, de comparaison, etc.

# Arithmétique
my $somme = 5 + 3; # 8
my $produit = 5 * 3; # 15

# Chaîne
my $concat = "Bonjour" . " le monde"; # "Bonjour le monde"
my $repeat = "abc" x 3; # "abcabcabc"

# Comparaison
if ($a < $b) { ... }
if ($chaine1 eq $chaine2) { ... }

# Logique
if ($a && $b) { ... } # ET logique
if ($a || $b) { ... }  # OU logique
if (!$a) { ... }       # NON logique

Structures de contrôle

Perl propose les structures de contrôle classiques :

# if, elsif, else
if ($condition1) {
    # code si condition1 est vraie
} elsif ($condition2) {
    # code si condition2 est vraie
} else {
    # code si aucune condition n'est vraie
}
# while
my $i = 0;
while ($i < 5) {
    print "$i\n";
    $i++;
}
# for
for my $j (1..5) {
    print "$j\n";
}
# foreach (ou for)
my @elements = qw(un deux trois);
foreach my $element (@elements) {
    print "$element\n";
}
# do-while
my $k = 0;
do {
    print "$k\n";
    $k++;
} while ($k < 5);
# until
my $l = 0;
until ($l >= 5) {
    print "$l\n";
    $l++;
}

Sous-routines

Les sous-routines sont des blocs de code réutilisables.

sub nom_de_la_sous_routine {
    # code de la sous-routine
    # les arguments sont dans le tableau spécial @_
    my $message = shift; # prend le premier argument
    print "Message reçu : $message\n";
    # la dernière valeur évaluée est retournée implicitement
    # ou utilisez 'return' explicitement
    return 1; # retourne 1
}

Appel d'une sous-routine :

nom_de_la_sous_routine("Ceci est un argument");

La manipulation de @_ :

# Méthode courante pour récupérer plusieurs arguments
my ($arg1, $arg2) = @_;
# Méthode moins courante et moins lisible
my $arg1 = $_[0];

Les sous-routines peuvent retourner des valeurs :

sub carre {
    my $num = shift;
    my $resultat = $num * $num;
    return $resultat;
}

Utilisation :

$carre_de_8 = carre(8); # $carre_de_8 vaut 64

Pour plus d'informations sur l'écriture de sous-routines, consultez perlsub.

Perl Objet

La programmation orientée objet en Perl est relativement simple et implémentée à l'aide de références qui savent quel type d'objet elles représentent, basé sur le concept de packages en Perl. Cependant, la POO en Perl dépasse largement le cadre de ce document. Lisez perlootut et perlobj.

En tant que programmeur Perl débutant, votre utilisation la plus fréquente de la POO en Perl sera l'utilisation de modules tiers, décrits ci-dessous.

Utilisation des modules Perl

Les modules Perl offrent une gamme de fonctionnalités pour vous aider à éviter de réinventer la roue, et peuvent être téléchargés depuis CPAN https://www.cpan.org/. Un certain nombre de modules populaires sont inclus dans la distribution Perl elle-même.

Les catégories de modules vont de la manipulation de texte aux protocoles réseau, en passant par l'intégration de bases de données et les graphiques. Une liste catégorisée des modules est également disponible sur CPAN.

Pour apprendre à installer les modules que vous téléchargez depuis CPAN, lisez perlmodinstall.

Pour apprendre à utiliser un module particulier, utilisez "perldoc Nom::Du::Module". Typiquement, vous voudrez faire "use Nom::Du::Module", ce qui vous donnera alors accès aux fonctions exportées ou à une interface objet pour le module.

perlfaq contient des questions et réponses relatives à de nombreuses tâches courantes, et propose souvent des suggestions de bons modules CPAN à utiliser.

perlmod décrit les modules Perl en général. perlmodlib liste les modules qui sont venus avec votre installation Perl.

Si l'envie vous prend d'écrire des modules Perl, perlnewmod vous donnera de bons conseils.
