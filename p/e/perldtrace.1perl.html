NOM

perldtrace - Support de Perl pour DTrace

SYNTAXE

# dtrace -Zn 'perl::sub-entry, perl::sub-return { trace(copyinstr(arg0)) }'

DESCRIPTION

DTrace est un framework de traçage complet au niveau système et application. Perl est un fournisseur DTrace, ce qui signifie qu'il expose plusieurs sondes pour l'instrumentation. Vous pouvez les utiliser en conjonction avec des sondes au niveau du noyau, ainsi que des sondes d'autres fournisseurs comme MySQL, afin de diagnostiquer des défauts logiciels, ou même simplement les goulots d'étranglement de votre application.

Perl doit être compilé avec l'option "-Dusedtrace" pour pouvoir utiliser les sondes fournies. Bien que DTrace vise à ne pas avoir de surcharge lorsque son instrumentation n'est pas active, le support de Perl lui-même ne peut pas garantir cela, il est donc construit sans sondes DTrace sur la plupart des systèmes. Une exception notable est que Mac OS X distribue un /usr/bin/perl avec le support DTrace activé.

HISTOIRE

5.10.1
Le support DTrace initial de Perl a été ajouté, fournissant les sondes "sub-entry" et "sub-return".
5.14.0
Les sondes "sub-entry" et "sub-return" ont un quatrième argument : le nom du package de la fonction.
5.16.0
La sonde "phase-change" a été ajoutée.
5.18.0
Les sondes "op-entry", "loading-file" et "loaded-file" ont été ajoutées.

SONDES

sub-entry(SUBNAME, FILE, LINE, PACKAGE)
Trace l'entrée de n'importe quelle sous-routine. Notez que toutes les variables se réfèrent à la sous-routine qui est invoquée ; il n'y a actuellement aucun moyen d'obtenir des informations sur l'*appelant* de la sous-routine à partir d'une action DTrace. 
:*perl*::sub-entry {
    printf("%s::%s entré à %s ligne %d\n",
          copyinstr(arg3), copyinstr(arg0), copyinstr(arg1), arg2);
}
sub-return(SUBNAME, FILE, LINE, PACKAGE)
Trace la sortie de n'importe quelle sous-routine. Notez que toutes les variables se réfèrent à la sous-routine qui retourne ; il n'y a actuellement aucun moyen d'obtenir des informations sur l'*appelant* de la sous-routine à partir d'une action DTrace. 
:*perl*::sub-return {
    printf("%s::%s retourné à %s ligne %d\n",
          copyinstr(arg3), copyinstr(arg0), copyinstr(arg1), arg2);
}
phase-change(NEWPHASE, OLDPHASE)
Trace les changements d'état de l'interpréteur Perl. Vous pouvez l'interpréter comme le traçage des changements de la variable Perl "${^GLOBAL_PHASE}", d'autant plus que les valeurs pour "NEWPHASE" et "OLDPHASE" sont les chaînes que "${^GLOBAL_PHASE}" rapporte. 
:*perl*::phase-change {
    printf("Phase changée de %s à %s\n",
        copyinstr(arg1), copyinstr(arg0));
}
op-entry(OPNAME)
Trace l'exécution de chaque opcode dans la boucle d'exécution de Perl. Cette sonde est déclenchée avant l'exécution de l'opcode. Lorsque le débogueur Perl est activé, la sonde DTrace est déclenchée *après* les hooks du débogueur (mais toujours avant l'exécution de l'opcode lui-même). 
:*perl*::op-entry {
    printf("Sur le point d'exécuter l'opcode %s\n", copyinstr(arg0));
}
loading-file(FILENAME)
Se déclenche lorsque Perl est sur le point de charger un fichier individuel, que ce soit via "use", "require", ou "do". Cette sonde se déclenche avant que le fichier ne soit lu depuis le disque. L'argument du nom de fichier est converti en chemins du système de fichiers local au lieu de fournir des noms de style "Module::Name". 
:*perl*:loading-file {
    printf("Sur le point de charger %s\n", copyinstr(arg0));
}
loaded-file(FILENAME)
Se déclenche lorsque Perl a chargé avec succès un fichier individuel, que ce soit via "use", "require", ou "do". Cette sonde se déclenche après que le fichier a été lu depuis le disque et que son contenu a été évalué. L'argument du nom de fichier est converti en chemins du système de fichiers local au lieu de fournir des noms de style "Module::Name". 
:*perl*:loaded-file {
    printf("Chargé avec succès %s\n", copyinstr(arg0));
}
