NOM

pee - recopie l'entrée standard vers des tubes

SYNTAXE


pee
[--[no-]ignore-sigpipe] [--[no-]ignore-write-errors] [« commande »...]

DESCRIPTION

pee est similaire à tee mais pour les tubes. Chaque commande est exécutée et reçoit une copie de l'entrée standard. La sortie de toutes les commandes est envoyée à la sortie standard.

Notez que bien que cela soit similaire à tee, une copie de l'entrée n'est pas envoyée à la sortie standard, comme le fait tee. Si cela est désiré, utilisez pee cat ...

OPTIONS

--ignore-sigpipe, --no-ignore-sigpipe
Ignore (ou non) SIGPIPE. Toute commande démarrée par pee pourrait provoquer un SIGPIPE lors de sa sortie. Si vous ignorez SIGPIPE, vous voudrez probablement aussi ignorer les erreurs d'écriture (voir ci-dessous). Ignorer SIGPIPE est le comportement par défaut.
--ignore-write-errors, --no-ignore-write-errors
Ignore (ou non) les erreurs d'écriture. Lorsqu'une commande démarrée par pee n'accepte plus de données via le tube entre elle et pee, une erreur d'écriture se produit dans pee. Si cette erreur n'est pas ignorée, pee terminera tous les processus enfants et quittera. Ignorer les erreurs d'écriture est le comportement par défaut.
