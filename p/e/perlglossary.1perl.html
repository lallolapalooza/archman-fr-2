DESCRIPTION

Un glossaire des termes (techniques ou autres) utilisés dans la documentation Perl, dérivé du Glossaire de Programming Perl, Quatrième Édition. Les mots ou phrases en gras sont définis ailleurs dans ce glossaire.

D'autres sources utiles incluent le Glossaire Unicode http://unicode.org/glossary/, le Free On-Line Dictionary of Computing http://foldoc.org/, le Jargon File http://catb.org/~esr/jargon/, et Wikipedia http://www.wikipedia.org/.

A

méthodes d'accesseur
Une méthode utilisée pour inspecter ou modifier indirectement l'état d'un objet (ses variables d'instance).
arguments actuels
Les valeurs scalaires que vous fournissez à une fonction ou une sous-routine lorsque vous l'appelez. Par exemple, lorsque vous appelez power("puff"), la chaîne "puff" est l'argument actuel. Voir aussi argument et arguments formels.
opérateur d'adresse
Certains langages travaillent directement avec les adresses mémoire des valeurs, mais cela peut être comme jouer avec le feu. Perl fournit un ensemble de gants en amiante pour gérer toute la gestion de la mémoire. Ce qui se rapproche le plus d'un opérateur d'adresse en Perl est l'opérateur backslash, mais il donne une référence forte, ce qui est beaucoup plus sûr qu'une adresse mémoire.
algorithme
Une séquence d'étapes bien définie, expliquée suffisamment clairement pour qu'un ordinateur puisse les exécuter.
alias
Un surnom pour quelque chose, qui se comporte de toutes les manières comme si vous aviez utilisé le nom original au lieu du surnom. Des alias temporaires sont implicitement créés dans la variable de boucle pour les boucles "foreach", dans la variable $_ pour les opérateurs "map" ou "grep", dans $a et $b pendant la fonction de comparaison de "sort", et dans chaque élément de @_ pour les arguments actuels d'un appel de sous-routine. Des alias permanents sont explicitement créés dans les packages en important des symboles ou par affectation à des typeglobs. Des alias de portée lexicale pour les variables de package sont explicitement créés par la déclaration "our".
alphabétique
Le type de caractères que nous mettons dans les mots. En Unicode, ce sont toutes les lettres, y compris tous les idéographes et certains diacritiques, les chiffres de lettres comme les chiffres romains, et diverses marques de combinaison.
alternatives
Une liste de choix possibles parmi lesquels vous ne pouvez en sélectionner qu'un seul, comme dans, « Voulez-vous la porte A, B ou C ? ». Les alternatives dans les expressions régulières sont séparées par une seule barre verticale : "|". Les alternatives dans les expressions Perl normales sont séparées par une double barre verticale : "||". Les alternatives logiques dans les expressions Booléennes sont séparées par "||" ou "or".
anonyme
Utilisé pour décrire un référent qui n'est pas directement accessible par une variable nommée. Un tel référent doit être accessible indirectement par au moins une référence forte. Lorsque la dernière référence forte disparaît, le référent anonyme est détruit sans pitié.
application
Une sorte de programme plus grand et plus sophistiqué avec un nom plus sophistiqué pour que les gens ne réalisent pas qu'ils utilisent un programme.
architecture
Le type d'ordinateur sur lequel vous travaillez, où un « type d'ordinateur » signifie tous les ordinateurs partageant un langage machine compatible. Comme les programmes Perl sont (typiquement) des fichiers texte simples, pas des images exécutables, un programme Perl est beaucoup moins sensible à l'architecture sur laquelle il s'exécute que les programmes dans d'autres langages, comme C, qui sont compilés en code machine. Voir aussi plateforme et système d'exploitation.
argument
Un morceau de données fourni à un programme, une sous-routine, une fonction ou une méthode pour lui dire ce qu'il est censé faire. Également appelé « paramètre ».
ARGV
Le nom du tableau contenant le vecteur d'arguments de la ligne de commande. Si vous utilisez l'opérateur vide "<>", "ARGV" est le nom à la fois du filehandle utilisé pour parcourir les arguments et du scalaire contenant le nom du fichier d'entrée actuel.
opérateur arithmétique
Un symbole tel que "+" ou "/" qui indique à Perl d'effectuer l'arithmétique que vous étiez censé apprendre à l'école primaire.
tableau
Une séquence ordonnée de valeurs, stockée de manière à pouvoir accéder facilement à n'importe laquelle des valeurs à l'aide d'un *indice entier* qui spécifie le décalage de la valeur dans la séquence.
contexte de tableau
Une expression archaïque pour ce qui est plus correctement appelé contexte de liste.
Licence Artistique
La licence open source que Larry Wall a créée pour Perl, maximisant l'utilité, la disponibilité et la modifiabilité de Perl. La version actuelle est la 2. (http://www.opensource.org/licenses/artistic-license.php).
ASCII
L'American Standard Code for Information Interchange (un jeu de caractères 7 bits suffisant uniquement pour mal représenter le texte anglais). Souvent utilisé de manière laxiste pour décrire les 128 valeurs les plus basses des divers jeux de caractères ISO-8859-X, un ensemble de codes 8 bits mutuellement incompatibles qui sont mieux décrits comme une moitié d'ASCII. Voir aussi Unicode.
assertion
Une composante d'une expression régulière qui doit être vraie pour que le motif corresponde, mais qui ne correspond pas nécessairement à des caractères elle-même. Souvent utilisée spécifiquement pour désigner une assertion de largeur nulle.
affectation
Un opérateur dont la mission assignée est de changer la valeur d'une variable.
opérateur d'affectation
Soit une affectation ordinaire, soit un opérateur composé d'une affectation ordinaire et d'un autre opérateur, qui change la valeur d'une variable en place ; c'est-à-dire par rapport à sa valeur précédente. Par exemple, "$a += 2" ajoute 2 à $a.
tableau associatif
Voir hash. S'il vous plaît. Le terme tableau associatif est l'ancien terme de Perl 4 pour un hash. Certains langages l'appellent dictionnaire.
associativité
Détermine si vous effectuez d'abord l'opérateur de gauche ou l'opérateur de droite lorsque vous avez « A opérateur B opérateur C », et que les deux opérateurs ont la même précédence. Les opérateurs comme "+" sont associatifs à gauche, tandis que les opérateurs comme "**" sont associatifs à droite. Voir le chapitre 3 du Camel, « Opérateurs unaires et binaires », pour une liste des opérateurs et de leur associativité.
asynchrone
Dit des événements ou activités dont la temporalité relative

A

asynchronous
Event ordering is indeterminate because too many things are going on at once. Hence, an asynchronous event is one you didn’t know when to expect.
atom
A regular expression component potentially matching a substring containing one or more characters and treated as an indivisible syntactic unit by any following quantifier. (Contrast with an assertion that matches something of zero width and may not be quantified.)
atomic operation
When Democritus gave the word “atom” to the indivisible bits of matter, he meant literally something that could not be cut: ἀ- (not) + -τομος (cuttable). An atomic operation is an action that can’t be interrupted, not one forbidden in a nuclear-free zone.
attribute
A new feature that allows the declaration of variables and subroutines with modifiers, as in "sub foo : locked method". Also another name for an instance variable of an object.
autogeneration
A feature of operator overloading of objects, whereby the behavior of certain operators can be reasonably deduced using more fundamental operators. This assumes that the overloaded operators will often have the same relationships as the regular operators. See Camel chapter 13, “Overloading”.
autoincrement
To add one to something automatically, hence the name of the "++" operator. To instead subtract one from something automatically is known as an “autodecrement”.
autoload
To load on demand. (Also called “lazy” loading.) Specifically, to call an "AUTOLOAD" subroutine on behalf of an undefined subroutine.
autosplit
To split a string automatically, as the –a switch does when running under –p or –n in order to emulate awk. (See also the "AutoSplit" module, which has nothing to do with the "–a" switch but a lot to do with autoloading.)
autovivification
A Graeco-Roman word meaning “to bring oneself to life”. In Perl, storage locations (lvalues) spontaneously generate themselves as needed, including the creation of any hard reference values to point to the next level of storage. The assignment "$a[5][5][5][5][5] = "quintet"" potentially creates five scalar storage locations, plus four references (in the first four scalar locations) pointing to four new anonymous arrays (to hold the last four scalar locations). But the point of autovivification is that you don’t have to worry about it.
AV
Short for “array value”, which refers to one of Perl’s internal data types that holds an array. The "AV" type is a subclass of SV.
awk
Descriptive editing term—short for “awkward”. Also coincidentally refers to a venerable text-processing language from which Perl derived some of its high-level ideas.

B

backreference
A substring captured by a subpattern within unadorned parentheses in a regex. Backslashed decimal numbers ("\1", "\2", etc.) later in the same pattern refer back to the corresponding subpattern in the current match. Outside the pattern, the numbered variables ($1, $2, etc.) continue to refer to these same values, as long as the pattern was the last successful match of the current dynamic scope.
backtracking
The practice of saying, “If I had to do it all over, I’d do it differently,” and then actually going back and doing it all over differently. Mathematically speaking, it’s returning from an unsuccessful recursion on a tree of possibilities. Perl backtracks when it attempts to match patterns with a regular expression, and its earlier attempts don’t pan out. See the section “The Little Engine That /Couldn(n’t)” in Camel chapter 5, “Pattern Matching”.
backward compatibility
Means you can still run your old program because we didn’t break any of the features or bugs it was relying on.
bareword
A word sufficiently ambiguous to be deemed illegal under "use strict 'subs'". In the absence of that stricture, a bareword is treated as if quotes were around it.
base class
A generic object type; that is, a class from which other, more specific classes are derived genetically by inheritance. Also called a “superclass” by people who respect their ancestors.
big-endian
From Swift: someone who eats eggs big end first. Also used of computers that store the most significant byte of a word at a lower byte address than the least significant byte. Often considered superior to little-endian machines. See also little-endian.
binary
Having to do with numbers represented in base 2. That means there’s basically two numbers: 0 and 1. Also used to describe a file of “nontext”, presumably because such a file makes full use of all the binary bits in its bytes. With the advent of Unicode, this distinction, already suspect, loses even more of its meaning.
binary operator
An operator that takes two operands.
bind
To assign a specific network address to a socket.
bit
An integer in the range from 0 to 1, inclusive. The smallest possible unit of information storage. An eighth of a byte or of a dollar. (The term “Pieces of Eight” comes from being able to split the old Spanish dollar into 8 bits, each of which still counted for money. That’s why a 25- cent piece today is still “two bits”.)
bit shift
The movement of bits left or right in a computer word, which has the effect of multiplying or dividing by a power of 2.
bit string
A sequence of bits that is actually being thought of as a sequence of bits, for once.
bless
In corporate life, to grant official approval to a thing, as in, “The VP of Engineering has blessed our WebCruncher project.” Similarly, in Perl, to grant official approval to a referent so that it can function as an object, such as a WebCruncher object. See the "bless" function in Camel chapter 27, “Functions”.
block
What a process does when it has to wait for something: “My process blocked waiting for the disk.” As an unrelated noun, it refers to a large chunk of data, of a size that the operating system likes to deal with (normally a power of 2 such as 512 or 8192). Typically refers to a chunk of data that’s coming from or going to a disk file.
BLOCK
A syntactic construct consisting of a sequence of Perl statements that is delimited by braces. The "if" and "while" statements are defined in terms of "BLOCK"s, for instance. Sometimes we also say “block” to mean a lexical scope; that is, a sequence of statements that acts like a "BLOCK", such as within an "eval" or a file, even though the statements aren’t delimited by braces.
block buffering
A method of making input and output efficient by passing one block at a time. By default, Perl does block buffering to disk files. See buffer and command buffering.
Boolean
A value that is either true or false.
Boolean context
A special kind of scalar context used in conditionals to decide whether the scalar value returned by an expression is true or false. Does not evaluate as either a string or a number. See context.
breakpoint
A spot in your program where you’ve told the debugger to stop execution so you can poke around and see whether anything is wrong yet.
broadcast
To send a datagram to multiple destinations simultaneously.
BSD
A psychoactive drug, popular in the ’80s, probably developed at UC Berkeley or thereabouts. Similar in many ways to the prescription-only medication called “System V”, but infinitely more useful. (Or, at least, more fun.) The full chemical name is “Berkeley Standard Distribution”.
bucket
A location in a hash table containing (potentially) multiple entries whose keys “hash” to the same hash value according to its hash function. (As internal policy, you don’t have to worry about it unless you’re into internals, or policy.)
buffer
A temporary holding location for data. Data that are Block
buffer
A temporary holding area for data. The system can buffer output in several ways. Full buffering means that the data is passed on to its destination whenever the buffer is full. Line buffering means that it’s passed on whenever a complete line is received. Command buffering means that it’s passed every time you do a "print" command (or equivalent). If your output is unbuffered, the system processes it one byte at a time without the use of a holding area. This can be rather inefficient.
built-in
A function that is predefined in the language. Even when hidden by overriding, you can always get at a built-in function by qualifying its name with the "CORE::" pseudopackage.
bundle
A group of related modules on CPAN. (Also sometimes refers to a group of command-line switches grouped into one switch cluster.)
byte
A piece of data worth eight bits in most places.
bytecode
A pidgin-like lingo spoken among ’droids when they don’t wish to reveal their orientation (see endian). Named after some similar languages spoken (for similar reasons) between compilers and interpreters in the late 20th century. These languages are characterized by representing everything as a nonarchitecture-dependent sequence of bytes.

C

C
A language beloved by many for its inside-out type definitions, inscrutable precedence rules, and heavy overloading of the function-call mechanism. (Well, actually, people first switched to C because they found lowercase identifiers easier to read than upper.) Perl is written in C, so it’s not surprising that Perl borrowed a few ideas from it.
cache
A data repository. Instead of computing expensive answers several times, compute it once and save the result.
callback
A handler that you register with some other part of your program in the hope that the other part of your program will trigger your handler when some event of interest transpires.
call by reference
An argument-passing mechanism in which the formal arguments refer directly to the actual arguments, and the subroutine can change the actual arguments by changing the formal arguments. That is, the formal argument is an alias for the actual argument. See also call by value.
call by value
An argument-passing mechanism in which the formal arguments refer to a copy of the actual arguments, and the subroutine cannot change the actual arguments by changing the formal arguments. See also call by reference.
canonical
Reduced to a standard form to facilitate comparison.
capture variables
The variables—such as $1 and $2, and "%+" and "%– "—that hold the text remembered in a pattern match. See Camel chapter 5, “Pattern Matching”.
capturing
The use of parentheses around a subpattern in a regular expression to store the matched substring as a backreference. (Captured strings are also returned as a list in list context.) See Camel chapter 5, “Pattern Matching”.
cargo cult
Copying and pasting code without understanding it, while superstitiously believing in its value. This term originated from preindustrial cultures dealing with the detritus of explorers and colonizers of technologically advanced cultures. See The Gods Must Be Crazy.
case
A property of certain characters. Originally, typesetter stored capital letters in the upper of two cases and small letters in the lower one. Unicode recognizes three cases: lowercase (character property "\p{lower}"), titlecase ("\p{title}"), and uppercase ("\p{upper}"). A fourth casemapping called foldcase is not itself a distinct case, but it is used internally to implement casefolding. Not all letters have case, and some nonletters have case.
casefolding
Comparing or matching a string case-insensitively. In Perl, it is implemented with the "/i" pattern modifier, the "fc" function, and the "\F" double-quote translation escape.
casemapping
The process of converting a string to one of the four Unicode casemaps; in Perl, it is implemented with the "fc", "lc", "ucfirst", and "uc" functions.
character
The smallest individual element of a string. Computers store characters as integers, but Perl lets you operate on them as text. The integer used to represent a particular character is called that character’s codepoint.
character class
A square-bracketed list of characters used in a regular expression to indicate that any character of the set may occur at a given point. Loosely, any predefined set of characters so used.
character property
A predefined character class matchable by the "\p" or "\P" metasymbol. Unicode defines hundreds of standard properties for every possible codepoint, and Perl defines a few of its own, too.
circumfix operator
An operator that surrounds its operand, like the angle operator, or parentheses, or a hug.
class
A user-defined type, implemented in Perl via a package that provides (either directly or by inheritance) methods (that is, subroutines) to handle instances of the class (its objects). See also inheritance.
class method
A method whose invocant is a package name, not an object reference. A method associated with the class as a whole. Also see instance method.
client
In networking, a process that initiates contact with a server process in order to exchange data and perhaps receive a service.
closure
An anonymous subroutine that, when a reference to it is generated at runtime, keeps track of the identities of externally visible lexical variables, even after those lexical variables have supposedly gone out of scope. They’re called “closures” because this sort of behavior gives mathematicians a sense of closure.
cluster
A parenthesized subpattern used to group parts of a regular expression into a single atom.
CODE
The word returned by the "ref" function when you apply it to a reference to a subroutine. See also CV.
code generator
A system that writes code for you in a low-level language, such as code to implement the backend of a compiler. See program generator.
codepoint
The integer a computer uses to represent a given character. ASCII codepoints are in the range 0 to 127; Unicode codepoints are in the range 0 to 0x10_FFFF; and Perl codepoints are in the range 0 to 232-1 or 0 to 264-1, depending on your native integer size. In Perl Culture, sometimes called ordinals.
code subpattern
A regular expression subpattern whose real purpose is to execute some Perl code—for example, the "(?{...})" and "(??{...})" subpatterns.
collating sequence
The order into which characters sort. This is used by string comparison routines to decide, for example, where in this glossary to put “collating sequence”.
co-maintainer
A person with permissions to index a namespace in PAUSE. Anyone can upload any namespace, but only primary and co-maintainers get their contributions indexed.
combining character
Any character with the General Category of Combining Mark ("\p{GC=M}"), which may be spacing or nonspacing. Some are even invisible. A sequence of combining characters following a grapheme base character together make up a single user-visible character called a grapheme. Most but not all diacritics are combining characters, and vice versa.
command
In shell programming, the syntactic combination of a program name and its arguments. More loosely, anything you type to a shell (a command interpreter) that starts it doing something. Even more loosely, a Perl statement, which might start with a label and typically ends with a semicolon.
command buffering
A mechanism in Perl that lets you store up the output of each Perl command and then flush it out as a single request to the operating system. It’s enabled by setting the $|
n> ($AUTOFLUSH) variable à une valeur vraie. Il est utilisé lorsque vous ne voulez pas que des données restent là, sans aller là où elles sont censées aller, ce qui peut arriver parce que la valeur par défaut sur un **fichier** ou un **tube** est d'utiliser la **mise en mémoire tampon par blocs**.
arguments de la ligne de commande
Les **valeurs** que vous fournissez avec le nom d'un programme lorsque vous demandez à un **shell** d'exécuter une **commande**. Ces valeurs sont passées à un programme Perl via @ARGV.
nom de la commande
Le nom du programme actuellement exécuté, tel qu'il a été tapé sur la ligne de commande. En C, le nom de la **commande** est passé au programme comme premier argument de la ligne de commande. En Perl, il arrive séparément sous la forme de $0.
commentaire
Une remarque qui n'affecte pas le sens du programme. En Perl, un commentaire est introduit par un caractère "#" et se poursuit jusqu'à la fin de la ligne.
unité de compilation
Le **fichier** (ou la **chaîne**, dans le cas de "eval") qui est actuellement en cours de **compilation**.
compiler
Le processus de transformation du code source en une forme utilisable par la machine. Voir **phase de compilation**.
phase de compilation
Tout moment avant que Perl ne commence à exécuter votre programme principal. Voir aussi **phase d'exécution**. La phase de compilation est principalement consacrée au **temps de compilation**, mais peut également être consacrée au **temps d'exécution** lorsque des blocs "BEGIN", des déclarations "use" ou "no", ou des sous-expressions constantes sont évalués. Le démarrage et le code d'importation de toute déclaration "use" sont également exécutés pendant la phase de compilation.
compilateur
Strictement parlant, un programme qui analyse un autre programme et produit un autre fichier contenant le programme sous une forme « plus exécutable », contenant généralement des instructions machine natives. Le programme perl n'est pas un compilateur selon cette définition, mais il contient une sorte de compilateur qui prend un programme et le transforme en une forme plus exécutable (des **arbres syntaxiques**) au sein du processus perl lui-même, que l'**interpréteur** interprète ensuite. Il existe cependant des **modules** d'extension pour que Perl agisse davantage comme un « vrai » compilateur. Voir Chapitre 16 du Manuel (Camel), « Compilation ».
temps de compilation
Le moment où Perl essaie de donner un sens à votre code, par opposition au moment où il pense connaître le sens de votre code et essaie simplement de faire ce qu'il pense que votre code lui dit de faire, ce qui est le **temps d'exécution**.
compositeur
Un « constructeur » pour un **référent** qui n'est pas vraiment un **objet**, comme un tableau anonyme ou une table de hachage (ou une sonate, d'ailleurs). Par exemple, une paire d'accolades agit comme un compositeur pour une table de hachage, et une paire de crochets agit comme un compositeur pour un tableau. Voir la section « Création de références » du Chapitre 8 du Manuel (Camel), « Références ».
concaténation
L'action de coller le nez d'un chat à la queue d'un autre chat. Également une opération similaire sur deux **chaînes**.
conditionnel
Quelque chose « d'incertain ». Voir **contexte booléen**.
connexion
En téléphonie, le circuit électrique temporaire entre le téléphone de l'appelant et celui de l'appelé. En réseau, le même type de circuit temporaire entre un **client** et un **serveur**.
construire
En tant que nom, un élément de syntaxe composé de plus petits éléments. En tant que verbe transitif, créer un **objet** en utilisant un **constructeur**.
constructeur
Toute **méthode de classe**, **instance** ou **sous-routine** qui compose, initialise, bénit et retourne un **objet**. Parfois, nous utilisons le terme de manière plus lâche pour désigner un **compositeur**.
contexte
Les environs ou l'environnement. Le contexte donné par le code environnant détermine le type de données qu'une **expression** particulière est censée retourner. Les trois contextes principaux sont le **contexte de liste**, le **scalaire** et le **contexte vide**. Le contexte scalaire est parfois subdivisé en **contexte booléen**, **contexte numérique**, **contexte de chaîne** et **contexte vide**. Il existe également un contexte « peu importe » (qui est traité dans le Chapitre 2 du Manuel (Camel), « Morceaux et bouts », si cela vous intéresse).
continuation
Le traitement de plusieurs **lignes** physiques comme une seule ligne logique. Les lignes de **Makefile** sont continuées en plaçant une barre oblique inverse avant le **nouvel interligne**. Les en-têtes de courrier, tels que définis par la RFC 822, sont continués en plaçant une espace ou une tabulation *après* le nouvel interligne. En général, les lignes de Perl n'ont pas besoin de marque de continuation, car les **espaces blancs** (y compris les nouveaux interlignes) sont joyeusement ignorés. Habituellement.
core dump
Le cadavre d'un **processus**, sous la forme d'un fichier laissé dans le **répertoire de travail** du processus, généralement à la suite de certains types d'erreurs fatales.
CPAN
Le Comprehensive Perl Archive Network. (Voir la Préface du Manuel (Camel) et le Chapitre 19 du Manuel (Camel), « CPAN », pour plus de détails.)
préprocesseur C
La première passe du compilateur C typique, qui traite les lignes commençant par "#" pour la compilation conditionnelle et la définition de macros, et effectue diverses manipulations du texte du programme en fonction des définitions actuelles. Également connu sous le nom de cpp(1).
cracker
Quelqu'un qui compromet la sécurité des systèmes informatiques. Un cracker peut être un véritable **hacker** ou seulement un **script kiddie**.
canal de sortie actuellement sélectionné
Le dernier **descripteur de fichier** qui a été désigné avec select(FILEHANDLE) ; "STDOUT", si aucun descripteur de fichier n'a été sélectionné.
package actuel
Le **package** dans lequel l'instruction actuelle est **compilée**. Parcourez vers l'arrière dans le texte de votre programme, à travers la **portée lexicale** actuelle ou toute portée lexicale englobante, jusqu'à ce que vous trouviez une déclaration de package. C'est le nom de votre package actuel.
répertoire de travail actuel
Voir **répertoire de travail**.
CV
Dans le monde universitaire, un curriculum vitæ, une sorte de CV sophistiqué. En Perl, une « valeur de code » interne, un type de données contenant une **sous-routine**. Le type "CV" est une sous-classe de **SV**.

D

instruction pendante
Une **instruction** unique et nue, sans accolades, accrochée à une condition "if" ou "while". C l'autorise. Perl ne le fait pas.
datagramme
Un paquet de données, tel qu'un message **UDP**, qui (du point de vue des programmes impliqués) peut être envoyé indépendamment sur le réseau. (En fait, tous les paquets sont envoyés indépendamment au niveau **IP**, mais les protocoles de **flux** comme **TCP** le cachent à votre programme.)
structure de données
Comment vos différentes pièces de données sont liées les unes aux autres et quelle forme elles prennent lorsque vous les assemblez, comme dans une table rectangulaire ou un arbre triangulaire.
type de données
Un ensemble de valeurs possibles, ainsi que toutes les opérations qui savent comment traiter ces valeurs. Par exemple, un type de données numérique a un certain ensemble de nombres avec lesquels vous pouvez travailler, ainsi que diverses opérations mathématiques que vous pouvez effectuer sur les nombres, mais qui n'auraient pas beaucoup de sens sur, disons, une chaîne comme "Kilroy". Les chaînes ont leurs propres opérations, comme la **concaténation**. Les types composés constitués d'un certain nombre de plus petites pièces ont généralement des opérations pour les composer et les décomposer, et peut-être pour les réorganiser. Les **objets** qui modélisent des choses dans le monde réel ont souvent des opérations qui correspondent à des activités réelles. Par exemple, si vous modélisez un ascenseur, votre objet ascenseur pourrait avoir une **méthode** "open_door".
DBM
Abréviation de « Database Management » (gestion de base de données), un ensemble de routines qui émulent un **tableau associatif** à l'aide de fichiers sur disque. Les routines utilisent un schéma de hachage dynamique pour localiser n'importe quelle entrée avec seulement deux accès disque. Les fichiers DBM permettent à un programme Perl de conserver un **hash** persistant entre plusieurs invocations. Vous pouvez « lier » vos variables de hachage à diverses implémentations DBM.
déclaration
Une **affirmation** qui déclare que quelque chose existe et décrit peut-être comment il est, sans s'engager sur la façon ou l'endroit où vous l'utiliserez. Une déclaration est comme la partie de votre recette qui dit : « deux tasses de farine, un gros œuf, quatre ou cinq têtards... » Voir **instruction** pour son opposé. Notez que certaines déclarations fonctionnent également comme des instructions. Les déclarations de sous-routines agissent également comme des définitions si un corps est fourni.
déclarateur
Quelque chose qui indique à votre programme le type de variable que vous souhaitez. Perl ne vous oblige pas à déclarer les variables, mais vous pouvez utiliser "my", "our" ou "state" pour indiquer que vous souhaitez autre chose que la valeur par défaut.

valeur par défaut
Une valeur choisie pour vous si vous n'en fournissez pas une personnellement.
défini
Avoir un sens. Perl considère que certaines choses que les gens essaient de faire sont dénuées de sens ; en particulier, l'utilisation de variables à lesquelles on n'a jamais donné de valeur et l'exécution de certaines opérations sur des données qui n'existent pas. Par exemple, si vous essayez de lire des données au-delà de la fin d'un fichier, Perl vous rendra une valeur indéfinie. Voir aussi faux et l'entrée "defined" dans le chapitre 27 du Manuel (Camel), « Fonctions ».
délimiteur
Un caractère ou une chaîne de caractères qui borne un objet textuel de taille arbitraire, à ne pas confondre avec un séparateur ou un terminateur. « Délimiter » signifie en réalité « entourer » ou « encadrer » (comme le font ces parenthèses).
déréférencer
Un terme sophistiqué de l'informatique signifiant « suivre une référence jusqu'à ce qu'elle pointe » . La partie « dé » fait référence au fait que vous retirez un niveau d'indirection.
classe dérivée
Une classe qui définit certaines de ses méthodes en termes d'une classe plus générique, appelée classe de base. Notez que les classes ne sont pas classées exclusivement en classes de base ou classes dérivées : une classe peut fonctionner à la fois comme classe dérivée et comme classe de base simultanément, ce qui est plutôt classe.
descripteur
Voir descripteur de fichier.
détruire
Libérer la mémoire d'un référencé (en déclenchant d'abord sa méthode "DESTROY", si elle existe).
destructeur
Une méthode spéciale qui est appelée lorsqu'un objet pense à se détruire. La méthode "DESTROY" d'un programme Perl ne fait pas la destruction effective ; Perl déclenche simplement la méthode au cas où la classe voudrait effectuer un nettoyage associé.
périphérique
Un appareil matériel sophistiqué (comme un disque dur, une bande, un modem, un joystick ou une souris) connecté à votre ordinateur, que le système d'exploitation essaie de faire ressembler à un fichier (ou à un ensemble de fichiers). Sous Unix, ces faux fichiers ont tendance à résider dans le répertoire /dev.
directive
Une directive pod. Voir le chapitre 23 du Manuel (Camel), « Plain Old Documentation ».
répertoire
Un fichier spécial qui contient d'autres fichiers. Certains systèmes d'exploitation les appellent « dossiers », « tiroirs », « catalogues ».
directory handle
Un nom qui représente une instance particulière d'ouverture d'un répertoire pour le lire, jusqu'à ce que vous le fermiez. Voir la fonction "opendir".
discipline
Certaines personnes en ont besoin et d'autres l'évitent. Pour Perl, c'est une ancienne façon de dire couche d'E/S.
distribution
Envoyer quelque chose à sa destination correcte. Souvent utilisé métaphoriquement pour indiquer un transfert de contrôle de programme vers une destination sélectionnée algorithmiquement, souvent par consultation d'une table de références de fonctions ou, dans le cas de méthodes d'objets, en parcourant l'arbre d'héritage à la recherche de la définition la plus spécifique pour la méthode.
distribution
Une version standard et groupée d'un système logiciel. L'usage par défaut implique que le code source est inclus. Si ce n'est pas le cas, elle sera appelée une distribution « binaire uniquement ».
double résidence
Certains modules résident à la fois dans la Bibliothèque Standard et sur CPAN. Ces modules peuvent être développés sur deux pistes car les gens modifient l'une ou l'autre version. La tendance actuelle est de démêler ces situations.
dweomer
Un enchantement, une illusion, un fantasme ou une jonglerie. Dit lorsque les effets magiques dwimmer de Perl ne font pas ce que vous attendez, mais semblent plutôt être le produit d'un artisanat magique, d'un sortilège ou d'une merveille occulte. [Du moyen anglais.]
dwimmer
DWIM est un acronyme pour « Do What I Mean » (Fais ce que je veux dire), le principe selon lequel quelque chose devrait simplement faire ce que vous voulez sans trop de complications. Un bout de code qui fait du « dwimming » est un « dwimmer ». Le dwimming peut nécessiter beaucoup de magie en arrière-plan, qui (si elle ne reste pas correctement en arrière-plan) est alors appelée un dweomer.
portée dynamique
La portée dynamique fonctionne sur une portée dynamique, rendant les variables visibles dans le reste du bloc dans lequel elles sont utilisées pour la première fois et dans toutes les sous-routines qui sont appelées par le reste du bloc. Les variables à portée dynamique peuvent voir leurs valeurs temporairement modifiées (et implicitement restaurées plus tard) par un opérateur "local". (Comparer avec la portée lexicale.) Utilisé plus largement pour signifier comment une sous-routine qui est en train d'en appeler une autre « contient » cette sous-routine au moment de l'exécution.

Dérivé de nombreuses sources. Certains diraient trop nombreuses.
élément
Un bloc de construction de base. Lorsque vous parlez d'un tableau, il s'agit de l'un des éléments qui composent le tableau.
intégration
Lorsqu'une chose est contenue dans une autre, en particulier lorsque cela peut être considéré comme surprenant : « J'ai intégré un interpréteur Perl complet dans mon éditeur ! »
test de sous-classe vide
L'idée qu'une classe dérivée vide devrait se comporter exactement comme sa classe de base.
encapsulation
Le voile d'abstraction séparant l'interface de l'implémentation (qu'elle soit imposée ou non), qui impose que tout accès à l'état d'un objet se fasse uniquement par le biais des méthodes.
boutisme
Voir petit-boutiste et gros-boutiste.
en passant
Lorsque vous modifiez une valeur pendant qu'elle est copiée. [Du français « en passant », comme dans la manœuvre exotique de capture de pion aux échecs.]
environnement
L'ensemble collectif des variables d'environnement que votre processus hérite de son parent. Accessible via %ENV.
environment variable
Un mécanisme par lequel un agent de haut niveau, tel qu'un utilisateur, peut transmettre ses préférences à ses futurs descendants (processus enfants, petits-enfants, arrière-petits-enfants, et ainsi de suite). Chaque variable d'environnement est une paire clé/valeur, comme une entrée dans une table de hachage.
EOF
Fin de fichier. Parfois utilisé métaphoriquement comme chaîne de terminaison d'un document ici.
errno
Le numéro d'erreur renvoyé par un appel système en cas d'échec. Perl fait référence à l'erreur par le nom $! (ou $OS_ERROR si vous utilisez le module English).
erreur
Voir exception ou erreur fatale.
séquence d'échappement
Voir métasymbole.
exception
Un terme sophistiqué pour une erreur. Voir erreur fatale.
exception handling
La manière dont un programme répond à une erreur. Le mécanisme de gestion des exceptions dans Perl est l'opérateur "eval".
exécuter (exec)
Jeter le programme du processus actuel et le remplacer par un autre, sans quitter le processus ni abandonner les ressources détenues (à l'exception de l'ancienne image mémoire).
fichier exécutable
Un fichier qui est spécialement marqué pour indiquer au système d'exploitation qu'il est acceptable d'exécuter ce fichier comme un programme. Généralement abrégé en « exécutable ».
exécuter
Lancer un programme ou une sous-routine. (N'a rien à voir avec la fonction intégrée "kill", sauf si vous essayez d'exécuter un gestionnaire de signaux.)
execute bit
La marque spéciale qui indique au système d'exploitation qu'il peut exécuter ce programme. Il existe en fait trois bits d'exécution sous Unix, et le bit utilisé dépend de si vous possédez le fichier individuellement, collectivement, ou pas du tout.
statut de sortie
Voir statut.
exploit
Utilisé ici comme nom, cela fait référence à une manière connue de compromettre un programme pour le faire faire quelque chose que l'auteur n'avait pas prévu. Votre tâche est d'écrire des programmes inexploitables.
exporter
Rendre des symboles d'un module disponibles pour l'importation par d'autres modules.
expression
Tout ce que vous pouvez légalement dire dans un endroit où une valeur est requise. Typiquement composé de littéraux, de variables, d'opérateurs, de fonctions et d'appels de sous-routines, pas nécessairement dans cet ordre.
e
extension
Un module Perl qui inclut également du code C ou C++ compilé. Plus généralement, toute option expérimentale pouvant être compilée dans Perl, comme le multithreading.

F

false
En Perl, toute valeur qui ressemblerait à "" ou "0" si évaluée dans un contexte de chaîne. Puisque les valeurs indéfinies s'évaluent en "", toutes les valeurs fausses sont indéfinies, mais toutes les valeurs fausses ne sont pas indéfinies.
FAQ
Foire Aux Questions (bien que pas nécessairement fréquemment répondue, surtout si la réponse apparaît dans la FAQ Perl fournie en standard avec Perl).
erreur fatale
Une exception non interceptée, qui provoque la terminaison du processus après l'affichage d'un message sur votre flux d'erreur standard. Les erreurs qui se produisent à l'intérieur d'un "eval" ne sont pas fatales. Au lieu de cela, l'"eval" se termine après avoir placé le message d'exception dans la variable $@ ($EVAL_ERROR). Vous pouvez essayer de provoquer une erreur fatale avec l'opérateur "die" (connu sous le nom de lancer ou lever une exception), mais cela peut être intercepté par un "eval" englobant dynamiquement. Si elle n'est pas interceptée, le "die" devient une erreur fatale.
feeping creaturism
Un calembour sur « creeping featurism » (l'ajout progressif de fonctionnalités), notant l'envie biologique d'ajouter juste une fonctionnalité de plus à un programme.
champ
Un seul élément de données numérique ou textuelle qui fait partie d'une chaîne, d'un enregistrement ou d'une ligne plus longue. Les champs de largeur variable sont généralement séparés par des séparateurs (donc utilisez "split" pour extraire les champs), tandis que les champs de largeur fixe sont généralement à des positions fixes (donc utilisez "unpack"). Les variables d'instance sont également connues sous le nom de « champs ».
FIFO
First In, First Out (Premier entré, premier sorti). Voir aussi LIFO. Également un surnom pour un tube nommé.
fichier
Une collection de données nommée, généralement stockée sur disque dans un répertoire d'un système de fichiers. Semblable à un document, si vous aimez les métaphores de bureau. Dans les systèmes de fichiers modernes, vous pouvez réellement donner à un fichier plus d'un nom. Certains fichiers ont des propriétés spéciales, comme les répertoires et les périphériques.
descripteur de fichier
Le petit nombre que l'système d'exploitation utilise pour suivre le fichier ouvert dont vous parlez. Perl cache le descripteur de fichier dans un flux d'E/S standard et attache ensuite le flux à un manche de fichier.
fileglob
Une correspondance de type « joker » sur les noms de fichiers. Voir la fonction "glob".
manche de fichier
Un identifiant (pas nécessairement lié au nom réel d'un fichier) qui représente une instance particulière d'ouverture d'un fichier, jusqu'à sa fermeture. Si vous prévoyez d'ouvrir et de fermer plusieurs fichiers différents successivement, il est possible de les ouvrir tous avec le même manche de fichier, vous évitant ainsi d'écrire du code distinct pour traiter chaque fichier.
nom de fichier
Un nom pour un fichier. Ce nom est répertorié dans un répertoire. Vous pouvez l'utiliser dans un "open" pour indiquer précisément au système d'exploitation quel fichier vous souhaitez ouvrir, et associer le fichier à un manche de fichier, qui portera l'identité ultérieure de ce fichier dans votre programme, jusqu'à sa fermeture.
système de fichiers
Un ensemble de répertoires et de fichiers résidant sur une partition du disque. Parfois appelé « partition ». Vous pouvez changer le nom d'un fichier ou même déplacer un fichier d'un répertoire à un autre au sein d'un système de fichiers sans réellement déplacer le fichier lui-même, du moins sous Unix.
opérateur de test de fichier
Un opérateur unaire intégré que vous utilisez pour déterminer si quelque chose est vrai à propos d'un fichier, tel que –o $filename pour tester si vous êtes le propriétaire du fichier.
filtre
Un programme conçu pour prendre un flux d'entrée et le transformer en un flux de sortie.
premier arrivé
Le premier auteur PAUSE à télécharger un espace de noms devient automatiquement le principal mainteneur de cet espace de noms. Les permissions « premier arrivé » distinguent un mainteneur principal qui s'est vu attribuer ce rôle de celui qui l'a reçu automatiquement.
indicateur
Nous avons tendance à éviter ce terme car il signifie tellement de choses. Il peut signifier un commutateur de ligne de commande qui ne prend pas d'argument lui-même (comme les indicateurs "–n" et "–p" de Perl) ou, moins fréquemment, un indicateur à un seul bit (comme les indicateurs "O_CREAT" et "O_EXCL" utilisés dans "sysopen"). Parfois utilisé informellement pour désigner certains modificateurs d'expression régulière.
virgule flottante
Une méthode de stockage des nombres en « notation scientifique », de sorte que la précision du nombre est indépendante de sa magnitude (le point décimal « flotte »). Perl effectue ses calculs numériques avec des nombres à virgule flottante (parfois appelés « flottants ») lorsqu'il ne peut pas s'en sortir avec des entiers. Les nombres à virgule flottante ne sont que des approximations des nombres réels.
vider
L'acte de vider un tampon, souvent avant qu'il ne soit plein.
FMTEYEWTK
Far More Than Everything You Ever Wanted To Know (Beaucoup plus que tout ce que vous avez jamais voulu savoir). Un traité exhaustif sur un sujet étroit, une sorte de super-FAQ. Demandez à Tom pour en savoir beaucoup plus.
foldcase
La casse utilisée en Unicode lors de la comparaison ou de la correspondance sans tenir compte de la casse. La comparaison en minuscules, en capitales ou en majuscules est peu fiable en raison des correspondances de casse complexes et de un à plusieurs de Unicode. Foldcase est une variante en minuscule (utilisant une forme de normalisation partiellement décomposée pour certains points de code) créée spécifiquement pour résoudre ce problème.
fork
Créer un processus enfant identique au processus parent au moment de sa conception, du moins jusqu'à ce qu'il ait ses propres idées. Un thread avec mémoire protégée.
arguments formels
Les noms génériques par lesquels une sous-routine connaît ses arguments. Dans de nombreux langages, les arguments formels reçoivent toujours des noms individuels ; en Perl, les arguments formels sont simplement les éléments d'un tableau. Les arguments formels d'un programme Perl sont $ARGV[0], $ARGV[1], et ainsi de suite. De même, les arguments formels d'une sous-routine Perl sont $_[0], $_[1], et ainsi de suite. Vous pouvez donner des noms individuels aux arguments en assignant les valeurs à une liste "my". Voir aussi arguments réels.
format
Une spécification indiquant combien d'espaces, de chiffres et d'autres éléments placer quelque part afin que ce que vous imprimez soit joli et bien présenté.
disponible gratuitement
Signifie que vous n'avez pas à payer pour l'obtenir, mais le droit d'auteur peut toujours appartenir à quelqu'un d'autre (comme Larry).
gratuitement redistribuable
Signifie que vous n'aurez pas de problèmes légaux si vous donnez une copie pirate à vos amis et que nous le découvrons. En fait, nous préférerions que vous donniez une copie à tous vos amis.
freeware
Historiquement, tout logiciel que vous distribuez gratuitement, surtout si vous mettez également le code source à disposition. Maintenant souvent appelé logiciel open source. Récemment, il y a eu une tendance à utiliser le terme en opposition au logiciel open source, pour ne désigner que les logiciels gratuits publiés sous la licence GPL (General Public License) de la Free Software Foundation, mais cela est difficile à justifier étymologiquement.
fonction
Mathématiquement, une application de chaque valeur d'un ensemble d'entrées à une valeur de sortie particulière. En informatique, fait référence à une sous-routine ou un opérateur qui renvoie une valeur. Il peut avoir ou non des valeurs d'entrée (appelées arguments).
caractère amusant
Quelqu'un comme Larry, ou l'un de ses amis particuliers. Fait également référence aux préfixes étranges que Perl exige comme marqueurs de nom sur ses variables.

G

ramasse-miettes
Une fonctionnalité mal nommée - elle devrait s'appeler « s'attendre à ce que votre mère nettoie après vous ». Strictement parlant, Perl ne fait pas cela, mais il s'appuie sur un mécanisme de comptage de références pour maintenir les choses en ordre. Cependant, nous parlons rarement strictement et ferons souvent référence au système de comptage de références comme une forme de ramasse-miettes. (Si cela peut vous rassurer, lorsque votre interpréteur se termine, un « vrai » ramasse-miettes s'exécute pour s'assurer que tout est nettoyé si vous avez été désordonné avec des références circulaires et autres.)
GID
Group ID (identifiant de groupe) - sous Unix, l'identifiant de groupe numérique que le système d'exploitation utilise pour vous identifier, vous et les membres de votre groupe.
glob

glob
Générer une liste de noms de fichiers. De manière générale, l'acte d'utiliser des jokers et des symboles similaires pour effectuer une correspondance de motifs. Voir aussi fileglob et typeglob.
global

En Perl, seules certaines variables spéciales sont vraiment globales ; la plupart des variables (et toutes les sous-routines) n'existent que dans le package courant. Les variables globales peuvent être déclarées avec "our". Voir « Déclarations globales » au chapitre 4 du livre Le Caméléon, « Instructions et déclarations ».

La ramasse-miettes des globales (et l'exécution des destructeurs d'objets associés) qui se produit lorsqu'un interpréteur Perl est en cours d'arrêt. La destruction globale ne doit pas être confondue avec l'Apocalypse, sauf peut-être lorsqu'elle devrait l'être.
langage de collage
Un langage tel que Perl qui est bon pour relier des choses qui n'étaient pas prévues pour être reliées.
granularité
La taille des morceaux avec lesquels vous traitez, en termes mentaux.
grapheme
Un graphène est un allotrope de carbone arrangé en un réseau cristallin hexagonal épais d'un atome. Un grapheme, ou plus complètement, une chaîne de cluster graphemique est un seul caractère visible par l'utilisateur, qui peut à son tour être constitué de plusieurs caractères (codepoints). Par exemple, un retour chariot plus un saut de ligne forme un seul grapheme mais deux caractères, tandis qu'un « ñ » est un seul grapheme mais un, deux, voire trois caractères, selon la normalisation.
gourmand
Un sous-motif dont le quantificateur veut faire correspondre autant d'éléments que possible.
grep
Issu à l'origine de l'ancienne commande de l'éditeur Unix pour « Rechercher globalement une expression régulière et l'imprimer », maintenant utilisé dans le sens général de toute sorte de recherche, en particulier les recherches de texte. Perl possède une fonction "grep" intégrée qui recherche dans une liste les éléments correspondant à un critère donné, tandis que le programme grep(1) recherche les lignes correspondant à une expression régulière dans un ou plusieurs fichiers.
groupe
Un ensemble d'utilisateurs dont vous faites partie. Dans certains systèmes d'exploitation (comme Unix), vous pouvez accorder certaines permissions d'accès aux fichiers à d'autres membres de votre groupe.
GV
Un type typedef interne « valeur de glob », contenant un typeglob. Le type "GV" est une sous-classe de SV.

H

hacker
Quelqu'un qui est brillamment persévérant pour résoudre des problèmes techniques, qu'il s'agisse de golf, de combat d'orcs ou de programmation. Hacker est un terme neutre, moralement parlant. Les bons hackers ne doivent pas être confondus avec les crackers maléfiques ou les script kiddies ignorants. Si vous les confondez, nous présumerons que vous êtes soit maléfique, soit ignorant.
gestionnaire
Une sous-routine ou une méthode que Perl appelle lorsque votre programme doit répondre à un événement interne, tel qu'un signal, ou la rencontre d'un opérateur soumis à la surcharge d'opérateurs. Voir aussi callback.
référence forte
Une valeur scalaire contenant l'adresse réelle d'un référent, de telle sorte que le compte de références du référent en tienne compte. (Certaines références fortes sont détenues en interne, comme la référence implicite d'une des cellules de variable d'un typeglob à son référent correspondant.) Une référence forte est différente d'une référence symbolique.
hash
Une association non ordonnée de paires clé/valeur, stockée de manière à ce que vous puissiez facilement utiliser une clé de chaîne de caractères pour rechercher sa valeur de données associée. Ce glossaire est comme un hash, où le mot à définir est la clé et la définition est la valeur. Un hash est aussi parfois appelé, en septisyllabisme, un « tableau associatif », ce qui est une assez bonne raison pour simplement l'appeler un « hash » à la place.
table de hachage
Une structure de données utilisée en interne par Perl pour implémenter efficacement les tableaux associatifs (hashes). Voir aussi bucket.
fichier d'en-tête
Un fichier contenant certaines définitions requises que vous devez inclure « avant » le reste de votre programme pour effectuer certaines opérations obscures. Un fichier d'en-tête C a une extension .h. Perl n'a pas vraiment de fichiers d'en-tête, bien qu'historiquement Perl ait parfois utilisé des fichiers .h traduits avec une extension .ph. Voir "require" au chapitre 27 du livre Le Caméléon, « Fonctions ». (Les fichiers d'en-tête ont été remplacés par le mécanisme de module.)
document ici
Appelé ainsi en raison d'un construct similaire dans les shells qui prétend que les lignes suivant la commande sont un fichier séparé à fournir à la commande, jusqu'à une certaine chaîne terminante. En Perl, cependant, c'est juste une forme sophistiquée de guillemets.
hexadécimal
Un nombre en base 16, « hex » pour faire court. Les chiffres de 10 à 15 sont habituellement représentés par les lettres "a" à "f". Les constantes hexadécimales en Perl commencent par "0x". Voir aussi la fonction "hex" au chapitre 27 du livre Le Caméléon, « Fonctions ».
répertoire personnel
Le répertoire dans lequel vous êtes placé lorsque vous vous connectez. Sur un système Unix, le nom est souvent placé dans $ENV{HOME} ou $ENV{LOGDIR} par login, mais vous pouvez aussi le trouver avec "(get""pwuid($<))[7]". (Certaines plateformes n'ont pas le concept de répertoire personnel.)
hôte
L'ordinateur sur lequel réside un programme ou d'autres données.
hubris
Un orgueil excessif, le genre de chose pour lequel Zeus vous punit. C'est aussi la qualité qui vous pousse à écrire (et maintenir) des programmes sur lesquels d'autres personnes ne voudront pas dire de mauvaises choses. Par conséquent, la troisième grande vertu d'un programmeur. Voir aussi laziness et impatience.
HV
Abréviation d'un type typedef « valeur de hachage », qui contient la représentation interne d'un hash par Perl. Le type "HV" est une sous-classe de SV.

I

identificateur
Un nom légalement formé pour la plupart des choses auxquelles un programme informatique pourrait s'intéresser. De nombreux langages (y compris Perl) permettent aux identificateurs de commencer par un caractère alphabétique, puis de contenir des lettres et des chiffres. Perl autorise également la ponctuation de connexion comme le caractère de soulignement là où il autorise les lettres. (Perl a également des noms plus compliqués, comme les noms qualifiés.)
impatience
La colère que vous ressentez lorsque l'ordinateur est paresseux. Cela vous pousse à écrire des programmes qui ne se contentent pas de réagir à vos besoins, mais qui les anticipent réellement. Ou du moins qui prétendent le faire. Par conséquent, la deuxième grande vertu d'un programmeur. Voir aussi laziness et hubris.
implémentation
La manière dont un morceau de code accomplit réellement son travail. Les utilisateurs du code ne devraient pas s'attendre à ce que les détails d'implémentation restent les mêmes, à moins qu'ils ne fassent partie de l'interface publiée.
importer
Pour obtenir l'accès à des symboles qui sont exportés depuis un autre module. Voir "use" au chapitre 27 du livre Le Caméléon, « Fonctions ».
incrémenter
Augmenter la valeur de quelque chose de 1 (ou d'un autre nombre, si spécifié).
indexation
Dans les temps anciens, l'acte de rechercher une clé dans un index réel (comme un annuaire téléphonique). Mais maintenant, c'est simplement l'acte d'utiliser n'importe quel type de clé ou de position pour trouver la valeur correspondante, même si aucun index n'est impliqué. Les choses ont dégénéré au point que la fonction "index" de Perl localise simplement la position (index) d'une chaîne dans une autre.

indirection
Si quelque chose dans un programme n'est pas la valeur que vous recherchez, mais indique où se trouve la valeur, c'est de l'indirection. Cela peut être fait soit avec des références symboliques, soit avec des références fortes.
objet indirect
En grammaire anglaise, un court groupe nominal entre un verbe et son objet direct indiquant le bénéficiaire ou le destinataire de l'action. En Perl, "print STDOUT "$foo\n";" peut être compris comme « verbe objet-indirect objet », où "STDOUT" est le destinataire de l'action "print", et "$foo" est l'objet qui est imprimé. De même, lors de l'invocation d'une méthode, vous pourriez placer l'invocant dans la position dative entre la méthode et ses arguments : 
$gollum = new Pathetic::Creature "Sméagol";
give $gollum "Fisssssh!";
give $gollum "Precious!";

t>
La position syntaxique située entre un appel de méthode et ses arguments lors de l'utilisation de la syntaxe d'invocation d'objet indirect. (La position est distinguée par l'absence de virgule entre elle et l'argument suivant.) "STDERR" est dans la position d'objet indirect ici :

infix
Un opérateur qui se place entre ses opérandes, comme la multiplication dans "24 * 7".
héritage
Ce que l'on obtient de ses ancêtres, génétiquement ou autrement. Si vous êtes une classe, vos ancêtres sont appelés classes de base et vos descendants sont appelés classes dérivées. Voir héritage simple et héritage multiple.

Abréviation de « une instance d'une classe », signifiant un objet de cette classe.
données d'instance
Voir variable d'instance.

Une méthode d'un objet, par opposition à une méthode de classe.

Une méthode dont l'invocant est un objet, et non un nom de package. Chaque objet d'une classe partage toutes les méthodes de cette classe, donc une méthode d'instance s'applique à toutes les instances de la classe, plutôt qu'à une instance particulière. Voir aussi méthode de classe.

variable d'instance
Un attribut d'un objet ; données stockées avec l'objet particulier plutôt qu'avec la classe dans son ensemble.
entier
Un nombre sans partie fractionnaire (décimale). Un nombre entier naturel, comme 1, 2, 3, etc., mais incluant 0 et les négatifs.
interface
Les services qu'un morceau de code promet de fournir à jamais, par opposition à son implémentation, qu'il devrait se sentir libre de modifier quand il le souhaite.
interpolation
L'insertion d'une valeur scalaire ou de liste quelque part au milieu d'une autre valeur, de sorte qu'elle semble y avoir toujours été. En Perl, l'interpolation de variable se produit dans les chaînes de caractères entre guillemets doubles et les motifs, et l'interpolation de liste se produit lors de la construction de la liste de valeurs à passer à un opérateur de liste ou à une autre construction similaire qui prend une "LIST".
interpréteur
Strictement parlant, un programme qui lit un second programme et exécute ce que dit le second programme directement sans transformer d'abord le programme sous une forme différente, ce que font les compilateurs. Perl n'est pas un interpréteur selon cette définition, car il contient une sorte de compilateur qui prend un programme et le transforme en une forme plus exécutable (arbres syntaxiques) au sein du processus perl lui-même, que le système d'exécution Perl interprète ensuite.
invocant
L'agent pour le compte duquel une méthode est invoquée. Dans une méthode de classe, l'invocant est un nom de package. Dans une méthode d'instance, l'invocant est une référence d'objet.
invocation
L'acte d'appeler une divinité, un démon, un programme, une méthode, une sous-routine ou une fonction pour la faire faire ce que vous pensez qu'elle est censée faire. Nous « appelons » généralement les sous-routines mais « invoquons » les méthodes, car cela sonne mieux.
E/S
Entrée depuis, ou sortie vers, un fichier ou un périphérique.
IO
Un objet d'E/S interne. Peut aussi signifier objet indirect.
couche E/S
Un des filtres entre les données et ce que vous obtenez en entrée ou ce que vous obtenez en sortie.
IPA
India Pale Ale. Également l'Alphabet Phonétique International, l'alphabet standard utilisé pour la notation phonétique dans le monde entier. Repose largement sur Unicode, y compris de nombreux caractères de combinaison.
IP
Internet Protocol, ou Propriété Intellectuelle.
IPC
Communication InterProcessus.
est-un
Une relation entre deux objets dans laquelle un objet est considéré comme une version plus spécifique de l'objet générique : « Un chameau est un mammifère. » Puisque l'objet générique n'existe réellement que dans un sens platonique, nous ajoutons généralement une légère abstraction à la notion d'objets et pensons que la relation existe entre une classe de base générique et une classe dérivée spécifique. Curieusement, les classes platoniques n'ont pas toujours des relations platoniques, voir héritage.
itération
Faire quelque chose de manière répétée.
itérateur
Un gadget de programmation spécial qui garde une trace de votre position dans quelque chose que vous essayez d'itérer. La boucle "foreach" en Perl contient un itérateur ; de même qu'une table de hachage, vous permettant de "each" à travers elle.
IV
L'entier quatre, à ne pas confondre avec six, l'éditeur préféré de Tom. IV signifie également une valeur entière interne du type qu'un scalaire peut contenir, à ne pas confondre avec un NV.

paresse

Elle vous pousse à écrire des programmes qui font gagner du temps et que d'autres personnes trouveront utiles, puis à documenter ce que vous avez écrit afin de ne pas avoir à répondre à autant de questions à ce sujet. Par conséquent, la première grande vertu d'un programmeur. D'où aussi, ce livre. Voir aussi impatience et hubris.
le plus à gauche le plus long
La préférence du moteur d'expressions régulières pour faire correspondre l'occurrence la plus à gauche d'un motif, puis étant donné une position à laquelle une correspondance se produit, la préférence pour la correspondance la plus longue (en supposant l'utilisation d'un quantificateur gourmand). portée lexicale
Regarder votre dictionnaire Oxford English à travers un microscope. (Aussi connu sous le nom de portée statique, car les dictionnaires ne changent pas très vite.) De même, regarder les variables stockées dans un dictionnaire privé (espace de noms) pour chaque portée, qui ne sont visibles qu'à partir de leur point de déclaration jusqu'à la fin de la portée lexicale dans laquelle elles sont déclarées. — Syn. portée statique. — Ant. portée dynamique.
variable lexicale
Une variable soumise à la portée lexicale, déclarée par "my". Souvent appelée simplement « lexicale ». (La déclaration "our" déclare un nom à portée lexicale pour une variable globale, qui n'est pas elle-même une variable lexicale.)
bibliothèque
Généralement, une collection de procédures. Dans les temps anciens, faisait référence à une collection de sous-routines dans un fichier .pl. À l'époque moderne, fait plus souvent référence à la collection entière de modules Perl sur votre système.
LIFO
Last In, First Out (Dernier entré, premier sorti). Voir aussi FIFO. Un LIFO est généralement appelé une pile.
ligne
Dans Unix, une séquence de zéro ou plusieurs caractères non-nouvelle ligne terminée par un caractère de nouvelle ligne. Sur les machines non-Unix, ceci est émulé par la bibliothèque C même si le système d'exploitation sous-jacent a des idées différentes.
saut de ligne
Un graphème constitué soit d'un retour chariot suivi d'un saut de ligne, soit de tout caractère ayant la propriété de caractère d'espace vertical Unicode.
buffer de ligne
Utilisé par un flux de sortie d'E/S standard qui vide son buffer après chaque nouvelle ligne. De nombreuses bibliothèques d'E/S standard configurent automatiquement le buffer de ligne pour les sorties destinées au terminal.
numéro de ligne
Le nombre de lignes lues précédemment, plus 1. Perl maintient un numéro de ligne distinct pour chaque fichier source ou fichier d'entrée qu'il ouvre. Le numéro de ligne du fichier source actuel est représenté par "__LINE__". Le numéro de ligne d'entrée actuel (pour le fichier qui a été le plus récemment lu via "<FH>") est représenté par la variable $. ($INPUT_LINE_NUMBER). De nombreux messages d'erreur signalent les deux valeurs, si elles sont disponibles.

link
Un nom dans un répertoire qui représente un fichier. Un fichier donné peut avoir plusieurs liens vers lui. C'est comme avoir le même numéro de téléphone répertorié dans l'annuaire sous différents noms. L'édition de liens peut généralement être statique ou dynamique, ce qui n'a rien à voir avec la portée statique ou dynamique.
LIST
Une construction syntaxique représentant une liste d'expressions séparées par des virgules, évaluée pour produire une valeur de liste. Chaque expression d'une "LIST" est évaluée dans un contexte de liste et interpolée dans la valeur de liste.
list
Un ensemble ordonné de valeurs scalaires.
list context
La situation dans laquelle une expression est censée, par son environnement (le code qui l'appelle), retourner une liste de valeurs plutôt qu'une seule valeur. list operator
Un opérateur qui effectue une action sur une liste de valeurs, telle que "join" ou "grep". Généralement utilisé pour des opérateurs intégrés nommés (tels que "print", "unlink" et "system") qui ne nécessitent pas de parenthèses autour de leur liste d'arguments.
list value
Une liste sans nom de valeurs scalaires temporaires qui peut être transmise dans un programme de toute fonction générant une liste à toute fonction ou construction qui fournit un contexte de liste.
literal
Un jeton dans un langage de programmation, tel qu'un nombre ou une chaîne, qui vous donne une valeur réelle au lieu de simplement représenter des valeurs possibles comme le fait une variable.
little-endian
D'après Swift : quelqu'un qui mange ses œufs par le petit bout. Souvent considéré comme supérieur aux machines big-endian. Voir aussi big-endian.

lookahead

loop
Une construction qui effectue quelque chose de manière répétée, comme des montagnes russes.

Toute instruction au sein du corps d'une boucle qui peut faire arrêter prématurément une boucle ou sauter une itération. Généralement, vous ne devriez pas essayer cela sur des montagnes russes.

Une sorte de clé ou de nom attaché à une boucle (ou des montagnes russes) afin que les instructions de contrôle de boucle puissent spécifier quelle boucle elles souhaitent contrôler.

En Unicode, pas seulement les caractères ayant la Catégorie Générale de Lettre Minuscule, mais tout caractère ayant la propriété Minuscule, y compris les Lettres Modificatrices, les Nombres Lettres, certains Autres Symboles, et une Marque Combinante.

memory
Cela désigne toujours votre mémoire principale, pas votre disque. La confusion vient du fait que votre machine peut implémenter une mémoire virtuelle ; c'est-à-dire qu'elle prétendra avoir plus de mémoire qu'elle n'en a réellement, et utilisera de l'espace disque pour contenir les bits inactifs. Cela peut donner l'impression d'avoir un peu plus de mémoire que ce que vous avez réellement, mais ce n'est pas un substitut à la mémoire réelle. La meilleure chose que l'on puisse dire de la mémoire virtuelle est qu'elle permet à vos performances de se dégrader progressivement plutôt que soudainement lorsque vous manquez de mémoire réelle. Mais votre programme peut aussi planter lorsque vous manquez de mémoire virtuelle, si vous n'avez pas d'abord mis votre disque à mort à force de "thrashing".
metacharacter

method

Votre programme peut demander à un objet de faire des choses, mais c'est l'objet qui décide s'il veut les faire ou non. Certains objets sont plus accommodants que d'autres.

Combien d'éléments vous devez ignorer lorsque vous passez du début d'une chaîne ou d'un tableau à une position spécifique à l'intérieur. Ainsi, le décalage minimum est zéro, pas un, car vous n'ignorez rien pour atteindre le premier élément.
one-liner
Un programme informatique entier condensé en une seule ligne de texte.

opérande
Une expression qui produit une valeur sur laquelle un opérateur opère. Voir aussi précédence.
système d'exploitation
Un programme spécial qui s'exécute sur la machine nue et cache les détails complexes de la gestion des processus et des périphériques. Généralement utilisé dans un sens plus large pour indiquer une culture de programmation particulière. Le sens large peut être utilisé à différents niveaux de spécificité. À une extrémité, vous pourriez dire que toutes les versions d'Unix et de ses imitateurs sont le même système d'exploitation (fâchant de nombreuses personnes, en particulier les avocats et autres défenseurs). À l'autre extrémité, vous pourriez dire que cette version particulière du système d'exploitation de ce fournisseur particulier est différente de toute autre version du système d'exploitation de ce fournisseur ou de tout autre fournisseur. Perl est beaucoup plus portable sur les systèmes d'exploitation que de nombreux autres langages. Voir aussi architecture et plateforme.
opérateur
Un gadget qui transforme un certain nombre de valeurs d'entrée en un certain nombre de valeurs de sortie, souvent intégré à un langage avec une syntaxe ou un symbole spécial. Un opérateur donné peut avoir des attentes spécifiques quant aux types de données que vous lui donnez en tant qu'arguments (opérandes) et au type de données que vous souhaitez en retour.
surcharge d'opérateurs
Un type de surcharge que vous pouvez effectuer sur les opérateurs intégrés pour les faire fonctionner sur des objets comme si les objets étaient des valeurs scalaires ordinaires, mais avec la sémantique réelle fournie par la classe de l'objet. Ceci est configuré avec le pragma overload — voir le chapitre 13 du Manuel (Camel), « Surcharge ».
options
Voir commutateurs ou modificateurs d'expressions régulières.
ordinal
La valeur entière d'un caractère abstrait. Identique à point de code.
surcharge
Donner des significations supplémentaires à un symbole ou une construction. En fait, tous les langages font de la surcharge à un degré ou à un autre, car les gens sont doués pour comprendre les choses en fonction du contexte.
remplacement
Cacher ou invalider une autre définition du même nom. (À ne pas confondre avec la surcharge, qui ajoute des définitions qui doivent être désambiguïsées d'une autre manière.) Pour compliquer encore les choses, nous utilisons le mot avec deux définitions surchargées : pour décrire comment vous pouvez définir votre propre sous-routine pour cacher une fonction intégrée du même nom (voir la section « Remplacement des fonctions intégrées » du chapitre 11 du Manuel (Camel), « Modules »), et pour décrire comment vous pouvez définir une méthode de remplacement dans une classe dérivée pour cacher une méthode du même nom d'une classe de base (voir le chapitre 12 du Manuel (Camel), « Objets »).
propriétaire
L'utilisateur unique (à part le superutilisateur) qui a un contrôle absolu sur un fichier. Un fichier peut également avoir un groupe d'utilisateurs qui peuvent exercer une propriété conjointe si le propriétaire réel le permet. Voir bits d'autorisation.

P

package
Un espace de noms pour les variables globales, les sous-routines, etc., de manière à ce qu'elles puissent être séparées des symboles de même nom dans d'autres espaces de noms. Dans un sens, seul le package est global, car les symboles dans la table des symboles du package ne sont accessibles depuis le code compilé en dehors du package qu'en nommant le package. Mais dans un autre sens, tous les symboles de package sont également des globales — ce sont juste des globales bien organisées.
tampon
Abréviation de scratchpad.
paramètre
Voir argument.
classe parente
Voir classe de base.
arbre d'analyse syntaxique
Voir arbre syntaxique.
Analyse syntaxique
L'art subtil mais parfois brutal de tenter de transformer votre programme potentiellement mal formé en un arbre syntaxique valide.
Patch
Pour corriger en appliquant un, pour ainsi dire. Dans le monde du hacking, une liste des différences entre deux versions d'un programme, telle qu'elle peut être appliquée par le programme patch(1) lorsque vous souhaitez corriger un bug ou mettre à niveau votre ancienne version.
PATH
La liste des répertoires que le système recherche pour trouver un programme que vous souhaitez exécuter. La liste est stockée comme l'une de vos variables d'environnement, accessible en Perl comme $ENV{PATH}.
Chemin
Un nom de fichier complet tel que /usr/bin/perl. Parfois confondu avec "PATH".
Motif
Un modèle utilisé dans la correspondance de motifs.
correspondance de motifs
Prendre un motif, généralement une expression régulière, et essayer le motif de différentes manières sur une chaîne pour voir s'il y a un moyen de le faire correspondre. Souvent utilisé pour extraire des informations intéressantes d'un fichier.
PAUSE
Le Perl Authors Upload SErver (http://pause.perl.org), la passerelle pour les modules en route vers CPAN.
Perl mongers
Un groupe d'utilisateurs Perl, tirant son nom des Perl mongers de New York, le premier groupe d'utilisateurs Perl. Trouvez-en un près de chez vous sur http://www.pm.org.
bits de permission
Bits que le propriétaire d'un fichier définit ou efface pour autoriser ou interdire l'accès à d'autres personnes. Ces bits de drapeau font partie du mot mode renvoyé par la fonction intégrée "stat" lorsque vous interrogez un fichier. Sur les systèmes Unix, vous pouvez consulter la page de manuel de ls(1) pour plus d'informations.
Pern
Ce que vous obtenez lorsque vous faites "Perl++" deux fois. Le faire une seule fois vous frise les cheveux. Vous devez l'incrémenter huit fois pour vous laver les cheveux. Mousse, rincez, itérez.
Phaser
La durée de vie (chronologie d'exécution) d'un programme est divisée en phases. Un phaser est un bloc de code appelé pendant une phase d'exécution spécifique.
Tube
Une connexion directe qui transporte la sortie d'un processus vers l'entrée d'un autre sans fichier temporaire intermédiaire. Une fois le tube établi, les deux processus en question peuvent lire et écrire comme s'ils parlaient à un fichier normal, avec quelques mises en garde.
Pipeline
Une série de processus alignés, reliés par des tubes, où chacun transmet son flux de sortie au suivant.
Plateforme
Le contexte matériel et logiciel complet dans lequel un programme s'exécute. Un programme écrit dans un langage dépendant de la plateforme pourrait échouer si vous modifiez l'un des éléments suivants : machine, système d'exploitation, bibliothèques, compilateur ou configuration système. L'interpréteur perl doit être compilé différemment pour chaque plateforme car il est implémenté en C, mais les programmes écrits dans le langage Perl sont largement indépendants de la plateforme.
POD
Le balisage utilisé pour intégrer la documentation dans votre code Perl. Pod signifie « Plain old documentation » (Documentation ordinaire). Voir le chapitre 23 du livre du Chameau, « Plain Old Documentation ».
commande pod
Une séquence, telle que "=head1", qui indique le début d'une section pod.
Pointeur
Une variable dans un langage comme le C qui contient l'adresse mémoire exacte d'un autre élément. Perl gère les pointeurs en interne, vous n'avez donc pas à vous en soucier. À la place, vous utilisez simplement des pointeurs symboliques sous forme de clés et de noms de variables, ou de références fortes, qui ne sont pas des pointeurs (mais agissent comme des pointeurs et contiennent en fait des pointeurs).
Polymorphisme
La notion selon laquelle vous pouvez demander à un objet de faire quelque chose de générique, et l'objet interprétera la commande de différentes manières selon son type. [< Grec πολυ- + μορϕή, formes multiples.]
Port
La partie de l'adresse d'une socket TCP ou UDP qui dirige les paquets vers le bon processus après avoir trouvé la bonne machine, un peu comme le numéro de poste que vous donnez lorsque vous atteignez l'opérateur de l'entreprise. Également le résultat de la conversion de code pour qu'il s'exécute sur une plateforme différente de celle initialement prévue, ou le verbe dénotant cette conversion.
Portable
Autrefois, code C compilable sous BSD et SysV. En général, code qui peut être facilement converti pour s'exécuter sur une autre plateforme, où « facilement » peut être défini comme vous le souhaitez, et l'est généralement. N'importe quoi peut être considéré comme portable si vous vous donnez suffisamment de mal, comme une maison mobile ou le pont de Londres.
Porteur
Quelqu'un qui « transporte » un logiciel d'une plateforme à une autre. Le portage de programmes écrits dans des langages dépendants de la plateforme comme le C peut être un travail difficile, mais le portage de programmes comme Perl vaut largement l'agonie.
Possessif
Qualifie les quantificateurs et les groupes dans les motifs qui refusent de lâcher quoi que ce soit une fois qu'ils l'ont obtenu. Plus accrocheur et plus facile à dire que le terme encore plus formel de non-rétroactable.
POSIX
La spécification Portable Operating System Interface.
Postfixé
Un opérateur qui suit son opérande, comme dans "$x++".
pp
Un raccourci interne pour un code « push-pop » ; c'est-à-dire du code C implémentant la machine à pile de Perl.
Pragma
Un module standard dont les indices et suggestions pratiques sont reçus (et potentiellement ignorés) au moment de la compilation. Les pragmas sont nommés en minuscules.
Précédence
Les règles de conduite qui, en l'absence d'autres indications, déterminent ce qui doit se passer en premier. Par exemple, en l'absence de parenthèses, vous effectuez toujours la multiplication avant l'addition.
Préfixé
Un opérateur qui précède son opérande, comme dans "++$x".
Prétraitement
Ce qu'un processus auxiliaire a fait pour transformer les données entrantes dans une forme plus appropriée pour le processus actuel. Souvent effectué avec un tube entrant. Voir aussi préprocesseur C.
mainteneur principal
L'auteur que PAUSE autorise à attribuer des permissions de co-mainteneur à un espace de noms. Un mainteneur principal peut renoncer à cette distinction en l'attribuant à un autre auteur PAUSE. Voir le chapitre 19 du livre du Chameau, « CPAN ».
Procédure
Une sous-routine.
Processus
Une instance d'un programme en cours d'exécution. Sous les systèmes multitâches comme Unix, deux processus ou plus peuvent exécuter le même programme indépendamment en même temps — en fait, la fonction "fork" est conçue pour amener cette situation heureuse. Sous d'autres systèmes d'exploitation, les processus sont parfois appelés « threads », « tâches » ou « jobs », souvent avec de légères nuances de sens.
Programme
Voir script.
générateur de programmes
Un système qui écrit algorithmiquement du code pour vous dans un langage de haut niveau. Voir aussi générateur de code.
correspondance progressive
Correspondance de motifs qui reprend là où elle s'est arrêtée auparavant.
Propriété
Voir variable d'instance ou propriété de caractère.
Protocole
En réseau, une manière convenue d'échanger des messages afin qu'aucun correspondant ne soit trop confus.
Prototype
Une partie facultative d'une déclaration de sous-routine indiquant au compilateur Perl le nombre et le type d'arguments pouvant être passés comme arguments réels, de sorte que vous puissiez écrire des appels de sous-routine qui s'analysent de manière très similaire aux fonctions intégrées. (Ou ne s'analysent pas, selon le cas.)
Pseudofonction
Une construction qui ressemble parfois à une fonction mais n'en est pas vraiment une. Généralement réservée aux modificateurs d'lvalue comme "my", aux modificateurs de contexte comme "scalar", et aux constructions permettant de choisir ses propres guillemets, "q//", "qq//", "qx//", "qw//", "qr//", "m//", "s///", "y///" et "tr///".
Pseudohachage
Anciennement, une référence à un tableau dont le premier élément contenait une référence à un hachage. Vous pouviez auparavant traiter une référence de pseudohachage comme une référence de tableau ou une référence de hachage. Les pseudohachages ne sont plus pris en charge.

domaine public
Quelque chose qui n'appartient à personne. Perl est protégé par copyright et n'est donc *pas* dans le domaine public — il est juste librement disponible et librement redistribuable.
pumpkin
Un "bâton" notionnel passé autour de la communauté Perl indiquant qui est l'intégrateur principal dans un domaine de développement donné.

Un détenteur de pumpkin, la personne en charge de pomper la pompe, ou du moins de l'amorcer. Doit être prêt à jouer le rôle du Grand Citrouille de temps en temps.

Q

qualifié
Possédant un nom complet. Le symbole $Ent::moot est qualifié ; $moot est non qualifié. Un nom de fichier entièrement qualifié est spécifié à partir du répertoire de niveau supérieur.
quantificateur
Une composante d'une expression régulière spécifiant combien de fois l'atome précédent peut survenir.

R

condition de concurrence
Une condition de concurrence existe lorsque le résultat de plusieurs événements interdépendants dépend de l'ordre de ces événements, mais que cet ordre ne peut être garanti en raison d'effets de synchronisation non déterministes. Si deux programmes ou plus, ou des parties du même programme, essaient de passer par la même série d'événements, l'un peut interrompre le travail de l'autre. C'est une bonne façon de trouver un exploit.
lisible
En ce qui concerne les fichiers, un fichier pour lequel le bit de permission approprié est défini pour vous permettre d'y accéder. En ce qui concerne les programmes informatiques, un programme qui est suffisamment bien écrit pour que quelqu'un ait une chance de comprendre ce qu'il essaie de faire.
récupération
Les derniers sacrements effectués par un processus parent au nom d'un processus enfant décédé afin qu'il ne reste pas un zombie. Voir les appels de fonction "wait" et "waitpid".
enregistrement
Un ensemble de valeurs de données liées dans un fichier ou un flux, souvent associé à un champ clé unique. Sous Unix, souvent équivalent à une ligne, ou un ensemble de lignes terminées par une ligne vide (un "paragraphe"). Chaque ligne du fichier /etc/passwd est un enregistrement, indexé par le nom de connexion, contenant des informations sur cet utilisateur.
récursion
L'art de définir quelque chose (au moins partiellement) en termes de soi-même, ce qui est un vilain interdit dans les dictionnaires mais fonctionne souvent bien dans les programmes informatiques si l'on fait attention à ne pas récurser à l'infini (ce qui ressemble à une boucle infinie avec des modes d'échec plus spectaculaires).
référence
Où l'on cherche pour trouver un pointeur vers une information ailleurs. (Voir indirection.) Les références existent en deux saveurs : références symboliques et références fortes.
référent
Ce à quoi une référence fait référence, qui peut ou non avoir un nom. Les types courants de référents incluent les scalaires, les tableaux, les hachages et les sous-routines.
regex
Voir expression régulière.
expression régulière
Une seule entité avec diverses interprétations, comme un éléphant. Pour un informaticien, c'est une grammaire pour un petit langage dans lequel certaines chaînes sont légales et d'autres ne le sont pas. Pour les gens normaux, c'est un motif que vous pouvez utiliser pour trouver ce que vous cherchez lorsqu'il varie d'un cas à l'autre. Les expressions régulières de Perl sont loin d'être régulières au sens théorique, mais en usage régulier, elles fonctionnent très bien. Voici une expression régulière : "/Oh s.*t./". Cela correspondra à des chaînes comme " "Oh say can you see by the dawn's early light" " et " "Oh sit!" ". Voir le chapitre 5 du Camel, "Correspondance de motifs".
modificateur d'expression régulière
Une option sur un motif ou une substitution, telle que "/i" pour rendre le motif insensible à la casse.
fichier régulier
Un fichier qui n'est ni un répertoire, ni un périphérique, ni un tube nommé (pipe) ni une socket, ni un lien symbolique. Perl utilise l'opérateur de test de fichier "–f" pour identifier les fichiers réguliers. Parfois appelé fichier "simple".
opérateur relationnel
Un opérateur qui indique si une relation d'ordre particulière est vraie pour une paire d'opérandes. Perl possède des opérateurs relationnels numériques et de chaîne. Voir séquence de tri.
mots réservés
Un mot ayant une signification spécifique et intégrée pour un compilateur, tel que "if" ou "delete". Dans de nombreux langages (pas en Perl), il est illégal d'utiliser des mots réservés pour nommer autre chose. (C'est pourquoi ils sont réservés, après tout.) En Perl, vous ne pouvez tout simplement pas les utiliser pour nommer des étiquettes ou des manches de fichier (filehandles). Également appelés "mots-clés".
valeur de retour
La valeur produite par une sous-routine ou une expression lorsqu'elle est évaluée. En Perl, une valeur de retour peut être soit une liste, soit un scalaire.
RFC
Request For Comment (Demande de commentaire), qui, malgré les connotations timides, est le nom d'une série de documents standards importants.
décalage à droite
Un décalage de bits qui divise un nombre par une puissance de 2.
rôle
Un nom pour un ensemble concret de comportements. Un rôle est une façon d'ajouter du comportement à une classe sans héritage.
root
Le superutilisateur ("UID" == 0). Aussi le répertoire de niveau supérieur du système de fichiers.
RTFM
Ce qu'on vous dit quand quelqu'un pense que vous devriez Lire Le Foutu Manuel (Read The Fine Manual).
phase d'exécution
Tout moment après que Perl commence à exécuter votre programme principal. Voir aussi phase de compilation. La phase d'exécution est principalement passée en temps d'exécution, mais peut également être passée en temps de compilation lorsque les opérateurs "require", "do" "FICHIER", ou "eval" "CHAÎNE" sont exécutés, ou lorsqu'une substitution utilise le modificateur "/ee".
temps d'exécution
Le moment où Perl exécute réellement ce que votre code lui dit de faire, par opposition à la période précédente où il essayait de déterminer si ce que vous aviez dit avait un sens quelconque, ce qui est le temps de compilation.
motif d'exécution
Un motif qui contient une ou plusieurs variables à interpoler avant d'analyser le motif comme une expression régulière, et qui, par conséquent, ne peut pas être analysé au moment de la compilation, mais doit être réanalysé chaque fois que l'opérateur de correspondance de motif est évalué. Les motifs d'exécution sont utiles mais coûteux.
RV
Un véhicule récréatif ("recreational vehicle"), à ne pas confondre avec la récréation véhiculaire. RV signifie également une valeur interne de référence ("Reference Value") du type qu'un scalaire peut contenir. Voir aussi IV et NV si vous n'êtes pas encore confus.
rvalue
Une valeur que l'on peut trouver du côté droit d'une affectation. Voir aussi lvalue.

S

bac à sable
Une zone clôturée qui n'est pas censée affecter ce qui se trouve au-delà de ses murs. On laisse les enfants jouer dans le bac à sable au lieu de courir dans la rue. Voir le chapitre 20 du Camel, "Sécurité".
scalaire
Une valeur simple et singulière ; un nombre, une chaîne, ou une référence.
contexte scalaire
La situation dans laquelle une expression est censée par son environnement (le code qui l'appelle) retourner une seule valeur plutôt qu'une liste de valeurs. Voir aussi contexte et contexte de liste. Un contexte scalaire impose parfois des contraintes supplémentaires sur la valeur de retour — voir contexte de chaîne et contexte numérique. Parfois, on parle de contexte booléen dans les conditions, mais cela n'impose aucune contrainte supplémentaire, car toute valeur scalaire, qu'elle soit numérique ou de chaîne, est déjà vraie ou fausse.
littéral scalaire
Un nombre ou une chaîne entre guillemets — une valeur réelle dans le texte de votre programme, par opposition à une variable.
valeur scalaire
Une valeur qui s'avère être un scalaire par opposition à une liste.
variable scalaire
Une variable précédée de "$" qui contient une seule valeur.
portée
À quelle distance on peut voir une variable, à travers une autre. Perl a deux mécanismes de visibilité. Il utilise la portée dynamique des variables locales, ce qui signifie que le reste du bloc, et toutes les sous-routines qui sont appelées par le reste du bloc, peuvent voir les variables qui sont
local au bloc. Perl a une portée lexicale pour les variables "my", ce qui signifie que le reste du bloc peut voir la variable, mais les autres sous-routines appelées par le bloc *ne peuvent pas* voir la variable.
scratchpad
La zone dans laquelle une invocation particulière d'un fichier ou d'une sous-routine particulière conserve certaines de ses valeurs temporaires, y compris les variables à portée lexicale.
script
Un fichier texte qui est un programme destiné à être exécuté directement plutôt que compilé en une autre forme de fichier avant son exécution.

Aussi, dans le contexte de l'Unicode, un système d'écriture pour une langue ou un groupe de langues particulier, tel que le grec, le bengali ou le tengwar.

script kiddie
Un cracker qui n'est pas un hacker mais qui sait juste assez pour exécuter des scripts tout faits. Un programmeur cargo-cult.
sed
Un vieil éditeur de flux (Stream EDitor) dont Perl tire certaines de ses idées.
semaphore
Un type sophistiqué de verrouillage qui empêche plusieurs threads ou processus d'utiliser simultanément les mêmes ressources.
séparateur
Un caractère ou une chaîne qui empêche deux chaînes adjacentes d'être confondues. La fonction "split" fonctionne sur les séparateurs. À ne pas confondre avec les délimiteurs ou les terminateurs. Le "ou" de la phrase précédente séparait les deux alternatives.
sérialisation
La mise d'une structure de données complexe dans un ordre linéaire afin qu'elle puisse être stockée sous forme de chaîne dans un fichier disque ou une base de données, ou envoyée via un pipe. Appelée aussi marshalling.
serveur
En réseau, un processus qui annonce un service ou qui attend simplement à un emplacement connu et attend que les clients qui ont besoin d'un service entrent en contact avec lui.
service
Quelque chose que l'on fait pour quelqu'un d'autre pour le rendre heureux, comme lui donner l'heure (ou l'heure de sa vie). Sur certaines machines, les services bien connus sont listés par la fonction "getservent".
setgid
Identique à setuid, mais concerne la cession des privilèges de groupe.
setuid
Se dit d'un programme qui s'exécute avec les privilèges de son propriétaire plutôt qu'avec (comme c'est le cas habituellement) les privilèges de celui qui l'exécute. Décrit également le bit dans le mot de mode (bits de permission) qui contrôle cette fonctionnalité. Ce bit doit être explicitement défini par le propriétaire pour activer cette fonctionnalité, et le programme doit être écrit avec soin pour ne pas céder plus de privilèges qu'il ne le devrait.
mémoire partagée
Un bloc de mémoire accessible par deux processus différents qui, autrement, ne verraient pas la mémoire l'un de l'autre.
shebang
Mot irlandais pour l'ensemble du McGillicuddy. Dans la culture Perl, un mot-valise de "sharp" (dièse) et "bang" (point d'exclamation), signifiant la séquence "#!" qui indique au système où trouver l'interpréteur.
shell
Un interpréteur en ligne de commande. Le programme qui donne interactivement une invite, accepte une ou plusieurs lignes d'entrée, et exécute les programmes que vous avez mentionnés, en fournissant à chacun leurs arguments et données d'entrée appropriés. Les shells peuvent également exécuter des scripts contenant de telles commandes. Sous Unix, les shells typiques incluent le Bourne shell (/bin/sh), le C shell (/bin/csh) et le Korn shell (/bin/ksh). Perl n'est pas strictement un shell car il n'est pas interactif (bien que les programmes Perl puissent être interactifs).
effets de bord
Quelque chose d'ajouté qui se produit lorsque vous évaluez une expression. De nos jours, cela peut se référer à presque tout. Par exemple, l'évaluation d'une simple instruction d'affectation a typiquement pour "effet de bord" l'affectation d'une valeur à une variable. (Et vous pensiez que l'affectation de la valeur était votre intention principale en premier lieu !) De même, affecter une valeur à la variable spéciale $| ($AUTOFLUSH) a pour effet de bord de forcer un vidage après chaque "write" ou "print" sur le descripteur de fichier actuellement sélectionné.
sigil
Un glyphe utilisé en magie. Ou, pour Perl, le symbole devant un nom de variable, tel que "$", "@" et "%".
signal
Un coup de tonnerre dans un ciel serein ; c'est-à-dire, un événement déclenché par le système d'exploitation, probablement lorsque vous vous y attendez le moins.
gestionnaire de signal
Une sous-routine qui, au lieu d'être contente d'être appelée de la manière normale, reste là à attendre un coup de tonnerre avant de daigner s'exécuter. Sous Perl, les coups de tonnerre dans un ciel serein s'appellent des signaux, et vous les envoyez avec la fonction intégrée "kill". Voir la table de hachage %SIG dans le chapitre 25, "Noms spéciaux", et la section "Signaux" dans le chapitre 15, "Communication inter-processus".
héritage simple
Les caractéristiques que vous avez reçues de votre mère, si elle vous a dit que vous n'aviez pas de père. (Voir aussi héritage et héritage multiple.) Dans les langages informatiques, l'idée que les classes se reproduisent asexuellement de sorte qu'une classe donnée ne peut avoir qu'un seul ancêtre direct ou classe de base. Perl n'impose aucune restriction de ce type, bien que vous puissiez certainement programmer en Perl de cette manière si vous le souhaitez.
tranche
Une sélection d'un nombre quelconque d'éléments d'une liste, d'un tableau ou d'une table de hachage.
engloutir
Lire un fichier entier dans une chaîne en une seule opération.
socket
Un point d'extrémité pour la communication réseau entre plusieurs processus qui fonctionne beaucoup comme un téléphone ou une boîte aux lettres. La chose la plus importante concernant un socket est son adresse réseau (comme un numéro de téléphone). Différents types de sockets ont différents types d'adresses - certains ressemblent à des noms de fichiers, et d'autres non.
référence faible
Voir référence symbolique.
filtre source
Un type spécial de module qui effectue un prétraitement sur votre script juste avant qu'il n'atteigne le tokéniseur.
pile
Un dispositif sur lequel vous pouvez placer des choses par le dessus, et plus tard les reprendre dans l'ordre inverse de celui dans lequel vous les avez mises. Voir LIFO.
standard
Inclus dans la distribution officielle de Perl, comme un module standard, un outil standard ou une page de manuel Perl standard.
erreur standard
Le flux de sortie par défaut pour les remarques désagréables qui n'ont pas leur place dans la sortie standard. Représenté dans un programme Perl par le descripteur de fichier de sortie "STDERR". Vous pouvez utiliser ce flux explicitement, mais les fonctions intégrées "die" et "warn" écrivent automatiquement dans votre flux d'erreur standard (sauf si elles sont interceptées ou redirigées).
entrée standard
Le flux d'entrée par défaut de votre programme, qui, si possible, ne devrait pas se soucier de l'origine de ses données. Représenté dans un programme Perl par le descripteur de fichier "STDIN".
E/S standard
Une bibliothèque C standard pour effectuer des entrées et sorties tamponnées vers le système d'exploitation. (Le "standard" des E/S standard est au mieux marginalement lié au "standard" de l'entrée et de la sortie standard.) En général, Perl s'appuie sur l'implémentation des E/S standard que fournit un système d'exploitation donné, de sorte que les caractéristiques de mise en tampon d'un programme Perl sur une machine peuvent ne pas correspondre exactement à celles d'une autre machine. Normalement, cela n'influence que l'efficacité, pas la sémantique. Si votre package d'E/S standard effectue une mise en tampon par bloc et que vous souhaitez qu'il vide le tampon plus souvent, il suffit de définir la variable $| à une valeur vraie.
Bibliothèque Standard
Tout ce qui est livré avec la distribution officielle de perl. Certaines versions de vendeur de perl modifient leurs distributions, en omettant certaines parties ou en incluant des extras. Voir aussi double durée de vie.
sortie standard
Le flux de sortie par défaut de votre programme, qui, si possible, ne devrait pas se soucier de la destination de ses données. Représenté dans un programme Perl par le descripteur de fichier "STDOUT".
instruction
Une commande à l'ordinateur sur ce qu'il doit faire ensuite, comme une étape dans une recette : "Ajouter de la marmelade à la pâte et mélanger jusqu'à ce que ce soit homogène." Une instruction se distingue d'une déclaration, qui ne dit rien à l'ordinateur de faire, mais seulement d'apprendre quelque chose.
modificateur d'instruction
Une conditionnelle ou une boucle que vous placez après l'instruction au lieu de avant, si vous voyez ce que nous voulons dire.
statique
Varier lentement par rapport à autre chose. (Malheureusement, tout est relativement stable par rapport à autre chose, sauf pour certaines particules élémentaires, et nous n'en sommes pas si sûrs.) Dans les ordinateurs, où les choses sont censées varier rapidement, "statique" a une connotation péjorative, indiquant une variable, une sous-routine ou une méthode légèrement dysfonctionnelle. Dans la culture Perl, le mot est poliment évité.

Si vous êtes un programmeur C ou C++, vous cherchez peut-être le mot-clé Perl "state".

méthode statique
N'existe pas. Voir méthode de classe.
portée statique
N'existe pas. Voir portée lexicale.
variable statique
N'existe pas. Utilisez simplement une variable lexicale dans une portée plus large que votre sous-routine, ou déclarez-la avec "state" au lieu de avec "my".
structure stat
Un emplacement interne spécial dans lequel Perl conserve les informations sur le dernier fichier pour lequel vous avez demandé des informations.
statut
La valeur renvoyée au processus parent lorsqu'un de ses processus enfants meurt. Cette valeur est placée dans la variable spéciale $?. Ses huit bits supérieurs sont le statut de sortie du processus defunct, et ses huit bits inférieurs identifient le signal (le cas échéant) qui a causé la mort du processus. Sur les systèmes Unix, ce statut est le même que le mot de statut renvoyé par wait(2). Voir "system" dans le chapitre 27 du livre du Chameau, « Fonctions ».
STDERR
Voir erreur standard.
STDIN
Voir entrée standard.
STDIO
Voir E/S standard.
STDOUT
Voir sortie standard.
flux
Un flux de données entrant ou sortant d'un processus sous forme d'une séquence continue d'octets ou de caractères, sans donner l'impression d'être décomposé en paquets. C'est une sorte d'interface—l'implémentation sous-jacente peut bien décomposer vos données en paquets distincts pour la livraison, mais cela vous est caché.
chaîne de caractères
Une séquence de caractères telle que « Il a dit !@#*&%@#*?! ». Une chaîne de caractères ne doit pas nécessairement être entièrement imprimable.
contexte de chaîne
La situation dans laquelle une expression est censée (par le code qui l'appelle) renvoyer une chaîne de caractères. Voir aussi contexte et contexte numérique.
transformation en chaîne
Le processus de production d'une représentation en chaîne de caractères d'un objet abstrait.
struct
Mot-clé C introduisant une définition de structure ou un nom.
structure
Voir structure de données.
sous-classe
Voir classe dérivée.
sous-motif
Un composant d'un motif d'expression régulière.
sous-routine
Une partie nommée ou autrement accessible d'un programme qui peut être appelée depuis ailleurs dans le programme afin d'accomplir un sous-objectif du programme. Une sous-routine est souvent paramétrée pour accomplir des choses différentes mais liées en fonction de ses arguments d'entrée. Si la sous-routine renvoie une valeur significative, elle est également appelée une fonction.
indice
Une valeur qui indique la position d'un élément d'tableau particulier dans un tableau.
substitution
Changer des parties d'une chaîne de caractères via l'opérateur "s///". (Nous évitons d'utiliser ce terme pour désigner l'interpolation de variable.)
sous-chaîne
Une partie d'une chaîne de caractères, commençant à une certaine position de caractère (décalage) et se poursuivant sur un certain nombre de caractères.
super-classe
Voir classe de base.
superutilisateur
La personne que l'système d'exploitation autorise à faire presque tout. Généralement votre administrateur système ou quelqu'un qui prétend être votre administrateur système. Sur les systèmes Unix, l'utilisateur root. Sur les systèmes Windows, généralement l'utilisateur Administrateur.
SV
Abréviation de « scalar value » (valeur scalaire). Mais au sein de l'interpréteur Perl, chaque référent est traité comme un membre d'une classe dérivée de SV, d'une manière orientée objet. Chaque valeur à l'intérieur de Perl est transmise en tant que pointeur C "SV*". La structure SV connaît son propre « type de référent », et le code est suffisamment intelligent (nous l'espérons) pour ne pas essayer d'appeler une fonction de hash sur une sous-routine.
commutateur
Une option que vous donnez sur une ligne de commande pour influencer le fonctionnement de votre programme, généralement introduite par un signe moins. Le mot est également utilisé comme surnom pour une instruction switch.
cluster de commutateurs
La combinaison de plusieurs commutateurs en ligne de commande (par exemple, "–a –b –c") en un seul commutateur (par exemple, "–abc"). Tout commutateur avec un argument supplémentaire doit être le dernier commutateur d'un cluster.
instruction switch
Une technique de programmation qui vous permet d'évaluer une expression et ensuite, en fonction de la valeur de l'expression, de faire un branchement multiple vers la partie appropriée du code pour cette valeur. Également appelée « structure de cas », nommée d'après le construct Pascal similaire. La plupart des instructions switch en Perl sont écrites "given". Voir « L'instruction "given" » dans le chapitre 4 du livre du Chameau, « Instructions et déclarations ».

Les mots-clés "given", "when" et l'opérateur de correspondance intelligente ("~~") seront supprimés dans Perl 5.42.

symbole
Généralement, tout jeton ou métasymbole. Souvent utilisé plus spécifiquement pour désigner le type de nom que l'on peut trouver dans une table de symboles.
débogueur symbolique
Un programme qui vous permet de parcourir l'exécution de votre programme, de vous arrêter ou d'imprimer des choses ici et là pour voir si quelque chose s'est mal passé, et, le cas échéant, quoi. La partie « symbolique » signifie simplement que vous pouvez interagir avec le débogueur en utilisant les mêmes symboles avec lesquels votre programme est écrit.
lien symbolique
Un nom de fichier alternatif qui pointe vers le nom de fichier réel, qui à son tour pointe vers le fichier réel. Chaque fois que le système d'exploitation essaie d'analyser un chemin d'accès contenant un lien symbolique, il se contente de substituer le nouveau nom et continue l'analyse.
référence symbolique
Une variable dont la valeur est le nom d'une autre variable ou sous-routine. En déréférençant la première variable, vous pouvez accéder à la seconde. Les références symboliques sont illégales sous "use strict "refs"".
table de symboles
Où un compilateur se souvient des symboles. Un programme comme Perl doit en quelque sorte se souvenir de tous les noms de toutes les variables, poignées de fichier et sous-routines que vous avez utilisés. Il le fait en plaçant les noms dans une table de symboles, qui est implémentée en Perl à l'aide d'une table de hachage. Il existe une table de symboles distincte pour chaque package afin de donner à chaque package son propre espace de noms.
synchrone
Programmation dans laquelle la séquence ordonnée des événements peut être déterminée ; c'est-à-dire, quand les choses se produisent les unes après les autres, pas en même temps.
sucre syntaxique
Une manière alternative d'écrire quelque chose plus facilement ; un raccourci.
syntaxe
Du grec σύνταξις, « arrangement commun ». Comment les choses (en particulier les symboles) sont assemblées les unes avec les autres.
arbre syntaxique
Une représentation interne de votre programme dans laquelle les constructions de niveau inférieur dépendent des constructions de niveau supérieur qui les englobent.
appel système
Un appel de fonction directement à l'exploitation système. Beaucoup des sous-routines et fonctions importantes que vous utilisez ne sont pas des appels système directs, mais sont construites en une ou plusieurs couches au-dessus du niveau de l'appel système. En général, les programmeurs Perl n'ont pas besoin de s'inquiéter de la distinction. Cependant, si vous savez quelles fonctions Perl sont réellement des appels système, vous pouvez prédire lesquelles d'entre elles définiront la variable $! ($ERRNO) en cas d'échec. Malheureusement, les programmeurs débutants utilisent souvent à tort le terme « appel système » pour désigner ce qui se passe lorsque vous appelez la fonction Perl "system", ce qui implique en réalité de nombreux appels système. Pour éviter toute confusion, nous disons presque toujours « appel système » pour quelque chose que vous pourriez appeler indirectement via la fonction Perl "syscall", et jamais pour quelque chose que vous appelleriez avec la fonction Perl "system".

T

vérifications de taint
La comptabilité spéciale que Perl effectue pour suivre le flux de données externes à travers votre programme et interdire leur utilisation dans les commandes système.
entaché
Se dit de données dérivées des mains sales d'un utilisateur, et donc dangereuses pour un programme sécurisé sur lesquelles s'appuyer. Perl effectue des vérifications de taint si vous exécutez un programme setuid (ou setgid), ou si vous utilisez le commutateur "–T".
mode taint
Exécuter sous le commutateur "–T", marquant toutes les données externes comme suspectes et refusant de les utiliser avec des commandes système. Voir le chapitre 20 du livre du Chameau, « Sécurité ».
TCP
Abréviation de Transmission Control Protocol. Un protocole enveloppé autour de

T

TCP
Transmission Control Protocol, the protocol that uses the Internet Protocol pour faire apparaître un mécanisme de transmission de paquets non fiable comme un flux d'octets pour le programme d'application. (Habituellement.)
terme
Abréviation de « terminal » — c'est-à-dire un nœud feuille d'un arbre de syntaxe. Une chose qui fonctionne grammaticalement comme un opérande pour les opérateurs dans une expression.
terminateur
Un caractère ou une chaîne qui marque la fin d'une autre chaîne. La variable $/ contient la chaîne qui termine une opération "readline", que "chomp" supprime de la fin. À ne pas confondre avec les délimiteurs ou les séparateurs. Le point à la fin de cette phrase est un terminateur.
ternaire
Un opérateur prenant trois opérandes. Parfois prononcé trinaire.
texte
Une chaîne ou un fichier contenant principalement des caractères imprimables.
thread
Semblable à un processus forgé, mais sans la protection mémoire inhérente de fork. Un thread est plus léger qu'un processus complet, en ce sens qu'un processus peut avoir plusieurs threads qui s'exécutent en son sein, tous se disputant le même espace mémoire du processus à moins que des mesures ne soient prises pour protéger les threads les uns des autres.
tie
Le lien entre une variable magique et sa classe d'implémentation. Voir la fonction "tie" dans le chapitre 27 du Camel, « Fonctions », et le chapitre 14 du Camel, « Variables liées ».
casse de titre
La casse utilisée pour les majuscules qui sont suivies de minuscules au lieu d'autres majuscules. Parfois appelée casse de phrase ou casse de titre. L'anglais n'utilise pas la casse de titre Unicode, mais les règles de casse pour les titres en anglais sont plus compliquées que la simple capitalisation de la première lettre de chaque mot.
TMTOWTDI
Il y a plus d'une façon de faire les choses, la devise de Perl. L'idée qu'il peut y avoir plus d'un chemin valide pour résoudre un problème de programmation dans un contexte donné. (Cela ne signifie pas que plus de chemins sont toujours meilleurs ou que tous les chemins possibles sont également désirables — juste qu'il n'y a pas besoin d'une seule Vraie Voie.)
jeton
Un morphème dans un langage de programmation, la plus petite unité de texte ayant une signification sémantique.
tokeniseur
Un module qui divise le texte d'un programme en une séquence de jetons pour une analyse ultérieure par un analyseur syntaxique.
tokenisation
Division d'un texte de programme en jetons. Également connu sous le nom de « lexing », auquel cas vous obtenez des « lexèmes » au lieu de jetons.
approche coffre à outils
L'idée qu'avec un ensemble complet d'outils simples qui fonctionnent bien ensemble, vous pouvez construire presque tout ce que vous voulez. Ce qui est bien si vous assemblez un tricycle, mais si vous construisez un régurgitateur comboflux défranishisant, vous voulez vraiment votre propre atelier de machines pour construire des outils spéciaux. Perl est une sorte d'atelier de machines.
sujet
La chose sur laquelle vous travaillez. Des structures comme while(<>), "for", "foreach", et "given" définissent le sujet pour vous en assignant à $_, la variable par défaut (de sujet).
translittérer
Transformer une représentation textuelle en une autre en mappant chaque caractère de la chaîne source à son caractère correspondant dans la chaîne résultante. À ne pas confondre avec la traduction : par exemple, le grec πολυχρωμος se translittère en polychromos mais se traduit par multicolore. Voir l'opérateur "tr///" dans le chapitre 5 du Camel, « Correspondance de motifs ».
déclencheur
Un événement qui provoque l'exécution d'un gestionnaire.
trinaire
Pas un système stellaire à trois étoiles, mais un opérateur prenant trois opérandes. Parfois prononcé ternaire.
troff
Un langage de composition typographique vénérable d'où Perl tire le nom de sa variable $% et qui est secrètement utilisé dans la production des livres du Camel.
vrai
Toute valeur scalaire qui n'évalue pas à 0 ou "".
troncature
Vider un fichier de son contenu existant, soit automatiquement lors de l'ouverture d'un fichier en écriture, soit explicitement via la fonction "truncate".
type
Voir type de données et classe.
type casting
Conversion de données d'un type à un autre. C le permet. Perl n'en a pas besoin. Ni n'en veut.
typedef
Une définition de type dans les langages C et C++.
lexical typé
Une variable lexicale qui est déclarée avec un type de classe : "my Pony $bill".
typeglob
Utilisation d'un seul identifiant, préfixé par "*". Par exemple, *name représente tout ou partie de $name, @name, %name, &name, ou simplement "name". La façon dont vous l'utilisez détermine s'il est interprété comme tous ou un seul d'entre eux. Voir « Typeglobs et Filehandles » dans le chapitre 2 du Camel, « Bits et Pièces ».
typemap
Une description de la manière dont les types C peuvent être transformés en et à partir des types Perl dans un module d'extension écrit en XS.

U

UDP
User Datagram Protocol, la manière typique d'envoyer des datagrammes sur Internet.
UID
Un identifiant utilisateur. Souvent utilisé dans le contexte de la propriété de fichier ou de processus.
umask
Un masque des bits de permission qui doivent être désactivés lors de la création de fichiers ou de répertoires, afin d'établir une politique des personnes à qui vous refuserez normalement l'accès. Voir la fonction "umask".
opérateur unaire
Un opérateur avec un seul opérande, comme "!" ou "chdir". Les opérateurs unaires sont généralement des opérateurs préfixes ; c'est-à-dire qu'ils précèdent leur opérande. Les opérateurs "++" et "––" peuvent être préfixes ou postfixes. (Leur position change leur signification.)
Unicode
Un jeu de caractères comprenant tous les principaux jeux de caractères du monde, plus ou moins. Voir http://www.unicode.org.
Unix
Un langage très vaste et en constante évolution avec plusieurs syntaxes alternatives et largement incompatibles, dans lequel chacun peut définir n'importe quoi de n'importe quelle manière qu'il choisit, et le fait généralement. Les locuteurs de cette langue pensent qu'elle est facile à apprendre parce qu'elle est si facilement tordue à ses propres fins, mais les différences dialectales rendent la communication tribale presque impossible, et les voyageurs sont souvent réduits à un sous-ensemble de la langue semblable à un pidgin. Pour être universellement compris, un programmeur de shell Unix doit passer des années à étudier cet art. Beaucoup ont abandonné cette discipline et communiquent maintenant via un langage ressemblant à l'espéranto appelé Perl.

Dans les temps anciens, Unix faisait également référence à du code écrit par quelques personnes des Bell Labs pour utiliser un ordinateur PDP-7 qui ne faisait pas grand-chose d'autre à l'époque.

majuscule
En Unicode, pas seulement les caractères de la catégorie générale Lettre Majuscule, mais tout caractère ayant la propriété Majuscule, y compris certains Nombres de Lettre et Symboles. À ne pas confondre avec la casse de titre.
chaîne UTF-8
Une « chaîne » dont les ordinaux représentent une séquence valide d'octets UTF-8. Parfois appelée « chaîne encodée en UTF-8 ».

(IMPORTANT : Ceci n'est pas lié au « drapeau UTF8 » interne de Perl, dont seule Perl devrait généralement se soucier. Les chaînes UTF-8 peuvent avoir ce drapeau défini ou non.)

V

valeur
Un morceau de données réel, par opposition à toutes les variables, références, clés, indices, opérateurs et autres nécessaires pour accéder à la valeur.
variable
Un emplacement de stockage nommé qui peut contenir n'importe quel type de valeur, selon ce que votre programme juge bon.
variable interpolation
L'interpolation d'une variable scalaire ou de tableau dans une chaîne.
variadique
Se dit d'une fonction qui accepte volontiers un nombre indéterminé d'arguments réels.
vecteur
Jargon mathématique pour une liste de valeurs scalaires.
virtuel
Fournir l'apparence de quelque chose sans la réalité, comme dans : la mémoire virtuelle n'est pas de la vraie mémoire. (Voir aussi mémoire
>.) L'opposé de « virtuel » est « transparent », ce qui signifie fournir la réalité de quelque chose sans l'apparence, comme dans : Perl gère l'encodage de caractères UTF-8 de longueur variable de manière transparente.
contexte void
Une forme de contexte scalaire dans laquelle une expression n'est pas censée renvoyer de valeur du tout et est évaluée pour ses effets de bord uniquement.
chaîne v
Une chaîne de « version » ou de « vecteur » spécifiée avec un "v" suivi d'une série d'entiers décimaux en notation pointée, par exemple, "v1.20.300.4000". Chaque nombre se transforme en un caractère avec la valeur ordinale spécifiée. (Le "v" est facultatif lorsqu'il y a au moins trois entiers.)

W

avertissement
Un message imprimé sur le flux "STDERR" indiquant que quelque chose pourrait être faux mais ne vaut pas la peine de s'en soucier. Voir "warn" dans le chapitre 27 du livre Camel, « Fonctions », et le pragmatique "warnings" dans le chapitre 28 du livre Camel, « Modules pragmatiques ».
expression de veille
Une expression qui, lorsque sa valeur change, provoque un point d'arrêt dans le débogueur Perl.
référence faible
Une référence qui n'est pas comptée normalement. Lorsque toutes les références normales aux données disparaissent, les données disparaissent. Celles-ci sont utiles pour les références circulaires qui ne disparaîtraient jamais autrement.
espace blanc
Un caractère qui déplace votre curseur mais n'affiche rien d'autre à l'écran. Fait généralement référence à n'importe lequel des éléments suivants : espace, tabulation, saut de ligne, retour chariot ou saut de page. En Unicode, correspond à de nombreux autres caractères que l'Unicode considère comme des espaces blancs, y compris le u+200B (largeur zéro non sécable).
mot
Dans le « jargon informatique » normal, le morceau de données dont la taille est la plus efficace pour votre ordinateur, généralement 32 bits ou plus, à quelques puissances de 2 près. Dans la culture Perl, il fait plus souvent référence à un identifiant alphanumérique (y compris les traits de soulignement), ou à une chaîne de caractères non blancs délimités par des espaces blancs ou des limites de chaîne.
répertoire de travail
Votre répertoire actuel, à partir duquel les chemins relatifs sont interprétés par le système d'exploitation. Le système d'exploitation connaît votre répertoire actuel parce que vous lui avez indiqué avec un "chdir", ou parce que vous avez commencé dans l'endroit où se trouvait votre processus parent lorsque vous êtes né.
wrapper
Un programme ou une sous-routine qui exécute un autre programme ou une autre sous-routine pour vous, modifiant une partie de ses entrées ou sorties pour mieux vous servir.
WYSIWYG
What You See Is What You Get (Ce que vous voyez est ce que vous obtenez). Généralement utilisé lorsque quelque chose qui apparaît à l'écran correspond à ce à quoi il ressemblera éventuellement, comme les déclarations "format" de Perl. Également utilisé pour signifier l'opposé de la magie car tout fonctionne exactement comme il apparaît, comme dans la forme à trois arguments de "open".

X

XS
Une sous-routine externe（External Subroutine）extraordinairement exportée, expéditivement excellente, expressément eXterne, exécutée en C ou C++ existant ou dans un langage d'extension passionnant appelé (exaspérément) XS.
XSUB
Une sous-routine externe définie en XS.

Y

yacc
Yet Another Compiler Compiler (Encore un autre compilateur de compilateurs). Un générateur d'analyseurs sans lequel Perl n'aurait probablement pas existé. Voir le fichier perly.y dans la distribution source de Perl.

Z

largeur zéro
Une assertion de sous-modèle correspondant à la chaîne nulle entre les caractères.
zombie
Un processus qui est mort (s'est terminé) mais dont le parent n'a pas encore reçu de notification appropriée de sa disparition en appelant "wait" ou "waitpid". Si vous faites un "fork", vous devez nettoyer vos processus enfants lorsqu'ils se terminent ; sinon, la table des processus se remplira et votre administrateur système ne sera pas content de vous.
