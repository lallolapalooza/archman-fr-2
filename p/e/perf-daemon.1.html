PERF-DAEMON(1) Manuel perf PERF-DAEMON(1)

NOM

perf-daemon - Exécute des sessions d'enregistrement en arrière-plan

SYNTAXE

perf daemon
perf daemon [<options>]
perf daemon start  [<options>]
perf daemon stop   [<options>]
perf daemon signal [<options>]
perf daemon ping   [<options>]

DESCRIPTION

Cette commande permet d'exécuter un processus de démon simple qui démarre et surveille les sessions d'enregistrement configurées.

Vous pouvez imaginer perf daemon comme un processus d'arrière-plan avec plusieurs tâches perf record enfants, comme suit :

# ps axjf
...
     1  916507 ... perf daemon start
916507  916508 ...  \_ perf record --control=fifo:control,ack -m 10M -e cycles --overwrite --switch-output -a
916507  916509 ...  \_ perf record --control=fifo:control,ack -m 20M -e sched:* --overwrite --switch-output -a

Toutes les sessions perf record ne conviennent pas à une exécution sous le démon. L'utilisateur a besoin d'une session perf qui produit des données sur demande, comme les sessions de l'enregistreur de vol dans l'exemple ci-dessus, ou d'une session configurée pour produire des données périodiquement, comme avec la configuration --switch-output pour l'heure et la taille.

Chaque session est démarrée avec une configuration de contrôle (avec les options perf record --control).

Les sessions sont configurées via un fichier de configuration, voir la section CONFIG FILE avec des EXEMPLES.

OPTIONS

-v, --verbose

Soyez plus verbeux.

--config=<CHEMIN>

Chemin du fichier de configuration. S'il n'est pas fourni, perf vérifiera les emplacements système et par défaut (/etc/perfconfig, $HOME/.perfconfig).

--base=<CHEMIN>

Chemin du répertoire de base. Chaque instance de démon s'exécute au-dessus d'un répertoire de base. Une seule instance de serveur peut s'exécuter au-dessus d'un répertoire à la fois.

Toutes les options génériques sont également disponibles sous les commandes.

COMMANDE START

La commande start crée le processus démon.

-f, --foreground

Ne pas placer le processus en arrière-plan.

COMMANDE STOP

La commande stop arrête toutes les sessions et le processus démon.

COMMANDE SIGNAL

La commande signal envoie un signal aux sessions configurées.

--session

Envoyer un signal à une session spécifique.

COMMANDE PING

La commande ping envoie une requête de contrôle aux sessions configurées.

--session

Envoyer un ping à une session spécifique.

FICHIER CONFIG

Le démon est configuré dans le fichier de configuration perf standard en utilisant les nouvelles variables suivantes :

daemon.base: Chemin de base pour les données du démon. Toutes les données de session sont stockées sous ce chemin.

session-<NOM>.run: Définit une nouvelle session d'enregistrement. La valeur est la ligne de commande de l'enregistrement sans le mot-clé record.

Chaque session perf record est exécutée dans le répertoire daemon.base/<NOM>.

EXEMPLES

Exemple avec 2 sessions d'enregistrement :

# cat ~/.perfconfig
[daemon]
base=/opt/perfdata
[session-cycles]
run = -m 10M -e cycles --overwrite --switch-output -a
[session-sched]
run = -m 20M -e sched:* --overwrite --switch-output -a

Démarrage du démon :

# perf daemon start

Vérification des sessions :

# perf daemon
[603349:daemon] base: /opt/perfdata
[603350:cycles] perf record -m 10M -e cycles --overwrite --switch-output -a
[603351:sched] perf record -m 20M -e sched:* --overwrite --switch-output -a

La première ligne contient les informations du processus démon avec la base de données configurée.

Vérification des sessions avec plus d'informations :

# perf daemon -v
[603349:daemon] base: /opt/perfdata
  output:  /opt/perfdata/output
  lock:    /opt/perfdata/lock
  up:      1 minutes
[603350:cycles] perf record -m 10M -e cycles --overwrite --switch-output -a
  base:    /opt/perfdata/session-cycles
  output:  /opt/perfdata/session-cycles/output
  control: /opt/perfdata/session-cycles/control
  ack:     /opt/perfdata/session-cycles/ack
  up:      1 minutes
[603351:sched] perf record -m 20M -e sched:* --overwrite --switch-output -a
  base:    /opt/perfdata/session-sched
  output:  /opt/perfdata/session-sched/output
  control: /opt/perfdata/session-sched/control
  ack:     /opt/perfdata/session-sched/ack
  up:      1 minutes

Le chemin base est la base du démon/session. Le fichier lock est le fichier de verrouillage du démon qui garantit qu'aucun autre démon ne s'exécute au-dessus de la base. Le fichier output est la sortie de perf record pour la session spécifique. Les fichiers control et ack sont les fichiers de contrôle de perf. Le nombre up indique le temps de fonctionnement du démon/session en minutes.

Assurez-vous que la session de contrôle est en ligne :

# perf daemon ping
OK   cycles
OK   sched

Envoyer le signal USR2 à la session cycles pour générer le fichier perf.data :

# perf daemon signal --session cycles
signal 12 sent to session 'cycles [603452]'
# tail -2  /opt/perfdata/session-cycles/output
[ perf record: dump data: Woken up 1 times ]
[ perf record: Dump perf.data.2020123017013149 ]

Envoyer le signal USR2 à toutes les sessions :

# perf daemon signal
signal 12 sent to session 'cycles [603452]'
signal 12 sent to session 'sched [603453]'
# tail -2  /opt/perfdata/session-cycles/output
[ perf record: dump data: Woken up 1 times ]
[ perf record: Dump perf.data.2020123017024689 ]
# tail -2  /opt/perfdata/session-sched/output
[ perf record: dump data: Woken up 1 times ]
[ perf record: Dump perf.data.2020123017024713 ]

Arrêter le démon :

# perf daemon stop
