PERLKO(1perl) Guide de référence du programmeur Perl PERLKO(1perl)

NOM

perlko - «Guide du programmeur Perl» en Coréen

DESCRIPTION

Bienvenue dans le monde de Perl !

Perl est souvent appelé 'Practical Extraction and Report Language', mais d'autres l'appellent 'Pathologically Eclectic Rubbish Lister'. En réalité, c'est un jeu de mots qui combine les premières lettres des mots mentionnés, et dont le nom complet a été décidé par Larry Wall, le créateur de Perl, plus tard. C'est pourquoi 'Perl' est généralement écrit en minuscules. Peu importe ce que vous supposez qu'il représente, cela n'a pas d'importance. Larry en a deux autres qu'il peut vous jeter.

Parfois, 'perl' est écrit avec un 'p' minuscule. Lorsque 'Perl' est en majuscules, cela signifie que vous faites référence à la langue elle-même, et lorsque 'p' est en minuscules, vous faites référence à l'exécutable qui interprète votre programme, et que vous utilisez pour le faire fonctionner.

PerlÀ propos de

Perl a été conçu à l'origine pour la génération de rapports textuels, mais est maintenant utilisé dans de nombreux domaines, notamment la gestion de système, le développement Web, le développement de GUI, etc. C'est un langage de programmation polyvalent.

Ce langage privilégie la lisibilité et la clarté (facile à lire, facile à comprendre et facile à déboguer) plutôt que la concision (facile à écrire, efficace et potentiellement le plus court). Il prend en charge la programmation impérative et objet, et est connu pour ses puissantes fonctionnalités de manipulation de chaînes de caractères, et pour contenir le noyau du modèle 3G le plus impressionnant du monde, ce qui est l'une des caractéristiques les plus importantes de Perl.

Les caractéristiques du langage Perl sont introduites dans le document pod/perlintro.pod.

Les changements les plus importants de cette version sont décrits dans pod/perldelta.pod.

Il existe de nombreux autres livres qui traitent de sujets Perl similaires. Pour plus d'informations détaillées, veuillez consulter le document pod/perlbook.pod.

Installation

Vous utilisez probablement un système d'exploitation commun et vous souhaitez installer la version actuelle de Perl. Dans ce cas, exécutez les commandes suivantes :

./Configure -des -Dprefix=$HOME/localperl
make test
make install

La commande ci-dessus configure l'environnement en fonction de votre système d'exploitation, compile et exécute les tests, puis installe Perl dans le répertoire localperl de votre répertoire personnel.

Si vous rencontrez des problèmes ou si vous devez installer une version différente de Perl, vous devez lire le fichier INSTALL dans le répertoire de distribution. Il contient des instructions détaillées sur la compilation et l'utilisation de Perl sur divers systèmes d'exploitation. Il existe également de nombreux conseils et astuces dans le fichier README.

Une fois que vous avez installé Perl, vous pouvez utiliser l'outil "perldoc" pour consulter la documentation abondante. Exécutez la commande suivante pour commencer :

perldoc perl

Difficultés d'exécution

Perl est un langage puissant et polyvalent utilisé dans tous les domaines, des centres de données aux supercalculateurs. Beaucoup d'entre vous ont peut-êt;re rencontré des difficultés lorsque vous avez dû déboguer votre code. Les problèmes que vous avez rencontrés peuvent probablement êt;re résolus par une autre personne. Si, même après avoir consulté la documentation, vous constatez toujours des bogues, veuillez utiliser l'outil "perlbug" pour nous signaler le bogue. ENCODAGE

Depuis la version 5.8.0, Perl prend en charge l'Unicode de manière générale. Le fait que l'Unicode ait été implémenté par une partie du monde entier signifie qu'il existait déjà avant, et il est maintenant largement implémenté. L'Unicode est un système de représentation des caractères du monde entier qui vise à devenir le supraset de tous les systèmes d'alphasyllabaires (alphabet latin, alphabet cyrillique, alphabet grec, alphabet hébreu, alphabet arabe, alphabet indic, alphabet chinois, alphabet hébreu, alphabet chinois, alphabet coréen, etc.). À ce moment-là, les systèmes alphabétiques existants étaient intégrés dans une combinaison de caractères et de systèmes d'encodage. Maintenant, presque tous les alphabets et tous les pays du monde s'intègrent dans des combinaisons de caractères et des systèmes d'encodage, bien que de nombreux alphabets ne soient pas encore inclus.

Perl utilise l'Unicode en interne pour représenter les caractères. Plus précisément, dans les scripts Perl, vous pouvez utiliser des séquences de caractères UTF-8, et la plupart des fonctions et des opérateurs (par exemple, index, substr) fonctionnent sur des séquences de caractères Unicode, qui sont des unités de caractères Unicode de niveau octet. Pour plus d'informations, consultez le manuel pod/perlunicode.pod. L'Unicode était déjà là avant d'être largement implémenté, et il est encore largement implémenté maintenant. Les systèmes d'encodage spécifiques à chaque langue/pays sont utilisés pour l'entrée/la sortie et pour convertir les données et les documents en caractères Unicode. C'est le module Encode qui est utilisé pour cela. L'utilisation du module Encode permet de convertir facilement entre de nombreux encodages.

Module Encode

Support d'encodage

Le module Encode prend en charge les encodages coréens suivants.

  • "euc-kr"

    Il s'agit d'un encodage multi-octets qui utilise US-ASCII et KS X 1001, généralement appelé euc-kr. Il est conforme à KS X 2901 et RFC 1557.

  • "cp949"

    Il s'agit d'une extension de KS X 1001 implémentée dans MS-Windows 9x/ME. Il ajoute 8 822 caractères Hanja aux caractères euc-kr. Les alias sont uhc, windows-949, x-windows-949, ks_c_5601-1987. Le dernier nom est un nom peu courant, mais il est utilisé comme nom de produit par Microsoft.

  • "johab"

    Il s'agit d'une combinaison définie dans la partie 3 de KS X 1001:1998. Le répertoire de caractères est similaire à cp949, et l'encodage est le même que pour US-ASCII et KS X 1001, avec 8 822 caractères Hanja ajoutés. Le système d'encodage est identique à celui décrit précédemment.

  • "iso-2022-kr"

    Il s'agit d'un encodage de transfert de courrier électronique coréen défini dans RFC 1557. Il utilise US-ASCII et KS X 1001 comme répertoires, et bien qu'il soit le même que euc-kr au niveau de l'encodage, le système d'encodage est différent. Il était utilisé jusqu'en 1997-8, mais n'est plus utilisé pour le transfert de courrier électronique.

  • "ksc5601-raw"

    Il s'agit de l'encodage utilisé lorsque KS X 1001 (KS C 5601) est défini dans GL (une plage où MSB est 0). Il n'est pas combiné avec US-ASCII et utilisé seul. Sauf pour la définition de caractères de X11 (ksc5601.1987-0, où '0' signifie GL), il n'y a pas d'autre définition. KS C 5601 a été renommé KS X 1001 en 1997. En 1998, 8 822 caractères supplémentaires (y compris les symboles et les caractères spéciaux) ont été ajoutés.

Exemple de conversion

Par exemple, pour convertir un fichier encodé en euc-kr en UTF-8, exécutez la commande suivante dans le terminal :

perl -Mencoding=euc-kr,STDOUT,utf8 -pe1 < file.euc-kr > file.utf8

Pour convertir dans le sens opposé, exécutez la commande suivante :

perl -Mencoding=utf8,STDOUT,euc-kr -pe1 < file.utf8 > file.euc-kr

Ces conversions rendent les conversions beaucoup plus faciles.

게 할 수 있도록 도와주는 piconv가 Perl에 기본으로 들어있습니다. 이 유틸리티는 Encode 모듈을 이용한 순수 Perl 유틸리티로 이름에서 알 수 있듯이 Unix의 "iconv"를 모델로 한 가입니다. 사용릁도는 다음과 같습니다.

모범 사례

Perl은 기본적으로 내부에서 UTF-8을 사용하며 Encode 모듈을 통해 다양한 인코딩을 지원하지만 항상 다음 괄숙을 지킴으로써 인코딩과 관련한 다양한게 발생할 수 있는 문제의 가능성을 줄이는 것을 추천합니다.

  • 소스 코드는 항상 UTF-8 인코딩으로 저장
  • 소스 코드 상단에 "use utf8;" 프라그마 사용
  • 소스 코드, 터미널, 운영써제, 데이터 인코딩을 분리해서 이해
  • 입출력 파일 핸들에 명시적인 인코딩을 사용
  • 중복(double) 인코딩을 주위
