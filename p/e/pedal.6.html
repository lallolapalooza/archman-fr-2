NOM

pedal - joli programme d'images géométriques

SYNTAXE

pedal [--display hôte:écran.numéro] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numéro][--delay secondes] [-maxlines numéro] [-mono] [--install] [--visual visuel] [--fps]

DESCRIPTION

Le programme pedal affiche de jolies images géométriques.

OPTIONS

pedal accepte les options suivantes :

--window
Dessine dans une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id numéro
Dessine sur la fenêtre spécifiée.
--foreground couleur
La couleur pour le premier plan. La valeur par défaut est blanc.
--background couleur
La couleur pour l'arrière-plan. La valeur par défaut est noir.
--delay secondes
Le nombre de secondes de pause entre chaque image.
--maxlines numéro
Le nombre maximum de lignes dans le dessin. Les bonnes valeurs se situent entre 20 et 2000. La valeur maximale est de 16K.

Pour faire travailler dur votre serveur X, et pour impressionner vos amis, essayez pedal -mono -delay 0 -maxlines 100.

--fps
Affiche la fréquence d'images actuelle et la charge du processeur.

ENVIRONNEMENT

DISPLAY
pour obtenir le nom d'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.
