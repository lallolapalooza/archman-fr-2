NOM

perf-data - Traitement lié aux fichiers de données

SYNTAXE

perf data [<options communes>] <commande> [<options>]",

DESCRIPTION

Traitement lié aux fichiers de données.

COMMANDES

convert

Convertit un fichier de données perf dans un autre format. Il est possible de définir la variable de débogage data-convert pour obtenir des messages de débogage lors de la conversion, par exemple : perf --debug data-convert data convert ...

OPTIONS POUR CONVERT

--to-ctf

Déclenche la conversion CTF, spécifiez le chemin du répertoire de données CTF.

--to-json

Déclenche la conversion JSON. Spécifiez le nom du fichier JSON de sortie.

--tod

Convertit le temps en temps réel (wall clock time).

-i

Spécifie le chemin du fichier de données perf d'entrée.

-f, --force

Ne pas se plaindre, le faire.

-v, --verbose

Être plus verbeux (afficher les erreurs d'ouverture de compteur, etc.).

--all

Convertit tous les événements, y compris les événements non échantillonnés (comm, fork, ...), dans la sortie. Par défaut, seul les échantillons sont convertis.
