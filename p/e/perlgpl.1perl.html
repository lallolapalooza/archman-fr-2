PERLGPL(1perl) Guide de référence pour programmeurs Perl PERLGPL(1perl)

NOM

perlgpl - la Licence Publique Générale GNU, version 1

SYNTAXE

Vous pouvez faire référence à ce document dans Pod via "L<perlgpl>"
Ou vous pouvez voir ce document en tapant "perldoc perlgpl"

DESCRIPTION

Perl est un logiciel libre ; vous pouvez le redistribuer et/ou le modifier selon les termes soit de :

a) la Licence Publique Générale GNU telle que publiée par la Free
Software Foundation ; soit la version 1, soit (à votre convenance) toute
version ultérieure, soit
b) la "Licence Artistique" qui accompagne ce Kit.

Ceci est la "Licence Publique Générale GNU, version 1". Elle est ici pour que les modules, programmes, etc., qui veulent déclarer ceci comme leur licence de distribution puissent y faire référence.

Pour la Licence Artistique Perl, voir perlartistic.
