NOM

perf-test - Exécute des tests de sanité.

SYNTAXE

perf test [<options>] [{list <fragment-nom-test>|[<fragments-nom-test>|<numéros-tests>]}]

DESCRIPTION

Cette commande effectue divers tests de sanité, initialement via des routines liées, mais recherchera également un répertoire contenant davantage de tests sous forme de scripts.

Pour obtenir une liste des tests disponibles, utilisez perf test list, en spécifiant un fragment de nom de test pour afficher tous les tests qui le contiennent.

Pour exécuter uniquement des tests spécifiques, indiquez des fragments de nom de test ou les numéros obtenus à partir de perf test list.

OPTIONS

-s, --skip

Tests à ignorer (liste numérique séparée par des virgules).

-v, -vv, -vvv, --verbose

Avec un seul -v, niveau de verbosité 1, seule la sortie des tests échoués est affichée. Avec -vv et plus, toute la sortie des tests est affichée.

-S, --sequential

Exécute tous les tests les uns après les autres. Par défaut, les tests "exclusifs" sont exécutés séquentiellement, mais les autres tests sont exécutés en parallèle pour accélérer l'exécution.

-r, --runs-per-test

Exécute chaque test le nombre de fois indiqué, par défaut une fois. Cette option peut être utile pour déterminer si un test est instable.

-F, --dont-fork

Ne pas créer de processus fils pour chaque test, exécuter tous les tests dans un seul processus, ce qui active le mode séquentiel.

--dso

Spécifie un DSO pour le test "Symbols".

-w, --workload=

Exécute une charge de travail intégrée, pour les lister utilisez --list-workloads, les charges de travail actuelles incluent : noploop, thloop, leafloop, sqrtloop, brstack, datasym et landlock. 
Utilisé avec les tests de régression de script shell.
Certains acceptent un paramètre supplémentaire :
secondes : leafloop, noploop, sqrtloop, thloop
nrloops : brstack
Les charges de travail datasym et landlock n'en acceptent aucune.

--list-workloads

Liste les charges de travail disponibles à utiliser avec -w/--workload.
