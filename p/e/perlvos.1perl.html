PERLVOS(1perl) Guide de référence du programmeur Perl PERLVOS(1perl)

NOM

perlvos - Perl pour Stratus OpenVOS

SYNOPIS

Ce fichier contient des notes pour la compilation de perl sous le système d'exploitation Stratus OpenVOS. Perl est un langage de script ou de macro populaire sur de nombreux systèmes. Voir perlbook pour un certain nombre de bons livres sur Perl.

Ce sont des instructions pour compiler Perl à partir des sources. Cette version de Perl nécessite la prise en charge du lien dynamique qui se trouve dans la version 17.1 d'OpenVOS et n'est donc pas prise en charge sur la version 17.0 ou les versions antérieures d'OpenVOS.

Si vous utilisez VOS Release 14.4.1 ou une version ultérieure, vous pouvez obtenir une copie précompilée et prise en charge de perl en achetant le produit GNU Tools auprès de Stratus Technologies.

COMPILATION DE PERL POUR OPENVOS

Pour compiler perl à partir de son code source sur la plateforme Stratus V Series, vous devez disposer d'OpenVOS Release 17.1.0 ou d'une version ultérieure, de GNU Tools Release 3.5 ou d'une version ultérieure, et des bibliothèques d'exécution C/POSIX.

Suivez les instructions normales pour compiler perl ; par exemple, entrez bash, exécutez le script Configure, puis utilisez "gmake" pour compiler perl.

INSTALLATION DE PERL DANS OPENVOS

1.
Après avoir compilé perl à l'aide du script Configure, assurez-vous que vous avez les permissions de modification et d'écriture par défaut sur ">system>ported" et tous ses sous-répertoires. Ensuite, tapez 
gmake install
2.
Bien qu'il n'y ait actuellement aucune extension ou module spécifique à l'architecture distribué avec perl, les répertoires suivants peuvent être utilisés pour contenir de tels fichiers (remplacez la chaîne VERSION par le numéro de version approprié) : 
>system>ported>lib>perl5>VERSION>i786
3.
Les extensions et modules perl spécifiques au site peuvent être installés dans l'un des deux endroits suivants. Placez les fichiers indépendants de l'architecture dans : 
>system>ported>lib>perl5>site_perl>VERSION

Placez les fichiers spécifiques au site et dépendants de l'architecture dans l'un des répertoires suivants :

>system>ported>lib>perl5>site_perl>VERSION>i786
4.
Vous pouvez examiner la variable @INC depuis un programme perl pour voir l'ordre dans lequel Perl recherche ces répertoires.

UTILISATION DE PERL DANS OPENVOS

Restrictions de Perl sur OpenVOS

Ce portage de Perl version 5 préfère les noms de chemins de style Unix, séparés par des barres obliques, aux noms de chemins de style OpenVOS, séparés par des chevrons. Les noms de chemins de style OpenVOS devraient fonctionner dans la plupart des contextes, mais si vous rencontrez des difficultés, remplacez tous les caractères supérieur par des caractères obliques. Étant donné que le caractère oblique est utilisé comme délimiteur de chemin, Perl ne peut pas traiter les noms de chemins OpenVOS contenant un caractère oblique dans un nom de répertoire ou de fichier ; ceux-ci doivent être renommés.

Ce portage de Perl utilise également des valeurs de date d'époque Unix en interne. Tant que vous traitez des représentations de chaînes de caractères ASCII de dates, cela ne devrait pas poser de problème. L'époque prise en charge va du 1er janvier 1980 au 17 janvier 2038.

Voir le fichier pod/perlport.pod pour plus d'informations sur le portage OpenVOS de Perl.

STATUT DES TESTS

Un certain nombre d'auto-tests de perl échouent pour diverses raisons ; généralement, ce sont des problèmes mineurs dus à des différences subtiles entre les environnements POSIX courants et l'environnement POSIX d'OpenVOS. Assurez-vous de réaliser des tests suffisants de votre code pour garantir qu'il fonctionne correctement dans l'environnement OpenVOS.
