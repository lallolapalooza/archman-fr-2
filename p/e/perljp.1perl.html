PERLJP(1perl) Guide de référence du programmeur Perl PERLJP(1perl)

NOM

perljp - Guide Perl en japonais

説明' (Description)

Bienvenue dans le monde de Perl !

Depuis Perl 5.8.0, le support d'Unicode a été considérablement renforcé, ce qui a permis d'inclure la prise en charge des jeux de caractères autres que l'ASCII, y compris ceux de l'Asie de l'Est (chinois, japonais, coréen). Unicode vise à être un standard qui gère tous les caractères du monde dans un seul jeu de caractères, incluant les caractères d'Extrême-Orient (caractères chinois, caractères kirillis, caractères arabes, caractères hébreux, caractères devanagari, etc.), ainsi que les caractères que les fournisseurs d'OS définissaient individuellement par le passé (caractères PC ou Macintosh).

Perl lui-même fonctionne avec Unicode. Les littéraux de chaînes de caractères et les expressions régulières dans les scripts Perl sont supposés être en Unicode. Pour les entrées/sorties, le module standard « Encode » est fourni, permettant des conversions faciles entre Unicode et les différents jeux de caractères.

Par exemple, pour convertir un fichier FOO vers UTF-8, faites comme suit :

perl -Mencoding=FOO,STDOUT,utf8 -pe1 < file.FOO > file.utf8

De plus, Perl est livré avec l'utilitaire de conversion de jeux de caractères entièrement écrit en Perl, piconv, vous pouvez donc aussi faire ceci :

piconv -f FOO -t utf8 < file.FOO > file.utf8
piconv -f utf8 -t FOO < file.utf8 > file.FOO

Migration depuis (jcode.pl|Jcode.pm|JPerl)

Dans les versions antérieures à la 5.8, les littéraux de scripts pouvaient gérer l'EUC-JP. De plus, en tant que modules de gestion des entrées/sorties, Jcode.pm (http://openlab.ring.gr.jp/Jcode/) était disponible, et en tant qu'utilitaire pour Perl4, jcode.pl existait, souvent utilisé pour les CGI gérant le japonais. Cependant, il était difficile de bien gérer les expressions régulières japonaises.

Dans Perl avant 5.005, une version localisée pour le japonais, Jperl, existait (http://homepage2.nifty.com/kipp/perl/jperl/index.html ＊1). De plus, une version japonaise de Perl pour Mac OS 9.x/Classic, MacPerl, existait sous le nom de MacJPerl (https://habilis.net/macjperl/). Ces versions pouvaient gérer non seulement l'EUC-JP comme jeu de caractères, mais aussi le Shift_JIS, et permettaient de gérer les expressions régulières japonaises.

Dans Perl 5.8, ces fonctionnalités sont implémentées nativement dans Perl. En plus du japonais, tous les 114 jeux de caractères mentionnés ci-dessus peuvent être gérés simultanément. De plus, l'obtention de modules pour de nouveaux jeux de caractères à partir de CPAN est devenue simple.

perljp(1perl) — Documentation Arch Linux

NAME

perljp - Perl Japanese Manual Page

DESCRIPTION

Il n'est pas possible d'accéder aux fichiers des manuels japonais de Perl via le site Web.

Vous pouvez obtenir des bibliothèques binaires Perl pour Windows depuis Vector (https://www.vector.co.jp/soft/win95/util/se098198.html), et des patchs Perl 4 depuis CPAN (https://www.cpan.org/src/unsupported/4.036/jperl/).

  • Entrée/Sortie

    Les exemples suivants convertissent l'entrée Shift_JIS en EUC-JP pour la sortie.

    # jcode.pl
require "jcode.pl";
while(<>){
  jcode::convert(*_, 'euc', 'sjis');
  print;
}
# Jcode.pm
use Jcode;
while(<>){
      print Jcode->new($_, 'sjis')->euc;
}
# Perl 5.8
use Encode;
while(<>){
  from_to($_, 'shiftjis', 'euc-jp');
  print;
}
# Perl 5.8 - en utilisant l'encodage
use encoding 'euc-jp', STDIN => 'shiftjis';
while(<>){
      print;
}
  • Script d'échange Jperl

    En changeant simplement le « shebang » (le premier ligne), la plupart des scripts pour Jperl peuvent être utilisés sans modification.

    #!/path/to/jperl
↓
#!/path/to/perl -Mencoding=euc-jp

    Pour plus de détails, veuillez consulter perldoc encoding.

Pour plus de détails

Perl est accompagné d'une quantité considérable de documentation, expliquant en détail les nouvelles fonctionnalités de Perl, la prise en charge d'Unicode, ainsi que l'utilisation du module Encode (malheureusement, la plupart de cette documentation est en anglais).

Vous pouvez consulter une partie de ces informations à l'aide des commandes suivantes :

perldoc perlunicode # Prise en charge générale d'Unicode dans Perl
perldoc Encode      # Concernant le module Encode
perldoc Encode::JP  # Concernant les encodages de caractères japonais
