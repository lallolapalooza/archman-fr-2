NOM

perf-ftrace - wrapper simple pour la fonctionnalité ftrace du noyau

SYNTAXE

perf ftrace {trace|latency|profile} <commande>

DESCRIPTION

La commande perf ftrace fournit une collection de sous-commandes qui utilisent l'infrastructure ftrace du noyau.

'perf ftrace trace' est un wrapper simple de ftrace. Il ne prend en charge que le traçage de fil unique actuellement et lit simplement trace_pipe sous forme de texte, puis l'écrit sur la sortie standard.
'perf ftrace latency' calcule la latence d'exécution d'une fonction donnée (facultativement avec BPF) et l'affiche sous forme d'histogramme.
'perf ftrace profile' affiche un profil d'exécution pour chaque fonction, y compris le temps total, moyen, maximum et le nombre d'appels.

Les options suivantes s'appliquent à perf ftrace.

OPTIONS COMMUNES

-p, --pid=

Tracer sur un identifiant de processus existant (liste séparée par des virgules).

--tid=

Tracer sur un identifiant de fil d'exécution existant (liste séparée par des virgules).

-a, --all-cpus

Forcer la collecte sur l'ensemble du système. Les scripts exécutés sans <commande> utilisent normalement -a par défaut, tandis que les scripts exécutés avec une <commande> ne le font normalement pas - cette option permet aux seconds d'être exécutés en mode système complet.

-C, --cpu=

Tracer uniquement pour la liste des CPU fournis. Plusieurs CPU peuvent être fournis sous forme de liste séparée par des virgules sans espace, comme ceci : 0,1. Les plages de CPU sont spécifiées avec - : 0-2. Par défaut, le traçage s'effectue sur tous les CPU disponibles.

-v, --verbose

Augmenter le niveau de verbosité.

OPTIONS POUR PERF FTRACE TRACE

-t, --tracer=

Traçeur à utiliser lorsque ni l'option -G ni l'option -F ne sont spécifiées : function_graph ou function.

-F, --funcs

Lister les fonctions disponibles à tracer. Il accepte un modèle pour ne lister que les fonctions d'intérêt.

-D, --delay

Temps (ms) à attendre avant de commencer le traçage après le démarrage du programme.

-m, --buffer-size

Définir la taille du tampon de traçage par CPU, <taille> est attendu comme un nombre avec un caractère d'unité ajouté - B/K/M/G.

--inherit

Tracer les processus enfants générés par notre cible.

-T, --trace-funcs=

Sélectionner le traçeur de fonctions et définir un filtre de fonctions sur la fonction donnée (ou un modèle glob). Plusieurs fonctions peuvent être données en utilisant cette option plusieurs fois. L'argument de fonction peut également être un modèle glob. Il sera passé à set_ftrace_filter dans tracefs.

-N, --notrace-funcs=

Sélectionner le traçeur de fonctions et ne pas tracer les fonctions données par l'argument. Comme l'option -T, cela peut être utilisé plusieurs fois pour spécifier plusieurs fonctions (ou modèles glob). Il sera passé à set_ftrace_notrace dans tracefs.

--func-opts

Liste des options autorisées à être définies :
•call-graph - Afficher la trace de pile du noyau pour le traçeur de fonctions.
•irq-info - Afficher les informations de contexte IRQ pour le traçeur de fonctions.

-G, --graph-funcs=

Sélectionner le traçeur function_graph et définir un filtre de graphe sur la fonction donnée (ou un modèle glob). Ceci est utile pour tracer les fonctions exécutées à partir de la fonction donnée. Cela peut être utilisé plusieurs fois pour spécifier plusieurs fonctions. Il sera passé à set_graph_function dans tracefs.

-g, --nograph-funcs=

Sélectionner le traçeur function_graph et définir un filtre no-trace de graphe sur la fonction donnée (ou un modèle glob). Comme l'option -G, ceci est utile uniquement pour le traçeur function_graph et désactive le traçage des fonctions exécutées à partir de la fonction donnée. Cela peut être utilisé plusieurs fois pour spécifier plusieurs fonctions. Il sera passé à set_graph_notrace dans tracefs.

--graph-opts

Liste des options autorisées à être définies :
•args - Afficher les arguments de la fonction.
•retval - Afficher la valeur de retour de la fonction.
•retval-hex - Afficher la valeur de retour de la fonction au format hexadécimal.
•retaddr - Afficher l'adresse de retour de la fonction.
•nosleep-time - Mesurer le temps CPU uniquement pour le traçeur function_graph.
•noirqs - Ignorer les fonctions qui se produisent pendant une interruption.
•verbose - Afficher les noms des processus, PID, horodatages, etc.
•thresh=<n> - Définir le seuil de durée de traçage en microsecondes.
•depth=<n> - Définir la profondeur maximale que le traçeur de graphes de fonctions doit suivre.
•tail - Imprimer le nom de la fonction à la fin.

OPTIONS POUR PERF FTRACE LATENCY

-T, --trace-funcs=

Définir le nom de la fonction pour obtenir l'histogramme. Contrairement à perf ftrace trace, il n'autorise qu'une seule fonction pour calculer l'histogramme.

-e, --events=

Définir la paire d'événements pour obtenir l'histogramme. L'histogramme est calculé par la différence de temps entre les deux événements du même fil d'exécution. Ceci nécessite l'option -b/--use-bpf.

-b, --use-bpf

Utiliser BPF pour mesurer la latence de la fonction au lieu d'utiliser ftrace (il utilise le traçeur function_graph en interne).

-n, --use-nsec

Utiliser les nanosecondes au lieu des microsecondes comme unité de base de l'histogramme.

--bucket-range=

Plage de buckets en ms ou ns (selon -n/--use-nsec), par défaut en mode log2().

--min-latency=

Latence minimale pour le début du premier bucket, en ms ou ns (selon -n/--use-nsec).

--max-latency=

Latence maximale pour le début du dernier bucket, en ms ou ns (selon -n/--use-nsec). Le réglage est ignoré si la valeur entraîne plus de 22 buckets.

OPTIONS POUR PERF FTRACE PROFILE

-T, --trace-funcs=

Définir un filtre de fonctions sur la fonction donnée (ou un modèle glob). Plusieurs fonctions peuvent être données en utilisant cette option plusieurs fois. L'argument de fonction peut également être un modèle glob. Il sera passé à set_ftrace_filter dans tracefs.

-N, --notrace-funcs=

Ne pas tracer les fonctions données par l'argument. Comme l'option -T, cela peut être utilisé plusieurs fois pour spécifier plusieurs fonctions (ou modèles glob). Il sera passé à set_ftrace_notrace dans tracefs.

-G, --graph-funcs=

Définir un filtre de graphe sur la fonction donnée (ou un modèle glob). Ceci est utile pour tracer les fonctions exécutées à partir de la fonction donnée. Cela peut être utilisé plusieurs fois pour spécifier plusieurs fonctions. Il sera passé à set_graph_function dans tracefs.

-g, --nograph-funcs=

Définir un filtre no-trace de graphe sur la fonction donnée (ou un modèle glob). Comme l'option -G, ceci est utile uniquement pour le traçeur function_graph et désactive le traçage des fonctions exécutées à partir de la fonction donnée. Cela peut être utilisé plusieurs fois pour spécifier plusieurs fonctions. Il sera passé à set_graph_notrace dans tracefs.

-m, --buffer-size

Définir la taille du tampon de traçage par CPU, <taille> est attendu comme un nombre avec un caractère d'unité ajouté - B/K/M/G.

-s, --sort=

Trier le résultat par le champ donné. Les valeurs disponibles sont : total, avg, max, count, name. Par défaut, c'est total.

--graph-opts

Liste des options autorisées à être définies :
•nosleep-time - Mesurer le temps CPU uniquement pour le traçeur function_graph.
•noirqs - Ignorer les fonctions qui se produisent pendant une interruption.
•thresh=<n> - Définir le seuil de durée de traçage en microsecondes.
•depth=<n> - Définir la profondeur maximale que le traçeur de graphes de fonctions doit suivre.
