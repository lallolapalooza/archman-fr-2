PERL5382DELTA(1perl) Guide du programmeur Perl PERL5382DELTA(1perl)

NOM

perl5382delta - ce qui est nouveau pour la version perl v5.38.2

DESCRIPTION

Ce document décrit les différences entre la version 5.38.0 et la version 5.38.2. Attention : Ce document ignore Perl 5.38.1, une version défectueuse qui n'a existé que quelques jours.

Si vous mettez à niveau à partir d'une version antérieure telle que 5.37.0, lisez d'abord perl5380delta, qui décrit les différences entre 5.37.0 et 5.38.0.

Sécurité

Cette version corrige les problèmes de sécurité suivants.

CVE-2023-47038 - Écriture au-delà de la fin du tampon via une propriété Unicode définie par l'utilisateur illégale

Cette vulnérabilité a été signalée directement à l'équipe de sécurité de Perl par Nathan Mills <the.true.nathan.mills@gmail.com>.

Une expression régulière conçue, lorsqu'elle est compilée par perl 5.30.0 à 5.38.0, peut provoquer un débordement de tampon contrôlé par l'attaquant d'un octet dans un tampon alloué sur le tas.

CVE-2023-47039 - Vulnérabilité de détournement de binaire Perl pour Windows

Cette vulnérabilité a été signalée à l'équipe de réponse aux incidents de sécurité des produits Intel (PSIRT) par l'utilisateur GitHub ycdxsb https://github.com/ycdxsb/WindowsPrivilegeEscalation. PSIRT l'a ensuite signalée à l'équipe de sécurité de Perl.

Perl pour Windows s'appuie sur la variable d'environnement PATH pour trouver l'interpréteur de commandes ("cmd.exe"). Lors de l'exécution d'un exécutable qui utilise l'interpréteur Perl Windows, Perl tente de trouver et d'exécuter "cmd.exe" au sein du système d'exploitation. Cependant, en raison de problèmes d'ordre de recherche dans le chemin, Perl recherche d'abord cmd.exe dans le répertoire de travail actuel.

Un attaquant disposant de privilèges limités peut exploiter ce comportement en plaçant "cmd.exe" dans des emplacements avec des permissions faibles, tels que "C:\ProgramData". Ce faisant, lorsqu'un administrateur tente d'utiliser cet exécutable à partir de ces emplacements compromis, un code arbitraire peut être exécuté.

Remerciements

Perl 5.38.2 représente environ 5 mois de développement depuis Perl 5.38.0 et contient environ 6 100 lignes de modifications réparties sur 34 fichiers provenant de 4 auteurs.

Hors fichiers générés automatiquement, documentation et outils de publication, il y a eu environ 1 300 lignes de modifications dans 9 fichiers .pm, .t, .c et .h.

Perl continue de prospérer pour sa quatrième décennie grâce à une communauté dynamique d'utilisateurs et de développeurs. Les personnes suivantes sont connues pour avoir contribué aux améliorations qui sont devenues Perl 5.38.2 :

Karl Williamson, Paul Evans, Steve Hay, Tony Cook.

La liste ci-dessus est presque certainement incomplète car elle est générée automatiquement à partir de l'historique du contrôle de version. En particulier, elle n'inclut pas les noms des contributeurs (très appréciés) qui ont signalé des problèmes dans le traqueur de bugs de Perl.

Bon nombre des modifications incluses dans cette version proviennent des modules CPAN inclus dans le cœur de Perl. Nous sommes reconnaissants à l'ensemble de la communauté CPAN d'aider Perl à prospérer.

Pour une liste plus complète de tous les contributeurs historiques de Perl, veuillez consulter le fichier AUTHORS dans la distribution source de Perl.

Signaler des erreurs

Si vous trouvez ce qui vous semble être une erreur, vous pourriez consulter la base de données des erreurs de Perl sur https://github.com/Perl/perl5/issues. Il peut également y avoir des informations sur http://www.perl.org/, la page d'accueil de Perl.

Si vous pensez avoir une erreur non signalée, veuillez ouvrir un ticket sur https://github.com/Perl/perl5/issues. Assurez-vous de réduire votre erreur à un cas de test minuscule mais suffisant.

Si l'erreur que vous signalez a des implications de sécurité qui la rendent inappropriée à envoyer à un traqueur d'erreurs public, consultez "CONTACT INFORMATION FOR SECURITY VULNERABILITIES" dans perlsec pour plus de détails sur la manière de signaler le problème.

Remercier

Si vous souhaitez remercier les Perl 5 Porters pour le travail effectué dans Perl 5, vous pouvez le faire en exécutant le programme "perlthanks" :

perlthanks

Cela enverra un e-mail à la liste des Perl 5 Porters avec votre message de remerciement.
