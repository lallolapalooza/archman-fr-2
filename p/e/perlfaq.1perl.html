NOM

perlfaq — Questions fréquemment posées sur Perl

VERSION

version 5.20250619

DESCRIPTION

Le perlfaq comprend plusieurs documents qui répondent aux questions les plus fréquemment posées sur Perl et la programmation Perl. Il est divisé par sujet en neuf sections principales décrites dans ce document.

Où trouver le perlfaq

Le perlfaq est un document en constante évolution. Lisez la dernière version sur https://perldoc.perl.org/perlfaq. Il est également inclus dans la distribution Perl standard.

Comment utiliser le perlfaq

L'outil en ligne de commande "perldoc" fait partie de la distribution Perl standard. Pour lire le perlfaq :

$ perldoc perlfaq

Pour rechercher dans les titres de questions du perlfaq :

$ perldoc -q open

Comment contribuer au perlfaq

Consultez https://github.com/perl-doc-cats/perlfaq/wiki. Si vous n'y trouvez pas votre suggestion, créez un problème ou une demande de tirage sur https://github.com/perl-doc-cats/perlfaq.

Une fois approuvées, les modifications seront distribuées avec la prochaine version de Perl et apparaîtront ensuite sur https://perldoc.perl.org/perlfaq.

Et si ma question n'est pas répondue dans la FAQ ?

Essayez les ressources de perlfaq2.
