PERL5383DELTA(1perl) Guide de référence du programmeur Perl PERL5383DELTA(1perl)

NOM

perl5383delta - quoi de neuf pour la version perl v5.38.3

DESCRIPTION

Ce document décrit les différences entre la version 5.38.2 et la version 5.38.3.

Si vous mettez à jour depuis une version antérieure comme la 5.38.1, lisez d'abord perl5382delta, qui décrit les différences entre 5.38.1 et 5.38.2.

CHANGEMENTS INCOMPATIBLES

Il n'y a pas de changements intentionnellement incompatibles avec la version 5.38.2. S'il en existe, il s'agit de bugs, et nous vous demandons de soumettre un rapport. Voir "Signalement de bugs" ci-dessous.

MODULES ET PRAGMATES

Modules et pragmata mis à jour

  • DynaLoader a été mis à jour de la version 1.54 à 1.54_01.

    Ceci corrige une erreur lors de la compilation de Perl sur OS X 10.3. [GH #21751 https://github.com/Perl/perl5/issues/21751]

  • Module::CoreList a été mis à jour de la version 5.20231129 à 5.20250118_38.

DOCUMENTATION

Changements dans la documentation existante

Nous avons tenté de mettre à jour la documentation pour refléter les changements listés dans ce document. Si vous en trouvez que nous avons manqué, ouvrez un ticket sur https://github.com/Perl/perl5/issues.

TESTS

Des tests ont été ajoutés et modifiés pour refléter les autres ajouts et changements de cette version.

Corrections de bugs sélectionnées

  • "use 5.36;" ou plus récent n'activait pas les avertissements post-analyse de Nom "%s::%s" utilisé une seule fois : faute de frappe possible lors de l'activation des avertissements. [GH #21271 https://github.com/Perl/perl5/issues/21271]
  • Correction d'un crash ou d'une assertion lors de la suppression d'une closure qui fait référence à une sous-routine "our" externe. [GH #21067 https://github.com/Perl/perl5/issues/21067]
  • Ne pas effacer le drapeau entier "IOK" des lignes dans le tableau "@{"_<$sourcefile"}" lorsqu'une opération "dbstate" est supprimée pour cette ligne. Ceci a été cassé lors de la correction de [GH #19198 https://github.com/Perl/perl5/issues/19198]. [GH #21564 https://github.com/Perl/perl5/issues/21564]
  • Correction d'un problème où utf8n_to_uvchr() échouait à identifier correctement certaines séquences UTF-8 invalides comme invalides. Notamment, les séquences commençant par des octets de continuation ou des octets non assignés pouvaient entraîner un comportement inattendu ou un plantage. Cette correction garantit que de telles séquences invalides sont désormais correctement détectées et traitées. Cette correction résout également des problèmes connexes dans les modules qui traitent le traitement UTF-8, tels que Encode.
  • Les compilations avec "-msse" et quadmath sur des systèmes x86 32 bits plantaient avec un accès mal aligné tôt dans le processus de compilation. [GH #22577 https://github.com/Perl/perl5/issues/22577]
  • Correction d'un bug introduit dans Perl 5.34 où des données non initialisées dans le tableau sous-jacent d'un AV après qu'il a été décalé et redimensionné pouvait entraîner des erreurs de segmentation ou d'autres erreurs en fonction des données. [GH #21235 https://github.com/Perl/perl5/issues/21235]
  • Correction d'un problème où Perl échouait parfois à passer correctement à une locale avec un séparateur décimal point. [GH #21746 https://github.com/Perl/perl5/issues/21746] [GH #22176 https://github.com/Perl/perl5/issues/22176]
  • Arrêt de certains erreurs de syntaxe de provoquer des vidages de noyau en raison d'une double libération d'un OP. [GH #21724 https://github.com/Perl/perl5/issues/21724]
  • Correction d'une erreur de double libération ou d'une possible fuite de mémoire lors de l'échec de la compilation de certaines expressions régulières. [GH #21661 https://github.com/Perl/perl5/issues/21661]
  • Correction de l'initialisation de l'émulation querylocale() de Perl afin que la locale soit correctement définie si l'environnement spécifie une locale non-C. [GH #21366 https://github.com/Perl/perl5/issues/21366]

Remerciements

Perl 5.38.3 représente environ 14 mois de développement depuis Perl 5.38.2 et contient environ 5 600 lignes de changements réparties sur 62 fichiers de 22 auteurs.

En excluant les fichiers générés automatiquement, la documentation et les outils de publication, il y a eu environ 2 600 lignes de changements dans 20 fichiers .pm, .t, .c et .h.

Perl continue de prospérer dans sa quatrième décennie grâce à une communauté d'utilisateurs et de développeurs dynamique. Les personnes suivantes sont connues pour avoir contribué aux améliorations qui sont devenues Perl 5.38.3 :

La liste ci-dessus est presque certainement incomplète car elle est générée automatiquement à partir de l'historique du contrôle de version. En particulier, elle n'inclut pas les noms des contributeurs (très appréciés) qui ont signalé des problèmes dans le traqueur de bugs Perl.

Beaucoup des changements inclus dans cette version proviennent des modules CPAN inclus dans le cœur de Perl. Nous sommes reconnaissants envers toute la communauté CPAN d'aider Perl à prospérer.

Pour une liste plus complète de tous les contributeurs historiques de Perl, veuillez consulter le fichier AUTHORS dans la distribution source de Perl.

SIGNALEMENT DE BUGS

Si vous trouvez ce que vous pensez être un bug, vous pourriez consulter la base de données des bugs de perl sur https://github.com/Perl/perl5/issues. Il peut également y avoir des informations sur http://www.perl.org/, la page d'accueil de Perl.

Si vous pensez avoir un bug non signalé, veuillez ouvrir un ticket sur https://github.com/Perl/perl5/issues. Assurez-vous de réduire votre bug à un cas de test minimal mais suffisant.

Si le bug que vous signalez a des implications de sécurité qui le rendent inapproprié à envoyer à un traqueur de bugs public, alors consultez "INFORMATIONS DE CONTACT EN CAS DE VULNÉRABILITÉ DE SÉCURITÉ" dans perlsec pour plus de détails sur la manière de signaler le problème.

Lui envoyer des remerciements

Si vous souhaitez remercier les Perl 5 Porters pour le travail que nous avons accompli dans Perl 5, vous pouvez le faire en exécutant le programme "perlthanks" :

perlthanks

Cela enverra un e-mail à la liste Perl 5 Porters avec votre message de remerciement.
