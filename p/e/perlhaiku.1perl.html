NOM

perlhaiku - Perl version 5.10+ sur Haiku

DESCRIPTION

Ce fichier contient des instructions sur la façon de compiler Perl pour Haiku et liste les problèmes connus.

COMPILATION ET INSTALLATION

La procédure de compilation est entièrement standard :

./Configure -de
make
make install

Rendez Perl exécutable et créez un lien symbolique pour libperl :

chmod a+x /boot/common/bin/perl
cd /boot/common/lib; ln -s perl5/5.42.0/BePC-haiku/CORE/libperl.so .

Remplacez 5.42.0 par votre version respective de Perl.

PROBLÈMES CONNUS

Les problèmes suivants sont rencontrés avec la révision Haiku 28311 :

  • Perl ne peut pas être compilé avec le support des threads pour le moment.
  • Le test cpan/Socket/t/socketpair.t échoue. Plus précisément : les sous-tests utilisant des sockets datagrammes échouent. Les sockets datagrammes Unix ne sont pas encore implémentés dans Haiku.
  • Un sous-test du test cpan/Sys-Syslog/t/syslog.t échoue. Cela est dû au fait que Haiku n'implémente pas encore le support de /dev/log.
  • Les tests dist/Net-Ping/t/450_service.t et dist/Net-Ping/t/510_ping_udp.t échouent. Ceci est dû à des bugs dans l'implémentation de la pile réseau de Haiku.

CONTACT

Pour les problèmes spécifiques à Haiku, contactez les développeurs de HaikuPorts : https://github.com/haikuports/haikuports
