PERL5143DELTA(1perl) Guide de référence du programmeur Perl PERL5143DELTA(1perl)

NOM

perl5143delta - ce qu'il y a de nouveau dans la version Perl v5.14.3

DESCRIPTION

Ce document décrit les différences entre la version 5.14.2 et la version 5.14.3.

Si vous mettez à niveau à partir d'une version antérieure telle que 5.12.0, lisez d'abord perl5140delta, qui décrit les différences entre 5.12.0 et 5.14.0.

Améliorations principales

Aucun changement depuis la version 5.14.0.

Sécurité

Utilisation dangereuse de l'eval dans "Digest" (CVE-2011-3597)

La fonction "Digest->new()" ne sanctionnait pas correctement l'entrée avant de l'utiliser dans un appel **eval()**, ce qui pouvait conduire à l'injection de code Perl arbitraire.

Pour exploiter cette faille, l'attaquant aurait eu besoin de pouvoir définir le nom de l'algorithme utilisé, ou d'être capable d'exécuter du code Perl arbitraire déjà.

Ce problème a été corrigé.

Dépassement de tampon dans le tas de l'opérateur de répétition de chaîne 'x' (CVE-2012-5195)

Un code Perl mal écrit qui permet à un attaquant de spécifier le compteur pour l'opérateur de répétition de chaîne 'x' de Perl peut déjà provoquer une attaque par déni de service par épuisement de la mémoire. Une faille dans les versions de Perl antérieures à 5.15.5 peut l'aggraver en un dépassement de tampon dans le tas ; couplé avec des versions de glibc antérieures à 2.16, cela permet potentiellement l'exécution de code arbitraire.

Ce problème a été corrigé.

Changements incompatibles

Il n'y a aucun changement intentionnellement incompatible avec la version 5.14.0. S'il y en a, ce sont des bugs et les rapports sont les bienvenus.

Dépréciations

Il n'y a eu aucune dépréciation depuis la version 5.14.0.

Modules et Pragmata

Nouveaux Modules et Pragmata

Aucun

Modules et Pragmata Mis à jour

  • PerlIO::scalar a été mis à jour pour corriger un bug dans lequel l'ouverture d'un handle de fichier vers une copie de glob provoquait des échecs d'assertion (en mode débogage) ou des blocages ou d'autres comportements erratiques sans débogage.
  • ODBM_File et NDBM_File ont été mis à jour pour permettre la compilation sur GNU/Hurd.
  • IPC::Open3 a été mis à jour pour corriger une régression introduite dans Perl 5.12, qui cassait "IPC::Open3::open3($in, $out, $err, '-')". [perl #95748]
  • Digest a été mis à niveau de la version 1.16 à 1.16_01.

    Voir "Sécurité".

  • Module::CoreList a été mis à jour vers la version 2.49_04 pour ajouter les données de cette version.

Configuration et Compilation

  • h2ph a été mis à jour pour rechercher correctement les répertoires d'inclusion de gcc sur les plateformes telles que Debian avec prise en charge multi-architecture.
  • Dans Configure, le test pour procselfexe a été refactorisé en une boucle.

Notes Spécifiques à la Plateforme

FreeBSD
Le fichier d'indices FreeBSD a été corrigé pour être compatible avec FreeBSD 10.0.
Solaris et NetBSD
Configure a été mis à jour pour la prise en charge de "procselfexe" sur Solaris et NetBSD.
HP-UX
README.hpux a été mis à jour pour signaler l'existence d'un en-tête défectueux dans HP-UX 11.00.
Linux
libutil n'est plus utilisé lors de la compilation sur les plateformes Linux, ce qui évite l'émission d'avertissements.

Le compilateur gcc système (plutôt que tout autre gcc qui pourrait se trouver dans le chemin de l'utilisateur qui compile) est maintenant utilisé lors de la recherche de bibliothèques telles que "-lm".

Mac OS X
Les tests de locale ont été mis à jour pour refléter le comportement des locales dans Mountain Lion.
GNU/Hurd
Divers correctifs de compilation et de test ont été inclus pour GNU/Hurd.

Le support LFS a été activé dans GNU/Hurd.

NetBSD
Le fichier d'indices NetBSD a été corrigé pour être compatible avec NetBSD 6.*

Corrections de Bugs

  • Une régression introduite en 5.14 dans la correspondance d'expressions régulières avec "/i" a été corrigée. Dans cette régression, une correspondance échoue de manière incorrecte si le motif est en UTF-8, la chaîne cible ne l'est pas, et un caractère Latin-1 précède un caractère dans la chaîne qui devrait correspondre au motif. [perl #101710]
  • Dans la correspondance de motifs d'expressions régulières insensible à la casse, sur les chaînes encodées en UTF-8, la recherche du début de la correspondance ne se limitera plus à la première position possible. Cela faisait échouer des correspondances telles que ""f\x{FB00}" =~ /ff/i".
  • Le support de sitecustomize a été rendu conscient de relocatableinc, de sorte que -Dusesitecustomize et -Duserelocatableinc puissent être utilisés ensemble.
  • L'opérateur de correspondance intelligente ("~~") a été modifié de sorte que le côté droit ait la priorité lors des opérations "Any ~~ Object".
  • Un bug dans le support de "tainting" a été corrigé, où une opération index() sur une constante "tainted" entraînait la "tainting" de toutes les autres constantes. [perl #64804]
  • Une régression introduite dans Perl 5.12 a été corrigée, où les erreurs de "tainting" n'étaient pas correctement propagées via die(). [perl #111654]
  • Une régression introduite dans Perl 5.14 a été corrigée, où "/[[:lower:]]/i" et "/[[:upper:]]/i" ne correspondaient plus à la casse opposée. [perl #101970]

Signalement des bogues

Si vous trouvez ce que vous pensez être un bogue, vous pouvez consulter les articles récemment publiés sur le groupe de discussion comp.lang.perl.misc et la base de données des bogues de Perl à l'adresse http://rt.perl.org/perlbug/ . Des informations peuvent également être disponibles sur http://www.perl.org/ , la page d'accueil de Perl.

Si vous pensez avoir un bogue non signalé, veuillez exécuter le programme perlbug inclus avec votre version. Assurez-vous de réduire votre bogue à un cas de test minuscule mais suffisant. Votre rapport de bogue, ainsi que la sortie de "perl -V", seront envoyés à perlbug@perl.org pour être analysés par l'équipe de portage de Perl.

Si le bogue que vous signalez a des implications de sécurité, ce qui le rend inapproprié à envoyer à une liste de diffusion publiquement archivée, veuillez l'envoyer à perl5-security-report@perl.org. Cela pointe vers une liste de diffusion à abonnement fermé et non archivée, qui comprend tous les committers principaux, qui seront en mesure d'aider à évaluer l'impact des problèmes, de trouver une solution et d'aider à coordonner la publication de correctifs pour atténuer ou résoudre le problème sur toutes les plateformes sur lesquelles Perl est pris en charge. Veuillez n'utiliser cette adresse que pour les problèmes de sécurité dans le noyau de Perl, et non pour les modules distribués indépendamment sur CPAN.
