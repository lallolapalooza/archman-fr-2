NOM

perror - expliquer les codes d'erreur

SYNTAXE

perror [options] code_erreur ...

DESCRIPTION

Pour la plupart des erreurs système, MariaDB affiche, en plus d'un message texte interne, le code d'erreur système dans l'un des styles suivants :

message ... (errno: #)
message ... (Errcode: #)

Vous pouvez découvrir ce que signifie le code d'erreur en examinant la documentation de votre système ou en utilisant l'utilitaire perror.

perror imprime une description d'un code d'erreur système ou d'un code d'erreur de moteur de stockage (gestionnaire de table).

Invoquez perror comme suit :

shell> perror [options] code_erreur ...

Exemple :

shell> perror 13 64
OS error code  13:  Permission denied
OS error code  64:  Machine is not on the network

Notez que la signification des messages d'erreur système peut dépendre de votre système d'exploitation. Un code d'erreur donné peut signifier des choses différentes sur différents systèmes d'exploitation.

perror prend en charge les options suivantes.

•--help, --info, -I, -?

Affiche un message d'aide et quitte.

•--silent, -s

Mode silencieux. Imprime uniquement le message d'erreur.

•--verbose, -v

Mode verbeux. Imprime le code d'erreur et le message. C'est le comportement par défaut.

•--version, -V

Affiche les informations de version et quitte.
