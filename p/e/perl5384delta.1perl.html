NOM

perl5384delta - ce qu'il y a de nouveau pour la version perl v5.38.4

DESCRIPTION

Ce document décrit les différences entre la version 5.38.3 et la version 5.38.4.

Si vous mettez à jour depuis une version antérieure comme la 5.38.2, lisez d'abord perl5383delta, qui décrit les différences entre la 5.38.2 et la 5.38.3.

Sécurité

[CVE-2024-56406] Vulnérabilité de dépassement de tampon sur le tas avec tr//

Une vulnérabilité de dépassement de tampon sur le tas a été découverte dans Perl.

Lorsqu'il y a des octets non-ASCII dans la partie gauche de l'opérateur "tr", S_do_trans_invmap() peut dépasser le pointeur de destination "d".

$ perl -e '$_ = "\x{FF}" x 1000000; tr/\xFF/\x{100}/;'
Segmentation fault (core dumped)

On estime que cette vulnérabilité peut permettre des attaques par déni de service ou par exécution de code arbitraire sur des plateformes qui manquent de défenses suffisantes.

Découvert par : Nathan Mills.

Changements incompatibles

Il n'y a pas de changements intentionnellement incompatibles avec la version 5.38.3. S'il en existe, il s'agit de bogues, et nous vous prions de soumettre un rapport. Voir "Signalement de bogues" ci-dessous.

Remerciements

Perl 5.38.4 représente environ 3 mois de développement depuis Perl 5.38.3 et contient environ 1 500 lignes de modifications réparties sur 36 fichiers de 7 auteurs.

En excluant les fichiers générés automatiquement, la documentation et les outils de publication, il y a eu environ 640 lignes de modifications dans les fichiers .pm, .t, .c et .h de Perl 5.

Perl continue de prospérer dans sa quatrième décennie grâce à une communauté dynamique d'utilisateurs et de développeurs. Les personnes suivantes sont connues pour avoir contribué aux améliorations apportées à Perl 5.38.4 :

Karl Williamson, Lukas Mai, Max Maischein, Paul Evans, Richard Leach, Steve Hay, Thibault Duponchelle.

La liste ci-dessus est presque certainement incomplète car elle est générée automatiquement à partir de l'historique du contrôle de version. En particulier, elle n'inclut pas les noms des contributeurs (très appréciés) qui ont signalé des problèmes sur le traqueur de bogues de Perl.

Beaucoup des changements inclus dans cette version proviennent des modules CPAN inclus dans le noyau de Perl. Nous sommes reconnaissants envers toute la communauté CPAN pour avoir aidé Perl à prospérer.

Pour une liste plus complète de tous les contributeurs historiques de Perl, veuillez consulter le fichier AUTHORS dans la distribution source de Perl.

Signalement de bogues

Si vous trouvez ce que vous pensez être un bogue, vous pouvez consulter la base de données des bogues de Perl à l'adresse https://github.com/Perl/perl5/issues. Vous trouverez peut-être également des informations sur https://www.perl.org/, la page d'accueil de Perl.

Si vous pensez avoir un bogue non signalé, veuillez ouvrir un ticket sur https://github.com/Perl/perl5/issues. Assurez-vous de réduire votre bogue à un exemple de test simple mais suffisant.

Si le bogue que vous signalez a des implications en matière de sécurité qui le rendent inapproprié à l'envoi à un traqueur de problèmes public, alors consultez "SECURITY VULNERABILITY CONTACT INFORMATION" dans perlsec pour plus de détails sur la façon de signaler le problème.

Envoyer des remerciements

Si vous souhaitez remercier les Perl 5 Porters pour le travail accompli dans Perl 5, vous pouvez le faire en exécutant le programme "perlthanks" :

perlthanks

Cela enverra un e-mail à la liste Perl 5 Porters avec votre témoignage de gratitude.
