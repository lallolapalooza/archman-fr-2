NOM

pedigree - créer un fichier TeX pour un arbre généalogique à partir d'un fichier csv

SYNTAXE

pedigree [-c fichier_configuration] [-d] [-o fichier_sortie] [-s id_debut] fichier_entree

pedigree -v

DESCRIPTION

Le programme convertit un fichier_entree séparé par des virgules en un fichier TeX utilisant les macros pst-pdgr.

OPTIONS

-c fichier_configuration
Le fichier de configuration à lire, en plus des fichiers de configuration système et utilisateur.
-d
Mode débogage activé.
-o -fichier_sortie
Le fichier de sortie au lieu de fichier_entree.tex.
-s -id_debut
Si cette option est sélectionnée, l'arbre généalogique est construit à partir du nœud avec l'identifiant i<id_debut>. Sinon, il est démarré à partir du nœud probant.

Cette option permet de créer des arbres généalogiques avec plusieurs probants ou des probants absents, ou de montrer des personnes qui ne sont pas des parents du probant.

-v
Afficher les informations sur la version.

FICHIERS

/etc/pedigree.cfg
Fichier de configuration global.
$HOME/.pedigreerc
Fichier de configuration utilisateur.

VOIR AUSSI

Le manuel distribué avec ce programme décrit le format du fichier de configuration et du fichier d'entrée.

Les fonctions de bibliothèque sont décrites dans Pedigree::Language(3), Pedigree::Parser(3), Pedigree::Node(3), Pedigree::PersonNode(3), Pedigree::MarriageNode(3), Pedigree::Area(3).
