NOM

perf-buildid-list - Liste les buildids dans un fichier perf.data

SYNTAXE

perf buildid-list <options>

DESCRIPTION

Cette commande affiche les buildids trouvés dans un fichier perf.data, afin que d'autres outils puissent être utilisés pour récupérer les paquets avec des tables de symboles correspondantes pour être utilisées par perf report.

Elle peut également être utilisée pour afficher le build id du noyau en cours d'exécution ou dans un fichier ELF en utilisant -i/--input.

OPTIONS

-H, --with-hits

Affiche uniquement les DSO avec des succès.

-i, --input=

Nom du fichier d'entrée. (par défaut : perf.data sauf si stdin est un fifo)

-f, --force

Ne pas effectuer de validation de propriété.

-k, --kernel

Affiche le build id du noyau en cours d'exécution.

-m, --kernel-maps

Affiche le buildid, l'adresse texte de début/fin et le chemin du noyau en cours d'exécution et de ses modules.

-v, --verbose

Soyez plus verbeux.

VOIR AUSSI

perf-record(1), perf-top(1), perf-report(1)
