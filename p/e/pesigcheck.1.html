PESIGCHECK(1) Manuel des commandes générales PESIGCHECK(1)

NOM

pesigcheck — outil pour vérifier les applications UEFI

SYNTAXE

pesigcheck -i fichier [-n] [-D fichier] [-X fichier] [-c fichier] [-q] [-v]

DESCRIPTION

pesigcheck est un outil en ligne de commande pour la vérification de la signature des applications UEFI.

OPTIONS

-i fichier | --in fichier
Fichier binaire PE fichier à vérifier
-n | --no-system-db
interdire l'utilisation de DB et DBX du système en cours d'exécution
-D fichier | --dbfile fichier
Liste de signatures EFI ou variable EFI fichier à utiliser comme base de données de sécurité autorisée

peut être utilisé plusieurs fois

-X fichier | --dbxfile fichier
Liste de signatures EFI ou variable EFI fichier à utiliser comme base de données de sécurité mise sur liste noire

peut être utilisé plusieurs fois

-c fichier | --certfile fichier
Fichier certificat encodé en DER fichier à ajouter à la base de données de sécurité autorisée

peut être utilisé plusieurs fois

-q | --quiet
être plus silencieux
-v | --verbose
être plus verbeux

NORMES

UEFI Specification Working Group, Unified Extensible Firmware Interface (UEFI) Specification Version 2.8, Unified Extensible Firmware Interface Forum, https://uefi.org/specifications , Mars 2019.

VOIR AUSSI

authvar(1), pesign(1), efisigdb(1)
