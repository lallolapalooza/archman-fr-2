NOM

pekwm_bg - une application simple de réglage de fond k

SYNOPSIS

pekwm_bg [--display] texture

DESCRIPTION

pekwm_bg est une application simple de réglage de fond incluse avec pekwm et elle est généralement exécutée chaque fois qu'un thème spécifie une texture de fond.

pekwm_bg répète la texture sur chaque tête, faisant apparaître les images une fois pour chaque tête disponible.

pekwm_bg accepte les textures dans le même format que les thèmes pekwm, où les plus courantes pour les fonds sont :

  • Image background.png#scaled, background.png mis à l'échelle à la taille de l'écran.
  • Solide #eeeeee, couleur unie.
  • LinesHorz 33% #afadbf #9f9daf #afadbf, 3 lignes horizontales.

OPTIONS

--daemon, s'exécute en tant que démon.

--display DISPLAY Se connecte à DISPLAY au lieu de DISPLAY défini dans l'environnement.

--help Affiche les informations d'aide.

--load-dir DIR Charge les images depuis le répertoire spécifié.

--stop Arrête l'exécution du démon pekwm_bg.
