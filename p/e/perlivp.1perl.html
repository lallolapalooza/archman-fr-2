PERLIVP(1perl) Guide de référence du programmeur Perl PERLIVP(1perl)

NOM

perlivp - Procédure de vérification d'installation de Perl

SYNTAXE

perlivp [-p] [-v] [-h]

DESCRIPTION

Le programme perlivp est configuré lors de la compilation du code source de Perl pour tester la version de Perl sous laquelle il a été compilé. Il peut être utilisé après l'exécution de :

make install

(ou la procédure équivalente sur votre plateforme) pour vérifier que perl et ses bibliothèques ont été correctement installés. Une installation correcte est vérifiée par une sortie ressemblant à :

ok 1
ok 2

etc.

OPTIONS

-h aide
Affiche un bref message d'aide.
-p afficher préface
Donne une description de chaque test avant de l'effectuer.
-v verbeux
Donne des informations plus détaillées sur chaque test, après qu'il ait été effectué. Notez que tout test échoué devrait afficher des informations supplémentaires que le drapeau -v soit utilisé ou non.

DIAGNOSTICS

  • print "# Le binaire Perl '$perlpath' ne semble pas exécutable.\n";

    Risque de se produire pour un binaire perl qui n'a pas été correctement installé. Corrigez en effectuant une installation correcte.

  • print "# La version Perl '$]' installée, attendue $ivp_VERSION.\n";

    Risque de se produire pour un perl qui n'a pas été correctement installé. Corrigez en effectuant une installation correcte.

  • print "# Le répertoire \@INC de Perl '$_' ne semble pas exister.\n";

    Risque de se produire pour un arbre de bibliothèques Perl qui n'a pas été correctement installé. Corrigez en effectuant une installation correcte.

  • print "# Le module requis '$_' ne semble pas être correctement installé.\n";

    L'un des deux modules utilisés par perlivp n'était pas présent dans l'installation. C'est une erreur grave car cela affecte la capacité de fonctionnement de perlivp. Vous pourrez peut-être corriger cela en effectuant une installation Perl correcte.

  • print "# Le module requis '$_' ne semble pas être correctement installé.\n";

    Une tentative d'"eval " require $module"" a échoué, même si la liste des extensions indiquait qu'elle devrait réussir. Corrigez en effectuant une installation correcte.

  • print "# Le module inutile 'bLuRfle' semble être installé.\n";

    L'échec de ce test pourrait indiquer que vous avez en fait installé un module bLuRfle.pm ou que le test "eval " require \"$module_name.pm\"; "" peut donner des résultats trompeurs avec votre installation de perl. Si vous êtes dans le second cas, veuillez en informer l'auteur.

  • print "# fichier",+($#missing == 0) ? '' : 's'," manquant dans l'installation :\n";

    Un ou plusieurs fichiers sont manquants selon une exécution de "ExtUtils::Installed -> validate()" sur votre installation. Corrigez en effectuant une installation correcte.

Pour plus d'informations sur la manière de procéder à une installation correcte, consultez le fichier INSTALL fourni avec le code source de Perl et le fichier README pour votre plateforme.
