NOM

pekwm_theme - gestionnaire de thèmes pour pekwm

SYNTAXE

pekwm_theme [installer|désinstaller|afficher|rechercher|nouveau]

DESCRIPTION

pekwm_theme est un gestionnaire de thèmes pour pekwm qui gère les opérations d'*installation*, *suppression*, *recherche* et *aperçu* des thèmes disponibles dans l'index de thèmes pekwm (https://github.com/pekwm/pekwm-theme-index/) et publiés sur le site des thèmes pekwm (https://www.pekwm.se/themes/).

OPTIONS

installer, installe un thème avec le nom fourni.

désinstaller, désinstalle un thème avec le nom fourni. Supprimera les modifications locales, à utiliser avec précaution.

afficher, affiche un aperçu du thème avec le nom fourni.

rechercher, recherche des thèmes correspondant au motif fourni (grep).

nouveau, crée un nouveau thème à partir d'un modèle.
