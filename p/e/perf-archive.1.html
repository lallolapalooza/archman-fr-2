NOM

perf-archive - Crée une archive avec les fichiers objets contenant des build-ids trouvés dans le fichier perf.data

SYNTAXE

perf archive [fichier]

DESCRIPTION

Cette commande exécute perf-buildid-list --with-hits, et collecte les fichiers contenant les build-ids trouvés afin que l'analyse du contenu de perf.data soit possible sur une autre machine.

VOIR AUSSI

perf-record(1), perf-buildid-list(1), perf-report(1)
