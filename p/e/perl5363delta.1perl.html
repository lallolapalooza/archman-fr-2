NOM

perl5363delta - Quoi de neuf pour la v5.36.3 de Perl

DESCRIPTION

Ce document décrit les différences entre la version 5.36.1 et la version 5.36.3. Notez bien : Ce document ignore la version 5.36.2 de Perl, une version défectueuse qui n'a existé que quelques jours.

Si vous effectuez une mise à niveau depuis une version antérieure telle que la 5.36.0, lisez d'abord perl5361delta, qui décrit les différences entre la 5.36.0 et la 5.36.1.

Sécurité

Cette version corrige les problèmes de sécurité suivants.

CVE-2023-47038 - Écriture hors des limites du tampon via une propriété Unicode illégale définie par l'utilisateur

Cette vulnérabilité a été signalée directement à l'équipe de sécurité de Perl par Nathan Mills "the.true.nathan.mills@gmail.com".

Une expression régulière spécialement conçue, lorsqu'elle est compilée par perl 5.30.0 à 5.38.0, peut provoquer un débordement de tampon contrôlé par l'attaquant d'un octet dans un tampon alloué sur le tas.

CVE-2023-47039 - Vulnérabilité d'usurpation de binaire Perl pour Windows

Cette vulnérabilité a été signalée à l'équipe de réponse aux incidents de sécurité des produits Intel (PSIRT) par l'utilisateur GitHub ycdxsb https://github.com/ycdxsb/WindowsPrivilegeEscalation. La PSIRT l'a ensuite signalée à l'équipe de sécurité de Perl.

Perl pour Windows s'appuie sur la variable d'environnement PATH système pour trouver le shell ("cmd.exe"). Lors de l'exécution d'un exécutable qui utilise l'interpréteur Perl de Windows, Perl tente de trouver et d'exécuter "cmd.exe" au sein du système d'exploitation. Cependant, en raison de problèmes d'ordre de recherche de chemin, Perl recherche initialement cmd.exe dans le répertoire de travail actuel.

Un attaquant disposant de privilèges limités peut exploiter ce comportement en plaçant "cmd.exe" dans des emplacements dotés d'autorisations faibles, tels que "C:\ProgramData". Ce faisant, lorsqu'un administrateur tente d'utiliser cet exécutable à partir de ces emplacements compromis, un code arbitraire peut être exécuté.

Remerciements

Perl 5.36.3 représente environ 1 mois de développement depuis Perl 5.36.1 et contient environ 2 300 lignes de modifications réparties sur 38 fichiers de 4 auteurs.

En excluant les fichiers générés automatiquement, la documentation et les outils de publication, il y a eu environ 1 400 lignes de modifications apportées à 8 fichiers .pm, .t, .c et .h.

Perl continue de prospérer dans sa quatrième décennie grâce à une communauté dynamique d'utilisateurs et de développeurs. Les personnes suivantes sont connues pour avoir contribué aux améliorations apportées à Perl 5.36.3 :

Karl Williamson, Paul Evans, Steve Hay, Tony Cook.

La liste ci-dessus est presque certainement incomplète car elle est générée automatiquement à partir de l'historique du contrôle de version. En particulier, elle n'inclut pas les noms des contributeurs (très appréciés) qui ont signalé des problèmes au traqueur de bugs de Perl.

Bon nombre des modifications incluses dans cette version proviennent des modules CPAN inclus dans le cœur de Perl. Nous sommes reconnaissants à l'ensemble de la communauté CPAN d'aider Perl à prospérer.

Pour une liste plus complète de tous les contributeurs historiques de Perl, veuillez consulter le fichier AUTHORS dans la distribution source de Perl.

Signalement des bogues

Si vous trouvez ce qui vous semble être un bogue, vous pouvez consulter la base de données des bogues de Perl sur https://github.com/Perl/perl5/issues. Vous trouverez peut-être également des informations sur http://www.perl.org/, la page d'accueil de Perl.

Si vous pensez avoir un bogue non signalé, veuillez ouvrir un ticket sur https://github.com/Perl/perl5/issues. Assurez-vous de réduire votre bogue à un exemple de test minimal mais suffisant.

Si le bogue que vous signalez a des implications en matière de sécurité qui le rendent inapproprié pour un traqueur de bogues public, veuillez consulter la section "INFORMATIONS DE CONTACT EN CAS DE VULNÉRABILITÉ DE SÉCURITÉ" dans perlsec pour plus de détails sur la façon de signaler le problème.

Donner des remerciements

Si vous souhaitez remercier les Perl 5 Porters pour le travail accompli dans Perl 5, vous pouvez le faire en exécutant le programme "perlthanks" :

perlthanks

Cela enverra un e-mail à la liste des Perl 5 Porters avec votre expression de gratitude.
