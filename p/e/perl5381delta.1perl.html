PERL5381DELTA(1perl) Guide de référence pour les programmeurs Perl PERL5381DELTA(1perl)

NOM

perl5381delta - ce qui est nouveau dans la version perl v5.38.1

DESCRIPTION

Ce document décrit les différences entre la version 5.38.0 et la version 5.38.1.

Si vous mettez à jour depuis une version antérieure telle que la 5.36.0, lisez d'abord perl5380delta, qui décrit les différences entre les versions 5.36.0 et 5.38.0.

Sécurité

Cette version corrige les problèmes de sécurité suivants.

CVE-2023-47038 - Écriture au-delà de la fin du tampon via une propriété Unicode définie par l'utilisateur non valide

Cette vulnérabilité a été signalée directement à l'équipe de sécurité Perl par Nathan Mills "the.true.nathan.mills@gmail.com".

Une expression régulière fabriquée lors de sa compilation par perl 5.30.0 à 5.38.0 peut provoquer un débordement de tampon d'un octet contrôlé par l'attaquant dans un tampon alloué sur le tas.

CVE-2023-47039 - Vulnérabilité de détournement de binaire de Perl pour Windows

Cette vulnérabilité a été signalée à l'équipe de réponse aux incidents de sécurité des produits Intel (PSIRT) par l'utilisateur GitHub ycdxsb https://github.com/ycdxsb/WindowsPrivilegeEscalation. PSIRT l'a ensuite signalée à l'équipe de sécurité Perl.

Perl pour Windows s'appuie sur la variable d'environnement PATH du système pour trouver le shell ("cmd.exe"). Lors de l'exécution d'un exécutable qui utilise l'interpréteur Perl Windows, Perl tente de trouver et d'exécuter "cmd.exe" dans le système d'exploitation. Cependant, en raison de l'ordre de recherche des chemins, Perl recherche d'abord cmd.exe dans le répertoire de travail actuel.

Un attaquant disposant de privilèges limités peut exploiter ce comportement en plaçant "cmd.exe" dans des emplacements aux permissions faibles, tels que "C:\ProgramData". Ce faisant, lorsqu'un administrateur tente d'utiliser cet exécutable depuis ces emplacements compromis, un code arbitraire peut être exécuté.

Remerciements

Perl 5.38.1 représente environ 5 mois de développement depuis Perl 5.38.0 et contient environ 6 100 lignes de changements réparties sur 34 fichiers de 4 auteurs.

En excluant les fichiers générés automatiquement, la documentation et les outils de publication, il y a eu environ 1 300 lignes de changements dans 9 fichiers .pm, .t, .c et .h.

Perl continue de s'épanouir dans sa quatrième décennie grâce à une communauté dynamique d'utilisateurs et de développeurs. Les personnes suivantes sont connues pour avoir contribué aux améliorations qui sont devenues Perl 5.38.1 :

Karl Williamson, Paul Evans, Steve Hay, Tony Cook.

La liste ci-dessus est presque certainement incomplète car elle est générée automatiquement à partir de l'historique du contrôle de version. En particulier, elle n'inclut pas les noms des contributeurs (très appréciés) qui ont signalé des problèmes au traqueur de bogues de Perl.

Beaucoup des changements inclus dans cette version proviennent des modules CPAN inclus dans le noyau de Perl. Nous sommes reconnaissants envers toute la communauté CPAN d'avoir aidé Perl à s'épanouir.

Pour une liste plus complète de tous les contributeurs historiques de Perl, veuillez consulter le fichier AUTHORS dans la distribution source de Perl.

Signalement de bogues

Si vous trouvez ce qui vous semble être un bogue, vous pourriez consulter la base de données des bogues de perl à https://github.com/Perl/perl5/issues. Il peut également y avoir des informations sur http://www.perl.org/, la page d'accueil de Perl.

Si vous pensez avoir un bogue non signalé, veuillez ouvrir un ticket sur https://github.com/Perl/perl5/issues. Assurez-vous de réduire votre bogue à un cas de test minimal mais suffisant.

Si le bogue que vous signalez a des implications de sécurité qui le rendent inapproprié pour un traqueur de bogues public, alors consultez "SECURITY VULNERABILITY CONTACT INFORMATION" dans perlsec pour plus de détails sur la manière de signaler le problème.

Remercier

Si vous souhaitez remercier les Perl 5 Porters pour le travail accompli dans Perl 5, vous pouvez le faire en exécutant le programme "perlthanks" :

perlthanks

Cela enverra un courriel à la liste Perl 5 Porters avec votre témoignage de gratitude.
