perfquery(8) Diagnostics Open IB perfquery(8)

Nom

perfquery - interroger les compteurs de ports InfiniBand sur un port unique

Syntaxe

perfquery [options] [<lid|guid> [[port(s)] [masque_reset]]]

Description

perfquery utilise les GMP de PerfMgt pour obtenir les compteurs de ports (compteurs de performance et d'erreurs de base), les compteurs étendus de ports, les données transmises par port SL, les données reçues par port SL, les détails des erreurs de réception de port, les détails des rejets de transmission, les compteurs de vitesses étendus, ou le contrôle d'échantillons de port à partir du PMA sur le nœud/port spécifié. Affiche éventuellement les compteurs agrégés pour tous les ports du nœud. Enfin, il peut réinitialiser les compteurs après lecture, ou simplement les réinitialiser.

Note : Dans PortCounters, PortCountersExtended, PortXmitDataSL et PortRcvDataSL, les composants qui représentent des données (par exemple, PortXmitData et PortRcvData) indiquent des octets divisés par 4 plutôt que de simples octets.

Note : La saisie d'un port de 255 indique qu'une opération doit être effectuée sur tous les ports.

Note : Pour PortCounters, ExtendedCounters et les réinitialisations, plusieurs ports peuvent être spécifiés par une liste séparée par des virgules ou une plage de ports. Voir les exemples ci-dessous.

Options

-x, --extended
afficher les compteurs de ports étendus plutôt que les compteurs de ports (de base). Notez que l'attribut des compteurs de ports étendus est facultatif.
-X, --xmtsl
afficher le compteur de données transmises par SL. C'est un compteur facultatif pour le QoS.
-S, --rcvsl
afficher le compteur de données reçues par SL. C'est un compteur facultatif pour le QoS.
-D, --xmtdisc
afficher les détails des rejets de transmission. C'est un compteur facultatif.
-E, --rcverr
afficher les détails des erreurs de réception. C'est un compteur facultatif.
-D, --xmtdisc
afficher les détails des rejets de transmission. C'est un compteur facultatif.
-T, --extended_speeds
afficher les compteurs de ports à vitesses étendues. C'est un compteur facultatif.
--oprcvcounters
afficher les compteurs de réception par code d'opération. C'est un compteur facultatif.
--flowctlcounters
afficher les compteurs de contrôle de flux. C'est un compteur facultatif.
--vloppackets
afficher les paquets reçus par code d'opération par VL. C'est un compteur facultatif.
--vlopdata
afficher les données reçues par code d'opération par VL. C'est un compteur facultatif.
--vlxmitflowctlerrors
afficher les erreurs de mise à jour du contrôle de flux par VL. C'est un compteur facultatif.
--vlxmitcounters
afficher les compteurs de temps d'attente pour la transmission par VL. C'est un compteur facultatif.
--swportvlcong
afficher la congestion du port logiciel par VL. C'est un compteur facultatif.
--rcvcc
afficher les compteurs de contrôle de congestion de réception. C'est un compteur facultatif.
--slrcvfecn
afficher les compteurs SL de réception FECN. C'est un compteur facultatif.
--slrcvbecn
afficher les compteurs SL de réception BECN. C'est un compteur facultatif.
--xmitcc
afficher les compteurs de contrôle de congestion de transmission. C'est un compteur facultatif.
--vlxmittimecc
afficher les compteurs de contrôle de congestion de temps de transmission VL. C'est un compteur facultatif.
-c, --smplctl
afficher le contrôle des échantillons de port.
-a, --all_ports
afficher les compteurs agrégés pour tous les ports du LID de destination, réinitialiser tous les compteurs pour tous les ports, ou si plusieurs ports sont spécifiés, agréger les compteurs des ports spécifiés. Si le LID de destination ne prend pas en charge le drapeau AllPortSelect, tous les ports seront parcourus pour émuler le comportement d'AllPortSelect.
-l, --loop_ports
Si tous les ports sont sélectionnés par l'utilisateur (soit via l'option -a, soit par le port 255) ou si plusieurs ports sont spécifiés, parcourir chaque port au lieu d'effectuer une opération d'agrégation.
-r, --reset_after_read
réinitialiser les compteurs après lecture
-R, --Reset_only
seulement réinitialiser les compteurs

Flags d'adressage

-G, --Guid L'adresse spécifiée est un GUID de port

-L, --Lid L'adresse spécifiée est un LID

-s, --sm_port <smlid> utiliser 'smlid' comme LID cible pour les requêtes SA.

Flags de sélection de port

-C, --Ca <nom_ca> utiliser le nom_ca spécifié.

-P, --Port <port_ca> utiliser le port_ca spécifié.

Sélection du port local

Support multi-port/multi-CA : lorsqu'aucun périphérique ou port IB n'est spécifié (voir les « paramètres umad locaux » ci-dessous), la bibliothèque libibumad sélectionne le port à utiliser selon les critères suivants :

1.
le premier port actif.
2.
si aucun n'est trouvé, le premier port actif (lien physique établi).

Si un nom de port et/ou de CA est spécifié, la bibliothèque libibumad tente de satisfaire la demande de l'utilisateur et échouera si ce n'est pas possible.

Par exemple :

ibaddr                 # utiliser le premier port (critère n°1 ci-dessus)
ibaddr -C mthca1       # choisir le meilleur port de "mthca1" uniquement.
ibaddr -P 2            # utiliser le deuxième port (actif/connecté) du premier périphérique IB disponible.
ibaddr -C mthca0 -P 2  # utiliser uniquement le port spécifié.

Flags de débogage

-d
augmenter le niveau de débogage IB. Peut être utilisé plusieurs fois (-ddd ou -d -d -d).
-e
afficher les erreurs d'envoi et de réception (timeouts et autres)

-h, --help afficher le message d'utilisation

-v, --verbose
augmenter le niveau de verbosité de l'application. Peut être utilisé plusieurs fois (-vv ou -v -v -v)

-V, --version afficher les informations de version.

Flags de configuration

-t, --timeout <timeout_ms> ignorer le timeout par défaut pour les MADS sollicités.

-y, --m_key <clé>
utiliser la M_key spécifiée pour les requêtes. Si une valeur non numérique (comme 'x') est spécifiée, une valeur sera demandée.

--config, -z <fichier_config> Spécifier un fichier de configuration alternatif.

Défaut : /etc/infiniband-diags/ibdiag.conf

EXEMPLES

perfquery                # lire les compteurs de performance des ports locaux
perfquery 32 1           # lire les compteurs de performance du lid 32, port 1
perfquery -x 32 1        # lire les compteurs de performance étendus du lid 32, port 1
perfquery -a 32          # lire les compteurs de performance du lid 32, tous les ports
perfquery -r 32 1        # lire les compteurs de performance et réinitialiser
perfquery -x -r 32 1     # lire les compteurs de performance étendus et réinitialiser
perfquery -R 0x20 1      # réinitialiser les compteurs de performance du port 1 uniquement
perfquery -x -R 0x20 1   # réinitialiser les compteurs de performance étendus du port 1 uniquement
perfquery -R -a 32       # réinitialiser les compteurs de performance de tous les ports
perfquery -R 32 2 0x0fff # réinitialiser uniquement les compteurs d'erreurs du port 2
perfquery -R 32 2 0xf000 # réinitialiser uniquement les compteurs non-erreurs du port 2
perfquery -a 32 1-10     # lire les compteurs de performance du lid 32, ports 1-10, agréger la sortie
perfquery -l 32 1-10     # lire les compteurs de performance du lid 32, ports 1-10, afficher chaque port
perfquery -a 32 1,4,8    # lire les compteurs de performance du lid 32, ports 1, 4 et 8, agréger la sortie
perfquery -l 32 1,4,8    # lire les compteurs de performance du lid 32, ports 1, 4 et 8, afficher chaque port
