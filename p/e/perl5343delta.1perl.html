PERL5343DELTA(1perl) Guide du programmeur Perl PERL5343DELTA(1perl)

NOM

perl5341delta — ce qui est nouveau pour la version perl v5.34.3

DESCRIPTION

Ce document décrit les différences entre la version 5.34.1 et la version 5.34.3. Attention : Ce document ignore Perl 5.34.2, une version défectueuse qui n'a existé que pendant quelques jours.

Si vous mettez à niveau depuis une version antérieure comme la 5.34.0, lisez d'abord perl5341delta, qui décrit les différences entre 5.34.0 et 5.34.1.

Sécurité

Cette version corrige les problèmes de sécurité suivants.

CVE-2023-47038 — Écriture au-delà de la fin du tampon via une propriété Unicode définie par l'utilisateur invalide

Cette vulnérabilité a été signalée directement à l'équipe de sécurité Perl par Nathan Mills <the.true.nathan.mills@gmail.com>.

Une expression régulière conçue, lorsqu'elle est compilée par perl 5.30.0 à 5.38.0, peut provoquer un dépassement de tampon contrôlé par l'attaquant d'un octet dans un tampon alloué sur le tas.

CVE-2023-47039 — Vulnérabilité de détournement de binaire Perl pour Windows

Cette vulnérabilité a été signalée à l'équipe de réponse aux incidents de sécurité des produits Intel (PSIRT) par l'utilisateur GitHub ycdxsb https://github.com/ycdxsb/WindowsPrivilegeEscalation. PSIRT l'a ensuite signalée à l'équipe de sécurité Perl.

Perl pour Windows s'appuie sur la variable d'environnement PATH pour trouver le shell ("cmd.exe"). Lors de l'exécution d'un exécutable utilisant l'interpréteur Perl Windows, Perl tente de trouver et d'exécuter "cmd.exe" au sein du système d'exploitation. Cependant, en raison de problèmes d'ordre de recherche dans le PATH, Perl recherche d'abord cmd.exe dans le répertoire de travail courant.

Un attaquant disposant de privilèges limités peut exploiter ce comportement en plaçant "cmd.exe" dans des emplacements ayant des permissions faibles, tels que "C:\ProgramData". Ce faisant, lorsqu'un administrateur tente d'utiliser cet exécutable depuis ces emplacements compromis, un code arbitraire peut être exécuté.

Remerciements

Perl 5.34.3 représente environ 1 mois de développement depuis Perl 5.34.1 et contient environ 3 700 lignes de changements réparties sur 40 fichiers de 4 auteurs.

À l'exclusion des fichiers générés automatiquement, de la documentation et des outils de publication, il y a eu environ 2 800 lignes de changements dans 9 fichiers .pm, .t, .c et .h.

Perl continue de s'épanouir dans sa quatrième décennie grâce à une communauté dynamique d'utilisateurs et de développeurs. Les personnes suivantes sont connues pour avoir contribué aux améliorations qui sont devenues Perl 5.34.3 :

Karl Williamson, Paul Evans, Steve Hay, Tony Cook.

La liste ci-dessus est presque certainement incomplète car elle est générée automatiquement à partir de l'historique du contrôle de version. En particulier, elle n'inclut pas les noms des contributeurs (très appréciés) qui ont signalé des problèmes dans le traqueur de bugs Perl.

Beaucoup des changements inclus dans cette version proviennent des modules CPAN inclus dans le cœur de Perl. Nous sommes reconnaissants envers toute la communauté CPAN pour avoir aidé Perl à prospérer.

Pour une liste plus complète de tous les contributeurs historiques de Perl, veuillez consulter le fichier AUTHORS dans la distribution source de Perl.

Signalement des bogues

Si vous trouvez ce que vous pensez être un bug, vous pourriez vérifier la base de données des bugs de Perl à l'adresse https://github.com/Perl/perl5/issues. Il peut également y avoir des informations sur http://www.perl.org/, la page d'accueil de Perl.

Si vous pensez avoir un bug non signalé, veuillez ouvrir un ticket sur https://github.com/Perl/perl5/issues. Assurez-vous de réduire votre bug à un cas de test minuscule mais suffisant.

Si le bug que vous signalez a des implications de sécurité qui le rendent inapproprié à l'envoi à un traqueur d'incidents public, consultez "SECURITY VULNERABILITY CONTACT INFORMATION" dans perlsec pour plus de détails sur la manière de signaler le problème.

Remercier

Si vous souhaitez remercier les Perl 5 Porters pour le travail accompli dans Perl 5, vous pouvez le faire en exécutant le programme "perlthanks" :

perlthanks

Cela enverra un e-mail à la liste Perl 5 Porters avec votre message de remerciement.
