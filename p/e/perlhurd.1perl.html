NOM

perlhurd - Version Perl 5 sur Hurd

DESCRIPTION

Si vous souhaitez utiliser Perl sur Hurd, je vous recommande d'utiliser la distribution Debian GNU/Hurd (voir https://www.debian.org/ ), même si une version officielle stable n'a pas encore été publiée. L'ancienne distribution binaire « gnu-0.2 » aura très certainement des problèmes supplémentaires.

Problèmes connus avec Perl sur Hurd

La suite de tests de Perl peut encore signaler des erreurs sur Hurd. Les tests « lib/anydbm » et « pragma/warnings » échoueront presque certainement. Les deux échecs ne sont pas vraiment spécifiques à Hurd, comme l'indiquent les résultats de la suite de tests.

Les tests de socket peuvent échouer si le réseau n'est pas configuré. Vous devez faire de « /hurd/pfinet » le traducteur de « /servers/socket/2 », en lui donnant les bons arguments. Essayez « /hurd/pfinet --help » pour plus d'informations.

Voici les statistiques pour Perl 5.005_62 sur mon système :

Failed Test  Status Wstat Total Fail  Failed  List of failed
-----------------------------------------------------------------------
lib/anydbm.t                 12    1   8.33%  12
pragma/warnings             333    1   0.30%  215
8 tests et 24 sous-tests sautés.
2/229 scripts de test échoués, 99.13% ok. 2/10850 sous-tests échoués,
    99.98% ok.

Il y a pas mal de systèmes qui font pire !

Cependant, comme j'utilise un aperçu très récent de Hurd, dans lequel de nombreux bugs exposés par la suite de tests Perl ont été corrigés, vous pourriez rencontrer plus d'échecs. Les candidats probables sont : « op/stat », « lib/io_pipe », « lib/io_sock », « lib/io_udp » et « lib/time ».

En tout cas, si vous constatez des échecs au-delà de ceux mentionnés dans ce document, veuillez envisager de mettre à jour vers la dernière version de Hurd avant de signaler l'échec comme un bug.
