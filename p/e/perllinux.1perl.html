PERLLINUX(1perl) Guide de référence du programmeur Perl PERLLINUX(1perl)

NOM

perllinux - Version 5 de Perl sur les systèmes Linux

DESCRIPTION

Ce document décrit diverses fonctionnalités de Linux qui affectent la façon dont Perl version 5 (ci-après simplement Perl) est compilé et/ou exécuté.

Déploiement de Perl sous Linux

Normalement, on peut installer /usr/bin/perl sous Linux en utilisant le gestionnaire de paquets de sa distribution (par exemple : "sudo apt-get install perl" ou "sudo dnf install perl"). Notez qu'il faut parfois installer quelques paquets système supplémentaires pour pouvoir utiliser les interfaces CPAN, et que modifier le Perl du système n'est pas toujours recommandé. On peut utiliser perlbrew https://perlbrew.pl/ pour éviter de tels problèmes.

Sinon, perl devrait se compiler correctement sous Linux en utilisant les compilateurs courants GCC et clang, en suivant les instructions habituelles.

Support expérimental pour les compilateurs Sun Studio pour OS Linux

Sun Microsystems a publié un portage de ses compilateurs Sun Studio pour Linux. En mai 2019, la dernière version stable a eu lieu en 2017, et il est possible d'acheter des contrats de support pour ceux-ci.

Il existe quelques instructions spéciales pour compiler Perl avec Sun Studio sous Linux. En suivant le script "Configure" habituel, vous devez exécuter make comme suit :

LDLOADLIBS=-lc make

"LDLOADLIBS" est une variable d'environnement utilisée par l'éditeur de liens pour lier les modules "/ext" à glibc. Actuellement, cette variable d'envi‐ ronnement n'est pas remplie par une combinaison d'entrées "Config" et de "ExtUtil::MakeMaker". Bien qu'il puisse y avoir un bug quelque part dans la configuration de Perl ou dans "ExtUtil::MakeMaker" causant le problème, la cause la plus probable est une compréhension incomplète de Sun Studio par cet auteur. Des investigations supplémentaires sont nécessaires pour améliorer cela.
