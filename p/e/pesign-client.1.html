PESIGN-CLIENT(1) Manuel des commandes générales PESIGN-CLIENT(1)

NOM

pesign-client — outil de signature d'applications UEFI avec un serveur pesign

SYNTAXE

pesign-client [-i fichier] [-o fichier] [-e fichier] [-t jeton] [-c nom_cn] ⟨[-k |] [-q |] [-s |] [-u]⟩ [-f desc_fich] [-F fichier]

DESCRIPTION

pesign-client est un outil en ligne de commande pour manipuler les signatures et les empreintes cryptographiques des applications UEFI.

OPTIONS

-i fichier | --infile fichier
Le fichier binaire d'entrée fichier à signer avec --sign
-o fichier | --outfile fichier
Le fichier binaire de sortie fichier à signer avec --sign
-e fichier | --export fichier
Exporter la signature de --sign vers le fichier
-t jeton | --token jeton
Signer en utilisant le jeton NSS jeton
-c nom_cn | --certificate nom_cn
Signer en utilisant le certificat NSS nom_cn
-k | --kill
Arrêter le serveur pesign
-q | --is-unlocked
Interroger l'état de verrouillage du jeton spécifié par --token
-s | --sign
Signer le fichier spécifié par --infile
-u | --unlock
Déverrouiller le jeton spécifié avec --token en utilisant le code PIN lu depuis --pinfd ou --pinfile, ou spécifié par PESIGN_TOKEN_PIN
-f desc_fich | --pinfd desc_fich
Descripteur de fichier pour lire le code PIN pour --unlock
-F fichier | --pinfile fichier
Fichier à partir duquel lire le code PIN pour le déverrouillage

ENVIRONNEMENT

PESIGN_TOKEN_PIN
Code PIN à utiliser avec --unlock pour le jeton spécifié par -fl -token

VOIR AUSSI

pesign(1), certutil(1)
