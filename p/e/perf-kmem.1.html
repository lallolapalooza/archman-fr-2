NOM

perf-kmem - Outil pour tracer/mesurer les propriétés de la mémoire du noyau

SYNTAXE

perf kmem [<options>] {record|stat}

DESCRIPTION

Il existe deux variantes de perf kmem :

'perf kmem [<options>] record [<perf-record-options>] <commande>' pour
enregistrer les événements kmem d'une charge de travail arbitraire. Des options
'perf record' supplémentaires peuvent être spécifiées après record, telles que '-o'
pour changer le nom du fichier de sortie.
'perf kmem [<options>] stat' pour rapporter les statistiques de la mémoire du noyau.

OPTIONS

-i <fichier>, --input=<fichier>

Pour stat, sélectionner le fichier d'entrée (par défaut : perf.data sauf si stdin est un fifo)

-f, --force

Ne pas faire de validation de propriété

-v, --verbose

Être plus verbeux. (afficher l'adresse du symbole, etc.)

--caller

Afficher les statistiques par site d'appel

--alloc

Afficher les statistiques par allocation

-s <clef[,clef2...]>, --sort=<clef[,clef2...]>

Trier la sortie (par défaut : frag,hit,bytes pour slab et bytes,hit pour page). Les clefs de tri disponibles sont ptr, callsite, bytes, hit, pingpong, frag pour slab et page, callsite, bytes, hit, order, migtype, gfp pour page. Cette option doit être précédée de l'une des options de sélection de mode, c'est-à-dire --slab, --page, --alloc et/ou --caller.

-l <num>, --line=<num>

Afficher n lignes seulement

--raw-ip

Afficher l'ip brut au lieu du symbole

--slab

Analyser les événements de l'allocateur SLAB.

--page

Analyser les événements de l'allocateur de pages

--live

Afficher les statistiques des pages actives. perf kmem affiche les statistiques d'allocation totale par défaut, mais cette option affiche les pages actives (actuellement allouées) à la place. (Cette option ne fonctionne qu'avec l'option --page)

--time=<début>,<fin>

Analyser uniquement les échantillons dans la fenêtre temporelle donnée : <début>,<fin>. Les temps ont le format secondes.microsecondes. Si début n'est pas donné (c'est-à-dire, la chaîne de temps est ,x.y) alors l'analyse commence au début du fichier. Si l'heure de fin n'est pas donnée (c'est-à-dire, la chaîne de temps est x.y,) alors l'analyse va jusqu'à la fin du fichier.
