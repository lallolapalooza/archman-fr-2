PERL586DELTA(1perl) Guide de référence du programmeur Perl PERL586DELTA(1perl)

NOM

perl586delta - ce qu'il y a de nouveau dans perl v5.8.6

DESCRIPTION

Ce document décrit les différences entre la version 5.8.5 et la version 5.8.6.

Changements Incompatibles

Il n'y a aucun changement incompatible avec la version 5.8.5.

Améliorations du Noyau

L'interpréteur Perl est maintenant plus tolérant aux scripts encodés en UTF-16.

Sous Win32, Perl peut maintenant utiliser des LSP non compatibles IFS, ce qui permet à Perl de fonctionner en conjonction avec des pare-feux tels que McAfee Guardian. Pour plus de détails, consultez le fichier README.win32, surtout si vous utilisez Win95.

Modules et Pragmata

  • Avec le pragma "base", une classe intermédiaire sans champs utilisée pour perturber les champs privés dans la classe de base. Ceci a été corrigé.
  • Cwd mis à jour vers la version 3.01 (dans le cadre de la nouvelle distribution PathTools)
  • Devel::PPPort mis à jour vers la version 3.03
  • File::Spec mis à jour vers la version 3.01 (dans le cadre de la nouvelle distribution PathTools)
  • Encode mis à jour vers la version 2.08
  • ExtUtils::MakeMaker reste à la version 6.17, car les versions stables ultérieures actuellement disponibles sur CPAN ont quelques problèmes avec les modules de base sur certaines plateformes principales.
  • I18N::LangTags mis à jour vers la version 0.35
  • Math::BigInt mis à jour vers la version 1.73
  • Math::BigRat mis à jour vers la version 0.13
  • MIME::Base64 mis à jour vers la version 3.05
  • La fonction POSIX::sigprocmask peut maintenant récupérer le masque de signal actuel sans le définir également.
  • Time::HiRes mis à jour vers la version 1.65

Changements Utilitaires

Perl dispose d'un nouveau drapeau de ligne de commande -dt, qui active le support des threads dans le débogueur.

Améliorations de Performance

"reverse sort ..." est maintenant optimisé pour trier en sens inverse, évitant la génération d'une liste intermédiaire temporaire.

"for (reverse @foo)" itère maintenant en sens inverse, évitant la génération d'une liste inversée temporaire.

Corrections de Bugs Sélectionnées

Le moteur d'expressions régulières est maintenant plus robuste lorsqu'il reçoit des entrées utf8 invalides, comme celles parfois générées par des modules XS défectueux.

L'itération sur un tableau threads::shared avec "foreach" pouvait faire planter Perl. Ce bug a maintenant été corrigé.

Une expression régulière dans le destructeur de "STDOUT" pouvait générer un core dump, car le pad d'expressions régulières était déjà libéré. Ceci a été corrigé.

"goto &" est maintenant plus robuste - les bugs dans la récursion profonde et le "goto &" chaîné ont été corrigés.

L'utilisation de "delete" sur un tableau ne fuit plus de mémoire. Un "pop" d'un élément d'une référence de tableau partagée ne provoque plus de fuite.

eval_sv() échouant un test de taint pouvait corrompre la pile - ceci a été corrigé.

Sur les plateformes avec des pointeurs 64 bits, les opérateurs de comparaison numérique comparaient à tort les adresses de références qui sont surchargées, plutôt que d'utiliser les valeurs surchargées. Ceci a été corrigé.

"read" dans un tampon encodé en UTF8 avec un décalage hors de la fin du tampon ne calcule plus incorrectement les longueurs de tampon.

Bien que Perl ait promis depuis la version 5.8 que sort() serait stable, les deux cas "sort {$b cmp $a}" et "sort {$b <=> $a}" pouvaient produire des tris non stables. Ceci est corrigé dans perl5.8.6.

La localisation de $^D ne génère plus de message de diagnostic concernant les drapeaux -D valides.

Diagnostics Nouveaux ou Modifiés

Pour -t et -T,
Too late for "-T" option a été changé en un message plus informatif
"-T" is on the #! line, it must also be used on the command line

Internes Modifiés

Désormais, toutes les applications intégrant perl se comporteront comme si perl avait été compilé avec -DPERL_USE_SAFE_PUTENV. Voir la section "Environment access" dans le fichier INSTALL pour plus de détails.

La plupart des fichiers sources "C" ont maintenant des commentaires en haut expliquant leur objectif, ce qui devrait aider toute personne souhaitant avoir un aperçu de l'implémentation.

Nouveaux Tests

Il y a beaucoup plus de tests pour la suite de modules "B".

Signalement de Bugs

Si vous trouvez ce qui vous semble être un bug, vous pourriez vérifier les articles récemment postés sur le groupe de nouvelles comp.lang.perl.misc et la base de données des bugs Perl sur http://bugs.perl.org. Il peut également y avoir des informations sur http://www.perl.org, la page d'accueil de Perl.

Si vous pensez avoir un bug non signalé, veuillez exécuter le programme perlbug inclus dans votre version. Assurez-vous de réduire votre bug à un exemple de test minuscule mais suffisant. Votre rapport de bug, ainsi que la sortie de "perl -V", seront envoyés à perlbug@perl.org pour être analysés par l'équipe de portage Perl. Vous pouvez parcourir et rechercher les bugs Perl 5 sur http://bugs.perl.org/
