NOM

perf - Outils d'analyse de performance pour Linux

SYNTAXE

perf [--version] [--help] [OPTIONS] COMMAND [ARGS]

OPTIONS

-h, --help

Exécute la commande d'aide de perf.

-v, --version

Affiche la version de perf.

-vv

Affiche l'état compilé des bibliothèques.

--exec-path

Affiche ou définit le chemin d'exécution.

--html-path

Affiche le chemin de la documentation HTML.

-p, --paginate

Configure le pagineur.

--no-pager

N'utilise pas le pagineur.

--buildid-dir

Définit le répertoire du cache des buildid. Il a une priorité plus élevée que l'option de fichier de configuration buildid.dir.

--list-cmds

Liste les commandes perf les plus couramment utilisées.

--list-opts

Liste les options perf disponibles.

--debugfs-dir

Définit le répertoire debugfs ou la variable d'environnement PERF_DEBUGFS_DIR.

--debug

Définit la variable de débogage (voir ci-dessous) dans la plage de valeurs (0, 10). Utiliser comme : --debug verbose # définit verbose = 1 --debug verbose=2 # définit verbose = 2 
Liste des variables de débogage autorisées à être définies :
  verbose          - messages de débogage généraux
  ordered-events   - messages de débogage de l'objet d'événements ordonnés
  data-convert     - messages de débogage de la commande data convert
  stderr           - écrit la sortie de débogage (option -v) sur la sortie d'erreur
                     en mode navigateur
  perf-event-open  - Affiche les arguments et la valeur de retour de perf_event_open()
  kmaps            - Affiche les cartes du noyau et des modules (script perf
                     et rapport perf sans navigateur)

--debug-file

Écrit la sortie de débogage dans un fichier spécifié.

DESCRIPTION

Les compteurs de performance pour Linux sont un nouveau sous-système basé sur le noyau qui fournit un cadre pour tout ce qui concerne l'analyse de performance. Il couvre les fonctionnalités matérielles (CPU/PMU, Performance Monitoring Unit) et les fonctionnalités logicielles (compteurs logiciels, points de trace).
