NOM

perl5402delta - nouveautés de la version perl v5.40.2

DESCRIPTION

Ce document décrit les différences entre la version 5.40.1 et la version 5.40.2.

Si vous effectuez une mise à niveau à partir d'une version antérieure comme la 5.40.0, lisez d'abord perl5401delta, qui décrit les différences entre 5.40.0 et 5.40.1.

Sécurité

[CVE-2024-56406] Vulnérabilité de dépassement de tampon dans le tas avec tr//

Une vulnérabilité de dépassement de tampon dans le tas a été découverte dans Perl.

Lorsque des octets non ASCII sont présents dans la partie gauche de l'opérateur "tr", S_do_trans_invmap() peut dépasser le pointeur de destination "d".

$ perl -e '$_ = "\x{FF}" x 1000000; tr/\xFF/\x{100}/;'
Segmentation fault (core dumped)

On pense que cette vulnérabilité peut permettre des attaques par déni de service ou d'exécution de code arbitraire sur des plateformes qui manquent de défenses suffisantes.

Découvert par : Nathan Mills.

Changements incompatibles

Il n'y a aucun changement intentionnellement incompatible avec la version 5.40.1. S'il en existe, ce sont des bogues, et nous vous demandons de soumettre un rapport. Voir "Signalement de bogues" ci-dessous.

Remerciements

Perl 5.40.2 représente environ 3 mois de développement depuis Perl 5.40.1 et contient environ 1 600 lignes de modifications réparties sur 37 fichiers provenant de 7 auteurs.

En excluant les fichiers générés automatiquement, la documentation et les outils de publication, il y a eu environ 640 lignes de modifications apportées à 5 fichiers .pm, .t, .c et .h.

Perl continue de s'épanouir dans sa quatrième décennie grâce à une communauté dynamique d'utilisateurs et de développeurs. Les personnes suivantes sont connues pour avoir contribué aux améliorations qui sont devenues Perl 5.40.2 :

Karl Williamson, Lukas Mai, Max Maischein, Paul Evans, Richard Leach, Steve Hay, Thibault Duponchelle.

La liste ci-dessus est presque certainement incomplète car elle est générée automatiquement à partir de l'historique du contrôle de version. En particulier, elle n'inclut pas les noms des contributeurs (très appréciés) qui ont signalé des problèmes sur le traqueur de bogues de Perl.

Beaucoup des modifications incluses dans cette version proviennent des modules CPAN inclus dans le cœur de Perl. Nous sommes reconnaissants à l'ensemble de la communauté CPAN d'aider Perl à prospérer.

Pour une liste plus complète de tous les contributeurs historiques de Perl, veuillez consulter le fichier AUTHORS dans la distribution source de Perl.

Signalement de bogues

Si vous trouvez ce qui vous semble être un bogue, vous pouvez consulter la base de données des bogues de Perl à l'adresse https://github.com/Perl/perl5/issues. Vous pourriez également trouver des informations sur https://www.perl.org/, la page d'accueil de Perl.

Si vous pensez avoir un bogue non signalé, veuillez ouvrir un ticket à l'adresse https://github.com/Perl/perl5/issues. Assurez-vous de réduire votre bogue à un exemple de test simple mais suffisant.

Si le bogue que vous signalez a des implications en matière de sécurité qui le rendent inapproprié pour un traqueur de problèmes public, alors consultez "SECURITY VULNERABILITY CONTACT INFORMATION" dans perlsec pour plus de détails sur la manière de signaler le problème.

Remercier

Si vous souhaitez remercier les Perl 5 Porters pour le travail accompli dans Perl 5, vous pouvez le faire en exécutant le programme "perlthanks" :

perlthanks

Cela enverra un e-mail à la liste des Perl 5 Porters avec votre témoignage de gratitude.
