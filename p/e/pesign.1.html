PESIGN(1) Manuel des commandes générales PESIGN(1)

NOM

pesign — outil pour signer les applications UEFI

SYNTAXE

pesign -i fichier [-o fichier] [-f] [-n répertoire] [-t token] [-c surnom] [-u nombre] [-m fichier] [-e fichier] [-I fichier] [-E fichier] [-R fichier] [-K fichier] [-C fichier] [-a] [-l] [-S] [-v] ⟨-s | -D [-N] | -r | -h [-d digest] [-P | -p]⟩

DESCRIPTION

pesign est un outil en ligne de commande pour manipuler les signatures et les résumés cryptographiques des applications UEFI.

OPTIONS

-i fichier | --entree fichier
Fichier PE fichier en entrée pour la signature
-o fichier | --sortie fichier
Fichier PE fichier en sortie pour la signature
-f | --forcer
Écraser le fichier spécifié avec --sortie
-n répertoire | --rep-cert répertoire
Utiliser la base de données NSS dans répertoire (par défaut : /etc/pki/pesign)
-t token | --token token
Utiliser le jeton NSS nommé token
-c surnom | --certificat surnom
Utiliser le certificat nommé surnom dans la base de données NSS
-u nombre | --num-signature nombre
Numéro de signature, indexé à partir de 0, à utiliser avec --supprimer-signature, --exporter-signature, ou --afficher-signature (défaut : 0)
-m fichier | --importer-signature fichier
Importer la signature Authenticode depuis fichier
-e fichier | --exporter-signature fichier
Exporter la signature Authenticode vers fichier
-I fichier | --importer-attributs-signes fichier
Importer les SignedAttributes PKCS-7 (sans signature) depuis fichier
-E fichier | --exporter-attributs-signes fichier
Exporter les SignedAttributes PKCS-7 (sans signature) vers fichier
-R fichier | --importer-signature-brute fichier
Importer le résumé de signature depuis fichier
-K fichier | --exporter-cle-publique fichier
Exporter la clé publique depuis la base de données NSS spécifiée par --token et --certificat vers fichier
-C fichier | --exporter-cert fichier
Exporter le certificat depuis la base de données NSS spécifiée par --token et --certificat vers fichier
-a | --armure-ascii
Lors de l'exportation de certificats, les encoder en armure ASCII
-l | --lister-signatures
Lister les signatures
-S | --afficher-signature
Afficher les informations sur les signatures
-v | --verbeux
Être plus verbeux
-s | --signer
Créer une nouvelle signature
-D | --daemon
Exécuter en tant que démon
-N | --pas-de-fork
Ne pas forker lors de la création d'un démon (le démon s'exécute en premier plan)
-r | --supprimer-signature
Supprimer la signature
-h | --hash
Afficher le hash Authenticode du binaire
-d digest | --type-digest digest
Utiliser le digest cryptographique avec --hash (utiliser help pour lister les options) (défaut : sha256)
-P | --rembourrage |

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

OPTIONS

--padding
Pad the binary according to PE 9.3 rules before signing or hashing. This is the default setting for pesign 113 and newer.
--nopadding
Do not pad the binary according to PE 9.3 rules before signing or hashing (default: --padding)

Padding is recommended (and in many circumstances required) even for binaries which predate the current PE spec, and is enabled by default as of pesign 113.

EXEMPLES

Signature avec le certificat et la clé privée dans des fichiers individuels

Si vous disposez d'un fichier de certificat et d'un fichier de clé privée, les étapes suivantes peuvent être utilisées pour signer une image PE :

# Créer un fichier pkcs12 à partir de la clé privée et du fichier de certificat.
host:~$ openssl pkcs12 -export -out foo_key.p12 \
        -inkey signing_key.pem -in xyz_cert.x509.pem

# Importer le fichier pkcs12 dans la base de données pesign
host:~$ pk12util -i foo_key.p12 -d /etc/pki/pesign

# Effectuer la signature
host:~$ pesign -c my-signing-cert -s \
        -i foo.unsigned.efi -o foo.signed.efi

Veuillez noter qu'il ne s'agit que d'un exemple, et que la meilleure pratique recommandée est de toujours stocker les clés privées dans un module matériel de sécurité (HSM) FIPS 140-2, de niveau 2 ou supérieur.

Signature en utilisant un HSM

Si vous avez une paire de clés dans votre HSM et que votre fournisseur de HSM fournit une bibliothèque PKCS-11, vous pouvez l'utiliser directement avec NSS :

# Ajouter la bibliothèque PKCS-11 du HSM à la base de données NSS

Signature en utilisant un HSM avec un moteur OpenSSL

Si vous avez une paire de clés dans votre HSM mais que vous ne pouvez pas y accéder directement, mais que vous avez accès à l'outil en ligne de commande openssl configuré avec les bibliothèques de votre fournisseur, vous pouvez toujours utiliser pesign pour signer vos binaires PE :

# Importer le certificat public dans la base de données NSS
host:~$ certutil -d /etc/pki/pesign -A -n myorg-sb-signer \
        -t ,,u -i myorg-sb-signer.cer

# Exporter la section SignedAttributes PKCS-7 que pesign génère
host:~$ pesign -i foo.unsigned.efi -E foo.sattrs.bin

# Générer une signature en utilisant OpenSSL
host:~$ openssl dgst -sha256 -sign $KEY \
        --keyform ENGINE --engine $ENGINEID \
        -out foo.sattrs.sig foo.sattrs.bin

# Importer la signature avec les SignedAttributes d'origine dans
# le binaire PE
host:~$ pesign -c myorg-sb-signer \
        -R foo.sattrs.sig -I foo.sattrs.bin \
        -i foo.unsigned.efi -o foo.efi

pesign(1)

pesign - Saisie de signatures numériques pour les fichiers PE

SYNOPSIS

pesign [OPTIONS] <fichier>...

DESCRIPTION

pesign permet de signer numériquement des fichiers au format Portable Executable (PE), tels que les exécutables Windows, les DLL, les pilotes de périphériques, etc. Il utilise les certificats stockés dans le magasin de certificats Windows ou des fichiers de certificat. Cette commande est particulièrement utile dans les environnements où les signatures numériques sont requises, comme le démarrage sécurisé (Secure Boot) ou les pilotes signés par le noyau.

OPTIONS

  • --cert-type TYPE : Spécifie le type de certificat à utiliser (par exemple, USER, MACHINE, ROOT). La valeur par défaut est MACHINE.
  • --cert-name NOM : Spécifie le nom du certificat à rechercher dans le magasin de certificats.
  • --cert-file FICHIER : Spécifie le chemin vers un fichier de certificat (par exemple, .pfx ou .cer).
  • --password MOT_DE_PASSE : Spécifie le mot de passe pour le fichier de certificat (si nécessaire).
  • --hash-alg ALGORITHME : Spécifie l'algorithme de hachage à utiliser pour la signature (par exemple, SHA1, SHA256). La valeur par défaut est SHA1.
  • --timestamp-url URL : Spécifie l'URL d'un serveur d'horodatage pour ajouter une preuve d'horodatage à la signature.
  • --verbose : Active la sortie détaillée.
  • --help : Affiche l'aide et quitte.
  • --version : Affiche les informations de version et quitte.

EXAMPLES

Signer un fichier exécutable avec un certificat nommé "MonCertificat" dans le magasin de certificats de la machine :

pesign --cert-name "MonCertificat" mon_programme.exe

Signer un fichier avec un certificat à partir d'un fichier .pfx et utiliser un serveur d'horodatage :

pesign --cert-file mon_certificat.pfx --password "mon_mot_de_passe" --timestamp-url http://ts.ssl.com/timestamp.sfs mon_pilote.sys

STANDARDS

PE/COFF, Authenticode.
