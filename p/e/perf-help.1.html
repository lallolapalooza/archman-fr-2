NOM

perf-help - afficher les informations d'aide sur perf

SYNTAXE

perf help [-a|--all] [COMMANDE]

DESCRIPTION

Sans options et sans COMMANDE donnée, la syntaxe de la commande perf et une liste des commandes perf les plus couramment utilisées sont affichées sur la sortie standard.

Si l'option --all ou -a est donnée, alors toutes les commandes disponibles sont affichées sur la sortie standard.

Si une commande perf est nommée, une page de manuel pour cette commande est affichée. Le programme man est utilisé par défaut à cet effet, mais cela peut être outrepassé par d'autres options ou variables de configuration.

Notez que perf --help ... est identique à perf help ... car le premier est converti en interne en ce dernier.

OPTIONS

-a, --all

Affiche toutes les commandes disponibles sur la sortie standard. Cette option remplace toute autre option.
