NOM

perf-check - vérifie si des fonctionnalités sont présentes dans perf

SYNTAXE

perf check [<options>]
perf check {feature <liste_de_fonctionnalites>} [<options>]

DESCRIPTION

Aucune sous-commande donnée, la commande perf check affiche simplement l'utilisation de la commande sur la sortie standard.

Si la sous-commande feature est utilisée, alors le statut de la fonctionnalité est imprimé sur la sortie standard (sauf si -q est également passé), c'est-à-dire si elle est compilée/intégrée ou non. De plus, perf check feature retourne avec le statut de sortie 0 si la fonctionnalité est intégrée, sinon elle retourne avec le statut de sortie 1.

SOUS-COMMANDES

feature

Imprime si la ou les fonctionnalités sont compilées ou non, et retourne également avec un statut de sortie de 0, si la ou les fonctionnalités passées sont compilées, sinon 1. 
Elle attend une liste de fonctionnalités comme argument. Il peut s'agir d'un seul nom/macro de fonctionnalité, ou plusieurs fonctionnalités peuvent également être passées sous forme de liste séparée par des virgules, auquel cas le statut de sortie sera 0 uniquement si toutes les fonctionnalités passées sont compilées.
Les noms/macros de fonctionnalités ne sont pas sensibles à la casse.
Exemples d'utilisation :
        perf check feature libtraceevent
        perf check feature HAVE_LIBTRACEEVENT
        perf check feature libtraceevent,bpf
Noms/macros de fonctionnalités pris en charge :
        aio                     /  HAVE_AIO_SUPPORT
        bpf                     /  HAVE_LIBBPF_SUPPORT
        bpf_skeletons           /  HAVE_BPF_SKEL
        debuginfod              /  HAVE_DEBUGINFOD_SUPPORT
        dwarf                   /  HAVE_LIBDW_SUPPORT
        dwarf_getlocations      /  HAVE_LIBDW_SUPPORT
        dwarf-unwind            /  HAVE_DWARF_UNWIND_SUPPORT
        auxtrace                /  HAVE_AUXTRACE_SUPPORT
        libbfd                  /  HAVE_LIBBFD_SUPPORT
        libbpf-strings          /  HAVE_LIBBPF_STRINGS_SUPPORT
        libcapstone             /  HAVE_LIBCAPSTONE_SUPPORT
        libdw-dwarf-unwind      /  HAVE_LIBDW_SUPPORT
        libelf                  /  HAVE_LIBELF_SUPPORT
        libnuma                 /  HAVE_LIBNUMA_SUPPORT
        libopencsd              /  HAVE_CSTRACE_SUPPORT
        libperl                 /  HAVE_LIBPERL_SUPPORT
        libpfm4                 /  HAVE_LIBPFM
        libpython               /  HAVE_LIBPYTHON_SUPPORT
        libslang                /  HAVE_SLANG_SUPPORT
        libtraceevent           /  HAVE_LIBTRACEEVENT
        libunwind               /  HAVE_LIBUNWIND_SUPPORT
        lzma                    /  HAVE_LZMA_SUPPORT
        numa_num_possible_cpus  /  HAVE_LIBNUMA_SUPPORT
        zlib                    /  HAVE_ZLIB_SUPPORT
        zstd                    /  HAVE_ZSTD_SUPPORT

OPTIONS

-q, --quiet

Ne pas imprimer de messages ou d'avertissements 
Ceci peut être utilisé avec des sous-commandes telles que 'perf check feature'
pour masquer la sortie inutile dans les scripts de test, par exemple
'perf check feature --quiet libtraceevent'
