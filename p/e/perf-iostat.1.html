NOM

perf-iostat - Afficher les métriques de performance E/S

SYNTAXE

perf iostat list
perf iostat <ports> -- <commande> [<options>]

DESCRIPTION

Le mode est destiné à fournir quatre métriques de performance E/S pour chaque port racine PCIe :

•Lecture entrante - Les périphériques E/S sous le port racine lisent depuis la mémoire hôte, en Mo
•Écriture entrante - Les périphériques E/S sous le port racine écrivent dans la mémoire hôte, en Mo
•Lecture sortante - Le CPU lit depuis les périphériques E/S sous le port racine, en Mo
•Écriture sortante - Le CPU écrit vers les périphériques E/S sous le port racine, en Mo

OPTIONS

<commande>...

Toute commande que vous pouvez spécifier dans un shell.

list

Lister tous les ports racine PCIe.

<ports>

Sélectionner les ports racine à surveiller. Une liste séparée par des virgules est prise en charge.

EXEMPLES

1.Lister tous les ports racine PCIe (exemple pour une plateforme 2-S) : 
$ perf iostat list
S0-uncore_iio_0<0000:00>
S1-uncore_iio_0<0000:80>
S0-uncore_iio_1<0000:17>
S1-uncore_iio_1<0000:85>
S0-uncore_iio_2<0000:3a>
S1-uncore_iio_2<0000:ae>
S0-uncore_iio_3<0000:5d>
S1-uncore_iio_3<0000:d7>
2.Collecter les métriques pour tous les ports racine PCIe : 
$ perf iostat -- dd if=/dev/zero of=/dev/nvme0n1 bs=1M oflag=direct
357708+0 enregistrements lus
357707+0 enregistrements écrits
375083606016 octets (375 Go, 349 Gio) copiés, 215.974 s, 1.7 Go/s
Statistiques des compteurs de performance pour 'system wide' :
   port             Lecture entrante(Mo)    Écriture entrante(Mo)    Lecture sortante(Mo)   Écriture sortante(Mo)
0000:00                    1                    0                    2                    3
0000:80                    0                    0                    0                    0
0000:17               352552                   43                    0                   21
0000:85                    0                    0                    0                    0
0000:3a                    3                    0                    0                    0
0000:ae                    0                    0                    0                    0
0000:5d                    0                    0                    0                    0
0000:d7                    0                    0                    0                    0
3.Collecter les métriques pour une liste de ports racine PCIe séparés par des virgules : 
$ perf iostat 0000:17,0:3a -- dd if=/dev/zero of=/dev/nvme0n1 bs=1M oflag=direct
357708+0 enregistrements lus
357707+0 enregistrements écrits
375083606016 octets (375 Go, 349 Gio) copiés, 197.08 s, 1.9 Go/s
Statistiques des compteurs de performance pour 'system wide' :
   port             Lecture entrante(Mo)    Écriture entrante(Mo)    Lecture sortante(Mo)   Écriture sortante(Mo)
0000:17               358559                   44                    0                   22
0000:3a                    3                    2                    0                    0
197.081983474 secondes temps écoulé
