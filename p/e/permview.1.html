Mono(permview) Mono(permview)

NOM

permview - Visionneuse pour les ensembles de permissions de sécurité déclaratifs dans les assemblages.

SYNTAXE

permview [options] assemblage

DESCRIPTION

Cet outil permet de lister les attributs de sécurité déclaratifs présents dans un assemblage. Les attributs de sécurité se trouvent soit au niveau de l'assemblage, soit sur les classes et les méthodes. Cet outil est utile pour diagnostiquer pourquoi un assemblage ne se charge pas ou pourquoi une classe/méthode lance une SecurityException.

OPTIONS

-output nom_fichier
Écrit toutes les informations relatives aux attributs de sécurité déclaratifs dans le fichier spécifié.
-xml | --xml | /XML
Écrit tous les attributs de sécurité déclaratifs dans un format XML.
-decl | --decl | /DECL
Affiche les attributs de sécurité déclaratifs sur les classes et les méthodes. Par défaut, sans l'option -decl, seuls les ensembles de permissions au niveau de l'assemblage sont affichés.
-? | /? | -h[elp] | /h[elp]
Affiche les informations d'aide sur l'outil permview.

EXEMPLES

permview mscorlib.dll
Ceci affichera les ensembles de permissions minimum, optionnels et refusés (c'est-à-dire les actions de sécurité au niveau de l'assemblage) qui sont compilés dans l'assemblage mscorlib.
permview -decl permview.exe
Ceci affichera tous les attributs de sécurité déclaratifs (au niveau de l'assemblage, de la classe ou de la méthode) présents dans l'assemblage permview.exe.
