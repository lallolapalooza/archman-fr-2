NOM

perf-version - afficher la version du binaire perf

SYNTAXE

perf version [--build-options]

DESCRIPTION

Sans aucune option, perf version affiche la version de perf sur la sortie standard.

Si l'option --build-options est donnée, alors l'état des bibliothèques compilées est affiché sur la sortie standard.

OPTIONS

--build-options

Affiche l'état des bibliothèques compilées sur la sortie standard.
