NOM

perl5262delta - nouveautés de la version perl v5.26.2

DESCRIPTION

Ce document décrit les différences entre la version 5.26.1 et la version 5.26.2.

Si vous mettez à jour depuis une version antérieure telle que la 5.26.0, lisez d'abord perl5261delta, qui décrit les différences entre les versions 5.26.0 et 5.26.1.

Sécurité

[CVE-2018-6797] débordement de tampon sur le tas (écriture de taille 1) dans S_regatom (regcomp.c)

Une expression régulière construite de manière malveillante pouvait provoquer un débordement d'écriture dans un tampon sur le tas, avec contrôle sur les octets écrits. [GH #16185] https://github.com/Perl/perl5/issues/16185

[CVE-2018-6798] Débordement de tampon sur le tas dans Perl__byte_dump_string (utf8.c)

La correspondance d'une expression régulière construite de manière malveillante et dépendante de la locale pouvait provoquer un débordement de lecture dans un tampon sur le tas et potentiellement divulguer des informations. [GH #16143] https://github.com/Perl/perl5/issues/16143

[CVE-2018-6913] Débordement de tampon sur le tas dans S_pack_rec

pack() pouvait provoquer un débordement d'écriture dans un tampon sur le tas avec un nombre d'éléments important. [GH #16098] https://github.com/Perl/perl5/issues/16098

Échec d'assertion dans Perl__core_swash_init (utf8.c)

Les caractères de contrôle dans un nom de propriété Unicode supposé pouvaient provoquer un crash de perl. Ceci a été corrigé. [perl #132055] https://rt.perl.org/Public/Bug/Display.html?id=132055 [perl #132553] https://rt.perl.org/Public/Bug/Display.html?id=132553 [perl #132658] https://rt.perl.org/Public/Bug/Display.html?id=132658

Changements incompatibles

Il n'y a aucun changement intentionnellement incompatible avec la version 5.26.1. S'il en existe, il s'agit de bugs et nous vous prions de soumettre un rapport. Voir "Signalement de bugs" ci-dessous.

Modules et pragmata

Modules et pragmata mis à jour

  • Module::CoreList a été mis à jour de la version 5.20170922_26 à 5.20180414_26.
  • PerlIO::via a été mis à jour de la version 0.16 à 0.17.
  • Term::ReadLine a été mis à jour de la version 1.16 à 1.17.
  • Unicode::UCD a été mis à jour de la version 0.68 à 0.69.

Documentation

Changements dans la documentation existante

perluniprops

•
Ceci a été mis à jour pour noter que "\p{Word}" inclut maintenant les points de code correspondant à la propriété "\p{Join_Control}". Le changement de propriété a été effectué dans Perl 5.18, mais n'a été documenté que maintenant. Il n'y a actuellement que deux points de code qui correspondent à cette propriété : U+200C (ZERO WIDTH NON-JOINER) et U+200D (ZERO WIDTH JOINER).

Support de plateforme

Notes spécifiques à la plateforme

Windows
La détection de la version du compilateur Visual C++ a été améliorée pour fonctionner sur les systèmes non anglophones. [GH #16235] https://github.com/Perl/perl5/issues/16235

Nous définissons maintenant $Config{libpth} correctement pour les constructions 64 bits utilisant des versions de Visual C++ antérieures à la 14.1. [GH #16269] https://github.com/Perl/perl5/issues/16269

Corrections de bugs sélectionnées

  • La fonction intégrée readpipe() vérifie maintenant à la compilation qu'elle n'a qu'une seule expression de paramètre, et la place dans un contexte scalaire, garantissant ainsi qu'elle ne corrompt pas la pile à l'exécution. [GH #2793] https://github.com/Perl/perl5/issues/2793
  • Correction d'un bug d'utilisation après libération dans "pp_list" introduit dans Perl 5.27.1. [GH #16124] https://github.com/Perl/perl5/issues/16124
  • L'analyse d'une définition de "sub" pouvait provoquer une utilisation après libération si le mot-clé "sub" était suivi d'espaces, y compris des sauts de ligne (et des commentaires). [GH #16097] https://github.com/Perl/perl5/issues/16097
  • Le tokenizer ajuste maintenant correctement un pointeur d'analyse lors du passage des espaces dans une construction " ${identificateur} ". [perl #131949] https://rt.perl.org/Public/Bug/Display.html?id=131949
  • Les accès à "${^LAST_FH}" ne provoquent plus d'assertion après avoir utilisé une variété d'opérations d'E/S sur un non-glob. [GH #15372] https://github.com/Perl/perl5/issues/15372
  • "sort" effectue maintenant un comptage de références correct lors de l'aliasage de $a et $b, évitant ainsi la destruction prématurée et la fuite de scalaires s'ils sont ré-aliasés pendant l'exécution du comparateur de tri. [GH #11422] https://github.com/Perl/perl5/issues/11422
  • Certains types complexes d'expressions régulières ne provoquent plus de débordement arithmétique lors de la compilation. [GH #16113] https://github.com/Perl/perl5/issues/16113
  • Correction d'un échec de symbole dupliqué avec les constructions -flto -mieee-fp. pp.c définissait "_LIB_VERSION" que -lieee définit déjà. [GH #16086] https://github.com/Perl/perl5/issues/16086
  • Un déréférencement de pointeur NULL dans la fonction S_regmatch() a été corrigé. [perl #132017] https://rt.perl.org/Public/Bug/Display.html?id=132017
  • Les échecs lors de la compilation de code à l'intérieur d'autres constructions, tels que l'interpolation de chaînes et la partie droite de "s///e" provoquent maintenant une interruption plus précoce de la compilation.

    Auparavant, la compilation pouvait continuer afin de signaler d'autres erreurs, mais l'analyse partielle échouée pouvait laisser des constructions partiellement analysées sur la pile de décalage-réduction de l'analyseur, confondant l'analyseur, conduisant à des crashs de perl. [GH #14739] https://github.com/Perl/perl5/issues/14739

DESCRIPTION

This document describes the differences between Perl 5.24.0 and Perl 5.24.1.

Perl 5.24.1 is a maintenance release containing bug fixes and minor improvements.

There were no security fixes in this release.
