NOM

perlopenbsd - Version Perl 5 sur les systèmes OpenBSD

DESCRIPTION

Ce document décrit diverses fonctionnalités d'OpenBSD qui affectent la manière dont Perl version 5 (ci-après Perl) est compilé et/ou exécuté.

Viduelles dans OpenBSD des fonctions getprotobyname_r et getservbyname_r avec les ithreads

Lorsque Perl est configuré pour utiliser les ithreads, il utilisera les appels de bibliothèque réentrantes de préférence aux versions non réentrantes. Il existe une incompatibilité dans les fonctions "getprotobyname_r" et "getservbyname_r" d'OpenBSD dans les versions 3.7 et ultérieures qui provoquera un SEGV lorsqu'elles seront appelées sans effectuer de "bzero" sur leurs structures de retour avant d'appeler ces fonctions. Les Perl actuels devraient gérer ce problème correctement. Les anciens Perl multithreads (5.8.6 ou antérieurs) rencontreront ce problème. Si vous souhaitez exécuter un Perl multithreads sur OpenBSD 3.7 ou supérieur, vous devrez mettre à niveau vers au moins Perl 5.8.7.
