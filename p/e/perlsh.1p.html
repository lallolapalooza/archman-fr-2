NOM

perlsh - évaluateur perl sur une seule ligne avec fonction d'édition de ligne et
fonction de complétion de nom de variable

SYNTAXE

perlsh

DESCRIPTION

Ce programme lit une ligne d'entrée, l'évalue par l'interpréteur perl, et affiche le résultat. Si le résultat est une valeur de liste, chaque valeur de la liste est affichée ligne par ligne. Ce programme peut être utilisé comme une calculatrice très puissante qui possède toutes les fonctions de perl.

Ceci est un exemple de programme du module Term::ReadLine::Gnu. Lorsque vous entrez une ligne, la fonction d'édition de ligne de la bibliothèque GNU Readline est disponible. La fonction de complétion de nom de symbole Perl est également disponible.

Avant d'être invoqué, ce programme lit ~/.perlshrc et évalue le contenu du fichier.

Lorsque ce programme est terminé, le contenu du tampon d'historique est sauvegardé dans un fichier ~/.perlsh_history, et il est lu lors de la prochaine invocation.

VARIABLES

Vous pouvez personnaliser le comportement de "perlsh" en définissant les variables suivantes dans ~/.perlshrc;

$PerlSh::PS1
La chaîne d'invite principale. Les caractères spéciaux échappés par une barre oblique inverse suivants peuvent être utilisés. 
\h: nom d'hôte
\u: nom d'utilisateur
\w: nom du paquet
\!: numéro d'historique

La valeur par défaut est `"\w[\!]$ "'.

$PerlSh::PS2
La chaîne d'invite secondaire. La valeur par défaut est `"> "'.
$PerlSh::HISTFILE
Le nom du fichier dans lequel l'historique des commandes est sauvegardé. La valeur par défaut est "~/.perlsh_history".
$PerlSh::HISTSIZE
Si ce n'est pas "undef", c'est le nombre maximum de commandes à mémoriser dans l'historique. La valeur par défaut est 256.
$PerlSh::STRICT
Si vrai, restreint les constructions non sûres. Voir "use strict" dans la page de manuel de perl. La valeur par défaut est 0;

FICHIERS

~/.perlshrc
Ce fichier est évalué à l'initialisation. Si une sous-routine "afterinit" est définie dans ce fichier, elle sera évaluée après l'initialisation. Voici un exemple. 
# -*- mode: perl -*-
# décimal vers hexa
sub h { map { sprintf("0x%x", $_ ) } @_;}
sub tk {
    $t->tkRunning(1);
    use Tk;
    $mw = MainWindow->new();
}
# pour le débogage de Term::ReadLine::Gnu
sub afterinit {
    *t = \$PerlSh::term;
    *a = \$PerlSh::attribs;
}
~/.perlsh_history
~/.inputrc
Un fichier d'initialisation pour la bibliothèque GNU Readline. Référez-vous à sa documentation pour plus de détails.
