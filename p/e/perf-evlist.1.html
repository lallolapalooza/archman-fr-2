NOM

perf-evlist - Lister les noms d'événements dans un fichier perf.data

SYNTAXE

perf evlist <options>

DESCRIPTION

Cette commande affiche les noms des événements échantillonnés dans un fichier perf.data.

OPTIONS

-i, --input=

Nom du fichier d'entrée. (par défaut : perf.data sauf si stdin est un fifo)

-f, --force

Ne pas se plaindre, le faire.

-F, --freq=

Afficher uniquement la fréquence d'échantillonnage utilisée pour chaque événement.

-v, --verbose

Afficher tous les champs.

-g, --group

Afficher les informations sur le groupe d'événements.

--trace-fields

Afficher les noms des champs de tracepoint.

VOIR AUSSI

perf-record(1), perf-list(1), perf-report(1)
