PEEKFD(1) Commandes utilisateur PEEKFD(1)

NOM

peekfd - observer les descripteurs de fichiers de processus en cours d'exécution

SYNTAXE

peekfd [-8,--eight-bit-clean] [-n,--no-headers] [-c,--follow] [-d,--duplicates-removed] [-V,--version] [-h,--help] pid [fd] [fd] ...

DESCRIPTION

peekfd s'attache à un processus en cours d'exécution et intercepte toutes les lectures et écritures sur les descripteurs de fichiers. Vous pouvez spécifier les numéros des descripteurs de fichiers désirés ou tous les afficher.

OPTIONS

-8
Ne pas effectuer de post-traitement sur les octets lus ou écrits.
-n
Ne pas afficher les en-têtes indiquant la source des octets affichés.
-c
Afficher également l'activité des descripteurs de fichiers demandés dans tous les nouveaux processus enfants qui sont créés.
-d
Supprimer les lectures/écritures dupliquées de la sortie. Si vous observez un tty avec écho, vous pourriez vouloir utiliser cette option.
-v
Afficher la chaîne de version.
-h
Afficher un message d'aide.

FICHIERS

/proc/*/fd

Non utilisé mais utile pour que l'utilisateur puisse regarder afin d'obtenir de bons numéros de descripteurs de fichiers.

ENVIRONNEMENT

Aucun.

DIAGNOSTICS

Les diagnostics suivants peuvent être émis sur stderr :

Erreur lors de la connexion au pid <PID>
Une erreur inconnue s'est produite lors de la tentative de connexion à un processus, vous pourriez avoir besoin d'être root.

BOGUES

Probablement beaucoup. Ne soyez pas surpris si le processus que vous surveillez meurt.
