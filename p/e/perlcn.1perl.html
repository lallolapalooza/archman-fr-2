PERLCN(1perl) Guide de référence du programmeur Perl PERLCN(1perl)

NOM

perlcn - Guide chinois simplifié Perl

DESCRIPTION

Bienvenue dans le monde de Perl !

Depuis la version 5.8.0, Perl prend entièrement en charge Unicode (jeu de caractères universel), et prend également en charge de nombreux jeux de caractères autres que les langues latines ; le CJK (Chinois, Japonais, Coréen) en fait partie. Unicode est une norme internationale qui vise à couvrir tous les caractères du monde : monde occidental, monde oriental, et tout ce qui se trouve entre les deux (langues grecque, cyrillique, arabe, hébraïque, indienne, annamite, etc.). Il intègre également des systèmes et plateformes variés (comme le PC et le Macintosh).

Perl lui-même fonctionne en Unicode. Cela signifie que les données de chaînes internes de Perl peuvent être représentées par Unicode ; les fonctions et opérateurs de Perl (comme la correspondance de modèles d'expressions régulières) peuvent également opérer sur Unicode. Lors des entrées et sorties, pour gérer les données stockées dans des jeux de caractères autres que Unicode, Perl fournit le module Encode, qui vous permet de lire et écrire facilement des données dans d'anciens jeux de caractères.

Le module d'extension Encode prend en charge les jeux de caractères chinois simplifiés suivants (par 'gb2312' on entend 'euc-cn') :

euc-cn      Ensemble de caractères étendus Unix, aussi appelé code national.
gb2312-raw  Table de caractères GB2312 non traitée (basse densité).
gb12345     Encodage chinois traditionnel non traité.
iso-ir-165  GB2312 + GB6345 + GB8565 + caractères ajoutés.
cp936       Page de codes 936, peut aussi être spécifiée comme 'GBK' (extension du code national).
hz          Encodage GB2312 en mode de décalage 7 bits.

Par exemple, pour convertir un fichier encodé en EUC-CN en Unicode, il suffit de taper la commande suivante :

perl -Mencoding=euc-cn,STDOUT,utf8 -pe1 < file.euc-cn > file.utf8

Perl inclut également "piconv", un utilitaire de conversion de caractères entièrement écrit en Perl, qui s'utilise comme suit :

piconv -f euc-cn -t utf8 < file.euc-cn > file.utf8
piconv -f utf8 -t euc-cn < file.utf8 > file.euc-cn

De plus, avec le module encoding, vous pouvez facilement écrire du code où les caractères sont l'unité de base, comme montré ci-dessous :

#!/usr/bin/env perl
# Active la décomposition de chaînes EUC-CN ; la sortie standard et la sortie d'erreur sont toutes deux définies comme encodage EUC-CN.
use encoding 'euc-cn', STDIN => 'euc-cn', STDOUT => 'euc-cn';
print length("骆驼");      #  2 (les guillemets doubles indiquent des caractères)
print length('骆驼');      #  4 (les guillemets simples indiquent des octets)
print index("谆谆教诲", "蛔唤"); # -1 (ne contient pas cette sous-chaîne)
print index('谆谆教诲', '蛔唤'); #  1 (commence à partir du deuxième octet)

Dans le dernier exemple, le deuxième octet de "谆" se combine avec le premier octet de "谆" pour former le code EUC-CN de "蛔" ; le deuxième octet de "谆" se combine ensuite avec le premier octet de "教" pour former "唤". Cela résout le problème courant du traitement de la correspondance de code EUC-CN.

Encodages chinois supplémentaires

Si vous avez besoin de plus d'encodages chinois, vous pouvez télécharger le module Encode::HanExtra depuis CPAN (https://www.cpan.org/). Il prend actuellement en charge les encodages suivants :

gb18030     Code national étendu, incluant le chinois traditionnel.

De plus, le module Encode::HanConvert fournit des conversions bidirectionnelles entre deux encodages :

big5-simp   Conversion bidirectionnelle entre le chinois traditionnel Big5 et le chinois simplifié Unicode.
gbk-trad    Conversion bidirectionnelle entre le chinois simplifié GBK et le chinois traditionnel Unicode.

Si vous souhaitez convertir entre GBK et Big5, veuillez consulter les programmes pl et g2b.pl inclus dans ce module, ou utiliser la méthode d'écriture suivante dans votre programme :

use Encode::HanConvert;
$euc_cn = big5_to_gb($big5); # Conversion de Big5 en GBK
$big5 = gb_to_big5($euc_cn); # Conversion de GBK en Big5

perlcn(1perl) — Perl documentation

NOM

perlcn — Encodage de caractères chinois pour Perl.

DESCRIPTION

Cette page de manuel décrit comment Perl gère les jeux de caractères chinois, principalement GB2312-80, Big5 et UTF-8. Les caractères chinois sont souvent représentés en utilisant l'encodage à plusieurs octets.

Les pages de manuel pertinentes pour la gestion des caractères sont:

Encode
Le module Encode, qui fournit une interface pour la conversion entre divers jeux de caractères.
Encode::CN
Encodages chinois pour le module Encode. Ce module implémente des encodages tels que GB2312 et Big5.
Encode::MIME
Encodages de type MIME, y compris les valeurs par %XX. Pertinent pour l'encodage des courriels contenant des caractères non-ASCII.
Encode::TW
Encodages taiwanais pour le module Encode. Inclut des variantes de Big5 et d'autres jeux de caractères utilisés à Taïwan.
Unicode
Introduction à Unicode et à la gestion des chaînes en Perl. Ce module fournit des informations générales sur Unicode et son utilisation dans Perl.
https://www.cl.cam.ac.uk/%7Emgk25/unicode.html
Problèmes courants et solutions pour UTF-8 et Unicode sous Unix/Linux.

VOIR AUSSI
