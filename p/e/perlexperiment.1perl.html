NOM

perlexperiment - Liste des fonctionnalités expérimentales de Perl

DESCRIPTION

Ce document liste les fonctionnalités expérimentales actuelles et passées du noyau de Perl. Bien que toutes soient documentées dans leurs rubriques appropriées, cette liste succincte vous donne un aperçu et des faits de base sur leur statut.

Jusqu'à présent, nous avons simplement essayé de trouver et de lister les fonctionnalités expérimentales et d'en déduire leur origine, leurs versions, etc. Il y a beaucoup de spéculation ici.

Expérimentations actuelles

Mots clés enfichables
Introduit dans Perl 5.11.2

Voir "PL_keyword_plugin" dans perlapi pour le mécanisme.

Le ticket pour cette expérimentation est [perl #13199] https://github.com/Perl/perl5/issues/13199.

Aliasing par référence
Introduit dans Perl 5.22.0

L'utilisation de cette fonctionnalité déclenche des avertissements dans la catégorie "experimental::refaliasing".

Le ticket pour cette expérimentation est [perl #14150] https://github.com/Perl/perl5/issues/14150.

Voir aussi : "Assigning to References" dans perlref

use re 'strict';
Introduit dans Perl 5.22.0

L'utilisation de cette fonctionnalité déclenche des avertissements dans la catégorie "experimental::re_strict".

Le ticket pour cette expérimentation est [perl #18755] https://github.com/Perl/perl5/issues/18755

Voir "'strict' mode" dans re

Déclaration d'une référence à une variable
Introduit dans Perl 5.26.0

L'utilisation de cette fonctionnalité déclenche des avertissements dans la catégorie "experimental::declared_refs".

Le ticket pour cette expérimentation est [perl #15458] https://github.com/Perl/perl5/issues/15458.

Voir aussi : "Declaring a Reference to a Variable" dans perlref

Il existe une cible "installhtml" dans le Makefile.
Le ticket pour cette expérimentation est [perl #12726] https://github.com/Perl/perl5/issues/12726.
(Limitée) Lookbehind (rétrospectif) de longueur variable
Introduit dans Perl 5.30.0.

Une variabilité allant jusqu'à 255 caractères est gérée.

L'utilisation de cette fonctionnalité déclenche des avertissements dans la catégorie "experimental::vlb".

Le ticket pour cette expérimentation est [perl #18756] https://github.com/Perl/perl5/issues/18756.

Voir aussi : "(*positive_lookbehind:pattern)" dans perlre et "(*negative_lookbehind:pattern)" dans perlre

Hooks de caractères d'usage privé Unicode
Introduit dans Perl 5.30.0.

Cette fonctionnalité fait partie d'une interface destinée à l'usage interne et expérimental par les développeurs de perl5. Il est peu probable que vous la rencontriez dans la nature.

L'utilisation de cette fonctionnalité déclenche des avertissements dans la catégorie "experimental::private_use".

Le ticket pour cette expérimentation est [perl #18758] https://github.com/Perl/perl5/issues/18758.

Caractères joker de propriété Unicode
Introduit dans Perl 5.30.0.

Cette fonctionnalité permet de faire correspondre plus concise des propriétés de caractères Unicode dans les expressions régulières.

L'utilisation de cette fonctionnalité déclenche des avertissements dans la catégorie "experimental::uniprop_wildcards".

Le ticket pour cette expérimentation est [perl #18759] https://github.com/Perl/perl5/issues/18759.

Structure de contrôle try/catch
Introduit dans Perl 5.34.0.

L'utilisation du bloc optionnel "finally" de cette fonctionnalité déclenche des avertissements dans la catégorie "experimental::try".

Le ticket pour cette expérimentation est [perl #18760] https://github.com/Perl/perl5/issues/18760

Utilisation de @_ dans les signatures de sous-routines
Introduit dans Perl 5.36.0 dans le cadre d'une réduction de la portée des signatures de sous-routines expérimentales.

L'utilisation du tableau d'arguments par défaut (@_) dans une sous-routine qui utilise des signatures émettra un avertissement dans la catégorie "experimental::args_array_with_signatures". Cela inclut @_ directement, des éléments de celui-ci tels que $_[$index], ou des situations où le tableau d'arguments par défaut est accédé implicitement tels que "shift" ou "pop" sans arguments.

L'espace de noms builtin
Introduit dans Perl 5.36.0.

L'utilisation de certaines fonctions de cette fonctionnalité déclenche des avertissements dans la catégorie "experimental::builtin".

Dans Perl 5.36.0, un nouvel espace de noms, "builtin", a été créé pour les nouvelles fonctions du noyau qui ne seront pas présentes dans tous les espaces de noms, mais qui seront disponibles à l'importation. L'espace de noms lui-même était considéré comme expérimental jusqu'à Perl 5.39.2. Certaines fonctions spécifiques à l'intérieur restent expérimentales.

Le ticket pour cette expérimentation est [perl #19764] https://github.com/Perl/perl5/issues/19764.

Le modificateur de bloc defer
Introduit dans Perl 5.36.0

L'utilisation de cette fonctionnalité déclenche des avertissements dans la catégorie "experimental::defer".

Cette fonctionnalité ajoute un nouveau type de bloc, un bloc "defer", qui ne sera exécuté que lorsque le bloc contenant est quitté.

Le ticket pour cette expérimentation est [perl #17949] https://github.com/Perl/perl5/issues/17949.

Délimiteurs paires supplémentaires pour les opérateurs de type citation
Introduit dans Perl 5.36.0

L'utilisation de cette fonctionnalité déclenche des avertissements dans la catégorie "experimental::extra_paired_delimiters".

Cette fonctionnalité permet de nombreuses paires non ASCII de délimiteurs miroirs, par exemple :

my @array = qw« tinker tailor soldier spy »;

Le ticket pour cette expérimentation est [perl #19765] https://github.com/Perl/perl5/issues/19765.

"any" et "all" opérateurs de traitement de liste
Introduit dans Perl 5.41.7.

L'utilisation de ces fonctionnalités déclenche des avertissements dans les catégories "experimental::any" ou "experiment::all".

Cela ajoute de nouveaux opérateurs de traitement de liste nommés "any" et "all", chacun comme sa propre fonctionnalité nommée.

Le ticket pour cette expérimentation est [perl #22794] https://github.com/Perl/perl5/issues/22794.

Fonctionnalités acceptées

Ces fonctionnalités ont connu un succès fou et ont si bien interagi avec les autres que nous avons décidé de supprimer leur statut expérimental et de les admettre comme des fonctionnalités complètes et stables dans le monde de Perl, en leur accordant tous les avantages et les luxes qui en découlent. Elles reçoivent également +5 en Stabilité et +3 en Charisme.

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

Fonctionnalités abandonnées sur place

Ce sont des expériences considérées comme des échecs, mais en raison d'une utilisation massive, elles ont été laissées en place.

Les fonctionnalités switch et smartmatch sont susceptibles d'être les seules à tomber dans cette catégorie. Elles ont été introduites avant que nous ayons un processus de fonctionnalité expérimentale bien défini.

Il est peu probable qu'elles soient mises à jour avec des changements de comportement.

Smart match ("~~")
Introduit dans Perl 5.10.0

Modifié dans Perl 5.10.1, 5.12.0

Déprécié dans 5.38.0

Prévu pour suppression dans 5.42.0, mais cela a été annulé.

Activé par défaut, et dans tous les paquets de fonctionnalités jusqu'à 5.40, désactivé par défaut dans le paquet de fonctionnalités 5.42, mais peut être activé avec use feature "smartmatch".

Le ticket pour cette expérience est [perl #13173] https://github.com/Perl/perl5/issues/13173.

Switch (given/when)
Introduit dans Perl 5.10.0

Déprécié dans 5.38.0

Prévu pour suppression dans 5.42.0, mais cela a été annulé.

Activé par les paquets de fonctionnalités 5.10 à 5.34, mais peut être activé avec "use feature "switch"".

Le ticket pour cette expérience est [perl #13173] https://github.com/Perl/perl5/issues/13173.

NOM

perlexperiment - Exécute un script Perl dans un environnement expérimental.

DESCRIPTION

Le programme perlexperiment est un script wrapper qui permet d'exécuter un script Perl en utilisant un interpréteur Perl configuré avec des options expérimentales ou des fonctionnalités non encore stables.

Il est particulièrement utile pour tester les nouvelles fonctionnalités de Perl ou pour travailler avec des modules qui nécessitent des versions spécifiques ou des configurations particulières de l'interpréteur.

L'utilisation de perlexperiment peut entraîner un comportement inattendu ou des erreurs si les fonctionnalités expérimentales ne sont pas encore matures.
