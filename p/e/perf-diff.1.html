NOM

perf-diff - Lire les fichiers perf.data et afficher le profil différentiel

SYNTAXE

perf diff [fichier de référence] [fichier de données1] [[fichier de données2] ... ]

DESCRIPTION

Cette commande affiche la différence de performance entre deux fichiers perf.data ou plus capturés via perf record.

Si aucun paramètre n'est passé, elle suppose perf.data.old et perf.data.

Le profil différentiel est affiché uniquement pour les événements correspondant aux deux fichiers perf.data spécifiés.

Si aucun paramètre n'est passé, les échantillons seront triés par dso et symbole. Comme les fichiers perf.data peuvent provenir de binaires différents, les adresses des symboles peuvent varier. Ainsi, perf diff est basé sur la comparaison des noms de fichiers et de symboles.

OPTIONS

-D, --dump-raw-trace

Enregistrer la trace brute en ASCII.

--kallsyms=<fichier>

Chemin d'accès aux kallsyms

-m, --modules

Charger les symboles des modules. ATTENTION : à utiliser uniquement avec -k et le noyau LIVE

-d, --dsos=

Ne considérer que les symboles dans ces dsos. CSV qui comprend les entrées file://nom_de_fichier. Cette option affectera le pourcentage des colonnes Baseline/Delta. Voir --percentage pour plus d'informations.

-C, --comms=

Ne considérer que les symboles dans ces comms. CSV qui comprend les entrées file://nom_de_fichier. Cette option affectera le pourcentage des colonnes Baseline/Delta. Voir --percentage pour plus d'informations.

-S, --symbols=

Ne considérer que ces symboles. CSV qui comprend les entrées file://nom_de_fichier. Cette option affectera le pourcentage des colonnes Baseline/Delta. Voir --percentage pour plus d'informations.

-s, --sort=

Trier par clé(s) : pid, comm, dso, symbol, cpu, parent, srcline. Veuillez consulter la description de --sort dans la page de manuel perf-report.

-t, --field-separator=

Utiliser un caractère séparateur spécial et ne pas remplir avec des espaces, remplaçant toutes les occurrences de ce séparateur dans les noms de symboles (et autres sorties) par un caractère ., qui est donc le seul séparateur valide.

-v, --verbose

Être verbeux, par exemple, afficher les décomptes bruts en plus de la différence.

-q, --quiet

Ne pas afficher d'avertissements ou de messages. (Supprime -v)

-f, --force

Ne pas effectuer de validation de propriété.

--symfs=<répertoire>

Rechercher les fichiers contenant des symboles par rapport à ce répertoire.

-b, --baseline-only

Afficher uniquement les éléments qui correspondent dans la référence.

-c, --compute

Sélection du calcul différentiel - delta, ratio, wdiff, cycles, delta-abs (par défaut delta-abs). La valeur par défaut peut être modifiée en utilisant l'option de configuration diff.compute. Voir la section MÉTHODES DE COMPARAISON pour plus d'informations.

--cycles-hist

Rapporter un histogramme et l'écart type pour les données de cycles. Cela peut nous aider à juger si les données de cycles rapportées sont bruitées ou non. Cette option doit être utilisée avec -c cycles.

-p, --period

Afficher les valeurs de période pour les deux entrées d'historique comparées.

-F, --formula

Afficher la formule pour le calcul donné.

-o, --order

Spécifier le numéro de colonne de tri du calcul. 0 signifie le tri par la surcharge de référence et 1 (par défaut) signifie le tri par la valeur calculée de la colonne 1 (données du premier fichier autre que la référence). Les valeurs supérieures à 1 ne peuvent être utilisées que si suffisamment de fichiers de données sont fournis. La valeur par défaut peut être définie à l'aide de l'option de configuration diff.order.

--percentage

Déterminer comment afficher le pourcentage de surcharge des entrées filtrées. Des filtres peuvent être appliqués par les options --comms, --dsos et/ou --symbols. 
"relative" signifie qu'il est relatif aux entrées filtrées uniquement, de sorte que la somme des entrées affichées sera toujours de 100%. "absolute" signifie qu'il conserve la valeur originale avant et après l'application du filtre.

--time

Analyser les échantillons dans la fenêtre de temps donnée. Il prend en charge le pourcentage de temps avec plusieurs plages horaires. La chaîne de temps est a%/n,b%/m,... ou a%-b%,c%-%d,.... 
Par exemple :
Sélectionner la deuxième tranche horaire de 10% pour la comparaison :
perf diff --time 10%/2
Sélectionner de la tranche horaire 0% à 10% pour la comparaison :
perf diff --time 0%-10%
Sélectionner les première et deuxième tranches horaires de 10% pour la comparaison :
perf diff --time 10%/1,10%/2
Sélectionner les tranches horaires de 0% à 10% et de 30% à 40% pour la comparaison :
perf diff --time 0%-10%,30%-40%
Il prend également en charge l'analyse des échantillons dans une fenêtre de temps donnée <début>,<fin>. Les heures ont le format secondes.nanosecondes. Si 'début' n'est pas donné (c'est-à-dire que la chaîne de temps est ',x.y'), l'analyse commence au début du fichier. Si l'heure de fin n'est pas donnée (c'est-à-dire que la chaîne de temps est 'x.y,'), l'analyse va jusqu'à la fin du fichier. Plusieurs plages peuvent être séparées par des espaces, ce qui nécessite que l'argument soit mis entre guillemets, par exemple --time "1234.567,1234.789 1235," La chaîne de temps est 'a1.b1,c1.d1:a2.b2,c2.d2'. Utilisez ':' pour séparer les horodatages de différents fichiers perf.data.
Par exemple, nous obtenons les informations d'horodatage de 'perf script'.
perf script -i perf.data.old
  mgen 13940 [000]  3946.361400: ...
perf script -i perf.data
  mgen 13940 [000]  3971.150589 ...
perf diff --time 3946.361400,:3971.150589,
Il analyse perf.data.old depuis l'horodatage 3946.361400 jusqu'à la fin de perf.data.old et analyse perf.data depuis l'horodatage 3971.150589 jusqu'à la fin de perf.data.

--cpu

Comparer uniquement les échantillons pour la liste des CPU fournie. Plusieurs CPU peuvent être fournis sous forme de liste séparée par des virgules sans espace : 0,1. Les plages de CPU sont spécifiées avec - : 0-2. Par défaut, tous les CPU sont rapportés.

--pid=

Comparer uniquement les échantillons pour l'ID de processus donné (liste séparée par des virgules).

--tid=

Comparer uniquement les échantillons pour l'ID de thread donné (liste séparée par des virgules).

--stream

Activer la comparaison de flux chauds. Un flux peut être une chaîne d'appels agrégée par les enregistrements de branchement des échantillons.

COMPARAISON

La comparaison est régie par le fichier de référence. Le fichier perf.data de référence est parcouru pour les échantillons. Tous les autres fichiers perf.data spécifiés dans la ligne de commande sont recherchés pour la paire d'échantillons de référence. Si la paire est trouvée, le calcul spécifié est effectué et le résultat est affiché.

Tous les échantillons des fichiers perf.data non référencés, qui ne correspondent à aucune entrée de référence, sont affichés avec un espace vide dans la colonne de référence et les résultats de calcul possibles (delta) dans leur colonne associée.

Exemple d'échantillons de fichiers : - fichier A avec les échantillons f1, f2, f3, f4, f6 - fichier B avec les échantillons f2, f4, f5 - fichier C avec les échantillons f1, f2, f5

Exemple de sortie : x - le calcul a lieu pour la paire b - pourcentage de l'échantillon de référence

•perf diff A B C 
référence/A calcul/B calcul/C  échantillons
---------------------------------------
b                    x          f1
b          x         x          f2
b                               f3
b          x                    f4
b                               f6
           x         x          f5
•perf diff B A C 
référence/B calcul/A calcul/C  échantillons
---------------------------------------
b          x         x          f2
b          x                    f4
b                    x          f5
           x         x          f1
           x                    f3
           x                    f6
•perf diff C B A 
référence/C calcul/B calcul/A  échantillons
---------------------------------------
b                    x          f1
b          x         x          f2
b          x                    f5
                     x          f3
           x         x          f4
                     x          f6

MÉTHODES DE COMPARAISON

delta

Si spécifié, la colonne Delta est affichée avec la valeur d calculée comme suit :

d = A->period_percent - B->period_percent

avec : - A/B étant les entrées d'historique correspondantes des fichiers de données/de référence spécifiés (ou perf.data/perf.data.old) respectivement.

• period_percent étant le % de la valeur de période de l'entrée d'historique dans un seul fichier de données
• avec filtrage par -C, -d et/ou -S, period_percent peut être modifié par rapport à la façon dont les entrées sont filtrées. Utilisez --percentage=absolute pour éviter de telles fluctuations.

delta-abs

Identique à la méthode 'delta', mais trie le résultat par les valeurs absolues.

ratio

Si spécifié, la colonne Ratio est affichée avec la valeur r calculée comme suit :

r = A->period / B->period

avec : - A/B étant les entrées d'historique correspondantes des fichiers de données/de référence spécifiés (ou perf.data/perf.data.old) respectivement.

• period étant la valeur de période de l'entrée d'historique

wdiff:WEIGHT-B,WEIGHT-A

Si spécifié, la colonne Différence pondérée est affichée avec la valeur d calculée comme suit :

d = B->period * WEIGHT-A - A->period * WEIGHT-B
• A/B étant les entrées d'historique correspondantes des fichiers de données/de référence spécifiés (ou perf.data/perf.data.old) respectivement.
• period étant la valeur de période de l'entrée d'historique
• WEIGHT-A/WEIGHT-B étant des poids fournis par l'utilisateur dans l'option -c derrière le séparateur : comme -c wdiff:1,2.
• WEIGHT-A étant le poids du fichier de données
• WEIGHT-B étant le poids du fichier de données de référence

cycles

Si spécifié, la colonne Différence de cycles [Plage de blocs de programme] est affichée. Elle affiche la différence de cycles des mêmes blocs de base de programme parmi deux perf.data. Le bloc de base de programme est le code entre deux branchements.

[Plage de blocs de programme] indique la plage d'un bloc de base de programme. La ligne source est signalée si elle peut être trouvée, sinon elle utilise le symbole + décalage.
