PERLHACKTUT(1perl) Guide de référence du programmeur Perl PERLHACKTUT(1perl)

NOM

perlhacktut — Parcourt la création d'un patch simple en code C

DESCRIPTION

Ce document vous guide à travers un exemple de patch simple.

Si vous n'avez pas encore lu perlhack, allez le faire d'abord ! Vous voudrez peut-être aussi parcourir perlsource.

Une fois que vous avez terminé ici, consultez perlhacktips ensuite.

EXEMPLE DE PATCH SIMPLE

Prenons un patch simple, du début à la fin.

Voici quelque chose que Larry a suggéré : si un format "U" est le premier format actif lors d'un "pack" (par exemple, "pack "U3C8", @stuff"), alors la chaîne résultante doit être traitée comme étant encodée en UTF-8.

Si vous travaillez avec un clone git du dépôt Perl, vous voudrez créer une branche pour vos modifications. Cela rendra la création d'un patch approprié beaucoup plus simple. Voir perlgit pour les détails sur la façon de faire cela.

Écrire le patch

Comment nous préparons-nous à corriger cela ? D'abord, nous localisons le code en question - le "pack" se produit à l'exécution, donc il sera dans l'un des fichiers pp. En effet, "pp_pack" se trouve dans pp.c. Comme nous allons modifier ce fichier, copions-le dans pp.c~.

[Eh bien, il était dans pp.c quand ce tutoriel a été écrit. Il a maintenant été séparé avec "pp_unpack" dans son propre fichier, pp_pack.c]

Maintenant, regardons "pp_pack" : nous prenons un motif dans "pat", puis nous parcourons le motif, prenant chaque caractère de format à tour de rôle dans "datum_type". Ensuite, pour chaque caractère de format possible, nous avalons les autres arguments du motif (une largeur de champ, un astérisque, et ainsi de suite) et convertissons le prochain morceau d'entrée dans le format spécifié, l'ajoutant au SV de sortie "cat".

Comment savons-nous si le "U" est le premier format dans le "pat" ? Eh bien, si nous avons un pointeur vers le début de "pat", alors, si nous voyons un "U", nous pouvons tester si nous sommes toujours au début de la chaîne. Donc, voici où "pat" est configuré :

STRLEN fromlen;
char *pat = SvPVx(*++MARK, fromlen);
char *patend = pat + fromlen;
I32 len;
I32 datumtype;
SV *fromstr;

Nous aurons un autre pointeur de chaîne là-dedans :

   STRLEN fromlen;
   char *pat = SvPVx(*++MARK, fromlen);
   char *patend = pat + fromlen;
+  char *patcopy;
   I32 len;
   I32 datumtype;
   SV *fromstr;

Et juste avant de commencer la boucle, nous allons définir "patcopy" pour qu'il pointe vers le début de "pat" :

   items = SP - MARK;
   MARK++;
   SvPVCLEAR(cat);
+  patcopy = pat;
   while (pat < patend) {

Maintenant, si nous voyons un "U" qui était au début de la chaîne, nous activons le drapeau "UTF8" pour le SV de sortie, "cat" :

+  if (datumtype == 'U' && pat==patcopy+1)
+      SvUTF8_on(cat);
   if (datumtype == '#') {
       while (pat < patend && *pat != '\n')
           pat++;

Rappelez-vous qu'il doit s'agir de "patcopy+1" car le premier caractère de la chaîne est le "U" qui a été avalé dans "datumtype!"

Oups, nous avons oublié une chose : qu'en est-il si des espaces se trouvent au début du motif ? "pack(" U*", @stuff)" aura "U" comme premier caractère actif, même si ce n'est pas la première chose dans le motif. Dans ce cas, nous devons avancer "patcopy" en même temps que "pat" lorsque nous rencontrons des espaces :

if (isSPACE(datumtype))
    continue;

devient

if (isSPACE(datumtype)) {
    patcopy++;
    continue;
}

OK. C'est la partie C terminée. Nous devons maintenant faire deux choses supplémentaires avant que ce patch ne soit prêt : nous avons modifié le comportement de Perl, nous devons donc documenter ce changement. Nous devons également fournir des tests de régression supplémentaires pour nous assurer que notre patch fonctionne et ne crée pas de bug ailleurs.

Tester le patch

Les tests de régression pour chaque opérateur se trouvent dans t/op/, nous faisons donc une copie de t/op/pack.t dans t/op/pack.t~. Maintenant, nous pouvons ajouter nos tests à la fin. D'abord, nous allons tester que le "U" crée bien des chaînes Unicode.

t/op/pack.t a une fonction ok() sensée, mais si ce n'était pas le cas, nous pourrions utiliser celle de t/test.pl.

require './test.pl';
plan( tests => 159 );

donc au lieu de cela :

print 'not ' unless "1.20.300.4000" eq sprintf "%vd",
                                              pack("U*",1,20,300,4000);
print "ok $test\n"; $test++;

nous pouvons écrire le plus sensé (voir Test::More pour une explication complète de is() et d'autres fonctions de test).

is( "1.20.300.4000", sprintf "%vd", pack("U*",1,20,300,4000),
                                      "U* produit de l'Unicode" );

Maintenant, nous allons tester que nous avons bien géré cette histoire d'espaces au début :

is( "1.20.300.4000", sprintf "%vd", pack("  U*",1,20,300,4000),
                                    "  avec des espaces au début" );

Et enfin, nous allons tester que nous ne créons pas de chaînes Unicode si "U" n'est **pas** le premier format actif :

isnt( v1.20.300.4000, sprintf "%vd", pack("C0U*",1,20,300,4000),
                                      "U* pas le premier n'est pas Unicode" );

Il ne faut pas oublier de changer le nombre de tests qui apparaît en haut, sinon le testeur automatisé sera confus. Cela ressemblera soit à ceci :

print "1..156\n";

soit à ceci :

plan( tests => 156 );

Nous compilons maintenant Perl et le faisons passer par la suite de tests. Nos nouveaux tests passent, hourra !

Documenter le patch

Enfin, la documentation. Le travail n'est jamais terminé tant que la paperasse n'est pas finie, alors décrivons le changement que nous venons d'apporter. L'endroit pertinent est pod/perlfunc.pod ; encore une fois, nous faisons une copie, puis nous insérerons ce texte dans la description de "pack" :

=item *
Si le motif commence par un C<U>, la chaîne résultante sera traitée comme de l'Unicode encodé en UTF-8. Vous pouvez forcer l'encodage UTF-8 dans une chaîne avec un C<U0> initial, et les octets qui suivent seront interprétés comme des caractères Unicode. Si vous ne voulez pas que cela se produise, vous pouvez commencer votre motif par C<C0> (ou autre chose) pour forcer Perl à ne pas encoder votre chaîne en UTF-8, puis faire suivre cela d'un C<U*> quelque part dans votre motif.

Soumettre

Voir perlhack pour les détails sur la façon de soumettre ce patch.
