DESCRIPTION

Ce document vise à enregistrer les publications du code source de Perl.

INTRODUCTION

Bref historique de Perl, par Larry Wall :

Perl 0 a introduit Perl aux collègues de mon bureau.
Perl 1 a introduit Perl au monde, et a changé /\(...\|...\)/ en
    /(...|...)/.  \(Dan Faigin ne m'a toujours pas pardonné. :-\)
Perl 2 a introduit le paquet d'expressions régulières de Henry Spencer.
Perl 3 a introduit la capacité de gérer des données binaires (nulls intégrés).
Perl 4 a introduit le premier livre Camel.  Vraiment. Nous avons surtout
    changé les numéros de version pour que le livre puisse faire référence à 4.000.
Perl 5 a introduit tout le reste, y compris la capacité
    d'introduire tout le reste.

CITROUILLE?

[provenant de Porting/pumpkin.pod dans la distribution source de Perl]

Chip Salzenberg en est crédité, avec un clin d'œil à son collègue, David Croy. Nous avions fait circuler divers noms (bâton, jeton, patate chaude) mais aucun n'a pris. Puis, Chip a demandé :

[début de citation]

Qui a la citrouille du correctif ?

Pour expliquer : David Croy m'a dit qu'à un emploi précédent, il y avait un seul lecteur de bande et plusieurs systèmes qui l'utilisaient pour les sauvegardes. Mais au lieu d'un logiciel d'exclusion high-tech, ils utilisaient une méthode low-tech pour empêcher les sauvegardes simultanées : une citrouille en peluche. Personne n'était autorisé à faire des sauvegardes sauf s'il avait la "citrouille de sauvegarde".

[fin de citation]

Le nom est resté. Le détenteur de la citrouille est parfois appelé le pumpking (gardien de la source ?) ou le pumpkineer (celui qui tire les cordes ?).

NAME

perlhist - History of Perl releases

DESCRIPTION

This document lists the releases of Perl, along with some information about them. It is intended to be a historical record, not a complete specification of Perl's evolution.

INTRODUCTION

This is a list of releases of Perl, with some associated data. The primary purpose is to track the history of significant changes. The columns are:

Name:
The release name, if any. This is often the name of the person who maintained the release.
Version:
The version number of the release.
Date:
The date of the release.
Files:
The number of files in the distribution.
Lines:
The total number of lines of code in the distribution.
Patch:
The number of lines that would be in a patch to upgrade from the previous version. This is not always the number of lines of code added or deleted, but rather the number of lines that differ between the two versions.

The data is gathered from various sources, primarily the release notes and the historical archives of the Perl development mailing lists. It is not guaranteed to be 100% accurate, but it represents a good faith effort to provide a useful historical record.
