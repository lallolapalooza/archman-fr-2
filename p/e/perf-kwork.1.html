NOM

perf-kwork - Outil pour tracer/mesurer les propriétés du travail du noyau (latences)

SYNTAXE

perf kwork {record|report|latency|timehist|top}

DESCRIPTION

Il existe plusieurs variantes de perf kwork :

'perf kwork record <commande>' pour enregistrer le travail du noyau
d'une charge de travail arbitraire.
'perf kwork report' pour rapporter le temps d'exécution par kwork.
'perf kwork latency' pour rapporter les latences par kwork.
'perf kwork timehist' fournit une analyse des événements de travail du noyau.
'perf kwork top' pour rapporter l'utilisation du CPU par tâche.
Exemple d'utilisation :
    perf kwork record -- sleep 1
    perf kwork report
    perf kwork report -b
    perf kwork latency
    perf kwork latency -b
    perf kwork timehist
    perf kwork top
    perf kwork top -b
Par défaut, il affiche les événements de travail individuels tels que irq, workqueue,
y compris le temps d'exécution et le délai (temps entre l'activation et l'entrée réelle) :

OPTIONS

-D, --dump-raw-trace=

Affiche une sortie détaillée des données de planification.

-f, --force

Ne pas se plaindre, le faire.

-k, --kwork

Liste des kworks à profiler (irq, softirq, workqueue, sched, etc.)

-v, --verbose

Être plus verbeux. (affiche l'adresse du symbole, etc.)

OPTIONS pour perf kwork report

.ft C
-b::
--use-bpf::
        Utilise BPF pour mesurer le temps d'exécution du kwork
-C::
--cpu::
        N'affiche les événements que pour le(s) CPU(s) donné(s) (liste séparée par des virgules).
-i::
--input::
        Nom du fichier d'entrée. (par défaut : perf.data sauf si stdin est un fifo)
-n::
--name::
        N'affiche les événements que pour le nom donné.
-s::
--sort::
        Trier par clé(s) : temps d'exécution, max, nombre
-S::
--with-summary::
        Afficher un résumé avec des statistiques
--time::
        N'analyser que les échantillons dans la fenêtre de temps donnée : <début>,<fin>. Les temps
        ont le format secondes.microsecondes. Si le début n'est pas donné (c'est-à-dire que la chaîne de temps est ',x.y') alors l'analyse commence au début du fichier. Si
        l'heure de fin n'est pas donnée (c'est-à-dire que la chaîne de temps est 'x.y,') alors l'analyse va
        jusqu'à la fin du fichier.
