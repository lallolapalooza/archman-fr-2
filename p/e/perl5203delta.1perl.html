PERL5203DELTA(1perl) Guide du programmeur Perl PERL5203DELTA(1perl)

NOM

perl5203delta - nouveautés de la version perl v5.20.3

DESCRIPTION

Ce document décrit les différences entre les versions 5.20.2 et 5.20.3.

Si vous mettez à jour depuis une version antérieure comme la 5.20.1, lisez d'abord perl5202delta, qui décrit les différences entre la 5.20.1 et la 5.20.2.

Changements incompatibles

Il n'y a aucun changement intentionnellement incompatible avec la version 5.20.2. S'il en existe, ce sont des bugs, et nous vous prions de soumettre un rapport. Voir "Signalement de bugs" ci-dessous.

Modules et Pragmata

Modules et Pragmata mis à jour

  • Errno a été mis à jour de la version 1.20_05 à 1.20_06.

    Ajouter -P à la ligne de commande du préprocesseur sur GCC 5. GCC a ajouté des directives de ligne supplémentaires, rompant l'analyse des définitions de codes d'erreur. [GH #14491] https://github.com/Perl/perl5/issues/14491

  • Module::CoreList a été mis à jour de la version 5.20150214 à 5.20150822.

    Mis à jour pour couvrir les dernières versions de Perl.

  • perl5db.pl a été mis à jour de la version 1.44 à 1.44_01.

    Le débogueur provoquait un échec d'assertion. [GH #14605] https://github.com/Perl/perl5/issues/14605

Documentation

Changements dans la documentation existante

perlfunc

•
Mentionner que study() ne fait actuellement rien.

perlguts

•
L'exemple OOK a été mis à jour pour tenir compte des changements COW et d'un changement dans le stockage du décalage.

perlhacktips

•
La documentation a été ajoutée pour illustrer les dangers de supposer que le contenu de la mémoire statique pointée par les valeurs de retour des wrappers Perl pour les fonctions de la bibliothèque C ne change pas.

perlpodspec

•
La spécification du langage POD change de manière à ce que l'encodage par défaut des POD qui ne sont pas en UTF-8 (sauf indication contraire) soit CP1252 au lieu de ISO-8859-1 (Latin1).

Changements utilitaires

h2ph

•
h2ph gère désormais les constantes hexadécimales dans les définitions de macros prédéfinies du compilateur, telles qu'elles apparaissent dans $Config{cppsymbols}. [GH #14491] https://github.com/Perl/perl5/issues/14491

Tests

  • t/perf/taint.t a été ajouté pour vérifier si les optimisations avec des problèmes de taint maintiennent la rapidité.
  • t/porting/re_context.t a été ajouté pour tester que utf8 et ses dépendances n'utilisent que le sous-ensemble des variables de capture "$1..$n" que Perl_save_re_context() est codé en dur pour localiser, car cette fonction n'a pas de moyen efficace de déterminer au moment de l'exécution quelles variables localiser.

Support plateforme

Notes spécifiques à la plateforme

Win32
  • Auparavant, lors de la compilation avec un Visual C++ 64 bits, tous les modules Perl XS (y compris ceux de CPAN) et les fichiers C conscients de Perl affichaient inconditionnellement une douzaine d'avertissements provenant de hv_func.h. Ces avertissements ont été supprimés. GCC (toutes tailles) et Visual C++ 32 bits n'étaient pas affectés.
  • miniperl.exe est désormais compilé avec -fno-strict-aliasing, permettant aux builds 64 bits de se terminer avec GCC 4.8. [GH #14556] https://github.com/Perl/perl5/issues/14556

Corrections de bugs sélectionnées

  • Les correspondances globales répétées dans un contexte scalaire sur de grandes chaînes marquées étaient exponentiellement lentes en fonction de la position de correspondance actuelle dans la chaîne. [GH #14238] https://github.com/Perl/perl5/issues/14238
  • La valeur visible d'origine de $/ est maintenant préservée lorsqu'elle est définie sur une valeur invalide. Auparavant, si vous définissiez $/ sur une référence à un tableau, par exemple, perl produisait une erreur d'exécution et ne définissait pas PL_rs, mais le code Perl qui vérifiait $/ voyait la référence au tableau. [GH #14245] https://github.com/Perl/perl5/issues/14245
  • Perl 5.14.0 a introduit un bug où "eval { LABEL: }" provoquait un crash. Ceci a été corrigé. [GH #14438] https://github.com/Perl/perl5/issues/14438
  • L'extension d'un tableau cloné à partir d'un thread parent pouvait entraîner des erreurs "Modification d'une valeur en lecture seule tentée" lors de la tentative de modification des nouveaux éléments. [GH #14605] https://github.com/Perl/perl5/issues/14605
  • Plusieurs cas de données utilisées pour stocker le contenu des variables d'environnement dans le code C principal qui pouvaient être écrasées avant d'être utilisées ont été corrigés. [GH #14476] https://github.com/Perl/perl5/issues/14476
  • Les noms de variables UTF-8 utilisés dans les index de tableaux, les terminateurs de documents HERE UTF-8 non cités et les noms de fonctions UTF-8 fonctionnent désormais correctement. [GH #14601] https://github.com/Perl/perl5/issues/14601
  • Un bug subtil introduit dans Perl 5.20.2 impliquant l'UTF-8 dans les expressions régulières et provoquant parfois un crash a été corrigé. Un nouveau script de test a été ajouté pour tester cette correction ; voir sous "Tests". [GH #14600] https://github.com/Perl/perl5/issues/14600
  • Certains motifs commençant par "/.*..../" correspondant à de longues chaînes étaient lents depuis Perl 5.8, et certains de la forme "/.*..../i" étaient lents depuis Perl 5.18. Ils sont maintenant à nouveau rapides. [GH #14475] https://github.com/Perl/perl5/issues/14475
  • La fatalité des avertissements est désormais ignorée lors du rembobinage de la pile. Cela empêche les récursions infinies lorsque l'erreur devenue fatale provoque également un rembobinage de la pile. [GH #14319] https://github.com/Perl/perl5/issues/14319
  • setpgrp($nonzero) (avec un argument) avait été accidentellement changé en Perl 5.16 pour signifier setpgrp(0). Ceci a été corrigé.
  • Un crash avec "%::=(); J->${\"::"}" a été corrigé. [GH #14790] https://github.com/Perl/perl5/issues/14790
  • Le quantificateur possessif d'expression régulière, régression de Perl 5.20, est maintenant corrigé. "qr/"PAT"{"min,max"}+""/" doit se comporter de manière identique à "qr/(?>"PAT"{"min,max"})/". Depuis Perl 5.20, cela ne fonctionnait pas si min et max étaient égaux. [GH #14857] https://github.com/Perl/perl5/issues/14857

Reporting Bugs

If you find what you think is a bug, you might check the articles recently posted to the comp.lang.perl.misc newsgroup and the perl bug database at https://rt.perl.org/ . There may also be information at http://www.perl.org/ , the Perl Home Page.

If you believe you have an unreported bug, please run the perlbug program included with your release. Be sure to trim your bug down to a tiny but sufficient test case. Your bug report, along with the output of "perl -V", will be sent off to perlbug@perl.org to be analysed by the Perl porting team.

If the bug you are reporting has security implications, which make it inappropriate to send to a publicly archived mailing list, then please send it to perl5-security-report@perl.org. This points to a closed subscription unarchived mailing list, which includes all the core committers, who will be able to help assess the impact of issues, figure out a resolution, and help co-ordinate the release of patches to mitigate or fix the problem across all platforms on which Perl is supported. Please only use this address for security issues in the Perl core, not for modules independently distributed on CPAN.
