NOM

perllexwarn - Avertissements lexicaux Perl

DESCRIPTION

Perl v5.6.0 a introduit le contrôle lexical sur la gestion des avertissements par catégorie. Le pragma "warnings" remplace généralement l'indicateur de ligne de commande -w. La documentation sur l'utilisation des avertissements lexicaux, autrefois partiellement trouvée dans ce document, se trouve maintenant dans la documentation des avertissements.
