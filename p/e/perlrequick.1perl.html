PERLREQUICK(1perl) Guide de référence du programmeur Perl PERLREQUICK(1perl)

NOM

perlrequick - Démarrage rapide des expressions régulières Perl

DESCRIPTION

Cette page couvre les bases de la compréhension, de la création et de l'utilisation des expressions régulières ('regex') en Perl.

Le guide

Cette page suppose que vous connaissez déjà des choses, comme ce qu'est un "motif" (pattern), et la syntaxe de base pour les utiliser. Si ce n'est pas le cas, consultez perlretut.

Correspondance de mots simples

La regex la plus simple est simplement un mot, ou plus généralement, une chaîne de caractères. Une regex composée d'un mot correspond à toute chaîne qui contient ce mot :

"Hello World" =~ /World/;  # correspond

Dans cette instruction, "World" est une regex et les délimiteurs "//" entourant "/World/" indiquent à Perl de rechercher une correspondance dans une chaîne. L'opérateur "=~" associe la chaîne à la correspondance de la regex et produit une valeur vraie si la regex a trouvé une correspondance, ou fausse si elle n'en a pas trouvé. Dans notre cas, "World" correspond au deuxième mot dans "Hello World", donc l'expression est vraie. Cette idée a plusieurs variations.

Des expressions comme celle-ci sont utiles dans les conditions :

print "Ça correspond\n" if "Hello World" =~ /World/;

Le sens de la correspondance peut être inversé en utilisant l'opérateur "!~" :

print "Ça ne correspond pas\n" if "Hello World" !~ /World/;

La chaîne littérale dans la regex peut être remplacée par une variable :

$greeting = "World";
print "Ça correspond\n" if "Hello World" =~ /$greeting/;

Si vous faites une correspondance avec $_, la partie "$_ =~" peut être omise :

$_ = "Hello World";
print "Ça correspond\n" if /World/;

Enfin, les délimiteurs par défaut "//" pour une correspondance peuvent être remplacés par des délimiteurs arbitraires en plaçant un 'm' devant :

"Hello World" =~ m!World!;   # correspond, délimité par '!'
"Hello World" =~ m{World};   # correspond, notez les accolades correspondantes '{}'
"/usr/bin/perl" =~ m"/perl"; # correspond après '/usr/bin',
                             # '/' devient un caractère ordinaire

Les regex doivent correspondre à une partie de la chaîne *exactement* pour que l'instruction soit vraie :

"Hello World" =~ /world/;  # ne correspond pas, sensible à la casse
"Hello World" =~ /o W/;    # correspond, ' ' est un caractère ordinaire
"Hello World" =~ /World /; # ne correspond pas, pas d'espace à la fin

Perl fera toujours correspondre au point le plus précoce possible dans la chaîne :

"Hello World" =~ /o/;       # correspond au 'o' dans 'Hello'
"That hat is red" =~ /hat/; # correspond au 'hat' dans 'That'

Tous les caractères ne peuvent pas être utilisés "tels quels" dans une correspondance. Certains caractères, appelés métacaractères, sont considérés comme spéciaux et réservés à une utilisation dans la notation regex. Les métacaractères sont

{}[]()^$.|*+?\

Un métacaractère peut être recherché littéralement en plaçant une barre oblique inverse avant lui :

"2+2=4" =~ /2+2/;    # ne correspond pas, le '+' est un métacaractère
"2+2=4" =~ /2\+2/;   # correspond, \+ est traité comme un '+' ordinaire
'C:\WIN32' =~ /C:\\WIN/;                       # correspond
"/usr/bin/perl" =~ /\/usr\/bin\/perl/;  # correspond

Dans la dernière regex, la barre oblique '/' est également échappée, car elle est utilisée pour délimiter la regex.

La plupart des métacaractères ne sont pas toujours spéciaux, et d'autres caractères (comme ceux qui délimitent le motif) deviennent spéciaux dans diverses circonstances. Cela peut être déroutant et entraîner des résultats inattendus. "use re 'strict'" peut vous informer des écueils potentiels.

Les caractères ASCII non imprimables sont représentés par des séquences d'échappement. Les exemples courants sont "\t" pour une tabulation, "\n" pour un saut de ligne et "\r" pour un retour chariot. Les octets arbitraires sont représentés par des séquences d'échappement octales, par ex. "\033", ou des séquences d'échappement hexadécimales, par ex. "\x1B" :

"1000\t2000" =~ m(0\t2)  # correspond
"cat" =~ /\143\x61\x74/  # correspond en ASCII, mais
                         # une manière étrange d'écrire cat

Les regex sont traitées la plupart du temps comme des chaînes entre guillemets doubles, donc la substitution de variables fonctionne :

$foo = 'house';
'cathouse' =~ /cat$foo/;   # correspond
'housecat' =~ /${foo}cat/; # correspond

Avec toutes les regex ci-dessus, si la regex correspondait n'importe où dans la chaîne, elle était considérée comme une correspondance. Pour spécifier *où* elle doit correspondre, nous utiliserions les métacaractères d'ancre "^" et "$". L'ancre "^" signifie correspondre au début de la chaîne et l'ancre "$" signifie correspondre à la fin de la chaîne, ou avant un saut de ligne à la fin de la chaîne. Quelques exemples :

"housekeeper" =~ /keeper/;         # correspond
"housekeeper" =~ /^keeper/;        # ne correspond pas
"housekeeper" =~ /keeper$/;        # correspond
"housekeeper\n" =~ /keeper$/;      # correspond
"housekeeper" =~ /^housekeeper$/;  # correspond

Utilisation des classes de caractères

Une classe de caractères permet qu'un ensemble de caractères possibles, plutôt qu'un seul caractère, corresponde à un point particulier d'une regex. Il existe plusieurs types de classes de caractères, mais généralement, lorsque les gens utilisent ce terme, ils font référence au type décrit dans cette section, techniquement appelé "classes de caractères entre crochets", car elles sont délimitées par des crochets "[...]", avec l'ensemble des caractères à éventuellement faire correspondre à l'intérieur. Mais nous laisserons tomber "entre crochets" ci-dessous pour correspondre à l'usage courant. Voici quelques exemples de classes de caractères (entre crochets) :

/cat/;            # correspond à 'cat'
/[bcr]at/;        # correspond à 'bat', 'cat', ou 'rat'
"abc" =~ /[cab]/; # correspond à 'a'

Dans la dernière instruction, même si 'c' est le premier caractère de la classe, le point le plus précoce auquel la regex peut correspondre est 'a'.

/[yY][eE][sS]/; # correspond à 'yes' d'une manière insensible à la casse
                # 'yes', 'Yes', 'YES', etc.
/yes/i;         # correspond également à 'yes' d'une manière insensible à la casse

Le dernier exemple montre une correspondance avec un modificateur 'i', qui rend la correspondance insensible à la casse.

Les classes de caractères ont également des caractères ordinaires et spéciaux, mais les ensembles de caractères ordinaires et spéciaux à l'intérieur d'une classe de caractères sont différents de ceux à l'extérieur d'une classe de caractères. Les caractères spéciaux pour une classe de caractères sont "-]\^$" et sont mis en correspondance à l'aide d'un échappement :

/[\]c]def/; # correspond à ']def' ou 'cdef'
$x = 'bcr';
/[$x]at/;   # correspond à 'bat', 'cat', ou 'rat'
/[\$x]at/;  # correspond à '$at' ou 'xat'
/[\\$x]at/; # correspond à '\at', 'bat', 'cat', ou 'rat'

Le caractère spécial '-' agit comme un opérateur de plage dans les classes de caractères, de sorte que l'encombrant "[0123456789]" et "[abc...xyz]" deviennent le svelte "[0-9]" et "[a-z]" :

/item[0-9]/;  # correspond à 'item0' ou ... ou 'item9'
/[0-9a-fA-F]/;  # correspond à un chiffre hexadécimal

Si '-' est le premier ou le dernier caractère d'une classe de caractères, il est traité comme un caractère ordinaire.

Le caractère spécial "^" dans la première position d'une classe de caractères indique une classe de caractères niée, qui correspond à tout caractère sauf ceux entre crochets. Les deux "[...]" et "[^...]" doivent correspondre à un caractère, sinon la correspondance échoue. Ensuite

/[^a]at/;  # ne correspond pas à 'aat' ou 'at', mais correspond
           # à tous les autres 'bat', 'cat', '0at', '%at', etc.
/[^0-9]/;  # correspond à un caractère non numérique
/[a^]at/;  # correspond à 'aat' ou '^at'; ici '^' est ordinaire

Les abréviations "\d\s\w\D\S\W" peuvent être utilisées à l'intérieur et à l'extérieur des classes de caractères. Voici quelques exemples d'utilisation :

/\d\d:\d\d:\d\d/; # correspond à un format horaire hh:mm:ss
/[\d\s]/;         # correspond à n'importe quel chiffre ou caractère d'espacement
/\w\W\w/;         # correspond à un caractère de mot, suivi d'un

/..rt/;           # correspond à n'importe quels deux caractères, suivis de 'rt'
/end\./;          # correspond à 'end.'
/end[.]/;         # même chose, correspond à 'end.'

L'ancre de mot "\b" correspond à une frontière entre un caractère de mot et un caractère non mot "\w\W" ou "\W\w" :

$x = "Housecat catenates house and cat";
$x =~ /\bcat/;  # correspond à cat dans 'catenates'
$x =~ /cat\b/;  # correspond à cat dans 'housecat'
$x =~ /\bcat\b/;  # correspond à 'cat' à la fin de la chaîne

Dans le dernier exemple, la fin de la chaîne est considérée comme une frontière de mot.

Pour le traitement du langage naturel (afin que, par exemple, les apostrophes soient inclus dans les mots), utilisez plutôt "\b{wb}"

"don't" =~ / .+? \b{wb} /x;  # correspond à toute la chaîne

Correspondance de ceci ou de cela

Nous pouvons faire correspondre différentes chaînes de caractères avec le méta-caractère d'alternance '|'. Pour faire correspondre "chien" ou "chat", nous formons l'expression régulière "chien|chat". Comme auparavant, Perl essaiera de faire correspondre l'expression régulière au plus tôt possible dans la chaîne. À chaque position de caractère, Perl essaiera d'abord de faire correspondre la première alternative, "chien". Si "chien" ne correspond pas, Perl essaiera ensuite la prochaine alternative, "chat". Si "chat" ne correspond pas non plus, alors la correspondance échoue et Perl passe à la position suivante dans la chaîne. Quelques exemples :

"chats et chiens" =~ /chat|chien|oiseau/;  # correspond à "chat"
"chats et chiens" =~ /chien|chat|oiseau/;  # correspond à "chat"

Même si "chien" est la première alternative dans la deuxième expression régulière, "chat" peut correspondre plus tôt dans la chaîne.

"chats"          =~ /c|ch|cha|chats/; # correspond à "c"
"chats"          =~ /chats|cha|ch|c/; # correspond à "chats"

À une position de caractère donnée, la première alternative qui permet à l'expression régulière de correspondre sera celle qui correspondra. Ici, toutes les alternatives correspondent à la première position de chaîne, donc la première correspond.

Groupement de choses et correspondance hiérarchique

Les méta-caractères de groupement "()" permettent de traiter une partie d'une expression régulière comme une seule unité. Les parties d'une expression régulière sont regroupées en les plaçant entre parenthèses. L'expression régulière maison(chat|gardien) signifie faire correspondre "maison" suivi de soit "chat" soit "gardien". D'autres exemples :

/(a|b)b/;    # correspond à 'ab' ou 'bb'
/(^a|b)c/;   # correspond à 'ac' au début de la chaîne ou 'bc' n'importe où
/maison(chat|)/;  # correspond soit à 'maisonchat' soit à 'maison'
/maison(chat(s|)|)/;  # correspond soit à 'maisonchats' soit à 'maisonchat' soit à
                    # 'maison'. Notez que les groupes peuvent être imbriqués.
"20" =~ /(19|20|)\d\d/;  # correspond à l'alternative nulle '()\d\d',
                         # car '20\d\d' ne peut pas correspondre

Extraction des correspondances

Les méta-caractères de groupement "()" permettent également d'extraire les parties d'une chaîne qui ont correspondu. Pour chaque groupement, la partie qui a correspondu à l'intérieur est stockée dans les variables spéciales $1, $2, etc. Elles peuvent être utilisées comme des variables ordinaires :

# extraire les heures, minutes, secondes
$temps =~ /(\d\d):(\d\d):(\d\d)/;  # faire correspondre le format hh:mm:ss
$heures = $1;
$minutes = $2;
$secondes = $3;

En contexte de liste, une correspondance "/regex/" avec des groupements retournera la liste des valeurs correspondantes "($1,$2,...)". Nous pourrions donc la réécrire ainsi :

($heures, $minutes, $secondes) = ($temps =~ /(\d\d):(\d\d):(\d\d)/);

Si les groupements dans une expression régulière sont imbriqués, $1 prend le groupe avec la parenthèse ouvrante la plus à gauche, $2 la parenthèse ouvrante suivante, etc. Par exemple, voici une expression régulière complexe et les variables correspondantes indiquées ci-dessous :

/(ab(cd|ef)((gi)|j))/;
 1  2      34

Associées aux variables correspondantes $1, $2, ... se trouvent les références arrière "\g1", "\g2", ... Les références arrière sont des variables correspondantes qui peuvent être utilisées *à l'intérieur* d'une expression régulière :

/(\w\w\w)\s\g1/; # trouver des séquences comme 'le le' dans la chaîne

$1, $2, ... ne doivent être utilisés qu'à l'extérieur d'une expression régulière, et "\g1", "\g2", ... uniquement à l'intérieur d'une expression régulière.

Correspondance des répétitions

Les méta-caractères quantificateurs "?", "*", "+", et "{}" nous permettent de déterminer le nombre de répétitions d'une partie d'une expression régulière que nous considérons comme une correspondance. Les quantificateurs sont placés immédiatement après le caractère, la classe de caractères ou le groupement dont nous voulons spécifier le nombre de répétitions. Ils ont les significations suivantes :

  • "a?" = correspond à 'a' 1 ou 0 fois
  • "a*" = correspond à 'a' 0 fois ou plus, c'est-à-dire un nombre quelconque de fois
  • "a+" = correspond à 'a' 1 fois ou plus, c'est-à-dire au moins une fois
  • "a{n,m}" = correspond au moins "n" fois, mais pas plus de "m" fois.
  • "a{n,}" = correspond au moins "n" fois ou plus
  • "a{,n}" = correspond "n" fois ou moins (Ajouté dans la v5.34)
  • "a{n}" = correspond exactement "n" fois

Voici quelques exemples :

/[a-z]+\s+\d*/;  # faire correspondre un mot en minuscules, au moins un espace, et
                 # n'importe quel nombre de chiffres
/(\w+)\s+\g1/;    # faire correspondre des mots doublés de longueur arbitraire
$annee =~ /^\d{2,4}$/;  # s'assurer que l'année a au moins 2 mais pas plus de
                       # 4 chiffres
$annee =~ /^\d{ 4 }$|^\d{2}$/; # meilleure correspondance ; rejeter les dates à 3 chiffres

Ces quantificateurs essaieront de faire correspondre autant de la chaîne que possible, tout en permettant à l'expression régulière de correspondre. Nous avons donc :

$x = 'le chat dans le chapeau';
$x =~ /^(.*)(at)(.*)$/; # correspond,
                        # $1 = 'le chat dans le h'
                        # $2 = 'at'
                        # $3 = ''   (0 correspondances)

Le premier quantificateur ".*" capture autant de la chaîne que possible tout en permettant à l'expression régulière de correspondre. Le deuxième quantificateur ".*" n'a plus de chaîne à sa disposition, il correspond donc 0 fois.

Plus de correspondances

Il y a quelques autres choses que vous pourriez vouloir savoir sur les opérateurs de correspondance. Le modificateur global "/g" permet à l'opérateur de correspondance de faire des correspondances dans une chaîne autant de fois que possible. En contexte scalaire, les correspondances successives avec une chaîne feront que "/g" passera d'une correspondance à l'autre, en suivant la position dans la chaîne. Vous pouvez obtenir ou définir la position avec la fonction pos(). Par exemple,

$x = "chat chien maison"; # 3 mots
while ($x =~ /(\w+)/g) {
    print "Mot est $1, se termine à la position ", pos $x, "\n";
}

imprime

Mot est chat, se termine à la position 3
Mot est chien, se termine à la position 7
Mot est maison, se termine à la position 13

Une correspondance échouée ou la modification de la chaîne cible réinitialise la position. Si vous ne voulez pas que la position soit réinitialisée après un échec de correspondance, ajoutez "/c", comme dans "/regex/gc".

En contexte de liste, "/g" retourne une liste de groupements correspondants, ou s'il n'y a pas de groupements, une liste de correspondances à l'expression régulière entière. Donc

@mots = ($x =~ /(\w+)/g);  # correspond,
                            # $mot[0] = 'chat'
                            # $mot[1] = 'chien'
                            # $mot[2] = 'maison'

DESCRIPTION

The substitution operator

The substitution operator is "s/regex/replacement/modifiers".

$x = "Time to feed the cat!";
$x =~ s/cat/hacker/;   # $x contains "Time to feed the hacker!"
$y = "'quoted words'";
$y =~ s/^'(.*)'$/$1/;  # strip single quotes,
                       # $y contains "quoted words"

With the "s///" operator, the matched variables $1, $2, etc. are immediately available for use in the replacement expression. With the global modifier, "s///g" will search and replace all occurrences of the regex in the string:

$x = "I batted 4 for 4";
$x =~ s/4/four/;   # $x contains "I batted four for 4"
$x = "I batted 4 for 4";
$x =~ s/4/four/g;  # $x contains "I batted four for four"

The non-destructive modifier "s///r" causes the result of the substitution to be returned instead of modifying $_ (or whatever variable the substitute was bound to with "=~"):

$x = "I like dogs.";
$y = $x =~ s/dogs/cats/r;
print "$x $y\n"; # prints "I like dogs. I like cats."
$x = "Cats are great.";
print $x =~ s/Cats/Dogs/r =~ s/Dogs/Frogs/r =~
    s/Frogs/Hedgehogs/r, "\n";
# prints "Hedgehogs are great."
@foo = map { s/[a-z]/X/r } qw(a b c 1 2 3);
# @foo is now qw(X X X 1 2 3)

The evaluation modifier "s///e" wraps an "eval{...}" around the replacement string and the evaluated result is substituted for the matched substring. Some examples:

# reverse all the words in a string
$x = "the cat in the hat";
$x =~ s/(\w+)/reverse $1/ge;   # $x contains "eht tac ni eht tah"
# convert percentage to decimal
$x = "A 39% hit rate";
$x =~ s!(\d+)%!$1/100!e;       # $x contains "A 0.39 hit rate"

The last example shows that "s///" can use other delimiters, such as "s!!!" and "s{}{}", and even "s{}//". If single quotes are used "s'''", then the regex and replacement are treated as single-quoted strings.

The split operator

"split /regex/, string" splits "string" into a list of substrings and returns that list. The regex determines the character sequence that "string" is split with respect to. For example, to split a string into words, use

$x = "Calvin and Hobbes";
@word = split /\s+/, $x;  # $word[0] = 'Calvin'
                          # $word[1] = 'and'
                          # $word[2] = 'Hobbes'

To extract a comma-delimited list of numbers, use

$x = "1.618,2.718,   3.142";
@const = split /,\s*/, $x;  # $const[0] = '1.618'
                            # $const[1] = '2.718'
                            # $const[2] = '3.142'

If the empty regex "//" is used, the string is split into individual characters. If the regex has groupings, then the list produced contains the matched substrings from the groupings as well:

$x = "/usr/bin";
@parts = split m!(/)!, $x;  # $parts[0] = ''
                            # $parts[1] = '/'
                            # $parts[2] = 'usr'
                            # $parts[3] = '/'
                            # $parts[4] = 'bin'

Since the first character of $x matched the regex, "split" prepended an empty initial element to the list.
