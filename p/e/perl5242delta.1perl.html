PERL5242DELTA(1perl) Guide de référence du programmeur Perl PERL5242DELTA(1perl)

NOM

perl5242delta - ce qu'il y a de nouveau pour la version perl v5.24.2

DESCRIPTION

Ce document décrit les différences entre la version 5.24.1 et la version 5.24.2.

Si vous mettez à niveau depuis une version antérieure comme la 5.24.0, lisez d'abord perl5241delta, qui décrit les différences entre la 5.24.0 et la 5.24.1.

Sécurité

Gestion améliorée de '.' dans @INC de base.pm

La gestion (la suppression) de '.' dans @INC dans base a été améliorée. Cela résout certains comportements problématiques de l'approche adoptée dans Perl 5.24.1, qui est probablement mieux décrite dans les deux fils de discussion suivants sur la liste de diffusion Perl 5 Porters : http://www.nntp.perl.org/group/perl.perl5.porters/2016/08/msg238991.html, http://www.nntp.perl.org/group/perl.perl5.porters/2016/10/msg240297.html.

Deux-points "échappés" et chemins relatifs dans PATH

Sur les systèmes Unix, Perl considère tout chemin relatif dans la variable d'environnement PATH comme "tainted" (contaminé) lors du démarrage d'un nouveau processus. Auparavant, il permettait à une barre oblique inverse d'échapper à un deux-points (contrairement au système d'exploitation), permettant ainsi aux chemins relatifs d'être considérés comme sûrs si le PATH était défini sur quelque chose comme "/\:.". La vérification a été corrigée pour considérer "." comme "tainted" dans cet exemple.

Modules et Pragmata mis à jour

  • Module::CoreList a été mis à jour de la version 5.20170114_24 à 5.20170715_24.

Remerciements

Perl 5.24.2 représente environ 6 mois de développement depuis Perl 5.24.1 et contient environ 2 500 lignes de changements répartis sur 53 fichiers et 18 auteurs.

En excluant les fichiers générés automatiquement, la documentation et les outils de publication, il y a eu environ 960 lignes de changements dans 17 fichiers .pm, .t, .c et .h.

Perl continue de s'épanouir dans sa troisième décennie grâce à une communauté dynamique d'utilisateurs et de développeurs. Les personnes suivantes sont connues pour avoir contribué aux améliorations qui sont devenues Perl 5.24.2 :

Aaron Crane, Abigail, Aristotle Pagaltzis, Chris 'BinGOs' Williams, Dan Collins, David Mitchell, Eric Herman, Father Chrysostomos, James E Keenan, Karl Williamson, Lukas Mai, Renee Baecker, Ricardo Signes, Sawyer X, Stevan Little, Steve Hay, Tony Cook, Yves Orton.

La liste ci-dessus est presque certainement incomplète car elle est générée automatiquement à partir de l'historique du contrôle de version. En particulier, elle n'inclut pas les noms des contributeurs (très appréciés) qui ont signalé des problèmes au système de suivi des bugs de Perl.

Beaucoup des changements inclus dans cette version proviennent des modules CPAN inclus dans le cœur de Perl. Nous sommes reconnaissants envers toute la communauté CPAN d'avoir aidé Perl à prospérer.

Pour une liste plus complète de tous les contributeurs historiques de Perl, veuillez consulter le fichier AUTHORS dans la distribution source de Perl.

Signalement de bugs

Si vous trouvez ce qui vous semble être un bug, vous pourriez consulter les articles récemment postés dans le groupe de discussion comp.lang.perl.misc et la base de données des bugs de Perl sur https://rt.perl.org/. Il peut également y avoir des informations sur http://www.perl.org/, la page d'accueil de Perl.

Si vous pensez avoir un bug non signalé, veuillez exécuter le programme perlbug inclus avec votre version. Assurez-vous de réduire votre bug à un cas de test minimal mais suffisant. Votre rapport de bug, ainsi que la sortie de "perl -V", seront envoyés à perlbug@perl.org pour être analysés par l'équipe de portage de Perl.

Si le bug que vous signalez a des implications de sécurité qui le rendent inapproprié à envoyer à une liste de diffusion archivée publiquement, alors consultez la section "SECURITY VULNERABILITY CONTACT INFORMATION" dans perlsec pour plus de détails sur la façon de signaler le problème.
