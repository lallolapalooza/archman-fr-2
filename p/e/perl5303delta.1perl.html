NOM

perl5303delta - nouveautés de la version Perl v5.30.3

DESCRIPTION

Ce document décrit les différences entre la version 5.30.2 et la version 5.30.3.

Si vous mettez à jour à partir d'une version antérieure comme la 5.30.1, lisez d'abord perl5302delta, qui décrit les différences entre les versions 5.30.1 et 5.30.2.

Sécurité

[CVE-2020-10543] Dépassement de tampon causé par une expression régulière spécialement conçue

Un dépassement de capacité de l'entier signé "size_t" dans les calculs d'espace de stockage pour les quantificateurs d'expressions régulières imbriquées pourrait causer un dépassement de tampon du tas dans le compilateur d'expressions régulières de Perl, écrasant la mémoire allouée après l'espace de stockage de l'expression régulière avec des données fournies par l'attaquant.

Le système cible nécessite une quantité de mémoire suffisante pour allouer des expansions partielles des quantificateurs imbriqués avant que le dépassement ne se produise. Cette exigence n'est probablement pas satisfaite sur les systèmes 64 bits.

Découvert par : ManhND de The Tarantula Team, VinCSS (membre de Vingroup).

[CVE-2020-10878] Dépassement d'entier via un bytecode malformé produit par une expression régulière spécialement conçue

Les dépassements d'entiers dans le calcul des décalages entre les instructions du moteur d'expressions régulières pourraient entraîner la corruption de l'état du langage intermédiaire d'une expression régulière compilée. Un attaquant pourrait abuser de ce comportement pour insérer des instructions dans la forme compilée d'une expression régulière Perl.

Découvert par : Hugo van der Sanden et Slaven Rezic.

[CVE-2020-12723] Dépassement de tampon causé par une expression régulière spécialement conçue

Les appels récursifs à S_study_chunk() par le compilateur d'expressions régulières de Perl pour optimiser la représentation du langage intermédiaire d'une expression régulière pourraient entraîner la corruption de l'état du langage intermédiaire d'une expression régulière compilée.

Découvert par : Sergey Aleynikov.

Note additionnelle

Une application écrite en Perl ne serait vulnérable à aucune des failles ci-dessus que si elle évalue des expressions régulières fournies par l'attaquant. L'évaluation d'expressions régulières de cette manière est connue pour être dangereuse, car le moteur d'expressions régulières ne protège pas contre les attaques par déni de service dans ce scénario d'utilisation.

Remerciements

Perl 5.30.3 représente environ 3 mois de développement depuis Perl 5.30.2 et contient environ 1 100 lignes de changements dans 42 fichiers de 7 auteurs.

En excluant les fichiers auto-générés, la documentation et les outils de publication, il y a eu environ 350 lignes de changements dans 8 fichiers .pm, .t, .c et .h.

Perl continue de prospérer dans sa quatrième décennie grâce à une communauté dynamique d'utilisateurs et de développeurs. Les personnes suivantes sont connues pour avoir contribué aux améliorations apportées à Perl 5.30.3 :

Signalement de bugs

Si vous trouvez ce qui vous semble être un bug, vous pouvez consulter la base de données des bugs de Perl à l'adresse https://github.com/Perl/perl5/issues. Vous pourrez également trouver des informations sur https://www.perl.org/, la page d'accueil de Perl.

Si vous pensez avoir un bug non signalé, veuillez ouvrir un ticket sur https://github.com/Perl/perl5/issues. Assurez-vous de réduire votre bug à un exemple de test minimal mais suffisant.

Si le bug que vous signalez a des implications de sécurité qui le rendent inapproprié à envoyer à un traqueur de problèmes public, consultez "INFORMATIONS DE CONTACT POUR LES VULNÉRABILITÉS DE SÉCURITÉ" dans perlsec pour connaître les détails de la manière de signaler le problème.

Faire des remerciements

Si vous souhaitez remercier les Perl 5 Porters pour le travail que nous avons accompli dans Perl 5, vous pouvez le faire en exécutant le programme "perlthanks" :

perlthanks

Cela enverra un e-mail à la liste Perl 5 Porters avec votre message de remerciement.
