perfmonctl(2) Manuel des appels système perfmonctl(2)

NOM

perfmonctl - interface de l'unité de surveillance des performances IA-64

SYNTAXE

#include <syscall.h>
#include <perfmon.h>
long perfmonctl(int narg;
                int fd, int cmd, void arg[narg], int narg);

Note : Il n'existe pas d'enveloppe glibc pour cet appel système ; voir HISTORIQUE.

DESCRIPTION

L'appel système perfmonctl() spécifique à IA-64 fournit une interface à l'unité de surveillance des performances (PMU - performance monitoring unit). La PMU est composée des registres de données de surveillance des performances (PMD - performance monitoring data) et des registres de contrôle des performances (PMC - performance monitoring control), qui collectent des statistiques matérielles.

perfmonctl() applique l'opération cmd aux arguments d'entrée spécifiés par arg. Le nombre d'arguments est défini par narg. L'argument fd spécifie le contexte perfmon sur lequel opérer.

Les valeurs prises en charge pour cmd sont :

PFM_CREATE_CONTEXT
perfmonctl(int fd, PFM_CREATE_CONTEXT, pfarg_context_t *ctxt, 1);
Configuration d'un contexte.
Le paramètre fd est ignoré. Un nouveau contexte perfmon est créé comme spécifié dans ctxt et son descripteur de fichier est retourné dans ctxt->ctx_fd.
Le descripteur de fichier peut être utilisé dans les appels ultérieurs à perfmonctl() et peut être utilisé pour lire des notifications d'événements (type pfm_msg_t) à l'aide de read(2). Le descripteur de fichier est interrogable à l'aide de select(2), poll(2) et epoll(7).
Le contexte peut être détruit en appelant close(2) sur le descripteur de fichier.
PFM_WRITE_PMCS
perfmonctl(int fd, PFM_WRITE_PMCS, pfarg_reg_t *pmcs, n);
Définir les registres PMC.
PFM_WRITE_PMDS
perfmonctl(int fd, PFM_WRITE_PMDS, pfarg_reg_t *pmds, n);
Définir les registres PMD.
PFM_READ_PMDS
perfmonctl(int fd, PFM_READ_PMDS, pfarg_reg_t *pmds, n);
Lire les registres PMD.
PFM_START
perfmonctl(int fd, PFM_START, NULL, 0);
Démarrer la surveillance.
PFM_STOP
perfmonctl(int fd, PFM_STOP, NULL, 0);
Arrêter la surveillance.
PFM_LOAD_CONTEXT
perfmonctl(int fd, PFM_LOAD_CONTEXT, pfarg_load_t *largs, 1);
Attacher le contexte à un thread.
PFM_UNLOAD_CONTEXT
perfmonctl(int fd, PFM_UNLOAD_CONTEXT, NULL, 0);
Détacher le contexte d'un thread.
PFM_RESTART
perfmonctl(int fd, PFM_RESTART, NULL, 0);
Redémarrer la surveillance après avoir reçu une notification de débordement.
PFM_GET_FEATURES
perfmonctl(int fd, PFM_GET_FEATURES, pfarg_features_t *arg, 1);
PFM_DEBUG
perfmonctl(int fd, PFM_DEBUG, val, 0);
Si val est non nul, activer le mode de débogage, sinon le désactiver.
PFM_GET_PMC_RESET_VAL
perfmonctl(int fd, PFM_GET_PMC_RESET_VAL, pfarg_reg_t *req, n);
Réinitialiser les registres PMC aux valeurs par défaut.

VALEUR RETOURNEE

perfmonctl() retourne zéro lorsque l'opération réussit. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

NORMES

Linux sur IA-64.

HISTORIQUE

Ajouté dans Linux 2.4 ; supprimé dans Linux 5.10.

Cet appel système a été défectueux pendant de nombreuses années et a finalement été supprimé dans Linux 5.10.

glibc ne fournit pas d'enveloppe pour cet appel système ; sur les noyaux où il existe, appelez-le en utilisant syscall(2).
