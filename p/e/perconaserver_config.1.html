Paquet: libperconaserverclient

MYSQL_CONFIG(1) Système de base de données MySQL MYSQL_CONFIG(1)

NOM

mysql_config - afficher les options pour la compilation des clients

SYNTAXE

mysql_config options

DESCRIPTION

mysql_config vous fournit des informations utiles pour compiler votre client MySQL et le connecter à MySQL. C'est un script shell, il n'est donc disponible que sur les systèmes Unix et similaires à Unix.


Note

pkg-config peut être utilisé comme alternative à mysql_config pour obtenir des informations telles que les drapeaux du compilateur ou les bibliothèques de liaison nécessaires pour compiler des applications MySQL. Pour plus d'informations, voir Construction de programmes clients de l'API C à l'aide de pkg-config[1].

mysql_config prend en charge les options suivantes.

•--cflags Drapeaux du compilateur C pour trouver les fichiers d'inclusion et les drapeaux et définitions critiques du compilateur utilisés lors de la compilation de la bibliothèque libmysqlclient. Les options retournées sont liées au compilateur spécifique utilisé lors de la création de la bibliothèque et pourraient entrer en conflit avec les paramètres de votre propre compilateur. Utilisez --include pour des options plus portables qui ne contiennent que des chemins d'inclusion.
•--cxxflags Comme --cflags, mais pour les drapeaux du compilateur C++.
•--include Options du compilateur pour trouver les fichiers d'inclusion MySQL.
•--libs Bibliothèques et options requises pour lier avec la bibliothèque client MySQL.
•--libs_r Bibliothèques et options requises pour lier avec la bibliothèque client MySQL thread-safe. Dans MySQL 8.4, toutes les bibliothèques client sont thread-safe, donc cette option n'a pas besoin d'être utilisée. L'option --libs peut être utilisée dans tous les cas.
•--plugindir Le nom du chemin du répertoire des plugins par défaut, défini lors de la configuration de MySQL.
•--port Le numéro de port TCP/IP par défaut, défini lors de la configuration de MySQL.
•--socket Le fichier de socket Unix par défaut, défini lors de la configuration de MySQL.
•--variable=nom_var Affiche la valeur de la variable de configuration nommée. Les valeurs de nom_var permises sont pkgincludedir (le répertoire des fichiers d'en-tête), pkglibdir (le répertoire des bibliothèques) et plugindir (le répertoire des plugins).
•--version Numéro de version de la distribution MySQL.

Si vous appelez mysql_config sans options, il affiche une liste de toutes les options qu'il prend en charge, et leurs valeurs :

$> mysql_config
Usage: ./mysql_config [OPTIONS]
Compiler: GNU 10.4.0
Options:
  --cflags         [-I/usr/local/mysql/include/mysql]
  --cxxflags       [-I/usr/local/mysql/include/mysql]
  --include        [-I/usr/local/mysql/include/mysql]
  --libs           [-L/usr/local/mysql/lib/mysql -lmysqlclient -lpthread -ldl  
                    -lssl  -lcrypto -lresolv -lm -lrt]
  --libs_r         [-L/usr/local/mysql/lib/mysql -lmysqlclient -lpthread -ldl  
                    -lssl  -lcrypto -lresolv -lm -lrt]
  --plugindir      [/usr/local/mysql/lib/plugin]
  --socket         [/tmp/mysql.sock]
  --port           [3306]
  --version        [8.4.0]
  --variable=VAR   VAR is one of:
          pkgincludedir [/usr/local/mysql/include]
          pkglibdir     [/usr/local/mysql/lib]
          plugindir     [/usr/local/mysql/lib/plugin]

Vous pouvez utiliser mysql_config dans une ligne de commande en utilisant des apostrophes inversées pour inclure la sortie qu'il produit pour des options particulières. Par exemple, pour compiler et lier un programme client MySQL, utilisez mysql_config comme suit :

gcc -c `mysql_config --cflags` progname.c
gcc -o progname progname.o `mysql_config --libs`
