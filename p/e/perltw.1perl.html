PERLTW(1perl) Guide de référence du programmeur Perl PERLTW(1perl)

NOM

perltw - Guide chinois traditionnel pour Perl

DESCRIPTION

Bienvenue au paradis de Perl !

Depuis la version 5.8.0, Perl prend en charge complètement Unicode (jeux de caractères universels), ainsi que de nombreux encodages de caractères en plus du jeu de caractères latin ; les caractères CJK (chinois, japonais, coréen) en font partie. Unicode est une norme internationale qui tente de couvrir tous les caractères du monde : langues occidentales, langues orientales et tout ce qui se trouve entre les deux (arabe, hébreu, alphasyllabaires, etc.). Elle inclut également de nombreux systèmes d'exploitation et plates-formes (comme le PC et le Macintosh).

Perl lui-même opère en interne avec Unicode. Cela signifie que les données de chaînes de caractères internes de Perl peuvent être représentées par Unicode ; les fonctions et opérateurs de Perl (comme les correspondances de patrons regex) peuvent également opérer sur Unicode. Lors de l'entrée et de la sortie, pour gérer les données stockées dans des encodages antérieurs à Unicode, Perl fournit le module Encode, qui vous permet de lire et d'écrire facilement des données encodées.

Le module Encode prend en charge les encodages de caractères chinois traditionnels suivants ('big5' représente 'big5-eten') :

big5-eten   Encodage Big5 (incluant les extensions Tian pour Big5)
big5-hkscs  Big5 + jeu de caractères étendus de Hong Kong, version 2001
cp950       Jeu de caractères 950 (Big5 + caractères ajoutés par Microsoft)

Par exemple, pour convertir un fichier encodé en Big5 en Unicode, vous devez taper la commande suivante :

perl -MEncode -pe '$_= encode( utf8 => decode( big5 => $_ ) )' \
  < file.big5 > file.utf8

Perl inclut également « piconv », un utilitaire de conversion de caractères entièrement écrit en Perl, utilisable comme suit :

piconv -f big5 -t utf8 < file.big5 > file.utf8
piconv -f utf8 -t big5 < file.utf8 > file.big5

De plus, si le code source du programme est stocké avec l'encodage utf8, en utilisant le module utf8, les chaînes et leurs opérations dans le programme seront traitées en tant que caractères et non en octets, comme illustré ci-dessous :

#!/usr/bin/env perl
use utf8;
print length("駱駝");      # 2 (pas 6)
print index("諄諄教誨", "教誨"); # 2 (commence à partir du 2ème caractère, index 0)

Informations supplémentaires sur l'encodage chinois

Si vous avez besoin de plus d'encodages chinois, vous pouvez télécharger le module Encode::HanExtra depuis CPAN (https://www.cpan.org/). Il prend actuellement en charge les encodages suivants :

cccii       Code d'échange d'informations chinois de la conférence de 1980
euc-tw      Jeu de caractères étendu Unix, incluant les plans 1-7 de CNS11643
big5plus    La base de promotion de la technologie de numérisation chinoise Big5+
big5ext     La base de promotion de la technologie de numérisation chinoise Big5e

En outre, le module Encode::HanConvert fournit deux encodages simplifiés pour la conversion :

big5-simp   Conversion bidirectionnelle entre le chinois traditionnel Big5 et le chinois simplifié Unicode
gbk-trad    Conversion bidirectionnelle entre le chinois simplifié GBK et le chinois traditionnel Unicode

Si vous souhaitez convertir entre GBK et Big5, consultez les deux programmes pl fournis dans le module, b2g.pl et g2b.pl, ou utilisez l'écriture suivante dans le programme :

use Encode::HanConvert;
$euc_cn = big5_to_gb($big5); # Convertit de Big5 en GBK
$big5 = gb_to_big5($euc_cn); # Convertit de GBK en Big5

NOM

perltw - un système de traduction automatique des pages de manuel dans d'autres langues.

DESCRIPTION

Le système perltw est une collection de scripts et de fichiers de données qui facilitent la traduction des pages de manuel dans différentes langues. Il est utilisé par le projet Arch Linux pour fournir des versions traduites des pages de manuel en plus de la version anglaise originale.

Ce script particulier, perltw, est l'un des composants de ce système. Son rôle spécifique est lié au processus de traduction des pages de manuel Perl.

VOIR AUSSI

Pour plus d'informations sur le fonctionnement du système perltw et sur la manière de contribuer aux traductions, veuillez consulter la documentation pertinente sur le site web d'Arch Linux ou les listes de diffusion.

L'adresse e-mail du mainteneur est audreyt@audreyt.org.
