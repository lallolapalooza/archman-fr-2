PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

perror — écrire des messages d'erreur sur la sortie d'erreur standard

SYNTAXE

#include <stdio.h>
void perror(const char *s);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

La fonction perror() doit mapper le numéro d'erreur accessible via le symbole errno à un message d'erreur dépendant de la langue, qui doit être écrit sur le flux d'erreur standard comme suit :

*
D'abord (si s n'est pas un pointeur nul et que le caractère pointé par s n'est pas l'octet nul), la chaîne pointée par s suivie d'un <deux-points> et d'un <espace>.
*
Ensuite, une chaîne de message d'erreur suivie d'un <nouvelle ligne>.

Le contenu des chaînes de message d'erreur doit être le même que celui renvoyé par strerror() avec l'argument errno.

La fonction perror() doit marquer pour mise à jour les horodatages de dernière modification des données et de dernier changement d'état de fichier du fichier associé au flux d'erreur standard à un moment donné entre son achèvement réussi et exit(), abort(), ou l'achèvement de fflush() ou fclose() sur stderr.

La fonction perror() ne doit pas modifier l'orientation du flux d'erreur standard.

En cas d'erreur, perror() doit définir l'indicateur d'erreur pour le flux auquel stderr pointe, et doit définir errno pour indiquer l'erreur.

Puisqu'aucune valeur n'est renvoyée, une application souhaitant vérifier les situations d'erreur doit appeler clearerr(stderr) avant d'appeler perror(), puis si ferror(stderr) renvoie une valeur non nulle, la valeur de errno indique quelle erreur s'est produite.

VALEUR RENVOYÉE

La fonction perror() ne doit pas renvoyer de valeur.

ERREURS

Se référer à fputc().

Les sections suivantes sont informatives.

EXEMPLES

Impression d'un message d'erreur pour une fonction

L'exemple suivant remplace bufptr par un tampon de taille nécessaire. Si une erreur se produit, la fonction perror() imprime un message et le programme se termine.

#include <stdio.h>
#include <stdlib.h>
...
char *bufptr;
size_t szbuf;
...
if ((bufptr = malloc(szbuf)) == NULL) {
    perror("malloc"); exit(2);
}
...

UTILISATION PAR L'APPLICATION

Les auteurs d'applications peuvent préférer utiliser des interfaces alternatives à perror(), telles que strerror_r() en combinaison avec fprintf().
