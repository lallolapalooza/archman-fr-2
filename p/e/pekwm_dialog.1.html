NOM

pekwm_dialog - une application de dialogue inspirée de xmessage

SYNTAXE

pekwm_dialog [--display] message

DESCRIPTION

pekwm_dialog présente une boîte de dialogue simple avec un titre, une image, un message texte et un bouton pour chaque option spécifiée. Si aucune option n'est spécifiée, la boîte de dialogue aura un bouton Ok.

L'appelant peut identifier quelle option a été sélectionnée en vérifiant le code de sortie de l'application. La première option sortira avec le code de statut 0, la suivante avec 1, et ainsi de suite.

Compte tenu de ce comportement, il est recommandé d'avoir "ok" comme première option, puis "cancel" comme seconde, suivies des autres options. Ceci correspond au code de sortie standard 0 pour "ok", et "cancel" donnerait le même code de sortie qu'en cas d'erreur.

L'illustration ci-dessous représente la disposition des éléments de la boîte de dialogue :

--------------------------------------------
| TITRE                                    |
--------------------------------------------
|                                          |
| L'image, le cas échéant, est affichée ici |
|                                          |
--------------------------------------------
| Le texte du message va ici               |
|                                          |
--------------------------------------------
|           [Option1] [Option2]            |
--------------------------------------------

OPTIONS

--help Afficher les informations d'aide.

--display DISPLAY Se connecter à DISPLAY au lieu de DISPLAY défini dans l'environnement.

--geometry GEOMETRY Géométrie de la fenêtre, par défaut 200x50 s'étendant pour la taille de l'image.

--image IMAGE Chemin vers l'image à afficher.

--option STRING Titre de l'option, plusieurs options sont prises en charge.

--title STRING Chaîne de titre.
