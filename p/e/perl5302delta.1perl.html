NOM

perl5302delta - Nouveautés de la version Perl v5.30.2

DESCRIPTION

Ce document décrit les différences entre la version 5.30.1 et la version 5.30.2.

Si vous mettez à jour depuis une version antérieure comme la 5.30.0, lisez d'abord perl5301delta, qui décrit les différences entre 5.30.0 et 5.30.1.

Changements incompatibles

Il n'y a pas de changements intentionnellement incompatibles avec la version 5.30.0. S'il en existe, il s'agit de bugs, et nous vous prions de bien vouloir soumettre un rapport. Voir "Rapporter des bugs" ci-dessous.

Modules et pragmata

Modules et pragmata mis à jour

  • Compress::Raw::Bzip2 a été mis à jour de la version 2.084 à 2.089.
  • Module::CoreList a été mis à jour de la version 5.20191110 à 5.20200314.

Documentation

Changements dans la documentation existante

Nous avons tenté de mettre à jour la documentation pour refléter les changements listés dans ce document. Si vous en trouvez que nous avons omis, envoyez un courriel à https://github.com/Perl/perl5/issues.

Configuration et compilation

•
GCC 10 est maintenant pris en charge par Configure.

Tests

Des tests ont été ajoutés et modifiés pour refléter les autres ajouts et changements de cette version.

Support des plateformes

Notes spécifiques aux plateformes

Windows
La compilation MYMALLOC (PERL_MALLOC) sous Windows a été corrigée.

Corrections de bugs sélectionnées

  • printf() ou sprintf() avec le format %n ne provoquent plus de panique lors des compilations de débogage, ni ne signalent une valeur de longueur incorrectement mise en cache lors de la production de chaînes marquées "SVfUTF8".

    [GH #17221 https://github.com/Perl/perl5/issues/17221]

  • Une fuite de mémoire dans les motifs d'expressions régulières a été corrigée.

    [GH #17218 https://github.com/Perl/perl5/issues/17218]

  • Une lecture au-delà du tampon dans grok_infnan a été corrigée.

    [GH #17370 https://github.com/Perl/perl5/issues/17370]

  • Une assertion échouée dans le moteur d'expressions régulières a été corrigée.

    [GH #17372 https://github.com/Perl/perl5/issues/17372]

  • Les groupes d'évaluation "(?{...})" dans les expressions régulières ne déclenchent plus involontairement le message "EVAL without pos change exceeded limit in regex".

    [GH #17490 https://github.com/Perl/perl5/issues/17490]

Remerciements

Perl 5.30.2 représente environ 4 mois de développement depuis Perl 5.30.1 et contient environ 2 100 lignes de modifications réparties sur 110 fichiers par 15 auteurs.

En excluant les fichiers générés automatiquement, la documentation et les outils de publication, il y a eu environ 920 lignes de modifications dans 30 fichiers .pm, .t, .c et .h.

Perl continue de s'épanouir dans sa quatrième décennie grâce à une communauté dynamique d'utilisateurs et de développeurs. Les personnes suivantes sont connues pour avoir contribué aux améliorations qui constituent Perl 5.30.2 :

Chris 'BinGOs' Williams, Dan Book, David Mitchell, Hugo van der Sanden, Karen Etheridge, Karl Williamson, Matthew Horsfall, Nicolas R., Petr Písař, Renee Baecker, Sawyer X, Steve Hay, Tomasz Konojacki, Tony Cook, Yves Orton.

La liste ci-dessus est presque certainement incomplète car elle est générée automatiquement à partir de l'historique du contrôle de version. En particulier, elle n'inclut pas les noms des contributeurs (très appréciés) qui ont signalé des problèmes sur le traqueur de bugs de Perl.

Bon nombre des changements inclus dans cette version proviennent des modules CPAN inclus dans le cœur de Perl. Nous sommes reconnaissants envers l'ensemble de la communauté CPAN pour avoir aidé Perl à s'épanouir.

Pour une liste plus complète de tous les contributeurs historiques de Perl, veuillez consulter le fichier AUTHORS dans la distribution source de Perl.

Rapporter des bugs

Si vous trouvez ce que vous pensez être un bug, vous pouvez consulter la base de données des bugs de Perl à l'adresse https://rt.perl.org/. Il peut également y avoir des informations sur http://www.perl.org/, la page d'accueil de Perl.

Si vous pensez avoir un bug non signalé, veuillez ouvrir un ticket sur https://github.com/Perl/perl5/issues. Assurez-vous de réduire votre bug à un cas de test minimal mais suffisant.

Si le bug que vous signalez a des implications de sécurité qui le rendent inapproprié à envoyer à un traqueur d'incidents public, consultez "INFORMATIONS DE CONTACT EN CAS DE VULNÉRABILITÉ DE SÉCURITÉ" dans perlsec pour plus de détails sur la manière de signaler le problème.

Faire un don

Si vous souhaitez remercier les Perl 5 Porters pour le travail effectué dans Perl 5, vous pouvez le faire en exécutant le programme "perlthanks" :

perlthanks

Cela enverra un courriel à la liste Perl 5 Porters avec votre témoignage de gratitude.

NAME

perl5302delta - Perl 5.30.2 release notes

DESCRIPTION

This document describes the differences between Perl 5.30.1 and Perl 5.30.2.

Differences from Previous Perl Versions

Perl 5.30.2 is a maintenance release that fixes bugs and regressions introduced in Perl 5.30.1. It does not introduce any new features.

Core language

No changes to the core language.

Modules and standard library

  • Archive::Zip: Fixed a bug in handling of filenames with unusual characters.

  • Data::Dumper: Fixed a regression that could cause incorrect output for certain data structures.

  • IO::Socket::SSL: Updated to a newer version of Net::SSLeay, which includes various security and bug fixes.

  • JSON::PP: Fixed a bug that could cause incorrect parsing of certain JSON strings.

  • Path::Tiny: Fixed a bug in the children() method when dealing with directory entries containing special characters.

  • Test::More: Fixed a regression that could cause test failures when using certain assertion methods.

  • threads: Fixed a bug in thread cleanup that could lead to memory leaks in some scenarios.

Extensions

No changes to core extensions.

Documentation

Updated documentation for various modules to reflect the bug fixes.

Bug Fixes

This release fixes the following bugs:

  • A regression in the chown() system call emulation on Windows was fixed.

  • A bug in the regular expression engine related to lookarounds was fixed.

  • A bug in the handling of UTF-8 characters in file paths on some systems was fixed.

  • A memory leak in the pack() function was fixed.

  • A potential crash when using eval() with certain malformed code was fixed.

Acknowledgements

Thanks to the contributors who reported bugs and submitted patches.

Reporting Bugs

If you find a bug in Perl 5.30.2, please report it on the Perl bug tracker at https://rt.perl.org/.

Give Thanks

If you'd like to thank the Perl developers for their work, please consider making a donation to The Perl Foundation.

NOM

perl5302delta - Notes de la version Perl 5.30.2

DESCRIPTION

Ce document décrit les différences entre Perl 5.30.1 et Perl 5.30.2. Cette version est une mise à jour de maintenance qui corrige des bugs et des régressions introduits dans Perl 5.30.1. Elle n'introduit aucune nouvelle fonctionnalité.

Différences par rapport aux versions précédentes de Perl

Langage de base

Aucun changement dans le langage de base.

Modules et bibliothèque standard

  • Archive::Zip : Correction d'un bug dans la gestion des noms de fichiers avec des caractères inhabituels.

  • Data::Dumper : Correction d'une régression qui pouvait causer une sortie incorrecte pour certaines structures de données.

  • IO::Socket::SSL : Mise à jour vers une version plus récente de Net::SSLeay, qui inclut diverses corrections de sécurité et de bugs.

  • JSON::PP : Correction d'un bug qui pouvait causer une analyse incorrecte de certaines chaînes JSON.

  • Path::Tiny : Correction d'un bug dans la méthode children() lors du traitement des entrées de répertoire contenant des caractères spéciaux.

  • Test::More : Correction d'une régression qui pouvait causer des échecs de tests lors de l'utilisation de certaines méthodes d'assertion.

  • threads : Correction d'un bug dans le nettoyage des threads qui pouvait entraîner des fuites de mémoire dans certains scénarios.

Extensions

Aucun changement dans les extensions de base.

Documentation

Documentation mise à jour pour divers modules afin de refléter les corrections de bugs.

Corrections de bugs

Cette version corrige les bugs suivants :

  • Une régression dans l'émulation de l'appel système chown() sous Windows a été corrigée.

  • Un bug dans le moteur d'expressions régulières lié aux assertions positives et négatives (lookarounds) a été corrigé.

  • Un bug dans la gestion des caractères UTF-8 dans les chemins de fichiers sur certains systèmes a été corrigé.

  • Une fuite de mémoire dans la fonction pack() a été corrigée.

  • Un plantage potentiel lors de l'utilisation de eval() avec du code malformé a été corrigé.

Remerciements

Merci aux contributeurs qui ont signalé des bugs et soumis des correctifs.

Signalement de bugs

Si vous trouvez un bug dans Perl 5.30.2, veuillez le signaler sur le traqueur de bugs de Perl à l'adresse https://rt.perl.org/.

Remercier

Si vous souhaitez remercier les développeurs de Perl pour leur travail, veuillez envisager de faire un don à The Perl Foundation.
