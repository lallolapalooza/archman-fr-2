PERL5121DELTA(1perl) Guide de référence pour les programmeurs Perl PERL5121DELTA(1perl)

NOM

perl5121delta - ce qu'il y a de nouveau pour la version Perl v5.12.1

DESCRIPTION

Ce document décrit les différences entre la version 5.12.0 et la version 5.12.1.

Si vous effectuez une mise à niveau à partir d'une version antérieure telle que la 5.10.1, lisez d'abord perl5120delta, qui décrit les différences entre les versions 5.10.0 et 5.12.0.

CHANGEMENTS INCOMPATIBLES

Aucun changement n'est intentionnellement incompatible avec la version 5.12.0. S'il existe des incompatibilités avec la version 5.12.0, il s'agit de bugs. Veuillez les signaler.

AMÉLIORATIONS DU CŒUR

Outre les corrections de bugs énumérées ci-dessous, il ne devrait y avoir aucun changement visible par l'utilisateur dans le langage principal de cette version.

MODULES ET PRAGMATES

CHANGEMENTS DES PRAGMATES

•
Nous avons corrigé l'exportation de "is_strict" et "is_lax" depuis la version.

Ils étaient exportés avec un wrapper qui les traitait comme des appels de méthode, ce qui les faisait échouer. Ce sont juste des fonctions, elles sont documentées comme telles, et ne devraient jamais être sous-classées, donc ce correctif les exporte simplement directement en tant que fonctions sans le wrapper.

MODULES MIS À JOUR

  • Nous avons mis à jour CGI vers la version 3.49 pour intégrer des correctifs pour les régressions introduites dans la version que nous avons fournie avec Perl 5.12.0.
  • Nous avons mis à jour Pod::Simple vers la version 3.14 pour bénéficier d'une amélioration de l'analyse des \C\<\>.
  • Nous avons apporté une petite correction à la suite de tests de CPANPLUS pour résoudre un échec de test occasionnel et fantaisiste.
  • Nous avons mis à jour Safe vers la version 2.27 pour encapsuler les coderefs retournés par reval() et rdo().

CHANGEMENTS DANS LA DOCUMENTATION EXISTANTE

  • Nous avons ajouté la nouvelle politique de publication de maintenance à perlpolicy.
  • Nous avons clarifié la construction à crochets multiples dans la spécification pour POD dans perlpodspec.
  • Nous avons ajouté une explication manquante pour un avertissement sur ":=" à perldiag.
  • Nous avons supprimé une affirmation fausse dans perlunitut selon laquelle toutes les chaînes de caractères sont des chaînes Unicode en Perl.
  • Nous avons mis à jour le lien du miroir GitHub dans perlrepository vers mirrors/perl, et non github/perl.
  • Nous avons corrigé une erreur mineure dans perl5114delta.
  • Nous avons remplacé une mention du désormais obsolète Switch par given/when.
  • Nous avons amélioré la documentation concernant $sitelibexp/sitecustomize.pl dans perlrun.
  • Nous avons corrigé perlmodlib qui avait involontairement omis un certain nombre de modules.
  • Nous avons mis à jour la documentation pour 'require' dans perlfunc concernant l'insertion de code Perl dans @INC.
  • Nous avons rétabli une partie de la documentation sur quotemeta dans perlfunc, qui avait été supprimée par erreur.
  • Nous avons corrigé un exemple d'a2p dans perlutil.
  • Nous avons rempli un blanc dans perlport avec la date de publication de Perl 5.12.
  • Nous avons corrigé des liens brisés dans un certain nombre de fichiers perldelta.
  • La documentation de Carp indiquait incorrectement que la variable $Carp::Verbose faisait générer des traces de pile à cluck.
  • Nous avons corrigé un certain nombre de fautes de frappe dans Pod::Functions.
  • Nous avons amélioré la documentation des fonctions de changement de casse dans perlfunc.
  • Nous avons corrigé perlgpl pour y inclure la version correcte de la licence publique générale GNU.

TESTS

AMÉLIORATIONS DES TESTS

  • t/op/sselect.t est maintenant moins susceptible de subir des fluctuations d'horloge lors des vérifications de temps sous Windows.

    Le temps de sleep() sous Win32 peut être arrondi à des multiples de l'intervalle d'horloge.

  • lib/blib.t et lib/locale.t : Corrections pour les échecs de tests sur Darwin/PPC.
  • perl5db.t : Correction pour les échecs de tests lorsque "Term::ReadLine::Gnu" est installé.

AMÉLIORATIONS INSTALLATION ET CONFIGURATION

AMÉLIORATIONS CONFIGURATION

•
Nous avons mis à jour INSTALL avec des notes sur la manière de gérer un dbm.h défectueux sur OpenSUSE (et potentiellement d'autres plateformes).

CORRECTIONS DE BOGUES

  • Un bug dans la manière dont nous traitons les opérations de test de fichier pouvait provoquer un segfault. Les tests de fichier ne s'attendent pas toujours à un op sur la pile, nous utilisons donc maintenant TOPs uniquement si nous sommes sûrs de ne pas faire un stat sur le descripteur de fichier _ . Ceci est indiqué par OPf_KIDS (comme vérifié dans ck_ftst).

    Voir aussi : https://github.com/Perl/perl5/issues/10335

  • Lors de la décompilation d'un op nextstate qui a à la fois un changement de package (par rapport au nextstate précédent) et une étiquette, la déclaration de package est maintenant émise en premier, car il est syntaxiquement impossible qu'une étiquette précède une déclaration de package.
  • XSUB.h redéfinit correctement fgets sous PERL_IMPLICIT_SYS.

    Voir aussi : http://rt.cpan.org/Public/Bug/Display.html?id=55049

  • utf8::is_utf8 respecte maintenant GMAGIC (par exemple $1).
  • Le code XS utilisant fputc() ou fputs() : sous Windows pouvait provoquer une erreur en raison de l'inversion de leurs arguments.

    Voir aussi : https://github.com/Perl/perl5/issues/10156

  • Nous avons corrigé un petit bug dans lex_stuff_pvn() qui provoquait des erreurs de syntaxe fantaisistes dans une situation obscure. Cela se produisait lorsque le stuffing était effectué sur la dernière ligne d'un fichier et que la ligne se terminait par une instruction sans point-virgule final.

    Voir aussi : https://github.com/Perl/perl5/issues/10273

  • Nous avons corrigé un bug qui faisait que les constructions \N{} suivies d'un seul . étaient analysées incorrectement.

    Voir aussi : https://github.com/Perl/perl5/issues/10367

  • Nous avons corrigé un bug qui faisait que when(scalar) sans argument n'était pas traité comme une erreur de syntaxe.

    Voir aussi : https://github.com/Perl/perl5/issues/10287

  • Nous avons corrigé une régression dans la gestion des étiquettes précédant immédiatement les évaluations de chaînes de caractères, introduite dans Perl 5.12.0.

    Voir aussi : https://github.com/Perl/perl5/issues/10301

  • Nous avons corrigé une régression dans la correspondance insensible à la casse des caractères pliés dans les expressions régulières, introduite dans Perl 5.10.1.

    Voir aussi : https://github.com/Perl/perl5/issues/10193

NOTES SPÉCIFIQUES À LA PLATEFORME

HP-UX

•
Perl autorise maintenant -Duse64bitint sans promouvoir en use64bitall sur HP-UX.

AIX

•
Perl se compile maintenant sur AIX 4.2.

Les modifications ont nécessité de contourner le manque de prise en charge d'IPv6 par AIX 4.2 et le support limité de sigaction() POSIX.

FreeBSD 7

•
FreeBSD 7 ne contient plus de
/usr/bin/objformat. Au moment de la compilation, Perl saute désormais la vérification d'objformat pour les versions 7 et supérieures et suppose ELF.

VMS

  • Il est désormais possible de construire des extensions sur d'anciens systèmes VMS (antérieurs à 7.3-2).

    La longueur des symboles DCL était limitée à 1 Ko jusqu'à il y a environ sept ans, mais il n'y avait pas de raison particulièrement profonde d'empêcher ces anciens systèmes de configurer et de construire Perl.

  • Nous avons corrigé la construction "-Uuseperlio" précédemment défectueuse sur VMS.

    Nous vérifiions une variable qui n'existe pas dans le cas non par défaut de désactivation de perlio. Nous ne la regardons désormais que lorsqu'elle existe.

  • Nous avons corrigé l'option de ligne de commande -Uuseperlio dans configure.com.

    Auparavant, elle ne fonctionnait que si vous passiez en revue toutes les questions interactivement et répondiez explicitement non.

Problèmes Connus

  • "List::Util::first" se comporte mal en présence d'une variable lexicale $_ (généralement introduite par "my $_" ou implicitement par "given"). La variable qui est définie pour chaque itération est la variable de paquet $_, et non la variable lexicale $_.

    Un problème similaire peut survenir dans d'autres modules qui fournissent des fonctions qui prennent un bloc comme premier argument, comme

    foo { ... $_ ...} list

    Voir aussi : https://github.com/Perl/perl5/issues/9798

  • "Module::Load::Conditional" et "version" ont une interaction malheureuse qui peut provoquer le crash de "CPANPLUS" lorsqu'il rencontre une chaîne de version non analysable. La mise à niveau vers "CPANPLUS" 0.9004 ou "Module::Load::Conditional" 0.38 depuis CPAN résoudra ce problème.

Rapports de Bugs

Si vous trouvez ce que vous pensez être un bug, vous pourriez consulter les articles récemment publiés sur le groupe de discussion comp.lang.perl.misc et la base de données des bugs Perl à l'adresse http://rt.perl.org/perlbug/ . Il peut également y avoir des informations sur http://www.perl.org/ , la page d'accueil de Perl.

Si vous pensez avoir un bug non signalé, veuillez exécuter le programme perlbug inclus dans votre version. Assurez-vous de réduire votre bug à un cas de test minuscule mais suffisant. Votre rapport de bug, ainsi que la sortie de "perl -V", seront envoyés à perlbug@perl.org pour être analysés par l'équipe de portage Perl.

Si le bug que vous signalez a des implications de sécurité, qui le rendent inapproprié à envoyer à une liste de diffusion archivée publiquement, veuillez l'envoyer à perl5-security-report@perl.org. Ceci pointe vers une liste de diffusion non archivée avec abonnement fermé, qui inclut tous les principaux contributeurs, qui pourront aider à évaluer l'impact des problèmes, trouver une solution et aider à coordonner la publication de correctifs pour atténuer ou résoudre le problème sur toutes les plateformes sur lesquelles Perl est pris en charge. Veuillez n'utiliser cette adresse que pour les problèmes de sécurité dans le cœur de Perl, pas pour les modules distribués indépendamment sur CPAN.
