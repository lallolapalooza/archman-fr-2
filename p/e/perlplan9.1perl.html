PERLPLAN9(1perl) Guide du programmeur Perl PERLPLAN9(1perl)

NOM

perlplan9 - Documentation spécifique à Plan 9 pour Perl

DESCRIPTION

Voici quelques notes décrivant les fonctionnalités propres à Perl sur Plan 9. À ce titre, il n'est pas destiné à remplacer le reste de la documentation Perl 5 (qui est à la fois abondante et excellente). Si vous avez des questions auxquelles vous ne trouvez pas de réponses dans ces pages man, contactez Luther Huffman à lutherh@stratcom.com et nous essaierons d'y répondre.

Invocation de Perl

Perl est invoqué depuis la ligne de commande comme décrit dans perl. La plupart des scripts perl, cependant, ont une première ligne telle que "#!/usr/local/bin/perl". C'est ce qu'on appelle une déclaration shebang (shell-bang) et elle indique au shell du système d'exploitation où trouver l'interpréteur perl. Dans Perl pour Plan 9, cette déclaration doit être "#!/bin/perl" si vous souhaitez pouvoir invoquer directement le script par son nom.
Alternativement, vous pouvez invoquer perl avec la commande "Perl" au lieu de "perl". Cela produira des messages d'erreur conviviaux de type Acme, du genre "nom_fichier:18".

Certains scripts, généralement identifiés par une extension *.PL, sont auto-configurants et capables de créer correctement leur propre chemin shebang à partir d'informations de configuration situées dans Perl pour Plan 9. Ceux-ci ne vous poseront aucun souci.

Ce qu'il y a dans Perl pour Plan 9

Bien que Perl pour Plan 9 ne fournisse actuellement qu'un chargement statique, il est construit avec un certain nombre d'extensions utiles. Celles-ci incluent Opcode, FileHandle, Fcntl et POSIX. Attendez-vous à en voir d'autres (et DynaLoading !) à l'avenir.

Ce qu'il n'y a pas dans Perl pour Plan 9

Comme mentionné précédemment, le chargement dynamique n'est pas disponible actuellement, pas plus que MakeMaker. Les deux sont des éléments de haute priorité.

Fonctions Perl5 non actuellement prises en charge dans Perl pour Plan 9

Certaines, comme "chown" et "umask", ne sont pas fournies car le concept n'existe pas au sein de Plan 9. D'autres, comme certaines des fonctions liées aux sockets, n'ont simplement pas encore été écrites. Beaucoup de celles de cette dernière catégorie pourraient être prises en charge à l'avenir.

Les fonctions actuellement non implémentées incluent :

chown, chroot, dbmclose, dbmopen, getsockopt, 
setsockopt, recvmsg, sendmsg, getnetbyname, 
getnetbyaddr, getnetent, getprotoent, getservent, 
sethostent, setnetent, setprotoent, setservent, 
endservent, endnetent, endprotoent, umask

Il peut y avoir plusieurs autres fonctions qui ont un comportement indéfini, donc cette liste ne doit pas être considérée comme exhaustive.

Signaux dans Perl pour Plan 9

Pour assurer la compatibilité avec les scripts perl écrits pour l'environnement Unix, Perl pour Plan 9 utilise l'émulation de signal POSIX fournie dans l'environnement POSIX ANSI (APE) de Plan 9. L'empilement de signaux n'est pas pris en charge. Les signaux fournis sont :

SIGHUP, SIGINT, SIGQUIT, SIGILL, SIGABRT,
SIGFPE, SIGKILL, SIGSEGV, SIGPIPE, SIGPIPE, SIGALRM, 
SIGTERM, SIGUSR1, SIGUSR2, SIGCHLD, SIGCONT,
SIGSTOP, SIGTSTP, SIGTTIN, SIGTTOU

COMPILATION ET INSTALLATION DE PERL SUR PLAN 9

BIENVENUE dans Perl pour Plan 9, âme courageuse !

   Ceci est une version alpha préliminaire de Perl pour Plan 9. Reste à implémenter
MakeMaker et DynaLoader. De nombreuses commandes perl manquent ou se comportent actuellement
de manière incompréhensible. Ces lacunes seront, avec persévérance et une part de
chance, corrigées dans un avenir proche. Pour installer ce logiciel :

1. Créez les répertoires sources et les bibliothèques pour perl en exécutant la commande plan9/setup.rc (c'est-à-dire située dans le sous-répertoire plan9). Note : la routine d'installation suppose que vous n'avez pas désarchivé ces fichiers dans /sys/src/cmd/perl. Après avoir exécuté setup.rc, vous pouvez supprimer la copie de la source que vous avez initialement décompressée, car le code source a maintenant été installé dans /sys/src/cmd/perl. Si vous prévoyez d'installer des binaires perl pour toutes les architectures, exécutez "setup.rc -a".

2. Après vous être assuré que vous disposez des privilèges adéquats pour construire les logiciels système, depuis /sys/src/cmd/perl/5.00301 (ajustez la version en conséquence) exécutez :

mk install

Si vous souhaitez installer des versions de perl pour toutes les architectures (68020, mips, sparc et 386) exécutez :

mk installall

3. Attendez. Le processus de compilation prendra un *très* long temps car perl s'auto-amorce. Une machine Pentium 75MHz avec 16 Mo de RAM prend environ 30 minutes pour construire la distribution à partir de zéro.

Installation de la documentation Perl sur Plan 9

Cette distribution perl est livrée avec une quantité énorme de documentation. Pour les ajouter aux manuels intégrés livrés avec Plan 9, depuis /sys/src/cmd/perl/5.00301 (ajustez la version en conséquence) exécutez :

mk man

Pour commencer votre lecture, commencez par :

man perl

C'est une bonne introduction et vous dirigera vers d'autres pages man qui pourraient vous intéresser.

(Remarque : "mk man" peut produire du bruit superflu. N'ayez crainte.)
