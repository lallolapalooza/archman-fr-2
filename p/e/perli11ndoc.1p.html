NOM

perli11ndoc - visualiser la documentation des bibliothèques installées liées via Glib::Object::Introspection

ABSTRACT

perli11ndoc permet de visualiser la documentation Perl pour les bibliothèques Glib liées à Perl via Glib::Object::Introspection. Glib::Object::Introspection utilise les projets gobject-introspection et libffi pour créer dynamiquement des liaisons Perl pour une grande variété de bibliothèques. Les exemples incluent gtk+, webkit, libsoup et bien d'autres. Toutes les bibliothèques actuellement installées seront affichées avec la documentation et les exemples spécifiques à Perl. Lorsque Glib::Object::Introspection diffère de la bibliothèque C, les différences sont signalées et l'interface spécifique à Perl est définie.

DÉPENDANCES

perli11ndoc nécessite que XML::LibXML soit installé pour fonctionner. Il nécessite également que les en-têtes des bibliothèques C correspondantes soient installés sur le système pour fournir la documentation. Par exemple, sur un système basé sur Debian, vous auriez besoin de libgtk-3-dev pour voir la documentation introspectée par Perl pour Gtk3.
