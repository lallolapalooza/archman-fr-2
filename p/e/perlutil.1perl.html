PERLUTIL(1perl) Guide de référence des programmeurs Perl PERLUTIL(1perl)

NOM

perlutil - utilitaires distribués avec Perl

DESCRIPTION

En plus de l'interpréteur Perl lui-même, la distribution Perl installe une gamme d'utilitaires sur votre système. Il existe également plusieurs utilitaires utilisés par la distribution Perl elle-même dans le cadre du processus d'installation. Ce document a pour but de lister tous ces utilitaires, d'expliquer leur fonction et de fournir des liens vers la documentation de chaque module, le cas échéant.

LISTE DES UTILITAIRES

Documentation

perldoc
L'interface principale de la documentation de Perl est perldoc, bien que si vous lisez ceci, vous l'avez très probablement déjà trouvé. perldoc extrait et formate la documentation de tout fichier dans le répertoire courant, de tout module Perl installé sur le système, ou de toutes les pages de documentation standard, comme celle-ci. Utilisez "perldoc <nom>" pour obtenir des informations sur l'un des utilitaires décrits dans ce document.
pod2man
pod2text
S'il est exécuté depuis un terminal, perldoc appellera généralement pod2man pour traduire POD (Plain Old Documentation - voir perlpod pour une explication) en page de manuel (manpage), puis exécutera man pour l'afficher ; si man n'est pas disponible, pod2text sera utilisé à la place et la sortie sera dirigée vers votre pagineur préféré.
pod2html
En plus de ces deux-là, il existe un autre convertisseur : pod2html produira des pages HTML à partir de POD.
pod2usage
Si vous voulez juste savoir comment utiliser les utilitaires décrits ici, pod2usage extraira uniquement la section "USAGE" ; certains utilitaires s'appelleront automatiquement pod2usage lorsqu'ils seront appelés avec "-help".
podchecker
Si vous écrivez votre propre documentation en POD, l'utilitaire podchecker recherchera les erreurs dans votre balisage.
splain
splain est une interface pour perldiag - collez votre message d'erreur dedans, et il vous l'expliquera.
roffitall
L'utilitaire roffitall n'est pas installé sur votre système mais se trouve dans le répertoire pod/ de votre kit source Perl ; il convertit toute la documentation de la distribution au format *roff, et produit un fichier PostScript ou texte composé de l'ensemble.

Convertisseurs

pl2pm
Pour vous aider à convertir des programmes hérités vers un Perl plus moderne, l'utilitaire pl2pm vous aidera à convertir les bibliothèques de style ancien de Perl 4 en modules Perl 5 de nouveau style.

Administration

libnetcfg
Pour afficher et modifier la configuration libnet, exécutez la commande libnetcfg.
perlivp
Le programme perlivp est configuré au moment de la compilation du code source Perl pour tester la version de Perl sous laquelle il a été construit. Il peut être utilisé après avoir exécuté "make install" (ou la procédure équivalente sur votre plateforme) pour vérifier que Perl et ses bibliothèques ont été correctement installés.

Développement

Il existe un ensemble d'utilitaires qui vous aident dans le développement de programmes Perl, et en particulier, dans l'extension de Perl avec C.

perlbug
perlbug était la méthode recommandée pour signaler les bugs dans l'interpréteur Perl lui-même ou dans l'un des modules de la bibliothèque standard aux développeurs ; les rapports de bugs et les correctifs doivent maintenant être soumis à https://github.com/Perl/perl5/issues.
perlthanks
Ce programme offre un moyen facile d'envoyer un message de remerciement aux auteurs et mainteneurs de Perl. C'est juste perlbug installé sous un autre nom.
h2ph
Avant que Perl n'ait le système XS pour se connecter aux bibliothèques C, les programmeurs utilisaient les fichiers d'en-tête C pour lire les constantes des bibliothèques. Vous pouvez encore voir "require 'syscall.ph'" ou similaire par là - le fichier .ph doit être créé en exécutant h2ph sur le fichier .h correspondant. Voir la documentation de h2ph pour plus d'informations sur la conversion d'un grand nombre de fichiers d'en-tête à la fois.
h2xs
h2xs convertit les fichiers d'en-tête C en modules XS, et essaiera d'écrire autant de code de liaison entre les bibliothèques C et les modules Perl que possible. Il est également très utile pour créer des squelettes de modules purement Perl.
enc2xs
enc2xs construit une extension Perl à utiliser par Encode à partir de fichiers de mappage de caractères Unicode (.ucm) ou de fichiers d'encodage Tcl (.enc). En plus d'être utilisé en interne pendant le processus de construction du module Encode, vous pouvez utiliser enc2xs pour ajouter votre propre encodage à Perl. Aucune connaissance de XS n'est nécessaire.
xsubpp
xsubpp est un compilateur pour convertir le code XS de Perl en code C. Il est généralement exécuté par les makefiles créés par ExtUtils::MakeMaker.

xsubpp compilera le code XS en code C en intégrant les constructions nécessaires pour permettre aux fonctions C de manipuler les valeurs Perl et crée la liaison nécessaire pour permettre à Perl d'accéder à ces fonctions.

prove
prove est une interface en ligne de commande pour la fonctionnalité d'exécution de tests de Test::Harness. C'est une alternative à "make test".
corelist
Une interface en ligne de commande pour Module::CoreList, pour interroger quels modules ont été livrés avec des versions données de Perl.

Outils généraux

Quelques outils à usage général sont livrés avec Perl, principalement parce qu'ils proviennent de modules inclus dans la distribution Perl.

encguess
encguess tentera de deviner l'encodage de caractères des fichiers.
json_pp
json_pp est un convertisseur et formateur JSON en pur Perl.
piconv
piconv est une version Perl de iconv(1), un convertisseur d'encodage de caractères largement disponible pour divers systèmes Unix aujourd'hui. Ce script était principalement une démonstration technologique pour Perl v5.8.0, mais vous pouvez utiliser piconv à la place d'iconv dans pratiquement tous les cas.
ptar
ptar est un programme de type tar, écrit en pur Perl.
ptardiff
ptardiff est un petit utilitaire qui produit une différence entre une archive extraite et une archive non extraite. (Notez que cet utilitaire nécessite le module Text::Diff pour fonctionner correctement ; ce module n'est pas distribué avec Perl, mais est disponible sur CPAN.)
ptargrep
ptargrep est un utilitaire pour appliquer la correspondance de motifs aux contenus des fichiers dans une archive tar.
shasum
Cet utilitaire, qui vient avec le module Digest::SHA, est utilisé pour afficher ou vérifier les sommes de contrôle SHA.
streamzip
streamzip compresse les données transmises à STDIN dans un conteneur zip en flux.
zipdet

perlutil - Utilitaires Perl

NAME

perlutil - Utilitaires Perl

DESCRIPTION

Cette page de manuel décrit un certain nombre d'utilitaires fournis avec Perl qui peuvent être utiles dans diverses situations.

LIST OF UTILITIES

Utilitaires d'archive et de compression

ptar
ptar est un utilitaire de ligne de commande pour créer et extraire des archives au format .tar. Il est particulièrement utile pour la gestion des archives créées par Perl. Il n'est pas conçu pour les fichiers compressés (comme les archives .zip ou .gz).
ptardiff
ptardiff compare les fichiers dans deux archives .tar. Il est utile pour déterminer les différences entre deux versions d'une archive, ou pour identifier les fichiers qui ont été ajoutés ou supprimés.
shasum
shasum est utilisé pour calculer et vérifier les sommes de contrôle SHA-1 pour les fichiers. Cela peut être utile pour s'assurer de l'intégrité des fichiers téléchargés ou pour vérifier qu'un fichier n'a pas été modifié.
streamzip
streamzip est un utilitaire pour créer et manipuler des archives au format .zip. Il permet d'ajouter, de supprimer, de lister et d'extraire des fichiers d'une archive zip, souvent sans avoir à charger l'intégralité de l'archive en mémoire.
zipdetails
zipdetails affiche des informations sur la structure interne des enregistrements d'un fichier zip. Il ne s'occupe pas d'afficher des détails sur les données compressées stockées dans le fichier zip.

Installation

Ces utilitaires aident à gérer les modules Perl supplémentaires qui ne sont pas fournis avec la distribution perl.

cpan
cpan est une interface en ligne de commande pour CPAN.pm. Elle vous permet d'installer des modules ou des distributions depuis CPAN, ou simplement d'obtenir des informations à leur sujet, et bien plus encore. Elle est similaire au mode ligne de commande du module CPAN, 
perl -MCPAN -e shell
instmodsh
Une petite interface pour ExtUtils::Installed afin d'examiner les modules installés, de valider vos listes de paquets et même de créer une archive tar à partir d'un module installé.
