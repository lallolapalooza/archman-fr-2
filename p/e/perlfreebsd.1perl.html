NOM

perlfreebsd - Version Perl 5 sur les systèmes FreeBSD

DESCRIPTION

Ce document décrit diverses caractéristiques de FreeBSD qui affectent la manière dont Perl version 5 (ci-après dénommé Perl) est compilé et/ou exécuté.

Les dumps en cas de crash de FreeBSD avec readdir_r et ithreads

Lorsque Perl est configuré pour utiliser les threads (ithreads), il préférera les appels de bibliothèque réentrables aux versions non réentrables. Il existe un bogue dans la fonction "readdir_r" de FreeBSD dans les versions 4.5 et antérieures qui peut provoquer un SEGV lors de la lecture de grands répertoires. Un patch pour la libc de FreeBSD est disponible (voir https://bugs.freebsd.org/bugzilla/show_bug.cgi?id=30631) et a été intégré dans FreeBSD 4.6.

$^X ne contient pas toujours un chemin complet sous FreeBSD

Perl définit $^X avec un chemin complet autant que possible en interrogeant le système d'exploitation. Sous FreeBSD, le chemin complet de l'interpréteur Perl est trouvé en utilisant "sysctl" avec "KERN_PROC_PATHNAME" si cela est supporté, sinon en lisant le lien symbolique /proc/curproc/file. FreeBSD 7 et versions antérieures ont un bogue où l'une ou l'autre approche retourne parfois une valeur incorrecte (voir https://bugs.freebsd.org/bugzilla/show_bug.cgi?id=35703). Dans ces cas, Perl reviendra au comportement précédent consistant à utiliser la valeur "argv[0]" de C pour $^X.
