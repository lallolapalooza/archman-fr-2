NOM

perlver - L'analyseur de version minimale de Perl

SYNTAXE

adam@red:~$ perlver Perl-MinimumVersion
Found directory '.'
Searching for Perl files... found 3 file(s)
Scanning lib/Perl/MinimumVersion.pm... done
Scanning t/01_compile.t... done
Scanning t/02_main.t... done
    ---------------------------------------------------------
  | file                       | explicit | syntax | external |
  | --------------------------------------------------------- |
  | lib/Perl/MinimumVersion.pm | 5.005    | ~      | n/a      |
  | t/01_compile.t             | ~        | ~      | n/a      |
  | t/02_main.t                | ~        | ~      | n/a      |
    ---------------------------------------------------------
Minimum version of Perl required: ...
adam@red:~$

DESCRIPTION

"perlver" est un script de console créé pour fournir un accès pratique aux fonctionnalités fournies par Perl::MinimumVersion.

L'option --blame affiche le code qui nécessite cette version de perl

La syntaxe ci-dessus couvre à peu près tout ce que vous devez savoir à ce stade.
