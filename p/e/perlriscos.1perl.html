PERLRISCOS(1perl) Guide de référence du programmeur Perl PERLRISCOS(1perl)

NOM

perlriscos - Version 5 de Perl pour RISC OS

DESCRIPTION

Ce document donne des instructions pour compiler Perl pour RISC OS. Cela est compliqué par la nécessité de compiler croisée. Une version binaire de perl est disponible sur https://www.cp15.org/perl/ que vous pourriez souhaiter utiliser au lieu d'essayer de la compiler vous-même.

COMPILATION

Vous avez besoin d'un compilateur croisé GCCSDK installé et fonctionnel https://www.riscos.info/downloads/gccsdk/latest/ et REXEN https://www.cp15.org/programming/.

D'abord, copiez les sources et compilez une copie native de perl pour votre système hôte. Ensuite, dans les sources à compiler croisement :

1.
$ ./Configure
2.
Sélectionnez le fichier d'indices RISC OS (hints/riscos.sh). Les réponses par défaut pour le reste des questions sont généralement suffisantes.

Notez que si vous souhaitez exécuter "Configure" de manière non interactive (voir le document INSTALL pour les détails), pour qu'il sélectionne le bon fichier d'indices, vous devrez fournir l'argument "-Dhintfile=riscos" sur la ligne de commande de "Configure".

3.
$ make miniperl
4.
Cela devrait compiler "miniperl" puis échouer lorsqu'il essaie de l'exécuter.
5.
Copiez l'exécutable miniperl de la compilation native effectuée précédemment pour remplacer le miniperl compilé croisement.
6.
$ make
7.
Cela utilisera "miniperl" pour compléter le reste de la compilation.
