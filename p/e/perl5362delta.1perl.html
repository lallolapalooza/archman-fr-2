PERL5362DELTA(1perl) Guide de référence du programmeur Perl PERL5362DELTA(1perl)

NOM

perl5362delta - ce qui est nouveau pour la version perl v5.36.2

DESCRIPTION

Ce document décrit les différences entre la version 5.36.1 et la version 5.36.2.

Si vous effectuez une mise à niveau à partir d'une version antérieure telle que la 5.36.0, lisez d'abord perl5361delta, qui décrit les différences entre les versions 5.36.0 et 5.36.1.

Sécurité

Cette version corrige les problèmes de sécurité suivants.

CVE-2023-47038 - Écriture hors de la fin du tampon via une propriété Unicode définie par l'utilisateur invalide

Cette vulnérabilité a été signalée directement à l'équipe de sécurité de Perl par Nathan Mills "the.true.nathan.mills@gmail.com".

Une expression régulière conçue, lorsqu'elle est compilée par perl 5.30.0 à 5.38.0, peut provoquer un dépassement de tampon d'un octet contrôlé par l'attaquant dans un tampon alloué sur le tas.

CVE-2023-47039 - Vulnérabilité d'usurpation de binaire Perl pour Windows

Cette vulnérabilité a été signalée à l'équipe de réponse aux incidents de sécurité des produits Intel (PSIRT) par l'utilisateur GitHub ycdxsb https://github.com/ycdxsb/WindowsPrivilegeEscalation. PSIRT l'a ensuite signalée à l'équipe de sécurité de Perl.

Perl pour Windows s'appuie sur la variable d'environnement PATH pour trouver le shell ("cmd.exe"). Lors de l'exécution d'un exécutable qui utilise l'interpréteur Perl Windows, Perl tente de trouver et d'exécuter "cmd.exe" au sein du système d'exploitation. Cependant, en raison de problèmes d'ordre de recherche dans le PATH, Perl recherche d'abord cmd.exe dans le répertoire de travail actuel.

Un attaquant disposant de privilèges limités peut exploiter ce comportement en plaçant "cmd.exe" dans des emplacements avec des permissions faibles, comme "C:\ProgramData". Ce faisant, lorsqu'un administrateur tente d'utiliser cet exécutable à partir de ces emplacements compromis, un code arbitraire peut être exécuté.

Remerciements

Perl 5.36.2 représente environ 1 mois de développement depuis Perl 5.36.1 et contient environ 2 300 lignes de modifications réparties sur 38 fichiers provenant de 4 auteurs.

En excluant les fichiers générés automatiquement, la documentation et les outils de publication, il y a eu environ 1 400 lignes de modifications dans 8 fichiers .pm, .t, .c et .h.

Perl continue de prospérer dans sa quatrième décennie grâce à une communauté dynamique d'utilisateurs et de développeurs. Les personnes suivantes sont connues pour avoir contribué aux améliorations qui sont devenues Perl 5.36.2 :

Karl Williamson, Paul Evans, Steve Hay, Tony Cook.

La liste ci-dessus est presque certainement incomplète car elle est générée automatiquement à partir de l'historique du contrôle de version. En particulier, elle n'inclut pas les noms des contributeurs (très appréciés) qui ont signalé des problèmes au traqueur de bugs de Perl.

De nombreuses modifications incluses dans cette version proviennent des modules CPAN inclus dans le noyau de Perl. Nous sommes reconnaissants à toute la communauté CPAN d'aider Perl à prospérer.

Pour une liste plus complète de tous les contributeurs historiques de Perl, veuillez consulter le fichier AUTHORS dans la distribution source de Perl.

Signalement des bogues

Si vous trouvez ce que vous pensez être un bogue, vous pourriez consulter la base de données des bogues de perl à l'adresse https://github.com/Perl/perl5/issues. Vous pourriez également trouver des informations sur http://www.perl.org/, la page d'accueil de Perl.

Si vous pensez avoir un bogue non signalé, veuillez ouvrir un ticket sur https://github.com/Perl/perl5/issues. Assurez-vous de réduire votre bogue à un cas de test minuscule mais suffisant.

Si le bogue que vous signalez a des implications de sécurité qui le rendent inapproprié à envoyer à un traqueur de problèmes public, alors consultez "SECURITY VULNERABILITY CONTACT INFORMATION" dans perlsec pour les détails sur la manière de signaler le problème.

Faire des remerciements

Si vous souhaitez remercier les Perl 5 Porters pour le travail accompli dans Perl 5, vous pouvez le faire en exécutant le programme "perlthanks" :

perlthanks

Cela enverra un e-mail à la liste Perl 5 Porters avec votre marque de remerciement.
