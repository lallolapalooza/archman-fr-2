NOM

pekwm_panel - un panneau simple à utiliser avec pekwm

SYNTAXE

pekwm_panel [--display]

DESCRIPTION

pekwm_panel est une application de panneau simple fournie avec pekwm.

OPTIONS

--help Afficher les informations d'aide.

--config PATH Utiliser la configuration du panneau à l'emplacement PATH.

--display DISPLAY Se connecter à DISPLAY au lieu de DISPLAY défini dans l'environnement.

--pekwm-config PATH Lire le thème actif à partir de la configuration pekwm à l'emplacement PATH.

--log-level LEVEL Niveau de journalisation.

--log-file PATH Journaliser vers PATH, utiliser - pour la sortie standard.
