NOM

persist-tool --- Fichier de configuration de {{ site.product.short_name }}

SYNOPSIS

persist-tool [commande] [options]

DESCRIPTION

Cette page de manuel n'est qu'un résumé.

L'application persist-tool est un utilitaire qui peut être utilisé pour extraire le contenu du fichier persist, et manipuler son contenu.

[](/assets/images/caution.png) ATTENTION : Persist-tool est un outil spécial pour les experts de syslog-ng. N'utilisez pas cet outil à moins de savoir exactement ce que vous faites. Une mauvaise configuration entraînera des dommages irrécupérables au fichier persist, sans aucun avertissement.

Limitations : * Les fonctions persist-state ne peuvent être utilisées qu'avec des fichiers persist SLP4 ou plus récents. Les anciens fichiers persist ne sont pas pris en charge. * Les caractères génériques ne sont pas pris en charge dans les noms de fichiers et de répertoires.

LA COMMANDE dump

dump [options] [fichier_persist]

Utilisez la commande dump pour afficher le contenu actuel du fichier persist au format JSON sur la console.

La commande dump a les options suivantes : * --help ou -?

Affiche un bref message d'aide.

EXEMPLE : persist-tool dump

persist-tool dump /usr/var/syslog-ng.persist

Une sortie valide est la suivante :

run_id = { "value": "00 00 00 00 0C 00 00 00 " }
host_id = { "value": "00 00 00 00 5F 49 2F 01 " }

LA COMMANDE add

add [options] [fichier_entrée]

Utilisez la commande add pour ajouter ou modifier une entrée d'état spécifiée dans le fichier persist. L'entrée d'état doit être dans le même format que celui affiché par la commande dump. Si l'entrée d'état donnée existe déjà, elle sera mise à jour. Sinon, une nouvelle valeur sera ajoutée. Si l'état persist donné est invalide, il sera ignoré.

Pour utiliser la commande add : utilisez persist-tool dump pour afficher le contenu du fichier persist actuel, et redirigez-le vers un fichier. Modifiez le contenu de ce fichier. Utilisez persist-tool add avec ce fichier pour modifier le persist.

La commande add a les options suivantes : * --help ou -?

Affiche un bref message d'aide.
•
--output-dir=<répertoire> ou -o

Paramètre requis. Le répertoire où se trouve le fichier persist. Le nom du fichier persist stocké dans ce répertoire doit être syslog-ng.persist.

•
--persist-name=<nom_fichier> ou -p

Paramètre optionnel. Le nom du fichier persist à générer. Valeur par défaut : syslog-ng.persist.

EXEMPLE : add dump_persist

/usr/bin/persist-tool add dump_persist -o .

Une sortie valide est la suivante :

log_reader_curpos(Application)      OK
affile_sd_curpos(/var/aaa.txt)        OK

Une sortie invalide est la suivante :

log_reader_curpos(Application)      OK
wrong
FAILED (error: Invalid entry syntax)
affile_sd_curpos(/var/aaa.txt)        OK

FICHIERS
