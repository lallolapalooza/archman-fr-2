NOM

podman-machine-os-apply - Appliquer une image OCI au système d'exploitation d'une machine Podman

SYNOPIS

podman machine os apply [options] image [vm]

DESCRIPTION

Applique les changements de système d'exploitation de la machine à partir d'une image OCI.

Les VM qui utilisent des systèmes d'exploitation basés sur rpm-ostree ont la capacité de se rebaser sur le contenu d'une image OCI. podman machine image apply prend une image OCI avec la fonctionnalité ostree native pour conteneur et se rebase sur cette image.

Par défaut, les machines Podman sur Mac, Linux et Windows Hyper-V utilisent une distribution personnalisée basée sur rpm-ostree (Fedora CoreOS). Les machines basées sur Microsoft WSL utilisent une distribution Fedora personnalisée et ne peuvent pas être mises à jour avec cette commande.

Note : Les machines basées sur WSL peuvent être mises à jour en utilisant la commande podman machine ssh <nom_machine> suivie de sudo dnf update. Cela peut cependant entraîner des résultats inattendus en cas de différences entre les versions du client et du serveur Podman.

Les images de machines Podman sont stockées sous forme d'images OCI sur quay.io/podman/machine-os. Lors de l'application d'une image avec cette commande, le nom de référence OCI complet doit être utilisé, y compris le tag où le tag est la version de Podman présente dans la VM. Par défaut, Podman tentera de ne récupérer que la version de l'énoncé elle-même.

Pour plus d'informations, consultez la documentation de rpm-ostree.

Le nom de machine par défaut est podman-machine-default. Si aucun nom de machine n'est spécifié en tant qu'argument, les changements de système d'exploitation seront appliqués à podman-machine-default.

OPTIONS

--help

Affiche le message d'utilisation.

--restart

Redémarre la VM après l'application des changements.

EXEMPLES

Met à jour la machine Podman par défaut vers la dernière version de développement de l'image OCI amorçable.

Note : Cela peut entraîner une version plus récente de Podman dans la machine que celle du client. Des résultats inattendus peuvent survenir.

Met à jour la machine Podman par défaut vers la dernière image OCI amorçable de Podman 5.4.

$ podman machine os apply quay.io/podman/machine-os:5.4

Met à jour la machine Podman spécifiée vers la dernière image OCI amorçable de Podman 5.3.

$ podman machine os apply quay.io/podman/machine-os:5.3 mymachine
