NOM

podman-image - Gérer les images

SYNOPSIS

podman image sous-commande

DESCRIPTION

La commande image permet la gestion des images.

COMMANDES

Commande Page de manuel Description
build podman-build(1) Construire un conteneur en utilisant un Dockerfile.
diff podman-image-diff(1) Inspecter les modifications sur le système de fichiers d'une image.
exists podman-image-exists(1) Vérifier si une image existe dans le stockage local.
history podman-history(1) Afficher l'historique d'une image.
import podman-import(1) Importer une archive tar et la sauvegarder en tant qu'image système de fichiers.
inspect podman-image-inspect(1) Afficher la configuration d'une image.
list podman-images(1) Lister les images de conteneurs sur le système. (alias ls)
load podman-load(1) Charger une image depuis l'archive docker.
mount podman-image-mount(1) Monter le système de fichiers racine d'une image.
prune podman-image-prune(1) Supprimer toutes les images inutilisées du stockage local.
pull podman-pull(1) Tirer une image depuis un registre.
push podman-push(1) Pousser une image depuis le stockage local ailleurs.
rm podman-rmi(1) Supprimer une ou plusieurs images stockées localement.
save podman-save(1) Sauvegarder une image en format docker-archive ou oci.
scp podman-image-scp(1) Copier en toute sécurité une image d'un hôte à un autre.
search podman-search(1) Rechercher une image dans un registre.
sign podman-image-sign(1) Créer une signature pour une image.
tag podman-tag(1) Ajouter un nom supplémentaire à une image locale.
tree podman-image-tree(1) Afficher la hiérarchie des couches d'une image sous forme d'arbre.
trust podman-image-trust(1) Gérer la politique de confiance des images du registre de conteneurs.
unmount podman-image-unmount(1) Démonter le système de fichiers racine d'une image.
untag podman-untag(1) Supprimer un ou plusieurs noms d'une image stockée localement.
