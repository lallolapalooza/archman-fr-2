NOM

podman-volume-inspect - Obtenir des informations détaillées sur un ou plusieurs volumes

SYNTAXE

podman volume inspect [options] volume [...]

DESCRIPTION

Affiche des informations détaillées sur un ou plusieurs volumes. La sortie peut être formatée à l'aide de l'indicateur --format et d'un modèle Go. Pour obtenir des informations détaillées sur tous les volumes existants, utilisez l'indicateur --all. Les volumes peuvent être interrogés individuellement en fournissant leur nom complet ou un nom partiel unique.

OPTIONS

--all, -a

Inspecter tous les volumes.

--format, -f=format

Formate la sortie des volumes en utilisant un modèle Go

Les espaces réservés valides pour le modèle Go sont listés ci-dessous:

Espace réservé Description
.Anonymous Indique si le volume est anonyme
.CreatedAt ... Heure de création du volume
.Driver Pilote du volume
.GID GID avec lequel le volume a été créé
.Labels ... Informations sur les étiquettes associées au volume
.LockNumber Numéro du verrou du volume Libpod
.MountCount Nombre de fois où le volume est monté
.Mountpoint Source du point de montage du volume
.Name Nom du volume
.NeedsChown Indique que le volume sera chowné lors de la prochaine utilisation
.NeedsCopyUp Indique que les données à la destination seront copiées dans le volume lors de la prochaine utilisation
.Options ... Options du volume
.Scope Portée du volume
.Status ... Statut du volume
.StorageID StorageID du volume
.Timeout Délai d'attente du volume
.UID UID avec lequel le volume a été créé

--help

Affiche le message d'utilisation

EXEMPLES

Inspecter un volume nommé.

$ podman volume inspect myvol
[
     {
          "Name": "myvol",
          "Driver": "local",
          "Mountpoint": "/home/myusername/.local/share/containers/storage/volumes/myvol/_data",
          "CreatedAt": "2023-03-13T16:26:48.423069028-04:00",
          "Labels": {},
          "Scope": "local",
          "Options": {},
          "MountCount": 0,
          "NeedsCopyUp": true,
          "NeedsChown": true
     }
]

Inspecter tous les volumes.

$ podman volume inspect --all
[
     {
          "Name": "myvol",
          "Driver": "local",
          "Mountpoint": "/home/myusername/.local/share/containers/storage/volumes/myvol/_data",
          "CreatedAt": "2023-03-13T16:26:48.423069028-04:00",
          "Labels": {},
          "Scope": "local",
          "Options": {},
          "MountCount": 0,
          "NeedsCopyUp": true,
          "NeedsChown": true
     }
]

Inspecter un volume nommé et afficher ses champs Driver et Scope.

$ podman volume inspect --format "{{.Driver}} {{.Scope}}" myvol
local local
