POSIX_SPAWNATTR_GETSCHEDPARAM(3P) Manuel du programmeur POSIX POSIX_SPAWNATTR_GETSCHEDPARAM(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_spawnattr_getschedparam, posix_spawnattr_setschedparam — obtenir et définir l'attribut spawn-schedparam d'un objet d'attributs de génération (TEMPS RÉEL AVANCÉ)

SYNTAXE

#include <spawn.h>
#include <sched.h>
int posix_spawnattr_getschedparam(const posix_spawnattr_t
    *restrict attr, struct sched_param *restrict schedparam);
int posix_spawnattr_setschedparam(posix_spawnattr_t *restrict attr,
    const struct sched_param *restrict schedparam);

DESCRIPTION

La fonction posix_spawnattr_getschedparam() récupère la valeur de l'attribut spawn-schedparam de l'objet d'attributs référencé par attr.

La fonction posix_spawnattr_setschedparam() définit l'attribut spawn-schedparam dans un objet d'attributs initialisé référencé par attr.

L'attribut spawn-schedparam représente les paramètres de planification à attribuer à la nouvelle image de processus dans une opération de génération (si POSIX_SPAWN_SETSCHEDULER ou POSIX_SPAWN_SETSCHEDPARAM est défini dans l'attribut spawn-flags). La valeur par défaut de cet attribut n'est pas spécifiée.

VALEUR DE RETOUR

En cas de succès, posix_spawnattr_getschedparam() renvoie zéro et stocke la valeur de l'attribut spawn-schedparam de attr dans l'objet référencé par le paramètre schedparam ; sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

En cas de succès, posix_spawnattr_setschedparam() renvoie zéro ; sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

ERREURS

Ces fonctions peuvent échouer si :

EINVAL
La valeur spécifiée par attr est invalide.

La fonction posix_spawnattr_setschedparam() peut échouer si :

EINVAL
La valeur de l'attribut en cours de définition n'est pas valide.
