NOM

podman-artifact-ls - Lister les artefacts OCI dans le stockage local

SYNTAXE

podman artifact ls [options]

DESCRIPTION

Liste tous les artefacts locaux dans votre stockage local.

OPTIONS

--format

Afficher les résultats avec un modèle Go.

Placeholder Description
.Created Temps écoulé depuis la création de l'artefact
.CreatedAt Horodatage complet de la création de l'artefact
.Digest Le résumé calculé du manifeste de l'artefact
.Repository Nom du dépôt de l'artefact
.Size Taille de l'artefact dans des unités lisibles par l'homme
.Tag Étiquette du nom de l'artefact
.VirtualSize Taille de l'artefact en octets

--no-trunc

Ne pas tronquer la sortie (par défaut false).

--noheading, -n

Omettre les en-têtes de table de la liste.

EXEMPLES

Lister les artefacts dans le stockage local

$ podman artifact ls
REPOSITORY                TAG         DIGEST         CREATED          SIZE
quay.io/artifact/foobar1  latest      ab609fad386d   6 hours ago      2.097GB
quay.io/artifact/foobar2  special     cd734b558ceb   53 seconds ago   12.58MB

Lister les artefacts dans le stockage local sans tronquer le résumé

$ podman artifact ls --no-trunc
REPOSITORY                TAG         DIGEST                                                              CREATED          SIZE
quay.io/artifact/foobar1  latest      ab609fad386df1433f461b0643d9cf575560baf633809dcc9c190da6cc3a3c29    6 hours ago      2.097GB
quay.io/artifact/foobar2  special     cd734b558ceb8ccc0281ca76530e1dea1eb479407d3163f75fb601bffb6f73d0    53 seconds ago   12.58MB

Lister les artefacts dans le stockage local sans l'en-tête de titre

$ podman artifact ls --noheading
quay.io/artifact/foobar1  latest      ab609fad386d   6 hours ago      2.097GB
quay.io/artifact/foobar2  special     cd734b558ceb   53 seconds ago   12.58MB

Lister les résumés et la taille des artefacts en utilisant un --format

$ podman artifact ls --format "{{.Digest}} {{.Size}}"
ab609fad386d 2.097GB
cd734b558ceb 12.58MB
