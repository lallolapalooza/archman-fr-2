NOM

podman-quadlet-install - Installer un fichier quadlet ou une application quadlet

SYNOPSIS

podman quadlet install [options] chemin-ou-url-quadlet [chemin-ou-url-fichiers]...

DESCRIPTION

Installe un fichier Quadlet ou une application (qui peut inclure plusieurs fichiers Quadlet) pour l'utilisateur actuel. Vous pouvez spécifier les fichiers Quadlet comme fichiers locaux ou URL web.

Cette commande vous permet de :

* Installer un seul fichier Quadlet, éventuellement suivi de fichiers non-Quadlet supplémentaires.
* Spécifier un répertoire contenant plusieurs fichiers Quadlet et d'autres fichiers non-Quadlet pour l'installation (par exemple, un fichier de configuration pour un conteneur quadlet).

Remarque : Si un quadlet fait partie d'une application, la suppression de ce quadlet spécifique supprimera toute l'application. Lorsqu'un quadlet est installé à partir d'un répertoire, tous les fichiers installés à partir de ce répertoire, y compris les fichiers quadlet et non-quadlet, sont considérés comme faisant partie d'une seule application.

Remarque : Si l'utilisateur souhaite installer une application Quadlet, le premier chemin doit être le chemin vers le répertoire de l'application.

OPTIONS

--reload-systemd

Recharge systemd après l'installation des Quadlets (par défaut : vrai). Pour le désactiver, les utilisateurs doivent définir manuellement la valeur de ce drapeau à false.

--replace, -r

Remplace l'installation Quadlet même si le fichier d'unité généré existe déjà (par défaut : faux). Pour l'activer, les utilisateurs doivent définir manuellement la valeur de ce drapeau à true. Ce drapeau est principalement utilisé pour mettre à jour une unité existante.

EXEMPLES

Installer un quadlet à partir d'un fichier.

$ podman quadlet install test-service-quadlet.container
/home/user/.config/containers/systemd/test-service-quadlet.container

Installer un quadlet à partir d'un répertoire.

$ podman quadlet install /home/user/work/quadlet-app/
/home/user/.config/containers/systemd/myquadlet1.container
/home/user/.config/containers/systemd/myquadlet2.container
/install/path/myquadlet1.container
/install/path/myquadlet2.container

Installer un quadlet à partir d'une URL

$ podman quadlet install https://github.com/containers/podman/blob/main/test/e2e/quadlet/basic.container
/home/user/.config/containers/systemd/basic.container
