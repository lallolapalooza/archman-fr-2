NOM

podman-system-connection - Gérer les destinations pour les services Podman

SYNTAXE

podman system connection sous-commande

DESCRIPTION

Gérer les destinations pour les services Podman.

L'utilisateur est invité à saisir le mot de passe de connexion ssh ou la phrase secrète du fichier clé, selon les besoins. ssh-agent est pris en charge s'il est en cours d'exécution.

Podman gère la connexion système en écrivant et en lisant le fichier podman-connections.json situé sous $XDG_CONFIG_HOME/containers ou, si l'environnement n'est pas défini, il utilise par défaut $HOME/.config/containers. Ou alors, la variable d'environnement PODMAN_CONNECTIONS_CONF peut être définie avec un chemin de fichier complet que podman utilisera à la place. Ce fichier est géré par les commandes podman et ne doit jamais être édité directement par les utilisateurs. Pour configurer manuellement les connexions, utilisez service_destinations dans containers.conf.

Si la colonne ReadWrite (LectureÉcriture) dans la sortie de podman system connection list est définie sur true, la connexion est stockée dans le fichier podman-connections.json, sinon elle est stockée dans containers.conf et ne peut donc pas être modifiée avec les commandes podman system connection.

COMMANDES

Commande Page de manuel Description
add podman-system-connection-add(1) Enregistrer la destination pour le service Podman
default podman-system-connection-default(1) Définir la destination nommée comme par défaut pour le service Podman
list podman-system-connection-list(1) Lister la destination pour les services Podman
remove podman-system-connection-remove(1) Supprimer la destination nommée
rename podman-system-connection-rename(1) Renommer la destination pour le service Podman

EXEMPLE

Lister les connexions système :

$ podman system connection list
Nom URI                                           Identité	      Défaut  LectureÉcriture
devl ssh://root@example.com/run/podman/podman.sock ~/.ssh/id_rsa  vrai     vrai
