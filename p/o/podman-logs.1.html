podman-logs(1) Manuel des commandes générales podman-logs(1)

NOM

podman-logs - Afficher les journaux d'un ou plusieurs conteneurs

SYNTAXE

podman logs [options] conteneur [conteneur...]

podman container logs [options] conteneur [conteneur...]

DESCRIPTION

La commande podman logs récupère par lots tous les journaux présents pour un ou plusieurs conteneurs au moment de l'exécution. Cela ne garantit pas l'ordre d'exécution lorsque la commande est combinée avec podman run (par exemple, le run peut ne pas avoir généré de journaux au moment où podman logs a été exécuté).

OPTIONS

--color

Afficher les conteneurs avec différentes couleurs dans le journal.

--follow, -f

Suivre la sortie du journal. Par défaut, la valeur est false.

Remarque : Lors du suivi d'un conteneur qui est supprimé par podman container rm ou qui est supprimé à la sortie (podman run --rm ...), il est possible que le fichier journal soit supprimé avant que podman logs ne lise le contenu final.

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utiliser le dernier conteneur créé. Remarque : le dernier conteneur démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (à l'exception de WSL2)).

--names, -n

Afficher les noms des conteneurs au lieu de leurs identifiants dans le journal.

--since=TIMESTAMP

Afficher les journaux depuis TIMESTAMP. L'option --since peut être des timestamps Unix, des timestamps formatés en date, ou des chaînes de durée Go (par exemple, 10m, 1h30m) calculées par rapport à l'heure de la machine client. Les formats pris en charge pour les timestamps formatés en date incluent RFC3339Nano, RFC3339, 2006-01-02T15:04:05, 2006-01-02T15:04:05.999999999, 2006-01-02Z07:00 et 2006-01-02.

--tail=LIGNES

Afficher le nombre spécifié de LIGNES à la fin des journaux. LIGNES doit être un entier. La valeur par défaut est -1, ce qui imprime toutes les lignes.

--timestamps, -t

Afficher les horodatages dans la sortie des journaux. Par défaut, la valeur est false.

--until=TIMESTAMP

Afficher les journaux jusqu'à TIMESTAMP. L'option --until peut être des timestamps Unix, des timestamps formatés en date, ou des chaînes de durée Go (par exemple, 10m, 1h30m) calculées par rapport à l'heure de la machine client. Les formats pris en charge pour les timestamps formatés en date incluent RFC3339Nano, RFC3339, 2006-01-02T15:04:05, 2006-01-02T15:04:05.999999999, 2006-01-02Z07:00 et 2006-01-02.

Pour afficher seulement les deux dernières lignes du journal du conteneur :

podman logs --tail 2 b3f2436bdb97
# WARNING: The TCP backlog setting of 511 cannot be enforced because /proc/sys/net/core/somaxconn is set to the lower value of 128.
# Server initialized

Pour afficher les journaux de tous les conteneurs :

podman logs -t --since 0 myserver

1:M 07 Aug 14:10:09.056 # Server initialized

Pour afficher les journaux d'un conteneur depuis une certaine heure :

podman logs -t --since 2017-08-07T10:10:09.055837383-04:00 myserver
1:M 07 Aug 14:10:09.055 # Server can't set maximum open files to 10032 because of OS error: Operation not permitted.

1:M 07 Aug 14:10:09.056 # Server initialized

Pour afficher les journaux d'un conteneur générés au cours des 10 dernières minutes :

podman logs --since 10m myserver
# Server can't set maximum open files to 10032 because of OS error: Operation not permitted.
# Current maximum open files is 4096. maxclients has been reduced to 4064 to compensate for low ulimit, Increase 'ulimit -n' when higher maxclients are required.
