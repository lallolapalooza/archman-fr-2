sous-programme cpotri (caractère uplo, entier n, complexe, dimension( lda, * ) a, entier lda, entier info)

CPOTRI

Objectif :

!>
!> CPOTRI calcule l'inverse d'une matrice complexe hermitienne définie positive
!> A en utilisant la factorisation de Cholesky A = U**H*U ou A = L*L**H
!> calculée par CPOTRF.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEX, de dimension (LDA,N)
!>          À l'entrée, le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**H*U ou A = L*L**H, tel que calculé par CPOTRF.
!>          À la sortie, le triangle supérieur ou inférieur de l'inverse (Hermitienne)
!>          de A, écrasant le facteur d'entrée U ou L.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, l'élément (i,i) du facteur U ou L est
!>                zéro, et l'inverse n'a pas pu être calculé.
!>
