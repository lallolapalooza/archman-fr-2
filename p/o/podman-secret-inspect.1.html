podman-secret-inspect(1) Manuel des commandes générales podman-secret-inspect(1)

NOM

podman-secret-inspect - Affiche des informations détaillées sur un ou plusieurs secrets

SYNTAXE

podman secret inspect [options] secret [...]

DESCRIPTION

Inspecte le secret spécifié.

Par défaut, cela rend tous les résultats dans un tableau JSON. Si un format est spécifié, le modèle donné est exécuté pour chaque résultat. Les secrets peuvent être interrogés individuellement en fournissant leur nom complet ou un nom partiel unique.

OPTIONS

--format, -f=format

Formate la sortie du secret en utilisant le modèle Go.

Espace réservé Description
.CreatedAt ... Quand le secret a été créé (horodatage relatif, lisible par l'homme)
.ID ID du secret
.SecretData Données du secret (affichées uniquement avec l'option --showsecret)
.Spec ... Détails du secret
.Spec.Driver ... Informations sur le pilote
.Spec.Driver.Name Nom du pilote (chaîne)
.Spec.Driver.Options ... Options du pilote (carte d'options spécifiques au pilote)
.Spec.Labels ... Étiquettes pour ce secret
.Spec.Name Nom du secret
.UpdatedAt ... Quand le secret a été mis à jour pour la dernière fois (horodatage relatif, lisible par l'homme)

--help

Affiche l'énoncé d'utilisation.

--pretty

Affiche la sortie de l'inspection dans un format lisible par l'homme. Ignore les champs de --format.

--showsecret

Affiche les données du secret

EXEMPLES

Inspecte le secret mysecret.

$ podman secret inspect mysecret

Inspecte le secret mysecret et l'affiche dans un format lisible par l'homme au lieu de JSON, avec les champs par défaut.

$ podman secret inspect --pretty mysecret

Inspecte le secret mysecret et affiche les champs Nom et Étiquettes.

$ podman secret inspect --format "{{.Spec.Name}} {{.Spec.Labels}}" mysecret

Inspecte le secret mysecret et affiche les champs Nom et SecretData. Notez que cela affichera les données du secret à l'écran.

$ podman secret inspect --showsecret --format "{{.Spec.Name}} {{.SecretData}}" mysecret
