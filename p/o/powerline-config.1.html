NOM

powerline-config - Script utilisé pour obtenir la configuration de powerline.

SYNTAXE

powerline-config [-pCHEMIN]… tmux ACTION ( [-s |n )]
powerline-config [-pCHEMIN]… shell ACTION [COMPOSANT] [-sSHELL]

DESCRIPTION

-p, --config-path CHEMIN
Chemin vers le répertoire de configuration. S'il est présent, les fichiers de configuration ne seront recherchés que dans le chemin fourni. Peut être fourni plusieurs fois pour rechercher dans une liste de répertoires.
-h, --help
Afficher l'aide et quitter.

Arguments spécifiques à la sous-commande tmux

ACTION
Si l'action est source, les fichiers de configuration tmux spécifiques à la version sont sourcés. Si c'est setenv, les variables d'environnement globales tmux spéciales (précédées de _POWERLINE) sont remplies avec les données de la configuration powerline. L'action setup effectue simplement setenv puis source.
-s, --source
Lors de l'utilisation de setup : utiliser toujours le sourcing de fichier de configuration. Par défaut, cela est déterminé automatiquement en fonction de la version de tmux : c'est le comportement par défaut pour tmux 1.8 et versions antérieures.
-n, --no-source
Lors de l'utilisation de setup : au lieu de sourcer directement, exécuter les fichiers de configuration. C'est-à-dire lire chaque fichier de configuration powerline nécessaire, substituer les variables $_POWERLINE_… par les valeurs appropriées et exécuter tmux config line. C'est le comportement par défaut pour tmux 1.9 et versions ultérieures.
-h, --help
Afficher l'aide et quitter.

Arguments spécifiques à la sous-commande shell

ACTION
Si l'action est command, la commande powerline préférée est sortie. Si c'est uses, le script powerline-config se terminera avec 1 si le composant spécifié est désactivé et 0 sinon.
COMPOSANT
Applicable uniquement pour la sous-commande uses : fait que powerline-config se termine avec 0 si un composant spécifique est activé et avec 1 sinon. Le composant tmux représente les liaisons tmux (par exemple, celles qui notifient tmux des changements de répertoire courant), le composant prompt représente l'invite de shell.
-s, --shell SHELL
Shell pour lequel la requête est exécutée.
-h, --help
Afficher l'aide et quitter.
