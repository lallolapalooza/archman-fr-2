NOM

podman-manifest-exists - Vérifie si la liste de manifestes donnée existe dans le stockage local

SYNTAXE

podman manifest exists manifest

DESCRIPTION

podman manifest exists vérifie si une liste de manifestes existe dans le stockage local. Podman renvoie un code de sortie de 0 lorsque le manifeste est trouvé. Un 1 est renvoyé sinon. Un code de sortie de 125 indique qu'il y a eu un autre problème.

OPTIONS

--help, -h

Affiche l'énoncé d'utilisation.

EXEMPLE

Vérifiez si une liste de manifestes appelée list1 existe (la liste de manifestes existe réellement) :

$ podman manifest exists list1
$ echo $?
0

Vérifiez si un manifeste appelé mylist existe (la liste de manifestes n'existe pas réellement) :

$ podman manifest exists mylist
$ echo $?
1

VOIR AUSSI
