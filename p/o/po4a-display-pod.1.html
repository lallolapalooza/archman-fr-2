NOM

po4a-display-pod - affichage d'un fichier POD traduit selon un PO

SYNTAXE

po4a-display-pod -p  FICHIER_PO -m  FICHIER_POD [-o  OPT_PO4A]

DESCRIPTION

Les traducteurs peuvent utiliser po4a-display-pod pour voir comment leur traduction d'une page de manuel sera rendue aux utilisateurs finaux, sans avoir à recompiler et réinstaller l'ensemble du projet. La plupart du temps, le fichier POD n'est disponible que dans le paquet source ou intégré dans un script Perl.

OPTIONS

-p FICHIER_PO

Le fichier PO contenant les traductions.

-m FICHIER_POD

Le fichier POD original utilisé par po4a pour générer le fichier PO.

-o OPT_PO4A

Quelques options à passer à po4a-translate(1).
