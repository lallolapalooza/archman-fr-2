POSIX_TRACE_ATTR_GETCLOCKRES(3P) Manuel du programmeur POSIX POSIX_TRACE_ATTR_GETCLOCKRES(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_trace_attr_getclockres, posix_trace_attr_getcreatetime, posix_trace_attr_getgenversion, posix_trace_attr_getname, posix_trace_attr_setname — récupérer et définir des informations sur un flux de trace (TRACING)

SYNTAXE

#include <time.h>
#include <trace.h>
int posix_trace_attr_getclockres(const trace_attr_t *attr,
    struct timespec *resolution);
int posix_trace_attr_getcreatetime(const trace_attr_t *attr,
    struct timespec *createtime);
#include <trace.h>
int posix_trace_attr_getgenversion(const trace_attr_t *attr,
    char *genversion);
int posix_trace_attr_getname(const trace_attr_t *attr,
    char *tracename);
int posix_trace_attr_setname(trace_attr_t *attr,
    const char *tracename);

DESCRIPTION

La fonction posix_trace_attr_getclockres() copie la résolution d'horloge de l'horloge utilisée pour générer les horodatages à partir de l'attribut résolution-horloge de l'objet d'attributs pointé par l'argument attr dans la structure pointée par l'argument resolution.

La fonction posix_trace_attr_getcreatetime() copie le moment de création du flux de trace à partir de l'attribut heure-création de l'objet d'attributs pointé par l'argument attr dans la structure pointée par l'argument createtime. L'attribut heure-création représente le moment de la création du flux de trace.

La fonction posix_trace_attr_getgenversion() copie la chaîne de caractères contenant les informations de version à partir de l'attribut version-génération de l'objet d'attributs pointé par l'argument attr dans la chaîne pointée par l'argument genversion. L'argument genversion est l'adresse d'un tableau de caractères pouvant stocker au moins {TRACE_NAME_MAX} caractères.

La fonction posix_trace_attr_getname() copie la chaîne de caractères contenant le nom de la trace à partir de l'attribut nom-trace de l'objet d'attributs pointé par l'argument attr dans la chaîne pointée par l'argument tracename. L'argument tracename est l'adresse d'un tableau de caractères pouvant stocker au moins {TRACE_NAME_MAX} caractères.

La fonction posix_trace_attr_setname() définit le nom dans l'attribut nom-trace de l'objet d'attributs pointé par l'argument attr, en utilisant la chaîne de nom de trace fournie par l'argument tracename. Si la chaîne fournie contient plus de {TRACE_NAME_MAX} caractères, le nom copié dans l'attribut nom-trace peut être tronqué à un caractère de moins que la longueur de {TRACE_NAME_MAX} caractères. La valeur par défaut est une chaîne nulle.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent une valeur de zéro. Sinon, elles retournent le numéro d'erreur correspondant.

En cas de succès, la fonction posix_trace_attr_getclockres() stocke la valeur de l'attribut résolution-horloge dans l'objet pointé par resolution. Sinon, le contenu de cet objet n'est pas spécifié.

En cas de succès, la fonction posix_trace_attr_getcreatetime() stocke le moment de création du flux de trace dans l'objet pointé par createtime. Sinon, le contenu de cet objet n'est pas spécifié.

En cas de succès, la fonction posix_trace_attr_getgenversion() stocke les informations de version de la trace dans la chaîne pointée par genversion. Sinon, le contenu de cette chaîne n'est pas spécifié.

En cas de succès, la fonction posix_trace_attr_getname() stocke le nom de la trace dans la chaîne pointée par tracename. Sinon, le contenu de cette chaîne n'est pas spécifié.

ERREURS

Les fonctions posix_trace_attr_getclockres(), posix_trace_attr_getcreatetime(), posix_trace_attr_getgenversion(), et posix_trace_attr_getname() peuvent échouer si :

EINVAL
La valeur spécifiée par l'un des arguments est invalide.
