NOM

podman-network-ls - Afficher un résumé des réseaux

SYNOPIS

podman network ls [options]

DESCRIPTION

Affiche une liste des réseaux podman existants.

OPTIONS

--filter, -f=filtre=valeur

Fournit des valeurs de filtre.

Le format de l'argument filtres est clé=valeur. S'il y a plus d'un filtre, passez plusieurs OPTIONS : --filter foo=bar --filter bif=baz.

Filtres pris en charge :

Filtre Description
driver Filtrer par type de pilote.
id Filtrer par ID de réseau complet ou partiel.
label Filtrer par réseau avec (ou sans, dans le cas où label!=[...] est utilisé) les étiquettes spécifiées.
name Filtrer par nom de réseau (accepte les expressions régulières).
until Filtrer par réseaux créés avant une certaine date/heure.
dangling Filtrer par réseaux sans conteneurs attachés.

Le filtre driver accepte les valeurs : bridge, macvlan, ipvlan.

Le filtre label accepte deux formats. L'un est label=clé ou label=clé=valeur, qui affiche les images avec les étiquettes spécifiées. L'autre format est label!=clé ou label!=clé=valeur, qui affiche les images sans les étiquettes spécifiées.

Le filtre until peut être des horodatages Unix, des horodatages formatés en date ou des chaînes de durée Go (par exemple, 10m, 1h30m) calculées par rapport à l'heure de la machine.

Le filtre dangling accepte les valeurs true ou false.

--format=format

Change le format de sortie par défaut. Il peut s'agir d'un type pris en charge comme 'json' ou d'un modèle Go. Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Espace réservé Description
.Created ... Horodatage de création du réseau
.DNSEnabled Le réseau a le DNS activé (booléen)
.Driver Pilote réseau
.ID ID du réseau
.Internal Le réseau est interne (booléen)
.IPAMOptions ... Options IPAM du réseau
.IPv6Enabled Le réseau a un sous-réseau IPv6 (booléen)
.Labels Étiquettes du réseau
.Name Nom du réseau
.NetworkDNSServers Tableau des serveurs DNS utilisés dans ce réseau
.NetworkInterface Nom de l'interface réseau sur l'hôte
.Options ... Options du réseau
.Routes Liste des routes statiques pour ce réseau
.Subnets Liste des sous-réseaux sur ce réseau

--no-trunc

Ne pas tronquer l'ID du réseau.

--noheading, -n

Omettre les en-têtes de table de la liste.

--quiet, -q

L'option quiet limite la sortie aux seuls noms de réseau.

EXEMPLE

Afficher les réseaux :

$ podman network ls
NETWORK ID    NAME         DRIVER
88a7120ee19d  podman       bridge
6dd508dbf8cd  podman6  bridge
8e35c2cd3bf6  podman5  macvlan

Afficher uniquement les noms des réseaux :

$ podman network ls -q
podman
podman2
outside
podman9

Afficher le nom du réseau qui prend en charge le plugin bridge :

$ podman network ls --filter driver=bridge --format {{.Name}}
podman
podman2
podman9

Lister les réseaux avec leurs sous-réseaux :

$ podman network ls --format "{{.Name}}: {{range .Subnets}}{{.Subnet}} {{end}}"
podman: 10.88.0.0/16
podman3: 10.89.30.0/24 fde4:f86f:4aab:e68f::/64
macvlan:
