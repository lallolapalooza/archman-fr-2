NOM

postfix2dlf_main - convertir la sortie de postfix2dlf_pre en dlf pour email

SYNTAXE

postfix2dlf_main dumpfile

DESCRIPTION

postfix2dlf_main attend un fichier journal postfix prétraité, tel qu'écrit par postfix2dlf_pre(1) sur STDIN. Il imprime un fichier DLF Lire pour email sur stdout, en utilisant une base de données Berkeley dans dumpfile, contenant une correspondance entre le nom d'hôte-identifiant de file d'attente et le nombre de lignes avec cet identifiant.

DEVELOPPEURS

Les structures de données sont les mêmes que celles de sendmail2dlf.

%msg stocke toutes les informations actuellement traitées du journal. Dans sendmail2dlf, ce hachage est indexé par les identifiants DLF :

$dlfid = $log->{'hostname'} . $log->{'queueid'}

. Dans postfix2dlf, nous utilisons uniquement l'identifiant de file d'attente, pour le moment.

Valeurs scalaires :

$msg{$dlfid} = {
  logrelay        => ...,
  queueid         => ...,
  time            => ...,
  nrcpts          => ...,
  from_user       => ...,
  from_domain     => ...,
  from_relay_host => ...,
  from_relay_ip   => ...,
  size            => ...,
  msgid           => ...,
};

De plus :

$del = $msg{$dlfid}->{deliveries}{$to};

$to est une adresse email telle que renvoyée par &Lire::Email::sanitize_tos .

$del->{to_user}   = ....;
$del->{to_domain} = ....;

Autres clés $del avec des valeurs scalaires :

to_relay_host
to_relay_ip
delay
xdelay
stat
xstat

.

La référence de hachage $msg{$dlfid} est souvent assignée à `$cur'.

EXEMPLES

postfix2dlf_main sera rarement utilisé seul : il est appelé par postfix2dlf(1). Référez-vous à la page man de postfix2dlf pour des exemples et des informations d'utilisation.
