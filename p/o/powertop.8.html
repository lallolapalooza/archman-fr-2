NOM

powertop - un outil de diagnostic de consommation et de gestion d'énergie.

SYNOPIS

powertop [options]

DESCRIPTION

powertop est un programme qui aide à diagnostiquer divers problèmes de consommation et de gestion d'énergie. Il dispose également d'un mode interactif permettant d'expérimenter avec divers paramètres de gestion d'énergie. Lorsque powertop est appelé sans arguments, il démarre en mode interactif.

OPTIONS

--auto-tune
Définit toutes les options ajustables sur leur bon réglage sans interaction.
-c, --calibrate
Exécute powertop en mode calibration. Lors d'une utilisation sur batterie, powertop peut suivre la consommation d'énergie ainsi que l'activité du système. Une fois suffisamment de mesures effectuées, powertop peut commencer à rapporter des estimations de consommation. On peut obtenir des estimations plus précises en utilisant cette option pour activer un cycle de calibration. Cela parcourra différents niveaux d'affichage, des activités des périphériques USB et des charges de travail.
-C, --csv[=nom_fichier]
Génère un rapport CSV. Si un nom_fichier n'est pas spécifié, le nom par défaut powertop.csv est utilisé. Le rapport CSV peut être utilisé pour le reporting et l'analyse de données.
--debug
Exécute en mode debug.
--extech=noeud_dev
Utilise l'analyseur de puissance Extech pour les mesures. Cela permet de spécifier le nœud de périphérique série de l'adaptateur série vers USB connecté à l'analyseur de puissance Extech, par exemple /dev/ttyUSB0.
-r, --html[=nom_fichier]
Génère un rapport HTML. Si un nom_fichier n'est pas spécifié, le nom par défaut powertop.html est utilisé. Le rapport HTML peut être envoyé à d'autres pour aider à diagnostiquer les problèmes d'énergie.
-i, --iteration[=itérations]
Nombre de fois où chaque test sera exécuté.
-q, --quiet
Supprime la sortie stderr.
-t, --time[=secondes]
Génère un rapport pour un nombre spécifié de secondes.
-w, --workload[=charge_travail]
Exécute le fichier charge_travail dans le cadre de la calibration avant de générer un rapport.
-V, --version
Affiche les informations de version et quitte.
-h, --help
Affiche le message d'aide et quitte.

COMMANDES

En mode interactif, les raccourcis clavier suivants sont disponibles :

Tabulation Affiche l'onglet suivant
Maj+Tabulation Affiche l'onglet précédent
Flèche droite Fait défiler vers la droite
Flèche gauche Fait défiler vers la gauche
Flèche haut, PagePréc Fait défiler vers le haut ou sélectionne l'élément précédent
Flèche bas, PageSuiv Fait défiler vers le bas ou sélectionne l'élément suivant
Espace, Entrée Active l'élément courant
s Définit le délai de rafraîchissement
r Rafraîchit la fenêtre
q, Ctrl-C, Échap Quitte powertop
