podman-mount(1) Manuel des commandes générales podman-mount(1)

NOM

podman-mount - Monter le système de fichiers racine d'un conteneur en cours d'exécution

SYNOPSIS

podman mount [options] [conteneur ...]

podman container mount [options] [conteneur ...]

DESCRIPTION

Monte le système de fichiers racine des conteneurs spécifiés dans un emplacement accessible depuis l'hôte, et retourne cet emplacement.

Podman liste tous les conteneurs actuellement montés, y compris les conteneurs externes, lorsque la commande est exécutée sans arguments. Les conteneurs externes sont des conteneurs dans le stockage de conteneurs (container/storage) gérés par des outils autres que Podman, par exemple Buildah et CRI-O.

Le mode sans privilèges ne prend en charge que le montage du pilote VFS, sauf si Podman est exécuté dans l'espace de noms utilisateur via la commande podman unshare. Tous les autres pilotes de stockage échouent au montage.

VALEUR DE RETOUR

L'emplacement du système de fichiers monté. En cas d'erreur, une chaîne vide et le code errno sont retournés.

OPTIONS

--all, -a

Monte tous les conteneurs podman. (Les conteneurs externes ne sont pas montés)

--format=format

Affiche les conteneurs montés dans le format spécifié (json).

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utilise le dernier conteneur créé. Note : le dernier conteneur démarré peut appartenir à d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (hors WSL2))

--no-trunc

Ne tronque pas la sortie (par défaut false).

EXEMPLES

En mode privilégié, monter le conteneur spécifié.

# podman mount c831414b10a3
/var/lib/containers/storage/overlay/f3ac502d97b5681989dff84dfedc8354239bcecbdc2692f9a639f4e080a02364/merged

En mode sans privilèges, le montage de conteneur ne fonctionne qu'à partir de l'intérieur de l'espace de noms utilisateur.

$ podman unshare
# podman mount affectionate_mcnulty
/home/dwalsh/.local/share/containers/storage/overlay/4218326b9a80619aef005ff95067f76687ad975ce101c176598fb416f6186906/merged

Lister les conteneurs actuellement montés :

podman mount
c831414b10a3 /var/lib/containers/storage/overlay/f3ac502d97b5681989dff84dfedc8354239bcecbdc2692f9a639f4e080a02364/merged
a7060253093b /var/lib/containers/storage/overlay/0ff7d7ca68bed1ace424f9df154d2dd7b5a125c19d887f17653cbcd5b6e30ba1/merged

Monter plusieurs conteneurs :

podman mount c831414b10a3 a7060253093b
/var/lib/containers/storage/overlay/f3ac502d97b5681989dff84dfedc8354239bcecbdc2692f9a639f4e080a02364/merged
/var/lib/containers/storage/overlay/0ff7d7ca68bed1ace424f9df154d2dd7b5a125c19d887f17653cbcd5b6e30ba1/merged
