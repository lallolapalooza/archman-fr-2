NOM

podman-farm - Distribuer les constructions à des machines exécutant podman pour différentes architectures

SYNTAXE

podman farm sous-commande

DESCRIPTION

Distribuer les constructions à des machines exécutant Podman pour différentes architectures.

Gérer des fermes en les créant, les mettant à jour et en les supprimant.

Remarque : Toutes les machines de la ferme doivent avoir une version minimale de podman de v4.9.0.

Podman gère les fermes en écrivant et en lisant le fichier podman-connections.json situé sous $XDG_CONFIG_HOME/containers ou, si la variable d'environnement n'est pas définie, il utilise par défaut $HOME/.config/containers. Ou, la variable d'environnement PODMAN_CONNECTIONS_CONF peut être définie sur un chemin de fichier complet que podman utilisera à la place. Ce fichier est géré par les commandes podman et ne doit jamais être modifié directement par les utilisateurs. Pour configurer manuellement les fermes, utilisez la section [farm] dans containers.conf.

Si la colonne ReadWrite dans la sortie de podman farm list est définie sur true, la ferme est stockée dans le fichier podman-connections.json, sinon elle est stockée dans containers.conf et ne peut donc pas être modifiée avec les commandes podman farm remove/update. Elle peut toujours être utilisée avec podman farm build.

COMMANDES

Commande Page de manuel Description
build podman-farm-build(1) Construire des images sur les nœuds de la ferme, puis les regrouper dans une liste de manifestes
create podman-farm-create(1) Créer une nouvelle ferme
list podman-farm-list(1) Lister les fermes existantes
remove podman-farm-remove(1) Supprimer une ou plusieurs fermes
update podman-farm-update(1) Mettre à jour une ferme existante
