NOM

podman-rename - Renommer un conteneur existant

SYNTAXE

podman rename conteneur nouveau_nom

podman container rename conteneur nouveau_nom

DESCRIPTION

Rename modifie le nom d'un conteneur existant. L'ancien nom est libéré et disponible pour être réutilisé. Cette commande peut être exécutée sur des conteneurs dans n'importe quel état. Cependant, les conteneurs en cours d'exécution pourraient ne pas recevoir pleinement les effets du changement jusqu'à leur redémarrage - par exemple, un conteneur en cours d'exécution pourrait toujours utiliser l'ancien nom dans ses journaux. Actuellement, seuls les conteneurs sont pris en charge ; les pods et les volumes ne peuvent pas être renommés.

OPTIONS

EXEMPLES

Renommer un conteneur avec un nom donné.

$ podman rename ancienConteneur unNouveauNom

Renommer un conteneur avec un identifiant donné.

$ podman rename 717716c00a6b conteneurTest

Créer un alias pour un conteneur avec un identifiant donné.

$ podman container rename 6e7514b47180 ctrDatabase
