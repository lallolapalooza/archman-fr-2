NOM

podman-volume-import - Importer le contenu d'une archive dans un volume podman existant

SYNOPSIS

podman volume import volume [source]

DESCRIPTION

podman volume import importe le contenu d'une archive dans le point de montage du volume podman. Le contenu du volume est fusionné avec le contenu de l'archive, cette dernière ayant la priorité. podman volume import peut consommer une entrée redirigée lorsqu'il utilise - comme chemin source.

Le volume donné doit déjà exister et n'est pas créé par podman volume import.

--help

Afficher l'énoncé d'utilisation

EXEMPLES

Importer le contenu d'un volume nommé à partir du fichier spécifié.

$ podman volume import myvol test.tar

Importer le contenu d'un volume nommé depuis stdin.

$ gunzip -c hello.tar.gz | podman volume import myvol -

Exporter le contenu d'un volume nommé et le rediriger vers un volume nommé via stdin.

$ podman volume export oldmyvol | podman volume import myvol -
