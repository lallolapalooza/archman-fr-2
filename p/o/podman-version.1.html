podman-version(1) Manuel des commandes générales podman-version(1)

NOM

podman-version - Afficher les informations de version de Podman

SYNTAXE

podman version [options]

DESCRIPTION

Affiche les informations suivantes : Version de l'API distante, Version, Version Go, Commit Git, Heure de compilation, OS et Architecture.

OPTIONS

--format, -f=format

Change le format de sortie en "json" ou en template Go.

Raccourci Description
.Client ... Version du podman local
.Server ... Version du podman distant

Chacun des champs ci-dessus se ramifie en sous-champs supplémentaires tels que .Version, .APIVersion, .GoVersion, et plus encore.

EXEMPLE

Un exemple de sortie de la commande version :

$ podman version
Version:      2.0.0
API Version:  1
Go Version:   go1.14.2
Git Commit:   4520664f63c3a7f9a80227715359e20069d95542
Built:        Tue May 19 10:48:59 2020
OS/Arch:      linux/amd64

Filtrage de la seule version :

$ podman version --format '{{.Client.Version}}'
2.0.0

--help, -h

Imprime le message d'utilisation
