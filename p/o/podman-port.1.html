podman-port(1) Manuel des commandes générales podman-port(1)

NOM

podman-port - Lister les mappages de ports d'un conteneur

SYNTAXE

podman port [options] conteneur [port-privé[/proto]]

podman container port [options] conteneur [port-privé[/proto]]

DESCRIPTION

Lister les mappages de ports pour le conteneur ou rechercher le port public auquel le port-privé est NAT-é.

OPTIONS

--all, -a

Lister tous les mappages de ports connus pour les conteneurs en cours d'exécution ; lorsque cette option est utilisée, les noms de conteneurs ou les filtres de ports/protocoles privés ne peuvent pas être utilisés.

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utiliser le dernier conteneur créé. Note : le dernier conteneur démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (sauf WSL2))

EXEMPLE

Lister tous les mappages de ports :

# podman port -a
b4d2f05432e482e017b1a4b2eae15fa7b4f6fb7e9f65c1bde46294fdef285906
80/udp -> 0.0.0.0:44327
80/tcp -> 0.0.0.0:44327
#

Lister les mappages de ports pour un conteneur spécifique :

# podman port b4d2f054
80/udp -> 0.0.0.0:44327
80/tcp -> 0.0.0.0:44327
#

Lister les mappages de ports spécifiés pour un conteneur spécifique :

# podman port b4d2f054 80
 0.0.0.0:44327
#

Lister les mappages de ports pour un conteneur spécifique pour le port 80 et le protocole tcp :

# podman port b4d2f054 80/tcp
0.0.0.0:44327
#
