NOM

podman-images - Lister les images dans le stockage local

SYNTAXE

podman images [options] [image]

podman image list [options] [image]

podman image ls [options] [image]

DESCRIPTION

Affiche les images stockées localement, leurs noms et leurs identifiants.

OPTIONS

--all, -a

Afficher toutes les images (par défaut, exclure les couches d'images intermédiaires). La valeur par défaut est false.

--digests

Afficher les digests des images.

--filter, -f=filtre

Fournir des valeurs de filtre.

Le format de l'argument filtres est clé=valeur ou clé!=valeur. S'il y a plus d'un filtre, passez plusieurs OPTIONS : --filter foo=bar --filter bif=baz.

Filtres supportés :

Filtre Description
id Filtrer par identifiant d'image.
before Filtrer par images créées avant l'IMAGE donnée (nom ou étiquette).
containers Filtrer par images avec un conteneur en cours d'exécution.
dangling Filtrer par images orphelines (inutilisées).
digest Filtrer par digest.
intermediate Filtrer par images qui sont orphelines et n'ont pas d'enfants.
label Filtrer par images avec (ou sans, dans le cas où label!=[...] est utilisé) les étiquettes spécifiées.
manifest Filtrer par images qui sont des listes de manifestes.
readonly Filtrer par images en lecture seule ou en lecture/écriture.
reference Filtrer par nom d'image.
after/since Filtrer par images créées après l'IMAGE donnée (nom ou étiquette).
until Filtrer par images créées jusqu'à la durée ou l'heure donnée.

Le filtre id accepte la chaîne d'identifiant d'image.

Le filtre before accepte les formats : <nom-image>[:<étiquette>], <identifiant-image> ou <image@digest>.

Le filtre containers affiche les images qui ont un conteneur en cours d'exécution basé sur cette image.

Le filtre dangling affiche les images qui occupent de l'espace disque et n'ont plus d'utilité. Une image orpheline est une couche de système de fichiers qui a été utilisée dans une construction précédente d'une image et qui n'est plus référencée par aucune image. Elles sont marquées avec l'étiquette <none>, consomment de l'espace disque et n'ont pas d'utilité active.

Le filtre digest accepte la chaîne de digest d'image.

Le filtre intermediate affiche les images qui sont orphelines et n'ont pas d'enfants.

Le filtre label accepte deux formats. L'un est label=clé ou label=clé=valeur, qui affiche les images avec les étiquettes spécifiées. L'autre format est label!=clé ou label!=clé=valeur, qui affiche les images sans les étiquettes spécifiées.

Le filtre manifest affiche les images qui sont des listes de manifestes.

Le filtre readonly affiche, par défaut, les images en lecture seule et en lecture/écriture. Les images en lecture seule peuvent être configurées en modifiant additionalimagestores dans le fichier /etc/containers/storage.conf.

Le filtre reference accepte le motif d'une référence d'image <nom-image>[:<étiquette>].

Les filtres after ou since acceptent les formats : <nom-image>[:<étiquette>], <identifiant-image> ou <image@digest>.

Le filtre until accepte les formats : durée golang, heure RFC3339, ou un horodatage Unix, et affiche toutes les images créées jusqu'à ce moment.

--format=format

Change le format de sortie par défaut. Il peut s'agir d'un type supporté comme 'json' ou d'un template Go. Les espaces réservés valides pour le template Go sont listés ci-dessous :

Espace réservé Description
.Containers Nombre de conteneurs utilisant cette image
.Created Temps écoulé depuis la création de l'image
.CreatedAt Heure de création de l'image, AAAA-MM-JJ HH:MM:SS +nnnn
.CreatedSince Identique à .Created
.CreatedTime Identique à .CreatedAt
.Dangling Identique à .IsDangling
.Digest Digest de l'image
.History Historique de la couche d'image
.ID ID de l'image (tronqué)
.Id ID de l'image (SHA complet)
.IsDangling L'image est-elle orpheline ? (vrai/faux)
.IsReadOnly L'image est-elle en lecture seule ? (vrai/faux)
.Labels ... map[] d'étiquettes
.Names FQIN de l'image
.ParentId SHA complet de l'ID de l'image parente, ou null (chaîne)
.ReadOnly Identique à .IsReadOnly
.RepoDigests map[] de zéro ou plusieurs chaînes repo/nom@sha256:SHA
.Repository Référentiel de l'image
.RepoTags map[] de zéro ou plusieurs chaînes FQIN pour cette image
.SharedSize Toujours semble être 0
.Size Taille de la couche sur le disque (chaîne lisible par l'homme)
.Tag Étiquette de l'image
.VirtualSize Taille de la couche sur le disque (octets)

--history

Afficher l'historique des noms d'images. Si une image est re-étiquetée ou dés-étiquetée, l'historique des noms d'images est préfixé (dernière image en premier). Ceci est particulièrement utile lors de l'annulation d'une opération d'étiquetage ou lorsqu'une image ne contient aucun nom parce qu'elle a été dés-étiquetée.

--no-trunc

Ne pas tronquer la sortie (par défaut : false).

--noheading, -n

Omettre les en-têtes de table de la liste.

--quiet, -q

Liste uniquement les identifiants des images.

--sort=tri

Trier par created, id, repository, size ou tag (par défaut : created). Lors du tri par repository, il trie également par tag comme second critère pour fournir une sortie stable.

SYNOPSIS

podman images [OPTIONS]

podman image ls [OPTIONS]

DESCRIPTION

The podman images command lists images that are stored in the local container storage. This command is an alias for podman image ls.

When listing images, podman displays the repository name, tag, image ID, creation date, and the virtual size of the image. If an image does not have a repository name and tag, none is displayed.

OPTIONS

All the global options common to `podman` commands are available on `podman-images` as well. They are detailed in podman(1).

The following options are available:

-a, --all
Show all images, including intermediate images that are not tagged.
-f, --filter [LABEL=]KEY=VALUE
Filter output based on the given keys. Supported filters:
dangling
If set to true, show only dangling images. If set to false, show only non-dangling images.
label
Filter images based on labels. The default driver is used to filter labels. The supported drivers are:
=
Show images that have the specified label key and value.
!=
Show images that do not have the specified label key and value.
Example: podman images --filter label=release=stable
