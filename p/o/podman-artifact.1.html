NOM

podman-artifact - Gérer les artefacts OCI

SYNTAXE

podman artifact sous-commande

DESCRIPTION

podman artifact est un ensemble de sous-commandes qui gèrent les artefacts OCI.

Les artefacts OCI sont un moyen courant de distribuer des fichiers associés aux images et conteneurs OCI. Podman est capable de gérer (pull, inspecter, push) ces artefacts depuis son « magasin d'artefacts » local.

SOUS-COMMANDES

Commande Page de manuel Description
add podman-artifact-add(1) Ajouter un artefact OCI au magasin d'artefacts local
extract podman-artifact-extract(1) Extraire un artefact OCI vers un chemin local
inspect podman-artifact-inspect(1) Inspecter un artefact OCI
ls podman-artifact-ls(1) Lister les artefacts OCI dans le magasin local
pull podman-artifact-pull(1) Récupérer un artefact depuis un registre et le stocker localement
push podman-artifact-push(1) Pousser un artefact OCI depuis le stockage local vers un registre d'images
rm podman-artifact-rm(1) Supprimer un ou plusieurs artefacts OCI du stockage local
