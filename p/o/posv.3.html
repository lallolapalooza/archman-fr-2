sous-routine cposv (caractère uplo, entier n, entier nrhs, complexe, dimension( lda, * ) a, entier lda, complexe, dimension( ldb, * ) b, entier ldb, entier info)

CPOSV calcule la solution du système d'équations linéaires complexes A * X = B pour les matrices hermitiennes positives définies N x N et X et B sont des matrices N x NRHS

Objectif :

!>
!> CPOSV calcule la solution d'un système d'équations linéaires complexes
!>    A * X = B,
!> où A est une matrice hermitienne N x N positive définie et X et B
!> sont des matrices N x NRHS.
!>
!> La décomposition de Cholesky est utilisée pour factoriser A comme
!>    A = U**H* U,  si UPLO = 'U', ou
!>    A = L * L**H,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et  L est une matrice triangulaire
!> inférieure.  La forme factorisée de A est ensuite utilisée pour résoudre le système d'équations
!> A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CARACTÈRE*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est ENTIER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA,N)
!>          En entrée, la matrice hermitienne A.  Si UPLO = 'U', la partie
!>          supérieure triangulaire N x N de A contient la partie
!>          supérieure triangulaire de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          inférieure triangulaire N x N de A contient la partie
!>          inférieure triangulaire de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>
!>          En sortie, si INFO = 0, le facteur U ou L de la décomposition de
!>          Cholesky A = U**H*U ou A = L*L**H.
!>

LDA

!>          LDA est ENTIER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEXE, dimension (LDB,NRHS)
!>          En entrée, la matrice du côté droit B de taille N x NRHS.
!>          En sortie, si INFO = 0, la matrice solution X de taille N x NRHS.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le mineur principal de taille i
!>                de A n'est pas positif, donc la factorisation n'a pas pu
!>                être complétée, et la solution n'a pas été calculée.
!>

sposv.3.en - LAPACK

NAME

sposv - sposv computes the solution to a real system of linear equations A * X = B

SYNOPSIS

subroutine sposv (character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldb, * ) b, integer ldb, integer info)

SPOSV computes the solution to system of linear equations A * X = B for PO matrices

Purpose:

!>
!> SPOSV calcule la solution d'un système réel d'équations linéaires
!>    A * X = B,
!> où A est une matrice N-par-N symétrique définie positive et X et B
!> sont des matrices N-par-NRHS.
!>
!> La décomposition de Cholesky est utilisée pour factoriser A comme
!>    A = U**T* U,  si UPLO = 'U', ou
!>    A = L * L**T,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et L est une matrice triangulaire inférieure.
!> La forme factorisée de A est ensuite utilisée pour résoudre le système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  La partie triangulaire supérieure de A est stockée ;
!>          = 'L':  La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau REAL, de dimension (LDA,N)
!>          En entrée, la matrice symétrique A.  Si UPLO = 'U', la partie
!>          supérieure N-par-N de A contient la partie triangulaire supérieure
!>          de la matrice A, et la partie strictement triangulaire inférieure
!>          de A n'est pas référencée.  Si UPLO = 'L', la partie
!>          inférieure N-par-N de A contient la partie triangulaire inférieure
!>          de la matrice A, et la partie strictement triangulaire supérieure
!>          de A n'est pas référencée.
!>
!>          En sortie, si INFO = 0, le facteur U ou L de la décomposition de Cholesky
!>          A = U**T*U ou A = L*L**T.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau REAL, de dimension (LDB,NRHS)
!>          En entrée, la matrice B des membres de droite N-par-NRHS.
!>          En sortie, si INFO = 0, la matrice solution X N-par-NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, le mineur principal de tête d'ordre i
!>                de A n'est pas positif, donc la factorisation n'a pas pu
!>                être complétée, et la solution n'a pas été calculée.
!>
