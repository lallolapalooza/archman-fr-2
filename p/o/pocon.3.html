sous-routine cpocon (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, real anorm, real rcond, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CPOCON

Objectif :

!>
!> CPOCON estime la réciproque du nombre de condition (en norme 1)
!> d'une matrice complexe hermitienne définie positive, en utilisant la
!> factorisation de Cholesky A = U**H*U ou A = L*L**H calculée par CPOTRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et la réciproque du
!> nombre de condition est calculée comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX, de dimension (LDA,N)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**H*U ou A = L*L**H, tel que calculé par CPOTRF.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

ANORM

!>          ANORM est REAL
!>          La norme 1 (ou norme infinie) de la matrice hermitienne A.
!>

RCOND

!>          RCOND est REAL
!>          La réciproque du nombre de condition de la matrice A,
!>          calculée comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est un tableau COMPLEX, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau REAL, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était illégal
!>

NAME


pocon, spocon, dpocon, cpocon, zpocon – estimate the reciprocal of the condition number of a general
    matrix






SYNOPSIS


subroutine spocon(character uplo, integer n, real, dimension( lda, * ) a, integer lda, real anorm, real rcond, real, dimension( * ) rwork, integer info)
subroutine dpocon(character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, double precision anorm, double precision rcond, double precision, dimension( * ) rwork, integer info)
subroutine cpocon(character uplo, integer n, complex, dimension( lda, * ) a, integer lda, real anorm, real rcond, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)
subroutine zpocon(character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision anorm, double precision rcond, complex*16, dimension( * ) work, double precision, dimension( * ) rwork, integer info)







Detailed Description


This routine estimates the reciprocal of the condition number of a
    general band matrix A, in either the upper or lower triangle, and so gives
    an indication of the accuracy of the solution obtained by calling BANDSOLVE to
    solve Ax = B.


The condition number of A is defined as:




kappa(A) = max(abs(A)) * max(abs(inv(A)))





where max(abs(A)) denotes the infinity norm of A.


If RCOND is small, then A is close to being singular. To use this
    routine, you must provide the upper or lower triangular part of the matrix A,
    and its infinity norm. Upper or lower triangular matrices are represented
    by BANDRED.






Function Documentation




subroutine spocon (character uplo, integer n, real, dimension( lda, * ) a, integer lda, real anorm, real rcond, real, dimension( * ) rwork, integer info)


SPOCON


Purpose:




!>
!> SPOCON estimates the reciprocal of the condition number (in the
!> 1-norm) of a single-precision complex Hermitian positive definite matrix.
!>
!> SPOCON is computed using the LU factorization with partial pivoting of
!> the matrix A, as computed by CGETRF.
!>
!> An estimate is obtained for norm(inv(A)), and the reciprocal of the
!> condition number is computed as RCOND = 1 / (ANORM * norm(inv(A))).
!> 




Parameters


UPLO

!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!> 


N


!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!> 


A


!>          A is REAL array, dimension (LDA,N)
!>          The factors L and U from the factorization A = P*L*U as computed
!>          by CGETRF.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!> 


ANORM


!>          ANORM is REAL
!>          The 1-norm (or infinity-norm) of the Hermitian matrix A.
!> 


RCOND


!>          RCOND is REAL
!>          The reciprocal of the condition number of the matrix A,
!>          computed as RCOND = 1/(ANORM * AINVNM), where AINVNM is an
!>          estimate of the 1-norm of inv(A) computed in this routine.
!> 


RWORK


!>          RWORK is REAL array, dimension (N)
!> 


INFO


!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
