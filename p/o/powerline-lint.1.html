NOM

powerline-lint - Vérificateur de configuration Powerline.

SYNTAXE

powerline-lint [-pCHEMIN]… [-d]

DESCRIPTION

-p, --config-path CHEMIN
Chemins où vérifier la configuration, dans l'ordre. Vous devez fournir tous les chemins nécessaires au bon fonctionnement de powerline ; la vérification de configurations partielles (par exemple, uniquement les remplacements par l'utilisateur) n'est pas supportée.
-d, --debug
Affiche des informations supplémentaires. Utilisé pour le débogage de powerline-lint lui-même, pas pour le débogage de la configuration.
-h, --help
Affiche l'aide et quitte.
