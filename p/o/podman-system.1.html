podman-system(1) Manuel des commandes générales podman-system(1)

NOM

podman-system - Gérer Podman

SYNTAXE

podman system sous-commande

DESCRIPTION

La commande system permet la gestion des systèmes Podman.

COMMANDES

Commande Page man Description
check podman-system-check(1) Effectuer des vérifications de cohérence sur le stockage d'images et de conteneurs.
connection podman-system-connection(1) Gérer les destinations des services Podman.
df podman-system-df(1) Afficher l'utilisation du disque par Podman.
events podman-events(1) Surveiller les événements Podman.
info podman-info(1) Afficher les informations système relatives à Podman.
migrate podman-system-migrate(1) Migrer les conteneurs existants vers une nouvelle version de Podman.
prune podman-system-prune(1) Supprimer tous les pods, conteneurs, images, réseaux et données de volume inutilisés.
renumber podman-system-renumber(1) Migrer les numéros de verrouillage pour gérer un changement dans le nombre maximum de verrous.
reset podman-system-reset(1) Réinitialiser le stockage à son état initial.
service podman-system-service(1) Exécuter un service d'API.
