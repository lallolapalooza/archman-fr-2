NOM

podman-image-mount - Monter le système de fichiers racine d'une image

SYNOPIS

podman image mount [options] [image ...]

DESCRIPTION

Monte le système de fichiers racine des images spécifiées dans un emplacement accessible depuis l'hôte, et retourne son emplacement.

La commande podman image mount sans arguments liste toutes les images actuellement montées.

Le mode sans privilèges ne supporte que le montage du pilote VFS, sauf si podman est exécuté dans un espace de noms utilisateur. Utilisez la commande podman unshare pour entrer dans l'espace de noms utilisateur. Tous les autres pilotes de stockage échouent au montage.

VALEUR DE RETOUR

L'emplacement du système de fichiers monté. En cas d'erreur, une chaîne vide et le code errno sont retournés.

OPTIONS

--all, -a

Monter toutes les images.

--format=format

Afficher les images montées dans le format spécifié (json).

EXEMPLES

Monter plusieurs images. Note: En mode sans privilèges, le montage d'images ne fonctionne qu'après avoir exécuté la commande podman unshare pour entrer dans l'espace de noms utilisateur.

podman image mount fedora ubi8-init
/var/lib/containers/storage/overlay/f3ac502d97b5681989dff84dfedc8354239bcecbdc2692f9a639f4e080a02364/merged
/var/lib/containers/storage/overlay/0ff7d7ca68bed1ace424f9df154d2dd7b5a125c19d887f17653cbcd5b6e30ba1/merged

Lister les images montées :

podman image mount
