NOM

poly - l'implémentation Standard ML de Poly/ML

SYNOPSIS

poly

DESCRIPTION

poly démarre le shell Poly/ML. Poly/ML est une implémentation de Standard ML écrite par David Matthews, initialement à l'Université de Cambridge et maintenue comme un projet soutenu par des contributeurs.

OPTIONS

-v
Affiche la version de Poly/ML et quitte.
--help
Affiche une liste des arguments et quitte.
-q
Supprime le message de démarrage.
-i
Mode interactif. Affiche une invite pour chaque ligne d'entrée. C'est le comportement par défaut si l'entrée provient d'un terminal.
--use FICHIER
Lit l'entrée depuis FICHIER comme si l'on exécutait la commande ML « use "FICHIER"; » avant le démarrage du shell ML.
--eval CHAINE
Compile et exécute CHAINE en tant que ML avant le démarrage du shell ML.
--error-exit
Normalement, si le code ML déclenche une exception non gérée, le contrôle revient au shell ML. Avec cette option, le shell se termine en cas d'exception non gérée.
--with-markup
Inclut des informations supplémentaires de balisage lors de l'affichage. Ceci n'est approprié que lorsque Poly/ML est exécuté dans un environnement capable de décoder les informations supplémentaires.
--ideprotocol
Exécute le protocole de communication IDE plutôt que la boucle normale de lecture-évaluation-affichage. Uniquement approprié pour une exécution dans un environnement de développement.
--script
L'entrée est un script shell. La première ligne est ignorée si elle commence par #!.
-H taille
Définit la taille initiale du tas (heap). La taille peut être écrite comme un nombre suivi éventuellement de K, M ou G représentant des kilo-octets, méga-octets ou giga-octets. Si aucun de ceux-ci n'est donné, le nombre est pris comme des méga-octets.
--minheap taille
Définit la taille minimale du tas. Le tas ne rétrécira pas en dessous de cette valeur.
--maxheap taille
Définit la taille maximale du tas. Le tas ne dépassera pas cette valeur.
--gcpercent pourcentage
Définit le pourcentage cible du temps que le code doit passer dans le ramasse-miettes (garbage collector). Le dimensionneur de tas tentera de définir la taille du tas pour atteindre cette cible, en tenant compte des tailles minimale et maximale du tas données par les arguments, et également en essayant de maîtriser le paging.
--gcthreads threads
Définit le nombre de threads utilisés dans le ramasse-miettes parallèle. Le définir à 1 force le ramasse-miettes à être monothread. La valeur 0, par défaut, est interprétée comme le nombre de processeurs (cœurs) disponibles.
--debug options
Définit diverses options de débogage pour le système d'exécution.
