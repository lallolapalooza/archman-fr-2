NOM

podman-unmount - Démonter le système de fichiers racine d'un conteneur en cours d'exécution

SYNOPSIS

podman unmount [options] conteneur [...]

podman umount [options] conteneur [...]

podman container unmount [options] conteneur [...]

podman container umount [options] conteneur [...]

DESCRIPTION

Démonte le système de fichiers racine des conteneurs spécifiés, s'il n'est utilisé par aucun autre processus.

Le stockage des conteneurs incrémente un compteur de montage chaque fois qu'un conteneur est monté. Lorsque le conteneur est démonté, le compteur de montage est décrémenté, et le système de fichiers racine du conteneur n'est physiquement démonté que lorsque le compteur atteint zéro, indiquant qu'aucun autre processus n'utilise le montage. Un démontage peut être forcé avec l'option --force.

Note : Podman peut être utilisé pour démonter des conteneurs Podman ainsi que des conteneurs externes. Les conteneurs externes sont des conteneurs créés dans le stockage de conteneurs (container storage) par d'autres outils comme Buildah et CRI-O.

OPTIONS

--all, -a

Tous les conteneurs actuellement montés sont démontés.

--force, -f

Force le démontage du système de fichiers racine des conteneurs spécifiés, même si d'autres processus l'ont monté.

Note : D'autres processus peuvent échouer si le point de montage qu'ils utilisent est supprimé à leur insu.

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utilise le dernier conteneur créé. Note : le dernier conteneur démarré peut appartenir à d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (sauf WSL2)).

EXEMPLE

Démonter un conteneur avec un ID donné :

podman container unmount containerID

Démonter plusieurs conteneurs avec des IDs donnés :

podman unmount containerID1 containerID2 containerID3

Démonter tous les conteneurs :

podman unmount --all

Forcer le démontage du conteneur avec un ID donné :

podman umount --force containerID

podman(1), podman-mount(1), podman-image-mount(1)
