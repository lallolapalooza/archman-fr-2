POPAUTH(1) Commandes utilisateur POPAUTH(1)

NOM

popauth - page de manuel pour popauth (GNU Mailutils)

SYNTAXE

popauth [OPTION...]

DESCRIPTION

GNU popauth -- gère la base de données d'authentification POP3

SIGNALLER LES BOGUES

Signaler les bogues à <bug-mailutils@gnu.org>.

VOIR AUSSI

La documentation complète de popauth est maintenue sous forme de manuel Texinfo. Si les programmes info et popauth sont correctement installés sur votre site, la commande

info popauth

devrait vous donner accès au manuel complet.
