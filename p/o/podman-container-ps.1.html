NOM

podman-ps - Afficher des informations sur les conteneurs

SYNOPHIS

podman ps [options]

podman container ps [options]

podman container list [options]

podman container ls [options]

DESCRIPTION

podman ps liste les conteneurs en cours d'exécution sur le système. Utilisez l'option --all pour afficher les informations de tous les conteneurs. Par défaut, elle liste :

  • l'identifiant du conteneur
  • le nom de l'image que le conteneur utilise
  • la COMMANDE que le conteneur exécute
  • l'heure de création du conteneur
  • l'état du conteneur
  • les mappages de ports que le conteneur utilise
  • les noms alternatifs pour le conteneur

OPTIONS

--all, -a

Afficher tous les conteneurs, par défaut seuls les conteneurs en cours d'exécution sont affichés.

Note : Podman partage le stockage des conteneurs avec d'autres outils tels que Buildah et CRI-O. Dans certains cas, ces conteneurs externes peuvent également exister dans le même stockage. Utilisez l'option --external pour voir ces conteneurs externes. Les conteneurs externes affichent le statut 'storage'.

--external

Afficher les conteneurs externes qui ne sont pas contrôlés par Podman mais qui sont stockés dans le stockage des conteneurs. Ces conteneurs externes sont généralement créés via d'autres technologies de conteneurisation comme Buildah ou CRI-O et peuvent dépendre des mêmes images de conteneur que Podman utilise également. Les conteneurs externes sont indiqués par 'buildah' ou 'storage' dans la colonne COMMAND et STATUS de la sortie ps.

--filter, -f

Filtrer les conteneurs affichés dans la sortie. Plusieurs filtres peuvent être donnés en utilisant plusieurs fois l'option --filter. Les filtres avec la même clé fonctionnent de manière inclusive à l'exception de label qui est exclusive. Les filtres avec des clés différentes fonctionnent toujours de manière exclusive.

Les filtres valides sont listés ci-dessous :

Filtre Description
id [ID] ID du conteneur (correspondance de préfixe CID par défaut ; accepte les regex)
name [Nom] Nom du conteneur (accepte les regex)
label [Clé] ou [Clé=Valeur] Étiquette attribuée à un conteneur
label! [Clé] ou [Clé=Valeur] Étiquette NON attribuée à un conteneur
exited [Int] Code de sortie du conteneur
status [Statut] Statut du conteneur : 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NomImage] Image ou descendant utilisé pour créer le conteneur (accepte les regex)
before [ID] ou [Nom] Conteneurs créés avant ce conteneur
since [ID] ou [Nom] Conteneurs créés depuis ce conteneur
volume [NomVolume] ou [PointMontageDestination] Volume monté dans le conteneur
health [Statut] healthy ou unhealthy
pod [Pod] nom ou ID complet ou partiel du pod
network [Réseau] nom ou ID complet du réseau
until [DateTime] conteneur créé avant la durée ou l'heure donnée.
command [Commande] la commande exécutée par le conteneur, seul argv[0] est pris en compte

--format=format

Afficher joliment les conteneurs au format JSON ou à l'aide d'un modèle Go

Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Espace réservé Description
.AutoRemove Si vrai, les conteneurs sont supprimés à la sortie
.CIDFile Fichier d'identifiant de conteneur
.Command Commande citée utilisée
.Created ... Heure de création du conteneur, A-M-J H:M:S
.CreatedAt Heure de création du conteneur (identique à ci-dessus)
.CreatedHuman Heure de création, relative
.ExitCode Code de sortie du conteneur
.Exited "true" si le conteneur est sorti
.ExitedAt Heure (secondes depuis l'époque) où le conteneur est sorti
.ExposedPorts ... Carte des ports exposés sur ce conteneur
.ID ID du conteneur
.Image Nom/ID de l'image
.ImageID ID de l'image
.IsInfra "true" si conteneur infra
.Label string Étiquette spécifiée du conteneur
.Labels ... Toutes les étiquettes attribuées au conteneur
.Mounts Volumes montés dans le conteneur
.Names Nom du conteneur
.Networks Afficher tous les réseaux connectés au conteneur
.Pid Identifiant de processus sur le système hôte
.Pod Pod auquel le conteneur est associé (SHA)
.PodName Nom du pod du conteneur
.Ports Ports redirigés et exposés
.Restarts Afficher le nombre de redémarrages du conteneur
.RunningFor Temps écoulé depuis le démarrage du conteneur
.Size Taille du conteneur
.StartedAt Heure (secondes depuis l'époque) où le conteneur a démarré
.State Description conviviale de l'état du conteneur
.Status Statut du conteneur

--help, -h

Afficher l'énoncé d'utilisation

--last, -n

Afficher les n derniers conteneurs créés (tous les états)

--latest, -l

Afficher le dernier conteneur créé (tous les états) (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (à l'exception de WSL2))

--namespace, --ns

Afficher les informations sur l'espace de noms

--no-trunc

Ne pas tronquer la sortie (par défaut false).

--noheading

Omettre les en-têtes de tableau de la liste des conteneurs.

--pod, -p

Afficher les pods auxquels les conteneurs sont associés

--quiet, -q

Afficher uniquement les identifiants numériques des conteneurs

--size, -s

Afficher la taille totale du fichier

--sort=created

Trier par commande, créé, id, image, noms, runningfor, taille, ou statut", Note : Choisir taille trie par la taille de rootFs, pas alphabétiquement comme les autres options

--sync

Forcer une synchronisation de l'état du conteneur avec le runtime OCI. Dans certains cas, l'état d'un conteneur dans le runtime peut devenir désynchronisé par rapport à l'état de Podman. Ceci met à jour l'état de Podman en fonction de ce que rapporte le runtime OCI. La synchronisation forcée est beaucoup plus lente, mais peut résoudre les problèmes d'état incohérents.

--watch, -w

Actualiser la sortie avec les conteneurs actuels à un intervalle en secondes.

EXEMPLES

Lister les conteneurs en cours d'exécution.

$ podman ps
CONTAINER ID  IMAGE                            COMMAND    CREATED        STATUS        PORTS                                                   NAMES
4089df24d4f

NOM

podman-container-ps - List containers

SYNOPIS

podman container ps [options]

podman ps [options]

DESCRIPTION

Le utilitaire podman ps liste les conteneurs qui s'exécutent sur votre machine hôte. Par défaut, seul un sous-ensemble des conteneurs en cours d'exécution est affiché. Vous pouvez modifier ce comportement avec des options.

OPTIONS

--all, -a

Afficher tous les conteneurs (par défaut, seuls les conteneurs en cours d'exécution sont affichés).

--cidfilters, --filter=cidfile

Filtre la sortie pour inclure uniquement les conteneurs dont le nom ou l'ID correspond à la valeur spécifiée. Les formats courants incluent les ID des conteneurs, les noms des conteneurs, les noms des conteneurs du pod, les noms des conteneurs créés par des outils externes, les étiquettes et le statut du conteneur. Plusieurs filtres peuvent être spécifiés en utilisant plusieurs occurrences de --filter.

Exemples:

  • --filter pod=web-pod : répertorie les conteneurs appartenant au pod nommé web-pod.
  • --filter status=running : répertorie les conteneurs dont le statut est running.
  • --filter name=webserver : répertorie les conteneurs nommés webserver.
  • --filter label=app=frontend : répertorie les conteneurs avec l'étiquette app=frontend.
  • --filter volume=mydata : répertorie les conteneurs qui utilisent le volume mydata.
  • --filter network=web-net : répertorie les conteneurs connectés au réseau web-net.

--format=format

Utiliser une sortie Go template pour formater la sortie. Les valeurs valides incluent {{.ID}}, {{.Image}}, {{.Command}}, {{.Labels}}, {{.Mounts}}, {{.Names}}, {{.Pod}}, {{.PodName}}, {{.Ports}}, {{.RunningFor}}, {{.Size}}, {{.State}}, {{.Status}}, {{.Volume}}.

--last, -l

Afficher le dernier conteneur créé (qui peut être en cours d'exécution ou arrêté).

--latest

Afficher le dernier conteneur créé (qui peut être en cours d'exécution ou arrêté). L'option --latest est un alias de l'option -l.

--no-trunc

Ne pas tronquer la sortie.

--pod

Afficher le nom du pod dont fait partie le conteneur.

--size

Afficher la taille totale du système de fichiers des conteneurs.

--sort=critère

Trier la sortie. Les valeurs valides incluent `command`, `created`, `id`, `image`, `names`, `status`, `pod`, `podname`, `size`.

--external

Afficher les conteneurs externes (créés par des outils autres que Podman).

--ns

Inclure les informations sur les espaces de noms dans la sortie.
