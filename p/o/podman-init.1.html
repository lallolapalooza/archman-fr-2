NOM

podman-init - Initialise un ou plusieurs conteneurs

SYNTAXE

podman init [options] conteneur [conteneur...]

podman container init [options] conteneur [conteneur...]

DESCRIPTION

Initialise un ou plusieurs conteneurs. Vous pouvez utiliser les ID ou les noms de conteneurs en entrée. L'initialisation d'un conteneur effectue toutes les tâches nécessaires pour démarrer le conteneur (montage des systèmes de fichiers, création d'un fichier de spécification OCI, initialisation du réseau du conteneur) mais ne démarre pas le conteneur. Si un conteneur n'est pas initialisé, les commandes podman start et podman run l'initialisent automatiquement avant de le démarrer. Cette commande est destinée à être utilisée pour inspecter le système de fichiers d'un conteneur ou sa spécification OCI avant de le démarrer. Cela peut être utilisé pour inspecter le conteneur avant son exécution, ou pour déboguer pourquoi un conteneur ne parvient pas à s'exécuter.

OPTIONS

--all, -a

Initialise tous les conteneurs. Les conteneurs qui ont déjà été initialisés (y compris les conteneurs qui ont été démarrés et sont en cours d'exécution) sont ignorés.

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utilise le dernier conteneur créé. Note : le dernier conteneur démarré peut appartenir à d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (sauf WSL2))

EXEMPLES

Initialiser le conteneur spécifié avec un ID donné.

$ podman init 35480fc9d568

Initialiser le conteneur spécifié avec un nom donné.

$ podman init test1

Initialiser le dernier conteneur. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (sauf WSL2))

$ podman init --latest

Initialiser tous les conteneurs.

$ podman init --all
