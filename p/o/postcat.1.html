POSTCAT(1) Manuel des commandes générales POSTCAT(1)

NOM

postcat - afficher le contenu des fichiers de la file d'attente Postfix

SYNTAXE

postcat [-bdefhnoqv] [-c rép_config] [fichiers...]

DESCRIPTION


La commande postcat(1) imprime le contenu des fichiers nommés sous une forme lisible par l'homme. Les fichiers sont attendus au format des fichiers de la file d'attente Postfix. Si aucun fichier n'est spécifié sur la ligne de commande, le programme lit depuis l'entrée standard.

Par défaut, postcat(1) affiche l'enveloppe et le contenu du message, comme si les options -beh étaient spécifiées. Pour afficher uniquement le contenu du message, spécifiez -bh (Postfix 2.7 et versions ultérieures).

Options:

-b
Afficher le contenu du corps. L'option -b commence à produire la sortie à la première ligne non-en-tête et s'arrête à la fin du message.

Cette fonctionnalité est disponible dans Postfix 2.7 et versions ultérieures.

-c rép_config
Le fichier de configuration main.cf se trouve dans le répertoire nommé au lieu du répertoire de configuration par défaut.
-d
Afficher le type décimal de chaque enregistrement.
-e
Afficher le contenu de l'enveloppe du message.

Cette fonctionnalité est disponible dans Postfix 2.7 et versions ultérieures.

-f
Ajouter le nom du fichier au début de chaque ligne de sortie.

Cette fonctionnalité est disponible dans Postfix 3.10 et versions ultérieures.

-h
Afficher le contenu de l'en-tête du message. L'option -h produit une sortie depuis le début du message jusqu'à, mais sans inclure, la première ligne non-en-tête.

Cette fonctionnalité est disponible dans Postfix 2.7 et versions ultérieures.

-o
Afficher le décalage du fichier de file d'attente de chaque enregistrement.
-q
Rechercher dans la file d'attente Postfix les fichiers nommés au lieu de prendre les noms littéralement.

Cette fonctionnalité est disponible dans Postfix 2.0 et versions ultérieures.

-r
Afficher les enregistrements dans l'ordre du fichier, ne pas suivre les enregistrements pointeurs.

Cette fonctionnalité est disponible dans Postfix 3.7 et versions ultérieures.

-s décalage
Sauter jusqu'au décalage spécifié du fichier de file d'attente.

Cette fonctionnalité est disponible dans Postfix 3.7 et versions ultérieures.

-v
Activer la journalisation détaillée à des fins de débogage. Plusieurs options -v rendent le logiciel de plus en plus verbeux.

DIAGNOSTICS


Les problèmes sont signalés sur le flux d'erreurs standard.

ENVIRONNEMENT

MAIL_CONFIG
Répertoire contenant les fichiers de configuration Postfix.

PARAMETRES DE CONFIGURATION

Les paramètres main.cf suivants sont particulièrement pertinents pour ce programme.

Le texte ci-dessous ne fournit qu'un résumé des paramètres. Voir postconf(5) pour plus de détails, y compris des exemples.

config_directory (voir la sortie de 'postconf -d')
L'emplacement par défaut des fichiers de configuration main.cf et master.cf de Postfix.
import_environment (voir la sortie de 'postconf -d')
La liste des variables d'environnement qu'un processus Postfix privilégié importera d'un processus parent non-Postfix, ou des remplacements d'environnement nom=valeur.
queue_directory (voir la sortie de 'postconf -d')
L'emplacement du répertoire de la file d'attente principale de Postfix.

FICHIERS

/var/spool/postfix, répertoire de la file d'attente Postfix
