NOM

po4a-normalize - normalise un fichier de documentation en le parsant avec po4a, et le réécrit

SYNTAXE

po4a-normalize -f fmt master.doc

DESCRIPTION

L'objectif du projet po4a (PO pour tout) est de faciliter les traductions (et plus intéressant encore, la maintenance des traductions) en utilisant les outils gettext sur des domaines où ils n'étaient pas attendus, comme la documentation.

Le script po4a-normalize est un outil de débogage utilisé pour s'assurer que po4a ne modifie pas le document lorsqu'il ne le devrait pas. Ne l'utilisez que si vous développez un nouveau module, ou si vous doutez de la cohérence des outils.

Le document généré sera écrit dans po4a-normalize.output tandis que le fichier POT généré sera écrit dans po4a-normalize.po par défaut, mais vous pouvez utiliser les options --localized et --pot pour changer cela.

OPTIONS

-o, --option
Option(s) supplémentaire(s) à passer au plugin de format. Voir la documentation de chaque plugin pour plus d'informations sur les options valides et leur signification. Par exemple, vous pourriez passer '-o tablecells' au parseur AsciiDoc, tandis que le parseur texte accepterait '-o tabs=split'.
-w, --width
Colonne à laquelle nous devrions renvoyer le fichier résultant si le format le prend en charge (défaut : 76). Si la valeur fournie est 0 ou négative, alors le fichier résultant ne sera pas renvoyé. Ceci est utile avec certains formats qui pourraient être cassés lors d'un renvoi.
-b, --blank
Crée un document traduit vide. Le document traduit généré sera produit en supposant que tous les messages sont traduits par un espace ou une nouvelle ligne.

Ceci est utile pour vérifier quelles parties du document ne peuvent pas être traduites.

Les options --blank et --capitalize ne peuvent pas être spécifiées en même temps.

-C, --capitalize
Crée un document traduit et un fichier po correspondant avec les chaînes originales traduites en leurs versions capitalisées.

Ceci est utile pour vérifier quelles parties du document ne peuvent pas être traduites et générer des données de test pour po4a.

Les options --blank et --capitalize ne peuvent pas être spécifiées en même temps.

-h, --help
Affiche un court message d'aide.
--help-format
Liste les formats de documentation compris par po4a.
-f, --format
Format de la documentation que vous souhaitez traiter. Utilisez l'option --help-format pour voir la liste des formats disponibles.
-M, --master-charset
Jeu de caractères du fichier contenant le document à traduire.
-l, --localized
Nom du fichier normalisé à produire (po4a-normalize.output par défaut).
-p, --pot
Fichier Pot à produire (po4a-normalize.po par défaut).
-V, --version
Affiche la version du script et quitte.
