NOM

podman-export - Exporter le contenu du système de fichiers d'un conteneur sous forme d'archive tar

SYNTAXE

podman export [options] conteneur

podman container export [options] conteneur

DESCRIPTION

podman export exporte le système de fichiers d'un conteneur et l'enregistre sous forme d'archive tar sur la machine locale. podman export écrit sur la sortie standard (STDOUT) par défaut et peut être redirigé vers un fichier à l'aide de l'option --output. L'image du conteneur exportée par podman export peut être importée par podman import. Pour exporter des images avec des couches parentes, utilisez podman save. Remarque : : est un caractère restreint et ne peut pas faire partie du nom de fichier.

podman [OPTIONS GLOBALES]

podman export [OPTIONS GLOBALES]

podman export [OPTIONS] CONTENEUR

OPTIONS

--help, -h

Afficher le message d'utilisation

--output, -o

Écrire dans un fichier, la valeur par défaut est STDOUT

EXEMPLES

Exporter un conteneur dans un fichier tar spécifié :

$ podman export -o redis-container.tar 883504668ec465463bc0fe7e63d53154ac3b696ea8d7b233748918664ea90e57

Exporter un conteneur vers la sortie standard :

$ podman export 883504668ec465463bc0fe7e63d53154ac3b696ea8d7b233748918664ea90e57 > redis-container.tar
