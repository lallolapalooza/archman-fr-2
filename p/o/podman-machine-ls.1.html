NOM

podman-machine-list - Lister les machines virtuelles

SYNOPSIS

podman machine list [options]

podman machine ls [options]

DESCRIPTION

Lister les machines virtuelles gérées par Podman.

Podman sur MacOS et Windows nécessite une machine virtuelle. Ceci est dû au fait que les conteneurs sont basés sur Linux - les conteneurs ne fonctionnent pas sur d'autres systèmes d'exploitation car leurs fonctionnalités de base sont liées au noyau Linux. Podman machine doit être utilisé pour gérer les machines MacOS et Windows, mais peut être utilisé optionnellement sous Linux.

Seulement sans privilèges root (rootless).

NOTE : Le fichier de configuration de podman-machine est géré dans le répertoire $XDG_CONFIG_HOME/containers/podman/machine/. Modifier la variable d'environnement $XDG_CONFIG_HOME pendant que les machines sont en cours d'exécution peut entraîner un comportement inattendu. (voir podman(1))

OPTIONS

--all-providers

Afficher les machines de tous les fournisseurs

--format=format

Modifier le format de sortie par défaut. Il peut s'agir d'un type supporté comme 'json' ou d'un template Go. Les espaces réservés valides pour le template Go sont listés ci-dessous :

Placeholder Description
.CPUs Nombre de CPUs
.Created Temps écoulé depuis la création de la VM
.Default Est la machine par défaut
.DiskSize Taille du disque de la machine
.IdentityPath Chemin vers le fichier d'identité ssh
.LastUp Temps écoulé depuis le dernier démarrage de la VM
.Memory Mémoire allouée pour la machine
.Name Nom de la VM
.Port Port SSH à utiliser pour se connecter à la VM
.RemoteUsername Nom d'utilisateur de la VM pour Podman sans privilèges root
.Running La machine est-elle en cours d'exécution
.Stream Nom du flux
.Swap Swap alloué pour la machine
.UserModeNetworking La machine utilise-t-elle le réseau en mode utilisateur
.VMType Type de VM

--help

Afficher le message d'utilisation.

--noheading, -n

Omettre les en-têtes du tableau de la liste.

--quiet, -q

Afficher uniquement le nom de la machine. Cela implique également qu'aucun en-tête de tableau ne soit imprimé.

EXEMPLES

Lister toutes les machines Podman.

$ podman machine list
NAME                    VM TYPE     CREATED      LAST UP      CPUS        MEMORY      DISK SIZE
podman-machine-default  qemu        2 weeks ago  2 weeks ago  1           2.147GB     10.74GB

Lister toutes les machines Podman en utilisant le format de tableau spécifié.

$ podman machine ls --format "table {{.Name}}\t{{.VMType}}\t{{.Created}}\t{{.LastUp}}"
NAME                    VM TYPE     CREATED      LAST UP
podman-machine-default  qemu        2 weeks ago  2 weeks ago

Lister toutes les machines Podman au format json.

$ podman machine ls --format json
[
    {
        "Name": "podman-machine-default",
        "Default": false,
        "Created": "2021-12-27T10:36:14.373347492-05:00",
        "Running": false,
        "LastUp": "2021-12-27T11:22:50.17333371-05:00",
        "Stream": "default",
        "VMType": "qemu",
        "CPUs": 1,
        "Memory": "2147483648",
        "DiskSize": "10737418240"
    }
]
