POSTDROP(1) Manuel des commandes générales POSTDROP(1)

NOM

postdrop - utilitaire de dépôt de courrier Postfix

SYNTAXE

postdrop [-rv] [-c config_dir]

DESCRIPTION


La commande postdrop(1) crée un fichier dans le répertoire maildrop et y copie son entrée standard.

Options :

-c config_dir
Le fichier de configuration main.cf se trouve dans le répertoire nommé au lieu du répertoire de configuration par défaut. Voir également le paramètre d'environnement MAIL_CONFIG ci-dessous.
-r
Utilise un protocole interne à Postfix pour lire le message depuis l'entrée standard, et pour rapporter les informations de statut sur la sortie standard. C'est actuellement la seule méthode supportée.
-v
Active la journalisation verbeuse à des fins de débogage. Plusieurs options -v rendent le logiciel de plus en plus verbeux. Depuis Postfix 2.3, cette option n'est disponible que pour le super-utilisateur.

SÉCURITÉ

La commande est conçue pour s'exécuter avec les privilèges set-group ID, afin qu'elle puisse écrire dans le répertoire de file d'attente maildrop et qu'elle puisse se connecter aux processus démon Postfix.

DIAGNOSTICS


Erreurs fatales : entrée mal formée, erreur d'E/S, manque de mémoire. Les problèmes sont enregistrés dans syslogd(8) ou postlogd(8) et dans le flux d'erreur standard. Lorsque l'entrée est incomplète, ou lorsque le processus reçoit un signal HUP, INT, QUIT ou TERM, le fichier de la file d'attente est supprimé.

ENVIRONNEMENT

MAIL_CONFIG
Répertoire contenant le fichier main.cf. Afin d'éviter l'exploitation des privilèges set-group ID, un répertoire non standard est autorisé uniquement si :
  • Le nom est listé dans le fichier main.cf standard avec le paramètre de configuration alternate_config_directories.
  • La commande est invoquée par le super-utilisateur.

PARAMÈTRES DE CONFIGURATION

Les paramètres main.cf suivants sont particulièrement pertinents pour ce programme. Le texte ci-dessous ne fournit qu'un résumé des paramètres. Voir postconf(5) pour plus de détails, y compris des exemples.

alternate_config_directories (vide)
Une liste de répertoires de configuration Postfix non par défaut qui peuvent être spécifiés avec "-c chemin_config" sur la ligne de commande (dans le cas de sendmail(1), avec l'option "-C"), ou via le paramètre d'environnement MAIL_CONFIG.
config_directory (voir la sortie de 'postconf -d')
L'emplacement par défaut des fichiers de configuration main.cf et master.cf de Postfix.
import_environment (voir la sortie de 'postconf -d')
La liste des variables d'environnement qu'un processus Postfix privilégié importera d'un processus parent non-Postfix, ou des remplacements nom=valeur d'environnement.
queue_directory (voir la sortie de 'postconf -d')
L'emplacement du répertoire de file d'attente de niveau supérieur de Postfix.
syslog_facility (mail)
La facilité syslog de la journalisation Postfix.
syslog_name (voir la sortie de 'postconf -d')
Un préfixe qui est ajouté au nom du processus dans les enregistrements syslog, de sorte que, par exemple, "smtpd" devienne "préfixe/smtpd".
trigger_timeout (10s)
La limite de temps pour envoyer un déclencheur à un démon Postfix (par exemple, le démon pickup(8) ou qmgr(8)).

Disponible dans Postfix version 2.2 et ultérieures :

authorized_submit_users (statique:quiconque)
Liste des utilisateurs autorisés à soumettre du courrier avec la commande sendmail(1) (et avec la commande auxiliaire privilégiée postdrop(1)).

Disponible dans Postfix version 3.6 et ultérieures :

local_login_sender_maps (statique:*)
Liste des tables de recherche qui sont recherchées par le nom de connexion UNIX, et qui renvoient une liste de modèles d'expéditeur d'enveloppe autorisés séparés par un espace ou une virgule.
empty_address_local_login_sender_maps_lookup_key (<>)
La clé de recherche à utiliser dans les tables local_login_sender_maps, au lieu de l'adresse d'expéditeur nulle.
recipient_delimiter (vide)
L'ensemble des caractères qui peuvent séparer la partie locale d'une adresse e-mail, le nom d'utilisateur, ou le nom d'un fichier .forward de son extension.
