NOM

podman-image-diff - Inspecter les modifications du système de fichiers d'une image

SYNTAXE

podman image diff [options] image [image]

DESCRIPTION

Affiche les modifications apportées au système de fichiers d'une image. L'image est comparée à sa couche parente ou au second argument s'il est fourni.

La sortie est préfixée par les symboles suivants :

Symbole Description
A Un fichier ou un répertoire a été ajouté.
D Un fichier ou un répertoire a été supprimé.
C Un fichier ou un répertoire a été modifié.

OPTIONS

--format

Modifie la sortie dans un format différent. Le seul format valide pour podman image diff est json.

EXEMPLES

Afficher les différences d'image par rapport à la couche parente de l'image :

$ podman image diff redis:old
C /usr
C /usr/local
C /usr/local/bin
A /usr/local/bin/docker-entrypoint.sh

Afficher les différences d'image entre deux images différentes au format JSON :

$ podman image diff --format json redis:old redis:alpine
{
  "changed": [
    "/usr",
    "/usr/local",
    "/usr/local/bin"
  ],
  "added": [
    "/usr/local/bin/docker-entrypoint.sh"
  ]
}
