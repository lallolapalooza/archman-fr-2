NOM

podman-secret-create - Créer un nouveau secret

SYNTAXE

podman secret create [options] nom fichier|-

DESCRIPTION

Crée un secret en utilisant l'entrée standard ou à partir d'un fichier pour le contenu du secret.

Create accepte un chemin vers un fichier, ou -, ce qui indique à podman de lire le secret depuis stdin.

Un secret est un blob de données sensibles dont un conteneur a besoin au moment de l'exécution mais qui n'est pas stocké dans l'image ou dans le contrôle de source, comme les noms d'utilisateur et les mots de passe, les certificats et clés TLS, les clés SSH ou d'autres chaînes importantes génériques ou contenu binaire (jusqu'à 512 Ko).

Les secrets ne sont pas validés dans une image avec podman commit, et ne sont pas validés dans l'archive créée par une commande podman export.

Les secrets peuvent également être utilisés pour stocker des mots de passe pour que podman login s'authentifie auprès des registres de conteneurs.

OPTIONS

--driver, -d=driver

Spécifie le pilote de secret (par défaut file).

--driver-opts=key1=val1,key2=val2

Spécifie les options spécifiques au pilote.

--env=false

Lit les données secrètes à partir d'une variable d'environnement.

--help

Affiche le message d'utilisation.

--ignore=false

Si un secret du même nom existe déjà, ne renvoie pas d'erreur et renvoie l'ID du secret existant au lieu d'en créer un nouveau. Ne peut pas être utilisé avec --replace. Par défaut, la valeur est false.

--label, -l=key=val1,key2=val2

Ajoute une étiquette au secret. Ces étiquettes peuvent être consultées dans podman secret inspect ou ls.

--replace=false

Si un secret existant du même nom existe déjà, met à jour le secret. L'option --replace ne modifie pas les secrets des conteneurs existants, seulement ceux des conteneurs nouvellement créés. Ne peut pas être utilisé avec --ignore.
Par défaut, la valeur est false.

PILOTES DE SECRETS

file

Le secret réside dans un fichier protégé en lecture.

pass

Le secret réside dans un fichier crypté GPG.

shell

Le secret est géré par des scripts personnalisés. Une variable d'environnement SECRET_ID est passée aux scripts (sauf pour list), et les secrets sont communiqués via stdin/stdout (lorsque applicable). Les options de pilote list, lookup, store, et delete servent à installer les scripts :

[secrets]
driver = "shell"
[secrets.opts]
list =
lookup =
store =
delete =

EXEMPLES

Crée le secret spécifié basé sur un fichier local.

echo -n mysecret > ./secret.txt
$ podman secret create my_secret ./secret.txt

Crée le secret spécifié via stdin.

$ printf <secret> | podman secret create my_secret -

Crée ou fait pivoter un secret aléatoire cryptographiquement sécurisé juste en dessous du maximum de 512000 octets via stdin.

openssl rand -base64 378000 | podman secret create --replace my_secret -

Monte un secret basé sur un fichier local de manière sécurisée dans un conteneur.

podman run --rm --secret source=my_secret,type=mount,uid=1001,gid=1001,mode=440 docker.io/library/alpine ls -l /run/secrets/my_secret

Crée un secret crypté gpg basé sur un fichier local en utilisant le pilote pass.

$ podman secret create --driver=pass my_secret ./secret.txt.gpg

Crée un secret à partir d'une variable d'environnement appelée 'MYSECRET'.

$ podman secret create --env=true my_secret MYSECRET
