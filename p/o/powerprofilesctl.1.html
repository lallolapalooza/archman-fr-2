POWERPROFILESCTL(1) Programme de contrôle du démon des profils d'alimentation POWERPROFILESCTL(1)

NOM

powerprofilesctl - Utilitaire en ligne de commande pour contrôler le démon des profils d'alimentation

SYNTAXE

powerprofilesctl [-h] {list,list-holds,list-actions,get,set,configure-action,configure-battery-aware,query-battery-aware,launch,version} ...

ARGUMENTS POSITIONNELS

powerprofilesctl list

Lister les profils d'alimentation disponibles

utilisation : powerprofilesctl list [-h]

powerprofilesctl list-holds

Lister les blocages de profil d'alimentation actuels

utilisation : powerprofilesctl list-holds [-h]

powerprofilesctl list-actions

Lister les actions de profil d'alimentation disponibles

utilisation : powerprofilesctl list-actions [-h]

powerprofilesctl get

Afficher le profil d'alimentation actuellement actif

utilisation : powerprofilesctl get [-h]

powerprofilesctl set

Définir le profil d'alimentation actuellement actif

utilisation : powerprofilesctl set [-h] {}

arguments :

{}
Profil à utiliser pour la commande set

powerprofilesctl configure-action

Configurer l'action à entreprendre pour le profil

utilisation : powerprofilesctl configure-action [-h] [--enable] [--disable] action

arguments :

action
action à modifier pour configure-action

options :

--enable
activer l'action
--disable
désactiver l'action

powerprofilesctl configure-battery-aware

Activer ou désactiver les changements dynamiques en fonction du niveau de la batterie ou de l'adaptateur secteur

utilisation : powerprofilesctl configure-battery-aware [-h] [--enable] [--disable]

options :

--enable
activer la détection de batterie
--disable
désactiver la détection de batterie

powerprofilesctl query-battery-aware

Interroger si les changements dynamiques basés sur le niveau de la batterie ou l'adaptateur secteur sont activés

utilisation : powerprofilesctl query-battery-aware [-h]

powerprofilesctl launch

Lancer une commande tout en maintenant un profil d'alimentation

utilisation : powerprofilesctl launch [-h] [--profile PROFILE] [--reason REASON]
[--appid APPID]
[arguments ...]

Lance la commande tout en maintenant un profil d'alimentation, soit performance, soit économie d'énergie. Par défaut, le blocage de profil concerne le profil de performance, mais il peut ne pas être disponible sur tous les systèmes. Voir la commande list pour une liste des profils disponibles.

arguments :

arguments
Commande à lancer

options :

--profile PROFIL, -p PROFIL
Profil à utiliser pour la commande launch
--reason RAISON, -r RAISON
Raison à utiliser pour la commande launch
--appid APPID, -i APPID
AppId à utiliser pour la commande launch

powerprofilesctl version

Afficher les informations de version et quitter

utilisation : powerprofilesctl version [-h]

COMMENTAIRES

Utilisez “powerprofilesctl COMMAND --help” pour obtenir de l'aide détaillée sur les commandes individuelles
