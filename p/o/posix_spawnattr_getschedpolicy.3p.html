POSIX_SPAWNATTR_GETSCHEDPOLICY(3P) Manuel du programmeur POSIX POSIX_SPAWNATTR_GETSCHEDPOLICY(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_spawnattr_getschedpolicy, posix_spawnattr_setschedpolicy — obtenir et définir la politique d'ordonnancement de création (spawn-schedpolicy) d'un objet d'attributs de création (TEMPS RÉEL AVANCÉ)

SYNTAXE

#include <spawn.h>
#include <sched.h>
int posix_spawnattr_getschedpolicy(const posix_spawnattr_t
    *restrict attr, int *restrict schedpolicy);
int posix_spawnattr_setschedpolicy(posix_spawnattr_t *attr,
    int schedpolicy);

DESCRIPTION

La fonction posix_spawnattr_getschedpolicy() obtient la valeur de l'attribut spawn-schedpolicy de l'objet d'attributs référencé par attr.

La fonction posix_spawnattr_setschedpolicy() définit l'attribut spawn-schedpolicy dans un objet d'attributs initialisé référencé par attr.

L'attribut spawn-schedpolicy représente la politique d'ordonnancement à attribuer à la nouvelle image de processus dans une opération de création (si POSIX_SPAWN_SETSCHEDULER est défini dans l'attribut spawn-flags). La valeur par défaut de cet attribut n'est pas spécifiée.

VALEUR DE RETOUR

En cas de succès, posix_spawnattr_getschedpolicy() retourne zéro et stocke la valeur de l'attribut spawn-schedpolicy de attr dans l'objet référencé par le paramètre schedpolicy ; sinon, un numéro d'erreur est retourné pour indiquer l'erreur.

En cas de succès, posix_spawnattr_setschedpolicy() retourne zéro ; sinon, un numéro d'erreur est retourné pour indiquer l'erreur.

ERREURS

Ces fonctions peuvent échouer si :

EINVAL
La valeur spécifiée par attr est invalide.

La fonction posix_spawnattr_setschedpolicy() peut échouer si :

EINVAL
La valeur de l'attribut défini n'est pas valide.
