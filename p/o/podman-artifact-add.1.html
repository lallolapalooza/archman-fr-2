NOM

podman-artifact-add - Ajouter un artefact OCI au magasin d'artefacts local

SYNTAXE

podman artifact add [options] nom-artefact fichier [fichier ...]

DESCRIPTION

Ajoute un artefact OCI au magasin local depuis le système de fichiers local. Vous devez fournir au moins un fichier pour créer l'artefact, mais plusieurs peuvent également être ajoutés.

Les artefacts incluent automatiquement un horodatage de création dans l'annotation org.opencontainers.image.created au format RFC3339Nano. Lors de l'utilisation de l'option --append, l'horodatage de création original est préservé.

OPTIONS

--annotation=annotation=valeur

Définit une annotation sur l'entrée pour l'image ou l'artefact spécifié.

Note : Définissez les annotations pour chaque fichier ajouté. L'annotation "org.opencontainers.image.title" est utilisée pour nommer la couche lorsqu'elle est montée dans un conteneur, ce titre doit être unique pour chaque couche d'artefact.

--append, -a

Ajoute des fichiers à un artefact existant. Cette option ne peut pas être utilisée avec l'option --type.

--file-type

Définit le type de média du fichier artefact au lieu de laisser la détection déterminer le type.

--help

Affiche l'énoncé d'utilisation.

--replace

Si un artefact du même nom existe déjà, le remplace et le supprime. La valeur par défaut est false. Cette option ne peut pas être utilisée avec l'option --append.

--type

Définit un type pour l'artefact ajouté.

EXEMPLES

Ajouter un seul fichier à un artefact

$ podman artifact add quay.io/myartifact/myml:latest /tmp/foobar.ml
0fe1488ecdef8cc4093e11a55bc048d9fc3e13a4ba846efd24b5a715006c95b3

Ajouter un artefact OCI au magasin avec un type :

$ podman artifact add --artifact-type application/com.example.ai --file-type application/vnd.gguf quay.io/myimage/myartifact:latest /home/user/model.gguf

Remplacer un artefact existant du même nom

$ podman artifact add quay.io/myartifact/myml:latest /tmp/foobar.ml
0fe1488ecdef8cc4093e11a55bc048d9fc3e13a4ba846efd24b5a715006c95b3

Ajouter plusieurs fichiers à un artefact

$ podman artifact add quay.io/myartifact/myml:latest /tmp/foobar1.ml /tmp/foobar2.ml
1487acae11b5a30948c50762882036b41ac91a7b9514be8012d98015c95ddb78

Ajouter des fichiers à un artefact OCI existant

$ podman artifact add --append quay.io/myimage/myartifact:latest /home/user/config.yaml

Créer un artefact avec le nom du titre de couche remplacé, puis le monter dans un conteneur.

podman artifact add --annotation org.opencontainers.image.title=smollm2 quay.io/myreg/smollm2:latest blobs/sha256-4d2396b16114669389d7555c15a1592aad584750310f648edad5ca8c4eccda17
podman run --mount type=artifact,source=quay.io/myreg/smollm2:latest,destination=/mnt fedora ls -l /mnt
smollm2
