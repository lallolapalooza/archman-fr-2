PODCHECKER(1perl) Guide de référence des programmeurs Perl PODCHECKER(1perl)

NOM

podchecker — vérifie la syntaxe des fichiers de documentation au format POD

SYNTAXE

podchecker [-help] [-man] [-(no)warnings] [fichier ...]

OPTIONS ET ARGUMENTS

-help
Affiche un bref message d'aide et quitte.
-man
Affiche la page de manuel et quitte.
-quiet
N'affiche pas de message de succès.
-warnings -nowarnings
Active/désactive l'affichage des avertissements. Répéter -warnings augmente le niveau d'avertissement, c'est-à-dire que plus d'avertissements sont affichés. Actuellement, passer au niveau deux signale les caractères "<,>" non échappés.
fichier
Le chemin d'accès à un fichier POD à vérifier syntaxiquement (par défaut, l'entrée standard).

DESCRIPTION

podchecker lit les fichiers d'entrée spécifiés à la recherche d'erreurs de syntaxe POD dans la documentation et affiche toutes les erreurs trouvées sur STDERR. À la fin, il affiche un message d'état indiquant le nombre d'erreurs trouvées.

Les répertoires sont ignorés, un message d'avertissement approprié est affiché.

podchecker appelle la fonction podchecker() exportée par Pod::Checker. Veuillez consulter "podchecker()" dans Pod::Checker pour plus de détails.

VALEUR DE RETOUR

podchecker renvoie un code de sortie de 0 (zéro) si tous les fichiers POD spécifiés sont corrects.

ERREURS

podchecker renvoie le code de sortie 1 si au moins l'un des fichiers POD donnés contient des erreurs de syntaxe.

Le code 2 indique qu'au moins l'un des fichiers spécifiés ne contient *aucune* commande POD.

Le code 1 remplace le code 2. Si vous souhaitez des résultats non ambigus, appelez podchecker avec un seul argument.

VOIR AUSSI

Pod::Simple et Pod::Checker
