CPORFSX

But :

!>
!>    CPORFSX améliore la solution calculée d'un système d'équations linéaires
!>    dont la matrice des coefficients est hermitienne définie positive, et fournit des bornes d'erreur et des estimations d'erreur arrière
!>    pour la solution. En plus de la borne d'erreur globale, le code
!>    fournit une borne d'erreur composante maximale si possible. Voir
!>    les commentaires pour ERR_BNDS_NORM et ERR_BNDS_COMP pour les détails des
!>    bornes d'erreur.
!>
!>    Le système d'équations linéaires d'origine peut avoir été équilibré
!>    avant d'appeler cette routine, comme décrit par les arguments EQUED et S
!>    ci-dessous. Dans ce cas, la solution et les bornes d'erreur renvoyées sont
!>    pour le système déséquilibré d'origine.
!> 
!>     Certains paramètres optionnels sont regroupés dans le tableau PARAMS. Ces
!>     paramètres déterminent comment le raffinement est effectué, mais souvent les
!>     valeurs par défaut sont acceptables. Si les valeurs par défaut sont acceptables, les utilisateurs
!>     peuvent passer NPARAMS = 0, ce qui empêche le code source d'accéder
!>     à l'argument PARAMS.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>       = 'U' : Le triangle supérieur de A est stocké ;
!>       = 'L' : Le triangle inférieur de A est stocké.
!>

EQUED

!>          EQUED est CHARACTER*1
!>     Spécifie la forme d'équilibrage qui a été effectuée sur A
!>     avant d'appeler cette routine. Ceci est nécessaire pour calculer
!>     la solution et les bornes d'erreur correctement.
!>       = 'N' : Pas d'équilibrage
!>       = 'Y' : Équilibrage des lignes et des colonnes, c'est-à-dire que A a été
!>               remplacé par diag(S) * A * diag(S).
!>               Le second membre B a été modifié en conséquence.
!>

N

!>          N est INTEGER
!>     L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>     Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>     des matrices B et X. NRHS >= 0.
!>

A

!>          A est tableau COMPLEX, dimension (LDA,N)
!>     La matrice hermitienne A. Si UPLO = 'U', la partie triangulaire
!>     supérieure N par N de A contient la partie triangulaire supérieure
!>     de la matrice A, et la partie strictement triangulaire inférieure de A
!>     n'est pas référencée. Si UPLO = 'L', la partie triangulaire
!>     inférieure N par N de A contient la partie triangulaire inférieure
!>     de la matrice A, et la partie strictement triangulaire supérieure de A
!>     n'est pas référencée.
!>

LDA

!>          LDA est INTEGER
!>     La dimension principale du tableau A. LDA >= max(1,N).
!>

AF

!>          AF est tableau COMPLEX, dimension (LDAF,N)
!>     Le facteur triangulaire U ou L de la factorisation de Cholesky
!>     A = U**H*U ou A = L*L**H, tel que calculé par CPOTRF.
!>

LDAF

!>          LDAF est INTEGER
!>     La dimension principale du tableau AF. LDAF >= max(1,N).
!>

S

!>          S est tableau RÉEL, dimension (N)
!>     Les facteurs d'échelle pour A. Si EQUED = 'Y', A est multiplié à
!>     gauche et à droite par diag(S). S est un argument d'entrée si FACT =
!>     'F' ; sinon, S est un argument de sortie. Si FACT = 'F' et EQUED
!>     = 'Y', chaque élément de S doit être positif. Si S est en sortie, chaque
!>     élément de S est une puissance de la base. Si S est en entrée, chaque
!>     élément de S doit être une puissance de la base pour garantir une solution fiable
!>     et des estimations d'erreur. L'échelonnement par des puissances de la base ne cause
!>     pas d'erreurs d'arrondi, sauf si le résultat déborde (underflow ou overflow).
!>     Les erreurs d'arrondi lors de l'échelonnement conduisent à un raffinement avec une matrice qui
!>     n'est pas équivalente à la matrice d'entrée, produisant des estimations d'erreur
!>     qui peuvent ne pas être fiables.
!>

B

!>          B est tableau COMPLEX, dimension (LDB,NRHS)
!>     La matrice du second membre B.
!>

LDB

!>          LDB est INTEGER
!>     La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est tableau COMPLEX, dimension (LDX,NRHS)
!>     À l'entrée, la matrice solution X, telle que calculée par SGETRS.
!>     En sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>     La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est RÉEL
!>     Conditionnement relatif échelonné réciproque. Ceci est une estimation du
!>     conditionnement relatif de Skeel de la matrice A après
!>     équilibrage (si effectué). S'il est inférieur à la précision machine
!>     (en particulier, s'il est zéro), la matrice est singulière
!>     à la précision de travail. Notez que l'erreur peut toujours être petite même
!>     si ce nombre est très petit et que la matrice semble mal
!>     conditionnée.
!>

BERR

!>          BERR est tableau RÉEL, dimension (NRHS)
!>     Erreur arrière relative composante par composante. Ceci est la
!>     l'erreur arrière relative composante par composante de chaque vecteur solution X(j)
!>     (c'est-à-dire le plus petit changement relatif dans un élément de A ou B qui
!>     rend X(j) une solution exacte).
!>

N_ERR_BNDS

!>          N_ERR_BNDS est INTEGER
!>     Nombre de bornes d'erreur à renvoyer pour chaque second membre
!>     et chaque type (global ou composante par composante). Voir ERR_BNDS_NORM et
!>     ERR_BNDS_COMP ci-dessous.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM est tableau RÉEL, dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses bornes d'erreur et nombres de conditionnement correspondant à
!>     l'erreur relative globale, qui est définie comme suit :
!>
!>     Erreur relative globale dans le i-ème vecteur solution :
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     Le tableau est indexé par le type

ERR_BNDS_COMP

!>          ERR_BNDS_COMP est un tableau RÉEL, de dimension (NRHS, N_ERR_BNDS)
!>     Pour chaque second membre, ce tableau contient des informations sur
!>     diverses marges d'erreur et nombres conditionnels correspondant à
!>     l'erreur relative par composante, qui est définie comme suit :
!>
!>     Erreur relative par composante dans le i-ème vecteur solution :
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     Le tableau est indexé par le second membre i (dont dépend l'erreur
!>     relative par composante), et le type d'information d'erreur tel que
!>     décrit ci-dessous. Actuellement, jusqu'à trois informations sont
!>     retournées pour chaque second membre. Si la précision par composante
!>     n'est pas demandée (PARAMS(3) = 0.0), alors ERR_BNDS_COMP n'est pas
!>     utilisé. Si N_ERR_BNDS < 3, alors au plus les premières entrées
!>     (:,N_ERR_BNDS) sont retournées.
!>
!>     Le premier indice dans ERR_BNDS_COMP(i,:) correspond au i-ème
!>     second membre.
!>
!>     Le second indice dans ERR_BNDS_COMP(:,err) contient les trois
!>     champs suivants :
!>     err = 1  booléen. Faites confiance à la réponse si le
!>              nombre conditionnel réciproque est inférieur au seuil
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  borne d'erreur : La marge d'erreur avant estimée,
!>              presque certainement dans un facteur de 10 de l'erreur
!>              réelle tant que la prochaine entrée est supérieure au seuil
!>              sqrt(n) * slamch('Epsilon'). Cette marge d'erreur ne doit être
!>              utilisée que si le booléen précédent est vrai.
!>
!>     err = 3  Nombre conditionnel réciproque : Norme estimée par composante
!>              du nombre conditionnel réciproque. Comparé au seuil
!>              sqrt(n) * slamch('Epsilon') pour déterminer si l'estimation
!>              de l'erreur est . Ces nombres conditionnels réciproques
!>              sont 1 / (norm(Z^{-1},inf) * norm(Z,inf)) pour une certaine
!>              matrice Z correctement mise à l'échelle.
!>              Soit Z = S*(A*diag(x)), où x est la solution pour le
!>              second membre courant et S met à l'échelle chaque ligne de
!>              A*diag(x) par une puissance du radix de sorte que toutes les
!>              sommes de lignes absolues de Z soient approximativement 1.
!>
!>     Voir la note de travail Lapack 165 pour plus de détails et des mises
!>     en garde supplémentaires.
!>

NPARAMS

!>          NPARAMS est un entier
!>     Spécifie le nombre de paramètres définis dans PARAMS. Si <= 0, le
!>     tableau PARAMS n'est jamais référencé et les valeurs par défaut sont utilisées.
!>

PARAMS

!>          PARAMS est un tableau RÉEL, de dimension NPARAMS
!>     Spécifie les paramètres de l'algorithme. Si une entrée est < 0.0, alors
!>     cette entrée sera remplie avec la valeur par défaut utilisée pour ce
!>     paramètre. Seules les positions jusqu'à NPARAMS sont accédées ; les
!>     valeurs par défaut sont utilisées pour les paramètres numérotés plus haut.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : Indique si l'on doit effectuer un
!>            raffinage itératif ou non.
!>         Par défaut : 1.0
!>            = 0.0 : Aucun raffinement n'est effectué, et aucune marge d'erreur n'est
!>                    calculée.
!>            = 1.0 : Utilise l'algorithme de raffinement en double précision,
!>                    éventuellement avec des calculs en simple précision doublés si
!>                    l'environnement de compilation ne prend pas en charge la
!>                    DOUBLE PRÉCISION.
!>              (les autres valeurs sont réservées à un usage futur)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : Nombre maximum de calculs résiduels
!>            autorisés pour le raffinement.
!>         Par défaut : 10
!>         Agressif : Défini à 100 pour permettre la convergence en utilisant des
!>                     factorisations approximatives ou des factorisations autres que LU. Si
!>                     la factorisation utilise une technique autre que l'élimination
!>                     gaussienne, les garanties dans err_bnds_norm et err_bnds_comp
!>                     peuvent ne plus être fiables.
!>
!>       PARAMS(LA_LINRX_CWISE_I = 3) : Indicateur déterminant si le code
!>            tentera de trouver une solution avec une faible erreur relative par
!>            composante dans l'algorithme en double précision.
!>            Positif est vrai, 0.0 est faux.
!>         Par défaut : 1.0 (tenter la convergence par composante)
!>

WORK

!>          WORK est un tableau COMPLET, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau RÉEL, de dimension (2*N)
!>

INFO

!>          INFO est un entier
!>       = 0 : Sortie réussie. La solution de chaque second membre est
!>         garantie.
!>       < 0 : Si INFO = -i, le i-ème argument avait une valeur illégale.
!>       > 0 et <= N : U(INFO,INFO) est exactement zéro. La factorisation
!>         a été terminée, mais le facteur U est exactement singulier, de sorte
!>         que la solution et les marges d'erreur n'ont pas pu être calculées. RCOND = 0
!>         est retourné.
!>       = N+J : La solution correspondant au J-ième second membre n'est
!>         pas garantie. Les solutions correspondant aux autres seconds
!>         membres K avec K > J peuvent également ne pas être garanties,
!>         mais seul le premier second membre de ce type est rapporté. Si une faible
!>         erreur par composante n'est pas demandée (PARAMS(3) = 0.0), alors
!>         le J-ième second membre est le premier dont la marge d'erreur normwise
!>         n'est pas garantie (le plus petit J tel que ERR_BNDS_NORM(J,1) = 0.0). Par défaut
!>         (PARAMS(3) = 1.0), le J-ième second membre est le premier dont la marge d'erreur
!>         normwise ou par composante n'est pas garantie (le plus petit J tel
!>         que ERR_BNDS_NORM(J,1) = 0.0 ou ERR_BNDS_COMP(J,1) = 0.0). Voir la définition de
!>         ERR_BNDS_NORM(:,1) et ERR_BNDS_COMP(:,1). Pour obtenir des informations
!>         sur tous les seconds membres, vérifiez ERR_BNDS_NORM ou
!>         ERR_BNDS_COMP.
!>

    the left and right by diag(S).  S is an input argument if FACT =
    'F'; otherwise, S is an output argument.  If FACT = 'F' and EQUED
    = 'Y', each element of S must be positive.  If S is output, each
    element of S is a power of the radix. If S is input, each element
    of S should be a power of the radix to ensure a reliable solution
    and error estimates. Scaling by powers of the radix does not cause
    rounding errors unless the result underflows or overflows.
    Rounding errors during scaling lead to refining with a matrix that
    is not equivalent to the input matrix, producing error estimates
    that may not be reliable.

    The right hand side matrix B.
