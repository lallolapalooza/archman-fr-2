podman-pod-stats(1) Manuel des commandes générales podman-pod-stats(1)

NOM

podman-pod-stats - Affiche un flux en direct des statistiques d'utilisation des ressources pour les conteneurs d'un ou plusieurs pods

SYNTAXE

podman pod stats [options] [pod]

DESCRIPTION

Affiche un flux en direct des statistiques d'utilisation des ressources des conteneurs dans un ou plusieurs pods. L'exécution sans privilèges root n'est prise en charge que sur les cgroups v2.

OPTIONS

--all, -a

Affiche tous les conteneurs. Seuls les conteneurs en cours d'exécution sont affichés par défaut.

--format=modèle

Affiche joliment les statistiques des conteneurs au format JSON ou à l'aide d'un modèle Go.

Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Espace réservé Description
.BlockIO Entrées/sorties de bloc
.CID ID du conteneur
.CPU Pourcentage du CPU
.Mem Pourcentage de mémoire
.MemUsage Utilisation de la mémoire
.MemUsageBytes Utilisation de la mémoire (IEC)
.Name Nom du conteneur
.NetIO Entrées/sorties réseau
.PIDS Nombre de PIDs
.Pod ID du pod

Lorsque vous utilisez un modèle Go, faites précéder le format par table pour afficher les en-têtes.

--latest, -l

Au lieu de fournir le nom ou l'ID du pod, utilise le dernier pod créé. Note : le dernier pod démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (à l'exception de WSL2)).

--no-reset

Ne pas effacer le terminal/l'écran entre les intervalles de rapport.

--no-stream

Désactive le streaming des statistiques de pod et ne récupère que le premier résultat, le paramètre par défaut est false.

EXEMPLES

Lister les statistiques de tous les pods sans streaming :

# podman pod stats -a --no-stream
ID             NAME              CPU %   MEM USAGE / LIMIT   MEM %   NET IO    BLOCK IO   PIDS
a9f807ffaacd   frosty_hodgkin    --      3.092MB / 16.7GB    0.02%   -- / --   -- / --    2
3b33001239ee   sleepy_stallman   --      -- / --             --      -- / --   -- / --    --

Lister les statistiques d'un pod spécifié sans streaming :

# podman pod stats --no-stream a9f80
ID             NAME             CPU %   MEM USAGE / LIMIT   MEM %   NET IO    BLOCK IO   PIDS
a9f807ffaacd   frosty_hodgkin   --      3.092MB / 16.7GB    0.02%   -- / --   -- / --    2

Lister les statistiques d'un pod spécifié au format JSON sans streaming :

# podman pod stats --no-stream --format=json a9f80
[
    {
        "id": "a9f807ffaacd",
        "name": "frosty_hodgkin",
        "cpu_percent": "--",
        "mem_usage": "3.092MB / 16.7GB",
        "mem_percent": "0.02%",
        "netio": "-- / --",
        "blocki": "-- / --",
        "pids": "2"
    }
]

Lister les statistiques sélectionnées formatées en tableau pour un pod spécifié :

# podman pod stats --no-stream --format "table {{.ID}} {{.Name}} {{.MemUsage}}" 6eae
ID             NAME           MEM USAGE / LIMIT
6eae9e25a564   clever_bassi   3.031MB / 16.7GB
