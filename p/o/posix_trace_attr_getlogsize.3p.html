POSIX_TRACE_ATTR_GETLOGSIZE(3P) Manuel du programmeur POSIX POSIX_TRACE_ATTR_GETLOGSIZE(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_trace_attr_getlogsize, posix_trace_attr_getmaxdatasize, posix_trace_attr_getmaxsystemeventsize, posix_trace_attr_getmaxusereventsize, posix_trace_attr_getstreamsize, posix_trace_attr_setlogsize, posix_trace_attr_setmaxdatasize, posix_trace_attr_setstreamsize — récupérer et définir les attributs de taille de flux de trace (TRACING)

SYNOPSIS

#include <sys/types.h>
#include <trace.h>
int posix_trace_attr_getlogsize(const trace_attr_t *restrict attr,
    size_t *restrict logsize);
int posix_trace_attr_getmaxdatasize(const trace_attr_t *restrict attr,
    size_t *restrict maxdatasize);
int posix_trace_attr_getmaxsystemeventsize(
    const trace_attr_t *restrict attr,
    size_t *restrict eventsize);
int posix_trace_attr_getmaxusereventsize(
    const trace_attr_t *restrict attr,
    size_t data_len, size_t *restrict eventsize);
int posix_trace_attr_getstreamsize(const trace_attr_t *restrict attr,
    size_t *restrict streamsize);
int posix_trace_attr_setlogsize(trace_attr_t *attr,
    size_t logsize);
int posix_trace_attr_setmaxdatasize(trace_attr_t *attr,
    size_t maxdatasize);
int posix_trace_attr_setstreamsize(trace_attr_t *attr,
    size_t streamsize);

DESCRIPTION

La fonction posix_trace_attr_getlogsize() copie la taille du journal, en octets, de l'attribut log-max-size de l'objet d'attributs pointé par l'argument attr dans la variable pointée par l'argument logsize. Cette taille de journal est le total maximal d'octets qui doit être alloué pour les événements de trace système et utilisateur dans le journal de trace. La valeur par défaut de l'attribut log-max-size est définie par l'implémentation.

La fonction posix_trace_attr_setlogsize() définit la taille maximale autorisée, en octets, dans l'attribut log-max-size de l'objet d'attributs pointé par l'argument attr, en utilisant la valeur de taille fournie par l'argument logsize.

La taille du journal de trace est utilisée si l'attribut log-full-policy est défini sur POSIX_TRACE_LOOP ou POSIX_TRACE_UNTIL_FULL. Si l'attribut log-full-policy est défini sur POSIX_TRACE_APPEND, l'implémentation ignore l'attribut log-max-size.

La fonction posix_trace_attr_getmaxdatasize() copie la taille maximale des données d'événement de trace utilisateur, en octets, de l'attribut max-data-size de l'objet d'attributs pointé par l'argument attr dans la variable pointée par l'argument maxdatasize. La valeur par défaut de l'attribut max-data-size est définie par l'implémentation.

La fonction posix_trace_attr_getmaxsystemeventsize() calcule la taille mémoire maximale, en octets, requise pour stocker un seul événement de trace système. Cette valeur est calculée pour l'objet d'attributs de flux de trace pointé par l'argument attr et est retournée dans la variable pointée par l'argument eventsize.

Les valeurs retournées comme tailles mémoire maximales des événements de trace utilisateur et système doivent être telles que si la somme des tailles mémoire maximales d'un ensemble d'événements de trace pouvant être enregistrés dans un flux de trace est inférieure ou égale à l'attribut stream-min-size de ce flux de trace, le système fournit les ressources nécessaires pour l'enregistrement de tous ces événements de trace, sans perte.

La fonction posix_trace_attr_getmaxusereventsize() calcule la taille mémoire maximale, en octets, requise pour stocker un seul événement de trace utilisateur généré par un appel à posix_trace_event() avec un paramètre data_len égal à la valeur data_len spécifiée dans cet appel. Cette valeur est calculée pour l'objet d'attributs de flux de trace pointé par l'argument attr et est retournée dans la variable pointée par l'argument eventsize.

La fonction posix_trace_attr_getstreamsize() copie la taille du flux, en octets, de l'attribut stream-min-size de l'objet d'attributs pointé par l'argument attr dans la variable pointée par l'argument streamsize.

Cette taille de flux est la taille mémoire totale actuelle réservée aux événements de trace système et utilisateur dans le flux de trace. La valeur par défaut de l'attribut stream-min-size est définie par l'implémentation. La taille du flux fait référence à la mémoire utilisée pour stocker les enregistrements des événements de trace. Les autres données du flux (par exemple, les valeurs d'attributs de trace) ne doivent pas être incluses dans cette taille.

La fonction posix_trace_attr_setmaxdatasize() définit la taille maximale autorisée, en octets, dans l'attribut max-data-size de l'objet d'attributs pointé par l'argument attr, en utilisant la valeur de taille fournie par l'argument maxdatasize. Cette taille maximale est la taille maximale autorisée pour l'argument de données utilisateur qui peut être passé à posix_trace_event(). L'implémentation est autorisée à tronquer les données passées à trace_user_event dont la taille est supérieure à maxdatasize.

La fonction posix_trace_attr_setstreamsize() définit la taille minimale autorisée, en octets, dans l'attribut stream-min-size de l'objet d'attributs pointé par l'argument attr, en utilisant la valeur de taille fournie par l'argument streamsize.

VALEUR RENVOYÉE

En cas de succès, ces fonctions renvoient une valeur de zéro. Sinon, elles renvoient le numéro d'erreur correspondant.

La fonction posix_trace_attr_getlogsize() stocke la taille maximale du journal de trace autorisée dans l'objet pointé par logsize, en cas de succès.

La fonction posix_trace_attr_getmaxdatasize() stocke la taille mémoire maximale de l'enregistrement d'événement de trace dans l'objet pointé par maxdatasize, en cas de succès.

La fonction posix_trace_attr_getmaxsystemeventsize() stocke la taille mémoire maximale pour stocker un seul événement de trace système dans l'objet pointé par eventsize, en cas de succès.

La fonction posix_trace_attr_getmaxusereventsize() stocke la taille mémoire maximale pour stocker un seul événement de trace utilisateur dans l'objet pointé par eventsize, en cas de succès.

La fonction posix_trace_attr_getstreamsize() stocke la taille maximale du flux de trace autorisée dans l'objet pointé par streamsize, en cas de succès.

ERREURS

Ces fonctions peuvent échouer si :

EINVAL
La valeur spécifiée par l'un des arguments est invalide.

NAME

posix_trace_attr_getlogsize, posix_trace_attr_setlogsize, posix_trace_attr_getallocsize, posix_trace_attr_setallocsize — get and set trace log size attributes

SYNOPSIS

#include <trace.h>

int

posix_trace_attr_getlogsize(const posix_trace_attr_t *attr, size_t *size);

int

posix_trace_attr_setlogsize(posix_trace_attr_t *attr, size_t size);

int

posix_trace_attr_getallocsize(const posix_trace_attr_t *attr, size_t *size);

int

posix_trace_attr_setallocsize(posix_trace_attr_t *attr, size_t size);

DESCRIPTION

These functions retrieve and set attributes of a trace attributes object that control the size of the trace log. The trace log is the memory buffer where trace events are stored.

The posix_trace_attr_getlogsize() function retrieves the maximum size of the trace log in bytes. This value is stored in the location pointed to by size.

The posix_trace_attr_setlogsize() function sets the maximum size of the trace log in bytes to size. The value must be greater than zero.

The posix_trace_attr_getallocsize() function retrieves the size of the memory buffer allocated for the trace log. This value is stored in the location pointed to by size.

The posix_trace_attr_setallocsize() function sets the size of the memory buffer allocated for the trace log in bytes to size. The value must be greater than zero.

The trace log size attributes are relevant when the trace log is created with the POSIX_TRACE_LOG_FILE option. In this case, the trace log is implemented as a file, and its size is limited by the value of the TRC_LOG_SIZE attribute.

The trace allocation size attributes are relevant when the trace log is created with the POSIX_TRACE_LOG_MEMORY option. In this case, the trace log is implemented as a memory buffer, and its size is limited by the value of the TRC_ALLOC_SIZE attribute.

For both TRC_LOG_SIZE and TRC_ALLOC_SIZE, the default value is system-dependent.

RETURN VALUE

On success, these functions return 0. On failure, they return an error number.

ERRORS

EINVAL
The attribute object referenced by attr is invalid, or the specified size is invalid (e.g. zero).
ENOMEM
Insufficient memory is available to set the attribute.

EXAMPLES

Set the trace log size to 1MB:

    size_t size = 1024 * 1024;
    posix_trace_attr_t attr;
    posix_trace_attr_init(&attr);
    posix_trace_attr_setlogsize(&attr, size);
    posix_trace_attr_destroy(&attr);

APPLICATION USAGE

These functions can be called from any time during the execution of a process.

RATIONALE

The POSIX trace facility provides mechanisms for tracing system events. The size of the trace log is a crucial parameter that affects the amount of tracing data that can be collected. These functions allow applications to control the size of the trace log, enabling them to tailor the tracing behavior to their specific needs.

FUTURE DIRECTIONS

No specific future directions are identified for these functions.
