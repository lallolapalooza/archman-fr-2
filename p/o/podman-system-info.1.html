podman-info(1) Manuel des commandes générales podman-info(1)

NOM

podman-info - Afficher les informations relatives à Podman

SYNOPSIS

podman info [options]

podman system info [options]

DESCRIPTION

Affiche les informations relatives à l'hôte, les statistiques de stockage actuelles, les registres de conteneurs configurés et la version de Podman.

OPTIONS

--format, -f=format

Change le format de sortie en "json" ou en un template Go.

Placeholder Infos relatives à ...
.Host ... ...l'hôte sur lequel podman s'exécute
.Plugins ... ...les plugins externes
.Registries ... ...les registres configurés
.Store ... ...le pilote de stockage et les chemins
.Version ... ...la version de podman

Chacun des éléments ci-dessus se subdivise en champs supplémentaires, plus nombreux qu'il n'est raisonnablement possible de les énumérer dans ce document.

Extraction de la liste des registres de conteneurs avec un modèle Go


Si la complétion automatique du shell est activée, tapez podman info
    --format={{. puis appuyez sur [TAB] deux fois.


$ podman info --format={{.
{{.Host.         {{.Plugins.      {{.Registries}}  {{.Store.        {{.Version.


Appuyez sur R [TAB] [ENTRÉE] pour afficher les informations
    sur les registres.


$ podman info -f {{.Registries}}
map[search:[registry.fedoraproject.org registry.access.redhat.com docker.io quay.io]]
$


La sortie contient toujours une carte (map) et un tableau (array). La valeur de la carte peut être
    extraite avec


$ podman info -f '{{index .Registries "search"}}'
[registry.fedoraproject.org registry.access.redhat.com docker.io quay.io]


Le tableau peut être affiché avec une entrée par ligne


$ podman info -f '{{range index .Registries "search"}}{{.}}\n{{end}}'
registry.fedoraproject.org
registry.access.redhat.com
docker.io
quay.io






Extraction de la liste des registres de conteneurs depuis JSON avec jq


Le processeur JSON en ligne de commande jq peut être utilisé pour extraire
    la liste des registres de conteneurs.


$ podman info -f json | jq '.registries["search"]'
[
  "registry.fedoraproject.org",
  "registry.access.redhat.com",
  "docker.io",
  "quay.io"
]


Le tableau peut être affiché avec une entrée par ligne


$ podman info -f json | jq -r '.registries["search"] | .[]'
registry.fedoraproject.org
registry.access.redhat.com
docker.io
quay.io


Notez que les champs de structure du modèle Go commencent par une majuscule. Lors de l'exécution de
    podman info ou podman info --format=json, les mêmes noms commencent par une minuscule.
