POSTLOG(1) Manuel des commandes générales POSTLOG(1)

NOM

postlog - Utilitaire de journalisation compatible Postfix

SYNTAXE

postlog [-iv] [-c répertoire_config] [-p priorité] [-t étiquette] [texte...]

DESCRIPTION


La commande postlog(1) implémente une interface de journalisation compatible Postfix à utiliser, par exemple, dans des scripts shell.

Par défaut, postlog(1) enregistre le texte fourni en ligne de commande comme un seul enregistrement. Si aucun texte n'est spécifié en ligne de commande, postlog(1) lit depuis l'entrée standard et enregistre chaque ligne d'entrée comme un seul enregistrement.

La journalisation est envoyée à syslogd(8) ou postlogd(8), et au flux d'erreur standard (avec Postfix < 3.8, postlog(1) écrit sur le flux d'erreur standard uniquement si ce flux est connecté à un terminal).

Les options suivantes sont implémentées :

-c répertoire_config
Lit le fichier de configuration main.cf dans le répertoire nommé au lieu du répertoire de configuration par défaut.
-i (obsolète)
Inclut l'identifiant du processus dans l'étiquette de journalisation. Cet indicateur est ignoré à partir de Postfix 3.4, où le PID est toujours inclus.
-p priorité (par défaut : info)
Spécifie la sévérité de la journalisation : info, warn, error, fatal, ou panic. Avec Postfix 3.1 et versions ultérieures, le programme fera une pause de 1 seconde après avoir signalé une condition fatal ou panic, comme les autres programmes Postfix.
-t étiquette
Spécifie l'étiquette de journalisation, c'est-à-dire le nom d'identification qui apparaît au début de chaque enregistrement de journalisation. Une étiquette par défaut est utilisée lorsqu'aucune n'est spécifiée.
-v
Active la journalisation détaillée à des fins de débogage. Plusieurs options -v rendent le logiciel de plus en plus détaillé.

SÉCURITÉ

La commande postlog(1) est conçue pour être exécutée avec les privilèges set-groupid, afin qu'elle puisse se connecter au processus démon postlogd(8) (Postfix 3.7 et versions ultérieures ; les implémentations antérieures de cette commande ne doivent pas avoir de permissions set-groupid ou set-userid).

ENVIRONNEMENT

MAIL_CONFIG
Répertoire contenant le fichier main.cf.

PARAMÈTRES DE CONFIGURATION

Les paramètres main.cf suivants sont particulièrement pertinents pour ce programme.

Le texte ci-dessous ne fournit qu'un résumé des paramètres. Voir postconf(5) pour plus de détails, y compris des exemples.

config_directory (voir la sortie de 'postconf -d')
L'emplacement par défaut des fichiers de configuration Postfix main.cf et master.cf.
import_environment (voir la sortie de 'postconf -d')
La liste des variables d'environnement qu'un processus Postfix privilégié importera d'un processus parent non-Postfix, ou des substitutions d'environnement nom=valeur.
syslog_facility (mail)
La facilité syslog de la journalisation Postfix.
syslog_name (voir la sortie de 'postconf -d')
Un préfixe qui est ajouté au nom du processus dans les enregistrements syslog, de sorte que, par exemple, "smtpd" devienne "prefix/smtpd".

Disponible dans Postfix 3.4 et versions ultérieures :

maillog_file (vide)
Le nom d'un fichier journal optionnel écrit par le service postlogd(8) de Postfix.
postlog_service_name (postlog)
Le nom de l'entrée de service postlogd(8) dans master.cf.

Disponible dans Postfix 3.9 et versions ultérieures :

maillog_file_permissions (0600)
Les permissions d'accès aux fichiers qui seront définies lorsque le fichier $maillog_file est créé pour la première fois, ou lorsque le fichier est créé après la rotation d'un fichier existant.
