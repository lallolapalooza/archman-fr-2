pow10(3) Manuel des fonctions de bibliothèque pow10(3)

NOM

pow10, pow10f, pow10l - fonctions de puissance en base 10

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNOPSIS

#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <math.h>
double pow10(double x);
float pow10f(float x);
long double pow10l(long double x);

DESCRIPTION

Ces fonctions retournent la valeur de 10 élevé à la puissance x.

Attention : Ces fonctions effectuent exactement la même tâche que les fonctions décrites dans exp10(3), à la différence que ces dernières fonctions sont désormais standardisées dans la norme TS 18661-4:2015. Il est préférable d'utiliser ces dernières fonctions plutôt que celles décrites dans cette page.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pow10 (), pow10f (), pow10l () Sécurité des threads MT-Safe

NORMES

GNU.

VERSIONS

glibc 2.1. Supprimé dans glibc 2.27.

VOIR AUSSI

exp10(3), pow(3)
