POSIX_FADVISE(3P) Manuel du programmeur POSIX POSIX_FADVISE(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_fadvise — informations consultatives sur les fichiers (TEMPS RÉEL AVANCÉ)

SYNOPSIS

#include <fcntl.h>
int posix_fadvise(int fd, off_t offset, off_t len, int advice);

DESCRIPTION

La fonction posix_fadvise() informe l'implémentation du comportement attendu de l'application concernant les données du fichier associé au descripteur de fichier ouvert, fd, en commençant à offset et sur len octets. La plage spécifiée n'a pas besoin d'exister dans le fichier. Si len est zéro, toutes les données suivant offset sont spécifiées. L'implémentation peut utiliser ces informations pour optimiser la gestion des données spécifiées. La fonction posix_fadvise() n'a aucun effet sur la sémantique des autres opérations sur les données spécifiées, bien qu'elle puisse affecter les performances des autres opérations.

Le conseil à appliquer aux données est spécifié par le paramètre advice et peut être l'une des valeurs suivantes :

POSIX_FADV_NORMAL

Spécifie que l'application n'a aucun conseil à donner sur son comportement concernant les données spécifiées. C'est la caractéristique par défaut si aucun conseil n'est donné pour un fichier ouvert.
POSIX_FADV_SEQUENTIAL

Spécifie que l'application s'attend à accéder aux données spécifiées séquentiellement, des offsets inférieurs aux offsets supérieurs.
POSIX_FADV_RANDOM

Spécifie que l'application s'attend à accéder aux données spécifiées de manière aléatoire.
POSIX_FADV_WILLNEED

Spécifie que l'application s'attend à accéder aux données spécifiées dans un avenir proche.
POSIX_FADV_DONTNEED

Spécifie que l'application s'attend à ne pas accéder aux données spécifiées dans un avenir proche.
POSIX_FADV_NOREUSE

Spécifie que l'application s'attend à accéder aux données spécifiées une seule fois, puis à ne plus les réutiliser.

Ces valeurs sont définies dans <fcntl.h>.

VALEUR DE RETOUR

En cas de succès, posix_fadvise() retourne zéro ; sinon, un numéro d'erreur est retourné pour indiquer l'erreur.

ERREURS

La fonction posix_fadvise() échouera si :

EBADF
L'argument fd n'est pas un descripteur de fichier valide.
EINVAL
La valeur de advice est invalide, ou la valeur de len est inférieure à zéro.
ESPIPE
L'argument fd est associé à un pipe ou un FIFO.

UTILISATION PAR L'APPLICATION

La fonction posix_fadvise() fait partie de l'option Informations Consultatives et peut ne pas être fournie sur toutes les implémentations.
