sous-routine cpotf2 (caractère uplo, entier n, complexe, dimension( lda, * ) a, entier lda, entier info)

CPOTF2 calcule la factorisation de Cholesky d'une matrice complexe Hermitienne définie positive (algorithme non bloqué).

Objectif :

!>
!> CPOTF2 calcule la factorisation de Cholesky d'une matrice complexe
!> Hermitienne définie positive A.
!>
!> La factorisation a la forme
!>    A = U**H * U ,  si UPLO = 'U', ou
!>    A = L  * L**H,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et L est une matrice triangulaire inférieure.
!>
!> Ceci est la version non bloquée de l'algorithme, faisant appel au BLAS de niveau 2.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice Hermitienne A est stockée.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          En entrée, la matrice Hermitienne A. Si UPLO = 'U', la partie
!>          supérieure triangulaire de taille n par n de A contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L', la partie
!>          inférieure triangulaire de taille n par n de A contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>
!>          En sortie, si INFO = 0, le facteur U ou L de la factorisation de
!>          Cholesky A = U**H *U  ou A = L*L**H.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0: succès
!>          < 0: si INFO = -k, le k-ième argument avait une valeur illégale
!>          > 0: si INFO = k, le mineur principal de tête d'ordre k
!>               n'est pas positif, et la factorisation n'a pas pu être
!>               complétée.
!>

potf2(3) - LAPACK

NAME

spotf2, dpotf2, cpotf2, zpotf2 - Cholesky factorization (unblocked algorithm)

SYNOPSIS

subroutine spotf2(character uplo, integer n, real, dimension( lda, * ) a, integer lda, integer info)
subroutine dpotf2(character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, integer info)
subroutine cpotf2(character uplo, integer n, complex, dimension( lda, * ) a, integer lda, integer info)
subroutine zpotf2(character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, integer info)

Detailed Description

This routine computes the Cholesky factorization of a real symmetric or complex Hermitian positive definite matrix, using the unblocked (vectorized) version of the algorithm. The factorization has the form

A = UTU, if UPLO = 'U', or

A = UHU, if UPLO = 'U' (complex)

A = LLT, if UPLO = 'L', or

A = LLH, if UPLO = 'L' (complex)

where U is an upper triangular matrix and L is a lower triangular matrix.

Function Documentation

subroutine spotf2 (character uplo, integer n, real, dimension( lda, * ) a, integer lda, integer info)

SPOTF2 computes the Cholesky factorization of a symmetric positive definite matrix (unblocked algorithm).

Purpose:

!>
!> SPOTF2 computes the Cholesky factorization of a real symmetric
!> positive definite matrix A.
!>
!> The factorization has the form
!>    A = U**T * U ,  if UPLO = 'U', or
!>    A = L  * L**T,  if UPLO = 'L',
!> where U is an upper triangular matrix and L is lower triangular.
!>
!> This is the unblocked version of the algorithm, calling Level 2 BLAS.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          Specifies whether the upper or lower triangular part of the
!>          symmetric matrix A is stored.
!>          = 'U':  Upper triangular
!>          = 'L':  Lower triangular
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          On entry, the symmetric matrix A.  If UPLO = 'U', the leading
!>          n by n upper triangular part of A contains the upper
!>          triangular part of the matrix A, and the strictly lower
!>          triangular part of A is not referenced.  If UPLO = 'L', the
!>          leading n by n lower triangular part of A contains the lower
!>          triangular part of the matrix A, and the strictly upper
!>          triangular part of A is not referenced.
!>
!>          On exit, if INFO = 0, the factor U or L from the Cholesky
!>          factorization A = U**T *U  or A = L*L**T.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -k, the k-th argument had an illegal value
!>          > 0: if INFO = k, the leading principal minor of order k
!>               is not positive, and the factorization could not be
!>               completed.
!>
