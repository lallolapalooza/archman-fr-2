NOM

pod2usage - affiche les messages d'utilisation à partir des docs pod intégrées dans les fichiers

SYNTAXE

pod2usage
[-help] [-man] [-exit valeur_sortie] [-output fichier_sortie] [-verbose niveau] [-pathlist liste_dossiers] [-formatter module] [-utf8] fichier

OPTIONS ET ARGUMENTS

-help
Affiche un bref message d'aide et quitte.
-man
Affiche la page de manuel de cette commande et quitte.
-exit valeur_sortie
La valeur du statut de sortie à retourner.
-output fichier_sortie
Le fichier de sortie vers lequel imprimer. Si les noms spéciaux "-" ou ">&1" ou ">&STDOUT" sont utilisés, alors la sortie standard est utilisée. Si ">&2" ou ">&STDERR" est utilisé, alors l'erreur standard est utilisée.
-verbose niveau
Le niveau de verbosité souhaité à utiliser : 
1 : affiche uniquement la SYNTAXE
2 : affiche les sections SYNTAXE et toute section OPTIONS/ARGUMENTS
3 : affiche la page de manuel entière (similaire à l'exécution de pod2text)
-pathlist liste_dossiers
Spécifie un ou plusieurs répertoires dans lesquels rechercher le fichier d'entrée s'il n'a pas été fourni avec un chemin absolu. Chaque chemin de répertoire dans la liste donnée doit être séparé par ':' sur Unix (';' sur MSWin32 et DOS).
-formatter module
Quel formateur de texte utiliser. Par défaut, c'est Pod::Text. Une alternative serait par exemple Pod::Text::Termcap.
-utf8
Cette option suppose que le formateur (voir ci-dessus) comprend l'option "utf8". Elle active la génération de sortie en utf8.
fichier
Le chemin d'accès d'un fichier contenant la documentation pod à afficher au format message d'utilisation. S'il est omis, l'entrée standard est lue - mais la sortie est alors formatée uniquement avec Pod::Text - à moins qu'un formateur spécifique n'ait été spécifié avec -formatter.

DESCRIPTION

pod2usage lira le fichier d'entrée donné à la recherche de la documentation pod et affichera le message d'utilisation correspondant. Si aucun fichier d'entrée n'est spécifié, l'entrée standard est lue.

pod2usage invoque la fonction pod2usage() dans le module Pod::Usage. Veuillez consulter "pod2usage()" dans Pod::Usage.

VOIR AUSSI

Pod::Usage, pod2text, Pod::Text, Pod::Text::Termcap, perldoc
