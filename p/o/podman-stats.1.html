podman-stats(1) Manuel des commandes générales podman-stats(1)

NOM

podman-stats - Afficher un flux en direct des statistiques d'utilisation des ressources d'un ou plusieurs conteneurs

SYNTAXE

podman stats [options] [conteneur]

podman container stats [options] [conteneur]

DESCRIPTION

Afficher un flux en direct des statistiques d'utilisation des ressources d'un ou plusieurs conteneurs

Note : podman stats ne fonctionne pas dans les environnements sans privilèges (rootless) qui utilisent cgroups v1. podman stats s'appuie sur les informations cgroup pour les statistiques, et cgroup v1 n'est pas pris en charge pour les cas d'utilisation sans privilèges.

Note : Les environnements sans privilèges qui utilisent cgroups v2 ne peuvent pas signaler les statistiques de leur utilisation réseau.

OPTIONS

--all, -a

Afficher tous les conteneurs. Seuls les conteneurs en cours d'exécution sont affichés par défaut.

--format=template

Afficher joliment les statistiques des conteneurs au format JSON ou à l'aide d'un modèle Go.

Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Espace réservé Description
.AvgCPU CPU moyen, nombre flottant pleine précision
.AVGCPU CPU moyen, formaté en pourcentage
.BlockInput Données totales lues depuis le périphérique bloc
.BlockIO Total de données lues / Total de données écrites sur le périphérique bloc
.BlockOutput Données totales écrites sur le périphérique bloc
.ContainerID ID du conteneur, hachage complet (non tronqué)
.ContainerStats ... Structure imbriquée, pour experts seulement
.CPU CPU en pourcentage, nombre flottant pleine précision
.CPUNano Utilisation CPU, total, en nanosecondes
.CPUPerc Pourcentage de CPU utilisé
.CPUSystemNano Utilisation CPU, noyau, en nanosecondes
.Duration Identique à CPUNano
.ID ID du conteneur, tronqué
.MemLimit Limite de mémoire, en octets
.MemPerc Pourcentage de mémoire utilisé
.MemUsage Utilisation de la mémoire
.MemUsageBytes Utilisation de la mémoire (IEC)
.Name Nom du conteneur
.NetIO Entrées/sorties réseau
.Network ... Entrées/sorties réseau, séparées par interface réseau
.PerCPU Temps CPU consommé par toutes les tâches [1]
.PIDs Nombre de PIDs
.PIDS Nombre de PIDs (oui, nous savons que c'est un doublon)
.SystemNano Date et heure système actuelles, nanosecondes depuis l'époque
.Up Durée (CPUNano), sous forme lisible
.UpTime Identique à Up

[1] Cgroups V1 uniquement.

Lors de l'utilisation d'un modèle Go, précédez le format de table pour afficher les en-têtes.

--interval, -i=secondes

Temps en secondes entre les rapports de statistiques, par défaut 5 secondes.

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utilisez le dernier conteneur créé. Note : le dernier conteneur démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (hors WSL2)).

--no-reset

Ne pas effacer le terminal/écran entre les intervalles de rapport.

--no-stream

Désactiver le streaming des statistiques et ne récupérer que le premier résultat, le paramètre par défaut est false.

--no-trunc

Ne pas tronquer la sortie.

EXEMPLE

Lister les statistiques de tous les conteneurs en cours d'exécution en mode sans streaming :

# podman stats -a --no-stream
ID             NAME              CPU %   MEM USAGE / LIMIT   MEM %   NET IO    BLOCK IO   PIDS
a9f807ffaacd   frosty_hodgkin    --      3.092MB / 16.7GB    0.02%   -- / --   -- / --    2
3b33001239ee   sleepy_stallman   --      -- / --             --      -- / --   -- / --    --

Lister les statistiques du conteneur spécifié en mode streaming :

# podman stats a9f80
ID             NAME             CPU %   MEM USAGE / LIMIT   MEM %   NET IO    BLOCK IO   PIDS
a9f807ffaacd   frosty_hodgkin   --      3.092MB / 16.7GB    0.02%   -- / --   -- / --    2

Lister les statistiques spécifiées du conteneur spécifié au format tableau :

$ podman stats --no-trunc 3667 --format 'table {{ .ID }} {{ .MemUsage }}'
ID                                                                MEM USAGE / LIMIT
3667c6aacb06aac2eaffce914c01736420023d56ef9b0f4cfe58b6d6a78b7503  49.15kB / 67.17GB

Lister les statistiques du conteneur spécifié au format JSON :

# podman stats --no-stream --format=json a9f80
[
    {
	"id": "a9f807ffaacd",
	"name": "frosty_hodgkin",
	"cpu_percent": "--",
	"mem_usage": "3.092MB / 16.7GB",
	"mem_percent": "0.02%",
	"netio": "-- / --",
	"blocki": "-- / --",
	"pids": "2"
    }
]

Lister les statistiques du conteneur spécifié au format tableau :

# podman stats --no-stream --format "table {{.ID}} {{.Name}} {{.MemUsage}}" 6eae
ID             NAME           MEM USAGE / LIMIT
6eae9e25a564   clever_bassi   3.031MB / 16.7GB

Note : Lors de l'utilisation d'un réseau slirp4netns avec le gestionnaire de ports rootlesskit, le trafic envoyé via le transfert de port est comptabilisé pour le périphérique lo. Le trafic comptabilisé pour lo n'est pas inclus dans la sortie des statistiques.
