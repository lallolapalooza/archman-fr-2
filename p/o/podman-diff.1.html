NOM

podman-diff - Inspecter les modifications du système de fichiers d'un conteneur ou d'une image

SYNTAXE

podman diff [options] conteneur|image [conteneur|image]

DESCRIPTION

Affiche les modifications du système de fichiers d'un conteneur ou d'une image. Le conteneur ou l'image est comparé à sa couche parente ou au deuxième argument lorsqu'il est fourni.

La sortie est précédée des symboles suivants :

Symbole Description
A Un fichier ou un répertoire a été ajouté.
D Un fichier ou un répertoire a été supprimé.
C Un fichier ou un répertoire a été modifié.

OPTIONS

--format

Modifier la sortie dans un format différent. Le seul format valide pour podman diff est json.

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utilisez le dernier conteneur créé. Remarque : le dernier conteneur démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (à l'exclusion de WSL2))

EXEMPLES

Afficher les fichiers modifiés par le conteneur par rapport à l'image du conteneur :

$ podman diff container1
A /myscript.sh

Afficher les fichiers modifiés par le conteneur par rapport à l'image du conteneur au format JSON :

$ podman diff --format json myimage
{
  "changed": [
    "/usr",
    "/usr/local",
    "/usr/local/bin"
  ],
  "added": [
    "/usr/local/bin/docker-entrypoint.sh"
  ]
}

Afficher la différence entre le conteneur spécifié et l'image :

$ podman diff container1 image1
A /test
