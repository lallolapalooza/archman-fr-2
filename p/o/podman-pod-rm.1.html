NOM

podman-pod-rm - Supprimer un ou plusieurs pods arrêtés et leurs conteneurs

SYNOPSIS

podman pod rm [options] pod

DESCRIPTION

podman pod rm supprime un ou plusieurs pods arrêtés et leurs conteneurs de l'hôte. Le nom ou l'ID du pod peut être utilisé. L'option -f arrête tous les conteneurs puis les supprime avant de supprimer le pod. Si tous les conteneurs ajoutés par l'utilisateur sont dans un état terminé, le pod est supprimé.

OPTIONS

--all, -a

Supprimer tous les pods. Peut être utilisé conjointement avec -f également.

--force, -f

Arrêter les conteneurs en cours d'exécution et supprimer tous les conteneurs arrêtés avant la suppression du pod.

--ignore, -i

Ignorer les erreurs lorsque les pods spécifiés ne sont pas dans le magasin de conteneurs. Un utilisateur peut avoir décidé de supprimer manuellement un pod, ce qui peut entraîner un échec lors de la directive ExecStop d'un service systemd référençant ce pod.

--latest, -l

Au lieu de fournir le nom ou l'ID du pod, utiliser le dernier pod créé. Note : le dernier pod démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (à l'exception de WSL2))

--pod-id-file=fichier

Lire l'ID du pod depuis le fichier spécifié et supprimer le pod. Peut être spécifié plusieurs fois.

S'il est spécifié, le fichier d'ID de pod est supprimé avec le pod.

--time, -t=secondes

Secondes à attendre avant d'arrêter de force les conteneurs en cours d'exécution dans le pod. Utiliser -1 pour une attente infinie.

L'option --force doit être spécifiée pour utiliser l'option --time.

EXEMPLE

Supprimer un pod avec un nom donné :

podman pod rm monpodwebserver

Supprimer plusieurs pods avec des noms et/ou IDs donnés :

podman pod rm monpodwebserver monpodflaskserver 860a4b23

Supprimer de force un pod avec un ID donné :

podman pod rm -f 860a4b23

Supprimer de force tous les pods :

podman pod rm -f -a
podman pod rm -fa

Supprimer un pod en utilisant un ID spécifié dans un fichier donné :

podman pod rm --pod-id-file /chemin/vers/fichier/id

STATUT DE SORTIE

0 Tous les pods spécifiés ont été supprimés

1 L'un des pods spécifiés n'existait pas, et aucune autre erreur

2 L'un des pods spécifiés est attaché à un conteneur

125 La commande échoue pour toute autre raison
