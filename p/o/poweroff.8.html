POWEROFF(8) poweroff POWEROFF(8)

NOM

poweroff, reboot, halt - Éteindre, redémarrer ou arrêter la machine

SYNTAXE

poweroff [OPTIONS...]

reboot [OPTIONS...]

halt [OPTIONS...]

DESCRIPTION

poweroff, reboot et halt peuvent être utilisés pour éteindre, redémarrer ou arrêter la machine. Ces trois commandes acceptent les mêmes options.

OPTIONS

Les options suivantes sont comprises :

--help

Affiche un court message d'aide et quitte.

Ajouté dans la version 253.

--halt

Arrête la machine, quel que soit le nom de la commande invoquée parmi les trois.

Ajouté dans la version 253.

-p, --poweroff

Éteint la machine, lorsque halt ou poweroff est invoqué. Cette option est ignorée lors de l'invocation de reboot.

Ajouté dans la version 253.

--reboot

Redémarre la machine, quel que soit le nom de la commande invoquée parmi les trois.

Ajouté dans la version 253.

-f, --force

Force l'extinction, l'arrêt ou le redémarrage immédiat. Si spécifiée, la commande ne contacte pas le système d'init. Dans la plupart des cas, les systèmes de fichiers ne sont pas correctement démontés avant l'arrêt. Par exemple, la commande reboot -f est principalement équivalente à systemctl reboot -ff, au lieu de systemctl reboot -f.

Ajouté dans la version 253.

-w, --wtmp-only

Écrit uniquement une entrée d'arrêt dans wtmp, n'éteint, ne redémarre ou n'arrête pas réellement.

Ajouté dans la version 253.

-d, --no-wtmp

N'écrit pas d'entrée d'arrêt dans wtmp.

Ajouté dans la version 253.

-n, --no-sync

Ne synchronise pas les disques durs/supports de stockage avant l'extinction, le redémarrage ou l'arrêt.

Ajouté dans la version 253.

--no-wall

N'envoie pas de message wall avant l'extinction, le redémarrage ou l'arrêt.

Ajouté dans la version 253.

CODE DE SORTIE

En cas de succès, 0 est retourné, un code d'échec non nul sinon.

NOTES

Ces commandes sont implémentées de manière à préserver une compatibilité de base avec les commandes SysV d'origine. Les verbes systemctl(1) poweroff, reboot, halt fournissent la même fonctionnalité avec quelques fonctionnalités supplémentaires.

Notez que sur de nombreux systèmes SysV, halt était synonyme de poweroff, c'est-à-dire que les deux commandes entraînaient l'extinction de la machine. systemd est plus précis ici, et halt ne fait qu'arrêter la machine (la laissant sous tension), et poweroff est nécessaire pour réellement l'éteindre.

VOIR AUSSI

systemd(1), systemctl(1), shutdown(8), wall(1)
