NOM

pomdump - vidage de l'arbre d'analyse POM pour un document POD

SYNOPIS

pomdump MonFichier.pm

DESCRIPTION

Ce script utilise Pod::POM pour analyser un document Pod puis invoque la méthode dump sur le nœud de plus haut niveau, résultant en une visualisation de la structure du document POD (l'arbre d'analyse).
