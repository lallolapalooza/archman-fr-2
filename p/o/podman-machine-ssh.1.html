NOM

podman-machine-ssh - Se connecter en SSH à une machine virtuelle

SYNOPSIS

podman machine ssh [options] [nom] [commande [arg ...]]

DESCRIPTION

Se connecte en SSH à une machine virtuelle gérée par Podman et exécute éventuellement une commande sur la machine virtuelle. Sauf si vous utilisez la machine virtuelle par défaut, le premier argument doit être le nom de la machine virtuelle. La commande facultative à exécuter peut alors suivre. Si aucune commande n'est fournie, une session interactive avec la machine virtuelle est établie.

Le code de sortie de la commande ssh est transmis à l'appelant podman machine ssh, voir Codes de sortie ⟨#Codes-de-sortie⟩.

Le nom de la machine par défaut est podman-machine-default. Si aucun nom de machine n'est spécifié comme argument, alors podman-machine-default sera utilisé pour la connexion SSH.

Uniquement sans privilèges root.

OPTIONS

--help

Affiche l'énoncé d'utilisation.

--username=nom

Nom d'utilisateur à utiliser lors de la connexion SSH à la VM.

CODES DE SORTIE

Le code de sortie de podman machine ssh donne des informations sur la raison de l'échec de la commande. Lorsque les commandes podman machine ssh se terminent avec un code non nul, les codes de sortie suivent la norme chroot, voir ci-dessous :

125 L'erreur concerne podman lui-même

$ podman machine ssh --foo; echo $?
Error: unknown flag: --foo
125

126 Exécution d'une commande contenue et la commande ne peut pas être invoquée

$ podman machine ssh /etc; echo $?
Error: fork/exec /etc: permission denied
126

127 Exécution d'une commande contenue et la commande est introuvable

$ podman machine ssh foo; echo $?
Error: fork/exec /usr/bin/bogus: no such file or directory
127

Code de sortie code de sortie de la commande contenue

$ podman machine ssh /bin/sh -c 'exit 3'; echo $?
3

EXEMPLES

Pour obtenir une session interactive avec la machine Podman par défaut :

Se connecter en SSH à la machine Podman par défaut.

$ podman machine ssh

Exécuter une commande à l'intérieur de la machine Podman par défaut via SSH.

$ podman machine ssh myvm

Exécuter une commande à l'intérieur de la machine Podman spécifiée via SSH.

$ podman machine ssh myvm rpm -q podman
