NOM

podman-container-prune - Supprime tous les conteneurs arrêtés du stockage local

SYNOPSIS

podman container prune [options]

DESCRIPTION

podman container prune supprime tous les conteneurs arrêtés du stockage local.

OPTIONS

--filter=filtres

Fournit des valeurs de filtre.

Le format de l'argument filtres est de type clé=valeur. S'il y a plus d'un filtre, passez plusieurs OPTIONS : --filter foo=bar --filter bif=baz.

Filtres supportés :

Filtre Description
label Supprime uniquement les conteneurs avec (ou sans, si label!=[...] est utilisé) les étiquettes spécifiées.
until Supprime uniquement les conteneurs créés avant l'horodatage donné.

Le filtre label accepte deux formats. L'un est label=clé ou label=clé=valeur, qui supprime les conteneurs avec les étiquettes spécifiées. L'autre format est label!=clé ou label!=clé=valeur, qui supprime les conteneurs sans les étiquettes spécifiées.

Le filtre until peut être des horodatages Unix, des horodatages formatés en date, ou des chaînes de durée Go (par exemple, 10m, 1h30m) calculées par rapport à l'heure de la machine.

--force, -f

Ne pas fournir d'invite interactive pour la suppression des conteneurs.
La valeur par défaut est false.

-h, --help

Afficher l'énoncé d'utilisation.
La valeur par défaut est false.
