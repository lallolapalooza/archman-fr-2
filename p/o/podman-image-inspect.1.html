NOM

podman-image-inspect - Afficher la configuration d'une image

SYNTAXE

podman image inspect [options] image [image ...]

DESCRIPTION

Affiche les informations de bas niveau sur les images identifiées par leur nom ou leur ID. Par défaut, toutes les résultats sont affichés sous forme de tableau JSON. Si un format est spécifié, le modèle donné est exécuté pour chaque résultat.

OPTIONS

--format, -f=format

Met en forme la sortie à l'aide du modèle Go spécifié. Les clés du JSON retourné peuvent être utilisées comme valeurs pour le drapeau --format (voir les exemples ci-dessous).

Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Placeholder Description
.Annotations ... Informations sur les annotations incluses dans l'image
.Architecture Architecture du logiciel dans l'image
.Author Auteur de l'image
.Comment Commentaire de l'image
.Config ... Structure avec les informations de configuration
.Created ... Heure de création de l'image (chaîne, ISO3601)
.Digest Digest de l'image (hash de 64 caractères sha256:+)
.GraphDriver ... Structure pour les informations du pilote graphique
.HealthCheck ... Structure pour les informations de vérification de santé
.History Informations sur l'historique stockées dans l'image
.ID ID de l'image (hash complet de 64 caractères)
.Labels ... Informations sur les étiquettes incluses dans l'image
.ManifestType Type de manifeste de l'image
.NamesHistory Informations sur l'historique des noms stockées dans l'image
.Os Système d'exploitation du logiciel dans l'image
.Parent Image parente de l'image spécifiée
.RepoDigests Digests du dépôt pour l'image
.RepoTags Tags du dépôt pour l'image
.RootFS ... Structure pour les informations du système de fichiers racine
.Size Taille de l'image, en octets
.User Utilisateur par défaut pour exécuter l'image
.Version Version de l'image
.VirtualSize Taille virtuelle de l'image, en octets
