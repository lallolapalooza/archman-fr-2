podman-save(1) Manuel des commandes générales podman-save(1)

NOM

podman-save - Enregistrer une ou plusieurs images dans une archive

SYNOPIS

podman save [options] nom[:étiquette]

podman image save [options] nom[:étiquette]

DESCRIPTION

podman save enregistre une image dans un fichier ou un répertoire local. podman save écrit sur la sortie standard (STDOUT) par défaut et peut être redirigé vers un fichier en utilisant l'option output. L'option quiet supprime la sortie lorsqu'elle est activée. podman save enregistre les couches parentes des images et les images peuvent être chargées en utilisant podman load. Pour exporter des conteneurs, utilisez podman export. Remarque : : est un caractère restreint et ne peut pas faire partie du nom de fichier.

OPTIONS

--compress

Compresse les couches d'images tarball lors de l'envoi vers un répertoire en utilisant le transport 'dir'. (la valeur par défaut est le même type de compression, compressé ou non compressé, que la source)

Remarque : Cette option ne peut être définie qu'avec --format=docker-dir.

--format=format

Un format d'image à produire, l'un des suivants :

Format Description
docker-archive Une archive tar interopérable avec docker load(1) (par défaut)
oci-archive Une archive tar utilisant le format d'image OCI
oci-dir Un répertoire utilisant le format d'image OCI
docker-dir Transport dir (voir containers-transports(5)) avec le type de manifeste v2s2

--help, -h

Affiche le message d'utilisation

--multi-image-archive, -m

Permet la création d'archives contenant plus d'une image. Les noms supplémentaires sont interprétés comme des images plutôt que des étiquettes. Uniquement pris en charge pour --format=docker-archive. La valeur par défaut pour cette option peut être modifiée via le drapeau multi_image_archive="true"|"false" dans containers.conf.

--output, -o=fichier

Écrire dans un fichier, la valeur par défaut est STDOUT

--quiet, -q

Supprimer la sortie

--uncompressed

Accepte les couches non compressées lors de l'utilisation de l'un des formats OCI.

EXEMPLES

Enregistrer une image dans un fichier local sans afficher la progression.

$ podman save --quiet -o alpine.tar alpine:2.6

Enregistrer une image sur la sortie standard et rediriger le contenu via le shell.

$ podman save alpine > alpine-all.tar

Enregistrer une image au format oci-archive dans le fichier local.

$ podman save -o oci-alpine.tar --format oci-archive alpine

Enregistrer une image compressée au format docker-dir.

$ podman save --compress --format docker-dir -o alp-dir alpine
