podman-volume-rm(1) Manuel des commandes générales podman-volume-rm(1)

NOM

podman-volume-rm - Supprime un ou plusieurs volumes

SYNTAXE

podman volume rm [options] volume [...]

DESCRIPTION

Supprime un ou plusieurs volumes. Seuls les volumes qui ne sont pas utilisés sont supprimés. Si un volume est utilisé par un conteneur, une erreur est retournée sauf si l'option --force est utilisée. Pour supprimer tous les volumes, utilisez l'option --all. Les volumes peuvent être supprimés individuellement en fournissant leur nom complet ou un nom partiel unique.

OPTIONS

--all, -a

Supprime tous les volumes.

--force, -f

Supprime un volume de force. S'il est utilisé par des conteneurs, les conteneurs sont supprimés en premier.

--help

Affiche le message d'utilisation

--time, -t=secondes

Secondes à attendre avant d'arrêter de force les conteneurs en cours d'exécution qui utilisent le volume spécifié. L'option --force doit être spécifiée pour utiliser l'option --time. Utilisez -1 pour attendre indéfiniment.

EXEMPLES

Supprimer plusieurs volumes spécifiés.

$ podman volume rm myvol1 myvol2

Supprimer tous les volumes.

$ podman volume rm --all

Supprimer le volume spécifié même s'il est en cours d'utilisation. Notez que cela supprime tous les conteneurs utilisant le volume.

$ podman volume rm --force myvol

STATUT DE SORTIE

0 Tous les volumes spécifiés ont été supprimés

1 L'un des volumes spécifiés n'existait pas, et aucune autre erreur

2 L'un des volumes spécifiés est utilisé par un conteneur

125 La commande échoue pour toute autre raison

VOIR AUSSI

podman(1), podman-volume(1)
