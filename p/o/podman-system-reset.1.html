NOM

podman-system-reset - Réinitialiser le stockage à l'état initial

SYNOPSIS

podman system reset [options]

DESCRIPTION

podman system reset supprime tous les pods, conteneurs, images, réseaux et volumes, ainsi que les machines. Il supprime également les répertoires configurés graphRoot et runRoot. Assurez-vous que ceux-ci ne sont pas définis sur un répertoire important.

Cette commande doit être exécutée avant de modifier l'un des champs suivants dans les fichiers containers.conf ou storage.conf : driver, static_dir, tmp_dir ou volume_path.

podman system reset lit la configuration actuelle et tente de supprimer toutes les configurations pertinentes. Si l'administrateur a modifié les fichiers de configuration en premier, podman system reset pourrait ne pas pouvoir nettoyer le stockage précédent.

podman system reset ne redémarre pas les unités systemd podman.service et podman.socket. Vous devrez peut-être les redémarrer manuellement après avoir exécuté cette commande.

OPTIONS

--force, -f

Ne pas demander de confirmation

--help, -h

Afficher le message d'utilisation

EXEMPLES

Réinitialiser tout le stockage à un état initial propre.

$ podman system reset
ATTENTION ! Ceci va supprimer :
        - tous les conteneurs
        - tous les pods
        - toutes les images
        - tous les réseaux
        - le cache de build
        - toutes les machines
        - tous les volumes
        - le répertoire graphRoot : /var/lib/containers/storage
        - le répertoire runRoot : /run/containers/storage
Êtes-vous sûr de vouloir continuer ? [y/N] y

Forcer la réinitialisation de tout le stockage à un état initial propre.

$ podman system reset --force

Passer l'utilisateur sans root du pilote VFS à overlay avec fuse-overlayfs

Si l'utilisateur a exécuté des conteneurs sans root sans avoir le programme fuse-overlayfs installé, podman utilise par défaut le stockage vfs dans son répertoire personnel. S'il souhaite passer à l'utilisation de fuse-overlay, il doit installer le paquet fuse-overlayfs. L'utilisateur doit d'abord exécuter podman system reset en tant qu'utilisateur pour supprimer le stockage VFS. L'utilisateur peut maintenant modifier le fichier /etc/containers/storage.conf pour apporter les modifications nécessaires. Si la valeur par défaut du système était déjà overlay, alors aucune modification n'est nécessaire pour passer à fuse-overlayfs. Podman recherche l'existence de fuse-overlayfs pour l'utiliser lorsqu'il est défini dans le pilote overlay, ne revenant à vfs que si le programme n'existe pas. Les utilisateurs peuvent exécuter podman info pour s'assurer que Podman utilise fuse-overlayfs et le pilote overlay.
