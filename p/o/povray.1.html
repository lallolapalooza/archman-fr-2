NOM

povray - POV-Ray : The Persistence of Vision Ray Tracer

SYNTAXE

povray [+Ofichier_sortie] [+/-option ...] [fichier_entree]

povray [+Ifichier_entree] [+Ofichier_sortie] [+/-option ...] [fichier_INI]

DESCRIPTION

POV-Ray est un ray tracer gratuit et complet, écrit et maintenu par une équipe de volontaires sur Internet. Sur la plateforme UNIX, POV-Ray peut être compilé avec le support des capacités de prévisualisation en utilisant le système de fenêtrage X Window.

Cette page de manuel ne liste que les fonctionnalités et options de ligne de commande de base pour POV-Ray et spécifiques à UNIX pour cette version de POV-Ray. Pour une description complète des fonctionnalités de POV-Ray et de son langage de description de scène (également appelé POV-Ray SDL), ou pour une meilleure explication de la signification des options de ligne de commande et de fichier INI, veuillez consulter la documentation qui devrait accompagner toutes les versions de POV-Ray. La documentation est installée dans PREFIX/share/doc/povray-3.7, où PREFIX est /usr/local par défaut, ou un chemin spécifié lors de la configuration du paquet source pour la compilation et l'installation.

Certaines des fonctionnalités spécifiques à UNIX sont :

Le support de l'affichage X Window utilise automatiquement la meilleure classe visuelle et la profondeur la plus élevée disponibles. Pour les visuels qui ne supportent pas 24 bits de couleur par pixel, la dithérisation par diffusion d'erreur de Floyd-Steinberg est utilisée, ainsi qu'une palette allouée dynamiquement et optimisée pour produire le meilleur affichage possible avec le visuel, la profondeur et la palette de couleurs actuels disponibles.
La conformité CCCI pour la version X Window signifie que la fenêtre de prévisualisation se comportera comme les programmes X Window standard, communiquera correctement avec le gestionnaire de fenêtres et acceptera les options de ligne de commande standard. Voir X(1) pour plus d'informations.
Les graphiques ASCII dans la version en mode texte permettent une vue de base du rendu actuel sur des terminaux uniquement texte.
Un gestionnaire d'interruption permet d'interrompre le rendu de manière sûre, de sorte que toute donnée non encore écrite sur le disque soit sauvegardée avant de quitter. Control-C ou SIGINT provoquera une interruption par l'utilisateur et sauvegardera le rendu actuel avant de quitter. Voir kill(1) pour plus d'informations.
Le rendu indépendant de la plateforme et de l'architecture signifie que la même scène sera rendue de la même manière sur tous les ordinateurs et systèmes d'exploitation (à l'exception de la vitesse de rendu, bien sûr).

OPTIONS

Les options peuvent être spécifiées avec un '+' ou un '-' en préfixe. De nombreuses options sont des commutateurs, ce qui signifie qu'un '+' active l'option et un '-' la désactive. Pour d'autres options, peu importe si un '+' ou un '-' est utilisé. La plupart des options ne peuvent pas contenir d'espaces, vous devez donc spécifier +FN plutôt que +F N, et la combinaison d'options n'est pas autorisée, donc +SC est très différent de +S +C. Les options ne sont pas sensibles à la casse.

Les options de ligne de commande sont présentées ci-dessous avec leurs options de fichier INI correspondantes. Si la même option est spécifiée plusieurs fois, que ce soit dans des fichiers INI ou sur la ligne de commande, la dernière option de ce type remplace toutes les précédentes, à l'exception de l'option +L ou Library_Path, qui est cumulative.

Options de parsing :

I<nom_fichier_entree> ou Nom_Fichier_Entree=fichier
Spécifie le fichier d'entrée à utiliser. Si le nom du fichier d'entrée est '-', la description de scène sera lue depuis l'entrée standard. Le
HI<nom_fichier_inclusion_entete> ou Inclusion_Entete=fichier
Spécifie un fichier comme premier fichier d'inclusion d'un fichier de scène. Ceci peut être utilisé pour inclure toujours un ensemble spécifique de fichiers d'inclusion par défaut utilisés par toutes vos scènes.
L<chemin_bibliotheque> ou Chemin_Bibliotheque=chemin
Spécifie un répertoire où rechercher les fichiers d'entrée, les fichiers d'inclusion, les polices et les cartes d'images, si le fichier spécifié n'est pas dans le répertoire courant. Ceci peut être spécifié plusieurs fois pour augmenter le nombre de répertoires à rechercher.
MVn.n ou Version=flottant
Traite les fichiers de scène comme s'ils étaient de la version n.n au lieu de la version actuelle. Ceci peut être outrepassé depuis le fichier de scène.
SU ou Diviser_Unions=bool
Divise les unions CSG bornées si les enfants sont finis. Ceci permet la mise en boîte automatique des objets CSG.
UR ou Supprimer_Bornes=bool
Supprime les objets de boîte inutiles. Ceci permet la mise en boîte automatique des anciens fichiers de scène.
BM1 ou Methode_Mise_En_Boite=1
Active la mise en boîte BVH (Bounding Volume Hierarchy) (par défaut).
BM2 ou Methode_Mise_En_Boite=2
Active la mise en boîte par arbre BSP (Binary Space Partitioning).

Options de sortie :

Hn ou Hauteur=entier
L'image doit faire n pixels de haut.
Wn ou Largeur=entier
L'image doit faire n pixels de large.
SRn ou Ligne_Debut=entier
Commence le rendu à la ligne n depuis le haut de l'écran.
SR0.n ou Ligne_Debut=flottant
Commence le rendu à n pour cent depuis le haut de l'écran.
ERn ou Ligne_Fin=entier
Termine le rendu à la ligne n depuis le haut de l'écran.
ER0.n ou Ligne_Fin=flottant
Termine le rendu à n pour cent depuis le haut de l'écran.
SCn ou Colonne_Debut=entier
Commence le rendu à la colonne n depuis la gauche de l'écran.
SC0.n ou Colonne_Debut=flottant
Commence le rendu à n pour cent depuis la gauche de l'écran.
ECn ou Colonne_Fin=entier
Termine le rendu à la colonne n depuis la gauche de l'écran.
EC0.n ou Colonne_Fin=flottant
Termine le rendu à n pour cent depuis la gauche de l'écran.
C ou Continuer_Trace=bool
Continue une trace précédemment interrompue.
P ou Pause_Quand_Fini=bool
Si en mode prévisualisation, fait une pause lorsque le rendu est terminé avant de fermer la fenêtre.
V ou Verbeux=bool
Affiche des messages de statut détaillés sur la progression du rendu.
WLn ou Niveau_Avertissement=entier
Définit le niveau d'avertissement à n.
X ou Tester_Interruption=bool
Active les touches 'q' et 'Q' pour interrompre un rendu en cours.
Xn ou Compteur_Test_Interruption=entier
Vérifie l'interruption utilisateur seulement tous les n pixels.

NOM

povray - The Persistence of Vision Raytracer

SYNOPSIS

povray [povray_options] scene_file

povray [povray_options] -

DESCRIPTION

This manual page describes the command-line options for POV-Ray for UNIX. POV-Ray is a powerful raytracing program that can create photorealistic images from textual descriptions. The syntax for describing scenes is general purpose and includes support for the vast majority of raytracing features such as reflections, refractions, volumetric absorption, procedural textures, and much more.

The options described below can be supplied on the command line, in an initialization file (povray.ini), or in a file specified by the GI option.

Many of the options have both a short (single letter) and a long (keyword) form. The short forms are not case sensitive, while the long forms are case sensitive.

OPTIONS

Options générales :

H or -H
Display a list of all POV-Ray command-line options.
V or -V
Display POV-Ray version information.
VA or -VA
Display POV-Ray license information.
I<input_file> or Input_File=file
Specify the scene file to render. If this option is omitted, POV-Ray prompts the user for a file name. If '-' is specified, POV-Ray reads from standard input.
D or -D
Enable debugging output. This option generates copious amounts of information that is useful for diagnosing problems. When used with POV-Ray for UNIX, it causes POV-Ray to run in the foreground and the output window is not removed from the screen when the render is complete.
SPn or Display_Pallete=char
Display palette. The default is '0'. This option is ignored on UNIX systems but is included for compatibility with other versions of POV-Ray. See also the -visual option.

Options de sortie - liées à l'affichage :

Wn or Window_Width=integer
Set the width of the output window to n pixels.
Hn or Window_Height=integer
Set the height of the output window to n pixels.
P or Preview=bool
Display a preview window during rendering. This option is recognized by POV-Ray for UNIX, but it is not functional. The preview window is disabled. For a working preview window, use the -visual option with POV-Ray or via the -visual option. Pour spécifier la palette, vous devez d'abord spécifier le type d'affichage (le deuxième caractère, indiqué ici par '0') pour des raisons de compatibilité, même s'il est ignoré dans les versions UNIX.
SPn or Preview_Start_Size=integer
Démarre l'aperçu en mosaïque avec des blocs de n pixels de côté.
EPn or Preview_End_Size=integer
Termine l'aperçu en mosaïque avec des blocs de n pixels de côté.
UD or Draw_Vistas=bool
Dessiner les rectangles de vue avant que le rendu ne soit obsolète.

Options de sortie - liées aux fichiers :

F[CEHJNPST][n] or Output_to_File=bool Output_File_Type=char
Enregistre l'image rendue en utilisant l'un des formats disponibles, à savoir TGA comprimé, OpenEXR, Radiance à haute plage dynamique, JPEG, PNG, PPM, Spécifique au système (PNG) et TGA.
O<fichier_sortie> or Output_File_Name=file
Écrit la sortie dans le fichier nommé fichier_sortie, ou la sortie standard si '-' est donné comme nom de fichier de sortie.
MIn or Max_Image_Buffer_Memory=n
Définit la taille autorisée du cache d'image de sortie en mégaoctets.

Options de traçage :

MBn or Bounding=bool Bounding_Threshold=integer
Utilise des dalles de délimitation automatiques si plus de n objets se trouvent dans la scène.
Qn ou Quality=integer
Rendu à la qualité n. Les qualités vont de 0 pour des images brutes et 9 pour un traçage de rayons et des textures complets, et 10 et 11 ajoutent la radiosité.
A0.n or Antialias=bool Antialias_Threshold=integer
Effectue l'anticrénelage sur les pixels jusqu'à ce que la différence entre les pixels adjacents soit inférieure à 0.n, ou que la profondeur de récursion maximale soit atteinte.
AMn or Sampling_Method=integer
Spécifie la méthode d'anticrénelage utilisée, non adaptative (n = 1), ou anticrénelage adaptatif (n = 2).
Jn.n or Jitter=bool Jitter_Amount=float
Spécifie le rayon maximal, en pixels, à partir duquel les échantillons anticrénelés doivent être décalés par rapport à leurs centres réels.
Rn or Antialias_Depth=integer
Définit la profondeur de récursion maximale pour le sous-échantillonnage de pixel anticrénelé.
UA or Output_Alpha=bool
Utilise le canal alpha pour le masque de transparence.
UL or Light_Buffer=bool
L'utilisation du tampon lumineux pour accélérer le rendu est obsolète.
UV or Vista_Buffer=bool
L'utilisation du tampon de vue pour accélérer le rendu est obsolète.

Options d'animation :

Kn.n or Clock=float
Rend une seule image d'une animation avec la valeur de l'horloge n.n.
KFIn or Initial_Frame=integer
Spécifie le numéro de la première image d'une animation.
KFFn or Final_Frame=integer
Spécifie le numéro de la dernière image d'une animation. Ceci doit être défini à une valeur autre que 1 pour rendre plusieurs images à la fois.
KIn.n or Initial_Clock=float
Spécifie la valeur de l'horloge pour la première image d'une animation.
KFn.n or Final_Clock=float
Spécifie la valeur de l'horloge pour la dernière image d'une animation.
SFn or Subset_Start_Frame=integer
Rend un sous-ensemble d'images d'une animation, en commençant à l'image n.
SF0.n or Subset_Start_Frame=float
Rend un sous-ensemble d'images d'une animation, en commençant n pour cent dans l'animation.
EFn or Subset_End_Frame=integer
Rend un sous-ensemble d'images d'une animation, en s'arrêtant à l'image n.
EF0.n or Subset_End_Frame=float
Rend un sous-ensemble d'images d'une animation, en s'arrêtant n pour cent dans l'animation.
KC or Cyclic_Animation=bool
Génère des valeurs d'horloge pour une animation cyclique.
UF or Field_Render=bool
Rend les images alternées en utilisant les champs impairs/pairs, adapté pour une sortie entrelacée.
UO or Odd_Field=bool
Commence une animation rendue par champ sur le champ impair, plutôt que sur le champ pair.

Options de redirection :

GI<name> or Create_Ini=bool or Create_Ini=file
Écrit tous les paramètres INI dans un fichier portant le nom du fichier de scène d'entrée, ou un avec le nom spécifié.
G[ADFRSW]<name> or <Stream>_File=bool or <Stream>_File=file
Écrit le flux dans la console et/ou le fichier spécifié. Les flux sont All_File (sauf statut), Debug_File, Fatal_File, Render_File, Statistics_File, et Warning_File.

Options du système de fenêtrage X :

En plus des options de ligne de commande standard, POV-Ray reconnaît des commutateurs de ligne de commande supplémentaires liés au système de fenêtrage X. Voir X(1) pour une description complète de ces options.

-display <nom_affichage>
Affiche l'aperçu sur nom_affichage plutôt que sur l'affichage par défaut. Ceci est destiné à être utilisé pour changer l'affichage vers un hôte distant. L'option d'affichage normale +d est toujours valide.
-geometry [LARGEURxHAUTEUR][+OFFSET_X+OFFSET_Y]
Rend l'image avec LARGEUR et HAUTEUR comme dimensions, et positionne la fenêtre à OFFSET_X du bord gauche, et OFFSET_Y du bord supérieur de l'écran (ou si négatif des bords droit et inférieur respectivement). La LARGEUR et la HAUTEUR, si elles sont données, remplacent tous les paramètres précédents Wn et Hn.
-help
Affiche la liste des options spécifiques au système de fenêtrage X. Utiliser -H seul sur la ligne de commande pour afficher les options générales de POV-Ray.
-icon
Démarre la fenêtre d'aperçu en tant qu'icône.
-title <titre_fenetre>
Remplace le titre par défaut de la fenêtre d'aperçu par titre_fenetre.
-visual <type_visuel>
Utilise le visuel le plus profond de type_visuel, s'il est disponible, au lieu du visuel sélectionné automatiquement. Les visuels valides sont StaticGray, GrayScale, StaticColor, PseudoColor, TrueColor, ou DirectColor.

RESSOURCES

Actuellement, aucun fichier de ressource X ou d'application par défaut n'est pris en charge pour les options du système de fenêtrage X.

FICHIERS

POV-Ray pour UNIX permet un fichier povray.ini dans le répertoire courant pour remplacer les paramètres individuels dans $HOME/.povray/3.7/povray.ini. POV-Ray recherche les informations de configuration initiales, comme les paramètres Library_Path, qui indiquent l'emplacement des fichiers d'inclusion standard, d'abord dans la variable d'environnement $POVINI, puis dans ./povray.ini, puis dans $HOME/.povray/3.7/povray.ini, puis dans PREFIX/etc/povray/3.7/povray.ini. Le répertoire PREFIX peut être modifié à la compilation à l'aide de l'option --prefix du script configure. Pour la compatibilité ascendante avec POV-Ray version 3.5 et antérieures, les fichiers $HOME/.povrayrc et $PREFIX/etc/povray.ini sont également recherchés lorsque aucun des fichiers ci-dessus n'a été trouvé.

Depuis la version 3.5, POV-Ray dispose d'un mécanisme de restriction des E/S. Les restrictions d'E/S tentent de protéger au moins partiellement une machine exécutant POV-Ray contre la lecture ou l'écriture de fichiers en dehors d'un ensemble donné de répertoires. Les paramètres sont définis dans deux fichiers de configuration, un fichier PREFIX/etc/povray/3.7/povray.conf au niveau du système et un fichier $HOME/.povray/3.7/povray.conf au niveau utilisateur avec des paramètres plus restrictifs. À partir de POV-Ray 3.6, le format de ces fichiers de configuration a changé et aucune compatibilité ascendante n'est conservée avec les fichiers de configuration de POV-Ray 3.5. Voir la documentation pour plus de détails et des exemples de paramètres de restriction d'E/S.
