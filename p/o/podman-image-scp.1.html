NOM

podman-image-scp - Copier une image en toute sécurité d'un hôte à un autre

SYNOPSIS

podman image scp [options] nom[:tag]

DESCRIPTION

podman image scp copie les images de conteneur entre des hôtes sur un réseau. Cette commande peut copier des images vers l'hôte distant ou depuis l'hôte distant, ainsi qu'entre deux hôtes distants. Note : :: est utilisé pour spécifier le nom de l'image selon que Podman enregistre ou charge. Les images peuvent également être transférées du stockage rootful vers le stockage rootless sur la même machine sans utiliser sshd. Cette fonctionnalité n'est pas prise en charge sur le client distant, y compris sur les machines Mac et Windows (à l'exception de WSL2).

podman image scp [OPTIONS GLOBALES]

podman image scp [OPTIONS] NOM[:TAG] [NOM_HOTE::]

podman image scp [OPTIONS] [NOM_HOTE::]NOM_IMAGE

podman image scp [OPTIONS] [NOM_HOTE::]NOM_IMAGE [NOM_HOTE::]

OPTIONS

--help, -h

Afficher le message d'utilisation

--quiet, -q

Supprimer la sortie

EXEMPLES

Copier l'image spécifiée vers le stockage local :

$ podman image scp alpine
Loaded image: docker.io/library/alpine:latest

Copier l'image spécifiée depuis le stockage local vers la connexion distante :

$ podman image scp alpine Fedora::/home/charliedoern/Documents/alpine
Getting image source signatures
Copying blob 72e830a4dff5 done
Copying config 85f9dc67c7 done
Writing manifest to image destination
Storing signatures
Loaded image: docker.io/library/alpine:latest

Copier l'image spécifiée depuis la connexion distante vers la connexion distante :

$ podman image scp Fedora::alpine RHEL::
Loaded image: docker.io/library/alpine:latest

Copier l'image spécifiée via ssh vers le stockage local :

$ podman image scp charliedoern@192.168.68.126:22/run/user/1000/podman/podman.sock::alpine
WARN[0000] Unknown connection name given. Please use system connection add to specify the default remote socket location
Getting image source signatures
Copying blob 9450ef9feb15 [--------------------------------------] 0.0b / 0.0b
Copying config 1f97f0559c done
Writing manifest to image destination
Storing signatures
Loaded image: docker.io/library/alpine:latest

Copier l'image spécifiée du compte root vers le stockage local des comptes utilisateur :

$ sudo podman image scp root@localhost::alpine username@localhost::
