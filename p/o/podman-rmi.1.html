podman-rmi(1) Manuel des commandes générales podman-rmi(1)

NOM

podman-rmi - Supprimer une ou plusieurs images stockées localement

SYNTAXE

podman rmi [options] image [...]

podman image rm [options] image [...]

DESCRIPTION

Supprime une ou plusieurs images stockées localement. Passer un argument image le supprime, ainsi que toutes ses images parentes orphelines. Une image orpheline est une image sans étiquette et qui n'est référencée par aucune autre image.

Note : Pour supprimer une image d'un registre distant, utilisez la commande skopeo delete. Certains registres ne permettent pas aux utilisateurs de supprimer une image via une interface CLI à distance.

OPTIONS

--all, -a

Supprime toutes les images du stockage local.

--force, -f

Cette option force Podman à supprimer tous les conteneurs qui utilisent l'image avant de supprimer l'image du système.

--ignore, -i

Si une image spécifiée n'existe pas dans le stockage local, l'ignore et ne génère pas d'erreur.

--no-prune

Cette option ne supprime pas les images parentes orphelines de l'image spécifiée.

EXEMPLES

Supprimer une image par son ID court

$ podman rmi c0ed59d05ff7

Supprimer une image et ses conteneurs associés.

$ podman rmi --force ID_image

Supprimer plusieurs images par leurs ID raccourcis.

$ podman rmi c4dfb1609ee2 93fd78260bd1 c0ed59d05ff7

Supprimer toutes les images et tous les conteneurs.

$ podman rmi -a -f

Supprimer une image absente avec et sans le drapeau --ignore.

$ podman rmi --ignore nothing
$ podman rmi nothing
Erreur : nothing : image inconnue

Supprimer une image tout en conservant ses images parentes.

podman rmi --no-prune d29200bf974d
Supprimé : d29200bf974dbc48dc66c23c4031548531b6b5943e5f25ee7bda232e3b6b27f4

STATUT DE SORTIE

0 Toutes les images spécifiées ont été supprimées

1 L'une des images spécifiées n'existait pas, et aucun autre échec

2 L'une des images spécifiées a des images enfants ou est utilisée par un conteneur

125 La commande échoue pour toute autre raison

podman(1), skopeo-delete(1)
