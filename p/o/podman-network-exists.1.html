NOM

podman-network-exists - Vérifie si le réseau donné existe

SYNTAXE

podman network exists réseau

DESCRIPTION

podman network exists vérifie si un réseau existe. Le Nom ou l'ID du réseau peuvent être utilisés comme entrée. Podman renvoie un code de sortie de 0 lorsque le réseau est trouvé. Un code de sortie de 1 est renvoyé dans le cas contraire. Un code de sortie de 125 indique qu'il y a eu un autre problème.

OPTIONS

--help, -h

Affiche l'énoncé d'utilisation

EXEMPLE

Vérifier si le réseau spécifié existe (le réseau existe réellement) :

$ podman network exists net1
$ echo $?
0

Vérifier si un réseau inexistant existe :

$ podman network exists webbackend
$ echo $?
1

VOIR AUSSI

podman(1), podman-network(1)
