POSIX_SPAWN_FILE_ACTIONS_DESTROY(3P) Manuel du programmeur POSIX POSIX_SPAWN_FILE_ACTIONS_DESTROY(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_spawn_file_actions_destroy, posix_spawn_file_actions_init — détruire et initialiser un objet d'actions de fichier de création (TEMPS RÉEL AVANCÉ)

SYNTAXE

#include <spawn.h>
int posix_spawn_file_actions_destroy(posix_spawn_file_actions_t
    *file_actions);
int posix_spawn_file_actions_init(posix_spawn_file_actions_t
    *file_actions);

DESCRIPTION

La fonction posix_spawn_file_actions_destroy() détruit l'objet référencé par file_actions ; l'objet devient, en effet, non initialisé. Une implémentation peut provoquer la définition par posix_spawn_file_actions_destroy() de l'objet référencé par file_actions à une valeur invalide. Un objet d'actions de fichier de création détruit peut être réinitialisé à l'aide de posix_spawn_file_actions_init() ; les résultats d'une référence à l'objet autrement après sa destruction sont indéfinis.

La fonction posix_spawn_file_actions_init() initialise l'objet référencé par file_actions pour qu'il ne contienne aucune action de fichier à effectuer par posix_spawn() ou posix_spawnp().

Un objet d'actions de fichier de création est tel que défini dans posix_spawn_file_actions_addclose().

L'effet de l'initialisation d'un objet d'actions de fichier de création déjà initialisé est indéfini.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent zéro ; sinon, un numéro d'erreur est retourné pour indiquer l'erreur.

ERREURS

La fonction posix_spawn_file_actions_init() échoue si :

ENOMEM
Il n'y a pas assez de mémoire pour initialiser l'objet d'actions de fichier de création.

La fonction posix_spawn_file_actions_destroy() peut échouer si :

EINVAL
La valeur spécifiée par file_actions est invalide.

UTILISATION APPLICATION

Ces fonctions font partie de l'option Spawn et ne sont pas nécessairement fournies sur toutes les implémentations.

RATIONALE
