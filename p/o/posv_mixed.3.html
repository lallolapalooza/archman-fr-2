sous-routine dsposv (character uplo, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( n, * ) work, real, dimension( * ) swork, integer iter, integer info)

DSPOSV calcule la solution du système d'équations linéaires A * X = B pour les matrices PO

Objectif :

!>
!> DSPOSV calcule la solution d'un système d'équations linéaires réelles
!>    A * X = B,
!> où A est une matrice symétrique définie positive de taille N×N et X et B
!> sont des matrices de taille N×NRHS.
!>
!> DSPOSV tente d'abord de factoriser la matrice en PRÉCISION SIMPLE
!> et utilise cette factorisation dans une procédure de raffinement itératif
!> pour produire une solution avec une qualité de la norme de l'erreur arrière
!> en PRÉCISION DOUBLE (voir ci-dessous). Si l'approche échoue, la méthode
!> bascule vers une factorisation et une résolution en PRÉCISION DOUBLE.
!>
!> Le raffinement itératif ne sera pas une stratégie gagnante si
!> le rapport performance en PRÉCISION SIMPLE sur performance en PRÉCISION
!> DOUBLE est trop faible. Une stratégie raisonnable devrait prendre en compte
!> le nombre de côtés droits et la taille de la matrice.
!> Ceci pourrait être fait avec un appel à ILAENV à l'avenir. Jusqu'à présent,
!> nous essayons toujours le raffinement itératif.
!>
!> Le processus de raffinement itératif est arrêté si
!>     ITER > ITERMAX
!> ou pour tous les RHS nous avons :
!>     RNRM < SQRT(N)*XNRM*ANRM*EPS*BWDMAX
!> où
!>     o ITER est le nombre de l'itération actuelle dans le processus de
!>       raffinement itératif
!>     o RNRM est la norme infinie du résidu
!>     o XNRM est la norme infinie de la solution
!>     o ANRM est la norme d'opérateur infinie de la matrice A
!>     o EPS est l'epsilon machine renvoyé par DLAMCH('Epsilon')
!> Les valeurs ITERMAX et BWDMAX sont fixées à 30 et 1.0D+00 respectivement.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau de DOUBLE PRECISION,
!>          dimension (LDA,N)
!>          À l'entrée, la matrice symétrique A.  Si UPLO = 'U', la partie
!>          triangulaire supérieure N×N de tête contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          triangulaire inférieure de A n'est pas référencée.  Si UPLO = 'L',
!>          la partie triangulaire inférieure N×N de tête contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          triangulaire supérieure de A n'est pas référencée.
!>          À la sortie, si le raffinement itératif a été utilisé avec succès
!>          (INFO = 0 et ITER >= 0, voir la description ci-dessous), alors A
!>          est inchangée, si la factorisation en précision double a été utilisée
!>          (INFO = 0 et ITER < 0, voir la description ci-dessous), alors le
!>          tableau A contient le facteur U ou L de la factorisation de Cholesky
!>          A = U**T*U ou A = L*L**T.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau de DOUBLE PRECISION, dimension (LDB,NRHS)
!>          La matrice B des N×NRHS côtés droits.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau de DOUBLE PRECISION, dimension (LDX,NRHS)
!>          Si INFO = 0, la matrice solution X de taille N×NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

WORK

!>          WORK est un tableau de DOUBLE PRECISION, dimension (N,NRHS)
!>          Ce tableau est utilisé pour contenir les vecteurs résiduels.
!>

SWORK

!>          SWORK est un tableau de REAL, dimension (N*(N+NRHS))
!>          Ce tableau est utilisé pour utiliser la matrice en précision simple et les
!>          vecteurs de droite ou les solutions en précision simple.
!>

ITER

!>          ITER est INTEGER
!>          < 0 : le raffinement itératif a échoué, une factorisation
!>                en précision double a été effectuée
!>               -1 : la routine a utilisé la précision complète pour des
!>                    raisons d'implémentation ou spécifiques à la machine
!>               -2 : le rétrécissement de la précision a provoqué un débordement,
!>                    la routine a utilisé la précision complète
!>               -3 : échec de SPOTRF
!>               -31: arrêt du raffinement itératif après la 30ème
!>                    itération
!>          > 0 : le raffinement itératif a été utilisé avec succès.
!>               Retourne le nombre d'itérations
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le mineur principal de tête d'ordre i
!>                de A (en DOUBLE PRECISION) n'est pas positif, donc la
!>                factorisation n'a pas pu être complétée, et la solution
!>                n'a pas été calculée.
!>

sous-routine zcposv (character uplo, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( n, * ) work, complex, dimension( * ) swork, double precision, dimension( * ) rwork, integer iter, integer info)

ZCPOSV calcule la solution du système d'équations linéaires A * X = B pour les matrices PO

Objectif :

!>
!> ZCPOSV calcule la solution d'un système d'équations linéaires complexes
!>    A * X = B,
!> où A est une matrice hermitienne définie positive de taille N×N et X et B
!> sont des matrices de taille N×NRHS.
!>
!> ZCPOSV tente d'abord de factoriser la matrice

Description Détaillée

La routine ZCPOSV effectue la résolution d'un système d'équations linéaires A*X = B pour un système complexe hermitien et défini positif en utilisant la factorisation de Cholesky, mais elle inclut une étape de raffinement itératif.

Elle utilise d'abord une factorisation en précision COMPLEX (simple précision) en conjonction avec un raffinement itératif pour produire une solution avec une qualité d'erreur de retour norme de COMPLEX*16 (double précision) (voir ci-dessous). Si l'approche échoue, la méthode bascule vers une factorisation et une résolution en COMPLEX*16.

Le raffinement itératif ne sera pas une stratégie gagnante si le ratio performance COMPLEX / performance COMPLEX*16 est trop faible. Une stratégie raisonnable devrait prendre en compte le nombre de vecteurs de droite et la taille de la matrice. Cela pourrait être fait avec un appel à ILAENV à l'avenir. Jusqu'à présent, nous essayons toujours le raffinement itératif.

Le processus de raffinement itératif est arrêté si

    ITER > ITERMAX

ou si pour tous les RHS nous avons :

    RNRM < SQRT(N)*XNRM*ANRM*EPS*BWDMAX

où

    o ITER est le numéro de l'itération courante dans le processus de
      raffinement itératif
    o RNRM est la norme infinie du résidu
    o XNRM est la norme infinie de la solution
    o ANRM est la norme d'opérateur infinie de la matrice A
    o EPS est l'epsilon machine retourné par DLAMCH('Epsilon')

Les valeurs ITERMAX et BWDMAX sont fixées respectivement à 30 et 1.0D+00.

!>          matrice A.  N >= 0.

!>          Le nombre de vecteurs de droite, c'est-à-dire le nombre de
!>          colonnes de la matrice B.  NRHS >= 0.
!>

!>          A est un tableau COMPLEX*16,
!>          de dimension (LDA,N)
!>          En entrée, la matrice hermitienne A. Si UPLO = 'U', la partie
!>          supérieure triangulaire de A de taille N-par-N contient la
!>          partie triangulaire supérieure de la matrice A, et la partie
!>          strictement triangulaire inférieure de A n'est pas référencée.
