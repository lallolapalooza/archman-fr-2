NOM

podman-machine - Gérer la machine virtuelle de Podman

SYNOPIS

podman machine sous-commande

DESCRIPTION

podman machine est un ensemble de sous-commandes qui gèrent la machine virtuelle de Podman.

Podman sous MacOS et Windows nécessite une machine virtuelle. En effet, les conteneurs sont basés sur Linux - les conteneurs ne fonctionnent pas sur d'autres systèmes d'exploitation car leurs fonctionnalités principales sont liées au noyau Linux. Podman machine doit être utilisé pour gérer les machines MacOS et Windows, mais peut être utilisé de manière optionnelle sous Linux.

Toutes les commandes podman machine sont réservées aux utilisateurs non-root.

NOTE : Le fichier de configuration de podman-machine est géré dans le répertoire $XDG_CONFIG_HOME/containers/podman/machine/. Changer la variable d'environnement $XDG_CONFIG_HOME pendant que les machines sont en cours d'exécution peut entraîner un comportement inattendu.

Le comportement de Podman machine peut être modifié via la section [machine] dans le fichier containers.conf(5).
