NOM

podman-system-migrate - Migrer les conteneurs existants vers une nouvelle version de Podman

SYNOPSIS

podman system migrate [options]

DESCRIPTION

podman system migrate migre les conteneurs vers la dernière version de Podman.

podman system migrate s'occupe de migrer les conteneurs existants vers la dernière version de Podman si un changement est nécessaire.

"Podman sans root utilise un processus de pause (pause process) pour maintenir les espaces de noms non privilégiés actifs. Cela empêche toute modification des fichiers /etc/subuid et /etc/subgid d'être propagée aux conteneurs sans root pendant que le processus de pause est en cours d'exécution.

Pour que ces modifications soient propagées, il est nécessaire d'abord d'arrêter tous les conteneurs en cours d'exécution associés à l'utilisateur, ainsi que le processus de pause, et de supprimer son fichier pid. Au lieu de le faire manuellement, podman system migrate peut être utilisé pour arrêter à la fois les conteneurs en cours d'exécution et le processus de pause. Les fichiers /etc/subuid et /etc/subgid peuvent ensuite être édités ou modifiés avec usermod pour recréer l'espace de noms utilisateur avec les mappings nouvellement configurés.

OPTIONS

--new-runtime=runtime

Définit un nouveau runtime OCI pour tous les conteneurs. Ceci peut être utilisé après une mise à niveau du système qui change le runtime OCI par défaut pour déplacer tous les conteneurs vers le nouveau runtime. Il n'y a aucune garantie que les conteneurs continueront de fonctionner sous le nouveau runtime, car certains runtimes supportent des options et des configurations différentes.

EXEMPLES

Invocation normale

### Aucune sortie n'est attendue de cette commande.
$ podman system migrate

Migration vers un nouveau runtime OCI (par exemple, de crun à runc)

### Créez un conteneur en utilisant le runtime par défaut actuel (par exemple, crun)
$ podman create --name test-alpine alpine
### Confirmez le runtime actuel
$ podman container inspect test-alpine | grep OCIRuntime
          "OCIRuntime": "crun",
### Migrez tous les conteneurs pour utiliser un nouveau runtime (par exemple, runc)
$ podman system migrate --new-runtime runc
### Vérifiez que le conteneur utilise maintenant le nouveau runtime
$ podman container inspect test-alpine | grep OCIRuntime
          "OCIRuntime": "runc",
