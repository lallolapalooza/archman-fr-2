PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour connaître les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NAME

posix_openpt — ouvrir un périphérique pseudo-terminal

SYNOPSIS

#include <stdlib.h>
#include <fcntl.h>
int posix_openpt(int oflag);

DESCRIPTION

La fonction posix_openpt() établit une connexion entre un périphérique maître pour un pseudo-terminal et un descripteur de fichier. Le descripteur de fichier est alloué comme décrit dans la Section 2.14, Allocation des descripteurs de fichiers et peut être utilisé par d'autres fonctions d'E/S qui font référence à ce pseudo-terminal.

Les drapeaux d'état de fichier et les modes d'accès au fichier de la description de fichier ouverte sont définis conformément à la valeur de oflag.

Les valeurs pour oflag sont construites par un OU inclusif au niveau du bit des drapeaux de la liste suivante, définis dans <fcntl.h> :

O_RDWR
Ouvrir en lecture et écriture.
O_NOCTTY
Si défini, posix_openpt() ne fera pas du périphérique terminal le terminal de contrôle du processus.

Le comportement des autres valeurs pour l'argument oflag n'est pas spécifié.

VALEUR DE RETOUR

En cas de succès, la fonction posix_openpt() ouvre un descripteur de fichier pour un périphérique pseudo-terminal maître et retourne un entier non négatif représentant le descripteur de fichier. Sinon, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

La fonction posix_openpt() échouera si :

EMFILE
Tous les descripteurs de fichiers disponibles pour le processus sont actuellement ouverts.
ENFILE
Le nombre maximum de fichiers autorisés est actuellement ouvert dans le système.

La fonction posix_openpt() peut échouer si :

EINVAL
La valeur de oflag n'est pas valide.
EAGAIN
Manque de ressources pseudo-terminal.
ENOSR
Manque de ressources STREAMS.

Les sections suivantes sont informatives.

EXEMPLES

Ouverture d'un pseudo-terminal et retour du nom du périphérique esclave et d'un descripteur de fichier

#include <fcntl.h>
#include <stdio.h>
int masterfd, slavefd;
char *slavedevice;
masterfd = posix_openpt(O_RDWR|O_NOCTTY);
if (masterfd == -1
    || grantpt (masterfd) == -1
    || unlockpt (masterfd) == -1
    || (slavedevice = ptsname (masterfd)) == NULL)
    return -1;
printf("le périphérique esclave est : %s\n", slavedevice);
slavefd = open(slavedevice, O_RDWR|O_NOCTTY);
if (slavefd < 0)
    return -1;

USAGE APPLICATIF

Cette fonction est une méthode pour obtenir de manière portable un descripteur de fichier d'un périphérique terminal maître pour un pseudo-terminal. Les fonctions grantpt() et ptsname() peuvent être utilisées pour manipuler les permissions de mode et de propriété, et pour obtenir le nom du périphérique esclave, respectivement.

RATIONALE

Les développeurs du standard ont examiné la question de l'ajout d'un périphérique spécial pour le clonage des pseudo-terminaux maîtres : le périphérique /dev/ptmx. Cependant, aucun consensus n'a pu être atteint, et il a été estimé que l'ajout d'une nouvelle fonction permettrait à d'autres implémentations. La fonction posix_openpt() est conçue pour compléter les fonctions grantpt(), ptsname() et unlockpt().

Sur les implémentations prenant en charge le périphérique de clonage /dev/ptmx, l'ouverture du périphérique maître d'un pseudo-terminal est simplement :

mfdp = open("/dev/ptmx", oflag );
if (mfdp < 0)
    return -1;
