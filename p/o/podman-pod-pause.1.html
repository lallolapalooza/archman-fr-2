NOM

podman-pod-pause - Met en pause un ou plusieurs pods

SYNTAXE

podman pod pause [options] pod ...

DESCRIPTION

Met en pause tous les processus en cours d'exécution dans les conteneurs d'un ou plusieurs pods. Vous pouvez utiliser les identifiants ou les noms des pods comme entrée.

OPTIONS

--all, -a

Met en pause tous les pods.

--latest, -l

Au lieu de fournir le nom ou l'identifiant du pod, met en pause le dernier pod créé. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (hors WSL2))

EXEMPLES

Mettre en pause un pod avec un nom donné :

$ podman pod pause monpodwebserveur

Mettre en pause un pod avec un identifiant donné :

$ podman pod pause 860a4b23

Mettre en pause tous les pods

$ podman pod pause --all
