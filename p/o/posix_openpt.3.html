posix_openpt(3) Manuel des fonctions de bibliothèque posix_openpt(3)

NOM

posix_openpt - ouvrir un périphérique de pseudo-terminal

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <stdlib.h>
#include <fcntl.h>
int posix_openpt(int flags);
Exigences de macro de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

posix_openpt():

    _XOPEN_SOURCE >= 600

DESCRIPTION

La fonction posix_openpt() ouvre un périphérique maître de pseudo-terminal inutilisé, renvoyant un descripteur de fichier qui peut être utilisé pour faire référence à ce périphérique.

L'argument flags est un masque de bits qui combine zéro ou plusieurs des indicateurs suivants :

O_RDWR
Ouvre le périphérique pour la lecture et l'écriture. Il est d'usage de spécifier cet indicateur.
O_NOCTTY
Ne fait pas de ce périphérique le terminal de contrôle du processus.

VALEUR DE RETOUR

En cas de succès, posix_openpt() renvoie un descripteur de fichier (un entier non négatif) qui est le descripteur de fichier inutilisé avec le plus petit numéro. En cas d'échec, -1 est renvoyé, et errno est défini pour indiquer l'erreur.

ERREURS

Voir open(2).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
posix_openpt () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.2.1. POSIX.1-2001.

Il fait partie du support des pseudo-terminaux UNIX 98 (voir pts(4)).

NOTES

Certaines anciennes implémentations UNIX qui supportent les pseudo-terminaux System V (alias UNIX 98) n'ont pas cette fonction, mais elle peut être facilement implémentée en ouvrant le périphérique multiplexeur de pseudo-terminal :


int
posix_openpt(int flags)
{
    return open("/dev/ptmx", flags);
}

Appeler posix_openpt() crée un nom de chemin pour le périphérique esclave de pseudo-terminal correspondant. Le nom de chemin du périphérique esclave peut être obtenu en utilisant ptsname(3). Le nom de chemin du périphérique esclave n'existe que tant que le périphérique maître est ouvert.

VOIR AUSSI

open(2), getpt(3), grantpt(3), ptsname(3), unlockpt(3), pts(4), pty(7)
