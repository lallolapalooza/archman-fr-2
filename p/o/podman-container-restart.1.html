podman-restart(1) Manuel des commandes générales podman-restart(1)

NOM

podman-restart - Redémarre un ou plusieurs conteneurs

SYNTAXE

podman restart [options] conteneur ...

podman container restart [options] conteneur ...

DESCRIPTION

La commande restart permet de redémarrer des conteneurs en utilisant leur ID ou leur nom. Les conteneurs en cours d'exécution sont arrêtés puis redémarrés. Les conteneurs arrêtés sont démarrés.

OPTIONS

--all, -a

Redémarre tous les conteneurs, quel que soit leur état actuel.

--cidfile

Lit l'ID du conteneur depuis le fichier spécifié et redémarre le conteneur. Peut être spécifié plusieurs fois.

--filter, -f=filtre

Filtre les conteneurs à redémarrer. Plusieurs filtres peuvent être fournis en utilisant plusieurs fois l'option --filter. Les filtres de même clé fonctionnent de manière inclusive, à l'exception de label qui est exclusive. Les filtres de clés différentes fonctionnent toujours de manière exclusive.

Les filtres valides sont listés ci-dessous :

Filtre Description
id [ID] ID du conteneur (correspondance partielle de préfixe CID par défaut ; accepte les regex)
name [Nom] Nom du conteneur (accepte les regex)
label [Clé] ou [Clé=Valeur] Étiquette assignée à un conteneur
exited [Int] Code de sortie du conteneur
status [Statut] Statut du conteneur : 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NomImage] Image ou descendant utilisé pour créer le conteneur
before [ID] ou [Nom] Conteneurs créés avant ce conteneur
since [ID] ou [Nom] Conteneurs créés depuis ce conteneur
volume [NomVolume] ou [PointMontageDestination] Volume monté dans le conteneur
health [Statut] healthy ou unhealthy
pod [Pod] nom ou ID complet ou partiel du pod
network [Réseau] nom ou ID complet du réseau
until [DateTime] Conteneurs créés avant la durée ou l'heure spécifiée.
command [Commande] la commande exécutée par le conteneur, seul argv[0] est pris en compte

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utilise le dernier conteneur créé. Note : le dernier conteneur démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (hors WSL2))

--running

Redémarre tous les conteneurs qui sont déjà dans l'état running.

--time, -t=secondes

Secondes d'attente avant d'arrêter de force le conteneur. Utiliser -1 pour une attente infinie.

EXEMPLES

Redémarre le dernier conteneur.

$ podman restart -l
ec588fc80b05e19d3006bf2e8aa325f0a2e2ff1f609b7afb39176ca8e3e13467

Redémarre un conteneur spécifique par ID partiel.

$ podman restart ff6cf1
ff6cf1e5e77e6dba1efc7f3fcdb20e8b89ad8947bc0518be1fcb2c78681f226f

Redémarre deux conteneurs par nom avec un délai de 4 secondes.

$ podman restart --time 4 test1 test2
c3bb026838c30e5097f079fa365c9a4769d52e1017588278fa00d5c68ebc1502
17e13a63081a995136f907024bcfe50ff532917988a152da229db9d894c5a9ec

Redémarre tous les conteneurs en cours d'exécution.

$ podman restart --running

Redémarre tous les conteneurs.

$ podman restart --all

Redémarre un conteneur en utilisant l'ID spécifié dans des fichiers donnés.

$ podman restart --cidfile /home/user/cidfile-1
$ podman restart --cidfile /home/user/cidfile-1 --cidfile ./cidfile-2

Redémarre un conteneur par son nom.

$ podman restart --filter name=id-name-test

Redémarre un conteneur par étiquette.

$ podman restart --filter label=app=label-test

Redémarre un conteneur par son code de sortie.

$ podman restart --filter exited=0

Redémarre un conteneur par son statut.

$ podman restart --filter status=running

Redémarre un conteneur par son image parente.

$ podman restart --filter ancestor=nginx

Redémarre des conteneurs créés avant un autre.

$ podman restart --filter before=second

Redémarre des conteneurs créés depuis un autre.

$ podman restart --filter since=first

Redémarre un conteneur par son volume.

$ podman restart --filter volume=vol-filter

Redémarre des conteneurs dans un pod.

$ podman restart --filter pod=mypod

Redémarre un conteneur par son réseau.

$ podman restart --filter network=net-filter

Redémarre des conteneurs créés jusqu'à une heure donnée.

$ podman restart --filter until=10s
