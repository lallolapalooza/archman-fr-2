NOM

podman-machine-inspect - Inspecter une ou plusieurs machines virtuelles

SYNTAXE

podman machine inspect [options] [nom] ...

DESCRIPTION

Inspecter une ou plusieurs machines virtuelles.

Obtenir plus de détails sur les machines virtuelles Podman. Plus d'une machine virtuelle peut être inspectée à la fois.

Le nom de machine par défaut est podman-machine-default. Si un nom de machine n'est pas spécifié comme argument, alors podman-machine-default sera inspecté.

Rootless uniquement.

OPTIONS

--format

Afficher les résultats avec un template Go.

Placeholder Description
.ConfigDir ... Emplacement du répertoire de configuration de la machine
.ConnectionInfo ... Informations de connexion de la machine
.Created ... Date de création de la machine (chaîne, ISO3601)
.LastUp ... Date de dernier démarrage de la machine
.Name Nom de la machine
.Resources ... Ressources utilisées par la machine
.Rootful Indique si la machine préfère l'exécution de conteneurs rootful ou rootless
.Rosetta Indique si cette machine utilise Rosetta
.SSHConfig ... Informations de configuration SSH pour communiquer avec la machine
.State État de la machine
.UserModeNetworking Indique si cette machine utilise la mise en réseau en mode utilisateur

--help

Afficher l'énoncé d'utilisation.

EXEMPLES

Inspecter la machine Podman spécifiée.

$ podman machine inspect podman-machine-default
[
     {
          "ConfigDir": {
               "Path": "/Users/jacksparrow/.config/containers/podman/machine/applehv"
          },
          "ConnectionInfo": {
               "PodmanSocket": {
                    "Path": "/var/folders/9r/n3056v597wv2cq8s2j80bdnw0000gn/T/podman/podman-machine-default-api.sock"
               },
               "PodmanPipe": null
          },
          "Created": "2025-02-11T14:12:48.231836+05:30",
          "LastUp": "2025-08-12T19:31:19.391294+05:30",
          "Name": "podman-machine-default",
          "Resources": {
               "CPUs": 6,
               "DiskSize": 100,
               "Memory": 6144,
               "USBs": []
          },
          "SSHConfig": {
               "IdentityPath": "/Users/jacksparrow/.local/share/containers/podman/machine/machine",
               "Port": 53298,
               "RemoteUsername": "core"
          },
          "State": "running",
          "UserModeNetworking": true,
          "Rootful": false,
          "Rosetta": true
     }
]

Afficher le nom et l'état de la machine :

$ podman machine inspect --format "{{.Name}}\t{{.State}}"
podman-machine-default running

Afficher les informations sur les ressources de la machine :

$ podman machine inspect --format "Machine: {{.Name}}\nCPUs: {{.Resources.CPUs}}\nMémoire : {{.Resources.Memory}} octets\nDisque : {{.Resources.DiskSize}} octets"
Machine: podman-machine-default
CPUs: 6
Mmoire : 6144 octets
Disque : 100 octets

Afficher les détails de configuration de la machine :

$ podman machine inspect --format "{{.Name}}: {{.State}} (Rootful: {{.Rootful}}, User Networking: {{.UserModeNetworking}})"
podman-machine-default: running (Rootful: false, User Networking: true)

Afficher les informations sur le temps d'activité de la machine :

$ podman machine inspect --format "Créé : {{.Created}}\nDernier démarrage : {{.LastUp}}\nÉtat : {{.State}}"
Créé : 2025-02-11 14:12:48.231836 +0000 UTC
Dernier démarrage : 2025-08-12 19:31:19.391294 +0000 UTC
État : running

Afficher les informations de connexion :

$ podman machine inspect --format "Socket : {{.ConnectionInfo.PodmanSocket}}\nRépertoire de configuration : {{.ConfigDir}}"
Socket : {/var/folders/9r/n3056v597wv2cq8s2j80bdnw0000gn/T/podman/podman-machine-default-api.sock <nil>}
Répertoire de configuration : {/Users/jacksparrow/.config/containers/podman/machine/applehv <nil>}
