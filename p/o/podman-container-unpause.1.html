podman-unpause(1) Manuel des commandes générales podman-unpause(1)

NOM

podman-unpause - Réactive un ou plusieurs conteneurs

SYNTAXE

podman unpause [options]|[conteneur ...]

podman container unpause [options]|[conteneur ...]

DESCRIPTION

Réactive les processus dans un ou plusieurs conteneurs. Les identifiants ou noms de conteneur peuvent être utilisés comme entrée.

OPTIONS

--all, -a

Réactive tous les conteneurs mis en pause.

--cidfile=fichier

Lit l'identifiant du conteneur depuis le fichier spécifié et réactive le conteneur. Peut être spécifié plusieurs fois.

--filter, -f=filtre

Filtre les conteneurs à réactiver. Plusieurs filtres peuvent être donnés en utilisant plusieurs fois l'option --filter. Les filtres avec la même clé fonctionnent de manière inclusive, à l'exception de label qui est exclusive. Les filtres avec des clés différentes fonctionnent toujours de manière exclusive.

Les filtres valides sont listés ci-dessous :

Filtre Description
id [ID] ID du conteneur (correspondance préfixée CID par défaut ; accepte les expressions régulières)
name [Nom] Nom du conteneur (accepte les expressions régulières)
label [Clé] ou [Clé=Valeur] Étiquette attribuée à un conteneur
exited [Entier] Code de sortie du conteneur
status [Statut] Statut du conteneur : 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NomImage] Image ou descendant utilisé pour créer le conteneur
before [ID] ou [Nom] Conteneurs créés avant ce conteneur
since [ID] ou [Nom] Conteneurs créés depuis ce conteneur
volume [NomVolume] ou [DestinationPointMontage] Volume monté dans le conteneur
health [Statut] healthy ou unhealthy
pod [Pod] nom ou ID complet ou partiel du pod
network [Réseau] nom ou ID complet du réseau
until [DateTime] Conteneurs créés avant la durée ou l'heure donnée.
command [Commande] la commande exécutée par le conteneur, seul argv[0] est pris en compte

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utilise le dernier conteneur créé. Note : le dernier conteneur démarré peut appartenir à d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (hors WSL2))

EXEMPLE

Réactiver un conteneur spécifié :

podman unpause mywebserver

Réactiver un conteneur par un ID partiel de conteneur :

podman unpause 860a4b23

Réactiver tous les conteneurs en pause :

podman unpause --all

Réactiver un conteneur en utilisant l'ID spécifié dans les fichiers donnés :

podman unpause --cidfile /home/user/cidfile-1
podman unpause --cidfile /home/user/cidfile-1 --cidfile ./cidfile-2

Réactiver le dernier conteneur. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (hors WSL2)) :

podman unpause --latest

VOIR AUSSI

podman(1), podman-pause(1)
