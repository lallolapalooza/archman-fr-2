NOM

podman-healthcheck run - Exécute une vérification d'état de conteneur

SYNTAXE

podman healthcheck run conteneur

DESCRIPTION

Exécute manuellement la commande de vérification d'état définie dans un conteneur en cours d'exécution. Les codes d'erreur résultants sont définis comme suit :

  • 0 = la commande de vérification d'état a réussi
  • 1 = la commande de vérification d'état a échoué
  • 125 = une erreur s'est produite

Les erreurs possibles lors de la vérification d'état sont : * impossible de trouver le conteneur * aucun contrôle d'état défini pour le conteneur * le conteneur ne fonctionne pas

OPTIONS

--help

Imprime le message d'utilisation

EXEMPLES

Exécutez les vérifications d'état dans le conteneur spécifié :

$ podman healthcheck run monapplicationweb
