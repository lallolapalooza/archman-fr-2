NOM

podman-history - Afficher l'historique d'une image

SYNOPIS

podman history [options] image[:tag|@digest]

podman image history [options] image[:tag|@digest]

DESCRIPTION

podman history affiche l'historique d'une image en imprimant des informations sur chaque couche utilisée dans l'image. Les informations imprimées pour chaque couche incluent la date et l'heure de création, la commande de création, la taille et un commentaire. La sortie peut être tronquée ou non en utilisant le flag --no-trunc. Si le flag --human est activé, l'heure de création et la taille sont affichées dans un format lisible par l'homme. Le flag --quiet affiche seulement l'ID de l'image lorsqu'il est défini et le flag --format est utilisé pour afficher les informations en utilisant le template Go fourni par l'utilisateur.

OPTIONS

--format=format

Modifier la sortie pour un format tel que 'json' ou un template Go.

Les espaces réservés valides pour le template Go sont listés ci-dessous :

Placeholder Description
.Comment Commentaire pour la couche
.Created si --human, temps écoulé depuis la création, sinon l'horodatage de création
.CreatedAt Heure à laquelle la couche de l'image a été créée
.CreatedBy Commande utilisée pour créer la couche
.CreatedSince Temps écoulé depuis la création de la couche de l'image
.ID ID de l'image
.Size Taille de la couche sur le disque
.Tags Tags de l'image

--help, -h

Imprimer l'énoncé d'utilisation

--human, -H

Afficher les tailles et les dates dans un format lisible par l'homme (par défaut true).

--no-trunc

Ne pas tronquer la sortie (par défaut false).

--quiet, -q

Imprimer uniquement les ID numériques (par défaut false).

EXEMPLES

Afficher l'historique de l'image spécifiée :

$ podman history debian
ID              CREATED       CREATED BY                                      SIZE       COMMENT
b676ca55e4f2c   9 semaines ago   /bin/sh -c #(nop) CMD ["bash"]                  0 B
<missing>       9 semaines ago   /bin/sh -c #(nop) ADD file:ebba725fb97cea4...   45.14 MB

Afficher l'historique de l'image spécifiée sans tronquer le contenu et en utilisant des données brutes :

$ podman history --no-trunc=true --human=false debian
ID              CREATED                CREATED BY                                      SIZE       COMMENT
b676ca55e4f2c   2017-07-24T16:52:55Z   /bin/sh -c #(nop) CMD ["bash"]                  0
<missing>       2017-07-24T16:52:54Z   /bin/sh -c #(nop) ADD file:ebba725fb97cea4...   45142935

Afficher l'historique formaté de l'image spécifiée :

$ podman history --format "{{.ID}} {{.Created}}" debian
b676ca55e4f2c   9 semaines ago
<missing>       9 semaines ago

Afficher l'historique au format JSON pour l'image spécifiée :

$ podman history --format json debian
