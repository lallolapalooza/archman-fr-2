NOM

podman-system-df - Afficher l'utilisation du disque par podman

SYNTAXE

podman system df [options]

DESCRIPTION

Affiche l'utilisation du disque par podman pour les images, les conteneurs et les volumes.

Remarque : La taille RECLAIMABLE signalée pour les images peut être incorrecte. Elle peut indiquer qu'il est possible de récupérer plus d'espace que ce qu'une opération de nettoyage ne libérerait réellement. Cela se produit si vous utilisez différentes images qui partagent certaines couches.

OPTIONS

--format=format

Affiche les images de manière formatée en utilisant un modèle Go ou JSON. Cette option n'est pas autorisée en combinaison avec --verbose.

Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Place-holder Description
.Active Indique si le volume est utilisé
.RawReclaimable Taille brute récupérable de chaque Type
.RawSize Taille brute de chaque type
.Reclaimable Taille récupérable de chaque type (lisible par l'homme)
.Size Taille de chaque type (lisible par l'homme)
.Total Nombre total d'éléments pour chaque type
.Type Type de données

--verbose, -v

Affiche des informations détaillées sur l'utilisation de l'espace.

EXEMPLE

Afficher l'utilisation du disque :

$ podman system df
TYPE            TOTAL   ACTIVE   SIZE    RECLAIMABLE
Images          6       2        281Mo   168Mo (59%)
Containers      3       1        0o      0o (0%)
Local Volumes   1       1        22o     0o (0%)

Afficher l'utilisation du disque en mode détaillé :

$ podman system df -v

Containers space usage:

3f19f5bba242    5cb3    sleep 100     0               5.52ko   22 heures ago   exited       pedantic_archimedes
8cd89bf645cc    5cb3    ls foodir     0               58o      21 heures ago   configured   agitated_hamilton

Afficher uniquement le nombre total pour chaque type :

$ podman system df --format "{{.Type}}\t{{.Total}}"
Images          1
Containers      5
Local Volumes   1

Afficher l'utilisation du disque au format JSON :

$ podman system df --format json
[
    {"Type":"Images","Total":12,"Active":3,"RawSize":13491151377,"RawReclaimable":922956674,"TotalCount":12,"Size":"13.49Go","Reclaimable":"923Mo (7%)"},
    {"Type":"Containers","Total":4,"Active":0,"RawSize":209266,"RawReclaimable":209266,"TotalCount":4,"Size":"209.3ko","Reclaimable":"209.3ko (100%)"},
    {"Type":"Local Volumes","Total":6,"Active":1,"RawSize":796638905,"RawReclaimable":47800633,"TotalCount":6,"Size":"796.6Mo","Reclaimable":"47.8Mo (6%)"}
]

Afficher le type et la taille dans un format personnalisé :

$ podman system df --format "{{.Type}}: {{.Size}} ({{.Reclaimable}} récupérable)"
Images: 13.49Go (923Mo (7%) récupérable)
Containers: 209.3ko (209.3ko (100%) récupérable)
Local Volumes: 796.6Mo (47.8Mo (6%) récupérable)
