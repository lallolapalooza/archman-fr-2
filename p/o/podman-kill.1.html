podman-kill(1) Manuel des commandes générales podman-kill(1)

NOM

podman-kill - Arrête le processus principal d'un ou plusieurs conteneurs

SYNTAXE

podman kill [options] [conteneur ...]

podman container kill [options] [conteneur ...]

DESCRIPTION

Le processus principal à l'intérieur de chaque conteneur spécifié reçoit le signal SIGKILL ou tout autre signal spécifié avec l'option --signal.

OPTIONS

--all, -a

Envoyer un signal à tous les conteneurs en cours d'exécution et en pause.

--cidfile=fichier

Lire l'ID du conteneur à partir du fichier spécifié et arrêter le conteneur. Peut être spécifié plusieurs fois.

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utiliser le dernier conteneur créé. Remarque : le dernier conteneur démarré peut appartenir à d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (hors WSL2)).

--signal, -s=signal

Signal à envoyer au conteneur. Pour plus d'informations sur les signaux Linux, référez-vous à signal(7). La valeur par défaut est SIGKILL.

EXEMPLE

Arrêter un conteneur avec un nom donné :

podman kill monserveurweb

Arrêter un conteneur avec un ID donné :

podman kill 860a4b23

Terminer un conteneur en envoyant le signal TERM :

podman kill --signal TERM 860a4b23

Arrêter le dernier conteneur. (Cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (hors WSL2)) :

podman kill --latest

Terminer tous les conteneurs en envoyant le signal KILL :

podman kill --signal KILL -a

Arrêter des conteneurs en utilisant des IDs spécifiés dans des fichiers donnés :

podman kill --cidfile /home/user/cidfile-1
podman kill --cidfile /home/user/cidfile-1 --cidfile ./cidfile-2

VOIR AUSSI

podman(1), podman-stop(1)
