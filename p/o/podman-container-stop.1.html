podman-stop(1) Manuel des commandes générales podman-stop(1)

NOM

podman-stop - Arrête un ou plusieurs conteneurs en cours d'exécution

SYNOPSIS

podman stop [options] conteneur ...

podman container stop [options] conteneur ...

DESCRIPTION

Arrête un ou plusieurs conteneurs en utilisant leurs identifiants ou noms comme entrées. L'option --time spécifie le nombre de secondes à attendre avant d'arrêter forcément le conteneur après l'émission de la commande d'arrêt au conteneur. La valeur par défaut est 10 secondes. Par défaut, les conteneurs sont arrêtés avec SIGTERM puis SIGKILL après le délai d'attente. Le défaut SIGTERM peut être remplacé par l'image utilisée pour créer le conteneur et également via la ligne de commande lors de la création du conteneur.

OPTIONS

--all, -a

Arrête tous les conteneurs en cours d'exécution. Cela n'inclut pas les conteneurs mis en pause.

--cidfile=fichier

Lit l'identifiant du conteneur depuis le fichier spécifié et arrête le conteneur. Peut être spécifié plusieurs fois.

La commande ne échoue pas lorsque le fichier est manquant et que l'utilisateur a spécifié --ignore.

--filter, -f=filtre

Filtre les conteneurs qui seront arrêtés. Plusieurs filtres peuvent être donnés en utilisant plusieurs fois l'option --filter. Les filtres avec la même clé fonctionnent de manière inclusive, à l'exception de label qui est exclusive. Les filtres avec des clés différentes fonctionnent toujours de manière exclusive.

Les filtres valides sont listés ci-dessous :

Filtre Description
id [ID] Identifiant du conteneur (correspondance de préfixe CID par défaut ; accepte les expressions régulières)
name [Nom] Nom du conteneur (accepte les expressions régulières)
label [Clé] ou [Clé=Valeur] Étiquette attribuée à un conteneur
exited [Int] Code de sortie du conteneur
status [Statut] Statut du conteneur : 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NomImage] Image ou descendant utilisé pour créer le conteneur
before [ID] ou [Nom] Conteneurs créés avant ce conteneur
since [ID] ou [Nom] Conteneurs créés depuis ce conteneur
volume [NomVolume] ou [PointMontageDestination] Volume monté dans le conteneur
health [Statut] healthy ou unhealthy
pod [Pod] nom ou ID complet ou partiel du pod
network [Réseau] nom ou ID complet du réseau
until [DateTime] Conteneurs créés avant la durée ou l'heure spécifiée.
command [Commande] la commande que le conteneur exécute, seul argv[0] est pris en compte

--ignore, -i

Ignore les erreurs lorsque les conteneurs spécifiés ne sont pas dans le magasin de conteneurs. Un utilisateur peut avoir décidé de supprimer manuellement un conteneur, ce qui entraîne un échec lors de la directive ExecStop d'un service systemd faisant référence à ce conteneur.

--latest, -l

Au lieu de fournir le nom ou l'identifiant du conteneur, utilise le dernier conteneur créé. Note : le dernier conteneur démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (hors WSL2)).

--time, -t=secondes

Nombre de secondes à attendre avant d'arrêter de force le conteneur. Utiliser -1 pour une attente infinie.

EXEMPLES

Arrête le conteneur spécifié par son nom.

$ podman stop monserveurweb

Arrête le conteneur par son identifiant.

$ podman stop 860a4b235279

Arrête plusieurs conteneurs.

$ podman stop monserveurweb 860a4b235279

Arrête le conteneur identifié dans le cidfile.

$ podman stop --cidfile /home/utilisateur/cidfile-1

Arrête les conteneurs identifiés dans les cidfiles.

$ podman stop --cidfile /home/utilisateur/cidfile-1 --cidfile ./cidfile-2

Arrête le conteneur spécifié en 2 secondes.

$ podman stop --time 2 860a4b235279

Arrête tous les conteneurs en cours d'exécution.

$ podman stop -a

Arrête le dernier conteneur créé (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (hors WSL2)).

$ podman stop --latest

Arrête par étiquette.

$ podman stop --filter label=app=frontend
9351ccb3ef4272532bc0c188bd4f0ddfc2b0de217732cd108259ea126b014647

Arrête par nom.

$ podman stop --filter name=db-replica
6c2680da61d54690718ac3aecdb04a8aad95ae353e42cc942736823bd05c8a1d

Arrête par étiquette de rôle.

$ podman stop --filter label=role=primary
bb3ff91d969a8dc622d627e4a8d76c18bdbd417d317c5e7e66543c0b0c8ed1e8
