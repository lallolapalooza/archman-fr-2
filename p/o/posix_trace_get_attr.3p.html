POSIX_TRACE_GET_ATTR(3P) Manuel du programmeur POSIX POSIX_TRACE_GET_ATTR(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_trace_get_attr, posix_trace_get_status — récupérer les attributs de trace ou le statut de trace (TRACING)

SYNTAXE

#include <trace.h>
int posix_trace_get_attr(trace_id_t trid, trace_attr_t *attr);
int posix_trace_get_status(trace_id_t trid,
    struct posix_trace_status_info *statusinfo);

DESCRIPTION

La fonction posix_trace_get_attr() copie les attributs du flux de trace actif identifié par trid dans l'objet pointé par l'argument attr. Si l'option Trace Log est supportée, trid peut représenter un journal de trace pré-enregistré.

La fonction posix_trace_get_status() renvoie, dans la structure pointée par l'argument statusinfo, le statut de trace actuel pour le flux de trace identifié par l'argument trid. Ces valeurs de statut renvoyées dans la structure pointée par statusinfo doivent avoir été lues de manière appropriée pour garantir que les valeurs renvoyées sont cohérentes. Si l'option Trace Log est supportée et que l'argument trid se réfère à un flux de trace pré-enregistré, le statut sera le statut du flux de trace terminé.

Chaque fois que la fonction posix_trace_get_status() est utilisée, le statut de dépassement du flux de trace est réinitialisé à POSIX_TRACE_NO_OVERRUN immédiatement après la fin de l'appel. Si l'option Trace Log est supportée, la fonction posix_trace_get_status() se comportera de la même manière que lorsque l'option n'est pas supportée, à l'exception des différences suivantes:

*
Si l'argument trid se réfère à un flux de trace avec journal, chaque fois que la fonction posix_trace_get_status() est utilisée, le statut de dépassement du journal du flux de trace est réinitialisé à POSIX_TRACE_NO_OVERRUN et le statut flush_error est réinitialisé à zéro immédiatement après la fin de l'appel.
*
Si l'argument trid se réfère à un flux de trace pré-enregistré, le statut renvoyé sera le statut du flux de trace terminé et les valeurs de statut du flux de trace ne seront pas réinitialisées.

VALEUR RENVOYÉE

En cas de succès, ces fonctions renvoient une valeur de zéro. Sinon, elles renvoient le numéro d'erreur correspondant.

La fonction posix_trace_get_attr() stocke les attributs de trace dans l'objet pointé par attr, en cas de succès.

La fonction posix_trace_get_status() stocke le statut de trace dans l'objet pointé par statusinfo, en cas de succès.

ERREURS

Ces fonctions échouent si :

EINVAL
L'argument trid du flux de trace ne correspond à aucun flux de trace actif valide ou à aucun journal de trace valide.
