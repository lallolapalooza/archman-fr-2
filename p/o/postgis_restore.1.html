NOM

postgis_restore - restaure une base de données PostGIS à partir d'un fichier archive créé par pg_dump

SYNTAXE

postgis_restore [-v] [-L TOC] [-s schéma] dumpfile

DESCRIPTION

La commande postgis_restore permet d'extraire les instructions SQL pour recréer des objets trouvés dans une sauvegarde personnalisée d'une base de données activée pour PostGIS tout en ignorant les objets spécifiques à PostGIS.

Ceci est seulement utile pour les sauvegardes de bases de données pour lesquelles PostGIS a été activé en chargeant le script postgis.sql. Les sauvegardes effectuées à partir de bases de données où PostGIS a été activé via CREATE EXTENSION ne contiendront pas d'objets PostGIS et peuvent donc être restaurées en toute sécurité directement avec pg_restore.

Notez que cette commande ne fonctionne qu'avec les sauvegardes utilisant le format personnalisé, c'est-à-dire celles créées avec pg_dump -Fc.

UTILISATION

Les informations d'utilisation sont affichées lorsque le script est invoqué sans arguments.

EXEMPLES

Créez une sauvegarde personnalisée de olddb :

pg_dump -Fc olddb > olddb.dump

Créez une nouvelle base de données newdb :

createdb newdb

Activez PostGIS pour la nouvelle base de données :

psql -c 'CREATE EXTENSION postgis' newdb

Restaurez vos données :

postgis_restore.pl olddb.dump | psql newdb
