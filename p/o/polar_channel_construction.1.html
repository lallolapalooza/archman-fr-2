NOM

polar_channel_construction - Configureur polaire Gnu Radio

DESCRIPTION

Construction de canaux polaires pour Gnu Radio.

Construction de canal

polar_channel_construction expose des fonctionnalités pour calculer des canaux polaires pour différentes tailles. Il peut être utilisé pour calculer les paramètres de Bhattacharyya une fois et les stocker dans un fichier dans '~/.gnuradio/polar'. Les positions des bits gelés sont recalculées à chaque exécution.

polar_channel_construction fournit une interface en ligne de commande pour tout le code de construction de canal. Ces fonctionnalités sont également accessibles via le bloc Polar Configurator dans GRC.

BEC

La construction de canal BEC peut être calculée explicitement car le BEC représente un cas particulier qui simplifie la tâche. Toutes les fonctionnalités concernant ce canal sont situées dans 'channel_construction_bec'.

AWGN

En général, la construction de canal pour les codes polaires est une tâche très coûteuse en temps. Tal et Vardy ont proposé un algorithme de quantification pour la construction de canal qui la rend réalisable. L'implémentation correspondante se trouve dans 'channel_construction_awgn'. Il convient de noter qu'il s'agit plutôt d'une implémentation de base qui manque de toutes les fonctionnalités avancées que l'implémentation originale fournit. Cependant, les simulations montrent que la construction de canal BEC avec un SNR de conception de 0.0dB donne des performances similaires et devrait être préférée ici.
