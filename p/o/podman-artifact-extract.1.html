NOM

podman-artifact-extract - Extraire un artefact OCI vers un chemin local

SYNOPSIS

podman artifact extract artefact cible

DESCRIPTION

Extrait les blobs d'un artefact OCI vers un fichier ou un répertoire local.

Si le chemin cible est un fichier ou n'existe pas, l'artefact doit soit être composé d'un seul blob (couche), soit, s'il a plusieurs blobs (couches), l'option --digest ou --title doit être utilisée pour sélectionner un seul blob. Si le fichier existe déjà, il sera écrasé.

Si la cible est un répertoire (il doit exister), tous les blobs seront copiés dans le répertoire cible. Le nom du fichier cible sera la valeur de l'annotation org.opencontainers.image.title. Si l'annotation est absente, le nom du fichier cible sera le digest du blob (avec les : remplacés par des - dans le nom). Si le fichier cible existe déjà dans le répertoire, il sera écrasé.

OPTIONS

--digest=digest

Lors de l'extraction de blobs de l'artefact, utiliser uniquement celui avec le digest spécifié. Si la cible est un répertoire, le digest sera toujours utilisé comme nom de fichier à la place, même si l'annotation title existe sur le blob. Conflit avec --title.

--help

Imprime le message d'utilisation.

--title=titre

Lors de l'extraction de blobs de l'artefact, utiliser uniquement celui avec le titre spécifié. Il recherche l'annotation org.opencontainers.image.title et la compare avec le titre donné. Conflit avec --digest.

EXEMPLES

Extraire un artefact avec un seul blob

$ podman artifact extract quay.io/artifact/foobar1:test /tmp/monfichier

Extraire un artefact avec plusieurs blobs

$ podman artifact extract quay.io/artifact/foobar2:test /tmp/mondossier
$ ls /tmp/mondossier
CONTRIBUTING.md  README.md

Extraire seulement un blob unique d'un artefact avec plusieurs blobs

$ podman artifact extract --title README.md quay.io/artifact/foobar2:test /tmp/mondossier
$ ls /tmp/mondossier
README.md

Ou en utilisant le digest au lieu du titre

$ podman artifact extract --digest sha256:c0594e012b17fd9e6548355ceb571a79613f7bb988d7d883f112513601ac6e9a quay.io/artifact/foobar2:test /tmp/mondossier
$ ls /tmp/mondossier
README.md
