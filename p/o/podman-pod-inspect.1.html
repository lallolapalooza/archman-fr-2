NOM

podman-pod-inspect - Afficher les informations décrivant un pod

SYNTAXE

podman pod inspect [options] pod ...

DESCRIPTION

Affiche la configuration et les informations d'état d'un pod donné. Elle affiche également des informations sur les conteneurs appartenant au pod.

OPTIONS

--format, -f=format

Change le format de sortie par défaut. Il peut s'agir d'un type supporté comme 'json' ou d'un modèle Go. Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Espace réservé Description
.BlkioDeviceReadBps Bloc d'E/S lu, en octets/sec
.BlkioDeviceWriteBps Bloc d'E/S écrit, en octets/sec
.BlkioWeight Poids des E/S de bloc
.BlkioWeightDevice Poids du périphérique d'E/S de bloc
.CgroupParent Cgroup parent du pod
.CgroupPath Chemin cgroup du pod
.Containers Conteneurs du pod
.CPUPeriod Période CPU
.CPUQuota Quota CPU
.CPUSetCPUs CPU Set CPUs
.CPUSetMems CPU Set Mems
.CPUShares Partages CPU
.CreateCgroup Indique si le cgroup a été créé
.CreateCommand Commande de création
.Created ... Heure de création du pod
.CreateInfra Indique si l'infrastructure a été créée
.Devices Périphériques
.ExitPolicy Politique de sortie
.Hostname Nom d'hôte du pod
.ID ID du pod
.InfraConfig ... Configuration d'infrastructure (contient d'autres champs)
.InfraContainerID ID de l'infrastructure du pod
.InspectPodData ... Structure imbriquée, pour experts uniquement
.Labels ... Étiquettes du pod
.LockNumber Numéro du verrou Libpod du pod
.MemoryLimit Limite de mémoire, en octets
.MemorySwap Limite de swap mémoire, en octets
.Mounts Montages
.Name Nom du pod
.Namespace Espace de noms
.NumContainers Nombre de conteneurs dans le pod
.RestartPolicy Politique de redémarrage du pod
.SecurityOpts Options de sécurité
.SharedNamespaces Espaces de noms partagés du pod
.State État du pod
.VolumesFrom Volumes depuis

--latest, -l

Au lieu de fournir le nom ou l'ID du pod, utilisez le dernier pod créé. Remarque : le dernier pod démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (à l'exception de WSL2))

EXEMPLE

Inspecter un pod spécifié :

$ podman pod inspect foobar
[
     {
         "Id": "3513ca70583dd7ef2bac83331350f6b6c47d7b4e526c908e49d89ebf720e4693",
         "Name": "foobar",
         "Labels": {},
         "CgroupParent": "/libpod_parent",
         "CreateCgroup": true,
         "Created": "2018-08-08T11:15:18.823115347-05:00"
         "State": "created",
         "Hostname": "",
         "SharedNamespaces": [
              "uts",
              "ipc",
              "net"
         ]
         "CreateInfra": false,
         "InfraContainerID": "1020dd70583dd7ff2bac83331350f6b6e007de0d026c908e49d89ebf891d4699"
         "CgroupPath": ""
         "Containers": [
              {
                   "id": "d53f8bf1e9730281264aac6e6586e327429f62c704abea4b6afb5d8a2b2c9f2c",
                   "state": "configured"
              }
         ]
     }
]

Afficher uniquement le nom et l'état du pod :

$ podman pod inspect --format "{{.Name}}\t{{.State}}" mypod
mypod	Running

Afficher l'ID du pod et le nombre de conteneurs :

$ podman pod inspect mypod --format "Pod {{.Name}} ({{.ID}}) a {{.NumContainers}} conteneurs"
Pod mypod (605f5f776e101a6e0ad11ea802cae25eabf299da77122f2963fa65dc6ccf6717) a 2 conteneurs

Afficher l'heure de création du pod et les espaces de noms partagés :

$ podman pod inspect mypod --format "Créé le : {{.Created}}\nPartagé : {{.SharedNamespaces}}"
Créé le : 2025-08-14 21:16:05.861363099 +0000 UTC
Partagé : [net uts ipc]

Afficher les limites de ressources du pod :

$ podman pod inspect --format "Mémoire : {{.MemoryLimit}}, Période CPU : {{.CPUPeriod}}, Quota CPU : {{.CPUQuota}}" mypod
Mémoire : 1073741824, Période CPU : 100000, Quota CPU : 50000

Afficher les ID des conteneurs dans le pod :

$ podman pod inspect --format "{{range .Containers}}{{.Id}}: {{.State}} {{end}}" mypod
e907f7902decca9d6b600b4d3cca9541d9b89dd726b2af7ad2eba05d2a97083f: running c5a53050a31aed71c55cb6a31b9564c69a1009f77750f3f0e8093bd98fcd8918: running
