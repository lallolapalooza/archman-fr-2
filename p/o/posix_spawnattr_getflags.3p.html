POSIX_SPAWNATTR_GETFLAGS(3P) Manuel du programmeur POSIX POSIX_SPAWNATTR_GETFLAGS(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_spawnattr_getflags, posix_spawnattr_setflags — obtenir et définir l'attribut spawn-flags d'un objet d'attributs de spawn (TEMPS RÉEL AVANCÉ)

SYNTAXE

#include <spawn.h>
int posix_spawnattr_getflags(const posix_spawnattr_t *restrict attr,
    short *restrict flags);
int posix_spawnattr_setflags(posix_spawnattr_t *attr, short flags);

DESCRIPTION

La fonction posix_spawnattr_getflags() obtient la valeur de l'attribut spawn-flags à partir de l'objet d'attributs référencé par attr.

La fonction posix_spawnattr_setflags() définit l'attribut spawn-flags dans un objet d'attributs initialisé référencé par attr.

L'attribut spawn-flags est utilisé pour indiquer quels attributs de processus doivent être modifiés dans la nouvelle image de processus lors de l'invocation de posix_spawn() ou posix_spawnp(). C'est l'opération OU bit-à-bit inclusive de zéro ou plusieurs des indicateurs suivants :

POSIX_SPAWN_RESETIDS
POSIX_SPAWN_SETPGROUP
POSIX_SPAWN_SETSIGDEF
POSIX_SPAWN_SETSIGMASK
POSIX_SPAWN_SETSCHEDPARAM
POSIX_SPAWN_SETSCHEDULER

Ces indicateurs sont définis dans <spawn.h>. La valeur par défaut de cet attribut doit être comme si aucun indicateur n'était défini.

VALEUR DE RETOUR

En cas de succès, posix_spawnattr_getflags() renvoie zéro et stocke la valeur de l'attribut spawn-flags de attr dans l'objet référencé par le paramètre flags ; sinon, un numéro d'erreur est retourné pour indiquer l'erreur.

En cas de succès, posix_spawnattr_setflags() renvoie zéro ; sinon, un numéro d'erreur est retourné pour indiquer l'erreur.

ERREURS

Ces fonctions peuvent échouer si :

EINVAL
La valeur spécifiée par attr est invalide.

La fonction posix_spawnattr_setflags() peut échouer si :

EINVAL
La valeur de l'attribut défini n'est pas valide.
