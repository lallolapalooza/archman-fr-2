POSIX_TRACE_GET_FILTER(3P) Manuel du programmeur POSIX POSIX_TRACE_GET_FILTER(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_trace_get_filter, posix_trace_set_filter — récupérer et définir le filtre d'un flux de trace initialisé (TRACING)

SYNTAXE

#include <trace.h>
int posix_trace_get_filter(trace_id_t trid, trace_event_set_t *set);
int posix_trace_set_filter(trace_id_t trid,
    const trace_event_set_t *set, int how);

DESCRIPTION

La fonction posix_trace_get_filter() récupère, dans l'argument pointé par set, le filtre d'événements de trace réel du flux de trace spécifié par trid.

La fonction posix_trace_set_filter() modifie l'ensemble des types d'événements de trace filtrés après la création d'un flux de trace identifié par l'argument trid. Cette fonction peut être appelée avant de démarrer le flux de trace, ou pendant que le flux de trace est actif. Par défaut, si aucun appel à posix_trace_set_filter() n'est effectué, tous les événements de trace sont enregistrés (c'est-à-dire qu'aucun type d'événement de trace n'est filtré).

Si cette fonction est appelée pendant que la trace est en cours, un événement de trace système spécial, POSIX_TRACE_FILTER, est enregistré dans la trace, indiquant les anciens et les nouveaux ensembles de types d'événements de trace filtrés (voir Tableau 2-4, Options de filtre d'événements de trace et de trace : Événements de trace système et Tableau 2-6, Options de trace, de journal de trace et de filtre d'événements de trace : Événements de trace système).

Si la fonction posix_trace_set_filter() est interrompue par un signal, une erreur est retournée et le filtre n'est pas modifié. Dans ce cas, l'état du flux de trace n'est pas modifié.

La valeur de l'argument how indique la manière dont l'ensemble doit être modifié et doit avoir l'une des valeurs suivantes, telles que définies dans l'en-tête <trace.h> :

POSIX_TRACE_SET_EVENTSET

L'ensemble résultant des types d'événements de trace à filtrer sera l'ensemble de types d'événements de trace pointé par l'argument set.
POSIX_TRACE_ADD_EVENTSET

L'ensemble résultant des types d'événements de trace à filtrer sera l'union de l'ensemble actuel et de l'ensemble de types d'événements de trace pointé par l'argument set.
POSIX_TRACE_SUB_EVENTSET

L'ensemble résultant des types d'événements de trace à filtrer sera tous les types d'événements de trace de l'ensemble actuel qui ne sont pas dans l'ensemble pointé par l'argument set ; c'est-à-dire que chaque élément de l'ensemble spécifié est retiré du filtre actuel.

VALEUR RENVOYÉE

En cas de succès, ces fonctions renvoient une valeur de zéro. Sinon, elles renvoient le numéro d'erreur correspondant.

La fonction posix_trace_get_filter() stocke l'ensemble des types d'événements de trace filtrés dans set, en cas de succès.

ERREURS

Ces fonctions échouent si :

EINVAL
La valeur de l'argument trid ne correspond pas à un flux de trace actif ou la valeur de l'argument pointé par set est invalide.
EINTR
L'opération a été interrompue par un signal.
