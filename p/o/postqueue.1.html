POSTQUEUE(1) Manuel des commandes générales POSTQUEUE(1)

NOM

postqueue - Contrôle de la file d'attente Postfix

SYNOPIS

Pour vider la file d'attente des courriels :
postqueue [-v] [-c config_dir] -f
postqueue [-v] [-c config_dir] -i queue_id
postqueue [-v] [-c config_dir] -s site
Pour lister la file d'attente des courriels :
postqueue [-v] [-c config_dir] -j
postqueue [-v] [-c config_dir] -p

DESCRIPTION


La commande postqueue(1) implémente l'interface utilisateur de Postfix pour la gestion de la file d'attente. Elle implémente des opérations qui sont traditionnellement disponibles via la commande sendmail(1). Consultez la commande postsuper(1) pour les opérations de file d'attente nécessitant les privilèges de super-utilisateur, comme la suppression d'un message de la file d'attente ou la modification de son statut.

Les options suivantes sont reconnues :

-c config_dir
Le fichier de configuration main.cf se trouve dans le répertoire nommé au lieu du répertoire de configuration par défaut. Voir aussi le paramètre d'environnement MAIL_CONFIG ci-dessous.
-f
Vider la file d'attente : tenter de livrer tous les courriels en file d'attente.

Cette option implémente la commande traditionnelle "sendmail -q", en contactant le démon qmgr(8) de Postfix.

Attention : vider fréquemment les courriels non livrables entraînera une mauvaise performance de livraison de tous les autres courriels.

-i queue_id
Planifier la livraison immédiate des courriels différés avec l'ID de file d'attente spécifié.

Cette option implémente la commande traditionnelle sendmail -qI, en contactant le serveur flush(8).

Cette fonctionnalité est disponible à partir de la version 2.4 de Postfix.

-j
Produire une liste de la file d'attente au format JSON LINES, basée sur la sortie du démon showq(8). Voir "FORMAT DES OBJETS JSON" ci-dessous pour plus de détails.

Cette fonctionnalité est disponible à partir de Postfix 3.1.

-p
Produire une liste de la file d'attente traditionnelle de style sendmail. Cette option implémente la commande traditionnelle mailq, en contactant le démon showq(8) de Postfix.

Chaque entrée de la file d'attente affiche l'ID du fichier de la file d'attente, la taille du message, l'heure d'arrivée, l'expéditeur et les destinataires qui doivent encore être livrés. Si un courriel n'a pas pu être livré lors de la dernière tentative, la raison de l'échec est affichée. L'ID de la file d'attente est suivi d'un caractère d'état optionnel :

*
Le message est dans la file d'attente active, c'est-à-dire que le message est sélectionné pour la livraison.
!
Le message est dans la file d'attente hold (retenue), c'est-à-dire qu'aucune autre tentative de livraison ne sera effectuée tant que le courriel n'aura pas été retiré de la retenue.
#
Le message est forcé à expirer. Voir les options -e ou -f de postsuper(1).

Cette fonctionnalité est disponible à partir de Postfix 3.5.

-s site
Planifier la livraison immédiate de tous les courriels mis en file d'attente pour le site nommé. Un site numérique doit être spécifié comme une adresse littérale valide RFC 5321 entre crochets, tout comme dans les adresses électroniques. Le site doit être éligible pour le service de "vidage rapide". Voir flush(8) pour plus d'informations sur le service de "vidage rapide".

Cette option implémente la commande traditionnelle "sendmail -qRsite", en contactant le démon flush(8) de Postfix.

-v
Activer la journalisation verbale à des fins de débogage. Plusieurs options -v rendent le logiciel de plus en plus verbeux. À partir de Postfix 2.3, cette option n'est disponible que pour le super-utilisateur.

FORMAT DES OBJETS JSON

Chaque objet JSON représente un fichier de file d'attente ; il est émis sous forme d'une seule ligne de texte suivie d'un caractère de nouvelle ligne.

Les membres de l'objet ont des valeurs de type chaîne de caractères, sauf indication contraire. Les programmes doivent ignorer les membres de l'objet qui ne sont pas listés ici ; la liste des membres est susceptible de croître avec le temps.

queue_name
Le nom de la file d'attente où le message a été trouvé. Notez que le contenu de la file d'attente des courriels peut changer pendant son listage ; certains messages peuvent apparaître plusieurs fois, et certains messages peuvent être manqués.
queue_id
Le nom du fichier de la file d'attente. L'identifiant de file d'attente peut être réutilisé au sein d'une instance Postfix, sauf si "enable_long_queue_ids = true" et que le temps est monotone. Même dans ce cas, l'identifiant de file d'attente n'est pas censé être unique entre différentes instances Postfix. Les outils de gestion qui nécessitent un nom unique devraient combiner l'identifiant de file d'attente avec le paramètre myhostname de l'instance Postfix.
arrival_time
Le nombre de secondes écoulées depuis le début de l'époque UNIX.
message_size
Le nombre d'octets dans l'en-tête et le corps du message. Ce nombre n'inclut pas les informations d'enveloppe du message. Il est approximativement égal au nombre d'octets qui seraient transmis via SMTP, y compris les fins de ligne <CR><LF>.
forced_expire
Le message est forcé à expirer (true ou false). Voir les options -e ou -f de postsuper(1).

Cette fonctionnalité est disponible à partir de Postfix 3.5.

sender
L'adresse de l'expéditeur de l'enveloppe.
recipients
Un tableau contenant zéro ou plusieurs objets avec les membres :
address
Une adresse de destinataire.
delay_reason
S'il est présent, la raison de la livraison différée. Les destinataires différés peuvent ne pas avoir de raison de différé, par exemple, pendant que la livraison est en cours, ou après que le système a été arrêté avant de pouvoir enregistrer la raison.

SÉCURITÉ

Ce programme est conçu pour s'exécuter avec des privilèges set-group ID, afin qu'il puisse se connecter aux processus démons de Postfix.

NORMES

RFC 7159 (notation JSON)

DIAGNOSTICS


Les problèmes sont enregistrés dans syslogd(8) ou postlogd(8), et dans le flux d'erreur standard.

ENVIRONNEMENT

MAIL_CONFIG
Répertoire contenant le fichier main.cf. Afin d'éviter l'exploitation des privilèges set-group ID, un répertoire non standard n'est autorisé que si :
  • Le nom est listé dans le fichier main.cf standard avec le paramètre de configuration alternate_config_directories.
  • La commande est invoquée par le super-utilisateur.

PARAMÈTRES DE CONFIGURATION

Les paramètres main.cf suivants sont particulièrement pertinents pour ce programme. Le texte ci-dessous ne fournit qu'un résumé des paramètres. Voir postconf(5) pour plus de détails, y compris des exemples.

postqueue(1) — Postfix manpage

NAME

postqueue — Postfix queue summary

SYNOPSIS

       postqueue [-p] [-s transport] [-j job_id] [-u user]
       postqueue [-f] [-i inet_domain] [-I inet_host] [-u user]
       postqueue [-d domain] [-D domain]
       postqueue [-m] [-M domain]
       postqueue [-c config_dir]
       postqueue [-v]

DESCRIPTION

The postqueue command reports the status of the mail queue. It can show the queue size, the number of messages for each destination, and the current queue age.

The command can also be used to flush mail from the queue.

The default behavior is to show the queue status for all destinations. Use the -p option to show the queue status per destination. Without options, postqueue reports the total number of messages and total queue size, in addition to the number of messages and queue size per destination.

Options that select messages for action (e.g., -f, -i, -I, -d, -D, -m, -M) implicitly enable the -p option.

When the command is run as root, it also has the privileges to flush the queue.

JSON OBJECT FORMAT

The postqueue command outputs JSON objects when the environment variable POSTQUEUE_VERBOSE is set to json.

Each JSON object represents a mail queue entry and contains the following fields:

queue_id
The unique identifier for the mail queue entry.
sender
The sender address of the email.
recipient
The recipient address of the email.
size
The size of the email in bytes.
arrival
The arrival time of the email in the queue (Unix timestamp).
delivery_time
The scheduled delivery time of the email (Unix timestamp).
flags
Flags associated with the mail queue entry (e.g., "D" for delivered, "B" for bounced).
trace
Trace information for the email.

Example of JSON output:

{
    "queue_id": "1234567890",
    "sender": "sender@example.com",
    "recipient": "recipient@example.com",
    "size": 1024,
    "arrival": 1678886400,
    "delivery_time": 1678886460,
    "flags": " ",
    "trace": "trace1 trace2"
}

SECURITY

Only the superuser can flush the queue. Ordinary users can only view the queue status.

STANDARDS

RFC 974, RFC 1869, RFC 2821, RFC 2822, RFC 2920, RFC 3030, RFC 3463, RFC 3464, RFC 3798, RFC 4280, RFC 5321, RFC 5322.

DIAGNOSTICS

The exit status is zero on success, or 1 on error.

ENVIRONMENT

e_config_directories
A list of non-default Postfix configuration directories that may be specified with "-c config_directory" on the command line (in the case of sendmail(1), with the "-C" option), or via the MAIL_CONFIG environment parameter.
config_directory
The default location of the Postfix main.cf and master.cf configuration files.
command_directory
The location of all postfix administrative commands.
fast_flush_domains ($relay_domains)
Optional list of destinations that are eligible for per-destination logfiles with mail that is queued to those destinations.
import_environment
The list of environment variables that a privileged Postfix process will import from a non-Postfix parent process, or name=value environment overrides.
queue_directory
The location of the Postfix top-level queue directory.
syslog_facility (mail)
The syslog facility of Postfix logging.
syslog_name
A prefix that is prepended to the process name in syslog records, so that, for example, "smtpd" becomes "prefix/smtpd".
trigger_timeout (10s)
The time limit for sending a trigger to a Postfix daemon (for example, the pickup(8) or qmgr(8) daemon).

Available in Postfix version 2.2 and later:

authorized_flush_users (static:anyone)
List of users who are authorized to flush the queue.
authorized_mailq_users (static:anyone)
List of users who are authorized to view the queue.
