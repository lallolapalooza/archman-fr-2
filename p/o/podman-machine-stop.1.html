NOM

podman-machine-stop - Arrêter une machine virtuelle

SYNTAXE

podman machine stop [nom]

DESCRIPTION

Arrête une machine virtuelle.

Le nom de machine par défaut est podman-machine-default. Si aucun nom de machine n'est spécifié comme argument, alors podman-machine-default sera arrêté.

Uniquement sans root.

Podman sur MacOS et Windows nécessite une machine virtuelle. Ceci est dû au fait que les conteneurs sont basés sur Linux - les conteneurs ne fonctionnent pas sur d'autres systèmes d'exploitation car les fonctionnalités de base des conteneurs sont liées au noyau Linux. Podman machine doit être utilisé pour gérer les machines MacOS et Windows, mais peut être utilisé facultativement sous Linux.

podman machine stop arrête une machine virtuelle Linux où les conteneurs sont exécutés.

OPTIONS

--help

Affiche l'énoncé d'utilisation.

EXEMPLES

Arrêter une machine podman nommée myvm.

$ podman machine stop myvm

VOIR AUSSI
