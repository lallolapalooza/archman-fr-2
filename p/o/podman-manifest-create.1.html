NOM

podman-manifest-create - Créer une liste de manifestes ou un index d'images

SYNOPSIS

podman manifest create [options] nomdelisteouindex [nomimage ...]

DESCRIPTION

Crée une nouvelle liste de manifestes et la stocke sous forme d'image dans le stockage local en utilisant le nom spécifié.

Si des images supplémentaires sont spécifiées, elles sont ajoutées à la liste ou à l'index nouvellement créé.

OPTIONS

--all

Si l'une des images ajoutées à la nouvelle liste ou à l'index est elle-même une liste ou un index, ajoutez tout son contenu. Par défaut, seule une image de cette liste est ajoutée à la liste ou à l'index nouvellement créé.

--amend, -a

Si une liste de manifestes nommée nomdelisteouindex existe déjà, modifiez la liste préexistante au lieu de sortir avec une erreur. Le contenu de nomdelisteouindex n'est pas modifié si aucun nom d'image n'est donné.

--annotation=valeur

Définir une annotation sur l'index d'images nouvellement créé.

--tls-verify

Exiger HTTPS et vérifier les certificats lors du contact avec les registres (par défaut : true). S'il est explicitement défini sur true, la vérification TLS est utilisée. S'il est défini sur false, la vérification TLS n'est pas utilisée. Si non spécifié, la vérification TLS est utilisée à moins que le registre cible ne soit répertorié comme registre non sécurisé dans containers-registries.conf(5)

EXEMPLES

Crée le manifeste spécifié.

podman manifest create mylist:v1.11
9cfd24048d5fc80903f088f1531a21bff01172abe66effa8941a4c2308dc745f

Crée le manifeste spécifié ou le modifie s'il existait précédemment.

podman manifest create --amend mylist:v1.11
9cfd24048d5fc80903f088f1531a21bff01172abe66effa8941a4c2308dc745f

Crée le manifeste nommé en incluant l'image spécifiée correspondant à la plateforme actuelle.

podman manifest create mylist:v1.11 docker://fedora
5c2bc76bfb4ba6665a7973f7e1c05ee0536b4580637f27adc9fa5a4b2bc03cf1

Crée le manifeste nommé en incluant toutes les images référencées par la référence d'image spécifiée.

podman manifest create --all mylist:v1.11 docker://fedora
30330571e79c65288a4fca421d9aed29b0210d57294d9c2056743fdcf6e3967b
