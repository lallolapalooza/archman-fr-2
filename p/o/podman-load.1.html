NOM

podman-load - Charger une ou plusieurs images à partir d'une archive tar dans le stockage de conteneurs

SYNTAXE

podman load [options]

podman image load [options]

DESCRIPTION

podman load charge une image à partir d'une archive oci-archive ou docker-archive stockée sur la machine locale dans le stockage de conteneurs. podman load lit depuis l'entrée standard par défaut ou depuis un fichier si l'option input est définie. podman load est utilisé pour charger à partir de l'archive générée par podman save, qui inclut les couches parentes de l'image. Pour charger l'archive du système de fichiers d'un conteneur créée par podman export, utilisez podman import.

Le client local prend également en charge le chargement d'un oci-dir ou d'un docker-dir tel que créé avec podman save (1).

L'option quiet supprime la sortie de progression lorsqu'elle est définie. Note : : est un caractère restreint et ne peut pas faire partie du nom de fichier.

OPTIONS

--help, -h

Afficher le message d'utilisation

--input, -i=input

Chargez le fichier d'entrée spécifié au lieu de l'entrée standard. Le fichier peut se trouver sur le système de fichiers local ou sur un serveur (par exemple, https://server.com/archive.tar). Prend également en charge le chargement de fichiers compressés.

Le client distant, y compris les machines Mac et Windows (à l'exception de WSL2), nécessite l'utilisation de cette option.

REMARQUE : Utilisez la variable d'environnement TMPDIR pour modifier l'emplacement de stockage temporaire des images de conteneurs. Podman utilise par défaut /var/tmp.

--quiet, -q

Supprimer la sortie de progression

EXEMPLES

Créer une image à partir d'un fichier tar compressé, sans afficher la progression.

$ podman load --quiet -i fedora.tar.gz

Créer une image à partir du fichier archive.tar récupéré depuis une URL, sans afficher la progression.

$ podman load -q -i https://server.com/archive.tar

Créer une image depuis l'entrée standard en utilisant la redirection bash depuis un fichier tar.

$ podman load < fedora.tar
