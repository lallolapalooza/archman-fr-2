podman-container(1) Manuel des commandes générales podman-container(1)

NOM

podman-container - Gérer les conteneurs

SYNTAXE

podman container sous-commande

DESCRIPTION

La commande container permet la gestion des conteneurs

COMMANDES

Commande Page de manuel Description
attach podman-attach(1) Se connecter à un conteneur en cours d'exécution.
checkpoint podman-container-checkpoint(1) Enregistrer un ou plusieurs conteneurs en cours d'exécution.
cleanup podman-container-cleanup(1) Nettoyer le réseau et les points de montage du conteneur.
clone podman-container-clone(1) Créer une copie d'un conteneur existant.
commit podman-commit(1) Créer une nouvelle image basée sur le conteneur modifié.
cp podman-cp(1) Copier des fichiers/dossiers entre un conteneur et le système de fichiers local.
create podman-create(1) Créer un nouveau conteneur.
diff podman-container-diff(1) Inspecter les modifications sur le système de fichiers d'un conteneur.
exec podman-exec(1) Exécuter une commande dans un conteneur en cours d'exécution.
exists podman-container-exists(1) Vérifier si un conteneur existe dans le stockage local.
export podman-export(1) Exporter le contenu du système de fichiers d'un conteneur sous forme d'archive tar.
init podman-init(1) Initialiser un conteneur.
inspect podman-container-inspect(1) Afficher la configuration d'un conteneur.
kill podman-kill(1) Arrêter le processus principal d'un ou plusieurs conteneurs.
list podman-ps(1) Lister les conteneurs sur le système. (alias ls)
logs podman-logs(1) Afficher les journaux d'un conteneur.
mount podman-mount(1) Monter le système de fichiers racine d'un conteneur en cours de travail.
pause podman-pause(1) Suspendre un ou plusieurs conteneurs.
port podman-port(1) Lister les mappages de ports pour le conteneur.
prune podman-container-prune(1) Supprimer tous les conteneurs arrêtés du stockage local.
ps podman-ps(1) Afficher des informations sur les conteneurs.
rename podman-rename(1) Renommer un conteneur existant.
restart podman-restart(1) Redémarrer un ou plusieurs conteneurs.
restore podman-container-restore(1) Restaurer un ou plusieurs conteneurs à partir d'un point de contrôle.
rm podman-rm(1) Supprimer un ou plusieurs conteneurs.
run podman-run(1) Exécuter une commande dans un conteneur.
runlabel podman-container-runlabel(1) Exécuter une commande telle que décrite par une étiquette d'image de conteneur.
start podman-start(1) Démarrer un ou plusieurs conteneurs.
stats podman-stats(1) Afficher un flux en direct des statistiques d'utilisation des ressources d'un ou plusieurs conteneurs.
stop podman-stop(1) Arrêter un ou plusieurs conteneurs en cours d'exécution.
top podman-top(1) Afficher les processus en cours d'exécution d'un conteneur.
unmount podman-unmount(1) Démonter le système de fichiers racine d'un conteneur en cours de travail. (Alias unmount)
unpause podman-unpause(1) Reprendre un ou plusieurs conteneurs.
update podman-update(1) Mettre à jour la configuration cgroup d'un conteneur donné.
wait podman-wait(1) Attendre qu'un ou plusieurs conteneurs s'arrêtent et afficher leurs codes de sortie.

VOIR AUSSI

podman(1), podman-exec(1), podman-run(1)
