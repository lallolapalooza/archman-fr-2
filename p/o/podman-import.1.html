NOM

podman-import - Importer une archive tar et l'enregistrer en tant qu'image de système de fichiers

SYNOPSIS

podman import [options] chemin [référence]

podman image import [options] chemin [référence]

DESCRIPTION

podman import importe une archive tar (éventuellement compressée avec Gzip, Bzip2, XZ ou Zstd) et l'enregistre en tant qu'image de système de fichiers. Les archives tar distantes peuvent être spécifiées à l'aide d'une URL. Diverses instructions d'image peuvent être configurées avec le drapeau --change et un message de commit peut être défini à l'aide du drapeau --message. référence, si présente, est une étiquette à attribuer à l'image. podman import est utilisé pour importer depuis l'archive générée par podman export, qui inclut le système de fichiers du conteneur. Pour importer l'archive des couches d'images créées par podman save, utilisez podman load. Note : : est un caractère restreint et ne peut pas faire partie du nom de fichier.

OPTIONS

--arch

Définit l'architecture de l'image importée.

--change, -c=instruction

Applique les instructions possibles suivantes à l'image créée : CMD | ENTRYPOINT | ENV | EXPOSE | LABEL | STOPSIGNAL | USER | VOLUME | WORKDIR

Peut être défini plusieurs fois

--help, -h

Affiche le message d'utilisation

--message, -m=message

Définit le message de commit pour l'image importée

--os

Définit le système d'exploitation de l'image importée.

--quiet, -q

Affiche la progression de l'importation

--variant

Définit la variante de l'image importée.
