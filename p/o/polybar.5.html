POLYBAR(5) Manuel utilisateur Polybar POLYBAR(5)

NOM

polybar - fichier de configuration pour polybar(1)

DESCRIPTION

[nom_section]
; Un commentaire
# Un autre commentaire
background = #ff992a
width = 90%
monitor = HDMI-0
screenchange-reload = false
; Utilisez des guillemets doubles si vous voulez conserver l'espace environnant.
text = " Un texte "

Au démarrage, polybar recherchera le fichier de configuration dans plusieurs emplacements dans l'ordre suivant :

  • Si l'argument de ligne de commande -c ou --config est spécifié, il utilisera le chemin indiqué.
  • $XDG_CONFIG_HOME/polybar/config
  • $XDG_CONFIG_HOME/polybar/config.ini
  • $HOME/.config/polybar/config
  • $HOME/.config/polybar/config.ini
  • $XDG_CONFIG_DIRS/polybar/config.ini
  • /etc/xdg/polybar/config.ini (uniquement si XDG_CONFIG_DIRS n'est pas défini)
  • /etc/polybar/config.ini

SYNTAXE

Toute la configuration est basée sur des lignes, donc tout est limité à une seule ligne. Cela signifie qu'il n'y a pas de valeurs multilignes ni d'autres constructions multilignes (à l'exception des sections). Chaque ligne est de l'un des quatre types suivants :

  • Vide
  • Commentaire
  • En-tête de section
  • Clé

Les espaces au début et à la fin de chaque ligne seront ignorés.

NOTE :

Dans ce contexte, les « espaces » incluent le caractère d'espace normal ainsi que le caractère de tabulation et tout autre caractère pour lequel isspace(3) renvoie true (par exemple, \r).

Toute ligne qui ne correspond pas à l'un de ces quatre types est une erreur de syntaxe.

NOTE :

Il est recommandé que les noms de sections et les noms de clés n'utilisent que des caractères alphanumériques ainsi que des tirets (-), des underscores (_) et des barres obliques (/).

En pratique, tous les caractères sont autorisés à l'exception des espaces et de l'un des caractères suivants : "'=;#[](){}:.$\%

En-têtes de Section

Les sections sont utilisées pour regrouper les options de configuration. Par exemple, chaque module est défini dans sa propre section.

Une section est définie en plaçant le nom de la section entre crochets ([ et ]). Par exemple :

[module/wm]

Cela déclare une section nommée module/wm et toutes les clés définies après cette ligne appartiendront à cette section jusqu'à ce qu'une nouvelle section soit déclarée.

ATTENTION :

La première ligne non vide et non commentée dans le fichier de configuration principal doit être un en-tête de section. Il ne peut pas s'agir d'une clé, car cette clé n'appartiendrait à aucune section.

NOTE :

Les noms de section suivants sont réservés et ne peuvent pas être utilisés dans la configuration : self, root et BAR.

Clés

Les clés sont définies en assignant une valeur à un nom comme ceci :

nom = valeur

Cela assigne valeur à la clé nom dans quelle que soit la section où se trouve cette ligne. Les noms de clés doivent être uniques par section. Si la valeur est entourée de guillemets doubles ("), les guillemets seront ignorés. Donc, ce qui suit assigne toujours valeur à nom :

nom = "valeur"

Les espaces autour du signe égal sont ignorés, les lignes suivantes sont toutes équivalentes :

nom=valeur
nom = valeur
nom =      valeur

Comme les espaces au début et à la fin de la ligne sont également ignorés, si vous souhaitez que votre valeur commence et/ou finisse par un espace, la valeur doit être entourée de guillemets doubles :

nom = " valeur "

Ici, la valeur de la clé nom a un espace en début et en fin.

Pour traiter les caractères ayant une signification spéciale comme des caractères littéraux, vous devez les faire précéder du caractère d'échappement backslash (\) :

nom = "valeur\\valeur\\valeur"

La valeur de cette clé nom résulte en valeur\valeur\valeur.

NOTE :

Le seul caractère ayant une signification spéciale pour le moment est le caractère backslash (\), qui sert de caractère d'échappement. D'autres seront ajoutés à l'avenir.

Lignes Vides & Commentaires

Les lignes vides et les lignes de commentaire sont ignorées lors de la lecture du fichier de configuration, elles n'affectent pas le comportement de polybar. Les lignes de commentaire commencent par le caractère ; ou #.

NOTE :

Les commentaires en ligne ne sont pas pris en charge. Par exemple, la ligne suivante ne se termine pas par un commentaire, la valeur de nom est en fait définie sur valeur ; commentaire : 
nom = valeur ; commentaire
