NOM

podman-container-exists - Vérifie si un conteneur existe dans le stockage local

SYNTAXE

podman container exists [options] conteneur

DESCRIPTION

podman container exists vérifie si un conteneur existe dans le stockage local. L'ID du conteneur ou le nom sont utilisés en entrée. Podman renvoie un code de sortie de 0 lorsque le conteneur est trouvé. Un code de sortie de 1 est renvoyé sinon. Un code de sortie de 125 indique qu'il y a eu un problème d'accès au stockage local.

OPTIONS

--external

Vérifie également les conteneurs externes en plus des conteneurs Podman. Ces conteneurs externes sont généralement créés via d'autres technologies de conteneurisation comme Buildah ou CRI-O.
La valeur par défaut est false.

-h, --help

Affiche le message d'utilisation.
La valeur par défaut est false.

EXEMPLES

Vérifie si un conteneur nommé "webclient" existe dans le stockage local. Ici, le conteneur existe.

$ podman container exists webclient
$ echo $?
0

Vérifie si un conteneur nommé "webbackend" existe dans le stockage local. Ici, le conteneur n'existe pas.

$ podman container exists webbackend
$ echo $?
1

Vérifie si un conteneur nommé "ubi8-working-container" créé via Buildah existe dans le stockage local. Ici, le conteneur n'existe pas.

$ podman container exists --external ubi8-working-container
$ echo $?
1
