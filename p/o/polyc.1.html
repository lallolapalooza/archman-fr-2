NOM

polyc - Compiler et lier un programme Standard ML avec Poly/ML

SYNTAXE

polyc fichier_source

DESCRIPTION

polyc est un script qui compile un programme Standard ML en utilisant le compilateur Poly/ML et crée un programme exécutable à partir de celui-ci. Il peut également être utilisé pour lier des fichiers objets créés avec la fonction PolyML.export avec les bibliothèques Poly/ML ou pour produire un fichier objet. Lorsqu'il est utilisé pour compiler un programme Standard ML, il s'attend à ce que la fonction principale soit appelée "main", par exemple : fun main() = print "Hello World\n";

Si le fichier source est un fichier texte, il est supposé être du code source ML. S'il s'agit d'un fichier binaire, il est supposé être un fichier objet et sera lié à la bibliothèque Poly/ML.

OPTIONS

-c Compiler mais ne pas lier. Le fichier objet est écrit dans un fichier dont le nom est basé sur le nom du fichier source, avec toute extension remplacée par .o

-o sortie
Écrit le fichier exécutable dans "sortie".
--help
Écrit une liste des arguments et quitte.
