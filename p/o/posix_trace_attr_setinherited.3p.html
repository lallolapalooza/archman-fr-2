POSIX_TRACE_ATTR_SETINHERITED(3P) Manuel du programmeur POSIX POSIX_TRACE_ATTR_SETINHERITED(3P)

PROLOGUE

Cette page de manuel fait partie du manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour connaître les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_trace_attr_setinherited, posix_trace_attr_setlogfullpolicy — récupérer et définir le comportement d'un flux de trace (TRACING)

SYNTAXE

#include <trace.h>
int posix_trace_attr_setinherited(trace_attr_t *attr,
    int inheritancepolicy);
int posix_trace_attr_setlogfullpolicy(trace_attr_t *attr,
    int logpolicy);

DESCRIPTION

Voir posix_trace_attr_getinherited().
