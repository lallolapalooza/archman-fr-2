NOM

podofocolor - modifie les couleurs dans un fichier PDF.

SYNTAXE

podofocolor [convertisseur] [fichier_entree] [fichier_sortie]

DESCRIPTION

podofocolor est l'un des outils en ligne de commande de la bibliothèque PoDoFo qui offre plusieurs opérations utiles pour travailler avec les couleurs dans les fichiers PDF. Il peut analyser et/ou modifier toutes les couleurs ou espaces colorimétriques dans un fichier PDF. Les modifications peuvent être définies via C++ ou un script Lua. Des conversions personnalisées comme convertir toutes les couleurs en niveaux de gris sont incluses. Veuillez noter que seules les couleurs des objets vectoriels sur les pages et dans les XObjects sont affectées. Cet outil ne transforme pas les couleurs des images pour le moment.

CONVERTISSEURS

[convertisseur] peut être l'un des suivants :

dummy - Convertit toutes les couleurs en rouge. Il s'agit simplement d'une implémentation factice et de test qui sert d'exemple pour les développeurs.
grayscale - Convertit toutes les couleurs des objets vectoriels d'un PDF en niveaux de gris.
lua [script] - Convertit toutes les couleurs en fonction d'une description Lua. Un script Lua doit être passé en paramètre supplémentaire.
