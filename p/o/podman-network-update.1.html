NOM

podman-network-update - Mettre à jour un réseau Podman existant

SYNTAXE

podman network update [options] réseau

DESCRIPTION

Permet d'apporter des modifications aux réseaux de conteneurs existants. À l'heure actuelle, seules les modifications des serveurs DNS utilisés par un réseau sont prises en charge.

NOTE : Uniquement pris en charge avec le backend réseau netavark.

OPTIONS

--dns-add

Accepte un tableau de résolveurs DNS et les ajoute à la liste existante des résolveurs configurés pour un réseau.

--dns-drop

Accepte un tableau de résolveurs DNS et les supprime de la liste existante des résolveurs configurés pour un réseau.

EXEMPLE

Mettre à jour un réseau :

$ podman network update network1 --dns-add 8.8.8.8,1.1.1.1

Mettre à jour un réseau et ajouter/supprimer des serveurs DNS :

$ podman network update network1 --dns-drop 8.8.8.8 --dns-add 3.3.3.3
