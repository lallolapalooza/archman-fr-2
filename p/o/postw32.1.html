NOM

postw32 - Processeur post-compilation pour exécutables Windows 32 bits Free Pascal.

SYNTAXE

postw32 [-vh] [-m sous-système] [-i fichier] [-V version] [-s taille]

DESCRIPTION

postw32 effectue un post-traitement sur un fichier exécutable ou une bibliothèque Windows 32 bits. Il peut définir le sous-système Windows, la taille de la pile et la version du fichier.

UTILISATION

postw32 nécessite au moins 2 options. L'une est le nom du fichier d'entrée (option -i) et l'autre est l'une des opérations possibles, avec leurs arguments.

OPTIONS

prend les options suivantes à ce moment :

-i fichier
spécifie le fichier d'entrée à traiter. Cette option est une notation courte pour l'option --input.
-h
Affiche un court message d'aide. Cette option est une notation courte pour l'option --help.
-m sous-système
Définit le sous-système (type d'application) à gui ou console. Notez qu'une application gui qui écrit sur la ligne de commande provoquera une erreur. Cette option est une notation courte pour l'option --subsystem.
-s taille
Définit la taille de la pile à taille octets. Cette option est une notation courte pour l'option --stack.
-v
Être verbeux sur les opérations effectuées. Cette option est une notation courte pour l'option --verbose.
-V M.N
Définit la version du fichier à M.N, où M et N sont des valeurs non signées de 16 bits. Cette option est une notation courte pour l'option --version.
