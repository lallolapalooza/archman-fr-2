podman-pod-start(1) Manuel des commandes générales podman-pod-start(1)

NOM

podman-pod-start - Démarre un ou plusieurs pods

SYNTAXE

podman pod start [options] pod ...

DESCRIPTION

Démarre les conteneurs dans un ou plusieurs pods. Vous pouvez utiliser les IDs ou les noms des pods comme entrée. Le pod doit avoir un conteneur attaché pour être démarré.

OPTIONS

--all, -a

Démarre tous les pods

--latest, -l

Au lieu de fournir le nom ou l'ID du pod, utilise le dernier pod créé. Note : le dernier pod démarré peut appartenir à d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (à l'exception de WSL2))

--pod-id-file=fichier

Lit l'ID du pod depuis le fichier spécifié et démarre le pod. Peut être spécifié plusieurs fois.

EXEMPLE

Démarre un pod avec un nom donné :

podman pod start monpodwebserver

Démarre des pods avec des IDs donnés :

podman pod start 860a4b23 5421ab4

Démarre le dernier pod. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (à l'exception de WSL2)) :

podman pod start --latest

Démarre tous les pods :

podman pod start --all

Démarre un pod en utilisant l'ID spécifié dans un fichier donné :

podman pod start --pod-id-file /chemin/vers/fichier/id

VOIR AUSSI

podman(1), podman-pod(1), podman-pod-stop(1)
