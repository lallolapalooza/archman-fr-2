podman-untag(1) Manuel des commandes générales podman-untag(1)

NOM

podman-untag - Supprime un ou plusieurs noms d'une image stockée localement

SYNTAXE

podman untag image [nom[:étiquette]...]

podman image untag image [nom[:étiquette]...]

DESCRIPTION

Supprime un ou plusieurs noms d'une image dans le stockage local. L'image peut être référencée par son ID ou sa référence. Si aucun nom n'est spécifié, tous les noms sont supprimés de l'image. Si un nom spécifié est un nom court et n'inclut pas de registre, localhost/ est préfixé (par exemple, fedora -> localhost/fedora). Si un nom spécifié n'inclut pas d'étiquette, :latest est ajouté (par exemple, localhost/fedora -> localhost/fedora:latest).

OPTIONS

--help, -h

Affiche l'énoncé d'utilisation

EXEMPLES

Supprime toutes les étiquettes de l'image spécifiée.

$ podman untag 0e3bbc2

Supprime une étiquette de l'image spécifiée.

$ podman untag nomImage:latest autreNomImage:latest

Supprime plusieurs étiquettes de l'image spécifiée.

$ podman untag httpd myhttpd myregistryhost:5000/fedora/httpd:v2
