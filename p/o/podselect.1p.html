NOM

podselect - imprime les sections sélectionnées de la documentation pod sur la sortie standard

SYNTAXE

podselect [-help] [-man] [-section spéc-section] [fichier ...]

OPTIONS ET ARGUMENTS

-help
Imprime un bref message d'aide et quitte.
-man
Imprime la page de manuel et quitte.
-section spéc-section
Spécifie une section à inclure dans la sortie. Voir "SPÉCIFICATIONS DE SECTION" dans Pod::Parser pour le format à utiliser pour spéc-section. Cette option peut être donnée plusieurs fois sur la ligne de commande.
fichier
Le chemin d'accès à un fichier à partir duquel sélectionner les sections de documentation pod (par défaut, l'entrée standard).

DESCRIPTION

podselect lira les fichiers d'entrée donnés à la recherche de documentation pod et imprimera (au format pod brut) toutes les sections qui correspondent à une ou plusieurs des spécifications de section données. Si aucune spécification de section n'est donnée, toutes les sections pod rencontrées seront affichées.

podselect invoque la fonction podselect() exportée par Pod::Select. Veuillez consulter "podselect()" dans Pod::Select pour plus de détails.

VOIR AUSSI

Pod::Parser et Pod::Select
