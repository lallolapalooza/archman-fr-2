NOM

podofopdfinfo - fournir des informations sur un fichier PDF

SYNTAXE

podofopdfinfo [DCPON] [fichier_entree]

DESCRIPTION

podofopdfinfo est l'un des outils en ligne de commande de la bibliothèque PoDoFo qui fournit plusieurs opérations utiles pour travailler avec des fichiers PDF. Il peut fournir un certain nombre de faits concernant un document PDF selon les instructions de formatage. Si les instructions ne sont pas fournies, des informations complètes sont affichées.

OPTIONS

D

affiche les informations du document.

C

affiche les métadonnées classiques.

P

affiche les informations des pages.

O

affiche les plans.

N

affiche les noms.

[fichier_entree]

Fichier PDF d'entrée.
