NOM

podman-commit - Créer une nouvelle image basée sur le conteneur modifié

SYNOPSIS

podman commit [options] conteneur [image]

podman container commit [options] conteneur [image]

DESCRIPTION

podman commit crée une image basée sur un conteneur modifié. L'auteur de l'image peut être défini à l'aide de l'option --author. Diverses instructions d'image peuvent être configurées avec l'option --change et un message de commit peut être défini à l'aide de l'option --message. Le conteneur et ses processus ne sont pas mis en pause pendant la création de l'image. Si cela n'est pas souhaité, l'option --pause peut être définie sur true. Une fois le commit terminé, Podman affiche l'ID de la nouvelle image.

Si image ne commence pas par un composant de nom de registre, localhost est ajouté au nom. Si image n'est pas fourni, les valeurs pour les valeurs RÉPOSITORIE et TAG de l'image créée sont définies sur <aucun>.

OPTIONS

--author, -a=auteur

Définit l'auteur de l'image commitée.

--change, -c=instruction

Applique les instructions possibles suivantes à l'image créée :

  • CMD
  • ENTRYPOINT
  • ENV
  • EXPOSE
  • LABEL
  • ONBUILD
  • STOPSIGNAL
  • USER
  • VOLUME
  • WORKDIR

Peut être défini plusieurs fois.

--config=FichierBlobConfig

Fusionne la configuration du conteneur du fichier spécifié dans la configuration de l'image lors de sa création. Le contenu du fichier doit être une version encodée en JSON d'une structure Schema2Config, définie à l'adresse https://github.com/containers/image/blob/v5.29.0/manifest/docker_schema2.go#L67.

--format, -f=oci | docker

Définit le format du manifeste et des métadonnées de l'image. Les formats actuellement pris en charge sont oci et docker.
La valeur par défaut est oci.

--iidfile=FichierIDImage

Écrit l'ID de l'image dans le fichier.

--include-volumes

Inclut dans l'image commitée tous les volumes ajoutés au conteneur par les options --volume ou --mount des commandes podman create et podman run.
La valeur par défaut est false.

--message, -m=message

Définit le message de commit pour l'image commitée.
IMPORTANT : Le champ message n'est pas pris en charge dans le format oci.

--pause, -p

Met en pause le conteneur lors de la création d'une image.
La valeur par défaut est false.

--quiet, -q

Supprime la sortie.
La valeur par défaut est false.

--squash, -s

Écrase les couches nouvellement construites en une seule nouvelle couche.
La valeur par défaut est false.

EXEMPLES

Créer une image à partir d'un conteneur avec un point d'entrée et une étiquette :

$ podman commit --change CMD=/bin/bash --change ENTRYPOINT=/bin/sh --change "LABEL blue=image" reverent_golick image-committed

 25.80 Mo / 25.80 Mo [======================================================] 0s
Copie de la configuration sha256:c16a6d30f3782288ec4e7521c754acc29d37155629cb39149756f486dae2d4cd
 448 octets / 448 octets [============================================================] 0s
Écriture du manifeste dans la destination de l'image
Stockage des signatures
e3ce4d93051ceea088d1c242624d659be32cf1667ef62f1d16d6b60193e2c7a8

Créer une image à partir d'un conteneur avec un message de commit :

$ podman commit -q --message "commit du conteneur vers l'image"
reverent_golick image-committed
e3ce4d93051ceea088d1c242624d659be32cf1667ef62f1d16d6b60193e2c7a8

Créer une image à partir d'un conteneur avec un auteur :

$ podman commit -q --author "Prénom Nom" reverent_golick image-committed
e3ce4d93051ceea088d1c242624d659be32cf1667ef62f1d16d6b60193e2c7a8

Mettre en pause le conteneur en cours d'exécution lors de la création de l'image :

$ podman commit -q --pause=true containerID image-committed
e3ce4d93051ceea088d1c242624d659be32cf1667ef62f1d16d6b60193e2c7a8

Créer une image à partir d'un conteneur avec une étiquette d'image par défaut :

$ podman commit containerID
e3ce4d93051ceea088d1c242624d659be32cf1667ef62f1d16d6b60193e2c7a8

Créer une image à partir d'un conteneur avec les capacités requises par défaut :

$ podman commit -q --change LABEL=io.containers.capabilities=setuid,setgid epic_nobel privimage
400d31a3f36dca751435e80a0e16da4859beb51ff84670ce6bdc5edb30b94066
