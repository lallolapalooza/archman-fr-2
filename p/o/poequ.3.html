sous-routine cpoequ (integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) s, real scond, real amax, integer info)

CPOEQU

But :

!>
!> CPOEQU calcule les échelles de ligne et de colonne destinées à équilibrer une
!> matrice hermitienne définie positive A et à réduire son nombre de conditionnement
!> (par rapport à la norme deux). S contient les facteurs d'échelle,
!> S(i) = 1/sqrt(A(i,i)), choisis de sorte que la matrice mise à l'échelle B avec
!> les éléments B(i,j) = S(i)*A(i,j)*S(j) ait des uns sur la diagonale. Ce
!> choix de S met le nombre de conditionnement de B à un facteur N du
!> plus petit nombre de conditionnement possible sur toutes les mises à l'échelle diagonales possibles.
!>

Paramètres

N 
!>          N est un entier
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEXE, de dimension (LDA,N)
!>          La matrice hermitienne définie positive de taille N x N dont les
!>          facteurs d'échelle doivent être calculés. Seuls les éléments diagonaux de A
!>          sont référencés.
!>

LDA

!>          LDA est un entier
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

S

!>          S est un tableau RÉEL, de dimension (N)
!>          Si INFO = 0, S contient les facteurs d'échelle pour A.
!>

SCOND

!>          SCOND est un RÉEL
!>          Si INFO = 0, S contient le rapport du plus petit S(i) au
!>          plus grand S(i). Si SCOND >= 0.1 et AMAX n'est ni trop
!>          grand ni trop petit, il n'est pas utile de mettre à l'échelle avec S.
!>

AMAX

!>          AMAX est un RÉEL
!>          Valeur absolue du plus grand élément de la matrice. Si AMAX est très
!>          proche du dépassement de capacité ou très proche du sous-dépassement, la matrice
!>          doit être mise à l'échelle.
!>

INFO

!>          INFO est un entier
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le i-ème élément diagonal est non positif.
!>

Description


POEQU calcule des facteurs d'équilibrage de ligne et de colonne
    destinés à équilibrer une matrice hermitienne à éléments positifs A et à
    réduire son nombre de condition (par rapport à la norme deux). S contient les
    facteurs d'échelle, S(i) = 1/sqrt(A(i,i)), choisis de telle sorte que la
    matrice mise à l'échelle B, avec les éléments B(i,j) = S(i)*A(i,j)*S(j), ait
    des uns sur la diagonale. Ce choix de S place le nombre de condition de B dans
    un facteur N du plus petit nombre de condition possible sur toutes les
    mises à l'échelle diagonales possibles.


Dans le cas de matrices réelles, la diagonale est supposée avoir
    des éléments positifs. Dans le cas de matrices complexes, la diagonale est
    supposée avoir des éléments réels positifs.


Si la matrice A n'est pas hermitienne, le résultat n'est pas
    défini.


La matrice A est supposée être à éléments positifs pour que la
    racine carrée existe.


La valeur de SCOND est le rapport du plus petit au plus grand des
    composants de S. Si SCOND >= 0.1, alors le rapport max(diag(A))/min(diag(A))
    est inférieur à 10. Dans ce cas, il n'est généralement pas nécessaire de
    mettre à l'échelle la matrice.


AMAX est la valeur absolue du plus grand élément de la matrice A.
    Si AMAX est proche de la limite de représentation en virgule flottante, la
    matrice est mise à l'échelle pour éviter un débordement.
