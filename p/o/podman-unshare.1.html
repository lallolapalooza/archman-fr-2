NOM

podman-unshare - Exécute une commande à l'intérieur d'un nouvel espace de noms utilisateur

SYNTAXE

podman unshare [options] [commande]

DESCRIPTION

Lance un processus (par défaut, $SHELL) dans un nouvel espace de noms utilisateur. L'espace de noms utilisateur est configuré de telle sorte que l'UID et le GID principal de l'utilisateur qui appelle apparaissent comme UID 0 et GID 0, respectivement. Toutes les plages qui correspondent à cet utilisateur et à ce groupe dans /etc/subuid et /etc/subgid sont également mappées comme elles-mêmes à l'aide des utilitaires newuidmap(1) et newgidmap(1).

podman unshare est utile pour dépanner les opérations non privilégiées et pour effacer manuellement le stockage et d'autres données relatives aux images et aux conteneurs.

Il est également utile d'utiliser la commande podman mount. Si un utilisateur non privilégié souhaite monter et travailler avec un conteneur, il doit exécuter podman unshare. L'exécution de podman mount échoue pour les utilisateurs non privilégiés, à moins que l'utilisateur ne s'exécute à l'intérieur d'une session podman unshare.

La session unshare définit deux variables d'environnement :

  • CONTAINERS_GRAPHROOT : le chemin d'accès aux données persistantes du conteneur.
  • CONTAINERS_RUNROOT : le chemin d'accès aux données volatiles du conteneur.

IMPORTANT : Cette commande n'est pas disponible avec le client Podman distant.

OPTIONS

--help, -h

Affiche l'énoncé d'utilisation

--rootless-netns

Rejoint l'espace de noms réseau rootless utilisé pour le réseau netavark. Il peut être utilisé pour se connecter à un conteneur rootless via une adresse IP (réseau pont). Ce n'est pas possible autrement depuis l'espace de noms réseau de l'hôte.

CODES DE SORTIE

Le code de sortie de podman unshare donne des informations sur la raison pour laquelle le conteneur n'a pas pu s'exécuter ou pourquoi il s'est terminé. Lorsque les commandes podman unshare se terminent avec un code non nul, les codes de sortie suivent la norme chroot, voir ci-dessous :

125 L'erreur concerne podman lui-même

$ podman unshare --foo; echo $?
Error: unknown flag: --foo
125

126 Exécution d'une commande contenue et la commande ne peut pas être invoquée

$ podman unshare /etc; echo $?
Error: fork/exec /etc: permission denied
126

127 Exécution d'une commande contenue et la commande ne peut pas être trouvée

$ podman unshare foo; echo $?
Error: fork/exec /usr/bin/bogus: no such file or directory
127

Code de sortie code de sortie de la commande contenue

$ podman unshare /bin/sh -c 'exit 3'; echo $?
3

EXEMPLE

Exécute la commande spécifiée dans l'espace de noms utilisateur rootless :

$ podman unshare id
uid=0(root) gid=0(root) groups=0(root),65534(nobody)

Affiche les mappages de l'espace de noms utilisateur pour les conteneurs rootless :

$ podman unshare cat /proc/self/uid_map /proc/self/gid_map
         0       1000          1
         1      10000      65536
         0       1000          1
         1      10000      65536
