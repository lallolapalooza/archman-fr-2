policyeditor(1) Manuel des commandes générales policyeditor(1)

NOM

policyeditor - visualiser et modifier les paramètres de politique de sécurité pour javaws et le plugin navigateur

SYNTAXE

policyeditor
policyeditor [-file] fichier_politique

DESCRIPTION

policyeditor est une application graphique avec un petit support en ligne de commande pour visualiser et modifier les paramètres de politique de sécurité des applets utilisés par l'implémentation IcedTea-Web de javaws et du plugin navigateur. Il se veut une alternative plus simple, plus facile à utiliser et plus accessible à l'outil standard JDK Policy Tool. Les administrateurs et les utilisateurs avancés qui ont besoin d'un contrôle précis sur les fichiers de politique devraient probablement utiliser Policy Tool plutôt que PolicyEditor.

S'il est exécuté sans aucun argument, aucun fichier n'est ouvert, et la sauvegarde du fichier entraînera une invite à choisir où le sauvegarder. Sinon, si un chemin de fichier est donné comme argument de ligne de commande, ce chemin sera ouvert et analysé comme fichier de politique.

OPTIONS

-codebase url
Spécifie une URL de codebase d'applet. Ceci peut être utilisé avec les autres options de sélection pour sélectionner une entrée de politique lors de l'ouverture de l'éditeur ; si aucun identifiant de ce type n'existe, il sera créé puis sélectionné. (Exactement un argument attendu)
-defaultfile
Spécifie que le fichier de politique utilisateur par défaut doit être ouvert. C'est le fichier normalement utilisé par IcedTea-Web pour prendre des décisions concernant les politiques personnalisées et les permissions des applets à l'exécution, sauf configuration contraire. (Aucun argument attendu)
-file fichier_politique
Spécifie un chemin de fichier de politique à ouvrir. Si exactement un argument est donné, et qu'il ne s'agit pas de ce drapeau, il est interprété comme un chemin de fichier à ouvrir, comme si ce drapeau était donné en premier. Ce drapeau existe principalement pour la compatibilité avec Policy Tool. (Exactement un argument attendu)
-help
Affiche des informations sur les commandes prises en charge et l'utilisation de base. (Aucun argument attendu)
-principals nom_classe nom_principal
Spécifie des paires nom de classe/nom principal (séparées par des espaces) pour l'identifiant de l'entrée de politique. Ceci peut être utilisé avec les autres options de sélection pour sélectionner une entrée de politique lors de l'ouverture de l'éditeur ; si aucun identifiant de ce type n'existe, il sera créé puis sélectionné. (Nombre pair d'arguments attendus avec param=valeur comme argument valide)
-signedby alias_certificat
Spécifie un alias de certificat pour un certificat stocké dans le magasin de clés. Ceci peut être utilisé avec les autres options de sélection pour sélectionner une entrée de politique lors de l'ouverture de l'éditeur ; si aucun identifiant de ce type n'existe, il sera créé puis sélectionné. (Exactement un argument attendu)
-verbose
Active la sortie détaillée. (Aucun argument attendu)

EXEMPLES

policyeditor
Affiche l'éditeur graphique sans fichier ouvert.
policyeditor -file $XDG_CONFIG_HOME/icedtea-web/security/java.policy
Affiche l'éditeur graphique et ouvre le fichier de politique par défaut.

FICHIERS

$XDG_CACHE_HOME/icedtea-web/cache/recently_used
Informations supplémentaires sur les éléments dans le cache
$XDG_CONFIG_HOME/icedtea-web/security/java.policy
Contient les permissions accordées pour les applications non signées sélectionnées. Contrôlé par deployment.user.security.policy

Où $XDG_CONFIG_DIR, $XDG_CACHE_DIR et $XDG_RUNTIME_DIR sont définis comme ~/.config, ~/.cache et /tmp ou /var/tmp s'ils ne sont pas définis.

policyeditor.1

NOM

policyeditor - Éditeur de politiques pour l'exécution de code Java

SYNOPSIS

policyeditor [options]

DESCRIPTION

policyeditor est un outil graphique qui permet de modifier les politiques de sécurité pour l'exécution de code Java. Il permet de définir les permissions accordées aux différents applets et applications Java, afin de contrôler leur accès aux ressources du système.

OPTIONS

Ce programme n'accepte aucune option en ligne de commande.

EXEMPLES

Pour lancer l'éditeur de politiques, tapez simplement :

policyeditor

FICHIERS

Le fichier de politique par défaut est généralement situé dans ~/.java.policy ou /etc/java.policy.

BOGUES

Aucun bogues connus signalés.
