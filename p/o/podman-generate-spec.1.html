podman-generate-spec(1) Manuel des commandes générales podman-generate-spec(1)

NOM

podman generate spec - Générer du JSON SpecGen basé sur des conteneurs ou des pods

SYNTAXE

podman generate spec [options] *conteneur | pod

DESCRIPTION

podman generate spec génère du JSON SpecGen à partir de conteneurs et de pods Podman. Ce JSON peut être imprimé dans un fichier, directement sur la ligne de commande, ou les deux.

Ce JSON peut ensuite être utilisé comme entrée pour l'API Podman, spécifiquement pour la création de conteneurs et de pods Podman. Specgen est la structure interne de Podman pour formuler de nouvelles entités liées aux conteneurs.

OPTIONS

--compact, -c

Imprimer la sortie dans un format compact, sur une seule ligne. Ceci est utile lors de la transmission des données à l'API Podman.

--filename, -f=nom_de_fichier

Sortie vers le fichier donné.

--name, -n

Renommer le pod ou le conteneur, afin qu'il n'entre pas en conflit avec l'entité existante. Ceci est utile lorsque le JSON doit être utilisé avant que le pod ou le conteneur source ne soit supprimé.

Générer du JSON SpecGen basé sur un conteneur. La sortie est sur une seule ligne.

$ podman generate spec --compact container1
{"name":"container1-clone","command":["/bin/sh"],...

Générer du JSON SpecGen basé sur un conteneur, en écrivant la sortie dans le fichier spécifié.

$ podman generate spec --filename output.json container1
