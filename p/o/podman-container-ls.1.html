NOM

podman-ps - Affiche des informations sur les conteneurs

SYNOPSIS

podman ps [options]

podman container ps [options]

podman container list [options]

podman container ls [options]

DESCRIPTION

podman ps liste les conteneurs en cours d'exécution sur le système. Utilisez l'option --all pour voir toutes les informations des conteneurs. Par défaut, il liste :

  • l'identifiant du conteneur
  • le nom de l'image utilisée par le conteneur
  • la COMMANDE exécutée par le conteneur
  • le moment où le conteneur a été créé
  • l'état du conteneur
  • les mappages de ports utilisés par le conteneur
  • les noms alternatifs pour le conteneur

OPTIONS

--all, -a

Affiche tous les conteneurs, par défaut seuls les conteneurs en cours d'exécution sont affichés.

Note : Podman partage le stockage des conteneurs avec d'autres outils tels que Buildah et CRI-O. Dans certains cas, ces conteneurs externes peuvent également exister dans le même stockage. Utilisez l'option --external pour voir ces conteneurs externes. Les conteneurs externes affichent le statut de 'stockage'.

--external

Affiche les conteneurs externes qui ne sont pas contrôlés par Podman mais qui sont stockés dans le stockage de conteneurs. Ces conteneurs externes sont généralement créés via d'autres technologies de conteneurisation comme Buildah ou CRI-O et peuvent dépendre des mêmes images de conteneur que Podman utilise également. Les conteneurs externes sont indiqués par 'buildah' ou 'storage' dans les colonnes COMMAND et STATUS de la sortie ps.

--filter, -f

Filtre les conteneurs affichés dans la sortie. Plusieurs filtres peuvent être donnés en utilisant plusieurs fois l'option --filter. Les filtres avec la même clé fonctionnent de manière inclusive, à l'exception de label qui est exclusive. Les filtres avec des clés différentes fonctionnent toujours de manière exclusive.

Les filtres valides sont listés ci-dessous :

Filtre Description
id [ID] ID du conteneur (correspondance de préfixe CID par défaut ; accepte les expressions régulières)
name [Nom] Nom du conteneur (accepte les expressions régulières)
label [Clé] ou [Clé=Valeur] Étiquette attribuée à un conteneur
label! [Clé] ou [Clé=Valeur] Étiquette NON attribuée à un conteneur
exited [Int] Code de sortie du conteneur
status [Statut] Statut du conteneur : 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NomImage] Image ou descendant utilisé pour créer le conteneur (accepte les expressions régulières)
before [ID] ou [Nom] Conteneurs créés avant ce conteneur
since [ID] ou [Nom] Conteneurs créés après ce conteneur
volume [NomVolume] ou [PointMontageDestination] Volume monté dans le conteneur
health [Statut] healthy ou unhealthy
pod [Pod] nom ou ID complet ou partiel du pod
network [Réseau] nom ou ID complet du réseau
until [DateTime] conteneur créé avant la durée ou l'heure donnée.
command [Commande] la commande que le conteneur exécute, seul argv[0] est pris en compte

--format=format

Affiche joliment les conteneurs en JSON ou à l'aide d'un modèle Go

Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Espace réservé Description
.AutoRemove Si vrai, les conteneurs sont supprimés à la sortie
.CIDFile Fichier d'ID de conteneur
.Command Commande mise entre guillemets utilisée
.Created ... Heure de création du conteneur, AAAA-MM-JJ HH:MM:SS
.CreatedAt Heure de création du conteneur (identique à ci-dessus)
.CreatedHuman Heure de création, relative
.ExitCode Code de sortie du conteneur
.Exited "true" si le conteneur est sorti
.ExitedAt Heure (secondes époch) de sortie du conteneur
.ExposedPorts ... Carte des ports exposés sur ce conteneur
.ID ID du conteneur
.Image Nom/ID de l'image
.ImageID ID de l'image
.IsInfra "true" si c'est un conteneur infra
.Label string Étiquette spécifiée du conteneur
.Labels ... Toutes les étiquettes attribuées au conteneur
.Mounts Volumes montés dans le conteneur
.Names Nom du conteneur
.Networks Affiche tous les réseaux connectés au conteneur
.Pid ID du processus sur le système hôte
.Pod Pod auquel le conteneur est associé (SHA)
.PodName Nom du pod du conteneur
.Ports Ports transférés et exposés
.Restarts Affiche le nombre de redémarrages du conteneur
.RunningFor Temps écoulé depuis le démarrage du conteneur
.Size Taille du conteneur
.StartedAt Heure (secondes époch) de démarrage du conteneur
.State Description conviviale de l'état du conteneur
.Status Statut du conteneur

--help, -h

Affiche le message d'utilisation

--last, -n

Affiche les n derniers conteneurs créés (tous états)

--latest, -l

Affiche le dernier conteneur créé (tous états) (Cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (à l'exclusion de WSL2))

--namespace, --ns

Affiche les informations de l'espace de noms

--no-trunc

Ne tronque pas la sortie (par défaut false).

--noheading

Omet les en-têtes de tableau de la liste des conteneurs.

--pod, -p

Affiche les pods auxquels les conteneurs sont associés

--quiet, -q

Affiche uniquement les identifiants numériques des conteneurs

--size, -s

Affiche la taille totale des fichiers

--sort=created

Trie par commande, created, id, image, names, runningfor, size, ou status". Note : Choisir size trie par la taille de rootFs, et non pas alphabétiquement comme les autres options.

--sync

Force une synchronisation de l'état des conteneurs avec le runtime OCI. Dans certains cas, l'état d'un conteneur dans le runtime peut devenir désynchronisé avec l'état de Podman. Ceci met à jour l'état de Podman en fonction de ce que rapporte le runtime OCI. La synchronisation forcée est beaucoup plus lente, mais peut résoudre les problèmes d'état incohérents.

--watch, -w

Actualise la sortie avec les conteneurs actuels à intervalles de quelques secondes.

NAME

podman-container-ls, podman-ps — List containers

SYNOPSIS

List containers.

podman container ls [options]

List all containers.

podman ps [options]

DESCRIPTION

The podman container ls command lists containers running on the system. This command is an alias for podman ps. By default, only running containers are listed. The -a or --all option can be used to list all containers, including stopped ones.

You can use the --format option to specify a Go template for formatting the output of the podman ps command.

OPTIONS

All the options from podman ps are available, plus the following.

-a, --all
Show all containers (default shows just prior, running containers).
-f, --filter filter=value
Filter output based on conditions provided.
Valid filters:
id=container ID or name
label=label name
or
label=label name=value
name=container name
network=network name or ID
status=container status
volume=volume name or mount point
pod=pod name or ID
--external
Only display containers that were created by tools other than Podman.
--format Go-template
Format output using Go template.
-l, --last
Show the latest created container (includes all states).
--latest
Show the latest created container as well as all running containers.
--ns
LabelnEntering the namespaces of the container. Deprecated: Use --format with Go template. For example: podman ps --format "{{.PID}} {{.Pod}} {{.Namespaces.Pid}} {{.Namespaces.Cgroup}}"
--pod-id-only
Display only the Pod IDs for containers running in a pod.
-s, --size
Display the total size of all images used by each container.
--sort string
Sort output by a specific field of the output.
created
id
image
names
status
pod.name
pod.id
--pod
List containers along with their pod information. If the container is not part of a pod, the Pod Name and Pod ID fields will be empty.
