NOM

podman-volume-reload - Recharge tous les volumes depuis les plugins de volumes

SYNTAXE

podman volume reload

DESCRIPTION

podman volume reload vérifie tous les plugins de volumes configurés et met à jour la base de données libpod avec tous les volumes disponibles. Les volumes existants sont également supprimés de la base de données lorsqu'ils ne sont plus présents dans le plugin.

Cette commande est fournie à titre indicatif et ne peut garantir un état parfait, car les plugins peuvent être modifiés de l'extérieur à tout moment.

Remarque : cette commande n'est pas prise en charge avec podman-remote.

EXEMPLES

Recharger les plugins de volumes.

$ podman volume reload
Ajoutés :
vol6
Supprimés :
t3

VOIR AUSSI

podman(1), podman-volume(1)
