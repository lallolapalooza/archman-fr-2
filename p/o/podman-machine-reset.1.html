NOM

podman-machine-reset - Réinitialiser les machines et l'environnement Podman

SYNOPSIS

podman machine reset [options]

DESCRIPTION

Réinitialise l'environnement de votre machine Podman. Cette commande arrête toutes les machines en cours d'exécution, puis les supprime. Les fichiers de configuration et de données sont ensuite supprimés. Les fichiers de données incluent les images disque de la machine et toutes les images de cache précédemment téléchargées. Lorsque cette commande est exécutée, toutes vos machines Podman auront été supprimées.

OPTIONS

--force, -f

Réinitialise sans confirmation.

--help

Affiche l'énoncé d'utilisation.

EXEMPLES

$ podman machine reset
Attention : cette commande supprimera toutes les machines podman existantes
ainsi que tous les répertoires de configuration et de données pour les machines podman
Les machines suivantes seront supprimées :
dev
podman-machine-default
Voulez-vous vraiment continuer ? [O/n] o
$

Réinitialise de force sans confirmation.

$ podman machine reset --force
$
