PO4A-TRANSLATE.1P(1) Documentation Perl fournie par l'utilisateur PO4A-TRANSLATE.1P(1)

NOM

po4a-translate - convertir un fichier PO dans un format de documentation

SYNOPSIS

po4a-translate -f fmt -m master.doc -p XX.po -l XX.doc

(XX.doc est la sortie, tous les autres sont des entrées)

DESCRIPTION

L'objectif du projet po4a (PO pour n'importe quoi) est de faciliter les traductions (et plus intéressant encore, la maintenance des traductions) en utilisant les outils gettext dans des domaines où ils n'étaient pas attendus, comme la documentation.

Le script po4a-translate est chargé de reconvertir la traduction (qui a été faite dans un fichier PO) dans le format de documentation. Le fichier PO fourni doit être la traduction du fichier POT qui a été produit par po4a-gettextize(1).

OPTIONS

-f, --format
Format de la documentation que vous souhaitez gérer. Utilisez l'option --help-format pour voir la liste des formats disponibles.
-a, --addendum
Ajouter un fichier au fichier résultant (pour y mettre le nom du traducteur ou une section "À propos de cette traduction", par exemple). La première ligne du fichier à insérer doit être un en-tête PO4A indiquant où elle doit être ajoutée (voir la section COMMENT ajouter du texte supplémentaire aux traductions dans po4a(7)).
-A, --addendum-charset
Jeu de caractères des addenda. Notez que tous les addenda doivent être dans le même jeu de caractères.
-m, --master
Fichier contenant le document maître à traduire.
-M, --master-charset
Jeu de caractères du fichier contenant le document à traduire.
-l, --localized
Fichier où le document localisé (traduit) doit être écrit.
-L, --localized-charset
Jeu de caractères du fichier contenant le document localisé.
-p, --po
Fichier à partir duquel le catalogue de messages doit être lu.
-o, --option
Option(s) supplémentaire(s) à passer au plugin de format. Voir la documentation de chaque plugin pour plus d'informations sur les options valides et leur signification. Par exemple, vous pourriez passer '-o tablecells' à l'analyseur AsciiDoc, tandis que l'analyseur de texte accepterait '-o tabs=split'.
-k, --keep
Seuil minimal de pourcentage de traduction pour conserver (c'est-à-dire écrire) le fichier résultant (par défaut: 80). Autrement dit, par défaut, les fichiers doivent être traduits à au moins 80% pour être écrits.
-w, --width
Colonne à laquelle le fichier résultant doit être mis en forme s'il est pris en charge par le format (par défaut: 76). Si la valeur fournie est 0 ou négative, alors le fichier résultant ne sera pas mis en forme du tout. Ceci est utile avec certains formats qui pourraient se casser lors de la remise en forme.
-h, --help
Afficher un court message d'aide.
--help-format
Lister les formats de documentation compris par po4a.
-V, --version
Afficher la version du script et quitter.
-v, --verbose
Augmenter la verbosité du programme.
-d, --debug
Afficher des informations de débogage.

Ajouter du contenu (outre les traductions) aux fichiers générés

Pour ajouter du contenu supplémentaire au document généré, en plus de ce que vous avez traduit (comme le nom du traducteur, ou une section "À propos de cette traduction"), vous devez utiliser l'option --addendum.

La première ligne de l'addendum doit être un en-tête indiquant où le placer dans le document (il peut être avant ou après une partie donnée du document). Le reste du fichier sera ajouté tel quel au fichier résultant, sans traitement supplémentaire.

Notez que si po4a-translate échoue à ajouter l'un des fichiers spécifiés, il rejette toute la traduction (car le fichier manquant pourrait être celui qui indique l'auteur, ce qui empêcherait les utilisateurs de le contacter pour signaler des bugs dans la traduction).

L'en-tête a une syntaxe assez rigide. Pour plus d'informations sur la façon d'utiliser cette fonctionnalité et son fonctionnement, veuillez vous reporter à la page de manuel po4a(7).

po4a-translate(1p) — po4a — page d'aide

SYNTAXE

po4a-translate [OPTIONS] --format FORMAT [--previous-version PREVIOUS_VERSION] --po-file PO_FILE [--output-dir OUTPUT_DIR] --source-file SOURCE_FILE

DESCRIPTION

L'outil po4a-translate est une coquille pourpo4a. Il est utilisé pour traduire la documentation à l'aide de fichiers PO (gettext).

Il prend en charge de nombreux formats de documentation, notamment :

  • man (pages de manuel)
  • texinfo
  • po (fichiers PO gettext)
  • iso2xml
  • xhtml
  • docbook
  • mdoc
  • readme

L'outil lit le fichier source de documentation, l'associe au fichier PO et génère un fichier de sortie traduit.

OPTIONS

--format FORMAT
Spécifie le format du fichier de documentation source. Les formats pris en charge incluent man, texinfo, po, iso2xml, xhtml, docbook, mdoc, readme.
--previous-version PREVIOUS_VERSION
Spécifie la version précédente du fichier source. Ceci est utilisé pour créer des fichiers diff si nécessaire.
--po-file PO_FILE
Chemin d'accès au fichier PO (gettext) contenant les traductions.
--output-dir OUTPUT_DIR
Répertoire où les fichiers de sortie traduits seront placés.
--source-file SOURCE_FILE
Chemin d'accès au fichier de documentation source original.
-h, --help
Affiche un message d'aide et quitte.
-v, --version
Affiche les informations de version et quitte.

EXEMPLE

Pour traduire une page de manuel en français à l'aide d'un fichier PO :

po4a-translate --format man --po-file fr.po --output-dir . --source-file man.1

LA DOCUMENTATION ORIGINALE

Pour plus d'informations, veuillez consulter la documentation originale de po4a disponible dans le paquet po4a-doc ou sur le site web du projet po4a.

ASTUCES

Utilisez l'outil po2xml pour convertir les fichiers DocBook en fichiers PO.
