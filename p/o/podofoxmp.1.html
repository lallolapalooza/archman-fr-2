NOM

podofoxmp - Modifier ou extraire les informations XMP d'un fichier PDF

SYNTAXE

podofoxmp [fichier_entree] [fichier_xmp fichier_sortie]

DESCRIPTION

podofoxmp est l'un des outils en ligne de commande de la bibliothèque PoDoFo qui fournit plusieurs opérations utiles pour travailler avec des fichiers PDF. Il peut extraire ou modifier les informations XMP dans un fichier PDF.

OPTIONS

[fichier_entree]

Fichier PDF d'entrée. C'est la seule option nécessaire pour extraire les informations XMP d'un fichier PDF.

[fichier_xmp]

Fichier optionnel fournissant la structure XMP du PDF. Il doit être utilisé conjointement avec un [fichier_sortie].

[fichier_sortie]

Fichier PDF de sortie. Il est uniquement utilisé en conjonction avec un [fichier_xmp].
