NOM

pokefmt - Le système de templating poke

SYNTAXE

pokefmt [OPTION]... [CODE-POKE]...

DESCRIPTION

Système de template pour traiter le code intégré dans les fichiers.

-h, --help
affiche un message d'aide et quitte
-v, --version
affiche la version et quitte
