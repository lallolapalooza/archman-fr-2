NOM

podman-container-cleanup - Nettoie les points de montage et les réseaux des conteneurs

SYNTAXE

podman container cleanup [options] conteneur [conteneur ...]

DESCRIPTION

podman container cleanup nettoie les conteneurs arrêtés en supprimant tous les points de montage et les configurations réseau de l'hôte. Le nom ou l'ID du conteneur peut être utilisé. La commande de nettoyage ne supprime pas les conteneurs. Les conteneurs en cours d'exécution ne sont pas nettoyés.
Parfois, les points de montage et les piles réseau des conteneurs peuvent rester si la commande podman a été interrompue ou si le conteneur s'exécutait en mode démon. Cette commande est automatiquement exécutée lorsque les conteneurs sont exécutés en mode démon par le processus conmon lorsque le conteneur s'arrête.

OPTIONS

--all, -a

Nettoie tous les conteneurs.
La valeur par défaut est false.
IMPORTANT : CETTE OPTION ne nécessite pas de nom ou d'ID de conteneur comme argument d'entrée.

--exec=session

Nettoie une session d'exécution pour un seul conteneur. Elle ne peut être spécifiée que si un seul conteneur est nettoyé (conflit donc avec --all). Si --rm n'est pas spécifié, les fichiers temporaires de la session d'exécution sont nettoyés ; si --rm est spécifié, la session d'exécution est supprimée du conteneur.
*IMPORTANT : Conflit avec --rmi car le conteneur n'est pas nettoyé, l'image ne peut donc pas être supprimée.*

--latest, -l

Au lieu de fournir l'ID ou le nom du conteneur, utilise le dernier conteneur créé. La valeur par défaut est false. IMPORTANT : CETTE OPTION n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (à l'exclusion de WSL2). CETTE OPTION ne nécessite pas de nom ou d'ID de conteneur comme argument d'entrée.

--rm

Après le nettoyage, supprime complètement le conteneur.
La valeur par défaut est false.

--rmi

Après le nettoyage, supprime complètement l'image.
La valeur par défaut est false.

EXEMPLES

Nettoyer le conteneur « mywebserver ».

$ podman container cleanup mywebserver

Nettoyer les conteneurs nommés « mywebserver », « myflaskserver », « 860a4b23 ».

$ podman container cleanup mywebserver myflaskserver 860a4b23
