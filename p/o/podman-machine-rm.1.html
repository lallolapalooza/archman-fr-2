NOM

podman-machine-rm - Supprimer une machine virtuelle

SYNTAXE

podman machine rm [options] [nom]

DESCRIPTION

Supprime une machine virtuelle et ses fichiers associés. Ce qui est effectivement supprimé dépend du type de machine virtuelle. Pour toutes les machines virtuelles, les connexions système podman générées sont supprimées. Les fichiers ignition générés pour cette VM sont également supprimés, de même que son fichier image sur le système de fichiers.

Les utilisateurs reçoivent un affichage de ce qui sera supprimé et devront confirmer, sauf si l'option --force est utilisée.

Le nom de machine par défaut est podman-machine-default. Si aucun nom de machine n'est spécifié en argument, alors podman-machine-default sera supprimé.

Uniquement sans root.

OPTIONS

--force, -f

Arrête et supprime sans confirmation.

--help

Affiche l'énoncé d'utilisation.

--save-ignition

Ne supprime pas le fichier ignition généré.

--save-image

Ne supprime pas l'image de la VM.

EXEMPLES

Supprime la machine Podman spécifiée.

$ podman machine rm test1
Les fichiers suivants seront supprimés :
/home/user/.config/containers/podman/machine/qemu/test1.ign
/home/user/.local/share/containers/podman/machine/qemu/test1_fedora-coreos-33.20210315.1.0-qemu.x86_64.qcow2
/home/user/.config/containers/podman/machine/qemu/test1.json
Voulez-vous continuer ? [y/N] y

Supprime la machine Podman spécifiée même si elle est en cours d'exécution.

$ podman machine rm -f test1
$
