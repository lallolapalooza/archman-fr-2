NOM

podman-rename - Renommer un conteneur existant

SYNTAXE

podman rename conteneur nouveaunom

podman container rename conteneur nouveaunom

DESCRIPTION

Rename change le nom d'un conteneur existant. L'ancien nom est libéré et devient disponible. Cette commande peut être exécutée sur des conteneurs dans n'importe quel état. Cependant, les conteneurs en cours d'exécution peuvent ne pas bénéficier pleinement des effets jusqu'à leur redémarrage - par exemple, un conteneur en cours d'exécution peut toujours utiliser l'ancien nom dans ses journaux. À l'heure actuelle, seuls les conteneurs sont pris en charge ; les pods et les volumes ne peuvent pas être renommés.

OPTIONS

EXEMPLES

Renommer un conteneur avec un nom donné.

$ podman rename ancienConteneur nouveauNom

Renommer un conteneur avec un identifiant donné.

$ podman rename 717716c00a6b conteneurTest

Créer un alias pour un conteneur avec un identifiant donné.

$ podman container rename 6e7514b47180 ctrBaseDeDonnees
