NOM

podman-compose - Exécute des charges de travail Compose via un fournisseur compose externe

SYNTAXE

podman compose [options] [commande [arg ...]]

DESCRIPTION

podman compose est un wrapper léger autour d'un fournisseur compose externe tel que docker-compose ou podman-compose. Cela signifie que podman compose exécute un autre outil qui implémente la fonctionnalité compose, mais configure l'environnement de manière à ce que le fournisseur compose communique de manière transparente avec le socket Podman local. Les options spécifiées ainsi que la commande et les arguments sont directement transmis au fournisseur compose.

Les fournisseurs compose par défaut sont docker-compose et podman-compose. S'ils sont installés, docker-compose a la priorité car il s'agit de l'implémentation originale de la spécification Compose et il est largement utilisé sur les plateformes prises en charge (c'est-à-dire Linux, Mac OS, Windows).

Si vous souhaitez modifier le comportement par défaut ou disposer d'un chemin d'installation personnalisé pour votre fournisseur de choix, veuillez modifier le champ compose_providers dans containers.conf(5) pour compose_providers = ["/chemin/vers/fournisseur"]. Vous pouvez également définir la variable d'environnement PODMAN_COMPOSE_PROVIDER.

Par défaut, podman compose émettra un avertissement indiquant qu'il exécute une commande externe. Cet avertissement peut être désactivé en définissant compose_warning_logs sur false dans containers.conf(5) ou en définissant la variable d'environnement PODMAN_COMPOSE_WARNING_LOGS sur false. Consultez la page de manuel de containers.conf(5) pour plus d'informations.

OPTIONS

Pour voir les options prises en charge par le fournisseur compose installé, veuillez exécuter podman compose --help.

VOIR AUSSI

podman(1), containers.conf(5)
