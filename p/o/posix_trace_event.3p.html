POSIX_TRACE_EVENT(3P) Manuel du programmeur POSIX POSIX_TRACE_EVENT(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_trace_event, posix_trace_eventid_open — fonctions de traçage pour l'instrumentation du code applicatif (TRACING)

SYNTAXE

#include <sys/types.h>
#include <trace.h>
void posix_trace_event(trace_event_id_t event_id,
    const void *restrict data_ptr, size_t data_len);
int posix_trace_eventid_open(const char *restrict event_name,
    trace_event_id_t *restrict event_id);

DESCRIPTION

La fonction posix_trace_event() enregistre l'event_id et les données utilisateur pointées par data_ptr dans le flux de traçage dans lequel le processus appelant est tracé et où l'event_id n'est pas filtré. Si la taille totale des données d'événement de traçage utilisateur représentée par data_len n'est pas supérieure à la taille maximale déclarée pour les données d'événement de traçage utilisateur, alors l'attribut truncation-status de l'événement de traçage enregistré est POSIX_TRACE_NOT_TRUNCATED. Sinon, les données de l'événement de traçage utilisateur sont tronquées à cette taille maximale déclarée et l'attribut truncation-status de l'événement de traçage enregistré est POSIX_TRACE_TRUNCATED_RECORD.

S'il n'y a pas de flux de traçage créé pour le processus, si le flux de traçage créé n'est pas en cours d'exécution, ou si l'événement de traçage spécifié par event_id est filtré dans le flux de traçage, la fonction posix_trace_event() n'aura aucun effet.

La fonction posix_trace_eventid_open() associe un nom d'événement de traçage utilisateur à un identifiant de type d'événement de traçage pour le processus appelant. Le nom de l'événement de traçage est la chaîne pointée par l'argument event_name. Il a une longueur maximale de {TRACE_EVENT_NAME_MAX} caractères (qui a une valeur minimale de {_POSIX_TRACE_EVENT_NAME_MAX}). Le nombre d'identifiants de type d'événement de traçage utilisateur pouvant être définis pour un processus donné est limité par la valeur maximale {TRACE_USER_EVENT_MAX}, qui a une valeur minimale de {POSIX_TRACE_USER_EVENT_MAX}.

Si l'option Héritage de Traçage n'est pas prise en charge, la fonction posix_trace_eventid_open() associe le nom d'événement de traçage utilisateur pointé par l'argument event_name à un identifiant de type d'événement de traçage qui est unique pour le processus tracé, et est retourné dans la variable pointée par l'argument event_id. Si le nom d'événement de traçage utilisateur a déjà été mappé pour le processus tracé, alors l'identifiant de type d'événement de traçage précédemment assigné sera retourné. Si la limite de noms d'événements de traçage utilisateur par processus représentée par {TRACE_USER_EVENT_MAX} a été atteinte, l'événement de traçage utilisateur prédéfini POSIX_TRACE_UNNAMED_USEREVENT (voir Table 2-7, Option de Traçage : Événement de Traçage Utilisateur) sera retourné.

Si l'option Héritage de Traçage est prise en charge, la fonction posix_trace_eventid_open() associe le nom d'événement de traçage utilisateur pointé par l'argument event_name à un identifiant de type d'événement de traçage qui est unique pour tous les processus tracés dans le même flux de traçage, et est retourné dans la variable pointée par l'argument event_id. Si le nom d'événement de traçage utilisateur a déjà été mappé pour les processus tracés, alors l'identifiant de type d'événement de traçage précédemment assigné sera retourné. Si la limite de noms d'événements de traçage utilisateur par processus représentée par {TRACE_USER_EVENT_MAX} a été atteinte, l'événement de traçage utilisateur prédéfini POSIX_TRACE_UNNAMED_USEREVENT (Table 2-7, Option de Traçage : Événement de Traçage Utilisateur) sera retourné.

Note :
La procédure ci-dessus, ainsi que le fait que plusieurs processus ne puissent être tracés dans le même flux de traçage que par héritage, garantissent que tous les processus tracés dans un flux de traçage ont le même mappage des noms d'événements de traçage aux identifiants de types d'événements de traçage.

S'il n'y a pas de flux de traçage créé, la fonction posix_trace_eventid_open() stockera ces informations pour les futurs flux de traçage créés pour ce processus.

VALEUR DE RETOUR

Aucune valeur de retour n'est définie pour la fonction posix_trace_event().

En cas de succès, la fonction posix_trace_eventid_open() retourne une valeur de zéro. Sinon, elle retourne le numéro d'erreur correspondant. La fonction posix_trace_eventid_open() stocke la valeur de l'identifiant du type d'événement de traçage dans l'objet pointé par event_id, en cas de succès.

ERREURS

La fonction posix_trace_eventid_open() échouera si :

ENAMETOOLONG

La taille du nom pointé par l'argument event_name était plus longue que la valeur définie par l'implémentation {TRACE_EVENT_NAME_MAX}.
