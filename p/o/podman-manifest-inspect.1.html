NOM

podman-manifest-inspect - Affiche une liste de manifestes ou un index d'images

SYNOPIS

podman manifest inspect [options] nomdelalisteouindex

DESCRIPTION

Affiche la liste de manifestes ou l'index d'images stocké en utilisant le nom d'image spécifié.

VALEUR DE RETOUR

Une représentation JSON formatée de la liste de manifestes ou de l'index d'images.

OPTIONS

--authfile=chemin

Chemin du fichier d'authentification. Par défaut : ${XDG_RUNTIME_DIR}/containers/auth.json sous Linux, et $HOME/.config/containers/auth.json sous Windows/macOS. Le fichier est créé par podman login. Si l'état d'autorisation n'y est pas trouvé, $HOME/.docker/config.json est vérifié, ce qui est défini à l'aide de docker login.

Remarque : Il existe également une option pour remplacer le chemin par défaut du fichier d'authentification en définissant la variable d'environnement REGISTRY_AUTH_FILE. Cela peut être fait avec export REGISTRY_AUTH_FILE=chemin.

--tls-verify

Exiger HTTPS et vérifier les certificats lors du contact avec les registres (par défaut : true). S'il est explicitement défini sur true, la vérification TLS est utilisée. S'il est défini sur false, la vérification TLS n'est pas utilisée. S'il n'est pas spécifié, la vérification TLS est utilisée à moins que le registre cible ne soit listé comme un registre non sécurisé dans containers-registries.conf(5)

EXEMPLES

Inspectez le manifeste de mylist:v1.11.

podman manifest inspect mylist:v1.11

VOIR AUSSI

podman(1), podman-manifest(1)
