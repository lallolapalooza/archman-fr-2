NOM

podman-pod-unpause - Réactiver un ou plusieurs pods

SYNTAXE

podman pod unpause [options] pod ...

DESCRIPTION

Réactive tous les processus suspendus dans les conteneurs d'un ou plusieurs pods. Vous pouvez utiliser les identifiants ou les noms des pods en entrée.

OPTIONS

--all, -a

Réactiver tous les pods.

--latest, -l

Au lieu de fournir le nom ou l'ID du pod, réactiver le dernier pod créé. (Cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (hors WSL2)).

EXEMPLE

Réactiver un pod avec un nom donné :

podman pod unpause monpodwebserver

Réactiver un pod avec un ID donné :

podman pod unpause 860a4b23
