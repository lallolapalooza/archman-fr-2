NOM

podman-logs - Afficher les journaux d'un ou plusieurs conteneurs

SYNTAXE

podman logs [options] conteneur [conteneur...]

podman container logs [options] conteneur [conteneur...]

DESCRIPTION

La commande podman logs récupère par lots les journaux présents pour un ou plusieurs conteneurs au moment de l'exécution. Cela ne garantit pas l'ordre d'exécution lorsqu'elle est combinée avec podman run (c'est-à-dire que le run peut ne pas avoir généré de journaux au moment où podman logs a été exécutée).

OPTIONS

--color

Sortir les conteneurs avec différentes couleurs dans le journal.

--follow, -f

Suivre la sortie du journal. Par défaut : false.

Note : Lorsque vous suivez un conteneur qui est supprimé par podman container rm ou supprimé à la sortie (podman run --rm ...), il y a une chance que le fichier journal soit supprimé avant que podman logs ne lise le contenu final.

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utiliser le dernier conteneur créé. Note : le dernier conteneur démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (à l'exclusion de WSL2)).

--names, -n

Sortir les noms des conteneurs au lieu de leurs ID dans le journal.

--since=TIMESTAMP

Afficher les journaux depuis TIMESTAMP. L'option --since peut être des horodatages Unix, des horodatages formatés en date, ou des chaînes de durée Go (par exemple, 10m, 1h30m) calculées par rapport à l'heure de la machine cliente. Les formats pris en charge pour les horodatages formatés en date incluent RFC3339Nano, RFC3339, 2006-01-02T15:04:05, 2006-01-02T15:04:05.999999999, 2006-01-02Z07:00, et 2006-01-02.

--tail=LIGNES

Afficher le nombre spécifié de LIGNES à la fin des journaux. LIGNES doit être un entier. La valeur par défaut est -1, ce qui imprime toutes les lignes.

--timestamps, -t

Afficher les horodatages dans les sorties de journal. Par défaut : false.

--until=TIMESTAMP

Afficher les journaux jusqu'à TIMESTAMP. L'option --until peut être des horodatages Unix, des horodatages formatés en date, ou des chaînes de durée Go (par exemple, 10m, 1h30m) calculées par rapport à l'heure de la machine cliente. Les formats pris en charge pour les horodatages formatés en date incluent RFC3339Nano, RFC3339, 2006-01-02T15:04:05, 2006-01-02T15:04:05.999999999, 2006-01-02Z07:00, et 2006-01-02.

NAME

podman-container-logs - Display log output from a container

SYNOPSIS

podman container logs [options] container

DESCRIPTION

The podman container logs command retrieves and displays log output from a container.

The command can display logs from a running container or a stopped container.

The logs are typically generated by the application running inside the container and are streamed to standard output or standard error.

OPTIONS

Following are the options that can be used with the podman container logs command:

--details, -d

Show extra details generated by the container runtime. This includes timestamps, image ID, container ID, and container name.

--follow, -f

Follow log output. This option streams the log output in real-time as new log entries are generated.

--since <timestamp>

Only return logs since a specified timestamp. The timestamp can be in RFC3339 format (e.g., 2023-10-27T10:00:00Z) or a relative duration (e.g., 1h for one hour ago).

--tail <number>

Number of lines to show from the end of the logs. Defaults to all lines.

--until <timestamp>

Only return logs before a specified timestamp. The timestamp can be in RFC3339 format (e.g., 2023-10-27T10:00:00Z) or a relative duration (e.g., 1h for one hour ago).

EXAMPLES

Display all logs from a container named "mycontainer":

podman container logs mycontainer

Follow log output from a container named "mycontainer" in real-time:

podman container logs -f mycontainer

Display the last 10 lines of logs from a container named "mycontainer":

podman container logs --tail 10 mycontainer

Display logs from a container named "mycontainer" since 1 hour ago:

podman container logs --since 1h mycontainer

Display logs from a container named "mycontainer" until 2023-10-27T10:00:00Z:

podman container logs --until 2023-10-27T10:00:00Z mycontainer

Display logs with extra details:

podman container logs -d mycontainer

NOM

podman-container-logs - Afficher la sortie des journaux d'un conteneur

SYNTAXE

podman container logs [options] conteneur

DESCRIPTION

La commande podman container logs récupère et affiche la sortie des journaux d'un conteneur.

La commande peut afficher les journaux d'un conteneur en cours d'exécution ou d'un conteneur arrêté.

Les journaux sont généralement générés par l'application exécutée à l'intérieur du conteneur et sont transmis à la sortie standard ou à l'erreur standard.

OPTIONS

Voici les options qui peuvent être utilisées avec la commande podman container logs :

--details, -d

Afficher les détails supplémentaires générés par le runtime du conteneur. Cela inclut les horodatages, l'identifiant de l'image, l'identifiant du conteneur et le nom du conteneur.

--follow, -f

Suivre la sortie des journaux. Cette option diffuse la sortie des journaux en temps réel à mesure que de nouvelles entrées de journaux sont générées.

--since <horodatage>

Ne retourner que les journaux depuis un horodatage spécifié. L'horodatage peut être au format RFC3339 (par exemple, 2023-10-27T10:00:00Z) ou une durée relative (par exemple, 1h pour il y a une heure).

--tail <nombre>

Nombre de lignes à afficher depuis la fin des journaux. La valeur par défaut est toutes les lignes.

--until <horodatage>

Ne retourner que les journaux avant un horodatage spécifié. L'horodatage peut être au format RFC3339 (par exemple, 2023-10-27T10:00:00Z) ou une durée relative (par exemple, 1h pour il y a une heure).

EXEMPLES

Afficher tous les journaux d'un conteneur nommé "mycontainer" :

podman container logs mycontainer

Suivre la sortie des journaux d'un conteneur nommé "mycontainer" en temps réel :

podman container logs -f mycontainer

Afficher les 10 dernières lignes de journaux d'un conteneur nommé "mycontainer" :

podman container logs --tail 10 mycontainer

Afficher les journaux d'un conteneur nommé "mycontainer" depuis il y a 1 heure :

podman container logs --since 1h mycontainer

Afficher les journaux d'un conteneur nommé "mycontainer" jusqu'au 2023-10-27T10:00:00Z :

podman container logs --until 2023-10-27T10:00:00Z mycontainer

Afficher les journaux avec des détails supplémentaires :

podman container logs -d mycontainer
