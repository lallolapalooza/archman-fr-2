POSIX_TRACE_EVENTID_EQUAL(3P) Manuel du programmeur POSIX POSIX_TRACE_EVENTID_EQUAL(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_trace_eventid_equal, posix_trace_eventid_get_name, posix_trace_trid_eventid_open — manipulation de l'identifiant de type d'événement de trace (TRACING)

SYNTAXE

#include <trace.h>
int posix_trace_eventid_equal(trace_id_t trid, trace_event_id_t event1,
    trace_event_id_t event2);
int posix_trace_eventid_get_name(trace_id_t trid,
    trace_event_id_t event, char *event_name);
int posix_trace_trid_eventid_open(trace_id_t trid,
    const char *restrict event_name,
    trace_event_id_t *restrict event);

DESCRIPTION

La fonction posix_trace_eventid_equal() compare les identifiants de type d'événement de trace event1 et event2 du même flux de trace ou du même journal de trace identifié par l'argument trid. Si les identifiants de type d'événement de trace event1 et event2 proviennent de flux de trace différents, la valeur de retour sera non spécifiée.

La fonction posix_trace_eventid_get_name() renvoie, dans l'argument pointé par event_name, le nom de l'événement de trace associé à l'identifiant de type d'événement de trace identifié par l'argument event, pour le flux de trace ou pour le journal de trace identifié par l'argument trid. Le nom de l'événement de trace aura un maximum de {TRACE_EVENT_NAME_MAX} caractères (qui a la valeur minimale {_POSIX_TRACE_EVENT_NAME_MAX}). Des appels successifs à cette fonction avec le même identifiant de type d'événement de trace et le même identifiant de flux de trace renverront le même nom d'événement.

La fonction posix_trace_trid_eventid_open() associe un nom d'événement de trace utilisateur à un identifiant de type d'événement de trace pour un flux de trace donné. Le flux de trace est identifié par l'argument trid, et il doit s'agir d'un flux de trace actif. Le nom de l'événement de trace est la chaîne pointée par l'argument event_name. Il aura un maximum de {TRACE_EVENT_NAME_MAX} caractères (qui a la valeur minimale {_POSIX_TRACE_EVENT_NAME_MAX}). Le nombre d'identifiants de type d'événement de trace utilisateur qui peuvent être définis pour un processus donné est limité par la valeur maximale {TRACE_USER_EVENT_MAX}, qui a la valeur minimale {_POSIX_TRACE_USER_EVENT_MAX}.

Si l'option d'héritage de trace n'est pas prise en charge, la fonction posix_trace_trid_eventid_open() associe le nom d'événement de trace utilisateur pointé par l'argument event_name à un identifiant de type d'événement de trace qui est unique pour le processus tracé dans le flux de trace identifié par l'argument trid, et le renvoie dans la variable pointée par l'argument event. Si le nom d'événement de trace utilisateur a déjà été mappé pour le processus tracé, l'identifiant de type d'événement de trace précédemment attribué sera renvoyé. Si la limite d'événements de trace utilisateur par processus représentée par {TRACE_USER_EVENT_MAX} est atteinte, l'événement de trace utilisateur prédéfini POSIX_TRACE_UNNAMED_USEREVENT (voir Table 2-7, Option de trace : Événement de trace utilisateur) sera renvoyé.

Si l'option d'héritage de trace est prise en charge, la fonction posix_trace_trid_eventid_open() associe le nom d'événement de trace utilisateur pointé par l'argument event_name à un identifiant de type d'événement de trace qui est unique pour tous les processus tracés dans le flux de trace identifié par l'argument trid, et le renvoie dans la variable pointée par l'argument event. Si le nom d'événement de trace utilisateur a déjà été mappé pour les processus tracés, l'identifiant de type d'événement de trace précédemment attribué sera renvoyé. Si la limite d'événements de trace utilisateur par processus représentée par {TRACE_USER_EVENT_MAX} est atteinte, l'événement de trace utilisateur prédéfini POSIX_TRACE_UNNAMED_USEREVENT (voir Table 2-7, Option de trace : Événement de trace utilisateur) sera renvoyé.

VALEUR RENVOYÉE

En cas de succès, les fonctions posix_trace_eventid_get_name() et posix_trace_trid_eventid_open() renvoient la valeur zéro. Sinon, elles renvoient le numéro d'erreur correspondant.

La fonction posix_trace_eventid_equal() renvoie une valeur non nulle si event1 et event2 sont égaux ; sinon, une valeur de zéro est renvoyée. Aucune erreur n'est définie. Si l'un des event1 ou event2 ne sont pas des identifiants de type d'événement de trace valides pour le flux de trace spécifié par trid ou si le trid est invalide, le comportement sera non spécifié.

La fonction posix_trace_eventid_get_name() stocke la valeur du nom de l'événement de trace dans l'objet pointé par event_name, en cas de succès.

La fonction posix_trace_trid_eventid_open() stocke la valeur de l'identifiant de type d'événement de trace dans l'objet pointé par event, en cas de succès.

ERREURS

Les fonctions posix_trace_eventid_get_name() et posix_trace_trid_eventid_open() échouent si :

EINVAL
L'argument trid n'était pas un identifiant de flux de trace valide.

La fonction posix_trace_trid_eventid_open() échoue si :

ENAMETOOLONG

La taille du nom pointé par l'argument event_name était supérieure à la valeur définie par l'implémentation {TRACE_EVENT_NAME_MAX}.

La fonction posix_trace_eventid_get_name() échoue si :

EINVAL
L'identifiant de type d'événement de trace event n'était associé à aucun nom.

NOM

posix_trace_eventid_equal — comparer l'égalité de deux identifiants d'événements de trace POSIX

SYNTAXE

#include <trace-events.h>

int posix_trace_eventid_equal(posix_trace_eventid_t id1, posix_trace_eventid_t id2);

DESCRIPTION

La fonction posix_trace_eventid_equal compare deux identifiants d'événements de trace POSIX, id1 et id2. Elle renvoie un entier non nul si les deux identifiants sont égaux, et zéro s'ils sont différents.

VALEUR DE RETOUR

Un entier non nul si id1 est égal à id2, zéro dans le cas contraire.

ERREURS

Aucune erreur n'est définie pour cette fonction.

EXEMPLES

Aucun exemple fourni.

UTILISATION DE L'APPLICATION

Cette fonction est utilisée dans le cadre du traçage d'événements POSIX pour déterminer si deux identifiants d'événements sont identiques.

RAISON D'ÊTRE

Permet une comparaison sémantique des identifiants d'événements de trace.

ORIENTATIONS FUTURES

Aucune orientation future spécifiée.
