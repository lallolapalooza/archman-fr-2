podman-tag(1) Manuel des commandes générales podman-tag(1)

NOM

podman-tag - Ajouter un nom supplémentaire à une image locale

SYNTAXE

podman tag image[:tag] [nom-cible[:tag]...] [options]

podman image tag image[:tag] [nom-cible[:tag]...] [options]

DESCRIPTION

Attribue un nouveau nom d'image à une image existante. Un nom complet fait référence à l'ensemble du nom de l'image, y compris le tag optionnel après le :. S'il n'y a pas de tag fourni, Podman utilise par défaut latest pour l'image et le nom-cible.

OPTIONS

--help, -h

Afficher le message d'utilisation

EXEMPLES

Taguer une image spécifiée avec un nom d'image par défaut :latest.

$ podman tag 0e3bbc2 fedora:latest

Taguer une image spécifiée avec un nom d'image entièrement spécifié.

$ podman tag httpd myregistryhost:5000/fedora/httpd:v2

Taguer une image spécifiée avec plusieurs tags.

$ podman tag mymariadb mycontainerregistry.io/namespace/mariadb:10 mycontainerregistry.io/namespace/mariadb:10.11 mycontainerregistry.io/namespace/mariadb:10.11.12
