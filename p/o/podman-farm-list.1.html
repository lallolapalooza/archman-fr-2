NOM

podman-farm-list - Lister les fermes existantes

SYNTAXE

podman farm list [options]

podman farm ls [options]

DESCRIPTION

Lister toutes les fermes existantes.

OPTIONS

--format=format

Changer le format de sortie par défaut. Il peut s'agir d'un type pris en charge comme 'json' ou d'un modèle Go. Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Placeholder Description
.Connections Liste de toutes les connexions système de la ferme
.Default Indique si la ferme est la ferme par défaut
.Name Nom de la ferme
.ReadWrite Indique si cette ferme peut être modifiée à l'aide des commandes podman farm

EXEMPLE

Lister toutes les fermes :

$ podman farm list
Name        Connections  Default     ReadWrite
farm1       [f38 f37]    false       true
farm2       [f37]        true        true

Afficher les fermes au format JSON :

$ podman farm list --format json
[
  {
    "Name": "farm1",
    "Connections": [
      "f38",
      "f37"
    ],
    "Default": false,
    "ReadWrite": true
  },
  {
    "Name": "farm2",
    "Connections": [
      "f37"
    ],
    "Default": true,
    "ReadWrite": true
  }
]

Afficher uniquement les noms des fermes :

$ podman farm list --format "{{.Name}}"
farm1
farm2

Afficher des informations détaillées sur les fermes :

$ podman farm list --format "Farm: {{.Name}} (Default: {{.Default}}, ReadWrite: {{.ReadWrite}})\nConnections: {{.Connections}}"
Farm: farm1 (Default: false, ReadWrite: true)
Connections: [f38 f37]
Farm: farm2 (Default: true, ReadWrite: true)
Connections: [f37]
