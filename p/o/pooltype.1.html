POOLTYPE(1) Manuel des commandes générales POOLTYPE(1)

NOM

pooltype - afficher un fichier pool WEB

SYNTAXE

pooltype nom_fichier_pool

DESCRIPTION

Ce manuel n'a pas pour but d'être exhaustif. La documentation complète pour cette version de TeX se trouve dans le fichier info ou manuel Web2C : Une implémentation de TeX.

Le programme pooltype traduit un fichier de pool de chaînes Web (orienté programme) en un fichier texte (orienté humain).

Le nom_fichier_pool doit être complet ; aucun ajout d'extensions par défaut ou recherche dans le chemin n'est effectué.

VOIR AUSSI

tangle(1).

AUTEURS

Donald E. Knuth a écrit le programme et l'a initialement porté sous Unix. Il a été publié dans le cadre du rapport technique TeXware, disponible auprès du TeX Users Group.
