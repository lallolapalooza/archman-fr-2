NOM

pom2 - convertir POD en Texte, HTML, etc., avec Pod::POM

SYNTAXE

pom2 text MonFichier.pm > MonFichier.txt
pom2 html MonFichier.pm > MonFichier.html
pom2 pod  MonFichier.pm > MonFichier.pod
pom2 format [options] MonFichier.pm > MonFichier.xyz

DESCRIPTION

Ce script utilise "Pod::POM" pour convertir un document Pod en texte, HTML, le reconvertir en Pod (par exemple pour normaliser un document afin de corriger toute erreur de balisage), ou tout autre format pour lequel vous disposez d'un module de visualisation.

Si le visualiseur n'est pas l'un de ceux inclus avec "Pod::POM", le script recherche un module installé "Pod::POM::View" qui correspond au format spécifié. Par exemple, si vous avez "Pod::POM::View::DocBook" installé, vous pouvez alors dire :

pod2 docbook MonFichier.pm > MonFichier.xml

Si des options autres que "--help" sont spécifiées, elles sont passées à la méthode du constructeur de la classe de visualisation. Par exemple :

pod2 docbook --root=chapter --titlecasing MonFichier.pm > MonFichier.xml

convertira le document Pod en un document DocBook de type chapitre avec l'option de mise en majuscules des titres activée. Notez que toute chaîne précédée de ""--"" est considérée comme une option valide et est passée au constructeur ; si aucune valeur n'est spécifiée, une valeur de 1 est passée.
