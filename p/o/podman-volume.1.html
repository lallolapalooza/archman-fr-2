podman-volume(1) Manuel des commandes générales podman-volume(1)

NOM

podman-volume - Outil de gestion simple des volumes

SYNTAXE

podman volume sous-commande

DESCRIPTION

podman volume est un ensemble de sous-commandes qui gèrent les volumes.

SOUS-COMMANDES

Commande Page de manuel Description
create podman-volume-create(1) Crée un nouveau volume.
exists podman-volume-exists(1) Vérifie si le volume donné existe.
export podman-volume-export(1) Exporte le volume vers un fichier tar externe.
import podman-volume-import(1) Importe le contenu d'une archive tar dans un volume podman existant.
inspect podman-volume-inspect(1) Obtient des informations détaillées sur un ou plusieurs volumes.
ls podman-volume-ls(1) Liste tous les volumes disponibles.
mount podman-volume-mount(1) Monte le système de fichiers d'un volume.
prune podman-volume-prune(1) Supprime tous les volumes inutilisés.
reload podman-volume-reload(1) Recharge tous les volumes à partir des plugins de volumes.
rm podman-volume-rm(1) Supprime un ou plusieurs volumes.
unmount podman-volume-unmount(1) Démonte un volume.
