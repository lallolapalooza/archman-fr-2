CPOTRS

Objectif :

!>
!> CPOTRS résout un système d'équations linéaires A*X = B avec une matrice A
!> hermitienne définie positive en utilisant la factorisation de Cholesky
!> A = U**H*U ou A = L*L**H calculée par CPOTRF.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**H*U ou A = L*L**H, tel que calculé par CPOTRF.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

B

!>          B est un tableau COMPLEX, dimension (LDB,NRHS)
!>          En entrée, la matrice membre de droite B.
!>          En sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

NOM


zpotrs — résout un système d'équations linéaires A*X = B avec
    une matrice A hermitienne et définie positive en utilisant la factorisation de
    Cholesky A = UH*U ou A = L*LH calculée par ZPOTRF.






SYNTAXIS


    SUBROUTINE ZPOTRS( UPLO, N, NRHS, A, LDA, B, LDB, INFO )


        CHARACTER *1        UPLO
        INTEGER            N
        INTEGER            NRHS
        COMPLEX*16         A( LDA, * )
        INTEGER            LDA
        COMPLEX*16         B( LDB, * )
        INTEGER            LDB
        INTEGER            INFO






DESCRIPTION


zpotrs résout un système d'équations linéaires A*X = B avec une
    matrice A hermitienne et définie positive en utilisant la factorisation de
    Cholesky A = UH*U ou A = L*LH calculée par ZPOTRF.






Parametres




UPLO


          UPLO est CHARACTER*1
          = 'U' : Le triangle supérieur de A est stocké ;
          = 'L' : Le triangle inférieur de A est stocké.
        


N


          N est INTEGER
          L'ordre de la matrice A. N >= 0.
        


NRHS


          NRHS est INTEGER
          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
          de la matrice B. NRHS >= 0.
        


A


          A est un tableau COMPLEX*16, de dimension (LDA,N)
          Le facteur triangulaire U ou L de la factorisation de Cholesky
          A = U**H * U ou A = L * L**H, tel que calculé par ZPOTRF.
        


LDA


          LDA est INTEGER
          La dimension principale du tableau A. LDA >= max(1,N).
        


B


          B est un tableau COMPLEX*16, de dimension (LDB,NRHS)
          En entrée, la matrice B des membres de droite.
          En sortie, la matrice X de la solution.
        


LDB


          LDB est INTEGER
          La dimension principale du tableau B. LDB >= max(1,N).
        


INFO


          INFO est INTEGER
          = 0 : sortie réussie
          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
