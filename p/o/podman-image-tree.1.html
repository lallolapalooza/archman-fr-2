NOM

podman-image-tree - Affiche la hiérarchie des couches d'une image au format arborescent

SYNTAXE

podman image tree [options] image:tag|id-image

DESCRIPTION

Affiche la hiérarchie des couches d'une image au format arborescent. Si aucun tag n'est fourni, Podman utilise par défaut latest pour l'image. Les couches sont indiquées avec les tags de l'image comme Top Layer of, lorsque le tag est connu localement.

OPTIONS

--help, -h

Affiche le message d'utilisation

--whatrequires

Affiche toutes les images enfants et leurs couches pour l'image spécifiée
