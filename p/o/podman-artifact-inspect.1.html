NOM

podman-artifact-inspect - Examiner un artefact OCI

SYNOPSIS

podman artifact inspect nom

DESCRIPTION

Examine un artefact dans le magasin local et affiche les résultats au format JSON. L'artefact peut être référencé par :

1.
Nom complet de l'artefact
2.
Digest complet ou partiel du manifeste de l'artefact

La sortie de l'inspection inclut le manifeste de l'artefact avec ses annotations. Tous les artefacts incluent automatiquement un horodatage de création dans l'annotation org.opencontainers.image.created au format RFC3339Nano, indiquant quand l'artefact a été créé initialement.

OPTIONS

--format, -f=format

Formate la sortie en utilisant le modèle Go spécifié. Les clés du JSON renvoyé peuvent être utilisées comme valeurs pour l'option --format (voir les exemples ci-dessous).

Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Espace réservé Description
.Artifact ... Détails de l'artefact (structure imbriquée)
.Digest Digest de l'artefact (hash de 64 caractères sha256:+)
.Manifest ... Détails du manifeste de l'artefact (structure)
.Name Nom de l'artefact (chaîne)
.TotalSizeBytes Taille totale de l'artefact en octets

--help, -h

Imprime l'énoncé d'utilisation

EXEMPLES

Examiner une image OCI dans le magasin local.

$ podman artifact inspect quay.io/myartifact/myml:latest
{
     "Manifest": {
          "schemaVersion": 2,
          "mediaType": "application/vnd.oci.image.manifest.v1+json",
          "config": {
               "mediaType": "application/vnd.oci.empty.v1+json",
               "digest": "sha256:44136fa355b3678a1146ad16f7e8649e94fb4fc21fe77e8310c060f61caaff8a",
               "size": 2,
               "data": "e30="
          },
          "layers": [
               {
                    "mediaType": "text/plain; charset=utf-8",
                    "digest": "sha256:f2ca1bb6c7e907d06dafe4687e579fce76b37e4e93b7605022da52e6ccc26fd2",
                    "size": 5,
                    "annotations": {
                         "org.opencontainers.image.title": "foobar.txt"
                    }
               }
          ]
     },
     "Name": "quay.io/myartifact/mytxt:latest",
     "Digest": "sha256:6c28fa07a5b0a1cee29862c1f6ea38a66df982495b14da2c052427eb628ed8c6"
}

Examiner le digest de l'artefact pour l'artefact spécifié :

$ podman artifact inspect quay.io/myartifact/mytxt:latest --format {{.Digest}}
sha256:6c28fa07a5b0a1cee29862c1f6ea38a66df982495b14da2c052427eb628ed8c6
