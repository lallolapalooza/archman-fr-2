POSIX_TRACE_EVENTSET_ADD(3P) Manuel du programmeur POSIX POSIX_TRACE_EVENTSET_ADD(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_trace_eventset_add, posix_trace_eventset_del, posix_trace_eventset_empty, posix_trace_eventset_fill, posix_trace_eventset_ismember — manipulation des ensembles de types d'événements de trace (TRACING)

SYNOPIS

#include <trace.h>
int posix_trace_eventset_add(trace_event_id_t event_id,
    trace_event_set_t *set);
int posix_trace_eventset_del(trace_event_id_t event_id,
    trace_event_set_t *set);
int posix_trace_eventset_empty(trace_event_set_t *set);
int posix_trace_eventset_fill(trace_event_set_t *set, int what);
int posix_trace_eventset_ismember(trace_event_id_t event_id,
    const trace_event_set_t *restrict set, int *restrict ismember);

DESCRIPTION

Ces primitives manipulent des ensembles de types d'événements de trace. Elles opèrent sur des objets de données accessibles par l'application, et non sur le filtre d'événements de trace actuel d'un flux de trace.

Les fonctions posix_trace_eventset_add() et posix_trace_eventset_del() ajoutent ou suppriment respectivement le type d'événement de trace individuel spécifié par la valeur de l'argument event_id, de ou vers l'ensemble de types d'événements de trace pointé par l'argument set. L'ajout d'un type d'événement de trace déjà présent dans l'ensemble ou la suppression d'un type d'événement de trace qui n'y est pas, ne sera pas considéré comme une erreur.

La fonction posix_trace_eventset_empty() initialise l'ensemble de types d'événements de trace pointé par l'argument set de telle sorte que tous les types d'événements de trace définis, tant système qu'utilisateur, soient exclus de l'ensemble.

La fonction posix_trace_eventset_fill() initialise l'ensemble de types d'événements de trace pointé par l'argument set, de telle sorte que l'ensemble de types d'événements de trace définis par l'argument what soit inclus dans l'ensemble. La valeur de l'argument what doit être l'une des valeurs suivantes, telles que définies dans l'en-tête <trace.h> :

POSIX_TRACE_WOPID_EVENTS

Tous les types d'événements de trace système définis par l'implémentation et indépendants du processus sont inclus dans l'ensemble.
POSIX_TRACE_SYSTEM_EVENTS

Tous les types d'événements de trace système définis par l'implémentation sont inclus dans l'ensemble, ainsi que ceux définis dans POSIX.1‐2008.
POSIX_TRACE_ALL_EVENTS

Tous les types d'événements de trace définis, tant système qu'utilisateur, sont inclus dans l'ensemble.

Les applications doivent appeler soit posix_trace_eventset_empty() soit posix_trace_eventset_fill() au moins une fois pour chaque objet de type trace_event_set_t avant toute autre utilisation de cet objet. Si un tel objet n'est pas initialisé de cette manière, mais est néanmoins fourni comme argument à l'une des fonctions posix_trace_eventset_add(), posix_trace_eventset_del() ou posix_trace_eventset_ismember(), les résultats sont indéfinis.

La fonction posix_trace_eventset_ismember() teste si le type d'événement de trace spécifié par la valeur de l'argument event_id est membre de l'ensemble pointé par l'argument set. La valeur retournée dans l'objet pointé par l'argument ismember est zéro si l'identifiant du type d'événement de trace n'est pas membre de l'ensemble et une valeur différente de zéro s'il en est membre.

VALEUR RENVOYÉE

En cas de succès, ces fonctions renvoient une valeur de zéro. Sinon, elles renvoient le numéro d'erreur correspondant.

ERREURS

Ces fonctions peuvent échouer si :

EINVAL
La valeur de l'un des arguments est invalide.

posix_trace_eventset_add(3p)

posix_trace_eventset_add — ajouter un identifiant d'événement à un ensemble d'événements trace

NOM

posix_trace_eventset_add — ajouter un identifiant d'événement à un ensemble d'événements trace

SYNOPIS

#include <trace.h>

int posix_trace_eventset_add(posix_trace_event_set_t *set , trace_event_id_t event_id );

DESCRIPTION

La fonction posix_trace_eventset_add ajoute l'identifiant d'événement spécifié par event_id à l'ensemble d'événements trace spécifié par set.

L'identifiant d'événement event_id doit être l'un des identifiants d'événement définis par la spécification POSIX.1-2001 Trace Event Management. Notez que tous les identifiants d'événement ne sont pas nécessairement pris en charge par toutes les implémentations. La fonction posix_trace_eventid_get_name peut être utilisée pour interroger le support de certains identifiants d'événement.

VALEUR DE RETOUR

En cas de succès, posix_trace_eventset_add renvoie 0. En cas d'erreur, elle renvoie un numéro d'erreur positif.

ERREURS

EINVAL
Le paramètre set n'est pas un pointeur valide vers un ensemble d'événements trace, ou event_id n'est pas un identifiant d'événement valide.
ENOMEM
Il n'y a pas assez de mémoire pour ajouter l'identifiant d'événement à l'ensemble.
ENOSYS
La fonction posix_trace_eventset_add n'est pas prise en charge par le système.

EXEMPLE

L'exemple suivant montre comment créer un ensemble d'événements trace et y ajouter un événement spécifique.


#include <stdio.h>
#include <stdlib.h>
#include <trace.h>

int main() {
    posix_trace_event_set_t event_set;
    trace_event_id_t event_id;
    int ret;

    // Initialiser l'ensemble d'événements trace
    ret = posix_trace_eventid_get_id(NULL, "process_name", &event_id);
    if (ret != 0) {
        perror("posix_trace_eventid_get_id");
        exit(EXIT_FAILURE);
    }

    ret = posix_trace_event_set_init(&event_set);
    if (ret != 0) {
        perror("posix_trace_event_set_init");
        exit(EXIT_FAILURE);
    }

    // Ajouter l'événement à l'ensemble
    ret = posix_trace_eventset_add(&event_set, event_id);
    if (ret != 0) {
        perror("posix_trace_eventset_add");
        exit(EXIT_FAILURE);
    }

    printf("Événement ajouté avec succès à l'ensemble.\n");

    // Nettoyer l'ensemble d'événements trace
    posix_trace_event_set_destroy(&event_set);

    return 0;
}
