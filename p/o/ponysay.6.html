NOM

ponysay - Réimplémentation de Cowsay pour les poneys

SYNTAXE

ponysay [options] [--] [message]
ponythink [options] [--] [message]

DESCRIPTION

ponysay affiche une image d'un poney disant un texte fourni par l'utilisateur dans un terminal. Si message n'est pas fourni, il accepte l'entrée standard, renvoie le message donné en retour à la ligne environ toutes les 60 colonnes, et affiche le poney disant le message donné sur la sortie standard.

Si aucun argument n'est fourni, le programme accepte uniquement l'entrée standard redirigée depuis un autre programme, un fichier, ou soit des "here documents", soit des "here strings" (voir man bash(1) pour plus d'informations sur les "here document"/"here string").

ponythink est à ponysay ce que cowthink est à cowsay.

Pour une documentation complète, exécutez `info ponysay`.

OPTIONS

Un résumé des options est inclus ci-dessous.

-h, --help
Affiche un résumé des options.
-v, --version
Affiche la version du programme.
-f, --file, --pony nom
Sélectionne un poney (soit un nom de fichier, soit un nom de poney). Vous pouvez utiliser cette option plusieurs fois, et l'un d'eux sera sélectionné aléatoirement.
+f, ++file, ++pony nom
Sélectionne un poney en dehors de My Little Pony: Friendship is Magic (soit un nom de fichier, soit un nom de poney). Vous pouvez utiliser ces options plusieurs fois, et l'un d'eux sera sélectionné aléatoirement.
-F, --any-file, --anyfile, --anypony --any-pony nom
Cette option combine -f et +f.
--f, --files, --ponies [nom...]
Variante varaiadique de -f, signifiant que tous les arguments ajoutés après celui-ci seront analysés comme un argument de cette option.
++f, ++files, ++ponies [nom...]
Variante varaiadique de +f, signifiant que tous les arguments ajoutés après celui-ci seront analysés comme un argument de cette option.
--F, --any-files, --anyfiles, --anyponies --any-ponies nom
Cette option combine --f et ++f.
-q, --quote [nom...]
En utilisant cette option, un poney sera imprimé avec des citations d'elle dans My Little Pony: Friendship is Magic. Le poney sera sélectionné aléatoirement, sauf si au moins un poney est ajouté comme argument à -q. Si plusieurs poneys sont ajoutés comme argument à -q, le poney sera sélectionné aléatoirement parmi cet ensemble de poneys.
--q, --quotes [nom...]
Variante varaiadique de -q, signifiant que tous les arguments ajoutés après celui-ci seront analysés comme un argument de cette option. De plus, ces options sont ajoutées à -q.
-b, --bubble, --balloon style
Spécifie le style de bulle à utiliser. Il peut s'agir d'un nom de fichier ou d'un nom de bulle imprimé par ponysay -B.
-W, --wrap colonne
La colonne de l'écran où le message doit être renvoyé à la ligne. La largeur supplémentaire de la bulle est prise en compte. Si l'argument n'est pas un nombre, mais commence par n, aucun retour à la ligne n'est effectué, et s'il commence par i, la largeur du terminal est utilisée.
-c, --compress, --compact [couleur-ANSI]
Compresse le message de la même manière que cowsay, c'est-à-dire essentiellement sans espaces multiples et uniquement avec des séparations de paragraphes.
-l, --list
Liste les fichiers de poneys.
-L, --symlist, --altlist
Liste les fichiers de poneys avec des noms alternatifs entre crochets.
+l, ++list
Liste les fichiers de poneys non-MLP:FiM.
+L, ++symlist, ++altlist
Liste les fichiers de poneys non-MLP:FiM avec des noms alternatifs entre crochets.
-B, --bubblelist, --balloonlist style
Imprime une liste de tous les styles de bulles.
-A, --all
Liste tous les fichiers de poneys, MLP:FiM et non-MLP:FiM. Dans ce cas, la première liste contient les MLP:FiM et la seconde les non-MLP:FiM.
+A, ++all, --symall, --altall
Liste tous les fichiers de poneys, y compris les noms alternatifs entre crochets. Ceux de MLP:FiM et non-MLP:FiM, la première liste étant celle des MLP:FiM et la seconde celle des non-MLP:FiM.
-o, --pony-only, --ponyonly
Imprime uniquement le poney, rien d'autre comme la bulle de dialogue.
-i, --info
En ajoutant ce drapeau, vous obtiendrez des métadonnées pour un poney imprimées, plutôt que le poney lui-même.
+i, ++info
Cela fonctionne de la même manière que l'option -i, sauf que le poney utilisera la sortie comme message plutôt que de simplement imprimer ces informations.
-r, --restriction
Cette option est utilisée pour restreindre les poneys qui peuvent être sélectionnés aléatoirement en fonction de leurs métadonnées. Une valeur dans l'argument est une combinaison du nom de la balise et de la valeur de la balise sous la forme NOM=VALEUR.
-X, --256-colours, --256colours, --x-colours
Utilise la prise en charge des 256 couleurs de xterm (prise en charge par la plupart des terminaux X11), malgré les compatibilités réelles de votre terminal.
-V, --tty-colours, --ttycolours, --vt-colours
Utilise les compatibilités VT de Linux sans utilisation KMS, malgré les compatibilités réelles de votre terminal.
-K, --kms-colours, --kmscolours
Utilise les compatibilités VT de Linux avec utilisation KMS, malgré les compatibilités réelles de votre terminal. (Peut ne pas fonctionner avec toutes les cartes vidéo KMS)
+c, --colour [couleur-ANSI]
Colore la bulle, y compris le lien et le message. Pour plus de fonctionnalités de coloration, voir le manuel info. L'argument, couleur-ANSI, devrait être une séquence de couleurs ANSI sans CSI préfixé et sans 'm' à la fin, par exemple 1;31 le rendra en rouge et gras (ou brillant selon le terminal).
--colour-bubble, --colour-balloon [couleur-ANSI]
Comme --colour, mais colore uniquement la bulle, sans le message ni le lien.
--colour-link [couleur-ANSI]
Comme --colour, mais colore uniquement le lien de la bulle.
--colour-msg, --colour-message [couleur-ANSI]
Comme --colour, mais colore uniquement le message.
--colour-pony [couleur-ANSI]
Comme --colour, mais colore le poney. Cette coloration n'a aucun effet sur les fichiers de poneys réguliers, car ils ont leur propre coloration.
--colour-wrap, --colour-hyphen [couleur-ANSI]
Comme --colour, mais colore le trait d'union ajouté par le retour à la ligne. Si vous voulez sans couleur, utilisez 0, la valeur par défaut est 31.

ENVIRONNEMENT

PONYSAY_BOTTOM
Sous TTY (Linux VT), si la sortie est plus grande que la hauteur de l'écran, seul le début est imprimé, laissant deux lignes vides. Si vous voulez que le bas soit imprimé plutôt que le début, vous pouvez exporter PONYSAY_BOTTOM avec la valeur yes, y ou 1.
PONYSAY_SHELL_LINES

PONYSAY_FULL_WIDTH
Vous pouvez exporter PONYSAY_FULL_WIDTH avec la valeur yes, y ou 1, si vous ne souhaitez pas que la sortie soit tronquée en largeur pour s'adapter au terminal.
PONYSAY_TRUNCATE_HEIGHT
Exportez PONYSAY_TRUNCATE_HEIGHT avec la valeur yes, y ou 1, si vous souhaitez tronquer la sortie en hauteur même si vous n'exécutez pas ponysay dans un TTY.
PONYSAY_UCS_ME
Exportez PONYSAY_UCS_ME avec la valeur yes, y ou 1, si vous souhaitez des liens symboliques [simulés] vers les fichiers de poneys en utilisant l'Universal Character Set dans leurs noms.
PONYSAY_KMS_PALETTE, PONYSAY_KMS_PALETTE_CMD
PONYSAY_KMS_PALETTE ou PONYSAY_KMS_PALETTE_CMD est utilisé pour indiquer à ponysay à quoi ressemble votre palette TTY, cette fonctionnalité vous permet d'obtenir les meilleures images en TTY si vous avez le support du Kernel Mode Setting (KMS).
PONYSAY_TYPO_LIMIT
ponysay est capable de corriger automatiquement les noms de poneys mal orthographiés et les noms de styles de ballons. Sans tenir compte des transpositions, par défaut si la distance pondérée est supérieure à 5 pour les mots les plus proches, la correction automatique est ignorée. Cette limite peut être modifiée en exportant la limite vers PONYSAY_TYPO_LIMIT ; régler la limite à zéro désactivera la correction automatique.
PONYSAY_WRAP_HYPHEN
Vous pouvez exporter ce que ponysay doit utiliser à la place d'un trait d'union lors de la césure des messages.
PONYSAY_WRAP_LIMIT
Définit la longueur qu'un mot doit atteindre pour être coupé par un trait d'union. Ceci est utilisé pour couper les mots longs afin que la sortie soit aussi esthétique que possible. Ce n'est pas la seule condition sous laquelle un mot peut être coupé par un trait d'union, il peut également être coupé si le mot ne rentre pas autrement.
PONYSAY_WRAP_EXCEED
Définit de combien un mot doit dépasser le point de césure pour être coupé par un trait d'union. Ce paramètre est utilisé conjointement avec PONYSAY_WRAP_LIMIT.
