podman-inspect(1) Manuel des commandes générales podman-inspect(1)

NOM

podman-inspect - Afficher la configuration d'un artefact, d'un conteneur, d'une image, d'un volume, d'un réseau ou d'un pod

SYNTAXE

podman inspect [options] nom [...]

DESCRIPTION

Affiche les informations de bas niveau sur les artefacts, les conteneurs et les images identifiés par leur nom ou leur ID. Par défaut, tous les résultats sont rendus sous forme de tableau JSON. Si le type d'inspection est `all`, l'ordre d'inspection est le suivant : conteneurs, images, volumes, réseaux, pods, artefacts.
Si un conteneur a le même nom qu'une image, alors le JSON du conteneur est retourné, et ainsi de suite.
Si un format est spécifié, le modèle donné est exécuté pour chaque résultat.

Pour plus d'options d'inspection, voir également podman-artifact-inspect(1), podman-container-inspect(1), podman-image-inspect(1), podman-network-inspect(1), podman-pod-inspect(1) et podman-volume-inspect(1).

OPTIONS

--format, -f=format

Formate la sortie en utilisant le modèle Go donné. Les clés du JSON retourné peuvent être utilisées comme valeurs pour l'option --format (voir les exemples ci-dessous).

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utilise le dernier conteneur créé. Note : le dernier conteneur démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (sauf WSL2)).

--size, -s

En plus de la sortie normale, affiche la taille totale du fichier si le type est un conteneur.

--type, -t=type

Retourne le JSON pour le type spécifié. Le type peut être 'artifact', 'container', 'image', 'volume', 'network', 'pod' ou 'all' (par défaut : all) (Uniquement significatif lorsqu'il est appelé en tant que podman inspect).

Inspecter l'image spécifiée avec le spécificateur de format ImageName :

# podman inspect a04 --format "{{.ImageName}}"
fedora

Inspecter l'image spécifiée pour le spécificateur de format GraphDriver :

# podman inspect a04 --format "{{.GraphDriver.Name}}"
overlay

Inspecter l'image spécifiée pour son spécificateur de format Size :

# podman image inspect --format "size: {{.Size}}" alpine
size:   4405240

Inspecter le dernier conteneur créé pour le spécificateur de format EffectiveCaps. (Cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (sauf WSL2)) :

podman container inspect --latest --format {{.EffectiveCaps}}
[CAP_CHOWN CAP_DAC_OVERRIDE CAP_FSETID CAP_FOWNER CAP_SETGID CAP_SETUID CAP_SETFCAP CAP_SETPCAP CAP_NET_BIND_SERVICE CAP_KILL]

Inspecter le pod spécifié pour le spécificateur de format Name :

# podman inspect myPod --type pod --format "{{.Name}}"
myPod

Inspecter le volume spécifié pour le spécificateur de format Name :

# podman inspect myVolume --type volume --format "{{.Name}}"
myVolume

Inspecter le réseau spécifié pour le spécificateur de format Name :

# podman inspect nyNetwork --type network --format "{{.name}}"
myNetwork

Inspecter l'artefact spécifié :

# podman inspect quay.io/myimage/myartifact:latest --type artifact
