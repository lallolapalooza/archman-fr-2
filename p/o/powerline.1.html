NOM

powerline - Script de prompt et de ligne de statut Powerline.

SYNTAXE

powerline EXT [SIDE] [-rMODULE] [-wLARGEUR] [--last-exit-code=INT]
          [--last-pipe-status=LISTE] [--jobnum=INT]
          [-cCLE.CLE=VALEUR]… [-tTHEME.CLE.CLE=VALEUR]… [-RCLE=VAL]…
          [-pCHEMIN]… [--socket=ADRESSE]

DESCRIPTION

EXT
Extension : application pour laquelle la commande powerline est lancée (généralement shell ou tmux). Prend également en charge les extensions wm. : wm.awesome.
SIDE
Côté : left et right représentent respectivement le côté gauche et droit, above émet des lignes qui sont censées être imprimées juste au-dessus du prompt et aboveleft est comme une concaténation de above avec left à l'exception qu'une seule instance Python est utilisée dans ce cas. Peut être omis pour les extensions wm.*.
-r, --renderer-module MODULE
Module de rendu. Habituellement quelque chose comme .bash ou .zsh (avec un point au début) qui est powerline.renderers.{ext}{MODULE}, peut aussi être un nom de module complet (doit contenir au moins un point ou se terminer par un point s'il s'agit d'un module de niveau supérieur) ou un sous-module de powerline.renderers (s'il n'y a pas de points).
-w, --width LARGEUR
Largeur maximale du prompt. Déclenche la troncature de certains segments.
--last-exit-code INT
Dernier code de sortie.
--last-pipe-status LISTE
Comme ci-dessus, mais est censé contenir un tableau de statuts séparés par des espaces, représentant les codes de sortie des commandes dans un seul tube.
--jobnum INT
Nombre de travaux.
-c, --config-override CLE.CLE=VALEUR
Surcharges de configuration pour config.json. Est traduit en un dictionnaire et fusionné avec le dictionnaire obtenu de la configuration JSON réelle : CLE.CLE=VALEUR est traduit en {"CLE": {"CLE": VALEUR}} puis fusionné récursivement. VALEUR peut être n'importe quelle valeur JSON, les valeurs qui ne sont pas null, true, false, commencent par un chiffre, {, [ sont traitées comme des chaînes de caractères. Si VALEUR est omis, la clé correspondante est supprimée.
-t, --theme-override THEME.CLE.CLE=VALEUR
Comme ci-dessus, mais spécifique au thème. THEME doit pointer vers un thème existant et utilisé pour avoir un effet, mais il est acceptable d'utiliser n'importe quel thème ici.
-R, --renderer-arg CLE=VAL
Comme ci-dessus, mais fournit un argument au rendu. Est censé être utilisé uniquement par les liaisons shell pour fournir diverses données comme le dernier code de sortie ou le dernier statut de tube (ils n'utilisent pas --renderer-arg pour des raisons historiques : --renderer-arg a été ajouté plus tard).
-p, --config-path CHEMIN
Chemin vers le répertoire de configuration. S'il est présent, les fichiers de configuration seront recherchés uniquement dans le chemin fourni. Peut être fourni plusieurs fois pour rechercher dans une liste de répertoires.
--socket ADRESSE
Adresse de socket à utiliser dans les clients démons. Est toujours un socket de domaine UNIX sous Linux et un socket de fichier sous Mac OS X. Non utilisé ici, présent uniquement pour la compatibilité avec d'autres clients powerline. Cet argument doit toujours être le premier et être sous la forme --socket ADRESSE : pas de = ou de forme courte autorisée (dans d'autres clients powerline, pas ici).
-h, --help
Afficher l'aide et quitter.
