NOM

po4a-display-man - affiche une page de manuel traduite selon un fichier PO

SYNTAXE

po4a-display-man -p FICHIER_PO [-m FICHIER_MAITRE] [-o OPTION_PO4A]

DESCRIPTION

Les traducteurs peuvent utiliser po4a-display-man pour voir comment leur traduction d'une page de manuel sera rendue aux utilisateurs finaux, sans avoir à recompiler et réinstaller tout le projet.

Ce script ne fonctionne qu'avec les pages de manuel écrites directement en nroff et gérées par le module man de po4a. Les pages manuelles générées à partir d'autres formats, tels que DocBook ou POD, ne sont pas prises en charge. Voir po4a-display-pod(1) pour un équivalent prenant en charge les documents POD.

OPTIONS

-p FICHIER_PO

Le fichier PO contenant les traductions.

-m FICHIER_MAITRE

La page de manuel originale. Il peut s'agir du chemin absolu ou relatif vers la page de manuel originale (compressée ou non), du nom de la page de manuel ou du nom et de la section de la page de manuel (en utilisant le format man.section). Lorsque le document maître n'est pas fourni avec l'option -m, po4a-display-man essaie de trouver la page de manuel originale en se basant sur la référence de ligne de la première chaîne dans le PO.

-o OPTION_PO4A

Quelques options à passer à po4a-translate(1).
