NOM

podman-machine-info - Afficher les informations de la machine hôte

SYNOPIS

podman machine info

DESCRIPTION

Affiche les informations relatives à la machine hôte. Uniquement en mode rootless, car toutes les commandes podman machine ne peuvent être utilisées qu'avec Podman sans privilèges.

Note : Le champ DefaultMachine dans la sortie Host ne suggère pas qu'il est possible de définir une machine Podman par défaut via les connexions système. Cette valeur représente la connexion système active actuelle associée à une machine Podman. Indépendamment de la connexion système par défaut, la machine Podman par défaut sera toujours podman-machine-default.

OPTIONS

--format, -f=format

Change le format de sortie en « json » ou en modèle Go.

Placeholder Description
.Host ... Informations sur l'hôte pour la machine locale
.Version ... Version de la machine

--help

Affiche le message d'utilisation.

EXEMPLES

Afficher les informations de la machine Podman par défaut.

$ podman machine info
Host:
  Arch: amd64
  CurrentMachine: ""
  DefaultMachine: ""
  EventsDir: /run/user/3267/podman
  MachineConfigDir: /home/myusername/.config/containers/podman/machine/qemu
  MachineImageDir: /home/myusername/.local/share/containers/podman/machine/qemu
  MachineState: ""
  NumberOfMachines: 0
  OS: linux
  VMType: qemu
Version:
  APIVersion: 4.4.0
  Built: 1677097848
  BuiltTime: Wed Feb 22 15:30:48 2023
  GitCommit: aa196c0d5c9abd5800edf9e27587c60343a26c2b-dirty
  GoVersion: go1.20
  Os: linux
  OsArch: linux/amd64
  Version: 4.4.0

Afficher les informations de la machine Podman par défaut au format json.

$ podman machine info --format json
{
  "Host": {
    "Arch": "amd64",
    "CurrentMachine": "",
    "DefaultMachine": "",
    "EventsDir": "/run/user/3267/podman",
    "MachineConfigDir": "/home/myusername/.config/containers/podman/machine/qemu",
    "MachineImageDir": "/home/myusername/.local/share/containers/podman/machine/qemu",
    "MachineState": "",
    "NumberOfMachines": 0,
    "OS": "linux",
    "VMType": "qemu"
  },
  "Version": {
    "APIVersion": "4.4.0",
    "Version": "4.4.0",
    "GoVersion": "go1.20",
    "GitCommit": "aa196c0d5c9abd5800edf9e27587c60343a26c2b-dirty",
    "BuiltTime": "Wed Feb 22 15:30:48 2023",
    "Built": 1677097848,
    "OsArch": "linux/amd64",
    "Os": "linux"
  }
}

Afficher le champ Host.Arch de la machine Podman par défaut.

$ podman machine info --format "{{ .Host.Arch }}"
amd64
