NOM

podman-network-inspect - Affiche la configuration réseau d'un ou plusieurs réseaux

SYNTAXE

podman network inspect [options] réseau [réseau ...]

DESCRIPTION

Affiche la configuration réseau (format JSON).

OPTIONS

--format, -f=format

Imprime joliment les réseaux en JSON ou à l'aide d'un modèle Go.

Placeholder Description
.Containers ... Conteneurs en cours d'exécution sur ce réseau.
.Created ... Horodatage de la création du réseau
.DNSEnabled Le DNS est activé pour le réseau (booléen)
.Driver Pilote réseau
.ID ID du réseau
.Internal Le réseau est interne (booléen)
.IPAMOptions ... Options IPAM du réseau
.IPv6Enabled Le réseau a un sous-réseau IPv6 (booléen)
.Labels ... Étiquettes du réseau
.Name Nom du réseau
.Network ... Type de réseau imbriqué
.NetworkDNSServers Tableau des serveurs DNS utilisés dans ce réseau
.NetworkInterface Nom de l'interface réseau sur l'hôte
.Options ... Options du réseau
.Routes Liste des routes statiques pour ce réseau
.Subnets Liste des sous-réseaux sur ce réseau

EXEMPLE

Inspecter le réseau podman par défaut.

$ podman network inspect podman
[
    {
        "name": "podman",
        "id": "2f259bab93aaaaa2542ba43ef33eb990d0999ee1b9924b557b7be53c0b7a1bb9",
        "driver": "bridge",
        "network_interface": "podman0",
        "created": "2021-06-03T12:04:33.088567413+02:00",
        "subnets": [
            {
                "subnet": "10.88.0.0/16",
                "gateway": "10.88.0.1"
            }
        ],
        "ipv6_enabled": false,
        "internal": false,
        "dns_enabled": false,
        "ipam_options": {
            "driver": "host-local"
        }
    }
]

Afficher le sous-réseau et la passerelle pour un réseau.

$ podman network inspect podman --format "{{range .Subnets}}Sous-réseau : {{.Subnet}} Passerelle : {{.Gateway}}{{end}}"
Sous-réseau : 10.88.0.0/16 Passerelle : 10.88.0.1
