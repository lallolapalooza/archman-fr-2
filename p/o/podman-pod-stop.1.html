podman-pod-stop(1) Manuel des commandes générales podman-pod-stop(1)

NOM

podman-pod-stop - Arrête un ou plusieurs pods

SYNTAXE

podman pod stop [options] pod ...

DESCRIPTION

Arrête les conteneurs d'un ou plusieurs pods. Vous pouvez utiliser les identifiants ou les noms des pods comme entrée.

OPTIONS

--all, -a

Arrête tous les pods

--ignore, -i

Ignore les erreurs lorsque les pods spécifiés ne sont pas dans le magasin de conteneurs. Un utilisateur peut avoir décidé de supprimer manuellement un pod, ce qui entraîne une erreur lors de la directive ExecStop d'un service systemd faisant référence à ce pod.

--latest, -l

Au lieu de fournir le nom ou l'identifiant du pod, utilise le dernier pod créé. Notez que le dernier pod démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (hors WSL2))

--pod-id-file=fichier

Lit l'identifiant du pod à partir du fichier spécifié et arrête le pod. Peut être spécifié plusieurs fois.

--time, -t=secondes

Secondes à attendre avant d'arrêter de force les conteneurs en cours d'exécution dans le pod. Utilisez -1 pour une attente infinie.

EXEMPLE

Arrêter un pod avec un nom donné.

$ podman pod stop mywebserverpod
cc8f0bea67b1a1a11aec1ecd38102a1be4b145577f21fc843c7c83b77fc28907

Arrêter plusieurs pods avec des identifiants donnés.

$ podman pod stop 490eb 3557fb
490eb241aaf704d4dd2629904410fe4aa31965d9310a735f8755267f4ded1de5
3557fbea6ad61569de0506fe037479bd9896603c31d3069a6677f23833916fab

Arrêter le dernier pod créé. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (hors WSL2))

$ podman pod stop --latest
3557fbea6ad61569de0506fe037479bd9896603c31d3069a6677f23833916fab

Arrêter tous les pods.

$ podman pod stop --all
19456b4cd557eaf9629825113a552681a6013f8c8cad258e36ab825ef536e818
3557fbea6ad61569de0506fe037479bd9896603c31d3069a6677f23833916fab
490eb241aaf704d4dd2629904410fe4aa31965d9310a735f8755267f4ded1de5
70c358daecf71ef9be8f62404f926080ca0133277ef7ce4f6aa2d5af6bb2d3e9
cc8f0bea67b1a1a11aec1ecd38102a1be4b145577f21fc843c7c83b77fc28907

Arrêter deux pods via --pod-id-file.

$ podman pod stop --pod-id-file file1 --pod-id-file file2
19456b4cd557eaf9629825113a552681a6013f8c8cad258e36ab825ef536e818
cc8f0bea67b1a1a11aec1ecd38102a1be4b145577f21fc843c7c83b77fc28907

Arrêter tous les pods avec un délai d'attente de 1 seconde.

$ podman pod stop -a -t 1

490eb241aaf704d4dd2629904410fe4aa31965d9310a735f8755267f4ded1de5
