NOM

podman-pod-logs - Afficher les journaux pour un pod avec un ou plusieurs conteneurs

SYNOPSIS

podman pod logs [options] pod

DESCRIPTION

La commande podman pod logs récupère par lots les journaux présents de tous les conteneurs d'un pod. Les journaux du pod peuvent être filtrés par nom ou ID de conteneur en utilisant l'option -c ou --container si nécessaire.

Note : Une commande podman pod log de longue durée avec l'option -f ou --follow doit être relancée si un nouveau conteneur est ajouté dynamiquement au pod ; sinon, les journaux des conteneurs nouvellement ajoutés ne seront pas visibles dans le flux de journaux.

OPTIONS

--color

Afficher les conteneurs avec des couleurs différentes dans le journal.

--container, -c

Par défaut, podman pod logs récupère les journaux de tous les conteneurs disponibles dans le pod, différenciés par le champ container. Cependant, il existe des cas d'utilisation où l'utilisateur souhaite limiter le flux de journaux à un conteneur particulier d'un pod. Dans ces cas, -c peut être utilisé comme podman pod logs -c nom_ou_id_conteneur nom_du_pod.

--follow, -f

Suivre la sortie des journaux. La valeur par défaut est false.

Note : Lors du suivi d'un pod qui est supprimé par podman pod rm ou supprimé à la sortie (podman run --rm ...), il y a une chance que le fichier journal soit supprimé avant que podman pod logs ne lise le contenu final.

--latest, -l

Au lieu de fournir le nom ou l'ID du pod, utiliser le dernier pod créé. Note : le dernier pod démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (hors WSL2))

--names, -n

Afficher les noms des conteneurs au lieu de leurs IDs dans le journal.

--since=TIMESTAMP

Afficher les journaux depuis TIMESTAMP. L'option --since peut être des timestamps Unix, des timestamps formatés en date, ou des chaînes de durée Go (par exemple, 10m, 1h30m) calculées par rapport à l'heure de la machine cliente. Les formats pris en charge pour les timestamps formatés en date incluent RFC3339Nano, RFC3339, 2006-01-02T15:04:05, 2006-01-02T15:04:05.999999999, 2006-01-02Z07:00, et 2006-01-02.

--tail=LIGNES

Afficher le nombre spécifié de LIGNES à la fin des journaux. LIGNES doit être un entier. La valeur par défaut est -1, ce qui imprime toutes les lignes.

--timestamps, -t

Afficher les timestamps dans la sortie des journaux. La valeur par défaut est false.

--until=TIMESTAMP

Afficher les journaux jusqu'à TIMESTAMP. L'option --until peut être des timestamps Unix, des timestamps formatés en date, ou des chaînes de durée Go (par exemple, 10m, 1h30m) calculées par rapport à l'heure de la machine cliente. Les formats pris en charge pour les timestamps formatés en date incluent RFC3339Nano, RFC3339, 2006-01-02T15:04:05, 2006-01-02T15:04:05.999999999, 2006-01-02Z07:00, et 2006-01-02.

EXEMPLE

Pour afficher les journaux d'un pod :

podman pod logs -t id_ou_nom_du_pod

Pour afficher les journaux d'un conteneur spécifique du pod :

podman pod logs -c id_ou_nom_du_conteneur id_ou_nom_du_pod

Pour afficher tous les journaux du pod :

podman pod logs -t --since 0 mon-pod-serveur-1

Pour afficher les journaux d'un pod depuis une certaine heure :

podman pod logs -t --since 2017-08-07T10:10:09.055837383-04:00 mon-pod-serveur-1

Pour afficher les journaux d'un pod des 10 dernières minutes :

podman pod logs --since 10m mon-pod-serveur-1

Pour afficher les journaux d'un pod jusqu'à il y a 30 minutes :

podman pod logs --until 30m mon-pod-serveur-1
