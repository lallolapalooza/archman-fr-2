NOM

podman-machine-cp - Copie sécurisée de contenu entre l'hôte et la machine virtuelle

SYNTAXE

podman machine cp [options] chemin_source chemin_destination

DESCRIPTION

Utilise la copie sécurisée (scp) pour copier des fichiers ou des répertoires entre la machine virtuelle et votre machine hôte.

podman machine cp ne prend pas en charge la copie entre deux machines virtuelles, ce qui nécessiterait l'exécution simultanée de deux machines.

De plus, podman machine cp effectuera automatiquement une copie récursive des fichiers et répertoires.

OPTIONS

--help

Affiche l'énoncé d'utilisation.

--quiet, -q

Supprime la sortie de statut de la copie.

EXEMPLES

Copier un fichier de votre hôte vers la machine Podman en cours d'exécution.

$ podman machine cp ~/configuration.txt podman-machine-default:~/configuration.txt
...
Copie réussie

Copier un fichier de la machine Podman en cours d'exécution vers votre hôte.

$ podman machine cp podman-machine-default:~/logs/log.txt ~/logs/podman-machine-default.txt
...
Copie réussie

Copier un répertoire de votre hôte vers la machine Podman en cours d'exécution.

$ podman machine cp ~/.config podman-machine-default:~/.config
...
Copie réussie

Copier un répertoire de la machine Podman en cours d'exécution vers votre hôte.

$ podman machine cp podman-machine-default:~/.config ~/podman-machine-default.config
...
Copie réussie
