NAME

postfix2dlf - convert postfix logfiles to dlf format

SYNOPSIS

postfix2dlf

DESCRIPTION

postfix2dlf convertit un fichier journal postfix en un fichier au format DLF (Distilled Log Format) de Lire. Il appelle postfix2dlf_pre(1) et postfix2dlf_main(1) pour effectuer le travail réel. Il s'attend à lire le fichier journal depuis l'entrée standard (stdin) et imprime le format DLF sur la sortie standard (stdout). Les messages de diagnostic sont imprimés sur la sortie d'erreur (stderr). Ce script est appelé par lr_log2xml(1).

RATIONALE

L'architecture de postfix2dlf est assez différente des autres convertisseurs dlf d'e-mails. Ceci est dû au fait que lors de l'analyse d'un fichier journal postfix, il n'y a aucun signe indiquant si un message a été livré à tous les destinataires. (Dans un journal sendmail, il y a un champ rcpts=, qui peut être utilisé à cette fin.)

Il existe plusieurs solutions de contournement pour gérer un tel journal. 1 : garder une trace de tous les identifiants de file d'attente (queueid) avec leurs informations d'origine pendant le traitement de l'ensemble du fichier journal. Ceci consomme trop de mémoire. 2 : utiliser une heuristique de 10 secondes : supposer qu'un message ne restera jamais plus de 10 secondes dans la file d'attente. Ou, alternativement, supposer qu'il n'y aura pas plus de $LR_POSTFIX_MAX_QUEUE_SIZE messages dans la file d'attente simultanément. Ceci est trop sujet aux erreurs. 3 : utiliser sort(1) pour trier les lignes du journal par identifiant de file d'attente. C'est ce que nous faisions auparavant. Cependant, nous ne savons pas à l'avance quel champ contiendra l'identifiant de la file d'attente (les fichiers journaux traités par le syslog de Sun Solaris auront leur identifiant de file d'attente à une position différente, par exemple). Calculer cette position impliquerait d'analyser le journal deux fois.

Nous avons choisi une variation de la troisième alternative : nous stockons les informations que nous aurions obtenues avec sort(1) dans un fichier de base de données (db file). Pendant la construction de ce fichier de base de données, qui contient une correspondance entre les identifiants de file d'attente et le nombre de lignes avec cet identifiant, nous effectuons autant de pré-traitement que possible. Le journal prétraité est imprimé dans un fichier temporaire (tmpfile). La structure du journal prétraité est la même que celle du journal brut : une ligne de journal brut donne une ligne prétraitée. Le journal prétraité est converti en DLF par lr_postfix2dlf_main(1), en utilisant les informations du fichier de base de données.

Un effet secondaire intéressant de cette méthode de traitement est que le journal est traité dans l'ordre chronologique d'origine.

NAME

postfix2dlf

convert Postfix logfile to DLF format

SYNOPSIS

postfix2dlf [-v] [-f] [-m] [-c config] [-o output] [logfile]

DESCRIPTION

This program converts a Postfix logfile to the DLF format. It is mainly useful for historical logfiles that you want to analyse with lr_log2report(1).

It is split in two parts:

postfix2dlf_pre reads the logfile and converts it to an intermediate DLF format file. This takes about the same amount of disk space as the original logfile.

postfix2dlf_main reads the intermediate file, filters it and produces the final DLF file.

The logfile can be empty or rotated. If empty, it's skipped. If rotated, it's assumed to be gzipped. You will need to have the gzip binary available.

The intermediate file is removed when done.

The options are:

-v
Verbose mode. Prints progress and other useful info.
-f
Force. Overwrite existing output file.
-m
Use message-id instead of queue-id. Useful when you want to track mail over a longer time span, or across different MTAs.
-c config
Read config from config instead of the default.
-o output
Write DLF output to output instead of standard output.

RATIONALE

The Postfix logfile format is difficult to parse and extract information from. This utility converts it to a simpler format, that is easier to process.

EXAMPLE

Convert the maillog file to DLF format and save it to /tmp/maillog.dlf:

postfix2dlf -o /tmp/maillog.dlf < /var/log/maillog

LOGFORMAT

The utility expects the standard Postfix logfile format. For example:

Jul 11 15:10:09 myhost postfix/smtpd[12345]: AB12345678: client=myclient[192.168.0.1]

The relevant information that is extracted is:

  • Timestamp
  • Hostname
  • Queue-id
  • Process name
  • Message

PERFORMANCE

The following logfile was converted:

    were:

postfix2dlf_main info read 177027 lines; output 61671 DLF lines; 0 errors
postfix2dlf_main info memory stats: vsize=5976Krss=4656K majflt=427
postfix2dlf_main info elapsed time in seconds real=245 user=152.05 system=4.15

.

EXAMPLES

postfix2dlf will be rarely used on its own, but is more likely called by lr_log2report:

$ lr_run lr_log2report postfix < /var/log/maillog

BUGS

This script needs a lot of space in TMPDIR: it creates a tmpfile which is about the same in size as the raw log it's being fed.

Occasionally, postfix reuses its queueids very fast. We can't cope with this.

NOM

postfix2dlf

convertir un fichier journal Postfix au format DLF

SYNTAXE

postfix2dlf [-v] [-f] [-m] [-c config] [-o sortie] [fichier_journal]

DESCRIPTION

Ce programme convertit un fichier journal Postfix au format DLF. Il est principalement utile pour les fichiers journaux historiques que vous souhaitez analyser avec lr_log2report(1).

Il est divisé en deux parties :

postfix2dlf_pre lit le fichier journal et le convertit en un fichier de format DLF intermédiaire. Cela prend à peu près le même espace disque que le journal original.

postfix2dlf_main lit le fichier intermédiaire, le filtre et produit le fichier DLF final.

Le fichier journal peut être vide ou rotatif. S'il est vide, il est ignoré. S'il est rotatif, on suppose qu'il est gzippé. Vous devrez avoir le binaire gzip disponible.

Le fichier intermédiaire est supprimé une fois terminé.

Les options sont :

-v
Mode verbeux. Affiche la progression et d'autres informations utiles.
-f
Forcer. Écrase le fichier de sortie existant.
-m
Utiliser l'identifiant de message au lieu de l'identifiant de file d'attente. Utile lorsque vous souhaitez suivre un e-mail sur une période plus longue, ou sur différents MTA.
-c config
Lire la configuration depuis config au lieu de celle par défaut.
-o sortie
Écrire la sortie DLF dans sortie au lieu de la sortie standard.

MOTIF

Le format du fichier journal Postfix est difficile à analyser et à extraire des informations. Cet utilitaire le convertit en un format plus simple, plus facile à traiter.

EXEMPLE

Convertir le fichier maillog au format DLF et l'enregistrer dans /tmp/maillog.dlf :

postfix2dlf -o /tmp/maillog.dlf < /var/log/maillog

FORMAT DU JOURNAL

L'utilitaire attend le format standard du fichier journal Postfix. Par exemple :

Jul 11 15:10:09 myhost postfix/smtpd[12345]: AB12345678: client=myclient[192.168.0.1]

Les informations pertinentes qui sont extraites sont :

  • Horodatage
  • Nom d'hôte
  • Identifiant de file d'attente
  • Nom du processus
  • Message

BOGUES

Ce script a besoin de beaucoup d'espace dans TMPDIR : il crée un fichier temporaire dont la taille est à peu près la même que celle du journal brut qui lui est fourni.

Parfois, Postfix réutilise très rapidement ses identifiants de file d'attente. Nous ne pouvons pas gérer cela.
