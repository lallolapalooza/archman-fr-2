NOM

podman-ps - Afficher des informations sur les conteneurs

SYNOPSIS

podman ps [options]

podman container ps [options]

podman container list [options]

podman container ls [options]

DESCRIPTION

podman ps liste les conteneurs en cours d'exécution sur le système. Utilisez l'option --all pour afficher toutes les informations sur les conteneurs. Par défaut, il liste :

  • l'ID du conteneur
  • le nom de l'image utilisée par le conteneur
  • la COMMANDE exécutée par le conteneur
  • l'heure de création du conteneur
  • l'état du conteneur
  • les mappages de ports utilisés par le conteneur
  • les noms alternatifs du conteneur

OPTIONS

--all, -a

Afficher tous les conteneurs, par défaut seuls les conteneurs en cours d'exécution sont affichés.

Note : Podman partage le stockage des conteneurs avec d'autres outils tels que Buildah et CRI-O. Dans certains cas, ces conteneurs externes peuvent également exister dans le même stockage. Utilisez l'option --external pour voir ces conteneurs externes. Les conteneurs externes affichent le statut 'storage'.

--external

Afficher les conteneurs externes qui ne sont pas contrôlés par Podman mais qui sont stockés dans le stockage des conteneurs. Ces conteneurs externes sont généralement créés via d'autres technologies de conteneurisation comme Buildah ou CRI-O et peuvent dépendre des mêmes images de conteneur que Podman utilise également. Les conteneurs externes sont désignés par 'buildah' ou 'storage' dans les colonnes COMMAND et STATUS de la sortie de ps.

--filter, -f

Filtrer les conteneurs affichés dans la sortie. Plusieurs filtres peuvent être donnés en utilisant plusieurs fois l'option --filter. Les filtres ayant la même clé fonctionnent de manière inclusive, à l'exception de label qui est exclusive. Les filtres ayant des clés différentes fonctionnent toujours de manière exclusive.

Les filtres valides sont listés ci-dessous :

Filtre Description
id [ID] ID du conteneur (correspondance préfixée de CID par défaut ; accepte les expressions régulières)
name [Nom] Nom du conteneur (accepte les expressions régulières)
label [Clé] ou [Clé=Valeur] Étiquette attribuée à un conteneur
label! [Clé] ou [Clé=Valeur] Étiquette NON attribuée à un conteneur
exited [Int] Code de sortie du conteneur
status [Statut] Statut du conteneur : 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [Nom d'image] Image ou descendant utilisée pour créer le conteneur (accepte les expressions régulières)
before [ID] ou [Nom] Conteneurs créés avant ce conteneur
since [ID] ou [Nom] Conteneurs créés depuis ce conteneur
volume [Nom du volume] ou [Point de montage de destination] Volume monté dans le conteneur
health [Statut] healthy ou unhealthy
pod [Pod] nom ou ID complet ou partiel du pod
network [Réseau] nom ou ID complet du réseau
until [DateTime] conteneur créé avant la durée ou l'heure spécifiée.
command [Commande] la commande exécutée par le conteneur, seul argv[0] est pris en compte

--format=format

Pré-formater les conteneurs en JSON ou en utilisant un modèle Go

Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Espace réservé Description
.AutoRemove Si vrai, les conteneurs sont supprimés à la sortie
.CIDFile Fichier d'ID de conteneur
.Command Commande utilisée entre guillemets
.Created ... Heure de création du conteneur, A-M-J H:M:S
.CreatedAt Heure de création du conteneur (identique à ci-dessus)
.CreatedHuman Heure de création, relative
.ExitCode Code de sortie du conteneur
.Exited "true" si le conteneur est sorti
.ExitedAt Heure (secondes depuis l'époque) de sortie du conteneur
.ExposedPorts ... Carte des ports exposés sur ce conteneur
.ID ID du conteneur
.Image Nom/ID de l'image
.ImageID ID de l'image
.IsInfra "true" si conteneur infra
.Label string Étiquette spécifiée du conteneur
.Labels ... Toutes les étiquettes attribuées au conteneur
.Mounts Volumes montés dans le conteneur
.Names Nom du conteneur
.Networks Afficher tous les réseaux connectés au conteneur
.Pid Identifiant de processus sur le système hôte
.Pod Pod auquel le conteneur est associé (SHA)
.PodName Nom du pod du conteneur
.Ports Ports redirigés et exposés
.Restarts Afficher le nombre de redémarrages du conteneur
.RunningFor Temps écoulé depuis le démarrage du conteneur
.Size Taille du conteneur
.StartedAt Heure (secondes depuis l'époque) de démarrage du conteneur
.State Description conviviale de l'état du conteneur
.Status Statut du conteneur

--help, -h

Afficher le message d'utilisation

--last, -n

Afficher les n derniers conteneurs créés (tous états)

--latest, -l

Afficher le dernier conteneur créé (tous états) (Cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (hors WSL2))

--namespace, --ns

Afficher les informations sur les espaces de noms

--no-trunc

Ne pas tronquer la sortie (par défaut false).

--noheading

Omettre les en-têtes de table de la liste des conteneurs.

--pod, -p

Afficher les pods auxquels les conteneurs sont associés

--quiet, -q

Afficher uniquement les IDs numériques des conteneurs

--size, -s

Afficher la taille totale des fichiers

--sort=created

Trier par commande, created, id, image, names, runningfor, size, ou status", Note : Choisir size trie par la taille de rootFs, pas alphabétiquement comme pour les autres options

--sync

Forcer une synchronisation de l'état des conteneurs avec le runtime OCI. Dans certains cas, l'état d'un conteneur dans le runtime peut être désynchronisé avec l'état de Podman. Ceci met à jour l'état de Podman en fonction de ce que rapporte le runtime OCI. La synchronisation forcée est beaucoup plus lente, mais peut résoudre les problèmes d'état incohérents.

--watch, -w

Actualiser la sortie avec les conteneurs actuels à intervalles réguliers en secondes.

EXEMPLES

Lister les conteneurs en cours d'exécution.

$ podman ps

NOM

podman-container-list, podman-ps - Lister des conteneurs

SYNOPSIS

podman container list [options]

podman ps [options]

DESCRIPTION

La commande podman ps liste les conteneurs. Par défaut, elle n'affiche que les conteneurs en cours d'exécution.

Pour lister tous les conteneurs, y compris ceux qui sont arrêtés ou qui n'ont pas été démarrés, utilisez l'option -a ou --all.

Le terme « conteneur » utilisé dans cette page de manuel peut également faire référence à des conteneurs créés par d'autres outils tels que Buildah.

OPTIONS

Les options suivantes sont disponibles :

-a, --all
Affiche tous les conteneurs (par défaut, seuls les conteneurs en cours d'exécution sont affichés).
--cancel
Annule la commande de mise à jour d'une mise à jour de conteneur.
--cidfile=path
Écrit le dernier ID de conteneur dans le fichier.
--creds=path
Fichier contenant les informations d'identification pour s'authentifier auprès d'un registre.
--filter=key=value
Filtre la sortie en fonction des critères spécifiés. Les filtres disponibles sont :
  • label : filtre par étiquette. L'étiquette doit être au format `key=value` ou `key`.
  • name : filtre par nom de conteneur.
  • network : filtre par nom ou ID de réseau.
  • pod : filtre par nom ou ID de pod.
  • status : filtre par état du conteneur. Les valeurs possibles sont : created, running, paused, restarting, removing, exited, dead.
  • volume : filtre par nom ou point de montage de volume.
--format=format
Utilise un format Go pour une sortie personnalisée. Les valeurs disponibles sont : .ID, .Image, .Command, .CreatedAt, .State, .Status, .Ports, .Names, .Labels, .Mounts, .Pod, .PodName.
--last, -n=num
Affiche les N derniers conteneurs (par défaut, tous les conteneurs sont affichés).
--no-trunc
N'arrête pas la sortie de l'ID complet du conteneur.
--pod
Affiche les informations sur les conteneurs et les pods associés.
--size
Affiche la taille totale utilisée par les conteneurs.
--sort=key
Trie la sortie par le champ spécifié. Les valeurs possibles sont : created, id, names, size, status.
--external
Affiche les conteneurs externes (créés par d'autres outils).
--ns
Affiche les espaces de noms du conteneur.
