podman-ps(1) Manuel des commandes générales podman-ps(1)

NOM

podman-ps - Afficher des informations sur les conteneurs

SYNTAXE

podman ps [options]

podman container ps [options]

podman container list [options]

podman container ls [options]

DESCRIPTION

podman ps liste les conteneurs en cours d'exécution sur le système. Utilisez l'option --all pour afficher les informations de tous les conteneurs. Par défaut, il liste :

  • l'identifiant du conteneur
  • le nom de l'image utilisée par le conteneur
  • la COMMANDE exécutée par le conteneur
  • l'heure de création du conteneur
  • l'état du conteneur
  • les mappages de ports utilisés par le conteneur
  • les noms alternatifs du conteneur

OPTIONS

--all, -a

Afficher tous les conteneurs, par défaut seuls les conteneurs en cours d'exécution sont affichés.

Note : Podman partage le stockage des conteneurs avec d'autres outils tels que Buildah et CRI-O. Dans certains cas, ces conteneurs externes peuvent également exister dans le même stockage. Utilisez l'option --external pour voir ces conteneurs externes. Les conteneurs externes affichent le statut 'storage'.

--external

Afficher les conteneurs externes qui ne sont pas contrôlés par Podman mais qui sont stockés dans le stockage des conteneurs. Ces conteneurs externes sont généralement créés via d'autres technologies de conteneurisation telles que Buildah ou CRI-O et peuvent dépendre des mêmes images de conteneur que Podman utilise également. Les conteneurs externes sont dénotés par 'buildah' ou 'storage' dans les colonnes COMMAND et STATUS de la sortie de ps.

--filter, -f

Filtrer les conteneurs affichés dans la sortie. Plusieurs filtres peuvent être donnés en utilisant plusieurs fois l'indicateur --filter. Les filtres ayant la même clé fonctionnent de manière inclusive, à l'exception de label qui est exclusive. Les filtres ayant des clés différentes fonctionnent toujours de manière exclusive.

Les filtres valides sont listés ci-dessous :

Filtre Description
id [ID] ID du conteneur (correspondance préfixe CID par défaut ; accepte les expressions régulières)
name [Nom] Nom du conteneur (accepte les expressions régulières)
label [Clé] ou [Clé=Valeur] Étiquette attribuée à un conteneur
label! [Clé] ou [Clé=Valeur] Étiquette NON attribuée à un conteneur
exited [Int] Code de sortie du conteneur
status [Statut] Statut du conteneur : 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NomImage] Image ou descendant utilisé pour créer le conteneur (accepte les expressions régulières)
before [ID] ou [Nom] Conteneurs créés avant ce conteneur
since [ID] ou [Nom] Conteneurs créés depuis ce conteneur
volume [NomVolume] ou [PointMontageDestination] Volume monté dans le conteneur
health [Statut] healthy ou unhealthy
pod [Pod] nom ou ID complet ou partiel du pod
network [Réseau] nom ou ID complet du réseau
until [DateTime] conteneur créé avant la durée ou l'heure donnée.
command [Commande] la commande que le conteneur exécute, seul argv[0] est pris en compte

--format=format

Imprimer joliment les conteneurs en JSON ou en utilisant un template Go

Les espaces réservés valides pour le template Go sont listés ci-dessous :

Espace réservé Description
.AutoRemove Si vrai, les conteneurs sont supprimés à la sortie
.CIDFile Fichier ID du conteneur
.Command Commande utilisée entre guillemets
.Created ... Heure de création du conteneur, A-M-J H:M:S
.CreatedAt Heure de création du conteneur (identique à ci-dessus)
.CreatedHuman Heure de création, relative
.ExitCode Code de sortie du conteneur
.Exited "true" si le conteneur est sorti
.ExitedAt Heure (secondes epoch) de sortie du conteneur
.ExposedPorts ... Carte des ports exposés sur ce conteneur
.ID ID du conteneur
.Image Nom/ID de l'image
.ImageID ID de l'image
.IsInfra "true" si conteneur infra
.Label string Étiquette spécifiée du conteneur
.Labels ... Toutes les étiquettes attribuées au conteneur
.Mounts Volumes montés dans le conteneur
.Names Nom du conteneur
.Networks Afficher tous les réseaux connectés au conteneur
.Pid Identifiant du processus sur le système hôte
.Pod Pod auquel le conteneur est associé (SHA)
.PodName Nom du pod du conteneur
.Ports Ports redirigés et exposés
.Restarts Afficher le nombre de redémarrages du conteneur
.RunningFor Temps écoulé depuis le démarrage du conteneur
.Size Taille du conteneur
.StartedAt Heure (secondes epoch) de démarrage du conteneur
.State Description lisible par l'homme de l'état du ctr
.Status Statut du conteneur

--help, -h

Afficher le message d'utilisation

--last, -n

Afficher les n derniers conteneurs créés (tous états)

--latest, -l

Afficher le dernier conteneur créé (tous états) (Cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (hors WSL2))

--namespace, --ns

Afficher les informations de namespace

--no-trunc

Ne pas tronquer la sortie (par défaut false).

--noheading

Omettre les en-têtes de table de la liste des conteneurs.

--pod, -p

Afficher les pods auxquels les conteneurs sont associés

--quiet, -q

Afficher uniquement les identifiants numériques des conteneurs

--size, -s

Afficher la taille totale du fichier

--sort=created

Trier par commande, created, id, image, names, runningfor, size, ou status", Note: Choisir size trie par la taille de rootFs, pas alphabétiquement comme les autres options

--sync

Forcer une synchronisation de l'état des conteneurs avec le runtime OCI. Dans certains cas, l'état d'un conteneur dans le runtime peut être désynchronisé avec l'état de Podman. Ceci met à jour l'état de Podman en fonction de ce que le runtime OCI rapporte. La synchronisation forcée est beaucoup plus lente, mais peut résoudre les problèmes d'état incohérent.

--watch, -w

Rafraîchir la sortie avec les conteneurs actuels à un intervalle en secondes.

EXEMPLES

Lister les conteneurs en cours d'exécution.

$ podman ps
CONTAINER ID  IMAGE                            COMMAND    CREATED        STATUS        PORTS                                                   NAMES
4089df24d4f3  docker.

NOM

podman-ps — lister les conteneurs

SYNOPIS

podman ps [-a | -l | -n] [-s] [-f FILTRE ...] [--format FORMAT] [--last | -n NOMBRE] [--no-trunc] [--pod] [--size] [--sort CHAMP] [--all | -a]

DESCRIPTION

L'utilitaire podman ps liste les conteneurs qui sont en cours d'exécution, ou tous les conteneurs s'ils sont configurés pour l'être.

Les conteneurs sont considérés comme étant en cours d'exécution s'ils sont dans l'état running, ou s'ils sont dans des états transitoires comme restarting, paused, ou created. Vous pouvez utiliser l'option -a pour voir tous les conteneurs.

Par défaut, les conteneurs sont affichés dans le format suivant :

CONTAINER ID   IMAGE   COMMAND   CREATED   STATUS   PORTS   NAMES

Les conteneurs sont triés par leur date de création, du plus récent au plus ancien.

OPTIONS

-a, --all
Ne pas masquer les conteneurs arrêtés. Par défaut, seul les conteneurs en cours d'exécution sont affichés.

-f, --filter FILTRE
Filtrer la sortie. Le filtre FILTRE est une chaîne de caractères au format clé=valeur. Les filtres disponibles sont :
ancestor : conteneurs d'une image donnée. Ex: --filter ancestor=nginx:latest
id : conteneurs d'un ID donné. Ex: --filter id=9c14f0e809c3
label : conteneurs avec un label donné. Ex: --filter label=app=frontend
name : conteneurs d'un nom donné. Ex: --filter name=webserver
network : conteneurs connectés à un réseau donné. Ex: --filter network=web-net
status : conteneurs d'un statut donné. Ex: --filter status=running
volume : conteneurs avec un volume donné. Ex: --filter volume=mydata
pod : conteneurs appartenant à un pod donné. Ex: --filter pod=web-pod
Vous pouvez spécifier plusieurs filtres.

--format FORMAT
Format de sortie Go v2. Par exemple, --format "{{.ID}}\t{{.Image}}\t{{.Names}}".

-l, --last NOMBRE
Afficher les N conteneurs les plus récemment créés, y compris ceux qui sont arrêtés. Par défaut, N=1.

--no-trunc
Ne pas tronquer la sortie.

--pod
Afficher les informations sur les pods auxquels appartiennent les conteneurs.

--size
Afficher la taille totale des images des conteneurs. Cela peut prendre plus de temps car Podman doit calculer la taille à partir du système de fichiers.

--sort CHAMP
Trier la sortie. Les champs disponibles sont command, created, id, image, names, status, et size.
