POSTLOCK(1) Manuel des commandes générales POSTLOCK(1)

NOM

postlock - verrouille un dossier de courrier et exécute une commande

SYNTAXE

postlock [-c config_dir] [-l lock_style]
[-v] fichier commande...

DESCRIPTION


La commande postlock(1) verrouille le fichier en accès exclusif et exécute la commande. La méthode de verrouillage est compatible avec l'agent de livraison locale UNIX de Postfix.

Options :

-c config_dir
Lit le fichier de configuration main.cf dans le répertoire nommé au lieu du répertoire de configuration par défaut.
-l lock_style
Remplace la méthode de verrouillage spécifiée via le paramètre de configuration mailbox_delivery_lock (voir ci-dessous).
-v
Active la journalisation détaillée à des fins de débogage. L'utilisation de plusieurs options -v rend le logiciel de plus en plus verbeux.

Arguments :

fichier
Un fichier de boîte aux lettres. L'utilisateur doit avoir les permissions de lecture/écriture.
commande...
La commande à exécuter pendant que le fichier est verrouillé en accès exclusif. La commande est exécutée directement, c'est-à-dire sans interprétation par un interpréteur de commandes shell.

DIAGNOSTICS


Le code de statut de résultat est 75 (EX_TEMPFAIL) lorsque postlock(1) n'a pas pu effectuer l'opération demandée. Sinon, le code de sortie est le code de sortie de la commande.

BUGS


Avec les systèmes de fichiers distants, la capacité d'acquérir un verrou n'élimine pas nécessairement les conflits d'accès. Évitez l'accès aux fichiers par des processus s'exécutant sur différentes machines.

ENVIRONNEMENT

MAIL_CONFIG
Répertoire contenant les fichiers de configuration Postfix.
MAIL_VERBOSE
Active la journalisation détaillée à des fins de débogage.

PARAMETRES DE CONFIGURATION

Les paramètres main.cf suivants sont particulièrement pertinents pour ce programme. Le texte ci-dessous ne fournit qu'un résumé des paramètres. Voir postconf(5) pour plus de détails, y compris des exemples.

COMMANDES DE VERROUILLAGE

deliver_lock_attempts (20)
Le nombre maximal de tentatives pour acquérir un verrou exclusif sur un fichier de boîte aux lettres ou un fichier journal de bounce(8).
deliver_lock_delay (1s)
Le temps entre les tentatives pour acquérir un verrou exclusif sur un fichier de boîte aux lettres ou un fichier journal de bounce(8).
stale_lock_time (500s)
Le temps après lequel un verrouillage obsolète de fichier de boîte aux lettres exclusif est supprimé.
mailbox_delivery_lock (voir la sortie de 'postconf -d')
Comment verrouiller une boîte aux lettres UNIX de type local(8) avant de tenter la livraison.

CONTROLES DE RESSOURCES ET DE TAUX

fork_attempts (5)
Le nombre maximal de tentatives pour créer un processus enfant via fork().
fork_delay (1s)
Le délai entre les tentatives pour créer un processus enfant via fork().

CONTROLES DIVERS

config_directory (voir la sortie de 'postconf -d')
L'emplacement par défaut des fichiers de configuration main.cf et master.cf de Postfix.
import_environment (voir la sortie de 'postconf -d')
La liste des variables d'environnement qu'un processus Postfix privilégié importera d'un processus parent non-Postfix, ou des remplacements d'environnement nom=valeur.
