NOM

podlint - vérifie la correction du POD à l'aide de Pod::POM

SYNTAXE

podlint MonFichier.pm

DESCRIPTION

Ce script utilise Pod::POM pour analyser un document Pod avec les avertissements complets activés, agissant ainsi comme un vérificateur de syntaxe et de structure.

L'option -f peut être spécifiée pour que le modèle d'objet Pod analysé soit imprimé sur STDOUT avec toute erreur de balisage corrigée. Notez qu'il existe des erreurs d'analyse critiques qui ne peuvent pas être gérées et corrigées par l'analyseur et dans ce cas, le script se terminera en signalant l'erreur.
