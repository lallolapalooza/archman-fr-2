NOM

podman-quadlet - Permet aux utilisateurs de gérer les Quadlets

SYNOPIS

podman quadlet sous-commande

DESCRIPTION

podman quadlet est un ensemble de sous-commandes qui gèrent les Quadlets.

Les Quadlets Podman permettent aux utilisateurs de gérer les conteneurs, les pods, les volumes, les réseaux et les images de manière déclarative via des fichiers unit systemd, simplifiant la gestion des conteneurs sur les systèmes Linux sans la complexité des outils d'orchestration complets comme Kubernetes.

SOUS-COMMANDES

Commande Page de manuel Description
install podman-quadlet-install(1) Installe un fichier quadlet ou une application quadlet
list podman-quadlet-list(1) Liste les quadlets installés
print podman-quadlet-print(1) Affiche le contenu d'un quadlet
rm podman-quadlet-rm(1) Supprime un quadlet installé
