NOM

postgis - utilitaire d'administration postgis

SYNTAXE

postgis commande [arguments]

DESCRIPTION

Le script postgis prend en charge diverses commandes pour faciliter l'administration d'une installation PostGIS.

UTILISATION

Les informations d'utilisation sont affichées lorsque le script est invoqué sans arguments ou avec l'argument help.

EXEMPLES

Un exemple de commande pour vérifier l'état de PostGIS dans la base de données template_postgis :

# postgis status template_postgis

AUTEURS
