NOM

podman-quadlet-rm - Supprime un quadlet installé

SYNOPSIS

podman quadlet rm [options] quadlet [quadlet]...

DESCRIPTION

Supprime un ou plusieurs Quadlets installés pour l'utilisateur actuel. La commande suivante prend également le nom de l'application en entrée et supprime tous les Quadlets appartenant à cette application spécifique.

Note : Si un quadlet fait partie d'une application, la suppression de ce quadlet spécifique supprimera l'application entière. Lorsqu'un quadlet est installé à partir d'un répertoire, tous les fichiers installés à partir de ce répertoire — y compris les fichiers quadlets et non-quadlets — sont considérés comme faisant partie d'une seule application.

OPTIONS

--all, -a

Supprime tous les Quadlets pour l'utilisateur actuel.

--force, -f

Supprime les quadlets en cours d'exécution.

--ignore, -i

Ne pas générer d'erreur pour les Quadlets qui n'existent pas.

--reload-systemd

Recharge systemd après la suppression des Quadlets (valeur par défaut : true). Pour désactiver cette fonctionnalité, les utilisateurs doivent définir manuellement la valeur de ce drapeau à false.

EXEMPLES

$ podman quadlet rm myquadlet.container
myquadlet.container
