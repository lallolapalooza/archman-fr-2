PON(1) Debian PPPD PON(1)

NOM

pon, poff, plog - démarre, arrête ou liste le journal des connexions PPP

SYNTAXE

pon [ nom-isp [ options ] ]
poff [ -r ] [ -d ] [ -c ] [ -a ] [ -h ] [ nom-isp ]
plog [ arguments ]

DESCRIPTION

Cette page de manuel décrit les scripts pon, plog et poff, qui permettent aux utilisateurs de contrôler les connexions PPP.

pon

pon, invoqué sans arguments, exécute le fichier /etc/ppp/ppp_on_boot, s'il existe et est exécutable. Sinon, une connexion PPP sera démarrée en utilisant la configuration de /etc/ppp/peers/provider. C'est le comportement par défaut sauf si un argument nom-isp est donné.

Par exemple, pour utiliser la configuration du fournisseur d'accès Internet "monfournisseur", exécutez :

pon monfournisseur

pon utilisera alors le fichier d'options /etc/ppp/peers/monfournisseur. Vous pouvez également passer des options supplémentaires après le nom du fournisseur d'accès Internet. pon peut être utilisé pour exécuter plusieurs connexions PPP simultanées.

poff

poff ferme une connexion PPP. S'il existe plusieurs connexions PPP, celle nommée dans l'argument de poff sera arrêtée, par exemple :

poff monfournisseur2

arrêtera la connexion à monfournisseur2, et laissera les connexions PPP à, par exemple, "monfournisseur1" ou "monfournisseur3" actives et en cours d'exécution.

poff accepte les options de ligne de commande suivantes :

-r
provoque la reconnexion après la déconnexion.
-d
bascule l'état de l'option de débogage de pppd.
-c
provoque la renégociation de la compression par pppd(8).
-a
arrête toutes les connexions ppp actives. Si l'argument nom-isp est donné, il sera ignoré.
-h
affiche les informations d'aide.
-v
affiche la version et quitte.

Si aucun argument n'est donné, poff arrêtera ou signalera pppd si et seulement s'il y a exactement une connexion active. S'il y a plus d'une connexion active, il quittera avec un code d'erreur de 1.

plog

plog vous montre les dernières lignes de /var/log/ppp.log. Si ce fichier n'existe pas, il vous montre les dernières lignes de votre fichier /var/log/syslog, mais en excluant les lignes non générées par pppd. Ce script utilise la commande tail(1), donc les arguments qui peuvent être passés à tail(1) peuvent également être passés à plog.

Note : le script plog ne peut être utilisé que par root ou un autre administrateur système du groupe "adm", pour des raisons de sécurité. De plus, pour avoir toutes les informations générées par pppd dans un seul fichier journal, que plog peut afficher, vous devez avoir la ligne suivante dans votre fichier /etc/syslog.conf :

local2.* -/var/log/ppp.log

FICHIERS

/etc/ppp/options
Fichier d'options système de PPpd.
/etc/ppp/pap-secrets
Fichier des secrets PAP système.
/etc/ppp/chap-secrets
Fichier des secrets CHAP système.
/etc/ppp/peers/
Répertoire contenant les fichiers d'options du pair. Le fichier par défaut s'appelle provider.
/etc/chatscripts/provider
Le script chat invoqué depuis le fichier par défaut /etc/ppp/peers/provider.
/var/log/ppp.log
Le fichier journal PPP par défaut.
