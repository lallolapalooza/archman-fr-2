NOM

podman-pod-ps - Affiche les informations sur les pods

SYNTAXE

podman pod ps [options]

DESCRIPTION

podman pod ps liste les pods sur le système. Par défaut, il liste :

  • l'ID du pod
  • le nom du pod
  • l'heure de création du pod
  • le nombre de conteneurs attachés au pod
  • l'ID du conteneur d'infrastructure du pod
  • le statut du pod tel que défini par le tableau suivant
    Statut Description
    Créé Aucun conteneur en cours d'exécution ni arrêté
    En cours au moins un conteneur est en cours d'exécution
    Arrêté Au moins un conteneur arrêté et aucun en cours d'exécution
    Terminé Tous les conteneurs arrêtés dans le pod
    Mort Erreur lors de la récupération de l'état

OPTIONS

--ctr-ids

Affiche les identifiants des conteneurs.

--ctr-names

Affiche les noms des conteneurs.

--ctr-status

Affiche les statuts des conteneurs.

--filter, -f=filtre

Fournit les valeurs de filtrage.

Le format de l'argument filtres est de type clé=valeur. S'il y a plus d'un filtre, passez plusieurs OPTIONS : --filter foo=bar --filter bif=baz.

Filtres supportés :

Filtre Description
ctr-ids Filtre par ID de conteneur dans le pod. (Correspondance de préfixe CID par défaut ; accepte les expressions régulières)
ctr-names Filtre par nom de conteneur dans le pod.
ctr-number Filtre par nombre de conteneurs dans le pod.
ctr-status Filtre par statut de conteneur dans le pod.
id Filtre par ID de pod. (Correspondance de préfixe par défaut ; accepte les expressions régulières)
label Filtre par conteneur avec (ou sans, dans le cas où label!=[...] est utilisé) les étiquettes spécifiées.
name Filtre par nom de pod.
network Filtre par nom de réseau ou ID complet du réseau.
status Filtre par statut du pod.
until Filtre par pods créés avant une certaine date limite.

Les filtres ctr-ids, ctr-names, id, name acceptent le format regex.

Le filtre ctr-status accepte les valeurs : created, running, paused, stopped, exited, unknown.

Le filtre label accepte deux formats. L'un est label=clé ou label=clé=valeur, ce qui supprime les conteneurs avec les étiquettes spécifiées. L'autre format est label!=clé ou label!=clé=valeur, ce qui supprime les conteneurs sans les étiquettes spécifiées.

Le filtre until peut être des timestamps Unix, des timestamps formatés en date, ou des chaînes de durée Go (par exemple, 10m, 1h30m) calculées par rapport à l'heure de la machine.

Le filtre status accepte les valeurs : stopped, running, paused, exited, dead, created, degraded.

--format=format

Affiche joliment les conteneurs au format JSON ou à l'aide d'un modèle Go.

Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Espace réservé Description
.Cgroup Chemin cgroup du pod
.ContainerIds Liste des ID de conteneurs dans le pod, séparés par des virgules
.ContainerNames Liste des noms de conteneurs dans le pod, séparés par des virgules
.ContainerStatuses Liste des statuts des conteneurs, séparés par des virgules
.Created Heure de création du pod
.ID ID du conteneur
.InfraID ID du conteneur d'infrastructure du pod
.Label chaîne Étiquette spécifiée du pod
.Labels ... Toutes les étiquettes attribuées au pod
.Name Nom du pod
.Networks Affiche tous les réseaux connectés au conteneur d'infrastructure
.NumberOfContainers Affiche le nombre de conteneurs attachés au pod
.Restarts Affiche le nombre total de redémarrages de conteneurs dans un pod
.Status Statut du pod

--help, -h

Affiche un message d'utilisation.

--latest, -l

Affiche le dernier pod créé (tous états) (cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (à l'exception de WSL2)).

--namespace, --ns

Affiche les informations de l'espace de noms du pod.

--no-trunc

Ne pas tronquer la sortie (par défaut false).

--noheading, -n

Omis les en-têtes de table de la liste.

--quiet, -q

Affiche uniquement les identifiants numériques des pods.

--sort

Trie par date de création, ID, nom, statut ou nombre de conteneurs.

Par défaut : date de création

EXEMPLES

Lister tous les pods en cours d'exécution.

$ podman pod ps
POD ID         NOM              STATUT    CRÉÉ             INFRA ID       # DE CONTENEURS
00dfd6fa02c0   jolly_goldstine   En cours   31 heures ago     ba465ab0a3a4   1
f4df8692e116   nifty_torvalds    Créé     10 minutes ago   331693bff40a   2

Lister tous les pods en cours d'exécution ainsi que les noms des conteneurs à l'intérieur des pods.

$ podman pod ps --ctr-names
POD ID         NOM              STATUT    CRÉÉ             INFRA ID       NOMS
00dfd6fa02c0   jolly_goldstine   En cours   31 heures ago     ba465ab0a3a4   loving_archimedes
f4df8692e116   nifty_torvalds    Créé     10 minutes ago   331693bff40a   thirsty_hawking,wizardly_golick

Lister tous les pods en cours d'exécution ainsi que leurs statuts, noms et identifiants.

$ podman pod ps --ctr-status --ctr-names --ctr-ids
POD ID         NOM              STATUT    CRÉÉ             INFRA ID       IDS                         NOMS                              STATUT
00dfd6fa02c0   jolly_goldstine   En cours   31 heures ago     ba465ab0a3a4   ba465ab0a3a4                loving_archimedes                 running
f4df8692e116   nifty_torvalds    Créé     10 minutes ago   331693bff40a   331693bff40a,8e428daeb89e   thirsty_hawking,wizardly_golick   configured,configured

Lister tous les pods en cours d'exécution et afficher l'ID, les noms des conteneurs et les cgroups.

$ podman pod ps --format "{{.ID}}  {{.ContainerNames}}  {{.Cgroup}}"
00dfd6fa02c0   loving_archimedes   /libpod_parent
f4df8692e116   thirsty_hawking,wizardly_golick   /libpod_parent

Lister tous les pods en cours d'exécution avec deux conteneurs, triés par ID de pod.

$ podman pod ps --sort id --filter ctr-number=2
POD ID         NOM             STATUT    CRÉÉ             INFRA ID       # DE CONTENEURS
f4df8692e116   nifty_torvalds   Créé     10 minutes ago   331693bff40a   2

Lister tous les pods en cours d'exécution avec leurs identifiants de conteneurs.

$ podman pod ps  --ctr-ids
POD ID         NOM              STATUT    CRÉÉ             INFRA ID       IDS
00dfd6fa02c0   jolly_goldstine   En cours   31 heures ago     ba465ab0a3a4   ba465ab0a3a4
f4df8692e116   nifty_torvalds    Créé     10 minutes ago   331693bff40a   331693bff40a,8e428daeb89e

Lister tous les pods en cours d'exécution avec les identifiants des conteneurs sans tronquer les identifiants.

$ podman pod ps --no-trunc --ctr-ids

NAME

                    
podman-pod-ps - Print a list of pods

                

                

                    
SYNOPSIS

                    
podman pod ps [options]

                

                

                    
DESCRIPTION

                    
The podman pod ps command prints a list of pods on the system.

                

                

                    
OPTIONS

                    

                        
-a, --all

                        
Do not omit exited pods when listing pods.

                        
--ctr-ids

                        
Print the container IDs.

                        
--ctr-names

                        
Print the container names.

                        
--filter, -f condition

                        
Filter output based on conditions. Valid conditions are:

                        

                            
    
                                
  • id=pattern Print pods matching the given pod ID pattern.
    • 
                                
  • label=key=value, label!=key=value Filter pods by labels.
    • 
                                
  • name=pattern Print pods matching the given pod name pattern.
    • 
                                
  • status=status Print pods based on their status. Valid statuses are: created, running, paused, restarting, removing, exited, dead, or degraded.
    • 
                                
  • until=timestamp Print pods with creation time less than or equal to the specified timestamp. The timestamp can be a duration, Unix timestamp, or RFC3339 date. Valid duration formats: d, h, m, s (e.g. 2h, 30m).
    • 
                            

                        

                        
--format Go-template

                        
Pretty-print pods using a Go template.

                        
--help, -h

                        
Print usage statement for the command.

                        
--latest, -l

                        
Show the latest created pod.

                        
--no-trunc

                        
Do not truncate output.

                        
--pod-id-ளவு, --pod-id-version

                        
Use a different version of the pod ID digest algorithm.

                        
--size, -s

                        
Use the --size option to display the approximate size of pods.

                        
--sync-container-ids

                        
Synchronize container IDs from the storage driver to the state.

List all running pods

                    
$ podman pod ps
