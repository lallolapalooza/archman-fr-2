NOM

podman-secret-ls - Lister tous les secrets disponibles

SYNTAXE

podman secret ls [options]

DESCRIPTION

Liste tous les secrets existants. La sortie peut être formatée en modèle Go en utilisant l'option --format.

OPTIONS

--filter, -f=filtre=valeur

Filtre la sortie en fonction des conditions données. Plusieurs filtres peuvent être utilisés en répétant l'option --filter.

Les filtres valides sont listés ci-dessous :

Filtre Description
name [Nom] Nom du secret (accepte les expressions régulières)
id [ID] ID du secret complet ou partiel

--format=format

Formate la sortie des secrets en utilisant un modèle Go.

Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Espace réservé Description
.CreatedAt Quand le secret a été créé (horodatage relatif, lisible par l'homme)
.Driver Nom du pilote (chaîne de caractères)
.ID ID du secret
.Name Nom du secret
.UpdatedAt Quand le secret a été mis à jour pour la dernière fois (horodatage relatif, lisible par l'homme)

--noheading, -n

Omet les en-têtes de table de la liste.

--quiet, -q

Affiche uniquement les ID des secrets.

EXEMPLES

Lister tous les secrets.

$ podman secret ls

Lister le champ nom de tous les secrets.

$ podman secret ls --format "{{.Name}}"

Lister tous les secrets dont le nom contient la chaîne spécifiée.

$ podman secret ls --filter name=confidential
