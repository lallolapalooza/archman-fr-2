podman-pod-kill(1) Manuel des commandes générales podman-pod-kill(1)

NOM

podman-pod-kill - Arrête le processus principal de chaque conteneur dans un ou plusieurs pods

SYNOPIS

podman pod kill [options] pod ...

DESCRIPTION

Le processus principal de chaque conteneur à l'intérieur des pods spécifiés reçoit le signal SIGKILL, ou tout autre signal spécifié avec l'option --signal.

OPTIONS

--all, -a

Envoie le signal à tous les conteneurs associés à un pod.

--latest, -l

Au lieu de fournir le nom ou l'ID du pod, utilise le dernier pod créé. Note : le dernier pod démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (sauf WSL2)).

--signal, -s=signal

Signal à envoyer aux conteneurs du pod. Pour plus d'informations sur les signaux Linux, référez-vous à signal(7). La valeur par défaut est SIGKILL.

EXEMPLE

Arrêter un pod avec un nom donné :

podman pod kill mywebserver

Arrêter un pod avec un ID donné :

podman pod kill 860a4b23

Terminer un pod en envoyant le signal TERM :

podman pod kill --signal TERM 860a4b23

Arrêter le dernier pod. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (sauf WSL2)) :

podman pod kill --latest

Terminer tous les pods en envoyant le signal KILL :

podman pod kill --all

VOIR AUSSI

podman(1), podman-pod(1), podman-pod-stop(1)
