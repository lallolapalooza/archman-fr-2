NOM

podman-secret-rm - Supprimer un ou plusieurs secrets

SYNOPIS

podman secret rm [options] secret [...]

DESCRIPTION

Supprime un ou plusieurs secrets.

podman secret rm peut être utilisé en toute sécurité sur des secrets utilisés par un conteneur. Le conteneur créé a accès aux données secrètes car les secrets sont copiés et montés dans le conteneur lorsqu'un conteneur est créé. Si un secret est supprimé et qu'un autre secret est créé avec le même nom, le secret à l'intérieur du conteneur ne change pas ; l'ancienne valeur du secret reste.

OPTIONS

--all, -a

Supprime tous les secrets existants.

--help

Affiche le message d'utilisation.

--ignore, -i

Ignore les erreurs lorsque les secrets spécifiés ne sont pas présents.

EXEMPLES

Supprimer les secrets mysecret1 et mysecret2.

$ podman secret rm mysecret1 mysecret2

Supprimer tous les secrets

$ podman secret rm --all
3fa78977c813cca1d5b1a4570
4ee314533b16a47d0d8c6e775

Supprime les secrets spécifiés. Aucune erreur n'est générée si un secret inexistant est inclus.

$ podman secret rm --ignore mysecret1 mysecret2 non_existent_secret
9bb0cad56c4a610da8ebca0cc
3c497981215f1b5dd9ce19cde
