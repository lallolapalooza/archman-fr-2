NOM

podman-manifest-annotate - Ajoute et met à jour des informations sur une image ou un artefact dans une liste de manifestes ou un index d'images

SYNOPSIS

podman manifest annotate [options] nomdelisteouindex digestouimageouartefactdemonmanifeste

DESCRIPTION

Ajoute ou met à jour des informations sur une image ou un artefact inclus dans une liste de manifestes ou un index d'images.

OPTIONS

--annotation=annotation=valeur

Définit une annotation sur l'entrée de l'image ou de l'artefact spécifié.

Si --index est également spécifié, l'annotation est définie sur l'index d'images entier.

--arch=architecture

Remplace l'architecture que la liste ou l'index enregistre comme exigence pour l'image. Ceci est généralement récupéré automatiquement à partir des informations de configuration de l'image, il est donc rarement nécessaire d'utiliser cette option.

--features=fonctionnalité

Spécifie la liste des fonctionnalités que la liste ou l'index enregistre comme exigences pour l'image. Cette option est rarement utilisée.

--index

Traite les arguments de l'option --annotation comme des valeurs d'annotation à définir sur l'index d'images lui-même plutôt que sur une entrée de l'index d'images. Implicite pour --subject.

--os=OS

Remplace le système d'exploitation que la liste ou l'index enregistre comme exigence pour l'image. Ceci est généralement récupéré automatiquement à partir des informations de configuration de l'image, il est donc rarement nécessaire d'utiliser cette option.

--os-features=fonctionnalité

Spécifie la liste des fonctionnalités du système d'exploitation que la liste ou l'index enregistre comme exigences pour l'image. Cette option est rarement utilisée.

--os-version=version

Spécifie la version du système d'exploitation que la liste ou l'index enregistre comme exigence pour l'image. Cette option est rarement utilisée.

--subject=nomImage

Définit le champ subject dans l'index d'images pour marquer l'index d'images comme étant associé à l'image spécifiée d'une manière ou d'une autre. Un index d'images ne peut être associé qu'à un seul sujet au maximum.

--variant

Spécifie la variante que la liste ou l'index enregistre pour l'image. Cette option est généralement utilisée pour distinguer plusieurs entrées qui partagent la même valeur d'architecture, mais qui attendent différentes versions de son jeu d'instructions.

EXEMPLES

Met à jour les informations d'architecture et de variante pour la liste de manifestes spécifiée pour l'image :

podman manifest annotate --arch arm64 --variant v8 mylist:v1.11 sha256:59eec8837a4d942cc19a52b8c09ea75121acc38114a2c68b98983ce9356b8610
07ec8dc22b5dba3a33c60b68bce28bbd2b905e383fdb32a90708fa5eeac13a07: sha256:59eec8837a4d942cc19a52b8c09ea75121acc38114a2c68b98983ce9356b8610
