powerof2(3) Manuel des fonctions de bibliothèque powerof2(3)

NOM

powerof2 - tester si une valeur est une puissance de 2

BIBLIOTHÈQUE

Bibliothèque C standard (libc)

SYNTAXE

#include <sys/param.h>
int powerof2(x);

DESCRIPTION

Cette macro retourne vrai si x est une puissance de 2, et faux sinon.

0 est considéré comme une puissance de 2. Cela peut avoir du sens en considérant le retournement des entiers non signés, et possède des propriétés intéressantes.

VALEUR DE RETOUR

Vrai ou faux, si x est une puissance de 2 ou non, respectivement.

NORMES

BSD.

ATTENTION

Les arguments peuvent être évalués plus d'une fois.

Étant donné que cette macro est implémentée à l'aide d'opérations bit à bit, certaines valeurs négatives peuvent entraîner un comportement indéfini. Par exemple, ce qui suit entraîne un comportement indéfini : powerof2(INT_MIN);. Appelez-la uniquement avec des types non signés pour être sûr.

VOIR AUSSI

stdc_bit_ceil(3), stdc_bit_floor(3)
