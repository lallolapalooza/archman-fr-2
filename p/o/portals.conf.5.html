PORTALS.CONF(5) Manuel des formats de fichiers PORTALS.CONF(5)

NOM

portals.conf - Configuration des portails de bureau XDG

SYNTAXE

$XDG_CONFIG_HOME/xdg-desktop-portal/{*-}portals.conf

$XDG_CONFIG_DIRS/xdg-desktop-portal/{*-}portals.conf

/etc/xdg-desktop-portal/{*-}portals.conf

$XDG_DATA_HOME/xdg-desktop-portal/{*-}portals.conf

$XDG_DATA_DIRS/xdg-desktop-portal/{*-}portals.conf

/usr/share/xdg-desktop-portal/{*-}portals.conf

DESCRIPTION

xdg-desktop-portal utilise un fichier de configuration pour déterminer quel backend de portail doit être utilisé pour fournir l'implémentation de l'interface demandée. Ce mécanisme est très similaire à la spécification freedesktop.org pour "l'Association entre les types MIME et les applications" (mime-apps).

Les environnements de bureau et les fournisseurs de systèmes d'exploitation doivent fournir une configuration par défaut pour leurs backends de portail choisis dans /usr/share/xdg-desktop-portal/DESKTOP-portals.conf, où DESKTOP est le nom de l'environnement de bureau tel qu'il apparaîtrait dans la variable d'environnement XDG_CURRENT_DESKTOP, après conversion des majuscules ASCII en minuscules. Par exemple, KDE doit fournir /usr/share/xdg-desktop-portal/kde-portals.conf.

Les utilisateurs peuvent remplacer ces valeurs par défaut, ou fournir une configuration pour un environnement de bureau non pris en charge, en écrivant un fichier ~/.config/xdg-desktop-portal/portals.conf. Les utilisateurs de plus d'un environnement de bureau peuvent utiliser des noms de fichiers spécifiques à l'environnement de bureau tels que kde-portals.conf qui ne seront utilisés que dans l'environnement de bureau approprié.

De même, les administrateurs système peuvent fournir une configuration par défaut pour tous les utilisateurs dans /etc/xdg-desktop-portal/DESKTOP-portals.conf ou /etc/xdg-desktop-portal/portals.conf.

Les emplacements suivants sont recherchés pour la configuration, avec la priorité la plus élevée en premier :

  • $XDG_CONFIG_HOME, qui par défaut est ~/.config
  • chaque répertoire dans $XDG_CONFIG_DIRS, qui par défaut est /etc/xdg
  • le répertoire de configuration système (sysconfdir) de xdg-desktop-portal au moment de la compilation, généralement /etc
  • $XDG_DATA_HOME, qui par défaut est ~/.local/share (recherché uniquement par souci de cohérence avec d'autres spécifications, l'écriture de configuration ici n'est pas recommandée)
  • chaque répertoire dans $XDG_DATA_DIRS, qui par défaut est /usr/local/share:/usr/share
  • le répertoire de données (datadir) de xdg-desktop-portal au moment de la compilation, généralement /usr/share

Dans chacun de ces emplacements, pour chaque nom d'environnement de bureau répertorié dans la variable d'environnement XDG_CURRENT_DESKTOP, xdg-desktop-portal recherche xdg-desktop-portal/DESKTOP-portals.conf, où DESKTOP est le nom de l'environnement de bureau en minuscules. Si un fichier de configuration spécifique à l'environnement de bureau n'est pas trouvé, un fichier non spécifique à l'environnement de bureau xdg-desktop-portal/portals.conf sera lu. Par exemple, si XDG_CURRENT_DESKTOP est défini sur Budgie:GNOME, alors xdg-desktop-portal recherchera xdg-desktop-portal/budgie-portals.conf, xdg-desktop-portal/gnome-portals.conf et xdg-desktop-portal/portals.conf dans cet ordre.

Seul le premier fichier de configuration trouvé est lu, et les fichiers de configuration de moindre priorité sont ignorés. Tous les fichiers de configuration possibles dans un répertoire sont essayés avant de passer au répertoire suivant, de sorte que, par exemple, ~/.config/xdg-desktop-portal/portals.conf a une priorité plus élevée que /usr/share/xdg-desktop-portal/kde-portals.conf.

FORMAT DU FICHIER

Le format du fichier de configuration des portails est le même format .ini utilisé par les fichiers d'unité systemd ou les fichiers de bureau d'application.

[preferred]

Le groupe de configuration principal pour les portails préférés.

Les clés suivantes peuvent être présentes dans le groupe preferred :

default (chaîne)

Le backend de portail par défaut à utiliser pour chaque interface, sauf si l'interface est listée explicitement.

org.freedesktop.impl.portal.* (chaîne)

Une des implémentations d'interface de portail valides exposées par xdg-desktop-portal.

Chaque clé du groupe contient une liste d'implémentations de backend de portail séparées par des points-virgules, à rechercher pour une implémentation de l'interface demandée, dans le même ordre que celui spécifié dans le fichier de configuration. De plus, les valeurs spéciales none et * peuvent être utilisées :

none

Ne pas fournir d'implémentation de portail pour cette interface.

*

Utiliser la première implémentation de portail trouvée, par ordre lexicographique.

EXEMPLE

[preferred]
# Utiliser xdg-desktop-portal-gtk pour toutes les interfaces de portail...
default=gtk
# ... sauf pour l'interface ScreenCast
org.freedesktop.impl.portal.ScreenCast=gnome

ENVIRONNEMENT

XDG_CURRENT_DESKTOP

Une liste d'environnements de bureau séparés par des deux-points, le plus spécifique en premier, utilisée pour choisir une configuration de portail spécifique à l'environnement de bureau. La valeur par défaut est une liste vide.

XDG_CONFIG_HOME

Le fichier portals.conf propre à l'utilisateur se trouve dans ce répertoire. La valeur par défaut est $HOME/.config.

XDG_CONFIG_DIRS

Une liste de répertoires de configuration système et de répertoires de configuration secondaires propres à l'utilisateur, séparés par des deux-points. La valeur par défaut est /etc/xdg.

XDG_DATA_HOME

Un répertoire de données propre à l'utilisateur, recherché par souci de cohérence avec d'autres spécifications. La valeur par défaut est $HOME/.local/share.

XDG_DATA_DIRS

Une liste de répertoires de données système et de répertoires de données secondaires propres à l'utilisateur, séparés par des deux-points. La valeur par défaut est /usr/local/share:/usr/share.
