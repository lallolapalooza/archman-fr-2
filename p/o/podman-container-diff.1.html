NOM

podman-container-diff - Inspecter les modifications sur le système de fichiers d'un conteneur

SYNTAXE

podman container diff [options] conteneur [conteneur]

DESCRIPTION

Affiche les modifications sur le système de fichiers d'un conteneur. Le conteneur est comparé à sa couche parente ou au second argument s'il est fourni.

La sortie est précédée des symboles suivants :

Symbole Description
A Un fichier ou un répertoire a été ajouté.
D Un fichier ou un répertoire a été supprimé.
C Un fichier ou un répertoire a été modifié.

OPTIONS

--format

Modifier le format de sortie. Le seul format valide pour podman container diff est json.

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utiliser le dernier conteneur créé. Note : le dernier conteneur démarré peut appartenir à d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (hors WSL2)).

EXEMPLES

# podman container diff conteneur1
C /usr
C /usr/local
C /usr/local/bin
A /usr/local/bin/docker-entrypoint.sh
$ podman container diff --format json conteneur1 conteneur2
{
     "added": [
          "/test"
     ]
}
$ podman container diff --latest
C /etc
