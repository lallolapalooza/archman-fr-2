NOM

pod2html - convertir les fichiers .pod en fichiers .html

SYNTAXE

pod2html --help --htmldir=<nom> --htmlroot=<URL>
         --infile=<nom> --outfile=<nom>
         --podpath=<nom>:...:<nom> --podroot=<nom>
         --cachedir=<nom> --flush --recurse --norecurse
         --quiet --noquiet --verbose --noverbose
         --index --noindex --backlink --nobacklink
         --header --noheader --poderrors --nopoderrors
         --css=<URL> --title=<nom>

DESCRIPTION

Convertit les fichiers du format pod (voir perlpod) au format HTML.

ARGUMENTS

pod2html accepte les arguments suivants :

backlink
--backlink
--nobacklink

Transforme les directives =head1 en liens pointant vers le haut du fichier HTML. --nobacklink (ce qui est le comportement par défaut) ne crée pas ces liens retour.

cachedir
--cachedir=nom

Spécifie quel répertoire est utilisé pour stocker le cache. Le répertoire par défaut est le répertoire de travail courant.

css
--css=URL

Spécifie l'URL de la feuille de style en cascade à lier depuis le fichier HTML résultant. Par défaut, aucune feuille de style n'est utilisée.

flush
--flush

Vide le cache.

header
--header
--noheader

Crée des blocs d'en-tête et de pied de page contenant le texte de la section "NOM". --noheader - ce qui est le comportement par défaut - ne crée pas de blocs d'en-tête ou de pied de page.

help
--help

Affiche le message d'utilisation.

htmldir
--htmldir=nom

Définit le répertoire auquel tous les renvois dans le fichier HTML résultant seront relatifs. Ne pas passer cet argument rend tous les liens absolus car c'est la valeur qui indique à Pod::Html la racine de l'arbre de documentation.

N'utilisez pas cet argument et --htmlroot dans le même appel à pod2html ; ils sont mutuellement exclusifs.

htmlroot
--htmlroot=URL

Définit l'URL de base pour les fichiers HTML. Lorsque des renvois sont effectués, la racine HTML est ajoutée en préfixe à l'URL.

N'utilisez pas cet argument si des liens relatifs sont souhaités : utilisez --htmldir à la place.

Ne pas passer cet argument et --htmldir à pod2html ; ils sont mutuellement exclusifs.

index
--index

Génère un index en haut du fichier HTML (comportement par défaut).

noindex
--noindex

Ne génère pas d'index en haut du fichier HTML.

infile
--infile=nom

Spécifie le fichier pod à convertir. L'entrée est prise de STDIN si aucun fichier d'entrée n'est spécifié.

outfile
--outfile=nom

Spécifie le fichier HTML à créer. La sortie va vers STDOUT si aucun fichier de sortie n'est spécifié.

poderrors
--poderrors
--nopoderrors

Inclut une section "ERREURS POD" dans le fichier de sortie s'il y a eu des erreurs POD dans le fichier d'entrée (comportement par défaut). --nopoderrors ne crée pas cette section "ERREURS POD".

podpath
--podpath=nom:...:nom

Spécifie quels sous-répertoires du podroot contiennent des fichiers pod dont les formes HTML converties peuvent être liées dans des renvois.

podroot
--podroot=nom

Spécifie le répertoire de base pour trouver les pods de bibliothèque.

quiet
--quiet
--noquiet

Ne pas afficher les messages d'avertissement la plupart du temps inoffensifs. --noquiet - ce qui est le comportement par défaut - affiche ces messages d'avertissement la plupart du temps inoffensifs (mais ce n'est pas la même chose que le mode "verbose").

recurse
--recurse
--norecurse

Récis dans les sous-répertoires spécifiés dans podpath (comportement par défaut). --norecurse ne récise pas dans ces sous-répertoires.

title
--title=titre

Spécifie le titre du fichier HTML résultant.

verbose
--verbose
--noverbose

Affiche les messages de progression. --noverbose - ce qui est le comportement par défaut - n'affiche pas ces messages de progression.
