POSIX_TRACE_ATTR_DESTROY(3P) Manuel du programmeur POSIX POSIX_TRACE_ATTR_DESTROY(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_trace_attr_destroy, posix_trace_attr_init — détruire et initialiser l'objet attributs du flux de trace (TRACING)

SYNTAXE

#include <trace.h>
int posix_trace_attr_destroy(trace_attr_t *attr);
int posix_trace_attr_init(trace_attr_t *attr);

DESCRIPTION

La fonction posix_trace_attr_destroy() détruit un objet attributs de trace initialisé. Un objet attributs attr détruit peut être réinitialisé à l'aide de posix_trace_attr_init() ; les résultats de toute référence à l'objet après sa destruction sont indéfinis.

La fonction posix_trace_attr_init() initialise un objet attributs de trace attr avec la valeur par défaut pour tous les attributs individuels utilisés par une implémentation donnée. Les attributs en lecture seule generation-version et clock-resolution du nouvel objet attributs de trace initialisé seront définis à leurs valeurs appropriées (voir Section 2.11.1.2, Structure posix_trace_status_info).

Les résultats sont indéfinis si posix_trace_attr_init() est appelée en spécifiant un objet attributs attr déjà initialisé.

Les implémentations peuvent ajouter des extensions à la structure de l'objet attributs de trace comme le permet le volume Bases Définitions de POSIX.1‐2017, Chapitre 2, Conformité.

L'objet attributs résultant (éventuellement modifié en définissant les valeurs des attributs individuels), lorsqu'il est utilisé par posix_trace_create(), définit les attributs du flux de trace créé. Un seul objet attributs peut être utilisé dans plusieurs appels à posix_trace_create(). Après qu'un ou plusieurs flux de trace ont été créés à l'aide d'un objet attributs, toute fonction affectant cet objet attributs, y compris sa destruction, n'affectera aucun flux de trace précédemment créé. Un objet attributs initialisé sert également à recevoir les attributs d'un flux de trace ou d'un journal de trace existant lors de l'appel de la fonction posix_trace_get_attr().

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient la valeur zéro. Sinon, elles renvoient le numéro d'erreur correspondant.

ERREURS

La fonction posix_trace_attr_destroy() peut échouer si :

EINVAL
La valeur de attr est invalide.

La fonction posix_trace_attr_init() peut échouer si :

ENOMEM
Il n'y a pas assez de mémoire pour initialiser l'objet attributs de trace.
