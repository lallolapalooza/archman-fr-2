NOM

podman-image-unmount - Démonter le système de fichiers racine d'une image

SYNTAXE

podman image unmount [options] image [...]

podman image umount [options] image [...]

DESCRIPTION

Démonte le système de fichiers racine des images spécifiées, si aucun autre processus ne l'utilise.

Le stockage des images incrémente un compteur de montage à chaque fois qu'une image est montée. Lorsqu'une image est démontée, le compteur de montage est décrémenté, et le système de fichiers racine de l'image est physiquement démonté uniquement lorsque le compteur de montage atteint zéro, indiquant qu'aucun autre processus n'utilise le montage. Un démontage peut être forcé avec l'option --force.

OPTIONS

--all, -a

Toutes les images actuellement montées sont démontées.

--force, -f

Force le démontage du système de fichiers racine des images spécifiées, même si d'autres processus l'ont monté.

Note : Les autres processus utilisant le système de fichiers peuvent échouer si le point de montage est supprimé sans leur connaissance.

EXEMPLE

Démonter une image avec un ID donné :

podman image unmount imageID

Démonter plusieurs images avec des IDs donnés :

podman image unmount imageID1 imageID2 imageID3

Démonter toutes les images :

podman image unmount --all

Forcer le démontage de l'image avec un ID donné :

podman image unmount --force imageID
