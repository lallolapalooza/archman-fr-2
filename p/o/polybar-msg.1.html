POLYBAR-MSG(1) Manuel utilisateur Polybar POLYBAR-MSG(1)

NOM

polybar-msg - Envoyer des messages IPC à polybar

SYNTAXE

polybar-msg [OPTIONS] action chaine-action
polybar-msg [OPTIONS] action module action [données]
polybar-msg [OPTIONS] cmd commande

DESCRIPTION

Polybar permet un contrôle externe via des actions et des commandes. Les actions contrôlent les modules individuels et les commandes contrôlent la barre elle-même.

La documentation IPC complète est liée à la fin de ce document.

Les actions disponibles dépendent du module cible. Pour les actions, la charge utile est soit une chaîne d'action unique, soit le nom du module, le nom de l'action et la chaîne de données optionnelle spécifiée séparément.

Pour que polybar-msg puisse envoyer un message à un processus polybar en cours d'exécution, la barre doit avoir l'IPC activé et polybar-msg ainsi que polybar doivent s'exécuter sous le même utilisateur.

OPTIONS

-h, --help
Afficher le texte d'aide et quitter
-p PID
Envoyer le message uniquement au processus polybar exécuté sous l'identifiant de processus donné. Si non spécifié, le message est envoyé à tous les processus polybar en cours d'exécution.

EXEMPLES

polybar-msg cmd quit
Terminer toutes les instances polybar en cours d'exécution.

polybar-msg action monmodule module_hide

polybar-msg action "#monmodule.module_hide"
Masquer le module nommé monmodule. La première variante spécifie les noms du module et de l'action séparément, la seconde utilise une chaîne d'action.
