podman-container-inspect(1) Manuel des commandes générales podman-container-inspect(1)

NOM

podman container inspect - Affiche la configuration d'un conteneur

SYNTAXE

podman container inspect [options] conteneur [conteneur ...]

DESCRIPTION

Affiche les informations de bas niveau sur les conteneurs identifiés par leur nom ou leur ID. Par défaut, cela affiche tous les résultats dans un tableau JSON. Si un format est spécifié, le modèle donné est exécuté pour chaque résultat.

OPTIONS

--format, -f=format

Formate la sortie en utilisant le modèle Go spécifié. Les clés du JSON renvoyé peuvent être utilisées comme valeurs pour l'option --format (voir les exemples ci-dessous).

Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Espace réservé Description
.AppArmorProfile Profil AppArmor (chaîne)
.Args Arguments de ligne de commande (tableau de chaînes)
.BoundingCaps Ensemble des capacités bornées (tableau de chaînes)
.Config ... Structure avec des informations de configuration
.ConmonPidFile Chemin d'accès au fichier contenant le PID de conmon (chaîne)
.Created ... Heure de création du conteneur (chaîne, ISO3601)
.Dependencies Dépendances (tableau de chaînes)
.Driver Pilote de stockage (chaîne)
.EffectiveCaps Ensemble des capacités effectives (tableau de chaînes)
.ExecIDs IDs d'exécution (tableau de chaînes)
.GraphDriver ... Détails supplémentaires du pilote graphique (struct)
.HostConfig ... Détails de la configuration hôte (struct)
.HostnamePath Chemin d'accès au fichier contenant le nom d'hôte (chaîne)
.HostsPath Chemin d'accès au fichier /etc/hosts du conteneur (chaîne)
.ID ID du conteneur (hash complet de 64 caractères)
.Image ID de l'image du conteneur (hash de 64 caractères)
.ImageDigest Résumé de l'image du conteneur (sha256:+hash de 64 caractères)
.ImageName Nom de l'image du conteneur (chaîne)
.IsInfra Est-ce un conteneur d'infrastructure ? (chaîne : vrai/faux)
.IsService Est-ce un conteneur de service ? (chaîne : vrai/faux)
.KubeExitCodePropagation Propagation du code de sortie Kube (chaîne)
.LockNumber Numéro du verrou Libpod du conteneur
.MountLabel Label SELinux du montage (chaîne)
.Mounts Montages (tableau de chaînes)
.Name Nom du conteneur (chaîne)
.Namespace Espace de noms du conteneur (chaîne)
.NetworkSettings ... Paramètres réseau (struct)
.OCIConfigPath Chemin d'accès au fichier de configuration OCI (chaîne)
.OCIRuntime Nom du runtime OCI (chaîne)
.Path Chemin d'accès à la commande du conteneur (chaîne)
.PidFile Chemin d'accès au fichier contenant le PID du conteneur (chaîne)
.Pod Pod parent (chaîne)
.ProcessLabel Label SELinux du processus (chaîne)
.ResolvConfPath Chemin d'accès au fichier resolv.conf du conteneur (chaîne)
.RestartCount Nombre de redémarrages du conteneur (int)
.Rootfs Rootfs du conteneur (chaîne)
.SizeRootFs Taille du rootfs, en octets [1]
.SizeRw Taille de la couche supérieure (R/W) du conteneur, en octets [1]
.State ... Informations sur l'état du conteneur (struct)
.StaticDir Chemin d'accès au répertoire de métadonnées du conteneur (chaîne)
.UseImageHostname Utiliser le fichier /etc/hostname de l'image s'il existe ? (chaîne : vrai/faux)
.UseImageHosts Utiliser le fichier /etc/hosts de l'image ? (chaîne : vrai/faux)

[1] Ce spécificateur de format nécessite l'option --size

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utilise le dernier conteneur créé. Note : le dernier conteneur démarré peut appartenir à d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (à l'exclusion de WSL2))

--size, -s

En plus de la sortie normale, affiche la taille totale du fichier si le type est un conteneur.
