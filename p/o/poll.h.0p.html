poll.h(0P) Manuel du programmeur POSIX poll.h(0P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

poll.h — définitions pour la fonction poll()

SYNOPIS

#include <poll.h>

DESCRIPTION

L'en-tête <poll.h> définira la structure pollfd, qui contiendra au moins les membres suivants :

int    fd       Le descripteur de fichier interrogé.
short  events   Les indicateurs d'événements d'entrée (voir ci-dessous).
short  revents  Les indicateurs d'événements de sortie (voir ci-dessous).

L'en-tête <poll.h> définira le type suivant via typedef :

nfds_t
Un type entier non signé utilisé pour le nombre de descripteurs de fichier.

L'implémentation prendra en charge un ou plusieurs environnements de programmation dans lesquels la largeur de nfds_t n'est pas supérieure à la largeur du type long. Les noms de ces environnements de programmation peuvent être obtenus en utilisant la fonction confstr() ou l'utilitaire getconf.

L'en-tête <poll.h> définira les constantes symboliques suivantes, dont zéro ou plus peuvent être combinées par OR pour former les membres events ou revents dans la structure pollfd :

POLLIN
Des données autres que des données de haute priorité peuvent être lues sans bloquer.
POLLRDNORM
Des données normales peuvent être lues sans bloquer.
POLLRDBAND
Des données prioritaires peuvent être lues sans bloquer.
POLLPRI
Des données de haute priorité peuvent être lues sans bloquer.
POLLOUT
Des données normales peuvent être écrites sans bloquer.
POLLWRNORM
Équivalent à POLLOUT.
POLLWRBAND
Des données prioritaires peuvent être écrites.
POLLERR
Une erreur s'est produite (revents uniquement).
POLLHUP
Le périphérique a été déconnecté (revents uniquement).
POLLNVAL
Membre fd invalide (revents uniquement).

La signification et la sémantique des données normales, prioritaires et de haute priorité sont spécifiques au fichier et au périphérique.

La déclaration suivante sera celle d'une fonction et pourra également être définie comme une macro. Une prototype de fonction sera fourni.

int   poll(struct pollfd [], nfds_t, int);
