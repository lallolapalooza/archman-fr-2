NOM

podman-images - Lister les images dans le stockage local

SYNOPSIS

podman images [options] [image]

podman image list [options] [image]

podman image ls [options] [image]

DESCRIPTION

Affiche les images stockées localement, leurs noms et leurs identifiants.

OPTIONS

--all, -a

Afficher toutes les images (par défaut, filtrer les couches d'images intermédiaires). La valeur par défaut est false.

--digests

Afficher les digests d'images.

--filter, -f=filtre

Fournir des valeurs de filtre.

Le format de l'argument filtres est clé=valeur ou clé!=valeur. S'il y a plus d'un filtre, passer plusieurs OPTIONS : --filter foo=bar --filter bif=baz.

Filtres supportés :

Filtre Description
id Filtrer par identifiant d'image.
before Filtrer par images créées avant l'IMAGE donnée (nom ou tag).
containers Filtrer par images avec un conteneur en cours d'exécution.
dangling Filtrer par images orphelines (inutilisées).
digest Filtrer par digest.
intermediate Filtrer par images orphelines sans enfants.
label Filtrer par images avec (ou sans, dans le cas où label!=[...] est utilisé) les labels spécifiés.
manifest Filtrer par images qui sont des listes de manifeste.
readonly Filtrer par images en lecture seule ou en lecture/écriture.
reference Filtrer par nom d'image.
after/since Filtrer par images créées après l'IMAGE donnée (nom ou tag).
until Filtrer par images créées jusqu'à la durée ou l'heure donnée.

Le filtre id accepte la chaîne d'identifiant d'image.

Le filtre before accepte les formats : <nom-image>[:<tag>], <identifiant-image> ou <image@digest>.

Le filtre containers affiche les images qui ont un conteneur en cours d'exécution basé sur cette image.

Le filtre dangling affiche les images qui occupent de l'espace disque et ne servent à rien. Une image orpheline est une couche de système de fichiers qui a été utilisée dans une construction précédente d'une image et qui n'est plus référencée par aucune image. Elles sont désignées par le tag <none>, consomment de l'espace disque et n'ont pas de but actif.

Le filtre digest accepte la chaîne du digest d'image.

Le filtre intermediate affiche les images qui sont orphelines et n'ont pas d'enfants.

Le filtre label accepte deux formats. L'un est label=clé ou label=clé=valeur, qui affiche les images avec les labels spécifiés. L'autre format est label!=clé ou label!=clé=valeur, qui affiche les images sans les labels spécifiés.

Le filtre manifest affiche les images qui sont des listes de manifeste.

Le filtre readonly affiche, par défaut, les images en lecture seule et en lecture/écriture. Les images en lecture seule peuvent être configurées en modifiant les additionalimagestores dans le fichier /etc/containers/storage.conf.

Le filtre reference accepte le motif d'une référence d'image <nom-image>[:<tag>].

Les filtres after ou since acceptent les formats : <nom-image>[:<tag>], <identifiant-image> ou <image@digest>.

Le filtre until accepte les formats : durée Golang, heure RFC3339, ou un horodatage Unix et affiche toutes les images créées jusqu'à cette heure.

--format=format

Modifier le format de sortie par défaut. Il peut s'agir d'un type supporté comme 'json' ou d'un modèle Go. Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Espace réservé Description
.Containers Nombre de conteneurs utilisant cette image
.Created Temps écoulé depuis la création de l'image
.CreatedAt Heure de création de l'image, AAAA-MM-JJ HH:MM:SS +nnnn
.CreatedSince Identique à .Created
.CreatedTime Identique à .CreatedAt
.Dangling Identique à .IsDangling
.Digest Digest de l'image
.History Historique de la couche d'image
.ID Identifiant de l'image (tronqué)
.Id Identifiant de l'image (SHA complet)
.IsDangling L'image est-elle orpheline ? (vrai/faux)
.IsReadOnly L'image est-elle en lecture seule ? (vrai/faux)
.Labels ... map[] de labels
.Names Nom qualifié complet (FQIN) de l'image
.ParentId SHA complet de l'identifiant de l'image parente, ou null (chaîne)
.ReadOnly Identique à .IsReadOnly
.RepoDigests map[] de zéro ou plusieurs chaînes repo/nom@sha256:SHA
.Repository Dépôt de l'image
.RepoTags map[] de zéro ou plusieurs chaînes FQIN pour cette image
.SharedSize Toujours semble être 0
.Size Taille de la couche sur disque (chaîne lisible par l'homme)
.Tag Tag de l'image
.VirtualSize Taille de la couche sur disque (octets)

--history

Afficher l'historique des noms d'images. Si une image est re-taguée ou détaguée, l'historique des noms d'images est préfixé (dernière image d'abord). Ceci est particulièrement utile lors de l'annulation d'une opération de taggage ou lorsqu'une image ne contient aucun nom car elle a été détaguée.

--no-trunc

Ne pas tronquer la sortie (par défaut false).

--noheading, -n

Omettre les en-têtes de tableau de la liste.

--quiet, -q

Liste uniquement les identifiants d'images.

--sort=tri

Trier par created, id, repository, size ou tag (par défaut : created) Lors du tri par repository, il trie également par tag comme deuxième critère pour fournir une sortie stable.

EXEMPLES

Lister toutes les images non orphelines dans le stockage local :

$ podman images
REPOSITORY                         TAG         IMAGE ID      CREATED       SIZE
quay.io/podman/stable              latest      e0b7dabc3352  22 hours ago  331 MB
docker.io/library/alpine           latest      9c6f07244728  5 days ago    5.83 MB
registry.fedoraproject.org/fedora  latest      2ecb6df95994  3 weeks ago   169 MB
quay.io/libpod/testimage           20220615    f26aa69bb3f3  2 months ago  8.4 MB

Lister toutes les images correspondant au nom spécifié :

$ podman images stable
REPOSITORY             TAG         IMAGE ID      CREATED       SIZE
quay.io/podman/stable  latest      e0b7dabc3352  22 hours ago  331 MB
