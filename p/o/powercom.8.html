POWERCOM(8) Manuel NUT POWERCOM(8)

NOM

powercom - Pilote UPS pour équipement UPS Powercom/Trust/Advice série

SYNOPIS

powercom -h

powercom -a NOM_ONDULEUR [OPTIONS]


Note

Cette page de manuel ne documente que les fonctionnalités matérielles spécifiques du pilote powercom. Pour des informations sur le pilote de base, voir nutupsdrv(8).

MATERIEL SUPPORTé

Ce pilote supporte de nombreux types d'équipements UPS série similaires (ainsi que quelques modèles UPS USB avec adaptateurs USB vers série). Les plus courants sont les Trust 425/625, Powercom et Advice Partner/King PR750. D'autres utilisant le même protocole peuvent également fonctionner. Pour les connexions USB, vous pourriez avoir besoin de usbhid-ups(8).

Pour des indications plus spécifiques sur le pilote applicable à une connexion USB, consultez la liste de compatibilité matérielle (HCL) de NUT.

ARGUMENTS SUPPLÉMENTAIRES

Ce pilote supporte les paramètres optionnels suivants dans le fichier ups.conf(5) :

linevoltage=valeur

Un entier spécifiant la tension secteur. Elle ne peut pas être détectée automatiquement. Les valeurs acceptables sont comprises entre 110-120 ou 220-240. La valeur par défaut est 230.

manufacturer=nom

Spécifie le nom du fabricant, qui ne peut pas non plus être détecté automatiquement. Il s'agit d'une chaîne définie par l'utilisateur, donc tout nom est acceptable. La valeur par défaut est PowerCom.

modelname=nom

Spécifie le nom du modèle, qui ne peut pas non plus être détecté automatiquement. Il s'agit d'une chaîne définie par l'utilisateur, donc tout nom est acceptable. La valeur par défaut est Unknown.

serialnumber=valeur

Comme pour modelname ci-dessus, mais pour le numéro de série. La valeur par défaut est Unknown.

type=nom

Le type exact du protocole de communication au sein de la famille powercom, qui sera utilisé pour communiquer avec l'UPS. Le type est nommé d'après le premier modelname qui a été codé avec ce protocole. Les noms acceptables sont Trust, Egys, KP625AP, IMP, KIN, BNT, BNT-other et OPTI. La valeur par défaut est Trust.

BNT-other est un type spécial pour d'autres modèles BNT (comme le 1500A à 120V et peut être utilisé pour remplacer TOUS les modèles utilisant TOUTES les valeurs suivantes.

shutdownArguments={{minutes,secondes},si_les_minutes_doivent_être_utilisées}

Les minutes et secondes que l'UPS doit attendre entre la réception de la commande d'arrêt et l'arrêt effectif. L'autre argument doit être réglé sur le caractère n uniquement lorsque la valeur des minutes doit être ignorée et non envoyée à l'UPS. La valeur par défaut est dépendante du type et est donnée ci-dessous. Les accolades et les virgules sont obligatoires. Notez qu'il ne doit y avoir aucun espace blanc.

numOfBytesFromUPS=valeur

Le nombre d'octets dans une trame UPS : 16 est courant, 11 pour Trust. La valeur par défaut est dépendante du type et est donnée ci-dessous.

methodOfFlowControl=nom

La méthode de contrôle de flux de communication série qui est engagée par l'UPS. La valeur par défaut est dépendante du type et est donnée ci-dessous. Les noms acceptables sont dtr0rts1, dtr1 ou no_flow_control.

validationSequence={{index1,valeur1},{index2,valeur2},{index3,valeur3}}

(Uniquement pour les types KP625AP, Trust, Egys.) 3 paires à utiliser pour valider l'UPS en comparant les octets des données brutes avec des valeurs constantes. L'index sélectionne l'octet de l'UPS (voir numOfBytesFromUPS) et la valeur sert à la comparaison avec l'octet. La valeur par défaut est dépendante du type et est donnée ci-dessous. Les accolades et les virgules sont obligatoires, tout comme l'absence d'espaces blancs.

frequency={A,B}

(Uniquement pour les types KP625AP, Trust, Egys.) Une paire pour convertir les données brutes de fréquence en une lecture de fréquence lisible par l'homme en utilisant la fonction 1/(A*x+B). Si la valeur brute x EST la fréquence, alors régler A=1/(x^2) et B=0. La valeur par défaut est dépendante du type et est donnée ci-dessous. Notez que les accolades et les virgules sont obligatoires, tout comme l'absence d'espaces blancs.

loadPercentage={BatteryA,BatteryB,LineA,LineB}

(Uniquement pour les types KP625AP, Trust, Egys.) Un quad pour convertir les données brutes de charge en une lecture de pourcentage de charge lisible par l'homme en utilisant la fonction A*x+B. Si la valeur brute x EST le Pourcentage de Charge, alors régler A=1 et B=0. La valeur par défaut est dépendante du type et est donnée ci-dessous. Notez que les accolades et les virgules sont obligatoires, tout comme l'absence d'espaces blancs.

batteryPercentage={Battery1,Battery2,Battery3,Line4,Line5}

(Uniquement pour KP625AP, Trust, Egys.) Un 5-tuple pour convertir les données brutes de batterie et de ligne en une lecture de pourcentage de batterie et de ligne lisible par l'homme en utilisant les fonctions (Batterie) A*x+B*y+C et (Ligne) D*x+E. Si la valeur brute x EST le Pourcentage de Batterie, alors régler A=1, B=0, C=0, D=1, E=0. La valeur par défaut est dépendante du type et est donnée ci-dessous. Notez que les accolades et les virgules sont obligatoires, tout comme l'absence d'espaces blancs.

voltage={240A,240B,120A,120B}

(Uniquement pour les types KP625AP, Trust, Egys.) Un quad qui est utilisé pour convertir les données brutes de tension en une lecture de tension lisible par l'homme en utilisant la fonction A*x+B. Si la valeur brute x EST la MOITIÉ de la Tension, alors régler A=2, B=0. La valeur par défaut est dépendante du type et est donnée ci-dessous. Notez que les accolades et les virgules sont obligatoires, tout comme l'absence d'espaces blancs.

nobt

Si ce drapeau est présent, le contrôle de batterie au démarrage est ignoré. Ceci est utile pour les systèmes qui ont tendance à surcharger l'UPS lors du test de la batterie au démarrage du système, juste au moment où la consommation d'énergie a tendance à être élevée.

powercom(8) - Manuel Network UPS Tools

SYNOPSIS

powercom -h | -v | -V
powercom -a arg [-a arg ...]
powercom -D N
powercom [-x extarg [-x extarg ...]]

SUPPORTED HARDWARE

Les onduleurs (UPS) de la série Powercom, y compris le nouveau modèle BANTAM, mais il peut également fonctionner avec des dispositifs plus anciens.

Les modèles pris en charge sont ceux qui utilisent des commandes de communication série standard avec des tableaux de données spécifiques à Powercom.

EXTRA ARGUMENTS

Ce pilote prend en charge les arguments facultatifs suivants pour l'adaptateur série.

-a arg
Arguments spécifiques à la série qui sont décrits dans nutupsdrv(8).
-D N
Mode de débogage. Cela active des messages de débogage supplémentaires dans la sortie du pilote.
-x extarg
Arguments étendus qui sont décrits plus en détail ci-dessous.

DEFAULT VALUES FOR THE EXTRA ARGUMENTS

BANTAM

trol = no_flow_control
validationSequence = {{8,0},{8,0},{8,0}}
shutdownArguments = {{1,30},y}

batteryPercentage = {1.0000,0.0000,0.0000,1.0000,0.0000}
voltage = {2.0000,0.0000,2.0000,0.0000}
