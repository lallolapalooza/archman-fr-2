POSIX_TRACE_START(3P) Manuel du programmeur POSIX POSIX_TRACE_START(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_trace_start, posix_trace_stop — démarrage et arrêt du traçage (TRACING)

SYNTAXE

#include <trace.h>
int posix_trace_start(trace_id_t trid);
int posix_trace_stop (trace_id_t trid);

DESCRIPTION

Les fonctions posix_trace_start() et posix_trace_stop(), respectivement, démarrent et arrêtent le flux de trace identifié par l'argument trid.

L'effet de l'appel à la fonction posix_trace_start() sera enregistré dans le flux de trace sous forme d'événement de trace système POSIX_TRACE_START et le statut du flux de trace deviendra POSIX_TRACE_RUNNING. Si le flux de trace est en cours lors de l'appel de cette fonction, l'événement de trace système POSIX_TRACE_START ne sera pas enregistré et le flux de trace continuera de s'exécuter. Si le flux de trace est plein, l'événement de trace système POSIX_TRACE_START ne sera pas enregistré et le statut du flux de trace ne sera pas modifié.

L'effet de l'appel à la fonction posix_trace_stop() sera enregistré dans le flux de trace sous forme d'événement de trace système POSIX_TRACE_STOP et le statut du flux de trace deviendra POSIX_TRACE_SUSPENDED. Si le flux de trace est suspendu lors de l'appel de cette fonction, l'événement de trace système POSIX_TRACE_STOP ne sera pas enregistré et le flux de trace restera suspendu. Si le flux de trace est plein, l'événement de trace système POSIX_TRACE_STOP ne sera pas enregistré et le statut du flux de trace ne sera pas modifié.

VALEUR DE RETOUR

En cas de succès, ces fonctions retourneront une valeur de zéro. Sinon, elles retourneront le numéro d'erreur correspondant.

ERREURS

Ces fonctions échoueront si :

EINVAL
La valeur de l'argument trid ne correspond pas à un flux de trace actif et donc aucun flux de trace n'a été démarré ou arrêté.
EINTR
L'opération a été interrompue par un signal et donc le flux de trace n'a pas nécessairement été démarré ou arrêté.
