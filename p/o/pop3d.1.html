POP3D(1) Manuel des commandes générales POP3D(1)

NOM

pop3d - page man pour pop3d (GNU Mailutils)

SYNTAXE

pop3d [OPTION...]

DESCRIPTION

GNU pop3d -- le démon POP3

SIGNALER LES BOGUES

Signaler les bogues à <bug-mailutils@gnu.org>.

VOIR AUSSI

La documentation complète de pop3d est maintenue sous la forme d'un manuel Texinfo. Si les programmes info et pop3d sont correctement installés sur votre site, la commande

info pop3d

devrait vous donner accès au manuel complet.
