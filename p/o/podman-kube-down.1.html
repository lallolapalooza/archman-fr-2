podman-kube-down(1) Manuel des commandes générales podman-kube-down(1)

NOM

podman-kube-down - Supprimer les conteneurs et les pods basés sur des fichiers YAML Kubernetes

SYNTAXE

podman kube down [options] fichier.yml|-|https://website.io/fichier.yml [fichier2.yml|https://website.io/fichier2.yml ...]

DESCRIPTION

podman kube down lit un ou plusieurs fichiers YAML Kubernetes spécifiés, et supprime les pods qui ont été créés par la commande podman kube play via les mêmes fichiers YAML Kubernetes. Tous les volumes qui ont été créés par la commande précédente podman kube play restent intacts à moins que l'option --force ne soit utilisée. Si le fichier YAML est spécifié comme -, podman kube down lit le YAML depuis l'entrée standard. Les entrées peuvent également être des URLs pointant vers des fichiers YAML tels que https://podman.io/demo.yml. podman kube down supprime les pods et conteneurs créés par podman kube play via le même YAML Kubernetes depuis les URLs. Cependant, podman kube down ne fonctionne pas avec une URL si le fichier YAML pointé par l'URL a été modifié ou altéré depuis la création des pods et conteneurs à l'aide de podman kube play.

Lorsque plusieurs fichiers YAML sont spécifiés (fichiers locaux, URLs, ou une combinaison), ils sont traités séquentiellement et combinés avec des séparateurs de documents YAML (---), tout comme avec podman kube play.

OPTIONS

--force

Supprime les volumes liés aux PersistentVolumeClaims ainsi que les pods.

EXEMPLES

Exemple de fichier YAML demo.yml :

apiVersion: v1
kind: Pod
metadata:
...
spec:
  containers:
  - command:
    - top
    - name: container
      value: podman
    image: foobar
...

Supprimer le pod et les conteneurs comme décrit dans le fichier demo.yml

$ podman kube down demo.yml
Pods stopped:
52182811df2b1e73f36476003a66ec872101ea59034ac0d4d3a7b40903b955a6
Pods removed:
52182811df2b1e73f36476003a66ec872101ea59034ac0d4d3a7b40903b955a6

Supprimer le pod et les conteneurs comme décrit dans le fichier demo.yml, YAML envoyé à l'entrée standard

$ cat demo.yml | podman kube play -
Pods stopped:
52182811df2b1e73f36476003a66ec872101ea59034ac0d4d3a7b40903b955a6
Pods removed:
52182811df2b1e73f36476003a66ec872101ea59034ac0d4d3a7b40903b955a6

Supprimer les pods et conteneurs comme décrit dans le fichier YAML demo.yml lu depuis une URL

$ podman kube down https://podman.io/demo.yml
Pods stopped:
52182811df2b1e73f36476003a66ec872101ea59034ac0d4d3a7b40903b955a6
Pods removed:
52182811df2b1e73f36476003a66ec872101ea59034ac0d4d3a7b40903b955a6

podman kube down ne fonctionne pas avec une URL si le fichier YAML que l'URL pointe a été modifié ou altéré depuis qu'il a été utilisé pour créer les pods et conteneurs.

Supprimer les pods et conteneurs créés à partir de plusieurs fichiers YAML

$ podman kube down pod.yml service.yml configmap.yml
Pods stopped:
52182811df2b1e73f36476003a66ec872101ea59034ac0d4d3a7b40903b955a6
Pods removed:
52182811df2b1e73f36476003a66ec872101ea59034ac0d4d3a7b40903b955a6

Supprimer les pods et conteneurs créés à partir de plusieurs URLs

$ podman kube down https://example.com/pod.yml https://example.com/service.yml https://example.com/configmap.yml
Pods stopped:
52182811df2b1e73f36476003a66ec872101ea59034ac0d4d3a7b40903b955a6
Pods removed:
52182811df2b1e73f36476003a66ec872101ea59034ac0d4d3a7b40903b955a6

Supprimer les pods et conteneurs créés à partir d'une combinaison de fichiers locaux et d'URLs

$ podman kube down local-pod.yml https://example.com/service.yml local-configmap.yml

52182811df2b1e73f36476003a66ec872101ea59034ac0d4d3a7b40903b955a6
