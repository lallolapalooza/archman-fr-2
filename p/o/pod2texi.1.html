NOM

pod2texi - convertir Pod en Texinfo

SYNTAXE

pod2texi [OPTION]... POD...

DESCRIPTION

Traduire des fichiers Pod en Texinfo. Il existe deux modes de fonctionnement de base. Premièrement, par défaut, chaque Pod est traduit en un manuel Texinfo autonome.

Deuxièmement, si "--base-level" est défini à une valeur supérieure à 0, chaque Pod est traduit en un fichier adapté à @include, et un fichier supplémentaire avec un menu principal et tous les @include est généré.

OPTIONS

--appendix-sections
Utilise les commandes de section d'annexe (@appendix, ...) au lieu des commandes Texinfo par défaut de numérotation de section (@-commands) (@chapter, @section, ...).
--base-level=NUM|NOM
Définit le niveau des commandes "head1". Il peut s'agir d'un entier ou d'une commande de sectionnement Texinfo (sans le "@") : 1 correspond au niveau @chapter/@unnumbered, 2 au niveau @section, et ainsi de suite. La valeur par défaut est 0, ce qui signifie que les commandes "head1" sont toujours générées en tant que chapitres, mais la sortie est organisée en tant que manuel autonome.

Si le niveau n'est pas 0, le fichier Pod est rendu comme un fragment d'un manuel Texinfo adapté à @include. Dans ce cas, chaque fichier Pod a une commande de sectionnement supplémentaire couvrant l'ensemble du fichier, un niveau au-dessus de la valeur de "--base-level". Par conséquent, pour faire de chaque fichier Pod un chapitre dans un grand manuel, vous devriez utiliser "section" comme niveau de base.

Pour un exemple de création de Texinfo à partir de la documentation Perl elle-même, voir "contrib/perldoc-all" dans la distribution source de Texinfo.

--debug=NUM
Définit le niveau de débogage à NUM.
--generate-setfilename
Génère une ligne @setfilename pour les manuels autonomes. Peut être nié avec "--no-generate-setfilename". Ignoré si "--base-level" n'est pas 0.
--headings-as-sections
Utilise les commandes de titres (@heading, ...) au lieu des commandes Texinfo par défaut de numérotation de section (@-commands) (@chapter, @section, ...). La commande de sectionnement couvrant le fichier généré pour chaque fichier Pod si --base-level n'est pas 0 est une commande numérotée.
--help
Affiche l'aide et quitte.
--menus
Génère les menus de nœuds. S'il y a un manuel principal, son menu du nœud supérieur est toujours généré, car un menu maître est généré. Les menus des autres nœuds ne sont pas générés dans le cas par défaut.
--outdir=NOM
S'il y a un manuel principal avec des fichiers d'inclusion (chacun correspondant à un fichier Pod d'entrée), alors les fichiers Texinfo générés sont placés dans le répertoire NOM. Par défaut, il est basé sur "--subdir".
--output=NOM
Nom du premier manuel, ou du manuel principal s'il y en a un. Par défaut, l'écriture se fait sur la sortie standard.
--no-section-nodes
Utilise des ancres pour les sections au lieu de nœuds.
--no-fill-section-gaps
Ne remplit pas les écarts de section avec des fichiers @unnumbered vides. D'ordinaire, il est bon de conserver la hiérarchie de sectionnement intacte.
--preamble=CHAÎNE
Insère CHAÎNE comme en-tête principal avant le menu et les inclusions. Si CHAÎNE est défini sur "-", lit l'en-tête principal depuis l'entrée standard. L'en-tête par défaut est un début minimal pour un document Texinfo.
--setfilename=CHAÎNE
Utilise CHAÎNE dans l'en-tête principal avant le menu et les inclusions pour @setfilename pour le manuel principal, si "--base-level" n'est pas défini à 0. Ignoré si "--base-level" est 0. Aucun @setfilename n'est généré dans le cas par défaut pour le manuel principal.
--subdir=NOM
S'il y a un manuel principal avec des fichiers d'inclusion (chacun correspondant à un fichier Pod d'entrée), alors ces fichiers d'inclusion sont inclus depuis NOM.

Si "--outdir" est défini, NOM devrait généralement être défini sur le répertoire relatif entre le manuel principal et l'argument "--outdir".

--unnumbered-sections
Utilise les commandes de sectionnement non numérotées (@unnumbered, ...) au lieu des commandes Texinfo par défaut de numérotation de section (@-commands) (@chapter, @section, ...).
--top=TOP
Nom de l'élément @top pour le manuel principal. Peut contenir du code Texinfo.
--version
Affiche les informations de version et quitte.
