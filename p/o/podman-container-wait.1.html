NOM

podman-wait - Attend que un ou plusieurs conteneurs s'arrêtent et affiche leurs codes de sortie

SYNTAXE

podman wait [options] conteneur [...]

podman container wait [options] conteneur [...]

DESCRIPTION

Attend que un ou plusieurs conteneurs s'arrêtent. Le conteneur peut être référencé par son nom ou son ID. Dans le cas de plusieurs conteneurs, Podman attend sur chacun d'eux consécutivement. Une fois que toutes les conditions sont satisfaites, les codes de retour des conteneurs sont affichés, séparés par un saut de ligne, dans le même ordre qu'ils ont été donnés à la commande. Un code de sortie de -1 est émis pour toutes les conditions autres que « stopped » et « exited ».

Lorsqu'on attend des conteneurs avec une politique de redémarrage always (toujours) ou on-failure (en cas d'échec), comme ceux créés par podman kube play, les conteneurs peuvent s'arrêter et redémarrer de manière répétée, potentiellement avec des codes de sortie différents. podman wait affichera et détectera uniquement le premier arrêt après le démarrage de la commande d'attente.

Lors de l'exécution d'un conteneur avec podman run --rm, wait n'attend pas que le conteneur soit complètement supprimé. Pour attendre la suppression d'un conteneur, utilisez --condition=removing.

OPTIONS

--condition=état

État ou condition du conteneur à attendre. Peut être spécifié plusieurs fois, où au moins une condition doit correspondre pour que la commande se termine. Les valeurs prises en charge sont : « configured », « created », « exited », « healthy », « initialized », « paused », « removing », « running », « stopped », « stopping », « unhealthy ». La condition par défaut est « stopped ».

--exit-first-match

Attend la sortie du premier conteneur qui correspond aux conditions, ignore les autres.

--help, -h

Affiche l'énoncé d'utilisation

--ignore

Ignore les erreurs lorsqu'un conteneur spécifié est manquant et marque son code de retour comme -1.

--interval, -i=durée

Intervalle de temps à attendre avant de vérifier l'achèvement. Une chaîne de durée est une séquence de nombres décimaux, chacun avec une fraction facultative et un suffixe d'unité, tels que « 300ms », « -1.5h » ou « 2h45m ». Les unités de temps valides sont « ns », « us » (ou « µs »), « ms », « s », « m », « h ». L'unité de temps par défaut est « ms ».

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utilisez le dernier conteneur créé. Note : le dernier conteneur démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (hors WSL2)).

EXEMPLES

Attend que le conteneur spécifié s'arrête.

$ podman wait mywebserver
0

Attend que le dernier conteneur s'arrête. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (hors WSL2)).

$ podman wait --latest
0

Attend que le conteneur s'arrête, en vérifiant toutes les deux secondes.

$ podman wait --interval 2s mywebserver
0

Attend le conteneur par ID. Ce conteneur se termine avec le code d'erreur 1 :

$ podman wait 860a4b23
1

Attend que les deux conteneurs spécifiés s'arrêtent.

$ podman wait mywebserver myftpserver
0
125

Attend que le conteneur nommé s'arrête, mais ne génère pas d'erreur si le conteneur n'existe pas.

$ podman wait --ignore does-not-exist
-1
