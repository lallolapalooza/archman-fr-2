NOM

podman-farm-create - Crée une nouvelle ferme

SYNTAXE

podman farm create nom [connexions]

DESCRIPTION

Crée une nouvelle ferme avec des connexions que Podman connaît et qui ont été ajoutées via la commande podman system connection add.

Une ferme vide peut être créée sans y ajouter de connexions. Ajoutez ou supprimez des connexions d'une ferme via la commande podman farm update.

EXEMPLES

Crée la ferme spécifiée sans connexions :

$ podman farm create farm2

Crée une ferme avec des connexions :

$ podman farm create farm1 f37 f38
