podman-system-connection-list(1) Manuel des commandes générales podman-system-connection-list(1)

NOM

podman-system-connection-list - Lister la destination pour les services Podman

SYNTAXE

podman system connection list [options]

podman system connection ls [options]

DESCRIPTION

Lister la (les) destination(s) ssh pour les services podman.

OPTIONS

--format, -f=format

Modifier le format de sortie par défaut. Il peut s'agir d'un type supporté comme « json » ou d'un modèle Go. Les espaces réservés valides pour le modèle Go sont listés ci-dessous :

Espace réservé Description
.Default Indique si la connexion est la connexion par défaut
.Identity Chemin d'accès au fichier contenant l'identité SSH
.Name Nom/Identifiant de la connexion
.ReadWrite Indique si cette connexion peut être modifiée à l'aide des commandes de connexion système
.TLSCA Chemin d'accès à un fichier PEM contenant le paquet d'autorité de certification pour vérifier le certificat du serveur.
.TLSCert Chemin d'accès à un fichier PEM contenant le paquet d'autorité de certification pour vérifier le certificat du serveur.
.TLSKey Chemin d'accès à un fichier PEM contenant la clé privée correspondant à .TLSCA
.URI URI du service podman. Les schémas valides sont ssh://[utilisateur@]hôte[:port]socket de domaine Unix[?secure=True], unix://socket de domaine Unix, et tcp://localhost[:port]

--quiet, -q

Afficher uniquement les noms des connexions

EXEMPLE

Lister les connexions système :

$ podman system connection list
Nom                  URI                                                      Identité	    Défaut  En Lecture/Écriture
deva                 ssh://root@example.com:/run/podman/podman.sock           ~/.ssh/id_rsa vrai     vrai
devb                 ssh://user@example.com:/run/user/1000/podman/podman.sock ~/.ssh/id_rsa faux    vrai

Afficher les connexions au format JSON :

$ podman system connection list --format json
[
    {
        "Name": "podman-machine-default",
        "URI": "ssh://core@127.0.0.1:53298/run/user/501/podman/podman.sock",
        "Identity": "/Users/ragm/.local/share/containers/podman/machine/machine",
        "IsMachine": true,
        "Default": true,
        "ReadWrite": true
    },
    {
        "Name": "podman-machine-default-root",
        "URI": "ssh://root@127.0.0.1:53298/run/podman/podman.sock",
        "Identity": "/Users/ragm/.local/share/containers/podman/machine/machine",
        "IsMachine": true,
        "Default": false,
        "ReadWrite": true
    }
]

Afficher les noms et les URI des connexions :

$ podman system connection list --format "{{.Name}}\t{{.URI}}"
podman-machine-default	ssh://core@127.0.0.1:53298/run/user/501/podman/podman.sock
podman-machine-default-root	ssh://root@127.0.0.1:53298/run/podman/podman.sock

Afficher tous les détails de la connexion dans un format complet :

$ podman system connection list --format "Nom: {{.Name}}\nURI: {{.URI}}\nIdentité: {{.Identity}}\nDéfaut: {{.Default}}\nLecture/Écriture: {{.ReadWrite}}\n---"
Nom: podman-machine-default
URI: ssh://core@127.0.0.1:53298/run/user/501/podman/podman.sock
Identité: /Users/ragm/.local/share/containers/podman/machine/machine
Défaut: true
Lecture/Écriture: true
---
Nom: podman-machine-default-root
URI: ssh://root@127.0.0.1:53298/run/podman/podman.sock
Identité: /Users/ragm/.local/share/containers/podman/machine/machine
Défaut: false
Lecture/Écriture: true
---
