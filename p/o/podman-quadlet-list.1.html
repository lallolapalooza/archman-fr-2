NOM

podman-quadlet-list - Lister les quadlets installés

SYNOPSIS

podman quadlet list [options]

DESCRIPTION

Lister tous les quadlets configurés pour l'utilisateur actuel.

OPTIONS

--filter, -f=filtre

Filtrer la sortie en fonction des conditions données.

Le format de l'argument filtre est de la forme clé=valeur. S'il y a plus d'un filtre, passez plusieurs OPTIONS : --filter foo=bar --filter bif=baz.

Filtres supportés :

Filtre Description
name Filtrer par nom de quadlet.

--format=format

Imprimer la sortie au format JSON ou en utilisant un template Go (par défaut "{{range .}}{{.Name}}\t{{.UnitName}}\t{{.Path}}\t{{.Status}}\n{{end -}}")

Imprimer les résultats avec un template Go.

Placeholder Description
.App Nom de l'application si le Quadlet fait partie d'une application
.Name Nom du fichier Quadlet
.Path Chemin d'accès au fichier Quadlet sur le disque
.Status Statut du Quadlet correspondant à l'unité systemd
.UnitName Nom de l'unité systemd correspondant au quadlet

EXEMPLES

Commande de liste simple

$ podman quadlet list
NAME                            UNIT NAME                     PATH ON DISK                                                          STATUS      APPLICATION
test-service-quadlet.container  test-service-quadlet.service  /home/user/.config/containers/systemd/test-service-quadlet.container  Not loaded
sample-quadlet.container        sample-quadlet.service        /home/user/.config/containers/systemd/sample-quadlet.container        Not loaded

Filtrer la liste par nom.

$ podman quadlet list --filter 'name=test*'
NAME                            UNIT NAME                     PATH ON DISK                                                          STATUS      APPLICATION
test-service-quadlet.container  test-service-quadlet.service  /home/user/.config/containers/systemd/test-service-quadlet.container  Not loaded

Formater la sortie de la liste pour un champ spécifique.

$ podman quadlet list --format '{{ .UnitName }}'
UNIT NAME
test-service-quadlet.service
sample-quadlet.service
