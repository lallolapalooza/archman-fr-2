NOM

polyphone - éditeur de soundfont

SYNTAXE

polyphone
polyphone [FICHIER]
polyphone [FICHIER_1] [FICHIER_2] ...
polyphone -1 [-i CHEMIN_FICHIER_ENTREE] [-d REPERTOIRE_SORTIE] [-o NOM_SORTIE]
polyphone -2 [-i CHEMIN_FICHIER_ENTREE] [-d REPERTOIRE_SORTIE] [-o NOM_SORTIE] [-c CONFIG]
polyphone -3 [-i CHEMIN_FICHIER_ENTREE] [-d REPERTOIRE_SORTIE] [-o NOM_SORTIE] [-c CONFIG]
polyphone -s [-i CHEMIN_FICHIER_ENTREE] [-c CONFIG]

DESCRIPTION

polyphone fournit une interface simple et efficace pour créer et éditer des fichiers .sf2. Ce logiciel comprend des outils pour faciliter et automatiser l'édition de différents paramètres, permettant ainsi de gérer une grande quantité de données.

Les formats sf2, sf3, sfz (import / export), sfArk (import seulement) et GrandOrgue (import seulement) sont pris en charge. Les lignes de commande peuvent être utilisées pour convertir des fichiers, ouvrir Polyphone en mode synthétiseur ou réinitialiser les configurations en cas de problème.

Plus d'informations peuvent être trouvées sur https://www.polyphone.io .

OPTIONS

FICHIER
Spécifie le fichier à ouvrir au démarrage de polyphone. Plusieurs fichiers peuvent être chargés s'ils sont séparés par des espaces. Les formats sf2 (version 2.01 ou 2.04), sf3, sfz, sfArk (version 1 ou 2) et GrandOrgue sont pris en charge.
-1
Utiliser polyphone pour convertir un fichier au format sf2.
-2
Utiliser polyphone pour convertir un fichier au format sf3.
-3
Utiliser polyphone pour convertir un fichier au format sfz.
-s
Ouvrir polyphone en mode synthétiseur.
[-i CHEMIN_FICHIER_ENTREE]
Chemin du fichier d'entrée à convertir ou à ouvrir. Le format du fichier d'entrée doit être sf2, sf3, sfz, sfArk ou organ.
[-d REPERTOIRE_SORTIE]
Répertoire de sortie dans lequel le fichier d'entrée sera converti. Par défaut, il s'agit du même répertoire que celui du fichier d'entrée.
[-o NOM_SORTIE]
Nom de sortie du fichier converti. L'extension sera ajoutée automatiquement en fonction de la conversion. Par défaut, il s'agit du même nom que le fichier d'entrée.
[-c CONFIG]
Configuration de conversion, le contenu dépendant du type de conversion. -r Supprime la configuration existante.

* Conversion sf2
Aucune configuration pour cette conversion.

* Conversion sf3
La configuration est constituée d'un caractère indiquant la qualité de compression. '0' pour basse, '1' pour moyenne et '2' pour haute qualité. Par défaut, c'est '1'.

* Conversion sfz
La configuration est composée de 3 valeurs séparées par un '|'. La première valeur est '1' si chaque preset doit être préfixé par son numéro de preset, '0' sinon. La deuxième valeur est '1' si un répertoire par banque doit être créé, '0' sinon. La troisième valeur est '1' si la classification MIDI générale doit être utilisée pour trier les presets, '0' sinon. Par défaut, c'est '0|0|0'.

* Mode synthétiseur
La configuration est composée de 3 valeurs séparées par un '|'. La première valeur spécifie le canal MIDI à écouter, qui peut être une valeur de 1 à 16. Une valeur de 0 ou "all" indique que tous les canaux seront utilisés et traités comme un seul canal. Une valeur de -1 ou "each" écoute chaque canal séparément, ce qui est une condition préalable pour jouer des fichiers MIDI par exemple. La deuxième valeur est 'on' ou 'off' pour activer la lecture de plusieurs presets simultanément. La troisième valeur est 'on', 'off' ou 'toggle' pour activer ou désactiver des presets par les notes les plus basses du clavier. Par défaut, c'est 'all|off|off'.

EXEMPLES


* Conversion de sfArk en sf2 :
polyphone -1 -i /chemin/vers/fichier.sfArk

* Conversion de sf2 en sf3 (bonne qualité) :
polyphone -2 -i /chemin/vers/fichier.sf2 -c 2

* Conversion de sf3 en sfz (sous-répertoires pour la banque et la classification gm) :
polyphone -3 -i /chemin/vers/fichier.sf3 -c '0|1|1'

* Ouvrir Polyphone en mode synthétiseur, permettant d'utiliser les touches basses pour sélectionner l'ensemble à jouer avec un clavier MIDI :
polyphone -s -i /chemin/vers/fichier.sf2 -c 'all|off|toggle'
