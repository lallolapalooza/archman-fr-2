NOM

podman-volume-prune - Supprimer tous les volumes inutilisés

SYNTAXE

podman volume prune [options]

DESCRIPTION

Supprime les volumes inutilisés. Par défaut, tous les volumes inutilisés sont supprimés. Le drapeau --filter peut être utilisé pour filtrer des volumes spécifiques. Les utilisateurs sont invités à confirmer la suppression de tous les volumes inutilisés. Pour contourner la confirmation, utilisez le drapeau --force.

OPTIONS

--filter

Fournir des valeurs de filtre.

Le format des arguments filtres est de type clé=valeur. S'il y a plus d'un filtre, passez plusieurs OPTIONS : --filter foo=bar --filter bif=baz.

Filtres pris en charge :

Filtre Description
dangling [Bool] Supprimer uniquement les volumes non référencés par des conteneurs
driver [String] Supprimer uniquement les volumes avec le pilote donné
label [String] Supprimer uniquement les volumes, avec (ou sans, dans le cas où label!=[...] est utilisé) les étiquettes spécifiées.
name [String] Supprimer uniquement le volume avec le nom donné
opt [String] Supprimer uniquement les volumes créés avec les options données
scope [String] Supprimer uniquement les volumes avec la portée donnée
until [DateTime] Supprimer uniquement les volumes créés avant l'horodatage donné.
after/since [Volume] Filtrer par les volumes créés après le VOLUME donné (nom ou étiquette)

Le filtre label accepte deux formats. L'un est label=clé ou label=clé=valeur, qui supprime les volumes avec les étiquettes spécifiées. L'autre format est label!=clé ou label!=clé=valeur, qui supprime les volumes sans les étiquettes spécifiées.

Le filtre until peut être des horodatages Unix, des horodatages formatés par date ou des chaînes de durée Go (par exemple, 10m, 1h30m) calculés par rapport à l'heure de la machine.

--force, -f

Ne pas demander de confirmation.

--help

Afficher l'énoncé d'utilisation

EXEMPLES

Supprimer tous les volumes inutilisés.

$ podman volume prune

Supprimer tous les volumes. Note : cette commande supprimera également tous les conteneurs qui utilisent un volume.

$ podman volume prune --force

Supprimer tous les volumes contenant l'étiquette spécifiée.

$ podman volume prune --filter label=mylabel=mylabelvalue
