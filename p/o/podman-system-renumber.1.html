NOM

podman-system-renumber - Migre les numéros de verrous pour gérer un changement dans le nombre maximal de verrous

SYNTAXE

podman system renumber

DESCRIPTION

podman system renumber renumérote les verrous utilisés par les conteneurs et les pods.

Chaque conteneur et pod Podman se voit attribuer un verrou lors de sa création, jusqu'à un nombre maximum contrôlé par le paramètre num_locks dans containers.conf.

Lorsque tous les verrous disponibles sont épuisés, aucun autre conteneur ou pod ne peut être créé tant que certains conteneurs et pods existants ne sont pas supprimés. Cela peut être évité en augmentant le nombre de verrous disponibles via la modification de containers.conf et en exécutant ensuite podman system renumber pour préparer les nouveaux verrous (et réallouer les numéros de verrous pour s'adapter à la nouvelle structure).

podman system renumber doit être appelé après toute modification de num_locks ; omettre cette étape entraîne des erreurs au démarrage de Podman car le nombre de verrous disponibles entre en conflit avec le nombre de verrous configuré.

podman system renumber peut également être utilisé pour migrer les versions 1.0 et antérieures de Podman, qui utilisaient un schéma de verrouillage différent, vers le nouveau modèle de verrouillage. Il n'est pas strictement obligatoire de le faire, mais il est fortement recommandé de le faire, car des interblocages peuvent survenir autrement.

Si possible, évitez d'appeler podman system renumber pendant qu'il y a d'autres processus Podman en cours d'exécution.

EXEMPLES

Renuméroter les verrous de conteneurs et de pods après avoir modifié le réglage num_locks dans containers.conf.

$ podman system renumber

VOIR AUSSI

podman(1), podman-system(1), containers.conf(5)
