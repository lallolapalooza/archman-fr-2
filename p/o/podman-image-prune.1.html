NOM

podman-image-prune - Supprime toutes les images inutilisées du stockage local

SYNOPIS

podman image prune [options]

DESCRIPTION

podman image prune supprime toutes les images pendantes du stockage local. Avec l'option all, toutes les images inutilisées sont supprimées (c'est-à-dire les images non utilisées par un conteneur).

La commande de nettoyage d'images ne nettoie pas les images de cache qui n'utilisent que des couches nécessaires à d'autres images.

OPTIONS

--all, -a

Supprime les images pendantes et les images qui n'ont pas de conteneurs associés.

--build-cache

Supprime le cache de construction persistant créé pour --mount=type=cache.

--external

Supprime les images même si elles sont utilisées par des conteneurs externes (par exemple, des conteneurs de construction).

--filter=filtres

Fournit des valeurs de filtre.

Le format de l'argument filtres est clé=valeur. S'il y a plus d'un filtre, passez plusieurs OPTIONS : --filter foo=bar --filter bif=baz.

Filtres pris en charge :

Filtre Description
label Supprime uniquement les images avec, ou sans (dans le cas où label!=[...] est utilisé), les étiquettes spécifiées.
until Supprime uniquement les images créées avant l'horodatage donné.

Le filtre label accepte deux formats. L'un est label=clé ou label=clé=valeur, qui supprime les conteneurs avec les étiquettes spécifiées. L'autre format est label!=clé ou label!=clé=valeur, qui supprime les conteneurs sans les étiquettes spécifiées.

Le filtre until peut être un horodatage Unix, un horodatage formaté par date ou une chaîne de durée Go (par exemple, 10m, 1h30m) calculé par rapport à l'heure de la machine.

--force, -f

Ne pas fournir d'invite interactive pour la suppression des conteneurs.

--help, -h

Affiche le message d'utilisation
