POSIX_SPAWNATTR_DESTROY(3P) Manuel du programmeur POSIX POSIX_SPAWNATTR_DESTROY(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_spawnattr_destroy, posix_spawnattr_init — détruire et initialiser un objet d'attributs de spawn (TEMPS RÉEL AVANCÉ)

SYNTAXE

#include <spawn.h>
int posix_spawnattr_destroy(posix_spawnattr_t *attr);
int posix_spawnattr_init(posix_spawnattr_t *attr);

DESCRIPTION

La fonction posix_spawnattr_destroy() détruit un objet d'attributs de spawn. Un objet d'attributs attr détruit peut être réinitialisé à l'aide de posix_spawnattr_init() ; les résultats de toute autre référence à l'objet après sa destruction sont indéfinis. Une implémentation peut amener posix_spawnattr_destroy() à définir l'objet référencé par attr sur une valeur invalide.

La fonction posix_spawnattr_init() initialise un objet d'attributs de spawn attr avec la valeur par défaut pour tous les attributs individuels utilisés par l'implémentation. Les résultats sont indéfinis si posix_spawnattr_init() est appelée en spécifiant un objet d'attributs attr déjà initialisé.

Un objet d'attributs de spawn est de type posix_spawnattr_t (défini dans <spawn.h>) et est utilisé pour spécifier l'héritage des attributs de processus lors d'une opération de spawn. POSIX.1-2008 ne définit pas d'opérateurs de comparaison ou d'affectation pour le type posix_spawnattr_t.

Chaque implémentation doit documenter les attributs individuels qu'elle utilise et leurs valeurs par défaut, sauf si ces valeurs sont définies par POSIX.1-2008. Les attributs non définis par POSIX.1-2008, leurs valeurs par défaut, et les noms des fonctions associées pour obtenir et définir ces valeurs d'attributs sont définis par l'implémentation.

L'objet d'attributs de spawn résultant (éventuellement modifié en définissant des valeurs d'attributs individuelles), est utilisé pour modifier le comportement de posix_spawn() ou posix_spawnp(). Après qu'un objet d'attributs de spawn a été utilisé pour lancer un processus par un appel à posix_spawn() ou posix_spawnp(), toute fonction affectant l'objet d'attributs (y compris la destruction) ne doit pas affecter aucun processus lancé de cette manière.

VALEUR DE RETOUR

En cas de succès, posix_spawnattr_destroy() et posix_spawnattr_init() retournent zéro ; sinon, un numéro d'erreur est retourné pour indiquer l'erreur.

ERREURS

La fonction posix_spawnattr_init() échoue si :

ENOMEM
Il n'y a pas assez de mémoire pour initialiser l'objet d'attributs de spawn.

La fonction posix_spawnattr_destroy() peut échouer si :

EINVAL
La valeur spécifiée par attr est invalide.

EXEMPLES

Aucun.

UTILISATION PAR APPLICATION

Ces fonctions font partie de l'option Spawn et ne doivent pas nécessairement être fournies sur toutes les implémentations.

RATIONALE

L'interface de spawn d'origine proposée dans POSIX.1-2008 définissait les attributs qui spécifient l'héritage des attributs de processus lors d'une opération de spawn comme une structure. Afin de pouvoir séparer les attributs individuels optionnels sous leurs options appropriées (c'est-à-dire les attributs spawn-schedparam et spawn-schedpolicy dépendant de l'option de Planification des Processus), et aussi pour l'extensibilité et la cohérence avec les interfaces POSIX plus récentes, l'interface des attributs a été changée en un type de données opaque. Cette interface se compose maintenant du type posix_spawnattr_t, représentant un objet d'attributs de spawn, avec des fonctions associées pour initialiser ou détruire l'objet d'attributs, et pour définir ou obtenir chaque attribut individuel. Bien que la nouvelle interface orientée objet soit plus verbeuse que la structure d'origine, elle est simple à utiliser, plus extensible et facile à implémenter.

posix_spawnattr_destroy.3p

NAME

posix_spawnattr_destroy - destroy process spawn attributes object

SYNOPSIS

#include <spawn.h>

int posix_spawnattr_destroy(posix_spawnattr_t *attr);

DESCRIPTION

The posix_spawnattr_destroy() function shall destroy the object indicated by attr; the storage location referred to by attr shall be made unavailable. The effect of calling posix_spawnattr_destroy() on an object that has already been destroyed is undefined.

RETURN VALUE

Upon successful completion, posix_spawnattr_destroy() shall return 0. Otherwise, it shall return an error number to indicate the error.

ERRORS

The posix_spawnattr_destroy() function shall fail if:

[EINVAL]
The value specified by attr is invalid.

posix_spawnattr_destroy.3p

NOM

posix_spawnattr_destroy - détruit un objet d'attributs de création de processus

SYNTAXE

#include <spawn.h>

int posix_spawnattr_destroy(posix_spawnattr_t *attr);

DESCRIPTION

La fonction posix_spawnattr_destroy() détruit l'objet indiqué par attr ; l'emplacement de stockage auquel attr fait référence devient indisponible. L'effet d'un appel à posix_spawnattr_destroy() sur un objet déjà détruit est indéfini.

VALEUR RENVOYÉE

En cas de succès, posix_spawnattr_destroy() renvoie 0. Sinon, elle renvoie un numéro d'erreur pour indiquer l'erreur.

ERREURS

La fonction posix_spawnattr_destroy() échoue si :

[EINVAL]
La valeur spécifiée par attr est invalide.
