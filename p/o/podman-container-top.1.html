podman-top(1) Manuel des commandes générales podman-top(1)

NOM

podman-top - Afficher les processus en cours d'exécution d'un conteneur

SYNTAXE

podman top [options] conteneur [descripteurs-format]

podman container top [options] conteneur [descripteurs-format]

DESCRIPTION

Affiche les processus en cours d'exécution du conteneur. Les descripteurs-format sont compatibles avec les descripteurs de format AIX de ps (1) mais étendus pour imprimer des informations supplémentaires, telles que le mode seccomp ou les capacités effectives d'un processus donné. Les descripteurs peuvent être passés en arguments séparés ou en un seul argument séparé par des virgules. Notez que les options et/ou drapeaux de ps(1) peuvent également être spécifiés ; dans ce cas, Podman se rabat sur l'exécution de ps(1) de l'hôte avec les arguments et drapeaux spécifiés dans l'espace de noms du conteneur. Si le conteneur possède la capacité CAP_SYS_PTRACE, nous exécuterons ps(1) dans le conteneur, il doit donc y être installé. Pour extraire des informations relatives à l'hôte, utilisez les descripteurs "h*". Par exemple, podman top $nom hpid huser pour afficher le PID et l'utilisateur des processus dans le contexte de l'hôte.

OPTIONS

--help, -h

Affiche le message d'utilisation

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utilise le dernier conteneur créé. Note : le dernier conteneur démarré peut appartenir à d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (hors WSL2))

DESCRIPTEURS FORMAT

Les descripteurs suivants sont pris en charge en plus des descripteurs de format AIX mentionnés dans ps (1) :

args, capbnd, capeff, capinh, capprm, comm, etime, group, groups, hgroup, hgroups, hpid, huser, label, nice, pcpu, pgid, pid, ppid, rgroup, ruser, seccomp, state, time, tty, user, vsz

capbnd

Ensemble des capacités de limitation (bounding). Voir capabilities (7) pour plus d'informations.

capeff

Ensemble des capacités effectives. Voir capabilities (7) pour plus d'informations.

capinh

Ensemble des capacités héritables. Voir capabilities (7) pour plus d'informations.

capprm

Ensemble des capacités autorisées (permitted). Voir capabilities (7) pour plus d'informations.

group

Le groupe effectif du processus.

groups

Les groupes supplémentaires du processus.

hgroup

Le groupe effectif correspondant d'un processus de conteneur sur l'hôte.

hgroups

Les groupes supplémentaires correspondants d'un processus de conteneur sur l'hôte.

hpid

Le PID de l'hôte correspondant d'un processus de conteneur.

huser

L'utilisateur effectif correspondant d'un processus de conteneur sur l'hôte.

label

Attributs de sécurité actuels du processus.

seccomp

Mode Seccomp du processus (par exemple : désactivé, strict ou filtre). Voir seccomp (2) pour plus d'informations.

state

Codes d'état du processus (par exemple : R pour en cours d'exécution, S pour en veille). Voir proc (5) pour plus d'informations.

stime

Heure de démarrage du processus (par exemple : "2019-12-09 10:50:36 +0100 CET).

EXEMPLES

Par défaut, podman-top affiche des données similaires à ps -ef.

$ podman top f5a62a71b07
USER   PID   PPID   %CPU    ELAPSED         TTY     TIME   COMMAND
root   1     0      0.000   20.386825206s   pts/0   0s     sh
root   7     1      0.000   16.386882887s   pts/0   0s     sleep
root   8     1      0.000   11.386886562s   pts/0   0s     vi

La sortie peut être contrôlée en spécifiant des descripteurs de format comme arguments après le conteneur.

$ podman top -l pid seccomp args %C
PID   SECCOMP   COMMAND     %CPU
1     filter    sh          0.000
8     filter    vi /etc/    0.000

Podman se rabat sur l'exécution de ps(1) de l'hôte dans l'espace de noms du conteneur si un descripteur inconnu est spécifié.

$ podman top -l -- aux
USER   PID   PPID   %CPU    ELAPSED             TTY   TIME   COMMAND
root   1     0      0.000   1h2m12.497061672s   ?     0s     sleep 100000
