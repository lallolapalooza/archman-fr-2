POSIX_MEMALIGN(3P) Manuel du programmeur POSIX POSIX_MEMALIGN(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement de Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

posix_memalign — allocation de mémoire alignée (TEMPS RÉEL AVANCÉ)

SYNOPSIS

#include <stdlib.h>
int posix_memalign(void **memptr, size_t alignment, size_t size);

DESCRIPTION

La fonction posix_memalign() alloue size octets alignés sur une frontière spécifiée par alignment, et renvoie un pointeur vers la mémoire allouée dans memptr. La valeur de alignment doit être une puissance de deux multiple de sizeof(void *).

En cas de succès, la valeur pointée par memptr sera un multiple de alignment.

Si la taille de l'espace demandé est de 0, le comportement est défini par l'implémentation : soit un pointeur nul est renvoyé dans memptr, soit le comportement est comme si la taille était une valeur non nulle, sauf que le comportement est indéfini si la valeur renvoyée dans memptr est utilisée pour accéder à un objet.

La fonction free() désalloue la mémoire précédemment allouée par posix_memalign().

VALEUR RENVOYÉE

En cas de succès, posix_memalign() renvoie zéro ; sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur et le contenu de memptr est soit laissé inchangé, soit défini à un pointeur nul.

Si size est 0, soit :

*
posix_memalign() n'essaie pas d'allouer d'espace, auquel cas soit un numéro d'erreur défini par l'implémentation est renvoyé, soit zéro est renvoyé avec un pointeur nul dans memptr, soit
*
posix_memalign() essaie d'allouer un espace et, si l'allocation réussit, zéro est renvoyé et un pointeur vers l'espace alloué est renvoyé dans memptr. L'application doit s'assurer que le pointeur n'est pas utilisé pour accéder à un objet.

ERREURS

La fonction posix_memalign() échoue si :

EINVAL
La valeur du paramètre d'alignement n'est pas un multiple de puissance de deux de sizeof(void *).
ENOMEM
Il n'y a pas assez de mémoire disponible avec l'alignement demandé.

Les sections suivantes sont informatives.

EXEMPLES

L'exemple suivant montre comment les applications peuvent obtenir un comportement cohérent en cas d'erreur en définissant *memptr à un pointeur nul avant d'appeler posix_memalign().

void *ptr = NULL;
...
// faire du travail, qui peut aller à error
if (posix_memalign(&ptr, align, size))
    goto error;
// faire plus de travail, qui peut aller à error
...
error:
    free(ptr);
    //plus de nettoyage;

UTILISATION PAR L'APPLICATION

La fonction posix_memalign() fait partie de l'option Informations consultatives et n'a pas besoin d'être fournie sur toutes les implémentations.
