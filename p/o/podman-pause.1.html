podman-pause(1) Manuel des commandes générales podman-pause(1)

NOM

podman-pause - Met en pause un ou plusieurs conteneurs

SYNTAXE

podman pause [options] [conteneur...]

podman container pause [options] [conteneur...]

DESCRIPTION

Met en pause tous les processus d'un ou plusieurs conteneurs. Vous pouvez utiliser les ID ou les noms des conteneurs en entrée.

OPTIONS

--all, -a

Met en pause tous les conteneurs en cours d'exécution.

--cidfile=fichier

Lit l'ID du conteneur à partir du fichier spécifié et met en pause le conteneur. Peut être spécifié plusieurs fois.

--filter, -f=filtre

Filtre les conteneurs à mettre en pause. Plusieurs filtres peuvent être utilisés avec plusieurs utilisations de l'option --filter. Les filtres avec la même clé fonctionnent de manière inclusive, à l'exception de label qui est exclusive. Les filtres avec des clés différentes fonctionnent toujours de manière exclusive.

Les filtres valides sont listés ci-dessous :

Filtre Description
id [ID] ID du conteneur (correspondance de préfixe CID par défaut ; accepte les expressions régulières)
name [Nom] Nom du conteneur (accepte les expressions régulières)
label [Clé] ou [Clé=Valeur] Étiquette attribuée à un conteneur
exited [Int] Code de sortie du conteneur
status [Statut] Statut du conteneur : 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NomImage] Image ou descendant utilisé pour créer le conteneur
before [ID] ou [Nom] Conteneurs créés avant ce conteneur
since [ID] ou [Nom] Conteneurs créés depuis ce conteneur
volume [NomVolume] ou [PointMontageDestination] Volume monté dans le conteneur
health [Statut] healthy ou unhealthy
pod [Pod] nom ou ID complet ou partiel du pod
network [Réseau] nom ou ID complet du réseau
until [DateTime] Conteneurs créés avant la durée ou l'heure donnée.
command [Commande] la commande exécutée par le conteneur, seul argv[0] est pris en compte

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utilisez le dernier conteneur créé. Remarque : le dernier conteneur démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (à l'exception de WSL2)).

EXEMPLE

Mettre en pause un conteneur spécifié :

podman pause monserveurweb

Mettre en pause un conteneur par ID partiel :

podman pause 860a4b23

Mettre en pause tous les conteneurs en cours d'exécution :

podman pause --all

Mettre en pause un conteneur en utilisant l'ID spécifié dans des fichiers donnés :

podman pause --cidfile /home/utilisateur/cidfile-1
podman pause --cidfile /home/utilisateur/cidfile-1 --cidfile ./cidfile-2

Mettre en pause le dernier conteneur. (Cette option n'est pas disponible avec le client Podman distant, y compris les machines Mac et Windows (à l'exception de WSL2)) :

podman pause --latest

VOIR AUSSI

podman(1), podman-unpause(1)
