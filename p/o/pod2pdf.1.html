NOM

pod2pdf - convertit le format Pod en PDF

DESCRIPTION

pod2pdf convertit les documents écrits au format POD (Plain Old Documentation) de Perl en fichiers PDF.

Utilisation

pod2pdf [options] input.pod >output.pdf

Si aucun nom de fichier d'entrée n'est spécifié, pod2pdf lira depuis STDIN, par exemple :

perldoc -u File::Find | pod2pdf [options] >File-Find.pdf

Options

pod2pdf accepte les options de ligne de commande suivantes :

"--output-file"
Définit le nom du fichier de sortie pour le fichier PDF généré. Par défaut, pod2pdf génère sur STDOUT.
"--page-size"
Définit la taille de page à utiliser dans le fichier PDF, peut être réglée sur toutes les tailles de papier standard (A4, A5, Lettre, etc.). Par défaut A4.
"--page-orientation"
Contrôle si les pages sont produites en format paysage ou portrait. Par défaut 'portrait'.
"--page-width", "--page-height"
Définit la largeur et la hauteur des pages générées en points (pour utiliser des tailles de papier non standard).
"--left-margin", "--right-margin", "--top-margin", "--bottom-margin"
Permet à chaque marge de page (haut, bas, gauche et droite) d'être réglée individuellement en points.
"--margins"
Définit toutes les marges de page à la même taille (spécifiée en points).
"--header", "--noheader"
Contrôle si un en-tête (contenant le titre de la page et éventuellement l'horodatage et l'icône) sera inclus sur chaque page. Par défaut, activé, utilisez donc "--noheader" pour le désactiver.
"--title"
Définit le titre de la page (par défaut, le nom du fichier d'entrée).
"--timestamp"
Option booléenne - si activée, inclut l'horodatage de 'dernière modification' du fichier d'entrée dans l'en-tête de la page.
"--icon"
Nom de fichier d'une icône à afficher dans le coin supérieur gauche de chaque page.
"--icon-scale"
Valeur de mise à l'échelle pour l'icône d'en-tête (par défaut 0.25).
"--footer", "--nofooter"
Contrôle si un pied de page (contenant le numéro de page actuel et une chaîne de texte optionnelle) sera inclus sur chaque page. Par défaut, le pied de page est inclus, utilisez donc "--nofooter" pour le désactiver.
"--footer-text"
Définit une chaîne de texte optionnelle pour le pied de page qui sera incluse dans le coin inférieur gauche de chaque page.
"--version"
Affiche le numéro de version et quitte.

Fichiers de configuration

Des ensembles d'options de ligne de commande peuvent être enregistrés dans des fichiers de configuration.

Un fichier de configuration contient des options dans le même format que celui utilisé par pod2pdf sur la ligne de commande, avec une option par ligne dans le fichier, par exemple :

--page-size A5
--page-orientation landscape

Pour utiliser un fichier de configuration, invoquez pod2pdf avec l'option "@/chemin/vers/fichier_config.conf".

Par exemple, si vous souhaitez toujours inclure un logo d'entreprise, un horodatage et une notice de copyright dans vos fichiers PDF, créez un fichier mycompany.conf contenant ce qui suit :

--icon "/chemin/vers/votre/logo.png"
--footer-text "Copyright 2007 MyCompany Limited"
--timestamp

Ensuite, invoquez pod2pdf comme ceci :

pod2pdf @/chemin/vers/mycompany.conf input.pod >output.pdf

Si vous créez un fichier de configuration appelé pod2pdf.conf et le placez dans le même répertoire que le script pod2pdf, il sera chargé comme configuration par défaut.

EXTENSIONS POD

En plus des commandes POD standard (voir perlpodspec), pod2pdf prend en charge les extensions suivantes au format POD :

"=ff"
La commande "=ff" insère un saut de page ( avance-feuille) dans le document.
"O<...>"
Le code de formatage "O<...>" insère un objet externe (fichier) dans le document. Ceci est principalement destiné à l'intégration d'images, par exemple : 
O</chemin/vers/figure1.jpg>

pour insérer des diagrammes, etc. dans la documentation.

pod2pdf prend en charge les types de fichiers JPG, GIF, TIFF, PNG et PNM pour les objets intégrés.

DÉPENDANCES

pod2pdf nécessite les modules suivants installés :

PDF::API2
Pod::Escapes
Getopt::ArgvFile

De plus, pour utiliser des images, les modules File::Type et Image::Size doivent être installés, et pour spécifier des tailles de page alternatives, le module Paper::Specs est requis.
