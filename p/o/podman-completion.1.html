NOM

podman completion - Génère des scripts d'achèvement de shell

SYNTAXE

podman completion [options] bash | zsh | fish | powershell

DESCRIPTION

podman completion génère des scripts d'achèvement de shell pour une variété de shells. Les shells pris en charge sont bash, zsh, fish et powershell.

Ces scripts sont utilisés par le shell pour fournir des suggestions et compléter les commandes lorsque la commande est tapée et que [TAB] est pressé.

Habituellement, ces scripts sont automatiquement installés via le gestionnaire de paquets.

OPTIONS

--file, -f=fichier

Écrit la sortie générée dans un fichier.

--no-desc

Ne pas fournir de description dans les complétions.
La valeur par défaut est false.

INSTALLATION

BASH

bash-completion doit être installé sur le système.

Pour charger le script d'achèvement dans la session actuelle, exécutez :

source <(podman completion bash)

Pour le rendre disponible pour toutes les sessions bash, exécutez :

podman completion -f /etc/bash_completion.d/podman bash

ZSH

L'achèvement du shell doit déjà être activé dans l'environnement. Ce qui suit peut être exécuté :

echo "autoload -U compinit; compinit" >> ~/.zshrc

Pour le rendre disponible pour toutes les sessions zsh, exécutez :

podman completion -f "${fpath[1]}/_podman" zsh

Une fois le shell rechargé, l'achèvement automatique fonctionne.

FISH

Pour charger le script d'achèvement dans la session actuelle, exécutez :

podman completion fish | source

Pour le rendre disponible pour toutes les sessions fish, exécutez :

podman completion -f ~/.config/fish/completions/podman.fish fish

POWERSHELL

Pour charger le script d'achèvement dans la session actuelle, exécutez :

podman.exe completion powershell | Out-String | Invoke-Expression

Pour le rendre disponible dans toutes les sessions powershell qu'un utilisateur possède, écrivez la sortie d'achèvement dans un fichier et référencez-le dans le profil powershell de l'utilisateur. Plus d'informations sur les profils sont disponibles avec Get-Help about_Profiles.

VOIR AUSSI

podman(1), zsh(1), fish(1), powershell(1)
