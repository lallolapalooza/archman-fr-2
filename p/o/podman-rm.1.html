podman-rm(1) Manuel des commandes générales podman-rm(1)

NOM

podman-rm - Supprime un ou plusieurs conteneurs

SYNTAXE

podman rm [options] conteneur

podman container rm [options] conteneur

DESCRIPTION

podman rm supprime un ou plusieurs conteneurs de l'hôte. Le nom ou l'ID du conteneur peut être utilisé. Ceci ne supprime pas les images. Les conteneurs en cours d'exécution ou inutilisables ne sont pas supprimés sans l'option -f.

OPTIONS

--all, -a

Supprime tous les conteneurs. Peut être utilisé conjointement avec -f.

--cidfile=fichier

Lit l'ID du conteneur à partir du fichier spécifié et supprime le conteneur. Peut être spécifié plusieurs fois.

La commande ne renvoie pas d'erreur lorsque le fichier est absent et que l'utilisateur a spécifié --ignore.

--depend

Supprime le conteneur sélectionné et supprime récursivement tous les conteneurs qui en dépendent.

--filter=filtre

Filtre les conteneurs à supprimer. Plusieurs filtres peuvent être donnés en utilisant plusieurs fois l'option --filter. Les filtres avec la même clé fonctionnent de manière inclusive, à l'exception de label qui est exclusive. Les filtres avec des clés différentes fonctionnent toujours de manière exclusive.

Les filtres valides sont listés ci-dessous :

Filtre Description
id [ID] ID du conteneur (correspondance de préfixe CID par défaut ; accepte les regex)
name [Nom] Nom du conteneur (accepte les regex)
label [Clé] ou [Clé=Valeur] Étiquette attribuée à un conteneur
exited [Int] Code de sortie du conteneur
status [Statut] Statut du conteneur : 'created', 'initialized', 'exited', 'paused', 'running', 'unknown'
ancestor [NomImage] Image ou descendant utilisé pour créer le conteneur
before [ID] ou [Nom] Conteneurs créés avant ce conteneur
since [ID] ou [Nom] Conteneurs créés depuis ce conteneur
volume [NomVolume] ou [PointMontageDestination] Volume monté dans le conteneur
health [Statut] healthy ou unhealthy
pod [Pod] nom ou ID complet ou partiel du pod
network [Réseau] nom ou ID complet du réseau
until [DateTime] Conteneurs créés avant la durée ou l'heure spécifiée.
command [Commande] la commande exécutée par le conteneur, seul argv[0] est pris en compte

--force, -f

Force la suppression des conteneurs en cours d'exécution et en pause. Forcer la suppression d'un conteneur supprime également les conteneurs du stockage de conteneurs, même si le conteneur n'est pas connu de Podman. Par exemple, les conteneurs créés par d'autres moteurs de conteneurs comme Buildah. De plus, forcer peut être utilisé pour supprimer des conteneurs inutilisables, par exemple des conteneurs dont le runtime OCI est devenu indisponible.

--ignore, -i

Ignore les erreurs lorsque les conteneurs spécifiés ne sont pas dans le stockage de conteneurs. Un utilisateur pourrait avoir décidé de supprimer manuellement un conteneur, ce qui entraîne une erreur lors de la directive ExecStop d'un service systemd faisant référence à ce conteneur.

Ignore également lorsque le --cidfile spécifié n'existe pas, car il pourrait avoir déjà été supprimé avec le conteneur.

--latest, -l

Au lieu de fournir le nom ou l'ID du conteneur, utilise le dernier conteneur créé. Remarque : le dernier conteneur démarré peut provenir d'autres utilisateurs de Podman sur la machine hôte. (Cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (à l'exception de WSL2)).

--time, -t=secondes

Nombre de secondes à attendre avant d'arrêter de force le conteneur. Utilisez -1 pour attendre indéfiniment.

L'option --force doit être spécifiée pour utiliser l'option --time.

--volumes, -v

Supprime les volumes anonymes associés au conteneur. Cela n'inclut pas les volumes nommés créés avec podman volume create, ni l'option --volume de podman run et podman create.

EXEMPLES

Supprimer un conteneur avec un nom donné :

$ podman rm mon-serveur-web

Supprimer un conteneur avec un nom donné et tous les conteneurs qui en dépendent :

$ podman rm --depend mon-serveur-web

Supprimer plusieurs conteneurs avec des noms ou des IDs donnés :

$ podman rm mon-serveur-web mon-serveur-flask 860a4b23

Supprimer plusieurs conteneurs dont les IDs sont lus à partir de fichiers :

$ podman rm --cidfile ./cidfile-1 --cidfile /home/user/cidfile-2

Forcer la suppression d'un conteneur avec un ID donné :

$ podman rm -f 860a4b23

Supprimer tous les conteneurs, quel que soit leur état d'exécution :

$ podman rm -f -a

Forcer la suppression du dernier conteneur créé. (Cette option n'est pas disponible avec le client Podman distant, y compris sur les machines Mac et Windows (à l'exception de WSL2)) :

$ podman rm -f --latest

Supprimer par nom :

$ podman rm --filter name=test-alpine

Statut de sortie

0 Tous les conteneurs spécifiés ont été supprimés

1 L'un des conteneurs spécifiés n'existait pas, et aucune autre erreur

2 L'un des conteneurs spécifiés est en pause ou en cours d'exécution

125 La commande échoue pour toute autre raison
