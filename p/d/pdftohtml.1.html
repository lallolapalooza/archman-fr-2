PDFTOHTML(1) Manuel des commandes générales PDFTOHTML(1)

NOM

pdftohtml - programme pour convertir des fichiers PDF en HTML, XML et images PNG

SYNOPHIS

pdftohtml [options] <fichier PDF> [<fichier HTML> <fichier XML>]

DESCRIPTION

Cette page de manuel documente brièvement la commande pdftohtml. Cette page de manuel a été rédigée pour la distribution Debian GNU/Linux car le programme original n'a pas de page de manuel.

pdftohtml est un programme qui convertit des documents PDF en HTML. Il génère sa sortie dans le répertoire de travail courant. Si fichier PDF est ´-', il lit le fichier PDF depuis l'entrée standard.

OPTIONS

Un résumé des options est inclus ci-dessous.

-h, -help
Affiche un résumé des options.
-f <entier>
Première page à imprimer
-l <entier>
Dernière page à imprimer
-q
N'imprime aucun message ou erreur
-v
Affiche les informations de copyright et de version
-p
Remplace les liens .pdf par .html
-c
Génère une sortie complexe
-s
Génère un unique fichier HTML incluant toutes les pages
-dataurls
Utilise des URLs de données au lieu d'images externes dans le HTML. Non disponible sur toutes les plateformes
-i
Ignore les images
-noframes
Ne génère pas de cadres. Non supporté en mode sortie complexe.
-stdout
Utilise la sortie standard
-zoom <fp>
Zoome le document PDF (par défaut 1.5) (1 signifie 72 DPI)
-xml
Sortie pour post-traitement XML
-noroundcoord
N'arrondit pas les coordonnées (uniquement avec la sortie XML)
-enc <chaîne>
Nom de l'encodage du texte de sortie
-opw <chaîne>
Mot de passe du propriétaire (pour les fichiers cryptés)
-upw <chaîne>
Mot de passe utilisateur (pour les fichiers cryptés)
-hidden
Force l'extraction du texte caché
-fmt
Format de fichier image pour la sortie Splash (png ou jpg). Si complexe est sélectionné mais que -fmt n'est pas spécifié, -fmt png sera supposé
-nomerge
Ne fusionne pas les paragraphes
-nodrm
Ignore les paramètres DRM du document
-wbt <fp>
Ajuste le seuil de césure de mots en pourcentage. La valeur par défaut est 10. La césure de mot se produit lorsque la distance entre deux caractères adjacents est supérieure à ce pourcentage de la hauteur du caractère.
-fontfullname
Affiche le nom de la police sans aucune substitution.
