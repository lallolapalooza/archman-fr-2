pdfsig(1) Manuel des commandes générales pdfsig(1)

NOM

pdfsig - Outil de signatures numériques au format PDF (Portable Document Format)

SYNTAXE

pdfsig [options] [fichier-PDF] [fichier-sortie]

DESCRIPTION

pdfsig vérifie les signatures numériques d'un document PDF. Il affiche également l'identité de chaque signataire (champ commonName et nom distinctif complet du certificat du signataire), l'heure et la date de la signature, l'algorithme de hachage utilisé pour la signature, le type de signature tel qu'indiqué dans le PDF, ainsi que les plages signées et une déclaration indiquant si le document complet est signé. Il peut également signer des documents PDF (options -add-signature ou -sign).

pdfsig utilise les certificats de confiance stockés soit dans la base de données Network Security Services (NSS), soit dans le système S/MIME de GnuPG (gpgsm).

pdfsig utilise également le protocole OCSP (Online Certificate Status Protocol) (voir http://en.wikipedia.org/wiki/Online_Certificate_Status_Protocol) pour rechercher le certificat en ligne et vérifier s'il a été révoqué (sauf si -no-ocsp a été spécifié).

Si le backend NSS est utilisé, la base de données NSS est recherchée aux emplacements suivants :

  • Si l'option -nssdir est spécifiée, le répertoire spécifié par cette option.
  • La base de données de certificats NSS du profil Firefox par défaut. C'est-à-dire $HOME/.mozilla/firefox/*.default.
  • La base de données de certificats NSS dans /etc/pki/nssdb.

Si le backend GPG est utilisé, le certificat S/MIME est lu depuis $GNUPGHOME, qui est par défaut $HOME/.gnupg.

OPTIONS

-nssdir [préfixe]répertoire
Spécifie le répertoire de la base de données contenant les fichiers de la base de données de certificats et de clés. Voir l'option -d de certutil(1) pour les détails du préfixe. Si non spécifié, les autres emplacements de recherche décrits dans DESCRIPTION sont utilisés.
-nss-pwd mot-de-passe
Spécifie le mot de passe nécessaire pour accéder à la base de données NSS (le cas échéant).
-nocert
Ne pas valider le certificat.
-no-ocsp
Ne pas effectuer de vérification de révocation de certificat OCSP en ligne (les listes de révocation de certificats (CRL) locales sont toujours utilisées).
-assert-signer empreinte_ou_fichier
Cette option vérifie si la signature couvrant le document complet a été faite avec la clé spécifiée. La clé est spécifiée soit par une empreinte, soit par un fichier listant des empreintes. L'empreinte doit être donnée ou listée au format compact (pas de deux-points ou d'espaces entre les caractères). Si empreinte_ou_fichier spécifie un fichier, les lignes vides sont ignorées ainsi que toutes les lignes commençant par un signe dièse. Uniquement disponible pour le backend GnuPG.
-no-appearance
Ne pas ajouter d'informations d'apparence lors de la signature de champs existants (nom du signataire et date).
-aia
Activer l'utilisation de l'extension Authority Information Access (AIA) pour récupérer les certificats manquants afin de construire la chaîne de certificats.
-dump
Extraire toutes les signatures dans le répertoire courant dans leur format natif. Il s'agit très probablement d'un lot CMS/PKCS7 non rembourré ou rembourré de zéros.
-add-signature
Ajouter une nouvelle signature au document.
-new-signature-field-name nom
Spécifie le nom du champ à utiliser lors de l'ajout d'une nouvelle signature. Un identifiant aléatoire sera utilisé par défaut.
-sign champ
Signer le document dans le champ de signature spécifié présent dans le document (doit être non signé). Le champ peut être spécifié par son nom (chaîne de caractères) ou comme n-ième champ de signature dans le document (entier).
-nick surnom
Utiliser le certificat avec le surnom donné pour la signature (backend NSS). Si le surnom commence par pkcs11:, il est traité comme une URI PKCS#11 (backend NSS). Si le surnom est donné sous forme d'empreinte, ce sera le certificat utilisé (backend GPG).
-backend backend
Utiliser le backend spécifié pour les signatures cryptographiques.
-kpw mot-de-passe
Utiliser le mot de passe donné pour la clé de signature (cela peut être manquant si la clé n'est pas protégée par mot de passe).
-digest algorithme
Utiliser l'algorithme de hachage donné pour la signature (par défaut : SHA256).
-reason raison
Définir la chaîne de caractères de raison donnée pour la signature (par défaut : aucune raison définie).
-enable-pgp
Activer les signatures PGP dans le backend GnuPG. Uniquement disponible pour le backend GnuPG.
-etsi
Créer une signature de type ETSI.CAdES.detached au lieu de adbe.pkcs7.detached.
-list-nicks
Lister les surnoms disponibles dans la base de données NSS.
-list-backends
Lister les backends disponibles pour les signatures cryptographiques.
-v
Afficher les informations de copyright et de version.
-h
Afficher les informations d'utilisation. (-help et --help sont équivalents.)

EXEMPLES

pdfsig fichier_signe.pdf
Affiche les informations de signature pour fichier_signe.pdf.
pdfsig entree.pdf sortie.pdf -add-signature -nss-pwd motdepasse -nick mon-cert -reason 'pour le plaisir !'
Crée un nouveau PDF nommé sortie.pdf avec le contenu de entree.pdf signé par le certificat 'mon-cert'.
pdfsig entree.pdf sortie.pdf -add-signature -nss-pwd motdepasse -nick 'pkcs11:token=carte_intelligente0;object=Deuxieme%20certificat;type=cert'
Identique, mais utilise une URI PKCS#11 telle que définie dans l'IETF RFC 7512 pour sélectionner le certificat à utiliser pour la signature.
pdfsig entree.pdf sortie.pdf -sign 0 -nss-pwd motdepasse -nick mon-cert -reason 'pour le plaisir !'
Crée un nouveau PDF nommé sortie.pdf avec le contenu de entree.pdf signé par le certificat 'mon-cert'. entree.pdf doit avoir un champ de signature existant et non signé.

pdfsig(1)

NOM

pdfsig - Signatures numériques des documents PDF

SYNOPIS

pdfsig [options] <PDF-file>

DESCRIPTION

pdfsig est un programme utilitaire qui vérifie les signatures numériques d'un document PDF.

OPTIONS

-h, --help
Affiche un message d'aide et quitte.
-v, --version
Affiche les informations sur la version et quitte.

EXEMPLES

Vérifier les signatures du fichier document.pdf :

pdfsig document.pdf
