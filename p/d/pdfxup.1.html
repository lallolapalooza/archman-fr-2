NOM

pdfxup - outil n-up avec marges réduites

SYNTAXE

pdfxup [OPTIONS] [FICHIER]

DESCRIPTION

pdfxup crée un document PDF où chaque page est obtenue en combinant plusieurs pages d'un fichier PDF donné en sortie. La caractéristique importante de pdfxup, par rapport à des programmes similaires, est qu'il essaie de calculer la boîte englobante (globale) du fichier PDF d'entrée, afin de supprimer les marges et de ne conserver que le texte. Au lieu d'avoir la taille de police divisée par 2 (pour le cas d'une sortie 2-up), vous pourriez dans certains cas vous retrouver avec une taille de police quasi identique à celle du document original (comme c'est le cas pour un document 'article' par défaut produit par LaTeX).

pdfxup utilise ghostscript pour calculer la boîte englobante maximale de (certaines) pages du document, puis utilise pdflatex (avec le package graphicx) afin de produire le nouveau document.

OPTIONS

pdfxup accepte de nombreuses options. Les plus importantes sont :

-x m, --colonnes m
définit le nombre de colonnes du fichier de sortie (par défaut 2) ;
-y n, --lignes n
définit le nombre de lignes de la sortie (par défaut 1) ;
-nup mxn, --nup mxn
définit le nombre de lignes et de colonnes de la sortie (par défaut 2x1) ;
-l (0|1), --paysage, --portrait
définit l'orientation du papier (du document final) ;
-cf fichier, --config fichier, --mode fichier
lit le fichier (avec l'extension .xup) et utilise les options définies dans ce fichier (voir ci-dessous pour les détails sur les fichiers .xup). Toutes les options sont traitées dans l'ordre où elles apparaissent sur la ligne de commande, de sorte qu'il est possible de modifier les options définies dans le fichier de configuration (et il est même possible d'inclure plusieurs fichiers de configuration, le dernier écrasant les options définies par les précédents). Les fichiers sont recherchés en utilisant kpsewhich (si disponible).
-b (le|se), --brochure (le|se)
configure pour l'impression en brochure. La valeur 'le' (qui est la valeur par défaut lorsque -b est utilisé sans argument) signifie que l'impression recto-verso est en mode 'bord long' (vous tournez d'une page à la suivante le long du bord long du papier). 'se' est l'option 'bord court'.
-c, --recadrer, -nc, --no-recadrer
recadre (ou ne recadre pas) les pages dans la boîte englobante calculée. Par défaut, le contenu est recadré, pour éviter le chevauchement entre pages voisines. Avec --no-recadrer, tout ce qui est en dehors de la boîte englobante sera affiché.
-o fichier, --sortie fichier
nom du fichier de sortie.
-i
demande avant d'écraser le fichier de sortie.
-ow
écrase le fichier de sortie sans demander.
-ps s, --papier s
définit la taille du papier (par défaut a4). Le nom doit être connu du package geometry (plus précisément, "<s>paper" doit être défini dans ce package).
-fw d, --largeur-cadre d
largeur du cadre autour de chaque page (par défaut 0.4pt). Mettre à 0pt pour ne pas avoir de cadre du tout.
-tf [0|1], --cadre-serré [0|1]
indique si le cadre doit être serré autour de la page, laissant un espace blanc horizontal à l'extérieur du cadre, ou s'il doit être large et s'étendre sur toute la largeur disponible.
-im d, --marges-internes d
marge interne entre le cadre et la page (par défaut 5pt).
-m d, --marges d
marge des pages du nouveau document (par défaut 5pt).
-is d, --espaces-inter d
espace entre différentes pages (par défaut 1pt).
-p liste, --pages liste
n'inclut que la sous-liste de pages du document d'entrée. La liste est une liste de pages ou de plages de pages séparées par des virgules sous la forme a-b ; a peut être omis pour commencer à la première page, et b peut être omis pour terminer à la dernière page. Par conséquent, ""-p -"" (qui est la valeur par défaut) inclut toutes les pages. Permet également le modulo, de sorte que ""-p 0%2"" n'inclurait que les pages paires.
-bb liste, --boite-englobante liste
n'inclut que la sous-liste de pages du document d'entrée pour le calcul de la boîte englobante.
-nobb liste, --pas-boite-englobante liste
exclut la liste de pages du document d'entrée du calcul de la boîte englobante.
-g, --recup-boite-englobante
calcule uniquement (et affiche) la boîte englobante. Ne produira aucun fichier de sortie.
-kbb, --garder-boite-englobante
ne calcule pas la boîte englobante, conserve les marges actuelles.
-s x y L H, --definir-bb x y L H
définit la boîte englobante avec les valeurs données. Les valeurs sont en pt ; les deux premiers éléments correspondent au coin inférieur gauche, tandis que les deux derniers représentent la largeur et la hauteur de la partie à afficher.
-w fichier, --filigrane fichier
utilise le fichier comme filigrane en arrière-plan. Le fichier peut être de n'importe quel format accepté par pdflatex (par exemple png ou pdf). Si le fichier est un fichier PDF multipage, la page n du fichier filigrane est utilisée avec la page n du fichier d'entrée, et la dernière page du fichier filigrane est répétée si le fichier d'entrée a plus de pages.
-wp p, --periode-filigrane p
répète les p dernières pages du fichier filigrane au lieu de seulement la dernière.
-d, --debug
mode debug : conserve les fichiers intermédiaires.
-col, --mode-colonnes, --vertical
remplit les pages de haut en bas d'abord (au lieu du mode gauche à droite par défaut). Par défaut, les pages sont insérées de gauche à droite, jusqu'à ce que la ligne soit pleine ; avec cette option, les pages sont insérées de haut en bas, jusqu'à ce que la colonne soit pleine. Par exemple : 
           ---------                     ---------
mode-ligne  | 1  2  3 |      mode-colonne  | 1  4  7 |
            | 4  5  6 |                   | 2  5  8 |
            | 7  8  9 |                   | 3  6  9 |
             ---------                     ---------
-row, --mode-lignes, --horizontal
remplit les pages de gauche à droite.
-bal, --equilibrer-derniere
équilibre la dernière page : en mode colonne, les pages sont remplies de haut en bas, et la dernière page ne fait pas exception. Néanmoins, il peut être préférable que les colonnes de la dernière page restent "équilibrées", ce que cette option réalise. Symétriquement, en mode ligne, cette option équilibrerait les lignes. 
                 ---------                        ---------
ligne, sans eq. | 1  2  3 |  colonne, sans eq.  | 1  4    |
                | 4  5    |                      | 2  5    |
                |         |                      | 3       |
                 ---------                        ---------
                 ---------                        ---------
   ligne, eq. | 1  2    |     colonne, eq.  | 1  3  5 |
              | 3  4    |                      | 2  4    |
              | 5       |                      |         |
               ---------                        ---------
-V [0-3], --verbeux [0-3]
sélectionne la verbosité (par défaut : 1).
-q, --silencieux
exécute silencieusement (équivaut à '-V 0').
-v, --version
affiche le numéro de version et quitte.
-h, --aide
affiche le message d'aide et quitte.

les (extension .xup) sont des scripts bash utilisés pour définir certaines variables. Si l'option « --config-file <fichier> » (ou équivalent) est utilisée, <fichier> est recherché d'abord avec kpsewhich, s'il ne contient pas de '/'. Si kpsewhich ne le trouve pas, alors pdfxup vérifie si le fichier existe (en utilisant 'test -e') avant de le sourcer (la variable PATH ne sera pas utilisée pour le trouver).

Le script ne doit définir que certaines variables internes de pdfxup, telles que NB_ROWS, NB_COLUMNS, LANDSCAPE (pour configurer une disposition prédéfinie). Il peut être utilisé pour définir la boîte englobante, mais il est souvent préférable de la calculer sur les premières pages du document. Voici quelques exemples de lignes qui peuvent être mises dans un fichier .xup :

NB_COLUMNS=1
définit le nombre de colonnes à 1
NB_ROWS=2
définit le nombre de lignes à 2
LANDSCAPE=0
définit le mode portrait
KEEP_ORIG_BBOX=1
ne pas rogner les marges
SET_BBOX="75 47 540 755"
définit la boîte englobante : coin inférieur gauche=(75,47) ; coin supérieur droit=(540,755)
TIGHT_FRAME=1
définit des cadres serrés autour des pages
INNER_MARGINS=10pt
définit la marge autour de chaque page (à l'intérieur du cadre) à 10pt
INTERM_SPACES=10pt
définit l'espace entre les pages à 10pt
FRAME_WIDTH=2mm
définit la largeur du cadre à 2mm

D'autres variables disponibles peuvent être trouvées dans la fonction setdefaultvalues.

EXEMPLES

# pdfxup fichier.pdf
produit un fichier pdf 2-up à partir de fichier.pdf.
# pdfxup -bb 1-4 fichier.pdf
même comportement, mais calcule la boîte englobante en utilisant uniquement les 4 premières pages (cela permet de gagner du temps lors du traitement de longs documents).
# pdfxup -b -o livret.pdf fichier.pdf
même comportement, mais crée un livret (sous le nom livret.pdf).
# pdfxup -kbb -x1 -y2 -l0 beamer-frames.pdf
dispose 2 cadres beamer par page (sans réduire les marges).
# pdfxup --mode beamer2 beamer-frames.pdf
dispose les pages PDF selon la configuration beamer2.xup.
# pdfxup -kbb -x2 -y2 -l beamer-frames.pdf:1-12,15-19
dispose 4 cadres beamer par page (sans réduire les marges), incluant uniquement les cadres 1 à 12 et 15 à 19.
