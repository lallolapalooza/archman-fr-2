pdftocairo(1) Manuel des commandes générales pdftocairo(1)

NOM

pdftocairo - Format de document portable (PDF) vers PNG/JPEG/TIFF/PDF/PS/EPS/SVG en utilisant cairo

SYNTAXE

pdftocairo [options] fichier-PDF [fichier-sortie]

DESCRIPTION

pdftocairo convertit les fichiers au format Portable Document Format (PDF), en utilisant le périphérique de sortie cairo de la bibliothèque PDF poppler, vers l'un des formats de sortie suivants :

  • Portable Network Graphics (PNG)
  • JPEG Interchange Format (JPEG)
  • Tagged Image File Format (TIFF)
  • Portable Document Format (PDF)
  • PostScript (PS)
  • Encapsulated PostScript (EPS)
  • Scalable Vector Graphics (SVG)
  • Imprimante Windows

pdftocairo lit le fichier PDF, fichier-PDF, et écrit dans fichier-sortie. Les formats d'image (PNG, JPEG et TIFF) génèrent un fichier par page, avec le numéro de page et le type de fichier ajoutés à la fin de fichier-sortie. Lorsque -singlefile est utilisé avec les formats d'image, le type de fichier est ajouté à fichier-sortie. Lorsque le format de sortie est un format vectoriel (PDF, PS, EPS et SVG), fichier-sortie est le nom de fichier complet.

Si le fichier-PDF est « - », le PDF est lu depuis l'entrée standard. Si le fichier-sortie est « - », le fichier de sortie sera écrit sur la sortie standard. L'utilisation de la sortie standard n'est pas valide avec les formats d'image, sauf si -singlefile est utilisé. Si fichier-sortie n'est pas spécifié, le nom du fichier de sortie sera dérivé du nom du fichier fichier-PDF.

Toutes les options ne sont pas valides avec tous les formats de sortie. Une (et une seule) des options de format de sortie (-png, -jpeg, -tiff, -pdf, -print, -ps, -eps ou -svg) doit être utilisée.

Les options de résolution (-r, -rx, -ry) définissent la résolution des formats de sortie image. Les dimensions de l'image dépendront de la taille de la page PDF et de la résolution. Pour les sorties vectorielles, les régions de la page qui ne peuvent pas être représentées nativement dans le format de sortie (par exemple, la translucidité en PS) seront rastérisées à la résolution spécifiée par les options de résolution.

Les options -scale-to peuvent être utilisées pour définir une taille d'image fixe. La résolution de l'image variera en fonction de la taille de la page.

Les options de recadrage (-x, -y, -W, et -H) utilisent des unités de pixels avec les formats d'image et des points PostScript (1/72 pouce) avec les formats vectoriels. Lorsque le recadrage est utilisé avec une sortie vectorielle, la région recadrée est centrée sauf si -nocenter est utilisé, auquel cas la région recadrée se trouve en haut à gauche (SVG) ou en bas à gauche (PDF, PS, EPS).

OPTIONS

-png
Génère un ou plusieurs fichiers PNG
-jpeg
Génère un ou plusieurs fichiers JPEG. Voir aussi -jpegopt.
-tiff
Génère un ou plusieurs fichiers TIFF
-pdf
Génère un fichier PDF
-ps
Génère un fichier PS
-eps
Génère un fichier EPS. Un fichier EPS contient une seule image, donc si vous utilisez cette option avec un fichier PDF multipage, vous devez utiliser -f et -l pour spécifier une seule page. Les options de taille de page (-origpagesizes, -paper, -paperw, -paperh) ne peuvent pas être utilisées avec cette option.
-svg
Génère un fichier SVG (Scalable Vector Graphics)
-print
(Windows uniquement) Imprime sur une imprimante système. Voir aussi -printer et -printeropt.
Si aucun fichier de sortie n'est spécifié, la sortie sera envoyée à l'imprimante.
Le fichier de sortie « - » ne peut pas être utilisé avec cette option.
-printdlg
(Windows uniquement) Imprime sur une imprimante système. Affiche la boîte de dialogue d'impression pour permettre la modification des options d'impression avant d'imprimer.
-f nombre
Spécifie la première page à convertir.
-l nombre
Spécifie la dernière page à convertir.
-o
Génère uniquement les pages impaires.
-e
Génère uniquement les pages paires.
-singlefile
Écrit uniquement la première page et n'ajoute pas de chiffres.
-r nombre
Spécifie la résolution X et Y, en pixels par pouce des fichiers image (ou des régions rastérisées dans la sortie vectorielle). La valeur par défaut est de 150 PPI.
-rx nombre
Spécifie la résolution X, en pixels par pouce des fichiers image (ou des régions rastérisées dans la sortie vectorielle). La valeur par défaut est de 150 PPI.
-ry nombre
Spécifie la résolution Y, en pixels par pouce des fichiers image (ou des régions rastérisées dans la sortie vectorielle). La valeur par défaut est de 150 PPI.
-scale-to nombre
Met à l'échelle le côté long de chaque page (largeur pour les pages paysage, hauteur pour les pages portrait) pour qu'il tienne dans 'nombre' pixels. La taille du côté court sera déterminée par le rapport d'aspect de la page (uniquement pour PNG/JPEG/TIFF).
-scale-to-x nombre
Met à l'échelle chaque page horizontalement pour qu'elle tienne dans 'nombre' pixels. Si scale-to-y est réglé sur -1, la taille verticale sera déterminée par le rapport d'aspect de la page (uniquement pour PNG/JPEG/TIFF).
-scale-to-y nombre
Met à l'échelle chaque page verticalement pour qu'elle tienne dans 'nombre' pixels. Si scale-to-x est réglé sur -1, la taille horizontale sera déterminée par le rapport d'aspect de la page (uniquement pour PNG/JPEG/TIFF).
-x nombre
Spécifie la coordonnée x du coin supérieur gauche de la zone de recadrage en pixels (sortie image) ou en points (sortie vectorielle)
-y nombre
Spécifie la coordonnée y du coin supérieur gauche de la zone de recadrage en pixels (sortie image) ou en points (sortie vectorielle)
-W nombre
Spécifie la largeur de la zone de recadrage en pixels (sortie image) ou en points (sortie vectorielle) (par défaut 0)
-H nombre
Spécifie la hauteur de la zone de recadrage en pixels (sortie image) ou en points (sortie vectorielle) (par défaut 0)
-sz nombre
Spécifie la taille du carré de recadrage en pixels (sortie image) ou en points (sortie vectorielle) (définit -W et -H)
-cropbox
Utilise la boîte de recadrage plutôt que la boîte de média lors de la génération des fichiers (uniquement PNG/JPEG/TIFF)
-mono
Génère un fichier monochrome (uniquement PNG et TIFF).
-gray
Génère un fichier en niveaux de gris (uniquement PNG, JPEG et TIFF).
-antialias
Définit l'option d'anticrénelage cairo utilisée pour le texte et le dessin dans les fichiers image (ou les régions rastérisées dans la sortie vectorielle). Les options sont :
default
Utilise l'anticrénelage par défaut pour le périphérique cible. C'est le réglage par défaut si -antialias n'est pas utilisé.
none
L'anticrénelage est désactivé.
gray
Effectue un anticrénelage monochrome en utilisant des nuances de gris.
subpixel
Effectue un anticrénelage en tirant parti de l'ordre des sous-pixels sur des périphériques tels que les écrans LCD.
fast
Indique au backend de réaliser un certain anticrénelage mais de privilégier la vitesse à la qualité.
good
Le backend doit équilibrer qualité et performance.
best
Indique au backend de rendre avec la plus haute qualité, quitte à sacrifier la vitesse.

OPTIONS

-transp
Utiliser une couleur de page transparente au lieu de blanc (PNG et TIFF uniquement).
-icc fichier-icc
Utiliser le fichier ICC spécifié comme profil de sortie (PNG uniquement). Le profil sera intégré dans le fichier PNG.
-jpegopt options-jpeg
Lorsqu'il est utilisé avec -jpeg, prend une liste d'options pour contrôler la compression jpeg. Voir OPTIONS JPEG pour les options disponibles.
-level2
Générer du PostScript de niveau 2 (PS uniquement).
-level3
Générer du PostScript de niveau 3 (PS uniquement). Cela active toutes les fonctionnalités de niveau 2 plus les dégradés de motifs et les images masquées. C'est le réglage par défaut.
-struct
Si le fichier d'entrée contient des informations structurelles sur le contenu du document, écrire ces informations dans le fichier de sortie (PDF uniquement).
-origpagesizes
Cette option est identique à "-paper match".
-paper taille
Définir la taille du papier sur "letter", "legal", "A4" ou "A3" (PS, PDF, SVG uniquement). Cela peut également être réglé sur "match", ce qui définira la taille du papier de chaque page pour correspondre à la taille spécifiée dans le fichier PDF. Si aucune des options -paper, -paperw ou -paperh n'est spécifiée, la valeur par défaut est de faire correspondre la taille du papier.
-paperw taille
Définir la largeur du papier, en points (PS, PDF, SVG uniquement).
-paperh taille
Définir la hauteur du papier, en points (PS, PDF, SVG uniquement).
-nocrop
Par défaut, la sortie d'impression est rognée selon le CropBox spécifié dans le fichier PDF. Cette option désactive le rognage (PS, PDF, SVG uniquement).
-expand
Agrandir les pages PDF plus petites que le papier pour remplir le papier (PS, PDF, SVG uniquement). Par défaut, ces pages ne sont pas mises à l'échelle.
-noshrink
Ne pas mettre à l'échelle les pages PDF plus grandes que le papier (PS, PDF, SVG uniquement). Par défaut, les pages plus grandes que le papier sont réduites pour s'adapter.
-nocenter
Par défaut, les pages PDF plus petites que le papier (après toute mise à l'échelle) sont centrées sur le papier. Cette option les fait aligner sur le coin inférieur gauche du papier à la place (PS, PDF, SVG uniquement).
-duplex
Ajoute le commentaire DSC %%IncludeFeature: *Duplex DuplexNoTumble au fichier PostScript (PS uniquement). Cela indique au gestionnaire d'impression d'activer le recto-verso.
-printer nom-imprimante
(Windows uniquement). Lorsqu'il est utilisé avec -print, spécifie le nom de l'imprimante à utiliser, au lieu de la valeur par défaut du système.
-printopt options-imprimante
(Windows uniquement). Lorsqu'il est utilisé avec -print, prend une liste d'options à utiliser pour configurer l'imprimante. Voir OPTIONS IMPRIMANTE WINDOWS pour les options disponibles.
-setupdlg
(Windows uniquement). Lorsqu'il est utilisé avec -print, la boîte de dialogue des propriétés de l'imprimante s'affiche, permettant de modifier les paramètres d'impression avant d'imprimer. La taille du papier sélectionnée dans la boîte de dialogue des propriétés d'impression sera utilisée, sauf si -origpagesizes est spécifié.
-opw mot-de-passe
Spécifier le mot de passe propriétaire du fichier PDF. Le fournir contournera toutes les restrictions de sécurité.
-upw mot-de-passe
Spécifier le mot de passe utilisateur du fichier PDF.
-q
Ne pas afficher de messages ni d'erreurs.
-v
Afficher les informations de copyright et de version.
-h
Afficher les informations d'utilisation. (-help et --help sont équivalents.)

CODES DE SORTIE

Les outils poppler utilisent les codes de sortie suivants :

0
Aucune erreur.
1
Erreur lors de l'ouverture d'un fichier PDF.
2
Erreur lors de l'ouverture d'un fichier de sortie.
3
Erreur liée aux permissions PDF.
4
Erreur liée au profil ICC.
99
Autre erreur.

OPTIONS JPEG

Lorsque la sortie JPEG est spécifiée, l'option -jpegopt peut être utilisée pour contrôler les paramètres de compression JPEG. Elle prend une chaîne de la forme "<opt>=<val>[,<opt>=<val>". Actuellement, les options disponibles sont :

quality
Sélectionne la valeur de qualité JPEG. La valeur doit être un entier compris entre 0 et 100.
progressive
Sélectionne la sortie JPEG progressive. Les valeurs possibles sont "y", "n", indiquant respectivement progressive (oui) ou non-progressive (non).
optimize
Définit s'il faut calculer des tables de codage Huffman optimales pour la sortie JPEG, ce qui créera des fichiers plus petits mais nécessitera un passage supplémentaire sur les données. La valeur doit être "y" ou "n", "y" effectuant l'optimisation, sinon les tables Huffman par défaut sont utilisées.

OPTIONS IMPRIMANTE WINDOWS

Sous Windows, vous pouvez utiliser l'option -print pour imprimer directement sur une imprimante système. De plus, vous pouvez utiliser l'option -printopt pour configurer l'imprimante. Elle prend une chaîne de la forme "<opt>=<val>[,<opt>=<val>". Actuellement, les options disponibles sont :

source
Sélectionne le bac papier à utiliser (bin). Les valeurs possibles sont "upper", "onlyone", "lower", "middle", "manual", "envelope", "envmanual", "auto", "tractor", "smallfmt", "largefmt", "largecapacity", "formsource", ou une valeur numérique pour choisir une source spécifique au pilote.
duplex
Définit le mode recto-verso de l'imprimante. Les valeurs possibles sont "off", "short" ou "long", indiquant respectivement pas de recto-verso, reliure par le petit côté ou reliure par le grand côté. L'option générale -duplex est un synonyme de "duplex=long". Si les deux options sont spécifiées, -printopt a la priorité.
