pdreceive(1) Manuel des commandes générales pdreceive(1)

NOM

pdreceive - recevoir des messages de pd sur cette machine ou une machine distante

SYNTAXE

pdreceive numéro-de-port [udp|tcp]

DESCRIPTION

Pdreceive ouvre une socket (avec le numéro de port spécifié) et attend l'arrivée de messages d'une ou plusieurs instances de pd(1). Chaque message reçu est affiché sur la sortie standard avec un point-virgule à la fin. Le protocole utilisé est facile à implémenter et s'appelle FUDI.

Le numéro de port doit correspondre au numéro de port d'un objet "netsend" dans pd. Le protocole est "tcp" par défaut ; cela effectue une poignée de main pour garantir que tous les messages arrivent complets et dans le bon ordre ; si vous envoyez des messages localement ou point à point, vous pouvez souvent vous contenter du protocole udp plus rapide à la place.

Vous pouvez également l'utiliser pour recevoir des messages d'un objet Max "pdnetsend" ou même simplement d'un "pdsend" dans un autre terminal. Si vous écrivez un autre programme, n'hésitez pas à récupérer les sources de pdsend/pdreceive et à les adapter à vos besoins ; elles font partie de la distribution Pd.

VOIR AUSSI
