pdfbook2(1) pdfbook2 - transformer des fichiers pdf en livrets pdfbook2(1)

NOM

pdfbook2 - transformer des fichiers pdf en livrets pour impression recto-verso

SYNTAXE

pdfbook2 [ options ] ENTRÉE [ ENTRÉE, ...]

DESCRIPTION

Crée des fichiers PDF prêts à l'impression à partir de certains fichiers PDF ENTRÉE pour l'impression de livrets. Les fichiers résultants doivent être imprimés en paysage/bord long recto-verso. Le format de papier par défaut dépend de la locale et est choisi par pdfjam. Il peut être défini avec l'option --paper.

Avant que le pdf ne soit composé, le fichier ENTRÉE est recadré à la zone pertinente afin de supprimer les espaces blancs inutiles. Dans ce processus, toutes les pages sont recadrées aux mêmes dimensions. Des marges supplémentaires peuvent être définies sur les bords du livret et au milieu où se trouve la reliure.

La SORTIE est écrite dans ENTRÉE-book.pdf. Les fichiers existants seront écrasés. Tous les fichiers d'entrée sont traités séparément.

EXEMPLE

Pour simplement créer un livret à partir de input.pdf, vous pouvez utiliser

pdfbook2 input.pdf

pour créer input-book.pdf. Pour sélectionner un type de papier spécial, vous pouvez faire

pdfbook2 --paper=letter input.pdf

pour la lettre (letter) ou

pdfbook2 --paper=a4paper input.pdf

pour le format A4 standard. Pour augmenter la marge intérieure pour la reliure, utilisez

pdfbook2 --inner-margin=200 input.pdf

pour augmenter la valeur par défaut de 150. Vous pouvez soumettre plusieurs fichiers au script pour traitement comme suit

pdfbook2 input1.pdf input2.pdf

ce qui résultera en input1-book.pdf et input2-book.pdf.

OPTIONS

--version
affiche le numéro de version du programme et quitte
-h, --help
affiche le message d'aide et quitte

GÉNÉRAL

-p, --paper=STR
Format des dimensions du papier de sortie en tant que mot-clé latex (par exemple, a4paper, letterpaper, legalpaper, ...)
-s, --short-edge
Formater le livret pour une impression recto-verso sur le bord court
-n, --no-crop
Empêcher le recadrage à la zone de contenu

MARGES

-o, --outer-margin=INT
Définit la marge extérieure dans le livret (par défaut : 40)
-i, --inner-margin=INT
Définit la marge intérieure entre les pages du livret (par défaut : 150)
-t, --top-margin=INT
Définit la marge supérieure dans le livret (par défaut : 30)
-b, --bottom-margin=INT
Définit la marge inférieure dans le livret (par défaut : 30)

AVANCÉ

--signature=INT
Définit la signature pour le livret transmise à pdfjam, doit être un multiple de 4 (par défaut : 4)
--signature*=INT
Identique à --signature
--resolution=INT
Résolution utilisée par ghostscript en bp (par défaut : 72)
