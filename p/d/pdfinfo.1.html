pdfinfo(1) Manuel des commandes générales pdfinfo(1)

NOM

pdfinfo - Extracteur d'informations de document Portable Document Format (PDF) (version 3.03)

SYNTAXE

pdfinfo [options] [fichier-PDF]

DESCRIPTION

Pdfinfo imprime le contenu du dictionnaire ´Info' (ainsi que d'autres informations utiles) à partir d'un fichier Portable Document Format (PDF).

Si fichier-PDF est ´-', il lit le fichier PDF depuis l'entrée standard.

Le dictionnaire ´Info' contient les valeurs suivantes :

titre
sujet
mots-clés
auteur
créateur
producteur
date de création
date de modification

De plus, les informations suivantes sont imprimées :

métadonnées personnalisées (oui/non)
flux de métadonnées (oui/non)
étiqueté (oui/non)
propriétés utilisateur (oui/non)
suspects (oui/non)
formulaire (AcroForm / XFA / aucun)
javascript (oui/non)
nombre de pages
indicateur crypté (oui/non)
autorisations d'impression et de copie (si crypté)
taille de la page
taille du fichier
linéarisé (oui/non)
version PDF
métadonnées (seulement si demandé)

Les options -listenc, -meta, -js, -struct, et -struct-text impriment uniquement les informations demandées. Le dictionnaire 'Info' et les données associées listées ci-dessus ne sont pas imprimés. Au plus une de ces cinq options peut être utilisée.

OPTIONS

-f numéro
Spécifie la première page à examiner. Si plusieurs pages sont demandées en utilisant les options "-f" et "-l", la taille de chaque page demandée (et, facultativement, les boîtes englobantes pour chaque page demandée) sont imprimées. Sinon, seule la page un est examinée.
-l numéro
Spécifie la dernière page à examiner.
-box
Imprime les boîtes englobantes de la page : MediaBox, CropBox, BleedBox, TrimBox, et ArtBox.
-meta
Imprime les métadonnées au niveau du document. (Ceci est le flux "Metadata" de l'objet Catalog du fichier PDF.)
-custom
Imprime les métadonnées personnalisées et standard.
-js
Imprime tout le JavaScript dans le PDF.
-struct
Imprime la structure logique du document d'un fichier PDF étiqueté.
-struct-text
Imprime le contenu textuel ainsi que la structure du document d'un fichier PDF étiqueté. Notez que l'extraction de texte de cette manière peut être lente pour les gros fichiers PDF. (Implique -struct.)
-url
Imprime toutes les URL dans le PDF. Seuls les types d'URL pris en charge par Poppler sont listés. Actuellement, cela est limité aux annotations. Note : seules les URL référencées par les objets PDF tels que les annotations de lien sont listées. pdfinfo ne tente pas d'extraire les chaînes correspondant à http://... du contenu textuel.
-isodates
Imprime les dates au format ISO-8601 (y compris le fuseau horaire).
-rawdates
Imprime les chaînes de dates brutes (non décodées), directement depuis le fichier PDF.
-dests
Imprime une liste de toutes les destinations nommées. Si une plage de pages est spécifiée en utilisant "-f" et "-l", seules les destinations dans la plage de pages sont listées.
-enc nom-encodage
Définit l'encodage à utiliser pour la sortie texte. Ceci est par défaut "UTF-8".
-listenc
Liste les encodages disponibles.
-opw mot-de-passe
Spécifie le mot de passe du propriétaire pour le fichier PDF. Le fournir contournera toutes les restrictions de sécurité.
-upw mot-de-passe
Spécifie le mot de passe utilisateur pour le fichier PDF.
-v
Imprime les informations de copyright et de version.
-h
Imprime les informations d'utilisation. (-help et --help sont équivalents.)

CODES DE SORTIE

Les outils Xpdf utilisent les codes de sortie suivants :

0
Aucune erreur.
1
Erreur lors de l'ouverture d'un fichier PDF.
2
Erreur lors de l'ouverture d'un fichier de sortie.
3
Erreur liée aux autorisations PDF.
99
Autre erreur.
