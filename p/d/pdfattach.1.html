pdfattach(1) Manuel des commandes générales pdfattach(1)

NOM

pdfattach - Créateur de fichiers embarqués pour documents Portable Document Format (PDF) (version 3.03)

SYNTAXE

pdfattach [options] fichier-PDF-entrée fichier-à-attacher fichier-PDF-sortie

DESCRIPTION

Pdfattach ajoute un nouveau fichier embarqué (pièce jointe) à un fichier Portable Document Format (PDF) existant.

OPTIONS

-replace
Remplace le fichier embarqué portant le même nom (s'il existe)
-v
Affiche les informations de copyright et de version.
-h
Affiche les informations d'utilisation. (-help et --help sont équivalents.)

CODES DE SORTIE

0
Aucune erreur.
1
Erreur lors de l'ouverture du fichier PDF d'entrée.
2
Erreur lors de l'ouverture du fichier à attacher.
3
Le fichier de sortie existe déjà.
3
Il existe déjà un fichier joint portant ce nom.
5
Erreur lors de l'enregistrement du fichier de sortie.
