PDFJADETEX(1) Manuel des commandes générales PDFJADETEX(1)

NOM

pdfjadetex - Sortie PDF depuis JadeTeX

SYNTAXE

pdfjadetex [options] [commandes]

DESCRIPTION

Cette page de manuel a été dérivée de la page de manuel de pdfTeX et n'est pas exhaustive. La documentation complète de cette version de TeX se trouve dans le fichier info ou le manuel Web2C: A TeX implementation.

pdfjadeTeX est une version de TeX qui peut créer des fichiers PDF ainsi que des fichiers DVI.

L'utilisation typique de pdfjadeTeX est avec des formats pré-générés pour lesquels la sortie PDF a été activée. La commande pdfjadetex utilise l'équivalent du format simple JadeTeX.

La gestion des arguments de ligne de commande par pdfjadeTeX est similaire à celle de LaTeX.

OPTIONS

Cette version de pdfjadeTeX comprend les options de ligne de commande suivantes.

--fmt format
Utilise format comme nom du format à utiliser, au lieu du nom sous lequel pdfjadeTeX a été appelé ou d'une ligne %&.
--help
Affiche le message d'aide et quitte.
--ini
Est pdfinitex, pour décharger les formats ; ceci est implicitement vrai si le programme est appelé comme pdfinitex.
--interaction mode
Définit le mode d'interaction. Le mode peut être l'un des suivants : batchmode, nonstopmode, scrollmode et errorstopmode. La signification de ces modes est la même que celle des \commandes correspondantes.
--ipc
Envoie la sortie DVI ou PDF à un socket ainsi qu'au fichier de sortie habituel. La disponibilité de cette option dépend de l'installateur.
--ipc-start
Comme --ipc, et démarre également le serveur à l'autre extrémité. La disponibilité de cette option dépend de l'installateur.
--kpathsea-debug masque-binaire
Définit les indicateurs de débogage de recherche de chemin selon le masque binaire. Voir le manuel Kpathsea pour plus de détails.
--maketex fmt
Active mktexfmt, où fmt doit être l'un de tex ou tfm.
--no-maketex fmt
Désactive mktexfmt, où fmt doit être l'un de tex ou tfm.
--output-comment chaîne
Utilise chaîne pour le commentaire du fichier DVI au lieu de la date.
--progname nom
Se fait passer pour le programme nom. Ceci affecte à la fois le format utilisé et les chemins de recherche.
--shell-escape
Active la construction \write18{commande}. La commande peut être n'importe quelle commande de shell Bourne. Cette construction est normalement interdite pour des raisons de sécurité.
--version
Affiche les informations de version et quitte.

ENVIRONNEMENT

Voir la documentation de la bibliothèque Kpathsearch (le nœud "Path specifications") pour les détails précis sur la façon dont les variables d'environnement sont utilisées. L'utilitaire kpsewhich peut être utilisé pour interroger les valeurs des variables.

Une mise en garde : dans la plupart des formats pdfjadeTeX, vous ne pouvez pas utiliser ~ dans un nom de fichier que vous donnez directement à pdfjadeTeX, car ~ est un caractère actif, et est donc développé, et non pris comme faisant partie du nom de fichier. D'autres programmes, comme Metafont, n'ont pas ce problème.

TEXMFOUTPUT
Normalement, pdfjadeTeX place ses fichiers de sortie dans le répertoire courant. Si un fichier de sortie ne peut pas être ouvert là, il essaie de l'ouvrir dans le répertoire spécifié par la variable d'environnement TEXMFOUTPUT. Il n'y a pas de valeur par défaut pour cette variable. Par exemple, si vous tapez tex paper et que le répertoire courant n'est pas accessible en écriture, si TEXMFOUTPUT a la valeur /tmp, pdfjadeTeX tente de créer /tmp/paper.log (et /tmp/paper.pdf, s'il y a une sortie produite.)
TEXINPUTS
Chemin de recherche pour les fichiers \input et \openin. Ceci devrait probablement commencer par ``.'', de sorte que les fichiers utilisateur soient trouvés avant les fichiers système.
TEXFONTS
Chemin de recherche pour les fichiers de métriques de polices (.tfm).
TEXFORMATS
Chemin de recherche pour les fichiers de formats.
TEXPOOL
Chemin de recherche pour les chaînes internes de pdfinitex.
TEXEDIT
Modèle de commande pour basculer vers l'éditeur. La valeur par défaut, généralement vi, est définie lors de la compilation de pdfjadeTeX.

FICHIERS

L'emplacement des fichiers mentionnés ci-dessous varie d'un système à l'autre. Utilisez l'utilitaire kpsewhich pour trouver leurs emplacements.

pdfjadetex.pool
Texte encodé des messages de pdfjadeTeX.
texfonts.map
Définitions de mappage de noms de fichiers.
*.tfm
Fichiers de métriques pour les polices de pdfjadeTeX.
*.fmt
Fichiers de formats pdfjadeTeX prédigérés (.fmt).

BOGUES

Cette version de pdfjadeTeX ne parvient pas à intercepter le dépassement arithmétique lors de l'addition ou de la soustraction de dimensions. Les cas où cela se produit sont rares, mais lorsqu'ils se produisent, le fichier DVI généré sera invalide.

VOIR AUSSI

jadetex(1), tex(1), mf(1), undump(1).

jadetex(1)

jadetex - Utilitaire pour convertir des documents DocBook en TeX.

SYNTAXE

jadetex [OPTIONS] FICHIER_ENTREE...

DESCRIPTION

jadetex est un programme qui permet de convertir des documents écrits en DocBook (un dialecte de SGML ou XML) en un format compatible avec TeX. Il utilise le moteur Jade (un processeur DSSSL) en arrière-plan pour effectuer la conversion.

OPTIONS

Les options spécifiques dépendent de la configuration de Jade et des feuilles de style utilisées. Les options courantes peuvent inclure :

  • -d style.ssd : Spécifie le fichier de style DSSSL à utiliser.
  • -s sgml-declaration : Spécifie la déclaration SGML.
  • -o fichier_sortie : Spécifie le nom du fichier de sortie.

EXEMPLES

Pour convertir un document DocBook nommé mon_document.xml en un fichier TeX nommé mon_document.tex : 

jadetex -o mon_document.tex mon_document.xml

FICHIERS

Aucun fichier système spécifique n'est mentionné, car la plupart des configurations dépendent des feuilles de style DSSSL.

VOIR AUSSI

jade(1), tex(1), sgmltools(1)
