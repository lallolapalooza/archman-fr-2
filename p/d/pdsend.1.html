pdsend(1) Manuel des commandes générales pdsend(1)

NOM

pdsend - envoyer des messages à pd sur cette machine ou une machine distante

SYNTAXE

pdsend numéro-de-port [nom-hote] [udp|tcp]

DESCRIPTION

Pdsend envoie des messages à pd(1), via une connexion socket, depuis l'entrée standard de pdsend. Cette entrée peut être n'importe quel flux de messages Pd séparés par des points-virgules. C'est probablement la manière la plus simple de contrôler pd depuis une autre application. Le protocole utilisé est facile à implémenter et s'appelle FUDI.

Le numéro de port doit correspondre au numéro de port d'un objet "netreceive" dans pd. Le nom d'hôte est "localhost" par défaut et peut être un nom de domaine ou une adresse IP. Le protocole est "tcp" par défaut ; cela effectue une poignée de main pour garantir que tous les messages arrivent complets et dans leur ordre correct ; si vous envoyez des messages localement ou en point à point, vous pouvez souvent vous contenter du protocole udp, plus rapide, à la place.

Vous pouvez également utiliser ceci pour communiquer avec un objet "pdnetreceive" de Max ou même simplement un "pdreceive" dans un autre shell. Si vous écrivez une autre application, vous êtes libre de simplement prendre les sources de pdsend/pdreceive et de les adapter à vos propres besoins ; ils font partie de la distribution Pd.
