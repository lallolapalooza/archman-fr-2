pdftops(1) Manuel des commandes générales pdftops(1)

NOM

pdftops - Convertisseur de Portable Document Format (PDF) en PostScript (version 3.03)

SYNTAXE

pdftops [options] <fichier-PDF> [<fichier-PS>]

DESCRIPTION

Pdftops convertit les fichiers Portable Document Format (PDF) en PostScript afin qu'ils puissent être imprimés.

Pdftops lit le fichier PDF, fichier-PDF, et écrit un fichier PostScript, fichier-PS. Si fichier-PS n'est pas spécifié, pdftops convertit fichier.pdf en fichier.ps (ou fichier.eps avec l'option -eps). Si fichier-PS est ´-', le PostScript est envoyé sur stdout. Si fichier-PDF est ´-', Pdftops lit le fichier PDF depuis stdin.

OPTIONS

-f nombre
Spécifie la première page à imprimer.
-l nombre
Spécifie la dernière page à imprimer.
-level1
Génère du PostScript de Niveau 1. Les fichiers PostScript résultants seront significativement plus grands (s'ils contiennent des images), mais s'imprimeront sur des imprimantes de Niveau 1. Cela convertit également toutes les images en noir et blanc. Pas plus d'une des options de niveau PostScript (-level1, -level1sep, -level2, -level2sep, -level3, -level3sep) ne peut être donnée.
-level1sep
Génère du PostScript séparable de Niveau 1. Toutes les couleurs sont converties en CMJN. Les images sont écrites avec des données de flux séparées pour les quatre composantes.
-level2
Génère du PostScript de Niveau 2. Le Niveau 2 prend en charge les images en couleur et la compression d'images. C'est le réglage par défaut.
-level2sep
Génère du PostScript séparable de Niveau 2. Toutes les couleurs sont converties en CMJN. Les opérateurs de convention de séparation PostScript sont utilisés pour gérer les couleurs personnalisées (tons directs).
-level3
Génère du PostScript de Niveau 3. Cela active toutes les fonctionnalités de Niveau 2 plus l'incorporation des polices CID.
-level3sep
Génère du PostScript séparable de Niveau 3. La gestion des séparations est identique à celle de -level2sep.
-eps
Génère un fichier Encapsulated PostScript (EPS). Un fichier EPS contient une seule image, donc si vous utilisez cette option avec un fichier PDF multi-pages, vous devez utiliser -f et -l pour spécifier une seule page. Pas plus d'une des options de mode (-eps, -form) ne peut être donnée.
-form
Génère un formulaire PostScript qui peut être importé par un logiciel comprenant les formulaires. Un formulaire contient une seule page, donc si vous utilisez cette option avec un fichier PDF multi-pages, vous devez utiliser -f et -l pour spécifier une seule page. L'option -level1 ne peut pas être utilisée avec -form. Pas plus d'une des options de mode (-eps, -form) ne peut être donnée.
-opi
Génère des commentaires OPI pour toutes les images et tous les formulaires qui ont des informations OPI. (Cette option n'est disponible que si pdftops a été compilé avec le support OPI.)
-binary
Écrit des données binaires en PostScript de Niveau 1. Par défaut, pdftops écrit des données encodées en hexadécimal en PostScript de Niveau 1. Les données binaires sont non standard en PostScript de Niveau 1 mais réduisent la taille du fichier et peuvent être utiles lorsque le PostScript de Niveau 1 est requis uniquement pour son utilisation restreinte des opérateurs PostScript.
-r nombre
Définit la résolution en DPI lorsque pdftops rastérise les images avec des transparences ou, pour le PostScript de Niveau 1, lorsque pdftops rastérise les images avec des masques de couleur. Par défaut, pdftops rastérise les images à 300 DPI.
-noembt1
Par défaut, les polices Type 1 incorporées dans le fichier PDF sont copiées dans le fichier PostScript. Cette option fait que pdftops substitue des polices de base à la place. Les polices incorporées rendent les fichiers PostScript plus volumineux, mais peuvent être nécessaires pour une sortie lisible.
-noembtt
Par défaut, les polices TrueType incorporées dans le fichier PDF sont copiées dans le fichier PostScript. Cette option fait que pdftops substitue des polices de base à la place. Les polices incorporées rendent les fichiers PostScript plus volumineux, mais peuvent être nécessaires pour une sortie lisible. De plus, certains interpréteurs PostScript n'ont pas de rastériseurs TrueType.
-noembcidps
Par défaut, les polices PostScript CID incorporées dans le fichier PDF sont copiées dans le fichier PostScript. Cette option désactive cette incorporation. Aucune tentative n'est faite pour substituer les polices PostScript CID non incorporées.
-noembcidtt
Par défaut, les polices TrueType CID incorporées dans le fichier PDF sont copiées dans le fichier PostScript. Cette option désactive cette incorporation. Aucune tentative n'est faite pour substituer les polices TrueType CID non incorporées.
-passfonts
Par défaut, les références aux polices 8 bits non incorporées dans le fichier PDF sont substituées par la police "Helvetica", "Times-Roman", ou "Courier" la plus proche. Cette option transmet les références aux polices non incorporées dans le fichier PostScript.
-aaRaster oui | non
Active ou désactive l'anti-crénelage raster. Par défaut, il est réglé sur "non". pdftops peut avoir besoin de rastériser les transparences et les masques d'images de motif dans le PDF. Si le PostScript sera imprimé, laissez -aaRaster désactivé et réglez -r sur la résolution de l'imprimante. Si le PostScript sera visualisé, activer -aaRaster peut rendre le texte rastérisé plus facile à lire.
-rasterize toujours | jamais | quandnécessaire
Par défaut, pdftops rastérise les pages au besoin, par exemple, si elles contiennent des transparences. Pour forcer la rastérisation, réglez -rasterize sur "toujours". Utilisez ceci pour éliminer les polices. Pour empêcher la rastérisation, réglez -rasterize sur "jamais". Cela peut produire des fichiers qui s'affichent incorrectement.
-processcolorformat MONO8 | CMJN8 | RVB8
Définit le format de couleur de traitement tel qu'utilisé lors de la rastérisation et de la réduction de transparence. Le défaut dépend des autres réglages: Pour -level1, le défaut est MONO8, pour -level{1,2,3}sep ou -overprint, le défaut est CMJN8, et dans tous les autres cas, RVB8 est le défaut. Si -processcolorprofile est donné, alors -processcolorformat est déduit du profil ICC spécifié.
-processcolorprofile nom-de-fichier
Définit le profil ICC qui est supposé lors de la rastérisation et de la réduction de transparence.
-defaultgrayprofile profil-gris-par-défaut-fichier
Si poppler est compilé avec le support de gestion des couleurs, cette option définit l'espace colorimétrique Gris par défaut avec le profil ICC stocké dans profil-gris-par-défaut-fichier.
-defaultrgbprofile profil-rvb-par-défaut-fichier
Si poppler est compilé avec le support de gestion des couleurs, cette option définit l'espace colorimétrique RVB par défaut avec le profil ICC stocké dans profil-rvb-par-défaut-fichier.
-defaultcmykprofile profil-cmjn-par-défaut-fichier
Si poppler est compilé avec le support de gestion des couleurs, cette option définit l'espace colorimétrique CMJN par défaut avec le profil ICC stocké dans profil-cmjn-par-défaut-fichier.
-optimizecolorspace
Par défaut, les images bitmap dans le PDF sont transmises à la sortie PostScript dans leur espace colorimétrique d'origine, ce qui produit des résultats prévisibles. Cette option convertit les images RVB et CMJN en images Gris si chaque pixel de l'image a des composantes égales. Cela peut résoudre des problèmes lors de la séparation des couleurs de PDF contenant des images noir et blanc incorporées encodées en RVB.
-preload
préchauffer les images et les formulaires
-paper nom-de-papier
Définit la taille du papier. Les tailles de papier courantes sont Letter, Legal, Tabloid, A, B, C, D, E, A3, A4, A5, B4, B5, C3, C4, C5, C6, RA3, SRA3, B4 (JIS), B5 (JIS), etc. L'option -paper "taille" peut également être utilisée pour spécifier une taille personnalisée de papier, par exemple, -paper "8.5inx11in" pour un format Lettre.
-papersize nom-de-papier
Identique à -paper.
-level2option options
Définit les options pour le niveau 2. Les options disponibles sont "image" (compression d'image), "transparence" (réduction de transparence), "image,transparence", "all" (active toutes les options), "none" (désactive toutes les options).
-overprint
Active le mode surimpression. Ceci est utile pour la création de séparations de couleurs où la surimpression des couleurs est souhaitée.
-newtonscsc
Utilise la transformation de couleur Newton's CSC pour la réduction de transparence.
-nooverprint
Désactive le mode surimpression.
-quiet
Ne pas imprimer les messages de démarrage ou de fermeture.
-silent
Identique à -quiet.
-verbose
Imprimer plus d'informations pendant la conversion.
-printdir
Imprimer le répertoire dans lequel le fichier PostScript sera écrit.
-show
Si ce commutateur est utilisé, pdftops affichera les informations de sortie du fichier sur stdout.
-compress
Génère un flux PostScript compressé (ASCIIHexDecode ou FlateDecode). Par défaut, le flux est compressé avec FlateDecode.
-nozip
Désactive la compression FlateDecode.
-rot angle
Fait pivoter la page d'un angle spécifié en degrés (0, 90, 180, 270).
-flip
Retourne la page horizontalement.
-flop
Retourne la page verticalement.
-nocenter
Ne pas centrer le contenu de la page sur la feuille.
-fi
Génère du PostScript pour un fichier PDF contenant des champs de formulaire interactifs. (Ceci n'est que des commentaires OPI.)
-fi_page
Génère du PostScript pour un fichier PDF contenant des champs de formulaire interactifs. (Ceci inclut la page actuelle.)
-fi_all
Génère du PostScript pour un fichier PDF contenant des champs de formulaire interactifs. (Ceci inclut toutes les pages.)
-help
Affiche un message d'aide.
-h
Identique à -help.
-H
Identique à -help.
-version
Affiche les informations de version de pdftops.
-v
Identique à -version.

EXEMPLES

Convertir toutes les pages du fichier document.pdf en document.ps :

$ pdftops document.pdf

Convertir les pages 5 à 10 du fichier document.pdf en document.ps :

$ pdftops -f 5 -l 10 document.pdf document.ps

Convertir la première page du fichier document.pdf en un fichier EPS :

$ pdftops -eps document.pdf document.eps

Convertir toutes les pages du fichier document.pdf en PostScript de Niveau 1 et les envoyer sur stdout :

$ pdftops -level1 document.pdf -

OPTIONS

-paper taille
Définit la taille du papier sur l'une des valeurs suivantes : "letter", "legal", "A4" ou "A3". Peut également être défini sur "match", ce qui définira la taille du papier de chaque page pour qu'elle corresponde à la taille spécifiée dans le fichier PDF. Si aucune des options -paper, -paperw ou -paperh n'est spécifiée, la valeur par défaut est de faire correspondre la taille du papier.
-paperw taille
Définit la largeur du papier, en points.
-paperh taille
Définit la hauteur du papier, en points.
-origpagesizes
Cette option est identique à "-paper match".
-nocrop
Par défaut, la sortie est rognée selon le CropBox spécifié dans le fichier PDF. Cette option désactive le rognage.
-expand
Agrandit les pages PDF plus petites que le papier pour remplir le papier. Par défaut, ces pages ne sont pas mises à l'échelle.
-noshrink
Ne redimensionne pas les pages PDF plus grandes que le papier. Par défaut, les pages plus grandes que le papier sont réduites pour s'adapter.
-nocenter
Par défaut, les pages PDF plus petites que le papier (après toute mise à l'échelle) sont centrées sur le papier. Cette option les aligne plutôt sur le coin inférieur gauche du papier.
-duplex
Définit l'entrée pagedevice Duplex dans le fichier PostScript. Cela indique aux imprimantes compatibles avec le recto-verso d'activer le recto-verso.
-opw motdepasse
Spécifie le mot de passe du propriétaire pour le fichier PDF. Le fournir contournera toutes les restrictions de sécurité.
-upw motdepasse
Spécifie le mot de passe utilisateur pour le fichier PDF.
-overprint
Active l'émulation de surimpression pendant la rastérisation. Pour -processcolorformat être CMYK8 et le niveau de langage supérieur à 2, cette option est définie sur vrai par défaut. Remarque : Cette option nécessite que -processcolorformat soit CMYK8.
-q
N'imprime aucun message ni erreur.
-v
Affiche les informations de copyright et de version.
-h
Affiche les informations d'utilisation. (-help et --help sont équivalents.)

CODES DE SORTIE

Les outils Xpdf utilisent les codes de sortie suivants :

0
Aucune erreur.
1
Erreur lors de l'ouverture d'un fichier PDF.
2
Erreur lors de l'ouverture d'un fichier de sortie.
3
Erreur liée aux autorisations PDF.
99
Autre erreur.
