NOM

pdfcrack - Outil de récupération de mots de passe pour les fichiers PDF

SYNTAXE

pdfcrack [ -f ] FICHIER [OPTION]...

DESCRIPTION

PDFCrack est un outil pour récupérer les mots de passe et le contenu des fichiers PDF.

S'il est interrompu par Ctrl-C ou par la réception d'un signal SIGINT, pdfcrack enregistrera automatiquement la position actuelle. La position sera enregistrée dans un fichier nommé savedstate.sav dans le répertoire de travail courant.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

OPTIONS

-b, --bench
exécuter une analyse comparative et quitter
-c, --charset=CHAÎNE
Utiliser les caractères de la CHAÎNE comme jeu de caractères
-w, --wordlist=FICHIER
Utiliser le FICHIER comme source de mots de passe à essayer
-n, --minpw=ENTIER
Ignorer les mots de passe de longueur inférieure à ENTIER
-m, --maxpw=ENTIER
Arrêter lorsque la longueur du mot de passe atteint cet ENTIER
-l, --loadstate=FICHIER
Continuer à partir de l'état sauvegardé dans le FICHIER
-o, --owner
Travailler avec le mot de passe du propriétaire
-u, --user
Travailler avec le mot de passe de l'utilisateur (par défaut)
-p, --password=CHAÎNE
Donner le mot de passe de l'utilisateur pour accélérer le déchiffrement du mot de passe du propriétaire (implique -o)
-q, --quiet
Exécuter silencieusement
-s, --permutate
Essayer de permuter les mots de passe (prend actuellement en charge uniquement la mise en majuscule du premier caractère)
-v, --version
Afficher la version et quitter
