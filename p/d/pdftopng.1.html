pdftopng(1) Manuel des commandes générales pdftopng(1)

NOM

pdftopng - Convertisseur de format Portable Document Format (PDF) en format Portable Network Graphics (PNG) (version 4.05)

SYNTAXE

pdftopng [options] fichier-PDF racine-PNG

DESCRIPTION

Pdftopng convertit les fichiers au format Portable Document Format (PDF) en fichiers image couleur, niveaux de gris ou monochrome au format Portable Network Graphics (PNG).

Pdftopng lit le fichier PDF, fichier-PDF, et écrit un fichier PNG pour chaque page, racine-PNG-nnnnnn.png, où nnnnnn est le numéro de page. Si racine-PNG est ´-', l'image est envoyée à la sortie standard (ce qui est probablement utile uniquement lors de la conversion d'une seule page).

FICHIER DE CONFIGURATION

Pdftopng lit un fichier de configuration au démarrage. Il essaie d'abord de trouver le fichier de configuration privé de l'utilisateur, ~/.xpdfrc. S'il n'existe pas, il recherche un fichier de configuration système, typiquement /etc/xpdfrc (mais cet emplacement peut être modifié lors de la compilation de pdftopng). Voir la page de manuel xpdfrc(5) pour plus de détails.

OPTIONS

Plusieurs des options suivantes peuvent être définies avec des commandes dans le fichier de configuration. Celles-ci sont listées entre crochets avec la description de l'option de ligne de commande correspondante.

-f nombre
Spécifie la première page à convertir.
-l nombre
Spécifie la dernière page à convertir.
-r nombre
Spécifie la résolution, en DPI. La valeur par défaut est 150 DPI.
-mono
Génère une image monochrome (au lieu d'une image couleur).
-gray
Génère une image en niveaux de gris (au lieu d'une image couleur).
-alpha
Génère un canal alpha dans le fichier PNG. Ceci n'est utile qu'avec les fichiers PDF construits avec un arrière-plan transparent. L'indicateur -alpha ne peut pas être utilisé avec -mono.
-rot angle
Fait pivoter les pages de 0 (par défaut), 90, 180 ou 270 degrés.
-freetype oui | non
Active ou désactive FreeType (un rasteriseur de polices TrueType / Type 1). Ceci est activé par défaut ("oui"). [fichier de configuration: enableFreeType]
-aa oui | non
Active ou désactive l'anti-aliasing des polices. Ceci est activé par défaut ("oui"). [fichier de configuration: antialias]
-aaVector oui | non
Active ou désactive l'anti-aliasing vectoriel. Ceci est activé par défaut ("oui"). [fichier de configuration: vectorAntialias]
-opw mot de passe
Spécifie le mot de passe propriétaire du fichier PDF. Le fournir contourne toutes les restrictions de sécurité.
-upw mot de passe
Spécifie le mot de passe utilisateur du fichier PDF.
-verbose
Affiche un message d'état (sur la sortie standard) avant de traiter chaque page. [fichier de configuration: printStatusInfo]
-q
N'affiche aucun message ni aucune erreur. [fichier de configuration: errQuiet]
-cfg fichier-config
Lit fichier-config à la place de ~/.xpdfrc ou du fichier de configuration système.
-v
Affiche les informations de copyright et de version.
-h
Affiche les informations d'utilisation. (-help et --help sont équivalents.)

CODES DE SORTIE

Les outils Xpdf utilisent les codes de sortie suivants :

0
Aucune erreur.
1
Erreur lors de l'ouverture d'un fichier PDF.
2
Erreur lors de l'ouverture d'un fichier de sortie.
3
Erreur liée aux permissions du PDF.
98
Mémoire insuffisante.
99
Autre erreur.
