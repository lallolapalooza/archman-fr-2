pdfmom(1) Manuel des commandes générales pdfmom(1)

Nom

pdfmom - produire des documents PDF à l'aide des macros mom pour groff

Synopsis

pdfmom [-Tpdf] [options-groff] [fichier ...]
pdfmom -Tps [options-pdfroff] [options-groff] [fichier ...]
pdfmom -v
pdfmom --version

Description

pdfmom est une enveloppe autour de groff(1) qui facilite la production de documents PDF à partir de fichiers formatés avec les macros mom.

pdfmom imprime sur la sortie standard, donc la sortie doit généralement être redirigée vers un fichier de destination. La taille du PDF final peut être réduite en canalisant la sortie à travers ps2pdf(1).

Si appelée avec l'option -Tpdf (qui est la valeur par défaut), pdfmom traite les fichiers en utilisant le pilote PDF natif de groff, gropdf(1). Si -Tps est donné, le traitement est transmis à pdfroff, qui utilise le pilote PostScript de groff. Dans les deux cas, plusieurs exécutions du fichier source sont effectuées afin de satisfaire les références avant dans le document.

pdfmom accepte toutes les mêmes options que groff. Si -Tps est donné, les options associées à pdfroff sont également acceptées. Lorsque pdfmom appelle pdfroff, les options “-mpdfmark -mom --no-toc” sont implicites et ne doivent pas être fournies sur la ligne de commande. De même, il n'est pas nécessaire de fournir les options -mom ou -m mom lorsque -Tps est absent.

L'intégration PDF avec les macros mom est discutée en détail dans le manuel “Producing PDFs with groff and mom”, qui a lui-même été produit avec pdfmom.

Si appelée avec les options -v ou --version, pdfmom affiche ses informations de version et se termine.

Auteurs

pdfmom a été écrit par Deri James et Peter Schaffter, et est maintenu par James.
