pdftotext(1) Manuel des commandes générales pdftotext(1)

NOM

pdftotext - Convertisseur de format de document portable (PDF) en texte (version 3.03)

SYNTAXE

pdftotext [options] PDF-file [text-file]

DESCRIPTION

Pdftotext convertit les fichiers au format Portable Document Format (PDF) en texte brut.

Pdftotext lit le fichier PDF, PDF-file, et écrit un fichier texte, text-file. Si text-file n'est pas spécifié, pdftotext convertit file.pdf en file.txt. Si text-file est ´-', le texte est envoyé à la sortie standard. Si PDF-file est ´-', il lit le fichier PDF depuis l'entrée standard.

OPTIONS

-f nombre
Spécifie la première page à convertir.
-l nombre
Spécifie la dernière page à convertir.
-r nombre
Spécifie la résolution en DPI. La valeur par défaut est 72 DPI.
-x nombre
Spécifie la coordonnée x du coin supérieur gauche de la zone de recadrage
-y nombre
Spécifie la coordonnée y du coin supérieur gauche de la zone de recadrage
-W nombre
Spécifie la largeur de la zone de recadrage en pixels (par défaut 0)
-H nombre
Spécifie la hauteur de la zone de recadrage en pixels (par défaut 0)
-layout
Conserve (autant que possible) la disposition physique originale du texte. Par défaut, la disposition physique est ´annulée' (colonnes, césures, etc.) et le texte est affiché dans l'ordre de lecture.
-fixed nombre
Suppose que le texte est à largeur fixe (ou tabulaire), avec la largeur de caractère spécifiée (en points). Cela force le mode de disposition physique.
-raw
Conserve le texte dans l'ordre du flux de contenu. C'est un correctif qui "annule" souvent la mise en forme en colonnes, etc. L'utilisation du mode brut n'est plus recommandée.
-nodiag
Ignore le texte diagonal (c'est-à-dire le texte qui n'est pas proche de l'un des axes 0, 90, 180 ou 270 degrés). Ceci est utile pour sauter les filigranes apposés sur le texte principal.
-htmlmeta
Génère un fichier HTML simple, incluant les métadonnées. Cela encapsule simplement le texte dans <pre> et </pre> et préfixe les en-têtes de métadonnées.
-bbox
Génère un fichier XHTML contenant les informations de boîte englobante pour chaque mot du fichier.
-bbox-layout
Génère un fichier XHTML contenant les informations de boîte englobante pour chaque bloc, ligne et mot du fichier.
-tsv
Génère un fichier TSV contenant les informations de boîte englobante pour chaque bloc, ligne et mot du fichier.
-cropbox
Utilise la boîte de recadrage plutôt que la boîte de format avec -bbox et -bbox-layout.
-colspacing nombre
Spécifie l'espacement autorisé après un mot avant de considérer le texte adjacent comme une nouvelle colonne, mesuré comme une fraction de la taille de la police. La valeur par défaut actuelle est 0.7, les anciennes versions avaient une valeur par défaut de 0.3.
-enc nom-encodage
Définit l'encodage à utiliser pour la sortie texte. Par défaut, c'est "UTF-8".
-listenc
Liste les encodages disponibles.
-eol unix | dos | mac
Définit la convention de fin de ligne à utiliser pour la sortie texte.
-nopgbrk
N'insère pas de sauts de page (caractères de saut de formulaire) entre les pages.
-opw mot-de-passe
Spécifie le mot de passe propriétaire du fichier PDF. Le fournir contournera toutes les restrictions de sécurité.
-upw mot-de-passe
Spécifie le mot de passe utilisateur du fichier PDF.
-q
N'imprime aucun message ni erreur.
-v
Affiche les informations de copyright et de version.
-h
Affiche les informations d'utilisation. (-help et --help sont équivalents.)

BOGUES

Certains fichiers PDF contiennent des polices dont les encodages ont été corrompus au point d'être irrécupérables. Il n'y a aucun moyen (à part l'OCR) d'extraire le texte de ces fichiers.

CODES DE RETOUR

Les outils Xpdf utilisent les codes de retour suivants :

0
Aucune erreur.
1
Erreur lors de l'ouverture d'un fichier PDF.
2
Erreur lors de l'ouverture d'un fichier de sortie.
3
Erreur liée aux permissions PDF.
99
Autre erreur.
