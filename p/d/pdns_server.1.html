PDNS_SERVER(1) Serveur Autoritaire PowerDNS PDNS_SERVER(1)

NOM

pdns_server - Le serveur de noms autoritaire PowerDNS

SYNTAXE

pdns_server [OPTION]

DESCRIPTION

Le serveur autoritaire PowerDNS est un serveur de noms polyvalent qui prend en charge un grand nombre de backends. Ces backends peuvent être soit des fichiers de zone simples, soit avoir une nature plus dynamique. Veuillez consulter la documentation en ligne pour plus d'informations.

OPTIONS

Consultez la documentation en ligne pour toutes les options. Les plus importantes sont :

--daemon
Indique si le serveur doit s'exécuter en arrière-plan en tant que vrai démon, ou au premier plan.
--guardian
Exécute pdns_server à l'intérieur d'un gardien. Ce gardien surveille les performances de l'instance interne de pdns_server. C'est aussi à ce gardien que pdns_control communique.
--control-console
Exécute le serveur dans un mode moniteur spécial. Cela permet une journalisation détaillée et expose le socket de contrôle brut.
--loglevel=<LEVEL>
Définit le niveau de journalisation.
--config
Affiche la configuration actuelle. Il existe trois valeurs facultatives :
--config=default
affiche la configuration par défaut.
--config=diff
affiche les options modifiées dans la configuration actuelle.
--config=check
analyse la configuration actuelle, avec vérification des erreurs.
--help
Affiche la liste de toutes les options disponibles.
