NOM

pdf2ps - Traducteur Ghostscript de PDF vers PostScript

SYNTAXE

pdf2ps [ options ] input.pdf [output.ps]

DESCRIPTION

pdf2ps utilise gs(1) pour convertir le fichier au format Portable Document Format (PDF) d'Adobe "input.pdf" en PostScript(tm) dans "output.ps". Normalement, la sortie est autorisée à utiliser des constructions PostScript de niveau 2 (mais pas de niveau 3) ; l'option -dLanguageLevel=1 restreint la sortie au niveau 1, tandis que -dLanguageLevel=3 permet d'utiliser le niveau de langage 3 dans la sortie.

FICHIERS

Exécutez "gs -h" pour trouver l'emplacement de la documentation Ghostscript sur votre système, à partir de laquelle vous pouvez obtenir plus de détails.
