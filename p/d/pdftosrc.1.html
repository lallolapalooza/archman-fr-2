pdftosrc(1) Manuel des commandes générales pdftosrc(1)

NOM

pdftosrc - extraire un fichier source ou un flux d'un fichier PDF

SYNTAXE

pdftosrc Fichier-PDF [Numéro-objet-flux]

DESCRIPTION

Si seul Fichier-PDF est donné en argument, pdftosrc extrait le fichier source intégré du premier objet flux trouvé avec /Type /SourceFile dans le Fichier-PDF et l'écrit dans un fichier portant le nom /SourceName tel que défini dans cet objet PDF (voir l'exemple d'application ci-dessous).

Si Fichier-PDF et Numéro-objet-flux sont donnés en arguments, et que Numéro-objet-flux est positif, pdftosrc extrait et décompresse le flux PDF de l'objet donné par son Numéro-objet-flux depuis le Fichier-PDF et l'écrit dans un fichier nommé Fichier-PDF.Numéro-objet-flux en retirant l'extension .pdf ou .PDF du nom du Fichier-PDF d'origine.

Un cas spécial concerne les flux d'objets XRef qui font partie de la norme PDF à partir de la version PDF-1.5 : Si Numéro-objet-flux est égal à -1, alors pdftosrc décompresse le flux XRef du fichier PDF et l'écrit dans un format de table de références croisées PDF lisible par l'homme dans un fichier nommé Fichier-PDF.xref (ces flux XRef ne peuvent pas être extraits simplement en donnant leur numéro d'objet).

Dans tous les cas, un fichier existant portant le nom du fichier de sortie sera écrasé.

OPTIONS

Aucune.

FICHIERS

Seulement l'exécutable pdftosrc.

ENVIRONNEMENT

Aucun.

DIAGNOSTICS

En cas de succès, le code de sortie de pdftosrc est 0, sinon 1.

Tous les messages vont vers stderr. Lors de l'invocation du programme, pdftosrc affiche le numéro de version actuel du programme xpdf, sur lequel pdftosrc est basé :

version de pdftosrc 3.01
Lorsque pdftosrc a réussi l'écriture du fichier de sortie, l'un des messages suivants sera émis :
Fichier source extrait vers nom-fichier-source
ou
Objet flux extrait vers Fichier-PDF.numéro-objet-flux
ou
Table de références croisées extraite vers Fichier-PDF.xref

Lorsque l'objet donné par le numéro-objet-flux ne contient pas de flux, pdftosrc émet le message d'erreur suivant :

Ce n'est pas un objet flux
Lorsque le Fichier-PDF ne peut pas être ouvert, le message d'erreur est :
Erreur : Impossible d'ouvrir le fichier 'Fichier-PDF'.
Lorsque pdftosrc rencontre un fichier PDF invalide, le message d'erreur (plusieurs lignes) est :
Erreur : Peut-être pas un fichier PDF (poursuite malgré tout)
(plus de lignes)
Fichier PDF invalide
Il existe également d'autres messages d'erreur de pdftosrc pour divers types de fichiers PDF corrompus.

NOTES

Un fichier source intégré sera écrit tel quel, c'est-à-dire qu'il ne sera pas décompressé pendant ce processus.

Seul le flux de l'objet sera écrit, c'est-à-dire pas le dictionnaire de cet objet.

Connaître le numéro-objet-flux à interroger nécessite des informations sur le fichier PDF qui doivent être obtenues ailleurs, par exemple en examinant le fichier PDF avec un éditeur.

Les capacités d'extraction de flux de pdftosrc (par exemple concernant les versions PDF comprises et les types de filtres) suivent les capacités de la version sous-jacente du programme xpdf.

Actuellement, le numéro de génération de l'objet flux n'est pas pris en charge. La valeur par défaut 0 (zéro) est utilisée.

L'expression numéro-objet-flux n'a rien à voir avec les `flux d'objets' introduits par la Référence PDF d'Adobe, 5ème édition, version 1.6.

EXEMPLES

Lors de l'utilisation de pdftex, un fichier source peut être intégré dans un Fichier-PDF en utilisant des primitives pdftex, comme l'illustre l'exemple suivant :

\immediate\pdfobj
stream attr {/Type /SourceFile /SourceName (myfile.zip)}


file{myfile.zip} \pdfcatalog{/SourceObject \the\pdflastobj\space 0 R}

Alors, ce fichier zip peut être extrait du Fichier-PDF en appelant pdftosrc Fichier-PDF.

BOGUES

Tous les fichiers sources intégrés ne seront pas extraits, seulement le premier trouvé.

Envoyez les rapports de bugs par e-mail à pdftex@tug.org.
