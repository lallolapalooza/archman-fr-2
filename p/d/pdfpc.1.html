NOM

pdfpc - Console de présentation PDF avec support multi-moniteurs

SYNOPIS

pdfpc [options] Fichier-PDF

DESCRIPTION

pdfpc est une visionneuse de présentation basée sur GTK qui utilise une sortie multi-moniteurs de type Keynote pour fournir des informations supplémentaires au présentateur pendant la présentation. Elle est capable d'afficher une fenêtre de présentation normale sur un écran tout en affichant un aperçu plus sophistiqué sur l'autre, fournissant des informations telles qu'une image de la diapositive suivante, ainsi que le temps restant dans la présentation. pdfpc traite des documents PDF, qui peuvent être créés à l'aide de presque tous les logiciels de présentation modernes.

Par défaut, la vue présentateur apparaît sur le moniteur principal et la vue présentation sur le second moniteur (si vous en avez deux).

FONCTIONNALITÉS

Mise en cache / Pré-rendu

Pour permettre des changements rapides entre les diapositives de la présentation, quelques pages PDF consécutives (dont le nombre est configurable) sont pré-rendues et conservées en mémoire. Pour éviter une consommation excessive de mémoire, seules les diapositives qui ont pris un temps significatif à rendre sont mises en cache ; ce seuil est configurable. Afin de réduire davantage la consommation de mémoire, les diapositives pré-rendues et mises en cache sont compressées de manière sélective. Le facteur de compression est généralement de 10 à 30 %, cependant, la compression et la décompression prennent du temps CPU, il y a donc un compromis. Les petites images dont la taille est inférieure à un certain seuil (configurable) ne seront pas compressées.

Veuillez vous référer à la page de manuel pdfpcrc(5) pour les options permettant d'affiner l'algorithme de mise en cache.

Chronomètre

Si une durée est donnée (option -d), le chronomètre affichera un compte à rebours avec les paramètres donnés. Si aucune durée n'est spécifiée (ou si une valeur de 0 est donnée à l'option -d), le chronomètre indiquera le temps écoulé. La durée est automatiquement enregistrée, vous n'avez donc pas besoin de la répéter à chaque invocation.

Le chronomètre démarre lorsque vous naviguez pour la première fois hors de la première page. Cette fonctionnalité est très utile car vous pourriez vouloir afficher la page de titre de votre présentation pendant que les gens entrent dans la salle et que la présentation n'a pas encore réellement commencé. Si vous souhaitez recommencer, vous pouvez utiliser la touche 'Ctrl + t' qui permettra à l'orateur de réinitialiser le chronomètre.

Si une durée est donnée, le chronomètre fournit également des indices aidant l'orateur à juger si la présentation se terminera à temps. Pdfpc peut fonctionner dans deux modes. Dans l'ancien mode (et le seul disponible jusqu'à pdfpc-4.0.8 inclus), au moment où le chronomètre atteint la valeur définie des dernières minutes, il changera de couleur pour indiquer que votre discours approche de sa fin, imitant ainsi un président faisant des gestes frénétiques devant vous avec cinq (quatre, trois, ...) doigts levés. L'inconvénient de cette approche est qu'il est souvent trop tard à ce moment-là pour modifier le rythme de la présentation sans ruiner dans une certaine mesure le reste du discours. D'un autre côté, l'indication d'avertissement constitue une distraction inutile si vous avez parfaitement géré le discours et que le temps restant est suffisant.

Contrairement à cela, dans le nouveau mode (par défaut), pdfpc suit continuellement votre progression, calculant le temps estimé comme (durée_du_discours)*(numéro_diapositive_utilisateur_actuel - 0.5)/(nombre_total_diapositives_utilisateur) et le comparant au temps réel écoulé depuis le début du discours. Si ces deux nombres diffèrent de plus de 60 secondes, le chronomètre change de couleur pour devenir orange (indiquant qu'il faut accélérer) ou bleuâtre (il faut ralentir). Une fois que la progression optimale est rétablie, le chronomètre redevient blanc. Dans ce mode, l'option des dernières minutes (-l) n'a aucun effet. Le comportement précédent peut être restauré en définissant l'option 'timer-pace-color' sur 'false' dans le fichier de configuration, voir pdfpcrc(5).

Dans tous les cas, dès que le chronomètre atteint zéro (00:00:00), il devient rouge et continue de compter à rebours en affichant un temps négatif, pour indiquer de combien de minutes vous êtes en retard.

Notes

Des notes textuelles peuvent être affichées pour chaque diapositive. pdfpc comprend la syntaxe Markdown, qui permet de rendre tout, du texte brut à un formatage très riche, si désiré. Quelques types d'annotations PDF sont compris par pdfpc et seront automatiquement importés et affichés. Les annotations PDF peuvent être créées à l'aide de nombreux éditeurs PDF et même de visualiseurs ; lors de l'utilisation de LaTeX, le package pdfpc (voir ci-dessous) fournit une macro pratique. Ces notes « natives » PDF ne peuvent pas être modifiées dans pdfpc.

De plus, en mode présentation, appuyer sur 'Ctrl + n' vous permettra de prendre ou de modifier des notes pour la diapositive actuelle. Ces notes sont stockées dans le fichier .pdfpc. Les annotations PDF natives ont la priorité sur ces notes, c'est-à-dire que si une note existe pour une diapositive donnée dans le fichier .pdfpc, toute annotation PDF sur cette page la remplacera silencieusement. Pendant la modification d'une note, les raccourcis clavier normaux sont désactivés, par exemple, vous ne pouvez pas changer de diapositive. Pour quitter le mode d'édition de notes, appuyez sur la touche Échap.

Bien que le mélange des deux types de notes soit possible, pour une présentation donnée, on préférera souvent n'utiliser que les notes « natives » (produites par le même logiciel de création PDF utilisé pour réaliser les diapositives) ou uniquement les notes « pdfpc ». Notez que si la présentation PDF change, les notes stockées dans le fichier .pdfpc correspondant peuvent devenir désynchronisées.

pdfpc prend également en charge les notes beamer de l'ancien style (voir l'option -n), qui sont typographiées sur une moitié de la diapositive « virtuelle » deux fois plus grande que la réelle. Notez qu'en raison d'un bug dans beamer, la fonction de regroupement automatique ne fonctionne pas avec de telles présentations.

Mode vue d'ensemble

Appuyer sur la touche Tab entre dans le mode vue d'ensemble, où des miniatures des diapositives sont affichées sous forme de grille. Vous pouvez sélectionner une diapositive vers laquelle sauter avec la souris ou avec les touches fléchées. Vous pouvez également définir des superpositions et la diapositive de fin (voir les sections suivantes) dans ce mode. Appuyez sur Échap pour quitter le mode sans apporter de modification.

Superpositions

De nombreux systèmes de préparation de diapositives permettent des superpositions, c'est-à-dire des ensembles de diapositives qui sont logiquement regroupés comme une seule diapositive changeante. Les exemples incluent les énumérations où les éléments de liste sont affichés un par un, ou des « animations » rudimentaires, où des parties d'une image changent d'une diapositive à l'autre. Pdfpc inclut des facilités pour gérer de telles superpositions.

Superpositions

Par défaut, toutes les étapes d'une superposition sont traversées. La commande de déplacement arrière fonctionne différemment selon que les diapositives actuelles et précédentes font partie d'une superposition :

•
Si la diapositive actuelle fait partie d'une superposition, nous sautons simplement à la diapositive précédente. Cela signifie que nous sommes au milieu d'une superposition et que nous pouvons avancer et reculer à travers les étapes individuelles de celle-ci.
•
Si la diapositive actuelle ne fait pas partie d'une superposition (ou si c'est la première), mais que les diapositives précédentes en font partie, nous sautons à la diapositive utilisateur précédente. Cela signifie que lorsque vous revenez en arrière dans la présentation, vous n'avez pas à passer par chaque étape de la superposition, pdfpc affiche simplement la première diapositive de chaque superposition. Comme on revient généralement en arrière dans une présentation uniquement lorsque l'on recherche une diapositive concrète, c'est plus pratique.

Les combinaisons de touches Maj + Page précédente/Page suivante fonctionnent sur la base de la « diapositive utilisateur ». Vous pouvez les utiliser pour sauter le reste d'une superposition ou pour passer à la diapositive utilisateur précédente, en ignorant l'état de la diapositive actuelle.

Lors du passage d'une superposition, deux aperçus supplémentaires peuvent être activés dans la vue présentateur, juste en dessous de la vue principale, montrant la diapositive suivante et précédente dans une superposition.

Pdfpc tente de trouver ces superpositions automatiquement en examinant les étiquettes de page dans le fichier PDF. Pour LaTeX, cela fonctionne correctement au moins avec la classe beamer et également en modifiant manuellement les numéros de page (compilation avec pdflatex). Si votre méthode de production de diapositives préférée ne fonctionne pas correctement avec cette détection, vous pouvez fournir cette information en utilisant la touche « Ctrl + o » pour chaque diapositive qui fait partie d'une superposition (sauf la première !). La numérotation des pages est également adaptée. Ces informations sont automatiquement stockées.

Diapositives cachées

Lors de la préparation d'une présentation à partir d'un ensemble de diapositives existantes, il est parfois utile de marquer certaines diapositives pour qu'elles soient ignorées pendant la présentation. La combinaison « Ctrl + h » active/désactive l'attribut « caché » de la diapositive actuelle, la rendant essentiellement invisible. Il est toujours possible de naviguer vers une diapositive cachée soit en mode Vue d'ensemble, en utilisant l'action Aller ('g'), soit en appuyant sur 'Maj + n' ou 'Maj + p' pour passer à la diapositive suivante/précédente, respectivement, en ignorant l'attribut « caché ».

Diapositive finale

Certaines personnes aiment avoir quelques diapositives supplémentaires, de secours, après la dernière diapositive de la présentation réelle. Les références bibliographiques ou les diapositives renvoyant à des questions spécialisées en sont des exemples typiques. Pdfpc vous permet de définir quelle est la dernière diapositive de la présentation réelle via la touche « Ctrl + e ». Cela modifie simplement l'affichage de la progression sur l'écran du présentateur, afin d'avoir une meilleure vue d'ensemble du nombre de diapositives restantes.

Transitions de page

Pdfpc prend en charge la plupart des transitions de page PDF animées standard : volets, boîte, couverture, fondu, fondu enchaîné, scintillement (sauf le diagonal), poussée, division, découverte et essuyage, y compris divers alignements, angles et directions (le cas échéant). Les transitions ne sont activées que pour le mouvement séquentiel (avant ou arrière) ; dans ce dernier cas, la transition est « inversée ».

L'avancement automatique des diapositives est également pris en charge.

Vidéos

Pdfpc peut lire les vidéos incluses dans le fichier PDF. Les vidéos peuvent être démarrées et arrêtées en cliquant dans leur zone. Pour le présentateur, une barre de progression est dessinée en bas de la vidéo. Elle s'étend lorsque la souris la survole, permettant de rechercher en cliquant ou en faisant glisser la souris dans la barre de progression. Le changement de diapositives arrête automatiquement la lecture, et les vidéos seront réinitialisées après avoir quitté et être revenu sur une diapositive.

Les vidéos peuvent être incluses dans des fichiers PDF en tant qu'« annotations écran ». En LaTeX, de telles vidéos peuvent être ajoutées à une présentation avec le package « multimedia ». Notez que l'option de lecture automatique n'est pas encore prise en charge.

pdfpc lira également les vidéos liées à partir d'un hyperlien de type « lancer ».

Consultez notre site Web ⟨URL : http://pdfpc.github.io/demo/pdfpc-video-example.zip ⟩ pour une explication détaillée avec des exemples.

Mode pointeur

Si nécessaire, il est possible d'activer un pointeur qui dessine un point rouge (par défaut) à l'endroit pointé par le curseur de la souris sur les écrans du présentateur et de la présentation. Il est également possible d'augmenter et de diminuer la taille du pointeur. De plus, lorsque le pointeur est activé, il est possible de mettre en surbrillance une zone de la diapositive actuelle en déplaçant la souris. La zone extérieure à la région sélectionnée sera assombrie. Vous pouvez zoomer sur la zone sélectionnée en appuyant sur 'z' ; appuyez sur 'Échap' pour quitter le mode zoom. Vous pouvez mettre en surbrillance une autre région en étant zoomé, mais il n'y aura aucune action supplémentaire en appuyant sur 'z'. Le dessin est également désactivé dans ce mode.

Mode projecteur

Le mode projecteur est similaire au mode pointeur : une zone circulaire qui se déplace avec la souris et dont la taille peut être ajustée, mais au lieu de mettre en surbrillance le point par une couleur différente, il assombrit l'arrière-plan.

Mode dessin

Il est possible d'activer un mode qui permet de dessiner sur les diapositives avec le curseur de la souris ou une tablette connectée. Lorsque le mode dessin est activé, des dessins peuvent être effectués sur l'écran du présentateur. Un dessin séparé sera conservé en mémoire pour chaque diapositive (en fonction des numéros de diapositives utilisateur, consolidant ainsi les diapositives de superposition). Les dessins ne sont actuellement pas sauvegardés entre les sessions.

En mode dessin, il existe deux outils de dessin, un stylo et une gomme. Un indicateur dans le coin inférieur gauche de l'écran du présentateur indiquera lequel est actif. En mode stylo, la couleur et la taille du stylo seront indiquées par le curseur. La taille du stylo peut être augmentée ou diminuée à l'aide de raccourcis clavier spécifiés dans les raccourcis clavier. Lorsque l'outil gomme est actif, la taille du curseur indique la quantité à effacer.

La couleur du stylo peut être changée via les raccourcis clavier ou en utilisant la boîte à outils.

Si vous utilisez une tablette, le stylo ou l'outil gomme sera sélectionné en fonction du fait que la tablette signale un périphérique d'entrée stylo ou gomme utilisé, remplaçant ainsi la sélection normale de l'outil de dessin. De plus, pour les périphériques d'entrée sensibles à la pression, la pression affectera la largeur de la ligne et la taille de la gomme. Ces deux fonctionnalités peuvent être désactivées dans le fichier de configuration, si désiré.

Plug and Play moniteur

Pdfpc peut gérer le Plug and Play des moniteurs. Par exemple, si pdfpc a été démarré avant que l'écran de présentation ne soit connecté à l'ordinateur, pdfpc peut créer et afficher l'écran de présentation après la connexion du deuxième écran. Cela permet à l'utilisateur de répéter les diapositives et de passer à une présentation normale sans avoir toute l'installation prête à l'ordinateur à l'avance.

Fichiers pdfpc

Les notes, les superpositions définies par l'utilisateur et certaines informations supplémentaires sont stockées dans un fichier avec l'extension « pdfpc ». Lorsque pdfpc est appelé avec un fichier PDF, il vérifie et charge automatiquement le fichier .pdfpc associé, s'il existe. Cela signifie que vous n'avez normalement pas à gérer ces types de fichiers explicitement.

En plus de la configuration interne, les options de ligne de commande suivantes sont enregistrées dans le fichier pdfpc pour une utilisation ultérieure :

•
duration
•
end_time
•
last_minutes
•
notes (position)
•
page_transition
•

Apparence

Avec GTK3, il est possible de modifier l'apparence de pdfpc. Il existe deux emplacements où pdfpc recherche des fichiers. L'emplacement par défaut est /usr/share/pixmaps/pdfpc/pdfpc.css. Il peut être copié dans $XDG_CONFIG_HOME/pdfpc/pdfpc.css et modifié selon les goûts de l'utilisateur.

La géométrie des différentes vues (la diapositive actuelle/suivante, etc.) dans la fenêtre du présentateur peut être ajustée à l'exécution dans le mode « Personnalisation », qui est activé en appuyant sur Maj+c. Dans ce mode, des poignées déplaçables à la souris apparaîtront. Quittez la personnalisation en appuyant sur Échap.

Intégration bureau

Pdfpc fournit une interface DBus qui apparaît sur le bus de session sous le nom io.github.pdfpc. D'autres applications peuvent, en particulier, exécuter n'importe quelle action répertoriée par --list-actions. Il est également possible de contrôler pdfpc depuis la ligne de commande (et d'écrire des scripts shell) en utilisant l'utilitaire dbus-send(1). Par exemple, pour passer à la diapositive suivante, exécutez :

dbus-send --type=method_call --session --dest=io.github.pdfpc
/io/github/pdfpc io.github.pdfpc.TriggerAction string:next

Pour les actions qui nécessitent un argument, utilisez TriggerActionArg, par exemple :

dbus-send --type=method_call --session --dest=io.github.pdfpc
/io/github/pdfpc io.github.pdfpc.TriggerActionArg string:switchMode
string:pointer

En plus de TriggerAction*, l'interface DBus de pdfpc expose la méthode GetNotes, trois propriétés (NumberOfOverlays, NumberOfSlides, Url) et deux signaux (OverlayChange et SlideChange).

Contrôle à distance

Pdfpc dispose d'un serveur REST intégré. Lorsqu'il est activé (désactivé par défaut), il permet de contrôler les présentations sur le réseau, par exemple en utilisant un appareil mobile comme contrôleur intelligent. (Cette section sera complétée avec plus de détails lorsque l'interface REST sera suffisamment stable.)

Package LaTeX

Un petit package LaTeX est disponible pour pdfpc sur CTAN. Il offre un moyen pratique de spécifier des notes et de définir certaines méta-propriétés de la présentation. Pour une documentation complète, veuillez consulter la documentation du package pdfpc. Vous pouvez l'ouvrir avec :

$ texdoc pdfpc

VOIR AUSSI

pdfpcrc(5)

Il existe plusieurs autres programmes avec des fonctionnalités similaires.

impressive(1) possède de jolis effets de transition.

hpdfp(1) est le programme Haskell PDF Presenter ⟨URL : http://michaeldadams.org/projects/haskell-pdf-presenter/ ⟩, qui contient un niveau de fonctionnalité incroyable dans peu de lignes de Haskell.

pympress(1) est un petit lecteur PDF écrit en Python ⟨URL : https://github.com/Cimbali/pympress ⟩ qui gère les doubles écrans et les notes beamer.

dspdfviewer(1) est une Visionneuse PDF Double-Écran spécialisée pour latex-beamer ⟨URL : https://github.com/dannyedel/dspdfviewer ⟩ pour les PDF larges produits par beamer avec des notes sur la droite.

De nombreux visionneurs PDF ont des modes de présentation plein écran, mais sans aperçu double moniteur, sans notes ni minuterie. Ceux-ci incluent zathura(1), evince(1), et okular(1).
