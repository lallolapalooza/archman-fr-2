PDNS_CONTROL(1) Serveur faisant autorité PowerDNS PDNS_CONTROL(1)

NOM

pdns_control - Contrôler le serveur de noms PowerDNS

SYNTAXE

pdns_control [OPTION]... COMMANDE

DESCRIPTION

pdns_control est utilisé pour envoyer des commandes à un serveur de noms PowerDNS en cours d'exécution.

OPTIONS

--help
Afficher un résumé des options.
--chroot=<DIR>
Répertoire où PowerDNS est chrooté.
--config-dir=<DIR>
Emplacement du répertoire de configuration (pdns.conf).
--config-name=<NOM>
Nom de cette configuration virtuelle - renommera l'image du binaire.
--remote-address=<ADRESSE>
Adresse distante à interroger.
--remote-port=<PORT>
Port distant à interroger.
--secret=<SECRET>
Secret nécessaire pour se connecter à un PowerDNS distant.
--socket-dir=<DIR>
Emplacement du socket de contrôle.

COMMANDES

bind-add-zone ZONE FICHIER

Lors de l'utilisation du backend BIND, ajoute une zone. Cette zone est ajoutée en mémoire et servie immédiatement. Notez que cela n'ajoute pas la zone au fichier bind-config. FICHIER doit être un chemin absolu.

bind-domain-extended-status [ZONE...]

Affiche un statut étendu de toutes les zones, contenant beaucoup plus d'informations que le simple statut de zone, comme le nombre d'enregistrements actuellement chargés, si pdns est primaire ou secondaire pour la zone, la liste des primaires, divers minuteurs, etc. Optionnellement, ajoutez ZONEs pour obtenir le statut de zones spécifiques.

bind-domain-status [ZONE...]

Lors de l'utilisation du backend BIND, liste le statut de toutes les zones. Optionnellement, ajoutez ZONEs pour obtenir le statut de zones spécifiques.

bind-list-rejects

Lors de l'utilisation du backend BIND, obtient une liste de toutes les zones rejetées.

bind-reload-now ZONE [ZONE...]

Lors de l'utilisation du backend BIND, recharge immédiatement ZONE depuis le disque.

ccounts

Affiche le contenu du cache.

current-config [diff]

Affiche la configuration actuellement en cours d'exécution. La sortie a le même format que pdns_server --config. Avec l'option diff, seules les options modifiées sont incluses dans la sortie.

cycle

Redémarre le serveur de noms pour qu'il recharge sa configuration. Ne fonctionne que lorsque le serveur est en cours d'exécution en mode gardien.

list

Affiche toutes les statistiques et leurs valeurs sous forme de liste séparée par des virgules, équivalent à show *.

list-zones [primary,secondary,native]

Affiche une liste de zones, filtre éventuellement sur le type de zones à afficher.

notify ZONE

Ajoute ZONE à la liste de notification, provoquant l'envoi de notifications par PowerDNS aux serveurs de noms d'une zone. Peut être utilisé si un secondaire a manqué des notifications précédentes ou est généralement dur d'oreille. Utilisez * pour notifier toutes les zones. (Notez que vous devrez peut-être échapper le signe * dans votre shell.)

notify-host ZONE ADRESSE

Identique à ce qui précède, mais avec l'adresse IP spécifiée par l'opérateur comme destination, à utiliser si vous en savez plus que PowerDNS.

ping, rping

Vérifie si le serveur est toujours actif. Retourne 'PONG' s'il l'est. ping fonctionne lorsqu'il est exécuté dans un gardien, tandis que rping fonctionne lorsqu'il est exécuté sans gardien.

purge [ENREGISTREMENT]

Vide les entrées du cache. Si ENREGISTREMENT se termine par un dollar ($), toutes les entrées qui se terminent par ce nom sont supprimées. Si aucun enregistrement n'est spécifié, le cache entier est vidé.

qtypes

Compte les requêtes par qtype sur la sortie standard.

quit ou stop

Indique à un pdns_server en cours d'exécution de quitter.

rediscover

Demande aux backends que de nouvelles zones peuvent être apparues dans la base de données, ou, dans le cas du backend BIND, dans named.conf.

reload

Demande au serveur de recharger toutes ses zones, cela n'ajoutera pas de nouvelles zones.

remotes

Obtient le nombre maximal d'adresses distantes (clients).

respsizes

Obtient un histogramme des tailles de réponses.

retrieve ZONE [IP]

Récupère la zone secondaire ZONE de son primaire. Fait presque immédiatement. Si IP est spécifié, alors la récupération est forcée depuis l'IP spécifiée. Le port peut être spécifié de manière spécifique à l'AFI.

set VARIABLE VALEUR

Définit le paramètre de configuration VARIABLE à VALEUR. Actuellement, seule la journalisation des requêtes peut être définie.

show STATISTIQUE

Affiche une seule statistique, telle qu'elle apparaît dans la sortie de la commande list.

show PREFIXE-STATISTIQUE*

Affiche toutes les statistiques dont les noms commencent par le PREFIXE-STATISTIQUE fourni, sous forme de liste séparée par des virgules. Un seul joker (final) est autorisé.

status

Affiche les statistiques d'utilisation. Cela ne fonctionne que si le serveur est en mode gardien.

token-login MODULE SLOT PIN

Connecte à un slot PKCS#11. Vous n'avez besoin de vous connecter qu'une seule fois par slot, même si vous avez plusieurs clés sur un seul slot. Uniquement disponible si PowerDNS a été compilé avec le support PKCS#11.

uptime

Affiche le temps de fonctionnement du serveur en cours.

version

Imprime la version du démon pdns en cours d'exécution.
