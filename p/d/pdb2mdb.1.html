NOM

pdb2mdb - Convertisseur de base de données de programmes en symboles de débogage Mono.

SYNTAXE

pdb2mdb fichier_pdb

DESCRIPTION

Cet outil est utilisé pour convertir les symboles de débogage générés par les compilateurs de Microsoft en symboles de débogage pouvant être consommés par le runtime de Mono.

Les fichiers de base de données de programmes sont des fichiers se terminant par l'extension .pdb et associés à une bibliothèque ou à un exécutable (un fichier .dll ou .exe). Ce format n'a pas été documenté jusqu'à récemment, de sorte que Mono utilisait son propre format de fichier pour stocker les informations de débogage, le format de débogage Mono.

Tout comme les fichiers PDB, les informations de débogage Mono sont stockées dans des fichiers qui résident côte à côte avec un exécutable de programme ou une bibliothèque.

Vous pouvez utiliser l'outil pdb2mdb pour transformer ces fichiers PDB en fichiers MDB que Mono peut ensuite consommer pour déboguer des programmes ou fournir des informations sur les numéros de ligne pour les traces de pile ou les exceptions.
