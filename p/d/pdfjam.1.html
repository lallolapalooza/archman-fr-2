PDFJAM(1) Commandes utilisateur PDFJAM(1)

NOM

pdfjam - Un script shell pour manipuler les fichiers PDF

SYNTAXE

pdfjam [options] [--] [fichier[pages]]...

DESCRIPTION

pdfjam assemble une liste de documents (pdf, ps, eps, jpg ou png) en un seul pdf. Il permet de faire pivoter, redimensionner, réordonner et combiner librement les pages en utilisant la puissance des packages LaTeX 'pdfpages' et 'graphicx'.

La sortie est écrite dans un nom généré (sauf si spécifié via --outfile). Les fichiers d'entrée sont intégrés comme graphiques dans la sortie. Les fichiers jpg sont particulièrement conservés tels quels sans transcodage. L'entrée depuis stdin est supportée en spécifiant /dev/stdin comme fichier et est la valeur par défaut si aucun fichier n'est donné.

En spécifiant pages, il est possible de spécifier quelles pages inclure et dans quel ordre. Le défaut '-' sélectionne toutes les pages. Un exemple :

pdfjam fichier1 '{},2,4-6,9-' ...

crée une page vide, suivie des pages 2,4,5,6 du fichier1, suivie des pages 9 et suivantes (jusqu'à la fin du fichier1).

Une sélection de pages peut être appliquée à plus d'un fichier, par exemple :

pdfjam fichier1 fichier2 fichier3 dernier-1 ...

applique la sélection de pages 'dernier-1' (inversant l'ordre des pages) à tous les trois fichiers ; mais par exemple :

pdfjam fichier1 fichier2 2- fichier3 1-7 ...

appliquera la sélection de pages '2-' aux fichiers fichier1 et fichier2, et '1-7' au fichier fichier3. Une sélection de pages s'applique à tous les fichiers *immédiatement* précédents dans la liste des arguments.

Voir le manuel pdfpages pour plus de détails sur la syntaxe des spécifications de pages.

OPTIONS POUR PDFPAGES ET GRAHPICX

Les options clé-valeur pour 'pdfpages' et 'graphicx' peuvent être spécifiées sous la forme --clé valeur.

OPTIONS MÉTA

-h, --help
Affiche ce texte uniquement ; aucun traitement des fichiers PDF.
--configpath
Affiche la variable 'configpath' et quitte immédiatement ; aucun traitement des fichiers PDF.
-V, --version
Affiche le numéro de version de pdfjam et quitte immédiatement ; aucun traitement des fichiers PDF.
-q, --quiet
Supprime les commentaires verbeux sur la progression.

OPTIONS DE TRAITEMENT

--batch
Exécute pdfjam séquentiellement sur chaque fichier d'entrée tour à tour, et produit un fichier de sortie séparé pour chacun, plutôt que le comportement de coalescence par défaut. Pour l'emplacement des fichiers de sortie, voir --outfile. L'option --batch ne peut pas être utilisée dans le cas d'une entrée depuis stdin.
-o, --outfile nom
Spécifie où iront les fichiers de sortie. Si 'nom' est un répertoire existant, pdfjam tentera d'y écrire ses fichiers PDF de sortie, avec des noms dérivés du nom des fichiers d'entrée et de l'option --suffix (voir ci-dessous). Sinon, le pdf de sortie sera écrit à 'nom'.
--suffix chaîne
Spécifie un suffixe pour les noms de fichiers de sortie, à utiliser lorsque --outfile n'est pas spécifié ou est un répertoire. La CHAÎNE ne doit pas être vide.
--checkfiles, --no-checkfiles
Si l'utilitaire Unix 'file' est disponible, la sortie de 'file -Lb FICHIER1' doit être 'PDF document...' où '...' donne des informations de version. Si c'est le cas sur votre système, vous devriez utiliser --checkfiles ; sinon, utilisez --no-checkfiles, dans ce cas tous les fichiers d'entrée doivent avoir les extensions correctes (.pdf, .ps, .eps .jpg, .jpeg, .png, ou leurs variantes majuscules).
--latex cheminverslatex
Spécifie le moteur LaTeX à utiliser (l'un des pdflatex, xelatex, lualatex). La chaîne cheminverslatex doit être le chemin complet vers un exécutable LaTeX approprié (par exemple /usr/bin/xelatex sur de nombreux systèmes Unix).
--tidy, --no-tidy
Spécifie si le répertoire temporaire créé par pdfjam doit être supprimé. Utilisez '--no-tidy' ou '--builddir' (voir ci-dessous) pour aider au débogage de la plupart des erreurs.
--builddir chemin
Spécifie un répertoire de construction à utiliser à la place d'un répertoire temporaire. Les fichiers existants à l'intérieur seront écrasés. Remplace --tidy.
--runs N
Exécute latex N fois, pour chaque document de sortie créé.
--vanilla
Supprime la lecture de tout fichier de configuration pdfjam.
--enc
Spécifie un encodage de ligne de commande

OPTIONS DE PAPIER

--paper nomdepapier, --nompapier
Spécifie une taille de papier LaTeX, par exemple '--paper a4' ou simplement '--a4paper' pour du papier ISO A4. Une large gamme de tailles de papier est disponible grâce au package LaTeX 'geometry'. Pour plus de détails, voir la documentation de LaTeX et/ou du package 'geometry'. Si aucune valeur par défaut n'est définie, obtient le papier par défaut du système via libpaper, en se rabattant sur A4.
--papersize largeur,hauteur
Spécifie une taille de papier personnalisée en points = 1/72 pouce (connu sous le nom de bp en LaTeX et pt dans d'autres logiciels), par exemple --papersize 612,792. Les unités peuvent également être spécifiées explicitement, par exemple --papersize 10in,18cm.
--landscape, --no-landscape
Spécifie l'orientation paysage (ou non) de la page dans le fichier PDF de sortie.
--twoside, --no-twoside
Spécifie (ou non) l'option de classe de document 'twoside'.
--other-edge, --no-other-edge
Fait pivoter chaque page impaire de 180 degrés (ou non). Modifie ainsi le bord le long duquel les pages sont retournées en impression recto-verso.
--pagecolor specrvb
Spécifie une couleur d'arrière-plan pour les pages de sortie. La SPECRVB doit être un triple séparé par des virgules d'entiers entre 0 et 255. Un exemple : --pagecolor 150,200,150. Par défaut, pas de couleur d'arrière-plan.

OPTIONS PDFINFO

--keepinfo, --no-keepinfo
Préserve (ou non) Titre, Auteur, Sujet et Mots-clés (du dernier fichier PDF, s'il y en a plusieurs) dans le fichier PDF de sortie. Cela nécessite l'utilitaire pdfinfo, du package poppler-utils, et le package LaTeX 'hyperref' ; si l'un de ceux-ci n'est pas disponible, '--keepinfo' est ignoré.
--pdftitle chaîne, --pdfauthor chaîne,
--pdfsubject chaîne, --pdfkeywords chaîne Fournit le texte pour le Titre, l'Auteur, le Sujet et les Mots-clés dans le fichier PDF de sortie. Nécessite le package LaTeX 'hyperref'. Ces options, individuellement, remplacent --keepinfo.

OPTIONS AVANCÉES

--preamble chaîne
Ajoute la CHAÎNE fournie au préambule des fichiers source LaTeX, juste avant la ligne '\begin{document}' pour charger des packages LaTeX ou définir des options globales. Un exemple :
pdfjam --nup 2x2 monfichier.pdf -o monfichier-4up.pdf --preamble '\usepackage{fancyhdr} \pagestyle{fancy}'

Si '--preamble' est utilisé plus d'une fois dans l'appel, les

les chaînes préambules sont concaténées. Pour une note sur la façon d'éviter les conflits, voir le fichier README, également disponible à l'adresse https://github.com/pdfjam/pdfjam.

--
Signale la fin du traitement des options.

OPTIONS PDFPAGES ET GRAPHICX

--CLE VALEUR
Spécifie les options pour '\includepdfmerge', dans le package LaTeX 'pdfpages'. Consultez la documentation de pdfpages (généralement 'texdoc pdfpages') pour plus d'informations. Ici, CLE est le nom de l'une des nombreuses options pour '\includepdfmerge', et VALEUR est une valeur correspondante. Exemples :
--nup 2x1 (pour une imposition 2 par page côte à côte)
--scale 0.7 (pour redimensionner toutes les pages d'entrée à 70 % de leur taille)
--offset '1cm 0.5cm' (pour décaler toutes les pages -- notez les guillemets !)
--frame true (pour encadrer chaque page d'entrée)
--booklet true (pour réorganiser les pages en signatures, généralement utile avec --nup)
--signature N (spécifie la taille de la signature, comme le nombre de pages originales dans une signature du document final. Attention : booklet est une forme courte pour signature, donc si vous utilisez --booklet true, signature sera ignoré)
--trim '1cm 2cm 1cm 2cm' --clip true (pour rogner ces montants respectivement de gauche, bas, droite et haut, des pages d'entrée)
--angle NNN (L'angle de rotation en degrés. Les angles qui ne sont pas soit 0, 90, 180 ou 270 créeront toujours des pages rectangulaires droites, seul le contenu sera tourné.)

FICHIERS DE CONFIGURATION

Les valeurs par défaut pour les options --suffix, --keepinfo, --paper, --outfile, --landscape, --twoside, --tidy, --latex, --runs, --checkfiles et --preamble peuvent être définies dans des fichiers de configuration globaux ou spécifiques à l'utilisateur. Les fichiers recherchés sont

/etc/pdfjam.conf /usr/share/etc/pdfjam.conf /usr/local/share/pdfjam.conf /usr/local/etc/pdfjam.conf $XDG_CONFIG_HOME/pdfjam.conf $HOME/.pdfjam.conf

Cette liste peut être modifiée en éditant 'configpath' dans le script pdfjam. Tous ces fichiers sont ignorés si l'argument --vanilla est utilisé.
