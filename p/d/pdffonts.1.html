NOM

pdffonts - Analyseur de polices Portable Document Format (PDF) (version 3.03)

SYNTAXE

pdffonts [options] [Fichier-PDF]

DESCRIPTION

Pdffonts liste les polices utilisées dans un fichier Portable Document Format (PDF) avec diverses informations pour chaque police.

Si Fichier-PDF est ´-', il lit le fichier PDF depuis l'entrée standard.

Les informations suivantes sont listées pour chaque police :

nom
le nom de la police, tel qu'indiqué dans le fichier PDF (pouvant inclure un préfixe de sous-ensemble)
type
le type de police – voir ci-dessous pour les détails
encodage
l'encodage de la police
emb
"oui" si la police est intégrée dans le fichier PDF
sub
"oui" si la police est un sous-ensemble
uni
"oui" s'il existe une carte explicite "ToUnicode" dans le fichier PDF (l'absence d'une carte ToUnicode n'implique pas nécessairement que le texte ne peut pas être converti en Unicode)
ID objet
l'ID de l'objet du dictionnaire de polices (nombre et génération)

Les fichiers PDF peuvent contenir les types de polices suivants :

Type 1
Type 1C – alias Compact Font Format (CFF)
Type 3
TrueType
CID Type 0 – police 16 bits sans type spécifié
CID Type 0C – police PostScript CFF 16 bits
CID TrueType – police TrueType 16 bits

OPTIONS

-f nombre
Spécifie la première page à analyser.
-l nombre
Spécifie la dernière page à analyser.
-subst
Liste les polices de substitution que poppler utilisera pour les polices non intégrées.
-opw mot de passe
Spécifie le mot de passe propriétaire pour le fichier PDF. Fournir ceci contournera toutes les restrictions de sécurité.
-upw mot de passe
Spécifie le mot de passe utilisateur pour le fichier PDF.
-v
Affiche les informations de copyright et de version.
-h
Affiche les informations d'utilisation. (-help et --help sont équivalents.)

CODES DE RETOUR

Les outils Xpdf utilisent les codes de retour suivants :

0
Aucune erreur.
1
Erreur lors de l'ouverture d'un fichier PDF.
2
Erreur lors de l'ouverture d'un fichier de sortie.
3
Erreur liée aux permissions PDF.
99
Autre erreur.
