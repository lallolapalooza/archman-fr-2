pdfimages(1) Manuel des commandes générales pdfimages(1)

NOM

pdfimages - extracteur d'images du format Portable Document Format (PDF) (version 3.03)

SYNTAXE

pdfimages [options] fichier-PDF racine-image

DESCRIPTION

Pdfimages enregistre les images d'un fichier Portable Document Format (PDF) sous forme de fichiers Portable Pixmap (PPM), Portable Bitmap (PBM), Portable Network Graphics (PNG), Tagged Image File Format (TIFF), JPEG, JPEG2000 ou JBIG2.

Pdfimages lit le fichier PDF fichier-PDF, analyse une ou plusieurs pages et écrit un fichier pour chaque image, racine-image-nnn.xxx, où nnn est le numéro de l'image et xxx est le type de l'image (.ppm, .pbm, .png, .tif, .jpg, jp2, jb2e, ou jb2g). Si fichier-PDF est ´-', il lit le fichier PDF depuis l'entrée standard.

Le format de sortie par défaut est PBM (pour les images monochromes) ou PPM pour les images non monochromes. Les options -png ou -tiff changent le format de sortie par défaut en PNG ou TIFF respectivement. Si -png et -tiff sont tous deux spécifiés, les images CMJN seront écrites en TIFF et toutes les autres images seront écrites en PNG. De plus, les options -j, -jp2, et -jbig2 feront que les images JPEG, JPEG2000 et JBIG2, respectivement, dans le fichier PDF seront écrites dans leur format natif.

OPTIONS

-f nombre
Spécifie la première page à analyser.
-l nombre
Spécifie la dernière page à analyser.
-png
Change le format de sortie par défaut en PNG.
-tiff
Change le format de sortie par défaut en TIFF.
-j
Écrit les images au format JPEG sous forme de fichiers JPEG au lieu du format par défaut. Le fichier JPEG est identique aux données JPEG stockées dans le PDF.
-jp2
Écrit les images au format JPEG2000 sous forme de fichiers JP2 au lieu du format par défaut. Le fichier JP2 est identique aux données JPEG2000 stockées dans le PDF.
-jbig2
Écrit les images au format JBIG2 sous forme de fichiers JBIG2 au lieu du format par défaut. Les données JBIG2 dans un PDF sont de type incorporé. Le type incorporé de JBIG2 a un fichier séparé optionnel contenant les données globales. Les données incorporées sont écrites avec l'extension .jb2e et les données globales (si disponibles) seront écrites sous le même numéro d'image avec l'extension .jb2g. Le contenu de ces deux fichiers est identique aux données JBIG2 dans le PDF.
-ccitt
Écrit les images au format CCITT sous forme de fichiers CCITT au lieu du format par défaut. Le fichier CCITT est identique aux données CCITT stockées dans le PDF. Les fichiers PDF contiennent des paramètres supplémentaires spécifiant comment décoder les données CCITT. Ces paramètres sont traduits en options d'entrée de fax2tiff et écrits dans un fichier .params avec le même numéro d'image. Les paramètres sont :
-1
Encodage Group 3 1D
-2
Encodage Group 3 2D
-4
Encodage Group 4
-A
Début de ligne aligné sur une frontière d'octet
-P
Début de ligne non aligné sur une frontière d'octet
-X n
La largeur de l'image en pixels
-W
L'encodage utilise 1 pour le noir et 0 pour le blanc
-B
L'encodage utilise 0 pour le noir et 1 pour le blanc
-M
Les données d'entrée se remplissent du bit le plus significatif au bit le moins significatif.
-all
Écrit les images JPEG, JPEG2000, JBIG2 et CCITT dans leur format natif. Les fichiers CMJN sont écrits en fichiers TIFF. Toutes les autres images sont écrites en fichiers PNG. Ceci est équivalent à spécifier les options -png -tiff -j -jp2 -jbig2 -ccitt.
-list
Au lieu d'écrire les images, liste les images ainsi que diverses informations pour chaque image. Ne spécifiez pas de racine-image avec cette option.
Les informations suivantes sont listées pour chaque image :
page
le numéro de page contenant l'image
num
le numéro de l'image
type
le type de l'image :
image - une image opaque
mask - une image masque monochrome
smask - une image de masque douce
stencil - une image masque monochrome utilisée pour peindre une couleur ou un motif

Note : la transparence dans les images est représentée en PDF à l'aide d'une image séparée pour l'image et le masque/smask. Le masque/smask utilisé comme partie d'une image transparente suit toujours immédiatement l'image dans la liste des images.

width
largeur de l'image (en pixels)
height
hauteur de l'image (en pixels)

Note : la largeur/hauteur de l'image est la taille de l'image incorporée, pas la taille à laquelle l'image sera rendue.

color
espace colorimétrique de l'image :
gray - Gris
rgb - RVB
cmyk - CMJN
lab - L\*a\*b
icc - Basé sur ICC
index - Couleur indexée
sep - Séparation
devn - DeviceN
comp
nombre de composantes de couleur
bpc
bits par composante
enc
encodage :
image - image raster (peut être compressé Flate ou LZW mais n'utilise pas d'encodage d'image)
jpeg - Joint Photographic Experts Group
jp2 - JPEG2000
jbig2 - Joint Bi-Level Image Experts Group
ccitt - Fax CCITT Group 3 ou Group 4
interp
"yes" si l'interpolation doit être effectuée lors de la mise à l'échelle de l'image
ID objet
l'ID objet du dictionnaire d'image (numéro et génération)
x-ppp
La résolution horizontale de l'image (en pixels par pouce) lors du rendu sur la page PDF.
y-ppp
La résolution verticale de l'image (en pixels par pouce) lors du rendu sur la page PDF.
taille
La taille de l'image incorporée dans le fichier PDF. Les suffixes suivants sont utilisés : 'B' octets, 'K' kilo-octets, 'M' méga-octets, et 'G' giga-octets.
ratio
Le ratio de compression de l'image incorporée.
-opw mot-de-passe
Spécifie le mot de passe propriétaire pour le fichier PDF. Le fournir permettra de contourner toutes les restrictions de sécurité.
-upw mot-de-passe
Spécifie le mot de passe utilisateur pour le fichier PDF.
-p
Inclut les numéros de page dans les noms de fichiers de sortie.
-print-filenames
Affiche les noms de fichiers d'image sur la sortie standard.
-q
Ne pas afficher de messages ou d'erreurs.
-v
Affiche les informations de copyright et de version.
-h
Affiche les informations d'utilisation. (-help et --help sont équivalents.)

EX

pdfimages(1)

CODES DE SORTIE

Les outils Xpdf utilisent les codes de sortie suivants :

0
Aucune erreur.
1
Erreur lors de l'ouverture d'un fichier PDF.
2
Erreur lors de l'ouverture d'un fichier de sortie.
3
Erreur liée aux permissions PDF.
99
Autre erreur.
