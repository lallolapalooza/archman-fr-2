NOM

pdfatfi - Programme d'aide pour le paquet LaTeX attachfile2.

SYNTAXE

pdfatfi <commande> [<options>] <fichier[.atfi]>

DESCRIPTION

Programme d'aide pour le paquet LaTeX attachfile2.

Ce paquet essaie également d'obtenir et d'ajouter des métadonnées, telles que la taille du fichier, la date du fichier, la somme de contrôle, ....

Le script pdfatfi.pl est fourni pour être utilisé avec les anciennes versions de pdfTeX et XeTeX qui ne fournissent pas d'accès aux métadonnées des fichiers.

L'utilisation du script Perl n'est pas obligatoire. Ces données peuvent être affichées par les visualiseurs PDF, mais elles ne sont pas une exigence de la spécification PDF.

Le paquet attachfile2 et le script Perl communiquent via un fichier auxiliaire avec l'extension .atfi. Le script est utilisé entre deux passes LaTeX et met à jour le fichier auxiliaire.

latex test
pdfatfi test
latex test
dvips test
ps2pdf test.ps test.pdf

OPTIONS

Diverses options sont prises en charge

--aide
Afficher le texte d'aide.
--version
Imprimer le numéro de version
--(no)quiet
Supprimer/ne pas supprimer les messages
--(no)verbose
Impression verbeuse (non verbeuse).
--(no)debug
Informations de débogage imprimées (non imprimées)
