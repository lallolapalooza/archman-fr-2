NOM

pdiff - produit une comparaison jolie entre fichiers

SYNTAXE

pdiff FICHIER1 FICHIER2 [-- OPTIONS-A2PS...]

DESCRIPTION

Imprime joliment les différences entre FICHIER1 et FICHIER2.

OPTIONS

-h, --help
affiche cette aide et quitte
-v, --version
affiche les informations de version et quitte
-q, --quiet
ne pas imprimer les messages d'information
-l, --lines
rechercher les différences de lignes (`diff')
-w, --words
rechercher les différences de mots (`wdiff')
-o, --output=FICHIER
enregistre la sortie dans FICHIER

Les options pour a2ps sont données après `--', par exemple

$ pdiff COPYING COPYING.LIB -- -Pdisplay
