TEXI2DVI(1) Commandes utilisateur TEXI2DVI(1)

NOM

texi2dvi - convertir des documents Texinfo en DVI ou PDF

SYNTAXE

texi2dvi [OPTION]... FICHIER...
texi2pdf [OPTION]... FICHIER...
pdftexi2dvi [OPTION]... FICHIER...

DESCRIPTION

Exécute chaque FICHIER Texinfo ou (La)TeX à tour de rôle jusqu'à ce que tous les renvois soient résolus, en construisant tous les index. Le répertoire contenant chaque FICHIER est recherché pour les fichiers inclus. Le suffixe de FICHIER est utilisé pour déterminer sa langue ((La)TeX ou Texinfo). Pour traiter les fichiers (e)plain TeX, définissez la variable d'environnement LATEX=tex.

Lorsqu'il est appelé sous le nom `texi2pdf' ou avec l'option --pdf, génère une sortie PDF. Sinon, génère du DVI.

Options générales :

-D, --debug
active le débogage shell (définit -x)
-h, --help
affiche cette aide et quitte avec succès
-o, --output=FICHIERO
laisse la sortie dans FICHIERO ; un seul FICHIER d'entrée est autorisé
-q, --quiet
pas de sortie sauf en cas d'erreurs
-v, --version
affiche les informations de version et quitte avec succès
-V, --verbose
rapporte ce qui est fait
--max-iterations=N
ne traite pas les fichiers plus de N fois [7]
--mostly-clean
supprime les fichiers ou répertoires auxiliaires des exécutions précédentes (mais pas la sortie)

Format de sortie :

--dvi
génère un fichier DVI [par défaut]
--dvipdf
génère un fichier PDF via DVI (en utilisant un programme dvi-vers-pdf)
-p, --pdf
utilise pdftex ou pdflatex pour le traitement
--ps
génère un fichier PostScript via DVI (en utilisant dvips)

Réglage de TeX :

-E, --expand
expansion des macros avec makeinfo
-I DIR
recherche dans DIR les fichiers Texinfo
-l, --language=LANG
spécifie LANG pour FICHIER, soit latex soit texinfo
--no-line-error
ne passe pas --file-line-error à TeX
--shell-escape
passe --shell-escape à TeX
--src-specials
passe --src-specials à TeX
--translate-file=FICHIER
utilise le fichier de traduction de jeu de caractères donné pour TeX
-t, --command=CMD
insère CMD dans une copie du fichier d'entrée

Modes de construction :

--build=MODE
spécifie le traitement des fichiers auxiliaires [local]
--tidy
identique à --build=tidy
-c, --clean
identique à --build=clean
--build-dir=DIR
spécifie où la compilation tidy est effectuée ; implique --tidy

Le MODE spécifie où la compilation TeX a lieu, et, par conséquent, comment les fichiers auxiliaires sont traités.

Les valeurs valides de MODE sont :

`local'
compile dans le répertoire courant, laissant tous les fichiers auxiliaires en place. C'est l'usage traditionnel de TeX.
`tidy'
compile dans un répertoire local *.t2d, où les fichiers auxiliaires sont laissés. Les fichiers de sortie sont copiés dans le fichier original.
`clean'
identique à `tidy', mais supprime le répertoire auxiliaire par la suite. Chaque compilation nécessite donc le cycle complet.

Le mode de construction peut également être défini en utilisant la variable d'environnement TEXI2DVI_BUILD_MODE. Le répertoire de construction tidy peut également être défini en utilisant la variable d'environnement TEXI2DVI_BUILD_DIRECTORY.

Les valeurs de ces variables d'environnement sont utilisées pour exécuter les commandes correspondantes, si elles sont définies :

BIBER BIBTEX DVIPDF DVIPS EGREP LATEX MAKEINDEX MAKEINFO PDFLATEX PDFTEX SED TEX TEXINDEX TEXINDY THUMBPDF_CMD

En ce qui concerne --dvipdf, si DVIPDF n'est pas défini dans l'environnement, les programmes suivants sont recherchés (dans cet ordre) : dvipdfmx dvipdfm dvipdf dvi2pdf dvitopdf.

Si Texinfo est installé sur votre site, alors la commande

info texi2dvi

devrait vous donner accès à plus de documentation.
