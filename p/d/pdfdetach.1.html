pdfdetach(1) Manuel des commandes générales pdfdetach(1)

NOM

pdfdetach - Extracteur de fichiers incorporés de documents Portable Document Format (PDF) (version 3.03)

SYNTAXE

pdfdetach [options] [fichier-PDF]

DESCRIPTION

Pdfdetach liste ou extrait les fichiers incorporés (pièces jointes) d'un fichier Portable Document Format (PDF).

OPTIONS

Certaines des options suivantes peuvent être définies à l'aide de commandes dans le fichier de configuration. Celles-ci sont listées entre crochets avec la description de l'option de ligne de commande correspondante.

-lister
Liste tous les fichiers incorporés dans le fichier PDF. Les noms de fichiers sont convertis au codage de texte spécifié par le commutateur "-enc".
-sauver nombre
Sauvegarde le fichier incorporé spécifié. Par défaut, utilise le nom de fichier associé au fichier incorporé (tel qu'affiché par le commutateur "-lister") ; le nom de fichier peut être modifié avec le commutateur "-o".
-sauverfichier nom_fichier
Sauvegarde le fichier incorporé spécifié. Par défaut, utilise le nom de fichier associé au fichier incorporé (tel qu'affiché par le commutateur "-lister") ; le nom de fichier peut être modifié avec le commutateur "-o".
-sauvertout
Sauvegarde tous les fichiers incorporés. Utilise les noms de fichiers associés aux fichiers incorporés (tels qu'affichés par le commutateur "-lister"). Par défaut, les fichiers sont sauvegardés dans le répertoire courant ; cela peut être modifié avec le commutateur "-o".
-o chemin
Définit le nom de fichier utilisé lors de la sauvegarde d'un fichier incorporé avec le commutateur "-sauver", ou le répertoire utilisé par "-sauvertout".
-enc nom-encodage
Définit l'encodage à utiliser pour la sortie texte (noms de fichiers incorporés). Par défaut, c'est "UTF-8".
-opw mot_de_passe
Spécifie le mot de passe propriétaire du fichier PDF. Fournir ceci contournera toutes les restrictions de sécurité.
-upw mot_de_passe
Spécifie le mot de passe utilisateur du fichier PDF.
-v
Affiche les informations de copyright et de version.
-h
Affiche les informations d'utilisation. (-aide et --aide sont équivalents.)

CODES DE SORTIE

Les outils Xpdf utilisent les codes de sortie suivants :

0
Aucune erreur.
1
Erreur lors de l'ouverture d'un fichier PDF.
2
Erreur lors de l'ouverture d'un fichier de sortie.
3
Erreur liée aux permissions PDF.
99
Autre erreur.
