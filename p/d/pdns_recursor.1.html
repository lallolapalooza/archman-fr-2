PDNS_RECURSOR(1) PowerDNS Recursor PDNS_RECURSOR(1)

NOM

pdns_recursor - Le binaire PowerDNS Recursor

SYNTAXE

pdns_recursor [OPTION]...

DESCRIPTION

pdns_recursor est un serveur de noms récursif haute performance, simple et sécurisé. Il alimente actuellement des centaines de millions de connexions Internet.

Le récursif est configuré via un fichier de configuration, mais chaque élément de ce fichier peut être remplacé en ligne de commande.

Cette page de manuel liste l'ensemble des fonctionnalités essentielles pour faire fonctionner le PowerDNS Recursor. Pour des détails complets et à jour, consultez https://doc.powerdns.com/.

EXEMPLES

Pour écouter sur 192.0.2.53 et autoriser le sous-réseau 192.0.2.0/24 à faire des requêtes récursives, et pour s'exécuter en arrière-plan, exécutez :

# pdns_recursor --local-address=192.0.2.53 --allow-from=192.0.2.0/24 --daemon

Pour arrêter le récursif manuellement, exécutez :

# rec_control quit-nicely

Cependant, la méthode recommandée pour démarrer et arrêter le récursif est d'utiliser systemctl(1) ou le script init.d.

OPTIONS

Pour une liste faisant autorité des options, consultez la documentation en ligne sur https://doc.powerdns.com/

--allow-from=<réseaux>
Si défini, autorise uniquement ces réseaux séparés par des virgules, avec le masque réseau, à faire des requêtes récursives. Par exemple : 192.0.2.0/24,203.0.113.128/25.
--auth-zones=<zones-autoritaires>
Où zone-autoritaire est <nom-zone>=<nom-fichier>. Sert nom-zone de manière faisant autorité à partir de nom-fichier. Par exemple : ds9a.nl=/var/zones/ds9a.nl,powerdns.com=/var/zones/powerdns.com.
--chroot=<répertoire>
Effectue un chroot du processus dans répertoire.
--client-tcp-timeout=<num>
Délai en secondes lors de la communication avec les clients TCP.
--config
Affiche la configuration actuelle. Depuis la version 4.8.0, il existe trois valeurs optionnelles : --config=default pour afficher la configuration par défaut. --config=diff pour afficher les options modifiées dans la configuration actuelle. --config=check pour vérifier la configuration actuelle à la recherche d'erreurs.
--config-dir=<répertoire>
Emplacement du répertoire de configuration (recursor.conf), le défaut dépend de l'option SYSCONFDIR au moment de la compilation, qui est généralement /etc/powerdns. Le défaut peut être trouvé avec pdns_recursor --config | grep ' config-dir='.
--daemon
Fonctionne comme un démon.
--entropy-source=<fichier>
Lit la nouvelle entropie à partir de fichier, par défaut /dev/urandom.
--export-etc-hosts
Si défini, ce drapeau exportera les noms d'hôtes et les adresses IP mentionnés dans /etc/hosts.
--forward-zones=<zones-transférées>
Où zone-transférée est <nom-zone>=<adresse>. Les requêtes pour nom-zone seront transférées à adresse. adresse doit être une adresse IP, pas un nom d'hôte (pour éviter les problèmes d'œuf et de poule). Exemple : forward-zones= ds9a.nl=213.244.168.210, powerdns.com=127.0.0.1.
--forward-zones-file=<nom-fichier>
Similaire à --forward-zones, mais lit les options à partir de nom-fichier. nom-fichier doit contenir une zone par ligne, comme : ds9a.nl=213.244.168.210.
--help
Affiche un résumé des options.
--hint-file=<nom-fichier>
Charge les indices racines à partir de ce nom-fichier.
--local-address=<adresse>
Écoute sur adresse, séparée par des espaces ou des virgules. Les adresses spécifiées peuvent inclure des numéros de port ; celles qui n'en incluent pas écouteront sur --local-port.
--local-port=<port>
Écoute sur port.
--log-common-errors
Si nous devons journaliser les erreurs plutôt communes.
--max-cache-entries=<num>
Nombre maximum d'entrées dans le cache principal.
--max-negative-ttl=<num>
Nombre maximum de secondes pour conserver une entrée de cache négative en mémoire.
--max-tcp-clients=<num>
Nombre maximum de clients TCP simultanés.
--max-tcp-per-client=<num>
Si défini, nombre maximum de sessions TCP par client (adresse IP).
--query-local-address=<adresse[,adresse...]>
Utilise adresse comme adresse IP source lors de l'envoi de requêtes.
--quiet
Supprime la journalisation des questions et des réponses.
--server-id=<texte>
Retourne texte lorsqu'on interroge pour un TXT 'id.server', par défaut le nom d'hôte.
--serve-rfc1918
Activé par défaut, cela rend le serveur autoritaire pour : 10.in-addr.arpa, 168.192.in-addr.arpa et 16-31.172.in-addr.arpa, ce qui réduit la charge sur les serveurs AS112. Les parties individuelles de ces zones peuvent toujours être chargées ou transférées.
--setgid=<gid>
Si défini, change l'identifiant de groupe en gid pour plus de sécurité.
--setuid=<uid>
Si défini, change l'identifiant d'utilisateur en uid pour plus de sécurité.
--single-socket
Si défini, n'utilise qu'un seul socket pour les requêtes sortantes.
--socket-dir=<répertoire>
Le socket de contrôle sera situé dans répertoire.
--spoof-nearmiss-max=<num>
Si différent de zéro, suppose un spoofing après ce nombre de quasi-échecs.
--trace
Si nous devons produire une quantité importante de journaux.
--version-string=<texte>
texte SERA rapporté sur les requêtes version.pdns ou version.bind.
