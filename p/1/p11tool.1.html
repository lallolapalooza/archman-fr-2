p11tool(1) Commandes utilisateur p11tool(1)

NOM

p11tool - Outil GnuTLS PKCS #11

SYNOPSIS

p11tool [-flags] [-flag [valeur]] [--option-name[[=| ]valeur]] [url]

Les opérandes et les options peuvent être mélangés. Ils seront réordonnés.

DESCRIPTION

Programme qui permet des opérations sur les cartes à puce et les modules de sécurité PKCS #11.

Pour utiliser les jetons PKCS #11 avec GnuTLS, les fichiers de configuration p11-kit doivent être configurés. C'est-à-dire créer un fichier .module dans /etc/pkcs11/modules avec le contenu 'module: /chemin/vers/pkcs11.so'. Alternativement, le fichier de configuration /etc/gnutls/pkcs11.conf doit exister et contenir un certain nombre de lignes de la forme 'load=/usr/lib/opensc-pkcs11.so'.

Vous pouvez fournir le code PIN à utiliser pour les opérations PKCS #11 avec les variables d'environnement GNUTLS_PIN et GNUTLS_SO_PIN.

OPTIONS

Jetons

--list-tokens

Lister tous les jetons disponibles.
--list-token-urls

Lister les URLs des jetons disponibles.

C'est une version plus compacte de --list-tokens.

--list-mechanisms

Lister tous les mécanismes disponibles dans un jeton.
--initialize

Initialise un jeton PKCS #11.
--initialize-pin

Initialise/Réinitialise le code PIN utilisateur d'un jeton PKCS #11.
--initialize-so-pin

Initialise/Réinitialise le code PIN de l'administrateur de sécurité d'un jeton PKCS #11.

Ceci initialise le code PIN de l'administrateur de sécurité. Lors d'une utilisation non interactive, utilisez les variables d'environnement GNUTLS_NEW_SO_PIN pour initialiser le code PIN de l'administrateur.

--set-pin=str

Spécifie le code PIN à utiliser lors des opérations sur le jeton.

Alternativement, la variable d'environnement GNUTLS_PIN peut être utilisée.

--set-so-pin=str

Spécifie le code PIN de l'administrateur de sécurité à utiliser lors de l'initialisation du jeton.

Alternativement, la variable d'environnement GNUTLS_SO_PIN peut être utilisée.

Listage des objets

--list-all

Lister tous les objets disponibles dans un jeton.

Tous les objets disponibles dans le jeton seront listés. Cela inclut les objets potentiellement inaccessibles avec cet outil.

--list-all-certs

Lister tous les certificats disponibles dans un jeton.

Cette option fournira également plus d'informations sur les certificats, par exemple, elle développera les extensions attachées dans un jeton de confiance (comme p11-kit-trust).

--list-certs

Lister tous les certificats ayant une clé privée associée.

Cette option n'affichera que les certificats qui ont une clé privée associée (partagent le même ID).

--list-all-privkeys

Lister toutes les clés privées disponibles dans un jeton.

Liste toutes les clés privées d'un jeton qui correspondent à l'URL spécifiée.

--list-privkeys

Ceci est un alias pour l'option --list-all-privkeys.
--list-keys

Ceci est un alias pour l'option --list-all-privkeys.
--list-all-trusted

Lister tous les certificats disponibles marqués comme fiables.
--export

Exporte l'objet spécifié par l'URL. Cette option ne doit pas être utilisée en combinaison avec les options suivantes: export-stapled, export-chain, export-pubkey.
--export-stapled

Exporte l'objet certificat spécifié par l'URL. Cette option ne doit pas être utilisée en combinaison avec les options suivantes: export, export-chain, export-pubkey.

Exporte le certificat spécifié par l'URL tout en incluant les extensions qui y sont attachées. Comme les extensions attachées sont une extension p11-kit, cette option n'est disponible que sur les modules de confiance enregistrés par p11-kit.

--export-chain

Exporte le certificat spécifié par l'URL et sa chaîne de confiance. Cette option ne doit pas être utilisée en combinaison avec les options suivantes: export-stapled, export, export-pubkey.

Exporte le certificat spécifié par l'URL et génère sa chaîne de confiance en se basant sur les certificats stockés dans le module.

--export-pubkey

Exporte la clé publique d'une clé privée. Cette option ne doit pas être utilisée en combinaison avec les options suivantes: export-stapled, export, export-chain.

Exporte la clé publique pour la clé privée spécifiée.

--info

Affiche des informations sur un objet disponible dans un jeton.
--trusted

Ceci est un alias pour l'option --mark-trusted.
--distrusted

Ceci est un alias pour l'option --mark-distrusted.

Génération de clés

--generate-privkey=str

Génère une paire clé privée-clé publique du type donné.

Génère une paire clé privée-clé publique dans le jeton spécifié. Les types acceptés sont RSA, ECDSA, Ed25519 et DSA. Doit être combiné avec --sec-param ou --bits.

--generate-rsa

Génère une paire clé privée-clé publique RSA.

Génère une paire clé privée-clé publique RSA sur le jeton spécifié. Doit être combiné avec --sec-param ou --bits.

NOTE : CETTE OPTION EST OBSOLÈTE

--generate-dsa

Génère une paire clé privée-clé publique DSA.

Génère une paire clé privée-clé publique DSA sur le jeton spécifié. Doit être combiné avec --sec-param ou --bits.

NOTE : CETTE OPTION EST OBSOLÈTE

--generate-ecc

Génère une paire clé privée-clé publique ECDSA.

Génère une paire clé privée-clé publique ECDSA sur le jeton spécifié. Doit être combiné avec --curve, --sec-param ou --bits.

NOTE : CETTE OPTION EST OBSOLÈTE

--bits=num

Spécifie le nombre de bits pour la clé générée. Cette option prend un nombre entier comme argument.

Pour les applications qui n'ont pas de restrictions sur la taille des clés, l'option --sec-param est recommandée, car les niveaux de paramètre de sécurité s'adapteront aux niveaux de sécurité acceptables avec les nouvelles versions de gnutls.

--curve=str

Spécifie la courbe utilisée pour la génération de clés EC.

Les valeurs supportées sont secp192r1, secp224r1, secp256r1, secp384r1 et secp521r1.

--sec-param=paramètre de sécurité

Spécifie le niveau de sécurité.

Écriture des objets

--set-id=str

Définit le CKA_ID (en hexadécimal) pour l'objet spécifié par l'URL. Cette option ne doit pas apparaître en combinaison avec l'une des options suivantes : write.

Modifie ou définit le CKA_ID dans l'objet spécifié par l'URL. L'ID doit être spécifié au format hexadécimal sans le préfixe '0x'.

--set-label=str

Définit le CKA_LABEL pour l'objet spécifié par l'URL. Cette option ne doit pas apparaître en combinaison avec l'une des options suivantes : write, set-id.

Modifie ou définit le CKA_LABEL dans l'objet spécifié par l'URL

--write

Écrit les objets chargés sur un jeton PKCS #11.

Il peut être utilisé pour écrire des clés privées, publiques, des certificats ou des clés secrètes sur un jeton. Doit être combiné avec l'une des options --load-privkey, --load-pubkey, --load-certificate.

Lors de l'écriture d'un objet certificat, son CKA_ID est défini sur le même CKA_ID de la clé publique correspondante, si elle existe sur le jeton ; sinon, il sera dérivé de l'identifiant de clé du sujet X.509 du certificat. Si ce comportement n'est pas souhaité, écrivez la clé publique sur le jeton au préalable.

--delete

Supprime les objets correspondant à l'URL PKCS #11 donnée.
--label=str

Définit une étiquette pour l'opération d'écriture.
--id=str

Définit un ID pour l'opération d'écriture.

Définit le CKA_ID à définir par l'opération d'écriture. L'ID doit être spécifié au format hexadécimal sans le préfixe '0x'.

--mark-wrap, --no-mark-wrap

Marque la clé générée comme clé de chiffrement. La forme no-mark-wrap désactive l'option.

Marque la clé générée avec le drapeau CKA_WRAP.

--mark-trusted, --no-mark-trusted

Marque l'objet à écrire comme fiable. Cette option ne doit pas apparaître en combinaison avec l'une des options suivantes : mark-distrusted. La forme no-mark-trusted désactive l'option.

Marque l'objet à générer/écrire avec le drapeau CKA_TRUST.

--mark-distrusted

Lors de la récupération d'objets, exige que les objets soient considérés comme non fiables. Cette option ne doit pas apparaître en combinaison avec l'une des options suivantes : mark-trusted.

Garantit que les objets récupérés ont le drapeau CKA_X_TRUST. Il s'agit d'une extension du module de confiance p11-kit, donc ce drapeau n'est valide qu'avec les modules de confiance enregistrés par p11-kit.

--mark-decrypt, --no-mark-decrypt

Marque l'objet à écrire pour le déchiffrement. La forme no-mark-decrypt désactive l'option.

Marque l'objet à générer/écrire avec le drapeau CKA_DECRYPT défini sur vrai.

--mark-sign, --no-mark-sign

Marque l'objet à écrire pour la génération de signature. La forme no-mark-sign désactive l'option.

Marque l'objet à générer/écrire avec le drapeau CKA_SIGN défini sur vrai.

--mark-ca, --no-mark-ca

Marque l'objet à écrire comme une AC. La forme no-mark-ca désactive l'option.

Marque l'objet à générer/écrire avec la catégorie de certificat CKA_CERTIFICATE_CATEGORY en tant qu'AC.

--mark-private, --no-mark-private

Marque l'objet à écrire comme privé. La forme no-mark-private désactive l'option.

Marque l'objet à générer/écrire avec le drapeau CKA_PRIVATE. L'objet écrit nécessitera un code PIN pour être utilisé.

--ca

Ceci est un alias pour l'option --mark-ca.
--private

Ceci est un alias pour l'option --mark-private.
--mark-always-authenticate, --no-mark-always-authenticate

Marque l'objet à écrire comme authentification toujours requise. La forme no-mark-always-authenticate désactive l'option.

Marque l'objet à générer/écrire avec le drapeau CKA_ALWAYS_AUTHENTICATE. L'objet écrit marquera l'objet comme nécessitant une authentification (saisie du code PIN) avant chaque opération.

--secret-key=str

Fournit une clé secrète encodée en hexadécimal.

Cette clé secrète sera écrite dans le module si --write est spécifié.

--load-privkey=file

Fichier de clé privée à utiliser.
--load-pubkey=file

Fichier de clé publique à utiliser.
--load-certificate=file

Fichier de certificat à utiliser.

Autres options

-d num, --debug=num

Active le débogage. Cette option prend un nombre entier comme argument. La valeur de num est contrainte à : 
être dans la plage de 0 à 9999

Spécifie le niveau de débogage.

--outfile=str

Fichier de sortie.
--login, --no-login

Force la connexion (utilisateur) au jeton. La forme no-login désactive l'option.
--so-login, --no-so-login

Force la connexion de l'officier de sécurité au jeton. La forme no-so-login désactive l'option.

Force la connexion au jeton en tant qu'officier de sécurité (administrateur).

--admin-login

Ceci est un alias pour l'option --so-login.
--test-sign

Teste l'opération de signature de l'objet fourni.

Il peut être utilisé pour tester le bon fonctionnement de l'opération de signature. Si une clé privée et une clé publique sont disponibles, cette opération signera et vérifiera les données signées.

--sign-params=str

Signe avec un algorithme de signature spécifique.

Cette option peut être combinée avec --test-sign, pour signer avec une variante d'algorithme de signature spécifique. La seule option prise en charge est 'RSA-PSS', et doit être spécifiée afin d'utiliser la signature RSA-PSS sur les clés RSA.

--hash=str

Algorithme de hachage à utiliser pour la signature.

Cette option peut être combinée avec test-sign. Les fonctions de hachage disponibles sont SHA1, RMD160, SHA256, SHA384, SHA512, SHA3-224, SHA3-256, SHA3-384, SHA3-512.

--generate-random=num

Génère des données aléatoires. Cette option prend un nombre entier comme argument.

Demande au jeton de générer un certain nombre d'octets aléatoires.

-8, --pkcs8

Utilise le format PKCS #8 pour les clés privées.
--inder, --no-inder

Utilise le format DER/RAW pour l'entrée. La forme no-inder désactive l'option.

Utilise le format DER/RAW pour les certificats et les clés privées d'entrée.

--inraw

Ceci est un alias pour l'option --inder.
--outder, --no-outder

Utilise le format DER pour les certificats de sortie, les clés privées et les paramètres DH. La forme no-outder désactive l'option.

La sortie sera au format DER ou RAW.

--outraw

Ceci est un alias pour l'option --outder.
--provider=file

Spécifie la bibliothèque du fournisseur PKCS #11.

Ceci remplacera les options par défaut dans /etc/gnutls/pkcs11.conf

--provider-opts=str

Spécifie les paramètres pour la bibliothèque du fournisseur PKCS #11.

Ceci est une option interne PKCS#11 utilisée par quelques modules. Principalement pour tester les modules PKCS#11.

NOTE : CETTE OPTION EST OBSOLÈTE

--detailed-url, --no-detailed-url

Affiche les URLs détaillées. La forme no-detailed-url désactive l'option.
--only-urls

Affiche une liste compacte utilisant uniquement les URLs.
--batch

Désactive toute interaction avec l'outil.

En mode batch, il n'y aura pas de messages d'invite, tous les paramètres doivent être spécifiés sur la ligne de commande.

-v arg, --version=arg

Affiche la version du programme et quitte. Le mode par défaut est 'v', une version simple. Le mode `c' affichera les informations de copyright et `n' affichera l'avis de copyright complet.
-h, --help

Affiche les informations d'utilisation et quitte.
-!, --more-help

Transmet les informations d'utilisation étendues à un pagineur.

EXEMPLES

Pour afficher tous les jetons de votre système, utilisez : 

$ p11tool --list-tokens

Pour afficher tous les objets d'un jeton, utilisez : 

$ p11tool --login --list-all "pkcs11:TOKEN-URL"

Pour stocker une clé privée et un certificat dans un jeton, exécutez : 

$ p11tool --login --write "pkcs11:URL" --load-privkey key.pem           --label "MaCle"
$ p11tool --login --write "pkcs11:URL" --load-certificate cert.pem           --label "MaCle"

Notez que certains jetons nécessitent que le même libellé soit utilisé pour le certificat et sa clé privée correspondante.

Pour générer une clé privée RSA dans le jeton, utilisez : 

$ p11tool --login --generate-privkey rsa --bits 1024 --label "MaNouvelleCle"           --outfile MaNouvelleCle.pub "pkcs11:TOKEN-URL"
Le paramètre `bits` dans l'exemple ci-dessus est explicitement défini car certains jetons ne prennent en charge que des choix limités dans la longueur de bits. Le fichier de sortie est la clé publique correspondante. Cette clé peut être utilisée pour générer une demande de certificat avec `certtool`. 

certtool --generate-request --load-privkey "pkcs11:KEY-URL"    --load-pubkey MaNouvelleCle.pub --outfile request.pem

ÉTAT DE SORTIE

L'une des valeurs de sortie suivantes sera retournée :

0 (EXIT_SUCCESS)

Exécution réussie du programme.
1 (EXIT_FAILURE)

L'opération a échoué ou la syntaxe de la commande était invalide.
