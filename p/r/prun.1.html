PRUN(1) Environnement d'exécution de référence PMIx PRUN(1)

prun — lance une application

SYNTAXE

shell$ prun ...options...

DESCRIPTION

prun soumet un travail à l'environnement d'exécution de référence PMIx (PRRTE). L'utilisateur a le contrôle sur diverses options de machine virtuelle distribuée (DVM).

Une grande partie de cette même documentation d'aide pour cette commande est également fournie via prun --help [sujet].
