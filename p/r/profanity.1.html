NOM

Profanity - un client de chat XMPP simple basé sur console.

SYNTAXE

profanity [-vh] [-l niveau] [-a compte]

DESCRIPTION

Profanity est un client de chat XMPP simple et léger basé sur console. Son accent est mis sur une interface utilisateur simple et configurable pilotée par commandes, voir la page d'accueil sur :

https://profanity-im.github.io

OPTIONS

-v, --version
Affiche la version et les informations de compilation.
-h, --help
Affiche l'aide sur les arguments de la ligne de commande.
-a, --account COMPTE
Se connecte automatiquement à un compte au démarrage, COMPTE doit être un compte existant.
-c, --config
Utilise un fichier de configuration alternatif.
-l, --log NIVEAU
Définit le niveau de journalisation, NIVEAU peut être réglé sur DEBUG, INFO (par défaut), WARN ou ERROR.
-f, --logfile
Spécifie un fichier journal différent
-r, --cmd
Spécifie les commandes qui doivent être exécutées juste après le démarrage. Cela peut être donné plusieurs fois, par exemple : 
profanity --cmd /foo --cmd "/sleep 10" --cmd /quit
-t, --theme THEME
Spécifie quel thème utiliser. THEME doit être l'un des thèmes installés dans $XDG_CONFIG_HOME/profanity/themes

RACCOURCIS CLAVIER

Tab, Shift+Tab
Complétion par tabulation suivant, précédent. Fonctionne pour les commandes, les pseudos et les citations (lorsque la ligne d'entrée commence par >).
ALT+1..Alt-0 ou F1..F10
Choisit la fenêtre 1..10.
ALT+q..Alt-p (en disposition QWERTY)
Choisit la fenêtre 11..20.
ALT+GAUCHE
Choisit la fenêtre de chat précédente.
ALT+DROITE
Choisit la fenêtre de chat suivante.
PAGEPREC
Fait défiler la fenêtre active vers le haut.
PAGESUIS
Fait défiler la fenêtre active vers le bas.
ALT+PAGEPREC
Fait défiler le panneau des occupants ou de la liste de contacts vers le haut.
ALT+PAGESUIS
Fait défiler le panneau des occupants ou de la liste de contacts vers le bas.
ALT+HAUT ou ROULETTEHAUT
Fait défiler vers le haut. Note : support limité du défilement avec la molette de la souris, merci de contacter les développeurs si vous savez comment ajouter le support pour d'autres terminaux.
ALT+BAS ou ROULETTEBAS
Fait défiler vers le bas. Voir la note ci-dessus.
ALT+a
Saute à la prochaine fenêtre non lue.
ALT+v
Marque la fenêtre actuelle pour une lecture ultérieure avec un indicateur d'attention.
ALT+m
Commute entre les fenêtres marquées avec l'indicateur d'attention.
ALT+ENTREE
Ajoute un caractère de nouvelle ligne sans envoyer de message/commande.
ALT+c
Lance l'éditeur externe (voir profanity-editor(1)) pour la ligne d'entrée actuelle.
CTRL+BAS
Stocke la ligne d'entrée actuelle dans l'historique mais ne l'exécute pas.

Note : Profanity utilise la bibliothèque GNU Readline pour gérer les entrées, donc le fichier de configuration par défaut ~/.inputrc affecte le fonctionnement. De plus, $XDG_CONFIG_HOME/profanity/inputrc est lu après que tous les raccourcis clavier par défaut sont définis, on peut donc y remplacer ou ajouter des paramètres. Pour référence, voir la documentation Readline : info readline "Command Line Editing" "Readline Init File" "Readline Init File Syntax" et la liste des commandes Profanity disponibles dans inputwin.c. Les raccourcis Readline standard sont pris en charge, y compris C-r pour la recherche interactive dans l'historique et C-x C-r pour recharger inputrc sans redémarrage.

UTILISATION DE PROFANITY

La première étape est de se connecter à un serveur XMPP. Les commandes /connect et /account peuvent être utilisées pour configurer les comptes XMPP dans profanity (voir profanity-connect(1) et profanity-account(1)) avec un compte XMPP existant. La commande /register peut être utilisée pour enregistrer un compte sur un serveur. profanity-register(1) Utilisez la commande /help commands connection dans profanity pour afficher plus de commandes pour gérer votre connexion.

La liste de contacts est votre carnet d'adresses. Par défaut, votre liste de contacts sera affichée dans la "fenêtre 1", qui est la /console de profanity. Il est possible de /roster hide et de /roster show le carnet d'adresses dans la console profanity. Les amis peuvent être ajoutés via /roster add JID.

Pour voir le statut en ligne de vos contacts, la commande /sub peut être utilisée pour gérer les abonnements à la présence des contacts. /sub request enverra une requête. /sub allow est utilisé pour approuver la requête d'abonnement d'un contact. Utilisez /help commands roster pour obtenir une liste des commandes qui peuvent être utilisées pour gérer votre liste de contacts.

Les fenêtres de discussion ouvertes peuvent être affichées par la commande /wins. Pour sauter à une fenêtre, utilisez /win NUMÉRO ou /win JID. Profanity prend en charge la complétion automatique avec la touche TAB. La commande /msg peut être utilisée pour démarrer un chat avec votre contact. Les discussions de groupe peuvent être rejointes avec la commande /join ou gérées dans les favoris du compte.

Si la discussion de groupe est stockée dans les favoris, la discussion de groupe peut être configurée pour une connexion automatique. Si la connexion automatique est désactivée, utilisez /bookmark join pour rejoindre la discussion de groupe. Les commandes /sendfile et /url peuvent être utilisées pour partager et télécharger des fichiers. Entrez > et appuyez sur la touche TAB pour citer un message existant dans la fenêtre de discussion.

Le guide de l'utilisateur se trouve sur https://profanity-im.github.io/userguide.html.

CHIFFREMENT

Profanity prend en charge divers types de chiffrement : OMEMO, OTR, PGP, OX. Vous ne pouvez en activer qu'un seul par correspondant à la fois.

OMEMO
OMEMO (/omemo) est défini dans XEP-0384. Il utilise une implémentation du protocole Signal pour la gestion des clés et la synchronisation des messages entre différents clients. Il fonctionne même lorsque les autres clients sont hors ligne. Et offre le Perfect Forward Secrecy et la déniabilité plausible. Les serveurs doivent prendre en charge PEP (XEP-0163). Nous implémentons la version "siacs" d'OMEMO. Version 0.3.0, qui est actuellement l'option la plus largement adoptée. OMEMO est la seule option de chiffrement dans Profanity qui prend également en charge le chiffrement pour les MUCs (XEP-0045) et le transfert de fichiers via le téléchargement HTTP (XEP-0363).
OTR
OTR (/otr) est défini dans XEP-0364. Il utilise une combinaison de l'algorithme de clé symétrique AES, de l'échange de clés Diffie-Hellman et de la fonction de hachage SHA-1. Il offre une authentification déniable et le Perfect Forward Secrecy. Pour initialiser une session, les deux clients doivent être en ligne en même temps. Une session est entre deux clients, donc les chats multi-clients ne fonctionnent pas. Ce qui est une fonctionnalité et non un bug. OTR ne fonctionne par conception pas pour les MUCs.
OpenPGP
OpenPGP (/pgp) est défini dans XEP-0027. Il utilise une clé publique et secrète. Il est également connu sous le nom de Lega

OX
OX (/ox) est défini dans XEP-0373 et XEP-0374. C'est une manière plus moderne d'utiliser OpenPGP sur XMPP et tente de corriger les lacunes de l'ancien XEP-0027. Les serveurs doivent prendre en charge PEP (XEP-0163). Les MUC et le transfert de fichiers via le téléchargement HTTP ne sont pas spécifiés et donc pas pris en charge.

TERMINOLOGIE

Il existe une terminologie spécifique à XMPP qui peut être inconnue des nouveaux utilisateurs. Nous allons essayer de les décrire ici car elles font souvent référence dans l'aide et les pages man.

JID
Signifie Jabber ID. Il fait référence à une adresse XMPP. Historiquement, XMPP était également connu sous le nom de Jabber.
MAM
Signifie Message Archive Management (XEP-0313) et décrit la capacité de stocker des messages sur le serveur et de les récupérer plus tard.
MUC
Signifie Mutli-User Chats (XEP-0045) et sont également appelés groupes, discussions de groupe, salons de discussion ou conférences.
Roster
La liste de contacts est votre liste de contacts. Par défaut, affichée sur le côté droit de la fenêtre de la console. Voir RFC6121.
XEP
XMPP est un protocole extensible. Il existe des fonctionnalités de base et des fonctionnalités optionnelles décrites dans les XMPP Extension Protocols, abrégés XEP.

VOIR AUSSI

Profanity lui-même a beaucoup d'aide intégrée. Consultez la commande /help pour plus d'informations. Tapez "/help help" pour obtenir des informations sur la façon d'utiliser l'aide elle-même. Profanity est livré avec une page man pour chaque commande intégrée, par exemple, il existe profanity-account(1) pour /account.

CONFIGURATION

La configuration de Profanity est stockée dans $XDG_CONFIG_HOME/profanity/profrc, les détails sur les commandes de configuration de Profanity peuvent être trouvés à https://profanity-im.github.io/reference.html ou dans l'aide intégrée ou les pages man respectives.
