NOM

prosodyctl - Gérer un serveur Prosody XMPP

SYNTAXE

prosodyctl commande [--help]

DESCRIPTION

prosodyctl est l'outil de contrôle du serveur Prosody XMPP. Il peut être utilisé pour contrôler le démon du serveur et gérer les utilisateurs.

prosodyctl doit être exécuté avec des privilèges suffisants pour effectuer ses commandes. Cela signifie généralement exécuter prosodyctl en tant qu'utilisateur root. Si un utilisateur nommé « prosody » est trouvé, prosodyctl changera vers cet utilisateur avant d'exécuter ses commandes.

COMMANDES

Gestion des utilisateurs

Dans les commandes suivantes, les utilisateurs sont identifiés par un ID Jabber, jid, de la forme habituelle : user@domain.

adduser jid
Ajoute un utilisateur avec l'identifiant Jabber, jid, au serveur. Il vous sera demandé de saisir le mot de passe de l'utilisateur.
passwd jid
Change le mot de passe d'un utilisateur existant avec l'identifiant Jabber, jid. Il vous sera demandé de saisir le nouveau mot de passe de l'utilisateur.
deluser jid
Supprime un utilisateur existant avec l'identifiant Jabber, jid, du serveur.

Gestion du démon

Bien que prosodyctl dispose de commandes pour gérer le démon prosody, il est recommandé d'utiliser les fonctionnalités de gestion des démons de votre distribution si vous avez obtenu Prosody via un paquet.

Pour effectuer des commandes de contrôle du démon, prosodyctl a besoin d'un fichier pidfile spécifié dans /etc/prosody/prosody.cfg.lua. Ne pas le faire fera se plaindre prosodyctl.

start
Démarre le démon du serveur prosody. S'il est exécuté en tant que root, prosodyctl tentera de changer pour un utilisateur nommé « prosody » avant d'exécuter. Cette opération bloquera jusqu'à cinq secondes pour attendre que le serveur s'exécute.
stop
Arrête le démon du serveur prosody. Cette opération bloquera jusqu'à cinq secondes pour attendre que le serveur cesse de s'exécuter.
restart
Redémarre le démon du serveur prosody. Équivalent à exécuter prosodyctl stop suivi de prosodyctl start.
reload
Signale au démon du serveur prosody de recharger la configuration et de rouvrir les fichiers journaux.
status
Affiche l'état d'exécution actuel du démon du serveur prosody.

Certificats

prosodyctl peut créer des certificats auto-signés, des demandes de certificats et des clés privées à utiliser avec Prosody. Les commandes sont de la forme prosodyctl cert sous-commande. Les commandes prennent une liste d'hôtes à inclure dans le certificat.

request hôtes
Crée un fichier de demande de certificat (CSR) à soumettre à une autorité de certification. Plusieurs hôtes peuvent être donnés, les sous-domaines sont automatiquement inclus.
generate hôtes
Génère un certificat auto-signé.
key hôte [taille]
Génère une clé privée de `taille' bits (par défaut 2048). Appelée automatiquement par `request' et `generate' si nécessaire.
config hôtes
Produit un fichier de configuration pour la liste des hôtes. Appelée automatiquement par `request' et `generate' si nécessaire.
import hôtes chemins
Copie les certificats des hôtes dans le chemin des certificats et recharge prosody.

Débogage

prosodyctl peut également afficher des informations sur l'environnement, les dépendances, etc., pour aider au débogage.

about
Affiche l'environnement, divers chemins utilisés par Prosody et les dépendances installées.
check [quoi]
Effectue diverses vérifications de cohérence sur la configuration, la configuration DNS et les certificats TLS configurés. quoi peut être config, dns, certs, disabled ou connectivity pour n'exécuter que cette vérification.

Compatibilité Ejabberd

ejabberd est un autre serveur XMPP qui fournit un outil de contrôle comparable, ejabberdctl, pour contrôler les opérations de son serveur. prosodyctl implémente certaines commandes compatibles avec ejabberdctl. Pour plus de détails sur le fonctionnement de ces commandes, consultez ejabberdctl(8).

register utilisateur serveur motdepasse
unregister utilisateur serveur

OPTIONS

--config nomfichier
Utilise le fichier de configuration spécifié au lieu du défaut.
--root
Ne pas abandonner les privilèges root (par exemple, lorsqu'il est invoqué avec sudo).
--help
Affiche le texte d'aide pour la commande spécifiée.
--verbose
Augmente le niveau de journalisation pour afficher les messages de débogage.
--quiet
Réduit le niveau de journalisation pour n'afficher que les erreurs.
--silent
Désactive complètement la journalisation, ne laissant que la sortie de la commande.

FICHIERS

/etc/prosody/prosody.cfg.lua
Le fichier de configuration principal de prosody. prosodyctl le lit pour déterminer le fichier PID du démon du serveur prosody et pour déterminer si un hôte a été configuré.

EN LIGNE

Plus d'informations peuvent être trouvées en ligne sur : https://prosody.im/

    NAME

    prosodyctl - control the Prosody XMPP server

    SYNOPSIS

    prosodyctl [OPTIONS] COMMAND [ARGS...]

    DESCRIPTION

    This manual page describes the prosodyctl command. It is used to control the Prosody XMPP server, performing administrative tasks such as user management, module control, and server status checks.

    COMMANDS

    The following commands are available:

    register <host> <username> [<password>]
    Register a new user on the specified host.
    password <host> <username> [<password>]
    Change the password for a user.
    delete <host> <username>
    Delete a user.
    listusers [<host>]
    List all registered users on the specified host (or all hosts if none specified).
    load <module>
    Load a Prosody module.
    unload <module>
    Unload a Prosody module.
    reload <module>
    Reload a Prosody module.
    modules
    List all loaded modules.
    status
    Show the current status of the Prosody server.
    restart
    Restart the Prosody server.
    stop
    Stop the Prosody server.
    start
    Start the Prosody server.
    console
    Open an interactive Prosody Lua console.

    OPTIONS

    -h, --help
    Show a help message and exit.
    -v, --version
    Show version information and exit.
    -c <config>, --config=<config>
    Specify an alternative configuration file.
    -d, --daemon
    Run Prosody as a daemon.
    -f <pidfile>, --pidfile=<pidfile>
    Specify a PID file.

    FILES

    /etc/prosody/prosody.cfg.lua
    Default Prosody configuration file.
    /var/run/prosody/prosody.pid
    Default PID file location.

    ONLINE

    More information can be found on the official Prosody website: https://prosody.im/
