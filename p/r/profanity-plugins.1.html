profanity-plugins(1)

Paquet: profanity

Licences: GPL3

man(1) Client XMPP Profanity man(1)

NOM

/plugins

DESCRIPTION

Gérer les plugins. Passer aucun argument liste les plugins installés et les plugins globaux disponibles pour une installation locale. Le répertoire global pour les plugins Python est /usr/local/share/profanity/plugins et pour les plugins C est /usr/local/lib64/profanity/plugins.

SYNTAXE

/plugins

/plugins install [<chemin ou URL>]

/plugins update [<chemin ou URL>]

/plugins uninstall [<plugin>]

/plugins unload [<plugin>]

/plugins load [<plugin>]

/plugins reload [<plugin>]

/plugins python_version

ARGUMENTS

install [<chemin ou URL>]

Installe un plugin, ou tous les plugins trouvés dans un répertoire (récursivement), ou télécharge et installe un plugin (le nom du plugin est basé sur le nom de fichier). Puis le/les charge.

update [<chemin ou URL>]

Désinstalle puis installe le plugin. Le nom du plugin à mettre à jour est le nom de fichier.

uninstall [<plugin>]

Désinstalle un plugin.

load [<plugin>]

Charge un plugin qui existe déjà dans le répertoire des plugins, passer aucun argument charge tous les plugins trouvés. Il sera également chargé au prochain démarrage, sauf s'il est déchargé.

unload [<plugin>]

Décharge un plugin chargé, passer aucun argument décharge tous les plugins.

reload [<plugin>]

Recharge un plugin, passer aucun argument recharge tous les plugins.

python_version

Affiche la version de l'interpréteur Python.

EXEMPLES

/plugins install /home/steveharris/Downloads/metal.py

/plugins install https://raw.githubusercontent.com/profanity-im/profanity-plugins/master/stable/sounds.py

/plugins update /home/steveharris/Downloads/metal.py

/plugins update https://raw.githubusercontent.com/profanity-im/profanity-plugins/master/stable/sounds.py

/plugins uninstall browser.py

/plugins load browser.py

/plugins unload say.py

/plugins reload wikipedia.py
