profanity-tls(1)

Paquet: profanity

Licences: GPL3

man(1) Client XMPP Profanity man(1)

NOM

/tls

DESCRIPTION

Gérer les certificats TLS.

SYNTAXE

/tls allow

/tls always

/tls deny

/tls cert [<empreinte>]

/tls trust

/tls trusted

/tls revoke <empreinte>

/tls certpath

/tls certpath set <chemin>

/tls certpath clear

/tls certpath default

ARGUMENTS

allow

Autoriser la connexion à se poursuivre avec le certificat TLS.

always

Toujours autoriser les connexions avec certificat TLS.

deny

Interrompre la connexion.

cert

Afficher le certificat TLS actuel.

cert <empreinte>

Afficher les détails du certificat approuvé.

trust

Ajouter le certificat TLS actuel aux certificats approuvés manuellement.

trusted

Lister un résumé des certificats approuvés manuellement (avec '/tls always' ou '/tls trust').

revoke <empreinte>

Supprimer un certificat approuvé manuellement.

certpath

Afficher le chemin du certificat approuvé.

certpath set <chemin>

Spécifier le chemin du système de fichiers contenant les certificats approuvés.

certpath clear

Effacer le chemin du certificat approuvé.

certpath default

Utiliser le chemin du certificat système par défaut, s'il peut être trouvé.
