PRS(1P) Manuel du programmeur POSIX PRS(1P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails sur le comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

prs — affiche un fichier SCCS (DÉVELOPPEMENT)

SYNTAXE

prs [-a] [-d spécification_données] [-r[SID]] fichier...
prs [-e|-l] -c date_limite [-d spécification_données] fichier...
prs [-e|-l] -r[SID] [-d spécification_données] fichier...

DESCRIPTION

L'utilitaire prs écrira sur la sortie standard des parties ou la totalité d'un fichier SCCS dans un format fourni par l'utilisateur.

OPTIONS

L'utilitaire prs se conformera au volume Définitions de base de POSIX.1‐2017, Section 12.2, Directives de syntaxe des utilitaires, à l'exception de l'option -r qui possède un argument d'option facultatif. Cet argument d'option facultatif ne peut pas être présenté comme un argument séparé. Les options suivantes seront prises en charge :

-d spécification_données
Spécifie la spécification des données de sortie. La spécification_données sera une chaîne composée de mots-clés de données de fichier SCCS (voir Mots-clés de données) entrelacés avec du texte facultatif fourni par l'utilisateur.
-r[SID]
Spécifie la chaîne d'identification SCCS (SID) d'un delta pour lequel des informations sont souhaitées. Si aucun argument d'option SID n'est spécifié, le SID du delta créé le plus récemment sera présumé.
-e
Demande des informations pour tous les deltas créés avant et incluant le delta désigné via l'option -r ou la date-heure donnée par l'option -c.
-l
Demande des informations pour tous les deltas créés après et incluant le delta désigné via l'option -r ou la date-heure donnée par l'option -c.
-c date_limite
Indique la date_limite, sous la forme :
AA[MM[JJ[HH[MM[SS]]]]]

Pour la composante AA, les valeurs dans la plage [69,99] se référeront aux années 1969 à 1999 incluses, et les valeurs dans la plage [00,68] se référeront aux années 2000 à 2068 incluses.

Note :
Il est prévu que dans une future version de cette norme, le siècle par défaut déduit d'une année à 2 chiffres changera. (Cela s'appliquerait à toutes les commandes acceptant une année à 2 chiffres en entrée.)

Aucune modification (delta) du fichier SCCS qui aurait été créée après la date-heure spécifiée date_limite ne sera incluse dans la sortie. Les unités omises de la date-heure seront remplacées par leurs valeurs maximales possibles ; par exemple, -c 7502 est équivalent à -c 750228235959.

-a
Demande l'écriture d'informations pour les deltas supprimés — c'est-à-dire, type_delta=R (voir rmdel) — et les deltas existants — c'est-à-dire, type_delta=D. Si l'option -a n'est pas spécifiée, seules les informations relatives aux deltas existants seront fournies.

OPÉRANDES

Le opérande suivant sera pris en charge :

fichier
Un chemin d'accès vers un fichier SCCS existant ou un répertoire. Si fichier est un répertoire, l'utilitaire prs se comportera comme si chaque fichier du répertoire était spécifié comme un fichier nommé, à l'exception des fichiers non SCCS (le dernier composant du chemin ne commence pas par s.) et des fichiers illisibles qui seront silencieusement ignorés.

Si exactement un opérande fichier apparaît, et qu'il s'agit de '-', l'entrée standard sera lue ; chaque ligne de l'entrée standard sera considérée comme le nom d'un fichier SCCS à traiter. Les fichiers non SCCS et les fichiers illisibles seront silencieusement ignorés.

STDIN

L'entrée standard sera un fichier texte utilisé uniquement lorsque l'opérande fichier est spécifié comme '-'. Chaque ligne du fichier texte sera interprétée comme un nom de chemin SCCS.

FICHIERS ENTREE

Tous les fichiers SCCS affichés sont des fichiers dont le format n'est pas spécifié.

VARIABLES ENVIRONNEMENT

Les variables d'environnement suivantes affecteront l'exécution de prs :

LANG
Fournit une valeur par défaut pour les variables d'internationalisation qui ne sont pas définies ou sont vides. (Voir le volume Définitions de base de POSIX.1‐2017, Section 8.2, Variables d'internationalisation la priorité des variables d'internationalisation utilisées pour déterminer les valeurs des catégories de locale.)
LC_ALL
Si elle est définie sur une chaîne de caractères non vide, remplace les valeurs de toutes les autres variables d'internationalisation.
LC_CTYPE
Détermine la locale pour l'interprétation des séquences d'octets de données textuelles en caractères (par exemple, caractères mono-octet par opposition aux caractères multi-octets dans les arguments et les fichiers d'entrée).
LC_MESSAGES

Détermine la locale qui devrait être utilisée pour affecter le format et le contenu des messages de diagnostic écrits sur la sortie d'erreur standard.
NLSPATH
Détermine l'emplacement des catalogues de messages pour le traitement de LC_MESSAGES.

ÉVÉNEMENTS ASYNCHRONES

Par défaut.

STDOUT

La sortie standard sera un fichier texte dont le format dépend des mots-clés de données spécifiés avec l'option -d.

Mots-clés de données

Les mots-clés de données spécifient quelles parties d'un fichier SCCS doivent être récupérées et affichées. Toutes les parties d'un fichier SCCS ont un mot-clé de données associé. Un mot-clé de données peut apparaître plusieurs fois dans une spécification_données.

Les informations écrites par prs comprendront :

1.
Le texte fourni par l'utilisateur
2.
Les valeurs appropriées (extraites du fichier SCCS) substituées aux mots-clés de données reconnus dans l'ordre d'apparition dans la spécification_données

Le format d'une valeur de mot-clé de données sera soit simple ('S'), auquel cas la substitution de mot-clé est directe, soit multiligne ('M').

Le texte fourni par l'utilisateur sera tout texte autre que les mots-clés de données reconnus. Une tabulation (<tab>) sera spécifiée par '\t' et un saut de ligne (<newline>) par '\n'. Lorsque l'option -r n'est pas spécifiée, la spécification_données par défaut sera :

:PN::\n\n

et la spécification_données suivante sera utilisée pour chaque delta sélectionné :

STDERR

Le flux d'erreurs standard ne sera utilisé que pour les messages de diagnostic.

STATUT DE SORTIE

Les valeurs de sortie suivantes seront retournées :

 0
Achèvement réussi.
>0
Une erreur s'est produite.

USAGE DE L'APPLICATION

Aucun.

EXEMPLES

1.
L'exemple suivant :
prs -d "User Names for :F: are:\n:UN:" s.file

pourrait écrire en sortie standard :

User Names for s.file are:
xyz
131
abc
2.
L'exemple suivant :
prs -d "Delta for pgm :M:: :I: - :D: By :P:" -r s.file

pourrait écrire en sortie standard :

Delta for pgm main.c: 3.7 - 77/12/01 By cas
3.
Comme cas spécial :
prs s.file

pourrait écrire en sortie standard :

s.file:
<ligne vide>
D 1.1 77/12/01 00:00:00 cas 1 000000/00000/00000
MRs:
bl78-12345
bl79-54321
COMMENTS:
this is the comment line for s.file initial delta
<ligne vide>

pour chaque entrée de table de delta de type D. La seule option autorisée avec ce cas spécial est l'option -a.
