NOM

/vcard

DESCRIPTION

Lire votre vCard ou la vCard d'un utilisateur, obtenir l'avatar d'un utilisateur via sa vCard, ou modifier votre vCard. Si aucun argument n'est fourni, votre vCard s'affichera dans une nouvelle fenêtre, ou dans une fenêtre de vCard existante.

SYNTAXE

/vcard get [<surnom|contact>]

/vcard photo open <surnom|contact> [<index>]

/vcard photo save <surnom|contact> [output <chemin_fichier>] [index <index>]

/vcard set nom_complet <nom_complet>

/vcard set nom famille <famille>

/vcard set nom prenom <prenom>

/vcard set nom second_prenom <second_prenom>

/vcard set nom prefixe <prefixe>

/vcard set nom suffixe <suffixe>

/vcard set <index> [<valeur>]

/vcard set <index> boite_postale <valeur>

/vcard set <index> adresse_etendue <valeur>

/vcard set <index> rue <valeur>

/vcard set <index> localite <valeur>

/vcard set <index> region <valeur>

/vcard set <index> code_postal <valeur>

/vcard set <index> pays <valeur>

/vcard set <index> type domestique|international

/vcard set <index> domicile on|off

/vcard set <index> travail on|off

/vcard set <index> voix on|off

/vcard set <index> fax on|off

/vcard set <index> bipeur on|off

/vcard set <index> msg on|off

/vcard set <index> portable on|off

/vcard set <index> video on|off

/vcard set <index> bbs on|off

/vcard set <index> modem on|off

/vcard set <index> isdn on|off

/vcard set <index> pcs on|off

/vcard set <index> prefere on|off

/vcard set <index> colis on|off

/vcard set <index> postal on|off

/vcard set <index> internet on|off

/vcard set <index> x400 on|off

/vcard add surnom <surnom>

/vcard add anniversaire <date>

/vcard add adresse

/vcard add tel <numero>

/vcard add email <id_utilisateur>

/vcard add jid <jid>

/vcard add titre <titre>

/vcard add role <role>

/vcard add note <note>

/vcard add url <url>

/vcard remove <index>

/vcard refresh

/vcard save

ARGUMENTS

get [<surnom|contact>]

Obtenez votre vCard, si un surnom/contact est fourni, obtenez la vCard de cet utilisateur.

photo open <surnom|contact> [<index>]

Téléchargez la photo d'un utilisateur depuis sa vCard dans un fichier, et ouvrez-la. Si l'index n'est pas spécifié, téléchargez la première photo (généralement l'avatar) de sa vCard.

photo save <surnom|contact>

Téléchargez la photo d'un utilisateur depuis sa vCard dans un fichier. Si l'index n'est pas spécifié, téléchargez la première photo (généralement l'avatar) de sa vCard. Si la sortie n'est pas spécifiée, téléchargez la photo dans le répertoire des photos de profanity.

photo open-self [<index>]

Téléchargez une photo de votre vCard dans un fichier, et ouvrez-la. Si l'index n'est pas spécifié, téléchargez la première photo (généralement l'avatar) de votre vCard.

photo save-self

Téléchargez une photo de votre vCard dans un fichier. Si l'index n'est pas spécifié, téléchargez la première photo (généralement l'avatar) de votre vCard. Si la sortie n'est pas spécifiée, téléchargez la photo dans le répertoire des photos de profanity. Mêmes arguments que `photo open`.

set nom_complet <nom_complet>

Définissez le nom complet de votre vCard à la valeur spécifiée.

set nom famille <famille>

Définissez le nom de famille de votre vCard à la valeur spécifiée.

set nom prenom <prenom>

Définissez le prénom de votre vCard à la valeur spécifiée.

set nom second_prenom <second_prenom>

Définissez le second prénom de votre vCard à la valeur spécifiée.

set nom prefixe <prefixe>

Définissez le préfixe du nom de votre vCard à la valeur spécifiée.

set nom suffixe <suffixe>

Définissez le suffixe du nom de votre vCard à la valeur spécifiée.

set <index> [<valeur>]

Définissez le champ principal d'un élément de votre vCard à la valeur spécifiée, ou si aucune valeur n'a été spécifiée, modifiez le champ dans un éditeur. Cela ne fonctionne que pour les éléments ayant un seul champ.

set <index> boite_postale <valeur>

Définissez la boîte postale dans un élément d'adresse de votre vCard à la valeur spécifiée.

set <index> adresse_etendue <valeur>

Définissez l'adresse étendue dans un élément d'adresse de votre vCard à la valeur spécifiée.

set <index> rue <valeur>

Définissez la rue dans un élément d'adresse de votre vCard à la valeur spécifiée.

set <index> localite <valeur>

Définissez la localité dans un élément d'adresse de votre vCard à la valeur spécifiée.

set <index> region <valeur>

Définissez la région dans un élément d'adresse de votre vCard à la valeur spécifiée.

set <index> code_postal <valeur>

Définissez le code postal dans un élément d'adresse de votre vCard à la valeur spécifiée.

set <index> type domestique|international

Définissez le type dans un élément d'adresse de votre vCard comme domestique ou international.

set <index> domicile on|off

Définissez l'option domicile dans un élément de votre vCard. (adresse, téléphone, e-mail uniquement)

set <index> travail on|off

Définissez l'option travail dans un élément de votre vCard. (adresse, téléphone, e-mail uniquement)

set <index> voix on|off

Définissez l'option voix dans un élément téléphonique de votre vCard.

set <index> fax on|off

Définissez l'option fax dans un élément téléphonique de votre vCard.

set <index> bipeur on|off

Définissez l'option bipeur dans un élément téléphonique de votre vCard.

set <index> msg on|off

Définissez l'option message dans un élément téléphonique de votre vCard.

set <index> portable on|off

Définissez l'option téléphone portable dans un élément téléphonique de votre vCard.

set <index> video on|off

Définissez l'option vidéo dans un élément téléphonique de votre vCard.

set <index> bbs on|off

Définissez l'option BBS dans un élément téléphonique de votre vCard.

set <index> modem on|off

Définissez l'option modem dans un élément téléphonique de votre vCard.

set <index> isdn on|off

Définissez l'option ISDN dans un élément téléphonique de votre vCard.

set <index> pcs on|off

Définissez l'option PCS dans un élément téléphonique de votre vCard.

set <index> prefere on|off

Définissez l'option préféré dans un élément de votre vCard. (adresse, téléphone, e-mail uniquement)

set <index> colis on|off

Définissez l'option colis dans un élément d'adresse de votre vCard.

set <index> postal on|off

Définissez l'option postal dans un élément d'adresse de votre vCard.

set <index> internet on|off

Définissez l'option internet dans une adresse e-mail de votre vCard.

Définissez l'option X400 dans une adresse e-mail de votre vCard.

Ajouter un surnom à votre vCard.

NAME

profanity-vcard

manipulate your vCard

DESCRIPTION

This command allows you to manipulate your vCard information which will be advertised by your profanity client.

SYNOPSIS

profanity-vcard

ARGUMENTS

add phone <number>

Ajouter un numéro de téléphone à votre vCard

add email <userid>

Ajouter une adresse e-mail à votre vCard

add jid <jid>

Ajouter un Jabber ID à votre vCard

add title <title>

Ajouter un titre à votre vCard

add role <role>

Ajouter un rôle à votre vCard

add note <note>

Ajouter une note à votre vCard

add url <url>

Ajouter une URL à votre vCard

remove <index>

Supprimer un élément de votre vCard par son index

refresh

Rafraîchit la copie locale de la vCard du compte courant (annule toutes vos modifications non publiées)

save

Enregistre les modifications sur le serveur
