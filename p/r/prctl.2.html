prctl(2) Manuel des appels système prctl(2)

NOM

prctl - opérations sur un processus ou un thread

BIBLIOTHÉQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <linux/prctl.h>  /* Définition des constantes PR_* */
#include <sys/prctl.h>
int prctl(int op, ...);

DESCRIPTION

prctl() manipule divers aspects du comportement du thread ou du processus appelant.

prctl() est appelé avec un premier argument décrivant l'action à effectuer, et des arguments supplémentaires dont la signification dépend du premier. Le premier argument peut être :

VALEUR DE RETOUR

En cas de succès, une valeur non négative est retournée. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

EINVAL
La valeur de op n'est pas reconnue ou n'est pas prise en charge sur ce système.
EINVAL
Un argument inutilisé est non nul.

HISTORIQUE

Linux 2.1.57, glibc 2.0.6

AVERTISSEMENTS

Le prototype de l'enveloppe libc utilise une liste d'arguments variadique. Cela rend nécessaire de passer les arguments avec la bonne largeur. Lors du passage de constantes numériques, telles que 0, utilisez un suffixe : 0L.

Une utilisation imprudente de certaines opérations prctl() peut confondre l'environnement d'exécution de l'espace utilisateur, ces opérations doivent donc être utilisées avec précaution.
