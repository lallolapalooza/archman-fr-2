NOM

projsync - Outil de téléchargement de fichiers de ressources

SYNTAXE

projsync
[--endpoint URL]
[--local-geojson-file NOM_FICHIER]
([--user-writable-directory] | [--system-directory] | [--target-dir REPERTOIRE])
[--bbox longitude_ouest,latitude_sud,longitude_est,latitude_nord]
[--spatial-test contains|intersects]
[--source-id ID] [--area-of-use NOM]
[--file NOM]
[--all] [--exclude-world-coverage]
[--quiet | --verbose] [--dry-run] [--list-files]
[--no-version-filtering]

DESCRIPTION

projsync est un programme qui télécharge des fichiers de ressources distants dans un répertoire local. C'est une alternative au téléchargement d'une archive proj-data-X.Y.Z, ou à l'utilisation des capacités réseau de PROJ en mode "à la demande".

Les paramètres de contrôle suivants peuvent apparaître dans n'importe quel ordre :

--endpoint URL
Définit l'URL où télécharger le fichier maître files.geojson puis les fichiers de ressources. La valeur par défaut est celle définie dans proj.ini.
--local-geojson-file NOM_FICHIER
Définit le nom du fichier maître GeoJSON qui référence les ressources. La valeur par défaut est ${endpoint}/files.geojson.
--user-writable-directory
Spécifie que les fichiers de ressources doivent être téléchargés dans le répertoire accessible en écriture par l'utilisateur. C'est le comportement par défaut.
--system-directory
Spécifie que les fichiers de ressources doivent être téléchargés dans le répertoire ${installation_prefix}/share/proj. L'utilisateur lançant projsync doit s'assurer qu'il dispose des droits d'écriture dans ce répertoire.
--target-dir REPERTOIRE
Répertoire dans lequel les fichiers de ressources doivent être téléchargés.
--bbox longitude_ouest,latitude_sud,longitude_est,latitude_nord
Spécifie une zone d'intérêt pour restreindre les ressources à télécharger. La zone d'intérêt est spécifiée comme une boîte englobante avec des coordonnées géographiques, exprimées en degrés dans un CRS géographique non spécifié. longitude_ouest et longitude_est doivent être dans la plage [-180,180], et latitude_sud et latitude_nord dans la plage [-90,90]. longitude_ouest est généralement inférieure à longitude_est, sauf dans le cas où la zone d'intérêt traverse l'antiméridien.
--spatial-test contains|intersects
Spécifie comment l'étendue des fichiers de ressources est comparée à la zone d'utilisation spécifiée explicitement avec --bbox. Par défaut, tous les fichiers de ressources dont l'étendue intersecte la valeur spécifiée par --bbox seront sélectionnés. Si la stratégie contains est utilisée, seuls les fichiers de ressources dont l'étendue est contenue dans la valeur spécifiée par --bbox seront sélectionnés.
--source-id ID
Restreint les fichiers de ressources à télécharger à ceux dont la propriété source_id contient la valeur ID. Spécifier ? comme ID listera toutes les valeurs possibles.
--area-of-use NOM
Restreint les fichiers de ressources à télécharger à ceux dont la propriété area_of_use contient la valeur NOM. Spécifier ? comme NOM listera toutes les valeurs possibles.
--file NOM
Restreint les fichiers de ressources à télécharger à ceux dont la propriété name contient la valeur NOM. Spécifier ? comme NOM listera toutes les valeurs possibles.
--all
Demande le téléchargement de tous les fichiers.
--exclude-world-coverage
Exclut les fichiers qui ont une couverture mondiale.
-q / --quiet
Mode silencieux
--verbose
Ajouté dans la version 8.1.

Mode verbeux (plus que par défaut)

--dry-run
Simule le comportement de l'outil sans télécharger les fichiers de ressources.
--list-files
Liste les noms de fichiers, avec les propriétés source_id et area_of_use.
--no-version-filtering
Ajouté dans la version 8.1.

Par défaut, projsync ne télécharge que les fichiers compatibles avec les métadonnées PROJ_DATA.VERSION de proj.db, en tenant compte des propriétés version_added et version_removed des entrées dans files.geojson. En spécifiant ce commutateur, tous les fichiers référencés dans files.geojson seront candidats (combinés avec d'autres filtres).

Au moins une des options --list-files, --file, --source-id, --area-of-use, --bbox ou --all doit être spécifiée.

Les options --file, --source-id, --area-of-use et --bbox sont combinées avec une logique ET.

EXEMPLES

1.
Télécharger tous les fichiers de ressources
projsync --all
2.
Télécharger les fichiers de ressources couvrant un point spécifié et attribués à une agence
projsync --source-id fr_ign --bbox 2,49,2,49

Synopsis:
projsync [OPTIONS] SRC DST
Description:

The projsync command synchronizes files between two directories. It can be used to copy files from a source directory to a destination directory, or to mirror a directory.

Options:
--delete
Delete files in DST that do not exist in SRC.
-h, --help
Show help message and exit.
-v, --verbose
Increase verbosity.
Examples:

Copy files from SRC to DST: 

projsync SRC DST

Mirror SRC to DST: 

projsync --delete SRC DST
See also:
rsync(1)
