profil(3) Manuel des fonctions de bibliothèque profil(3)

NOM

profil - profilage du temps d'exécution

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <unistd.h>
int profil(unsigned short *buf, size_t bufsiz,
           size_t offset, unsigned int scale);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

profil():

    Depuis glibc 2.21 :
        _DEFAULT_SOURCE
    Dans glibc 2.19 et 2.1.20 :
        _DEFAULT_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)
    Jusqu'à et y compris glibc 2.19 :
        _BSD_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)

DESCRIPTION

Cette routine fournit un moyen de savoir dans quels domaines votre programme passe le plus de temps. L'argument buf pointe vers bufsiz octets de mémoire. Toutes les 10 millisecondes virtuelles, le compteur de programme (PC) de l'utilisateur est examiné : offset est soustrait et le résultat est multiplié par scale et divisé par 65536. Si la valeur résultante est inférieure à bufsiz, alors l'entrée correspondante dans buf est incrémentée. Si buf est NULL, le profilage est désactivé.

VALEUR DE RETOUR

Zéro est toujours retourné.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
profil () Sécurité des threads MT-Unsafe

NORMES

Aucune.

HISTORIQUE

Similaire à un appel dans SVr4.

BOGUES

profil() ne peut pas être utilisé sur un programme qui utilise également des timers d'intervalle ITIMER_PROF (voir setitimer(2)).

Le profilage réel du noyau fournit des résultats plus précis.

VOIR AUSSI

gprof(1), sprof(1), setitimer(2), sigaction(2), signal(2)
