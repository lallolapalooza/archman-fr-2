profanity-ox-setup(1)

Paquet: profanity

man(1) Client de chat XMPP Profanity man(1)

NOM

Profanity - un simple client de chat XMPP basé sur console.

DESCRIPTION

Cette page de manuel est destinée à vous aider à configurer XEP-0374 : OpenPGP pour la messagerie instantanée XMPP. Également connu sous le nom de OX.

Pour plus de détails sur l'utilisation, consultez man profanity-ox ou /help ox.

Profanity souhaite donner à l'utilisateur une liberté maximale dans la configuration de son système. Nous n'allons donc pas toucher directement à vos paramètres GPG. Cela signifie que vous devrez effectuer quelques étapes manuelles. Elles sont décrites ici.

Générer les matériaux de clé OpenPGP

La première étape consiste à créer une paire de clés OpenPGP. La génération de la paire de clés se fera avec la commande gpg de GnuPG.

gpg --quick-generate-key xmpp:alice@domain.tld future-default default 3y

Cette commande générera une clé OpenPGP avec un UID xmpp:alice@domain.tld. L'option future-default a été utilisée pour générer une clé ed25519/cv25519. La clé expire dans trois ans.

Remplacez l'ID Jabber par votre JID et n'oubliez pas le préfixe d'URI xmpp:.

Exemple de sortie :

pub   ed25519 2021-09-21 [SC] [verfällt: 2024-09-20]
      583BAE703A801095B6B71A56BD801174B1A0B84A
uid                      xmpp:alice@domain.tld
sub   cv25519 2021-09-21 [E]

Exporter votre clé publique

Vous devez exporter votre clé publique afin de pouvoir la télécharger ultérieurement dans un nœud PEP. C'est simplement une façon pour vos interlocuteurs de récupérer votre clé publique. Utilisez la commande ci-dessous pour exporter la clé publique :

Exemple de commande :

gpg --export \
  --export-options export-minimal \
  --export-filter 'keep-uid=uid =~ xmpp:alice@domain.tld' \
  --export-filter 'drop-subkey=usage =~ a' \
  583BAE703A801095B6B71A56BD801174B1A0B84A \
  > /tmp/pep-key.gpg

La clé sera exportée dans /tmp/pep-key.gpg. Vous pouvez vérifier la clé avec la commande ci-dessous :

gpg --show-key --with-sig-list /tmp/pep-key.gpg

Gardez à l'esprit : les clés publiques peuvent contenir certaines informations (signatures, nom, adresse e-mail). Faites attention aux données qui seront exportées. Les options export-options et export-filter de GnuPG vous aideront à filtrer les données.

Publier votre clé

Vous pouvez utiliser profanity pour publier votre clé exportée sur votre compte (PEP). La commande /ox announce publiera votre clé.

/ox announce /tmp/pep-key.gpg

La commande créera deux enregistrements de nœud PEP pour stocker la clé.

Découvrir des clés

Pour découvrir les clés publiques de vos correspondants, utilisez la commande /ox discover.

Exemple de sortie :

/ox discover buddy@domain.tld
Discovering Public Key for buddy@domain.tld 
1234567890ABCDEF1234567890ABCDEF12345678

Pour demander et importer une clé, vous pouvez utiliser la commande /ox request.

/ox request buddy@domain.tld 1234567890ABCDEF1234567890ABCDEF12345678
Requesting Public Key 1234567890ABCDEF1234567890ABCDEF12345678 for buddy@domain.tld
Public Key imported

La clé sera importée dans votre trousseau gnupg.

Signer la clé importée

La clé peut être affichée via gpg gpg -k xmpp:buddy@domain.tld. Assurez-vous que la clé est bien celle de votre correspondant et signez la clé avec votre clé.

gpg --ask-cert-level --default-key 583BAE703A801095B6B71A56BD801174B1A0B84A --sign-key 1234567890ABCDEF1234567890ABCDEF12345678

La commande /ox contacts affichera les clés avec leur UID XMPP. La commande /ox keys affichera toutes les clés OpenPGP connues.

Ce n'est qu'une fois que vous aurez signé la clé que vous pourrez réellement utiliser OX avec votre correspondant.

Utiliser OX

Dans une fenêtre de chat, vous pouvez démarrer OX avec /ox start et l'arrêter avec /ox end.

Les messages seront envoyés signés et chiffrés.
