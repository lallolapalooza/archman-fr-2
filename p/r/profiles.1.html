PROFILES(1) Commandes utilisateur PROFILES(1)

NOM

profiles - Un utilitaire pour rapporter et changer les SIDs dans les fichiers de registre

SYNTAXE

profiles [-c|--change-sid=CHAÎNE] [-n|--new-sid=CHAÎNE] [-v|--verbose] [-?|--help] [--usage] [-d|--debuglevel=NIVEAU_DEBOGAGE] [--debug-stdout] [--configfile=FICHIER_CONFIG] [--option=nom=valeur] [-l|--log-basename=FICHIER_JOURNAL] [--leak-report] [--leak-report-full] {FICHIER}

DESCRIPTION

Cet outil fait partie de la suite samba(7).

profiles est un utilitaire qui rapporte et change les SIDs dans les fichiers de registre Windows. Il ne supporte actuellement que NT.

OPTIONS

fichier

Fichier de registre à consulter ou à modifier.

-v,--verbose

Augmente la verbosité des messages.

-c SID1 -n SID2, --change-sid SID1 --new-sid SID2

Change toutes les occurrences de SID1 dans le fichier par SID2.

-d|--debuglevel=niveau

niveau est un entier de 0 à 10. La valeur par défaut si ce paramètre n'est pas spécifié est 1 pour les applications client.

Plus cette valeur est élevée, plus les détails seront enregistrés dans les fichiers journaux sur les activités du serveur. Au niveau 0, seuls les erreurs critiques et les avertissements sérieux seront enregistrés. Le niveau 1 est un niveau raisonnable pour une utilisation quotidienne : il génère une petite quantité d'informations sur les opérations effectuées.

Les niveaux supérieurs à 1 généreront une quantité considérable de données de journalisation et ne devraient être utilisés que lors de l'investigation d'un problème. Les niveaux supérieurs à 3 sont conçus pour être utilisés uniquement par les développeurs et génèrent d'énormes quantités de données de journalisation, dont la plupart sont extrêmement cryptiques.

Notez que la spécification de ce paramètre ici remplacera le paramètre log level du fichier /etc/samba/smb.conf.

--debug-stdout

Redirigera la sortie de débogage vers STDOUT. Par défaut, tous les clients enregistrent sur STDERR.

--configfile=<fichier de configuration>

Le fichier spécifié contient les détails de configuration requis par le client. Les informations de ce fichier peuvent être générales pour le client et le serveur ou fournir uniquement des options spécifiques au client telles que client smb encrypt. Voir /etc/samba/smb.conf pour plus d'informations. Le nom du fichier de configuration par défaut est déterminé lors de la compilation.

--option=<nom>=<valeur>

Définit l'option smb.conf(5) "<nom>" à la valeur "<valeur>" depuis la ligne de commande. Cela remplace les valeurs par défaut compilées et les options lues dans le fichier de configuration. Si un nom ou une valeur contient un espace, entourez tout --option=nom=valeur de guillemets.

-l|--log-basename=répertoire_journal

Nom du répertoire de base pour les fichiers de journalisation/débogage. L'extension ".nom_programme" sera ajoutée (par exemple, log.smbclient, log.smbd, etc...). Le fichier journal n'est jamais supprimé par le client.

--leak-report

Active le rapport de fuite talloc à la sortie.

--leak-report-full

Active le rapport complet de fuite talloc à la sortie.

-V|--version

Affiche le numéro de version du programme.

-?|--help

Affiche un résumé des options de la ligne de commande.

--usage

Affiche un bref message d'utilisation.
