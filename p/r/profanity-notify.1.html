profanity-notify(1)

Paquet: profanity

Licences: GPL3

man(1) Client XMPP Profanity man(1)

NOM

/notify

DESCRIPTION

Configurer les notifications de bureau. Pour configurer les messages de mise à jour de présence dans la console, les fenêtres de chat et de salon de discussion, voir '/help presence'.

SYNTAXE

/notify chat on|off

/notify chat current on|off

/notify chat text on|off

/notify room on|off

/notify room mention on|off

/notify room mention case_sensitive|case_insensitive

/notify room mention word_whole|word_part

/notify room offline on|off

/notify room current on|off

/notify room text on|off

/notify room trigger add <texte>

/notify room trigger remove <texte>

/notify room trigger list

/notify room trigger on|off

/notify on|off

/notify mention on|off

/notify trigger on|off

/notify reset

/notify remind <secondes>

/notify typing on|off

/notify typing current on|off

/notify invite on|off

/notify sub on|off

ARGUMENTS

chat on|off

Notifications pour les messages de chat réguliers.

chat current on|off

Afficher ou non les notifications de messages de chat réguliers lorsque la fenêtre est focalisée.

chat text on|off

Afficher le texte du message dans les notifications de messages réguliers.

room on|off

Notifications pour tous les messages des salons de discussion.

room mention on|off

Notifications pour les messages de salon de discussion lorsque votre pseudo est mentionné.

room mention case_sensitive

Définir les notifications de mention de salon comme sensibles à la casse.

room mention case_insensitive

Définir les notifications de mention de salon comme insensibles à la casse.

room mention word_whole

Définir les notifications de mention de salon uniquement sur une correspondance de mot entier, c'est-à-dire lorsque le pseudo ne fait pas partie d'un mot plus grand.

room mention word_part

Définir les notifications de mention de salon sur une correspondance de mot partiel, c'est-à-dire que le pseudo peut faire partie d'un mot plus grand.

room offline on|off

Notifications pour les messages de salon de discussion envoyés pendant que vous étiez hors ligne.

room current on|off

Afficher ou non les notifications de tous les messages de salon de discussion lorsque la fenêtre est focalisée.

room text on|off

Afficher le texte du message dans les notifications de messages de salon de discussion.

room trigger add <texte>

Notifier lorsque le texte spécifié est inclus dans tous les messages de salon de discussion.

room trigger remove <texte>

Supprimer un déclencheur de notification de salon de discussion.

room trigger list

Lister tous les déclencheurs de surlignage des salons de discussion.

room trigger on|off

Activer ou désactiver tous les déclencheurs de notification des salons de discussion.

on|off

Remplacer le paramètre global de message pour le salon de discussion actuel.

mention on|off

Remplacer le paramètre global de 'mention' pour le salon de discussion actuel.

trigger on|off

Remplacer le paramètre global de 'trigger' pour le salon de discussion actuel.

reset

Réinitialiser les paramètres de notification globaux pour le salon de discussion actuel.

remind <secondes>

Période de rappel de notification pour les messages non lus, utiliser 0 pour désactiver.

typing on|off

Notifications lorsque les contacts sont en train d'écrire.

typing current on|off

Si les notifications d'écriture sont déclenchées pour la fenêtre actuelle.

invite on|off

Notifications pour les invitations de salons de discussion.

sub on|off

Notifications pour les demandes d'abonnement.

EXEMPLES

/notify chat on

/notify chat text on

/notify room mention on

/notify room offline on

/notify room trigger add beer

/notify room trigger on

/notify room current off

/notify room text off

/notify remind 60

/notify typing on

/notify invite on
