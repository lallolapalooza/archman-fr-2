prune(1) Manuel des commandes générales prune(1)

NOM

prune - Émonder des graphes orientés

SYNTAXE

prune [ -n nœud ] [ -N spécifieur_attribut ] [ -v ] [ -(h|?) ] [ fichiers ... ]

DESCRIPTION

prune lit des graphes orientés dans le même format que celui utilisé par dot(1) et supprime les sous-graphes racinés aux nœuds spécifiés sur la ligne de commande via des options. Ces nœuds eux-mêmes ne seront pas supprimés, mais peuvent recevoir des attributs afin qu'ils puissent être facilement localisés par un éditeur de flux de graphes tel que gvpr(1). prune gère correctement les cycles, les boucles et les multi-arêtes.

Les deux options peuvent apparaître plusieurs fois sur la ligne de commande. Tous les sous-graphes enracinés aux nœuds respectifs donnés seront alors traités. Si un nœud n'existe pas, prune l'ignorera et affichera un message d'avertissement sur stderr. Si plusieurs attributs sont donnés, ils seront appliqués à tous les nœuds qui ont été traités. prune écrit le résultat sur stdout.

OPTIONS

-n nom
Spécifie le nom du nœud à émonder.
-N spécifieur_attribut
Spécifie l'attribut qui sera défini (ou modifié s'il existe) pour tout nœud émondé. spécifieur_attribut est une chaîne de la forme attribut=valeur.
-v
Sortie verbeuse.
-h -?
Affiche l'aide et quitte.

EXEMPLES

Un graphe d'entrée test.gv de la forme

digraph DG {
A -> B;
A -> C;

B -> D;
B -> E;
}

, traité par la commande

prune -n B test.gv

produirait la sortie suivante (le code réel pourrait être formaté d'une manière légèrement différente).

digraph DG {
A -> B;
A -> C;
}

Un autre graphe d'entrée test.gv de la forme

digraph DG {
A -> B;
A -> C;

B -> D;
B -> E;

C -> E;
}

(notez l'arête supplémentaire de C à E ), traité par la commande

prune -n B -N color=red test.gv

résulte en

digraph DG {
B [color=red];
A -> B;
A -> C;
C -> E;
}

Le nœud E n'a pas été supprimé car son second parent C n'est pas émondé.

STATUT DE SORTIE

prune renvoie 0 en cas de succès. Il renvoie 1 en cas d'erreur.

VOIR AUSSI
