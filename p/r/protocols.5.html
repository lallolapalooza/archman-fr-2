protocols(5) Manuel des formats de fichiers protocols(5)

NOM

protocols - fichier de définition des protocoles

DESCRIPTION

Ce fichier est un fichier texte ASCII, décrivant les différents protocoles Internet DARPA disponibles dans le sous-système TCP/IP. Il doit être consulté au lieu d'utiliser les numéros dans les fichiers d'inclusion ARPA, ou, pire encore, de les deviner. Ces numéros apparaîtront dans le champ protocole de tout en-tête IP.

Laissez ce fichier intact car les modifications entraîneraient des paquets IP incorrects. Les numéros et noms de protocoles sont spécifiés par l'IANA (Internet Assigned Numbers Authority).

Chaque ligne est du format suivant :

numéro de protocole alias ...

où les champs sont délimités par des espaces ou des tabulations. Les lignes vides sont ignorées. Si une ligne contient un dièse (#), le dièse et la partie de la ligne qui suit sont ignorés.

Les descriptions des champs sont :

protocole
le nom natif du protocole. Par exemple ip, tcp, ou udp.
numéro
le numéro officiel de ce protocole tel qu'il apparaîtra dans l'en-tête IP.
alias
des alias optionnels pour le protocole.

Ce fichier peut être distribué sur un réseau en utilisant un service de nommage réseau tel que Yellow Pages/NIS ou BIND/Hesiod.

FICHIERS

/etc/protocols
Le fichier de définition des protocoles.

VOIR AUSSI

getprotoent(3)

http://www.iana.org/assignments/protocol-numbers
