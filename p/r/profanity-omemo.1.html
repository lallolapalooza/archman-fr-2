NOM

/omemo

DESCRIPTION

Commandes OMEMO pour gérer les clés et effectuer le chiffrement pendant les sessions de chat.

SYNTAXE

/omemo gen

/omemo log on|off|redact

/omemo start [<contact>]

/omemo trust [<contact>] <empreinte_digitale>

/omemo end

/omemo fingerprint [<contact>]

/omemo char <caractere>

/omemo trustmode manual|firstusage|blind

/omemo policy manual|automatic|always

/omemo clear_device_list

/omemo qrcode

ARGUMENTS

gen

Génère le matériel cryptographique OMEMO pour le compte actuel.

start [<contact>]

Démarre une session OMEMO avec le contact, ou le destinataire actuel si omis.

end

Termine la session OMEMO actuelle.

log on|off

Active ou désactive la journalisation en texte clair des messages chiffrés OMEMO.

log redact

Journalise les messages chiffrés OMEMO, mais remplace le contenu par [redacted].

fingerprint [<contact>]

Affiche les empreintes digitales du contact, ou celles du destinataire actuel si omises.

char <caractere>

Définit le caractère à afficher à côté des messages chiffrés OMEMO.

trustmode manual

Définit le mode de confiance global OMEMO sur manuel, les clés OMEMO doivent être explicitement approuvées.

trustmode firstusage

Définit le mode de confiance global OMEMO sur ToFu (Trust On First Usage), les premières clés OMEMO sont approuvées automatiquement.

trustmode blind

Définit le mode de confiance global OMEMO sur aveugle, TOUTES les clés OMEMO sont approuvées automatiquement.

policy manual

Définit la politique globale OMEMO sur manuelle, les sessions OMEMO doivent être démarrées manuellement.

policy automatic

Définit la politique globale OMEMO sur opportuniste, une session OMEMO sera tentée au démarrage d'une conversation.

policy always

Définit la politique globale OMEMO sur toujours, une erreur sera affichée si une session OMEMO ne peut être initiée au démarrage d'une conversation.

clear_device_list

Efface votre propre liste d'appareils sur le serveur. Chaque client se ré-annoncera lors de sa reconnexion.

qrcode

Affiche le code QR de votre empreinte digitale OMEMO.

EXEMPLES

/omemo gen

/omemo start odin@valhalla.edda

/omemo trust c4f9c875-144d7a3b-0c4a05b6-ca3be51a-a037f329-0bd3ae62-07f99719-55559d2a

/omemo untrust loki@valhalla.edda c4f9c875-144d7a3b-0c4a05b6-ca3be51a-a037f329-0bd3ae62-07f99719-55559d2a

/omemo char *
