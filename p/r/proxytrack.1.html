proxytrack(1) Manuel des commandes générales proxytrack(1)

NOM

proxytrack - proxy pour servir du contenu archivé par httrack website copier

SYNTAXE

proxytrack adresse_proxy:port_proxy icp_adresse:icp_port [ nom_fichier_cache_httrack_1 [ nom_fichier_cache_httrack_2 .. ] ]

DESCRIPTION

proxytrack ce programme vous permet de créer un proxy pour distribuer du contenu déjà archivé par httrack(1) , un copieur de site web.

EXEMPLES

proxytrack proxy:8080 localhost:3130 /home/archives/example.com/hts-cache/new.zip

lancera le proxytrack proxy, écoutant sur :8080, pour distribuer le contenu archivé dans le cache /home/archives/example.com/hts-cache/new.zip
