PRINTF_GETTEXT(1) Commandes utilisateur PRINTF_GETTEXT(1)

NOM

printf_gettext - traduit une chaîne de format et l'applique

SYNTAXE

printf_gettext [OPTION] FORMAT [ARGUMENT]...

DESCRIPTION

Le programme printf_gettext traduit une chaîne de format dans la langue de l'utilisateur, en recherchant la traduction dans un catalogue de messages, et applique la chaîne de format traduite aux arguments spécifiés.

Produit une sortie formatée, en appliquant la traduction dans la langue native de FORMAT aux ARGUMENTs.

Options et arguments :

-c, --context=CONTEXT
spécifie le contexte pour FORMAT
FORMAT
chaîne de format
ARGUMENT
chaîne ou argument numérique

Sortie informative :

-h, --help
affiche cette aide et quitte
-V, --version
affiche les informations de version et quitte

La chaîne de format se compose de

- texte brut, - directives, qui commencent par '%', - séquences d'échappement, qui commencent par une barre oblique inverse.

Une directive qui consomme un argument

- commence par '%' ou '%m$' où m est un entier positif, - est facultativement suivie par l'un des caractères '#', '0', '-', ' ', '+',
chacun agissant comme un indicateur,
- est facultativement suivie par une spécification de largeur (un entier non négatif), - est facultativement suivie par '.' et une spécification de précision (un entier non négatif facultatif),
- se termine par un spécificateur
- 'c', qui affiche un caractère, - 's', qui affiche une chaîne, - 'i', 'd', qui affichent un entier, - 'u', 'o', 'x', 'X', qui affichent un entier non signé (positif), - 'e', 'E', qui affichent un nombre à virgule flottante en notation scientifique, - 'f', 'F', qui affichent un nombre à virgule flottante sans exposant, - 'g', 'G', qui affichent un nombre à virgule flottante en notation générale, - 'a', 'A', qui affichent un nombre à virgule flottante en notation hexadécimale.

De plus, il y a la directive '%%', qui affiche un seul '%'.

Si une directive spécifie l'argument par son numéro (notation '%m$'), toutes les directives qui consomment un argument doivent le faire.

Les séquences d'échappement sont :

\\
barre oblique inverse
\a
sonnerie (BEL)
\b
retour arrière (BS)
\f
saut de page (FF)
\n
nouvelle ligne (LF)
\r
retour chariot (CR)
\t
tabulation horizontale (HT)
\v
tabulation verticale (VT)
\nnn
nombre octal avec 1 à 3 chiffres octaux

Variables d'environnement :

La traduction de la chaîne de format est recherchée dans le domaine de traduction donné par la variable d'environnement TEXTDOMAIN. Elle est recherchée dans le répertoire des catalogues donné par la variable d'environnement TEXTDOMAINDIR ou, si elle n'est pas présente, dans le répertoire par défaut des catalogues. Ce binaire est configuré pour utiliser le répertoire par défaut des catalogues : /usr/share/locale
