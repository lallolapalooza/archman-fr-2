proc_pid_pagemap(5) Manuel des formats de fichiers proc_pid_pagemap(5)

NOM

/proc/pid/pagemap - mappage des pages virtuelles

DESCRIPTION

/proc/pid/pagemap (depuis Linux 2.6.25)
Ce fichier montre le mappage de chaque page virtuelle du processus vers des cadres de page physiques ou une zone d'échange. Il contient une valeur de 64 bits pour chaque page virtuelle, avec les bits définis comme suit :
63
Si défini, la page est présente dans la RAM.
62
Si défini, la page est dans l'espace d'échange (swap).
61 (depuis Linux 3.5)
La page est une page mappée à un fichier ou une page anonyme partagée.
60–58 (depuis Linux 3.11)
Zéro
57 (depuis Linux 5.14)
Si défini, la page est protégée en écriture via userfaultfd(2).
56 (depuis Linux 4.2)
La page est mappée exclusivement.
55 (depuis Linux 3.11)
Le PTE est « soft-dirty » (voir le fichier source du noyau Documentation/admin-guide/mm/soft-dirty.rst).
54–0
Si la page est présente dans la RAM (bit 63), ces bits fournissent le numéro du cadre de page, qui peut être utilisé pour indexer /proc/kpageflags et /proc/kpagecount. Si la page est présente dans l'espace d'échange (bit 62), alors les bits 4–0 donnent le type d'échange, et les bits 54–5 codent l'offset d'échange.
Avant Linux 3.11, les bits 60–55 étaient utilisés pour coder le logarithme en base 2 de la taille de la page.
Pour utiliser efficacement /proc/pid/pagemap, utilisez /proc/pid/maps pour déterminer quelles zones de mémoire sont effectivement mappées et évitez de parcourir les régions non mappées.
Le fichier /proc/pid/pagemap est présent uniquement si l'option de configuration du noyau CONFIG_PROC_PAGE_MONITOR est activée.
L'autorisation d'accéder à ce fichier est régie par une vérification du mode d'accès ptrace PTRACE_MODE_READ_FSCREDS ; voir ptrace(2).
