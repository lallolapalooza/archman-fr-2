NOM

provider-keyexch - Fonctions de bibliothèque keyexch <-> fournisseur

SYNOPSIS

#include <openssl/core_dispatch.h>
#include <openssl/core_names.h>
/*
 * Aucune de ces fonctions n'est une fonction réelle, mais elles sont affichées
 * comme ceci pour les signatures de fonctions qui sont proposées sous forme
 * de pointeurs de fonction dans les tableaux OSSL_DISPATCH.
 */
/* Gestion du contexte */
void *OSSL_FUNC_keyexch_newctx(void *provctx);
void OSSL_FUNC_keyexch_freectx(void *ctx);
void *OSSL_FUNC_keyexch_dupctx(void *ctx);
/* Dérivation du secret partagé */
int OSSL_FUNC_keyexch_init(void *ctx, void *provkey,
                           const OSSL_PARAM params[]);
int OSSL_FUNC_keyexch_set_peer(void *ctx, void *provkey);
int OSSL_FUNC_keyexch_derive(void *ctx, unsigned char *secret, size_t *secretlen,
                             size_t outlen);
int OSSL_FUNC_keyexch_derive_skey(void *ctx, const char *key_type, void *provctx,
                                  OSSL_FUNC_skeymgmt_import_fn *import,
                                  size_t keylen, const OSSL_PARAM params[]);
/* Paramètres d'échange de clés */
int OSSL_FUNC_keyexch_set_ctx_params(void *ctx, const OSSL_PARAM params[]);
const OSSL_PARAM *OSSL_FUNC_keyexch_settable_ctx_params(void *ctx,
                                                        void *provctx);
int OSSL_FUNC_keyexch_get_ctx_params(void *ctx, OSSL_PARAM params[]);
const OSSL_PARAM *OSSL_FUNC_keyexch_gettable_ctx_params(void *ctx,
                                                        void *provctx);

DESCRIPTION

Cette documentation s'adresse principalement aux auteurs de fournisseurs. Voir provider(7) pour plus d'informations.

L'opération d'échange de clés (OSSL_OP_KEYEXCH) permet aux fournisseurs d'implémenter des algorithmes d'échange de clés et de les rendre disponibles aux applications via EVP_PKEY_derive(3) et d'autres fonctions associées.

Toutes les "fonctions" mentionnées ici sont passées comme pointeurs de fonction entre libcrypto et le fournisseur dans des tableaux OSSL_DISPATCH(3) via des tableaux OSSL_ALGORITHM(3) qui sont retournés par la fonction provider_query_operation() du fournisseur (voir "Fonctions du fournisseur" dans provider-base(7)).

Toutes ces "fonctions" ont une définition de type de fonction correspondante nommée OSSL_FUNC_{name}_fn, et une fonction d'aide pour récupérer le pointeur de fonction à partir d'un élément OSSL_DISPATCH(3) nommé OSSL_FUNC_{name}. Par exemple, la "fonction" OSSL_FUNC_keyexch_newctx() possède ceux-ci :

typedef void *(OSSL_FUNC_keyexch_newctx_fn)(void *provctx);
static ossl_inline OSSL_FUNC_keyexch_newctx_fn
    OSSL_FUNC_keyexch_newctx(const OSSL_DISPATCH *opf);

Les tableaux OSSL_DISPATCH(3) sont indexés par des nombres fournis sous forme de macros dans openssl-core_dispatch.h(7), comme suit :

OSSL_FUNC_keyexch_newctx                OSSL_FUNC_KEYEXCH_NEWCTX
OSSL_FUNC_keyexch_freectx               OSSL_FUNC_KEYEXCH_FREECTX
OSSL_FUNC_keyexch_dupctx                OSSL_FUNC_KEYEXCH_DUPCTX
OSSL_FUNC_keyexch_init                  OSSL_FUNC_KEYEXCH_INIT
OSSL_FUNC_keyexch_set_peer              OSSL_FUNC_KEYEXCH_SET_PEER
OSSL_FUNC_keyexch_derive                OSSL_FUNC_KEYEXCH_DERIVE
OSSL_FUNC_keyexch_derive_skey           OSSL_FUNC_KEYEXCH_DERIVE_SKEY
OSSL_FUNC_keyexch_set_ctx_params        OSSL_FUNC_KEYEXCH_SET_CTX_PARAMS
OSSL_FUNC_keyexch_settable_ctx_params   OSSL_FUNC_KEYEXCH_SETTABLE_CTX_PARAMS
OSSL_FUNC_keyexch_get_ctx_params        OSSL_FUNC_KEYEXCH_GET_CTX_PARAMS
OSSL_FUNC_keyexch_gettable_ctx_params   OSSL_FUNC_KEYEXCH_GETTABLE_CTX_PARAMS

Une implémentation d'algorithme d'échange de clés peut ne pas implémenter toutes ces fonctions. Pour former un ensemble cohérent de fonctions, un fournisseur doit implémenter OSSL_FUNC_keyexch_newctx, OSSL_FUNC_keyexch_freectx, OSSL_FUNC_keyexch_init et au moins une parmi OSSL_FUNC_keyexch_derive et OSSL_FUNC_keyexch_derive_skey. Toutes les autres fonctions sont facultatives.

Un algorithme d'échange de clés doit également implémenter un mécanisme pour générer, charger ou importer des clés via l'opération de gestion des clés (OSSL_OP_KEYMGMT). Voir provider-keymgmt(7) pour plus de détails.

Fonctions de gestion du contexte

OSSL_FUNC_keyexch_newctx() doit créer et retourner un pointeur vers une structure côté fournisseur pour conserver les informations de contexte pendant une opération d'échange de clés. Un pointeur vers ce contexte sera renvoyé dans plusieurs autres appels de fonction d'opération d'échange de clés. Le paramètre provctx est le contexte du fournisseur généré lors de l'initialisation du fournisseur (voir provider(7)).

OSSL_FUNC_keyexch_freectx() reçoit un pointeur vers le contexte d'échange de clés du fournisseur dans le paramètre ctx. Cette fonction doit libérer toutes les ressources associées à ce contexte.

OSSL_FUNC_keyexch_dupctx() doit dupliquer le contexte d'échange de clés du fournisseur dans le paramètre ctx et retourner la copie dupliquée.

Fonctions de dérivation de secret partagé

OSSL_FUNC_keyexch_init() initialise une opération d'échange de clés étant donné un contexte d'échange de clés du fournisseur dans le paramètre ctx, et un pointeur vers un objet clé du fournisseur dans le paramètre provkey. Les params, s'ils ne sont pas NULL, doivent être définis sur le contexte d'une manière similaire à l'utilisation de OSSL_FUNC_keyexch_set_params(). L'objet clé doit avoir été précédemment généré, chargé ou importé dans le fournisseur à l'aide de l'opération de gestion des clés (OSSL_OP_KEYMGMT) (voir provider-keymgmt(7)).

OSSL_FUNC_keyexch_set_peer() est appelé pour fournir la clé publique du pair (dans le paramètre provkey) à utiliser lors de la dérivation du secret partagé. Il reçoit également un contexte d'échange de clés préalablement initialisé dans le paramètre ctx. L'objet clé doit avoir été précédemment généré, chargé ou importé dans le fournisseur à l'aide de l'opération de gestion des clés (OSSL_OP_KEYMGMT) (voir provider-keymgmt(7)>.

OSSL_FUNC_keyexch_derive() effectue l'échange de clés réel en dérivant un secret partagé. Un contexte d'échange de clés préalablement initialisé est passé dans le paramètre ctx. Le secret dérivé doit être écrit à l'emplacement secret, qui ne doit pas dépasser outlen octets. La longueur du secret partagé doit être écrite dans *secretlen. Si secret est NULL, la longueur maximale du secret partagé doit être écrite dans *secretlen.

OSSL_FUNC_keyexch_derive_skey() est similaire à OSSL_FUNC_keyexch_derive() mais utilise un objet opaque pour stocker la clé dérivée. Il accepte le paramètre key_type pour donner une indication au fournisseur quel type de clé (par exemple, générique ou AES) serait généré et la fonction import de l'objet EVP_SKEYMGMT à associer à la clé. L'objet EVP_SKEYMGMT provient du même fournisseur que le KDF lui-même.

Fonctions paramètres échange clé

OSSL_FUNC_keyexch_set_ctx_params() définit les paramètres d'échange de clés associés au contexte d'échange de clés du fournisseur donné ctx à params, voir "Paramètres communs d'échange de clés". Tous les paramètres définis sont supplémentaires à ceux qui ont été précédemment définis. Passer NULL pour params doit retourner vrai.

OSSL_FUNC_keyexch_get_ctx_params() récupère les paramètres d'échange de clés associés au contexte d'échange de clés du fournisseur donné ctx dans params, voir "Paramètres communs d'échange de clés". Passer NULL pour params doit retourner vrai.

OSSL_FUNC_keyexch_settable_ctx_params() produit un tableau constant OSSL_PARAM(3) qui décrit les paramètres modifiables, c'est-à-dire les paramètres qui peuvent être utilisés avec OP_signature_set_ctx_params(). Si OSSL_FUNC_keyexch_settable_ctx_params() est présent, OSSL_FUNC_keyexch_set_ctx_params() doit également être présent, et inversement. De même, OSSL_FUNC_keyexch_gettable_ctx_params() produit un tableau constant OSSL_PARAM(3) qui décrit les paramètres récupérables, c'est-à-dire les paramètres qui peuvent être gérés par OP_signature_get_ctx_params(). NOM

provider-keyexch - Interface du fournisseur pour l'échange de clés

SYNOPSIS

#include <openssl/core_dispatch.h>

typedef enum OSSL_NELEM_keyexch {
    OSSL_NELEM_keyexch_SIZE = 8
} OSSL_NELEM_keyexch;

/* Fonctions */
const OSSL_DISPATCH *OSSL_FUNC_keyexch_newctx(OPENSSL_CTX *ctx);
void OSSL_FUNC_keyexch_freectx(OSSL_PROVIDER_CTX *provctx);
void OSSL_FUNC_keyexch_teardown(OPENSSL_PROVIDER_CTX *provctx);
const OSSL_PARAM *OSSL_FUNC_keyexch_gettable_params(OPENSSL_PROVIDER_CTX *provctx);
const OSSL_PARAM *OSSL_FUNC_keyexch_settable_params(OPENSSL_PROVIDER_CTX *provctx);
const OSSL_DISPATCH *OSSL_FUNC_keyexch_get_ctx_params(OPENSSL_PROVIDER_CTX *provctx);
const OSSL_DISPATCH *OSSL_FUNC_keyexch_set_ctx_params(OPENSSL_PROVIDER_CTX *provctx);
int OSSL_FUNC_keyexch_init(OPENSSL_PROVIDER_CTX *provctx,
                            OPENSSL_PROVIDER_CTX *keyexchctx);
int OSSL_FUNC_keyexch_set_peer(OPENSSL_PROVIDER_CTX *keyexchctx,
                                const OSSL_ASYM_CIPHER *peerkey);
int OSSL_FUNC_keyexch_derive(OPENSSL_PROVIDER_CTX *keyexchctx,
                              unsigned char *secret, size_t *secretlen,
                              size_t maxlen);
int OSSL_FUNC_keyexch_derive_skey(OPENSSL_PROVIDER_CTX *keyexchctx,
                                   unsigned char *skey, size_t *skeylen,
                                   size_t maxlen,
                                   const OSSL_PARAM params[]);
int OSSL_FUNC_keyexch_set_params(OPENSSL_PROVIDER_CTX *keyexchctx,
                                  const OSSL_PARAM params[]);
int OSSL_FUNC_keyexch_get_params(OPENSSL_PROVIDER_CTX *keyexchctx,
                                  OSSL_PARAM params[]);
OPENSSL_PROVIDER_CTX *OSSL_FUNC_keyexch_dupctx(OPENSSL_PROVIDER_CTX *keyexchctx);

DESCRIPTION

La famille de fonctions OSSL_FUNC_keyexch_* constitue l'interface du fournisseur pour l'échange de clés.

Les fournisseurs implémentent des algorithmes d'échange de clés et rendent ces fonctions disponibles via la table de dispatch.

Fonctions de gestion du contexte

OSSL_FUNC_keyexch_newctx()
Cette fonction doit créer et initialiser un nouveau contexte pour l'échange de clés. Elle renvoie un pointeur vers la structure de dispatch contenant les fonctions implémentées par le fournisseur, ou NULL en cas d'échec.
OSSL_FUNC_keyexch_freectx()
Libère le contexte d'échange de clés provctx.
OSSL_FUNC_keyexch_teardown()
Cette fonction est appelée lors de la libération du contexte ctx d'OpenSSL. Elle doit nettoyer toute ressource détenue par le fournisseur qui est associée à ce contexte.
OSSL_FUNC_keyexch_dupctx()
Duplique le contexte d'échange de clés keyexchctx. La copie doit être indépendante de l'originale.

Fonctions de paramétrage

Ces fonctions sont utilisées pour récupérer la liste des paramètres configurables et pour lire et écrire des paramètres dans un contexte d'échange de clés.

OSSL_FUNC_keyexch_gettable_params()
Retourne une structure OSSL_PARAM(3) listant les paramètres qui peuvent être lus à partir du fournisseur pour des opérations d'échange de clés en général.
OSSL_FUNC_keyexch_settable_params()
Retourne une structure OSSL_PARAM(3) listant les paramètres qui peuvent être écrits dans le fournisseur pour des opérations d'échange de clés en général.
OSSL_FUNC_keyexch_get_ctx_params()
Retourne une structure OSSL_PARAM(3) listant les paramètres qui peuvent être lus à partir d'un contexte d'échange de clés spécifique.
OSSL_FUNC_keyexch_set_ctx_params()
Retourne une structure OSSL_PARAM(3) listant les paramètres qui peuvent être écrits dans un contexte d'échange de clés spécifique.
OSSL_FUNC_keyexch_get_params()
Lit les paramètres spécifiés dans params à partir du contexte d'échange de clés keyexchctx.
OSSL_FUNC_keyexch_set_params()
Écrit les paramètres spécifiés dans params dans le contexte d'échange de clés keyexchctx.

Notez que non tous les paramètres configurables ne sont pas aussi accessibles, et vice versa.

Paramètres communs d'échange de clés

Voir OSSL_PARAM(3) pour plus de détails sur la structure des paramètres utilisée par les fonctions OSSL_FUNC_keyexch_set_ctx_params() et OSSL_FUNC_keyexch_get_ctx_params().

Les paramètres communs actuellement reconnus par les algorithmes d'échange de clés intégrés sont les suivants.

"kdf-type" (OSSL_EXCHANGE_PARAM_KDF_TYPE) <chaîne UTF8>
Définit ou récupère le type de fonction de dérivation de clé à appliquer dans le contexte d'échange de clés associé.
"kdf-digest" (OSSL_EXCHANGE_PARAM_KDF_DIGEST) <chaîne UTF8>
Définit ou récupère l'algorithme de résumé à utiliser dans le cadre de la fonction de dérivation de clé associée au contexte d'échange de clés donné.
"kdf-digest-props" (OSSL_EXCHANGE_PARAM_KDF_DIGEST_PROPS) <chaîne UTF8>
Définit les propriétés à utiliser lors de la recherche de l'implémentation pour l'algorithme de résumé sélectionné pour la fonction de dérivation de clé associée au contexte d'échange de clés donné.
"kdf-outlen" (OSSL_EXCHANGE_PARAM_KDF_OUTLEN) <entier non signé>
Définit ou récupère la taille souhaitée pour la sortie de la fonction de dérivation de clé choisie associée au contexte d'échange de clés donné. La longueur du paramètre "kdf-outlen" ne doit pas dépasser celle d'un type size_t.
"kdf-ukm" (OSSL_EXCHANGE_PARAM_KDF_UKM) <chaîne d'octets>
Définit le matériel de clé utilisateur (User Key Material) à utiliser dans le cadre de la fonction de dérivation de clé sélectionnée associée au contexte d'échange de clés donné.
"kdf-ukm" (OSSL_EXCHANGE_PARAM_KDF_UKM) <pointeur vers chaîne d'octets>
Récupère un pointeur vers le matériel de clé utilisateur (User Key Material) à utiliser dans le cadre de la fonction de dérivation de clé sélectionnée associée au contexte d'échange de clés donné. Les fournisseurs n'ont généralement pas besoin de prendre en charge ce paramètre accessible en lecture car son seul but est de prendre en charge la fonctionnalité des fonctions dépréciées EVP_PKEY_CTX_get0_ecdh_kdf_ukm() et EVP_PKEY_CTX_get0_dh_kdf_ukm().

Le fournisseur FIPS d'OpenSSL prend également en charge les paramètres suivants :

"fips-indicator" (OSSL_EXCHANGE_PARAM_FIPS_APPROVED_INDICATOR) <entier>
Un accesseur qui renvoie 1 si l'opération est approuvée FIPS, ou 0 sinon. Ceci peut être utilisé après avoir appelé OSSL_FUNC_keyexch_derive(). Il peut renvoyer 0 si soit le "digest-check" soit le "key-check" sont réglés sur 0.
"key-check" (OSSL_EXCHANGE_PARAM_FIPS_KEY_CHECK) <entier>
Si requis, ce paramètre doit être défini en utilisant OSSL_FUNC_keyexch_init(). La valeur par défaut de 1 provoque une erreur lors de l'initialisation si la clé n'est pas approuvée FIPS (par exemple, la clé a une force de sécurité inférieure à 112 bits). La régler sur 0 ignorera l'erreur et réglera le "fips-indicator" approuvé sur 0. Cette option enfreint la conformité FIPS si elle entraîne le renvoi de 0 par le "fips-indicator" approuvé.
"digest-check" (OSSL_EXCHANGE_PARAM_FIPS_DIGEST_CHECK) <entier>
Si requis, ce paramètre doit être défini avant qu'un résumé optionnel ne soit défini. La valeur par défaut de 1 provoque une erreur lorsque le résumé est défini si le résumé n'est pas approuvé FIPS. La régler sur 0 ignorera l'erreur et réglera le "fips-indicator" approuvé sur 0. Cette option enfreint la conformité FIPS si elle entraîne le renvoi de 0 par le "fips-indicator" approuvé.

Fonctions dérivées

OSSL_FUNC_keyexch_init()
Initialise un contexte d'échange de clés keyexchctx pour une opération donnée. Le paramètre keyexchctx est celui qui a été renvoyé par OSSL_FUNC_keyexch_newctx(). Le paramètre key est la clé privée locale pour l'opération d'échange de clés.
OSSL_FUNC_keyexch_set_peer()
Définit la clé publique du pair dans le contexte d'échange de clés keyexchctx.
OSSL_FUNC_keyexch_derive()
Effectue l'opération d'échange de clés. Le secret dérivé est placé dans secret. La longueur du secret est renvoyée dans secretlen. maxlen est la taille maximale du tampon secret.
OSSL_FUNC_keyexch_derive_skey()
Fonction alternative à OSSL_FUNC_keyexch_derive(). Elle dérive une clé secrète et la place dans skey. Elle accepte également des paramètres supplémentaires via params, ce qui peut affecter la façon dont la clé est dérivée.

VALEURS DE RETOUR

OSSL_FUNC_keyexch_newctx() et OSSL_FUNC_keyexch_dupctx() doivent renvoyer le contexte d'échange de clés du côté fournisseur nouvellement créé, ou NULL en cas d'échec.

OSSL_FUNC_keyexch_init(), OSSL_FUNC_keyexch_set_peer(), OSSL_FUNC_keyexch_derive(), OSSL_FUNC_keyexch_derive_skey(), OSSL_FUNC_keyexch_set_params(), et OSSL_FUNC_keyexch_get_params() doivent renvoyer 1 en cas de succès ou 0 en cas d'erreur.

OSSL_FUNC_keyexch_settable_ctx_params() et OSSL_FUNC_keyexch_gettable_ctx_params() doivent toujours renvoyer un tableau constant OSSL_PARAM(3).

HISTORIQUE

L'interface KEYEXCH du fournisseur a été introduite dans OpenSSL 3.0.

Les paramètres d'échange de clés "fips-indicator", "key-check" et "digest-check" ont été ajoutés dans OpenSSL 3.4.

La fonction OSSL_FUNC_keyexch_derive_skey() a été ajoutée dans OpenSSL 3.6.
