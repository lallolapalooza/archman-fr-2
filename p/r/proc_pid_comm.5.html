proc_pid_comm(5) Manuel des formats de fichiers proc_pid_comm(5)

NOM

/proc/pid/comm - nom de commande

DESCRIPTION

/proc/pid/comm (depuis Linux 2.6.33)
Ce fichier expose la valeur comm du processus, c'est-à-dire le nom de commande associé au processus. Différents threads du même processus peuvent avoir des valeurs comm différentes, accessibles via /proc/pid/task/tid/comm. Un thread peut modifier sa valeur comm, ou celle de tout autre thread du même groupe de threads (voir la discussion sur CLONE_THREAD dans clone(2)), en écrivant dans le fichier /proc/self/task/tid/comm. Les chaînes de caractères plus longues que TASK_COMM_LEN (16) caractères (y compris l'octet nul de fin) sont silencieusement tronquées.
Ce fichier fournit un sur-ensemble des opérations PR_SET_NAME et PR_GET_NAME de prctl(2), et est utilisé par pthread_setname_np(3) lorsqu'il est utilisé pour renommer des threads autres que celui qui appelle. La valeur de ce fichier est utilisée pour le spécificateur %e dans /proc/sys/kernel/core_pattern ; voir core(5).
