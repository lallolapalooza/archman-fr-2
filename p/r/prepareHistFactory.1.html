NOM

prepareHistFactory - créer un répertoire de travail pour les outils HistFactory

SYNTAXE

prepareHistFactory [nom_du_répertoire]

DESCRIPTION

prepareHistFactory est un script simple qui prépare une zone de travail (et crée le répertoire nom_du_répertoire s'il est spécifié). À l'intérieur du répertoire nom_du_répertoire, il crée un répertoire results/, data/ et config/ relatifs au chemin donné. Il copie également HistFactorySchema.dtd et des fichiers XML d'exemple dans le répertoire config/. De plus, il copie un fichier root dans le répertoire data/ à utiliser avec les exemples. Une fois cela fait, on est prêt à exécuter l'exemple hist2workspace input.xml ou à modifier les fichiers XML pour un nouveau projet.
