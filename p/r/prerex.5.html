NOM

prerex_format -- un format pour les descriptions de diagrammes de prérequis

DESCRIPTION

Ce manuel décrit le format des descriptions de diagrammes de prérequis pouvant être traitées par [pdf]latex (normalement à l'aide d'un fichier de style prerex.sty(7) approprié) et édité à l'aide de l'éditeur interactif prerex(1) (ou par tout éditeur de texte conventionnel).

TERMINOLOGIE

Un diagramme de prérequis est composé d'un certain nombre de boîtes de cours, reliées par des flèches. Les cours sont soit mi-temps soit temps plein, et peuvent être requis ou optionnels (ou ni l'un ni l'autre). Chaque boîte de cours peut contenir un code de cours (en haut à gauche), un titre de cours (partie inférieure), et des informations de planning (en haut à droite). Une flèche peut être un prérequis (pleine), un coréquis (pointillé), ou recommandée (tirets). Lorsqu'une flèche conventionnelle serait inappropriée, un cours mini juste au-dessus d'une boîte cible peut être utilisé.

STRUCTURE

Le fichier doit contenir exactement une instance d'un environnement LaTeX

\begin{chart} instruction ... \end{chart}

avec au plus une instruction par ligne. Notez qu'un programme comme prerex(1) analyse les fichiers au format prerex sans utiliser TeX ; par exemple, les définitions de macros seront ignorées et les appels de macros ne seront pas développés.

Les instructions peuvent être précédées d'espaces blancs. Les lignes commençant par % sont traitées comme des commentaires et ignorées. L'ordre des instructions n'est pas significatif, sauf que l'instruction pour la boîte source et cible d'une flèche doit précéder l'instruction de la flèche. Les formats d'instruction sont décrits dans les sections suivantes.

BOITES DE COURS

Les instructions produisant des boîtes de cours ont les formes suivantes :

\halfcourse x,y:{code}{titre}{planning}

\fullcourse x,y:{code}{titre}{planning}

\reqhalfcourse x,y:{code}{titre}{planning}

\reqfullcourse x,y:{code}{titre}{planning}

\opthalfcourse x,y:{code}{titre}{planning}

\optfullcourse x,y:{code}{titre}{planning}

où x,y sont les coordonnées du point central de la boîte, par rapport à l'origine du système de coordonnées au coin inférieur gauche du diagramme. Les arguments code, titre, et planning sont du texte arbitraire (bien délimité), éventuellement avec du balisage LaTeX.

Les commandes suivantes sont similaires mais prennent un argument supplémentaire pour spécifier la couleur de fond (non par défaut) de la boîte de cours :

\halfcoursec x,y:{code}{titre}{planning}{couleur}
\fullcoursec x,y:{code}{titre}{planning}{couleur}
\reqhalfcoursec x,y:{code}{titre}{planning}{couleur}
\reqfullcoursec x,y:{code}{titre}{planning}{couleur}
\opthalfcoursec x,y:{code}{titre}{planning}{couleur}
\optfullcoursec x,y:{code}{titre}{planning}{couleur}

BOITES DE COURS MINI ET TEXTE

Un cours mini est produit par une instruction de la forme

\mini x,y:{code}

Une ligne de texte est insérée dans le diagramme par une instruction de la forme

\text x,y:{ligne-de-texte}

La longueur maximale autorisée d'un code de cours peut être inférieure à la longueur maximale autorisée pour une ligne de texte.

FLÈCHES

Les flèches entre les boîtes de cours (ou d'un mini vers une boîte de cours) sont produites par des instructions de la forme

\prereq x0,y0,x1,y1:

\coreq x0,y0,x1,y1:

\recomm x0,y0,x1,y1:

Ces instructions produisent respectivement des flèches pleines, pointillées et en tirets, allant de la boîte de cours (ou mini) centrée aux coordonnées x0,y0 à la boîte de cours centrée aux coordonnées x1,y1.

Dans certaines implémentations, certaines flèches ont par défaut une courbure non nulle. Il est possible de remplacer la courbure par défaut pour une flèche particulière en utilisant les instructions

\prereqc x0,y0,x1,y1;c:

\coreqc x0,y0,x1,y1;c:

\recommc x0,y0,x1,y1;c:

où c est un entier dans la plage -100:100 spécifiant la courbure désirée ; par exemple, c=0 produira une flèche droite. Pour modifier la courbure par défaut, le programme utilisateur peut redéfinir la commande \DefaultCurvature.

GRILLE DE COORDONNÉES

L'instruction suivante produit une grille de coordonnées, utile pour éditer un diagramme :

\grid

Ceci est normalement placé avant toutes les autres instructions afin que les lignes de la grille soient en arrière-plan, recouvertes par les boîtes de cours, les minis et les flèches.

LIENS WEB

Les boîtes de cours peuvent être liées à des adresses web. L'URL des boîtes de cours peut être définie par l'utilisateur en redéfinissant la commande \CourseURL ; lorsqu'elle est appelée pour une boîte de cours, elle reçoit trois arguments : les coordonnées x et y de la boîte, du mini, ou de la ligne de texte, et l'argument code de la boîte de cours. Par exemple,

\renewcommand{\CourseURL}[3]{http://www.cs.queensu.ca/undergraduate/courses/#3.html}

est approprié pour les cours de l'École d'Informatique de l'Université Queen's. Les deux premiers arguments peuvent être utilisés pour afficher les coordonnées d'une boîte, d'un mini, ou d'une ligne de texte dans certains lecteurs PDF lorsque la souris survole l'élément pendant l'édition du fichier source.

prerex(5)

NOM

prerex — Format de fichier pour les prérequis de cours.

SYNOPSIS

$<numéro> ...
$<numéro> [<nombre>] ...

DESCRIPTION

Le format de fichier prerex est utilisé pour spécifier les prérequis de cours. Chaque ligne peut contenir une ou plusieurs spécifications de prérequis. Les prérequis peuvent être des numéros de cours absolus ou des numéros de cours relatifs, avec la possibilité de spécifier un nombre de cours à prendre. Les numéros de cours sont généralement des entiers positifs.

STRUCTURE

Le fichier est organisé en sections, bien que la structure exacte ne soit pas rigoureusement définie dans cette page de manuel. Chaque entrée commence par un préfixe indiquant le type d'information (par exemple, des numéros de cours).

BOÎTES DE COURS

Les numéros de cours absolus sont spécifiés directement. Par exemple, $101 fait référence au cours numéro 101.

MINI BOÎTES DE COURS ET TEXTE

Cette section décrit des formats plus spécifiques qui ne sont pas détaillés ici, mais qui sont susceptibles de concerner des représentations graphiques ou textuelles des cours.

FLÈCHES

Probablement utilisé pour indiquer des relations ou des dépendances entre les cours.

GRILLE DE COORDONNÉES

Indique l'utilisation d'un système de coordonnées, probablement pour le positionnement dans une représentation visuelle.

LIENS WEB

Permet de spécifier des liens vers des ressources externes, comme des pages web.

AUTEUR

Informations sur l'auteur du fichier de prérequis.
