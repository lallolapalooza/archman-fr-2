NOM

/account

DESCRIPTION

Commandes pour créer et gérer des comptes. Appelée sans arguments, elle affichera des informations pour le compte actuel.

SYNTAXE

/account

/account list

/account show <compte>

/account enable|disable <compte>

/account default set <compte>

/account default off

/account add <compte>

/account remove <compte>

/account rename <compte> <nouveaudecompte>

/account set <compte> jid <jid>

/account set <compte> server <serveur>

/account set <compte> port <port>

/account set <compte> status <présence>

/account set <compte> status last

/account set <compte> <présence> <priorité>

/account set <compte> resource <ressource>

/account set <compte> password <motdepasse>

/account set <compte> eval_password <commande>

/account set <compte> muc <service>

/account set <compte> nick <surnom>

/account set <compte> otr <politique>

/account set <compte> pgpkeyid <pgpkeyid>

/account set <compte> startscript <script>

/account set <compte> clientid "<nom> <version>"

/account set <compte> tls force|allow|trust|legacy|disable

/account set <compte> auth default|legacy

/account set <compte> theme <thème>

/account set <compte> session_alarm <max_sessions>

/account clear <compte> password

/account clear <compte> eval_password

/account clear <compte> server

/account clear <compte> port

/account clear <compte> otr

/account clear <compte> pgpkeyid

/account clear <compte> startscript

/account clear <compte> clientid

/account clear <compte> muc

/account clear <compte> resource

/account clear <compte> session_alarm

ARGUMENTS

list

Liste tous les comptes.

enable <compte>

Active le compte, il sera utilisé pour l'autocomplétion.

show <compte>

Affiche les détails du compte spécifié.

disable <compte>

Désactive le compte.

default set <compte>

Définit le compte par défaut, utilisé lorsqu'aucun argument n'est passé à la commande /connect.

default off

Supprime le réglage du compte par défaut.

add <compte>

Crée un nouveau compte.

remove <compte>

Supprime un compte.

rename <compte> <nouveaudecompte>

Renomme 'compte' en 'nouveaudecompte'.

set <compte> jid <jid>

Définit le Jabber ID pour le compte, le nom du compte sera utilisé s'il n'est pas défini.

set <compte> server <serveur>

Le serveur de discussion, s'il est différent de la partie domaine du JID.

set <compte> port <port>

Le port utilisé pour la connexion s'il n'est pas le port par défaut (5222, ou 5223 pour SSL).

set <compte> status <présence>

Le statut de présence à utiliser lors de la connexion.

set <compte> status last

Utilise votre dernier statut avant de vous déconnecter, lors de la reconnexion.

set <compte> <présence> <priorité>

Définit la priorité (-128..127) à utiliser pour la présence spécifiée.

set <compte> resource <ressource>

La ressource à utiliser pour ce compte, par défaut 'profanity'.

set <compte> password <motdepasse>

Mot de passe du compte, notez qu'il est actuellement stocké en clair s'il est défini.

set <compte> eval_password <commande>

Commande shell évaluée pour récupérer le mot de passe du compte. Peut être utilisé pour récupérer le mot de passe du trousseau de clés.

set <compte> muc <service>

Le service de discussion MUC par défaut à utiliser, par défaut, il utilise la réponse disco info du serveur.

set <compte> nick <surnom>

Le surnom par défaut à utiliser lors de l'adhésion aux salles de discussion.

set <compte> otr <politique>

Remplace la politique OTR globale pour ce compte, voir /otr.

set <compte> pgpkeyid <pgpkeyid>

Définit l'ID de la clé PGP pour ce compte, voir /pgp.

set <compte> startscript <script>

Définit le script à exécuter après la connexion.

set <compte> clientid "<nom> <version>"

Définit le nom du client XMPP pour la découverte selon XEP-0092. Pour les amateurs de confidentialité. Il est recommandé de laisser tel quel.

set <compte> tls force

Force la connexion TLS, et échoue si une connexion ne peut être établie, c'est le comportement par défaut.

set <compte> tls allow

Utilise TLS pour la connexion si elle est disponible.

set <compte> tls trust

Force la connexion TLS et fait confiance au certificat du serveur.

set <compte> tls legacy

Utilise TLS hérité pour la connexion. Cela signifie que le serveur ne supporte pas STARTTLS et que TLS est forcé juste après l'établissement de la connexion TCP.

set <compte> tls disable

Désactive TLS pour la connexion.

set <compte> auth default

Utilise le processus d'authentification par défaut.

set <compte> auth legacy

Autorise l'authentification héritée.

set <compte> theme <thème>

Définit le thème de l'interface utilisateur pour le compte.

set <compte> session_alarm <max_sessions>

Alerte en cas d'activité suspecte si le nombre de sessions dépasse max_sessions.

clear <compte> server

Supprime le réglage du serveur pour ce compte.

clear <compte> port

Supprime le réglage du port pour ce compte.

clear <compte> password

Supprime le réglage du mot de passe pour ce compte.

clear <compte> eval_password

Supprime le réglage eval_password pour ce compte.

clear <compte> otr

Supprime le réglage de la politique OTR pour ce compte.

clear <compte> pgpkeyid

Supprime le pgpkeyid associé à ce compte.

clear <compte> startscript

Supprime le script de démarrage associé à ce compte.

clear <compte> clientid

Réinitialise le nom du client aux valeurs par défaut.

clear <compte> theme

Supprime le réglage du thème pour le compte, le thème global sera utilisé.

clear <compte> resource

Supprime le réglage de la ressource pour ce compte.

clear <compte> muc

Supprime le réglage du service MUC par défaut.

clear <compte> session_alarm

Désactive l'alarme de session.

EXEMPLES

/account add me

/account set me jid ulfhednar@valhalla.edda

/account set me server talk.chat.com

/account set me port 5111

/account set me muc chatservice.mycompany.com

/acco

profanity-account(1)

NOM

profanity-account - Gérer vos comptes.

DESCRIPTION

Ce fichier ne doit pas être utilisé directement.

Toutes les commandes du programme de ligne de commande profanity commencent par le préfixe /account et sont décrites dans cette page de manuel. L'utilisation de ces commandes modifie le fichier de configuration ~/.config/profanity/accounts.xml.

SYNOPSIS

/account set me nick NICK
/account set me status dnd
/account set me dnd -1
/account set me clientid "CLIENTID"
/account rename me CHATTy
/account clear me pgpkeyid

ARGUMENTS

set
Définir une propriété du compte.
rename
Renommer le compte.
clear
Supprimer une propriété du compte.
me
S'applique au compte courant.
nick
Définit le pseudonyme utilisé par profanity.
status
Définit le statut du compte.
dnd
Définit un état « Ne pas déranger » (Do Not Disturb).
clientid
Définit l'ID client à utiliser pour le compte.
pgpkeyid
Supprime l'ID de clé publique GPG pour le compte.

EXEMPLES

Définit le pseudonyme du compte sur « nick dennis ».

/account set me nick dennis

Définit le statut du compte sur « dnd » (Ne pas déranger).

/account set me status dnd

Définit le statut « Ne pas déranger » sur « -1 » (probablement une valeur par défaut ou une durée).

/account set me dnd -1

Définit l'ID client sur « Profanity 0.42 (Dev) ».

/account set me clientid "Profanity 0.42 (Dev)"

Renomme le compte en « chattyme ».

/account rename me chattyme

Supprime l'ID de clé publique GPG pour le compte.

/account clear me pgpkeyid
