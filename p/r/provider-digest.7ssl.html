NOM

provider-digest - Fonctions de bibliothèque de condensation <-> fournisseur

SYNOPSIS

#include <openssl/core_dispatch.h>
#include <openssl/core_names.h>
/*
 * Les condensations prennent en charge les signatures de fonction suivantes dans les tableaux OSSL_DISPATCH.
 * (Les signatures de fonction ne sont pas de vraies fonctions).
 */
/* Fonctions de gestion de contexte */
void *OSSL_FUNC_digest_newctx(void *provctx);
void OSSL_FUNC_digest_freectx(void *dctx);
void *OSSL_FUNC_digest_dupctx(void *dctx);
void OSSL_FUNC_digest_copyctx(void *voutctx, void *vinctx);
/* Génération de condensation */
int OSSL_FUNC_digest_init(void *dctx, const OSSL_PARAM params[]);
int OSSL_FUNC_digest_update(void *dctx, const unsigned char *in, size_t inl);
int OSSL_FUNC_digest_final(void *dctx, unsigned char *out, size_t *outl,
                           size_t outsz);
int OSSL_FUNC_digest_digest(void *provctx, const unsigned char *in, size_t inl,
                            unsigned char *out, size_t *outl, size_t outsz);
/* Descripteurs de paramètres de condensation */
const OSSL_PARAM *OSSL_FUNC_digest_gettable_params(void *provctx);
/* Descripteurs de paramètres d'opération de condensation */
const OSSL_PARAM *OSSL_FUNC_digest_gettable_ctx_params(void *dctx,
                                                       void *provctx);
const OSSL_PARAM *OSSL_FUNC_digest_settable_ctx_params(void *dctx,
                                                       void *provctx);
/* Paramètres de condensation */
int OSSL_FUNC_digest_get_params(OSSL_PARAM params[]);
/* Paramètres d'opération de condensation */
int OSSL_FUNC_digest_set_ctx_params(void *dctx, const OSSL_PARAM params[]);
int OSSL_FUNC_digest_get_ctx_params(void *dctx, OSSL_PARAM params[]);

DESCRIPTION

Cette documentation s'adresse principalement aux auteurs de fournisseurs. Voir provider(7) pour plus d'informations.

L'opération DIGEST permet aux fournisseurs d'implémenter des algorithmes de condensation et de les rendre disponibles aux applications via les fonctions API EVP_DigestInit_ex(3), EVP_DigestUpdate(3) et EVP_DigestFinal(3) (et autres fonctions associées).

Toutes les "fonctions" mentionnées ici sont passées sous forme de pointeurs de fonction entre libcrypto et le fournisseur dans des tableaux OSSL_DISPATCH(3) via des tableaux OSSL_ALGORITHM(3) qui sont retournés par la fonction provider_query_operation() du fournisseur (voir "Fonctions du Fournisseur" dans provider-base(7)).

Toutes ces "fonctions" ont une définition de type de fonction correspondante nommée OSSL_FUNC_{name}_fn, et une fonction d'aide pour récupérer le pointeur de fonction à partir d'un élément OSSL_DISPATCH(3) nommée OSSL_FUNC_{name}. Par exemple, la "fonction" OSSL_FUNC_digest_newctx() a ceci :

typedef void *(OSSL_FUNC_digest_newctx_fn)(void *provctx);
static ossl_inline OSSL_FUNC_digest_newctx_fn
    OSSL_FUNC_digest_newctx(const OSSL_DISPATCH *opf);

OSSL_DISPATCH(3) les tableaux sont indexés par des nombres qui sont fournis sous forme de macros dans openssl-core_dispatch.h(7), comme suit :

OSSL_FUNC_digest_newctx               OSSL_FUNC_DIGEST_NEWCTX
OSSL_FUNC_digest_freectx              OSSL_FUNC_DIGEST_FREECTX
OSSL_FUNC_digest_dupctx               OSSL_FUNC_DIGEST_DUPCTX
OSSL_FUNC_digest_copyctx              OSSL_FUNC_DIGEST_COPYCTX
OSSL_FUNC_digest_init                 OSSL_FUNC_DIGEST_INIT
OSSL_FUNC_digest_update               OSSL_FUNC_DIGEST_UPDATE
OSSL_FUNC_digest_final                OSSL_FUNC_DIGEST_FINAL
OSSL_FUNC_digest_digest               OSSL_FUNC_DIGEST_DIGEST
OSSL_FUNC_digest_get_params           OSSL_FUNC_DIGEST_GET_PARAMS
OSSL_FUNC_digest_get_ctx_params       OSSL_FUNC_DIGEST_GET_CTX_PARAMS
OSSL_FUNC_digest_set_ctx_params       OSSL_FUNC_DIGEST_SET_CTX_PARAMS
OSSL_FUNC_digest_gettable_params      OSSL_FUNC_DIGEST_GETTABLE_PARAMS
OSSL_FUNC_digest_gettable_ctx_params  OSSL_FUNC_DIGEST_GETTABLE_CTX_PARAMS
OSSL_FUNC_digest_settable_ctx_params  OSSL_FUNC_DIGEST_SETTABLE_CTX_PARAMS

Une implémentation d'algorithme de condensation peut ne pas implémenter toutes ces fonctions. Pour être utilisables, toutes ou aucune des fonctions OSSL_FUNC_digest_newctx, OSSL_FUNC_digest_freectx, OSSL_FUNC_digest_init, OSSL_FUNC_digest_update, OSSL_FUNC_digest_final et OSSL_FUNC_digest_get_params doivent être implémentées. Toutes les autres fonctions sont facultatives.

Fonctions de gestion de contexte

OSSL_FUNC_digest_newctx() doit créer et retourner un pointeur vers une structure côté fournisseur pour contenir les informations de contexte pendant une opération de condensation. Un pointeur vers ce contexte sera renvoyé dans plusieurs autres appels de fonction d'opération de condensation. Le paramètre provctx est le contexte du fournisseur généré lors de l'initialisation du fournisseur (voir provider(7)).

OSSL_FUNC_digest_freectx() reçoit un pointeur vers le contexte de condensation côté fournisseur dans le paramètre dctx. Cette fonction doit libérer toutes les ressources associées à ce contexte.

OSSL_FUNC_digest_dupctx() doit dupliquer le contexte de condensation côté fournisseur dans le paramètre dctx et retourner la copie dupliquée.

OSSL_FUNC_digest_copyctx() doit copier le contexte de condensation côté fournisseur dans le paramètre vinctx vers le paramètre voutctx qui est un autre contexte côté fournisseur. La fonction OSSL_FUNC_digest_copyctx est utilisée dans la fonction EVP_MD_CTX_copy_ex pour accélérer les opérations HMAC dans PBKDF2. Cette fonction est facultative, et dupctx sera utilisée s'il n'y a pas de fonction EVP_MD_CTX_copy_ex.

Fonctions de génération de condensation

OSSL_FUNC_digest_init() initialise une opération de condensation étant donné un contexte de condensation côté fournisseur nouvellement créé dans le paramètre dctx. Les params, s'ils ne sont pas NULL, doivent être définis sur le contexte d'une manière similaire à l'utilisation de OSSL_FUNC_digest_set_ctx_params().

OSSL_FUNC_digest_update() est appelée pour fournir des données à condenser dans le cadre d'une opération de condensation précédemment initialisée. Le paramètre dctx contient un pointeur vers un contexte côté fournisseur précédemment initialisé. OSSL_FUNC_digest_update() doit condenser inl octets de données à l'emplacement pointé par in. OSSL_FUNC_digest_update() peut être appelée plusieurs fois pour une seule opération de condensation.

OSSL_FUNC_digest_final() génère une condensation commencée par les appels précédents OSSL_FUNC_digest_init() et OSSL_FUNC_digest_update(). Le paramètre dctx contient un pointeur vers le contexte côté fournisseur. La condensation doit être écrite dans *out et la longueur de la condensation dans *outl. La condensation ne doit pas dépasser outsz octets.

OSSL_FUNC_digest_digest() est une fonction de condensation "à usage unique". Aucun contexte de condensation côté fournisseur n'est utilisé. Au lieu de cela, le contexte du fournisseur qui a été créé lors de l'initialisation du fournisseur est passé dans le paramètre provctx (voir provider(7)). Les inl octets à l'emplacement in doivent être condensés et le résultat doit être stocké à l'emplacement out. La longueur de la condensation doit être stockée dans *outl, qui ne doit pas dépasser outsz octets.

Paramètres de condensation

Voir OSSL_PARAM(3) pour plus de détails sur la structure des paramètres utilisée par ces fonctions.

OSSL_FUNC_digest_get_params() récupère les détails de l'implémentation de l'algorithme et les stocke dans params.

OSSL_FUNC_digest_set_ctx_params() définit les paramètres de l'opération de condensation pour le contexte de condensation côté fournisseur dctx à params. Tous les paramètres définis sont supplémentaires à ceux qui étaient précédemment définis. Passer NULL pour params devrait retourner vrai.

OSSL_FUNC_digest_get_ctx_params() récupère les détails de l'opération de condensation à partir du contexte de condensation côté fournisseur donné dctx et les stocke dans params. Passer NULL pour params devrait retourner vrai.

OSSL_FUNC_digest_gettable_params() retourne un tableau constant OSSL_PARAM(3) contenant les descripteurs des paramètres que OSSL_FUNC_digest_get_params() peut gérer.

OSSL_FUNC_digest_gettable_ctx_params() et OSSL_FUNC_digest_settable_ctx_params() retournent tous deux des tableaux constants OSSL_PARAM(3) comme descripteurs des paramètres que OSSL_FUNC_digest_get_ctx_params() et OSSL_FUNC_digest_set_

NAME

provider-digest - Provider DIGEST interface

SYNOPSIS

```c #include <openssl/core_dispatch.h> typedef void *(*digest_newctx_fn)(void *provctx); typedef void (*digest_freectx_fn)(void *ctx); typedef int (*digest_dupctx_fn)(void *tctx, const void *sctx); typedef int (*digest_init_fn)(void *ctx); typedef int (*digest_update_fn)(void *ctx, const unsigned char *data, size_t datalen); typedef int (*digest_final_fn)(void *ctx, unsigned char *digest); typedef int (*digest_digest_fn)(void *ctx, const unsigned char *data, size_t datalen, unsigned char *digest, size_t *digestlen, size_t hashesizelen); typedef size_t (*digest_size_fn)(const OSSL_PARAM params[]); typedef size_t (*digest_block_size_fn)(const OSSL_PARAM params[]); typedef int (*digest_get_params_fn)(OSSL_PARAM params[]); typedef int (*digest_set_ctx_params_fn)(void *ctx, const OSSL_PARAM params[]); typedef int (*digest_get_ctx_params_fn)(void *ctx, OSSL_PARAM params[]); static const OSSL_DISPATCH_GLOBAL * OSSL_PROVIDER_digest_dispatch(int kih); /* Functions from openssl/evp.h */ int EVP_DigestInit(EVP_MD_CTX *ctx, const EVP_MD *type); int EVP_DigestUpdate(EVP_MD_CTX *ctx, const void *d, size_t cnt); int EVP_DigestFinal_ex(EVP_MD_CTX *ctx, unsigned char *md, unsigned int *s); int EVP_Digest(const void *data, size_t len, unsigned char *md, unsigned int *s, const EVP_MD *type, ENGINE *impl); int EVP_Q_digest(const char *name, const char *propq, const unsigned char *data, size_t datalen, unsigned char *md, size_t *mdlen); ```

DESCRIPTION

The DIGEST interface is used by the OpenSSL library to provide digest functionality. A provider implements this interface to offer digests.

The functions available through the OSSL_DISPATCH_GLOBAL structure are:

OSSL_FUNC_digest_newctx
Creates a new digest context. The supplied provctx is the provider context.
OSSL_FUNC_digest_freectx
Frees a digest context ctx.
OSSL_FUNC_digest_copyctx
Duplicates a digest context sctx into a new context tctx.
OSSL_FUNC_digest_init
Initialises a digest context ctx. This is the same functionality as EVP_DigestInit(3).
OSSL_FUNC_digest_update
Updates a digest context ctx with data data of length datalen. This is the same functionality as EVP_DigestUpdate(3).
OSSL_FUNC_digest_final
Computes the digest from the data available in the digest context ctx. The result is stored in digest. The length of the digest is determined by the digest algorithm. This is the same functionality as EVP_DigestFinal_ex(3), but without the size parameter.
OSSL_FUNC_digest_digest
Computes the digest for the input data data of length datalen in one go. The result is stored in digest. If digestlen is not NULL, then it is set to the actual digest length. This function can be used in place of EVP_Digest(3). If hashesizelen is non-zero, it specifies the size of the buffer for the digest. This is useful for XOFs where the output size can be specified.
OSSL_FUNC_digest_get_size
Returns the size in bytes of the digest computed by the digest algorithm. This is the same functionality as EVP_MD_size(3).
OSSL_FUNC_digest_get_block_size
Returns the block size in bytes of the underlying digest algorithm. This is the same functionality as EVP_MD_block_size(3).
OSSL_FUNC_digest_get_params
Gets algorithm-wide parameters. See "Digest Algorithm Parameters" below.
OSSL_FUNC_digest_set_params
Sets algorithm-wide parameters. See "Digest Algorithm Parameters" below.
OSSL_FUNC_digest_set_ctx_params
Sets digest context specific parameters. See "Digest Context Parameters" below.
OSSL_FUNC_digest_get_ctx_params
Gets digest context specific parameters. See "Digest Context Parameters" below.

Digest Algorithm Parameters

The parameter sets available through the OSSL_FUNC_digest_get_params and OSSL_FUNC_digest_set_params functions are described here. These parameters are intended for algorithm-wide settings, not for settings specific to a particular context.

Parameters currently recognised by built-in digests with these functions are as follows. Not all parameters are relevant to, or are understood by all digests:

"blocksize" (OSSL_DIGEST_PARAM_BLOCK_SIZE) <unsigned integer>
The digest block size. The length of the "blocksize" parameter should not exceed that of a size_t.
"size" (OSSL_DIGEST_PARAM_SIZE) <unsigned integer>
The digest output size. The length of the "size" parameter should not exceed that of a size_t.
"flags" (OSSL_DIGEST_PARAM_FLAGS) <unsigned integer>
Diverse flags that describe exceptional behaviour for the digest:
EVP_MD_FLAG_ONESHOT
This digest method can only handle one block of input.
EVP_MD_FLAG_XOF
This digest method is an extensible-output function (XOF).
EVP_MD_FLAG_DIGALGID_NULL
When setting up a DigestAlgorithmIdentifier, this flag will have the parameter set to NULL by default. Use this for PKCS#1. Note: if combined with EVP_MD_FLAG_DIGALGID_ABSENT, the latter will override.
EVP_MD_FLAG_DIGALGID_ABSENT
When setting up a DigestAlgorithmIdentifier, this flag will have the parameter be left absent by default. Note: if combined with EVP_MD_FLAG_DIGALGID_NULL, the latter will be overridden.
EVP_MD_FLAG_DIGALGID_CUSTOM
Custom DigestAlgorithmIdentifier handling via ctrl, with EVP_MD_FLAG_DIGALGID_ABSENT as default. Note: if combined with EVP_MD_FLAG_DIGALGID_NULL, the latter will be overridden. Currently unused.

The length of the "flags" parameter should equal that of an unsigned long int.

Digest Context Parameters

OSSL_FUNC_digest_set_ctx_params() sets digest parameters associated with the given provider side digest context dctx to params. Any parameter settings are additional to any that were previously set. See OSSL_PARAM(3) for further details on the parameters structure.

OSSL_FUNC_digest_get_ctx_params() gets details of currently set parameters values associated with the give provider side digest context dctx and stores them in params. See OSSL_PARAM(3) for further details on the parameters structure.

RETURN VALUES

OSSL_FUNC_digest_newctx() and OSSL_FUNC_digest_dupctx() should return the newly created provider side digest context, or NULL on failure.

OSSL_FUNC_digest_init(), OSSL_FUNC_digest_update(), OSSL_FUNC_digest_final(), OSSL_FUNC_digest_digest(), OSSL_FUNC_digest_set_params() and OSSL_FUNC_digest_get_params() should return 1 for success or 0 on error.

OSSL_FUNC_digest_size() should return the digest size.

OSSL_FUNC_digest_block_size() should return the block size of the underlying digest algorithm.

BUGS

The EVP_Q_digest(), EVP_Digest() and EVP_DigestFinal_ex() API calls do not expect the digest size to be larger than EVP_MAX_MD_SIZE. Any algorithm which produces larger digests is unusable with those API calls.
