PROGRESS(1) Manuel des commandes générales PROGRESS(1)

NOM

progress - Visionneuse de progression des utilitaires Coreutils

SYNOPSIS

progress [ -qdwmM ] [ -W secondes ] [ -c commande ] [ -a commande ] [ -p pid ]
progress -v | --version
progress -h | --help

DESCRIPTION

Cette page de manuel documente brièvement la commande progress.

Cet outil peut être décrit comme une commande C petite, sale, qui recherche les commandes de base des utilitaires Coreutils (cp, mv, dd, tar, gzip/gunzip, cat, etc.) actuellement en cours d'exécution sur votre système et affiche le pourcentage de données copiées.

Il peut désormais également estimer le débit (en utilisant l'option -w).

OPTIONS

-q (--quiet)
masque tous les messages
-d (--debug)
affiche tous les messages d'avertissement/erreur
-w (--wait)
estime le débit d'E/S et le temps restant estimé (affichage plus lent)
-W (--wait-delay secondes)
attend 'secondes' pour l'estimation des E/S (implique -w)
-m (--monitor)
boucle tant que les processus surveillés sont en cours d'exécution
-M (--monitor-continuously)
comme monitor, mais ne s'arrête jamais (similaire à watch progress)
-c (--command cmd)
surveille uniquement ce nom de commande (ex: firefox). Cette option peut être utilisée plusieurs fois sur la ligne de commande.
-a (--additional-command cmd)
ajoute cette commande à la liste par défaut. Cette option peut être utilisée plusieurs fois sur la ligne de commande.
-p (--pid id)
surveille uniquement cet ID de processus numérique (ex: `pidof firefox`). Cette option peut être utilisée plusieurs fois sur la ligne de commande.
-i (--ignore-file fichier)
ne signale pas un processus pour 'fichier'. Si le fichier n'existe pas encore, vous devez fournir un chemin absolu complet et propre. Cette option peut être utilisée plusieurs fois sur la ligne de commande.
-o (--open-mode {r|w})
ne signale que les fichiers ouverts en lecture ou en écriture par le processus. Cette option est utile lorsque vous souhaitez surveiller uniquement les fichiers de sortie (ou d'entrée) d'un processus.
-v (--version)
affiche la version du programme et quitte
-h (--help)
affiche le message d'aide et quitte

ENVIRONNEMENT

Il est possible de donner des options permanentes en utilisant la variable d'environnement PROGRESS_ARGS. Voir l'exemple ci-dessous. Les arguments de la ligne de commande ont la priorité sur l'environnement.

EXEMPLES

Surveiller en continu toutes les instances actuelles et futures des commandes Coreutils

watch progress -q

Voir la progression de votre téléchargement

watch progress -wc firefox

Observer l'activité de votre serveur Web

progress -c httpd

Lancer et surveiller toute commande lourde en utilisant $!

cp bigfile newfile & progress -mp $!

Utiliser la variable d'environnement pour définir des arguments permanents (multiples)

export PROGRESS_ARGS='-M --ignore-file ~/.xsession-errors'
