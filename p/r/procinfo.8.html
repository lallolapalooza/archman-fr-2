NOM

procinfo - afficher les statistiques système collectées depuis /proc

SYNTAXE

procinfo [ -fdDSbrhv ] [ -nN ]

DESCRIPTION

procinfo collecte des données système depuis le répertoire /proc et les affiche joliment formatées sur la sortie standard.

La signification des champs est la suivante :

Mémoire :
Voir la page de manuel de free(1).
Démarrage :
L'heure à laquelle le système a démarré.
Charge moyenne :
Le nombre moyen de tâches en cours d'exécution, suivi du nombre de processus prêts à être exécutés et du nombre total de processus, suivi de l'ID du dernier processus exécuté. L'ID du dernier processus exécuté sera probablement toujours l'ID de procinfo.
utilisateur :
Le temps passé à exécuter des tâches en espace utilisateur.
nice :
Le temps passé à exécuter des tâches « nice » en espace utilisateur.
système :
Le temps passé à s'exécuter en espace noyau. Note : le temps passé à gérer les interruptions n'est pas compté par le noyau (et il n'y a rien que procinfo puisse faire à ce sujet).
inactif :
Le temps passé sans rien faire.
temps de fonctionnement :
Le temps pendant lequel le système a été actif. Les quatre éléments précédents devraient plus ou moins s'additionner pour donner ce chiffre.
page en :
Le nombre de blocs disque chargés en mémoire depuis le disque. 1 bloc équivaut à 1 kio.
page en dehors :
Le nombre de blocs disque déchargés de la mémoire vers le disque. Cela inclut les écritures disque normales.
échange en :
Le nombre de pages mémoire chargées depuis l'espace d'échange.
échange en dehors :
Le nombre de pages mémoire déchargées vers l'espace d'échange.
contexte :
Le nombre de changements de contexte, soit depuis le démarrage, soit par intervalle.
Statistiques disque(hda, hdb, sda, sdb) :
Le nombre de lectures et d'écritures effectuées sur les disques, qu'il s'agisse de CD-ROM, de disques durs ou de clés USB. Affiche tous les disques s'ils sont de type hdX ou sdX, ou s'ils ont un nombre de lectures/écritures non nul.
Interruptions :
Nombre d'interruptions traitées depuis le démarrage, ou par intervalle, listé par IRQ.

OPTIONS

-nN
Pause de N secondes entre les mises à jour. Cette option implique -f. Elle peut contenir un point décimal. Par défaut, 5 secondes. Lorsqu'elle est exécutée par root avec une pause de 0 seconde, le programme s'exécutera au niveau de priorité le plus élevé possible.
-d
Pour la mémoire, les temps CPU, la pagination, l'échange, les statistiques disque, de contexte et d'interruptions, afficher les valeurs par seconde plutôt que les totaux. Cette option implique -f.
-D
Identique à -d, sauf que les statistiques mémoire sont affichées comme des totaux.
-S
Lorsque vous exécutez avec -d ou -D, affichez toujours les valeurs par seconde, même lorsque vous exécutez avec -n N où N est supérieur à une seconde.
-b
Afficher les nombres d'octets plutôt que le nombre de requêtes d'E/S.
-r
Cette option ajoute une ligne supplémentaire aux informations mémoire montrant la mémoire libre « réelle », tout comme le fait free(1). Les nombres produits supposent que les tampons et le cache sont jetables.
-H
Affiche les statistiques mémoire en nombres « humains » (base 1024) (Kio, Mio, Gio), au lieu de Kilo-octets implicites.
-h
Afficher un bref message d'aide.
-v
Afficher les informations de version.

COMMANDES

INTERACTIVES

Lorsque vous exécutez procinfo en plein écran, vous pouvez modifier son comportement en appuyant sur d, D, S, r et b, qui basculent les indicateurs correspondant à leurs options en ligne de commande portant le même nom. De plus, vous pouvez appuyer sur q pour quitter le programme.

FICHIERS

/proc
Le système de fichiers proc.

BOGUES

Toutes ces statistiques sont prises verbatim du noyau, sans aucune mise à l'échelle. Dans tous les cas où le noyau spécifie qu'un champ particulier signifie quelque chose de différent de la manière dont il est documenté dans cette page de manuel, le noyau a toujours raison.

Certaines fonctionnalités de procinfo original ont été supprimées, car elles étaient considérées comme non utiles, d'autant plus que beaucoup d'entre elles ne changent plus et que des utilitaires meilleurs existent pour les lister/afficher.

VOIR AUSSI

free(1), uptime(1), w(1), init(8), proc(5).
