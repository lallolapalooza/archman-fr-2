NOM

providence - économiseur d'écran œil dans la gloire

SYNTAXE

providence [--display hôte:écran.numéro] [--window] [--root] [--window-id numéro]
[--install] [--visual visuel] [--delay microsecondes] [--wireframe] [--fps]

DESCRIPTION

Le code providence affiche un œil, enveloppé de gloire, posé sur la base d'une pyramide.

OPTIONS

providence accepte les options suivantes :

--window
Dessiner dans une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessiner dans la fenêtre racine.
--window-id numéro
Dessiner dans la fenêtre spécifiée.
--install
Installer une carte de couleurs privée pour la fenêtre.
--eye
Dessiner un œil/$.
--visual visuel
Spécifier le visuel à utiliser. Les valeurs légales sont le nom d'une classe de visuel, ou le numéro d'identification (décimal ou hexadécimal) d'un visuel spécifique.
--wireframe
Rendu en mode filaire (avec suppression des lignes cachées) au lieu de solides texturés.
--fps
Afficher le taux d'images par seconde, la charge CPU et le nombre de polygones.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de la fenêtre à utiliser avec --root.

VOIR AUSSI
