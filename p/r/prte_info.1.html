prte_info — Fournir des informations détaillées sur votre installation PRRTE

SYNTAXE

prte_info ...options...

DESCRIPTION

prte_info fournit des informations détaillées sur votre installation de l'environnement d'exécution de référence PMIx (PRRTE).

Une documentation d'aide complète pour cette commande est disponible via prte_info --help [sujet].

Au moins pour l'instant, ce contenu n'est pas disponible sous forme de page de manuel. Les demandes de tirage (pull requests) pour ajouter tout le contenu (via une infrastructure reproductible) seraient grandement appréciées.
