NOM

pruneemptydirs - Détecte les répertoires source obsolètes dans un arbre CVS

SYNOPSIS

pruneemptydirs [-f]

DESCRIPTION

pruneemptydirs est utilisé pour nettoyer un arbre CVS local. Il détecte les répertoires contenant des restes d'anciens éléments qui ont été supprimés de CVS. Ces répertoires obsolètes provoquent souvent des échecs de compilation. Le répertoire courant et tous les répertoires en dessous seront examinés.

Notez que cet outil ne supprime rien ; il se contente d'afficher les commandes de suppression à exécuter. Vous pouvez copier-coller ces commandes, ou les utiliser avec eval dans un script.

Cet outil fonctionne mieux si le répertoire source n'est pas le même que le répertoire de construction, car il n'affichera pas les répertoires contenant d'anciens exécutables.

Cet utilitaire fait partie du kit de développement logiciel KDE.

OPTIONS

-f

Effectue réellement les suppressions au lieu de simplement les afficher. Utilisez cette option avec précaution.
