profanity-executable(1)

Paquet: profanity-gtk

Licences: GPL3

man(1) Client XMPP Profanity man(1)

NOM

/executable

DESCRIPTION

Configure un exécutable qui doit être appelé lors d'une certaine commande.

SYNOPSIS

/executable avatar set <modèletemplate>

/executable avatar default

/executable urlopen set <modèletemplate>

/executable urlopen default

/executable urlsave set <modèletemplate>

/executable urlsave default

/executable editor set <modèletemplate>

/executable editor default

/executable vcard_photo set <modèletemplate>

/executable vcard_photo default

ARGUMENTS

avatar set

Définit l'exécutable qui est exécuté par /avatar open. Utilisez votre visionneuse d'images préférée.

avatar default

Restaure les paramètres par défaut.

urlopen set

Définit l'exécutable qui est exécuté par /url open. Prend un modèle de commande qui remplace %u et %p par l'URL et le chemin respectivement.

urlopen default

Restaure les paramètres par défaut.

urlsave set

Définit l'exécutable qui est exécuté par /url save. Prend un modèle de commande qui remplace %u et %p par l'URL et le chemin respectivement.

urlsave default

Utilise la méthode de téléchargement intégrée pour enregistrer.

editor set

Définit l'éditeur à utiliser avec /editor. Nécessite un éditeur de terminal ou un script pour lancer un éditeur graphique.

editor default

Restaure les paramètres par défaut.

vcard_photo set

Définit l'exécutable qui est exécuté par /vcard photo open. Prend un modèle de commande qui remplace %p par le chemin.

vcard_photo default

Restaure les paramètres par défaut.

EXEMPLES

/executable avatar xdg-open

/executable urlopen set "xdg-open %u"

/executable urlopen set "firefox %u"

/executable urlopen default

/executable urlsave set "wget %u -O %p"

/executable urlsave set "curl %u -o %p"

/executable urlsave default

/executable vcard_photo set "feh %p"

/executable editor set "emacsclient -t"
