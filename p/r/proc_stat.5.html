proc_stat(5) Manuel des formats de fichiers proc_stat(5)

NOM

/proc/stat - statistiques système du noyau

DESCRIPTION

/proc/stat
statistiques noyau/système. Varie selon l'architecture. Les entrées courantes incluent :
cpu 10132153 290696 3084719 46828483 16683 0 25195 0 175628 0
cpu0 1393280 32966 572056 13343292 6130 0 17875 0 23933 0
La quantité de temps, mesurée en unités de USER_HZ (1/100èmes de seconde sur la plupart des architectures, utilisez sysconf(_SC_CLK_TCK) pour obtenir la bonne valeur), que le système (« ligne cpu ») ou le CPU spécifique (« ligne cpuN ») a passé dans divers états :
user
(1) Temps passé en mode utilisateur.
nice
(2) Temps passé en mode utilisateur à basse priorité (nice).
system
(3) Temps passé en mode système.
idle
(4) Temps passé dans la tâche idle. Cette valeur devrait être USER_HZ fois la deuxième entrée du pseudo-fichier /proc/uptime.
iowait (depuis Linux 2.5.41)
(5) Temps d'attente de la fin des opérations d'E/S. Cette valeur n'est pas fiable, pour les raisons suivantes :
•
Le CPU n'attend pas la fin des opérations d'E/S ; iowait est le temps pendant lequel une tâche attend la fin des opérations d'E/S. Quand un CPU passe à l'état idle en raison d'E/S de tâches en attente, une autre tâche sera planifiée sur ce CPU.
•
Sur un CPU multi-cœurs, la tâche attendant la fin des opérations d'E/S ne tourne sur aucun CPU, donc l'iowait de chaque CPU est difficile à calculer.
•
La valeur de ce champ peut *diminuer* dans certaines conditions.
irq (depuis Linux 2.6.0)
(6) Temps passé à gérer les interruptions.
softirq (depuis Linux 2.6.0)
(7) Temps passé à gérer les interruptions logicielles (softirqs).
steal (depuis Linux 2.6.11)
(8) Temps volé (stolen time), qui est le temps passé dans d'autres systèmes d'exploitation lors de l'exécution dans un environnement virtualisé
guest (depuis Linux 2.6.24)
(9) Temps passé à exécuter un CPU virtuel pour des systèmes d'exploitation invités sous le contrôle du noyau Linux.
guest_nice (depuis Linux 2.6.33)
(10) Temps passé à exécuter un invité "nice" (CPU virtuel pour des systèmes d'exploitation invités sous le contrôle du noyau Linux).
page 5741 1808
Le nombre de pages que le système a chargées (paged in) et le nombre qui ont été déchargées (paged out) (depuis le disque).
swap 1 0
Le nombre de pages de swap qui ont été chargées et déchargées.
intr 1462898
Cette ligne montre le compte des interruptions gérées depuis le démarrage, pour chacune des interruptions système possibles. La première colonne est le total de toutes les interruptions gérées, y compris les interruptions non numérotées spécifiques à l'architecture ; chaque colonne suivante est le total pour cette interruption numérotée particulière. Les interruptions non numérotées ne sont pas affichées, seulement additionnées au total.
disk_io: (2,0):(31,30,5764,1,2) (3,0):...
(major,disk_idx):(noinfo, read_io_ops, blks_read, write_io_ops, blks_written)
(Linux 2.4 seulement)
ctxt 115315
Le nombre de changements de contexte que le système a subis.
btime 769041601
heure de démarrage (boot time), en secondes depuis l'Epoch, 1970-01-01 00:00:00 +0000 (UTC).
processes 86031
Nombre de forks depuis le démarrage.
procs_running 6
Nombre de processus en état exécutable. (Depuis Linux 2.5.45.)
procs_blocked 2
Nombre de processus bloqués attendant la fin des opérations d'E/S. (Depuis Linux 2.5.45.)
softirq 229245889 94 60001584 13619 5175704 2471304 28 51212741 59130143 0 51240672
Cette ligne montre le nombre de softirqs pour tous les CPUs. La première colonne est le total de tous les softirqs et chaque colonne suivante est le total pour un softirq particulier. (Depuis Linux 2.6.31.)
