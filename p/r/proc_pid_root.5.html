proc_pid_root(5) Manuel des formats de fichiers proc_pid_root(5)

NOM

/proc/pid/root/ - lien symbolique vers le répertoire racine

DESCRIPTION

/proc/pid/root/
UNIX et Linux prennent en charge l'idée d'une racine de système de fichiers par processus, définie par l'appel système chroot(2). Ce fichier est un lien symbolique qui pointe vers le répertoire racine du processus et se comporte de la même manière que exe et fd/*.
Notez cependant que ce fichier n'est pas simplement un lien symbolique. Il fournit la même vue du système de fichiers (y compris les espaces de noms et l'ensemble des montages par processus) que le processus lui-même. Un exemple illustre ce point. Dans un terminal, nous démarrons un shell dans de nouveaux espaces de noms utilisateur et de montage, et dans ce shell, nous créons de nouveaux montages :

$ PS1='sh1# ' unshare -Urnm;
sh1# mount -t tmpfs tmpfs /etc;  # Monte un tmpfs vide dans /etc
sh1# mount --bind /usr /dev;     # Monte /usr dans /dev
sh1# echo $$;
27123

Dans une deuxième fenêtre de terminal, dans l'espace de noms de montage initial, nous examinons le contenu des montages correspondants dans les espaces de noms initial et nouveau :

$ PS1='sh2# ' sudo sh;
sh2# ls /etc | wc -l;                  # Dans l'espace de noms initial
309
sh2# ls /proc/27123/root/etc | wc -l;  # /etc dans l'autre espace de noms
0                                     # Le répertoire tmpfs vide
sh2# ls /dev | wc -l;                  # Dans l'espace de noms initial
205
sh2# ls /proc/27123/root/dev | wc -l;  # /dev dans l'autre espace de noms
11                                    # En fait, lié
                                      # monté à partir de /usr
sh2# ls /usr | wc -l;                  # /usr dans l'espace de noms initial
11

Dans un processus multithreadé, le contenu du lien symbolique /proc/pid/root n'est pas disponible si le thread principal a déjà terminé (typiquement en appelant pthread_exit(3)).
La permission de déréférencer ou de lire (readlink(2)) ce lien symbolique est régie par une vérification de mode d'accès ptrace PTRACE_MODE_READ_FSCREDS ; voir ptrace(2).
