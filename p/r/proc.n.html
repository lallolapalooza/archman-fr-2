proc(n) Commandes intégrées Tcl proc(n)

NOM

proc - Créer une procédure Tcl

SYNTAXE

proc nom args corps

DESCRIPTION

La commande proc crée une nouvelle procédure Tcl nommée nom, remplaçant toute commande ou procédure existante portant ce nom. Chaque fois que la nouvelle commande est invoquée, le contenu de corps sera exécuté par l'interpréteur Tcl. Normalement, nom est non qualifié (n'inclut pas les noms des espaces de noms parents), et la nouvelle procédure est créée dans l'espace de noms courant. Si nom inclut des qualificateurs d'espace de noms, la procédure est créée dans l'espace de noms spécifié. Args spécifie les arguments formels de la procédure. Il consiste en une liste, potentiellement vide, dont chaque élément spécifie un argument. Chaque spécificateur d'argument est également une liste d'un ou deux champs. S'il n'y a qu'un seul champ dans le spécificateur, il s'agit du nom de l'argument ; s'il y a deux champs, le premier est le nom de l'argument et le second est sa valeur par défaut. Les arguments avec des valeurs par défaut qui sont suivis par des arguments non par défaut deviennent des arguments requis ; suffisamment d'arguments réels doivent être fournis pour permettre à tous les arguments jusqu'au dernier argument formel requis (inclus) d'être satisfaits.

Lorsque nom est invoqué, une variable locale sera créée pour chacun des arguments formels de la procédure ; sa valeur sera la valeur de l'argument correspondant dans la commande d'invocation ou la valeur par défaut de l'argument. Les arguments réels sont assignés aux arguments formels strictement dans l'ordre. Les arguments avec des valeurs par défaut n'ont pas besoin d'être spécifiés dans une invocation de procédure. Cependant, il doit y avoir suffisamment d'arguments réels pour tous les arguments formels qui n'ont pas de valeurs par défaut, et il ne doit y avoir aucun argument réel supplémentaire. Les arguments avec des valeurs par défaut qui sont suivis par des arguments non par défaut deviennent des arguments de facto requis, bien que cela puisse changer dans une future version de Tcl ; le code portable doit s'assurer que tous les arguments optionnels viennent après tous les arguments requis.

Il existe un cas spécial pour permettre des procédures avec un nombre variable d'arguments. Si le dernier argument formel a le nom “args”, alors un appel à la procédure peut contenir plus d'arguments réels que la procédure n'a d'arguments formels. Dans ce cas, tous les arguments réels commençant par celui qui serait assigné à args sont combinés en une liste (comme si la commande list avait été utilisée) ; cette valeur combinée est assignée à la variable locale args.

Lorsque corps est exécuté, les noms de variables font normalement référence à des variables locales, qui sont créées automatiquement lorsqu'elles sont référencées et supprimées lorsque la procédure retourne. Une variable locale est automatiquement créée pour chacun des arguments de la procédure. D'autres variables ne peuvent être accédées qu'en invoquant l'une des commandes global, variable, upvar ou namespace upvar. L'espace de noms courant lors de l'exécution de corps sera l'espace de noms dans lequel le nom de la procédure existe, qui sera l'espace de noms dans lequel elle a été créée, à moins qu'il n'ait été modifié avec rename.

La commande proc retourne une chaîne vide. Lorsqu'une procédure est invoquée, la valeur de retour de la procédure est la valeur spécifiée dans une commande return. Si la procédure n'exécute pas explicitement un return, alors sa valeur de retour est la valeur de la dernière commande exécutée dans le corps de la procédure. Si une erreur se produit lors de l'exécution du corps de la procédure, la procédure dans son ensemble retournera la même erreur.

EXEMPLES

Ceci est une procédure qui prend deux arguments et imprime leur somme et leur produit. Elle retourne également la chaîne “OK” à l'appelant comme résultat explicite.

proc imprimerSommeProduit {x y} {
    set somme [expr {$x + $y}]
    set prod [expr {$x * $y}]
    puts "la somme est $somme, le produit est $prod"
    return "OK"
}

Ceci est une procédure qui accepte un nombre arbitraire d'arguments et les imprime, un par un.

proc imprimerArguments args {
    foreach arg $args {
        puts $arg
    }
}

Cette procédure est un peu comme la commande incr, sauf qu'elle multiplie le contenu de la variable nommée par la valeur, qui est par défaut 2 :

proc mult {nomVar {multiplicateur 2}} {
    upvar 1 $nomVar var
    set var [expr {$var * $multiplicateur}]
}
