profanity-statusbar(1)

Paquet: profanity-gtk

Licences: GPL3

man(1) Client XMPP Profanity man(1)

NOM

/statusbar

DESCRIPTION

Gérer les préférences d'affichage de la barre d'état.

SYNTAXE

/statusbar show name|number|read

/statusbar hide name|number|read

/statusbar maxtabs <valeur>

/statusbar tablen <valeur>

/statusbar tabmode default|dynamic|actlist

/statusbar self user|barejid|fulljid|off

/statusbar chat user|jid

/statusbar room title bookmark|jid|localpart|name

/statusbar up

/statusbar down

ARGUMENTS

maxtabs <valeur>

Définit le nombre maximum d'onglets à afficher, <valeur> doit être compris entre 0 et 10.

tablen <valeur>

Définit le nombre maximum de caractères à afficher pour le nom de l'onglet, 0 signifie illimité.

tabmode default|dynamic|actlist

Définit le mode d'affichage des onglets. `dynamic` est un mode qui affiche les onglets de manière pratique autour de l'onglet actuel, assurant ainsi une pagination correcte. Le réglage `actlist` n'affiche que les onglets actifs. Le réglage `default` affiche toujours les onglets dans la plage de 1 à max_tabs.

show|hide name

Afficher ou masquer les noms dans les onglets.

show|hide number

Afficher ou masquer les numéros dans les onglets.

show|hide read

Afficher ou masquer les onglets inactifs.

self user|barejid|fulljid

Affiche le nom d'utilisateur du compte, le barejid, le fulljid comme titre de la barre d'état.

self off

Désactive l'affichage de soi comme titre de la barre d'état.

chat user|jid

Affiche le nom des utilisateurs ou le fulljid. Un changement nécessite un redémarrage/rafraîchissement pour prendre effet.

room title bookmark|jid|localpart|name

Affiche le nom du signet, le JID, la partie locale du JID ou le nom de la pièce comme titre pour les onglets MUC.

up

Déplace la barre d'état vers le haut de l'écran.

down

Déplace la barre d'état vers le bas de l'écran.

EXEMPLES

/statusbar maxtabs 8

/statusbar tablen 5

/statusbar tabmode actlist

/statusbar self user

/statusbar chat jid

/statusbar hide read

/statusbar hide name
