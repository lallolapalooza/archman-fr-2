NAME

proj - Cartographic projection filter

SYNOPSIS

proj [-beEfiIlmorsStTvVwW] [args]] ([+opt[=arg] ...] | {crs}) file ...

invproj [-beEfiIlmorsStTvVwW] [args]] ([+opt[=arg] ...] | {crs}) file ...

DESCRIPTION

proj et invproj effectuent respectivement la conversion directe et inverse de données cartographiques vers ou à partir de données cartésiennes avec une large gamme de fonctions de projection sélectionnables.

invproj peut ne pas être disponible sur toutes les plateformes ; dans ce cas, utilisez proj -I à la place.

Les paramètres de contrôle suivants peuvent apparaître dans n'importe quel ordre

-b
Option spéciale pour l'entrée et la sortie de données de coordonnées binaires via l'entrée et la sortie standard. Les données sont supposées être en mots flottants double précision du système. Cette option doit être utilisée lorsque proj est un processus enfant et permet de contourner les opérations de formatage.
-d <n>

Ajouté dans la version 5.2.0 : Spécifie le nombre de décimales vers lesquelles arrondir la sortie.

-i
Sélectionne uniquement l'entrée binaire (voir -b).
-I
Méthode alternative pour spécifier la projection inverse. Redondant lorsqu'il est utilisé avec invproj.
-o
Sélectionne uniquement la sortie binaire (voir -b).
-t<a>
Où a spécifie un caractère utilisé comme premier caractère pour indiquer une ligne de contrôle qui sera transmise sans traitement. Cette option est applicable uniquement aux entrées ASCII. (# est la valeur par défaut).
-e <string>
Où string est une chaîne de caractères arbitraire à afficher en cas d'erreur détectée lors des transformations de données. La valeur par défaut est une chaîne de trois caractères : *\t*. Notez que si les options -b, -i ou -o sont utilisées, une erreur est renvoyée sous forme de valeur HUGE_VAL pour les deux valeurs de retour.
-E
Force la copie des coordonnées d'entrée sur la ligne de sortie avant l'impression des valeurs converties.
-l<[=id]>
Liste les identifiants de projection qui peuvent être sélectionnés avec +proj. proj -l=id donne une description détaillée de la projection id, par exemple proj -l=merc.
-lp
Liste de tous les identifiants de projection utilisables avec le paramètre +proj. Équivalent à proj -l.
-lP
Description détaillée de toutes les projections utilisables avec le paramètre +proj.
-le
Liste de tous les ellipsoïdes qui peuvent être sélectionnés avec les paramètres +ellps.
-lu
Liste de toutes les unités de distance qui peuvent être sélectionnées avec le paramètre +units.
-r
Cette option inverse l'ordre des entrées attendues, passant de longitude-latitude ou x-y à latitude-longitude ou y-x.
-s
Cette option inverse l'ordre de la sortie, passant de x-y ou longitude-latitude à y-x ou latitude-longitude.
-S
Force l'estimation des facteurs d'échelle méridien et parallèle, du facteur d'échelle de surface et de la distorsion angulaire, ainsi que des facteurs d'échelle maximum et minimum, qui sont listés entre <> pour chaque point d'entrée. Pour les projections conformes, les facteurs d'échelle méridien et parallèle seront égaux et la distorsion angulaire nulle. Les projections équivalentes auront un facteur de surface de 1.
-m <mult>
Les données cartésiennes peuvent être mises à l'échelle par le paramètre mult. Lors du traitement des données en mode de projection directe, les valeurs de sortie cartésiennes sont multipliées par mult, sinon les valeurs cartésiennes d'entrée sont divisées par mult avant la projection inverse. Si les deux premiers caractères de mult sont 1/ ou 1:, alors la valeur réciproque de mult est employée.
-f <format>
Où format est une chaîne de format printf pour contrôler la forme des valeurs de sortie. Pour les projections inverses, la sortie sera en degrés lorsque cette option est employée. Le format par défaut est "%.2f" pour la projection directe et DMS pour l'inverse.
-w<n>
Où n est le nombre de décimales fractionnaires significatives à utiliser pour la sortie des secondes (lorsque l'option n'est pas spécifiée, -w3 est supposé).
-W<n>
Où n est le nombre de décimales fractionnaires significatives à utiliser pour la sortie des secondes. Lorsque -W est employé, les champs seront de largeur constante avec des zéros initiaux.
-v
Affiche la liste des paramètres de contrôle cartographiques testés et utilisés par le programme avant les données d'entrée.
-V
Cette option affiche une liste annotée et détaillée des caractéristiques du point projeté. -v est implicite avec cette option.

Les arguments de ligne de commande +opt sont associés aux paramètres cartographiques. Des paramètres de contrôle de projection supplémentaires peuvent être contenus dans deux fichiers de contrôle auxiliaires : le premier est référencé éventuellement avec +init=file:id et le second est toujours traité après le nom de la projection établi à partir de la ligne de commande ou du contenu du fichier +init. Le paramètre d'environnement PROJ_DATA établit le répertoire par défaut pour une référence de fichier sans chemin absolu. Il est également utilisé pour les fichiers de support comme les fichiers de décalage de datum.

Ajouté dans la version 9.3.0 : {crs} est une des possibilités acceptées par :c:proj_create(), à condition qu'il exprime un SCR projeté, comme une chaîne WKT, un code objet (comme "EPSG:32632" une chaîne PROJJSON, etc. La projection calculée sera celle de la projection de carte implicite par la transformation du SCR géographique de base du SCR projeté vers le SCR projeté.

Un ou plusieurs fichiers (traités de gauche à droite) spécifient la source des données à convertir. Un - spécifiera l'emplacement de traitement de l'entrée standard. Si aucun fichier n'est spécifié, l'entrée est supposée provenir de stdin. Pour les données d'entrée ASCII, les deux valeurs de données doivent se trouver dans les deux premiers champs séparés par des espaces blancs et lorsque l'entrée et la sortie sont ASCII, toutes les parties finales de la ligne d'entrée sont ajoutées à la ligne de sortie.

Les données géographiques d'entrée (longitude et latitude) doivent être au format DMS ou degrés décimaux, et les données cartésiennes d'entrée doivent être dans des unités cohérentes avec les unités du demi-grand axe de l'ellipsoïde ou du rayon de la sphère. Les coordonnées géographiques de sortie seront en DMS (si le commutateur -w n'est pas utilisé) et précises à 0.001" avec suppression des champs minutes-secondes nuls et finaux.

PROJ

système de projection cartographique géodésique

NOM

proj

SYNOPIS

proj [OPTION]... [+PROJ] [+ELLPS] [+UNITS] [+TYPE] [+AREA] [+R] [+I] [+ON_0] [+ES_0]

DESCRIPTION

Le programme proj peut être utilisé pour transformer des coordonnées d'un système de référence géodésique à un autre. Les systèmes de référence géodésique sont définis dans des fichiers de grille de transformation, fournis avec la distribution PROJ.

Le paramètre obligatoire +proj spécifie le système de coordonnées de destination. Les autres paramètres définissent le système de coordonnées source, s'il n'est pas spécifié dans le fichier de grille ou si une transformation spécifique est souhaitée.

Les coordonnées sont généralement spécifiées en entrée sous forme d'une liste de longitude, latitude (ou est, nord). Les coordonnées d'entrée peuvent être spécifiées sur la ligne de commande, via un fichier, ou via l'entrée standard.

Les coordonnées de sortie sont généralement en (est, nord) ou (longitude, latitude), selon le système de coordonnées de destination.

EXEMPLE

proj +proj=utm +zone=12 -r <<EOF
45d15'33.1" 111.5W
45d15.551666667N -111d30
+45.25919444444 111d30'000w
EOF

effectuera une projection UTM de la zone 12. Le défaut +ellps=GRS80 est utilisé car aucun +ellps n'a été spécifié. Les valeurs géographiques de cet exemple sont équivalentes et sont destinées à illustrer différentes formes d'entrée DMS. Les données de sortie x-y apparaîtront sur trois lignes de :

460770.43     5011865.86

Cet autre exemple :

proj EPSG:6421 -V <<EOF
-120 35.8
EOF

effectuera la projection des coordonnées de « NAD83(2011) / California zone 4 » (EPSG:6421) vers son système géographique, « NAD83(2011) », montrant la liste annotée développée. La sortie apparaîtra comme suit :

AUTRES PROGRAMMES

Le programme proj est limité à la conversion entre coordonnées géographiques et projetées au sein d'un même datum.

Le programme cs2cs fonctionne de manière similaire, mais permet la translation entre toute paire de systèmes de coordonnées de référence définissables, y compris la prise en charge de la translation de datum.
