proc_pid_seccomp(5) Manuel des formats de fichiers proc_pid_seccomp(5)

NOM

/proc/pid/seccomp - mode de calcul sécurisé

DESCRIPTION

/proc/pid/seccomp (Linux 2.6.12 à Linux 2.6.22)
Ce fichier peut être utilisé pour lire et modifier le paramètre du mode de calcul sécurisé (seccomp) du processus. Il contient la valeur 0 si le processus n'est pas en mode seccomp, et 1 s'il est en mode seccomp strict (voir seccomp(2)). Écrire 1 dans ce fichier place le processus de manière irréversible en mode seccomp strict. (Les tentatives ultérieures d'écriture dans le fichier échoueront avec l'erreur EPERM.)
Dans Linux 2.6.23, ce fichier a disparu, remplacé par les opérations PR_GET_SECCOMP et PR_SET_SECCOMP de prctl(2) (et plus tard par seccomp(2) et le champ Seccomp dans /proc/pid/status).
