process-keyring(7) Manuel d'informations diverses process-keyring(7)

NOM

process-keyring - Trousseau de clés partagé par processus

DESCRIPTION

Le trousseau de clés de processus est un trousseau de clés utilisé pour ancrer des clés pour le compte d'un processus. Il n'est créé que lorsqu'un processus le demande. Le trousseau de clés de processus porte le nom (description) _pid.

Une valeur spéciale de numéro de série, KEY_SPEC_PROCESS_KEYRING, est définie et peut être utilisée à la place du numéro de série réel du trousseau de clés de processus de l'appelant.

Depuis l'utilitaire keyctl(1), '@p' peut être utilisé à la place d'un ID de clé numérique de la même manière, mais comme keyctl(1) est un programme exécuté après un fork, cela n'a aucune utilité.

Un thread créé en utilisant le drapeau clone(2) CLONE_THREAD a le même trousseau de clés de processus que l'appelant de clone(2). Lorsqu'un nouveau processus est créé en utilisant fork(), il n'a initialement pas de trousseau de clés de processus. Le trousseau de clés d'un processus est effacé lors de execve(2). Le trousseau de clés de processus est détruit lorsque le dernier thread qui y fait référence se termine.

Si un processus n'a pas de trousseau de clés de processus lorsqu'il est accédé, alors le trousseau de clés de processus sera créé si le trousseau doit être modifié ; sinon, l'erreur ENOKEY en résulte.
