PRLIMIT(1) Commandes utilisateur PRLIMIT(1)

NOM

prlimit - obtenir et définir les limites de ressources d'un processus

SYNTAXE

prlimit [options] [--ressource[=limites]] [--pid PID]

prlimit [options] [--ressource[=limites]] commande [argument...]

DESCRIPTION

Étant donné un identifiant de processus et une ou plusieurs ressources, prlimit tente de récupérer et/ou de modifier les limites.

Lorsque commande est donnée, prlimit exécutera cette commande avec les arguments spécifiés.

Le paramètre limites est composé d'une valeur douce et d'une valeur dure, séparées par deux-points (:), afin de modifier les valeurs existantes. Si aucune limites n'est donnée, prlimit affichera les valeurs actuelles. Si l'une des valeurs n'est pas fournie, alors celle qui existe sera utilisée. Pour spécifier la limite illimitée ou infinie (RLIM_INFINITY), la chaîne -1 ou 'unlimited' peut être passée.

En raison de la nature des limites, la limite douce doit être inférieure ou égale à la limite haute (également appelée plafond). Pour voir toutes les limites de ressources disponibles, référez-vous à la section OPTIONS DE RESSOURCES.

•douce:dure Spécifie les deux limites.
•douce: Spécifie uniquement la limite douce.
•:dure Spécifie uniquement la limite dure.
•valeur Spécifie les deux limites à la même valeur.

OPTIONS GÉNÉRALES

--noheadings

Ne pas imprimer de ligne d'en-tête.

-o, --output liste

Définit les colonnes de sortie à utiliser. Si aucun arrangement de sortie n'est spécifié, alors un ensemble par défaut est utilisé. Utilisez --help pour obtenir une liste de toutes les colonnes supportées.

-p, --pid PID

Spécifie l'identifiant du processus. Sans cette option (et sans commande), le processus en cours sera utilisé.

--raw

Utilise le format de sortie brut.

--verbose

Mode verbeux.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

OPTIONS DE RESSOURCES

-c, --core[=limites]

Taille maximale d'un fichier core.

-d, --data[=limites]

Taille maximale des données.

-e, --nice[=limites]

Priorité nice maximale autorisée pour l'augmentation.

-f, --fsize[=limites]

Taille maximale de fichier.

-i, --sigpending[=limites]

Nombre maximal de signaux en attente.

-l, --memlock[=limites]

Espace d'adressage mémoire maximal verrouillé.

-m, --rss[=limites]

Taille maximale de l'ensemble résident (RSS).

-n, --nofile[=limites]

Nombre maximal de fichiers ouverts.

-q, --msgqueue[=limites]

Nombre maximal d'octets dans les files de messages POSIX.

-r, --rtprio[=limites]

Priorité temps réel maximale.

-s, --stack[=limites]

Taille maximale de la pile.

-t, --cpu[=limites]

Temps CPU, en secondes.

-u, --nproc[=limites]

Nombre maximal de processus.

-v, --as[=limites]

Limite de l'espace d'adressage.

-x, --locks[=limites]

Nombre maximal de verrous de fichiers détenus.

-y, --rttime[=limites]

Délai d'attente pour les tâches temps réel.

NOTES

L'appel système prlimit(2) est supporté depuis Linux 2.6.36, les anciens noyaux feront échouer ce programme.

EXEMPLES

prlimit --pid 13134

Affiche les valeurs limites pour toutes les ressources actuelles.

prlimit --pid 13134 --rss --nofile=1024:4095

Affiche les limites de RSS et définit les limites douces et dures pour le nombre de fichiers ouverts à 1024 et 4095 respectivement.

prlimit --pid 13134 --nproc=512:

Modifie uniquement la limite douce pour le nombre de processus.

prlimit --pid $$ --nproc=unlimited

Définit pour le processus actuel les valeurs douces et plafond pour le nombre de processus à illimité.

prlimit --cpu=10 sort -u hugefile

Définit les limites douces et dures du temps CPU à dix secondes et exécute sort(1).
