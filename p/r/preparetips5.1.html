NOM

preparetips5
- extraire le texte d'un fichier de conseils (tips)

SYNOPSIS

preparetips5

DESCRIPTION

preparetips5 est un script pour extraire le texte d'un fichier de conseils (tips). Il génère le texte afin que xgettext puisse ajouter les conseils à un fichier PO. Les fichiers PO fournissent un format de chaîne lisible par l'homme, utilisé pour les traductions.

preparetips5 recherche le fichier de conseils sous le nom data/tips.
