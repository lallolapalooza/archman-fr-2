proc_pid_mounts(5) Manuel des formats de fichiers proc_pid_mounts(5)

NOM

/proc/pid/mounts - systèmes de fichiers montés

DESCRIPTION

/proc/pid/mounts (depuis Linux 2.4.19)
Ce fichier liste tous les systèmes de fichiers actuellement montés dans l'espace de noms de montage du processus (voir mount_namespaces(7)). Le format de ce fichier est documenté dans fstab(5).
Depuis Linux 2.6.15, ce fichier est interrogeable : après avoir ouvert le fichier en lecture, une modification de ce fichier (c'est-à-dire un montage ou démontage de système de fichiers) fait que select(2) marque le descripteur de fichier comme ayant une condition exceptionnelle, et poll(2) et epoll_wait(2) marquent le fichier comme ayant un événement prioritaire (POLLPRI). (Avant Linux 2.6.30, une modification de ce fichier était indiquée par le descripteur de fichier étant marqué comme lisible pour select(2), et étant marqué comme ayant une condition d'erreur pour poll(2) et epoll_wait(2).)
/proc/mounts
Avant Linux 2.4.19, ce fichier était une liste de tous les systèmes de fichiers actuellement montés sur le système. Avec l'introduction des espaces de noms de montage par processus en Linux 2.4.19 (voir mount_namespaces(7)), ce fichier est devenu un lien vers /proc/self/mounts, qui liste les montages de l'espace de noms de montage du propre processus. Le format de ce fichier est documenté dans fstab(5).
