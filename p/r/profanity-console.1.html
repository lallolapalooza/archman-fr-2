man(1) Client XMPP Profanity man(1)

NOM

/console

DESCRIPTION

Configure ce qui est affiché dans la fenêtre de console lors de la réception de messages. La valeur par défaut est réglée sur 'all' pour tous les types de messages.

SYNOPIS

/console chat all|first|none

/console muc all|first|mention|none

/console private all|first|none

ARGUMENTS

chat all

Indique tous les nouveaux messages de discussion dans la console.

chat first

Indique seulement le premier nouveau message par discussion dans la console.

chat none

N'affiche aucun nouveau message de discussion dans la fenêtre de console.

muc all

Indique tous les nouveaux messages de salle de discussion dans la console.

muc first

Indique seulement le premier nouveau message dans chaque salle dans la console.

muc mention

Indique seulement les messages dans lesquels vous avez été mentionné dans la console.

muc none

N'affiche aucun nouveau message de salle de discussion dans la fenêtre de console.

private all

Indique tous les nouveaux messages de salle privée dans la console.

private first

Indique seulement le premier message de salle privée dans la console.

private none

N'affiche aucun nouveau message de salle privée dans la fenêtre de console.
