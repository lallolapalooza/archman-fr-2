FBB::PrimeFactors(3bobcat) Factorisation en nombres premiers FBB::PrimeFactors(3bobcat)

NOM

FBB::PrimeFactors - Effectue la factorisation en nombres premiers de valeurs (BigInt)

SYNTAXE

#include <bobcat/primefactors>
Option de liaison : -lbobcat

DESCRIPTION

Les valeurs entières se divisent en deux catégories : les nombres premiers, dont les seuls diviseurs entiers sont leur propre valeur et 1, et les nombres composés, qui ont au moins un autre diviseur entier (nombre premier). Toutes les valeurs entières composées peuvent être factorisées comme le produit de nombres premiers. Par exemple, 6 peut être factorisé en 2 * 3 ; 8 peut être factorisé en 2 * 2 * 2. Trouver ces facteurs premiers est appelé la factorisation en nombres premiers, ou `factorisation première'. Lors de la factorisation d'une valeur, ses facteurs premiers peuvent parfois être utilisés de manière répétée comme diviseurs entiers : 8 est factorisé en pow(2, 3), et 36 est factorisé en

    36 = pow(2, 2) * pow(3, 2)

La classe FBB::PrimeFactors effectue la factorisation en nombres premiers de valeurs FBB::BigInt. Lors de la factorisation d'une valeur, les nombres premiers jusqu'à sqrt(valeur) doivent être disponibles, car les nombres premiers jusqu'à sqrt(valeur) peuvent être des facteurs de valeur. Actuellement, PrimeFactors utilise le crible d'Ératosthène pour trouver ces nombres premiers. Pour trouver le prochain nombre premier après dernierPremier, le crible d'Ératosthène doit être utilisé de manière répétée pour dernierPremier += 2 jusqu'à ce que dernierPremier soit premier. Une fois déterminés, les nombres premiers peuvent bien sûr être utilisés directement pour déterminer le prochain nombre premier ou pour factoriser une valeur entière. Pour accélérer la factorisation en nombres premiers et le crible d'Ératosthène, PrimeFactors enregistre tous ses nombres premiers calculés soit dans un std::vector, soit dans un fichier. Une fois déterminés, ces nombres premiers peuvent être réutilisés lors de la factorisation de la prochaine valeur entière.

Après avoir factorisé une valeur entière, ses facteurs premiers et leurs puissances associées sont mis à disposition dans un vecteur de structures (PrimeFactors::PrimePower), contenant les facteurs premiers triés de la valeur et leurs puissances associées.

CONSTRUCTEURS

o
PrimeFactors(BigIntVector &primes):
Les nombres premiers qui ont été déterminés lors de la factorisation de valeurs sont collectés dans le BigIntVector passé en argument à ce constructeur.
Initialement, le BigIntVector passé en argument peut être vide ou peut contenir au moins deux nombres premiers (qui doivent être, respectivement, 2 et 3). Les nombres premiers dans primes doivent être triés. Le constructeur ne vérifie pas si les nombres premiers sont effectivement triés, mais s'il contient des nombres premiers, il vérifie si les deux premiers nombres premiers sont bien 2 et 3. Une FBB::Exception est levée si cette condition n'est pas remplie.
Pendant la factorisation des nombres, de nouveaux nombres premiers peuvent être ajoutés à primes, et primes peut être réutilisé par d'autres objets PrimeFactors.
o
PrimeFactors(std::string const &name = "~/.primes", size_t blockSize = 1000):
Les nombres premiers qui sont déterminés lors de la factorisation de valeurs sont collectés dans un flux dont le nom est passé en argument à ce constructeur. Par défaut, ~/.primes est utilisé. Si name commence par `~/', alors cette chaîne est remplacée par le répertoire personnel de l'utilisateur.
Les nombres premiers sont lus depuis le flux nommé par blocs d'au plus blockSize, et les nouveaux nombres premiers sont vidés vers ce flux une fois blockSize nouveaux nombres premiers générés ou lorsque l'objet PrimeFactors (c'est-à-dire le dernier objet PrimeFactors partageant le flux) cesse d'exister.
Si le flux n'existe pas encore, il est créé par PrimeFactors. Le flux peut être vide, ou il doit contenir des nombres premiers triés et délimités par des espaces blancs (insérés sous forme de valeurs BigInt hexadécimales). Les deux premiers nombres premiers de ce fichier doivent être, respectivement, 2 et 3. Le constructeur ne vérifie pas si les nombres premiers sont effectivement triés, mais si le flux contient des nombres premiers, il vérifie si les deux premiers nombres premiers sont bien 2 et 3. Une FBB::Exception est levée si cette condition n'est pas remplie.
Pendant la factorisation des nombres, de nouveaux nombres premiers peuvent être ajoutés au flux, et le flux peut être réutilisé par d'autres objets PrimeFactors.

Les constructeurs et opérateurs d'affectation par copie et déplacement sont disponibles.

Les objets FBB::PrimeFactor créés en utilisant le constructeur de copie ou recevant leurs valeurs via l'opérateur d'affectation par copie partagent le périphérique de stockage des nombres premiers (le BigIntVector ou le flux contenant les nombres premiers) avec leurs objets source.

FONCTION MEMBRE

o
Factors const &factorize(BigInt const &value):
Les facteurs premiers de value sont déterminés et retournés dans le vecteur PrimeFactors::Factors. Pendant que les facteurs premiers de value sont déterminés, de nouveaux nombres premiers peuvent être ajoutés au BigIntVector ou au flux passé à l'objet PrimeFactors. Les éléments de PrimeFactors::Factors sont triés par leurs nombres premiers. Le premier élément contient le plus petit facteur premier de la valeur.

EXEMPLE

#include <iostream>
#include <bobcat/primefactors>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    PrimeFactors pf1("/tmp/primes");
    PrimeFactors::Factors const *factors = &pf1.factorize(stoull(argv[1]));
    cout << "Utilisation de /tmp/primes:\n";
    for (auto &factor: *factors)
        cout << factor.prime << "**" << factor.power << ’ ’;
    vector<BigInt> primes;
    PrimeFactors pf2(primes);
    factors = &pf2.factorize(stoull(argv[1]));
    cout << "\n"
            "Utilisation de BigIntVector:\n";
    for (auto &factor: *factors)
        cout << factor.prime << "**" << factor.power << ’ ’;
    cout << "\n"
            "Nombres premiers collectés: ";
    for (auto &prime: primes)
        cout << prime << ’ ’;
    cout << ’\n’;
}

Si ce programme est exécuté avec l'argument 1950, il produit la sortie suivante :

    Utilisation de /tmp/primes:
    2**1 3**1 5**2 13**1
    Utilisation de BigIntVector:
    2**1 3**1 5**2 13**1
    Nombres premiers collectés: 2 3 5 7 11 13

NOM

libbobcat-dev — bibliothèques et fichiers d'en-tête Bobcat

DESCRIPTION

Ce paquet contient les fichiers d'en-tête C++ nécessaires pour compiler des programmes qui utilisent la bibliothèque Bobcat.

Les fichiers d'en-tête sont généralement installés dans /usr/include/bobcat/.

La bibliothèque Bobcat est une collection de classes et de modèles C++ de bas niveau, conçue pour être légère et efficace. Elle fournit des fonctionnalités telles que la gestion de chaînes de caractères, la gestion de collections, la gestion des flux, et bien plus encore.
