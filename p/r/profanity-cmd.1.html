NOM

/cmd

DESCRIPTION

Exécute des commandes ad hoc.

SYNTAXE

/cmd list [<jid>]

/cmd exec <commande> [<jid>]

ARGUMENTS

list

Liste les commandes ad hoc prises en charge.

exec <commande>

Exécute une commande.

EXEMPLES

/cmd list

/cmd exec ping
