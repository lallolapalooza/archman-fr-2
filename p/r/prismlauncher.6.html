NOM

prismlauncher - un lanceur et gestionnaire d'instances pour Minecraft.

SYNOPIS

prismlauncher [OPTIONS...]

DESCRIPTION

Prism Launcher est un lanceur personnalisé pour Minecraft qui vous permet de gérer facilement plusieurs installations de Minecraft à la fois. Il vous permet également d'installer et de supprimer facilement des mods en les faisant simplement glisser-déposer. Voici les fonctionnalités actuelles de Prism Launcher.

OPTIONS

-d, --dir=RÉPERTOIRE

Utilise RÉPERTOIRE comme répertoire racine de Prism Launcher.

-l, --launch=ID_INSTANCE

Lance l'instance spécifiée par ID_INSTANCE.

--show=ID_INSTANCE

Affiche la fenêtre de configuration de l'instance spécifiée par ID_INSTANCE.

--alive

Écrit un petit fichier 'live.check' après le démarrage de Prism Launcher.

-h, --help

Affiche le texte d'aide et quitte.

-v, --version

Affiche la version du programme et quitte.

-a, --profile=PROFIL

Utilise le compte spécifié par PROFIL (valide uniquement en combinaison avec --launch).

ENVIRONNEMENT

Le comportement du lanceur peut être personnalisé par les variables d'environnement suivantes, en plus d'autres variables Qt courantes :

QT_LOGGING_RULES

Spécifie quelles catégories de journalisation sont affichées dans les journaux. On peut activer/désactiver plusieurs catégories en les séparant par un point-virgule (;).

La syntaxe spécifique, et les alternatives à ce réglage, peuvent être trouvées sur https://doc.qt.io/qt-6/qloggingcategory.html#configuring-categories.

QT_MESSAGE_PATTERN

Spécifie le format dans lequel la sortie de la console sera affichée.

Les options disponibles, ainsi que la syntaxe, peuvent être consultées sur https://doc.qt.io/qt-6/qtglobal.html#qSetMessagePattern.
