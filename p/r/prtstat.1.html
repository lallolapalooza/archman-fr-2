PRTSTAT(1) Commandes utilisateur PRTSTAT(1)

NOM

prtstat - afficher les statistiques d'un processus

SYNTAXE

prtstat [-r|--raw] pid
prtstat -V|--version

DESCRIPTION

prtstat affiche les statistiques du processus spécifié. Ces informations proviennent du fichier /proc/pid/stat.

OPTIONS

-r, --raw
Afficher les informations au format brut.
-V, --version
Afficher les informations de version pour prtstat.

FICHIERS

/proc/pid/stat
Source des informations utilisées par prtstat.
