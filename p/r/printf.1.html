PRINTF(1) Commandes utilisateur PRINTF(1)

NOM

printf - formater et afficher des données

SYNTAXE

printf FORMAT [ARGUMENT]...
printf OPTION

DESCRIPTION

Affiche ARGUMENT(s) selon FORMAT, ou exécute selon OPTION :

--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte

FORMAT contrôle la sortie comme dans printf de C. Les séquences interprétées sont :

\"
guillemet double
\\
antislash
\a
sonnerie (BEL)
\b
retour arrière
\c
ne produit aucune sortie supplémentaire
\e
échappement
\f
saut de page
\n
nouvelle ligne
\r
retour chariot
\t
tabulation horizontale
\v
tabulation verticale
\NNN
octet avec la valeur octale NNN (1 à 3 chiffres)
\xHH
octet avec la valeur hexadécimale HH (1 à 2 chiffres)
\uHHHH
caractère Unicode (ISO/IEC 10646) avec la valeur hexadécimale HHHH (4 chiffres)
\UHHHHHHHH
caractère Unicode avec la valeur hexadécimale HHHHHHHH (8 chiffres)
%%
un seul %
%b
ARGUMENT comme une chaîne avec les échappements '\' interprétés, sauf que les échappements octaux doivent avoir un 0 préfixé comme \0NNN
%q
ARGUMENT est affiché dans un format qui peut être réutilisé comme entrée du shell, en échappant les caractères non imprimables avec la syntaxe POSIX $''

et toutes les spécifications de format C se terminant par l'un des caractères diouxXfeEgGcs, les ARGUMENTs étant d'abord convertis dans le type approprié. Les largeurs variables sont gérées.

Votre shell peut avoir sa propre version de printf, qui supplante généralement la version décrite ici. Veuillez vous référer à la documentation de votre shell pour les détails sur les options qu'il prend en charge.
