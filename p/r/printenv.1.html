PRINTENV(1) Commandes utilisateur PRINTENV(1)

NOM

printenv - affiche tout ou partie de l'environnement

SYNTAXE

printenv [OPTION] [VARIABLE]...

DESCRIPTION

Affiche les valeurs de la ou des Variables d'environnement spécifiées. Si aucune VARIABLE n'est spécifiée, affiche les paires nom et valeur pour toutes.

-0, --null
termine chaque ligne de sortie par un caractère NUL, pas une nouvelle ligne.
--help
affiche cette aide et quitte.
--version
affiche les informations de version et quitte.

Votre shell peut avoir sa propre version de printenv, qui remplace généralement la version décrite ici. Veuillez consulter la documentation de votre shell pour les détails sur les options qu'elle prend en charge.
