proc_pid_io(5) Manuel des formats de fichiers proc_pid_io(5)

NOM

/proc/pid/io - statistiques d'E/S

DESCRIPTION

/proc/pid/io (depuis Linux 2.6.20)
Ce fichier contient les statistiques d'E/S pour le processus et ses enfants attendus, par exemple :

# cat /proc/3828/io
rchar: 323934931
wchar: 323929600
syscr: 632687
syscw: 632675
read_bytes: 0
write_bytes: 323932160
cancelled_write_bytes: 0

Les champs sont les suivants :
rchar : octets lus
Le nombre d'octets retournés par les appels système read(2) et similaires réussis.
wchar : octets écrits
Le nombre d'octets retournés par les appels système write(2) et similaires réussis.
syscr : appels système de lecture
Le nombre d'appels système de « lecture de fichier » — ceux de la famille read(2), sendfile(2), copy_file_range(2), et ioctl(2) BTRFS_IOC_ENCODED_READ[_32] (y compris lorsqu'ils sont invoqués par le noyau dans le cadre d'autres appels système).
syscw : appels système d'écriture
Le nombre d'appels système d'« écriture de fichier » — ceux de la famille write(2), sendfile(2), copy_file_range(2), et ioctl(2) BTRFS_IOC_ENCODED_WRITE[_32] (y compris lorsqu'ils sont invoqués par le noyau dans le cadre d'autres appels système).
read_bytes : octets lus
Le nombre d'octets réellement récupérés de la couche de stockage. Ceci est précis pour les systèmes de fichiers basés sur des blocs.
write_bytes : octets écrits
Le nombre d'octets réellement envoyés à la couche de stockage.
cancelled_write_bytes :
Les statistiques ci-dessus ne tiennent pas compte de la troncature : si un processus écrit 1 Mo dans un fichier régulier puis le supprime, ce Mo ne sera pas écrit, mais aura néanmoins été comptabilisé comme une écriture de 1 Mo. Ce champ représente le nombre d'octets « économisés » par la sortie d'E/S. Cela peut conduire à des E/S négatives si des caches salis par un autre processus sont tronqués. cancelled_write_bytes s'applique aux E/S déjà comptabilisées dans write_bytes.
L'autorisation d'accéder à ce fichier est régie par le mode d'accès ptrace(2) PTRACE_MODE_READ_FSCREDS.

POINTS ATTENTION

Ces compteurs ne sont pas atomiques : sur les systèmes où les opérations sur les entiers 64 bits peuvent être interrompues, un compteur pourrait être mis à jour simultanément avec une lecture, produisant une valeur intermédiaire incorrecte.

VOIR AUSSI

getrusage(2), proc(5)
