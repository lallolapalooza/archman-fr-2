man(1) Client XMPP Profanity man(1)

NOM

/resource

DESCRIPTION

Permet de remplacer la ressource de session de chat et de gérer les paramètres d'affichage des ressources.

SYNTAXE

/resource set <ressource>

/resource off

/resource title on|off

/resource message on|off

ARGUMENTS

set <ressource>

Définit la ressource à laquelle les messages seront envoyés.

off

Laisse le serveur choisir la ressource vers laquelle acheminer les messages.

title on|off

Affiche ou masque la ressource actuelle dans la barre de titre.

message on|off

Affiche ou masque la ressource lors de l'affichage d'un message entrant.
