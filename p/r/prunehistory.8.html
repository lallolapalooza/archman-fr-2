NOM

prunehistory - Supprime des jetons du fichier d'historique Usenet

SYNTAXE

prunehistory [-p] [-f nom_fichier]

DESCRIPTION

prunehistory modifie un fichier texte au format history(5) pour "supprimer" un ensemble de jetons. Les jetons sont supprimés en les écrasant avec des espaces, de sorte que la taille et la position des entrées suivantes ne changent pas. Cela a un effet similaire à l'expiration de l'article, car il est toujours mentionné dans la base de données d'historique mais ne peut pas être récupéré.

prunehistory lit l'entrée standard. L'entrée est traitée comme un ensemble de lignes. Les lignes vides et les lignes commençant par un signe de numération ("#") sont ignorées. Toutes les autres lignes doivent contenir un identifiant de message suivi de zéro ou plusieurs autres champs (qui sont ignorés). L'identifiant du message est utilisé comme clé dbz pour obtenir un décalage dans le fichier texte. Comme innd ne fait qu'ajouter au fichier texte, prunehistory n'a pas besoin d'interagir avec lui.

OPTIONS

-p
prunehistory se plaindra normalement des lignes qui ne suivent pas le format correct. Si l'option -p est utilisée, le programme affichera silencieusement toutes les lignes invalides sur sa sortie standard. (Les lignes vides et les lignes de commentaire sont également transmises.)
-f nom_fichier
Le nom par défaut du fichier history est pathdb/history ; pour spécifier un nom différent, utilisez l'option -f.
