PREZIP-BIN(1) Manuel utilisateur abrégé d'Aspell PREZIP-BIN(1)

NOM

prezip-bin - compresseur/décompresseur de listes de mots préfixées compressées par delta

SYNTAXE

prezip-bin [ -V | -d | -z ]

DESCRIPTION

prezip-bin compresse/décompresse les listes de mots triées depuis l'entrée standard vers la sortie standard.

Prezip-bin est similaire à word-list-compress(1) mais il permet un jeu de caractères plus large {0x00...0x09, 0x0B, 0x0C, 0x0E...0xFF} et des mots multiples de plus de 255 caractères. Il peut aussi décompresser des fichiers compatibles avec word-list-compress(1).

COMMANDES

Prezip-bin n'accepte qu'une seule de ces commandes.

-V
Affiche le numéro de version de prezip-bin sur la sortie standard.
-d
Lit une liste de mots compressée depuis l'entrée standard et la décompresse sur la sortie standard. Il peut s'agir d'un fichier compressé par word-list-compress(1) ou par prezip-bin.
-z
Lit une liste de mots binaire depuis l'entrée standard et la compresse sur la sortie standard.

EXEMPLES

prezip-bin -d <wordlist.cwl >wordlist.txt
Décompresse le fichier wordlist.cwl dans le fichier texte wordlist.txt.
prezip-bin -z <wordlist.txt >wordlist.pz 2>errors.txt
Compresse wordlist.txt dans le fichier binaire wordlist.pz et redirige tous les messages d'erreur vers un fichier texte nommé errors.txt.
LC_COLLATE=C sort -u <wordlist.txt | prezip-bin -z >wordlist.pz
Trie une liste de mots, puis la redirige vers prezip-bin pour créer un fichier binaire compressé wordlist.pz.
prezip-bin -d <words.pz | aspell create master ./words.rws
Décompresse une liste de mots, puis la redirige vers aspell(1) pour créer une liste orthographique. Veuillez consulter le manuel d'information de aspell(1) pour une utilisation et des options correctes.

CONSEILS

Prezip-bin est plus efficace avec les listes de mots triées. Ce n'est pas un programme de compression à usage général car les fichiers résultants peuvent en fait augmenter de taille.

Contrairement à word-list-compress(1), si votre liste de mots contient des espaces blancs en début ou en fin de ligne à des fins de formatage, vous devriez les supprimer avant de compresser votre liste à l'aide de prezip-bin -z, sinon ces espaces seront inclus dans la sortie binaire compressée.

DIAGNOSTICS

Prezip-bin se termine normalement avec un code de retour de 0. En cas d'erreur, un message est envoyé à la sortie d'erreur standard (stderr), et prezip-bin se termine avec une valeur de retour non nulle. Les messages d'erreur sont listés ci-dessous :

(affichage du message d'aide/utilisation)
Une commande inconnue a été donnée sur la ligne de commande, donc prezip-bin affiche un message d'utilisation sur la sortie d'erreur standard.
format inconnu
Le fichier d'entrée ne semble pas être dans un format attendu, ou pourrait éventuellement être dans un format plus avancé. Le fichier de sortie sera vide.
entrée corrompue
Ceci est uniquement pour la commande de décompression -d. Le fichier d'entrée semblait être dans un format correct, mais quelque chose semble maintenant erroné. Il peut y avoir des données valides en sortie, mais en raison de la corruption de l'entrée, le reste du fichier ne peut pas être achevé.
fin inattendue
Le fichier d'entrée semblait correct mais s'est terminé plus tôt que prévu, par conséquent, le fichier de sortie n'est pas complet.
