NOM

prepmx - préprocesseur pour PMX, programme facile de composition musicale

SYNTAXE

prepmx [options] nom_travail [rep_sortir/] [fichier_style]

DESCRIPTION

M-Tx est un langage préprocesseur facile à utiliser pour le programme de composition musicale PMX, destiné aux personnes qui ne sont pas expertes. Pour un exemple simple, regardez l'exemple suivant :


c2+ e4 g | b4d- c1 d c2 |
c8 g+ e g c- g+ e g | d g f g c- g+ e g |

Pour une référence de la syntaxe, veuillez consulter le manuel M-Tx écrit par Dirk Laurie, le créateur du langage M-Tx et l'auteur de prepmx(1), son utilitaire en ligne de commande.

prepmx traite le fichier nom_travail.mtx pour générer nom_travail.pmx. Vous pouvez ensuite traiter ce fichier en utilisant la commande pmxab(1), qui est un préprocesseur pour MusiXTeX.

rep_sortir/ est le répertoire où `pmx' placera le fichier .tex final. Notez que la barre oblique finale est obligatoire. Vous pouvez fournir un fichier_style pour M-Tx. S'il est omis, le fichier `mtxstyle.txt' dans le répertoire courant est utilisé, s'il existe.

OPTIONS

Les options peuvent également être spécifiées dans une ligne `Options:' dans le préambule, qui a la priorité sur la ligne de commande.

-b
désactiver unbeamVocal
-c
désactiver doChords
-D
activer debugMode
-f
activer solfaNoteNames
-i
activer ignoreErrors
-m
désactiver doLyrics
-n
activer instrumentNames
-t
désactiver doUptext
-u
désactiver uptextOnRests
-v
activer beVerbose
-w
activer pedanticWarnings
-n
sélectionner le Cas Spécial n
-H
afficher le statut activé de toutes les options

STATUT DE SORTIE

Si aucune erreur n'a été trouvée, prepmx se termine avec le code de retour 0. En cas d'erreur, le numéro de ligne du fichier traité est renvoyé. Cela ne correspond pas toujours à la ligne contenant l'erreur réelle. Un statut de retour de 10000 signifie que le fichier d'entrée était vide ou n'a pas pu être ouvert.
