NOM

projid - Fichier de mappage des noms de projet

DESCRIPTION

Le fichier /etc/projid fournit un mappage entre les identifiants de projet numériques et un nom simple lisible par l'homme (relation similaire à celle qui existe entre les noms d'utilisateur et les uid). Son format est simplement :

# les commentaires sont préfixés par un dièse
# ...
cage:10
logfiles:42

Ce fichier est facultatif ; si un identifiant de projet ne peut pas être mappé à un nom, il sera analysé et affiché comme une valeur numérique.

VOIR AUSSI

xfs_quota(8), xfsctl(3), projects(5).
