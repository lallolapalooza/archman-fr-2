NOM

provider-skeymgmt - Fonctions de bibliothèque SKEY MGMT <-> fournisseur

SYNTAXE

#include <openssl/core_dispatch.h>
/*
 * Aucune de ces fonctions n'est réelle, mais elles sont affichées comme telles pour
 * les signatures de fonctions qui sont proposées sous forme de pointeurs de fonction
 * dans les tableaux OSSL_DISPATCH.
 */
/* Destruction d'objet clé */
void OSSL_FUNC_skeymgmt_free(void *keydata);
/* Fonctions d'importation et d'exportation d'objet clé */
void *OSSL_FUNC_skeymgmt_import(void *provctx, int selection,
                                const OSSL_PARAM params[]);
int OSSL_FUNC_skeymgmt_export(void *keydata, int selection,
                              OSSL_CALLBACK *param_cb, void *cbarg);
void *OSSL_FUNC_skeymgmt_generate(void *provctx,
                                  const OSSL_PARAM params[]);
const OSSL_PARAM *OSSL_FUNC_skeymgmt_gen_settable_params(void *provctx);
const OSSL_PARAM *OSSL_FUNC_skeymgmt_imp_settable_params(void *provctx);
const char *OSSL_FUNC_skeymgmt_get_key_id(void *keydata);

DESCRIPTION

L'opération SKEY MGMT n'a pas beaucoup de visibilité publique dans les bibliothèques OpenSSL ; il s'agit plutôt d'une opération interne conçue pour fonctionner avec des opérations utilisant des objets de clé symétrique opaques.

L'opération SKEY MGMT partage des connaissances avec les opérations avec lesquelles elle travaille, par conséquent, SKEY MGMT et les algorithmes qui l'utilisent doivent appartenir au même fournisseur. Les bibliothèques OpenSSL s'en assureront.

La responsabilité principale de l'opération SKEY MGMT est de contenir les données de clé côté fournisseur pour la structure EVP_SKEY de la bibliothèque OpenSSL.

Toutes les "fonctions" mentionnées ici sont transmises sous forme de pointeurs de fonction entre libcrypto et le fournisseur dans les tableaux OSSL_DISPATCH(3) via les tableaux OSSL_ALGORITHM(3) qui sont renvoyés par la fonction provider_query_operation() du fournisseur (voir "Fonctions du fournisseur" dans provider-base(7)).

Toutes ces "fonctions" ont un type de fonction correspondant nommé OSSL_FUNC_{name}_fn, et une fonction d'aide pour récupérer le pointeur de fonction d'un élément OSSL_DISPATCH(3) nommé OSSL_FUNC_{name}.

OSSL_DISPATCH(3) Les tableaux sont indexés par des nombres qui sont fournis sous forme de macros dans openssl-core_dispatch.h(7), comme suit :

OSSL_FUNC_skeymgmt_free                 OSSL_FUNC_SKEY MGMT_FREE
OSSL_FUNC_skeymgmt_import               OSSL_FUNC_SKEY MGMT_IMPORT
OSSL_FUNC_skeymgmt_export               OSSL_FUNC_SKEY MGMT_EXPORT
OSSL_FUNC_skeymgmt_generate             OSSL_FUNC_SKEY MGMT_GENERATE
OSSL_FUNC_skeymgmt_get_key_id           OSSL_FUNC_SKEY MGMT_GET_KEY_ID
OSSL_FUNC_skeymgmt_imp_settable_params  OSSL_FUNC_SKEY MGMT_IMP_SETTABLE_PARAMS
OSSL_FUNC_skeymgmt_gen_settable_params  OSSL_FUNC_SKEY MGMT_GEN_SETTABLE_PARAMS

La gestion SKEY MGMT est inspirée de KEY MGMT mais est plus simple.

Objets clés

Un objet clé est une collection de données pour une clé symétrique, et est représenté comme keydata dans ce manuel.

Le contenu exact d'un objet clé est défini par le fournisseur, et il est supposé que différentes opérations au sein d'un même fournisseur utilisent exactement la même structure pour représenter cette collection de données, de sorte que, par exemple, une clé créée à l'aide de l'interface SKEY MGMT puisse être transmise telle quelle à d'autres opérations du même fournisseur, telles que OSSL_FUNC_mac_init_opaque() (voir provider-mac(7)).

Avec la fonction d'exportation SKEY MGMT, il est possible de sélectionner un sous-ensemble spécifique de données à gérer, régi par les bits d'un indicateur selection. Les bits sont :

OSSL_SKEYMGMT_SELECT_SECRET_KEY
Indiquant que les octets bruts de la clé secrète dans un objet clé doivent être inclus.
OSSL_SKEY MGMT_SELECT_PARAMETERS
Indiquant que les paramètres d'un objet clé doivent être inclus.

Des bits de sélection combinés sont également définis pour une utilisation plus facile :

OSSL_SKEY MGMT_SELECT_ALL
Indiquant que tout dans un objet clé doit être inclus.

L'interprétation exacte de ces bits ou de leur combinaison est laissée à chaque fonction où un sélecteur peut être spécifié.

Fonction de destruction

OSSL_FUNC_skeymgmt_free() doit libérer le keydata transmis.

Fonctions d'importation et d'exportation d'objet clé

OSSL_FUNC_skeymgmt_import() doit importer des données dans keydata avec des valeurs prises dans le tableau OSSL_PARAM(3) params. Il alloue l'objet keydata (il n'y a pas de fonction d'allocation séparée).

OSSL_FUNC_skeymgmt_imp_settable_params() renvoie une liste de paramètres qui peuvent être fournis à la fonction OSSL_FUNC_skeymgmt_import().

OSSL_FUNC_skeymgmt_export() doit extraire les valeurs indiquées par selection de keydata, créer un tableau OSSL_PARAM(3) avec celles-ci et appeler param_cb avec ce tableau ainsi que le cbarg donné. Le tableau OSSL_PARAM(3) transmis est transitoire et est libéré lors du retour de param_cb.

Fonctions de génération d'objet clé

OSSL_FUNC_skeymgmt_generate() crée une nouvelle clé selon les valeurs prises dans le tableau OSSL_PARAM(3) params. Elle alloue l'objet keydata.

OSSL_FUNC_skeymgmt_gen_settable_params() renvoie une liste de paramètres qui peuvent être fournis à la fonction OSSL_FUNC_skeymgmt_generate().

Fonctions d'information sur les objets clés

OSSL_FUNC_skeymgmt_get_key_id() renvoie une chaîne terminée par un caractère nul identifiant la clé particulière. La chaîne renvoyée sera libérée par un appel à EVP_SKEY_free(), donc les appelants doivent la copier eux-mêmes s'ils souhaitent conserver la valeur au-delà de la durée de vie de la clé. Le but de cette fonction est de fournir une chaîne imprimable qui peut aider les utilisateurs à accéder à la clé spécifique. Le contenu de cette chaîne est spécifique au fournisseur.

Paramètres communs d'importation et d'exportation

Voir OSSL_PARAM(3) pour plus de détails sur la structure des paramètres.

Les paramètres d'information courants actuellement reconnus par les algorithmes skeymgmt intégrés sont les suivants :

"raw-bytes" (SKEY_PARAM_RAW_BYTES) <chaîne d'octets>
La valeur représente la clé symétrique sous forme de tableau d'octets.
"key-length" (SKEY_PARAM_KEY_LENGTH) <entier>
La valeur est la longueur en octets de la clé donnée.

VALEURS DE RETOUR

OSSL_FUNC_skeymgmt_import() et OSSL_FUNC_skeymgmt_generate() renvoient un pointeur vers un objet alloué en cas de succès et NULL en cas d'erreur.

OSSL_FUNC_skeymgmt_export() renvoie 1 en cas de succès ou 0 en cas d'erreur.

OSSL_FUNC_skeymgmt_get_key_id() renvoie un pointeur vers une chaîne terminée par 0 ou NULL.

OSSL_FUNC_skeymgmt_gen_settable_params() et OSSL_FUNC_skeymgmt_imp_settable_params() renvoient des références à un tableau de OSSL_PARAM qui peut être NULL s'il n'y a pas de paramètres configurables.
