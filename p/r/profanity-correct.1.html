profanity-correct(1)

Paquet: profanity

Licences: GPL3

man(1) Client XMPP Profanity man(1)

NOM

/correct

DESCRIPTION

Corriger et renvoyer le dernier message (XEP-0308). Utilisez la complétion par tabulation pour obtenir le dernier message envoyé. Pour plus d'informations sur la manière de configurer les corrections, consultez : /help correction.

SYNTAXE

/correct <message>

ARGUMENTS

message

Le message corrigé.
