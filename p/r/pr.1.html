PR(1) Commandes Utilisateur PR(1)

NOM

pr - convertir des fichiers texte pour l'impression

SYNTAXE

pr [OPTION]... [FICHIER]...

DESCRIPTION

Paginer ou coloniser FICHIER(s) pour l'impression.

Sans FICHIER, ou quand FICHIER est -, lire l'entrée standard.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

+PREMIERE_PAGE[:DERNIERE_PAGE], --pages=PREMIERE_PAGE[:DERNIERE_PAGE]
commencer [arrêter] l'impression avec la page PREMIERE_[DERNIERE_]PAGE
-COLONNE, --columns=COLONNE
produire COLONNE colonnes et imprimer les colonnes vers le bas, sauf si -a est utilisé. Équilibrer le nombre de lignes dans les colonnes de chaque page
-a, --across
imprimer les colonnes en travers plutôt qu'en bas, utilisé conjointement avec -COLONNE
-c, --show-control-chars
utiliser la notation chapeau (^G) et la notation octale anti-slash
-d, --double-space
doubler l'espacement de la sortie
-D, --date-format=FORMAT
utiliser FORMAT pour la date de l'en-tête
-e[CHAR[LARGEUR]], --expand-tabs[=CHAR[LARGEUR]]
étendre les CARACTERES d'entrée (TAB) à une LARGEUR de tabulation (8)
-F, -f, --form-feed
utiliser des sauts de page au lieu de nouvelles lignes pour séparer les pages (par un en-tête de page de 3 lignes avec -F ou un en-tête et un pied de page de 5 lignes sans -F)
-h, --header=HEADER
utiliser un HEADER centré au lieu du nom de fichier dans l'en-tête de page, -h "" imprime une ligne vide, n'utilisez pas -h""
-i[CHAR[LARGEUR]], --output-tabs[=CHAR[LARGEUR]]
remplacer les espaces par des CARACTERES (TAB) pour une tabulation de LARGEUR (8)
-J, --join-lines
fusionner les lignes complètes, désactive la troncature de ligne -W, pas d'alignement de colonne, --sep-string[=CHAINE] définit les séparateurs
-l, --length=LONGUEUR_PAGE
définir la longueur de la page à LONGUEUR_PAGE (66) lignes (nombre par défaut de lignes de texte 56, et avec -F 63). implique -t si LONGUEUR_PAGE <= 10
-m, --merge
imprimer tous les fichiers en parallèle, un dans chaque colonne, tronquer les lignes, mais joindre les lignes de pleine longueur avec -J
-n[SEP[CHIFFRES]], --number-lines[=SEP[CHIFFRES]]
numéroter les lignes, utiliser CHIFFRES (5) chiffres, puis SEP (TAB), le comptage par défaut commence à la 1ère ligne du fichier d'entrée
-N, --first-line-number=NUMERO
commencer le comptage avec NUMERO à la 1ère ligne de la première page imprimée (voir +PREMIERE_PAGE)
-o, --indent=MARGE
décaler chaque ligne avec MARGE (zéro) espaces, n'affecte pas -w ou -W, MARGE sera ajoutée à LARGEUR_PAGE
-r, --no-file-warnings
omettre les avertissements lorsqu'un fichier ne peut pas être ouvert
-s[CAR], --separator[=CAR]
séparer les colonnes par un seul caractère, le caractère par défaut est le caractère <TAB> sans -w et 'aucun caractère' avec -w. -s[CAR] désactive la troncature de ligne de toutes les 3 options de colonne (-COLONNE|-a -COLONNE|-m) sauf si -w est défini
-S[CHAINE], --sep-string[=CHAINE]
séparer les colonnes par CHAINE, sans -S : séparateur par défaut <TAB> avec -J et <espace> sinon (identique à -S" "), aucun effet sur les options de colonne
-t, --omit-header
omettre les en-têtes et pieds de page; implicite si LONGUEUR_PAGE <= 10
-T, --omit-pagination
omettre les en-têtes et pieds de page, éliminer toute pagination par des sauts de page définis dans les fichiers d'entrée
-v, --show-nonprinting
utiliser la notation octale anti-slash
-w, --width=LARGEUR_PAGE
définir la largeur de la page à LARGEUR_PAGE (72) caractères uniquement pour la sortie multi-colonnes de texte, -s[car] désactive (72)
-W, --page-width=LARGEUR_PAGE
définir la largeur de la page à LARGEUR_PAGE (72) caractères toujours, tronquer les lignes, sauf si l'option -J est définie, sans interférence avec -S ou -s
--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter
