NOM

/caps

DESCRIPTION

Découvrir le logiciel client d'un contact, ou les capacités des membres d'une salle. Si dans un chat privé initié depuis une salle de chat, aucun paramètre n'est requis.

SYNTAXE

/caps

/caps <fulljid>|<nick>

ARGUMENTS

<fulljid>

Si dans la console ou une fenêtre de chat, le JID complet dont vous souhaitez voir les capacités.

<nick>

Si dans une salle de chat, le pseudonyme dont vous souhaitez voir les capacités.

EXEMPLES

/caps ran@cold.sea.org/laptop

/caps ran@cold.sea.org/phone

/caps aegir
