profanity-mood(1)

Paquet: profanity-gtk

Licences: GPL3

man(1) Client XMPP Profanity man(1)

NOM

/mood

DESCRIPTION

Définir l'humeur (XEP-0107).

SYNTAXE

/mood on|off

/mood set <humeur> [texte]

/mood clear

ARGUMENTS

on|off

Active ou désactive l'affichage de l'humeur des autres utilisateurs. Activé par défaut.

set <humeur> [texte]

Définit l'humeur de l'utilisateur à <humeur> avec un [texte] optionnel. Utilisez /mood set <tab> pour parcourir les humeurs prédéfinies.

clear

Supprime l'humeur de l'utilisateur.

EXEMPLES

/mood set happy "Tellement heureux d'utiliser Profanity !"

/mood set amazed

/mood clear
