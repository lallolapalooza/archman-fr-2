PRTE(1) Environnement d'exécution de référence PMIx PRTE(1)

prte — instancier une instance de DVM PRRTE

SYNTAXE

shell$ prte ...options...

DESCRIPTION

prte instancie une instance de l'environnement d'exécution de référence (PRRTE) de machine virtuelle distribuée (DVM) de PMIx.

Une aide complète sur la documentation de cette commande est fournie via prte --help [sujet].

Pour l'instant, ce contenu n'est pas disponible sous forme de page de manuel. Les demandes d'extraction pour ajouter tout le contenu (via une infrastructure répétable) seraient grandement appréciées.
