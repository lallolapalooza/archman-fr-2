profanity-connect(1)

Paquet: profanity

man(1) Client XMPP Profanity man(1)

NOM

/connect

DESCRIPTION

Se connecter à un service de chat. Si aucun compte n'est spécifié, le compte par défaut est utilisé s'il est configuré. Un compte local est créé avec le JID comme nom s'il n'existe pas déjà. Si vous souhaitez vous connecter à un serveur via SASL ANONYMOUS (cf. XEP-0175), vous pouvez également le faire.

SYNTAXE

/connect [<compte>]

/connect <compte> [serveur <serveur>] [port <port>] [tls forcer|autoriser|confiance|legacy|désactiver] [auth défaut|legacy]

/connect <serveur>

ARGUMENTS

<compte>

Le compte local que vous souhaitez utiliser pour la connexion, ou un JID si vous vous connectez pour la première fois.

serveur <serveur>

Fournissez un serveur s'il est différent de la partie domaine de votre JID.

port <port>

Le port à utiliser s'il est différent du port par défaut (5222, ou 5223 pour SSL).

<serveur>

Se connecter au serveur indiqué de manière anonyme. (Attention : Peu de serveurs prennent en charge cette option.)

tls forcer

Forcer la connexion TLS, et échouer si aucune ne peut être établie, c'est le comportement par défaut.

tls autoriser

Utiliser TLS pour la connexion si elle est disponible.

tls confiance

Forcer la connexion TLS et faire confiance au certificat du serveur.

tls legacy

Utiliser TLS legacy pour la connexion. Cela signifie que le serveur ne prend pas en charge STARTTLS et que TLS est forcé juste après l'établissement de la connexion TCP.

tls désactiver

Désactiver TLS pour la connexion.

auth défaut

Processus d'authentification par défaut.

auth legacy

Autoriser l'authentification legacy.

EXEMPLES

/connect

/connect odin@valhalla.edda

/connect odin@valhalla.edda serveur talk.google.com

/connect freyr@vanaheimr.edda port 5678

/connect me@localhost.test.org serveur 127.0.0.1 tls désactiver

/connect me@chatty serveur chatty.com port 5443

/connect serveur.qui.supporte.sasl.anonymous.exemple
