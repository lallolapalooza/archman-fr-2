profanity-occupants(1)

Paquet: profanity

Licences: GPL3

man(1) Client XMPP Profanity man(1)

NOM

/occupants

DESCRIPTION

Affiche ou masque les occupants de la salle, et les paramètres d'affichage du panneau des occupants.

SYNTAXE

/occupants show|hide [jid|offline]

/occupants char <caractère>|none

/occupants color on|off

/occupants default show|hide [jid|offline]

/occupants size [<pourcentage>]

/occupants indent <indentation>

/occupants header char <caractère>|none

/occupants wrap on|off

ARGUMENTS

show

Affiche le panneau des occupants dans la salle courante.

char <caractère>

Précède les occupants du caractère spécifié.

char none

Supprime le préfixe caractère des occupants.

color on

Active les noms de couleur générés (XEP-0392) pour les occupants.

color off

Désactive les noms de couleur générés (XEP-0392) pour les occupants.

hide

Masque le panneau des occupants dans la salle courante.

show jid

Affiche le JID dans le panneau des occupants dans la salle courante.

hide jid

Masque le JID dans le panneau des occupants dans la salle courante.

show offline

Affiche le panneau des occupants hors ligne dans la salle courante.

hide offline

Masque le panneau des occupants hors ligne dans la salle courante.

default show|hide

Indique si les occupants sont affichés par défaut dans les nouvelles salles.

default show|hide jid

Indique si les JIDs des occupants sont affichés par défaut dans les nouvelles salles.

default show|hide offline

Indique si les occupants hors ligne sont affichés par défaut dans les nouvelles salles.

size <pourcentage>

Pourcentage de l'écran occupé par la liste des occupants dans les salles (1-99).

indent <indentation>

Indente la ligne de contact de <indentation> espaces (0 à 10).

header char <caractère>

Précède les en-têtes des occupants du caractère spécifié.

header char none

Supprime le préfixe caractère des en-têtes des occupants.

wrap on|off

Active ou désactive le retour à la ligne dans le panneau des occupants.
