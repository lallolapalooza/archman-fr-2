proc_tid(5) Manuel des formats de fichiers proc_tid(5)

NOM

/proc/pid/task/, /proc/tid/, /proc/thread-self/ - informations sur les threads

DESCRIPTION

/proc/pid/task/ (depuis Linux 2.6.0)
Ceci est un répertoire qui contient un sous-répertoire pour chaque thread du processus. Le nom de chaque sous-répertoire est l'ID numérique du thread (tid) du thread (voir gettid(2)).
Dans chacun de ces sous-répertoires, il y a un ensemble de fichiers avec les mêmes noms et contenus que sous les répertoires /proc/pid. Pour les attributs qui sont partagés par tous les threads, le contenu de chacun des fichiers sous les sous-répertoires task/tid sera le même que dans le fichier correspondant du répertoire parent /proc/pid (par exemple, dans un processus multithreadé, tous les fichiers task/tid/cwd auront la même valeur que le fichier /proc/pid/cwd du répertoire parent, car tous les threads d'un processus partagent un répertoire de travail). Pour les attributs qui sont distincts pour chaque thread, les fichiers correspondants sous task/tid peuvent avoir des valeurs différentes (par exemple, divers champs dans chacun des fichiers task/tid/status peuvent être différents pour chaque thread), ou ils peuvent ne pas exister du tout dans /proc/pid.
Dans un processus multithreadé, le contenu du répertoire /proc/pid/task n'est pas disponible si le thread principal a déjà terminé (typiquement en appelant pthread_exit(3)).
/proc/tid/
Il existe un sous-répertoire numérique pour chaque thread en cours d'exécution qui n'est pas un leader de groupe de threads (c'est-à-dire, un thread dont l'ID n'est pas le même que son ID de processus) ; le sous-répertoire est nommé par l'ID du thread. Chacun de ces sous-répertoires contient des fichiers et des sous-répertoires exposant des informations sur le thread avec l'ID de thread tid. Le contenu de ces répertoires est le même que celui des répertoires correspondants /proc/pid/task/tid.
Les sous-répertoires /proc/tid ne sont *pas* visibles lors de l'itération sur /proc avec getdents(2) (et ne sont donc *pas* visibles lorsqu'on utilise ls(1) pour afficher le contenu de /proc). Cependant, les noms de chemin de ces répertoires sont visibles pour (c'est-à-dire, utilisables comme arguments dans) les appels système qui opèrent sur les noms de chemin.
/proc/thread-self/ (depuis Linux 3.17)
Ce répertoire fait référence au thread accédant au système de fichiers /proc, et est identique au répertoire /proc/self/task/tid nommé par l'ID de thread du processus (tid) du même thread.
