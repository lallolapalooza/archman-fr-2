NOM

/proc/vmstat - statistiques de la mémoire virtuelle

DESCRIPTION

/proc/vmstat (depuis Linux 2.6.0)
Ce fichier affiche diverses statistiques de la mémoire virtuelle. Chaque ligne de ce fichier contient une seule paire nom-valeur, délimitée par des espaces blancs. Certaines lignes ne sont présentes que si le noyau a été configuré avec des options appropriées. (Dans certains cas, les options requises pour des fichiers particuliers ont changé entre les versions du noyau, elles ne sont donc pas listées ici. Les détails peuvent être trouvés en consultant le code source du noyau.) Les champs suivants peuvent être présents :
