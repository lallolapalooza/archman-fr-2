NOM

pr29_4z - Fonction API

SYNTAXE

#include <pr29.h>

int pr29_4z(const uint32_t * in);

ARGUMENTS

const uint32_t * in
tableau terminé par zéro de points de code Unicode.

DESCRIPTION

Vérifie l'entrée pour voir si elle peut être normalisée en différentes chaînes par différentes implémentations NFKC, en raison d'une anomalie dans les spécifications NFKC.

Valeur de retour : Renvoie la valeur Pr29_rc PR29_SUCCESS en cas de succès, et PR29_PROBLEM si la séquence d'entrée est une "séquence problématique" (c'est-à-dire qu'elle peut être normalisée en différentes chaînes par différentes implémentations).
