PROCS(1) Commandes utilisateur PROCS(1)

NOM

procs - un remplacement pour `ps` écrit en Rust

SYNTAXE

procs [OPTIONS] [MOTSCLEFS]

DESCRIPTION

procs est un outil en ligne de commande qui fournit une alternative à la commande ps.

OPTIONS

--and

Afficher les processus qui correspondent à tous les mots-clés.

--or

Afficher les processus qui correspondent à n'importe quel mot-clé.

--nand

Masquer les processus qui correspondent à tous les mots-clés.

--nor

Masquer les processus qui correspondent à n'importe quel mot-clé.

--watch

Activer le mode veille pour des mises à jour en temps réel.

--watch-interval <seconde>

Définir l'intervalle de mise à jour pour le mode veille.

--tree

Afficher les processus dans une vue arborescente.

--sorta <colonne>

Trier les processus par ordre croissant selon la colonne spécifiée.

--sortd <colonne>

Trier les processus par ordre décroissant selon la colonne spécifiée.

--insert <colonne>

Insérer une nouvelle colonne à la position de Slot ou MultiSlot.

--gen-completion

Générer des fichiers de complétion de shell pour les shells pris en charge.

EXEMPLES

Afficher tous les processus

procs

Rechercher par mot-clé non numérique

procs zsh

Rechercher par mot-clé numérique

procs --or 6000 60000 60001 16723

Afficher le nom du conteneur Docker

procs growi

PAGER

Sur Linux et macOS, less est le pager par défaut. S'il n'est pas disponible, more est utilisé. Le pager intégré peut être utilisé en configurant use_builtin. Sur Windows, le pager intégré est toujours utilisé.

RACCOURCIS MODE VEILLE

Si l'option --watch ou --watch-interval <seconde> est utilisée, procs met à jour automatiquement la sortie comme top. Des raccourcis clavier sont disponibles pour le contrôle.

n

Changer la colonne de tri vers la colonne suivante

p

Changer la colonne de tri vers la colonne précédente

a

Changer l'ordre de tri en ascendant

d

Changer l'ordre de tri en descendant

q

Quitter
