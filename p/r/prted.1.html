prted — démon auxiliaire pour PRRTE

SYNTAXE

shell$ prted ...options...

DESCRIPTION

prted est le démon auxiliaire backend pour l'environnement d'exécution de référence PMIx (PRRTE).

Une documentation d'aide étendue pour cette commande est fournie via prted --help [sujet].

Au moins pour l'instant, ce contenu n'est pas disponible sous forme de page de manuel. Les demandes de tirage (pull requests) pour ajouter tout le contenu (via une infrastructure répétable) seraient grandement appréciées.
