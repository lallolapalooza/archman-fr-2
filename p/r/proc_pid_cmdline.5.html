proc_pid_cmdline(5) Manuel des formats de fichiers proc_pid_cmdline(5)

NOM

/proc/pid/cmdline - ligne de commande

DESCRIPTION

/proc/pid/cmdline
Ce fichier en lecture seule contient la ligne de commande complète du processus, sauf si le processus est un zombie. Dans ce dernier cas, ce fichier est vide : une lecture sur ce fichier renverra 0 caractère.
Pour les processus encore en cours d'exécution, les arguments de la ligne de commande apparaissent dans ce fichier dans la même disposition que dans la mémoire du processus : Si le processus est bien élevé, il s'agit d'un ensemble de chaînes séparées par des octets nuls ('\0'), avec un octet nul supplémentaire après la dernière chaîne.
C'est le cas général, mais les processus ont la liberté de modifier la région mémoire et de rompre les hypothèses sur le contenu ou le format du fichier /proc/pid/cmdline.
Si, après un appel à execve(2), le processus modifie ses chaînes argv, ces changements apparaîtront ici. Ce n'est pas la même chose que de modifier le tableau argv.
De plus, un processus peut changer l'emplacement mémoire auquel ce fichier fait référence via des opérations prctl(2) telles que PR_SET_MM_ARG_START.
Considérez ce fichier comme la ligne de commande que le processus veut que vous voyiez.
