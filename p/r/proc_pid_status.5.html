proc_pid_status(5) Manuel des formats de fichiers proc_pid_status(5)

NOM

/proc/pid/status - informations sur l'utilisation de la mémoire et l'état du processus

DESCRIPTION

/proc/pid/status
Fournit une grande partie des informations de /proc/pid/stat et /proc/pid/statm dans un format plus facile à analyser pour les humains. Voici un exemple :

$ cat /proc/$$/status
Name:   bash
Umask:  0022
State:  S (sleeping)
Tgid:   17248
Ngid:   0
Pid:    17248
PPid:   17200
TracerPid:      0
Uid:    1000    1000    1000    1000
Gid:    100     100     100     100
FDSize: 256
Groups: 16 33 100
NStgid: 17248
NSpid:  17248
NSpgid: 17248
NSsid:  17200
VmPeak:	  131168 kB
VmSize:	  131168 kB
VmLck:	       0 kB
VmPin:	       0 kB
VmHWM:	   13484 kB
VmRSS:	   13484 kB
RssAnon:	   10264 kB
RssFile:	    3220 kB
RssShmem:	       0 kB
VmData:	   10332 kB
VmStk:	     136 kB
VmExe:	     992 kB
VmLib:	    2104 kB
VmPTE:	      76 kB
VmPMD:	      12 kB
VmSwap:	       0 kB
HugetlbPages:          0 kB		# 4.4
CoreDumping:	0                       # 4.15
Threads:        1
SigQ:   0/3067
SigPnd: 0000000000000000
ShdPnd: 0000000000000000
SigBlk: 0000000000010000
SigIgn: 0000000000384004
SigCgt: 000000004b813efb
CapInh: 0000000000000000
CapPrm: 0000000000000000
CapEff: 0000000000000000
CapBnd: ffffffffffffffff
CapAmb:	0000000000000000
NoNewPrivs:     0
Seccomp:        0
Seccomp_filters:        0
Speculation_Store_Bypass:       vulnerable
Cpus_allowed:   00000001
Cpus_allowed_list:      0
Mems_allowed:   1
Mems_allowed_list:      0
voluntary_ctxt_switches:        150
nonvoluntary_ctxt_switches:     545

Les champs sont les suivants :
Name
Commande exécutée par ce processus. Les chaînes de plus de TASK_COMM_LEN (16) caractères (y compris le caractère nul de fin) sont tronquées silencieusement.
Umask
Umask du processus, exprimée en octal avec un zéro initial ; voir umask(2). (Depuis Linux 4.7.)
State
État actuel du processus. L'un des éléments suivants : "R (running)", "S (sleeping)", "D (disk sleep)", "T (stopped)", "t (tracing stop)", "Z (zombie)", ou "X (dead)".
Tgid
Identifiant du groupe de threads (c'est-à-dire l'ID du processus).
Ngid
Identifiant du groupe NUMA (0 si aucun ; depuis Linux 3.13).
Pid
Identifiant du thread (voir gettid(2)).
PPid
PID du processus parent.
TracerPid
PID du processus qui trace ce processus (0 s'il n'est pas tracé).
Uid
Gid
UIDs (GIDs) réels, effectifs, sauvegardés et du système de fichiers.
FDSize
Nombre d'emplacements de descripteurs de fichiers actuellement alloués.
Groups
Liste des groupes supplémentaires.
NStgid
Identifiant du groupe de threads (c'est-à-dire le PID) dans chacun des espaces de noms PID dont pid est membre. L'entrée la plus à gauche affiche la valeur par rapport à l'espace de noms PID du processus qui a monté ce procfs (ou l'espace de noms racine s'il est monté par le noyau), suivi de la valeur dans les espaces de noms internes successivement imbriqués. (Depuis Linux 4.1.)
NSpid
Identifiant du thread dans chacun des espaces de noms PID dont pid est membre. Les champs sont ordonnés comme pour NStgid. (Depuis Linux 4.1.)
NSpgid
Identifiant du groupe de processus dans chacun des espaces de noms PID dont pid est membre. Les champs sont ordonnés comme pour NStgid. (Depuis Linux 4.1.)
NSsid
Identifiant de session dans chacun des espaces de noms PID dont pid est membre. Les champs sont ordonnés comme pour NStgid. (Depuis Linux 4.1.)
VmPeak
Pic de taille de mémoire virtuelle.
VmSize
Taille de mémoire virtuelle.
VmLck
Taille de la mémoire verrouillée (voir mlock(2)).
VmPin
Taille de la mémoire épinglée (depuis Linux 3.2). Ce sont des pages qui ne peuvent pas être déplacées car quelque chose doit accéder directement à la mémoire physique.
VmHWM
Pic de taille de l'ensemble résident ("high water mark"). Cette valeur est inexacte ; voir /proc/pid/statm ci-dessus.
VmRSS
Taille de l'ensemble résident. Notez que la valeur ici est la somme de RssAnon, RssFile et RssShmem. Cette valeur est inexacte ; voir /proc/pid/statm ci-dessus.
RssAnon
Taille de la mémoire anonyme résidente. (depuis Linux 4.5). Cette valeur est inexacte ; voir /proc/pid/statm ci-dessus.
RssFile
Taille des mappages de fichiers résidents. (depuis Linux 4.5). Cette valeur est inexacte ; voir /proc/pid/statm ci-dessus.
RssShmem
Taille de la mémoire partagée résidente (inclut la mémoire partagée System V, les mappages de tmpfs(5) et les mappages anonymes partagés). (depuis Linux 4.5).
VmData
VmStk
VmExe
Taille des segments de données, de pile et de texte. Cette valeur est inexacte ; voir /proc/pid/statm ci-dessus.
VmLib
Taille du code des bibliothèques partagées.
VmPTE
Taille des entrées de table de pages (depuis Linux 2.6.10).
VmPMD
Taille des tables de pages de second niveau (ajouté dans Linux 4.0 ; supprimé dans Linux 4.15).
VmSwap
Taille de la mémoire virtuelle échangée par les pages privées anonymes ; l'utilisation du swap shmem n'est pas incluse (depuis Linux 2.6.34). Cette valeur est inexacte ; voir /proc/pid/statm ci-dessus.
HugetlbPages
Taille des portions de mémoire hugetlb (depuis Linux 4.4).
CoreDumping
Contient la valeur 1 si le processus est en train de vider une core dump, et 0 s'il ne l'est pas (depuis Linux 4.15). Ces informations peuvent être utilisées par un processus de surveillance pour éviter de tuer un processus qui est en train de vider une core dump, ce qui pourrait entraîner un fichier core dump corrompu.
Threads
Nombre de threads dans le processus contenant ce thread.
SigQ
Ce champ contient deux nombres séparés par une barre oblique qui concernent les signaux mis en file d'attente pour l'ID utilisateur réel de ce processus. Le premier est le nombre de signaux actuellement mis en file d'attente pour cet ID utilisateur réel, et le second est la limite de ressources sur le nombre de signaux mis en file d'attente pour ce processus (voir la description de RLIMIT_SIGPENDING dans getrlimit(2)).
SigPnd
ShdPnd
Masque (exprimé en hexadécimal) des signaux en attente pour le thread et pour le processus dans son ensemble (voir pthreads(7) et signal(7)).

f="#SigBlk">SigBlk
SigIgn
SigCgt
Masques (exprimés en hexadécimal) indiquant les signaux bloqués, ignorés et interceptés (voir signal(7)).
CapInh
CapPrm
CapEff
Masques (exprimés en hexadécimal) des capacités activées dans les ensembles héritables, autorisés et effectifs (voir capabilities(7)).
CapBnd
Ensemble de délimitation des capacités, exprimé en hexadécimal (depuis Linux 2.6.26, voir capabilities(7)).
CapAmb
Ensemble de capacités ambiantes, exprimé en hexadécimal (depuis Linux 4.3, voir capabilities(7)).
NoNewPrivs
Valeur du bit no_new_privs (depuis Linux 4.10, voir prctl(2)).
Seccomp
Mode Seccomp du processus (depuis Linux 3.8, voir seccomp(2)). 0 signifie SECCOMP_MODE_DISABLED ; 1 signifie SECCOMP_MODE_STRICT ; 2 signifie SECCOMP_MODE_FILTER. Ce champ n'est fourni que si le noyau a été compilé avec l'option de configuration du noyau CONFIG_SECCOMP activée.
Seccomp_filters
Nombre de filtres seccomp attachés au processus (depuis Linux 5.9, voir seccomp(2)).
Speculation_Store_Bypass
État de la mitigation de la faille de spéculation (depuis Linux 4.17, voir prctl(2)).
Cpus_allowed
Masque hexadécimal des CPU sur lesquels ce processus peut s'exécuter (depuis Linux 2.6.24, voir cpuset(7)).
Cpus_allowed_list
Identique au précédent, mais au format "liste" (depuis Linux 2.6.26, voir cpuset(7)).
Mems_allowed
Masque des nœuds de mémoire autorisés pour ce processus (depuis Linux 2.6.24, voir cpuset(7)).
Mems_allowed_list
Identique au précédent, mais au format "liste" (depuis Linux 2.6.26, voir cpuset(7)).
voluntary_ctxt_switches
nonvoluntary_ctxt_switches
Nombre de commutations de contexte volontaires et involontaires (depuis Linux 2.6.23).
