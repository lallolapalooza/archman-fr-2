NOM

projects - définition de la racine de projet persistante

DESCRIPTION

Le fichier /etc/projects fournit une correspondance entre les identifiants numériques de projet et les répertoires qui sont les racines de l'arbre des quotas. Son format est simplement :

# les commentaires sont préfixés par un dièse
# ...
10:/export/cage
42:/var/log

Le fichier /etc/projects est optionnel. Alternativement, xfs_quota(8) peut être utilisé avec l'argument -p pour spécifier une racine de projet directement pour chaque opération.

VOIR AUSSI

xfs_quota(8), xfsctl(3), projid(5).
