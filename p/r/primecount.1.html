NOM

primecount - compter les nombres premiers

SYNTAXE

primecount x [options]

DESCRIPTION

Compte le nombre de nombres premiers inférieurs ou égaux à x (<= 10^31) en utilisant des implémentations rapides des algorithmes de comptage de nombres premiers combinatoires. Par défaut, primecount compte les nombres premiers en utilisant l'algorithme de Xavier Gourdon, qui a une complexité temporelle de O(x^(2/3) / log^2 x) opérations et utilise O(x^(2/3) * log^3 x) de mémoire. primecount est multi-threadé, il utilise tous les cœurs de processeur disponibles par défaut.

OPTIONS

-d, --deleglise-rivat

Compte les nombres premiers en utilisant l'algorithme de Deleglise-Rivat.

--double-check

Recalcule pi(x) avec des facteurs de réglage alpha alternatifs pour vérifier le premier résultat. Cette redondance aide à se prémunir contre les bugs potentiels dans primecount : si une erreur existe, il est très peu probable que les deux calculs de pi(x) produisent le même résultat (incorrect).

-g, --gourdon

Compte les nombres premiers en utilisant l'algorithme de Xavier Gourdon (algorithme par défaut).

-l, --legendre

Compte les nombres premiers en utilisant la formule de Legendre.

--lehmer

Compte les nombres premiers en utilisant la formule de Lehmer.

--lmo

Compte les nombres premiers en utilisant l'algorithme de Lagarias-Miller-Odlyzko.

-m, --meissel

Compte les nombres premiers en utilisant la formule de Meissel.

--Li

Approxime pi(x) en utilisant l'intégrale logarithmique eulérienne : Li(x), avec Li(x) = li(x) - li(2).

--Li-inverse

Approxime le n-ième nombre premier en utilisant l'intégrale logarithmique eulérienne inverse : Li^-1(x).

-n, --nth-prime

Calcule le n-ième nombre premier.

-p, --primesieve

Compte les nombres premiers en utilisant le crible d'Ératosthène.

--phi X A

phi(x, a) compte les nombres <= x qui ne sont divisibles par aucun des a premiers nombres.

-R, --RiemannR

Approxime pi(x) en utilisant la fonction R de Riemann : R(x).

--RiemannR-inverse

Approxime le n-ième nombre premier en utilisant la fonction R de Riemann inverse : R^-1(x).

-s, --status[=NUM]

Affiche la progression du calcul e.g. 1%, 2%, 3%, ... Affiche NUM chiffres après la virgule : --status=1 imprime 99.9%.

--test

Exécute divers tests de correction et quitte.

--time

Affiche le temps écoulé en secondes.

-t, --threads=NUM

Définit le nombre de threads, 1 <= NUM <= cœurs CPU. Par défaut, primecount utilise tous les cœurs de processeur disponibles.

-v, --version

Affiche la version et les informations de licence.

-h, --help

Affiche ce menu d'aide.

OPTIONS AVANCÉES POUR L'ALGORITHME DE DELEGLISE-RIVAT

--P2

Calcule la 2ème fonction de crible partielle.

--S1

Calcule les feuilles ordinaires.

--S2-trivial

Calcule les feuilles spéciales triviales.

--S2-easy

Calcule les feuilles spéciales faciles.

--S2-hard

Calcule les feuilles spéciales difficiles.

Facteur de réglage

Le facteur de réglage alpha équilibre principalement le calcul des formules S2_easy et S2_hard. En augmentant alpha, le temps d'exécution de la formule S2_hard diminue généralement, tandis que le temps d'exécution de la formule S2_easy augmente. Par défaut, primecount sélectionne automatiquement un facteur de réglage alpha susceptible d'offrir les meilleures performances pour l'entrée de l'utilisateur.

Le facteur de réglage alpha est également très utile pour vérifier les calculs de pi(x). Vous effectuez pi(x) deux fois, mais pour le second calcul, vous utilisez un facteur alpha légèrement différent. Si les résultats des deux calculs de pi(x) correspondent, alors pi(x) a été vérifié avec succès.

-a, --alpha=NUM

Définit le facteur de réglage alpha : y = x^(1/3) * alpha, 1 <= alpha <= x^(1/6).

OPTIONS AVANCÉES POUR L'ALGORITHME DE XAVIER GOURDON

--AC

Calcule les formules A + C.

--B

Calcule la formule B.

--D

Calcule la formule D.

--Phi0

Calcule la formule Phi0.

--Sigma

Calcule les 7 formules Sigma.

Facteurs de réglage

Les facteurs de réglage alpha_y et alpha_z équilibrent principalement le calcul des formules A, B, C et D. Lorsque alpha_y est diminué et alpha_z est augmenté, le temps d'exécution de la formule B augmente, tandis que le temps d'exécution des formules A, C et D diminue. Par défaut, primecount sélectionne automatiquement les facteurs de réglage alpha_y et alpha_z susceptibles d'offrir les meilleures performances pour l'entrée de l'utilisateur.

Les facteurs de réglage alpha_y et alpha_z sont également très utiles pour vérifier les calculs de pi(x). Vous effectuez pi(x) deux fois, mais pour le second calcul, vous utilisez des facteurs de réglage alpha_y et/ou alpha_z légèrement différents. Si les résultats des deux calculs de pi(x) correspondent, alors pi(x) a été vérifié avec succès.

--alpha-y=NUM

Définit le facteur de réglage alpha_y : y = x^(1/3) * alpha_y, 1 <= alpha_y <= x^(1/6).

--alpha-z=NUM

Définit le facteur de réglage alpha_z : z = y * alpha_z, 1 <= alpha_z <= x^(1/6).

VÉRIFICATION DES CALCULS DE PI(X)

Pour les grands calculs de pi(x) qui durent plusieurs semaines ou mois, il est important de vérifier ces calculs pour se prémunir contre les erreurs de calcul dues à des erreurs matérielles et/ou des bugs dans primecount.

Pour vérifier un calcul de pi(x), vous effectuez pi(x) deux fois. Mais pour la seconde exécution, vous utilisez l'option --double-check. L'option --double-check permet l'utilisation de facteurs de réglage alpha alternatifs, garantissant que toutes les bornes internes du second calcul diffèrent légèrement du premier calcul. Cette redondance aide à se prémunir contre les bugs potentiels dans primecount : si une erreur existe, il est très peu probable que les deux calculs de pi(x) produisent le même résultat (incorrect).

primecount 1e20 --status

Premier calcul de pi(x) utilisant les facteurs de réglage alpha par défaut.

primecount 1e20 --status --double-check

Second calcul de pi(x) utilisant des facteurs de réglage alpha alternatifs.

EXEMPLES

primecount 1000

Compte les nombres premiers <= 1000.

primecount 1e17 --status

Compte les nombres premiers <= 10^17 et affiche des informations de statut.

primecount 1e15 --threads 1 --time

Compte les nombres premiers <= 10^15 en utilisant un seul thread et affiche le temps écoulé.
