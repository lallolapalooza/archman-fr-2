proc_pid_timers(5) Manuel des formats de fichiers proc_pid_timers(5)

NOM

/proc/pid/timers - minuteurs POSIX

DESCRIPTION

/proc/pid/timers (depuis Linux 3.10)
Une liste des minuteurs POSIX pour ce processus. Chaque minuteur est listé sur une ligne qui commence par la chaîne "ID:". Par exemple :

ID: 1
signal: 60/00007fff86e452a8
notify: signal/pid.2634
ClockID: 0
ID: 0
signal: 60/00007fff86e452a8
notify: signal/pid.2634
ClockID: 1

Les lignes présentées pour chaque minuteur ont les significations suivantes :
ID
L'ID de ce minuteur. Ce n'est pas le même que l'ID de minuteur retourné par timer_create(2) ; c'est plutôt le même ID interne du noyau qui est disponible via le champ si_timerid de la structure siginfo_t (voir sigaction(2)).
signal
C'est le numéro de signal que ce minuteur utilise pour livrer les notifications, suivi d'une barre oblique, puis de la valeur sigev_value fournie au gestionnaire de signal. Valide uniquement pour les minuteurs qui notifient via un signal.
notify
La partie avant la barre oblique spécifie le mécanisme que ce minuteur utilise pour livrer les notifications, et est l'un de "thread", "signal", ou "none". Immédiatement après la barre oblique se trouve soit la chaîne "tid" pour les minuteurs avec notification SIGEV_THREAD_ID, soit "pid" pour les minuteurs qui notifient par d'autres mécanismes. Après le "." se trouve le PID du processus (ou l'ID du thread du noyau du thread) auquel un signal sera livré si le minuteur délivre des notifications via un signal.
ClockID
Ce champ identifie l'horloge que le minuteur utilise pour mesurer le temps. Pour la plupart des horloges, il s'agit d'un nombre qui correspond à l'une des constantes utilisateur CLOCK_* exposées via <time.h>. Les minuteurs CLOCK_PROCESS_CPUTIME_ID s'affichent avec une valeur de -6 dans ce champ. Les minuteurs CLOCK_THREAD_CPUTIME_ID s'affichent avec une valeur de -2 dans ce champ.
Ce fichier n'est disponible que lorsque le noyau a été configuré avec CONFIG_CHECKPOINT_RESTORE.
