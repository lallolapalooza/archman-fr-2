proc_pid_exe(5) Manuel des formats de fichiers proc_pid_exe(5)

NOM

proc_pid_exe - lien symbolique vers le chemin d'accès du programme

DESCRIPTION

/proc/pid/exe
Sous Linux 2.2 et versions ultérieures, ce fichier est un lien symbolique contenant le chemin d'accès réel de la commande exécutée. Ce lien symbolique peut être déréférencé normalement ; tenter de l'ouvrir ouvrira l'exécutable. Vous pouvez même taper /proc/pid/exe pour exécuter une autre copie du même exécutable que celle exécutée par le processus pid. Si le chemin d'accès a été désinscrit, le lien symbolique contiendra la chaîne ' (supprimé)' ajoutée au chemin d'accès d'origine. Dans un processus multithreadé, le contenu de ce lien symbolique n'est pas disponible si le thread principal a déjà terminé (généralement en appelant pthread_exit(3)).
L'autorisation de déréférencer ou de lire (readlink(2)) ce lien symbolique est régie par une vérification du mode d'accès ptrace PTRACE_MODE_READ_FSCREDS ; voir ptrace(2).
Sous Linux 2.0 et antérieur, /proc/pid/exe est un pointeur vers le binaire qui a été exécuté, et apparaît comme un lien symbolique. Un appel à readlink(2) sur ce fichier sous Linux 2.0 renvoie une chaîne au format :

[périphérique]:inode

Par exemple, [0301]:1502 serait l'inode 1502 sur le périphérique majeur 03 (disques IDE, MFM, etc.) mineur 01 (première partition du premier disque).
find(1) avec l'option -inum peut être utilisé pour localiser le fichier.
