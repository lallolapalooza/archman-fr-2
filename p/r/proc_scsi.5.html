proc_scsi(5) Format de fichier proc_scsi(5)

NOM

/proc/scsi/ - SCSI

DESCRIPTION

/proc/scsi/
Un répertoire avec le pseudo-fichier intermédiaire scsi et divers répertoires de pilotes bas niveau SCSI, qui contiennent un fichier pour chaque hôte SCSI de ce système, lesquels donnent l'état d'une partie du sous-système d'E/S SCSI. Ces fichiers contiennent des structures ASCII et sont donc lisibles avec cat(1).
Vous pouvez également écrire dans certains fichiers pour reconfigurer le sous-système ou activer/désactiver certaines fonctionnalités.
/proc/scsi/scsi
Ceci est une liste de tous les périphériques SCSI connus du noyau. La liste est similaire à celle vue au démarrage. SCSI supporte actuellement uniquement la commande add-single-device qui permet à root d'ajouter un périphérique branché à chaud à la liste des périphériques connus.
La commande

echo 'scsi add-single-device 1 0 5 0' > /proc/scsi/scsi

demandera à l'hôte scsi1 de scanner sur le canal SCSI 0 pour un périphérique à l'ID 5 LUN 0. S'il existe déjà un périphérique connu à cette adresse ou si l'adresse est invalide, une erreur sera retournée.
/proc/scsi/nom_pilote/
nom_pilote peut actuellement être NCR53c7xx, aha152x, aha1542, aha1740, aic7xxx, buslogic, eata_dma, eata_pio, fdomain, in2000, pas16, qlogic, scsi_debug, seagate, t128, u15-24f, ultrastore, ou wd7000. Ces répertoires apparaissent pour tous les pilotes qui ont enregistré au moins un HBA SCSI. Chaque répertoire contient un fichier par hôte enregistré. Chaque fichier hôte est nommé d'après le numéro que l'hôte s'est vu attribuer lors de l'initialisation.
La lecture de ces fichiers montre généralement la configuration du pilote et de l'hôte, les statistiques, etc.
L'écriture dans ces fichiers permet différentes actions sur différents hôtes. Par exemple, avec les commandes latency et nolatency, root peut activer ou désactiver le code de mesure de latence des commandes dans le pilote eata_dma. Avec les commandes lockup et unlock, root peut contrôler les blocages de bus simulés par le pilote scsi_debug.
