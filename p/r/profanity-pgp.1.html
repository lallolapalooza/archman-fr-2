NOM

/pgp

DESCRIPTION

Commandes PGP pour gérer les clés et effectuer le chiffrement PGP pendant les sessions de chat. Voir la commande /account pour définir votre propre clé PGP.

SYNTAXE

/pgp libver

/pgp keys

/pgp contacts

/pgp setkey <contact> <keyid>

/pgp start [<contact>]

/pgp end

/pgp log on|off|redact

/pgp char <char>

/pgp sendfile on|off

/pgp sendpub [<contact>]

ARGUMENTS

libver

Affiche la version de la bibliothèque libgpgme utilisée.

keys

Liste toutes les clés connues du système.

contacts

Affiche les contacts avec les clés publiques associées.

setkey <contact> <keyid>

Associe manuellement un contact à une clé publique.

start [<contact>]

Démarre un chat chiffré PGP, le contact actuel sera utilisé s'il n'est pas spécifié.

end

Termine le chat chiffré PGP avec le destinataire actuel.

log on|off

Active ou désactive la journalisation en texte clair des messages chiffrés PGP.

log redact

Journalise les messages chiffrés PGP, mais remplace le contenu par [redacted]. C'est le comportement par défaut.

char <char>

Définit le caractère à afficher à côté des messages chiffrés PGP.

sendfile on|off

Permet à /sendfile d'envoyer des fichiers non chiffrés tout en utilisant PGP.

autoimport on|off

Importe automatiquement les clés PGP à partir des messages.

sendpub [<contact>]

Envoie un message au destinataire actuel avec votre clé publique PGP, le contact actuel sera utilisé s'il n'est pas spécifié.

EXEMPLES

/pgp log off

/pgp setkey odin@valhalla.edda BA19CACE5A9592C5

/pgp start odin@valhalla.edda

/pgp end

/pgp char P
