proc_locks(5) Manuel des formats de fichiers proc_locks(5)

NOM

/proc/locks - Verrous et baux de fichiers courants

DESCRIPTION

/proc/locks
Ce fichier affiche les verrous (flock(2) et fcntl(2)) et les baux (fcntl(2)) de fichiers courants.
Voici un exemple du contenu affiché dans ce fichier :

1: POSIX  ADVISORY  READ  5433 08:01:7864448 128 128
2: FLOCK  ADVISORY  WRITE 2001 08:01:7864554 0 EOF
3: FLOCK  ADVISORY  WRITE 1568 00:2f:32388 0 EOF
4: POSIX  ADVISORY  WRITE 699 00:16:28457 0 EOF
5: POSIX  ADVISORY  WRITE 764 00:16:21448 0 0
6: POSIX  ADVISORY  READ  3548 08:01:7867240 1 1
7: POSIX  ADVISORY  READ  3548 08:01:7865567 1826 2335
8: OFDLCK ADVISORY  WRITE -1 08:01:8713209 128 191

Les champs affichés sur chaque ligne sont les suivants :
[1]
La position ordinale du verrou dans la liste.
[2]
Le type de verrou. Les valeurs pouvant apparaître ici incluent :
FLOCK
Ceci est un verrou de fichier BSD créé à l'aide de flock(2).
OFDLCK
Ceci est un verrou de description de fichier ouvert (OFD) créé à l'aide de fcntl(2).
POSIX
Ceci est un verrou de plage d'octets POSIX créé à l'aide de fcntl(2).
[3]
Parmi les chaînes de caractères pouvant apparaître ici, on trouve les suivantes :
ADVISORY
Ceci est un verrou consultatif.
MANDATORY
Ceci est un verrou obligatoire.
[4]
Le type de verrou. Les valeurs pouvant apparaître ici sont :
READ
Ceci est un verrou de lecture POSIX ou OFD, ou un verrou partagé BSD.
WRITE
Ceci est un verrou d'écriture POSIX ou OFD, ou un verrou exclusif BSD.
[5]
Le PID du processus qui détient le verrou.
Comme les verrous OFD ne sont pas détenus par un seul processus (puisque plusieurs processus peuvent avoir des descripteurs de fichiers qui font référence à la même description de fichier ouverte), la valeur -1 est affichée dans ce champ pour les verrous OFD. (Avant Linux 4.14, un bogue faisait que le PID du processus qui avait initialement acquis le verrou était affiché au lieu de la valeur -1.)
[6]
Trois sous-champs séparés par des deux-points qui identifient l'ID de périphérique majeur et mineur du périphérique contenant le système de fichiers où réside le fichier verrouillé, suivis du numéro d'inode du fichier verrouillé.
[7]
Le décalage en octets du premier octet du verrou. Pour les verrous BSD, cette valeur est toujours 0.
[8]
Le décalage en octets du dernier octet du verrou. EOF dans ce champ signifie que le verrou s'étend jusqu'à la fin du fichier. Pour les verrous BSD, la valeur affichée est toujours EOF.
Depuis Linux 4.9, la liste des verrous affichés dans /proc/locks est filtrée pour n'afficher que les verrous des processus de l'espace de noms PID (voir pid_namespaces(7)) pour lesquels le système de fichiers /proc a été monté. (Dans l'espace de noms PID initial, aucun filtrage des enregistrements affichés dans ce fichier n'est effectué.)
La commande lslocks(8) fournit des informations supplémentaires sur chaque verrou.
