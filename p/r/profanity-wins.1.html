NOM

/wins

DESCRIPTION

Gérer les fenêtres. Si aucun argument n'est passé, liste toutes les fenêtres actives et les informations sur leur utilisation.

SYNTAXE

/wins

/wins unread

/wins attention

/wins prune

/wins swap <source> <cible>

ARGUMENTS

unread

Liste les fenêtres avec des messages non lus.

attention

Liste les fenêtres qui ont été marquées avec le drapeau d'attention (alt+v). Vous pouvez basculer entre les fenêtres marquées avec alt+m.

prune

Ferme toutes les fenêtres sans messages non lus.

swap <source> <cible>

Échange les fenêtres, la cible peut être une position vide.
