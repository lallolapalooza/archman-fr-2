profanity-presence(1)

Paquet: profanity

Licences: GPL3

man(1) Client XMPP Profanity man(1)

NOM

/presence

DESCRIPTION

Affiche la présence des contacts dans la barre de titre et configure les messages de présence pour différents types de fenêtres.

SYNTAXE

/presence titlebar on|off

/presence console all|online|none

/presence chat all|online|none

/presence room all|online|none

ARGUMENTS

titlebar on|off

Active ou désactive l'affichage de la présence des contacts dans la barre de titre.

console all

Affiche tous les changements de présence dans la fenêtre de la console.

console online

Affiche uniquement les changements de présence en ligne/hors ligne dans la fenêtre de la console.

console none

N'affiche aucun changement de présence dans la fenêtre de la console.

chat all

Affiche tous les changements de présence dans les fenêtres de chat.

chat online

Affiche uniquement les changements de présence en ligne/hors ligne dans les fenêtres de chat.

chat none

N'affiche aucun changement de présence dans les fenêtres de chat.

room all

Affiche tous les changements de présence dans les fenêtres de salon de discussion.

room online

Affiche uniquement les changements de présence en ligne/hors ligne dans les fenêtres de salon de discussion.

room none

N'affiche aucun changement de présence dans les fenêtres de salon de discussion.

EXEMPLES

/presence titlebar off

/presence console none

/presence chat online

/presence room all
