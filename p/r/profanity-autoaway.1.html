NOM

/autoaway

DESCRIPTION

Gérer les paramètres d'auto-away (absence automatique) pour le temps d'inactivité.

SYNTAXE

/autoaway mode idle|away|off

/autoaway time away|xa <minutes>

/autoaway message away|xa <message>|off

/autoaway check on|off

ARGUMENTS

mode idle

Envoie le temps d'inactivité, le statut reste en ligne.

mode away

Envoie la présence away et xa ainsi que le temps d'inactivité.

mode off

Désactivé (par défaut).

time away <minutes>

Nombre de minutes avant l'envoi de la présence away, par défaut : 15.

time xa <minutes>

Nombre de minutes avant l'envoi de la présence xa, par défaut : 0 (désactivé).

message away <message>

Message optionnel à envoyer avec la présence away, par défaut : off (désactivé).

message xa <message>

Message optionnel à envoyer avec la présence xa, par défaut : off (désactivé).

message away off

Aucun message envoyé avec la présence away.

message xa off

Aucun message envoyé avec la présence xa.

check on|off

Lorsque activé, vérifie l'activité et envoie la présence en ligne, par défaut : on.

EXEMPLES

/autoaway mode away

/autoaway time away 30

/autoaway message away Absent de l'ordinateur pour un moment

/autoaway time xa 120

/autoaway message xa Absent de l'ordinateur pour très longtemps

/autoaway check off
