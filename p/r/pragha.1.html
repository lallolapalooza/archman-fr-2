NOM

pragha - Un lecteur de musique léger, dérivé de Consonance Music Manager

SYNTAXE

pragha [OPTION...] [FICHIER1 [FICHIER2...]]

DESCRIPTION

pragha est un lecteur de musique léger qui vise à être rapide, sans superflu, et léger en consommation de mémoire. Il est entièrement écrit en C et GTK+. Certaines des fonctionnalités sont :


* Gestion de bibliothèque à l'aide de sqlite3
* Vues multiples
* Support OSD
* Support pour asf, ape, flac, mp3, mp4, ogg, wav, wma et CDDA

pragha est distribué sous licence GNU General Public Licence version 3 (GPLv3).

OPTIONS

-?, --help
Affiche l'aide et quitte.
--help-all
Affiche toutes les options d'aide et quitte.
--help-gtk
Affiche les options GTK+ et quitte.
-v, --version
Affiche les informations de version et quitte.
-e, --debug
Active le débogage (Niveaux : 1,2,3,4)
-l, --log-file
Journalise le débogage dans un fichier.
-p, --play
Commence la lecture.
-s, --stop
Arrête la lecture.
-t, --pause
Met en pause/reprend la chanson actuelle.
-r, --prev
Joue la chanson précédente dans la liste de lecture.
-n, --next
Joue la chanson suivante dans la liste de lecture.
-f, --shuffle
Active/désactive le mode aléatoire.
-u, --repeat
Active/désactive le mode répétition.
-i, --inc_vol
Augmente le volume de 1.
-d, --dec_vol
Diminue le volume de 1.
-o, --show_osd
Affiche la notification OSD (une fenêtre pop-up avec des informations sur la chanson actuelle).
-x, --toggle_view
Affiche/masque la fenêtre du lecteur
-c, --current_state
Obtient l'état actuel du lecteur.
-a, --audio_backend
Backend audio (options valides : alsa/oss)
-g, --audio_device
Périphérique audio (Pour ALSA : hw:0,0 etc.., Pour OSS : /dev/dsp etc..)
-m, --audio_mixer
Élément de mixage (Pour ALSA : Master, PCM, etc.., Pour OSS : /dev/mixer, etc...)
--display=DISPLAY
Définit l'affichage X à utiliser.

UTILISATION

* Ajouter un emplacement de bibliothèque dans le menu Édition - Préférences.
* Réanalyser la bibliothèque depuis le menu Outils.
* Commencer à utiliser. :-)

FICHIERS

$HOME/.config/pragha/pragha.db
Base de données de la bibliothèque (au format sqlite3)
$HOME/.config/pragha/config
Paramètres personnels (utiliser l'interface graphique pour les modifier, Édition - Préférences)
$HOME/.cache/pragha-album-art
Cache de base pour les pochettes d'albums téléchargées, enregistrées sous le nom artiste - album.jpeg
