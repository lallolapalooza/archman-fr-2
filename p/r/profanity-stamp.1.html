profanity-stamp(1)

Paquet: profanity-gtk

Licences: GPL3

man(1) Client XMPP Profanity man(1)

NOM

/stamp

DESCRIPTION

Définit l'estampille de la fenêtre de chat. Le format d'une ligne dans la fenêtre de chat est : "<horodatage> <signe de chiffrement> <estampille> <message>" où <estampille> est "moi:" pour les messages entrants ou "nomutilisateur@serveur/ressource" pour les messages sortants. Cette commande permet de modifier la valeur de <estampille>.

SYNTAXE

/stamp sortant <chaîne>

/stamp entrant <chaîne>

/stamp annuler sortant|entrant

ARGUMENTS

sortant

Définit l'estampille sortante

entrant

Définit l'estampille entrante

annuler sortant|entrant

Utilise les valeurs par défaut

EXEMPLES

/stamp sortant -->

/stamp entrant <--

/stamp annuler entrant
