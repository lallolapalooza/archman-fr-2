profanity-avatar(1)

Paquet: profanity-gtk

Licences: GPL3

man(1) Client XMPP Profanity man(1)

NOM

/avatar

DESCRIPTION

Télécharger un avatar pour soi-même, désactiver son avatar ou télécharger l'avatar d'un contact (XEP-0084). Si rien ne se passe après avoir utilisé cette commande, l'utilisateur n'a soit pas d'avatar défini, soit n'utilise pas XEP-0084 pour le publier.

SYNTAXE

/avatar set <chemin>

/avatar disable

/avatar get <barejid>

/avatar open <barejid>

ARGUMENTS

set <chemin>

Définit l'avatar à l'image située à <chemin>.

disable

Désactive la publication de l'avatar ; votre avatar ne sera pas visible par les autres.

get <barejid>

Télécharge l'avatar. barejid est le JID à partir duquel télécharger l'avatar.

open <barejid>

Télécharge l'avatar et l'ouvre avec la commande. Voir /executable.

EXEMPLES

/avatar set ~/images/avatar.png

/avatar disable

/avatar get thor@valhalla.edda

/avatar open freyja@vanaheimr.edda
