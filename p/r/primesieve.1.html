NOM

primesieve - générer des nombres premiers

SYNTAXE

primesieve [DÉBUT] FIN [OPTION]...

DESCRIPTION

Génère les nombres premiers et/ou les k-uplets premiers dans l'intervalle [DÉBUT, FIN] (< 2^64) en utilisant le crible segmenté d'Ératosthène. primesieve inclut un certain nombre d'extensions au crible d'Ératosthène qui améliorent considérablement les performances : les multiples de petits nombres premiers sont pré-criblés, il utilise la factorisation par roue pour sauter les multiples ayant de petits facteurs premiers et il utilise l'algorithme de criblage par seaux qui améliore l'efficacité du cache lors du criblage de nombres > 2^32. primesieve est également multi-threadé, il utilise tous les cœurs de CPU disponibles par défaut pour compter les nombres premiers et pour trouver le n-ième nombre premier.

Le crible segmenté d'Ératosthène a une complexité temporelle de O(n log log n) opérations et utilise O(n^(1/2)) bits de mémoire. Plus spécifiquement, primesieve utilise 8 octets par nombre premier de criblage, par conséquent, son utilisation mémoire peut être approximée par Pi(n^(1/2)) * 8 octets (par thread).

OPTIONS

-c[NUM+], --count[=NUM+]

Compte les nombres premiers et/ou les k-uplets premiers, 1 <= NUM <= 6. Compte les nombres premiers : -c ou --count, compte les nombres premiers jumeaux : -c2 ou --count=2, compte les triplets de nombres premiers : -c3 ou --count=3, ... Vous pouvez également compter les nombres premiers et les k-uplets premiers simultanément, par exemple -c123 compte les nombres premiers, les nombres premiers jumeaux et les triplets de nombres premiers.

--cpu-info

Affiche les informations CPU : nom du CPU, fréquence, nombre de cœurs, tailles de cache, ...

-d, --dist=DIST

Crible l'intervalle [DÉBUT, DÉBUT + DIST].

-h, --help

Affiche ce menu d'aide.

-n, --nth-prime

Trouve le n-ième nombre premier, par exemple 100 -n trouve le 100ème nombre premier. Si 2 nombres N DÉBUT sont fournis, trouve le n-ième nombre premier > DÉBUT, par exemple 2 100 -n trouve le 2ème nombre premier > 100.

--no-status

Désactive la barre de progression.

-p[NUM], --print[=NUM]

Imprime les nombres premiers ou les k-uplets premiers, 1 <= NUM <= 6. Imprime les nombres premiers : -p, imprime les nombres premiers jumeaux : -p2, imprime les triplets de nombres premiers : -p3, ...

-q, --quiet

Mode silencieux, affiche moins de sortie.

-R, --RiemannR

Approximativement Pi(x) en utilisant la fonction R de Riemann : R(x).

--RiemannR-inverse

Approximativement le n-ième nombre premier en utilisant la fonction inverse R de Riemann : R^-1(x).

-s, --size=TAILLE

Définit la taille du tableau de criblage en Ko, 16 <= TAILLE <= 8192. Par défaut, primesieve utilise une taille de crible qui correspond à la taille du cache L1 de votre CPU (par cœur) ou qui est légèrement plus petite que la taille du cache L2 de votre CPU. Ce réglage est crucial pour les performances, sur des CPU exotiques, primesieve ne parvient parfois pas à déterminer les tailles de cache du CPU, ce qui entraîne généralement un ralentissement important. Dans ce cas, vous pouvez obtenir une amélioration significative des performances en réglant manuellement la taille du crible sur la taille du cache L1 ou L2 de votre CPU (par cœur).

-S, --stress-test[=MODE]

Exécute un test de résistance. Le MODE peut être CPU (par défaut) ou RAM. Le MODE CPU utilise peu de mémoire (< 5 Mio par thread) et soumet le CPU à une charge maximale. Le MODE RAM, en revanche, utilise beaucoup plus de mémoire que le MODE CPU (chaque thread utilise environ 1,16 Gio), mais le CPU ne chauffe généralement pas autant qu'en MODE CPU. Le test de résistance continue jusqu'à ce qu'un calcul erroné se produise (en raison d'un problème matériel) ou que le délai d'expiration expire. Le délai d'expiration par défaut est de 24 heures, il peut être modifié en utilisant l'option --timeout=SECS. Par défaut, le test de résistance utilise un nombre de threads correspondant au nombre de cœurs de CPU, ce nombre peut être modifié en utilisant l'option --threads=NUM.

--test

Exécute divers tests de correction (< 1 minute).

-t, --threads=NUM

Définit le nombre de threads, 1 <= NUM <= cœurs de CPU. Par défaut, primesieve utilise tous les cœurs de CPU disponibles pour compter les nombres premiers et pour trouver le n-ième nombre premier.

--time

Affiche le temps écoulé en secondes.

--timeout=SECS

Définit le délai d'expiration du test de résistance en secondes. Les unités de temps pour les secondes, minutes, heures, jours et années sont également supportées avec le suffixe s, m, h, d ou y. Par exemple, --timeout 10m définit un délai d'expiration de 10 minutes. Le délai d'expiration par défaut pour le test de résistance est de 24 heures.

-v, --version

Affiche la version et les informations de licence.

EXEMPLES

primesieve 1000

Compte les nombres premiers <= 1000.

primesieve 1e6 --print

Imprime les nombres premiers <= 10^6.

primesieve 1e6 --print > primes.txt

Enregistre les nombres premiers <= 10^6 dans un fichier texte.

primesieve 2^32 --print=2

Imprime les nombres premiers jumeaux <= 2^32.

primesieve 1e16 --dist=1e10 --threads=1

Compte les nombres premiers dans l'intervalle [10^16, 10^16 + 10^10] en utilisant un seul thread.
