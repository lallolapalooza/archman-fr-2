profanity-win(1)

Paquet: profanity

Licences: GPL3

man(1) Client XMPP Profanity man(1)

NOM

/win

DESCRIPTION

Déplacez-vous vers la fenêtre spécifiée.

SYNTAXE

/win console

/win <numéro>

/win <barejid>

/win <surnom>

/win <roomjid>

/win <roomoccupantjid>

/win xmlconsole

/win <plugin>

ARGUMENTS

console

Met le focus sur la fenêtre Console.

<numéro>

Met le focus sur la fenêtre spécifiée par son numéro.

<barejid>

Met le focus sur la fenêtre de discussion avec le contact par JID si elle est ouverte.

<surnom>

Met le focus sur la fenêtre de discussion avec le contact par surnom si elle est ouverte.

<roomjid>

Met le focus sur la fenêtre de discussion de la salle par roomjid si elle est ouverte.

<roomoccupantjid>

Met le focus sur la discussion privée roomoccupantjid si elle est ouverte.

xmlconsole

Met le focus sur la fenêtre Console XML si elle est ouverte.

<plugin>

Met le focus sur la fenêtre du plugin.

EXEMPLES

/win console

/win 4

/win odin@valhalla.edda

/win Eddie

/win bigroom@conference.chat.org

/win bigroom@conference.chat.org/thor

/win wikipedia
