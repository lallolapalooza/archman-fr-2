NOM

proxy - Outil de test de Libproxy

SYNTAXE

proxy [scheme://hôte][:port]

DESCRIPTION

Le programme proxy affiche le serveur proxy qui doit être utilisé pour atteindre une ressource réseau donnée. Vous pouvez fournir une URL en tant que paramètre ou démarrer l'outil en mode interactif pour entrer plusieurs URL. Comme valeur de retour, le proxy requis sera affiché.

libproxy est une bibliothèque qui gère la configuration automatique du proxy en utilisant différents backends.

EXEMPLE

# proxy http://www.example.com

# http://127.0.0.1:8080

SORTIE DEBOGAGE

Pour afficher plus de sorties de débogage, vous pouvez définir la variable d'environnement PX_DEBUG=1

Pendant l'exécution, l'outil affiche désormais des informations internes de la bibliothèque telles que les modules de plugin existants, quelle configuration est utilisée et les valeurs de retour.
