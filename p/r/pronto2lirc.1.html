NOM

pronto2lirc - convertir des données encodées en Pronto au format lircd.conf

SYNTAXE

pronto2lirc <fichier_entree>

DESCRIPTION

Convertit un fichier d'entrée dans un fichier au format lircd.conf. Le fichier d'entrée peut être :

  • Un fichier XML généré par CCFTools/CCFDecompiler.
  • Un fichier texte où chaque ligne contient le nom du bouton et tous les codes qui lui sont associés : 
             Bouton1:0000 00ac 000b 00de ...
pronto2lirc écrit le résultat dans un fichier lircd.conf dans le répertoire courant
contenant tous les codes Pronto extraits du fichier d'entrée.

OPTIONS

-h --help
Affiche un résumé de l'utilisation.
