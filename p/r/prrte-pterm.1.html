PTERM(1) Environnement d'exécution de référence PMIx PTERM(1)

pterm — termine une instance de l'environnement d'exécution de référence PRRTE

SYNOPSIS

shell$ pterm ...options...

DESCRIPTION

pterm termine une instance de la machine virtuelle distribuée (DVM) de l'environnement d'exécution de référence PMIx (PRRTE).

Une aide détaillée pour cette commande est fournie via pterm --help [sujet].

Pour l'instant, ce contenu n'est pas disponible sous forme de page man. Les demandes d'extraction pour ajouter tout le contenu (via une infrastructure répétable) seraient très appréciées.
