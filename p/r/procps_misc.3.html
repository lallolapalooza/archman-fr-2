PROCPS_MISC(3) Manuel des fonctions de bibliothèque PROCPS_MISC(3)

NOM

procps_misc - API pour les informations diverses dans le système de fichiers /proc

SYNOPSIS

#include <libproc2/misc.h>
Particularités de la plateforme
long         procps_cpu_count (void);
long         procps_hertz_get (void);
unsigned int procps_pid_length (void);
int          procps_linux_version (void);
Particularités d'exécution
int   procps_container_uptime (double *uptime_secs);
int   procps_loadavg (double *av1, double *av5, double *av15);
int   procps_uptime (double *uptime_secs, double *idle_secs);
int   procps_uptime_snprint ( char *restrict str, size_t size, double uptime_secs, const int pretty);
char *procps_uptime_sprint (void);
char *procps_uptime_sprint_short (void);
int   procps_users (void);
Particularités des namespaces
int         procps_ns_get_id (const char *name);
const char *procps_ns_get_name (int id);
int         procps_ns_read_pid (int pid, struct procps_ns *nsp);
Résolution des noms de masque
int procps_sigmask_names (char *const str, size_t size , const char *sigmask);
int procps_capmask_names (char *const str, size_t size,  const char *capmask);
Lier avec -lproc2.

DESCRIPTION

procps_cpu_count() renvoie le nombre de CPUs actuellement en ligne comme sysconf(_SC_NPROCESSORS_ONLY) ou 1 par défaut.

procps_hertz_get() renvoie le nombre de cycles d'horloge par seconde comme sysconf(_SC_CLK_TCK) ou 100 par défaut. Diviser les cycles par cette valeur donne les secondes.

procps_pid_length() renvoie la longueur maximale de la chaîne pour un PID sur le système. Par exemple, si la plus grande valeur PID possible était 123, alors la longueur serait 3. Si le fichier /proc/sys/kernel/pid_max ne peut pas être lu, la valeur est supposée être 5.

procps_linux_version() renvoie la version actuelle de Linux sous forme d'entier encodé. Sur les systèmes non-Linux qui ont un système de fichiers proc émulé, cette fonction renvoie la version de l'émulation Linux à la place. La version se compose de trois entiers positifs représentant les niveaux majeur, mineur et de correction. Les macros suivantes sont fournies pour encoder une version Linux donnée ou pour séparer les composants de la version actuelle.

LINUX_VERSION( major , minor , patch )

LINUX_VERSION_MAJOR( ver )

LINUX_VERSION_MINOR( ver )

LINUX_VERSION_PATCH( ver )

procps_loadavg() récupère la moyenne de charge du système et place les moyennes de 1, 5 et 15 minutes dans les emplacements spécifiés par tout pointeur qui n'est pas NULL.

procps_container_uptime() renvoie le temps de fonctionnement d'un conteneur dans l'emplacement spécifié par le pointeur s'il n'est pas NULL. Ceci est actuellement déterminé par le temps écoulé du PID 1, qui peut être obtenu avec la commande :


$ ps -o etimes 1
ELAPSED
12345

Il n'y a pas de concept de temps inactif dans un conteneur, donc procps_container_uptime() n'a pas ce paramètre.

procps_uptime() renvoie le temps de fonctionnement et/ou les secondes inactives dans les emplacements spécifiés par tout pointeur qui n'est pas NULL. Les variantes sprint renvoient une chaîne lisible par l'homme sous l'une des deux formes.

HH:MM:SS up HH:MM, # utilisateurs, charge moyenne : 1, 5, 15 moyennes MM

up HH, MM

procps_uptime_snprint() Utilise le tampon donné str d'une longueur size pour remplir la chaîne du temps de fonctionnement au lieu d'un tampon alloué statiquement. La fonction nécessite la valeur uptime_secs, qui peut être obtenue à partir de procps_uptime() ou procps_container_uptime() et le drapeau pretty détermine si la sortie est standard ou jolie/courte.

procps_users() renvoie le nombre d'utilisateurs sur le système. Cette valeur provient de sd_get_sessions(3) et compte les sessions de la classe user, user-early et user-incomplete ou en énumérant via getutent(3).

procps_ns_get_id() renvoie l'identifiant entier (enum namespace_type) du namespace pour le name de namespace donné.

procps_ns_get_name() renvoie le nom du namespace pour l'id id donné (enum namespace_type).

procps_ns_read_pid() renvoie les inodes pour les namespaces du processus donné dans la structure procps_ns pointée par nsp. Ces inodes apparaîtront dans l'ordre prescrit par enum namespace_type.

enum namespace_type {
    PROCPS_NS_CGROUP,
    PROCPS_NS_IPC,
    PROCPS_NS_MNT,
    PROCPS_NS_NET,
    PROCPS_NS_PID,
    PROCPS_NS_TIME,
    PROCPS_NS_USER,
    PROCPS_NS_UTS
};

procps_sigmask_names() Remplit str avec une chaîne de texte lisible par l'homme de jusqu'à size octets des signaux définis dans le masque de signaux hexadécimal sigmask, voir signal(7). Si la liste des signaux dépasse size octets, la chaîne sera tronquée et se terminera par un '+'. Il incombe au programme appelant de s'assurer que str est correctement alloué avec au moins size octets.

procps_capmask_names() Remplit str avec une chaîne de texte lisible par l'homme de jusqu'à size octets des capacités définies dans le masque de capacités hexadécimal capmask, voir capabilities(7). Si la liste des capacités dépasse size octets, la chaîne sera tronquée et se terminera par un '+'. Il incombe au programme appelant de s'assurer que str est correctement alloué avec au moins size octets.

Pour un processus qui n'a pas de capacités ou toutes les capacités, la chaîne sera "-" et "full" respectivement.

VALEUR DE RETOUR

Fonctions retournant un ‘int’ ou ‘long’

Une erreur sera indiquée par un nombre négatif qui est toujours l'inverse d'une valeur bien connue de errno.h.

Fonctions retournant une ‘adresse’

Une erreur sera indiquée par un pointeur de retour NULL avec la raison trouvée dans la valeur formelle errno.

FICHIERS

/proc/loadavg
Les valeurs brutes de la moyenne de charge.
/proc/sys/kernel/osrelease
Contient la version de publication du noyau Linux ou du système de fichiers proc.
/proc/sys/kernel/pid_max
Contient la valeur à laquelle les PIDs reviennent à zéro, un de plus que la valeur PID maximale.
/proc/uptime
Les valeurs brutes du temps de fonctionnement et du temps inactif du système.
/proc/PID/ns
contient l'ensemble des namespaces pour un PID particulier.

VOIR AUSSI

procps(3), procps_pids(3), getutent(3), sd_get_sessions(3), proc(5), capabilities(7), signal(7).
