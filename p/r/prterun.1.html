PRTERUN(1) Environnement d'exécution de référence PMIx PRTERUN(1)

prterun — lance une application avec un DVM par défaut

SYNTAXE

shell$ prterun ...options...

DESCRIPTION

prterun soumet un travail à l'environnement d'exécution de référence PMIx (PRRTE). Un ensemble par défaut d'options de machine virtuelle distribuée (DVM) est utilisé ; utilisez prun(1) si vous souhaitez utiliser des options DVM spécifiques.

Une grande partie de cette même documentation d'aide pour cette commande est également fournie via prun --help [sujet].
