NOM

/join

DESCRIPTION

Rejoindre une salle de discussion sur le serveur de conférence. Si aucune salle n'est spécifiée, un nom sera généré avec le format private-chat-[UUID]. Si la partie domaine n'est pas incluse dans le nom de la salle, la préférence de compte 'muc.service' sera utilisée. Si aucun pseudonyme n'est spécifié, la préférence de compte 'muc.nick' sera utilisée, qui par défaut est la partie locale de votre JID. Si la salle n'existe pas et que le serveur le permet, une nouvelle sera créée. Si vous rejoignez une salle souvent, vous pourriez également vouloir ajouter un signet (voir `/help bookmark`), qui permet également de définir un pseudonyme par défaut. Dans ce cas, vous devriez utiliser `/bookmark join`.

SYNTAXE

/join

/join <salle> [nick <nick>] [password <mot de passe>]

ARGUMENTS

<salle>

La salle de discussion à rejoindre.

nick <nick>

Pseudonyme à utiliser dans la salle.

password <mot de passe>

Mot de passe si la salle en requiert un.

EXEMPLES

/join

/join profanity@rooms.dismail.de

/join profanity@rooms.dismail.de nick monnick

/join private@conference.jabber.org nick monnick password monmotdepasse

/join ma_chaine
