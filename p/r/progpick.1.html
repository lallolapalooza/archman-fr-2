progpick(1) Manuel des commandes générales progpick(1)

NOM

progpick - Force brute avec un flux de permutations d'un modèle spécifique

SYNTAXE

progpick [-vqc] [-e cmd] MODÈLE

DESCRIPTION

progpick est un programme destiné à générer des permutations d'un modèle explicitement fourni. Il est utile si vous avez oublié certains détails d'une phrase de passe, mais que vous vous en souvenez encore en grande partie.

OPTIONS

-v, --verbose

Journaux verbeux (peut être utilisé plusieurs fois, maximum : 4)

-q, --quiet

Ne pas afficher la barre de progression

-c, --count

Compter le nombre total de permutations au lieu de les afficher

-e cmd, --exec cmd

Envoyer les permutations à l'entrée standard d'un sous-processus. cmd est analysé en une liste d'arguments, puis exécuté directement au lieu de passer par /bin/sh, donc le placement entre guillemets shell fonctionne, mais d'autres fonctionnalités shell ne fonctionnent pas.

-h, --help

Affiche les informations d'aide.

EXEMPLES

Générer toutes les combinaisons de a-z avec une longueur de 5

progpick '{a..z}{a..z}{a..z}{a..z}{a..z}'

Avec barre de progression

progpick '{a..z}{a..z}{a..z}{a..z}{a..z}' > /dev/null

Sans barre de progression

progpick -q '{a..z}{a..z}{a..z}{a..z}{a..z}' > /dev/null

Pour rendre un caractère facultatif

progpick '{a..z}{{a..z},}'

De a-z et 0-9

progpick '{{a..z},{0..9}}'

Exécuter un script pour chaque résultat

progpick 'a{b,c{d,e{f,g}}}' | while read -r x; do
./script "$x"
done

Envoyer le résultat à l'entrée standard d'un script

progpick -e './script.sh' 'a{b,c{d,e{f,g}}}'

Tenter d'ouvrir une partition luks

sudo progpick -e 'cryptsetup open --test-passphrase /dev/sdc1' 'a{b,c{d,e{f,g}}}'
