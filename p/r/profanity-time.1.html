profanity-time(1)

Paquet: profanity

Licences: GPL3

man(1) Client XMPP Profanity man(1)

NOM

/time

DESCRIPTION

Configure les préférences d'affichage de l'heure. Les formats d'heure sont des chaînes prises en charge par g_date_time_format. Voir https://developer.gnome.org/glib/stable/glib-GDateTime.html#g-date-time-format pour plus de détails. Définir le format sur une chaîne non prise en charge affichera la chaîne. Si le format contient des espaces, il doit être entouré de guillemets doubles. Il est possible de passer le format sous la forme 'iso8601' afin de définir le format de l'heure selon la norme ISO-8601 (heure locale uniquement, sans indicateur de fuseau horaire).

SYNTAXE

/time all|console|chat|muc|config|private|xml set <format>

/time all|console|chat|muc|config|private|xml off

/time statusbar set <format>

/time statusbar off

/time lastactivity set <format>

/time vcard set <format>

ARGUMENTS

console set <format>

Définit le format de l'heure pour la fenêtre de la console.

console off

N'affiche pas l'heure dans la fenêtre de la console.

chat set <format>

Définit le format de l'heure pour les fenêtres de chat.

chat off

N'affiche pas l'heure dans les fenêtres de chat.

muc set <format>

Définit le format de l'heure pour les fenêtres de salon de discussion (MUC).

muc off

N'affiche pas l'heure dans les fenêtres de salon de discussion.

config set <format>

Définit le format de l'heure pour les fenêtres de configuration.

config off

N'affiche pas l'heure dans les fenêtres de configuration.

private set <format>

Définit le format de l'heure pour les fenêtres de chat privé.

private off

N'affiche pas l'heure dans les fenêtres de chat privé.

xml set <format>

Définit le format de l'heure pour la fenêtre de la console XML.

xml off

N'affiche pas l'heure dans la fenêtre de la console XML.

statusbar set <format>

Change le format de l'heure dans la barre d'état.

statusbar off

N'affiche pas l'heure dans la barre d'état.

lastactivity set <format>

Change le format de l'heure pour la dernière activité.

vcard set <format>

Change le format de l'heure utilisé pour afficher l'heure/les dates dans la vCard (comme les anniversaires).

all set <format>

Définit l'heure pour : les fenêtres console, chat, muc, config, private et xml.

all off

N'affiche pas l'heure pour : les fenêtres console, chat, muc, config, private et xml.

EXEMPLES

/time console set %H:%M:%S

/time chat set "%d-%m-%y %H:%M:%S"

/time xml off

/time statusbar set %H:%M

/time lastactivity set "%d-%m-%y %H:%M:%S"

/time all set "%d-%m-%y %H:%M:%S"

/time all set iso8601
