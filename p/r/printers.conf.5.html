NOM

printers.conf - fichier de configuration de l'imprimante pour cups

DESCRIPTION

Le fichier printers.conf définit les imprimantes locales disponibles. Il est normalement situé dans le répertoire /etc/cups et est maintenu par le programme cupsd(8). Ce fichier n'est pas destiné à être modifié ou géré manuellement.

NOTES

Le nom, l'emplacement et le format de ce fichier sont des détails d'implémentation qui changeront dans les futures versions de CUPS.
