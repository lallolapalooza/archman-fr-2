NOM

/log

DESCRIPTION

Gérer les paramètres de journalisation de profanity.

SYNTAXE

/log where

/log rotate on|off

/log maxsize <octets>

/log shared on|off

/log level INFO|DEBUG|WARN|ERROR

ARGUMENTS

where

Affiche l'emplacement actuel du fichier journal.

rotate on|off

Fait pivoter le journal, par défaut activé. N'a pas d'effet si vous avez spécifié un nom de fichier vous-même au démarrage de Profanity.

maxsize <octets>

Avec la rotation activée, spécifie la taille maximale du journal, par défaut 10485760 (10 Mo).

shared on|off

Partage les journaux entre toutes les instances, par défaut : activé. Si désactivé, l'identifiant du processus sera inclus dans le nom du fichier journal. N'a pas d'effet si vous avez spécifié un nom de fichier vous-même au démarrage de Profanity.

level INFO|DEBUG|WARN|ERROR

Définit le niveau du journal. Par défaut : INFO. Ne fonctionne qu'avec le fichier journal par défaut, pas avec un fichier journal fourni par l'utilisateur au démarrage via -f.
