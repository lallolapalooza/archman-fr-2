NOM

pam_usertype - vérifie si l'utilisateur authentifié est un compte système ou régulier

SYNTAXE

pam_usertype.so [indicateur...] {condition}

DESCRIPTION

pam_usertype.so est conçu pour réussir ou échouer l'authentification en fonction du type de compte de l'utilisateur authentifié. Le type de compte est décidé à l'aide du paramètre SYS_UID_MAX dans /etc/login.defs. Une utilisation consiste à sélectionner si d'autres modules doivent être chargés en fonction de ce test.

Le module ne devrait recevoir qu'une seule condition comme argument de module. L'authentification ne réussira que si la condition est remplie.

OPTIONS

Les indicateurs suivants sont pris en charge :

use_uid

Évalue les conditions en utilisant le compte de l'utilisateur sous lequel l'application s'exécute au lieu de l'utilisateur en cours d'authentification.

audit

Enregistre les utilisateurs inconnus dans le journal système.

Les conditions disponibles sont :

issystem

Réussit si l'utilisateur est un utilisateur système.

isregular

Réussit si l'utilisateur est un utilisateur régulier.

TYPES DE MODULES FOURNIS

Tous les types de modules (account, auth, password et session) sont fournis.

VALEURS DE RETOUR

PAM_SUCCESS

La condition était vraie.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_CONV_ERR

La méthode de conversation fournie par l'application n'a pas réussi à obtenir le nom d'utilisateur.

PAM_INCOMPLETE

La méthode de conversation fournie par l'application a renvoyé PAM_CONV_AGAIN.

PAM_AUTH_ERR

La condition était fausse.

PAM_SERVICE_ERR

Une erreur de service s'est produite ou les arguments n'ont pas pu être analysés correctement.

PAM_USER_UNKNOWN

Utilisateur introuvable.

EXEMPLES

Ignorer les modules restants si l'utilisateur est un utilisateur système :

account sufficient pam_usertype.so issystem

VOIR AUSSI
