NOM

pam_get_user - obtenir le nom d'utilisateur

SYNTAXE

#include <security/pam_modules.h>

int pam_get_user(const pam_handle_t *pamh, const char **user, const char *prompt);

DESCRIPTION

La fonction pam_get_user retourne le nom de l'utilisateur spécifié par pam_start(3). Si aucun utilisateur n'a été spécifié, elle retourne ce que pam_get_item (pamh, PAM_USER, ... ); aurait retourné. Si cela est NULL, elle obtient le nom d'utilisateur via le mécanisme de pam_conv(3), elle demande à l'utilisateur avec la première chaîne non-NULL dans la liste suivante :

•L'argument prompt passé à la fonction.
•Ce qui est retourné par pam_get_item (pamh, PAM_USER_PROMPT, ... );
•La demande par défaut : "login: "

Par quelque moyen que le nom d'utilisateur soit obtenu, un pointeur vers celui-ci est retourné comme contenu de *user. Notez que cette mémoire ne doit pas être free()d ou modifiée par le module.

Cette fonction définit l'élément PAM_USER associé aux fonctions pam_set_item(3) et pam_get_item(3).

VALEURS DE RETOUR

PAM_SUCCESS

Le nom d'utilisateur a été récupéré avec succès.

PAM_SYSTEM_ERR

Un pointeur NULL a été soumis.

PAM_CONV_ERR

La méthode de conversation fournie par l'application n'a pas réussi à obtenir le nom d'utilisateur.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_ABORT

Erreur lors de la reprise d'une ancienne conversation.

PAM_CONV_AGAIN

La méthode de conversation fournie par l'application attend un événement.

VOIR AUSSI

pam_end(3), pam_get_item(3), pam_set_item(3), pam_strerror(3)
