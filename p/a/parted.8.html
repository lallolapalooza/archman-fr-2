PARTED(8) Manuel GNU Parted PARTED(8)

NOM

parted - un programme de manipulation de partitions

SYNTAXE

parted [options] [périphérique [commande [options...]...]]

DESCRIPTION

parted est un programme permettant de manipuler des partitions de disque. Il prend en charge plusieurs formats de table de partitions, y compris MS-DOS et GPT. Il est utile pour créer de l'espace pour de nouveaux systèmes d'exploitation, réorganiser l'utilisation du disque et copier des données sur de nouveaux disques durs.

Cette page de manuel décrit parted brièvement. La documentation complète est distribuée avec le paquet sous forme GNU Info.

OPTIONS

-h, --help
affiche un message d'aide
-l, --list
liste la disposition des partitions sur tous les périphériques bloc
-m, --machine
affiche une sortie analysable par machine
-j, --json
affiche une sortie JSON
-s, --script
ne demande jamais d'intervention utilisateur
-f, --fix
répond automatiquement "fix" aux exceptions en mode script
-v, --version
affiche la version
-a type-alignement, --align type-alignement
Définit l'alignement pour les nouvelles partitions créées, les types d'alignement valides sont :
none
Utilise l'alignement minimum autorisé par le type de disque.
cylinder
Aligne les partitions sur les cylindres.
minimal
Utilise l'alignement minimum tel que fourni par les informations de topologie du disque. Ceci et la valeur opt utiliseront les informations de disposition fournies par le disque pour aligner les adresses de la table de partitions logique sur les blocs physiques réels des disques. La valeur min est l'alignement minimum requis pour aligner correctement la partition sur les blocs physiques, ce qui évite la dégradation des performances.
optimal
Utilise l'alignement optimal tel que fourni par les informations de topologie du disque. Ceci s'aligne sur un multiple de la taille des blocs physiques d'une manière qui garantit des performances optimales.

COMMANDES

[périphérique]
Le périphérique bloc à utiliser. Lorsqu'aucun n'est donné, parted utilisera le premier périphérique bloc qu'il trouve.
[commande [options]]
Spécifie la commande à exécuter. Si aucune commande n'est donnée, parted présentera une invite de commande. Les commandes possibles sont :
help [commande]
Affiche l'aide générale, ou l'aide sur la commande si spécifiée.
align-check type partition
Vérifie si la partition respecte la contrainte d'alignement du type. Le type doit être "minimal" ou "optimal".
mklabel type-étiquette
Crée une nouvelle étiquette de disque (table de partitions) de type-étiquette. Le type-étiquette doit être l'un des suivants : "aix", "amiga", "bsd", "dvh", "gpt", "loop", "mac", "msdos", "pc98", ou "sun".
mkpart [type-part nom type-fs] début fin
Crée une nouvelle partition. type-part peut être spécifié uniquement avec les tables de partitions msdos et dvh, il doit être l'un des suivants : "primary", "logical", ou "extended". nom est requis pour les tables de partitions GPT et type-fs est optionnel. type-fs peut être l'un des suivants : "btrfs", "ext2", "ext3", "ext4", "fat16", "fat32", "hfs", "hfs+", "linux-swap", "ntfs", "reiserfs", "udf", ou "xfs".
name partition nom
Définit le nom de la partition à nom. Cette option ne fonctionne que sur les étiquettes de disque Mac, PC98 et GPT. Le nom peut être placé entre guillemets doubles, si nécessaire. Et selon le shell, il peut également être nécessaire de l'entourer de guillemets simples afin que le shell ne supprime pas les guillemets doubles.
print type-impression
Affiche la table de partitions. type-impression est facultatif, et peut être l'un des suivants : devices, free, list, ou all.
quit
Quitte parted.
rescue début fin
Récupère une partition perdue qui était située entre début et fin. Si une partition est trouvée, parted demandera si vous voulez créer une entrée pour elle dans la table de partitions.
resizepart partition fin
Modifie la position de fin de la partition. Notez que cela ne modifie aucun système de fichiers présent dans la partition.
rm partition
Supprime la partition.
select périphérique
Choisit le périphérique comme périphérique actuel à éditer. Le périphérique devrait généralement être un périphérique disque dur Linux, mais il peut être une partition, un périphérique RAID logiciel ou un volume logique LVM si nécessaire.
set partition flag état
Modifie l'état du flag sur la partition à état. Les flags supportés sont : "boot", "root", "swap", "hidden", "raid", "lvm", "lba", "legacy_boot", "irst", "msftres", "esp", "chromeos_kernel", "bls_boot", "linux-home", "no_automount", "bios_grub", et "palo". L'état doit être soit "on" soit "off".
unit unité
Définit unité comme unité à utiliser lors de l'affichage des emplacements et des tailles, et pour l'interprétation de ceux fournis par l'utilisateur lorsqu'ils ne sont pas suffixés avec une unité explicite. L'unité peut être l'une des suivantes : "s" (secteurs), "B" (octets), "kB", "MB", "KiB", "MiB", "GB", "GiB", "TB", "TiB", "%" (pourcentage de la taille du périphérique), "cyl" (cylindres), "chs" (cylindres, têtes, secteurs), ou "compact" (mégaoctets pour l'entrée, et une forme lisible par l'homme pour la sortie).
toggle partition flag
Inverse l'état du flag sur la partition.
type partition id ou uuid
Sur MS-DOS, définit le type dit. ID de partition de la partition à id. L'id est une valeur comprise entre "0x01" et "0xff". Sur GPT, l'UUID de type de la partition à uuid.
disk_set flag état
Modifie un flag sur le disque à l'état. Un flag peut être "on" ou "off". Certains ou tous ces flags seront disponibles, selon l'étiquette de disque que vous utilisez. Les flags supportés sont : "pmbr_boot" sur GPT pour activer le flag de démarrage sur la partition MBR protectrice de GPT.

parted.8.fr

NOM

parted — utilitaire de partitionnement de disque

SYNOPSIS

parted [OPTION]... [DEVICE [COMMAND]...]

DESCRIPTION

parted est un programme de partitionnement de disque permettant de créer, supprimer, vérifier et modifier des tables de partitions et des partitions. parted prend en charge un certain nombre de formats de table de partitions, y compris les styles MSDOS et GPT. Les commandes peuvent être données sur la ligne de commande, et parted entrera dans un mode interactif si aucune commande n'est spécifiée.

DEVICE est généralement un nom de périphérique comme /dev/sda.

Pour rendre les changements effectifs, vous devrez peut-être redémarrer le système, ou utiliser les utilitaires appropriés du noyau.

OPTIONS

--automake
N'est pas pris en charge, mais il est présent pour la compatibilité avec les versions futures.
--capacity[=UNIT]
Affiche les tailles de partition en unités lisibles par l'homme (par exemple, 10GiB) au lieu de blocs. L'unité peut être B, KiB, MiB, GiB, TiB, etc. Par défaut, il est activé.
--debug
Active l'impression de messages de débogage à la sortie d'erreur standard. Notez que cette option ne permet pas d'activer le débogage des opérations de stockage sous-jacentes.
--script [SCRIPT]
Exécute parted en mode script. Il est utile pour exécuter des opérations de partitionnement non interactives. Si SCRIPT est spécifié, les commandes sont lues à partir de ce fichier ; sinon, elles sont lues depuis l'entrée standard. Voir la section COMMANDES ci-dessous pour la syntaxe des commandes dans le mode script. En mode script, parted ne génère pas de messages d'invite ou d'autres messages non essentiels, sauf si l'option --verbose est également spécifiée.
--help
Affiche un message d'aide et quitte.
--machine
Affiche la sortie au format machine. Ceci est destiné à être analysé par des programmes.
--verbosity=NIVEAU
Définit le niveau de verbosité. Les valeurs possibles sont quiet, normal et verbose.
--version
Affiche les informations de version et un message de copyright.

COMMANDES

Les commandes suivantes peuvent être données sur la ligne de commande (en mode script) ou tapées dans l'invite interactive.

(parted) help [[motif]]
Demande de l'aide.
(parted) mklabel, mktable LABEL-TYPE
Crée une nouvelle table de partitions vide du type LABEL-TYPE (par exemple, gpt, msdos, loop). Cela effacera toutes les partitions existantes sur le disque.
(parted) mkpart PART-TYPE FS-TYPE START END
Crée une partition avec les spécifications données. PART-TYPE est soit primary, extended, ou logical. FS-TYPE est le type du système de fichiers qui sera stocké dans la partition (par exemple, ext2, linux-swap). START et END sont les positions de début et de fin de la partition. Les unités peuvent être en Mo, Go, etc. (par exemple, 100MiB).
(parted) rm PARTITION
Supprime la partition spécifiée par le numéro de partition.
(parted) print [[major minor]]
Affiche une liste des partitions sur le disque.
(parted) quit
Quitte le programme.
(parted) rescue [START END]
Tente de trouver des partitions perdues dans la plage spécifiée.
(parted) resizepart PARTITION END
Redimensionne la partition spécifiée à la nouvelle fin.
(parted) select DEVICE
Sélectionne le périphérique à modifier.
(parted) set PARTITION FLAG [on|off]
Définit ou désactive un drapeau pour la partition donnée. Les drapeaux disponibles dépendent du type de table de partitions. Les drapeaux courants pour les partitions MS-DOS incluent boot, root, swap. Les drapeaux pour GPT incluent boot, esp, legacy_boot, msdata.
(parted) align-check TYPE PARTITION
Vérifie que le début et la fin de la partition sont alignés sur le type spécifié. Les types courants sont minimal et optimal.
(parted) check [PARTITION]
Vérifie l'intégrité de la table de partitions ou d'une partition spécifique.
(parted) cp [FROM-DISK [FROM-PART [TO-PART]]]
Copie les partitions d'un disque à un autre.
(parted) expand PARTITION NEW-END
Étends la partition au nouvelle fin spécifiée.
(parted) help [[motif]]
Demande de l'aide.
(parted) label, mklabel LABEL-TYPE
Crée une nouvelle table de partitions vide du type LABEL-TYPE (par exemple, gpt, msdos, loop). Cela effacera toutes les partitions existantes sur le disque.
(parted) name PARTITION NAME
Donne un nom à la partition spécifiée.
(parted) move PARTITION NEW-START [NEW-END]
Déplace la partition spécifiée vers une nouvelle position.
(parted) print [[major minor]]
Affiche une liste des partitions sur le disque.
(parted) quit
Quitte le programme.
