NOM

paclist - lister tous les paquets installés à partir d'un dépôt donné

SYNTAXE

paclist <dépôt ...>

DESCRIPTION

paclist listera tous les paquets installés sur le système à partir d'un dépôt donné. Utile pour voir quels paquets vous avez peut-être installés à partir des dépôts de test, par exemple.

Exemple : paclist core-testing

OPTIONS

-h, --help

Afficher la syntaxe et les options de la ligne de commande.

-V, --version

Afficher les informations de version.

VOIR AUSSI

pacman(8)

BOGUES

Des bogues ? Vous devez plaisanter ; il n'y a pas de bogues dans ce logiciel. Mais si nous nous trompions, déposez un incident avec autant de détails que possible sur https://gitlab.archlinux.org/pacman/pacman-contrib/-/issues/new.
