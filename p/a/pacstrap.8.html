NOM

pacstrap - installe des paquets dans le répertoire racine nouveau spécifié

SYNTAXE

pacstrap [options] racine [paquets...]

DESCRIPTION

pacstrap est conçu pour créer une nouvelle installation système à partir de zéro. Les paquets spécifiés seront installés dans un répertoire donné après la configuration de quelques points de montage de base. Par défaut, les clés de signature pacman et la liste des miroirs du système hôte seront utilisées pour amorcer l'environnement chroot.

Si aucun paquet n'est spécifié pour être installé, le méta-paquet base sera installé.

OPTIONS

-C <config>

Utilise un fichier de configuration alternatif pour pacman.

-c

Utilise le cache de paquets de l'hôte, plutôt que celui de la cible.

-D

Ignore les vérifications de dépendances de pacman.

-G

Évite de copier le trousseau de clés pacman de l'hôte vers la cible.

-i

Demande une confirmation pour les paquets si nécessaire (exécution interactive).

-K

Initialise un trousseau de clés pacman vide dans la cible (implique -G).

-M

Évite de copier la liste des miroirs de l'hôte vers la cible.

-N

S'exécute en mode unshare. Ceci utilisera unshare(1) pour créer un nouvel espace de montage et utilisateur, permettant aux utilisateurs ordinaires de créer de nouvelles installations système.

-P

Copie la configuration pacman de l'hôte vers la cible.

-U

Utilise pacman -U pour installer les paquets. Utile pour obtenir un contrôle précis sur les paquets installés.

-h

Affiche la syntaxe et les options de la ligne de commande.

VOIR AUSSI
