PARTCLONE.DD(8) Manuel Utilisateur Partclone PARTCLONE.DD(8)

NOM

partclone.dd - utilitaire de sauvegarde de système de fichiers non pris en charge (comme `dd`)

SYNTAXE

partclone.dd {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] cible} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] logfile [-R | --rescue] [-L | --logfile] logfile [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPTION

partclone.dd fait partie du projet Partclone pour cloner les systèmes de fichiers non pris en charge avec la méthode dd. Il sauvegardera tous les blocs de la partition. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une compatibilité accrue des systèmes de fichiers en utilisant des bibliothèques existantes, par exemple, e2fslibs est utilisé pour lire les blocs utilisés des partitions ext2.

Les systèmes de fichiers pris en charge par Partclone incluent btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Il prend également en charge certains systèmes d'exploitation non-Linux, par exemple : NTFS et FAT (pour Windows), HFS plus (MAC OS d'APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere). Tous les utilitaires partclone peuvent être exécutés comme partclone.xxx, ce qui est très similaire à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, exécutez simplement partclone.hfsp.

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-s FICHIER, --source FICHIER

FICHIER source. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique, selon votre action. Normalement, la source de sauvegarde est un périphérique, la source de restauration est un fichier image.

La réception de données à partir d'un pipeline n'est prise en charge QUE pour la restauration. Ignorez simplement l'option -s ou utilisez '-' pour recevoir des données depuis stdin.

-o FICHIER, --output FICHIER

FICHIER de sortie. Le FICHIER peut être un fichier image (que partclone générera) ou un périphérique, selon votre action. Normalement, la sortie de sauvegarde vers un fichier image et la sortie de restauration vers un périphérique.

L'envoi de données vers un pipeline est également pris en charge UNIQUEMENT pour la sauvegarde. Ignorez simplement l'option -o ou utilisez '-' pour envoyer des données vers stdout.

-O FICHIER, --overwrite FICHIER

Écrase FICHIER, en écrasant s'il existe.

-W FICHIER, --restore_raw_file FICHIER

crée un fichier brut spécial pour le périphérique de boucle.

-D, --domain

Crée un fichier journal de domaine GNU Ddrescue à partir du périphérique source. C'est un fichier lisible par l'homme dans lequel + marque les zones de blocs utilisées et ? marque les zones libres.

--offset_domain=X

Ajoute X (en octets) à toutes les positions signalées dans le fichier journal de domaine.

--restore_raw_file

Crée un fichier brut spécial pour le périphérique de boucle.

-L FICHIER, --logfile FICHIER

spécifie un chemin spécial pour enregistrer les informations du journal partclone. (par défaut /var/log/partclone.log)

-R, --rescue

Continue après les erreurs de lecture du disque.

-C, --no_check

Ne vérifie pas la taille du périphérique ni l'espace libre.

-N, --ncurses

Utilise l'interface utilisateur textuelle Ncurses.

-I, --ignore_fschk

Ignore la vérification du système de fichiers.

-i, --ignore_crc

Ignore les erreurs de vérification crc.

-F, --force

Force la progression.

-f sec, --UI-fresh sec

spécifie un intervalle en secondes pour la mise à jour.

-z taille, --buffer_size taille

Taille du tampon de lecture/écriture (par défaut : 1048576)

-q, --quiet

Désactive le message de progression.

-dniveau, --debug niveau

Définit le niveau de débogage [1|2|3]

-aX, --checksum-mode=X

Formule de somme de contrôle à utiliser pour ajouter la détection d'erreurs

où X :

0 : Pas de somme de contrôle (pas de ralentissement, image la plus petite)

1 : CRC32 (Rapide à calculer, détection de base)

-kX, --blocks-per-checksum=X

Écrit une somme de contrôle pour chaque X blocs.

-w, --skip_write_error

Continue la restauration en cas d'erreurs d'écriture.

--write-direct-io

Écrit les données dans la partition CIBLE sans cache.

--read-direct-io

Lit les données depuis la partition SOURCE sans cache.

-B, --no_block_detail

Affiche le message de progression sans détails sur les blocs.

--binary-prefix

Affiche la progression avec la taille en bits (par défaut, c'est Mo, Go...).

--prog-second

Affiche la progression en secondes (par défaut, c'est en minutes).

-E, --offset=X

Ajoute un décalage X (en octets) à la SORTIE.

-T, --btfiles

Restaure le bloc comme fichier pour ClonezillaBT.

-t, --btfiles_torrent

Restaure le bloc comme fichier pour ClonezillaBT mais ne génère que le torrent.

-h, --help

Affiche un résumé des options.

-v, --version

Affiche la version du programme.

FICHIERS

/var/log/partclone.log

Le fichier journal de partclone.dd

EXEMPLES

 Cloner /dev/hda1 vers hda1.dd.img et afficher les informations de débogage.
   partclone.dd -d -s /dev/hda1 -o hda1.dd.img
 Restaurer /dev/hda1 depuis hda1.dd.img et afficher les informations de débogage.
   partclone.dd -d -s hda1.dd.img -o /dev/hda1

DIAGNOSTICS

Les diagnostics suivants peuvent être émis sur stderr :

partclone.dd fournit des codes de retour, qui peuvent être utilisés dans les scripts :

Code Diagnostic
0 Le programme s'est terminé avec succès.
1 Le clonage ou la restauration semble avoir échoué.
