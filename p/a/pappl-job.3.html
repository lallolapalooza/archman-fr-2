DESCRIPTION

Les fonctions de travaux PAPPL fournissent un accès à l'objet de travail. Les travaux et le cycle de vie des objets pappl_job_t sont gérés automatiquement par l'objet système pour l'application imprimante.

Les fonctions papplJobGet obtiennent les valeurs actuelles associées à un travail, tandis que les fonctions papplJobSet définissent les valeurs actuelles associées à un travail.

La fonction papplJobCancel annule le traitement d'un travail, tandis que la fonction papplJobIsCanceled renvoie si un travail est dans l'état annulé (IPP_JSTATE_CANCELED) ou en cours d'annulation (IPP_JSTATE_PROCESSING et PAPPL_JREASON_PROCESSING_TO_STOP_POINT).

La fonction papplJobOpenFile ouvre un fichier associé au travail. Le descripteur de fichier doit être fermé par l'appelant à l'aide de l'appel système close(2).

La fonction papplJobFilterImage convertit les données d'image brutes en données rasterisées appropriées pour l'imprimante.

FONCTIONS

papplJobCancel

Annuler un travail.

void papplJobCancel (
    pappl_job_t *job
);

Cette fonction annule le travail spécifié. Si le travail est en cours d'impression, il sera arrêté à un moment opportun (généralement à la fin d'une page) afin que l'imprimante soit laissée dans un état connu.

papplJobCreatePrintOptions

Créer les options d'impression pour un travail.

pappl_pr_options_t * papplJobCreatePrintOptions (
    pappl_job_t *job,
    unsigned num_pages,
    bool color
);

Cette fonction alloue une structure d'options d'impression et calcule les options d'impression pour un travail en fonction des attributs du modèle de travail soumis dans la requête d'impression et des valeurs par défaut définies dans les données du pilote d'imprimante.

Les arguments "num_pages" et "color" spécifient le nombre de pages et si le document contient des couleurs non-gris - ces informations proviennent généralement de l'analyse du fichier de travail.

papplJobCreateWithFile

Créer un travail avec un fichier local.

pappl_job_t * papplJobCreateWithFile (
    pappl_printer_t *printer,
    const char *username,
    const char *format,
    const char *job_name,
    int num_options,
    cups_option_t *options,
    const char *filename
);

Cette fonction crée un nouveau travail d'impression avec un fichier local. Les paramètres "num_options" et "options" spécifient des options d'impression supplémentaires, si nécessaire. Le fichier spécifié par "filename" est automatiquement supprimé s'il réside dans le répertoire de file d'attente.

papplJobDeletePrintOptions

Supprimer une structure d'options de travail.

void papplJobDeletePrintOptions (
    pappl_pr_options_t *options
);

Cette fonction libère la mémoire utilisée par une structure d'options de travail.

papplJobFilterImage

Filtrer une image en mémoire.

bool  papplJobFilterImage (
    pappl_job_t *job,
    pappl_device_t *device,
    pappl_pr_options_t *options,
    const unsigned char *pixels,
    int width,
    int height,
    int depth,
    int ppi,
    bool smoothing
);

Cette fonction imprimera une image en niveaux de gris ou sRGB en utilisant l'interface du pilote raster de l'imprimante, en redimensionnant et en positionnant l'image si nécessaire en fonction des options du travail, et en imprimant autant de copies que demandé.

Les données de l'image sont un tableau de pixels en niveaux de gris ("depth" = 1) ou sRGB ("depth" = 3) commençant dans le coin supérieur gauche de l'image.

La résolution de l'image ("ppi") est exprimée en pixels par pouce et est utilisée pour certains modes "print-scaling". Passez 0 si l'image n'a pas d'informations de résolution explicites.

papplJobGetState

Obtenir l'état actuel du travail.

ipp_jstate_t  papplJobGetState (
    pappl_job_t *job
);

Cette fonction renvoie l'état de traitement actuel du travail, qui est représenté par une énumération :

  • IPP_JSTATE_ABORTED : Le travail a été abandonné par le système en raison d'une erreur.
  • IPP_JSTATE_CANCELED : Le travail a été annulé par un utilisateur.
  • IPP_JSTATE_COMPLETED : Le travail a terminé son impression.
  • IPP_JSTATE_HELD : Le travail est retenu pour une raison quelconque, typiquement parce que
    les données du document sont en cours de réception.
  • IPP_JSTATE_PENDING : Le travail est dans la file d'attente et attend d'être imprimé.
  • IPP_JSTATE_PROCESSING : Le travail est en cours d'impression.
  • IPP_JSTATE_STOPPED : Le travail est mis en pause, généralement lorsque l'imprimante n'est pas
    prête.</li> </ul>

    pappl_job_t *job,

    const char *ext,
    const char *mode
);


This function creates or opens a file for a job. The
    "fname" and "fnamesize" arguments specify the location
    and size of a buffer to store the job filename, which incorporates the
    "directory", printer ID, job ID, job name (title), and
    "ext" values. The job name is "sanitized" to only
    contain alphanumeric characters.


The "mode" argument is "r" to read an existing
    job file or "w" to write a new job file. New files are created
    with restricted permissions for security purposes.
