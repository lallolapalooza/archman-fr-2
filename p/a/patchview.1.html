patchview(1)

Paquet: patchutils

Licences: GPL

PATCHVIEW(1) Pages man PATCHVIEW(1)

NOM

patchview - Sans options, affiche les fichiers numérotés modifiés par le patch. Avec des options, se comporte comme filterdiff.

SYNTAXE

patchview [[-n] | [--line-number]] [[-p n] | [--strip-match=n]] [--strip=n] [--addprefix=PREFIX] [[-s] | [--status]] [[-E] | [--empty-files-as-removed]] [[-i PATTERN] | [--include=PATTERN]] [[-x PATTERN] | [--exclude=PATTERN]] [[-z] | [--decompress]] [[-# RANGE] | [--hunks=RANGE]] [--lines=RANGE] [[-FRANGE] | [--files=RANGE]] [[-H] | [--with-filename]] [[-h] | [--no-filename]] [[-v] | [--verbose]...] [fichier...]

patchview {[--help] | [--version] | [--filter ...] | [--grep ...]}

DESCRIPTION

Alors, qu'est-ce que patchview ? C'est un wrapper de filterdiff à utiliser avec des fichiers numérotés.

patchview

(sans arguments) est équivalent à : lsdiff --number

patchview -F2-

(ou avec n'importe quels autres arguments) est équivalent à : filterdiff -F2- (ou quels que soient les arguments fournis)

Il existe deux scripts pour travailler avec git (gitdiff et gitdiffview) et deux pour svn (svndiff et svndiffview).

svndiff
gitdiff

(sans arguments) donnera la liste des fichiers modifiés

svndiff -F1
gitdiff -F1

affichera le patch du fichier #1

svndiffview
gitdiffview

canalise tous les patchs à travers filterdiff vers vim - -R (en mode lecture seule, facile à quitter), affichant le patch complet avec couleur.

svndiffview -F2
gitdiffview -F2

(ou tout autre argument) canalisera le patch du fichier #2 vers vim - -R

OPTIONS

-n, --line-number

Affiche le numéro de ligne où commence chaque patch. Si une sortie verbeuse est demandée (avec -nv), chaque bloc de chaque patch est également listé.

Pour chaque fichier modifié, une ligne est générée contenant le numéro de ligne du début du patch, suivi d'un caractère Tab, suivi du nom du fichier modifié. Si -v est donné une fois, chaque ligne de ce type est suivie d'une ligne pour chaque bloc, consistant en un caractère Tab, le numéro de ligne où le bloc commence, un autre Tab, la chaîne « Hunk # », et le numéro du bloc (commençant à 1).

Si -v est donné deux fois en conjonction avec -n (c'est-à-dire -nvv), le format est légèrement différent : un texte descriptif au niveau du bloc est affiché après chaque numéro de bloc, et l'option --number-files est activée.

-N, --number-files

Les numéros de fichiers sont listés, commençant à 1, avant chaque nom de fichier.

-# PLAGE, --hunks=PLAGE

Liste uniquement les blocs dans la PLAGE spécifiée. Les blocs sont numérotés à partir de 1, et la plage est une liste de nombres séparés par des virgules ou des intervalles « premier-dernier », éventuellement précédée d'un modificateur 'x' qui inverse toute la plage ; le premier ou le dernier de l'intervalle peut être omis pour indiquer aucune limite dans cette direction.

--lines=PLAGE

Liste uniquement les blocs qui contiennent des lignes du fichier original situées dans la PLAGE spécifiée. Les lignes sont numérotées à partir de 1, et la plage est une liste de nombres séparés par des virgules ou des intervalles « premier-dernier », éventuellement précédée d'un modificateur 'x' qui inverse toute la plage ; le premier ou le dernier de l'intervalle peut être omis pour indiquer aucune limite dans cette direction.

-F=PLAGE, --files=PLAGE

Liste uniquement les fichiers indiqués par la PLAGE spécifiée. Les fichiers sont numérotés à partir de 1 dans l'ordre où ils apparaissent dans l'entrée du patch, et la plage est une liste de nombres séparés par des virgules ou des intervalles « premier-dernier », éventuellement précédée d'un modificateur 'x' qui inverse toute la plage ; le premier ou le dernier de l'intervalle peut être omis pour indiquer aucune limite dans cette direction.

-p n, --strip-match=n

Lors de la correspondance, ignore les n premiers composants du chemin d'accès.

--strip=n

Supprime les n premiers composants du chemin d'accès avant de l'afficher.

--addprefix=PREFIXE

Ajoute le préfixe PREFIXE au chemin d'accès avant de l'afficher.

-s, --status

Affiche les ajouts, modifications et suppressions de fichiers. Un ajout de fichier est indiqué par un « + », une suppression par un « - », et une modification par un « ! ».

-E, --empty-files-as-removed

Traite les fichiers vides comme absents pour l'affichage des ajouts, modifications et suppressions de fichiers.

-i MOTIF, --include=MOTIF

Inclut uniquement les fichiers correspondant au MOTIF.

-x MOTIF, --exclude=MOTIF

Exclut les fichiers correspondant au MOTIF.

-z, --decompress

Décompresse les fichiers avec les extensions .gz et .bz2.

-H, --with-filename

Affiche le nom du fichier de patch contenant chaque patch.

-h, --no-filename

Supprime le nom du fichier de patch contenant chaque patch.

-v, --verbose

Sortie verbeuse.

--help

Affiche un court message d'utilisation.

--version

Affiche le numéro de version de patchview.

--filter

Se comporte comme filterdiff(1) à la place.

--grep

Se comporte comme grepdiff(1) à la place.

VOIR AUSSI

lsdiff(1),filterdiff(1), grepdiff(1)

EXEMPLES

Nous pouvons créer le script suivant d'une seule ligne nommé difftotrunk.sh, pour visualiser les différences de deux répertoires ou dépôts svn (trunk et .)

diff ../trunk . -ru -x .svn | patchview "$@"
./difftotrunk.sh , affichera tous les fichiers différents et son numéro.
./difftotrunk.sh -F3,4 , affichera uniquement les différences des fichiers #3 et #4.
./difftotrunk.sh -F3 -#1 , affichera uniquement le bloc #1 du fichier #3.
./difftotrunk.sh -F3 -#x1 , affichera les différences du fichier #3 sans le bloc #1 (x signifie exclure).
