NOM

pactree — visualiseur d'arbre de dépendances de paquets

SYNTAXE

pactree [options] <paquet>

DESCRIPTION

pactree produit un arbre de dépendances pour un paquet.

Par défaut, une sortie en forme d'arbre est générée, mais avec l'option --graph, une description Graphviz est générée.

OPTIONS

-a, --ascii

Utilise des caractères ASCII pour le formatage de l'arbre. Par défaut, pactree utilise des caractères de dessin de ligne Unicode s'il peut détecter que la locale les prend en charge.

-c, --color

Colorise la sortie.

--config <fichier>

Spécifie un fichier de configuration pacman alternatif.

-b, --dbpath

Spécifie un emplacement de base de données alternatif.

--debug

Affiche les messages de journal produits par libalpm.

-d, --depth <num>

Limite le nombre de niveaux de dépendance à afficher. Zéro signifie n'afficher que le paquet nommé, un affiche les paquets directement requis.

--gpgdir <répertoire>

Spécifie un répertoire GnuPG alternatif pour vérifier les signatures de la base de données (par défaut est /etc/pacman.d/gnupg).

-g, --graph

Génère une description Graphviz. Si cette option est donnée, les options --color et --linear sont ignorées.

-h, --help

Affiche la syntaxe et les options de la ligne de commande.

-l, --linear

Affiche les noms des paquets au début de chaque ligne, un par ligne.

-o, --optional[=profondeur]

Affiche également les dépendances optionnelles jusqu'à une certaine profondeur, par défaut 1 pour les dépendances optionnelles immédiates. Lorsqu'il est utilisé conjointement avec -r, il montre pour quels paquets elle est optionnelle. En mode Graphviz, produit des lignes pointillées. Les valeurs négatives signifient une profondeur infinie.

-r, --reverse

Affiche les paquets qui dépendent du paquet nommé.

-s, --sync

Lit les données des paquets à partir des bases de données de synchronisation au lieu de la base de données locale.

-u, --unique

Liste les paquets dépendants une seule fois. Implique --linear.

-V, --version

Affiche la version.

VOIR AUSSI

pacman(8), pacman.conf(5), makepkg(8)

BOGUES

Des bogues ? Vous devez plaisanter ; il n'y a pas de bogues dans ce logiciel. Mais si nous nous trompions, déposez un ticket avec autant de détails que possible sur https://gitlab.archlinux.org/pacman/pacman-contrib/-/issues/new.
