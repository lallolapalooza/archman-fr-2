NOM

pamseq - génère une image PAM de toutes les valeurs de tuple possibles, en séquence

SYNTAXE

pamseq [-typedetuple=typedetuple] profondeur valeurmax

Toutes les options peuvent être abrégées à leur plus court préfixe unique. Vous pouvez utiliser deux tirets au lieu d'un pour désigner une option. Vous pouvez utiliser un espace blanc ou un signe égal entre un nom d'option et sa valeur.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pamseq génère une image PAM d'une profondeur spécifiée et d'une valeur maximale spécifiée, qui consiste en une seule ligne. La ligne se compose d'un tuple de chaque valeur possible, dans l'ordre.

Pour une profondeur de un, l'ordre est simple : de 0 à valeurmax, en allant de gauche à droite. Pour des profondeurs plus élevées, le plan le plus élevé numéroté va de 0 à valeurmax (en allant de gauche à droite) tandis que tous les autres plans ont la valeur 0. Ensuite, la séquence se répète, mais avec le plan suivant le plus élevé défini à une valeur de 1, puis 2, etc.

OPTIONS

-typedetuple
C'est la valeur de l'attribut « tuple_type » de l'image PAM créée. Il peut s'agir de n'importe quelle chaîne de caractères comportant jusqu'à 255 caractères.

UTILISATION

Pour créer une rampe simple des valeurs 0..255, pour l'entrée de divers calculs matriciels, essayez


  pamseq 1 255

(Avant l'existence de pamseq, pgmramp était souvent utilisé pour cela).

Pour créer une carte de couleurs PPM de toutes les couleurs possibles représentables avec une valeur maximale de 5, faites


  pamseq 3 5 -typedetuple=RGB | pamtopnm

Encore une fois, avec un programme moderne basé sur la bibliothèque Netpbm, vous n'avez pas besoin de pamtopnm car une image PAM RGB est équivalente à une image PPM.

Vous pouvez utiliser une telle carte de couleurs avec pnmremap(1)
pour quantifier les couleurs d'une image. Avec la valeur maximale de 5 donnée dans l'exemple, vous obtenez une carte de couleurs de l'ensemble des couleurs « web-safe » telles que définies par Netscape. La plupart des navigateurs Web garantissent qu'ils peuvent produire au moins ces 216 couleurs (215 plus le noir).

VOIR AUSSI

pnmremap(1) , pamtopnm(1) , pam(5)
