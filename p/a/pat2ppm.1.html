PAT2PPM(1) Manuel des commandes générales PAT2PPM(1)

NOM

pat2ppm - Convertit un fichier image du format PAT au format PPM.

SYNTAXE

pat2ppm infile.pat

DESCRIPTION

pat2ppm est un programme qui convertit un fichier image du format PAT au format PPM.

infile est un fichier PAT ; le fichier .ppm résultant est écrit sur la sortie standard.

OPTIONS

Cette commande n'a pas d'options.

VOIR AUSSI

patextract(1), png2pat(1), rgb2pat(1), visgrep(1), xte(1).
