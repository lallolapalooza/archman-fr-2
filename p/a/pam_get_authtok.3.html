PAM_GET_AUTHTOK(3) Manuel Linux-PAM PAM_GET_AUTHTOK(3)

NOM

pam_get_authtok, pam_get_authtok_verify, pam_get_authtok_noverify - obtenir le jeton d'authentification

SYNTAXE

#include <security/pam_ext.h>

int pam_get_authtok(pam_handle_t *pamh, int item, const char **authtok, const char *prompt);

int pam_get_authtok_noverify(pam_handle_t *pamh, const char **authtok, const char *prompt);

int pam_get_authtok_verify(pam_handle_t *pamh, const char **authtok, const char *prompt);

DESCRIPTION

La fonction pam_get_authtok retourne le jeton d'authentification mis en cache, ou invite l'utilisateur si aucun jeton n'est actuellement mis en cache. Elle est destinée à une utilisation interne par Linux-PAM et les modules de service PAM. Après un retour réussi, authtok contient un pointeur vers la valeur du jeton d'authentification. Attention, il s'agit d'un pointeur vers les données *réelles* et il ne faut **pas** le libérer avec free() ni l'écraser !

L'argument prompt spécifie une invite à utiliser si aucun jeton n'est mis en cache. Si un pointeur NULL est donné, pam_get_authtok utilise des invites prédéfinies.

Les valeurs suivantes sont supportées pour item :

PAM_AUTHTOK

Retourne le jeton d'authentification actuel. Appelée depuis pam_sm_chauthtok(3), pam_get_authtok demandera à l'utilisateur de confirmer le nouveau jeton en le retapant. Si une invite a été spécifiée, "Retype" sera utilisé comme préfixe.

PAM_OLDAUTHTOK

Retourne le jeton d'authentification précédent lors du changement des jetons d'authentification.

La fonction pam_get_authtok_noverify ne peut être utilisée que pour changer le mot de passe (depuis pam_sm_chauthtok(3)). Elle retourne le jeton d'authentification mis en cache, ou invite l'utilisateur si aucun jeton n'est actuellement mis en cache. La différence avec pam_get_authtok est que cette fonction ne demande pas une deuxième fois le mot de passe pour le vérifier. Après un retour réussi, authtok contient un pointeur vers la valeur du jeton d'authentification. Attention, il s'agit d'un pointeur vers les données *réelles* et il ne faut **pas** le libérer avec free() ni l'écraser !

La fonction pam_get_authtok_verify peut uniquement être utilisée pour vérifier un mot de passe pour les fautes de frappe obtenues par pam_get_authtok_noverify(3). Cette fonction demande une deuxième fois le mot de passe et le vérifie avec le mot de passe fourni par l'argument authtok. En cas d'erreur, la valeur de authtok est indéfinie. Sinon, cet argument pointera vers les données *réelles* et ne devra **pas** être libéré avec free() ni écrasé !

OPTIONS

pam_get_authtok honore les options de module suivantes :

try_first_pass

Avant d'inviter l'utilisateur à entrer son mot de passe, le module tente d'abord le mot de passe du module empilé précédent, au cas où il satisferait également ce module.

use_first_pass

L'argument use_first_pass force le module à utiliser le mot de passe d'un module empilé précédent et n'invitera jamais l'utilisateur - si aucun mot de passe n'est disponible ou si le mot de passe n'est pas approprié, l'accès sera refusé à l'utilisateur.

use_authtok

Lors du changement de mot de passe, force le module à définir le nouveau jeton sur celui fourni par un module password empilé précédemment. Si aucun jeton n'est disponible, le changement de jeton échouera.

authtok_type=XXX

L'action par défaut consiste pour le module à utiliser les invites suivantes lors de la demande de mots de passe : "Nouveau mot de passe UNIX : " et "Retype mot de passe UNIX : ". Le mot d'exemple UNIX peut être remplacé par cette option, par défaut il est vide.

VALEURS DE RETOUR

PAM_AUTH_ERR

Le jeton d'authentification n'a pas pu être récupéré.

PAM_AUTHTOK_ERR

Le nouveau jeton d'authentification n'a pas pu être récupéré.

PAM_SUCCESS

Le jeton d'authentification a été récupéré avec succès.

PAM_SYSTEM_ERR

Un pointeur NULL a été spécifié comme handle PAM, ou aucun espace pour un jeton d'authentification n'a été fourni.

PAM_TRY_AGAIN

Les nouveaux jetons d'authentification ne correspondent pas.
