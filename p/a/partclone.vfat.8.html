PARTCLONE(8) Manuel de l'utilisateur Partclone PARTCLONE(8)

NOM

partclone - L'utilitaire pour cloner et restaurer une partition.

SYNTAXE

partclone.[fstype] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] cible} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] logfile [-R | --rescue] [-L | --logfile] logfile [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPTION

partclone.[fstype] fait partie du projet Partclone. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une plus grande compatibilité du système de fichiers en utilisant des bibliothèques existantes, par exemple, e2fslibs est utilisé pour lire les blocs utilisés d'une partition ext2.

Les systèmes de fichiers supportés par Partclone incluent btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Il prend également en charge certains systèmes d'exploitation non-linux, par exemple : NTFS, FAT et EXFAT (pour Windows), HFS plus (MAC OS APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) et MINIX (MINIX3).

Tous les utilitaires partclone peuvent être exécutés comme partclone.[fstype] ce qui est très similaire à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, lancez simplement partclone.hfsp

       Système de fichiers                 partclone.[fstype]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       autres (FS non supporté)    partclone.imager

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-s FICHIER, --source FICHIER

FICHIER source. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique en fonction de votre action. Normalement, la source de sauvegarde est un périphérique, la source de restauration est un fichier image.

La réception de données à partir d'un pipeline est prise en charge UNIQUEMENT pour la restauration, ignorez simplement l'option -s ou utilisez '-' pour recevoir des données depuis stdin.

-o FICHIER, --output FICHIER

FICHIER de sortie. Le FICHIER peut être un fichier image (que partclone générera) ou un périphérique en fonction de votre action. Normalement, la sortie de sauvegarde va vers un fichier image et la sortie de restauration va vers un périphérique.

L'envoi de données vers un pipeline est également pris en charge UNIQUEMENT pour la sauvegarde, ignorez simplement l'option -o ou utilisez '-' pour envoyer des données vers stdout.

-O FICHIER, --overwrite FICHIER

Écraser FICHIER, en l'écrasant s'il existe.

-W FICHIER, --restore_raw_file FICHIER

créer un fichier brut spécial pour le périphérique de boucle.

-c, --clone

Sauvegarder la partition dans le format d'image spécial.

-r, --restore

Restaurer la partition à partir du format d'image spécial.

-b, --dev-to-dev

Copie locale de périphérique à périphérique à la volée, source et sortie étant toutes deux des périphériques.

-D, --domain

Créer un fichier journal de domaine GNU Ddrescue à partir du périphérique source. C'est un fichier lisible par l'homme dans lequel + marque les zones de blocs utilisées et ? marque les zones libres.

--offset_domain=X

Ajoute X (en octets) à toutes les positions rapportées dans le fichier journal de domaine

--restore_raw_file

Création d'un fichier brut spécial pour le périphérique de boucle.

-L FICHIER, --logfile FICHIER

Placer un chemin spécial pour enregistrer les informations du journal partclone. (par défaut /var/log/partclone.log)

-R, --rescue

Continuer après les erreurs de lecture de disque.

-C, --no_check

Ne pas vérifier la taille du périphérique et l'espace libre.

-N, --ncurses

Utilisation d'une interface utilisateur textuelle Ncurses.

-I, --ignore_fschk

Ignorer la vérification du système de fichiers.

-i, --ignore_crc

Ignorer l'erreur de vérification crc.

-F, --force

Forcer la progression.

-f sec, --UI-fresh sec

Définir un intervalle différent en secondes.

-z taille, --buffer_size taille

Taille du tampon de lecture/écriture (par défaut : 1048576)

-q, --quiet

Désactiver le message de progression.

-dniveau, --debug niveau

Définir le niveau de débogage [1|2|3]

-x, --compresscmd CMD

Lancer CMD comme un pipeline de sortie pour compresser l'image clonée

-aX, --checksum-mode=X

Formule de somme de contrôle à utiliser pour ajouter la détection d'erreurs

où X :

0 : Pas de somme de contrôle (pas de ralentissement, image la plus petite)

1 : CRC32 (Rapide à calculer, détection de base)

2 : xxHash algorithme de hachage non cryptographique extrêmement rapide

-kX, --blocks-per-checksum=X

Écrire une somme de contrôle pour chaque X blocs

-w, --skip_write_error

Continuer la restauration en cas d'erreurs d'écriture

--write-direct-io

Écrire les données dans la partition CIBLE sans cache

--read-direct-io

Lire les données de la partition SOURCE sans cache

-B, --no_block_detail

Afficher le message de progression sans détails de bloc

--binary-prefix

Afficher la progression avec la taille en bits (par défaut, c'est en Mo, Go...)

--prog-second

Afficher la progression en secondes (par défaut, c'est en minutes)

-E, --offset=X

Ajoute un décalage X (en octets) à la SORTIE

-T, --btfiles

Restaurer le bloc en tant que fichier pour ClonezillaBT.

-t, --btfiles_torrent

Restaurer le bloc en tant que fichier pour ClonezillaBT mais générer uniquement le torrent.

-n, --note NOTE

Afficher une NOTE de message (128 mots).

-h, --help

Afficher un résumé des options.

-v, --version

Afficher la versi

partclone.vfat(8) - Page de manuel

NOM

partclone.vfat - Une application pour cloner un système de fichiers VFAT.

SYNOPIS

partclone.vfat [ -c | -r ] [ -s source ] [ -o destination ] [ -d ] [ -h ] [ -q ] [ -N ] [ -X ] [ -e ] [ -i ] [ -b ] [ -C ]

DESCRIPTION

partclone.vfat est un programme pour cloner et restaurer des partitions VFAT. Il tente de manière intelligente de sauvegarder uniquement les blocs de données utilisés. Il prend en charge le clonage et la restauration de partitions VFAT. Vous pouvez utiliser toutes les options de la ligne de commande de partclone.

Les options suivantes sont pour partclone.vfat :

-c
Cloner la partition source vers la destination.
-r
Restaurer la partition source (fichier image) vers la destination.
-s
Spécifier la source. Cela peut être un périphérique de partition, un fichier image ou un tiret (-), qui signifie stdin.
-o
Spécifier la destination. Cela peut être un périphérique de partition, un fichier image ou un tiret (-), qui signifie stdout.
-d
Activer le mode de débogage.
-h
Afficher un message d'aide.
-q
Mode silencieux.
-N
Ne pas demander de confirmation.
-X
Ne pas fermer la session en cas d'erreur.
-e
Activer le clonage sans vérifier les erreurs.
-i
Ne pas vérifier la taille de l'image lors de la restauration.
-b
Forcer la sauvegarde des blocs vides.
-C
Ne pas fermer la partition ou le volume après l'opération.

FICHIERS

/var/log/partclone.log

Le fichier journal de partclone

EXEMPLES

 Cloner /dev/hda1 vers hda1.img et afficher les informations de débogage.
   partclone.vfat -c -d -s /dev/hda1 -o hda1.img
 Restaurer /dev/hda1 à partir de hda1.img et afficher les informations de débogage.
   partclone.vfat -r -d -s hda1.img -o /dev/hda1
 Restaurer l'image de clonezilla (divisée, gzipée, etc.) avec une source stdin
   cat sda1.vfat-ptcl-img.gz.a* | gunzip -c | partclone.vfat -d -r -s - -o /dev/sda1

DIAGNOSTICS

Les diagnostics suivants peuvent être émis sur stderr :

partclone fournit certains codes de retour, qui peuvent être utilisés dans les scripts :

Code Diagnostic
0 Le programme s'est terminé avec succès.
1 Le clonage ou la restauration semblent avoir échoué.

BOGUES

Signaler les bogues à thomas@clonezilla.org ou http://partclone.org.

Vous pouvez obtenir de l'aide sur http://partclone.org
