NOM

partclone.ntfsfixboot - gère l'absurdité des systèmes de fichiers NTFS déplacés.

SYNTAXE

partclone.ntfsfixboot [-w] [-h n] [-t n] [-s n] [-b] [-f] [-p] {APPAREIL}

DESCRIPTION

partclone.ntfsfixboot N'EST PAS une partie du projet Partclone, mais il est inclus pour corriger les problèmes de démarrage NTFS. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une compatibilité plus élevée du système de fichiers en utilisant des bibliothèques existantes, par exemple, e2fslibs est utilisé pour lire les blocs utilisés des partitions ext2.

Partclone.ntfsfixboot gère l'absurdité des systèmes de fichiers NTFS déplacés. écrit par Orgad Shaneh (2009) et Daniel J. Grace (2006).

OPTIONS

Le programme suit la syntaxe habituelle de la ligne de commande GNU, un résumé des options est inclus ci-dessous.

-w

Écrit le nouveau secteur de démarrage sur la partition.

-h nombre

Spécifie le nombre de têtes par piste. Si omis, déterminé via ioctl.

-t nombre

Spécifie le nombre de secteurs par piste. Si omis, déterminé via ioctl.

-s nombre

Nouveau secteur de démarrage à écrire. Si omis, déterminé via ioctl.

-b

Continue même si l'appareil spécifié n'est pas une partition.

-f

Force l'opération même si l'appareil ne ressemble pas à une partition NTFS valide ou si les valeurs sont égales.

-p

Affiche les informations de débogage (valeurs lues, valeurs demandées, etc.).

appareil

où appareil pointe vers une partition NTFS

DIAGNOSTICS

Les diagnostics suivants peuvent être émis sur stderr :

partclone.ntfsfixboot fournit quelques codes de retour, qui peuvent être utilisés dans les scripts :

Code Diagnostic
0 succès (les valeurs sont correctes ou modifiées avec succès)
1 un changement est nécessaire, mais -w n'a pas été spécifié
2 une erreur s'est produite
