PARTCLONE(8) Manuel utilisateur Partclone PARTCLONE(8)

NOM

partclone - L'utilitaire pour cloner et restaurer une partition.

SYNTAXE

partclone.[type_système_fichiers] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] cible} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] journal_log [-R | --rescue] [-L | --logfile] journal_log [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPTION

partclone.[type_système_fichiers] fait partie du projet Partclone. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une compatibilité accrue avec les systèmes de fichiers en utilisant des bibliothèques existantes, par exemple, e2fslibs est utilisé pour lire les blocs utilisés d'une partition ext2.

Les systèmes de fichiers supportés par Partclone incluent btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Il supporte également certains systèmes d'exploitation non-Linux, par ex : NTFS, FAT et EXFAT (pour Windows), HFS plus (MAC OS APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) et MINIX (MINIX3).

Tous les utilitaires partclone peuvent être exécutés comme partclone.[type_système_fichiers], ce qui est très similaire à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, exécutez simplement partclone.hfsp

       Système de fichiers             partclone.[type_système_fichiers]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       autres (FS non supportés)   partclone.imager

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-s FICHIER, --source FICHIER

FICHIER source. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique selon votre action. Normalement, la source de sauvegarde est un périphérique, la source de restauration est un fichier image.

La réception de données depuis un pipeline est supportée UNIQUEMENT pour la restauration, ignorez l'option -s ou utilisez '-' pour recevoir des données depuis stdin.

-o FICHIER, --output FICHIER

FICHIER de sortie. Le FICHIER peut être un fichier image (que partclone générera) ou un périphérique selon votre action. Normalement, la sortie de sauvegarde va vers un fichier image et la sortie de restauration va vers un périphérique.

L'envoi de données vers un pipeline est également supporté UNIQUEMENT pour la sauvegarde, ignorez l'option -o ou utilisez '-' pour envoyer des données vers stdout.

-O FICHIER, --overwrite FICHIER

Écrase le FICHIER s'il existe.

-W FICHIER, --restore_raw_file FICHIER

Crée un fichier brut spécial pour un périphérique de boucle.

-c, --clone

Enregistre la partition au format d'image spécial.

-r, --restore

Restaure la partition à partir du format d'image spécial.

-b, --dev-to-dev

Copie locale de périphérique à périphérique à la volée, la source et la sortie sont toutes deux des périphériques.

-D, --domain

Crée un fichier journal de domaine GNU Ddrescue à partir du périphérique source. C'est un fichier lisible par l'homme où + marque les zones de blocs utilisés et ? marque les zones libres.

--offset_domain=X

Ajoute X (en octets) à toutes les positions rapportées dans le fichier journal de domaine

--restore_raw_file

Crée un fichier brut spécial pour un périphérique de boucle.

-L FICHIER, --logfile FICHIER

Place un chemin spécial pour enregistrer les informations de journalisation de partclone. (par défaut /var/log/partclone.log)

-R, --rescue

Continue après les erreurs de lecture du disque.

-C, --no_check

Ne vérifie pas la taille du périphérique et l'espace libre.

-N, --ncurses

Utilise l'interface utilisateur graphique en mode texte Ncurses.

-I, --ignore_fschk

Ignore la vérification du système de fichiers.

-i, --ignore_crc

Ignore l'erreur de vérification crc.

-F, --force

Force la progression.

-f sec, --UI-fresh sec

Spécifie l'intervalle de rafraîchissement de l'interface utilisateur en secondes.

-z taille, --buffer_size taille

Taille du tampon de lecture/écriture (par défaut : 1048576)

-q, --quiet

Désactive les messages de progression.

-dniveau, --debug niveau

Définit le niveau de débogage [1|2|3]

-x, --compresscmd CMD

Démarre CMD comme un pipeline de sortie pour compresser l'image clonée

-aX, --checksum-mode=X

Formule de somme de contrôle à utiliser pour ajouter la détection d'erreurs

où X :

0 : Pas de somme de contrôle (pas de ralentissement, image la plus petite)

1 : CRC32 (Rapide à calculer, détection de base)

2 : xxHash, algorithme de hachage non cryptographique extrêmement rapide

-kX, --blocks-per-checksum=X

Écrit une somme de contrôle pour chaque X blocs

-w, --skip_write_error

Continue la restauration en cas d'erreurs d'écriture

--write-direct-io

Écrit les données dans la partition CIBLE sans cache

--read-direct-io

Lit les données depuis la partition SOURCE sans cache

-B, --no_block_detail

Affiche le message de progression sans détail des blocs

--binary-prefix

Affiche la progression avec la taille en bits (par défaut, c'est en Mo, Go...)

--prog-second

Affiche la progression en secondes (par défaut, c'est en minutes)

-E, --offset=X

Ajoute un décalage X (octets) à la SORTIE

-T, --btfiles

Restaure les blocs sous forme de fichiers pour ClonezillaBT.

-t, --btfiles_torrent

Restaure les blocs sous forme de fichiers pour ClonezillaBT mais génère uniquement le torrent.

-n, --note NOTE

Affiche un message NOTE (128 mots).

-h, --help

Affiche un résumé des options.

-v, --version

Affiche la version de

partclone(8) — Manuel partclone

NOM

partclone — programme de clonage de partition

SYNTAXE

DESCRIPTION

partclone est un programme qui permet de cloner et de restaurer des partitions. Il est basé sur le programme partimage et vise à fournir un ensemble de fonctionnalités similaires mais avec une meilleure prise en charge des systèmes de fichiers modernes et des méthodes de clonage plus efficaces.

Contrairement à dd, partclone ne clone que les blocs utilisés du système de fichiers, ce qui réduit considérablement la taille des images créées. Il prend en charge plusieurs systèmes de fichiers, notamment ext2, ext3, ext4, reiserfs, reiser4, btrfs, xfs, jfs, ntfs, fat, etc.

OPTIONS

Les options spécifiques à chaque système de fichiers sont détaillées dans les pages de manuel individuelles (par exemple, `partclone.ext3(8)`). Cependant, certaines options générales sont partagées par tous les programmes partclone :

-c, --clone
Cloner la partition source vers un fichier image. C'est le mode par défaut.
-r, --restore
Restaurer la partition à partir d'un fichier image.
-s, --source SOURCE
Spécifie la partition source ou le fichier image source. Si la source est '-', elle sera lue depuis l'entrée standard.
-o, --output OUTPUT
Spécifie le fichier image de destination ou la partition de destination. Si la destination est '-', elle sera écrite sur la sortie standard.
-d, --debug
Activer la sortie de débogage détaillée.
-v, --verbose
Activer la sortie verbeuse.
-q, --quiet
Supprimer la sortie de progression.
-N, --no_clone
Ne pas cloner les blocs vides.
-X, --force
Forcer l'exécution même si des avertissements sont émis.
-Z, --zero
Remplir les blocs vides avec des zéros.

FICHIERS

/var/log/partclone.log

Le fichier journal de partclone

EXEMPLES

 Cloner /dev/hda1 vers hda1.img et afficher les informations de débogage.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 Restaurer /dev/hda1 à partir de hda1.img et afficher les informations de débogage.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 Restaurer une image de clonezilla (split, gzip,) avec une source stdin
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

Les diagnostics suivants peuvent être émis sur stderr :

partclone fournit des codes de retour qui peuvent être utilisés dans les scripts :

Code Diagnostic
0 Le programme s'est terminé avec succès.
1 Le clonage ou la restauration semble avoir échoué.

BOGUES

Signaler les bogues à thomas@clonezilla.org ou http://partclone.org.

Vous pouvez obtenir de l'aide sur http://partclone.org
