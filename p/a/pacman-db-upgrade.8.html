NOM

pacman-db-upgrade - met à jour la base de données locale de pacman vers un format plus récent

SYNTAXE

pacman-db-upgrade [options]

DESCRIPTION

pacman-db-upgrade est un script qui met à jour la base de données locale utilisée par pacman(8) vers un format plus récent.

Options

*-h, \--help*::
Affiche le message d'aide intégré et quitte.
*-V, \--version*::
Affiche les informations de version et quitte.
*-d, \--dbpath* <chemin>::
Définit un emplacement de base de données alternatif.
*-r, \--root* <chemin>::
Définit une racine d'installation alternative.
*\--config* <chemin>::
Définit un fichier de configuration alternatif.
*\--nocolor*::
Supprime les couleurs de la sortie.
Voir aussi

pacman(8)
