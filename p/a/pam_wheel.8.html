NOM

pam_wheel - Permet uniquement l'accès root aux membres du groupe wheel

SYNTAXE

pam_wheel.so [debug] [deny] [group=nom] [root_only] [trust] [use_uid]

DESCRIPTION

Le module PAM pam_wheel est utilisé pour appliquer le soi-disant groupe wheel. Par défaut, il autorise l'accès à l'utilisateur cible si l'utilisateur demandeur est membre du groupe wheel. Si aucun groupe de ce nom n'existe, le module utilise le groupe avec l'ID de groupe 0.

OPTIONS

debug

Affiche des informations de débogage.

deny

Inverse le sens de l'opération d'authentification : si l'utilisateur essaie d'obtenir l'accès UID 0 et est membre du groupe wheel (ou du groupe spécifié par l'option group), refuse l'accès. Inversement, si l'utilisateur n'est pas dans le groupe, retourne PAM_IGNORE (sauf si trust a également été spécifié, auquel cas nous retournons PAM_SUCCESS).

group=nom

Au lieu de vérifier les groupes wheel ou GID 0, utilise le groupe nom pour effectuer l'authentification.

root_only

La vérification de l'appartenance au groupe wheel n'est effectuée que lorsque l'UID de l'utilisateur cible est 0.

trust

Le module pam_wheel retournera PAM_SUCCESS au lieu de PAM_IGNORE si l'utilisateur est membre du groupe wheel (ainsi, en empilant les modules, les membres de wheel peuvent éventuellement utiliser su pour devenir root sans être invités à saisir un mot de passe).

use_uid

La vérification sera effectuée contre l'UID réel du processus appelant, au lieu d'essayer d'obtenir l'utilisateur à partir de la session de connexion associée au terminal utilisé.

TYPES DE MODULES FOURNIS

Les types de modules auth et account sont fournis.

VALEURS DE RETOUR

PAM_AUTH_ERR

Échec d'authentification.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_IGNORE

La valeur de retour doit être ignorée par le dispatch PAM.

PAM_PERM_DENY

Permission refusée.

PAM_SERVICE_ERR

Impossible de déterminer le nom d'utilisateur.

PAM_SUCCESS

Succès.

PAM_USER_UNKNOWN

Utilisateur inconnu.

EXEMPLES

Le compte root obtient l'accès par défaut (rootok), seuls les membres de wheel peuvent devenir root (wheel), mais Unix authentifie les demandeurs non-root.

su      auth     sufficient     pam_rootok.so
su      auth     required       pam_wheel.so
su      auth     required       pam_unix.so
