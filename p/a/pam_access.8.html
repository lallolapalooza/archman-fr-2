NOM

pam_access - Module PAM pour le contrôle d'accès à la connexion de type logdaemon

SYNTAXE

pam_access.so [debug] [noaudit] [nodefgroup] [nodns] [quiet_log] [accessfile=fichier] [fieldsep=séparateur] [listsep=séparateur]

DESCRIPTION

Le module PAM pam_access est principalement destiné à la gestion des accès. Il fournit un contrôle d'accès à la connexion de type logdaemon basé sur les noms de connexion, les noms d'hôte ou de domaine, les adresses IP ou les numéros de réseau, ou sur les noms de lignes de terminaux, les valeurs X $DISPLAY, ou les noms de service PAM dans le cas de connexions non connectées au réseau.

Par défaut, les règles de gestion des accès sont tirées du fichier de configuration /etc/security/access.conf si vous n'en spécifiez pas un autre. Ensuite, les fichiers individuels *.conf du répertoire /etc/security/access.d/ sont lus. Les fichiers sont analysés les uns après les autres dans l'ordre de la locale du système. L'effet des fichiers individuels est le même que si tous les fichiers étaient concaténés dans l'ordre d'analyse. Cela signifie qu'une fois qu'un motif est trouvé dans un fichier, aucun fichier supplémentaire n'est analysé. Si un fichier de configuration est explicitement spécifié avec l'option accessfile, les fichiers du répertoire ci-dessus ne sont pas analysés.

Si Linux PAM est compilé avec le support d'audit, le module rapportera lorsqu'il refusera l'accès en fonction de l'origine (hôte, tty, etc.).

OPTIONS

accessfile=/chemin/vers/access.conf

Indique un fichier de configuration de style access.conf alternatif pour remplacer celui par défaut. Cela peut être utile lorsque différents services ont besoin de listes d'accès différentes.

debug

Beaucoup d'informations de débogage sont imprimées avec syslog(3).

noaudit

Ne pas signaler les connexions depuis des hôtes et des tty non autorisés au sous-système d'audit.

nodefgroup

Les jetons utilisateur qui ne sont pas entre parenthèses ne seront pas comparés à la base de données des groupes. Le comportement par défaut compatible avec la rétrocompatibilité est d'essayer la comparaison de la base de données des groupes même pour les jetons non entourés de parenthèses.

nodns

N'essaie pas de résoudre les jetons en noms d'hôtes, seules les adresses IPv4 et IPv6 seront résolues. Cela signifie que pour autoriser la connexion depuis un hôte distant, les adresses IP doivent être spécifiées dans access.conf.

quiet_log

Ne pas enregistrer les refus avec syslog(3).

fieldsep=séparateurs

Cette option modifie le caractère séparateur de champ que pam_access reconnaîtra lors de l'analyse du fichier de configuration d'accès. Par exemple : fieldsep=| fera que le caractère par défaut ':' sera traité comme faisant partie d'une valeur de champ et '|' deviendra le séparateur de champ. Cela peut être utile en conjonction avec un système qui souhaite utiliser pam_access avec des applications basées sur X, car l'élément PAM_TTY est susceptible d'être de la forme "nomhote:0" qui inclut un caractère ':' dans sa valeur. Mais vous ne devriez pas en avoir besoin.

listsep=séparateurs

Cette option modifie le caractère séparateur de liste que pam_access reconnaîtra lors de l'analyse du fichier de configuration d'accès. Par exemple : listsep=, fera que les caractères espace (' ') et tabulation ('\t') par défaut seront traités comme faisant partie d'un élément de liste et ',' deviendra le seul séparateur d'éléments de liste. Cela peut être utile sur un système avec des informations de groupe obtenues à partir d'un domaine Windows, où les groupes intégrés par défaut "Utilisateurs du domaine", "Administrateurs du domaine" contiennent un espace.

TYPES DE MODULES FOURNIS

Tous les types de modules (auth, account, password et session) sont fournis.

VALEURS DE RETOUR

PAM_SUCCESS

L'accès a été accordé.

PAM_PERM_DENIED

L'accès n'a pas été accordé.

PAM_IGNORE

pam_setcred a été appelé et ne fait rien.

PAM_ABORT

Toutes les données ou options pertinentes n'ont pas pu être obtenues.

PAM_USER_UNKNOWN

L'utilisateur n'est pas connu du système.

FICHIERS

/etc/security/access.conf

Fichier de configuration par défaut

VOIR AUSSI
