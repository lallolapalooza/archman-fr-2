NOM

pam_nologin - Empêcher les utilisateurs non-root de se connecter

SYNTAXE

pam_nologin.so [fichier=/chemin/nologin] [successok]

DESCRIPTION

pam_nologin est un module PAM qui empêche les utilisateurs de se connecter au système lorsque /var/run/nologin ou /etc/nologin existe. Le contenu du fichier est affiché à l'utilisateur. Le module pam_nologin n'a aucun effet sur la capacité de l'utilisateur root à se connecter.

OPTIONS

fichier=/chemin/nologin

Utiliser ce fichier au lieu des fichiers par défaut /var/run/nologin ou /etc/nologin.

successok

Retourne PAM_SUCCESS si aucun fichier n'existe, la valeur par défaut est PAM_IGNORE.

TYPES DE MODULES FOURNIS

Les types de modules auth et account sont fournis.

VALEURS DE RETOUR

PAM_AUTH_ERR

L'utilisateur n'est pas root et /etc/nologin existe, donc l'utilisateur n'est pas autorisé à se connecter.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_IGNORE

C'est la valeur de retour par défaut.

PAM_SUCCESS

Succès : soit l'utilisateur est root, soit le fichier nologin n'existe pas.

PAM_USER_UNKNOWN

Utilisateur inconnu du module d'authentification sous-jacent.

EXEMPLES

L'utilisation suggérée pour /etc/pam.d/login est :

auth  required  pam_nologin.so

NOTES

Pour rendre ce module efficace, toutes les méthodes de connexion doivent être sécurisées par celui-ci. Il doit être utilisé comme une méthode *requise* (required) listée avant toute méthode *suffisante* (sufficient) afin d'obtenir la sémantique standard de nologin Unix. Notez que l'utilisation de l'argument de module successok fait que le module retourne PAM_SUCCESS et briserait donc une telle configuration - les modules sufficient échoués mèneraient à une connexion réussie parce que le module nologin aurait *réussi*.

VOIR AUSSI
