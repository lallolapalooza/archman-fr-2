NOM

pam_group - Module PAM pour l'accès aux groupes

SYNOPIS

pam_group.so

DESCRIPTION

Le module PAM pam_group n'authentifie pas l'utilisateur, mais il accorde des appartenances de groupe (dans la phase de définition des identifiants du module d'authentification) à l'utilisateur. Ces appartenances sont basées sur le service pour lequel ils postulent.

Par défaut, les règles d'appartenance aux groupes sont tirées du fichier de configuration /etc/security/group.conf.

L'utilité de ce module repose sur les systèmes de fichiers accessibles à l'utilisateur. Le principe est qu'une fois l'appartenance à un groupe accordée, l'utilisateur peut tenter de créer un binaire setgid avec une propriété de groupe restreinte. Plus tard, lorsque l'utilisateur n'a pas reçu l'adhésion à ce groupe, il peut retrouver l'appartenance au groupe avec le binaire précompilé. La raison pour laquelle les systèmes de fichiers auxquels l'utilisateur a accès sont si importants est le fait que lorsqu'un système est monté en mode nosuid, l'utilisateur ne peut pas créer ou exécuter un tel fichier binaire. Pour que ce module fournisse un quelconque niveau de sécurité, tous les systèmes de fichiers auxquels l'utilisateur a un accès en écriture doivent être montés en nosuid.

Le module pam_group fonctionne parallèlement au fichier /etc/group. Si l'utilisateur se voit accorder des groupes en fonction du comportement de ce module, ils sont accordés *en plus* de ces entrées /etc/group (ou équivalent).

OPTIONS

Ce module ne reconnaît aucune option.

TYPES DE MODULE FOURNIS

Seul le type de module auth est fourni.

VALEURS DE RETOUR

PAM_SUCCESS

l'appartenance au groupe a été accordée.

PAM_ABORT

Toutes les données pertinentes n'ont pas pu être obtenues.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_CRED_ERR

L'appartenance au groupe n'a pas été accordée.

PAM_IGNORE

pam_sm_authenticate a été appelé, ce qui ne fait rien.

PAM_USER_UNKNOWN

L'utilisateur n'est pas connu du système.

FICHIERS

/etc/security/group.conf

Fichier de configuration par défaut

VOIR AUSSI

group.conf(5), pam.d(5), pam(8).
