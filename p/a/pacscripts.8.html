NOM

pacscripts - affiche les scripts {pre,post}_{install,remove,upgrade} d'un paquet donné.

SYNOPSIS

pacscripts [--nocolor] <nom_paquet | fichier_paquet>

DESCRIPTION

pacscripts affichera les scripts {pre,post}_{install,remove,upgrade} d'un paquet donné.

Exemple : pacscripts gconf-editor

Exemple : pacscripts gconf-editor-3.0.1-3-x86_64.pkg.tar.xz

OPTIONS

-h, --help

Affiche la syntaxe et les options de la ligne de commande.

-m, --nocolor

Ne pas coloriser la sortie.

-V, --version

Affiche les informations de version.

VOIR AUSSI

pacman(8)

BOGUES

Des bogues ? Vous devez plaisanter ; il n'y a pas de bogues dans ce logiciel. Mais si nous nous trompions, déposez un ticket avec autant de détails que possible sur https://gitlab.archlinux.org/pacman/pacman-contrib/-/issues/new.
