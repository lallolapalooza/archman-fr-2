NOM

pam_motd - Afficher le fichier motd

SYNTAXE

pam_motd.so [motd=/chemin/nom_fichier] [motd_dir=/chemin/nom_repertoire.d]

DESCRIPTION

pam_motd est un module PAM qui peut être utilisé pour afficher des fichiers motd (message du jour) arbitraires après une connexion réussie. Par défaut, pam_motd affiche les fichiers aux emplacements suivants :

/etc/motd
/run/motd
/usr/lib/motd
/etc/motd.d/
/run/motd.d/
/usr/lib/motd.d/

Chaque taille de message est limitée à 64 Ko.

Si /etc/motd n'existe pas, alors /run/motd est affiché. Si /run/motd n'existe pas, alors /usr/lib/motd est affiché.

Un comportement de remplacement similaire s'applique aux répertoires. Les fichiers dans /etc/motd.d/ remplacent les fichiers du même nom dans /run/motd.d/ et /usr/lib/motd.d/. Les fichiers dans /run/motd.d/ remplacent les fichiers du même nom dans /usr/lib/motd.d/.

Les fichiers dans les répertoires listés ci-dessus sont affichés dans l'ordre lexicographique par nom. De plus, les fichiers sont filtrés en les lisant avec les identifiants de l'utilisateur cible s'authentifiant sur le système.

Pour faire taire un message, un lien symbolique dont la cible est /dev/null peut être placé dans /etc/motd.d avec le même nom de fichier que le message à faire taire. Exemple : Créer un lien symbolique comme suit fait taire /usr/lib/motd.d/my_motd.

ln -s /dev/null /etc/motd.d/my_motd

La variable d'environnement MOTD_SHOWN=pam est définie après l'affichage des fichiers motd, même lorsqu'ils ont tous été mis en sourdine à l'aide de liens symboliques.

OPTIONS

motd=/chemin/nom_fichier

Le fichier /chemin/nom_fichier est affiché comme message du jour. Plusieurs chemins à essayer peuvent être spécifiés sous forme de liste séparée par des deux-points. Par défaut, cette option est définie sur /etc/motd:/run/motd:/usr/lib/motd.

motd_dir=/chemin/nom_repertoire.d

Le répertoire /chemin/nom_repertoire.d est analysé et chaque fichier qu'il contient est affiché. Plusieurs répertoires à analyser peuvent être spécifiés sous forme de liste séparée par des deux-points. Par défaut, cette option est définie sur /etc/motd.d:/run/motd.d:/usr/lib/motd.d.

Lorsque aucune option n'est donnée, le comportement par défaut s'applique aux deux options. La spécification d'une option (ou des deux) désactivera le comportement par défaut pour les deux options.

TYPES DE MODULE FOURNIS

Seul le type de module session est fourni.

VALEURS DE RETOUR

PAM_ABORT

Toutes les données ou options pertinentes n'ont pas pu être obtenues.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_IGNORE

C'est la valeur de retour par défaut de ce module.

EXEMPLES

L'utilisation suggérée pour /etc/pam.d/login est :

session  optional  pam_motd.so

Pour utiliser un fichier motd d'un emplacement différent :

session  optional  pam_motd.so motd=/ailleurs/motd

Pour utiliser un fichier motd d'ailleurs, ainsi qu'un répertoire .d correspondant :

session  optional  pam_motd.so motd=/ailleurs/motd motd_dir=/ailleurs/motd.d
