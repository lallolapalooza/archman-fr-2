NOM

pam_acct_mgmt - Gestion de la validation des comptes PAM

SYNTAXE

#include <security/pam_appl.h>

int pam_acct_mgmt(pam_handle_t *pamh, int flags);

DESCRIPTION

La fonction pam_acct_mgmt est utilisée pour déterminer si le compte de l'utilisateur est valide. Elle vérifie l'expiration du jeton d'authentification et du compte, et valide les restrictions d'accès. Elle est généralement appelée après que l'utilisateur a été authentifié.

L'argument pamh est un descripteur d'authentification obtenu par un appel préalable à pam_start(). L'argument flags est le résultat d'un OU binaire de zéro ou plusieurs des valeurs suivantes :

PAM_SILENT

Ne pas émettre de messages.

PAM_DISALLOW_NULL_AUTHTOK

Le service de module PAM doit retourner PAM_NEW_AUTHTOK_REQD si l'utilisateur a un jeton d'authentification nul.

VALEURS DE RETOUR

PAM_ACCT_EXPIRED

Le compte utilisateur a expiré.

PAM_AUTH_ERR

Échec de l'authentification.

PAM_NEW_AUTHTOK_REQD

Le compte utilisateur est valide mais son jeton d'authentification est *expiré*. La réponse correcte à cette valeur de retour est d'exiger que l'utilisateur satisfasse la fonction pam_chauthtok() avant d'obtenir le service. Il peut être impossible pour certaines applications de le faire. Dans de tels cas, l'utilisateur doit se voir refuser l'accès jusqu'à ce qu'il puisse mettre à jour son mot de passe.

PAM_PERM_DENIED

Permission refusée.

PAM_SUCCESS

Le jeton d'authentification a été mis à jour avec succès.

PAM_USER_UNKNOWN

Utilisateur inconnu du service de mots de passe.

VOIR AUSSI

pam_start(3), pam_authenticate(3), pam_chauthtok(3), pam_strerror(3), pam(8)
