NOM

pam_open_session - démarrer la gestion de session PAM

SYNTAXE

#include <security/pam_appl.h>

int pam_open_session(pam_handle_t *pamh, int flags);

DESCRIPTION

La fonction pam_open_session met en place une session utilisateur pour un utilisateur authentifié avec succès précédemment. La session doit être ultérieurement terminée par un appel à pam_close_session(3).

Il convient de noter que l'UID effectif, geteuid(2), de l'application doit disposer de privilèges suffisants pour effectuer des tâches telles que la création ou le montage du répertoire personnel de l'utilisateur, par exemple.

L'argument flags est le OU binaire de zéro ou plusieurs des valeurs suivantes :

PAM_SILENT

Ne pas émettre de messages.

VALEURS DE RETOUR

PAM_ABORT

Échec général.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_SESSION_ERR

Échec de session.

PAM_SUCCESS

La session a été créée avec succès.

VOIR AUSSI

pam_close_session(3), pam_strerror(3)
