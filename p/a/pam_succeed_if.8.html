NOM

pam_succeed_if - teste les caractéristiques du compte

SYNTAXE

pam_succeed_if.so [flag...] [condition...]

DESCRIPTION

pam_succeed_if.so est conçu pour réussir ou échouer l'authentification en fonction des caractéristiques du compte de l'utilisateur en cours d'authentification ou des valeurs d'autres éléments PAM. Une utilisation consiste à sélectionner si d'autres modules doivent être chargés en fonction de ce test.

Le module doit recevoir une ou plusieurs conditions en tant qu'arguments de module, et l'authentification ne réussira que si toutes les conditions sont remplies.

OPTIONS

Les flags suivants sont pris en charge :

debug

Active les messages de débogage envoyés à syslog.

use_uid

Évalue les conditions en utilisant le compte de l'utilisateur sous lequel l'application s'exécute au lieu de l'utilisateur en cours d'authentification.

quiet

Ne journalise pas l'échec ou le succès dans le journal système.

quiet_fail

Ne journalise pas l'échec dans le journal système.

quiet_success

Ne journalise pas le succès dans le journal système.

audit

Journalise les utilisateurs inconnus dans le journal système.

Les conditions sont composées de trois mots : un champ, un test et une valeur à tester.

Les champs disponibles sont user, uid, gid, shell, home, ruser, rhost, tty et service :

field < number

Le champ a une valeur numériquement inférieure à number.

field <= number

Le champ a une valeur numériquement inférieure ou égale à number.

field eq number

Le champ a une valeur numériquement égale à number.

field >= number

Le champ a une valeur numériquement supérieure ou égale à number.

field > number

Le champ a une valeur numériquement supérieure à number.

field ne number

Le champ a une valeur numériquement différente de number.

field = string

Le champ correspond exactement à la chaîne donnée.

field != string

Le champ ne correspond pas à la chaîne donnée.

field =~ glob

Le champ correspond au glob donné.

field !~ glob

Le champ ne correspond pas au glob donné.

field in item:item:...

Le champ est contenu dans la liste d'éléments séparés par des deux-points.

field notin item:item:...

Le champ n'est pas contenu dans la liste d'éléments séparés par des deux-points.

user ingroup group[:group:....]

L'utilisateur est dans le(s) groupe(s) donné(s).

user notingroup group[:group:....]

L'utilisateur n'est pas dans le(s) groupe(s) donné(s).

user innetgr netgroup

(user,host) est dans le netgroup donné.

user notinnetgr group

(user,host) n'est pas dans le netgroup donné.

TYPES DE MODULES FOURNIS

Tous les types de modules (account, auth, password et session) sont fournis.

VALEURS DE RETOUR

PAM_SUCCESS

La condition était vraie.

PAM_AUTH_ERR

La condition était fausse.

PAM_SERVICE_ERR

Une erreur de service s'est produite ou les arguments n'ont pas pu être analysés correctement.

EXEMPLES

Pour émuler le comportement de pam_wheel, sauf qu'il n'y a pas de repli vers le groupe 0, qui est uniquement approximé en vérifiant également l'appartenance au groupe root :

auth required pam_succeed_if.so quiet user ingroup wheel:root

Étant donné que le type correspond, ne charge la règle othermodule que si l'UID est supérieur à 500. Ajustez le nombre après default pour ignorer plusieurs règles.

type [default=1 success=ignore] pam_succeed_if.so quiet uid > 500
type required othermodule.so arguments...
