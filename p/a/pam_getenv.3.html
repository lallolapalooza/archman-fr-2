NOM

pam_getenv - obtenir une variable d'environnement PAM

SYNOPSIS

#include <security/pam_appl.h>

const char *pam_getenv(pam_handle_t *pamh, const char *name);

DESCRIPTION

La fonction pam_getenv recherche dans la liste d'environnement PAM associée au handle pamh un élément qui correspond à la chaîne pointée par name et renvoie un pointeur vers la valeur de la variable d'environnement. L'application n'est pas autorisée à libérer les données.

VALEUR DE RETOUR

La fonction pam_getenv renvoie NULL en cas d'échec.

VOIR AUSSI

pam_start(3), pam_getenvlist(3), pam_putenv(3), pam(8)
