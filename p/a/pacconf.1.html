NOM

pacconf - interroger le fichier de configuration de pacman

SYNOPIS

pacconf [options] [<directive>...]
pacconf (--repo-list|--help|--version)

DESCRIPTION

Interroge les options de configuration du fichier de configuration de pacman. Si aucun directive n'est fourni, la configuration entière sera affichée dans un format normalisé. Par défaut, si une seule directive est fournie, seule sa valeur sera affichée sans le nom de l'option. Pour les directives sans valeur, le nom de la directive sera utilisé comme valeur.

Les valeurs affichées sont les valeurs finales telles qu'elles seraient analysées par pacman lui-même. Toutes les valeurs par défaut sont définies, les directives "Include" sont traitées, les variables $arch et $repo dans les serveurs de dépôts sont remplacées, et "Architecture" sera remplacé si défini sur "auto".

OPTIONS

--config=chemin
Définit un chemin de fichier de configuration alternatif.
--root=chemin
Définit une racine d'installation alternative.
--sysroot=chemin
Définit une racine système alternative. Voir pacutils-sysroot(7).
--arch=arch
Définit une architecture alternative.
--null[=sep]
Définit un séparateur alternatif pour les valeurs analysées depuis stdin. Par défaut, un retour à la ligne "\n" est utilisé comme séparateur. Si --null est utilisé sans spécifier sep, "NUL" sera utilisé.
--options
Affiche uniquement les paramètres globaux de la section "[options]". L'en-tête "[options]" lui-même n'est pas imprimé.
--raw
Affiche les valeurs non modifiées. Les directives "Include" seront traitées, mais les valeurs par défaut ne seront pas définies, les variables $arch et $repo dans les serveurs de dépôts ne seront pas remplacées, et "Architecture" ne sera pas remplacé si défini sur "auto".
--repo=nom
Affiche uniquement les directives pour le dépôt nom. L'en-tête du dépôt n'est pas imprimé.
--repo-list
Liste les dépôts configurés.
--single
Affiche uniquement la première valeur des options multi-valeurs.
--verbose
Affiche toujours les noms des directives même si une seule directive est fournie.
--help
Affiche les informations d'utilisation et quitte.
--version
Affiche les informations de version et quitte.

EXEMPLES

Vérifier si la couleur est activée :
color=$(pacconf color)
[[ -n $color ]] && ... # afficher quelque chose en couleur
