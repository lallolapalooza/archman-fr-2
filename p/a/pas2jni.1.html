pas2jni(1) Outil de génération d'interface native Java Free Pascal pas2jni(1)

NOM

pas2jni - Outil de génération d'interface native Java Free Pascal

SYNTAXE

pas2jni [options] <unité> [<unité2> <unité3> ...]

Génère une description d'interface native Java et une bibliothèque à partir d'unités Free Pascal compilées. pas2jni génère 2 fichiers par unité : une bibliothèque qui fournit un accès aux fonctions et procédures de l'unité Pascal d'une manière que Java comprend, et un fichier .java qui décrit la bibliothèque et peut être utilisé pour accéder à la bibliothèque depuis Java.

OPTIONS

-U<chemin>
Chemin de recherche des unités, délimité par des points-virgules. Les caractères génériques sont autorisés.
-L<nom>
Définit le nom de la bibliothèque de sortie. Par défaut, c'est le nom de l'unité suivi de 'jni'.
-P<nom>
Définit le nom du paquet Java. Par défaut, c'est 'pas'.
-O<chemin>
Définit le chemin de sortie pour les fichiers Pascal. C'est le répertoire courant par défaut.
-J<chemin>
Définit le chemin de sortie pour les fichiers Java. Par défaut, c'est 'pas'.
-D<prog>
Définit le chemin complet du programme "ppudump". Le programme ppudump est nécessaire pour analyser le contenu des fichiers d'unité.
-I<liste>
Inclut la liste des objets spécifiés dans la sortie. La liste est délimitée par des points-virgules. Pour lire cette liste depuis un fichier, utilisez -I@<fichier>
-E <liste>
Exclut la liste des objets spécifiés de la sortie. La liste est délimitée par des points-virgules. Pour lire cette liste depuis un fichier, utilisez -E@<fichier>
-?
Affiche un message d'aide.

EXEMPLES

La commande suivante crée un fichier pas/getopts.java et une unité de fichier bibliothèque getoptsjni.pas à partir de l'unité standard getopts :

pas2jni units/x86_64-linux/getopts.ppu

La commande suivante crée un fichier getopts.java et une unité de bibliothèque pasgetopts.pas à partir de l'unité standard getopts :

pas2jni -J. -O. -Lpasgetopts -units/x86_64-linux/getopts.ppu
