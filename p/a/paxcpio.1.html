NAME

paxcpio — copie les archives de fichiers vers et depuis un archive

SYNOPSIS

paxcpio -o [-0AaBcJjLVvZz] [-C octets] [-F archive] [-H format] [-M flag] [-O archive] < liste-noms [> archive]

paxcpio -i [-06BbcdfJjmrSstuVvZz] [-C octets] [-E fichier] [-F archive] [-H format] [-I archive] [-M flag] [motif ...] [< archive]

paxcpio -p [-0adLlmuVv] repertoire-destination < liste-noms

DESCRIPTION

La commande paxcpio copie des fichiers vers et depuis une archive cpio.

Les options sont les suivantes :

-0
Utilise le caractere NUL (‘\0’) comme terminateur de nom de chemin, au lieu de la nouvelle ligne (‘\n’). Ceci ne s'applique qu'aux noms de chemin lus depuis l'entree standard en mode ecriture et copie, et aux noms de chemin ecrits sur la sortie standard en mode liste. Cette option est attendue pour etre utilisee conjointement avec la fonction -print0 de find(1), l'option -d '' de l'utilitaire interne read de mksh(1) ou le drapeau -0 dans xargs(1).
-o
Cree une archive. Lit la liste des fichiers a stocker dans l'archive depuis l'entree standard, et ecrit l'archive sur la sortie standard.
-A
Ajoute a l'archive specifiee.
-a
Reinitialise les temps d'acces aux fichiers qui ont ete copies dans l'archive.
-B
Definit la taille du bloc de sortie a 5120 octets.
-C octets
Definit la taille du bloc de sortie a octets.
-c
Utilise le format ASCII pour l'entete cpio pour la portabilite.
-F archive
Utilise le fichier specifie comme entree pour l'archive.
-H format
Ecrit l'archive dans le format specifie. Les formats reconnus sont :
ar
Archiveur Unix.
bcpio
Ancien format binaire cpio. Selectionne par -6.
cpio
Ancien format de caractere octal cpio. Selectionne par -c.
sv4cpio
Format cpio hexadecimale SVR4.
sv4crc
Format cpio hexadecimale SVR4 avec sommes de controle. C'est le format par defaut pour la creation de nouvelles archives.
tar
Ancien format tar.
ustar
Format POSIX ustar.
 
 
bin
Ces quatre formats...
crc
...
newc
...
odc
...sont supportes pour la compatibilite descendante seulement.
-J
Utilise l'utilitaire xz pour compresser l'archive.
-j
Utilise l'utilitaire bzip2 pour compresser l'archive.
-L
Suit les liens symboliques.
-M flag
Configure le normaliseur d'archive. flag est soit une valeur numerique compatible avec strtonum(3) qui est directement stockee dans le mot des drapeaux, soit l'une des valeurs suivantes, eventuellement prefaced par “no-” pour les desactiver :
inodes
0x0001 : Serialize les inodes, zero les informations de peripherique.
(cpio, sv4cpio, sv4crc)
links
0x0002 : Stocke le contenu des liens materiels une seule fois.
(cpio, sv4cpio, sv4crc)
mtime
0x0004 : Met a zero l'heure de modification du fichier.
(ar, cpio, sv4cpio, sv4crc, ustar)
uidgid
0x0008 : Definit le proprietaire a 0:0 (root:wheel).
(ar, cpio, sv4cpio, sv4crc, ustar)
verb
0x0010 : Debug cette option.
debug
0x0020 : Debug le stockage de l'entete du fichier.
lncp
0x0040 : Extrait les liens materiels par copie si le lien echoue.
numid
0x0080 : Utilise uniquement des valeurs uid et gid numeriques.
(ustar)
gslash
0x0100 : Ajoute une barre oblique apres les noms de repertoires.
(ustar)
set
0x0003 : Conserve la propriete et l'heure de modification intactes.
dist
0x008B : Nettoie tout sauf l'heure de modification.
norm
0x008F : Nettoie tout.
root
0x0089 : Nettoie les informations de proprietaire et de peripherique.

Lors de la creation d'une archive et de l'affichage verbeux de la sortie, ces operations de normalisation ne sont pas reflechies dans la sortie, car elles sont effectuees apres que la sortie ait ete affichee.

Cette option n'est implementee que pour les routines d'ecriture des formats de fichier ar, cpio, sv4cpio, sv4crc et ustar.

-O archive
Utilise le nom de fichier specifie comme archive vers laquelle ecrire.
-V
Affiche un point (‘.’) pour chaque fichier ecrit dans l'archive.
-v
Soit verbeux sur les operations. Affiche les noms de fichiers tels qu'ils sont ecrits dans l'archive.
-Z
Utilise l'utilitaire compress(1) pour compresser l'archive.
-z
Utilise l'utilitaire gzip pour compresser l'archive.
-i
Extrait les fichiers d'une archive. Lit l'archive depuis l'entree standard, et la stocke dans le repertoire courant. Les motifs peuvent etre specifies pour limiter l'extraction aux fichiers dont le nom correspond a l'un des motifs.
-6
Extrait les archives au format binaire ancien.
-b
Utilise le format binaire ancien.
Translates—Utilise le format octal.
-d

-f

-E fichier

-F archive

-H format

-I archive

-J
Utilise l'utilitaire xz pour decompresser l'archive.
-j

-l

-m
Ne restaure pas les permissions des fichiers.
-r

-t

-u
Ne met pas a jour les fichiers plus recents.
-V
Affiche un point (‘.’) pour chaque fichier extrait de l'archive.
-v
Soit verbeux sur les operations. Affiche les noms de fichiers tels qu'ils sont extraits de l'archive.
-Z
Utilise l'utilitaire compress(1) pour decompresser l'archive.
-z
Utilise l'utilitaire gzip pour decompresser l'archive.
-p
Reproduit les fichiers dans le repertoire de destination. Lit la liste des fichiers depuis l'entree standard et les copie dans le repertoire de destination.
-0
Utilise le caractere NUL comme terminateur de nom de chemin.
-a
Tente de preserver tous les attributs de fichier.
-d
Cree les repertoires de destination si necessaire.
-l
Copie les fichiers par liens physiques.
-L
Suit les liens symboliques.
-m
Ne restaure pas les temps de modification des fichiers.
-u
Ne met pas a jour les fichiers plus recents.
-V
Affiche un point (‘.’) pour chaque fichier copie.
-v
Soit verbeux sur les operations. Affiche les noms de fichiers tels qu'ils sont copies.
-z
Utiliser l'utilitaire gzip(1) pour compresser l'archive.
-i
Restaurer les fichiers à partir d'une archive. Lit le fichier archive à partir de l'entrée standard et extrait les fichiers correspondant aux patterns qui ont été spécifiés sur la ligne de commande.
-6
Traiter les archives au format cpio ancien.
-B
Définir la taille du bloc de l'archive lue à 5120 octets.
-b
Effectuer l'échange d'octets et de mots après la lecture des données de l'archive, pour restaurer des archives créées sur des systèmes avec un ordre d'octets différent.
-C octets

-c

-d
Créer tous les répertoires intermédiaires nécessaires lors de la restauration.
-E fichier

-m

-r

-S

-s

-t
Lister uniquement le contenu de l'archive, aucun fichier ou répertoire ne sera créé.
-u
Écraser les fichiers même si le fichier dans l'archive est plus ancien que celui qui sera écrasé.
-V
Afficher un point (‘.’) pour chaque fichier lu depuis l'archive.
-v
Être verbeux sur les opérations. Lister les noms de fichiers tels qu'ils sont copiés depuis l'archive.
-Z
Utiliser l'utilitaire compress(1) pour décompresser l'archive.
-z
Utiliser l'utilitaire gzip(1) pour décompresser l'archive.
-p
Copier des fichiers d'un emplacement à un autre en une seule passe. La liste des fichiers à copier est lue depuis l'entrée standard et écrite dans un répertoire relatif à l'argument répertoire spécifié.
-a
Réinitialiser les temps d'accès sur les fichiers qui ont été copiés.
-d
Créer tous les répertoires intermédiaires nécessaires pour écrire les fichiers au nouvel emplacement.
-L
Suivre les liens symboliques.

ENVIRONNEMENT

TMPDIR
Chemin dans lequel stocker les fichiers temporaires.

STATUT DE SORTIE

L'utilitaire paxcpio se termine avec l'une des valeurs suivantes :

0
Tous les fichiers ont été traités avec succès.
1
Une erreur s'est produite.

DIAGNOSTICS

Chaque fois que paxcpio ne peut pas créer un fichier ou une liaison lors de l'extraction d'une archive ou ne peut pas trouver un fichier lors de l'écriture d'une archive, ou ne peut pas préserver l'ID utilisateur, l'ID groupe, le mode de fichier, ou les temps d'accès et de modification lorsque l'option -p est spécifiée, un message de diagnostic est écrit dans la sortie d'erreur standard et une valeur de sortie non nulle sera retournée, mais le traitement continuera. Dans le cas où paxcpio ne peut pas créer une liaison vers un fichier, sauf si -M lncp est donné, paxcpio ne créera pas de deuxième copie du fichier.

Si l'extraction d'un fichier d'une archive est terminée prématurément par un signal ou une erreur, paxcpio peut n'avoir extrait que partiellement le fichier souhaité par l'utilisateur. De plus, les modes de fichier des fichiers et répertoires extraits peuvent avoir des bits de fichier incorrects, et les temps de modification et d'accès peuvent être erronés.

Si la création d'une archive est terminée prématurément par un signal ou une erreur, paxcpio peut n'avoir créé l'archive que partiellement, ce qui peut violer la spécification du format d'archive.

AVERTISSEMENTS

Différents formats de fichiers ont différentes tailles de fichiers maximales. Il est recommandé d'utiliser un format tel que cpio ou ustar pour les fichiers plus volumineux.

Format de fichier Taille maximale de fichier
ar 10 Gigaoctets - 1 Octet
bcpio 4 Gibioctets
sv4cpio 4 Gibioctets
sv4crc 4 Gibioctets
cpio 8 Gibioctets
tar 8 Gibioctets
ustar 8 Gibioctets

Les options de format compatibles avec les versions antérieures ne sont pas disponibles dans le frontal pax(1).

L'option -M est une extension MirBSD, disponible à partir de Les archives écrites avec ces options sont cependant compatibles avec la norme et devraient être lisibles sur tout autre système. La seule option dont le comportement n'est pas explicitement autorisé par la norme est l'unification des liens physiques (écriture du contenu des fichiers une seule fois) sélectionnée par -M 0x0002.

L'option -V est une extension GNU, disponible à partir de

La variable ar le format de fichier correspond aux dépôts APT et à la spécification ar(1) de BSD, pas aux binutils GNU (qui peuvent cependant les lire) ni aux systèmes SYSV.

BUGS

Les options -s et -S ne sont actuellement pas implémentées.

Le format de fichier pax n'est pas encore pris en charge.
