NOM

pammasksharpen - Accentue une image via un masque flou

SYNTAXE

pammasksharpen [-nettete=nombre_reel] [-seuil=nombre_reel] fichier_masque [fichier_entree]

Toutes les options peuvent être abrégées à leur plus court préfixe unique. Vous pouvez utiliser deux tirets au lieu d'un seul. Vous pouvez séparer un nom d'option et sa valeur par un espace blanc au lieu d'un signe égal.

EXEMPLES

   pamgauss 5 5 -sigma=.7 -tupletype=GRAYSCALE | pamtopnm >gauss.pgm
   pnmconvol -nooffset gauss.pgm myimage.ppm >blurred.ppm
   pammasksharpen blurred.ppm myimage.ppm >sharpened.ppm

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pammasksharpen lit une image Netpbm en entrée et produit une version accentuée de celle-ci, dans le même format, en sortie. Il le fait via un masque flou, que vous fournissez sous forme d'une autre image Netpbm.

Un masque flou est généralement une version floutée de l'image originale. Le calcul de l'accentuation est le suivant : Calculer le caractère de "bord" d'un échantillon dans l'image d'entrée comme la différence signée entre la valeur de l'échantillon et celle de l'échantillon correspondant dans le masque flou. Cela indique à quel point le pixel est différent de ses voisins. Ajouter un multiple du caractère de bord à l'échantillon original pour obtenir l'échantillon de sortie correspondant. Tronquer si nécessaire. Cela fait que les pixels plus brillants que leurs voisins deviennent encore plus brillants, tandis que les pixels plus sombres que leurs voisins deviennent encore plus sombres. Cela rend les bords — les endroits où les valeurs des pixels changent rapidement dans l'espace — plus apparents.

Le masque flou doit avoir les mêmes dimensions et le même maxval que l'image d'entrée.

Le Masque Flou

Vous créez généralement le masque flou comme un flou gaussien de l'image originale, ce que vous pouvez faire en utilisant pamgauss et pnmconvol comme dans l'exemple ci-dessus. Le noyau de convolution que vous utilisez avec pnmconvol est normalement un carré dont le côté a un nombre impair de pixels.

Lorsque vous créez un masque flou de cette manière, vous devrez choisir la longueur du côté du noyau de convolution. Cette longueur implémente le paramètre de l'accentuation par masque flou généralement connu sous le nom de "rayon". En particulier, un rayon de R pixels correspond à un noyau de convolution de 2R+1 pixels de côté.

Le rayon est un paramètre très important ; vous pouvez ruiner une image avec un rayon trop grand. Vous pouvez utiliser en toute sécurité le rayon le plus élevé avec un objet inanimé, tandis qu'un visage humain exige le moins. Les paysages se situent entre les deux. Mais cela dépend vraiment de la taille des détails. Les détails fins nécessitent un rayon plus petit, sinon vous pourriez oblitérer des détails minuscules de la même taille que la largeur du rayon. Une grande image a souvent des détails plus grands (plus de pixels impliqués), donc peut utiliser un rayon plus grand. Le rayon et la nettété (voir l'option -nettete) interagissent : réduire l'un permet d'augmenter l'autre.

OPTIONS

-nettete=nombre_reel
Spécifie l'ampleur de l'accentuation. C'est le multiple du caractère de bord qui est ajouté à chaque échantillon comme décrit ci-dessus.

nombre_reel est un nombre décimal réel non négatif. Zéro signifie aucune accentuation.

Ce paramètre est connu sous le nom de "amount" dans ImageMagick.

La valeur par défaut est 1.0.

Cette option est nouvelle dans Netpbm 10.30 (octobre 2005). Avant cela, la nettété était toujours de 1.0.

-seuil=nombre_reel
C'est la quantité minimale de caractère de bord qui sera considérée comme un caractère de bord. C'est-à-dire, si la magnitude du caractère de bord est inférieure à cela, pammasksharpen traitera le caractère de bord comme nul.

Une valeur non nulle peut être nécessaire ici pour éviter la tache dans les zones lisses.

C'est une fraction du maxval (donc elle est dans la plage [0, 1.0]).

La valeur par défaut est 0.

Cette option est nouvelle dans Netpbm 10.34 (juin 2006).
