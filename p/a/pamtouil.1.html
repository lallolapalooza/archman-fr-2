NOM

pamtouil - convertir une image PNM ou PNM/alpha en fichier icône Motif UIL

SYNTAXE

pamtouil [-nom=nom_uil] [fichier_pam]

Vous pouvez abréger n'importe quelle option à son plus court préfixe unique. Vous pouvez utiliser deux tirets au lieu d'un pour délimiter une option. Vous pouvez séparer une option de sa valeur par un espace blanc au lieu de =.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pamtouil lit une image PNM ou PAM en entrée et produit un fichier icône Motif UIL en sortie. Si l'entrée est PAM, il peut s'agir d'une image niveaux de gris ou couleur régulière, ou niveaux de gris+alpha, ou couleur+alpha. Lorsque le canal alpha est présent, pamtouil rend les pixels qui sont plus qu'à moitié transparents comme transparents dans la sortie.

Dans la table des couleurs UIL, pamtouil utilise les noms de couleurs de la base de données RGB -- la même que celle utilisée par ppmmake(1).

Lorsqu'une couleur de l'entrée ne correspond pas exactement à l'une des couleurs nommées dans la base de données RGB, pamtouil utilise la couleur nommée la plus proche dans la base de données RGB.

OPTIONS

-nom

Permet de spécifier la chaîne de préfixe qui est imprimée dans la sortie
UIL résultante. Si non spécifié, par défaut le nom de fichier
(sans extension) de l'argument fichier_ppm. Si -nom n'est pas
spécifié et aucun fichier_ppm n'est spécifié (c'est-à-dire entrée par
pipe), le préfixe par défaut sera la chaîne 'noname'.

HISTORIQUE

Avant mai 2002, pamtouil s'appelait ppmtouil et n'avait aucun moyen de spécifier la transparence.
