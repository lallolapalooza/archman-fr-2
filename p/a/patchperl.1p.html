PATCHPERL(1) Documentation Perl fournie par l'utilisateur PATCHPERL(1)

NOM

patchperl - Applique un patch à un arborescence source de perl

VERSION

version 2.14

SYNTAXE

patchperl

OPTIONS DE LIGNE DE COMMANDE

"--version"
Affiche la version de Devel::PatchPerl sur STDOUT et quitte.
"--patchlevel"
Devel::PatchPerl mettra normalement à jour le fichier "patchlevel.h" dans l'arborescence source de perl pour indiquer que des correctifs locaux ont été appliqués. Ce comportement est annulé s'il est détecté que le script opère dans un dépôt git. Pour outrepasser cela et mettre à jour "patchlevel.h" lorsqu'on est dans un dépôt Git, utilisez cette option.
