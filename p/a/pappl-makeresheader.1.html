NOM

pappl-makeresheader - utilitaire d'en-tête de ressource

SYNTAXE

pappl-makeresheader FICHIERS > NOMFICHIER.h

DESCRIPTION

pappl-makeresheader crée un fichier d'en-tête C approprié pour être inclus dans une application d'imprimante. Le fichier d'en-tête crée un tableau de caractères C non signés ou une constante de chaîne qui peut être utilisée avec les fonctions papplSystemAddResourceData ou papplSystemAddResourceString, ou comme données pour une icône d'imprimante dans la structure pappl_icon_t. Les noms de variables C utilisés pour chaque fichier sont générés en remplaçant tous les espaces, points et tirets par un soulignement. Par exemple, un fichier nommé « my printer-icon.png » aurait le nom de variable C « my_printer_icon_png ».
