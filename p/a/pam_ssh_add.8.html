NOM

pam_ssh_add - Module PAM pour charger automatiquement les clés ssh dans un agent

DESCRIPTION

pam_ssh_add fournit des modules d'authentification et de session qui permettent aux utilisateurs de démarrer leur session avec un ssh-agent en cours d'exécution avec autant de clés ssh que possible chargées.

S'il est utilisé, le module d'authentification stocke simplement le jeton d'authentification pour une utilisation ultérieure par le module de session. Comme ce module n'effectue aucune authentification réelle, il renvoie PAM_CRED_INSUFFICIENT en cas de succès et doit toujours être accompagné d'un module d'authentification réel dans votre configuration pam.

Par défaut, le module de session démarre un nouveau ssh-agent et exécute ssh-add, chargeant toutes les clés qui existent dans le chemin par défaut pour l'utilisateur nouvellement connecté. Si des clés demandent un mot de passe et qu'un jeton d'authentification a été stocké avec succès, ce jeton sera fourni comme mot de passe.

OPTIONS

debug

Cette option activera la journalisation de débogage dans syslog.

EXEMPLES

        auth     required  pam_unix.so
        auth     optional  pam_ssh_add.so
        session  optional  pam_ssh_add.so
