NOM

pam_cifscreds - Module PAM pour gérer les identifiants NTLM dans le keyring du noyau

SYNOPSIS

Modifiez les fichiers de configuration PAM des systèmes pour lesquels vous souhaitez enregistrer automatiquement les identifiants NTLM, par exemple /etc/pam.d/login, et modifiez comme suit :

    ...
    auth       substack     system-auth
+++ auth       optional     pam_cifscreds.so
    auth       include      postlogin
    ...
    ...
    session    include      system-auth
+++ session    optional     pam_cifscreds.so domain=DOMAINE
    session    include      postlogin
    ...

Remplacez DOMAINE par le nom de votre domaine Windows, ou utilisez host= comme décrit ci-dessous.

DESCRIPTION

Le module PAM pam_cifscreds est un outil permettant d'ajouter automatiquement des identifiants (nom d'utilisateur et mot de passe) dans le but d'établir des sessions pour des montages multi-utilisateurs.

Lorsqu'un système de fichiers cifs est monté avec l'option "multiuser", et n'utilise pas l'authentification krb5, il doit pouvoir obtenir les identifiants de chaque utilisateur à partir d'une source. Le module pam_cifscreds peut être utilisé pour fournir ces identifiants au noyau automatiquement à l'ouverture de session.

Dans la section session du fichier de configuration PAM, le module peut spécifier soit un nom de domaine NT, soit une liste de noms d'hôtes ou d'adresses.

OPTIONS

pam_cifscreds prend en charge quelques options qui peuvent être définies dans les fichiers de configuration PAM. Vous devez spécifier soit domain=, soit host= (et une seule de ces deux options).

debug
Active des journaux de débogage supplémentaires.
domain=<nom du domaine NT>
Les identifiants seront ajoutés pour le nom du domaine NT spécifié.
host=<nom d'hôte ou adresse IP>[,...]
Les identifiants seront ajoutés pour les noms d'hôtes ou les adresses IP spécifiés.

NOTES

Le module PAM pam_cifscreds nécessite un noyau compilé avec le support du type de clé login. Ce type de clé a été ajouté dans la version 3.3 des noyaux Linux principaux.

Étant donné que pam_cifscreds ajoute des clés au keyring de session, il est fortement recommandé d'utiliser pam_keyinit pour s'assurer qu'un keyring de session est établi à l'ouverture de session.

VOIR AUSSI
