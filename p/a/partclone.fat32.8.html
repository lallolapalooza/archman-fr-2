PARTCLONE(8) Manuel utilisateur Partclone PARTCLONE(8)

NOM

partclone - L'utilitaire pour cloner et restaurer une partition.

SYNTAXE

partclone.[typefst] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] cible} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] logfile [-R | --rescue] [-L | --logfile] logfile [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPTION

partclone.[typefst] fait partie du projet Partclone. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une compatibilité accrue du système de fichiers en utilisant des bibliothèques existantes, par exemple, e2fslibs est utilisé pour lire le bloc utilisé de la partition ext2.

Les systèmes de fichiers supportés par Partclone incluent btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Il prend également en charge certains systèmes d'exploitation non-linux, par ex. : NTFS, FAT et EXFAT (pour Windows), HFS plus (MAC OS APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) et MINIX (MINIX3).

Tous les utilitaires partclone peuvent être exécutés comme partclone.[typefst], ce qui est très similaire à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, exécutez simplement partclone.hfsp

       Système de Fichiers                 partclone.[typefst]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       autres (FS non supporté)    partclone.imager

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-s FICHIER, --source FICHIER

FICHIER source. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique, selon votre action. Normalement, la source de sauvegarde est un périphérique, la source de restauration est un fichier image.

La réception de données depuis un pipeline n'est supportée QUE pour la restauration, ignorez simplement l'option -s ou utilisez '-' pour recevoir des données de stdin.

-o FICHIER, --output FICHIER

FICHIER de sortie. Le FICHIER peut être un fichier image (que partclone générera) ou un périphérique, selon votre action. Normalement, la sortie de sauvegarde va vers un fichier image et la sortie de restauration va vers un périphérique.

L'envoi de données vers un pipeline est également supporté UNIQUEMENT pour la sauvegarde, ignorez simplement l'option -o ou utilisez '-' pour envoyer des données vers stdout.

-O FICHIER, --overwrite FICHIER

Écrase le FICHIER, en l'écrasant s'il existe.

-W FICHIER, --restore_raw_file FICHIER

Crée un fichier brut spécial pour le périphérique de boucle.

-c, --clone

Sauvegarde la partition dans le format d'image spécial.

-r, --restore

Restaure la partition à partir du format d'image spécial.

-b, --dev-to-dev

Copie locale de périphérique à périphérique à la volée, la source et la sortie sont toutes deux des périphériques.

-D, --domain

Crée un fichier journal de domaine GNU Ddrescue à partir du périphérique source. C'est un fichier lisible par l'homme dans lequel + marque les zones de blocs utilisées et ? marque les zones libres.

--offset_domain=X

Ajoute X (en octets) à toutes les positions signalées dans le fichier journal de domaine.

--restore_raw_file

Crée un fichier brut spécial pour le périphérique de boucle.

-L FICHIER, --logfile FICHIER

Spécifie un chemin spécial pour enregistrer les informations du journal partclone. (par défaut /var/log/partclone.log)

-R, --rescue

Continue après les erreurs de lecture du disque.

-C, --no_check

Ne vérifie pas la taille du périphérique et l'espace libre.

-N, --ncurses

Utilise l'interface utilisateur textuelle Ncurses.

-I, --ignore_fschk

Ignore la vérification du système de fichiers.

-i, --ignore_crc

Ignore l'erreur de vérification crc.

-F, --force

Force le déroulement.

-f sec, --UI-fresh sec

Définit un intervalle spécial en secondes pour l'actualisation de l'interface utilisateur.

-z taille, --buffer_size taille

Taille du tampon de lecture/écriture (par défaut : 1048576)

-q, --quiet

Désactive les messages de progression.

-dniveau, --debug niveau

Définit le niveau de débogage [1|2|3]

-x, --compresscmd CMD

Lance CMD comme un tuyau de sortie pour compresser l'image clonée.

-aX, --checksum-mode=X

Formule de somme de contrôle à utiliser pour ajouter la détection d'erreurs.

où X :

0 : Aucune somme de contrôle (pas de ralentissement, image la plus petite)

1 : CRC32 (Rapide à calculer, détection basique)

2 : xxHash, algorithme de hachage non cryptographique extrêmement rapide

-kX, --blocks-per-checksum=X

Écrit une somme de contrôle pour tous les X blocs.

-w, --skip_write_error

Continue la restauration en cas d'erreurs d'écriture.

--write-direct-io

Écrit les données sur la partition CIBLE sans cache.

--read-direct-io

Lit les données de la partition SOURCE sans cache.

-B, --no_block_detail

Affiche les messages de progression sans détail des blocs.

--binary-prefix

Affiche la progression avec la taille en bits (par défaut, c'est en Mo, Go...).

--prog-second

Affiche la progression en secondes (par défaut, c'est en minutes).

-E, --offset=X

Ajoute un décalage X (en octets) à la sortie.

-T, --btfiles

Restaure les blocs sous forme de fichiers pour ClonezillaBT.

-t, --btfiles_torrent

Restaure les blocs sous forme de fichiers pour ClonezillaBT mais ne génère que le torrent.

-n, --note NOTE

Affiche une NOTE de message (128 mots).

-h, --help

Affiche le résumé des options.

-v, --version

Affiche la version

partclone.fat32(8) — Partclone

NOM

partclone.fat32 — outil de clonage pour les systèmes de fichiers FAT32.

SYNTAXE

partclone.fat32 [OPTIONS] -s SOURCE -o DESTINATION

DESCRIPTION

partclone.fat32 est un utilitaire qui permet de cloner, restaurer et vérifier les systèmes de fichiers FAT32. Il est conçu pour être efficace en ne copiant que les blocs utilisés.

OPTIONS

Les options courantes sont les suivantes :

-c, --clone
Cloner le système de fichiers source vers la destination.
-r, --restore
Restaurer le système de fichiers source (image) vers la destination.
-s, --source SOURCE
Spécifie la source. Il peut s'agir d'un périphérique bloc (par ex. /dev/sda1) ou d'un fichier image.
-o, --output DESTINATION
Spécifie la destination. Il peut s'agir d'un périphérique bloc ou d'un fichier.
-d, --debug
Activer les informations de débogage.
-v, --verbose
Afficher des informations détaillées pendant l'opération.
-f, --force
Forcer l'opération, même si des avertissements sont rencontrés.
-Z, --zlib
Utiliser la compression zlib pour les images. Nécessite que le format d'image soit compatible.
-c, --xz
Utiliser la compression xz pour les images. Nécessite que le format d'image soit compatible.
-q, --quick
Mode rapide pour la vérification de l'image (moins rigoureux).
-C, --check
Vérifier l'intégrité d'une image.
--log-file FICHIER
Spécifie un fichier pour enregistrer les journaux du programme.

FICHIERS

/var/log/partclone.log

Le fichier journal de partclone

EXEMPLES

 Cloner /dev/hda1 vers hda1.img et afficher les informations de débogage.
   partclone.fat32 -c -d -s /dev/hda1 -o hda1.img
 Restaurer /dev/hda1 à partir de hda1.img et afficher les informations de débogage.
   partclone.fat32 -r -d -s hda1.img -o /dev/hda1
 Restaurer une image de clonezilla (split, gzip,) avec une source stdin
   cat sda1.fat32-ptcl-img.gz.a* | gunzip -c | partclone.fat32 -d -r -s - -o /dev/sda1

DIAGNOSTICS

Les diagnostics suivants peuvent être émis sur stderr :

partclone fournit des codes de retour qui peuvent être utilisés dans les scripts :

Code Diagnostic
0 Le programme s'est terminé avec succès.
1 Le clonage ou la restauration semblent avoir échoué.

BOGUES

Signaler les bogues à thomas@clonezilla.org ou http://partclone.org.

Vous pouvez obtenir de l'aide sur http://partclone.org
