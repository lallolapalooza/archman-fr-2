NOM

pam_ldap - Module PAM pour l'authentification basée sur LDAP

SYNTAXE


pam_ldap.so
[...]

DESCRIPTION

Ceci est un module PAM qui utilise un serveur LDAP pour vérifier les droits d'accès et les identifiants des utilisateurs.

OPTIONS

use_first_pass
Spécifie que le module PAM doit utiliser le premier mot de passe fourni dans la pile d'authentification et ne pas demander à l'utilisateur un mot de passe.
try_first_pass
Spécifie que le module PAM doit utiliser le premier mot de passe fourni dans la pile d'authentification et s'il échoue, demander à l'utilisateur un mot de passe.
nullok
Spécifier cette option permet aux utilisateurs de se connecter avec un mot de passe vide. Normalement, les connexions sans mot de passe sont refusées.
ignore_unknown_user
Spécifie que le module PAM doit renvoyer PAM_IGNORE pour les utilisateurs qui ne sont pas présents dans l'annuaire LDAP. Cela amène le framework PAM à ignorer ce module.
ignore_authinfo_unavail
Spécifie que le module PAM doit renvoyer PAM_IGNORE s'il ne parvient pas à contacter le serveur LDAP. Cela amène le framework PAM à ignorer ce module.
no_warn
Spécifie que les messages d'avertissement ne doivent pas être propagés à l'application PAM.
use_authtok
Ceci amène le module PAM à utiliser le mot de passe fourni précédemment lors du changement de mot de passe. Le module ne demandera pas à l'utilisateur un nouveau mot de passe (il est analogue à use_first_pass).
debug
Cette option amène le module PAM à enregistrer des informations de débogage dans syslog(3).
minimum_uid=UID
Cette option amène le module PAM à ignorer l'utilisateur si l'identifiant de l'utilisateur est inférieur à la valeur spécifiée. Ceci peut être utilisé pour contourner les vérifications LDAP pour les utilisateurs système (par exemple, en le réglant à 1000).

SERVICES FOURNIS PAR LE MODULE

Tous les services sont fournis par ce module, mais actuellement les changements de session ne sont pas implémentés dans le démon nslcd.

FICHIERS

/etc/pam.conf
le fichier de configuration principal de PAM
/etc/nslcd.conf
Le fichier de configuration du démon nslcd (voir nslcd.conf(5))

VOIR AUSSI

pam.conf(5), nslcd(8), nslcd.conf(5)
