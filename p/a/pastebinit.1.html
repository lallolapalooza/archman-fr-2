NOM

pastebinit - client de pastebin en ligne de commande

SYNOPSIS

pastebinit [-abfhiljmrtup]

DESCRIPTION

Cette page de manuel documente brièvement les commandes pastebinit

pastebinit lit du texte et l'envoie vers un "pastebin" sur internet, retournant l'URL à l'utilisateur.

Il permet de passer le texte via un pipe (|) ou à partir de fichiers en tant qu'arguments.

OPTIONS

Arguments optionnels (non pris en charge par tous les pastebins)

-a [auteur] (défaut : $USER)

-b [url_du_pastebin] (le défaut est spécifique à la distribution avec un repli sur pastebin.com)

-E Imprime le contenu sur stdout également

-f [format_pour_coloration_syntaxique] (défaut : text) (vérifiez le site web du pastebin pour la liste complète, exemple : python)

-h Écran d'aide

-i [nom_fichier] Utilise le nom de fichier pour l'entrée

-l Liste tous les pastebins pris en charge

-j [jabberid] (défaut : none)

-m [permatag] (défaut : none)

-t [titre_du_paste] (défaut : none)

-P [privé] (défaut : 1)

-u [nom_utilisateur] (défaut : none)

-p [mot_de_passe] (défaut : none)

-v Numéro de version

FICHIER DE CONFIGURATION

Si un fichier .pastebinit.xml est trouvé dans le répertoire personnel de l'utilisateur, pastebinit l'utilisera pour sa configuration.

Voici un exemple de fichier :


<pastebinit>
<pastebin>https://paste.ubuntu.com</pastebin>
<author>Stephane Graber</author>
<jabberid>stgraber@stgraber.org</jabberid>
<format>text</format>
</pastebinit>
