NOM

pamchannel - extraire des canaux d'une image PAM

SYNTAXE

pamchannel [-infile=infile] [-tupletype=tupletype] [numcanal ...]

L'abréviation unique minimale de l'option est acceptable. Vous pouvez utiliser des doubles tirets au lieu de tirets simples pour désigner les options. Vous pouvez utiliser des espaces blancs à la place du signe égal pour séparer un nom d'option de sa valeur.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pamchannel lit une image Netpbm en entrée et produit une image PAM en sortie, composée des canaux (plans) indiqués de l'entrée.

Chaque argument numcanal est le numéro d'un canal de l'entrée, le premier canal étant zéro. Les canaux dans la sortie sont dans l'ordre de ces arguments.

La sortie a les mêmes dimensions que l'entrée, sauf que la profondeur est le nombre d'arguments numcanal que vous fournissez. Le type de tuple est une chaîne nulle à moins que vous ne spécifiiez l'option -tupletype.

Ce programme fonctionne sur les flux multi-images, produisant un flux de sortie correspondant. Mais avant Netpbm 10.32 (février 2006), il ignorait toutes les images après la première.

pamstack fait l'inverse de pamchannel : il prend plusieurs images PAM ou PNM comme entrée et empile leurs plans (canaux) les uns sur les autres pour produire une seule image PAM.

OPTIONS

-infile infile
Ceci spécifie le fichier d'entrée, qui est par défaut l'entrée standard. Vous pouvez spécifier - pour sélectionner explicitement l'entrée standard.

Ceci est un peu peu conventionnel pour les programmes Netpbm, qui ont généralement la spécification du fichier d'entrée comme argument. Pour pamchannel, les arguments sont des numéros de canal.

-tupletype tupletype
Ceci spécifie le nom du type de tuple à enregistrer dans la sortie. Vous pouvez utiliser n'importe quelle chaîne de caractères d'une longueur maximale de 255 caractères. Certains programmes reconnaissent certains noms. Si vous omettez cette option, le nom du type de tuple par défaut est nul.

VOIR AUSSI

pam(5)

pamstack(1)

HISTORIQUE

pamchannel était nouveau, ainsi que le format PAM, dans Netpbm 9.7 (août 2000).
