NOM

pacini - interroger les fichiers de configuration de style pacman

SYNTAXE

pacini [options] [<fichier> [<directive>...]]
pacini (--liste-sections|--aide|--version)

DESCRIPTION

Interroge les options de configuration des fichiers INI de style pacman. Si aucune directive n'est fournie, le fichier sera affiché dans un format normalisé. Par défaut, si une seule directive est fournie, seule sa valeur sera affichée sans le nom de l'option. Pour les directives sans valeur, le nom de la directive sera utilisé comme valeur. Si fichier est omis ou vaut "-", la configuration sera lue depuis stdin.

OPTIONS

--section=nom
N'affiche que les directives listées dans la section nom.
--liste-sections
Liste les sections configurées.
--verbeux
Affiche toujours les noms des directives même si une seule directive est fournie.
--aide
Affiche les informations d'utilisation et quitte.
--version
Affiche les informations de version et quitte.
