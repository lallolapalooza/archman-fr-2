NOM

pano_modify - Modifier les paramètres de sortie d'un fichier de projet

SYNTAXE

pano_modify [options] input.pto

DESCRIPTION

pano_modify modifie un seul projet Hugin .pto.

OPTIONS

-o, --output=fichier.pto
Fichier PTO Hugin de sortie. Par défaut : <nom_fichier>_mod.pto
-p, --projection=NOMBRE
Définit la projection de sortie à NOMBRE
RECTILINEAR = 0,
PANORAMA (Circulaire) = 1,
EQUIRECTANGULAR = 2,
FISHEYE_FF = 3,
STEREOGRAPHIC = 4,
MERCATOR = 5,
TRANS_MERCATOR = 6,
SINUSOIDAL = 7,
LAMBERT_EQUAL_AREA_CONIC = 8,
LAMBERT_AZIMUTHAL = 9,
ALBERS_EQUAL_AREA_CONIC = 10,
MILLER_CYLINDRICAL = 11,
PANINI = 12,
ARCHITECTURAL = 13,
ORTHOGRAPHIC = 14,
EQUISOLID = 15,
EQUI_PANINI = 16,
BIPLANE = 17,
TRIPLANE = 18,
PANINI_GENERAL = 19,
THOBY = 20,
HAMMER = 21
--fov=AUTO|HFOV|HFOVxVFOV
Définit le champ de vision.

AUTO : calcule le fov optimal

HFOV|HFOVxVFOV : définit le fov donné

-s, --straighten
Redresse le panorama
-c, --center
Centre le panorama
--canvas=AUTO|num%|LARGEURxHAUTEUR
Définit la taille de la toile de sortie

AUTO : calcule la taille optimale de la toile

num% : met à l'échelle la taille optimale selon le pourcentage donné

LARGEURxHAUTEUR : définit la taille donnée

--crop=AUTO|AUTOHDR|gauche,droite,haut,bas
Définit le rectangle de recadrage

AUTO : recadrage automatique du panorama

AUTOHDR : recadrage automatique du panorama HDR

gauche,droite,haut,bas : à la taille donnée

--output-exposure=AUTO|num
Définit la valeur d'exposition de sortie à l'exposition moyenne (AUTO) ou à la valeur donnée
--output-type=str
Définit le type de sortie

Les éléments valides sont (plusieurs éléments séparés par une virgule)

NORMAL|N : panorama normal

STACKSFUSEDBLENDED|BF : panorama LDR avec piles mélangées

EXPOSURELAYERSFUSED|FB : panorama LDR avec couches d'exposition fusionnées (toute disposition)

HDR : panorama HDR

REMAP : images remappées avec exposition corrigée

REMAPORIG : images remappées avec exposition non corrigée

HDRREMAP : images remappées dans un espace colorimétrique linéaire

FUSEDSTACKS : piles d'exposition fusionnées

HDRSTACKS : piles HDR

EXPOSURELAYERS : couches d'exposition mélangées

--ldr-file=JPG|TIF|PNG
Définit le type de fichier pour la sortie du panorama LDR
--ldr-compression=str
Définit la compression pour la sortie du panorama LDR

Pour TIF : NONE|PACKBITS|LZW|DEFLATE

Pour JPG : qualité en tant que nombre

--hdr-file=EXR|TIF
Définit le type de fichier pour la sortie du panorama HDR
--hdr-compression=str
Définit la compression pour la sortie du panorama HDR

Pour TIF : NONE|PACKBITS|LZW|DEFLATE

--blender=ENBLEND|INTERNAL
Définit le mélangeur à utiliser lors de l'étape de couture
--rotate=lacet,tangage,roulis
Fait pivoter l'ensemble du panorama avec les angles donnés
--translate=x,y,z
Translade l'ensemble du panorama avec les valeurs données
-h, --help
Affiche l'aide
