NOM

pam_ecryptfs - Module PAM pour eCryptfs

SYNTAXE

pam_ecryptfs.so [unwrap]

DESCRIPTION

pam_ecryptfs est un module PAM qui peut utiliser le mot de passe de connexion pour déchiffrer une phrase de passe de montage ecryptfs stockée dans ~/.ecryptfs/wrapped-passphrase, et monter automatiquement un répertoire cryptographique privé.

OPTIONS

unwrap
Utilise la phrase de passe de connexion pour déchiffrer une phrase de passe de montage eCryptfs.

SERVICES FOURNIS PAR LE MODULE

Les services auth et session sont pris en charge.

EXEMPLES

Pour déchiffrer une phrase de passe de montage et monter automatiquement un répertoire privé lors de la connexion, ajoutez les lignes suivantes à

/etc/pam.d/common-auth:

        auth    required        pam_ecryptfs.so unwrap

/etc/pam.d/common-session:

        session optional        pam_ecryptfs.so unwrap
