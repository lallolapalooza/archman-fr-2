NOM

parl - Chargeur binaire PAR

SYNTAXE

(Veuillez consulter pp pour des moyens pratiques de créer des exécutables autonomes, des scripts ou des archives PAR à partir de programmes Perl.)

Pour créer une distribution PAR à partir d'une distribution de module CPAN :

% parl -p                 # crée une distribution PAR dans le chemin courant
% parl -p Foo-0.01        # suppose une distribution CPAN décompressée dans Foo-0.01/

Pour manipuler une distribution PAR :

% parl -i Foo-0.01-i386-freebsd-5.8.0.par   # installer
% parl -i http://foo.com/Foo-0.01           # ajoute automatiquement le nom d'architecture + version Perl
% parl -i cpan://AUTRIJUS/PAR-0.74          # utilise le répertoire de l'auteur CPAN
% parl -u Foo-0.01-i386-freebsd-5.8.0.par   # désinstaller
% parl -s Foo-0.01-i386-freebsd-5.8.0.par   # signer
% parl -v Foo-0.01-i386-freebsd-5.8.0.par   # vérifier

Pour utiliser Hello.pm depuis ./foo.par :

% parl -A./foo.par -MHello 
% parl -A./foo -MHello      # la partie .par est facultative

Même chose, mais rechercher foo.par dans @INC :

% parl -Ifoo.par -MHello 
% parl -Ifoo -MHello        # idem

Exécuter test.pl ou script/test.pl depuis foo.par :

% parl foo.par test.pl      # recherche 'main.pl' par défaut,
                            # sinon exécute 'test.pl'

Pour créer un exécutable autonome contenant un fichier PAR :

% parl -O./foo foo.par
% ./foo test.pl             # identique à ci-dessus

Pour intégrer les modules et objets partagés nécessaires à l'exécution de PAR (comme "Zlib", "IO", "Cwd", etc.), utilisez l'option -b :

% parl -b -O./foo foo.par
% ./foo test.pl             # s'exécute n'importe où avec les modules de base installés

Si vous souhaitez également intégrer les modules de base, utilisez l'option -B à la place :

% parl -B -O./foo foo.par
% ./foo test.pl             # s'exécute n'importe où avec l'interpréteur Perl

Ceci est particulièrement utile lors de la création d'exécutables binaires autonomes ; voir pp pour les détails.

DESCRIPTION

Cette commande autonome offre à peu près la même fonctionnalité que "perl -MPAR", sauf qu'elle prend les fichiers .par préchargés via "-Afoo.par" au lieu de "-MPAR=foo.par".

De plus, elle vous permet de convertir une distribution CPAN en une distribution PAR, ainsi que de manipuler de telles distributions. Pour plus d'informations sur les distributions PAR, voir PAR::Dist.

Vous pouvez l'utiliser pour exécuter des fichiers .par :

# exécute script/run.pl dans l'archive, utilise ses lib/* comme bibliothèques
% parl myapp.par run.pl     # exécute run.pl ou script/run.pl dans myapp.par
% parl otherapp.pl          # exécute également des scripts perl normaux

Cependant, si l'archive .par contient soit main.pl, soit script/main.pl, celle-ci est utilisée à la place :

% parl myapp.par run.pl     # exécute main.pl, avec 'run.pl' comme @ARGV

Enfin, l'option "-O" crée un exécutable binaire autonome à partir d'un fichier PAR :

% parl -B -Omyapp myapp.par
% ./myapp                   # exécutez-le n'importe où sans binaires Perl

Avec l'option "--par-options", les binaires générés peuvent agir comme "parl" pour empaqueter de nouveaux binaires :

% ./myapp --par-options -Omyap2 myapp.par   # identique à ./myapp
% ./myapp --par-options -Omyap3 myap3.par   # maintenant avec un PAR différent

Pour une explication du format d'exécutable autonome, veuillez consulter par.pl.
