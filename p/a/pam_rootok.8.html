NOM

pam_rootok - Accès root uniquement pour l'authentification

SYNTAXE

pam_rootok.so [debug]

DESCRIPTION

pam_rootok est un module PAM qui authentifie l'utilisateur si son UID est 0. Les applications créées avec setuid-root conservent généralement le UID de l'utilisateur mais s'exécutent avec l'autorité d'un UID effectif amélioré. C'est l'UID réel qui est vérifié.

OPTIONS

debug

Affiche des informations de débogage.

TYPES DE MODULES FOURNIS

Les types de modules auth, account et password sont fournis.

VALEURS DE RETOUR

PAM_SUCCESS

L'UID est 0.

PAM_AUTH_ERR

L'UID n'est pas 0.

EXEMPLES

Dans le cas de l'application su(1), l'utilisation historique consiste à permettre au superutilisateur d'adopter l'identité d'un utilisateur moins privilégié sans utiliser de mot de passe. Pour obtenir ce comportement avec PAM, les deux lignes suivantes sont nécessaires pour l'entrée correspondante dans le fichier de configuration /etc/pam.d/su :

# Authentification su. Le root a l'accès par défaut.
auth  sufficient   pam_rootok.so
auth  required     pam_unix.so

VOIR AUSSI

su(1), pam.conf(5), pam.d(5), pam(8)
