NOM

pacinfo - afficher des informations sur les paquets

SYNTAXE

pacinfo [options] (<pkgspec>|<pkgname>)...
pacinfo (--help|--version)

DESCRIPTION

Si un pkgname est donné, les informations pour tous les paquets correspondant à ce nom dans toutes les bases de données seront affichées.

Si stdin n'est pas connecté à un terminal, les paquets seront lus depuis stdin.

OPTIONS

--config=chemin
Définir un chemin alternatif pour le fichier de configuration.
--dbext=extension
Définir une extension alternative pour la base de données de synchronisation.
--dbpath=chemin
Définir un chemin alternatif pour la base de données.
--root=chemin
Définir une racine d'installation alternative.
--sysroot=chemin
Définir une racine système alternative. Voir pacutils-sysroot(7).
--null[=sep]
Définir un séparateur alternatif pour les valeurs analysées depuis stdin. Par défaut, une nouvelle ligne "\n" est utilisée comme séparateur. Si --null est utilisé sans spécifier sep, "NUL" sera utilisé.
--no-timeout
Désactiver les timeouts à faible vitesse pour les téléchargements.
--short
Afficher des informations succinctes. Adapté pour imprimer un nombre potentiellement important de paquets : 
pacsift --name libreoffice | pacinfo --short
--verbose
Afficher des informations supplémentaires sur les paquets : "requis par", "optionnel pour", et "signature base64".
--raw
Afficher les tailles et dates brutes numériques.
--removable-size
Inclure la taille des dépendances amovibles dans la taille installée.
--help
Afficher les informations d'utilisation et quitter.
--version
Afficher les informations de version et quitter.

CAVEATS

pacinfo détermine s'il doit lire les paquets depuis stdin en se basant sur une vérification naïve utilisant isatty(3). Si pacinfo est appelé dans un environnement, tel qu'une fonction shell ou un script utilisé dans un pipe, où stdin n'est pas connecté à un terminal mais ne contient pas de paquets à imprimer, pacinfo devrait être appelé avec stdin fermé. Pour les shells compatibles POSIX, cela peut être fait avec "<&-".
