PATEXTRACT(1) Manuel des commandes générales PATEXTRACT(1)

NOM

patextract - Extraire une partie d'un fichier image PNG

SYNTAXE

patextract fichier_entree x y largeur hauteur

DESCRIPTION

patextract est un programme qui extrait une partie d'un fichier image PNG et génère cette partie au format PAT.

fichier_entree.png est un fichier PNG RVB ou ARVB ; la partie résultante de l'image est écrite au format PAT sur la sortie standard. Le fichier peut être utilisé avec visgrep(1) pour extraire le contenu de l'écran.

OPTIONS

Cette commande ne possède pas d'options.

VOIR AUSSI

pat2ppm(1), patextract(1), rgb2pat(1), visgrep(1), xte(1).
