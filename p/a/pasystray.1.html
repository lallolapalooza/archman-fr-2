PASYSTRAY(1) Manuel des commandes générales PASYSTRAY(1)

NOM

pasystray - Contrôleur PulseAudio pour la barre d'état système

SYNTAXE

pasystray [options]

DESCRIPTION

pasystray permet de contrôler divers paramètres du serveur PulseAudio depuis la barre d'état système X11. Cliquer sur l'icône dans la barre d'état système affichera un menu graphique, permettant à l'utilisateur de :

•
Ajuster le volume des flux (streams) et des sorties/entrées (sinks/sources)
•
Transférer les flux entre les sorties/entrées
•
Changer la sortie/entrée par défaut
•
Définir le serveur par défaut (PULSE_SERVER)
•
Détecter les services PulseAudio réseau
•
Renommer les périphériques

ASSOCIATIONS SOURIS

Icône d'état :

•
Clic milieu / Alt + clic gauche : activer/désactiver le son, sortie par défaut
•
Ctrl + clic milieu / Ctrl + Alt + clic gauche : activer/désactiver le son, entrée par défaut
•
Faire défiler haut/bas : ajuster le volume, sortie par défaut
•
Ctrl + faire défiler haut/bas : ajuster le volume, entrée par défaut

Élément de menu sortie/entrée :

•
Faire défiler haut/bas : ajuster le volume
•
Clic gauche : définir comme sortie/entrée par défaut
•
Clic milieu / Alt + clic gauche : activer/désactiver le son
•
Clic droit : ouvrir le menu pour déplacer toutes les sorties/entrées vers cette sortie/entrée ou la renommer

Élément de menu flux de lecture/enregistrement :

•
Faire défiler haut/bas : ajuster le volume
•
Clic milieu : activer/désactiver le son

MODULES PULSEAUDIO OPTIONNELS

pasystray peut utiliser les modules PulseAudio suivants :

•
module-device-manager - renommage de périphériques
•
module-zeroconf-discover - découverte de périphériques réseau

Ces modules peuvent devoir être chargés, en utilisant par exemple pactl(1) ou pasystray lui-même.

SORTIES/ENTRÉES DISTANTES

Pour détecter les sorties/entrées distantes, ainsi que pour activer module-zeroconf-discover localement, module-zeroconf-publish doit être activé sur le serveur distant.

SERVEUR DISTANT

Comme avec la plupart des applications compatibles PulseAudio, la variable d'environnement PULSE_SERVER peut être définie avec l'adresse d'un hôte distant afin d'utiliser pasystray pour contrôler le serveur exécuté sur cet hôte.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux tirets (`-').

-V, --version
Affiche la version du programme.
-d, --debug
Affiche des informations de débogage.
-m, --volume-max=N
Définit le volume maximum (en pourcentage).
-i, --volume-inc=N
Définit l'incrément de volume.
-r, --reverse-scroll
Inverse la direction de l'ajustement du volume avec la molette de la souris.
-t, --no-icon-tooltip
Désactive l'infobulle de l'icône d'état pour l'état connecté.
-n, --no-notify
Désactive toutes les notifications. Obsolète ; utilisez --notify=none à la place.
-a, --always-notify
Active les notifications pour tous les changements dans pulseaudio. Obsolète ; utilisez --notify=all à la place.
--include-monitors
Affiche les sources de surveillance.
-g, --key-grabbing
Active le contrôle du volume via le clavier et les touches de sourdine pour ajuster les paramètres de volume.
-N, --notify=option
Définit les options de notification ; utilisez --notify=help pour une liste des options valides.

VOIR AUSSI

pulseaudio(1), pactl(1).
