DESCRIPTION

Les fonctions système PAPPL fournissent l'accès à l'objet système. Les systèmes sont créés et supprimés par l'application d'imprimante tandis que le cycle de vie de l'objet pappl_system_t est géré automatiquement pour l'application d'imprimante. La fonction papplSystemCreate crée un nouveau système tandis que la fonction papplSystemDelete supprime un système.

La fonction papplSystemRun démarre un système tandis que la fonction papplSystemShutdown arrête un système en cours d'exécution.

Les fonctions papplSystemGet récupèrent les valeurs actuelles associées à un système tandis que les fonctions papplSystemSet définissent les valeurs actuelles associées à un système.

papplSystemAddListeners

Ajoute des écouteurs de socket réseau ou de domaine.

bool  papplSystemAddListeners (
    pappl_system_t *system,
    const char *name
);

Cette fonction ajoute des écouteurs de socket. Le paramètre "name" spécifie l'adresse de l'écouteur. Les noms commençant par un slash (/) spécifient un chemin de socket de domaine UNIX, sinon le nom est traité comme un nom de domaine entièrement qualifié ou une adresse IPv4 ou IPv6 numérique. Si name est NULL, les adresses "any" sont utilisées ("0.0.0.0" et "[::]").

Les écouteurs ne peuvent pas être ajoutés après l'appel de papplSystemRun.

papplSystemAddMIMEFilter

Ajoute un filtre de fichier au système.

void papplSystemAddMIMEFilter (
    pappl_system_t *system,
    const char *srctype,
    const char *dsttype,
    pappl_mime_filter_cb_t cb,
    void *data
);

Cette fonction ajoute un filtre de fichier au système pour traiter différents types de données de document dans les travaux d'impression. Les arguments "srctype" et "dsttype" spécifient les types de médias MIME source et destination en tant que chaînes constantes. Un type de média MIME de destination de "image/pwg-raster" spécifie un filtre utilisant l'interface raster du pilote. D'autres types de destination impliquent une soumission directe au périphérique de sortie à l'aide des fonctions papplDeviceXxx.

papplSystemAddTimerCallback

Ajoute un rappel de minuteur à un système.

bool  papplSystemAddTimerCallback (
    pappl_system_t *system,
    time_t start,
    int interval,
    pappl_timer_cb_t cb,
    void *cb_data
);

Cette fonction planifie une fonction qui sera appelée sur le thread de la boucle principale d'exécution à l'heure spécifiée et éventuellement toutes les "interval" secondes par la suite. La précision du temps est généralement de quelques millisecondes mais n'est pas garantie. Étant donné que le rappel s'exécute sur le thread de la boucle principale d'exécution, les fonctions doivent créer un nouveau thread pour toute opération longue.

La fonction de rappel reçoit les pointeurs "system" et "cb_data" et renvoie true pour répéter le minuteur ou false pour le supprimer :

    bool my_timer_cb(pappl_system_t *system, void *cb_data)
    {
      ... faire la tâche périodique ...
      return (true); // répéter le minuteur
    }

papplSystemCreate

Crée un objet système.

pappl_system_t * papplSystemCreate (
    pappl_soptions_t options,
    const char *name,
    int port,
    const char *subtypes,
    const char *spooldir,
    const char *logfile,
    pappl_loglevel_t loglevel,
    const char *auth_service,
    bool tls_only
);

Cette fonction crée un nouvel objet système, qui est responsable de la gestion de toutes les imprimantes, travaux et ressources utilisés par l'application d'impression.

L'argument "options" spécifie quelles options sont activées pour le serveur :

  • PAPPL_SOPTIONS_NONE : Aucune option.
  • PAPPL_SOPTIONS_DNSSD_HOST : Lors de la résolution des collisions de noms de service DNS-SD,
    utilise le nom d'hôte DNS-SD au lieu d'un numéro de série ou d'un UUID.
  • PAPPL_SOPTIONS_WEB_LOG : Inclut la page Web du fichier journal.
  • PAPPL_SOPTIONS_MULTI_QUEUE : Prend en charge plusieurs imprimantes.
  • PAPPL_SOPTIONS_WEB_NETWORK : Inclut la page Web des paramètres réseau.
  • PAPPL_SOPTIONS_RAW_SOCKET : Accepte les travaux via des sockets bruts à partir du port
    9100 (tous sauf Windows).
  • PAPPL_SOPTIONS_WEB_REMOTE : Permet la gestion des files d'attente à distance.
  • PAPPL_SOPTIONS_WEB_SECURITY : Inclut la page Web des paramètres de sécurité.
  • PAPPL_SOPTIONS_WEB_INTERFACE : Inclut les pages Web standard de surveillance des imprimantes et des travaux
    .
  • PAPPL_SOPTIONS_WEB_TLS : Inclut la page des paramètres TLS.
  • PAPPL_SOPTIONS_USB_PRINTER : Accepte les travaux via USB pour l'imprimante par défaut
    (Linux embarqué uniquement).

L'argument "name" spécifie un nom lisible par l'homme pour le système.

L'argument "port" spécifie le numéro de port auquel se connecter. Une valeur de 0 entraînera l'attribution d'un numéro de port disponible lors de l'ajout du premier écouteur avec la fonction papplSystemAddListeners.

L'argument "subtypes" spécifie un ou plusieurs sous-types de service DNS-SD séparés par des virgules, tels que "_print" et "_universal".

L'argument "spooldir" spécifie l'emplacement des fichiers de travaux. Si NULL, un répertoire temporaire est créé.

L'argument "logfile" spécifie où envoyer les messages de journal. Si NULL, les messages de journal sont écrits dans un fichier temporaire.

L'argument "loglevel" spécifie le niveau de journalisation initial.

L'argument "auth_service" spécifie un nom de service d'authentification PAM. Si NULL, aucune authentification utilisateur ne sera fournie.

L'argument "tls_only" contrôle si l'application d'impression acceptera les connexions non chiffrées. En général, cet argument devrait toujours être false (autoriser les connexions non chiffrées) car tous les clients ne prennent pas en charge l'impression chiffrée.

papplSystemGetMaxLogSize

Obtient la taille maximale du fichier journal.

size_t  papplSystemGetMaxLogSize (
    pappl_system_t *system
);

Cette fonction obtient la taille maximale du fichier journal, qui n'est utilisée que lors de la journalisation directe dans un fichier. Lorsque la limite est atteinte, le fichier journal actuel est renommé en "filename.O" et un nouveau fichier journal est créé. Définissez la taille maximale sur 0 pour désactiver la rotation des fichiers journaux.

La taille maximale par défaut du fichier journal est de 1 Mio ou 1048576 octets.

papplSystemSetWiFiCallbacks


Définir les fonctions de rappel Wi-Fi.


void papplSystemSetWiFiCallbacks (
    pappl_system_t *system,
    pappl_wifi_join_cb_t join_cb,
    pappl_wifi_list_cb_t list_cb,
    pappl_wifi_status_cb_t status_cb,
    void *data
);


Cette fonction définit les fonctions de rappel de l'interface Wi-Fi 802.11 pour le système. La fonction join_cb est utilisée pour se connecter à un réseau Wi-Fi, la fonction list_cb est utilisée pour lister les réseaux disponibles, et la fonction status_cb est utilisée pour interroger l'état actuel de la connexion réseau Wi-Fi et le Secure Set Identifier (SSID). Les fonctions join_cb et status_cb sont utilisées pour prendre en charge l'obtention et la définition des attributs IPP "printer-wifi-state", "printer-wifi-ssid" et "printer-wifi-password", tandis que la fonction list_cb permet de changer le réseau Wi-Fi depuis l'interface web du réseau, si elle est activée.


Note : Les fonctions de rappel Wi-Fi ne peuvent être définies qu'avant d'appeler papplSystemRun.
