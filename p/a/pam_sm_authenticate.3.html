NOM

pam_sm_authenticate - fonction de service PAM pour l'authentification utilisateur

SYNTAXE

#include <security/pam_modules.h>

int pam_sm_authenticate(pam_handle_t *pamh, int flags, int argc, const char **argv);

DESCRIPTION

La fonction pam_sm_authenticate est l'implémentation du module de service de l'interface pam_authenticate(3).

Cette fonction effectue la tâche d'authentification de l'utilisateur.

Les indicateurs valides, qui peuvent être combinés logiquement avec PAM_SILENT, sont :

PAM_SILENT

Ne pas afficher de messages.

PAM_DISALLOW_NULL_AUTHTOK

Retourne PAM_AUTH_ERR si la base de données des jetons d'authentification pour ce mécanisme d'authentification contient une entrée NULL pour l'utilisateur. Sans cet indicateur, un tel jeton NULL conduira à un succès sans que l'utilisateur ne soit invité à entrer ses informations.

VALEURS DE RETOUR

PAM_AUTH_ERR

Échec de l'authentification.

PAM_CRED_INSUFFICIENT

Pour une raison quelconque, l'application ne dispose pas des informations d'identification suffisantes pour authentifier l'utilisateur.

PAM_AUTHINFO_UNAVAIL

Les modules n'ont pas pu accéder aux informations d'authentification. Cela peut être dû à une défaillance réseau ou matérielle, etc.

PAM_SUCCESS

Le jeton d'authentification a été mis à jour avec succès.

PAM_USER_UNKNOWN

Le nom d'utilisateur fourni n'est pas connu du service d'authentification.

PAM_MAXTRIES

Un ou plusieurs des modules d'authentification ont atteint leur limite d'essais pour authentifier l'utilisateur. N'essayez plus.

VOIR AUSSI
