NOM

passt-repair - Aide au réglage des options de socket TCP_REPAIR pour passt(1)

SYNTAXE

passt-repair CHEMIN

DESCRIPTION

passt-repair est une aide privilégiée qui définit et efface le mode de réparation sur les sockets TCP pour le compte de passt(1), selon les instructions reçues via des commandes d'un seul octet sur un socket de domaine UNIX.

Il peut être utilisé pour migrer des connexions TCP entre des invités sans accorder de capacités supplémentaires à passt(1) lui-même : pour migrer des connexions TCP, passt(1) utilise le mode de réparation, qui nécessite que la capacité CAP_NET_ADMIN (voir capabilities(7)) soit définie ou effacée.

Si CHEMIN représente un socket de domaine UNIX, passt-repair(1) tente de s'y connecter. S'il s'agit d'un répertoire, passt-repair(1) attend qu'un fichier se terminant par .repair apparaisse dedans, puis tente de s'y connecter.

PROTOCOLE

passt-repair(1) se connecte à passt(1) en utilisant le socket spécifié via l'option --repair-path dans passt(1) lui-même. Par défaut, le nom est le même que le socket de domaine UNIX utilisé pour la communication avec les invités, suffixé par .repair.

Les messages consistent en un entier signé de 8 bits qui peut être TCP_REPAIR_ON (1), TCP_REPAIR_OFF (0), ou TCP_REPAIR_OFF_NO_WP (-1), tels que définis par l'API utilisateur du noyau Linux, et de un à SCM_MAX_FD (253) sockets en tant que message auxiliaire SCM_RIGHTS (voir unix(7)), envoyé par le serveur, passt(1).

Le client, passt-repair(1), répond avec le même octet (et aucun message auxiliaire) pour indiquer le succès, et ferme la connexion en cas d'échec.

Le serveur ferme la connexion en cas d'erreur ou d'achèvement.

NOTES

passt-repair(1) peut se voir accorder la capacité CAP_NET_ADMIN (préférable, car cela limite les privilèges aux plus strictement nécessaires), ou il peut être exécuté en tant que root.
