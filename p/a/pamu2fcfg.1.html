Pamu2fcfg(1) Outil de configuration PAM U2F Pamu2fcfg(1)

NOM

pamu2fcfg - Outil de configuration pour le module PAM U2F.

SYNTAXE

pamu2fcfg [OPTION]...

DESCRIPTION

Effectue une procédure d'enregistrement FIDO2/U2F à l'aide d'un authentificateur connecté et produit une ligne de configuration qui peut être utilisée avec le module PAM U2F.

OPTIONS

-d, --debug

Imprime les informations de débogage (très verbeux)

-h, --help

Imprime l'aide et quitte

-o, --origin=CHAÎNE

Définit l'identifiant du parti de confiance FIDO2 à utiliser lors de l'enregistrement. Par défaut, pam://hostname. Avant pamu2fcfg v1.1.0, cela définissait l'URL d'origine U2F.

-i, --appid=CHAÎNE

Définit le nom du parti de confiance FIDO2 à utiliser lors de l'enregistrement. Par défaut, origin. Avant pamu2fcfg v1.1.0, cela définissait l'identifiant d'application U2F.

-r, --resident

Génère une clé résidente. Désactivé par défaut.

-t, --type=CHAÎNE

Type COSE à utiliser lors de l'enregistrement (ES256, EDDSA, ou RS256). Par défaut, ES256.

-P, --no-user-presence

Permet l'utilisation de la clé sans s'assurer de la présence de l'utilisateur. Désactivé par défaut.

-N, --pin-verification

Exige la vérification du PIN lors de l'authentification. Désactivé par défaut.

-V, --user-verification

Exige la vérification de l'utilisateur lors de l'authentification. Désactivé par défaut.

--version: Imprime la version et quitte

-u, --username=CHAÎNE

Le nom de l'utilisateur qui enregistre l'appareil. Par défaut, le nom d'utilisateur actuel.

-n, --nouser

Imprime uniquement les informations d'enregistrement (handle de clé, clé publique et options). Utile pour l'ajout.
