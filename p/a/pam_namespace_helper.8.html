NOM

pam_namespace_helper - Programme auxiliaire qui crée les répertoires personnels

SYNTAXE

pam_namespace_helper

DESCRIPTION

pam_namespace_helper est un programme auxiliaire pour le module pam_namespace qui configure un espace de noms privé pour une session avec des répertoires polyinstanciés. L'auxiliaire garantit que les points de montage de l'espace de noms existent avant qu'ils ne soient utilisés pour les répertoires polyinstanciés. Les points de montage pour les répertoires personnels (lignes avec $HOME) ne sont pas créés.

pam_namespace_helper doit être exécuté par systemd au démarrage du système. Il doit également être exécuté par l'administrateur après avoir défini les répertoires polyinstanciés, mais avant de les activer.
