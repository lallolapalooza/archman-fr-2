NOM

pam_strerror - renvoie une chaîne décrivant le code d'erreur PAM

SYNTAXE

#include <security/pam_appl.h>

const char *pam_strerror(pam_handle_t *pamh, int errnum);

DESCRIPTION

La fonction pam_strerror renvoie un pointeur vers une chaîne décrivant le code d'erreur passé dans l'argument errnum, en utilisant éventuellement la partie LC_MESSAGES de la locale actuelle pour sélectionner la langue appropriée. Cette chaîne ne doit pas être modifiée par l'application. Aucune fonction de la bibliothèque ne modifiera cette chaîne.

VALEURS DE RETOUR

Cette fonction renvoie toujours un pointeur vers une chaîne.
