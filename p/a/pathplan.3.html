Paquet: graphviz

Licences: EPL

LIBPATH(3) Manuel des fonctions de bibliothèque LIBPATH(3)

NOM

libpathplan - trouve et lisse les chemins les plus courts

SYNTAXE

#include <graphviz/pathplan.h>
typedef struct Pxy_t {
    double x, y;
} Pxy_t;
typedef struct Pxy_t Ppoint_t;
typedef struct Pxy_t Pvector_t;
typedef struct Ppoly_t {
    Ppoint_t *ps;
    int pn;
} Ppoly_t;
typedef Ppoly_t Ppolyline_t;
typedef struct Pedge_t {
    Ppoint_t a, b;
} Pedge_t;
typedef struct vconfig_s vconfig_t;
#define POLYID_NONE	
#define POLYID_UNKNOWN
int Pshortestpath(Ppoly_t *boundary, Ppoint_t endpoints[2], Ppolyline_t *output_route);
vconfig_t *Pobsopen(Ppoly_t **obstacles, int n_obstacles);
int Pobspath(vconfig_t *config, Ppoint_t p0, int poly0, Ppoint_t p1, int poly1, Ppolyline_t *output_route);
void Pobsclose(vconfig_t *config);
int Proutespline (Pedge_t *barriers, int n_barriers, Ppolyline_t input_route, Pvector_t endpoint_slopes[2],
	Ppolyline_t *output_route);
int Ppolybarriers(Ppoly_t **polys, int n_polys, Pedge_t **barriers, int *n_barriers);

DESCRIPTION

libpathplan fournit des fonctions pour créer des chemins splines dans le plan qui sont contraints par une frontière polygonale ou des obstacles à éviter. Tous les polygones doivent être simples, mais pas nécessairement convexes.

int Pshortestpath(Ppoly_t *boundary, Ppoint_t endpoints[2], Ppolyline_t *output_route);

La fonction Pshortestpath trouve un chemin le plus court entre deux points dans un polygone simple. Le polygone est spécifié par une liste de ses sommets, dans l'ordre des aiguilles d'une montre ou dans le sens inverse. Vous passez des points terminaux à l'intérieur de la frontière polygonale. Un chemin le plus court reliant les points et restant dans le polygone est renvoyé dans output_route. Si l'un des points terminaux ne se trouve pas dans le polygone, -1 est renvoyé ; sinon, 0 est renvoyé en cas de succès. Le tableau de points dans output_route est statique à la bibliothèque. Il ne doit pas être libéré et doit être utilisé avant un autre appel à Pshortestpath.

vconfig_t *Pobsopen(Ppoly_t **obstacles, int n_obstacles);

Pobspath(vconfig_t *config, Ppoint_t p0, int poly0, Ppoint_t p1, int poly1, Ppolyline_t *output_route);

void Pobsclose(vconfig_t *config);

Ces fonctions trouvent un chemin le plus court entre deux points dans le plan qui contient des obstacles polygonaux (trous). Pobsopen crée une configuration (une structure opaque de type vconfig_t) sur un ensemble d'obstacles. Les n_obstacles obstacles sont donnés dans le tableau obstacles ; les points de chaque polygone doivent être dans l'ordre des aiguilles d'une montre. La fonction Pobsclose libère les données allouées dans Pobsopen.

Pobspath trouve un chemin le plus court entre les points terminaux qui reste à l'extérieur des obstacles. Si les points terminaux sont connus pour se trouver à l'intérieur d'obstacles, poly0 ou poly1 doit être défini sur l'indice dans le tableau obstacles. Si un point terminal n'est certainement pas à l'intérieur d'un obstacle, alors POLYID_NONE doit être passé. Si l'appelant n'a pas vérifié, alors POLYID_UNKNOWN doit être passé, et la bibliothèque de chemin effectuera le test. Le chemin le plus court résultant est renvoyé dans output_route. Notez que cette fonction ne fournit pas de frontière polygonale. Le tableau de points stockés dans output_route est alloué par la bibliothèque, mais doit être libéré par l'utilisateur.

int Proutespline (Pedge_t *barriers, int n_barriers, Ppolyline_t input_route, Pvector_t endpoint_slopes[2], Ppolyline_t *output_route);

Cette fonction ajuste une courbe B-spline cubique à un chemin polyligne. La courbe est construite pour éviter un ensemble de n_barriers segments de droite barrières spécifiés dans le tableau barriers. Si vous partez d'obstacles polygonaux, vous pouvez fournir les arêtes de chaque polygone comme partie de la liste des barrières. La polyligne input_route fournit un modèle pour le chemin final ; c'est généralement le output_route de l'un des localisateurs de chemin le plus court, mais cela peut être n'importe quel chemin simple qui ne croise aucun segment de barrière. L'entrée permet également de spécifier les pentes souhaitées aux points terminaux via endpoint_slopes. Celles-ci sont spécifiées comme des vecteurs. Par exemple, pour avoir un angle de T à un point terminal, on pourrait utiliser (cos(T),sin(T)). Un vecteur (0,0) signifie une pente non contrainte. La sortie est renvoyée dans output_route et consiste en les points de contrôle de la B-spline. La fonction renvoie 0 en cas de succès ; une valeur de retour de -1 indique un échec. Le tableau de points dans output_route est statique à la bibliothèque. Il ne doit pas être libéré et doit être utilisé avant un autre appel à Proutespline.

int Ppolybarriers(Ppoly_t **polys, int n_polys, Pedge_t **barriers, int *n_barriers);

Il s'agit d'une fonction utilitaire qui convertit une liste d'entrée de polygones en une liste de sortie de segments de barrières. Le tableau de points dans barriers est statique à la bibliothèque. Il ne doit pas être libéré et doit être utilisé avant un autre appel à Ppolybarriers. La fonction renvoie 1 en cas de succès.

BOGUES

La fonction Proutespline ne garantit pas qu'elle préservera la topologie du chemin d'entrée par rapport aux frontières. Par exemple, si certains segments correspondent à un petit polygone, il est possible que le chemin final ait basculé par-dessus l'obstacle.
