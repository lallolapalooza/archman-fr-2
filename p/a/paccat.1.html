NOM

paccat - Afficher les fichiers des paquets pacman

SYNTAXE

paccat [options] <cible> <fichiers>
paccat [options] [cibles] -- <fichiers>
paccat [options] -<Q|F> <fichiers>
paccat [options] <-Q|-F> [cibles] -- <fichiers>

une cible peut être spécifiée comme :
<nomdepaquets>, <dépôt>/<nomdepaquet>, <url> ou <fichier>.

les fichiers peuvent être spécifiés par leur nom seul ou leur chemin complet.

DESCRIPTION

Afficher les fichiers des paquets pacman.

paccat affiche les fichiers des paquets indépendamment de votre système en téléchargeant les paquets nécessaires et en extrayant les fichiers requis.

COLORATION SYNTAXIQUE

paccat utilisera bat pour la coloration syntaxique si celui-ci est installé.

OPTIONS

-F, --files
Utiliser la base de données des fichiers pour rechercher les fichiers avant le téléchargement.
-Q, --query
Utiliser la base de données locale pour rechercher les fichiers avant le téléchargement.
-r, --root <chemin>
Définir un répertoire racine alternatif.
-b, --dbpath <chemin>
Définir un emplacement de base de données alternatif.
--config <fichier>
Utiliser un pacman.conf alternatif.
--color <quand>
Spécifier quand activer la coloration. Les options valides sont toujours, jamais, ou auto.
-y, --refresh
Télécharger les bases de données de paquets fraîches depuis le serveur. Passer deux fois pour forcer le téléchargement même si les bases de données sont à jour.
--cachedir <chemin>
Définir le répertoire de cache principal.

Ce répertoire sera le répertoire préféré pour le téléchargement des paquets s'il est accessible en écriture. Les autres répertoires configurés seront toujours utilisés pour la lecture.

-a, --all
afficher tous les fichiers correspondants au lieu d'un seul.
-x, --regex
Activer la recherche à l'aide d'expressions régulières.
--binary
Afficher les fichiers binaires.
-X, --executable
Filtrer les résultats pour n'afficher que les fichiers exécutables.
-e, --extract
Extraire les fichiers correspondants dans le répertoire courant.
-l, --list
Afficher les noms de fichiers au lieu du contenu des fichiers.
-i, --install
Installer les fichiers correspondants sur le système.
--debug
Afficher les messages de débogage.
-h, --help
Afficher les informations d'aide.
-V, --version
Afficher les informations de version.

EXEMPLES

paccat grub etc/default/grub
Afficher le contenu de 'etc/default/grub' à partir du paquet grub.
paccat pacman pacman.conf
Afficher le contenu du premier fichier nommé 'pacman.conf' du paquet pacman.
paccat -F pacman.conf
Afficher le contenu du premier fichier nommé 'pacman.conf' dans les dépôts.
paccat -x pacman mkinitcpio -- '.conf$'
Afficher le contenu de tous les fichiers se terminant par '.conf' des paquets pacman et mkinitcpio.
paccat ~/pkgs/my-pkg-1.0.0-1.pkg.tar.zst myfile
Afficher le contenu de 'myfile' à partir d'une archive de paquet.
paccat https://archlinux.org/packages/extra/x86_64/git/download git-blame.1.gz
Télécharger et afficher le contenu de 'git-blame.1.gz' du paquet git.
