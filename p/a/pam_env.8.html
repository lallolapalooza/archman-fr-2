NOM

pam_env - Module PAM pour définir/supprimer des variables d'environnement

SYNTAXE

pam_env.so [debug] [conffile=fichier-conf] [envfile=fichier-env] [readenv=0|1] [user_envfile=fichier-env] [user_readenv=0|1]

DESCRIPTION

Le module PAM pam_env permet de définir/supprimer des variables d'environnement. Il prend en charge l'utilisation de variables d'environnement précédemment définies ainsi que des éléments PAM tels que PAM_RHOST.

Par défaut, les règles de définition/suppression de variables sont tirées du fichier de configuration /etc/security/pam_env.conf. Un fichier alternatif peut être spécifié avec l'option conffile.

Ensuite, un fichier (/etc/environment par défaut) avec des paires simples CLÉ=VALEUR sur des lignes séparées sera lu. Avec l'option envfile, un fichier alternatif peut être spécifié. Et avec l'option readenv, cela peut être complètement désactivé.

Enfin, il lira un fichier de configuration utilisateur ($HOME/.pam_environment par défaut). Le fichier par défaut peut être modifié avec l'option user_envfile et activé ou désactivé avec l'option user_readenv.

Étant donné que la définition de variables d'environnement PAM peut avoir des effets secondaires sur d'autres modules, ce module doit être le dernier de la pile.

Ce module n'est exécuté que si l'application principale appelle pam_setcred(3) ou pam_open_session(3). Le module ne fait rien et renvoie PAM_IGNORE s'il est appelé par pam_authenticate(3).

OPTIONS

conffile=/chemin/vers/pam_env.conf

Indique un fichier de configuration de style pam_env.conf alternatif pour remplacer le défaut. Ceci peut être utile lorsque différents services nécessitent des environnements différents.

debug

Beaucoup d'informations de débogage sont affichées avec syslog(3).

envfile=/chemin/vers/environment

Indique un fichier d'environnement alternatif pour remplacer le défaut. La syntaxe est de simples paires CLÉ=VALEUR sur des lignes séparées. L'instruction export peut être spécifiée pour la compatibilité bash, mais sera ignorée. Ceci peut être utile lorsque différents services nécessitent des environnements différents.

readenv=0|1

Active ou désactive la lecture du fichier spécifié par envfile (0 est désactivé, 1 est activé). Par défaut, cette option est activée.

user_envfile=nom_fichier

Indique un fichier .pam_environment alternatif pour remplacer le défaut. La syntaxe est la même que pour /etc/security/pam_env.conf. Le nom du fichier est relatif au répertoire personnel de l'utilisateur. Ceci peut être utile lorsque différents services nécessitent des environnements différents.

user_readenv=0|1

Active ou désactive la lecture du fichier d'environnement spécifique à l'utilisateur. 0 est désactivé, 1 est activé. Par défaut, cette option est désactivée car les variables d'environnement fournies par l'utilisateur dans l'environnement PAM pourraient affecter le comportement des modules suivants dans la pile sans le consentement de l'administrateur système.

En raison de problèmes de sécurité, cette fonctionnalité est obsolète depuis la version 1.5.0 et sera complètement supprimée à un moment donné dans le futur.

TYPES DE MODULES FOURNIS

Les types de modules auth et session sont fournis.

VALEURS DE RETOUR

PAM_ABORT

Toutes les données ou options pertinentes n'ont pas pu être obtenues.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_IGNORE

Aucun fichier pam_env.conf et fichier d'environnement n'a été trouvé ou le module a été appelé par pam_authenticate(3).

PAM_SUCCESS

Les variables d'environnement ont été définies.

FICHIERS

/etc/security/pam_env.conf

Fichier de configuration par défaut

/etc/environment

Fichier d'environnement par défaut

$HOME/.pam_environment

Fichier d'environnement spécifique à l'utilisateur
