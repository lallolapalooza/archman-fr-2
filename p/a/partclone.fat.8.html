PARTCLONE(8) Manuel utilisateur Partclone PARTCLONE(8)

NOM

partclone - L'utilitaire pour cloner et restaurer une partition.

SYNTAXE

partclone.[type_fs] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] cible} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] journal_log [-R | --rescue] [-L | --logfile] journal_log [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPTION

partclone.[type_fs] fait partie du projet Partclone. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une plus grande compatibilité du système de fichiers en utilisant des bibliothèques existantes, par exemple, e2fslibs est utilisé pour lire les blocs utilisés de la partition ext2.

Les systèmes de fichiers pris en charge par Partclone incluent btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Il prend également en charge certains systèmes d'exploitation non-linux, par ex. NTFS, FAT et EXFAT (pour Windows), HFS plus (MAC OS APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) et MINIX (MINIX3).

Tous les utilitaires partclone peuvent être exécutés comme partclone.[type_fs], très similaires à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, il suffit d'exécuter partclone.hfsp

       Système de fichiers           partclone.[type_fs]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       autres (FS non pris en charge) partclone.imager

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-s FICHIER, --source FICHIER

FICHIER source. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique, selon votre action. Normalement, la source de sauvegarde est un périphérique, la source de restauration est un fichier image.

La réception de données depuis un pipeline n'est prise en charge QUE pour la restauration, ignorez l'option -s ou utilisez '-' pour recevoir des données depuis stdin.

-o FICHIER, --output FICHIER

FICHIER de sortie. Le FICHIER peut être un fichier image (que partclone générera) ou un périphérique, selon votre action. Normalement, la sortie de sauvegarde va vers un fichier image et la sortie de restauration va vers un périphérique.

L'envoi de données vers un pipeline est également pris en charge SEULEMENT pour la sauvegarde, ignorez l'option -o ou utilisez '-' pour envoyer des données vers stdout.

-O FICHIER, --overwrite FICHIER

Écrase FICHIER, s'il existe déjà.

-W FICHIER, --restore_raw_file FICHIER

Crée un fichier brut spécial pour le périphérique de boucle.

-c, --clone

Sauvegarde la partition dans le format d'image spécial.

-r, --restore

Restaure la partition à partir du format d'image spécial.

-b, --dev-to-dev

Copie locale de périphérique à périphérique à la volée, la source et la sortie sont toutes deux des périphériques.

-D, --domain

Crée un fichier journal de domaine GNU Ddrescue à partir du périphérique source. Il s'agit d'un fichier lisible par l'homme dans lequel + marque les zones de blocs utilisées et ? marque les zones libres.

--offset_domain=X

Ajoute X (en octets) à toutes les positions signalées dans le fichier journal de domaine

--restore_raw_file

Création d'un fichier brut spécial pour le périphérique de boucle.

-L FICHIER, --logfile FICHIER

Spécifie le chemin pour enregistrer les informations du journal partclone. (par défaut /var/log/partclone.log)

-R, --rescue

Continue après les erreurs de lecture du disque.

-C, --no_check

Ne pas vérifier la taille du périphérique et l'espace libre.

-N, --ncurses

Utilise une interface utilisateur textuelle Ncurses.

-I, --ignore_fschk

Ignore la vérification du système de fichiers.

-i, --ignore_crc

Ignore l'erreur de vérification crc.

-F, --force

Force le déroulement.

-f sec, --UI-fresh sec

Spécifie l'intervalle (en secondes) pour l'actualisation de l'interface utilisateur.

-z taille, --buffer_size taille

Taille du tampon de lecture/écriture (par défaut : 1048576)

-q, --quiet

Désactive les messages de progression.

-dniveau, --debug niveau

Définit le niveau de débogage [1|2|3]

-x, --compresscmd CMD

Démarre CMD comme un pipeline de sortie pour compresser l'image clonée

-aX, --checksum-mode=X

Formule de somme de contrôle à utiliser pour ajouter la détection d'erreurs

où X :

0 : Pas de somme de contrôle (pas de ralentissement, image la plus petite)

1 : CRC32 (Rapide à calculer, détection basique)

2 : xxHash, algorithme de hachage non cryptographique extrêmement rapide

-kX, --blocks-per-checksum=X

Écrit une somme de contrôle tous les X blocs

-w, --skip_write_error

Continue la restauration en cas d'erreurs d'écriture

--write-direct-io

Écrit les données sur la partition CIBLE sans cache

--read-direct-io

Lit les données depuis la partition SOURCE sans cache

-B, --no_block_detail

Affiche le message de progression sans détail des blocs

--binary-prefix

Affiche la progression avec la taille en bits (par défaut Mo, Go...)

--prog-second

Affiche la progression en secondes (par défaut minutes)

-E, --offset=X

Ajoute un décalage X (octets) à la SORTIE

-T, --btfiles

Restaure le bloc comme fichier pour ClonezillaBT.

-t, --btfiles_torrent

Restaure le bloc comme fichier pour ClonezillaBT mais ne génère que le torrent.

-n, --note NOTE

Affiche un message NOTE (128 mots).

-h, --help

Affiche un résumé des options.

-v, --version

Affiche la version

NAME

partclone.fat

clone FAT filesystem

SYNOPSIS

partclone.fat [-c|-r] [-s source] [-o output] [-N] [-b] [-v] [-C] [-d] [-q] [-P] [-Z partition]

DESCRIPTION

partclone.fat is a tool that allows you to clone or restore a FAT filesystem. It is part of the partclone suite of tools, designed for efficient disk imaging and cloning.

It supports the FAT12, FAT16, and FAT32 filesystem types.

OPTIONS

-c, --clone
Clone the specified source filesystem to the output file or device.
-r, --restore
Restore the filesystem from the source file or device to the output filesystem.
-s, --source source
Specify the source file or device. Use '-' for standard input.
-o, --output output
Specify the output file or device. Use '-' for standard output.
-N, --no-create-dir
Do not create directories automatically.
-b, --block-size size
Set the block size for operations.
-v, --verbose
Enable verbose output.
-C, --checksum
Calculate and verify checksums.
-d, --debug
Enable debug messages.
-q, --quiet
Suppress non-essential output.
-P, --progressbar
Show a progress bar during the operation.
-Z, --partition partition
Specify the partition number to operate on (useful when cloning/restoring from/to a disk image containing multiple partitions).

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 Clone the FAT filesystem on /dev/sda1 to an image file sda1.fat.img.
   partclone.fat -c -s /dev/sda1 -o sda1.fat.img

 Restore the FAT filesystem from sda1.fat.img to /dev/sda1.
   partclone.fat -r -s sda1.fat.img -o /dev/sda1

 Clone the FAT filesystem from /dev/hda1, showing verbose output and progress bar.
   partclone.fat -c -v -P -s /dev/hda1 -o hda1.fat.img

 Restore a FAT filesystem from a gzipped image file using stdin.
   cat sda1.fat.img.gz | gunzip -c | partclone.fat -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
