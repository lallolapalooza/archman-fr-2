PARTX(8) Administration système PARTX(8)

NOM

partx - informer le noyau de la présence et de la numérotation des partitions sur disque

SYNTAXE

partx [-a|-d|-P|-r|-s|-u] [-t type] [-n M:_N_] [-] disk

partx [-a|-d|-P|-r|-s|-u] [-t type] partition [disk]

DESCRIPTION

À partir d'un périphérique ou d'une image disque, partx essaie d'analyser la table de partitions et de lister son contenu. Il peut aussi demander au noyau d'ajouter ou de supprimer des partitions de sa gestion interne.

L'argument disk est optionnel lorsqu'un argument partition est fourni. Pour forcer l'analyse d'une partition comme s'il s'agissait d'un disque entier (par exemple pour lister des sous-partitions imbriquées), utilisez l'argument "-" (tiret). Par exemple:

partx --show - /dev/sda3

Ceci traitera sda3 comme un disque entier plutôt que comme une partition.

partx n'est pas un programme fdisk - ajouter et supprimer des partitions ne modifie pas le disque, cela indique simplement au noyau la présence et la numérotation des partitions sur le disque.

OPTIONS

-a, --add

Ajoute les partitions spécifiées, ou lit le disque et ajoute toutes les partitions.

-b, --bytes

Affiche les tailles en octets plutôt que dans un format lisible par l'homme.

Par défaut, l'unité dans laquelle les tailles sont exprimées est l'octet, et les préfixes d'unité sont en puissance de 2^10 (1024). Les abréviations des symboles sont présentées tronquées afin d'atteindre une meilleure lisibilité, en présentant seul la première lettre d'entre eux ; exemples : "1 Kio" et "1 Mio" sont respectivement présentés comme "1 K" et "1 M", omettant ainsi volontairement la mention "io", qui fait partie de ces abréviations.

-d, --delete

Supprime les partitions spécifiées ou toutes les partitions. Ce n'est pas une erreur de supprimer des partitions inexistantes, donc cette option peut être utilisée ensemble avec de larges plages --nr sans se soucier de l'ensemble actuel des partitions sur le périphérique.

-g, --noheadings

N'affiche pas de ligne d'en-tête avec --show ou --raw.

-l, --list

Liste les partitions. Notez que tous les nombres sont en secteurs de 512 octets. Ce format de sortie est DÉPRÉCIÉ au profit de --show. Ne l'utilisez pas dans de nouveaux scripts.

-n, --nr M:N

Spécifie la plage de partitions. Pour la compatibilité descendante, le format M-N est également supporté. La plage peut contenir des nombres négatifs, par exemple --nr -1:-1 signifie la dernière partition, et --nr -2:-1 signifie les deux dernières partitions. Les spécifications de plage supportées sont :

M

Spécifie une seule partition (par exemple, --nr 3).

M:

Spécifie uniquement la limite inférieure (par exemple, --nr 2:).

:N

Spécifie uniquement la limite supérieure (par exemple, --nr :4).

M:N

Spécifie les limites inférieure et supérieure (par exemple, --nr 2:4).

-o, --output liste

Définit les colonnes de sortie à utiliser pour les sorties --show, --pairs et --raw. Si aucun arrangement de sortie n'est spécifié, alors un ensemble par défaut est utilisé. Utilisez --help pour obtenir la liste de toutes les colonnes supportées. Cette option ne peut pas être combinée avec les options --add, --delete, --update ou --list.

--output-all

Affiche toutes les colonnes disponibles.

-P, --pairs

Liste les partitions au format CLÉ="valeur".

-r, --raw

Liste les partitions en utilisant le format de sortie brut.

-s, --show

Liste les partitions. Les colonnes de sortie peuvent être sélectionnées et réorganisées avec l'option --output. Tous les nombres (sauf SIZE) sont en secteurs de 512 octets.

-t, --type type

Spécifie le type de table de partitions.

--list-types

Liste les types de partitions supportés et quitte.

-u, --update

Met à jour les partitions spécifiées.

-S, --sector-size taille

Remplace la taille de secteur par défaut.

-v, --verbose

Mode verbeux.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

ENVIRONNEMENT

LIBBLKID_DEBUG=all

active la sortie de débogage de libblkid.

EXEMPLE

partx --show /dev/sdb3, partx --show --nr 3 /dev/sdb, partx --show /dev/sdb3 /dev/sdb

Ces trois commandes listent la partition 3 de /dev/sdb.

partx --show - /dev/sdb3

Liste toutes les sous-partitions sur /dev/sdb3 (le périphérique est utilisé comme disque entier).

partx -o START -g --nr 5 /dev/sdb

Affiche le secteur de début de la partition 5 sur /dev/sdb sans en-tête.

partx -o SECTORS,SIZE /dev/sda5 /dev/sda

Liste la longueur en secteurs et la taille lisible par l'homme de la partition 5 sur /dev/sda.

partx --add --nr 3:5 /dev/sdd

Ajoute toutes les partitions disponibles de 3 à 5 (inclus) sur /dev/sdd.

partx -d --nr -1: /dev/sdd

Supprime la dernière partition sur /dev/sdd.

partx(8)

NOM

partx - Partition table information.

SYNTAXE

partx [options] device

DESCRIPTION

The partx command is used to report partition information for a partition device.

OPTIONS

-a, --show
Show partition information.
-s, --show-gpt
Show partition information in GPT format.
-g, --show-mbr
Show partition information in MBR format.
-l, --list
List partition information.
-o, --output list
Specify the output format.
-r, --raw
Output in a raw format.
-h, --help
Display help text and exit.
-v, --version
Display version information and exit.

ENVIRONNEMENT

None.

EXEMPLE

partx /dev/sda

partx -a /dev/sda

AUTEURS

Written by Anton Blanchard.

VOIR AUSSI

fdisk(8), gdisk(8), parted(8)
