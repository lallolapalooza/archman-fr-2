PASSMASS(1) Manuel des commandes générales PASSMASS(1)

NOM

passmass - changer le mot de passe sur plusieurs machines

SYNTAXE

passmass [ hote1 hote2 hote3 ... ]

INTRODUCTION

Passmass change un mot de passe sur plusieurs machines. Si vous avez des comptes sur plusieurs machines qui ne partagent pas de bases de données de mots de passe, Passmass peut vous aider à les maintenir tous synchronisés. Cela, à son tour, facilitera leur changement plus fréquent.

Lorsque Passmass s'exécute, il vous demande l'ancien et le nouveau mot de passe. (Si vous changez les mots de passe root et que vous avez l'équivalence, l'ancien mot de passe n'est pas utilisé et peut être omis.)

Passmass comprend les conventions "usuelles". Des arguments supplémentaires peuvent être utilisés pour l'ajustement. Ils affectent tous les hôtes qui suivent jusqu'à ce qu'un autre argument le remplace. Par exemple, si vous êtes connu sous le nom de "libes" sur les hôtes host1 et host2, mais "don" sur host3, vous diriez :

passmass host1 host2 -user don host3

Les arguments sont :

-utilisateur
Utilisateur dont le mot de passe sera changé. Par défaut, l'utilisateur actuel est utilisé.
-rlogin
Utiliser rlogin pour accéder à l'hôte. (par défaut)
-slogin
Utiliser slogin pour accéder à l'hôte.
-ssh
Utiliser ssh pour accéder à l'hôte.
-telnet
Utiliser telnet pour accéder à l'hôte.
-programme

L'argument suivant est un programme à exécuter pour définir le mot de passe. Par défaut, c'est "passwd". D'autres choix courants sont "yppasswd" et "set passwd" (par exemple, les hôtes VMS). Un nom de programme tel que "password fred" peut être utilisé pour créer des entrées pour de nouveaux comptes (lorsqu'il est exécuté en tant que root).

-invite
L'argument suivant est un modèle de suffixe d'invite. Cela permet au script de savoir quand le shell affiche une invite. Le défaut est "# " pour root et "% " pour les comptes non-root.
-delai
L'argument suivant est le nombre de secondes à attendre les réponses. Le défaut est 30, mais certains systèmes peuvent être beaucoup plus lents à se connecter.
-su

L'argument suivant est 1 ou 0. Si 1, vous êtes également invité à entrer un mot de passe root qui est utilisé pour faire un `su` après la connexion. C'est le mot de passe de root qui est changé plutôt que celui de l'utilisateur. Ceci est utile pour les hôtes qui ne permettent pas à root de se connecter.

MODE D'EMPLOI

La meilleure façon d'exécuter Passmass est de placer la commande dans un script shell en une seule ligne ou un alias. Chaque fois que vous obtenez un nouveau compte sur une nouvelle machine, ajoutez les arguments appropriés à la commande. Ensuite, exécutez-la chaque fois que vous souhaitez changer vos mots de passe sur tous les hôtes.

MISES EN GARDE

Utiliser le même mot de passe sur plusieurs hôtes comporte des risques. En particulier, si le mot de passe peut être volé, alors tous vos comptes sont menacés. Ainsi, vous ne devriez pas utiliser Passmass dans des situations où votre mot de passe est visible, comme sur un réseau dont les hackers sont connus pour écouter.

D'un autre côté, si vous avez suffisamment de comptes avec des mots de passe différents, vous pourriez finir par les écrire quelque part - et *cela* peut être un problème de sécurité. Histoire drôle : mon colocataire de collège avait une feuille de papier de 11x13 pouces sur laquelle il avait listé les comptes et les mots de passe sur tout Internet. Cela représentait plusieurs années de travail minutieux et il la transportait partout avec lui. Un jour, il a oublié de l'enlever de son jean, et nous avons trouvé une feuille de papier parfaitement vierge lorsque nous avons fait la lessive le lendemain !"
