NOM

pam_misc_paste_env - transcription d'un environnement vers celui de PAM

SYNTAXE

#include <security/pam_misc.h>

int pam_misc_paste_env(pam_handle_t *pamh, const char * const *user);

DESCRIPTION

Cette fonction prend la liste fournie de pointeurs d'environnement et en importe le contenu dans l'environnement PAM. Le succès est indiqué par PAM_SUCCESS.

VOIR AUSSI

pam_putenv(3), pam(8)

STANDARDS

La fonction pam_misc_paste_env fait partie de la bibliothèque libpam_misc et n'est définie dans aucun standard.
