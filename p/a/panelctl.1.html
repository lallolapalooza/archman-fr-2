PANELCTL(1) Commandes utilisateur PANELCTL(1)

NOM

panelctl - page de manuel pour panelctl 0.2

SYNTAXE

panelctl [OPTION...] <canal|commande>

DESCRIPTION

AV/C panelctl - changer de canal sur, ou émettre des commandes à, un périphérique AV firewire

-c, --commandes
Afficher la liste des commandes (nécessite un argument factice)
-d, --debug
Mode debug
-g, --guid=GUID
Spécifier le GUID du STB à contrôler

-n, --swversion=VERSION_LOGICIELLE Spécifier la version logicielle du STB

-s, --specid=ID_SPEC
Spécifier l'ID_SPEC du STB à contrôler
-v, --verbeux
Produire une sortie verbeuse
-?, --aide
Donner cette liste d'aide
--usage
Donner un bref message d'utilisation
-V, --version
Afficher la version du programme

Les arguments obligatoires ou optionnels des options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.

Ce programme est principalement utile pour un tuner firewire ou un décodeur avec une interface AV. Utilisez-le pour émettre une commande (panelctl <commande>) ou pour changer de chaîne sur le tuner (panelctl <canal>). Pour obtenir une liste des commandes valides, utilisez le commutateur --commandes.

Par défaut, panelctl contrôlera le premier STB Motorola sur la chaîne firewire. Cela ne fonctionnera qu'avec certains STB Motorola. Pour contrôler tout autre STB, ou pour contrôler plusieurs STB, spécifiez le GUID ou à la fois l'ID_SPEC et la version logicielle du STB désiré. Cela peut être découvert en exécutant "panelctl -v -g 1 1". Comme il n'y aura pas de STB avec le GUID 1, il parcourra tous les périphériques possibles et affichera les informations pour chacun d'eux. Une fois que le GUID, ou l'ID_SPEC et la version logicielle du périphérique désiré auront été appris, ils pourront être utilisés dans les commandes suivantes, par ex. "panelctl -g 0x123456 666". Généralement, il sera préférable d'utiliser le GUID, car il sera unique à chaque STB.
