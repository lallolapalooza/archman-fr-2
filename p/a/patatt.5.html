NOM

PATATT - Attestation cryptographique de correctifs, similaire à DKIM

SYNTAXE

patatt {sign,validate,genkey,install-hook} [options]

DESCRIPTION

Cet outil permet de signer cryptographiquement les correctifs envoyés par e-mail en utilisant des en-têtes de message similaires à DKIM. Cette approche est à la fois efficace et n'interfère pas avec d'autres outils de revue de code, contrairement aux signatures PGP en ligne ou détachées. Pour un aperçu complet des concepts clés et des considérations, veuillez consulter le README.

Si vous avez déjà une clé PGP configurée pour signer les tags ou les commits git, alors vous devriez être en mesure d'utiliser patatt sans configuration supplémentaire. Essayez d'exécuter la commande suivante dans n'importe quel dépôt git :

git format-patch -1 --stdout | patatt sign

Si patatt ne trouve pas votre clé PGP, essayez d'ajouter ce qui suit à votre fichier ~/.gitconfig :

[user]
    signingkey = [votre-id-cle]

Pour trouver votre id de clé, exécutez gpg --list-secret-keys. Si vous souhaitez utiliser une sous-clé spécifique, vous pouvez spécifier l'ID de la sous-clé avec un ! à la fin.

UTILISATION COMME HOOK GIT

Si vous utilisez git-send-email pour envoyer des correctifs, vous pouvez les faire signer automatiquement via le hook sendemail-validate. Pour l'installer, exécutez la commande suivante dans le dépôt pour lequel vous souhaitez activer la signature :

$ patatt install-hook

Ou vous pouvez l'installer manuellement :

$ echo 'patatt sign --hook "${1}"' >> .git/hooks/sendemail-validate
$ chmod a+x .git/hooks/sendemail-validate

SOUS-COMMANDES

  • sign: signe l'entrée standard ou les fichiers RFC2822 passés en arguments
  • validate: validation de base pour les messages signés
  • genkey: génère une nouvelle paire de clés ed25519
  • install-hook: installe le hook sendemail-validate dans le dépôt actuel

Vous pouvez exécuter patatt [sous-commande] --help pour voir un résumé des options pour chaque sous-commande.
