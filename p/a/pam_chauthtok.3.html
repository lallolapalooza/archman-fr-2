NOM

pam_chauthtok - mise à jour des jetons d'authentification

SYNTAXE

#include <security/pam_appl.h>

int pam_chauthtok(pam_handle_t *pamh, int flags);

DESCRIPTION

La fonction pam_chauthtok est utilisée pour changer le jeton d'authentification d'un utilisateur donné (tel qu'indiqué par l'état associé au handle pamh).

L'argument pamh est un handle d'authentification obtenu par un appel antérieur à pam_start(). L'argument flags est le résultat d'un OU binaire de zéro ou plusieurs des valeurs suivantes :

PAM_SILENT

Ne pas émettre de messages.

PAM_CHANGE_EXPIRED_AUTHTOK

Cet argument indique aux modules que le jeton d'authentification de l'utilisateur (mot de passe) ne doit être changé que s'il a expiré. Si cet argument n'est pas passé, l'application exige que tous les jetons d'authentification soient changés.

VALEURS DE RETOUR

PAM_AUTHTOK_ERR

Un module n'a pas pu obtenir le nouveau jeton d'authentification.

PAM_AUTHTOK_RECOVERY_ERR

Un module n'a pas pu obtenir l'ancien jeton d'authentification.

PAM_AUTHTOK_LOCK_BUSY

Un ou plusieurs modules n'ont pas pu changer le jeton d'authentification car il est actuellement verrouillé.

PAM_AUTHTOK_DISABLE_AGING

Le vieillissement du jeton d'authentification a été désactivé pour au moins un des modules.

PAM_PERM_DENIED

Permission refusée.

PAM_SUCCESS

Le jeton d'authentification a été mis à jour avec succès.

PAM_TRY_AGAIN

Tous les modules n'étaient pas en mesure de mettre à jour le(s) jeton(s) d'authentification. Dans ce cas, aucun des jetons d'authentification de l'utilisateur n'est mis à jour.

PAM_USER_UNKNOWN

Utilisateur inconnu du service de mots de passe.
