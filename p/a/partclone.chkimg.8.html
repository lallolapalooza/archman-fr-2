PARTCLONE.CHKIMG(8) Manuel de l'utilisateur Partclone PARTCLONE.CHKIMG(8)

NOM

partclone.chkimg - L'utilitaire pour vérifier l'image créée par partclone

SYNTAXE

partclone.chkimg {[-s | --source] source} [[-dX | --debug=X] [-N | --ncurses] [-f | --UI-fresh] [-F | --force] [--ignore_crc] [-C | --no_check] [-B | --no_block_detail] [-z | --buffer_size] [-L | --logfile] logfile]

DESCRIPTION

partclone.chkimg fait partie du projet Partclone, destiné à vérifier les fichiers image. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une compatibilité accrue avec le système de fichiers en utilisant des bibliothèques existantes, par exemple, e2fslibs est utilisé pour lire le bloc utilisé d'une partition ext2.

Les systèmes de fichiers supportés par Partclone incluent btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Il supporte également certains systèmes d'exploitation non-linux, par exemple : NTFS, FAT, EXFAT (pour Windows), HFS plus (MAC OS APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere). Tous les utilitaires partclone peuvent être exécutés comme partclone.xxx, très similaires à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, il suffit d'exécuter partclone.hfsp.

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec les options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-s FICHIER, --source FICHIER

FICHIER source. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique, selon votre action. Normalement, la source de sauvegarde est un périphérique, la source de restauration est un fichier image.

La réception de données à partir d'un pipeline n'est supportée QUE pour la restauration, ignorez simplement l'option -s ou utilisez '-' pour indiquer la réception de données depuis stdin.

-L FICHIER, --logfile FICHIER

Spécifiez un chemin pour enregistrer les informations de journalisation de partclone. (par défaut /var/log/partclone.log)

-C, --no_check

Ne pas vérifier la taille du périphérique et l'espace libre.

-N, --ncurses

Utiliser l'interface utilisateur textuelle Ncurses.

-X, --dialog

Afficher les messages au format Dialog.

--ignore_crc

Ignorer les erreurs de vérification CRC.

-F, --force

Forcer la progression.

-f sec, --UI-fresh sec

Spécifier l'intervalle en secondes pour la mise à jour de l'interface utilisateur.

-dniveau, --debug niveau

Définir le niveau de débogage [1|2|3]

-h, --help

Afficher un résumé des options.

-v, --version

Afficher la version du programme.

FICHIERS

/var/log/partclone.log

Le fichier journal de partclone.chkimg

EXEMPLES

 Vérifier si le fichier partclone.img est correct ou non.
   partclone.chkimg -d -s partclone.img

DIAGNOSTICS

Les diagnostics suivants peuvent être émis sur stderr :

partclone.chkimg fournit certains codes de retour, qui peuvent être utilisés dans les scripts :

Code Diagnostic
0 Le programme s'est terminé avec succès.
1 La clonage ou la restauration semblent avoir échoué.
