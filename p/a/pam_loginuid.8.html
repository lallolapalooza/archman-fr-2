NOM

pam_loginuid - Enregistrer l'UID de connexion de l'utilisateur dans l'attribut du processus

SYNTAXE

pam_loginuid.so [require_auditd]

DESCRIPTION

Le module pam_loginuid définit l'attribut loginuid du processus pour le processus qui a été authentifié. Ceci est nécessaire pour que les applications soient correctement auditées. Ce module PAM ne doit être utilisé que pour les applications de point d'entrée telles que : login, sshd, gdm, vsftpd, crond et atd. Il existe probablement d'autres applications de point d'entrée en dehors de celles-ci. Vous ne devriez pas l'utiliser pour des applications comme sudo ou su car cela va à l'encontre du but recherché en modifiant le loginuid vers le compte auquel ils viennent de passer.

OPTIONS

require_auditd

Cette option, lorsqu'elle est donnée, amènera ce module à interroger l'état du démon d'audit et à refuser les connexions s'il n'est pas en cours d'exécution.

TYPES DE MODULES FOURNIS

Seul le type de module session est fourni.

VALEURS DE RETOUR

PAM_SUCCESS

La valeur loginuid est définie et auditd est en cours d'exécution si la vérification a été demandée.

PAM_IGNORE

Le fichier /proc/self/loginuid n'est pas présent sur le système ou le processus de connexion s'exécute dans un espace de noms d'UID et le noyau ne prend pas en charge l'écrasement de loginuid.

PAM_SESSION_ERR

Toute autre erreur a empêché la définition de loginuid ou auditd n'est pas en cours d'exécution.

EXEMPLES

#%PAM-1.0
auth       required     pam_unix.so
auth       required     pam_nologin.so
account    required     pam_unix.so
password   required     pam_unix.so
session    required     pam_unix.so
session    required     pam_loginuid.so
