NOM

pam_putenv - définir ou modifier une variable d'environnement PAM

SYNTAXE

#include <security/pam_appl.h>

int pam_putenv(pam_handle_t *pamh, const char *name_value);

DESCRIPTION

La fonction pam_putenv est utilisée pour ajouter ou modifier la valeur des variables d'environnement PAM associées au descripteur pamh.

L'argument pamh est un descripteur d'authentification obtenu par un appel antérieur à pam_start(). L'argument name_value est une chaîne unique terminée par un NUL de l'une des formes suivantes :

NOM=valeur de la variable

Dans ce cas, la variable d'environnement du NOM donné est définie à la valeur indiquée : valeur de la variable. Si cette variable est déjà connue, elle est écrasée. Sinon, elle est ajoutée à l'environnement PAM.

NOM=

Cette fonction définit la variable à une valeur vide. Elle est listée séparément pour indiquer que c'est la manière correcte d'atteindre une telle définition.

NOM

Sans '=' , la fonction pam_putenv() supprimera la variable correspondante de l'environnement PAM.

pam_putenv() opère sur une copie de name_value, ce qui signifie que contrairement à putenv(3), l'application est responsable de la libération de la mémoire.

VALEURS DE RETOUR

PAM_PERM_DENIED

L'argument name_value fourni est un pointeur NULL.

PAM_BAD_ITEM

La variable demandée (pour suppression) n'est pas actuellement définie.

PAM_ABORT

Le descripteur pamh est corrompu.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_SUCCESS

La variable d'environnement a été mise à jour avec succès.

VOIR AUSSI

pam_start(3), pam_getenv(3), pam_getenvlist(3), pam_strerror(3), pam(8)
