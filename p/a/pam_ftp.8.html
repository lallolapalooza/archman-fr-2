NOM

pam_ftp - module d'accès FTP anonyme

SYNTAXE

pam_ftp.so [debug] [ignore] [users=XXX,YYY,...]

DESCRIPTION

pam_ftp est un module PAM qui fournit un mode d'accès FTP anonyme pluggable.

Ce module intercepte le nom d'utilisateur et le mot de passe. Si le nom est ftp ou anonymous, le mot de passe de l'utilisateur est coupé au délimiteur @ en une partie PAM_RUSER et une partie PAM_RHOST ; ces éléments PAM sont définis en conséquence. Le nom d'utilisateur (PAM_USER) est défini à ftp. Dans ce cas, le module réussit. Alternativement, le module définit l'élément PAM_AUTHTOK avec le mot de passe saisi et échoue.

Ce module n'est pas sécurisé et peut être facilement usurpé.

OPTIONS

debug

Affiche des informations de débogage.

ignore

Ignore l'adresse e-mail de l'utilisateur (si fournie).

ftp=XXX,YYY,...

Au lieu de ftp ou anonymous, permet la connexion anonyme à la liste d'utilisateurs séparée par des virgules : XXX,YYY,.... Si le demandeur saisit l'un de ces noms d'utilisateur, le nom d'utilisateur retourné est défini au premier de la liste : XXX.

TYPES DE MODULE FOURNIS

Seul le type de module auth est fourni.

VALEURS DE RETOUR

PAM_SUCCESS

L'authentification a réussi.

PAM_USER_UNKNOWN

Utilisateur inconnu.

EXEMPLES

Ajoutez la ligne suivante à /etc/pam.d/ftpd pour gérer la connexion anonyme de style ftp :

#
# ftpd ; ajouter les spécificités ftp. Ces lignes activent le ftp anonyme via
#       un accès UN*X standard (l'entrée listfile bloque l'accès aux
#       utilisateurs listés dans /etc/ftpusers)
#
auth    sufficient  pam_ftp.so
auth    required    pam_unix.so use_first_pass
auth    required    pam_listfile.so \
           onerr=succeed item=user sense=deny file=/etc/ftpusers
