NOM

pam_tty_audit - Activer ou désactiver l'audit TTY pour les utilisateurs spécifiés

SYNTAXE

pam_tty_audit.so [disable=motifs] [enable=motifs]

DESCRIPTION

Le module PAM pam_tty_audit est utilisé pour activer ou désactiver l'audit TTY. Par défaut, le noyau n'audite aucune entrée sur un TTY.

OPTIONS

disable=motifs

Pour chaque utilisateur correspondant aux motifs, désactiver l'audit TTY. Ceci remplace toute option enable précédente correspondant au même nom d'utilisateur sur la ligne de commande. Voir NOTES pour une description plus détaillée des motifs.

enable=motifs

Pour chaque utilisateur correspondant aux motifs, activer l'audit TTY. Ceci remplace toute option disable précédente correspondant au même nom d'utilisateur sur la ligne de commande. Voir NOTES pour une description plus détaillée des motifs.

open_only

Définir le drapeau d'audit TTY lors de l'ouverture de la session, mais ne pas le restaurer lors de la fermeture de la session. L'utilisation de cette option est nécessaire pour certains services qui ne font pas fork() pour exécuter la session authentifiée, comme sudo.

log_passwd

Enregistrer les frappes lorsque le mode ECHO est désactivé mais que le mode ICANON est actif. C'est le mode dans lequel le tty est placé pendant la saisie du mot de passe. Par défaut, les mots de passe ne sont pas enregistrés. Cette option peut ne pas être disponible sur les anciens noyaux (3.9 ?).

TYPES DE MODULES FOURNIS

Seul le type session est pris en charge.

VALEURS DE RETOUR

PAM_SESSION_ERR

Erreur lors de la lecture ou de la modification du drapeau d'audit TTY. Voir le journal système pour plus de détails.

PAM_SUCCESS

Succès.

NOTES

Lorsque l'audit TTY est activé, il est hérité par tous les processus démarrés par cet utilisateur. En particulier, les démons redémarrés par un utilisateur auront toujours l'audit TTY activé, et auditeront les entrées TTY même par d'autres utilisateurs, sauf si l'audit pour ces utilisateurs est explicitement désactivé. Par conséquent, il est recommandé d'utiliser disable=* comme première option pour la plupart des démons utilisant PAM.

Pour visualiser les données enregistrées par le noyau pour l'audit, utilisez la commande aureport --tty.

Les motifs sont des listes séparées par des virgules de motifs glob ou de plages d'UID. Une plage est spécifiée comme min_uid:max_uid où l'une de ces valeurs peut être vide. Si min_uid est vide, seul l'utilisateur avec l'UID max_uid sera correspondant. Si max_uid est vide, les utilisateurs avec un UID supérieur ou égal à min_uid seront correspondants.

Veuillez noter que les mots de passe peuvent dans certaines circonstances être enregistrés par l'audit TTY même si log_passwd n'est pas utilisé. Par exemple, toutes les entrées d'une session SSH seront enregistrées - même s'il y a un mot de passe tapé dans un logiciel fonctionnant sur l'hôte distant, car seul l'état du TTY local affecte l'audit TTY local.

EXEMPLES

Auditer toutes les actions administratives.

session	required pam_tty_audit.so disable=* enable=root
