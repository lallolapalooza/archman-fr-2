NOM

pamfile - décrire un fichier Netpbm (PAM ou PNM)

SYNTAXE

pamfile

[-allimages] [-count] [-comments]

[fichier ...]

Les abréviations uniques minimales des options sont acceptables. Vous pouvez utiliser des doubles traits d'union à la place de traits d'union simples pour indiquer les options. Vous pouvez utiliser des espaces blancs à la place du signe égal pour séparer le nom d'une option de sa valeur.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pamfile lit un ou plusieurs fichiers Netpbm en entrée et affiche de courtes descriptions du type d'image, de la taille, etc. Ceci est en partie destiné à être utilisé dans des scripts shell, donc le format n'est pas particulièrement esthétique.

Par défaut, pamfile ne lit que l'en-tête du fichier d'entrée. Si ce fichier est un pipe, cela peut poser des problèmes au processus qui alimente le pipe. Dans ce cas, voir l'option -allimages.

OPTIONS

-allimages
Cette option amène pamfile à décrire chaque image dans chaque fichier d'entrée. Sans cette option, pamfile décrit uniquement la première image de chaque fichier d'entrée.

Cette option amène également pamfile à lire toutes les images du flux d'entrée, alors que sans elle, pamfile ne lit que l'en-tête de la première. Si le flux d'entrée provient d'un pipe, le processus qui alimente le pipe peut nécessiter que le flux entier soit consommé. Dans ce cas, utilisez cette option même si le flux ne contient qu'une seule image.

Cette option n'a aucun effet si vous spécifiez également -count.

Notez qu'avant juillet 2000, un fichier ne pouvait pas contenir plus d'une image et de nombreux programmes ignorent toutes sauf la première.

Cette option est nouvelle dans Netpbm 9.5 (juillet 2000).

-comments
Cette option amène pamfile à inclure pour chaque image PAM un rapport des commentaires provenant de l'en-tête de l'image.

Pour une image PBM, PGM ou PPM, pamfile indique qu'il n'y a pas de commentaires, même s'il y en a.

Cette option est nouvelle dans Netpbm 10.35 (août 2006).

-count
Cette option amène pamfile à afficher uniquement un compte du nombre d'images dans chaque fichier d'entrée.

Comme avec -allimages, cela amène pamfile à lire toutes les images.

Cette option est nouvelle avec Netpbm 10.31 (décembre 2005).
