NOM

pappl-resource - Fonctions de ressources pappl

BIBLIOTHÈQUE

Framework d'application d'imprimante (libpappl, "pkg-config --cflags --libs pappl")

SYNTAXE

#include <pappl/pappl.h>

typedef struct _pappl_printer_s pappl_printer_t;

typedef struct _pappl_system_s pappl_system_t;

void
papplPrinterAddLink(pappl_printer_t *printer, const char *label, const char *path_or_url, bool secure);

void
papplSystemAddLink(pappl_system_t *system, const char *label, const char *path_or_url, bool secure);

void
papplSystemAddResourceCallback(pappl_system_t *system, const char *path, const char *format, pappl_resource_cb_t cb, void *data);

void
papplSystemAddResourceData(pappl_system_t *system, const char *path, const char *format, const void *data, size_t datalen);

void
papplSystemAddResourceDirectory(pappl_system_t *system, const char *basepath, const char *directory);

void
papplSystemAddResourceFile(pappl_system_t *system, const char *path, const char *format, const char *filename);

void
papplSystemAddResourceString(pappl_system_t *system, const char *path, const char *format, const char *data);

void
papplSystemAddStringsData(pappl_system_t *system, const char *path, const char *language, const char *data);

void
papplSystemAddStringsFile(pappl_system_t *system, const char *path, const char *language, const char *filename);

void
papplSystemRemoveResource(pappl_system_t *system, const char *path);

DESCRIPTION

Les fonctions de ressources PAPPL gèrent les fichiers de ressources, les rappels et les liens dans l'application d'impression.

FONCTIONS

papplPrinterAddLink

Ajoute un lien d'imprimante à l'en-tête de navigation.

void papplPrinterAddLink (
    pappl_printer_t *printer,
    const char *label,
    const char *path_or_url,
    pappl_loptions_t options
);

Cette fonction ajoute un lien de navigation pour une imprimante. L'argument "path_or_url" spécifie un chemin absolu tel que "/ipp/print/example/page" ou une URL absolue telle que "https://www.example.com/". L'argument "options" spécifie où le lien est affiché et si le lien doit rediriger un chemin absolu vers l'interface Web sécurisée ("https://.../path").

papplPrinterRemoveLink

Supprime un lien d'imprimante de l'en-tête de navigation.

void papplPrinterRemoveLink (
    pappl_printer_t *printer,
    const char *label
);

Cette fonction supprime le lien nommé pour l'imprimante.

papplSystemAddLink

Ajoute un lien à l'en-tête de navigation.

void papplSystemAddLink (
    pappl_system_t *system,
    const char *label,
    const char *path_or_url,
    pappl_loptions_t options
);

Cette fonction ajoute un lien de navigation pour le système. L'argument "path_or_url" spécifie un chemin absolu tel que "/page" ou une URL absolue telle que "https://www.example.com/". L'argument "options" spécifie où le lien est affiché et si le lien doit rediriger un chemin absolu vers l'interface Web sécurisée ("https://.../path").

papplSystemAddResourceCallback

Ajoute une ressource dynamique utilisant une fonction de rappel.

void papplSystemAddResourceCallback (
    pappl_system_t *system,
    const char *path,
    const char *format,
    pappl_resource_cb_t cb,
    void *data
);

Cette fonction ajoute une ressource dynamique au chemin spécifié. Lorsqu'une requête GET ou POST du client est reçue au chemin spécifié, la fonction "cb" sera appelée avec le pointeur client et le pointeur "data" pour y répondre.

Les rappels de ressources sont le plus souvent utilisés pour implémenter des pages Web personnalisées.

5
Note : Toute page Web personnalisée ajoutée avant d'appeler la fonction
5
papplSystemRun remplacera la page Web standard correspondante au même
5
chemin.

papplSystemAddResourceData

Ajoute une ressource de données statique.

void papplSystemAddResourceData (
    pappl_system_t *system,
    const char *path,
    const char *format,
    const void *data,
    size_t datalen
);

Cette fonction ajoute une ressource statique au chemin spécifié. Les données fournies ne sont pas copiées dans la ressource et doivent rester stables tant que la ressource est ajoutée au système.

5
Note : Toute ressource ajoutée avant d'appeler la fonction papplSystemRun
5
remplacera la ressource standard correspondante au même chemin.

papplSystemAddResourceDirectory

Ajoute des fichiers externes dans un répertoire comme ressources.

void papplSystemAddResourceDirectory (
    pappl_system_t *system,
    const char *basepath,
    const char *directory
);

Cette fonction ajoute des ressources statiques du répertoire spécifié sous le chemin spécifié. Le répertoire est scanné et seuls les fichiers présents au moment de l'appel sont disponibles, et ces fichiers doivent rester stables tant que les ressources sont ajoutées au système.

5
Note : Toute ressource ajoutée avant d'appeler la fonction papplSystemRun
5
remplacera la ressource standard correspondante au même chemin.

papplSystemAddStringsData

Ajoute une ressource de fichier de localisation statique.

void papplSystemAddStringsData (
    pappl_system_t *system,
    const char *path,
    const char *language,
    const char *data
);

Cette fonction ajoute une ressource de localisation statique au chemin spécifié. Les fichiers de localisation utilisent le format

NeXTStep strings ("text/strings") format défini dans la norme candidate PWG 5100.13-2013. Les données fournies ne sont pas copiées dans la ressource et doivent rester stables tant que la ressource est ajoutée au système.
