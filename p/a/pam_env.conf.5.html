NOM

pam_env.conf, environnement - les fichiers de configuration des variables d'environnement

DESCRIPTION

Le fichier /etc/security/pam_env.conf spécifie les variables d'environnement à définir, annuler ou modifier par pam_env(8). Lorsqu'une personne se connecte, ce fichier est lu et les variables d'environnement sont définies en conséquence.

Chaque ligne commence par le nom de la variable, il y a ensuite deux options possibles pour chaque variable : DEFAULT et OVERRIDE. DEFAULT permet à un administrateur de définir la valeur de la variable à une valeur par défaut, si aucune n'est fournie, la chaîne vide est supposée. L'option OVERRIDE indique à pam_env qu'il doit saisir sa valeur (en remplaçant la valeur par défaut) s'il y en a une à utiliser. Lorsque OVERRIDE n'est pas utilisé, "" est supposé et aucune substitution ne sera effectuée.

VARIABLE [DEFAULT=[valeur]] [OVERRIDE=[valeur]]

Les variables d'environnement (éventuellement inexistantes) peuvent être utilisées dans les valeurs en utilisant la syntaxe ${chaîne} et les PAM_ITEMs (éventuellement inexistantes) ainsi que HOME et SHELL peuvent être utilisées dans les valeurs en utilisant la syntaxe @{chaîne}. Les deux caractères $ et @ peuvent être échappés avec une barre oblique inverse pour être utilisés comme valeurs littérales. Les valeurs peuvent être délimitées par "", les guillemets échappés ne sont pas pris en charge. Notez que de nombreuses variables d'environnement que vous aimeriez utiliser peuvent ne pas être définies lorsque le module est appelé. Par exemple, ${HOME} est utilisé ci-dessous plusieurs fois, mais de nombreuses applications PAM ne le rendent pas disponible au moment où vous en avez besoin. Les variables spéciales @{HOME} et @{SHELL} sont développées en valeurs pour l'utilisateur à partir de l'entrée passwd correspondante.

Le caractère "#" en début de ligne (sans espace avant) peut être utilisé pour marquer cette ligne comme commentaire.

Le fichier /etc/environment spécifie les variables d'environnement à définir. Le fichier doit consister en simples paires NOM=VALEUR sur des lignes séparées. Le module pam_env(8) lira le fichier après le fichier pam_env.conf.

EXEMPLES

Voici quelques lignes d'exemple qui pourraient être spécifiées dans /etc/security/pam_env.conf.

Définir la variable REMOTEHOST pour tous les hôtes distants, avec par défaut "localhost" plutôt que de ne pas être définie du tout

      REMOTEHOST     DEFAULT=localhost OVERRIDE=@{PAM_RHOST}

Définir la variable DISPLAY si cela semble raisonnable

      DISPLAY        DEFAULT=${REMOTEHOST}:0.0 OVERRIDE=${DISPLAY}

Maintenant quelques variables simples

      PAGER          DEFAULT=less
      MANPAGER       DEFAULT=less
      LESS           DEFAULT="M q e h15 z23 b80"
      NNTPSERVER     DEFAULT=localhost
      PATH           DEFAULT=${HOME}/bin:/usr/local/bin:/bin\
      :/usr/bin:/usr/local/bin/X11:/usr/bin/X11
      XDG_DATA_HOME  DEFAULT=@{HOME}/share/

Exemples farfelus de variables échappées, juste pour montrer comment elles fonctionnent.

      DOLLAR         DEFAULT=\$
      DOLLARDOLLAR   DEFAULT=        OVERRIDE=\$${DOLLAR}
      DOLLARPLUS     DEFAULT=\${REMOTEHOST}${REMOTEHOST}
      ATSIGN         DEFAULT=""      OVERRIDE=\@
