NOM

pam_matrix - Module PAM de test pour récupérer des éléments spécifiques au module PAM

SYNTAXE

pam_matrix.so [...]

DESCRIPTION

Les applications PAM de test nécessitent souvent de mettre en place un backend d'authentification avec le moins d'effort possible. Le module pam_matrix permet de s'authentifier auprès d'un fichier texte clé-valeur, fourni par une option ou une variable d'environnement.

IMPORTANT

pam_matrix est un outil de test. Il doit être considéré comme complètement non sécurisé et ne jamais être utilisé en dehors des environnements de test ! Comme vous le verrez en lisant la description des options et des actions, beaucoup d'entre elles n'ont aucun sens dans le monde réel et ont été ajoutées uniquement pour permettre les tests.

BASE DE DONNÉES DES MOTS DE PASSE

Le module pam_matrix authentifie les utilisateurs auprès d'un fichier CSV en texte brut. Le format du fichier est le suivant :

nom_utilisateur:mot_de_passe:service_autorisé

Exemple : L'utilisateur bob est autorisé à s'authentifier avec le service sshd

bob:secret:sshd

OPTIONS

•passdb=/chemin/vers/fichier - le chemin vers la base de données des mots de passe. Si la base de données n'est pas fournie avec cette option de module, pam_matrix.so lit la variable d'environnement PAM_MATRIX_PASSWD et tente de charger le fichier à partir de là. Si cela échoue également, PAM_AUTHINFO_UNAVAIL est retourné.
•echo - si cette option est fournie, pam_matrix.so demandera le mot de passe en utilisant PAM_PROMPT_ECHO_ON, c'est-à-dire que le mot de passe sera affiché à l'utilisateur. Cette option a été ajoutée pour permettre de mieux tester les fonctions de conversation.
•verbose - si cette option est fournie, pam_matrix.so affichera un message PAM_TEXT_INFO lorsque l'authentification réussit et un message PAM_ERROR_MSG lorsque l'authentification échoue. Cette option a été ajoutée pour permettre de mieux tester les fonctions de conversation.

TYPES DE MODULES FOURNIS

Tous les types de modules (account, auth, password et session) sont pris en charge.

Le module auth recherche l'utilisateur dans le fichier passdb et compare le mot de passe fourni avec celui du fichier passdb.

Le module password est capable de mettre à jour le mot de passe dans le fichier passdb.

Le module access compare le nom du service avec lequel la conversation PAM a été invoquée avec le service autorisé pour l'utilisateur tel que défini dans le fichier passdb.

Le module session définit la variable d'environnement PAM HOMEDIR à "/home/%u" où %u représente l'utilisateur qui ouvre la session. La variable est désactivée à la fermeture de la session.

EXEMPLE

auth        required    pam_matrix.so passdb=/tmp/passdb verbose
account     required    pam_matrix.so passdb=/tmp/passdb verbose
password    required    pam_matrix.so passdb=/tmp/passdb verbose
session     required    pam_matrix.so passdb=/tmp/passdb verbose
