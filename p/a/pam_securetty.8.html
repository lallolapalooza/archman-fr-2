NOM

pam_securetty - Limiter la connexion root à des périphériques spéciaux

SYNTAXE

pam_securetty.so [debug]

DESCRIPTION

pam_securetty est un module PAM qui autorise les connexions root uniquement si l'utilisateur se connecte sur un tty « sécurisé », tel que défini par la liste du fichier securetty. pam_securetty vérifie d'abord si /etc/securetty existe. Sinon, et s'il a été compilé avec le support vendordir, il utilisera /securetty. pam_securetty vérifie également que les fichiers securetty sont des fichiers normaux et ne sont pas inscriptibles par tous. Il autorise également les connexions root sur le tty spécifié avec le commutateur console= sur la ligne de commande du noyau et sur les ttys de /sys/class/tty/console/active.

Ce module n'a aucun effet sur les utilisateurs non root et nécessite que l'application remplisse correctement l'élément PAM_TTY.

Pour une utilisation canonique, il doit être listé comme une méthode d'authentification requise avant toute méthode d'authentification suffisante.

OPTIONS

debug

Imprime des informations de débogage.

noconsole

N'autorise pas automatiquement les connexions root sur le périphérique de console du noyau, tel que spécifié dans la ligne de commande du noyau ou par le fichier sys, s'il n'est pas également spécifié dans le fichier securetty.

TYPES DE MODULE FOURNIS

Seul le type de module auth est fourni.

VALEURS DE RETOUR

PAM_SUCCESS

L'utilisateur est autorisé à poursuivre l'authentification. Soit l'utilisateur n'est pas root, soit l'utilisateur root essaie de se connecter sur un appareil acceptable.

PAM_AUTH_ERR

Authentification rejetée. Soit root tente de se connecter via un appareil inacceptable, soit le fichier securetty est inscriptible par tous ou n'est pas un fichier normal.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_CONV_ERR

La méthode de conversation fournie par l'application n'a pas réussi à obtenir le nom d'utilisateur.

PAM_INCOMPLETE

La méthode de conversation fournie par l'application a renvoyé PAM_CONV_AGAIN.

PAM_SERVICE_ERR

Une erreur s'est produite pendant que le module déterminait le nom d'utilisateur ou le tty, ou le module n'a pas pu ouvrir le fichier securetty.

PAM_USER_UNKNOWN

Le module n'a pas trouvé le nom d'utilisateur dans le fichier /etc/passwd pour vérifier si l'utilisateur avait un UID de 0. Par conséquent, les résultats de l'exécution de ce module sont ignorés.

EXEMPLES

auth  required  pam_securetty.so
auth  required  pam_unix.so

VOIR AUSSI
