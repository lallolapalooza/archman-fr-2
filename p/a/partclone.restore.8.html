PARTCLONE.RESTORE(8) Manuel utilisateur Partclone PARTCLONE.RESTORE(8)

NOM

partclone.restore - restaure une image partclone sur un périphérique.

SYNTAXE

partclone.restore {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] cible} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [--ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] logfile [-w | --skip_write_error] [--write-direct-io] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-B | --no_block_detail]]

DESCRIPTION

partclone.restore fait partie du projet Partclone pour restaurer toutes les images créées par partclone.[fstype] ou partclone.dd. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une meilleure compatibilité du système de fichiers en utilisant des bibliothèques existantes, par exemple, e2fslibs est utilisé pour lire le bloc utilisé de la partition ext2.

Les systèmes de fichiers pris en charge par Partclone comprennent btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Il prend également en charge certains systèmes d'exploitation non Linux, par exemple : NTFS, FAT, EXFAT (pour Windows), HFS plus (MAC OS APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere). Tous les utilitaires partclone peuvent être exécutés comme partclone.xxx, très similaires à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, exécutez simplement partclone.hfsp.

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-s FICHIER, --source FICHIER

FICHIER source. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique, selon votre action. Normalement, la source de sauvegarde est un périphérique, la source de restauration est un fichier image.

La réception de données depuis un pipeline n'est prise en charge que pour la restauration, ignorez l'option -s ou utilisez '-' pour indiquer la réception de données depuis stdin.

-o FICHIER, --output FICHIER

FICHIER de sortie. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique, selon votre action. Normalement, la sortie de sauvegarde va vers un fichier image et la sortie de restauration va vers un périphérique.

L'envoi de données vers un pipeline est également pris en charge pour la sauvegarde uniquement, ignorez l'option -o ou utilisez '-' pour indiquer l'envoi de données vers stdout.

-O FICHIER, --overwrite FICHIER

Écrase le FICHIER, même s'il existe.

--restore_raw_file

Création d'un fichier brut spécial pour le périphérique de boucle.

-L FICHIER, --logfile FICHIER

Spécifie un chemin pour enregistrer les informations du journal de partclone. (par défaut /var/log/partclone.log)

-R, --rescue

Continue après les erreurs de lecture du disque.

-C, --no_check

Ne vérifie pas la taille du périphérique et l'espace libre.

-N, --ncurses

Utilise une interface utilisateur textuelle Ncurses.

-X, --dialog

Affiche les messages au format Dialog.

-I, --ignore_fschk

Ignore la vérification du système de fichiers.

--ignore_crc

Ignore les erreurs de vérification CRC.

-F, --force

Force la progression.

-f sec, --UI-fresh sec

Spécifie l'intervalle en secondes pour rafraîchir l'interface.

-z taille, --buffer_size taille

Taille du tampon de lecture/écriture (par défaut : 1048576)

-q, --quiet

Désactive les messages de progression.

-dniveau, --debug niveau

Définit le niveau de débogage [1|2|3]

-h, --help

Affiche un résumé des options.

-v, --version

Affiche la version du programme.

FICHIERS

/var/log/partclone.log

Le fichier journal de partclone.restore

EXEMPLES

 Restaurer /dev/hda1 à partir de hda1.img et afficher les informations de débogage.
  partclone.restore -d -s hda1.img -o /dev/hda1
 Restaurer une image de clonezilla (divisée, gzipée, etc.) avec source stdin
  cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.restore -d -s - -o /dev/sda1
 Restaurer une image brute à partir de partclone.dd
  partclone.dd -d -c -s /dev/sda1 -o - | partclone.restore -d -s - -o /dev/sdb1

DIAGNOSTICS

Les diagnostics suivants peuvent être émis sur stderr :

partclone.restore fournit quelques codes de retour, qui peuvent être utilisés dans les scripts :

Code Diagnostic
0 Le programme s'est terminé avec succès.
1 Le clonage ou la restauration a échoué.
