PARTCLONE.INFO(8) Manuel utilisateur Partclone PARTCLONE.INFO(8)

NOM

partclone.info - L'utilitaire pour afficher les informations de l'en-tête d'image.

SYNTAXE

partclone.info {FICHIER}

DESCRIPTION

partclone.info fait partie du projet Partclone pour récupérer les informations de l'en-tête de partition à partir des fichiers image. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une meilleure compatibilité du système de fichiers en utilisant des bibliothèques existantes, par exemple e2fslibs est utilisé pour lire le bloc utilisé de la partition ext2.

Le système de fichiers supporté par Partclone inclut btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Il supporte également certains systèmes d'exploitation non-linux, par exemple NTFS, FAT, EXFAT (pour Windows), HFS plus (MAC OS APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere). Tous les utilitaires partclone peuvent être exécutés comme partclone.xxx qui est très similaire à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, lancez simplement partclone.hfsp.

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

FICHIER

Fichier image. Le FICHIER peut être un fichier image (créé par partclone).

EXEMPLES

  Récupérer les informations d'utilisation de la partition
    partclone.info /home/partimag/sdb2.img
    Partclone v0.2.20 http://partclone.org
    Système de fichiers :  EXTFS
    Taille du périphérique :  928.0 Mo
    Espace utilisé :  535.4 Mo
    Espace libre :   392.6 Mo
    Taille du bloc :   4096 octets
    Bloc utilisé :  130708

DIAGNOSTICS

Les diagnostics suivants peuvent être émis sur stderr :

partclone.info fournit des codes de retour qui peuvent être utilisés dans les scripts :

Code Diagnostic
0 Programme terminé avec succès.
1 Clonage ou restauration semblent avoir échoué.
