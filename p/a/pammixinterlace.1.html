NOM

pammixinterlace - mélanger les lignes adjacentes pour fusionner les images entrelacées

SYNTAXE

pammixinterlace

[-filtre={linéaire, fir, ffmpeg}]

[-adaptatif]

[fichierentree]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pammixinterlace est conçu pour fonctionner sur une image qui est l'entrelacement de deux images, où les lignes de balayage 0, 2, 4, etc. proviennent d'une image et les lignes 1, 3, 5, etc. d'une autre. (Voir ci-dessous pour savoir pourquoi vous pourriez vous attendre à rencontrer une telle image).

pammixinterlace fait de chaque ligne de la sortie un mélange de la ligne correspondante de l'entrée et de ses deux voisines. Il utilise la moitié de la ligne principale et un quart de chacune des deux lignes voisines.

Cela peut être utile si l'image est une capture vidéo provenant d'une source vidéo entrelacée. Dans ce cas, chaque ligne montre le sujet 1/60 seconde avant ou après les deux lignes qui l'entourent. Si le sujet est en mouvement, cela peut nuire à la qualité de l'image.

Dans les flux de données vidéo, vous trouvez souvent chaque image contenant seulement la moitié des lignes de l'image - la moitié impaire ou la moitié paire. Le périphérique d'affichage affiche les lignes dans leurs positions correctes sur un écran cathodique à mesure qu'elles arrivent. Lorsque vous affichez les lignes dans cet ordre, l'écran cathodique scintille moins car une zone particulière de l'écran est rafraîchie deux fois plus souvent. Lors de la capture d'un tel flux, les ordinateurs génèrent souvent l'image entrelacée du type sur lequel pammixinterlace travaille. Mais cette image entrelacée, lorsqu'elle est affichée sur un écran cathodique, ne ressemble pas à ce que produirait un périphérique d'affichage rendant le flux directement sur un écran cathodique à mesure qu'il arrivait, en raison du moment où les différents pixels sont dessinés et s'estompent ensuite. C'est pourquoi vous avez besoin de quelque chose comme pammixinterlace.

Vous pourriez préférer l'effet d'extraire simplement l'une des deux images. Vous pouvez le faire avec pamdeinterlace.

OPTIONS

-filtre={linéaire,fir,ffmpeg}
Cette option permet de choisir entre l'un des trois mécanismes de filtrage. linéaire est une formule de mélange linéaire. fir est un filtre passe-bas FIR de taille 5, et ffmpeg est une formule tirée de la documentation du programme ffmpeg .

La valeur par défaut est fir.

-adaptatif
Cette option active le mode de filtrage "adaptatif". Dans ce mode, pammixinterlace ne modifie que les pixels qui font manifestement partie d'un motif de "peigne".
