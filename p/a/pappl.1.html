NOM

pappl - framework d'application d'imprimante

BIBLIOTHÈQUE

Framework d'application d'imprimante (libpappl, "pkg-config --cflags --libs pappl")

SYNTAXE

#include <pappl/pappl.h>

DESCRIPTION

PAPPL est un framework/une bibliothèque simple basée sur C pour développer des applications d'imprimante CUPS, qui sont le remplacement recommandé pour les pilotes d'imprimante. Il est suffisamment général pour prendre en charge tout type d'imprimante ou de pilote pouvant être utilisé sur les ordinateurs de bureau, les serveurs et dans les environnements embarqués.

PAPPL intègre un serveur HTTP / IPP Everywhere™ multi-threadé et fournit des rappels pour une variété d'événements qui permettent à une application graphique ou en ligne de commande d'interagir à la fois avec l'utilisateur local qui exécute l'application d'imprimante et avec les clients réseau qui soumettent des travaux d'impression, interrogent l'état et les capacités de l'imprimante, etc.

PAPPL fournit une interface de pilote simple pour l'impression graphique raster, et les développeurs de pilotes CUPS Raster s'y adapteront rapidement. PAPPL peut également être utilisé avec des imprimantes qui prennent en charge l'impression graphique vectorielle, bien que vous deviez développer plus de code pour les prendre en charge. Les pilotes fournissent des informations de configuration et de capacité à PAPPL, et PAPPL appelle ensuite le pilote pour imprimer les éléments nécessaires. PAPPL prend automatiquement en charge l'impression de fichiers JPEG, PNG, PWG Raster, Apple Raster et "raw" vers les imprimantes connectées via USB et réseau (AppSocket/JetDirect). D'autres formats peuvent être pris en charge via des rappels de "filtre" que vous enregistrez.
