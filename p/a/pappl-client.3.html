DESCRIPTION

Les fonctions client de PAPPL fournissent l'accès aux connexions client. Les connexions client et le cycle de vie des objets pappl_client_t sont gérés automatiquement par l'objet système pour l'application imprimante.

Les fonctions papplClientGet récupèrent les valeurs actuelles des diverses données de requête fournies par le client.

RÉPONDRE AUX DEMANDES CLIENT

La fonction papplClientRespond lance une réponse HTTP à une demande client. Les fonctions papplClientHTMLHeader et papplClientHTMLFooter envoient les en-têtes et pieds de page HTML standard pour l'interface web configurée de l'application imprimante, tandis que les fonctions papplClientHTMLEscape, papplClientHTMLPrintf, papplClientHTMLPuts, et papplClientHTMLStartForm envoient des messages ou chaînes HTML. Utilisez les fonctions papplClientGetHTTP et (CUPS) httpWrite2 pour envoyer des données arbitraires dans une réponse client. Les cookies peuvent être inclus dans les requêtes du navigateur web en utilisant la fonction papplClientSetCookie.

La fonction papplClientRespondIPP lance une réponse IPP. Utilisez les différentes fonctions ippAdd de CUPS pour ajouter des attributs au message de réponse.

La fonction papplClientRespondRedirect envoie une réponse de redirection au client.

FORMULAIRES HTML

PAPPL fournit les fonctions papplClientGetCSRFToken, papplClientGetForm, papplClientHTMLStartForm et papplClientValidateForm pour gérer de manière sécurisée les formulaires HTML.

La fonction papplClientHTMLStartForm démarre un formulaire HTML et insère une variable cachée contenant un jeton CSRF qui a été généré par PAPPL à partir d'une clé de session sécurisée mise à jour périodiquement. Lors de la réception d'une demande de soumission de formulaire ultérieure, les fonctions papplClientGetForm et papplClientValidateForm peuvent être utilisées pour lire de manière sécurisée les données du formulaire (y compris les pièces jointes) et valider le jeton CSRF caché.

AUTHENTIFICATION ET AUTORISATION

PAPPL prend en charge à la fois l'authentification basée sur l'utilisateur à l'aide de modules PAM et un mécanisme simple d'authentification par mot de passe basé sur les cookies, utilisé pour limiter l'accès administratif via l'interface web.

La fonction papplHTMLAuthorize autorise l'accès à l'interface web et gère l'affichage d'un formulaire d'authentification sur le navigateur web du client. La valeur de retour indique si le client est autorisé à accéder à la page web.

La fonction papplIsAuthorized peut être utilisée pour déterminer si le client actuel est autorisé à effectuer des opérations administratives et est normalement utilisée uniquement pour les clients IPP. Les utilisateurs locaux sont toujours autorisés, tandis que les utilisateurs distants doivent fournir des informations d'identification (généralement un nom d'utilisateur et un mot de passe) pour y accéder. Cette fonction retournera un code d'état HTTP qui peut être fourni à la fonction httpClientSendResponse. La valeur HTTP_STATUS_CONTINUE indique que l'autorisation est accordée et que la requête doit se poursuivre. La fonction papplGetUsername peut être utilisée pour obtenir l'identité de l'utilisateur authentifié.

FONCTIONS

papplClientGetCSRFToken

Obtient un jeton unique de prévention des attaques CSRF (Cross-Site Request Forgery) sous forme de chaîne.

char * papplClientGetCSRFToken (
    pappl_client_t *client,
    char *buffer,
    size_t bufsize
);

Cette fonction génère et renvoie une chaîne de jeton unique de prévention des attaques CSRF à utiliser comme valeur d'une variable cachée dans tous les formulaires HTML envoyés en réponse, puis comparée lors de la validation des données du formulaire dans la requête subséquente.

La valeur est basée sur la clé de session système actuelle et l'adresse du client afin de rendre les attaques par rejeu infaisables.

5
Note : La fonction papplClientHTMLStartForm ajoute automatiquement la
5
variable CSRF cachée, et la fonction papplClientIsValidForm
5
valide la valeur.

papplClientGetCookie

Obtient un cookie du client.

char * papplClientGetCookie (
    pappl_client_t *client,
    const char *name,
    char *buffer,
    size_t bufsize
);

Cette fonction obtient la valeur d'un "cookie" HTTP à partir de la demande client. NULL est renvoyé si aucun cookie n'a été défini par une demande antérieure, ou si l'utilisateur a désactivé ou supprimé le cookie.

Utilisez la fonction papplClientSetCookie pour définir un cookie dans une re

ponse à une requête.

5
Note : Les cookies définis avec papplClientSetCookie ne seront pas disponibles
5
pour cette fonction avant la requête suivante.

papplClientGetForm

Obtenir les données du formulaire à partir du client Web.

int  papplClientGetForm (
    pappl_client_t *client,
    cups_option_t **form
);

Pour les requêtes HTTP GET, les données du formulaire sont collectées à partir de l'URI de la requête. Pour les requêtes HTTP POST, les données du formulaire sont lues depuis le client.

Les valeurs de formulaire retournées doivent être libérées à l'aide de la fonction cupsFreeOptions.

5
Note : Comme les données du formulaire sont lues à partir de la connexion client, cette
5
fonction ne peut être appelée qu'une seule fois par requête.

papplClientGetHTTP

Obtenir la connexion HTTP associée à un objet client.

http_t * papplClientGetHTTP (
    pappl_client_t *client
);

Cette fonction retourne la connexion HTTP associée au client et est utilisée lors de l'envoi de données de réponse directement au client à l'aide des fonctions httpXxx de CUPS.

papplClientGetHostName

Obtenir le nom d'hôte du champ Host : fourni par le client.

const char * papplClientGetHostName (
    pappl_client_t *client
);

Cette fonction retourne le nom d'hôte qui a été utilisé dans la requête et qui devrait être utilisé dans toutes les URL ou URI que vous générez.

papplClientGetHostPort

Obtenir le port du champ Host : fourni par le client.

int  papplClientGetHostPort (
    pappl_client_t *client
);

Cette fonction retourne le numéro de port qui a été utilisé dans la requête et qui devrait être utilisé dans toutes les URL ou URI que vous générez.

Obtenir le travail cible pour une requête IPP.

Cette fonction retourne le travail associé à la requête IPP actuelle. NULL est retourné si la requête ne cible pas un travail.

papplClientGetOptions

Obtenir les options de l'URI de requête.

const char * papplClientGetOptions (
    pappl_client_t *client
);

Cette fonction retourne toutes les options qui ont été passées dans l'URI de la requête HTTP. Les options sont les caractères après le caractère « ? », par exemple une URI de requête de « /mypage?name=value » aura une chaîne d'options de « name=value ».

NULL est retourné si l'URI de requête ne contenait aucune option.

papplClientHTMLAuthorize

Gérer l'autorisation pour l'interface Web.

bool  papplClientHTMLAuthorize (
    pappl_client_t *client
);

L'interface Web prend en charge l'authentification par rapport aux comptes d'utilisateurs et l'authentification à l'aide d'un mot de passe d'accès administratif unique. Cette fonction gère les détails d'authentification pour l'interface Web en fonction de la configuration du service d'authentification du système, c'est-à-dire l'argument « auth_service » de papplSystemCreate et tout rappel défini à l'aide de papplSystemSetAuthCallback.

Cette fonction envoie le pied de page standard de l'interface Web suivi d'un segment de longueur nulle final pour terminer la réponse HTTP actuelle. Utilisez la fonction papplSystemSetFooterHTML pour ajouter tout HTML personnalisé nécessaire dans le pied de page.

papplClientHTMLHeader

Afficher l'en-tête et le titre de l'interface Web.

void papplClientHTMLHeader (
    pappl_client_t *client,

DESCRIPTION

These functions are used by PAPPL web servers to communicate with web browser clients.

papplClientHTMLHeader

Envoyer l'en-tête et le titre de l'interface Web standard pour une imprimante. Si l'argument "refresh" est supérieur à zéro, la page sera automatiquement rechargée après ce nombre de secondes.

Si "label" et "path_or_url" sont des chaînes non NULL, un lien de navigation supplémentaire est inclus avec l'en-tête de titre - ceci est généralement utilisé pour un bouton d'action ("Changer").

Utilisez la fonction papplSystemAddLink pour ajouter des liens de navigation à l'échelle du système à l'en-tête. De même, utilisez papplPrinterAddLink pour ajouter des liens spécifiques à l'imprimante, qui apparaîtront dans l'interface Web de l'imprimante si le système n'est pas configuré pour prendre en charge plusieurs imprimantes (l'option PAPPL_SOPTIONS_MULTI_QUEUE de papplSystemCreate).

papplClientHTMLPrintf

Envoyer du texte formaté au client du navigateur Web,
en échappant si nécessaire.

void papplClientHTMLPrintf (
    pappl_client_t *client,
    const char *format,
    ...
);

Cette fonction envoie du texte formaté au client du navigateur Web en utilisant des codes de formatage de style printf. La chaîne de format elle-même n'est pas échappée pour permettre le HTML incorporé, mais les chaînes insérées à l'aide des codes '%c' ou %s sont correctement échappées pour le HTML - "&" est envoyé comme &amp;, etc.

papplClientHTMLPuts

Envoyer une chaîne HTML au client du navigateur Web.

void papplClientHTMLPuts (
    pappl_client_t *client,
    const char *s
);

Cette fonction envoie une chaîne HTML au client sans effectuer d'échappement de caractères spéciaux.

papplClientHTMLStartForm

Démarrer un formulaire HTML.

void papplClientHTMLStartForm (
    pappl_client_t *client,
    const char *action,
    bool multipart
);

Cette fonction démarre un formulaire HTML avec le chemin "action" spécifié et inclut le jeton CSRF comme variable cachée. Si l'argument "multipart" est true, le formulaire est annoté pour prendre en charge les pièces jointes de fichiers jusqu'à 2 Mio.

papplClientIsAuthorized

Déterminer si un client est autorisé pour les
requêtes administratives.

http_status_t  papplClientIsAuthorized (
    pappl_client_t *client
);

Cette fonction détermine si un client est autorisé à soumettre une requête administrative.

La valeur de retour est HTTP_STATUS_CONTINUE si l'accès est autorisé, HTTP_STATUS_FORBIDDEN si l'accès n'est pas autorisé, HTTP_STATUS_UNAUTHORIZED si l'autorisation est requise, ou HTTP_STATUS_UPGRADE_REQUIRED si la connexion doit être chiffrée. Toutes ces valeurs peuvent être passées à la fonction papplClientRespond.

papplClientIsEncrypted

Retourner si une connexion client est chiffrée.

bool  papplClientIsEncrypted (
    pappl_client_t *client
);

Cette fonction retourne une valeur booléenne indiquant si une connexion client est chiffrée avec TLS.

papplClientIsValidForm

Valider les variables du formulaire HTML.

bool  papplClientIsValidForm (
    pappl_client_t *client,
    int num_form,
    cups_option_t *form
);

Cette fonction valide le contenu d'un formulaire HTML à l'aide du jeton CSRF inclus comme variable cachée. Lors de l'envoi d'un formulaire HTML, vous devez utiliser la fonction papplClientStartForm pour démarrer le formulaire HTML et insérer le jeton CSRF pour validation ultérieure.

5
Remarque : Les appelants sont censés valider toutes les autres variables du formulaire.

papplClientRespond

Envoyer une réponse HTTP régulière.

bool  papplClientRespond (
    pappl_client_t *client,
    http_status_t code,
    const char *content_encoding,
    const char *type,
    time_t last_modified,
    size_t length
);

Cette fonction envoie tous les champs HTTP requis et inclut des messages standard pour les erreurs. Les valeurs suivantes pour "code" sont explicitement prises en charge :

  • HTTP_STATUS_OK : La requête est réussie.
  • HTTP_STATUS_BAD_REQUEST : Le client a soumis une requête incorrecte.
  • HTTP_STATUS_CONTINUE : Un défi d'authentification n'est pas nécessaire.
  • HTTP_STATUS_FORBIDDEN : Authentifié mais non autorisé.
  • HTTP_STATUS_METHOD_NOT_ALLOWED : La méthode HTTP n'est pas prise en charge pour
    l'URI donné.
  • HTTP_STATUS_UNAUTHORIZED : Non authentifié.
  • HTTP_STATUS_UPGRADE_REQUIRED : Redirige le client vers une page sécurisée.

Utilisez papplClientRespondRedirect lorsque vous avez besoin de rediriger le client vers une autre page.

5
Remarque : Vous devez appeler cette fonction avant d'ajouter des attributs de réponse.
5
attributs.

papplClientRespondIPPUnsupported

Répondre avec un attribut IPP non pris en charge.

void papplClientRespondIPPUnsupported (
    pappl_client_t *client,
    ipp_attribute_t *attr
);

Cette fonction retourne un code d'état 'client-error-attributes-or-values-not-supported' et ajoute l'attribut spécifié au groupe d'attributs non pris en charge dans la réponse.

papplClientRespondRedirect

Répondre avec une redirection vers une autre page.

bool  papplClientRespondRedirect (
    pappl_client_t *client,
    http_status_t code,
    const char *path
);

Cette fonction envoie une réponse HTTP qui redirige le client vers une autre page ou URL. La valeur la plus courante pour "code" est HTTP_STATUS_FOUND.

papplClientSetCookie

Définir un cookie pour le client du navigateur Web.

void papplClientSetCookie (
    pappl_client_t *client,
    const char *name,
    const char *value,
    int expires
);

Cette fonction définit la valeur d'un cookie pour le client en mettant à jour l'en-tête Set-Cookie dans la réponse HTTP qui sera envoyée. Les chaînes "name" et "value" doivent contenir uniquement des caractères valides pour un cookie et sa valeur tels que documentés dans la RFC 6265, ce qui signifie essentiellement des lettres, des chiffres, "@", "-", "." et "_".

L'argument "expires" spécifie combien de temps le cookie restera actif en secondes, par exemple 3600 secondes correspondent à une heure et 86400 secondes correspondent à un jour. Si la valeur est zéro ou négative, un cookie de "session" est créé à la place, qui expirera dès que le navigateur Web sera fermé.

papplClientSetUsername

Définir le nom d'utilisateur authentifié, le cas échéant.

void papplClientSetUsername (
    pappl_client_t *client,
    const char *username
);

Cette fonction définit le nom d'utilisateur authentifié actuel, le cas échéant.

    NOM

    pappl-client - API du client Piment

    SYNOPSIS

    #include <pappl/pappl-client.h>

// Types...
typedef struct pappl_client_s pappl_client_t;
typedef struct pappl_printer_s pappl_printer_t;
// ... autres types ...

// Fonctions...
pappl_client_t *pappl_client_connect(const char *host, int port, const char *username, const char *password);
void pappl_client_disconnect(pappl_client_t *client);
// ... autres fonctions ...

    DESCRIPTION

    Les fonctions de cette page décrivent l'API du client pour interagir avec un serveur Piment. Elle permet de découvrir et de gérer des imprimantes, des travaux d'impression, des pilotes, des ressources et des événements.

    FONCTIONS

    pappl_client_connect

    Établit une connexion à un serveur Piment.

    pappl_client_t *pappl_client_connect(const char *host, int port, const char *username, const char *password);
    • host : Nom d'hôte ou adresse IP du serveur Piment.
    • port : Port du serveur Piment (généralement 631).
    • username : Nom d'utilisateur pour l'authentification (peut être NULL).
    • password : Mot de passe pour l'authentification (peut être NULL).
    • Retourne un pointeur vers une structure pappl_client_t en cas de succès, NULL en cas d'échec.
    pappl_client_disconnect

    Ferme la connexion au serveur Piment.

    void pappl_client_disconnect(pappl_client_t *client);
    • client : Pointeur vers la structure pappl_client_t retournée par pappl_client_connect.
    pappl_client_get_printer_list

    Récupère la liste de toutes les imprimantes disponibles sur le serveur.

    cups_array_t *pappl_client_get_printer_list(pappl_client_t *client);
    • client : Pointeur vers la structure pappl_client_t.
    • Retourne un tableau d'imprimantes (chaque élément est un pointeur vers pappl_printer_t), ou NULL en cas d'erreur. Utilisez cupsArrayDelete() pour libérer la mémoire.
    pappl_client_get_printer

    Récupère les détails d'une imprimante spécifique.

    pappl_printer_t *pappl_client_get_printer(pappl_client_t *client, const char *name);
    • client : Pointeur vers la structure pappl_client_t.
    • name : Nom de l'imprimante.
    • Retourne un pointeur vers une structure pappl_printer_t, ou NULL en cas d'erreur. La mémoire est gérée par le client et doit être libérée avec pappl_printer_free().
    pappl_client_create_printer

    Crée une nouvelle imprimante sur le serveur.

    pappl_printer_t *pappl_client_create_printer(pappl_client_t *client, const pappl_printer_t *printer);
    • client : Pointeur vers la structure pappl_client_t.
    • printer : Pointeur vers la structure pappl_printer_t contenant les informations de la nouvelle imprimante.
    • Retourne un pointeur vers la structure pappl_printer_t créée, ou NULL en cas d'erreur. La mémoire doit être libérée avec pappl_printer_free().
    pappl_client_update_printer

    • printer : Pointeur vers la structure pappl_printer_t contenant les informations mises à jour.
    • Retourne un pointeur vers la structure pappl_printer_t mise à jour, ou NULL en cas d'erreur. La mémoire doit être libérée avec pappl_printer_free().

    • Retourne un pointeur vers la structure pappl_service_t enregistrée, ou NULL en cas d'erreur. La mémoire doit être libérée avec pappl_service_free().
    pappl_client_unregister_service

    Désenregistre un service auprès du serveur Piment.

    bool pappl_client_unregister_service(pappl_client_t *client, const char *service_name);
    • client : Pointeur vers la structure pappl_client_t.
    • service_name : Nom du service à désenregistrer.
    • Retourne true en cas de succès, false en cas d'erreur.
    pappl_client_get_oauth_callback_url

    Récupère l'URL de rappel OAuth pour l'authentification.

    char *pappl_client_get_oauth_callback_url(pappl_client_t *client, const char *redirect_uri);
    • client : Pointeur vers la structure pappl_client_t.
    • redirect_uri : URI de redirection après l'authentification OAuth.
    • Retourne l'URL de rappel, ou NULL en cas d'erreur. Utilisez free() pour libérer la mémoire.
    pappl_client_get_oauth_userinfo

    Récupère les informations utilisateur via OAuth.

    char *pappl_client_get_oauth_userinfo(pappl_client_t *client, const char *access_token);
    • client : Pointeur vers la structure pappl_client_t.
    • access_token : Jeton d'accès OAuth.
    • Retourne les informations utilisateur (généralement en JSON), ou NULL en cas d'erreur. Utilisez free() pour libérer la mémoire.
    pappl_client_get_oauth_token

    Récupère un jeton d'accès OAuth.

    char *pappl_client_get_oauth_token(pappl_client_t *client, const char *code, const char *redirect_uri);
    • client : Pointeur vers la structure pappl_client_t.
    • code : Code d'autorisation reçu après le rappel OAuth.
    • redirect_uri : URI de redirection utilisée.
    • Retourne le jeton d'accès, ou NULL en cas d'erreur. Utilisez free() pour libérer la mémoire.
    pappl_client_get_oauth_end_session_url

    Récupère l'URL de fin de session OAuth.

    char *pappl_client_get_oauth_end_session_url(pappl_client_t *client, const char *id_token, const char *post_logout_redirect_uri);
    • client : Pointeur vers la structure pappl_client_t.
    • id_token : Jeton d'identification (ID token).
    • post_logout_redirect_uri : URI de redirection après la déconnexion.
    • Retourne l'URL de fin de session, ou NULL en cas d'erreur. Utilisez free() pour libérer la mémoire.
    pappl_client_get_job_data

    Récupère les données d'un travail d'impression.

    char *pappl_client_get_job_data(pappl_client_t *client, const char *printer_name, int job_id, size_t *data_len);
    • client : Pointeur vers la structure pappl_client_t.
    • printer_name : Nom de l'imprimante.
    • job_id : ID du travail d'impression.
    • data_len : Pointeur vers une variable size_t pour stocker la longueur des données.
    • Retourne les données du travail d'impression sous forme de chaîne allouée, ou NULL en cas d'erreur. Utilisez free() pour libérer la mémoire.
    pappl_client_get_job_data_stream

    Récupère les données d'un travail d'impression sous forme de flux.

    pappl_istream_t *pappl_client_get_job_data_stream(pappl_client_t *client, const char *printer_name, int job_id);
    • client : Pointeur vers la structure pappl_client_t.
    • printer_name : Nom de l'imprimante.
    • job_id : ID du travail d'impression.
    • Retourne un pointeur vers un flux de données, ou NULL en cas d'erreur. Utilisez pappl_istream_close() pour fermer le flux.

    STRUCTURES

    pappl_client_t

    Structure représentant une connexion client au serveur Piment. Elle contient des informations sur la connexion et l'état.

    pappl_printer_t

    Structure représentant une imprimante. Contient des champs comme le nom, l'URI, le modèle, les capacités, etc.

    pappl_job_t

    Structure représentant un travail d'impression. Contient des champs comme l'ID du travail, le nom de l'imprimante, le titre, l'état, etc.

    pappl_driver_t

    Structure représentant un pilote d'imprimante. Contient des informations sur le nom, le type, les options, etc.

    pappl_resource_t

    Structure représentant une ressource d'imprimante (ex: logo, page de garde).

    pappl_system_info_t

    Structure contenant des informations globales sur le système Piment (version, nom d'hôte, etc.).

    pappl_subscription_t

    Structure représentant un abonnement aux événements. Contient l'ID de l'abonnement, l'URL de notification, les types d'événements, etc.

    pappl_event_t

    Structure représentant un événement système ou d'imprimante.

    pappl_service_t

    Structure représentant un service enregistré auprès de Piment (ex: un fournisseur de services d'impression).

    pappl_media_t

    Structure représentant un format de papier.

    pappl_hal_media_t

    Structure représentant un format de papier tel que rapporté par le HAL.

    pappl_orientation_t

    Énumération représentant les orientations d'impression (portrait, paysage, etc.).

    pappl_ipp_t

    Structure représentant un objet IPP (par exemple, une file d'attente, une classe).

    pappl_printer_status_t

    Énumération représentant l'état d'une imprimante (ex: PAPPL_PRINTER_STATUS_IDLE, PAPPL_PRINTER_STATUS_PRINTING).

    RÉPONDRE AUX REQUÊTES DU CLIENT

    L'API client est principalement destinée à interroger l'état et à envoyer des commandes au serveur Piment. Les fonctions fournissent un moyen simple d'obtenir des listes, des détails et d'effectuer des actions comme la création ou la suppression d'imprimantes et de travaux.

    FORMULAIRES HTML

    Le serveur Piment utilise des formulaires HTML pour les interfaces d'administration et de configuration. L'API client n'interagit pas directement avec ces formulaires, mais les données retournées par l'API peuvent être utilisées pour générer ou interpréter des formulaires.

    AUTHENTIFICATION ET AUTORISATION

    La connexion au serveur Piment peut nécessiter une authentification via un nom d'utilisateur et un mot de passe. Certaines opérations peuvent être restreintes en fonction des droits de l'utilisateur authentifié. L'API gère la transmission des informations d'identification lors de la connexion.
