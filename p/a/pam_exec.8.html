NOM

pam_exec - Module PAM qui appelle une commande externe

SYNTAXE

pam_exec.so [debug] [expose_authtok] [seteuid] [quiet] [quiet_log] [stdout] [log=fichier] [type=type] commande [...]

DESCRIPTION

pam_exec est un module PAM qui peut être utilisé pour exécuter une commande externe.

L'environnement de l'enfant est défini sur la liste d'environnement PAM actuelle, telle que retournée par pam_getenvlist(3). De plus, les éléments PAM suivants sont exportés en tant que variables d'environnement : PAM_RHOST, PAM_RUSER, PAM_SERVICE, PAM_TTY, PAM_USER et PAM_TYPE, qui contient l'un des types de module : account, auth, password, open_session et close_session.

Les commandes appelées par pam_exec doivent être conscientes que l'utilisateur peut avoir le contrôle de l'environnement.

OPTIONS

debug

Imprime des informations de débogage.

expose_authtok

Pendant l'authentification et le changement de mot de passe, la commande appelante peut lire le mot de passe depuis stdin(3). Seuls les PAM_MAX_RESP_SIZE premiers octets d'un mot de passe sont fournis à la commande.

log=fichier

La sortie de la commande est ajoutée au fichier.

type=type

Exécuter la commande uniquement si le type de module correspond au type donné.

stdout

Par défaut, la sortie de la commande exécutée est écrite dans /dev/null. Avec cette option, la sortie stdout de la commande exécutée est redirigée vers l'application appelante. Il incombe à cette application de décider ce qu'il advient de la sortie. L'option log est ignorée.

quiet

Par défaut, pam_exec.so affichera le code de retour de la commande externe en cas d'échec. Spécifier cette option supprimera le message.

quiet_log

Par défaut, pam_exec.so enregistrera le code de retour de la commande externe en cas d'échec. Spécifier cette option supprimera le message de journalisation.

seteuid

Par défaut, pam_exec.so exécutera la commande externe avec l'ID utilisateur réel du processus appelant. Spécifier cette option signifie que la commande sera exécutée avec l'ID utilisateur effectif.

TYPES DE MODULE FOURNIS

Tous les types de module (auth, account, password et session) sont fournis.

VALEURS DE RETOUR

PAM_SUCCESS

La commande externe a été exécutée avec succès.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_CONV_ERR

La méthode de conversation fournie par l'application a échoué à obtenir le nom d'utilisateur.

PAM_INCOMPLETE

La méthode de conversation fournie par l'application a retourné PAM_CONV_AGAIN.

PAM_SERVICE_ERR

Aucun argument ou un nombre incorrect d'arguments n'a été donné.

PAM_SYSTEM_ERR

Une erreur système s'est produite ou la commande à exécuter a échoué.

PAM_IGNORE

pam_setcred a été appelé, ce qui n'exécute pas la commande. Ou, la valeur donnée pour le paramètre type= ne correspondait pas au type de module.

EXEMPLES

Ajoutez la ligne suivante à /etc/pam.d/passwd pour reconstruire la base de données NIS après chaque changement de mot de passe local :

        password optional pam_exec.so seteuid /usr/bin/make -C /var/yp

Cela exécutera la commande

make -C /var/yp

avec l'ID utilisateur effectif.
