NOM

patchmatrix_monitor - un moniteur de ports JACK

SYNOPSIS

patchmatrix_monitor [options]

DESCRIPTION

patchmatrix_monitor est un moniteur de ports JACK.

À utiliser en conjonction avec patchmatrix.

Livré avec le support de gestion de session JACK.

OPTIONS

-v

Afficher les informations sur la version et la licence

-h

Afficher les informations d'utilisation

-t type-port

Type de port (audio, midi)

-i nb-entrées

Nombre de ports d'entrée (1-128)

-n nom-serveur

Se connecter au démon JACK nommé
