PARTCLONE(8) Manuel de l'utilisateur Partclone PARTCLONE(8)

NOM

partclone - L'utilitaire pour cloner et restaurer une partition.

SYNTAXE

partclone.[type_fs] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] cible} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] logfile [-R | --rescue] [-L | --logfile] logfile [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPTION

partclone.[type_fs] fait partie du projet Partclone. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une plus grande compatibilité du système de fichiers en utilisant des bibliothèques existantes, par exemple, e2fslibs est utilisé pour lire le bloc utilisé de la partition ext2.

Les systèmes de fichiers pris en charge par Partclone incluent btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Il prend également en charge certains systèmes d'exploitation non-Linux, par exemple : NTFS, FAT et EXFAT (pour Windows), HFS plus (MAC OS APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) et MINIX (MINIX3).

Tous les utilitaires partclone peuvent être exécutés comme partclone.[type_fs] est très similaire à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, exécutez simplement partclone.hfsp

       Système de fichiers           partclone.[type_fs]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       autres (Système de fichiers non pris en charge)   partclone.imager

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-s FICHIER, --source FICHIER

FICHIER source. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique, selon votre action. Normalement, la source de sauvegarde est un périphérique, la source de restauration est un fichier image.

La réception de données depuis un pipeline n'est prise en charge QUE pour la restauration, ignorez simplement l'option -s ou utilisez '-' pour recevoir des données depuis l'entrée standard.

-o FICHIER, --output FICHIER

FICHIER de sortie. Le FICHIER peut être un fichier image (généré par partclone) ou un périphérique, selon votre action. Normalement, la sortie de sauvegarde va vers un fichier image et la sortie de restauration va vers un périphérique.

L'envoi de données vers un pipeline est également pris en charge UNIQUEMENT pour la sauvegarde, ignorez simplement l'option -o ou utilisez '-' pour envoyer des données vers la sortie standard.

-O FICHIER, --overwrite FICHIER

Écraser FICHIER, en écrasant s'il existe.

-W FICHIER, --restore_raw_file FICHIER

créer un fichier brut spécial pour le périphérique de boucle.

-c, --clone

Sauvegarder la partition dans le format d'image spécial.

-r, --restore

Restaurer la partition à partir du format d'image spécial.

-b, --dev-to-dev

Copie locale de périphérique à périphérique à la volée, la source et la sortie sont toutes deux des périphériques.

-D, --domain

Créer un fichier journal de domaine GNU Ddrescue à partir du périphérique source. C'est un fichier lisible par l'homme dans lequel + marque les zones de blocs utilisées et ? marque les zones libres.

--offset_domain=X

Ajoute X (en octets) à toutes les positions rapportées dans le fichier journal du domaine

--restore_raw_file

Création d'un fichier brut spécial pour le périphérique de boucle.

-L FICHIER, --logfile FICHIER

Placer un chemin spécial pour enregistrer les informations du journal partclone. (par défaut /var/log/partclone.log)

-R, --rescue

Continuer après les erreurs de lecture du disque.

-C, --no_check

Ne pas vérifier la taille du périphérique et l'espace libre.

-N, --ncurses

Utiliser l'interface utilisateur textuelle Ncurses.

-I, --ignore_fschk

Ignorer la vérification du système de fichiers.

-i, --ignore_crc

Ignorer l'erreur de vérification crc.

-F, --force

Forcer la progression.

-f sec, --UI-fresh sec

Définir un intervalle différent en secondes.

-z taille, --buffer_size taille

Taille du tampon de lecture/écriture (par défaut : 1048576)

-q, --quiet

Désactiver le message de progression.

-dniveau, --debug niveau

Définir le niveau de débogage [1|2|3]

-x, --compresscmd CMD

Démarrer CMD comme un pipeline de sortie pour compresser l'image clonée

-aX, --checksum-mode=X

Formule de somme de contrôle à utiliser pour ajouter la détection d'erreurs

où X :

0 : Pas de somme de contrôle (pas de ralentissement, image la plus petite)

1 : CRC32 (Rapide à calculer, détection de base)

2 : xxHash algorithme de hachage non cryptographique extrêmement rapide

-kX, --blocks-per-checksum=X

Écrire une somme de contrôle pour chaque X blocs

-w, --skip_write_error

Continuer la restauration en cas d'erreurs d'écriture

--write-direct-io

Écrire les données dans la partition CIBLE sans cache

--read-direct-io

Lire les données depuis la partition SOURCE sans cache

-B, --no_block_detail

Afficher le message de progression sans détails de bloc

--binary-prefix

Afficher la progression avec la taille en bits (par défaut, c'est Mo, Go...)

--prog-second

Afficher la progression en secondes (par défaut, c'est en minutes)

-E, --offset=X

Ajouter un décalage X (en octets) à la SORTIE

-T, --btfiles

Restaurer le bloc sous forme de fichier pour ClonezillaBT.

-t, --btfiles_torrent

Restaurer le bloc sous forme de fichier pour ClonezillaBT mais générer uniquement le torrent.

-n, --note NOTE

Afficher un message (128 mots maximum).

-h, --help

Afficher un résumé des options.

-v, --version

Afficher la version
partclone.xfs(8) — partclone — Arch Linux manual pages

NAME

partclone.xfs - partclone support for XFS filesystem

SYNOPSIS

partclone.xfs [-c] [-d] [-s source] [-o output]

partclone.xfs -r [-d] [-s source] [-o output]

DESCRIPTION

partclone.xfs is a partclone tool which supports XFS filesystem.

Partclone is a program that allows you to clone and restore a partition to an image file. It is similar to the concepts of Clonezilla and partedmagic.

Partclone works by reading a filesystem and writing the blocks that contain data to disk. Unused blocks are not written. This makes the image file smaller than using dd.

For Partclone to work, it needs to understand the filesystem type. For example, to clone an ext3 partition, you would use partclone.ext3.

The command line syntax for most partclone tools is the same.

-c
Clone, that is create an image file from a partition.
-r
Restore, that is restore a partition from an image file.
-s source
Source. This can be a device or an image file. Use '-' for stdin.
-o output
Output. This can be a device or an image file. Use '-' for stdout.
-d
Display debug information.

OPTIONS

See DESCRIPTION.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 Clone an XFS partition /dev/hda1 to hda1.img and display debug information.
   partclone.xfs -c -d -s /dev/hda1 -o hda1.img

 Restore an XFS partition /dev/hda1 from hda1.img and display debug information.
   partclone.xfs -r -d -s hda1.img -o /dev/hda1

 Restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.xfs-ptcl-img.gz.a* | gunzip -c | partclone.xfs -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
