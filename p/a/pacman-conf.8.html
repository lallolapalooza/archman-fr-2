NOM

pacman-conf - interroger le fichier de configuration de pacman

SYNTAXE

pacman-conf [options] [<directive> ...]

pacman-conf (--repo-list|--help|--version)

DESCRIPTION

pacman-conf est un utilitaire pour analyser le fichier de configuration pacman et retourner une sortie facilement utilisable par des scripts. Il est conçu pour gérer correctement les fonctionnalités de configuration non triviales telles que l'interpolation de variables et l'utilisation de la directive Include, et garantit qu'il retournera les mêmes valeurs de configuration que celles que pacman lui-même utiliserait.

pacman-conf affichera par défaut le contenu entièrement résolu du fichier de configuration, ou, si le nom d'une directive de configuration est fourni, affichera uniquement le contenu de cette directive.

OPTIONS

-c, --config <chemin>

Spécifier un fichier de configuration alternatif.

-R, --rootdir <chemin>

Spécifier une racine d'installation alternative (par défaut /).

-r, --repo <dépôt>

Interroger les options pour un dépôt spécifique.

-v, --verbose

Afficher toujours les noms des directives.

-l, --repo-list

Lister les dépôts configurés.

-h, --help

Afficher la syntaxe et les options de la ligne de commande.

-V, --version

Afficher la version et quitter.

EXEMPLES

pacman-conf -r core Usage

Afficher la valeur de l'option de configuration Usage pour le dépôt core.

pacman-conf HoldPkg

Afficher la valeur de l'option de configuration HoldPkg.
