NOM

pam_time - Module PAM pour le contrôle du temps d'accès

SYNTAXE

pam_time.so [conffile=fichier-conf] [debug] [noaudit]

DESCRIPTION

Le module PAM pam_time n'authentifie pas l'utilisateur, mais restreint l'accès à un système et/ou à des applications spécifiques à certains moments de la journée, certains jours de la semaine ou via différentes lignes terminal. Ce module peut être configuré pour refuser l'accès à des (utilisateurs individuels) en fonction de leur nom, de l'heure de la journée, du jour de la semaine, du service demandé et du terminal depuis lequel ils font leur requête.

Par défaut, les règles de contrôle d'accès par temps/port sont tirées du fichier de configuration /etc/security/time.conf. Un fichier alternatif peut être spécifié avec l'option conffile.

Si Linux PAM est compilé avec le support d'audit, le module signalera lorsqu'il refusera l'accès.

OPTIONS

conffile=/chemin/vers/time.conf

Indique un fichier de configuration de style time.conf alternatif pour remplacer celui par défaut.

debug

Imprime des informations de débogage via syslog(3).

noaudit

Ne signale pas les connexions à une heure non autorisée au sous-système d'audit.

TYPES DE MODULES FOURNIS

Seul le type account est fourni.

VALEURS DE RETOUR

PAM_SUCCESS

L'accès a été accordé.

PAM_ABORT

Toutes les données pertinentes n'ont pas pu être obtenues.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_PERM_DENIED

L'accès n'a pas été accordé.

PAM_USER_UNKNOWN

L'utilisateur n'est pas connu du système.

FICHIERS

/etc/security/time.conf

Fichier de configuration par défaut

EXEMPLES

#%PAM-1.0
#
# appliquer pam_time à la comptabilité des demandes de connexion
#
login  account  required  pam_time.so

VOIR AUSSI

time.conf(5), pam.d(5), pam(8).
