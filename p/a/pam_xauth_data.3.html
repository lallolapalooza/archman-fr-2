NOM

pam_xauth_data - structure contenant les données d'authentification X

SYNOPIS

#include <security/pam_appl.h>
struct pam_xauth_data {
    int namelen;
    char *name;
    int datalen;
    char *data;
};

DESCRIPTION

La structure pam_xauth_data contient les données d'authentification X utilisées pour établir une connexion à un écran X. En utilisant ce mécanisme, une application peut communiquer des données d'authentification X aux modules de service PAM. Cela permet aux modules d'établir une connexion à l'écran X de l'utilisateur afin de labelliser la session de l'utilisateur lors de la connexion, d'afficher un retour visuel ou à d'autres fins.

Le champ name contient le nom de la méthode d'authentification, tel que "MIT-MAGIC-COOKIE-1". Le champ namelen contient la longueur de cette chaîne, sans inclure le caractère NUL final.

Le champ data contient les données spécifiques à la méthode d'authentification correspondant au nom spécifié. Le champ datalen contient sa longueur en octets.

Les données d'authentification X peuvent être modifiées avec l'élément PAM_XAUTH_DATA. Elles peuvent être interrogées et définies avec pam_get_item(3) et pam_set_item (3) respectivement. La valeur utilisée pour la définir doit être un pointeur vers une structure pam_xauth_data. Une copie interne de la structure elle-même et de ses champs est effectuée par PAM lors de la définition de l'élément.

VOIR AUSSI

pam_start(3), pam_get_item(3),

NORMES

La structure pam_xauth_data et l'élément PAM_XAUTH_DATA sont des extensions de Linux-PAM.
