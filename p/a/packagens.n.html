pkg::create(n) Commandes intégrées Tcl pkg::create(n)

NOM

pkg::create - Construire une commande 'package ifneeded' appropriée pour une spécification de paquet donnée

SYNOPSIS

::pkg::create -name nomPaquet -version versionPaquet ?-load spécFichier? ... ?-source spécFichier? ...

DESCRIPTION

::pkg::create est une procédure utilitaire qui fait partie de la bibliothèque standard Tcl. Elle est utilisée pour créer une commande package ifneeded appropriée pour une spécification de paquet donnée. Elle peut être utilisée pour construire un fichier pkgIndex.tcl à utiliser avec le mécanisme package.

OPTIONS

Les paramètres supportés sont :

-name nomPaquet
Ce paramètre spécifie le nom du paquet. Il est requis.
-version versionPaquet
Ce paramètre spécifie la version du paquet. Il est requis.
-load spécFichier
Ce paramètre spécifie une bibliothèque binaire qui doit être chargée avec la commande load. spécFichier est une liste de deux éléments. Le premier élément est le nom du fichier à charger. Le second élément, optionnel, est une liste de commandes fournies par le chargement de ce fichier. Si la liste des procédures est vide ou omise, ::pkg::create configurera la bibliothèque pour un chargement direct (voir pkg_mkIndex). Un nombre quelconque de paramètres -load peut être spécifié.
-source spécFichier
Ce paramètre est similaire au paramètre -load, sauf qu'il spécifie une bibliothèque Tcl qui doit être chargée avec la commande source. Un nombre quelconque de paramètres -source peut être spécifié.

Au moins un paramètre -load ou -source doit être fourni.
