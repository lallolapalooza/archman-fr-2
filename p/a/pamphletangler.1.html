NOM

pamphletangler - Extrait des morceaux de code de fichiers brochure LaTeX.

SYNTAXE

pamphletangler [OPTION...] FICHIER NOMMORCEAU

DESCRIPTION

Le système de brochures clojure est un système basé sur le système littéraire clojure. Dans le système de brochures de clojure, vous avez votre fichier LaTeX principal, qui peut être compilé régulièrement. Ce fichier contient de la documentation et du code source (comme dans d'autres formes de programmation littéraire). Ces extraits de code sont encapsulés dans l'environnement 'chunk', ils peuvent donc être reconnus par le tangler afin de les extraire. Les morceaux peuvent être inclus les uns dans les autres par la commande 'getchunk' (qui sera mise en forme en conséquence). Enfin, vous exécutez votre fichier LaTeX à travers le tangler et obtenez votre morceau de code désiré.

OPTIONS

-L, --ligne=texteligne
S'il est défini, ce texte sera inséré après les sauts de ligne, remplaçant la chaîne dans "textedroit" par le numéro de ligne. Ceci est utilisé pour que le rapport d'erreur fasse référence au numéro de ligne de la brochure au lieu du numéro de ligne de sortie.
-C, --changer=textedroit
Par défaut "{}", c'est le texte qui sera remplacé par le numéro de ligne si l'option texteligne est spécifiée.
-?, --aide
Donne cette liste d'aide.
--usage
Donne un court message d'utilisation.
--man
Imprime la page de manuel.
-V, --version
Imprime la version du programme.
