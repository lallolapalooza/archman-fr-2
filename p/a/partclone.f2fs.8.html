PARTCLONE(8) Manuel utilisateur Partclone PARTCLONE(8)

NOM

partclone - L'utilitaire pour cloner et restaurer une partition.

SYNTAXE

partclone.[fstype] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] cible} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] logfile [-R | --rescue] [-L | --logfile] logfile [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPTION

partclone.[fstype] fait partie du projet Partclone. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une compatibilité accrue des systèmes de fichiers en utilisant des bibliothèques existantes, par exemple, e2fslibs est utilisé pour lire les blocs utilisés d'une partition ext2.

Les systèmes de fichiers pris en charge par Partclone incluent btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Prend également en charge certains systèmes d'exploitation non-linux, par exemple : NTFS, FAT et EXFAT (pour Windows), HFS plus (MAC OS APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) et MINIX (MINIX3).

Tous les utilitaires partclone peuvent être exécutés comme partclone.[fstype], ce qui est très similaire à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, exécutez simplement partclone.hfsp

       Système de fichiers                 partclone.[fstype]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       autres (FS non pris en charge)   partclone.imager

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-s FICHIER, --source FICHIER

FICHIER source. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique selon votre action. Normalement, la source de sauvegarde est un périphérique, la source de restauration est un fichier image.

La réception de données depuis un pipe n'est prise en charge QUE pour la restauration, ignorez simplement l'option -s ou utilisez '-' pour recevoir des données depuis stdin.

-o FICHIER, --output FICHIER

FICHIER de sortie. Le FICHIER peut être un fichier image (que partclone générera) ou un périphérique selon votre action. Normalement, la sortie de sauvegarde va vers un fichier image et la sortie de restauration vers un périphérique.

L'envoi de données vers un pipe est également pris en charge UNIQUEMENT pour la sauvegarde, ignorez simplement l'option -o ou utilisez '-' pour envoyer des données vers stdout.

-O FICHIER, --overwrite FICHIER

Écrase FICHIER, en écrasant s'il existe.

-W FICHIER, --restore_raw_file FICHIER

Crée un fichier brut spécial pour le périphérique de boucle.

-c, --clone

Sauvegarde la partition au format d'image spécial.

-r, --restore

Restaure la partition à partir du format d'image spécial.

-b, --dev-to-dev

Copie locale de périphérique à périphérique à la volée, la source et la sortie sont toutes deux des périphériques.

-D, --domain

Crée un fichier journal de domaine GNU Ddrescue à partir du périphérique source. C'est un fichier lisible par l'homme dans lequel + marque les zones de blocs utilisées et ? marque les zones libres.

--offset_domain=X

Ajoute X (en octets) à toutes les positions signalées dans le fichier journal de domaine

--restore_raw_file

Crée un fichier brut spécial pour le périphérique de boucle.

-L FICHIER, --logfile FICHIER

Spécifie un chemin spécial pour enregistrer les informations du journal partclone. (par défaut /var/log/partclone.log)

-R, --rescue

Continue après les erreurs de lecture du disque.

-C, --no_check

Ne vérifie pas la taille du périphérique ni l'espace libre.

-N, --ncurses

Utilise l'interface utilisateur textuelle Ncurses.

-I, --ignore_fschk

Ignore la vérification du système de fichiers.

-i, --ignore_crc

Ignore l'erreur de vérification CRC.

-F, --force

Force la progression.

-f sec, --UI-fresh sec

Spécifie l'intervalle en secondes pour la mise à jour de l'interface utilisateur.

-z taille, --buffer_size taille

Taille du tampon de lecture/écriture (par défaut : 1048576)

-q, --quiet

Désactive les messages de progression.

-dniveau, --debug niveau

Définit le niveau de débogage [1|2|3]

-x, --compresscmd CMD

Démarre CMD comme un pipe de sortie pour compresser l'image clonée

-aX, --checksum-mode=X

Formule de somme de contrôle à utiliser pour ajouter la détection d'erreurs

où X :

0 : Aucune somme de contrôle (pas de ralentissement, image la plus petite)

1 : CRC32 (Rapide à calculer, détection basique)

2 : xxHash algorithme de hachage non cryptographique extrêmement rapide

-kX, --blocks-per-checksum=X

Écrit une somme de contrôle pour tous les X blocs

-w, --skip_write_error

Continue la restauration en cas d'erreurs d'écriture

--write-direct-io

Écrit les données sur la partition CIBLE sans cache

--read-direct-io

Lit les données depuis la partition SOURCE sans cache

-B, --no_block_detail

Affiche le message de progression sans détail de bloc

--binary-prefix

Affiche la progression avec la taille en bits (par défaut : Mo, Go...)

--prog-second

Affiche la progression en secondes (par défaut : minutes)

-E, --offset=X

Ajoute un décalage X (octets) à la SORTIE

-T, --btfiles

Restaure les blocs sous forme de fichiers pour ClonezillaBT.

-t, --btfiles_torrent

Restaure les blocs sous forme de fichiers pour ClonezillaBT, mais ne génère que le torrent.

-n, --note NOTE

Affiche un message NOTE (128 mots).

-h, --help

Affiche un résumé des options.

-v, --version

Affiche la versi

partclone.ext3(8) — partclone — Man pages

NOM

partclone.ext3

sauvegarde et restaure une partition de système de fichiers ext3

SYNOPSIS

partclone.ext3 [-d] [-c] [-s source] [-o destination] [-C clonefile] [-N nrof] [-b block_size] [-q]

DESCRIPTION

partclone.ext3 est un programme qui permet de sauvegarder et de restaurer des partitions de système de fichiers ext3. Il est basé sur les utilitaires e2fsprogs et permet de sauvegarder uniquement les blocs utilisés du système de fichiers. Il peut également être utilisé pour cloner une partition ext3 directement sur une autre partition ext3.

Les options de partclone.ext3 sont les mêmes que celles de partclone(8).

Les options suivantes sont spécifiques à partclone.ext3:

-d, --debug
Active le mode de débogage.
-c, --clone
Mode de clonage. Permet de cloner une partition sur une autre partition.
-s, --source source
Spécifie le périphérique source (partition ou fichier image).
-o, --output destination
Spécifie le périphérique de destination (partition ou fichier image).
-C, --clonefile clonefile
Spécifie le fichier image de clone.
-N, --nrof nrof
Spécifie le numéro de la partition.
-b, --block_size block_size
Spécifie la taille des blocs.
-q, --quiet
Mode silencieux. Supprime la sortie de progression.

FICHIERS

/var/log/partclone.log

Le fichier journal de partclone

EXEMPLES

 cloner /dev/hda1 vers hda1.img et afficher les informations de débogage.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restaurer /dev/hda1 à partir de hda1.img et afficher les informations de débogage.
   partclone.ext3 -r -d -s hda1.img -o /dev/hda1
 restaurer une image de clonezilla (divisée, gzipée, ...) avec une source stdin
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

Les diagnostics suivants peuvent être émis sur stderr:

partclone fournit certains codes de retour qui peuvent être utilisés dans les scripts:

Code Diagnostic
0 Le programme s'est terminé avec succès.
1 Le clonage ou la restauration semblent avoir échoué.
