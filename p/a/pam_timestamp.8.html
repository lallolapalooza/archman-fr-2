NOM

pam_timestamp - Authentifier à l'aide de tentatives d'authentification réussies mises en cache

SYNTAXE

pam_timestamp.so [timestampdir=répertoire] [timestamp_timeout=nombre] [verbose] [debug]

DESCRIPTION

En bref, pam_timestamp met en cache les tentatives d'authentification réussies et permet d'utiliser une tentative réussie récente comme base pour l'authentification. Ceci est un mécanisme similaire à celui utilisé par sudo.

Lorsqu'une application ouvre une session avec pam_timestamp, un fichier d'horodatage est créé dans le répertoire timestampdir pour l'utilisateur. Lorsqu'une application tente d'authentifier l'utilisateur, pam_timestamp traitera un fichier d'horodatage suffisamment récent comme motif de succès.

OPTIONS

timestampdir=répertoire

Spécifiez un répertoire alternatif où pam_timestamp crée les fichiers d'horodatage.

timestamp_timeout=nombre

Combien de temps pam_timestamp doit-il considérer l'horodatage comme valide après sa dernière date de modification (en secondes). La valeur par défaut est 300 secondes.

verbose

Tenter d'informer l'utilisateur lorsque l'accès est accordé.

debug

Active les messages de débogage envoyés à syslog(3).

TYPES DE MODULES FOURNIS

Les types de modules auth et session sont fournis.

VALEURS DE RETOUR

PAM_AUTH_ERR

Le module n'a pas pu récupérer le nom d'utilisateur ou aucun fichier d'horodatage valide n'a été trouvé.

PAM_SUCCESS

Tout s'est bien passé.

PAM_SESSION_ERR

Le fichier d'horodatage n'a pas pu être créé ou mis à jour.

NOTES

Les utilisateurs peuvent être confus lorsqu'ils ne sont pas toujours invités à entrer leur mot de passe lors de l'exécution d'un programme donné. Certains utilisateurs commencent à taper des informations par réflexe avant de remarquer qu'on ne les leur demande pas.

EXEMPLES

auth sufficient pam_timestamp.so verbose
auth required   pam_unix.so
session required pam_unix.so
session optional pam_timestamp.so

FICHIERS

/var/run/pam_timestamp/...

fichiers et répertoires d'horodatage

VOIR AUSSI

pam_timestamp_check(8), pam.conf(5), pam.d(5), pam(8)
