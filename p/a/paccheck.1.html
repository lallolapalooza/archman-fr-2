NOM

paccheck - vérifier les paquets installés

SYNTAXE

paccheck [options] [<paquet>]...
paccheck (--help|--version)

DESCRIPTION

Vérifie les paquets installés. Des paquets supplémentaires peuvent être spécifiés via stdin. Si aucun paquet n'est fourni, tous les paquets installés seront vérifiés. Par défaut, seules les dépendances des paquets et les informations de base des fichiers sont vérifiées.

OPTIONS

--config=chemin
Définit un chemin de fichier de configuration alternatif.
--dbpath=chemin
Définit un chemin de base de données alternatif.
--root=chemin
Définit une racine d'installation alternative.
--sysroot=chemin
Définit une racine système alternative. Voir pacutils-sysroot(7).
--null[=sep]
Définit un séparateur alternatif pour les valeurs analysées à partir de stdin. Par défaut, un saut de ligne "\n" est utilisé comme séparateur. Si --null est utilisé sans spécifier sep, "NUL" sera utilisé.
--list-broken
N'affiche que les noms des paquets qui échouent aux vérifications sélectionnées.
--quiet
N'affiche des messages que si un problème est trouvé.
--recursive
Effectue récursivement des vérifications sur les dépendances des paquets également.
--depends
Vérifie que toutes les dépendances des paquets sont satisfaites.
--opt-depends
Vérifie que toutes les dépendances optionnelles des paquets sont satisfaites.
--files
Vérifie les fichiers des paquets par rapport à la base de données locale.
--file-properties
Vérifie les fichiers des paquets par rapport aux données MTREE.
--md5sum
Vérifie les sommes md5 des fichiers par rapport aux données MTREE.
--sha256sum
Vérifie les sommes sha256 des fichiers par rapport aux données MTREE.
--require-mtree
Traite les données MTREE manquantes comme une erreur pour --db-files et/ou --file-properties.
--db-files
Inclut les fichiers de base de données dans les vérifications --files et --file-properties. --files testera l'existence des fichiers desc, files, et mtree (avec --require-mtree) dans l'entrée de la base de données du paquet. --file-properties vérifiera les fichiers install et changelog dans la base de données du paquet le cas échéant.
--backup
Inclut les fichiers de sauvegarde dans les vérifications de modification de fichiers.
--noextract
Inclut les fichiers NoExtract dans les vérifications de modification de fichiers.
--noupgrade
Inclut les fichiers NoUpgrade dans les vérifications de modification de fichiers.
--help
Affiche les informations d'utilisation et quitte.
--version
Affiche les informations de version et quitte.

CAVEATS

paccheck détermine s'il faut lire les paquets à partir de stdin sur la base d'une vérification naïve utilisant isatty(3). Si paccheck est appelé dans un environnement, comme une fonction shell ou un script utilisé dans un pipeline, où stdin n'est pas connecté à un terminal mais ne contient pas de paquets à vérifier, paccheck devrait être appelé avec stdin fermé. Pour les shells compatibles POSIX, cela peut être fait avec "<&-".
