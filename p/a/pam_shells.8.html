NOM

pam_shells - Module PAM pour vérifier les shells de connexion valides

SYNOPSIS

pam_shells.so

DESCRIPTION

pam_shells est un module PAM qui n'autorise l'accès au système que si le shell de l'utilisateur est listé dans /etc/shells.

Il vérifie également si les fichiers nécessaires (par exemple, /etc/shells) sont des fichiers ordinaires et ne sont pas inscriptibles par tous.

OPTIONS

Ce module ne reconnaît aucune option.

TYPES DE MODULE FOURNIS

Les types de module auth et account sont fournis.

VALEURS DE RETOUR

PAM_AUTH_ERR

L'accès au système a été refusé.

PAM_SUCCESS

Le shell de connexion de l'utilisateur a été listé comme shell valide dans /etc/shells.

PAM_USER_UNKNOWN

L'utilisateur n'existe pas ou le shell de connexion de l'utilisateur n'a pas pu être déterminé.

PAM_SERVICE_ERR

Le module n'a pas pu obtenir le nom de l'utilisateur.

EXEMPLES

auth  required  pam_shells.so

VOIR AUSSI

shells(5), pam.conf(5), pam.d(5), pam(8)
