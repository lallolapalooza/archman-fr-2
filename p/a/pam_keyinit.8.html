NOM

pam_keyinit - Module d'initialisation de la session du keyring du noyau

SYNOPSIS

pam_keyinit.so [debug] [force] [revoke]

DESCRIPTION

Le module PAM pam_keyinit garantit que le processus appelant dispose d'un keyring de session autre que le keyring de session par défaut de l'utilisateur.

Le module vérifie si le keyring de session du processus est celui de user-session-keyring(7), et, si c'est le cas, en crée un nouveau session-keyring(7) pour le remplacer. Si un nouveau keyring de session est créé, il installera un lien vers le user-keyring(7) dans le keyring de session afin que les clés communes à l'utilisateur y soient automatiquement accessibles. Le keyring de session du processus appelant sera dorénavant hérité par tous ses enfants à moins qu'ils ne le substituent.

Afin de permettre à d'autres modules PAM de joindre des jetons au keyring, ce module fournit à la fois une composante auth (limitée à pam_setcred(3) et une composante session. Le keyring de session est créé dans le module appelé. De plus, ce module doit être inclus le plus tôt possible dans une configuration PAM.

Ce module est principalement destiné à être utilisé par les processus de connexion. Soyez conscient qu'après le remplacement du keyring de session, l'ancien keyring de session et les clés qu'il contient ne seront plus accessibles.

Ce module ne doit généralement pas être appelé par des programmes comme su, car il est généralement souhaitable que l'ensemble des clés se propage vers le contexte alternatif. Les clés ont leur propre système de permissions pour gérer cela.

Le paquet keyutils est utilisé pour manipuler les clés plus directement. Ceci peut être obtenu à partir de:

Keyutils[1]

OPTIONS

debug

Enregistre les informations de débogage avec syslog(3).

force

Force le remplacement inconditionnel du keyring de session du processus appelant.

revoke

Force la révocation du keyring de session du processus appelant à la sortie de celui-ci si le keyring de session a été créé pour ce processus en premier lieu.

TYPES DE MODULES FOURNIS

Seul le type de module session est fourni.

VALEURS DE RETOUR

PAM_SUCCESS

Ce module retournera généralement cette valeur.

PAM_AUTH_ERR

Erreur d'authentification.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_IGNORE

La valeur de retour doit être ignorée par le dispatch PAM.

PAM_SERVICE_ERR

Impossible de déterminer le nom d'utilisateur.

PAM_SESSION_ERR

Ce module retournera cette valeur si ses arguments sont invalides ou si une erreur système telle que ENOMEM se produit.

PAM_USER_UNKNOWN

Utilisateur inconnu.

EXEMPLES

Ajoutez cette ligne à vos entrées de connexion pour démarrer chaque session de connexion avec son propre keyring de session :

session  required  pam_keyinit.so

Cela empêchera les clés d'une session de fuiter vers une autre session pour le même utilisateur.
