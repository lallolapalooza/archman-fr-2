pas2ut(1) Outil de création de cas de test d'unité Free Pascal pas2ut(1)

NOM

pas2ut - L'outil de conversion d'unité Free Pascal en cas de test d'unité.

SYNTAXE

pas2ut [options] fichier_entree [fichier_sortie]

DESCRIPTION

pas2ut analyse le fichier d'entrée à la recherche de classes et de routines, et crée un cas de test pour toutes les classes et routines trouvées dans la section d'interface du fichier. Il peut générer une unité ou un fichier d'inclusion. Tous les tests sont créés avec un message d'échec standard. Par défaut, seuls les tests pour les membres publics, publiés et de visibilité par défaut des classes sont générés.

UTILISATION

pas2ut prend les options suivantes pour le moment :

--testparclasspar-defaut=liste
Spécifiez une liste d'identifiants séparés par des virgules pour les tests par défaut de chaque classe. Les éléments de la liste doivent être des identifiants pascal valides.
--message-echec=Msg
Définit le message pour l'instruction Fail() à l'intérieur de chaque méthode de test.
--limite=liste
Spécifiez une liste d'identifiants globaux séparés par des virgules pour lesquels générer des tests. Par défaut, des tests sont générés pour tous les identifiants globaux dans la section d'interface d'une unité.
--prefixe=nom
Définit le préfixe des noms de test (par défaut, Test). Un test est nommé d'après l'identifiant qu'il teste, avec ce préfixe.
--classe-test-unique
Utilise une seule classe de test pour chaque classe trouvée. Par défaut, une classe de cas de test est créée pour chaque classe de l'unité d'entrée.
--ignorer-classes
Ne génère pas de code de test pour les classes, uniquement pour les fonctions et procédures.
--ignorer-declaration
Ne génère pas de déclarations pour les tests, uniquement les implémentations.
--ignorer-defaut
Ignore les tests pour les membres de visibilité par défaut. Par défaut, ils sont générés, ainsi que les membres publics ou publiés.
--ignorer-echec
Ne crée pas d'instructions fail() dans les implémentations des routines de test.
--ignorer-champs
Ne génère pas de cas de test pour les champs des classes (uniquement pour les méthodes et les propriétés).
--ignorer-fonctions
Ne génère pas de tests pour les fonctions/procédures, uniquement pour les classes.
--ignorer-implementation
Ne génère pas d'implémentation (vide) pour les tests, seule une déclaration de classe est générée. (elle peut être complétée dans un IDE comme Lazarus ou MSIDE)
--ignorer-methodes
Ne génère pas de tests pour les méthodes des classes, uniquement pour les champs et les propriétés.
--ignorer-proprietés
Ne génère pas de tests pour les propriétés des classes, uniquement pour les champs et les méthodes.
--ignorer-propriete-defaut
Ne génère pas de test par défaut pour chaque propriété.
--ignorer-public
Ignore les tests pour les membres publics, seuls les membres protégés seront testés si --tester-protege est actif.
--ignorer-publie
Ne génère pas de tests pour les membres publiés, seuls les membres publics et par défaut seront testés.
--ignorer-enregistrement
Ne génère pas l'instruction RegisterTests.
--ignorer-configuration
Ne surcharge pas la méthode TTestCase.Setup() dans la classe générée.
--ignorer-desinstallation
Ne surcharge pas la méthode TTestCase.TearDown() dans la classe générée.
--ignorer-unite
Ne génère pas d'unité, juste un fichier d'inclusion.
--nom-classe-parent=nom
Définit le nom de la classe parente pour les classes de test générées. Par défaut, il s'agit de TTestCase ; cela peut être utilisé pour définir un autre nom de classe.
--tester-limites-propriete
Génère un test GetBounds pour chaque propriété.
--tester-longueur-max-propriete
Génère un test MaxLen pour chaque propriété.
--tester-notification-propriete
Génère un test Notify pour chaque propriété.
--tester-obligatoire-propriete
Génère un test Required pour chaque propriété.
--tester-protege
Génère également des tests pour les membres de classe protégés. Par défaut, les tests ne sont générés que pour les membres publics, publiés et de visibilité par défaut.
--nom-unite-test=nom
Définit le nom de l'unité générée (par défaut, il est tiré du nom du fichier de sortie)
--tiopf
Crée des tests tiopf (cela équivaut à spécifier les tests --par défaut, --limites, --obligatoire, --notification et --longueur maximale.)
--nom-classe-unite-test=nom
Définit le nom de la classe d'unité de test globale. À utiliser avec --classe-test-unique. Les options --limite et --testparclasspar-defaut peuvent être spécifiées plusieurs fois.
