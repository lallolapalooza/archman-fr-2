NOM

pacfile - affiche des informations sur les fichiers de paquets

SYNOPSIS

pacfile [options] <chemin>...
pacfile (--help|--version)

DESCRIPTION

Affiche les informations de fichiers à partir de la base de données locale des paquets.

OPTIONS

--config=chemin
Définit un chemin de fichier de configuration alternatif.
--dbpath=chemin
Définit un chemin de base de données alternatif.
--root=chemin
Définit une racine d'installation alternative.
--sysroot=chemin
Définit une racine système alternative. Voir pacutils-sysroot(7).
--package=nom_paquet
Limite les informations au paquet spécifié. Peut être spécifié plusieurs fois.
--check
Compare les valeurs de la base de données avec le système de fichiers.
--help
Affiche les informations d'utilisation et quitte.
--version
Affiche les informations de version et quitte.
