DESCRIPTION

Les fonctions d'imprimante PAPPL fournissent l'accès à l'objet imprimante. Les imprimantes sont créées et supprimées par l'application d'impression tandis que le cycle de vie des objets pappl_printer_t est géré automatiquement par l'objet système pour l'application d'impression.

La fonction papplPrinterCreate crée une nouvelle imprimante tandis que la fonction papplPrinterDelete supprime une imprimante.

La fonction papplPrinterPause arrête une imprimante tandis que la fonction papplPrinterResume démarre une imprimante.

Les fonctions papplPrinterGet récupèrent les valeurs actuelles associées à une imprimante tandis que les fonctions papplPrinterSet définissent les valeurs actuelles associées à une imprimante.

Les fonctions papplPrinterCancelAddJobs, papplPrinterFindJob, papplPrinterGetNumberOfActiveJobs, papplPrinterGetNumberOfCompletedJobs, papplPrinterGetNumberOfJobs, papplPrinterIterateActiveJobs, papplPrinterIterateAllJobs, et papplPrinterIterateCompletedJobs fournissent l'accès aux travaux mis en queue sur une imprimante.

La fonction papplPrinterOpenDevice fournit l'accès à l'appareil associé à une imprimante lorsqu'il ne traite pas un travail. L'appareil doit être ultérieurement fermé en utilisant la fonction papplPrinterCloseDevice afin que l'imprimante puisse reprendre le traitement des travaux.

papplPrinterCreate

Créer une nouvelle imprimante.

pappl_printer_t * papplPrinterCreate (
    pappl_system_t *system,
    int printer_id,
    const char *printer_name,
    const char *driver_name,
    const char *device_id,
    const char *device_uri
);

Cette fonction crée une nouvelle imprimante (service) sur le système spécifié. L'argument "type" spécifie le type de service à créer et doit actuellement être la valeur PAPPL_SERVICE_TYPE_PRINT.

L'argument "printer_id" spécifie un identifiant entier positif unique pour le système. Si vous spécifiez une valeur de 0, un nouvel identifiant sera attribué.

L'argument "driver_name" spécifie un pilote nommé pour l'imprimante, parmi la liste des pilotes enregistrés avec la fonction papplSystemSetPrinterDrivers.

Les arguments "device_id" et "device_uri" spécifient l'identifiant de périphérique IEEE-1284 et les chaînes d'URI de périphérique pour l'imprimante.

En cas d'erreur, cette fonction définit la variable errno à l'une des valeurs suivantes:

  • EEXIST: Une imprimante avec le nom spécifié existe déjà.
  • EINVAL: Des valeurs incorrectes ont été spécifiées pour les arguments.
  • EIO: L'appel de rappel du pilote a échoué.
  • ENOENT: Aucun appel de rappel de pilote n'a été défini.
  • ENOMEM: Mémoire insuffisante.</li> </ul>

papplPrinterOpenFile

Créer ou ouvrir un fichier pour une imprimante.

int  papplPrinterOpenFile (
    pappl_printer_t *printer,
    char *fname,
    size_t fnamesize,
    const char *directory,
    const char *resname,
    const char *ext,
    const char *mode
);

Cette fonction crée, ouvre ou supprime un fichier pour une imprimante. Les arguments "fname" et "fnamesize" spécifient l'emplacement et la taille d'un tampon pour stocker le nom du fichier de l'imprimante, qui incorpore les valeurs "directory", ID de l'imprimante, nom de ressource et "ext". Le nom de la ressource est "nettoyé" pour ne contenir que des caractères alphanumériques.

L'argument "mode" est "r" pour lire un fichier d'imprimante existant, "w" pour écrire un nouveau fichier d'imprimante, ou "x" pour supprimer un fichier d'imprimante existant. Les nouveaux fichiers sont créés avec des permissions restreintes pour des raisons de sécurité.

Pour les modes "r" et "w", la valeur de retour est le descripteur de fichier en cas de succès, ou -1 en cas d'erreur. Pour le mode "x", la valeur de retour est 0 en cas de succès et -1 en cas d'erreur. La variable errno est correctement définie en cas d'erreur.

Cette fonction définit le groupe d'autorisation de l'imprimante. Si NULL, le groupe est effacé.

5

papplPrinterSetUSB

Définit les identifiants de vendeur et de produit USB pour une imprimante.

void papplPrinterSetUSB (
    pappl_printer_t *printer,
    unsigned vendor_id,
    unsigned product_id,
    pappl_uoptions_t options,
    const char *storagefile,
    pappl_pr_usb_cb_t usb_cb,
    void *usb_cbdata
);

Cette fonction définit les identifiants de vendeur et de produit USB pour une imprimante, ainsi que les options du gadget USB lors de l'enregistrement de l'imprimante auprès du contrôleur de périphérique USB.

L'argument usb_cb spécifie une fonction de rappel de traitement qui est appelée pour chaque octet de données envoyé depuis l'hôte USB et qui est responsable de l'interprétation des données, de l'écriture des données sur l'appareil et de la gestion des données de canal arrière.

5
Note : La fonctionnalité de gadget USB n'est actuellement disponible que lors de l'exécution
5
sous Linux avec du matériel compatible tel que le Raspberry Pi Zero et 4B.
