NOM

pam_stress - Le module PAM pour les tests de stress

SYNTAXE

pam_stress.so [debug] [no_warn] [use_first_pass] [try_first_pass] [rootok] [expired] [fail_1] [fail_2] [prelim] [required]

DESCRIPTION

Le module PAM pam_stress est principalement destiné à donner l'impression d'échouer, comme pourrait le faire un module pleinement fonctionnel.

OPTIONS

debug

Écrit beaucoup d'informations dans syslog. *NOTE* cette option écrit les mots de passe dans syslog, n'utilisez donc rien de sensible lors des tests.

no_warn

Ne génère pas d'avertissements concernant les choses (sinon les avertissements sont émis via la fonction de conversation)

use_first_pass

Ne demande pas de mot de passe, pour la fonction pam_sm_authentication utilise simplement l'élément PAM_AUTHTOK.

try_first_pass

Ne demande pas de mot de passe à moins qu'il n'y ait pas eu de jeton d'authentification précédent (l'élément PAM_AUTHTOK est NULL)

rootok

Ceci est prévu pour la fonction pam_sm_chauthtok et elle instruit cette fonction de permettre à root de changer le mot de passe de l'utilisateur sans entrer l'ancien mot de passe.

expired

Un argument prévu pour les parties du module de compte et de changement de mot de passe. Il instruit le module d'agir comme si le mot de passe de l'utilisateur avait expiré.

fail_1

Ceci instruit le module de faire échouer sa première fonction.

fail_2

Ceci instruit le module de faire échouer sa deuxième fonction (s'il y en a une).

prelim

Pour pam_sm_chauthtok, signifie échec sur PAM_PRELIM_CHECK.

required

Pour pam_sm_chauthtok, signifie échec si l'utilisateur n'a pas déjà été authentifié par ce module. (Voir la chaîne de données stress_new_pwd dans les NOTES.)

TYPES DE MODULES FOURNIS

Tous les types de modules (auth, account, password et session) sont fournis.

VALEURS DE RETOUR

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_PERM_DENIED

Permission refusée.

PAM_AUTH_ERR

L'accès au système a été refusé.

PAM_CONV_ERR

Échec de la conversation.

PAM_SUCCESS

La fonction passe toutes les vérifications.

PAM_USER_UNKNOWN

L'utilisateur n'est pas connu du système.

PAM_CRED_ERR

Échec lié aux informations d'identification de l'utilisateur.

PAM_NEW_AUTHTOK_REQD

Le jeton d'authentification n'est plus valide ; un nouveau est requis.

PAM_SESSION_ERR

Échec de session.

PAM_TRY_AGAIN

Vérification préliminaire par le service échouée.

PAM_AUTHTOK_LOCK_BUSY

Le verrouillage du jeton d'authentification est occupé.

PAM_AUTHTOK_ERR

Erreur de manipulation du jeton d'authentification.

PAM_SYSTEM_ERR

Erreur système.

NOTES

Ce module utilise la chaîne de données stress_new_pwd qui indique à pam_sm_chauthtok que pam_sm_acct_mgmt dit que nous avons besoin d'un nouveau mot de passe. La seule valeur possible pour cette chaîne de données est 'yes'.

EXEMPLES

#%PAM-1.0
#
# L'un des éléments suivants suffit
account  required pam_stress.so
auth     required pam_stress.so
password required pam_stress.so
session  required pam_stress.so

VOIR AUSSI

pam.conf(5), pam.d(5), pam(8).
