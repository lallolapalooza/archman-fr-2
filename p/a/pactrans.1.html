NOM

pactrans, pacinstall, pacremove - installer/supprimer des paquets alpm

SYNTAXE

pactrans   [options] <cible>...
pacinstall [options] <cible>...
pacremove  [options] <cible>...
pactrans   (--help|--version)

DESCRIPTION

Installe/supprime des paquets alpm. Les alias pacinstall et pacremove sont fournis par commodité, ne différant que par leur interprétation par défaut des cibles. Sinon, ils sont identiques.

Si stdin n'est pas connecté à un terminal, les pkgspecs à installer/supprimer seront lus depuis stdin.

OPTIONS

Opérations

Les options d'opération affectent l'interprétation de toutes les cibles qui les suivent jusqu'à ce qu'une autre option d'opération soit rencontrée.

--spec (par défaut pactrans)
Interprète les cibles suivantes comme des pkgspecs. Si un pkgspec indique un fichier de paquet ou un paquet de dépôt, il sera installé. S'il indique un paquet dans la base de données locale, il sera supprimé. Voir PKGSPEC pour les détails du format.
--install (par défaut pacinstall)
Interprète les cibles suivantes comme des paquets à installer depuis un dépôt. Si seul le nom du paquet est fourni, les dépôts seront recherchés dans l'ordre où ils sont déclarés.
--remove (par défaut pacremove)
Interprète les cibles suivantes comme des noms de paquets à désinstaller.
--file
Interprète les cibles suivantes comme des chemins vers des fichiers de paquets à installer.
--sysupgrade
Met à jour les paquets installés.

Options de configuration

--cachedir=chemin
Définit un chemin de répertoire de cache alternatif.
--config=chemin
Définit un chemin de fichier de configuration alternatif.
--dbext=extension
Définit une extension de base de données de synchronisation alternative.
--dbpath=chemin
Définit un chemin de base de données alternatif.
--logfile=chemin
Définit un chemin de fichier journal alternatif.
--root=chemin
Définit une racine d'installation alternative.
--sysroot=chemin
Définit une racine système alternative. Voir pacutils-sysroot(7).
--null[=sep]
Définit un séparateur alternatif pour les valeurs analysées depuis stdin. Par défaut, une nouvelle ligne "\n" est utilisée comme séparateur. Si --null est utilisé sans spécifier sep, "NUL" sera utilisé.
--debug
Affiche des informations de débogage supplémentaires.
--print-only
Affiche ce que la transaction ferait et quitte.
--no-confirm
Assume les réponses par défaut à toutes les invites.
--no-timeout
Désactive les timeouts à faible vitesse pour les téléchargements.
--help
Affiche les informations d'utilisation et quitte.
--version
Affiche les informations de version et quitte.

Options de transaction

--dbsync
Met à jour les bases de données de synchronisation avant d'effectuer la transaction.
--dbonly
Apporte les modifications à la base de données sans extraire ni supprimer réellement de paquets.
--nodeps
Ignore les versions des dépendances. Passez deux fois pour ignorer complètement les vérifications de dépendances.
--no-scriptlet
N'exécute pas les scripts d'installation des paquets.
--no-hooks
N'exécute pas les hooks de transaction.
--assume-installed=paquet[=version]
Se comporte comme si le paquet était installé.

Options de mise à jour système

--ignore-pkg=paquet
Ignore les mises à jour pour le paquet paquet. paquet peut être un motif glob de style shell.
--ignore-group=groupe
Ignore les mises à jour pour tous les paquets du groupe groupe. groupe peut être un motif glob de style shell.

Options --install/--file

--as-deps
Marque tous les paquets installés comme dépendances.
--as-explicit
Marque tous les paquets installés comme explicitement installés.
--download-only
Télécharge les paquets sans les installer réellement.

Options --remove

--cascade
Désinstalle tous les paquets installés qui dépendent d'un paquet en cours de désinstallation.
--no-backup
Ne sauvegarde pas les sauvegardes .pacsave.
--recursive
Désinstalle les dépendances des paquets en cours de suppression qui ne sont pas requises par d'autres paquets.
--unneeded
Ne désinstalle aucun paquet requis par un paquet installé.

Options de disposition des invites

--resolve-conflicts=méthode
Sélectionne une méthode à utiliser pour résoudre les conflits. Les valeurs possibles pour méthode sont :
"prompt"
Invite l'utilisateur à supprimer le paquet conflictuel installé.
"none"
Ne supprime aucun paquet conflictuel.
"all"
Supprime tous les paquets conflictuels.
"provided"
Supprime un paquet conflictuel si le nouveau paquet le fournit.
"depends"
Supprime un paquet conflictuel s'il a été installé comme dépendance.
"provided-depends"
Supprime un paquet conflictuel s'il a été installé comme dépendance et que le nouveau paquet le fournit.
--resolve-replacements=méthode
Sélectionne une méthode à utiliser pour résoudre les remplacements. Les valeurs possibles pour méthode sont :
"prompt"
Invite l'utilisateur à remplacer le paquet.
"none"
Ne remplace aucun paquet.
"all"
Effectue tous les remplacements de paquets disponibles.
"provided"
Effectue les remplacements où le nouveau paquet fournit l'ancien.
"depends"
Effectue les remplacements où l'ancien paquet a été installé comme dépendance.
"provided-depends"
Effectue les remplacements où l'ancien paquet a été installé comme dépendance et que le nouveau paquet

NAME

pactrans — transfer packages between repositories

SYNOPSIS

pactrans [options] pkgspec...

pactrans [options] --import | --remove

DESCRIPTION

pactrans is a frontend to pacman that allows you to transfer packages between repositories. It can install packages from one repository and remove them from another, or install new packages. It relies on pacman's transaction capabilities and therefore uses the same configuration file (/etc/pacman.conf).

Packages are identified by pkgspecs. A pkgspec may consist of a repository name and a package name, e.g. "core/pacman", or a full path to a package file.

By default, pactrans attempts to install all packages specified on the command line, and remove any packages that have the same name and are installed from a different repository. This behavior can be modified with the options below.

OPTIONS

The following options are available:

--no-confirm
Do not ask for confirmation.
--nodeps
Do not check dependencies.
--dbpath=path
Use an alternate local package database. Default is /var/lib/pacman/.
--cachedir=path
Use an alternate directory for package files. Default is /var/cache/pacman/pkg/.
--logdir=path
Use an alternate directory for log files. Default is /var/log/pacman.log.
--config=path
Use an alternate configuration file. Default is /etc/pacman.conf.
--root=path
Use an alternate root directory. Default is /.
--target=repo
Only transfer packages to and from the specified repository. This option is implied when packages are specified with a repository name, e.g. "core/pacman".
--install
Install packages. By default, packages will be removed from their original repository if they exist.
--remove
Remove packages. Packages will be removed from all repositories they are installed from.
--print
Print the transaction to stdout, do not execute it.
--test
Print the transaction to stdout, and exit successfully. Same as "--print".
--confirm=prompt|yes|no
Set the disposition for prompts to confirm a transaction.
--progress=prompt|yes|no
Set the disposition for prompts to show download progress.
--interfere=prompt|yes|no
Set the disposition for prompts to replace packages that conflict with the target packages.
--overwrite=prompt|yes|no
Set the disposition for prompts to overwrite files owned by other packages.
--install-ignored-packages=prompt|yes|no
Set the disposition for prompts to install ignored packages.
--delete-corrupt-files=prompt|yes|no
Set the disposition for prompts to delete corrupt package.
--use-first-provider=prompt|yes|no
Set the disposition for prompts to select a provider. If set to "yes", the first available provider will be selected.
--skip-unresolvable=prompt|yes|no
Set the disposition for prompts to skip packages with unresolvable dependencies.
--import-pgp-keys=prompt|yes|no
Set the disposition for prompts to import missing PGP keys.
--yolo
Set all prompt disposition options to their "all" or "yes" value and set --no-confirm.

NOTE: regardless of the disposition options chosen, all dependencies must still be satisfied in order for the transaction to succeed unless --nodeps is used as well.

PKGSPEC

A pkgspec is a string that can identify an individual package. Accepted formats are:

<repository>/<package>
core/pacman
<proto>://<path/to/package/file>
file:///var/cache/pacman/pkg/pacman-4.1.0-1-x86_64.pkg.tar.xz

EXAMPLES

Replace foo with bar
pactrans local/foo baz/bar

Or, if bar's repository is unknown:

pacinstall bar --remove foo
Install foo and bar:
pactrans --install foo bar

CAVEATS

pactrans determines whether or not to read pkgspecs from stdin based on a naive check using isatty(3). If pactrans is called in an environment, such as a shell function or script being used in a pipe, where stdin is not connected to a terminal but does not contain pkgspecs to install/remove, pactrans should be called with stdin closed. For POSIX-compatible shells, this can be done with "<&-".
