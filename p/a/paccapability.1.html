NOM

paccapability - interroger les capacités de libalpm

SYNTAXE

paccapability [options] [<capacité>...]
paccapability (--help|--version)

DESCRIPTION

paccapability fournit un moyen d'interroger les fonctionnalités avec lesquelles libalpm a été compilé. Les capacités reconnues sont :

  • ALPM_CAPABILITY_NLS
  • ALPM_CAPABILITY_DOWNLOADER
  • ALPM_CAPABILITY_SIGNATURES

Les capacités sont insensibles à la casse et peuvent omettre le préfixe "ALPM_CAPABILITY_". Si aucune capacité n'est fournie, toutes les capacités activées seront imprimées, une par ligne. Sinon, chaque capacité fournie sera imprimée, une par ligne, suivie d'un un ou zéro pour indiquer si la fonctionnalité est activée ou désactivée, respectivement. Si des capacités données sont désactivées, paccapability se terminera avec une valeur non nulle.

OPTIONS

--help
Afficher les informations d'utilisation et quitter.
--version
Afficher les informations de version et quitter.

EXEMPLES

Vérifier si libalpm a été compilé avec la vérification de signature :
paccapability signatures >/dev/null && ...
