pacat(1) Manuel des commandes générales pacat(1)

NOM

pacat - Lire ou enregistrer des flux audio bruts ou encodés sur un serveur son PulseAudio

SYNTAXE

paplay [options] [FICHIER]

parecord [options] [FICHIER]

pacat [options] [FICHIER]

parec [options] [FICHIER]

pamon [options] [FICHIER]

pacat --help

pacat --version

DESCRIPTION

pacat est un outil simple pour lire ou capturer des fichiers audio bruts ou encodés sur un serveur son PulseAudio. Il comprend tous les formats de fichiers audio pris en charge par libsndfile.

OPTIONS

-h | --help
Afficher l'aide.
--version
Afficher les informations sur la version.
-r | --record
Capturer les données audio et les écrire dans le fichier spécifié ou dans STDOUT si aucun n'est spécifié. Si l'outil est appelé sous le nom parec, c'est le comportement par défaut.
-p | --playback
Lire les données audio depuis le fichier spécifié ou depuis STDIN si aucun n'est spécifié, et les lire. Si l'outil est appelé sous le nom pacat, c'est le comportement par défaut.
-v | --verbose
Activer le mode verbeux. Affiche l'heure de lecture actuelle sur STDERR pendant la lecture/capture.
-s | --server=SERVEUR
Choisir le serveur auquel se connecter.
-d | --device=CANALSOUSOURCE
Spécifier le nom symbolique du canal de sortie/source sur lequel lire/à partir duquel enregistrer ce flux. Les noms spéciaux , et peuvent être utilisés pour spécifier le canal de sortie, la source et le moniteur par défaut respectivement.
--monitor-stream=INDEX
Enregistrer à partir de l'entrée du canal de sortie avec l'index INDEX.
-n | --client-name=NOM
Spécifier le nom du client que paplay doit passer au serveur lors de la connexion.
--stream-name=NOM
Spécifier le nom du flux que paplay doit passer au serveur lors de la création du flux.
--volume=VOLUME
Spécifier le volume de lecture initial à utiliser. Choisir une valeur entre 0 (silencieux) et 65536 (volume 100%).
--rate=TAUXECHANTILLONNAGE
Capturer ou lire l'audio avec le taux d'échantillonnage spécifié. Par défaut 44100 Hz.
--format=FORMAT
Capturer ou lire l'audio avec le format d'échantillon spécifié. Voir https://www.freedesktop.org/wiki/Software/PulseAudio/Documentation/User/SupportedAudioFormats/ pour les valeurs prises en charge. Par défaut s16ne.
--channels=CANAUX
Capturer ou lire l'audio avec le nombre de canaux spécifié. Si plus de deux canaux sont utilisés, il est recommandé d'utiliser l'option --channel-map ci-dessous. Par défaut 2.
--channel-map=CARTECANAUX
Choisir explicitement une carte de canaux lors de la lecture de ce flux. L'argument doit être une liste de noms de canaux séparés par des virgules : front-left, front-right, mono, front-center, rear-left, rear-right, rear-center, lfe, front-left-of-center, front-right-of-center, side-left, side-right, top-center, top-front-center, top-front-left, top-front-right, top-rear-left, top-rear-right, top-rear-center, ou l'un des 32 noms de canaux auxiliaires aux0 à aux31.
--fix-format
Si spécifié, le format d'échantillon du flux est changé pour le format natif du canal de sortie auquel le flux est connecté.
--fix-rate
Si spécifié, le taux d'échantillonnage du flux est changé pour le taux natif du canal de sortie auquel le flux est connecté.
--fix-channels
Si spécifié, le nombre de canaux et la carte de canaux du flux sont changés pour le nombre natif de canaux et la carte de canaux native du canal de sortie auquel le flux est connecté.
--no-remix
Ne jamais upmixer ou downmixer les canaux.
--no-remap
Ne jamais remapper les canaux. Au lieu de mapper les canaux par leur nom, cela les fera correspondre uniquement par leur index/ordre.
--latency=OCTETS
Configurer explicitement la latence, avec une durée spécifiée en octets dans le format d'échantillon sélectionné. Si omise, le serveur choisira la latence, généralement relativement élevée pour des raisons d'économie d'énergie. Utilisez soit cette option, soit --latency-msec, mais pas les deux.
--latency-msec=MSEC
Configurer explicitement la latence, avec une durée spécifiée en millisecondes. Si omise, le serveur choisira la latence, généralement relativement élevée pour des raisons d'économie d'énergie. Utilisez soit cette option, soit --latency, mais pas les deux.
--process-time=OCTETS
Configurer explicitement le temps de traitement, avec une durée spécifiée en octets dans le format d'échantillon sélectionné. Si omis, le serveur choisira le temps de traitement. Utilisez soit cette option, soit --process-time-msec, mais pas les deux.
--process-time-msec=MSEC
Configurer explicitement le temps de traitement, avec une durée spécifiée en millisecondes. Si omis, le serveur choisira le temps de traitement. Utilisez soit cette option, soit --process-time, mais pas les deux.
--property=PROPRIETE=VALEUR
Attacher une propriété au client et au flux. Peut être utilisée plusieurs fois.
--raw
Lire/enregistrer des données audio brutes. C'est le comportement par défaut si ce programme est invoqué sous les noms pacat, parec ou pamon.
--file-format[=FORMATFICHIER]
Lire/enregistrer des données audio encodées dans le format de fichier spécifié. C'est le comportement par défaut si ce programme est invoqué sous les noms paplay et parecord.
--list-file-formats
Lister les formats de fichiers pris en charge.

LIMITATIONS

En raison d'une limitation dans libsndfile, paplay ne définit actuellement pas toujours la carte de canaux correcte pour la lecture de fichiers audio multicanaux (c'est-à-dire surround), même si les informations de la carte de canaux sont disponibles dans le fichier audio.
