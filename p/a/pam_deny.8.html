NOM

pam_deny - Le module PAM de blocage

SYNTAXE

pam_deny.so

DESCRIPTION

Ce module peut être utilisé pour refuser l'accès. Il indique toujours un échec à l'application via le framework PAM. Il peut être approprié pour les entrées par défaut (la section OTHER).

OPTIONS

Ce module ne reconnaît aucune option.

TYPES DE MODULES FOURNIS

Tous les types de modules (account, auth, password et session) sont fournis.

VALEURS DE RETOUR

PAM_AUTH_ERR

Ceci est renvoyé par les services de compte et d'authentification.

PAM_CRED_ERR

Ceci est renvoyé par la fonction setcred.

PAM_AUTHTOK_ERR

Ceci est renvoyé par le service de mot de passe.

PAM_SESSION_ERR

Ceci est renvoyé par le service de session.

EXEMPLES

#%PAM-1.0
#
# Si nous n'avons pas d'entrées de configuration pour un service,
# les entrées OTHER sont utilisées. Pour être sécurisé, avertissez et refusez
# l'accès à tout.
other auth     required       pam_warn.so
other auth     required       pam_deny.so
other account  required       pam_warn.so
other account  required       pam_deny.so
other password required       pam_warn.so
other password required       pam_deny.so
other session  required       pam_warn.so
other session  required       pam_deny.so

VOIR AUSSI

pam.conf(5), pam.d(5), pam(8)
