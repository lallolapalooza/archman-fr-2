NOM

panel - extension de pile de panneaux pour curses

SYNOPIS

#include <panel.h>
PANEL *new_panel(WINDOW *win);
int bottom_panel(PANEL *pan);
int top_panel(PANEL *pan);
int show_panel(PANEL *pan);
void update_panels(void);
int hide_panel(PANEL *pan);
WINDOW *panel_window(const PANEL *pan);
int replace_panel(PANEL *pan, WINDOW *window);
int move_panel(PANEL *pan, int starty, int startx);
int panel_hidden(const PANEL *pan);
PANEL *panel_above(const PANEL *pan);
PANEL *panel_below(const PANEL *pan);
int set_panel_userptr(PANEL *pan, const void *ptr);
const void *panel_userptr(const PANEL *pan);
int del_panel(PANEL *pan);
/* Extensions ncurses */
PANEL *ground_panel(SCREEN *sp);
PANEL *ceiling_panel(SCREEN *sp);

DESCRIPTION

Les panneaux sont des fenêtres curses(3X) avec la propriété ajoutée de profondeur. Les fonctions de panneau permettent d'utiliser des fenêtres empilées et garantissent que les portions appropriées de chaque fenêtre et de la fenêtre curses stdscr sont cachées ou affichées lorsque les panneaux sont ajoutés, déplacés, modifiés ou supprimés. L'ensemble des panneaux actuellement visibles constitue la pile de panneaux. La fenêtre stdscr se trouve sous tous les panneaux et n'est pas considérée comme faisant partie de la pile.

Une fenêtre est associée à chaque panneau. Les routines de panneau vous permettent de créer, déplacer, cacher et montrer des panneaux. Vous pouvez repositionner un panneau à n'importe quelle position souhaitée dans la pile.

Les routines de panneau sont une couche fonctionnelle ajoutée à curses, elles n'utilisent que des appels curses de haut niveau et fonctionnent partout où curses fonctionne.

FONCTIONS

bottom_panel

bottom_panel(pan) place le panneau pan au bas de tous les panneaux.

ceiling_panel

ceiling_panel(sp) agit comme panel_below(NULL) pour le SCREEN sp donné.

del_panel

del_panel(pan) supprime le panneau donné pan de la pile et désalloue la structure PANEL (mais pas sa fenêtre associée).

ground_panel

ground_panel(sp) agit comme panel_above(NULL) pour le SCREEN sp donné.

hide_panel

hide_panel(pan) retire le panneau donné pan de la pile de panneaux et le cache donc de la vue. La structure PANEL n'est pas perdue, simplement retirée de la pile.

move_panel

move_panel(pan, starty, startx) déplace la fenêtre du panneau pan donné afin que son coin supérieur gauche soit à starty, startx. Cela ne change pas la position du panneau dans la pile. Assurez-vous d'utiliser cette fonction, et non mvwin(3X), pour déplacer une fenêtre de panneau.

new_panel

new_panel(win) alloue une structure PANEL, l'associe à win, place le panneau en haut de la pile (le fait apparaître au-dessus de tout autre panneau) et retourne un pointeur vers le nouveau panneau.

panel_above

panel_above(pan) retourne un pointeur vers le panneau situé au-dessus de pan. Si l'argument du panneau est “(PANEL *)0”, il retourne un pointeur vers le panneau du bas dans la pile.

panel_below

panel_below(pan) retourne un pointeur vers le panneau juste en dessous de pan. Si l'argument du panneau est “(PANEL *)0”, il retourne un pointeur vers le panneau du haut dans la pile.

panel_hidden

panel_hidden(pan) retourne FALSE si le panneau pan est dans la pile de panneaux, et TRUE s'il ne l'est pas. Si le panneau est un pointeur nul, il retourne ERR.

panel_userptr

panel_userptr(pan) retourne le pointeur utilisateur pour un panneau donné pan.

panel_window

panel_window(pan) retourne un pointeur vers la fenêtre du panneau donné pan.

replace_panel

replace_panel(pan, window) remplace la fenêtre actuelle du panneau pan par window. Ceci est utile si, par exemple, vous souhaitez redimensionner un panneau. Dans ncurses, vous pouvez appeler replace_panel pour redimensionner un panneau en utilisant une fenêtre redimensionnée avec wresize(3X). Cela ne change pas la position du panneau dans la pile.

set_panel_userptr

set_panel_userptr(pan, ptr) définit le pointeur utilisateur du panneau.

show_panel

show_panel(pan) rend un panneau caché visible en le plaçant au-dessus des panneaux dans la pile de panneaux. Voir “PORTABILITÉ” ci-dessous.

top_panel

top_panel(pan) place le panneau visible donné pan au sommet de tous les panneaux de la pile. Voir “PORTABILITÉ” ci-dessous.

update_panels

update_panels() rafraîchit l'écran virtuel pour refléter les relations entre les panneaux de la pile, mais n'appelle pas doupdate(3X) pour rafraîchir l'écran physique. Utilisez cette fonction et non wrefresh(3X) ou wnoutrefresh(3X).

update_panels peut être appelé plusieurs fois avant un appel à doupdate, mais doupdate est la fonction responsable de la mise à jour de l'écran physique.

VALEUR DE RETOUR

Chaque routine qui retourne un pointeur retourne NULL si une erreur se produit. Chaque routine qui retourne une valeur entière retourne OK si elle s'exécute avec succès et ERR sinon.

Sauf indication contraire, les paramètres pan et window doivent être non nuls. Si l'un d'eux est nul, une erreur est retournée.

La fonction move_panel utilise mvwin(3X) et retourne une erreur si mvwin retourne une erreur.

NOTES

Le fichier d'en-tête panel.h inclut lui-même le fichier d'en-tête curses.h.

PORTABILITÉ

Un soin raisonnable a été apporté pour assurer la compatibilité avec la fonctionnalité de panneau native introduite dans System V ; l'inspection des pages de manuel SVr4 suggère que l'interface de programmation n'a jamais changé. Les structures de données PANEL sont simplement similaires. Le programmeur est averti de ne t

o utiliser directement les champs PANEL.

Les fonctions show_panel et top_panel sont identiques dans cette implémentation et fonctionnent aussi bien avec des panneaux affichés ou masqués. Dans l'implémentation System V, show_panel est destinée à rendre visible un panneau masqué (au sommet de la pile) et top_panel est destinée à déplacer un panneau déjà visible au sommet de la pile. Il est conseillé d'utiliser la fonction correcte pour assurer la compatibilité avec les bibliothèques de panneaux System V.

HISTORIQUE

Une installation de panneaux a été documentée dans le manuel Character User Interface Programming de SVr4.2.

Elle ne fait pas partie de X/Open Curses.

Quelques implémentations existent :

  • Les systèmes basés sur le code source SVr4, tels que Solaris, fournissent cette bibliothèque.
  • ncurses (depuis la version 0.6 en 1993) et PDCurses (depuis la version 2.2 en 1995) fournissent une bibliothèque de panneaux dont l'ancêtre commun est une implémentation dans le domaine public de Warren Tucker publiée dans u386mon 2.20 (1990).
Selon Tucker, la bibliothèque de panneaux System V a été publiée pour la première fois dans SVr3.2 (1988), et son implémentation a aidé à un portage vers SVr3.1 (1987).
Plusieurs développeurs ont amélioré chacune d'elles ; elles ne sont plus identiques à l'implémentation de Tucker.
•
NetBSD 8 (2018) a une bibliothèque de panneaux commencée par Valery Ushakov en 2015, basée sur la documentation System V.

AUTEURS

Warren Tucker <wht@n4hgf.mt-park.ga.us> a écrit à l'origine cette implémentation, principalement pour aider au portage de u386mon vers des systèmes sans bibliothèque de panneaux native.

Zeyd ben-Halim l'a reconditionnée pour ncurses.

Juergen Pfeifer et Thomas E. Dickey ont révisé et amélioré la bibliothèque.
