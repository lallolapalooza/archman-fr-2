NOM

pappl-mainloop - fonctions de boucle principale pappl

BIBLIOTHEQUE

Printer Application Framework (libpappl, "pkg-config --cflags --libs pappl")

SYNTAXE

#include <pappl/pappl.h>

int
papplMainloop(int argc, char *argv[], const char *version, const char *footer_html, int num_drivers, pappl_driver_t *drivers, pappl_driver_cb_t driver_cb, pappl_ml_autoadd_cb_t autoadd_cb, const char *subcmd_name, pappl_ml_subcmd_cb_t subcmd_cb, pappl_ml_system_cb_t system_cb, pappl_ml_usage_cb_t usage_cb, void *data);

DESCRIPTION

La fonction

mainloop démarre l'application imprimante et prend en charge les arguments de ligne de commande et les comportements standards.

FONCTIONS

papplMainloop

Exécute une boucle principale standard pour les applications imprimantes.

int  papplMainloop (
    int argc,
    char *argv[],
    const char *version,
    const char *footer_html,
    int num_drivers,
    pappl_pr_driver_t *drivers,
    pappl_pr_autoadd_cb_t autoadd_cb,
    pappl_pr_driver_cb_t driver_cb,
    const char *subcmd_name,
    pappl_ml_subcmd_cb_t subcmd_cb,
    pappl_ml_system_cb_t system_cb,
    pappl_ml_usage_cb_t usage_cb,
    void *data
);

Cette fonction exécute une boucle principale standard pour une application imprimante. Les arguments "argc" et "argv" sont ceux fournis à la fonction main.

L'argument "version" spécifie un numéro de version numérique pour l'application imprimante, conforme aux directives de versionnement sémantique avec jusqu'à quatre nombres, par exemple "1.2.3.4".

L'argument "footer_html" spécifie un texte HTML à utiliser dans le pied de page de l'interface web. Si NULL, le pied de page est omis.

Les arguments "num_drivers", "drivers" et "driver_cb" spécifient une liste de pilotes et la fonction de rappel du pilote pour les imprimantes. Spécifiez 0 et NULL si les pilotes sont configurés dans la fonction de rappel système. L'argument "autoadd_cb" spécifie une fonction de rappel pour l'ajout automatique de nouvelles imprimantes avec la sous-commande "autoadd" et pour la détection automatique du pilote lors de l'ajout manuel.

L'argument "usage_cb" spécifie une fonction de rappel qui affiche un résumé d'utilisation/aide. Si NULL, un résumé générique est affiché si nécessaire.

Les arguments "subcmd_name" et "subcmd_cb" spécifient le nom et une fonction de rappel pour une sous-commande personnalisée. Si NULL, aucune sous-commande personnalisée ne sera prise en charge.

L'argument "system_cb" spécifie une fonction qui créera un nouvel objet pappl_system_t. Si NULL, un objet système par défaut est créé.

L'argument "data" fournit des données spécifiques à l'application pour chacune des fonctions de rappel.

papplMainloopShutdown

Demande l'arrêt d'un système en cours d'exécution.

void papplMainloopShutdown (void);

Cette fonction demande l'arrêt du système démarré par papplMainloop.
