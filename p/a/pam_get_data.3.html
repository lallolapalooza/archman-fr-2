NOM

pam_get_data - obtenir des données internes au module

SYNTAXE

#include <security/pam_modules.h>

int pam_get_data(const pam_handle_t *pamh, const char *nom_donnee_module, const void **donnees);

DESCRIPTION

Cette fonction, avec la fonction pam_set_data(3), est utile pour gérer des données spécifiques au module qui ne sont utiles qu'au module PAM appelant.

La fonction pam_get_data recherche l'objet associé à la chaîne (espérons-le) unique nom_donnee_module dans le contexte PAM spécifié par l'argument pamh. Un appel réussi à pam_get_data entraînera donnees pointant vers l'objet. Notez que ces données ne sont pas une copie et doivent être traitées comme constantes par le module.

VALEURS DE RETOUR

PAM_SUCCESS

Les données ont été récupérées avec succès.

PAM_SYSTEM_ERR

Un pointeur NULL a été soumis comme handle PAM ou la fonction a été appelée par une application.

PAM_NO_MODULE_DATA

Aucune donnée spécifique au module n'est présente.

VOIR AUSSI

pam_end(3), pam_set_data(3), pam_strerror(3)
