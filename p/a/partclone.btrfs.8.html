PARTCLONE(8) Manuel utilisateur Partclone PARTCLONE(8)

NOM

partclone - L'utilitaire pour cloner et restaurer une partition.

SYNTAXE

partclone.[type_fs] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] cible} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] logfile [-R | --rescue] [-L | --logfile] logfile [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPTION

partclone.[type_fs] fait partie du projet Partclone. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une compatibilité accrue du système de fichiers en utilisant des bibliothèques existantes, par exemple, e2fslibs est utilisé pour lire le bloc utilisé de la partition ext2.

Les systèmes de fichiers pris en charge par Partclone incluent btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Il prend également en charge certains systèmes d'exploitation non-linux, par exemple : NTFS, FAT et EXFAT (pour Windows), HFS plus (MAC OS APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) et MINIX (MINIX3).

Tous les utilitaires partclone peuvent être exécutés comme partclone.[type_fs], très similaire à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, exécutez simplement partclone.hfsp

       Système de fichiers           partclone.[type_fs]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       autres (FS non pris en charge)   partclone.imager

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-s FICHIER, --source FICHIER

FICHIER source. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique selon votre action. Normalement, la source de sauvegarde est un périphérique, la source de restauration est un fichier image.

La réception de données à partir d'un pipeline n'est prise en charge QUE pour la restauration, ignorez simplement l'option -s ou utilisez '-' pour recevoir les données de l'stdin.

-o FICHIER, --output FICHIER

FICHIER de sortie. Le FICHIER peut être un fichier image (que partclone générera) ou un périphérique selon votre action. Normalement, la sortie de sauvegarde va vers un fichier image et la sortie de restauration va vers un périphérique.

L'envoi de données vers un pipeline est également pris en charge UNIQUEMENT pour la sauvegarde, ignorez simplement l'option -o ou utilisez '-' pour envoyer les données vers stdout.

-O FICHIER, --overwrite FICHIER

Écrase FICHIER, s'il existe.

-W FICHIER, --restore_raw_file FICHIER

Crée un fichier brut spécial pour le périphérique de boucle.

-c, --clone

Sauvegarde la partition dans le format d'image spécial.

-r, --restore

Restaure la partition à partir du format d'image spécial.

-b, --dev-to-dev

Copie locale de périphérique à périphérique à la volée, la source et la sortie sont toutes deux des périphériques.

-D, --domain

Crée un fichier journal de domaine GNU Ddrescue à partir du périphérique source. Il s'agit d'un fichier lisible par l'homme dans lequel + marque les zones de blocs utilisées et ? marque les zones libres.

--offset_domain=X

Ajoute X (en octets) à toutes les positions signalées dans le fichier journal de domaine

--restore_raw_file

Crée un fichier brut spécial pour le périphérique de boucle.

-L FICHIER, --logfile FICHIER

Spécifie un chemin spécial pour enregistrer les informations du journal de partclone. (par défaut /var/log/partclone.log)

-R, --rescue

Continue après les erreurs de lecture de disque.

-C, --no_check

Ne vérifie pas la taille du périphérique et l'espace libre.

-N, --ncurses

Utilise l'interface utilisateur textuelle Ncurses.

-I, --ignore_fschk

Ignore la vérification du système de fichiers.

-i, --ignore_crc

Ignore les erreurs de vérification crc.

-F, --force

Force la progression.

-f sec, --UI-fresh sec

Définit un intervalle de rafraîchissement de l'interface utilisateur en secondes.

-z taille, --buffer_size taille

Taille du tampon de lecture/écriture (par défaut : 1048576)

-q, --quiet

Désactive les messages de progression.

-dniveau, --debug niveau

Définit le niveau de débogage [1|2|3]

-x, --compresscmd CMD

Démarre CMD comme un pipeline de sortie pour compresser l'image clonée

-aX, --checksum-mode=X

Formule de somme de contrôle à utiliser pour ajouter la détection d'erreurs

où X :

0 : Pas de somme de contrôle (pas de ralentissement, image la plus petite)

1 : CRC32 (Calcul rapide, détection de base)

2 : xxHash, algorithme de hachage non cryptographique extrêmement rapide

-kX, --blocks-per-checksum=X

Écrit une somme de contrôle pour chaque X blocs

-w, --skip_write_error

Continue la restauration malgré les erreurs d'écriture

--write-direct-io

Écrit les données dans la partition CIBLE sans cache

--read-direct-io

Lit les données depuis la partition SOURCE sans cache

-B, --no_block_detail

Affiche les messages de progression sans détails de bloc

--binary-prefix

Affiche la progression avec la taille en bits (par défaut, c'est en Mo, Go...)

--prog-second

Affiche la progression en secondes (par défaut, c'est en minutes)

-E, --offset=X

Ajoute un décalage X (en octets) à la SORTIE

-T, --btfiles

Restaure le bloc sous forme de fichier pour ClonezillaBT.

-t, --btfiles_torrent

Restaure le bloc sous forme de fichier pour ClonezillaBT mais ne génère que le torrent.

-n, --note NOTE

Affiche une note de message (128 mots).

-h, --help

Affiche un résumé des options.

-v, --version

Affiche la version
partclone.ext3(8)

NAME

partclone.ext3

partition clone utility for ext3 filesystem

SYNOPSIS

partclone.ext3 [-c|-r] [-d] [-s source] [-o output]

DESCRIPTION

partclone.ext3 is a tool to clone and restore ext3 partitions. It is part of the partclone package.

It can clone a partition to an image file or restore an image file to a partition.

The program can clone a partition block-by-block, but it also has the capability to clone only used blocks, thus saving disk space and time.

OPTIONS

The options are as follows:

-c
Clone mode. Copy data from source to output.
-r
Restore mode. Copy data from input to output.
-d
Display debug information.
-s source
The source partition or image file. Use "-" to specify stdin.
-o output
The output partition or image file. Use "-" to specify stdout.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 clone /dev/hda1 to hda1.img and display debug information.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restore /dev/hda1 from hda1.img and display debug information.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
