NOM

pacrepairfile - réinitialiser les propriétés des fichiers gérés par alpm

SYNTAXE

pacrepairfile [options] (--gid|--mode|--mtime|--uid)... <fichier>...
pacrepairfile (--help|--version)

DESCRIPTION

Réinitialise les propriétés des fichiers pour les fichiers gérés par alpm en se basant sur les données MTREE.

Si stdin n'est pas connecté à un terminal, les fichiers seront lus depuis stdin.

OPTIONS

--config=chemin
Définit un chemin de fichier de configuration alternatif.
--dbpath=chemin
Définit un chemin de base de données alternatif.
--root=chemin
Définit une racine d'installation alternative.
--sysroot=chemin
Définit une racine système alternative. Voir pacutils-sysroot(7).
--quiet
N'affiche pas les informations de progression.
--package=nom_paquet
Recherche les propriétés du fichier dans nom_paquet. Peut être spécifié plusieurs fois. Si --package n'est pas spécifié, tous les paquets installés seront recherchés.
--help
Affiche les informations d'utilisation et quitte.
--version
Affiche les informations de version et quitte.

Champs

--gid
Réinitialise l'ID de groupe propriétaire du fichier.
--mode
Réinitialise les permissions du fichier.
--mtime
Réinitialise l'heure de modification du fichier.
--uid
Réinitialise l'ID utilisateur propriétaire du fichier.

MISE EN GARDE

pacrepairfile détermine s'il faut lire les fichiers depuis stdin en se basant sur une vérification naïve utilisant isatty(3). Si pacrepairfile est appelé dans un environnement, tel qu'une fonction shell ou un script utilisé dans un pipe, où stdin n'est pas connecté à un terminal mais ne contient pas de fichiers à réinitialiser, pacrepairfile devrait être appelé avec stdin fermé. Pour les shells compatibles POSIX, cela peut être fait avec "<&-".

Pour que pacrepairfile puisse réinitialiser les propriétés d'un fichier, le paquet qui possède le fichier doit avoir des données MTREE.
