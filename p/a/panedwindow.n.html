NOM

panedwindow - Créer et manipuler des widgets conteneurs divisés 'panedwindow'

SYNOPSIS

panedwindow nomChemin ?options?

OPTIONS STANDARD

-background	-borderwidth	-cursor
-orient	-relief

Voir l'entrée de manuel options pour plus de détails sur les options standard.

OPTIONS SPÉCIFIQUES AU WIDGET

Nom de base de données :	handlePad
Classe de base de données :	HandlePad
Lorsque les poignées de barre de séparation sont dessinées, spécifie la distance depuis le haut ou la gauche de la barre de séparation (selon l'orientation du widget) à laquelle dessiner la poignée. Peut être toute valeur acceptée par Tk_GetPixels.
Nom de ligne de commande :	-handlesize
Nom de base de données :	handleSize
Classe de base de données :	HandleSize

Nom de base de données :	height
Classe de base de données :	Height
Spécifie une hauteur souhaitée pour le widget panedwindow global. Peut être toute valeur acceptée par Tk_GetPixels. Si une chaîne vide, le widget sera suffisamment haut pour permettre à tous les widgets contenus d'avoir leur hauteur naturelle.
Nom de ligne de commande :	-opaqueresize
Nom de base de données :	opaqueResize
Classe de base de données :	OpaqueResize
Spécifie si les panneaux doivent être redimensionnés lorsque la barre de séparation est déplacée (true), ou si le redimensionnement doit être différé jusqu'à ce que la barre de séparation soit placée (false). Cette version « fantôme » de la barre de séparation est le proxy. Son rendu peut être configuré à l'aide des options -proxybackground, -proxyborderwidth et -proxyrelief.

Nom de base de données :	proxyBackground
Classe de base de données :	ProxyBackground

Nom de base de données :	proxyBorderWidth
Classe de base de données :	ProxyBorderWidth
Spécifie la largeur de bordure du proxy. Peut être toute valeur acceptée par Tk_GetPixels.
Nom de ligne de commande :	-proxyrelief
Nom de base de données :	proxyRelief
Classe de base de données :	ProxyRelief
Relief à utiliser lors du dessin du proxy. Peut être n'importe laquelle des valeurs de relief Tk standard. Si une chaîne vide, la valeur de l'option -sashrelief sera utilisée.
Nom de ligne de commande :	-sashcursor
Nom de base de données :	sashCursor
Classe de base de données :	SashCursor
Curseur de souris à utiliser lorsqu'il est au-dessus d'une barre de séparation. Si nul, sb_h_double_arrow sera utilisé pour les panedwindows horizontaux, et sb_v_double_arrow sera utilisé pour les panedwindows verticaux.
Nom de ligne de commande :	-sashpad
Nom de base de données :	sashPad
Classe de base de données :	SashPad
Spécifie la quantité de remplissage à laisser de chaque côté d'une barre de séparation. Peut être toute valeur acceptée par Tk_GetPixels.

Nom de base de données :	sashRelief
Classe de base de données :	SashRelief

Nom de ligne de commande :	-sashwidth
Nom de base de données :	sashWidth
Classe de base de données :	SashWidth
Spécifie la largeur de chaque barre de séparation. Peut être toute valeur acceptée par Tk_GetPixels.
Nom de ligne de commande :	-showhandle
Nom de base de données :	showHandle
Classe de base de données :	ShowHandle
Spécifie si les poignées de barre de séparation doivent être affichées. Peut être n'importe quelle valeur booléenne Tcl valide.
Nom de ligne de commande :	-width
Nom de base de données :	width
Classe de base de données :	Width
Spécifie une largeur souhaitée pour le widget panedwindow global. Peut être toute valeur acceptée par Tk_GetPixels. Si une chaîne vide, le widget sera suffisamment large pour permettre à tous les widgets contenus d'avoir leur largeur naturelle.

DESCRIPTION

La commande panedwindow crée une nouvelle fenêtre (donnée par l'argument nomChemin) et en fait un widget panedwindow. Des options supplémentaires, décrites ci-dessus, peuvent être spécifiées sur la ligne de commande ou dans la base de données d'options pour configurer des aspects du panedwindow tels que sa couleur d'arrière-plan par défaut et son relief. La commande panedwindow retourne le nom du chemin de la nouvelle fenêtre.

Un widget panedwindow contient un nombre quelconque de panneaux, disposés horizontalement ou verticalement, selon la valeur de l'option -orient. Chaque panneau contient un widget, et chaque paire de panneaux est séparée par une barre de séparation mobile (via les mouvements de souris). Le déplacement d'une barre de séparation provoque le redimensionnement des widgets de chaque côté de la barre.

COMMANDE WIDGET

La commande panedwindow crée une nouvelle commande Tcl dont le nom est identique au nom du chemin de la fenêtre du panedwindow. Cette commande peut être utilisée pour invoquer diverses opérations sur le widget. Elle a la forme générale suivante :

nomChemin option ?arg arg ...?
nomChemin est le nom de la commande, qui est identique au nom du chemin du widget panedwindow. Option et les arg déterminent le comportement exact de la commande. Les commandes suivantes sont possibles pour les widgets panedwindow :
nomChemin add fenetre ?fenetre ...? ?option valeur ...?
Ajoute une ou plusieurs fenêtres au panedwindow, chacune dans un panneau séparé. Les arguments consistent en les noms d'une ou plusieurs fenêtres suivis de paires d'arguments qui spécifient comment gérer les fenêtres. Option peut avoir l'une des valeurs acceptées par la sous-commande configure.
nomChemin cget option
Retourne la valeur actuelle de l'option de configuration donnée par option. Option peut avoir l'une des valeurs acceptées par la commande panedwindow.
nomChemin configure ?option? ?valeur option valeur ...?
Interroge ou modifie les options de configuration du widget. Si aucune option n'est spécifiée, retourne une liste décrivant toutes les options disponibles pour nomChemin (voir Tk_ConfigureInfo pour des informations sur le format de cette liste). Si option est spécifiée sans valeur, alors la commande retourne une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur retournée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, alors la commande modifie les options du widget données pour avoir les valeurs données ; dans ce cas, la commande retourne une chaîne vide. Option peut avoir l'une des valeurs acceptées par la commande panedwindow.
nomChemin forget fenetre ?fenetre ...?
Supprime le panneau contenant fenetre du panedwindow. Toutes les options de gestion de géométrie pour fenetre seront oubliées.
nomChemin identify x y
Identifie le composant panedwindow sous le point donné par x et y, dans les coordonnées de la fenêtre. Si le point est sur une barre de séparation ou une poignée de barre de séparation, le résultat est une liste à deux éléments contenant l'indice de la barre de séparation ou de la poignée, et un mot indiquant s'il est sur une barre de séparation ou une poignée, tel que {0 sash} ou {2 handle}. Si le point est sur toute autre partie du panedwindow, le résultat est une liste vide.
nomChemin panecget fenetre option
Interroge une option de gestion pour fenetre. Op

tion peut être n'importe quelle valeur autorisée par la sous-commande paneconfigure.
pathName paneconfigure window ?option? ?value option value ...?
Interroge ou modifie les options de gestion de window. Si aucune option n'est spécifiée, renvoie une liste décrivant toutes les options disponibles pour pathName (voir Tk_ConfigureInfo pour des informations sur le format de cette liste). Si option est spécifiée sans value, la commande renvoie une liste décrivant l'option nommée (cette liste sera identique à la sous-liste correspondante de la valeur renvoyée si aucune option n'est spécifiée). Si une ou plusieurs paires option-valeur sont spécifiées, la commande modifie les options du widget données pour avoir les valeurs données ; dans ce cas, la commande renvoie une chaîne vide. Les options suivantes sont prises en charge :
-after window
Insère la fenêtre après la fenêtre spécifiée. window doit être le nom d'une fenêtre déjà gérée par pathName.
-before window
Insère la fenêtre avant la fenêtre spécifiée. window doit être le nom d'une fenêtre déjà gérée par pathName.
-height size
Spécifie une hauteur pour la fenêtre. La hauteur sera la dimension extérieure de la fenêtre, y compris sa bordure, le cas échéant. Si size est une chaîne vide, ou si -height n'est pas spécifié, la hauteur demandée en interne par la fenêtre sera utilisée initialement ; la hauteur peut être ajustée ultérieurement par le mouvement des sécateurs dans la fenêtre segmentée. Size peut être toute valeur acceptée par Tk_GetPixels.
-hide boolean
Contrôle la visibilité d'une fenêtre. Lorsque boolean est vrai (selon Tcl_GetBoolean), la fenêtre ne sera pas visible, mais elle sera maintenue dans la liste des fenêtres.
-minsize n
Spécifie que la taille de la fenêtre ne peut pas être inférieure à n. Cette contrainte n'affecte que la taille du widget dans la dimension segmentée — la dimension x pour les fenêtres segmentées horizontales, la dimension y pour les fenêtres segmentées verticales. Peut être toute valeur acceptée par Tk_GetPixels.
-padx n
Spécifie une valeur non négative indiquant l'espace supplémentaire à laisser de chaque côté de la fenêtre dans la direction X. La valeur peut avoir l'une des formes acceptées par Tk_GetPixels.
-pady n
Spécifie une valeur non négative indiquant l'espace supplémentaire à laisser de chaque côté de la fenêtre dans la direction Y. La valeur peut avoir l'une des formes acceptées par Tk_GetPixels.
-sticky style
Si la fenêtre d'une fenêtre est plus grande que les dimensions demandées de la fenêtre, cette option peut être utilisée pour positionner (ou étirer) la fenêtre dans sa fenêtre. Style est une chaîne qui contient zéro ou plusieurs des caractères n, s, e ou w. La chaîne peut éventuellement contenir des espaces ou des virgules, mais ils sont ignorés. Chaque lettre fait référence à un côté (nord, sud, est ou ouest) auquel la fenêtre sera « collée ». Si n et s (ou e et w) sont spécifiés, la fenêtre sera étirée pour remplir toute la hauteur (ou largeur) de sa cavité.
-stretch when
Contrôle la manière dont l'espace supplémentaire est alloué à chacune des fenêtres. When est l'une des valeurs always, first, last, middle et never. La fenêtre segmentée calculera la taille requise de toutes ses fenêtres. L'espace restant (ou le déficit) sera distribué aux fenêtres marquées pour l'étirement. L'espace sera distribué en fonction du rapport actuel de chaque fenêtre par rapport à l'ensemble. Les valeurs de when ont la définition suivante :
always
Cette fenêtre sera toujours étirée.
first
Seulement si cette fenêtre est la première (la plus à gauche ou la plus en haut) sera-t-elle étirée.
last
Seulement si cette fenêtre est la dernière (la plus à droite ou la plus en bas) sera-t-elle étirée. C'est la valeur par défaut.
middle
Seulement si cette fenêtre n'est ni la première ni la dernière sera-t-elle étirée.
never
Cette fenêtre ne sera jamais étirée.
-width size
Spécifie une largeur pour la fenêtre. La largeur sera la dimension extérieure de la fenêtre, y compris sa bordure, le cas échéant. Si size est une chaîne vide, ou si -width n'est pas spécifié, la largeur demandée en interne par la fenêtre sera utilisée initialement ; la largeur peut être ajustée ultérieurement par le mouvement des sécateurs dans la fenêtre segmentée. Size peut être toute valeur acceptée par Tk_GetPixels.
pathName panes
Renvoie une liste ordonnée des widgets gérés par pathName.
pathName proxy ?args?
Cette commande est utilisée pour interroger et modifier la position du proxy de sécateur, utilisé pour le redimensionnement des fenêtres segmentées de type « rubberband ». Elle peut prendre l'une des formes suivantes :
pathName proxy coord
Renvoie une liste contenant les coordonnées x et y de la dernière position du proxy.
pathName proxy forget
Supprime le proxy de l'affichage.
pathName proxy place x y
Place le proxy aux coordonnées x et y données.
pathName sash ?args?
Cette commande est utilisée pour interroger et modifier la position des sécateurs dans la fenêtre segmentée. Elle peut prendre l'une des formes suivantes :
pathName sash coord index
Renvoie la paire de coordonnées x et y actuelle du sécateur donné par index. Index doit être un entier compris entre 0 et 1 de moins que le nombre de fenêtres dans la fenêtre segmentée. Les coordonnées données sont celles du coin supérieur gauche de la région contenant le sécateur.
pathName sash dragto index x y
Cette commande calcule la différence entre les coordonnées données et les coordonnées données à la dernière commande sash mark pour le sécateur donné. Elle déplace ensuite ce sécateur de la différence calculée. La valeur renvoyée est la chaîne vide.
pathName sash mark index x y
Enregistre x et y pour le sécateur donné par index ; utilisé en conjonction avec les commandes ultérieures sash dragto pour déplacer le sécateur.
pathName sash place index x y
Place le sécateur donné par index aux coordonnées données.

REDIMENSIONNEMENT DES FENETRES

Une fenêtre est redimensionnée en saisissant le sécateur (ou la poignée du sécateur s'il y en a une) et en le faisant glisser avec la souris. Ceci est réalisé via des liaisons de mouvement de souris sur le widget. Lorsqu'un sécateur est déplacé, les tailles des fenêtres de chaque côté du sécateur, et donc les widgets dans ces fenêtres, sont ajustées.

Lorsqu'une fenêtre est redimensionnée de l'extérieur (par exemple, elle est empaquetée pour s'étendre et remplir, et la fenêtre parente est redimensionnée), l'espace est ajouté à la dernière fenêtre (la plus à droite ou la plus en bas) dans la fenêtre.

Contrairement aux fenêtres enfants gérées par, par exemple, pack ou grid, les fenêtres gérées par une fenêtre segmentée ne changent pas de largeur ou de hauteur pour s'adapter aux changements de largeur ou de hauteur demandés des fenêtres, une fois qu'elles sont mappées. Il peut donc être conseillé, en particulier lors de la création de mises en page interactives, de ne pas ajouter une fenêtre au widget de fenêtre segmentée avant que les requêtes de géométrie de cette fenêtre ne soient finalisées (c'est-à-dire, tous les composants de la fenêtre insérés, toutes les options affectant la géométrie réglées à leurs valeurs correctes, etc.).

NOM

panedwindow — Widget de fenêtre divisée de Tk

SYNTAXE


package require Tk

tk_paneWindow pathName ?option value ...?
tk_paneWindow pathName add childPathName ?option value ...?
tk_paneWindow pathName remove childPathName
tk_paneWindow pathName configure ?option value ...?

DESCRIPTION

Le panedwindow est un widget qui permet à l'utilisateur de contrôler la taille des fenêtres enfants dans une fenêtre principale en faisant glisser des séparateurs. Il est souvent utilisé pour implémenter des dispositions de type "Explorateur" où une arborescence se trouve sur la gauche et une vue du contenu sur la droite.

La commande tk_paneWindow crée et manipule des widgets panedwindow.

Création

tk_paneWindow pathName ?option value ...?

Crée un nouveau widget panedwindow avec le nom de chemin pathName. Les options suivantes sont disponibles :

  • -orient : Spécifie l'orientation des séparateurs. Peut être horizontal ou vertical. La valeur par défaut est vertical.
  • -showhandle : Si défini sur true, affiche des poignées sur les séparateurs pour indiquer qu'ils sont déplaçables. La valeur par défaut est false.
  • -width, -height : Spécifient la largeur et la hauteur du widget panedwindow.

Ajout d'enfants

tk_paneWindow pathName add childPathName ?option value ...?

Ajoute un widget enfant childPathName au widget panedwindow pathName. Les options suivantes sont disponibles pour le widget enfant :

  • -before, -after : Spécifie un autre widget enfant avant ou après lequel le nouveau widget sera inséré.
  • -minsize : La taille minimale du widget enfant.
  • -maxsize : La taille maximale du widget enfant.
  • -sticky : Indique comment le widget enfant doit s'étirer pour remplir l'espace disponible. Peut être n, s, e, w ou une combinaison.

Suppression d'enfants

tk_paneWindow pathName remove childPathName

Supprime le widget enfant childPathName du widget panedwindow pathName.

Configuration

tk_paneWindow pathName configure ?option value ...?

Permet de modifier les options du widget panedwindow pathName.

OPTIONS

Voir les options de création et de configuration ci-dessus.

EXEMPLE


package require Tk

# Créer une fenêtre principale
toplevel .main

# Créer un widget panedwindow vertical
tk_paneWindow .main.paned -orient vertical

pack .main.paned -fill both -expand true

# Créer et ajouter le premier enfant (par exemple, une liste)
frame .main.paned.left
# ... ajouter des widgets à .main.paned.left ...
tk_paneWindow .main.paned add .main.paned.left -minsize 100

# Créer et ajouter le deuxième enfant (par exemple, une zone de texte)
text .main.paned.right
# ... configurer la zone de texte ...
tk_paneWindow .main.paned add .main.paned.right -minsize 100

# Configurer les tailles initiales
tk_paneWindow .main.paned configure -width 400 -height 300
