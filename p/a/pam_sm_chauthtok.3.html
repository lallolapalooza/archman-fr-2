NOM

pam_sm_chauthtok - Fonction de service PAM pour la gestion des jetons d'authentification

SYNTAXE

#include <security/pam_modules.h>

int pam_sm_chauthtok(pam_handle_t *pamh, int flags, int argc, const char **argv);

DESCRIPTION

La fonction pam_sm_chauthtok est l'implémentation du module de service de l'interface pam_chauthtok(3).

Cette fonction est utilisée pour (ré)initialiser le jeton d'authentification de l'utilisateur.

Les drapeaux valides, qui peuvent être combinés logiquement avec PAM_SILENT par un OU, sont :

PAM_SILENT

Ne pas afficher de messages.

PAM_CHANGE_EXPIRED_AUTHTOK

Cet argument indique au module que le jeton d'authentification de l'utilisateur (mot de passe) ne doit être modifié que s'il a expiré. Ce drapeau est optionnel et doit être combiné avec l'un des deux drapeaux suivants. Notez cependant que les deux options suivantes sont mutuellement exclusives.

PAM_PRELIM_CHECK

Cela indique que les modules sont interrogés sur leur statut de préparation pour modifier le jeton d'authentification de l'utilisateur. Si le module nécessite un accès à un autre système sur un réseau, il devrait essayer de vérifier qu'il peut se connecter à ce système lors de la réception de ce drapeau. Si un module ne peut pas établir qu'il est prêt à mettre à jour le jeton d'authentification de l'utilisateur, il doit renvoyer PAM_TRY_AGAIN, cette information sera renvoyée à l'application.

Si la valeur de contrôle sufficient est utilisée dans la pile de mots de passe, la section PAM_PRELIM_CHECK des modules suivant cette valeur de contrôle n'est pas toujours exécutée.

PAM_UPDATE_AUTHTOK

Cela informe le module qu'il s'agit de l'appel auquel il doit modifier les jetons d'autorisation. Si le drapeau est combiné logiquement avec PAM_CHANGE_EXPIRED_AUTHTOK par un OU, le jeton n'est modifié que s'il a effectivement expiré.

La bibliothèque PAM appelle cette fonction deux fois de suite. La première fois avec PAM_PRELIM_CHECK, puis, si le module ne renvoie pas PAM_TRY_AGAIN, ensuite avec PAM_UPDATE_AUTHTOK. C'est seulement lors du second appel que le jeton d'autorisation est (éventuellement) modifié.

VALEURS DE RETOUR

PAM_AUTHTOK_ERR

Le module n'a pas pu obtenir le nouveau jeton d'authentification.

PAM_AUTHTOK_RECOVERY_ERR

Le module n'a pas pu obtenir l'ancien jeton d'authentification.

PAM_AUTHTOK_LOCK_BUSY

Impossible de modifier le jeton d'authentification car il est actuellement verrouillé.

PAM_AUTHTOK_DISABLE_AGING

Le vieillissement du jeton d'authentification a été désactivé.

PAM_PERM_DENIED

Permission refusée.

PAM_TRY_AGAIN

La vérification préliminaire a échoué. Indique un retour immédiat à l'application souhaité.

PAM_SUCCESS

Le jeton d'authentification a été mis à jour avec succès.

PAM_USER_UNKNOWN

Utilisateur inconnu du service de mots de passe.
