NOM

pam_timestamp_check - Vérifie si l'horodatage par défaut est valide

SYNTAXE

pam_timestamp_check [-k] [-d] [utilisateur_cible]

DESCRIPTION

Sans arguments, pam_timestamp_check vérifie si l'horodatage par défaut est valide, ou le supprime éventuellement.

OPTIONS

-k

Au lieu de vérifier la validité d'un horodatage, le supprime. Ceci est analogue à l'option -k de sudo.

-d

Au lieu de retourner la validité à l'aide d'un code de retour, boucle indéfiniment, interroge régulièrement et affiche le statut sur la sortie standard.

utilisateur_cible

Par défaut, pam_timestamp_check vérifie ou supprime les horodatages générés par pam_timestamp lorsque les utilisateurs s'authentifient en tant qu'eux-mêmes. Lorsque l'utilisateur s'authentifie en tant qu'un autre utilisateur, le nom du fichier d'horodatage change pour l'accueillir. utilisateur_cible permet de spécifier ce nom d'utilisateur.

VALEURS DE RETOUR

0

L'horodatage est valide.

2

Le binaire n'est pas défini SUID root.

3

Invocation invalide.

4

Utilisateur inconnu.

5

Erreur de permissions.

6

TTY de contrôle invalide.

7

L'horodatage n'est pas valide.

NOTES

Les utilisateurs peuvent être désorientés lorsqu'ils ne sont pas toujours invités à saisir leur mot de passe lorsqu'ils exécutent un programme donné. Certains utilisateurs commencent instinctivement à taper des informations avant de remarquer qu'elles ne sont pas demandées.

EXEMPLES

auth sufficient pam_timestamp.so verbose
auth required   pam_unix.so
session required pam_unix.so
session optional pam_timestamp.so

FICHIERS

/var/run/sudo/...

fichiers et répertoires d'horodatage
