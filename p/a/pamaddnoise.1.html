NOM

pamaddnoise - ajouter du bruit à une image Netpbm

SYNTAXE

pamaddnoise

[-type type_bruit]

[-seed int] pamaddnoise -type gaussian

[-sigma1 valeur]

[-sigma2 valeur] [-seed int]

[fichier_netpbm] pamaddnoise -type multiplicative_gaussian

[-mgsigma valeur] [-seed int]

[fichier_netpbm] pamaddnoise -type impulse

[-tolerance ratio]

[-seed int] [fichier_netpbm] pamaddnoise -type laplacian

[-lsigma valeur]

[-seed int] [fichier_netpbm] pamaddnoise -type poisson

[-lambda valeur]

[-seed int] [fichier_netpbm]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pamaddnoise ajoute le type de bruit spécifié à une image Netpbm. pamaddnoise traite une image PPM comme 3 plans indépendants, pas comme un plan de couleurs dans un espace colorimétrique.

OPTIONS

-lambda valeur
Utilisé uniquement pour le bruit de Poisson. La valeur par défaut est 0.05.
-lsigma valeur
Utilisé uniquement pour le bruit Laplacien. La valeur par défaut est 10.0.
-mgsigma valeur
Utilisé uniquement pour le bruit Gaussien multiplicatif. La valeur par défaut est 0.5.
-seed int
Utilisé pour tous les types de bruit. Définit la valeur d'initialisation du générateur de nombres aléatoires.
-sigma1 valeur
Utilisé uniquement pour le bruit Gaussien. La valeur par défaut est 4.0.
-sigma2 valeur
Utilisé uniquement pour le bruit Gaussien. La valeur par défaut est 20.0.
-tolerance ratio
Utilisé uniquement pour le bruit impulsionnel. La valeur par défaut est 0.10. Cela signifie que 5% de toutes les valeurs de pixels seront mises à 0 et 5% seront mises à la valeur maximale.
-type type_bruit
Sélectionne le type de bruit par son nom. Les types de bruit suivants sont disponibles : gaussian, multiplicative_gaussian, impulse, laplacian, poisson. Seules les lettres suffisantes pour être uniques sont requises pour l'option de type de bruit. Le type de bruit par défaut est gaussian.

  • multiplicative_gaussian
  • impulse
  • laplacian
  • poisson

HISTORIQUE

pamaddnoise a été ajouté à Netpbm dans la version 10.29 (août 2005). Il avait été distribué par Mike Burns via son propre site web avant cela (et a continué de l'être).

La version de Burns, et celle de Netpbm 10.29, s'appelait pnmaddnoise et ne fonctionnait que sur les images PNM. Dans Netpbm 10.30, elle a été convertie pour gérer les images PAM et renommée pamaddnoise.
