PACKETFORGE-NG(1) Manuel des commandes générales PACKETFORGE-NG(1)

NOM

packetforge-ng - forge des paquets : ARP, UDP, ICMP ou personnalisés.

SYNTAXE

packetforge-ng <mode> <options>

DESCRIPTION

packetforge-ng est un outil permettant de créer des paquets chiffrés qui peuvent ensuite être utilisés pour l'injection. Vous pouvez créer divers types de paquets tels que des requêtes ARP, UDP, ICMP et des paquets personnalisés. L'utilisation la plus courante est de créer des requêtes ARP pour une injection ultérieure.

Pour créer un paquet chiffré, vous devez disposer d'un fichier PRGA (algorithme de génération pseudo-aléatoire). Celui-ci est utilisé pour chiffrer le paquet que vous créez. Il est généralement obtenu à partir d'attaques chopchop ou de fragmentation avec aireplay-ng.

OPTIONS

-H, --help
Affiche l'écran d'aide.
-p <fctrl>
Définit le mot de contrôle de trame (hex).
-a <bssid>
Définit l'adresse MAC du point d'accès.
-c <dmac>
Définit l'adresse MAC de destination.
-h <smac>
Définit l'adresse MAC source.
-j
Définit le bit FromDS.
-o
Efface le bit ToDS.
-e
Désactive le chiffrement WEP.
-k <ip:[port]>
Définit l'IP (et le port) de destination.
-l <ip:[port]>
Définit l'IP (et le port) source.
-w <fichier>
Écrit le paquet dans ce fichier pcap.
-r <fichier>
Lit le paquet à partir de ce fichier pcap.
-y <fichier>
Lit le PRGA à partir de ce fichier.
-t <ttl>
Définit la durée de vie (Time To Live) dans l'en-tête IP.
-s <taille>
Définit la taille du paquet nul généré.
-0, --arp
Forge un paquet ARP.
-1, --udp
Forge un paquet UDP.
-2, --icmp
Forge un paquet ICMP.
-3, --null
Forge un paquet llc nul.
-9, --custom
Construit un paquet personnalisé, nécessite -r pour lire une trame non chiffrée à partir d'un fichier pcap.

EXEMPLE

packetforge-ng -y test.xor -a 00:09:5b:12:40:cc -h 00:10:2a:cb:30:14 -k 192.168.1.100 -l 192.168.1.1 -w arp-request.cap
