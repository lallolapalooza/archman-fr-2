NOM

pamstereogram - créer un stéréogramme d'image unique à partir d'une carte de profondeur PAM

SYNOPSIS

pamstereogram [-help] [-verbose] [-blackandwhite | -grayscale | -color] [-maxval=valeur] [-patfile=pamfile] [-texfile=pamfile] [-bgcolor=couleur] [-smoothing=pixels] [-xshift=pixels] [-yshift=pixels] [-magnifypat=échelle] [-guidetop] [-guidebottom] [-guidesize=pixels] [-dpi=résolution] [-crosseyed] [-makemask] [-eyesep=pouces] [-depth=fraction] [-planes=pixels_proches,pixels_lointains] [-randomseed=entier] [infile]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pamstereogram lit une carte de profondeur (une carte des distances de votre œil des points d'une scène) et produit un stéréogramme d'image unique (SIS). Un SIS est une image 2D spécialement conçue pour apparaître en trois dimensions lorsqu'elle est vue avec des yeux détendus et légèrement flous. Ce qui est intéressant avec les stéréogrammes d'image unique, c'est qu'ils ne nécessitent pas de lunettes spéciales pour être visualisés, bien qu'il faille un peu de pratique pour entraîner ses yeux à flouter correctement. Le programme pamstereogram offre un grand contrôle sur la génération du stéréogramme, y compris les éléments suivants :

  • sortie en noir et blanc, en niveaux de gris ou en couleur
  • stéréogrammes d'image unique à points aléatoires (SIRDS), stéréogrammes d'image unique (SIS) utilisant une image en mosaïque, ou stéréogrammes à texture mappée (MTS)
  • images ciblant une résolution de périphérique et une séparation oculaire données
  • boîtes de guidage optionnelles pour aider à la mise au point
  • la possibilité d'échanger des niveaux de profondeur pour une visualisation plus facile
  • choix de stéréogrammes "wall-eyed" (yeux écartés) ou "cross-eyed" (yeux croisés)

La sortie est une image PAM sur la sortie standard. Les options contrôlent le format exact du PAM. Si vous souhaitez une image PNM (PBM, PGM ou PPM), utilisez pamtopnm sur la sortie. Il n'est pas nécessaire de convertir si vous utiliserez l'image comme entrée pour un programme Netpbm actuel, mais de nombreux autres programmes ne savent pas ce qu'est un PAM.

Pour créer un stéréogramme de type rouge/vert (que vous visualisez avec des lunettes 3D) à la place, voir ppm3d.

OPTIONS

Vous pouvez utiliser des tirets simples ou doubles pour indiquer les options. Vous pouvez utiliser un espace blanc ou un signe égal pour séparer le nom d'une option de sa valeur.

-verbose
Affiche des messages sur les tailles et formats d'image et les propriétés du stéréogramme en cours de génération.
-blackandwhite
Produit un stéréogramme d'image unique à points aléatoires en noir et blanc. C'est l'option par défaut.
-grayscale
Produit un stéréogramme d'image unique à points aléatoires en niveaux de gris.
-color
Produit un stéréogramme d'image unique à points aléatoires en couleur.
-maxval=valeur
Désigne la valeur maximale de chaque composante de gris/couleur, c'est-à-dire la résolution de couleur. Des valeurs plus petites font que l'image de sortie a un nombre plus petit de gris/couleurs uniques. Si vous ne spécifiez pas -maxval, pamstereogram utilise le maxval de l'image d'entrée. Cette option n'a aucun effet avec -blackandwhite.
-patfile=pamfile
Spécifie une image à utiliser comme motif de fond répété pour le stéréogramme au lieu d'un motif de points aléatoires. Les images complexes produisent généralement un effet 3D plus net que les images plus simples. Le fichier de sortie aura le même maxval et le même format (noir et blanc, niveaux de gris ou couleur) que le fichier motif. Vous ne pouvez pas spécifier l'option -patfile en même temps que -blackandwhite, -grayscale, -color ou -maxval.
-texfile=pamfile
Spécifie une image à utiliser comme texture pour un stéréogramme à texture mappée. L'idée est que l'image de la carte de profondeur fournit les valeurs de profondeur de l'objet/scène 3D tandis que l'image de texture fournit les valeurs de couleur réelles. Par conséquent, l'image de texture doit correspondre à l'image de la carte de profondeur. (Notez qu'elles doivent avoir les mêmes dimensions.) La couleur d'arrière-plan de l'image de texture est ignorée lors du mélange des couleurs.

Cette option est nouvelle dans Netpbm 10.53 (décembre 2010).

-bgcolor=couleur
Utilise couleur comme couleur d'arrière-plan de l'image de texture au lieu de laisser pamstereogram la déterminer automatiquement. Spécifiez la couleur comme décrit pour l'argument de la routine de bibliothèque ppm_parsecolor(). L'option -bgcolor n'est significative qu'en conjonction avec -texfile.

Cette option est nouvelle dans Netpbm 10.53 (décembre 2010).

-smoothing=pixels
Lorsqu'il est utilisé sans -texfile, tente d'éliminer les artefacts introduits par les bords de la carte de profondeur si pixels est supérieur à zéro.

Lorsqu'il est utilisé avec -texfile, floute horizontalement les couleurs non d'arrière-plan dans les pixels d'arrière-plan jusqu'à une distance de pixels pixels. Cela permet d'adoucir les glitches distrayants introduits par les contraintes de couleur du stéréogramme lors de la production d'un stéréogramme à texture mappée. Dans ce cas, l'option -smoothing est utile lorsque l'image de texture comprend des transitions de couleur douces (comme dans une photographie) mais rend floues les images à texture nette (comme dans un dessin au trait).

Cette option est nouvelle dans Netpbm 10.53 (décembre 2010). Avant Netpbm 10.61 (décembre 2012), elle n'avait aucun effet sans -texfile.

-xshift=pixels
Décale l'image motif (désignée par -patfile) vers la droite de pixels pixels (par défaut : 0).

Cette option n'est valide qu'avec -patfile.

-yshift pixels
Décale l'image motif (désignée par -patfile) vers le bas de pixels pixels (par défaut : 0). Cette option n'est valide qu'avec -patfile.
-magnifypat=échelle
Agrandit chaque pixel du fichier motif ou chaque point aléatoire par un facteur d'échelle intégral échelle. Notez que pamstereogram applique l'agrandissement du motif *après* le décalage du motif (-xshift et -yshift).
-guidebottom
Dessine une paire de carrés noirs sur fond blanc sous le stéréogramme proprement dit. Ces carrés vous aident à guider vos yeux pour une mise au point correcte afin de visualiser l'image 3D. L'astuce consiste à focaliser vos yeux à une certaine distance derrière l'image, ce qui vous amène à voir quatre carrés noirs, puis à continuer de modifier votre distance de mise au point jusqu'à ce que les deux carrés noirs du milieu fusionnent en un seul carré noir. À ce moment-là, une image nette et en 3D apparaîtra.

Cette option est nouvelle dans Netpbm 10.61 (décembre 2012). Avant cela, la présence de -guidesize, avec une valeur positive, avait le même effet.

-guidetop
Identique à -guidebottom, sauf que les guides sont placés en haut de l'image.

Cette option est nouvelle dans Netpbm 10.61 (décembre 2012). Avant cela, la présence de -guidesize, avec une valeur négative, avait le même effet.

-guidesize=pixels
La taille (largeur et hauteur) de chaque boîte de guidage.

Ceci n'est valide qu'avec -guidetop ou -guidebottom.

Par défaut : 20.

SYNOPSIS

pamstereogram [option ...] [infile]

DESCRIPTION

pamstereogram is a Netpbm program that creates stereograms from depth maps. A stereogram is an image that can be viewed in 3-D. The depth map is an image where each pixel's intensity represents the distance from the viewer of the corresponding point in the 3-D scene. Darker pixels are farther away, and lighter pixels are closer.

There are several types of stereograms that pamstereogram can create:

  • SIRDS (Single Image Random Dot Stereogram): The 3-D image is formed by a field of random dots. The depth information is encoded in the density and placement of these dots.
  • SIS (Single Image Stereogram): Similar to SIRDS, but instead of random dots, the image is formed by tiling a smaller pattern image.
  • MTS (Mapped-Texture Stereogram): The 3-D image is rendered with true colors, and the depth is encoded in the pixel positions. This type of stereogram can be viewed in 2-D as well, showing a repeating pattern of the 3-D image.

The program can generate a mask image instead of a stereogram, which can be used to help create more sophisticated pattern files.

OPTIONS

-magnifypat=integer
Magnify the pattern pixels by the specified integer factor. This is useful for creating SIRDS images with larger dots or patterns. The default is 1 (no magnification).
-patwidth=pixels
Specify the width of the pattern to be tiled in pixels. If this is not specified, the width of the pattern file is used. This option is relevant when using the -patfile option.
-patfile=filename
Use the image specified by filename as the pattern to tile for creating an SIS. The pattern image must have a width that is an exact divisor of the output image width. The height of the pattern image must be an exact divisor of the output image height.
-texfile=filename
Use the image specified by filename as a texture image for creating an MTS. The texture image should contain the colors for the 3-D object.
-smoothing=integer
Apply smoothing to the output image. The integer specifies the number of times to apply a 3x3 smoothing filter. This can help reduce aliasing artifacts, especially in MTS images. The default is 0 (no smoothing).
-color
Generate a color stereogram. If this option is not specified, a grayscale stereogram is generated. This option is only applicable when a texture file (-texfile) is provided.
-maxval=integer
Specify the maximum possible value for a pixel in the input depth map. This is useful if the input image does not have the full range of possible values. The default is determined by the input image format (e.g., 255 for 8-bit images).
-guidetop=pixels
Specify the vertical position of the top guide box in pixels. A guide box is a horizontal line that helps in aligning the left and right eye views. If negative, it is measured from the bottom.
-guidebottom=pixels
Specify the vertical position of the bottom guide box in pixels. If negative, it is measured from the top.
-guidesize=pixels
Specify the vertical size of the guide boxes in pixels. If negative, it is interpreted as a relative size based on the image height.
-dpi=resolution
Specify the resolution of the output device in dots per inch. The default is 100 DPI, which represents a fairly crisp screen resolution.

Before Netpbm 10.53 (December 2010), the default was 96 DPI.

-crosseyed
Invert the gray levels in the depth map (input image) so that the 3-D image pops out of the page where it would otherwise sink into the page and vice versa. Some people are unable to diverge their eyes and can only cross them. The -crosseyed option enables such people to see the 3-D image as intended. You can also specify the -crosseyed option if you prefer using depth maps in which darker colors are closer to the eye and lighter colors are farther from the eye.

Before Netpbm 10.53 (December 2010), pamstereogram used higher (lighter) numbers for things closer to the eye without -crosseyed and vice versa.

-makemask
Instead of a stereogram, output a PAM mask image showing coloring constraints. New pixels will be taken from the pattern file where the mask is black. Copies of existing pixels will be taken from the pattern file where the mask is white. The -makemask option can be used to help create more sophisticated pattern files (to use with -patfile) Note that -makemask ignores -magnifypat; it always produces masks that assume a pattern magnification of 1.
-eyesep=inches
Specify the separation in inches between your eyes. The default, 2.5 inches (6.4 cm), should be sufficient for most people and probably doesn't need to be changed.
-depth=fraction
Specify the output image's depth of field. That is, fraction represents the fractional distance of the near plane from the far plane. Smaller numbers make the 3-D image easier to perceive but flatter. Larger numbers make the 3-D image more difficult to perceive but deeper. The default, 0.3333, generally works fairly well.
-planes=near_pixels,far_pixels
Explicitly specify the distance between repeated pixels in the near plane and in the far plane. This is an alternative to -eyesep and -depth. The following equalities hold:
  • eyesep = 2 * far
  • depth = 2 * (far &minus; near) /
    (2 * far &minus; near)

    The number of distinct 3-D depths is far &minus; near + 1. One might say that -eyesep and -depth are a more human-friendly way to specify stereoscopic parameters (distance between eyes and tradeoff between perceptibility and depth) while -planes is a more computer-centric way (pixel distances in the resulting stereogram).

    This option was new in Netpbm 10.59 (June 2012).

-randomseed=integer
Specify a seed to be used for the random number generator. The default is to use a seed based on the time of day, to one second granularity.

It is useful to specify the seed if you want to create reproducible results. With the same random seed, you should get identical results every time you run pamstereogram.

This is irrelevant if you use a pattern file (-patfile option), because there is no random element to pamstereogram's behavior.

This option was new in Netpbm 10.32 (February 2006).

PARAMETERS

The only parameter, infile, is the name of an input file that is a depth map image. If you don't specify infile, the input is from standard input.

The input is a PAM image of depth 1. Each sample represents the distance from the eye that the 3-D image at that location should be. Lower (darker) numbers mean further from the eye.

NOTES

Input Images

pamstereogram pays no attention to the image's tuple type and ignores all planes other than plane 0.

Like any Netpbm program, pamstereogram will accept PNM input as if it were the PAM equivalent.

Mapped-texture Stereograms

In a mapped-texture stereogram (MTS), the 3-D image can be drawn with true colors. Unlike a SIRDS or tiled-image SIS, however, the image portrayed by an MTS is apparent in normal 2-D viewing. It appears repeated multiple times and overlapped with itself, but it is not hidden.

You create an MTS with pamstereogram by passing the filename of a PAM <q>texture image</q> with a -texfile option. A texture image portrays the same 3-D object as the depth-map image but indicates the colors that the program should apply to the object.

pamstereogram ignores the texture image's background color when it overlaps copies of the 3-D object. This prevents, for example, a bright-red object on a black background from being drawn as a dark-red object (a blend of 50% bright red and 50% black); instead, the program ignores the black and the object remains bright red. A consequence of this feature is that an MTS looks best when the objects in the texture image have a crisp outline. Smooth transitions to the background color result in unwanted color artifacts around edges because the program ignores only exact matches with the background color.

You should specify a larger-than-normal value for -eyesep (and/or -dpi) when producing an MTS. Otherwise, the 3-D object will repeat so many times that most colored pixels will overlap other colored pixels, reducing the number of true-colored pixels that remain.

An MTS can employ a background pattern (-patfile). In this case, pamstereogram replaces background pixels with pattern pixels in the final step of generating the image.

Miscellaneous

A good initial test is to input an image consisting of a solid shape of distance 0 within a large field of maximum distance (e.g., a white square on a black background).

With the default values for -dpi and -eyesep, pattern images that are 128 pixels wide can tile seamlessly.

EXAMPLES

Generate a SIRDS out of small, brightly colored squares and prepare it for display on an 87 DPI monitor:

    pamstereogram depthmap.pam \
        -dpi 87 -verbose -color -maxval 1 -magnifypat 3 \
        >3d.pam

Generate a SIS by tiling a PPM file (a prior run with -verbose indicates how wide the pattern file should be for seamless tiling, although any width is acceptable for producing SISes):

    pamstereogram depthmap.pam -patfile mypattern.ppm >3d.pam

Generate an MTS by associating colors with a depth-mapped object (using a large eye separation to reduce the number of repetitions of the texture image) and twice smoothing over background-colored speckles:

    pamstereogram depthmap.pam \
        -texfile colormap.pam -smoothing 2 -eyesep 3.5 \
        >3d.pam
