PARTCLONE(8) Manuel de l'utilisateur Partclone PARTCLONE(8)

NOM

partclone - L'utilitaire pour cloner et restaurer une partition.

SYNTAXE

partclone.[fstype] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] cible} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] fichier_journal [-R | --rescue] [-L | --logfile] fichier_journal [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPTION

partclone.[fstype] fait partie du projet Partclone. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une plus grande compatibilité du système de fichiers en utilisant les bibliothèques existantes, par exemple e2fslibs est utilisé pour lire le bloc utilisé d'une partition ext2.

Les systèmes de fichiers supportés par Partclone incluent btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Supporte également certains systèmes d'exploitation non-Linux, par exemple : NTFS, FAT et EXFAT (pour Windows), HFS plus (MAC OS APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) et MINIX (MINIX3).

Tous les utilitaires partclone peuvent être exécutés comme partclone.[fstype], ce qui est très similaire à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, lancez simplement partclone.hfsp

       Système de fichiers                 partclone.[fstype]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       autres (FS non supportés)   partclone.imager

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-s FICHIER, --source FICHIER

FICHIER source. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique, en fonction de votre action. Normalement, la source de sauvegarde est un périphérique, la source de restauration est un fichier image.

La réception de données depuis un pipeline n'est supportée QUE pour la restauration, ignorez simplement l'option -s ou utilisez '-' pour recevoir des données depuis stdin.

-o FICHIER, --output FICHIER

FICHIER de sortie. Le FICHIER peut être un fichier image (partclone générera) ou un périphérique, en fonction de votre action. Normalement, la sortie de sauvegarde vers un fichier image et la sortie de restauration vers un périphérique.

L'envoi de données vers un pipeline est également supporté UNIQUEMENT pour la sauvegarde, ignorez simplement l'option -o ou utilisez '-' pour envoyer des données vers stdout.

-O FICHIER, --overwrite FICHIER

Écrase le FICHIER s'il existe.

-W FICHIER, --restore_raw_file FICHIER

Crée un fichier brut spécial pour le périphérique de boucle.

-c, --clone

Sauvegarde la partition dans le format d'image spécial.

-r, --restore

Restaure la partition à partir du format d'image spécial.

-b, --dev-to-dev

Copie locale de périphérique à périphérique à la volée, la source et la sortie sont toutes deux des périphériques.

-D, --domain

Crée un fichier journal de domaine GNU Ddrescue à partir du périphérique source. C'est un fichier lisible par l'homme dans lequel + marque les zones de blocs utilisées et ? marque les zones libres.

--offset_domain=X

Ajoute X (en octets) à toutes les positions signalées dans le fichier journal de domaine.

--restore_raw_file

Création d'un fichier brut spécial pour le périphérique de boucle.

-L FICHIER, --logfile FICHIER

Spécifie un chemin spécial pour enregistrer les informations du journal de partclone. (par défaut /var/log/partclone.log)

-R, --rescue

Continue après les erreurs de lecture du disque.

-C, --no_check

Ne vérifie pas la taille du périphérique et l'espace libre.

-N, --ncurses

Utilise l'interface utilisateur textuelle Ncurses.

-I, --ignore_fschk

Ignore la vérification du système de fichiers.

-i, --ignore_crc

Ignore les erreurs de vérification CRC.

-F, --force

Force la progression.

-f sec, --UI-fresh sec

Spécifie un intervalle en secondes pour l'actualisation de l'interface utilisateur.

-z taille, --buffer_size taille

Taille du tampon de lecture/écriture (par défaut : 1048576)

-q, --quiet

Désactive les messages de progression.

-dniveau, --debug niveau

Définit le niveau de débogage [1|2|3].

-x, --compresscmd CMD

Lance CMD comme un pipeline de sortie pour compresser l'image clonée.

-aX, --checksum-mode=X

Formule de somme de contrôle à utiliser pour ajouter la détection d'erreurs.

où X :

0 : Pas de somme de contrôle (pas de ralentissement, image la plus petite)

1 : CRC32 (Rapide à calculer, détection de base)

2 : xxHash, algorithme de hachage non cryptographique extrêmement rapide.

-kX, --blocks-per-checksum=X

Écrit une somme de contrôle pour tous les X blocs.

-w, --skip_write_error

Continue la restauration en cas d'erreurs d'écriture.

--write-direct-io

Écrit les données dans la partition CIBLE sans cache.

--read-direct-io

Lit les données depuis la partition SOURCE sans cache.

-B, --no_block_detail

Affiche les messages de progression sans détails sur les blocs.

--binary-prefix

Affiche la progression avec la taille en bits (par défaut en Mo, Go...).

--prog-second

Affiche la progression en secondes (par défaut en minutes).

-E, --offset=X

Ajoute un décalage X (en octets) à la SORTIE.

-T, --btfiles

Restaure le bloc sous forme de fichier pour ClonezillaBT.

-t, --btfiles_torrent

Restaure le bloc sous forme de fichier pour ClonezillaBT mais génère uniquement le torrent.

-n, --note NOTE

Affiche un message NOTE (128 mots).

-h, --help

Affiche un résumé des options.

-v, --version

Affiche la version
partclone.8.en - partclone

NOM

partclone

cloner et restaurer des partitions

SYNOPSIS

partclone [-c|-r] [-s source] [-o destination] [-d] [-N number] [-b block-size] [-p part-size] [-L log-file] [-Z compress-type] [-A number]

DESCRIPTION

partclone est un programme qui permet de cloner et de restaurer des partitions. Il est capable de cloner des systèmes de fichiers tels que ext2, ext3, ext4, reiserfs, reiser4, btrfs, xfs, ntfs, fat32, hfs+, ufs, etc. Il peut aussi cloner une partition entière sans tenir compte du système de fichiers, à la manière de dd.

partclone peut lire et écrire à partir de périphériques de stockage, de fichiers images, ou de flux standards (stdin/stdout).

Il est écrit en C et utilise des fonctions du noyau Linux pour la manipulation des systèmes de fichiers. Cela permet de créer des copies de partitions à chaud (sans démonter le système de fichiers) pour les systèmes de fichiers supportés.

Le programme peut également enregistrer des informations sur le système de fichiers, telles que le type de système de fichiers, la taille du système de fichiers, le nombre de blocs, etc.

OPTIONS

Les options suivantes sont disponibles :

-c, --clone
Cloner la partition.
-r, --restore
Restaurer la partition.
-s, --source source
Spécifie la source. Il peut s'agir d'un périphérique (par ex. /dev/hda1) ou d'un fichier image (par ex. hda1.img).
Utiliser '-' pour lire depuis stdin.
-o, --output destination
Spécifie la destination. Il peut s'agir d'un périphérique (par ex. /dev/hda1) ou d'un fichier image (par ex. hda1.img).
Utiliser '-' pour écrire sur stdout.
-d, --debug
Activer le mode de débogage. Des informations détaillées sur le processus seront affichées.
-N, --number number
Spécifie le nombre de blocs à copier ou à restaurer. Utile pour les partitions partielles.
-b, --block-size block-size
Spécifie la taille des blocs à utiliser pour la copie ou la restauration. La valeur par défaut est 4096 octets.
-p, --part-size part-size
Spécifie la taille de la partition. Utile lorsque vous travaillez avec des fichiers images qui ne sont pas de la taille exacte de la partition d'origine.
-L, --log-file log-file
Spécifie le fichier journal où enregistrer les informations du programme.
-Z, --compress-type compress-type
Spécifie le type de compression à utiliser. Les valeurs possibles sont : gzip, bzip2, lzma, xz, lzo, zstd. Utile pour créer des fichiers images compressés.
-A, --autobackup number
Active la sauvegarde automatique des données. Si la restauration échoue, la copie de sauvegarde sera utilisée.

FICHIERS

/var/log/partclone.log

Le fichier journal de partclone

EXEMPLES

 Cloner /dev/hda1 vers hda1.img et afficher les informations de débogage.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 Restaurer /dev/hda1 à partir de hda1.img et afficher les informations de débogage.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 Restaurer une image depuis clonezilla (split, gzip,) avec une source stdin
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

Les diagnostics suivants peuvent être émis sur stderr :

partclone fournit des codes de retour qui peuvent être utilisés dans les scripts :

Code Diagnostic
0 Le programme s'est terminé avec succès.
1 Le clonage ou la restauration semble avoir échoué.
