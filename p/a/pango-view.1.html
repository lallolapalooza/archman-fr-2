PANGO-VIEW(1) Commandes Pango PANGO-VIEW(1)

NOM

pango-view - Visionneuse de texte Pango

SYNTAXE

pango-view [OPTIONS...] FICHIER

DESCRIPTION

pango-view formate un texte en utilisant Pango, avec des options pour exploiter la plupart des fonctionnalités de mise en page de Pango.

OPTIONS D'AIDE

-h, --help

Afficher les options d'aide.

--help-all

Afficher toutes les options d'aide.

--help-cairo

Afficher l'aide pour les options comprises par le backend cairo.

--version

Afficher la version de la commande et quitter.

OPTIONS DU BACKEND CAIRO

--annotate=FLAGS

Annoter la sortie. Liste séparée par des virgules de gravité, progression, lignes de base, mise en page, ligne, exécution, cluster, caractère, glyphe, caret, pente

OPTIONS D'APPLICATION

--no-auto-dir

Pas de direction de mise en page selon le contenu.

--backend=cairo/xft/ft2

Backend Pango à utiliser pour le rendu (par défaut : cairo).

--background=red/#rrggbb/#rrggbbaa/transparent

Définir la couleur d'arrière-plan.

-q, --no-display

Ne pas afficher (écrire juste dans un fichier ou autre).

--dpi=nombre

Définir la résolution.

--align=left/center/right

Définir l'alignement du texte.

--ellipsize=start/middle/end

Définir le mode d'élision.

--font=description

Définir la description de la police.

--foreground=red/#rrggbb/#rrggbbaa

Définir la couleur du texte.

--gravity=south/east/north/west/auto

Définir la gravité de base : rotation du glyphe.

--gravity-hint=natural/strong/line

Définir l'indice de gravité.

--header

Afficher les options dans la sortie.

--height=+points/-numlines

Définir la hauteur en points (positif) ou le nombre de lignes (négatif) pour l'élision.

--hinting=none/auto/slight/medium/full

Définir le style de hinting.

--antialias=none/gray/subpixel

Définir l'anti-crénelage.

--hint-metrics=on/off

Définir les métriques de hinting.

--subpixel-positions

Définir le positionnement subpixel.

--subpixel-order=rgb/bgr/vrgb/vbgr

Définir l'ordre subpixel.

--indent=points

Définir l'indentation du paragraphe (en points).

--spacing=points

Définir l'espacement des lignes (en points).

--line-spacing=factor

Définir le facteur d'étalement pour la hauteur des lignes.

--justify

Étendre les lignes du paragraphe pour qu'elles soient justifiées.

--justify-last-line

Justifier la dernière ligne du paragraphe.

--language=en_US/etc

Définir la langue à utiliser pour la sélection de la police.

--margin=nombres de style CSS en pixels

Définir la marge de la sortie en pixels.

--markup

Interpréter le texte comme du balisage Pango.

-o, --output=fichier

Enregistrer l'image rendue dans le fichier de sortie.

--pixels

Utiliser des unités de pixels au lieu de points (définit dpi à 72).

--pango-units

Utiliser des unités Pango au lieu de points.

--rtl

Définir la direction de base de droite à gauche.

--rotate=degrés

Définir l'angle de rotation des résultats,

-n, --runs=entier

Exécuter le moteur de mise en page Pango ce nombre de fois.

--single-par

Activer le mode paragraphe unique.

-t, --text=chaîne

Texte à afficher (au lieu d'un fichier).

--waterfall

Créer un affichage en cascade.

-w, --width=points

Largeur en points à laquelle envelopper les lignes ou élider.

--wrap=word/char/word-char

Mode de retour à la ligne du texte (nécessite la définition d'une largeur).

--serialized=FICHIER

Créer une mise en page à partir d'un fichier sérialisé,

--serialize-to=FICHIER

Sérialiser le résultat dans un fichier.
