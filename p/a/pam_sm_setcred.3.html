NOM

pam_sm_setcred - fonction de service PAM pour modifier les identifiants

SYNTAXE

#include <security/pam_modules.h>

int pam_sm_setcred(pam_handle_t *pamh, int flags, int argc, const char **argv);

DESCRIPTION

La fonction pam_sm_setcred est l'implémentation du module de service de l'interface pam_setcred(3).

Cette fonction effectue la tâche de modification des identifiants de l'utilisateur par rapport au schéma d'autorisation correspondant. Généralement, un module d'authentification peut avoir accès à plus d'informations sur un utilisateur que son jeton d'authentification. Cette fonction est utilisée pour rendre ces informations disponibles à l'application. Elle ne doit être appelée qu'*après* que l'utilisateur a été authentifié mais avant qu'une session ne soit établie.

Les indicateurs valides, qui peuvent être combinés logiquement avec PAM_SILENT, sont :

PAM_SILENT

Ne pas émettre de messages.

PAM_ESTABLISH_CRED

Initialiser les identifiants de l'utilisateur.

PAM_DELETE_CRED

Supprimer les identifiants associés au service d'authentification.

PAM_REINITIALIZE_CRED

Réinitialiser les identifiants de l'utilisateur.

PAM_REFRESH_CRED

Prolonger la durée de vie des identifiants de l'utilisateur.

La manière dont la pile auth est parcourue pour évaluer l'appel de fonction pam_setcred(), indépendamment des codes de retour de pam_sm_setcred(), est exactement la même manière dont elle a été parcourue lors de l'évaluation de l'appel de bibliothèque pam_authenticate(). Typiquement, si une entrée de pile a été ignorée lors de l'évaluation de pam_authenticate(), elle sera ignorée lorsque libpam évaluera l'appel de fonction pam_setcred(). Sinon, les codes de retour de chaque appel pam_sm_setcred() spécifique au module sont traités comme requis.

VALEURS DE RETOUR

PAM_CRED_UNAVAIL

Ce module ne peut pas récupérer les identifiants de l'utilisateur.

PAM_CRED_EXPIRED

Les identifiants de l'utilisateur ont expiré.

PAM_CRED_ERR

Ce module n'a pas pu définir les identifiants de l'utilisateur.

PAM_SUCCESS

Les identifiants de l'utilisateur ont été définis avec succès.

PAM_USER_UNKNOWN

L'utilisateur n'est pas connu de ce module d'authentification.

Ces valeurs de retour, non-PAM_SUCCESS, entraîneront généralement l'échec de la pile d'identifiants. La première erreur de ce type dominera la valeur de retour de pam_setcred().
