pactl(1) Manuel des commandes générales pactl(1)

NOM

pactl - Contrôler un serveur sonore PulseAudio en cours d'exécution

SYNTAXE

pactl [options] COMMANDE [ARGUMENTS ...]

pactl --help

pactl --version

DESCRIPTION

pactl peut être utilisé pour émettre des commandes de contrôle vers le serveur sonore PulseAudio.

pactl expose uniquement un sous-ensemble des opérations disponibles. Pour l'ensemble complet, utilisez pacmd(1).

OPTIONS

-h | --help
Afficher l'aide.
--version
Afficher les informations de version.
-s | --server=SERVEUR
Choisir le serveur auquel se connecter.
-f | --format=FORMAT
Choisir le format de sortie, les options disponibles sont "text" ou "json".
-n | --client-name=NOM
Spécifier le nom du client que pactl doit passer au serveur lors de la connexion.

COMMANDES

Lorsqu'ils sont fournis comme arguments aux commandes ci-dessous, les noms spéciaux @DEFAULT_SINK@, @DEFAULT_SOURCE@ et @DEFAULT_MONITOR@ peuvent être utilisés pour spécifier la sortie, la source et le moniteur par défaut respectivement.

stat
Afficher quelques statistiques sur l'utilisation de la mémoire du démon PulseAudio.
info
Afficher des informations sur le démon PulseAudio.
list [short] [TYPE]
Afficher tous les modules actuellement chargés, les sorties, les sources, les flux, etc. disponibles. TYPE doit être l'un des éléments suivants : modules, sinks, sources, sink-inputs, source-outputs, clients, samples, cards, message-handlers. S'il n'est pas spécifié, toutes les informations sont listées à l'exception des gestionnaires de messages. Si short est donné, la sortie est au format tabulaire, pour un traitement facile par les scripts.
exit
Demande au serveur PulseAudio de se terminer.
upload-sample FILENAME [NAME]
Télécharger un son à partir du fichier audio spécifié dans le cache d'échantillons. Les types de fichiers pris en charge sont ceux compris par libsndfile. L'échantillon dans le cache porte le nom du fichier audio, à moins que le nom ne soit explicitement spécifié.
play-sample NAME [SINK]
Jouer l'échantillon spécifié à partir du cache d'échantillons. Il est joué sur la sortie par défaut, sauf si le nom symbolique ou l'indice numérique de la sortie sur laquelle il doit être joué est spécifié.
remove-sample NAME
Supprimer l'échantillon spécifié du cache d'échantillons.
load-module NAME [ARGUMENTS ...]
Charger le module spécifié avec les arguments spécifiés dans le serveur sonore en cours d'exécution. Affiche l'indice numérique du module qui vient d'être chargé sur STDOUT. Vous pouvez l'utiliser pour décharger le module plus tard.
unload-module ID|NAME
Décharger l'instance du module identifiée par l'indice numérique spécifié ou décharger tous les modules par le nom spécifié.
move-sink-input ID SINK
Déplacer le flux de lecture spécifié (identifié par son indice numérique) vers la sortie spécifiée (identifiée par son nom symbolique ou son indice numérique).
move-source-output ID SOURCE
Déplacer le flux d'enregistrement spécifié (identifié par son indice numérique) vers la source spécifiée (identifiée par son nom symbolique ou son indice numérique).
suspend-sink SINK true|false
Suspendre ou reprendre la sortie spécifiée (qui peut être spécifiée soit par son nom symbolique, soit par son indice numérique), selon que true (suspendre) ou false (reprendre) est passé comme dernier argument. Suspendre une sortie mettra en pause toute lecture. Selon le module implémentant la sortie, cela pourrait avoir pour effet de fermer le périphérique sous-jacent, le rendant disponible pour d'autres applications. Le comportement exact dépend du module.
suspend-source SOURCE true|false
Suspendre ou reprendre la source spécifiée (qui peut être spécifiée soit par son nom symbolique, soit par son indice numérique), selon que true (suspendre) ou false (reprendre) est passé comme dernier argument. Suspendre une source mettra en pause toute capture. Selon le module implémentant la source, cela pourrait avoir pour effet de fermer le périphérique sous-jacent, le rendant disponible pour d'autres applications. Le comportement exact dépend du module.
set-card-profile CARD PROFILE
Définir la carte spécifiée (identifiée par son nom symbolique ou son indice numérique) sur le profil spécifié (identifié par son nom symbolique).
get-default-sink
Retourne le nom symbolique de la sortie par défaut.
set-default-sink SINK
Faire de la sortie spécifiée (identifiée par son nom symbolique ou son indice numérique) la sortie par défaut. Utiliser le nom symbolique @NONE@ pour annuler la sortie par défaut définie par l'utilisateur. Cela fera que pulseaudio reviendra à la sélection de la sortie par défaut basée sur la priorité des sorties.
set-sink-port SINK PORT
Définir la sortie spécifiée (identifiée par son nom symbolique ou son indice numérique) sur le port spécifié (identifié par son nom symbolique).
get-default-source
Retourne le nom symbolique de la source par défaut.
set-default-source SOURCE
Faire de la source spécifiée (identifiée par son nom symbolique ou son indice numérique) la source par défaut. Utiliser le nom symbolique @NONE@ pour annuler la source par défaut définie par l'utilisateur. Cela fera que pulseaudio reviendra à la sélection de la source par défaut basée sur la priorité des sources.
set-source-port SOURCE PORT
Définir la source spécifiée (identifiée par son nom symbolique ou son indice numérique) sur le port spécifié (identifié par son nom symbolique).
set-port-latency-offset CARD PORT OFFSET
Définir un décalage de latence pour un port spécifié (identifié par son nom symbolique) qui appartient à une carte (identifiée par son nom symbolique ou son indice numérique). OFFSET est un nombre qui représente le décalage de latence en microsecondes.
get-sink-volume SINK
Obtenir le volume de la sortie spécifiée (identifiée par son nom symbolique ou son indice numérique) affiché dans le même format que la commande `info`.
set-sink-volume SINK VOLUME [VOLUME ...]
Définir le volume de la sortie spécifiée (identifiée par son nom symbolique ou son indice numérique). VOLUME peut être spécifié comme un entier (par ex. 2000, 16384), un facteur linéaire (par ex. 0.4, 1.100), un pourcentage (par ex. 10%, 100%) ou une valeur en décibels (par ex. 0dB, 20dB). Si la spécification du volume commence par + ou -, le réglage du volume sera relatif au volume actuel de la sortie. Une seule valeur de volume affecte tous les canaux ; si plusieurs valeurs de volume sont données, leur nombre doit correspondre au nombre de canaux de la sortie.
get-source-volume SOURCE

pactl(1) — Documentation Arch Linux

NOM

pactl — Contrôle d'un serveur PulseAudio

SYNOPSIS

pactl [ OPTIONS ] COMMAND [ ARGS... ]

DESCRIPTION

pactl est un utilitaire en ligne de commande pour contrôler un serveur PulseAudio. Il permet de voir des informations sur les périphériques audio et les flux, ainsi que de modifier leurs propriétés.

OPTIONS

-n, --no-exit-idle-time
N'arrête pas le serveur PulseAudio lorsqu'il devient inactif.
-H, --server HOST
Spécifie le serveur à utiliser.
-s, --status
Affiche des informations d'état sur le serveur.
-L, --log-target TARGET
Cible du journal.
-q, --quiet
Réduit le niveau de verbosité.
-v, --verbose
Augmente le niveau de verbosité.
-F, --file FILE
Lit les commandes à partir du fichier spécifié.

COMMANDS

get-card-profile-list CARD
Récupère la liste des profils disponibles pour la carte spécifiée (identifiée par son nom symbolique ou son index numérique).
get-card-profile CARD
Récupère le profil actif de la carte spécifiée.
set-card-profile CARD PROFILE
Définit le profil de la carte spécifiée (identifiée par son nom symbolique ou son index numérique).
get-sink-input-list
Récupère la liste des entrées de mixage (sink inputs).
get-source-output-list
Récupère la liste des sorties de source (source outputs).
get-sink-list
Récupère la liste des mixages (sinks).
get-source-list
Récupère la liste des sources.
get-server-info
Récupère des informations sur le serveur.
info [OBJECT]
Affiche des informations sur le serveur ou sur un objet spécifique (identifié par son nom symbolique ou son index numérique). Si aucun objet n'est spécifié, affiche des informations sur le serveur.
set-source-volume SOURCE VOLUME [VOLUME ...]
Définit le volume de la source spécifiée (identifiée par son nom symbolique ou son index numérique). Le VOLUME peut être spécifié comme un entier (par exemple 2000, 16384), un facteur linéaire (par exemple 0.4, 1.100), un pourcentage (par exemple 10%, 100%) ou une valeur en décibels (par exemple 0dB, 20dB). Si la spécification du volume commence par un + ou un -, l'ajustement du volume sera relatif au volume actuel de la source. Une seule valeur de volume affecte tous les canaux ; si plusieurs valeurs de volume sont données, leur nombre doit correspondre au nombre de canaux de la source.
set-sink-input-volume INPUT VOLUME [VOLUME ...]
Définit le volume de l'entrée de mixage spécifiée (identifiée par son index numérique). Le VOLUME peut être spécifié comme un entier (par exemple 2000, 16384), un facteur linéaire (par exemple 0.4, 1.100), un pourcentage (par exemple 10%, 100%) ou une valeur en décibels (par exemple 0dB, 20dB). Si la spécification du volume commence par un + ou un -, l'ajustement du volume sera relatif au volume actuel de l'entrée de mixage. Une seule valeur de volume affecte tous les canaux ; si plusieurs valeurs de volume sont données, leur nombre doit correspondre au nombre de canaux de l'entrée de mixage.
set-source-output-volume OUTPUT VOLUME [VOLUME ...]
Définit le volume de la sortie de source spécifiée (identifiée par son index numérique). Le VOLUME peut être spécifié comme un entier (par exemple 2000, 16384), un facteur linéaire (par exemple 0.4, 1.100), un pourcentage (par exemple 10%, 100%) ou une valeur en décibels (par exemple 0dB, 20dB). Si la spécification du volume commence par un + ou un -, l'ajustement du volume sera relatif au volume actuel de la sortie de source. Une seule valeur de volume affecte tous les canaux ; si plusieurs valeurs de volume sont données, leur nombre doit correspondre au nombre de canaux de la sortie de source.
get-sink-mute SINK
Récupère l'état de la sourdine du mixage spécifié (identifié par son nom symbolique ou son index numérique).
set-sink-mute SINK 1|0|toggle
Définit l'état de la sourdine du mixage spécifié (identifié par son nom symbolique ou son index numérique).
get-source-mute SOURCE
Récupère l'état de la sourdine de la source spécifiée (identifiée par son nom symbolique ou son index numérique).
set-source-mute SOURCE 1|0|toggle
Définit l'état de la sourdine de la source spécifiée (identifiée par son nom symbolique ou son index numérique).
set-sink-input-mute INPUT 1|0|toggle
Définit l'état de la sourdine de l'entrée de mixage spécifiée (identifiée par son index numérique).
set-source-output-mute OUTPUT 1|0|toggle
Définit l'état de la sourdine de la sortie de source spécifiée (identifiée par son index numérique).
set-sink-formats SINK FORMATS
Définit les formats supportés du mixage spécifié (identifié par son index numérique) s'ils sont supportés par le mixage. FORMATS est spécifié comme une liste de formats séparés par des points-virgules (;) sous la forme 'encodage[, cle1=valeur1, cle2=valeur2, ...]' (par exemple, AC3 à 32000, 44100 et 48000 Hz serait spécifié comme 'ac3-iec61937, format.rate = "[ 32000, 44100, 48000 ]"'). Voir https://www.freedesktop.org/wiki/Software/PulseAudio/Documentation/User/SupportedAudioFormats/ pour les encodages possibles.
send-message RECIPIENT MESSAGE MESSAGE_PARAMETERS
Envoie un message à l'objet destinataire spécifié. Si applicable, une chaîne supplémentaire contenant les paramètres du message peut être spécifiée. Une chaîne est retournée en réponse au message. Pour les messages disponibles, voir https://cgit.freedesktop.org/pulseaudio/pulseaudio/tree/doc/messaging_api.txt.
subscribe
S'abonne aux événements. `pactl` ne se termine pas de lui-même, mais continue d'attendre de nouveaux événements.
