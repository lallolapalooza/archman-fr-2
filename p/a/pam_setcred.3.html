NOM

pam_setcred - établir / supprimer les identifiants d'un utilisateur

SYNTAXE

#include <security/pam_appl.h>

int pam_setcred(pam_handle_t *pamh, int flags);

DESCRIPTION

La fonction pam_setcred est utilisée pour établir, maintenir et supprimer les identifiants d'un utilisateur. Elle doit être appelée pour définir les identifiants après qu'un utilisateur a été authentifié et avant qu'une session ne soit ouverte pour l'utilisateur (avec pam_open_session(3)). Les identifiants doivent être supprimés après que la session a été fermée (avec pam_close_session(3)).

Un identifiant est quelque chose que l'utilisateur possède. C'est une propriété, telle qu'un ticket Kerberos, ou une appartenance à un groupe supplémentaire qui constitue l'unicité d'un utilisateur donné. Sur un système Linux, l'UID et les GID de l'utilisateur sont également des identifiants. Cependant, il a été décidé que ces propriétés (ainsi que les groupes supplémentaires par défaut dont l'utilisateur fait partie) sont des identifiants qui doivent être définis directement par l'application et non par PAM. Ces identifiants doivent être établis, par l'application, avant un appel à cette fonction. Par exemple, initgroups(2) (ou équivalent) aurait dû être effectué.

Les flags valides, dont l'un quelconque peut être combiné logiquement avec PAM_SILENT, sont :

PAM_ESTABLISH_CRED

Initialise les identifiants de l'utilisateur.

PAM_DELETE_CRED

Supprime les identifiants de l'utilisateur.

PAM_REINITIALIZE_CRED

Réinitialise complètement les identifiants de l'utilisateur.

PAM_REFRESH_CRED

Prolonge la durée de vie des identifiants existants.

VALEURS DE RETOUR

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_CRED_ERR

Échec de la définition des identifiants de l'utilisateur.

PAM_CRED_EXPIRED

Les identifiants de l'utilisateur ont expiré.

PAM_CRED_UNAVAIL

Échec de la récupération des identifiants de l'utilisateur.

PAM_SUCCESS

Les données ont été stockées avec succès.

PAM_SYSTEM_ERR

Un pointeur NULL a été soumis comme handle PAM, la fonction a été appelée par un module ou une autre erreur système s'est produite.

PAM_USER_UNKNOWN

L'utilisateur n'est pas connu d'un module d'authentification.

VOIR AUSSI
