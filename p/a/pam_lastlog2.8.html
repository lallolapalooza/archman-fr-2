NOM

pam_lastlog2 - Module PAM pour afficher la date de dernière connexion

SYNTAXE

pam_lastlog2.so [debug] [silent] [silent_if=<services>] [database=<file>]

DESCRIPTION

pam_lastlog2 est un module PAM destiné à afficher une ligne d'informations concernant la dernière connexion de l'utilisateur. Le module utilise le fichier de base de données /var/lib/lastlog/lastlog2.db pour stocker toutes les informations.

Comparé à pam_lastlog, ce module PAM est compatible Y2038 et utilise sqlite3 pour stocker les informations.

OPTIONS

debug

Affiche des informations de débogage.

silent

Évite tous les messages sauf les erreurs et n'informe pas l'utilisateur d'une connexion précédente ; met uniquement à jour la base de données /var/lib/lastlog/lastlog2.db.

silent_if=<services>

L'argument services est une liste de services PAM séparés par des virgules. Si un service est listé ici, le message de dernière connexion ne sera pas affiché.

database=<file>

Utilise file au lieu de /var/lib/lastlog/lastlog2.db.

TYPES DE MODULES FOURNIS

Le type de module session est fourni pour afficher les informations sur la dernière connexion et mettre à jour le fichier lastlog.

VALEURS DE RETOUR

PAM_SUCCESS

Tout s'est bien déroulé.

PAM_SERVICE_ERR

Erreur interne du module de service. Cela inclut les erreurs de lecture ou d'écriture dans la base de données.

PAM_USER_UNKNOWN

Utilisateur inconnu.

PAM_IGNORE

Retourné par les types de services qui ne font rien.

EXEMPLES

Ajoutez la ligne suivante par exemple à /etc/pam.d/login pour afficher l'heure de la dernière connexion d'un utilisateur :

session optional pam_lastlog2.so silent_if=gdm,gdm-password

Il appartient à l'administrateur de décider si l'utilisateur peut se connecter (optional/required) lorsque pam_lastlog2 a retourné une erreur.
