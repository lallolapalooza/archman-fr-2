NOM

partclone.extfs - L'utilitaire pour cloner et restaurer une partition.

SYNTAXE

partclone.[fstype] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] cible} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] logfile [-R | --rescue] [-L | --logfile] logfile [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPTION

partclone.[fstype] fait partie du projet Partclone. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une compatibilité plus élevée avec le système de fichiers en utilisant les bibliothèques existantes, par exemple e2fslibs est utilisé pour lire le bloc utilisé de la partition ext2.

Les systèmes de fichiers supportés par Partclone incluent btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Il prend également en charge certains systèmes d'exploitation non-linux, par exemple NTFS, FAT et EXFAT (pour Windows), HFS plus (APPLE MAC OS), UFS2 (FreeBSD), VMFS (VMWare Vsphere) et MINIX (MINIX3).

Tous les utilitaires partclone peuvent être exécutés comme partclone.[fstype] est très similaire à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, exécutez simplement partclone.hfsp

       Système de fichiers                 partclone.[fstype]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       autres (FS non supportés)   partclone.imager

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-s FICHIER, --source FICHIER

FICHIER source. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique en fonction de votre action. Normalement, la source de sauvegarde est un périphérique, la source de restauration est un fichier image.

La réception de données depuis un pipe est prise en charge UNIQUEMENT pour la restauration, ignorez simplement l'option -s ou utilisez '-' pour indiquer la réception de données depuis stdin.

-o FICHIER, --output FICHIER

FICHIER de sortie. Le FICHIER peut être un fichier image (que partclone générera) ou un périphérique en fonction de votre action. Normalement, la sortie de sauvegarde va vers un fichier image et la sortie de restauration va vers un périphérique.

L'envoi de données vers un pipe est également pris en charge UNIQUEMENT pour la sauvegarde, ignorez simplement l'option -o ou utilisez '-' pour indiquer l'envoi de données vers stdout.

-O FICHIER, --overwrite FICHIER

Écrase le FICHIER s'il existe.

-W FICHIER, --restore_raw_file FICHIER

crée un fichier brut spécial pour le périphérique de boucle.

-c, --clone

Sauvegarde la partition dans le format d'image spécial.

-r, --restore

Restaure la partition à partir du format d'image spécial.

-b, --dev-to-dev

Copie locale de périphérique à périphérique à la volée, la source et la sortie sont toutes deux des périphériques.

-D, --domain

Crée un fichier journal de domaine GNU Ddrescue à partir du périphérique source. C'est un fichier lisible par l'homme dans lequel + marque les zones de blocs utilisées et ? marque les zones libres.

--offset_domain=X

Ajoute X (en octets) à toutes les positions signalées dans le fichier journal de domaine

--restore_raw_file

Création d'un fichier brut spécial pour le périphérique de boucle.

-L FICHIER, --logfile FICHIER

Spécifie un chemin pour enregistrer les informations du journal partclone. (par défaut /var/log/partclone.log)

-R, --rescue

Continue après les erreurs de lecture sur disque.

-C, --no_check

Ne vérifie pas la taille de l'appareil et l'espace libre.

-N, --ncurses

Utilise l'interface utilisateur textuelle Ncurses.

-I, --ignore_fschk

Ignore la vérification du système de fichiers.

-i, --ignore_crc

Ignore les erreurs de vérification crc.

-F, --force

Force la progression.

-f sec, --UI-fresh sec

Spécifie un intervalle en secondes.

-z taille, --buffer_size taille

Taille du tampon de lecture/écriture (par défaut : 1048576)

-q, --quiet

Désactive les messages de progression.

-dniveau, --debug niveau

Définit le niveau de débogage [1|2|3]

-x, --compresscmd CMD

Démarre CMD comme un pipe de sortie pour compresser l'image clonée

-aX, --checksum-mode=X

Formule de somme de contrôle à utiliser pour ajouter la détection d'erreurs

où X :

0 : Pas de somme de contrôle (pas de ralentissement, image la plus petite)

1 : CRC32 (Calcul rapide, détection basique)

2 : xxHash, algorithme de hachage non cryptographique extrêmement rapide

-kX, --blocks-per-checksum=X

Écrit une somme de contrôle pour tous les X blocs

-w, --skip_write_error

Continue la restauration en cas d'erreurs d'écriture

--write-direct-io

Écrit les données dans la partition CIBLE sans cache

--read-direct-io

Lit les données à partir de la partition SOURCE sans cache

-B, --no_block_detail

Affiche les messages de progression sans détails sur les blocs

--binary-prefix

Affiche la progression avec la taille en bits (par défaut : Mo, Go...)

--prog-second

Affiche la progression en secondes (par défaut : minutes)

-E, --offset=X

Ajoute un décalage X (en octets) à la sortie

-T, --btfiles

Restaure le bloc en tant que fichier pour ClonezillaBT.

-t, --btfiles_torrent

Restaure le bloc en tant que fichier pour ClonezillaBT mais ne génère que le torrent.

-n, --note NOTE

Affiche un message Note (128 mots).

-h, --help

Affiche le résumé des options.

-v, --version

Affiche la versio

NOM

partclone.extfs - clone a filesystem (ext2, ext3, ext4).

SYNTAXIS

partclone.extfs [-R] [-s source] [-o destination] [-c] [-L logfile] [-d debuglevel]

DESCRIPTION

partclone est un programme pour cloner et restaurer des systèmes de fichiers. Il peut être utilisé pour cloner des systèmes de fichiers entiers, ou pour cloner des partitions spécifiques. partclone est utile pour sauvegarder et restaurer des systèmes de fichiers. partclone peut aussi cloner une image de Clonezilla.

OPTIONS

Les options suivantes sont disponibles :

-r, --restore
Restaurer une image sur une partition.
-s, --source source
Source pour le clonage ou la restauration. Il peut s'agir d'un périphérique (par exemple, /dev/hda1) ou d'un fichier image.
-o, --output destination
Destination pour le clonage ou la restauration. Il peut s'agir d'un périphérique (par exemple, /dev/hda1) ou d'un fichier image.
-c, --clone
Cloner une partition dans un fichier image.
-L, --log logfile
Enregistrer la sortie dans un fichier journal.
-d, --debug debuglevel
Activer la sortie de débogage. Le niveau de débogage peut être un nombre entier.

FICHIERS

/var/log/partclone.log

Le fichier journal de partclone

EXEMPLES

 cloner /dev/hda1 vers hda1.img et afficher les informations de débogage.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restaurer /dev/hda1 depuis hda1.img et afficher les informations de débogage.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 restaurer une image depuis clonezilla (split, gzip,) avec source stdin
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

Les diagnostics suivants peuvent être émis sur stderr :

partclone fournit des codes de retour qui peuvent être utilisés dans des scripts :

Code Diagnostic
0 Le programme s'est terminé avec succès.
1 Le clonage ou la restauration semblent avoir échoué.
