NOM

partclone - L'utilitaire pour cloner et restaurer une partition.

SYNTAXE

partclone.[typefst] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] cible} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] journal_de_bord [-R | --rescue] [-L | --logfile] journal_de_bord [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPTION

partclone.[typefst] fait partie du projet Partclone. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une plus grande compatibilité du système de fichiers en utilisant la bibliothèque existante, par exemple e2fslibs est utilisé pour lire le bloc utilisé de la partition ext2.

Les systèmes de fichiers pris en charge par Partclone incluent btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Prend également en charge certains systèmes d'exploitation non-linux, par exemple : NTFS, FAT et EXFAT (pour Windows), HFS plus (MAC OS APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) et MINIX (MINIX3).

Tous les utilitaires partclone peuvent être exécutés comme partclone.[typefst], ce qui est très similaire à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, exécutez simplement partclone.hfsp

       Système de fichiers                 partclone.[typefst]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       autres (Systèmes de fichiers non pris en charge)   partclone.imager

OPTIONS

Le programme suit la syntaxe habituelle de la ligne de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-s FICHIER, --source FICHIER

FICHIER source. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique en fonction de votre action. Normalement, la source de sauvegarde est un périphérique, la source de restauration est un fichier image.

La réception de données à partir d'un pipeline n'est prise en charge QUE pour la restauration, ignorez simplement l'option -s ou utilisez '-' qui signifie recevoir des données de stdin.

-o FICHIER, --output FICHIER

FICHIER de sortie. Le FICHIER peut être un fichier image (partclone générera) ou un périphérique en fonction de votre action. Normalement, la sortie de sauvegarde vers un fichier image et la restauration vers un périphérique.

L'envoi de données vers un pipeline est également pris en charge UNIQUEMENT pour la sauvegarde, ignorez simplement l'option -o ou utilisez '-' qui signifie envoyer des données à stdout.

-O FICHIER, --overwrite FICHIER

Écrase FICHIER, en l'écrasant s'il existe.

-W FICHIER, --restore_raw_file FICHIER

Crée un fichier brut spécial pour le périphérique de boucle.

-c, --clone

Enregistre la partition dans le format d'image spécial.

-r, --restore

Restaure la partition à partir du format d'image spécial.

-b, --dev-to-dev

Copie locale de périphérique à périphérique à la volée, la source et la sortie sont toutes deux des périphériques.

-D, --domain

Crée un fichier journal de domaine GNU Ddrescue à partir du périphérique source. C'est un fichier lisible par l'homme dans lequel + marque les zones de bloc utilisées et ? marque les zones libres.

--offset_domain=X

Ajoute X (en octets) à toutes les positions rapportées dans le fichier journal de domaine

--restore_raw_file

Création d'un fichier brut spécial pour le périphérique de boucle.

-L FICHIER, --logfile FICHIER

Indique le chemin spécial pour enregistrer les informations du journal de partclone. (par défaut /var/log/partclone.log)

-R, --rescue

Continue après les erreurs de lecture du disque.

-C, --no_check

Ne vérifie pas la taille du périphérique et l'espace libre.

-N, --ncurses

Utilise l'interface utilisateur textuelle Ncurses.

-I, --ignore_fschk

Ignore la vérification du système de fichiers.

-i, --ignore_crc

Ignore l'erreur de vérification crc.

-F, --force

Force la progression.

-f sec, --UI-fresh sec

Définit un intervalle différent en secondes.

-z taille, --buffer_size taille

Taille du tampon de lecture/écriture (par défaut : 1048576)

-q, --quiet

Désactive les messages de progression.

-dniveau, --debug niveau

Définit le niveau de débogage [1|2|3]

-x, --compresscmd CMD

Démarre CMD comme un tuyau de sortie pour compresser l'image clonée

-aX, --checksum-mode=X

Formule de somme de contrôle à utiliser pour ajouter la détection d'erreurs

où X :

0 : Pas de somme de contrôle (pas de ralentissement, image la plus petite)

1 : CRC32 (Rapide à calculer, détection de base)

2 : xxHash, algorithme de hachage non cryptographique extrêmement rapide

-kX, --blocks-per-checksum=X

Écrit une somme de contrôle pour tous les X blocs

-w, --skip_write_error

Continue la restauration en cas d'erreurs d'écriture

--write-direct-io

Écrit les données dans la partition CIBLE sans cache

--read-direct-io

Lit les données de la partition SOURCE sans cache

-B, --no_block_detail

Affiche les messages de progression sans détails sur les blocs

--binary-prefix

Affiche la progression avec la taille en bits (par défaut, il s'agit de Mo, Go...)

--prog-second

Affiche la progression en secondes (par défaut, il s'agit de minutes)

-E, --offset=X

Ajoute un décalage X (en octets) à la sortie

-T, --btfiles

Restaure le bloc sous forme de fichier pour ClonezillaBT.

-t, --btfiles_torrent

Restaure le bloc sous forme de fichier pour ClonezillaBT, mais ne génère que le torrent.

Affiche un message (128 mots).

Affiche un résumé des options.

NAME

partclone.hfsplus

save, restore and clone HFS+ file system

SYNOPSIS

partclone.hfsplus [-c|-r] [-s source] [-o output] [-b] [-N] [-p progress_bar_type] [-L logfile] [-d] [-v] [-z block_size] [-Z number_of_threads] [-q] [-Q checksum]

DESCRIPTION

The partclone.hfsplus command saves, restores and clones an HFS+ file system. It can work with a device or a file as source/output.

OPTIONS

The options are the same as the original partclone.

See partclone(8) for more details.

-c
Clone mode. Used to save the partition to an image file.
-r
Restore mode. Used to restore the partition from an image file.
-s source
Specify the source device or file.
-o output
Specify the output file or device.
-b
Run in batch mode. No interactive question will be asked.
-N
Disable checking of the file system size. Be careful when using this option.
-p progress_bar_type
Specify the progress bar type. Supported types are: pstyle1, pstyle2, pstyle3, pstyle4.
-L logfile
Specify the log file.
-d
Debug mode. Display more information during the process.
-v
Display the version of program.
-z block_size
Set the block size. Default is 4096.
-Z number_of_threads
Set the number of threads to use for saving/restoring. Default is 1.
-q
Quiet mode. Suppress all output except errors.
-Q checksum
Set the checksum algorithm. Supported algorithms are: md5, sha1, sha256, sha512.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 Clone /dev/hda1 to hda1.img and display debug information.
   partclone.hfsplus -c -d -s /dev/hda1 -o hda1.img
 Restore /dev/hda1 from hda1.img and display debug information.
   partclone.hfsplus -r -d -s hda1.img -o /dev/hda1
 Restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.hfsplus-ptcl-img.gz.a* | gunzip -c | partclone.hfsplus -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.

BUGS

Report bugs to thomas@clonezilla.org or http://partclone.org.

You can get support at http://partclone.org

SEE ALSO

partclone(8), partclone.chkimg(8), partclone.restore(8), partclone.dd(8), partclone.info(8)

NOM

partclone.hfsplus

sauvegarde, restaure et clone le système de fichiers HFS+

SYNTAXE

partclone.hfsplus [-c|-r] [-s source] [-o sortie] [-b] [-N] [-p type_barre_progression] [-L fichier_journal] [-d] [-v] [-z taille_bloc] [-Z nombre_threads] [-q] [-Q somme_controle]

DESCRIPTION

La commande partclone.hfsplus sauvegarde, restaure et clone un système de fichiers HFS+. Elle peut fonctionner avec un périphérique ou un fichier comme source/sortie.

OPTIONS

Les options sont les mêmes que celles de partclone original.

Voir partclone(8) pour plus de détails.

-c
Mode clone. Utilisé pour sauvegarder la partition dans un fichier image.
-r
Mode restauration. Utilisé pour restaurer la partition à partir d'un fichier image.
-s source
Spécifier le périphérique ou le fichier source.
-o sortie
Spécifier le fichier ou le périphérique de sortie.
-b
Exécuter en mode batch. Aucune question interactive ne sera posée.
-N
Désactiver la vérification de la taille du système de fichiers. Soyez prudent en utilisant cette option.
-p type_barre_progression
Spécifier le type de barre de progression. Les types supportés sont : pstyle1, pstyle2, pstyle3, pstyle4.
-L fichier_journal
Spécifier le fichier journal.
-d
Mode débogage. Afficher plus d'informations pendant le processus.
-v
Afficher la version du programme.
-z taille_bloc
Définir la taille du bloc. La valeur par défaut est 4096.
-Z nombre_threads
Définir le nombre de threads à utiliser pour la sauvegarde/restauration. La valeur par défaut est 1.
-q
Mode silencieux. Supprimer toute sortie sauf les erreurs.
-Q somme_controle
Définir l'algorithme de somme de contrôle. Les algorithmes supportés sont : md5, sha1, sha256, sha512.

FICHIERS

/var/log/partclone.log

Le fichier journal de partclone

EXEMPLES

 Cloner /dev/hda1 vers hda1.img et afficher les informations de débogage.
   partclone.hfsplus -c -d -s /dev/hda1 -o hda1.img
 Restaurer /dev/hda1 depuis hda1.img et afficher les informations de débogage.
   partclone.hfsplus -r -d -s hda1.img -o /dev/hda1
 Restaurer une image de clonezilla (split, gzip,) avec une source stdin
   cat sda1.hfsplus-ptcl-img.gz.a* | gunzip -c | partclone.hfsplus -d -r -s - -o /dev/sda1
