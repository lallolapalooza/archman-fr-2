NOM

parsort - Triez (gros fichiers) en parallèle

SYNTAXE

parsort options pour sort

DESCRIPTION

parsort utilise sort de GNU pour trier en parallèle. Il fonctionne comme sort mais plus rapidement sur des entrées de plus d'un million de lignes, si vous avez une machine multicœur.

Espérons que ces idées seront intégrées dans sort de GNU à l'avenir.

OPTIONS

Identiques à sort. Sauf :

--parallel=N
Change le nombre de tris exécutés simultanément à N. N sera augmenté au nombre de fichiers si parsort reçoit plus de N fichiers.

EXEMPLE

Trier des fichiers :

parsort *.txt > trie.txt

Trier l'entrée standard numériquement :

cat nombres | parsort -n > trie.txt

PERFORMANCE

parsort est plus rapide sur des fichiers que sur l'entrée standard, car différentes parties d'un fichier peuvent être lues en parallèle.

Sur une machine à 48 cœurs, vous devriez observer une amélioration de vitesse de 3x par rapport à sort.
