NOM

pam_get_item - obtenir des informations PAM

SYNTAXE

#include <security/pam_modules.h>

int pam_get_item(const pam_handle_t *pamh, int item_type, const void **item);

DESCRIPTION

La fonction pam_get_item permet aux applications et aux modules de service PAM d'accéder et de récupérer des informations PAM du type item_type. En cas de succès, item contient un pointeur vers la valeur de l'élément correspondant. Notez qu'il s'agit d'un pointeur vers les données *réelles* et qu'il ne doit **pas** être libéré par free() ni écrasé ! Les valeurs suivantes sont prises en charge pour item_type:

PAM_SERVICE

Le nom du service (qui identifie la pile PAM que les fonctions PAM utiliseront pour authentifier le programme).

PAM_USER

Le nom d'utilisateur de l'entité sous l'identité de laquelle le service sera donné. C'est-à-dire qu'après l'authentification, PAM_USER identifie l'entité locale qui a le droit d'utiliser le service. Notez que cette valeur peut être mappée de quelque chose (par exemple, "anonymous") à autre chose (par exemple, "guest119") par n'importe quel module de la pile PAM. Ainsi, une application doit consulter la valeur de PAM_USER après chaque appel à une fonction PAM.

PAM_USER_PROMPT

La chaîne utilisée lors de la demande du nom d'utilisateur. La valeur par défaut de cette chaîne est une version localisée de "login: ".

PAM_TTY

Le nom du terminal préfixé par /dev/ pour les fichiers de périphérique. Par le passé, les applications graphiques basées sur X utilisaient pour stocker la variable $DISPLAY ici, mais avec l'introduction de PAM_XDISPLAY, cette utilisation est obsolète.

PAM_RUSER

Le nom d'utilisateur demandeur : nom local pour un utilisateur demandeur local ou nom d'utilisateur distant pour un utilisateur demandeur distant.

En général, une application ou un module tentera de fournir la valeur la plus fortement authentifiée (un compte local avant un compte distant). Le niveau de confiance dans cette valeur est incarné par la pile d'authentification réelle associée à l'application, donc c'est finalement à la discrétion de l'administrateur système.

PAM_RUSER@PAM_RHOST devrait toujours identifier l'utilisateur demandeur. Dans certains cas, PAM_RUSER peut être NULL. Dans de telles situations, on ne sait pas qui est l'entité demandeur.

PAM_RHOST

Le nom d'hôte demandeur (le nom d'hôte de la machine depuis laquelle l'entité PAM_RUSER demande le service). C'est PAM_RUSER@PAM_RHOST qui identifie l'utilisateur demandeur. Dans certaines applications, PAM_RHOST peut être NULL. Dans de telles situations, on ne sait pas d'où provient la requête d'authentification.

PAM_AUTHTOK

Le jeton d'authentification (souvent un mot de passe). Ce jeton doit être ignoré par toutes les fonctions de module sauf pam_sm_authenticate(3) et pam_sm_chauthtok(3). Dans la première fonction, il est utilisé pour passer le jeton d'authentification le plus récent d'un module empilé à un autre. Dans la dernière fonction, le jeton est utilisé à un autre objectif. Il contient le jeton d'authentification actuellement actif.

PAM_OLDAUTHTOK

L'ancien jeton d'authentification. Ce jeton doit être ignoré par toutes les fonctions de module sauf pam_sm_chauthtok(3).

PAM_CONV

La structure pam_conv. Voir pam_conv(3).

Les éléments supplémentaires suivants sont spécifiques à Linux-PAM et ne doivent pas être utilisés dans des applications portables :

PAM_FAIL_DELAY

Un pointeur de fonction pour rediriger les délais d'échec gérés centralement. Voir pam_fail_delay(3).

PAM_XDISPLAY

Le nom de l'affichage X. Pour les applications graphiques basées sur X, la valeur de cet élément doit être la variable $DISPLAY. Cette valeur peut être utilisée indépendamment de PAM_TTY pour transmettre le nom de l'affichage.

PAM_XAUTHDATA

Un pointeur vers une structure contenant les données d'authentification X requises pour établir une connexion à l'affichage spécifié par PAM_XDISPLAY, si de telles informations sont nécessaires. Voir pam_xauth_data(3).

PAM_AUTHTOK_TYPE

L'action par défaut est que le module utilise les invites suivantes lors de la demande de mots de passe : "Nouveau mot de passe UNIX : " et "Retype mot de passe UNIX : ". Le mot exemple UNIX peut être remplacé par cet élément, par défaut il est vide. Cet élément est utilisé par pam_get_authtok(3).

Si un module de service souhaite obtenir le nom de l'utilisateur, il ne doit pas utiliser cette fonction, mais effectuer plutôt un appel à pam_get_user(3).

Seul un module de service est privilégié pour lire les jetons d'authentification, PAM_AUTHTOK et PAM_OLDAUTHTOK.

VALEURS DE RETOUR

PAM_BAD_ITEM

L'application a tenté de définir un élément non défini ou inaccessible.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_PERM_DENIED

La valeur de item était NULL.

PAM_SUCCESS

Les données ont été mises à jour avec succès.

PAM_SYSTEM_ERR

Le pam_handle_t passé comme premier argument était invalide.

VOIR AUSSI

pam_set_item(3), pam_strerror(3)
