NOM

passwd - le fichier de mots de passe

DESCRIPTION

/etc/passwd contient une ligne pour chaque compte utilisateur, avec sept champs séparés par des deux-points (“:”). Ces champs sont :

•nom de connexion
•mot de passe chiffré optionnel
•identifiant utilisateur numérique
•identifiant de groupe numérique
•nom d'utilisateur ou champ de commentaire
•répertoire personnel de l'utilisateur
•interpréteur de commandes optionnel de l'utilisateur

Si le champ mot de passe est un “x” en minuscule, alors le mot de passe chiffré est en fait stocké dans le fichier shadow(5) ; il doit y avoir une ligne correspondante dans le fichier /etc/shadow, sinon le compte utilisateur est invalide.

Le champ mot de passe chiffré peut être vide, dans ce cas aucun mot de passe n'est requis pour s'authentifier en tant que nom de connexion spécifié. Cependant, certaines applications qui lisent le fichier /etc/passwd peuvent décider de ne permettre aucun accès du tout si le champ mot de passe est vide.

Un champ mot de passe commençant par un point d'exclamation signifie que le mot de passe est verrouillé. Les caractères restants sur la ligne représentent le champ mot de passe avant que le mot de passe ne soit verrouillé.

Consulter crypt(3) pour les détails sur la manière dont cette chaîne est interprétée.

Si le champ mot de passe contient une chaîne qui n'est pas un résultat valide de crypt(3), par exemple ! ou *, l'utilisateur ne pourra pas utiliser un mot de passe unix pour se connecter (mais l'utilisateur pourra se connecter au système par d'autres moyens).

Le champ commentaire, également connu sous le nom de champ gecos, est utilisé par divers utilitaires système, tels que finger(1). L'utilisation d'un esperluette ici sera remplacée par le nom de connexion capitalisé lorsque le champ est utilisé ou affiché par de tels utilitaires système.

Le champ répertoire personnel fournit le nom du répertoire de travail initial. Le programme login utilise ces informations pour définir la valeur de la variable d'environnement $HOME.

Le champ interpréteur de commandes fournit le nom de l'interpréteur de langage de commande de l'utilisateur, ou le nom du programme initial à exécuter. Le programme login utilise ces informations pour définir la valeur de la variable d'environnement $SHELL. Si ce champ est vide, il prend par défaut la valeur /bin/sh.

FICHIERS

/etc/passwd

Informations du compte utilisateur.

/etc/shadow

fichier de mots de passe chiffrés optionnel

/etc/passwd-

Fichier de sauvegarde pour /etc/passwd.

Notez que ce fichier est utilisé par les outils de la suite d'outils shadow, mais pas par tous les outils de gestion d'utilisateurs et de mots de passe.
