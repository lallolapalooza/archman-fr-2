NOM

pam_pwhistory - module PAM pour mémoriser les derniers mots de passe

SYNTAXE

pam_pwhistory.so [debug] [use_authtok] [enforce_for_root] [remember=N] [retry=N] [authtok_type=STRING] [file=/chemin/nom_fichier] [conf=/chemin/vers/fichier_config]

DESCRIPTION

Ce module enregistre les derniers mots de passe pour chaque utilisateur afin de forcer l'historique des changements de mot de passe et d'empêcher l'utilisateur de basculer trop fréquemment entre le même mot de passe.

Ce module ne fonctionne pas avec kerberos. En général, il n'a pas beaucoup de sens d'utiliser ce module en conjonction avec NIS ou LDAP, car les anciens mots de passe sont stockés sur la machine locale et ne sont pas disponibles sur une autre machine pour la vérification de l'historique des mots de passe.

OPTIONS

debug

Active le débogage via syslog(3).

use_authtok

Lors du changement de mot de passe, force le module à utiliser le nouveau mot de passe fourni par un module password précédemment empilé (ceci est utilisé dans l'exemple d'empilement du module pam_passwdqc documenté ci-dessous).

enforce_for_root

Si cette option est définie, la vérification est également appliquée à root.

remember=N

Les derniers N mots de passe de chaque utilisateur sont enregistrés. La valeur par défaut est 10. Une valeur de 0 fait que le module conserve le contenu existant du fichier opasswd inchangé.

retry=N

Demande à l'utilisateur au plus N fois avant de retourner une erreur. La valeur par défaut est 1.

authtok_type=STRING

Voir pam_get_authtok(3) pour plus de détails.

file=/chemin/nom_fichier

Stocke l'historique des mots de passe dans le fichier /chemin/nom_fichier plutôt que dans l'emplacement par défaut. L'emplacement par défaut est /etc/security/opasswd.

conf=/chemin/vers/fichier_config

Utilise un autre fichier de configuration au lieu du fichier par défaut /etc/security/pwhistory.conf.

Les options de configuration du comportement du module sont décrites dans la page de manuel pwhistory.conf(5). Les options spécifiées sur la ligne de commande du module remplacent les valeurs du fichier de configuration.

TYPES DE MODULES FOURNIS

Seul le type de module password est fourni.

VALEURS DE RETOUR

PAM_AUTHTOK_ERR

Aucun nouveau mot de passe n'a été saisi, l'utilisateur a abandonné le changement de mot de passe ou le nouveau mot de passe n'a pas pu être défini.

PAM_IGNORE

L'historique des mots de passe a été désactivé.

PAM_MAXTRIES

Le mot de passe a été rejeté trop souvent.

PAM_USER_UNKNOWN

L'utilisateur n'est pas connu du système.

EXEMPLES

Une section de mot de passe d'exemple serait :

#%PAM-1.0
password     required       pam_pwhistory.so
password     required       pam_unix.so        use_authtok

En combinaison avec pam_passwdqc :

#%PAM-1.0
password     required       pam_passwdqc.so    config=/etc/passwdqc.conf
password     required       pam_pwhistory.so   use_authtok
password     required       pam_unix.so        use_authtok

FICHIERS

/etc/security/opasswd

Fichier par défaut avec l'historique des mots de passe

/etc/security/pwhistory.conf

Fichier de configuration pour les options de pam_pwhistory

VOIR AUSSI

pwhistory.conf(5), pam.conf(5), pam.d(5), pam(8) pam_get_authtok(3)
