papers(1) Manuel des commandes générales papers(1)

NOM

papers - Visionneuse de documents GNOME

L'application Visionneuse de documents Papers pour l'environnement de bureau GNOME

SYNTAXE

papers [--help] [--page-label=PAGE | --page-index=NUMBER | --named-dest=DEST] [--fullscreen] [--presentation] [nom_fichier(s)...]

DESCRIPTION

Papers est une visionneuse de documents capable d'afficher des formats de documents multiples et à page unique comme le PDF et le DjVu. Pour plus d'informations générales sur Papers, veuillez visiter notre site Web à l'adresse https://apps.gnome.org/Papers/

OPTIONS

-?, -h, --help
Affiche les options de la ligne de commande.
-p, --page-label=PAGE
Ouvre le document à la page avec l'étiquette de page spécifiée (ou le numéro de page).
-i, --page-index=NUMBER
Ouvre le document à la page avec l'index de page spécifié (c'est le numéro de page exact, pas une étiquette de page).
-n, --named-dest=DEST
Ouvre le document à la destination nommée spécifiée.
-f, --fullscreen
Exécute papers en mode plein écran.
-s, --presentation
Exécute papers en mode présentation.
nom_fichier(s)...
Spécifie le fichier à ouvrir au démarrage de Papers. Si cela n'est pas spécifié, Papers ouvrira une fenêtre vide. Plusieurs fichiers peuvent être chargés s'ils sont séparés par des espaces. Papers prend également en charge la gestion des fichiers distants. Par exemple, vous pouvez passer l'emplacement sur le Web ou charger un fichier depuis un serveur FTP, comme "ftp://adobe.com/sample.pdf".

BOGUES

Si vous trouvez un bogue, veuillez le signaler à https://gitlab.gnome.org/GNOME/papers/issues.
