NOM

pam_set_items - Un module PAM de test pour définir des éléments PAM spécifiques au module

SYNTAXE

pam_set_items.so

DESCRIPTION

Les modules PAM stockent des données dans des éléments PAM. Ces éléments ne sont accessibles que depuis le contexte du module, pas depuis le contexte de l'application, car ils peuvent inclure des données privées (PAM_AUTHTOK contient normalement le mot de passe). Mais lors du test de modules PAM, il est souvent utile de s'assurer qu'un module PAM testé peut récupérer des données de la pile. Le module pam_set_items rend cela possible en lisant des variables d'environnement et en les définissant comme des éléments PAM.

OPTIONS

Aucune

TYPES DE MODULES FOURNIS

Tous les types de modules (account, auth, password et session) sont fournis.

EXEMPLE

Considérez un exemple qui teste que pam_unix est capable de lire un mot de passe fourni et ne demande pas lui-même. Le fichier de service de test contiendrait :

auth required        pam_set_items.so
auth required        pam_unix.so

Ensuite, le test placerait l'élément dans l'environnement de test avec :

setenv("PAM_AUTHTOK", "secret");

Puis exécuterait la conversation PAM.
