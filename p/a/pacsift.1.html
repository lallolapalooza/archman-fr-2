PACSIFT(1) pacsift PACSIFT(1)

NOM

pacsift - interroger et filtrer des paquets

SYNTAXE

pacsift [options] (<champ> <terme>)...
pacsift (--help|--version)

DESCRIPTION

Par défaut, l'intersection des paquets correspondants est retournée. Si un champ est fourni plusieurs fois, l'union des correspondances sera utilisée pour ce champ.

Si stdin n'est pas connecté à un terminal, les paquets à filtrer seront lus depuis stdin.

À combiner avec pacinfo pour afficher des informations brèves sur les paquets, similaires à "pacman -Qs" et "pacman -Ss" :

pacsift --name pacman | pacinfo --short

OPTIONS

--config=chemin
Spécifie un chemin alternatif pour le fichier de configuration.
--dbext=extension
Spécifie une extension alternative pour la base de données de synchronisation.
--dbpath=chemin
Spécifie un chemin alternatif pour la base de données.
--root=chemin
Spécifie une racine d'installation alternative.
--sysroot=chemin
Spécifie une racine système alternative. Voir pacutils-sysroot(7).
--null[=sep]
Spécifie un séparateur alternatif pour les valeurs lues depuis stdin. Par défaut, un saut de ligne "\n" est utilisé comme séparateur. Si --null est utilisé sans spécifier sep, "NUL" sera utilisé.
--exists
Se termine avec une valeur non nulle si aucune correspondance n'est trouvée.
--not-exists
Se termine avec une valeur non nulle si des correspondances sont trouvées.
--invert
Retourne les paquets qui NE correspondent PAS aux termes de recherche fournis.
--any
Retourne l'union des paquets correspondants plutôt que l'intersection.
--exact
Correspond aux valeurs exactement.
--regex
Traite les valeurs de chaîne comme des expressions régulières étendues insensibles à la casse.
--help
Affiche les informations d'utilisation et se termine.
--version
Affiche les informations de version et se termine.

Filtres

Les filtres limitent l'ensemble initial de paquets à rechercher. Ils ne peuvent pas être utilisés si des paquets sont fournis sur stdin et ils ne sont pas affectés par --invert ou --any.

--local
Recherche les paquets installés localement. Similaire à :
pacsift --repo=local | pacsift ...
--sync
Recherche les paquets dans les bases de données de synchronisation. Similaire à :
pacsift --invert --repo=local | pacsift ...
--cache (EXPÉRIMENTAL)
Recherche les paquets dans les répertoires de cache.

Champs de chaîne de caractères

Par défaut, les champs de chaîne de caractères utiliseront une recherche de sous-chaîne insensible à la casse. Si --exact est utilisé, les champs de chaîne de caractères doivent correspondre exactement à val. Si "--regex" est utilisé, val sera traité comme une expression régulière étendue insensible à la casse.

--repo=val
--name=val
--base=val
--description=val
--packager=val
--group=val
--owns-file=chemin
Les chemins de fichiers doivent correspondre à la base de données des paquets; aucune tentative n'est faite pour résoudre le chemin fourni. Note : lorsqu'il est utilisé avec --exact, la racine d'installation sera supprimée de chemin si présente, sinon chemin sera utilisé exactement tel que fourni. Peut être utilisé avec realpath ou which pour rechercher plus facilement le propriétaire des fichiers installés : 
pacsift --local --exact --owns-file="$(which pacsift)"
--license=val
--url=val

Champs de dépendance

Les dépendances peuvent être spécifiées au format "<nom_paquet>[<cmp><version>". "cmp" peut être l'un des suivants : "=", "<", "<=", ">", ">=". Si "version" est fourni, la dépendance du paquet doit correspondre exactement au terme de recherche. Si "version" est omis, seule la "nom_paquet" sera comparée sauf si --exact est utilisé. Si "--exact" est utilisé et que "version" n'est pas fourni, seules les dépendances sans version spécifiée seront mises en correspondance.

Les champs de dépendance ne sont pas affectés par --regex.

--provides
--conflicts
--replaces
--depends
--optdepends

Champs de taille

Les champs de taille peuvent être préfixés par l'une des comparaisons suivantes : "=", "!=", "<", "<=", ">", ">=". Si aucune comparaison n'est fournie, "=" sera utilisée. La taille peut être suivie d'une unité abrégée. Les unités sont sensibles à la casse.

--size
--installed-size
--download-size

Champs de date

Les champs de date peuvent être préfixés par l'une des comparaisons suivantes : "=", "!=", "<", "<=", ">", ">=". Si aucune comparaison n'est fournie, "=" sera utilisée. Les dates peuvent être fournies en secondes depuis l'époque ou dans l'un des formats "strptime" suivants : "%Y-%m-%d", "%Y-%m-%d %H:%M", "%Y-%m-%d %H:%M:%S".

--install-date
--build-date

Autres

Champs booléens qui sont seulement comparés à vrai ou faux.

--backup
--optional
--required

EXEMPLES

Trouver tous les paquets qui fournissent "bash" dans le dépôt "core" : 

pacsift --repo core --provides bash

Trouver tous les paquets installés localement dont le nom contient "vim" : 

pacsift --local --name vim

Trouver tous les paquets dont la description correspond à "network manager" et qui sont installés : 

pacsift --local --description "network manager"

Trouver tous les paquets qui ne sont PAS installés localement et qui sont dans le dépôt "extra" : 

pacsift --sync --repo extra

Trouver les paquets qui fournissent "python" ou qui ont une description contenant "python" : 

pacsift --provides python --description python --any

Trouver les paquets dont le nom commence par "lib" et se termine par "png" : 

pacsift --name ^lib.*png$ --regex

Trouver les paquets qui remplacent le paquet "oldpackage" et qui sont installés : 

pacsift --local --replaces oldpackage

Trouver tous les paquets installés dont la taille d'installation est supérieure à 100 Mo : 

pacsift --local --installed-size >100M

Trouver tous les paquets construits après le 1er janvier 2023 : 

pacsift --build-date >2023-01-01

Trouver tous les paquets qui dépendent exactement de "perl" (sans spécification de version) : 

pacsift --depends --exact perl

Trouver tous les paquets qui dépendent de "sudo" avec une version supérieure ou égale à 1.9 : 

pacsift --depends sudo>=1.9

Trouver les paquets qui possèdent le fichier "/usr/bin/ls" : 

pacsift --owns-file /usr/bin/ls

pacsift(1) — pacutils

NAME

pacsift — sifts through installed packages

SYNOPSIS

pacsift [OPTIONS]...

DESCRIPTION

pacsift is a tool that can filter installed packages based on a variety of criteria. It can read package information from standard input, or query the pacman database directly.

OPTIONS

--all
Do not filter out packages that are not installed locally. By default, only installed packages are considered.
--description=pattern
Search for packages that have pattern in their description.
--exists
Search for packages that exist in the database (installed or not).
--group=group
Search for packages that belong to group.
--local
Search for locally installed packages only.
--name=pattern
Search for packages that have pattern in their name.
--optional=dependency
Search for packages that require dependency as an optional dependency.
--packager=packager
Search for packages that were packaged by packager.
--provides=capability
Search for packages that provide capability.
--required=dependency
Search for packages that require dependency as a required dependency.
--size=size
Search for locally installed packages that are larger than size. size may be suffixed with k, M, or G for kilobytes, megabytes, or gigabytes, respectively. Without a suffix, size is in bytes.
--satisfies=dependency
Search for packages that satisfy dependency.

EXAMPLES

Find broken packages:
pacsift --packager allan
Find large installed packages:
pacsift --local --size '>1.5GB'
Find packages with either "pacman" or "alpm" in their description:
pacsift --description pacman --description alpm
Find packages with both "pacman" and "alpm" in their description:
pacsift --description pacman | pacsift --description alpm
Check if a package is installed:
pacsift --local --exists --satisfies pacman && echo "pacman is installed"

CAVEATS

pacsift determines whether or not to read packages from stdin based on a naive check using isatty(3). If pacsift is called in an environment, such as a shell function or script being used in a pipe, where stdin is not connected to a terminal but does not contain packages to filter, pacsift should be called with stdin closed. For POSIX-compatible shells, this can be done with "<&-".
