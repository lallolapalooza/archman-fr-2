PAN(1) Manuel des commandes générales PAN(1)

NOM

Pan - lire et poster des articles Usenet

SYNTAXE

pan [OPTIONS...] [headers:NOM-GROUPE | news:ID-MESSAGE]

DESCRIPTION

Pan est un lecteur de nouvelles Usenet qui est performant aussi bien pour le texte que pour les binaires. Il prend en charge la lecture hors ligne, le scoring et les killfiles, yEnc, NZB, la gestion PGP, les serveurs multiples et les connexions sécurisées.

UTILISATION

pan est un programme qui peut être exécuté sans interface graphique en mode non-GUI, permettant le traitement par lots de fichiers NZB, le téléchargement d'en-têtes, et plus encore.

OPTIONS

Options Générales

-h, --help
Affiche les informations d'utilisation et quitte.
-v, --version
Affiche la version de la publication et quitte.
--verbose
Être verbeux (en mode non-GUI).
--debug
Exécuter en mode débogage. Utiliser --debug deux fois pour un débogage verbeux.
--debug-ssl
Exécuter en mode débogage TLS (aka SSL).

Options URL

headers:NOM-GROUPE
Télécharge les nouveaux en-têtes pour le groupe de nouvelles NOM-GROUPE.
news:ID-MESSAGE
Lorsqu'il est spécifié avec --no-gui, envoie l'article ID-MESSAGE en sortie standard.

Options Batch NZB

--nzb FICHIER-1 FICHIER-2 ...
Traite les fichiers NZB en mode non-GUI.
-o, --output=CHEMIN
Chemin pour enregistrer les pièces jointes listées dans le(s) fichier(s) NZB.
--no-gui
N'affiche que la sortie console, pas la file d'attente de téléchargement.

ENVIRONNEMENT

PAN_HOME
Répertoire des données utilisateur à utiliser. Par défaut, $HOME/.pan2.
SSL_CERT_DIR, SSL_DIR
Répertoires dans lesquels rechercher les certificats SSL.
