NOM

pam_prompt, pam_vprompt - interface de la fonction de conversation

SYNTAXE

#include <security/pam_ext.h>

int pam_prompt(pam_handle_t *pamh, int style, char **response, const char *fmt, ...);

int pam_vprompt(pam_handle_t *pamh, int style, char **response, const char *fmt, va_list args);

DESCRIPTION

La fonction pam_prompt construit un message à partir de la chaîne de format spécifiée et des arguments, et le transmet à la fonction de conversation définie par le service. En cas de succès, response est défini pour pointer vers une chaîne renvoyée par la fonction de conversation. Cette chaîne est allouée sur le tas et doit être libérée.

VALEURS DE RETOUR

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_CONV_ERR

Échec de la conversation.

PAM_SUCCESS

Conversation réussie, la réponse est définie.

PAM_SYSTEM_ERR

Erreur système.

VOIR AUSSI

pam(8), pam_conv(3)

NORMES

Les fonctions pam_prompt et pam_vprompt sont des extensions de Linux-PAM.
