NOM

pam_sm_acct_mgmt - fonction de service PAM pour la gestion de compte

SYNTAXE

#include <security/pam_modules.h>

int pam_sm_acct_mgmt(pam_handle_t *pamh, int flags, int argc, const char **argv);

DESCRIPTION

La fonction pam_sm_acct_mgmt est l'implémentation du module de service de l'interface pam_acct_mgmt(3).

Cette fonction a pour tâche de déterminer si l'utilisateur est autorisé à accéder à ce moment. Il faut comprendre que l'utilisateur a déjà été validé par un module d'authentification. Cette fonction vérifie d'autres éléments. Ces éléments peuvent être : l'heure du jour ou la date, la ligne du terminal, le nom d'hôte distant, etc. Cette fonction peut également déterminer des éléments tels que l'expiration des mots de passe et répondre que l'utilisateur doit le changer avant de continuer.

Les drapeaux valides, qui peuvent être combinés logiquement avec PAM_SILENT, sont :

PAM_SILENT

Ne pas émettre de messages.

PAM_DISALLOW_NULL_AUTHTOK

Retourne PAM_AUTH_ERR si la base de données des jetons d'authentification pour ce mécanisme d'authentification a une entrée NULL pour l'utilisateur.

VALEURS DE RETOUR

PAM_ACCT_EXPIRED

Le compte utilisateur a expiré.

PAM_AUTH_ERR

Échec de l'authentification.

PAM_NEW_AUTHTOK_REQD

Le jeton d'authentification de l'utilisateur a expiré. Avant d'appeler à nouveau cette fonction, l'application s'arrangera pour qu'un nouveau jeton soit fourni. Cela entraînera probablement un appel à pam_sm_chauthtok().

PAM_PERM_DENIED

Permission refusée.

PAM_SUCCESS

Le jeton d'authentification a été mis à jour avec succès.

PAM_USER_UNKNOWN

Utilisateur inconnu du service de mots de passe.
