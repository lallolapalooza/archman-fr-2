NOM

pam_fprintd - Module PAM pour s'authentifier auprès de fprintd, le démon d'empreintes digitales

SYNTAXE

pam_fprintd.so [debug|debug=[on|off|true|false|1|0]] [max-tries=MAX_TRIES] [timeout=TIMEOUT]

DESCRIPTION

Le module pam_fprintd est utilisé pour vérifier les empreintes digitales d'un utilisateur par rapport aux empreintes enregistrées à l'aide de fprintd, le démon de gestion des empreintes digitales.

OPTIONS

debug
debug=[on|off|true|false|1|0]
Active ou désactive le mode debug. Les messages de débogage seront générés en utilisant pam_syslog, ce qui signifie qu'ils seront enregistrés dans le journal systemd par défaut.
max-tries=MAX_TRIES
Le nombre de tentatives d'authentification par empreinte digitale à essayer avant de retourner un échec d'authentification. Le nombre minimum d'essais est 1, tandis que la valeur par défaut est 3.

Utilisez une valeur négative pour ne fixer aucune limite, de sorte que le module n'échoue jamais en cas de plusieurs tentatives, mais dans ce cas, il est suggéré que le chargeur du module gère cela.

timeout=TIMEOUT
La durée avant de retourner un échec d'authentification. Le délai d'attente par défaut est de 30 secondes, avec 1 seconde comme minimum.

Utilisez une valeur négative pour ne fixer aucune limite, de sorte que l'authentification par empreinte digitale soit toujours active tant que ce module est chargé.

LIMITATIONS

La pile PAM est, par conception, une authentification sérialisée, il n'est donc pas possible pour pam_fprintd d'autoriser l'authentification par mots de passe et empreintes digitales en même temps.

Il appartient à l'application utilisant les services PAM de mettre en œuvre des processus PAM distincts et d'exécuter des piles d'authentification séparées. C'est ainsi que plusieurs méthodes d'authentification sont mises à la disposition des utilisateurs de gdm, par exemple.
