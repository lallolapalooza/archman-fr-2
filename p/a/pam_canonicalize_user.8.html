NOM

pam_canonicalize_user - Obtenir le nom d'utilisateur et le canoniser

SYNTAXE

pam_canonicalize_user.so

DESCRIPTION

Ce module PAM utilise le nom d'utilisateur obtenu via pam_get_user(3) comme clé pour interroger la base de données des mots de passe, et remplace PAM_USER par la valeur pw_name retournée.

OPTIONS

Ce module ne reconnaît aucune option.

TYPES DE MODULES FOURNIS

Seul le type de module auth est fourni.

VALEURS DE RETOUR

PAM_IGNORE

Le nom d'utilisateur a été défini avec succès.

PAM_USER_UNKNOWN

L'utilisateur n'a pas été trouvé.

PAM_SYSTEM_ERR

L'application n'a fourni ni nom d'utilisateur ni méthode de conversation.

PAM_INCOMPLETE

La méthode de conversation fournie par l'application attend un événement.

PAM_CONV_ERR

La méthode de conversation fournie par l'application n'a pas réussi à obtenir le nom d'utilisateur.

PAM_ABORT

Erreur lors de la reprise d'une ancienne conversation.

PAM_BUF_ERR

Erreur de tampon mémoire.

EXEMPLES

Ajoutez la ligne suivante au début de la pile d'authentification PAM pour canoniser le nom d'utilisateur avant l'authentification :

        auth required pam_canonicalize_user.so

VOIR AUSSI

pam_get_user(3), pam_get_item(3), pam_set_item(3), getpwnam(3), pam.conf(5), pam.d(5), pam(8)
