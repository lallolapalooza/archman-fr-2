PANGO-LIST(1) Commandes Pango PANGO-LIST(1)

NOM

pango-list - Énumération des polices Pango

SYNTAXE

pango-list [OPTIONS...]

DESCRIPTION

pango-list énumère les polices en utilisant les API de la carte de polices de Pango.

OPTIONS D'AIDE

-h, --help

Affiche les options d'aide.

--version

Imprime la version de la commande et quitte.

OPTIONS APPLICATIVES

--verbose

Imprime des informations détaillées.

--metrics

Imprime les métriques de police.

--variations

Imprime les variations de police.
