NOM

pam_issue - Module PAM pour ajouter un fichier d'avertissement à l'invite utilisateur

SYNTAXE

pam_issue.so [noesc] [issue=nom-fichier-avertissement]

DESCRIPTION

pam_issue est un module PAM destiné à préfixer un fichier d'avertissement à l'invite de saisie du nom d'utilisateur. Il analyse également par défaut les codes d'échappement dans le fichier d'avertissement, de manière similaire à certains getty courants (en utilisant le format \x).

Échappements reconnus :

\d

jour courant

\l

nom du tty actuel

\m

architecture de la machine (uname -m)

\n

nom d'hôte du réseau de la machine (uname -n)

\o

nom de domaine du système

\r

numéro de version du système d'exploitation (uname -r)

\t

heure courante

\s

nom du système d'exploitation (uname -s)

\u

nombre d'utilisateurs actuellement connectés

\U

identique à \u sauf qu'il est suffixé par "user" ou "users" (par ex. "1 user" ou "10 users")

\v

version du système d'exploitation et date de compilation (uname -v)

OPTIONS

noesc

Désactive l'analyse des codes d'échappement.

issue=nom-fichier-avertissement

Le fichier à utiliser si le fichier par défaut n'est pas souhaité.

TYPES DE MODULES PROPOSÉS

Seul le type de module auth est proposé.

VALEURS DE RETOUR

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_IGNORE

L'invite a déjà été modifiée.

PAM_SERVICE_ERR

Une erreur de module de service s'est produite.

PAM_SUCCESS

La nouvelle invite a été définie avec succès.

EXEMPLES

Ajoutez la ligne suivante à /etc/pam.d/login pour définir l'avertissement spécifique à l'utilisateur lors de la connexion :

        auth optional pam_issue.so issue=/etc/issue

VOIR AUSSI

pam.conf(5), pam.d(5), pam(8)
