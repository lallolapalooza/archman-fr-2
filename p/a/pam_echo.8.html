NOM

pam_echo - Module PAM pour afficher des messages textuels

SYNOPIS

pam_echo.so [file=/chemin/vers/message]

DESCRIPTION

Le module PAM pam_echo sert à afficher des messages textuels pour informer l'utilisateur de choses particulières. Les séquences commençant par le caractère % sont interprétées de la manière suivante :

%H

Le nom de l'hôte distant (PAM_RHOST).

%h

Le nom de l'hôte local.

%s

Le nom du service (PAM_SERVICE).

%t

Le nom du terminal de contrôle (PAM_TTY).

%U

Le nom d'utilisateur distant (PAM_RUSER).

%u

Le nom d'utilisateur local (PAM_USER).

Toutes les autres séquences commençant par % sont développées pour inclure les caractères qui suivent le caractère %.

OPTIONS

file=/chemin/vers/message

Le contenu du fichier /chemin/vers/message sera affiché avec la fonction de conversion PAM PAM_TEXT_INFO.

TYPES DE MODULES FOURNIS

Tous les types de modules (auth, account, password et session) sont fournis.

VALEURS DE RETOUR

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_SUCCESS

Le message a été affiché avec succès.

PAM_IGNORE

Le drapeau PAM_SILENT a été donné ou le fichier de message n'existe pas, aucun message affiché.

EXEMPLES

Pour un exemple d'utilisation de ce module, nous montrons comment il peut être utilisé pour afficher des informations sur les bons mots de passe :

password optional pam_echo.so file=/usr/share/doc/bon-mot-de-passe.txt
password required pam_unix.so
