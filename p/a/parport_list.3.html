PARPORT_LIST(3) Structures PARPORT_LIST(3)

NOM

parport_list - une collection de ports parallèles

SYNTAXE

#include <ieee1284.h>

DESCRIPTION

Une structure parport_list est juste un vecteur de structures parport.

MEMBRES STRUCTURE

La structure a les membres suivants :

struct parport_list {
  /* Nombre d'éléments dans le vecteur. */
  int portc;
  /* Les ports. */
  struct parport **portv;
};
