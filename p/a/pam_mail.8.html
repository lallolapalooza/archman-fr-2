NOM

pam_mail - Informer sur le courrier disponible

SYNTAXE

pam_mail.so [close] [debug] [dir=maildir] [empty] [hash=count] [noenv] [nopen] [quiet] [standard]

DESCRIPTION

Le module PAM pam_mail fournit le service "vous avez du nouveau courrier" à l'utilisateur. Il peut être intégré à toute application possédant des crochets de privilèges ou de session. Il affiche un seul message indiquant si du courrier est trouvé dans le dossier de courrier de l'utilisateur et s'il est nouveau. Ce module définit également la variable d'environnement PAM, MAIL, au répertoire de courrier de l'utilisateur.

Si le fichier de la file d'attente de courrier (que ce soit /var/mail/$USER ou un chemin d'accès donné avec le paramètre dir=) est un répertoire, alors pam_mail suppose qu'il est au format Maildir.

OPTIONS

close

Indiquer si l'utilisateur a du courrier également à la déconnexion.

debug

Afficher des informations de débogage.

dir=maildir

Rechercher le courrier de l'utilisateur dans un emplacement alternatif défini par maildir/<login>. L'emplacement par défaut pour le courrier est /var/mail/<login>. Notez que si maildir est préfixé par un '~', le répertoire est interprété comme un fichier dans le répertoire personnel de l'utilisateur.

empty

Afficher également un message si l'utilisateur n'a pas de courrier.

hash=count

Profondeur de hachage du répertoire de courrier. Par exemple, un hashcount de 2 ferait du fichier de courrier /var/spool/mail/u/s/user.

noenv

Ne pas définir la variable d'environnement MAIL.

nopen

Ne pas afficher d'informations sur le courrier à la connexion. Cet indicateur est utile pour que la variable d'environnement MAIL soit définie, mais sans afficher d'informations à ce sujet.

quiet

Signaler uniquement lorsqu'il y a du nouveau courrier.

standard

Format ancien "Vous avez..." qui n'indique pas le fichier de courrier utilisé. Ceci implique également "empty".

TYPES DE MODULES FOURNIS

Les types de modules session et auth (lors de l'établissement et de la suppression des identifiants) sont fournis.

VALEURS DE RETOUR

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_SERVICE_ERR

Arguments mal formés.

PAM_SUCCESS

Succès.

PAM_USER_UNKNOWN

Utilisateur inconnu.

EXEMPLES

Ajoutez la ligne suivante à /etc/pam.d/login pour indiquer que l'utilisateur a du nouveau courrier lors de sa connexion au système.

session  optional  pam_mail.so standard
