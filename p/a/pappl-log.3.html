NOM

pappl-log - Fonctions de journalisation pappl

BIBLIOTHQUE

Printer Application Framework (libpappl, "pkg-config --cflags --libs pappl")

SYNOPSIS

#include <pappl/pappl.h>

void
papplLog(pappl_system_t *system, pappl_loglevel_t level, const char *message, ...);

void
papplLogClient(pappl_client_t *client, pappl_loglevel_t level, const char *message, ...);

void
papplLogJob(pappl_job_t *job, pappl_loglevel_t level, const char *message, ...);

void
papplLogPrinter(pappl_printer_t *printer, pappl_loglevel_t level, const char *message, ...);

DESCRIPTION

Les fonctions de journalisation PAPPL enregistrent les messages dans le fichier journal configuré.

papplLog enregistre les messages s'appliquant au système dans son ensemble.

papplLogClient, papplLogJob, et papplLogPrinter enregistrent les messages spécifiques à une connexion client, un travail d'impression ou une imprimante respectivement.

L'argument level spécifie un niveau de journalisation, du débogage (PAPPL_LOGLEVEL_DEBUG) au fatal (PAPPL_LOGLEVEL_FATAL) et est utilisé pour déterminer si le message est enregistré dans le journal.

L'argument message spécifie le message en utilisant une chaîne de format printf(3).

FONCTIONS

papplLog

Enregistre un message pour le système.

void papplLog (
    pappl_system_t *system,
    pappl_loglevel_t level,
    const char *message,
    ...
);

Cette fonction envoie un message au fichier journal du système. L'argument "level" spécifie l'urgence du message :

  • PAPPL_LOGLEVEL_DEBUG : Un message de débogage.
  • PAPPL_LOGLEVEL_ERROR : Un message d'erreur.
  • PAPPL_LOGLEVEL_FATAL : Un message d'erreur fatale.
  • PAPPL_LOGLEVEL_INFO : Un message informatif.
  • PAPPL_LOGLEVEL_WARN : Un message d'avertissement.

L'argument "message" spécifie une chaîne de format de style printf. Les valeurs enregistrées à l'aide des spécificateurs de format "%c" et "%s" sont assainies pour ne pas contenir de caractères de contrôle.
