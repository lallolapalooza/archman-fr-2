NOM

pacman-key - gérer la liste des clés de confiance de pacman

SYNTAXE

pacman-key [options] opération [cibles]

DESCRIPTION

pacman-key est un script enveloppe pour GnuPG utilisé pour gérer le trousseau de clés de pacman, qui est la collection de clés PGP utilisées pour vérifier les paquets et les bases de données signés. Il offre la possibilité d'importer et d'exporter des clés, de récupérer des clés de serveurs de clés et de mettre à jour la base de données de confiance des clés.

Une gestion plus complexe du trousseau de clés peut être réalisée en utilisant directement GnuPG avec l'option --homedir pointant vers le trousseau de clés de pacman (situé dans /etc/pacman.d/gnupg par défaut).

L'invocation de pacman-key consiste à fournir une opération avec toutes les options et cibles potentielles pour opérer. Selon l'opération, une cible peut être un identifiant de clé, un nom de fichier ou un répertoire valide.

OPÉRATIONS

-a, --add

Ajoute la ou les clés contenues dans le ou les fichiers spécifiés au trousseau de clés de pacman. Si une clé existe déjà, la met à jour.

-d, --delete

Supprime la ou les clés identifiées par les identifiants de clé spécifiés du trousseau de clés de pacman.

-e, --export

Exporte la ou les clés identifiées par les identifiants de clé spécifiés vers stdout. Si aucun identifiant de clé n'est spécifié, toutes les clés seront exportées.

--edit-key

Présente un menu pour les tâches de gestion de clé sur l'identifiant de clé spécifié. Utile pour ajuster le niveau de confiance d'une clé.

-f, --finger

Liste une empreinte pour chaque identifiant de clé spécifié, ou pour toutes les clés connues si aucun identifiant de clé n'est spécifié.

-h, --help

Affiche la syntaxe et les options de ligne de commande.

--import

Importe les clés de pubring.gpg dans le trousseau de clés public à partir des répertoires spécifiés.

--import-trustdb

Importe les valeurs de confiance propriétaire de trustdb.gpg dans la base de données de confiance partagée à partir des répertoires spécifiés.

--init

Assure que le trousseau de clés est correctement initialisé et a les permissions d'accès requises.

-l, --list-keys

Liste toutes les clés ou les clés spécifiées du trousseau de clés public.

--list-sigs

Identique à --list-keys, mais les signatures sont également listées.

--lsign-key

Signe localement la clé donnée. Ceci est principalement utilisé pour ancrer la toile de confiance dans la clé privée locale générée par --init.

--nocolor

Désactive la sortie colorée de pacman-key.

-r, --recv-keys

Équivalent à --recv-keys dans GnuPG.

--refresh-keys

Équivalent à --refresh-keys dans GnuPG.

--populate

Recharge les clés par défaut à partir des trousseaux de clés (facultativement fournis) dans /usr/share/pacman/keyrings. Pour plus d'informations, voir Fournir un trousseau de clés pour l'importation ci-dessous.

-u, --updatedb

Équivalent à --check-trustdb dans GnuPG. Cette opération peut être spécifiée avec d'autres opérations.

-V, --version

Affiche la version du programme.

-v, --verify

Suppose que le premier argument est une signature et la vérifie. Si un deuxième argument est fourni, c'est le fichier à vérifier.

Avec un seul argument, suppose que la signature est une signature détachée, et cherche un fichier de données correspondant en supprimant l'extension du fichier. Si aucun fichier de données correspondant n'est trouvé, reviendra à la sémantique GnuPG et tentera de vérifier un fichier avec une signature intégrée.

OPTIONS

--config <fichier>

Utilise un fichier de configuration alternatif au lieu du défaut /etc/pacman.conf.

--gpgdir <répertoire>

Définit un répertoire personnel alternatif pour GnuPG. S'il n'est pas spécifié, la valeur est lue à partir de /etc/pacman.conf.

--keyserver <serveur-de-clés>

Utilise le serveur de clés spécifié si l'opération en requiert un. Ceci aura la priorité sur toute option de serveur de clés spécifiée dans un fichier de configuration gpg.conf. L'exécution de --init avec cette option définira le serveur de clés par défaut s'il n'était pas déjà configuré.

FOURNIR UN TROUSSEAU DE CLÉS POUR L'IMPORTATION

Une distribution ou un autre dépôt fourni peut vouloir fournir un ensemble de clés PGP utilisées pour la signature de ses paquets et bases de données de dépôt qui peuvent être facilement importées dans le trousseau de clés de pacman. Ceci est réalisé en fournissant un fichier de trousseau de clés PGP foo.gpg qui contient les clés pour le trousseau foo dans le répertoire /usr/share/pacman/keyrings.

Optionnellement, le fichier foo-trusted peut être fourni contenant une liste d'identifiants de clés de confiance pour ce trousseau. Ceci est un fichier dans un format compatible avec la sortie de gpg --export-ownertrust. Ce fichier informera l'utilisateur des clés qu'un utilisateur doit vérifier et signer pour construire une toile de confiance locale, en plus d'attribuer les valeurs de confiance propriétaire fournies.

Également optionnellement, le fichier foo-revoked peut être fourni contenant une liste d'identifiants de clés révoquées pour ce trousseau. Révoqué est défini comme "ne valant plus pour aucune signature", il faut donc l'utiliser avec prudence. Une clé marquée comme révoquée sera désactivée dans le trousseau de clés et ne sera plus traitée comme valide, donc cela prend toujours le dessus sur son état de confiance dans tout autre trousseau de clés.

NAME

pacman-key - manage the pacman keyring

SYNOPSIS

pacman-key [--init|--add|--lsign|--recv-keys|--refresh-keys|--delete-keys|--edit-key] [-Syu] [-f] [-n] [-q] [-v] [--] [keyid ...]

DESCRIPTION

pacman-key is used to manage the pacman GnuPG keyring. This keyring is used to verify the integrity of packages downloaded from the repositories.

When pacman is used to install packages, it checks the signature of the package. If the signature is not trusted, the package installation will be aborted.

pacman-key allows you to import, export, sign, and manage keys in the pacman keyring.

OPERATIONS

The following operations can be performed with pacman-key:

  • --init: Initializes a new pacman keyring. This should be done before importing any keys.
  • --add: Adds a key to the pacman keyring. The key can be specified as a file path or a key ID.
  • --lsign: Locally signs a key with your own key. This is useful for trusting keys that are not yet signed by other trusted keys.
  • --recv-keys: Receives keys from a keyserver. The key ID must be specified.
  • --refresh-keys: Refreshes keys from a keyserver. This will update existing keys with new signatures or information.
  • --delete-keys: Deletes keys from the pacman keyring. The key ID must be specified.
  • --edit-key: Edits a key in the pacman keyring. This allows you to change the trust level of a key or add comments.

OPTIONS

  • -Syu: Synchronizes the package databases and upgrades all installed packages. This option is often used in conjunction with key management operations to ensure that pacman has the latest information.
  • -f: Force. Overrides some checks and proceeds with the operation. Use with caution.
  • -n: Dry run. Shows what would be done but does not perform the actual operation.
  • -q: Quiet. Suppresses most output messages.
  • -v: Verbose. Shows more detailed output messages.
  • --: Separates options from key IDs. This is useful if a key ID could be mistaken for an option.
  • keyid: The ID of the key to operate on. This can be a full key ID or a partial ID.

PROVIDING A KEYRING FOR IMPORT

Keys can be provided for import in several ways:

  • As a file path to a public key file (e.g., pacman-key --add /path/to/key.asc).
  • As a key ID, in which case pacman-key will attempt to retrieve the key from a keyserver (e.g., pacman-key --recv-keys 0xDEADBEEF).
