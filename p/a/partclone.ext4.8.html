PARTCLONE(8) Manuel utilisateur Partclone PARTCLONE(8)

NOM

partclone - L'utilitaire pour cloner et restaurer une partition.

SYNTAXE

partclone.[type_fs] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] cible} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] logfile [-R | --rescue] [-L | --logfile] logfile [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPTION

partclone.[type_fs] fait partie du projet Partclone. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une meilleure compatibilité du système de fichiers en utilisant les bibliothèques existantes, par exemple, e2fslibs est utilisé pour lire le bloc utilisé de la partition ext2.

Le système de fichiers supporté par Partclone inclut btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Supporte également certains systèmes d'exploitation non-linux, par exemple : NTFS, FAT et EXFAT (pour Windows), HFS plus (MAC OS D'APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) et MINIX (MINIX3).

Tous les utilitaires partclone peuvent être exécutés comme partclone.[type_fs] est très similaire à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, exécutez simplement partclone.hfsp

       Système de fichiers                 partclone.[type_fs]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       autres (FS non supportés)   partclone.imager

OPTIONS

Le programme suit la syntaxe habituelle des commandes GNU, avec des options longues commençant par deux traits d'union (`-'). Un résumé des options est inclus ci-dessous.

-s FICHIER, --source FICHIER

FICHIER source. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique selon votre action. Normalement, la source de sauvegarde est un périphérique, la source de restauration est un fichier image.

La réception de données depuis un pipeline est supportée UNIQUEMENT pour la restauration, ignorez simplement l'option -s ou utilisez '-' qui signifie recevoir les données de stdin.

-o FICHIER, --output FICHIER

FICHIER de sortie. Le FICHIER peut être un fichier image (que partclone générera) ou un périphérique selon votre action. Normalement, la sortie de sauvegarde vers un fichier image et la sortie de restauration vers un périphérique.

L'envoi de données vers un pipeline est également supporté UNIQUEMENT pour la sauvegarde, ignorez simplement l'option -o ou utilisez '-' qui signifie envoyer les données à stdout.

-O FICHIER, --overwrite FICHIER

Écrase FICHIER, en écrasant s'il existe.

-W FICHIER, --restore_raw_file FICHIER

crée un fichier brut spécial pour le périphérique de boucle.

-c, --clone

Sauvegarde la partition dans le format d'image spécial.

-r, --restore

Restaure la partition à partir du format d'image spécial.

-b, --dev-to-dev

Copie locale de périphérique à périphérique à la volée, la source et la sortie sont toutes deux des périphériques.

-D, --domain

Crée un fichier log de domaine GNU Ddrescue à partir du périphérique source. C'est un fichier lisible par l'homme dans lequel + marque les zones de blocs utilisées et ? marque les zones libres.

--offset_domain=X

Ajoute X (en octets) à toutes les positions rapportées dans le fichier log de domaine

--restore_raw_file

Crée un fichier brut spécial pour le périphérique de boucle.

-L FICHIER, --logfile FICHIER

Place un chemin spécial pour enregistrer les informations du log partclone. (par défaut /var/log/partclone.log)

-R, --rescue

Continue après les erreurs de lecture du disque.

-C, --no_check

Ne vérifie pas la taille du périphérique et l'espace libre.

-N, --ncurses

Utilise une interface utilisateur textuelle Ncurses.

-I, --ignore_fschk

Ignore la vérification du système de fichiers.

-i, --ignore_crc

Ignore les erreurs de vérification CRC.

-F, --force

Force la progression.

-f sec, --UI-fresh sec

Définit un intervalle spécial en secondes.

-z taille, --buffer_size taille

Taille du tampon de lecture/écriture (par défaut : 1048576)

-q, --quiet

Désactive les messages de progression.

-dniveau, --debug niveau

Définit le niveau de débogage [1|2|3]

-x, --compresscmd CMD

Démarre CMD comme un tube de sortie pour compresser l'image clonée.

-aX, --checksum-mode=X

Formule de somme de contrôle à utiliser pour ajouter la détection d'erreurs.

où X :

0 : Pas de somme de contrôle (pas de ralentissement, image la plus petite)

1 : CRC32 (Rapide à calculer, détection basique)

2 : xxHash, algorithme de hachage non cryptographique extrêmement rapide.

-kX, --blocks-per-checksum=X

Écrit une somme de contrôle tous les X blocs.

-w, --skip_write_error

Continue la restauration en cas d'erreurs d'écriture.

--write-direct-io

Écriture des données dans la partition CIBLE sans cache.

--read-direct-io

Lecture des données de la partition SOURCE sans cache.

-B, --no_block_detail

Affiche le message de progression sans détails de bloc.

--binary-prefix

Affiche la progression avec la taille en bits (par défaut en Mo, Go...).

--prog-second

Affiche la progression en secondes (par défaut en minutes).

-E, --offset=X

Ajoute un décalage X (en octets) à la sortie.

-T, --btfiles

Restaure le bloc en tant que fichier pour ClonezillaBT.

-t, --btfiles_torrent

Restaure le bloc en tant que fichier pour ClonezillaBT mais génère seulement un torrent.

-n, --note NOTE

Affiche une note (128 mots).

-h, --help

Affiche le résumé des options.

-v, --version

Affiche la versi

partclone.ext4(8) — Manual page

NOM

partclone.ext4 - programme de clonage de partition et de copie de fichiers

SYNTAXE

partclone.ext4 [OPTIONS] -s <source> -o <destination>

DESCRIPTION

partclone.ext4 est un programme pour cloner une partition ou sauvegarder et restaurer des fichiers sur une partition. Il est conçu pour fonctionner avec les systèmes de fichiers ext2, ext3, ext4, reiserfs, reiser4, btrfs, xfs, f2fs, nilfs2 et certains autres systèmes de fichiers.

Les principales caractéristiques de partclone sont :

  • Clonage de partition bloc par bloc ou fichier par fichier.
  • Sauvegarde et restauration de partitions.
  • Support pour divers systèmes de fichiers.
  • Compression et décompression d'images (avec des outils externes).
  • Possibilité d'utiliser l'entrée et la sortie standard.
  • Option de débogage pour plus d'informations.

OPTIONS

Les options suivantes sont disponibles :

-c, --clone
Cloner la partition.
-r, --restore
Restaurer la partition à partir d'une image.
-s, --source <source>
Spécifier la source (partition ou fichier image).
-o, --output <destination>
Spécifier la destination (partition ou fichier image).
-d, --debug
Activer le mode de débogage.
-N, --no_common_error
Ne pas afficher les erreurs communes.
-h, --help
Afficher l'aide et quitter.
-v, --version
Afficher la version et quitter.

FICHIERS

/var/log/partclone.log

Le fichier journal de partclone

EXEMPLES

 Cloner /dev/hda1 vers hda1.img et afficher les informations de débogage.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 Restaurer /dev/hda1 à partir de hda1.img et afficher les informations de débogage.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 Restaurer une image de clonezilla (split, gzip,) avec une source stdin
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

Les diagnostics suivants peuvent être émis sur stderr :

partclone fournit certains codes de retour qui peuvent être utilisés dans les scripts :

Code Diagnostic
0 Le programme s'est terminé avec succès.
1 Le clonage ou la restauration semble avoir échoué.

BOGUES

Signalez les bogues à thomas@clonezilla.org ou http://partclone.org.

Vous pouvez obtenir de l'aide sur http://partclone.org
