NOM

pamtotga - convertir une image Netpbm en fichier TrueVision Targa

SYNTAXE

pamtotga [-mono|-cmap|-rgb] [-norle] [-nom=nom [fichier_pam]

Toutes les options peuvent être abrégées à leur préfixe unique le plus court. Vous pouvez utiliser deux tirets au lieu d'un pour désigner une option. Vous pouvez utiliser soit un espace, soit un signe égal entre le nom d'une option et sa valeur.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pamtotga lit une image PBM, PGM, PPM ou PAM en entrée et produit un fichier TrueVision Targa en sortie. L'image PAM peut être une image en noir et blanc (BLACKANDWHITE), en niveaux de gris (GRAYSCALE), RVB (RGB) ou RVB avec alpha (RGB_ALPHA).

Pour créer une image TGA avec transparence (c'est-à-dire avec un masque alpha), utilisez une entrée PAM au format RGB_ALPHA. Certains programmes Netpbm qui génèrent des images avec des masques alpha les génèrent dans ce format. Pour une autre manière de créer le flux d'entrée approprié, voir pamstack(1)

Il n'est pas clair que quoi que ce soit d'autre que pamtotga comprenne les TGA avec transparence. L'historique de cette fonctionnalité de pamtotga n'est pas clair. Le format produit par pamtotga est simplement le même qu'une image TGA RVB ordinaire, sauf qu'une 4ème plane est ajoutée pour la transparence. Le champ PixelSize de l'en-tête TGA spécifie 32 bits au lieu de 24 et le raster a un octet supplémentaire ajouté à chaque pixel, à la fin. La valeur de cet octet a la même signification que dans une image PAM avec un maxval de 255.

OPTIONS

-cmap
Crée un fichier Targa de sortie de type 24 bits avec palette de couleurs. L'entrée ne doit pas contenir plus de 256 couleurs distinctes.
-mono
Crée un fichier Targa de sortie de type 8 bits monochrome. L'entrée doit être PBM ou PGM ou un PAM avec un type de tuple BLACKANDWHITE ou GRAYSCALE. Voir -cmap.

Vous pouvez spécifier au plus une des options -mono, -cmap et -rgb. Si vous ne spécifiez aucune de ces options, le type d'image par défaut est le type compatible le plus restreint, où le monochrome est plus restreint que la palette de couleurs, qui est elle-même plus restreinte que non mappée.

-rgb
Crée un fichier Targa de sortie de type 24 bits couleur non mappée. Voir -cmap.
-norle
N'utilise pas le codage run-length dans le fichier Targa de sortie. Les fichiers codés en run-length sont plus petits, mais certains lecteurs Targa ne peuvent pas lire les fichiers codés en run-length.
-nom=nom
Ceci est la valeur de l'ID de l'image indiqué dans l'en-tête du fichier de sortie TGA. pamtotga le tronque si nécessaire pour respecter les normes TGA.

Par défaut, pamtotga utilise le nom de fichier d'entrée, jusqu'au premier point (ou le nom entier s'il n'y a pas de point). Il le tronque si nécessaire pour respecter les normes TGA. Si vous spécifiez (ou utilisez par défaut) l'entrée standard, pamtotga omet l'ID de l'image de l'en-tête TGA.

HISTORIQUE

Ce programme s'appelait ppmtotga jusqu'à Netpbm 10.6 (juillet 2002). C'était cependant toujours un nom trompeur, car un programme de la classe PPM ne pourrait pas faire la différence entre une entrée PGM et PPM (cela ressemblerait tout à fait à du PPM), et ne pourrait donc pas choisir le type d'image Targa de sortie en fonction du type de l'entrée. Netpbm 10.6 a également ajouté la capacité de gérer un canal alpha, il est donc devenu un programme de la classe PAM.

Dans Netpbm 10.15 (avril 2003), le programme est devenu le premier du paquet Netpbm à reconnaître un canal alpha dans un PAM. Il reconnaissait le type de tuple 'RGBA'. Mais lorsque ce type d'image PAM a été ajouté plus tard à la spécification PAM, il a été spécifié avec le type de tuple 'RGB_ALPHA'. Donc, dans Netpbm 10-26 (janvier 2005), pamtotga a changé pour reconnaître 'RGB_ALPHA' au lieu de 'RGBA'.
