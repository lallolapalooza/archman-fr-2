pactester(1) pactester(1)

NOM

pactester - Outil pour tester les fichiers de configuration proxy automatique (pac).

SYNTAXE

pactester <-p fichier_pac> <-u url> [-h hôte] [-c ip_client] [-e]

pactester <-p fichier_pac> <-f liste_urls> [-c ip_client] [-e]

DESCRIPTION

pactester est un outil pour tester les fichiers de configuration proxy automatique (pac). Il renvoie la chaîne de configuration du proxy pour l'URL donnée et le fichier pac. pactester utilise la bibliothèque C pacparser pour la plupart de ses fonctionnalités.

OPTIONS

-p fichier_pac
Fichier PAC à tester. Spécifiez "-" pour lire depuis l'entrée standard.
-u url
URL pour tester le fichier PAC.
-h hôte
Partie hôte de l'URL. Si elle n'est pas spécifiée, elle est déterminée à partir de l'URL.
-c ip_client
Adresse IP du client (telle que retournée par la fonction myIpAddress() dans les fichiers PAC). Si elle n'est pas spécifiée, elle prend par défaut l'adresse IP de la machine sur laquelle cet outil est exécuté.
-e
Active les extensions PAC de Microsoft (dnsResolveEx, myIpAddressEx, isResolvableEx).
-f liste_urls
Un fichier contenant la liste des URL à tester. C'est utile pour tester un fichier PAC par rapport à un ensemble d'URL.

EXEMPLES

Pour trouver la chaîne de configuration du proxy pour le fichier pac "wpad.dat" et l'URL "http://www.google.com" :

$ pactester -p wpad.dat -u http://www.google.com

Pour un client avec l'adresse IP 10.0.12.123 :

$ pactester -p wpad.dat -c 10.0.12.123 -u http://www.google.com

Pour un fichier pac hébergé à http://wpad/wpad.dat :

$ curl -s http://wpad/wpad.dat | pactester -p - -u http://google.com
