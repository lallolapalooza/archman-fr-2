PADTHV1(1) Manuel des commandes générales PADTHV1(1)

NOM

padthv1 - un synthétiseur additif polyphonique old-school

SYNTAXE

padthv1_jack [options] [fichier-preset]

DESCRIPTION

Cette page de manuel documente brièvement la commande padthv1_jack.

padthv1 est un synthétiseur additif polyphonique old-school avec effets stéréo.

fonctionnalités :

un client JACK autonome pur avec prise en charge de JACK-session, NSM et des entrées MIDI JACK et ALSA ;
un plugin d'instrument LV2. URI : http://padthv1.sourceforge.net/lv2

OPTIONS

-g, --no-gui

Désactiver l'interface utilisateur graphique (GUI)

-n, --client-name=[label]

Définir le nom du client JACK (par défaut : padthv1)

-h, --help

Afficher l'aide sur les options de la ligne de commande

-v, --version

Afficher les informations sur la version

FICHIERS

Les paramètres de configuration sont stockés dans ~/.config/rncbc.org/padthv1.conf
