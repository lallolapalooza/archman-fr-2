NOM

pam_limits - module PAM pour limiter les ressources

SYNTAXE

pam_limits.so [conf=/chemin/vers/limits.conf] [debug] [set_all] [utmp_early] [noaudit]

DESCRIPTION

Le module PAM pam_limits définit des limites sur les ressources système qui peuvent être obtenues dans une session utilisateur. Les utilisateurs avec uid=0 sont également affectés par ces limites.

Par défaut, les limites sont tirées du fichier de configuration /etc/security/limits.conf. Ensuite, les fichiers *.conf individuels du répertoire /etc/security/limits.d/ sont lus. Les fichiers sont analysés un par un dans l'ordre de la locale "C". L'effet des fichiers individuels est le même que si tous les fichiers étaient concaténés ensemble dans l'ordre d'analyse. Si un fichier de configuration est explicitement spécifié avec une option de module, les fichiers du répertoire ci-dessus ne sont pas analysés.

Le module ne doit pas être appelé par une application multithreadée.

Si Linux PAM est compilé avec le support d'audit, le module signalera lorsqu'il refusera l'accès en raison de la limite du nombre maximum de sessions de connexion simultanées.

OPTIONS

conf=/chemin/vers/limits.conf

Indique un fichier de configuration alternatif de style limits.conf pour remplacer le défaut.

debug

Imprime des informations de débogage.

set_all

Définit les limites pour lesquelles aucune valeur n'est spécifiée dans le fichier de configuration à celle du processus avec le PID 1. Veuillez noter que si le processus init est systemd, ces limites ne seront pas les limites par défaut du noyau et cette option ne doit pas être utilisée.

utmp_early

Certaines applications défectueuses allouent une entrée utmp pour l'utilisateur avant que celui-ci ne soit admis dans le système. Si certains des services pour lesquels vous configurez PAM font cela, vous pouvez utiliser sélectivement cet argument de module pour compenser ce comportement et en même temps maintenir la cohérence à l'échelle du système avec un seul fichier limits.conf.

noaudit

Ne pas signaler le dépassement du nombre maximum de connexions au sous-système d'audit.

TYPES DE MODULES FOURNIS

Seul le type de module session est fourni.

VALEURS DE RETOUR

PAM_ABORT

Impossible d'obtenir les limites actuelles.

PAM_IGNORE

Aucune limite trouvée pour cet utilisateur.

PAM_PERM_DENIED

Les nouvelles limites n'ont pas pu être définies.

PAM_SERVICE_ERR

Impossible de lire le fichier de configuration.

PAM_SESSION_ERR

Erreur lors de la récupération du nom de compte.

PAM_SUCCESS

Les limites ont été modifiées.

PAM_USER_UNKNOWN

L'utilisateur n'est pas connu du système.

FICHIERS

/etc/security/limits.conf

Fichier de configuration par défaut

EXEMPLES

Pour les services qui nécessitent des limites de ressources (connexion, par exemple), ajoutez la ligne suivante dans /etc/pam.d/login comme dernière ligne pour ce service (généralement après la ligne de session pam_unix) :

#%PAM-1.0
#
# Limites de ressources imposées aux sessions de connexion via pam_limits
#
session  required  pam_limits.so

Remplacez "login" par chaque service pour lequel vous utilisez ce module.

VOIR AUSSI

limits.conf(5), pam.d(5), pam(8).
