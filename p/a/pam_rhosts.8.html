NOM

pam_rhosts - Le module PAM rhosts

SYNOPSIS

pam_rhosts.so

DESCRIPTION

Ce module effectue l'authentification réseau standard pour les services, telle qu'utilisée par les implémentations traditionnelles de rlogin, rsh, etc.

Le mécanisme d'authentification de ce module est basé sur le contenu de deux fichiers ; /etc/hosts.equiv (ou et ~/.rhosts. Premièrement, les hôtes listés dans le premier fichier sont traités comme équivalents à localhost. Deuxièmement, les entrées dans la copie du second fichier par l'utilisateur sont utilisées pour mapper les paires "hôte-distant utilisateur-distant" au compte de cet utilisateur sur l'hôte courant. L'accès est accordé à l'utilisateur si son hôte est présent dans /etc/hosts.equiv et si son compte distant est identique à son compte local, ou si son compte distant a une entrée dans son fichier de configuration personnel.

Le module authentifie un utilisateur distant (spécifié en interne par l'élément PAM_RUSER) se connectant depuis un hôte distant (spécifié en interne par l'élément PAM_RHOST). En conséquence, pour que les applications soient compatibles avec ce module d'authentification, elles doivent définir ces éléments avant d'appeler pam_authenticate(). Le module n'est pas capable de sonder indépendamment la connexion réseau pour de telles informations.

OPTIONS

debug

Affiche des informations de débogage.

silent

N'affiche pas de messages informatifs.

superuser=account

Traite account comme root.

TYPES DE MODULES FOURNIS

Seul le type de module auth est fourni.

VALEURS DE RETOUR

PAM_AUTH_ERR

L'hôte distant, le nom d'utilisateur distant ou le nom d'utilisateur local n'ont pas pu être déterminés ou l'accès a été refusé par le fichier .rhosts.

PAM_USER_UNKNOWN

L'utilisateur n'est pas connu du système.

EXEMPLES

Pour accorder l'accès à un utilisateur distant via /etc/hosts.equiv ou .rhosts pour rsh, ajoutez les lignes suivantes à /etc/pam.d/rsh :

#%PAM-1.0
#
auth     required       pam_rhosts.so
auth     required       pam_nologin.so
auth     required       pam_env.so
auth     required       pam_unix.so
