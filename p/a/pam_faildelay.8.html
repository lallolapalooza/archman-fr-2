NOM

pam_faildelay - Changer le délai en cas d'échec par application

SYNTAXE

pam_faildelay.so [debug] [delay=microsecondes]

DESCRIPTION

pam_faildelay est un module PAM qui peut être utilisé pour définir le délai en cas d'échec par application.

Si aucun delay n'est spécifié, pam_faildelay utilisera la valeur de FAIL_DELAY de /etc/login.defs.

OPTIONS

debug

Active les messages de débogage envoyés à syslog.

delay=N

Définit le délai en cas d'échec à N microsecondes.

TYPES DE MODULES FOURNIS

Seul le type de module auth est fourni.

VALEURS DE RETOUR

PAM_IGNORE

Le délai a été ajusté avec succès.

PAM_SYSTEM_ERR

Le délai spécifié n'était pas valide.

EXEMPLES

L'exemple suivant définira le délai en cas d'échec à 10 secondes :

auth  optional  pam_faildelay.so  delay=10000000

VOIR AUSSI

pam_fail_delay(3), pam.conf(5), pam.d(5), pam(8)
