NOM

pam_sm_open_session - fonction de service PAM pour démarrer la gestion de session

SYNTAXE

#include <security/pam_modules.h>

int pam_sm_open_session(pam_handle_t *pamh, int flags, int argc, const char **argv);

DESCRIPTION

La fonction pam_sm_open_session est l'implémentation par le module de service de l'interface pam_open_session(3).

Cette fonction est appelée pour commencer une session. La seule valeur valide pour flags est zéro ou :

PAM_SILENT

Ne pas émettre de messages.

VALEURS DE RETOUR

PAM_SESSION_ERR

Impossible de créer/supprimer une entrée pour la session spécifiée.

PAM_SUCCESS

La session a été démarrée avec succès.

VOIR AUSSI
