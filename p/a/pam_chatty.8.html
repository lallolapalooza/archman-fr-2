NOM

pam_chatty - Un module de test PAM qui génère des messages d'information et d'erreur PAM.

SYNTAXE

pam_chatty.so [...]

DESCRIPTION

Le module pam_chatty facilite la réplication du comportement des modules PAM qui génèrent beaucoup de sortie, afin de s'assurer que les clients PAM réagissent comme prévu.

IMPORTANT

pam_chatty est un outil de test. Il doit être considéré comme totalement non sécurisé et ne jamais être utilisé en dehors des environnements de test ! Comme vous le verrez en lisant la description des options, beaucoup d'entre elles n'ont aucun sens dans le monde réel et ont été ajoutées juste pour rendre les tests possibles.

Le module pam_chatty génère beaucoup de messages d'information et d'erreur PAM, lorsque sa méthode d'authentification est appelée, puis retourne le succès.

OPTIONS

•num_lines=NOMBRE - le nombre de lignes de messages à générer, pour chacun des types de messages activés sélectionnés.
•error - si des messages de niveau erreur doivent être générés.
•info - si des messages de niveau information doivent être générés.

TYPES DE MODULES FOURNIS

Seul le type de module auth est pris en charge.

EXEMPLE

auth            required        pam_chatty.so num_lines=16 info error
