NOM

pamrgbatopng - convertir une image couleur/transparence PAM en PNG

SYNTAXE

pamrgbatopng [pamfile]

Une abréviation unique minimale de l'option est acceptable. Vous pouvez utiliser des doubles tirets au lieu de tirets simples pour désigner les options. Vous pouvez utiliser des espaces blancs à la place du signe égal pour séparer le nom d'une option de sa valeur.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pamrgbatopng lit une image PAM avec le type de tuple RGB_ALPHA (une image visuelle couleur avec transparence) et produit une image PNG équivalente en sortie.

L'image d'entrée provient du fichier nommé par l'argument pamfile, ou de l'entrée standard si vous ne spécifiez pas pamfile. La sortie va vers la sortie standard.

La valeur maximale de l'image d'entrée doit être 255. Vous pouvez utiliser pamdepth pour changer la valeur maximale d'une image à 255 si nécessaire.

pnmtopng(1)
est un programme beaucoup plus puissant pour générer des images PNG à partir d'images Netpbm, mais il ne peut pas prendre des images PAM avec transparence comme entrée. Pour fournir des informations de transparence, vous devez les fournir dans une image PGM séparée. Cela le rend considérablement moins pratique à utiliser.

(Mais notez que pnmtopng prend des images PAM, même avec le type de tuple RGB_ALPHA, sans problème - il ignore simplement le plan alpha).

La direction stratégique de Netpbm est d'ajouter à pnmtopng toutes les capacités de pamrgbatopng et de retirer pamrgbatopng. Mais on ne sait pas quand cela arrivera.

OPTIONS

Aucune.
