PACCACHE(8) Manuel Pacman-contrib PACCACHE(8)

NOM

paccache — utilitaire flexible de nettoyage du cache pacman

SYNTAXE

paccache <opération> [options] [cible ...]

DESCRIPTION

paccache supprime les anciens paquets du répertoire de cache de pacman. Par défaut, les trois dernières versions d'un paquet sont conservées.

OPÉRATIONS

-d, --dryrun

Effectuer un essai à blanc, ne trouvant que les paquets candidats.

-m, --move <dir>

Déplacer les paquets candidats du répertoire de cache vers dir.

-r, --remove

Supprimer les paquets candidats du répertoire de cache.

OPTIONS

-a, --arch <arch>

Analyser les paquets d'une architecture spécifique. Par défaut, l'analyse porte sur toutes les architectures.

-c, --cachedir <dir>

Spécifier un répertoire de cache différent. Cette option peut être utilisée plusieurs fois. Par défaut, le répertoire de cache configuré dans pacman.conf est utilisé.

-f, --force

Appliquer la force aux opérations mv et rm.

-h, --help

Afficher la syntaxe et les options de ligne de commande.

-i, --ignore <pkgs>

Spécifier les paquets à ignorer, séparés par des virgules. Alternativement, "-" peut être utilisé pour lire les noms des paquets depuis stdin, délimités par des sauts de ligne.

-k, --keep <num>

Spécifier combien de versions de chaque paquet sont conservées dans le répertoire de cache, par défaut 3.

--min-atime <time>, --min-mtime <time>

Conserver les paquets dont le temps d'accès (atime) / de modification (mtime) n'est pas plus ancien que le temps donné, même si cela signifie conserver plus de paquets que spécifié par l'option --keep. Accepte des arguments selon info "Date input formats", par exemple 30 days ago (il y a 30 jours).

--nocolor

Ne pas coloriser la sortie.

-z, --null

Utiliser des délimiteurs nuls pour les noms de candidats (uniquement avec -v et -vv).

-q, --quiet

Minimiser la sortie.

-u, --uninstalled

Cibler les paquets désinstallés.

-v, --verbose

Augmenter la verbosité, peut être spécifié jusqu'à 3 fois.

-V, --version

Afficher les informations de version.

SYSTÈME TIMER

Le cache des paquets peut être nettoyé périodiquement à l'aide du timer systemd paccache.timer. Si le timer est activé, le cache sera nettoyé chaque semaine avec les options par défaut de paccache.

VOIR AUSSI

pacman(8), pacman.conf(5), systemctl(1)

BOGUES

Des bogues ? Vous plaisantez ; il n'y a pas de bogues dans ce logiciel. Mais si nous nous trompons, veuillez signaler un problème avec autant de détails que possible sur https://gitlab.archlinux.org/pacman/pacman-contrib/-/issues/new.
