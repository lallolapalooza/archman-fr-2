pas2fpm(1) Outil de génération de fichiers fpmake pour Free Pascal pas2fpm(1)

NOM

pas2fpm - L'outil de génération de fichiers fpmake.pp pour les unités Free Pascal.

SYNTAXE

pas2fpm [options] fichier1...fic_n

DESCRIPTION

pas2fpm Crée un fichier fpmake.pp à partir des fichiers d'unité spécifiés. Il essaie d'ordonner les unités de manière optimale en analysant la clause uses. Il ne gère pas les fichiers de programme, seuls les fichiers d'unité sont pris en charge.

UTILISATION

pas2fpm accepte les options suivantes pour le moment :

-h
Affiche un court message d'aide.
-o fichier_sortie
Par défaut, pas2fpm écrit un fichier fpmake.pp et avec cette option, le nom peut être modifié.
-p nom_package
Spécifie le nom du package dans le fichier fpmake.
-v
Être verbeux : écrire des informations de diagnostic.
