NOM

pamsplit - diviser un fichier Netpbm multi-images en fichiers d'images uniques

SYNTAXE

pamsplit

[fichier_netpbm

[ modèle_fichier_sortie]]

[-padname=n]

L'abréviation unique minimale de l'option est acceptable. Vous pouvez utiliser des doubles tirets au lieu de tirets simples pour désigner les options. Vous pouvez utiliser des espaces blancs à la place du signe égal pour séparer un nom d'option de sa valeur.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pamsplit lit un flux PNM ou PAM en entrée. Il copie chaque image de l'entrée dans un fichier séparé, dans le même format.

fichier_netpbm est le nom du fichier d'entrée, ou - pour indiquer l'entrée standard. La valeur par défaut est l'entrée standard.

modèle_fichier_sortie indique comment nommer les fichiers de sortie. C'est le nom du fichier de sortie, à l'exception de la première occurrence de '%d' qui est remplacée par le numéro de séquence de l'image en décimal ASCII non rempli, la séquence commençant à 0. S'il n'y a pas de '%d' dans le modèle, pamsplit échoue.

Le modèle de fichier de sortie par défaut est 'image%d'.

L'option -padname spécifie à combien de caractères vous souhaitez que le numéro de séquence de l'image dans le nom du fichier de sortie soit rempli de zéros. pamsplit ajoute des zéros en tête au numéro de séquence de l'image pour atteindre au moins ce nombre de caractères. Il s'agit simplement du nombre de caractères dans la partie du nom du numéro de séquence. Par exemple, pamsplit - fichier_sortie%d.ppm -padname=3 produirait des noms de fichiers de sortie fichier_sortie000.ppm, fichier_sortie001.ppm, etc.

La valeur par défaut est aucun remplissage (équivalent à -padname=0).

L'option -padname est nouvelle dans Netpbm 10.23 (juillet 2004). Avant cela, il n'y avait jamais de remplissage.

Notez que pour effectuer l'opération inverse (combiner plusieurs fichiers Netpbm d'une seule image en un seul fichier multi-images), il n'y a pas de programme Netpbm spécial. Utilisez simplement cat.

Si vous voulez simplement obtenir des informations de base sur les images d'un flux, vous pouvez utiliser pamfile sur le flux.

Pour extraire des images d'un flux et générer un flux unique les contenant, utilisez pampick.

Pour exécuter un programme sur chaque image d'un flux sans avoir à gérer de fichiers temporaires, utilisez pamexec.
