Documentation des fonctions

int pacparser_init (void)

Initialise le parseur PAC.

Retourne :

0 en cas d'échec et 1 en cas de succès.

Initialise le moteur JavaScript et effectue quelques initialisations de base spécifiques à pacparser.

int pacparser_parse_pac_file (const char *pacfile)

Analyse le fichier PAC donné.

Paramètres :

pacfile Fichier PAC à analyser.

Retourne :

0 en cas d'échec et 1 en cas de succès.

Lit le fichier PAC donné et l'évalue dans le contexte JavaScript créé par pacparser_init.

int pacparser_parse_pac_string (const char *pacstring)

Analyse la chaîne de script PAC donnée.

Paramètres :

pacstring Chaîne PAC à analyser.

Retourne :

0 en cas d'échec et 1 en cas de succès.

Évalue la chaîne de script PAC donnée dans le contexte JavaScript créé par pacparser_init.

int pacparser_parse_pac (const char *pacfile)

Analyse le fichier PAC donné.

Obsolète

Utilisez plutôt pacparser_parse_pac_file.

Paramètres :

pacfile Fichier PAC à analyser.

Retourne :

0 en cas d'échec et 1 en cas de succès.

Identique à pacparser_parse_pac_file. Inclus uniquement pour des raisons de compatibilité ascendante.

char* pacparser_find_proxy (const char *url, const char *host)

Trouve un proxy pour l'URL et l'hôte donnés.

Paramètres :

url URL pour laquelle trouver un proxy.
host Partie hôte de l'URL.

Retourne :

Chaîne de proxy en cas de succès et NULL en cas d'erreur.

Trouve un proxy pour l'URL et l'hôte donnés. Cette fonction ne doit être appelée qu'après l'initialisation du moteur pacparser (avec pacparser_init) et l'analyse du script PAC (avec pacparser_parse_pac_file ou pacparser_parse_pac_string).

char* pacparser_just_find_proxy (const char *pacfile, const char *url, const char *host)

Trouve un proxy pour le fichier PAC, l'URL et l'hôte donnés.

Paramètres :

pacfile Fichier PAC à analyser.
url URL pour laquelle trouver un proxy.
host Partie hôte de l'URL.

Retourne :

Chaîne de proxy en cas de succès et NULL en cas d'erreur.

Cette fonction est un wrapper autour des fonctions pacparser_init, pacparser_parse_pac_file, pacparser_find_proxy et pacparser_cleanup. Si vous voulez simplement trouver le proxy pour un ensemble donné de fichier PAC, URL et hôte, c'est la fonction à appeler. Cette fonction s'occupe de toute l'initialisation et du nettoyage.

void pacparser_cleanup (void)

Détruit le contexte JavaScript. Cette fonction doit être appelée une fois que vous avez terminé d'utiliser le moteur pacparser.

void pacparser_setmyip (const char *ip)

Définit mon adresse IP.

Paramètres :

ip Adresse IP personnalisée.

Définit mon adresse IP à une valeur personnalisée. C'est l'adresse IP retournée par la fonction JavaScript myIpAddress().

void pacparser_set_error_printer (pacparser_error_printerfunc)

Définit la fonction d'impression des erreurs.

Paramètres :

func Fonction d'impression.

Définit la fonction d'impression des erreurs avec arguments variables. Si elle n'est pas définie, les messages sont imprimés sur stderr. Si les messages commencent par DEBUG: ou WARNING:, ce ne sont pas des messages d'erreur fatals, sinon ils le sont. Peut être appelée avant pacparser_init().

void pacparser_enable_microsoft_extensions (void)

(Obsolète) Active les extensions IPv6 de Microsoft pour les PAC. Obsolète. Les extensions IPv6 (fonctions *Ex) sont activées par défaut maintenant.

char* pacparser_version (void)

Retourne la version de pacparser.

Retourne :

Chaîne de version si la version est définie, '' sinon.

La chaîne de version est déterminée au moment de la compilation. Si compilé à partir d'un paquet publié, la version correspond au dernier tag de sortie (git). Si compilé à partir du dépôt, elle correspond à la dernière révision du dépôt.
