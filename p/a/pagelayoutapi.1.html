NOM

pagelayoutapi - API pour la classe LaTeX pagelayout

SYNTAXE

pagelayoutapi getwidth % FICHIER

pagelayoutapi getheight % FICHIER

pagelayoutapi optimize % FICHIER % NOMFICHIER % EXTENSION % LARGEURORIGINALE % HAUTEURORIGINALE % ROGNERGAUCHE % ROGNERDROITE % ROGNERHAUT % ROGNERBAS % DENSITE % LARGEUR % HAUTEUR % SEUILREDUCTION % AFFAUTAGE % QUALITE

pagelayoutapi makeshadow % NOMFICHIER % ECARTTYPE % OPACITE % COULEUR % LARGEUR % HAUTEUR % LARGEURCADRE % HAUTEURCADRE % MARGE % RAYONBORDURE

pagelayoutapi start [% import % [CHEMINGRAPHIQUES]] [% turbo % NOMTRAVAIL]

pagelayoutapi batchoptimize % LISTEBATCH

DESCRIPTION

Ce script fournit une API pour la classe LaTeX pagelayout.

pagelayoutapi getwidth
Retourne la largeur en pixels pour le fichier image donné.
pagelayoutapi getheight
Retourne la hauteur en pixels pour le fichier image donné.
pagelayoutapi optimize
Crée une image rognée, redimensionnée, affûtée et compressée et la stocke dans le répertoire de cache.
pagelayoutapi makeshadow
Crée une image d'ombre et la stocke dans le répertoire de cache.
pagelayoutapi start
Le paramètre import déclenche l'importation d'images (voir le chapitre « Optimisation des images » du manuel pagelayout). L'exécution de la commande avec le paramètre turbo, où le nom du travail est le nom du fichier du document, traite le document en mode batch spécial, qui crée une liste de jobs et appelle la commande pagelayoutapi batchoptimize.
pagelayoutapi batchoptimize
Optimise plusieurs images en parallèle.

OPTIONS

--help
Affiche un message d'aide.
--version
Affiche les informations sur la version.

PARAMETRES

FICHIER
Nom du fichier avec extension (par ex. IMG1234.JPEG)
NOMFICHIER
Nom du fichier sans extension (par ex. IMG1234)
EXTENSION
Extension de fichier optimisé (.jpg|.png)
DENSITE
Densité en ppp (par ex. 72)
SEUILREDUCTION
Seuil de réduction (entier >= 100)
AFFAUTAGE
Filtre d'affûtage (par ex. 2x1)
QUALITE
Qualité (entier > 0, <= 100)
ECARTTYPE
Écart-type (décimal > 0.0)
OPACITE
Opacité (décimal >= 0.0, <= 1.0)
COULEUR
Chaîne de caractères de couleur (par ex. rose)
CHEMINGRAPHIQUES
Liste de répertoires (par ex. {images/}{tmp/})
NOMTRAVAIL
Nom du fichier LaTeX sans extension (par ex. mon-document)
LISTEBATCH
Une liste plate d'éléments batch où chaque élément batch est une liste plate des 15 paramètres requis par la commande `pagelayoutapi optimize`

Tous les autres paramètres sont des dimensions de longueur. La commande pagelayoutapi optimize attend des valeurs entières dans l'unité LaTeX sp (par ex. 65536). La commande pagelayoutapi makeshadow attend des valeurs décimales dans une unité compatible SVG (par ex. 420.0pt).

ENVIRONNEMENT

pagelayoutapi nécessite ImageMagick 7.0 ou supérieur et Inkscape 1.0 ou supérieur.

PAGELAYOUT_IMPORT_DIRECTORY
Définit un répertoire d'importation global.
