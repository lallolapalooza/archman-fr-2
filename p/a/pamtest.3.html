Documentation des types énumérés

enum pamtest_err

Le code de retour de la fonction pamtest.

Énumérateur

PAMTEST_ERR_OK
Les cas de test retournés correspondent à l'entrée.
PAMTEST_ERR_START
pam_start() a échoué.
PAMTEST_ERR_CASE
Un cas de test a échoué. Utilisez pamtest_failed_case.
PAMTEST_ERR_OP
Impossible d'exécuter un cas de test.
PAMTEST_ERR_END
pam_end a échoué.
PAMTEST_ERR_KEEPHANDLE
Géré en interne.
PAMTEST_ERR_INTERNAL
Erreur interne - entrée invalide ou similaire.

enum pamtest_ops

L'enum qui décrit les opérations effectuées par pamtest().

Énumérateur

PAMTEST_AUTHENTICATE
exécute pam_authenticate pour authentifier le compte.
PAMTEST_SETCRED
exécute pam_setcred() pour établir/supprimer les identifiants de l'utilisateur.
PAMTEST_ACCOUNT
exécute pam_acct_mgmt() pour valider le compte PAM.
PAMTEST_OPEN_SESSION
exécute pam_open_session() pour démarrer une session PAM.
PAMTEST_CLOSE_SESSION
exécute pam_close_session() pour terminer une session PAM.
PAMTEST_CHAUTHTOK
exécute pam_chauthtok() pour mettre à jour le jeton d'authentification.
PAMTEST_GETENVLIST
Si cette option est définie, le test appellera pam_getenvlist() et copiera l'environnement dans case_out.envlist.
PAMTEST_KEEPHANDLE
Cela empêchera l'appel de pam_end() et retournera simplement le handle PAM dans case_out.ph.

Documentation des fonctions

const struct pam_testcase * pamtest_failed_case (struct pam_testcase * test_cases)

Aide que vous pouvez appeler si run_pamtest() échoue. Si PAMTEST_ERR_CASE est retourné par run_pamtest(), vous devriez appeler cette fonction pour obtenir un pointeur vers le cas de test échoué.

Paramètres

test_cases Le tableau des tests.

Retourne

un pointeur vers le tableau de test_cases[] qui correspond au premier cas de test où le code d'erreur attendu ne correspond pas au code d'erreur réel.

void pamtest_free_env (char ** envlist)

Ceci libère le tableau de chaînes retourné par le test PAMTEST_GETENVLIST.

Paramètres

envlist Le tableau à libérer.

const char * pamtest_strerror (enum pamtest_err perr)

retourne une représentation textuelle du code d'erreur libpamtest.

Paramètres

perr Code d'erreur libpamtest

Retourne

Représentation textuelle de l'argument perr. Ne retourne jamais NULL.

Références PAMTEST_ERR_CASE, PAMTEST_ERR_END, PAMTEST_ERR_INTERNAL, PAMTEST_ERR_KEEPHANDLE, PAMTEST_ERR_OK, PAMTEST_ERR_OP, et PAMTEST_ERR_START.

run_pamtest

Exécute des cas de test libpamtest. Utilise la fonction de conversation par défaut de libpamtest.

Paramètres

service Le service PAM à utiliser dans la conversation
user L'utilisateur pour lequel exécuter la conversation
conv_data Données de conversation spécifiques au test
test_cases Liste des cas de test libpamtest. Doit se terminer par PAMTEST_CASE_SENTINEL
pam_handle Le handle PAM à utiliser pour exécuter les tests
int main(void) {
    int rc;
    const struct pam_testcase tests[] = {
        pam_test(PAM_AUTHENTICATE, PAM_SUCCESS),
    };
    rc = run_pamtest(tests, NULL, NULL);
    return rc;
}

Retourne

PAMTEST_ERR_OK en cas de succès, sinon le code d'erreur correspondant à l'échec.
