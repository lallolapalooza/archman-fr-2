NOM

pampick - sélectionner des images à partir d'un flux d'images Netpbm multi-images

SYNTAXE

pampick

numéro_séquence_image ...

L'abréviation unique minimale de l'option est acceptable. Vous pouvez utiliser des doubles tirets au lieu de simples tirets pour désigner les options. Vous pouvez utiliser un espace blanc à la place du signe égal pour séparer un nom d'option de sa valeur.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pampick lit un flux d'images PNM ou PAM en entrée. Il sélectionne certaines images du flux et les copie dans un nouveau flux d'images sur la sortie standard.

Vous identifiez les images à sélectionner par leur numéro de séquence dans le flux. Chaque numéro_séquence_image est un numéro de séquence décimal, zéro signifiant la première image.

Les arguments doivent être dans un ordre croissant, sans doublons. Les résultats sont indéfinis s'ils ne le sont pas. (Il existe un certain nombre d'améliorations qui pourraient être apportées dans les futures versions qui rendraient le comportement de pampick lorsque vous enfreignez cette règle obsolète). pampick produit les images dans le même ordre qu'elles apparaissent dans l'entrée. Si vous ne spécifiez aucun numéro de séquence, pampick ne produit rien. Si vous spécifiez un numéro de séquence qui dépasse ce qui est dans l'entrée, pampick échoue avec un message d'erreur à cet effet.

pampick lit toujours l'intégralité du flux d'entrée. (Ceci est utile lorsque le flux d'entrée est un pipe et que ce qui alimente le pipe serait contrarié s'il se remplissait ou se cassait).

Pour voir combien d'images, et de quel type, se trouvent dans un flux, utilisez pamfile.

Pour extraire toutes les images d'un flux dans des fichiers nommés séparément, utilisez pamsplit.
