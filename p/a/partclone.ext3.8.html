PARTCLONE(8) Manuel de l'utilisateur Partclone PARTCLONE(8)

NOM

partclone - L'utilitaire pour cloner et restaurer une partition.

SYNTAXE

partclone.[type_fs] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] cible} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] fichier_journal [-R | --rescue] [-L | --logfile] fichier_journal [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPTION

partclone.[type_fs] fait partie du projet Partclone. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une compatibilité accrue du système de fichiers en utilisant des bibliothèques existantes, par exemple, e2fslibs est utilisé pour lire le bloc utilisé d'une partition ext2.

Les systèmes de fichiers supportés par Partclone incluent btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Il supporte également certains systèmes d'exploitation non-Linux, par exemple : NTFS, FAT et EXFAT (pour Windows), HFS plus (MAC OS APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) et MINIX (MINIX3).

Tous les utilitaires partclone peuvent être exécutés comme partclone.[type_fs], ce qui est très similaire à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, lancez simplement partclone.hfsp

       Système de Fichier           partclone.[type_fs]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       autres (FS non supportés)   partclone.imager

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-s FICHIER, --source FICHIER

FICHIER source. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique selon votre action. Normalement, la source de sauvegarde est un périphérique, la source de restauration est un fichier image.

La réception de données depuis un pipe est supportée UNIQUEMENT pour la restauration, ignorez simplement l'option -s ou utilisez '-' pour recevoir des données depuis stdin.

-o FICHIER, --output FICHIER

FICHIER de sortie. Le FICHIER peut être un fichier image (que partclone générera) ou un périphérique selon votre action. Normalement, la sortie de sauvegarde va vers un fichier image et la sortie de restauration va vers un périphérique.

L'envoi de données vers un pipe est également supporté UNIQUEMENT pour la sauvegarde, ignorez simplement l'option -o ou utilisez '-' pour envoyer des données vers stdout.

-O FICHIER, --overwrite FICHIER

Écrase le FICHIER s'il existe.

-W FICHIER, --restore_raw_file FICHIER

Crée un fichier brut spécial pour le périphérique de boucle.

-c, --clone

Sauvegarde la partition dans le format d'image spécial.

-r, --restore

Restaure la partition à partir du format d'image spécial.

-b, --dev-to-dev

Copie locale d'un périphérique à un autre à la volée, la source et la sortie sont toutes deux des périphériques.

-D, --domain

Crée un fichier journal de domaine GNU Ddrescue à partir du périphérique source. C'est un fichier lisible par l'homme dans lequel + marque les zones de blocs utilisées et ? marque les zones libres.

--offset_domain=X

Ajoute X (en octets) à toutes les positions rapportées dans le fichier journal de domaine.

--restore_raw_file

Création d'un fichier brut spécial pour le périphérique de boucle.

-L FICHIER, --logfile FICHIER

Définit un chemin spécial pour enregistrer les informations du journal de partclone. (par défaut /var/log/partclone.log)

-R, --rescue

Continue après les erreurs de lecture du disque.

-C, --no_check

Ne pas vérifier la taille du périphérique et l'espace libre.

-N, --ncurses

Utilise une interface utilisateur textuelle Ncurses.

-I, --ignore_fschk

Ignore la vérification du système de fichiers.

-i, --ignore_crc

Ignore les erreurs de vérification CRC.

-F, --force

Force la progression.

-f sec, --UI-fresh sec

Définit un intervalle en secondes pour l'actualisation de l'interface utilisateur.

-z taille, --buffer_size taille

Taille du tampon de lecture/écriture (par défaut : 1048576)

-q, --quiet

Désactive les messages de progression.

-dniveau, --debug niveau

Définit le niveau de débogage [1|2|3]

-x, --compresscmd CMD

Lance CMD comme un pipe de sortie pour compresser l'image clonée.

-aX, --checksum-mode=X

Formule de somme de contrôle à utiliser pour ajouter la détection d'erreur.

où X :

0 : Pas de somme de contrôle (pas de ralentissement, image la plus petite)

1 : CRC32 (Rapide à calculer, détection basique)

2 : xxHash, algorithme de hachage non cryptographique extrêmement rapide

-kX, --blocks-per-checksum=X

Écrit une somme de contrôle pour tous les X blocs.

-w, --skip_write_error

Continue la restauration en cas d'erreurs d'écriture.

--write-direct-io

Écrit les données sur la partition CIBLE sans cache.

--read-direct-io

Lit les données depuis la partition SOURCE sans cache.

-B, --no_block_detail

Affiche les messages de progression sans détails des blocs.

--binary-prefix

Affiche la progression avec la taille en bits (par défaut, c'est Mo, Go...).

--prog-second

Affiche la progression en secondes (par défaut, c'est en minutes).

-E, --offset=X

Ajoute un décalage X (en octets) à la SORTIE.

-T, --btfiles

Restaure le bloc sous forme de fichier pour ClonezillaBT.

-t, --btfiles_torrent

Restaure le bloc sous forme de fichier pour ClonezillaBT mais ne génère que le torrent.

-n, --note NOTE

Affiche une NOTE de message (128 mots).

-h, --help

Affiche un résumé des options.

-v, --version

Affiche la versi

partclone.ext3(8)

NAME

partclone.ext3 - clone a filesystem, or a partition

SYNOPSIS

partclone.ext3 [-d] [-c] [-s source] [-o output]

DESCRIPTION

partclone.ext3 is a tool that allows you to clone a filesystem or a partition. It works by reading the filesystem and writing the data to another location. It can be used to create disk images, clone partitions, and restore partitions from disk images.

This utility is designed to work with the ext3 filesystem, but can also be used with other filesystems that have similar structures.

OPTIONS

-c
This option specifies that the operation is a clone (copy) operation.
-d
This option enables debug mode, which will print more detailed information about the operation.
-r
This option specifies that the operation is a restore (copy back) operation.
-s source
This option specifies the source of the operation. It can be a device (e.g., /dev/hda1) or a file (e.g., hda1.img).
-o output
This option specifies the output of the operation. It can be a device (e.g., /dev/hda1) or a file (e.g., hda1.img).

When cloning, the source must be a device and the output can be a file or a device. When restoring, the source must be a file and the output must be a device.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 clone /dev/hda1 to hda1.img and display debug information.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restore /dev/hda1 from hda1.img and display debug information.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
