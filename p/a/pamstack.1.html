NOM

pamstack - empiler les plans de plusieurs images PAM en une image PAM

SYNTAXE

pamstack [-tupletype type_de_tuple] [spécification_fichiers_entrée ...]

Toutes les options peuvent être abrégées à leur préfixe unique le plus court. Vous pouvez utiliser deux tirets au lieu d'un. Vous pouvez séparer une option de sa valeur avec un espace au lieu de =.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pamstack lit plusieurs images PAM ou PNM en entrée et produit une image PAM en sortie, constituée de tous les plans (canaux) des entrées, empilés dans l'ordre spécifié.

Pour un (mais pas plus) des fichiers d'entrée, vous pouvez spécifier '-' pour indiquer l'entrée standard. Si vous ne spécifiez aucun argument, l'entrée est un fichier : l'entrée standard.

La sortie a les mêmes dimensions que les entrées, sauf que la profondeur est la somme des profondeurs des entrées. Elle a le même maxval. pamstack échoue si les entrées n'ont pas toutes la même largeur, hauteur et maxval. Le type de tuple est une chaîne nulle sauf si vous spécifiez l'option -tupletype.

pamstack fonctionne avec des flux multi-images. Il empile la 1ère image de tous les flux en une image de sortie (la première du flux de sortie), puis empile la 2ème image de tous les flux en la 2ème image du flux de sortie, et ainsi de suite, jusqu'à ce qu'un des flux soit épuisé. C'est comme une opération matricielle.

Avant Netpbm 10.32 (février 2006), pamstack ignorait toutes les images sauf la première de chaque flux d'entrée.

pamchannel fait l'inverse de pamstack : il extrait des plans individuels d'un seul PAM.

Utilisez pamtopnm(1)
pour convertir une image PAM appropriée en une image PNM plus traditionnelle (PBM, PGM ou PPM). (Mais il n'est pas nécessaire de le faire si vous allez l'alimenter à un programme Netpbm moderne - ils acceptent tous directement une entrée PAM appropriée).

Un exemple d'utilisation de pamstack est que certains programmes Netpbm acceptent en entrée un PAM qui représente une image graphique avec des informations de transparence. En prenant une image couleur par exemple, ce serait un PAM avec le type de tuple "RGB_ALPHA". Dans Netpbm, de telles images étaient traditionnellement représentées par deux images - un PPM pour la couleur et un PGM pour la transparence. Pour convertir une paire PPM/PGM en une entrée PAM (RGB_ALPHA) dont les programmes plus récents ont besoin, faites quelque chose comme ceci :


$ pamstack -tupletype=RGB_ALPHA monimage.ppm monalpha.pgm | \
      pamtouil >monimage.uil

OPTIONS

-tupletype type_de_tuple
Ceci spécifie le nom du type de tuple à enregistrer dans la sortie. Vous pouvez utiliser n'importe quelle chaîne de caractères jusqu'à 255 caractères. Certains programmes reconnaissent certains noms. Si vous omettez cette option, le nom du type de tuple par défaut est nul.

VOIR AUSSI

pamchannel(1)
