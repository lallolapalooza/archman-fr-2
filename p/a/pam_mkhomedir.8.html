NOM

pam_mkhomedir - Module PAM pour créer le répertoire personnel des utilisateurs

SYNTAXE

pam_mkhomedir.so [silent] [debug] [umask=mode] [skel=skeldir]

DESCRIPTION

Le module PAM pam_mkhomedir créera le répertoire personnel d'un utilisateur s'il n'existe pas lors du début de la session. Ceci permet aux utilisateurs d'être présents dans une base de données centrale (comme NIS, kerberos ou LDAP) sans utiliser de système de fichiers distribué ou pré-créer un grand nombre de répertoires. Le répertoire squelette (habituellement /etc/skel/) est utilisé pour copier les fichiers par défaut et définit également un masque de création pour la création.

Le nouveau répertoire personnel de l'utilisateur ne sera pas supprimé après la déconnexion de l'utilisateur.

OPTIONS

silent

Ne pas afficher de messages informatifs.

debug

Active le débogage via syslog(3).

umask=mask

Le masque de création de fichiers est défini sur mask. La valeur par défaut de mask est 0022. Si cette option n'est pas spécifiée, alors les permissions du répertoire personnel créé seront définies sur la valeur de l'élément de configuration HOME_MODE de /etc/login.defs. S'il n'y a pas d'élément de configuration de ce type, alors la valeur est calculée à partir de la valeur de UMASK dans le même fichier. S'il n'y a pas non plus d'option de configuration de ce type, la valeur par défaut de 0755 est utilisée pour le mode.

skel=/chemin/vers/le/repertoire/squelette

Indique un répertoire squelette alternatif pour remplacer le répertoire par défaut /etc/skel.

TYPES DE MODULES FOURNIS

Seul le type de module session est fourni.

VALEURS DE RETOUR

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_PERM_DENIED

Permissions insuffisantes pour créer le nouveau répertoire ou lire le répertoire squelette.

PAM_USER_UNKNOWN

Utilisateur inconnu du module d'authentification sous-jacent.

PAM_SUCCESS

Les variables d'environnement ont été définies.

FICHIERS

/etc/skel

Répertoire squelette par défaut

EXEMPLES

Un exemple de fichier /etc/pam.d/login :

  auth       requisite   pam_securetty.so
  auth       sufficient  pam_ldap.so
  auth       required    pam_unix.so
  auth       required    pam_nologin.so
  account    sufficient  pam_ldap.so
  account    required    pam_unix.so
  password   required    pam_unix.so
  session    required    pam_mkhomedir.so skel=/etc/skel/ umask=0022
  session    required    pam_unix.so
  session    optional    pam_lastlog.so
  session    optional    pam_mail.so standard

VOIR AUSSI

pam.d(5), pam(8).
