par.pl(1)

Paquet: perl-par-packer

Licences: GPL

PAR(1) Documentation Perl fournie par l'utilisateur PAR(1)

NOM

par.pl - Créer et exécuter des archives Perl

SYNTAXE

(Veuillez consulter pp pour des moyens pratiques de créer des exécutables autonomes, des scripts ou des archives PAR à partir de programmes Perl.)

Pour créer une distribution PAR à partir d'une distribution de module CPAN :

% par.pl -p                 # créer une dist PAR dans le chemin actuel
% par.pl -p Foo-0.01        # supposer une dist CPAN décompressée dans Foo-0.01/

Pour manipuler une distribution PAR :

% par.pl -i Foo-0.01-i386-freebsd-5.8.0.par # installer
% par.pl -i http://foo.com/Foo-0.01         # ajoute automatiquement le nom d'architecture + version perl
% par.pl -i cpan://AUTRIJUS/PAR-0.74        # utilise le répertoire d'auteur CPAN
% par.pl -u Foo-0.01-i386-freebsd-5.8.0.par # désinstaller
% par.pl -s Foo-0.01-i386-freebsd-5.8.0.par # signer
% par.pl -v Foo-0.01-i386-freebsd-5.8.0.par # vérifier

Pour utiliser Hello.pm à partir de ./foo.par :

% par.pl -A./foo.par -MHello
% par.pl -A./foo -MHello    # la partie .par est facultative

Même chose, mais rechercher foo.par dans @INC ;

% par.pl -Ifoo.par -MHello
% par.pl -Ifoo -MHello      # idem

Exécuter test.pl ou script/test.pl à partir de foo.par :

% par.pl foo.par test.pl    # recherche 'main.pl' par défaut,
                            # sinon exécute 'test.pl'

Pour créer un script autonome contenant un fichier PAR :

% par.pl -O./foo.pl foo.par
% ./foo.pl test.pl          # identique à ci-dessus

Pour intégrer les modules non principaux et les objets partagés nécessaires à l'exécution de PAR (comme "Zlib", "IO", "Cwd", etc.), utilisez l'indicateur -b :

% par.pl -b -O./foo.pl foo.par
% ./foo.pl test.pl          # s'exécute n'importe où avec les modules de base installés

Si vous souhaitez également intégrer les modules *principaux*, utilisez plutôt l'indicateur -B :

% par.pl -B -O./foo.pl foo.par
% ./foo.pl test.pl          # s'exécute n'importe où avec l'interpréteur perl

Ceci est particulièrement utile lors de la création d'exécutables binaires autonomes ; voir pp pour plus de détails.

DESCRIPTION

Cette commande autonome offre à peu près la même fonctionnalité que "perl -MPAR", sauf qu'elle prend les fichiers .par préchargés via "-Afoo.par" au lieu de "-MPAR=foo.par".

De plus, elle vous permet de convertir une distribution CPAN en une distribution PAR, ainsi que de manipuler ces distributions. Pour plus d'informations sur les distributions PAR, voir PAR::Dist.

Chargeur PAR binaire (parl)

Si vous disposez d'un compilateur C, ou si un paquet binaire pré-compilé de PAR est disponible pour votre plateforme, une version binaire de par.pl sera également installée automatiquement sous le nom parl. Vous pouvez l'utiliser pour exécuter des fichiers .par :

# exécute script/run.pl dans l'archive, utilise ses lib/* comme bibliothèques
% parl myapp.par run.pl     # exécute run.pl ou script/run.pl dans myapp.par
% parl otherapp.pl          # exécute également des scripts perl normaux

Cependant, si l'archive .par contient main.pl ou script/main.pl, celui-ci est utilisé à la place :

% parl myapp.par run.pl     # exécute main.pl, avec 'run.pl' comme @ARGV

Enfin, l'option "-O" crée un exécutable binaire autonome à partir d'un fichier PAR :

% parl -B -Omyapp myapp.par
% ./myapp                   # exécutez-le n'importe où sans binaires perl

Avec l'indicateur "--par-options", les binaires générés peuvent servir de "parl" pour empaqueter de nouveaux binaires :

% ./myapp --par-options -Omyap2 myapp.par   # identique à ./myapp
% ./myapp --par-options -Omyap3 myap3.par   # maintenant avec un PAR différent

Format exécutable autonome

Le format de l'exécutable autonome consiste simplement à concaténer les éléments suivants :

  • L'exécutable lui-même

    Soit en texte brut (par.pl), soit au format exécutable natif (parl ou parl.exe).

  • Tout nombre de fichiers intégrés

    Ceux-ci sont généralement utilisés pour l'amorçage des diverses dépendances XS de PAR. Chaque section contient :

La chaîne magique "FILE"
La longueur du nom de fichier au format pack('N') plus 9
8 octets de CRC32 du contenu du fichier encodé en hexadécimal
Une barre oblique ("/")
Le nom du fichier (sans chemin)
La longueur du fichier au format pack('N')
Le contenu du fichier (non compressé)
  • Un fichier PAR

    Ceci est juste un fichier zip commençant par la chaîne magique ""PK\003\004"".

  • Section de fin

    Le nom du cache pré-calculé. Une chaîne pack('Z40') de la valeur de -T (--tempcache) ou du hachage du fichier, suivie de "\0CACHE". Le hachage du fichier est calculé avec Digest::SHA.

    Un nombre pack('N') de la longueur totale des sections FILE et PAR, suivi d'une chaîne magique de 8 octets : ""\012PAR.pm\012"".
