NOM

pacsync - mettre à jour les bases de données synchronisées

SYNTAXE

pacsync [options] [<syncdb>]...
pacsync (--help|--version)

DESCRIPTION

Met à jour les bases de données synchronisées. Si aucun nom de syncdb n'est fourni, toutes les bases de données seront mises à jour.

OPTIONS

--config=chemin
Définit un chemin alternatif pour le fichier de configuration.
--dbext=extension
Définit une extension alternative pour la base de données synchronisée.
--dbpath=chemin
Définit un chemin alternatif pour la base de données.
--logfile=chemin
Définit un chemin alternatif pour le fichier journal.
--no-timeout
Désactive les délais d'attente pour les téléchargements à faible vitesse.
--root=chemin
Définit une racine d'installation alternative.
--sysroot=chemin
Définit une racine système alternative. Voir pacutils-sysroot(7).
--debug
Affiche des informations de débogage supplémentaires.
--updated
Retourne vrai uniquement si une base de données a effectivement été mise à jour.
--force
Met à jour les bases de données même si elles sont déjà à jour.
--help
Affiche les informations d'utilisation et quitte.
--version
Affiche les informations de version et quitte.
