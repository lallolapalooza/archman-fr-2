NOM

pacreport - afficher un résumé des paquets installés

SYNTAXE

pacreport [options]
pacreport (--help|--version)

DESCRIPTION

Génère un rapport des paquets installés incluant :

paquets inutiles installés explicitement
paquets inutiles installés en tant que dépendances
paquets inutiles dans une boucle de dépendances
paquets installés non présents dans un dépôt
paquets manquants de groupes spécifiés
fichiers de paquet manquants
fichiers de sauvegarde non fusionnés
fichiers sans propriétaire
tailles du répertoire de cache

Les tailles des paquets incluent les dépendances qui ne sont pas nécessaires à d'autres paquets.

Les paquets précédés d'un astérisque ("*") sont des dépendances optionnelles d'un autre paquet.

OPTIONS

--config=chemin
Définit un chemin de fichier de configuration pacman alternatif.
--dbext=extension
Définit une extension de base de données de synchronisation alternative.
--dbpath=chemin
Définit un chemin de base de données alternatif.
--root=chemin
Définit une racine d'installation alternative.
--sysroot=chemin
Définit une racine système alternative. Voir pacutils-sysroot(7).
--cachedir=chemin
Définit un chemin de répertoire de cache alternatif.
--backups
Recherche les fichiers .pac{save,orig,new}. Par défaut, /etc est parcouru et tous les fichiers de configuration connus sont vérifiés ; passer deux fois pour rechercher en dehors de /etc.
--group=nom
Affiche tous les paquets du groupe nom qui ne sont pas actuellement installés. Peut être spécifié plusieurs fois.
--missing-files
Vérifie les fichiers de paquet manquants.
--unowned-files
Vérifie les fichiers sans propriétaire. Voir /etc/pacreport.conf sous FILES pour plus d'informations.
--optional-for
Indique quels paquets dépendent optionnellement des paquets listés.
--optional-deps
Prend en compte les dépendances optionnelles lors de l'énumération des paquets inutiles et des boucles de dépendances.
--help
Affiche les informations d'utilisation et quitte.
--version
Affiche les informations de version et quitte.

FICHIERS

/etc/pacreport.conf
Fichier de configuration de style INI listant les chemins à ignorer lors de l'exécution avec --unowned-files. Les chemins qui doivent toujours être ignorés peuvent être spécifiés avec "IgnoreUnowned" dans la section "Options". Les chemins qui ne doivent être ignorés que si un paquet particulier est installé peuvent être listés sous la section "PkgIgnoreUnowned" en utilisant le nom du paquet comme nom d'option et le chemin à ignorer comme valeur. Toutes les options peuvent être spécifiées plusieurs fois. Les chemins peuvent inclure des jokers de style shell. La racine d'installation ne doit pas être incluse dans les chemins. 
[Options]
IgnoreUnowned = home/*
IgnoreUnowned = proc/*
IgnoreUnowned = mnt/*
[PkgIgnoreUnowned]
linux = boot/initramfs-linux.img
linux = boot/initramfs-linux-fallback.img
