PARTCLONE(8) Manuel utilisateur de Partclone PARTCLONE(8)

NOM

partclone - L'utilitaire pour cloner et restaurer une partition.

SYNTAXE

partclone.[fstype] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] cible} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] fichier_journal [-R | --rescue] [-L | --logfile] fichier_journal [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

DESCRIPTION

partclone.[fstype] fait partie du projet Partclone. Partclone fournit des utilitaires pour sauvegarder les blocs utilisés et est conçu pour une compatibilité accrue du système de fichiers en utilisant des bibliothèques existantes, par exemple, e2fslibs est utilisé pour lire le bloc utilisé d'une partition ext2.

Le système de fichiers pris en charge par Partclone comprend btrfs, ext2, ext3, ext4, reiserfs, reiser4, xfs et jfs pour LINUX. Il prend également en charge certains systèmes d'exploitation non-linux, par exemple : NTFS, FAT et EXFAT (pour Windows), HFS plus (MAC OS d'APPLE), UFS2 (FreeBSD), VMFS (VMWare Vsphere) et MINIX (MINIX3).

Tous les utilitaires partclone peuvent être exécutés comme partclone.[fstype], ce qui est très similaire à fsck ou mkfs. Par exemple, pour sauvegarder/restaurer hfsplus, exécutez simplement partclone.hfsp

       Système de fichiers                 partclone.[fstype]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       autres (FS non pris en charge)   partclone.imager

OPTIONS

Le programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-'). Un résumé des options est inclus ci-dessous.

-s FICHIER, --source FICHIER

FICHIER source. Le FICHIER peut être un fichier image (créé par partclone) ou un périphérique en fonction de votre action. Normalement, la source de sauvegarde est un périphérique, la source de restauration est un fichier image.

La réception de données depuis un pipeline n'est prise en charge QUE pour la restauration, ignorez simplement l'option -s ou utilisez '-' pour recevoir des données depuis stdin.

-o FICHIER, --output FICHIER

FICHIER de sortie. Le FICHIER peut être un fichier image (partclone générera) ou un périphérique en fonction de votre action. Normalement, la sauvegarde sort vers un fichier image et la restauration sort vers un périphérique.

L'envoi de données vers un pipeline est également pris en charge UNIQUEMENT pour la sauvegarde, ignorez simplement l'option -o ou utilisez '-' pour envoyer des données vers stdout.

-O FICHIER, --overwrite FICHIER

Écrase FICHIER, en écrasant s'il existe.

-W FICHIER, --restore_raw_file FICHIER

Crée un fichier brut spécial pour le périphérique de boucle.

-c, --clone

Enregistrer la partition au format d'image spécial.

-r, --restore

Restaurer la partition depuis le format d'image spécial.

-b, --dev-to-dev

Copie locale de périphérique à périphérique à la volée, la source et la sortie sont toutes deux des périphériques.

-D, --domain

Crée un fichier journal de domaine GNU Ddrescue à partir du périphérique source. C'est un fichier lisible par l'homme dans lequel + marque les zones de blocs utilisées et ? marque les zones libres.

--offset_domain=X

Ajoute X (en octets) à toutes les positions signalées dans le fichier journal de domaine

--restore_raw_file

Création d'un fichier brut spécial pour le périphérique de boucle.

-L FICHIER, --logfile FICHIER

Spécifie le chemin pour enregistrer les informations du journal partclone. (par défaut /var/log/partclone.log)

-R, --rescue

Continue après les erreurs de lecture du disque.

-C, --no_check

Ne pas vérifier la taille du périphérique et l'espace libre.

-N, --ncurses

Utilise l'interface utilisateur textuelle Ncurses.

-I, --ignore_fschk

Ignore la vérification du système de fichiers.

-i, --ignore_crc

Ignore les erreurs de vérification CRC.

-F, --force

Force la progression.

-f sec, --UI-fresh sec

Spécifie l'intervalle en secondes pour l'actualisation.

-z taille, --buffer_size taille

Taille du tampon de lecture/écriture (par défaut : 1048576)

-q, --quiet

Désactive les messages de progression.

-dniveau, --debug niveau

Définit le niveau de débogage [1|2|3]

-x, --compresscmd CMD

Démarre CMD comme un tuyau de sortie pour compresser l'image clonée

-aX, --checksum-mode=X

Formule de somme de contrôle à utiliser pour ajouter la détection d'erreurs

où X :

0 : Pas de somme de contrôle (pas de ralentissement, image la plus petite)

1 : CRC32 (Calcul rapide, détection de base)

2 : xxHash, un algorithme de hachage non cryptographique extrêmement rapide

-kX, --blocks-per-checksum=X

Écrit une somme de contrôle tous les X blocs

-w, --skip_write_error

Continue la restauration en cas d'erreurs d'écriture

--write-direct-io

Écrit les données sur la partition CIBLE sans cache

--read-direct-io

Lit les données depuis la partition SOURCE sans cache

-B, --no_block_detail

Affiche le message de progression sans détails sur les blocs

--binary-prefix

Affiche la progression avec la taille en bits (par défaut, c'est en Mo, Go...)

--prog-second

Affiche la progression en secondes (par défaut, c'est en minutes)

-E, --offset=X

Ajoute un décalage X (en octets) à la SORTIE

-T, --btfiles

Restaure le bloc sous forme de fichier pour ClonezillaBT.

-t, --btfiles_torrent

Restaure le bloc sous forme de fichier pour ClonezillaBT mais ne génère que le torrent.

-n, --note NOTE

Affiche une note de message (128 mots).

-h, --help

Affiche un résumé des options.

-v, --version

Affiche la vers

partclone.fat12(8) — partclone

NAME

partclone.fat12 — clone FAT12 filesystem

SYNOPSIS

partclone.fat12 [-c|-r] [-d] [-s source] [-o destination]

DESCRIPTION

partclone.fat12 is used to clone FAT12 filesystem. It can clone the filesystem from a device to a file, or restore it from a file to a device. It is part of the partclone package.

The options -c and -r are mutually exclusive.

-c, --clone

Clone the filesystem from source to destination.

-r, --restore

Restore the filesystem from source to destination.

-d, --debug

Enable debug messages.

-s, --source source

Specify the source. It can be a device file (e.g. /dev/sda1) or a file name.

-o, --output destination

Specify the destination. It can be a device file (e.g. /dev/sda1) or a file name.

-z, --ncompression

Disable compression.

-v, --verbose

Display verbose information.

-h, --help

Show help message and exit.

-V, --version

Show program version and exit.

Note: When restoring a filesystem, the destination partition must be at least as large as the original partition. If you want to restore to a smaller partition, you will need to resize the filesystem after restoring. Also, the partclone tool can only save the used space of the filesystem. The unused blocks will be ignored.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 Clone /dev/sda1 to sda1.img and display debug information.
   partclone.fat12 -c -d -s /dev/sda1 -o sda1.img

 Restore /dev/sda1 from sda1.img and display debug information.
   partclone.fat12 -r -d -s sda1.img -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
