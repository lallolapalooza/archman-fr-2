NOM

pam_authenticate - authentification de compte

SYNTAXE

#include <security/pam_appl.h>

int pam_authenticate(pam_handle_t *pamh, int flags);

DESCRIPTION

La fonction pam_authenticate est utilisée pour authentifier l'utilisateur. L'utilisateur doit fournir un jeton d'authentification en fonction du service d'authentification, il s'agit généralement d'un mot de passe, mais cela peut aussi être une empreinte digitale.

Le module de service PAM peut demander à l'utilisateur de saisir son nom d'utilisateur via le mécanisme de conversation (voir pam_start(3) et pam_conv(3)). Le nom de l'utilisateur authentifié sera présent dans l'élément PAM PAM_USER. Cet élément peut être récupéré par un appel à pam_get_item(3).

L'argument pamh est un handle d'authentification obtenu par un appel antérieur à pam_start(). L'argument flags est l'OR binaire de zéro ou plusieurs des valeurs suivantes :

PAM_SILENT

Ne pas émettre de messages.

PAM_DISALLOW_NULL_AUTHTOK

Le service du module PAM doit retourner PAM_AUTH_ERR si l'utilisateur n'a pas de jeton d'authentification enregistré.

VALEURS DE RETOUR

PAM_ABORT

L'application doit se terminer immédiatement après avoir d'abord appelé pam_end(3).

PAM_AUTH_ERR

L'utilisateur n'a pas été authentifié.

PAM_CRED_INSUFFICIENT

Pour une raison quelconque, l'application ne dispose pas des informations d'identification suffisantes pour authentifier l'utilisateur.

PAM_AUTHINFO_UNAVAIL

Les modules n'ont pas pu accéder aux informations d'authentification. Cela pourrait être dû à une défaillance réseau ou matérielle, etc.

PAM_MAXTRIES

Un ou plusieurs des modules d'authentification ont atteint leur limite d'essais pour authentifier l'utilisateur. N'essayez pas à nouveau.

PAM_SUCCESS

L'utilisateur a été authentifié avec succès.

PAM_USER_UNKNOWN

Utilisateur inconnu du service d'authentification.

VOIR AUSSI

pam_start(3), pam_setcred(3), pam_chauthtok(3), pam_strerror(3), pam(8)
