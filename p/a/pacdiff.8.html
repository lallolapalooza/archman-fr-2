NOM

pacdiff - utilitaire de maintenance pour les fichiers pacorig, pacnew et pacsave

SYNTAXE

pacdiff [options]

DESCRIPTION

pacdiff est un script qui recherche les fichiers pacorig, pacnew et pacsave à partir des entrées de sauvegarde trouvées dans la base de données pacman locale. Pour chaque fichier trouvé, une option est proposée pour visualiser, fusionner, ignorer, comparer, supprimer ou écraser le fichier pacorig, pacnew ou pacsave trouvé.

OPTIONS

Options de recherche

-f, --find

Analyse en utilisant find.

-l, --locate

Analyse en utilisant locate.

-p, --pacmandb

Analyse les fichiers de configuration actifs de la base de données pacman. (par défaut)

Options générales

-b, --backup

Lors de l'écrasement, sauvegarde les anciens fichiers avec l'extension .bak.

-c, --cachedir <dir>

Analyse dir à la place du cache pacman pour les candidats de base de fusion à 3 voies.

-h, --help

Affiche la syntaxe et les options de ligne de commande.

--nocolor

Ne pas coloriser la sortie.

-o, --output

Affiche les fichiers au lieu de les fusionner.

-s, --sudo

Utilise sudo et sudoedit pour fusionner/supprimer des fichiers.

-3, --threeway

Affiche les différences de manière à 3 voies si le paquet de base est disponible dans le cache. Reviens à une comparaison normale à 2 voies sinon.

-V, --version

Affiche les informations de version.

ENVIRONNEMENT

DIFFPROG

Remplace le programme de différence par défaut vim -d, ou nvim -d si EDITOR=nvim.

DIFFSEARCHPATH

Remplace le chemin de recherche par défaut /etc, uniquement lors de l'utilisation de find.

MERGEPROG

Remplace le programme de fusion à 3 voies par défaut diff3 -m. Une alternative possible est git merge-file -p.

VOIR AUSSI

pacman(8), pacman.conf(5)

BOGUES

Des bogues ? Vous plaisantez ; il n'y a pas de bogues dans ce logiciel. Mais si nous nous trompions, déposez un ticket avec autant de détails que possible sur https://gitlab.archlinux.org/pacman/pacman-contrib/-/issues/new.
