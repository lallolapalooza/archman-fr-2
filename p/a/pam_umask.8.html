NOM

pam_umask - Module PAM pour définir le masque de création de mode de fichier

SYNTAXE

pam_umask.so [debug] [silent] [usergroups] [nousergroups] [umask=masque]

DESCRIPTION

pam_umask est un module PAM pour définir le masque de création de mode de fichier de l'environnement courant. L'umask affecte les permissions par défaut assignées aux nouveaux fichiers créés.

Le module PAM essaie d'obtenir la valeur de l'umask aux endroits suivants, dans l'ordre :

•Entrée umask= dans le champ GECOS de l'utilisateur (voir ci-dessous pour les détails)
•Argument umask=
•Entrée UMASK de /etc/login.defs
•Entrée UMASK= de /etc/default/login

Le champ GECOS est divisé par des caractères virgule ','. Les entrées doivent être définies dans son champ 'other' (sous-champ), ce qui peut être fait, par exemple, en utilisant chfn --other. En plus de l'entrée umask=, le module reconnaît également l'entrée pri=, qui définit la valeur de priorité nice pour la session, et l'entrée ulimit=, qui définit la taille maximale des fichiers que les processus de la session peuvent créer.

OPTIONS

debug

Affiche les informations de débogage.

silent

N'affiche pas les messages informatifs.

usergroups

Si l'utilisateur n'est pas root et que le nom d'utilisateur est identique au nom du groupe primaire, les bits de groupe de l'umask sont définis pour être identiques aux bits du propriétaire (exemples : 022 -> 002, 077 -> 007).

nousergroups

C'est l'exact opposé de l'option usergroups décrite ci-dessus, ce qui peut être utile si pam_umask a été compilé avec usergroups activé par défaut et que vous souhaitez le désactiver à l'exécution.

umask=masque

Définit l'umask (masque de création de mode de fichier) du processus appelant à masque & 0777. La valeur est interprétée comme Octale.

TYPES DE MODULES FOURNIS

Seul le type session est fourni.

VALEURS DE RETOUR

PAM_SUCCESS

La nouvelle umask a été définie avec succès.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_CONV_ERR

La méthode de conversation fournie par l'application n'a pas réussi à obtenir le nom d'utilisateur.

PAM_INCOMPLETE

La méthode de conversation fournie par l'application a renvoyé PAM_CONV_AGAIN.

PAM_SERVICE_ERR

Aucun nom d'utilisateur n'a été fourni.

PAM_USER_UNKNOWN

Utilisateur inconnu.

EXEMPLES

Ajoutez la ligne suivante à /etc/pam.d/login pour définir l'umask spécifique à l'utilisateur lors de la connexion :

        session optional pam_umask.so umask=0022

VOIR AUSSI
