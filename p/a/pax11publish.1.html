pax11publish(1) Manuel des commandes générales pax11publish(1)

NOM

pax11publish - Utilitaire de credentials PulseAudio X11

SYNTAXE

pax11publish -h

pax11publish [options] [-d]

pax11publish [options] -e

pax11publish [options] -i

pax11publish [options] -r

DESCRIPTION

L'utilitaire pax11publish peut être utilisé pour exporter ou manipuler les credentials du serveur PulseAudio qui peuvent être stockés comme propriétés sur la fenêtre racine X11.

Veuillez noter que le module chargeable module-x11-publish exporte les mêmes informations directement depuis le serveur sonore PulseAudio, et devrait dans la plupart des cas être utilisé de préférence à cet outil.

Utilisez la commande suivante pour exporter les données brutes spécifiques à PulseAudio qui sont stockées dans votre fenêtre racine X11 :

xprop -root | grep ^PULSE_

OPTIONS

-h
Affiche l'aide.
-d
Lit les credentials du serveur PulseAudio actuellement définis sur la fenêtre racine X11 et les affiche sous une forme lisible par l'homme. Ceci lit les propriétés PULSE_SERVER, PULSE_SINK, PULSE_SOURCE et PULSE_COOKIE.
-i
Similaire à -d, cependant, les affiche dans un format compatible avec le shell Bourne afin qu'ils puissent être utilisés conjointement avec la commande shell eval pour définir les variables d'environnement $PULSE_SERVER, $PULSE_SINK, $PULSE_SOURCE. Lit également le cookie d'authentification depuis la fenêtre racine et le stocke dans ~/.config/pulse/cookie.
-e
Exporte le serveur sonore, le sink, la source de configuration actuellement utilisés localement vers la fenêtre racine X11. Ceci prend les données des variables d'environnement $PULSE_SERVER, $PULSE_SINK, $PULSE_SOURCE et les combine avec les données de ~/.config/pulse/client.conf (ou /etc/pulse/client.conf si ce fichier n'existe pas). Si des options spécifiques sont passées en ligne de commande (-S, -O, -I, -c, voir ci-dessous), elles ont la priorité. Télécharge également le cookie d'authentification local ~/.config/pulse/cookie vers le serveur X11.
-r
Supprime la configuration PulseAudio configurée de la fenêtre racine X11.
-D DISPLAY
Se connecte à l'affichage X11 spécifié, au lieu de celui par défaut configuré dans $DISPLAY.
-S SERVER
Uniquement valide pour -e : exporte le serveur PulseAudio spécifié comme défaut vers l'affichage X11 au lieu de celui configuré via la configuration locale.
-O SINK
Uniquement valide pour -e : exporte le sink spécifié comme sink par défaut vers l'affichage X11 au lieu de celui configuré via la configuration locale.
-I SOURCE
Uniquement valide pour -e : exporte la source spécifiée comme source par défaut vers l'affichage X11 au lieu de celle configurée via la configuration locale.
-c FILE
Uniquement valide pour -e : exporte le cookie d'authentification PulseAudio stocké dans le fichier spécifié vers l'affichage X11 au lieu de celui stocké dans ~/.config/pulse/cookie.

AUTEURS

Les développeurs de PulseAudio <pulseaudio-discuss (at) lists (dot) freedesktop (dot) org>; PulseAudio est disponible sur http://pulseaudio.org/
