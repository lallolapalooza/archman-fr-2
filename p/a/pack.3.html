LIBPACK(3) Manuel des fonctions de bibliothèque LIBPACK(3)

NOM

libpack - prise en charge des composantes connexes

SYNTAXE

#include <graphviz/pack.h>
typedef enum { l_clust, l_node, l_graph, l_array} pack_mode;
typedef struct {
	float aspect;		 /* ratio d'aspect souhaité */
	int sz;			     /* taille de ligne/colonne */
	unsigned int margin; /* marge laissée autour des objets, en points */
	int doSplines;		 /* utiliser des splines dans la construction de la forme du graphe */
	pack_mode mode;		 /* granularité et méthode */
	boolean *fixed;		 /* fixed[i] == true implique que g[i] ne doit pas être déplacé */
	packval_t* vals;	 /* pour les tableaux, nombres de tri */
	int flags;       
} pack_info;
point*     putRects(int ng, boxf* bbs, pack_info* pinfo);
int        packRects(int ng, boxf* bbs, pack_info* pinfo);
point*     putGraphs (int, Agraph_t**, Agraph_t*, pack_info*);
int        packGraphs (int, Agraph_t**, Agraph_t*, pack_info*);
int        packSubgraphs (int, Agraph_t**, Agraph_t*, pack_info*);
pack_mode  getPackMode (Agraph_t*, pack_mode dflt);
int        getPack (Agraph_t*, int, int);
int        isConnected (Agraph_t*);
Agraph_t** ccomps (Agraph_t*, int*, char*);
Agraph_t** pccomps (Agraph_t*, int*, char*, boolean*);
int        nodeInduce (Agraph_t*);

DESCRIPTION

libpack prend en charge l'utilisation des composantes connexes dans le contexte de la disposition des graphes à l'aide d'autres bibliothèques graphviz. Un ensemble de fonctions peut être utilisé pour prendre un unique graphe et le diviser en composantes connexes. Un ensemble complémentaire de fonctions prend une collection de graphes (pas nécessairement des composantes d'un seul graphe) qui ont été disposés séparément, et les compacte ensemble.

Comme cette bibliothèque est destinée à être utilisée avec libcommon, elle repose sur Agraphinfo_t, Agnodeinfo_t et Agedgeinfo_t utilisés dans cette bibliothèque. Les dépendances spécifiques sont données ci-dessous dans les descriptions des fonctions.

Création des composantes

Agraph_t** ccomps (Agraph_t* g, int* cnt, char* pfx)

La fonction ccomps prend un graphe g et retourne un tableau de pointeurs vers des sous-graphes de g qui sont ses composantes connexes. cnt est défini au nombre de composantes. Si pfx n'est pas NUL, il est utilisé comme préfixe pour les noms des sous-graphes ; sinon, la chaîne ``_cc_'' est utilisée. Notez que les sous-graphes ne contiennent que les nœuds pertinents, et non les arêtes correspondantes. Selon l'utilisation, cela permet à l'appelant de récupérer les informations d'arête du graphe racine.

Le tableau retourné est obtenu à partir de malloc et doit être libéré par l'appelant. La fonction repose sur le champ mark dans Agnodeinfo_t.

Agraph_t** pccomps (Agraph_t* g, int* cnt, char* pfx, boolean* pinned)

Ceci est identique à ccomps sauf qu'il place tous les nœuds épinglés dans la première composante retournée. De plus, si pinned n'est pas NUL, il est défini sur vrai si des nœuds épinglés sont trouvés et faux sinon.

int nodeInduce (Agraph_t* g)

Cette fonction prend un sous-graphe g et trouve toutes les arêtes dans son graphe racine dont les deux extrémités sont dans g. Elle retourne le nombre de ces arêtes et, si cette arête n'est pas déjà dans le sous-graphe, elle est ajoutée.

int isConnected (Agraph_t* g)

Cette fonction retourne une valeur non nulle si le graphe g est connecté.

Compactage des composantes

point* putGraphs (int ng, Agraph_t** gs, Agraph_t* root, pack_info ip)

putGraphs compacte une collection de graphes disposés en une unique disposition qui évite tout chevauchement. Elle prend en entrée ng graphes gs. Pour chaque graphe, on suppose que tous les nœuds ont été positionnés en utilisant pos, et que les champs xsize et ysize ont été définis.

Si root n'est pas NUL, il est considéré comme le graphe racine des sous-graphes gs et est utilisé pour trouver les arêtes. Sinon, putGraphs utilise les arêtes trouvées dans chaque graphe gs[i].

Pour les modes l_node, l_clust et l_graph, le compactage est effectué à l'aide de l'algorithme basé sur les polyominos de Freivalds et al. Cela permet un compactage assez serré, où une partie convexe d'un graphe peut être insérée dans la partie concave d'un autre. La granularité des polyominos utilisés dépend de la valeur de ip->mode. Si c'est l_node, un polyomino est construit pour approximer les nœuds et les arêtes. Si c'est l_clust, le polyomino traite les clusters de premier niveau comme des rectangles uniques, union des polyominos pour les nœuds et arêtes restants. Si la valeur est l_graph, le polyomino d'un graphe est un rectangle unique correspondant à la boîte englobante du graphe.

Le mode l_node spécifie que les graphes doivent être compactés en tant que tableau.

Si ip->doSplines est vrai, la fonction utilise les informations de spline dans le champ spl d'une arête, si elles existent. Sinon, l'algorithme représente une arête comme un segment de ligne droite reliant les centres des nœuds.

Le paramètre ip->margin spécifie une bordure de margin points à laisser autour de chaque nœud. Il doit être non négatif.

Le paramètre ip->fixed, s'il n'est pas nul, doit pointer vers un tableau de ng booléens. Si ip->fixed[i] est vrai, le graphe gs[i] doit rester à sa position d'origine. Le compactage placera d'abord tous les graphes fixes, puis remplira avec les graphes restants.

La fonction retourne un tableau de points qui peuvent être utilisés comme origine de la boîte englobante de chaque graphe. Si les graphes sont traduits vers ces positions, aucun des composants du graphe ne se chevauchera. Le tableau retourné est obtenu à partir de malloc et doit être libéré par l'appelant. En cas de problème, putGraphs retourne NUL. Par effet secondaire, au début, putGraphs définit le bb de chaque graphe pour refléter sa disposition initiale. Notez que putGraphs ne fait aucune traduction ni ne modifie les graphes d'entrée d'aucune autre manière que la définition du bb.

Cette fonction utilise le champ bb dans Agraphinfo_t, les champs pos, xsize et ysize dans nodehinfo_t et le champ spl dans Aedgeinfo_t.

int packGraphs (int ng, Agraph_t** gs, Agraph_t* root, pack_info* ip)

Cette fonction prend ng sous-graphes gs d'un graphe racine root et appelle putGraphs avec les arguments donnés pour générer un compactage des sous-graphes. En cas de succès, elle invoque ensuite le déplacement des sous-graphes vers leurs nouvelles positions. Elle retourne 0 en cas de succès.

int packSubgraphs (int ng, Agraph_t** gs, Agraph_t* root, pack_info* ip)

Cette fonction appelle simplement packGraphs avec les arguments donnés, puis recalcule la boîte englobante du graphe root.

int pack_graph(int ng, Agraph_t** gs, Agraph_t* root, boolean* fixed)

utilise packSubgraphs pour placer les sous-graphes individuels dans une disposition unique avec les paramètres obtenus à partir de getPackInfo. En cas de succès, dotneato_postprocess est appelé sur le graphe racine.

point* putRects (int ng, boxf* bbs, pack_info* ip)

NOM

pack - Fonction de mise en page de rectangles

SYNTAXIS

int packRects (int ng, boxf* bbs, pack_info* ip)

pack_mode parsePackModeInfo (char* p, pack_mode dflt, pack_info* pinfo)

pack_mode getPackModeInfo (Agraph_t* g, pack_mode dflt, pack_info* pinfo)

pack_mode getPackMode (Agraph_t* g, pack_mode dflt)

int getPack (Agraph_t* g, int not_def, int dflt)

pack_mode getPackInfo (Agraph_t* g, pack_mode dflt, int dfltMargin, pack_info* pinfo)

DESCRIPTION

putRects empaquette une collection de rectangles en une seule disposition qui évite tout chevauchement. Il prend en entrée ng rectangles bbs.

Son comportement et sa valeur de retour sont analogues à ceux de putGraphs. Cependant, les modes l_node et l_clust sont illégaux. Les champs fixed et doSplines de ip ne sont pas utilisés.

int packRects (int ng, boxf* bbs, pack_info* ip)

packRects est analogue à packGraphs: il appelle putRects et, si cela réussit, il traduit les rectangles dans bbs de manière appropriée.

Fonctions utilitaires

La bibliothèque fournit plusieurs fonctions qui peuvent être utilisées pour adapter la mise en page en fonction des attributs du graphe.

pack_mode parsePackModeInfo(char* p, pack_mode dflt, pack_info* pinfo)

analyse p comme une représentation textuelle du mode de mise en page, stockant les informations dans pinfo. Si p est "cluster", il renvoie l_clust ; pour "graph", il renvoie l_graph ; pour "node", il renvoie l_node ; pour "array", il renvoie l_array ; pour "aspect", il renvoie l_aspect ; sinon, il renvoie dflt. Les données associées sont également stockées dans pinfo.

pack_mode getPackModeInfo(Agraph_t * g, pack_mode dflt, pack_info* pinfo)

Cette fonction traite l'attribut "packmode" du graphe, stockant les informations dans pinfo. Elle renvoie pinfo->mode. L'attribut est traité en utilisant parsePackModeInfo avec dflt passé comme argument par défaut.

pack_mode getPackMode (Agraph_t* g, pack_mode dflt)

Cette fonction renvoie un pack_mode associé à g.

int getPack (Agraph_t* g, int not_def, int dflt)

Cette fonction interroge l'attribut de graphe "pack". S'il est défini comme un entier non négatif, l'entier est renvoyé ; s'il est défini comme "true", la valeur dflt est renvoyée ; sinon, la valeur not_def est renvoyée.

pack_mode getPackInfo(Agraph_t * g, pack_mode dflt, int dfltMargin, pack_info* pinfo)

Cette fonction appelle à la fois getPackModeInfo et getPack, stockant les informations dans pinfo. dfltMargin est utilisé pour les deux arguments entiers de getPack, le résultat étant sauvegardé sous pinfo->margin. Elle renvoie pinfo->mode.

BOGUES
