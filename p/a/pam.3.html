NOM

pam - Bibliothèque des modules d'authentification enfichables

SYNTAXE

#include <security/pam_appl.h>
#include <security/pam_modules.h>
#include <security/pam_ext.h>

DESCRIPTION

PAM est un système de bibliothèques qui gèrent les tâches d'authentification des applications (services) sur le système. La bibliothèque fournit une interface de programmation d'applications (API) générale et stable que les programmes d'octroi de privilèges (tels que login(1) et su(1)) utilisent pour déléguer l'accomplissement des tâches d'authentification standard.

Initialisation et nettoyage

La fonction pam_start(3) crée le contexte PAM et initialise la transaction PAM. C'est la première des fonctions PAM qui doit être appelée par une application. L'état de la transaction est entièrement contenu dans la structure identifiée par ce handle, il est donc possible d'avoir plusieurs transactions en parallèle. Cependant, il n'est pas possible d'utiliser le même handle pour différentes transactions ; un nouveau handle est nécessaire pour chaque nouveau contexte.

La fonction pam_end(3) termine la transaction PAM et est la dernière fonction qu'une application doit appeler dans le contexte PAM. Après le retour de cette fonction, le handle pamh n'est plus valide et toute la mémoire associée sera invalide. Elle peut être appelée à tout moment pour terminer une transaction PAM.

Authentification

La fonction pam_authenticate(3) est utilisée pour authentifier l'utilisateur. L'utilisateur est tenu de fournir un jeton d'authentification en fonction du service d'authentification ; il s'agit généralement d'un mot de passe, mais cela pourrait aussi être une empreinte digitale.

La fonction pam_setcred(3) gère les informations d'identification de l'utilisateur.

Gestion de compte

La fonction pam_acct_mgmt(3) est utilisée pour déterminer si le compte de l'utilisateur est valide. Elle vérifie l'expiration du jeton d'authentification et du compte, et valide les restrictions d'accès. Elle est généralement appelée après que l'utilisateur a été authentifié.

Gestion des mots de passe

La fonction pam_chauthtok(3) est utilisée pour modifier le jeton d'authentification d'un utilisateur donné, sur demande ou parce que le jeton a expiré.

Gestion de session

La fonction pam_open_session(3) configure une session utilisateur pour un utilisateur précédemment authentifié avec succès. La session doit être ultérieurement terminée par un appel à pam_close_session(3).

Conversation

La bibliothèque PAM utilise un rappel défini par l'application pour permettre une communication directe entre un module chargé et l'application. Ce rappel est spécifié par la structure struct pam_conv passée à pam_start(3) au début de la transaction. Voir pam_conv(3) pour plus de détails.

Objets de données

Les fonctions pam_set_item(3) et pam_get_item(3) permettent aux applications et aux modules de service PAM de définir et de récupérer des informations PAM.

La fonction pam_get_user(3) est la méthode privilégiée pour obtenir le nom d'utilisateur.

Les fonctions pam_set_data(3) et pam_get_data(3) permettent aux modules de service PAM de définir et de récupérer des données de forme libre d'une invocation à l'autre.

Gestion de l'environnement et des erreurs

Les fonctions pam_putenv(3), pam_getenv(3) et pam_getenvlist(3) servent à maintenir un ensemble de variables d'environnement privées.

La fonction pam_strerror(3) renvoie un pointeur vers une chaîne décrivant le code d'erreur PAM donné.

VALEURS DE RETOUR

Les codes de retour suivants sont connus de PAM :

PAM_ABORT

Erreur critique, abandon immédiat.

PAM_ACCT_EXPIRED

Le compte de l'utilisateur a expiré.

PAM_AUTHINFO_UNAVAIL

Le service d'authentification ne peut pas récupérer les informations d'authentification.

PAM_AUTHTOK_DISABLE_AGING

La vieillissement du jeton d'authentification est désactivé.

PAM_AUTHTOK_ERR

Erreur de manipulation du jeton d'authentification.

PAM_AUTHTOK_EXPIRED

Le jeton d'authentification a expiré.

PAM_AUTHTOK_LOCK_BUSY

Le verrouillage du jeton d'authentification est occupé.

PAM_AUTHTOK_RECOVERY_ERR

Les informations d'authentification ne peuvent pas être récupérées.

PAM_AUTH_ERR

Échec de l'authentification.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_CONV_ERR

Erreur de conversation.

PAM_CRED_ERR

Échec de la définition des informations d'identification de l'utilisateur.

PAM_CRED_EXPIRED

Les informations d'identification de l'utilisateur ont expiré.

PAM_CRED_INSUFFICIENT

Informations d'identification insuffisantes pour accéder aux données d'authentification.

PAM_CRED_UNAVAIL

Le service d'authentification ne peut pas récupérer les informations d'identification de l'utilisateur.

PAM_IGNORE

La valeur de retour doit être ignorée par la distribution PAM.

PAM_MAXTRIES

Nombre maximal de tentatives pour le service épuisé.

PAM_MODULE_UNKNOWN

Module inconnu.

PAM_NEW_AUTHTOK_REQD

Le jeton d'authentification n'est plus valide ; un nouveau est requis.

PAM_NO_MODULE_DATA

Aucune donnée spécifique au module n'est présente.

PAM_OPEN_ERR

Échec du chargement du module.

PAM_PERM_DENIED

Accès refusé.

PAM_SERVICE_ERR

Erreur dans le module de service.

PAM_SESSION_ERR

Impossible de créer/supprimer une entrée pour la session spécifiée.

PAM_SUCCESS

Succès.

PAM_SYMBOL_ERR

Symbole introuvable.

PAM_SYSTEM_ERR

Erreur système.

PAM_TRY_AGAIN

Échec de la vérification préliminaire par le service de mot de passe.

PAM_USER_UNKNOWN

Utilisateur inconnu du module d'authentification sous-jacent.

VOIR AUSSI

NOTES

Les interfaces libpam ne sont thread-safe que si chaque thread au sein de l'application multithread utilise son propre descripteur PAM.
