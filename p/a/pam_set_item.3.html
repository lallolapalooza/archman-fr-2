PAM_SET_ITEM(3) Manuel Linux-PAM PAM_SET_ITEM(3)

NOM

pam_set_item - définir et mettre à jour les informations PAM

SYNTAXE

#include <security/pam_modules.h>

int pam_set_item(pam_handle_t *pamh, int item_type, const void *item);

DESCRIPTION

La fonction pam_set_item permet aux applications et aux modules de service PAM d'accéder et de mettre à jour les informations PAM de type item_type. Pour ce faire, une copie de l'objet pointé par l'argument item est créée. Les item_types suivants sont pris en charge :

PAM_SERVICE

Le nom du service (qui identifie la pile PAM que les fonctions PAM utiliseront pour authentifier le programme).

PAM_USER

Le nom d'utilisateur de l'entité sous l'identité de laquelle le service sera fourni. Autrement dit, après authentification, PAM_USER identifie l'entité locale qui obtient l'accès au service. Notez que cette valeur peut être mappée de quelque chose (par exemple, « anonymous ») à quelque chose d'autre (par exemple, « guest119 ») par n'importe quel module de la pile PAM. Ainsi, une application doit vérifier la valeur de PAM_USER après chaque appel à une fonction PAM.

PAM_USER_PROMPT

La chaîne de caractères utilisée lors de la demande du nom d'utilisateur. La valeur par défaut de cette chaîne est une version localisée de « login: ».

PAM_TTY

Le nom du terminal préfixé par /dev/ pour les fichiers d'appareils. Dans le passé, les applications basées sur X graphique utilisaient pour stocker la variable $DISPLAY ici, mais avec l'introduction de PAM_XDISPLAY, cette utilisation est dépréciée.

PAM_RUSER

Le nom d'utilisateur demandeur : nom local pour un utilisateur demandeur local ou nom d'utilisateur distant pour un utilisateur demandeur distant.

En général, une application ou un module tentera de fournir la valeur la plus fortement authentifiée (un compte local avant un compte distant). Le niveau de confiance accordé à cette valeur est incarné dans la pile d'authentification réelle associée à l'application, donc c'est en fin de compte à la discrétion de l'administrateur système.

PAM_RUSER@PAM_RHOST doit toujours identifier l'utilisateur demandeur. Dans certains cas, PAM_RUSER peut être NULL. Dans de telles situations, il n'est pas clair qui est l'entité demanderesse.

PAM_RHOST

Le nom d'hôte demandeur (le nom d'hôte de la machine à partir de laquelle l'entité PAM_RUSER demande le service). C'est-à-dire que PAM_RUSER@PAM_RHOST identifie l'utilisateur demandeur. Dans certaines applications, PAM_RHOST peut être NULL. Dans de telles situations, il n'est pas clair d'où provient la demande d'authentification.

PAM_AUTHTOK

Le jeton d'authentification (souvent un mot de passe). Ce jeton doit être ignoré par toutes les fonctions de module autres que pam_sm_authenticate(3) et pam_sm_chauthtok(3). Dans la première fonction, il est utilisé pour passer le jeton d'authentification le plus récent d'un module empilé à un autre. Dans la seconde fonction, le jeton est utilisé à une autre fin. Il contient le jeton d'authentification actuellement actif.

PAM_OLDAUTHTOK

L'ancien jeton d'authentification. Ce jeton doit être ignoré par toutes les fonctions de module, sauf pam_sm_chauthtok(3).

PAM_CONV

La structure pam_conv. Voir pam_conv(3).

Les éléments supplémentaires suivants sont spécifiques à Linux-PAM et ne doivent pas être utilisés dans les applications portables :

PAM_FAIL_DELAY

Un pointeur de fonction pour rediriger les retards d'échec gérés centralement. Voir pam_fail_delay(3).

PAM_XDISPLAY

Le nom de l'affichage X. Pour les applications graphiques basées sur X, la valeur de cet élément doit être la variable $DISPLAY. Cette valeur peut être utilisée indépendamment de PAM_TTY pour passer le nom de l'affichage.

PAM_XAUTHDATA

Un pointeur vers une structure contenant les données d'authentification X nécessaires pour établir une connexion à l'affichage spécifié par PAM_XDISPLAY, si de telles informations sont nécessaires. Voir pam_xauth_data(3).

PAM_AUTHTOK_TYPE

L'action par défaut consiste pour le module à utiliser les invites suivantes lors de la demande de mots de passe : « Nouveau mot de passe UNIX : » et « Retapez le mot de passe UNIX : ». Le mot exemple UNIX peut être remplacé par cet élément, par défaut il est vide. Cet élément est utilisé par pam_get_authtok(3).

Pour tous les item_types, autres que PAM_CONV et PAM_FAIL_DELAY, item est un pointeur vers une chaîne de caractères terminée par <NUL>. Dans le cas de PAM_CONV, item pointe vers une structure pam_conv initialisée. Dans le cas de PAM_FAIL_DELAY, item est un pointeur de fonction : void (*delay_fn)(int retval, unsigned usec_delay, void *appdata_ptr)

PAM_AUTHTOK et PAM_OLDAUTHTOK seront réinitialisés avant le retour à l'application. Cela signifie qu'une application ne peut pas accéder aux jetons d'authentification.

VALEURS DE RETOUR

PAM_BAD_ITEM

L'application a tenté de définir un élément indéfini ou inaccessible.

PAM_BUF_ERR

Erreur de tampon mémoire.

PAM_SUCCESS

Les données ont été mises à jour avec succès.

PAM_SYSTEM_ERR

Le pam_handle_t passé comme premier argument était invalide.

VOIR AUSSI
