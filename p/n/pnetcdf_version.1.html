NOM

pnetcdf_version - affiche les informations de version de la bibliothèque PnetCDF

SYNTAXE

pnetcdf_version [-v] [-d] [-c] [-b] [-h]

DESCRIPTION

pnetcdf_version affiche les informations de version de la bibliothèque PnetCDF et la ligne de commande de configuration utilisée pour construire la bibliothèque.

Si aucun argument n'est donné, toutes les informations sont affichées.

OPTIONS

-v
Numéro de version de cette publication PnetCDF.
-d
Date de publication.
-c
Arguments de la ligne de commande de configuration utilisés pour construire ce PnetCDF.
-b
Compilateurs MPI utilisés pour construire cette bibliothèque PnetCDF.
-h
Affiche les options de ligne de commande disponibles de pnetcdf_version.

EXEMPLES

Affiche toutes les informations sur la bibliothèque PnetCDF en exécutant la commande sans option.

% pnetcdf_version

PnetCDF Version:    	1.14.1
PnetCDF Release date:	July 31, 2025
PnetCDF configure: 	--with-mpi=/usr/local/bin
MPICC:  /usr/local/bin/mpicc -g -O2
MPICXX: /usr/local/bin/mpicxx -g -O2
MPIF77: /usr/local/bin/mpif77 -g -O2
MPIF90: /usr/local/bin/mpif90 -g -O2
