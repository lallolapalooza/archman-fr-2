pngquant(1) Manuel des commandes générales pngquant(1)

NOM

pngquant — Convertisseur et compresseur d'image PNG avec perte

SYNTAXE

pngquant ⟨options⟩ [ncouleurs] fichier [fichier ...]

pngquant ⟨options⟩ [ncouleurs] - <fichier >fichier

DESCRIPTION

pngquant convertit les PNG RGBA 32 bits en PNG RGBA 8 bits (ou moins) avec palette, en utilisant optionnellement le diffusé (dithering) de Floyd-Steinberg. Le nom du fichier de sortie est le même que le nom d'entrée sauf qu'il se termine par ‘-fs8.png’ ou ‘-or8.png’ (sauf si l'entrée est stdin, auquel cas l'image quantifiée sera envoyée à stdout). Le comportement par défaut si le fichier de sortie existe est de sauter la conversion ; utilisez --force pour écraser.

OPTIONS

-o sortie.png, --output sortie.png
Écrit le fichier converti dans le chemin spécifié. Lorsque cette option est utilisée, un seul fichier d'entrée est autorisé.
--ext nouveau.png
Extension de fichier (suffixe) à utiliser pour les fichiers de sortie au lieu du suffixe par défaut ‘-fs8.png’ ou ‘-or8.png’.
-f, --force
Écrase les fichiers de sortie existants. “--ext .png --force” peut être utilisé pour convertir les fichiers sur place (ce qui est dangereux).
--nofs, --ordered
Désactive le diffusé de Floyd-Steinberg.
--floyd [=N]
Définit le niveau de diffusé en utilisant un nombre fractionnaire entre 0 (aucun) et 1 (complet, par défaut).
-s N, --speed N
1 (force brute) à 11 (le plus rapide). La valeur par défaut est 3. La vitesse 10 a une qualité inférieure de 5 %, mais est environ 8 fois plus rapide que la valeur par défaut. La vitesse 11 désactive le diffusé et abaisse le niveau de compression.
-Q min-max, --quality min-max
min et max sont des nombres dans la plage 0 (le pire) à 100 (parfait), similaires au JPEG. pngquant utilisera la quantité de couleurs la plus faible requise pour atteindre ou dépasser la qualité max. Si la conversion entraîne une qualité inférieure à la qualité min, l'image ne sera pas enregistrée (ou si la sortie est stdin, l'original 24 bits sera émis) et pngquant se terminera avec le code de statut 99.
--skip-if-larger
Si la conversion aboutit à un fichier plus volumineux que l'original, l'image ne sera pas enregistrée et pngquant se terminera avec le code de statut 98. De plus, le gain de taille de fichier doit être supérieur à la perte de qualité. Si la qualité baisse de 50 %, il s'attendra à une réduction de taille de fichier de 50 % pour considérer cela comme utile.
--posterize bits
Tronque le nombre de bits de couleur (par canal) les moins significatifs. Utilisez ceci lorsque l'image sera affichée sur des écrans à faible profondeur (par exemple, RGB 16 bits). pngquant rendra les pixels presque opaques complètement opaques et réduira le nombre de couleurs semi-transparentes. Lorsque cette option est activée, le suffixe par défaut du nom de fichier est ‘-ie-fs8.png’ / ‘-ie-or8.png’.
--strip
Supprime les fragments optionnels (métadonnées) des fichiers PNG.
--transbug
Contournement pour les lecteurs qui attendent que la couleur entièrement transparente soit la dernière entrée de la palette.
-v, --verbose
Active les messages détaillés montrant la progression et les informations sur l'entrée/la sortie. L'opposé est --quiet. Les erreurs sont affichées sur stderr quelle que soit cette option.
-V, --version
Affiche la version sur stdout et quitte.
-h, --help
Affiche l'aide et quitte.

EXEMPLE

Création d'une nouvelle image avec le nombre de couleurs réduit à 64 :

pngquant 64 image.png

L'image résultante comportera 64 couleurs et sera enregistrée sous le nom image-fs8.png.

Écrasement de l'image sur place si elle peut être réduite sans trop de perte de qualité :

pngquant -f --ext .png --quality 70-95 image.png
