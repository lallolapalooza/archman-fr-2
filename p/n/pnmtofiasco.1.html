NOM

pnmtofiasco - Convertir un fichier PNM en fichier compressé FIASCO

SYNTAXE

pnmtofiasco [option]... [nom_fichier]...

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pnmtofiasco compresse les fichiers image pbm, pgm ou ppm nommés, ou l'entrée standard si aucun fichier n'est nommé, et produit un fichier FIASCO sur la sortie standard.

OPTIONS

Tous les noms d'options peuvent être abrégés ; par exemple, --optimize peut être écrit --optim ou --opt. Pour la plupart des options, une option courte à une lettre est fournie. Les arguments obligatoires ou optionnels aux options longues sont obligatoires ou optionnels pour les options courtes également. Les options courtes et longues respectent la casse.

Les options de base sont :

-i nom, --input-name=nom
Compresse les images nommées, pas l'entrée standard. Si nom est -, lit l'entrée standard. nom doit être soit un nom de fichier image, soit un modèle de la forme : 
préfixe[début-fin{+,-}pas]suffixe

Les modèles sont utiles lors de la compression de flux vidéo : par exemple, si vous spécifiez le modèle img0[12-01-2].pgm, alors pnmtofiasco compresse les images img012.pgm, img010.pgm, ..., img002.pgm.

Si nom est un chemin relatif, pnmtofiasco recherche les fichiers image dans le répertoire courant et dans la liste des répertoires (séparés par des deux-points) donnée par la variable d'environnement FIASCO_IMAGES.

-o fichier-sortie, --output-name=nom
Écrit la sortie FIASCO dans le fichier nommé, pas sur la sortie standard.

Si nom est un chemin relatif et que la variable d'environnement FIASCO_DATA est une liste de répertoires (séparés par des deux-points), alors pnmtofiasco écrit le fichier de sortie dans le premier répertoire (écrivable) de cette liste. Sinon, pnmtofiasco l'écrit dans le répertoire courant.

-q N, --quality=N
Définit la qualité de compression à N. La qualité va de 1 (la pire) à 100 (la meilleure) ; la valeur par défaut est 20.

    -F N, --fps=N

    pour contrôler le taux de rafraîchissement.
    -p type, --pattern=type
    Définit le type de compression inter-images qui doit être appliqué aux images individuelles d'un flux vidéo. type est une séquence de caractères ; la valeur par défaut est 'IPPPPPPPPP'. L'élément N définit le type de prédiction qui doit être utilisé pour l'image N ; le modèle de type d'image est étendu périodiquement. Les caractères valides sont :
    I
    image intra, c'est-à-dire qu'aucune prédiction compensée en mouvement n'est utilisée du tout.
    P
    image prédite, c'est-à-dire qu'une image précédemment encodée est utilisée pour la prédiction (prédiction directe).
    B
    image prédite bidirectionnellement, c'est-à-dire qu'une image antérieurement affichée mais aussi une image du futur sont utilisées pour la prédiction (prédiction directe, arrière ou interpolée).
    --cross-B-search
    Au lieu d'utiliser une recherche exhaustive, l'algorithme 'Cross-B-Search' est utilisé pour trouver la meilleure prédiction interpolée des images B.
    --B-as-past-ref
    Utiliser également les images B précédemment encodées lors de la prédiction de l'image actuelle. Si cette option n'est pas définie, seules les images I et P sont utilisées pour prédire l'image actuelle.

    EXEMPLES

    Compresser l'image fixe 'foo.ppm' dans le fichier FIASCO 'foo.wfa' en utilisant les options par défaut :

            pnmtofiasco < foo.ppm >foo.wfa

    Compresser les images vidéo 'foo0*.ppm' dans le fichier FIASCO 'video.wfa' en utilisant une compensation de mouvement à demi-pixel près avec un taux de rafraîchissement de 15 images par seconde. L'image intra 1 est utilisée pour prédire l'image P 4, les images 1 et 4 sont utilisées pour prédire les images B 2 et 3, et ainsi de suite. L'image 10 est à nouveau une image intra.

            pnmtofiasco -2 -p 'IBBPBBPBB' -fps 15 -o video.wfa foo0*.ppm

    ENVIRONNEMENT

    FIASCO_IMAGES
    Chemin de recherche pour les fichiers image. La valeur par défaut est './'.
    FIASCO_DATA
    Chemin de recherche et de sauvegarde pour les fichiers FIASCO. La valeur par défaut est './'.
