NOM

pngtopnm - convertir une image PNG en image PNM

SYNTAXE

pngtopnm [-verbose] [-alpha | -mix] [-background=couleur] [-gamma=valeur] [-text=nom_fichier] [-time] [fichier_png]

L'abréviation unique minimale d'une option est acceptable. Vous pouvez utiliser des doubles tirets au lieu de tirets simples pour désigner les options. Vous pouvez utiliser des espaces à la place du signe égal pour séparer un nom d'option de sa valeur.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pngtopnm a été obsolète par pngtopam(1) , introduit avec Netpbm 10.44 (septembre 2008). pngtopam est rétrocompatible avec pngtopnm, et ajoute de nombreuses fonctions supplémentaires, dont la possibilité de produire une image PAM incluant un canal alpha (transparence).

À partir de la version 10.48, pngtopnm n'est qu'un alias pour pngtopam.

pngtopnm est resté dans le paquet Netpbm jusqu'à la version 10.47 car il peut avoir moins de bugs que pngtopam dans ces versions, et peut être plus rapide dans certains environnements. Mais l'incompatibilité de pngtopnm avec les bibliothèques PNG les plus récentes rend sa maintenance difficile aux côtés de pngtopam désormais.

Dans les versions antérieures à 10.48, vous pouvez utiliser la documentation de pngtopam pour pngtopnm, en tenant compte des différences suivantes :

  • Les options de pngtopnm sont un sous-ensemble de celles de pngtopam, comme documenté ci-dessus.
  • Tout changement que le manuel de pngtopam indique comme étant survenu à partir de Netpbm 10.44 ne s'applique pas à pngtopnm.
