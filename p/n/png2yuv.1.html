NOM

png2yuv - Convertit les images PNG au format de flux YUV4MPEG.

SYNTAXE

png2yuv [-b num] [-f num] [-I num] [-L num] [-n num] [-j nomfichier]

DESCRIPTION

png2yuv décompresse une séquence de fichiers PNG et envoie les données d'image vers la sortie standard sous forme de flux YUV4MPEG2. Tout format PNG 8 bits/pixel pris en charge par libpng peut être lu. La sortie standard sera remplie avec le flux de données du film YUV4MPEG, il faut donc être prêt à le rediriger vers mpeg2enc ou à l'écrire dans un fichier.

Cet outil est incomplet. L'utilitaire alternatif que vous recherchez probablement est ppmtoy4m(1), qui est également inclus dans MJPEGtools.

OPTIONS

png2yuv accepte les options suivantes :

-b num
Décalage de trame : ignore la sortie des 'num' premières trames. (défaut : 0)
-f num
Définit la fréquence d'images du flux. Accepte les mêmes numéros. Pas de valeur par défaut, cette option doit être spécifiée.
-I num
Mode entrelacement : p = aucun / progressif
t = champ supérieur d'abord
b = champ inférieur d'abord
Pas de valeur par défaut, cette option doit être spécifiée.
-L num
0 = non entrelacé (deux champs successifs par fichier PNG)
1 = champs entrelacés
-S mode_ech
Mode de sous-échantillonnage de la chrominance, réservé aux professionnels, pour plus d'informations voir ppmtoy4m et le guide YUV sur http://www.mir.com/DMG/.
défaut : 420_jpeg
-n num
Spécifie le nombre de trames à traiter. (défaut : toutes = -1)
-j {1}%{2}d{3}
Lit les trames PNG avec les composants de nom comme suit :
{1} Préfixe du nom de fichier PNG (par ex. : picture_ )
{2} Marqueur de comptage (comme en C, printf, par ex. 06 ))
{3} Extension de fichier. Quelque chose comme ceci : .png Une description correcte des fichiers pourrait ressembler à ceci : picture_%06d.png
-v num
Niveau de verbosité (0, 1 ou 2)

BOGUES

La description de la fréquence d'images ne semble pas à jour. Les ratios entiers NTSC ne sont pas pris en charge (utilisez des nombres à virgule flottante à la place). Comme solution de contournement, spécifiez un PAL (25) ou un FILM natif (24) et définissez la bonne fréquence d'images dans mpeg2enc avec l'option -F. La gestion de l'entrelacement n'est pas encore implémentée.
