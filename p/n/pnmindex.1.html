NOM

pnmindex - construire un index visuel d'un ensemble d'images PNM

SYNOPSIS

pnmindex

[-taille=N]

[-largeur=N]

[-couleurs=N]

[-noir]

[-titre=titre]

[-quant|-noquant]

fichier_pnm ...

Vous pouvez utiliser l'abréviation minimale unique des options. Vous pouvez utiliser deux tirets au lieu d'un. Vous pouvez séparer un nom d'option de sa valeur par un espace blanc au lieu d'un signe égal.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pnmindex crée une image d'index contenant des versions miniatures (petites) d'un ensemble de fichiers PNM que vous fournissez. (Similaire à une 'feuille de contact' photographique.)

pnmindex étiquette chaque miniature et, éventuellement, contient un titre.

Si vous souhaitez simplement concaténer des images dans une grille, utilisez pamundice pour cela.

Si vous souhaitez extraire l'image que vous avez générée avec pnmindex, utilisez pamdice ou pamcut.

OPTIONS

-taille=N
La taille de chaque miniature. L'image est mise à l'échelle pour s'adapter au mieux à une boîte de N x N pixels sans changer son rapport d'aspect. La valeur par défaut est 100.
-largeur=N
Le nombre de miniatures dans chaque rangée. La valeur par défaut est 6.
-couleurs=N
Le nombre maximum de couleurs autorisées dans l'image globale. Si elle en avait autrement plus que ce nombre, pnmindex quantifie le résultat. La valeur par défaut est 256.

Cependant, cette valeur n'a aucun sens si vous spécifiez l'option -noquant.

-noir
Ceci contrôle la couleur du remplissage entre les images ; normalement, il est blanc et les étiquettes sont des lettres noires sur fond blanc, mais l'option -noir inverse cela.
-titre=titre
Spécifie un titre à placer en haut de l'image. La valeur par défaut est pas de titre.
-quant
Active la quantification (au nombre de couleurs spécifié par -couleurs). La quantification est activée par défaut, mais vous pouvez la désactiver avec -noquant.
-noquant
Voir -quant.
