NOM

pnmquant - quantifier les couleurs d'une image Netpbm vers un ensemble plus petit

SYNTAXE

pnmquant [-center|-meancolor|-meanpixel] [-floyd|-fs] [-nofloyd|-nofs] [-spreadbrightness|-spreadluminosity] ncolors [pnmfile]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pnmquant lit une image PNM en entrée. Il choisit ncolors couleurs pour représenter au mieux l'image, remplace les couleurs existantes par les nouvelles, et écrit une image PNM en sortie.

Toutes les options peuvent être abrégées à leur préfixe unique le plus court. Vous pouvez utiliser deux tirets au lieu d'un pour désigner une option. Vous pouvez utiliser soit des espaces, soit des signes égal entre un nom d'option et sa valeur.

Ce programme est simplement une combinaison de pnmcolormap et pnmremap, où les couleurs de l'entrée sont remappées à l'aide d'une table de couleurs générée à partir des couleurs de cette même entrée. Les options ont la même signification que dans ces programmes. Consultez leur documentation pour comprendre pnmquant.

Il est beaucoup plus rapide d'appeler directement pnmcolormap et pnmremap que d'exécuter pnmquant. Vous économisez la surcharge de l'interpréteur Perl et la création de deux processus supplémentaires. pnmquant est juste une commodité.

Voici un exemple de la relation entre les programmes :

Ceci :


    $ pnmquant 256 monimage.pnm >/tmp/colormap.pnm >monimage256.pnm

fait essentiellement ceci :


    $ pnmcolormap 256 monimage.pnm >/tmp/colormap.pnm
    $ pnmremap -mapfile=/tmp/colormap.pnm monimage.pnm >monimage256.pnm

pnmquant n'existait pas avant Netpbm 9.21 (janvier 2001). Avant cela, ppmquant faisait la même chose, mais uniquement sur les images PPM. ppmquant continue d'exister, mais n'est qu'une interface (pour la compatibilité des noms) vers pnmquant.
