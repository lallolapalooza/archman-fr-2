NOM

pn53x-tamashell - Shell de démonstration pour la communication TAMA du PN53x

SYNOPSIS

pn53x-tamashell [script]

DESCRIPTION

pn53x-tamashell est un outil interactif simple pour envoyer les commandes dites TAMA et recevoir les réponses. TAMA fait référence à l'ensemble de commandes pris en charge par la famille PN53x. Les messages sont binaires et le shell attend une notation hexadécimale. Les préfixes des commandes et réponses TAMA (0xD4/0xD5), le CRC et tout encadrement sont gérés de manière transparente.

Vous pouvez utiliser le shell de manière interactive (avec prise en charge de readline) ou vous pouvez écrire votre propre fichier script composé de commandes et de commentaires (tout ce qui commence par ";", "#" ou "//"). Les espaces sont ignorés et peuvent être utilisés pour la lisibilité.

Le shebang est pris en charge, commencez simplement votre script par :
#!/usr/bin/env pn53x-tamashell

COMMANDES

p N pour introduire une pause de N millisecondes.

q ou Ctrl-d pour quitter.

EXEMPLES

La commande GetFirmware est D4 02, il suffit donc d'envoyer la commande "02" :


$ pn53x-tamashell
Connecté au lecteur NFC : SCM Micro/SCL3711-NFC&RW - PN533 v2.7 (0x07)
> 02
Tx : 02
Rx : 33 02 07 07
> 40
Tx : 40
Rx : Commande non acceptable
> q
Au revoir !

Même chose, avec un script :


$ pn53x-tamashell << EOF
// Ceci est un commentaire
02 // GetFirmware
40 // Commande avec arguments manquants
EOF


Connecté au lecteur NFC : SCM Micro/SCL3711-NFC&RW - PN533 v2.7 (0x07)
> // Ceci est un commentaire
> 02 // GetFirmware
Tx : 02
Rx : 33 02 07 07
> 40 // Commande avec arguments manquants
Tx : 40
Rx : Commande non acceptable
> Au revoir !

OPTIONS

script Fichier script avec des commandes tama
