NOM

pnmmontage - créer un montage d'images PNM

SYNTAXE

pnmmontage

[-header=fichier_entete]

[-quality=n]

[-prefix=prefixe]

[-0|-1|-2|...|-9]

[-data=nom_de_fichier]

fichier_pnm...

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pnmmontage regroupe des images de tailles différentes dans une image composite de surface minimale.

Les zones de la sortie qui ne peuvent pas être occupées par une image sont noires.

OPTIONS

-data=nom_de_fichier
Cette option demande à pnmmontage d'écrire un fichier qui décrit sous forme lisible par machine les positions des images d'origine dans l'image composite. Voici un exemple : 

            :0:0:227:298
            ../image1.ppm:0:0:227:149
            ../image2.ppm:0:149:227:149

Il y a une ligne pour chaque image composante et une pour l'image composite.

Les 5 champs de chaque ligne sont :

  • nom de l'image source (ou chaîne vide indiquant la ligne de l'image composite)
  • Numéro de colonne du coin supérieur gauche de l'image
  • Numéro de ligne du coin supérieur gauche de l'image
  • largeur de l'image (colonnes)
  • hauteur de l'image (lignes)

    Cette option est nouvelle dans Netpbm 10.6 (juillet 2002).

-header=fichier_entete
Indique à pnmmontage d'écrire un fichier d'en-tête C des emplacements des images d'origine dans l'image composite. Chaque image d'origine génère quatre #defines dans le fichier composite : xxxX, xxxY, xxxSZX et xxxSZY, où xxx est le nom du fichier, converti en majuscules. La sortie inclut également les #defines OVERALLX et OVERALLY, qui spécifient la taille totale de l'image de montage.

Voici un exemple :


            #define OVERALLX 227
            #define OVERALLY 298
            
            #define X 0
            #define Y 0
            #define SZX 227
            #define SZY 149
            
            #define X 0
            #define Y 149
            #define SZX 227
            #define SZY 149
-prefix
Indique à pnmmontage d'utiliser le préfixe spécifié sur tous les #defines qu'il génère.
-quality
Avant de tenter de placer les sous-images, pnmmontage calculera une surface minimale possible pour le montage ; il s'agit soit de la somme des surfaces de toutes les sous-images, soit de la largeur de la sous-image la plus large multipliée par la hauteur de la sous-image la plus haute, le plus grand des deux étant retenu. pnmmontage lance ensuite une recherche dans l'espace des problèmes pour trouver le meilleur arrangement ; s'il trouve une solution au moins aussi bonne que la surface minimale multipliée par la qualité en pourcentage, il sortira de la recherche. Ainsi, -quality=100 trouvera la meilleure solution possible ; cependant, cela peut prendre très longtemps. La valeur par défaut est -quality=200.
-0, -1, ... -9
Ces options contrôlent la qualité à un niveau supérieur à -quality ; -0 est la pire qualité (choisir la première solution trouvée), tandis que -9 est la meilleure qualité (effectuer une recherche exhaustive de l'espace des problèmes pour le meilleur arrangement absolu). Plus le nombre est élevé, plus le calcul est lent. La valeur par défaut est -5.

NOTES

L'utilisation de -9 est très lente sur des ensembles d'images autres que de petite taille.

L'arrangement de surface minimale n'a souvent pas une forme pratique. Par exemple, il peut s'agir d'une colonne d'images haute et mince, alors que vous préféreriez quelque chose de plus carré. Pour forcer une largeur ou une hauteur minimale, vous pouvez inclure une image de contrainte - une image noire de cette largeur et d'un pixel de hauteur. De même, vous pouvez utiliser une contrainte verticale pour forcer une hauteur minimale.
