NOM

pnmtorle - convertir un fichier image Netpbm en fichier image RLE.

SYNTAXE

pnmtorle

[-h] [-v] [-a] [-o fichier_sortie] [fichier_pnm]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

Ce programme convertit les fichiers image Netpbm en fichiers image RLE de Utah. Vous pouvez inclure un masque alpha. Si l'entrée est un fichier à images multiples, la sortie consiste en plusieurs images RLE concaténées.

Le fichier RLE contiendra soit une image couleur à trois canaux (24 bits), soit une image en niveaux de gris à un seul canal (8 bits) selon la profondeur du fichier pnm. Si un ppm converti est affiché sur un écran 8 bits, l'image doit être tramée. Afin de produire une image plus esthétique (sur les écrans 8 bits), il est recommandé de quantifier l'image (en couleur mappée 8 bits) avant son affichage. Cela peut être fait en redirigeant la sortie de ce programme vers les utilitaires mcut ou rlequant de Utah. Nous montrons un exemple de cela plus loin.

OPTIONS

-v
Cette option fera fonctionner pnmtorle en mode verbeux. Les informations d'en-tête sont écrites sur 'stderr'. En fait, il n'y a pas beaucoup d'informations d'en-tête stockées dans un fichier Netpbm, donc cette information est minimale.
-h
Cette option permet de déverser l'en-tête de l'image Netpbm sur 'stderr' sans convertir le fichier. Elle est équivalente à l'option -v, sauf qu'aucune conversion de fichier n'a lieu.
-a
Cette option fait en sorte que pnmtorle inclue un canal alpha dans l'image de sortie. Le canal alpha est basé sur l'image : partout où un pixel est noir, la valeur alpha correspondante est transparente. Partout ailleurs, la valeur alpha est complètement opaque.
-o fichier_sortie
Si vous spécifiez cette option, pnmtorle écrit la sortie dans ce fichier. Si fichier_sortie est - ou si vous ne spécifiez pas -o, pnmtorle écrit la sortie sur la sortie standard.
fichier_pnm
Le nom du fichier de données image Netpbm à convertir. S'il n'est pas spécifié, l'entrée standard est supposée.

EXEMPLES

   pnmtorle -v fichier.ppm -o fichier.rle

Pendant l'exécution en mode verbeux, convertissez fichier.ppm au format RLE et stockez les données résultantes dans fichier.rle.

   pnmtorle -h fichier.pgm

Déversez les informations d'en-tête du fichier Netpbm nommé fichier.pgm.
