NOM

pnmtosgi - convertir une image PNM en fichier image SGI

SYNTAXE

pnmtosgi

[-verbatim|-rle]

[-imagename Nom]

[fichier_pnm]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pnmtosgi lit une image PNM en entrée et produit un fichier image SGI en sortie. L'image SGI sera en 2 dimensions (1 canal) pour une entrée PBM et PGM, et en 3 dimensions (3 canaux) pour une entrée PPM.

OPTIONS

-verbatim
Écrit un fichier non compressé.
-rle (par défaut)
Écrit un fichier compressé (encodage par longueur de séquence).
-imagename nom
Écrit la chaîne 'nom' dans le champ nom de l'image de l'en-tête. La chaîne de nom est limitée à 79 caractères. Si aucun nom n'est donné, pnmtosgi écrit 'no name' dans ce champ.

RÉFÉRENCES

Documentation du format de fichier image SGI (brouillon v0.95) par Paul Haeberli (paul@sgi.com). Disponible via ftp sur sgi.com:graphics/SGIIMAGESPEC.
