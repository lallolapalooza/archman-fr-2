pnm(5) Manuel des formats de fichiers pnm(5)

NOM

pnm - Superformat Netpbm

DESCRIPTION

Le format PNM est simplement une abstraction des formats PBM, PGM et PPM. Autrement dit, le nom 'PNM' fait référence collectivement à PBM, PGM et PPM.

Le nom 'PNM' est un acronyme dérivé de 'Portable Any Map' (Carte Quelconque Portable). Cette dérivation a plus de sens si vous la considérez dans le contexte des autres noms de formats Netpbm : PBM, PGM et PPM.

Le terme plus général 'format Netpbm' fait référence aux formats PNM plus PAM.

PNM est principalement utilisé avec Netpbm(1)

Notez qu'en plus d'être des noms de formats, PBM, PGM, PPM et PNM sont également des classes de programmes. Un programme PNM peut accepter une entrée PBM, PGM ou PPM. Ce n'est rien de spécial – un programme PPM le peut aussi. Mais un programme PNM peut souvent produire plusieurs formats de sortie, et un programme PNM peut voir la différence entre une entrée PBM, PGM et PPM et y répondre différemment, tandis qu'un programme PPM voit tout comme s'il s'agissait de PPM. Ceci est discuté plus en détail dans la description des programmes Netpbm (1)

'pnm' apparaît également dans les noms des plus généraux routines(3) de la bibliothèque Netpbm, dont certaines ne sont même pas liées au format PNM.

TYPE MEDIA INTERNET

Aucun type de média Internet (également appelé type MIME, type de contenu) pour PNM n'a été enregistré auprès de l'IANA, mais la valeur image/x-portable-anymap est conventionnelle.

Notez qu'il existe également des types de médias Internet conventionnels pour chacun des sous-formats PNM. La pratique recommandée est de les utiliser de préférence au code PNM lorsque cela est pratique.

NOM FICHIER

Il n'y a pas d'exigences quant au nom d'un fichier PNM, mais la convention est d'utiliser le suffixe 'pbm', 'pgm' ou 'ppm', en fonction du sous-format particulier, ou 'pnm' s'il n'est pas pratique de distinguer les sous-formats.

VOIR AUSSI

ppm(5), pgm(5), pbm(5), pam(5), programmes quitraitent PNM(1), libnetpbm(3)
