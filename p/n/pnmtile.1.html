NOM

pnmtile - réplique une image pour remplir une région spécifiée

SYNTAXE

pnmtile largeur hauteur [fichier_pnm]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pnmtile lit une image PNM en entrée. Il la réplique pour remplir une zone de dimensions spécifiées et produit une image dans le même format en sortie.

Vous pouvez faire pratiquement l'inverse avec pamdice.

Vous pouvez explicitement concaténer une image avec elle-même (ou toute autre chose) avec pnmcat.

Si vous essayez de combiner plusieurs images en une super-image, consultez pamundice ou (pour une planche de miniatures) pnmindex.
