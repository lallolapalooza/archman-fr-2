NOM

pptpsetup - configuration du protocole Point-to-Point Tunneling

SYNTAXE

pptpsetup --create <TUNNEL> --server <SERVEUR> [--domain <DOMAINE>]
          --username <NOM_UTILISATEUR> [--password <MOT_DE_PASSE>]
          [--encrypt] [--start]
pptpsetup --delete <TUNNEL>

DESCRIPTION

PPTP Client est un client pour Linux, FreeBSD, NetBSD et OpenBSD du protocole propriétaire Microsoft Point-to-Point Tunneling, PPTP.

Ce script configure PPTP Client sous Linux.

OPTIONS

--create TUNNEL
crée un tunnel nommé TUNNEL
--delete TUNNEL
supprime le fichier /etc/ppp/peers/TUNNEL et toutes les lignes de /etc/ppp/chap-secrets qui contiennent "TUNNEL" en tant que mot unique
--server SERVEUR
l'adresse IP ou le nom d'hôte du serveur
--domain DOMAINE
le nom du domaine d'authentification (facultatif)
--username NOM_UTILISATEUR
le nom d'utilisateur à utiliser
--password MOT_DE_PASSE
le mot de passe à utiliser. Si vous ne spécifiez pas de mot de passe, pptpsetup vous en demandera un.
--encrypt
indique si le chiffrement est requis
--start
indique si la connexion doit être démarrée après la configuration.
