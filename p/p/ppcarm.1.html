NOM

ppcarm - binaire du compilateur Free Pascal (FPC), nom dérivé de Portable Pascal Compiler

SYNTAXE

ppcarm [options] [fichier_source]

DESCRIPTION

Ce binaire est le back-end du compilateur Free Pascal (FPC) qui est un compilateur Pascal multitarget indépendant (sans frontal GCC) compatible avec Turbo Pascal et Delphi (7.0).

Ce binaire ne doit pas être appelé directement, mais plutôt le programme fpc doit être utilisé à la place. Il choisira le back-end approprié pour compiler les unités pour les plateformes demandées.

OPTIONS

Pour une liste complète de toutes les options de ligne de commande prises en charge, consultez la page de manuel fpc(1).
