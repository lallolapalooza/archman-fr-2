ppudump(1) Utilitaire d'extraction des unités FPC ppudump(1)

NOM

ppudump - Le programme d'extraction des unités Pascal de FPC.

SYNTAXE

ppudump [-h] [-v[h|i|m|d|s|b|a]] fichier_ppu1 fichier_ppu2 ...

DESCRIPTION

ppudump écrit le contenu d'un fichier d'unité Free Pascal en sortie standard. Il donne une liste de toutes les définitions contenues dans le fichier d'unité. Le format de la liste peut être contrôlé par les options.

UTILISATION

Vous pouvez invoquer ppudump avec comme arguments les noms des unités que vous souhaitez extraire. Vous n'avez pas besoin de spécifier l'extension, par défaut .ppu est supposé. La sortie va à la sortie standard.

OPTIONS

ppudump n'a que deux options :

-h
affiche un court écran d'aide.
-vxxx
Contrôle le niveau de verbosité. xxx est une combinaison quelconque des lettres suivantes :
a
Affiche toutes les informations stockées dans le fichier PPU.
b
Affiche les informations du navigateur dans le fichier PPU (si présentes).
d
Affiche les définitions dans le fichier PPU.
h
Affiche les informations d'en-tête dans le fichier PPU.
i
Affiche uniquement les informations de l'interface, les informations d'implémentation ne sont pas affichées.
m
Affiche uniquement les informations d'implémentation, les informations de l'interface ne sont pas affichées.
s
Affiche les symboles stockés dans le fichier PPU.
