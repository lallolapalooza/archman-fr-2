PPPOE-SNIFF(8) Manuel du gestionnaire système PPPOE-SNIFF(8)

NOM

pppoe-sniff - examine le réseau pour des trames PPPoE non standard

SYNTAXE

pppoe-sniff [options]

DESCRIPTION

pppoe-sniff écoute les trames PPPoE PADR et de session qui semblent correspondantes et déduit les options supplémentaires requises pour que pppoe(8) fonctionne.

Certains fournisseurs DSL semblent utiliser des types de trames non standard pour les trames PPPoE, et/ou exigent une certaine valeur dans le champ Service-Name. Il est souvent plus facile de renifler ces valeurs à partir d'une machine qui peut se connecter avec succès plutôt que d'essayer de les obtenir du fournisseur DSL.

Pour utiliser pppoe-sniff, vous avez besoin de deux ordinateurs, d'un modem DSL et d'un hub Ethernet (pas un switch Ethernet).

Si le modem DSL se connecte normalement directement à la carte Ethernet de votre ordinateur, connectez-le au port "uplink" du hub Ethernet. Branchez deux ordinateurs sur des ports normaux du hub. Sur l'un des ordinateurs, exécutez le logiciel que le fournisseur DSL vous a donné sur le système d'exploitation que le fournisseur DSL prend en charge. Sur l'autre ordinateur, exécutez Linux et connectez-vous en tant que root.

Sur la machine Linux, mettez l'interface Ethernet en mode promiscueux et démarrez pppoe-sniff. Si l'interface Ethernet est eth0, par exemple, tapez ces commandes :

ip link set eth0 promisc on
pppoe-sniff -I eth0

Sur l'autre machine, démarrez votre connexion DSL comme d'habitude. Après un court instant, pppoe-sniff devrait afficher des recommandations pour la valeur d'une option '-f' pour pppoe.

Après que pppoe-sniff ait terminé (ou que vous l'ayez arrêté s'il semble bloqué), n'oubliez pas de désactiver le mode promiscueux :

ip link set eth0 promisc on

OPTIONS

-I interface
L'option -I spécifie l'interface Ethernet à utiliser. Sous Linux, il s'agit généralement de eth0 ou eth1. L'interface doit être "up" et en mode promiscueux avant de démarrer pppoe-sniff.
-V
L'option -V fait en sorte que pppoe-sniff affiche son numéro de version et se termine.

BOGUES

pppoe-sniff ne fonctionne que sous Linux.
