NOM

ppmtoacad - convertir PPM en base de données ou diapositive Autocad

SYNTAXE

ppmtoacad

[-dxb]

[-poly]

[-background couleur]

[-white]

[-aspect ratio]

[-8]

[fichier.ppm]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

ppmtoacad lit une image PPM en entrée et produit un fichier de diapositive Autocad® ou un fichier d'importation de base de données binaire (.dxb) en sortie. Si vous ne spécifiez pas fichier.ppm, ppmtoacad prend l'entrée depuis l'entrée standard.

(Note typographique : le nom d'Autocad est souvent rendu sous la forme AutoCAD. La documentation Netpbm utilise la typographie américaine standard, où ce n'est pas une forme de capitalisation valide).

OPTIONS

Vous pouvez abréger toute option à son plus court préfixe unique.

-dxb
ppmtoacad écrit un fichier d'importation de base de données binaire Autocad (.dxb). Vous lisez ce fichier avec la commande DXBIN et, une fois chargé, il devient une partie de la base de données géométrique d'Autocad, vous pouvez donc le visualiser et le modifier comme n'importe quel autre objet. Chaque séquence de pixels identiques devient un objet distinct dans la base de données ; cela peut entraîner des fichiers de dessin Autocad très volumineux. Cependant, si vous souhaitez tracer par-dessus une image matricielle, cela vous permet de zoomer et de faire un panoramique autour de l'image matricielle comme vous le souhaitez.
-poly
Si vous ne spécifiez pas l'option -dxb, ppmtoacad génère un fichier de diapositive Autocad. Normalement, chaque ligne de pixels est représentée par une entité ligne Autocad. Si vous spécifiez -poly, ppmtoacad rend les pixels sous forme de polygones remplis. Si vous visualisez la diapositive sur un écran avec une résolution plus élevée que l'image source, cela provoquera l'agrandissement des pixels au lieu d'apparaître comme des lignes distinctes sur la couleur de fond de l'écran. Malheureusement, cette représentation produit des fichiers de diapositive qui occupent plus d'espace de stockage et prennent plus de temps à afficher.
-background couleur
La plupart des pilotes d'affichage Autocad peuvent être configurés pour utiliser n'importe quelle couleur disponible comme arrière-plan de l'écran. Certains utilisateurs préfèrent un arrière-plan noir, d'autres blanc, tandis que des groupes dissidents prônent le ocre brûlé, le puce fauve et le gris choquant. Écarter les pixels dont la représentation de couleur Autocad la plus proche est égale à la couleur d'arrière-plan peut réduire considérablement la taille de la base de données Autocad ou du fichier de diapositive nécessaire pour représenter une image matricielle. Si vous ne spécifiez pas -background, ppmtoacad suppose que la couleur d'arrière-plan de l'écran est noire. Vous pouvez spécifier n'importe quel numéro de couleur Autocad comme arrière-plan de l'écran ; ppmtoacad suppose que les numéros de couleur spécifient les teintes définies dans la palette standard de 256 couleurs d'Autocad.
-white
Étant donné que de nombreux utilisateurs d'Autocad choisissent un arrière-plan d'écran blanc, cette option est fournie comme raccourci. Spécifier -white est identique en effet à -background 7.
-aspect ratio
Si l'image source avait des pixels non carrés (ce qui signifie qu'elle n'est pas une PPM standard), spécifiez le ratio de la largeur du pixel à la hauteur du pixel comme ratio. ppmtoacad corrigera le fichier de diapositive ou .dxb résultant afin que les pixels à l'écran Autocad soient carrés. Par exemple, pour corriger une image faite pour un écran VGA/MCGA 320x200, spécifiez -aspect 0.8333.
-8
Limite les couleurs dans le fichier de sortie aux 8 nuances RVB.

RESTRICTIONS

Autocad a une palette fixe de 256 couleurs, distribuées sur les axes de teinte, de luminosité et de saturation. Il peut donc mal rendre les images contenant de nombreuses couleurs quasi identiques, ou des couleurs qui ne sont pas bien approchées par la palette d'Autocad.

ppmtoacad fonctionne mieux si le système affichant sa sortie peut afficher la palette complète de 256 couleurs d'Autocad. Les configurations monochromes, 8 couleurs et 16 couleurs produiront des résultats moins optimaux.

Lors de la création d'un fichier .dxb ou d'un fichier de diapositive avec l'option -poly, ppmtoacad trouve des séquences de pixels identiques verticales et horizontales et les consolide en régions rectangulaires pour réduire la taille du fichier de sortie. Ceci est efficace pour les images avec de grandes zones de couleur constante, mais ce n'est pas un substitut à une véritable conversion de raster en vecteur. En particulier, ce processus n'optimise pas du tout les lignes diagonales fines.

Les fichiers de sortie peuvent être énormes.
