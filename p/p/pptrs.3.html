sous-routine cpptrs (character uplo, integer n, integer nrhs, complex, dimension( * ) ap, complex, dimension( ldb, * ) b, integer ldb, integer info)

CPPTRS

Objectif :

!>
!> CPPTRS résout un système d'équations linéaires A*X = B avec une matrice
!> hermitienne définie positive A en stockage compact en utilisant la
!> factorisation de Cholesky A = U**H*U ou A = L*L**H calculée par CPPTRF.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : le triangle supérieur de A est stocké ;
!>          = 'L' : le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B. NRHS >= 0.
!>

AP

!>          AP est un tableau de type COMPLEX, dimension (N*(N+1)/2)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**H*U ou A = L*L**H, stocké en colonne dans un tableau
!>          linéaire. La j-ième colonne de U ou L est stockée dans le
!>          tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = U(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = L(i,j) pour j<=i<=n.
!>

B

!>          B est un tableau de type COMPLEX, dimension (LDB,NRHS)
!>          À l'entrée, la matrice des seconds membres B.
!>          À la sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale
!>

zpptrs(3)

LAPACK 3.12.0

NAME

ZPPTRS

résout un système d'équations linéaires A*X = B avec une matrice A hermitienne définie positive en stockage packé

SYNOPSIS

  SUBROUTINE ZPPTRS( UPLO, N, NRHS, AP, B, LDB, INFO )
      CHARACTER      UPLO
      INTEGER        INFO, LDB, N, NRHS
      COMPLEX*16     AP( * ), B( LDB, * )

Detailed Description

ZPPTRS résout un système d'équations linéaires A*X = B avec une matrice A hermitienne définie positive en stockage packé en utilisant la décomposition de Cholesky A = U**H * U ou A = L * L**H calculée par ZPPTRF.

Arguments

UPLO

UPLO est CHARACTER*1

= 'U': La partie triangulaire supérieure de A est stockée ;

= 'L': La partie triangulaire inférieure de A est stockée.

N

N est INTEGER

L'ordre de la matrice A. N >= 0.

NRHS

NRHS est INTEGER

Le nombre de membres de droite, c'est-à-dire le nombre de colonnes de la matrice B. NRHS >= 0.

AP

AP est un tableau COMPLEX*16, de dimension (N*(N+1)/2)

Le facteur triangulaire U ou L de la décomposition de Cholesky A = U**H * U ou A = L * L**H, packé par colonnes dans un tableau linéaire. La j-ème colonne de U ou L est stockée dans le tableau AP comme suit :

si UPLO = 'U', AP(i + (j-1)*j/2) = U(i,j) pour 1<=i<=j ;

si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = L(i,j) pour j<=i<=n.

B

B est un tableau COMPLEX*16, de dimension (LDB,NRHS)

En entrée, la matrice des membres de droite B.

En sortie, la matrice solution X.

LDB

LDB est INTEGER

La dimension principale du tableau B. LDB >= max(1,N).

INFO

INFO est INTEGER

= 0: Sortie réussie

< 0: Si INFO = -i, le i-ème argument avait une valeur illégale.
