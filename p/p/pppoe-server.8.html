NOM

pppoe-server - serveur PPPoE en espace utilisateur

SYNTAXE

pppoe-server [options]

DESCRIPTION

pppoe-server est un serveur en espace utilisateur pour PPPoE (Point-to-Point Protocol over Ethernet) pour Linux et autres systèmes UNIX. pppoe-server fonctionne en concertation avec le client pppoe pour répondre aux paquets de découverte PPPoE et établir des sessions PPPoE.

OPTIONS

-F
L'option -F fait en sorte que pppoe-server ne se détache pas pour devenir un démon. Le comportement par défaut est de se détacher et de devenir un démon.
-I interface
L'option -I spécifie l'interface Ethernet à utiliser. Sous Linux, il s'agit généralement de eth0 ou eth1. L'interface doit être "up" (activée) avant de démarrer pppoe-server, mais elle n'a pas besoin d'avoir une adresse IP. Vous pouvez fournir plusieurs options -I si vous souhaitez que le serveur réponde sur plus d'une interface.
-X fichier_pid
Cette option fait en sorte que pppoe-server écrive son identifiant de processus (PID) dans fichier_pid. De plus, il maintient le fichier verrouillé de sorte qu'un seul processus puisse être lancé pour un fichier_pid donné.
-q /chemin/vers/pppd
Spécifie le chemin complet du programme pppd. Le chemin par défaut est déterminé lors de la compilation. Une utilisation de cette option est de fournir un programme wrapper qui modifie les arguments passés à pppd. Cela vous permet de faire des choses non directement prises en charge par le serveur (par exemple, spécifier des adresses IPv6.)
-Q /chemin/vers/pppoe
Spécifie le chemin complet du programme pppoe. Le chemin par défaut est déterminé lors de la compilation. Cette option n'est pertinente que si vous n'utilisez PAS PPPoE en mode noyau.
-T délai
Cette option est passée directement à pppoe ; voir pppoe(8) pour les détails. Si vous utilisez PPPoE en mode noyau, cette option n'a aucun effet.
-C nom_ac
Spécifie le nom qui sera rapporté comme nom de concentrateur d'accès. S'il n'est pas fourni, le nom d'hôte est utilisé.
-S nom
Proposer un service nommé nom. Plusieurs options -S peuvent être spécifiées ; chacune fait en sorte que le service nommé soit annoncé dans une balise Service-Name dans l'image PADO. La première option -S spécifie le service par défaut, et est utilisée si le client PPPoE demande un Service-Name de longueur zéro.
-m MSS
Cette option est passée directement à pppoe ; voir pppoe(8) pour les détails. Si vous utilisez PPPoE en mode noyau, cette option n'a aucun effet.
-x n
Limite le nombre de sessions par adresse MAC de pair à n. Si une adresse MAC donnée tente de créer plus de n sessions, ses paquets PADI et PADR sont ignorés. Si vous définissez n sur 0 (par défaut), aucune limite n'est imposée au nombre de sessions par adresse MAC de pair.
-s
Cette option est passée directement à pppoe ; voir pppoe(8) pour les détails. De plus, elle fait en sorte que pppd soit invoqué avec l'option sync.
-L ip
Définit l'adresse IP locale. Ceci est passé aux processus pppd engendrés. Si non spécifié, la valeur par défaut est 10.0.0.1. Si spécifié comme 0.0.0.0, la sélection de l'adresse IP locale est déléguée à pppd.
-R ip
Définit l'adresse IP distante de départ. Au fur et à mesure que les sessions sont établies, les adresses IP sont attribuées à partir de ip. pppoe-server garde automatiquement une trace du pool d'adresses et transmet une adresse IP distante valide à pppd. Si non spécifié, une adresse de départ de 10.67.15.1 est utilisée. Si spécifié comme 0.0.0.0, l'allocation de l'adresse IP distante sera déléguée à pppd.
-N num
Autorise au plus num sessions PPPoE simultanées. Si non spécifié, la valeur par défaut est 64.
-M chaîne
Envoie chaîne dans une balise MOTM (Message du Jour) dans une image PADM juste après l'envoi de PADS à un client.
-H url
Envoie url dans une balise HURL dans une image PADM juste après l'envoi de PADS à un client. Notez que url doit commencer par http:// ou https://.
-O nom_fichier
Cette option fait en sorte que pppoe-server demande à pppd d'utiliser le fichier d'options nom_fichier au lieu du fichier par défaut /etc/ppp/pppoe-server-options.
-p nom_fichier
Lit le fichier spécifié nom_fichier qui est un fichier texte composé d'une adresse IP par ligne. Ces adresses IP seront attribuées aux clients. Le nombre de sessions autorisées sera égal au nombre d'adresses trouvées dans le fichier. L'option -p remplace à la fois -R et -N.

En plus de contenir des adresses IP, le fichier de pool peut contenir des lignes de la forme :

a.b.c.d-e

ce qui inclut toutes les adresses IP de a.b.c.d à a.b.c.e. Par exemple, la ligne :

1.2.3.4-7

est équivalente à :

1.2.3.4
1.2.3.5
1.2.3.6
1.2.3.7
-r
Indique au serveur PPPoE de permuter aléatoirement les numéros de session. Au lieu de distribuer les sessions dans l'ordre, les numéros de session sont attribués dans un ordre imprévisible.
-u
Indique au serveur d'invoquer pppd avec l'option unit. Notez que cette option ne fonctionne qu'avec la version 2.4.0 ou plus récente de pppd.
-o décalage
Au lieu de numéroter les sessions PPPoE à partir de 1, elles seront numérotées à partir de décalage+1. Cela vous permet d'exécuter plusieurs serveurs sur une même machine ; assurez-vous simplement que leurs numéros de session ne se chevauchent pas.
-f disc:sess
L'option -f définit les types de trames Ethernet pour la découverte PPPoE et les trames de session. Les types sont spécifiés sous forme de nombres hexadécimaux séparés par un deux-points. PPPoE standard utilise les types de trames 8863:8864. Vous ne devriez pas utiliser cette option à moins d'être absolument sûr que le pair avec lequel vous traitez utilise des types de trames non standard.
-k
L'option -k indique au serveur d'utiliser PPPoE en mode noyau sous Linux. Cette option n'est disponible que sur les noyaux Linux 2.4.0 et ultérieurs, et uniquement si le serveur a été compilé avec le support du mode noyau.
-g chemin
L'option -g indique au serveur le chemin complet du plugin pppoe.so ou rp-pppoe.so à utiliser avec PPPoE en mode noyau. S'il est omis, une valeur par défaut intégrée est utilisée ; cette valeur par défaut peut être affichée à l'aide de l'option -h.
-i
L'option -i indique au serveur d'ignorer complètement les paquets PADI s'il n'y a pas de slots de session libres.
-h
L'option -h affiche un bref message d'utilisation et se termine.
-U chemin
L'option -U crée un socket UNIX auquel il est possible de se connecter pour gérer pppoe-server à l'exécution. Veuillez vous référer à la section SOCKET DE CONTRÔLE ci-dessous pour des instructions plus détaillées.

FONCTIONNEMENT

pppoe-server écoute les paquets de découverte PPPoE entrants. Lorsqu'une session est établie, il engendre un processus pppd. Les options suivantes sont passées à pppd :

nodetach noaccomp nobsdcom nodeflate nopcomp novj novjccomp
default-asyncmap

NAME

pppoe-server — PPPoE server

SYNOPSIS

pppoe-server [-U control-socket] [-L local-ip] [-R remote-ip] [-d] [-h] [-n] [-s] [-v] [-I interface] [pppd options]

DESCRIPTION

pppoe-server is a simple PPPoE server that can be used to allow PPPoE clients to connect to a network. It works by launching a new instance of pppd for each client that connects.

The server listens for PPPoE discovery packets (PADI) on the specified network interface. When a PADI packet is received, it may send a PADO reply (if not in drain mode), and if the client proceeds to request a session, it launches a new instance of pppd to handle the PPP session.

OPTIONS

-U control-socket
Specifies a control socket path. This allows for runtime control of the server using commands like pppoe-serverctl.
-L local-ip
Specifies the IP address to be assigned to the server side of the PPP connection. If not specified, it defaults to the IP address of the specified interface. This option is typically used when the server is behind a NAT gateway and needs to assign private IP addresses to clients.
-R remote-ip
Specifies the IP address to be assigned to the client side of the PPP connection. If not specified, it defaults to 0.0.0.0, which means the client will obtain its IP address via DHCP (if configured in pppd options).
-d
Enables drain mode. In this mode, the server will not respond to PADI packets, allowing existing sessions to continue while new connections are prevented.
-h
Prints a help message and exits.
-n
Disables the use of the connection setup protocol. This means that pppd will be invoked directly without any connection setup script.
-s
Enables single-session mode. In this mode, only one PPPoE session is allowed at a time. This is useful for testing.
-v
Prints the version information and exits.
-I interface
Specifies the network interface on which to listen for PPPoE packets. This option is mandatory.

Any remaining arguments are passed directly to the pppd command.

OPERATION

The local and remote IP addresses are set based on the -L and -R options. The pty option is supplied along with a pppoe command to initiate the PPPoE session. Finally, additional pppd options can be placed in the file /etc/ppp/pppoe-server-options (which must exist, even if it is just empty!)

Note that pppoe-server is meant mainly for testing PPPoE clients. It is not a high-performance server meant for production use.

CONTROL-SOCKET

The control-socket was implemented as a secondary mechanism to improve run-time control of the pppoe-server. To use it you need to start pppoe-server with the -U option described above. You can then (in the absense of a control-client currently) use netcat to connect to the control socket, for example:

nc -U /run/pppoe-server.control

Assuming -U /run/pppoe-server.control was passed to pppoe-server.

The following commands are implemented:

set drain {off|on|quit}
This will set whether or not pppoe-server responds to PADI packets or not. When set to off pppoe-server will respond, else PADI packets will be ignored. This allows the pppoe-server to be drained from clients. In addition when set to quit will terminate pppoe-server when all pppoe-clients have terminated.

This allows for (mostly) seamless upgrades in that the currently running instance can be issued with "set drain quit" prior to starting a new interface on the same interfaces, thus allowing new connections to be made whilst maintaining proper state on existing clients.

show status
This will show basic status information for the connected-to pppoe-server.

AUTHORS

The pppoe home page is https://dianne.skoll.ca/projects/rp-pppoe/.
