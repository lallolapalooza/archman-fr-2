NOM

ppmdcfont - Transformer un fichier Ppmdfont en code source C pour une police intégrée

SYNTAXE

ppmdcfont

DESCRIPTION

Ce programme fait partie de Netpbm(1)

(Il n'y a pas d'arguments ni d'options)

ppmdcfont crée un fichier source C que vous pouvez compiler en une police intégrée à utiliser avec les facilités de dessin PPM de Netpbm. Il lit un fichier Ppmdfont sur l'entrée standard et écrit le code source C sur la sortie standard.

Le code source C de sortie a le nom de l'objet police codé en dur comme ppmd_standardfont, que vous voudrez absolument modifier, car c'est le nom de la police intégrée à libnetpbm. Si vous ne le changez pas, cela créera un conflit à la fois sur le plan cognitif et lors de la liaison du programme. Il devrait évidemment y avoir une option sur ppmdcfont pour choisir cela, mais l'effort de développement n'a pas été justifié jusqu'à présent.

Voir Manuel des fonctions de dessin PPM de Libnetpbm (1)
pour plus de détails sur les fichiers Ppmdfont.
