PPL-CONFIG(1) Commandes utilisateur PPL-CONFIG(1)

NOM

ppl-config - obtenir des informations sur une installation de la Parma Polyhedra Library

SYNTAXE

ppl-config [OPTION]...

DESCRIPTION

Affiche des informations, dans divers formats, sur une installation de la Parma Polyhedra Library.

OPTIONS

-h, --help
affiche ce texte d'aide sur la sortie standard
-FFMT, --format=FMT
définit le format de sortie à FMT (l'un de `plain', `makefile', `sh' ou `csh')
-IINT, --interface=INT
sélectionne une interface de bibliothèque (l'un de `C++', `C', `Ciao-Prolog', `GNU-Prolog', `SICStus-Prolog', `SWI-Prolog', `XSB-Prolog', `YAP-Prolog', `OCaml' ou `Java')
-A, --application
sélectionne la sortie pour la compilation d'une application
-L, --library
sélectionne la sortie pour la compilation d'une bibliothèque
-p[PFX], --prefix[=PFX]
affiche ou définit les informations de préfixe de la bibliothèque
-e[PFX], --exec-prefix[=PFX]
affiche ou définit les informations de préfixe d'exécution de la bibliothèque
-O, --configure-options
affiche les options de configuration
-V, --version
affiche les informations de version
-M, --version-major
affiche le numéro majeur de la version
-N, --version-minor
affiche le numéro mineur de la version
-R, --version-revision
affiche le numéro de révision de la version
-B, --version-beta
affiche le numéro bêta de la version
-E, --banner
affiche la bannière de la bibliothèque
-n, --coefficients
affiche le type des coefficients de la bibliothèque
-i, --includedir
affiche le répertoire des fichiers d'inclusion
-b, --bindir
affiche le répertoire des exécutables binaires
-l, --libdir
affiche le répertoire des fichiers de bibliothèque
-P, --cppflags
affiche les options du préprocesseur
-C, --cflags
affiche les options du compilateur C
-X, --cxxflags
affiche les options du compilateur C++
-D, --ldflags
affiche les options de l'éditeur de liens
-g, --license
affiche des informations de licence synthétiques
-c, --copying
affiche des informations de licence détaillées
-u, --bugs
affiche les informations sur le signalement de bugs
-r, --credits
affiche les crédits
