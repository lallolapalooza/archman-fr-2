ADDR2LINE(1) Outils de développement GNU ADDR2LINE(1)

NOM

addr2line - convertir des adresses ou des symboles+décalages en noms de fichiers et numéros de ligne

SYNTAXE

addr2line [-a|--addresses]
[-b nom_bfd|--target=nom_bfd]
[-C|--demangle[=style]]
[-r|--no-recurse-limit]
[-R|--recurse-limit]
[-e nom_fichier|--exe=nom_fichier]
[-f|--functions] [-s|--basename]
[-i|--inlines]
[-p|--pretty-print]
[-j|--section=nom]
[-H|--help] [-V|--version]
[adresse adresse ...]

DESCRIPTION

addr2line traduit des adresses ou des symboles+décalages en noms de fichiers et numéros de ligne. Étant donné une adresse ou un symbole+décalage dans un exécutable ou un décalage dans une section d'un objet relocable, il utilise les informations de débogage pour déterminer le nom du fichier et le numéro de ligne qui y sont associés.

L'exécutable ou l'objet relocable à utiliser est spécifié avec l'option -e. Par défaut, il s'agit du fichier a.out. La section dans l'objet relocable à utiliser est spécifiée avec l'option -j.

addr2line a deux modes de fonctionnement.

Dans le premier, des adresses hexadécimales ou des symboles+décalages sont spécifiés sur la ligne de commande, et addr2line affiche le nom du fichier et le numéro de ligne pour chaque adresse.

Dans le second, addr2line lit des adresses hexadécimales ou des symboles+décalages depuis l'entrée standard et affiche le nom du fichier et le numéro de ligne pour chaque adresse sur la sortie standard. Dans ce mode, addr2line peut être utilisé dans un pipeline pour convertir des adresses choisies dynamiquement.

Le format de la sortie est NOMFICHIER:NUMEROLIGNE. Par défaut, chaque adresse d'entrée génère une ligne de sortie.

Deux options peuvent générer des lignes supplémentaires avant chaque ligne NOMFICHIER:NUMEROLIGNE (dans cet ordre).

Si l'option -a est utilisée, une ligne avec l'adresse d'entrée est affichée.

Si l'option -f est utilisée, une ligne avec le NOMFONCTION est affichée. C'est le nom de la fonction contenant l'adresse.

Une option peut générer des lignes supplémentaires après la ligne NOMFICHIER:NUMEROLIGNE.

Si l'option -i est utilisée et que le code à l'adresse donnée est présent là en raison de l'inlining par le compilateur, des lignes supplémentaires sont affichées ensuite. Une ou deux lignes supplémentaires (si l'option -f est utilisée) sont affichées pour chaque fonction inlinée.

Alternativement, si l'option -p est utilisée, chaque adresse d'entrée génère une seule longue ligne de sortie contenant l'adresse, le nom de la fonction, le nom du fichier et le numéro de ligne. Si l'option -i a également été utilisée, les fonctions inlinées seront affichées de la même manière, mais sur des lignes séparées et précédées du texte (inlined by).

Si le nom du fichier ou le nom de la fonction ne peuvent pas être déterminés, addr2line affichera deux points d'interrogation à leur place. Si le numéro de ligne ne peut pas être déterminé, addr2line affichera 0.

Lorsque symbole+décalage est utilisé, +décalage est facultatif, sauf lorsque le symbole est ambigu avec un nombre hexadécimal. Les symboles résolus peuvent être manglés ou non manglés, sauf que les symboles non manglés avec + ne sont pas autorisés.

OPTIONS

Les formes longues et courtes des options, présentées ici comme alternatives, sont équivalentes.

-a
--addresses
Affiche l'adresse avant le nom de la fonction, le nom du fichier et les informations de numéro de ligne. L'adresse est imprimée avec un préfixe 0x pour l'identifier facilement.
-b nom_bfd
--target=nom_bfd
Spécifie que le format du code objet pour les fichiers objet est nom_bfd.
-C
--demangle[=style]
Décode (démangle) les noms de symboles de bas niveau en noms de niveau utilisateur. En plus de supprimer le trait de soulignement initial ajouté par le système, cela rend les noms de fonctions C++ lisibles. Différents compilateurs ont différents styles de mangling. L'argument optionnel de style de démangling peut être utilisé pour choisir un style de démangling approprié pour votre compilateur.
-e nom_fichier
--exe=nom_fichier
Spécifie le nom de l'exécutable pour lequel les adresses doivent être traduites. Le fichier par défaut est a.out.
-f
--functions
Affiche les noms de fonctions ainsi que les informations sur le nom du fichier et le numéro de ligne.
-s
--basenames
Affiche uniquement la base de chaque nom de fichier.
-i
--inlines
Si l'adresse appartient à une fonction qui a été inlinée, les informations sources pour tous les scopes englobants jusqu'à la première fonction non inlinée seront également imprimées. Par exemple, si "main" inlines "callee1" qui inlines "callee2", et que l'adresse provient de "callee2", les informations sources pour "callee1" et "main" seront également imprimées.
-j
--section
Lit les décalages relatifs à la section spécifiée au lieu des adresses absolues.
-p
--pretty-print
Rend la sortie plus conviviale : chaque emplacement est imprimé sur une ligne. Si l'option -i est spécifiée, les lignes pour tous les scopes englobants sont précédées de (inlined by).
-r
-R
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
Active ou désactive une limite sur la quantité de récursion effectuée lors du démangling des chaînes. Étant donné que les formats de mangling de noms permettent un niveau de récursion infini, il est possible de créer des chaînes dont le décodage épuiserait l'espace de pile disponible sur la machine hôte, déclenchant une erreur de mémoire. La limite tente d'éviter que cela ne se produise en restreignant la récursion à 2048 niveaux d'imbrication.

Par défaut, cette limite est activée, mais sa désactivation peut être nécessaire pour démangler des noms véritablement compliqués. Notez cependant que si la limite de récursion est désactivée, l'épuisement de la pile est possible et tout rapport de bug concernant un tel événement sera rejeté.

L'option -r est un synonyme de l'option --no-recurse-limit. L'option -R est un synonyme de l'option --recurse-limit.

Notez que cette option n'est effective que si l'option -C ou --demangle a été activée.

@fichier
Lit les options de ligne de commande depuis fichier. Les options lues sont insérées à la place de l'option @fichier d'origine. Si fichier n'existe pas ou ne peut pas être lu, alors l'option sera traitée littéralement et non supprimée.

Les options dans fichier sont séparées par des espaces. Un caractère d'espace blanc peut être inclus dans une option en entourant l'option entière de guillemets simples ou doubles. N'importe quel caractère (y compris un antislash) peut être inclus en faisant précéder le caractère à inclure d'un antislash. Le fichier peut lui-même contenir d'autres options @fichier ; toutes ces options seront traitées

ppc64le-elf-addr2line(1)

NOM

addr2line - convertir les adresses en noms de fichiers, adresses et décalages de lignes.

SYNTAXE

ppc64le-elf-addr2line [-a | --all] [-b | --demangle] [-e executable] [-i | --inlines] [-j | --section-symbols] [-p | --pretty-print] [-R | --read-file] [-C | --demangle] [-f | --functions] [-l | --line-numbers] [-s name] [-v | --version] [--help] [--target=BFD_name] address...

DESCRIPTION

L'utilitaire addr2line utilise la table des symboles d'un fichier objet (par défaut, le fichier objet a.out) pour convertir les adresses des objets en noms de fichiers, adresses et décalages de lignes.

Si vous utilisez l'option -l, addr2line tentera de trouver le nom du fichier source et le numéro de ligne correspondant à l'adresse spécifiée. Si vous utilisez l'option -f, addr2line affichera également le nom de la fonction.

Si aucun nom de fichier n'est spécifié, addr2line lira à partir de l'entrée standard.

Les adresses peuvent être spécifiées en hexadécimal, avec ou sans le préfixe 0x.

Les options sont les suivantes :

-a, --all
Afficher toutes les adresses correspondantes. Par défaut, seul le premier symbole correspondant est affiché.
-b, --demangle
Démangler les noms de fonctions C++. Par défaut, les noms sont affichés tels qu'ils se trouvent dans la table des symboles.
-e executable
Spécifie le fichier objet à utiliser. Par défaut, ce fichier est a.out.
-i, --inlines
Afficher les informations sur les fonctions en ligne, en plus des informations sur les fonctions non en ligne. Si l'adresse correspond à une fonction en ligne, les informations sur la fonction parente seront également affichées.
-j, --section-symbols
Afficher les symboles de section. Utile pour déboguer les programmes avec plusieurs sections.
-p, --pretty-print
Afficher la sortie dans un format plus lisible. Ceci est utile lorsque vous n'utilisez pas l'option -l.
-R, --read-file
Lire le nom du fichier source à partir d'un fichier. Ceci est utile lorsque vous souhaitez spécifier un nom de fichier source qui contient des espaces ou d'autres caractères spéciaux.
-C, --demangle
Démangler les noms de fonctions C++. Identique à -b.
-f, --functions
Afficher le nom de la fonction correspondant à l'adresse donnée. Par défaut, le nom de la fonction n'est pas affiché.
-l, --line-numbers
Afficher le nom du fichier source et le numéro de ligne correspondant à l'adresse donnée. Par défaut, le nom du fichier source et le numéro de ligne ne sont pas affichés.
-s name
Spécifie un nom de section à rechercher. Par défaut, toutes les sections sont recherchées.
-v, --version
Afficher les informations de version de addr2line et quitter.
--help
Afficher un message d'aide et quitter.
--target=BFD_name
Spécifie le format du fichier objet. Par défaut, le format est déduit automatiquement du fichier objet.
