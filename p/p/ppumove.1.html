ppumove(1) Mouvement d'unités FPC ppumove(1)

NOM

ppumove - Le mouvementeur d'unités Pascal FPC.

SYNTAXE

ppumove [-sqbhw] [-o Fichier] [-d chemin] [-e extension] fichiers...

Description

ppumove collecte une ou plusieurs unités Pascal Free Pascal et les archive dans une bibliothèque statique ou dynamique.

Utilisation

Vous pouvez invoquer ppumove avec comme seul argument requis le nom de l'unité à partir de laquelle vous souhaitez créer une archive. La spécification de plusieurs fichiers est également possible, ils seront placés dans la même archive.

Options

ppumove possède plusieurs options, qui sont sensibles à la casse :

-b
Cette option indique à ppumove d'écrire un script shell (un fichier batch sous DOS) qui effectue les appels nécessaires à ar et ld. Le script sera appelé pmove, avec une extension .sh sous Linux, et .bat sous DOS. Vous pouvez ensuite appeler ce script manuellement.
-d chemin
Cette option indique à ppumove où générer les nouveaux fichiers d'unités. Par défaut, c'est le même répertoire que celui où se trouvent les fichiers. Si vous spécifiez comme extension de sortie la même extension que les unités que vous souhaitez déplacer, ne pas spécifier le répertoire de destination peut causer des problèmes.
-e ext
Cette option définit l'extension des nouveaux fichiers d'unités à ext. Par défaut, .ppl est utilisé. Cependant, vous pouvez spécifier .ppu comme extension. Si vous le faites, assurez-vous d'utiliser également le commutateur -d, sinon vous écraserez les anciennes unités. Notez cependant que le compilateur ne recherchera que les extensions .ppu et .ppl lors de la recherche d'unités.
-h
Affiche un bref écran d'aide.
-o fichier
Cette option vous permet de spécifier le nom de la bibliothèque à générer. Vous devez utiliser cette option si vous spécifiez plus d'une unité sur la ligne de commande. Si vous n'avez spécifié qu'une seule unité sur la ligne de commande, la bibliothèque générée portera le nom de l'unité, avec lib préfixé (sous Linux). Vous n'avez pas besoin de spécifier la partie lib, elle sera ajoutée automatiquement si nécessaire.
-q
Indique à ppumove de fonctionner silencieusement.
-s
Indique à ppumove de générer une bibliothèque statique. Par défaut, une bibliothèque dynamique est générée (sauf sous DOS).
-w
Indique à ppumove qu'il doit utiliser l'éditeur de liens et l'archiveur de Windows. N'utilisez pas cette option sous Linux.
