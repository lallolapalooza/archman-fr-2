sous-programme cppsv (caractère uplo, entier n, entier nrhs, complexe, dimension( * ) ap, complexe, dimension( ldb, * ) b, entier ldb, entier info)

CPPSV calcule la solution du système d'équations linéaires A * X = B pour les matrices AUTRES

Objectif :

!>
!> CPPSV calcule la solution d'un système d'équations linéaires complexes
!>    A * X = B,
!> où A est une matrice hermitienne positive définie de taille N x N stockée
!> au format compact et où X et B sont des matrices de taille N x NRHS.
!>
!> La décomposition de Cholesky est utilisée pour factoriser A comme suit :
!>    A = U**H * U,  si UPLO = 'U', ou
!>    A = L * L**H,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et L est une matrice triangulaire inférieure.
!> La forme factorisée de A est ensuite utilisée pour résoudre le système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CARACTERE*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est ENTIER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

NRHS

!>          NRHS est ENTIER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

AP

!>          AP est un tableau COMPLEXE, de dimension (N*(N+1)/2)
!>          À l'entrée, le triangle supérieur ou inférieur de la matrice hermitienne
!>          A, stocké de manière compacte dans un tableau linéaire. La j-ème colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.
!>
!>          À la sortie, si INFO = 0, le facteur U ou L de la décomposition de Cholesky
!>          A = U**H*U ou A = L*L**H, dans le même format de stockage que A.
!>

B

!>          B est un tableau COMPLEXE, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice B des membres de droite de taille N x NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N x NRHS.
!>

LDB

!>          LDB est ENTIER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est ENTIER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était illégal
!>          > 0 : si INFO = i, le mineur principal de tête d'ordre i
!>                de A n'est pas positif, donc la factorisation n'a pas pu
!>                être terminée, et la solution n'a pas été calculée.
!>

!>  lorsque N = 4, UPLO = 'U' :
!>
!>  Stockage bidimensionnel de la matrice hermitienne A :
!>
!>     a11 a12 a13 a14
!>         a22 a23 a24
!>             a33 a34     (aij = conjg(aji))
!>                 a44
!>
!>  Stockage compact du triangle supérieur de A :
!>
!>  AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
!>

NAME

sppsv, zppsv - routines for solving systems of linear equations with packed symmetric or Hermitian matrices

SYNOPSIS

subroutine sppsv (character uplo, integer n, integer nrhs, real, dimension( * ) ap, real, dimension( ldb, * ) b, integer ldb, integer info)
subroutine zppsv (character uplo, integer n, integer nrhs, complex*16, dimension( * ) ap, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

Detailed Description

SPPSV computes the solution to system of linear equations A * X = B for OTHER matrices

Purpose:

!>
!> SPPSV computes the solution to a real system of linear equations
!>    A * X = B,
!> where A is an N-by-N symmetric positive definite matrix stored in
!> packed format and X and B are N-by-NRHS matrices.
!>
!> The Cholesky decomposition is used to factor A as
!>    A = U**T* U,  if UPLO = 'U', or
!>    A = L * L**T,  if UPLO = 'L',
!> where U is an upper triangular matrix and L is a lower triangular
!> matrix.  The factored form of A is then used to solve the system of
!> equations A * X = B.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!>

N

!>          N is INTEGER
!>          The number of linear equations, i.e., the order of the
!>          matrix A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrix B.  NRHS >= 0.
!>

AP

!>          AP is REAL array, dimension (N*(N+1)/2)
!>          On entry, the upper or lower triangle of the symmetric matrix
!>          A, packed columnwise in a linear array.  The j-th column of A
!>          is stored in the array AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
!>          See below for further details.
!>
!>          On exit, if INFO = 0, the factor U or L from the Cholesky
!!>          factorization A = U**T*U or A = L*L**T, in the same storage
!>          format as A.
!>

B

!>          B is REAL array, dimension (LDB,NRHS)
!>          On entry, the N-by-NRHS right hand side matrix B.
!>          On exit, if INFO = 0, the N-by-NRHS solution matrix X.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, the leading principal minor of order i
!>                of A is not positive, so the factorization could not
!>                be completed, and the solution has not been computed.
!>
