NOM

Ppmcheckpdf - Tests de régression basés sur des images pour les paquets LaTeX

SYNTAXE

ppmcheckpdf <action> [<option>]

DESCRIPTION

Ppmcheckpdf facilite l'exécution de tests de régression basés sur des images pour les paquets LaTeX, à partir de fichiers PDF générés par l3build ou d'autres outils.

Les actions ppmcheckpdf les plus couramment utilisées sont :

check, --check
Exécute les tests sans sauvegarder les sorties des tests échoués
save, --save
Exécute les tests et sauvegarde les sorties des tests échoués
help, --help
Affiche un message d'aide et quitte
version, --version
Affiche les informations de version et quitte

OPTIONS

Diverses options s'appliquent.

-c
Définit la configuration utilisée pour l'action check ou save

BOGUES

Veuillez signaler les problèmes sur https://github.com/lvjr/ppmcheckpdf/issues
