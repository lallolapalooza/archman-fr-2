PPTPCTRL(8) Manuel du gestionnaire système PPTPCTRL(8)

NOM

pptpctrl - gestionnaire de connexion de contrôle PPTP

SYNTAXE

pptpctrl flag-debug-pptp flag-no-ipparam valeur-options-ppp valeur-vitesse-ppp valeur-ip-local-ppp valeur-ip-distant-ppp [ id-appel-pptp ] [ binaire-ppp ] [ logwtmp-pptp ]

DESCRIPTION

pptpctrl est généralement exécuté par pptpd(8), mais peut également être exécuté depuis inetd(8) si certaines des fonctionnalités de pptpd(8), telles que la gestion des pools d'adresses IP et les enveloppes TCP intégrées, ne sont pas requises.

OPTIONS

Les options de pptpctrl sont peu conventionnelles, car elles sont conçues pour être utilisées par pptpd(8) plutôt que par les utilisateurs. L'ordre des options est critique. Les options de drapeau consistent en un 0 ou un 1, et doivent être présentes. Les options de valeur consistent en un 0, ou un 1 suivi de la valeur. Soit le 0, soit le 1 et la valeur doivent être présents. Les options restantes sont facultatives, mais doivent être présentes dans l'ordre défini. Les options sont les suivantes :

flag-debug-pptp
s'il est défini (1), active les messages de débogage vers syslog depuis pptpctrl. Ceci n'a aucun effet sur le paramètre de l'option de débogage PPP.
flag-no-ipparam
s'il est défini, pptpctrl ne transmettra pas l'adresse IP du client à pppd(8) en utilisant l'option ipparam. Voir l'option noipparam dans pptpd.conf(5).
valeur-options-ppp
fichier à utiliser pour les options PPP. Voir l'option file dans pppd(8).
valeur-vitesse-ppp
valeur pour l'option speed donnée à pppd(8). Notez que sous Linux, ce paramètre est inefficace.
valeur-ip-local-ppp
s'il est défini, spécifie l'adresse IP que pppd(8) doit utiliser pour l'interface réseau sur le serveur. S'il n'est pas défini, pppd(8) la déterminera en fonction des options ; il s'agira généralement de l'adresse Ethernet du serveur.
valeur-ip-distant-ppp
s'il est défini, spécifie l'adresse IP que pppd(8) doit utiliser pour l'interface réseau sur le client. S'il n'est pas défini, pppd(8) la déterminera en fonction des options ; il s'agira généralement de l'adresse Ethernet du client, ou d'une adresse spécifiée dans chap-secrets. Doit être défini si valeur-ip-local-ppp est défini.
id-appel-pptp
s'il est présent, spécifie l'identifiant d'appel pour la session PPTP. S'il est omis, l'identifiant d'appel est zéro. Normalement, l'ID est alloué par pptpd(8) et passé à pptpctrl.
binaire-ppp
s'il est présent, chemin vers le binaire PPP à utiliser. S'il est omis, la valeur par défaut est utilisée.
logwtmp-pptp
s'il est présent, spécifie si wtmp(5) doit être mis à jour lors de la connexion et de la déconnexion des utilisateurs.
