NOM

ppl_pips - solveur de problèmes de programmation entière paramétrique basé sur PPL

SYNTAXE

ppl_pips [OPTION]... [FICHIER]

DESCRIPTION

Lit la définition d'un problème de programmation entière paramétrique et affiche le minimum lexicographique en termes des valeurs des paramètres.

OPTIONS

-RMB, --max-memory=MO
limite l'utilisation de la mémoire à MO méga-octets
-h, --help
affiche ce texte d'aide sur la sortie standard
-oPATH, --output=CHEMIN
ajoute la sortie à CHEMIN
-P, --polylib
lit le problème au format PolyLib (par défaut)
-p, --piplib
lit le problème au format PipLib
-t, --timings
affiche les temps d'exécution sur la sortie d'erreur standard
-v, --verbose
produit beaucoup de sortie
-i, --iterations=N
exécute la résolution N fois (par défaut=1)
-V, --version
-cPATH, --check=CHEMIN
vérifie si le résultat est égal à ce qui se trouve dans CHEMIN

Options de génération de découpes :

-f, --cut-first
utilise la première ligne non entière (par défaut)
-d, --cut-deepest
essaie de générer la découpe la plus profonde
-a, --cut-all
génère toujours toutes les découpes possibles

Options de stratégie de ligne de pivot :

-F, --row-first
utilise la première ligne avec un paramètre négatif (par défaut)
-M, --row-max
choisit la ligne générant la colonne de pivot lexicographiquement maximale

DISPONIBILITÉ

La dernière version de la Parma Polyhedra Library et toute la documentation est disponible à l'adresse http://bugseng.com/products/ppl/ .

NOTES

Les options -CSECS (--max-cpu=SECS) et -t (--timings) ne sont pas disponibles sur certaines plateformes.

Le format PolyLib est le suivant :

-
La première ligne décrit la matrice de contexte (c'est-à-dire les contraintes sur les paramètres). La première valeur est le nombre de lignes (qui peut être zéro) et la seconde valeur est le nombre de colonnes. Le nombre de paramètres est le nombre de colonnes moins 2.
-
À partir de la deuxième ligne, il y a les lignes de la matrice de contexte, le cas échéant. Chaque ligne, qui représente une contrainte de la forme c1*p1 + ... + cn*pn + c0 =/>= 0 , contient : la valeur 0 si la contrainte est une égalité, 1 si c'est une inégalité ; les coefficients des paramètres c1, ..., cn ; le terme constant c0 . Par exemple, la contrainte d'inégalité sur deux paramètres p1 + 2*p2 - 1 >= 0 est encodée par la ligne 1 1 2 -1 .
-
La ligne suivante contient le numéro du paramètre pour le soi-disant paramètre principal. Si aucun paramètre principal n'est utilisé, la valeur est -1.
-
Les lignes suivantes encodent la matrice d'inégalité du problème. Comme pour la matrice de contexte, les deux premières valeurs sont les dimensions de la matrice. Le nombre de variables est le nombre de colonnes de la matrice moins le nombre de paramètres moins 2. Chaque ligne, qui représente une contrainte de la forme d1*v1 + ... + dm*vm + c1*p1 + ... + cn*pn + c0 =/>= 0 , contient : la valeur 0 si la contrainte est une égalité, 1 si c'est une inégalité ; les coefficients des variables d1, ..., dm ; les coefficients des paramètres c1, ..., cn ; le terme constant c0 .

Le format PipLib est décrit dans la section 2.2 de PIP/PipLib: A Solver for Parametric Integer Programming Problems (voir ci-dessous).
