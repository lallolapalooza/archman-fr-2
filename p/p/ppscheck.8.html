NOM

ppscheck - outil pour vérifier un port série pour le PPS

SYNTAXE

ppscheck [-?] [--help] [-p] [--pps] [--version] [-h] [-V]

ppscheck [-m] appareil

DESCRIPTION

ppscheck surveille un port série spécifié pour les transitions qui pourraient être du PPS. Il recherche les changements dans les lignes de négociation CD, CTS, DSR et RI en exécutant ioctl(...., TIOCMIWAIT, ...) dans une boucle. Lorsqu'il voit un changement d'état, il émet une ligne de sortie horodatée décrivant l'état des signaux de négociation. Il est utile pour vérifier si un appareil émet du PPS.

ppscheck peut être exécuté par un utilisateur normal, mais cet utilisateur doit avoir les permissions de lire l'appareil cible. L'exécution sous sudo peut fonctionner ou non. L'exécution en tant que root fonctionnera toujours.

Pour vérifier le premier port série, faites ceci :

# ppscheck /dev/ttyS0

En tant qu'effet secondaire, ppscheck tentera de créer l'appareil /dev/ppsX correspondant en définissant la discipline de ligne (ldisc) du tty sur N_PPS (18). Vous devriez alors avoir un appareil /dev/pps0. Notez que tous les appareils série ne prennent pas en charge la ldisc N_PPS.

Vous pouvez maintenant utiliser ppscheck pour voir si l'interface KPPS (RFC 2783) fonctionne :

# ppscheck /dev/pps0

ppscheck n'est pas destiné à une utilisation routinière, mais plutôt à des fins de diagnostic. Une fois que vous avez vérifié qu'un appareil particulier peut émettre des signaux PPS, vous n'aurez plus jamais besoin de l'utiliser sur cet appareil.

OPTIONS

Le programme accepte les options suivantes :

-?, `-h, `--help

Affiche le message d'aide, puis quitte.

-m, `--match

Trouve l'appareil PPS qui correspond à appareil.

-p, `--pps

Affiche les appareils PPS actifs, puis quitte.

-V, `--version

Affiche la version, puis quitte.

-x SEC, --seconds SEC

Quitte après un délai de SEC secondes.

ARGUMENTS

L'argument appareil doit être le chemin d'accès d'un appareil. Comme /dev/ttyS0 ou /dev/pps0. Ce sera l'appareil surveillé.

Pour un appareil tty, chaque ligne de sortie contient les parties seconde et nanoseconde d'un horodatage suivies des noms des signaux de négociation ensuite validés. Les transitions hors état peuvent générer des lignes sans aucun signal validé.

Pour un appareil pps, chaque ligne de sortie contiendra les temps d'assertion et d'effacement détectés pour la dernière fois par KPPS.

Si vous ne voyez aucune sortie dans la seconde, utilisez cgps, xgps, ou un autre outil équivalent pour vérifier que votre appareil a un verrouillage satellite et obtient des fixations 3D avant d'abandonner la possibilité de PPS.

Vérifiez votre câble. Les câbles DB9 vers DB9 bon marché, comme ceux fournis avec les UPS, ne transportent souvent que TXD/RXD/GND, omettant les lignes de négociation comme CD. Soupçonnez ceci surtout si la gaine du câble semble trop mince pour contenir plus de trois fils !

La plupart des GPS qui ont un USB intégré ne prennent pas en charge le PPS. En cas de doute, contactez le vendeur pour confirmation que votre appareil fournit bien du PPS.

VALEURS DE RETOUR

0

OK

1

si l'appareil n'a pas pu être ouvert, ou un autre échec
