NOM

radius.so - Module d'authentification RADIUS pour pppd(8)

SYNOPIS

pppd [ options ] plugin radius.so

DESCRIPTION

Le module RADIUS pour pppd permet à pppd d'effectuer l'authentification PAP, CHAP, MS-CHAP et MS-CHAPv2 auprès d'un serveur RADIUS au lieu des fichiers /etc/ppp/pap-secrets et /etc/ppp/chap-secrets usuels.

Le module RADIUS est basé sur une bibliothèque appelée radiusclient qui possède ses propres fichiers de configuration (généralement dans /etc/radiusclient), consultez ces fichiers pour plus d'informations sur la configuration du module RADIUS.

OPTIONS

Le module RADIUS introduit une option supplémentaire pour pppd :

radius-config-file nom_fichier
Le fichier nom_fichier est utilisé comme fichier de configuration radiusclient. Si cette option n'est pas utilisée, le module utilise /etc/radiusclient/radiusclient.conf comme fichier de configuration.
avpair attribut=valeur
Ajoute une paire Attribut-Valeur qui sera transmise au serveur RADIUS lors de chaque requête.
map-to-ifname
Définit l'attribut Radius NAS-Port à un nombre égal au nom de l'interface (Défaut).
map-to-ttyname
Définit la valeur de l'attribut Radius NAS-Port via la bibliothèque libradiusclient.

UTILISATION

Pour utiliser le module, fournissez simplement l'option plugin radius.so à pppd, et éditez /etc/radiusclient/radiusclient.conf en conséquence. Si vous utilisez le module RADIUS, les schémas d'authentification normaux de pppd (connexion, vérification des fichiers /etc/ppp/*-secrets) sont ignorés. Le serveur RADIUS devrait attribuer une adresse IP au pair en utilisant l'attribut RADIUS Framed-IP-Address.
