NOM

ppdc - compilateur ppd cups (obsolète)

SYNTAXE

ppdc [ -D nom[=valeur] ] [ -I répertoire-inclusion ] [ -c catalogue-messages ] [ -d répertoire-sortie ] [ -l langue(s) ] [ -m ] [ -t ] [ -v ] [ -z ] [ --cr ] [ --crlf ] [ --lf ] fichier-source

DESCRIPTION

ppdc compile les fichiers sources PPDC en un ou plusieurs fichiers PPD. Ce programme est obsolète et sera supprimé dans une future version de CUPS.

OPTIONS

ppdc supporte les options suivantes :

-D nom[=valeur]
Définit la variable nommée pour être utilisée dans le fichier source. Ceci est équivalent à utiliser la directive #define dans le fichier source.
-I répertoire-inclusion
Spécifie un répertoire d'inclusion alternatif. Plusieurs options -I peuvent être fournies pour ajouter des répertoires supplémentaires.
-c catalogue-messages
Spécifie un seul fichier catalogue de messages au format gettext GNU (nomfichier.po) ou Apple strings (nomfichier.strings) à utiliser pour la localisation.
-d répertoire-sortie
Spécifie le répertoire de sortie pour les fichiers PPD. Le répertoire de sortie par défaut est "ppd".
-l langue(s)
Spécifie une ou plusieurs langues à utiliser lors de la localisation des fichiers PPD. La langue par défaut est "en" (anglais). Séparez plusieurs langues par des virgules, par exemple "de_DE,en_UK,es_ES,es_MX,es_US,fr_CA,fr_FR,it_IT" créera des fichiers PPD avec les langues allemande, anglaise (RU), espagnole (Espagne, Mexique, États-Unis), française (France et Canada) et italienne dans chaque fichier.
-m
Spécifie que le nom du fichier de sortie doit être basé sur la valeur ModelName au lieu de FileName ou PCFileName.
-t
Spécifie que les fichiers PPD doivent être testés au lieu d'être générés.
-v
Spécifie une sortie détaillée, essentiellement un état d'avancement des fichiers en cours de chargement ou d'écriture. -z Génère des fichiers PPD compressés (nomfichier.ppd.gz). Par défaut, les fichiers PPD sont générés non compressés.
--cr
--crlf
--lf
Spécifie la terminaison de ligne à utiliser - retour chariot, retour chariot et saut de ligne, ou saut de ligne seul. Par défaut, seul le caractère de saut de ligne est utilisé.

NOTES

Les fichiers PPD sont obsolètes et ne seront plus pris en charge dans une future version majeure de CUPS. Les imprimantes qui ne prennent pas en charge l'IPP peuvent être prises en charge à l'aide d'applications telles que ippeveprinter(1).
