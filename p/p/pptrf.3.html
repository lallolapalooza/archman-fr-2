sous-programme cpptrf (caractère uplo, entier n, complexe, dimension( * ) ap, entier info)

CPPTRF

Objectif:

!>
!> CPPTRF calcule la factorisation de Cholesky d'une matrice A complexe, hermitienne
!> et définie positive, stockée au format compacté.
!>
!> La factorisation a la forme
!>    A = U**H * U,  si UPLO = 'U', ou
!>    A = L  * L**H,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et L une matrice triangulaire inférieure.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

AP

!>          AP est un tableau COMPLEX, de dimension (N*(N+1)/2)
!>          En entrée, le triangle supérieur ou inférieur de la matrice hermitienne
!>          A, compacté par colonnes dans un tableau linéaire. La j-ième colonne de A
!>          est stockée dans le tableau AP comme suit :
!>          si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;
!>          si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.
!>          Voir ci-dessous pour plus de détails.
!>
!>          En sortie, si INFO = 0, le facteur triangulaire U ou L de la
!>          factorisation de Cholesky A = U**H*U ou A = L*L**H, dans le même
!>          format de stockage que A.
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument était illégal
!>          > 0 : si INFO = i, le mineur principal de tête d'ordre i
!>                n'est pas défini positif, et la factorisation n'a pas pu
!>                être complétée.
!>

Auteur

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Détails supplémentaires:

!>
!>  Le schéma de stockage compacté est illustré par l'exemple suivant
!>  quand N = 4, UPLO = 'U' :
!>
!>  Stockage bidimensionnel de la matrice hermitienne A :
!>
!>     a11 a12 a13 a14
!>         a22 a23 a24
!>             a33 a34     (aij = conjg(aji))
!>                 a44
!>
!>  Stockage compacté du triangle supérieur de A :
!>
!>  AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
!>

Définition à la ligne 118 du fichier cpptrf.f.

NAME

                    
pptrf - computes the Cholesky factorization of a
                        real symmetric positive definite matrix stored in packed
                        format.

                

                

                    
SYNOPSIS

                    
​subroutine       pptrf (character uplo, integer n, real, dimension( * ) ap, integer   info)

                

                

                    
Description

                    
This subroutine computes the Cholesky factorization
                        of a real symmetric positive definite matrix stored in packed
                        format.

                    
The factorization has the form

                    
A = U**T * U,  if UPLO = 'U', or
A = L  * L**T,  if UPLO = 'L',


                    
where U is an upper triangular matrix and L is a
                        lower triangular matrix.

                

                

                    
Parameters

                    
UPLO

                    
UPLO is CHARACTER*1
​           = 'U':  Upper triangle of A is stored;
​           = 'L':  Lower triangle of A is stored.


                    
N

                    
N is INTEGER
​           The order of the matrix A.  N >= 0.


                    
AP

                    
AP is REAL array, dimension (N*(N+1)/2)
​           On entry, the upper or lower triangle of the symmetric matrix
​           A, packed columnwise in a linear array.  The j-th column of A
​           is stored in the array AP as follows:
​           if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
​           if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
​           See below for further details.
​           On exit, if INFO = 0, the triangular factor U or L from the
​           Cholesky factorization A = U**T*U or A = L*L**T, in the same
​           storage format as A.


                    
INFO

                    
INFO is INTEGER
​           = 0:  successful exit
​           < 0:  if INFO = -i, the i-th argument had an illegal value
​           > 0:  if INFO = i, the leading principal minor of order i
​                 is not positive, and the factorization could not be
​                 completed.


                

                

                    
Author

                    
Univ. of Tennessee

                    
Univ. of California Berkeley

                    
Univ. of Colorado Denver

                    
NAG Ltd.

                

                

                    
Further Details

                    
​ The packed storage scheme is illustrated by the following example
​ when N = 4, UPLO = 'U':
​
​ Two-dimensional storage of the symmetric matrix A:
​
​    a11 a12 a13 a14
​        a22 a23 a24
​            a33 a34     (aij = aji)
​                a44
​
​ Packed storage of the upper triangle of A:
​
​ AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
​

subroutine zpptrf (character uplo, integer n, complex*16, dimension( * ) ap, integer info)

                    
ZPPTRF

                    
Purpose:

                    

                        
ZPPTRF computes the Cholesky factorization of a complex Hermitian
positive definite matrix A stored in packed format.

The factorization has the form
   A = U**H * U,  if UPLO = 'U', or
   A = L  * L**H,  if UPLO = 'L',
where U is an upper triangular matrix and L is lower triangular.


                    

                    
Parameters

                    
UPLO
                        
UPLO is CHARACTER*1
          = 'U':  Upper triangle of A is stored;
          = 'L':  Lower triangle of A is stored.


                        
N

                        
N is INTEGER
          The order of the matrix A.  N >= 0.


                        
AP

                        
AP is COMPLEX*16 array, dimension (N*(N+1)/2)
          On entry, the upper or lower triangle of the Hermitian matrix
          A, packed columnwise in a linear array.  The j-th column of A
          is stored in the array AP as follows:
          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
          See below for further details.

          On exit, if INFO = 0, the triangular factor U or L from the
          Cholesky factorization A = U**H*U or A = L*L**H, in the same
          storage format as A.


                        
INFO

                        
INFO is INTEGER
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
          > 0:  if INFO = i, the leading principal minor of order i
                is not positive, and the factorization could not be
                completed.


                    

                    
Author

                    
Univ. of Tennessee
                        
Univ. of California Berkeley

                        
Univ. of Colorado Denver

                        
NAG Ltd.

                    

                    
Further Details:

                    

                        
The packed storage scheme is illustrated by the following example
when N = 4, UPLO = 'U':

Two-dimensional storage of the Hermitian matrix A:

   a11 a12 a13 a14
       a22 a23 a24
           a33 a34     (aij = conjg(aji))
               a44

Packed storage of the upper triangle of A:

AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
