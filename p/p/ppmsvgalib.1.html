NOM

ppmsvgalib - afficher une image PPM sur la console Linux en utilisant Svgalib

SYNTAXE

ppmsvgalib

[-mode=mode]

Toutes les options peuvent être abrégées à leur plus court préfixe unique. Vous pouvez utiliser deux traits d'union au lieu d'un pour désigner une option. Vous pouvez utiliser soit un espace blanc, soit un signe égal entre le nom d'une option et sa valeur.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

ppmsvgalib affiche une image PPM sur une console virtuelle Linux en utilisant la fonctionnalité Svgalib. Svgalib est un moyen populaire d'afficher des graphiques sous Linux sans utiliser le système X Window. (Pour afficher une image Netpbm dans une fenêtre X, voir pamx).

Si vous exécutez ppmsvgalib avec une version de Svgalib antérieure à 1.9, vous devez l'exécuter avec la capacité CAP_SYS_RAWIO (sur la plupart des systèmes Linux, cela signifie que vous l'exécutez en tant que superutilisateur), car Svgalib utilise l'appel système ioperm() pour accéder au matériel de la console. Svgalib plus récent possède son propre pilote de périphérique, vous n'avez donc besoin que des permissions appropriées sur un fichier spécial de périphérique pour accéder à la console.

ppmsvgalib n'est pas capable d'utiliser les modes vidéo à palette de couleurs. Ce sont les anciens modes vidéo généralement appelés modes couleur '8 bits'.

ppmsvgalib est un simple afficheur. Il n'effectuera aucune manipulation de l'image et n'est interactif d'aucune manière. Si vous souhaitez un spectateur graphique interactif régulier utilisant Svgalib, essayez zgv (non inclus dans Netpbm).

Pour quitter ppmsvgalib pendant qu'il affiche votre image, envoyez-lui un signal SIGINT (normalement, cela signifie 'appuyez sur Control C').

ppmsvgalib dessine une bordure blanche autour des bords de l'écran. Il le fait pour vous aider à isoler les problèmes entre l'image que vous affichez et les fonctionnalités que vous utilisez pour l'afficher.

(Note : si l'image que vous affichez atteint les bords de l'écran, elle remplacera la bordure blanche).

ppmsvgalib place l'image au centre de l'écran.

Si votre image est trop grande pour être affichée dans le mode vidéo que vous avez sélectionné, ppmsvgalib échoue. Vous pouvez utiliser pamcut pour découper une partie de l'image à afficher ou utiliser pamscale pour réduire l'image afin qu'elle tienne.

Si vous voulez expérimenter avec ppmsvgalib, ppmcie est un bon moyen de générer une image de test.

Pour être pédant, nous devons observer que ppmsvgalib affiche une image PPM dans les bonnes couleurs uniquement si l'écran possède une fonction de transfert qui est l'inverse exact de la fonction gamma spécifiée dans la spécification PPM. Heureusement, la plupart des écrans CRT et les écrans modernes qui les émulent sont assez proches.

Passer l'image PPM à travers pnmgamma peut aider ppmsvgalib à afficher les bonnes couleurs.

OPTIONS

-mode=mode
Ceci indique à ppmsvgalib quel mode vidéo utiliser. mode est le numéro de mode vidéo Svgalib. Vous pouvez obtenir une liste de tous les modes vidéo et de leurs numéros de mode vidéo Svgalib avec le programme vgatest qui est fourni avec Svgalib. (Malheureusement, les divers programmes intéressants fournis avec Svgalib ne sont généralement pas installés sur les systèmes qui ont la bibliothèque Svgalib installée).

En pratique, il n'y a probablement que deux modes qui vous intéresseront : 25 est le mode couleur directe SVGA standard, qui est de 1024 colonnes par 768 lignes avec 8 bits de composants rouge, vert et bleu pour chaque pixel et aucune option fantaisiste. 28 est identique, mais avec la résolution plus élevée populaire de 1280 x 1024.

Mais si vous avez une ancienne carte vidéo (avec moins de 4 Mo de mémoire), ces modes ne sont pas disponibles, vous pourriez aimer le mode 19, qui est 640 x 480 et nécessite moins d'un mégaoctet de mémoire vidéo. C'est un mode vidéo VGA standard.
