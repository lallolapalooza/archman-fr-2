ppdep(1) Suivi des dépendances des unités Pascal FPC ppdep(1)

NOM

ppdep - Le programme de suivi des dépendances des unités Pascal FPC.

SYNTAXE

ppdep [-DDefine] [-oFichier] [-eExtension] [-V] [-h] [A[appel]] fichier

DESCRIPTION

ppdep affiche les dépendances d'une unité dans un format compréhensible par GNU make. Il écrit ces dépendances sur la sortie standard. Il prend en compte les dépendances dans les sections d'interface et d'implémentation de l'unité, et il peut gérer les définitions conditionnelles.

UTILISATION

Vous pouvez invoquer ppdep avec comme seul argument requis le nom du fichier (programme ou unité) dont vous souhaitez lister les dépendances. Vous n'avez pas besoin de spécifier une extension, par défaut .pp est supposé.

OPTIONS

ppdep possède plusieurs options, qui ne sont pas sensibles à la casse :

-aappel
Cette option indique à ppdep de générer un appel de compilateur pour le makefile. L'appel de compilateur sera généré pour chaque fichier trouvé dans le répertoire courant. Si vous ne spécifiez pas d'appel de compilateur explicite, ppc386 est utilisé.
-dmot-clé
Cette option définit mot-clé qui peut être utilisé pour vérifier les définitions conditionnelles. ppdep comprend les définitions conditionnelles, vous devriez utiliser ce paramètre si la clause uses des programmes ou des unités peut contenir des définitions conditionnelles.
-eextension
Ceci vous permet de spécifier une extension différente pour les fichiers d'unité. Par défaut, .ppu est supposé. Cette extension est écrite dans le makefile.
-f[appel]
Cette option indique à ppdep de générer un appel de compilateur pour le makefile. L'appel de compilateur sera généré uniquement pour le fichier spécifié dans la ligne de commande de ppdep. Si vous souhaitez générer un appel de compilateur pour chaque fichier trouvé, utilisez l'option -a. Si vous ne spécifiez pas d'appel de compilateur explicite, ppc386 est utilisé.
-h
Affiche un écran d'aide court.
-ofichier
Cette option vous permet de spécifier un fichier dans lequel les dépendances devraient être écrites. Par défaut, les dépendances sont écrites sur la sortie standard. Si vous spécifiez cette option, les dépendances sont écrites dans fichier

à la place.

-v
Écrit des messages de diagnostic. Si vous utilisez cette option, assurez-vous d'utiliser également -o, car les messages de diagnostic seront également écrits sur la sortie standard.
