NOM

ppmdither - tramage ordonné pour images couleur

SYNTAXE

ppmdither

[-dim=puissance]

[-red=n]

[-green=n]

[-blue=n]

[fichier netpbm]

Toutes les options peuvent être abrégées à leur préfixe unique le plus court. Vous pouvez utiliser deux tirets au lieu d'un pour désigner une option. Vous pouvez utiliser soit un espace blanc, soit un signe égal entre un nom d'option et sa valeur.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

ppmdither lit une image Netpbm en entrée et applique un tramage pour réduire le nombre de couleurs utilisées au nombre spécifié de nuances pour chaque primaire. Il produit une image PPM en sortie.

Le nombre par défaut de nuances est 5 pour le rouge, 9 pour le vert et 5 pour le bleu, pour un total de 225 couleurs. Pour convertir l'image dans un format binaire RVB adapté aux imprimantes couleur primitives, utilisez -red=2 -green=2 -blue=2.

Vous pouvez effectuer un autre type de tramage -- Floyd-Steinberg -- avec pnmquant ou pnmremap.

OPTIONS

-dim puissance

La taille de la matrice de tramage. La matrice de tramage est un carré dont la dimension est une puissance de 2. puissance est cette puissance de 2. La valeur par défaut est 4, pour une matrice de 16 par 16.
-red=n
Le nombre de nuances de rouge à utiliser, y compris le noir ; minimum 2.

Par défaut : 5.

-green n
Le nombre de nuances de vert à utiliser, y compris le noir ; minimum 2.

Par défaut : 9.

-blue n
Le nombre de nuances de bleu à utiliser, y compris le noir ; minimum 2.

Par défaut : 5.
