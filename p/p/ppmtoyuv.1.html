NOM

ppmtoyuv - convertir une image PPM en fichier YUV Abekas

SYNTAXE

ppmtoyuv [fichier_ppm]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

ppmtoyuv lit une image PPM en entrée et produit un fichier YUV Abekas en sortie.

Le fichier de sortie contient une grille de codes YUV de quatre octets, chacun étant unique et associé à deux pixels côte à côte dans l'image. La grille contient les lignes dans l'ordre, de haut en bas, et à l'intérieur de chaque ligne, les colonnes de gauche à droite. La taille du fichier de sortie en octets est donc deux fois le nombre de pixels de l'image.

Chaque code YUV est associé à deux pixels de l'image d'entrée que nous appellerons le pixel de gauche et le pixel de droite. Le 2ème octet du code est la valeur Y du pixel de gauche. Le 4ème octet du code est la valeur Y du pixel de droite. Le 1er octet du code est une moyenne de la valeur U du pixel *à gauche du pixel de gauche*, du pixel de gauche et du pixel de droite. Le 3ème octet du code est analogue pour les valeurs V. Ces moyennes sont des moyennes arithmétiques pondérées où le pixel de gauche est pondéré doublement par rapport aux deux autres pixels.

Ce format rappelle le format YUV 4:2:0 courant (alias YUV 420) et les formats similaires YUV 4:4:4, YUV 4:2:2, YUV 4:1:1, YUV 4:1:1s et YUV 4:1:0, mais en est assez différent. En YUV 4:2:0, la grille est différente pour les lignes paires et impaires. Sur les lignes paires, il y a deux fois plus de bits pour le Y de chaque pixel que pour le U ou le V. Sur les lignes impaires, il y a le même nombre de bits pour le Y que sur les lignes paires, mais aucun bit pour le U et le V.

Un autre format basé sur YUV est YUV4MPEG2, qui est un format de film normalement utilisé avec MJPEGTools . Netpbm n'a pas de convertisseurs pour ce format, mais MJPEGTools en a.
