NOM

pppusage - générer des résumés de connexion PPP

SYNOPSIS

pppusage [-bcq] [-f datafile] [-t aaaa[mm[jj]][-aaaa[mm[jj]]]] [logfile...]

pppusage [-hv]

DESCRIPTION

pppusage résume les volumes de transfert moyens et totaux, le nombre de connexions et le temps moyen et total en ligne pour toutes les connexions PPP enregistrées. Les données sont collectées en lisant les fichiers journaux logfile qui contiennent les messages de ppp[d]. Plusieurs fichiers journaux logfile (c'est-à-dire les fichiers journaux ppp[d] actifs et archivés) peuvent être lus afin de s'assurer que les nouvelles entrées ppp[d] ne sont pas manquées lorsque le fichier journal pertinent est archivé avant que pppusage n'ait vu les entrées. Cependant, veuillez voir "CAVEATS" ci-dessous ! pppusage sauvegarde les données pertinentes dans datafile (une base de données Berkeley DB) qui peut être mise à jour automatiquement à intervalles réguliers en utilisant cron(5) ou quelque chose de similaire.

OPTIONS

Par défaut, pppusage effectue les quatre étapes : Il analyse les fichiers journaux système PPP, sauvegarde les données, lit les données sauvegardées et affiche les résumés pour toutes les données disponibles. Vous pouvez séparer la construction de la base de données d'une part, et sa requête d'autre part, en utilisant certaines des options suivantes.

-b
Ne pas utiliser les couleurs et attributs ANSI pour la sortie de pppusage.
-c
Analyser les fichiers journaux système PPP, mettre à jour le fichier de base de données Berkeley DB (ou le créer s'il n'existe pas), et quitter. Cette option est particulièrement utile si vous souhaitez que la base de données soit mise à jour automatiquement en arrière-plan à intervalles réguliers. Par exemple : 
05 14 * * * nice /usr/bin/core_perl/pppusage -c > /dev/null

Cette entrée crontab(5) mettrait à jour la base de données une fois par jour (à 14h05).

-f datafile
Spécifier le fichier de base de données qui doit être utilisé par pppusage.
-q
Interroger la base de données : Lire le fichier de base de données et afficher les résumés. Si la plage de temps n'est pas spécifiée avec -t, toutes les données disponibles seront traitées.
-h
Afficher un bref aperçu de toutes les options disponibles et quitter.
-t aaaa[mm[jj]][-<aaaa>[mm[jj]]]
Spécifier la période de temps pour une requête. Ceci peut être fait soit en spécifiant une seule année, mois ou jour, soit en spécifiant une plage de temps. Une plage de temps est utilisée en spécifiant deux dates, séparées par un `-'. L'ordre dans lequel les deux dates sont données est sans importance. Toute combinaison de jours, mois ou années peut être spécifiée. Implique -q.
-v
Afficher les informations de version et quitter.

CONFIGURATION

Le fichier de configuration utilisé par pppusage est simplement un fichier perl qui est lu au démarrage. Les fichiers journaux à analyser et le fichier de base de données à utiliser peuvent être ajustés en définissant les variables suivantes. Cependant, les spécifier sur la ligne de commande remplacera ces paramètres. Les valeurs par défaut sont indiquées entre crochets.

$logfiles = 'logfile...'; [`ls /var/log/messages*`]
Les fichiers journaux logfile de ppp[d] à analyser. Une liste séparée par des espaces doit être utilisée pour spécifier plusieurs fichiers. Notez que si vous spécifiez les fichiers à analyser directement (par opposition à l'utilisation de la sortie d'une commande comme ls), vous devez utiliser des guillemets normaux (""), pas des apostrophes inverses (``) !
$datafile = 'datafile'; ['/tmp/pppusage.db']
Le fichier qui est utilisé par pppusage pour stocker ses données. Normalement, il est judicieux de définir cela sur un chemin différent, surtout si le répertoire /tmp est effacé de temps en temps (par exemple, par un travail cron(5) ou au démarrage).
$configured = 0|1; [0]
Oubliez ceci. Nous en avions besoin pour nous assurer que ceux d'entre vous qui ont mis à niveau à partir d'anciennes versions de pppusage ont défini $logfiles correctement en les forçant à ouvrir le fichier de configuration et à définir $configured sur 1 ;-) En fait, vous pouvez simplement supprimer cette variable complètement. Elle sera supprimée des futures versions de pppusage.

EXEMPLES

pppusage

Analyse les fichiers journaux système sur lesquels ppp[d] enregistre ses messages, sauvegarde les données pertinentes dans un fichier Berkeley DB et écrit les résumés concernant toutes les données disponibles sur STDOUT.

pppusage -t 2003

Recherche dans le fichier de base de données toutes les connexions PPP enregistrées en 2003 et écrit les résultats sur STDOUT.

pppusage -t 200305

Recherche dans le fichier de base de données toutes les connexions PPP enregistrées en mai 2003 et écrit les résultats sur STDOUT.

pppusage -t 2003-200303

Recherche dans le fichier de base de données toutes les connexions PPP enregistrées au premier trimestre 2003 et écrit les résultats sur STDOUT.

pppusage -t 20030915-20030931

Recherche dans le fichier de base de données toutes les connexions PPP enregistrées dans la seconde moitié de septembre 2003 et écrit les résultats sur STDOUT.

pppusage -b -f /tmp/pppusage.2002.db -t 20020501

Recherche dans le fichier de base de données /tmp/pppusage.2002.db toutes les connexions PPP enregistrées le 1er mai 2002 et affiche les résultats sans utiliser de couleurs ou d'attributs ANSI.

FICHIERS

~/.pppusagerc
Fichier de configuration utilisateur.

/etc/pppusagerc
Fichier de configuration du système.

CAVEATS

Étant donné que pppusage essaie d'obtenir plusieurs fichiers journaux dans le bon ordre simplement en les triant par leur dernière date de modification, alimenter plusieurs fichiers journaux à pppusage produira très probablement une base de données corrompue s'ils ont été modifiés après avoir été archivés.

Encore pire : Mettre à jour une base de données existante avec des fichiers journaux contenant des données plus anciennes que les données déjà analysées ne fonctionnera pas non plus. Cela entraînerait à nouveau une base de données corrompue.

Dans les deux cas, le fichier de base de données doit être supprimé et recréé.

BUGS

Il y en a très probablement. Faites-moi savoir si vous en trouvez !
