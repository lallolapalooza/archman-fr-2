NOM

ppmlabel - ajouter du texte à une image PPM

SYNTAXE

ppmlabel

[-angle angle]

[-background { transparent | couleur } ]

[-color couleur]

[-file nom_fichier]

[-size

taille_texte]

[-text chaîne_texte]

[-x colonne]

[-y ligne]

...

[fichier_ppm]

EXEMPLE


    ppmlabel -x 50 -y 50 -text bonjour \
             -angle -30 -text le monde \
             testimg.ppm

DESCRIPTION

Ce programme fait partie de Netpbm(1)

ppmlabel utilise les facilités de dessin de texte du composant 'ppmd' de libnetpbm pour ajouter du texte à une image PBM. Vous contrôlez l'emplacement, la taille, l'angle de ligne de base, la couleur du texte et la couleur de fond (le cas échéant) à l'aide d'arguments de ligne de commande. Vous pouvez spécifier le texte sur la ligne de commande ou le fournir dans des fichiers.

Vous pouvez ajouter autant d'étiquettes distinctes que vous le souhaitez en une seule invocation de ppmlabel, limité uniquement par les restrictions de votre environnement concernant le nombre et la taille des arguments de programme (par exemple, la limite de taille de commande d'un shell).

Si vous ne spécifiez pas fichier_ppm, ppmlabel lit son image PPM d'entrée depuis l'entrée standard.

L'image de sortie va vers la sortie standard.

Une manière plus sophistiquée d'ajouter une étiquette à une image est d'utiliser pbmtext ou pbmtextps pour créer une image du texte, puis pamcomp pour la superposer sur l'image de base.

Un autre programme plus général est ppmdraw. Il est légèrement plus difficile à utiliser pour des étiquetages simples.

OPTIONS

Les arguments de la ligne de commande ppmlabel ne sont pas des options au sens strict ; ce sont des commandes qui contrôlent le placement et l'apparence du texte ajouté à l'image d'entrée. Elles sont exécutées de gauche à droite, et n'importe quel nombre d'arguments peut apparaître.

Vous pouvez abréger toute option à son préfixe unique le plus court.

-angle angle
Cette option définit l'angle de la ligne de base du texte suivant. angle est un nombre entier de degrés, mesuré dans le sens inverse des aiguilles d'une montre par rapport à l'axe des lignes de l'image.
-background { transparent | couleur }
Si l'argument est transparent, ppmlabel dessine le texte par-dessus les pixels existants dans l'image. Si vous spécifiez une couleur (voir l'option -color ci-dessous pour plus d'informations sur la façon de spécifier les couleurs), ppmlabel génère des rectangles d'arrière-plan entourant le texte suivant, et ces rectangles sont remplis de cette couleur.
-color couleur
Cette option définit la couleur du texte suivant.

Spécifiez la couleur (couleur) comme décrit pour l'argument de la routine de bibliothèque ppm_parsecolor().

-couleur est une orthographe alternative acceptable.

-file nom_fichier
Cette option fait que ppmlabel lit des lignes de texte du fichier nommé nom_fichier et les dessine sur des lignes successives.
-size taille_texte
Cette option définit la hauteur des caractères les plus hauts au-dessus de la ligne de base à taille_texte pixels.
-text chaîne_texte
Cette option fait que ppmlabel dessine la chaîne de texte spécifiée. Elle avance l'emplacement du texte suivant de 1,75 fois la taille_texte actuelle. Cela vous permet de dessiner plusieurs lignes de texte de manière raisonnable sans spécifier la position de chaque ligne.

Notez que si vous invoquez ppmlabel via une commande shell et que votre chaîne de texte contient des espaces, vous devrez la mettre entre guillemets afin que le shell traite la chaîne entière comme un seul jeton. Par exemple :

  $ ppmlabel -text "ceci est mon texte" image_base.ppm >image_annotee.ppm
-x colonne
Cette option définit la colonne de pixels à laquelle le texte suivant sera justifié à gauche. Selon la forme du premier caractère, le texte réel peut commencer quelques pixels à droite de ce point.
-y ligne
Cette option définit la ligne de pixels qui formera la ligne de base du texte suivant. Les caractères avec des hampes descendantes, tels que « y », s'étendront sous cette ligne.

LIMITATIONS

Les chaînes de texte sont limitées à l'ASCII 7 bits. La police de texte utilisée par ppmlabel n'inclut pas de définitions pour les caractères ISO 8859/1 8 bits.

Lors du dessin de plusieurs lignes de texte avec un arrière-plan non transparent, celui-ci devrait probablement remplir l'espace entre les lignes avec la couleur de fond. C'est difficile à bien faire lorsque le texte est tourné selon un angle non orthogonal.
