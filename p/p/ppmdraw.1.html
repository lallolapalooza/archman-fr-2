NOM

ppmdraw - dessiner des lignes, du texte, etc. sur une image PPM

SYNOPSIS

ppmdraw

{ -script=script | -scriptfile=nomfichier } [-verbose]

[fichierppm]

Toutes les options peuvent être abrégées à leur préfixe unique le plus court. Vous pouvez utiliser deux tirets au lieu d'un pour désigner une option. Vous pouvez utiliser un espace blanc ou un signe égal entre le nom d'une option et sa valeur.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

ppmdraw dessine des lignes, des formes, du texte, etc. sur une image PPM. C'est essentiellement une interface facile à programmer pour les sous-routines 'ppmd' de libnetpbm. Il vous permet de créer un script convivial pour décrire le dessin plutôt que d'écrire un programme C.

Vous fournissez les instructions de dessin avec un script, que vous fournissez soit dans un fichier nommé par une option -scriptfile, soit comme valeur d'une option -script. Voici un exemple de script :


setpos 50 50;
text_here 10 30 'bonjour';
setcolor noir;
text_here 10 0 'le monde';
line_here 5 20;

Cet exemple commence à la colonne 50, ligne 50 de l'image d'entrée et y écrit le mot 'bonjour' avec des lettres blanches de 10 pixels de haut, à un angle de 30 degrés par rapport à l'horizontale. Ensuite, à partir de là où cela s'arrête, le script écrit 'le monde' avec des lettres noires de 10 pixels de haut, horizontalement. Enfin, il dessine une ligne noire vers un point situé 5 pixels plus loin et 20 pixels plus bas que la fin de 'le monde'.

Si vous ne spécifiez pas fichierppm, ppmdraw lit son image PPM d'entrée à partir de l'entrée standard.

L'image de sortie va à la sortie standard.

ppmdraw fonctionne sur les flux multi-images. Il exécute le même script sur chaque image d'entrée et produit un flux de sortie avec une image pour chaque image d'entrée. Mais avant Netpbm 10.32 (février 2006), ppmdraw ignorait toutes les images après la première.

Si vous voulez juste ajouter une seule ligne de texte à une image, ppmlabel pourrait être plus approprié.

OPTIONS

-script=script
Cette option donne le script. Voir Script.

Vous ne pouvez spécifier ni -script ni -scriptfile.

-scriptfile=nomfichier
Cette option nomme un fichier contenant le script. - signifie entrée standard.

Vous ne pouvez spécifier ni -script ni -scriptfile.

Vous ne pouvez pas spécifier - (entrée standard) à la fois pour -scriptfile et pour le fichier image d'entrée.

SCRIPT

Le cœur de la fonction de ppmdraw est son script. Le script est un flux de caractères. Le flux se compose de commandes. Les commandes sont séparées par des points-virgules. Les espaces blancs sont traités comme en C : toute série continue d'espaces blancs non cités équivaut à un seul caractère espace. Notez que cela signifie que les sauts de ligne n'ont pas de signification particulière.

Une commande est composée de jetons, séparés les uns des autres par des espaces blancs. Pour écrire un jeton qui contient des espaces blancs, entourez-le de guillemets doubles. Tout ce qui se trouve entre deux guillemets correspondants constitue un jeton.

Le premier jeton d'une commande est le verbe, qui détermine la fonction de base de la commande. Le reste des jetons de la commande sont des arguments, dont la signification dépend du verbe. La liste suivante donne tous les verbes valides, et pour chacun sa signification et ses arguments.

De nombreuses commandes ont des arguments qui spécifient une position sur la toile, que vous spécifiez par ligne et colonne. La ligne 0 est la ligne du haut. La colonne 0 est la colonne la plus à gauche. Vous pouvez spécifier des nombres négatifs (mais une telle position serait nécessairement en dehors de la toile).

Vos instructions de dessin peuvent impliquer des positions qui ne sont pas sur la toile. Mais tous les pixels que vous y dessinez sont simplement rejetés.

setpos
Définit la 'position courante' dans l'image. Cela affecte l'endroit où les commandes suivantes dessinent des choses. Les 2 arguments sont le numéro de colonne et de ligne.

Au début du script, la position courante est (0,0).

setlinetype
L'argument 1 est 'normal' ou 'nodiag.'. Cela affecte un appel ppmd_setlinetype(). Plus de détails non encore documentés.
setlineclip
Cela affecte un appel ppmd_setlineclip(). Pas encore documenté.
setcolor
Définit la 'couleur courante', qui détermine la couleur dans laquelle les commandes de dessin suivantes dessinent. Avant le premier setcolor, la couleur courante est le blanc.
setfont
Définit la 'police courante', qui détermine la police dans laquelle les commandes de dessin de texte suivantes dessinent. Avant le premier setfont, la police courante est une police intégrée appelée 'standard'.

L'argument de cette commande est un nom de fichier. C'est le nom d'un fichier de polices PPMD Netpbm.

Un fichier de polices PPMD Netpbm a typiquement un nom qui se termine par '.ppmdfont' et ses 8 premiers octets sont l'encodage ASCII de 'ppmdfont'.

Il n'y a qu'une seule de ces polices à notre connaissance. Elle est distribuée avec Netpbm sous le nom de fichier standard.ppmdfont, mais vous n'avez pas besoin d'utiliser ce fichier car la même police est intégrée dans la bibliothèque Netpbm et est celle par défaut. Si vous souhaitez créer une nouvelle police, vous pouvez trouver le format d'un fichier ppmdfont dans le fichier d'en-tête de l'interface Netpbm ppmdfont.h, mais vous devrez créer vos propres outils pour la construire. Le programme ppmdmkfont génère standard.ppmdfont, vous pouvez donc l'utiliser comme exemple.

line
Dessine une ligne d'un pixel de large dans la couleur courante. Les 4 arguments sont : colonne de départ, ligne de départ, colonne d'arrivée, ligne d'arrivée.

Cette commande n'affecte pas la position courante.

line_here
C'est comme line, sauf que cela fonctionne de manière plus relative.

La ligne commence au point courant. Les deux arguments sont le déplacement vers la droite et vers le bas à partir de là jusqu'au point terminal. La commande déplace la position courante vers le point terminal après le dessin.

spline3
Dessine une spline dans la couleur courante entre 2 points, en utilisant un troisième comme point de contrôle. Elle approxime un segment de spline cubique.

La forme de la courbe est telle qu'elle passe par les points d'extrémité spécifiés, et les lignes tangentes à la courbe à ces points d'extrémité se croisent au point de contrôle. Le contrôle des tangentes vous permet de connecter cette courbe à d'autres courbes générées de la même manière sans avoir d'angles aux points de connexion.

Les 6 arguments sont la colonne du point de départ, la ligne du point de départ, la colonne du point de contrôle, la ligne du point de contrôle, la colonne du point d'arrivée et la ligne du point d'arrivée.

Cette commande n'affecte pas la position courante.

circle
Cette commande dessine un cercle dans la couleur courante. Les trois arguments sont le numéro de colonne et le numéro de ligne du centre du cercle et le rayon du cercle en pixels.
filledrectangle
Cette commande dessine un rectangle rempli avec la couleur courante.

Les 4 arguments sont les numéros de colonne et de ligne du coin supérieur gauche du rectangle, la largeur du rectangle et la hauteur du rectangle.

text
Cette commande dessine du texte dans la couleur courante dans la police intégrée. Les 5 arguments sont :
  • numéro de colonne du point de départ de la ligne de base
  • numéro de ligne du point de départ de la ligne de base
  • hauteur des caractères, en pixels
  • angle de la ligne de base en degrés par rapport à l'horizontale

ppmdraw(1) — Documentation Netpbm

Nom

ppmdraw — dessine des primitives graphiques dans une image PPM.

Synopsis

ppmdraw [options...] [fichier-image]

Description

La commande ppmdraw dessine des primitives graphiques dans une image PPM. Les primitives sont spécifiées sur l'entrée standard sous la forme de commandes, où chaque commande est sur une ligne séparée. Le format des commandes est le suivant :

[x y] colour command [arguments]

où x et y sont les coordonnées du point de départ, colour est une couleur PPM valide (par exemple, un nom de couleur comme « red » ou une spécification RGB comme « #RRGGBB ») et command est l'une des commandes de dessin disponibles.

L'image de sortie est écrite sur la sortie standard.

Options

Aucune option n'est spécifiée dans cette section.

Script

Voici quelques commandes disponibles dans un script ppmdraw :

  • point x y colour : Dessine un point de la couleur spécifiée aux coordonnées x, y.

  • line x1 y1 x2 y2 colour : Dessine une ligne de (x1, y1) à (x2, y2) avec la couleur spécifiée.

  • rect x y width height colour : Dessine un rectangle aux coordonnées (x, y) avec la largeur et la hauteur spécifiées, et la couleur spécifiée.

  • circle x y radius colour : Dessine un cercle centré en (x, y) avec le rayon spécifié, et la couleur spécifiée.

  • text x y font colour "string" : Dessine la chaîne de caractères spécifiée à la position (x, y) avec la police et la couleur spécifiées.

    Notez que pour les chaînes contenant des espaces, vous devrez utiliser des guillemets doubles pour qu'elles soient traitées comme un seul jeton.

text_here
Ceci est similaire à text, sauf que la ligne de base commence à la position actuelle et que la commande met à jour la position actuelle à l'autre extrémité de la ligne de base après le dessin.

Gardez à l'esprit qu'un script commence avec la position actuelle sur la ligne supérieure, donc si vous la laissez là, seule la ligne inférieure de votre texte sera dans l'image !

Historique

ppmdraw est apparu pour la première fois dans Netpbm 10.29 (août 2005).
