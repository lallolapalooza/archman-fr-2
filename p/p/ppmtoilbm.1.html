NOM

ppmtoilbm - convertir une image PPM en fichier ILBM

SYNTAXE

ppmtoilbm

[-maxplanes|-mp N]

[-fixplanes|-fp N]

[-ham6|-ham8]

[ {-dcbits|-dcplanes} r g b ]

[ -normal|-hamif|-hamforce|-24if|-24force| -dcif|-dcforce|-cmaponly ]

[-ecs|-aga]

[-compress|-nocompress]

[-cmethod type]

[-map fichierppm]

[-savemem]

[fichierppm]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

ppmtoilbm lit une image PPM en entrée. Produit un fichier ILBM en sortie. ppmtoilbm comprend les types ILBM suivants :

  • ILBM normaux avec 1 à 16 plans
  • Amiga HAM avec 3 à 16 plans
  • 24 bits
  • Table de couleurs (uniquement les blocs BMHD et CMAP, nPlanes = 0)
  • Couleur directe non officielle. 1 à 16 plans pour chaque composante de couleur.

Blocs écrits : BMHD, CMAP, CAMG (uniquement pour HAM), BODY (pas pour les fichiers de table de couleurs) bloc DCOL non officiel pour ILBM en couleur directe.

OPTIONS

Les options marquées d'une * peuvent être préfixées par 'no', par ex. '-nohamif'. Toutes les options peuvent être abrégées à leur préfixe unique le plus court.

-maxplanes | -mp n
(par défaut 5, minimum 1, maximum 16) Nombre maximum de plans à écrire dans un ILBM normal. Si l'image ne rentre pas dans <n> plans, ppmtoilbm écrit un fichier HAM (si -hamif est utilisé), un fichier 24 bits (si -24if est utilisé) ou un fichier couleur directe (si -dcif est utilisé) ou abandonne avec une erreur.
-fixplanes | -fp b
(minimum 1, maximum 16) Si un ILBM normal est écrit, il aura exactement <n> plans.
-hambits | -hamplanes n
(par défaut 6, minimum 3, maximum 16) Sélectionne le nombre de plans pour une image HAM. Le matériel Amiga actuel supporte 6 et 8 plans, donc pour l'instant, vous ne devriez utiliser que ces valeurs.
-normal
Désactive -hamif/-24if/-dcif, -hamforce/-24force/-dcforce et -cmaponly. Définit également le type de compression sur byterun1.

C'est le comportement par défaut.

-hamif (*)
-24if (*)
-dcif (*)
Écrit un fichier HAM/24 bits/couleur directe si l'image ne rentre pas dans <maxplanes> plans.
-hamforce (*)
-24force (*)
-dcforce (*)
Écrit un fichier HAM/24 bits/couleur directe.
-dcbits r g b
-dcplanes r g b
(par défaut 5, minimum 1, maximum 16). Sélectionne le nombre de bits pour le rouge, le vert et le bleu dans un ILBM en couleur directe.
-ecs
Raccourci pour : -hamplanes 6 -maxplanes 5

C'est le comportement par défaut.

-aga
Raccourci pour : -hamplanes 8 -maxplanes 8
-ham6
Raccourci pour : -hamplanes 6 -hamforce
-ham8
Raccourci pour : -hamplanes 8 -hamforce
-compress (*)
C'est le comportement par défaut. Compresse le bloc BODY. La méthode de compression par défaut est byterun1. La compression nécessite de construire l'image ILBM en mémoire ; désactiver la compression permet d'écrire l'image en flux, mais le fichier résultant sera généralement 30% à 50% plus grand. Une autre alternative est l'option -savemem ; cela maintient les besoins en mémoire pour la compression au minimum, mais est très lent.
-cmethod none|byterun1
Cette option fait la même chose que -compress.
-map fichierppm
Écrit un ILBM normal en utilisant les couleurs du fichier <ppmfile> comme table de couleurs. Le fichier de table de couleurs détermine également le nombre de plans, une option -maxplanes ou -fixplanes est ignorée.
-cmaponly
Écrit un fichier de table de couleurs : uniquement les blocs BMHD et CMAP, pas de bloc BODY, nPlanes = 0.
-savemem
Voir l'option -compress.

LIMITATIONS

Les images HAM obtiendront toujours une table de couleurs en niveaux de gris ; un algorithme de sélection de couleurs réel pourrait donner de meilleurs résultats. D'un autre côté, cela permet une opération ligne par ligne sur les images HAM, et toutes les images HAM de même profondeur (nombre de plans) partagent une table de couleurs commune, ce qui est utile pour construire des animations HAM.
