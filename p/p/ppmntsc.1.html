NOM

ppmntsc - Rendre les couleurs RVB légales pour les systèmes couleur NTSC ou PAL.

SYNOPHIS

ppmntsc

[--pal] [--legalonly] [--illegalonly] [--correctedonly] [--verbose] [--debug] [infile]

Les abréviations uniques minimales des options sont acceptées.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

Ce programme rend les couleurs légales dans les systèmes couleur NTSC (ou PAL). Souvent, les images générées sur ordinateur sont conçues pour être utilisées dans des films qui finissent par être diffusés sur un écran de télévision. Cependant, la gamme de couleurs (telle que spécifiée par leurs valeurs RVB) d'un ordinateur ne correspond pas à la gamme de couleurs qui peuvent être représentées en utilisant les systèmes NTSC (ou PAL). Si une image avec des couleurs « illégales » est envoyée directement à un système vidéo NTSC (ou PAL) pour enregistrement, les couleurs « illégales » seront coupées. Cela peut entraîner une image indésirable.

Cet utilitaire teste chaque pixel d'une image pour voir s'il se situe dans la plage légale NTSC (ou PAL). Sinon, il augmente ou diminue la saturation du pixel dans la sortie afin qu'il se situe dans les limites légales. Les pixels qui sont déjà corrects sont simplement transférés sans modification dans la sortie.

L'entrée provient du fichier nommé input. Si input est -, l'entrée provient de l'entrée standard. Si vous ne spécifiez pas input, l'entrée provient de l'entrée standard.

La sortie se fait toujours sur la sortie standard.

Ce programme gère les entrées PPM multi-images, produisant des sorties PPM multi-images.

OPTIONS

--pal
Utiliser la transformation PAL au lieu de NTSC par défaut.
--verbose
Imprimer un total général du nombre de pixels illégaux.
--debug
Produire une liste énorme de couleurs illégales et de leurs équivalents légaux. NOTE : Cette option peut produire une grande quantité de sortie.
--legalonly
N'afficher que les pixels qui sont déjà légaux. Afficher du noir à la place des pixels qui ne le sont pas.
--illegalonly
N'afficher que les pixels qui sont illégaux (et les afficher sans correction). Afficher du noir à la place des pixels qui sont déjà légaux.
--correctedonly
N'afficher que les pixels qui sont des versions corrigées des pixels illégaux. Afficher du noir à la place des pixels qui sont déjà légaux.
