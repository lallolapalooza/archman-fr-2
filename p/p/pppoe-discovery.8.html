NOM

pppoe-discovery - effectuer la découverte PPPoE

SYNTAXE

pppoe-discovery [ options ]
pppoe-discovery { -V | -h }

DESCRIPTION

pppoe-discovery effectue le même processus de découverte que pppoe, mais n'initie pas de session. Il envoie un paquet PADI puis imprime les noms des concentrateurs d'accès dans chaque paquet PADO qu'il reçoit.

OPTIONS

-I interface
L'option -I spécifie l'interface Ethernet à utiliser. Sous Linux, il s'agit généralement de eth0 ou eth1. L'interface doit être “active” avant de démarrer pppoe-discovery, mais elle ne doit pas être configurée avec une adresse IP. Cette option est obligatoire.
-D nom_fichier
L'option -D provoque le vidage de chaque paquet dans le nom_fichier spécifié. Ceci est destiné uniquement au débogage.
-U
Force pppoe-discovery à utiliser la balise Host-Uniq dans ses paquets de découverte. Cela vous permet d'exécuter plusieurs instances de pppoe-discovery et/ou pppoe sans que leurs paquets de découverte ne s'interfèrent mutuellement. Vous devez fournir cette option à toutes les instances que vous prévoyez d'exécuter simultanément.
-S nom_service
Spécifie le nom du service souhaité. pppoe-discovery n'acceptera que les concentrateurs d'accès pouvant fournir le service spécifié. Dans la plupart des cas, vous ne devriez pas spécifier cette option. Utilisez-la uniquement si vous savez qu'il existe plusieurs concentrateurs d'accès ou si vous savez que vous avez besoin d'un nom de service spécifique.
-C nom_ac
Spécifie le nom du concentrateur d'accès souhaité. pppoe-discovery n'acceptera que le concentrateur d'accès spécifié. Dans la plupart des cas, vous ne devriez pas spécifier cette option. Utilisez-la uniquement si vous savez qu'il existe plusieurs concentrateurs d'accès. Si les options -S et -C sont toutes deux spécifiées, elles doivent toutes deux correspondre.
-A
Cette option est acceptée pour la compatibilité avec pppoe, mais n'a aucun effet.
-V | -h
L'une ou l'autre de ces options fait que pppoe-discovery affiche son numéro de version et ses informations d'utilisation, puis se termine.
