NOM

ppmchange - changer toutes les pixels d'une couleur en une autre dans une image PPM

SYNTAXE

ppmchange

[-closeness=pourcentage_proximite] [-remainder=couleur_reste] [-closeok] [couleur_ancienne couleur_nouvelle] ... [fichier_ppm]

EXEMPLES

ppmchange rouge bleu image_rouge.ppm >image_bleue.ppm
ppmchange rouge rouge -remainder=noir image_mon.ppm >rouge_noir.ppm
ppmchange -closeness=90 blanc blanc noir noir

DESCRIPTION

Ce programme fait partie de Netpbm(1)

ppmchange lit une image PPM en entrée et change toutes les pixels de couleur couleur_ancienne en couleur_nouvelle.

Vous pouvez spécifier jusqu'à 256 paires couleur_ancienne/couleur_nouvelle sur la ligne de commande. ppmchange laisse toutes les couleurs non mentionnées inchangées, sauf si vous spécifiez l'option -remainder, auquel cas elles sont toutes changées en la couleur unique spécifiée.

Vous pouvez spécifier que les couleurs similaires, mais pas identiques, à celles que vous spécifiez soient remplacées en indiquant un facteur de 'closeness'.

Spécifiez les couleurs comme décrit pour la routine de bibliothèque ppm_parsecolor().

Si un pixel correspond à deux couleur_ancienne différentes, ppmchange le remplace par la couleur_nouvelle de celle spécifiée le plus à gauche.

La valeur maximale de l'image de sortie est la même que celle de l'image d'entrée. Si une couleur_nouvelle que vous spécifiez ne peut pas être représentée exactement avec cette valeur maximale, ppmchange utilise une couleur aussi proche que possible de celle que vous avez spécifiée mais qui peut être représentée avec votre valeur maximale. Sauf si vous spécifiez l'option -closeok, ppmchange émet un avertissement indiquant qu'il utilise une approximation.

Une façon courante d'avoir ce problème de valeur maximale, où la couleur que vous spécifiez ne peut pas être représentée avec votre valeur maximale, est que votre entrée est une image PBM (noir et blanc) que vous êtes en train de coloriser. La valeur maximale dans ce cas est 1, ce qui limite considérablement les couleurs vers lesquelles vous pouvez changer. Pour éviter ce problème, utilisez pamdepth pour définir la valeur maximale de votre entrée à quelque chose de cohérent avec vos couleurs. 255 est généralement un bon choix.

Avant Netpbm 10.22 (avril 2004), ppmchange se comportait toujours comme si l'utilisateur avait spécifié -closeok et qu'il n'y avait pas d'option -closeok.

OPTIONS

-closeness pourcentage_proximite
closeness est un pourcentage entier indiquant à quel point un pixel doit être proche de la couleur que vous avez spécifiée pour être remplacé. Par défaut, il est de 0, ce qui signifie que le pixel doit avoir exactement la couleur que vous avez spécifiée.

Un pixel est remplacé si la distance en couleur entre lui et la couleur que vous avez spécifiée est inférieure ou égale à closeness pour cent de la valeur maximale.

La 'distance' en couleur est définie comme la somme cartésienne des différences individuelles dans les intensités rouge, verte et bleue entre les deux pixels, normalisée de sorte que la différence entre le noir et le blanc soit de 100 %.

Ceci est probablement plus simple que ce que vous souhaitez la plupart du temps. Vous voudriez probablement changer les couleurs qui ont une chrominance similaire, quelle que soit leur intensité. Ainsi, s'il y a une grange rouge qui est diversement ombragée, vous voulez que toute la grange soit changée. Mais comme l'ombrage change significativement la couleur selon la formule de distance de ppmchange, certaines parties de la grange seront probablement aussi distantes en couleur d'autres parties de la grange qu'elles le sont de l'herbe verte à côté de la grange.

Peut-être que ppmchange sera amélioré un jour pour faire une analyse de chrominance.

Cette option a été ajoutée dans Netpbm 9.8 (septembre 2000).

-closeok
Cette option affecte la manière dont ppmchange interprète une couleur que vous spécifiez dans les arguments. Lorsque vous spécifiez cette option, ppmchange peut utiliser une couleur proche, mais pas identique, à celle que vous spécifiez. Voir la section description pour plus de détails.

Cette option a été ajoutée dans Netpbm 10.22 (avril 2004). Avant cela, ppmchange se comportait toujours comme si vous aviez spécifié cette option.

-remainder couleur
ppmchange change toutes les pixels qui ne correspondent pas à une couleur pour laquelle vous spécifiez explicitement une couleur de remplacement sur la ligne de commande, en la couleur couleur.

Une application courante de ceci est

ppmchange -remainder=noir rouge rouge

pour extraire uniquement les portions rouges d'une image, ou

ppmchange -remainder=noir rouge blanc | ppmtopgm

pour créer un masque pour les portions rouges de l'image.
