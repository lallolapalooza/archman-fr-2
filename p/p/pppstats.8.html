NOM

pppstats - affiche les statistiques PPP

SYNTAXE

pppstats [ -a ] [ -d ] [ -v ] [ -r ] [ -z ] [ -c <compte> ] [ -w <secs> ] [ interface ]

DESCRIPTION

L'utilitaire pppstats signale les statistiques liées à PPP à intervalles réguliers pour l'interface PPP spécifiée. Si l'interface n'est pas spécifiée, elle sera ppp0 par défaut. L'affichage est divisé horizontalement en sections d'entrée et de sortie contenant des colonnes de statistiques décrivant les propriétés et le volume des paquets reçus et transmis par l'interface.

Les options sont les suivantes :

-a
Affiche les valeurs absolues plutôt que les deltas. Avec cette option, tous les rapports montrent les statistiques depuis le début de la liaison. Sans cette option, les deuxième rapports et suivants montrent les statistiques depuis le dernier rapport.
-d
Affiche le débit de données (Ko/s) au lieu des octets.
-c compte
Répète l'affichage compte fois. Si cette option n'est pas spécifiée, le compte de répétition par défaut est 1 si l'option -w n'est pas spécifiée, sinon l'infini.
-r
Affiche des statistiques supplémentaires résumant le ratio de compression atteint par l'algorithme de compression de paquets utilisé.
-v
Affiche des statistiques supplémentaires relatives aux performances de l'algorithme de compression d'en-tête TCP Van Jacobson.
-w attente
Met en pause attente secondes entre chaque affichage. Si cette option n'est pas spécifiée, l'intervalle par défaut est de 5 secondes.
-z
Au lieu de l'affichage standard, affiche des statistiques indiquant les performances de l'algorithme de compression de paquets utilisé.

Les champs suivants sont imprimés du côté de l'entrée lorsque l'option -z n'est pas utilisée :

IN
Le nombre total d'octets reçus par cette interface.
PACK
Le nombre total de paquets reçus par cette interface.
VJCOMP
Le nombre de paquets TCP compressés en en-tête reçus par cette interface.
VJUNC
Le nombre de paquets TCP non compressés en en-tête reçus par cette interface. Non rapporté lorsque l'option -r est spécifiée.
VJERR
Le nombre de paquets TCP compressés en en-tête corrompus ou invalides reçus par cette interface. Non rapporté lorsque l'option -r est spécifiée.
VJTOSS
Le nombre de paquets TCP compressés en en-tête VJ déposés lors de la réception par cette interface à cause d'erreurs précédentes. Seulement rapporté lorsque l'option -v est spécifiée.
NON-VJ
Le nombre total de paquets non TCP reçus par cette interface. Seulement rapporté lorsque l'option -v est spécifiée.
RATIO
Le ratio de compression atteint pour les paquets reçus par le schéma de compression de paquets utilisé, défini comme la taille non compressée divisée par la taille compressée. Seulement rapporté lorsque l'option -r est spécifiée.
UBYTE
Le nombre total d'octets reçus, après décompression des paquets compressés. Seulement rapporté lorsque l'option -r est spécifiée.

Les champs suivants sont imprimés du côté de la sortie :

OUT
Le nombre total d'octets transmis depuis cette interface.
PACK
Le nombre total de paquets transmis depuis cette interface.
VJCOMP
Le nombre de paquets TCP transmis depuis cette interface avec des en-têtes TCP compressés VJ.
VJUNC
Le nombre de paquets TCP transmis depuis cette interface avec des en-têtes TCP non compressés VJ. Non rapporté lorsque l'option -r est spécifiée.
NON-VJ
Le nombre total de paquets non TCP transmis depuis cette interface. Non rapporté lorsque l'option -r est spécifiée.
VJSRCH
Le nombre de recherches de l'entrée d'en-tête mise en cache pour un paquet TCP compressé en en-tête VJ. Seulement rapporté lorsque l'option -v est spécifiée.
VJMISS
Le nombre de recherches échouées de l'entrée d'en-tête mise en cache pour un paquet TCP compressé en en-tête VJ. Seulement rapporté lorsque l'option -v est spécifiée.
RATIO
Le ratio de compression atteint pour les paquets transmis par le schéma de compression de paquets utilisé, défini comme la taille avant compression divisée par la taille compressée. Seulement rapporté lorsque l'option -r est spécifiée.
UBYTE
Le nombre total d'octets à transmettre, avant que la compression de paquet ne soit appliquée. Seulement rapporté lorsque l'option -r est spécifiée.

Lorsque l'option -z est spécifiée, pppstats affiche à la place les champs suivants, relatifs à l'algorithme de compression de paquet actuellement utilisé. Si la compression de paquet n'est pas utilisée, ces champs afficheront tous des zéros. Les champs affichés du côté de l'entrée sont :

OCTETS COMPRIMÉS
Le nombre d'octets des paquets compressés reçus.
PAQUETS COMPRIMÉS
Le nombre de paquets compressés reçus.
OCTETS NON COMPRIMIBLES
Le nombre d'octets des paquets non compressibles (c'est-à-dire ceux qui ont été transmis sous forme non compressée) reçus.
PAQUETS NON COMPRIMIBLES
Le nombre de paquets non compressibles reçus.
RATIO DE COMPRESSION
Le ratio de compression récent pour les paquets entrants, défini comme la taille non compressée divisée par la taille compressée (incluant les paquets compressibles et non compressibles).

Les champs affichés du côté de la sortie sont :

OCTETS COMPRIMÉS
Le nombre d'octets des paquets compressés transmis.
PAQUETS COMPRIMÉS
Le nombre de paquets compressés transmis.
OCTETS NON COMPRIMIBLES
Le nombre d'octets des paquets non compressibles transmis (c'est-à-dire ceux qui ont été transmis sous forme non compressée).
PAQUETS NON COMPRIMIBLES
Le nombre de paquets non compressibles transmis.
RATIO DE COMPRESSION
Le ratio de compression récent pour les paquets sortants.

NAME

pppstats - Afficher des statistiques de déconnexion de la couche PPP

SYNTAXE

pppstats [ -h ] [ -l ] [ -c ]

DESCRIPTION

Le programme pppstats affiche les statistiques de déconnexion de la couche PPP, qui sont stockées dans le fichier /proc/net/ppp.

Les options suivantes sont disponibles :

-h
Affiche une aide.
-l
Affiche le nom des interfaces PPP.
-c
Remet à zéro les compteurs de statistiques.
