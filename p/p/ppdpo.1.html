NOM

ppdpo - générateur de catalogue de messages ppd (obsolète)

SYNTAXE

ppdpo [ -D nom[=valeur] ] [ -I répertoire-inclusion ] [ -o fichier-sortie ] fichier-source

DESCRIPTION

ppdpo extrait les chaînes d'interface utilisateur des fichiers source PPDC et met à jour un fichier source de catalogue de messages au format GNU gettext ou macOS strings pour la traduction. Ce programme est obsolète et sera supprimé dans une future version de CUPS.

OPTIONS

ppdpo prend en charge les options suivantes :

-D nom[=valeur]
Définit la variable nommée pour utilisation dans le fichier source. C'est équivalent à l'utilisation de la directive #define dans le fichier source.
-I répertoire-inclusion
Spécifie un répertoire d'inclusion alternatif. Plusieurs options -I peuvent être fournies pour ajouter des répertoires supplémentaires.
-o fichier-sortie
Spécifie le fichier de sortie. Les extensions prises en charge sont .po ou .po.gz pour les catalogues de messages au format GNU gettext et .strings pour les fichiers strings de macOS.

NOTES

Les fichiers PPD sont obsolètes et ne seront plus pris en charge dans une future version majeure de CUPS. Les imprimantes qui ne supportent pas IPP peuvent être prises en charge en utilisant des applications telles que ippeveprinter(1).
