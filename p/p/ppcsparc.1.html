NOM

ppcsparc - binaire du compilateur Free Pascal (FPC), nom dérivé de Portable Pascal Compiler

SYNTAXE

ppcsparc [options] [fichier_source]

DESCRIPTION

Ce binaire est le back-end binaire du Compilateur Free Pascal (FPC) qui est un compilateur Pascal multi-cible autonome (sans frontend GCC) compatible avec Turbo Pascal et Delphi (7.0).

Ce binaire ne doit pas être appelé directement, mais le programme fpc doit être utilisé à la place. Celui-ci choisira le back-end adapté pour compiler les unités pour les plateformes demandées.

OPTIONS

Pour une liste complète de toutes les options de ligne de commande supportées, voir la page man de fpc(1).
