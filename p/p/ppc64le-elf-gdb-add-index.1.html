NOM

gdb-add-index - Ajouter des fichiers d'index pour accélérer GDB

SYNTAXE

gdb-add-index nom_de_fichier

DESCRIPTION

Lorsque GDB trouve un fichier de symboles, il scanne les symboles du fichier afin de construire une table de symboles interne. Cela permet à la plupart des opérations GDB de fonctionner rapidement, au prix d'un délai initial. Pour les grands programmes, ce délai peut être assez long, c'est pourquoi GDB propose un moyen de construire un index, ce qui accélère le démarrage.

Pour déterminer si un fichier contient un tel index, utilisez la commande "readelf -S nom_de_fichier" : l'index est stocké dans une section nommée ".gdb_index". Le fichier d'index ne peut être produit que sur les systèmes qui utilisent des binaires ELF et des informations de débogage DWARF (c'est-à-dire, des sections nommées ".debug_*").

gdb-add-index utilise GDB et objdump trouvés dans la variable d'environnement PATH. Si vous souhaitez utiliser différentes versions de ces programmes, vous pouvez les spécifier via les variables d'environnement GDB et OBJDUMP.

Voir plus de détails dans le manuel de GDB, au nœud "Index Files" -- commande shell "info -f gdb -n "Index Files"".
