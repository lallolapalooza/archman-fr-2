PPL_LPSOL(1) Commandes utilisateur PPL_LPSOL(1)

NOM

ppl_lpsol - un solveur de problèmes de programmation linéaire en nombres entiers basé sur PPL

SYNTAXE

ppl_lpsol [OPTION]... [FICHIER]

DESCRIPTION

Lit un fichier au format MPS et tente de le résoudre en utilisant les algorithmes d'optimisation fournis par PPL.

Voir le *Manuel de référence de GNU Linear Programming Kit (Version 4.31)* pour des informations sur le format MPS.

OPTIONS

-c, --check[=SEUIL] vérifie les résultats obtenus à l'aide de GLPK ;
les optima sont vérifiés avec une tolérance de SEUIL (par défaut 1e-09) ; les données d'entrée sont également perturbées de la même manière que GLPK le fait
-i, --incremental
résout le problème de manière incrémentielle
-m, --min
minimise la fonction objectif
-M, --max
maximise la fonction objectif (par défaut)
-n, --no-optimization
vérifie uniquement la satisfiabilité
-r, --no-mip
considère les variables entières comme des variables réelles
-CSECS, --max-cpu=SECS
limite l'utilisation du processeur à SECS secondes
-RMB, --max-memory=MB
limite l'utilisation de la mémoire à MB mégaoctets
-h, --help
affiche ce texte d'aide sur la sortie standard
-oPATH, --output=CHEMIN
ajoute la sortie à CHEMIN
-e, --enumerate
utilise la méthode (coûteuse !) d'énumération
-pM, --pricing=M
utilise la méthode de tarification M pour le simplexe (suppose -s) ; M est un entier de 0 à 2, par défaut 0 : 0 --> bord le plus raide utilisant des nombres à virgule flottante 1 --> bord le plus raide utilisant de l'arithmétique exacte 2 --> textbook
-s, --simplex
utilise la méthode du simplexe
-t, --timings
affiche les temps d'exécution sur la sortie d'erreur standard
-v, --verbosity=NIVEAU
définit le niveau de verbosité (de 0 à 4, par défaut 3) : 0 --> silencieux : aucune sortie sauf les erreurs et
les notifications explicitement requises
1 --> état du solveur uniquement 2 --> état + valeur optimale 3 --> état + valeur optimale + localisation optimale 4 --> beaucoup de sortie
-V, --version
affiche les informations de version sur la sortie standard

DISPONIBILITE

La dernière version de la Parma Polyhedra Library et toute la documentation est disponible sur http://bugseng.com/products/ppl/ .

NOTES

Les options -CSECS (--max-cpu=SECS) et -t (--timings) ne sont pas disponibles sur certaines plateformes.
