NOM

ppcppc - Binaire du compilateur Free Pascal (FPC), nom dérivé de Portable Pascal Compiler

SYNTAXE

ppcppc [options] [fichier source]

DESCRIPTION

Ce binaire est le composant backend du compilateur Free Pascal (FPC), qui est un compilateur Pascal indépendant (sans frontend GCC), compatible avec Turbo Pascal et Delphi (7.0), et capable de compiler pour plusieurs cibles.

Ce binaire ne doit pas être appelé directement ; utilisez plutôt le programme fpc. Il choisira le backend approprié pour compiler les unités pour les plateformes demandées.

OPTIONS

Pour une liste complète de toutes les options en ligne de commande supportées, consultez la page de manuel fpc(1).
