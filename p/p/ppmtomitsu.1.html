NOM

ppmtomitsu - convertir une image PPM en fichier Mitsubishi S340-10

SYNTAXE

ppmtomitsu

[-sharpness val]

[-enlarge val]

[-media string]

[-copy val]

[-dpi300]

[-tiny]

[fichierppm]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

ppmtomitsu lit une image PPM en entrée et la convertit dans un format approprié pour être imprimée par une imprimante Mitsubishi S340-10, ou toute autre imprimante à sublimation thermique couleur Mitsubishi.

L'imprimante Mitsubishi S340-10 à sublimation thermique couleur supporte la couleur 24 bits. Les images des tailles disponibles prennent tellement de temps à transférer qu'il existe une méthode rapide, utilisant une table de correspondance, que ppmtomitsu utilisera s'il y a un maximum de 256 couleurs dans l'image. ppmtomitsu tentera de positionner votre image au centre du papier, et fera pivoter votre image si xsize est plus grand que ysize. Si votre image est plus grande que le support autorisé, ppmtomitsu s'arrêtera avec un message d'erreur. (Nous avons décidé que les supports étaient trop chers pour que des utilisateurs négligents produisent des erreurs d'impression.) Une fois la transmission des données commencée, le travail ne peut pas être arrêté de manière sensée sans réinitialiser l'imprimante. L'imprimante comprend l'assemblage d'images dans sa mémoire; ppmtomitsu ne l'utilise pas car pnmcat etc fournissent la même fonctionnalité et vous permettent également de visualiser le résultat à l'écran. Le S340-10 est l'imprimante du dénominateur commun le plus bas; pour les imprimantes à plus haute résolution, il y a l'option dpi300. Les autres imprimantes supportent également des valeurs plus élevées pour enlarge eg, mais je ne pense pas que ce soit assez essentiel pour justifier un changement dans le programme.

Pour des résultats corrects, la valeur maximale d'entrée doit être 255. Utilisez pamdepth pour vous en assurer.

Avant Netpbm 10.40 (septembre 2007), tous les programmes PPM de Netpbm, y compris ppmtomitsu, voient une image PBM comme ayant une valeur maximale de 1, donc ppmtomitsu ne fonctionne pas correctement avec une entrée PBM. Vous pouvez utiliser ppmtoppm avec pamdepth pour transformer votre entrée PBM en une entrée PPM avec une valeur maximale de 255 que ppmtomitsu utilisera correctement.

OPTIONS

-sharpness 1-4
Désignation de 'netteté'. La valeur par défaut est d'utiliser la netteté actuelle.
-enlarge 1-3
Agrandir par un facteur; La valeur par défaut est 1 (pas d'agrandissement)
-media {A|A4|AS|A4S}
Désignez le support que vous utilisez. La valeur par défaut est 1184 x 1350, ce qui convient à tout support. A est 1216 x 1350, A4 est 1184 x 1452, AS est 1216 x 1650 et A4S est 1184 x 1754. Attention : Si vous spécifiez un support différent de celui actuellement chargé dans l'imprimante, l'imprimante attendra jusqu'à ce que vous insériez le bon support ou que vous l'éteigniez.
-copy 1-9
Le nombre de copies à produire. La valeur par défaut est 1.
-dpi300
Double le nombre de pixels autorisés pour une imprimante S3600-30 en mode de compatibilité S340-10. (Le S3600-30 a 300 dpi).
-tiny
Économie de mémoire, mais toujours lent. L'imprimante recevra les données ligne par ligne en 24 bits. Il est probablement conseillé d'utiliser cette option si votre machine commence à beaucoup utiliser la pagination sans cette option.
