NOM

ppmtoy4m - Convertit les images PPM en flux YUV4MPEG2

SYNTAXE

ppmtoy4m [options] [ nom_fichier ]

DESCRIPTION

ppmtoy4m convertit une ou plusieurs images PPM brutes en un flux YUV4MPEG2 prêt pour un traitement ultérieur par d'autres outils vidéo.

La sortie se fait vers la sortie standard afin de faciliter le piping vers d'autres outils MJPEG. La taille des images de sortie est déterminée à partir de la (première) image d'entrée.

L'entrée est une image PPM au format 'brut', lue depuis l'entrée standard ou depuis le nom de fichier optionnel. L'entrée peut contenir plusieurs images PPM concaténées ; ppmtoy4m les lira et les traitera séquentiellement. Toutes les images doivent avoir une taille et un format identiques. Les images d'entrée peuvent être interprétées comme des images progressives complètes, des champs entrelacés, ou (par paires) comme des champs séquentiels. Les images d'entrée doivent avoir 8 bits par canal (c'est-à-dire que 'maxval' doit être 255).

Les images d'entrée doivent être dans l'espace colorimétrique R'G'B' habituel. Elles sont converties dans l'espace colorimétrique Y'CbCr (ITU-R BT.601) (et sous-échantillonnées, si désiré) avant la sortie.

ppmtoy4m et y4mtoppm sont inverses l'un de l'autre ; vous pouvez rediriger la sortie de l'un vers l'autre, et vice-versa. Notez que les opérations de sous-échantillonnage et d'espace colorimétrique sont avec perte dans les deux sens. Et, lors de la conversion vers PPM, les informations sur l'entrelacement et le rapport d'aspect des échantillons sont perdues (mais peuvent être reconstruites en fournissant des arguments de ligne de commande à ppmtoy4m).

OPTIONS

ppmtoy4m accepte les options suivantes :

-o num
Décalage de trames : ignore la sortie des 'num' premières trames. (par défaut : 0)
-n num
Produit un total de 'num' trames de sortie. Utilisez '0' pour spécifier toutes les trames. (par défaut : 0)
-F n:d
Définit la fréquence d'images encodée dans le flux de sortie, comme un rapport entier exact. (par défaut : 30000:1001) Les fréquences courantes sont :
24000:1001 - NTSC 3:2 pulldown film converti
24:1 - film natif
25:1 - PAL/SECAM
30000:1001 - vidéo NTSC
50:1 - fréquence de champ PAL
60000:1001 - fréquence de champ NTSC
-A n:d
Définit le rapport d'aspect des pixels encodé dans le flux de sortie, comme un rapport entier exact. (par défaut : 1:1) Les rapports courants sont :
1:1 - pixels carrés (graphiques informatiques)
10:11 - CCIR-601 NTSC
59:54 - CCIR-601 PAL
-B
Interprète les données comme étant BGR plutôt que RGB.
-I x
Définit le mode d'entrelacement, utilisé pour interpréter l'image (les images) PPM, et également encodé dans le flux de sortie. (par défaut : 'p')
p - progressif, non entrelacé
t - entrelacé champ supérieur/haut en premier
b - entrelacé champ inférieur/bas en premier
-L
Pour les flux entrelacés, traite chaque image PPM comme deux champs entrelacés. (Sinon, deux images PPM seront lues pour chaque trame ; une par champ.)
-r
Répète la dernière image d'entrée jusqu'à ce que la sortie soit complète. Si '-n 0' est également spécifié, la dernière image d'entrée sera répétée à l'infini.
-S mode
Définit le mode de sous-échantillonnage de chroma. (par défaut : 444)
444 - 4:4:4 (pas de sous-échantillonnage)
420jpeg - 4:2:0 JPEG/MPEG-1, cositing interstitiel
420mpeg2 - 4:2:0 MPEG-2, cositing horizontal

Les modes sous-échantillonnés utilisent un filtre de sous-échantillonnage médiocre ; de meilleurs résultats seront obtenus en passant la sortie 4:4:4 par défaut à un redimensionneur prenant en charge le sous-échantillonnage, tel que y4mscaler(1).

-v [0,1,2]
Définit le niveau de verbosité.
0 = avertissements et erreurs seulement.
1 = ajoute des messages informatifs, aussi.
2 = ajoute des messages de débogage bavards, aussi.

EXEMPLES

Pour convertir un fichier contenant une seule image PPM en un flux de 15 images (identiques) :

ppmtoy4m -n 15 -r some-image.ppm

Pour convertir une série d'images au format Targa (dans le répertoire courant) en un flux YUV4MPEG2 lu par yuvplay :

ls *.tga | xargs -n1 tgatoppm | ppmtoy4m | yuvplay
