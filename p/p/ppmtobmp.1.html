NOM

ppmtobmp - convertir une image PPM en fichier BMP

SYNTAXE

ppmtobmp

[-windows]

[-os2]

[-bpp=bits_par_pixel]

[-mapfile=nom_de_fichier]

[fichier_ppm]

L'abréviation minimale unique de l'option est acceptable. Vous pouvez utiliser des doubles tirets au lieu d'un seul pour indiquer les options. Vous pouvez utiliser des espaces à la place du signe égal pour séparer un nom d'option de sa valeur.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

ppmtobmp lit une image PPM en entrée et produit un fichier BMP Microsoft Windows ou OS/2 en sortie.

OPTIONS

-windows
Indique au programme de produire un fichier BMP Microsoft Windows. (C'est le défaut.)
-os2
Indique au programme de produire un fichier BMP OS/2. (Avant Août 2000, c'était le défaut).
-bpp
Cela indique le nombre de bits par pixel que vous souhaitez que le fichier BMP contienne. Seuls 1, 4, 8 et 24 sont possibles. Par défaut, ppmtobmp choisit le plus petit nombre avec lequel il peut représenter toutes les couleurs de l'image d'entrée. Si vous spécifiez un nombre trop petit pour représenter toutes les couleurs de l'image d'entrée, ppmtobmp vous informe et se termine. Vous pouvez utiliser pnmquant ou ppmdither pour réduire le nombre de couleurs dans l'image.
-mapfile=nom_de_fichier
Ceci identifie un fichier à utiliser comme palette BMP (aussi appelée 'colormap'). Dans un sous-format BMP, le flux BMP contient une palette de jusqu'à 256 couleurs et représente le raster de l'image comme des indices dans cette palette. Normalement, ppmtobmp s'occupe de calculer une palette appropriée, mais si vous allez disséquer la sortie BMP d'une certaine manière, vous pourriez vouloir des valeurs spécifiques pour les indices de palette. Par exemple, vous pourriez vouloir que le rouge soit 13, là où ppmtobmp choisirait (arbitrairement) 39. Dans ce cas, vous pouvez construire la palette vous-même et utiliser cette option pour indiquer à ppmtobmp d'utiliser votre palette.

Cette option ne contrôle *pas* quelles couleurs se trouvent dans la sortie. Les couleurs dans la sortie sont exactement celles de l'entrée, et la palette que vous fournissez doit contenir au moins toutes les couleurs présentes dans l'entrée. Vous pouvez utiliser pnmremap pour ajuster votre image d'entrée afin qu'elle ne contienne que les couleurs de votre palette.

Le fichier de palette est un fichier au format Netpbm avec un pixel par entrée de palette. Chaque pixel doit avoir une couleur distincte (pas de répétitions). L'ordre de la palette BMP que ppmtobmp génère est l'ordre des pixels dans le fichier de palette, de haut en bas, de gauche à droite.

Une palette BMP peut avoir au maximum 256 couleurs, donc le fichier de palette doit avoir au maximum 256 pixels.

Vous pourriez trouver pnmcolormap utile pour générer le fichier de palette. pamseq également.

Cette option a été ajoutée dans Netpbm 10.45 (décembre 2008).

NOTES

Pour obtenir une reproduction fidèle de l'image d'entrée, le maxval de l'image d'entrée doit être de 255. S'il est différent, les couleurs du fichier BMP peuvent être légèrement différentes des couleurs de l'entrée.

Les icônes Windows ne sont pas des fichiers BMP. Utilisez ppmtowinicon pour les créer.
