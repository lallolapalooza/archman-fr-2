NOM

strip - supprime les symboles et autres données des fichiers objets

SYNTAXE

strip [-F nombfd |--target=nombfd]
[-I nombfd |--input-target=nombfd]
[-O nombfd |--output-target=nombfd]
[-s|--strip-all]
[-S|-g|-d|--strip-debug]
[--strip-dwo]
[-K nom_symbole|--keep-symbol=nom_symbole]
[-M|--merge-notes][--no-merge-notes]
[-N nom_symbole |--strip-symbol=nom_symbole]
[-w|--wildcard]
[-x|--discard-all] [-X |--discard-locals]
[-R nom_section |--remove-section=nom_section]
[--keep-section=motif_section]
[--remove-relocations=motif_section]
[--strip-section-headers]
[-o fichier] [-p|--preserve-dates]
[-D|--enable-deterministic-archives]
[-U|--disable-deterministic-archives]
[--keep-section-symbols]
[--keep-file-symbols]
[--only-keep-debug]
[-v |--verbose] [-V|--version]
[--help] [--info]
fichier_objet...

DESCRIPTION

GNU strip supprime tous les symboles des fichiers objets fichier_objet. La liste des fichiers objets peut inclure des archives. Au moins un fichier objet doit être fourni.

strip modifie les fichiers nommés dans ses arguments, plutôt que d'écrire des copies modifiées sous d'autres noms.

OPTIONS

-F nombfd
--target=nombfd
Traite le fichier_objet original comme un fichier avec le format de code objet nombfd, et le réécrit dans le même format.
--help
Affiche un résumé des options de strip et quitte.
--info
Affiche une liste montrant tous les formats d'architecture et d'objet disponibles.
-I nombfd
--input-target=nombfd
Traite le fichier_objet original comme un fichier avec le format de code objet nombfd.
-O nombfd
--output-target=nombfd
Remplace fichier_objet par un fichier dans le format de sortie nombfd.
-R nom_section
--remove-section=nom_section
Supprime toute section nommée nom_section du fichier de sortie, en plus de toutes les sections qui seraient autrement supprimées. Cette option peut être donnée plus d'une fois. Notez qu'utiliser cette option de manière inappropriée peut rendre le fichier de sortie inutilisable. Le caractère joker * peut être donné à la fin de nom_section. Si c'est le cas, toute section commençant par nom_section sera supprimée.

Si le premier caractère de motif_section est le point d'exclamation (!) alors les sections correspondantes ne seront pas supprimées, même si une utilisation antérieure de --remove-section sur la même ligne de commande les supprimait autrement. Par exemple :

--remove-section=.text.* --remove-section=!.text.foo

supprimera toutes les sections correspondant au motif '.text.*', mais ne supprimera pas la section '.text.foo'.

--keep-section=motif_section
Lors de la suppression de sections du fichier de sortie, conserve les sections qui correspondent à motif_section.
--remove-relocations=motif_section
Supprime les relocations du fichier de sortie pour toute section correspondant à motif_section. Cette option peut être donnée plus d'une fois. Notez que l'utilisation de cette option de manière inappropriée peut rendre le fichier de sortie inutilisable. Les caractères jokers sont acceptés dans motif_section. Par exemple : 
--remove-relocations=.text.*

supprimera les relocations de toutes les sections correspondant au motif '.text.*'.

Si le premier caractère de motif_section est le point d'exclamation (!) alors les sections correspondantes n'auront pas leurs relocations supprimées même si une utilisation antérieure de --remove-relocations sur la même ligne de commande causerait autrement la suppression des relocations. Par exemple :

--remove-relocations=.text.* --remove-relocations=!.text.foo

supprimera toutes les relocations pour les sections correspondant au motif '.text.*', mais ne supprimera pas les relocations pour la section '.text.foo'.

--strip-section-headers
Supprime les en-têtes de section. Cette option est spécifique aux fichiers ELF. Implique --strip-all et --merge-notes.
-s
--strip-all
Supprime tous les symboles.
-g
-S
-d
--strip-debug
Supprime uniquement les symboles de débogage.
--strip-dwo
Supprime le contenu de toutes les sections DWARF .dwo, laissant les sections de débogage restantes et tous les symboles intacts. Voir la description de cette option dans la section objcopy pour plus d'informations.
--strip-unneeded
Supprime tous les symboles qui ne sont pas nécessaires au traitement des relocations en plus des symboles et sections de débogage supprimés par --strip-debug.
-K nom_symbole
--keep-symbol=nom_symbole
Lors de la suppression de symboles, conserve le symbole nom_symbole même s'il serait normalement supprimé. Cette option peut être donnée plus d'une fois.
-M
--merge-notes
--no-merge-notes
Pour les fichiers ELF, tente (ou ne tente pas) de réduire la taille des sections de type SHT_NOTE en supprimant les notes dupliquées. Par défaut, cette réduction est tentée, sauf si des informations de débogage ou DWO sont supprimées.
-N nom_symbole
--strip-symbol=nom_symbole
Supprime le symbole nom_symbole du fichier source. Cette option peut être donnée plus d'une fois, et peut être combinée avec d'autres options de strip autres que -K.
-o fichier
Place la sortie débarrassée dans fichier, plutôt que de remplacer le fichier existant. Lorsque cet argument est utilisé, un seul argument fichier_objet peut être spécifié.
-p
--preserve-dates
Préserve les dates d'accès et de modification du fichier.
-D
--enable-deterministic-archives
Fonctionne en mode déterministe. Lors de la copie des membres d'archive et de l'écriture de l'index d'archive, utilise zéro pour les UID, GID, horodatages, et utilise des modes de fichier cohérents pour tous les fichiers.

Si binutils a été configuré avec --enable-deterministic-archives, alors ce mode est activé par défaut. Il peut être désactivé avec l'option -U, ci-dessous.

-U
--disable-deterministic-archives
Ne pas fonctionner en mode déterministe. Ceci

strip(1) — ppc64le-elf-binutils

NOM

strip — supprimer les symboles et les sections des fichiers objets

SYNTAXE

strip [-F FMT] [-I listing] [-R section] [-s] [--strip-debug] [--strip-unneeded] [--strip-symbol symbol] [--keep-symbol symbol] [--strip-unreachable-symbols] [--no-discard-all] [--no-discard-locals] [--discard-all] [--discard-locals] [--wildcard] [--strip-section-symbols] [--keep-section-symbols] [--strip-file-symbols] [--keep-file-symbols] [--only-keep-debug] [-V] [--version] [-v] [--verbose] [-p] [--preserve-dates] [-x] [-X] [--help] [--info-script=name] [-o obj_format] [--target=obj_format] [objfile...]

DESCRIPTION

La commande strip supprime les symboles et/ou les sections des fichiers objets. Les fichiers objets peuvent être des fichiers binaires, des bibliothèques statiques ou des bibliothèques partagées. La commande strip peut être utilisée pour réduire la taille des fichiers exécutables et des bibliothèques.

OPTIONS

-s
--strip-debug
Supprime toutes les informations de débogage des fichiers objets. Les informations de débogage comprennent généralement les symboles de débogage, les tables de chaînes de symboles, les informations de ligne source, etc.
--strip-unneeded
Supprime les symboles qui ne sont pas nécessaires à la liaison. Cela inclut les symboles de débogage ainsi que les symboles qui ne sont pas référencés par d'autres symboles.
--strip-symbol symbole
Supprime le symbole spécifié par symbole. Cette option peut être utilisée plusieurs fois pour supprimer plusieurs symboles.
--keep-symbol symbole
Conserve le symbole spécifié par symbole, même s'il serait normalement supprimé par une autre option. Cette option peut être utilisée plusieurs fois pour conserver plusieurs symboles.
--strip-unreachable-symbols
Supprime les symboles qui ne sont pas référencés par d'autres symboles. Ceci est utile pour supprimer les symboles inutilisés des bibliothèques.
--no-discard-all
Ne supprime pas les symboles non globaux. C'est l'inverse de l'option -w.
--no-discard-locals
Ne supprime pas les symboles locaux générés par le compilateur. C'est l'inverse de l'option -X.
--discard-all
Supprime les symboles non globaux.
--discard-locals
Supprime les symboles locaux générés par le compilateur. (Ceux-ci commencent généralement par L ou ..)
--wildcard
Permet l'utilisation d'expressions régulières dans les symbolnames utilisés dans d'autres options de ligne de commande. Les opérateurs point d'interrogation (?), astérisque (*), antislash (\) et crochets ([]) peuvent être utilisés n'importe où dans le nom du symbole. Si le premier caractère du nom du symbole est le point d'exclamation (!), alors le sens de l'option est inversé pour ce symbole. Par exemple : 
-w -K !foo -K fo*

ferait que strip ne conserve que les symboles qui commencent par les lettres « fo », mais écarterait le symbole « foo ».

--keep-section-symbols
Lors de la suppression d'un fichier, peut-être avec --strip-debug ou --strip-unneeded, conserve les symboles spécifiant les noms de section, qui seraient autrement supprimés.
--keep-file-symbols
Lors de la suppression d'un fichier, peut-être avec --strip-debug ou --strip-unneeded, conserve les symboles spécifiant les noms de fichiers source, qui seraient autrement supprimés.
--only-keep-debug
Supprime un fichier, vidant le contenu de toutes les sections qui ne seraient pas supprimées par --strip-debug et laissant intactes les sections de débogage. Dans les fichiers ELF, cela préserve également toutes les sections de notes dans la sortie.

Remarque : les en-têtes des sections supprimées sont préservés, y compris leurs tailles, mais le contenu de la section est rejeté. Les en-têtes de section sont préservés afin que d'autres outils puissent faire correspondre le fichier de débogage avec l'exécutable réel, même si cet exécutable a été déplacé vers un espace d'adressage différent.

L'intention est que cette option soit utilisée conjointement avec --add-gnu-debuglink pour créer un exécutable en deux parties. L'une est un binaire dépouillé qui occupera moins d'espace en RAM et dans une distribution, et la seconde est un fichier d'informations de débogage qui n'est nécessaire que si des capacités de débogage sont requises. La procédure suggérée pour créer ces fichiers est la suivante :

1.<Lier l'exécutable normalement. En supposant qu'il s'appelle>
« foo », alors...
1.<Exécuter "objcopy --only-keep-debug foo foo.dbg" pour>
créer un fichier contenant les informations de débogage.
1.<Exécuter "objcopy --strip-debug foo" pour créer un>
exécutable dépouillé.
1.<Exécuter "objcopy --add-gnu-debuglink=foo.dbg foo">
pour ajouter un lien vers les informations de débogage dans l'exécutable dépouillé.

Remarque : le choix de « .dbg » comme extension pour le fichier d'informations de débogage est arbitraire. De plus, l'étape « --only-keep-debug » est facultative. Vous pouvez faire ceci à la place :

1.<Lier l'exécutable normalement.>
1.<Copier "foo" vers "foo.full">
1.<Exécuter "strip --strip-debug foo">
1.<Exécuter "objcopy --add-gnu-debuglink=foo.full foo">

c'est-à-dire que le fichier pointé par --add-gnu-debuglink peut être l'exécutable complet. Il n'a pas besoin d'être un fichier créé par l'option --only-keep-debug.

Remarque : cette option est uniquement destinée à être utilisée sur des fichiers entièrement liés. Il n'est pas logique de l'utiliser sur des fichiers objets où les informations de débogage peuvent être incomplètes. De plus, la fonctionnalité gnu_debuglink ne prend actuellement en charge que la présence d'un seul nom de fichier contenant des informations de débogage, et non de plusieurs noms de fichiers sur une base un par fichier objet.

-p
--preserve-dates
L'inverse de l'option -D, ci-dessus : lors de la copie des membres d'archive et de l'écriture de l'index d'archive, utilisez leurs valeurs réelles d'UID, GID, horodatage et mode de fichier.

C'est le comportement par défaut, sauf si binutils a été configuré avec --enable-deterministic-archives.

-w
-X
--discard-locals
Supprime les symboles locaux générés par le compilateur. (Ceux-ci commencent généralement par L ou ..)
-V
--version
Affiche le numéro de version de strip.
-v
--verbose
Sortie détaillée : liste tous les fichiers objets modifiés. Dans le cas des archives, strip -v liste tous les membres de l'archive.
@file
Lit les options de la ligne de commande depuis file. Les options lues sont insérées à la place de l'option originale @file. Si file n'existe pas, ou ne peut pas être lu, alors l'option sera traitée littéralement, et non supprimée.

Les options dans file sont séparées par des espaces blancs. Un caractère d'espace blanc peut être inclus dans une option en entourant l'option entière de guillemets simples ou doubles. N'importe quel caractère (y compris un antislash) peut être inclus en faisant précéder le caractère à inclure par un antislash. Le file peut lui-même contenir des options supplémentaires @file ; toutes ces options seront traitées récursivement.
