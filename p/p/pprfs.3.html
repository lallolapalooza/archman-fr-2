CPPRFS

Purpose:

!>
!> CPPRFS improves the computed solution to a system of linear
!> equations when the coefficient matrix is Hermitian positive definite
!> and packed, and provides error bounds and backward error estimates
!> for the solution.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrices B and X.  NRHS >= 0.
!>

AP

!>          AP is COMPLEX array, dimension (N*(N+1)/2)
!>          The upper or lower triangle of the Hermitian matrix A, packed
!>          columnwise in a linear array.  The j-th column of A is stored
!>          in the array AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
!>

AFP

!>          AFP is COMPLEX array, dimension (N*(N+1)/2)
!>          The triangular factor U or L from the Cholesky factorization
!>          A = U**H*U or A = L*L**H, as computed by SPPTRF/CPPTRF,
!>          packed columnwise in a linear array in the same format as A
!>          (see AP).
!>

B

!>          B is COMPLEX array, dimension (LDB,NRHS)
!>          The right hand side matrix B.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

X

!>          X is COMPLEX array, dimension (LDX,NRHS)
!>          On entry, the solution matrix X, as computed by CPPTRS.
!>          On exit, the improved solution matrix X.
!>

LDX

!>          LDX is INTEGER
!>          The leading dimension of the array X.  LDX >= max(1,N).
!>

FERR

!>          FERR is REAL array, dimension (NRHS)
!>          The estimated forward error bound for each solution vector
!>          X(j) (the j-th column of the solution matrix X).
!>          If XTRUE is the true solution corresponding to X(j), FERR(j)
!>          is an estimated upper bound for the magnitude of the largest
!>          element in (X(j) - XTRUE) divided by the magnitude of the
!>          largest element in X(j).  The estimate is as reliable as
!>          the estimate for RCOND, and is almost always a slight
!>          overestimate of the true error.
!>

BERR

!>          BERR is REAL array, dimension (NRHS)
!>          The componentwise relative backward error of each solution
!>          vector X(j) (i.e., the smallest relative change in
!>          any element of A or B that makes X(j) an exact solution).
!>

WORK

!>          WORK is COMPLEX array, dimension (2*N)
!>

RWORK

!>          RWORK is REAL array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>

Internal Parameters:

!>  ITMAX is the maximum number of steps of iterative refinement.
!>

Nom

DPPRFS - Améliore la solution calculée d'un système d'équations linéaires et fournit des bornes d'erreur et des estimations d'erreur rétrograde pour la solution.

Synopsis

SUBROUTINE DPPRFS(UPLO, N, NRHS, AP, AFP, B, LDB, X, LDX, FERR, BERR, WORK, IWORK, INFO)

  CHARACTER(LEN=1) UPLO
  INTEGER N, NRHS, LDB, LDX, INFO
  DOUBLE PRECISION AP(*), AFP(*), B(LDB, *), X(LDX, *), FERR(*), BERR(*), WORK(*)
  INTEGER IWORK(*)

Description

DPPRFS améliore la solution calculée d'un système d'équations linéaires lorsque la matrice des coefficients est symétrique définie positive et empaquetée, et fournit des bornes d'erreur et des estimations d'erreur rétrograde pour la solution.

L'argument UPLO spécifie si le triangle supérieur ou inférieur de la matrice A est stocké.

Les arguments N et NRHS spécifient l'ordre de la matrice A et le nombre de colonnes des matrices B et X, respectivement.

Les arguments AP et AFP sont des tableaux de précision double contenant respectivement la matrice A et sa factorisation de Cholesky.

Les arguments B et X sont des tableaux de précision double contenant respectivement le côté droit et la solution du système d'équations linéaires.

Les arguments LDB et LDX spécifient les dimensions principales des tableaux B et X, respectivement.

Les arguments FERR et BERR sont des tableaux de précision double retournant respectivement les bornes d'erreur avant estimées et les erreurs rétrogrades relatives par composante pour chaque vecteur solution.

Les arguments WORK et IWORK sont des tableaux de travail utilisés par la routine.

L'argument INFO est un entier retournant le statut de sortie.

Paramètres

UPLO

UPLO est CHARACTER*1

= 'U': Le triangle supérieur de A est stocké ;

= 'L': Le triangle inférieur de A est stocké.

N

N est INTEGER

L'ordre de la matrice A. N >= 0.

NRHS

NRHS est INTEGER

Le nombre de côtés droits, c'est-à-dire le nombre de colonnes des matrices B et X. NRHS >= 0.

AP

AP est un tableau DOUBLE PRECISION, dimension (N*(N+1)/2)

Le triangle supérieur ou inférieur de la matrice symétrique A, empaqueté par colonne dans un tableau linéaire. La j-ème colonne de A est stockée dans le tableau AP comme suit :

si UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) pour 1<=i<=j ;

si UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) pour j<=i<=n.

AFP

AFP est un tableau DOUBLE PRECISION, dimension (N*(N+1)/2)

Le facteur triangulaire U ou L de la factorisation de Cholesky A = U**T*U ou A = L*L**T, tel que calculé par DPPTTRF/CPPTTRF, empaqueté par colonne dans un tableau linéaire dans le même format que AP (voir AP).

B

B est un tableau DOUBLE PRECISION, dimension (LDB,NRHS)

La matrice du côté droit B.

LDB

LDB est INTEGER

La dimension principale du tableau B. LDB >= max(1,N).

X

X est un tableau DOUBLE PRECISION, dimension (LDX,NRHS)

En entrée, la matrice solution X, telle que calculée par DPPTTRS.

En sortie, la matrice solution améliorée X.

LDX

LDX est INTEGER

La dimension principale du tableau X. LDX >= max(1,N).

FERR

FERR est un tableau DOUBLE PRECISION, dimension (NRHS)

La borne d'erreur avant estimée pour chaque vecteur solution X(j) (la j-ème colonne de la matrice solution X).

Si XTRUE est la vraie solution correspondant à X(j), FERR(j) est une borne supérieure estimée de la magnitude de l'élément le plus grand dans (X(j) - XTRUE) divisée par la magnitude de l'élément le plus grand dans X(j). L'estimation est aussi fiable que l'estimation pour RCOND, et est presque toujours une légère surestimation de l'erreur réelle.

BERR

BERR est un tableau DOUBLE PRECISION, dimension (NRHS)

L'erreur rétrograde relative par composante de chaque vecteur solution X(j) (c'est-à-dire, le plus petit changement relatif dans n'importe quel élément de A ou B qui fait de X(j) une solution exacte).

WORK

WORK est un tableau DOUBLE PRECISION, dimension (3*N)

IWORK

IWORK est un tableau INTEGER, dimension (N)

INFO

INFO est INTEGER

= 0: sortie réussie

< 0: si INFO = -i, le i-ème argument avait une valeur illégale

Paramètres internes

ITMAX est le nombre maximum d'étapes de raffinement itératif.

Zpprfs(3) - LAPACK

NAME

zpprfs - zpprfs

SYNOPSIS

SUBROUTINE ZPPRFS(
     UPLO, N, NRHS, AP, B, LDB, X, LDX, FERR, BERR, WORK, RWORK, INFO
    )


     CHARACTER * 1 UPLO
     INTEGER N, NRHS, LDB, LDX, INFO
     COMPLEX*16 AP( * ), B( LDB, * ), X( LDX, * )
     DOUBLE PRECISION FERR( * ), BERR( * )
     COMPLEX*16 WORK( * )
     DOUBLE PRECISION RWORK( * )

Detailed Description

ZPPRFS calcule une estimation de l'erreur relative sur la solution du système d'équations linéaires P*X = B, où P est une matrice triangulaire par blocs complexe hermitienne par morceaux, pour plusieurs vecteurs de second membre.

Il s'agit d'une routine de raffinement itératif.

Arguments :

  • UPLO

    CHARACTER*1. ='U': P est supérieure par blocs;

    ='L': P est inférieure par blocs.

  • N

    INTEGER. Ordre de la matrice P. N >= 0.

  • NRHS

    INTEGER. Nombre de colonnes de la matrice B. NRHS >= 0.

  • AP

    COMPLEX*16 array, dimension (N*(N+1)/2). Partie triangulaire de la matrice P, stockée par blocs.

  • B

    COMPLEX*16 array, dimension (LDB,NRHS). Matrice du second membre, dont les colonnes sont les vecteurs B_j.

  • LDB

    INTEGER. Leading dimension of the array B. LDB >= max(1,N).

  • X

    COMPLEX*16 array, dimension (LDX,NRHS). Sur l'entrée, X est une matrice dont les colonnes sont des estimations des solutions X_j des systèmes P*X = B. Sur la sortie, X est la solution raffinée.

  • LDX

    INTEGER. Leading dimension of the array X. LDX >= max(1,N).

  • FERR

    DOUBLE PRECISION array, dimension (NRHS). Sur la sortie, FERR(j) est une estimation ascendante de l'erreur relative sur la j-ième solution, c'est-à-dire, la plus petite modification relative de tout élément de A ou B qui rend X(j) une solution exacte.

  • BERR

    DOUBLE PRECISION array, dimension (NRHS). Sur la sortie, BERR(j) est une estimation ascendante de l'erreur relative sur la j-ième solution, c'est-à-dire, la plus petite modification relative de tout élément de A ou B qui rend X(j) une solution exacte.

  • WORK

    WORK est COMPLEX*16 array, dimension (2*N)

  • RWORK

    RWORK est DOUBLE PRECISION array, dimension (N)

  • INFO

    INFO est INTEGER

    = 0: sortie réussie

    < 0: si INFO = -i, le i-ème argument avait une valeur illégale

Paramètres internes

!>  ITMAX est le nombre maximum d'étapes de raffinement itératif.
