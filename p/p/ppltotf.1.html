PPLTOTF(1) Manuel des commandes générales PPLTOTF(1)

NOM

ppltotf, uppltotf - Créer une métrique de police pTeX japonaise (JFM)

SYNOPIS

ppltotf [options] nom_fichier_pl[.pl] [nom_fichier_tfm[.tfm]]

DESCRIPTION

Le programme ppltotf traduit un fichier de liste de propriétés japonaise (JPL) en un fichier de métriques de police pTeX japonaise (JFM). Le fichier JFM résultant peut être utilisé avec pTeX et e-pTeX.

Le programme uppltotf est une version prenant en charge Unicode de ppltotf. Le fichier JFM résultant peut être utilisé avec upTeX et e-upTeX.

Dans les sections suivantes, nous faisons référence à ces programmes comme (u)ppltotf.

(u)ppltotf est compatible par le haut avec pltotf ; si le fichier PL d'entrée concerne des polices romaines, il est traduit en un fichier de métriques de police TeX (TFM) ordinaire. La différence entre ppltotf et uppltotf réside dans le codage de sortie : ppltotf produit toujours un JFM codé JIS ; en revanche, uppltotf produit un JFM codé Unicode par défaut.

OPTIONS

Comparé à pltotf, l'option suivante est ajoutée à (u)ppltotf.

-kanji chaîne
Définit le code Kanji japonais d'entrée. La chaîne peut être l'une des suivantes : euc (EUC-JP), jis (ISO-2022-JP), sjis (Shift_JIS), utf8 (UTF-8), uptex (UTF-8 ; uppltotf uniquement).

Lorsqu'un des codes euc, jis, sjis ou utf8 est spécifié, ppltotf et uppltotf produisent un JFM codé JIS. Lorsque uptex est spécifié avec uppltotf, il produit un JFM codé Unicode.

VOIR AUSSI

ptex(1).
