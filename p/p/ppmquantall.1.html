NOM

ppmquantall - remplacé par pnmquantall

DESCRIPTION

Ce programme fait partie de Netpbm(1)

ppmquantall a été remplacé par pnmquantall(1), introduit avec Netpbm 10.58 (mars 2012). pnmquantall n'est qu'un changement de nom pour refléter le fait que le programme gère tous types de fichiers d'entrée Netpbm, pas seulement PPM. Bien que cela n'ait pas toujours été le cas, c'était le cas depuis de nombreuses années avant le changement de nom.

Pour les versions de Netpbm antérieures à 10.58, où le programme s'appelle toujours ppmquantall, utilisez simplement le manuel de pnmquantall.
