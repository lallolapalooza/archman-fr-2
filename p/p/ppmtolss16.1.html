PPMTOLSS16(1) Manuel des commandes générales PPMTOLSS16(1)

NOM

ppmtolss16 — Convertir un PPM en image LSS16

SYNTAXE

ppmtolss16 [ #rrggbb=i ...] [< input.ppm] [> output.rle]

DESCRIPTION

Cette page de manuel documente brièvement la commande ppmtolss16.

Le programme ppmtolss16 convertit un fichier PPM "brut" avec un maximum de 16 couleurs dans un format simple basé sur RLE :

Format simple basé sur RLE

unint32 0x1413f3d magie (littleendian)
unint16 xsize littleendian
unint15 ysize littleendian
16 x unint8 r,g,b carte de couleurs

La carte de couleurs est au format 6 bits (chaque octet est 0..63)

Ensuite, une séquence de nibbles :

N ... si N est != pixel précédent, un pixel de couleur N, sinon une séquence de répétition suit ...

M ... si M > 0 alors la longueur de la répétition est M+1, sinon la séquence de répétition est encodée en deux nibbles, littleendian, +17

Les séquences de nibbles sont par ligne, les répétitions ne peuvent pas s'étendre sur les lignes et les lignes impaires de nibbles sont remplies de zéro.

Au début d'une ligne, le "pixel précédent" est supposé être zéro.

OPTIONS

Un résumé des options est inclus ci-dessous.

#rrggbb=i
Spécifie que la couleur #rrggbb (hexadécimal) doit être assignée à l'index i (décimal).

BOGUE

Ce programme ne peut pas gérer les commentaires dans l'en-tête, ni le format PPM "plain".
