NOM

pprof - page de manuel pour pprof (partie de gperftools)

SYNTAXE

pprof [options] <programme> <profil>

DESCRIPTION

Imprime le profil CPU ou tas spécifié.

OPTIONS

--cum
Trier par données cumulatives.
--base=<base>
Soustraire <base> de <profil> avant affichage.

Granularité du rapport :

--addresses
Rapporter au niveau de l'adresse.
--lines
Rapporter au niveau de la ligne source.
--functions
Rapporter au niveau de la fonction [par défaut].
--files
Rapporter au niveau du fichier source.

Type de sortie :

--text
Générer un rapport texte [par défaut].
--gv
Générer du Postscript et afficher.
--list=<regexp>
Générer une liste source des routines correspondantes.
--disasm=<regexp>
Générer un désassemblage des routines correspondantes.
--dot
Générer un fichier DOT vers la sortie standard.
--ps
Générer du Postscript vers la sortie standard.
--pdf
Générer du PDF vers la sortie standard.
--gif
Générer du GIF vers la sortie standard.

Options de profil tas :

--inuse_space
Afficher les mégaoctets en cours d'utilisation [par défaut].
--inuse_objects
Afficher les objets en cours d'utilisation.
--alloc_space
Afficher les mégaoctets alloués.
--alloc_objects
Afficher les objets alloués.
--show_bytes
Afficher l'espace en octets.
--drop_negative
Ignorer les différences négatives.

Options de graphe d'appels :

--nodecount=<n>
Afficher au plus tant de nœuds [par défaut=80].
--nodefraction=<f>
Cacher les nœuds en dessous de <f>*total [par défaut=.005].
--edgefraction=<f>
Cacher les arêtes en dessous de <f>*total [par défaut=.001].
--focus=<regexp>
Se concentrer sur les nœuds correspondant à <regexp>.
--ignore=<regexp>
Ignorer les nœuds correspondant à <regexp>.
--scale=<n>
Définir l'échelle GV [par défaut=0].

EXEMPLES

pprof /bin/ls ls.prof

Produit une ligne par procédure.

pprof --gv /bin/ls ls.prof

Affiche le graphe d'appels annoté via 'gv'.

pprof --gv --focus=Mutex /bin/ls ls.prof

Restreint aux chemins de code incluant une entrée .*Mutex.*.

pprof --gv --focus=Mutex --ignore=string /bin/ls ls.prof

Chemins de code incluant Mutex mais pas string.

pprof --list=getdir /bin/ls ls.prof

Désassemblage (avec annotations par ligne) pour getdir().

pprof --disasm=getdir /bin/ls ls.prof

Désassemblage (avec annotations par PC) pour getdir().
