NOM

ppdmerge - fusionner des fichiers ppd (obsolète)

SYNTAXE

ppdmerge [ -o fichier-ppd-sortie ] fichier-ppd fichier-ppd [ ... fichier-ppd ]

DESCRIPTION

ppdmerge fusionne deux fichiers PPD ou plus en un seul fichier PPD multilingue. Ce programme est obsolète et sera supprimé dans une future version de CUPS.

OPTIONS

ppdmerge supporte les options suivantes :

-o fichier-ppd-sortie
Spécifie le fichier PPD à créer. S'il n'est pas spécifié, le fichier PPD fusionné est écrit sur la sortie standard. Si le fichier de sortie existe déjà, il est silencieusement écrasé.

NOTES

Les fichiers PPD sont obsolètes et ne seront plus supportés dans une future version de CUPS. Les imprimantes qui ne supportent pas IPP peuvent être supportées à l'aide d'applications telles que ippeveprinter(1).

ppdmerge ne vérifie pas si les fichiers PPD fusionnés sont pour le même appareil. La fusion de PPDs d'appareils différents donnera des résultats imprévisibles.
