NOM

radattr.so - Plugin utilitaire RADIUS pour pppd(8)

SYNTAXE

pppd [ options ] plugin radius.so plugin radattr.so

DESCRIPTION

Le plugin radattr pour pppd fait que tous les attributs RADIUS retournés par le serveur RADIUS au moment de l'authentification sont stockés dans le fichier /var/run/radattr.pppN où pppN est le nom de l'interface PPP. Les attributs RADIUS sont stockés un par ligne dans le format « Nom-Attribut Valeur-Attribut ». Ce format est pratique pour une utilisation dans les scripts /etc/ppp/ip-up et /etc/ppp/ip-down.

Notez que vous devez charger le plugin radius.so avant de charger le plugin radattr.so ; radattr.so dépend de symboles définis dans radius.so.

UTILISATION

Pour utiliser le plugin, fournissez simplement les options plugin radius.so plugin radattr.so à pppd.
