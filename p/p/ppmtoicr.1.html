NOM

ppmtoicr - convertir une image PPM au format NCSA ICR

SYNTAXE

ppmtoicr

[-windowname nom]

[-expand expansion]

[-display affichage]

[-rle]

[fichierppm]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

ppmtoicr lit un fichier PPM en entrée. Il produit un fichier graphique raster couleur interactif NCSA Telnet en sortie.

Si fichierppm n'est pas fourni, ppmtoicr lit depuis l'entrée standard.

Interactive Color Raster (ICR) est un protocole pour afficher des graphiques raster sur les écrans de stations de travail. Le protocole est implémenté dans NCSA Telnet pour Macintosh version 2.3. Le protocole ICR partage des caractéristiques avec le protocole d'émulation de terminal graphique Tektronix. Par exemple, des séquences d'échappement sont utilisées pour contrôler l'affichage.

ppmtoicr produira les séquences appropriées pour créer une fenêtre des dimensions de l'image d'entrée, créer une palette de couleurs jusqu'à 256 couleurs sur l'écran, puis charger les données de l'image dans la fenêtre.

Notez qu'il n'existe pas d'outil icrtoppm - cette transformation est à sens unique.

OPTIONS

-windowname nom
La sortie sera affichée dans nom (Par défaut, utilisation de fichierppm ou 'untitled' si l'entrée provient de l'entrée standard).
-expand expansion
La sortie sera agrandie à l'affichage par un facteur expansion (Par exemple, une valeur de 2 entraînera l'affichage de quatre pixels pour chaque pixel d'entrée.)
-display affichage
La sortie sera affichée sur l'écran numéro affichage
-rle
Utiliser le format à codage par longueur de course (run-length encoded) pour l'affichage. (Cela entraînera presque toujours un affichage plus rapide, mais peut fausser la palette de couleurs).

EXEMPLES

Pour afficher un fichier PPM nommé fichierppm en utilisant le protocole :

    ppmtoicr fichierppm

Cela créera une fenêtre nommée fichierppm sur l'affichage avec les bonnes dimensions pour fichierppm, créera et téléchargera une palette de couleurs jusqu'à 256 couleurs, et téléchargera l'image dans la fenêtre. Vous pouvez obtenir le même effet avec la séquence suivante :

    ppmtoicr fichierppm > nomfichier
    cat nomfichier

Pour afficher un fichier GIF en utilisant le protocole dans une fenêtre titrée d'après le fichier d'entrée, zoomer l'image affichée par un facteur de 2, et coder les données par longueur de course :

    giftopnm ficchiergif | ppmtoicr -w ficchiergif -r -e 2

LIMITATIONS

Le protocole utilise des appels fréquents à fflush() pour accélérer l'affichage. Si vous enregistrez la sortie dans un fichier pour un affichage ultérieur via cat, ppmtoicr dessinera beaucoup plus lentement. Dans les deux cas, augmenter la limite de taille de bloc sur l'affichage accélérera considérablement la transmission.
