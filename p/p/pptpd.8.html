NOM

pptpd - démon VPN PPTP

SYNTAXE

pptpd [ options ]

DESCRIPTION

pptpd est le démon Poptop PPTP, qui gère les connexions PPP tunnelisées encapsulées dans GRE en utilisant le protocole VPN PPTP. Il peut contenir des fonctionnalités telles que la gestion des adresses IP et les wrappers TCP s'ils sont compilés.

OPTIONS

Nous documentons ici les options en ligne de commande. Voir pptpd.conf(5) pour les directives de configuration, l'allocation d'adresses IP, le routage et les règles de pare-feu.

-b|--bcrelay interface-interne
spécifie que les broadcasts reçus sur l'interface réseau interne du serveur doivent être relayés aux clients.
-c|--conf fichier-conf
spécifie le fichier de configuration pour pptpd (par défaut /etc/pptpd.conf)
-d|--debug
active le mode débogage, provoquant l'envoi de plus de messages de débogage à syslog.
-e|--ppp programme-ppp
utilise programme-ppp à la place du pppd(8) par défaut.
-f|--fg
exécute en premier plan au lieu de se détacher du terminal.
-h|--help
affiche l'aide du programme.
-i|--noipparam
n'envoie pas l'adresse IP du client aux scripts ip-up (nécessaire si vous utilisez l'option ipparam de pppd(8) pour un autre usage).
-l|--listen x.x.x.x
spécifie l'adresse IP de l'interface locale sur laquelle écouter.
-o|--option fichier-conf-ppp
spécifie que pptpd doit utiliser un fichier de configuration alternatif pour le démon ppp (le fichier par défaut est normalement /etc/ppp/options mais peut varier en fonction de votre démon ppp).
-p|--pidfile fichier-pid
spécifie un emplacement alternatif pour stocker le fichier d'ID de processus (par défaut /var/run/pptpd.pid).
-s|--speed débit
spécifie que le débit débit doit être passé au démon ppp comme débit du port série à utiliser (dans certains cas, cela est ignoré par le démon ppp).
-t|--stimeout secondes
spécifie le nombre de secondes à attendre pour le premier paquet avant de rejetter la connexion. Ceci est une fonctionnalité de protection contre les attaques par déni de service.
-w|--logwtmp
met à jour wtmp(5) lorsque les utilisateurs se connectent et se déconnectent. Voir wtmp(1).
-C|--connections n
limite le nombre de connexions clients qui peuvent être acceptées. Correspond à l'option connections dans pptpd.conf. Si pptpd alloue des adresses IP (par exemple, si --delegate n'est pas utilisé), le nombre de connexions est également limité par l'option remoteip dans pptpd.conf.
-D|--delegate
délègue l'allocation des adresses IP clients à pppd(8). Sans cette option, qui est la valeur par défaut, pptpd gère la liste des adresses IP pour les clients et transmet la prochaine adresse libre à pppd. Avec cette option, pptpd ne transmet pas d'adresse, et pppd peut donc utiliser radius ou chap-secrets pour allouer une adresse.
-V|--vrf nom-vrf
spécifie le VRF à utiliser pour l'écoute.
-v|--version
affiche la version actuelle du démon pptp.

FICHIERS

/etc/pptpd.conf
/var/run/pptpd.pid

DEBOGAGE

Pour activer le débogage, ajoutez 'debug' à /etc/pptpd.conf et à votre fichier d'options PPP, puis redémarrez pptpd.

En général, le fichier d'options PPP est options.pptpd dans /etc/ppp, bien que sur certaines distributions, il puisse s'agir de pptpd-options. Utilisez votre gestionnaire de paquets pour le trouver, par exemple 'rpm -ql pptpd | grep options' ou 'dpkg --listfiles pptpd | grep options'.

Vous devrez peut-être configurer syslogd pour capturer les messages de débogage. Par exemple, modifiez /etc/syslog.conf et ajoutez quelque chose de similaire à l'exemple ci-dessous, puis redémarrez syslogd.

# journalisation de débogage
*.debug;mail.none /var/log/debug

Ceci enregistrera toutes les informations de débogage, à l'exception de celles relatives au courrier, dans le fichier /var/log/debug. Notez qu'il s'agit d'une grande quantité d'informations et que cela pourrait saturer vos disques. Si les performances sont un problème, vous pouvez essayer de désactiver la synchronisation pendant votre débogage, en préfixant la destination par '-'.

# journalisation de débogage
*.debug;mail.none -/var/log/debug

Désactivez cette ligne et redémarrez syslog une fois le débogage terminé. Voir les pages de manuel de syslog pour plus de détails.

NOM

pptpd — Daemon de serveur Point-to-Point Protocol over IP

SYNOPSIS

pptpd [-b] [-c config] [-d] [-e] [-f] [-h] [-i] [-l logfile] [-o] [-p pidfile] [-s speed] [-v]

DESCRIPTION

pptpd est un démon de serveur qui implémente le Point-to-Point Protocol (PPP) sur le réseau IP. Il permet aux clients PPTP (souvent appelés clients VPN) de se connecter à un serveur Linux et d'obtenir une connectivité réseau via le protocole PPP.

pptpd écoute les connexions TCP entrantes sur le port 1723 (par défaut). Lorsqu'une connexion est établie, il négocie une connexion PPP avec le client. Les paramètres de connexion PPP, tels que les adresses IP, les serveurs DNS, etc., sont généralement configurés dans le fichier de configuration pptpd.conf.

OPTIONS

-b
Mode de fond (daemon). pptpd se détache du terminal et s'exécute en arrière-plan.
-c config
Spécifie le fichier de configuration à utiliser. Par défaut, il s'agit de /etc/pptpd.conf.
-d
Activer le débogage détaillé. Utile pour le dépannage.
-e
Ne pas relancer les connexions PPTP sur erreur.
-f
Ne pas effectuer de requête DNS inverse.
-h
Afficher un message d'aide et quitter.
-i
Ne pas se soucier des paquets IGMP.
-l logfile
Spécifie le fichier journal à utiliser. Par défaut, les journaux sont envoyés à syslog.
-o
Ne pas gérer le protocole MPPE.
-p pidfile
Spécifie le fichier PID. Par défaut, il s'agit de /var/run/pptpd.pid.
-s speed
Définir la vitesse de la ligne virtuelle (par exemple, 115200). Ceci est rarement utilisé avec PPTP car la vitesse est dynamique.
-v
Afficher la version de pptpd et quitter.

FICHIERS

/etc/pptpd.conf
Fichier de configuration principal pour pptpd. Il contient des paramètres tels que les adresses IP à attribuer aux clients, les serveurs DNS, les options PPP, etc.
/etc/ppp/chap-secrets
Fichier contenant les noms d'utilisateur et mots de passe pour l'authentification CHAP.
/etc/ppp/pap-secrets
Fichier contenant les noms d'utilisateur et mots de passe pour l'authentification PAP.
/var/run/pptpd.pid
Fichier contenant le PID du processus pptpd en cours d'exécution.

DÉBOGAGE

Utilisez l'option -d pour activer le débogage détaillé. Les messages de débogage seront envoyés à syslog ou au fichier spécifié par l'option -l. L'examen des journaux système (souvent dans /var/log/syslog ou /var/log/messages) est essentiel pour le dépannage des problèmes de connexion.
