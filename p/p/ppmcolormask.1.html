NOM

ppmcolormask - produire un masque des zones d'une certaine couleur dans un fichier PPM

SYNTAXE

ppmcolormask -couleur=liste_couleurs [fichierppm]

ppmcolormask couleur [fichierppm]

EXEMPLES


    ppmcolormask -couleur rouge testimg.ppm >redmask.pbm
    pamcomp background.ppm testimg.ppm -alpha=redmask.pbm >test.ppm
    ppmcolormask -couleur=rouge,rose,saumon testimg.ppm >reddishmask.pbm
    ppmcolormask -couleur=bk:rouge,bk:orange,bk:jaune testimg.ppm >firemask.pbm

DESCRIPTION

Ce programme fait partie de Netpbm(1)

ppmcolormask lit un fichier PPM en entrée et produit un fichier PBM (bitmap) en sortie. Le fichier de sortie a les mêmes dimensions que le fichier d'entrée et est noir dans tous les endroits où le fichier d'entrée a une couleur indiquée par l'option -couleur, et blanc partout ailleurs.

La sortie de ppmcolormask est utile comme masque alpha en entrée pour pamcomp. Notez que vous pouvez générer automatiquement un tel masque alpha lors de la conversion au format PNG avec l'option pnmtopng(1).

fichierppm est le fichier d'entrée. Si vous ne spécifiez pas fichierppm, l'entrée provient de l'entrée standard.

La sortie va vers la sortie standard.

Dans la syntaxe alternative obsolète, spécifier la couleur nomme une seule couleur exacte à masquer.

ppmchange fait quelque chose de similaire : il modifie une image en changeant les couleurs que vous spécifiez en d'autres couleurs que vous spécifiez. Les deux programmes vous donnent des moyens quelque peu différents de spécifier les couleurs dans l'image d'entrée.

Pour créer un masque de l'arrière-plan d'une image, sans avoir à lui dire de quelle couleur il s'agit, utilisez pambackground.

OPTIONS

-couleur=liste_couleurs
Cette option obligatoire spécifie les couleurs qui doivent être masquées (là où l'image est l'une de ces couleurs, le masque de sortie sera noir).

Exemples :

  • -couleur=rouge
  • -couleur=rouge,rose,saumon
  • -couleur=rgb:80/80/ff
  • -couleur=bk:rouge,bk:orange,bk:jaune

    liste_couleurs est une liste de couleurs séparées par des virgules. Chaque couleur est soit un nom de couleur exact tel que décrit pour l'argument de la routine de bibliothèque ppm_parsecolor() ici , soit l'un des noms de couleur de Berlin-Kay. Dans ce dernier cas, toutes les couleurs qui sont mieux décrites par ce nom de couleur de Berlin-Kay que par tout autre sont incluses dans l'ensemble du masque.

    L'algorithme utilisé par ppmcolormask pour déterminer à quelles couleurs un nom de couleur de Berlin-Kay s'applique est basé sur un système d'inférence floue de type Sugeno développé par Kenan Kalajdzic en 2006. Le modèle flou se compose de fonctions d'appartenance partiellement linéaires définies dans l'espace colorimétrique HSV. Bien que des algorithmes plus complexes de correspondance floue des couleurs existent, cet algorithme est intentionnellement simplifié pour atteindre une vitesse satisfaisante en utilisant un code relativement compact.

    Cette option a été ajoutée dans Netpbm 10.34 (juin 2006). Avant cela, vous deviez utiliser l'argument couleur et ne pouviez pas spécifier une couleur de Berlin-Kay.
