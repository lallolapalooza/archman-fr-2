ppufiles(1) Liste des fichiers objet des unités Pascal FPC ppufiles(1)

NOM

ppufiles - Le listeur de fichiers objet des unités Pascal FPC.

SYNTAXE

ppufiles [options] [fichier [fichier [fichier]]]

Description

ppufiles liste tous les fichiers binaires nécessaires à la liaison d'un fichier unité. Cela inclut tous les fichiers objet ou bibliothèques qui doivent être liés via une directive dans l'unité.

Utilisation

Vous pouvez invoquer ppufiles avec comme arguments le nom des unités dont vous souhaitez lister les fichiers objet. Une extension doit être fournie. Ceci peut être utile pour créer une liste de tous les fichiers objet générés et les supprimer dans un Makefile.

Options

ppufiles a plusieurs options, qui ne sont pas sensibles à la casse :

-a
Cette option indique à ppufiles de lister tous les fichiers.
-h
Écran d'aide.
-l
Cette option indique à ppufiles de lister uniquement les bibliothèques partagées.
-o
Cette option indique à ppufiles de lister uniquement les fichiers objet.
-s
Cette option indique à ppufiles de lister uniquement les bibliothèques statiques.

ERREURS

Si l'unité est dans un format plus ancien ou non reconnu, ppufiles s'en plaindra.
