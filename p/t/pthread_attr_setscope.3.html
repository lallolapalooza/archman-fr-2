pthread_attr_setscope(3) Manuel des fonctions de bibliothèque pthread_attr_setscope(3)

NOM

pthread_attr_setscope, pthread_attr_getscope - définir/obtenir l'attribut de portée de contention dans un objet d'attributs de thread

BIBLIOTHQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <pthread.h>
int pthread_attr_setscope(pthread_attr_t *attr, int scope);
int pthread_attr_getscope(const pthread_attr_t *restrict attr,
                          int *restrict scope);

DESCRIPTION

La fonction pthread_attr_setscope() définit l'attribut de portée de contention de l'objet d'attributs de thread référencé par attr à la valeur spécifiée dans scope. L'attribut de portée de contention définit l'ensemble des threads contre lesquels un thread est en compétition pour les ressources telles que le CPU. POSIX.1 spécifie deux valeurs possibles pour scope :

PTHREAD_SCOPE_SYSTEM
Le thread est en compétition pour les ressources avec tous les autres threads de tous les processus du système qui se trouvent dans le même domaine d'allocation de planification (un groupe d'un ou plusieurs processeurs). Les threads PTHREAD_SCOPE_SYSTEM sont planifiés les uns par rapport aux autres selon leur politique de planification et leur priorité.
P THREAD_SCOPE_PROCESS
Le thread est en compétition pour les ressources avec tous les autres threads du même processus qui ont également été créés avec la portée de contention PTHREAD_SCOPE_PROCESS. Les threads PTHREAD_SCOPE_PROCESS sont planifiés les uns par rapport aux autres dans le processus selon leur politique de planification et leur priorité. POSIX.1 ne spécifie pas comment ces threads sont en compétition avec d'autres threads d'autres processus du système ou avec d'autres threads du même processus qui ont été créés avec la portée de contention PTHREAD_SCOPE_SYSTEM.

POSIX.1 exige qu'une implémentation prenne en charge au moins une de ces portées de contention. Linux prend en charge PTHREAD_SCOPE_SYSTEM, mais pas PTHREAD_SCOPE_PROCESS.

Dans les systèmes qui prennent en charge plusieurs portées de contention, le paramètre défini par pthread_attr_setscope() aura un effet lors de l'appel à pthread_create(3), si l'appelant utilise pthread_attr_setinheritsched(3) pour définir l'attribut d'héritage du planificateur de l'objet d'attributs attr sur PTHREAD_EXPLICIT_SCHED.

La fonction pthread_attr_getscope() renvoie l'attribut de portée de contention de l'objet d'attributs de thread référencé par attr dans le tampon pointé par scope.

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient 0 ; en cas d'erreur, elles renvoient un numéro d'erreur non nul.

ERREURS

pthread_attr_setscope() peut échouer avec les erreurs suivantes :

EINVAL
Une valeur invalide a été spécifiée dans scope.
ENOTSUP
scope a spécifié la valeur PTHREAD_SCOPE_PROCESS, qui n'est pas prise en charge sous Linux.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_attr_setscope (), pthread_attr_getscope () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

NOTES

La portée de contention PTHREAD_SCOPE_SYSTEM indique généralement qu'un thread utilisateur est directement lié à une seule entité de planification du noyau. C'est le cas sous Linux pour l'implémentation obsolète LinuxThreads et l'implémentation moderne NPTL, qui sont toutes deux des implémentations de threading 1:1.

POSIX.1 spécifie que la portée de contention par défaut est définie par l'implémentation.
