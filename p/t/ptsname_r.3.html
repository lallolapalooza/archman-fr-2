ptsname(3) Manuel des fonctions de bibliothèque ptsname(3)

NOM

ptsname, ptsname_r - obtenir le nom du pseudoterminal esclave

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
char *ptsname(int fd);
int ptsname_r(size_t size;
              int fd, char buf[size], size_t size);
Exigences des macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

ptsname():

    Depuis glibc 2.24 :
        _XOPEN_SOURCE >= 500
    glibc 2.23 et versions antérieures :
        _XOPEN_SOURCE

ptsname_r():

    _GNU_SOURCE

DESCRIPTION

La fonction ptsname() renvoie le nom du périphérique pseudoterminal esclave correspondant au maître référencé par le descripteur de fichier fd.

La fonction ptsname_r() est l'équivalent réentrable de ptsname(). Elle renvoie le nom du périphérique pseudoterminal esclave sous la forme d'une chaîne de caractères terminée par un octet nul dans le tampon pointé par buf. L'argument size spécifie le nombre d'octets disponibles dans buf.

VALEUR DE RETOUR

En cas de succès, ptsname() renvoie un pointeur vers une chaîne dans un stockage statique qui sera écrasé par les appels ultérieurs. Ce pointeur ne doit pas être libéré. En cas d'échec, NULL est renvoyé.

En cas de succès, ptsname_r() renvoie 0. En cas d'échec, un numéro d'erreur est renvoyé pour indiquer l'erreur.

ERREURS

EINVAL
(Uniquement pour ptsname_r()) buf est NULL. (Cette erreur n'est renvoyée que pour glibc 2.25 et versions antérieures.)
ENOTTY
fd ne fait pas référence à un périphérique maître pseudoterminal.
ERANGE
(Uniquement pour ptsname_r()) buf est trop petit.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
ptsname () Sécurité des threads MT-Unsafe race:ptsname
ptsname_r () Sécurité des threads MT-Safe

VERSIONS

Une version de ptsname_r() est documentée sur Tru64, HP-UX et FreeBSD, mais sur ces implémentations, -1 est renvoyé en cas d'erreur, avec errno défini pour indiquer l'erreur. Évitez d'utiliser cette fonction dans les programmes portables.

NORMES

ptsname():
POSIX.1-2008.
ptsname_r():
POSIX.1-2024.

HISTORIQUE

ptsname():
POSIX.1-2001. glibc 2.1.

ptsname() fait partie du support des pseudoterminals UNIX 98 (voir pts(4)).

ptsname_r():
GNU.
