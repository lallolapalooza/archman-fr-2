PTHREAD_BARRIERATTR_DESTROY(3P) Manuel du programmeur POSIX PTHREAD_BARRIERATTR_DESTROY(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pthread_barrierattr_destroy, pthread_barrierattr_init — détruire et initialiser l'objet d'attributs de barrière

SYNTAXE

#include <pthread.h>
int pthread_barrierattr_destroy(pthread_barrierattr_t *attr);
int pthread_barrierattr_init(pthread_barrierattr_t *attr);

DESCRIPTION

La fonction pthread_barrierattr_destroy() détruit un objet d'attributs de barrière. Un objet d'attributs attr détruit peut être réinitialisé en utilisant pthread_barrierattr_init() ; les résultats de toute autre référence à l'objet après sa destruction sont indéfinis. Une implémentation peut provoquer la définition de l'objet référencé par attr à une valeur invalide par pthread_barrierattr_destroy().

La fonction pthread_barrierattr_init() initialise un objet d'attributs de barrière attr avec la valeur par défaut pour tous les attributs définis par l'implémentation.

Si pthread_barrierattr_init() est appelée en spécifiant un objet d'attributs attr déjà initialisé, les résultats sont indéfinis.

Après qu'un objet d'attributs de barrière a été utilisé pour initialiser une ou plusieurs barrières, toute fonction affectant l'objet d'attributs (y compris la destruction) ne doit pas affecter les barrières déjà initialisées.

Le comportement est indéfini si la valeur spécifiée par l'argument attr à pthread_barrierattr_destroy() ne fait pas référence à un objet d'attributs de barrière initialisé.

VALEUR DE RETOUR

En cas de succès, les fonctions pthread_barrierattr_destroy() et pthread_barrierattr_init() renvoient zéro ; sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

ERREURS

La fonction pthread_barrierattr_init() échoue si :

ENOMEM
Il n'y a pas assez de mémoire pour initialiser l'objet d'attributs de barrière.

Ces fonctions ne doivent pas renvoyer de code d'erreur [EINTR].

EXEMPLES

UTILISATION APPLICATION

Aucune.

RATIONALE

Si une implémentation détecte que la valeur spécifiée par l'argument attr à pthread_barrierattr_destroy() ne fait pas référence à un objet d'attributs de barrière initialisé, il est recommandé que la fonction échoue et signale une erreur [EINVAL].
