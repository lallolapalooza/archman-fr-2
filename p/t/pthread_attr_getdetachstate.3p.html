PTHREAD_ATTR_GETDETACHSTATE(3P) Manuel du programmeur POSIX PTHREAD_ATTR_GETDETACHSTATE(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pthread_attr_getdetachstate, pthread_attr_setdetachstate — obtenir et définir l'attribut detachstate

SYNOPSIS

#include <pthread.h>
int pthread_attr_getdetachstate(const pthread_attr_t *attr,
    int *detachstate);
int pthread_attr_setdetachstate(pthread_attr_t *attr, int detachstate);

DESCRIPTION

L'attribut detachstate contrôle si le thread est créé dans un état détaché. Si le thread est créé détaché, alors l'utilisation de l'identifiant du thread nouvellement créé par la fonction pthread_detach() ou pthread_join() est une erreur.

Les fonctions pthread_attr_getdetachstate() et pthread_attr_setdetachstate() obtiennent et définissent respectivement l'attribut detachstate dans l'objet attr.

Pour pthread_attr_getdetachstate(), detachstate sera défini sur PTHREAD_CREATE_DETACHED ou PTHREAD_CREATE_JOINABLE.

Pour pthread_attr_setdetachstate(), l'application définira detachstate sur PTHREAD_CREATE_DETACHED ou PTHREAD_CREATE_JOINABLE.

Une valeur PTHREAD_CREATE_DETACHED entraînera la création de tous les threads avec attr dans un état détaché, tandis qu'une valeur PTHREAD_CREATE_JOINABLE entraînera la création de tous les threads avec attr dans un état joignable. La valeur par défaut de l'attribut detachstate sera PTHREAD_CREATE_JOINABLE.

Le comportement est indéfini si la valeur spécifiée par l'argument attr à pthread_attr_getdetachstate() ou pthread_attr_setdetachstate() ne fait pas référence à un objet d'attributs de thread initialisé.

VALEUR DE RETOUR

En cas de succès, pthread_attr_getdetachstate() et pthread_attr_setdetachstate() renverront une valeur de 0 ; sinon, un numéro d'erreur sera renvoyé pour indiquer l'erreur.

La fonction pthread_attr_getdetachstate() stocke la valeur de l'attribut detachstate dans detachstate en cas de succès.

ERREURS

La fonction pthread_attr_setdetachstate() échouera si :

EINVAL
La valeur de detachstate n'était pas valide.

Ces fonctions ne renverront pas de code d'erreur [EINTR].

Les sections suivantes sont informatives.

EXEMPLES

Récupérer l'attribut detachstate

Cet exemple montre comment obtenir l'attribut detachstate d'un objet d'attributs de thread.

#include <pthread.h>
pthread_attr_t thread_attr;
int            detachstate;
int            rc;
/* code initialisant thread_attr */
...
rc = pthread_attr_getdetachstate (&thread_attr, &detachstate);
if (rc!=0) {
    /* gérer l'erreur */
    ...
}
else {
    /* les valeurs légales pour detachstate sont :
     * PTHREAD_CREATE_DETACHED ou PTHREAD_CREATE_JOINABLE
     */
     ...
}

UTILISATION APPLICATIVE

Aucune.

RATIONALE

Si une implémentation détecte que la valeur spécifiée par l'argument attr à pthread_attr_getdetachstate() ou pthread_attr_setdetachstate() ne fait pas référence à un objet d'attributs de thread initialisé, il est recommandé que la fonction échoue et signale une erreur [EINVAL].
