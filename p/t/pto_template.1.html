NOM

pto_template - Appliquer un fichier modèle

SYNTAXE

pto_template [options] input.pto

DESCRIPTION

pto_template ajoute un fichier modèle à PTO

UTILISATION

pto_template --template=template.pto

OPTIONS

-o | --output=fichier.pto
Fichier de sortie Hugin PTO. Par défaut : <nom_fichier>_template.pto
--template=fichier_modele.pto
Appliquer le fichier modèle spécifié.
-h | --help
Affiche cette aide
