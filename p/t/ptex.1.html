PTEX(1) Manuel des commandes générales PTEX(1)

NOM

ptex, uptex, eptex, euptex - "Publishing TeX" japonais

SYNTAXE

ptex [options] [&format] [fichier|\commandes]

DESCRIPTION

pTeX (ptex) est un moteur TeX avec des extensions pour la composition japonaise, incluant des fonctionnalités liées aux règles de césure, à l'espacement entre caractères et à l'écriture verticale. Il a été développé initialement par ASCII Corporation, dans le but de fournir un TeX japonais pouvant être utilisé pour la publication commerciale. Pour pTeX, le jeu de caractères disponibles est limité à JIS X 0208, à savoir les niveaux JIS 1 et 2.

upTeX (uptex) est un pTeX prenant en charge Unicode avec des extensions pour une meilleure gestion des documents multilingues CJK (chinois, japonais et coréen). Il est développé par Takuji Tanaka depuis 2007.

e-pTeX (eptex) est une fusion d'e-TeX et de pTeX.

e-upTeX (euptex) est une fusion d'e-TeX et d'upTeX.

Dans les sections suivantes, nous faisons référence à ces moteurs comme (e-)(u)pTeX.

La gestion des arguments en ligne de commande de (e-)(u)pTeX est similaire à celle des autres programmes TeX de l'implémentation web2c.

OPTIONS

Nous listons ici uniquement les ajouts/suppressions d'options de ligne de commande spécifiques à (e-)(u)pTeX. Pour (u)pTeX, les autres options sont similaires à celles de TeX. Pour e-(u)pTeX, les autres options sont similaires à celles d'e-TeX.

Ajouts (supportés par la bibliothèque ptexenc) :
-kanji chaîne
Définit le code japonais de saisie Kanji. La chaîne peut être soit euc (EUC-JP), jis (ISO-2022-JP), sjis (Shift_JIS), et utf8 (UTF-8). Pour (e-)upTeX, uptex est également autorisé.
-kanji-internal chaîne
Définit le code Kanji interne. La chaîne peut être soit euc, soit sjis. Pour (e-)upTeX, uptex est également autorisé.
Suppression :
-enc
Dans cette version de (e-)(u)pTeX, les extensions encTeX ne sont *pas* disponibles.
