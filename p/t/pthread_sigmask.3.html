pthread_sigmask(3) Manuel des fonctions de bibliothèque pthread_sigmask(3)

NOM

pthread_sigmask - examiner et modifier le masque des signaux bloqués

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <signal.h>
int pthread_sigmask(int how, const sigset_t *set, sigset_t *oldset);
Exigences relatives aux macros de test de fonctionnalités dans glibc (voir feature_test_macros(7)):

pthread_sigmask():

    _POSIX_C_SOURCE >= 199506L || _XOPEN_SOURCE >= 500

DESCRIPTION

La fonction pthread_sigmask() est identique à sigprocmask(2), à la différence près que son utilisation dans les programmes multithreadés est explicitement spécifiée par POSIX.1. D'autres différences sont notées sur cette page.

Pour une description des arguments et du fonctionnement de cette fonction, voir sigprocmask(2).

VALEUR DE RETOUR

En cas de succès, pthread_sigmask() retourne 0 ; en cas d'erreur, elle retourne un numéro d'erreur.

ERREURS

Voir sigprocmask(2).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_sigmask () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

NOTES

Un nouveau thread hérite d'une copie du masque de signaux de son créateur.

La fonction pthread_sigmask() de glibc ignore silencieusement les tentatives de blocage des deux signaux temps réel utilisés en interne par l'implémentation de threads NPTL. Voir nptl(7) pour plus de détails.

EXEMPLES

Le programme ci-dessous bloque certains signaux dans le thread principal, puis crée un thread dédié pour les récupérer via sigwait(3). La session shell suivante montre son utilisation :


$ ./a.out &
[1] 5423
$ kill -QUIT %1
Signal handling thread got signal 3
$ kill -USR1 %1
Signal handling thread got signal 10
$ kill -TERM %1
[1]+  Terminated              ./a.out

Source du programme

#include <err.h>
#include <errno.h>
#include <pthread.h>
#include <signal.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
/* Fonctions simples de gestion des erreurs */
static void *
sig_thread(void *arg)
{
    sigset_t *set = arg;
    int s, sig;
    for (;;) {
        s = sigwait(set, &sig);
        if (s != 0)
            errc(EXIT_FAILURE, s, "sigwait");
        printf("Signal handling thread got signal %d\n", sig);
    }
}
int
main(void)
{
    pthread_t thread;
    sigset_t set;
    int s;
    /* Bloquer SIGQUIT et SIGUSR1 ; les autres threads créés par main()
       hériteront d'une copie du masque de signaux.  */
    sigemptyset(&set);
    sigaddset(&set, SIGQUIT);
    sigaddset(&set, SIGUSR1);
    s = pthread_sigmask(SIG_BLOCK, &set, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_sigmask");
    s = pthread_create(&thread, NULL, &sig_thread, &set);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_create");
    /* Le thread principal continue pour créer d'autres threads et/ou effectuer
       d'autres travaux.  */
    pause();            /* Pause fictive pour pouvoir tester le programme */
}
