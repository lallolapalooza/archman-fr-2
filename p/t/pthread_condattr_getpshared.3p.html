PTHREAD_CONDATTR_GETPSHARED(3P) Manuel du programmeur POSIX PTHREAD_CONDATTR_GETPSHARED(3P)

PROLOG

Cette page de manuel fait partie du manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour connaître le comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pthread_condattr_getpshared, pthread_condattr_setpshared — obtenir et définir les attributs de variable de condition partagée par processus

SYNTAXE

#include <pthread.h>
int pthread_condattr_getpshared(const pthread_condattr_t *restrict attr,
    int *restrict pshared);
int pthread_condattr_setpshared(pthread_condattr_t *attr,
    int pshared);

DESCRIPTION

La fonction pthread_condattr_getpshared() récupère la valeur de l'attribut partagé par processus de l'objet attribut référencé par attr.

La fonction pthread_condattr_setpshared() définit l'attribut partagé par processus dans un objet attribut initialisé référencé par attr.

L'attribut partagé par processus est défini sur PTHREAD_PROCESS_SHARED pour permettre à une variable de condition d'être opérée par tout thread ayant accès à la mémoire où la variable de condition est allouée, même si la variable de condition est allouée dans une mémoire partagée par plusieurs processus. Voir la Section 2.9.9, Copies d'objets de synchronisation et mappages alternatifs pour des exigences supplémentaires. La valeur par défaut de l'attribut est PTHREAD_PROCESS_PRIVATE.

Le comportement est indéfini si la valeur spécifiée par l'argument attr pour pthread_condattr_getpshared() ou pthread_condattr_setpshared() ne fait pas référence à un objet attribut de variable de condition initialisé.

VALEUR DE RETOUR

En cas de succès, la fonction pthread_condattr_setpshared() renvoie zéro ; sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

En cas de succès, la fonction pthread_condattr_getpshared() renvoie zéro et stocke la valeur de l'attribut partagé par processus de attr dans l'objet référencé par le paramètre pshared. Sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

ERREURS

La fonction pthread_condattr_setpshared() peut échouer si :

EINVAL
La nouvelle valeur spécifiée pour l'attribut est en dehors de la plage des valeurs légales pour cet attribut.

Ces fonctions ne doivent pas renvoyer le code d'erreur [EINTR].

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION APPLICATION

Aucune.

RATIONALE

Si une implémentation détecte que la valeur spécifiée par l'argument attr pour pthread_condattr_getpshared() ou pthread_condattr_setpshared() ne fait pas référence à un objet attribut de variable de condition initialisé, il est recommandé que la fonction échoue et signale une erreur [EINVAL].
