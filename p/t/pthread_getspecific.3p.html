PTHREAD_GETSPECIFIC(3P) Manuel du programmeur POSIX PTHREAD_GETSPECIFIC(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour connaître les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pthread_getspecific, pthread_setspecific — gestion des données spécifiques au thread

SYNTAXE

#include <pthread.h>
void *pthread_getspecific(pthread_key_t key);
int pthread_setspecific(pthread_key_t key, const void *value);

DESCRIPTION

La fonction pthread_getspecific() renvoie la valeur actuellement associée à la key spécifiée au nom du thread appelant.

La fonction pthread_setspecific() associe une value spécifique au thread à une key obtenue lors d'un appel précédent à pthread_key_create(). Différents threads peuvent associer différentes valeurs à la même clé. Ces valeurs sont généralement des pointeurs vers des blocs de mémoire alloués dynamiquement qui ont été réservés pour l'utilisation par le thread appelant.

L'effet d'un appel à pthread_getspecific() ou pthread_setspecific() avec une valeur de key non obtenue à partir de pthread_key_create() ou après que la key ait été supprimée avec pthread_key_delete() est indéfini.

Les deux fonctions pthread_getspecific() et pthread_setspecific() peuvent être appelées depuis une fonction destructrice de données spécifiques au thread. Un appel à pthread_getspecific() pour la clé de données spécifiques au thread en cours de destruction renverra la valeur NULL, à moins que la valeur ne soit modifiée (après le début du destructeur) par un appel à pthread_setspecific(). L'appel à pthread_setspecific() depuis une routine destructrice de données spécifiques au thread peut entraîner soit une perte de stockage (après au moins PTHREAD_DESTRUCTOR_ITERATIONS tentatives de destruction), soit une boucle infinie.

Les deux fonctions peuvent être implémentées sous forme de macros.

VALEUR DE RETOUR

La fonction pthread_getspecific() renvoie la valeur de données spécifique au thread associée à la key donnée. Si aucune valeur de données spécifique au thread n'est associée à la key, la valeur NULL est renvoyée.

En cas de succès, la fonction pthread_setspecific() renvoie zéro ; sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

ERREURS

Aucune erreur n'est renvoyée par pthread_getspecific().

La fonction pthread_setspecific() échouera si :

ENOMEM
Il n'y a pas assez de mémoire pour associer la valeur non NULL à la clé.

La fonction pthread_setspecific() ne renverra pas un code d'erreur de [EINTR].

UTILISATION APPLICATIVE

Aucune.

RATIONALE

Les performances et la facilité d'utilisation de pthread_getspecific() sont critiques pour les fonctions qui s'appuient sur le maintien de l'état dans les données spécifiques aux threads. Comme aucune erreur ne doit être détectée par cette fonction, et comme la seule erreur qui pourrait être détectée est l'utilisation d'une clé invalide, la fonction pthread_getspecific() a été conçue pour privilégier la vitesse et la simplicité par rapport à la signalisation d'erreurs.

Si une implémentation détecte que la valeur spécifiée par l'argument key de pthread_setspecific() ne fait pas référence à une clé obtenue à partir de pthread_key_create() ou fait référence à une clé qui a été supprimée avec pthread_key_delete(), il est recommandé que la fonction échoue et signale une erreur [EINVAL].
