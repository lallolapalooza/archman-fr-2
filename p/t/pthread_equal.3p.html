PTHREAD_EQUAL(3P) Manuel du programmeur POSIX PTHREAD_EQUAL(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pthread_equal — comparer les identifiants de thread

SYNTAXE

#include <pthread.h>
int pthread_equal(pthread_t t1, pthread_t t2);

DESCRIPTION

Cette fonction doit comparer les identifiants de thread t1 et t2.

VALEUR DE RETOUR

La fonction pthread_equal() doit retourner une valeur non nulle si t1 et t2 sont égaux ; sinon, zéro doit être retourné.

Si t1 ou t2 ne sont pas des identifiants de thread valides, le comportement est indéfini.

ERREURS

Aucune erreur n'est définie.

La fonction pthread_equal() ne doit pas retourner de code d'erreur [EINTR].

USAGE APPLICATIF

Aucun.

RATIONALE

Les implémentations peuvent choisir de définir un identifiant de thread comme une structure. Cela permet une plus grande flexibilité et robustesse par rapport à l'utilisation d'un int. Par exemple, un identifiant de thread pourrait inclure un numéro de séquence qui permet de détecter les ``identifiants périmés'' (copies d'un identifiant de thread qui a été détaché). Puisque le langage C ne supporte pas la comparaison des types structure, la fonction pthread_equal() est fournie pour comparer les identifiants de thread.
