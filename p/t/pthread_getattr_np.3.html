pthread_getattr_np(3) Manuel des fonctions de bibliothèque pthread_getattr_np(3)

NOM

pthread_getattr_np - obtenir les attributs d'un thread créé

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#define _GNU_SOURCE             /* Voir feature_test_macros(7) */
#include <pthread.h>
int pthread_getattr_np(pthread_t thread, pthread_attr_t *attr);

DESCRIPTION

La fonction pthread_getattr_np() initialise l'objet d'attributs de thread référencé par attr afin qu'il contienne les valeurs d'attributs réelles décrivant le thread en cours d'exécution thread.

Les valeurs d'attribut retournées peuvent différer des valeurs d'attribut correspondantes passées dans l'objet attr qui a été utilisé pour créer le thread à l'aide de pthread_create(3). En particulier, les attributs suivants peuvent différer :

•
l'état de détachement, car un thread joignable peut s'être détaché après sa création ;
•
la taille de la pile, que l'implémentation peut aligner sur une frontière appropriée.
•
et la taille de la garde, que l'implémentation peut arrondir au multiple suivant de la taille de page, ou ignorer (c'est-à-dire considérer comme 0), si l'application alloue sa propre pile.

De plus, si l'attribut d'adresse de la pile n'a pas été défini dans l'objet d'attributs de thread utilisé pour créer le thread, l'objet d'attributs de thread retourné rapportera l'adresse de pile réelle que l'implémentation a sélectionnée pour le thread.

Lorsque l'objet d'attributs de thread retourné par pthread_getattr_np() n'est plus requis, il doit être détruit à l'aide de pthread_attr_destroy(3).

VALEUR DE RETOUR

En cas de succès, cette fonction retourne 0 ; en cas d'erreur, elle retourne un numéro d'erreur non nul.

ERREURS

ENOMEM
Mémoire insuffisante.

De plus, si thread fait référence au thread principal, alors pthread_getattr_np() peut échouer en raison d'erreurs provenant de divers appels sous-jacents : fopen(3), si /proc/self/maps ne peut pas être ouvert ; et getrlimit(2), si la limite de ressource RLIMIT_STACK n'est pas prise en charge.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_getattr_np () Sécurité des threads MT-Safe

NORMES

GNU ; d'où le suffixe "_np" (non portable) dans le nom.

HISTORIQUE

glibc 2.2.3.

Lors de la première exécution, sur un système x86-32, un thread est créé en utilisant les attributs par défaut :


$ ulimit -s      # Pas de limite de pile ==> taille de pile par défaut est de 2 Mo

$ ./a.out
Attributes of created thread:
        Guard size          = 4096 bytes
        Stack address       = 0x40196000 (EOS = 0x40397000)

Lors de l'exécution suivante, nous voyons que si une taille de garde est spécifiée, elle est arrondie au multiple suivant de la taille de page du système (4096 octets sur x86-32) :


$ ./a.out -g 4097
Thread attributes object after initializations:
        Guard size          = 4097 bytes
        Stack address       = (nil)
        Stack size          = 0x0 (0) bytes
Attributes of created thread:
        Guard size          = 8192 bytes
        Stack address       = 0x40196000 (EOS = 0x40397000)
        Stack size          = 0x201000 (2101248) bytes

Dans la dernière exécution, le programme alloue manuellement une pile pour le thread. Dans ce cas, l'attribut de taille de garde est ignoré.


$ ./a.out -g 4096 -s 0x8000 -a
Allocated thread stack at 0x804d000
Thread attributes object after initializations:
        Guard size          = 4096 bytes
        Stack address       = 0x804d000 (EOS = 0x8055000)
        Stack size          = 0x8000 (32768) bytes
Attributes of created thread:
        Guard size          = 0 bytes
        Stack address       = 0x804d000 (EOS = 0x8055000)

static void
display_stack_related_attributes(pthread_attr_t *attr, char *prefix)
{
    int s;
    size_t stack_size, guard_size;
    void *stack_addr;
    s = pthread_attr_getguardsize(attr, &guard_size);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getguardsize");
    printf("%sGuard size          = %zu bytes\n", prefix, guard_size);
    s = pthread_attr_getstack(attr, &stack_addr, &stack_size);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getstack");
    printf("%sStack address       = %p", prefix, stack_addr);
    if (stack_size > 0)
        printf(" (EOS = %p)", (char *) stack_addr + stack_size);
    printf("\n");
    printf("%sStack size          = %#zx (%zu) bytes\n",
           prefix, stack_size, stack_size);
}
static void
display_thread_attributes(pthread_t thread, char *prefix)
{
    int s;
    pthread_attr_t attr;
    s = pthread_getattr_np(thread, &attr);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_getattr_np");
    display_stack_related_attributes(&attr, prefix);
    s = pthread_attr_destroy(&attr);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_destroy");
}
static void *           /* Start function for thread we create */
thread_start(void *arg)
{
    printf("Attributes of created thread:\n");
    display_thread_attributes(pthread_self(), "\t");
    exit(EXIT_SUCCESS);         /* Terminate all threads */
}
static void
usage(char *pname, char *msg)
{
    if (msg != NULL)
        fputs(msg, stderr);
    fprintf(stderr, "Usage: %s [-s stack-size [-a]]"
            " [-g guard-size]\n", pname);
    fprintf(stderr, "\t\t-a means program should allocate stack\n");
    exit(EXIT_FAILURE);
}
