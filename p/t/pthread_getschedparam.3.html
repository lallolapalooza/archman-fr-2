pthread_setschedparam(3) Manuel des fonctions de bibliothèque pthread_setschedparam(3)

NOM

pthread_setschedparam, pthread_getschedparam - définir/obtenir la politique et les paramètres de planification d'un thread

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <pthread.h>
int pthread_setschedparam(pthread_t thread, int policy,
                          const struct sched_param *param);
int pthread_getschedparam(pthread_t thread, int *restrict policy,
                          struct sched_param *restrict param);

DESCRIPTION

La fonction pthread_setschedparam() définit la politique et les paramètres de planification du thread thread.

policy spécifie la nouvelle politique de planification pour thread. Les valeurs prises en charge pour policy, et leurs sémantiques, sont décrites dans sched(7).

La structure pointée par param spécifie les nouveaux paramètres de planification pour thread. Les paramètres de planification sont maintenus dans la structure suivante :


struct sched_param {
    int sched_priority;     /* Priorité de planification */
};

Comme on peut le voir, un seul paramètre de planification est pris en charge. Pour les détails sur les plages autorisées pour les priorités de planification dans chaque politique de planification, voir sched(7).

La fonction pthread_getschedparam() renvoie la politique et les paramètres de planification du thread thread, dans les buffers pointés par policy et param, respectivement. La valeur de priorité renvoyée est celle définie par le dernier appel pthread_setschedparam(), pthread_setschedprio(3), ou pthread_create(3) qui a affecté thread. La priorité renvoyée ne reflète aucun ajustement temporaire de priorité résultant d'appels à des fonctions d'héritage de priorité ou de plafond de priorité (voir, par exemple, pthread_mutexattr_setprioceiling(3) et pthread_mutexattr_setprotocol(3)).

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient 0 ; en cas d'erreur, elles renvoient un numéro d'erreur non nul. Si pthread_setschedparam() échoue, la politique et les paramètres de planification de thread ne sont pas modifiés.

ERREURS

Ces deux fonctions peuvent échouer avec l'erreur suivante :

ESRCH
Aucun thread avec l'identifiant thread n'a pu être trouvé.

pthread_setschedparam() peut également échouer avec les erreurs suivantes :

EINVAL
policy n'est pas une politique reconnue, ou param n'a pas de sens pour la policy.
EPERM
L'appelant ne dispose pas des privilèges appropriés pour définir la politique et les paramètres de planification spécifiés.

POSIX.1 documente également une erreur ENOTSUP ("une tentative a été faite pour définir la politique ou les paramètres de planification à une valeur non prise en charge") pour pthread_setschedparam().

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_setschedparam (), pthread_getschedparam () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

NOTES

Pour une description des permissions requises et de l'effet de la modification de la politique de planification et de la priorité d'un thread, ainsi que des détails sur les plages autorisées pour les priorités dans chaque politique de planification, voir sched(7).

EXEMPLES

Le programme ci-dessous démontre l'utilisation de pthread_setschedparam() et pthread_getschedparam(), ainsi que l'utilisation d'un certain nombre d'autres fonctions pthreads liées à la planification.

Dans l'exécution suivante, le thread principal définit sa politique de planification sur SCHED_FIFO avec une priorité de 10, et initialise un objet d'attributs de thread avec un attribut de politique de planification de SCHED_RR et un attribut de priorité de planification de 20. Le programme définit ensuite (en utilisant pthread_attr_setinheritsched(3)) l'attribut de planification d'héritage de l'objet d'attributs de thread sur PTHREAD_EXPLICIT_SCHED, ce qui signifie que les threads créés en utilisant cet objet d'attributs doivent prendre leurs attributs de planification à partir de l'objet d'attributs de thread. Le programme crée ensuite un thread en utilisant l'objet d'attributs de thread, et ce thread affiche sa politique et sa priorité de planification.


$ su;      # Nécessite des privilèges pour définir les politiques de planification temps réel
Password:
# ./a.out -mf10 -ar20 -i e;
Scheduler settings of main thread
    policy=SCHED_FIFO, priority=10
Scheduler settings in 'attr'
    policy=SCHED_RR, priority=20
    inheritsched is EXPLICIT
Scheduler attributes of new thread
    policy=SCHED_RR, priority=20

Dans la sortie ci-dessus, on peut voir que la politique et la priorité de planification ont été tirées des valeurs spécifiées dans l'objet d'attributs du thread.

L'exécution suivante est identique à la précédente, sauf que l'attribut de planification d'héritage est défini sur PTHREAD_INHERIT_SCHED, ce qui signifie que les threads créés en utilisant l'objet d'attributs du thread doivent ignorer les attributs de planification spécifiés dans l'objet d'attributs et prendre plutôt leurs attributs de planification à partir du thread créateur.


# ./a.out -mf10 -ar20 -i i;
Scheduler settings of main thread
    policy=SCHED_FIFO, priority=10
Scheduler settings in 'attr'
    policy=SCHED_RR, priority=20
    inheritsched is INHERIT
Scheduler attributes of new thread
    policy=SCHED_FIFO, priority=10

Dans la sortie ci-dessus, on peut voir que la politique et la priorité de planification ont été tirées du thread créateur, plutôt que de l'objet d'attributs du thread.

Notez que si nous avions omis l'option -i i, la sortie aurait été la même, car PTHREAD_INHERIT_SCHED est la valeur par défaut pour l'attribut de planification d'héritage.

/* pthreads_sched_test.c */
#include <err.h>
#include <errno.h>
#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
[[noreturn]]
static void
usage(char *prog_name, char *msg)
{
    if (msg != NULL)
        fputs(msg, stderr);
    fprintf(stderr, "Usage: %s [options]\n", prog_name);
    fprintf(stderr, "Options are:\n");
#define fpe(msg) fprintf(stderr, "\t%s", msg)          /* Shorter */
    fpe("-a<policy><prio> Définit la politique et la priorité de planification dans\n");
    fpe("                 l'objet d'attributs du thread\n");
    fpe("                 <policy> peut être\n");
    fpe("                     f  SCHED_FIFO\n");
    fpe("                     r  SCHED_RR\n");
    fpe("                     o  SCHED_OTHER\n");
    fpe("-A               Utiliser l'objet d'attributs de thread par défaut\n");
    fpe("-i {e|i}         Définit l'attribut de planification d'héritage sur\n");
    fpe("                 'explicite' ou 'héritage'\n");
    fpe("-m<policy><prio> Définit la politique et la priorité de planification sur\n");
    fpe("                 le thread principal avant l'appel pthread_create()\n");
    exit(EXIT_FAILURE);
}
static int
get_policy(char p, int *policy)
{
    switch (p) {
    case 'f': *policy = SCHED_FIFO;     return 1;
    case 'r': *policy = SCHED_RR;       return 1;
    case 'o': *policy = SCHED_OTHER;    return 1;
    default: return 0;
    }
}
int
main(int argc, char *argv[])
{
    int ch;
    char *prog_name = argv[0];
    pthread_attr_t attr;
    int inherit_sched;
    int main_policy, main_prio;
    int attr_policy, attr_prio;
    int explicit_sched;
    main_policy = -1;
    main_prio = -1;
    attr_policy = -1;
    attr_prio = -1;
    inherit_sched = PTHREAD_INHERIT_SCHED; /* Default */
    explicit_sched = 0;
    while ((ch = getopt(argc, argv, "Aai:m:r:")) != -1) {
        switch (ch) {
        case 'A':
            if (pthread_attr_init(&attr) != 0)
                err(1, "pthread_attr_init");
            break;
        case 'a':
            if (!get_policy(optarg[0], &attr_policy))
                usage(prog_name, "Invalid policy specified for -a option\n");
            attr_prio = atoi(&optarg[1]);
            if (attr_prio < 0)
                usage(prog_name, "Invalid priority specified for -a option\n");
            explicit_sched = 1;
            break;
        case 'i':
            if (optarg[0] == 'e')
                inherit_sched = PTHREAD_EXPLICIT_SCHED;
            else if (optarg[0] == 'i')
                inherit_sched = PTHREAD_INHERIT_SCHED;
            else
                usage(prog_name, "Invalid inherit scheduler option\n");
            explicit_sched = 1;
            break;
        case 'm':
            if (!get_policy(optarg[0], &main_policy))
                usage(prog_name, "Invalid policy specified for -m option\n");
            main_prio = atoi(&optarg[1]);
            if (main_prio < 0)
                usage(prog_name, "Invalid priority specified for -m option\n");
            break;
        case 'r':
            if (!get_policy(optarg[0], &attr_policy))
                usage(prog_name, "Invalid policy specified for -r option\n");
            attr_prio = atoi(&optarg[1]);
            if (attr_prio < 0)
                usage(prog_name, "Invalid priority specified for -r option\n");
            explicit_sched = 1;
            break;
        default:
            usage(prog_name, NULL);
        }
    }
    if (!explicit_sched) {
        if (pthread_attr_init(&attr) != 0)
            err(1, "pthread_attr_init");
    }
    if (explicit_sched) {
        if (pthread_attr_setinheritsched(&attr, inherit_sched) != 0)
            err(1, "pthread_attr_setinheritsched");
        if (attr_policy != -1) {
            if (pthread_attr_setschedpolicy(&attr, attr_policy) != 0)
                err(1, "pthread_attr_setschedpolicy");
            if (attr_prio != -1) {
                struct sched_param sp;
                sp.sched_priority = attr_prio;
                if (pthread_attr_setschedparam(&attr, &sp) != 0)
                    err(1, "pthread_attr_setschedparam");
            }
        }
    }
    if (main_policy != -1) {
        struct sched_param sp;
        sp.sched_priority = main_prio;
        if (pthread_setschedparam(pthread_self(), main_policy, &sp) != 0)
            err(1, "pthread_setschedparam (main thread)");
    }
    print_thread_sched_info(pthread_self(), "main thread");
    print_attr_sched_info(&attr);
    pthread_t thread;
    if (pthread_create(&thread, &attr, thread_start, NULL) != 0)
        err(1, "pthread_create");
    if (pthread_join(thread, NULL) != 0)
        err(1, "pthread_join");
    exit(EXIT_SUCCESS);
}
static void
print_thread_sched_info(pthread_t tid, const char *msg)
{
    int policy, ret;
    struct sched_param sp;
    ret = pthread_getschedparam(tid, &policy, &sp);
    if (ret != 0) {
        errno = ret;
        err(1, "pthread_getschedparam (%s)", msg);
    }
    printf("Scheduler settings of %s\n", msg);
    printf("    policy=%s, priority=%d\n",
            policy_to_string(policy), sp.sched_priority);
}
static const char *
policy_to_string(int policy)
{
    switch (policy) {
    case SCHED_FIFO:    return "SCHED_FIFO";
    case SCHED_RR:      return "SCHED_RR";
    case SCHED_OTHER:   return "SCHED_OTHER";
    default:            return "Unknown";
    }
}
static void
print_attr_sched_info(pthread_attr_t *attr)
{
    int policy, inherit;
    struct sched_param sp;
    pthread_getschedparam(*attr, &policy, &sp);
    pthread_attr_getinheritsched(attr, &inherit);
    printf("Scheduler settings in 'attr'\n");
    printf("    policy=%s, priority=%d\n",
            policy_to_string(policy), sp.sched_priority);
    printf("    inheritsched is %s\n",
            (inherit == PTHREAD_INHERIT_SCHED) ? "INHERIT" : "EXPLICIT");
}
static void *
thread_start(void *arg)
{
    print_thread_sched_info(pthread_self(), "new thread");
    return NULL;
}
