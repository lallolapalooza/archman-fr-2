pthread_tryjoin_np(3) Manuel des fonctions de bibliothèque pthread_tryjoin_np(3)

NOM

pthread_tryjoin_np, pthread_timedjoin_np - essayer de rejoindre un thread terminé

BIBLIOTHEQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#define _GNU_SOURCE             /* Voir feature_test_macros(7) */
#include <pthread.h>
int pthread_tryjoin_np(pthread_t thread, void **retval);
int pthread_timedjoin_np(pthread_t thread, void **retval,
                         const struct timespec *abstime);

DESCRIPTION

Ces fonctions fonctionnent de la même manière que pthread_join(3), à l'exception des différences décrites sur cette page.

La fonction pthread_tryjoin_np() effectue une jonction non bloquante avec le thread thread, retournant le statut de sortie du thread dans *retval. Si thread n'a pas encore terminé, alors au lieu de bloquer, comme le fait pthread_join(3), l'appel renvoie une erreur.

La fonction pthread_timedjoin_np() effectue une jonction avec temporisation. Si thread n'a pas encore terminé, l'appel bloque jusqu'à une durée maximale, spécifiée dans abstime, mesurée par rapport à l'horloge CLOCK_REALTIME. Si le délai expire avant que thread ne termine, l'appel renvoie une erreur. L'argument abstime est une structure timespec(3), spécifiant une heure absolue mesurée depuis l'Époque (voir time(2)).

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent 0 ; en cas d'erreur, elles retournent un numéro d'erreur.

ERREURS

Ces fonctions peuvent échouer avec les mêmes erreurs que pthread_join(3). pthread_tryjoin_np() peut en outre échouer avec l'erreur suivante :

EBUSY
thread n'avait pas encore terminé au moment de l'appel.

pthread_timedjoin_np() peut en outre échouer avec les erreurs suivantes :

EINVAL
La valeur de abstime est invalide (tv_sec est inférieur à 0 ou tv_nsec est supérieur à 1e9).
ETIMEDOUT
L'appel a expiré avant que thread ne termine.

pthread_timedjoin_np() ne retourne jamais l'erreur EINTR.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_tryjoin_np (), pthread_timedjoin_np () Sécurité des threads MT-Safe

NORMES

GNU ; d'où le suffixe « _np » (non portable) dans les noms.

HISTORIQUE

glibc 2.3.3.

BOGUES

La fonction pthread_timedjoin_np() mesure le temps en calculant interne un intervalle de sommeil relatif qui est ensuite mesuré par rapport à l'horloge CLOCK_MONOTONIC au lieu de l'horloge CLOCK_REALTIME. Par conséquent, le délai n'est pas affecté par les changements discontinus de l'horloge CLOCK_REALTIME.

EXEMPLES

Le code suivant attend jusqu'à 5 secondes pour rejoindre :


struct timespec ts;
int s;
...
if (clock_gettime(CLOCK_REALTIME, &ts) == -1) {
    /* Gérer l'erreur */
}
ts.tv_sec += 5;
s = pthread_timedjoin_np(thread, NULL, &ts);
if (s != 0) {
    /* Gérer l'erreur */
}

VOIR AUSSI

clock_gettime(2), pthread_exit(3), pthread_join(3), timespec(3), pthreads(7)
