pthread_setname_np(3) Manuel des fonctions de bibliothèque pthread_setname_np(3)

NOM

pthread_setname_np, pthread_getname_np - définir/obtenir le nom d'un thread

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#define _GNU_SOURCE             /* Voir feature_test_macros(7) */
#include <pthread.h>
int pthread_setname_np(pthread_t thread, const char *name);
int pthread_getname_np(size_t size;
                       pthread_t thread, char name[size], size_t size);

DESCRIPTION

Par défaut, tous les threads créés à l'aide de pthread_create() héritent du nom du programme. La fonction pthread_setname_np() peut être utilisée pour définir un nom unique pour un thread, ce qui peut être utile pour le débogage d'applications multithreadées. Le nom du thread est une chaîne de caractères C significative, dont la longueur est limitée à 16 caractères, y compris le caractère nul de fin ('\0'). L'argument thread spécifie le thread dont le nom doit être modifié ; name spécifie le nouveau nom.

La fonction pthread_getname_np() peut être utilisée pour récupérer le nom du thread. L'argument thread spécifie le thread dont le nom doit être récupéré. Le tampon name est utilisé pour renvoyer le nom du thread ; size spécifie le nombre d'octets disponibles dans name. Le tampon spécifié par name doit avoir une longueur d'au moins 16 caractères. Le nom du thread renvoyé dans le tampon de sortie sera terminé par un caractère nul.

VALEUR RENVOYÉE

En cas de succès, ces fonctions renvoient 0 ; en cas d'erreur, elles renvoient un numéro d'erreur non nul.

ERREURS

La fonction pthread_setname_np() peut échouer avec l'erreur suivante :

ERANGE
La longueur de la chaîne spécifiée pointée par name dépasse la limite autorisée.

La fonction pthread_getname_np() peut échouer avec l'erreur suivante :

ERANGE
Le tampon spécifié par name et size est trop petit pour contenir le nom du thread.

Si l'une de ces fonctions ne parvient pas à ouvrir /proc/self/task/tid/comm, l'appel peut échouer avec l'une des erreurs décrites dans open(2).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_setname_np (), pthread_getname_np () Sécurité des threads MT-Safe

NORMES

GNU ; d'où le suffixe « _np » (non portable) dans les noms.

HISTORIQUE

glibc 2.12.

NOTES

pthread_setname_np() écrit en interne dans le fichier spécifique au thread comm sous le système de fichiers /proc : /proc/self/task/tid/comm. pthread_getname_np() le récupère au même endroit.

EXEMPLES

Le programme ci-dessous illustre l'utilisation de pthread_setname_np() et pthread_getname_np().

La session shell suivante montre un exemple d'exécution du programme :


$ ./a.out;
Created a thread.  Default name is: a.out
The thread name after setting it is THREADFOO.
^Z                           # Suspendre le programme
[1]+  Stopped           ./a.out
$ ps H -C a.out -o 'pid tid cmd comm'
  PID   TID CMD                         COMMAND
 5990  5990 ./a.out                     a.out
 5990  5991 ./a.out                     THREADFOO
$ cat /proc/5990/task/5990/comm
a.out
$ cat /proc/5990/task/5991/comm
THREADFOO

Source du programme

#define _GNU_SOURCE
#include <err.h>
#include <errno.h>
#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#define NAMELEN 16
static void *
threadfunc(void *parm)
{
    sleep(5);          // permettre au programme principal de définir le nom du thread
    return NULL;
}
int
main(int argc, char *argv[])
{
    pthread_t thread;
    int rc;
    char thread_name[NAMELEN];
    rc = pthread_create(&thread, NULL, threadfunc, NULL);
    if (rc != 0)
        errc(EXIT_FAILURE, rc, "pthread_create");
    rc = pthread_getname_np(thread, thread_name, NAMELEN);
    if (rc != 0)
        errc(EXIT_FAILURE, rc, "pthread_getname_np");
    printf("Created a thread.  Default name is: %s\n", thread_name);
    rc = pthread_setname_np(thread, (argc > 1) ? argv[1] : "THREADFOO");
    if (rc != 0)
        errc(EXIT_FAILURE, rc, "pthread_setname_np");
    sleep(2);
    rc = pthread_getname_np(thread, thread_name, NAMELEN);
    if (rc != 0)
        errc(EXIT_FAILURE, rc, "pthread_getname_np");
    printf("The thread name after setting it is %s.\n", thread_name);
    rc = pthread_join(thread, NULL);
    if (rc != 0)
        errc(EXIT_FAILURE, rc, "pthread_join");
    printf("Done\n");
    exit(EXIT_SUCCESS);
}
