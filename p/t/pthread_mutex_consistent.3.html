pthread_mutex_consistent(3) Manuel des fonctions de bibliothèque pthread_mutex_consistent(3)

NOM

pthread_mutex_consistent - rendre un mutex robuste cohérent

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <pthread.h>
int pthread_mutex_consistent(pthread_mutex_t *mutex);
Exigences de macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

pthread_mutex_consistent():

    _POSIX_C_SOURCE >= 200809L

DESCRIPTION

Cette fonction rend un mutex robuste cohérent s'il est dans un état incohérent. Un mutex peut être laissé dans un état incohérent si son propriétaire se termine alors qu'il détient le mutex, auquel cas le prochain propriétaire qui acquiert le mutex réussira et sera informé par une valeur de retour de EOWNERDEAD d'un appel à pthread_mutex_lock().

VALEUR DE RETOUR

En cas de succès, pthread_mutex_consistent() renvoie 0. Sinon, elle renvoie un numéro d'erreur positif pour indiquer l'erreur.

ERREURS

EINVAL
Le mutex n'est pas robuste ou n'est pas dans un état incohérent.

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.12. POSIX.1-2008.

Avant l'ajout de pthread_mutex_consistent() à POSIX, glibc définissait la fonction non standard équivalente suivante si _GNU_SOURCE était défini:

[[deprecated]]
int pthread_mutex_consistent_np(const pthread_mutex_t *mutex);

Cette API spécifique à GNU, apparue pour la première fois dans glibc 2.4, est aujourd'hui obsolète et ne doit pas être utilisée dans de nouveaux programmes ; depuis glibc 2.34, elle a été marquée comme obsolète.

NOTES

pthread_mutex_consistent() informe simplement l'implémentation que l'état (données partagées) protégé par le mutex a été restauré à un état cohérent et que les opérations normales peuvent maintenant être effectuées avec le mutex. Il incombe à l'application de s'assurer que les données partagées ont été restaurées à un état cohérent avant d'appeler pthread_mutex_consistent().

EXEMPLES

Voir pthread_mutexattr_setrobust(3).

VOIR AUSSI

pthread_mutex_lock(3), pthread_mutexattr_getrobust(3), pthread_mutexattr_init(3), pthread_mutexattr_setrobust(3), pthreads(7)
