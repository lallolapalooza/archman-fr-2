pthread_attr_setsigmask_np(3) Manuel des fonctions de bibliothèque pthread_attr_getsigmask_np(3)

NOM

pthread_attr_setsigmask_np, pthread_attr_getsigmask_np - définir/obtenir l'attribut de masque de signal dans l'objet d'attributs de thread

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNOPSIS

#define _GNU_SOURCE             /* Voir feature_test_macros(7) */
#include <pthread.h>
int pthread_attr_setsigmask_np(pthread_attr_t *attr,
                               const sigset_t *sigmask);
int pthread_attr_getsigmask_np(const pthread_attr_t *attr,
                               sigset_t *sigmask);

DESCRIPTION

La fonction pthread_attr_setsigmask_np() définit l'attribut de masque de signal de l'objet d'attributs de thread référencé par attr à la valeur spécifiée dans *sigmask. Si sigmask est spécifié comme NULL, alors tout attribut de masque de signal existant dans attr est désactivé.

La fonction pthread_attr_getsigmask_np() renvoie l'attribut de masque de signal de l'objet d'attributs de thread référencé par attr dans le tampon pointé par sigmask. Si l'attribut de masque de signal est actuellement désactivé, cette fonction renvoie la valeur spéciale PTHREAD_ATTR_NO_SIGMASK_NP comme résultat.

VALEUR RENVOYÉE

La fonction pthread_attr_setsigmask_np() renvoie 0 en cas de succès, ou un numéro d'erreur non nul en cas d'échec.

La fonction pthread_attr_getsigmask_np() renvoie soit 0, soit PTHREAD_ATTR_NO_SIGMASK_NP. Lorsque 0 est renvoyé, le masque de signal est renvoyé via sigmask. Une valeur de retour de PTHREAD_ATTR_NO_SIGMASK_NP indique que l'attribut de masque de signal n'est pas défini dans attr.

En cas d'erreur, ces fonctions renvoient un numéro d'erreur positif.

ERREURS

ENOMEM
(pthread_attr_setsigmask_np()) Impossible d'allouer de la mémoire.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_attr_setsigmask_np (), pthread_attr_getsigmask_np () Sécurité des threads MT-Safe

NORMES

GNU ; d'où le suffixe "_np" (non portable) dans les noms.

HISTORIQUE

glibc 2.32.

NOTES

L'attribut de masque de signal détermine le masque de signal qui sera assigné à un thread créé à l'aide de l'objet d'attributs de thread attr. Si cet attribut n'est pas défini, un thread créé à l'aide de attr héritera d'une copie du masque de signal du thread créateur.

Pour plus de détails sur les masques de signal, voir sigprocmask(2). Pour une description d'un ensemble de macros pouvant être utilisées pour manipuler et inspecter les ensembles de signaux, voir sigsetops(3).

En l'absence de pthread_attr_setsigmask_np(), il est possible de créer un thread avec le masque de signal souhaité comme suit :

•
Le thread créateur utilise pthread_sigmask(3) pour sauvegarder son masque de signal actuel et définir son masque pour bloquer tous les signaux.
•
Le nouveau thread est ensuite créé à l'aide de pthread_create() ; le nouveau thread héritera du masque de signal du thread créateur.
•
Le nouveau thread définit son masque de signal à la valeur souhaitée à l'aide de pthread_sigmask(3).
•
Le thread créateur restaure son masque de signal à la valeur d'origine.

En suivant les étapes ci-dessus, il n'y a aucune possibilité pour le nouveau thread de recevoir un signal avant qu'il n'ait ajusté son masque de signal à la valeur souhaitée.
