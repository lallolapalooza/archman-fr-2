Paquet: perl-tk

PTKSH(1) Documentation Perl/Tk PTKSH(1)

NOM

ptksh - Shell Perl/Tk pour fournir une interface utilisateur graphique pour tester des commandes et des scripts Perl/Tk.

SYNTAXE

% ptksh  ?fichier_script?
... informations de version ...
ptksh> $b=$mw->Button(-text=>'Salut',-command=>sub{print 'Salut'})
ptksh> $b->pack
ptksh> o $b
... liste des options ...
ptksh> help
... informations d'aide ...
ptksh> exit
%

DESCRIPTION

ptksh est un shell Perl/Tk pour entrer interactivement des commandes Perl. Lorsque l'on démarre ptksh, une fenêtre principale (MainWindow) est automatiquement créée, ainsi qu'une fenêtre de commande ptksh. On peut accéder à la fenêtre principale en tapant des commandes en utilisant la variable $mw à l'invite 'ptksh> ' de la fenêtre de commande.

ptksh prend en charge l'édition de ligne de commande et l'historique. Tapez simplement "<Flèche Haut>" à l'invite de commande pour voir une liste d'historique. Les 50 dernières commandes entrées sont sauvegardées, puis rechargées dans la liste d'historique la prochaine fois que vous démarrez ptksh.

ptksh prend en charge quelques commandes pratiques pour inspecter les widgets Tk. Voir ci-dessous.

Pour quitter ptksh, utilisez : "exit".

ptksh n'est **pas** un débogueur symbolique complet. Pour déboguer des programmes Perl/Tk à bas niveau, utilisez le débogueur Perl plus puissant. (Tapez simplement ``O tk'' sur la ligne de commande du débogueur pour démarrer la boucle d'événements Tk.)

FONCTIONNALITÉS

Historique

Appuyez sur <Flèche Haut> dans la fenêtre perlwish pour obtenir une liste d'historique basée sur une interface graphique. Appuyez sur <Entrée> sur n'importe quelle ligne d'historique pour l'entrer dans la fenêtre perlwish. Puis appuyez sur retour. Donc, par exemple, répéter la dernière commande est <Flèche Haut><Entrée><Entrée>. Vous pouvez quitter la fenêtre d'historique avec <Échap>. REMARQUE : l'historique n'est sauvegardé que si la sortie est "gracieuse" (c'est-à-dire par la commande "exit" depuis la console ou en quittant toutes les fenêtres principales - PAS par interruption).

Support du débogage

ptksh fournit quelques fonctions pratiques pour faciliter la navigation dans les widgets Perl/Tk :

?, ou h
affiche un bref résumé d'aide.
d, ou x ?args, ...?
Dump récursivement les arguments vers stdout. (voir Data::Dumper). Vous devez avoir <Data::Dumper> installé pour supporter cette fonctionnalité.

x a été introduit pour la compatibilité avec le débogueur Perl.

p ?arg, ...?
ajoute "|\n" à chacun de ses arguments et l'imprime. Si la valeur est undef, '(undef)' est imprimé sur stdout.
o $widget ?-option ...?
imprime l'option(s) de $widget une par ligne. Si aucune option n'est donnée, toutes les options du widget sont listées. Voir Tk::options pour plus de détails sur le format et le contenu de la liste retournée.
o $widget /regexp/
Liste les options de $widget correspondant à l'expression régulière regexp.
u ?classe?
Si aucun argument n'est donné, liste les modules chargés par les commandes que vous avez exécutées ou depuis la dernière fois que vous avez appelé "u".

Si l'argument est une chaîne vide, liste tous les modules chargés par ptksh.

Si l'argument est une chaîne, ``text'' tente de faire un ``use Tk::Text;''.

Paquets

Ptksh se compile dans le paquet Tk::ptksh. Votre code est évalué dans le paquet main. La beauté de cela est que votre code évalué ne devrait pas interférer avec ptksh lui-même.

Commandes multilignes

ptksh acceptera les commandes multilignes. Placez simplement un caractère "\" immédiatement avant le retour à la ligne, et ptksh continuera votre commande sur la ligne suivante.

Support des fichiers source

Si vous avez un script Perl/Tk sur lequel vous souhaitez faire du débogage, essayez d'exécuter la commande

ptksh> do 'monscript';
 -- ou  (à l'invite de commande shell) --
% ptksh monscript

Ensuite, utilisez les commandes Perl/Tk pour essayer différentes opérations sur votre script.

ENVIRONNEMENT

Recherche votre fichier .ptksh_history dans le répertoire spécifié par la variable d'environnement $HOME ( $HOMEPATH sur les systèmes Win32).

FICHIERS

.ptksh_init
S'il est trouvé dans le répertoire courant, il est lu et évalué après la création de la fenêtre principale $mw. .ptksh_init peut contenir du code Perl valide.
~/.ptksh_history
Contient les 50 dernières lignes entrées dans les sessions ptksh.

PIEGES

Il est préférable de ne pas utiliser "my" dans les commandes que vous tapez dans ptksh. Par exemple, "my $v" rendra $v local uniquement à la commande ou aux commandes entrées jusqu'à ce que <Retour> soit pressé. Pour une raison connexe, il n'y a pas de variables "my" à portée de fichier dans le code ptksh lui-même (sinon l'utilisateur pourrait les piétiner par accident).

BOGUES

La fonction Tk::MainLoop entrée interactivement ou sourcée dans un fichier init ou script bloquera ptksh.

ptksh(1p)

Date: 2023-11-01

Section: 1p

Titre: ptksh - une version de ksh qui permet d'appeler des commandes depuis le noyau.

Description

ptksh est un shell de commande interactif. Il est implémenté en utilisant le kit d'outils Tcl/Tk. Le shell offre des fonctionnalités de base telles que la gestion des processus, les redirections d'entrée/sortie, les pipes et l'expansion des noms de fichiers.

Ce qui distingue ptksh, c'est sa capacité à exécuter des commandes directement à partir du noyau. Cela peut être utile pour des tâches d'administration système de bas niveau ou pour interagir avec des fonctionnalités spécifiques au noyau qui ne sont pas directement accessibles via les utilitaires système standards.

Pour exécuter une commande depuis le noyau, utilisez la syntaxe spéciale `kernel:comando`. Par exemple, pour obtenir des informations sur les processus, vous pourriez taper : 

kernel:ps aux

Ou pour interroger les informations du système de fichiers : 

kernel:df -h

La liste exacte des commandes disponibles via `kernel:` dépend de l'implémentation spécifique et des permissions accordées.

Fonctionnalités

  • Shell interactif basé sur Tcl/Tk.
  • Gestion des processus standard.
  • Redirections d'entrée/sortie et pipes.
  • Expansion des noms de fichiers.
  • Exécution de commandes directement depuis le noyau via la syntaxe `kernel:`.

Exemples

Démarrer une session ptksh : 

ptksh

Exécuter une commande shell normale : 

ls -l

Exécuter une commande noyau pour afficher les modules chargés : 

kernel:lsmod

Exécuter une commande noyau pour afficher l'état du réseau : 

kernel:ip addr show
