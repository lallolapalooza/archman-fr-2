sous-routine cpttrf (integer n, real, dimension( * ) d, complex, dimension( * ) e, integer info)

CPTTRF

Objectif :

!>
!> CPTTRF calcule la factorisation L*D*L**H d'une matrice tridiagonale
!> hermitienne complexe définie positive A. La factorisation peut aussi
!> être considérée comme ayant la forme A = U**H *D*U.
!>

Paramètres :

N 
!>          N est un entier (INTEGER)
!>          L'ordre de la matrice A. N >= 0.
!>

D

!>          D est un tableau de réels (REAL), de dimension (N)
!>          À l'entrée, les n éléments diagonaux de la matrice tridiagonale
!>          A. À la sortie, les n éléments diagonaux de la matrice diagonale
!>          D issue de la factorisation L*D*L**H de A.
!>

E

!>          E est un tableau de complexes (COMPLEX), de dimension (N-1)
!>          À l'entrée, les (n-1) éléments sous-diagonaux de la matrice
!>          tridiagonale A. À la sortie, les (n-1) éléments sous-diagonaux
!>          du facteur bidiagonal unitaire L issu de la factorisation L*D*L**H
!>          de A. E peut aussi être considéré comme la superdiagonale du
!>          facteur bidiagonal unitaire U issu de la factorisation U**H *D*U de A.
!>

INFO

!>          INFO est un entier (INTEGER)
!>          = 0: succès de l'exécution
!>          < 0: si INFO = -k, le k-ième argument avait une valeur illégale
!>          > 0: si INFO = k, le mineur principal de tête d'ordre k
!>               n'est pas positif ; si k < N, la factorisation n'a pas pu
!>               être terminée, tandis que si k = N, la factorisation a été
!>               terminée, mais D(N) <= 0.
!>

NAME

pttrf — PTTRF computes the L*D*L' or L*L' factorization of a real symmetric tridiagonal matrix.

SYNOPSIS

Parameters

INTEGER
INFO (Output)

Detailed Description

PTTRF computes the factorization of a real symmetric tridiagonal matrix.

    It is assumed that the matrix A is symmetric, and the routine only needs
    to factorize the upper or lower triangular part of the matrix.

The factorization is of the form

    A = P * L * D * L' * P'

or

    A = P * U * U' * P'

where U is a tridiagonal matrix and P is a permutation vector of size N, L is a unit bidiagonal matrix, and D is a diagonal matrix. L' denotes the transpose of L.

The option UPLO indicates whether the factorization is upper- or lower-triangular.

The option TRANS indicates whether the matrix is transposed.

The output of the factorization is in the real arrays D and E.

The array AR contains the matrix.

The array WORK is a workspace array.

The integer INFO is an output parameter.

Function Documentation

!> @brief
!>
!> PTTRF computes the L*D*L' or L*L' factorization of a real symmetric
!> tridiagonal matrix.
!>
!> This routine is generated from the LAPACK routine ZPTTRF.
!>
!> @param[in] N
!>          N is INTEGER, The order of the matrix A. N >= 0.
!>
!> @param[in,out] D
!>          D is REAL array, dimension (N).
!>          On entry, D contains the diagonal elements of A.
!>          On exit, D contains the diagonal elements of the diagonal matrix
!>          in the factorization.
!>
!> @param[in,out] E
!>          E is REAL array, dimension (N-1).
!>          On entry, E contains the off-diagonal elements of A.
!>          On exit, E contains the off-diagonal elements of the unit
!>          bidiagonal matrix L or the unit upper bidiagonal matrix U.
!>
!> @param[out] INFO
!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -k, the k-th argument had an illegal value
!>          > 0: if INFO = k, the leading principal minor of order k
!>               is not positive; if k < N, the factorization could not
!>               be completed, while if k = N, the factorization was
!>               completed, but D(N) <= 0.
!>
