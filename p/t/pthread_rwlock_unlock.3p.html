PTHREAD_RWLOCK_UNLOCK(3P) Manuel du programmeur POSIX PTHREAD_RWLOCK_UNLOCK(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pthread_rwlock_unlock — déverrouiller un objet de verrouillage lecture-écriture

SYNOPIS

#include <pthread.h>
int pthread_rwlock_unlock(pthread_rwlock_t *rwlock);

DESCRIPTION

La fonction pthread_rwlock_unlock() libère un verrou détenu sur l'objet de verrouillage lecture-écriture référencé par rwlock. Les résultats sont indéfinis si le verrouillage lecture-écriture rwlock n'est pas détenu par le thread appelant.

Si cette fonction est appelée pour libérer un verrou de lecture de l'objet de verrouillage lecture-écriture et qu'il existe d'autres verrous de lecture actuellement détenus sur cet objet de verrouillage lecture-écriture, l'objet de verrouillage lecture-écriture reste dans l'état de verrouillage de lecture. Si cette fonction libère le dernier verrou de lecture pour cet objet de verrouillage lecture-écriture, l'objet de verrouillage lecture-écriture sera mis dans l'état déverrouillé sans propriétaire.

Si cette fonction est appelée pour libérer un verrou d'écriture pour cet objet de verrouillage lecture-écriture, l'objet de verrouillage lecture-écriture sera mis dans l'état déverrouillé.

S'il y a des threads bloqués sur le verrou lorsqu'il devient disponible, la politique de planification déterminera quel(s) thread(s) acquerra le verrou. Si l'option de planification d'exécution des threads est prise en charge, lorsque les threads exécutant avec les politiques de planification SCHED_FIFO, SCHED_RR ou SCHED_SPORADIC attendent sur le verrou, ils acquerront le verrou dans l'ordre de priorité lorsque le verrou devient disponible. Pour les threads de priorité égale, les verrous d'écriture ont la priorité sur les verrous de lecture. Si l'option de planification d'exécution des threads n'est pas prise en charge, il est défini par l'implémentation si les verrous d'écriture ont la priorité sur les verrous de lecture.

Les résultats sont indéfinis si cette fonction est appelée avec un verrouillage lecture-écriture non initialisé.

VALEUR DE RETOUR

En cas de succès, la fonction pthread_rwlock_unlock() renvoie zéro ; sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

ERREURS

La fonction pthread_rwlock_unlock() ne renverra pas de code d'erreur [EINTR].

UTILISATION PAR L'APPLICATION

Aucune.

RATIONALE

Si une implémentation détecte que la valeur spécifiée par l'argument rwlock de pthread_rwlock_unlock() ne se réfère pas à un objet de verrouillage lecture-écriture initialisé, il est recommandé que la fonction échoue et signale une erreur [EINVAL].

Si une implémentation détecte que la valeur spécifiée par l'argument rwlock de pthread_rwlock_unlock() se réfère à un objet de verrouillage lecture-écriture pour lequel le thread courant ne détient pas de verrou, il est recommandé que la fonction échoue et signale une erreur [EPERM].
