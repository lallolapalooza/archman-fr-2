ptop(1) Formatteur de code source ptop ptop(1)

NOM

ptop - Le formatteur de code source Pascal configurable de FPC.

Origine probablement Pascal-TO-Pascal.

SYNTAXE

ptop[-v][-iindent][-bbufsize][-coptsfile]<fichierentree><fichierSortie>

Description

ptop est un formateur de code source plus ou moins configurable pour les sources pascal, et plus particulièrement ceux compatibles avec FPC (qui sont plus ou moins compatibles Turbo Pascal ou Delphi 2.0).

ptop fait partie du paquet FPC utils, qui contient actuellement aussi ppdep, h2pas, ppudump et ppumove.

Utilisation

ptop reformate essentiellement "fichierentree" et génère le résultat dans "fichierSortie". il utilise un fichier de configuration expliqué plus bas, et peut générer un fichier de configuration par défaut pour que vous le modifiiez. (pas nécessaire si vous utilisez les valeurs par défaut).

Options

-h
Affiche une brève description de ces options.
-c
lit les options depuis le fichier de configuration. Un fichier de configuration n'est pas nécessaire, ptop utilisera alors les valeurs par défaut internes. Voir aussi -g.
-i ident
Définit le nombre d'espaces d'indentation utilisés pour les blocs BEGIN END; et autres.
-b bufsize
Définit la taille du tampon à bufsize. Par défaut 255, 0 est considéré comme invalide et ignoré.
-v
soit verbeux. Actuellement, affiche seulement le nombre de lignes lues/écrites et quelques messages d'erreur.
-g ptop.cfg
Écrit un fichier de configuration par défaut à modifier dans le fichier ptop.cfg.

Essayez de jouer avec ptop et son fichier de configuration jusqu'à obtenir l'effet désiré. La configurabilité et les possibilités de ptop sont assez grandes par rapport aux formateurs de code source shareware trouvés par exemple sur SIMTEL.

Remerciements

L'auteur du programme, Michael van Canneyt, qui a également aidé à expliquer le format de ptop.cfg.

Les questions/corrections peuvent être envoyées à fpc-devel@vekoll.saturnus.vein.hu

Merci aussi au reste de l'équipe de développement de FPC.

Le programme est une version modernisée (POO, Flux, extensions Delphi) basée sur un programme de Peter Grogono, qui à son tour a basé son programme sur un formatteur de code Pascal écrit par Ledgard, Hueras et Singer. Voir SIGPLAN Notices, Vol. 12, No. 7, juillet 1977, pages 101-105, et PP.DOC/HLP. Cette version de PP développée sous Pascal/Z V4.0 ou plus. Modifications très mineures pour Turbo Pascal faites par Willett Kempton mars 1984 et oct 84. Fonctionne sous Turbo 8 bits ou Turbo 16 bits. Modification Toad Hall, réécriture pour TP 5, 28 nov 89.
