PTSNAME(3P) Manuel du programmeur POSIX PTSNAME(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

ptsname — obtenir le nom du périphérique esclave de pseudo-terminal

SYNOPIS

#include <stdlib.h>
char *ptsname(int fildes);

DESCRIPTION

La fonction ptsname() renvoie le nom du périphérique esclave de pseudo-terminal associé à un périphérique maître de pseudo-terminal. L'argument fildes est un descripteur de fichier qui fait référence au périphérique maître. La fonction ptsname() renvoie un pointeur vers une chaîne contenant le chemin d'accès du périphérique esclave correspondant.

La fonction ptsname() n'a pas besoin d'être thread-safe.

VALEUR DE RETOUR

En cas de succès, ptsname() renvoie un pointeur vers une chaîne qui est le nom du périphérique esclave de pseudo-terminal. En cas d'échec, ptsname() renvoie un pointeur nul et peut définir errno. Cela pourrait se produire si fildes est un descripteur de fichier invalide ou si le nom du périphérique esclave n'existe pas dans le système de fichiers.

L'application ne doit pas modifier la chaîne renvoyée. Le pointeur renvoyé pourrait être invalidé ou le contenu de la chaîne pourrait être écrasé par un appel ultérieur à ptsname(). Le pointeur renvoyé et le contenu de la chaîne pourraient également être invalidés si le thread appelant est terminé.

ERREURS

La fonction ptsname() peut échouer si :

EBADF
L'argument fildes n'est pas un descripteur de fichier valide.
ENOTTY
Le fichier associé à l'argument fildes n'est pas un périphérique maître de pseudo-terminal.
