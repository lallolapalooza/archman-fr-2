PTHREAD_RWLOCKATTR_GETPSHARED(3P) Manuel du programmeur POSIX PTHREAD_RWLOCKATTR_GETPSHARED(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pthread_rwlockattr_getpshared, pthread_rwlockattr_setpshared — obtenir et définir l'attribut de partage inter-processus d'un objet d'attributs de verrou de lecture-écriture

SYNTAXE

#include <pthread.h>
int pthread_rwlockattr_getpshared(const pthread_rwlockattr_t
    *restrict attr, int *restrict pshared);
int pthread_rwlockattr_setpshared(pthread_rwlockattr_t *attr,
    int pshared);

DESCRIPTION

La fonction pthread_rwlockattr_getpshared() obtient la valeur de l'attribut process-shared de l'objet d'attributs initialisé référencé par attr. La fonction pthread_rwlockattr_setpshared() définit l'attribut process-shared dans un objet d'attributs initialisé référencé par attr.

L'attribut process-shared est défini à PTHREAD_PROCESS_SHARED pour permettre à un verrou de lecture-écriture d'être utilisé par n'importe quel thread ayant accès à la mémoire où le verrou de lecture-écriture est alloué, même si le verrou de lecture-écriture est alloué dans une mémoire partagée par plusieurs processus. Voir la Section 2.9.9, Copies d'objets de synchronisation et mappages alternatifs pour des exigences supplémentaires. La valeur par défaut de l'attribut process-shared est PTHREAD_PROCESS_PRIVATE.

Les attributs supplémentaires, leurs valeurs par défaut et les noms des fonctions associées pour obtenir et définir ces valeurs d'attributs sont définis par l'implémentation.

Le comportement est indéfini si la valeur spécifiée par l'argument attr pour pthread_rwlockattr_getpshared() ou pthread_rwlockattr_setpshared() ne fait pas référence à un objet d'attributs de verrou de lecture-écriture initialisé.

VALEUR RENVOYÉE

En cas de succès, la fonction pthread_rwlockattr_getpshared() renvoie zéro et stocke la valeur de l'attribut process-shared de attr dans l'objet référencé par le paramètre pshared. Sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

En cas de succès, la fonction pthread_rwlockattr_setpshared() renvoie zéro ; sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

ERREURS

La fonction pthread_rwlockattr_setpshared() peut échouer si :

EINVAL
La nouvelle valeur spécifiée pour l'attribut est en dehors de la plage des valeurs légales pour cet attribut.

Ces fonctions ne doivent pas renvoyer le code d'erreur [EINTR].
