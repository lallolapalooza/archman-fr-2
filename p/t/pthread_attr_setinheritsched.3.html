pthread_attr_setinheritsched(3) Manuel des fonctions de bibliothèque pthread_attr_setinheritsched(3)

NOM

pthread_attr_setinheritsched, pthread_attr_getinheritsched - définir/obtenir l'attribut d'héritage de planification dans l'objet d'attributs de thread

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNOPSIS

#include <pthread.h>
int pthread_attr_setinheritsched(pthread_attr_t *attr,
                                 int inheritsched);
int pthread_attr_getinheritsched(const pthread_attr_t *restrict attr,
                                 int *restrict inheritsched);

DESCRIPTION

La fonction pthread_attr_setinheritsched() définit l'attribut d'héritage de planification de l'objet d'attributs de thread référencé par attr à la valeur spécifiée dans inheritsched. L'attribut d'héritage de planification détermine si un thread créé en utilisant l'objet d'attributs de thread attr héritera de ses attributs de planification du thread appelant ou s'il les prendra de attr.

Les attributs de planification suivants sont affectés par l'attribut d'héritage de planification : politique de planification (pthread_attr_setschedpolicy(3)), priorité de planification (pthread_attr_setschedparam(3)), et portée de contention (pthread_attr_setscope(3)).

Les valeurs suivantes peuvent être spécifiées dans inheritsched :

PTHREAD_INHERIT_SCHED
Les threads qui sont créés en utilisant attr héritent des attributs de planification du thread créateur ; les attributs de planification dans attr sont ignorés.
PTHREAD_EXPLICIT_SCHED
Les threads qui sont créés en utilisant attr prennent leurs attributs de planification à partir des valeurs spécifiées par l'objet d'attributs.

La valeur par défaut de l'attribut d'héritage de planification dans un objet d'attributs de thread nouvellement initialisé est PTHREAD_INHERIT_SCHED.

La fonction pthread_attr_getinheritsched() renvoie l'attribut d'héritage de planification de l'objet d'attributs de thread attr dans le tampon pointé par inheritsched.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent 0 ; en cas d'erreur, elles retournent un numéro d'erreur non nul.

ERREURS

pthread_attr_setinheritsched() peut échouer avec l'erreur suivante :

EINVAL
Valeur invalide dans inheritsched.

POSIX.1 documente également une erreur optionnelle ENOTSUP ("tentative a été faite de définir l'attribut à une valeur non prise en charge") pour pthread_attr_setinheritsched().

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_attr_setinheritsched (), pthread_attr_getinheritsched () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.0. POSIX.1-2001.

BOGUES

Au moment de glibc 2.8, si un objet d'attributs de thread est initialisé en utilisant pthread_attr_init(3), alors la politique de planification de l'objet d'attributs est définie à SCHED_OTHER et la priorité de planification est définie à 0. Cependant, si l'attribut d'héritage de planification est ensuite défini à PTHREAD_EXPLICIT_SCHED, alors un thread créé en utilisant l'objet d'attributs hérite à tort de ses attributs de planification du thread créateur. Ce bogue ne se produit pas si la politique de planification ou l'attribut de priorité de planification est explicitement défini dans l'objet d'attributs de thread avant d'appeler pthread_create(3).

EXEMPLES

Voir pthread_setschedparam(3).
