PTHREAD_ATTR_GETSCOPE(3P) Manuel du programmeur POSIX PTHREAD_ATTR_GETSCOPE(3P)

PROLOG

Cette page de manuel fait partie du manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pthread_attr_getscope, pthread_attr_setscope — obtenir et définir l'attribut contentionscope (THREADS TEMPS RÉEL)

SYNTAXE

#include <pthread.h>
int pthread_attr_getscope(const pthread_attr_t *restrict attr,
    int *restrict contentionscope);
int pthread_attr_setscope(pthread_attr_t *attr, int contentionscope);

DESCRIPTION

Les fonctions pthread_attr_getscope() et pthread_attr_setscope() obtiennent et définissent respectivement l'attribut contentionscope dans l'objet attr.

L'attribut contentionscope peut avoir les valeurs PTHREAD_SCOPE_SYSTEM, signifiant une portée de contention de planification système, ou PTHREAD_SCOPE_PROCESS, signifiant une portée de planification de processus. Les symboles PTHREAD_SCOPE_SYSTEM et PTHREAD_SCOPE_PROCESS sont définis dans l'en-tête <pthread.h>.

Le comportement est indéfini si la valeur spécifiée par l'argument attr à pthread_attr_getscope() ou pthread_attr_setscope() ne fait pas référence à un objet d'attributs de thread initialisé.

VALEUR DE RETOUR

En cas de succès, les fonctions pthread_attr_getscope() et pthread_attr_setscope() renvoient zéro ; sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

ERREURS

La fonction pthread_attr_setscope() échoue si :

ENOTSUP
Une tentative a été faite pour définir l'attribut à une valeur non prise en charge.

La fonction pthread_attr_setscope() peut échouer si :

EINVAL
La valeur de contentionscope n'est pas valide.

Ces fonctions ne renvoient pas de code d'erreur [EINTR].

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION APPLICATION

Une fois ces attributs définis, un thread peut être créé avec les attributs spécifiés à l'aide de pthread_create(). L'utilisation de ces routines n'affecte pas le thread en cours d'exécution.

Voir la Section 2.9.4, Planification des threads pour plus de détails sur les attributs de planification des threads et leurs paramètres par défaut.

RATIONALE

Si une implémentation détecte que la valeur spécifiée par l'argument attr à pthread_attr_getscope() ou pthread_attr_setscope() ne fait pas référence à un objet d'attributs de thread initialisé, il est recommandé que la fonction échoue et signale une erreur [EINVAL].
