NOM

pto_gen - Générer un fichier projet Hugin à partir d'une liste d'images.

SYNTAXE

pto_gen [options] image [...]

DESCRIPTION

pto_gen assemble un fichier projet Hugin .pto adapté comme entrée pour d'autres outils tels que le générateur de points de contrôle cpfind, ou pour être ouvert avec l'interface graphique Hugin elle-même. La fonctionnalité est similaire à match-n-shift.

UTILISATION

pto_gen *.jpg

Cela crée un fichier projet à partir de toutes les images jpg, dans le même dossier que la première photo. Le fichier projet est nommé premier_fichier-dernier_fichier.pto en utilisant la même convention que l'interface graphique Hugin.

OPTIONS

-o|--output fichier
Fichier Hugin PTO de sortie.
-p|--projection num
Type de projection (par défaut : 0)
-f|--fov float
Champ de vision horizontal des images (par défaut : 50)
-c|--crop=gauche,droite,haut,bas
Définit le recadrage des images d'entrée (en particulier pour les objectifs fisheye)
-s|--stacklength num
Nombre d'images dans la pile (par défaut : détection automatique)
-l|--linkstacks
Lier les positions des images dans les piles
--distortion
Essayer de charger les informations de distorsion à partir de la base de données des objectifs
--vignetting
Essayer de charger les informations de vignettage à partir de la base de données des objectifs
-h|--help
affiche l'aide
