pthread_attr_init(3) Manuel des fonctions de bibliothèque pthread_attr_init(3)

NOM

pthread_attr_init, pthread_attr_destroy - initialiser et détruire un objet d'attributs de thread

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNOPSIS

#include <pthread.h>
int pthread_attr_init(pthread_attr_t *attr);
int pthread_attr_destroy(pthread_attr_t *attr);

DESCRIPTION

La fonction pthread_attr_init() initialise l'objet d'attributs de thread pointé par attr avec des valeurs d'attribut par défaut. Après cet appel, les attributs individuels de l'objet peuvent être définis à l'aide de diverses fonctions connexes (listées sous VOIR AUSSI), puis l'objet peut être utilisé dans un ou plusieurs appels à pthread_create(3) qui créent des threads.

Appeler pthread_attr_init() sur un objet d'attributs de thread déjà initialisé entraîne un comportement indéfini.

Lorsqu'un objet d'attributs de thread n'est plus requis, il doit être détruit à l'aide de la fonction pthread_attr_destroy(). La destruction d'un objet d'attributs de thread n'a aucun effet sur les threads qui ont été créés à l'aide de cet objet.

Une fois qu'un objet d'attributs de thread a été détruit, il peut être réinitialisé à l'aide de pthread_attr_init(). Toute autre utilisation d'un objet d'attributs de thread détruit a des résultats indéfinis.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent 0 ; en cas d'erreur, elles retournent un numéro d'erreur non nul.

ERREURS

POSIX.1 documente une erreur ENOMEM pour pthread_attr_init ; sous Linux, ces fonctions réussissent toujours (mais les applications portables et pérennes devraient néanmoins gérer un éventuel retour d'erreur).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_attr_init (), pthread_attr_destroy () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

NOTES

Le type pthread_attr_t doit être traité comme opaque : tout accès à l'objet autre que par les fonctions pthreads est non portable et produit des résultats indéfinis.

EXEMPLES

Le programme ci-dessous utilise éventuellement pthread_attr_init() et diverses fonctions connexes pour initialiser un objet d'attributs de thread utilisé pour créer un seul thread. Une fois créé, le thread utilise la fonction pthread_getattr_np(3) (une extension GNU non standard) pour récupérer les attributs du thread, puis affiche ces attributs.

Si le programme est exécuté sans argument de ligne de commande, il passe NULL comme argument attr de pthread_create(3), de sorte que le thread est créé avec des attributs par défaut. En exécutant le programme sous Linux/x86-32 avec l'implémentation de threading NPTL, nous obtenons ce qui suit :


$ ulimit -s       # Pas de limite de pile ==> la taille de pile par défaut est de 2 Mo
unlimited
$ ./a.out
Attributs du thread :
        État de détachement        = PTHREAD_CREATE_JOINABLE
        Portée               = PTHREAD_SCOPE_SYSTEM
        Planification héritée   = PTHREAD_INHERIT_SCHED
        Politique de planification   = SCHED_OTHER
        Priorité de planification = 0
        Taille de garde          = 4096 octets
        Adresse de pile       = 0x40196000
        Taille de pile          = 0x201000 octets

Lorsque nous fournissons une taille de pile comme argument de ligne de commande, le programme initialise un objet d'attributs de thread, définit divers attributs dans cet objet et passe un pointeur vers l'objet dans l'appel à pthread_create(3). En exécutant le programme sous Linux/x86-32 avec l'implémentation de threading NPTL, nous obtenons ce qui suit :


$ ./a.out 0x3000000
posix_memalign() alloué à 0x40197000
Attributs du thread :
        État de détachement        = PTHREAD_CREATE_DETACHED
        Portée               = PTHREAD_SCOPE_SYSTEM
        Planification héritée   = PTHREAD_EXPLICIT_SCHED
        Politique de planification   = SCHED_OTHER
        Priorité de planification = 0
        Taille de garde          = 0 octets
        Adresse de pile       = 0x40197000
        Taille de pile          = 0x3000000 octets

Source du programme

#define _GNU_SOURCE     /* Pour obtenir la déclaration de pthread_getattr_np() */
#include <err.h>
#include <errno.h>
#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
static void
display_pthread_attr(pthread_attr_t *attr, char *prefix)
{
    int s, i;
    size_t v;
    void *stkaddr;
    struct sched_param sp;
    s = pthread_attr_getdetachstate(attr, &i);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getdetachstate");
    printf("%sÉtat de détachement        = %s\n", prefix,
           (i == PTHREAD_CREATE_DETACHED) ? "PTHREAD_CREATE_DETACHED" :
           (i == PTHREAD_CREATE_JOINABLE) ? "PTHREAD_CREATE_JOINABLE" :
           "???");
    s = pthread_attr_getscope(attr, &i);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getscope");
    printf("%sPortée               = %s\n", prefix,
           (i == PTHREAD_SCOPE_SYSTEM)  ? "PTHREAD_SCOPE_SYSTEM" :
           (i == PTHREAD_SCOPE_PROCESS) ? "PTHREAD_SCOPE_PROCESS" :
           "???");
    s = pthread_attr_getinheritsched(attr, &i);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getinheritsched");
    printf("%sPlanification héritée   = %s\n", prefix,
           (i == PTHREAD_INHERIT_SCHED)  ? "PTHREAD_INHERIT_SCHED" :
           (i == PTHREAD_EXPLICIT_SCHED) ? "PTHREAD_EXPLICIT_SCHED" :
           "???");
    s = pthread_attr_getschedpolicy(attr, &i);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getschedpolicy");
    printf("%sPolitique de planification   = %s\n", prefix,
           (i == SCHED_OTHER) ? "SCHED_OTHER" :
           (i == SCHED_FIFO)  ? "SCHED_FIFO" :
           (i == SCHED_RR)    ? "SCHED_RR" :
           "???");
    s = pthread_attr_getschedparam(attr, &sp);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getschedparam");
    printf("%sPriorité de planification = %d\n", prefix, sp.sched_priority);
    s = pthread_attr_getguardsize(attr, &v);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getguardsize");
    printf("%sTaille de garde          = %zu octets\n", prefix, v);
    s = pthread_attr_getstack(attr, &stkaddr, &v);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getstack");
    printf("%sAdresse de pile       = %p\n", prefix, stkaddr);
    printf("%sTaille de pile          = %#zx octets\n", prefix, v);
}
static void *
thread_start(void *arg)
{
    int s;
    pthread_attr_t gattr;
    /* pthread_getattr_np() est une extension GNU non standard qui
       récupère les attributs du thread spécifié dans son premier argument.  */
    s = pthread_getattr_np(pthread_self(), &gattr);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_getattr_np");
    printf("Attributs du thread :\n");
    display_pthread_attr(&gattr, "\t");
    exit(EXIT_SUCCESS);         /* Terminer tous les threads */
}
int
main(int argc, char *argv[])
{
    pthread_t thr;
    pthread_attr_t attr;
    pthread_attr_t *attrp;      /* NULL ou &attr */
    int s;
    attrp = NULL;
    /* Si un argument de ligne de commande a été fourni, on l'utilise pour définir
       l'attribut de taille de pile et définir quelques autres attributs de thread,
       et on fait pointer attrp vers l'objet d'attributs de thread.  */
    if (argc > 1) {
        size_t stack_size;
        void *sp;
        attrp = &attr;
        s = pthread_attr_init(&attr);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_attr_init");
        s = pthread_attr_setdetachstate(&attr, PTHREAD_CREATE_DETACHED);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_attr_setdetachstate");
        s = pthread_attr_setinheritsched(&attr, PTHREAD_EXPLICIT_SCHED);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_attr_setinheritsched");
        stack_size = strtoul(argv[1], NULL, 0);
        s = posix_memalign(&sp, sysconf(_SC_PAGESIZE), stack_size);
        if (s != 0)
            errc(EXIT_FAILURE, s, "posix_memalign");
        printf("posix_memalign() alloué à %p\n", sp);
        s = pthread_attr_setstack(&attr, sp, stack_size);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_attr_setstack");
    }
    s = pthread_create(&thr, attrp, &thread_start, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_create");
    if (attrp != NULL) {
        s = pthread_attr_destroy(attrp);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_attr_destroy");
    }
    pause();    /* Se termine lorsque l'autre thread appelle exit() */
}
