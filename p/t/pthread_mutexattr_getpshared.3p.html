PTHREAD_MUTEXATTR_GETPSHARED(3P) Manuel du programmeur POSIX PTHREAD_MUTEXATTR_GETPSHARED(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pthread_mutexattr_getpshared, pthread_mutexattr_setpshared — obtenir et définir l'attribut de partage entre processus

SYNTAXE

#include <pthread.h>
int pthread_mutexattr_getpshared(const pthread_mutexattr_t
    *restrict attr, int *restrict pshared);
int pthread_mutexattr_setpshared(pthread_mutexattr_t *attr,
    int pshared);

DESCRIPTION

La fonction pthread_mutexattr_getpshared() récupère la valeur de l'attribut process-shared à partir de l'objet d'attributs référencé par attr.

La fonction pthread_mutexattr_setpshared() définit l'attribut process-shared dans un objet d'attributs initialisé référencé par attr.

L'attribut process-shared est défini sur PTHREAD_PROCESS_SHARED pour permettre à un mutex d'être manipulé par tout thread ayant accès à la mémoire où le mutex est alloué, même si le mutex est alloué dans une mémoire partagée par plusieurs processus. Voir Section 2.9.9, Copies d'objets de synchronisation et mappages alternatifs pour des exigences supplémentaires. La valeur par défaut de l'attribut est PTHREAD_PROCESS_PRIVATE.

Le comportement est indéfini si la valeur spécifiée par l'argument attr pour pthread_mutexattr_getpshared() ou pthread_mutexattr_setpshared() ne référence pas un objet d'attributs de mutex initialisé.

VALEUR DE RETOUR

En cas de succès, pthread_mutexattr_setpshared() renvoie zéro ; sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

En cas de succès, pthread_mutexattr_getpshared() renvoie zéro et stocke la valeur de l'attribut process-shared de attr dans l'objet référencé par le paramètre pshared. Sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

ERREURS

La fonction pthread_mutexattr_setpshared() peut échouer si :

EINVAL
La nouvelle valeur spécifiée pour l'attribut est en dehors de la plage des valeurs légales pour cet attribut.

Ces fonctions ne renverront pas de code d'erreur [EINTR].

UTILISATION APPLICATION

RATIONALE

Si une implémentation détecte que la valeur spécifiée par l'argument attr pour pthread_mutexattr_getpshared() ou pthread_mutexattr_setpshared() ne référence pas un objet d'attributs de mutex initialisé, il est recommandé que la fonction échoue et signale une erreur [EINVAL].
