pthread_cancel(3) Manuel des fonctions de bibliothèque pthread_cancel(3)

NOM

pthread_cancel - envoyer une requête d'annulation à un thread

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <pthread.h>
int pthread_cancel(pthread_t thread);

DESCRIPTION

La fonction pthread_cancel() envoie une requête d'annulation au thread thread. La manière dont le thread cible réagit à la requête d'annulation, et quand, dépend de deux attributs contrôlés par ce thread : son état d'annulabilité et son type.

L'état d'annulabilité d'un thread, déterminé par pthread_setcancelstate(3), peut être activé (par défaut pour les nouveaux threads) ou désactivé. Si un thread a désactivé l'annulabilité, une requête d'annulation reste mise en file d'attente jusqu'à ce que le thread active l'annulabilité. Si un thread a activé l'annulabilité, son type d'annulabilité détermine quand l'annulation se produit.

Le type d'annulabilité d'un thread, déterminé par pthread_setcanceltype(3), peut être asynchrone ou différé (par défaut pour les nouveaux threads). L'annulabilité asynchrone signifie que le thread peut être annulé à tout moment (généralement immédiatement, mais le système ne le garantit pas). L'annulabilité différée signifie que l'annulation sera retardée jusqu'à ce que le thread appelle une fonction qui est un point d'annulation. Une liste de fonctions qui sont ou peuvent être des points d'annulation est fournie dans pthreads(7).

Lorsqu'une requête d'annulation est traitée, les étapes suivantes se produisent pour thread (dans cet ordre) :

(1)
Les gestionnaires de nettoyage d'annulation sont dépilés (dans l'ordre inverse de celui dans lequel ils ont été empilés) et appelés. (Voir pthread_cleanup_push(3).)
(2)
Les destructeurs de données spécifiques au thread sont appelés, dans un ordre non spécifié. (Voir pthread_key_create(3).)
(3)
Le thread est terminé. (Voir pthread_exit(3).)

Les étapes ci-dessus se produisent de manière asynchrone par rapport à l'appel pthread_cancel(); le statut de retour de pthread_cancel() informe simplement l'appelant si la requête d'annulation a été mise en file d'attente avec succès.

Après qu'un thread annulé a terminé, une jointure avec ce thread en utilisant pthread_join(3) renvoie PTHREAD_CANCELED comme statut de sortie du thread. (La jointure avec un thread est le seul moyen de savoir que l'annulation est terminée.)

VALEUR DE RETOUR

En cas de succès, pthread_cancel() renvoie 0 ; en cas d'erreur, elle renvoie un numéro d'erreur non nul.

ERREURS

ESRCH
Aucun thread avec l'identifiant thread n'a été trouvé.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_cancel () Sécurité des threads MT-Safe

VERSIONS

Sous Linux, l'annulation est implémentée à l'aide de signaux. Sous l'implémentation des threads NPTL, le premier signal temps réel (c'est-à-dire le signal 32) est utilisé à cette fin. Sous LinuxThreads, le deuxième signal temps réel est utilisé, si les signaux temps réel sont disponibles, sinon SIGUSR2 est utilisé.

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.0 POSIX.1-2001.

EXEMPLES

Le programme ci-dessous crée un thread, puis l'annule. Le thread principal joint avec le thread annulé pour vérifier que son statut de sortie était PTHREAD_CANCELED. La session shell suivante montre ce qui se passe lorsque nous exécutons le programme :


$ ./a.out
thread_func(): started; cancelation disabled
main(): sending cancelation request
thread_func(): about to enable cancelation
main(): thread was canceled

Source du programme

#include <err.h>
#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
static void *
thread_func(void *ignored_argument)
{
    int s;
    /* Disable cancelation for a while, so that we don't
       immediately react to a cancelation request.  */
    s = pthread_setcancelstate(PTHREAD_CANCEL_DISABLE, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_setcancelstate");
    printf("%s(): started; cancelation disabled\n", __func__);
    sleep(5);
    printf("%s(): about to enable cancelation\n", __func__);
    s = pthread_setcancelstate(PTHREAD_CANCEL_ENABLE, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_setcancelstate");
    /* sleep() is a cancelation point.  */
    sleep(1000);        /* Should get canceled while we sleep */
    /* Should never get here.  */
    printf("%s(): not canceled!\n", __func__);
    return NULL;
}
int
main(void)
{
    pthread_t thr;
    void *res;
    int s;
    /* Start a thread and then send it a cancelation request.  */
    s = pthread_create(&thr, NULL, &thread_func, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_create");
    sleep(2);           /* Give thread a chance to get started */
    printf("%s(): sending cancelation request\n", __func__);
    s = pthread_cancel(thr);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_cancel");
    /* Join with thread to see what its exit status was.  */
    s = pthread_join(thr, &res);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_join");
    if (res == PTHREAD_CANCELED)
        printf("%s(): thread was canceled\n", __func__);
    else
        printf("%s(): thread wasn't canceled (shouldn't happen!)\n",
               __func__);
    exit(EXIT_SUCCESS);
}

NOM

pthread_cancel - annuler un thread

BIBLIOTHÈQUE

Bibliothèque de threads POSIX (libpthread, -lpthread)

SYNTAXE

#include <pthread.h>

int pthread_cancel(pthread_t thread);

DESCRIPTION

La fonction pthread_cancel demande l'annulation du thread spécifié par thread. L'annulation est effectuée de manière asynchrone par défaut, ce qui signifie que le thread peut être annulé à tout moment lorsqu'il atteint un point d'annulation.

Le thread cible peut contrôler si et quand il sera annulé en utilisant pthread_setcancelstate et pthread_setcanceltype.

Lorsqu'un thread est annulé, il est terminé. La fonction de rappel enregistrée avec pthread_cleanup_push est appelée avant que le thread ne soit réellement terminé. La mémoire du thread est libérée si le thread est attaché.

VALEUR DE RETOUR

En cas de succès, pthread_cancel retourne 0. En cas d'erreur, elle retourne un numéro d'erreur positif.

ERREURS

ESRCH
Aucun thread avec le numéro d'ID spécifié par thread n'a été trouvé.
EINVAL
thread est un ID de thread invalide.

ATTRIBUTS

Pour une explication des attributs ci-dessous, voir pthread_getattr_np(3).

INTERFACE_SIZE_LARGE
pthread_cancel
MT_SAFE
pthread_cancel

VERSIONS

La fonction pthread_cancel est disponible dans les versions 2.0 et ultérieures de glibc.

NORMES

POSIX.1-2001, POSIX.1-2008.

HISTORIQUE
