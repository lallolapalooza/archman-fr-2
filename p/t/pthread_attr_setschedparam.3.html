pthread_attr_setschedparam(3) Manuel des fonctions de bibliothèque pthread_attr_setschedparam(3)

NOM

pthread_attr_setschedparam, pthread_attr_getschedparam - définir/obtenir les attributs des paramètres de planification dans l'objet d'attributs de thread

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <pthread.h>
int pthread_attr_setschedparam(pthread_attr_t *restrict attr,
                              const struct sched_param *restrict param);
int pthread_attr_getschedparam(const pthread_attr_t *restrict attr,
                              struct sched_param *restrict param);

DESCRIPTION

La fonction pthread_attr_setschedparam() définit les attributs des paramètres de planification de l'objet d'attributs de thread référencé par attr selon les valeurs spécifiées dans le tampon pointé par param. Ces attributs déterminent les paramètres de planification d'un thread créé à l'aide de l'objet d'attributs de thread attr.

La fonction pthread_attr_getschedparam() renvoie les attributs des paramètres de planification de l'objet d'attributs de thread attr dans le tampon pointé par param.

Les paramètres de planification sont maintenus dans la structure suivante :


struct sched_param {
    int sched_priority;     /* Priorité de planification */
};

Comme on peut le voir, un seul paramètre de planification est pris en charge. Pour plus de détails sur les plages autorisées pour les priorités de planification dans chaque politique de planification, voir sched(7).

Pour que le paramètre défini par pthread_attr_setschedparam() ait effet lors de l'appel de pthread_create(3), l'appelant doit utiliser pthread_attr_setinheritsched(3) pour définir l'attribut hériter-planificateur de l'objet d'attributs attr sur PTHREAD_EXPLICIT_SCHED.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent 0 ; en cas d'erreur, elles retournent un numéro d'erreur non nul.

ERREURS

pthread_attr_setschedparam() peut échouer avec l'erreur suivante :

EINVAL
La priorité spécifiée dans param n'est pas valide pour la politique de planification actuelle de attr.

POSIX.1 documente également une erreur ENOTSUP pour pthread_attr_setschedparam(). Cette valeur n'est jamais retournée sous Linux (mais les applications portables et pérennes devraient néanmoins gérer cette valeur de retour d'erreur).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).
