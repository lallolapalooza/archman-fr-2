NOM

pt-fifo-split - Divise les fichiers et dirige les lignes vers un fifo sans réellement diviser.

SYNTAXE

Utilisation : pt-fifo-split [OPTIONS] [FICHIER]

pt-fifo-split divise FICHIER et dirige les lignes vers un fifo. Sans FICHIER, ou lorsque FICHIER est -, lit l'entrée standard.

Lire hugefile.txt par morceaux d'un million de lignes sans le diviser physiquement :

pt-fifo-split --lines 1000000 hugefile.txt
while [ -e /tmp/pt-fifo-split ]; do cat /tmp/pt-fifo-split; done

DESCRIPTION

pt-fifo-split vous permet de lire à partir d'un fichier comme s'il ne contenait qu'une partie des lignes du fichier. Lorsque vous le lisez à nouveau, il contient le prochain ensemble de lignes ; lorsque vous avez parcouru l'ensemble, le fichier disparaît. Cela ne fonctionne que sur les systèmes de type Unix.

Vous pouvez spécifier plusieurs fichiers sur la ligne de commande. Si vous n'en spécifiez aucun, ou si vous utilisez le nom de fichier spécial "-", les lignes sont lues depuis l'entrée standard.

OPTIONS

Cet outil accepte des arguments de ligne de commande supplémentaires. Référez-vous à la "SYNTAXE" et aux informations d'utilisation pour les détails.

--config
type : Tableau

Lire cette liste de fichiers de configuration séparés par des virgules ; si spécifié, cela doit être la première option sur la ligne de commande.

--fifo
type : chaîne ; par défaut : /tmp/pt-fifo-split

Le nom du fifo à partir duquel les lignes peuvent être lues.

--force
Supprimer le fifo s'il existe déjà, puis le recréer.
--help
Afficher l'aide et quitter.
--lines
type : entier ; par défaut : 1000

Le nombre de lignes à lire dans chaque morceau.

--offset
type : entier ; par défaut : 0

Commencer à la Nème ligne. Si l'argument est 0, toutes les lignes sont imprimées dans le fifo. Si 1, alors en commençant par la première ligne, les lignes sont imprimées (exactement comme 0). Si 2, la première ligne est ignorée, et la 2ème et les lignes suivantes sont imprimées dans le fifo.

--pid
type : chaîne

Créer le fichier PID donné. L'outil ne démarrera pas si le fichier PID existe déjà et que le PID qu'il contient est différent du PID actuel. Cependant, si le fichier PID existe et que le PID qu'il contient n'est plus en cours d'exécution, l'outil écrasera le fichier PID avec le PID actuel. Le fichier PID est supprimé automatiquement lorsque l'outil se termine.

--statistics
Afficher des statistiques entre les morceaux. Les statistiques sont le nombre de morceaux, le nombre de lignes, le temps écoulé, et les lignes par seconde au total et pendant le dernier morceau.
--version
Afficher la version et quitter.

ENVIRONNEMENT

La variable d'environnement "PTDEBUG" active la sortie de débogage verbeuse vers STDERR. Pour activer le débogage et capturer toute la sortie dans un fichier, exécutez l'outil comme ceci :

PTDEBUG=1 pt-fifo-split ... > FICHIER 2>&1

Attention : la sortie de débogage est volumineuse et peut générer plusieurs mégaoctets de sortie.

ATTENTION

L'utilisation de <PTDEBUG> peut exposer des mots de passe. Lorsque le débogage est activé, tous les paramètres de la ligne de commande sont affichés dans la sortie.

EXIGENCES SYSTÈME

Vous avez besoin de Perl, DBI, DBD::mysql et de quelques paquets de base qui devraient être installés dans toute version raisonnablement récente de Perl.
