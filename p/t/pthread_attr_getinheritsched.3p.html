PTHREAD_ATTR_GETINHERITSCHED(3P) Manuel du programmeur POSIX PTHREAD_ATTR_GETINHERITSCHED(3P)

PROLOG

Cette page de manuel fait partie du manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pthread_attr_getinheritsched, pthread_attr_setinheritsched — obtenir et définir l'attribut inheritsched (THREADS RÉELLES)

SYNTAXE

#include <pthread.h>
int pthread_attr_getinheritsched(const pthread_attr_t *restrict attr,
    int *restrict inheritsched);
int pthread_attr_setinheritsched(pthread_attr_t *attr,
    int inheritsched);

DESCRIPTION

Les fonctions pthread_attr_getinheritsched() et pthread_attr_setinheritsched(), respectivement, obtiennent et définissent l'attribut inheritsched dans l'argument attr.

Lorsque les objets d'attributs sont utilisés par pthread_create(), l'attribut inheritsched détermine comment les autres attributs de planification du thread créé seront définis.

Les valeurs prises en charge pour inheritsched sont :

PTHREAD_INHERIT_SCHED

Spécifie que les attributs de planification du thread seront hérités du thread créant, et que les attributs de planification dans cet argument attr seront ignorés.
PTHREAD_EXPLICIT_SCHED

Spécifie que les attributs de planification du thread seront définis aux valeurs correspondantes de cet objet d'attributs.

Les symboles PTHREAD_INHERIT_SCHED et PTHREAD_EXPLICIT_SCHED sont définis dans l'en-tête <pthread.h>.

Les attributs de planification de thread suivants définis par POSIX.1‐2008 sont affectés par l'attribut inheritsched : politique de planification (schedpolicy), paramètres de planification (schedparam) et portée de contention de planification (contentionscope).

Le comportement est indéfini si la valeur spécifiée par l'argument attr à pthread_attr_getinheritsched() ou pthread_attr_setinheritsched() ne fait pas référence à un objet d'attributs de thread initialisé.

VALEUR RENVOYÉE

En cas de succès, les fonctions pthread_attr_getinheritsched() et pthread_attr_setinheritsched() renvoient zéro ; sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

ERREURS

La fonction pthread_attr_setinheritsched() échouera si :

ENOTSUP
Une tentative a été faite pour définir l'attribut à une valeur non prise en charge.

La fonction pthread_attr_setinheritsched() peut échouer si :

EINVAL
La valeur de inheritsched n'est pas valide.

Ces fonctions ne renverront pas de code d'erreur [EINTR].

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION PAR L'APPLICATION

Après que ces attributs ont été définis, un thread peut être créé avec les attributs spécifiés en utilisant pthread_create(). L'utilisation de ces routines n'affecte pas le thread en cours d'exécution.

Voir la Section 2.9.4, Planification des threads pour plus de détails sur les attributs de planification des threads et leurs paramètres par défaut.

RATIONALE

Si une implémentation détecte que la valeur spécifiée par l'argument attr à pthread_attr_getinheritsched() ou pthread_attr_setinheritsched() ne fait pas référence à un objet d'attributs de thread initialisé, il est recommandé que la fonction échoue et renvoie une erreur [EINVAL].
