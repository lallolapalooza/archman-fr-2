pthread_mutexattr_getpshared(3) Manuel des fonctions de bibliothèque pthread_mutexattr_getpshared(3)

NOM

pthread_mutexattr_getpshared, pthread_mutexattr_setpshared - obtenir/définir l'attribut de mutex partagé entre processus

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <pthread.h>
int pthread_mutexattr_getpshared(
                      const pthread_mutexattr_t *restrict attr,
                      int *restrict pshared);
int pthread_mutexattr_setpshared(pthread_mutexattr_t *attr,
                      int pshared);

DESCRIPTION

Ces fonctions obtiennent et définissent l'attribut de partage entre processus dans un objet d'attributs de mutex. Cet attribut doit être correctement défini pour assurer un fonctionnement correct et efficace d'un mutex créé à l'aide de cet objet d'attributs.

L'attribut de partage entre processus peut avoir l'une des valeurs suivantes :

PTHREAD_PROCESS_PRIVATE
Les mutex créés avec cet objet d'attributs doivent être partagés uniquement entre les threads du même processus qui ont initialisé le mutex. C'est la valeur par défaut pour l'attribut de mutex partagé entre processus.
PTHREAD_PROCESS_SHARED
Les mutex créés avec cet objet d'attributs peuvent être partagés entre tous les threads qui ont accès à la mémoire contenant l'objet, y compris les threads de processus différents.

pthread_mutexattr_getpshared() place la valeur de l'attribut de partage entre processus de l'objet d'attributs de mutex référencé par attr à l'emplacement pointé par pshared.

pthread_mutexattr_setpshared() définit la valeur de l'attribut de partage entre processus de l'objet d'attributs de mutex référencé par attr à la valeur spécifiée dans pshared.

Si attr ne référence pas un objet d'attributs de mutex initialisé, le comportement est indéfini.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent 0. En cas d'erreur, elles retournent un numéro d'erreur positif.

ERREURS

pthread_mutexattr_setpshared() peut échouer avec les erreurs suivantes :

EINVAL
La valeur spécifiée dans pshared est invalide.
ENOTSUP
pshared est PTHREAD_PROCESS_SHARED mais l'implémentation ne prend pas en charge les mutex partagés entre processus.

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

VOIR AUSSI
