pthread_once(3) Manuel des fonctions de bibliothèque pthread_once(3)

NOM

pthread_once - initialisation à exécution unique

SYNOPSIS

#include <pthread.h>

pthread_once_t once_control = PTHREAD_ONCE_INIT;

int pthread_once(pthread_once_t *once_control, typeof(void (void)) *init_routine;

DESCRIPTION

Le but de pthread_once() est de s'assurer qu'un morceau de code d'initialisation est exécuté au plus une fois. L'argument once_control pointe vers une variable statique ou externe initialisée statiquement à PTHREAD_ONCE_INIT.

La première fois que pthread_once() est appelée avec un argument once_control donné, elle appelle init_routine sans argument et modifie la valeur de la variable once_control pour enregistrer que l'initialisation a été effectuée. Les appels ultérieurs à pthread_once() avec le même argument once_control ne font rien.

VALEUR DE RETOUR

pthread_once() retourne toujours 0.

ERREURS

Aucune.
