PTHREAD_CONDATTR_GETCLOCK(3P) Manuel du programmeur POSIX PTHREAD_CONDATTR_GETCLOCK(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pthread_condattr_getclock, pthread_condattr_setclock — obtenir et définir l'attribut de sélection d'horloge pour une variable de condition

SYNTAXE

#include <pthread.h>
int pthread_condattr_getclock(const pthread_condattr_t *restrict attr,
    clockid_t *restrict clock_id);
int pthread_condattr_setclock(pthread_condattr_t *attr,
    clockid_t clock_id);

DESCRIPTION

La fonction pthread_condattr_getclock() récupère la valeur de l'attribut clock à partir de l'objet d'attributs référencé par attr.

La fonction pthread_condattr_setclock() définit l'attribut clock dans un objet d'attributs initialisé référencé par attr. Si pthread_condattr_setclock() est appelée avec un argument clock_id qui fait référence à une horloge de temps CPU, l'appel échouera.

L'attribut clock est l'identifiant de l'horloge qui sera utilisée pour mesurer le délai d'attente de pthread_cond_timedwait(). La valeur par défaut de l'attribut clock fait référence à l'horloge système.

Le comportement est indéfini si la valeur spécifiée par l'argument attr pour pthread_condattr_getclock() ou pthread_condattr_setclock() ne fait pas référence à un objet d'attributs de variable de condition initialisé.

VALEUR RENVOYÉE

En cas de succès, la fonction pthread_condattr_getclock() renvoie zéro et stocke la valeur de l'attribut d'horloge de attr dans l'objet référencé par l'argument clock_id. Sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

En cas de succès, la fonction pthread_condattr_setclock() renvoie zéro ; sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

ERREURS

La fonction pthread_condattr_setclock() peut échouer si :

EINVAL
La valeur spécifiée par clock_id ne fait pas référence à une horloge connue, ou est une horloge de temps CPU.

Ces fonctions ne renverront pas de code d'erreur [EINTR].

UTILISATION PAR L'APPLICATION

RATIONALE

Si une implémentation détecte que la valeur spécifiée par l'argument attr pour pthread_condattr_getclock() ou pthread_condattr_setclock() ne fait pas référence à un objet d'attributs de variable de condition initialisé, il est recommandé que la fonction échoue et signale une erreur [EINVAL].
