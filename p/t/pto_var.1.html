NOM

pto_var - changer les variables d'image dans les fichiers de projet Hugin .pto

SYNTAXE

pto_var [options] --opt|--link|--unlink|--set "liste_de_variables d'image" fichier.pto

DESCRIPTION

pto_var est un outil en ligne de commande, adapté pour être inclus dans des scripts shell, et permet de modifier les variables d'image dans un fichier de projet Hugin .pto. Les variables d'optimisation peuvent être définies, modifiées, liées et déliées. Les variables d'image suivantes sont autorisées :

position : y, p, r, TrX, TrY, TrZ paramètres de l'objectif : v, a, b, c, d, e, g, t paramètres photométriques : EeV, Er, Eb, Vb, Vc, Vd, Vx, Vy, Ra, Rb, Rc, Rd, Re (les paramètres de vignettage et de réponse seront traités en groupe.)

Les numéros d'image commencent à zéro. Si le numéro est manquant, cela s'applique aux variables de toutes les images (Dans ce cas, un traitement spécial s'applique à la position de l'image d'ancrage). Un point d'exclamation avant la variable supprimera la variable de la liste des variables à optimiser.

OPTIONS

-o|--output = fichier.pto
Fichier de sortie Hugin PTO. Par défaut : <nom_de_fichier>_var.pto
-h|--help
Affiche l'aide
--opt liste_var
Modifier les variables de l'optimiseur
--modify-opt
Modifier les variables de l'optimiseur existantes
(sans pto_var commencera avec un jeu de variables vide)
Exemples :
--opt=y,p,r           Optimiser le lacet, le tangage et le roulis de toutes les images
                      (traitement spécial pour l'image d'ancrage s'applique)
--opt=v0,b2           Optimiser le champ de vision de l'image 0 et la distorsion en barillet
                      de l'image 2
--opt=v,!v0           Optimiser le champ de vision pour toutes les images sauf
                      la première image
--modify-opt --opt=!v n'optimisera pas le champ de vision.
--opt=!a,!b,!c        Ne pas optimiser la distorsion (ne fonctionne qu'avec
                      le commutateur --modify-opt ensemble)
--link liste_var
Exemple :
--link=v3          Lier le champ de vision de l'image 3
--link=a1,b1,c1    Lier les paramètres de distorsion pour l'image 1
--unlink liste_var
Exemples :
--unlink=v5        Délier le champ de vision de l'image 5
--unlink=a2,b2,c2  Délier les paramètres de distorsion de l'image 2
--set liste_var
Exemples :
--set=y0=0,r0=0,p0=0  Réinitialise la position de l'image 0
--set=Vx4=-10,Vy4=10  Définit le décalage de vignettage pour l'image 4
--set=v=20            Définit le champ de vision à 20 pour toutes les images
--set=y=val+20        Augmente le lacet de 20 degrés pour toutes les images
--set=v=val*1.1       Augmente le champ de vision de 10 % pour toutes les images
--set=y=i*20        Définit le lacet à 0, 20, 40, ...
--set-from-file nom_fichier
Définit les variables à de nouvelles valeurs
Il lit la liste de variables depuis un fichier
