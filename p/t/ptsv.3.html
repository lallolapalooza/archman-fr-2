sous-routine cptsv (integer n, integer nrhs, real, dimension( * ) d, complex, dimension( * ) e, complex, dimension( ldb, * ) b, integer ldb, integer info)

CPTSV calcule la solution d'un système d'équations linéaires complexes A * X = B pour les matrices PT

Objectif :

!>
!> CPTSV calcule la solution d'un système linéaire complexe
!> A*X = B, où A est une matrice tridiagonale hermitienne définie positive de taille N x N
!> et X et B sont des matrices de taille N x NRHS.
!>
!> A est factorisée sous la forme A = L*D*L**H, et la forme factorisée de A est ensuite
!> utilisée pour résoudre le système d'équations.
!>

Paramètres

N 
!>          N est un INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est un INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B. NRHS >= 0.
!>

D

!>          D est un tableau de type REAL, de dimension (N)
!>          À l'entrée, les n éléments diagonaux de la matrice tridiagonale
!>          A. À la sortie, les n éléments diagonaux de la matrice diagonale
!>          D issue de la factorisation A = L*D*L**H.
!>

E

!>          E est un tableau de type COMPLEX, de dimension (N-1)
!>          À l'entrée, les n-1 éléments sous-diagonaux de la matrice tridiagonale
!>          A. À la sortie, les n-1 éléments sous-diagonaux du facteur bidiagonal unitaire
!>          L issu de la factorisation L*D*L**H de A.
!>          E peut également être considéré comme la superdiagonale du facteur bidiagonal unitaire
!>          U issu de la factorisation U**H*D*U de A.
!>

B

!>          B est un tableau de type COMPLEX, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice membre de droite B de taille N x NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N x NRHS.
!>

LDB

!>          LDB est un INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

INFO

!>          INFO est un INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, alors le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le mineur principal de tête d'ordre i
!>                n'est pas positif, et la solution n'a pas été calculée.
!>                La factorisation n'est pas terminée sauf si i = N.
!>

NAME


ptsv - PTSV résout le système d'équations linéaires AX = B pour les matrices PT






SYNOPSIS


   SUBROUTINE PTSV(N, NRHS, D, E, B, LDB, INFO)

   INTEGER N
   REAL E(*)
   REAL D(*)
   INTEGER NRHS
   REAL B(LDB,*)
   INTEGER LDB
   INTEGER INFO







Detailed Description


PTSV calcule la solution du système d'équations linéaires A*X = B,
    où A est une matrice tridiagonale symétrique définie positive N x N, et X et B
    sont des matrices N x NRHS.


A est factorisée comme A = L*D*L**T, et la forme factorisée de A est
    alors utilisée pour résoudre le système d'équations.
