CPTSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices PT

Objectif :

!>
!> CPTSVX utilise la factorisation A = L*D*L**H pour calculer la solution
!> d'un système complexe d'équations linéaires A*X = B, où A est une
!> matrice tridiagonale hermitienne définie positive de taille N x N et
!> X et B sont des matrices de taille N x NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de condition sont
!> également fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'N', la matrice A est factorisée en A = L*D*L**H, où L
!>    est une matrice bidiagonale inférieure unitaire et D est diagonale.
!>    La factorisation peut également être considérée comme ayant la forme
!>    A = U**H*D*U.
!>
!> 2. Si le mineur principal d'ordre i n'est pas positif,
!>    alors la routine retourne avec INFO = i. Sinon, la forme factorisée
!>    de A est utilisée pour estimer le nombre de conditionnement de la
!>    matrice A. Si l'inverse du nombre de conditionnement est inférieur à la
!>    précision machine, INFO = N+1 est retourné comme avertissement, mais la
!>    routine continue à résoudre pour X et à calculer les bornes d'erreur
!>    comme décrit ci-dessous.
!>
!> 3. Le système d'équations est résolu pour X en utilisant la forme
!>    factorisée de A.
!>
!> 4. Un raffinement itératif est appliqué pour améliorer la solution calculée
!>    et calculer des bornes d'erreur et des estimations d'erreur arrière
!>    pour celle-ci.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice
!>          A est fournie ou non à l'entrée.
!>          = 'F' : À l'entrée, DF et EF contiennent la forme factorisée de A.
!>                  D, E, DF et EF ne seront pas modifiés.
!>          = 'N' : La matrice A sera copiée dans DF et EF et
!>                  factorisée.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          des matrices B et X. NRHS >= 0.
!>

D

!>          D est un tableau REAL, de dimension (N)
!>          Les n éléments diagonaux de la matrice tridiagonale A.
!>

E

!>          E est un tableau COMPLEX, de dimension (N-1)
!>          Les n-1 éléments sous-diagonaux de la matrice tridiagonale A.
!>

DF

!>          DF est un tableau REAL, de dimension (N)
!>          Si FACT = 'F', alors DF est un argument d'entrée et contient à
!>          l'entrée les n éléments diagonaux de la matrice diagonale D
!>          de la factorisation L*D*L**H de A.
!>          Si FACT = 'N', alors DF est un argument de sortie et contient à
!>          la sortie les n éléments diagonaux de la matrice diagonale D
!>          de la factorisation L*D*L**H de A.
!>

EF

!>          EF est un tableau COMPLEX, de dimension (N-1)
!>          Si FACT = 'F', alors EF est un argument d'entrée et contient à
!>          l'entrée les n-1 éléments sous-diagonaux du facteur bidiagonal
!>          unitaire L de la factorisation L*D*L**H de A.
!>          Si FACT = 'N', alors EF est un argument de sortie et contient à
!>          la sortie les n-1 éléments sous-diagonaux du facteur bidiagonal
!>          unitaire L de la factorisation L*D*L**H de A.
!>

B

!>          B est un tableau COMPLEX, de dimension (LDB,NRHS)
!>          La matrice membre de droite B de taille N x NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEX, de dimension (LDX,NRHS)
!>          Si INFO = 0 ou INFO = N+1, la matrice solution X de taille
!>          N x NRHS.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X. LDX >= max(1,N).
!>

RCOND

!>          RCOND est REAL
!>          L'inverse du nombre de conditionnement de la matrice A. Si RCOND
!>          est inférieur à la précision machine (en particulier, si
!>          RCOND = 0), la matrice est singulière à la précision de travail.
!>          Cette condition est indiquée par un code de retour INFO > 0.
!>

FERR

!>          FERR est un tableau REAL, de dimension (NRHS)
!>          La borne d'erreur avant pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément de X(j).
!>

BERR

!>          BERR est un tableau REAL, de dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque
!>          vecteur solution X(j) (c'est-à-dire le plus petit changement relatif
!>          dans n'importe quel élément de A ou B qui rend X(j) une solution
!>          exacte).
!>

WORK

!>          WORK est un tableau COMPLEX, de dimension (N)
!>

RWORK

!>          RWORK est un tableau REAL, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, et i est
!>                <= N : le mineur principal d'ordre i de A
!>                       n'est pas positif, donc la factorisation n'a pas pu
!>                       être complétée, et la solution n'a pas été
!>                       calculée. RCOND = 0 est retourné.
!>                = N+1 : U est non singulier, mais RCOND est inférieur à la
!>                       précision machine, ce qui signifie que la matrice est
!>                       singulière à la précision de travail. Néanmoins, la
!>                       solution et les bornes d'erreur sont calculées car
!>                       il existe un certain nombre de situations où la
!>                       solution calculée peut être plus précise que la
!>                       valeur de RCOND ne le suggérerait.
!>

Définition à la ligne 226 du fichier sptsvx.f.

SPTSVX computes the solution to a real system of linear equations A * X = B for tridiagonal matrices.

Purpose: 

    SPTSVX uses the factorization A = P*L*D*L**T*Q**T to compute the solution
    to a real system of linear equations A*X = B, where A is an N-by-N
    tridiagonal matrix, P and Q are permutation matrices, L is unit
    lower bidiagonal, and D is diagonal.

    Error bounds on the solution and a condition estimate are also
    provided.

Description: 

    The following steps are performed:

    1. If FACT = 'N', the matrix A is factored as A = P*L*D*L**T*Q**T, where L
       is unit lower bidiagonal and D is diagonal. L isN-by-N and the
       diagonals of D are stored in the array DF. The subdiagonals of L
       are stored in the array EF.

    2. If the factorization fails (e.g., a diagonal element of D is zero),
       the routine returns with INFO > 0.

    3. The condition number of the matrix A is estimated by computing an
       upper bound on the relative residual. If the reciprocal of the
       condition number is less than machine epsilon, the routine may
       still attempt to compute X and error bounds, but it will return
       INFO = N+1 as a warning.

    4. The system of equations is solved for X using the factored form of
       A.

    5. Iterative refinement is applied to improve the computed solution
       matrix X and to calculate error bounds and backward error estimates
       for it.

Parameters:

FACT
        FACT is CHARACTER*1
        Specifies whether or not the factored form of the matrix
        A is supplied on entry.
        = 'F':  On entry, DF and EF contain the factored form of A.
                D, E, DF, and EF will not be modified.
        = 'N':  The matrix A will be copied to DF and EF and
                factored.
TRANS
        TRANS is CHARACTER*1
        Specifies the form of the system of equations:
        = 'N':  A * X = B       (No transpose)
        = 'T':  A**T * X = B    (Transpose)
        = 'C':  A**H * X = B    (Conjugate Transpose)
N
        N is INTEGER
        The order of the matrix A.  N >= 0.
NRHS
        NRHS is INTEGER
        The number of right hand sides, i.e., the number of columns
        of the matrices B and X.  NRHS >= 0.
D
        D is REAL array, dimension (N)
        The n diagonal elements of the tridiagonal matrix A.
E
        E is REAL array, dimension (N-1)
        The (n-1) subdiagonal elements of the tridiagonal matrix A.
        The (n-1) superdiagonal elements are implicitly stored in E.
DF
        DF is REAL array, dimension (N)
        If FACT = 'F', then DF is an input argument and on entry
        contains the n diagonal elements of the diagonal matrix D
        from the factorization A = P*L*D*L**T*Q**T.
        If FACT = 'N', then DF is an output argument and on exit
        contains the n diagonal elements of the diagonal matrix D
        from the factorization A = P*L*D*L**T*Q**T.
EF
        EF is REAL array, dimension (N-1)
        If FACT = 'F', then EF is an input argument and on entry
        contains the (n-1) subdiagonal elements of the unit
        bidiagonal factor L from the factorization A = P*L*D*L**T*Q**T.
        If FACT = 'N', then EF is an output argument and on exit
        contains the (n-1) subdiagonal elements of the unit
        bidiagonal factor L from the factorization A = P*L*D*L**T*Q**T.
B
        B is REAL array, dimension (LDB,NRHS)
        The N-by-NRHS right hand side matrix B.
LDB
        LDB is INTEGER
        The leading dimension of the array B.  LDB >= max(1,N).
X
        X is REAL array, dimension (LDX,NRHS)
        If INFO = 0 or INFO = N+1, the N-by-NRHS solution matrix X.
LDX
        LDX is INTEGER
        The leading dimension of the array X.  LDX >= max(1,N).
RCOND
        RCOND is REAL
        The reciprocal condition number of the matrix A.  If RCOND
        is less than the machine precision (in particular, if
        RCOND = 0), the matrix is singular to working precision.
        This condition is indicated by a return code of INFO > 0.
FERR
        FERR is REAL array, dimension (NRHS)
        The forward error bound for each solution vector
        X(j) (the j-th column of the solution matrix X).
        If XTRUE is the true solution corresponding to X(j), FERR(j)
        is an estimated upper bound for the magnitude of the largest
        element in (X(j) - XTRUE) divided by the magnitude of the
        largest element in X(j).
BERR
        BERR is REAL array, dimension (NRHS)
        The componentwise relative backward error of each solution
        vector X(j) (i.e., the smallest relative change in any
        element of A or B that makes X(j) an exact solution).
WORK
        WORK is REAL array, dimension (2*N)
INFO
        INFO is INTEGER
        = 0:  successful exit
        < 0:  if INFO = -i, the i-th argument had an illegal value
        > 0:  if INFO = i, and i is
              <= N:  the leading principal minor of order i of A
                     is not positive, so the factorization could not
                     be completed, and the solution has not been
                     computed. RCOND = 0 is returned.
              = N+1: U is nonsingular, but RCOND is less than machine
                     precision, meaning that the matrix is singular
                     to working precision.  Nevertheless, the
                     solution and error bounds are computed because
                     there are a number of situations where the
                     computed solution can be more accurate than the
                     value of RCOND would suggest.
