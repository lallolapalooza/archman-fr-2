PTHREAD_SPIN_UNLOCK(3P) Manuel du programmeur POSIX PTHREAD_SPIN_UNLOCK(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pthread_spin_unlock — déverrouiller un objet de verrouillage par rotation (spin lock)

SYNTAXE

#include <pthread.h>
int pthread_spin_unlock(pthread_spinlock_t *lock);

DESCRIPTION

La fonction pthread_spin_unlock() libère le verrouillage par rotation référencé par lock, qui a été verrouillé via les fonctions pthread_spin_lock() ou pthread_spin_trylock().

Les résultats ne sont pas définis si le verrou n'est pas détenu par le thread appelant.

S'il y a des threads en attente sur le verrou lorsque pthread_spin_unlock() est appelée, le verrou devient disponible et un thread en attente indéfini acquiert le verrou.

Les résultats ne sont pas définis si cette fonction est appelée avec un verrou par rotation de thread non initialisé.

VALEUR DE RETOUR

En cas de succès, la fonction pthread_spin_unlock() retourne zéro ; sinon, un numéro d'erreur est retourné pour indiquer l'erreur.

ERREURS

Cette fonction ne retournera pas de code d'erreur [EINTR].

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION APPLICATION

Aucune.

RATIONALE

Si une implémentation détecte que la valeur spécifiée par l'argument lock de pthread_spin_unlock() ne fait pas référence à un objet de verrouillage par rotation initialisé, il est recommandé que la fonction échoue et signale une erreur [EINVAL].

Si une implémentation détecte que la valeur spécifiée par l'argument lock de pthread_spin_unlock() fait référence à un objet de verrouillage par rotation pour lequel le thread actuel ne détient pas le verrou, il est recommandé que la fonction échoue et signale une erreur [EPERM].
