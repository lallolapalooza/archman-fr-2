PTHREAD_ATTR_GETSCHEDPARAM(3P) Manuel du programmeur POSIX PTHREAD_ATTR_GETSCHEDPARAM(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pthread_attr_getschedparam, pthread_attr_setschedparam — obtenir et définir l'attribut schedparam

SYNTAXE

#include <pthread.h>
int pthread_attr_getschedparam(const pthread_attr_t *restrict attr,
    struct sched_param *restrict param);
int pthread_attr_setschedparam(pthread_attr_t *restrict attr,
    const struct sched_param *restrict param);

DESCRIPTION

Les fonctions pthread_attr_getschedparam() et pthread_attr_setschedparam() obtiennent et définissent respectivement les attributs de paramètres de planification dans l'argument attr. Le contenu de la structure param est défini dans l'en-tête <sched.h>. Pour les politiques SCHED_FIFO et SCHED_RR, le seul membre requis de param est sched_priority.

Pour la politique SCHED_SPORADIC, les membres requis de la structure param sont sched_priority, sched_ss_low_priority, sched_ss_repl_period, sched_ss_init_budget, et sched_ss_max_repl. Le sched_ss_repl_period spécifié doit être supérieur ou égal au sched_ss_init_budget spécifié pour que la fonction réussisse ; sinon, la fonction échoue. La valeur de sched_ss_max_repl doit être comprise dans l'intervalle fermé [1,{SS_REPL_MAX}] pour que la fonction réussisse ; sinon, la fonction échoue. Le comportement est indéfini quant à savoir si les valeurs sched_ss_repl_period et sched_ss_init_budget sont stockées telles que fournies par cette fonction ou sont arrondies pour s'aligner sur la résolution de l'horloge utilisée.

Le comportement est indéfini si la valeur spécifiée par l'argument attr à pthread_attr_getschedparam() ou pthread_attr_setschedparam() ne fait pas référence à un objet d'attributs de thread initialisé.

VALEUR DE RETOUR

En cas de succès, les fonctions pthread_attr_getschedparam() et pthread_attr_setschedparam() retournent zéro ; sinon, un numéro d'erreur est retourné pour indiquer l'erreur.

ERREURS

La fonction pthread_attr_setschedparam() échoue si :

ENOTSUP
Une tentative a été faite pour définir l'attribut à une valeur non prise en charge.

La fonction pthread_attr_setschedparam() peut échouer si :

EINVAL
La valeur de param n'est pas valide.

Ces fonctions ne retournent pas le code d'erreur [EINTR].

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION APPLICATION

Une fois ces attributs définis, un thread peut être créé avec les attributs spécifiés à l'aide de pthread_create(). L'utilisation de ces routines n'affecte pas le thread en cours d'exécution.

RATIONALE

Si une implémentation détecte que la valeur spécifiée par l'argument attr à pthread_attr_getschedparam() ou pthread_attr_setschedparam() ne fait pas référence à un objet d'attributs de thread initialisé, il est recommandé que la fonction échoue et signale une erreur [EINVAL].
