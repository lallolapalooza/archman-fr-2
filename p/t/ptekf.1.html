PTEKF(1) Manuel des commandes générales PTEKF(1)

NOM

ptekf - Filtre Kanji pTeX-enc

SYNTAXE

ptekf [options] [--] fichier_entree1 [fichier_entree2 ...]

ptekf --help | --version

DESCRIPTION

ptekf est un utilitaire simple de conversion de codage de caractères pour les fichiers d'entrée/sortie des programmes de la famille pTeX. Cet utilitaire peut être utilisé pour vérifier les procédures de conversion de codage de caractères et de devinage de codage qui sont implémentées dans la famille pTeX, c'est-à-dire (e)(u)ptex, (u)pbibtex, mendex et autres.

OPTIONS

-j
Spécifie le codage de sortie ISO-2022-JP.
-s
Spécifie le codage de sortie Shift_JIS.
-e
Spécifie le codage de sortie EUC-JP.
-u
Spécifie le codage de sortie UTF-8.
-J
Spécifie le codage d'entrée ISO-2022-JP.
-S
Spécifie le codage d'entrée Shift_JIS.
-E
Spécifie le codage d'entrée EUC-JP.
-U
Spécifie le codage d'entrée UTF-8.
-g --guess
Devine le codage d'entrée (aucune conversion).
-G
Devine le codage d'entrée et sort vers stdout ou des fichiers.
-b --buffer
Sort le tampon interne sans conversion de code.
-v --version
Affiche le numéro de version.
-h --help
Affiche le message d'aide.
Le codage d'entrée/sortie par défaut dépend des paramètres de recherche de chemin PTEX_KANJI_ENC et guess_input_kanji_encoding.

VOIR AUSSI

eptex(1), euptex(1), pbibtex(1), upbibtex(1), mendex(1)
