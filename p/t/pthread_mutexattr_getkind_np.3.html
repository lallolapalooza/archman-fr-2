pthread_mutexattr_setkind_np(3) Manuel des fonctions de bibliothèque pthread_mutexattr_setkind_np(3)

NOM

pthread_mutexattr_setkind_np, pthread_mutexattr_getkind_np - attributs de création de mutex obsolètes

SYNTAXE

#include <pthread.h>
int pthread_mutexattr_setkind_np(pthread_mutexattr_t *attr, int kind);
int pthread_mutexattr_getkind_np(const pthread_mutexattr_t *attr,
                                 int *kind);

DESCRIPTION

Ces fonctions sont obsolètes, utilisez plutôt pthread_mutexattr_settype(3) et pthread_mutexattr_gettype(3).

VALEUR DE RETOUR

pthread_mutexattr_getkind_np() renvoie toujours 0.

pthread_mutexattr_setkind_np() renvoie 0 en cas de succès et un code d'erreur non nul en cas d'erreur.

ERREURS

En cas d'erreur, pthread_mutexattr_setkind_np() renvoie le code d'erreur suivant :

EINVAL
kind n'est ni PTHREAD_MUTEX_FAST_NP ni PTHREAD_MUTEX_RECURSIVE_NP ni PTHREAD_MUTEX_ERRORCHECK_NP.

VOIR AUSSI

pthread_mutexattr_settype(3), pthread_mutexattr_gettype(3).
