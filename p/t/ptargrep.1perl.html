NOM

ptargrep - Appliquer une correspondance de motif au contenu des fichiers dans une archive tar

SYNTAXE

ptargrep [options] <motif> <fichier tar> ...
Options :
 --basename|-b     ignorer les chemins de répertoire de l'archive
 --ignore-case|-i  effectuer une correspondance de motif insensible à la casse
 --list-only|-l    lister les noms de fichiers correspondants plutôt qu'extraire les correspondances
 --verbose|-v      écrire un message de débogage sur STDERR
 --help|-?         message d'aide détaillé

DESCRIPTION

Cet utilitaire vous permet d'appliquer une correspondance de motif au contenu des fichiers contenus dans une archive tar. Vous pourriez l'utiliser pour identifier tous les fichiers d'une archive qui contiennent des lignes correspondant au motif spécifié et soit imprimer les noms de chemins, soit extraire les fichiers.

Le motif sera utilisé comme une expression régulière Perl (par opposition à une simple expression régulière grep).

Plusieurs noms de fichiers d'archives tar peuvent être spécifiés - ils seront chacun traités à tour de rôle.

OPTIONS

--basename (alias -b)
Lors de l'extraction des fichiers correspondants, ignorer le chemin du répertoire de l'archive et écrire dans le répertoire courant en utilisant le nom de base du fichier de l'archive. Attention : si deux fichiers correspondants dans l'archive ont le même nom de base, le second fichier extrait écrasera le premier.
--ignore-case (alias -i)
Rendre la correspondance de motif insensible à la casse.
--list-only (alias -l)
Imprimer le nom de chemin de chaque fichier correspondant de l'archive sur STDOUT. Sans cette option, le comportement par défaut est d'extraire chaque fichier correspondant.
--verbose (alias -v)
Enregistrer les informations de débogage sur STDERR.
--help (alias -?)
Afficher cette documentation.
