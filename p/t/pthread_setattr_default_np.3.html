pthread_getattr_default_np(3) Manuel des fonctions de bibliothèque pthread_getattr_default_np(3)

NOM

pthread_getattr_default_np, pthread_setattr_default_np, - obtenir ou définir les attributs par défaut de création de thread

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#define _GNU_SOURCE             /* Voir feature_test_macros(7) */
#include <pthread.h>
int pthread_getattr_default_np(pthread_attr_t *attr);
int pthread_setattr_default_np(const pthread_attr_t *attr);

DESCRIPTION

La fonction pthread_setattr_default_np() définit les attributs par défaut utilisés pour la création d'un nouveau thread — c'est-à-dire, les attributs qui sont utilisés lorsque pthread_create(3) est appelé avec un deuxième argument qui est NULL. Les attributs par défaut sont définis à l'aide des attributs fournis dans *attr, un objet d'attributs de thread préalablement initialisé. Notez les détails suivants concernant l'objet d'attributs fourni :

•
Les paramètres d'attributs dans l'objet doivent être valides.
•
L'attribut adresse de pile ne doit pas être défini dans l'objet.
•
Définir l'attribut taille de pile à zéro signifie laisser la taille de pile par défaut inchangée.

La fonction pthread_getattr_default_np() initialise l'objet d'attributs de thread auquel pointe attr afin qu'il contienne les attributs par défaut utilisés pour la création de threads.

ERREURS

EINVAL
(pthread_setattr_default_np()) L'un des paramètres d'attributs dans attr est invalide, ou l'attribut d'adresse de pile est défini dans attr.
ENOMEM
(pthread_setattr_default_np()) Mémoire insuffisante.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_getattr_default_np (), pthread_setattr_default_np () Sécurité des threads MT-Safe

NORMES

GNU ; d'où le suffixe « _np » (non portable) dans leurs noms.

HISTORIQUE

glibc 2.18.

EXEMPLES

Le programme ci-dessous utilise pthread_getattr_default_np() pour récupérer les attributs par défaut de création de thread, puis affiche divers paramètres de l'objet d'attributs de thread retourné. En exécutant le programme, on obtient la sortie suivante :


$ ./a.out;
Taille de pile :          8388608
Taille de garde :          4096
Politique de planification :   SCHED_OTHER
Priorité de planification : 0
État d'abandon :       JOINABLE
Hériter du planificateur :   INHERIT

Source du programme

#define _GNU_SOURCE
#include <err.h>
#include <pthread.h>
#include <sched.h>
#include <stdio.h>
#include <stdlib.h>
static void
display_pthread_attr(pthread_attr_t *attr)
{
    int s;
    size_t stacksize;
    size_t guardsize;
    int policy;
    struct sched_param schedparam;
    int detachstate;
    int inheritsched;
    s = pthread_attr_getstacksize(attr, &stacksize);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getstacksize");
    printf("Taille de pile :          %zu\n", stacksize);
    s = pthread_attr_getguardsize(attr, &guardsize);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getguardsize");
    printf("Taille de garde :          %zu\n", guardsize);
    s = pthread_attr_getschedpolicy(attr, &policy);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getschedpolicy");
    printf("Politique de planification :   %s\n",
           (policy == SCHED_FIFO) ? "SCHED_FIFO" :
           (policy == SCHED_RR) ? "SCHED_RR" :
           (policy == SCHED_OTHER) ? "SCHED_OTHER" : "[unknown]");
    s = pthread_attr_getschedparam(attr, &schedparam);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getschedparam");
    printf("Priorité de planification : %d\n", schedparam.sched_priority);
    s = pthread_attr_getdetachstate(attr, &detachstate);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getdetachstate");
    printf("État d'abandon :       %s\n",
           (detachstate == PTHREAD_CREATE_DETACHED) ? "DETACHED" :
           (detachstate == PTHREAD_CREATE_JOINABLE) ? "JOINABLE" :
           "???");
    s = pthread_attr_getinheritsched(attr, &inheritsched);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getinheritsched");
    printf("Hériter du planificateur :   %s\n",
           (inheritsched == PTHREAD_INHERIT_SCHED) ? "INHERIT" :
           (inheritsched == PTHREAD_EXPLICIT_SCHED) ? "EXPLICIT" :
           "???");
}
int
main(void)
{
    int s;
    pthread_attr_t attr;
    s = pthread_getattr_default_np(&attr);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_getattr_default_np");
    display_pthread_attr(&attr);
    exit(EXIT_SUCCESS);
}
