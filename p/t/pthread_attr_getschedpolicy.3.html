pthread_setschedpolicy(3) Manuel des fonctions de bibliothèque pthread_setschedpolicy(3)

NOM

pthread_attr_setschedpolicy, pthread_attr_getschedpolicy - définir/obtenir l'attribut de politique d'ordonnancement dans l'objet d'attributs de thread

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <pthread.h>
int pthread_attr_setschedpolicy(pthread_attr_t *attr, int policy);
int pthread_attr_getschedpolicy(const pthread_attr_t *restrict attr,
                                int *restrict policy);

DESCRIPTION

La fonction pthread_attr_setschedpolicy() définit l'attribut de politique d'ordonnancement de l'objet d'attributs de thread auquel le pointeur attr fait référence, à la valeur spécifiée par policy. Cet attribut détermine la politique d'ordonnancement d'un thread créé en utilisant l'objet d'attributs de thread attr.

Les valeurs prises en charge pour policy sont SCHED_FIFO, SCHED_RR et SCHED_OTHER, avec les sémantiques décrites dans sched(7).

La fonction pthread_attr_getschedpolicy() renvoie l'attribut de politique d'ordonnancement de l'objet d'attributs de thread attr dans le tampon pointé par policy.

Pour que le réglage de politique effectué par pthread_attr_setschedpolicy() ait effet lors de l'appel à pthread_create(3), l'appelant doit utiliser pthread_attr_setinheritsched(3) pour définir l'attribut hériter-ordonnanceur de l'objet d'attributs attr à PTHREAD_EXPLICIT_SCHED.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent 0 ; en cas d'erreur, elles retournent un numéro d'erreur non nul.

ERREURS

pthread_attr_setschedpolicy() peut échouer avec l'erreur suivante :

EINVAL
Valeur invalide dans policy.

POSIX.1 documente également une erreur optionnelle ENOTSUP ("une tentative a été faite pour définir l'attribut sur une valeur non prise en charge") pour pthread_attr_setschedpolicy().

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).
