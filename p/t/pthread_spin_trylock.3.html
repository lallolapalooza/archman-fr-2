pthread_spin_lock(3) Manuel des fonctions de bibliothèque pthread_spin_lock(3)

NOM

pthread_spin_lock, pthread_spin_trylock, pthread_spin_unlock - verrouiller et déverrouiller un verrou à rotation

BIBLIOTHÈQUE

Bibliothèque de threads POSIX (libpthread, -lpthread)

SYNTAXE

#include <pthread.h>
int pthread_spin_lock(pthread_spinlock_t *lock);
int pthread_spin_trylock(pthread_spinlock_t *lock);
int pthread_spin_unlock(pthread_spinlock_t *lock);
Exigences concernant les macros de test de fonctionnalités dans glibc (voir feature_test_macros(7)):

pthread_spin_lock(), pthread_spin_trylock():

    _POSIX_C_SOURCE >= 200112L

DESCRIPTION

La fonction pthread_spin_lock() verrouille le verrou à rotation référencé par lock. Si le verrou à rotation est actuellement déverrouillé, le thread appelant acquiert le verrou immédiatement. Si le verrou à rotation est actuellement verrouillé par un autre thread, le thread appelant tourne en rond (spin), testant le verrou jusqu'à ce qu'il soit disponible, moment auquel le thread appelant acquiert le verrou.

Appeler pthread_spin_lock() sur un verrou qui est déjà détenu par l'appelant ou sur un verrou qui n'a pas été initialisé avec pthread_spin_init(3) entraîne un comportement indéfini.

La fonction pthread_spin_trylock() est similaire à pthread_spin_lock(), sauf que si le verrou à rotation référencé par lock est actuellement verrouillé, alors, au lieu de tourner en rond, l'appel retourne immédiatement avec l'erreur EBUSY.

La fonction pthread_spin_unlock() déverrouille le verrou à rotation référencé par lock. Si des threads tournent en rond sur le verrou, l'un de ces threads acquerra alors le verrou.

Appeler pthread_spin_unlock() sur un verrou qui n'est pas détenu par l'appelant entraîne un comportement indéfini.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent zéro. En cas d'échec, elles retournent un numéro d'erreur.

ERREURS

pthread_spin_lock() peut échouer avec les erreurs suivantes :

EDEADLOCK
Le système a détecté une condition de interblocage.

pthread_spin_trylock() échoue avec les erreurs suivantes :

EBUSY
Le verrou à rotation est actuellement verrouillé par un autre thread.

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.2. POSIX.1-2001.

CAVEATS

Appliquer l'une des fonctions décrites sur cette page à un verrou à rotation non initialisé entraîne un comportement indéfini.

Lisez attentivement les NOTES dans pthread_spin_init(3).

VOIR AUSSI

pthread_spin_destroy(3), pthread_spin_init(3), pthreads(7)
