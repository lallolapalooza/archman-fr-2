NOM

pt-fingerprint - Convertit les requêtes en empreintes digitales.

SYNTAXE

Utilisation: pt-fingerprint [OPTIONS] [FICHIERS]

pt-fingerprint convertit les requêtes en empreintes digitales. Avec l'option --query, il convertit la valeur de l'option en empreinte digitale. Sans option, il traite les arguments de la ligne de commande comme des FICHIERS et lit et convertit les requêtes séparées par des points-virgules à partir des FICHIERS. Lorsque FICHIER est -, il lit l'entrée standard.

Convertir une seule requête:

pt-fingerprint --query "select a, b, c from users where id = 500"

Convertir un fichier plein de requêtes:

pt-fingerprint /chemin/vers/fichier.txt

  • Examiner les "BOGUES" connus de l'outil
  • Tester l'outil sur un serveur non-production
  • Sauvegarder votre serveur de production et vérifier les sauvegardes

DESCRIPTION

Une empreinte digitale de requête est la forme abstraite d'une requête, qui permet de regrouper des requêtes similaires. L'abstraction d'une requête supprime les valeurs littérales, normalise les espaces blancs, etc. Par exemple, considérez ces deux requêtes:

SELECT name, password FROM user WHERE id='12823';
select name,   password from user
   where id=5;

Ces deux requêtes seront traduites en l'empreinte suivante:

select name, password from user where id=?

Une fois l'empreinte digitale de la requête connue, nous pouvons alors parler d'une requête comme si elle représentait toutes les requêtes similaires.

L'empreinte digitale de requête prend en charge un grand nombre de cas spéciaux, qui se sont avérés nécessaires dans le monde réel. Par exemple, une liste IN avec 5 littéraux est en réalité équivalente à une avec 4 littéraux, donc les listes de littéraux sont réduites à un seul. Si vous souhaitez en savoir plus sur comment et pourquoi tous ces cas sont gérés, veuillez examiner les cas de test dans le dépôt Github. Si vous trouvez quelque chose qui n'est pas correctement traité par l'empreinte digitale, veuillez soumettre un rapport de bogue avec un cas de test reproductible. Voici une liste des transformations lors de la génération d'empreintes digitales, qui pourrait ne pas être exhaustive:

  • Regrouper toutes les requêtes SELECT de mysqldump, même si elles portent sur différentes tables. Idem pour toutes les requêtes de checksum de pt-table-checksum.
  • Raccourcir les instructions INSERT à valeurs multiples en une seule liste VALUES().
  • Supprimer les commentaires.
  • Abstraire les bases de données dans les instructions USE, de sorte que toutes les instructions USE soient regroupées.
  • Remplacer tous les littéraux, tels que les chaînes entre guillemets. Pour des raisons d'efficacité, le code qui remplace les nombres littéraux est quelque peu non sélectif et peut remplacer certaines choses comme des nombres alors qu'elles ne le sont pas réellement. Les littéraux hexadécimaux sont également remplacés. NULL est traité comme un littéral. Les nombres intégrés dans les identifiants sont également remplacés, de sorte que les tables ayant des noms similaires seront traduites en empreintes digitales identiques (par exemple, users_2009 et users_2010 auront des empreintes digitales identiques).
  • Réduire tous les espaces blancs en un seul espace.
  • Mettre toute la requête en minuscules.
  • Remplacer tous les littéraux à l'intérieur des listes IN() et VALUES() par un seul espace réservé, quelle que soit la cardinalité.
  • Réduire les requêtes UNION multiples identiques en une seule.

OPTIONS

Cet outil accepte des arguments supplémentaires en ligne de commande. Reportez-vous à la "SYNTAXE" et aux informations d'utilisation pour plus de détails.

--config
type: Tableau

Lire cette liste de fichiers de configuration séparés par des virgules; si spécifié, cela doit être la première option sur la ligne de commande.

--help
Afficher l'aide et quitter.
--match-embedded-numbers
Fait correspondre les nombres intégrés dans les mots et les remplace par des valeurs uniques. Cette option rend l'outil plus prudent dans la mise en correspondance des nombres afin que les mots contenant des nombres, comme "catch22", soient mis en correspondance et remplacés par un seul espace réservé "?". Sinon, le modèle de correspondance des nombres par défaut remplacera "catch22" par "catch?".

Ceci est utile si les noms de bases de données ou de tables contiennent des nombres.

--match-md5-checksums
Fait correspondre les sommes de contrôle MD5 et les remplace par des valeurs uniques. Cette option rend l'outil plus prudent dans la mise en correspondance des nombres afin que les sommes de contrôle MD5 comme "fbc5e685a5d3d45aa1d0347fdb7c4d35" soient mises en correspondance et remplacées par un seul espace réservé "?". Sinon, le modèle de correspondance des nombres par défaut remplacera "fbc5e685a5d3d45aa1d0347fdb7c4d35" par "fbc?".
--query
type: chaîne

La requête à convertir en empreinte digitale.

--version
Afficher la version et quitter.

ENVIRONNEMENT

La variable d'environnement "PTDEBUG" active la sortie de débogage détaillée sur STDERR. Pour activer le débogage et capturer toute la sortie dans un fichier, exécutez l'outil comme suit:

PTDEBUG=1 pt-fingerprint ... > FICHIER 2>&1

Soyez prudent : la sortie de débogage est volumineuse et peut générer plusieurs mégaoctets de sortie.

ATTENTION

L'utilisation de <PTDEBUG> peut exposer des mots de passe. Lorsque le débogage est activé, tous les paramètres de la ligne de commande sont affichés dans la sortie.

EXIGENCES SYSTÈME
