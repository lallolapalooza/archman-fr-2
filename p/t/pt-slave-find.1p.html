NOM

pt-replica-find - Trouver et afficher l'arbre hiérarchique de réplication des réplicas MySQL.

SYNTAXE

Utilisation : pt-replica-find [OPTIONS] [DSN]

pt-replica-find trouve et affiche une vue hiérarchique des réplicas MySQL.

Exemples :

pt-replica-find --host source-host

RISQUES

Percona Toolkit est mature, éprouvé sur le terrain et bien testé, mais tous les outils de base de données peuvent présenter un risque pour le système et le serveur de base de données. Avant d'utiliser cet outil, veuillez :

  • Lire la documentation de l'outil
  • Examiner les « BUGS » connus de l'outil
  • Tester l'outil sur un serveur non-production
  • Sauvegarder votre serveur de production et vérifier les sauvegardes

DESCRIPTION

pt-replica-find se connecte à une source de réplication MySQL et trouve ses réplicas. Actuellement, la seule chose qu'il puisse faire est d'afficher une vue arborescente de la hiérarchie de réplication.

L'hôte source peut être spécifié en utilisant l'une des deux méthodes. La première méthode consiste à utiliser les options de ligne de commande standard liées à la connexion : « --defaults-file », « --password », « --host », « --port », « --socket » ou « --user ».

La seconde méthode pour spécifier l'hôte source est un DSN. Un DSN est une syntaxe spéciale qui peut être soit simplement un nom d'hôte (comme "serveur.domaine.com" ou 1.2.3.4), soit une chaîne "clé=valeur,clé=valeur". Les clés sont d'une seule lettre :

CLÉ SIGNIFICATION
=== =============
h   Se connecter à l'hôte
P   Port de connexion
S   Fichier socket pour la connexion
u   Utilisateur pour la connexion si ce n'est pas l'utilisateur actuel
p   Mot de passe à utiliser lors de la connexion
F   Lire uniquement les options par défaut du fichier donné

"pt-replica-find" lit tous les fichiers d'options MySQL normaux, tels que ~/.my.cnf, donc vous n'aurez peut-être pas besoin de spécifier l'utilisateur, le mot de passe et d'autres options courantes.

STATUT DE SORTIE

Un statut de sortie de 0 (parfois appelé valeur de retour ou code de retour) indique le succès. Toute autre valeur représente le statut de sortie du processus Perl lui-même.

OPTIONS

Cet outil accepte des arguments de ligne de commande supplémentaires. Reportez-vous à la « SYNTAXE » et aux informations d'utilisation pour plus de détails.

--ask-pass
Demander un mot de passe lors de la connexion à MySQL.
--charset
forme courte : -A ; type : chaîne

Jeu de caractères par défaut. Si la valeur est utf8, définit le mode binaire de Perl sur STDOUT en utf8, passe l'option mysql_enable_utf8 à DBD::mysql et exécute SET NAMES UTF8 après la connexion à MySQL. Toute autre valeur définit le mode binaire sur STDOUT sans la couche utf8 et exécute SET NAMES après la connexion à MySQL.

--config
type : Tableau

Lire cette liste de fichiers de configuration séparés par des virgules ; si spécifié, cela doit être la première option sur la ligne de commande.

--database
type : chaîne ; forme courte : -D

Base de données à utiliser.

--defaults-file
forme courte : -F ; type : chaîne

Lire uniquement les options mysql du fichier donné. Vous devez spécifier un chemin d'accès absolu.

--help
Afficher l'aide et quitter.
--host
forme courte : -h ; type : chaîne

Se connecter à l'hôte.

--password
forme courte : -p ; type : chaîne

Mot de passe à utiliser lors de la connexion. Si le mot de passe contient des virgules, elles doivent être échappées avec une barre oblique inverse : "exam\,ple"

--pid
type : chaîne

Créer le fichier PID donné. L'outil ne démarrera pas si le fichier PID existe déjà et que le PID qu'il contient est différent du PID actuel. Cependant, si le fichier PID existe et que le PID qu'il contient n'est plus en cours d'exécution, l'outil remplacera le fichier PID par le PID actuel. Le fichier PID est supprimé automatiquement lorsque l'outil se termine.

--port
forme courte : -P ; type : entier

Numéro de port à utiliser pour la connexion.

--recurse
type : entier

Nombre de niveaux à parcourir dans la hiérarchie. Par défaut, c'est infini.

Voir « --recursion-method ».

--recursion-method
type : tableau ; par défaut : processlist,hosts

Méthode de récursion préférée utilisée pour trouver les réplicas.

Les méthodes possibles sont :

MÉTHODE      UTILISE
===========  ==================
processlist  SHOW PROCESSLIST
hosts        SHOW REPLICAS (SHOW SLAVE HOSTS avant MySQL 8.1)
none         Ne pas trouver les réplicas

La méthode processlist est préférée car SHOW REPLICAS n'est pas fiable. Cependant, la méthode hosts est requise si le serveur utilise un port non standard (pas 3306). Normalement, pt-replica-find fait la bonne chose et trouve les réplicas, mais vous pouvez spécifier une méthode préférée et elle sera utilisée en premier. Si elle ne trouve aucun réplica, les autres méthodes seront essayées.

--report-format
type : chaîne ; par défaut : summary

Définit les informations sur les réplicas à imprimer. Le format du rapport peut être l'un des suivants :

  • hostname

    Imprime uniquement le nom d'hôte des réplicas. Cela ressemble à :

    127.0.0.1:12345
+- 127.0.0.1:12346
   +- 127.0.0.1:12347
  • summary

    Imprime un résumé des paramètres de chaque réplica. Ce rapport affiche plus d'informations sur chaque réplica, comme suit :

    127.0.0.1:12345
Version         5.1.34-log
Server ID       12345
Uptime          04:56 (démarré le 2010-06-17T11:21:22)
Réplication     N'est pas un réplica, a 1 réplicas connectés
Filtres
Journalisation binaire  STATEMENT
Statut esclave
Mode esclave      STRICT
Auto-incrémentation  incrément 1, décalage 1
+- 127.0.0.1:12346
   Version         5.1.34-log
   Server ID       12346
   Uptime          04:54 (démarré le 2010-06-17T11:21:24)
   Réplication     Est un réplica, a 1 réplicas connectés
   Filtres
   Journalisation binaire  STATEMENT
   Statut esclave    0 secondes de retard, en cours, aucune erreur
   Mode esclave      STRICT
   Auto-incrémentation  incrément 1, décalage 1
--resolve-address
Résoudre l'adresse IP en nom d'hôte. Le rapport affichera l'adresse IP et le nom d'hôte.

Exemple :

10.10.7.14 (dbase1.sample.net)

Peut ralentir l'exécution de quelques secondes.

--slave-user
type : chaîne

Cette option est obsolète et sera supprimée dans les futures versions. Utilisez « --replica-user » à la place.

--slave-password
type : chaîne

Cette option est obsolète et sera supprimée dans les futures versions. Utilisez « --replica-password » à la place.

--replica-user
type : chaîne

Définit l'utilisateur à utiliser pour se connecter aux réplicas. Ce paramètre vous permet d'avoir un utilisateur différent avec moins de privilèges sur les réplicas, mais cet utilisateur doit exister sur tous les réplicas.

--replica-password
type : chaîne

Définit le mot de passe à utiliser pour se connecter aux réplicas. Il peut être utilisé avec --replica-user et le mot de passe de l'utilisateur doit être le même sur tous les réplicas.

--set-vars
type : Tableau

Définit les variables MySQL dans cette liste de paires "variable=valeur" séparées par des virgules.

Par défaut, l'outil définit :

wait_timeout=10000

Les variables spécifiées sur la ligne de commande remplacent celles-ci

OPTIONS

These are the command-line options available for pt-replica-find.

--ask-pass
Prompt for a password when connecting to MySQL. This option is supported only if the DBD::mysql Perl module is newer than version 1.22.
--charset
short form: -A; type: string

Use charset when connecting to MySQL.

--config-file
short form: -c; type: string; default: ~/.my.cnf

Read these connection parameters from the given file. The file is a standard MySQL option file. See mysql_config_editor(1) for more information.

--data-source-name
short form: -D; type: string

The DSN to use when connecting to MySQL. This is a string of comma-separated MySQL options, like "host=db.example.com,user=foo". See "DSN OPTIONS".

--defaults-file
short form: -f; type: string; default: ~/.my.cnf

Only read default options from the given file. There is no per-tool default; when you don't specify this option, Percona Toolkit reads the default options from the standard MySQL option files. See mysql(1) for more information.

--defaults
type: string

Overrides the default value for the specified variable. For example, specifying "--set-vars wait_timeout=500" overrides the default value of 10000.

The tool prints a warning and continues if a variable cannot be set.

--socket
short form: -S; type: string

Socket file to use for connection.

--user
short form: -u; type: string

User for login if not current user.

--version
Show version and exit.

DSN OPTIONS

These DSN options are used to create a DSN. Each option is given like "option=value". The options are case-sensitive, so P and p are not the same option. There cannot be whitespace before or after the "=" and if the value contains whitespace it must be quoted. DSN options are comma-separated. See the percona-toolkit manpage for full details.

  • A

    dsn: charset; copy: yes

    Default character set.

  • D

    dsn: database; copy: yes

    Default database.

  • F

    dsn: mysql_read_default_file; copy: yes

    Only read default options from the given file

  • h

    dsn: host; copy: yes

    Connect to host.

  • p

    dsn: password; copy: yes

    Password to use when connecting. If password contains commas they must be escaped with a backslash: "exam\,ple"

  • P

    dsn: port; copy: yes

    Port number to use for connection.

  • S

    dsn: mysql_socket; copy: yes

    Socket file to use for connection.

  • u

    dsn: user; copy: yes

    User for login if not current user.

  • s

    dsn: mysql_ssl; copy: yes

    Create SSL connection

ENVIRONMENT

The environment variable "PTDEBUG" enables verbose debugging output to STDERR. To enable debugging and capture all output to a file, run the tool like:

PTDEBUG=1 pt-replica-find ... > FILE 2>&1

Be careful: debugging output is voluminous and can generate several megabytes of output.

ATTENTION

Using <PTDEBUG> might expose passwords. When debug is enabled, all command line parameters are shown in the output.

SYSTEM REQUIREMENTS

You need Perl, DBI, DBD::mysql, and some core packages that ought to be installed in any reasonably new version of Perl.
