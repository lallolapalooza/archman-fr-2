PTHREAD_ATTR_GETSTACK(3P) Manuel du programmeur POSIX PTHREAD_ATTR_GETSTACK(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pthread_attr_getstack, pthread_attr_setstack — obtenir et définir les attributs de la pile

SYNTAXE

#include <pthread.h>
int pthread_attr_getstack(const pthread_attr_t *restrict attr,
    void **restrict stackaddr, size_t *restrict stacksize);
int pthread_attr_setstack(pthread_attr_t *attr, void *stackaddr,
    size_t stacksize);

DESCRIPTION

Les fonctions pthread_attr_getstack() et pthread_attr_setstack() obtiennent et définissent respectivement les attributs de pile de création de thread stackaddr et stacksize dans l'objet attr.

Les attributs de pile spécifient la zone de stockage à utiliser pour la pile du thread créé. La base (octet le plus bas adressable) du stockage est stackaddr, et la taille du stockage est stacksize octets. stacksize doit être au moins {PTHREAD_STACK_MIN}. La fonction pthread_attr_setstack() peut échouer avec [EINVAL] si stackaddr ne respecte pas les exigences d'alignement définies par l'implémentation. Toutes les pages dans la pile décrite par stackaddr et stacksize doivent être lisibles et inscriptibles par le thread.

Si la fonction pthread_attr_getstack() est appelée avant que l'attribut stackaddr n'ait été défini, le comportement est indéterminé.

Le comportement est indéfini si la valeur spécifiée par l'argument attr de pthread_attr_getstack() ou pthread_attr_setstack() ne fait pas référence à un objet d'attributs de thread initialisé.

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient une valeur de 0 ; sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

La fonction pthread_attr_getstack() stocke les valeurs des attributs de pile dans stackaddr et stacksize en cas de succès.

ERREURS

La fonction pthread_attr_setstack() échoue si :

EINVAL
La valeur de stacksize est inférieure à {PTHREAD_STACK_MIN} ou dépasse une limite définie par l'implémentation.

La fonction pthread_attr_setstack() peut échouer si :

EINVAL
La valeur de stackaddr n'a pas le bon alignement pour être utilisée comme pile, ou ((char *)stackaddr + stacksize) manque le bon alignement.
EACCES
Les pages de pile décrites par stackaddr et stacksize ne sont pas à la fois lisibles et inscriptibles par le thread.

Ces fonctions ne renvoient pas de code d'erreur [EINTR].

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION APPLICATIVE

Ces fonctions conviennent à une utilisation par des applications dans un environnement où la pile d'un thread doit être placée dans une région mémoire particulière.

Bien qu'il puisse sembler qu'une application puisse détecter un débordement de pile en fournissant une page protégée en dehors de la région de pile spécifiée, cela ne peut pas être fait de manière portable. Les implémentations sont libres de placer le pointeur de pile initial du thread n'importe où dans la région spécifiée pour tenir compte du comportement du pointeur de pile de la machine et des exigences d'allocation. De plus, sur certaines architectures, comme IA-64, un « débordement » peut signifier que deux pointeurs de pile distincts alloués dans la région se chevauchent quelque part au milieu de la région.

Après un appel réussi à pthread_attr_setstack(), la zone de stockage spécifiée par le paramètre stackaddr est sous le contrôle de l'implémentation, comme décrit dans Section 2.9.8, Utilisation des piles de threads gérées par l'application.

La spécification de l'attribut stackaddr présente plusieurs ambiguïtés qui rendent l'utilisation portable de ces fonctions impossible. Par exemple, la norme autorise les implémentations à imposer des exigences d'alignement arbitraires sur stackaddr. Les applications ne peuvent pas supposer qu'un tampon obtenu à partir de malloc() est correctement aligné. Notez que, bien que la valeur stacksize passée à pthread_attr_setstack() doive satisfaire aux exigences d'alignement, il en va de même pour pthread_attr_setstacksize(), où l'implémentation doit augmenter la taille spécifiée si nécessaire pour obtenir le bon alignement.

RATIONALE

Si une implémentation détecte que la valeur spécifiée par l'argument attr de pthread_attr_getstack() ou pthread_attr_setstack() ne fait pas référence à un objet d'attributs de thread initialisé, il est recommandé que la fonction échoue et signale une erreur [EINVAL].

pthread_attr_getstack(3)

NOM

pthread_attr_getstack - obtenir les attributs de pile d'un thread

SYNOPSIS

#include <pthread.h>

int pthread_attr_getstack(const pthread_attr_t *attr, void **stackaddr, size_t *stacksize);

DESCRIPTION

La fonction pthread_attr_getstack récupère les attributs de pile associés à un objet pthread_attr_t donné.

Les attributs de pile sont constitués de l'adresse de début de la pile et de la taille de la pile.

L'argument attr est un pointeur vers l'objet pthread_attr_t dont les attributs de pile doivent être récupérés.

L'argument stackaddr est un pointeur vers une variable de type void * dans laquelle l'adresse de début de la pile sera stockée.

L'argument stacksize est un pointeur vers une variable de type size_t dans laquelle la taille de la pile sera stockée.

VALEUR DE RETOUR

En cas de succès, pthread_attr_getstack renvoie 0. En cas d'erreur, elle renvoie un numéro d'erreur positif.

ERREURS

La fonction pthread_attr_getstack peut échouer avec les erreurs suivantes :

EINVAL
attr ne pointe pas vers un objet pthread_attr_t valide, ou stackaddr ou stacksize sont des pointeurs nuls.

EXEMPLES

Voici un exemple d'utilisation de pthread_attr_getstack :

#include <stdio.h>
                    #include <pthread.h>

                    int main() {
                        pthread_attr_t attr;
                        void *stackaddr;
                        size_t stacksize;

                        // Initialiser les attributs du thread
                        pthread_attr_init(&attr);

                        // Obtenir les attributs de pile
                        if (pthread_attr_getstack(&attr, &stackaddr, &stacksize) != 0) {
                            perror("pthread_attr_getstack");
                            return 1;
                        }

                        printf("Adresse de pile: %p\n", stackaddr);
                        printf("Taille de pile: %zu octets\n", stacksize);

                        // Nettoyer les attributs du thread
                        pthread_attr_destroy(&attr);

                        return 0;
                    }

UTILISATION DE L'APPLICATION

La fonction pthread_attr_getstack est généralement utilisée pour obtenir des informations sur les attributs de pile par défaut ou configurés d'un thread. Elle est utile lorsque vous avez besoin de connaître la taille ou l'adresse de la pile d'un thread avant de le créer ou pour des raisons de débogage.

EXPLICATION

La pile d'un thread est une zone de mémoire allouée pour stocker les informations d'exécution du thread, telles que les variables locales, les paramètres de fonction et les adresses de retour. La fonction pthread_attr_getstack permet d'inspecter ces paramètres.

ORIENTATIONS FUTURES

Pas de directions futures spécifiées pour cette fonction.

VOIR AUSSI
