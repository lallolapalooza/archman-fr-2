NOM

pt-sift - Navigue dans les fichiers créés par pt-stalk.

SYNOPIS

Utilisation : pt-sift FICHIER|PREFIXE|RÉPERTOIRE

pt-sift navigue dans les fichiers créés par pt-stalk. Si aucune option n'est donnée, l'outil navigue dans tous les fichiers pt-stalk du répertoire "/var/lib/pt-stalk" si ce répertoire existe, sinon le répertoire de travail actuel est utilisé. Si un FICHIER est donné, l'outil navigue dans les fichiers ayant le même préfixe dans le répertoire du fichier donné. Si un PREFIXE est donné, l'outil navigue dans "/var/lib/pt-stalk" (ou le répertoire de travail actuel) avec le même préfixe. Si un RÉPERTOIRE est donné, l'outil navigue dans tous les fichiers pt-stalk qu'il contient.

RISQUES

Percona Toolkit est mature, éprouvé en production et bien testé, mais tous les outils de base de données peuvent présenter un risque pour le système et le serveur de base de données. Avant d'utiliser cet outil, veuillez :

  • Lire la documentation de l'outil
  • Examiner les "BOGUES" connus de l'outil
  • Tester l'outil sur un serveur non-production
  • Sauvegarder votre serveur de production et vérifier les sauvegardes

DESCRIPTION

pt-sift télécharge d'autres outils dont il pourrait avoir besoin, tels que pt-diskstats, puis crée une liste des préfixes d'horodatage uniques de tous les fichiers dans le répertoire, tels qu'écrits par l'outil pt-stalk. Si l'utilisateur a spécifié un horodatage sur la ligne de commande, il commence par cet échantillon de données ; sinon, il commence par afficher une liste des horodatages et invite à une sélection. Par la suite, il affiche un résumé de l'échantillon sélectionné, et l'utilisateur peut naviguer et inspecter à l'aide de frappes au clavier. Les commandes de frappe au clavier que vous pouvez utiliser sont les suivantes :

  • d

    Définit l'action pour démarrer l'outil pt-diskstats sur les statistiques de performance du disque de l'échantillon.

  • i

    Définit l'action pour visualiser le premier échantillon de SHOW STATUS dans less.

  • m

    Affiche les 4 premiers échantillons de compteurs SHOW STATUS côte à côte avec l'outil pt-mext.

  • n

    Résume le premier échantillon de données netstat de deux manières : par hôte d'origine, et par état de connexion.

  • j

    Sélectionne le prochain horodatage comme échantillon actif.

  • k

    Sélectionne l'horodatage précédent comme échantillon actif.

  • q

    Quitte le programme.

  • 1

    Définit l'action pour chaque échantillon sur la valeur par défaut, qui consiste à afficher un résumé de l'échantillon.

  • Définit l'action pour simplement lister les fichiers de l'échantillon.
  • *

    Définit l'action pour visualiser tous les fichiers de l'échantillon dans le programme less.

OPTIONS

--help
Affiche l'aide et quitte.
--version
Affiche la version et quitte.

ENVIRONNEMENT

Cet outil n'utilise aucune variable d'environnement.

EXIGENCES SYSTÈME

Cet outil nécessite Bash v3 et les programmes suivants : pt-diskstats, pt-pmp, pt-mext et pt-align. Si ces programmes ne sont pas dans votre PATH, ils seront téléchargés depuis Internet si curl est disponible.

BOGUES

Pour une liste des bogues connus, voir https://jira.percona.com/projects/PT/issues.

Veuillez signaler les bogues à https://jira.percona.com/projects/PT. Incluez les informations suivantes dans votre rapport de bogue :

  • Commande complète utilisée pour exécuter l'outil
  • "--version" de l'outil
  • Version de MySQL de tous les serveurs impliqués
  • Sortie de l'outil, y compris STDERR
  • Fichiers d'entrée (fichiers journaux/dump/configuration, etc.)

Si possible, incluez la sortie de débogage en exécutant l'outil avec "PTDEBUG" ; voir "ENVIRONNEMENT".

ATTENTION

L'utilisation de <PTDEBUG> peut exposer des mots de passe. Lorsque le débogage est activé, tous les paramètres de la ligne de commande sont affichés dans la sortie.
