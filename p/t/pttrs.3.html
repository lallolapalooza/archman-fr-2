sous-routine cpttrs (character uplo, integer n, integer nrhs, real, dimension( * ) d, complex, dimension( * ) e, complex, dimension( ldb, * ) b, integer ldb, integer info)

CPTTRS

Objectif :

!>
!> CPTTRS résout un système tridiagonal de la forme
!>    A * X = B
!> en utilisant la factorisation A = U**H*D*U ou A = L*D*L**H calculée par CPTTRF.
!> D est une matrice diagonale spécifiée dans le vecteur D, U (ou L) est une matrice
!> bidiagonale unitaire dont la superdiagonale (sous-diagonale) est spécifiée dans
!> le vecteur E, et X et B sont des matrices N par NRHS.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie la forme de la factorisation et si le vecteur E est la
!>          superdiagonale du facteur bidiagonal supérieur U ou la sous-diagonale
!>          du facteur bidiagonal inférieur L.
!>          = 'U' :  A = U**H*D*U, E est la superdiagonale de U
!>          = 'L' :  A = L*D*L**H, E est la sous-diagonale de L
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice tridiagonale A.  N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de membres de droite, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

D

!>          D est un tableau REAL de dimension (N)
!>          Les n éléments diagonaux de la matrice diagonale D de la
!>          factorisation A = U**H*D*U ou A = L*D*L**H.
!>

E

!>          E est un tableau COMPLEX de dimension (N-1)
!>          Si UPLO = 'U', les (n-1) éléments superdiagonaux du facteur
!>          bidiagonal unitaire U de la factorisation A = U**H*D*U.
!>          Si UPLO = 'L', les (n-1) éléments sous-diagonaux du facteur
!>          bidiagonal unitaire L de la factorisation A = L*D*L**H.
!>

B

!>          B est un tableau COMPLEX de dimension (LDB,NRHS)
!>          À l'entrée, les vecteurs de membre de droite B pour le système d'équations
!>          linéaires.
!>          À la sortie, les vecteurs solution, X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès
!>          < 0 : si INFO = -k, le k-ième argument était illégal
!>

pttrs — solves a tridiagonal system of the form A*X = B

Detailed Description

This routine uses the L*D*L**T or U**H*D*U factorization of a tridiagonal matrix A computed by DPPTTRF to solve the system of equations A*X = B.

subroutine spttrs (character uplo, integer n, integer nrhs, real, dimension( * ) d, real, dimension( * ) e, real, dimension( ldb, * ) b, integer ldb, integer info)

SPTTTR

Purpose:

!>
!> SPTTRS solves a tridiagonal system of the form
!>    A * X = B
!> using the factorization A = U**T *D* U or A = L*D*L**T computed by SPTTRF.
!> D is a diagonal matrix specified in the vector D, U (or L) is a unit
!> bidiagonal matrix whose superdiagonal (subdiagonal) is specified in
!> the vector E, and X and B are N by NRHS matrices.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          Specifies the form of the factorization and whether the
!>          vector E is the superdiagonal of the upper bidiagonal factor
!>          U or the subdiagonal of the lower bidiagonal factor L.
!>          = 'U':  A = U**T *D*U, E is the superdiagonal of U
!>          = 'L':  A = L*D*L**T, E is the subdiagonal of L
!>

N

!>          N is INTEGER
!>          The order of the tridiagonal matrix A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrix B.  NRHS >= 0.
!>

D

!>          D is REAL array, dimension (N)
!>          The n diagonal elements of the diagonal matrix D from the
!>          factorization A = U**T *D*U or A = L*D*L**T.
!>

E

!>          E is REAL array, dimension (N-1)
!>          If UPLO = 'U', the (N-1) superdiagonal elements of the unit
!>          bidiagonal factor U from the factorization A = U**T*D*U.
!>          If UPLO = 'L', the (N-1) subdiagonal elements of the unit
!>          bidiagonal factor L from the factorization A = L*D*L**T.
!>

B

!>          B is REAL array, dimension (LDB,NRHS)
!>          On entry, the right hand side vectors B for the system of
!>          linear equations.
!>          On exit, the solution vectors, X.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -k, the k-th argument had an illegal value
!>
