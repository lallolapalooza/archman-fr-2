pthread_attr_setstack(3) Manuel des fonctions de bibliothèque pthread_attr_setstack(3)

NOM

pthread_attr_setstack, pthread_attr_getstack - définir/obtenir les attributs de pile dans un objet d'attributs de thread

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <pthread.h>
int pthread_attr_setstack(pthread_attr_t *attr,
                          void *stackaddr,
                          size_t stacksize);
int pthread_attr_getstack(const pthread_attr_t *restrict attr,
                          void **restrict stackaddr,
                          size_t *restrict stacksize);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

pthread_attr_getstack(), pthread_attr_setstack():

    _POSIX_C_SOURCE >= 200112L

DESCRIPTION

La fonction pthread_attr_setstack() définit les attributs d'adresse de pile et de taille de pile de l'objet d'attributs de thread référencé par attr aux valeurs spécifiées par stackaddr et stacksize, respectivement. Ces attributs spécifient l'emplacement et la taille de la pile qui doivent être utilisés par un thread créé à l'aide de l'objet d'attributs de thread attr.

stackaddr doit pointer vers l'octet le plus bas adressable d'un tampon de stacksize octets qui a été alloué par l'appelant. Les pages du tampon alloué doivent être à la fois lisibles et inscriptibles.

La fonction pthread_attr_getstack() renvoie les attributs d'adresse de pile et de taille de pile de l'objet d'attributs de thread référencé par attr dans les tampons pointés par stackaddr et stacksize, respectivement.

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient 0 ; en cas d'erreur, elles renvoient un numéro d'erreur non nul.

ERREURS

pthread_attr_setstack() peut échouer avec l'erreur suivante :

EINVAL
stacksize est inférieur à PTHREAD_STACK_MIN (16384) octets. Sur certains systèmes, cette erreur peut également se produire si stackaddr ou stackaddr + stacksize n'est pas correctement aligné.

POSIX.1 documente également une erreur EACCES si la zone de pile décrite par stackaddr et stacksize n'est ni lisible ni inscriptible par l'appelant.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_attr_setstack (), pthread_attr_getstack () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.2. POSIX.1-2001.

NOTES

Ces fonctions sont fournies pour les applications qui doivent garantir que la pile d'un thread est placée à un emplacement particulier. Pour la plupart des applications, cela n'est pas nécessaire et l'utilisation de ces fonctions doit être évitée. (Utilisez pthread_attr_setstacksize(3) si une application nécessite simplement une taille de pile autre que celle par défaut.)

Lorsqu'une application utilise pthread_attr_setstack(), elle assume la responsabilité de l'allocation de la pile. Toute taille de garde définie à l'aide de pthread_attr_setguardsize(3) est ignorée. Si jugé nécessaire, il incombe à l'application d'allouer une zone de garde (une ou plusieurs pages protégées contre la lecture et l'écriture) pour gérer la possibilité de débordement de pile.

L'adresse spécifiée dans stackaddr doit être correctement alignée : pour une portabilité complète, alignez-la sur une frontière de page (sysconf(_SC_PAGESIZE)). posix_memalign(3) peut être utile pour l'allocation. Probablement, stacksize devrait également être un multiple de la taille de page du système.

Si attr est utilisé pour créer plusieurs threads, l'appelant doit modifier l'attribut d'adresse de pile entre les appels à pthread_create(3) ; sinon, les threads tenteront d'utiliser la même zone mémoire pour leurs piles, et le chaos s'ensuivra.

EXEMPLES

Voir pthread_attr_init(3).
