NOM

pt-ioprofile - Surveille les entrées/sorties des processus et affiche un tableau d'activité des fichiers et des entrées/sorties.

SYNTAXE

Usage: pt-ioprofile [OPTIONS] [FICHIER]

pt-ioprofile fait deux choses : 1) obtenir lsof+strace pendant -s secondes, 2) agréger le résultat. Si vous spécifiez un FICHIER, alors l'étape 1) n'est pas effectuée.

RISQUES

AVERTISSEMENT : pt-ioprofile bloque le serveur et peut faire planter le processus, ou le faire mal fonctionner après le détachement, ou le laisser dans un état de veille ! Avant d'utiliser cet outil, veuillez :

  • Lire la documentation de l'outil
  • Examiner les "BOGUES" connus de l'outil
  • Tester l'outil sur un serveur non-production
  • Sauvegarder votre serveur de production et vérifier les sauvegardes

    pt-ioprofile doit être considéré comme un outil intrusif et ne doit pas être utilisé sur des serveurs de production à moins que vous ne compreniez et acceptiez les risques.

DESCRIPTION

pt-ioprofile utilise "strace" et "lsof" pour surveiller les entrées/sorties d'un processus et afficher un tableau de fichiers et d'activité d'entrées/sorties. Par défaut, il surveille le processus mysqld pendant 30 secondes. La sortie est comme ceci :

Mar 27 15:33:57 PST 2011
Traçage du processus ID 1833
     total       read      write      lseek  ftruncate nom_fichier
  0.000150   0.000029   0.000068   0.000038   0.000015 /tmp/ibBE5opS

Vous devrez probablement exécuter cet outil en tant que root.

pt-ioprofile fonctionne en attachant "strace" au processus en utilisant ptrace(), ce qui le ralentira considérablement jusqu'à ce que "strace" se détache. En plus de bloquer le serveur, il y a un certain risque que le processus plante ou fonctionne mal après que "strace" s'en soit détaché, ou que "strace" ne se détache pas proprement et laisse le processus dans un état de veille. Par conséquent, cet outil doit être considéré comme intrusif et ne doit pas être utilisé sur des serveurs de production à moins que vous ne soyez à l'aise avec cela.

OPTIONS

--aggregate
forme courte : -a ; type : chaîne ; par défaut : sum

La fonction d'agrégation, soit "sum" (somme), soit "avg" (moyenne).

Si sum, alors chaque cellule contiendra la somme des valeurs qu'elle contient. Si avg, alors chaque cellule contiendra la moyenne des valeurs qu'elle contient.

--cell
forme courte : -c ; type : chaîne ; par défaut : times

Le contenu de la cellule.

Les valeurs valides sont :

VALEUR  LE CONTENU DES CELLULES
=====  =======================
count  Nombre d'opérations d'E/S
sizes  Tailles des opérations d'E/S
times  Temps des opérations d'E/S
--group-by
forme courte : -g ; type : chaîne ; par défaut : filename

L'élément de regroupement.

Les valeurs valides sont :

VALEUR    REGROUPEMENT
=====     ======================================
all       Résumer en une seule ligne de sortie
filename  Une ligne de sortie par nom de fichier
pid       Une ligne de sortie par ID de processus
--help
Afficher l'aide et quitter.
--profile-pid
forme courte : -p ; type : int

Le PID à profiler, remplace "--profile-process".

--profile-process
forme courte : -b ; type : chaîne ; par défaut : mysqld

Le nom du processus à profiler.

--run-time
type : int ; par défaut : 30

Durée du profilage.

--save-samples
type : chaîne

Nom du fichier où enregistrer les échantillons ; ceux-ci peuvent être utilisés pour une analyse ultérieure.

--version
Afficher la version de l'outil et quitter.

ENVIRONNEMENT

Cet outil n'utilise aucune variable d'environnement.

SYSTÈME REQUIS

Cet outil nécessite le shell Bourne (/bin/sh).

BOGUES

Pour une liste des bogues connus, voir https://jira.percona.com/projects/PT/issues.

Veuillez signaler les bogues à https://jira.percona.com/projects/PT. Incluez les informations suivantes dans votre rapport de bogue :

  • Commande complète utilisée pour exécuter l'outil
  • "--version" de l'outil
  • Version de MySQL de tous les serveurs impliqués
  • Sortie de l'outil, y compris STDERR
  • Fichiers d'entrée (journaux/sauvegardes/fichiers de configuration, etc.)

Si possible, incluez la sortie de débogage en exécutant l'outil avec "PTDEBUG" ; voir "ENVIRONNEMENT".

ATTENTION

L'utilisation de <PTDEBUG> peut exposer des mots de passe. Lorsque le débogage est activé, tous les paramètres de la ligne de commande sont affichés dans la sortie.
