NOM

pterm ‐ encore un émulateur de terminal X

SYNTAXE

pterm [ options ]

DESCRIPTION

pterm est un émulateur de terminal pour X. Il est basé sur un portage du moteur d'émulation de terminal du client SSH PuTTY pour Windows.

OPTIONS

Les options en ligne de commande prises en charge par pterm sont :

-e commande [ arguments ]
Spécifie une commande à exécuter dans le nouveau terminal. Tout ce qui se trouve sur la ligne de commande après cette option sera directement passé à l'appel système execvp ; donc si vous avez besoin que la commande redirige son entrée ou sa sortie, vous devrez utiliser sh :
pterm -e sh -c 'ma_commande < fichier_entree'
--display nom_affichage
Spécifie l'affichage X sur lequel ouvrir pterm. (Notez que cette option a un double tiret, même si aucune autre n'en a. C'est parce que cette option est fournie automatiquement par GTK. Désolé.)
-name nom
Spécifie le nom sous lequel pterm recherche les ressources X. Normalement, il les recherchera comme (par exemple) pterm.Font. Si vous spécifiez `-name xyz', il les recherchera comme xyz.Font à la place. Cela vous permet de configurer plusieurs ensembles de valeurs par défaut et de choisir entre eux.
-fn nom_police
Spécifie la police à utiliser pour le texte normal affiché dans le terminal. Par exemple, -fn fixed, -fn "Monospace 12".
-fb nom_police
Spécifie la police à utiliser pour le texte en gras affiché dans le terminal. Si la ressource BoldAsColour est définie sur 1 (par défaut), le texte en gras sera affiché dans des couleurs différentes au lieu d'une police différente, donc cette option sera ignorée. Si BoldAsColour est définie sur 0 ou 2 et que vous ne spécifiez pas de police en gras, pterm surimprimera la police normale pour la rendre plus audacieuse.
-fw nom_police
Spécifie la police à utiliser pour les caractères double largeur (typiquement le texte chinois, japonais et coréen) affichés dans le terminal.
-fwb nom_police
Spécifie la police à utiliser pour les caractères double largeur en gras (typiquement le texte chinois, japonais et coréen). Comme -fb, cela sera ignoré sauf si la ressource BoldAsColour est définie sur 0 ou 2.
-geometry géométrie
Spécifie la taille du terminal, en lignes et colonnes de texte. Voir X(7) pour plus d'informations sur la syntaxe des spécifications de géométrie.
-sl lignes
Spécifie le nombre de lignes de défilement à sauvegarder au-dessus du terminal.
-fg couleur
Spécifie la couleur de premier plan à utiliser pour le texte normal.
-bg couleur
Spécifie la couleur d'arrière-plan à utiliser pour le texte normal.
-bfg couleur
Spécifie la couleur de premier plan à utiliser pour le texte en gras, si la ressource BoldAsColour est définie sur 1 (par défaut) ou 2.
-bbg couleur
Spécifie la couleur de premier plan à utiliser pour le texte en gras en vidéo inversée, si la ressource BoldAsColour est définie sur 1 (par défaut) ou 2. (Cette couleur est mieux comprise comme la version en gras de la couleur d'arrière-plan ; elle n'apparaît donc que lorsque du texte est affiché sur la couleur d'arrière-plan.)
-cfg couleur
Spécifie la couleur de premier plan à utiliser pour le texte couvert par le curseur.
-cbg couleur
Spécifie la couleur d'arrière-plan à utiliser pour le texte couvert par le curseur. En d'autres termes, c'est la couleur principale du curseur.
-title titre
Spécifie le titre initial de la fenêtre du terminal. (Celui-ci peut être modifié sous le contrôle du serveur.)
-ut- ou +ut
Indique à pterm de ne pas enregistrer votre connexion dans les fichiers journaux système utmp, wtmp et lastlog ; vous n'apparaîtrez donc pas dans les listes finger ou who, par exemple.
-ut
Indique à pterm d'enregistrer votre connexion dans utmp, wtmp et lastlog : c'est l'inverse de -ut-. C'est l'option par défaut : vous n'aurez probablement besoin de la spécifier explicitement que si vous avez modifié la valeur par défaut à l'aide de la ressource StampUtmp.
-ls- ou +ls
Indique à pterm de ne pas exécuter votre shell en tant que shell de connexion.
-ls
Indique à pterm d'exécuter votre shell en tant que shell de connexion : c'est l'inverse de -ls-. C'est l'option par défaut : vous n'aurez probablement besoin de la spécifier explicitement que si vous avez modifié la valeur par défaut à l'aide de la ressource LoginShell.
-sb- ou +sb
Indique à pterm de ne pas afficher de barre de défilement.
-sb
Indique à pterm d'afficher une barre de défilement : c'est l'inverse de -sb-. C'est l'option par défaut : vous n'aurez probablement besoin de la spécifier explicitement que si vous avez modifié la valeur par défaut à l'aide de la ressource ScrollBar.
-log fichier_journal, -sessionlog fichier_journal
Cette option permet à pterm d'enregistrer toute la sortie du terminal dans un fichier en plus de l'afficher dans le terminal.
-cs jeu_caracteres
Cette option spécifie le jeu de caractères dans lequel pterm doit présumer que la session fonctionne. Ce jeu de caractères sera utilisé pour interpréter toutes les données reçues de la session, et toutes les entrées que vous tapez ou collez dans pterm seront converties dans ce jeu de caractères avant d'être envoyées à la session.

Tout nom de jeu de caractères valide dans un en-tête MIME (et pris en charge par pterm) devrait être valide ici (exemples : `ISO-8859-1', `windows-1252' ou `UTF-8'). De plus, tout encodage de caractères valide dans une description de police logique X devrait être valide (`ibm-cp437', par exemple).

Le comportement par défaut de pterm est d'utiliser le même encodage de caractères que sa police principale. Si vous fournissez une police Unicode (iso10646-1), il utilisera par défaut le jeu de caractères UTF-8.

Les noms des jeux de caractères ne sont pas sensibles à la casse.

-nethack
Indique à pterm d'activer le mode pavé numérique NetHack, dans lequel le pavé numérique génère les touches de direction hjklyubn de NetHack. Cela vous permet de jouer à NetHack avec le pavé numérique sans avoir à utiliser l'option number_pad de NetHack (qui nécessite d'appuyer sur 'n' avant tout compteur de répétition). Ainsi, vous pouvez vous déplacer avec le pavé numérique et entrer les compteurs de répétition avec les touches numériques normales.
-xrm chaine_ressource
Cette option spécifie une chaîne de ressources X. Utile pour définir des ressources qui n'ont pas leurs propres options en ligne de commande. Par exemple :
pterm -xrm 'ScrollbarOnLeft: 1'
-help, --help
Affiche un message résumant les options disponibles.
-pgpfp
Affiche les empreintes digitales des clés maîtres PGP de PuTTY, afin d'aider à vérifier les nouveaux fichiers publiés par l'équipe PuTTY.

RESSOURCES X

pterm peut être configuré plus complètement au moyen des ressources X. Toutes ces

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

les ressources sont de la forme pterm.FOO pour un certain FOO ; vous pouvez faire en sorte que pterm les recherche sous un autre nom, tel que xyz.FOO, en spécifiant l'option de ligne de commande `-name xyz'.

pterm.CloseOnExit
Cette option doit être définie sur 0, 1 ou 2 ; la valeur par défaut est 2. Elle contrôle ce que pterm fait lorsque le processus qui s'exécute à l'intérieur se termine. Lorsqu'elle est définie sur 2 (par défaut), pterm ferme sa fenêtre dès que le processus à l'intérieur se termine. Lorsqu'elle est définie sur 0, pterm affiche le statut de sortie du processus, et la fenêtre reste ouverte jusqu'à ce qu'une touche soit pressée (vous permettant d'inspecter le défilement et de copier-coller du texte).

Lorsque ce paramètre est défini sur 1, pterm se ferme immédiatement si le processus se termine proprement (avec un statut de sortie de zéro), mais la fenêtre reste ouverte si le processus se termine avec un code non nul ou sur un signal. Cela vous permet de voir ce qui a mal tourné si le processus subit une erreur, mais sans avoir à vous soucier de fermer la fenêtre dans des circonstances normales.

pterm.WarnOnClose
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 1. Lorsqu'elle est définie sur 1, pterm demande une confirmation avant de fermer sa fenêtre lorsque vous appuyez sur le bouton de fermeture.
pterm.TerminalType
Ceci contrôle la valeur définie dans la variable d'environnement TERM à l'intérieur du nouveau terminal. La valeur par défaut est `xterm'.
pterm.BackspaceIsDelete
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 1. Lorsqu'elle est définie sur 0, la touche Retour arrière ordinaire génère le caractère Retour arrière (^H) ; lorsqu'elle est définie sur 1, elle génère le caractère Suppr (^?). Quelle que soit la valeur que vous définissez, le périphérique terminal à l'intérieur de pterm sera configuré pour l'attendre.
pterm.RXVTHomeEnd
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, les touches Home et End génèrent les séquences de contrôle qu'elles généreraient dans l'émulateur de terminal rxvt, au lieu de celles plus habituelles générées par d'autres émulateurs.
pterm.LinuxFunctionKeys
Cette option peut être définie sur n'importe quel nombre compris entre 0 et 5 inclus ; la valeur par défaut est 0. Les modes varient les séquences de contrôle envoyées par les touches de fonction ; pour une documentation plus complète, il est probablement plus simple d'essayer chaque option dans `pterm -e cat', et d'appuyer sur les touches pour voir ce qu'elles génèrent.
pterm.NoApplicationKeys
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, elle empêche le serveur de basculer le clavier numérique en mode application (où les touches envoient des séquences similaires à des touches de fonction au lieu de chiffres ou de flèches). Vous n'en avez probablement besoin que si une application vous gêne.
pterm.NoApplicationCursors
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, elle empêche le serveur de basculer les touches curseur en mode application (où les touches envoient des séquences légèrement différentes). Vous n'en avez probablement besoin que si une application vous gêne.
pterm.NoMouseReporting
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, elle empêche le serveur d'activer le mode de rapport de souris (où les clics de souris sont envoyés à l'application au lieu de contrôler la coupe et le collage).
pterm.NoRemoteResize
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, elle empêche le serveur de contrôler à distance la taille de la fenêtre pterm.
pterm.NoAltScreen
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, elle empêche le serveur d'utiliser la fonctionnalité d'écran 'alternatif' du terminal, qui permet aux applications en plein écran de laisser l'écran exactement tel qu'elles l'ont trouvé.
pterm.NoRemoteWinTitle
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, elle empêche le serveur de contrôler à distance le titre de la fenêtre pterm.
pterm.NoRemoteQTitle
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 1. Lorsqu'elle est définie sur 1, elle empêche le serveur de demander à distance le titre de la fenêtre pterm.

Cette fonctionnalité est un DANGER POTENTIEL POUR LA SÉCURITÉ. Si une application malveillante peut écrire des données dans votre terminal (par exemple, si vous faites simplement un cat d'un fichier appartenant à quelqu'un d'autre sur la machine serveur), elle peut changer le titre de votre fenêtre (sauf si vous l'avez désactivé en utilisant la ressource NoRemoteWinTitle) et utiliser ensuite ce service pour que le nouveau titre de la fenêtre soit renvoyé au serveur comme s'il avait été tapé au clavier. Cela permet à un attaquant de simuler des frappes au clavier et potentiellement de faire faire à vos applications côté serveur des choses que vous ne vouliez pas. Par conséquent, cette fonctionnalité est désactivée par défaut, et nous vous recommandons de ne pas l'activer sauf si vous savez vraiment ce que vous faites.

pterm.NoDBackspace
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, elle désactive l'action normale du caractère Suppr (^?) lorsqu'il est envoyé du serveur au terminal, qui est de déplacer le curseur d'un espace vers la gauche et d'effacer le caractère qui s'y trouve.
pterm.ApplicationCursorKeys
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, l'état initial par défaut des touches curseur est le mode application (où les touches envoient des séquences similaires à des touches de fonction au lieu de chiffres ou de flèches). Lorsqu'elle est définie sur 0, l'état par défaut est le mode normal.
pterm.ApplicationKeypad
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, l'état initial par défaut du clavier numérique est le mode application (où les touches envoient des séquences similaires à des touches de fonction au lieu de chiffres ou de flèches). Lorsqu'elle est définie sur 0, l'état par défaut est le mode normal.
pterm.NetHackKeypad
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, le clavier numérique fonctionne en mode NetHack. Ceci est équivalent à l'option de ligne de commande -nethack.
pterm.Answerback
Cette option contrôle la chaîne que le terminal envoie en réponse à la réception du caractère ^E ('parle-moi de toi'). Par défaut, cette chaîne est `PuTTY'.
pterm.HideMousePtr
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, le pointeur de la souris disparaît s'il se trouve au-dessus de la fenêtre pterm et que vous appuyez sur une touche. Il réapparaît dès que vous le déplacez.
pterm.WindowBorder
Cette option contrôle le nombre de pixels d'espace entre le texte dans la fenêtre pterm et le cadre de la fenêtre. La valeur par défaut est 1. Vous pouvez augmenter cette valeur, mais la diminuer à 0 n'est pas recommandé car cela peut entraîner un mauvais fonctionnement des indications de taille du gestionnaire de fenêtres.
pterm.CurType
Cette option doit être définie sur 0, 1 ou 2 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 0, le curseur texte affiché dans la fenêtre est un bloc rectangulaire. Lorsqu'elle est définie sur 1, le curseur est un soulignement ; lorsqu'elle est définie sur 2, c'est une ligne verticale.
pterm.BlinkCur
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, le curseur texte clignote lorsque la fenêtre est active.
pterm.Beep
Cette option doit être définie sur 0 ou 2 (oui, 2) ; la valeur par défaut est 0. Lorsqu'elle est définie sur 2, pterm répond à un caractère d'alerte (^G) en faisant clignoter la fenêtre au lieu de biper.
pterm.BellOverload
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, pterm surveille un grand nombre de bips arrivant dans un court laps de temps et désactive temporairement le bip jusqu'à ce qu'ils cessent. L'idée est que si vous faites un cat d'un fichier binaire, les bips frénétiques seront en grande partie supprimés par cette fonctionnalité et ne vous rendront pas fou.

Le mode de surcharge des bips est activé en recevant N bips dans le temps T ; après un temps S supplémentaire sans aucun bip, le mode de surcharge s'éteindra de lui-même.

Le mode de surcharge des bips est toujours désactivé par toute frappe au clavier dans le terminal. Cela signifie qu'il peut répondre à des flux de données inattendus importants, mais n'interfère pas avec les activités de ligne de commande ordinaires qui génèrent des bips (telles que la complétion de noms de fichiers).

pterm.BellOverloadN
Cette option compte le nombre de caractères d'alerte qui activeront la surcharge des bips s'ils sont reçus dans un laps de temps T. La valeur par défaut est 5.
pterm.BellOverloadT
Cette option spécifie la période de temps pendant laquelle la réception de N ou plus de bips activera le mode de surcharge des bips. Elle est mesurée en microsecondes, donc (par exemple) définissez-la sur 1000000 pour une seconde. La valeur par défaut est 2000000 (deux secondes).
pterm.BellOverloadS
Cette option spécifie la période de silence requise pour désactiver le mode de surcharge des bips. Elle est mesurée en microsecondes
secondes, donc (par exemple) définissez-le sur 1000000 pour une seconde. La valeur par défaut est 5000000 (cinq secondes de silence).
pterm.ScrollbackLines
Cette option spécifie le nombre de lignes de retour sur défilement à enregistrer au-dessus de l'écran du terminal visible. La valeur par défaut est 200. Cette ressource est équivalente à l'option de ligne de commande -sl.
pterm.DECOriginMode
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Elle spécifie l'état par défaut du mode d'origine DEC. (Si vous ne savez pas ce que cela signifie, vous n'avez probablement pas besoin de vous en soucier.)
pterm.AutoWrapMode
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 1. Elle spécifie l'état par défaut du mode de retour automatique à la ligne. Lorsqu'elle est définie sur 1, les lignes très longues passeront à la ligne suivante sur le terminal ; lorsqu'elle est définie sur 0, les lignes longues seront écrasées contre le bord droit de l'écran.
pterm.LFImpliesCR
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, le terminal ramènera le curseur sur le côté gauche de l'écran lorsqu'il recevra un caractère de saut de ligne.
pterm.WinTitle
Cette ressource est identique à l'option de ligne de commande -T : elle contrôle le titre initial de la fenêtre. La valeur par défaut est `pterm'.
pterm.TermWidth
Cette ressource est identique à la partie largeur de l'option de ligne de commande -geometry : elle contrôle le nombre de colonnes de texte dans la fenêtre. La valeur par défaut est 80.
pterm.TermHeight
Cette ressource est identique à la partie largeur de l'option de ligne de commande -geometry : elle contrôle le nombre de colonnes de texte dans la fenêtre. La valeur par défaut est 24.
pterm.Font
Cette ressource est identique à l'option de ligne de commande -fn : elle contrôle la police utilisée pour afficher le texte normal. La valeur par défaut est `fixed'.
pterm.BoldFont
Cette ressource est identique à l'option de ligne de commande -fb : elle contrôle la police utilisée pour afficher le texte en gras lorsque BoldAsColour est défini sur 0 ou 2. La valeur par défaut n'est pas définie (la police sera mise en gras en l'imprimant deux fois avec un décalage d'un pixel).
pterm.WideFont
Cette ressource est identique à l'option de ligne de commande -fw : elle contrôle la police utilisée pour afficher les caractères double largeur. La valeur par défaut n'est pas définie (les caractères double largeur ne peuvent pas être affichés).
pterm.WideBoldFont
Cette ressource est identique à l'option de ligne de commande -fwb : elle contrôle la police utilisée pour afficher les caractères double largeur en gras, lorsque BoldAsColour est défini sur 0 ou 2. La valeur par défaut n'est pas définie (les caractères double largeur sont affichés en gras en les imprimant deux fois avec un décalage d'un pixel).
pterm.ShadowBoldOffset
Cette ressource peut être définie sur un entier ; la valeur par défaut est -1. Elle spécifie le décalage auquel le texte est superposé lors de l'utilisation du mode "gras fantôme". La valeur par défaut (1) signifie que le texte sera imprimé à l'emplacement normal, et également un caractère vers la droite ; cela semble bien fonctionner pour la plupart des polices bitmap X, qui ont une ligne vide de pixels sur le côté droit. Pour certaines polices, vous devrez peut-être la définir sur -1, de sorte que le texte soit superposé un pixel vers la gauche ; pour des polices vraiment grandes, vous pourriez vouloir la définir sur une valeur supérieure à 1 (dans une direction ou l'autre).
pterm.BoldAsColour
Cette option doit être définie sur 0, 1 ou 2 ; la valeur par défaut est 1. Elle spécifie comment le texte en gras doit être affiché. Lorsqu'elle est définie sur 1, le texte en gras est affiché en utilisant une couleur plus vive ; lorsqu'elle est définie sur 0, le texte en gras est affiché en utilisant une police plus épaisse ; lorsqu'elle est définie sur 2, les deux effets se produisent simultanément (une police épaisse et une couleur plus vive).
pterm.Colour0, pterm.Colour1, ..., pterm.Colour21
Ces options contrôlent les différentes couleurs utilisées pour afficher le texte dans la fenêtre pterm. Chacune doit être spécifiée comme un triple de nombres décimaux donnant les valeurs rouge, vert et bleu : ainsi, le noir est `0,0,0', le blanc est `255,255,255', le rouge est `255,0,0' et ainsi de suite.

Les couleurs 0 et 1 spécifient la couleur de premier plan et son équivalent en gras (les options de ligne de commande -fg et -bfg). Les couleurs 2 et 3 spécifient la couleur d'arrière-plan et son équivalent en gras (les options de ligne de commande -bg et -bbg). Les couleurs 4 et 5 spécifient les couleurs de texte et de bloc utilisées pour le curseur (les options de ligne de commande -cfg et -cbg). Chaque nombre pair de 6 à 20 inclus spécifie la couleur à utiliser pour l'une des spécifications de couleur primaire ANSI (noir, rouge, vert, jaune, bleu, magenta, cyan, blanc, dans cet ordre) ; les nombres impairs de 7 à 21 inclus spécifient la version en gras de chaque couleur, dans le même ordre. Les valeurs par défaut sont :

pterm.Colour0:  187,187,187
pterm.Colour1:  255,255,255
pterm.Colour2:  0,0,0
pterm.Colour3:  85,85,85
pterm.Colour4:  0,0,0
pterm.Colour5:  0,255,0
pterm.Colour6:  0,0,0
pterm.Colour7:  85,85,85
pterm.Colour8:  187,0,0
pterm.Colour9:  255,85,85
pterm.Colour10:  0,187,0
pterm.Colour11:  85,255,85
pterm.Colour12:  187,187,0
pterm.Colour13:  255,255,85
pterm.Colour14:  0,0,187
pterm.Colour15:  85,85,255
pterm.Colour16:  187,0,187
pterm.Colour17:  255,85,255
pterm.Colour18:  0,187,187
pterm.Colour19:  85,255,255
pterm.Colour20:  187,187,187
pterm.Colour21:  255,255,255
pterm.RectSelect
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 0, le déplacement de la souris sur plusieurs lignes sélectionne jusqu'à la fin de chaque ligne et à partir du début de la ligne suivante ; lorsqu'elle est définie sur 1, le déplacement de la souris sur plusieurs lignes sélectionne une région rectangulaire. Dans chaque cas, le fait de maintenir la touche Alt enfoncée tout en déplaçant la souris donne l'autre comportement.
pterm.MouseOverride
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 1. Lorsqu'elle est définie sur 1, si l'application demande le suivi de la souris (afin que les clics de souris lui soient envoyés au lieu de sélectionner), le fait de maintenir la touche Maj enfoncée ramène la souris à la sélection normale. Lorsqu'elle est définie sur 0, le suivi de la souris désactive complètement la sélection.
pterm.Printer
Cette option n'est pas définie par défaut. Si vous la définissez, l'impression contrôlée par le serveur est activée : le serveur peut envoyer des séquences de contrôle pour demander l'envoi de données vers une imprimante. Ces données seront redirigées vers la commande que vous spécifiez ici ; vous pourriez donc vouloir la définir sur `lpr', par exemple, ou `lpr -Pmyprinter'.
pterm.ScrollBar
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 1. Lorsqu'elle est définie sur 0, la barre de défilement est masquée (bien que Maj+PagePréc et Maj+PageSuiv fonctionnent toujours). Ceci est identique à l'option de ligne de commande -sb.
pterm.ScrollbarOnLeft
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, la barre de défilement sera affichée sur la gauche du terminal au lieu de la droite.
pterm.ScrollOnKey
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, toute pression de touche réinitialise la position du retour sur défilement tout en bas.
pterm.ScrollOnDisp
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 1. Lorsqu'elle est définie sur 1, toute activité dans l'affichage réinitialise la position du retour sur défilement tout en bas.
pterm.LineCodePage
Cette option spécifie le jeu de caractères à utiliser pour la session. Ceci est identique à l'option de ligne de commande -cs.
pterm.NoRemoteCharset
Cette option désactive la capacité du terminal à changer son jeu de caractères lorsqu'il reçoit des séquences d'échappement lui demandant de le faire. Vous pourriez avoir besoin de le faire pour interagir avec des programmes qui changent incorrectement le jeu de caractères à quelque chose qu'ils jugent pertinent.
pterm.BCE
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 1. Lorsqu'elle est définie sur 1, les différentes séquences de contrôle qui effacent des parties de l'affichage du terminal effaceront dans la couleur d'arrière-plan actuelle ; lorsqu'elle est définie sur 0, elles effaceront toujours en noir.
pterm.BlinkText
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 0. Lorsqu'elle est définie sur 1, le texte spécifié comme clignotant par le serveur clignotera réellement ; lorsqu'elle est définie sur 0, pterm utilisera l'approche moins distrayante de rendre la couleur d'arrière-plan du texte plus foncée.
pterm.StampUtmp
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 1. Lorsqu'elle est définie sur 1, pterm enregistrera la connexion dans les différents fichiers journaux du système. Cette ressource est équivalente à l'option de ligne de commande -ut.
pterm.LoginShell
Cette option doit être définie sur 0 ou 1 ; la valeur par défaut est 1. Lorsqu'elle est définie sur 1, pterm exécutera votre shell comme un shell de connexion. Cette ressource est équivalente à l'option de ligne de commande -ls.
