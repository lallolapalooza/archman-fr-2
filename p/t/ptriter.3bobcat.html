FBB::PtrIter(3bobcat) Itérateur pointant vers des pointeurs FBB::PtrIter(3bobcat)

NOM

FBB::PtrIter - Itérateur retournant un pointeur lorsqu'il est déréférencé

SYNTAXE

#include <bobcat/ptriter>

DESCRIPTION

Le modèle de classe PtrIter implémente un itérateur d'entrée dont le operator* retourne l'adresse de l'élément auquel l'itérateur fait référence. Considérons une std::unordered_map<std::string, DataType>. Son membre begin retourne un itérateur dont le operator* retourne une std::pair<std::string, DataType> (const) &. C'est généralement ce que l'on souhaite, mais supposons maintenant que l'on veuille afficher le contenu de la map, trié par ses clés. Le tri peut simplement être effectué en définissant un vecteur de support contenant des pointeurs vers les éléments de la map, puis en triant les chaînes de caractères auxquelles pointent les pointeurs.

PtrIter est un outil qui peut être utilisé pour construire un tel vecteur de support, comme montré dans la section EXEMPLE.

PtrIter est un modèle de classe nécessitant un paramètre de type de modèle : Iterator, le type de l'itérateur (par exemple, vector<string>::iterator)

Les utilisateurs de PtrIter n'ont pas à spécifier le type de modèle de PtrIter. Le modèle de fonction ptrIter, lorsqu'il est fourni avec un itérateur, retourne l'objet PtrIter correspondant.

ESPACE DE NOM

FBB
Tous les constructeurs, membres, opérateurs et manipulateurs mentionnés dans cette page de manuel sont définis dans l'espace de nommage FBB.

HÉRITE DE

std::iterator<std::input_iterator_tag, ...>

FONCTION LIBRE

o
PtrIter<Iterator> ptrIter(Iterator const &iter):
ce modèle de fonction retourne un objet PtrIter pour l'argument Iterator de la fonction. Ce modèle de fonction simplifie la construction d'un PtrIter car aucun paramètre de modèle ne doit être spécifié (voir aussi la section EXEMPLE)

CONSTRUCTEURS

o
PtrIter(Iterator const &iter):
le paramètre iter doit être initialisé avec un itérateur d'entrée existant, offrant operator*, operator++, operator== et operator!=. Comme PtrIter est un modèle de classe, ses paramètres de type doivent être spécifiés lors de la définition d'un objet PtrIter. Par exemple, 
    PtrIter<set<string>::iterator> PtrIter(mySet.begin());

Les constructeurs par copie et par déplacement (et les opérateurs d'affectation) sont disponibles.

OPÉRATEURS SURCHARGÉS

o
PtrType operator*() const:
l'adresse de l'entité référencée par l'itérateur est retournée ;
o
PtrIter &operator++():
l'itérateur est incrémenté (pré-incrémenté) à la position suivante ;
o
bool operator==(PtrIter const &other) const:
true est retourné si les deux itérateurs sont égaux ;
o
bool operator!=(PtrIter const &other) const:
true est retourné si les deux itérateurs sont inégaux ;

DÉCLARATION USING

Le modèle de classe PtrIter définit PtrType :

o
using PtrType = decltype(&*Iterator()):

FONCTIONS MEMBRES

Tous les membres de std::iterator<std:::input_iterator_tag, ...> sont disponibles, car FBB::PtrIter en hérite.

EXEMPLE

#include <algorithm>
#include <unordered_map>
#include <vector>
#include <cstring>
#include <iostream>
#include <bobcat/ptriter>
using namespace std;
using namespace FBB;
int main()
{
    cout << "Entrez des lignes, le premier mot sera la clé de la map ; "
                                            "^D lorsque vous avez terminé.\n";
    string key;
    string line;
    unordered_map<string, string> map;
    while (cin >> key && getline(cin, line))    // remplir la map
        map[key] = line;
    cout << ’\n’;
                                        // initialiser un vecteur
    vector<decltype(&*map.begin())>     // de support, en utilisant ptrIter
        support(ptrIter(map.begin()), ptrIter(map.end()));
                                        // trier 'support'
    typedef unordered_map<string, string>::value_type VT;
    sort(support.begin(), support.end(),
        [&](VT const *p1, VT const *p2)
        {
            return strcasecmp(p1->first.c_str(), p2->first.c_str()) < 0;
        }
    );
    for(auto &element: support)         // afficher trié par clé
        cout << element->first << ’ ’ << element->second << ’\n’;
}
