pthread_detach(3) Manuel des fonctions de bibliothèque pthread_detach(3)

NOM

pthread_detach - détacher un thread

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <pthread.h>
int pthread_detach(pthread_t thread);

DESCRIPTION

La fonction pthread_detach() marque le thread identifié par thread comme détaché. Lorsqu'un thread détaché se termine, ses ressources sont automatiquement libérées vers le système sans qu'un autre thread ait besoin de le rejoindre avec pthread_join(3).

Tenter de détacher un thread déjà détaché a un comportement non spécifié.

VALEUR DE RETOUR

En cas de succès, pthread_detach() retourne 0 ; en cas d'erreur, elle retourne un numéro d'erreur.

ERREURS

EINVAL
thread n'est pas un thread joignable.
ESRCH
Aucun thread avec l'identifiant thread n'a été trouvé.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_detach () Thread safety MT-Safe

STANDARDS

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

NOTES

Une fois qu'un thread a été détaché, il ne peut pas être rejoint avec pthread_join(3) ni être rendu joignable à nouveau.

Un nouveau thread peut être créé dans un état détaché en utilisant pthread_attr_setdetachstate(3) pour définir l'attribut de détachement de l'argument attr de pthread_create(3).

L'attribut de détachement détermine simplement le comportement du système lorsque le thread se termine ; il n'empêche pas le thread d'être terminé si le processus se termine avec exit(3) (ou de manière équivalente, si le thread principal retourne).

Soit pthread_join(3), soit pthread_detach() devrait être appelé pour chaque thread qu'une application crée, afin que les ressources système pour le thread puissent être libérées. (Mais notez que les ressources de tout thread pour lequel l'une de ces actions n'a pas été effectuée seront libérées lorsque le processus se terminera.)

EXEMPLES

L'instruction suivante détache le thread appelant :


pthread_detach(pthread_self());

VOIR AUSSI

pthread_attr_setdetachstate(3), pthread_cancel(3), pthread_create(3), pthread_exit(3), pthread_join(3), pthreads(7)
