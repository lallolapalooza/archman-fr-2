pthread_setaffinity_np(3) Manuel des fonctions de bibliothèque pthread_setaffinity_np(3)

NOM

pthread_setaffinity_np, pthread_getaffinity_np - définir/obtenir l'affinité CPU d'un thread

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#define _GNU_SOURCE             /* Voir feature_test_macros(7) */
#include <pthread.h>
int pthread_setaffinity_np(pthread_t thread, size_t cpusetsize,
                           const cpu_set_t *cpuset);
int pthread_getaffinity_np(pthread_t thread, size_t cpusetsize,
                           cpu_set_t *cpuset);

DESCRIPTION

La fonction pthread_setaffinity_np() définit le masque d'affinité CPU du thread thread au jeu de CPU pointé par cpuset. Si l'appel réussit, et que le thread ne s'exécute pas actuellement sur l'un des CPU du jeu cpuset, alors il est migré vers l'un de ces CPU.

La fonction pthread_getaffinity_np() renvoie le masque d'affinité CPU du thread thread dans le tampon pointé par cpuset.

Pour plus de détails sur les masques d'affinité CPU, voir sched_setaffinity(2). Pour une description d'un ensemble de macros pouvant être utilisées pour manipuler et inspecter les jeux de CPU, voir CPU_SET(3).

L'argument cpusetsize est la longueur (en octets) du tampon pointé par cpuset. Typiquement, cet argument serait spécifié comme sizeof(cpu_set_t). (Il peut s'agir d'une autre valeur, si vous utilisez les macros décrites dans CPU_SET(3) pour allouer dynamiquement un jeu de CPU.)

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient 0 ; en cas d'erreur, elles renvoient un numéro d'erreur non nul.

ERREURS

EFAULT
Une adresse mémoire fournie était invalide.
EINVAL
(pthread_setaffinity_np()) Le masque de bits d'affinité mask ne contient aucun processeur actuellement physiquement présent sur le système et autorisé pour le thread conformément aux restrictions qui peuvent être imposées par le mécanisme "cpuset" décrit dans cpuset(7).
EINVAL
(pthread_setaffinity_np()) cpuset a spécifié un CPU qui était en dehors de l'ensemble supporté par le noyau. (L'option de configuration du noyau CONFIG_NR_CPUS définit la plage de l'ensemble supporté par le type de données du noyau utilisé pour représenter les jeux de CPU.)
EINVAL
(pthread_getaffinity_np()) cpusetsize est plus petit que la taille du masque d'affinité utilisé par le noyau.
ESRCH
Aucun thread avec l'ID thread n'a pu être trouvé.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_setaffinity_np (), pthread_getaffinity_np () Sécurité des threads MT-Safe

NORMES

GNU ; d'où le suffixe "_np" (non portable) dans les noms.

HISTORIQUE

glibc 2.3.4.

Dans glibc 2.3.3 uniquement, des versions de ces fonctions étaient fournies qui ne possédaient pas d'argument cpusetsize. Au lieu de cela, la taille du jeu de CPU transmise aux appels système sous-jacents était toujours sizeof(cpu_set_t).

NOTES

Après un appel à pthread_setaffinity_np(), l'ensemble des CPU sur lesquels le thread s'exécutera réellement est l'intersection de l'ensemble spécifié dans l'argument cpuset et de l'ensemble des CPU actuellement présents sur le système. Le système peut restreindre davantage l'ensemble des CPU sur lesquels le thread s'exécute si le mécanisme "cpuset" décrit dans cpuset(7) est utilisé. Ces restrictions sur l'ensemble réel des CPU sur lesquels le thread s'exécutera sont silencieusement imposées par le noyau.

Ces fonctions sont implémentées par-dessus les appels système sched_setaffinity(2) et sched_getaffinity(2).

Un nouveau thread créé par pthread_create(3) hérite d'une copie du masque d'affinité CPU de son créateur.

EXEMPLES

Dans le programme suivant, le thread principal utilise pthread_setaffinity_np() pour définir son masque d'affinité CPU afin d'inclure les CPU 0 à 7 (qui ne sont pas tous nécessairement disponibles sur le système), puis appelle pthread_getaffinity_np() pour vérifier le masque d'affinité CPU résultant du thread.

#define _GNU_SOURCE
#include <err.h>
#include <pthread.h>
#include <sched.h>
#include <stdio.h>
#include <stdlib.h>
int
main(void)
{
    int s;
    cpu_set_t cpuset;
    pthread_t thread;
    thread = pthread_self();
    /* Définir le masque d'affinité pour inclure les CPU 0 à 7.  */
    CPU_ZERO(&cpuset);
    for (size_t j = 0; j < 8; j++)
        CPU_SET(j, &cpuset);
    s = pthread_setaffinity_np(thread, sizeof(cpuset), &cpuset);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_setaffinity_np");
    /* Vérifier le masque d'affinité réel attribué au thread.  */
    s = pthread_getaffinity_np(thread, sizeof(cpuset), &cpuset);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_getaffinity_np");
    printf("L'ensemble renvoyé par pthread_getaffinity_np() contenait :\n");
    for (size_t j = 0; j < CPU_SETSIZE; j++)
        if (CPU_ISSET(j, &cpuset))
            printf("    CPU %zu\n", j);
    exit(EXIT_SUCCESS);
}
