pthread_cleanup_push(3) Manuel des fonctions de bibliothèque pthread_cleanup_push(3)

NOM

pthread_cleanup_push, pthread_cleanup_pop - ajouter et retirer des gestionnaires de nettoyage d'annulation de thread

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <pthread.h>
void pthread_cleanup_push(typeof(void (void *)) *routine, void *arg);
void pthread_cleanup_pop(int execute);

DESCRIPTION

Ces fonctions manipulent la pile des gestionnaires de nettoyage d'annulation du thread appelant. Un gestionnaire de nettoyage est une fonction qui est automatiquement exécutée lorsqu'un thread est annulé (ou dans diverses autres circonstances décrites ci-dessous) ; il peut, par exemple, déverrouiller un mutex afin qu'il devienne disponible pour d'autres threads du processus.

La fonction pthread_cleanup_push() ajoute routine en haut de la pile des gestionnaires de nettoyage. Lorsque routine est ensuite appelée, elle recevra arg comme argument.

La fonction pthread_cleanup_pop() retire le gestionnaire situé en haut de la pile des gestionnaires de nettoyage et l'exécute éventuellement si execute est différent de zéro.

Un gestionnaire de nettoyage d'annulation est retiré de la pile et exécuté dans les circonstances suivantes :

•
Lorsqu'un thread est annulé, tous les gestionnaires de nettoyage empilés sont retirés et exécutés dans l'ordre inverse de celui dans lequel ils ont été ajoutés à la pile.
•
Lorsqu'un thread se termine en appelant pthread_exit(3), tous les gestionnaires de nettoyage sont exécutés comme décrit dans le point précédent. (Les gestionnaires de nettoyage ne sont *pas* appelés si le thread se termine en effectuant un *retour* de la fonction de démarrage du thread.)
•
Lorsqu'un thread appelle pthread_cleanup_pop() avec un argument execute différent de zéro, le gestionnaire de nettoyage le plus haut est retiré et exécuté.

POSIX.1 permet que pthread_cleanup_push() et pthread_cleanup_pop() soient implémentées comme des macros qui s'étendent en du code contenant respectivement '{' et '}'. Pour cette raison, l'appelant doit s'assurer que les appels à ces fonctions sont appariés au sein de la même fonction, et au même niveau d'imbrication lexical. (Autrement dit, un gestionnaire de nettoyage n'est établi que lors de l'exécution d'une section de code spécifiée.)

Appeler longjmp(3) (siglongjmp(3)) produit des résultats indéfinis si un appel a été fait à pthread_cleanup_push() ou pthread_cleanup_pop() sans l'appel correspondant de la paire depuis que le tampon de saut a été rempli par setjmp(3) (sigsetjmp(3)). De même, appeler longjmp(3) (siglongjmp(3)) depuis l'intérieur d'un gestionnaire de nettoyage produit des résultats indéfinis, sauf si le tampon de saut a également été rempli par setjmp(3) (sigsetjmp(3)) à l'intérieur du gestionnaire.

VALEUR DE RETOUR

Ces fonctions ne retournent aucune valeur.

ERREURS

Il n'y a pas d'erreurs.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_cleanup_push (), pthread_cleanup_pop () Sécurité des threads MT-Safe

VERSIONS

Sur glibc, les fonctions pthread_cleanup_push() et pthread_cleanup_pop() sont implémentées comme des macros qui s'étendent en du code contenant respectivement '{' et '}'. Cela signifie que les variables déclarées dans la portée des appels appariés de ces fonctions seront visibles uniquement dans cette portée.

POSIX.1 stipule que l'effet de l'utilisation de *return*, *break*, *continue* ou *goto* pour quitter prématurément un bloc délimité par pthread_cleanup_push() et pthread_cleanup_pop() est indéfini. Les applications portables devraient éviter de faire cela.

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001. glibc 2.0.

EXEMPLES

Le programme ci-dessous fournit un exemple simple de l'utilisation des fonctions décrites dans cette page. Le programme crée un thread qui exécute une boucle délimitée par pthread_cleanup_push() et pthread_cleanup_pop(). Cette boucle incrémente une variable globale, cnt, une fois par seconde. Selon les arguments de ligne de commande fournis, le thread principal envoie une requête d'annulation à l'autre thread, ou définit une variable globale qui amène l'autre thread à quitter sa boucle et à se terminer normalement (en effectuant un *retour*).

Dans la session shell suivante, le thread principal envoie une requête d'annulation à l'autre thread :


$ ./a.out;
New thread started
cnt = 0
cnt = 1
Canceling thread
Called clean-up handler
Thread was canceled; cnt = 0

D'après ce qui précède, nous constatons que le thread a été annulé, et que le gestionnaire de nettoyage d'annulation a été appelé et a réinitialisé la valeur de la variable globale cnt à 0.

Lors de l'exécution suivante, le programme principal définit une variable globale qui amène l'autre thread à se terminer normalement :


$ ./a.out x;
New thread started
cnt = 0
cnt = 1
Thread terminated normally; cnt = 2

D'après ce qui précède, nous constatons que le gestionnaire de nettoyage n'a pas été exécuté (car cleanup_pop_arg était 0), et par conséquent la valeur de cnt n'a pas été réinitialisée.

Lors de l'exécution suivante, le programme principal définit une variable globale qui amène l'autre thread à se terminer normalement et fournit une valeur non nulle pour cleanup_pop_arg :


$ ./a.out x 1;
New thread started
cnt = 0
cnt = 1
Called clean-up handler
Thread terminated normally; cnt = 0

Dans ce cas, nous voyons que même si le thread n'a pas été annulé, le gestionnaire de nettoyage a été exécuté, car l'argument donné à pthread_cleanup_pop() était différent de zéro.

Source du programme

#include <err.h>
#include <errno.h>
#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/types.h>
#include <unistd.h>
static int done = 0;
static int cleanup_pop_arg = 0;
static int cnt = 0;
static void
cleanup_handler(void *arg)
{
    printf("Called clean-up handler\n");
    cnt = 0;
}
static void *
thread_start(void *arg)
{
    time_t curr;
    printf("New thread started\n");
    pthread_cleanup_push(cleanup_handler, NULL);
    curr = time(NULL);
    while (!done) {
        pthread_testcancel();           /* Un point d'annulation */
        if (curr < time(NULL)) {
            curr = time(NULL);
            printf("cnt = %d\n", cnt);  /* Un point d'annulation */
            cnt++;
        }
    }
    pthread_cleanup_pop(cleanup_pop_arg);
    return NULL;
}
int
main(int argc, char *argv[])
{
    pthread_t thr;
    int s;
    void *res;
    s = pthread_create(&thr, NULL, thread_start, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_create");
    sleep(2);           /* Laisser le nouveau thread s'exécuter un peu */
    if (argc > 1) {
        if (argc > 2)
            cleanup_pop_arg = atoi(argv[2]);
        done = 1;
    } else {
        printf("Canceling thread\n");
        s = pthread_cancel(thr);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_cancel");
    }
    s = pthread_join(thr, &res);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_join");
    if (res == PTHREAD_CANCELED)
        printf("Thread was canceled; cnt = %d\n", cnt);
    else
        printf("Thread terminated normally; cnt = %d\n", cnt);
    exit(EXIT_SUCCESS);
}
