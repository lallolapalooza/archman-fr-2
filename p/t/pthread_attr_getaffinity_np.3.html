pthread_attr_setaffinity_np(3) Manuel des fonctions de bibliothèque pthread_attr_setaffinity_np(3)

NOM

pthread_attr_setaffinity_np, pthread_attr_getaffinity_np - définir/obtenir l'attribut d'affinité CPU dans l'objet d'attributs de thread

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#define _GNU_SOURCE             /* Voir feature_test_macros(7) */
#include <pthread.h>
int pthread_attr_setaffinity_np(pthread_attr_t *attr,
                   size_t cpusetsize, const cpu_set_t *cpuset);
int pthread_attr_getaffinity_np(const pthread_attr_t *attr,
                   size_t cpusetsize, cpu_set_t *cpuset);

DESCRIPTION

La fonction pthread_attr_setaffinity_np() définit le masque d'affinité CPU de l'objet d'attributs de thread référencé par attr à la valeur spécifiée dans cpuset. Cet attribut détermine le masque d'affinité CPU d'un thread créé en utilisant l'objet d'attributs de thread attr.

La fonction pthread_attr_getaffinity_np() retourne le masque d'affinité CPU de l'objet d'attributs de thread référencé par attr dans le tampon pointé par cpuset.

L'argument cpusetsize est la longueur (en octets) du tampon pointé par cpuset. Typiquement, cet argument serait spécifié comme sizeof(cpu_set_t).

Pour plus de détails sur les masques d'affinité CPU, voir sched_setaffinity(2). Pour une description d'un ensemble de macros qui peuvent être utilisées pour manipuler et inspecter des ensembles de CPU, voir CPU_SET(3).

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent 0 ; en cas d'erreur, elles retournent un numéro d'erreur non nul.

ERREURS

EINVAL
(pthread_attr_setaffinity_np()) cpuset spécifiait un CPU qui était en dehors de l'ensemble supporté par le noyau. (L'option de configuration du noyau CONFIG_NR_CPUS définit la plage de l'ensemble supporté par le type de données du noyau utilisé pour représenter les ensembles de CPU.)
EINVAL
(pthread_attr_getaffinity_np()) Un CPU dans le masque d'affinité de l'objet d'attributs de thread référencé par attr se trouve en dehors de la plage spécifiée par cpusetsize (c'est-à-dire que cpuset/cpusetsize est trop petit).
ENOMEM
(pthread_attr_setaffinity_np()) Impossible d'allouer de la mémoire.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_attr_setaffinity_np (), pthread_attr_getaffinity_np () Thread safety MT-Safe

NORMES

GNU ; d'où le suffixe "_np" (non portable) dans les noms.

HISTORIQUE

glibc 2.3.4.

NOTES

Dans glibc 2.3.3 uniquement, des versions de ces fonctions étaient fournies sans argument cpusetsize. Au lieu de cela, la taille de l'ensemble de CPU donnée aux appels système sous-jacents était toujours sizeof(cpu_set_t).

VOIR AUSSI

sched_setaffinity(2), pthread_attr_init(3), pthread_setaffinity_np(3), cpuset(7), pthreads(7)
