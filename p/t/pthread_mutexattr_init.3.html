pthread_mutexattr_init(3) Manuel des fonctions de bibliothèque pthread_mutexattr_init(3)

NOM

pthread_mutexattr_init, pthread_mutexattr_destroy - initialiser et détruire un objet d'attributs de mutex

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <pthread.h>
int pthread_mutexattr_init(pthread_mutexattr_t *attr);
int pthread_mutexattr_destroy(pthread_mutexattr_t *attr);

DESCRIPTION

La fonction pthread_mutexattr_init() initialise l'objet d'attributs de mutex pointé par attr avec les valeurs par défaut pour tous les attributs définis par l'implémentation.

Les résultats de l'initialisation d'un objet d'attributs de mutex déjà initialisé ne sont pas définis.

La fonction pthread_mutexattr_destroy() détruit un objet d'attributs de mutex (le rendant non initialisé). Une fois qu'un objet d'attributs de mutex a été détruit, il peut être réinitialisé avec pthread_mutexattr_init().

Les résultats de la destruction d'un objet d'attributs de mutex non initialisé ne sont pas définis.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent 0. En cas d'erreur, elles retournent un numéro d'erreur positif.

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

NOTES

Les modifications ultérieures d'un objet d'attributs de mutex n'affectent pas les mutex qui ont déjà été initialisés à l'aide de cet objet.

VOIR AUSSI

pthread_mutex_init(3), pthread_mutexattr_getpshared(3), pthread_mutexattr_getrobust(3), pthreads(7)
