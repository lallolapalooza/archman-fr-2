PTAR(1perl) Guide de référence du programmeur Perl PTAR(1perl)

NOM

ptar - un programme semblable à tar écrit en perl

DESCRIPTION

ptar est un petit programme ressemblant à tar qui utilise le module perl Archive::Tar pour extraire, créer et lister des archives tar.

SYNTAXE

ptar -c [-v] [-z] [-C] [-f ARCHIVE_FILE | -] FICHIER FICHIER ...
ptar -c [-v] [-z] [-C] [-T index | -] [-f ARCHIVE_FILE | -]
ptar -x [-v] [-z] [-f ARCHIVE_FILE | -]
ptar -t [-z] [-f ARCHIVE_FILE | -]
ptar -h

OPTIONS

c   Créer ARCHIVE_FILE ou STDOUT (-) à partir de FICHIER
x   Extraire de ARCHIVE_FILE ou STDIN (-)
t   Lister le contenu de ARCHIVE_FILE ou STDIN (-)
f   Nom du FICHIER ARCHIVE à utiliser. Par défaut './default.tar'
z   Lire/écrire ARCHIVE_FILE compressé avec zlib (pas toujours disponible)
v   Afficher les noms de fichiers lorsqu'ils sont ajoutés ou extraits de ARCHIVE_FILE
h   Affiche ce message d'aide
C   Mode CPAN - retire 022 des permissions
T   obtenir les noms à créer à partir d'un fichier

VOIR AUSSI

tar(1), Archive::Tar.
