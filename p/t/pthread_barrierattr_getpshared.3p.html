PTHREAD_BARRIERATTR_GETPSHARED(3P) Manuel du programmeur POSIX PTHREAD_BARRIERATTR_GETPSHARED(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pthread_barrierattr_getpshared, pthread_barrierattr_setpshared — obtenir et définir l'attribut de partage entre processus d'un objet d'attributs de barrière

SYNOPIS

#include <pthread.h>
int pthread_barrierattr_getpshared(const pthread_barrierattr_t
    *restrict attr, int *restrict pshared);
int pthread_barrierattr_setpshared(pthread_barrierattr_t *attr,
    int pshared);

DESCRIPTION

La fonction pthread_barrierattr_getpshared() obtient la valeur de l'attribut process-shared de l'objet d'attributs référencé par attr. La fonction pthread_barrierattr_setpshared() définit l'attribut process-shared dans un objet d'attributs initialisé référencé par attr.

L'attribut process-shared est défini à PTHREAD_PROCESS_SHARED pour permettre à une barrière d'être manipulée par n'importe quel thread ayant accès à la mémoire où la barrière est allouée. Voir Section 2.9.9, Copies d'objets de synchronisation et mappages alternatifs pour des exigences supplémentaires. La valeur par défaut de l'attribut est PTHREAD_PROCESS_PRIVATE. Les deux constantes PTHREAD_PROCESS_SHARED et PTHREAD_PROCESS_PRIVATE sont définies dans <pthread.h>.

Les attributs supplémentaires, leurs valeurs par défaut et les noms des fonctions associées pour obtenir et définir ces valeurs d'attributs sont définis par l'implémentation.

Le comportement est indéfini si la valeur spécifiée par l'argument attr à pthread_barrierattr_getpshared() ou pthread_barrierattr_setpshared() ne fait pas référence à un objet d'attributs de barrière initialisé.

VALEUR DE RETOUR

En cas de succès, la fonction pthread_barrierattr_getpshared() retourne zéro et stocke la valeur de l'attribut process-shared de attr dans l'objet référencé par le paramètre pshared. Sinon, un numéro d'erreur est retourné pour indiquer l'erreur.

En cas de succès, la fonction pthread_barrierattr_setpshared() retourne zéro ; sinon, un numéro d'erreur est retourné pour indiquer l'erreur.

ERREURS

La fonction pthread_barrierattr_setpshared() peut échouer si :

EINVAL
La nouvelle valeur spécifiée pour l'attribut process-shared n'est pas l'une des valeurs légales PTHREAD_PROCESS_SHARED ou PTHREAD_PROCESS_PRIVATE.

Ces fonctions ne retourneront pas le code d'erreur [EINTR].

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION DE L'APPLICATION

Les fonctions pthread_barrierattr_getpshared() et pthread_barrierattr_setpshared() font partie de l'option de synchronisation de partage entre processus des threads et ne sont pas nécessairement fournies sur toutes les implémentations.

RATIONALE

Si une implémentation détecte que la valeur spécifiée par l'argument attr à pthread_barrierattr_getpshared() ou pthread_barrierattr_setpshared() ne fait pas référence à un objet d'attributs de barrière initialisé, il est recommandé que la fonction échoue et signale une erreur [EINVAL].
