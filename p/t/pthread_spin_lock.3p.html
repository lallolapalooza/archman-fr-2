PTHREAD_SPIN_LOCK(3P) Manuel du programmeur POSIX PTHREAD_SPIN_LOCK(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pthread_spin_lock, pthread_spin_trylock — verrouiller un objet de verrouillage par rotation

SYNTAXE

#include <pthread.h>
int pthread_spin_lock(pthread_spinlock_t *lock);
int pthread_spin_trylock(pthread_spinlock_t *lock);

DESCRIPTION

La fonction pthread_spin_lock() verrouille le verrou par rotation référencé par lock. Le thread appelant acquiert le verrou s'il n'est pas détenu par un autre thread. Sinon, le thread tourne (c'est-à-dire, ne retourne pas de l'appel pthread_spin_lock()) jusqu'à ce que le verrou devienne disponible. Les résultats sont indéfinis si le thread appelant détient le verrou au moment de l'appel. La fonction pthread_spin_trylock() verrouille le verrou par rotation référencé par lock s'il n'est détenu par aucun thread. Sinon, la fonction échoue.

Les résultats sont indéfinis si l'une de ces fonctions est appelée avec un verrou par rotation non initialisé.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent zéro ; sinon, un numéro d'erreur est retourné pour indiquer l'erreur.

ERREURS

La fonction pthread_spin_lock() peut échouer si :

EDEADLK
Une condition de interblocage a été détectée.

La fonction pthread_spin_trylock() échoue si :

EBUSY
Un thread détient actuellement le verrou.

Ces fonctions ne retournent pas de code d'erreur [EINTR].

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION APPLICATION

Les applications utilisant cette fonction peuvent être sujettes à l'inversion de priorité, comme discuté dans le volume des Définitions de base de POSIX.1‐2017, Section 3.291, Inversion de priorité.

RATIONALE

Si une implémentation détecte que la valeur spécifiée par l'argument lock de pthread_spin_lock() ou pthread_spin_trylock() ne fait pas référence à un objet de verrouillage par rotation initialisé, il est recommandé que la fonction échoue et signale une erreur [EINVAL].

Si une implémentation détecte que la valeur spécifiée par l'argument lock de pthread_spin_lock() fait référence à un objet de verrouillage par rotation que le thread appelant détient déjà, il est recommandé que la fonction échoue et signale une erreur [EDEADLK].
