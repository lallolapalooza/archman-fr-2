NOM

pt-eustack-resolver - Obtenir des traces de pile pour un programme sélectionné avec "eu-stack" et résoudre les symboles.

SYNTAXE

Utilisation : pt-eustack-resolver <pid>

pt-eustack-resolver collecte les traces de pile pour le processus spécifié par "pid".

RISQUES

Percona Toolkit est mature, éprouvé en production et bien testé, mais tous les outils de base de données peuvent présenter un risque pour le système et le serveur de base de données. Avant d'utiliser cet outil, veuillez :

  • Lire la documentation de l'outil
  • Consulter les "BUGS" connus de l'outil
  • Tester l'outil sur un serveur non productif
  • Sauvegarder votre serveur de production et vérifier les sauvegardes

DESCRIPTION

pt-eustack-resolver est l'outil qui obtient des traces de pile pour un programme sélectionné avec "eu-stack" et résout les symboles. C'est un outil compagnon pour pt-pmp, appelé lorsque l'option "--dumper=pteu" est spécifiée.

"eu-stack" est un outil du package elfutils https://sourceware.org/elfutils qui affiche une pile pour chaque thread dans un processus ou un fichier core. "eu-stack" est plus rapide que gdb et a une surcharge plus faible sur le processus diagnostiqué.

SORTIE

Pile pour chaque thread, formatée de manière similaire à la sortie de "gdb thread apply all bt".

ATTENTION

L'utilisation de <PTDEBUG> peut exposer des mots de passe. Lorsque le débogage est activé, tous les paramètres de la ligne de commande sont affichés dans la sortie.

EXIGENCES SYSTÈME

Vous avez besoin de "eu-stack" du package elfutils https://sourceware.org/elfutils.

BOGUES

Pour une liste des bogues connus, voir https://jira.percona.com/projects/PT/issues.

Veuillez signaler les bogues à https://jira.percona.com/projects/PT. Incluez les informations suivantes dans votre rapport de bogue :

  • Commande complète utilisée pour exécuter l'outil
  • Version de l'outil "--version"
  • Version MySQL de tous les serveurs impliqués
  • Sortie de l'outil, y compris STDERR
  • Fichiers d'entrée (fichiers journaux/dump/config, etc.)

Si possible, incluez la sortie de débogage en exécutant l'outil avec "PTDEBUG" ; voir "ENVIRONNEMENT".
