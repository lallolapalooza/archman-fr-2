Ptyxis(1) Manuel des commandes générales Ptyxis(1)

NOM

ptyxis - un terminal orienté conteneurs

SYNTAXE

ptyxis [OPTION]... [-- PROGRAMME ARGUMENTS]

DESCRIPTION

ptyxis est un terminal orienté conteneurs, conçu pour le bureau GNOME. Il offre une intégration étroite avec podman, toolbox, distrobox et jhbuild pour simplifier le développement et la gestion du système basés sur des conteneurs.

--version
Afficher la version du programme.
--preferences
Afficher la fenêtre des préférences.
--new-window
Ouvrir une nouvelle fenêtre dans une instance existante de Ptyxis. Si Ptyxis n'est pas en cours d'exécution, une nouvelle instance est lancée.

Peut être combiné avec les options --working-directory, --execute et --title.

--tab
Ouvrir un nouvel onglet dans la fenêtre la plus récemment utilisée d'une instance Ptyxis existante. Si Ptyxis n'est pas en cours d'exécution, une nouvelle instance est lancée.

Peut être combiné avec les options --working-directory, --execute et --title.

-x, --execute
Exécuter une commande personnalisée.

Ceci est similaire à l'utilisation de -- pour fournir la commande personnalisée, sauf que toute la ligne de commande doit être fournie en tant qu'argument unique.

En général, vous devriez utiliser -- à la place de cette option. Elle est principalement disponible pour être similaire à bash -c 'command'

Peut être combiné avec les options --working-directory et --title.

-d, --working-directory
Définir le répertoire de travail actuel pour un nouvel onglet [--tab], une nouvelle fenêtre [--window], ou une commande personnalisée [-- COMMAND...].
--title=TITLE
Définit le titre d'une nouvelle page de terminal créée avec --tab ou --new-window.
--maximize
Maximiser une fenêtre nouvellement créée.
--fullscreen
Mettre en plein écran une fenêtre nouvellement créée.
--tab-with-profile=PROFILE
Crée un nouvel onglet dans une instance existante en utilisant le profil spécifié. Le profil doit être une chaîne UUID qui peut être trouvée dans l'éditeur de profil de la boîte de dialogue des préférences.
-s, --standalone
Lancer une nouvelle instance de Ptyxis, en mode instance unique, en ignorant toute instance déjà en cours d'exécution.

Le mode instance unique est implicite lors de l'exécution d'une commande --.

-s, --gapplication-app-id=ID
Remplace l'identifiant de l'application ID en mode instance unique.
-h, --help
Afficher un résumé des options.
Les autres options GNOME standard non listées ici sont également prises en charge.
