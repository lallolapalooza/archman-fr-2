NOM

pt-mext - Examiner côte à côte plusieurs échantillons de "SHOW GLOBAL STATUS" de MySQL.

SYNOPIS

Usage : pt-mext [OPTIONS] -- COMMANDE

pt-mext colonne les sorties répétées d'un programme comme mysqladmin extended.

Obtenir la sortie de "mysqladmin" :

pt-mext -r -- mysqladmin ext -i10 -c3

Obtenir la sortie d'un fichier :

pt-mext -r -- cat mysqladmin-output.txt

RISQUES

Percona Toolkit est mature, éprouvé sur le terrain et bien testé, mais tous les outils de base de données peuvent présenter un risque pour le système et le serveur de base de données. Avant d'utiliser cet outil, veuillez :

  • Lire la documentation de l'outil
  • Examiner les "BUGS" connus de l'outil
  • Tester l'outil sur un serveur non-production
  • Sauvegarder votre serveur de production et vérifier les sauvegardes

DESCRIPTION

pt-mext exécute la "COMMANDE" que vous spécifiez, et lit le résultat ligne par ligne. Il place chaque ligne dans un fichier temporaire. Lorsqu'il trouve une ligne vide, il suppose qu'un nouvel échantillon de SHOW GLOBAL STATUS démarre, et il crée un nouveau fichier temporaire. À la fin de ce processus, il a un certain nombre de fichiers temporaires. Il joint les fichiers temporaires côte à côte et affiche le résultat. Si l'option "--relative" est donnée, il soustrait d'abord chaque échantillon du suivant avant d'afficher les résultats.

OPTIONS

--help
Afficher l'aide et quitter.
--relative
forme courte : -r

Soustrait chaque colonne de la colonne précédente.

--version
Afficher la version et quitter.

ENVIRONNEMENT

Cet outil n'utilise aucune variable d'environnement.

EXIGENCES SYSTÈME

Cet outil nécessite le shell Bourne (/bin/sh) et le programme seq.

BUGS

Pour une liste des bugs connus, voir https://jira.percona.com/projects/PT/issues.

Veuillez signaler les bugs à https://jira.percona.com/projects/PT. Incluez les informations suivantes dans votre rapport de bug :

  • Commande complète utilisée pour exécuter l'outil
  • "--version" de l'outil
  • Version MySQL de tous les serveurs impliqués
  • Sortie de l'outil, y compris STDERR
  • Fichiers d'entrée (fichiers log/dump/config, etc.)

Si possible, incluez la sortie de débogage en exécutant l'outil avec "PTDEBUG" ; voir "ENVIRONNEMENT".

ATTENTION

L'utilisation de <PTDEBUG> peut exposer les mots de passe. Lorsque le débogage est activé, tous les paramètres de la ligne de commande sont affichés dans la sortie.
