pthread_sigqueue(3) Manuel des fonctions de bibliothèque pthread_sigqueue(3)

NOM

pthread_sigqueue - met en file d'attente un signal et des données pour un thread

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <signal.h>
#include <pthread.h>
int pthread_sigqueue(pthread_t thread, int sig,
                     const union sigval value);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

pthread_sigqueue():

    _GNU_SOURCE

DESCRIPTION

La fonction pthread_sigqueue() effectue une tâche similaire à sigqueue(3), mais, au lieu d'envoyer un signal à un processus, elle envoie un signal à un thread du même processus que le thread appelant.

L'argument thread est l'identifiant d'un thread du même processus que l'appelant. L'argument sig spécifie le signal à envoyer. L'argument value spécifie les données accompagnant le signal ; voir sigqueue(3) pour plus de détails.

VALEUR DE RETOUR

En cas de succès, pthread_sigqueue() retourne 0 ; en cas d'erreur, elle retourne un numéro d'erreur.

ERREURS

EAGAIN
La limite des signaux pouvant être mis en file d'attente a été atteinte. (Voir signal(7) pour plus d'informations.)
EINVAL
sig était invalide.
ENOSYS
pthread_sigqueue() n'est pas pris en charge sur ce système.
ESRCH
thread n'est pas valide.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_sigqueue () Sécurité des threads MT-Safe

VERSIONS

L'implémentation glibc de pthread_sigqueue() renvoie une erreur (EINVAL) lors des tentatives d'envoi de l'un des signaux temps réel utilisés en interne par l'implémentation de threading NPTL. Voir nptl(7) pour les détails.

NORMES

GNU.

HISTORIQUE

glibc 2.11.

VOIR AUSSI

rt_tgsigqueueinfo(2), sigaction(2), pthread_sigmask(3), sigqueue(3), sigwait(3), pthreads(7), signal(7)
