pthread_yield(3) Manuel des fonctions de bibliothèque pthread_yield(3)

NOM

pthread_yield - céder le processeur

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#define _GNU_SOURCE             /* Voir feature_test_macros(7) */
#include <pthread.h>
[[deprecated]] int pthread_yield(void);

DESCRIPTION

Note : Cette fonction est obsolète ; voir ci-dessous.

pthread_yield() fait céder le CPU au thread appelant. Le thread est placé à la fin de la file d'attente d'exécution pour sa priorité statique et un autre thread est planifié pour s'exécuter. Pour plus de détails, voir sched_yield(2)

VALEUR DE RETOUR

En cas de succès, pthread_yield() retourne 0 ; en cas d'erreur, il retourne un numéro d'erreur.

ERREURS

Sous Linux, cet appel réussit toujours (mais les applications portables et pérennes devraient néanmoins gérer un possible retour d'erreur).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_yield () Sécurité des threads MT-Safe

VERSIONS

Sous Linux, cette fonction est implémentée comme un appel à sched_yield(2).

NORMES

Aucune.

HISTORIQUE

Obsolète depuis glibc 2.34. Utiliser plutôt le standard sched_yield(2).

NOTES

pthread_yield() est destiné à être utilisé avec les politiques de planification temps réel (c'est-à-dire SCHED_FIFO ou SCHED_RR). L'utilisation de pthread_yield() avec des politiques de planification non déterministes telles que SCHED_OTHER n'est pas spécifiée et signifie très probablement que la conception de votre application est défectueuse.

VOIR AUSSI

sched_yield(2), pthreads(7), sched(7)
