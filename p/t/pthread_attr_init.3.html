pthread_attr_init(3) Manuel des fonctions de bibliothèque pthread_attr_init(3)

NOM

pthread_attr_init, pthread_attr_destroy - initialiser et détruire un objet d'attributs de thread

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <pthread.h>
int pthread_attr_init(pthread_attr_t *attr);
int pthread_attr_destroy(pthread_attr_t *attr);

DESCRIPTION

La fonction pthread_attr_init() initialise l'objet d'attributs de thread pointé par attr avec des valeurs d'attribut par défaut. Après cet appel, les attributs individuels de l'objet peuvent être définis à l'aide de diverses fonctions associées (listées dans VOIR AUSSI), puis l'objet peut être utilisé dans un ou plusieurs appels à pthread_create(3) qui créent des threads.

Appeler pthread_attr_init() sur un objet d'attributs de thread déjà initialisé entraîne un comportement indéfini.

Lorsqu'un objet d'attributs de thread n'est plus requis, il doit être détruit à l'aide de la fonction pthread_attr_destroy(). La destruction d'un objet d'attributs de thread n'a aucun effet sur les threads qui ont été créés à l'aide de cet objet.

Une fois qu'un objet d'attributs de thread a été détruit, il peut être réinitialisé à l'aide de pthread_attr_init(). Toute autre utilisation d'un objet d'attributs de thread détruit a des résultats indéfinis.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent 0 ; en cas d'erreur, elles retournent un numéro d'erreur non nul.

ERREURS

POSIX.1 documente une erreur ENOMEM pour pthread_attr_init ; sous Linux, ces fonctions réussissent toujours (mais les applications portables et pérennes devraient néanmoins gérer un possible retour d'erreur).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
pthread_attr_init (), pthread_attr_destroy () Sécurité des threads MT-Safe

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

NOTES

Le type pthread_attr_t doit être traité comme opaque : tout accès à l'objet autre que via les fonctions pthreads est non portable et produit des résultats indéfinis.

EXEMPLES

Le programme ci-dessous utilise éventuellement pthread_attr_init() et diverses fonctions associées pour initialiser un objet d'attributs de thread qui est utilisé pour créer un seul thread. Une fois créé, le thread utilise la fonction pthread_getattr_np(3) (une extension non standard de GNU) pour récupérer les attributs du thread, puis affiche ces attributs.

Si le programme est exécuté sans argument de ligne de commande, il passe NULL comme argument attr de pthread_create(3), de sorte que le thread est créé avec des attributs par défaut. En exécutant le programme sous Linux/x86-32 avec l'implémentation de threads NPTL, nous obtenons le résultat suivant :


$ ulimit -s       # Pas de limite de pile ==> la taille de pile par défaut est de 2 Mo
unlimited
$ ./a.out
Attributs du thread :
        État de détachement = PTHREAD_CREATE_JOINABLE
        Portée             = PTHREAD_SCOPE_SYSTEM
        Ordonnancement hérité = PTHREAD_INHERIT_SCHED
        Politique d'ordonnancement = SCHED_OTHER
        Priorité d'ordonnancement = 0
        Taille de garde         = 4096 octets
        Adresse de pile        = 0x40196000
        Taille de pile         = 0x201000 octets

Lorsque nous fournissons une taille de pile comme argument de ligne de commande, le programme initialise un objet d'attributs de thread, définit divers attributs dans cet objet et passe un pointeur vers l'objet dans l'appel à pthread_create(3). En exécutant le programme sous Linux/x86-32 avec l'implémentation de threads NPTL, nous obtenons le résultat suivant :


$ ./a.out 0x3000000
posix_memalign() alloué à 0x40197000
Attributs du thread :
        État de détachement = PTHREAD_CREATE_DETACHED

    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_getschedparam");

    s = pthread_attr_getguardsize(attr, &v);
    if (s != 0)

    printf("%sTaille de pile         = %#zx octets\n", prefix, v);

    s = pthread_getattr_np(pthread_self(), &gattr);

    printf("Attributs du thread :\n");
    display_pthread_attr(&gattr, "\t");
    exit(EXIT_SUCCESS);         /* Terminer tous les threads */
}

pthread_attr_init(3) — manpages.debian.org

NAME

pthread_attr_init — initialize thread attributes object

LIBRARY

– POSIX Threads Library

SYNOPSIS

#include <pthread.h>

int
pthread_attr_init(pthread_attr_t *attr);

DESCRIPTION

The pthread_attr_init() function shall initialize the thread attributes object pointed to by attr with default attribute values.

The default values for the attributes are implementation-defined. However, the default values shall be such that a thread created using the initialized attributes object will be joinable, have the default scheduling policy and priority, have the same scheduling inheritance mode as the creating thread, have a stack size sufficient to meet the system's default requirements, and have stack address requirements that are satisfied by the implementation. The default detach-state shall be PTHREAD_CREATE_JOINABLE.

The attributes object may be used in subsequent calls to pthread_attr_setdetachstate(3), pthread_attr_setschedparam(3), pthread_attr_setschedpolicy(3), pthread_attr_setscope(3), pthread_attr_setinheritsched(3), pthread_attr_setstack(3), pthread_attr_setstackaddr(3), pthread_attr_setstacksize(3), pthread_attr_setguardsize(3), pthread_attr_setaffinity_np(3), and pthread_attr_setsigmask_np(3) to set various attributes.

It is recommended that an application should not use a pthread_attr_t object after it has been destroyed by pthread_attr_destroy(3).

RETURN VALUE

On success, pthread_attr_init() shall return 0; otherwise, an error number shall be returned to indicate the error.

ERRORS

The pthread_attr_init() function may fail if:

ENOMEM
Insufficient memory is available to initialize the thread attributes object.

ATTRIBUTES

CONCURRENCY INFORMATION

For functions with this attribute, the concurrency requirements specified in pthreads(7) apply.

STANDARDS

The pthread_attr_init() function conforms to Version 2 of the POSIX.1-2001 standard.

HISTORY

Version GLIBC_2.0

The pthread_attr_init() function was added in glibc 2.0.

NOTES

Before calling pthread_attr_init(), the pthread_attr_t object must be valid but uninitialized.

A thread attributes object is typically declared as a pthread_attr_t variable on the stack.

EXAMPLES

The following example shows how to initialize a thread attributes object and set some of its attributes:

#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <errno.h>

#define errc(exit_status, error_code, msg) \
    do { \
        fprintf(stderr, "%s: %s (%d)\n", msg, strerror(error_code), error_code); \
        exit(exit_status); \
    } while (0)

void *thread_start(void *arg) {
    printf("Thread started.\n");
    sleep(1); // Simulate work
    printf("Thread finished.\n");
    return NULL;
}

int main(int argc, char *argv[]) {
    pthread_t thr;
    pthread_attr_t attr;
    void *sp;
    size_t stack_size;
    int s;

    // Initialize attributes object
    s = pthread_attr_init(&attr);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_init");

    // Set detach state to detached
    s = pthread_attr_setdetachstate(&attr, PTHREAD_CREATE_DETACHED);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_setdetachstate");

    // Set scheduling policy to explicit
    s = pthread_attr_setinheritsched(&attr, PTHREAD_EXPLICIT_SCHED);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_setinheritsched");

    // Get stack size from command line argument or use a default
    if (argc > 1) {
        stack_size = strtoul(argv[1], NULL, 0);
        if (stack_size == 0) {
            fprintf(stderr, "Invalid stack size provided: %s\n", argv[1]);
            exit(EXIT_FAILURE);
        }
    } else {
        // Default stack size (e.g., 1MB)
        stack_size = 1024 * 1024;
        printf("Using default stack size: %zu bytes\n", stack_size);
    }

    // Allocate memory for the stack, aligned to page size
    s = posix_memalign(&sp, sysconf(_SC_PAGESIZE), stack_size);
    if (s != 0)
        errc(EXIT_FAILURE, s, "posix_memalign");
    printf("posix_memalign() allocated stack at %p\n", sp);

    // Set the stack attributes
    s = pthread_attr_setstack(&attr, sp, stack_size);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_setstack");

    // Create the thread
    s = pthread_create(&thr, &attr, &thread_start, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_create");

    // Destroy the attributes object
    s = pthread_attr_destroy(&attr);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_destroy");

    printf("Main thread continuing...\n");

    // In this example, we'll let the main thread exit,
    // and the detached thread will continue running.
    // If you wanted the main thread to wait, you could use pthread_join
    // or pause() as in the original example.
    // pause(); // Terminates when other thread calls exit()

    // Free the allocated stack memory when done (though in this simple example,
    // the process exits before we get a chance to free it).
    // For a long-running application, you'd need to manage this properly.
    // free(sp); // This line would typically be placed where it's safe to free.

    return 0;
}
