pthread_mutexattr_setrobust(3) Manuel des fonctions de bibliothèque pthread_mutexattr_setrobust(3)

NOM

pthread_mutexattr_getrobust, pthread_mutexattr_setrobust - obtenir et définir l'attribut de robustesse d'un objet d'attributs de mutex

BIBLIOTHÈQUE

Bibliothèque POSIX threads (libpthread, -lpthread)

SYNTAXE

#include <pthread.h>
int pthread_mutexattr_getrobust(const pthread_mutexattr_t *attr,
                                int *robustness);
int pthread_mutexattr_setrobust(pthread_mutexattr_t *attr,
                                int robustness);
Exigences de macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

pthread_mutexattr_getrobust(), pthread_mutexattr_setrobust():

    _POSIX_C_SOURCE >= 200809L

DESCRIPTION

La fonction pthread_mutexattr_getrobust() place la valeur de l'attribut de robustesse de l'objet d'attributs de mutex référencé par attr dans *robustness. La fonction pthread_mutexattr_setrobust() définit la valeur de l'attribut de robustesse de l'objet d'attributs de mutex référencé par attr à la valeur spécifiée dans *robustness.

L'attribut de robustesse spécifie le comportement du mutex lorsque le thread propriétaire meurt sans déverrouiller le mutex. Les valeurs suivantes sont valides pour robustness:

PTHREAD_MUTEX_STALLED
C'est la valeur par défaut pour un objet d'attributs de mutex. Si un mutex est initialisé avec l'attribut PTHREAD_MUTEX_STALLED et que son propriétaire meurt sans le déverrouiller, le mutex reste verrouillé par la suite et toute tentative future d'appel à pthread_mutex_lock(3) sur le mutex sera bloquée indéfiniment.
PTHREAD_MUTEX_ROBUST
Si un mutex est initialisé avec l'attribut PTHREAD_MUTEX_ROBUST et que son propriétaire meurt sans le déverrouiller, toute tentative future d'appel à pthread_mutex_lock(3) sur ce mutex réussira et retournera EOWNERDEAD pour indiquer que le propriétaire d'origine n'existe plus et que le mutex est dans un état incohérent. Généralement, après le retour de EOWNERDEAD, le propriétaire suivant devrait appeler pthread_mutex_consistent(3) sur le mutex acquis pour le rendre cohérent à nouveau avant de l'utiliser davantage.
Si le propriétaire suivant déverrouille le mutex à l'aide de pthread_mutex_unlock(3) avant de le rendre cohérent, le mutex deviendra définitivement inutilisable et toute tentative ultérieure de le verrouiller à l'aide de pthread_mutex_lock(3) échouera avec l'erreur ENOTRECOVERABLE. La seule opération autorisée sur un tel mutex est pthread_mutex_destroy(3).
Si le propriétaire suivant termine avant d'appeler pthread_mutex_consistent(3), les futures opérations pthread_mutex_lock(3) sur ce mutex retourneront toujours EOWNERDEAD.

Notez que l'argument attr de pthread_mutexattr_getrobust() et pthread_mutexattr_setrobust() doit se référer à un objet d'attributs de mutex qui a été initialisé par pthread_mutexattr_init(3), sinon le comportement est indéfini.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent 0. En cas d'erreur, elles retournent un numéro d'erreur positif.

Dans l'implémentation glibc, pthread_mutexattr_getrobust() retourne toujours zéro.

ERREURS

EINVAL
Une valeur autre que PTHREAD_MUTEX_STALLED ou PTHREAD_MUTEX_ROBUST a été passée à pthread_mutexattr_setrobust().

VERSIONS

Dans l'implémentation Linux, lors de l'utilisation de mutex robustes partagés entre processus, un thread en attente reçoit également la notification EOWNERDEAD si le propriétaire d'un mutex robuste effectue un execve(2) sans déverrouiller au préalable le mutex. POSIX.1 ne spécifie pas ce détail, mais le même comportement se produit également dans au moins certaines autres implémentations.

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.12. POSIX.1-2008.

Avant l'ajout de pthread_mutexattr_getrobust() et pthread_mutexattr_setrobust() à POSIX, glibc définissait les fonctions non standard équivalentes suivantes si _GNU_SOURCE était défini:

[[deprecated]]
int pthread_mutexattr_getrobust_np(const pthread_mutexattr_t *attr,
                                   int *robustness);
[[deprecated]]
int pthread_mutexattr_setrobust_np(const pthread_mutexattr_t *attr,
                                   int robustness);

Par conséquent, les constantes PTHREAD_MUTEX_STALLED_NP et PTHREAD_MUTEX_ROBUST_NP étaient également définies.

Ces API spécifiques à GNU, apparues pour la première fois dans glibc 2.4, sont aujourd'hui obsolètes et ne doivent pas être utilisées dans de nouveaux programmes ; depuis glibc 2.34, ces API sont marquées comme obsolètes.

EXEMPLES

Le programme ci-dessous démontre l'utilisation de l'attribut de robustesse d'un objet d'attributs de mutex. Dans ce programme, un thread détenant le mutex meurt prématurément sans déverrouiller le mutex. Le thread principal acquiert ensuite le mutex avec succès et obtient l'erreur EOWNERDEAD, après quoi il rend le mutex cohérent.

La session shell suivante montre ce que nous voyons en exécutant ce programme:


$ ./a.out;
[propriétaire d'origine] Setting lock...
[propriétaire d'origine] Locked.  Now exiting without unlocking.
[main] Tentative de verrouillage du mutex robuste.
[main] pthread_mutex_lock() a retourné EOWNERDEAD
[main] Maintenant, rendre le mutex cohérent
[main] Le mutex est maintenant cohérent; déverrouillage

Source du programme

#include <err.h>
#include <errno.h>
#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
static pthread_mutex_t mtx;
static void *
original_owner_thread(void *ptr)
{
    printf("[propriétaire d'origine] Setting lock...\n");
    pthread_mutex_lock(&mtx);
    printf("[propriétaire d'origine] Locked.  Now exiting without unlocking.\n");
    pthread_exit(NULL);
}
int
main(void)
{
    pthread_t thr;
    pthread_mutexattr_t attr;
    int s;
    pthread_mutexattr_init(&attr);
    pthread_mutexattr_setrobust(&attr, PTHREAD_MUTEX_ROBUST);
    pthread_mutex_init(&mtx, &attr);
    pthread_create(&thr, NULL, original_owner_thread, NULL);
    sleep(2);
    /* "original_owner_thread" aurait dû se terminer à ce moment-là.  */
    printf("[main] Tentative de verrouillage du mutex robuste.\n");
    s = pthread_mutex_lock(&mtx);
    if (s == EOWNERDEAD) {
        printf("[main] pthread_mutex_lock() a retourné EOWNERDEAD\n");
        printf("[main] Maintenant, rendre le mutex cohérent\n");
        s = pthread_mutex_consistent(&mtx);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_mutex_consistent");
        printf("[main] Le mutex est maintenant cohérent ; déverrouillage\n");
        s = pthread_mutex_unlock(&mtx);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_mutex_unlock");
        exit(EXIT_SUCCESS);
    } else if (s == 0) {
        printf("[main] pthread_mutex_lock() a réussi de manière inattendue\n");
        exit(EXIT_FAILURE);
    } else {
        printf("[main] pthread_mutex_lock() a échoué de manière inattendue\n");
        errc(EXIT_FAILURE, s, "pthread_mutex_lock");
    }
}
