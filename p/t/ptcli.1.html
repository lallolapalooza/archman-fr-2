ptcli() ptcli()

Nom

ptcli - Une CLI pour interagir avec phosh-thumbnailer.

Syntaxe

ptcli [OPTION…] /chemin/vers/repertoire

ptcli [OPTION…] /chemin/vers/fichier_1 /chemin/vers/fichier_2 …

ptcli [OPTION…] --stop

Description

ptcli peut être utilisé pour interagir avec le service phosh-thumbnailer(8). Il est principalement utilisé pour créer des miniatures conformément à la norme de gestion des miniatures https://specifications.freedesktop.org/thumbnail-spec/latest/.

-h, --help
Affiche les options d'aide et quitte.
-s, --stop
Arrête l'opération de création de miniatures en cours.
-v, --version
Affiche la version et quitte.

Exemples

Pour créer des miniatures pour tous les fichiers du répertoire courant :

ptcli .

Pour créer des miniatures pour tous les fichiers dans $HOME/Pictures :

ptcli $HOME/Pictures

Pour créer des miniatures pour un ensemble de fichiers :

ptcli $HOME/Pictures/foo.png bar.txt ../spam.ogg

Pour arrêter l'opération de création de miniatures en cours :

ptcli --stop
