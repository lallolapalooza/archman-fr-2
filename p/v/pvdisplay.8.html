DESCRIPTION

pvdisplay affiche les attributs des PV, comme la taille, la taille des extensions physiques, l'espace utilisé pour la zone de descripteur VG, etc.

pvs(8) est une alternative préférée qui affiche les mêmes informations et plus encore, en utilisant un format de sortie plus compact et configurable.

UTILISATION

pvdisplay

[ -m|--maps ]
[ -s|--short ]
[ OPTIONS_COMMUNES ]
[ PV|Tag ... ]

OPTIONS

--aligned
Utiliser avec --separator pour aligner les colonnes de sortie.
-a|--all
Affiche les informations relatives aux périphériques qui n'ont pas été initialisés par LVM, c'est-à-dire qu'ils ne sont pas des PV.
--binary
Utilise les valeurs binaires "0" ou "1" au lieu des valeurs littérales descriptives pour les colonnes qui ont exactement deux valeurs valides à rapporter (sans compter la valeur "unknown" qui indique que la valeur n'a pas pu être déterminée).
-c|--colon
Génère une sortie séparée par des deux-points pour faciliter l'analyse dans les scripts ou les programmes. Voir aussi pvs(8) qui offre un contrôle considérablement plus important sur la sortie. Les valeurs sont :
  • Nom du périphérique du volume physique
  • Nom du groupe de volumes
  • Taille du volume physique en secteurs
  • Numéro interne du volume physique (obsolète)
  • Statut du volume physique
  • Volume physique (non) allouable
  • Nombre actuel de volumes logiques sur ce volume physique
  • Taille de l'extension physique en kilooctets
  • Nombre total d'extensions physiques
  • Nombre d'extensions physiques libres
  • Nombre d'extensions physiques allouées
-C|--columns
Affiche la sortie en colonnes. L'équivalent de pvs(8). Les options listées sont les mêmes que les options données dans pvs(8).
--commandprofile Chaîne
Le profil de commande à utiliser pour la configuration de la commande. Voir lvm.conf(5) pour plus d'informations sur les profils.
--config Chaîne
Paramètres de configuration pour la commande. Ils remplacent les paramètres de lvm.conf(5). La chaîne d'arguments utilise le même format que lvm.conf(5), ou peut utiliser la syntaxe section/champ. Voir lvm.conf(5) pour plus d'informations sur la configuration.
--configreport log|vg|lv|pv|pvseg|seg
Voir lvmreport(7).
-d|--debug ...
Définit le niveau de débogage. Répétez de 1 à 6 fois pour augmenter le détail des messages envoyés au fichier journal et/ou à syslog (si configuré).
--devices PV
Restreint les périphériques qui sont visibles et accessibles à la commande. Les périphériques non listés seront
ppear to be missing. This option can be repeated, or accepts a comma separated list of devices. This overrides the devices file.
--devicesfile String
Un fichier listant les périphériques que LVM doit utiliser. Le fichier doit exister dans /etc/lvm/devices/ et est géré avec la commande lvmdevices(8). Ceci remplace les paramètres devices/devicesfile et devices/use_devicesfile de lvm.conf(5).
--driverloaded o|n
Si réglé sur non, la commande ne tentera pas d'utiliser device-mapper. Pour les tests et le débogage.
--foreign
Signaler/afficher les VG étrangers qui seraient autrement ignorés. Voir lvmsystemid(7) pour plus d'informations sur les VG étrangers.
--headings none|abbrev|full|0|1|2
Type d'en-têtes à utiliser dans la sortie du rapport. none ou 0 : Pas d'en-têtes. abbrev ou 1 : Abréviations des noms de colonnes. full ou 2 : Noms de colonnes complets.
-h|--help
Afficher le texte d'aide.
--ignorelockingfailure
Permet à une commande de continuer avec des opérations de métadonnées en lecture seule après des échecs de verrouillage.
--journal String
Enregistrer des informations dans le journal systemd. Ces informations s'ajoutent aux informations activées par le paramètre log/journal de lvm.conf. command : enregistrer des informations sur la commande. output : enregistrer la sortie de commande par défaut. debug : enregistrer le débogage complet de la commande.
--lockopt String
Utilisé pour passer des options pour des cas spéciaux à lvmlockd. Voir lvmlockd(8) pour plus d'informations.
--logonly
Supprimer le rapport de commande et n'afficher que le rapport de journalisation.
--longhelp
Afficher le texte d'aide détaillé.
-m|--maps
Afficher le mappage des extentions physiques vers les LVs et les extentions logiques.
--nameprefixes
Ajouter un préfixe "LVM2_" suivi du nom du champ à la sortie. Utile avec --noheadings pour produire une liste de paires champ=valeur qui peuvent être utilisées pour définir des variables d'environnement (par exemple, dans les règles udev).
--noheadings
Supprimer la ligne d'en-têtes qui est normalement la première ligne de la sortie. Utile lors de l'utilisation de grep sur la sortie.
--nohints
Ne pas utiliser le fichier d'indices pour localiser les périphériques des PV. Une commande peut lire plus de périphériques pour trouver les PV lorsque les indices ne sont pas utilisés. La commande effectuera toujours une invalidation standard du fichier d'indices si nécessaire.
--nolocking
Désactiver le verrouillage. À utiliser avec prudence, les commandes concurrentes peuvent produire des résultats incorrects.
--nosuffix
Supprimer le suffixe des tailles de sortie. À utiliser avec --units (sauf h et H) si vous traitez la sortie.
-o|--options String
Liste de champs, séparés par des virgules et ordonnés, à afficher en colonnes. La syntaxe de l'argument String est : [+|-|#]Champ1[,Champ2 ...] Le préfixe + ajoutera les champs spécifiés aux champs par défaut, - supprimera les champs spécifiés des champs par défaut, et # compactera les champs spécifiés (les supprimant lorsqu'ils sont vides pour toutes les lignes). Utiliser -o help pour voir la liste de tous les champs disponibles. Utiliser des listes de champs séparées pour ajouter, supprimer ou compacter en répétant l'option -o : -o+champ1,champ2 -o-champ3,champ4 -o#champ5. Ces listes sont évaluées de gauche à droite. Utiliser le nom de champ lv_all pour voir tous les champs LV, vg_all tous les champs VG, pv_all tous les champs PV, seg_all tous les champs de segments LV, et pvseg_all tous les champs de segments PV. Voir la section de rapport de lvm.conf(5) pour plus d'options de configuration. Voir lvmreport(7) pour plus d'informations sur les rapports.
--profile String
Un alias pour --commandprofile ou --metadataprofile, en fonction de la commande.
-q|--quiet ...
Supprimer la sortie et les messages de journalisation. Remplace --debug et --verbose. Répéter une fois pour également supprimer toutes les invites avec la réponse 'non'.
--readonly
Empêcher la commande d'apporter des modifications, y compris l'activation et les mises à jour des métadonnées. (Voir --permission r pour les LVs en lecture seule.)
--reportformat basic|json|json_std
Remplace le format de sortie actuel pour les rapports qui est défini globalement par le paramètre report/output_format dans lvm.conf(5). basic est le format original avec des colonnes et des lignes. S'il y a plus d'un rapport par commande, chaque rapport est préfixé du nom du rapport pour identification. json produit la sortie du rapport au format JSON. json_std produit la sortie du rapport au format JSON qui est plus conforme à la norme JSON. Voir lvmreport(7) pour plus d'informations.
--rows
Afficher les colonnes sous forme de lignes.
--segments
-S|--select String
Sélectionner les objets à traiter et à signaler en fonction de critères spécifiés. La syntaxe des critères est décrite par --select help et lvmreport(7). Pour les commandes de rapport, une ligne est affichée pour chaque objet correspondant aux critères. Voir --options help pour les champs d'objets sélectionnables. Les lignes peuvent être affichées avec un champ supplémentaire "selected" (-o selected) indiquant 1 si la ligne correspond à la sélection et 0 sinon. Pour les commandes qui ne génèrent pas de rapports et qui traitent des entités LVM, la sélection est utilisée pour choisir les éléments à traiter.
--separator String
Chaîne à utiliser pour séparer chaque colonne. Utile lors de l'utilisation de grep sur la sortie.
--shared
Signaler/afficher les VG partagés qui seraient autrement ignorés lorsque lvmlockd n'est pas utilisé sur l'hôte. Voir lvmlockd(8) pour plus d'informations sur les VG partagés.
-s|--short
Afficher uniquement la taille des PV donnés.
-O|--sort String
Liste ordonnée de colonnes séparées par des virgules pour le tri. Remplace la sélection par défaut. Précéder toute colonne de - pour un tri inversé sur cette colonne.
-t|--test
Exécuter en mode test. Les commandes ne mettront pas à jour les métadonnées. Ceci est implémenté en désactivant toute écriture de métadonnées mais en renvoyant néanmoins un succès à la fonction appelante. Cela peut entraîner des messages d'erreur inhabituels dans les opérations en plusieurs étapes si un outil s'appuie sur la lecture des métadonnées qu'il croit avoir changé, mais qui n'ont pas changé.
--unbuffered
Produire la sortie immédiatement sans trier ou aligner correctement les colonnes.
--units [Number]r|R|h|H|b|B|s|S|k|K|m|M|g|G|t|T|p|P|e|E
Toutes les tailles sont affichées dans ces unités : lisibles par l'homme (r)avec indicateur d'arrondi par '<', lisibles par l'homme (h), octets (b|B), secteurs (s|S), kilo-octets (k|K), méga-octets (m|M), giga-octets (g|G), téra-octets (t|T), péta-octets (p|P), exa-octets (e|E). Mettre en majuscule pour utiliser des multiples de 1000 (S.I.) au lieu de 1024. Des unités personnalisées peuvent être spécifiées, par exemple --units 3M.
--unquoted
Lorsqu'il est utilisé avec --nameprefixes, les valeurs de sortie dans les paires champ=valeur ne sont pas mises entre guillemets.
-v|--verbose ...
Définir le niveau de verbosité. Répéter de 1 à 4 fois pour augmenter le détail des messages envoyés à stdout et stderr.
--version
Afficher les informations de version.
-y|--yes
Ne pas demander de confirmation interactivement mais toujours supposer la réponse oui. À utiliser avec une extrême prudence. (Pour un non automatique, voir -qq.)

VARIABLES

PV
Nom du Volume Physique (Physical Volume), un chemin de périphérique sous /dev. Pour les commandes qui gèrent des extentions physiques, un argument positionnel PV accepte généralement un suffixe indiquant une plage (ou plusieurs plages) d'extentions physiques (PE). Lorsque la première PE est omise, elle par défaut au début du périphérique, et lorsque la dernière PE est omise, elle par défaut à la fin.
Plage de début et de fin (inclusive) : PV[:PE-PE] ...
Plage de début et de longueur (en commençant par 0) : PV[:PE+PE] ...
Tag
Nom du tag. Voir lvm(8) pour des informations sur les noms de tags et l'utilisation des tags à la place d'un VG, LV ou PV.
String
Voir la description de l'option pour des informations sur le contenu de la chaîne.
Size[UNIT]
Size est un nombre d'entrée qui accepte une unité optionnelle. Les unités d'entrée sont toujours traitées comme des valeurs de base deux, quelle que soit la casse, par exemple 'k' et 'K' font tous deux référence à 1024. L'unité d'entrée par défaut est spécifiée par la lettre, suivie de |UNIT. UNIT représente d'autres unités d'entrée possibles : b|B sont les octets, s|S sont les secteurs de 512 octets, k|K sont les KiB, m|M sont les MiB,

NAME

pvdisplay — Report properties of physical volumes

SYNOPSIS

pvdisplay [OPTIONS] [PV_NAME [PV_NAME...]]

DESCRIPTION

Collects and displays information about the specified physical volumes. If no physical volume names are specified, all physical volumes are displayed.

The information displayed includes:

  • PV Name
  • VG Name
  • PV Size
  • Attr
  • PE Size
  • Total PE
  • Allocated PE
  • Free PE
  • PV UUID

USAGE

Lists all physical volumes:

        pvdisplay

Lists information about specific physical volumes:

        pvdisplay /dev/sda1 /dev/sdb1

Lists information about a physical volume belonging to a volume group:

        pvdisplay vg0/0

OPTIONS

-c, --colon
Create output in a colon-separated format. This is useful for scripting.
-C, --continuous
Create output in a continuous, colon-separated format. This is useful for scripting.
-j, --uuid
Display the PV UUID instead of the PV name.
-m, --maps
Display physical extent mappings. This is equivalent to pvdisplay -p.
-p, --partial
Display partial information for each physical volume, showing only the PV name, VG name, PV size, and the first and last physical extent numbers. This is useful for very large numbers of physical volumes.
-s, --short
Display only a short information summary about each physical volume. This is equivalent to pvdisplay -p.

VARIABLES

PV_NAME
The name of the physical volume. This can be a device name (e.g., /dev/sda1), a PV UUID (e.g., W1C5p1-h1g8-p11r-m190-f3y7-t5fI-N80M2S), or a name in the format VG_NAME/PV_NUMBER. (e.g., vg0/0).

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables used by lvm. For example, LVM_VG_NAME can generally be substituted for a required VG parameter.
