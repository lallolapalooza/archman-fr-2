NOM

pvs — Afficher des informations sur les volumes physiques

SYNTAXE

pvs
[ arguments_options ]
[ arguments_positionnels ]

DESCRIPTION

pvs produit des sorties formatées sur les PV.

OPTIONS

--aligned
À utiliser avec --separator pour aligner les colonnes de sortie.
-a|--all
Afficher les informations sur les périphériques qui n'ont pas été initialisés par LVM, c'est-à-dire qu'ils ne sont pas des PV.
-A|--allpvs
Afficher les informations sur les PV en dehors du fichier de périphériques. Combiner avec -a|--all pour inclure les périphériques qui ne sont pas des PV.
--binary
Utiliser des valeurs binaires « 0 » ou « 1 » au lieu de valeurs littérales descriptives pour les colonnes qui ont exactement deux valeurs valides à rapporter (sans compter la valeur « unknown » qui indique que la valeur n'a pas pu être déterminée).
--commandprofile Chaîne
Le profil de commande à utiliser pour la configuration de la commande. Voir lvm.conf(5) pour plus d'informations sur les profils.
--config Chaîne
Paramètres de configuration pour la commande. Ceux-ci remplacent les paramètres de lvm.conf(5). L'argument Chaîne utilise le même format que lvm.conf(5), ou peut utiliser la syntaxe section/champ. Voir lvm.conf(5) pour plus d'informations sur la configuration.
--configreport log|vg|lv|pv|pvseg|seg
Voir lvmreport(7).
-d|--debug ...
Définir le niveau de débogage. Répéter de 1 à 6 fois pour augmenter le détail des messages envoyés au fichier journal et/ou à syslog (si configuré).
--devices PV
Restreint les périphériques qui sont visibles et accessibles par la commande. Les périphériques non listés apparaîtront comme manquants. Cette option peut être répétée, ou accepter une liste de périphériques séparés par des virgules. Ceci remplace le fichier de périphériques.
--devicesfile Chaîne
Un fichier listant les périphériques que LVM doit utiliser. Le fichier doit exister dans /etc/lvm/devices/ et est géré avec la commande lvmdevices(8). Ceci remplace les paramètres lvm.conf(5) devices/devicesfile et devices/use_devicesfile.
--driverloaded y|n
Si défini sur non, la commande ne tentera pas d'utiliser device-mapper. Pour les tests et le débogage.
--foreign
Rapporter/afficher les VG étrangers qui seraient autrement ignorés. Voir lvmsystemid(7) pour plus d'informations sur les VG étrangers.
--headings none|abbrev|full|0|1|2
Type d'en-têtes à utiliser dans la sortie du rapport. none ou 0 : Pas d'en-têtes. abbrev ou 1 : Abréviations des noms de colonnes. full ou 2 : Noms complets des colonnes.
-h|--help
Afficher le texte d'aide.
--ignorelockingfailure
Permet à une commande de continuer avec des opérations de métadonnées en lecture seule après des échecs de verrouillage.
--journal Chaîne
Enregistrer des informations dans le journal systemd. Ces informations s'ajoutent aux informations activées par le paramètre lvm.conf log/journal. command: enregistrer des informations sur la commande. output: enregistrer la sortie par défaut de la commande. debug: enregistrer le débogage complet de la commande.
--lockopt Chaîne
Utilisé pour passer des options pour des cas spéciaux à lvmlockd. Voir lvmlockd(8) pour plus d'informations.
--logonly
Supprimer le rapport de commande et afficher uniquement le rapport de journal.
--longhelp
Afficher le texte d'aide détaillé.
--nameprefixes
Ajouter un préfixe « LVM2_ » suivi du nom du champ à la sortie. Utile avec --noheadings pour produire une liste de paires champ=valeur qui peuvent être utilisées pour définir des variables d'environnement (par exemple, dans les règles udev).
--noheadings
Supprimer la ligne d'en-têtes qui est normalement la première ligne de la sortie. Utile si vous utilisez grep sur la sortie.
--nohints
Ne pas utiliser le fichier d'indices pour localiser les périphériques pour les PV. Une commande peut lire plus de périphériques pour trouver des PV lorsque les indices ne sont pas utilisés. La commande effectuera toujours une invalidation standard du fichier d'indices le cas échéant.
--nolocking
Désactiver le verrouillage. Utiliser avec prudence, les commandes concurrentes peuvent produire des résultats incorrects.
--nosuffix
Supprimer le suffixe sur les tailles de sortie. Utiliser avec --units (sauf h et H) si vous traitez la sortie.
-o|--options Chaîne
Liste ordonnée de champs, séparés par des virgules, à afficher dans les colonnes. La syntaxe de l'argument Chaîne est : [+|-|#]Champ1[,Champ2 ...] Le préfixe + ajoutera les champs spécifiés aux champs par défaut, - supprimera les champs spécifiés des champs par défaut, et # compactera les champs spécifiés (les supprimant lorsqu'ils sont vides pour toutes les lignes.) Utiliser -o help pour voir la liste de tous les champs disponibles. Utiliser des listes séparées de champs pour ajouter, supprimer ou

OPTIONS

-o|--options String
Specify the fields to be displayed by a command. Use a comma-separated list of field names. Use --options help to see a list of available fields. Some fields may be specific to certain LVM commands. Fields can be prefixed with '+' to add them to the default list, or '-' to remove them from the default list. Fields without a prefix will replace the default list.
The default list is determined by the command and may be altered by lvm.conf(5) settings.
Example: 
-o +devices -o uuid
This displays the default fields, plus the 'devices' and 'uuid' fields.
Example: 
-o lv_name,vg_name,lv_size
This displays only the 'lv_name', 'vg_name', and 'lv_size' fields.
Example: 
-o lv_name,vg_name -o +lv_uuid
This displays the 'lv_name' and 'vg_name' fields, plus the 'lv_uuid' field.
The option can be repeated to compact by repeating the -o option: -o+field1,field2 -o-field3,field4 -o#field5. These lists are evaluated from left to right. Use field name lv_all to view all LV fields, vg_all all VG fields, pv_all all PV fields, seg_all all LV segment fields, and pvseg_all all PV segment fields. See the lvm.conf(5) report section for more config options. See lvmreport(7) for more information about reporting.
--profile String
An alias for --commandprofile or --metadataprofile, depending on the command.
-q|--quiet ...
Suppress output and log messages. Overrides --debug and --verbose. Repeat once to also suppress any prompts with answer 'no'.
--readonly
Prevent the command from making changes, including activation and metadata updates. (See --permission r for read only LVs.)
--reportformat basic|json|json_std
Overrides current output format for reports which is defined globally by the report/output_format setting in lvm.conf(5). basic is the original format with columns and rows. If there is more than one report per command, each report is prefixed with the report name for identification. json produces report output in JSON format. json_std produces report output in JSON format which is more compliant with JSON standard. See lvmreport(7) for more information.
--rows
Output columns as rows.
--segments
Produces one line of output for each contiguous allocation of space on each PV, showing the start (pvseg_start) and length (pvseg_size) in units of physical extents.
-S|--select String
Select objects for processing and reporting based on specified criteria. The criteria syntax is described by --select help and lvmreport(7). For reporting commands, one row is displayed for each object matching the criteria. See --options help for selectable object fields. Rows can be displayed with an additional "selected" field (-o selected) showing 1 if the row matches the selection and 0 otherwise. For non-reporting commands which process LVM entities, the selection is used to choose items to process.
--separator String
String to use to separate each column. Useful if grepping the output.
--shared
Report/display shared VGs that would otherwise be skipped when lvmlockd is not being used on the host. See lvmlockd(8) for more information about shared VGs.
-O|--sort String
Comma-separated ordered list of columns to sort by. Replaces the default selection. Precede any column with - for a reverse sort on that column.
-t|--test
Run in test mode. Commands will not update metadata. This is implemented by disabling all metadata writing but nevertheless returning success to the calling function. This may lead to unusual error messages in multi-stage operations if a tool relies on reading back metadata it believes has changed but hasn't.
--unbuffered
Produce output immediately without sorting or aligning the columns properly.
--units [Number]r|R|h|H|b|B|s|S|k|K|m|M|g|G|t|T|p|P|e|E
All sizes are output in these units: human-(r)eadable with '<' rounding indicator, (h)uman-readable, (b)ytes, (s)ectors, (k)ilobytes, (m)egabytes, (g)igabytes, (t)erabytes, (p)etabytes, (e)xabytes. Capitalise to use multiples of 1000 (S.I.) instead of 1024. Custom units can be specified, e.g. --units 3M.
--unquoted
When used with --nameprefixes, output values in the field=value pairs are not quoted.
-v|--verbose ...
Set verbose level. Repeat from 1 to 4 times to increase the detail of messages sent to stdout and stderr.
--version
Display version information.
-y|--yes
Do not prompt for confirmation interactively but always assume the answer yes. Use with extreme caution. (For automatic no, see -qq.)

VARIABLES

PV
Physical Volume name, a device path under /dev. For commands managing physical extents, a PV positional arg generally accepts a suffix indicating a range (or multiple ranges) of physical extents (PEs). When the first PE is omitted, it defaults to the start of the device, and when the last PE is omitted it defaults to end.
Start and end range (inclusive): PV[:PE-PE] ...
Start and length range (counting from 0): PV[:PE+PE] ...
Tag
Tag name. See lvm(8) for information about tag names and using tags in place of a VG, LV or PV.
String
See the option description for information about the string content.
Size[UNIT]
Size is an input number that accepts an optional unit. Input units are always treated as base two values, regardless of capitalization, e.g. 'k' and 'K' both refer to 1024. The default input unit is specified by letter, followed by |UNIT. UNIT represents other possible input units: b|B is bytes, s|S is sectors of 512 bytes, k|K is KiB, m|M is MiB, g|G is GiB, t|T is TiB, p|P is PiB, e|E is EiB. (This should not be confused with the output control --units, where capital letters mean multiple of 1000.)

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables used by lvm. For example, LVM_VG_NAME can generally be substituted for a required VG parameter.
