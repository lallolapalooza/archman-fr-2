pyacc(1) Générateur d'analyseur Pascal pyacc(1)

NOM

pyacc - Compilateur de compilateur Yacc Pascal.

UTILISATION

yacc [options] fichier-yacc[.y] [fichier-sortie[.pas]]

OPTIONS SH

-v
Verbose : Pascal Yacc génère une description lisible de l'analyseur généré, écrite dans le fichier yacc avec la nouvelle extension .lst.
-d
Debug : TP Yacc génère un analyseur avec sortie de débogage.

DESCRIPTION

TP Yacc est un programme qui vous permet de préparer des analyseurs à partir de la description de langages d'entrée par des grammaires de type BNF. Vous spécifiez simplement la grammaire de votre langage cible, augmentée du code Turbo Pascal nécessaire au traitement des constructions syntaxiques, et TP Yacc traduit votre grammaire en code Turbo Pascal pour une routine d'analyse correspondante nommée yyparse.

TP Yacc analyse la grammaire source contenue dans le fichier yacc (avec le suffixe par défaut .y) et écrit la routine d'analyse construite dans le fichier de sortie spécifié (avec le suffixe par défaut .pas) ; si aucun fichier de sortie n'est spécifié, la sortie va dans le fichier yacc avec la nouvelle extension .pas. Si des erreurs sont trouvées lors de la compilation, les messages d'erreur sont écrits dans le fichier liste (fichier yacc avec la nouvelle extension .lst).

La routine d'analyse générée, yyparse, est déclarée comme suit :


function yyparse : Integer;

Cette routine peut être appelée par votre programme principal pour exécuter l'analyseur. La valeur de retour de la routine yyparse indique le succès ou l'échec de l'analyseur (valeurs de retour possibles : 0 = succès, 1 = erreur de syntaxe irrécupérable ou dépassement de pile d'analyse).

Similaire à TP Lex, le modèle de code pour la routine yyparse peut être trouvé dans le fichier yyparse.cod. Les règles de localisation de ce fichier sont analogues à celles de TP Lex (voir la section `TP Lex').

L'unité de bibliothèque TP Yacc (YaccLib) est requise par les programmes utilisant les analyseurs générés par Yacc ; vous devrez donc mettre une clause uses appropriée dans votre programme ou unité qui contient la routine d'analyse. L'unité YaccLib fournit également certaines routines qui peuvent être utilisées pour contrôler les actions de l'analyseur. Voir le fichier yacclib.pas pour plus d'informations.

Plus d'informations

Pour plus d'informations, consultez la documentation fournie avec TP lex et yacc.
