L'un des scénarios typiques où sshtunnel est utile est décrit dans la figure ci-dessous. L'utilisateur peut avoir besoin de connecter un port d'un serveur distant (par exemple, 8080) où seul le port SSH (généralement le port 22) est accessible.

----------------------------------------------------------------------
                            |
-------------+              |    +----------+
    CLIENT   |              |    |  SERVEUR | :22 SSH
    LOCAL    | <== SSH ========> |  DISTANT | :8080 service web
-------------+              |    +----------+
                            |
                         PARE-FEU (seul le port 22 est ouvert)
----------------------------------------------------------------------

Fig1: Comment se connecter à un service bloqué par un pare-feu via un tunnel SSH.

Si le serveur SSH le permet, il est également possible d'atteindre un serveur privé (du point de vue du SERVEUR DISTANT) qui n'est pas directement visible de l'extérieur (perspective du CLIENT LOCAL).

----------------------------------------------------------------------
                            |
-------------+              |    +----------+               +---------
    CLIENT   |              |    |  SERVEUR |               | SERVEUR
    LOCAL    | <== SSH ========> |  DISTANT | <== local ==> | PRIVÉ
-------------+              |    +----------+               +---------
                            |
                         PARE-FEU (seul le port 443 est ouvert)
----------------------------------------------------------------------

Fig2: Comment se connecter au SERVEUR PRIVÉ via un tunnel SSH.

L'API permet soit d'initialiser le tunnel et de le démarrer, soit d'utiliser un contexte with, qui s'occupera de démarrer et d'arrêter le tunnel :

EXEMPLE 1

Le code correspondant à la Fig1 ci-dessus suit, étant donné que l'adresse du serveur distant est pahaz.urfuclub.ru, l'authentification par mot de passe et un port de liaison local assigné aléatoirement.

from sshtunnel import SSHTunnelForwarder
server = SSHTunnelForwarder(
    'alfa.8iq.dev',
    ssh_username="pahaz",
    ssh_password="secret",
    remote_bind_address=('127.0.0.1', 8080)
)
server.start()
print(server.local_bind_port)  # afficher le port local assigné
# travailler avec le `SERVICE SECRET` via `server.local_bind_port`.
server.stop()

EXEMPLE 2

Exemple de transfert de port vers un serveur privé non directement accessible, supposant une authentification par clé pkey protégée par mot de passe, le service SSH du serveur distant écoutant sur le port 443 et que ce port est ouvert dans le pare-feu (Fig2) :

import paramiko
import sshtunnel
with sshtunnel.open_tunnel(
    (REMOTE_SERVER_IP, 443),
    ssh_username="",
    ssh_pkey="/var/ssh/rsa_key",
    ssh_private_key_password="secret",
    remote_bind_address=(PRIVATE_SERVER_IP, 22),
    local_bind_address=('0.0.0.0', 10022)
) as tunnel:
    client = paramiko.SSHClient()
    client.load_system_host_keys()
    client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
    client.connect('127.0.0.1', 10022)
    # effectuer des opérations avec la session client
    client.close()
print('TERMINÉ !')

EXEMPLE 3

Exemple de transfert de port pour le port local MySQL de Vagrant :

from sshtunnel import open_tunnel
from time import sleep
with open_tunnel(
    ('localhost', 2222),
    ssh_username="vagrant",
    ssh_password="vagrant",
    remote_bind_address=('127.0.0.1', 3306)
) as server:
    print(server.local_bind_port)
    while True:
        # appuyez sur Ctrl-C pour arrêter
        sleep(1)
print('TERMINÉ !')

Ou simplement en utilisant la ligne de commande :

(bash)$ python -m sshtunnel -U vagrant -P vagrant -L :3306 -R 127.0.0.1:3306 -p 2222 localhost

EXEMPLE 4

Ouverture d'une session SSH via deux tunnels. Le transport SSH et les tunnels seront démonisés, ce qui n'attendra pas la fermeture des connexions lors de l'arrêt.

import sshtunnel
from paramiko import SSHClient
with sshtunnel.open_tunnel(
    ssh_address_or_host=('GW1_ip', 20022),
    remote_bind_address=('GW2_ip', 22),
) as tunnel1:
    print('Connexion au tunnel1 (GW1_ip:GW1_port) OK...')
    with sshtunnel.open_tunnel(
        ssh_address_or_host=('localhost', tunnel1.local_bind_port),
        remote_bind_address=('target_ip', 22),
        ssh_username='GW2_user',
        ssh_password='GW2_pwd',
    ) as tunnel2:
        print('Connexion au tunnel2 (GW2_ip:GW2_port) OK...')
        with SSHClient() as ssh:
            ssh.connect('localhost',
                port=tunnel2.local_bind_port,
                username='target_user',
                password='target_pwd',
            )
            ssh.exec_command(...)

sshtunnel - Initialise des tunnels SSH via une passerelle distante.

sshtunnel fonctionne en ouvrant une connexion SSH de transfert de port en arrière-plan, en utilisant des threads.

Les connexions sont fermées lors de l'appel explicite de la méthode SSHTunnelForwarder.stop() ou en l'utilisant comme contexte.

Classe de tunnel SSH
  • Initialise un tunnel SSH vers un hôte distant selon les arguments d'entrée
Optionnellement :
  • Lire un fichier de configuration SSH (typiquement ~/.ssh/config)
  • Charger les clés à partir d'un agent SSH en cours d'exécution (par exemple, Pageant, GNOME Keyring)

Lève :

BaseSSHTunnelForwarderError :
levée par les méthodes de la classe SSHTunnelForwarder
HandlerSSHTunnelForwarderError :
levée par les threads de transfert de tunnel

NOTE :

Les attributs mute_exceptions et raise_exception_if_any_forwarder_have_a_problem (obsolète) peuvent être utilisés pour supprimer la plupart des exceptions levées par cette classe

NOTE :

Cela devait être géré avec soin avant la version 0.1.0 :
  • si une redirection de port est ouverte
  • la destination n'est pas joignable
  • nous tentons une connexion à ce tunnel (SYN est envoyé et acquitté, puis un paquet FIN est envoyé et jamais acquitté... étrange)
  • nous essayons de fermer : cela ne réussira pas avant que les délais FIN_WAIT_2 et CLOSE_WAIT ne soient expirés.
