NOM

parso - Documentation de parso

Version v0.8.5. (Installation)

Parso est un analyseur Python qui prend en charge la récupération d'erreurs et l'analyse aller-retour pour différentes versions de Python (dans plusieurs versions de Python). Parso est également capable de répertorier plusieurs erreurs de syntaxe dans votre fichier python.

Parso se compose d'une petite API pour analyser Python et analyser l'arbre syntaxique.

Un exemple simple :

>>> import parso
>>> module = parso.parse('hello + 1', version="3.9")
>>> expr = module.children[0]
>>> expr
PythonNode(arith_expr, [<Name: hello@1,0>, <Operator: +>, <Number: 1>])
>>> print(expr.get_code())
hello + 1
>>> name = expr.children[0]
>>> name
<Name: hello@1,0>
>>> name.end_pos
(1, 5)
>>> expr.end_pos
(1, 9)

Pour lister plusieurs problèmes :

>>> grammar = parso.load_grammar()
>>> module = grammar.parse('foo +\nbar\ncontinue')
>>> error1, error2 = grammar.iter_errors(module)
>>> error1.message
'SyntaxError: invalid syntax'
>>> error2.message
"SyntaxError: 'continue' not properly in loop"

La méthode préférée (pip)

Sur n'importe quel système, vous pouvez installer parso directement depuis l'index des paquets Python en utilisant pip :

sudo pip install parso

Pour l'installer, naviguez vers le répertoire contenant setup.py dans votre console et tapez :

sudo python setup.py install

Utilisation

parso fonctionne autour des grammaires. Vous pouvez simplement créer des grammaires Python en appelant parso.load_grammar(). Les grammaires (avec un analyseur lexical et des arbres d'analyse personnalisés) peuvent également être créées en instanciant directement parso.Grammar(). Plus d'informations sur les objets résultants se trouvent dans la documentation de l'arbre d'analyse.

La manière la plus simple d'utiliser parso est sans même charger une grammaire (parso.parse()) :

>>> import parso
>>> parso.parse('foo + bar')
<Module: @1-1>

Chargement d'une Grammaire

Généralement, si vous souhaitez travailler avec une version spécifique de Python, utilisez :

Paramètres

Parser Tree

The parser tree is returned by calling parso.Grammar.parse().

NOTE:

Note that parso positions are always 1 based for lines and zero based for columns. This means the first position in a file is (1, 0).

Arbre du Parseur Python

C'est l'arbre syntaxique pour les syntaxes Python 3. Les classes représentent des éléments de syntaxe tels que les fonctions et les importations.

Il y a beaucoup de logique ici qui facilite le traitement d'un arbre syntaxique Python par Jedi (et d'autres bibliothèques).

En utilisant parso.tree.NodeOrLeaf.get_code() sur un module, vous pouvez récupérer la représentation 1-à-1 de l'entrée donnée au parseur. Ceci est important si vous souhaitez refactoriser un arbre de parseur.

>>> from parso import parse
>>> parser = parse('import os')
>>> module = parser.get_root_node()
>>> module
<Module: @1-1>

Toutes les sous-classes de Scope, y compris Module, ont un attribut iter_imports :

>>> list(module.iter_imports())
[<ImportName: import os@1,0>]

Modifications de la Grammaire Python

Quelques éléments ont été modifiés par rapport aux fichiers de grammaire Python :

  • Param n'existe pas dans les fichiers de grammaire Python. Il fait essentiellement partie d'un nœud parameters. parso le divise pour faciliter l'analyse des paramètres. Cependant, cela rend simplement le traitement de l'arbre syntaxique plus facile, cela ne modifie pas la syntaxe valide.
  • Quelques nœuds comme lambdef et lambdef_nocond ont été fusionnés dans l'arbre syntaxique pour faciliter leur manipulation.

DESCRIPTION

parso est une bibliothèque d'analyse Python qui est plus rapide et offre plus de fonctionnalités que l'ast module intégré.

La caractéristique la plus importante est la possibilité d'utiliser l'analyseur Python pour construire des arbres syntaxiques abstraits (AST) qui ont de nombreuses fonctions pour l'introspection. Cet AST peut être créé à partir de chaînes de caractères de code Python.

Dans cette partie, on peut trouver des descriptions de classes et de fonctions qui sont d'une grande utilité pour travailler avec des ASTs qui ont été générés par parso.

Utilitaire

parso.tree.search_ancestor(node: NodeOrLeaf, *node_types: str) -> BaseNode | None
Examine récursivement les parents d'un noeud et retourne le premier noeud trouvé qui correspond à node_types. Retourne None si aucun noeud correspondant n'est trouvé.

Cette fonction est dépréciée, utilisez NodeOrLeaf.search_ancestor() à la place.

Parameters
  • node -- Les ancêtres de ce noeud seront vérifiés.
  • node_types -- noms de types recherchés.

Développement

Si vous souhaitez contribuer quoi que ce soit à parso, ouvrez simplement un ticket ou une pull request pour en discuter. Nous apprécions les changements ! Vérifiez d'abord le fichier CONTRIBUTING.md dans le dépôt.

Processus de dépréciation

Le processus de dépréciation est le suivant :

1.
Une dépréciation est annoncée dans la prochaine version majeure/mineure.
2.
Nous attendons au moins un an et au moins deux versions mineures avant de supprimer la fonctionnalité dépréciée.
