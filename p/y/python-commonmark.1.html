NOM

commonmark-py - Documentation de commonmark.py

commonmark.py est testé contre la spécification CommonMark avec les versions Python 2.7, 3.4, 3.5, 3.6 et 3.7.

Version actuelle : 0.9.1

INSTALLATION

$ pip install commonmark

UTILISATION

>>> import commonmark
>>> commonmark.commonmark('*hello!*')
'<p><em>hello!</em></p>\n'

Ou, sans le sucre syntaxique :

import commonmark
parser = commonmark.Parser()
ast = parser.parse("Hello *World*")
renderer = commonmark.HtmlRenderer()
html = renderer.render(ast)
print(html) # <p>Hello <em>World</em><p/>
# inspection de l'arbre syntaxique abstrait
json = commonmark.dumpJSON(ast)
commonmark.dumpAST(ast) # impression formatée de la structure AST générée

TESTS

Pour travailler sur commonmark.py, vous devrez pouvoir exécuter la suite de tests pour vous assurer que vos modifications ne cassent rien. Pour exécuter les tests, vous pouvez faire quelque chose comme ceci :

$ pyvenv venv
$ ./venv/bin/python setup.py develop test

Le script de tests, commonmark/tests/run_spec_tests.py, est essentiellement un outil de développement. En plus d'exécuter tous les tests intégrés dans spec.txt, il vous permet également d'exécuter des tests spécifiques à l'aide de l'argument -t, de fournir des informations sur les tests passés avec -p, le pourcentage de réussite par catégorie de test avec -s, et d'entrer du markdown de manière interactive avec -i (En mode interactif, terminez un bloc en saisissant une ligne avec juste end, pour quitter faites de même mais avec quit). -d peut être utilisé pour afficher le traçage des appels.

@param str {String} La chaîne à concaténer.

reStructuredText

class commonmark.render.rst.ReStructuredTextRenderer(indent_char=' ')
Rendu reStructuredText à partir de Markdown

Exemple :

import commonmark
parser = commonmark.Parser()
ast = parser.parse('Hello `inline code` example')
renderer = commonmark.ReStructuredTextRenderer()
rst = renderer.render(ast)
print(rst)  # Hello ``inline code`` example

@param str {String} La chaîne à concaténer.

Parser

class commonmark.blocks.Parser(options={})
add_child(tag, offset)
Ajouter un bloc de type tag comme enfant de la pointe. Si la pointe ne peut pas accepter d'enfants, la fermer et la finaliser, et essayer son parent, jusqu'à ce que nous trouvions un bloc qui peut accepter des enfants.
add_line()
Ajouter une ligne au bloc à la pointe. Nous supposons que la pointe peut accepter des lignes -- cette vérification doit être faite avant d'appeler cela.
close_unmatched_blocks()
Finaliser et fermer tous les blocs non appariés.
finalize(block, line_number)
Finaliser un bloc. Le fermer et effectuer tout post-traitement nécessaire, par exemple, créer du contenu de chaîne à partir de chaînes, définir le statut 'tight' ou 'loose' d'une liste, et analyser les débuts de paragraphes pour les définitions de référence. Réinitialiser la pointe au parent du bloc fermé.
incorporate_line(ln)
Analyser une ligne de texte et mettre à jour le document de manière appropriée.

Nous analysons le texte markdown en appelant cette méthode pour chaque ligne d'entrée, puis en finalisant le document.

parse(my_input)
La fonction principale d'analyse. Retourne un AST de document analysé.
process_inlines(block)
Parcourt récursivement un bloc et ses enfants, en analysant le contenu textuel en contenu en ligne lorsque cela est approprié.
