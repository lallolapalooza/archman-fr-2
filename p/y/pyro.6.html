NOM

pyro - simuler des feux d'artifice

SYNTAXE

pyro [--display hôte:écran.numéro] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numéro][--mono] [--install] [--visual visuel] [--count entier] [--frequency entier] [--scatter entier] [--fps]

DESCRIPTION

Le programme pyro simule des feux d'artifice, d'une manière similaire à un programme Macintosh du même nom.

OPTIONS

pyro accepte les options suivantes :

--window
Dessiner dans une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--mono
Si sur un écran couleur, faire comme si on était sur un écran monochrome.
--install
Installer une palette de couleurs privée pour la fenêtre.
--visual visuel
Spécifier quel visuel utiliser. Les valeurs valides sont le nom d'une classe de visuel, ou le numéro d'identification (décimal ou hexadécimal) d'un visuel spécifique.
--count entier
Combien de particules doivent être autorisées à l'écran simultanément. Défaut 600.
--frequency entier
À quelle fréquence de nouveaux missiles doivent être lancés. Défaut 30.
--scatter entier
Combien de particules doivent apparaître lorsqu'un missile explose. Défaut 100. Le nombre réel utilisé est compris entre N et N+(N/2).
--fps
Afficher le taux d'images par seconde actuel et la charge CPU.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.
