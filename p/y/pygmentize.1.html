PYGMENTIZE(1) Manuel des commandes générales PYGMENTIZE(1)

NOM

pygmentize - colore le fichier d'entrée

SYNTAXE

pygmentize [-l <lexeur> | -g] [-F <filtre>[:<options>]] [-f <formateur>] [-O <options> ] [-P <option=valeur> ] [-o <fichier_sortie> ] [<fichier_entree>]
pygmentize -S <style> -f <formateur> [-a <arg>] [-O <options>] [-P <option=valeur>]
pygmentize -L [<quoi> ...]
pygmentize -N <nom_fichier>
pygmentize -C
pygmentize -H <type> <nom>
pygmentize -h | -V

DESCRIPTION

Pygments est un surligneur syntaxique générique destiné à être utilisé dans toutes sortes de logiciels tels que les systèmes de forums, les wikis ou d'autres applications qui ont besoin de rendre le code source plus lisible.

Ses points forts sont :
* une large gamme de langages courants et de formats de balisage est prise en charge
* une attention particulière est portée aux détails, augmentant la qualité d'un bon montant
* la prise en charge de nouveaux langages et formats est facile à ajouter
* un certain nombre de formats de sortie, actuellement HTML, LaTeX et séquences ANSI
* il peut être utilisé comme un outil en ligne de commande et comme une bibliothèque
* ... et il colore même Brainfuck !

pygmentize est une commande qui utilise Pygments pour colorer le fichier d'entrée et écrire le résultat dans <fichier_sortie>. Si aucun <fichier_entree> n'est donné, l'entrée standard est utilisée.

OPTIONS

Un résumé des options est inclus ci-dessous.

-l <lexeur>
Définit le nom du lexeur. S'il n'est pas donné, le lexeur est deviné à partir de l'extension du nom du fichier d'entrée (cela ne fonctionne évidemment pas si l'entrée est stdin).
-g
Tente de deviner le lexeur à partir du contenu du fichier, ou le transmet en texte brut si cela échoue (cette option fonctionne pour la coloration de l'entrée standard).
-F <filtre>[:<options>]
Ajoute un filtre au flux de jetons. Vous pouvez donner des options de la même manière que pour -O après un deux-points (remarque : il ne doit pas y avoir d'espaces autour du deux-points). Cette option peut être donnée plusieurs fois.
-f <formateur>
Définit le nom du formateur. S'il n'est pas donné, il sera deviné à partir de l'extension du nom du fichier de sortie. Si aucun fichier de sortie n'est donné, le formateur de terminal sera utilisé par défaut.
-o <fichier_sortie>
Définit le fichier de sortie. S'il n'est pas donné, stdout est utilisé.
-O <options>
Avec cette option, vous pouvez donner au lexeur et au formateur une liste d'options séparées par des virgules, par exemple "-O bg=light,python=cool". Les options valides pour chaque lexeur et formateur se trouvent dans la documentation. Cette option peut être donnée plusieurs fois.
-P <option=valeur>
Cette option ajoute des options de lexeur et de formateur comme l'option -O, mais vous ne pouvez donner qu'une seule option par -P. Ainsi, la valeur de l'option peut contenir des virgules et des signes égal, ce qu'elle ne peut pas faire avec -O.
-S <style>
Imprime les définitions de style pour le style <style> et pour le formateur <formateur>. La signification de l'argument donné par -a <arg> dépend du formateur et peut être trouvée dans la documentation.
-L [<quoi> ...]
Liste les lexeurs, les formateurs, les styles ou les filtres. Définissez <quoi> sur l'élément que vous souhaitez lister (par exemple, "styles"), ou omettez-le pour lister tout.
-N <nom_fichier>
Devine et imprime un nom de lexeur basé uniquement sur le nom de fichier donné. Ne prend aucune entrée et ne colore rien. Si aucun lexeur spécifique ne peut être trouvé, "text" est imprimé.
-C
Comme -N, mais devine un lexeur basé sur le contenu lu depuis l'entrée standard.
-H <type> <nom>
Imprime l'aide détaillée pour l'objet <nom> de type <type>, où <type> est l'un de "lexer", "formatter" ou "filter".
-h
Affiche l'écran d'aide.
-V
Affiche la version du paquet Pygments.
