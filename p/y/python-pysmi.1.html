Documentation PySMI

La bibliothèque PySMI est hautement modulaire. Le composant de plus haut niveau est appelé compiler et il agit comme l'objet principal visible par l'utilisateur. La plupart des autres composants sont branchés dans l'objet compiler avant son utilisation.

Normalement, l'utilisateur demande au compiler d'effectuer une certaine transformation sur un module MIB nommé. Le compilateur :

  • Recherche dans ses sources de données le module MIB donné (identifié par son nom) en notant leurs dates de dernière modification.
  • Recherche dans les dépôts gérés par le compilateur de modules MIB déjà convertis, des modules plus récents que le module MIB source correspondant.
  • Si un module MIB fraîchement transformé est trouvé, le traitement s'arrête ici.
  • Sinon, le compilateur passe le contenu du module MIB ASN.1 au composant lexer.
  • Le lexer renvoie une séquence de tokens du contenu MIB ASN.1. Le compilateur passe ensuite cette séquence de tokens au composant parser.
  • Le parser exécute l'algorithme LR sur le MIB tokenisé, transformant ainsi le contenu du MIB en Arbre de Syntaxe Abstraite (AST) et notant également quels autres modules MIB sont référencés dans le MIB en cours d'analyse.
  • En cas d'échec du parser, ce qui indique généralement une syntaxe MIB ASN.1 incorrecte, le compilateur peut tenter de récupérer le contenu MIB pré-transformé depuis une source configurée. Ce processus est appelé borrowing dans PySMI.
  • En cas de succès de l'achèvement du parser, le compilateur passera l'AST produit au composant code generator.
  • Le générateur de code parcourt son AST d'entrée et effectue la transformation des données réelle.
  • Les étapes ci-dessus peuvent être répétées pour chacun des modules MIB référencés, au fur et à mesure que le parser les découvre. Une fois qu'il ne reste plus de dépendances non résolues, le compilateur appellera son composant writer pour stocker tous les modules MIB transformés.

L'emplacement des modules MIB ASN.1 et le type de leur syntaxe, ainsi que le format de transformation désiré, sont déterminés par les composants respectifs choisis et configurés pour le compilateur.

L'outil mibdump

L'outil mibdump.py est une interface en ligne de commande pour la bibliothèque PySMI. Cet outil peut être utilisé pour télécharger et transformer automatiquement les modules MIB SNMP dans divers formats.

Spécifier la source MIB

L'option --mib-source peut être donnée plusieurs fois. Chaque instance de --mib-source doit spécifier une URL où les modules MIB ASN.1 doivent être recherchés et téléchargés. Pour le moment, trois méthodes de sourcing MIB sont supportées :

  • Fichiers locaux. Il peut s'agir d'un répertoire de niveau supérieur où se trouvent les fichiers MIB. Les sous-répertoires seront également parcourus automatiquement. Exemple : file:///usr/share/snmp
  • Archives ZIP contenant des fichiers MIB. Les sous-répertoires et les archives ZIP intégrées seront automatiquement parcourus. Exemple : zip://mymibs.zip
  • HTTP/HTTPS. Une URL entièrement spécifiée où le nom du module MIB est spécifié par un jeton de remplacement @mib@. Lorsque le MIB spécifique est recherché, PySMI remplacera ce jeton par le nom du module MIB qu'il recherche. Exemple : http://mibs.snmplabs.com/asn1/@mib@
  • SFTP/FTP. Une URL entièrement spécifiée incluant le nom d'utilisateur et le mot de passe FTP. Le nom du module MIB est spécifié par un jeton de remplacement @mib@. Lorsque le MIB spécifique est recherché, PySMI remplacera ce jeton par le nom du module MIB qu'il recherche. Exemple : http://mibs.snmplabs.com/asn1/@mib@

Lorsqu'il essaie de récupérer un module MIB, l'outil mibdump.py essaiera chaque transport --mib-source configuré dans l'ordre de spécification jusqu'au premier succès.

Par défaut, mibdump.py recherchera :

  • file:///usr/share/snmp
  • http://mibs.snmplabs.com/asn1/@mib@

Une fois qu'une autre option --mib-source est donnée, ces valeurs par défaut ne seront pas utilisées et devront être fournies manuellement à mibdump.py si nécessaire.

Noms de modules MIB flous

Il n'y a pas de convention unique sur la façon dont les noms de fichiers des modules MIB doivent être nommés. Par défaut, mibdump.py essaiera quelques hypothèses lorsqu'il cherchera un fichier contenant un module MIB spécifique. Il essaiera les majuscules et minuscules, un fichier nommé d'après le module MIB, essaiera d'ajouter différentes extensions au fichier (.mib, .my etc), essaiera d'ajouter/supprimer la partie '-MIB' du nom de fichier. Si rien ne correspond, mibdump.py considérera que le --mib-source sondé ne contient pas le module MIB recherché.

Il y a une faible chance, cependant, que la correspondance floue entraîne l'obtention d'un mauvais MIB. Si cela se produit, vous pouvez désactiver le flou mentionné ci-dessus en donnant à mibdump.py l'option --disable-fuzzy-source.

\n

Gestion des MIB incorrectes

\n

Curieusement, certaines MIB provenant de fournisseurs assez importants semblent syntaxiquement\n incorrectes. Cela conduit les compilateurs de MIB à échouer sur ces MIB. Bien que de nombreuses\n implémentations de compilateurs de MIB (y compris PySMI) introduisent des solutions de contournement\n et des relaxations de grammaire permettant de compiler des MIB légèrement incorrectes, les MIB\n gravement incorrectes ne peuvent pas être compilées de manière fiable.

\n

Comme autre solution de contournement, PySMI propose la fonctionnalité de *borrow* (emprunt).\n Elle permet à PySMI de récupérer des MIB déjà transformées, même si la MIB ASN.1 correspondante\n ne peut pas être trouvée ou analysée.

\n

La source par défaut des MIB pré-compilées pour la cible pysnmp est :

\n
\n
    \n
  • http://mibs.snmplabs.com/pysnmp/fulltexts/@mib@
    • \n
  • http://mibs.snmplabs.com/pysnmp/notexts/@mib@
    • \n
\n
\n

Si vous souhaitez modifier cette liste par défaut, utilisez une ou plusieurs\n options --mib-borrower.

Choix de la transformation cible

\n

La conception de PySMI permet à de nombreux formats de transformation d'être pris en charge\n sous forme de composants spécialisés de génération de code. Pour le moment, PySMI peut produire\n des MIB sous forme de classes pysnmp et de documents JSON.

\n

Le schéma du document JSON est choisi pour préserver autant d'informations de la MIB que possible.\n Il n'existe pas de schéma JSON établi connu des auteurs.

Exécution de la transformation inconditionnelle

\n

Par défaut, PySMI évitera de créer de nouvelles transformations si des versions suffisamment récentes\n existent déjà. En utilisant l'option --rebuild, vous pouvez forcer PySMI à effectuer la transformation\n demandée pour tous les modules MIB donnés.

Ignorer les erreurs de transformation

\n

Par défaut, PySMI s'arrêtera à la première erreur fatale survenue lors de la transformation d'une série de MIB.\n Si vous souhaitez que PySMI ignore les erreurs fatales et donc saute la MIB échouée, utilisez l'option --ignore-errors.

Gardez à l'esprit que sauter la transformation de MIB importées par d'autres MIB peut rendre\n les MIB dépendantes incohérentes pour l'utilisation.

Sauter les dépendances

\n

La plupart des MIB dépendent d'autres MIB pour leur fonctionnement. Ceci est indiqué par\n l'instruction IMPORT dans le langage ASN.1. PySMI tente de transformer toutes les MIB IMPORTées par\n la MIB en cours de transformation. Ceci est fait de manière récursive.

\n

En utilisant le drapeau --no-dependencies, vous pouvez indiquer à PySMI de ne pas transformer\n d'autres MIB que celles explicitement demandées à être transformées.

\n

Gardez à l'esprit que sauter les dépendances peut rendre l'ensemble des MIB transformées\n incohérent.

\n
\n
\n

Générer les textes des MIB

\n

La plupart des MIB sont très verbeuses. Elles contiennent de nombreuses descriptions et clarifications\n orientées vers l'humain, écrites en anglais simple. Ces textes peuvent être utiles pour les applications\n de navigateur MIB (pour afficher ces textes à un opérateur humain) mais peuvent n'avoir aucun sens\n dans d'autres applications.

\n

Pour économiser de l'espace et du temps CPU, PySMI n'inclut pas par défaut ces textes\n dans les MIB transformées. Cependant, cela peut être annulé en ajoutant l'option --generate-mib-texts.

\n

Lorsque les textes des MIB sont générés, les espaces blancs et les sauts de ligne sont supprimés par défaut.\n Parfois, cela casse l'art ASCII s'il apparaît dans les textes des MIB. Pour préserver la mise en forme\n originale du texte, l'option --keep-texts-layout peut être utilisée.

\n
\n
\n

Construction des indices de MIB

Si l'option --build-index est donnée, en fonction du format de destination choisi, l'outil\n mibdump.py peut créer un nouveau document (ou mettre à jour un existant) contenant des informations\n de MIB sous une forme pratique pour interroger les propriétés fondamentales des fichiers MIB.

Accélérations mineures

\n

Il existe quelques options qui peuvent améliorer les performances de PySMI.

\n

L'option --cache-directory peut être utilisée pour spécifier un répertoire temporaire inscriptible où\n l'analyseur PySMI (par exemple, Ply) stockerait ses tables de recherche.

\n

Par défaut, PySMI, lors de la transformation au format pysnmp, pré-compile également la source Python\n en bytecode interpréteur. Cela prend du temps et de l'espace. Si vous ne souhaitez pas mettre en cache\n le bytecode Python ou le faire plus tard, utilisez l'option --no-python-compile.

\n

L'outil mibcopy

\n

L'outil mibcopy.py tente de normaliser le nom du fichier MIB.

\n

Il s'est avéré que parfois les fournisseurs nomment leurs MIB de quelque manière que ce soit,\n pas nécessairement d'après le nom canonique de la MIB. Cela pose des problèmes aux consommateurs de MIB,\n car ils pourraient ne pas être en mesure de trouver la MIB dont ils ont besoin sur le système de fichiers.

\n

La façon dont mibcopy.py fonctionne est qu'il essaie de lire la MIB à partir du fichier donné\n (ou de tous les fichiers d'un répertoire ou d'une archive donné(e)). Il analyse le nom canonique de la MIB\n à partir du contenu du fichier. Sur cette base, l'outil essaie de renommer le fichier MIB avec un nom\n qui est le même que le nom canonique de la MIB. Si mibcopy.py rencontre un fichier du même nom déjà\n présent sur le système de fichiers, il le lit pour voir sa date de révision. Ensuite, l'outil compare\n les dates de révision des fichiers MIB qui entrent en collision et remplace le fichier fautif ou\n rejette le fichier en cours de copie comme étant obsolète.

\n

L'objectif ultime est de disposer des dernières versions des fichiers MIB, tous nommés d'après leurs noms canoniques.

Ignorer les erreurs de transformation

Par défaut, PySMI s'arrête à la première erreur fatale survenue lors de la transformation d'une série de MIB. Si vous souhaitez que PySMI ignore les erreurs fatales et saute ainsi le MIB défaillant, utilisez l'option --ignore-errors.

Gardez à l'esprit que le saut de transformation de MIB qui sont importés par d'autres MIB peut rendre les MIB dépendants incohérents pour l'utilisation.

Accélérations mineures

L'option --cache-directory peut être utilisée pour pointer vers un répertoire temporaire inscriptible où l'analyseur PySMI (par exemple, Ply) stockerait ses tables de recherche. Cela devrait améliorer un peu les performances de PySMI.

Bibliothèque PySMI

L'objet MibCompiler est l'interface la plus haute pour les fonctionnalités de la bibliothèque PySMI. Il rassemble les différentes parties isolées de l'infrastructure du compilateur et gère le flux de travail de la transformation des MIB ASN.1.

Cet exemple présente certaines de ses fonctionnalités :

from pysmi.reader import HttpReader
from pysmi.searcher import StubSearcher
from pysmi.writer import CallbackWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import JsonCodeGen
from pysmi.compiler import MibCompiler
inputMibs = ['IF-MIB', 'IP-MIB']
httpSources = [('mibs.snmplabs.com', 80, '/asn1/@mib@')]
# stocker les MIB compilés en appelant cette fonction
def store_mibs(mibName, jsonDoc, cbCtx):
    print('# MIB module %s' % mibName)
    print(jsonDoc)
mibCompiler = MibCompiler(
    SmiStarParser(), JsonCodeGen(), CallbackWriter(store_mibs)
)
# extraire les MIB ASN.1 sur HTTP
mibCompiler.addSources(*[HttpReader(*x) for x in httpSources])
# ne jamais recompiler les MIB avec des MACRO ASN.1
mibCompiler.addSearchers(StubSearcher(*JsonCodeGen.baseMibs))
status = mibCompiler.compile(*inputMibs)
print(status)

Statut de compilation

L'instance de la classe MibStatus est utilisée par MibCompiler.compiler() pour indiquer le résultat de l'opération de transformation de MIB.

Sources MIB

PySMI offre une poignée de mécanismes de transport distincts pour récupérer les MIB par nom à partir d'emplacements spécifiques. Dans tous les cas, la correspondance entre le nom du module MIB et le nom de fichier peut ne pas être exacte - un certain flou dans le nom peut être effectué pour atténuer les changements possibles dans le nom du fichier MIB.

Lecteur de fichiers locaux

L'instance de la classe FileReader recherche les fichiers MIB dans les répertoires spécifiés sur l'hôte exécutant PySMI.

Lecteur d'archives ZIP

L'instance de la classe ZipReader recherche les fichiers MIB dans une archive ZIP locale. Les sous-répertoires ZIP et les archives ZIP intégrées seraient parcourus.

Lecteur HTTP

L'instance de la classe HttpReader tente de télécharger des fichiers MIB en utilisant l'URL configurée.

Lecteur FTP

L'instance de la classe FtpReader tente de télécharger des fichiers MIB à partir du serveur FTP configuré.

Lecteur de rappel

L'instance de la classe CallbackReader tente de récupérer les fichiers MIB en appelant un objet utilisateur.

Compilation conditionnelle

Il existe des cas où la transformation des MIB peut ou ne doit pas être effectuée. Ces cas incluent :

  • les MIB fondamentaux contenant des pièces implémentées manuellement ou des MACRO's ASN.1
  • les MIB obsolètes entièrement réimplémentés dans des MIB modernes
  • les MIB déjà transformés

MibCompiler s'attend à ce que l'utilisateur fournisse un objet searcher qui permettrait ou ignorerait la transformation des MIB pour un nom particulier en fonction de la raison dont il a connaissance.

Recherche de fichiers Python

Les MIB transformés qui ont été sauvegardés sous forme de fichiers Python peuvent être vérifiés avec des instances de la classe PyFileSearcher.

Recherche de packages Python

Certains MIB, le plus souvent les MIB de base, peuvent être stockés dans un package Python. Leur existence peut être vérifiée avec des instances de la classe PyPackageSearcher.

Ignorer inconditionnellement les MIB

Les MIB fondamentaux ou obsolètes qui ne doivent jamais être transformés peuvent être exclus aveuglément en listant leurs noms dans l'instance de la classe StubSearcher.

Configuration du parseur

Les MIB peuvent être écrits dans l'une des deux versions majeures du langage SMI (v1 et v2). Certains MIB peuvent contenir des erreurs typiques.

PySMI offre un moyen de personnaliser le parseur pour consommer l'une des grammaires SMI majeures ainsi que pour récupérer des erreurs bien connues dans les fichiers MIB.

Parseur SMI

Les MIB SNMP sont écrits dans deux types de langages spéciaux - SMIv1 et SMIv2. La première version SMI est obsolète, la plupart des MIB sont maintenant écrits dans la grammaire SMIv2. Il y a aussi des efforts visant à améliorer SMIv2, mais ces MIB sont en minorité à l'heure de cette rédaction.

PySMI est conçu pour gérer à la fois SMIv1 et SMIv2. La manière dont cela est fait est que SMIv2 est considéré comme le plus basique et le plus complet, tandis que SMIv1 est une spécialisation de la syntaxe SMIv2.

Pour qu'un utilisateur obtienne un parseur SMIv2, la fonction parserFactory doit être appelée avec l'objet dialect SMI.

L'objet parseur doit être passé à l'objet MibCompiler.

NOTE:

Veuillez noter que la fonction parserFactory retourne une classe, pas une instance de classe. Assurez-vous de l'instancier lors de la transmission au constructeur de la classe MibCompiler.

Dialectes du langage SMI

PySMI offre une collection pré-construite d'options de relaxation de grammaire du parseur pour simplifier son utilisation :

  • pysmi.parser.dialect.smiV2 - grammaire SMIv2 canonique
  • pysmi.parser.dialect.smiV1 - grammaire SMIv1 canonique
  • pysmi.parser.dialect.smiV1Relaxed - grammaire SMIv1 relaxée autorisant quelques déviations

L'objet grammaire doit être passé à la fonction parserFactory.

from pysmi.parser.dialect import smiV1
from pysmi.parser.smi import parserFactory
SmiV1Parser = parserFactory(**smiV1)

Apparemment, de nombreux MIB de production ont été livrés dans un état syntaxiquement défectueux. PySMI tente de contourner ces problèmes en autorisant certaines relaxations supplémentaires de la grammaire SMI. Vous pouvez activer toutes ces relaxations à la fois pour maximiser le nombre de MIB, trouvés dans la nature, compilés avec succès.

from pysmi.parser.dialect import smiV1Relaxed
from pysmi.parser.smi import parserFactory
RelaxedSmiV1Parser = parserFactory(**smiV1Relaxed)

Compiler les MIB en JSON

Rechercher des MIB ASN.1 spécifiques sur des sites Web et FTP configurés, les compiler en documents JSON et les imprimer sur la sortie standard.

Essayer de prendre en charge les deux saveurs SMIv1 et SMIv2 de SMI, ainsi que les déviations populaires de la syntaxe officielle trouvées dans la nature.

from pysmi.reader import FileReader, HttpReader
from pysmi.searcher import StubSearcher
from pysmi.writer import CallbackWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import JsonCodeGen
from pysmi.compiler import MibCompiler
# from pysmi import debug
# debug.setLogger(debug.Debug('reader', 'compiler'))
inputMibs = ['IF-MIB', 'IP-MIB']
srcDirectories = ['/usr/share/snmp/mibs']
httpSources = [
    ('mibs.snmplabs.com', 80, '/asn1/@mib@')
]
def printOut(mibName, jsonDoc, cbCtx):
    print('\n\n# MIB module %s' % mibName)
    print(jsonDoc)
# Initialiser l'infrastructure du compilateur
mibCompiler = MibCompiler(
    SmiStarParser(), JsonCodeGen(), CallbackWriter(printOut)
)
# rechercher les MIB sources ici
mibCompiler.addSources(*[FileReader(x) for x in srcDirectories])
# rechercher les MIB sources sur les sites Web
mibCompiler.addSources(*[HttpReader(*x) for x in httpSources])
# ne jamais recompiler les MIB avec des MACROs
mibCompiler.addSearchers(StubSearcher(*JsonCodeGen.baseMibs))
# lancer la compilation récursive des MIB
results = mibCompiler.compile(*inputMibs)
print('\n# Résultats : %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

Compiler les MIB depuis le Web

Rechercher des MIB ASN.1 spécifiques sur des sites Web et FTP configurés, les compiler au format pysnmp et enregistrer les modules Python sous forme de fichiers texte brut dans un répertoire local.

Essayer de prendre en charge les deux saveurs SMIv1 et SMIv2 de SMI, ainsi que les déviations populaires de la syntaxe officielle trouvées dans la nature.

Dans cet exemple, nous désactivons la vérification automatique des dépendances lors de la compilation des MIB en utilisant l'indicateur noDeps.

De plus, nous ne vérifions pas si le fichier cible existe déjà, de sorte que la compilation des MIB se produit à chaque invocation.

from pysmi.reader import HttpReader
from pysmi.reader import FtpReader
from pysmi.searcher import StubSearcher
from pysmi.writer import PyFileWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import PySnmpCodeGen
from pysmi.compiler import MibCompiler
inputMibs = ['IF-MIB', 'IP-MIB']
httpSources = [
    ('mibs.snmplabs.com', 80, '/asn1/@mib@')
]
ftpSources = [
    ('ftp.cisco.com', '/pub/mibs/v2/@mib@')
]
dstDirectory = '.pysnmp-mibs'
# Initialiser l'infrastructure du compilateur
mibCompiler = MibCompiler(
    SmiStarParser(), PySnmpCodeGen(), PyFileWriter(dstDirectory)
)
# rechercher les MIB sources sur les sites Web et FTP
mibCompiler.addSources(*[HttpReader(*x) for x in httpSources])
mibCompiler.addSources(*[FtpReader(*x) for x in ftpSources])
# ne jamais recompiler les MIB avec des MACROs
mibCompiler.addSearchers(StubSearcher(*PySnmpCodeGen.baseMibs))
# lancer la compilation non récursive des MIB
results = mibCompiler.compile(*inputMibs, **dict(noDeps=True))
print('Résultats : %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

Compiler les MIB SMIv1/v2

Rechercher des MIB ASN.1 spécifiques dans des répertoires locaux configurés, les compiler au format pysnmp si ce n'est pas déjà fait et enregistrer les modules Python sous forme de fichiers texte brut dans un répertoire local.

Essayer de prendre en charge les deux saveurs SMIv1 et SMIv2 de SMI, ainsi que les déviations populaires de la syntaxe officielle trouvées dans la nature.

Lorsqu'il détermine si une compilation est nécessaire, il vérifie tous les endroits connus où les MIB pysnmp pourraient éventuellement se trouver.

Vous pouvez forcer la recompilation des MIB en passant l'indicateur rebuild au compilateur de MIB (voir ci-dessous).

L'invocation par défaut du compilateur de MIB ne génère pas les commentaires et textes [potentiellement volumineux] trouvés dans les MIB. Si vous en avez besoin dans les modules MIB pysnmp, passez simplement l'indicateur genTexts au compilateur de MIB.

from pysmi.reader import FileReader
from pysmi.searcher import PyFileSearcher, PyPackageSearcher, StubSearcher
from pysmi.writer import PyFileWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import PySnmpCodeGen
from pysmi.compiler import MibCompiler
inputMibs = ['IF-MIB', 'IP-MIB']
srcDirectories = ['/usr/share/snmp/mibs']
dstDirectory = '.pysnmp-mibs'
# Initialiser l'infrastructure du compilateur
mibCompiler = MibCompiler(SmiStarParser(),
                          PySnmpCodeGen(),
                          PyFileWriter(dstDirectory))
# rechercher les MIB sources ici
mibCompiler.addSources(*[FileReader(x) for x in srcDirectories])
# vérifier les MIB compilées dans nos propres productions
mibCompiler.addSearchers(PyFileSearcher(dstDirectory))
# ... et dans les paquets MIB PySNMP par défaut
mibCompiler.addSearchers(*[PyPackageSearcher(x) for x in PySnmpCodeGen.defaultMibPackages])
# ne jamais recompiler les MIB avec des MACROs
mibCompiler.addSearchers(StubSearcher(*PySnmpCodeGen.baseMibs))
# lancer la compilation récursive [éventuelle] des MIB
results = mibCompiler.compile(*inputMibs)  #, rebuild=True, genTexts=True)
print('Résultats : %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

Compiler les MIB SMIv2

Invoquer une fonction de rappel utilisateur pour fournir le texte de la MIB, compiler la chaîne de texte donnée au format MIB pysnmp et transmettre les résultats à une autre fonction de rappel utilisateur pour le stockage.

Ici, nous nous attendons à ne traiter que des MIB valides SMIv2.

Nous utilisons l'indicateur noDeps pour empêcher le compilateur de MIB de tenter de compiler également les MIB IMPORTées.

import sys
from pysmi.reader import CallbackReader
from pysmi.searcher import StubSearcher
from pysmi.writer import CallbackWriter
from pysmi.parser import SmiV2Parser
from pysmi.codegen import PySnmpCodeGen
from pysmi.compiler import MibCompiler
inputMibs = ['IF-MIB', 'IP-MIB']
srcDir = '/usr/share/snmp/mibs/'  # nous lirons les MIB à partir d'ici
# Initialiser l'infrastructure du compilateur
mibCompiler = MibCompiler(
    SmiV2Parser(),
    PySnmpCodeGen(),
    # notre propre fonction de rappel stocke les résultats à sa manière
    CallbackWriter(lambda m, d, c: sys.stdout.write(d))
)
# notre propre fonction de rappel sert de source de MIB ici
mibCompiler.addSources(
  CallbackReader(lambda m, c: open(srcDir+m+'.txt').read())
)
# ne jamais recompiler les MIB avec des MACROs
mibCompiler.addSearchers(StubSearcher(*PySnmpCodeGen.baseMibs))
# lancer la compilation non récursive des MIB
results = mibCompiler.compile(*inputMibs, **dict(noDeps=True))
print('Résultats : %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

Emprunter les MIB pysnmp en cas d'échec

Rechercher des MIB ASN.1 spécifiques sur des sites Web/FTP configurés. Si la MIB requise n'est pas trouvée ou si sa compilation échoue pour une raison quelconque, tenter de télécharger une version précompilée de la MIB défaillante et de la stocker localement comme si nous l'avions compilée.

from pysmi.reader import HttpReader
from pysmi.searcher import PyFileSearcher
from pysmi.searcher import StubSearcher
from pysmi.borrower import PyFileBorrower
from pysmi.writer import PyFileWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import PySnmpCodeGen
from pysmi.compiler import MibCompiler
# from pysmi import debug
# debug.setLogger(debug.Debug('borrower', 'reader', 'searcher'))
inputMibs = ['BORROWED-MIB']
httpSources = [ 
    ('mibs.snmplabs.com', 80, '/asn1/@mib@')
]
httpBorrowers = [
    ('mibs.snmplabs.com', 80, '/pysnmp/notexts/@mib@')
]
dstDirectory = '.pysnmp-mibs'
# Initialiser l'infrastructure du compilateur
mibCompiler = MibCompiler(
    SmiStarParser(), PySnmpCodeGen(), PyFileWriter(dstDirectory)
)
# rechercher les MIB sources sur les sites Web
mibCompiler.addSources(*[HttpReader(*x) for x in httpSources])
# ne jamais recompiler les MIB avec des MACROs
mibCompiler.addSearchers(StubSearcher(*PySnmpCodeGen.baseMibs))
# vérifier les MIB compilées/empruntées dans nos propres productions
mibCompiler.addSearchers(PyFileSearcher(dstDirectory))
# rechercher les MIB compilées sur les sites Web si la source n'est pas disponible ou cassée
mibCompiler.addBorrowers(*[PyFileBorrower(HttpReader(*x)).setOptions(genTexts=False) for x in httpBorrowers])
# lancer la compilation non récursive des MIB
results = mibCompiler.compile(*inputMibs)
print('Résultats : %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

Toujours emprunter les MIB pysnmp

Essayer d'emprunter des fichiers MIB pysnmp précompilés sur un site Web.

Dans cet exemple, aucune tentative n'est faite pour trouver et compiler la source MIB ASN.1.

Les MIB pysnmp récupérées sont stockées dans un répertoire local.

from pysmi.reader import HttpReader
from pysmi.searcher import PyFileSearcher
from pysmi.borrower import PyFil
eBorrower
from pysmi.writer import PyFileWriter
from pysmi.parser import NullParser
from pysmi.codegen import NullCodeGen
from pysmi.compiler import MibCompiler
inputMibs = ['BORROWED-MIB']
httpBorrowers = [
    ('mibs.snmplabs.com', 80, '/pysnmp/notexts/@mib@')
]
dstDirectory = '.pysnmp-mibs'
# Initialisation de l'infrastructure du compilateur
mibCompiler = MibCompiler(
    NullParser(), NullCodeGen(), PyFileWriter(dstDirectory)
)
# vérifier les MIB compilées/empruntées dans nos propres productions
mibCompiler.addSearchers(PyFileSearcher(dstDirectory))
# rechercher les MIB pré-compilées sur les sites Web
mibCompiler.addBorrowers(
    *[PyFileBorrower(HttpReader(*x)) for x in httpBorrowers]
)
# exécuter la compilation des MIB
results = mibCompiler.compile(*inputMibs)
print('Résultats : %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))
