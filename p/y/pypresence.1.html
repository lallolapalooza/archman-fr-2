INSTALLATION

Installez pypresence avec pip :

pip install pypresence

Ou pour la version en développement, vous pouvez utiliser :

pip install https://github.com/qwertyquerty/pypresence/archive/master.zip

INFORMATION

À propos

Pypresence est un wrapper pour Discord RPC. Vous pouvez l'utiliser pour la Présence Riche de vos jeux, ainsi que pour d'autres intégrations Discord.

Démarrage rapide

Cette page existe si vous n'avez absolument aucune idée de ce que vous faites, ou si vous avez juste besoin d'un démarrage rapide. (Pour la présence riche)

La première chose à faire est de créer une application Discord RPC. Voici les étapes :

  • Accédez à https://discord.com/developers/
  • Cliquez sur « Créer une application ».
  • Configurez l'application comme vous le souhaitez, donnez-lui le nom que vous voulez et une bonne image.
  • Juste en dessous du nom de votre application, trouvez votre ID client. Vous en aurez besoin plus tard.
  • Enfin, sauvegardez votre application.

Ensuite, vous devez installer pypresence. Vous aurez besoin de python 3.9+ installé. Voici les étapes :

  • Ouvrez l'invite de commande
  • Tapez pip install pypresence et appuyez sur Entrée
  • Il devrait dire quelque chose vers la fin comme « Successfully installed pypresence ».

Maintenant, vous devrez créer le programme pour définir votre présence riche. D'abord, nous devons importer ce dont nous avons besoin, comme suit :

from pypresence import Presence # Le client de présence riche simple dans pypresence
import time

Ensuite, nous devons initialiser notre client de Présence Riche. Vous aurez besoin de cet ID client d'avant :

client_id = "ID ICI"  # Mettez votre ID client ici
RPC = Presence(client_id)  # Initialiser le client Presence

Maintenant, nous devons connecter notre client à Discord, afin qu'il puisse envoyer des mises à jour de présence :

RPC.connect() # Démarrer la boucle de négociation

Maintenant, nous devons réellement définir notre présence riche. Nous pouvons utiliser la fonction update() pour cela. Il existe de nombreuses options que nous pouvons utiliser, mais pour cela, nous utiliserons celles-ci :

 RPC.update(
    state="La voici !",
    details="Une présence fonctionnelle, depuis python !",
    name="Exemple de présence riche",
) # Met à jour notre présence

Maintenant, nous avons besoin que notre programme s'exécute indéfiniment, donc nous utilisons une boucle while.

while True:  # La présence restera activée tant que le programme est en cours d'exécution
    time.sleep(15) # Ne peut mettre à jour la présence riche que toutes les 15 secondes

Maintenant, lorsque vous exécutez votre programme, il devrait ressembler à ceci !

Utilisation des types d'activités et des types d'affichage de statut

Vous pouvez personnaliser l'apparence de votre présence en utilisant les énumérations ActivityType et StatusDisplayType. Voici un exemple :

from pypresence import Presence
from pypresence.types import ActivityType, StatusDisplayType
import time
client_id = "ID ICI"
RPC = Presence(client_id)
RPC.connect()
# Afficher comme « Écoute » au lieu de « Joue »
RPC.update(
    activity_type=ActivityType.LISTENING,
    details="Ma chanson préférée",
    state="Par mon artiste préféré"
)
# Ou utilisez StatusDisplayType pour contrôler ce qui apparaît dans le statut de l'utilisateur
RPC.update(
    status_display_type=StatusDisplayType.STATE,
    state="Je construis quelque chose d'incroyable",
    details="Utilisation de pypresence"
)
while True:
    time.sleep(15)

Types d'activités disponibles : PLAYING (par défaut), LISTENING, WATCHING, COMPETING

Types d'affichage de statut disponibles : NAME (par défaut - affiche le nom de l'application), STATE, DETAILS

Présence Riche pour afficher l'utilisation du CPU :

import psutil
from pypresence import Presence
import time
client_id = "64567352374564"  # Faux ID, mettez le vôtre ici
RPC = Presence(client_id, pipe=0)  # Initialiser la classe client
RPC.connect()  # Démarrer la boucle de négociation
while True:  # La présence restera activée tant que le programme est en cours d'exécution
    cpu_per = round(psutil.cpu_percent(), 1)  # Obtenir l'utilisation du CPU
    mem = psutil.virtual_memory()
    mem_per = round(psutil.virtual_memory().percent, 1)
    print(
        RPC.update(
            details="RAM : " + str(mem_per) + "%", state="CPU : " + str(cpu_per) + "%"
        )
    )  # Définir la présence
    time.sleep(15)  # Ne peut mettre à jour la présence riche que toutes les 15 secondes

    Énumération ActivityType

    L'énumération ActivityType spécifie le type d'activité affiché. Elle est importée de pypresence.types.

    Valeurs disponibles :

    • ActivityType.PLAYING (0) - Affiche "Joue à {nom du jeu}" (par défaut)
    • ActivityType.LISTENING (2) - Affiche "Écoute {nom}"
    • ActivityType.WATCHING (3) - Affiche "Regarde {nom}"
    • ActivityType.COMPETING (5) - Affiche "Participe à {nom}"

    Exemple d'utilisation :

    from pypresence import Presence
from pypresence.types import ActivityType
RPC = Presence(client_id)
RPC.connect()
RPC.update(
    activity_type=ActivityType.LISTENING,
    details="Ma chanson préférée",
    state="Par mon artiste préféré"
)

    Note : Discord ne prend en charge que les types d'activité 0, 2, 3 et 5. Les types 1 (STREAMING) et 4 (CUSTOM) ne sont pas disponibles via la Présence riche.

    Énumération StatusDisplayType

    L'énumération StatusDisplayType contrôle quel champ de votre présence est affiché dans le statut de l'utilisateur. Elle est importée de pypresence.types.

    Valeurs disponibles :

    • StatusDisplayType.NAME (0) - Affiche le nom de l'application (par défaut)
    • StatusDisplayType.STATE (1) - Affiche le champ state
    • StatusDisplayType.DETAILS (2) - Affiche le champ details

    Exemple d'utilisation :

    from pypresence import Presence
from pypresence.types import StatusDisplayType
RPC = Presence(client_id)
RPC.connect()
RPC.update(
    status_display_type=StatusDisplayType.STATE,
    state="Message de statut personnalisé",
    details="Ce que je fais"
)

    Cela vous permet de contrôler ce qui apparaît dans la barre de statut de Discord de l'utilisateur tout en conservant toutes les informations dans l'affichage complet de la Présence riche.
