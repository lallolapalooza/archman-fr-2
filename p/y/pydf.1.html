PYDF(1) Manuel des commandes générales PYDF(1)

NOM

pydf - rapport d'utilisation de l'espace disque du système de fichiers colorisé

SYNTAXE

pydf [options] [fichier]

DESCRIPTION

pydf est un script python qui affiche la quantité d'espace disque disponible sur les systèmes de fichiers montés, en utilisant différentes couleurs pour différents types de systèmes de fichiers. Le format de sortie est entièrement personnalisable.

Si un argument
fichier optionnel est donné, pydf affiche uniquement les informations sur le système de fichiers contenant le(s) fichier(s), sinon il affiche les informations sur tous les systèmes de fichiers montés.

OPTIONS

--help
Afficher un résumé des options.
-v, --version
Afficher la version du programme.
-a, --all
inclure les systèmes de fichiers ayant 0 blocs
-h, --human-readable
afficher les tailles dans un format lisible par l'homme (par exemple, 133K 2341M 2448G)
-H, --si
idem, mais utiliser des puissances de 1000 et non de 1024
--taille-bloc=TAILLE
utiliser des blocs de TAILLE octets
-k, --kilooctets
équivalent à --taille-bloc=1024
-i, --inodes
afficher des informations sur les inodes au lieu des blocs
-l, --local
limiter l'affichage aux systèmes de fichiers locaux
-m, --mega-octets
équivalent à --taille-bloc=1048576
-g, --giga-octets
équivalent à --taille-bloc=1073741824
--blocs
utiliser la taille de bloc native du système de fichiers
--nb
ne pas utiliser les couleurs
--montages=FICHIER
fichier à partir duquel obtenir les informations de montage. Sur un système Linux normal, seuls /etc/mtab ou /proc/mounts ont un sens. Utiliser /proc/mounts lorsque /etc/mtab est corrompu ou inaccessible (la sortie semblera un peu étrange dans ce cas)
-B, --show-binds
Afficher également les systèmes de fichiers montés avec --mount --bind.

BOGUES

Lors de l'exécution avec python3, les points de montage avec des noms non ASCII hors locale ne seront pas affichés (en raison de l'incapacité d'os.statvfs à utiliser des octets au lieu de chaînes).

FICHIERS

/etc/pydfrc
fichier de configuration principal
~/.pydfrc
fichier de configuration par utilisateur
