Ce module peut être utilisé pour générer des fils d'actualité web aux formats ATOM et RSS. Il prend en charge les extensions. Il inclut, par exemple, une extension pour produire des podcasts.

INSTALLATION

Paquets précompilés

Si votre distribution inclut ce projet en tant que paquet, comme Fedora Linux, vous pouvez simplement utiliser votre gestionnaire de paquets pour installer le paquet. Par exemple :

$ dnf install python3-feedgen

Utilisation de pip

Vous pouvez également utiliser pip pour installer le module feedgen. Exécutez simplement :

$ pip install feedgen

CRÉER UN FIL D'ACTUALITÉ

Pour créer un fil d'actualité, instanciez simplement la classe FeedGenerator et insérez des données :

from feedgen.feed import FeedGenerator
fg = FeedGenerator()
fg.id('http://lernfunk.de/media/654321')
fg.title('Some Testfeed')
fg.author( {'name':'John Doe','email':'john@example.de'} )
fg.link( href='http://example.com', rel='alternate' )
fg.logo('http://ex.com/logo.jpg')
fg.subtitle('This is a cool feed!')
fg.link( href='http://larskiesow.de/test.atom', rel='self' )
fg.language('en')

Notez que pour les méthodes qui définissent des champs pouvant apparaître plusieurs fois dans un fil d'actualité, vous pouvez utiliser toutes les manières suivantes de fournir des données :

  • Fournir les données pour cet élément sous forme d'arguments nommés (keyword arguments).
  • Fournir les données pour cet élément sous forme de dictionnaire.
  • Fournir une liste de dictionnaires avec les données pour plusieurs éléments.

Exemple :

fg.contributor( name='John Doe', email='jdoe@example.com' )
fg.contributor({'name':'John Doe', 'email':'jdoe@example.com'})
fg.contributor([{'name':'John Doe', 'email':'jdoe@example.com'}, ...])

GÉNÉRER LE FIL D'ACTUALITÉ

Après cela, vous pouvez générer des flux RSS ou ATOM en appelant la méthode respective :

atomfeed = fg.atom_str(pretty=True) # Obtenir le flux ATOM sous forme de chaîne
rssfeed  = fg.rss_str(pretty=True) # Obtenir le flux RSS sous forme de chaîne
fg.atom_file('atom.xml') # Écrire le flux ATOM dans un fichier
fg.rss_file('rss.xml') # Écrire le flux RSS dans un fichier

AJOUTER DES ENTRÉES AU FIL D'ACTUALITÉ

Pour ajouter des entrées (éléments) à un fil d'actualité, vous devez créer de nouveaux objets FeedEntry et les ajouter à la liste des entrées dans le FeedGenerator. La manière la plus pratique est d'utiliser le FeedGenerator lui-même pour l'instanciation de l'objet FeedEntry :

fe = fg.add_entry()
fe.id('http://lernfunk.de/media/654321/1')
fe.title('The First Episode')
fe.link(href="http://lernfunk.de/feed")

La méthode add_entry(...) du FeedGenerator générera un nouvel objet FeedEntry, l'ajoutera automatiquement à la liste interne des entrées du flux et la retournera, afin que des données supplémentaires puissent être ajoutées.

EXTENSIONS

FeedGenerator prend en charge les extensions pour inclure des données supplémentaires dans la structure XML des flux. Les extensions peuvent être chargées comme ceci :

fg.load_extension('someext', atom=True, rss=True)

Cet exemple tenterait de charger l'extension “someext” depuis le fichier ext/someext.py. Il est requis que someext.py contienne une classe nommée “SomextExtension” qui doit avoir au moins les deux méthodes extend_rss(...) et extend_atom(...). Bien que non requis, il est fortement suggéré d'utiliser BaseExtension de ext/base.py comme classe parente.

load_extension('someext', ...) tentera également de charger une classe nommée “SomextEntryExtension” pour chaque entrée du flux. Cette classe peut être située soit dans le même fichier que SomextExtension, soit dans ext/someext_entry.py, ce qui est suggéré en particulier pour les extensions volumineuses.

Les paramètres atom et rss contrôlent si l'extension est utilisée pour les flux ATOM et RSS respectivement. La valeur par défaut pour les deux paramètres est True, ce qui signifie que l'extension est utilisée pour les deux types de flux.

Exemple : Produire un Podcast

Une extension déjà fournie est l'extension podcast. Un podcast est un flux RSS avec des éléments supplémentaires pour ITunes.

Pour produire un podcast, chargez simplement l'extension podcast :

from feedgen.feed import FeedGenerator
fg = FeedGenerator()
fg.load_extension('podcast')
...
fg.podcast.itunes_category('Technology', 'Podcasting')
...
fe = fg.add_entry()
fe.id('http://lernfunk.de/media/654321/1/file.mp3')
fe.title('The First Episode')
fe.description('Enjoy our first episode.')
fe.enclosure('http://lernfunk.de/media/654321/1/file.mp3', 0, 'audio/mpeg')
...
fg.rss_str(pretty=True)
fg.rss_file('podcast.xml')

Si la classe FeedGenerator est utilisée pour charger une extension, elle est automatiquement chargée pour chaque entrée du flux également. Vous pouvez, cependant, charger une extension pour un FeedEntry spécifique uniquement en appelant load_extension(...) sur cette entrée.

Même si les extensions sont chargées, elles peuvent être temporairement désactivées pendant la génération du flux en appelant la méthode de génération avec l'argument nommé extensions défini sur False.

Extensions personnalisées

Si vous souhaitez charger des extensions personnalisées qui ne font pas partie du package feedgen, vous pouvez utiliser la méthode register_extension à la place. Vous pouvez passer directement les classes pour le flux et l'extension d'entrée à cette méthode, ce qui signifie que vous pouvez les définir n'importe où.

  • name transmet un nom lisible par l'homme pour la personne.
  • uri contient une page d'accueil pour la personne.
  • email contient une adresse e-mail pour la personne.

  • author -- Dictionnaire ou liste de dictionnaires avec les données de l'auteur.
  • replace -- Ajouter ou remplacer l'o
d donnée.

link(link=None, replace=False, **kwargs)
Obtient ou définit les données de lien. Un élément de lien est un dict avec les champs href, rel, type, hreflang, title et length. Href est obligatoire pour ATOM.

Cette méthode peut être appelée avec :

  • les champs d'un lien en tant qu'arguments de mot-clé
  • les champs d'un lien en tant que dictionnaire
  • une liste de dictionnaires contenant les champs de lien

Un lien a les champs suivants :

  • href est l'URI de la ressource référencée (typiquement une page Web)
  • rel contient un seul type de relation de lien. Il peut s'agir d'une URI complète, ou de l'une des valeurs prédéfinies suivantes (défaut=alternate) :
  • alternate une représentation alternative de l'entrée ou du flux, par exemple un permalien vers la version html de l'entrée, ou la page d'accueil du weblog.
  • enclosure une ressource associée potentiellement volumineuse qui pourrait nécessiter un traitement spécial, par exemple un enregistrement audio ou vidéo.
  • related un document lié à l'entrée ou au flux.
  • self le flux lui-même.
  • via la source des informations fournies dans l'entrée.
  • type indique le type de média de la ressource.
  • hreflang indique la langue de la ressource référencée.
  • title informations lisibles par l'homme sur le lien, généralement pour l'affichage.
  • length la longueur de la ressource, en octets.

RSS ne prend en charge qu'un seul lien avec une URL uniquement.

Paramètres
  • link -- Dict ou liste de dicts avec les données.
  • replace -- Si les anciens liens doivent être remplacés (défaut : False)
Retourne
Ensemble actuel des données de lien

    • alternate une représentation alternative de l'entrée ou du flux, par exemple un permalien vers la version html de l'entrée, ou la page d'accueil du blog.

    • self le flux lui-même.
    • via la source des informations fournies dans l'entrée.

    • hreflang indique la langue de la ressource référencée.
    • title informations lisibles par l'homme sur le lien, généralement à des fins d'affichage.
    • length la longueur de la ressource, en octets.

    from feedgen.feed import FeedGenerator

fg = FeedGenerator()

fg.logo('http://example.com/logo.png')
fg.language('en')
fg.lastBuildDate(datetime.now())

fg.id('my-feed-id') # or use fg.link for this

    from datetime import datetime

fe = fg.add_entry()
fe.title('My first entry')
fe.description('This is a description of my first entry.')
fe.link(href='http://example.com/entry1')
fe.pubdate(datetime.now())

fe.guid('my-entry-guid-1')

fe = fg.add_entry()
