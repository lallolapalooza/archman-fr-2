pysmi - Compilateur SMI SNMP

DOCUMENTATION

Documentation PySMI

La bibliothèque PySMI est hautement modulaire. Le composant de niveau supérieur est appelé compiler et agit comme l'objet principal visible par l'utilisateur. La plupart des autres composants sont branchés à l'objet compiler avant son utilisation.

Normalement, l'utilisateur demande au compiler d'effectuer une certaine transformation de module MIB nommé. Le compilateur effectuera les actions suivantes :

  • Recherche dans ses sources de données le module MIB donné (identifié par son nom) en notant leurs dates de dernière modification.
  • Recherche dans les dépôts gérés par le compilateur de modules MIB déjà convertis, les modules qui sont plus récents que le module MIB source correspondant.
  • Si un module MIB fraîchement transformé est trouvé, le traitement s'arrête ici.
  • Sinon, le compilateur passe le contenu du module MIB ASN.1 au composant lexer.
  • Le lexer renvoie une séquence de tokens du contenu MIB ASN.1. Le compilateur passe ensuite cette séquence de tokens au composant parser.
  • Le parser exécute un algorithme LR sur le MIB tokenisé, transformant ainsi le contenu du MIB en un Arbre de Syntaxe Abstraite (AST) et notant également quels autres modules MIB sont référencés à partir du MIB en cours d'analyse.
  • En cas d'échec du parser, ce qui indique généralement une syntaxe MIB ASN.1 incorrecte, le compilateur peut tenter de récupérer le contenu MIB pré-transformé à partir de la source configurée. Ce processus est appelé borrowing dans PySMI.
  • En cas de succès de l'achèvement du parser, le compilateur passe l'AST produit au composant code generator.
  • Le générateur de code parcourt son AST d'entrée et effectue la transformation des données réelle.
  • Les étapes ci-dessus peuvent être répétées pour chacun des modules MIB référencés au fur et à mesure que le parser les découvre. Une fois qu'il n'y a plus de dépendances non résolues, le compilateur appelle son composant writer pour stocker tous les modules MIB transformés.

L'emplacement des modules MIB ASN.1 et la saveur de leur syntaxe, ainsi que le format de transformation souhaité, sont déterminés par les composants respectifs choisis et configurés pour le compilateur.

L'outil mibdump

L'outil mibdump.py est une interface en ligne de commande pour la bibliothèque PySMI. Cet outil peut être utilisé pour télécharger et transformer automatiquement les modules MIB SNMP dans divers formats.

Spécification de la source MIB

L'option --mib-source peut être donnée plusieurs fois. Chaque instance de --mib-source doit spécifier une URL où les modules MIB ASN.1 doivent être recherchés et téléchargés. Actuellement, trois méthodes de sourcing MIB sont prises en charge :

  • Fichiers locaux. Il peut s'agir d'un répertoire de niveau supérieur où se trouvent les fichiers MIB. Les sous-répertoires seront également parcourus automatiquement. Exemple : file:///usr/share/snmp
  • Archives ZIP contenant des fichiers MIB. Les sous-répertoires et les archives ZIP incorporées seront parcourus automatiquement. Exemple : zip://mymibs.zip
  • HTTP/HTTPS. Une URL complètement spécifiée où le nom du module MIB est spécifié par un espace réservé @mib@. Lorsqu'un MIB spécifique est recherché, PySMI remplacera cet espace réservé par le nom du module MIB qu'il recherche. Exemple : http://mibs.snmplabs.com/asn1/@mib@
  • SFTP/FTP. Une URL complètement spécifiée incluant le nom d'utilisateur et le mot de passe FTP. Le nom du module MIB est spécifié par un espace réservé @mib@. Lorsqu'un MIB spécifique est recherché, PySMI remplacera cet espace réservé par le nom du module MIB qu'il recherche. Exemple : http://mibs.snmplabs.com/asn1/@mib@

Lors de la tentative de récupération d'un module MIB, l'outil mibdump.py essaiera chaque transport --mib-source configuré dans l'ordre de spécification jusqu'à la première réussite.

Par défaut, mibdump.py recherchera :

  • file:///usr/share/snmp
  • http://mibs.snmplabs.com/asn1/@mib@

Une fois qu'une autre option --mib-source est donnée, ces valeurs par défaut ne seront pas utilisées et devront être fournies manuellement à mibdump.py si nécessaire.

Fuzzing des noms de modules MIB

Il n'y a pas de convention unique sur la façon dont les noms de fichiers de modules MIB doivent être nommés. Par défaut, mibdump.py essaiera plusieurs devinettes lors de la recherche d'un fichier contenant un module MIB spécifique. Il essaiera les majuscules et minuscules, un fichier nommé d'après le module MIB, essaiera d'ajouter différentes extensions au fichier (.mib, .my etc.), essaiera d'ajouter/supprimer la partie '-MIB' du nom du fichier. Si rien ne correspond, mibdump.py considérera que le --mib-source sondé ne contient pas le module MIB recherché.

Il y a une petite chance, cependant, que la correspondance floue puisse aboutir à l'obtention d'un MIB incorrect. Si cela se produit, vous pouvez désactiver le fuzzing ci-dessus en donnant à mibdump.py le drapeau --disable-fuzzy-source.

L'option --mib-searcher spécifie soit un répertoire local, soit un paquet Python importable (applicable à la transformation pysnmp) contenant des modules MIB transformés.   • --mib-searcher=pysnmp_mibs

Mise sur liste noire des MIB

Certaines MIB ne peuvent pas être automatiquement transformées sous une autre forme et doivent donc être explicitement exclues du traitement. Ces MIB sont normalement implémentées manuellement pour chaque format de MIB cible. Les exemples incluent les MIB contenant des types SMI de base ou des définitions de MACRO ASN.1 (SNMPv2-SMI, SNMPV2-TC), les MIB initialement compilées mais modifiées manuellement par la suite, et d'autres.

La liste par défaut des MIB mises sur liste noire pour la cible de transformation pysnmp est : RFC-1212, RFC-1215, RFC1065-SMI, RFC1155-SMI, RFC1158-MIB, RFC1213-MIB, SNMP-FRAMEWORK-MIB, SNMP-TARGET-MIB, SNMPv2-CONF, SNMPv2-SMI, SNMPv2-TC, SNMPv2-TM, TRANSPORT-ADDRESS-MIB.

Si vous avez besoin de modifier cette liste, utilisez l'option --mib-stub.

Gestion des MIB cassées

Curieusement, certaines MIB provenant de fournisseurs très importants semblent syntaxiquement incorrectes. Cela conduit les compilateurs de MIB à échouer sur ces MIB. Bien que de nombreuses implémentations de compilateurs de MIB (y compris PySMI) introduisent des solutions de contournement et des assouplissements de grammaire permettant de compiler des MIB légèrement cassées, les MIB gravement cassées ne peuvent pas être compilées de manière fiable.

Comme autre solution de contournement, PySMI propose la fonctionnalité de borrow (emprunt). Elle permet à PySMI de récupérer des MIB déjà transformées, même si la MIB ASN.1 correspondante ne peut pas être trouvée ou analysée.

La source par défaut des MIB pré-compilées pour la cible pysnmp est :

  • http://mibs.snmplabs.com/pysnmp/fulltexts/@mib@
  • http://mibs.snmplabs.com/pysnmp/notexts/@mib@

Si vous souhaitez modifier cette liste par défaut, utilisez une ou plusieurs options --mib-borrower.

Choix de la transformation cible

La conception de PySMI permet de prendre en charge de nombreux formats de transformation sous forme de composants de génération de code spécialisés. Actuellement, PySMI peut produire des MIB sous forme de classes pysnmp et de documents JSON.

Le schéma du document JSON est choisi pour préserver autant d'informations de la MIB que possible. Il n'existe pas de schéma JSON établi connu des auteurs.

Définition du répertoire de destination

Par défaut, mibdump.py écrit les MIB pysnmp dans :

  • $HOME/.pysnmp/mibs (sur UNIX)
  • @HOME@PySNMP ConfigurationMIBs (sur Windows)

et les fichiers JSON dans le répertoire de travail courant.

Utilisez l'option --destination-directory pour changer le répertoire de sortie par défaut.

Effectuer une transformation inconditionnelle

Par défaut, PySMI évitera de créer de nouvelles transformations si des versions suffisamment récentes existent déjà. En utilisant l'option --rebuild, vous pouvez tromper PySMI pour qu'il effectue la transformation demandée pour tous les modules MIB donnés.

Ignorer les erreurs de transformation

Par défaut, PySMI s'arrêtera à la première erreur fatale survenue lors de la transformation d'une série de MIB. Si vous souhaitez que PySMI ignore les erreurs fatales et donc ignore la MIB échouée, utilisez l'option --ignore-errors.

Gardez à l'esprit que l'omission de la transformation des MIB qui sont importées par d'autres MIB peut rendre les MIB dépendantes incohérentes pour l'utilisation.

Ignorer les dépendances

La plupart des MIB dépendent d'autres MIB pour leur fonctionnement. Ceci est indiqué par l'instruction IMPORT dans le langage ASN.1. PySMI tente de transformer toutes les MIB IMPORTées par la MIB en cours de transformation. Ceci est fait de manière récursive.

En utilisant le drapeau --no-dependencies, vous pouvez indiquer à PySMI de ne pas transformer d'autres MIB que celles explicitement demandées pour être transformées.

Gardez à l'esprit que l'omission des dépendances peut rendre l'ensemble des MIB transformées incohérent.

Générer les textes des MIB

La plupart des MIB sont très verbeuses. Elles contiennent de nombreuses descriptions et clarifications destinées aux humains, écrites en anglais courant. Ces textes peuvent être utiles pour les applications de navigation MIB (pour afficher ces textes à un opérateur humain) mais peuvent ne pas avoir de sens dans d'autres applications.

Pour économiser de l'espace et du temps CPU, PySMI n'inclut pas par défaut ces textes dans les MIB transformées. Cependant, cela peut être annulé en ajoutant l'option --generate-mib-texts.

Lorsque les textes de MIB sont générés, les espaces blancs et les retours à la ligne sont supprimés par défaut. Parfois, cela casse les dessins en ASCII qui pourraient apparaître dans les textes de MIB. Pour préserver la mise en forme originale du texte, l'option --keep-texts-layout peut être utilisée.

Construire les index de MIB

Si l'option --build-index est donnée, en fonction du format de destination choisi, l'outil mibdump.py peut créer de nouveaux documents (ou mettre à jour ceux existants) contenant des informations MIB sous une forme pratique pour interroger les propriétés fondamentales des fichiers MIB.

Petites optimisations

Il existe quelques options qui peuvent améliorer les performances de PySMI.

L'option --cache-directory peut être utilisée pour spécifier un répertoire temporaire inscriptible où l'analyseur PySMI (par exemple, Ply) stockerait ses tables de recherche.

Par défaut, PySMI, lors de la transformation au format pysnmp, précompile également la source Python en bytecode interpréteur. Cela prend du temps et de l'espace. Si vous ne souhaitez pas mettre en cache le bytecode Python ou le faire plus tard, utilisez l'option --no-python-compile.

L'outil mibcopy

L'outil mibcopy.py tente de normaliser le nom du fichier MIB.

Il s'est avéré que parfois les fournisseurs nomment leurs MIB de toutes les manières possibles, pas nécessairement d'après le nom canonique de la MIB. Cela pose des problèmes aux consommateurs de MIB car ils pourraient ne pas pouvoir localiser la MIB dont ils ont besoin sur le système de fichiers.

La façon dont fonctionne mibcopy.py est qu'il essaie de lire la MIB à partir du fichier donné (ou de tous les fichiers d'un répertoire ou d'une archive donnée), d'analyser le nom canonique de la MIB à partir du contenu du fichier. Sur cette base, l'outil essaie de renommer le fichier MIB avec un nom identique au nom canonique de la MIB. Si mibcopy.py rencontre un fichier portant le même nom déjà présent sur le système de fichiers, il le lit pour voir sa date de révision. Ensuite, l'outil compare les dates de révision des fichiers MIB en collision et remplace le fichier incriminé ou rejette le fichier en cours de copie comme étant obsolète.

L'objectif final est d'obtenir les dernières versions des fichiers MIB, tous nommés d'après leurs noms canoniques.

Emprunter des MIB pré-compilées

Certaines MIB en circulation semblent irrémédiablement cassées. Pour gérer de tels cas, PySMI introduit la fonctionnalité de *borrowing de MIB*. Lorsque *MibCompiler* abandonne la compilation d'une MIB, il peut essayer de chercher et de copier une MIB déjà transformée pour terminer la requête avec succès.

Exemples

Les exemples suivants se concentrent sur diverses fonctionnalités de la bibliothèque PySMI.

Compiler les MIB en JSON

Rechercher des MIB ASN.1 spécifiques sur des sites Web et FTP configurés, les compiler en documents JSON et les afficher sur stdout.

Essayer de prendre en charge les formats SMIv1 et SMIv2 de SMI, ainsi que les déviations populaires de la syntaxe officielle trouvées dans la nature.

from pysmi.reader import FileReader, HttpReader
from pysmi.searcher import StubSearcher
from pysmi.writer import CallbackWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import JsonCodeGen
from pysmi.compiler import MibCompiler
# from pysmi import debug
# debug.setLogger(debug.Debug('reader', 'compiler'))
inputMibs = ['IF-MIB', 'IP-MIB']
srcDirectories = ['/usr/share/snmp/mibs']
httpSources = [
    ('mibs.snmplabs.com', 80, '/asn1/@mib@')
]
def printOut(mibName, jsonDoc, cbCtx):
    print('\n\n# MIB module %s' % mibName)
    print(jsonDoc)
# Initialisation de l'infrastructure du compilateur
mibCompiler = MibCompiler(
    SmiStarParser(), JsonCodeGen(), CallbackWriter(printOut)
)
# rechercher les MIB sources ici
mibCompiler.addSources(*[FileReader(x) for x in srcDirectories])
# rechercher les MIB sources sur des sites Web
mibCompiler.addSources(*[HttpReader(*x) for x in httpSources])
# ne jamais recompiler les MIB avec des MACROs
mibCompiler.addSearchers(StubSearcher(*JsonCodeGen.baseMibs))
# exécuter la compilation récursive des MIB
results = mibCompiler.compile(*inputMibs)
print('\n# Résultats : %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

Compiler les MIB depuis le web

Rechercher des MIB ASN.1 spécifiques sur des sites Web et FTP configurés, les compiler au format pysnmp et enregistrer les modules Python sous forme de fichiers texte dans un répertoire local.

Essayer de prendre en charge les formats SMIv1 et SMIv2 de SMI, ainsi que les déviations populaires de la syntaxe officielle trouvées dans la nature.

Dans cet exemple, nous désactivons la vérification automatique des dépendances lors de la compilation des MIB en utilisant l'option noDeps.

De plus, nous ne vérifions pas si le fichier cible existe déjà, donc la compilation des MIB se produit à chaque invocation.

from pysmi.reader import HttpReader
from pysmi.reader import FtpReader
from pysmi.searcher import StubSearcher
from pysmi.writer import PyFileWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import PySnmpCodeGen
from pysmi.compiler import MibCompiler
inputMibs = ['IF-MIB', 'IP-MIB']
httpSources = [
    ('mibs.snmplabs.com', 80, '/asn1/@mib@')
]
ftpSources = [
    ('ftp.cisco.com', '/pub/mibs/v2/@mib@')
]
dstDirectory = '.pysnmp-mibs'
# Initialisation de l'infrastructure du compilateur
mibCompiler = MibCompiler(
    SmiStarParser(), PySnmpCodeGen(), PyFileWriter(dstDirectory)
)
# rechercher les MIB sources sur des sites Web et FTP
mibCompiler.addSources(*[HttpReader(*x) for x in httpSources])
mibCompiler.addSources(*[FtpReader(*x) for x in ftpSources])
# ne jamais recompiler les MIB avec des MACROs
mibCompiler.addSearchers(StubSearcher(*PySnmpCodeGen.baseMibs))
# exécuter la compilation non récursive des MIB
results = mibCompiler.compile(*inputMibs, **dict(noDeps=True))
print('Résultats : %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

Compiler les MIB SMIv1/v2

Rechercher des MIB ASN.1 spécifiques dans des répertoires locaux configurés, les compiler au format pysnmp si ce n'est pas déjà fait et enregistrer les modules Python sous forme de fichiers texte dans un répertoire local.

Essayer de prendre en charge les formats SMIv1 et SMIv2 de SMI, ainsi que les déviations populaires de la syntaxe officielle trouvées dans la nature.

Lors de la détermination si une compilation est nécessaire, vérifier tous les endroits connus où les MIB pysnmp pourraient éventuellement se trouver.

Vous pouvez forcer la recompilation des MIB en passant l'option rebuild au compilateur de MIB (voir ci-dessous).

L'invocation par défaut du compilateur de MIB ne génère pas les commentaires et textes [potentiellement volumineux] trouvés dans les MIB. Si vous en avez besoin dans les modules MIB pysnmp, passez simplement l'option genTexts au compilateur de MIB.

from pysmi.reader import FileReader
from pysmi.searcher import PyFileSearcher, PyPackageSearcher, StubSearcher
from pysmi.writer import PyFileWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import PySnmpCodeGen
from pysmi.compiler import MibCompiler
inputMibs = ['IF-MIB', 'IP-MIB']
srcDirectories = ['/usr/share/snmp/mibs']
dstDirectory = '.pysnmp-mibs'
# Initialisation de l'infrastructure du compilateur
mibCompiler = MibCompiler(SmiStarParser(),
                          PySnmpCodeGen(),
                          PyFileWriter(dstDirectory))
# rechercher les MIB sources ici
mibCompiler.addSources(*[FileReader(x) for x in srcDirectories])
# vérifier les MIB compilées dans nos propres productions
mibCompiler.addSearchers(PyFileSearcher(dstDirectory))
# ... et dans les paquets MIB pysnmp par défaut
mibCompiler.addSearchers(*[PyPackageSearcher(x) for x in PySnmpCodeGen.defaultMibPackages])
# ne jamais recompiler les MIB avec des MACROs
mibCompiler.addSearchers(StubSearcher(*PySnmpCodeGen.baseMibs))
# exécuter la compilation des MIB [potentiellement récursive]
results = mibCompiler.compile(*inputMibs)  #, rebuild=True, genTexts=True)
print('Résultats : %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

Compiler les MIB SMIv2

Invoquer une fonction de rappel utilisateur pour fournir le texte de la MIB, compiler la chaîne de texte donnée au format MIB pysnmp et passer les résultats à une autre fonction de rappel utilisateur pour le stockage.

Ici, nous nous attendons à ne traiter que des MIB valides SMIv2.

Nous utilisons l'option noDeps pour empêcher le compilateur de MIB d'essayer de compiler également les MIB IMPORTées.

import sys
from pysmi.reader import CallbackReader
from pysmi.searcher import StubSearcher
from pysmi.writer import CallbackWriter
from pysmi.parser import SmiV2Parser
from pysmi.codegen import PySnmpCodeGen
from pysmi.compiler import MibCompiler
inputMibs = ['IF-MIB', 'IP-MIB']
srcDir = '/usr/share/snmp/mibs/'  # nous lirions les MIB à partir d'ici
# Initialisation de l'infrastructure du compilateur
mibCompiler = MibCompiler(
    SmiV2Parser(),
    PySnmpCodeGen(),
    # notre propre fonction de rappel stocke les résultats à sa manière
    CallbackWriter(lambda m, d, c: sys.stdout.write(d))
)
# notre propre fonction de rappel sert de source de MIB ici
mibCompiler.addSources(
  CallbackReader(lambda m, c: open(srcDir+m+'.txt').read())
)
# ne jamais recompiler les MIB avec des MACROs
mibCompiler.addSearchers(StubSearcher(*PySnmpCodeGen.baseMibs))
# exécuter la compilation non récursive des MIB
results = mibCompiler.compile(*inputMibs, **dict(noDeps=True))
print('Résultats : %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

Emprunter les MIB pysnmp en cas d'échec

Rechercher des MIB ASN.1 spécifiques sur des sites Web/FTP configurés. Si aucune MIB requise n'est trouvée ou si sa compilation échoue pour une raison quelconque, tenter de télécharger une version précompilée de la MIB défaillante et de la stocker localement comme si nous l'avions compilée.

from pysmi.reader import HttpReader
from pysmi.searcher import PyFileSearcher
from pysmi.searcher import StubSearcher
from pysmi.borrower import PyFileBorrower
from pysmi.writer import PyFileWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import PySnmpCodeGen
from pysmi.compiler import MibCompiler
# from pysmi import debug
# debug.setLogger(debug.Debug('borrower', 'reader', 'searcher'))
inputMibs = ['BORROWED-MIB']
httpSources = [
    ('mibs.snmplabs.com', 80, '/asn1/@mib@')
]
httpBorrowers = [
    ('mibs.snmplabs.com', 80, '/pysnmp/notexts/@mib@')
]
dstDirectory = '.pysnmp-mibs'
# Initialisation de l'infrastructure du compilateur
mibCompiler = MibCompiler(
    SmiStarParser(), PySnmpCodeGen(), PyFileWriter(dstDirectory)
)
# rechercher les MIB sources sur des sites Web
mibCompiler.addSources(*[HttpReader(*x) for x in httpSources])
# ne jamais recompiler les MIB avec des MACROs
mibCompiler.addSearchers(StubSearcher(*PySnmpCodeGen.baseMibs))
# vérifier les MIB compilées/empruntées dans nos propres productions
mibCompiler.addSearchers(PyFileSearcher(dstDirectory))
# rechercher les MIB compilées sur des sites Web si la source n'est pas disponible ou est cassée
mibCompiler.addBorrowers(*[PyFileBorrower(HttpReader(*x)).setOptions(genTexts=False) for x in httpBorrowers])
# exécuter la compilation non récursive des MIB
results = mibCompiler.compile(*inputMibs)
print('Résultats : %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

Emprunter toujours les MIB pysnmp

Essayer d'emprunter des fichiers MIB pysnmp précompilés depuis un site web.

PySMI - SNMP SMI objects compiler

APERÇU

La bibliothèque pysmi est un compilateur MIB SNMP qui prend des informations de définition de modules MIB SNMP (texte brut ou format binaire) et les traduit dans une autre syntaxe d'information structurée. Actuellement, il prend en charge la génération de code Python pour la bibliothèque pysnmp et les fichiers JSON.

La bibliothèque pysmi est un outil en ligne de commande et une bibliothèque Python.

UTILISATION

Le script mibdump.py est l'outil principal de la bibliothèque pysmi. Il est utilisé pour rechercher, télécharger et compiler des modules MIB.

Utilisation de base

Pour compiler et enregistrer le module MIB BORROWED-MIB dans le répertoire .pysnmp-mibs, utilisez le script suivant :

from pysmi.reader import HttpReader
from pysmi.searcher import PyFileSearcher
from pysmi.searcher import PyFileBorrower
from pysmi.writer import PyFileWriter
from pysmi.parser import NullParser
from pysmi.codegen import NullCodeGen
from pysmi.compiler import MibCompiler
inputMibs = ['BORROWED-MIB']
httpBorrowers = [
    ('mibs.snmplabs.com', 80, '/pysnmp/notexts/@mib@')
]
dstDirectory = '.pysnmp-mibs'
# Initialize compiler infrastructure
mibCompiler = MibCompiler(
    NullParser(), NullCodeGen(), PyFileWriter(dstDirectory)
)
# check compiled/borrowed MIBs in our own productions
mibCompiler.addSearchers(PyFileSearcher(dstDirectory))
# search for precompiled MIBs at Web sites
mibCompiler.addBorrowers(
    *[PyFileBorrower(HttpReader(*x)) for x in httpBorrowers]
)
# run MIB compilation
results = mibCompiler.compile(*inputMibs)
print('Results: %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))
