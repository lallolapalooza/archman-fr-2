pw-cli(1) Manuel des commandes générales pw-cli(1)

NOM

pw-cli - L'interface en ligne de commande de PipeWire

SYNTAXE

pw-cli [commande]

DESCRIPTION

Interagissez avec une instance PipeWire.

Lorsqu'une commande est donnée, pw-cli exécutera la commande et se terminera.

Lorsqu'aucune commande n'est donnée, pw-cli démarre une session interactive avec l'instance PipeWire par défaut pipewire-0.

Des connexions à d'autres instances, distantes, peuvent être établies. Le nom de l'instance actuelle est affiché à l'invite.

Notez que pw-cli crée également une instance PipeWire locale. Certaines commandes opèrent sur l'instance actuelle (distante) et d'autres sur l'instance locale, comme le chargement de modules.

Utilisez la commande 'help' pour lister les commandes disponibles.

COMMANDES GÉNÉRALES

help | h

Affiche une aide rapide sur les commandes disponibles. Elle liste également les alias de nombreuses commandes.

quit | q

Quitte pw-cli

GESTION DES MODULES

Les modules sont chargés et déchargés dans l'instance locale, donc le binaire pw-cli lui-même, et peuvent ajouter des fonctionnalités ou des objets à l'instance locale. Il n'est pas possible dans PipeWire de charger des modules dans une autre instance.

load-module nom [arguments...]

Charge un module spécifié par son nom et ses arguments dans l'instance locale. Pour la plupart des modules, il est acceptable de les charger plusieurs fois.

Cette commande retourne une variable de module qui peut être utilisée pour décharger le module.

Le module local n'est pas visible dans l'instance distante. Il n'est pas possible dans PipeWire de charger des modules dans une instance distante.

unload-module var-module

Décharge un module, spécifié soit par sa variable.

INTROSPECTION DES OBJETS

list-objects

Liste les objets de l'instance actuelle.

Les objets sont listés avec leur id, type et version.

info id | all

Obtient des informations sur un objet spécifique ou tous les objets.

Demander des informations sur un objet vous notifiera également des changements.

TRAVAIL AVEC LES DISTANTS

connect [nom-distant]

Se connecte à une instance distante et en fait la nouvelle instance actuelle.

Si aucun nom distant n'est spécifié, une connexion est établie avec l'instance distante par défaut, généralement pipewire-0.

Le nom distant spécial appelé internal peut être utilisé pour se connecter à l'instance PipeWire locale de pw-cli.

Cette commande retourne une variable distante qui peut être utilisée pour se déconnecter ou changer d'instance distante.

disconnect [var-distante]

Se déconnecte d'une instance distante.

Si aucun nom distant n'est spécifié, l'instance actuelle est déconnectée.

list-remotes

Liste toutes les instances distantes.

switch-remote [var-distante]

Fait de l'instance distante spécifiée l'instance actuelle.

Si aucun nom distant n'est spécifié, la première instance est faite actuelle.

GESTION DES NOEUDS

create-node nom-fabrique [propriétés...]

Crée un nœud à partir d'une fabrique dans l'instance actuelle.

Les propriétés sont des paires clé=valeur séparées par des espaces.

Cette commande retourne une variable de nœud.

export-node id-nœud [var-distante]

Exporte un nœud de l'instance locale vers l'instance spécifiée. Lorsqu'aucune instance n'est spécifiée, le nœud sera exporté vers l'instance actuelle.

GESTION DES APPAREILS

create-device nom-fabrique [propriétés...]

Crée un appareil à partir d'une fabrique dans l'instance actuelle.

Les propriétés sont des paires clé=valeur séparées par des espaces.

Cette commande retourne une variable d'appareil.

GESTION DES CONNEXIONS

create-link id-nœud id-port id-nœud id-port [propriétés...]

Crée une connexion entre 2 nœuds et ports.

Les id de port et les id de nœud peuvent être définis à - pour sélectionner automatiquement un nœud ou un port.

Les id de port peuvent être * pour connecter automatiquement les ports correspondants dans les nœuds.

Les propriétés sont des paires clé=valeur séparées par des espaces.

Cette commande retourne une ou plusieurs variables de connexion.

GESTION DES GLOBALS

destroy id-objet

Détruit un objet global.

GESTION DES PARAMÈTRES

enum-params id-objet id-paramètre

Énumère les paramètres d'un objet.

id-paramètre peut également être donné sous forme de nom court du paramètre.

set-param id-objet id-paramètre json-paramètre

Définit le paramètre d'un objet.

id-paramètre peut également être donné sous forme de nom court du paramètre.

GESTION DES PERMISSIONS

permissions id-client id-objet permission

Définit les permissions pour un client.

id-objet peut être -1 pour définir les permissions par défaut.

get-permissions id-client

Obtient les permissions d'un client.

GESTION DES COMMANDES

send-command id-objet

Envoie une commande à un objet.
