pwd.h(0P) Manuel du programmeur POSIX pwd.h(0P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

pwd.h — structure de mot de passe

SYNTAXE

#include <pwd.h>

DESCRIPTION

L'en-tête <pwd.h> définira la structure struct passwd, qui contiendra au moins les membres suivants :

char    *pw_name   Nom de connexion de l'utilisateur.
uid_t    pw_uid    Identifiant numérique de l'utilisateur.
gid_t    pw_gid    Identifiant numérique du groupe.
char    *pw_dir    Répertoire de travail initial.
char    *pw_shell  Programme à utiliser comme shell.

L'en-tête <pwd.h> définira les types gid_t, uid_t et size_t tels que décrits dans <sys/types.h>.

Les éléments suivants seront déclarés comme fonctions et pourront également être définis comme macros. Les prototypes de fonctions seront fournis.

void           endpwent(void);
struct passwd *getpwent(void);
struct passwd *getpwnam(const char *);
int            getpwnam_r(const char *, struct passwd *, char *,
                   size_t, struct passwd **);
struct passwd *getpwuid(uid_t);
int            getpwuid_r(uid_t, struct passwd *, char *,
                   size_t, struct passwd **);
void           setpwent(void);
