pw-jack(1) Manuel des commandes générales pw-jack(1)

NOM

pw-jack - Utiliser PipeWire à la place de JACK

SYNTAXE

pw-jack [options] COMMANDE [ARGUMENTS...]

DESCRIPTION

pw-jack modifie la variable d'environnement LD_LIBRARY_PATH de sorte que les applications chargent la réimplémentation des bibliothèques client JACK par PipeWire au lieu des propres bibliothèques de JACK. Cela a pour effet de rediriger les clients JACK vers PipeWire.

Si la réimplémentation des bibliothèques client JACK par PipeWire a été installée comme remplacement à l'échelle du système pour les propres bibliothèques de JACK, alors l'ensemble du système se comporte déjà de cette manière, auquel cas pw-jack n'a aucun effet pratique.

OPTIONS

-h

Afficher l'aide.

-r NOM

Le nom de l'instance distante à laquelle se connecter. Si non spécifié, une connexion est établie avec l'instance PipeWire par défaut.

-v

Mode verbeux.

EXEMPLES

pw-jack sndfile-jackplay /usr/share/sounds/freedesktop/stereo/bell.oga

AUTEURS

Les développeurs de PipeWire https://gitlab.freedesktop.org/pipewire/pipewire/issues; PipeWire est disponible sur https://pipewire.org
