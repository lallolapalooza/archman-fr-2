NOM

pw-mididump - Le vidage MIDI de PipeWire

SYNOPSIS

pw-mididump [options] [FICHIER]

DESCRIPTION

Vider les messages MIDI vers la sortie standard.

Lorsqu'un fichier MIDI est donné, les événements contenus dans le fichier sont affichés.

Lorsqu'aucun fichier n'est donné, pw-mididump crée un flux d'entrée MIDI PipeWire et affichera tous les événements MIDI reçus sur le port vers la sortie standard.

OPTIONS

-r | --remote=NOM

Le nom de l'instance distante à surveiller. Si non spécifié, une connexion est établie à l'instance PipeWire par défaut.

-h | --help

Afficher l'aide.

--version

Afficher les informations sur la version.

AUTEURS

Les développeurs de PipeWire https://gitlab.freedesktop.org/pipewire/pipewire/issues; PipeWire est disponible à partir de https://pipewire.org
