NOM

pw-loopback - Client de bouclage (loopback) PipeWire

SYNTAXE

pw-loopback [options]

DESCRIPTION

Le programme pw-loopback est un client PipeWire qui utilise le module de bouclage PipeWire pour créer des nœuds de bouclage, avec une configuration donnée via les options de la ligne de commande.

OPTIONS

-h | --help

Afficher l'aide.

-r | --remote=NOM

Le nom de l'instance distante à laquelle se connecter. Si non spécifié, une connexion est établie à l'instance PipeWire par défaut.

-n | --name=NOM

Nom du nœud de bouclage

-g | --group=NOM

Nom du groupe de nœuds de bouclage

-c | --channels=NOMBRE

Nombre de canaux à fournir

-m | --channel-map=CARTE

Carte des canaux (par défaut [ FL, FR ])

-l | --latency=LATENCE

Latence souhaitée en ms

-d | --delay=RETARD

Retard ajouté en secondes (nombre flottant autorisé)

-C | --capture=CIBLE

Périphérique cible à capturer

-P | --playback=CIBLE

Périphérique cible à lire

-i | --capture-props=PROPRIETES

Propriétés souhaitées du nœud de capture (en JSON)

-o | --playback-props=PROPRIETES

Propriétés souhaitées du nœud de capture (en JSON)

AUTEURS

Les développeurs de PipeWire https://gitlab.freedesktop.org/pipewire/pipewire/issues ; PipeWire est disponible sur https://pipewire.org

VOIR AUSSI

pipewire(1), pw-cat(1), pactl(1)

D'autres moyens de créer des nœuds de bouclage consistent à ajouter le module de bouclage dans la configuration d'un démon PipeWire, ou à charger le module de bouclage en utilisant les commandes Pulseaudio (pactl load-module module-loopback ...).
