pw-profiler(1) Manuel des commandes générales pw-profiler(1)

NOM

pw-profiler - Le profileur PipeWire

SYNTAXE

pw-profiler [options]

DESCRIPTION

Lance le profilage d'une instance PipeWire.

Si le serveur a le module de profilage chargé, ce programme s'y connectera et enregistrera les données du profileur. Les données du profileur contiennent les temps et durées de début et fin de traitement des nœuds et des périphériques.

Lorsque ce programme est arrêté, un ensemble de fichiers gnuplot et un script pour générer des fichiers SVG à partir des fichiers .plot sont générés, ainsi qu'un fichier .html pour visualiser les résultats du profilage dans un navigateur.

Cette fonction utilise les mêmes données que celles utilisées par pw-top.

OPTIONS

-r | --remote=NOM

Le nom de l'instance distante à surveiller. Si non spécifié, une connexion est établie à l'instance PipeWire par défaut.

-h | --help

Afficher l'aide.

--version

Afficher les informations de version.

-o | --output=FICHIER

Nom du fichier de sortie du profileur (par défaut "profiler.log").

AUTEURS

Les développeurs de PipeWire https://gitlab.freedesktop.org/pipewire/pipewire/issues; PipeWire est disponible sur https://pipewire.org

VOIR AUSSI
