PWD(1) Commandes utilisateur PWD(1)

NOM

pwd - afficher le nom du répertoire courant/de travail

SYNTAXE

pwd [OPTION]...

DESCRIPTION

Affiche le nom de fichier complet du répertoire de travail courant.

-L, --logical
utilise PWD de l'environnement, même s'il contient des liens symboliques
-P, --physical
résout tous les liens symboliques
--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte

Si aucune option n'est spécifiée, -P est présumé.

Votre shell peut avoir sa propre version de pwd, qui supplante généralement la version décrite ici. Veuillez vous référer à la documentation de votre shell pour connaître les détails des options qu'il supporte.
