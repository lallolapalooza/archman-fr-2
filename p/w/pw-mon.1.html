pw-mon(1) Manuel des commandes générales pw-mon(1)

NOM

pw-mon - Le moniteur PipeWire

SYNTAXE

pw-mon [options]

DESCRIPTION

Surveille les objets de l'instance PipeWire.

OPTIONS

-r | --remote=NOM

Le nom de l'instance distante à surveiller. Si non spécifié, une connexion est établie à l'instance PipeWire par défaut.

-h | --help

Affiche l'aide.

--version

Affiche les informations sur la version.

-N | --color=QUAND

Indique si il faut utiliser la couleur, l'une des valeurs 'never', 'always', ou 'auto'. La valeur par défaut est 'auto'. -N est équivalent à --color=never.

AUTEURS

Les développeurs de PipeWire https://gitlab.freedesktop.org/pipewire/pipewire/issues ; PipeWire est disponible sur https://pipewire.org
