NOM

pwd - Retourne le chemin absolu du répertoire de travail courant

SYNTAXE

pwd

DESCRIPTION

Retourne le nom du chemin absolu du répertoire de travail courant.

EXEMPLE

Il est parfois utile de changer pour un répertoire connu lors de l'exécution d'une commande externe à l'aide de exec, mais il est important de maintenir l'application généralement en cours d'exécution dans le répertoire où elle a été démarrée (sauf si l'utilisateur spécifie le contraire) car cela minimise la confusion pour l'utilisateur. La manière de faire est de sauvegarder le répertoire courant pendant l'exécution de la commande externe :

set tarFile [file normalize somefile.tar]
set savedDir [pwd]
cd /tmp
exec tar -xf $tarFile
cd $savedDir

VOIR AUSSI

file(n), cd(n), glob(n), filename(n)
