PWCONV(8) Commandes de gestion système PWCONV(8)

NOM

pwconv, pwunconv, grpconv, grpunconv - convertir entre les fichiers de compte système protégés (shadow) et les fichiers de compte en clair

SYNTAXE

pwconv [options]

pwunconv [options]

grpconv [options]

grpunconv [options]

DESCRIPTION

La commande pwconv crée le fichier shadow à partir du fichier passwd et d'un fichier shadow éventuellement existant.

La commande pwunconv crée un fichier passwd en clair à partir des fichiers passwd protégés et shadow, puis supprime le fichier shadow.

La commande grpconv crée le fichier gshadow à partir du fichier group et d'un fichier gshadow éventuellement existant.

La commande grpunconv crée un fichier group en clair à partir des fichiers group protégés et gshadow, puis supprime le fichier gshadow.

Ces quatre programmes opèrent tous sur les fichiers normaux et protégés (shadow) des mots de passe et des groupes : /etc/passwd, /etc/group, /etc/shadow, et /etc/gshadow.

Chaque programme acquiert les verrous nécessaires avant la conversion. pwconv et grpconv sont similaires. Premièrement, les entrées du fichier protégé qui n'existent pas dans le fichier en clair sont supprimées. Ensuite, les entrées du fichier protégé qui n'ont pas de 'x' comme mot de passe dans le fichier en clair sont mises à jour. Toutes les entrées protégées manquantes sont ajoutées. Enfin, les mots de passe dans le fichier en clair sont remplacés par 'x'. Ces programmes peuvent être utilisés pour une conversion initiale ainsi que pour mettre à jour le fichier protégé si le fichier en clair a été modifié manuellement.

pwconv utilisera les valeurs de PASS_MIN_DAYS, PASS_MAX_DAYS, et PASS_WARN_AGE de /etc/login.defs lors de l'ajout de nouvelles entrées à /etc/shadow.

De même, pwunconv et grpunconv sont similaires. Les mots de passe dans le fichier en clair sont mis à jour à partir du fichier protégé. Les entrées qui existent dans le fichier en clair mais pas dans le fichier protégé sont laissées telles quelles. Enfin, le fichier protégé est supprimé. Certaines informations d'expiration des mots de passe sont perdues par pwunconv. Il convertira ce qu'il peut.

OPTIONS

Les options qui s'appliquent aux commandes pwconv, pwunconv, grpconv, et grpunconv sont :

-h, --help

Affiche un message d'aide et quitte.

-R, --root CHROOT_DIR

Applique les modifications dans le répertoire CHROOT_DIR et utilise les fichiers de configuration du répertoire CHROOT_DIR. Seuls les chemins absolus sont supportés.

BOGUES

Les erreurs dans les fichiers de mots de passe ou de groupes (telles que des entrées invalides ou dupliquées) peuvent amener ces programmes à boucler indéfiniment ou à échouer de manière étrange. Veuillez exécuter pwck et grpck pour corriger toute erreur de ce type avant de convertir vers ou depuis des fichiers protégés.

CONFIGURATION

La variable de configuration suivante dans /etc/login.defs modifie le comportement de grpconv et grpunconv :

MAX_MEMBERS_PER_GROUP (nombre)

Nombre maximum de membres par entrée de groupe. Lorsque le maximum est atteint, une nouvelle ligne de groupe est démarrée dans /etc/group (avec le même nom, le même mot de passe et le même GID).

La valeur par défaut est 0, ce qui signifie qu'il n'y a pas de limite au nombre de membres dans un groupe.

Cette fonctionnalité (groupe divisé) permet de limiter la longueur des lignes dans le fichier group. Ceci est utile pour s'assurer que les lignes pour les groupes NIS ne dépassent pas 1024 caractères.

Si vous devez imposer une telle limite, vous pouvez utiliser 25.

Remarque : les groupes divisés peuvent ne pas être pris en charge par tous les outils (même dans la suite d'outils Shadow). Vous ne devriez pas utiliser cette variable à moins d'en avoir vraiment besoin.

Les variables de configuration suivantes dans /etc/login.defs modifient le comportement de pwconv :

PASS_MAX_DAYS (nombre)

Le nombre maximum de jours pendant lesquels un mot de passe peut être utilisé. Si le mot de passe est plus ancien que cela, un changement de mot de passe sera forcé. Si non spécifié, -1 sera supposé (ce qui désactive la restriction).

PASS_MIN_DAYS (nombre)

Le nombre minimum de jours autorisés entre deux changements de mot de passe. Toute tentative de changement de mot de passe effectuée avant cette date sera rejetée. Si non spécifié, 0 sera supposé (ce qui désactive la restriction).

PASS_WARN_AGE (nombre)

Le nombre de jours d'avertissement avant l'expiration d'un mot de passe. Une valeur de zéro signifie qu'un avertissement n'est donné que le jour de l'expiration, une valeur de -1 signifie qu'aucun avertissement n'est donné. Si non spécifié, aucun avertissement ne sera fourni.

FICHIERS

/etc/login.defs

Configuration de la suite de mots de passe shadow.
