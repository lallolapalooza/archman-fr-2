NOM

pwhistory.conf - fichier de configuration de pam_pwhistory

DESCRIPTION

pwhistory.conf offre un moyen de configurer les paramètres par défaut pour l'enregistrement des derniers mots de passe pour chaque utilisateur. Ce fichier est lu par le module pam_pwhistory et constitue la méthode préférée par rapport à la configuration directe de pam_pwhistory.

Le fichier a un format très simple nom = valeur avec des commentaires possibles commençant par le caractère #. Les espaces en début de ligne, en fin de ligne et autour du signe = sont ignorés.

OPTIONS

debug

Active le débogage via syslog(3).

enforce_for_root

Si cette option est activée, la vérification est appliquée pour root également.

remember=N

Les N derniers mots de passe de chaque utilisateur sont enregistrés. La valeur par défaut est 10. Une valeur de 0 amène le module à laisser inchangé le contenu existant du fichier opasswd.

retry=N

Demande à l'utilisateur au plus N fois avant de retourner une erreur. La valeur par défaut est 1.

file=/chemin/nom_fichier

Stocke l'historique des mots de passe dans le fichier /chemin/nom_fichier plutôt qu'à l'emplacement par défaut. L'emplacement par défaut est /etc/security/opasswd.

EXEMPLES

Exemple de fichier /etc/security/pwhistory.conf :

debug
remember=5
file=/tmp/opasswd

FICHIERS

/etc/security/pwhistory.conf

le fichier de configuration pour les options personnalisées
