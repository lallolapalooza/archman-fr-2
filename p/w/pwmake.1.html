NOM

pwmake - outil simple pour générer des mots de passe aléatoires relativement prononçables

SYNTAXE

pwmake <bits-entropie>

DESCRIPTION

pwmake est un outil simple et configurable pour générer des mots de passe aléatoires et relativement prononçables. L'outil vous permet de spécifier le nombre de bits d'entropie utilisés pour générer le mot de passe.

L'entropie est extraite de /dev/urandom.

Le nombre minimum de bits est 56, utilisable pour les mots de passe sur les systèmes/services où les attaques par force brute ont un taux d'essais très limité. Les 64 bits devraient être suffisants pour les applications où l'attaquant n'a pas un accès direct au fichier de hachage du mot de passe. Pour les situations où l'attaquant pourrait obtenir un accès direct au hachage du mot de passe ou si le mot de passe est utilisé comme clé de chiffrement, 80 à 128 bits devraient être utilisés en fonction de votre niveau de paranoïa.

Toute valeur de bits-entropie en dehors de la plage de 56 à 256 bits sera ajustée pour s'inscrire dans la plage autorisée.

OPTIONS

Le premier et unique argument est le nombre de bits d'entropie utilisés pour générer le mot de passe.

FICHIERS

/etc/security/pwquality.conf - Le fichier de configuration pour la bibliothèque libpwquality.

CODES DE RETOUR

pwmake retourne 0 en cas de succès, une valeur non nulle en cas d'erreur.

VOIR AUSSI

pwscore(1), pam_pwquality(8)
