NOM

pwdhash - Générateur de hachages de mot de passe

SYNTAXE

pwdhash [-D config‐dir] [-H] [-s schéma | -c comparepwd] motdepasse

DESCRIPTION

Génère des hachages de mots de passe qui peuvent également être utilisés dans les champs de mot de passe LDIF. Ceci utilise le générateur de mots de passe du serveur d'annuaire.

OPTIONS

Un résumé des options est inclus ci-dessous :

-H
Afficher un résumé des options.
-s schéma
Schéma de mot de passe à utiliser (par ex. MD5, SHA1, SHA256, SHA512, SSHA, SSHA256, SSHA512)
-c comparepassword
Mot de passe à comparer
-D configdir
Prend le schéma de mot de passe directement de la configuration ns-slapd
