NOM

pw-metadata - Les métadonnées PipeWire

SYNTAXE

pw-metadata [options] [id [clé [valeur [type ] ] ] ]

DESCRIPTION

Surveille, définit et supprime les métadonnées sur les objets PipeWire.

Les métadonnées sont des triplets clé/type/valeur attachés à des objets identifiés par id. Les métadonnées sont partagées entre toutes les applications se liant au même objet de métadonnées. Lorsqu'un objet est détruit, toutes ses métadonnées sont automatiquement supprimées.

Lorsqu'aucune valeur n'est fournie, pw-metadata interrogera et affichera les métadonnées correspondant aux arguments optionnels id et clé. Sans aucun argument, toutes les métadonnées sont affichées.

Lorsque valeur est fournie, pw-metadata définira la métadonnée pour id et clé à valeur et un type optionnel.

OPTIONS

-r | --remote=NOM

Le nom de l'instance distante à utiliser. Si non spécifié, une connexion est établie avec l'instance PipeWire par défaut.

-h | --help

Afficher l'aide.

--version

Afficher les informations de version.

-l | --list

Lister les objets de métadonnées disponibles

-m | --monitor

Continue de s'exécuter et enregistre les modifications apportées aux métadonnées.

-d | --delete

Supprimer toutes les métadonnées pour id ou pour la clé spécifiée de l'objet id. Sans aucune option, toutes les métadonnées sont supprimées.

-n | --name

Nom des métadonnées (Défaut : "default").

EXEMPLES

pw-metadata

Afficher les métadonnées du nom par défaut.

pw-metadata -n settings 0

Afficher les paramètres.

pw-metadata -n settings 0 clock.quantum 1024

Changer clock.quantum à 1024.
