NOM

pw-v4l2 - Utiliser PipeWire à la place de V4L2

SYNTAXE

pw-v4l2 [options] COMMANDE [ARGUMENTS...]

DESCRIPTION

pw-v4l2 exécute une commande à l'aide d'une couche de compatibilité qui rend les périphériques vidéo PipeWire visibles pour les applications utilisant V4L2.

Ceci est implémenté en préchargeant une bibliothèque partagée via LD_PRELOAD, qui traduit les appels de bibliothèque tentant d'accéder aux périphériques V4L2.

OPTIONS

-h

Afficher l'aide.

-r NOM

Le nom de l'instance distante à laquelle se connecter. Si non spécifié, une connexion est établie à l'instance PipeWire par défaut.

-v

Fonctionnement verbeux.

EXEMPLES

pw-v4l2 v4l2-ctl --list-devices
