pw-top(1) Manuel des commandes générales pw-top(1)

NOM

pw-top - Le visualiseur de processus PipeWire

SYNTAXE

pw-top [options]

DESCRIPTION

Le programme pw-top fournit une vue dynamique en temps réel des statistiques des nœuds et périphériques PipeWire.

Une vue hiérarchique des nœuds Pilotes et des nœuds Suiveurs est affichée. Les nœuds Pilotes utilisent activement une minuterie pour planifier le flux de données dans les Suiveurs. Les Suiveurs d'un nœud Pilote sont présentés en dessous de leur Pilote avec un signe + dans une représentation arborescente.

Les colonnes présentées sont les suivantes :

S

État du nœud.
  • E = ERREUR
  • C = CRÉATION
  • S = SUSPENDU
  • I = INACTIF
  • R = EN COURS
  • t = EN COURS + transport en cours de démarrage
  • T = EN COURS + transport en cours

ID

L'identifiant du nœud/périphérique pipewire, tel que trouvé dans pw-dump et pw-cli

QUANT

Le quantum actuel (pour les pilotes) et le quantum suggéré pour les nœuds suiveurs.

Le quantum seul doit être divisé par la colonne RATE pour calculer la durée d'une période de planification en fractions de seconde.

Pour un QUANT de 1024 et une RATE de 48000, la durée d'une période dans le graphe est de 1024/48000 soit 21,3 millisecondes.

Les nœuds suiveurs peuvent avoir un champ QUANT de 0, ce qui signifie que le nœud n'a pas de suggestion pour le quantum et utilise donc celui sélectionné par le pilote.

Le pilote utilisera le quantum le plus bas de tous les suiveurs. Si aucun des suiveurs ne sélectionne de quantum, le quantum par défaut du fichier de configuration pipewire sera utilisé.

Le QUANT sur les pilotes se traduit généralement directement par le nombre d'échantillons audio traités par cycle de traitement du graphe.

Voir également https://gitlab.freedesktop.org/pipewire/pipewire/-/wikis/FAQ#pipewire-buffering-explained

RATE

Le débit actuel (pour les pilotes) et le débit suggéré pour les nœuds suiveurs.

C'est le débit auquel le graphe traite les données et il doit être combiné avec la valeur QUANT pour dériver la durée d'un cycle de traitement dans le graphe.

Certains nœuds peuvent avoir une RATE de 0, ce qui signifie qu'ils n'ont aucune suggestion de débit pour le graphe. Les nœuds qui suggèrent un débit peuvent faire basculer le graphe (si le graphe est sinon inactif et que le nouveau débit est autorisé comme débit de graphe possible (voir le fichier de configuration pipewire)).

La RATE sur les nœuds pilotes (audio) se traduit généralement directement par le taux d'échantillonnage utilisé par le périphérique. Bien que certains périphériques ne puissent pas fonctionner au taux d'échantillonnage donné, des rééchantillonnages seront nécessaires. Le taux d'échantillonnage négocié avec le périphérique et le flux se trouve dans la colonne FORMAT.

WAIT

Le temps d'attente d'un nœud est le temps écoulé entre le moment où le nœud est prêt à commencer le traitement et le moment où il a réellement commencé le traitement.

Pour les nœuds Pilotes, c'est le temps entre le moment où le nœud se réveille pour commencer à traiter le graphe et le moment où le pilote (et donc aussi le graphe) achève un cycle. Le temps d'attente pour le pilote est donc le temps écoulé pour le traitement du graphe.

Pour les nœuds suiveurs, c'est le temps passé entre le réveil (lorsque toutes les dépendances du nœud sont satisfaites) et le début du traitement. Le temps d'attente pour les nœuds suiveurs est donc principalement causé par les changements de contexte.

Une valeur de --- signifie que le nœud n'a pas été signalé. Une valeur de +++ signifie que le nœud a été signalé mais n'était pas éveillé.

BUSY

Le temps de traitement est le temps écoulé entre le moment où le nœud commence le traitement et le moment où il est terminé et réveille les nœuds suivants dans le graphe.

Une valeur de --- signifie que le nœud n'a pas été démarré. Une valeur de +++ signifie que le nœud a été démarré mais n'a pas été terminé.

W/Q

Ratio de WAIT / QUANT.

Le temps W/Q du nœud pilote est une bonne mesure de la charge du graphe. Les moyennes mobiles des ratios W/Q du pilote sont utilisées comme charge DSP dans d'autres outils (JACK).

Les valeurs de --- et +++ sont copiées de la colonne WAIT.

B/Q

Ratio de BUSY / QUANT

C'est une bonne mesure de la charge d'un pilote ou d'un nœud suiveur particulier.

Les valeurs de --- et +++ sont copiées de la colonne BUSY.

ERR

Total des Xruns et des erreurs

Les Xruns pour les pilotes se produisent lorsque le graphe n'a pas pu compléter un cycle. Cela peut être dû à un nœud dans le graphe qui a également un Xrun. Cela peut également être causé lorsque des retards de planification entraînent la perte d'une échéance, provoquant un Xrun matériel.

Les Xruns pour les suiveurs sont incrémentés lorsque le nœud a commencé le traitement mais n'a pas pu le terminer avant la fin de l'échéance du cycle du graphe.

FORMAT

Le format utilisé par le nœud pilote ou le flux. C'est le format matériel négocié avec le périphérique ou le flux.

Si le flux ou le pilote a un taux différent de celui du graphe, un rééchantillonnage sera effectué.

Pour les formats audio bruts, la disposition est <format d'échantillon> <canaux> <taux d'échantillonnage>.

Pour les formats audio de transmission IEC958, la disposition est IEC958 <codec> <taux d'échantillonnage>.

Pour les formats DSD, la disposition est <taux-dsd> <canaux>.

Pour les formats vidéo, la disposition est <format de pixel> <largeur>x<hauteur>.

NAME

Nom attribué au périphérique/nœud, tel que trouvé dans le nœud pw-dump node.name

Les noms sont préfixés par + lorsqu'ils sont liés à un pilote (entrée ci-dessus sans +)

OPTIONS

-h | --help

Afficher l'aide.

-b | --batch-mode

Exécuter en mode batch non interactif, similaire au mode batch de top.

-n | --iterations=NOMBRE

Quitter après NOMBRE itérations en mode batch. Utilisé uniquement en mode batch.

-r | --remote=NOM

Le nom de l'instance remote à surveiller. Si non spécifié, une connexion est établie à l'instance PipeWire par défaut.

-V | --version

Afficher les informations de version.

AUTEURS

Les développeurs de PipeWire https://gitlab.freedesktop.org/pipewire/pipewire/issues ; PipeWire est disponible à l'adresse https://pipewire.org
