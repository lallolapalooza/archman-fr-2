pw-config(1) Manuel des commandes générales pw-config(1)

NOM

pw-config - Analyser le débogage de la configuration PipeWire

SYNTAXE

pw-config [options] chemins

pw-config [options] liste [SECTION]

pw-config [options] fusionner SECTION

DESCRIPTION

Lister les chemins de configuration et les sections de configuration et afficher la sortie analysée.

Cet outil peut être utilisé pour obtenir un aperçu du fichier de configuration qui sera analysé par le serveur et les clients PipeWire.

OPTIONS COMMUNES

-h | --help

Afficher l'aide.

--version

Afficher les informations de version.

-n | --name=NOM

Nom de la configuration (par défaut 'pipewire.conf')

-p | --prefix=PREFIXE

Préfixe de configuration (par défaut '')

-L | --no-newline

Omettre les nouvelles lignes après les valeurs

-r | --recurse

Reformater les sections de configuration récursivement

-N | --no-colors

Désactiver la sortie couleur

-C | -color[=QUAND]

pour activer la prise en charge des couleurs. QUAND est jamais, toujours, ou auto

LISTAGE DES CHEMINS

Spécifiez la commande paths. Elle affichera tous les fichiers de configuration qui seront analysés et dans quel ordre.

LISTAGE DES SECTIONS DE CONFIGURATION

Spécifiez la commande list avec une SECTION facultative pour lister les fragments de configuration utilisés pour SECTION. Sans SECTION, toutes les sections seront listées.

Utilisez les options -r pour reformater les sections.

FUSIONNER UNE SECTION DE CONFIGURATION

Avec l'option merge et une SECTION, pw-config fusionnera tous les fichiers de configuration en une section de configuration fusionnée et affichera les résultats. Ce sera la section utilisée par le client ou le serveur.

Utilisez les options -r pour reformater les sections.

EXEMPLES

pw-config

Lister tous les fichiers de configuration qui seront utilisés

pw-config -n pipewire-pulse.conf

Lister tous les fichiers de configuration qui seront utilisés par le serveur pulseaudio PipeWire.

pw-config -n pipewire-pulse.conf list

Lister toutes les sections de configuration utilisées par le serveur pulseaudio PipeWire

pw-config -n jack.conf list context.properties

Lister les fragments context.properties utilisés par les clients JACK

pw-config -n jack.conf merge context.properties

Lister le context.properties fusionné utilisé par les clients JACK

pw-config -n pipewire.conf -r merge context.modules

Lister le context.modules fusionné utilisé par le serveur PipeWire et reformater
