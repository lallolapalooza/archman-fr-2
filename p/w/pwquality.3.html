PWQUALITY(3) Manuel de l'API Libpwquality PWQUALITY(3)

NOM

pwquality - Documentation de l'API libpwquality

SYNTAXE

#include <pwquality.h>
pwquality_settings_t *pwquality_default_settings(void);
void pwquality_free_settings(pwquality_settings_t *pwq);
int pwquality_read_config(pwquality_settings_t *pwq, const char *cfgfile,
       void **auxerror);
int pwquality_set_option(pwquality_settings_t *pwq, const char *option);
int pwquality_set_int_value(pwquality_settings_t *pwq, int setting, int value);
int pwquality_set_str_value(pwquality_settings_t *pwq, int setting,
       const char *value);
int pwquality_get_int_value(pwquality_settings_t *pwq, int setting, int *value);
int pwquality_get_str_value(pwquality_settings_t *pwq, int setting, const char **value);
int pwquality_generate(pwquality_settings_t *pwq, int entropy_bits,
       char **password);
int pwquality_check(pwquality_settings_t *pwq, const char *password,
       const char *oldpassword, const char *user, void **auxerror);
const char *pwquality_strerror(char *buf, size_t len, int errcode, void *auxerror);

DESCRIPTION

La fonction pwquality_default_settings() alloue et renvoie les paramètres par défaut de pwquality à utiliser dans d'autres appels de bibliothèque. La structure opaque allouée doit être libérée avec l'appel pwquality_free_settings().

La fonction pwquality_read_config() analyse le fichier de configuration (si cfgfile est NULL, alors celui par défaut). Si auxerror n'est pas NULL, elle peut également renvoyer des informations d'erreur auxiliaires qui doivent être passées à la fonction pwquality_strerror().

Nouveau dans 1.3.0 :
La bibliothèque tente d'abord d'analyser tous les fichiers de configuration *.conf du répertoire <cfgfile>.d s'il existe. L'ordre d'analyse détermine quelles valeurs seront en vigueur - la dernière l'emporte.

La fonction pwquality_set_option() est utile pour définir les options telles que configurées sur une ligne de commande du module pam sous la forme opt=val.

Les fonctions d'obtention et de définition des valeurs de paramètres entiers et de chaînes individuelles sont : pwquality_set_int_value(), pwquality_set_str_value(), pwquality_get_int_value() et pwquality_get_str_value(). Dans le cas de l'obtention de chaînes, l'appelant doit copier la chaîne avant d'autres appels susceptibles de manipuler l'objet de configuration pwq.

La fonction pwquality_generate() génère un mot de passe aléatoire de entropy_bits bits d'entropie et le vérifie selon les paramètres. Le *password est alloué sur le tas par la bibliothèque. La valeur entropy_bits est ajustée pour tenir dans la plage PWQ_MIN_ENTROPY_BITS et PWQ_MAX_ENTROPY_BITS avant de générer un mot de passe.

La fonction pwquality_check() vérifie le password selon les paramètres. Elle renvoie soit un score (valeur comprise entre 0 et 100), soit un code d'erreur négatif, et éventuellement des informations d'erreur auxiliaires qui doivent être passées à la fonction pwquality_strerror(). L'argument oldpassword est facultatif et peut être NULL. L'argument user est utilisé pour vérifier le password par rapport au nom d'utilisateur et potentiellement à d'autres informations de passwd(5) et peut être NULL. L'argument auxerror peut être NULL - dans ce cas, les informations d'erreur auxiliaires ne sont pas renvoyées. Cependant, s'il n'est pas NULL, ne pas passer le *auxerror renvoyé à pwquality_strerror() peut entraîner des fuites de mémoire.

Le score d'un mot de passe dépend de la valeur du paramètre PWQ_SETTING_MIN_LENGTH. S'il est défini plus haut, le score des mêmes mots de passe sera plus bas.

La fonction pwquality_strerror() traduit le errcode et les données auxiliaires auxerror en un message textuel localisé. Si buf est NULL, la fonction utilise un tampon statique interne, ce qui la rend non réentrante dans ce cas. Le pointeur renvoyé n'est pas garanti de pointer vers buf. La fonction désalloue les données éventuelles auxerror qui lui sont passées, elle ne doit donc pas être appelée deux fois avec les mêmes données auxerror.

VALEURS DE RETOUR

En général, les fonctions qui renvoient un int renvoient 0 comme valeur de succès et des valeurs négatives comme code d'erreur concret PWQ_ERROR. pwquality_strerror() n'alloue pas de données et ne peut donc pas échouer.

Le score positif ou nul renvoyé par pwquality_check() ne doit pas être utilisé pour rejeter des mots de passe, il doit être utilisé uniquement comme indicateur approximatif de l'entropie présente dans le mot de passe, avec des valeurs telles que 0-30 étant faibles, 30-60 moyennes, et 60-100 élevées.

EXEMPLE

Utilisation typique de l'API libpwquality :

#include <pwquality.h>
...
       pwquality_settings_t *pwq;
       int rv;
       void *auxerror;
       char buf[PWQ_MAX_ERROR_MESSAGE_LEN];
       pwq = pwquality_default_settings();
       if (pwq == NULL) {
               fprintf(stderr, "Erreur : %s\n", pwquality_strerror(buf, sizeof(buf), PWQ_ERROR_MEM_ALLOC, NULL));
               return -1;
       }

       if ((rv=pwquality_read_config(pwq, NULL, &auxerror)) != 0) {
               pwquality_free_settings(pwq);
               fprintf(stderr, "Erreur : %s\n", pwquality_strerror(buf, sizeof(buf), rv, auxerror));
               return -1;
       }

       rv = pwquality_check(pwq, buf, NULL, user, &auxerror);
       pwquality_free_settings(pwq);
       if (rv >= 0) {
               fprintf(stderr, "Le score d'entropie du mot de passe est : %d\n", rv);
       } else {
               fprintf(stderr, "Le mot de passe est rejeté avec l'erreur : %s\n", pwquality_strerror(buf, sizeof(buf), rv, auxerror));
       }
