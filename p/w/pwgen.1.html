PWGEN(1) Manuel des commandes générales PWGEN(1)

NOM

pwgen - générer des mots de passe prononçables

SYNTAXE

pwgen [ OPTION ] [ longueur_mot_de_passe ] [ nb_mots_de_passe ]

DESCRIPTION

Le programme pwgen génère des mots de passe conçus pour être facilement mémorisables par les humains, tout en étant aussi sécurisés que possible. Les mots de passe facilement mémorisables ne seront jamais aussi sécurisés que des mots de passe complètement aléatoires. En particulier, les mots de passe générés par pwgen sans l'option -s ne doivent pas être utilisés là où le mot de passe pourrait être attaqué par une attaque par force brute hors ligne. D'autre part, les mots de passe complètement générés aléatoirement ont tendance à être écrits, et sont susceptibles d'être compromis de cette manière.

Le programme pwgen est conçu pour être utilisé aussi bien de manière interactive que dans des scripts shell. Par conséquent, son comportement par défaut diffère selon que la sortie standard est un terminal tty ou un pipe vers un autre programme. Utilisé interactivement, pwgen affichera un écran de mots de passe, permettant à l'utilisateur de choisir un seul mot de passe, puis d'effacer rapidement l'écran. Cela empêche quelqu'un de pouvoir "regarder par-dessus l'épaule" le mot de passe choisi par l'utilisateur.

Lorsque la sortie standard (stdout) n'est pas un tty, pwgen ne générera qu'un seul mot de passe, ce qui est généralement beaucoup plus pratique pour les scripts shell, et afin d'être compatible avec les versions précédentes de ce programme.

OPTIONS

-0, --no-numerals
N'inclure aucun nombre dans les mots de passe générés.
-1
Imprimer les mots de passe générés un par ligne.
-A, --no-capitalize
Ne pas inclure de lettres majuscules dans les mots de passe générés.
-a, --alt-phonics
Cette option ne fait rien de spécial ; elle est présente uniquement pour la rétrocompatibilité.
-B, --ambiguous
Ne pas utiliser de caractères qui pourraient être confondus par l'utilisateur lors de l'impression, tels que 'l' et '1', ou '0' et 'O'. Cela réduit considérablement le nombre de mots de passe possibles, et par conséquent la qualité des mots de passe. Cela peut être utile pour les utilisateurs ayant une mauvaise vue, mais en général, l'utilisation de cette option n'est pas recommandée.
-c, --capitalize
Inclure au moins une lettre majuscule dans le mot de passe. C'est le comportement par défaut si la sortie standard est un terminal tty.
-C
Imprimer les mots de passe générés en colonnes. C'est le comportement par défaut si la sortie standard est un terminal tty.
-N, --num-passwords=num
Générer num mots de passe. Par défaut, il s'agit d'un écran complet si les mots de passe sont imprimés par colonnes, et d'un seul mot de passe sinon.
-n, --numerals
Inclure au moins un chiffre dans le mot de passe. C'est le comportement par défaut si la sortie standard est un terminal tty.
-H, --sha1=/chemin/vers/fichier[#semence]
Utilisera le hachage sha1 du fichier donné et de la semence optionnelle pour créer le mot de passe. Cela vous permettra de recalculer le même mot de passe plus tard, si vous vous souvenez du fichier, de la semence et des options pwgen utilisées. par exemple : pwgen -H ~/your_favorite.mp3#your@email.com donne une liste de mots de passe possibles pour votre compte pop3, et vous pouvez demander cette liste encore et encore.
ATTENTION : Les mots de passe générés avec cette option ne sont pas très aléatoires. Si vous utilisez cette option, assurez-vous que l'attaquant ne peut pas obtenir une copie du fichier. Notez également que le nom du fichier peut être facilement disponible à partir du fichier ~/.history ou ~/.bash_history.
-h, --help
Afficher un message d'aide.
-r caractères, --remove-chars=caractères
N'utiliser pas les caractères spécifiés dans le mot de passe. Cette option désactivera le générateur basé sur les phonèmes et utilisera le générateur de mots de passe aléatoires.
-s, --secure
Générer des mots de passe complètement aléatoires et difficiles à mémoriser. Ceux-ci ne devraient être utilisés que pour les mots de passe machine, car sinon il est presque garanti que les utilisateurs écriront le mot de passe sur un morceau de papier collé sur le moniteur...
-v, --no-vowels
Générer des mots de passe aléatoires qui ne contiennent pas de voyelles ou de chiffres qui pourraient être confondus avec des voyelles. Il fournit des mots de passe moins sécurisés pour permettre aux administrateurs système de ne pas avoir à se soucier des sous-chaînes offensantes dans les mots de passe aléatoires.
-y, --symbols
Inclure au moins un caractère spécial dans le mot de passe.
