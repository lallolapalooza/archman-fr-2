NOM

pw-dump - Le vidage de l'état PipeWire

SYNTAXE

pw-dump [options]

DESCRIPTION

Le programme pw-dump produit une représentation de l'état actuel de PipeWire au format JSON, incluant les informations sur les nœuds, les périphériques, les modules, les ports et autres objets.

OPTIONS

-h | --help

Afficher l'aide.

-r | --remote=NOM

Le nom de l'instance distante à vider. Si non spécifié, une connexion est établie à l'instance PipeWire par défaut.

-m | --monitor

Surveiller les changements d'état de PipeWire et afficher des tableaux JSON décrivant les changements.

-N | --no-colors

Désactiver la sortie couleur.

-C | --color=QUAND

Activer la prise en charge des couleurs. QUAND peut être jamais, toujours, ou auto.

AUTEURS

Les développeurs de PipeWire https://gitlab.freedesktop.org/pipewire/pipewire/issues ; PipeWire est disponible sur https://pipewire.org
