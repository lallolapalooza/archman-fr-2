PWQUALITY.CONF(5) Manuel des formats de fichiers PWQUALITY.CONF(5)

NOM

pwquality.conf - configuration pour la bibliothèque libpwquality

SYNOPSIS

/etc/security/pwquality.conf

/etc/security/pwquality.conf.d/*.conf

DESCRIPTION

pwquality.conf permet de configurer les exigences par défaut de qualité des mots de passe pour les mots de passe du système. Ce fichier est lu par la bibliothèque libpwquality et les utilitaires qui utilisent cette bibliothèque pour vérifier et générer des mots de passe.

Le fichier a un format très simple nom = valeur avec des commentaires possibles commençant par le caractère "#". Les espaces au début de la ligne, à la fin de la ligne et autour du signe "=" sont ignorés.

La bibliothèque libpwquality lit également d'abord tous les fichiers *.conf du répertoire /etc/security/pwquality.conf.d dans l'ordre trié ASCII. Les valeurs des mêmes paramètres sont remplacées dans l'ordre où les fichiers sont analysés.

OPTIONS

Les options possibles dans le fichier sont :

difok
Nombre de caractères dans le nouveau mot de passe qui ne doivent pas être présents dans l'ancien mot de passe. (par défaut 1)

La valeur spéciale 0 désactive toutes les vérifications de similitude entre le nouveau mot de passe et l'ancien, sauf si le nouveau mot de passe est exactement le même que l'ancien.

minlen
Taille minimale acceptable pour le nouveau mot de passe (plus un si les crédits ne sont pas désactivés, ce qui est le cas par défaut). (Voir pam_pwquality(8).) Ne peut pas être défini à une valeur inférieure à 6. (par défaut 8)
dcredit
Crédit maximal pour la présence de chiffres dans le nouveau mot de passe. Si inférieur à 0, il s'agit du nombre minimum de chiffres dans le nouveau mot de passe. (par défaut 0)
ucredit
Crédit maximal pour la présence de caractères majuscules dans le nouveau mot de passe. Si inférieur à 0, il s'agit du nombre minimum de caractères majuscules dans le nouveau mot de passe. (par défaut 0)
lcredit
Crédit maximal pour la présence de caractères minuscules dans le nouveau mot de passe. Si inférieur à 0, il s'agit du nombre minimum de caractères minuscules dans le nouveau mot de passe. (par défaut 0)
ocredit
Crédit maximal pour la présence d'autres caractères dans le nouveau mot de passe. Si inférieur à 0, il s'agit du nombre minimum d'autres caractères dans le nouveau mot de passe. (par défaut 0)
minclass
Nombre minimum de classes de caractères requises pour le nouveau mot de passe (chiffres, majuscules, minuscules, autres). (par défaut 0)
maxrepeat
Nombre maximal de caractères consécutifs identiques autorisés dans le nouveau mot de passe. La vérification est désactivée si la valeur est 0. (par défaut 0)
maxsequence
Longueur maximale des séquences de caractères monotones dans le nouveau mot de passe. Des exemples de telles séquences sont '12345' ou 'fedcb'. Notez que la plupart de ces mots de passe ne passeront pas la vérification de simplicité, à moins que la séquence ne soit qu'une partie mineure du mot de passe. La vérification est désactivée si la valeur est 0. (par défaut 0)
maxclassrepeat
Nombre maximal de caractères consécutifs de la même classe autorisés dans le nouveau mot de passe. La vérification est désactivée si la valeur est 0. (par défaut 0)
gecoscheck
Si non nul, vérifie si les mots de plus de 3 caractères du champ GECOS de l'entrée passwd(5) de l'utilisateur sont contenus dans le nouveau mot de passe. La vérification est désactivée si la valeur est 0. (par défaut 0)
dictcheck
Si non nul, vérifie si le mot de passe (avec d'éventuelles modifications) correspond à un mot d'un dictionnaire. Actuellement, la vérification du dictionnaire est effectuée à l'aide de la bibliothèque cracklib. (par défaut 1)
usercheck=N
Si non nul, vérifie si le mot de passe (avec d'éventuelles modifications) contient le nom d'utilisateur sous une certaine forme. Il n'est pas effectué pour les noms d'utilisateur de moins de 3 caractères. (par défaut 1)
usersubstr=N
Si supérieur à 3 (en raison de la longueur minimale dans usercheck), vérifie si le mot de passe contient une sous-chaîne d'au moins N caractères sous une certaine forme. (par défaut 0)
enforcing=N
Si non nul, rejette le mot de passe s'il échoue aux vérifications, sinon affiche uniquement l'avertissement. Ce paramètre s'applique uniquement au module pam_pwquality et éventuellement à d'autres applications qui modifient explicitement leur comportement en fonction de celui-ci. Il n'affecte pas pwmake(1) et pwscore(1). (par défaut 1)
badwords
Liste de mots séparés par des espaces qui ne doivent pas être contenus dans le mot de passe. Ce sont des mots supplémentaires à la vérification du dictionnaire cracklib. Ce paramètre peut également être utilisé par les applications pour émuler la vérification gecos pour les comptes utilisateur qui ne sont pas encore créés.
dictpath
Chemin vers les dictionnaires cracklib. Par défaut, utilise la valeur par défaut de cracklib.
retry=N
Demande à l'utilisateur au plus N fois avant de retourner une erreur. La valeur par défaut est 1.
enforce_for_root
Le module retournera une erreur en cas d'échec de vérification, même si l'utilisateur qui modifie le mot de passe est root. Cette option est désactivée par défaut, ce qui signifie que seul le message concernant l'échec de la vérification est affiché, mais root peut modifier le mot de passe de toute façon. Notez que root n'est pas invité à saisir l'ancien mot de passe, donc les vérifications qui comparent l'ancien et le nouveau mot de passe ne sont pas effectuées.
local_users_only
Le module ne testera pas la qualité du mot de passe pour les utilisateurs qui ne sont pas présents dans le fichier /etc/passwd. Le module demande toujours le mot de passe, de sorte que les modules suivants dans la pile peuvent utiliser l'option use_authtok. Cette option est désactivée par défaut.
