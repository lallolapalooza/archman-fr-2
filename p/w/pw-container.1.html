pw-container(1) Manuel des commandes générales pw-container(1)

NOM

pw-container - L'utilitaire de conteneur PipeWire

SYNTAXE

pw-container [options] [PROGRAMME]

DESCRIPTION

Exécute un programme dans un nouveau contexte de sécurité [1].

pw-container créera un nouveau socket Unix temporaire et utilisera l'API d'extension SecurityContext pour créer un serveur sur ce socket avec les propriétés données. Les clients créés à partir de ce socket serveur auront les propriétés de sécurité qui leur sont associées.

Ceci peut être utilisé pour simuler le comportement de Flatpak ou d'autres conteneurs.

Sans aucun argument, pw-container crée simplement le nouveau socket et affiche son adresse sur la sortie standard. D'autres programmes PipeWire peuvent alors être exécutés avec PIPEWIRE_REMOTE=<adresse_socket> pour se connecter via ce contexte de sécurité.

Lorsque PROGRAMME est donné, la variable d'environnement PIPEWIRE_REMOTE sera définie et PROGRAMME sera passé à system(). Les arguments de PROGRAMME doivent être correctement cités.

OPTIONS

-P | --properties=VALEUR

Définit des propriétés de contexte supplémentaires sous forme d'objet JSON.

-r | --remote=NOM

Le nom de l'instance distante à laquelle se connecter. Si non spécifié, une connexion est établie avec l'instance PipeWire par défaut.

-h | --help

Affiche l'aide.

--version

Affiche les informations de version.

STATUT DE SORTIE

Si le contexte de sécurité a été créé avec succès, pw-container ne se termine pas tant qu'il n'est pas arrêté par un signal. Il se termine avec le statut 0 s'il est arrêté par SIGINT ou SIGTERM dans ce cas.

Sinon, il se termine avec un statut de sortie non nul.

EXEMPLES

pw-container 'pw-dump i 0'

Exécute pw-dump de l'objet Core. Notez la différence dans les permissions de l'objet lorsque pw-dump est exécuté avec et sans pw-container.

pw-container 'pw-dump pw-dump'

Exécute pw-dump de lui-même. Notez la différence dans les jetons de sécurité du client lorsque pw-dump est exécuté avec et sans pw-container.
