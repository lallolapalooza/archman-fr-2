PW-INSPECTOR(1) Manuel des commandes générales PW-INSPECTOR(1)

NOM

pw-inspector - Un outil pour réduire la liste de mots de passe

SYNOPSIS

pw-inspector [-i FICHIER] [-o FICHIER] [-m LMIN] [-M LMAX] [-c NMIN] -l -u -n -p -s

DESCRIPTION

PW-Inspector lit des mots de passe et affiche ceux qui répondent aux exigences. Le code de retour est le nombre de mots de passe valides trouvés, 0 si aucun n'a été trouvé. À utiliser pour la sécurité : vérifier les mots de passe, si 0 est retourné, rejeter le choix du mot de passe. À utiliser pour le piratage : réduire votre fichier dictionnaire aux exigences de mot de passe de la cible. L'utilisation n'est autorisée qu'à des fins légales.

OPTIONS

-i FICHIER
fichier à partir duquel lire les mots de passe (par défaut : stdin)
-o FICHIER
fichier dans lequel écrire les mots de passe valides (par défaut : stdout)
-m LMIN
longueur minimale d'un mot de passe valide
-M LMAX
longueur maximale d'un mot de passe valide
-c NMIN
le nombre minimum d'ensembles requis (par défaut : tous ceux donnés)
-h, --help
Affiche un résumé des options.

ENSEMBLES

-l
caractères minuscules (a, b, c, d, etc.)
-u
caractères majuscules (A, B, C, D, etc.)
-n
chiffres (1, 2, 3, 4, etc.)
-p
caractères imprimables (qui ne sont pas -l/-n/-n, par exemple $, !, /, (, *, etc.)
 -s
caractères spéciaux - tous les autres qui ne sont pas dans les ensembles ci-dessus
