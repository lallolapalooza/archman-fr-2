user_from_uid(3) Manuel des fonctions de bibliothèque user_from_uid(3)

NOM

user_from_uid, uid_from_user, group_from_gid, gid_from_group — mise en cache des entrées de mot de passe et de groupe

BIBLIOTHÈQUE

bibliothèque « libbsd »

SYNOPSIS

#include <pwd.h> (Voir libbsd(7) pour l'utilisation des inclusions.)
int
uid_from_user(const char *name, uid_t *uid);

const char *
user_from_uid(uid_t uid, int nouser);

#include <grp.h>

int
gid_from_group(const char *name, gid_t *gid);

const char *
group_from_gid(gid_t gid, int nogroup);

DESCRIPTION

La fonction user_from_uid() retourne le nom d'utilisateur associé à l'argument uid. Le nom d'utilisateur est mis en cache afin que des appels multiples avec le même uid ne nécessitent pas d'appels supplémentaires à getpwuid(3). S'il n'y a pas d'utilisateur associé au uid, un pointeur vers une représentation sous forme de chaîne du uid est retourné, sauf si l'argument nouser est non nul, auquel cas un pointeur nul est retourné.

La fonction uid_from_user() retourne l'ID utilisateur associé à l'argument name. L'ID utilisateur est mis en cache afin que des appels multiples avec le même name ne nécessitent pas d'appels supplémentaires à getpwnam(3). S'il n'y a pas d'ID utilisateur associé au name, la fonction uid_from_user() retourne -1 ; sinon, elle stocke l'ID utilisateur à l'emplacement pointé par uid et retourne 0.

La fonction group_from_gid() retourne le nom de groupe associé à l'argument gid. Le nom de groupe est mis en cache afin que des appels multiples avec le même gid ne nécessitent pas d'appels supplémentaires à getgrgid(3). S'il n'y a pas de groupe associé au gid, un pointeur vers une représentation sous forme de chaîne du gid est retourné, sauf si l'argument nogroup est non nul, auquel cas un pointeur nul est retourné.

La fonction gid_from_group() retourne l'ID de groupe associé à l'argument name. L'ID de groupe est mis en cache afin que des appels multiples avec le même name ne nécessitent pas d'appels supplémentaires à getgrnam(3). S'il n'y a pas d'ID de groupe associé au name, la fonction gid_from_group() retourne -1 ; sinon, elle stocke l'ID de groupe à l'emplacement pointé par gid et retourne 0.

VOIR AUSSI

getgrgid(3), getpwuid(3)

HISTORIQUE

Les fonctions user_from_uid() et group_from_gid() sont apparues pour la première fois dans 4.4BSD.

Les fonctions uid_from_user() et gid_from_group() sont apparues pour la première fois dans NetBSD 1.4 et OpenBSD 6.4.
