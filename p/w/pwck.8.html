PWCK(8) Commandes de gestion du système PWCK(8)

NOM

pwck - vérifier l'intégrité des fichiers de mots de passe

SYNTAXE

pwck [options] [FICHIER_MOT_DE_PASSE [ FICHIER_OMBRE ]]

DESCRIPTION

La commande pwck vérifie l'intégrité des informations des utilisateurs et de l'authentification. Elle vérifie que toutes les entrées dans /etc/passwd et /etc/shadow ont le format approprié et contiennent des données valides. L'utilisateur est invité à supprimer les entrées mal formatées ou présentant d'autres erreurs irrécupérables.

Les vérifications suivantes sont effectuées pour chaque entrée :

•le nombre correct de champs
•un nom d'utilisateur unique et valide
•un identifiant utilisateur et groupe valide
•un groupe principal valide
•un répertoire personnel valide
•un shell de connexion valide

Les vérifications des informations de mot de passe chiffré sont activées lorsque le deuxième paramètre de fichier FICHIER_OMBRE est spécifié ou lorsque /etc/shadow existe sur le système.

Ces vérifications sont les suivantes :

•chaque entrée passwd a une entrée shadow correspondante, et chaque entrée shadow a une entrée passwd correspondante
•les mots de passe sont spécifiés dans le fichier chiffré
•les entrées shadow ont le nombre correct de champs
•les entrées shadow sont uniques dans le fichier shadow
•les derniers changements de mot de passe ne sont pas dans le futur

Les vérifications du nombre correct de champs et du nom d'utilisateur unique sont fatales. Si une entrée a un nombre incorrect de champs, l'utilisateur sera invité à supprimer la ligne entière. Si l'utilisateur ne répond pas affirmativement, toutes les vérifications ultérieures seront ignorées. Une entrée avec un nom d'utilisateur dupliqué sera proposée à la suppression, mais les vérifications restantes seront toujours effectuées. Toutes les autres erreurs sont des avertissements et l'utilisateur est encouragé à exécuter la commande usermod pour corriger l'erreur.

Les commandes qui opèrent sur le fichier /etc/passwd ne peuvent pas modifier les entrées corrompues ou dupliquées. pwck doit être utilisé dans ces circonstances pour supprimer l'entrée fautive.

OPTIONS

Les options -r et -s ne peuvent pas être combinées.

Les options applicables à la commande pwck sont :

--badname 

Autoriser les noms qui ne sont pas conformes aux standards.

-h, --help

Afficher le message d'aide et quitter.

-q, --quiet

Signaler uniquement les erreurs. Les avertissements qui ne nécessitent aucune action de la part de l'utilisateur ne seront pas affichés.

-r, --read-only

Exécuter la commande pwck en mode lecture seule.

-R, --root CHROOT_DIR

Appliquer les modifications dans le répertoire CHROOT_DIR et utiliser les fichiers de configuration du répertoire CHROOT_DIR. Seuls les chemins absolus sont pris en charge.

-s, --sort

Trier les entrées dans /etc/passwd et /etc/shadow par UID.

Par défaut, pwck opère sur les fichiers /etc/passwd et /etc/shadow. L'utilisateur peut sélectionner des fichiers alternatifs avec les paramètres passwd et shadow.

CONFIGURATION

Les variables de configuration suivantes dans /etc/login.defs modifient le comportement de cet outil :

NONEXISTENT (chaîne)

Si un compte système n'a intentionnellement pas de répertoire personnel qui existe, cette chaîne peut être fournie dans l'entrée /etc/passwd pour le compte afin de l'indiquer. Le résultat est que pwck n'émettra pas d'avertissement superflu pour ce compte.

PASS_MAX_DAYS (nombre)

Le nombre maximum de jours pendant lesquels un mot de passe peut être utilisé. Si le mot de passe est plus ancien que cela, un changement de mot de passe sera forcé. S'il n'est pas spécifié, -1 sera supposé (ce qui désactive la restriction).

PASS_MIN_DAYS (nombre)

Le nombre minimum de jours autorisés entre les changements de mot de passe. Toute tentative de modification de mot de passe moins de temps avant cela sera rejetée. S'il n'est pas spécifié, 0 sera supposé (ce qui désactive la restriction).

PASS_WARN_AGE (nombre)

Le nombre de jours d'avertissement donnés avant l'expiration d'un mot de passe. Zéro signifie que l'avertissement est donné seulement le jour de l'expiration, une valeur de -1 signifie qu'aucun avertissement n'est donné. S'il n'est pas spécifié, aucun avertissement ne sera fourni.

FICHIERS

/etc/group

Informations sur les comptes de groupe.

/etc/passwd

Informations sur les comptes utilisateurs.

/etc/shadow

Informations sécurisées sur les comptes utilisateurs.

VALEURS DE RETOUR

La commande pwck se termine avec les valeurs suivantes :

0

succès

1

syntaxe de commande invalide

2

une ou plusieurs entrées de mot de passe incorrectes

3

impossible d'ouvrir les fichiers de mots de passe

4

impossible de verrouiller les fichiers de mots de passe

5

impossible de mettre à jour les fichiers de mots de passe

6

impossible de trier les fichiers de mots de passe
