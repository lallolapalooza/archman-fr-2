pipectl(1) Manuel des commandes générales pipectl(1)

NOM

pipectl - un utilitaire simple de gestion de tubes nommés

SYNTAXE

pipectl [-h,-o,-i,-n N,-p P,-f,-l]

DESCRIPTION

pipectl est un outil pour créer et gérer des tubes nommés éphémères qui peuvent être utilisés pour alimenter l'entrée standard d'un programme plus long, depuis une autre partie du système, sans nécessiter de mécanisme IPC complexe tel que les sockets de domaine UNIX.

pipectl est destiné à être utilisé par paires, un appel à pipectl ouvre le tube (-o) et l'alimente dans un processus, et tous les autres avec le même nom ou chemin écriront dans l'entrée standard de ce processus :

$ pipectl -o | daemon-process

$ echo "faire-la-chose --couleur rouge" | pipectl -i

$ echo "quitter" | pipectl -i

Le processus démon ne verra jamais de fin de fichier (EOF) sur son entrée standard. pipectl bloquera plutôt jusqu'à ce qu'un autre tube d'entrée (-i) soit ouvert, puis alimentera l'entrée standard de ce processus de manière asynchrone.

Lorsque le processus démon se termine ou ferme son entrée standard, pipectl nettoiera et supprimera automatiquement le tube nommé créé.

OPTIONS

-h, --help

Afficher le message d'aide et quitter.

-o, --out

Créer un tube nommé et imprimer son contenu sur la sortie standard.

-i, --in

Écrire l'entrée standard dans un tube nommé ouvert créé avec -o.

-n N, --name N

Créer un tube nommé avec un nom personnalisé. Voir CHEMINS.

-p P, --path P

Créer un tube nommé à un chemin personnalisé. Voir CHEMINS.

-f, --force

Forcer l'écrasement d'un tube nommé existant même s'il existe déjà (utilisable uniquement avec -o).

-l, --lock

Utiliser flock(2) pour synchroniser les écritures dans le tube (utilisable uniquement avec -i).

CHEMINS

Par défaut, pipectl créera le tube nommé dans un répertoire temporaire (TMP). Le premier répertoire disponible parmi les suivants sera utilisé :

  • $XDG_RUNTIME_DIR
  • $TMPDIR
  • /tmp

Le chemin résultant du tube nommé est le suivant :

par défaut

TMP/pipectl.UID.pipe

avec --name NOM

TMP/pipectl.UID.NOM.pipe

avec --path CHEMIN

CHEMIN

où UID est l'identifiant utilisateur réel du processus pipectl (voir getuid(3)).
