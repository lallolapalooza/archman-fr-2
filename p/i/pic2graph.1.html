pic2graph(1) Manuel des commandes générales pic2graph(1)

Nom

pic2graph - convertir un diagramme pic en une image recadrée

Synopsis

pic2graph [-unsafe] [-format format-sortie] [-eqn délimiteurs] [argument-convert ...]
pic2graph --help
pic2graph -v
pic2graph --version

Description

pic2graph lit un programme pic(1) depuis l'entrée standard et écrit un fichier image, par défaut au format Portable Network Graphics (PNG), sur la sortie standard. Il traduit en outre les constructions eqn(1), il peut donc être utilisé pour générer des images de formules mathématiques.

Le code PIC d'entrée ne doit pas être enveloppé avec les macros .PS et .PE/.PF qui le protègent normalement dans les documents groff(1).

Les arguments non reconnus par pic2graph sont transmis au programme convert(1) d'ImageMagick ou GraphicsMagick. En les spécifiant, vous pouvez ajouter une bordure à votre image, définir la densité de pixels de l'image ou effectuer d'autres transformations utiles.

L'image de sortie est découpée à l'aide de l'option -trim de convert pour obtenir la plus petite boîte englobante possible contenant tous les pixels noirs.

Options

--help affiche un message d'utilisation, tandis que -v et --version affichent les informations de version ; tous quittent ensuite.

-eqn délimiteurs
Utilise délimiteurs comme caractères d'ouverture et de fermeture qui délimitent les directives eqn ; le défaut est “$$”. L'argument de l'option délimiteurs doit être une chaîne de deux caractères, mais une chaîne vide ("") est acceptée comme directive pour désactiver le traitement eqn.
-format format-sortie
Écrit l'image au format-sortie, qui doit être compris par convert ; le défaut est PNG.
-unsafe
Exécute groff en mode unsafe, permettant à la commande PIC sh d'exécuter des commandes shell Unix arbitraires. Le défaut de groff est d'interdire cela.

Environnement

GROFF_TMPDIR
TMPDIR
TMP
TEMP
Ces variables d'environnement sont recherchées dans l'ordre donné pour déterminer le répertoire où les fichiers temporaires seront créés. Si aucune n'est définie, /tmp est utilisé.

Auteurs

pic2graph a été écrit par Eric S. Raymond, basé sur une recette de W. Richard Stevens.
