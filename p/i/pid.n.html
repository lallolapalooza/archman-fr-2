NOM

pid - Récupérer les identifiants de processus

SYNTAXE

pid ?fileId?

DESCRIPTION

Si l'argument fileId est fourni, il doit normalement faire référence à un pipeline de processus créé avec la commande open. Dans ce cas, la commande pid renverra une liste dont les éléments sont les identifiants des processus du pipeline, dans l'ordre. La liste sera vide si fileId fait référence à un fichier ouvert qui n'est pas un pipeline de processus. Si aucun argument fileId n'est fourni, pid renvoie l'identifiant du processus courant. Tous les identifiants de processus sont renvoyés sous forme de chaînes décimales.

EXEMPLE

Imprimer les informations sur les processus d'un pipeline en utilisant le programme SysV ps avant de lire la sortie de ce pipeline :

set pipeline [open "| zcat somefile.gz | grep foobar | sort -u"]
# Imprimer les informations sur les processus
exec ps -fp [pid $pipeline] >@stdout
# Imprimer un séparateur puis la sortie du pipeline
puts [string repeat - 70]
puts [read $pipeline]
close $pipeline
