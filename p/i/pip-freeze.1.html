NOM

pip-freeze - description de la commande pip freeze

DESCRIPTION

Affiche les paquets installés au format requirements.

Les paquets sont listés par ordre alphabétique insensible à la casse.

UTILISATION

python -m pip freeze [options]

OPTIONS

-r, --requirement <fichier>
Utilise l'ordre du fichier requirements donné et ses commentaires lors de la génération de la sortie. Cette option peut être utilisée plusieurs fois.

(variable d'environnement : PIP_REQUIREMENT)

-l, --local
Si vous êtes dans un environnement virtuel avec accès global, n'affiche pas les paquets installés globalement.

(variable d'environnement : PIP_LOCAL)

--user
N'affiche que les paquets installés dans le site utilisateur.

(variable d'environnement : PIP_USER)

--path <chemin>
Limite aux chemins d'installation spécifiés pour lister les paquets (peut être utilisé plusieurs fois).

(variable d'environnement : PIP_PATH)

--all
Ne saute pas ces paquets dans la sortie : pip

(variable d'environnement : PIP_ALL)

--exclude-editable
Exclut les paquets modifiables de la sortie.

(variable d'environnement : PIP_EXCLUDE_EDITABLE)

--exclude <paquet>
Exclut le paquet spécifié de la sortie.

(variable d'environnement : PIP_EXCLUDE)
