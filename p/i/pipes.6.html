NOM

pipes - remplir l'écran avec un système de tuyauterie.

SYNTAXE

pipes [--display hote:ecran.no] [--visual visuel] [--window] [--root] [--window-id nombre] [-count 0] [-count 1] [-cycles nombre] [-size nombre] [-factory nombre] [-delay nombre] [-no-fisheye] [-tightturns] [-db] [-fps]

DESCRIPTION

Si vous avez déjà été dans la même pièce qu'une machine Windows NT, vous avez probablement vu ce hack GL. Il remplit l'écran avec un système de tuyauterie.

OPTIONS

--visual visuel
Spécifie quel visuel utiliser. Les valeurs valides sont le nom d'une classe visuelle, ou l'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--window
Dessine sur une nouvelle fenêtre créée. C'est le comportement par défaut.
--root
Dessine sur la fenêtre racine.
--window-id nombre
Dessine sur la fenêtre spécifiée.
--count 0
Tuyaux courbes.
--count 1
Jointures de boules.
--cycles nombre
Nombre de systèmes de tuyauterie à dessiner simultanément. Défaut : 5.
--size nombre
Longueur de chaque système de tuyauterie. Défaut : 500.
--factory nombre
Quantité de gadgets à créer ; la plage utile est de 0 à 10. Défaut : 2.
--delay nombre
Temps (en microsecondes) de pause entre chaque image. Défaut : 10000.
--fisheye | --no-fisheye
Utiliser ou non un objectif fisheye.
--tightturns | --no-tightturns
Autoriser ou non les virages serrés.
--db | --no-db
Utiliser ou non le double buffering.
--fps
Afficher le taux d'images par seconde actuel, la charge CPU et le nombre de polygones.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de fenêtre à utiliser avec --root.
