pipewire-client.conf(5) Manuel des formats de fichiers pipewire-client.conf(5)

NOM

pipewire-client.conf - client.conf

DESCRIPTION

Le fichier de configuration du client PipeWire.

SYNTAXE

$XDG_CONFIG_HOME/pipewire/client.conf

/etc/pipewire/client.conf

/usr/share/pipewire/client.conf

/usr/share/pipewire/client.conf.d/

/etc/pipewire/client.conf.d/

$XDG_CONFIG_HOME/pipewire/client.conf.d/

DESCRIPTION

Configuration pour les clients natifs PipeWire, et pour le plugin ALSA de PipeWire.

Un programme client natif PipeWire sélectionne la configuration par défaut à charger, et si rien n'est spécifié, il charge généralement client.conf.

Le format du fichier de configuration et la logique de recherche sont les mêmes que pour pipewire.conf(5).

Les fichiers de configuration "drop-in" client.conf.d/*.conf peuvent être utilisés, et sont recommandés. Voir pipewire.conf(5).

SECTIONS DU FICHIER DE CONFIGURATION

stream.properties

Configure les options pour les flux clients.

stream.rules

Configure les règles pour les flux clients.

alsa.properties

Configuration du client ALSA.

alsa.rules

Règles de correspondance du client ALSA.

En outre, les sections de configuration du contexte PipeWire peuvent également être spécifiées, voir pipewire.conf(5).

PROPRIÉTÉS DU FLUX

Les fichiers de configuration client contiennent une section stream.properties qui configure les options pour les flux clients :

# ~/.config/pipewire/client.conf.d/custom.conf
stream.properties = {
    #node.latency = 1024/48000
    #node.autoconnect = true
    #resample.disable = false
    #resample.quality = 4
    #monitor.channel-volumes = false
    #channelmix.disable = false
    #channelmix.min-volume = 0.0
    #channelmix.max-volume = 10.0
    #channelmix.normalize = false
    #channelmix.lock-volume = false
    #channelmix.mix-lfe = true
    #channelmix.upmix = true
    #channelmix.upmix-method = psd  # none, simple
    #channelmix.lfe-cutoff = 150.0
    #channelmix.fc-cutoff  = 12000.0
    #channelmix.rear-delay = 12.0
    #channelmix.stereo-widen = 0.0
    #channelmix.hilbert-taps = 0
    #dither.noise = 0
    #dither.method = none # rectangular, triangular, triangular-hf, wannamaker3, shaped5
    #debug.wav-path = ""
}

Certaines des propriétés font référence à différents aspects du flux :

  • Propriétés générales du flux pour identifier le flux.
  • Propriétés générales du flux pour classifier le flux.
  • Comment il sera planifié par le graphe.
  • Comment il sera lié par le gestionnaire de session.
  • Comment le traitement interne sera effectué.
  • Propriétés pour configurer le format média.

Une liste des propriétés d'objet qui peuvent être appliquées aux flux se trouve dans pipewire(7) Propriétés communes des nœuds et pipewire(7) Propriétés des adaptateurs audio

RÈGLES DU FLUX

Vous pouvez ajouter des **règles de correspondance, voir pipewire(1)** pour définir des propriétés pour certains flux et filtres.

stream.rules et filter.rules fournissent une action update-props qui prend un objet avec des propriétés qui sont mises à jour sur l'objet nœud du flux et du filtre.

Ajoutez une section stream.rules ou filter.rules dans le fichier de configuration comme ceci :

# ~/.config/pipewire/client.conf.d/custom.conf
stream.rules = [
    {
        matches = [
            {
                # toutes les clés doivent correspondre à la valeur. ! nie. ~ commence une regex.
                application.process.binary = "firefox"
            }
        ]
        actions = {
            update-props = {
                node.name = "Mon Nom"
            }
        }
    }
]

Définira le node.name de Firefox à "Mon Nom".

PROPRIÉTÉS CLIENT ALSA

Une section alsa.properties peut être ajoutée pour configurer les applications clientes qui se connectent via le plugin ALSA de PipeWire.

# ~/.config/pipewire/client.conf.d/custom.conf
alsa.properties = {
    #alsa.deny = false
    #alsa.format = 0
    #alsa.rate = 0
    #alsa.channels = 0
    #alsa.period-bytes = 0
    #alsa.buffer-bytes = 0
    #alsa.volume-method = cubic         # linear, cubic
}

alsa.deny

Refuse l'accès ALSA au client. Utile dans les règles ou la variable d'environnement PIPEWIRE_ALSA.

alsa.format

Le format ALSA à utiliser pour le client. Il s'agit d'un nom de format ALSA. Par défaut 0, ce qui signifie autoriser tous les formats.

alsa.rate

Le taux d'échantillonnage à utiliser pour le client. La valeur par défaut est 0, ce qui signifie autoriser tous les taux.

alsa.channels

Le nombre de canaux pour le client. La valeur par défaut est 0, ce qui signifie autoriser n'importe quel nombre de canaux.

alsa.period-bytes

Le nombre d'octets par période. La valeur par défaut est 0, ce qui signifie autoriser n'importe quel nombre d'octets par période.

alsa.buffer-bytes

Le nombre d'octets dans le tampon ALSA. La valeur par défaut est 0, ce qui signifie autoriser n'importe quel nombre d'octets.

alsa.volume-method = cubic | linear

Contrôle la courbe de volume utilisée sur le mixeur ALSA. Les valeurs possibles sont cubic et linear. Par défaut, on utilise cubic.

RÈGLES CLIENT ALSA

Il est possible de définir des propriétés spécifiques aux clients ALSA en utilisant des **Règles de correspondance, voir pipewire(1)**. Vous pouvez définir n'importe laquelle des propriétés ALSA ci-dessus ou n'importe laquelle des stream.properties.

Exemple

# ~/.config/pipewire/client.conf.d/custom.conf
alsa.rules = [
    {   matches = [ { application.process.binary = "resolve" } ]
        actions = {
            update-props = {
                alsa.buffer-bytes = 131072
            }
        }
    }
]

VARIABLES D'ENVIRONNEMENT

Voir pipewire(1) pour les variables d'environnement communes. Beaucoup de celles-ci s'appliquent également aux applications clientes.

Les variables d'environnement influencent également les applications ALSA qui utilisent le plugin ALSA de PipeWire.

PIPEWIRE_ALSA

Ceci peut être un objet avec des propriétés de alsa.properties ou stream.properties qui seront utilisées pour construire le client et les flux.

Par exemple :

PIPEWIRE_ALSA='{ alsa.buffer-bytes=16384 node.name=foo }' aplay ...


Lance aplay avec des propriétés personnalisées.

PIPEWIRE_NODE

Indique au client ALSA de se lier à un objet puits ou source spécifique. numéro de série ou node.name.

Par exemple :

PIPEWIRE_NODE=alsa_output.pci-0000_00_1b.0.analog-stereo aplay ...


Fait jouer aplay sur le puits audio donné.
