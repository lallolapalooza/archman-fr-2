NOM

pip-search - description de la commande pip search

DESCRIPTION

Recherche des paquets PyPI dont le nom ou le résumé contient <query>.

UTILISATION

python -m pip search [options] <query>

OPTIONS

-i, --index <url>
URL de base du Python Package Index (par défaut https://pypi.org/pypi)

(variable d'environnement : PIP_INDEX)
