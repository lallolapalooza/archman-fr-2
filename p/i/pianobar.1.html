pianobar(1) Manuel des commandes générales pianobar(1)

NOM

pianobar - lecteur de musique en console pour pandora.com

SYNOPSIS

pianobar

DESCRIPTION

pianobar est un lecteur de musique léger en console pour le service de radio personnalisée en ligne pandora.com.

FICHIERS

$XDG_CONFIG_HOME/pianobar/config ou ~/.config/pianobar/config

Fichier de configuration par utilisateur. Voir CONFIGURATION.

/etc/libao.conf ou ~/.libao

Configuration globale/par utilisateur de la sortie audio. Voir la documentation de libao à http://xiph.org/ao/doc/config.html

CONFIGURATION

Le fichier de configuration se compose de lignes simples clé = valeur, chacune terminée par un caractère de nouvelle ligne (\n). Les clés sont sensibles à la casse.

Les clés act_* contrôlent les raccourcis clavier de pianobar. Tout caractère d'un octet, à l'exception de \x00 et de la valeur spéciale disabled, est autorisé ici.

act_help = ?
Affiche les raccourcis clavier.
act_songlove = +
Aime la chanson actuellement jouée.
act_songban = -
Banne la piste actuelle. Elle ne sera plus jouée et ne peut être supprimée qu'en utilisant l'interface web de pandora.com.
act_stationaddmusic = a
Ajoute plus de musique à la station actuelle. Il vous sera demandé une chaîne de recherche. Suivez simplement les instructions. Si vous ne savez pas quoi faire, essayez '?' (sans guillemets).
act_bookmark = b
Ajoute un signet à la chanson ou à l'artiste actuel.
act_stationcreate = c
Crée une nouvelle station. Vous devez entrer une chaîne de recherche et sélectionner la chanson ou l'artiste de votre choix.
act_stationdelete = d
Supprime la station actuelle.
act_songexplain = e
Explique pourquoi cette chanson est jouée.
act_stationaddbygenre = g
Ajoute une station par genre fournie par pandora.
act_history = h
Affiche l'historique.
act_songinfo = i
Affiche les informations sur la chanson/station actuellement jouée.
act_addshared = j
Ajoute une station partagée par identifiant. L'identifiant est un très grand entier sans "sh" au début.
act_managestation = =
Supprime les graines de chansons/artistes ou les retours.
act_songnext = n
Passe à la chanson suivante.
act_songpause = S
Met la lecture en pause.
act_songpausetoggle = p
act_songpausetoggle2 = <Espace>
Met en pause/reprend la lecture.
act_songplay = P
Reprend la lecture.
act_quit = q
Quitte pianobar.
act_stationrename = r
Renomme la station actuellement jouée.
act_stationchange = s
Sélectionne une autre station. La liste des stations peut être filtrée comme la plupart des listes en entrant une chaîne de recherche au lieu d'un numéro de station.
act_songtired = t
Banne la chanson pour un mois.
act_upcoming = u
Affiche les prochaines chansons de la playlist.
act_stationcreatefromsong = v
Crée une nouvelle station à partir de la chanson ou de l'artiste actuel.
act_stationselectquickmix = x
Sélectionne les stations quickmix. Vous pouvez basculer la sélection avec 't', sélectionner tout avec 'a' ou ne sélectionner aucune avec 'n'.
act_voldown = (
Diminue le volume.
act_volreset = ^
Réinitialise le volume.
act_volup = )
Augmente le volume.
act_settings = !
Modifie les paramètres de Pandora.
at_icon = @
Remplacement de %@ dans la chaîne de format de station. C'est " @ " par défaut.
audio_quality = {high, medium, low}
Sélectionne la qualité audio.
audio_pipe = /chemin/vers/pipe
Diffuse les échantillons audio bruts décodés vers un tuyau au lieu du périphérique audio par défaut. Utilisez sample_rate pour forcer un taux d'échantillonnage fixe.
autoselect = {1,0}
Sélectionne automatiquement le dernier élément restant d'une liste filtrée. Actuellement activé uniquement pour la sélection de station.
autostart_station = stationid
Joue cette station au démarrage. Vous pouvez obtenir le stationid en appuyant sur i ou sur la touche que vous avez définie dans act_songinfo.
ban_icon = </3
Icône pour les chansons bannies.
bind_to = {if!tunX,host!x.x.x.x,..}
Définit le nom de l'interface à utiliser comme interface réseau sortante. Le nom peut être un nom d'interface, une adresse IP ou un nom d'hôte. (depuis CURLOPT_INTERFACE)

Il peut être utilisé comme remplacement pour control_proxy en conjonction avec l'option route-nopull d'OpenVPN.

buffer_seconds = 5
Taille du tampon audio en secondes.
ca_bundle = /etc/ssl/certs/ca-certificates.crt
Chemin vers le bundle de certificats CA, contenant les certificats racine et intermédiaires requis pour valider le certificat SSL de Pandora.
control_proxy = http://utilisateur:motdepasse@hote:port/
Les utilisateurs non américains ont besoin d'un proxy pour utiliser pandora.com. Seule l'interface xmlrpc utilisera ce proxy. La musique est diffusée directement.
decrypt_password = R=U!LH$O2B#
device = android-generic
encrypt_password = 6#26FRL$ZWD
event_command = chemin
Fichier qui est exécuté lorsqu'un événement se produit. Voir la section EVENTCMD.
fifo = $XDG_CONFIG_HOME/pianobar/ctl
Emplacement du tuyau de contrôle. Voir la section TÉLÉCOMMANDE

format_list_song = %i) %a - %t%r
Caractères de formatage disponibles :

%i Numéro de la chanson

%a Artiste de la chanson

%t Titre de la chanson

%r Icône de note

%d Durée de la chanson

%@

L'icône at_icon

%s

Station de la chanson, si ce n'est pas la station actuelle.

format_msg_none = %s
format_msg_info = (i) %s
format_msg_nowplaying = |> %s
format_msg_time = # %s
format_msg_err = /! %s
format_msg_question = [?] %s
format_msg_list = %s
Chaînes de formatage de message. %s est remplacé par le message réel.
format_nowplaying_song = "%t" par "%a" sur "%l"%r%@%s
Format du message de la chanson en cours de lecture. Les caractères de formatage disponibles sont :

%t Titre de la chanson

%a Artiste de la chanson

%l Nom de l'album

%r Icône de note

%@ at_icon si la station est quickmix, vide sinon.

%s Nom réel de la station si quickmix

%u URL des détails de la chanson

format_nowplaying_station = Station "%n" (%i)
Format du message de la station en cours de lecture. Les caractères de formatage disponibles sont :

%n Nom de la station

%i ID de la station

format_time = %s%r/%t
Format de l'heure.

%e Temps écoulé

%r Temps restant

%s Signe

%t Temps total

gain_mul = 1.0
Pandora envoie une valeur ReplayGain avec chaque chanson. Ceci définit un multiplicateur afin que le réglage de gain puisse être réduit. 0.0 signifie aucun réglage de gain, 1.0 signifie un réglage de gain complet, les valeurs intermédiaires réduisent l'amplitude du réglage de gain.
history = 5
Conserver un historique des n dernières chansons (5 par défaut). Vous pouvez noter ces chansons.
love_icon = <3
Icône pour les chansons aimées.
max_retry = 3
Nombre maximum d'échecs pour plusieurs actions avant d'abandonner.
partner_password = AC7IBG09A3DTSYM4R41UJWL07VLN8JI7
partner_user = android
password = plaintext_password
Votre mot de passe pandora.com. En texte clair.
password_command = gpg --decrypt ~/password
Utiliser la sortie de la commande comme mot de passe. Ce réglage est remplacé en spécifiant un mot de passe avec password.
proxy = http://user:password@host:port/
Utiliser un proxy http. Notez que ce réglage remplace la variable d'environnement http_proxy. Seule l'authentification http "Basic" est supportée.
rpc_host = tuner.pandora.com
rpc_tls_port = 443
sample_rate = 0
Forcer un taux d'échantillonnage de sortie fixe. Le défaut, 0, utilise le taux d'échantillonnage du flux.
sort = {name_az, name_za, quickmix_01_name_az, quickmix_01_name_za, quickmix_10_name_az, quickmix_10_name_za}
Trier la liste des stations par nom ou type (est quickmix) et nom. name_az par exemple trie par nom de a à z, quickmix_01_name_za par type (quickmix en bas) et nom de z à a.
timeout = 30
Délai d'attente des opérations réseau.
tired_icon = zZ
Icône pour les chansons temporairement suspendues.
user = your@user.name
Votre nom d'utilisateur pandora.com.
volume = 0
Correction de volume initiale en dB. Généralement entre -30 et +5.

COMMANDE À DISTANCE

pianobar peut être contrôlé via un fifo. Vous devez le créer vous-même en exécutant


mkfifo ~/.config/pianobar/ctl

Ajustez le chemin si vous avez configuré $XDG_CONFIG_HOME ou modifié le réglage du fifo. Ensuite, vous pouvez écrire des commandes directement dans le fifo. Exemple (chanson suivante) :


echo -n 'n' > ~/.config/pianobar/ctl

n est la touche de raccourci pour "chanson suivante". Si vous avez personnalisé vos raccourcis clavier, vous devez utiliser ces caractères pour contrôler pianobar. Ce comportement peut changer à l'avenir !

Un autre exemple :


while true; do;
nc -l -p 12345 -s localhost localhost > ~/.config/pianobar/ctl;
sleep 1;
done


echo -ne 'n\x1a' | nc -q 0 127.0.0.1 12345

EVENTCMD

pianobar peut rapporter certains "événements" à une application externe (voir CONFIGURATION). Cette application est démarrée avec le nom de l'événement comme premier argument. Plus d'informations comme le code d'erreur et la description, ainsi que les informations sur la chanson liées à l'événement actuel, sont fournies via stdin.

Les événements actuellement pris en charge sont : artistbookmark, settingschange, settingsget, songban, songbookmark, songexplain, songfinish, songlove, songshelf, songstart, stationaddgenre, stationaddmusic, stationaddshared, stationcreate, stationdelete, stationdeleteartistseed, stationdeletefeedback, stationdeletesongseed, stationdeletestationseed, stationfetchgenre, stationfetchinfo, stationfetchplaylist, stationgetmodes, stationquickmixtoggle, stationrename, stationsetmode, usergetstations, userlogin

Un exemple de script peut être trouvé dans le répertoire contrib/ de la distribution source de pianobar.
