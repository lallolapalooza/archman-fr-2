NOM

pip-check - description de la commande pip check

DESCRIPTION

Vérifie que les paquets installés ont des dépendances compatibles.

UTILISATION

python -m pip check [options]

OPTIONS

-h, --help
Affiche l'aide.

(variable d'environnement : PIP_HELP)

--debug
Laisse les exceptions non gérées se propager en dehors de la sous-routine principale, au lieu de les enregistrer dans stderr.

(variable d'environnement : PIP_DEBUG)

--isolated
Exécute pip en mode isolé, ignorant les variables d'environnement et la configuration utilisateur.

(variable d'environnement : PIP_ISOLATED)

--require-virtualenv
Permet à pip de s'exécuter uniquement dans un environnement virtuel ; sinon, il se termine avec une erreur.

(variables d'environnement : PIP_REQUIRE_VIRTUALENV, PIP_REQUIRE_VENV)

--python <python>
Exécute pip avec l'interpréteur Python spécifié.

(variable d'environnement : PIP_PYTHON)

-v, --verbose
Donne plus de détails. L'option est additive et peut être utilisée jusqu'à 3 fois.

(variable d'environnement : PIP_VERBOSE)

-V, --version
Affiche la version et quitte.

(variable d'environnement : PIP_VERSION)

-q, --quiet
Donne moins de détails. L'option est additive et peut être utilisée jusqu'à 3 fois (correspondant aux niveaux de journalisation WARNING, ERROR et CRITICAL).

(variable d'environnement : PIP_QUIET)

--log <path>
Chemin vers un journal verbeux en mode ajout.

(variables d'environnement : PIP_LOG, PIP_LOG_FILE, PIP_LOCAL_LOG)

--no-input
Désactive la demande d'entrée.

(variable d'environnement : PIP_NO_INPUT)

--keyring-provider <keyring_provider>
Active la recherche d'identifiants via la bibliothèque keyring si l'entrée utilisateur est autorisée. Spécifie quel mécanisme utiliser [auto, disabled, import, subprocess]. (par défaut : auto)

(variable d'environnement : PIP_KEYRING_PROVIDER)

--proxy <proxy>
Spécifie un proxy sous la forme scheme://[user:passwd@]proxy.server:port.

(variable d'environnement : PIP_PROXY)

--retries <retries>
Nombre maximum de tentatives pour établir une nouvelle connexion HTTP. (par défaut : 5)

(variable d'environnement : PIP_RETRIES)

--timeout <sec>
Définit le délai d'attente de la socket (par défaut 15 secondes).

(variables d'environnement : PIP_TIMEOUT, PIP_DEFAULT_TIMEOUT)

--exists-action <action>
Action par défaut lorsqu'un chemin existe déjà : (s)witch, (i)gnore, (w)ipe, (b)ackup, (a)bort.

(variable d'environnement : PIP_EXISTS_ACTION)

--trusted-host <hostname>
Marque cet hôte ou cette paire hôte:port comme digne de confiance, même s'il n'a pas de HTTPS valide ou pas de HTTPS du tout.

(variable d'environnement : PIP_TRUSTED_HOST)

--cert <path>
Chemin vers le bundle de certificats CA encodé en PEM. S'il est fourni, il remplace la valeur par défaut. Voir 'SSL Certificate Verification' dans la documentation de pip pour plus d'informations.

(variable d'environnement : PIP_CERT)

--client-cert <path>
Chemin vers le certificat client SSL, un fichier unique contenant la clé privée et le certificat au format PEM.

(variable d'environnement : PIP_CLIENT_CERT)

--cache-dir <dir>
Stocke les données du cache dans <dir>.

(variable d'environnement : PIP_CACHE_DIR)

--no-cache-dir
Désactive le cache.

(variable d'environnement : PIP_NO_CACHE_DIR)

--disable-pip-version-check
Ne vérifie pas périodiquement PyPI pour déterminer si une nouvelle version de pip est disponible en téléchargement. Impliqué par --no-index.

(variable d'environnement : PIP_DISABLE_PIP_VERSION_CHECK)

--no-color
Supprime la sortie colorée.

(variable d'environnement : PIP_NO_COLOR)

--use-feature <feature>
Active de nouvelles fonctionnalités, potentiellement incompatibles avec les versions précédentes.

(variable d'environnement : PIP_USE_FEATURE)

--use-deprecated <feature>
Active des fonctionnalités dépréciées, qui seront supprimées dans le futur.

(variable d'environnement : PIP_USE_DEPRECATED)

--resume-retries <resume_retries>
Nombre maximum de tentatives pour reprendre ou redémarrer un téléchargement incomplet. (par défaut : 5)

(variable d'environnement : PIP_RESUME_RETRIES)

NOM

pip-check — Vérifie si tous les paquets pip installés sont à jour

DESCRIPTION

pip-check vérifie si tous les paquets pip installés sont à jour. Il vérifie si une nouvelle version de chaque paquet est disponible et liste tous les paquets obsolètes.

UTILISATION

pip-check [OPTIONS]

OPTIONS

Aucune option n'est disponible pour le moment.
