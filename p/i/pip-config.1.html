NOM

pip-config - description de la commande pip config

DESCRIPTION

Gérer la configuration locale et globale.

Sous-commandes :

  • list : Lister la configuration active (ou à partir du fichier spécifié)
  • edit : Modifier le fichier de configuration dans un éditeur
  • get : Obtenir la valeur associée à commande.option
  • set : Définir commande.option=valeur
  • unset : Supprimer la valeur associée à commande.option
  • debug : Lister les fichiers de configuration et les valeurs définies sous eux

Les clés de configuration doivent être séparées par des points (commande.nom_option), avec le préfixe spécial « global » affectant toute commande. Par exemple, « pip config set global.index-url https://example.org/ » configurera l'URL de l'index pour toutes les commandes, mais « pip config set download.timeout 10 » configurera un délai d'attente de 10 secondes uniquement pour les commandes « pip download ».

Si aucun des drapeaux --user, --global et --site n'est passé, un fichier de configuration d'environnement virtuel est utilisé s'il est actif et si le fichier existe. Sinon, toutes les modifications sont apportées au fichier utilisateur par défaut.

UTILISATION

python -m pip config [<option-fichier>] list
python -m pip config [<option-fichier>] [--editor <chemin-editeur>] edit
python -m pip config [<option-fichier>] get commande.option
python -m pip config [<option-fichier>] set commande.option valeur
python -m pip config [<option-fichier>] unset commande.option
python -m pip config [<option-fichier>] debug

OPTIONS

--editor <editeur>
Éditeur à utiliser pour modifier le fichier. Utilise les variables d'environnement VISUAL ou EDITOR si elles ne sont pas fournies.

(variable d'environnement : PIP_EDITOR)

--global
Utiliser uniquement le fichier de configuration système

(variable d'environnement : PIP_GLOBAL)

--user
Utiliser uniquement le fichier de configuration utilisateur

(variable d'environnement : PIP_USER)

--site
Utiliser uniquement le fichier de configuration de l'environnement actuel

(variable d'environnement : PIP_SITE)
