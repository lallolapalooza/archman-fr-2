NOM

pip-index - description de la commande pip index

DESCRIPTION

Inspecter les informations disponibles à partir des index de paquets.

UTILISATION

python -m pip index versions <paquet>

OPTIONS

--platform <plateforme>
Utiliser uniquement les wheels compatibles avec <plateforme>. Par défaut, utilise la plateforme du système en cours d'exécution. Utilisez cette option plusieurs fois pour spécifier plusieurs plateformes prises en charge par l'interpréteur cible.

(variable d'environnement : PIP_PLATFORM)

--python-version <version_python>
La version de l'interpréteur Python à utiliser pour les vérifications de compatibilité des wheels et de "Requires-Python". Par défaut, une version dérivée de l'interpréteur en cours d'exécution. La version peut être spécifiée en utilisant jusqu'à trois entiers séparés par des points (par exemple, "3" pour 3.0.0, "3.7" pour 3.7.0, ou "3.7.3"). Une version majeure-mineure peut également être donnée sous forme de chaîne sans points (par exemple, "37" pour 3.7.0).

(variable d'environnement : PIP_PYTHON_VERSION)

--implementation <implementation>
Utiliser uniquement les wheels compatibles avec l'implémentation Python <implementation>, par exemple 'pp', 'jy', 'cp', ou 'ip'. Si non spécifié, l'implémentation de l'interpréteur actuel est utilisée. Utilisez 'py' pour forcer les wheels indépendantes de l'implémentation.

(variable d'environnement : PIP_IMPLEMENTATION)

--abi <abi>
Utiliser uniquement les wheels compatibles avec l'abi Python <abi>, par exemple 'pypy_41'. Si non spécifié, l'étiquette abi de l'interpréteur actuel est utilisée. Utilisez cette option plusieurs fois pour spécifier plusieurs abis pris en charge par l'interpréteur cible. Généralement, vous devrez spécifier --implementation, --platform et --python-version lorsque vous utilisez cette option.

(variable d'environnement : PIP_ABI)

--ignore-requires-python
Ignorer les informations Requires-Python.

(variable d'environnement : PIP_IGNORE_REQUIRES_PYTHON)

--pre
Inclure les versions pré-release et de développement. Par défaut, pip ne trouve que les versions stables.

(variable d'environnement : PIP_PRE)

--json
Sortir les données dans un format JSON lisible par machine.

(variable d'environnement : PIP_JSON)

--no-binary <format_control>
Ne pas utiliser les paquets binaires. Peut être fourni plusieurs fois, et chaque fois s'ajoute à la valeur existante. Accepte soit ":all:" pour désactiver tous les paquets binaires, ":none:" pour vider l'ensemble (remarquez les deux points), soit un ou plusieurs noms de paquets séparés par des virgules (sans deux points). Notez que certains paquets sont difficiles à compiler et peuvent échouer à l'installation lorsque cette option leur est appliquée.

(variable d'environnement : PIP_NO_BINARY)

--only-binary <format_control>
Ne pas utiliser les paquets sources. Peut être fourni plusieurs fois, et chaque fois s'ajoute à la valeur existante. Accepte soit ":all:" pour désactiver tous les paquets sources, ":none:" pour vider l'ensemble, soit un ou plusieurs noms de paquets séparés par des virgules. Les paquets sans distributions binaires échoueront à l'installation lorsque cette option leur sera appliquée.

(variable d'environnement : PIP_ONLY_BINARY)
