NOM

pip-cache - description de la commande pip cache

DESCRIPTION

Inspecter et gérer le cache de roues de pip.

Sous-commandes :

  • dir : Afficher le répertoire du cache.
  • info : Afficher des informations sur le cache.
  • list : Lister les noms de fichiers des paquets stockés dans le cache.
  • remove : Supprimer un ou plusieurs paquets du cache.
  • purge : Supprimer tous les éléments du cache.

<pattern> peut être une expression glob ou un nom de paquet.

UTILISATION

python -m pip cache dir
python -m pip cache info
python -m pip cache list [<pattern>] [--format=[human, abspath]]
python -m pip cache remove <pattern>
python -m pip cache purge

OPTIONS

--format <list_format>
Sélectionne le format de sortie parmi : human (par défaut) ou abspath

(variable d'environnement : PIP_FORMAT)
