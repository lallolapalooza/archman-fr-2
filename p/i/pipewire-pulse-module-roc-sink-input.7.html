NOM

pipewire-pulse-module-roc-sink-input - Entrée de sink ROC

NOM DU MODULE

module-roc-sink-input

OPTIONS DU MODULE

  • sink: nom du sink
  • sink_input_properties: propriétés pour le sink_input
  • resampler_profile: empty>|high|medium|low
  • fec_code: empty>|disable|rs8m|ldpc
  • sess_latency_msec: latence réseau cible en millisecondes
  • local_ip: ip du récepteur local
  • local_source_port: port du récepteur local pour les paquets source
  • local_repair_port: port du récepteur local pour les paquets de réparation
  • local_control_port: port du récepteur local pour les paquets de contrôle
