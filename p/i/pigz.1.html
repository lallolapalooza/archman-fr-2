PIGZ(1) Manuel des commandes générales PIGZ(1)

NOM

pigz, unpigz - compresser ou décompresser des fichiers

SYNTAXE

pigz [ -cdfhikKlLmMnNqrRtz0..9,11 ] [ -b taille_bloc ] [ -p threads ] [ -S suffixe ] [ nom ... ]
unpigz [ -cfhikKlLmMnNqrRtz ] [ -b taille_bloc ] [ -p threads ] [ -S suffixe ] [ nom ... ]

DESCRIPTION

Pigz compresse en utilisant des threads pour tirer parti de plusieurs processeurs et cœurs. L'entrée est divisée en blocs de 128 Ko, chacun étant compressé en parallèle. La valeur de contrôle individuelle pour chaque bloc est également calculée en parallèle. Les données compressées sont écrites dans l'ordre sur la sortie, et une valeur de contrôle combinée est calculée à partir des valeurs de contrôle individuelles.

Le format des données compressées générées est en format gzip, zlib, ou zip à entrée unique utilisant la méthode de compression deflate. La compression produit des flux deflate bruts partiels qui sont concaténés par un seul thread d'écriture et enveloppés avec l'en-tête et le pied de page appropriés, où le pied de page contient la valeur de contrôle combinée.

Chaque flux deflate brut partiel est terminé par un bloc stocké vide (en utilisant l'option Z_SYNC_FLUSH de zlib), afin de terminer ce flux binaire partiel à une frontière d'octet. Cela permet aux flux partiels d'être simplement concaténés comme des séquences d'octets. Cela ajoute un très petit surcoût de quatre à cinq octets à la sortie pour chaque bloc d'entrée.

La taille par défaut du bloc d'entrée est de 128 Ko, mais peut être modifiée avec l'option -b. Le nombre de threads de compression est défini par défaut sur le nombre de processeurs en ligne, ce qui peut être modifié en utilisant l'option -p. Spécifier -p 1 évite totalement l'utilisation des threads.

Les blocs d'entrée, bien que compressés indépendamment, conservent les 32 Ko derniers du bloc précédent chargés comme dictionnaire prédéfini pour maintenir l'efficacité de compression de la décompression dans un seul thread. Ceci peut être désactivé en utilisant l'option -i ou --independent, de sorte que les blocs puissent être décompressés indépendamment pour une récupération d'erreurs partielle ou un accès aléatoire. Cela insère également un bloc vide supplémentaire pour marquer les blocs indépendants en les précédant de la séquence de neuf octets (en hexadécimal) : 00 00 FF FF 00 00 00 FF FF.

La décompression ne peut pas être parallélisée, du moins pas sans flux deflate spécialement préparés à cet effet. Par conséquent, pigz utilise un seul thread (le thread principal) pour la décompression, mais créera trois autres threads pour la lecture, l'écriture et le calcul des contrôles, ce qui peut accélérer la décompression dans certaines circonstances. La décompression parallèle peut être désactivée en spécifiant un processus ( -dp 1 ou -tp 1 ).

Toutes les options de la ligne de commande sont traitées avant le traitement des noms. Si aucun nom n'est fourni sur la ligne de commande, ou si "-" est donné comme nom (mais pas après "--"), alors l'entrée est prise depuis stdin. Si les variables d'environnement GZIP ou PIGZ sont définies, alors les options sont prises de leurs valeurs avant que toute option de la ligne de commande ne soit traitée, d'abord depuis GZIP, puis depuis PIGZ.

Les fichiers compressés peuvent être restaurés dans leur forme originale en utilisant pigz -d ou unpigz.

OPTIONS

-# --fast --best
Régule la vitesse de compression en utilisant le chiffre spécifié #, où -1 ou --fast indique la méthode de compression la plus rapide (moins de compression) et -9 ou --best indique la méthode de compression la plus lente (meilleure compression). -0 est aucune compression. -11 offre quelques pourcents de meilleure compression au prix d'une exécution plus lente, en utilisant l'algorithme zopfli de Jyrki Alakuijala. La valeur par défaut est -6.
-A --alias xxx
Utilise xxx comme nom pour toute entrée --zip depuis stdin (le nom par défaut est "-").
-b --blocksize mmm
Définit la taille du bloc de compression à mmmK (par défaut 128 Kio).
-c --stdout --to-stdout
Écrit toute la sortie traitée sur stdout (ne supprime pas).
-C --comment ccc
Inclut le commentaire fourni dans l'en-tête gzip ou l'en-tête de fichier central zip.
-d --decompress --uncompress
Décompresse l'entrée compressée.
-f --force
Forcer l'écrasement, compresser .gz, les liens, et vers le terminal.
-h --help
Affiche un écran d'aide et quitte.
-H --huffman
Compresse en utilisant la stratégie Huffman uniquement.
-i --independent
Compresse les blocs indépendamment pour la récupération des dommages.
-k --keep
Ne pas supprimer le fichier original après traitement.
-K --zip
Compresse au format PKWare zip (.zip) à entrée unique.
-l --list
Liste le contenu de l'entrée compressée.
-L --license
Affiche la licence de pigz et quitte.
-m --no-time
Ne pas enregistrer ou restaurer l'heure de modification. -Nm enregistrera ou restaurera le nom, mais pas l'heure de modification. Notez que l'ordre des options est important.
-M --time
Enregistrer ou restaurer l'heure de modification. -nM enregistrera ou restaurera l'heure de modification, mais pas le nom. Notez que l'ordre des options est important. Les heures de modification sont enregistrées uniquement pour les fichiers réguliers, pas pour les pipes.
-n --no-name
Ne pas enregistrer ou restaurer le nom du fichier ou l'heure de modification. C'est le comportement par défaut lors de la décompression. Lorsque le nom du fichier n'est pas restauré depuis l'en-tête, le nom du fichier compressé avec le suffixe retiré est le nom du fichier décompressé. Lorsque l'heure de modification n'est pas restaurée depuis l'en-tête, l'heure de modification du fichier compressé est utilisée (pas l'heure actuelle).
-N --name
Enregistrer ou restaurer à la fois le nom du fichier et l'heure de modification. C'est le comportement par défaut lors de la compression.
-p --processes n
Autoriser jusqu'à n processus (par défaut est le nombre de processeurs en ligne)
-q --quiet --silent
Ne pas afficher de messages, même en cas d'erreur.
-r --recursive
Traiter le contenu de tous les sous-répertoires.
-R --rsyncable
Emplacements des blocs déterminés par l'entrée pour rsync.
-S --suffix .sss
Utiliser le suffixe .sss au lieu de .gz (pour la compression).
-t --test
Tester l'intégrité de l'entrée compressée.
-U --rle
Compresser en utilisant la stratégie de codage par longueurs de séquences.
-v --verbose
Fournir une sortie plus détaillée.
-V --version
Afficher la version de pigz. -vV affiche également la version de zlib.
-z --zlib
Compresser au format zlib (.zz) au lieu de gzip.
--
Tous les arguments après "--" sont traités comme des noms de fichiers (pour les noms commençant par "-")
Ces options sont propres au niveau de compression -11 :
-F --first
Effectuer les itérations d'abord, avant la division en blocs (par défaut : dernières).
-I, --iterations n
Nombre d'itérations pour l'optimisation (par défaut 15).
-J, --maxsplits n
Nombre maximum de blocs divisés (par défaut 15).
-O --oneblock
Ne pas diviser en blocs plus petits (par défaut : division en blocs).

pigz(1) — pigz

NAME

pigz — Parallel gzip

SYNOPSIS

pigz [-d] [-k] [-c] [-f] [-n] [-q] [-r ratio] [-t threads] [-b blocksize] [-p processes] [-s level] [-S suffix] [-l] [-B level] [-o offset] [-e eos_offset] [-i i_offset] [-h h_offset] [-m m_offset] [-O only_store] [-a] [-v] [-V] [-‑help] [-‑version] [file ...]

DESCRIPTION

pigz is a parallel implementation of the gzip compression utility. It uses multiple threads to compress files faster by dividing the input data into blocks and compressing each block in parallel. The compressed output is compatible with standard gzip.

OPTIONS

The options for pigz are largely compatible with those of gzip. The following are the most common options:

-d, --decompress, --uncompress
Decompress.
-k, --keep-going
Keep files even if errors occur.
-c, --stdout, --to-stdout
Write output on standard output.
-f, --force
Overwrite existing output files.
-n, --no-name
Do not store or restore the original file name.
-q, --quiet
Suppress all messages.
-r ratio, --rsyncable ratio
Make output suitable for rsyncable compression. The ratio is the percentage of blocks to skip, from 0 to 99. The default is 0 (not rsyncable).
-t threads, --threads threads
Number of threads to use. Defaults to the number of available processors.
-b blocksize, --blocksize blocksize
Size of compression blocks in kibibytes. Default is 128 KiB.
-p processes, --processes processes
Number of processes to use. Defaults to the number of available processors.
-s level, --fast level
Compression level for speed. From 1 to 9.
-S suffix, --suffix suffix
Use suffix for compressed files. Default is .gz.
-l, --list
List contents of compressed file.
-B level, --best level
Compression level for best compression. From 1 to 9.
-o offset, --offset offset
Seek offset for decompression.
-e eos_offset, --eos-offset eos_offset
Seek offset for end of stream for decompression.
-i i_offset, --index-offset i_offset
Seek offset for index for decompression.
-h h_offset, --header-offset h_offset
Seek offset for header for decompression.
-m m_offset, --marker-offset m_offset
Seek offset for marker for decompression.
-O only_store, --only-store only_store
Only store blocks given by offset.
-a, --adapt
Adapt compression level to input data.
-v, --verbose
Verbosity level.
-V, --version
Print version number and exit.
--help
Display help text and exit.
--version
Display version number and exit.
