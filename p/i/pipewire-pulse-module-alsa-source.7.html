NOM

pipewire-pulse-module-alsa-source - Source ALSA

NOM DU MODULE

module-alsa-source

OPTIONS DU MODULE

  • nom : nom de la source, à préfixer
  • source_nom : nom pour la source
  • source_propriétés : propriétés pour la source
  • namereg_fail : si faux, tente de synthétiser un nouveau source_nom s'il est déjà pris
  • périphérique : périphérique ALSA
  • périphérique_id : index de la carte ALSA
  • format : format d'échantillon
  • taux : taux d'échantillonnage
  • taux_alternatif : taux d'échantillonnage alternatif
  • canaux : nombre de canaux
  • carte_canaux : carte des canaux
  • fragments : nombre de fragments
  • taille_fragment : taille du fragment
  • mmap : activer la mise en mémoire ?
  • tsched : activer le mode de planification basé sur le timer système ?
  • tsched_taille_tampon : taille du tampon en mode planification par timer
  • tsched_seuil_tampon : seuil inférieur de remplissage
  • contrôle : nom du contrôle du mélangeur, ou nom et index séparés par une virgule
  • rewind_safeguard : nombre d'octets qui ne peuvent pas être rebobinés
  • volume_différé : synchroniser les changements de volume logiciel et matériel pour éviter les sauts momentanés ?
  • marge_sécurité_volume_différé : ajustement en microsecondes en fonction de la direction du volume
  • retard_supplémentaire_volume_différé : ajustement en microsecondes des changements de volume matériel
  • plage_latence_fixe : désactiver les changements de plage de latence en cas d'underrun ?
