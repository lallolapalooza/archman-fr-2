NOM

pi_stress - un test de stress pour les mutex POSIX à héritage de priorité

SYNOPSIS

pi_stress [-d|--debug] [-D|--duration [-g|--groups N] [-i|--inversions INV] [--json FICHIER] [-m|--mlockall] [-p|--prompt] [-q|--quiet] [-r|--rr] [-s|--sched OPTS] [-u|--uniprocessor] [-v|--verbose] [-V|--version]

DESCRIPTION

pi_stress est un programme utilisé pour tester les chemins de code d'héritage de priorité pour les mutex POSIX, à la fois dans le noyau Linux et dans la bibliothèque C. Il s'exécute en tant que tâche à priorité temps réel et lance des groupes de threads d'inversion de priorité. Chaque groupe d'inversion provoque une condition d' inversion de priorité qui se bloquerait si l'héritage de priorité ne fonctionnait pas.

OPTIONS

-d|--debug
Exécuter en mode débogage ; nombreux messages supplémentaires
-D TEMPS, --duration=TEMPS
Spécifier une durée pour l'exécution du test.
Ajouter 'm', 'h' ou 'd' pour spécifier des minutes, des heures ou des jours.
-g N|--groups=N
Le nombre de groupes d'inversion à exécuter. La valeur par défaut est 10.
-h|--help
Afficher un court message d'aide et les options.
-i N|--inversions=N
N nombre de conditions d'inversion. C'est le nombre total d'inversions pour tous les groupes d'inversion. La valeur par défaut est -1 pour infini.
--json=FICHIER
Écrire les résultats finaux dans FICHIER, format JSON.
-m|--mlockall
Appeler mlockall pour verrouiller les allocations mémoire actuelles et futures et empêcher le pagination.
-p|--prompt
Demander une confirmation avant de lancer le test de stress.
-q|--quiet
Supprimer la sortie en cours d'exécution.
-r|--rr
Exécuter les threads des groupes d'inversion en mode SCHED_RR (round-robin). Par défaut, les threads d'inversion sont exécutés en mode SCHED_FIFO.
-s OPTS|--sched OPTS
options de planification par type de thread :
id=[high|med|low],
policy=[fifo,rr],priority=N,
policy=deadline,runtime=N,deadline=N,period=N
-u|--uniprocessor
Exécuter tous les threads sur un seul processeur. Par défaut, tous les threads des groupes d'inversion sont exécutés sur un processeur et les threads d'administration (thread de rapport, lecteur de clavier, etc.) sur un autre processeur.
-v|--verbose
Exécuter avec des messages détaillés.
-V|--version
Afficher le numéro de version.

CAVEATS

Les threads de test pi_stress s'exécutent en tant que threads SCHED_FIFO ou SCHED_RR, ce qui signifie qu'ils peuvent affamer les threads système critiques. Il est conseillé de changer la politique de planification des threads système critiques en SCHED_FIFO avant d'exécuter pi_stress et d'utiliser une priorité de 10 ou plus, afin d'éviter que ces threads ne soient affamés par le test de stress.
