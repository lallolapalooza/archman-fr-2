PICONV(1perl) Guide de référence pour programmeurs Perl PICONV(1perl)

NOM

piconv -- iconv(1), réinventé en perl

SYNTAXE

piconv [-f encodage_source] [-t encodage_destination]
       [-p|--perlqq|--htmlcref|--xmlcref] [-C N|-c] [-D] [-S schéma]
       [-s chaîne|fichier...]
piconv -l
piconv -r alias_encodage
piconv -h

DESCRIPTION

piconv est la version perl de iconv, un convertisseur d'encodage de caractères largement disponible sur divers systèmes Unix aujourd'hui. Ce script était principalement une démonstration technologique pour Perl 5.8.0, mais vous pouvez utiliser piconv à la place d'iconv dans pratiquement tous les cas.

piconv convertit l'encodage des caractères de STDIN ou des fichiers spécifiés dans l'argument et imprime le résultat sur STDOUT.

Voici la liste des options. Certaines options peuvent être au format court (-f) ou long (--from).

-f,--from encodage_source
Spécifie l'encodage à partir duquel convertir. Contrairement à iconv, cette option peut être omise. Dans ce cas, le locale courant est utilisé.
-t,--to encodage_destination
Spécifie l'encodage vers lequel convertir. Contrairement à iconv, cette option peut être omise. Dans ce cas, le locale courant est utilisé.

Par conséquent, lorsque -f et -t sont tous deux omis, piconv agit comme cat.

-s,--string chaîne
Utilise chaîne au lieu d'un fichier comme source de texte.
-l,--list
Liste tous les encodages disponibles, un par ligne, par ordre insensible à la casse. Notez que seuls les noms canoniques sont listés ; de nombreux alias existent. Par exemple, les noms sont insensibles à la casse, et de nombreux alias standard et courants fonctionnent, tels que "latin1" pour "ISO-8859-1", ou "ibm850" au lieu de "cp850", ou "winlatin1" pour "cp1252". Voir Encode::Supported pour une discussion complète.
-r,--resolve alias_encodage
Résout alias_encodage en nom d'encodage canonique d'Encode.
-C,--check N
Vérifie la validité du flux si N = 1. Lorsque N = -1, quelque chose d'intéressant se produit lorsqu'un caractère invalide est rencontré.
-c
Identique à "-C 1".
-p,--perlqq
Translittère les caractères manquants dans l'encodage en \x{HHHH} où HHHH est le point de code Unicode hexadécimal.
--htmlcref
Translittère les caractères manquants dans l'encodage en &#NNN; où NNN est le point de code Unicode décimal.
--xmlcref
Translittère les caractères manquants dans l'encodage en &#xHHHH; où HHHH est le point de code Unicode hexadécimal.
-h,--help
Affiche l'aide.
-D,--debug
Invoque le mode de débogage. Principalement pour les hackers d'Encode.
-S,--scheme schéma
Sélectionne le schéma à utiliser pour la conversion. Les schémas disponibles sont les suivants :
from_to
Utilise Encode::from_to pour la conversion. C'est le comportement par défaut.
decode_encode
Les chaînes d'entrée sont decode()ées puis encode()ées. Une implémentation simple en deux étapes.
perlio
La nouvelle couche perlIO est utilisée. La préférée de NI-S.

Vous devriez utiliser cette option si vous utilisez UTF-16 et d'autres formats où le saut de ligne n'est pas $/.

Comme l'option -D, celle-ci est également destinée aux hackers d'Encode.
