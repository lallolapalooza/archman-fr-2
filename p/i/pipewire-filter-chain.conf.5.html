NOM

pipewire-filter-chain.conf - filter-chain.conf

DESCRIPTION

Configuration d'exemple de PipeWire pour l'exécution de filtres audio.

SYNTAXE

$XDG_CONFIG_HOME/pipewire/filter-chain.conf

/etc/pipewire/filter-chain.conf

/usr/share/pipewire/filter-chain.conf

/usr/share/pipewire/filter-chain.conf.d/

/etc/pipewire/filter-chain.conf.d/

$XDG_CONFIG_HOME/pipewire/filter-chain.conf.d/

DESCRIPTION

Lorsque pipewire(1) est exécuté en utilisant ce fichier de configuration, pipewire -c filter-chain.conf, il démarre une application client PipeWire qui publie des nœuds appliquant divers filtres audio à leur entrée.

C'est une application client PipeWire à tous égards.

Les fichiers de configuration "drop-in" filter-chain.conf.d/*.conf peuvent être utilisés pour modifier la configuration des filtres, voir pipewire.conf(5). Certains exemples se trouvent dans /usr/share/pipewire/filter-chain/

AUTEURS

Les développeurs de PipeWire https://gitlab.freedesktop.org/pipewire/pipewire/issues; PipeWire est disponible sur https://pipewire.org

VOIR AUSSI

pipewire(1), pipewire.conf(5)
