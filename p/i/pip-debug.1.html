NOM

pip-debug - description de la commande pip debug

DESCRIPTION

Affiche les informations de débogage.

UTILISATION

python -m pip debug <options>

Attention :

Cette commande est uniquement destinée au débogage. Ses options et ses sorties sont provisoires et peuvent être modifiées sans préavis.

OPTIONS

--platform <plateforme>
N'utiliser que les roues compatibles avec <plateforme>. La valeur par défaut est la plateforme du système en cours d'exécution. Utiliser cette option plusieurs fois pour spécifier plusieurs plateformes supportées par l'interpréteur cible.

(variable d'environnement : PIP_PLATFORM)

--python-version <version_python>
La version de l'interpréteur Python à utiliser pour les roues et les vérifications de compatibilité "Requires-Python". La valeur par défaut est une version dérivée de l'interpréteur en cours d'exécution. La version peut être spécifiée en utilisant jusqu'à trois entiers séparés par des points (par exemple, "3" pour 3.0.0, "3.7" pour 3.7.0, ou "3.7.3"). Une version majeure-mineure peut également être donnée sous forme de chaîne sans points (par exemple, "37" pour 3.7.0).

(variable d'environnement : PIP_PYTHON_VERSION)

--implementation <implementation>
N'utiliser que les roues compatibles avec l'implémentation Python <implementation>, par exemple 'pp', 'jy', 'cp', ou 'ip'. Si elle n'est pas spécifiée, alors l'implémentation de l'interpréteur actuel est utilisée. Utiliser 'py' pour forcer les roues indépendantes de l'implémentation.

(variable d'environnement : PIP_IMPLEMENTATION)

--abi <abi>
N'utiliser que les roues compatibles avec l'abi Python <abi>, par exemple 'pypy_41'. Si elle n'est pas spécifiée, alors l'étiquette abi de l'interpréteur actuel est utilisée. Utiliser cette option plusieurs fois pour spécifier plusieurs abis supportées par l'interpréteur cible. Généralement, vous devrez spécifier --implementation, --platform et --python-version lorsque vous utilisez cette option.

(variable d'environnement : PIP_ABI)
