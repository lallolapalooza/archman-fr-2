NOM

pip-uninstall - description de la commande pip uninstall

DESCRIPTION

Désinstalle des paquets.

pip peut désinstaller la plupart des paquets installés. Les exceptions connues sont :

  • Les paquets purement distutils installés avec python setup.py install, qui ne laissent aucun métadonnées permettant de déterminer quels fichiers ont été installés.
  • Les wrappers de script installés par python setup.py develop.

UTILISATION

python -m pip uninstall [options] <paquet> ...
python -m pip uninstall [options] -r <fichier_requirements> ...

OPTIONS

-r, --requirement <fichier>
Désinstalle tous les paquets listés dans le fichier de requirements spécifié. Cette option peut être utilisée plusieurs fois.

(variable d'environnement : PIP_REQUIREMENT)

-y, --yes
Ne demande pas de confirmation pour la suppression des désinstallations.

(variable d'environnement : PIP_YES)

--root-user-action <action_utilisateur_root>
Action si pip est exécuté en tant qu'utilisateur root [warn, ignore] (par défaut : warn)

(variable d'environnement : PIP_ROOT_USER_ACTION)

--break-system-packages
Permet à pip de modifier une installation Python EXTERNALLY-MANAGED (gérée de l'extérieur)

(variable d'environnement : PIP_BREAK_SYSTEM_PACKAGES)
