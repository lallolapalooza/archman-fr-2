NOM

pip-help - description de la commande d'aide de pip

DESCRIPTION

Affiche l'aide pour les commandes.

UTILISATION

python -m pip help <commande>

OPTIONS

-h, --help
Affiche l'aide.

(variable d'environnement : PIP_HELP)

--debug
Laisse les exceptions non gérées se propager en dehors de la sous-routine principale, au lieu de les enregistrer dans stderr.

(variable d'environnement : PIP_DEBUG)

--isolated
Exécute pip en mode isolé, ignorant les variables d'environnement et la configuration utilisateur.

(variable d'environnement : PIP_ISOLATED)

--require-virtualenv
Permet à pip de ne s'exécuter que dans un environnement virtuel ; sinon, il se termine avec une erreur.

(variables d'environnement : PIP_REQUIRE_VIRTUALENV, PIP_REQUIRE_VENV)

--python <python>
Exécute pip avec l'interpréteur Python spécifié.

(variable d'environnement : PIP_PYTHON)

-v, --verbose
Donne plus d'informations. L'option est cumulative et peut être utilisée jusqu'à 3 fois.

(variable d'environnement : PIP_VERBOSE)

-V, --version
Affiche la version et quitte.

(variable d'environnement : PIP_VERSION)

-q, --quiet
Donne moins d'informations. L'option est cumulative et peut être utilisée jusqu'à 3 fois (correspondant aux niveaux de journalisation WARNING, ERROR et CRITICAL).

(variable d'environnement : PIP_QUIET)

--log <chemin>
Chemin vers un journal détaillé en mode ajout.

(variables d'environnement : PIP_LOG, PIP_LOG_FILE, PIP_LOCAL_LOG)

--no-input
Désactive la demande de saisie.

(variable d'environnement : PIP_NO_INPUT)

--keyring-provider <fournisseur_keyring>
Active la recherche d'identifiants via la bibliothèque keyring si la saisie utilisateur est autorisée. Spécifie quel mécanisme utiliser [auto, désactivé, importer, sous-processus]. (par défaut : auto)

(variable d'environnement : PIP_KEYRING_PROVIDER)

--proxy <proxy>
Spécifie un proxy sous la forme scheme://[user:motdepasse@]serveur_proxy:port.

(variable d'environnement : PIP_PROXY)

--retries <tentatives>
Nombre maximal de tentatives pour établir une nouvelle connexion HTTP. (par défaut : 5)

(variable d'environnement : PIP_RETRIES)

--timeout <sec>
Définit le délai d'attente des sockets (par défaut 15 secondes).

(variables d'environnement : PIP_TIMEOUT, PIP_DEFAULT_TIMEOUT)

--exists-action <action>
Action par défaut lorsqu'un chemin existe déjà : (s)witch, (i)gnore, (w)ipe, (b)ackup, (a)bort.

(variable d'environnement : PIP_EXISTS_ACTION)

--trusted-host <nom_hote>
Marque cet hôte ou cette paire hôte:port comme fiable, même s'il n'a pas de HTTPS valide ou aucun HTTPS.

(variable d'environnement : PIP_TRUSTED_HOST)

--cert <chemin>
Chemin vers un paquet de certificats d'autorité de certification codé en PEM. S'il est fourni, remplace la valeur par défaut. Voir 'Vérification des certificats SSL' dans la documentation de pip pour plus d'informations.

(variable d'environnement : PIP_CERT)

--client-cert <chemin>
Chemin vers un certificat client SSL, un fichier unique contenant la clé privée et le certificat au format PEM.

(variable d'environnement : PIP_CLIENT_CERT)

--cache-dir <repertoire>
Stocke les données du cache dans <repertoire>.

(variable d'environnement : PIP_CACHE_DIR)

--no-cache-dir
Désactive le cache.

(variable d'environnement : PIP_NO_CACHE_DIR)

--disable-pip-version-check
Ne vérifie pas périodiquement PyPI pour déterminer si une nouvelle version de pip est disponible en téléchargement. Implicite avec --no-index.

(variable d'environnement : PIP_DISABLE_PIP_VERSION_CHECK)

--no-color
Supprime la sortie colorée.

(variable d'environnement : PIP_NO_COLOR)

--use-feature <fonctionnalite>
Active de nouvelles fonctionnalités qui pourraient être rétrocompatibles.

(variable d'environnement : PIP_USE_FEATURE)

--use-deprecated <fonctionnalite>
Active des fonctionnalités obsolètes qui seront supprimées à l'avenir.

(variable d'environnement : PIP_USE_DEPRECATED)

--resume-retries <resume_retries>
Nombre maximal de tentatives pour reprendre ou redémarrer un téléchargement incomplet. (par défaut : 5)

(variable d'environnement : PIP_RESUME_RETRIES)
