PIDSTAT(1) Manuel de l'utilisateur Linux PIDSTAT(1)

NOM

pidstat - Rapporte les statistiques pour les tâches Linux.

SYNTAXE

pidstat [ -d ] [ -H ] [ -h ] [ -I ] [ -l ] [ -R ] [ -r ] [ -s ] [ -t ] [ -U [ nomutilisateur ] ] [ -u ] [ -V ] [ -v ] [ -w ] [ -C comm ] [ -G nomprocessus ] [ --dec={ 0 | 1 | 2 } ] [ --human ] [ -o JSON ] [ -p { pid[,...] | SELF | ALL } ] [ -T { TASK | CHILD | ALL } ] [ intervalle [ compte ] ] [ -e programme args ]

DESCRIPTION

La commande pidstat est utilisée pour surveiller les tâches individuelles actuellement gérées par le noyau Linux. Elle écrit sur la sortie standard les activités pour chaque tâche sélectionnée avec l'option -p ou pour chaque tâche gérée par le noyau Linux si l'option -p ALL a été utilisée. Ne pas sélectionner de tâches est équivalent à spécifier -p ALL, mais seules les tâches actives (tâches avec des valeurs de statistiques non nulles) apparaîtront dans le rapport.

La commande pidstat peut également être utilisée pour surveiller les processus fils des tâches sélectionnées. Lisez l'option -T ci-dessous.

Le paramètre intervalle spécifie la durée en secondes entre chaque rapport. Une valeur de 0 (ou aucun paramètre) indique que les statistiques des tâches doivent être rapportées depuis le démarrage du système (boot). Le paramètre compte peut être spécifié en conjonction avec le paramètre intervalle si ce dernier n'est pas réglé à zéro. La valeur de compte détermine le nombre de rapports générés à intervalle secondes d'intervalle. Si le paramètre intervalle est spécifié sans le paramètre compte, la commande pidstat génère des rapports en continu.

Vous pouvez sélectionner des informations sur des activités de tâche spécifiques en utilisant des drapeaux. Ne pas spécifier de drapeaux sélectionne uniquement l'activité CPU.

OPTIONS

-C comm
Affiche uniquement les tâches dont le nom de commande inclut la chaîne comm. Cette chaîne peut être une expression régulière.
-d
Rapporte les statistiques d'E/S (noyaux 2.6.20 et ultérieurs uniquement). Les valeurs suivantes peuvent être affichées :
UID
Le numéro d'identification utilisateur réel de la tâche surveillée.
UTILISATEUR
Le nom de l'utilisateur réel propriétaire de la tâche surveillée.
PID
Le numéro d'identification de la tâche surveillée.
Ko_rd/s
Nombre de kibioctets que la tâche a provoqués à lire du disque par seconde.
Ko_wr/s
Nombre de kibioctets que la tâche a provoqués, ou provoquera, à écrire sur le disque par seconde.
Ko_ccwr/s
Nombre de kibioctets dont l'écriture sur disque a été annulée par la tâche. Cela peut se produire lorsque la tâche tronque une page cache sale. Dans ce cas, certaines E/S dont une autre tâche était responsable ne se produiront pas.
retardE_S
Retard d'E/S disque de la tâche surveillée, mesuré en ticks d'horloge. Cette métrique inclut les retards passés à attendre la complétion des E/S disque synchronisées et la complétion des E/S de swap.
Commande
Le nom de commande de la tâche.
--dec={ 0 | 1 | 2 }
Spécifie le nombre de décimales à utiliser (de 0 à 2, la valeur par défaut est 2).
-e programme args
Exécute programme avec les arguments donnés args et le surveille avec pidstat. pidstat s'arrête lorsque programme se termine. Une valeur non nulle doit être spécifiée pour le paramètre intervalle.
-G nomprocessus
Affiche uniquement les processus dont le nom de commande inclut la chaîne nomprocessus. Cette chaîne peut être une expression régulière. Si l'option -t est utilisée conjointement avec l'option -G, les threads appartenant à ce processus sont également affichés (même si leur nom de commande n'inclut pas la chaîne nomprocessus).
-H
Affiche l'horodatage en secondes depuis l'époque.
-h
Affiche toutes les activités horizontalement sur une seule ligne, sans statistiques moyennes à la fin du rapport. Ceci est destiné à faciliter l'analyse par d'autres programmes.
--human
Affiche les tailles dans un format lisible par l'homme (par exemple, 1.0k, 1.2M, etc.). Les unités affichées avec cette option remplacent toutes les autres unités par défaut (par exemple, kibioctets, secteurs...) associées aux métriques.
-I
Dans un environnement SMP, indique que l'utilisation CPU des tâches (telle qu'affichée par l'option -u) doit être divisée par le nombre total de processeurs.
-l
Affiche le nom de commande du processus et tous ses arguments.
-o JSON
Affiche les statistiques au format JSON (JavaScript Object Notation). L'ordre des champs de sortie JSON n'est pas garanti, et de nouveaux champs peuvent être ajoutés à l'avenir.
-p { pid[,...] | SELF | ALL }
Sélectionne les tâches (processus) pour lesquelles les statistiques doivent être rapportées. pid est le numéro d'identification du processus. Le mot-clé SELF indique que les statistiques doivent être rapportées pour le processus pidstat lui-même, tandis que le mot-clé ALL indique que les statistiques doivent être rapportées pour toutes les tâches gérées par le système.
-R
Rapporte la priorité temps réel et les informations sur la politique d'ordonnancement. Les valeurs suivantes peuvent être affichées :
UID
Le numéro d'identification utilisateur réel de la tâche surveillée.
UTILISATEUR
Le nom de l'utilisateur réel propriétaire de la tâche surveillée.
PID
Le numéro d'identification de la tâche surveillée.
prio
La priorité temps réel de la tâche surveillée.
politique
La politique d'ordonnancement de la tâche surveillée.
Commande
Le nom de commande de la tâche.
-r
Rapporte les défauts de page et l'utilisation de la mémoire.

Lors du rapport des statistiques pour des tâches individuelles, les valeurs suivantes peuvent être affichées :

UID
Le numéro d'identification utilisateur réel de la tâche surveillée.
UTILISATEUR
Le nom de l'utilisateur réel propriétaire de la tâche surveillée.
PID
Le numéro d'identification de la tâche surveillée.
minflt/s
Nombre total de défauts mineurs que la tâche a générés par seconde, ceux qui n'ont pas nécessité le chargement d'une page mémoire depuis le disque.
majflt/s
Nombre total de défauts majeurs que la tâche a générés par seconde, ceux qui ont nécessité le chargement d'une page mémoire depuis le disque.
VSZ
Taille Virtuelle : L'utilisation de la mémoire virtuelle de la tâche entière en kibioctets.
RSS
Taille Résidente : La mémoire physique non échangée utilisée par la tâche en kibioctets.
%MEM">%MEM
La part de la mémoire physique disponible actuellement utilisée par la tâche.
Commande
Le nom de commande de la tâche.
Lors du rapport des statistiques globales pour les tâches et tous leurs enfants, les valeurs suivantes peuvent être affichées :
UID
Le numéro d'identification utilisateur réel de la tâche surveillée.
UTILISATEUR
Le nom de l'utilisateur réel propriétaire de la tâche surveillée.
PID
Le numéro d'identification de la tâche surveillée.
minflt/s
Nombre total de défauts mineurs des enfants de la tâche par seconde.
majflt/s
Nombre total de défauts majeurs des enfants de la tâche par seconde.
VSZ
Taille Virtuelle : L'utilisation de la mémoire virtuelle des enfants de la tâche entière en kibioctets.
RSS
Taille Résidente : La mémoire physique non échangée utilisée par les enfants de la tâche en kibioctets.
%MEM~2">%MEM
La part de la mémoire physique disponible actuellement utilisée par les enfants de la tâche.
Commande
Le nom de commande de la tâche.
-s
Affiche les statistiques de swap. Les valeurs suivantes peuvent être affichées :
UID
Le numéro d'identification utilisateur réel de la tâche surveillée.
UTILISATEUR
Le nom de l'utilisateur réel propriétaire de la tâche surveillée.
PID
Le numéro d'identification de la tâche surveillée.
SI
Nombre de kibibytes qui ont été swapés par seconde.
SO
Nombre de kibibytes qui ont été swapés en par seconde.
voir
Nombre de kibibytes qui sont actuellement dans le swap par seconde.
Commande
Le nom de commande de la tâche.
-T { TASK | CHILD | ALL }
Indique si les statistiques des fils d'exécution (threads) doivent être affichées. Par défaut, pidstat ne rapporte que les statistiques des processus. L'option -t permet de visualiser les fils d'exécution.

L'option -T permet de sélectionner les tâches pour lesquelles les statistiques doivent être rapportées. Les valeurs possibles sont :

TASK
Rapporte les statistiques pour les tâches spécifiées (par défaut).
CHILD
Rapporte les statistiques pour les processus fils des tâches spécifiées.
ALL
Rapporte les statistiques pour les tâches spécifiées et tous leurs processus fils.
-t
Rapporte les statistiques pour chaque fils d'exécution (thread) de chaque processus. L'activité CPU des fils d'exécution est affichée en pourcentage de l'activité CPU de leur processus parent.
-U [ nomutilisateur ]
Rapporte les statistiques d'utilisation CPU des tâches appartenant à un utilisateur donné. Si aucun nom d'utilisateur n'est spécifié, les statistiques sont rapportées pour tous les utilisateurs.
-u
Rapporte les statistiques d'utilisation CPU. Les valeurs suivantes peuvent être affichées :
UID
Le numéro d'identification utilisateur réel de la tâche surveillée.
UTILISATEUR
Le nom de l'utilisateur réel propriétaire de la tâche surveillée.
PID
Le numéro d'identification de la tâche surveillée.
%PERCPU
Pourcentage du temps CPU qu'une tâche a passé dans chaque état. Les états sont : utilisateur (%user), système (%system), steale (%stolen), invité (%guest) et invité volé (%gnice).
C+ICU
Le temps CPU total passé par la tâche dans les états utilisateur et système, ou temps CPU total passé par la tâche dans les états invité et invité verbeux.
CPU
Le processeur sur lequel la tâche est en cours d'exécution.
Commande
Le nom de commande de la tâche.
-V
Affiche les informations de version et quitte.
-v
Rapporte les informations sur les descripteurs de fichiers et les statuts des processus. Les valeurs suivantes peuvent être affichées :
UID
Le numéro d'identification utilisateur réel de la tâche surveillée.
UTILISATEUR
Le nom de l'utilisateur réel propriétaire de la tâche surveillée.
PID
Le numéro d'identification de la tâche surveillée.
Threads
Nombre de fils d'exécution appartenant à la tâche.
FR
Nombre de descripteurs de fichiers ouverts par la tâche.
FDsize
Le nombre maximal de descripteurs de fichiers que la tâche est autorisée à ouvrir.
runnable
Nombre de tâches dans l'état "runnable".
running
Nombre de tâches dans l'état "running".
blocked
Nombre de tâches dans l'état "blocked" (bloqué).
Commande
Le nom de commande de la tâche.
-w
Rapporte les statistiques de changement de contexte. Les valeurs suivantes peuvent être affichées :
UID
Le numéro d'identification utilisateur réel de la tâche surveillée.
UTILISATEUR
Le nom de l'utilisateur réel propriétaire de la tâche surveillée.
PID
Le numéro d'identification de la tâche surveillée.
cswch/s
Nombre de changements de contexte volontaires que la tâche a effectués par seconde.
nvcswch/s
Nombre de changements de contexte involontaires que la tâche a effectués par seconde.
Commande
Le nom de commande de la tâche.

EXEMPLES

Afficher l'utilisation CPU de tous les processus toutes les 5 secondes :
pidstat 5
Afficher l'utilisation CPU et mémoire de tous les processus toutes les 10 secondes :
pidstat -u -r 10
Afficher l'utilisation CPU, mémoire et E/S du processus avec le PID 1234, 3 fois toutes les 2 secondes :
pidstat -ur -p 1234 2 3
Afficher l'utilisation CPU, mémoire et E/S de tous les processus, y compris les fils d'exécution, toutes les secondes :
pidstat -tur 1
Afficher l'utilisation CPU de tous les processus appartenant à l'utilisateur 'john', toutes les 5 secondes :
pidstat -u -U john 5
Exécuter le programme 'my_script.sh' et surveiller son utilisation CPU, mémoire et E/S pendant son exécution :
pidstat -ur -e ./my_script.sh arg1 arg2

ENVIRONNEMENT

La commande pidstat prend en compte les variables d'environnement suivantes :

S_COLORS
Par défaut, les statistiques sont affichées en couleur lorsque la sortie est connectée à un terminal. Utilisez cette variable pour modifier les paramètres. Les valeurs possibles pour cette variable sont never, always ou auto (cette dernière est équivalente aux paramètres par défaut).
Veuillez noter que la couleur (rouge, jaune ou une autre couleur) utilisée pour afficher une valeur n'indique aucun problème simplement en raison de la couleur. Elle indique seulement différentes plages de valeurs.
S_COLORS_SGR
Spécifie les couleurs et autres attributs utilisés pour afficher les statistiques sur le terminal. Sa valeur est une liste de capacités séparées par des deux-points, qui par défaut est I=32;22:N=34;1:W=35;1:X=31;1:Z=34;22. Les capacités prises en charge sont :
I=
Sous-chaîne SGR (Select Graphic Rendition) pour les valeurs d'éléments comme PID, UID ou numéro de processeur.
N=
Sous-chaîne SGR pour les valeurs statistiques non nulles et pour les noms de tâches.
W= (ou M=)
Sous-chaîne SGR pour les valeurs en pourcentage comprises entre 75 % et 90 % (ou comprises entre 10 % et 25 % selon la signification de la métrique).
X= (ou H=)
Sous-chaîne SGR pour les valeurs en pourcentage supérieures ou égales à 90 % (ou inférieures ou égales à 10 % selon le métr
ric's meaning).
Z=
Chaîne SGR pour les valeurs nulles et pour les noms de threads.
S_TIME_FORMAT
Si cette variable existe et que sa valeur est ISO, la locale actuelle sera ignorée lors de l'impression de la date dans l'en-tête du rapport. La commande pidstat utilisera le format ISO 8601 (AAAA-MM-JJ) à la place. L'horodatage sera également conforme au format ISO 8601.

EXEMPLES

pidstat 2 5
Affiche cinq rapports de statistiques CPU pour chaque tâche active du système toutes les deux secondes.
pidstat -r -p 1643 2 5
Affiche cinq rapports de fautes de page et de statistiques mémoire pour le PID 1643 toutes les deux secondes.
pidstat -C "fox|bird" -r -p ALL
Affiche les fautes de page globales et les statistiques mémoire pour tous les processus dont le nom de commande inclut la chaîne "fox" ou "bird".
pidstat -T CHILD -r 2 5
Affiche cinq rapports de statistiques de fautes de page toutes les deux secondes pour les processus enfants de toutes les tâches du système. Seuls les processus enfants avec des valeurs de statistiques non nulles sont affichés.

BOGUES

Le système de fichiers /proc doit être monté pour que la commande pidstat fonctionne.

Bien que pidstat affiche des unités correspondant à des kilooctets (kB), mégaoctets (MB)..., il utilise en réalité des kibioctets (kiB), mébioctets (MiB)... Un kibioctet est égal à 1024 octets, et un mébioctet est égal à 1024 kibioctets.

FICHIERS

/proc contient divers fichiers avec des statistiques système.
