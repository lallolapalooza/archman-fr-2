NOM

pipewire-pulse-module-simple-protocol-tcp - Protocole TCP simple

NOM DU MODULE

module-simple-protocol-tcp

OPTIONS DU MODULE

  • rate: fréquence d'échantillonnage
  • format: format d'échantillonnage
  • channels: nombre de canaux
  • channel_map: nombre de canaux
  • sink: récepteur auquel se connecter
  • source: source à laquelle se connecter
  • playback: activer la lecture ?
  • record: activer l'enregistrement ?
  • port: numéro de port TCP
  • listen: adresse sur laquelle écouter
