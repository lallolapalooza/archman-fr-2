PIDOF(1) Manuel des commandes générales PIDOF(1)

NOM

pidof - trouver l'ID de processus d'un programme en cours d'exécution

SYNTAXE

pidof [-s] [-c] [-q] [-w] [-x] [-o omitpid[,...]] ... [-t] [-S séparateur] programme ...

DESCRIPTION

Pidof trouve les identifiants de processus (pid) des programmes nommés. Il imprime ces identifiants sur la sortie standard.

OPTIONS

-s
Tir unique - ceci demande au programme de ne retourner qu'un seul pid.
-c
Ne retourner que les identifiants de processus en cours d'exécution avec le même répertoire racine. Cette option est ignorée pour les utilisateurs non root, car ils ne pourront pas vérifier le répertoire racine actuel des processus qu'ils ne possèdent pas.
-q
Mode silencieux, supprimer toute sortie et régler uniquement le statut de sortie en conséquence.
-w
Afficher également les processus qui n'ont pas de ligne de commande visible (par exemple, les threads de travail du noyau).
-x
Scripts aussi - ceci demande au programme de retourner également les identifiants de processus des shells exécutant les scripts nommés.
-o omitpid
Indique à pidof d'omettre les processus avec cet identifiant de processus. L'identifiant spécial %PPID peut être utilisé pour nommer le processus parent du programme pidof, c'est-à-dire le shell ou le script shell appelant.
-t
Affiche tous les identifiants de thread au lieu des pid.
-S séparateur
Utiliser séparateur comme séparateur entre les pids. Utilisé uniquement lorsque plusieurs pids sont affichés pour le programme. L'option -d est un alias pour cette option pour la compatibilité avec le pidof de sysvinit.

STATUT DE SORTIE

0
Au moins un programme a été trouvé avec le nom demandé.
1
Aucun programme n'a été trouvé avec le nom demandé.

BOGUES

Lors de l'utilisation de l'option -x, pidof n'a qu'une méthode simple pour détecter les scripts et manquera les scripts qui, par exemple, utilisent env. Cette limitation est due à la façon dont les scripts apparaissent dans le système de fichiers proc.

VOIR AUSSI

pgrep(1), pkill(1)
