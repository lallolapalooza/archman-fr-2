NOM

pip-wheel - description de la commande pip wheel

DESCRIPTION

Construit des archives Wheel pour vos exigences et dépendances.

Wheel est un format de paquet pré-compilé, et offre l'avantage de ne pas recompiler votre logiciel à chaque installation. Pour plus de détails, consultez la documentation de wheel : https://wheel.readthedocs.io/en/latest/

pip wheel utilise l'interface du système de compilation décrite ici : https://pip.pypa.io/en/stable/reference/build-system/

UTILISATION

python -m pip wheel [options] <spécificateur d'exigence> ...
python -m pip wheel [options] -r <fichier d'exigences> ...
python -m pip wheel [options] [-e] <url de projet vcs> ...
python -m pip wheel [options] [-e] <chemin de projet local> ...
python -m pip wheel [options] <url/chemin d'archive> ...

OPTIONS

-w, --wheel-dir <répertoire>
Construit les roues dans <répertoire>, le répertoire par défaut étant le répertoire de travail actuel.

(variable d'environnement : PIP_WHEEL_DIR)

--no-binary <contrôle_format>
N'utilise pas les paquets binaires. Peut être fourni plusieurs fois, et chaque fois s'ajoute à la valeur existante. Accepte soit ":all:" pour désactiver tous les paquets binaires, ":none:" pour vider l'ensemble (notez les deux-points), ou un ou plusieurs noms de paquets séparés par des virgules (sans deux-points). Notez que certains paquets sont difficiles à compiler et peuvent échouer à l'installation lorsque cette option est utilisée sur eux.

(variable d'environnement : PIP_NO_BINARY)

--only-binary <contrôle_format>
N'utilise pas les paquets sources. Peut être fourni plusieurs fois, et chaque fois s'ajoute à la valeur existante. Accepte soit ":all:" pour désactiver tous les paquets sources, ":none:" pour vider l'ensemble, ou un ou plusieurs noms de paquets séparés par des virgules. Les paquets sans distribution binaire échoueront à l'installation lorsque cette option est utilisée sur eux.

(variable d'environnement : PIP_ONLY_BINARY)

--prefer-binary
Préfère les paquets binaires aux paquets sources, même si les paquets sources sont plus récents.

(variable d'environnement : PIP_PREFER_BINARY)

--no-build-isolation
Désactive l'isolation lors de la compilation d'une distribution source moderne. Les dépendances de compilation spécifiées par la PEP 518 doivent déjà être installées si cette option est utilisée.

(variable d'environnement : PIP_NO_BUILD_ISOLATION)

--check-build-dependencies
Vérifie les dépendances de compilation.

(variable d'environnement : PIP_CHECK_BUILD_DEPENDENCIES)

-c, --constraint <fichier>
Contraint les versions en utilisant le fichier de contraintes donné. Cette option peut être utilisée plusieurs fois.

(variable d'environnement : PIP_CONSTRAINT)

--build-constraint <fichier>
Contraint les dépendances de compilation en utilisant le fichier de contraintes donné. Cette option peut être utilisée plusieurs fois.

(variable d'environnement : PIP_BUILD_CONSTRAINT)

-e, --editable <chemin/url>
Installe un projet en mode éditable (c'est-à-dire le mode "develop" de setuptools) à partir d'un chemin de projet local ou d'une URL VCS.

(variable d'environnement : PIP_EDITABLE)

-r, --requirement <fichier>
Installe à partir du fichier d'exigences donné. Cette option peut être utilisée plusieurs fois.

(variable d'environnement : PIP_REQUIREMENT)

--src <répertoire>
Répertoire dans lequel vérifier les projets éditable. La valeur par défaut dans un environnement virtuel est "<chemin_venv>/src". La valeur par défaut pour les installations globales est "<répertoire_actuel>/src".

(variables d'environnement : PIP_SRC, PIP_SOURCE, PIP_SOURCE_DIR, PIP_SOURCE_DIRECTORY)

--ignore-requires-python
Ignore les informations Requires-Python.

(variable d'environnement : PIP_IGNORE_REQUIRES_PYTHON)

--no-deps
N'installe pas les dépendances du paquet.

(variables d'environnement : PIP_NO_DEPS, PIP_NO_DEPENDENCIES)

--progress-bar <barre_progression>
Spécifie si la barre de progression doit être utilisée. En mode "auto", --quiet supprimera toutes les barres de progression. [auto, on, off, raw] (par défaut : auto)

(variable d'environnement : PIP_PROGRESS_BAR)

--no-verify
Ne vérifie pas si la roue construite est valide.

(variable d'environnement : PIP_NO_VERIFY)

-C, --config-settings <paramètres>
Paramètres de configuration à passer au backend de compilation. Les paramètres sont de la forme CLE=VALEUR. Utilisez plusieurs options --config-settings pour passer plusieurs clés au backend.

(variable d'environnement : PIP_CONFIG_SETTINGS)

--pre
Inclut les versions pré-release et de développement. Par défaut, pip ne trouve que les versions stables.

(variable d'environnement : PIP_PRE)

--require-hashes
Exige un hash pour vérifier chaque exigence, pour des installations répétables. Cette option est implicite lorsque tout paquet dans un fichier d'exigences a une option --hash.

(variable d'environnement : PIP_REQUIRE_HASHES)

--group <[chemin:]groupe>
Installe un groupe de dépendances nommé à partir d'un fichier "pyproject.toml". Si un chemin est donné, le nom du fichier doit être "pyproject.toml". Par défaut, utilise "pyproject.toml" dans le répertoire actuel.

(variable d'environnement : PIP_GROUP)

--no-clean
Ne nettoie pas les répertoires de compilation.

(variable d'environnement : PIP_NO_CLEAN)
