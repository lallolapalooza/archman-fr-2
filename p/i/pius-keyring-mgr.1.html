PIUS-KEYRING-MGR(1) Manuel des commandes générales PIUS-KEYRING-MGR(1)

NOM

pius-keyring-mgr - Gestionnaire de trousseau de clés PIUS (PGP Individual UID Signer)

SYNTAXE

pius-keyring-mgr <mode> [options]

DESCRIPTION

pius-keyring-mgr possède plusieurs modes pour gérer les trousseaux de clés. Il a été conçu pour les "signing parties" (fêtes de signature), mais peut être utilisé pour n'importe quel trousseau de clés PGP. Le mode doit être le premier argument, avec les options expliquées ci-dessous.

OPTIONS

-d, --debug
Activer la sortie de débogage.
-g CHEMIN, --gpg-path=CHEMIN
Chemin vers le binaire gpg. [défaut : /usr/bin/gpg2]
-r TROUSSEAU, --keyring=TROUSSEAU
Utiliser ce trousseau de clés.
-v, --verbose
Afficher des résumés.

MODES

Le mode build est utilisé la plupart du temps. Il peut analyser un fichier CSV, rechercher automatiquement des clés et envoyer un e-mail à toute personne dont la clé n'a pas été trouvée. Ce mode peut également importer des clés à partir d'un fichier mbox. Les options sont :

-b FICHIER-MBOX, --mbox-file=FICHIER-MBOX
Analyser FICHIER-MBOX et examiner chaque message pour y trouver des empreintes PGP ou des clés ASCII-armor. Décode les messages si nécessaire.
-c FICHIER-CSV, --csv-file=FICHIER-CSV
Analyser FICHIER-CSV et importer les clés. Vous voudrez presque certainement aussi utiliser -D, -E, -F et -N.
-D DELIMITEUR, --delimiter=DELIMITEUR
Délimiteur de champ à utiliser lors de l'analyse CSV. N'a de sens qu'avec -c. [défaut : ,]
-E COLONNE-EMAIL, --email-field=COLONNE-EMAIL
Numéro de la colonne contenant l'adresse e-mail dans le fichier CSV. N'a de sens qu'avec -c. [défaut : 3]
-F COLONNE-EMPREINTE, --fp-field=COLONNE-EMPREINTE
Numéro de la colonne contenant l'empreinte GPG dans le fichier CSV. N'a de sens qu'avec -c. [défaut : 4]
-m EMAIL-EXPEDITEUR, --mail=EMAIL-EXPEDITEUR
Envoyer un e-mail aux personnes dont les clés n'ont pas été trouvées, en utilisant EMAIL-EXPEDITEUR comme expéditeur.
-M FICHIER, --mail-text=FICHIER
Utiliser le texte du FICHIER comme corps de l'e-mail lors de l'envoi des e-mails au lieu du texte par défaut. Pour voir le texte par défaut, utilisez --print-default-email. Nécessite -m.
-N COLONNE-NOM, --name-field=COLONNE-NOM
Numéro de la colonne contenant le nom dans le fichier CSV. N'a de sens qu'avec -c. [défaut : 2]
-n EMAIL-DESTINATAIRE, --override-email=EMAIL-DESTINATAIRE
Au lieu d'envoyer à l'utilisateur, envoyer à cette adresse. Principalement utile pour le débogage.
-p NOM-FETE, --party=NOM-FETE
Le nom de la fête. Sera imprimé dans l'e-mail envoyé. N'est utile qu'avec -m.
-s SERVEUR-CLES, --keyservers=SERVEUR-CLES
Essayer ce serveur de clés. Spécifiez une fois pour chaque serveur (-s foo -s bar). [défaut : pool.sks-keyservers.net, pgp.mit.edu, keys.gnupg.net]
-t DIR-TEMPO, --tmp-dir=DIR-TEMPO
Répertoire pour placer les éléments temporaires. [défaut : /tmp/pius_keyring_mgr_tmp]
-T, --print-default-email
Imprimer l'e-mail par défaut.
--ignore-emails=IGNORES-EMAILS
Liste d'e-mails séparés par des virgules à ignorer (sans espaces).
--ignore-fingerprints=IGNORES-EMPREINTES
Liste d'empreintes PGP séparées par des virgules à ignorer (sans espaces).

Le mode prune ouvre un trousseau de clés et, pour chaque clé, demande s'il faut la supprimer. Utile après une fête pour élaguer le trousseau des personnes qui ne se sont pas présentées, et avant de distribuer le trousseau à ceux qui y ont participé. Il n'y a pas d'options.

Le mode raw passe les options directement à gpg. Utile pour ajouter des clés manuellement. Vos options sont ajoutées à celles nécessaires pour travailler en toute sécurité sur le trousseau de la fête. (Il ne charge pas votre trousseau personnel.) Vos options doivent être passées après '--' pour empêcher pius-keyring-manager de les interpréter comme les siennes.

EXEMPLES

Analyser un fichier CSV et un MBOX pour des e-mails et écrire à toute personne dont la clé n'a pas été trouvée, en utilisant vous@entreprise.com comme expéditeur :

/usr/bin/pius-keyring-mgr build --csv-file /tmp/report --mbox-file
/tmp/mbox --mail vous@entreprise.com

Télécharger une clé et l'ajouter au trousseau de la fête :

pius-keyring-mgr raw -r chemin/vers/keyring.gpg -- --recv-key <id_cle>
