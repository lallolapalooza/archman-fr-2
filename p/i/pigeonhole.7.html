NOM

pigeonhole - Aperçu du support Pigeonhole pour le langage Sieve pour Dovecot

DESCRIPTION

Pigeonhole ajoute la prise en charge du langage Sieve (RFC 5228) et du protocole ManageSieve (RFC 5804) à Dovecot (dovecot(1)).

Au sens littéral, une « pigeonnière » est un trou ou une alcôve dans un colombier pour que les pigeons nichent. C'est également le nom donné à l'un d'une série de petits compartiments ouverts dans une armoire utilisée pour le classement ou le tri du courrier. Comme verbe, cela décrit l'acte de placer un élément dans l'un de ces compartiments. Le nom « Pigeonhole » décrit donc bien une partie importante des fonctionnalités qu'il ajoute à Dovecot : le tri et le classement des messages électroniques.

Le langage Sieve est utilisé pour spécifier comment les e-mails doivent être traités. En écrivant des scripts Sieve, les utilisateurs peuvent personnaliser la manière dont les messages sont livrés, par exemple s'ils sont transférés ou stockés dans des dossiers spéciaux. Les messages indésirables peuvent être ignorés ou rejetés, et lorsque l'utilisateur n'est pas disponible, l'interpréteur Sieve peut envoyer une réponse automatisée. Par-dessus tout, le langage Sieve est conçu pour être simple, extensible et indépendant du système. Et, contrairement à la plupart des autres langages de script de filtrage de courrier, il ne permet pas aux utilisateurs d'exécuter des programmes arbitraires. Ceci est particulièrement utile pour empêcher les utilisateurs virtuels d'avoir un accès complet au magasin de courrier. L'intention du langage est de rendre impossible pour les utilisateurs de faire quoi que ce soit de plus complexe (et dangereux) que d'écrire de simples filtres de courrier.

En utilisant le protocole ManageSieve, les utilisateurs peuvent télécharger leurs scripts Sieve à distance, sans avoir besoin d'un accès direct au système de fichiers via FTP ou SCP. De plus, un serveur ManageSieve s'assure toujours que les scripts téléchargés sont valides, empêchant ainsi les échecs de compilation lors de la livraison du courrier.

Pigeonhole fournit les éléments suivants :

  • Le plugin LDA Sieve pour l'agent de livraison locale (LDA) de Dovecot (dovecot-lda(1)) qui facilite le filtrage Sieve réel lors de la livraison.
  • Le service ManageSieve qui implémente le protocole ManageSieve via lequel les utilisateurs peuvent gérer à distance les scripts Sieve sur le serveur.
  • Un plugin pour l'outil en ligne de commande doveadm(1) de Dovecot qui ajoute de nouvelles commandes doveadm-sieve(1) pour la gestion du filtrage Sieve.
  • Le plugin de documentation imap-sieve, qui permet d'attacher des scripts Sieve qui sont exécutés pour les événements IMAP dans leurs boîtes aux lettres.
  • La documentation du plugin imap-filter-sieve qui permet de refiltrer les e-mails dans une boîte aux lettres en utilisant des scripts Sieve.

La fonctionnalité et la configuration du plugin LDA Sieve et du service ManageSieve sont décrites en détail dans les fichiers README et INSTALL contenus dans le paquet Pigeonhole et dans sieve.

Les outils en ligne de commande suivants sont disponibles en dehors de doveadm :

sievec(1)

Compile les scripts Sieve en une représentation binaire pour une exécution ultérieure.

sieve-test(1)

L'outil de test Sieve universel pour tester l'effet d'un script Sieve sur un message particulier.

sieve-filter(1)

Filtre tous les messages d'une boîte aux lettres source particulière via un script Sieve.

sieve-dump(1)

Vide le contenu d'un fichier binaire Sieve à des fins de débogage (développement).
