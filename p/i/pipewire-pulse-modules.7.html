NOM

pipewire-pulse-modules - Modules Pulseaudio de PipeWire

DESCRIPTION

L'émulation Pulseaudio de PipeWire implémente plusieurs modules Pulseaudio. Elle ne supporte que ses propres modules intégrés et ne peut pas charger de modules externes écrits pour Pulseaudio.

CHARGEMENT DES MODULES

Les modules intégrés peuvent être chargés en utilisant des programmes clients Pulseaudio, par exemple pactl load-module <nom-du-module> <options-du-module>. Ils peuvent également être ajoutés à pipewire-pulse.conf, typiquement par un fichier de remplacement dans ~/.config/pipewire/pipewire-pulse.conf.d/ contenant le nom du module et ses arguments

# ~/.config/pipewire/pipewire-pulse.conf.d/custom.conf
pulse.cmd = [
    { cmd = "load-module" args = "module-null-sink sink_name=foo" flags = [ ] }
]

Pour lister tous les modules actuellement chargés, avec leurs arguments :

pactl list modules

Pour une liste courte des modules chargés :

pactl list modules short

Les modules peuvent être déchargés en utilisant soit le nom du module, soit son numéro d'index :

pactl load-module <nom-du-module> <paramètres>
pactl unload-module <nom-du-module|index#>

OPTIONS COMMUNES DES MODULES

La plupart des modules qui créent des flux/périphériques supportent les propriétés suivantes :

nom_de_destination, nom_de_source

Nom de la destination (resp. source). Les caractères autorisés dans le nom sont a-z, A-Z, les chiffres, le point (.) et le trait de soulignement (_). La longueur doit être de 1 à 128 caractères.

format

Le format d'échantillon. Les formats audio supportés sont :

PCM

  • u8 : entier non signé de 8 bits
  • aLaw : entier de 8 bits encodé en A-law
  • uLaw : entier de 8 bits encodé en µ-law
  • s16le : entier signé de 16 bits little-endian
  • s16be : entier signé de 16 bits big-endian
  • s16, s16ne : alias d'endianness native pour s16le ou s16be
  • s16re : alias d'endianness inversée pour s16le ou s16be
  • float32le : flottant 32 bits little-endian
  • float32be : flottant 32 bits big-endian
  • float32, float32ne : alias d'endianness native pour float32le ou float32be
  • float32re : alias d'endianness inversée pour float32le ou float32be
  • s32le : entier signé de 32 bits little-endian
  • s32be : entier signé de 32 bits big-endian
  • s32, s32ne : alias d'endianness native pour s32le ou s32be
  • s32re : alias d'endianness inversée pour s32le ou s32be
  • s24le : entier signé de 24 bits little-endian (note : ALSA appelle cela "S24_3LE")
  • s24be : entier signé de 24 bits big-endian (note : ALSA appelle cela "S24_3BE")
  • s24, s24ne : alias d'endianness native pour s24le ou s24be
  • s24re : alias d'endianness inversée pour s24le ou s24be
  • s24-32le : entier signé de 24 bits little-endian, packed dans un entier de 32 bits de sorte que les 8 bits les plus significatifs soient ignorés (note : ALSA appelle cela "S24_LE")
  • s24-32be : entier signé de 24 bits big-endian, packed dans un entier de 32 bits de sorte que les 8 bits les plus significatifs soient ignorés (note : ALSA appelle cela "S24_BE")
  • s24-32, s24-32ne : alias d'endianness native pour s24-32le ou s24-32be
  • s24-32re : alias d'endianness inversée pour s24-32le ou s24-32be

Formats audio compressés

Ci-dessous une liste de tous les formats compressés supportés. Le code au début de chaque ligne est utilisé chaque fois qu'un identifiant textuel pour un format est nécessaire (par exemple dans les fichiers de configuration ou en ligne de commande). Les formats dont l'identifiant se termine par -iec61937 doivent être encapsulés dans des trames IEC 61937, ce qui fait que l'audio compressé se comporte davantage comme un audio PCM normal.

  • ac3-iec61937 : Dolby Digital (DD / AC-3 / A/52)
  • eac3-iec61937 : Dolby Digital Plus (DD+ / E-AC-3)
  • mpeg-iec61937 : MPEG-1 ou MPEG-2 Part 3 (pas MPEG-2 AAC)
  • dts-iec61937 : DTS
  • mpeg2-aac-iec61937 : MPEG-2 AAC (supporté depuis PulseAudio 4.0)
  • truehd-iec61937 : Dolby TrueHD (ajouté dans PulseAudio 13.0, mais ne fonctionne pas encore en pratique)
  • dtshd-iec61937 : DTS-HD Master Audio (ajouté dans PulseAudio 13.0, mais ne fonctionne pas encore en pratique)
  • pcm : PCM (pas un format compressé, mais listé ici, car pcm est l'un des identifiants d'encodage reconnus)
  • any : (identifiant spécial pour indiquer que n'importe quel encodage peut être utilisé)

taux

Le taux d'échantillonnage.

canaux

Nombre de canaux audio.

carte_des_canaux

Une carte des canaux. Une liste de noms de canaux séparés par des virgules. Les noms de canaux actuellement définis sont : left, right, mono, center, front-left, front-right, front-center, rear-center, rear-left, rear-right, lfe, subwoofer, front-left-of-center, front-right-of-center, side-left, side-right, aux0, aux1 à aux15, top-center, top-front-left, top-front-right, top-front-center, top-rear-left, top-rear-right, top-rear-center

proprietes_de_destination, proprietes_de_source

Définit des propriétés supplémentaires de la destination/source. Par exemple, vous pouvez définir la description directement lors du chargement du module en définissant ce paramètre.

load-module module-alsa-sink sink_name=headphones sink_properties=device.description=Headphones
