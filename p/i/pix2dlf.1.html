NOM

pix2dlf - convertir les logs PIX au format DLF du pare-feu

SYNOPSIS

pix2dlf

DESCRIPTION

Ce script attend des logs de type syslog provenant d'un pare-feu Cisco PIX sur l'entrée standard. Les messages avec un niveau de sévérité informationnel (6) et supérieur devraient être enregistrés. Ils ressemblent par exemple à :

Jan 15 12:58:37 pix1 %PIX-4-106543: Deny tcp src outside:1.2.3.4/1234 dst
 inside:2.3.4.5/80 by access-group "foo"
Jan 16 10:37:09 pix1 %PIX-4-106543: Deny udp src outside:3.4.5.6/137 dst
 inside:4.5.6.7/137 by access-group "foo"
Jan 17 08:43:46 pix1 %PIX-4-106543: Deny icmp src outside:5.6.7.8 dst
 inside:6.7.8.9 (type 8, code 0) by access-group "foo"
Jan 24 00:07:39 pix1 %PIX-6-302000: Teardown TCP connection 178359 faddr
 7.8.9.10/102 gaddr 8.9.10.11/21652 laddr 9.10.11.12/4107 duration
 0:00:01 bytes 755 (TCP FINs)
Jan 24 00:07:45 pix1 %PIX-6-302000: Teardown UDP connection for faddr
 10.11.12.13/711 gaddr 11.12.13.14/1259 laddr 12.13.14.15/1259

C'est-à-dire

syslog_time_stamp log_host %PIX-Level-Message_number: Message_text

Voir aussi http://www.cisco.com/univercd/cc/td/doc/product/iaabu/pix/pix_62/ syslog/pixemint.htm#xtocid11 .

Il produira des enregistrements DLF au format DLF du pare-feu Lire sur STDOUT.

Pour l'instant, seuls les messages

%PIX-2-106001
%PIX-2-106002
%PIX-2-106006
%PIX-2-106007
%PIX-3-106010
%PIX-3-106014
%PIX-6-106015
%PIX-1-106021
%PIX-4-106023
%PIX-6-302002
%PIX-6-302006
%PIX-6-302014
%PIX-6-302016

sont utilisés. Notez que le niveau de sévérité 1 est `alert', 6 est ` informational'. (0 est `emergency', 7 est `debugging'.)

EXEMPLES

Pour traiter un log tel que produit par un Cisco PIX :

$ pix2dlf < pix.log

pix2dlf sera rarement utilisé seul, mais sera plus probablement appelé par lr_log2report :

$ lr_log2report pix < /var/log/pix.log

BOGUES

Ce script n'a pas encore été testé sur une très large gamme de fichiers de logs, et par conséquent, il n'est pas encore mature.

L'étude de la documentation Cisco pour d'éventuels changements dans le format du fichier log, par exemple entre PIX Firewall Version 4.0 et 6.2, n'a *pas* encore été faite.

Nous ne supportons probablement aucun des produits PIX de manière vraiment complète. Nous avons trouvé de la documentation pour les fichiers de logs des versions 4.3, 4.4, 5.0, 5.1, 5.2, 5.3, 6.0, 6.1 et 6.2 de PIX, mais nous n'avons pas encore implémenté toutes les particularités trouvées dans ces documents. Ce script s'efforce de supporter PIX 6.2 dans les cas les plus courants.

En modifiant ce script, attention, la syntaxe des logs a changé pendant le développement de PIX. De plus, notez que certains états rudimentaires sont représentés dans les logs PIX. Cet état n'est pas encore utilisé dans ce script.
