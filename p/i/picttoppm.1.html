NOM

picttoppm - convertir un fichier PICT Macintosh en PPM

SYNOPSIS

picttoppm

[-verbose]

[-fullres]

[-noheader]

[-quickdraw] [-fontdir fichier]

[fichier_pict]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

picttoppm lit un fichier PICT (version 1 ou 2) et produit une image PPM.

PICT est un format d'image développé par Apple Computer en 1984 comme format natif pour les graphiques Macintosh. Une image PICT est codée en commandes QuickDraw. Le format PICT est un méta-format qui peut être utilisé pour les images bitmap et vectorielles. PICT est aussi connu sous le nom de format 'Macintosh Picture' ou format QuickDraw Picture.

Les fichiers PICT sont principalement utilisés pour échanger des graphiques entre diverses applications Macintosh.

Dans MacOS X, PDF remplace PICT comme format graphique principal.

OPTIONS

-fontdir fichier
Rend la liste des polices BDF dans fichier disponible pour picttoppm lors du dessin de texte. Voir ci-dessous pour le format du fichier fontdir. Ceci s'ajoute aux polices intégrées et à celles du fichier fontdir.
-fullres
Force les images contenues dans le fichier PICT à être sorties avec au moins leur pleine résolution. Un fichier PICT peut indiquer qu'une image contenue doit être mise à l'échelle vers le bas avant la sortie. Cette option force les images à conserver leurs tailles et à empêcher la perte d'informations. Cette option désactive toutes les opérations PICT sauf les images.
-noheader
Ne suppose pas que les 512 premiers octets du fichier sont un en-tête. Tous les fichiers PICT ont un tel en-tête, mais c'est utile lorsque vous avez des données PICT qui n'ont pas été stockées dans le data fork d'un fichier PICT.
-quickdraw
Exécute uniquement les opérations quickdraw pures. En particulier, désactive l'interprétation des opérations spéciales de l'imprimante PostScript.
-verbose
Imprime un tas d'informations sur le fichier PICT et le processus de conversion qui n'intéressent vraiment que les programmeurs de picttoppm.

LIMITATIONS

Le format de fichier PICT est un format de dessin général. picttoppm ne reconnaît pas toutes les commandes de dessin, mais il implémente complètement toutes les commandes d'image et implémente en grande partie le dessin de lignes, rectangles, polygones et textes. Il est utile pour convertir des images scannées et certaines conversions de dessin.

Avec -fullres, picttoppm ignore les commandes de dessin de texte. Depuis Netpbm 10.45 (décembre 2008), il émet un message d'avertissement lorsqu'il omet du texte pour cette raison.

POLICES

Certaines informations d'un fichier PICT sont du texte, avec un nombre indiquant la police dans laquelle le texte doit être rendu. picttoppm a une police intégrée, mais vous pouvez en ajouter d'autres en indiquant à picttoppm des fichiers de polices BDF, ce que vous faites avec des fichiers de répertoire de polices.

picttoppm utilise automatiquement le fichier nommé fontdir dans le répertoire courant, s'il existe. Vous pouvez spécifier un fichier de répertoire de polices supplémentaire avec l'option -fontdir.

Évidemment, les définitions de polices sont fortement liées au Macintosh. Vous pouvez trouver plus de numéros de polices et d'informations sur les polices dans la documentation Macintosh.

FORMAT DU FICHIER FONT DIR

Chaque ligne du fichier est soit un commentaire, soit des informations sur la police. Un commentaire commence par #. Les informations sur la police consistent en 4 champs séparés par des espaces. Le premier est le numéro de la police, le second est la taille de la police en pixels, le troisième est le style de la police et le quatrième est le nom d'un fichier BDF contenant la police. Le format BDF est défini par le système X Window et dépasse la portée de ce document.
