NOM

pip-list - description de la commande pip list

DESCRIPTION

Liste les paquets installés, y compris les paquets éditables.

Les paquets sont listés par ordre alphabétique insensible à la casse.

UTILISATION

python -m pip list [options]

OPTIONS

-o, --outdated
Lister les paquets obsolètes

(variable d'environnement : PIP_OUTDATED)

-u, --uptodate
Lister les paquets à jour

(variable d'environnement : PIP_UPTODATE)

-e, --editable
Lister les projets éditables.

(variable d'environnement : PIP_EDITABLE)

-l, --local
Si dans un environnement virtuel ayant un accès global, ne pas lister les paquets installés globalement.

(variable d'environnement : PIP_LOCAL)

--user
Afficher uniquement les paquets installés dans le site utilisateur.

(variable d'environnement : PIP_USER)

--path <chemin>
Restreindre aux chemins d'installation spécifiés pour lister les paquets (peut être utilisé plusieurs fois).

(variable d'environnement : PIP_PATH)

--pre
Inclure les versions pré-release et de développement. Par défaut, pip ne trouve que les versions stables.

(variable d'environnement : PIP_PRE)

--format <format_liste>
Sélectionner le format de sortie parmi : colonnes (par défaut), freeze, ou json. Le format 'freeze' ne peut pas être utilisé avec l'option --outdated.

(variable d'environnement : PIP_FORMAT)

--not-required
Lister les paquets qui ne sont pas des dépendances de paquets installés.

(variable d'environnement : PIP_NOT_REQUIRED)

--exclude-editable
Exclure les paquets éditables de la sortie.

(variable d'environnement : PIP_EXCLUDE_EDITABLE)

--include-editable
Inclure les paquets éditables dans la sortie.

(variable d'environnement : PIP_INCLUDE_EDITABLE)

--exclude <paquet>
Exclure un paquet spécifié de la sortie.

(variable d'environnement : PIP_EXCLUDE)
