NOM

pipewire - Le serveur multimédia PipeWire

SYNTAXE

pipewire [options]

DESCRIPTION

PipeWire est un service qui facilite le partage de contenu multimédia entre les appareils et les applications.

Le démon pipewire lit un fichier de configuration qui est davantage documenté dans la page de manuel pipewire.conf(5).

OPTIONS

-h | --help

Affiche l'aide.

-v | --verbose

Augmente le niveau de verbosité d'un cran. Cette option peut être spécifiée plusieurs fois.

--version

Affiche les informations de version.

-c | --config=FICHIER

Charge le fichier de configuration donné (Défaut : pipewire.conf).

-P | --properties=PROPS

Ajoute les propriétés données sous forme d'objet JSON SPA au contexte.

PARAMÈTRES DE FONCTIONNEMENT

Un démon PipeWire exposera également un objet de métadonnées de paramètres qui peut être utilisé pour modifier certains paramètres à l'exécution.

Normalement, ces paramètres peuvent outrepasser toutes les restrictions listées dans les options de configuration ci-dessus, telles que les valeurs de quantum et de taux d'échantillonnage.

Les paramètres peuvent être modifiés à l'aide de pw-metadata(1) :

pw-metadata -n settings                  # liste les paramètres
pw-metadata -n settings 0                # liste les paramètres du serveur
pw-metadata -n settings 0 log.level 2    # modifie un paramètre du serveur

log.level = ENTIER

Modifie le niveau de journalisation du démon PipeWire.

clock.rate = ENTIER

Le taux d'échantillonnage par défaut.

clock.allowed-rates = [ TAUX1 TAUX2... ]

Les taux d'échantillonnage autorisés.

clock.force-rate = ENTIER

Force temporairement le graphique à fonctionner à un taux d'échantillonnage fixe. Le traitement DSP et les périphériques passeront immédiatement au nouveau taux. Les flux en cours (applications PulseAudio, natives et ALSA) se rééchantillonneront automatiquement pour correspondre au nouveau taux.

Définissez la valeur à 0 pour permettre à nouveau au taux d'échantillonnage de varier.

clock.quantum = ENTIER

Le quantum (taille du tampon) par défaut.

clock.min-quantum = ENTIER

Le plus petit quantum à utiliser.

clock.max-quantum = ENTIER

Le plus grand quantum à utiliser.

clock.force-quantum = ENTIER

Force temporairement le graphique à fonctionner avec un quantum fixe.

Définissez la valeur à 0 pour permettre à nouveau au quantum de varier.

VARIABLES D'ENVIRONNEMENT

Répertoires de sockets

PIPEWIRE_RUNTIME_DIR

XDG_RUNTIME_DIR

USERPROFILE

Utilisé pour trouver le socket PipeWire sur le serveur (et les clients natifs).

PIPEWIRE_CORE

Nom du socket à créer.

PIPEWIRE_REMOTE

Nom du socket auquel se connecter.

PIPEWIRE_DAEMON

S'il est défini sur true, le processus devient un nouveau serveur PipeWire.

Répertoires de configuration, nom du fichier de configuration et préfixe

PIPEWIRE_CONFIG_DIR

XDG_CONFIG_HOME

HOME

Utilisé pour trouver les répertoires de fichiers de configuration.

PIPEWIRE_CONFIG_PREFIX

PIPEWIRE_CONFIG_NAME

Utilisé pour remplacer le préfixe de configuration et le nom de configuration fournis par l'application.

PIPEWIRE_NO_CONFIG

Active (false) ou désactive (true) le remplacement de la configuration par défaut.

Informations sur le contexte

Dans le cadre d'un contexte client, les informations suivantes sont collectées à partir des variables d'environnement et placées dans les propriétés du contexte :

LANG

La langue actuelle dans application.language.

XDG_SESSION_ID

Est définie comme la propriété application.process.session-id.

DISPLAY

Est définie comme la propriété window.x11.display.

Modules

PIPEWIRE_MODULE_DIR

Définit le répertoire où trouver les modules PipeWire.

SPA_SUPPORT_LIB

Le nom de la bibliothèque de support SPA à charger. Ceci peut être utilisé pour passer à une bibliothèque de support alternative, par exemple, pour s'exécuter sur le noyau temps réel EVL.

Options de journalisation

JOURNAL_STREAM

Est utilisée pour analyser le flux utilisé par le journal. Ceci est généralement configuré par systemd.

PIPEWIRE_LOG_LINE

Active la journalisation des numéros de ligne. Par défaut true.

PIPEWIRE_LOG_TIMESTAMP

Type d'horodatage de journalisation : "local", "monotonic", "realtime", "none". Par défaut "local".

PIPEWIRE_LOG

Spécifie un fichier journal à utiliser à la place du journalisateur par défaut.

PIPEWIRE_LOG_SYSTEMD

Active l'utilisation de systemd pour le journalisateur, par défaut true.

Autres paramètres

PIPEWIRE_CPU

Sélectionne le CPU et les indicateurs. Ceci est un masque de bits de n'importe lequel des indicateurs CPU

PIPEWIRE_VM

Sélectionne la machine virtuelle sur laquelle PipeWire s'exécute. Il peut s'agir de l'un des types de VM

DISABLE_RTKIT

Désactive l'utilisation de RTKit ou du portail temps réel pour la planification temps réel.

NO_COLOR

Désactive l'utilisation des couleurs dans la sortie de la console.

Options de débogage

PIPEWIRE_DLCLOSE

Active (true) ou désactive (false) l'utilisation de dlclose lorsqu'une bibliothèque partagée n'est plus utilisée. Lors du débogage, il peut être judicieux de désactiver dlclose afin de pouvoir obtenir les symboles de débogage de l'objet.

Options de flux

PIPEWIRE_NODE

Fait qu'un flux se connecte à un objet.serial ou node.name spécifique.

PIPEWIRE_PROPS

Ajoute des propriétés supplémentaires à un flux ou à un filtre.

PIPEWIRE_QUANTUM

Force un taux et une taille de tampon spécifiques pour le flux ou le filtre.

PIPEWIRE_LATENCY

Définit une latence spécifique pour un flux ou un filtre. Ceci n'est qu'une suggestion, mais la latence configurée ne sera pas plus grande.

PIPEWIRE_RATE

Définit un taux pour un flux ou un filtre. Ceci n'est qu'une suggestion. Le taux sera modifié lorsque le graphique sera inactif.

PIPEWIRE_AUTOCONNECT

Remplace les paramètres par défaut de connexion automatique des flux.

Options de plugin

SPA_PLUGIN_DIR

Est utilisé pour localiser les plugins SPA.

SPA_DATA_DIR

SPA_DEBUG

Définit le niveau de journalisation des plugins SPA. Ceci est généralement contrôlé par la variable PIPEWIRE_DEBUG lorsque les plugins sont gérés par PipeWire, mais certains outils autonomes (comme spa-inspect) utilisent cette variable.

ACP_BUILDDIR

S'il est défini, les profils ACP sont chargés à partir du répertoire de compilation.

ACP_PATHS_DIR

ACP_PROFILES_DIR

Utilisé pour localiser respectivement les répertoires de chemins et de profils ACP.

LADSPA_PATH

Liste séparée par des virgules des répertoires où les plugins ladspa peuvent être trouvés.

LIBJACK_PATH

Répertoire où le fichier libjack.so de jack1 ou jack2 peut être trouvé.
