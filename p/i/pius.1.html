NOM

pius - Signataire d'UID individuel PGP

SYNOPIS

pius [options] -s <signer-keyid> <keyid> [ <keyid> ... ]
pius [options] -A -r <chemin-du-keyring> -s <signer-keyid>

DESCRIPTION

pius est un outil pour signer individuellement tous les UID d'un ensemble de clés, et pour envoyer par courrier électronique une copie chiffrée de chaque signature de ce type à l'adresse e-mail associée à cet UID.

En conséquence de ce processus, le destinataire peut choisir quelles signatures importer. De plus, les signatures d'UID inactifs ne sont pas livrées. Cet outil réduit considérablement le temps et les erreurs lors de la signature des clés.

OPTIONS

--version
affiche le numéro de version du programme et quitte
-h, --help
affiche ce message d'aide et quitte
-A, --all-keys
Signe toutes les clés du keyring. Nécessite -r.
-d, --debug
Active la sortie de débogage.
-b CHEMIN, --gpg-path=CHEMIN
Chemin vers l'exécutable gpg. [défaut : /usr/bin/gpg2]
-e, --encrypt-outfiles
Chiffre les fichiers de sortie avec les clés respectives.
-H HOTE, --mail-host=HOTE
Nom d'hôte du serveur SMTP. [défaut : localhost]
-I, --import
Importe également les clés non signées du keyring dans le keyring par défaut. Ignoré si -r n'est pas spécifié, ou s'il est identique au keyring par défaut.
-m EMAIL-EXPEDITEUR, --mail=EMAIL-EXPEDITEUR
Envoie par courrier électronique les clés chiffrées et signées aux adresses e-mail respectives en utilisant EMAIL-EXPEDITEUR comme expéditeur. Voir aussi -H et -P.
-M FICHIER, --mail-text=FICHIER
Utilise le texte contenu dans FICHIER comme corps de l'e-mail lors de l'envoi d'e-mails au lieu du texte par défaut. Pour voir le texte par défaut, utilisez --print-default-email. Nécessite -m.
-N, --no-sort-keyring
Ne pas trier le keyring par nom.
-n EMAIL-DESTINATAIRE, --override-email=EMAIL-DESTINATAIRE
Au lieu d'envoyer à l'utilisateur, envoyer à cette adresse. Principalement utile pour le débogage.
-o REPERTOIRE-SORTIE, --out-dir=REPERTOIRE-SORTIE
Répertoire où placer les clés signées. [défaut : /tmp/pius_out]
-O, --no-pgp-mime
N'utilise pas PGP/Mime lors de l'envoi d'e-mails.
-P PORT, --mail-port=PORT
Port du serveur SMTP. [défaut : 587]
-r KEYRING, --keyring=KEYRING
Le keyring à utiliser. Assurez-vous de spécifier le chemin complet ou relatif. Un simple nom de fichier amènera GPG à supposer qu'il est relatif à ~/.gnupg. [défaut : ~/.gnupg/pubring.gpg]
-s SIGNER-KEYID, --signer=SIGNER-KEYID
Le keyid à utiliser pour signer (requis).
-f KEYID, --force-signer=KEYID
Force GnuPG à utiliser cet keyid exact pour signer (ne pas deviner la sous-clé)
-S, --no-mail-tls
N'utilise pas STARTTLS lors de la communication avec le serveur SMTP.
-t REPERTOIRE-TEMPORAIRE, --tmp-dir=REPERTOIRE-TEMPORAIRE
Répertoire où placer les fichiers temporaires. [défaut : /tmp/pius_tmp]
-T, --print-default-email
Affiche l'e-mail par défaut.
-u UTILISATEUR, --mail-user=UTILISATEUR
S'authentifie auprès du serveur SMTP avec le nom d'utilisateur UTILISATEUR. Le mot de passe vous sera demandé.
-U URL-POLITIQUE, --policy-url=URL-POLITIQUE
URL de politique à inclure dans chaque signature.
-v, --verbose
Soit plus verbeux.
