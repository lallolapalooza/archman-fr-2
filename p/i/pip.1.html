NOM

pip - gestionnaire de paquets pour les paquets Python

SYNTAXE

pip <commande> [options]

DESCRIPTION

pip est le gestionnaire de paquets recommandé par la PyPA pour les paquets Python.

OPTIONS

-h, --help
Afficher l'aide.

(variable d'environnement : PIP_HELP)

--debug
Laisser les exceptions non gérées se propager en dehors de la sous-routine principale, au lieu de les enregistrer dans stderr.

(variable d'environnement : PIP_DEBUG)

--isolated
Exécuter pip en mode isolé, ignorant les variables d'environnement et la configuration utilisateur.

(variable d'environnement : PIP_ISOLATED)

--require-virtualenv
Autoriser pip à s'exécuter uniquement dans un environnement virtuel ; sinon, quitter avec une erreur.

(variables d'environnement : PIP_REQUIRE_VIRTUALENV, PIP_REQUIRE_VENV)

--python <python>
Exécuter pip avec l'interpréteur Python spécifié.

(variable d'environnement : PIP_PYTHON)

-v, --verbose
Fournir plus d'informations. L'option est additive et peut être utilisée jusqu'à 3 fois.

(variable d'environnement : PIP_VERBOSE)

-V, --version
Afficher la version et quitter.

(variable d'environnement : PIP_VERSION)

-q, --quiet
Fournir moins d'informations. L'option est additive et peut être utilisée jusqu'à 3 fois (correspondant aux niveaux de journalisation WARNING, ERROR et CRITICAL).

(variable d'environnement : PIP_QUIET)

--log <path>
Chemin vers un journal d'ajout détaillé.

(variables d'environnement : PIP_LOG, PIP_LOG_FILE, PIP_LOCAL_LOG)

--no-input
Désactiver la demande d'entrée.

(variable d'environnement : PIP_NO_INPUT)

--keyring-provider <keyring_provider>
Activer la recherche d'identifiants via la bibliothèque keyring si l'entrée utilisateur est autorisée. Spécifier quel mécanisme utiliser [auto, disabled, import, subprocess]. (par défaut : auto)

(variable d'environnement : PIP_KEYRING_PROVIDER)

--proxy <proxy>
Spécifier un proxy sous la forme scheme://[user:passwd@]proxy.server:port.

(variable d'environnement : PIP_PROXY)

--retries <retries>
Nombre maximum de tentatives pour établir une nouvelle connexion HTTP. (par défaut : 5)

(variable d'environnement : PIP_RETRIES)

--timeout <sec>
Définir le délai d'attente de la socket (par défaut 15 secondes).

(variables d'environnement : PIP_TIMEOUT, PIP_DEFAULT_TIMEOUT)

--exists-action <action>
Action par défaut lorsqu'un chemin existe déjà : (s)witch, (i)gnore, (w)ipe, (b)ackup, (a)bort.

(variable d'environnement : PIP_EXISTS_ACTION)

--trusted-host <hostname>
Marquer cet hôte ou cette paire hôte:port comme fiable, même s'il n'a pas HTTPS valide ou pas de HTTPS du tout.

(variable d'environnement : PIP_TRUSTED_HOST)

--cert <path>
Chemin vers le bundle de certificats CA encodés en PEM. S'il est fourni, il remplace la valeur par défaut. Voir 'SSL Certificate Verification' dans la documentation de pip pour plus d'informations.

(variable d'environnement : PIP_CERT)

--client-cert <path>
Chemin vers le certificat client SSL, un fichier unique contenant la clé privée et le certificat au format PEM.

(variable d'environnement : PIP_CLIENT_CERT)

--cache-dir <dir>
Stocker les données du cache dans <dir>.

(variable d'environnement : PIP_CACHE_DIR)

--no-cache-dir
Désactiver le cache.

(variable d'environnement : PIP_NO_CACHE_DIR)

--disable-pip-version-check
Ne pas vérifier périodiquement PyPI pour déterminer si une nouvelle version de pip est disponible en téléchargement. Implicite avec --no-index.

(variable d'environnement : PIP_DISABLE_PIP_VERSION_CHECK)

--no-color
Supprimer la sortie colorée.

(variable d'environnement : PIP_NO_COLOR)

--use-feature <feature>
Activer de nouvelles fonctionnalités, potentiellement incompatibles avec les versions précédentes.

(variable d'environnement : PIP_USE_FEATURE)

--use-deprecated <feature>
Activer des fonctionnalités dépréciées, qui seront supprimées dans le futur.

(variable d'environnement : PIP_USE_DEPRECATED)

--resume-retries <resume_retries>
Nombre maximum de tentatives pour reprendre ou redémarrer un téléchargement incomplet. (par défaut : 5)

(variable d'environnement : PIP_RESUME_RETRIES)

COMMANDES

pip-install(1)
Installer des paquets.
pip-download(1)
Télécharger des paquets.
pip-uninstall(1)
Désinstaller des paquets.
pip-freeze(1)
Afficher les paquets installés au format requirements.
pip-lock(1)
Générer un fichier de verrouillage pour les dépendances et leurs dépendances.
pip-list(1)
Lister les paquets installés.
pip-show(1)
Afficher des informations sur les paquets installés.
pip-check(1)
Vérifier que les paquets installés ont des dépendances compatibles.
