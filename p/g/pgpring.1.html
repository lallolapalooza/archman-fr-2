PGPRING(1) Manuel des commandes générales PGPRING(1)

NOM

pgpring - déchargeur de trousseau de clés

SYNTAXE

pgpring [ -k trousseau | -2 | -5 ] [ -s ] [ -S ] [ -e ] [ -E ]

DESCRIPTION

pgpring est un déchargeur de trousseau de clés. Il extrait des informations du trousseau de clés binaire de PGP et les émet dans un format de sortie (presque) lisible compris par mutt(1) et process_keys(1). Ce format de sortie imite celui utilisé par GNU Privacy Guard (GPG).

OPTIONS

-k trousseau
Décharge le contenu du trousseau de clés spécifié.
-2
Utilise le trousseau de clés par défaut pour PGP 2.x.
-5
Utilise le trousseau de clés par défaut pour PGP 5.
-s
Décharge le trousseau de clés secret.
-S
Inclure les signatures.
-e
Exclure les signatures expirées.
-E
Exclure les clés expirées.
