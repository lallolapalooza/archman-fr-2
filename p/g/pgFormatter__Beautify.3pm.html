NOM

pgFormatter::Beautify - Bibliothèque pour l'impression soignée des requêtes SQL

VERSION

Version 5.8

SYNOPSIS

Ce module peut être utilisé pour reformater une requête SQL donnée, en anonymisant éventuellement les paramètres.

La sortie peut être soit du texte brut, soit du HTML avec des styles appropriés afin qu'il puisse être affiché sur une page web.

Exemple d'utilisation :

my $beautifier = pgFormatter::Beautify->new();
$beautifier->query( 'select a,b,c from d where e = f' );
$beautifier->beautify();
my $nice_txt = $beautifier->content();
$beautifier->format('html');
$beautifier->beautify();
my $nice_html = $beautifier->content();
$beautifier->format('html');
$beautifier->anonymize();
$beautifier->beautify();
my $nice_anonymized_html = $beautifier->content();
$beautifier->format();
$beautifier->beautify();
$beautifier->wrap_lines()
my $wrapped_txt = $beautifier->content();

FONCTIONS

new

Constructeur générique - crée un objet, définit les valeurs par défaut et lit la configuration à partir d'une table de hachage donnée avec des options.

Prend des options sous forme de table de hachage. Les options suivantes sont reconnues :

  • break - Chaîne de caractères utilisée pour les sauts de ligne. La valeur par défaut est "\n".
  • colorize - si défini à false, le style CSS ne sera pas appliqué à la sortie HTML. Utilisé en interne pour afficher les erreurs en mode CGI sans style.
  • comma - définit la virgule au début ou à la fin d'une ligne dans une liste de paramètres
end - met la virgule à la fin de la liste (par défaut)
start - met la virgule au début de la liste
  • comma_break - ajoute un retour à la ligne après chaque virgule dans les instructions INSERT
  • format - définit le format d'impression à appliquer au contenu (par défaut : text)
text - sortie du contenu en texte brut (par défaut en mode ligne de commande)
html - sortie texte/html avec style CSS appliqué au contenu (par défaut en mode CGI)
  • functions - liste (arrayref) de chaînes de caractères qui sont des noms de fonctions
  • keywords - liste (arrayref) de chaînes de caractères qui sont des mots-clés
  • multiline - utilise la recherche multi-lignes pour l'expression régulière de placeholder, voir placeholder.
  • no_comments - si défini à true, les commentaires seront supprimés de la requête
  • no_grouping - si défini à true, les instructions ne seront pas regroupées dans une transaction, un caractère de nouvelle ligne supplémentaire sera ajouté entre les instructions comme en dehors d'une transaction.
  • placeholder - utilise l'expression régulière spécifiée pour trouver le code qui ne doit pas être modifié dans la requête.
  • query - requête à formater
  • rules - table de hachage de règles - utilise la sémantique de règles de SQL::Beautify
  • space - caractère(s) à utiliser comme espace pour l'indentation
  • spaces - nombre d'espaces à utiliser pour l'indentation
  • uc_functions - que faire des noms de fonctions :
0 - ne pas changer
1 - changer en minuscules
2 - changer en majuscules
3 - changer en majuscule initiale
  • separator - chaîne de caractères utilisée comme séparateur de code dynamique, la valeur par défaut est une apostrophe simple
  • uc_keywords - que faire des mots-clés - signification de la valeur comme avec uc_functions
  • uc_types - que faire des types de données - signification de la valeur comme avec uc_functions
  • wrap - encapsule les mots-clés donnés dans des balises pre et post. Documentation spécifique dans SQL::Beautify
  • format_type - essaie un autre formatage
  • wrap_limit - encapsule les requêtes à une certaine longueur
  • wrap_after - nombre de colonnes après lesquelles les listes doivent être encapsulées
  • wrap_comment - applique l'encapsulation aux commentaires commençant par --
  • numbering - numérotation des instructions sous forme de commentaire avant chaque requête
  • redshift - ajoute les mots-clés Redshift (obsolète, utiliser --extra-keyword)
  • no_extra_line - n'ajoute pas de ligne vide supplémentaire à la fin de la sortie
  • keep_newline - préserve les lignes vides dans le code plpgsql
  • no_space_function - supprime l'espace avant l'appel de fonction et la parenthèse ouvrante
  • redundant_parenthesis - n'élimine pas les parenthèses redondantes dans les requêtes DML

Pour les valeurs par défaut, veuillez vérifier la fonction set_defaults.

query

Accesseur de la chaîne de requête. Lit et écrit :

$object->query()

, et écrit :

$object->query( $quelquechose )

content

Accesseur du contenu des résultats. Doit être appelé après $object->beautify().

Il peut s'agir de texte brut ou de HTML, conformément au format demandé par le client avec la méthode $object->format().

highlight_code

Génère le résultat en HTML avec des styles définis pour la mise en évidence.

tokenize_sql

Divise la requête SQL d'entrée en tokens

beautify

Formate la requête SQL.

format

Définit le format de sortie - valeurs possibles : 'text' et 'html'

La valeur par défaut est la sortie texte. Retourne 0 en cas de format incorrect et utilise la valeur par défaut.

set_dicts

Définit divers dictionnaires (listes de mots-clés, fonctions, symboles, etc.)

Ceci a été déplacé vers une fonction séparée, de sorte qu'il puisse être placé tout à la fin du module afin de faciliter la lecture du reste du code.

_remove_dynamic_code

Fonction interne utilisée pour masquer le code dynamique en plpgsql au parseur. Les valeurs originales sont restaurées avec la fonction _restore_dynamic_code().

_restore_dynamic_code

Fonction interne utilisée pour restaurer le code dynamique plpgsql en plpgsql qui a été supprimé par la méthode _remove_dynamic_code().

_quote_operator

Fonction interne utilisée pour échapper les opérateurs à plusieurs caractères afin qu'ils soient traités comme un seul mot. Les valeurs originales sont restaurées avec la fonction _restore_operator().

_restore_operator

Fonction interne utilisée pour restaurer les opérateurs qui ont été supprimés par la méthode _quote_operator().

_quote_comment_stmt

Fonction interne utilisée pour remplacer les constantes dans une instruction COMMENT afin qu'elles soient traitées comme un seul mot. Les valeurs originales sont restaurées avec la fonction _restore_comment_stmt().

_restore_comment_stmt

Fonction interne utilisée pour restaurer les chaînes de commentaires qui ont été supprimées par la méthode _quote_comment_stmt().

_remove_comments

Fonction interne utilisée pour supprimer les commentaires dans le code SQL afin de simplifier le travail de wrap_lines. Les commentaires doivent être restaurés avec la méthode _restore_comments().

_restore_comments

Fonction interne utilisée pour restaurer les commentaires dans le code SQL qui ont été supprimés par la méthode _remove_comments().

wrap_lines

Fonction interne utilisée pour couper les lignes à une certaine longueur.
