PG(1) Commandes utilisateur PG(1)

NOM

pg - parcourir des fichiers texte page par page

SYNTAXE

pg -*quantité *-p invite +ligne +/motif/ fichier(s) ...

DESCRIPTION

pg affiche un fichier texte sur un écran cathodique, une page à la fois. Après chaque page, une invite est affichée. L'utilisateur peut alors soit appuyer sur la touche retour chariot pour voir la page suivante, soit utiliser l'une des touches décrites ci-dessous.

Si aucun nom de fichier n'est donné en ligne de commande, pg lit depuis l'entrée standard. Si la sortie standard n'est pas un terminal, pg se comporte comme cat(1) mais précède chaque fichier de son nom s'il y en a plus d'un.

Si l'entrée provient d'un tuyau (pipe), pg stocke les données dans un fichier tampon lors de la lecture, pour permettre la navigation.

OPTIONS

pg accepte les options suivantes :

+nombre

Commence à la ligne spécifiée.

+/motif*/*

Commence à la ligne contenant le motif d'expression régulière de base motif donné.

-nombre

Le nombre de lignes par page. Par défaut, c'est le nombre de lignes de l'écran moins un.

-c

Efface l'écran avant d'afficher une page, si la capacité est fournie par l'entrée terminfo du terminal.

-e

N'affiche pas et ne met pas en pause avec (EOF) à la fin d'un fichier.

-f

Ne coupe pas les lignes longues.

-n

Sans cette option, les commandes doivent être terminées par un caractère de retour chariot.

Avec cette option, pg avance une fois la lettre de commande entrée.

-p chaîne

Au lieu de l'invite normale :, la chaîne est affichée. Si chaîne contient %d, sa première occurrence est remplacée par le numéro de la page courante.

-r

Interdit l'évasion vers le shell.

-s

Affiche les messages en mode standout (mise en évidence), si la capacité est fournie par l'entrée terminfo du terminal.

-h, --help

Affiche le texte d'aide et quitte.

-V, --version

Affiche la version et quitte.

COMMANDES

Les commandes suivantes peuvent être entrées à l'invite. Les commandes précédées de i dans ce document acceptent un nombre comme argument, positif ou négatif. Si cet argument commence par + ou -, il est interprété par rapport à la position actuelle dans le fichier d'entrée, sinon par rapport au début.

i<Retour chariot>

Affiche la page suivante ou la page indiquée.

id ou ^D

Affiche la moitié de page suivante. Si i est donné, il est toujours interprété par rapport à la position actuelle.

il

Affiche la ligne suivante ou la ligne indiquée.

if

Saute une page vers l'avant. i doit être un nombre positif et est toujours interprété par rapport à la position actuelle.

iw ou iz

Comme <Retour chariot> sauf que i devient la nouvelle taille de page.

. ou ^L

Redessine l'écran.

$

Avance à la dernière ligne du fichier d'entrée.

i/motif/

Recherche vers l'avant jusqu'à la première ou la i-ème occurrence de l'expression régulière de base motif trouvée. La recherche commence après la page actuelle et s'arrête à la fin du fichier. Aucun retour (wrap-around) n'est effectué. i doit être un nombre positif.

i?motif? ou imotif

Recherche vers l'arrière jusqu'à la première ou la i-ème occurrence de l'expression régulière de base motif trouvée. La recherche commence avant la page actuelle et s'arrête au début du fichier. Aucun retour (wrap-around) n'est effectué. i doit être un nombre positif.

Les commandes de recherche acceptent une lettre supplémentaire. Si t est donné, la ligne contenant le motif est affichée en haut de l'écran, ce qui est le comportement par défaut. m sélectionne le milieu et b le bas de l'écran. La position sélectionnée est également utilisée dans les recherches suivantes.

in

Avance au fichier suivant ou i fichiers vers l'avant.

ip

Relit le fichier précédent ou i fichiers vers l'arrière.

s nom_fichier

Sauvegarde le fichier actuel dans le nom_fichier donné.

h

Affiche un résumé des commandes.

!commande

Exécute la commande en utilisant le shell.

q ou Q

Quitter.

Si l'utilisateur appuie sur la touche d'interruption ou de sortie pendant que pg lit depuis le fichier d'entrée ou écrit sur le terminal, pg affichera immédiatement l'invite. Dans toutes les autres situations, ces touches termineront pg.

ENVIRONNEMENT

Les variables d'environnement suivantes affectent le comportement de pg :

COLUMNS

Remplace le nombre de colonnes fourni par le système si défini.

LANG, LC_ALL, LC_COLLATE, LC_CTYPE, LC_MESSAGES

Voir locale(7).

LINES

Remplace le nombre de lignes fourni par le système si défini.

SHELL

Utilisé par la commande !.

TERM

Détermine le type de terminal.

NOTES

pg s'attend à ce que les tabulateurs du terminal soient réglés tous les huit positions.

Les fichiers qui incluent des caractères NUL ne peuvent pas être affichés par pg.

VOIR AUSSI

cat(1), more(1), sh(1p), terminfo(5), locale(7), regex(7), term(7)
