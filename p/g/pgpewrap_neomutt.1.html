NOM

pgpewrap - Outil de manipulation de ligne de commande pour NeoMutt

SYNTAXE

pgpewrap [ options ] -- préfixe [ destinataires ]

DESCRIPTION

Il s'agit d'un petit programme C qui effectue une manipulation de ligne de commande : Le premier argument est une commande à exécuter. Lorsque pgpewrap rencontre un argument "--" (tiret-tiret), il interprétera l'argument suivant comme un préfixe qui sera placé avant tous les arguments suivants.

EXEMPLE


pgpewrap pgpe file -- -r a b c

exécutera :


pgpe file -r a -r b -r c

Ce script est nécessaire avec PGP 5 et avec GPG, car leurs interfaces de ligne de commande ne peuvent pas être correctement gérées par le mécanisme de formatage de neomutt.
