NOM

pgtopo_import - importateur de topologie postgis

SYNTAXE

pgtopo_import [options] topologie

DESCRIPTION

Le chargeur de données pgtopo_import lit un fichier d'exportation écrit par pgtopo_export et produit un script SQL reconstruisant la topologie qu'il contient.

UTILISATION

La <topologie> est le nom à donner à la topologie recréée, qui peut être différent du nom de la topologie à partir de laquelle l'export a été effectué.

Par défaut, le script SQL est écrit sur la sortie standard.

OPTIONS

Voici les options prises en charge :

(Notez que --skip-layers et --only-layers s'excluent mutuellement.)

--skip-layers
N'inclut pas les couches dans le script SQL de sortie. Uniquement le schéma de topologie.
--only-layers
N'inclut pas le schéma de topologie dans le script SQL de sortie. Uniquement les couches.
-f <nom_fichier>
Lit le fichier d'exportation à partir du nom de fichier spécifié, plutôt que depuis l'entrée standard. -h Affiche les informations d'utilisation.

EXEMPLES

Un exemple de session utilisant le chargeur pour créer un fichier SQL et le téléverser pourrait ressembler à ceci :

# pgtopo_import city_data < city_data.pgtopo_export | psql newdb
