NOM

pg_waldump - afficher un rendu lisible du journal des transactions (write-ahead log) d'un cluster de bases de données PostgreSQL

SYNOPSIS

pg_waldump [option...] [segment_de_départ [segment_de_fin]]

DESCRIPTION

pg_waldump affiche le journal des transactions (WAL) et est principalement utile à des fins de débogage ou pédagogiques.

Cet utilitaire ne peut être exécuté que par l'utilisateur qui a installé le serveur, car il nécessite un accès en lecture seule au répertoire de données.

OPTIONS

Les options de ligne de commande suivantes contrôlent l'emplacement et le format de la sortie :

segment_de_départ

Commence la lecture au niveau du fichier de segment WAL spécifié. Cela détermine implicitement le chemin dans lequel les fichiers seront recherchés et la ligne de temps à utiliser.

segment_de_fin

Arrête après la lecture du fichier de segment WAL spécifié.

-b
--details-sauvegarde

Affiche des informations détaillées sur les blocs de sauvegarde.

-B bloc
--bloc=bloc

Affiche uniquement les enregistrements qui modifient le bloc donné. La relation doit également être fournie avec --relation ou -R.

-e fin
--fin=fin

Arrête la lecture à l'emplacement WAL spécifié, au lieu de lire jusqu'à la fin du flux de journal.

-f
--suivre

Après avoir atteint la fin du WAL valide, continue de vérifier une fois par seconde l'apparition de nouveaux WAL.

-F fork
--fork=fork

Affiche uniquement les enregistrements qui modifient des blocs dans le fork donné. Les valeurs valides sont main pour le fork principal, fsm pour la carte d'espace libre, vm pour la carte de visibilité et init pour le fork init.

-n limite
--limite=limite

Affiche le nombre spécifié d'enregistrements, puis s'arrête.

-p chemin
--chemin=chemin

Spécifie un répertoire pour rechercher les fichiers de segment WAL ou un répertoire avec un sous-répertoire pg_wal qui contient de tels fichiers. Par défaut, la recherche s'effectue dans le répertoire courant, le sous-répertoire pg_wal du répertoire courant et le sous-répertoire pg_wal de PGDATA.

-q
--silencieux

N'affiche aucune sortie, sauf pour les erreurs. Cette option peut être utile lorsque vous voulez savoir si une plage d'enregistrements WAL peut être analysée avec succès mais que le contenu des enregistrements ne vous intéresse pas.

-r gestionnaire_ressources
--rmgr=gestionnaire_ressources

Affiche uniquement les enregistrements générés par le gestionnaire de ressources spécifié. Vous pouvez spécifier l'option plusieurs fois pour sélectionner plusieurs gestionnaires de ressources. Si la liste est passée sous forme de nom, imprime une liste des noms valides de gestionnaires de ressources et quitte.

Les extensions peuvent définir des gestionnaires de ressources personnalisés, mais pg_waldump ne charge pas le module d'extension et ne reconnaît donc pas les gestionnaires de ressources personnalisés par leur nom. Au lieu de cela, vous pouvez spécifier les gestionnaires de ressources personnalisés sous la forme custom### où ### est l'identifiant du gestionnaire de ressources à trois chiffres. Les noms de cette forme seront toujours considérés comme valides.

-R tablespace/db/rel
--relation=tablespace/db/rel

Affiche uniquement les enregistrements qui modifient des blocs dans la relation donnée. La relation est spécifiée avec l'OID du tablespace, l'OID de la base de données et le relfilenode séparés par des barres obliques, par exemple 1234/12345/12345. C'est le même format utilisé pour les relations dans la sortie du programme.

-s début
--début=début

Emplacement WAL à partir duquel commencer la lecture. Par défaut, la lecture commence au premier enregistrement WAL valide trouvé dans le fichier le plus ancien trouvé.

-t ligne_de_temps
--ligne-de-temps=ligne_de_temps

Ligne de temps à partir de laquelle lire les enregistrements WAL. Par défaut, la valeur de segment_de_départ est utilisée, si elle est spécifiée ; sinon, la valeur par défaut est 1. La valeur peut être spécifiée en décimal ou en hexadécimal, par exemple 17 ou 0x11.

-V
--version

Affiche la version de pg_waldump et quitte.

-w
--page-entiere

Affiche uniquement les enregistrements qui incluent des images de page entières.

-x xid
--xid=xid

Affiche uniquement les enregistrements marqués avec l'ID de transaction donné.

-z
--stats[=enregistrement]

Affiche des statistiques récapitulatives (nombre et taille des enregistrements et des images de page entières) au lieu des enregistrements individuels. Génère éventuellement des statistiques par enregistrement au lieu de par gestionnaire de ressources.

Si pg_waldump est terminé par le signal SIGINT (Control+C), le résumé des statistiques calculées est affiché jusqu'au point de terminaison. Cette opération n'est pas prise en charge sous Windows.

--sauvegarder-page-entiere=chemin_sauvegarde

Sauvegarde les images de page entières trouvées dans les enregistrements WAL dans le répertoire chemin_sauvegarde. Les images sauvegardées sont soumises aux mêmes critères de filtrage et de limitation que les enregistrements affichés.

Les images de page entières sont sauvegardées avec le format de nom de fichier suivant : TIMELINE-LSN.TABLESPACE.DATOID.RELNODE.NUMBLOC_FORK Les noms de fichiers sont composés des parties suivantes :

Composant Description
TIMELINE La ligne de temps du fichier de segment WAL où se trouve l'enregistrement, formaté sous forme d'un nombre hexadécimal de 8 caractères %08X
LSN Le LSN de l'enregistrement avec cette image, formaté sous forme de deux nombres hexadécimaux de 8 caractères %08X-%08X
TABLESPACE OID du tablespace du bloc
DATOID OID de la base de données du bloc
RELNODE filenode du bloc
NUMBLOC numéro de bloc du bloc
FORK Le nom du fork d'où provient l'image de page entière, comme main, fsm, vm ou init.

-?
--aide

Affiche l'aide sur les arguments de la ligne de commande de pg_waldump et quitte.

ENVIRONNEMENT

PGDATA

Répertoire de données ; voir aussi l'option -p.

PG_COLOR

Spécifie si la couleur doit être utilisée dans les messages de diagnostic. Les valeurs possibles sont always, auto et never.

NOTES

Peut donner des résultats incorrects lorsque le serveur est en cours d'exécution.

Seule la ligne de temps spécifiée est affichée (ou la valeur par défaut, si aucune n'est spécifiée). Les enregistrements des autres lignes de temps sont ignorés.

pg_waldump ne peut pas lire les fichiers WAL avec le suffixe .partial. Si ces fichiers doivent être lus, le suffixe .partial doit être supprimé du nom du fichier.

pg_waldump(1)

NOM

pg_waldump — extrait le contenu des fichiers WAL (Write-Ahead Log) de PostgreSQL

SYNOPIS

pg_waldump [option(s)...] [regression_test_path]

DESCRIPTION

pg_waldump est un utilitaire qui permet d'extraire et de visualiser le contenu des fichiers WAL (Write-Ahead Log) de PostgreSQL. Il est utile pour le débogage, la récupération de données ou l'analyse du fonctionnement interne de la réplication et de la récupération de PostgreSQL.

L'utilitaire peut lire des fichiers WAL bruts directement depuis le système de fichiers ou depuis la sortie de la commande pg_receivewal. Il décode les enregistrements WAL et les présente sous une forme lisible par l'homme.

Le paramètre regression_test_path est optionnel. S'il est fourni, pg_waldump s'attend à trouver les fichiers WAL dans un répertoire nommé « wal » à l'intérieur du chemin spécifié. Ceci est principalement utilisé pour les tests de régression.

OPTIONS

-D repertoire

Spécifie le répertoire contenant les fichiers WAL à lire. Si cette option n'est pas spécifiée, pg_waldump cherche les fichiers WAL dans le répertoire de données PostgreSQL actuel.

-b borne

Spécifie la borne inférieure (l'octet de début) pour la lecture des journaux de transactions. Utile pour extraire une portion spécifique d'un fichier WAL.

-e end_lsn

Spécifie la borne supérieure (l'octet de fin) pour la lecture des journaux de transactions. Utile pour extraire une portion spécifique d'un fichier WAL.

-f nom_fichier

Spécifie le nom du fichier WAL à lire. Si cette option n'est pas spécifiée, pg_waldump lit tous les fichiers WAL disponibles dans le répertoire spécifié par -D ou dans le répertoire de données actuel.

-p prefixe

Spécifie le préfixe des fichiers WAL à lire. Par défaut, c'est 00000001.

-t type

Spécifie le type d'enregistrements WAL à afficher. Les types possibles sont lahat (tous), wal (enregistrements WAL standard), tlist (enregistrements de liste de tuples), trpipe (enregistrements de pipeline de transactions), conninfo (informations de connexion), checkpt (points de contrôle), subtrans (enregistrements de sous-transcription), backup (enregistrements de sauvegarde).

-n nombre

Spécifie le nombre maximal d'enregistrements WAL à afficher. Utile pour limiter la sortie.

-o offset

Spécifie un décalage dans le fichier WAL. Utilisé en combinaison avec -f pour commencer la lecture à un certain point dans un fichier WAL spécifique.

-w

Indique que les noms de fichiers WAL sont écrits sous forme hexadécimale (par exemple, 000000010000000100000001) au lieu du format par défaut (par exemple, 00000001/0000000100000001).

-s

Affiche les LSN (Log Sequence Number) sous forme décimale au lieu de leur représentation hexadécimale standard.

-v

Affiche la version de pg_waldump.

-h, --help

Affiche l'aide et quitte.

ENVIRONNEMENT

pg_waldump utilise les variables d'environnement courantes de PostgreSQL, telles que PGDATA, qui spécifie le répertoire des données PostgreSQL.

NOTES

L'utilisation de pg_waldump nécessite une compréhension des fichiers WAL de PostgreSQL et des concepts de journalisation et de récupération. Une mauvaise utilisation peut entraîner une interprétation incorrecte des données.

Il est recommandé d'utiliser pg_waldump sur une copie des fichiers WAL, afin de ne pas perturber le fonctionnement normal de la base de données.
