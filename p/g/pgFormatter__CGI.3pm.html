pgFormatter::CGI(3) Documentation Perl fournie par l'utilisateur pgFormatter::CGI(3)

NOM

pgFormatter::CGI - Implémentation du script CGI-BIN pour formater les requêtes SQL.

VERSION

Version 5.8

SYNOPSIS

Ce module est appelé par le programme pg_format, lorsqu'il détecte qu'il est exécuté dans un environnement CGI. Dans ce cas, tout contrôle sur le flux est passé à ce module en appelant :

my $program = pgFormatter::CGI->new();
$program->run()

FONCTIONS

new

Constructeur d'objet, appelle la méthode set_config pour définir les valeurs par défaut de divers paramètres.

run

Route vers le bon gestionnaire en fonction du type de données reçu.

run_webpage

Encapsule tout le travail lié à la génération de la page HTML.

Elle appelle un ensemble de fonctions pour obtenir l'objet CGI, recevoir les paramètres de la requête, les nettoyer, embellir la requête (si fournie) et imprimer le HTML.

run_api

Encapsule tout le travail lié à la génération d'une réponse JSON lorsqu'elle est utilisée en tant qu'API.

get_cgi

Crée un objet CGI et définit la limite de taille des requêtes POST.

set_config

Définit la configuration pour la page et l'embellisseur. URLs, noms des fichiers auxiliaires, configuration pour le module pgFormatter::Beautify.

get_css

Charge et retourne le CSS par défaut à partir de __DATA__.

get_params

Récupère les valeurs des paramètres, et éventuellement le fichier téléchargé de l'objet CGI, dans les structures de $self.

get_api_params

Obtient les paramètres pour la version API de ce service.

sanitize_params

Remplace les valeurs des paramètres si les valeurs fournies n'étaient pas dans des plages acceptables.

beautify_query

Exécute l'embellissement sur la requête fournie, et stocke la nouvelle version dans $self->{'content'}

print_json

Affiche le SQL embelli en tant que JSON.

print_body

Affiche le corps de la page.

print_footer

Affiche le pied de page.

_load_optional_file

Fonction d'aide pour tenter de charger un fichier. Si elle réussit, elle retourne le contenu du fichier, sinon, elle retourne une chaîne vide (au lieu de planter).

print_error

Affiche un message d'erreur lorsqu'aucune réponse acceptable n'est trouvée.

print_headers

Affiche les en-têtes de la page - les en-têtes au niveau HTTP, et le HTML.

DONNEES

La section __DATA__ (à la fin de ce fichier) est utilisée pour stocker le style CSS par défaut, de sorte qu'il ne "pollue" pas le code Perl, et qu'il ne nécessite pas d'indentation.
