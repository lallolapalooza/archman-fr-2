NOM

pg_config - récupérer des informations sur la version installée de PostgreSQL

SYNTAXE

pg_config [option...]

DESCRIPTION

L'utilitaire pg_config affiche les paramètres de configuration de la version actuellement installée de PostgreSQL. Il est destiné, par exemple, à être utilisé par les paquets logiciels qui souhaitent interagir avec PostgreSQL afin de faciliter la recherche des fichiers d'en-tête et des bibliothèques nécessaires.

OPTIONS

Pour utiliser pg_config, fournissez une ou plusieurs des options suivantes :

--bindir

Affiche l'emplacement des exécutables utilisateur. Utilisez cette option, par exemple, pour trouver le programme psql. C'est normalement aussi l'emplacement où réside le programme pg_config.

--docdir

Affiche l'emplacement des fichiers de documentation.

--htmldir

Affiche l'emplacement des fichiers de documentation HTML.

--includedir

Affiche l'emplacement des fichiers d'en-tête C des interfaces client.

--pkgincludedir

Affiche l'emplacement des autres fichiers d'en-tête C.

--includedir-server

Affiche l'emplacement des fichiers d'en-tête C pour la programmation serveur.

--libdir

Affiche l'emplacement des bibliothèques de code objet.

--pkglibdir

Affiche l'emplacement des modules chargeables dynamiquement, ou où le serveur les rechercherait. (D'autres fichiers de données dépendants de l'architecture peuvent également être installés dans ce répertoire.)

--localedir

Affiche l'emplacement des fichiers de support des locales. (Ce sera une chaîne vide si le support des locales n'a pas été configuré lors de la compilation de PostgreSQL.)

--mandir

Affiche l'emplacement des pages de manuel.

--sharedir

Affiche l'emplacement des fichiers de support indépendants de l'architecture.

--sysconfdir

Affiche l'emplacement des fichiers de configuration système.

--pgxs

Affiche l'emplacement des makefiles d'extensions.

--configure

Affiche les options qui ont été passées au script configure lors de la configuration de PostgreSQL pour la compilation. Ceci peut être utilisé pour reproduire la configuration identique, ou pour savoir avec quelles options un paquet binaire a été compilé. (Notez cependant que les paquets binaires contiennent souvent des correctifs personnalisés spécifiques au vendeur.) Voir aussi les exemples ci-dessous.

--cc

Affiche la valeur de la variable CC qui a été utilisée pour compiler PostgreSQL. Ceci indique le compilateur C utilisé.

--cppflags

Affiche la valeur de la variable CPPFLAGS qui a été utilisée pour compiler PostgreSQL. Ceci indique les commutateurs du compilateur C nécessaires au moment du prétraitement (typiquement, des commutateurs -I).

--cflags

Affiche la valeur de la variable CFLAGS qui a été utilisée pour compiler PostgreSQL. Ceci indique les commutateurs du compilateur C.

--cflags_sl

Affiche la valeur de la variable CFLAGS_SL qui a été utilisée pour compiler PostgreSQL. Ceci indique les commutateurs du compilateur C supplémentaires utilisés pour compiler les bibliothèques partagées.

--ldflags

Affiche la valeur de la variable LDFLAGS qui a été utilisée pour compiler PostgreSQL. Ceci indique les commutateurs de l'éditeur de liens.

--ldflags_ex

Affiche la valeur de la variable LDFLAGS_EX qui a été utilisée pour compiler PostgreSQL. Ceci indique les commutateurs de l'éditeur de liens utilisés pour compiler uniquement les exécutables.

--ldflags_sl

Affiche la valeur de la variable LDFLAGS_SL qui a été utilisée pour compiler PostgreSQL. Ceci indique les commutateurs de l'éditeur de liens utilisés pour compiler uniquement les bibliothèques partagées.

--libs

Affiche la valeur de la variable LIBS qui a été utilisée pour compiler PostgreSQL. Ceci contient normalement des commutateurs -l pour les bibliothèques externes liées à PostgreSQL.

--version

Affiche la version de PostgreSQL.

-?
--help

Affiche l'aide sur les arguments de la ligne de commande de pg_config et quitte.
Si plusieurs options sont données, les informations sont imprimées dans cet ordre, un élément par ligne. Si aucune option n'est donnée, toutes les informations disponibles sont imprimées, avec des étiquettes.

NOTES

Les options --docdir, --pkgincludedir, --localedir, --mandir, --sharedir, --sysconfdir, --cc, --cppflags, --cflags, --cflags_sl, --ldflags, --ldflags_sl et --libs ont été ajoutées dans PostgreSQL 8.1. L'option --htmldir a été ajoutée dans PostgreSQL 8.4. L'option --ldflags_ex a été ajoutée dans PostgreSQL 9.0.

EXEMPLE

Pour reproduire la configuration de construction de l'installation PostgreSQL actuelle, exécutez la commande suivante :

eval ./configure `pg_config --configure`

La sortie de pg_config --configure contient des guillemets de shell afin que les arguments avec des espaces soient correctement représentés. Par conséquent, l'utilisation de eval est nécessaire pour obtenir des résultats corrects.
