NOM

pgFormatter::CLI - Implémentation du programme en ligne de commande pour formater les requêtes SQL.

VERSION

Version 5.8

SYNOPSIS

Ce module est appelé par le programme pg_format, lorsqu'il détecte qu'il n'est pas exécuté dans un environnement CGI. Dans ce cas, tout le contrôle du flux est passé à ce module en appelant :

my $program = pgFormatter::CLI->new();
$program->run()

FONCTIONS

new

Constructeur d'objet, rien de particulier ici.

run

Englobe tout le travail lié au programme en ligne de commande pg_format. Cela inclut l'appel des méthodes pour lire les paramètres de la ligne de commande, les valider, lire la requête, l'embellir et la sortir.

beautify

Formate réellement la requête chargée en utilisant la bibliothèque pgFormatter::Beautify. Si nécessaire, exécute l'anonymisation.

save_output

Sauvegarde la requête formatée dans le descripteur de fichier de sortie.

logmsg

Affiche un message en suivant le niveau de journalisation.

show_help_and_die

Comme son nom l'indique - affiche la page d'aide, avec un message d'erreur optionnel, et termine le programme.

load_sql

Charge le SQL à partir du fichier d'entrée ou de stdin.

get_command_line_args

Analyse les options de la ligne de commande et les place dans $self->{'cfg'}.

validate_args

Valide que les options analysées depuis la ligne de commande ont des valeurs sensées, ouvre les fichiers d'entrée et de sortie.
