NOM

pgpdump - Un visualiseur de paquets PGP

SYNTAXE

pgpdump [options] [fichier PGP]

DESCRIPTION

pgpdump est un visualiseur de paquets PGP qui affiche le format des paquets OpenPGP (RFC 4880) et PGP version 2 (RFC 1991).

Les options sont les suivantes :

-a
Accepte uniquement les entrées ASCII.
-g
Sélectionne un format de vidage alternatif.
-h
Affiche un message d'aide.
-i
Vide les paquets entiers.
-l
Vide les paquets littéraux.
-m
Vide les paquets marqueurs.
-p
Vide les paquets privés.
-u
Affiche l'heure UTC.
-v
Affiche la version.
