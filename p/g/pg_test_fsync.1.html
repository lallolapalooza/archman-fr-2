NOM

pg_test_fsync - détermine la méthode de synchronisation wal_sync_method la plus rapide pour PostgreSQL

SYNTAXE

pg_test_fsync [option...]

DESCRIPTION

pg_test_fsync vise à vous donner une idée raisonnable de la méthode wal_sync_method la plus rapide sur votre système spécifique, ainsi qu'à fournir des informations diagnostiques en cas de problème d'E/S identifié. Cependant, les différences montrées par pg_test_fsync pourraient ne pas faire de différence significative dans le débit réel de la base de données, d'autant plus que de nombreux serveurs de bases de données ne sont pas limités en vitesse par leurs journaux de transactions (WAL). pg_test_fsync rapporte le temps moyen d'opération de synchronisation de fichier en microsecondes pour chaque wal_sync_method, ce qui peut également être utilisé pour éclairer les efforts d'optimisation de la valeur de commit_delay.

OPTIONS

pg_test_fsync accepte les options de ligne de commande suivantes :

-f
--filename

Spécifie le nom du fichier dans lequel écrire les données de test. Ce fichier doit se trouver dans le même système de fichiers que le répertoire pg_wal est ou sera placé. (pg_wal contient les fichiers WAL.) Le défaut est pg_test_fsync.out dans le répertoire courant.

-s
--secs-per-test

Spécifie le nombre de secondes pour chaque test. Plus le temps par test est long, plus le test est précis, mais plus il prend de temps à s'exécuter. Le défaut est de 5 secondes, ce qui permet au programme de se terminer en moins de 2 minutes.

-V
--version

Affiche la version de pg_test_fsync et quitte.

-?
--help

Affiche l'aide sur les arguments de la ligne de commande de pg_test_fsync et quitte.

ENVIRONNEMENT

La variable d'environnement PG_COLOR spécifie s'il faut utiliser la couleur dans les messages de diagnostic. Les valeurs possibles sont always, auto et never.
