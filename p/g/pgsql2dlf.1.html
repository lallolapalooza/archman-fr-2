NOM

pgsql2dlf - convertir les fichiers journaux pgsql au format dlf

SYNTAXE

pgsql2dlf

DESCRIPTION

pgsql2dlf convertit un fichier journal de requêtes PostgreSQL au format DLF. Des informations sur PostgreSQL sont disponibles sur http://www.postgresql.org/. La journalisation peut être activée dans le fichier postgresql.conf.

Les options suivantes doivent au moins être présentes pour que ce convertisseur fonctionne correctement :

debug_level = 1

debug_print_parse = on

debug_print_query = on

Le format générique de base de données dlf est décrit dans database.xml.

EXEMPLES

Pour traiter un journal tel que produit par PostgreSQL :

$ pgsql2dlf < /var/log/postgresql.log

pgsql2dlf sera rarement utilisé seul, mais sera plus probablement appelé par lr_log2report :

$ lr_log2report pgsql < /var/log/postgresql.log

NOTES

L'analyseur a été testé pour les fichiers journaux de PostgreSQL 7.2.1.

VOIR AUSSI

psql(1), postmaster(1), postgresql.conf(5)
