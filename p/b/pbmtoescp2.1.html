NOM

pbmtoescp2 - convertir une image PBM en un fichier d'imprimante ESC/P2

SYNTAXE

pbmtoescp2

[-compress=modecompression] [-resolution=dpi] [fichierpbm]

Toutes les options peuvent être abrégées à leur préfixe unique le plus court. Vous pouvez utiliser deux tirets au lieu d'un pour désigner une option. Vous pouvez utiliser soit un espace, soit un signe égal entre le nom d'une option et sa valeur.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pbmtoescp2 lit une image PBM en entrée. Il produit un flux de contrôle graphique matriciel ESC/P2 en sortie.


Ce programme crée une sortie imprimable sur les imprimantes Epson qui comprennent le langage de contrôle d'imprimante ESC/P2 (par exemple, les modèles Stylus). Pour les anciennes imprimantes matricielles Epson 9 aiguilles, qui utilisent le protocole ESC/P, voir pbmtoepson.

OPTIONS

L'entrée est lue depuis le fichier fichierpbm s'il est spécifié, sinon depuis stdin. La sortie est écrite sur stdout.

-compress=modecompression
Ceci détermine le mode de compression que pbmtoescp2 utilise dans sa sortie. Les valeurs valides pour modecompression sont 0 et 1. -compress=0 donne un flux de contrôle d'imprimante avec des données graphiques matricielles non compressées. -compress=1 donne un flux de contrôle d'imprimante avec des données graphiques matricielles compressées RLE (RLE signifie Run Length Encoding - Encodage par longueur de course). La valeur par défaut est -compress=1.
-resolution=dpi
Ceci détermine la résolution d'impression horizontale et verticale définie dans le flux de contrôle de l'imprimante. Une autre façon de le voir est une déclaration de la résolution de l'image d'entrée (les images PBM n'ont pas de résolution intrinsèque). Les valeurs valides pour dpi sont 180 et 360. Voir indices pour plus d'informations à ce sujet.

La valeur par défaut est -resolution=360.

INDICES

Le RLE compresse très bien les bitmaps de dessins au trait, de préférence les contenus orientés horizontalement comme les textes, les partitions de musique, etc. Cependant, les bitmaps dérivés de photographies ne sont pas idéaux pour le RLE. Dans les cas extrêmes, lorsqu'aucune répétition d'octet ne se produit dans l'entrée, le résultat sera même légèrement plus grand que l'entrée. Pour éviter cela, utilisez le mode de compression 0 pour désactiver le RLE.

Chaque pixel de l'image PBM d'entrée devient un point dans la sortie imprimée. Par conséquent, vous devez vous assurer que la largeur et la hauteur de l'entrée sont appropriées à la résolution d'impression que vous choisissez et à la zone d'impression souhaitée. Par exemple, si vous imprimez à 180 dpi et que vous souhaitez que l'image s'imprime sur 8 pouces par 10, vous devez fournir un PBM de 1440 pixels de large par 1800 pixels de haut. Vous pouvez ajuster la taille de l'entrée avec pamscale, pamstretch, pbmreduce, ou pamenlarge.
