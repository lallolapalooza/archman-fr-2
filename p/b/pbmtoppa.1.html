NOM

pbmtoppa - convertir une image PBM en HP Printer Performance Architecture (PPA)

SYNTAXE

pbmtoppa [fichier_pbm [fichier_ppa]]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pbmtoppa convertit les images de page au format PBM en format PPA (Printer Performance Architecture) de Hewlett Packard, qui est le flux de données attendu par certaines imprimantes HP « uniquement sous Windows », notamment les séries HP Deskjet 820C, les séries HP DeskJet 720 et les séries HP DeskJet 1000.

fichier_pbm est la spécification du fichier d'entrée ou - pour l'entrée standard. Par défaut, il s'agit de l'entrée standard.

Le fichier d'entrée contient une ou plusieurs images PBM, chacune représentant une seule page. Chaque image doit avoir les dimensions exactes d'une page (à 600 pixels par pouce dans les deux directions). Notamment, c'est le format que produit Ghostscript.

fichier_ppa est la spécification du fichier de sortie ou - pour la sortie standard. Par défaut, il s'agit de la sortie standard.

Pour imprimer du Postscript sur une imprimante HP PPA, utilisez simplement Ghostscript avec le pilote de périphérique pbmraw (ou pbm).

Vous pouvez générer une page de test à utiliser avec ce programme avec pbmpage.

Vous pouvez également configurer un filtre d'impression afin de pouvoir soumettre directement des entrées PBM à votre file d'attente d'impression. Consultez la documentation de votre système d'impression pour savoir comment faire, ou regardez dans hp820install.doc pour un exemple de filtre d'impression lpr pour les fichiers Postscript et texte.

Parfois, pbmtoppa génère un fichier que l'imprimante n'imprime pas (car l'entrée de pbmtoppa est non imprimable). Lorsque cela se produit, les trois voyants clignotent pour signaler l'erreur. Cela est généralement dû au fait qu'il y a du contenu en dehors de la zone imprimable de l'imprimante. Pour que le fichier s'imprime, augmentez les marges via les options de pbmtoppa ou un fichier de configuration. Voir la section sur le calibrage ci-dessous.

À propos du PPA

Le langage d'imprimante PPA est un langage beaucoup plus bas niveau que la plupart des autres. Lorsque vous utilisez une imprimante PPA, la majeure partie du traitement qu'une imprimante conventionnelle effectue est plutôt réalisée côté ordinateur. En particulier, pbmtoppa doit effectuer la « découpe en bandes » et le « formatage par balayage », que d'autres imprimantes font elles-mêmes. Il y a très peu d'intelligence à l'intérieur d'une imprimante PPA ; pbmtoppa génère des contrôles directs pour le matériel de l'imprimante.

L'objectif de conception du PPA était de réduire le coût d'une imprimante en exploitant les ressources informatiques déjà présentes dans l'ordinateur qui demande l'impression. Les exigences en matière de puissance CPU, de ROM et de RAM dans l'imprimante sont toutes réduites par rapport à une imprimante conventionnelle.

Le PPA était nouveau en 1997. Il a été précédé par le langage PCL (Printer Control Language) de Hewlett Packard. HP n'a fabriqué des imprimantes PPA que pendant quelques années, et personne d'autre ne l'a jamais fait.

OPTIONS

-v version
version de l'imprimante (720, 820 ou 1000)
-x xoff
ajustement du décalage horizontal en 1/600 de pouce.
-y yoff
ajustement du décalage vertical en 1/600 de pouce.
-t marge_haut
marge supérieure en 1/600 de pouce (par défaut : 150 = 0,25 pouce)
-l marge_gauche
marge gauche en 1/600 de pouce (par défaut : 150 = 0,25 pouce)
-r marge_droite
marge droite en 1/600 de pouce (par défaut : 150 = 0,25 pouce)
-b marge_bas
marge inférieure en 1/600 de pouce (par défaut : 150 = 0,25 pouce)
-s papier
taille du papier : us ou a4. Par défaut : us.
-d dpi
Résolution d'impression en points par pouce.
-f fichier_cfg
Lire les paramètres à partir du fichier de configuration nommé fichier_cfg. Voir FICHIERS DE CONFIGURATION

Les ajustements de décalage que vous spécifiez avec -x et -y s'accumulent. C'est-à-dire si vous les spécifiez plusieurs fois, le décalage total est la somme des ajustements que vous spécifiez. -x 60 -x 120 est identique à -x 180.

L'option -v annule toutes les options -x et -y précédentes, laissant les ajustements horizontal et vertical à leurs valeurs par défaut.

FICHIERS DE CONFIGURATION

Vous pouvez utiliser un fichier de configuration pour spécifier des paramètres au lieu d'utiliser des options d'invocation. pbmtoppa traite le fichier /etc/pbmtoppa.conf, s'il existe, avant de traiter les options. Il traite ensuite chaque fichier de configuration nommé par une option -f dans l'ordre, appliquant les paramètres du fichier de configuration comme s'ils étaient des options d'invocation utilisées à la place de l'option -f.

Les fichiers de configuration ont le format suivant :

#Commentaire
cle1 valeur1
cle2 valeur2
[etc.]

Les clés valides sont version, xoffset, yoffset, topmargin, leftmargin, rightmargin, bottommargin, papersize, ou tout préfixe non nul de ces mots. Les valeurs valides sont les mêmes que pour les paramètres d'invocation correspondants.

EXEMPLES

Imprimer un motif de test :

pbmpage | pbmppa >/dev/lp1

Imprimer trois pages :

cat page1.pbm page2.pbm page3.pbm | pbmppa >/dev/lp1

Imprimer le fichier Postscript myfile.ps :

gs -sDEVICE=rawpbm -q -dNOPAUSE -r600 \
   -sOutputFile=- myfile.ps ;\
| pbmtoppa | lpr

CALIBRAGE

Pour pouvoir imprimer avec succès et correctement, vous devez indiquer à pbmtoppa un décalage X et Y approprié pour que votre imprimante l'utilise lors de la génération de la page. Vous pouvez spécifier ces décalages avec les options d'invocation -x et -y ou avec les paramètres xoff et yoff dans un fichier de configuration pbmtoppa.

Pour déterminer les décalages corrects, utilisez le programme pbmpage.

Si, lors de cette tentative de calibrage, l'imprimante refuse d'imprimer une page, mais fait simplement clignoter les trois voyants, spécifiez de grandes marges (par exemple, 600 pixels – un pouce) via les options d'invocation de pbmpage pendant le calibrage.

Par exemple :

pbmpage | pbmtoppa >/dev/lp1
ou 
pbmpage | pbmtoppa | lpr -l

(si votre filtre d'impression reconnaît le paramètre '-l' (sortie directe)).

Dans le motif de test, la grille est marquée avec des numéros de coordonnées en pixels. Malheureusement, ces coordonnées sont probablement coupées avant le bord du papier. Vous devrez utiliser une règle pour estimer la coordonnée en pixels des bords gauche et supérieur de la feuille de papier réelle (devrait être dans +/- 300, peut être négatif ; il y a 600 pixels par pouce).

Ajoutez ces coordonnées aux décalages X et Y soit en modifiant le fichier de configuration, soit en utilisant les paramètres de ligne de commande -x et -y.

Lorsque pbmtoppa est correctement calibré, le repère central doit se trouver au centre du papier. De plus, les marges devraient pouvoir être aussi petites que 0,25 pouce sans provoquer le blocage de l'imprimante avec le « syndrome des voyants clignotants ».

INSTALLATION RED HAT LINUX

Les utilisateurs de RedHat pourraient trouver utile le conseil suivant de Panayotis Vryonis <vrypan@hol.gr>. La même chose devrait fonctionner pour les 820 et 1000, mais cela n'a pas été testé. Utilisez également le pilote GSDriver pbmraw si vous l'avez ; il est plus rapide.

Voici une astuce pour intégrer le support HP720C dans le printtool de RedHat :

Installez pbmtoppa. Copiez pbmtoppa dans /usr/bin.

Modifiez 'printerdb' (sur mon système, il se trouve dans /usr/lib/rhs/rhs-printfilters) et ajoutez les lignes suivantes :

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

----------------------Coupez ici----------------------- StartEntry: DeskJet720C GSDriver: pbm Description: {HP DeskJet 720C} About: { \ Ce pilote pilote l'imprimante jet d'encre HP DeskJet 720C. \ Il ne prend pas en charge l'impression couleur. \ IMPORTANT ! Insérez \ '- | pbm2ppa -' \ dans le champ 'Options GS supplémentaires'.\ } Resolution: {600} {600} {} EndEntry ----------------------------------------------------

Vous pouvez maintenant ajouter une imprimante HP720C comme n'importe quelle autre, en utilisant printtool.

VOIR AUSSI

pbmpage(1) , pstopnm(1) , pbm(5)

Ce programme est dérivé de pbm2ppa. pbm2ppa est obsolète et a été remplacé par pnm2ppa, qui fait les mêmes choses que pbmtoppa, sauf qu'il fonctionne également avec la couleur et possède beaucoup plus de fonctionnalités. Voir http://pnm2ppa.sourceforge.net pour plus d'informations sur le protocole PPA et le programme pnm2ppa distribué séparément.

Le fichier INSTALL-MORE dans le répertoire pbmtoppa du code source de Netpbm contient des instructions détaillées sur la configuration d'un système pour utiliser pbmtoppa afin de permettre une impression pratique sur les imprimantes HP PPA. Il a été écrit par Michael Buehlmann.
