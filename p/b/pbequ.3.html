sous-routine cpbequ (caractère uplo, entier n, entier kd, complexe, dimension( ldab, * ) ab, entier ldab, réel, dimension( * ) s, réel scond, réel amax, entier info)

CPBEQU

Objectif:

!>
!> CPBEQU calcule les échelles de lignes et de colonnes destinées à équilibrer une
!> matrice bande hermitienne définie positive A et à réduire son nombre de conditionnement
!> (par rapport à la norme des deux). S contient les facteurs d'échelle,
!> S(i) = 1/sqrt(A(i,i)), choisis de telle sorte que la matrice mise à l'échelle B avec
!> les éléments B(i,j) = S(i)*A(i,j)*S(j) ait des uns sur la diagonale. Ce
!> choix de S place le nombre de conditionnement de B dans un facteur N du
!> plus petit nombre de conditionnement possible sur toutes les échelles diagonales
!> possibles.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  La partie triangulaire supérieure de A est stockée ;
!>          = 'L':  La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'. KD >= 0.
!>

AB

!>          AB est un tableau COMPLEXE, de dimension (LDAB,N)
!>          La partie supérieure ou inférieure de la matrice bande hermitienne A,
!>          stockée dans les KD+1 premières lignes du tableau. La j-ème colonne
!>          de A est stockée dans la j-ème colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau A. LDAB >= KD+1.
!>

S

!>          S est un tableau RÉEL, de dimension (N)
!>          Si INFO = 0, S contient les facteurs d'échelle pour A.
!>

SCOND

!>          SCOND est RÉEL
!>          Si INFO = 0, S contient le rapport du plus petit S(i) au
!>          plus grand S(i). Si SCOND >= 0.1 et AMAX n'est ni trop
!>          grand ni trop petit, il n'est pas utile de mettre à l'échelle avec S.
!>

AMAX

!>          AMAX est RÉEL
!>          La valeur absolue de l'élément de matrice le plus grand. Si AMAX est très
!>          proche du débordement ou très proche du sous-dépassement, la matrice
!>          devrait être mise à l'échelle.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0:  si INFO = i, le i-ème élément diagonal est non positif.
!>
