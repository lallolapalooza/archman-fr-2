pbzip2(1) Manuel des commandes générales pbzip2(1)

NOM

pbzip2 - compresseur de fichiers bzip2 parallèle, v1.1.10

SYNTAXE

pbzip2 [ -123456789 ] [ -b#cdfhklm#p#qrS#tvVz ] [ noms de fichiers ... ]

DESCRIPTION

pbzip2 est une implémentation parallèle du compresseur de fichiers de tri par blocs bzip2 qui utilise des pthreads et atteint une accélération quasi linéaire sur les machines SMP. La sortie de cette version est entièrement compatible avec bzip2 v1.0.2 ou plus récent (c'est-à-dire que tout ce qui est compressé avec pbzip2 peut être décompressé avec bzip2).

pbzip2 devrait fonctionner sur tout système disposant d'un compilateur C++ compatible pthreads (tel que gcc). Il a été testé sur : Linux, Windows (cygwin), Solaris, Tru64/OSF1, HP-UX et Irix.

Les paramètres par défaut de pbzip2 fonctionneront bien dans la plupart des cas. Le seul commutateur que vous aurez probablement besoin d'utiliser est -d pour décompresser les fichiers et -p pour définir le nombre de processeurs que pbzip2 doit utiliser si la détection automatique n'est pas prise en charge sur votre système, ou si vous souhaitez utiliser un nombre spécifique de CPU.

OPTIONS

-b#
Où # est la taille du bloc par pas de 100k (par défaut 9 = 900k)
-c, --stdout
Sortie vers la sortie standard (stdout)
-d,--decompress
Décompresser le fichier
-f,--force
Forcer, écraser le fichier de sortie existant
-h,--help
Afficher ce message d'aide
-k,--keep
Conserver le fichier d'entrée, ne pas le supprimer
-l,--loadavg
La charge moyenne détermine le nombre maximum de processeurs à utiliser
-m#
Où # est l'utilisation maximale de la mémoire par pas de 1 Mo (par défaut 100 = 100 Mo)
-p#
Où # est le nombre de processeurs (par défaut : détection automatique)
-q,--quiet
Mode silencieux (par défaut)
-r,--read
Lire l'intégralité du fichier d'entrée en RAM et le diviser entre les processeurs
-S#
Taille de la pile du thread enfant par pas de 1 Ko (taille de pile par défaut si non spécifiée)
-t,--test
Tester l'intégrité du fichier compressé
-v,--verbose
Mode verbeux
-V
Afficher les informations de version pour pbzip2 puis quitter
-z,--compress
Compresser le fichier (par défaut)
-1,--fast ... -9,--best
Définir la taille du bloc BWT de 100k à 900k (par défaut 900k).
--ignore-trailing-garbage=#
Indicateur d'ignorance des caractères de remplissage finaux (1 - ignoré ; 0 - interdit)

Si aucun nom de fichier n'est donné, pbzip2 compresse ou décompresse de l'entrée standard vers la sortie standard.

TAILLES DE FICHIERS

Vous devriez être capable de compresser des fichiers de plus de 4 Go avec pbzip2.

Les fichiers compressés avec pbzip2 sont divisés en morceaux et chaque morceau individuel est compressé. C'est ainsi que pbzip2 fonctionne plus rapidement sur plusieurs CPU, car les morceaux peuvent être compressés simultanément. Le fichier .bz2 final peut être légèrement plus grand que s'il avait été compressé avec le programme bzip2 régulier (généralement moins de 0,2 % plus grand). Les fichiers compressés avec pbzip2 bénéficieront également d'une accélération considérable lorsqu'ils seront décompressés avec pbzip2.

Les fichiers compressés avec bzip2 ne bénéficieront pas d'une accélération car bzip2 emballe les données dans un seul bloc qui ne peut pas être divisé entre les processeurs.

EXEMPLES

Exemple 1 : pbzip2 myfile.tar

Cet exemple compressera le fichier "myfile.tar" dans le fichier compressé "myfile.tar.bz2". Il utilisera le nombre de processeurs détecté automatiquement (ou 2 processeurs si la détection automatique n'est pas prise en charge) avec la taille de bloc de fichier par défaut de 900k et la taille de bloc BWT par défaut de 900k.

Exemple 2 : pbzip2 -b15k myfile.tar

Cet exemple compressera le fichier "myfile.tar" dans le fichier compressé "myfile.tar.bz2". Il utilisera le nombre de processeurs détecté automatiquement (ou 2 processeurs si la détection automatique n'est pas prise en charge) avec une taille de bloc de fichier de 1500k et une taille de bloc BWT de 900k. Le fichier "myfile.tar" ne sera pas supprimé une fois la compression terminée.

Exemple 3 : pbzip2 -p4 -r -5 myfile.tar second*.txt

Cet exemple compressera le fichier "myfile.tar" dans le fichier compressé "myfile.tar.bz2". Il utilisera 4 processeurs avec une taille de bloc BWT de 500k. La taille du bloc de fichier sera la taille de "myfile.tar" divisée par 4 (nombre de processeurs) afin que les données soient réparties uniformément entre chaque processeur. Cela nécessite que vous ayez suffisamment de RAM pour que pbzip2 puisse lire l'intégralité du fichier en mémoire pour la compression. Pbzip2 utilisera ensuite les mêmes options pour compresser tous les autres fichiers correspondant au caractère générique "second*.txt" dans ce répertoire.

Exemple 4 : tar cf myfile.tar.bz2 --use-compress-prog=pbzip2 dir_to_compress/
Exemple 4 : tar -c directory_to_compress/ | pbzip2 -c > myfile.tar.bz2

Ces exemples compresseront les données transmises à pbzip2 via un pipe depuis TAR dans le fichier compressé "myfile.tar.bz2". Il utilisera le nombre de processeurs détecté automatiquement (ou 2 processeurs si la détection automatique n'est pas prise en charge) avec la taille de bloc de fichier par défaut de 900k et la taille de bloc BWT par défaut de 900k. TAR collecte tous les fichiers du répertoire "directory_to_compress/" et transmet les données à pbzip2 pendant son exécution.

Exemple 5 : pbzip2 -d -m500 myfile.tar.bz2

Cet exemple décompressera le fichier "myfile.tar.bz2" dans le fichier décompressé "myfile.tar". Il utilisera le nombre de processeurs détecté automatiquement (ou 2 processeurs si la détection automatique n'est pas prise en charge). Il utilisera un maximum de 500 Mo de mémoire pour la décompression. Les commutateurs -b, -r et -1..-9 ne sont pas valides pour la décompression.

Exemple 6 : pbzip2 -dc myfile.tar.bz2 | tar x

Cet exemple décompressera et extraira le fichier "myfile.tar.bz2" en transmettant la sortie de pbzip2 en cours de décompression à tar.

Exemple 7 : pbzip2 -c < myfile.txt > myfile.txt.bz2

Cet exemple lira myfile.txt depuis l'entrée standard, le compressera vers la sortie standard qui sera redirigée vers myfile.txt.bz2.
