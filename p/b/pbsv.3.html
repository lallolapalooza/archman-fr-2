sous-routine cpbsv (character uplo, integer n, integer kd, integer nrhs, complex, dimension( ldab, * ) ab, integer ldab, complex, dimension( ldb, * ) b, integer ldb, integer info)

CPBSV calcule la solution du système d'équations linéaires A * X = B pour les matrices OTHER

Objectif :

!>
!> CPBSV calcule la solution d'un système d'équations linéaires complexes
!>    A * X = B,
!> où A est une matrice bande hermitienne définie positive N x N et X
!> et B sont des matrices N x NRHS.
!>
!> La décomposition de Cholesky est utilisée pour factoriser A comme suit :
!>    A = U**H * U,  si UPLO = 'U', ou
!>    A = L * L**H,  si UPLO = 'L',
!> où U est une matrice bande triangulaire supérieure et L est une matrice bande triangulaire inférieure, avec le même nombre de superdiagonales ou de sous-diagonales que A. La forme factorisée de A est ensuite utilisée pour résoudre le système d'équations A * X = B.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U' : La partie triangulaire supérieure de A est stockée ;
!>          = 'L' : La partie triangulaire inférieure de A est stockée.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B.  NRHS >= 0.
!>

AB

!>          AB est un tableau COMPLEX de dimension (LDAB,N)
!>          À l'entrée, la partie triangulaire supérieure ou inférieure de la matrice bande hermitienne
!>          A, stockée dans les KD+1 premières lignes du tableau. La
!>          j-ème colonne de A est stockée dans la j-ème colonne du tableau AB
!>          comme suit :
!>          si UPLO = 'U', AB(KD+1+i-j,j) = A(i,j) pour max(1,j-KD) <= i <= j ;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j <= i <= min(N,j+KD).
!>          Voir ci-dessous pour plus de détails.
!>
!>          À la sortie, si INFO = 0, le facteur triangulaire U ou L de la
!>          décomposition de Cholesky A = U**H*U ou A = L*L**H de la matrice bande
!>          A, dans le même format de stockage que A.
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

B

!>          B est un tableau COMPLEX de dimension (LDB,NRHS)
!>          À l'entrée, la matrice B des seconds membres N x NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N x NRHS.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, le mineur principal de tête d'ordre i
!>                de A n'est pas positif, donc la décomposition n'a pas pu
!>                être achevée et la solution n'a pas été calculée.
!>

NAME

dpbsv, spbsv, zpbsv - solve a system of linear equations A * X = B for a symmetric or Hermitian positive definite band matrix

SYNOPSIS

SUBROUTINE DPBSV( UPLO, N, KD, NRHS, AB, LDAB, B, LDB, INFO )
    CHARACTER    UPLO
    INTEGER      KD, INFO, LDB, LDAB, N, NRHS
    DOUBLE PRECISION AB( LDAB, * ), B( LDB, * )

SUBROUTINE SPBSV( UPLO, N, KD, NRHS, AB, LDAB, B, LDB, INFO )
    CHARACTER    UPLO
    INTEGER      KD, INFO, LDB, LDAB, N, NRHS
    REAL         AB( LDAB, * ), B( LDB, * )

SUBROUTINE ZPBSV( UPLO, N, KD, NRHS, AB, LDAB, B, LDB, INFO )
    CHARACTER    UPLO
    INTEGER      KD, INFO, LDB, LDAB, N, NRHS
    COMPLEX*16   AB( LDAB, * ), B( LDB, * )

DESCRIPTION

The routines compute the solution to a system of linear equations A * X = B for a symmetric or Hermitian positive definite band matrix A. The Cholesky decomposition is used to factor A as follows:

    A = U**T * U,  if UPLO = 'U', or
    A = L * L**T,  if UPLO = 'L',

for DPBSV and SPBSV, where U is an upper triangular band matrix and L is a lower triangular band matrix. For ZPBSV:

    A = U**H * U,  if UPLO = 'U', or
    A = L * L**H,  if UPLO = 'L',

where U is an upper triangular band matrix and L is a lower triangular band matrix. U (or L) has the same number of superdiagonals (or subdiagonals) as A. The factored form of A is then used to solve the system of equations A * X = B.

subroutine dpbsv (character uplo, integer n, integer kd, integer nrhs, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( ldb, * ) b, integer ldb, integer info)

DPBSV computes the solution to system of linear equations A * X = B for OTHER matrices

Purpose:

!>
!> DPBSV computes the solution to a double precision system of linear equations
!>    A * X = B,
!> where A is an N-by-N symmetric positive definite band matrix and X
!> and B are N-by-NRHS matrices.
!>
!> The Cholesky decomposition is used to factor A as
!>    A = U**T * U,  if UPLO = 'U', or
!>    A = L * L**T,  if UPLO = 'L',
!> where U is an upper triangular band matrix, and L is a lower
!> triangular band matrix, with the same number of superdiagonals or
!> subdiagonals as A.  The factored form of A is then used to solve the
!> system of equations A * X = B.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!>

N

!>          N is INTEGER
!>          The number of linear equations, i.e., the order of the
!>          matrix A.  N >= 0.
!>

KD

!>          KD is INTEGER
!>          The number of superdiagonals of the matrix A if UPLO = 'U',
!>          or the number of subdiagonals if UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrix B.  NRHS >= 0.
!>

AB

!>          AB is DOUBLE PRECISION array, dimension (LDAB,N)
!>          On entry, the upper or lower triangle of the symmetric band
!>          matrix A, stored in the first KD+1 rows of the array.  The
!>          j-th column of A is stored in the j-th column of the array AB
!>          as follows:
!>          if UPLO = 'U', AB(KD+1+i-j,j) = A(i,j) for max(1,j-KD)<=i<=j;
!>          if UPLO = 'L', AB(1+i-j,j)    = A(i,j) for j<=i<=min(N,j+KD).
!>          See below for further details.
!>
!>          On exit, if INFO = 0, the triangular factor U or L from the
!>          Cholesky factorization A = U**T*U or A = L*L**T of the band
!>          matrix A, in the same storage format as A.
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of the array AB.  LDAB >= KD+1.
!>

B

!>          B is DOUBLE PRECISION array, dimension (LDB,NRHS)
!>          On entry, the N-by-NRHS right hand side matrix B.
!>          On exit, if INFO = 0, the N-by-NRHS solution matrix X.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, the leading principal minor of order i
!>                of A is not positive, so the factorization could not
!>                be completed, and the solution has not been computed.
!>

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

!>  The band storage scheme is illustrated by the following example, when
!>  N = 6, KD = 2, and UPLO = 'U':
!>
!>  On entry:                       On exit:
!>
!>      *    *   a13  a24  a35  a46      *    *   u13  u24  u35  u46
!>      *   a12  a23  a34  a45  a56      *   u12  u23  u34  u45  u56
!>     a11  a22  a33  a44  a55  a66     u11  u22  u33  u44  u55  u66
!>
!>  Similarly, if UPLO = 'L' the format of A is as follows:

!>  On entry:                       On exit:
!>
!>     a11  a22  a33  a44  a55  a66     l11  l22  l33  l44  l55  l66
!>     a21  a32  a43  a54  a65   *      l21  l32  l43  l54  l65   *
!>     a31  a42  a53  a64   *    *      l31  l42  l53  l64   *    *

ALGORITHME

PBsv utilise la factorisation de Cholesky pour décomposer la matrice A. Comme A est une matrice bande, la décomposition de Cholesky est effectuée par la routine PB de LAPACK.

Les étapes sont les suivantes :

  1. Factorisation de Cholesky : A = UHU (ou A = LLH).
  2. Substitution avant : Résolution de LU = B.
  3. Substitution arrière : Résolution de UHX = Y.

DESCRIPTION

PBsv calcule la solution X du système d'équations linéaires Ax = B, où A est une matrice bande symétrique définie positive d'ordre N, et B est une matrice N par NRHS. La matrice bande A est représentée dans un tableau AB.

Les entrées sont :

UPLO
Caractère. Spécifie si la partie supérieure ou inférieure de la matrice bande A est stockée dans le tableau AB.
U = 'U' : La partie supérieure est stockée.
L = 'L' : La partie inférieure est stockée.
N
Entier. L'ordre de la matrice A. N ≥ 0.
KD
Entier. Le nombre de diagonales au-dessus ou au-dessous de la diagonale principale. KD ≥ 0.
NRHS
Entier. Le nombre de colonnes de la matrice B. NRHS ≥ 0.
AB
Tableau (matrice). Représentation de la matrice bande A. La dimension est LDAB x N.
Si UPLO = 'U', AB contient la diagonale supérieure et KD diagonales au-dessus. AB(KD+1, j) contient l'élément A(j,j).
Si UPLO = 'L', AB contient la diagonale inférieure et KD diagonales en dessous. AB(1, j) contient l'élément A(j,j).
LDAB
Entier. Longueur de ligne du tableau AB. LDAB ≥ KD+1.
B
Tableau (matrice). Sur l'entrée, le tableau B contient la matrice de second membre.
Sur la sortie, B est remplacé par la matrice solution X.
La dimension est LDB x max(1, NRHS).
LDB
Entier. Longueur de ligne du tableau B. LDB ≥ max(1, N).
INFO
Entier.
  • INFO = 0 : Exécution réussie.
  • INFO < 0 : Si INFO = -i, alors le i-ème argument avait une valeur illégale.
  • INFO > 0 : Si INFO = i, alors la factorisation a échoué. Le élément i de la diagonale principale de la matrice triangulaire est zéro, donc la matrice n'est pas définie positive.
