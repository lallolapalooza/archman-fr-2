CPBCON

Objectif :

!>
!> CPBCON estime la réciproque du nombre de conditionnement (en
!> norme 1) d'une matrice bande complexe hermitienne définie positive,
!> en utilisant la factorisation de Cholesky A = U**H*U ou A = L*L**H
!> calculée par CPBTRF.
!>
!> Une estimation de norm(inv(A)) est obtenue, et la réciproque du
!> nombre de conditionnement est calculée comme RCOND = 1 / (ANORM * norm(inv(A))).
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  Facteur triangulaire supérieur stocké dans AB;
!>          = 'L':  Facteur triangulaire inférieur stocké dans AB.
!>

N

!>          N est INTEGER
!>          Ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB est un tableau COMPLEX, de dimension (LDAB,N)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**H*U ou A = L*L**H de la matrice bande A, stocké dans les
!>          KD+1 premières lignes du tableau. La j-ème colonne de U ou L est
!>          stockée dans la j-ème colonne du tableau AB comme suit:
!>          si UPLO ='U', AB(kd+1+i-j,j) = U(i,j) pour max(1,j-kd)<=i<=j;
!>          si UPLO ='L', AB(1+i-j,j)    = L(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

ANORM

!>          ANORM est REAL
!>          La norme 1 (ou norme infinie) de la matrice bande hermitienne A.
!>

RCOND

!>          RCOND est REAL
!>          La réciproque du nombre de conditionnement de la matrice A,
!>          calculée comme RCOND = 1/(ANORM * AINVNM), où AINVNM est une
!>          estimation de la norme 1 de inv(A) calculée dans cette routine.
!>

WORK

!>          WORK est un tableau COMPLEX, de dimension (2*N)
!>

RWORK

!>          RWORK est un tableau REAL, de dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

NAME

    
pbcon - estimates the reciprocal of the condition number of a symmetric/Hermitian positive definite band matrix.

Detailed Description

    
This routine estimates the reciprocal of the condition number of a
    band matrix A, in which A11, ..., Ass have been computed by ZPBTRF.
    The condition number of A is defined as the ratio of the 1-norm of A to the
    1-norm of its inverse.

    
This routine estimates norm(inv(A)), and RCOND = 1 / (ANORM *
    norm(inv(A)))

subroutine   spbcon (character uplo, integer n, integer kd, real, dimension( ldab, *   ) ab, integer ldab, real anorm, real rcond,   real, dimension( * ) work, integer info)

        
SPBCON

        
Purpose:

        

            
!>
!> SPBCON estimates the reciprocal of the condition number (in the
!> 1-norm) of a real symmetric positive definite band matrix using
!> the Cholesky factorization A = U**T*U or A = L*L**T computed by
!> SPBTRF.
!>
!> An estimate is obtained for norm(inv(A)), and the reciprocal of the
!> condition number is computed as RCOND = 1 / (ANORM * AINVNM), where AINVNM is an
!> estimate of the 1-norm of inv(A) computed in this routine.
!> 

        

        
Parameters

        
UPLO
            
!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangular factor stored in AB;
!>          = 'L':  Lower triangular factor stored in AB.
!> 

            
N

            
!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!> 

            
KD

            
!>          KD is INTEGER
!>          The number of superdiagonals of the matrix A if UPLO = 'U',
!>          or the number of subdiagonals if UPLO = 'L'.  KD >= 0.
!> 

            
AB

            
!>          AB is REAL array, dimension (LDAB,N)
!>          The triangular factor U or L from the Cholesky factorization
!>          A = U**T*U or A = L*L**T of the band matrix A, stored in the
!>          first KD+1 rows of the array.  The j-th column of U or L is
!>          stored in the j-th column of the array AB as follows:
!>          if UPLO ='U', AB(kd+1+i-j,j) = U(i,j) for max(1,j-kd)<=i<=j;
!>          if UPLO ='L', AB(1+i-j,j)    = L(i,j) for j<=i<=min(n,j+kd).
!> 

            
LDAB

            
!>          LDAB is INTEGER
!>          The leading dimension of the array AB.  LDAB >= KD+1.
!> 

            
ANORM

            
!>          ANORM is REAL
!>          The 1-norm (or infinity-norm) of the symmetric band matrix A.
!> 

            
RCOND

            
!>          RCOND is REAL
!>          The reciprocal of the condition number of the matrix A,
!>          computed as RCOND = 1/(ANORM * AINVNM), where AINVNM is an
!>          estimate of the 1-norm of inv(A) computed in this routine.
!> 

            
WORK

            
!>          WORK is REAL array, dimension (3*N)
!> 

            
INFO

            
!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
