NOM

pbibtex, upbibtex - créer une bibliographie (japonaise) pour (La)TeX

SYNOPIS

pbibtex [options] nom_aux*[.aux]

DESCRIPTION

pBibTeX (pbibtex) est une version modifiée de BibTeX pour la gestion du japonais. Il trie les entrées selon les points de code EUC-JP. De plus, une nouvelle fonction intégrée is.kanji.str$ qui détermine si une entrée est en dehors de l'ASCII est introduite.

upBibTeX (upbibtex) est une version modifiée de pBibTeX, qui trie les entrées selon les points de code Unicode.

Extensions des fonctions de style bibliographique

Une nouvelle fonction intégrée est disponible, et certaines autres fonctions sont modifiées pour simplifier la gestion du japonais.

is.kanji.str$
[Nouvelle fonctionnalité] Retire le littéral (chaîne) supérieur pour voir s'il contient des caractères non-ASCII. Pousse 1 s'il en contient au moins un, 0 sinon.
substring$
Modifiée pour éviter de diviser une chaîne de caractères au milieu d'un caractère multibyte.
text.prefix$
Modification similaire à substring$ décrite ci-dessus.
add.period$
Modifiée pour empêcher l'ajout de "." après les ponctuations japonaises correspondant à "!", "?" et "." (par exemple, U+FF01, U+FF1F, U+3002 et U+FF0E).
format.name$
Modifiée pour accepter l'espace idéographique zenkaku japonais (U+3000) pour les noms affichés en japonais. Également modifiée pour reconnaître les virgules japonaises (U+3001 et U+FF0C) de manière similaire à "et" entre les noms.

VOIR AUSSI

bibtex(1), ptex(1).

AUTEURS

La version japonaise de BibTeX a été initialement développée par Shouichi Matsui sous le nom de JBibTeX jusqu'en 1991. Elle a été développée pour se comporter de manière cohérente avec NTT JTeX dans la gestion des anciens encodages japonais. Les anciennes documentations jbibtex.pdf, jbtxdoc.tex, jbtxhak.tex (toutes disponibles dans TeX Live) décrivent les capacités de gestion du japonais et quelques notes supplémentaires sur JBibTeX.

La version actuelle (u)pBibTeX est une version dérivée de JBibTeX, et a remplacé la routine de conversion d'encodage par une compatible avec l'édition communautaire (u)pTeX utilisant la bibliothèque ptexenc. Notez que les descriptions des encodages dans les anciennes documentations j*.pdf (en particulier la section 3.3 de jbibtex.pdf, tels que BIBTERMCODE et BIBFILECODE) sont obsolètes.
