CPBSVX calcule la solution du système d'équations linéaires A * X = B pour les matrices AUTRES

Objectif :

!>
!> CPBSVX utilise la factorisation de Cholesky A = U**H*U ou A = L*L**H pour
!> calculer la solution d'un système complexe d'équations linéaires
!>    A * X = B,
!> où A est une matrice bande hermitienne définie positive de taille N x N et X
!> et B sont des matrices de taille N x NRHS.
!>
!> Des bornes d'erreur sur la solution et une estimation de condition sont également
!> fournies.
!>

Description :

!>
!> Les étapes suivantes sont effectuées :
!>
!> 1. Si FACT = 'E', des facteurs d'échelle réels sont calculés pour équilibrer
!>    le système :
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    L'équilibrage du système sera effectué ou non en fonction de
!>    l'échelle de la matrice A, mais si l'équilibrage est utilisé, A est
!>    écrasé par diag(S)*A*diag(S) et B par diag(S)*B.
!>
!> 2. Si FACT = 'N' ou 'E', la décomposition de Cholesky est utilisée pour
!>    factoriser la matrice A (après équilibrage si FACT = 'E') comme
!>       A = U**H * U,  si UPLO = 'U', ou
!>       A = L * L**H,  si UPLO = 'L',
!>    où U est une matrice bande triangulaire supérieure, et L est une matrice bande triangulaire inférieure.
!>
!> 3. Si le mineur principal principal d'ordre i n'est pas positif,
!>    la routine renvoie INFO = i. Sinon, la forme factorisée de A
!>    est utilisée pour estimer le nombre de condition de la matrice
!>    A.  Si l'inverse du nombre de condition est inférieur à la précision machine,
!>    INFO = N+1 est renvoyé comme avertissement, mais la routine
!>    continue de résoudre pour X et de calculer les bornes d'erreur comme
!>    décrit ci-dessous.
!>
!> 4. Le système d'équations est résolu pour X en utilisant la forme factorisée
!>    de A.
!>
!> 5. Un raffinement itératif est appliqué pour améliorer la solution calculée
!>    la matrice et calculer les bornes d'erreur et les erreurs arrières
!>    pour celle-ci.
!>
!> 6. Si l'équilibrage a été utilisé, la matrice X est multipliée par pré-multiplication
!>    par diag(S) de sorte qu'elle résolve le système original avant
!>    l'équilibrage.
!>

Paramètres

FACT 
!>          FACT est CHARACTER*1
!>          Spécifie si la forme factorisée de la matrice A est fournie
!>          en entrée, et sinon, si la matrice A doit être équilibrée
!>          avant d'être factorisée.
!>          = 'F' : En entrée, AFB contient la forme factorisée de A.
!>                  Si EQUED = 'Y', la matrice A a été équilibrée
!>                  avec les facteurs d'échelle donnés par S.
!>                  AB et AFB ne seront pas modifiés.
!>          = 'N' : La matrice A sera copiée dans AFB et factorisée.
!>          = 'E' : La matrice A sera équilibrée si nécessaire, puis
!>                  copiée dans AFB et factorisée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A est stocké ;
!>          = 'L' : Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de
!>          la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de superdiagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de côtés droits, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

AB

!>          AB est un tableau COMPLEX de dimension (LDAB,N)
!>          En entrée, le triangle supérieur ou inférieur de la matrice bande hermitienne
!>          A, stocké dans les KD+1 premières lignes du tableau, sauf
!>          si FACT = 'F' et EQUED = 'Y', auquel cas A doit contenir la
!>          matrice équilibrée diag(S)*A*diag(S).  La j-ème colonne de A
!>          est stockée dans la j-ème colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(KD+1+i-j,j) = A(i,j) pour max(1,j-KD)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(N,j+KD).
!>          Voir ci-dessous pour plus de détails.
!>
!>          En sortie, si FACT = 'E' et EQUED = 'Y', A est écrasé par
!>          diag(S)*A*diag(S).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau A.  LDAB >= KD+1.
!>

AFB

!>          AFB est un tableau COMPLEX de dimension (LDAFB,N)
!>          Si FACT = 'F', alors AFB est un argument d'entrée et contient en entrée
!>          le facteur triangulaire U ou L de la décomposition de Cholesky
!>          A = U**H*U ou A = L*L**H de la matrice bande
!>          A, dans le même format de stockage que A (voir AB). Si EQUED = 'Y',
!>          alors AFB est la forme factorisée de la matrice A équilibrée.
!>
!>          Si FACT = 'N', alors AFB est un argument de sortie et renvoie en sortie
!>          le facteur triangulaire U ou L de la décomposition de Cholesky
!>          A = U**H*U ou A = L*L**H.
!>
!>          Si FACT = 'E', alors AFB est un argument de sortie et renvoie en sortie
!>          le facteur triangulaire U ou L de la décomposition de Cholesky
!>          de la matrice équilibrée A = U**H*U ou A = L*L**H (voir la description de A pour la forme de la
!>          matrice équilibrée).
!>

LDAFB

!>          LDAFB est INTEGER
!>          La dimension principale du tableau AFB.  LDAFB >= KD+1.
!>

EQUED

!>          EQUED est CHARACTER*1
!>          Spécifie la forme d'équilibrage qui a été effectuée.
!>          = 'N' : Aucun équilibrage (toujours vrai si FACT = 'N').
!>          = 'Y' : L'équilibrage a été effectué, c'est-à-dire que A a été remplacé par
!>                  diag(S) * A * diag(S).
!>          EQUED est un argument d'entrée si FACT = 'F' ; sinon, c'est un
!>          argument de sortie.
!>

S

!>          S est un tableau REAL de dimension (N)
!>          Les facteurs d'échelle pour A ; non accédé si EQUED = 'N'.  S est
!>          un argument d'entrée si FACT = 'F' ; sinon, S est un argument de sortie
!>



NAME


cpbsvx - compute the solution to a complex symmetric positive
definite band system of linear equations with error bounds and condition
estimate






SYNOPSIS


SUBROUTINE CPBSVX(FACT, UPLO, N, KD, NRHS, AB, LDAB, AFB, LDAFB, EQUED, S,
                 B, LDB, X, LDX, RCOND, FERR, BERR, WORK, RWORK, INFO)
      CHARACTER          FACT, UPLO
      INTEGER            N, KD, NRHS, LDAB, LDAFB, LDB, LDX, INFO
      COMPLEX            AB( LDAB, * ), AFB( LDAFB, * ), B( LDB, * ),
     $                   X( LDX, * ), WORK( * )
      REAL               S( * ), RCOND, FERR( * ), BERR( * ), RWORK( * )







DESCRIPTION


CPBSVX uses the Cholesky factorization A = U**H*U or A = L*L**H
    to compute the solution to a complex system of linear equations


A * X = B,


where A is an N-by-N symmetric positive definite band matrix and X
    and B are N-by-NRHS matrices. Error bounds on the solution and a condition
    estimate are also provided.


The following steps are performed:


    
  
  1. If FACT = 'E', real scaling factors are computed to
      equilibrate the system:
      
    diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
    
      Whether or not the system will be equilibrated depends on the scaling of
      the matrix A, but if equilibration is used, A is overwritten by
      diag(S)*A*diag(S) and B by diag(S)*B.
    2. 
  
  2. If FACT = 'N' or 'E', the Cholesky decomposition is used to
      factor the matrix A (after equilibration if FACT = 'E') as
      
    A = U**H * U, if UPLO = 'U', or
    
      
    A = L * L**H, if UPLO = 'L',
    
      where U is an upper triangular band matrix, and L is a lower triangular
      band matrix.
    3. 
  
  3. If the leading principal minor of order i is not positive,
      then the routine returns with INFO = i. Otherwise, the factored form of A
      is used to estimate the condition number of the matrix A. If the reciprocal
      of the condition number is less than machine epsilon, INFO = N+1 is
      returned as a warning, but the routine still goes on to solve for X and
      compute error bounds as described below.
    4. 
  
  4. The system of equations is solved for X using the factored form
      of A.
    5. 
  
  5. Iterative refinement is applied to improve the computed
      solution matrix and calculate error bounds and backward error estimates
      for it.
    6. 
  
  6. If equilibration was used, the matrix X is premultiplied by
      diag(S) so that it solves the original system before equilibration.
    7. 







PARAMETERS



  
FACT

  

    
FACT is CHARACTER*1

    
Specifies whether or not the factored form of the matrix A is
        supplied on entry, and if not, whether the matrix A should be
        equilibrated before it is factored.

    
= 'F': On entry, AFB contains the factored form of A. If EQUED =
        'Y', the matrix A has been equilibrated with scaling factors given by
        S. AB and AFB will not be modified.

    
= 'N': The matrix A will be copied to AFB and factored.

    
= 'E': The matrix A will be equilibrated if necessary, then
        copied to AFB and factored.

  

  
UPLO

  

    
UPLO is CHARACTER*1

    
= 'U': Upper triangle of A is stored.

    
= 'L': Lower triangle of A is stored.

  

  
N

  

    
N is INTEGER

    
The number of linear equations, i.e., the order of the
        matrix A. N >= 0.

  

  
KD

  

    
KD is INTEGER

    
The number of superdiagonals of the matrix A if UPLO = 'U',
        or the number of subdiagonals if UPLO = 'L'. KD >= 0.

  

  
NRHS

  

    
NRHS is INTEGER

    
The number of right-hand sides, i.e., the number of columns
        of the matrices B and X. NRHS >= 0.

  

  
AB

  

    
AB is COMPLEX array, dimension (LDAB,N)

    
On entry, the upper or lower triangle of the symmetric band
        matrix A, stored in the first KD+1 rows of the array, except if FACT =
        'F' and EQUED = 'Y', then A must contain the equilibrated matrix
        diag(S)*A*diag(S). The j-th column of A is stored in the j-th column
        of the array AB as follows:

    
if UPLO = 'U', AB(KD+1+i-j,j) = A(i,j) for max(1,j-KD)<=i<=j;

    
if UPLO = 'L', AB(1+i-j,j) = A(i,j) for j<=i<=min(N,j+KD).

    
See below for further details.

    
On exit, if FACT = 'E' and EQUED = 'Y', A is overwritten by
        diag(S)*A*diag(S).

  

  
LDAB

  

    
LDAB is INTEGER

    
The leading dimension of the array A. LDAB >= KD+1.

  

  
AFB

  

    
AFB is COMPLEX array, dimension (LDAFB,N)

    
If FACT = 'F', then AFB is an input argument and on entry
        contains the triangular factor U or L from the Cholesky factorization
        A = U**H*U or A = L*L**H of the band matrix A, in the same storage
        format as A (see AB). If EQUED = 'Y', then AFB is the factored form of
        the equilibrated matrix A.

    
If FACT = 'N', then AFB is an output argument and on exit
        returns the triangular factor U or L.

    
If FACT = 'E', then AFB is an output argument and on exit
        returns the triangular factor of the equilibrated matrix A.

  

  
LDAFB

  

    
LDAFB is INTEGER

    
The leading dimension of the array AFB. LDAFB >= KD+1.

  

  
EQUED

  

    
EQUED is CHARACTER*1

    
Describes on which row and column indices S was computed.

    
= 'N': None of the scaling were done.

    
= 'R': Row scaling was done; S contains the row scaling
        factors.

    
= 'C': Column scaling was done; S contains the column scaling
        factors.

    
= 'B': Both row and column scaling were done; S contains the
        equilibration constants used by both row and column scaling.

    
Used only if FACT = 'F'.

  

  
S

  

    
S is REAL array, dimension (N)

    
If FACT = 'F' and EQUED = 'R' or 'B', S is an input array,
        and S(i) is the scale factor used to equilibrate the i-th row of A.
        If FACT = 'F' and EQUED = 'C' or 'N', S is not used.

    
If FACT = 'E', S is an output array, and S(i) is the scale
        factor used to equilibrate the i-th row of A. Only the diagonal elements
        of the array are used if EQUED = 'N' or 'C'. S is not used if
        EQUED = 'N'.

    
If EQUED = 'Y' and FACT = 'F', the diagonal of A is multiplied
        by S. If FACT = 'E', the diagonal of A is multiplied by S. If FACT =
        'F' and EQUED = 'Y', the diagonal of A is multiplied by S.
        If FACT = 'E' and EQUED = 'Y', A is overwritten by diag(S)*A*diag(S).

    
This argument is used only when N > 0.

  

  
B

  

    
B is COMPLEX array, dimension (LDB,NRHS)

    
On entry, the N-by-NRHS right hand side matrix B.

    
On exit, if EQUED = 'N', B is not modified; if EQUED = 'Y',
        B is overwritten by diag(S) * B.

  

  
LDB

  

    
LDB is INTEGER

    
The leading dimension of the array B. LDB >= max(1,N).

  

  
X

  

    
X is COMPLEX array, dimension (LDX,NRHS)

    
If INFO = 0 or INFO = N+1, the N-by-NRHS solution matrix X to
        the original system of equations. Note that if EQUED = 'Y', A and B are
        modified on exit, and the solution to the equilibrated system is
        inv(diag(S))*X.

  

  
LDX

  

    
LDX is INTEGER

    
The leading dimension of the array X. LDX >= max(1,N).

  

  
RCOND

  

    
RCOND is REAL

    
The estimate of the reciprocal condition number of the matrix
        A after equilibration (if done). If RCOND is less than the machine
        precision (in particular, if RCOND = 0), the matrix is singular to
        working precision. This condition is indicated by a return code of INFO
        > 0.

  

  
FERR

  

    
FERR is REAL array, dimension (NRHS)

    
The estimated forward error bound for each solution vector
        X(j) (the j-th column of the solution matrix X). If XTRUE is the true
        solution corresponding to X(j), FERR(j) is an estimated upper bound for
        the magnitude of the largest element in (X(j) - XTRUE) divided by the
        magnitude of the largest element in X(j). The estimate is as reliable as
        the estimate for RCOND, and is almost always a slight overestimate of the
        true error.

  

  
BERR

  

    
BERR is REAL array, dimension (NRHS)

    
The componentwise relative backward error of each solution
        vector X(j) (i.e., the smallest relative change in any element of A or
        B that makes X(j) an exact solution).

  

  
WORK

  

    
WORK is COMPLEX array, dimension (2*N)

  

  
RWORK

  

    
RWORK is REAL array, dimension (N)

  

  
INFO

  

    
INFO is INTEGER

    
= 0: successful exit

    
< 0: if INFO = -i, the i-th argument had an illegal
        value

    
> 0: if INFO = i, and i is

    
i <= N: the leading principal minor of order i of A is not
        positive, so the factorization could not be completed, and the solution
        has not been computed. RCOND = 0 is returned.

    
= N+1: U is nonsingular, but RCOND is less than machine
        precision, meaning that the matrix is singular to working precision.
        Nevertheless, the solution and error bounds are computed because there
        are a number of situations where the computed solution can be more
        accurate than the value of RCOND would suggest.

FURTHER DETAILS


  The band storage scheme is illustrated by the following example, when
  N = 6, KD = 2, and UPLO = 'U':

  Two-dimensional storage of the symmetric matrix A:

     a11  a12  a13
          a22  a23  a24
               a33  a34  a35
                    a44  a45  a46
                         a55  a56
                              a66

  Band storage of the upper triangle of A:

      *    *   a13  a24  a35  a46
      *   a12  a23  a34  a45  a56
     a11  a22  a33  a44  a55  a66

  Array elements marked * are not used by the routine.

  Similarly, if UPLO = 'L' the format of A is as follows:

     a11  a22  a33  a44  a55  a66
     a21  a32  a43  a54  a65   *
     a31  a42  a53  a64   *    *

  Array elements marked * are not used by the routine.

zpbsvx computes the solution to system of linear equations A * X = B for OTHER matrices

Syntax

Purpose

!>
!> ZPBSVX uses the Cholesky factorization A = U**H*U or A = L*L**H to
!> compute the solution to a complex system of linear equations
!>    A * X = B,
!> where A is an N-by-N Hermitian positive definite band matrix and X
!> and B are N-by-NRHS matrices.
!>
!> Error bounds on the solution and a condition estimate are also
!> provided.
!>

Description

!>
!> The following steps are performed:
!>
!> 1. If FACT = 'E', real scaling factors are computed to equilibrate
!>    the system:
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    Whether or not the system will be equilibrated depends on the
!>    scaling of the matrix A, but if equilibration is used, A is
!>    overwritten by diag(S)*A*diag(S) and B by diag(S)*B.
!>
!> 2. If FACT = 'N' or 'E', the Cholesky decomposition is used to
!>    factor the matrix A (after equilibration if FACT = 'E') as
!>       A = U**H * U,  if UPLO = 'U', or
!>       A = L * L**H,  if UPLO = 'L',
!>    where U is an upper triangular band matrix, and L is a lower
!>    triangular band matrix.
!>
!> 3. If the leading principal minor of order i is not positive,
!>    then the routine returns with INFO = i. Otherwise, the factored
!>    form of A is used to estimate the condition number of the matrix
!>    A.  If the reciprocal of the condition number is less than machine
!>    precision, INFO = N+1 is returned as a warning, but the routine
!>    still goes on to solve for X and compute error bounds as
!!>    described below.
!>
!> 4. The system of equations is solved for X using the factored form
!>    of A.
!>
!> 5. Iterative refinement is applied to improve the computed solution
!>    matrix and calculate error bounds and backward error estimates
!>    for it.
!>
!> 6. If equilibration was used, the matrix X is premultiplied by
!>    diag(S) so that it solves the original system before
!>    equilibration.
!>
