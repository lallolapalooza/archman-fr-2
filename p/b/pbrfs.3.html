CPBRFS

But:

!>
!> CPBRFS améliore la solution calculée d'un système d'équations linéaires
!> lorsque la matrice des coefficients est hermitienne définie positive
!> et bande, et fournit des bornes d'erreur et des estimations d'erreur rétrograde
!> pour la solution.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          = 'U':  Le triangle supérieur de A est stocké ;
!>          = 'L':  Le triangle inférieur de A est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

KD

!>          KD est INTEGER
!>          Le nombre de super-diagonales de la matrice A si UPLO = 'U',
!>          ou le nombre de sous-diagonales si UPLO = 'L'.  KD >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          des matrices B et X.  NRHS >= 0.
!>

AB

!>          AB est un tableau COMPLEXE, dimension (LDAB,N)
!>          Le triangle supérieur ou inférieur de la matrice bande hermitienne A,
!>          stocké dans les KD+1 premières lignes du tableau. La j-ème colonne
!>          de A est stockée dans la j-ème colonne du tableau AB comme suit :
!>          si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j;
!>          si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB est INTEGER
!>          La dimension principale du tableau AB.  LDAB >= KD+1.
!>

AFB

!>          AFB est un tableau COMPLEXE, dimension (LDAFB,N)
!>          Le facteur triangulaire U ou L de la factorisation de Cholesky
!>          A = U**H*U ou A = L*L**H de la matrice bande A, tel que calculé par
!>          CPBTRF, dans le même format de stockage que A (voir AB).
!>

LDAFB

!>          LDAFB est INTEGER
!>          La dimension principale du tableau AFB.  LDAFB >= KD+1.
!>

B

!>          B est un tableau COMPLEXE, dimension (LDB,NRHS)
!>          La matrice des seconds membres B.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!>

X

!>          X est un tableau COMPLEXE, dimension (LDX,NRHS)
!>          À l'entrée, la matrice solution X, telle que calculée par CPBTRS.
!>          À la sortie, la matrice solution améliorée X.
!>

LDX

!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!>

FERR

!>          FERR est un tableau RÉEL, dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ème colonne de la matrice solution X).
!>          Si XTRUE est la vraie solution correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée de la magnitude du plus grand
!>          élément de (X(j) - XTRUE) divisée par la magnitude du plus grand
!>          élément de X(j). L'estimation est aussi fiable que
!>          l'estimation de RCOND, et est presque toujours une légère
!>          sur-estimation de l'erreur réelle.
!>

BERR

!>          BERR est un tableau RÉEL, dimension (NRHS)
!>          L'erreur rétrograde relative composante par composante de chaque vecteur
!>          solution X(j) (c'est-à-dire la plus petite modification relative de
!>          n'importe quel élément de A ou B qui fait de X(j) une solution exacte).
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (2*N)
!>

RWORK

!>          RWORK est un tableau RÉEL, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Paramètres internes :

!>  ITMAX est le nombre maximum d'étapes de raffinement itératif.
!>

NOM

zpbrfs - ZPBRFS vérifie la solution d'un système d'équations linéaires avec une matrice à bande hermitienne.

SYNTAXE

 SUBROUTINE ZPBRFS( UPLO, N, KD, NRHS, AB, LDAB, AFB, LDAFB, B, LDB, X,
 LDX, FERR, BERR, WORK, RWORK, INFO )
 CHARACTER*1 UPLO
 INTEGER N, KD, NRHS, LDAB, LDAFB, LDB, LDX, INFO
 COMPLEX*16 AB( LDAB, * ), AFB( LDAFB, * ), B( LDB, * ), X( LDX, * )
 COMPLEX*16 WORK( * )
 DOUBLE PRECISION FERR( * ), BERR( * ), RWORK( * )

DESCRIPTION

ZPBRFS met à jour une solution X pour le système d'équations linéaires A*X = B, où A est une matrice à bande hermitienne, et calcule des bornes d'erreur. L'utilisation de ZPBRFS est recommandée pour obtenir une estimation fiable de l'erreur dans la solution retournée par ZPBTRI.

Cette routine ne calcule pas la solution elle-même, qui est supposée avoir été calculée par ZPBTRF suivie de ZPBTRS.

Le paramètre `ITERATION` peut être utilisé pour affiner la solution.

Paramètres de lancement

UPLO
 UPLO est CHARACThR*1
 Specifie si la matrice A est triangulaire superieure ou inferieure.
 = 'U': A est triangulaire superieure
 = 'L': A est triangulaire inferieure
N
 N est INTEGER
 Le nombre d'ordres de la matrice A. N >= 0.
KD
 KD est INTEGER
 Le nombre de superdiagonales ou sous-diagonales dans la matrice A.
 KD >= 0.
NRHS
 NRHS est INTEGER
 Le nombre de membres de droite, c'est-a-dire le nombre de colonnes
 des matrices B et X. NRHS >= 0.
AB
 AB est COMPLEX*16 array, dimension (LDAB,N)
 Le triangle superieur ou inferieur de la matrice a bande hermitienne A,
 stockee dans les KD+1 premieres lignes du tableau. La j-eme colonne
 de A est stockee dans la j-eme colonne du tableau AB comme suit :
 si UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) pour max(1,j-kd)<=i<=j;
 si UPLO = 'L', AB(1+i-j,j)    = A(i,j) pour j<=i<=min(n,j+kd).
LDAB
 LDAB est INTEGER
 La dimension principale du tableau AB. LDAB >= KD+1.
AFB
 AFB est COMPLEX*16 array, dimension (LDAFB,N)
 Le facteur triangulaire U ou L de la factorisation de Cholesky
 A = U**H*U ou A = L*L**H de la matrice a bande A telle que calculee par
 ZPBTRF, dans le meme format de stockage que A (voir AB).
LDAFB
 LDAFB est INTEGER
 La dimension principale du tableau AFB. LDAFB >= KD+1.
B
 B est COMPLEX*16 array, dimension (LDB,NRHS)
 La matrice membre de droite B.
LDB
 LDB est INTEGER
 La dimension principale du tableau B. LDB >= max(1,N).
X
 X est COMPLEX*16 array, dimension (LDX,NRHS)
 En entree, la matrice solution X, telle que calculee par ZPBTRS.
 En sortie, la matrice solution amelioree X.
LDX
 LDX est INTEGER
 La dimension principale du tableau X. LDX >= max(1,N).
FERR
 FERR est DOUBLE PRECISION array, dimension (NRHS)
 La borne d'erreur avant estimee pour chaque vecteur solution
 X(j) (la j-eme colonne de la matrice solution X).
 Si XTRUE est la vraie solution correspondant a X(j), FERR(j)
 est une borne superieure estimee pour la magnitude du plus grand
 element de (X(j) - XTRUE) divise par la magnitude du plus grand
 element de X(j). L'estimation est aussi fiable que
 l'estimation pour RCOND, et est presque toujours une legere
 surestimation de l'erreur reelle.
BERR
 BERR est DOUBLE PRECISION array, dimension (NRHS)
 L'erreur arriere relative composante par composante de chaque vecteur solution
 X(j) (c'est-a-dire le plus petit changement relatif dans
 n'importe quel element de A ou B qui fait de X(j) une solution exacte).
WORK
 WORK est COMPLEX*16 array, dimension (2*N)
RWORK
 RWORK est DOUBLE PRECISION array, dimension (N)
INFO
