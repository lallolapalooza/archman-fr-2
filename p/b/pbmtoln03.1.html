NOM

pbmtoln03 - convertir une image PBM en sortie Sixel DEC LN03+

SYNTAXE

pbmtoln03 [-rltbf] fichier_pbm

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pbmtoln03 lit une image PBM en entrée et produit un fichier de sortie Sixel DEC LN03+.

OPTIONS

-l nn
Utiliser 'nn' comme valeur pour la marge gauche (par défaut 0).
-r nn
Utiliser 'nn' comme valeur pour la marge droite (par défaut 2400).
-t nn
Utiliser 'nn' comme valeur pour la marge supérieure (par défaut 0).
-b nn
Utiliser 'nn' comme valeur pour la marge inférieure (par défaut 3400).
-f nn
Utiliser 'nn' comme valeur pour la longueur du formulaire (par défaut 3400).
