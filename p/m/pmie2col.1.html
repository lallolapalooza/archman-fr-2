PMIE2COL(1) Manuel des commandes générales PMIE2COL(1)

NOM

pmie2col - convertir la sortie de pmie en format multicolonne

SYNTAXE

pmie2col [-?] [-d delimiteur] [-p precision] [-w largeur]

DESCRIPTION

pmie2col est un outil simple qui convertit la sortie de pmie(1) en un format de colonne régulier. Chaque colonne a une largeur de 7 caractères (par défaut, peut être modifiée avec l'option -w) avec un seul espace entre les colonnes. Cet espace unique peut être substitué par un délimiteur alternatif en utilisant l'option -d (ce qui est utile pour importer les données dans une feuille de calcul, par exemple).

La précision des valeurs tabulées de pmie peut être spécifiée avec l'option -p (par défaut, 2 décimales). Cette option peut et annulera tout réglage de largeur afin de présenter la précision demandée.

La configuration de pmie(1) doit suivre ces règles :

(1)
Chaque expression de pmie(1) est de la forme ``NOM = expr;''. NOM sera utilisé comme en-tête de colonne et ne doit pas contenir d'espace blanc, bien que les caractères spéciaux puissent être échappés en entourant NOM de guillemets simples.
(2)
L'expression ``expr'' doit être une expression valide de pmie(1) qui produit une valeur singulière.

De plus, pmie(1) doit être exécuté avec l'option de commande -v.

Il est également possible d'utiliser la commande -e pour pmie(1) et les lignes de sortie seront préfixées par un horodatage.

OPTIONS

Les options de ligne de commande disponibles sont :

-d caractère, --delimiter=caractère
Utilise caractère comme délimiteur de sortie.
-p N, --precision=N
Utilise n comme précision des nombres à virgule flottante en sortie.
-w N, --width=N
Utilise n comme largeur de colonne en sortie.
-?, --help
Affiche le message d'utilisation et quitte.

EXEMPLES

Étant donné ce fichier de configuration pmie(1) (config) : 

loadav = kernel.all.load #'1 minute';
'%usr' = kernel.all.cpu.user;
'%sys' = kernel.all.cpu.sys;
'%wio' = kernel.all.cpu.wait.total;
'%idle' = kernel.all.cpu.idle;
'max-iops' = max_inst(disk.dev.total);


Alors ce pipeline de commande : 

$ pmie -v -t 5 <config | pmie2col -w 8


Produit une sortie comme celle-ci : 

   loadav     %usr     %sys     %wio    %idle max-iops
     0.21        ?        ?        ?        ?        ?
     0.36     0.49     0.03     0.18     0.29    25.40
     0.49     0.41     0.10     0.36     0.13    51.00
     0.69     0.49     0.10     0.05     0.37    43.20
     0.71     0.39     0.08     0.04     0.49    14.00
     0.83     0.63     0.15     0.00     0.21    32.30
     1.09     0.60     0.02     0.10     0.27    47.00
     0.92     0.01     0.00     0.00     0.99     2.40


ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).
