PMDACIFS(1) Manuel des commandes générales PMDACIFS(1)

NOM

pmdacifs - PMDA du système de fichiers Internet commun (CIFS)

SYNTAXE

$PCP_PMDAS_DIR/cifs/pmdacifs [-D debug]

DESCRIPTION

pmdacifs est un agent de domaine de métriques de performance (PMDA) qui exporte les valeurs métriques des partages CIFS montés à partir du répertoire /proc/fs/cifs. Ce PMDA nécessite au moins que le module noyau CIFS soit chargé pour renvoyer certaines valeurs métriques et au moins un partage CIFS monté afin de fournir des données pour toutes les métriques.

INSTALLATION

Installez le PMDA CIFS en utilisant le script d'installation en tant que root :

# cd $PCP_PMDAS_DIR/cifs
# ./Install

Pour désinstaller, les actions suivantes doivent être effectuées en tant que root :

# cd $PCP_PMDAS_DIR/cifs
# ./Remove

pmdacifs est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd lorsque l'agent est installé ou retiré.

FICHIERS

$PCP_PMDAS_DIR/cifs/help
fichier d'aide par défaut pour les métriques CIFS
$PCP_PMDAS_DIR/cifs/Install
script d'installation de l'agent pmdacifs
$PCP_PMDAS_DIR/cifs/Remove
script d'annulation de l'installation de l'agent pmdacifs
$PCP_LOG_DIR/pmcd/cifs.log
fichier journal par défaut pour les messages d'erreur de pmdacifs

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DEBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider au dépannage, bien que les informations soient parfois cryptiques et principalement destinées aux développeurs plutôt qu'aux utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

VOIR AUSSI

PCPIntro(1), pmcd(1), pmstore(1) et mount.cifs(8).
