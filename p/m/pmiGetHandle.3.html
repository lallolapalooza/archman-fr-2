NOM

pmiGetHandle - définir un identifiant pour une paire métrique-instance

C SYNTAXE

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiGetHandle(const char *name, const char *instance);

cc ... -lpcp_import -lpcp

SYNTAXE PERL

use PCP::LogImport;

$handle = pmiGetHandle($name, $instance);

DESCRIPTION

Dans le cadre de l'API d'importation de journaux de Performance Co-Pilot (voir LOGIMPORT(3)), pmiGetHandle crée un identifiant pour une métrique et une instance données. L'identifiant est retourné comme valeur de l'appel pmiGetHandle et peut être utilisé dans les appels ultérieurs à pmiPutValueHandle(3).

Le nom de la métrique doit correspondre à un nom défini précédemment dans un appel à pmiAddMetric(3).

Pour les métriques singulières (celles définies avec un domaine d'instance de PM_INDOM_NULL), instance doit être NULL ou une chaîne vide, sinon instance doit correspondre au nom d'une instance définie précédemment dans un appel à pmiAddInstance(3) pour le domaine d'instance de la métrique.

Lorsqu'il est combiné avec pmiPutValueHandle(3), l'utilisation d'identifiants offre une amélioration des performances par rapport à la recherche alternative d'un nom de métrique et d'un nom d'instance pour chaque valeur de données requise pour pmiPutValue(3).

DIAGNOSTICS

En cas d'échec, pmiGetHandle retourne une valeur négative qui peut être convertie en message d'erreur en appelant pmiErrStr(3).

VOIR AUSSI

LOGIMPORT(3), pmiAddInstance(3), pmiAddMetric(3), pmiErrStr(3) et pmiPutValueHandle(3).
