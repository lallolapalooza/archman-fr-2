PMFREELABELSETS(3) Manuel des fonctions de bibliothèque PMFREELABELSETS(3)

NOM

pmFreeLabelSets - libérer la mémoire allouée pour les étiquettes de métriques de performance

SYNTAXE C

#include <pcp/pmapi.h>

void pmFreeLabelSets(pmLabelSet *sets, int nsets);

cc ... -lpcp

DESCRIPTION

Le tableau d'ensembles d'étiquettes sets renvoyé par pmLookupLabels(3) et les API associées est alloué sous l'interface de programmation d'applications de métriques de performance (PMAPI) en utilisant divers appels aux interfaces d'allocation de mémoire dynamique du système (c'est-à-dire malloc(3)).

Les applications doivent appeler pmFreeLabelSets pour libérer le stockage précédemment alloué pour le tableau d'ensembles d'étiquettes sets lorsque l'accès à la structure n'est plus nécessaire. La valeur de retour de pmLookupLabels indique le nombre d'éléments dans le tableau d'ensembles d'étiquettes sets, et cela doit être passé via le paramètre nsets.

En **aucun cas** une application ne doit utiliser free(labelset) pour libérer le stockage précédemment alloué pour un pmLabelSet par pmLookupLabels(3) ou les API associées.

Pour simplifier la gestion des erreurs, si sets est NULL, pmFreeLabelSets retourne simplement sans libérer de stockage.

VOIR AUSSI

malloc(3), PMAPI(3) et pmLookupLabels(3).
