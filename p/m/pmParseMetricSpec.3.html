PMPARSEMETRICSPEC(3) Manuel des fonctions de bibliothèque PMPARSEMETRICSPEC(3)

NOM

pmParseMetricSpec, pmFreeMetricSpec - analyseur de spécification métrique uniforme

C SYNTAXE

#include <pcp/pmapi.h>

int pmParseMetricSpec(const char *string,
int isarch, char *source, pmMetricSpec **rsltp, char **errmsg);

void pmFreeMetricSpec(pmMetricSpec *rslt);

cc ... -lpcp

DESCRIPTION

pmParseMetricSpec accepte une chaîne spécifiant le nom d'une métrique de performance PCP, et optionnellement la source (soit un nom d'hôte, soit un nom de fichier d'archive PCP) et les instances pour cette métrique. La syntaxe est décrite dans PCPIntro(1).

Si ni le composant host ni le composant archive de la spécification de métrique n'est fourni, les arguments isarch et source sont utilisés pour remplir la structure pmMetricSpec renvoyée.

La structure pmMetricSpec qui est renvoyée via rsltp représente la chaîne analysée et a la déclaration suivante :

    typedef struct {
        int     isarch;      /* type de source : 0 -> hôte live, 1 -> archive, 2 -> contexte local */
        char    *source;     /* nom de la source hôte ou archive */
        char    *metric;     /* nom de la métrique */
        int     ninst;       /* nombre d'instances, 0 -> toutes */
        char    *inst[1];    /* tableau de noms d'instances */
    } pmMetricSpec;

pmParseMetricSpec renvoie 0 si la chaîne donnée a été analysée avec succès. Dans ce cas, tout le stockage alloué par pmParseMetricSpec peut être libéré par un appel unique à free(3) en utilisant l'adresse renvoyée depuis pmMetricSpec via rsltp. La macro pratique pmFreeMetricSpec est un wrapper déguisé pour free(3).

pmParseMetricSpec renvoie PM_ERR_GENERIC et un message d'erreur alloué dynamiquement dans errmsg, si la chaîne donnée ne peut pas être analysée. Assurez-vous de free(3) la chaîne de message d'erreur dans cette situation.

En cas d'erreur, rsltp est indéfini. En cas de succès, errmsg est indéfini. Si rsltp->ninst est 0, alors rsltp->inst[0] est indéfini.

VOIR AUSSI

PMAPI(3) et pmLookupName(3).
