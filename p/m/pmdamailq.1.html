PMDAMAILQ(1) Manuel des commandes générales PMDAMAILQ(1)

NOM

pmdamailq - agent de domaine de métriques de performance de la file d'attente des courriels (PMDA)

SYNTAXE

$PCP_PMDAS_DIR/mailq/pmdamailq [-b liste_intervalles] [-D debug] [-d domaine] [-l fichier_journal] [-r expression_reguliere] [-U nom_utilisateur] [repertoire_attente]

DESCRIPTION

pmdamailq est un agent de domaine de métriques de performance (PMDA) qui extrait les métriques de performance décrivant l'état des files d'attente de courriels gérées par sendmail(1) et d'autres agents de transfert de courriels.

Le PMDA mailq exporte des métriques qui mesurent le nombre total d'entrées dans la file d'attente des courriels, et les sous-totaux pour les entrées qui ont été mises en file d'attente pendant différentes périodes.

Une brève description des options de ligne de commande de pmdamailq suit :

-b
L'argument liste_intervalles spécifie une liste de seuils de délai utilisés pour "classer" les entrées de la file d'attente dans un histogramme basé sur la durée pendant laquelle l'entrée est restée dans la file d'attente des courriels. Les seuils par défaut sont : 1 heure, 4 heures, 8 heures, 1 jour, 3 jours et 7 jours. Les entrées de liste_intervalles sont des intervalles de temps séparés par des virgules, en utilisant la syntaxe décrite dans PCPIntro(1) pour un intervalle de mise à jour ou de rapport, par exemple, la liste par défaut pourrait être spécifiée en utilisant la valeur 1h,4h,8h,1j,3j,7j.

Les valeurs de liste_intervalles sont supposées être dans l'ordre croissant, et les éléments de courriel dans la file d'attente dont la durée est inférieure au premier seuil sont classés dans une catégorie spéciale intitulée "récent".

-d
Il est absolument crucial que le numéro de domaine des métriques de performance spécifié ici soit unique et cohérent. C'est-à-dire que le domaine doit être différent pour chaque PMDA sur le même hôte, et le même numéro de domaine doit être utilisé pour le même PMDA sur tous les hôtes.
-l
Emplacement du fichier journal. Par défaut, un fichier journal nommé mailq.log est écrit dans le répertoire courant de pmcd(1) lorsque pmdamailq est démarré, c'est-à-dire $PCP_LOG_DIR/pmcd . Si le fichier journal ne peut pas être créé ou n'est pas accessible en écriture, la sortie est redirigée vers la sortie d'erreur standard à la place.
-r
Utiliser une expression régulière étendue pour faire correspondre les noms de fichiers dans le répertoire de la file d'attente des courriels, plutôt que de supposer que tous les fichiers préfixés par "df" dans le répertoire sont des fichiers de courriels (le préfixe "df" est la convention de sendmail, mais cette convention n'est pas suivie par d'autres démons de courriel). Le modèle expression_reguliere spécifié doit être conforme au format POSIX décrit dans regex(3), et il décrit les noms de fichiers qui doivent être considérés comme des courriels.
-U
Compte utilisateur sous lequel exécuter l'agent. Par défaut, il s'agit du compte non privilégié "pcp" dans les versions courantes de PCP, mais dans les versions plus anciennes, le compte superutilisateur ("root") était utilisé par défaut.

L'argument optionnel repertoire_attente définit le répertoire dans lequel pmdamailq s'attend à trouver la file d'attente des courriels. Le défaut est /var/spool/mqueue.

INSTALLATION

Si vous souhaitez accéder aux noms, aux textes d'aide et aux valeurs des métriques de performance de la file d'attente des courriels, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/mailq
# ./Install

Si vous souhaitez annuler l'installation, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/mailq
# ./Remove

pmdamailq est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMCDCONF_PATH
options de ligne de commande utilisées pour lancer pmdamailq
$PCP_PMDAS_DIR/mailq/help
fichier d'aide par défaut pour les métriques de la file d'attente des courriels
$PCP_PMDAS_DIR/mailq/Install
script d'installation pour l'agent pmdamailq
$PCP_PMDAS_DIR/mailq/Remove
script d'annulation d'installation pour l'agent pmdamailq
$PCP_LOG_DIR/pmcd/mailq.log
fichier journal par défaut pour les messages d'erreur et autres informations de pmdamailq

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider au dépannage, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

VOIR AUSSI

PCPIntro(1), pmcd(1), pcp.conf(5) et pcp.env(5).
