NOM

pmdahdb - PMDA SAP HANA

DESCRIPTION

pmdahdb est un agent de domaine de métriques de performance (PMDA) qui exporte les valeurs de métriques concernant une base de données SAP HANA (High-performance ANalytic Appliance), une base de données multi-modèle qui stocke les données en mémoire au lieu de les garder sur disque.

Ce PMDA peut être utilisé dans des scénarios de scale-out. Toutes les métriques sont conscientes de l'hôte et du port. L'hôte et le port sont inclus dans les noms d'instances (<hôte>.<port>.<instance>).

pmdahdb ne prend actuellement pas en charge les systèmes de conteneurs de base de données multi-locataires (MDC). L'agent ne peut cibler qu'un seul conteneur de base de données à la fois (ce conteneur peut être une base de données locataire).

INSTALLATION

La configuration hdb est gérée avec hdb.conf. Actuellement, il n'y a qu'une seule section hdb qui contient les paramètres de connexion SAP HANA. Les mots de passe entre guillemets sont pris en charge. Pour plus d'informations sur les mots de passe entre guillemets, voir : https://help.sap.com/docs/SAP_HANA_ONE/
102d9916bf77407ea3942fef93a47da8/
61662e3032ad4f8dbdb5063a21a7d706.html#password-layout.

Installez le PMDA hdb en utilisant le script Install en tant que root :

# cd $PCP_PMDAS_DIR/hdb
# ./Install

Pour désinstaller, faites ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/hdb
# ./Remove

pmdahdb est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove informent pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_SYSCONF_DIR/hdb/hdb.conf
fichier de configuration de l'agent pmdahdb
$PCP_PMDAS_DIR/hdb/Install
script d'installation de l'agent pmdahdb
$PCP_PMDAS_DIR/hdb/Remove
script d'annulation d'installation de l'agent pmdahdb
$PCP_LOG_DIR/pmcd/hdb.log
fichier journal par défaut pour les messages d'erreur de pmdahdb

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).
