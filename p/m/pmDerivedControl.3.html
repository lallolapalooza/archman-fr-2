PMDERIVEDCONTROL(3) Manuel des fonctions de bibliothèque PMDERIVEDCONTROL(3)

NOM

pmGetDerivedControl, pmSetDerivedControl - obtenir et définir des contrôles pour les métriques dérivées

SYNTAXE C

#include <pcp/pmapi.h>

int pmGetDerivedControl(int what, int *valuep);
int pmSetDerivedControl(int what, int value);

cc ... -lpcp

DESCRIPTION

Ces routines peuvent être utilisées pour influencer le comportement des services de métriques dérivées qui sont activés pour les métriques dérivées globales en utilisant pmRegisterDerived(3), pmRegisterDerivedMetric(3) et pmLoadDerivedConfig(3), ou les métriques dérivées par contexte en utilisant pmAddDerived(3) et pmAddDerivedMetric(3).

L'argument what sélectionne un contrôle, l'argument value fournit une valeur pour pmSetDerivedControl et l'argument valuep est utilisé pour retourner la valeur pour pmGetDerivedControl.

L'argument what peut prendre l'une des valeurs suivantes :

PCP_DERIVED_GLOBAL_LIMIT
Le nombre maximum de métriques dérivées globales pouvant être définies. La valeur -1 indique aucune limite.
PCP_DERIVED_CONTEXT_LIMIT
Le nombre maximum de métriques dérivées par contexte pouvant être définies. La valeur -1 indique aucune limite.
PCP_DERIVED_DEBUG_SYNTAX
Diagnostics de débogage lors de l'analyse syntaxique de l'expression de la métrique dérivée. La valeur 1 active les diagnostics, la valeur 0 les désactive.
PCP_DERIVED_DEBUG_SEMANTICS
Diagnostics de débogage pour les vérifications sémantiques lors de la liaison des métriques dans l'expression de la métrique dérivée aux métriques disponibles dans un nouveau contexte PMAPI. La valeur 1 active les diagnostics, la valeur 0 les désactive.
PCP_DERIVED_DEBUG_EVAL
Diagnostics de débogage lorsque des métriques dérivées sont utilisées dans des opérations PMAPI comme pmFetch(3), pmGetChildren(3), pmGetChildrenStatus(3), pmLookupDesc(3), pmLookupName(3), pmNameAll(3), pmNameID(3) et pmTraversePMNS(3).

VALEURS DE RETOUR

Les deux routines retournent 0 en cas de succès, sinon une valeur inférieure à 0 qui peut être décodée en utilisant pmErrStr(3).

VOIR AUSSI

PCPIntro(1), pmAddDerived(3), pmAddDerivedMetric(3), PMAPI(3), pmErrStr(3), pmLoadDerivedConfig(3), pmRegisterDerived(3), pmRegisterDerivedMetric(3) et PMNS(5).
