pmiSetTimezone(3)

PMISETTIMEZONE(3) Manuel des fonctions de bibliothèque PMISETTIMEZONE(3)

NOM

pmiSetTimezone - définir le fuseau horaire source pour une archive LOGIMPORT

C SYNTAXE

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiSetTimezone(const char *value);

cc ... -lpcp_import -lpcp

SYNTAXE PERL

use PCP::LogImport;

pmiSetTimezone($value);

DESCRIPTION

Dans le cadre de l'API d'importation de journaux de Performance Co-Pilot (voir LOGIMPORT(3)), pmiSetTimezone définit le fuseau horaire source dans le contexte actuel à value.

En l'absence d'appel à pmiSetTimezone, le fuseau horaire source est par défaut le fuseau horaire de la machine locale.

DIAGNOSTICS

pmiSetTimezone retourne zéro en cas de succès, sinon une valeur négative qui peut être transformée en message d'erreur en appelant pmiErrStr(3).

VOIR AUSSI

LOGIMPORT(3), pmiErrStr(3), pmiSetHostname(3), pmiSetVersion(3) et pmiStart(3).
