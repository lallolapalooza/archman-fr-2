pmix_info — Afficher des informations sur l'installation de PMIx

SYNTAXE

pmix_info [options]

DESCRIPTION

pmix_info fournit des informations détaillées sur l'installation de PMIx. Il peut être utile pour au moins trois scénarios courants :

1.
Vérifier la configuration locale et voir comment PMIx a été installé.
2.
Soumettre des rapports de bugs / demandes d'aide à la communauté PMIx (voir Obtenir de l'aide).
3.
Voir une liste des plugins PMIx installés et interroger les paramètres MCA qu'ils prennent en charge.

OPTIONS

pmix_info accepte les options suivantes :

  • -h | --help <arg0> : Afficher le message d'aide. Si l'argument facultatif n'est pas fourni, un message d'aide général similaire aux informations fournies ici est retourné. Si un argument est fourni, un message d'aide plus détaillé pour cette option de ligne de commande spécifique est retourné.
  • -v | --verbose : Activer la sortie de débogage.
  • -V | --version : Afficher la version et quitter.
  • -a | --all : Afficher toutes les options de configuration et les paramètres MCA.
  • --arch : Afficher l'architecture sur laquelle PMIx a été compilé.
  • -c | --config : Afficher les options de configuration
  • --hostname : Afficher le nom d'hôte sur lequel PMIx a été configuré et construit.
  • --internal : Afficher les paramètres MCA internes (non destinés à être modifiés par les utilisateurs).
  • --param <arg0>:<arg1>,<arg2> : Afficher les paramètres MCA. Le premier paramètre est le framework (ou le mot-clé “all”) ; le second paramètre est une liste délimitée par des virgules de noms de composants spécifiques (si seul <arg0> est donné, alors tous les composants seront rapportés).
  • --path <type> : Afficher les chemins avec lesquels PMIx a été configuré. Accepte les paramètres suivants : prefix, bindir, libdir, incdir, pkglibdir, sysconfdir.
  • --pretty-print : Lorsqu'il est utilisé conjointement avec d'autres paramètres, la sortie est affichée au format “prettyprint” (par défaut)
  • --parsable : Lorsqu'il est utilisé conjointement avec d'autres paramètres, la sortie est affichée dans un format analysable par machine
  • --parseable : Synonyme de --parsable
  • --show-failed : Afficher les composants qui n'ont pas pu être chargés ainsi que la raison pour laquelle ils ont échoué
  • --selected-only : Afficher uniquement les variables des composants sélectionnés.

STATUT DE SORTIE

Retourne 0 en cas de succès, une valeur non nulle en cas d'erreur

EXEMPLES

Exemples d'utilisation de cette commande.

Afficher la sortie par défaut des options et la liste des composants installés dans un format lisible par l'homme / prettyprint :

pmix_info

Afficher la sortie par défaut des options et la liste des composants installés dans un format analysable par machine :

pmix_info --parsable

Afficher les paramètres MCA du composant PNET “opa” dans un format lisible par l'homme / prettyprint :

pmix_info --param pnet opa

Afficher le “bindir” avec lequel PMIx a été configuré :

pmix_info --path bindir

Afficher la version des numéros de version de PMIx dans un format prettyprint :

pmix_info --version

Afficher *toutes* les informations sur l'installation de PMIx, y compris tous les composants trouvés, tous les paramètres MCA qu'ils prennent en charge, les versions de PMIx et des composants, etc. :

pmix_info --all
