PMDAUWSGI(1) Manuel des commandes générales PMDAUWSGI(1)

NOM

pmdauwsgi - agent de domaine de métriques de performance uwsgi (PMDA)

DESCRIPTION

pmdauwsgi est un Agent de Domaine de Métriques de Performance (PMDA) qui exporte les métriques de performance d'uwsgi. uWSGI est souvent utilisé en conjonction avec des serveurs web comme Nginx, qui offrent un support direct du protocole natif uwsgi de uWSGI, pour servir des applications web Python telles que Django.

pmdauwsgi lit un fichier de configuration optionnel de style ini :

$PCP_SYSCONF_DIR/uwsgi/uwsgi.conf

Ce fichier a une section [pmda]

[pmda]

hote = (127.0.0.1)
Connecte le serveur de statistiques uwsgi sur le nom d'hôte donné.
port = (9051)
Connecte au serveur de statistiques uwsgi sur le port donné.

INSTALLATION

Ce PMDA nécessite qu'uwsgi soit en cours d'exécution sur l'hôte local avec un serveur de statistiques uwsgi fonctionnant sur le port TCP 9051 (par défaut) et avec stats-http activé.

Installez le PMDA uwsgi en utilisant le script d'installation en tant que root :

  # cd $PCP_PMDAS_DIR/uwsgi
  # ./Install

Pour désinstaller, faites ce qui suit en tant que root :

  # cd $PCP_PMDAS_DIR/uwsgi
  # ./Remove

pmdauwsgi est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/uwsgi/Install
script d'installation pour l'agent pmdauwsgi
$PCP_PMDAS_DIR/uwsgi/Remove
script d'annulation de l'installation pour l'agent pmdauwsgi
$PCP_LOG_DIR/pmcd/uwsgi.log
fichier journal par défaut pour les messages d'erreur de pmdauwsgi
$PCP_SYSCONF_DIR/uwsgi/uwsgi.conf
fichier de configuration optionnel pour l'agent pmdauwsgi

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, tel que décrit dans pcp.conf(5).
