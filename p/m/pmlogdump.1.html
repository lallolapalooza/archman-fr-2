PMLOGDUMP(1) Manuel des commandes générales PMLOGDUMP(1)

NOM

pmlogdump, pmdumplog - extraire les détails internes d'une archive de métriques de performance

SYNTAXE

pmlogdump [-adehIilLmMrstxzV?] [-D debug] [-n pmnsfile] [-S starttime] [-T endtime] [-Z timezone] archive [nom_métrique ...]
pmlogdump [-v fichier]

DESCRIPTION

pmlogdump extrait diverses informations de contrôle, métadonnées, index et d'état des fichiers d'une archive Performance Co-Pilot (PCP). L'archive a le nom de base archive et doit avoir été précédemment créée à l'aide de pmlogger(1). Alternativement, archive est le nom d'un répertoire contenant un ensemble d'archives PCP qui pourraient être ouvertes avec pmNewContext(3).

Historiquement, pmlogdump était connu sous le nom de pmdumplog, mais ce dernier nom n'est pas cohérent avec les autres commandes PCP qui opèrent sur les archives PCP, donc pmlogdump est préféré. Cependant, pmdumplog est maintenu pour des raisons de compatibilité ascendante.

Normalement, pmlogdump opère sur l'espace de noms distribué des métriques de performance (PMNS), mais si l'option -n est spécifiée, un PMNS local alternatif est chargé depuis le fichier pmnsfile.

Si des arguments nom_métrique apparaissent, le rapport sera limité aux informations pertinentes pour les métriques de performance nommées. Si nom_métrique est un nœud non feuille dans l'espace de noms (voir PMNS(5)), alors pmlogdump descendra récursivement l'espace de noms de l'archive et rapportera tous les nœuds feuilles.

Les options en ligne de commande contrôlent les informations spécifiques à rapporter.

OPTIONS

Les options de ligne de commande disponibles sont :

-a, --tous
Rapporter presque tout, c'est-à-dire les indicateurs -d, -i, -L, -m, -s et -t. Le texte d'aide optionnel (-h) et les chaînes de métadonnées de label (-e) ne sont pas rapportés par défaut.
-d, --descriptions
Afficher les métadonnées et descriptions pour les métriques de performance qui apparaissent au moins une fois dans l'archive : voir pmLookupDesc(3) pour plus de détails sur les métadonnées décrivant les métriques. Les métriques sont rapportées dans l'ordre croissant de l'identifiant de métrique de performance (PMID).
-e, --ensembles-de-labels
Afficher les métadonnées de label si elles sont présentes dans l'archive. Voir pmLookupLabels(3) pour plus de détails sur la hiérarchie des métadonnées de label associée aux métriques.
-h, --texte-aide
Afficher le texte d'aide des métriques et des domaines d'instance s'il est présent dans l'archive. Voir pmLookupText(3) pour plus de détails sur le texte d'aide associé aux métriques.
-i, --instances
Afficher les domaines d'instance, et toute variation de leurs membres d'instance sur la durée de l'archive : voir pmGetInDom(3) pour plus de détails sur les domaines d'instance. Les domaines d'instance sont rapportés dans l'ordre croissant de l'identifiant de domaine d'instance, puis par ordre chronologique croissant pour chaque ensemble de membres d'instance observés au sein d'un domaine d'instance.
-I, --instances-disque
Afficher les domaines d'instance sur disque, qui peuvent utiliser un format et un encodage différents de ceux visibles via l'API des métriques de performance (PMAPI) lors de l'utilisation de pmGetInDom(3) et des routines associées. Le format sur disque n'intéresse que lors de l'investigation de la structure interne des archives PCP.
-l, --label
Extraire le label de l'archive, affichant la version du format de l'archive, l'heure et la date de début et de fin (actuelle) de l'archive, et l'hôte à partir duquel les valeurs des métriques de performance ont été collectées.
-L
Similaire à -l, juste un peu plus verbeux.
-m, --métriques
Imprimer les valeurs des métriques de performance de l'archive. C'est l'option d'affichage par défaut.

Les métriques sans domaine d'instance sont rapportées comme :
[horodatage] id_métrique (nom_métrique): valeur1 valeur2

Les métriques avec un domaine d'instance sont rapportées comme :
[horodatage] id_métrique (nom_métrique):
inst [id_interne ou "id_externe"] valeur1 valeur2

L' horodatage n'est rapporté que pour la première métrique d'un groupe de métriques partageant le même horodatage.

-M, --marquages
Si aucun nom_métrique n'est spécifié, alors les enregistrements <marque> sont rapportés lorsqu'ils sont trouvés dans l' archive. Si des arguments nom_métrique sont spécifiés, alors les enregistrements <marque> ne sont pas rapportés par défaut. L'option -M force le rapport des enregistrements <marque>, même lorsque des arguments nom_métrique sont spécifiés.

Les enregistrements <marque> sont insérés dans une archive PCP par pmlogger(1), pmlogextract(1), et des outils similaires pour indiquer une discontinuité temporelle dans la série temporelle des valeurs métriques.

-n pmnsfile, --espace-noms=pmnsfile
Charger un espace de noms de métriques de performance (PMNS) alternatif depuis le fichier pmnsfile.
-r, --inverse
Traiter l'archive dans l'ordre inverse, des valeurs métriques les plus récentes aux plus anciennes enregistrées.
-s, --tailles
Rapporter la taille en octets de chaque enregistrement physique dans l'archive.
-S début, --début=début
Lors de l'utilisation de l'option -m, le rapport sera limité aux enregistrements enregistrés à partir de début (inclus). Reportez-vous à PCPIntro(1) pour une description complète de la syntaxe de début.
-t
Extraire l'index temporel utilisé pour fournir un accès accéléré aux gros fichiers d'archive.

L'intégrité de l'index sera également vérifiée. Si l'index est trouvé corrompu, le fichier ``*.index'' peut être renommé ou supprimé et l'archive restera accessible, bien que les récupérations puissent prendre plus de temps sans l'index. Notez cependant qu'un index temporel corrompu est généralement indicatif d'un problème plus profond qui peut affecter tous les fichiers d'une archive PCP.

-T fin, --fin=fin
Lors de l'utilisation de l'option -m, le rapport sera limité aux enregistrements enregistrés avant ou à fin (inclus). Reportez-vous à PCPIntro(1) pour une description complète de la syntaxe de fin.
-v fichier
Mode verbeux. Extraire les enregistrements d'un fichier d'archive physique au format hexadécimal. Dans ce cas, fichier est le nom d'un seul fichier, généralement un nom de base (tel qu'il apparaîtrait autrement comme argument de commande archive), concaténé avec ``.'' suivi de l'un des éléments suivants : meta (les métadonnées), index (l'index temporel), ou un chiffre (l'un des volumes de valeurs métriques).

L'utilisation de -v exclut l'utilisation de toutes les autres options et arguments.

-V, --version
Afficher le numéro de version et quitter.
-x
Format de rapport d'horodatage étendu qui inclut le jour de la semaine, le jour du mois, le mois et l'année en plus de l'heure (par défaut) en heures, minutes et secondes. Ceci est utile pour les archives qui couvrent plusieurs jours.

Une deuxième option -x affichera également l'horodatage sous forme de décalage par rapport au début de l'archive en unités de secondes.

EXEMPLES

pmlogdump
Affiche les informations de base de l'archive PCP courante (les valeurs par défaut sont équivalentes à -d, -i, -m, -s, -t).
pmlogdump -a
Affiche presque toutes les informations de l'archive PCP courante.
pmlogdump -r archive
Traite l'archive nommée archive dans l'ordre chronologique inverse.
pmlogdump -t archive
Affiche l'index temporel de l'archive nommée archive.
pmlogdump -i archive
Affiche les domaines d'instance de l'archive nommée archive.
pmlogdump -m archive
Affiche les métriques et leurs valeurs de l'archive nommée archive.
pmlogdump -S 10:00:00 -T 10:05:00 -m archive
Affiche les métriques et leurs valeurs de l'archive nommée archive entre 10:00:00 et 10:05:00.
pmlogdump -x archive
Affiche les métriques et leurs valeurs de l'archive nommée archive avec des horodatages détaillés.
pmlogdump -v archive.meta
Affiche le contenu du fichier métadonnées de l'archive en mode hexadécimal.

-z, --hostzone
Change le fuseau horaire pour le fuseau horaire local de l'hôte source des métriques de performance, tel que spécifié dans l'enregistrement d'étiquette de l'archive.
-Z timezone, --timezone=timezone
Par défaut, pmlogdump affiche l'heure du jour selon le fuseau horaire local du système où pmlogdump est exécuté. L'option -Z change le fuseau horaire pour timezone dans le format de la variable d'environnement TZ, comme décrit dans environ(7).
-?, --help
Affiche le message d'utilisation et quitte.

FICHIERS

$PCP_LOG_DIR/pmlogger/<hostname>
Répertoire par défaut des archives PCP contenant les valeurs de métriques de performance collectées de l'hôte hostname.

ENVIRONNEMENT PCP

Les variables d'environnement préfixées par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active l'affichage de diagnostics supplémentaires sur stderr pour aider au triage des problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.
