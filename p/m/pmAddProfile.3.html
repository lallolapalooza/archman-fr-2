PMADDPROFILE(3) Manuel des fonctions de bibliothèque PMADDPROFILE(3)

NOM

pmAddProfile - ajouter une ou plusieurs instances au profil PMAPI actuel

C SYNTAXE

#include <pcp/pmapi.h>

int pmAddProfile(pmInDom indom,
int numinst, int *instlist);

cc ... -lpcp

DESCRIPTION

L'ensemble des instances pour les métriques de performance retournées par un appel à pmFetch(3) peut être filtré ou restreint à l'aide d'un profil d'instance. Il existe un profil d'instance pour chaque contexte que l'application crée à l'interface de programmation d'applications de métriques de performance (PMAPI(3)), et chaque profil d'instance peut inclure des instances d'un ou plusieurs domaines d'instances (voir pmLookupDesc(3)).

pmAddProfile peut être utilisé pour ajouter de nouvelles spécifications d'instance au profil d'instance du contexte PMAPI actuel.

Dans la variante la plus simple, la liste des instances identifiées par l'argument instlist pour le domaine d'instances indom sont ajoutées au profil d'instance. La liste des identifiants d'instance contient numinst valeurs.

La valeur indom serait normalement extraite d'un appel à pmLookupDesc(3) pour une métrique de performance particulière, et les instances dans instlist seraient typiquement déterminées par des appels à pmGetInDom(3) ou pmLookupInDom(3).

Pour sélectionner toutes les instances dans tous les domaines d'instances, utilisez


pmAddProfile(PM_INDOM_NULL, 0, (int *)0)

C'est le seul cas où indom peut être égal à PM_INDOM_NULL. Si numinst est zéro, ou si instlist est NULL, alors toutes les instances dans indom sont sélectionnées.

AVERTISSEMENT

Il est possible d'ajouter des domaines d'instances inexistants et des instances inexistantes à un profil d'instance. Aucune des routines qui utilisent le profil d'instance ne générera d'erreur si vous le faites. Le coût de la vérification, lorsque la vérification est possible, l'emporte sur les avantages.

DIAGNOSTICS

PM_ERR_PROFILESPEC
indom était PM_INDOM_NULL et instlist n'était pas vide

VOIR AUSSI

PMAPI(3), pmDelProfile(3), pmFetch(3), pmGetInDom(3), pmLookupDesc(3), pmLookupInDom(3), pmNewContext(3), pmUseContext(3) et pmWhichContext(3).
