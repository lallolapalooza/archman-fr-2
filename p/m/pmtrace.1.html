PMTRACE(1) Manuel des commandes générales PMTRACE(1)

NOM

pmtrace - instrumentation de performance en ligne de commande

SYNTAXE

pmtrace [-q?] [-c valeur | -e commande | -v valeur] [-h hôte] [-S état] étiquette

DESCRIPTION

pmtrace fournit une interface simple en ligne de commande vers l'agent du domaine de métriques de performance (PMDA) de traçage et la bibliothèque pcp_trace associée.

Le comportement par défaut de pmtrace est de fournir des données de traçage ponctuel au PMDA de traçage, en utilisant l'argument étiquette comme nom identificateur associé à chaque point de trace. L'étiquette devient alors un identificateur d'instance dans l'ensemble des métriques trace.point.

OPTIONS

Les options de ligne de commande disponibles sont :

-c valeur
Permet d'exporter une valeur de compteur valeur arbitraire à travers les métriques trace.count.
-e commande
Permet d'exécuter une commande arbitraire. Cette commande sera mesurée comme une transaction, car elle a des points de début et de fin bien définis. Les informations sont rendues disponibles via les métriques trace.transact.
-h hôte
Envoie les données de traçage au PMDA de traçage s'exécutant sur hôte, plutôt que sur localhost. Ceci remplace l'utilisation de la variable d'environnement PCP_TRACE_HOST.
-q
Supprime les messages d'un traçage réussi, de sorte que pmtrace s'exécute silencieusement.
-S état
Active le débogage et le traçage internes. La valeur de état est une combinaison bit à bit de drapeaux de débogage tels que définis dans pmtracestate(3), et peut être spécifiée en utilisant la syntaxe décimale ou hexadécimale prescrite par strtol(3).
-v valeur
Permet d'exporter une valeur à virgule flottante valeur arbitraire à travers les métriques trace.observe.
-?
Affiche le message d'utilisation et quitte.

DIAGNOSTICS

Tous sont générés sur l'erreur standard et sont destinés à être auto-explicatifs.

Le code de sortie de pmtrace est toujours zéro, sauf lorsque l'option -e est utilisée, auquel cas le code de sortie de commande est retourné.

FICHIERS

$PCP_DEMOS_DIR/trace/pmtrace.c
code source de pmtrace

ENVIRONNEMENT

Comme pmtrace utilise les routines de la bibliothèque libpcp_trace, les variables d'environnement PCP_TRACE_HOST, PCP_TRACE_PORT et PCP_TRACE_TIMEOUT sont toutes honorées. Reportez-vous à pmdatrace(3) pour une description détaillée des sémantiques de chacune.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).
