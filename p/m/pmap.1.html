PMAP(1) Manuel des commandes générales PMAP(1)

NOM

pmap - affiche la carte mémoire d'un processus

SYNTAXE

pmap [option ...] pid ...

DESCRIPTION

La commande pmap affiche la carte mémoire d'un ou plusieurs processus.

OPTIONS

-x, --extended
Affiche le format étendu.
-d, --device
Affiche le format de périphérique.
-q, --quiet
Ne pas afficher certaines lignes d'en-tête ou de pied de page.
-A, --range bas,haut
Limite les résultats à la plage d'adresses donnée entre bas et haut. Notez que les arguments bas et haut sont une seule chaîne séparée par une virgule.
-X
Affiche encore plus de détails que l'option -x. ATTENTION : le format change en fonction de /proc/PID/smaps
-XX
Affiche tout ce que le noyau fournit.
-p, --show-path
Affiche le chemin complet des fichiers dans la colonne de mappage.
-c, --read-rc
Lit la configuration par défaut.
-C, --read-rc-from fichier
Lit la configuration depuis fichier.
-n, --create-rc
Crée une nouvelle configuration par défaut.
-N, --create-rc-to fichier
Crée une nouvelle configuration dans fichier.
-h, --help
Affiche le texte d'aide et quitte.
-V, --version
Affiche les informations de version et quitte.

ÉTAT DE SORTIE

0
Succès.
1
Échec.
42
N'a pas trouvé tous les processus demandés.

VOIR AUSSI

ps(1), pgrep(1)

NORMES

Aucune norme ne s'applique, mais pmap ressemble beaucoup à une commande SunOS.

SIGNALER LES BOGUES

Veuillez envoyer les rapports de bogues à procps@freelists.org.
