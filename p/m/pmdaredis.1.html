PMDAREDIS(1) Manuel des commandes générales PMDAREDIS(1)

NOM

pmdaredis - agent de domaine de métriques de performance Redis (PMDA)

DESCRIPTION

Ce PMDA extrait les données de performance en envoyant la commande INFO à un serveur Redis (redis.io), ce qui inclut :

•
Informations générales sur le serveur Redis
•
Connexions clients
•
Consommation de mémoire
•
Statistiques de persistance
•
Statistiques de réplication
•
Statistiques de consommation CPU
•
Statistiques des commandes Redis
•
Statistiques du cluster Redis
•
Statistiques liées à la base de données

Le nom d'hôte (localhost), le port (6379 par défaut) et d'autres informations de configuration doivent être spécifiés dans le fichier $PCP_PMDAS_DIR/redis/redis.conf.

# cd $PCP_PMDAS_DIR/redis
# [ éditer redis.conf ]
  host=localhost.localdomain:6379

Une fois cela configuré, vous pouvez accéder aux noms et valeurs des métriques de performance redis en faisant ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/redis
# ./Install

Pour désinstaller, les actions suivantes doivent être effectuées en tant que root :

# cd $PCP_PMDAS_DIR/redis
# ./Remove

pmdaredis est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/redis/redis.conf
fichier de configuration obligatoire listant les instances redis surveillées
$PCP_PMDAS_DIR/redis/Install
script d'installation pour l'agent pmdaredis
$PCP_PMDAS_DIR/redis/Remove
script d'annulation de l'installation pour l'agent pmdaredis
$PCP_LOG_DIR/pmcd/redis.log
fichier journal par défaut pour les messages d'erreur de pmdaredis

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, tel que décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1) et pmcd(1).
