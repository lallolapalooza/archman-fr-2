PMDAPROFILE(3) Manuel des fonctions de bibliothèque PMDAPROFILE(3)

NOM

pmdaProfile - met à jour le profil d'instance pour le PMDA en préparation de la prochaine récupération à partir de PMCD

C SYNTAXE

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaProfile(pmProfile *prof, pmdaExt *pmda);

cc ... -lpcp_pmda -lpcp

DESCRIPTION

Dans le cadre de l'API du domaine de métriques de performance (PMDA) (voir PMDA(3)), pmdaProfile est la fonction de rappel par défaut qui gère la réception d'un pmProfile de pmcd(1). Un profil décrit les instances dont pmcd a besoin dans la structure pmResult renvoyée par la prochaine récupération. pmdaProfile stocke simplement le nouveau profil.

AVERTISSEMENT

Le PMDA doit utiliser PMDA_INTERFACE_2 ou une version ultérieure, comme spécifié dans l'appel à pmdaDSO(3) ou pmdaDaemon(3).

VOIR AUSSI

PMAPI(3), PMDA(3), pmdaDaemon(3), pmdaDSO(3) et pmdaFetch(3).
