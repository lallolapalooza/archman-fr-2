PMSEARCH(1) Manuel des commandes générales PMSEARCH(1)

NOM

pmsearch - Aide et noms de recherche pour les métriques, les instances et les domaines d'instances.

SYNTAXE

pmsearch [-CdinqsStTV?] [-c config] [-D debug] [-h hote] [-p port] [-N nombre] [-O decalage] [requete | indom]

DESCRIPTION

pmsearch effectue des requêtes de recherche textuelle complète pour trouver des métriques en utilisant les noms et les textes d'aide des métriques, des domaines d'instances et des instances.

Il exploite les capacités du service Performance Co-Pilot (PCP) pmproxy(1), du magasin clé-valeur distribué Valkey et du module ValkeySearch associé.

Notez que pour utiliser ces services, il est obligatoire que pmproxy communique avec un serveur clé-valeur Valkey qui a chargé le module valkey-search.so. Lorsqu'il est configuré pour le faire, pmproxy indexera alors automatiquement les noms de métriques PCP, les noms d'instances, et les textes d'aide des métriques et des domaines d'instances dans le magasin ValkeySearch, à partir des archives PCP qu'il découvre localement. Référez-vous à pmlogger(1) et pmlogger_daily(1) pour plus de détails.

Par défaut, pmsearch communique avec un serveur clé-valeur local, cependant les options -h et -p peuvent être utilisées pour spécifier une instance Valkey alternative. Si cette instance est un nœud d'un cluster Valkey, toutes les autres instances du cluster seront découvertes et utilisées automatiquement.

OPTIONS

-c config, --config=config
Spécifie le fichier config à utiliser.
-C, --no-colour
Pas de mise en évidence dans le texte des résultats.
-d, --docid
Rapporte l'identifiant du document de chaque résultat de recherche. Les documents sont identifiés par un hachage SHA-1 unique qui est toujours affiché sous une forme lisible par l'homme de 40 chiffres hexadécimaux.
-h hote, --host=hote
Se connecte au serveur clé-valeur sur hote, plutôt qu'à celui de localhost.
-i, --info
Rapporte les métriques internes du moteur de recherche.
-n, --indom
Effectue une recherche d'entités liées au domaine d'instance instance.
-N N, --number=N
Retourne au plus N résultats de recherche.
-O N, --offset=N
Résultats paginés à partir du décalage donné.
-p port, --port=port
Se connecte au serveur clé-valeur sur le port, plutôt que le port par défaut 6379.
-q, --query
Effectue une recherche textuelle générale (par défaut).
-s, --suggest
Effectue une recherche de suggestion de nom.
-S, --score
Rapporte le score (classement) de chaque résultat.
-T, --total
Rapporte le nombre total de résultats de recherche.
-t, --times
Rapporte le temps d'exécution de la recherche.
-V, --version
Affiche le numéro de version et quitte.
-?, --help
Affiche le message d'utilisation et quitte.

EXEMPLES

$ pmsearch kernel idle
Type: metric
Name: kernel.all.cpu.idle
One line: total idle CPU time from /proc/stat for all CPUs
Type: metric
Name: kernel.all.idletime
One line: time the current kernel has been idle since boot
Type: metric
Name: kernel.percpu.cpu.idle
InDom: 60.0
One line: percpu idle CPU time metric from /proc/stat

ENVIRONNEMENT PCP

Les variables d'environnement préfixées par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

Pour les variables d'environnement affectant les outils PCP, voir pmGetOptions(3).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à trier les problèmes, bien que les informations soient parfois cryptiques et principalement destinées aux développeurs plutôt qu'aux utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.
