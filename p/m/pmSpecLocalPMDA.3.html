NOM

pmSpecLocalPMDA - Traite un argument de ligne de commande pour la table des PMDA DSO

C SYNTAXE

#include"pmapi.h"
#include"libpcp.h"

char *pmSpecLocalPMDA(const char *spec);

cc ... -lpcp

DESCRIPTION

Pour les applications PCP (Performance Co-Pilot), les contextes de type PM_CONTEXT_LOCAL sont utilisés par les clients qui souhaitent récupérer des métriques directement à partir d'un ou plusieurs PMDA sur l'hôte local sans impliquer pmcd(1).

pmSpecLocalPMDA fournit un wrapper pratique destiné à être utilisé par les applications qui souhaitent utiliser un argument de ligne de commande (généralement avec -K) pour contrôler les PMDA DSO qui sont disponibles pour un contexte PM_CONTEXT_LOCAL.

L'argument spec spécifie des actions pour un ou plusieurs PMDA DSO en utilisant jusqu'à quatre champs séparés par des virgules (``,''), à savoir :

  • un opcode parmi les valeurs add (ajouter une nouvelle entrée), del (supprimer une entrée existante) ou clear (effacer toutes les entrées de la table).
  • le numéro de domaine du PMDA
  • le chemin vers le DSO du PMDA (peut être absolu ou relatif au répertoire $PCP_VAR_DIR/pmdas et le suffixe DSO est facultatif), et
  • le nom de la routine d'initialisation du PMDA.

Tous les champs sont requis pour ajouter une nouvelle entrée. Pour supprimer une entrée, l'opcode est requis ainsi qu'un ou les deux champs : le numéro de domaine et/ou le chemin. Pour effacer toutes les entrées, seul l'opcode est requis.

Si spec est analysé avec succès, la table DSO est mise à jour avec les champs extraits.

VALEUR DE RETOUR

En cas de succès, pmSpecLocalPMDA retournera NULL.

En cas d'erreur ou d'échec, pmSpecLocalPMDA retournera un pointeur vers un message d'erreur statique.

EXEMPLES

Quelques exemples de chaînes spec valides :

clear
Supprime toutes les entrées de la table DSO.
add,123,foo/foo_pmda,foo_init
Ajoute le PMDA ``foo'' en utilisant le domaine 123. Le DSO du PMDA se trouve très probablement dans le répertoire $PCP_PMDAS_DIR et est nommé foo/foo_pmda.so (pour les plateformes de type ELF) ou foo/foo_pmda.dylib (pour les plateformes de type BSD) ou foo\foo_pmda.dll (pour les plateformes de type Windows). La routine d'initialisation pour le PMDA ``foo'' est foo_init().
del,123
Supprime l'entrée pour le DSO avec le domaine 123.
del,,foo/foo_pmda
Supprime l'entrée avec un chemin vers le DSO qui correspond à foo/foo_pmda.
del,123,foo/foo_pmda
Supprime l'entrée pour le DSO avec le domaine 123 et/ou un chemin vers le DSO qui correspond à foo/foo_pmda.

VOIR AUSSI

pmcd(1), PMAPI(3) et pmNewContext(3).
