pmdaText(3)

Paquet: pcp

PMDATEXT(3) Manuel des fonctions de bibliothèque PMDATEXT(3)

NOM

pmdaText - extraire le texte d'aide des métriques pour un PMDA

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaText(int ident,
int type, char **buffer, pmdaExt *pmda);

cc ... -lpcp_pmda -lpcp

DESCRIPTION

Dans le cadre de l'API du domaine des métriques de performance (PMDA) (voir PMDA(3)), pmdaText utilise les structures de données standard PMDA(3) pour retourner le texte d'aide de la métrique ident dans buffer. Le texte d'aide doit être situé dans des fichiers d'aide créés avec newhelp(1), et les fichiers associés sont automatiquement ouverts par pmdaInit(3).

Le chemin vers le (nom de base des) fichiers de texte d'aide peut être défini dans les appels à pmdaDSO(3) ou pmdaDaemon(3) et remplacé par l'option de ligne de commande -h dans pmdaGetOpt(3).

Le codage de ident suit le schéma interne utilisé par les routines pmLookupText(3) et pmLookupInDomText(3), à savoir que ident encode soit un identifiant de métrique, soit un identifiant de domaine d'instance, selon la valeur de type.

L'argument type est un masque de bits qui code l'interprétation de ident et la forme de texte d'aide demandée, comme suit : soit PM_TEXT_PMID si ident est un identifiant de métrique, soit PM_TEXT_INDOM si ident est un identifiant de domaine d'instance, plus soit PM_TEXT_ONELINE pour le texte d'aide sur une seule ligne, soit PM_TEXT_HELP pour le texte d'aide complet.

Le buffer est géré en interne (généralement mis en cache), et il ne doit pas être libéré ou désalloué par l'appelant de pmdaText.

ATTENTION

Le PMDA doit utiliser PMDA_INTERFACE_2 ou une version ultérieure, comme spécifié dans l'appel à pmdaDSO(3) ou pmdaDaemon(3).

DIAGNOSTICS

Si le texte d'aide demandé n'a pas pu être obtenu, pmdaText retournera PM_ERR_TEXT.

VOIR AUSSI

newhelp(1), malloc(3), PMAPI(3), PMDA(3), pmdaDaemon(3), pmdaDSO(3), pmdaInit(3), pmLookupInDomText(3) et pmLookupText(3).
