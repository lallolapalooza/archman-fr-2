PMDAMONGODB(1) Manuel des commandes générales PMDAMONGODB(1)

NOM

pmdamongodb - métriques de la base de données MongoDB

DESCRIPTION

pmdamongodb est un agent de domaine de métriques de performance (PMDA) de Performance Co-Pilot (PCP) qui extrait des données de performance en temps réel d'un serveur de base de données MongoDB en cours d'exécution.

CONFIGURATION

Premièrement, pmdamongodb nécessite l'installation des packages de support pymongo - un module Python à usage général pour interroger MongoDB.

Ensuite, pmdamongodb lit un fichier de configuration optionnel de style ini :

$PCP_PMDAS_DIR/mongodb/mongodb.conf

Ce fichier permet actuellement deux sections, une pour configurer la connexion socket MongoDB, l'autre pour l'authentification.

[connection]

host (localhost)
Se connecter au socket MongoDB sur le nom d'hôte donné.
port (27017)
Se connecter au socket MongoDB sur le port donné.

[authentification]

nom_utilisateur (vide)
Nom d'utilisateur pour se connecter à la base de données.
mot_de_passe (vide)
Mot de passe pour se connecter à la base de données.

INSTALLATION

Pour installer, les actions suivantes doivent être effectuées en tant que root :

# cd $PCP_PMDAS_DIR/mongodb
# ./Install

Pour désinstaller, les actions suivantes doivent être effectuées en tant que root :

# cd $PCP_PMDAS_DIR/mongodb
# ./Remove

pmdamongodb est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou désinstallé.

FICHIERS

$PCP_PMDAS_DIR/mongodb/mongodb.conf
fichier de configuration pour l'agent pmdamongodb
$PCP_PMDAS_DIR/mongodb/Install
script d'installation pour l'agent pmdamongodb
$PCP_PMDAS_DIR/mongodb/Remove
script d'annulation d'installation pour l'agent pmdamongodb
$PCP_LOG_DIR/pmcd/mongodb.log
fichier journal par défaut pour les messages de l'agent pmdamongodb

Notez que la valeur habituelle/par défaut pour $PCP_PMDAS_DIR est /var/lib/pcp/pmdas et la valeur par défaut pour $PCP_LOG_DIR est /var/log/pcp, mais ces paramètres dépendent de la plateforme.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI
