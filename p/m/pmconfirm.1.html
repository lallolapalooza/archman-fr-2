PMQUERY(1) Manuel des commandes générales PMQUERY(1)

NOM

pmconfirm, pmmessage, pmquery - boîte de dialogue à usage général

SYNTAXE

pmconfirm [-c] [-b nom-bouton] [-B nom-bouton-par-défaut] [-t chaîne] [-file nom-fichier] [-icon type-icône] [-font police] [-header chaîne-titre] [-useslider] [-noslider] [-noframe] [-exclusive]

pmmessage [-buttons libellé1[:valeur1][,libellé2[:valeur2][,...]]] [-center] [-nearmouse] [-default bouton] [-file nom-fichier] [-print] [-timeout sec] message...

pmquery [-input] [toutes les options ci-dessus...] [message...]

DESCRIPTION

pmquery fournit une implémentation compatible avec les options de ligne de commande des outils xconfirm et xmessage, utilisant un look and feel cohérent avec pmchart. Plusieurs extensions aux fonctionnalités des outils d'origine ont été apportées, afin d'améliorer leur utilité spécifique pour pmchart, mais dans la mesure du possible, les sémantiques d'origine sont conservées.

pmconfirm affiche une ligne de texte pour chaque option -t spécifiée (ou un fichier lorsque l'option -file est utilisée), et un bouton pour chaque option -b spécifiée. Lorsque l'un des boutons est pressé, le libellé de ce bouton est écrit sur la sortie standard de pmquery. Cela fournit un moyen de communication/retour d'information depuis des scripts shell et un moyen d'afficher des informations utiles à un utilisateur à partir d'une application.

pmmessage affiche une fenêtre contenant un message provenant de la ligne de commande, d'un fichier ou de l'entrée standard. Il permet en outre d'associer des boutons à un statut de sortie, et écrira seulement en option le libellé du bouton sur la sortie standard.

pmquery étend les outils ci-dessus pour prendre en charge en plus une entrée utilisateur limitée, sous forme de texte libre. Dans ce mode -input, tout texte entré sera affiché lorsque le bouton par défaut sera pressé. Un texte par défaut peut être entré en utilisant les mêmes mécanismes que les autres outils.

Des options de ligne de commande sont disponibles pour spécifier le style de police, le style de cadre, la modalité et l'une des plusieurs icônes différentes à présenter pour un retour visuel adapté à l'utilisateur.

OPTIONS

Les options de ligne de commande disponibles sont :

-c, -center
Centre la fenêtre sur l'écran.
-nearmouse
Fait apparaître la fenêtre près du curseur de la souris.
-b nom-bouton
Affiche un bouton avec le libellé nom-bouton. Si nom-bouton est une chaîne vide, le bouton à cet emplacement n'est pas affiché. Si aucune option -b n'est présente, le bouton par défaut est un bouton avec le libellé Continue. Le statut de sortie associé à nom-bouton est zéro.
-B nom-bouton-par-défaut
Affiche un bouton avec le libellé nom-bouton-par-défaut et le spécifie comme bouton à activer lorsque la touche Entrée est pressée. Le statut de sortie associé à nom-bouton-par-défaut est zéro.
-buttons bouton,bouton,...
Cette option créera un bouton pour chaque bouton séparé par des virgules. Chaque bouton consiste en un libellé suivi éventuellement d'un deux-points et d'une valeur de sortie. La valeur de sortie sera retournée si ce bouton est sélectionné. La valeur de sortie par défaut est 100 plus le numéro du bouton. Les boutons sont numérotés de gauche à droite à partir de un.
-default libellé
Définit le bouton avec un libellé correspondant comme étant le défaut. Si non spécifié, il n'y a pas de défaut. La ressource correspondante est defaultButton. Appuyer sur Entrée n'importe où dans la fenêtre xmessage activera le bouton par défaut. Le bouton par défaut a une bordure plus large que les autres.
-t message
Affiche un message. N'importe quel nombre de chaînes peut être listé sur la ligne de commande (chacune doit être précédée de l'option -t).
-file nom-fichier
Affiche le fichier nom-fichier. Toutes les options -t seront ignorées. Un nom-fichier de `-' lit depuis l'entrée standard.
-icon type-icône
Affiche l'icône type-icône où type-icône est l'un de : info, error, question, warning, critical. action est aussi accepté comme synonyme de error pour la compatibilité descendante. pmquery introduit les types d'icônes supplémentaires archive et host ainsi que les types originaux xconfirm listés précédemment.
-font nom-police
Utilise nom-police comme police. Cette option n'est disponible que lors de l'utilisation du système X Window.
-header chaîne
Utilise chaîne comme titre de la fenêtre.
-print
Cela fait que le programme écrit le libellé du bouton pressé sur la sortie standard. C'est le comportement par défaut pour pmconfirm et pmquery.
-noprint
Cela fait que le programme n'écrit pas le libellé du bouton pressé sur la sortie standard. C'est le comportement par défaut pour pmmessage.
-geometry chaîne-géométrie
Cela fournit à l'outil une spécification de chaîne de géométrie compatible avec X. Cette option n'est disponible que lors de l'utilisation du système X Window.
-useslider
Lors de l'affichage d'un fichier, utilise toujours un curseur au lieu de déterminer automatiquement si un curseur est nécessaire.
-noslider
Ne crée pas de curseur et coupe le texte à la taille de la fenêtre, au lieu de déterminer automatiquement si un curseur est nécessaire.
-noframe
N'affiche pas de cadre autour du contenu.
-exclusive
Capture le clavier/pointeur et ne permet aucune autre entrée jusqu'à ce qu'un bouton soit pressé.
-timeout sec
Sort avec le statut 0 après sec secondes si l'utilisateur n'a pas encore cliqué sur un bouton. La ressource correspondante est timeout.
-?, -h, -help
Affiche le message d'utilisation et quitte.

EXEMPLES

Le script shell suivant affichera une fenêtre avec une icône d'information, demandant à l'utilisateur une question oui ou non avec "Yes" comme réponse par défaut.

 #! /bin/sh
 case `pmquery -t "Vraiment éteindre ?" -b Non -B Oui -icon question
 in
   Oui) shutdown;;
   Non) ;;
 esac

Un deuxième exemple, qui demande un nom d'hôte puis démarre un terminal avec une session ssh connectée à l'hôte demandé.

 #! /bin/sh
 host=`pmquery -input -icon host -b Annuler -B OK \
               -header "Terminal distant - Secure Shell"
 [ "$host" = "Annuler" -o -z "$host" ] && exit
 gnome-terminal -e "ssh $host"

ENVIRONNEMENT

pmquery est un excellent choix d'utilitaire pour le paramètre de configuration PCP_XCONFIRM_PROG de Performance Co-Pilot (référez-vous à pcp.conf(5) pour les détails).

Notez que PCP_XCONFIRM_PROG sera automatiquement défini sur pmquery dans les outils comme pmchart, sauf si PCP_XCONFIRM_PROG est déjà défini dans l'environnement.

STATUT DE SORTIE

En cas de détection d'une erreur, pmquery retourne toujours 1, cette valeur ne doit donc pas être associée à un bouton. Sauf si l'option -button n'a pas été utilisée, le code de retour sera zéro en cas de succès.
