NOM

pmSeriesSetup, pmSeriesSetSlots, pmSeriesSetEventLoop, pmSeriesSetConfiguration, pmSeriesSetMetricRegistry, pmSeriesClose - services de séries temporelles rapides et évolutifs

SYNTAXE C

#include <pcp/pmwebapi.h>

int pmSeriesSetup(pmSeriesModule *module,
pmSeriesCallBacks *callbacks, void *arg);

int pmSeriesSetSlots(pmSeriesModule *module,
void *slots);

int pmSeriesSetEventLoop(pmSeriesModule *module,
void *uvloop);

int pmSeriesSetConfiguration(pmSeriesModule *module,
struct dict *config);

int pmSeriesSetMetricRegistry(pmSeriesModule *module,
struct mmv_registry *registry);

int pmSeriesClose(pmSeriesModule *module);

cc ... -lpcp_web

DESCRIPTION

Les fonctions API pmSeriesSetup et associées préparent une application à accéder aux fonctionnalités de requête de séries temporelles rapides et évolutives de Performance Co-Pilot (PCP).

Cette fonctionnalité est fournie par des API asynchrones, qui fonctionnent de manière événementielle. Les interfaces décrites ici préparent un module de séries temporelles donné qui associe des routines de rappel à certains événements asynchrones qui se produisent lors du traitement des requêtes de séries temporelles.

En tant que modèle général, toutes les interfaces de ces API qui doivent invoquer des callbacks fournis par le programme appelant prendront un paramètre opaque (pointeur void *), arg. Ce pointeur sera passé tel quel et est généralement utilisé pour accéder à une structure de données maintenant l'état dans le programme appelant.

Lorsque la configuration asynchrone est requise par pmSeriesSetup, son achèvement sera indiqué par l'utilisation du rappel on_setup, qui fait partie de la structure pmSeriesModule passée. Cette structure fournit également une gestion des diagnostics personnalisés, via le rappel on_info. Ceux-ci s'expliquent d'eux-mêmes, voir <pcp/pmwebapi.h> pour les conventions d'appel exactes.

Les callbacks enregistrés par pmSeriesSetup pour gérer les événements sont les suivants :

pmSeriesMatchCallBack on_match
Lorsqu'une requête de séries temporelles découvre des identifiants de séries temporelles qui correspondent à la requête, le rappel on_match sera appelé une fois pour chaque identifiant de série (SID). Le SID est une représentation ASCII unique de 40 octets d'un hachage SHA.
pmSeriesDescCallBack on_desc
Les requêtes de descripteurs de métriques de pmSeriesDescs(1) invoqueront ce rappel une fois pour chaque identifiant de série.
pmSeriesInstCallBack on_inst
Rappel d'identification d'instance - identifiants d'instance internes (numériques) et externes (chaîne de caractères), ainsi que les identifiants SHA1 de séries temporelles et de source (hôte). Appelée une fois pour chaque instance. L'identifiant de série associé est également fourni au rappel.
pmSeriesLabelCallBack on_labelmap
Fournit les étiquettes de métriques (noms et correspondances de valeurs) pour chaque identifiant de série passé à pmSeriesLabels(1).
pmSeriesStringCallBack on_instance
Fournit un nom d'instance pour un appel à pmSeriesInstances(1)- le rappel est appelé une fois pour chaque nom d'instance. L'identifiant de série associé est également fourni au rappel.
pmSeriesStringCallBack on_context
Fournit un nom de contexte pour un appel à pmSeriesSources(1)- le rappel est appelé une fois pour chaque source (nom d'hôte ou archive). Le identifiant de source associé est également fourni au rappel.
pmSeriesStringCallBack on_metric
Fournit un nom de métrique pour un appel à pmSeriesMetrics(1)- le rappel est appelé une fois pour chaque nom de métrique. L'identifiant de série associé est également fourni au rappel.
pmSeriesStringCallBack on_label
Fournit un nom d'étiquette pour un appel à pmSeriesLabels(1)- le rappel est appelé une fois pour chaque nom d'étiquette. L'identifiant de série associé est également fourni au rappel.
pmSeriesValueCallBack on_value
Les appels à l'interface pmSeriesQuery qui fournissent une fenêtre temporelle peuvent entraîner la découverte de valeurs pour les séries temporelles correspondantes. Le rappel on_value sera invoqué une fois pour chaque valeur de série temporelle, fournissant également l'horodatage de l'échantillon (sous forme de chaîne et binaire, comme un temps en nanosecondes depuis l'époque). L'identifiant de série associé est également fourni au rappel.
pmSeriesDoneCallBack on_done
À la fin de toutes les interfaces asynchrones qui retournent un succès (code de retour zéro), ce rappel sera appelé. Il fournit un code de statut indiquant le succès global (zéro) ou l'échec (code PMAPI négatif) de l'opération.

Les fonctions utilitaires pmSeriesSetSlots (serveur clé-valeur), pmSeriesSetEventLoop (libuv), pmSeriesSetConfiguration (fichier de configuration) et pmSeriesSetMetricRegistry (instrumentation MMV) fournissent un mécanisme pour passer l'état de chacun des sous-systèmes associés.

Enfin, un appel à pmSeriesClose est utilisé pour terminer les services disponibles à partir d'un module de série établi précédemment par pmSeriesSetup.

Dans PCP, les utilitaires pmproxy(1) et pmseries(1) sont les principaux utilisateurs de ces interfaces, fournissant respectivement des services de requête de séries temporelles via API REST et ligne de commande.

DIAGNOSTICS

Lorsque ces fonctions retournent un code de statut, il est toujours zéro en cas de succès. En cas d'échec, un code d'erreur PMAPI négatif est retourné.

VOIR AUSSI

pmproxy(1), pmlogger(1), pmseries(1), mmv_stats_registry(3), pmSeriesDescs(3), pmSeriesQuery(3), PMAPI(3) et PMWEBAPI(3).

pmSeriesSetup(3) — Documentation Arch Linux

NOM

pmSeriesSetup — Configure une série PM

SYNOPSIS

#include <pcp/pmapi.h>

int pmSeriesSetup(pmSeries *series, const char *name, const char *config);

DESCRIPTION

pmSeriesSetup configure la série spécifiée par series avec les informations de nom et de configuration. La chaîne name doit être un nom unique pour cette série PM. La chaîne config doit être une description de configuration pour cette série PM.

VALEURS DE RETOUR

En cas de succès, pmSeriesSetup renvoie 0. En cas d’échec, elle renvoie un numéro d’erreur négatif.

VOIR AUSSI

pmSeriesArchiveControl(3), pmSeriesStart(3), pmSeriesStop(3)
