NOM

pmdbg - signaler les options de débogage de Performance Co-Pilot

SYNOPSIS

pmdbg [-l]

DESCRIPTION

Les composants de Performance Co-Pilot (PCP) utilisent un mécanisme global pour contrôler la sortie de diagnostic et de débogage.

pmdbg affiche toutes les options de débogage disponibles avec le nom de l'option et une brève description.

L'option -l ne fait rien, mais elle est incluse pour la compatibilité ascendante avec les anciennes versions de pmdbg.

La plupart des applications utilisant les facilités de PCP supportent la syntaxe de commande -D nom[,nom ...] pour activer le contrôle de débogage à l'aide du ou des noms des options de débogage désirées.

Alternativement, la valeur initiale des indicateurs de contrôle de débogage peut être définie à une liste séparée par des virgules si les noms d'option sont spécifiés via la variable d'environnement $PCP_DEBUG, à condition que les applications utilisent pmGetOptions(3) pour traiter les options et arguments de la ligne de commande. Si les deux mécanismes sont utilisés, leur effet est additif, de sorte que les indicateurs résultants sont ceux définis via $PCP_DEBUG combinés à ceux définis via toute option de ligne de commande -D.

ENVIRONNEMENT PCP

Les variables d'environnement commençant par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

COMPATIBILITÉ

Avant PCP 7.0, les options de débogage étaient maintenues dans un état double avec un entier encodé en binaire de style ancien (plus un nom de macro pour les programmeurs), et un nom de chaîne de caractères de style nouveau pour chaque option de débogage.

Dans PCP 7.0, le support du style ancien a été supprimé.
