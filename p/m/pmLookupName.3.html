PMLOOKUPNAME(3) Manuel des fonctions de bibliothèque PMLOOKUPNAME(3)

NOM

pmLookupName - traduire les noms de métriques de performance en PMID

SYNTAXE

#include <pcp/pmapi.h>

int pmLookupName(int numpmid,
const char **namelist, pmID *pmidlist);

cc ... -lpcp

DESCRIPTION

Étant donné une liste dans namelist contenant numpmid chemins complets pour les métriques de performance d'un Espace de noms de métriques de performance (PMNS), pmLookupName renvoie la liste des Identifiants de métriques de performance (PMID) associés via pmidlist.

Le résultat de pmLookupName dépend de la présence d'échecs de recherche, de leur sévérité et du nombre de métriques recherchées.

1.
S'il n'y a aucun échec de recherche, la valeur de retour sera numpmid.
2.
Si une erreur fatale est rencontrée, la valeur de retour sera inférieure à 0. Par exemple PM_ERR_TOOSMALL, PM_ERR_NOPMNS ou PM_ERR_IPC.
3.
Si numpmid est supérieur à un et que des erreurs non fatales sont rencontrées, la valeur de retour est le nombre de noms de métriques qui ont été recherchés avec succès (supérieur ou égal à zéro et inférieur ou égal à numpmid).
4.
Si numpmid est un et qu'une erreur non fatale est rencontrée, la valeur de retour est le code d'erreur (inférieur à zéro).

Lorsque des erreurs sont rencontrées, toutes les métriques qui ne peuvent pas être recherchées entraînent la définition de l'élément correspondant de pmidlist à PM_ID_NULL.

Le protocole d'erreur légèrement compliqué permet des recherches en masse, puis la recherche de plus de détails sur les erreurs en cas d'échec spécifique, comme montré dans la section EXEMPLE ci-dessous.

Notez que le protocole d'erreur garantit une relation 1:1 entre les éléments de namelist et pmidlist, par conséquent, les deux listes contiennent exactement numpmid éléments. Pour cette raison, il est attendu de l'appelant qu'il ait pré-alloué un tableau de taille appropriée pour pmidlist.

EXEMPLE

#include <pcp/pmapi.h>
#define NUMPMID (sizeof(names)/sizeof(const char *))
const char *names[] = {
		     "sample.bin",
		     "sample",
		     "sample.bog",
		     "sample.secret.bar",
		     "sample.secret.bar.bad"
		   };
pmID pmids[NUMPMID];
int
main(int argc, char **argv)
{
    int	sts;
    int	numpmid = NUMPMID;
    pmNewContext(PM_CONTEXT_HOST, "local:");
    sts = pmLookupName(numpmid, names, pmids);
    if (sts < 0) {
	fprintf(stderr, "pmLookupName failed: %s0, pmErrStr(sts));
	exit(1);
    }
    if (sts != numpmid) {
	/*
	 * some of the lookups failed ... report the reason(s)
	 */
	int	i;
	for (i = 0; i < numpmid; i++) {
	    if (pmids[i] != PM_ID_NULL) continue;
	    /* this one failed */
	    sts = pmLookupName(1, &names[i], &pmids[i]);
	    fprintf(stderr, "%s: lookup failed: %s0, names[i], pmErrStr(sts));
	}
	exit(1);
    }
    /* all good ... */
    ...
}

DIAGNOSTICS

PM_ERR_TOOSMALL
numpmid doit être au moins 1
PM_ERR_NOPMNS
Échec d'accès à un PMNS pour l'opération. Notez que si l'application n'a pas appelé au préalable pmLoadNameSpace(3) et souhaite utiliser le PMNS distribué, alors un appel à pmLookupName doit être effectué après la création d'un contexte (voir pmNewContext(3)).
PM_ERR_NAME
namelist[0] ne correspond pas à un nom de métrique valide dans le PMNS.
PM_ERR_NONLEAF
namelist[0] fait référence à un nœud dans le PMNS mais ce n'était pas un nœud feuille.
PM_ERR_*
D'autres diagnostics concernent les échecs de protocole lors de l'accès au PMNS distribué.
