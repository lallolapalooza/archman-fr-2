PMTYPESTR(3) Manuel des fonctions de bibliothèque PMTYPESTR(3)

NOM

pmTypeStr, pmTypeStr_r - convertir un type de métrique de performance en chaîne de caractères

SYNTAXE C

#include <pcp/pmapi.h>

const char *pmTypeStr(int type);
char *pmTypeStr_r(int type, char *buf, int buflen);

cc ... -lpcp

DESCRIPTION

Étant donné un type de métrique de performance, pmTypeStr produit un équivalent ASCII concis, approprié pour une utilisation dans les messages d'erreur et de diagnostic. La fonction pmTypeStr_r fait de même, mais stocke le résultat dans un tampon fourni par l'utilisateur buf d'une longueur buflen, qui devrait avoir de la place pour au moins 20 octets.

La valeur pour type est typiquement extraite d'une structure pmDesc, après un appel à pmLookupDesc(3) pour une métrique de performance particulière.

Les exemples sont 32 (pour type égal à PM_TYPE_32), U64 (pour type égal à PM_TYPE_U64), STRING (pour type égal à PM_TYPE_STRING), etc.

NOTES

Ces deux fonctions peuvent être appelées en toute sécurité depuis des contextes multi-threads.

VOIR AUSSI

PMAPI(3), pmAtomStr(3), pmConvScale(3), pmExtractValue(3), pmLookupDesc(3), pmPrintValue(3), pmIDStr(3), pmInDomStr(3), pmSemStr(3) et pmUnitsStr(3).
