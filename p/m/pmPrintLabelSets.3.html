PMPRINTLABELSETS(3) Manuel des fonctions de bibliothèque PMPRINTLABELSETS(3)

NOM

pmPrintLabelSets - affiche un tableau d'ensembles d'étiquettes

SYNTAXE C

#include <pcp/pmapi.h>

void pmPrintLabelSets(FILE *f,
int ident, int type, pmLabelSet *sets, int nsets);

cc ... -lpcp

DESCRIPTION

Affiche tous les éléments de l'ensemble d'étiquettes de métriques de performance sets associé à l'identifiant ident du niveau de hiérarchie type. sur le flux de sortie f.

VOIR AUSSI

PMAPI(3) et pmLookupLabels(3).
