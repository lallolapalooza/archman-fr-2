PMDADS389LOG(1) Manuel des commandes générales PMDADS389LOG(1)

NOM

pmdads389log - Agent PMD pour le journal du serveur d'annuaire 389

DESCRIPTION

pmdads389log est un agent de domaine de métriques de performance (PMDA) qui extrait les statistiques du journal d'accès du serveur d'annuaire 389 à l'aide de l'utilitaire logconv.pl(1).

INSTALLATION

pmdads389log lit le fichier de configuration

$PCP_PMDAS_DIR/ds389log/ds389log.conf

Ce fichier peut contenir des valeurs redéfinies (code Perl) pour les paramètres listés au début de pmdads389log.pl, à savoir :

  • Paramètres de logconv.pl
  • Intervalle de requête minimal
  • Journal d'accès du DS 389 à utiliser
  • Répertoire du journal DS 389 à utiliser (utilisé si aucun fichier n'est spécifié)
  • Utilisateur non root ayant un accès en lecture au fichier journal d'accès

Une fois cela configuré, vous pouvez accéder aux noms et valeurs des métriques de performance du DS 389 en procédant comme suit en tant que root :

# cd $PCP_PMDAS_DIR/ds389log
# ./Install

Pour désinstaller, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/ds389log
# ./Remove

pmdads389log est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts d'installation et de désinstallation informent pmcd(1) lorsque l'agent est installé ou désinstallé.

FICHIERS

$PCP_PMDAS_DIR/ds389log/ds389log.conf
fichier de configuration de l'agent pmdads389log
$PCP_PMDAS_DIR/ds389log/Install
script d'installation de l'agent pmdads389log
$PCP_PMDAS_DIR/ds389log/Remove
script d'annulation de l'installation de l'agent pmdads389log
$PCP_LOG_DIR/pmcd/ds389log.log
fichier journal par défaut pour les messages d'erreur de pmdads389log
/var/log/dirsrv/slapd-.../access
journal d'accès du serveur d'annuaire 389 analysé par logconv.pl

ENVIRONNEMENT PCP

Les variables d'environnement préfixées par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1), logconv.pl(1), pmcd(1) et pmdads389(1).
