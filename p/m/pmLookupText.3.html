PMLOOKUPTEXT(3) Manuel des fonctions de bibliothèque PMLOOKUPTEXT(3)

NOM

pmLookupText - renvoie le texte décrivant une métrique de performance

C SYNTAXE

#include <pcp/pmapi.h>

int pmLookupText(pmID pmid, int level, char **buffer);

cc ... -lpcp

DESCRIPTION

Récupère le texte descriptif de la métrique de performance identifiée par pmid.

L'argument level doit être soit PM_TEXT_ONELINE pour un résumé en une ligne, soit PM_TEXT_HELP pour une description plus détaillée, adaptée à une boîte de dialogue d'aide.

L'espace pointé par buffer aura été alloué dans pmLookupText avec malloc(3), et il est de la responsabilité de l'appelant de libérer cet espace avec free(3) lorsqu'il n'est plus nécessaire.

pmLookupText renvoie zéro en cas de succès.

DIAGNOSTICS

PM_ERR_NOTHOST
Pour les archives créées avec des versions de PCP antérieures à 4.0, si le contexte PMAPI actuel est une archive (le texte d'aide et en une ligne n'était pas précédemment maintenu dans les archives).
