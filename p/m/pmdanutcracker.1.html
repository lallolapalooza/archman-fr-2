PMDANUTCRACKER(1) Manuel des commandes générales PMDANUTCRACKER(1)

NOM

pmdanutcracker - agent de domaine de métriques NutCracker (PMDA)

DESCRIPTION

Ce PMDA extrait les données de performance de NutCracker (ou TwemProxy), un proxy rapide et léger pour les protocoles memcached et Redis.

INSTALLATION

Configurez pour exporter les statistiques via son interface de statistiques (voir l'option --stats-port du serveur nutcracker). La configuration correspondante doit être reflétée dans le fichier $PCP_PMDAS_DIR/nutcracker/nutcracker.conf.

# cd $PCP_PMDAS_DIR/nutcracker
# [ éditer nutcracker.conf ]

Une fois cela configuré, vous pouvez accéder aux noms et valeurs des métriques de performance de nutcracker en faisant ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/nutcracker
# ./Install

Pour désinstaller, il faut faire ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/nutcracker
# ./Remove

pmdanutcracker est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou retiré.

FICHIERS

$PCP_PMDAS_DIR/nutcracker/nutcracker.conf
fichier de configuration obligatoire listant les instances memcache ou Redis surveillées
$PCP_PMDAS_DIR/nutcracker/Install
script d'installation pour l'agent pmdanutcracker
$PCP_PMDAS_DIR/nutcracker/Remove
script d'annulation d'installation pour l'agent pmdanutcracker
$PCP_LOG_DIR/pmcd/nutcracker.log
fichier journal par défaut pour les messages d'erreur de pmdanutcracker

ENVIRONNEMENT PCP

Les variables d'environnement préfixées par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1), pmcd(1), pmdamemcache(1) et pmdaredis(1).
