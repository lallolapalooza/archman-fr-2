PMHOSTNAME(1) Manuel des commandes générales PMHOSTNAME(1)

NOM

pmhostname - signaler le nom d'hôte

SYNTAXE

pmhostname [-D debug] [-?] [hostname]

DESCRIPTION

pmhostname signale le nom de l'hôte hostname tel que retourné par gethostbyname(3).

Si hostname n'est pas spécifié, alors le nom d'hôte local est récupéré en utilisant gethostname(2) et celui-ci est ensuite passé à gethostbyname(3).

pmhostname fournit un service pour les scripts shell qui imite la logique anciennement utilisée par les applications Performance Co-Pilot lors de la tentative de détermination du nom officiel d'un hôte. Les applications PCP n'utilisent plus les heuristiques basées sur DNS, et par conséquent cette commande est *dépréciée*.

Si gethostbyname(3) échoue, le nom d'hôte d'entrée (soit hostname, soit le résultat de l'appel à gethostname(2)) est signalé.

OPTIONS

Les options de ligne de commande disponibles sont :

-?, --help
Affiche le message d'utilisation et quitte.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à diagnostiquer les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à fournir des conseils aux développeurs plutôt qu'aux utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

Les options de débogage spécifiques à pmhostname sont les suivantes :

Option Description
appl0 diagnostics détaillés, par exemple le résultat de l'appel à gethostname(2) et les routines PMAPI

VOIR AUSSI

nslookup(1), gethostname(2), gethostbyname(3), pcp.conf(5), pcp.env(5) et resolver(5).
