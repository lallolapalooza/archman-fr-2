PMDARESCTRL(1) Manuel des commandes générales PMDARESCTRL(1)

NOM

pmdaresctrl - agent de domaine de métriques de performance resctrl (PMDA)

SYNTAXE

$PCP_PMDAS_DIR/pmdaresctrl [-D debug] [-d domaine] [-l logfile]

DESCRIPTION

pmdaresctrl est un agent de domaine de métriques de performance (PMDA) pour resctrl qui expose les valeurs des métriques de performance de l'interface /sys/fs/resctrl pour fournir des informations sur le cache de dernier niveau.


Plus de détails sur le support Linux des métriques de cache de dernier niveau sont disponibles sur https://github.com/torvalds/linux/tree/master/Documentation/arch/x86/resctrl.rst.

INSTALLATION

Si vous souhaitez avoir accès aux noms, aux textes d'aide et aux valeurs des métriques de performance resctrl, effectuez les opérations suivantes en tant que root :

# cd $PCP_PMDAS_DIR/resctrl
# ./Install

Si vous souhaitez annuler l'installation (et supprimer les deux PMDA), effectuez les opérations suivantes en tant que root :

# cd $PCP_PMDAS_DIR/resctrl
# ./Remove

pmdaresctrl est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMCDCONF_PATH
options de ligne de commande utilisées pour lancer pmdaresctrl
$PCP_PMDAS_DIR/resctrl/help
fichier d'aide par défaut pour les métriques resctrl
$PCP_PMDAS_DIR/resctrl/Install
script d'installation pour l'agent pmdaresctrl
$PCP_PMDAS_DIR/resctrl/Remove
script d'annulation d'installation pour l'agent pmdaresctrl

ENVIRONNEMENT PCP

Les variables d'environnement commençant par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5). En particulier, $PCP_RESCTRL_DIR peut être défini pour modifier le répertoire par défaut de /sys/fs/resctrl.

OPTIONS DEBOGAGE

Les options -D ou --debug activent la sortie de diagnostics supplémentaires sur stderr pour aider à résoudre les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

VOIR AUSSI

PCPIntro(1), pmcd(1), pcp.conf(5), pcp.env(5) et resctrl(1).
