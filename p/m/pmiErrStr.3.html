PMIERRSTR(3) Manuel des fonctions de bibliothèque PMIERRSTR(3)

NOM

pmiErrStr, pmiErrStr_r - convertir un code d'erreur LOGIMPORT en chaîne de caractères

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/import.h>

const char *pmiErrStr(int code);
char *pmiErrStr_r(int code, char buf, int buflen);

cc ... -lpcp_import -lpcp

SYNTAXE Perl

use PCP::LogImport;

pmiErrStr($code);

DESCRIPTION

Dans le cadre de l'API d'importation de journaux de Performance Co-Pilot (voir LOGIMPORT(3)), pmiErrStr traduit les codes d'erreur renvoyés par les autres routines de la bibliothèque Log Import en messages d'erreur imprimables.

code aurait normalement une valeur négative. Dans un cas spécial, si code est -1, alors le code d'erreur renvoyé par la dernière routine appelée dans la bibliothèque LOGIMPORT pour ce contexte sera utilisé.

La fonction pmiErrStr_r fait de même, mais stocke le résultat dans un tampon fourni par l'utilisateur buf d'une longueur buflen, qui devrait avoir de la place pour au moins PMI_MAXERRMSGLEN octets.

L'ensemble des codes d'erreur et des messages possibles comprend tous ceux définis par pmErrStr(3) et PCPIntro(3), plus les codes supplémentaires définis dans <pcp/import.h> avec des noms de codes d'erreur de la forme PMI_ERR_....

VOIR AUSSI

LOGIMPORT(3), PCPIntro(3) et pmErrStr(3).
