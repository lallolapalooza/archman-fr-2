NOM

pmxchords - Ce script traite les fichiers pmx avec des symboles d'accords, permettant des transpositions de tonalité

SYNOPIS

[ texlua ] pmxchords { option | nom_travail [ .pmx ] } ...

L'effet par défaut est de prétraiter chaque fichier pmx afin que les accords soient transposés si nécessaire, générant un fichier pmx temporaire qui est ensuite traité par pmxab. Enfin, le fichier tex résultant est renommé pour porter le nom de travail d'origine. Le nom de fichier par défaut pour le fichier temporaire est <nom_travail>_chtr.pmx.

OPTIONS

-v
afficher le nom du programme et le numéro de version, puis quitter
-h
afficher le résumé de l'utilisation et quitter
-s
arrêter après la première étape (de production d'un fichier pmx temporaire avec symboles d'accords transposés).

VOIR AUSSI
