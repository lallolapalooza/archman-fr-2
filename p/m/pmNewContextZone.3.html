PMNEWCONTEXTZONE(3) Manuel des fonctions de bibliothèque PMNEWCONTEXTZONE(3)

NOM

pmNewContextZone - établir un fuseau horaire de reporting basé sur un contexte PMAPI

SYNTAXE C

#include <pcp/pmapi.h>

int pmNewContextZone(void);

cc ... -lpcp

DESCRIPTION

Le fuseau horaire de reporting actuel affecte le fuseau horaire utilisé par pmCtime(3) et pmLocaltime(3).

Si le contexte PMAPI actuel est une archive, pmNewContextZone utilise le fuseau horaire de l'enregistrement d'étiquette de l'archive pour définir le fuseau horaire de reporting actuel.

Si le contexte PMAPI actuel correspond à une source hôte de métriques, pmNewContextZone exécute un pmFetch(3) pour récupérer la valeur de la métrique pmcd.timezone et l'utilise pour définir le fuseau horaire de reporting actuel.

Dans les deux cas, pmNewContextZone renvoie une valeur pour identifier le fuseau horaire de reporting actuel qui peut être utilisé dans un appel ultérieur à pmUseZone(3) pour restaurer ce fuseau horaire de reporting.

DIAGNOSTICS

PM_ERR_NOCONTEXT
le contexte PMAPI actuel n'est pas valide
autre
une valeur de retour inférieure à zéro indique une erreur fatale d'un appel système, le plus probablement malloc(3)
