NOM

pmdamic - PMDA de carte MIC

DESCRIPTION

pmdamic est un agent de domaine de métriques de performance (PMDA) qui exporte les valeurs métriques des cartes Intel MIC à l'aide des liaisons Python de libmicmgmt(7).

Cela fournit des informations sur l'utilisation des cœurs, de la mémoire et de l'alimentation.

INSTALLATION

Installez le PMDA MIC en utilisant le script Install en tant que root :

# cd $PCP_PMDAS_DIR/mic
# ./Install

Si vous souhaitez annuler l'installation, faites ceci en tant que root :

# cd $PCP_PMDAS_DIR/mic
# ./Remove

pmdamic est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove informent pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/mic/Install
script d'installation de l'agent pmdamic
$PCP_PMDAS_DIR/mic/Remove
script d'annulation d'installation de l'agent pmdamic
$PCP_LOG_DIR/pmcd/mic.log
fichier journal par défaut pour les messages d'erreur de pmdamic

ENVIRONNEMENT PCP

Les variables d'environnement dont le préfixe est PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1), pmcd(1) et libmicmgmt(7).
