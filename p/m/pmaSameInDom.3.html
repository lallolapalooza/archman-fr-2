PMASAMEINDOM(3) Manuel des fonctions de bibliothèque PMASAMEINDOM(3)

NOM

pmaSameInDom - vérifier si deux observations d'un domaine d'instance sont identiques`

C SYNTAXE

#include <pcp/pmapi.h>
#include <pcp/libpcp.h>
#include <pcp/archive.h>

int pmaSameInDom(__pmLogInDom *old, __pmLogInDom *new);

cc ... -lpcp_archive -lpcp

ATTENTION

Cette documentation est destinée à un usage interne par les développeurs de Performance Co-Pilot (PCP).

Ces interfaces ne font pas partie des API de PCP garanties pour rester fixes d'une version à l'autre, et elles peuvent ne pas fonctionner, ou avoir des sémantiques différentes à un moment donné dans le futur.

DESCRIPTION

Vérifie si deux observations du même domaine d'instance sont identiques. Le code suppose que (a) old->indom == new->indom et (b) les deux domaines d'instance sont triés dans l'ordre croissant des identifiants d'instance internes ; voir pmaSortInDom(3) pour savoir comment rendre la deuxième condition vraie.

pmaSameInDom retourne 1 si elles sont identiques, retourne 0 sinon.

Les domaines d'instance sont considérés comme différents si l'une des conditions suivantes est remplie :

1.
old->numinst != new->numinst
2.
Pour un certain i, old->instlist[i] != new->instlist[i]
3.
Pour un certain i, les chaînes pointées par old->namelist[i] et new->instlist[i] ne sont pas identiques

Pour les archives Version 3 avec prise en charge des « delta indom », il est plus probable que pmaDeltaInDom(3) soit plus utile que pmaSameInDom, car la première combine la vérification de l'identité de deux observations d'un domaine d'instance avec la création optionnelle du format « delta indom » si c'est le codage le plus efficace.

VOIR AUSSI

pmaDeltaInDom(3), PMAPI(3) et pmaSortInDom(3).
