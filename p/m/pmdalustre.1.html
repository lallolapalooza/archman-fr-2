NOM

pmdalustre - agent de domaine de métriques de performance (PMDA) pour les statistiques du système de fichiers Lustre

DESCRIPTION

pmdalustre est un agent de domaine de métriques de performance (PMDA) qui lit et exporte les valeurs de métriques des interfaces de statistiques d'un système de fichiers Lustre.

pmdalustre recherche les interfaces de statistiques dans plusieurs emplacements, qui varient en fonction de la version de Lustre installée localement.

Les versions récentes de Lustre (v2.12 et ultérieures) exportent les statistiques à partir du pseudo-système de fichiers debugfs du noyau, dans les répertoires /sys/kernel/debug/lustre/llite et /sys/kernel/debug/lnet. Si ces interfaces ne sont pas trouvées au démarrage, pmdalustre vérifie automatiquement si les interfaces de statistiques sont disponibles à partir du pseudo-système de fichiers procfs sous les répertoires /proc/fs/lustre/llite et /proc/sys/lnet. Ce sont les emplacements par défaut des statistiques pour les versions de Lustre antérieures à v2.12.

Si aucune des interfaces de système de fichiers ci-dessus n'est détectée, ou si l'utilisateur souhaite remplacer les emplacements par défaut, pmdalustre prend également en charge un fichier de configuration optionnel nommé $PCP_PMDAS_DIR/lustre/lustre.conf. Notez que $PCP_PMDAS_DIR est défini sur /var/lib/pcp/pmdas sur la plupart des systèmes basés sur Linux. Le fichier de configuration prend en charge la syntaxe d'affectation de variables de perl(1). Un exemple de fichier de configuration adapté à Lustre v2.12 et ultérieures est :

$LLITE_PATH="/sys/kernel/debug/lustre/llite/";
$LNET_PATH="/sys/kernel/debug/lustre/lnet/";
Voir les commentaires dans le fichier lustre.conf fourni pour plus de détails. Par défaut, ce fichier est installé avec tout commenté (et n'a donc aucun effet sauf modification) car les heuristiques intégrées utilisées par pmdalustre devraient suffire.

Enfin, en remplaçant tout ce qui précède, les variables d'environnement LUSTRE_LLITE_PATH et LUSTRE_LNET_PATH peuvent être définies (et exportées) pour spécifier les emplacements des répertoires des interfaces de statistiques à utiliser. Ce mécanisme utilisant des variables d'environnement est destiné à être utilisé uniquement à des fins de développement et de test.

Le processus pmdalustre s'exécute en tant qu'utilisateur root car les répertoires debugfs ne sont normalement pas lisibles par les utilisateurs non privilégiés.

INSTALLATION

Installez pmdalustre en utilisant le script Install en tant qu'utilisateur root :

# cd $PCP_PMDAS_DIR/lustre
# ./Install

Si vous souhaitez annuler l'installation, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/lustre
# ./Remove

pmdalustre est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/lustre/Install
script d'installation pour l'agent pmdalustre
$PCP_PMDAS_DIR/lustre/Remove
script d'annulation d'installation pour l'agent pmdalustre
$PCP_LOG_DIR/pmcd/lustre.log
fichier journal par défaut pour les messages d'erreur de pmdalustre
$PCP_PMDAS_DIR/lustre/lustre.conf
fichier de configuration pour remplacer les répertoires de statistiques par défaut utilisés par pmdalustre.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1), perl(1), pmcd(1) et llstat(1).
