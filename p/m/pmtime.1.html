PMTIME(1) Manuel des commandes générales PMTIME(1)

NOM

pmtime - serveur de contrôle temporel pour Performance Co-Pilot

SYNTAXE

pmtime [-D debug] [-V?] [-p port]

DESCRIPTION

pmtime est une interface graphique pour les applications de surveillance des performances utilisant l'infrastructure PCP et nécessitant un contrôle temporel interactif.

pmtime n'est normalement pas invoqué directement par les utilisateurs. Il est plutôt plus courant qu'il soit lancé par des applications clientes (par exemple, pmchart(1), pmstat(1) ou pmval(1)).

Il existe deux modes d'interaction avec un processus pmtime : le mode hôte en direct et le mode archive historique. En mode archive, la fenêtre présente des contrôles temporels appropriés pour manipuler la position dans l'archive, permettant un contrôle complet de magnétoscope pour se déplacer dans le temps, en avant et en arrière, à des vitesses et des intervalles configurables. En mode direct, la fenêtre pmtime contient les contrôles temporels plus simples, adaptés à la surveillance en direct.

Notez que la fenêtre pmtime n'est rendue visible que lorsqu'elle est explicitement demandée. Plusieurs applications clientes peuvent être connectées à un seul serveur pmtime ; lorsque la dernière application cliente se ferme, pmtime se ferme également.

OPTIONS

Les options de ligne de commande disponibles sont :

-p port, --guiport=port
port est le numéro de port que pmtime utilisera pour la communication avec ses clients (applications de surveillance).
-V, --version
Affiche le numéro de version et quitte.
-?, --help
Affiche le message d'utilisation et quitte.

ENVIRONNEMENT

Lorsqu'aucun numéro de port n'est explicitement demandé sur la ligne de commande via l'option -p, la variable d'environnement PMTIME_PORT peut être définie pour spécifier le numéro de port à partir duquel la recherche de ports disponibles commencera lorsque pmtime cherchera un port à utiliser.

Le numéro de port de départ par défaut est 43334.

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à résoudre les problèmes, bien que les informations soient parfois cryptiques et destinées principalement à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

Les options de débogage spécifiques à pmtime sont les suivantes :

Option Description
appl0 active les diagnostics internes qui rapportent tous les événements pmtime, par exemple le réglage du fuseau horaire, les changements d'état, les changements d'intervalle, les changements d'échelle de temps, etc.

VOIR AUSSI

PCPIntro(1), pmchart(1), pmstat(1) et pmval(1).
