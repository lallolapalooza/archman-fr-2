PMIUNITS(3) Manuel des fonctions de bibliothèque PMIUNITS(3)

NOM

pmiUnits, pmiID, pmiInDom - construction des structures de données de métriques de base

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/import.h>

pmID pmiID(int domain, int cluster, int item);
pmInDom pmiInDom(int domain, int serial);
pmUnits pmiUnits(int dimSpace,
int dimTime, int dimCount, int scaleSpace, int scaleTime, int scaleCount);

cc ... -lpcp_import -lpcp

SYNTAXE Perl

use PCP::LogImport;

$pmid = pmiID($domain, $cluster, $item);
$indom = pmiInDom($domain, $serial);
$units = pmiUnits($dimSpace,
$dimTime, $dimCount, $scaleSpace, $scaleTime, $scaleCount);

DESCRIPTION

Dans le cadre de l'API d'importation de journaux de Performance Co-Pilot (voir LOGIMPORT(3)), ces routines fournissent des méthodes pratiques (en particulier pour l'utilisation dans les scripts) pour construire respectivement les structures pmID, pmInDom et pmUnits, qui seront utilisées dans les appels ultérieurs à pmiAddMetric(3) et pmiAddInstance(3).

Consultez pmLookupDesc(3) pour une description complète des valeurs et de la sémantique des composantes d'une structure pmUnits, et par conséquent des valeurs d'arguments valides pour pmiUnits.

VOIR AUSSI

LOGIMPORT(3), pmiAddMetric(3), pmiAddInstance(3) et pmLookupDesc(3).
