PMDAMEMCACHE(1) Manuel des commandes générales PMDAMEMCACHE(1)

NOM

pmdamemcache - agent de domaine de métriques de performance memcached (PMDA)

DESCRIPTION

Ce PMDA extrait les données de performance de memcached, un démon de cache en mémoire distribué couramment utilisé pour améliorer les performances des serveurs web. Une ferme de processus memcached sur plusieurs serveurs peut être utilisée par une seule application web, augmentant la taille totale du cache d'objets disponible et réduisant la charge de la base de données associée à des tailles de cache plus petites. Ce système est décrit en détail sur http://www.danga.com/memcached.

INSTALLATION

Configurez pmdamemcache pour extraire les valeurs d'un ensemble d'hôtes utilisés dans la ferme memcache. Ces hôtes peuvent être listés dans le fichier $PCP_PMDAS_DIR/memcache/memcache.conf, dans le format (c'est-à-dire tableau Perl) décrit en haut de pmdamemcache.pl. Un taux de rafraîchissement personnalisé peut également être configuré en utilisant ce mécanisme.

# cd $PCP_PMDAS_DIR/memcache
# [ éditer memcache.conf ]

Une fois que cela est configuré, vous pouvez accéder aux noms et aux valeurs des métriques de performance memcache en faisant ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/memcache
# ./Install

Si vous souhaitez annuler l'installation, faites ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/memcache
# ./Remove

pmdamemcache est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts d'installation et de suppression notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/memcache/memcache.conf
fichier de configuration optionnel listant les instances memcache surveillées
$PCP_PMDAS_DIR/memcache/Install
script d'installation pour l'agent pmdamemcache
$PCP_PMDAS_DIR/memcache/Remove
script d'annulation d'installation pour l'agent pmdamemcache
$PCP_LOG_DIR/pmcd/memcache.log
fichier journal par défaut pour les messages d'erreur de pmdamemcache

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. À chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).
