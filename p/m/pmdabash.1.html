PMDABASH(1) Manuel des commandes générales PMDABASH(1)

NOM

pmdabash - agent de domaine de métriques de performance pour le shell Bourne-Again

SYNTAXE

$PCP_PMDAS_DIR/bash/pmdabash [-C] [-D debug] [-d domaine] [-l fichier_journal] [-I intervalle] [-t délai] [-U nom_utilisateur] fichier_config

DESCRIPTION

pmdabash est un agent de domaine de métriques de performance (PMDA) expérimental qui exporte les événements "xtrace" d'un processus bash(1) tracé. Cela inclut les informations d'exécution de commande qui seraient normalement envoyées à la sortie standard d'erreur avec l'option set -x du shell.

Les métriques d'événements sont exportées montrant chaque commande exécutée, le nom de la fonction et le numéro de ligne dans le script, ainsi qu'un horodatage. De plus, l'identifiant du processus pour le shell et son processus parent sont exportés.

Ceci nécessite la version 4 ou ultérieure de bash.

Une brève description des options de ligne de commande de pmdabash suit :

-d
Il est absolument crucial que le numéro de domaine des métriques de performance spécifié ici soit unique et cohérent. C'est-à-dire que le domaine doit être différent pour chaque PMDA sur un même hôte, et le même numéro de domaine doit être utilisé pour le même PMDA sur tous les hôtes.
-l
Emplacement du fichier journal. Par défaut, un fichier journal nommé bash.log est écrit dans le répertoire courant de pmcd(1) lorsque pmdabash est démarré, c'est-à-dire $PCP_LOG_DIR/pmcd. Si le fichier journal ne peut être créé ou n'est pas accessible en écriture, la sortie est envoyée à la sortie standard d'erreur.
-s
Temps (en secondes) entre les évaluations successives du descripteur de fichier de trace du shell. La valeur par défaut est de 2 secondes.
-m
Quantité maximale de mémoire allouée pour chaque file d'attente d'événements (une par processus tracé). La valeur par défaut est de 2 mégaoctets.
-U
Compte utilisateur sous lequel exécuter l'agent. Par défaut, il s'agit du compte "pcp" non privilégié dans les versions actuelles de PCP, mais dans les versions plus anciennes, le compte superutilisateur ("root") était utilisé par défaut.

INSTALLATION

Pour que l'hôte puisse exporter les noms, le texte d'aide et les valeurs des métriques de performance bash, faites ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/bash
# ./Install

Dès qu'un script shell instrumenté (voir la sélection INSTRUMENTATION ci-dessous) est exécuté, avec le traçage activé, de nouvelles valeurs de métriques apparaîtront - aucune configuration supplémentaire de l'agent n'est requise.

Si vous souhaitez annuler l'installation, faites ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/bash
# ./Remove

pmdabash est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

INSTRUMENTATION

Afin de permettre le flux de données d'événements entre un script bash(1) et pmdabash, le script doit effectuer les actions suivantes :

#!/bin/sh
source $PCP_DIR/etc/pcp.env
source $PCP_SHARE_DIR/lib/bashproc.sh
pcp_trace on $@       # activer le traçage
echo "awoke, $count"
pcp_trace off         # désactiver le traçage

Le traçage peut être activé et désactivé autant de fois que nécessaire par le script. Lors de l'installation réussie de l'agent, plusieurs métriques seront disponibles :

$ pminfo bash
bash.xtrace.numclients
bash.xtrace.maxmem
bash.xtrace.queuemem
bash.xtrace.count
bash.xtrace.records
bash.xtrace.parameters.pid
bash.xtrace.parameters.parent
bash.xtrace.parameters.lineno
bash.xtrace.parameters.function
bash.xtrace.parameters.command

FICHIERS

$PCP_PMCDCONF_PATH
options de ligne de commande utilisées pour lancer pmdabash
$PCP_PMDAS_DIR/bash/help
fichier d'aide par défaut pour les métriques bash
$PCP_PMDAS_DIR/bash/Install
script d'installation pour l'agent pmdabash
$PCP_PMDAS_DIR/bash/Remove
script d'annulation d'installation pour pmdabash
$PCP_LOG_DIR/pmcd/bash.log
fichier journal par défaut pour les messages d'erreur et autres informations de pmdabash

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE BOURAGEAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à trier les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

Les options de débogage spécifiques à pmdabash sont les suivantes :

Option Description
appl0 journalisation verbeuse des événements d'intérêt
