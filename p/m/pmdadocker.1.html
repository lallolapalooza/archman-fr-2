PMDADOCKER(1) Manuel des commandes générales PMDADOCKER(1)

NOM

pmdadocker — agent de domaine de métriques de performance docker (PMDA)

SYNTAXE

$PCP_PMDAS_DIR/docker/pmdadocker [-D debug] [-d domaine] [-l fichier_journal]

DESCRIPTION

pmdadocker est un agent de domaine de métriques de performance Docker (PMDA) qui expose les métriques de performance rapportées par l'API distante de Docker.

Une brève description des options de ligne de commande de pmdadocker suit :

-d
Il est absolument crucial que le numéro de domaine des métriques de performance spécifié ici soit unique et cohérent. C'est-à-dire que domaine doit être différent pour chaque PMDA sur le même hôte, et le même numéro de domaine doit être utilisé pour le même PMDA sur tous les hôtes.
-l
Emplacement du fichier journal. Par défaut, un fichier journal nommé docker.log est écrit dans le répertoire courant de pmcd(1) lors du démarrage de pmdadocker, c'est-à-dire $PCP_LOG_DIR/pmcd. Si le fichier journal ne peut être créé ou n'est pas accessible en écriture, la sortie est dirigée vers la sortie d'erreur standard.

Les requêtes de métriques de l'API distante sont activées automatiquement et récupérées périodiquement. Ce délai est représenté par pmdadocker via docker.control.timing. Par défaut, pmdadocker est configuré pour récupérer les données toutes les 1 seconde.

pmdadocker itérera sur trois appels différents de l'API distante docker :

/containers/$ID/json
Métriques du conteneur concernant l'état actuel du conteneur. Par exemple, PID, nom ou si le conteneur est en cours d'exécution.
/version
Métriques de version de base concernant le démon Docker actuel utilisé.
/containers/$ID/stats?stream=0
Métriques plus détaillées de mémoire et de CPU du conteneur.

INSTALLATION

Si vous souhaitez accéder aux noms, aux textes d'aide et aux valeurs des métriques de performance Docker, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/docker
# ./Install

Si vous souhaitez annuler l'installation (et supprimer les deux PMDA), procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/docker
# ./Remove

pmdadocker est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts d'installation et de suppression informent pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMCDCONF_PATH
options de ligne de commande utilisées pour lancer pmdadocker
$PCP_PMDAS_DIR/docker/help
fichier d'aide par défaut pour les métriques Docker
$PCP_PMDAS_DIR/docker/Install
script d'installation pour l'agent pmdadocker
$PCP_PMDAS_DIR/docker/Remove
script d'annulation d'installation pour l'agent pmdadocker
$PCP_LOG_DIR/pmcd/docker.log
fichier journal par défaut pour les messages d'erreur et autres informations provenant de pmdadocker

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à diagnostiquer les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à fournir des indications aux développeurs plutôt qu'aux utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

Les options de débogage spécifiques à pmdadocker sont les suivantes :

Option Description
appl1 signaler un échec de récupération des statistiques via http
