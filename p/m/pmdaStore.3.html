PMDASTORE(3) Manuel des fonctions de bibliothèque PMDASTORE(3)

NOM

pmdaStore - stocker une valeur dans une métrique pour un PMDA

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaStore(pmResult *result, pmdaExt *pmda);

cc ... -lpcp_pmda -lpcp

DESCRIPTION

Dans le cadre de l'API du domaine d'agents de métriques de performance (PMDA) (voir PMDA(3)), pmdaStore est le rappel générique pour stocker une valeur dans une métrique. pmdaStore est généralement une opération nulle car, par défaut, aucune métrique ne peut être modifiée. De plus, l'implémentation d'un rappel de stockage qui autorise les modifications de métriques par pmstore(1) est très dépendante de l'application.

AVERTISSEMENT

Le PMDA doit utiliser PMDA_INTERFACE_2 ou une version ultérieure, comme spécifié dans l'appel à pmdaDSO(3) ou pmdaDaemon(3).

DIAGNOSTICS

pmdaStore renvoie PM_ERR_PERMISSION pour indiquer qu'aucune métrique ne peut être modifiée.

VOIR AUSSI

pmstore(1), PMAPI(3), PMDA(3), pmdaDaemon(3), pmdaDSO(3) et pmStore(3).
