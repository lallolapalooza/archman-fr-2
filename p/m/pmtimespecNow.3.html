PMTIMESPECNOW(3) Manuel des fonctions de bibliothèque PMTIMESPECNOW(3)

NOM

pmtimespecNow, pmtimespecInc, pmtimespecDec, pmtimespecAdd, pmtimespecSub, pmtimespecToReal, pmtimespecFromReal, pmtimespecTotimeval, pmtimespecPrint, pmtimespecPrintInterval - routines d'aide pour le temps stocké sous forme de struct timespec

SYNTAXE EN C

#include <pcp/pmapi.h>

void pmtimespecNow(struct timespec *tp);
void pmtimespecInc(struct timespec *ap, const struct timespec *bp);
void pmtimespecDec(struct timespec *ap, const struct timespec *bp);
double pmtimespecAdd(const struct timespec *ap,
const struct timespec *bp);

double pmtimespecSub(const struct timespec *ap,
const struct timespec *bp);

double pmtimespecToReal(const struct timespec *tp);
void pmtimespecFromReal(double secs, struct timespec *tp);
void pmtimespecTotimeval(struct timespec *tsp, struct timeval *tvp);
void pmtimespecPrint(FILE *f, const struct timespec *tp);
void pmtimespecPrintInterval(FILE *f, const struct timespec *tp);

cc ... -lpcp

DESCRIPTION

pmtimespecNow est une méthode indépendante de la plateforme qui renvoie l'heure système actuelle depuis l'Epoch dans tp.

pmtimespecInc ajoute le temps dans ap au temps dans bp et stocke le résultat dans ap. De même, pmtimespecDec soustrait le temps dans bp du temps dans ap et stocke le résultat dans ap.

pmtimespecAdd (et pmtimespecSub) ajoutent (et soustrayent) des temps et renvoient le résultat sous forme de valeur double. Le temps dans l'argument ap n'est pas modifié.

pmtimespecToReal convertit le temps dans tp en une valeur double équivalente. pmtimespecFromReal effectue la conversion inverse, prenant le temps en secs et renvoyant le temps équivalent dans tp.

pmtimespecTotimeval convertit la struct timespec tsp en une struct timeval tvp équivalente (modulo troncature des nanosecondes en microsecondes).

Pour pmtimespecAdd, pmtimespecSub, pmtimespecToReal et pmtimespecFromReal, il existe un problème de précision numérique. Si le résultat ou l'opérande double a plus de 6 chiffres décimaux dans la partie secondes de la valeur, alors la valeur fractionnaire est convertie en microsecondes avant les calculs arithmétiques, de sorte que le champ nanosecondes n'est précis qu'à 6 décimales dans ce cas.

pmtimespecPrint imprime l'horodatage de tp sur le flux f dans l'heure locale (telle que renvoyée par pmLocaltime(3)) au format HH:MM:SS.XXXXXXXXX.

pmtimespecPrintInterval imprime l'intervalle de tp sur le flux f dans un format minimaliste [[HHh]MMm]SS[.XXXXXXXXX]s où les heures, les minutes et les nanosecondes ne sont signalées que si elles sont non nulles, et les zéros terminaux dans les nanosecondes sont omis. Par exemple, si tp->tv_sec était 75 et tp->tv_nsec était 51000000, la sortie serait 1h15.51s.

NOTES

Pour les variantes de ces interfaces utilisant la précision des microsecondes et la structure timeval, référez-vous à pmtimevalNow(3).

COMPATIBILITÉ

Avant PCP 7.0, la routine pmtimespecPrint était appelée pmPrintHighResStamp. Pour prendre en charge la transition PMAPI, l'ancienne routine peut toujours être utilisée si les applications sont recompilées avec -DPMAPI_VERSION=2.

pmPrintHighResStamp est maintenant obsolète et le support à la compilation pour ce nom de routine sera supprimé dans une future version.

VOIR AUSSI

PMAPI(3), pmLocaltime(3) et pmtimevalNow(3).
