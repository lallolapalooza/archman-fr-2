PMDASUMMARY(1) Manuel des commandes générales PMDASUMMARY(1)

NOM

pmdasummary - agent de domaine de métriques de performance (PMDA) de résumé

SYNTAXE

$PCP_PMDAS_DIR/summary/pmdasummary [-D debug] [-d domaine] [-h aide] [-l journal] [-U utilisateur] ligne-commande-pmie

DESCRIPTION

pmdasummary est un agent de domaine de métriques de performance (PMDA) qui dérive des valeurs de métriques de performance à partir des valeurs rendues disponibles par d'autres PMDA. pmdasummary se compose de deux processus :

processus pmie
Le moteur d'inférence pour les valeurs de performance pmie(1) est utilisé pour échantillonner périodiquement les valeurs des métriques de base et calculer les valeurs dérivées. Ce processus est lancé avec les arguments ligne-commande-pmie fournis par le processus principal, décrit ci-dessous.
processus principal
Le processus principal lit et met en mémoire tampon les valeurs calculées par pmie(1) et les rend disponibles au démon collecteur de métriques de performance pmcd(1).

Une brève description des options de ligne de commande de pmdasummary suit :

-d
Il est absolument crucial que le numéro de domaine des métriques de performance spécifié ici soit unique et cohérent. C'est-à-dire que le domaine doit être différent pour chaque PMDA sur un hôte, et le même numéro de domaine doit être utilisé pour le même PMDA sur tous les hôtes.
-h
Cette option spécifie un fichier de texte d'aide alternatif aide pour décrire les métriques que pmdasummary représente.
-l
Emplacement du fichier journal. Par défaut, un fichier journal nommé summary.log est écrit dans le répertoire courant de pmcd(1) au démarrage de pmdasummary, c'est-à-dire $PCP_LOG_DIR/pmcd. Si le fichier journal ne peut pas être créé ou n'est pas accessible en écriture, la sortie est dirigée vers la sortie d'erreur standard.
-U
Compte utilisateur sous lequel exécuter l'agent. Par défaut, c'est le compte non privilégié "pcp" dans les versions actuelles de PCP, mais dans les versions plus anciennes, le compte superutilisateur ("root") était utilisé par défaut.

INSTALLATION

Si vous souhaitez accéder aux noms, textes d'aide et valeurs des métriques de performance de résumé, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/summary
# ./Install

Si vous souhaitez annuler l'installation, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/summary
# ./Remove

pmdasummary est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove informent pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMCDCONF_PATH
options de ligne de commande utilisées pour lancer pmdasummary
$PCP_PMDAS_DIR/summary/expr.pmie
expressions pmie(1) par défaut définissant les métriques de résumé
$PCP_PMDAS_DIR/summary/help
texte d'aide par défaut pour les métriques de résumé
$PCP_PMDAS_DIR/summary/Install
script d'installation pour l'agent pmdasummary
$PCP_PMDAS_DIR/summary/Remove
script d'annulation d'installation pour l'agent pmdasummary
$PCP_LOG_DIR/pmcd/summary.log
fichier journal par défaut pour les messages d'erreur et autres informations de pmdasummary

ENVIRONNEMENT PCP

Les variables d'environnement commençant par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à diagnostiquer les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.
