PMDIFF(1) Manuel des commandes générales PMDIFF(1)

NOM

pmdiff - compare les archives et signale les différences significatives

SYNTAXE

pmdiff [-dzV?] [-B heuredebut] [-E heurefin] [-p precision] [-q seuil] [-S heuredebut] [--skip-excluded] [--skip-missing] [-T heurefin] [-x metrique] [-X fichier] [-Z fuseauhoraire] archive1 [archive2]

DESCRIPTION

pmdiff compare les valeurs moyennes de chaque métrique dans une ou deux séries d'archives, dans une fenêtre temporelle donnée, pour les changements susceptibles d'être intéressants lors de la recherche de régressions de performance.

Les spécificateurs d'archive archive1 et archive2 peuvent être des listes de noms séparées par des virgules, dont chacun peut être le nom de base d'une archive ou le nom d'un répertoire contenant une ou plusieurs archives. Chaque archive de l'ensemble résultant doit avoir été créée précédemment à l'aide de pmlogger(1). L'utilitaire pmlogsummary(1) est utilisé pour obtenir les valeurs moyennes utilisées pour la comparaison.

Il existe deux types d'invocation de l'outil : avec une ou deux séries d'archives.

Dans le premier cas, la seule ligne de commande logique nécessite l'utilisation des quatre arguments de fenêtre temporelle. Ceux-ci sont spécifiés en utilisant le même format de fenêtre temporelle décrit dans PCPIntro(1), et sont -S/--start et -T/--finish pour les heures de début et de fin de la première fenêtre temporelle d'intérêt dans l'ensemble d'archives, et -B/--before et -E/--end pour les heures de début et de fin de la seconde fenêtre temporelle d'intérêt.

Dans le second cas, avec deux séries d'archives, les options -B/--before et -E/--end peuvent être inutiles. Cela peut être le cas, par exemple, lors de la comparaison de la même fenêtre temporelle de deux jours consécutifs (généralement deux séries d'archives distinctes), ou d'une fenêtre temporelle le même jour de semaines différentes.

Dans les deux cas, pmdiff produit un résumé trié des métriques dans la fenêtre spécifiée dont les valeurs ont le plus dévié d'un seuil minimal. Le niveau de déviation est calculé en divisant la valeur moyenne de chaque métrique dans les deux journaux, puis en calculant si le ratio tombe en dehors d'une plage considérée comme normale. Ce ratio peut être ajusté à l'aide de l'option -q/--threshold, et par défaut, il est de 2 (c'est-à-dire qu'il signale toutes les métriques dont les valeurs moyennes ont plus que doublé dans les deux fenêtres temporelles ou ont plus que diminué de moitié dans les deux fenêtres temporelles).

Si la valeur de base est zéro et que la valeur de comparaison est non nulle, le ratio est signalé comme « |+| » (infiniment grand). Si la valeur de comparaison est zéro et que la valeur de base est non nulle, le ratio est signalé comme « |-| » (infiniment petit).

Les métriques signalées sont triées par ordre de ratio croissant.

Si des métriques sont présentes dans une fenêtre mais manquantes dans l'autre, un diagnostic sera affiché répertoriant chaque métrique manquante et l'ensemble d'archives dont elle était absente.

Les métriques avec sémantique de compteur sont converties en taux avant d'être évaluées.

OPTIONS

Les options de ligne de commande disponibles sont :

-d, --keep
Mode de débogage, conserve les fichiers intermédiaires.
-B temps, --begin=temps
Temps de début pour la seconde fenêtre temporelle.
-E temps, --end=temps
Temps de fin pour la seconde fenêtre temporelle.
-p precision, --precision=precision
Affiche tous les nombres à virgule flottante avec precision chiffres après la virgule.
-q seuil, --threshold=seuil
Change le seuil pour les métriques intéressantes, voir ci-dessus pour plus de détails.
-S temps, --start=temps
Temps de début de la première fenêtre temporelle.
-T temps, --finish=temps
Temps de fin de la première fenêtre temporelle.
-V, --version
Affiche le numéro de version et quitte.
-x metrique
Compare chaque metrique dans chaque série d'archives dans les fenêtres temporelles spécifiées à un motif egrep(1) donné, excluant ceux qui correspondent du rapport de sortie.
-X fichier
Permet de spécifier un fichier contenant des motifs egrep(1) qui sont appliqués aux noms des métriques pour exclure éventuellement certaines d'entre elles du rapport.
-z, --hostzone
Utilise le fuseau horaire local de la série d'archives donnée.
-Z fuseauhoraire, --timezone=fuseauhoraire
Change le fuseau horaire dans les étiquettes d'archives à fuseauhoraire dans le format de la variable d'environnement TZ comme décrit dans environ(7).
-?, --help
Affiche le message d'utilisation et quitte.
--skip-excluded
Élague la liste des noms de métriques exclues de la sortie.
--skip-missing
Par défaut, pmdiff signalera les noms de toutes les métriques qui sont dans une série d'archives mais pas dans l'autre. Cette option supprime cette signalisation.

FICHIERS

$PCP_LOG_DIR/pmlogger/<nomdethote>
Répertoire par défaut pour les archives PCP contenant les valeurs des métriques de performance collectées à partir de l'hôte nomdethote.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1), pmlogger(1), pmlogsummary(1), egrep(1), pcp.conf(5) et pcp.env(5).
