PMLOGLABEL(1) Manuel des commandes générales PMLOGLABEL(1)

NOM

pmloglabel - vérifier et réparer une étiquette d'archive de métriques de performance

SYNTAXE

pmloglabel [-lLsv?] [-D debug] [-h hôte] [-p pid] [-V version] [-Z fuseauhoraire] archive

DESCRIPTION

pmloglabel vérifie, rapporte et peut modifier tous les détails des étiquettes dans chacun des fichiers d'une archive Performance Co-Pilot (PCP). L'archive a le nom de base archive et doit avoir été précédemment créée en utilisant pmlogger(1).

Chacun des fichiers d'une archive PCP (métadonnées, index temporel et un ou plusieurs volumes de données) doit contenir une étiquette valide au début, sinon les outils PCP refuseront d'ouvrir l'archive.

Ainsi, la fonction principale de pmloglabel est de pouvoir réparer des champs d'étiquette incohérents ou corrompus, afin que l'archive entière ne soit pas perdue. Il ne vérifiera pas le reste de l'archive, mais il vous donnera une chance de récupérer des données autrement perdues. Ensemble, pmloglabel et pmlogextract peuvent produire une archive PCP valide à partir de nombreuses formes de corruption.

Notez que si l'index temporel est trouvé corrompu, le fichier "*.index" peut être déplacé sans risque et l'archive restera accessible, bien que les récupérations puissent prendre plus de temps sans l'index.

OPTIONS

Les options de ligne de commande disponibles sont :

-h hôte, --host=hôte
Modifie le nom d'hôte enregistré dans l'étiquette de l'archive, pour tous les fichiers de l'archive.
-l, --label
Affiche l'étiquette de l'archive, montrant la version du format de l'archive, la date et l'heure de début et de fin (actuelle) de l'archive, et l'hôte à partir duquel les métriques de performance ont été collectées.
-L
Comme -l, mais un peu plus verbeux, affichant également le fuseau horaire et l'identifiant du processus créateur de l'étiquette de l'archive.
-p pid, --pid=pid
Définit l'identifiant du processus stocké dans l'étiquette de l'archive à pid, pour tous les fichiers de l'archive.
-s
Réécrit les valeurs sentinelles qui précèdent et suivent l'étiquette de l'archive, pour tous les fichiers de l'archive.
-v, --verbose
Mode verbeux. Des informations de progression supplémentaires sont produites à chaque étape.
-V version, --version=version
Appose le numéro de version dans le champ du nombre magique au début de l'étiquette de l'archive, pour tous les fichiers de l'archive.
-Z fuseauhoraire, --timezone=fuseauhoraire
Change le fuseau horaire dans les étiquettes de l'archive pour fuseauhoraire, dans le format de la variable d'environnement TZ tel que décrit dans environ(7).
-?, --help
Affiche le message d'utilisation et quitte.

EXEMPLES

L'exemple suivant démontre l'utilisation de pmloglabel pour trouver puis corriger un champ corrompu (PID) dans l'étiquette de l'index temporel d'une archive nommée "20080125".


$ pmlogdump -l 20080125
pmlogdump: Impossible d'ouvrir l'archive « 20080125 » : enregistrement d'étiquette illégal au début d'un fichier d'archive PCP
$ pmloglabel 20080125
PID non concordant (5264/5011) entre l'index temporel et le volume de données 0
$ pmloglabel -p 5264 20080125
$ pmlogdump -l 20080125
Étiquette du journal (Version du format du journal 2)
Métriques de performance de l'hôte fw1
  commençant le ven. 25 janv. 00:10:09.341 2008
  finissant le sam. 26 janv. 00:09:54.344 2008

STATUT DE SORTIE

pmloglabel se termine avec le statut 0 si les étiquettes de l'archive sont propres. En cas d'invocation incorrecte, le statut de sortie sera 1. Si une corruption est détectée et qu'elle existe toujours à la fin, le statut de sortie sera 2. Si une écriture des étiquettes d'archive est demandée et que certains aspects de cette écriture échouent, le statut de sortie sera 3.

FICHIERS

$PCP_LOG_DIR/pmlogger/<hôte>
Répertoire par défaut pour les archives PCP contenant les valeurs de métriques de performance collectées à partir de l'hôte <hôte>.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, tel que décrit dans pcp.conf(5).

OPTIONS DE DEBOGAGE

L'option -D ou --debug active l'affichage de diagnostics supplémentaires sur stderr pour aider à dépanner les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à fournir des indications aux développeurs plutôt qu'aux utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.
