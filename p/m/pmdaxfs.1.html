PMDAXFS(1) Manuel des commandes générales PMDAXFS(1)

NOM

pmdaxfs - Agent de domaine de métriques de performance du système de fichiers XFS (PMDA)

SYNTAXE

$PCP_PMDAS_DIR/xfs/pmdaxfs [-D debug] [-d domaine] [-l logfile]

DESCRIPTION

pmdaxfs est un Agent de Domaine de Métriques de Performance (PMDA) qui extrait les métriques de performance décrivant l'état du système de fichiers XFS du noyau Linux.

Le PMDA xfs expose des métriques qui mesurent des informations sur l'utilisation des tampons de métadonnées, le journal, les opérations btree, les opérations d'inode, les attributs étendus, les répertoires, les quotas, les compteurs d'opérations de lecture et d'écriture et bien sûr le débit.

Le PMDA fournit une facilité pour réinitialiser les valeurs de tous les compteurs à zéro en utilisant pmstore(1) avec la métrique xfs.control.reset.

Une brève description des options de ligne de commande de pmdaxfs suit :

-d
Il est absolument crucial que le numéro de domaine des métriques de performance spécifié ici soit unique et cohérent. C'est-à-dire que domaine doit être différent pour chaque PMDA sur le même hôte, et le même numéro de domaine doit être utilisé pour le même PMDA sur tous les hôtes.
-l
Emplacement du fichier journal. Par défaut, un fichier journal nommé xfs.log est écrit dans le répertoire courant de pmcd(1) lorsque pmdaxfs est démarré, c'est-à-dire $PCP_LOG_DIR/pmcd. Si le fichier journal ne peut pas être créé ou n'est pas accessible en écriture, la sortie est écrite dans la sortie d'erreur standard.

INSTALLATION

Le PMDA xfs est installé et disponible par défaut sous Linux. Si vous souhaitez annuler l'installation, faites ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/xfs
# ./Remove

Si vous souhaitez rétablir l'accès aux noms, au texte d'aide et aux valeurs des métriques de performance XFS, après la suppression, faites ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/xfs
# ./Install

pmdaxfs est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMCDCONF_PATH
options de ligne de commande utilisées pour lancer pmdaxfs
$PCP_PMDAS_DIR/xfs/help
fichier d'aide par défaut pour les métriques xfs
$PCP_PMDAS_DIR/xfs/Install
script d'installation pour l'agent pmdaxfs
$PCP_PMDAS_DIR/xfs/Remove
script d'annulation d'installation pour l'agent pmdaxfs
$PCP_LOG_DIR/pmcd/xfs.log
fichier journal par défaut pour les messages d'erreur et autres informations de pmdaxfs

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à diagnostiquer les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et de leur signification.

VOIR AUSSI
