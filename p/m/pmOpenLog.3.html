PMOPENLOG(3) Manuel des fonctions de bibliothèque PMOPENLOG(3)

NOM

pmOpenLog - créer un fichier journal pour les diagnostics et les sorties de débogage

C SYNTAXE

#include <pcp/pmapi.h>

FILE *pmOpenLog(const char *progname,
const char *logname, FILE *oldstream, int *status);

cc ... -lpcp

DESCRIPTION

pmOpenLog réaffecte le flux d'E/S standard oldstream (normalement stderr) pour qu'il soit associé au fichier logname.

Si logname n'est pas "-" et que le fichier existe déjà, il sera renommé en logname.prev sinon supprimé. En raison des restrictions de permissions, le renommage ou la suppression peut ne pas réussir, mais dans les cas d'utilisation courants, logname.prev conserve le contenu de la version précédente de logname. Ensuite, logname est recréé si possible (pour garantir la propriété et les permissions correctes de l'appelant envers pmOpenLog).

À titre de cas spécial, si logname est "-", aucun renommage, aucune suppression ni réouverture n'est effectué et la fonction définit simplement status à 1 et retourne oldstream. Ceci est utile lorsque l'appelant souhaite des diagnostics sur le flux oldstream (normalement stderr) plutôt que sur un fichier, par exemple, pmlogger -l- ou pmcd -f -l-. La journalisation vers stderr est également utile pour les PMDA dans un environnement conteneurisé où il est avantageux que tous les journaux PMDA soient écrits dans le flux stderr de pmcd (et donc vers une seule destination), que ce soit un fichier tel que pmcd.log ou le flux d'origine hérité du shell.

Au retour, la valeur de retour est le flux d'E/S standard, remplaçant éventuellement oldstream. En cas d'erreur, la valeur de retour sera oldstream inchangé et status sera 0.

En cas de succès, status est 1, et un préambule standard est écrit dans logname Journal pour progname sur hostname démarré date et heure
et un gestionnaire atexit(3) est installé pour écrire le message de post-scriptum dans logname Journal terminé date et heure lorsque le processus se termine.

progname est uniquement utilisé pour annoter les messages.

VOIR AUSSI

atexit(3) et freopen(3).
