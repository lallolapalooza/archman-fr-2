PMLOGSUMMARY(1) Manuel des commandes générales PMLOGSUMMARY(1)

NOM

pmlogsummary - calculer les moyennes des métriques stockées dans un ensemble d'archives PCP

SYNTAXE

pmlogsummary [-abfFHiIlmMNsvVxyz?] [-B nbins] [-D debug] [-n pmnsfile] [-p precision] [-S starttime] [-T endtime] [-Z timezone] archive [nommetric ...]

DESCRIPTION

pmlogsummary imprime des informations statistiques sur les métriques de type numérique contenues dans les fichiers d'un ensemble d'archives Performance Co-Pilot (PCP). La sortie par défaut imprime les moyennes temporelles pour les métriques de compteur et non-compteur. L'ensemble d'archives est identifié par archive, qui est une liste séparée par des virgules de noms, chacun pouvant être le nom de base d'une archive ou le nom d'un répertoire contenant une ou plusieurs archives. Les archives sont généralement créées à l'aide de pmlogger(1).

Les métriques d'intérêt sont nommées dans les arguments nommetric. Si nommetric est un nœud non-feuille dans l'espace de noms des métriques de performance (PMNS(5)), alors pmlogsummary descendra récursivement le PMNS et rapportera tous les nœuds feuilles. Si aucun argument nommetric n'est fourni, la racine de l'espace de noms est utilisée.

Les métriques avec sémantique de compteur sont converties en taux avant d'être évaluées.

OPTIONS

Les options de ligne de commande disponibles sont :

-a, --all
Imprimer toutes les informations. Ceci est équivalent à -blmMy.
-b
Imprimer les deux formes de moyennage, c'est-à-dire le moyennage stochastique et temporel.
-B nbins, --bins=nbins
Imprimer la distribution approximative des valeurs, en utilisant des intervalles d'histogramme tels que la plage de valeurs (minimum - maximum) pour chaque métrique est divisée équitablement en nbins intervalles, et chaque intervalle accumule la fréquence des valeurs observées dans la plage correspondante. Référez-vous à la section « FORMAT DE SORTIE » ci-dessous pour une description de la façon dont la distribution des valeurs est rapportée).
-f
Format tableur - le caractère tabulation est utilisé pour délimiter chaque champ imprimé. Cette option est destinée à permettre à la sortie de pmlogsummary d'être importée directement dans des applications tableur courantes.
-F
Format tableur - le caractère virgule est utilisé pour délimiter chaque champ imprimé. Cette option est destinée à permettre à la sortie de pmlogsummary d'être importée directement dans des applications tableur courantes qui supportent le format CSV (Comma Separated Value).
-H, --header
Imprimer une ligne d'en-tête au début indiquant ce que chaque champ représente.
-i, --mintime
Imprimer également l'heure à laquelle la valeur minimale a été enregistrée. Le format de ce horodatage est décrit dans la section « FORMAT DE SORTIE » ci-dessous.
-I, --maxtime
Imprimer également l'heure à laquelle la valeur maximale a été enregistrée. Le format de ce horodatage est décrit dans la section « FORMAT DE SORTIE » ci-dessous.
-l, --label
Imprimer également l'étiquette de l'archive, montrant la version du format de l'archive, l'heure et la date de début et de fin de la fenêtre temporelle de l'archive, et l'hôte d'où les valeurs des métriques de performance ont été collectées.
-m, --minimum
Imprimer également la valeur minimale enregistrée pour chaque métrique.
-M, --maximum
Imprimer également la valeur maximale enregistrée pour chaque métrique.
-n pmnsfile, --namespace=pmnsfile
Charger un espace de noms alternatif des métriques de performance (PMNS(5)) à partir du fichier pmnsfile.
-N
Supprimer tous les avertissements résultant des récupérations d'archives individuelles (par défaut).
-p precision, --precision=precision
Imprimer tous les nombres à virgule flottante avec precision chiffres après la virgule.
-s, --sum
Imprimer (uniquement) la somme de toutes les valeurs enregistrées pour chaque métrique.
-S starttime, --start=starttime
Définir l'starttime de la fenêtre temporelle. Référez-vous à PCPIntro(1) pour une description complète de la syntaxe de starttime.
-T endtime, --finish=endtime
Définir l'endtime de la fenêtre temporelle. Référez-vous à PCPIntro(1) pour une description complète de la syntaxe de endtime.
-v, --verbose
Rapporter (verbeusement) les avertissements résultant des récupérations d'archives individuelles.
-V, --version
Afficher le numéro de version et quitter.
-x
Imprimer les moyennes stochastiques au lieu des moyennes temporelles par défaut.
-y, --samples
Imprimer également le nombre d'échantillons rencontrés dans l'ensemble d'archives pour chaque métrique.
-z, --hostzone
Changer le fuseau horaire pour le fuseau horaire local sur l'hôte qui est la source des métriques de performance, comme spécifié dans l'enregistrement d'étiquette de l'archive.
-Z timezone, --timezone=timezone
Par défaut, pmlogsummary rapporte l'heure locale sur le système où pmlogsummary est exécuté. Changez le fuseau horaire pour timezone dans le format de la variable d'environnement TZ, tel que décrit dans environ(7).
-?, --help
Afficher le message d'utilisation et quitter.

FORMAT DE SORTIE

La sortie de pmlogsummary est spartiate car elle est destinée à être post-traitée avec des outils standard. Cela signifie qu'il n'y a pas d'annotation associée à chaque champ de sortie, ce qui rendrait le traitement plus difficile. L'intention est que la sortie de pmlogsummary soit formatée pour pouvoir être utilisée par un programme tableur, incluse dans une page Web, ou autre.

Pour chaque métrique, pmlogsummary produit une seule ligne de sortie comme suit :


nommetric  valeur(s) unités

Pour les métriques à instances multiples, pmlogsummary produit plusieurs lignes de sortie comme suit :


nommetric ["instance 1"] valeur(s) unités
nommetric ["instance 2"] valeur(s) unités
nommetric ["instance N"] valeur(s) unités

Les valeur(s) imprimées pour chaque métrique suivent toujours cet ordre : moyenne stochastique, moyenne temporelle, minimum, horodatage du minimum, maximum, horodatage du maximum, nombre, [plage bac 1], nombre bac 1, ... [plage bac nbins], nombre bac nbins. Les valeurs individuelles pour chaque métrique sont séparées par des espaces (sauf si l'option -f est utilisée).

Toutes les métriques de compteur mesurées en unités de temps seront converties en secondes avant d'être converties en taux et utilisées dans les calculs de pmlogsummary. Les valeurs calculées pour ces métriques sont également imprimées en secondes.

Les unités seront affichées dans le format décrit par pmUnitsStr(3).

Avec l'une des options -i ou -I, pmlogsummary produit deux formats d'horodatage différents, en fonction de l'intervalle sur lequel il est exécuté. Pour un intervalle supérieur à 24 heures, la date est affichée en plus de l'heure à laquelle les maxima et/ou minima se sont produits. Si l'étendue des données vérifiées est inférieure à 24 heures, un format plus précis est utilisé (l'heure est affichée avec une précision milliseconde, mais sans la date).

NOTES

La moyenne pour une métrique individuelle est calculée comme suit :

Les métriques non-compteurs sont moyennées en utilisant la moyenne stochastique - chaque observation a un poids égal dans le calcul de la moyenne (la somme de toutes les valeurs divisée par le nombre total de valeurs, pour chaque métrique).

Les métriques compteurs sont moyennées en utilisant la moyenne temporelle (par défaut), mais l'option -x peut être utilisée pour spécifier que les compteurs doivent être moyennés en utilisant la méthode stochastique à la place. Lors du calcul d'une moyenne temporelle, la somme du produit de chaque valeur d'échantillon multipliée par la différence de temps entre chaque échantillon, est divisée par le temps total sur lequel cette métrique a été enregistrée.

Les métriques compteurs dont les mesures ne couvrent pas 90 % de l'ensemble des archives seront imprimées avec le nom de la métrique précédé d'un astérisque (*).

FICHIERS

$PCP_VAR_DIR/pmns/*
fichiers de spécification PMNS par défaut
$PCP_LOG_DIR/pmlogger/<hostname>
Répertoire par défaut pour les archives PCP contenant les valeurs de métriques de performance collectées à partir de l'hôte <hostname>.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider au diagnostic des problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

Les options de débogage spécifiques à pmlogsummary sont les suivantes :

Option Description
appl0 rapport des métriques dans l'archive, métriques sélectionnées, valeurs métrique-instance, enregistrements de marque, début de la deuxième itération
appl1 détails du dépassement du compteur, données brutes pour les extrêmes et les moyennes
appl2 suivi des valeurs maximales et minimales
