PMIDSTR(3) Manuel des fonctions de bibliothèque PMIDSTR(3)

NOM

pmIDStr, pmIDStr_r - convertir un identifiant de métrique de performance en chaîne de caractères

C SYNTAXE

#include <pcp/pmapi.h>

const char *pmIDStr(pmID pmid);
char *pmIDStr_r(pmID pmid, char *buf, int buflen);

cc ... -lpcp

DESCRIPTION

Pour être utilisé dans les messages d'erreur et de diagnostic, pmIDStr renvoie une version "lisible par l'homme" de l'identifiant de métrique de performance (PMID) spécifié. La fonction pmIDStr_r fait de même, mais stocke le résultat dans un tampon fourni par l'utilisateur buf d'une longueur buflen, qui devrait avoir la place pour au moins 20 octets.

En interne, un PMID est encodé avec trois champs : domaine, cluster et élément. pmIDStr renvoie une chaîne où chacun des champs apparaît sous forme de nombres décimaux, séparés par des points.

La valeur de chaîne résultante de pmIDStr est conservée dans un unique tampon statique, donc la valeur renvoyée n'est valide que jusqu'au prochain appel à pmIDStr.

NOTES

pmIDStr renvoie un pointeur vers un tampon statique et n'est donc pas thread-safe. Les applications multithread devraient plutôt utiliser pmIDStr_r.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5). Les valeurs de ces variables peuvent être obtenues par programme en utilisant la fonction pmGetConfig(3).
