PMDARSYSLOG(1) Manuel des commandes générales PMDARSYSLOG(1)

NOM

pmdarsyslog - PMDA pour rsyslog (reliable and extended syslog)

DESCRIPTION

pmdarsyslog est un Agent de Domaine de Métriques de Performance (PMDA) qui exporte les valeurs des métriques du serveur rsyslogd(8).

Plus de détails sur rsyslog sont disponibles sur http://www.rsyslog.com/.

INSTALLATION

Si vous souhaitez accéder aux noms et aux valeurs des métriques de performance de rsyslog, effectuez les actions suivantes en tant que root :

# cd $PCP_PMDAS_DIR/rsyslog
# ./Install

Pour désinstaller, effectuez les actions suivantes en tant que root :

# cd $PCP_PMDAS_DIR/rsyslog
# ./Remove

pmdarsyslog est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts d'installation et de désinstallation informent pmcd(1) lorsque l'agent est installé ou supprimé.

Pour pouvoir utiliser cet agent, la collecte des statistiques rsyslog doit être activée. Ceci est fait en ajoutant les lignes :

module(load="impstats" interval="10" severity="7")
if $syslogtag contains 'rsyslogd-pstats' then {
    action(
        name="pstats-for-pcp"
        type="ompipe"
        template="RSYSLOG_FileFormat"
        pipe="/var/log/pcp/rsyslog/stats"
    )
    stop
}

à votre fichier de configuration rsyslog.conf(5) après l'installation du PMDA.

FICHIERS

$PCP_LOG_DIR/rsyslog/stats
tube nommé contenant les statistiques exportées par rsyslog, généralement créé par le script d'installation du PMDA.
$PCP_PMDAS_DIR/rsyslog/rsyslog.conf
fichier de configuration optionnel pour pmdarsyslog
$PCP_PMDAS_DIR/rsyslog/Install
script d'installation de l'agent pmdarsyslog
$PCP_PMDAS_DIR/rsyslog/Remove
script d'annulation d'installation de l'agent pmdarsyslog
$PCP_LOG_DIR/pmcd/rsyslog.log
fichier journal par défaut pour les messages d'erreur de pmdarsyslog

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. À chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1), pmcd(1) et rsyslogd(1).
