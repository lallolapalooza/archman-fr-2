PMDATRIVIAL(1) Manuel des commandes générales PMDATRIVIAL(1)

NOM

pmdatrivial - agent de domaine métrique de performance trivial (PMDA)

SYNTAXE

$PCP_PMDAS_DIR/trivial/pmdatrivial [-D debug] [-d domaine] [-l fichierjournal] [-U nomutilisateur]

DESCRIPTION

pmdatrivial est l'agent de domaine métrique de performance (PMDA) le plus simple possible, qui exporte une seule métrique de performance : le temps en secondes écoulé depuis le 1er janvier 1970.

Le PMDA trivial est distribué sous forme de code source et est conçu pour aider les développeurs de PMDA.

Une brève description des options de ligne de commande de pmdatrivial suit :

-d
Il est absolument crucial que le numéro de domaine des métriques de performance spécifié ici soit unique et cohérent. C'est-à-dire que domaine doit être différent pour chaque PMDA sur le même hôte, et le même numéro de domaine doit être utilisé pour le même PMDA sur tous les hôtes.
-l
Emplacement du fichier journal. Par défaut, un fichier journal nommé trivial.log est écrit dans le répertoire courant de pmcd(1) lorsque pmdatrivial est démarré, c'est-à-dire $PCP_LOG_DIR/pmcd. Si le fichier journal ne peut pas être créé ou n'est pas accessible en écriture, la sortie est redirigée vers la sortie d'erreur standard.
-U
Compte utilisateur sous lequel exécuter l'agent. Par défaut, il s'agit du compte non privilégié "pcp" dans les versions actuelles de PCP, mais dans les versions plus anciennes, le compte superutilisateur ("root") était utilisé par défaut.

INSTALLATION

Si vous souhaitez accéder aux noms, aux textes d'aide et aux valeurs des métriques de performance triviales, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/trivial
# ./Install

Si vous souhaitez annuler l'installation, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/trivial
# ./Remove

pmdatrivial est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove informent pmcd(1) lorsque l'agent est installé ou désinstallé.

FICHIERS

$PCP_PMCDCONF_PATH
options de ligne de commande utilisées pour lancer pmdatrivial
$PCP_PMDAS_DIR/trivial/help
fichier texte d'aide par défaut pour les métriques triviales
$PCP_PMDAS_DIR/trivial/Install
script d'installation pour l'agent pmdatrivial
$PCP_PMDAS_DIR/trivial/Remove
script d'annulation d'installation pour l'agent pmdatrivial
$PCP_LOG_DIR/pmcd/trivial.log
fichier journal par défaut pour les messages d'erreur et autres informations provenant de pmdatrivial

ENVIRONNEMENT PCP

Les variables d'environnement préfixées par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à diagnostiquer les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.
