NOM

pmdasnmp - Passerelle de SNMP vers PCP (PMDA)

DESCRIPTION

pmdasnmp est un Agent de Domaine de Mesures de Performance (PMDA) qui fournit une passerelle générique des requêtes PCP d'un client PCP vers des requêtes SNMP d'un ou plusieurs agents SNMP.

INSTALLATION

Si vous souhaitez accéder aux métriques de performance de la passerelle SNMP, effectuez les opérations suivantes en tant que root :

# cd $PCP_PMDAS_DIR/snmp
# ./Install

Si vous souhaitez annuler l'installation, effectuez les opérations suivantes en tant que root :

# cd $PCP_PMDAS_DIR/snmp
# ./Remove

pmdasnmp est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove informent pmcd(1) lorsque l'agent est installé ou supprimé.
