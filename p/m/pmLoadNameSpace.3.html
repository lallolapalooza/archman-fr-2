NOM

pmLoadNameSpace - charge un PMNS local pour une application

SYNTAXE EN C

#include <pcp/pmapi.h>

int pmLoadNameSpace(const char *filename);

cc ... -lpcp

DESCRIPTION

Si l'application souhaite forcer l'utilisation d'un espace de noms de métriques de performance (PMNS) local au lieu d'un PMNS distribué, elle doit charger le PMNS en utilisant pmLoadNameSpace ou pmLoadASCIINameSpace(3). Si l'application doit utiliser un PMNS distribué, elle ne doit PAS faire d'appel pour charger explicitement le PMNS.

La plupart des applications utilisant un contexte d'interface de programmation d'application de métriques de performance (PMAPI) (de quelque type que ce soit, donc PM_CONTEXT_HOST ou PM_CONTEXT_ARCHIVE ou PM_CONTEXT_LOCAL) n'auront pas besoin d'appeler pmLoadNameSpace.

L'argument filename désigne le PMNS d'intérêt. Pour les applications ne nécessitant pas de PMNS personnalisé, la valeur spéciale PM_NS_DEFAULT peut être utilisée pour filename, afin de forcer le chargement du PMNS local par défaut.

Le PMNS local par défaut se trouve dans le fichier $PCP_VAR_DIR/pmns/root, sauf si la variable d'environnement PMNS_DEFAULT est définie, auquel cas la valeur est supposée être le chemin d'accès au fichier contenant le PMNS local par défaut.

Externellement, un PMNS est stocké dans un format ASCII tel que décrit dans PMNS(5). Cependant, notez que pmLoadNameSpace suppose que filename ne contient aucun commentaire de style C, aucune directive de préprocesseur ni aucune macro ; si tel n'est pas le cas, pmLoadASCIINameSpace(3) doit être utilisé à la place.

Depuis la version 3.10.3 de PCP, par défaut, plusieurs noms dans le PMNS peuvent être associés à un seul identifiant de métrique de performance (PMID) et ceci est inconditionnellement autorisé par pmLoadNameSpace. pmLoadASCIINameSpace(3) fournit une interface alternative avec un contrôle défini par l'utilisateur sur la gestion des noms dupliqués pour le même PMID dans le PMNS.

pmLoadNameSpace renvoie zéro en cas de succès.

DIAGNOSTICS

Les erreurs de syntaxe et autres erreurs lors de l'analyse du PMNS sont signalées sur stderr avec un message de la forme « Error Parsing ASCII PMNS: ... ».

PM_ERR_DUPPMNS

Il est interdit d'essayer de charger plus d'un PMNS, ou d'appeler pmLoadNameSpace et/ou pmLoadASCIINameSpace(3) plus d'une fois.

PM_ERR_PMNS

Erreur de syntaxe dans le fichier PMNS.

FICHIERS

$PCP_VAR_DIR/pmns/root
le PMNS local par défaut, lorsque la variable d'environnement PMNS_DEFAULT est non définie

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5). Les valeurs de ces variables peuvent être obtenues par programme en utilisant la fonction pmGetConfig(3).

VOIR AUSSI

PMAPI(3), pmGetConfig(3), pmLoadASCIINameSpace(3), pmTrimNameSpace(3), pcp.conf(5), pcp.env(5) et PMNS(5).
