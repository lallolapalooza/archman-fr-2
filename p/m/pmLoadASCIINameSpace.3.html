NOM

pmLoadASCIINameSpace - établir un PMNS local pour une application

SYNTAXE C

#include <pcp/pmapi.h>

int pmLoadASCIINameSpace(const char *filename, int dupok);

cc ... -lpcp

DESCRIPTION

Si l'application souhaite forcer l'utilisation d'un espace de noms de métriques de performance (PMNS) local au lieu d'un PMNS distribué, elle doit charger le PMNS en utilisant pmLoadASCIINameSpace ou pmLoadNameSpace(3). Si l'application souhaite utiliser un PMNS distribué, elle ne doit PAS appeler explicitement le chargement du PMNS.

La plupart des applications utilisant un contexte d'interface de programmation d'applications de métriques de performance (PMAPI) (de quelque type que ce soit, donc PM_CONTEXT_HOST ou PM_CONTEXT_ARCHIVE ou PM_CONTEXT_LOCAL) n'ont pas besoin d'appeler pmLoadASCIINameSpace.

L'argument filename désigne le PMNS d'intérêt. Pour les applications ne nécessitant pas un PMNS personnalisé, la valeur spéciale PM_NS_DEFAULT peut être utilisée pour filename, afin de forcer le chargement du PMNS local par défaut.

Le PMNS local par défaut se trouve dans le fichier $PCP_VAR_DIR/pmns/root à moins que la variable d'environnement PMNS_DEFAULT ne soit définie, auquel cas la valeur est supposée être le chemin d'accès au fichier contenant le PMNS local par défaut.

pmLoadASCIINameSpace est une variante de pmLoadNameSpace(3) dans laquelle l'argument dupok peut être utilisé pour contrôler le traitement des noms multiples dans le PMNS qui peuvent être associés à un identifiant unique de métrique de performance (PMID). Une valeur de 0 interdit les doublons, toute autre valeur les autorise et ce dernier est le comportement par défaut de pmLoadNameSpace(3) à partir de la Version 3.10.3 de PCP.

L'autre différence est que lorsque pmLoadASCIINameSpace est utilisé et que filename n'est **pas** PM_NS_DEFAULT, le fichier PMNS sera toujours pré-traité avec pmcpp(1) comme décrit dans PMNS(5). Cela permet à un fichier PMNS contenant des commentaires de style C, des directives de préprocesseur ou des macros d'être traité correctement avant que le PMNS ne soit analysé.

pmLoadASCIINameSpace retourne zéro en cas de succès.

DIAGNOSTICS

Les erreurs de syntaxe et autres erreurs lors de l'analyse du PMNS sont signalées sur stderr avec un message de la forme « Erreur lors de l'analyse du PMNS ASCII : ... ».

PM_ERR_DUPPMNS

Il est interdit de charger plus d'un PMNS, ou d'appeler pmLoadASCIINameSpace et/ou pmLoadNameSpace(3) plus d'une fois.

PM_ERR_PMNS

Erreur de syntaxe dans un PMNS au format ASCII.

FICHIERS

$PCP_VAR_DIR/pmns/root
le PMNS local par défaut, lorsque la variable d'environnement PMNS_DEFAULT est non définie

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5). Les valeurs de ces variables peuvent être obtenues par programme en utilisant la fonction pmGetConfig(3).

VOIR AUSSI

PMAPI(3), pmGetConfig(3), pmLoadNameSpace(3), pmTrimNameSpace(3), pcp.conf(5), pcp.env(5) et PMNS(5).
