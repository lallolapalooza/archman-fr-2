DESCRIPTION

Un agent de domaine de métriques de performance (PMDA) qui souhaite exporter des enregistrements d'événements (ou des enregistrements de trace) est encouragé à utiliser une métrique de type PM_TYPE_EVENT ou PM_TYPE_HIGHRES_EVENT pour encoder un groupe d'enregistrements d'événements dans un seul tableau compacté.

La seule différence entre les deux types de métriques est la résolution de l'horodatage associé à chacun - sous forme haute résolution, il est à l'échelle de la nanoseconde (voir clock_gettime(2)), sinon il est à l'échelle de la microseconde (voir gettimeofday(2)). Pour simplifier, nous ne ferons référence qu'à l'API et aux structures de données de résolution inférieure par la suite - cependant, les variantes à résolution plus élevée sont toutes nommées de manière similaire et utilisées de la même manière.

Le format du tableau compacté d'enregistrements d'événements est défini dans <pcp/pmapi.h> et se compose d'une structure pmEventArray contenant un nombre variable de structures pmEventRecord, chacune contenant un nombre variable de structures pmEventParameter, qui peuvent à leur tour contenir une valeur de longueur variable pour chaque paramètre de chaque enregistrement d'événement.

Les équivalents haute résolution sont définis au même endroit, et les structures portent les mêmes noms. Notez que la structure pmEventParameter n'a pas d'horodatage associé, donc elle n'a pas de contrepartie haute résolution.

Les routines décrites ici sont conçues pour aider le développeur PMDA à construire un tableau compacté d'enregistrements d'événements et à gérer toutes les allocations de mémoire nécessaires pour conserver chaque instance d'un tableau d'enregistrements d'événements dans un tampon contigu. L'utilisation normale se ferait dans le cadre de la méthode pmdaFetchCallBack du PMDA.

pmdaEventNewArray est utilisé pour créer un nouveau tableau d'événements. La valeur de retour est un petit entier qui est utilisé comme paramètre idx pour les autres routines afin d'identifier un tableau d'événements spécifique. Si nécessaire, un PMDA peut créer et utiliser plusieurs tableaux d'événements.

Pour commencer un nouveau cycle et remplir un tableau d'événements depuis le début, appelez pmdaEventResetArray.

Si le PMDA a fini d'utiliser un tableau d'événements, pmdaEventReleaseArray peut être utilisé pour libérer le stockage sous-jacent et "fermer" le tableau d'événements afin que les tentatives ultérieures d'utilisation de idx renvoient PM_ERR_NOCONTEXT.

Pour démarrer un nouvel enregistrement d'événement, utilisez pmdaEventAddRecord. L'horodatage de l'enregistrement d'événement est fourni via tp et le paramètre flags peut être utilisé pour définir le champ de contrôle qui détermine le type de l'enregistrement d'événement - flags peut être le "ou" binaire d'une ou plusieurs des valeurs PM_EVENT_FLAG_* définies dans <pcp/pmapi.h> (mais notez que PM_EVENT_FLAG_MISSED ne doit pas être utilisé dans ce contexte).

Si des enregistrements d'événements ont été manqués, soit parce que le PMDA ne peut pas suivre, soit parce que le client PMAPI ne peut pas suivre, alors pmdaEventAddMissedRecord peut être utilisé. idx et tp ont la même signification que pour pmdaEventAddRecord et nmissed est le nombre d'enregistrements d'événements qui ont été manqués à ce point de la série temporelle des enregistrements d'événements. pmdaEventAddMissedRecord peut être appelé plusieurs fois pour un seul lot d'enregistrements d'événements s'il y a plus d'un épisode "enregistrement d'événement manqué".

Une fois qu'un enregistrement d'événement a été démarré en appelant pmdaEventAddRecord, un ou plusieurs paramètres d'événement peuvent être ajoutés en utilisant pmdaEventAddParam. Les paramètres pmid et type décrivent le PMID du paramètre et le type de données (l'un des valeurs PM_TYPE_* de <pcp/pmapi.h>) de la valeur passée via avp. type doit être un type dont la taille de la valeur est impliquée par le type ou par la longueur d'une valeur de chaîne (pour PM_TYPE_STRING) ou encodée dans avp->vbp (pour PM_TYPE_AGGREGATE).

Une fois que le tableau compacté a été construit, pmdaEventGetAddr doit être utilisé pour initialiser les champs ea_type et ea_len au début de la structure pmEventArray et renvoyer l'adresse de base du tableau d'événements qui est assignée au champ vp de la structure pmAtomValue que la méthode pmdaFetchCallBack doit renvoyer.

pmdaEventHighResAddParam et pmdaEventHighResGetAddr sont d'anciens noms pour pmdaEventAddHighResParam et pmdaEventGetHighResAddr (respectivement) qui ont été conservés pour la compatibilité ascendante.

EXEMPLE

Le code squelettique suivant montre comment ces routines pourraient être utilisées.

int             sts;
int             myarray;
int             first = 1;
pmEventArray    eap;
if (first) {
   first = 0;
   if ((myarray = pmdaEventNewArray()) < 0) {
      // signaler une erreur et échouer
   }
}
pmdaEventResetArray(myarray);
// boucle sur tous les enregistrements d'événements à exporter
... {
   struct timeval   stamp;
   int              flags;
   // établir l'horodatage et définir les drapeaux à 0 ou à une combinaison
   // de PM_EVENT_FLAG_POINT, PM_EVENT_FLAG_START, PM_EVENT_FLAG_ID,
   // etc.
   if ((sts = pmdaEventAddRecord(myarray, &stamp, flags)) < 0) {
      // signaler une erreur et échouer
   }
   // boucle sur tous les paramètres de cet enregistrement d'événement
   ... {
      pmID          pmid;
      int           type;
      pmAtomValue   atom;
      // construire pmid, type et atom pour le paramètre et
      // sa valeur
      if ((sts = pmdaEventAddParam(myarray, pmid, type, &atom)) < 0) {
	 // signaler une erreur et échouer
      }
   }
   // si des enregistrements d'événements ont été manqués (cela pourrait être au début
   // de l'ensemble exporté, ou à la fin, ou au milieu, ou
   // une combinaison de plusieurs épisodes d'enregistrements manqués)
   ... {
      int              nmissed;
      struct timeval   stamp;
      if ((sts = pmdaEventAddMissedRecord(myarray, &stamp, nmissed)) < 0) {
	 // signaler une erreur et échouer
      }
   }
}
// finalisation
eap = pmdaEventGetAddr(myarray);
