NOM

pmdads389 - PMDA du serveur d'annuaire 389

DESCRIPTION

pmdads389 est un agent de domaine de métriques de performance (PMDA) qui extrait les données de performance en direct d'une instance en cours d'exécution du serveur d'annuaire 389.

Voir le Guide d'administration du serveur d'annuaire Red Hat pour la description de chaque métrique.

INSTALLATION

pmdads389 lit un fichier de configuration optionnel

$PCP_PMDAS_DIR/ds389/ds389.conf

Ce fichier peut contenir des valeurs remplacées (code Perl) pour les paramètres listés au début de pmdads389.pl, à savoir :

  • Serveur LDAP
  • DN de liaison
  • Mot de passe de liaison
  • Portée de recherche par défaut
  • Base de recherche par défaut
  • Filtre de recherche par défaut
  • Intervalle de requête
  • Liste des sources
  • Liste des attributs à afficher pour chaque source

Veuillez utiliser le fichier ds389.conf.example fourni comme point de départ. Une fois cela configuré, vous pouvez accéder aux noms et valeurs des métriques de performance de 389 DS en effectuant les opérations suivantes en tant que root :

# cd $PCP_PMDAS_DIR/ds389
# ./Install

Pour désinstaller, effectuez les opérations suivantes en tant que root :

# cd $PCP_PMDAS_DIR/ds389
# ./Remove

pmdads389 est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove informent pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/ds389/ds389.conf.example
fichier de configuration d'exemple pour l'agent pmdads389
$PCP_PMDAS_DIR/ds389/ds389.conf
fichier de configuration pour l'agent pmdads389
$PCP_PMDAS_DIR/ds389/Install
script d'installation de l'agent pmdads389
$PCP_PMDAS_DIR/ds389/Remove
script d'annulation de l'installation de l'agent pmdads389
$PCP_LOG_DIR/pmcd/ds389.log
fichier journal par défaut pour les messages d'erreur de pmdads389

ENVIRONNEMENT PCP

Les variables d'environnement commençant par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).
