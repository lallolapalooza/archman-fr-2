PMGETUSERNAME(3) Manuel des fonctions de bibliothèque PMGETUSERNAME(3)

NOM

pmGetUsername - récupérer le nom d'utilisateur spécial de PCP

SYNTAXE C

#include <pcp/pmapi.h>

int pmGetUsername(char **username);

cc ... -lpcp

DESCRIPTION

Dans le cadre du Performance Co-Pilot (PCP), certaines applications utilisent un nom d'utilisateur spécial (non-root) pour permettre l'accès, par exemple pour écrire des fichiers journaux dans des répertoires protégés.

pmGetUsername renvoie le nom via username.

La variable nommée PCP_USER est récupérée à l'aide de pmGetOptionalConfig(3). Si cela réussit, pmGetUsername renvoie 1. Sinon, username est défini sur la valeur par défaut de pcp et pmGetUsername renvoie 0.

pmGetUsername est le plus souvent utilisé en conjonction avec pmSetProcessIdentity(3) au démarrage du processus.

VOIR AUSSI

PMAPI(3), pmGetOptionalConfig(3) et pmSetProcessIdentity(3).
