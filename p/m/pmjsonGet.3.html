PMJSONGET(3) Manuel des fonctions de bibliothèque PMJSONGET(3)

NOM

pmjsonGet, pmjsonPrint, pmjsonInit, pmjsonInitIndom - Fonctions d'aide pour les chaînes JSON et extraction de métriques

C SYNTAXE

#include <pcp/pmapi.h>
#include <pcp/pmjson.h>

typedef int (*json_get)(void *buffer,
int length, void *data);

int pmjsonGet(json_metric_desc *json_metrics,
int nmetrics, pmInDom indom, json_get callback, void *data);

int pmjsonPrint(FILE *fp,
json_flag *output_flags, const char *json_pointer, json_get callback, void *data);

int pmjsonInit(int fd,
json_metric_desc *json_metrics, int nmetrics);

int pmjsonInitIndom(int fd,
json_metric_desc *json_metrics, int nmetrics, pmInDom indom);

cc ... -lpcp_web

DESCRIPTION

pmjsonGet effectue l'extraction des valeurs de métriques à partir de chaînes JSON pour un agent de domaine de métriques de performance (PMDA(3)). Les métriques et les instances sont définies par le paramètre json_metrics. Le résultat de l'analyse est l'extraction des valeurs pour les métriques demandées (telles que définies dans le champ json_pointer) dans le champ values.

Un utilitaire de diagnostic simple pour le rapport des chaînes JSON est également fourni à titre de commodité. Son argument output_flags lui permet de prendre en charge une variété de formats de sortie alternatifs, y compris le JSON minimal (sans espace blanc facultatif), formaté joliment, et un sous-ensemble YAML simple.

json_metrics est le tableau de la structure json_metric_desc qui contient le pointeur JSON vers les données de la métrique, des indicateurs possibles pour vérifier les données, le nombre de valeurs (dans le cas d'un tableau), pmAtomValue où les données sont stockées, ainsi que le domaine d'instance au cas où le PMDA aurait plusieurs domaines d'instance. Le nombre d'éléments dans le tableau json_metrics est indiqué par le paramètre nmetrics.

Des interfaces pour les cas courants sont fournies - pmjsonInit spécifie un appel aux fonctionnalités d'analyse JSON et d'extraction de valeurs de métriques où il n'y a pas de domaines d'instance (ou le PMDA souhaite effectuer lui-même des opérations sur les domaines d'instance) et où les données peuvent être lues directement à partir d'un descripteur de fichier ouvert. pmjsonInitIndom est similaire, mais utilise la fonction pmdaCacheStore(3) lorsque c'est possible.

La chaîne JSON doit être fournie par la fonction callback. Cette fonction reçoit un buffer mémoire de length octets et un pointeur utilisateur opaque data qui reste inchangé depuis l'appel d'origine à pmjsonGet ou pmjsonPrint. Le résultat retourné doit être le nombre d'octets écrits dans buffer, zéro lorsqu'il n'y a plus de données disponibles ou moins que zéro en cas d'erreur.

indom est le domaine d'instance à passer à pmdaCacheStore.

typedef struct json_metrics_desc {
    char          *json_pointer;  /* pointeur JSON vers la métrique */
    int           flags;          /* indicateurs à vérifier s'ils sont définis */
    int           num_values;     /* nombre de valeurs */
    pmAtomValue   values;         /* valeur de la métrique */
    char          *dom;           /* domaine d'instance */
} json_metric_desc;

La syntaxe du pointeur JSON suit actuellement la norme RFC6901 pour spécifier l'emplacement d'une métrique dans le document JSON.

EXEMPLE

Pour le document JSON d'exemple :

{
    "Name": "/clever_almeida",
    "State": {
        "Dead": false,
        "Error": "",
        "ExitCode": 0,
        "FinishedAt": "2016-07-18T21:21:20.332488706Z",
        "OOMKilled": false,
        "Paused": false,
        "Pid": 0,
        "Restarting": false,
        "Running": false,
        "StartedAt": "2016-07-18T14:10:58.52487316Z"
    }
}

Un tableau json_metric correspondant possible serait le suivant pour le Pid, le Nom et les métriques indiquant si le conteneur est en cours d'exécution, en pause ou en redémarrage.

static json_metric_desc json_metrics[] = {
    { "State/Pid", 0, 1, {0}, ""},
    { "Name", 0, 1, {0}, ""},
    { "State/Running", CONTAINER_FLAG_RUNNING, 1, {0}, ""},
    { "State/Paused", CONTAINER_FLAG_PAUSED, 1, {0}, ""},
    { "State/Restarting", CONTAINER_FLAG_RESTARTING, 1, {0}, ""},
};

CODE DE RETOUR

Les fonctions retournent zéro en cas de succès, sinon un code d'erreur approprié pour être passé à pmErrStr_r(3).
