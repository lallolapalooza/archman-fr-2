PMDAAMDGPU(1) Manuel des commandes générales PMDAAMDGPU(1)

NOM

pmdaamdgpu - agent de domaine de métriques GPU AMD (PMDA)

SYNTAXE

$PCP_PMDAS_DIR/amdgpu/pmdaamdgpu [-D debug] [-d domaine] [-l fichierlog] [-t intervalle]

DESCRIPTION

pmdaamdgpu est un agent de domaine de métriques de performance (PMDA) qui extrait les métriques décrivant les métriques disponibles sur les cartes GPU AMD via la bibliothèque DRM.

Le PMDA amdgpu exporte des métriques qui mesurent l'activité du GPU, l'utilisation de la mémoire, la température, etc. sur les GPU AMD GCN 1.2+.

Une brève description des options de ligne de commande de pmdaamdgpu suit :

-d
Il est absolument crucial que le numéro de domaine des métriques de performance spécifié ici soit unique et cohérent. C'est-à-dire que domaine doit être différent pour chaque PMDA sur le même hôte, et le même numéro de domaine doit être utilisé pour le même PMDA sur tous les hôtes.
-l
Emplacement du fichier journal. Par défaut, un fichier journal nommé amdgpu.log est écrit dans le répertoire courant de pmcd(1) lorsque pmdaamdgpu est démarré, c'est-à-dire $PCP_LOG_DIR/pmcd. Si le fichier journal ne peut pas être créé ou n'est pas accessible en écriture, la sortie est envoyée sur l'erreur standard.
-t
Active et définit un intervalle d'échantillonnage pour le rafraîchissement automatique des valeurs de métriques. La fonctionnalité est désactivée par défaut, cependant cette option permet de spécifier un intervalle de temps auquel toutes les valeurs sont échantillonnées - cela a pour effet de mettre à jour constamment les métriques cumulatives, dans le but d'aider les outils clients tels que pcp-atop(1) et pmlogger(1) à observer des changements sub-temporels dans l'état du GPU et du processus. Typiquement, ces outils ont des intervalles d'échantillonnage plus longs, et peuvent ainsi 'manquer' une activité se produisant pendant leur intervalle d'échantillonnage.

INSTALLATION

Le PMDA amdgpu n'est pas installé et disponible par défaut. Si vous souhaitez annuler l'installation, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/amdgpu
# ./Remove

Si vous souhaitez rétablir l'accès aux noms, au texte d'aide et aux valeurs des métriques de performance des GPU AMD, après suppression, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/amdgpu
# ./Install

pmdaamdgpu est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove informent pmcd(1) lorsque l'agent est installé ou retiré.

FICHIERS

$PCP_PMCDCONF_PATH
options de ligne de commande utilisées pour lancer pmdaamdgpu
$PCP_PMDAS_DIR/amdgpu/help
fichier de texte d'aide par défaut pour les métriques amdgpu
$PCP_PMDAS_DIR/amdgpu/Install
script d'installation de l'agent pmdaamdgpu
$PCP_PMDAS_DIR/amdgpu/Remove
script d'annulation d'installation de l'agent pmdaamdgpu
$PCP_LOG_DIR/pmcd/amdgpu.log
fichier journal par défaut pour les messages d'erreur et autres informations provenant de pmdaamdgpu

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour configurer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à résoudre les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

Les options de débogage spécifiques à pmdaamdgpu sont les suivantes :

Option Description
appl0 interaction avec pmcd(1)
appl2 traçage des appels select(2)
