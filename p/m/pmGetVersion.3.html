PMGETVERSION(3) Manuel des fonctions de bibliothèque PMGETVERSION(3)

NOM

pmGetVersion - récupérer le numéro de version de PCP installé

SYNTAXE C

#include <pcp/pmapi.h>

int pmGetVersion(void);

cc ... -lpcp

DESCRIPTION

pmGetVersion renvoie un encodage binaire du numéro de version de PCP installé localement.

Cela peut être utilisé en conjonction avec les macros associées PM_VERSION(a,b,c) et PM_VERSION_CURRENT qui génèrent des numéros de version de PCP dans le même format. Voir l'exemple ci-dessous.

L'encodage utilise un octet pour chacune des parties du numéro de version du paquet PCP installé, à savoir le numéro majeur, le numéro mineur et le numéro de révision. Ainsi, la version 3.10.5 de PCP est encodée sous la forme 0x30a05.

Le format chaîne de caractères du numéro de version du paquet PCP installé est également disponible via pmGetConfig avec l'argument PCP_VERSION.

pmGetVersion a été introduit dans PCP 3.10.5.

EXEMPLE

Le fragment C suivant démontre l'utilisation des macros de compilation et de la fonction d'exécution pmGetVersion pour une application qui ne doit pas être compilée pour des versions de PCP antérieures à 3.10.5, mais après cela, il existe deux implémentations alternatives avec une variante plus récente (plus rapide, plus performante, plus petite) du service XYZ qui ne deviendra disponible qu'avec PCP 4.0.0.

#include <pcp/pmapi.h>
#ifdef PM_VERSION_CURRENT
#if PM_VERSION_CURRENT < PM_VERSION(3,10,5)
    /* pas de pmGetVersion() avant PCP 3.10.5 */
    printf("Version de PCP 0x%x trop ancienne\n", PM_VERSION_CURRENT);
#endif
    version = pmGetVersion();
    if (version >= PM_VERSION(4,0,0) {
	/* V2 du service XYZ introduite dans PCP 4.0.0 */
	printf("Utilisation de la V2 du service XYZ\n")
	...
    }
    else {
	printf("Utilisation de la V1 du service XYZ\n")
	...
    }
#else
    {
	char *ver = pmGetConfig("PCP_VERSION");
	/* seule option est d'extraire le numéro de version de la chaîne retournée */
	...
    }
#endif
