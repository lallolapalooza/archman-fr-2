NOM

pmlogredact - supprimer les informations sensibles des archives PCP

SYNOPIS

pmlogredact [-vx?] [-D debug] [-c config] inarch [outarch]

DESCRIPTION

Les archives de Performance Co-Pilot (PCP) peuvent contenir une grande quantité d'informations collectées à partir de tous les composants d'un système.

Certaines de ces informations peuvent être considérées comme sensibles en dehors du contexte de la collecte d'origine pour l'analyse des performances du système. Les exemples d'informations sensibles peuvent inclure les noms d'utilisateur, les chemins vers les répertoires personnels des utilisateurs (qui peuvent impliquer les noms d'utilisateur), les noms d'hôtes, les adresses IP, les adresses MAC, les arguments de ligne de commande, les variables d'environnement des processus, etc.

pmlogredact peut être utilisé pour supprimer les informations sensibles avant que les archives ne soient expédiées à une autre organisation, ou stockées dans une autre géographie, ou pour se conformer aux réglementations ou à la vie privée. L'archive de sortie outarch est la version expurgée de l'archive d'entrée inarch.

pmlogredact est un wrapper léger autour de pmlogrewrite(1), et donc les fichiers de configuration de pmlogredact suivent la même syntaxe que les fichiers de configuration de pmlogrewrite(1).

Il existe un ensemble par défaut de règles d'expurgation dans les fichiers $PCP_VAR_DIR/config/pmlogredact/*. Ces règles suppriment certaines métriques, réécrivent les domaines d'instance de certaines métriques et réécrivent les valeurs de certaines métriques. L'option -x (ou --exclude-std) peut être utilisée pour ne pas utiliser l'ensemble par défaut des règles.

Des fichiers de configuration supplémentaires (ou alternatifs) peuvent être spécifiés avec une ou plusieurs options -c (ou --config), où chaque config est soit un fichier, soit un répertoire (impliquant tous les fichiers de ce répertoire).

L'option -v (ou --verbose) ajoute de la verbosité (et est passée directement à pmlogrewrite(1)).

L'option -? (ou --help) affiche un message d'utilisation et se termine.

FICHIERS

$PCP_VAR_DIR/config/pmlogredact/*
règles d'expurgation par défaut

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à dépanner les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à fournir des indications aux développeurs plutôt qu'aux utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et de leur signification.

VOIR AUSSI

pmlogrewrite(1), pcp.conf(5) et pcp.env(5).
