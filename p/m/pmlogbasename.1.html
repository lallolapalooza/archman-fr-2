PMLOGBASENAME(1) Manuel des commandes générales PMLOGBASENAME(1)

NOM

pmlogbasename - nom de base d'une archive PCP

SYNTAXE

pmlogbasename [-D debug] nom

DESCRIPTION

pmlogbasename prend nom (généralement le nom d'un des fichiers physiques d'une archive PCP) et lui supprime les suffixes de compression puis les suffixes de composant d'archive PCP, puis rapporte le résultat (le nom de base d'une archive PCP) sur la sortie standard.

Les suffixes de compression connus de PCP sont : .xz, .lzma, .bz2, .bz, .gz, .Z et .z.

Les suffixes de composant d'archive PCP sont : .meta, .index et .<n> pour tout entier <n>.

Dans la plupart des cas, la suppression est purement textuelle et est effectuée sans tests sur l'existence d'un des fichiers associés, bien que si nom ne correspond pas au motif d'un nom de fichier valide pour une archive PCP, la sortie soit nom sans aucune suppression.

La seule exception est lorsque nom se termine par .N où N est une séquence de 1 chiffre ou plus, auquel cas une ambiguïté se produit. Par exemple, considérons que nom est 20241125.05.48, où cela pourrait signifier que le nom de base de l'archive est en réalité 20241125.05.48 ou cela pourrait signifier qu'il fait référence au volume 48 du nom de base d'archive 20241125.05. Dans le premier cas, le fichier nom.meta (ou une de ses versions compressées) devrait exister et pmlogbasename sonde le système de fichiers pour déterminer si un tel fichier existe.

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à résoudre les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparée par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

Les options de débogage spécifiques à pmlogbasename sont les suivantes :

Option Description
appl0 rapporte le nom de chaque fichier existant qui correspond potentiellement à nom
appl1 rapporte le nom de chaque fichier qui n'existe pas mais qui a été sondé à la recherche de correspondances avec nom
