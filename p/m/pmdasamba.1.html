PMDASAMBA(1) Performance Co-Pilot PMDASAMBA(1)

NOM

pmdasamba - agent de domaine de métriques de performance Samba (PMDA)

DESCRIPTION

pmdasamba est un agent de domaine de métriques de performance (PMDA) qui exporte les valeurs métriques de Samba, un serveur SMB/CIFS Windows pour UNIX.

Pour que les valeurs soient disponibles par ce PMDA, Samba doit avoir été compilé avec le support du profilage (WITH_PROFILE dans la sortie de "smb -b"). Ce PMDA énumère dynamiquement une grande partie de sa hiérarchie métrique, basée sur le contenu de "smbstatus --profile".

Lorsque l'agent est installé (voir ci-dessous), le script d'installation tentera d'activer la collecte de statistiques Samba, en utilisant "smbcontrol --profile".

INSTALLATION

Si vous souhaitez accéder aux noms et aux valeurs des métriques de performance Samba, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/samba
# ./Install

Si vous souhaitez annuler l'installation, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/samba
# ./Remove

pmdasamba est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou désinstallé.

FICHIERS

$PCP_PMDAS_DIR/samba/Install
script d'installation de l'agent pmdasamba
$PCP_PMDAS_DIR/samba/Remove
script d'annulation de l'installation de l'agent pmdasamba
$PCP_LOG_DIR/pmcd/samba.log
fichier journal par défaut pour les messages d'erreur de pmdasamba

VOIR AUSSI

pmcd(1), samba(7) et smbd(8).
