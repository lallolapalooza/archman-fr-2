PMERRSTR(3) Manuel des fonctions de bibliothèque PMERRSTR(3)

NOM

pmErrStr, pmErrStr_r - convertir un code d'erreur PMAPI en chaîne de caractères

C SYNTAXE

#include <pcp/pmapi.h>

const char *pmErrStr(int code);
char *pmErrStr_r(int code, char *buf, int buflen);

cc ... -lpcp

DESCRIPTION

Traduit un code d'erreur en une chaîne de caractères, adaptée à la génération d'un message de diagnostic. La fonction pmErrStr_r fait la même chose, mais stocke le résultat dans un tampon fourni par l'utilisateur buf d'une longueur buflen, qui devrait avoir de la place pour au moins PM_MAXERRMSGLEN octets.

Par convention, tous les codes d'erreur sont négatifs. Les petites valeurs sont supposées être les versions négativées des codes d'erreur Unix tels que définis dans <errno.h> et les chaînes retournées sont conformes à strerror(3). Les codes d'erreur plus grands et négatifs sont des conditions d'erreur de l'interface de programmation d'applications de métriques de performance (PMAPI) et pmErrStr(3) retourne une chaîne d'erreur PMAPI appropriée, telle que déterminée par code.

NOTES

pmErrStr retourne un pointeur vers un tampon statique, donc la valeur retournée n'est valide que jusqu'au prochain appel à pmErrStr et n'est donc pas thread-safe. Les applications multithread devraient utiliser pmErrStr_r à la place.

VOIR AUSSI

pmerr(1), PMAPI(3) et perror(3).
