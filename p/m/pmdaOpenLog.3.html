PMDAOPENLOG(3) Manuel des fonctions de bibliothèque PMDAOPENLOG(3)

NOM

pmdaOpenLog - redirige stderr vers un fichier journal

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

void pmdaOpenLog(pmdaInterface * dispatch);

cc ... -lpcp_pmda -lpcp

DESCRIPTION

pmdaOpenLog redirige stderr vers le fichier journal spécifié dans la structure dispatch, définie par l'appel précédent à pmdaDaemon(3) ou pmdaGetOpt(3). La première ligne du fichier journal détaillera le nom du processus appelant, l'hôte sur lequel le processus est en cours d'exécution, et l'heure actuelle. De plus, le journal est complété par l'heure de sortie du processus par une routine enregistrée auprès de atexit(3).

ATTENTION

Le PMDA doit utiliser PMDA_INTERFACE_2 ou une version ultérieure, comme spécifié dans l'appel à pmdaDSO(3) ou pmdaDaemon(3).

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5). Les valeurs de ces variables peuvent être obtenues par programme en utilisant la fonction pmGetConfig(3).

VOIR AUSSI

pmcd(1), atexit(2), PMAPI(3), PMDA(3), pmdaDaemon(3) et pmdaGetOpt(3).
