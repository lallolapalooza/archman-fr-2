PMIUSECONTEXT(3) Manuel des fonctions de bibliothèque PMIUSECONTEXT(3)

NOM

pmiUseContext - changer le contexte de LOGIMPORT

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiUseContext(int context);

cc ... -lpcp_import -lpcp

SYNTAXE PERL

use PCP::LogImport;

pmiUseContext($context);

DESCRIPTION

Dans le cadre de l'API d'importation de journaux de Performance Co-Pilot (voir LOGIMPORT(3)), pmiUseContext peut être utilisé par les applications souhaitant générer plusieurs archives PCP simultanément.

L'argument context est une valeur retournée par un appel précédent à pmiStart(3). Lors d'un retour réussi de pmiUseContext, le contexte actuel sera changé pour celui identifié par context.

DIAGNOSTICS

pmiUseContext retourne zéro en cas de succès, sinon une valeur négative qui peut être transformée en message d'erreur en appelant pmiErrStr(3).

VOIR AUSSI

LOGIMPORT(3), pmiErrStr(3) et pmiStart(3).
