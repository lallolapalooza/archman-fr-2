PMDAROOT(1) Manuel des commandes générales PMDAROOT(1)

NOM

pmdaroot - un agent de domaine de métriques de performance privilégié pour le PMCD

SYNOPSIS

$PCP_PMDAS_DIR/root/pmdaroot [-D debug] [-d domaine] [-l logfile] [-s sockname]

DESCRIPTION

pmdaroot est un Agent de Domaine de Métriques de Performance (PMDA) spécial qui coopère étroitement avec pmcd(1) et d'autres PMDA pour fournir des services privilégiés limités aux processus non privilégiés.

Dans ce rôle, il est utilisé pour découvrir les conteneurs du système d'exploitation exécutés sur l'hôte local. Il permet également l'accès aux données de performance à partir de ces conteneurs par d'autres PMDA exécutés sur l'hôte bare-metal, en utilisant pmdaRootConnect(3) et les interfaces de namespace associées.

Comme tous les autres PMDA, il exporte également des métriques de performance du domaine qu'il contrôle. Actuellement, cela se limite aux informations sur les conteneurs du système local ; les conteneurs Docker et LXC peuvent être détectés.

Si un nom de cgroup parent Docker non par défaut est utilisé, cette valeur peut être indiquée à pmdaroot par l'ajout d'une variable $PCP_SYSTEMD_CGROUP dans /etc/pcp.conf.

-d
Il est absolument crucial que le numéro de domaine de métriques de performance spécifié ici soit unique et cohérent. C'est-à-dire que domaine doit être différent pour chaque PMDA sur le même hôte, et le même numéro de domaine doit être utilisé pour le même PMDA sur tous les hôtes.
-l
Emplacement du fichier journal. Par défaut, un fichier journal nommé root.log est écrit dans le répertoire courant de pmcd(1) lorsque pmdaroot est démarré, c'est-à-dire $PCP_LOG_DIR/pmcd. Si le fichier journal ne peut pas être créé ou n'est pas accessible en écriture, la sortie est envoyée vers la sortie d'erreur standard.
-s
Emplacement du socket de domaine unix(7) pour la communication avec les clients demandant des opérations privilégiées. Par défaut, un fichier socket nommé $PCP_TMP_DIR/pmcd/root.socket est utilisé.

INSTALLATION

L'accès aux noms, aux textes d'aide et aux valeurs des métriques de performance du noyau est disponible par défaut - contrairement à la plupart des autres agents, aucune action n'est requise pour les activer et ils ne doivent pas être supprimés.

FICHIERS

$PCP_PMDAS_DIR/root/help
fichier texte d'aide par défaut pour les métriques exportées par le PMDA root.
$PCP_LOG_DIR/pmcd/root.log
fichier journal par défaut pour les messages d'erreur et autres informations provenant du PMDA root.
$PCP_VAR_DIR/pmcd/root.socket
fichier socket par défaut pour la communication avec les clients du PMDA root.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE BONNAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à dépanner les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à fournir des conseils aux développeurs plutôt qu'aux utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et de leur signification.

Les options de débogage spécifiques à pmdaroot sont les suivantes :

Option Description
appl0 interactions avec pmcd(1)
appl1 traitement du démarrage du PMDA

VOIR AUSSI

PCPIntro(1), pmcd(1), PMDA(3), pmdaRootConnect(3), pcp.conf(5) et unix(7).
