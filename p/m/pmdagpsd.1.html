PMDAGPSD(1) Performance Co-Pilot PMDAGPSD(1)

NOM

pmdagpsd - agent de domaine de métriques de performance (PMDA) pour gpsd

DESCRIPTION

pmdagpsd est un agent de domaine de métriques de performance (PMDA) qui exporte les valeurs du démon gpsd.

INSTALLATION

Si vous souhaitez accéder aux noms et valeurs de gpsd, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/gpsd
# ./Install

Si vous souhaitez annuler l'installation, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/gpsd
# ./Remove

pmdagpsd est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou désinstallé.

FICHIERS

$PCP_PMDAS_DIR/gpsd/Install
script d'installation pour l'agent pmdagpsd
$PCP_PMDAS_DIR/gpsd/Remove
script d'annulation d'installation pour l'agent pmdagpsd
$PCP_LOG_DIR/pmcd/gpsd.log
fichier journal par défaut pour les messages d'erreur de pmdagpsd

VOIR AUSSI

pmcd(1).
