PMDAROCESTAT(1) Manuel des commandes générales PMDAROCESTAT(1)

NOM

pmdarocestat - Agent de domaine de métriques de performance (PMDA) pour les périphériques RoCE

SYNTAXE

$PCP_PMDAS_DIR/rocestat/pmdarocestat

DESCRIPTION

Le Rocestat PMDA (Performance Metrics Domain Agent) est un module Performance Co-Pilot (PCP) qui collecte et exporte des statistiques de performance pour les périphériques RDMA over Converged Ethernet (RoCE). Il fournit des aperçus sur les performances réseau, les conditions d'erreur et les événements de congestion, aidant au diagnostic et à la surveillance des communications basées sur RoCE.

Ce PMDA rapporte des statistiques de port InfiniBand agrégées par logiciel, notamment les octets et paquets reçus/transmis, les erreurs de liaison et les gouttes liées à la congestion, aidant à identifier les goulots d'étranglement et les défaillances potentielles. De plus, il inclut des compteurs matériels qui suivent les métriques de transmission de bas niveau, les requêtes dupliquées, les NAKs et les erreurs physiques/de contrainte, offrant une vision plus approfondie de la fiabilité et de l'efficacité du transport sous-jacent.

En outre, Rocestat PMDA collecte des métriques de voies basées sur la priorité à partir de ethtool -S <interface>, filtrant les statistiques liées aux voies de priorité dans le trafic RoCE. Ces métriques donnent un aperçu de la distribution du trafic sur les voies, aidant à diagnostiquer les points chauds de congestion et à optimiser l'équilibrage de charge sur différentes voies.

En intégrant Rocestat PMDA dans un environnement de surveillance PCP, les utilisateurs peuvent analyser efficacement le comportement du réseau RoCE, détecter les anomalies de performance et optimiser les charges de travail RDMA à haute vitesse dans les environnements de centres de données et HPC.

INSTALLATION

Pour installer le Rocestat PMDA, suivez ces étapes :

# cd $PCP_PMDAS_DIR/rocestat
# ./Install

Pour vérifier que le PMDA est en cours d'exécution :

$ pminfo -t rocestat

UTILISATION

Pour interroger les métriques Rocestat, utilisez la commande suivante :

$ pminfo rocestat
Pour récupérer des valeurs de métriques spécifiques : 
$ pmval rocestat.hw.rcv.port_rcv_packets

FICHIERS

$PCP_PMDAS_DIR/rocestat/Install
Script d'installation du Rocestat PMDA.
$PCP_PMDAS_DIR/rocestat/Remove
Script de désinstallation.
$PCP_LOG_DIR/pmcd/rocestat.log
Fichier journal pour les événements et erreurs du Rocestat PMDA.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. À chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).
