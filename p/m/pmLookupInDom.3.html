NOM

pmLookupInDom - traduire un nom d'instance en identifiant d'instance

SYNTAXE C

#include <pcp/pmapi.h>

int pmLookupInDom(pmInDom indom, const char *name);

cc ... -lpcp

DESCRIPTION

Pour le domaine d'instance indom, dans le contexte actuel de l'API d'application de métriques de performance (PMAPI), localiser l'instance avec l'identification externe donnée par name, et retourner l'identifiant d'instance interne.

Seuls les caractères non-espaces de début de name seront utilisés pour identifier l'instance.

La valeur du domaine d'instance indom est typiquement extraite d'une structure pmDesc, suite à un appel à pmLookupDesc(3) pour une métrique de performance particulière.

pmLookupInDom retournera un identifiant d'instance positif en cas de succès.

DIAGNOSTICS

PM_ERR_INDOM
indom n'est pas un identifiant de domaine d'instance valide
PM_ERR_INST
L'instance externe name n'est pas connue pour le domaine d'instance indom dans le contexte PMAPI actuel

VOIR AUSSI

PMAPI(3), pmGetConfig(3), pmGetInDom(3), pmLookupDesc(3), pmLookupInDomArchive(3), pmNameInDom(3), pcp.conf(5) et pcp.env(5).
