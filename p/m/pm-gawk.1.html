PM-GAWK(1) Commandes utilitaires PM-GAWK(1)

NOM

persistent memory gawk - données et fonctions persistantes

SYNOPIS

truncate -s taille heap.pma
export GAWK_PERSIST_FILE=heap.pma
gawk ...

truncate -s taille heap.pma
GAWK_PERSIST_FILE=heap.pma gawk ...

truncate -s taille heap.pma
alias pm='GAWK_PERSIST_FILE=heap.pma'
pm gawk ...                       # succinct

unset GAWK_PERSIST_FILE   # désactiver la persistance

export GAWK_PERSIST_FILE=other_heap.pma  # changer de tas

rm heap.pma               # supprimer le tas

DESCRIPTION

Gawk 5.2 et versions ultérieures prennent en charge une fonctionnalité de mémoire persistante qui peut stocker les variables et fonctions définies par le script dans un fichier pour une utilisation ultérieure. Cette fonctionnalité, appelée pm-gawk, est décrite dans GAWK: Effective AWK Programming et dans le Manuel de l'utilisateur de Persistent Memory gawk.

pm-gawk est activé en passant à gawk le nom d'un fichier tas initialement vide (toutes les octets à zéro), via la variable d'environnement GAWK_PERSIST_FILE. pm-gawk conserve les variables et fonctions définies par le script dans le fichier tas pour une utilisation dans les invocations de gawk ultérieures.

pm-gawk offre au moins deux avantages par rapport à l'extension rwarray existante : il offre un accès en temps constant (``temps O(1)'') aux éléments individuels des tableaux associatifs persistants, et il peut stocker des fonctions définies par le script en plus des variables.

EXEMPLES

Démonstration des variables persistantes :

$ truncate -s 1G heap.pma            # créer le fichier tas
$ export GAWK_PERSIST_FILE=heap.pma  # variable d'environnement "ambiante"
$ gawk 'BEGIN { print ++i }'
1
$ gawk 'BEGIN { print ++i }'
2
$ gawk 'BEGIN { print ++i }'
3

Pour passer la variable d'environnement par commande :

$ unset GAWK_PERSIST_FILE
$ GAWK_PERSIST_FILE=heap.pma gawk 'BEGIN { print ++i }'
4
$ GAWK_PERSIST_FILE=heap.pma gawk 'BEGIN { print ++i }'
5
$ GAWK_PERSIST_FILE=heap.pma gawk 'BEGIN { print ++i }'
6

Pour réduire l'encombrement visuel du passage de variables d'environnement par commande :

$ alias pm='GAWK_PERSIST_FILE=heap.pma'
$ pm gawk 'BEGIN { print ++i }'
7
$ pm gawk 'BEGIN { print ++i }'
8

Pour ne pas activer la persistance :

$ unset GAWK_PERSIST_FILE
$ gawk 'BEGIN { print ++i }'
1
$ gawk 'BEGIN { print ++i }'
1

Pour "oublier" définitivement le contenu du fichier tas :

$ rm heap.pma

VARIABLES D'ENVIRONNEMENT

GAWK_PERSIST_FILE contient le nom d'un fichier tas où les variables et fonctions définies par le script sont stockées. Si cette variable d'environnement n'est pas visible par gawk, la fonctionnalité de persistance n'est pas activée et gawk se comporte de manière traditionnelle.

INFORMATIONS VERSION

La mémoire persistante gawk a été publiée pour la première fois dans gawk 5.2.

AUTEURS

Arnold Robbins, le mainteneur de gawk, a implémenté pm-gawk en utilisant un allocateur de mémoire persistante (pma) fourni par Terence Kelly. Un prototype de preuve de concept antérieur de gawk persistant a été développé par Haris Volos, Zi Fan Tan et Jianan Li en utilisant un fork des sources officielles de gawk.

AVERTISSEMENTS

Le système de fichiers CIFS GNU/Linux est connu pour causer des problèmes à l'allocateur de mémoire persistante. N'utilisez pas de fichier de sauvegarde sur un tel système avec pm-gawk.

SIGNALEMENT BOGUES

Suivez les procédures décrites dans GAWK: Effective AWK Programming et dans le Manuel de l'utilisateur de Persistent Memory gawk. Pour les bogues suspectés liés à la persistance (par opposition aux autres bogues de gawk non liés à la persistance), veuillez également envoyer un e-mail à Terence Kelly à une ou plusieurs des adresses suivantes : tpkelly@acm.org, tpkelly@eecs.umich.edu, ou tpkelly@cs.princeton.edu.

    pm-gawk(1) - Manuel Arch Linux

    NOM

    pm-gawk - Gnu awk pour les scripts Perl

    SYNTAXE

    pm-gawk [-dLlinMpV] [-a idx] [-b bufsz] [-c conn] [-e env] [-f file] [-F fs] [-I inc] [-j n] [-k keylen] [-m max] [-N msize] [-o opt] [-p prec] [-q qual] [-r radix] [-s sep] [-T tmpdir] [-v var=val] [-W warn] [--help] [--version] [pattern] [program] [--] [arg ...]

    DESCRIPTION

    pm-gawk est une implémentation du langage de traitement de texte et de données awk. Le langage awk est principalement conçu pour l'analyse de texte, la correspondance de motifs et la manipulation de données. Il est particulièrement utile pour les tâches d'extraction et de génération de rapports à partir de données structurées.

    pm-gawk est une version spéciale d’awk qui peut être utilisée dans des scripts Perl pour étendre leurs capacités de traitement de chaînes et de fichiers. Il permet aux développeurs Perl d'intégrer la puissance d'awk directement dans leurs scripts Perl, simplifiant ainsi certaines tâches complexes de manipulation de données.

    OPTIONS

    -d, --debug
    Active le mode débogage pour le script.
    -L
    Désactive le mode de formatage des chaînes (pas de chaînes délimitées par des guillemets).
    -l, --version
    Affiche la version de pm-gawk et quitte.
    -i
    Active le mode interactif.
    -n
    Traite les entrées sans nouvelle ligne.
    -M
    Désactive la mise en mémoire tampon de sortie.
    -p
    Active le mode d'analyse d'expressions régulières POSIX.
    -V
    Affiche les informations de version et quitte.
    -a idx
    Définit la taille de l'index pour les tableaux associatifs.
    -b bufsz
    Définit la taille du tampon d'entrée.
    -c conn
    Définit le type de connexion pour les entrées distantes.
    -e env
    Définit une variable d'environnement pour le script.
    -f file
    Lit le programme awk à partir du fichier spécifié.
    -F fs
    Utilise fs comme séparateur de champ d'entrée.
    -I inc
    Ajoute inc au chemin de recherche des fichiers inclus.
    -j n
    Définit le nombre de threads à utiliser pour le traitement parallèle.
    -k keylen
    Définit la longueur maximale de la clé pour les tableaux associatifs.
    -m max
    Définit la valeur maximale pour les opérations numériques.
    -N msize
    Définit la taille du tas pour les structures de données.
    -o opt
    Définit des options d'optimisation spécifiques.
    -p prec
    Définit la précision pour les nombres à virgule flottante.
    -q qual
    Définit des qualificatifs pour les opérations de fichier.
    -r radix
    Définit la base numérique par défaut pour les conversions.
    -s sep
    Utilise sep comme séparateur de champ de sortie.
    -T tmpdir
    Définit le répertoire pour les fichiers temporaires.
    -v var=val
    Définit une variable awk var avec la valeur val avant l'exécution du script.
    -W warn
    Définit le niveau d'avertissement pour les messages d'erreur.
    --help
    Affiche un message d'aide et quitte.
    --version
    Affiche les informations de version et quitte.
    pattern
    Un motif optionnel à faire correspondre avant d'exécuter le programme.
    program
    Le script awk à exécuter.
    --
    Indique la fin des options. Tout ce qui suit est traité comme des arguments du script.
    arg ...
    Arguments à passer au script awk.

    EXEMPLES

    # Compter le nombre de lignes dans un fichier
pm-gawk '{ count++ } END { print count }' fichier.txt

# Extraire la deuxième colonne d'un fichier CSV
pm-gawk -F',' '{ print $2 }' donnees.csv

# Traiter des données dans un script Perl
use strict;
use warnings;

my $awk_script = q{
  /error/ { errors++ }
  END { print "Nombre d\'erreurs : ", errors }
};

my $file = 'log.txt';
open my $fh, '<', $file or die "Impossible d\'ouvrir $file: $!";

while (my $line = <$fh>) {
    # Utilisation de pm-gawk pour traiter la ligne
    # Note : Cette approche est plus complexe et généralement, on utiliserait plutôt une bibliothèque Perl dédiée.
    # Ceci est une illustration conceptuelle.
    my $result = `echo "$line" | pm-gawk "$awk_script"`;
    print $result;
}
close $fh;

    AUTEURS

    Les auteurs originaux d'awk sont Alfred Aho, Peter Weinberger et Brian Kernighan. GNU awk est développé et maintenu par la communauté GNU. pm-gawk est un wrapper ou une intégration spécifique pour Perl, potentiellement développé par des contributeurs distincts.

    MISES EN GARDE

    L'intégration de pm-gawk dans des scripts Perl peut introduire une complexité supplémentaire. Pour la plupart des tâches de traitement de chaînes et de fichiers en Perl, il est souvent préférable d'utiliser les modules Perl natifs (comme Text::CSV, Mojo::JSON, ou des expressions régulières Perl) qui sont plus intégrés à l'écosystème Perl et plus faciles à maintenir.

    L'utilisation de commandes externes comme montré dans l'exemple peut être moins performante et moins sûre que l'utilisation d'une bibliothèque dédiée si disponible.

    RAPPORTS DE BOGUES

    Veuillez signaler les bogues ou les problèmes à la liste de diffusion appropriée ou au système de suivi des bogues du projet awk ou de l'intégration Perl spécifique que vous utilisez.
