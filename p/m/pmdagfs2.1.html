PMDAGFS2(1) Manuel des commandes générales PMDAGFS2(1)

NOM

pmdagfs2 - PMDA pour Global Filesystem v2 (GFS2)

SYNTAXE

$PCP_PMDAS_DIR/gfs2/pmdagfs2 [-D debug]

DESCRIPTION

pmdagfs2 est un Agent de Domaine de Métriques de Performance (PMDA) qui exporte des valeurs de métriques sur les systèmes de fichiers GFS2 montés depuis le système de fichiers debugfs. Ce PMDA nécessite que debugfs soit monté, ainsi qu'au moins un système de fichiers GFS2 monté, pour pouvoir fournir des données de métriques.

Ce PMDA peut être utilisé avec les systèmes de fichiers GFS2 qui sont montés comme des systèmes de fichiers locaux et comme des systèmes de fichiers montés en stockage partagé dans un environnement en cluster. Cependant, certaines métriques nécessitent spécifiquement que GFS2 soit configuré dans un environnement en cluster pour pouvoir fournir des données de métriques. Ceci est dû au fait qu'elles attendent que les messages de verrouillage soient passés via le gestionnaire de verrouillage distribué (DLM) entre les nœuds d'un cluster afin de générer leur sortie.

Ces métriques spécifiques à l'environnement cluster peuvent être distinguées par l'inclusion de leurs métriques de contrôle correspondantes afin qu'elles puissent être activées ou désactivées à la demande dans les systèmes où elles ne sont pas souhaitées ou prises en charge.

Vous pouvez utiliser pmstore(3) pour assigner des valeurs à ces métriques de contrôle afin de les activer (1) ou de les désactiver (0). Ce mécanisme est également utile sur les distributions qui ne prennent pas entièrement en charge les points de trace GFS2 ou qui fournissent des versions plus anciennes du pilote GFS2.

INSTALLATION

Installez le PMDA GFS2 en utilisant le script Install en tant que root :

# cd $PCP_PMDAS_DIR/gfs2
# ./Install

Pour désinstaller, effectuez les opérations suivantes en tant que root :

# cd $PCP_PMDAS_DIR/gfs2
# ./Remove

pmdagfs2 est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove informent pmcd lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/gfs2/help
fichier d'aide par défaut pour les métriques GFS2
$PCP_PMDAS_DIR/gfs2/Install
script d'installation de l'agent pmdagfs2
$PCP_PMDAS_DIR/gfs2/Remove
script d'annulation d'installation de l'agent pmdagfs2
$PCP_LOG_DIR/pmcd/gfs2.log
fichier journal par défaut pour les messages d'erreur de pmdagfs2

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5). [-D debug]

OPTIONS DEBOGAGE

Les options -D ou --debug activent l'affichage de diagnostics supplémentaires sur stderr pour aider à diagnostiquer les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir la liste des options de débogage disponibles et leur signification.

Les options de débogage spécifiques à pmdagfs2 sont les suivantes :

Option Description
appl0 détails de la récupération et du rafraîchissement de sbstats et worst_glock
