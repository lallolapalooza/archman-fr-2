NOM

pmlogger_merge - script d'aide pour fusionner les archives Performance Co-Pilot

SYNTAXE

$PCP_BINADM_DIR/pmlogger_merge [-fNVE?] [base-nom-entrée ... nom-sortie]

DESCRIPTION

pmlogger_merge est un script d'aide utilisé par pmlogger_daily(1) lors de la fusion de toutes les archives Performance Co-Pilot (PCP) pour un hôte unique sur une seule journée en une archive PCP combinée.

pmlogger_merge est un script enveloppant pour pmlogextract(1) qui fusionne toutes les archives correspondant aux arguments base-nom-entrée et crée une nouvelle archive en utilisant nom-sortie comme nom de base pour les fichiers physiques qui constituent une archive. Les arguments base-nom-entrée peuvent contenir des méta-caractères dans le style de sh(1).

Si certains des fichiers qui sont des composants des archives base-nom-entrée ont été compressés, alors en cas de succès, pmlogger_merge compressera nom-sortie en utilisant pmlogcompress(1).

OPTIONS

Les options de ligne de commande disponibles sont :

-f, --force
Cette option provoque la suppression de tous les fichiers d'entrée une fois que l'archive de sortie a été créée.
-N, --showme
Exécute pmlogger_merge dans un mode « montre-moi » ou « simulation » où les tâches qui seraient effectuées sont rapportées, mais aucune modification n'est effectuée. Ceci est généralement utilisé pour le débogage en combinaison avec une (verbeuse) ou deux (très verbeuses) options -V.
-V, --verbose
Augmente la verbosité dans le rapport de progression de la sortie.
-E, --expunge
Lorsque des différences de métadonnées métriques sont rencontrées entre les archives à fusionner, le comportement par défaut est que pmlogger_merge échoue avec une erreur fatale et l'archive nom-sortie n'est pas créée. Le drapeau -E émet à la place un avertissement et exclut les métriques affectées de l'archive de sortie fusionnée. Ceci est destiné à la rotation quotidienne automatisée des archives où il est très souhaitable que la fusion, la réécriture et la compression quotidiennes sans surveillance réussissent. Voir également pmlogger_daily(1) et l'option -x de pmlogextract(1).
-?, --help
Affiche le message d'utilisation et quitte.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1), pmlogcompress(1), pmlogextract(1), pmlogger(1) et pmlogger_daily(1).
