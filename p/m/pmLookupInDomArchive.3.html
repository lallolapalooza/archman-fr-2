NOM

pmLookupInDomArchive - traduire un nom d'instance en un identifiant d'instance

SYNTAXE

#include <pcp/pmapi.h>

int pmLookupInDomArchive(pmInDom indom, const char *name);

cc ... -lpcp

DESCRIPTION

À condition que le contexte actuel de l'interface de programmation d'application des métriques de performance (PMAPI) soit associé à un ensemble d'archives, pmLookupInDomArchive parcourra l'union de toutes les métadonnées de domaines d'instance pour le domaine d'instance indom, localisera la première instance avec l'identification externe donnée par name, et retournera l'identifiant d'instance interne.

Cette routine est une version spécialisée de la routine PMAPI plus générale pmLookupInDom.

Seuls les caractères non blancs de début de name seront utilisés pour identifier l'instance.

La valeur pour le domaine d'instance indom est généralement extraite d'une structure pmDesc, suite à un appel à pmLookupDesc(3) pour une métrique de performance particulière.

pmLookupInDomArchive retournera un identifiant d'instance positif en cas de succès.

DIAGNOSTICS

PM_ERR_NOTARCHIVE
le contexte PMAPI actuel n'est pas associé à un ensemble d'archives
PM_ERR_INDOM_LOG
indom n'est pas un identifiant de domaine d'instance défini pour l'ensemble d'archives
PM_ERR_INST_LOG
l'instance externe name n'est pas connue pour le domaine d'instance indom dans l'ensemble d'archives

VOIR AUSSI

PMAPI(3), pmGetConfig(3), pmGetInDomArchive(3), pmLookupDesc(3), pmLookupInDom(3), pmNameInDomArchive(3), pcp.conf(5) et pcp.env(5).
