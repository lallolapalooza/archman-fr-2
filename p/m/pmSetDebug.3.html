PMSETDEBUG(3) Manuel des fonctions de bibliothèque PMSETDEBUG(3)

NOM

pmSetDebug, pmDebug, pmGetDebug, pmClearDebug - manipuler les options de contrôle de débogage PCP

SYNTAXE

#include <pcp/pmapi.h>

int pmSetDebug(const char *spec);
int pmDebug(const char *spec);
char *pmGetDebug(void);
int pmClearDebug(const char *spec);

cc ... -lpcp

DESCRIPTION

Dans les bibliothèques et applications du Performance Co-Pilot (PCP), il existe un ensemble complet d'options de débogage qui peuvent être activées ou désactivées à l'exécution.

pmSetDebug, pmDebug et pmClearDebug analysent tous spec en supposant qu'il s'agit d'une liste d'options de débogage PCP séparées par des virgules.

Les noms des options disponibles peuvent être trouvés en utilisant l'argument -l de pmdbg(1).

Comme cas spécial, le nom « all » est traité comme un synonyme pour identifier tous les noms d'options.

pmSetDebug définit les options correspondantes, tandis que pmClearDebug efface les options correspondantes.

pmDebug est utilisé pour tester si les options ont été définies et renvoie 1 si au moins une des options de spec a été définie, sinon il renvoie 0.

Les appels consécutifs à pmSetDebug ou pmClearDebug seront additifs. Par exemple, les fragments de code suivants sont équivalents en termes d'état final des options de débogage.

sts = pmClearDebug("all");
sts = pmSetDebug("appl0");
sts = pmSetDebug("pdu,fetch");
sts = pmSetDebug("fetch,profile,context");
sts = pmClearDebug("appl0");

sts = pmClearDebug("all");
sts = pmSetDebug("pdu,fetch,profile,context");

Pour les applications qui utilisent pmGetOptions(3) pour traiter les options et arguments de la ligne de commande, la définition de la variable d'environnement $PCP_DEBUG offre un mécanisme alternatif pour définir les indicateurs de débogage, comme décrit dans PCPIntro(1).

pmGetDebug renvoie l'ensemble actuel des options de débogage activées sous la forme d'une liste séparée par des virgules. Si aucune option n'est définie, le résultat est une chaîne vide. Si toutes les options sont définies, le résultat est « all ». Le résultat est alloué par malloc(3) et il incombe à l'appelant d'appeler free(3) lorsque le résultat n'est plus nécessaire.

DIAGNOSTICS

En cas de succès, les routines pmSetDebug, pmDebug et pmClearDebug renvoient 0 ou 1, sinon la valeur de retour est PM_ERR_CONV pour indiquer une erreur lors de l'analyse de spec.

Pour pmGetDebug, une valeur de retour de NULL indique un échec de malloc(3).

VOIR AUSSI

PCPIntro(1), pmdbg(1), free(3) et malloc(3).
