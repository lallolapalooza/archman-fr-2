PMHTTPNEWCLIENT(3) Manuel des fonctions de bibliothèque PMHTTPNEWCLIENT(3)

NOM

pmhttpNewClient, pmhttpFreeClient, pmhttpClientFetch - Interfaces simples de client HTTP

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/pmhttp.h>

struct http_client *pmhttpNewClient(void);
void pmhttpFreeClient(struct http_client *client);
int pmhttpClientFetch(struct http_client *client,
const char *url, char *bodybuf, size_t bodylen, char *typebuf, size_t typelen);

cc ... -lpcp_web

DESCRIPTION

pmhttpNewClient alloue et initialise un client HTTP opaque prêt à effectuer des requêtes à un serveur.

L'interface de requête d'URL pmhttpClientFetch émet une requête HTTP GET vers le serveur spécifié dans l'URL fournie. Le corps de la réponse est retourné dans le tampon bodybuf fourni par l'appelant, d'une longueur de bodylen octets. Un tampon optionnel typebuf, d'une longueur de typelen octets, peut également être fourni et (s'il n'est pas NULL) contiendra la valeur de l'en-tête content-type renvoyé par le serveur.

Le paramètre url est une URL au format RFC1630. Il sera généralement préfixé par "http://", cependant ces interfaces prennent également en charge les sockets de domaine Unix. Ceux-ci sont préfixés par "unix://", suivi du chemin complet du système de fichiers vers le socket de domaine Unix désiré.

Pour libérer les ressources associées à un client HTTP, y compris la fermeture de toute connexion serveur persistante qui a été établie précédemment, on utilise la routine pmhttpFreeClient.

DIAGNOSTICS

pmhttpNewClient retournera NULL en cas d'échec, ce qui ne peut se produire que lorsque l'allocation de mémoire n'est pas possible.

pmhttpClientFetch retournera le nombre d'octets placés dans le tampon bodybuf, sinon un code d'erreur négatif indiquant la nature de l'échec.

VOIR AUSSI

pmdaapache(1), pmjsonInit(3), PMAPI(3), PMWEBAPI(3) et https://tools.ietf.org/html/rfc1630.
