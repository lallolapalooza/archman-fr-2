PMPATHSEPARATOR(3) Manuel des fonctions de bibliothèque PMPATHSEPARATOR(3)

NOM

pmPathSeparator - renvoie le caractère séparateur de chemin du système de fichiers

C SYNTAXE

#include <pcp/pmapi.h>

int pmPathSeparator(void);

cc ... -lpcp

DESCRIPTION

pmPathSeparator est une méthode pratique qui renvoie « / » dans le monde civilisé. Pour les plateformes Windows, vous pouvez obtenir « / » ou « \ » en fonction de l'environnement d'exécution.

Le scénario d'utilisation le plus courant consiste à utiliser pmPathSeparator pour construire le chemin complet d'un fichier à partir d'un nom de répertoire connu et d'un nom de fichier relatif.
