NOM

pmaSortInDom - trier un domaine d'instance

C SYNTAXE

#include <pcp/pmapi.h>
#include <pcp/libpcp.h>
#include <pcp/archive.h>

void pmaSortInDom(__pmLogInDom *lidp);

cc ... -lpcp_archive -lpcp

AVERTISSEMENT

Cette documentation est destinée à un usage interne par les développeurs de Performance Co-Pilot (PCP).

Ces interfaces ne font pas partie des API PCP qui sont garanties de rester fixes entre les versions, et elles peuvent ne pas fonctionner, ou fournir une sémantique différente à un moment donné dans le futur.

DESCRIPTION

Le domaine d'instance identifié par lidp est trié par ordre croissant de sa valeur d'identifiant d'instance interne. Le tableau lidp->instlist[] et le tableau correspondant lidp->namelist[] sont triés.

Étant donné que les domaines d'instance sont généralement triés (à leur source par un PMDA), un tri à bulles est utilisé. Cela signifie que si l'appelant n'est pas sûr si le domaine d'instance est trié (mais qu'il l'est déjà), alors appeler pmaSortInDom est aussi rapide que de vérifier si le domaine d'instance est trié, donc en cas de doute, appelez simplement pmaSortInDom.

DIAGNOSTICS ET VALEURS DE RETOUR

Aucun.

VOIR AUSSI

PMAPI(3) et pmGetInDom(3).
