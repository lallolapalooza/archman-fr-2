PMDAIB(1) Manuel des commandes générales PMDAIB(1)

NOM

pmdaib - agent de domaine de métriques de performance Infiniband (PMDA)

SYNTAXE

$PCP_PMDAS_DIR/infiniband/pmdaib [-c fichierConfig] [-D debug] [-d domaine] [-l fichierLog] [-w]

DESCRIPTION

pmdaib est un agent de domaine de métriques de performance (PMDA) qui exporte des informations et des métriques de performance sur les HCA Infiniband locaux et les GUIDs Infiniband locaux ou distants.

Une brève description des options de ligne de commande de pmdaib suit :

-c
Emplacement du fichier de configuration. Par défaut, le fichier de configuration s'appelle $PCP_PMDAS_DIR/infiniband/config. Voir FICHIER DE CONFIGURATION pour plus d'informations.
-d
Spécifier un numéro de domaine de métriques de performance alternatif. Presque jamais nécessaire.
-l
Emplacement du fichier journal. Par défaut, un fichier journal nommé ib.log est écrit dans $PCP_LOG_DIR/pmcd. Si le fichier journal ne peut pas être créé ou n'est pas accessible en écriture, la sortie est écrite sur la sortie standard d'erreur.
-w
Écrit le fichier de configuration par défaut dans $PCP_PMDAS_DIR/infiniband et sort immédiatement. Le fichier de configuration écrit contiendra les ports HCA locaux. Il n'écrasera pas un fichier existant. Cet argument ne doit être utilisé que pour créer le fichier de configuration modèle et ne doit jamais apparaître dans pmcd.conf. Voir FICHIER DE CONFIGURATION pour plus d'informations sur le format du fichier et sur la surveillance des GUIDs distants.

FICHIER DE CONFIGURATION

Par défaut, le PMDA fonctionnera sans utiliser de fichier de configuration. Dans ce mode de fonctionnement, les ports HCA locaux seront surveillés. Notez que si un nouveau HCA est ajouté à la machine, la nommage des instances peut changer car il sera toujours basé sur le nommage du noyau.

Dans les cas où cela n'est pas acceptable, ou dans le cas où la surveillance des ports Infiniband distants est requise, un fichier de configuration doit être créé. Un fichier « modèle » peut être créé en exécutant le démon pmdaib avec l'argument -w. Cela créera un fichier de configuration avec les ports et les GUIDs locaux.

Si le fichier de configuration est exécutable, alors il sera exécuté et la sortie sera utilisée comme fichier de configuration.

Le fichier de configuration est composé d'enregistrements basés sur des lignes. Les lignes vides et tout ce qui suit le caractère dièse (#) sont ignorés. Chaque ligne a 6 champs :

[nomInst] [GUIDPort] [numPort] via [nomPortLocal]:[numPortLocal]

Le premier champ est utilisé pour donner un nom d'instance statique au port Infiniband qui a un GUID spécifique. Tous les autres champs doivent être correctement spécifiés afin de surveiller un port particulier.

Par exemple, pour surveiller le port 1 du HCA local nommé 'mthca0', une ligne de fichier de configuration possible serait :

monPort1 0xdeadbeef01234567 1 via mthca0:1

Les ports distants peuvent être facilement surveillés en spécifiant le GUID du HCA ou du switch et en spécifiant le numéro de port distant. Le tuple nomPortLocal:numPortLocal spécifie quel HCA et quel port local utiliser comme « premier saut » pour contacter le GUID distant. Par ex., pour surveiller le port 13 d'un switch distant qui est connecté au tissu sur le premier port du deuxième HCA :

switch13 0xfeeffeefabcdabcd 13 via mthca1:1

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à diagnostiquer les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à fournir des conseils aux développeurs plutôt qu'aux utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et de leur signification.

VOIR AUSSI

PCPIntro(1), pmcd(1), PMAPI(3) et ibnetdiscover(8).
