PMDABPFTRACE(1) Manuel des commandes générales PMDABPFTRACE(1)

NOM

pmdabpftrace - PMDA bpftrace

DESCRIPTION

pmdabpftrace est un agent de domaine de métriques de performance (PMDA) de Performance Co-Pilot (PCP) qui exporte les métriques des scripts bpftrace(8).

CONFIGURATION

pmdabpftrace lit un fichier de configuration optionnel de style ini :

$PCP_PMDAS_DIR/bpftrace/bpftrace.conf

Ce fichier peut contenir des sections [bpftrace] et [dynamic_scripts]. Si vous activez la fonctionnalité de scripts dynamiques, veuillez consulter https://pcp.io/docs/lab.auth.html pour savoir comment configurer l'authentification. Ceci est fortement recommandé, car sinon n'importe qui pourrait exécuter n'importe quel script bpftrace(8) en tant que root.

La section [bpftrace] spécifie les valeurs pour les paramètres suivants (leurs valeurs par défaut sont indiquées entre parenthèses) :

bpftrace_path (bpftrace)
Chemin d'accès à l'exécutable bpftrace(8).
script_expiry_time (60)
Les scripts sans nom sont supprimés après cette période (en secondes) s'il n'y a plus eu de requêtes pour leurs valeurs.
max_throughput (2097152)
Débit maximal des scripts bpftrace en octets.

La section [dynamic_scripts] spécifie les valeurs pour les paramètres suivants (leurs valeurs par défaut sont indiquées entre parenthèses) :

enabled (false)
Une valeur booléenne pour spécifier si un script doit être démarré à la demande, en exécutant pmStore (3) bpftrace.control.register. Cette fonctionnalité doit être activée pour la source de données PCP bpftrace dans grafana-pcp.
auth_enabled (true)
Une valeur booléenne pour spécifier si l'authentification est requise ou non. Veuillez consulter la note ci-dessus sur la configuration de l'authentification.
allowed_users (root)
Une liste d'utilisateurs séparés par des virgules qui sont autorisés à enregistrer des scripts bpftrace(8).

INSTALLATION

Pour installer, les opérations suivantes doivent être effectuées en tant que root :

# cd $PCP_PMDAS_DIR/bpftrace
# ./Install

Pour désinstaller, les opérations suivantes doivent être effectuées en tant que root :

# cd $PCP_PMDAS_DIR/bpftrace
# ./Remove

pmdabpftrace est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lors de l'installation ou de la suppression de l'agent.

FICHIERS

$PCP_PMDAS_DIR/bpftrace/bpftrace.conf
fichier de configuration pour l'agent pmdabpftrace
$PCP_PMDAS_DIR/bpftrace/Install
script d'installation pour l'agent pmdabpftrace
$PCP_PMDAS_DIR/bpftrace/Remove
script d'annulation d'installation pour l'agent pmdabpftrace
$PCP_LOG_DIR/pmcd/bpftrace.log
fichier journal par défaut pour les messages de l'agent pmdabpftrace

Notez que la valeur habituelle/par défaut pour $PCP_PMDAS_DIR est /var/lib/pcp/pmdas et la valeur par défaut pour $PCP_LOG_DIR est /var/log/pcp, mais ces paramètres dépendent de la plateforme.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1), pmcd(1) et bpftrace(8).
