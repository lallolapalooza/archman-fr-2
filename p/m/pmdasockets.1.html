PMDASOCKETS(1) Manuel des commandes générales PMDASOCKETS(1)

NOM

pmdasockets - PMDA de statistiques des sockets

SYNTAXE

$PCP_PMDAS_DIR/sockets/pmdasockets [-D debug]

DESCRIPTION

pmdasockets est un Agent de Domaine de Métriques de Performance (PMDA) qui exporte les valeurs des métriques pour les sockets actuels sur le système local.

Ce PMDA collecte actuellement ses données via l'utilitaire ss(8) et nécessite que le programme soit installé pour fonctionner. Cette dépendance pourrait changer à l'avenir.

INSTALLATION

Pour installer (activer) le PMDA sockets, faites ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/sockets
# ./Install

Pour désinstaller (désactiver), faites ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/sockets
# ./Remove

pmdasockets est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

CONFIGURATION DU FILTRE

La métrique de type chaîne de caractères network.persocket.filter spécifie le filtre ss(1) à appliquer pour sélectionner optionnellement les états des sockets, les adresses IP et d'autres options que pmdasockets collectera (pour peupler son domaine d'instance). Ceci est chargé au démarrage du PMDA à partir du fichier $(PCP_SYSCONF_DIR)/sockets/filter.conf (typiquement /etc/pcp/sockets/filter.conf) et par défaut state connected, ce qui signifie que seuls les sockets dans l'état connected seront inclus. Cela peut être changé de manière persistante en éditant filter.conf en tant qu'utilisateur root. Le filtre peut également être modifié dynamiquement après le démarrage du PMDA en utilisant pmstore(1) pour stocker une nouvelle chaîne de filtre dans la métrique network.persocket.filter. Par exemple : 

# pmstore network.persocket.filter "state all"

changera le filtre pour inclure les sockets dans tous les états. Notez qu'un filtre stocké dynamiquement n'est pas persistant après redémarrages du PMDA ou redémarrages du système (éditez le fichier de configuration pour un changement persistant). Pour plus de détails sur la syntaxe et les options du filtre, consultez ss(8).

CONFIGURATION DE LA JOURNALISATION

Le fichier de configuration pmlogconf(1) pour pmdasockets est $PCP_VAR_DIR/config/pmlogconf/networking/persocket-linux (où $PCP_VAR_DIR est typiquement /var/lib/pcp) qui spécifie d'enregistrer toutes les métriques sous network.persocket dans l'espace de noms PCP avec un intervalle d'échantillonnage par défaut de 60 secondes. L'intervalle de journalisation et les métriques à journaliser peuvent être modifiés en éditant ce fichier puis en redémarrant le service pmlogger. Pour les détails de la syntaxe, voir pmlogconf(1).

MÉTRIQUES

Les métriques et métadonnées supportées par pmdasockets correspondent aux champs rapportés par ss -noemitauOH et sont également disponibles sous forme de texte d'aide fourni par le PMDA, par exemple, pour lister toutes les métriques, descripteurs de métadonnées et texte d'aide : 

# pminfo -fmdtT network.persocket

Notez que le PMDA doit être installé (activé) pour que cette commande fonctionne correctement, voir ci-dessus.

ENVIRONNEMENT PCP

Les variables d'environnement commençant par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. À chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à résoudre les problèmes, bien que les informations soient parfois cryptiques et destinées principalement aux développeurs plutôt qu'aux utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

Les options de débogage spécifiques à pmdasockets sont les suivantes :

Option Description
appl0 chargement du filtre d'état du socket depuis $PCP_SYSCONF_DIR/filter.conf et source des données
appl1 analyse de la sortie de la source de données

VOIR AUSSI

PCPIntro(1), pmcd(1), pmlogger(1) et ss(8).
