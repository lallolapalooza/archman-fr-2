PMCONVSCALE(3) Manuel des fonctions de bibliothèque PMCONVSCALE(3)

NOM

pmConvScale - redimensionner la valeur d'une métrique de performance

SYNTAXE EN C

#include <pcp/pmapi.h>

int pmConvScale(int type,
const pmAtomValue *ival, const pmUnits *iunit, pmAtomValue *oval, const pmUnits *ounit);

cc ... -lpcp

DESCRIPTION

Toutes les valeurs de métriques de performance peuvent être encodées dans une union pmAtomValue, définie comme suit :

typedef union {
    __int32_t    l;     /* 32 bits signé */
    __uint32_t   ul;    /* 32 bits non signé */
    __int64_t    ll;    /* 64 bits signé */
    __uint64_t   ull;   /* 64 bits non signé */
    float        f;     /* 32 bits flottant */
    double       d;     /* 64 bits flottant */
    char         *cp;   /* pointeur char */
    pmValueBlock *vbp;  /* pointeur pmValueBlock */
} pmAtomValue;

L'encodage de la dimensionnalité et de l'échelle d'une métrique de performance utilise une structure pmUnits ; voir pmLookupDesc(3).

Étant donné une valeur de métrique de performance pointée par ival, multipliez-la par un facteur d'échelle et renvoyez la valeur dans oval. La mise à l'échelle s'effectue depuis les unités définies par iunit vers les unités définies par ounit. Les unités d'entrée et de sortie doivent avoir la même dimensionnalité.

Le type de métrique de performance pour les valeurs d'entrée et de sortie est déterminé par type, dont la valeur est généralement extraite d'une structure pmDesc, suite à un appel à pmLookupDesc(3) pour une métrique de performance particulière.

pmConvScale est plus utile lorsque les valeurs renvoyées via pmFetch(3) (et éventuellement extraites en utilisant pmExtractValue(3)) doivent être normalisées dans une échelle et des unités canoniques à des fins de calcul.

À titre de cas spécial, si tous les composants de la dimension sont nuls, cela est traité comme synonyme d'une dimension de ``compte'' de un, et donc les composants d'échelle de ``compte'' déterminent le redimensionnement relatif. Ceci permet de gérer le cas où les métriques de performance sont sans dimension, sans traitement spécial de la part de l'appelant.

DIAGNOSTICS

PM_ERR_CONV

iunit et ounit ont des dimensionnalités différentes, ou ont un type inapproprié

PM_ERR_UNIT

Paramètre iunit ou ounit inapproprié

VOIR AUSSI

PMAPI(3), pmAtomStr(3), pmExtractValue(3), pmFetch(3), pmLookupDesc(3), pmPrintValue(3), pmTypeStr(3) et pmUnitsStr(3).
