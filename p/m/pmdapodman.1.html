PMDAPODMAN(1) Manuel des commandes générales PMDAPODMAN(1)

NOM

pmdapodman - agent de domaine de métriques de performance des conteneurs podman (PMDA)

SYNTAXE

$PCP_PMDAS_DIR/podman/pmdapodman [-D debug] [-d domaine] [-l logfile]

DESCRIPTION

podman(1) est un utilitaire pour gérer les pods, les conteneurs et les images de conteneurs, suivant le concept de pod de conteneurs popularisé par Kubernetes. pmdapodman est un agent de domaine de métriques de performance (PMDA) qui extrait les métriques de performance décrivant l'état des conteneurs et des pods gérés par podman.

Le PMDA podman exporte des métriques qui mesurent des informations sur les conteneurs individuels et les groupes de conteneurs, appelés pods.

Une brève description des options de ligne de commande de pmdapodman suit :

-d
Il est absolument crucial que le numéro de domaine des métriques de performance spécifié ici soit unique et cohérent. C'est-à-dire que le domaine doit être différent pour chaque PMDA sur un hôte donné, et le même numéro de domaine doit être utilisé pour le même PMDA sur tous les hôtes.
-l
Emplacement du fichier journal. Par défaut, un fichier journal nommé podman.log est écrit dans le répertoire courant de pmcd(1) lorsque pmdapodman est démarré, c'est-à-dire $PCP_LOG_DIR/pmcd. Si le fichier journal ne peut être créé ou n'est pas accessible en écriture, la sortie est redirigée vers la sortie d'erreur standard.

INSTALLATION

Le PMDA podman est installé et disponible par défaut sous Linux. Si vous souhaitez annuler l'installation, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/podman
# ./Remove

Si vous souhaitez rétablir l'accès aux noms, aux textes d'aide et aux valeurs des métriques de performance podman, après la suppression, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/podman
# ./Install

pmdapodman est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMCDCONF_PATH
options de ligne de commande utilisées pour lancer pmdapodman
$PCP_PMDAS_DIR/podman/help
fichier d'aide par défaut pour les métriques podman
$PCP_PMDAS_DIR/podman/Install
script d'installation pour l'agent pmdapodman
$PCP_PMDAS_DIR/podman/Remove
script d'annulation d'installation pour l'agent pmdapodman
$PCP_LOG_DIR/pmcd/podman.log
fichier journal par défaut pour les messages d'erreur et autres informations de pmdapodman

ENVIRONNEMENT PCP

Les variables d'environnement commençant par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à diagnostiquer les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

VOIR AUSSI

PCPIntro(1), pmcd(1), podman(1), pcp.conf(5) et pcp.env(5).
