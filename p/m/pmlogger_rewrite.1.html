NOM

pmlogger_rewrite - script d'aide pour réécrire les archives Performance Co-Pilot

SYNTAXE

$PCP_BINADM_DIR/pmlogger_rewrite [-dNsVvw?] [-c configuration] archive ...

DESCRIPTION

pmlogger_rewrite est un script d'aide utilisé par pmlogger_daily(1) lors de la réécriture des archives Performance Co-Pilot (PCP). La réécriture est généralement nécessaire pour s'adapter aux changements évolutifs des métadonnées afin que les anciennes archives puissent être mises à jour puis fusionnées avec les archives actuelles.

pmlogger_rewrite est un script d'encapsulation pour pmlogrewrite(1) qui réécrit potentiellement toutes les archives correspondant aux arguments archive. Chaque argument archive peut être un nom de fichier d'archive PCP, le nom de base des fichiers dans une archive PCP, ou un répertoire (auquel cas toutes les archives PCP subordonnées sont trouvées par descente récursive).

pmlogrewrite est exécuté avec l'option -i afin que la réécriture se fasse « sur place ». L'option -q est également utilisée, de sorte que si aucune réécriture n'est nécessaire, aucune modification n'est apportée aux fichiers d'archives.

OPTIONS

Les options suivantes sont transmises à pmlogrewrite : -c (ou --config), -d (ou --desperate), -s (ou --scale), -v (ou --verbose) et -w (ou --warnings). Référez-vous à pmlogrewrite(1) pour la signification de ces options.

Les options restantes sont :

-N, --showme
Exécute pmlogger_rewrite en mode « montre-moi » ou « essai à blanc » où les tâches qui seraient effectuées sont signalées, mais aucune modification n'est apportée. Ceci est généralement utilisé pour le débogage en combinaison avec une (verbeuse) ou deux (très verbeuses) options -V.
-V, --verbose
Augmente la verbosité de la sortie du script.
-?, --help
Affiche le message d'utilisation et quitte.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1), pmlogger(1), pmlogger_daily(1) et pmlogrewrite(1).
