PMDADAEMON(3) Manuel des fonctions de bibliothèque PMDADAEMON(3)

NOM

pmdaDaemon - initialise le PMDA pour qu'il s'exécute en tant que démon

SYNTAXE EN C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

void pmdaDaemon(pmdaInterface *dispatch,
int interface, const char *name, int domain, const char *logfile, const char *helptext);

cc ... -lpcp_pmda -lpcp

DESCRIPTION

pmdaDaemon initialise la structure pmdaInterface pour utiliser les extensions interface en supposant que le PMDA(3) doit s'exécuter en tant que démon. La structure pmdaInterface est initialisée avec :

name
Le nom de l'agent.
domain
Le numéro de domaine par défaut de l'agent, qui identifie de manière unique ce PMDA parmi les autres PMDA en cours d'exécution. Ceci peut être modifié ultérieurement par une option de ligne de commande -d (voir pmdaGetOpt(3)).
logfile
Le chemin par défaut du fichier journal. Ceci peut être remplacé par l'option de ligne de commande -l si vous utilisez pmdaGetOpt. logfile sera copié avec strdup(3), donc la mémoire associée à logfile peut être libérée après l'appel à pmdaDaemon.
helptext
Le chemin par défaut du texte d'aide (voir pmdaText(3). Ceci peut être remplacé par l'option de ligne de commande -h si vous utilisez pmdaGetOpt(3). Si aucun texte d'aide n'est installé, ou si vous n'utilisez pas pmdaText(3), alors ceci doit être défini à NULL, sinon helptext sera copié avec strdup(3), donc la mémoire associée à helptext peut être libérée après l'appel à pmdaDaemon.

Les rappels sont initialisés à pmdaProfile(3), pmdaFetch(3), pmdaDesc(3), pmdaText(3), pmdaInstance(3) et pmdaStore(3).

CAVEAT

Le PMDA doit utiliser PMDA_INTERFACE_2 ou une version ultérieure.

Une fois que pmdaDaemon a été appelé, il est attendu que la structure pmdaInterface pointée par dispatch reste accessible aux routines de libpcp_pmda (pas récupérée de la pile, pas libérée ou autrement rendue indisponible, etc.). Si l'appelant a besoin de déplacer ou de relocaliser la structure pmdaInterface pour une raison quelconque, alors après le déplacement, pmdaInterfaceMoved(3) doit être appelé pour rétablir l'intégrité interne de la structure pmdaInterface à la nouvelle position avant que toute autre routine de libpcp_pmda ne soit appelée.

DIAGNOSTICS

Impossible d'allouer de la mémoire pour la structure pmdaExt
De plus, le champ dispatch->status est défini à une valeur inférieure à zéro.
Version de l'interface PMDA interface non prise en charge
La version interface n'est pas prise en charge par pmdaDaemon.

VOIR AUSSI

PMAPI(3), PMDA(3), pmdaDSO(3), pmdaGetOpt(3), pmdaInterfaceMoved(3) et pmdaText(3).
