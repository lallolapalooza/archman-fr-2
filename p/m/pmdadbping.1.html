PMDADBPING(1) Manuel des commandes générales PMDADBPING(1)

NOM

pmdadbping - PMDA de mesure du temps de réponse et de disponibilité de la base de données

DESCRIPTION

pmdadbping est un PMDA de mesure du temps de réponse des bases de données.

pmdadbping exécute dbprobe(1) et exporte les mesures de performance qu'il réalise sous forme de métriques PCP.

dbprobe(1) doit être configuré pour utiliser le type de DBI approprié pour la base de données locale, incluant : le type de SGBDR, l'utilisateur/mot de passe, le délai entre les requêtes de "ping", et l'instruction SQL à utiliser.

INSTALLATION

Configurez dbprobe(1) - il utilise un fichier de configuration à partir de (dans cet ordre) :

  • /etc/pcpdbi.conf
  • $PCP_PMDAS_DIR/dbping/dbprobe.conf

Ce fichier peut contenir des valeurs remplacées (code Perl) pour les paramètres listés au début de dbprobe.pl, à savoir :

  • nom de la base de données (voir DBI(3) pour les détails)
  • nom d'utilisateur de la base de données
  • mot de passe de la base de données
  • instruction SQL à mesurer (sonder)
  • délai entre les sondes

Une fois cela configuré, vous pouvez accéder aux noms et valeurs des métriques de performance dbping en faisant ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/dbping
# ./Install

Pour désinstaller, les actions suivantes doivent être effectuées en tant que root :

# cd $PCP_PMDAS_DIR/dbping
# ./Remove

pmdadbping est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove informent pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/dbping/dbprobe.conf
fichier de configuration de sonde pour dbprobe(1), utilisé indirectement par pmdadbping
$PCP_PMDAS_DIR/dbping/Install
script d'installation pour l'agent pmdadbping
$PCP_PMDAS_DIR/dbping/Remove
script de désinstallation pour l'agent pmdadbping
$PCP_LOG_DIR/pmcd/dbping.log
fichier journal par défaut pour les messages d'erreur de pmdadbping

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1), pmcd(1), dbprobe(1) et DBI(3).
