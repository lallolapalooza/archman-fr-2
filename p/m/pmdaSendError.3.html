PMDASENDERROR(3) Manuel des fonctions de bibliothèque PMDASENDERROR(3)

NOM

pmdaSendError - envoyer une PDU d'erreur à PMCD

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

void pmdaSendError(pmdaInterface *dispatch, int err);

cc ... -lpcp_pmda -lpcp

SYNTAXE PYTHON

from pcp.pmda import PMDA
PMDA.pmda_notready()
PMDA.pmda_ready()

DESCRIPTION

Dans le cadre de l'API du domaine d'agents de métriques de performance (PMDA) (voir PMDA(3)), cette routine permet à un PMDA d'envoyer une PDU d'erreur à PMCD. Il n'y a actuellement qu'une seule utilisation pour cela : pour que le PMDA puisse informer PMCD qu'il est prêt (ou non prêt) à traiter les requêtes.

Les détails du protocole sont décrits dans pmcd(1) et PMDA(3), mais fondamentalement si un PMDA démarre dans l'état notready (comme spécifié dans pmcd.conf, voir pmcd(1)), alors PMCD ne lui enverra aucune requête jusqu'à ce que le PMDA envoie une PDU d'erreur PM_ERR_PMDAREADY en utilisant cette fonction. Ceci est utilisé par un PMDA qui peut avoir un long temps de démarrage, par exemple pour traiter un fichier de configuration volumineux ou similaire.

VOIR AUSSI

PMAPI(3), PMDA(3), pmcd(1), et pmdaopenmetrics(1).
