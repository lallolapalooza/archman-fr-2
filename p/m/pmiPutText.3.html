PMIPUTTEXT(3) Manuel des fonctions de bibliothèque PMIPUTTEXT(3)

NOM

pmiPutText - ajouter du texte d'aide pour un domaine de métrique ou d'instance

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiPutText(unsigned int type,
unsigned int class, unsigned int id, const char *content);

cc ... -lpcp_import -lpcp

SYNTAXE PERL

use PCP::LogImport;

pmiPutText($type, $class, $id, $content);

DESCRIPTION

Dans le cadre de l'API d'importation de journaux de Performance Co-Pilot (voir LOGIMPORT(3)), pmiPutText ajoute du texte d'aide pour un domaine de métrique ou d'instance donné.

Le type doit être l'une des valeurs PM_TEXT_PMID ou PM_TEXT_INDOM.

La class doit être l'une des valeurs PM_TEXT_ONELINE ou PM_TEXT_HELP.

Si type est PM_TEXT_PMID, alors id doit correspondre à un pmid défini précédemment dans un appel à pmiAddMetric(3). Si type est PM_TEXT_INDOM, alors id doit correspondre à un domaine d'instance défini précédemment dans un appel à pmiAddMetric(3).

content est une chaîne de caractères contenant le contenu du texte d'aide.

Aucune donnée ne sera écrite avant que pmiWrite(3) ne soit appelé. Ainsi, plusieurs appels à pmiPutText sont généralement utilisés pour accumuler le texte d'aide pour plusieurs métriques ou domaines d'instances avant d'appeler pmiWrite(3).

DIAGNOSTICS

pmiPutText renvoie zéro en cas de succès, sinon une valeur négative qui peut être transformée en message d'erreur en appelant pmiErrStr(3).

VOIR AUSSI

LOGIMPORT(3), pmiAddInstance(3), pmiAddMetric(3), pmiErrStr(3), pmiPutResult(3), pmiPutValue(3), pmiPutValueHandle(3), pmiPutLabel(3) et pmiWrite(3).
