NOM

pmdagpfs - agent de domaine de métriques de performance pour les statistiques du système de fichiers gpfs (PMDA)

DESCRIPTION

pmdagpfs est un agent de domaine de métriques de performance (PMDA) qui exporte les valeurs de métriques du programme /usr/lpp/mmfs/bin/mmpmon pour fournir des informations sur les systèmes de fichiers gpfs montés.

INSTALLATION

Installez le PMDA gpfs en utilisant le script d'installation en tant que root :

# cd $PCP_PMDAS_DIR/gpfs
# ./Install

Pour désinstaller, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/gpfs
# ./Remove

pmdagpfs est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove informent pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/gpfs/Install
script d'installation de l'agent pmdagpfs
$PCP_PMDAS_DIR/gpfs/Remove
script d'annulation de l'installation de l'agent pmdagpfs
$PCP_LOG_DIR/pmcd/gpfs.log
fichier journal par défaut pour les messages d'erreur de pmdagpfs

ENVIRONNEMENT PCP

Les variables d'environnement préfixées par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI
