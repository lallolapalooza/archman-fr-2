PMIWRITE(3) Manuel des fonctions de bibliothèque PMIWRITE(3)

NOM

pmiWrite - vider les données vers une archive LOGIMPORT

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiWrite(int sec, int usec);

cc ... -lpcp_import -lpcp

SYNTAXE PERL

use PCP::LogImport;

pmiWrite($sec, $usec);

DESCRIPTION

Dans le cadre de l'API d'importation de journaux de Performance Co-Pilot (voir LOGIMPORT(3)), pmiWrite force les valeurs de données accumulées à être écrites dans l'archive PCP.

Les valeurs des données et les métadonnées associées ont été précédemment construites à l'aide des appels à pmiAddMetric(3), pmiAddInstance(3), pmiPutValue(3) et pmiPutValueHandle(3).

L'ensemble actuel des valeurs de données et toute nouvelle métadonnée est écrit dans l'archive avec une horodatage de sec et usec dans le fuseau horaire source de l'archive, voir pmiSetTimezone(3).

DIAGNOSTICS

pmiWrite retourne zéro en cas de succès, sinon une valeur négative qui peut être transformée en message d'erreur en appelant pmiErrStr(3).

VOIR AUSSI

LOGIMPORT(3), pmiAddInstance(3), pmiAddMetric(3), pmiErrStr(3), pmiPutValue(3), pmiPutValueHandle(3), pmiPutText(3), pmiPutLabel(3) et pmiSetTimezone(3).
