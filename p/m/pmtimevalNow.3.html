PMTIMEVALNOW(3) Manuel des fonctions de bibliothèque PMTIMEVALNOW(3)

NOM

pmtimevalNow, pmtimevalInc, pmtimevalDec, pmtimevalAdd, pmtimevalSub, pmtimevalToReal, pmtimevalFromReal, pmtimevalTotimespec, pmtimevalPrint - routines d'aide pour le temps stocké sous forme de struct timeval

C SYNTAXE

#include <pcp/pmapi.h>

void pmtimevalNow(struct timeval *tv);
void pmtimevalInc(struct timeval *ap, const struct timeval *bp);
void pmtimevalDec(struct timeval *ap, const struct timeval *bp);
double pmtimevalAdd(const struct timeval *ap,
const struct timeval *bp);

double pmtimevalSub(const struct timeval *ap,
const struct timeval *bp);

double pmtimevalToReal(const struct timeval *val);
void pmtimevalFromReal(double secs, struct timeval *val);
void pmtimevalTotimespec(struct timeval *tvp, struct timespec *tsp);
void pmtimevalPrint(FILE *f, const struct timeval *tp);

cc ... -lpcp

DESCRIPTION

pmtimevalNow est une méthode indépendante de la plateforme qui renvoie l'heure système actuelle depuis l'Epoch dans tv.

pmtimevalInc ajoute le temps dans ap au temps dans bp et stocke le résultat dans ap. De même, pmtimevalDec soustraie le temps dans bp du temps dans ap et stocke le résultat dans ap.

pmtimevalAdd (et pmtimevalSub) ajoutent (et soustraient) des temps et renvoient le résultat sous forme de valeur double. Le temps dans l'argument ap n'est pas modifié.

pmtimevalToReal convertit le temps dans tp en une valeur double équivalente. pmtimevalFromReal fournit la conversion inverse, prenant le temps en secs et renvoyant le temps équivalent dans val.

pmtimevalTotimespec convertit la struct timeval tvp en une struct timespec tsp équivalente (modulo arrondissement des microsecondes en nanosecondes).

pmtimevalPrint imprime l'horodatage de tp sur le flux f à l'heure locale (tel que renvoyé par pmLocaltime(3)) au format HH:MM:SS.XXX.

NOTES

Pour les variantes de ces interfaces utilisant la précision en nanosecondes et la structure timespec, référez-vous à pmtimespecNow(3).

COMPATIBILITÉ

Avant PCP 7.0, la routine pmtimevalPrint s'appelait pmPrintStamp. Pour supporter la transition PMAPI, l'ancienne routine peut toujours être utilisée si les applications sont recompilées avec -DPMAPI_VERSION=2.

pmPrintStamp est maintenant déprécié et le support au moment de la compilation pour ce nom de routine sera supprimé dans une future version.

VOIR AUSSI

gettimeofday(2), time(2), PMAPI(3), pmLocaltime(3) et pmtimespecNow(3).
