PMDAHACLUSTER(1) Manuel des commandes générales PMDAHACLUSTER(1)

NOM

pmdahacluster - PMDA de cluster à haute disponibilité

SYNTAXE

$PCP_PMDAS_DIR/hacluster/pmdahacluster [-D debug]

DESCRIPTION

pmdahacluster est capable de collecter des informations métriques pour permettre la surveillance des clusters HA basés sur Pacemaker via Performance Co-Pilot.

Le PMDA collecte ses données métriques à partir des composants suivants qui constituent un cluster HA basé sur Pacemaker : Pacemaker, Corosync, SBD, DRBD.

Pour des informations plus détaillées concernant les métriques disponibles, veuillez consulter le fichier pmns et le fichier d'aide inclus avec le PMDA.

INSTALLATION

Installez le PMDA de cluster HA en utilisant le script d'installation en tant que root :

# cd $PCP_PMDAS_DIR/hacluster
# ./Install

Pour désinstaller, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/hacluster
# ./Remove

pmdahacluster est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove notifient pmcd lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/hacluster/help
fichier texte d'aide par défaut pour les métriques du cluster HA
$PCP_PMDAS_DIR/hacluster/Install
script d'installation pour l'agent pmdahacluster
$PCP_PMDAS_DIR/hacluster/Remove
script d'annulation de l'installation pour l'agent pmdahacluster
$PCP_LOG_DIR/pmcd/hacluster.log
fichier journal par défaut pour les messages d'erreur de pmdahacluster

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. À chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider au dépannage, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et de leur signification.

VOIR AUSSI

PCPIntro(1), pmcd(1) et pmstore(1).
