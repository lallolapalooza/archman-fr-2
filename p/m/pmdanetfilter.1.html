PMDANETFILTER(1) Manuel des commandes générales PMDANETFILTER(1)

NOM

pmdanetfilter - Agent de domaine de métriques de performance pour le suivi de connexion IP netfilter de Linux (PMDA)

DESCRIPTION

pmdanetfilter est un agent de domaine de métriques de performance (PMDA) qui exporte les valeurs de métriques du module de suivi de connexion IP dans le noyau Linux.

INSTALLATION

Installez le PMDA netfilter en utilisant le script d'installation en tant que root :

# cd $PCP_PMDAS_DIR/netfilter
# ./Install

Pour désinstaller, exécutez les commandes suivantes en tant que root :

# cd $PCP_PMDAS_DIR/netfilter
# ./Remove

pmdanetfilter est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/netfilter/Install
script d'installation de l'agent pmdanetfilter
$PCP_PMDAS_DIR/netfilter/Remove
script d'annulation d'installation de l'agent pmdanetfilter
$PCP_LOG_DIR/pmcd/netfilter.log
fichier journal par défaut pour les messages d'erreur de pmdanetfilter

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).
