PMIEND(3) Manuel des fonctions de bibliothèque PMIEND(3)

NOM

pmiEnd - finaliser une archive LOGIMPORT

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiEnd(void);

cc ... -lpcp_import -lpcp

SYNTAXE PERL

use PCP::LogImport;

pmiEnd();

DESCRIPTION

Dans le cadre de l'API d'importation de journaux de Performance Co-Pilot (voir LOGIMPORT(3)), pmiEnd ferme le contexte actuel, force l'écriture des enregistrements de fin dans les fichiers d'archive PCP, puis ferme ces fichiers.

Dans le fonctionnement normal, une application inclurait un appel à pmiEnd à la fin du traitement pour chaque contexte créé avec un appel à pmiStart(3).

DIAGNOSTICS

pmiEnd retourne zéro en cas de succès, sinon une valeur négative qui peut être convertie en message d'erreur en appelant pmiErrStr(3).

VOIR AUSSI

LOGIMPORT(3) et pmiStart(3).
