PMINDOMSTR(3) Manuel des fonctions de bibliothèque PMINDOMSTR(3)

NOM

pmInDomStr, pmInDomStr_r - convertir un identifiant de domaine d'instance de métrique de performance en chaîne de caractères

C SYNTAXE

#include <pcp/pmapi.h>

const char *pmInDomStr(pmInDom indom);
char *pmInDomStr_r(pmInDom indom, char *buf, int buflen);

cc ... -lpcp

DESCRIPTION

Pour être utilisé dans les messages d'erreur et de diagnostic, pmInDomStr retourne une version « lisible par l'homme » de l'identifiant de domaine d'instance spécifié. La fonction pmInDomStr_r fait de même, mais stocke le résultat dans un tampon fourni par l'utilisateur buf d'une longueur buflen, qui devrait avoir de la place pour au moins 20 octets.

La valeur de l'identifiant de domaine d'instance indom est généralement extraite d'une structure pmDesc, après un appel à pmLookupDesc(3) pour une métrique de performance particulière.

En interne, un identifiant de domaine d'instance est codé avec deux champs : domaine et série.

pmInDomStr retourne une chaîne de caractères avec chacun des champs apparaissant sous forme de nombres décimaux, séparés par des points.

La valeur de chaîne retournée par pmInDomStr est conservée dans un seul tampon statique, de sorte que la valeur retournée n'est valide qu'à l'appel suivant à pmInDomStr.

NOTES

pmInDomStr retourne un pointeur vers un tampon statique et n'est donc pas thread-safe. Les applications multithread devraient utiliser pmInDomStr_r à la place.

ENVIRONNEMENT PCP

Les variables d'environnement commençant par le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5). Les valeurs de ces variables peuvent être obtenues par programme en utilisant la fonction pmGetConfig(3).
