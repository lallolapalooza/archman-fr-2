PMVIEW(1) Manuel des commandes générales PMVIEW(1)

NOM

pmview - interface de visualisation 3D des métriques de performance

SYNTAXE

pmview [-Cz] [-A align] [-a archive[,archive,...]] [-c configfile] [-D debug] [-h host] [-n pmnsfile] [-O origin] [-p port] [-R logconfig] [-r addconfig] [-S starttime] [-t interval] [-T endtime] [-x version] [-Z timezone] [-geometry geometry] [-display display] [-name name] [-title title]

DESCRIPTION

pmview est un outil généralisé de visualisation 3D des métriques de performance pour Performance Co-Pilot (PCP(1)).

pmview est l'utilitaire de base derrière les outils de visualisation des métriques de performance tels que dkvis(1), mpvis(1), osvis(1) et nfsvis(1). Il est également utilisé par une gamme d'outils associés spécifiques aux agents de domaine de performance (PMDA) optionnels et/ou aux produits complémentaires PCP. pmview peut également être utilisé pour construire des affichages de performance 3D personnalisés.

pmview affiche les métriques de performance sous forme de blocs colorés et de cylindres disposés sur des plans de base monochromes. Chaque objet peut représenter une seule métrique de performance, ou une pile de plusieurs métriques de performance. Étant donné que les objets sont modulés par la valeur de la métrique qu'ils représentent, seules les métriques numériques peuvent être visualisées. Les objets représentant une seule métrique peuvent être modulés en termes de hauteur, de couleur, ou de hauteur et de couleur. Les objets d'une pile ne peuvent être modulés qu'en hauteur, mais la pile peut être normalisée à la hauteur maximale. Des étiquettes peuvent être ajoutées à la scène pour aider à identifier les groupes de métriques.

Un fichier de configuration (spécifié par l'option -c, ou lu depuis l'entrée standard) est utilisé pour spécifier la position, la couleur, la valeur maximale et les étiquettes des métriques et des instances de métriques dans la scène. La valeur maximale agit comme un facteur de normalisation et est utilisée pour mettre à l'échelle la hauteur et/ou la couleur de l'objet proportionnellement aux valeurs des métriques. Les valeurs de métriques qui dépassent la valeur maximale associée sont affichées comme des objets blancs solides. Si une métrique est indisponible, l'objet aura une hauteur minimale et sera coloré en gris.

La syntaxe complète du langage de description de scène est fournie dans pmview(5).

Normalement, l'outil fonctionne en mode « live » où les métriques de performance sont récupérées en temps réel. L'utilisateur peut visualiser des métriques de n'importe quel hôte exécutant pmcd(1). pmview peut également rejouer des archives de métriques de performance (voir pmlogger(1)) et permettre à l'utilisateur de contrôler interactivement le temps et le taux de lecture actuels à l'aide du paradigme magnétoscope. Ceci est particulièrement utile pour les comparaisons rétrospectives et pour l'analyse post-mortem des problèmes de performance où un système distant n'est pas accessible ou où un analyste de performance n'est pas disponible sur site.

Toutes les métriques de l'espace de noms des métriques de performance (PMNS) ayant des sémantiques de valeur numérique provenant d'un nombre quelconque d'hôtes ou d'archives peuvent être visualisées. pmview examine les sémantiques des métriques et, lorsque cela est judicieux, convertit les valeurs de métriques en un débit avant la mise à l'échelle.

OPTIONS DE LIGNE DE COMMANDE

Les options -S, -T, -O et -A peuvent être utilisées pour définir une fenêtre temporelle afin de restreindre les échantillons récupérés, définir une origine initiale dans la fenêtre temporelle, ou spécifier un alignement « naturel » des temps d'échantillonnage ; reportez-vous à PCPIntro(1) pour une description complète de ces options.

Les autres options disponibles sont :

-a archive[,archive,...]]
Spécifie une archive à partir de laquelle les métriques peuvent être obtenues pour un hôte particulier. archive est le nom de base d'une archive, ou le nom d'un répertoire contenant des archives, précédemment créées par pmlogger(1). Plusieurs ensembles d'archives (séparés par des virgules ou dans différentes options -a) provenant de différents hôtes peuvent être fournis, mais une erreur se produira s'il y a plus d'un ensemble d'archives provenant du même hôte. Toutes les métriques qui ne sont pas associées à un hôte ou une archive spécifique dans le fichier de configuration utiliseront le premier ensemble d'archives comme source.
-C
Analyse le fichier de configuration et quitte avant d'afficher la fenêtre pmview. Toute erreur dans le fichier de configuration sera affichée.
-c configfile
Charge la configuration à partir de configfile plutôt que de l'entrée standard.
-h host
Récupère les métriques de performance à partir de pmcd(1) sur host, plutôt que de localhost par défaut. Implique que pmview s'exécutera en mode live, donc aucune archive ne peut être spécifiée sur la ligne de commande ou dans le fichier de configuration. Une seule option -h peut être donnée.
-n pmnsfile
Normalement, pmview opère sur l'espace de noms des métriques de performance distribué (PMNS), cependant, si l'option -n est spécifiée, un PMNS local alternatif est chargé à partir du fichier pmnsfile.
-p port
Se connecte aux contrôles temporels (voir pmtime(1)) sur ce port. Utilisé lorsqu'un outil en lance un autre afin qu'ils puissent se connecter aux mêmes contrôles temporels.
-R logconfig
Utilise logconfig comme configuration de pmlogger(1) lors de l'enregistrement.
-r addconfig
Ajoute addconfig à la configuration de pmlogger(1) générée par pmview lors de l'enregistrement.
-t interval
L'intervalle de mise à jour utilisé pour récupérer les métriques des sources live ou d'archives. L'argument interval suit la syntaxe décrite dans PCPIntro(1), et sous sa forme la plus simple peut être un entier non signé (les unités implicites dans ce cas sont les secondes). La valeur par défaut est de 2.0 secondes.
-x version
Utilise la version spécifiée de la spécification pmlaunch(5). Les versions actuellement prises en charge sont « 1.0 » et la version par défaut « 2.0 ».
-Z timezone
Par défaut, pmview affiche l'heure locale du fuseau horaire du système où pmview est exécuté. L'option -Z change le fuseau horaire par défaut pour timezone, qui doit être au format de la variable d'environnement TZ comme décrit dans environ(7).
-z
Change le fuseau horaire d'affichage au fuseau horaire local de l'hôte qui est la source des métriques de performance, tel qu'identifié via soit l'option -h, soit la première option -a.

-geometry geometry
-display display
-name name
-title title

FENÊTRE

La fenêtre pmview est composée d'une barre de menus, de contrôles de temps et d'échelle, de valeurs de métriques et de temps, et d'une visionneuse « examiner ».

VISIONNEUSE EXAMINER

Les bords gauche, droit et inférieur de la visionneuse examiner contiennent une variété de molettes et de boutons qui peuvent être utilisés pour ajuster la visualisation de la scène 3D. Les molettes Rotx et Roty permettent à l'utilisateur de faire pivoter la scène autour des axes x et y respectivement. La molette dolly rapproche et éloigne la caméra virtuelle de la scène, permettant à l'utilisateur d'examiner des parties spécifiques en détail ou de voir la scène entière. Sur le bord droit de la visionneuse se trouvent huit boutons qui affectent la manière dont l'utilisateur peut interagir avec la scène.

Pointeur
Change le curseur en pointeur, ce qui permet de sélectionner des blocs.

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

ACTIONS DE LA SOURIS

La souris peut être utilisée pour interagir avec la scène. Pour plus d'informations sur la manière dont les métriques sont choisies, voir la section SELECTION DE MESURES ci-dessous.

Main
Change le curseur en une main qui permet de faire pivoter, translater et déplacer la scène en utilisant une combinaison des boutons de la souris. Le bouton gauche de la souris peut être utilisé pour faire pivoter la scène dans la direction de la souris. Relâcher le bouton gauche de la souris avant que la souris ne cesse de bouger fera continuer la rotation de la scène, qui pourra être arrêtée en appuyant à nouveau sur le bouton gauche de la souris. Le bouton du milieu de la souris effectuera un « panoramique » de la scène, et les deux boutons de la souris agiront comme un zoom avant/arrière pour la caméra virtuelle.
Point d'interrogation
Affiche les informations d'aide SGI pour le visualiseur d'examinateur.
Accueil
Ramène la scène à sa position d'origine, à moins que la position d'accueil n'ait été modifiée par le bouton pointeur d'accueil.
Pointeur d'accueil
Modifie la position d'accueil de la scène pour qu'elle soit la scène actuellement visible.
Œil
Redimensionne la scène afin qu'elle s'insère complètement dans la zone de visualisation 3D.
Réticule
Déplace l'objet situé sous le curseur au centre de la zone de visualisation, si le curseur en forme de main a été sélectionné. Appuyer sur la touche « s » lorsque le curseur est sur un objet a le même effet.
Boîte de perspective
Commute l'affichage entre les projections perspective et orthogonale.

Appuyer sur le bouton droit de la souris dans la fenêtre de la scène affichera un menu d'options qui affectent la manière dont la scène 3D est dessinée. Les options incluent le dessin des blocs en mode filaire et l'activation de la visualisation stéréo.

SELECTION DE MESURES

Lorsque le curseur pointeur est actif, plus d'informations sur la scène 3D peuvent être obtenues. Un texte décrivant la mesure représentée par le bloc sous le curseur sera affiché dans la zone de texte supérieure de la fenêtre pmview. Le texte contient la source et le nom de la mesure, la valeur actuelle et les unités, ainsi que le pourcentage de la valeur maximale attendue (ou de normalisation). La zone de texte est mise à jour chaque fois que la scène est mise à jour avec les dernières valeurs de mesure ou lorsque le curseur est déplacé sur un autre bloc de la scène. Déplacer le curseur sur un bloc du plan de base, du texte ou de l'espace environnant effacera la zone de texte.

Cliquer sur le bouton gauche de la souris sur un bloc liera la zone de texte de cette instance de mesure afin que la mesure puisse être surveillée tout en effectuant d'autres actions avec la souris. Le bloc sera mis en évidence avec un fil de fer rouge. Cliquer sur le bouton gauche de la souris sur du texte ou sur l'espace entourant la scène désélectionnera l'objet, provoquant le retour de la zone de texte au comportement d'origine, c'est-à-dire l'affichage de la mesure sous le curseur.

Sélectionner un plan de base au lieu d'un bloc modulé entraînera la sélection de tous les blocs de ce plan de base. Lorsque plus d'un objet est sélectionné, la zone de texte se comporte comme si rien n'était sélectionné, de sorte que la mesure affichée est la mesure actuellement sous le curseur. Des sélections multiples sont également possibles en appuyant sur la touche MAJ tout en sélectionnant un objet avec le bouton gauche de la souris.

MENUS

Il y a quatre menus dans l'interface utilisateur de pmview qui permettent d'enregistrer, de sauvegarder et d'imprimer les scènes (Fichier), d'accéder aux contrôles temporels (Options), de lancer d'autres outils (Lancer) et d'obtenir de l'aide en ligne (Aide).

Fichier/Enregistrer
En mode « direct », cette option lancera des processus pmlogger(1) pour enregistrer la scène actuelle dans un folio d'archives (voir pmafm(1)) afin qu'elle puisse être rejouée ultérieurement. Cette option n'est pas disponible en mode « relecture ».

Lorsque Fichier/Enregistrer est sélectionné, une boîte de dialogue de choix de fichier demandera le nom du nouveau folio d'archives. Si le répertoire du folio n'existe pas, pmview tentera de le créer. Il est généralement pratique de conserver chaque folio dans son propre répertoire car plusieurs autres fichiers seront associés au folio, y compris les archives générées.

Une fois qu'un folio valide a été créé, pmview lancera un processus pmlogger(1) pour chaque hôte afin de collecter les mesures requises de cet hôte dans la scène actuelle. Les sélections actuelles n'affectent pas l'ensemble des mesures enregistrées.

Pendant l'enregistrement, un point rouge apparaîtra sur le bouton des contrôles temporels dans le coin supérieur gauche de la fenêtre pmview. L'option Fichier/Enregistrer deviendra également Fichier/Arrêter l'enregistrement car une seule session d'enregistrement est possible à la fois. La sélection de blocs ou le lancement d'autres outils n'auront aucun effet sur la session d'enregistrement.

La session d'enregistrement peut être terminée en sélectionnant Fichier/Arrêter l'enregistrement. Cela affichera des boîtes de dialogue pour chaque instance de pmlogger(1) décrivant la taille et l'emplacement des fichiers d'archives avant de terminer chaque processus. Lorsque tous les processus pmlogger(1) auront été terminés, le point rouge sera retiré du bouton des contrôles temporels et le menu reviendra à Fichier/Enregistrer pour permettre une nouvelle session d'enregistrement.

Si l'application se ferme pendant l'enregistrement, une boîte de dialogue apparaîtra, vous permettant de terminer chaque processus pmlogger(1), ou de le laisser en cours d'exécution sans attachement.

Un folio d'archives peut être rejoué en utilisant la commande : « pmafm folio replay ». Voir pmafm(1) pour plus de détails.

Il n'est pas rare qu'un script frontal générant une scène pmview utilise des mesures qui ne sont pas contenues dans la scène. Par exemple, osvis(1) utilise plusieurs mesures hinv pour déterminer la taille et la disposition de certains objets. Comme ces mesures sont également nécessaires lors de la relecture de l'archive générée avec le script frontal, une configuration complète de pmlogger(1) peut être spécifiée (-R) qui remplace la configuration générée par pmview, ou une configuration supplémentaire peut être ajoutée (-r) à la configuration générée par pmview.

Fichier/Sauvegarder
Sauvegarde la scène actuelle dans un fichier Open Inventor lisible par l'homme (voir inventor(1)). Une boîte de dialogue de fichier demandera l'emplacement du fichier. L'extension de fichier par défaut est « .iv », reconnue par ivview(1) et certains navigateurs Web.
Fichier/Imprimer
Envoie la scène actuelle à une imprimante. Une boîte de dialogue d'impression s'affichera, permettant de sélectionner une imprimante spécifique.
Fichier/Quitter
pmview se ferme immédiatement. Si l'enregistrement était actif, des boîtes de dialogue s'afficheront pour chaque processus pmlogger(1) afin qu'ils puissent être terminés.
Options/Afficher le Contrôle Temporel
Affiche les contrôles temporels (voir pmtime(1)) qui pilotent cette instance de pmview. Les contrôles temporels peuvent être partagés par d'autres outils, y compris pmchart(1), qui ont été lancés par d'autres instances de pmview et oview(1). Par conséquent, cet élément de menu peut sembler n'avoir aucun effet si les contrôles temporels sont déjà visibles.
Options/Nouveau Contrôle Temporel
Se déconnecte des contrôles temporels actuels (qui peuvent être partagés par d'autres outils, voir pmtime(1)) et utilise un nouveau contrôle temporel qui n'est connecté à aucun autre outil. Le nouveau contrôle temporel sera immédiatement affiché.
Lancer
Le menu de lancement est généré à partir d'un fichier de spécification de menu (voir pmlaunch(5)). Le menu contient des outils qui peuvent être lancés en fonction des sources et des noms des mesures sélectionnées dans la scène. Par exemple, si les mesures sélectionnées proviennent de trois hôtes différents, trois copies d'un outil peuvent être lancées, une pour chaque hôte. Le comportement d'un lancement dépend des mesures sélectionnées et des outils lancés.

Lors de la sélection d'un élément du menu Lancer, pmview génère des informations d'état dans le format de spécification des mesures de pmlaunch(5). Cela fournit une description des mesures sélectionnées (ou de toutes les mesures s'il n'y a pas de sélection) dans la scène, sans aucune information de géométrie.

Les outils capables de surveiller plusieurs hôtes et des mesures spécifiées par l'utilisateur ne peuvent être lancés qu'une seule fois pour ces mesures (par exemple, pmdumptext(1)). D'autres outils ayant une vue fixe pour un hôte (par exemple, mpvis(1)) peuvent être lancés plusieurs fois, une fois pour chaque hôte dans la liste des mesures sélectionnées. Si les outils lancés ont des contrôles temporels, ils partageront les contrôles temporels avec le pmview lanceur.

L'ensemble des outils lancés est configurable et peut inclure des applications IRIX et utilisateur. Voir pmlaunch(5) pour plus de détails.

Aide/...
Si pcp.books.help a été installé, alors les livres insight(1) pour pmview sont affichés.

CONTRÔLES TEMPORELS

En plus des options de menu pour les contrôles temporels, la direction actuelle des contrôles temporels (voir pmtime(1)) est indiquée sur un bouton dans le coin supérieur gauche de la fenêtre pmview. Appuyer sur ce bouton affichera le contrôle temporel et est identique en comportement à Options/Afficher le Contrôle Temporel.

CONTRÔLES D'ÉCHELLE

Au-dessus de la fenêtre d'examinateur se trouve une molette et une zone de texte modifiable qui permettent à l'utilisateur d'appliquer un multiplicateur à toutes les valeurs représentées dans la scène. Faire tourner la molette vers la droite et/ou augmenter la valeur du texte pour l'échelle augmentera la hauteur des barres. Faire tourner la molette vers la gauche et/ou abaisser la valeur diminuera

La hauteur des barres. Le bouton à droite de la molette permet de réinitialiser l'échelle afin que les barres apparaissent à la hauteur d'origine pour leur valeur actuelle.

INFORMATIONS TEMPORELLES

À côté des contrôles d'échelle se trouve une autre zone de texte qui affiche l'heure des métriques récupérées. L'heure changera avec le contrôleur de temps (voir pmtime(1)).

DIAGNOSTICS

Sont conçus pour être auto-explicatifs. La variable d'environnement PCP_STDERR peut être définie pour forcer la plupart des avertissements et erreurs de démarrage à être envoyés au flux d'erreurs standard plutôt que d'être affichés dans une boîte de dialogue.

répertoire où Inventor recherche normalement les contours des polices Type1.

ENVIRONNEMENT

La face par défaut de la police 3D dans la fenêtre pmview peut être modifiée via la variable d'environnement PMVIEW_FONT qui peut être définie sur le nom de base d'un fichier de police Type1 dans le répertoire de polices Inventor par défaut.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. À chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DEBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à trier les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

Les options de débogage spécifiques à pmvew sont les suivantes :

Option Description
appl0 construction de scène
appl1 sélection, désélection et lancement d'objets
appl2 récupération et modulation d'objets
appl3 rafraîchissement d'objets
appl4 objets de l'interface utilisateur (autres que la fenêtre Inventor)
pmc opérations sur les classes de métriques (libpcp_qmc)
timecontrol interactions pmtime(1)
qed méthodes libpcp_qed
