PMDANEWS(1) Performance Co-Pilot PMDANEWS(1)

NOM

pmdanews - agent de domaine de métriques de performance (PMDA) d'échantillon pour les news Usenet

DESCRIPTION

pmdanews est un exemple d'agent de domaine de métriques de performance (PMDA) qui exporte des valeurs de métriques relatives à un ensemble de groupes de news.

INSTALLATION

Si vous souhaitez accéder aux noms et valeurs des métriques de performance des news, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/news
# ./Install

Si vous souhaitez annuler l'installation, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/news
# ./Remove

pmdanews est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/news/Install
script d'installation pour l'agent pmdanews
$PCP_PMDAS_DIR/news/Remove
script d'annulation d'installation pour l'agent pmdanews
$PCP_LOG_DIR/pmcd/news.log
fichier journal par défaut pour les messages d'erreur de pmdanews

VOIR AUSSI
