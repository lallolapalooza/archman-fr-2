PMDANAMED(1) Performance Co-Pilot PMDANAMED(1)

NOM

pmdanamed - PMDA pour BIND (named)

DESCRIPTION

pmdanamed est un Agent de Domaine de Métriques de Performance (PMDA) qui exporte les valeurs métriques du serveur DNS BIND. Vous trouverez plus de détails sur BIND sur http://isc.org/.

INSTALLATION

Si vous souhaitez accéder aux noms et valeurs des métriques de performance de named, effectuez les actions suivantes en tant que root :

# cd $PCP_PMDAS_DIR/named
# ./Install

Si vous souhaitez annuler l'installation, effectuez les actions suivantes en tant que root :

# cd $PCP_PMDAS_DIR/named
# ./Remove

pmdanamed est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

/var/named/data/named_stats.txt
fichier de statistiques affichant les valeurs exportées par named
/var/named/chroot/var/named/data/named_stats.txt
variante chroot du fichier de statistiques affichant les valeurs exportées par named
$PCP_PMDAS_DIR/named/Install
script d'installation de l'agent pmdanamed
$PCP_PMDAS_DIR/named/Remove
script d'annulation de l'installation de l'agent pmdanamed
$PCP_LOG_DIR/pmcd/named.log
fichier de log par défaut pour les messages d'erreur de pmdanamed

VOIR AUSSI

pmcd(1), named.conf(5), named(8).
