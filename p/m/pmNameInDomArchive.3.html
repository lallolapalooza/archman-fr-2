NOM

pmNameInDomArchive - traduire un identifiant d'instance en nom d'instance

SYNTAXE

#include <pcp/pmapi.h>

int pmNameInDomArchive(pmInDom indom,
int inst, char **name);

cc ... -lpcp

DESCRIPTION

À condition que le contexte actuel de l'API de performance (PMAPI) soit associé à un ensemble d'archives, pmNameInDomArchive parcourra l'union de tous les métadonnées de domaine d'instance pour le domaine d'instance indom, localisera la première instance avec l'identifiant d'instance interne donné par inst, et renverra l'identification externe complète de l'instance via name.

Cette routine est une version spécialisée de la routine PMAPI plus générale pmNameInDom.

La valeur du domaine d'instance indom est généralement extraite d'une structure pmDesc, après un appel à pmLookupDesc(3) pour une métrique de performance particulière.

L'espace pour la valeur de name aura été alloué dans pmNameInDomArchive avec malloc(3), et il incombe à l'appelant de free(3) cet espace lorsqu'il n'est plus nécessaire.

pmNameInDomArchive renvoie zéro en cas de succès.

DIAGNOSTICS

PM_ERR_NOTARCHIVE
le contexte PMAPI actuel n'est pas associé à un ensemble d'archives
PM_ERR_INDOM_LOG
indom n'est pas un identifiant de domaine d'instance défini pour l'ensemble des archives
PM_ERR_INST_LOG
l'identifiant d'instance inst n'est pas connu pour le domaine d'instance indom dans l'ensemble des archives

VOIR AUSSI

PMAPI(3), pmGetConfig(3), pmGetInDomArchive(3), pmLookupInDomArchive(3), pmNameInDom(3), pcp.conf(5) et pcp.env(5).
