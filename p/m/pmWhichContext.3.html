PMWHICHCONTEXT(3) Manuel des fonctions de bibliothèque PMWHICHCONTEXT(3)

NOM

pmWhichContext - identifier le contexte PMAPI actuel

SYNTAXE C

#include <pcp/pmapi.h>

int pmWhichContext(void);

cc ... -lpcp

DESCRIPTION

Une application utilisant l'API d'application des métriques de performance (PMAPI) peut manipuler plusieurs contextes simultanés, chacun associé à une source de métriques de performance, par exemple pmcd(1) sur un hôte donné, ou une archive de métriques de performance telle que créée par pmlogger(1).

pmWhichContext renvoie un descripteur pour le contexte PMAPI actuel, qui peut être utilisé dans les routines PMAPI associées nécessitant un descripteur pour identifier un contexte PMAPI.

DIAGNOSTICS

PM_ERR_NOCONTEXT
aucun contexte actuel

VOIR AUSSI

PMAPI(3), pmDestroyContext(3), pmDupContext(3), pmNewContext(3) et pmUseContext(3).
