PMINDOM_BUILD(3) Manuel des fonctions de bibliothèque PMINDOM_BUILD(3)

NOM

pmInDom_build, pmInDom_domain, pmInDom_serial - méthodes d'aide pour la manipulation des identifiants de domaine d'instance

C SYNTAXE

#include <pcp/pmapi.h>

pmInDom pmInDom_build(unsigned int domain, unsigned int serial);
unsigned int pmInDom_domain(pmInDom indom);
unsigned int pmInDom_serial(pmInDom indom);

cc ... -lpcp

DESCRIPTION

Au sein du Performance Co-Pilot (PCP), chaque domaine d'instance se voit attribuer un Identifiant de Domaine d'Instance (pmInDom) unique. En interne, un pmInDom est construit à partir de 2 champs : le numéro de domaine (de l'agent de domaine de métriques de performance associé, ou PMDA) et le numéro de série (attribué par le PMDA).

pmInDom_build construit un pmInDom à partir de domain et serial.

pmInDom_domain et pmInDom_serial retournent les champs respectifs de indom.

VOIR AUSSI

PMAPI(3) et pmInDomStr(3).
