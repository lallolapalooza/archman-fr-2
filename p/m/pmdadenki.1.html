PMDADENKI(1) Manuel des commandes générales PMDADENKI(1)

NOM

pmdadenki - métriques relatives à la consommation électrique du système

SYNTAXE

$PCP_PMDAS_DIR/denki/pmdadenki [-D debug] [-d domaine] [-l logfile]

DESCRIPTION

pmdadenki est un agent de domaine de métriques de performance (PMDA) qui extrait les métriques de performance liées à l'électricité.

Actuellement, les métriques de la fonction CPU Intel RAPL (Running Average Power Limit) et les valeurs de charge de batterie sont disponibles, si le matériel le supporte.

-l Emplacement du fichier journal. Par défaut, un fichier journal nommé denki.log est écrit dans le répertoire courant de pmcd(1) lorsque pmdadenki est démarré, c'est-à-dire $PCP_LOG_DIR/pmcd. Si le fichier journal ne peut pas être créé ou n'est pas inscriptible, la sortie est écrite dans la sortie d'erreur standard à la place.

INSTALLATION

Le PMDA denki est installé et disponible par défaut sous Linux. Si vous souhaitez annuler l'installation, faites ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/denki
# ./Remove

Si vous souhaitez rétablir l'accès aux noms, au texte d'aide et aux valeurs des métriques denki après suppression, faites ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/denki
# ./Install

pmdadenki est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove informent pmcd(1) lorsque l'agent est installé ou retiré.

FICHIERS

$PCP_PMCDCONF_PATH
options de ligne de commande utilisées pour lancer pmdadenki
$PCP_PMDAS_DIR/denki/help
fichier d'aide par défaut pour les métriques denki
$PCP_PMDAS_DIR/denki/Install
script d'installation pour l'agent pmdadenki
$PCP_PMDAS_DIR/denki/Remove
script d'annulation d'installation pour l'agent pmdadenki
$PCP_LOG_DIR/pmcd/denki.log
fichier journal par défaut pour les messages d'erreur et autres informations de pmdadenki

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. À chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider au diagnostic des problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

Les options de débogage spécifiques à pmdadenki sont les suivantes :

Option Description
appl0 diagnostics verbaux

VOIR AUSSI

PCPIntro(1), pmcd(1), le fichier denki/README pcp.conf(5) et pcp.env(5).
