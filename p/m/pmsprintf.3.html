PMSPRINTF(3) Manuel des fonctions de bibliothèque PMSPRINTF(3)

NOM

pmsprintf - conversion de chaîne formatée

SYNTAXE C

#include <pcp/pmapi.h>

int pmsprintf(char *str,
size_t size, const char *fmt, ... /*args*/);

cc ... -lpcp

DESCRIPTION

Interface de formatage de chaîne sécurisée qui encapsule l'appel vsnprintf(3).

Elle diffère principalement en ce que pmsprintf garantit que le tampon de sortie str sera terminé par null, même lorsque le tampon fourni size est insuffisant pour contenir la chaîne formatée. Dans ce cas, une chaîne tronquée terminée par null sera retournée dans str.

En cas d'échec de l'interface vsnprintf sous-jacente, une chaîne vide terminée par null sera retournée dans str, et la valeur de retour sera zéro.

DIAGNOSTICS

En cas de succès, pmsprintf retourne le nombre de caractères écrits dans le tampon fourni, sans inclure le terminateur null.

Le code de retour est toujours zéro ou plus, jamais négatif.

VOIR AUSSI

vsnprintf(3), pmprintf(3) et PMAPI(3).
