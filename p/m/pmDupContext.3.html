PMDUPCONTEXT(3) Manuel des fonctions de bibliothèque PMDUPCONTEXT(3)

NOM

pmDupContext - dupliquer un contexte PMAPI

SYNTAXE C

#include <pcp/pmapi.h>

int pmDupContext(void);

cc ... -lpcp

DESCRIPTION

Une application utilisant l'interface de programmation d'application de métriques de performance (PMAPI) peut manipuler plusieurs contextes concurrants, chacun associé à une source de métriques de performance, par exemple pmcd(1) sur un certain hôte, ou un ensemble d'archives de métriques de performance comme créé par pmlogger(1).

Appeler pmDupContext reproduira le contexte PMAPI actuel, renvoyant un handle pour le nouveau contexte qui pourra être utilisé avec les appels subséquents à pmUseContext(3).

Une fois créé, le contexte dupliqué et le contexte d'origine ont une existence indépendante, et donc leurs profils d'instance et le temps de collecte (pertinent uniquement pour les contextes d'archives) peuvent être variés indépendamment.

Le contexte nouvellement répliqué devient le contexte actuel.

VOIR AUSSI

PMAPI(3), pmNewContext(3) et pmUseContext(3).
