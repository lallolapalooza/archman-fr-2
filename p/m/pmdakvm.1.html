PMDAKVM(1) Manuel des commandes générales PMDAKVM(1)

NOM

pmdakvm - Agent de domaine de métriques de performance de la virtualisation Linux (PMDA)

SYNTAXE

$PCP_PMDAS_DIR/kvm/pmdakvm [-D debug]

DESCRIPTION

pmdakvm est un Agent de Domaine de Métriques (PMDA) qui exporte les valeurs métriques du sous-système de virtualisation KVM (Kernel Virtual Machine) de Linux.

Les métriques de trace KVM par processeur, issues des événements du noyau répertoriés sous /sys/kernel/debug/tracing/events/kvm, peuvent être configurées statiquement via le fichier de configuration pmdakvm, /etc/pcp/kvm/kvm.conf.

INSTALLATION

Configurez éventuellement les points de trace dans le fichier de configuration, puis installez le PMDA KVM en utilisant le script d'installation en tant que root :

# cd $PCP_PMDAS_DIR/kvm
# ./Install

Pour désinstaller, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/kvm
# ./Remove

pmdakvm est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

ATTENTION

Lorsque pmdakvm est en cours d'exécution, il détient des références aux ressources du noyau au sein du pilote de périphérique KVM. Il n'est donc pas possible de décharger ou de recharger le module du pilote de noyau tant que le PMDA est en cours d'exécution. La procédure idéale à suivre pour recharger le module du noyau est l'inverse de celle décrite dans la section « INSTALLATION » ci-dessus - c'est-à-dire exécuter d'abord ./Remove, puis recharger le module du noyau, puis exécuter ./Install.

FICHIERS

$PCP_SYSCONF_DIR/kvm/kvm.conf
fichier de configuration pour l'agent pmdakvm
$PCP_PMDAS_DIR/kvm/Install
script d'installation pour l'agent pmdakvm
$PCP_PMDAS_DIR/kvm/Remove
script d'annulation de l'installation pour l'agent pmdakvm
$PCP_LOG_DIR/pmcd/kvm.log
fichier journal par défaut pour les messages d'erreur de pmdakvm

ENVIRONNEMENT PCP

Les variables d'environnement préfixées par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. À chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à diagnostiquer les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

VOIR AUSSI

PCPIntro(1), pmcd(1) et kvm(1).
