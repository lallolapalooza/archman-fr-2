PMDALIBVIRT(1) Manuel des commandes générales PMDALIBVIRT(1)

NOM

pmdalibvirt - PMDA libvirt

DESCRIPTION

pmdalibvirt est un Agent de Domaine de Métriques de Performance (PMDA) qui extrait les données de performance en direct de l'hyperviseur et des domaines (VM) libvirt.

Voir la documentation de libvirt pour une description détaillée de chaque métrique.

INSTALLATION

pmdalibvirt lit un fichier de configuration optionnel de type ini

$PCP_PMDAS_DIR/libvirt/libvirt.conf

Ce fichier peut contenir dans sa section [pmda] des valeurs remplaçant celles des options PMDA suivantes :

  • user
  • uri
  • backing

Par défaut, root, qemu:///system et False sont utilisés comme valeurs pour ces options, respectivement.

Le paramètre backing peut être utilisé pour développer les informations de périphériques bloc afin de couvrir les chaînes de support avec les versions récentes de libvirt.

Le paramètre old API peut être utilisé dans les environnements où les ajout de l'API libvirt récents ne sont pas disponibles (par exemple, RHEL 6 / libvirt-0.10.2) pour fournir certaines des métriques disponibles avec la nouvelle API. Quelle que soit la version de l'API, aucun agent invité n'est nécessaire pour les métriques.

Notez que l'utilisation d'un utilisateur non root nécessite généralement également une configuration côté libvirt ; veuillez vous référer à la documentation de libvirt pour plus de détails à ce sujet.

Une fois la configuration nécessaire prête, vous pouvez tester la connexion et installer le PMDA pour permettre l'accès aux noms et valeurs des métriques de performance libvirt. Pour installer, faites ceci en tant que root :

# cd $PCP_PMDAS_DIR/libvirt
# ./connect
# ./Install

Pour désinstaller, faites ceci en tant que root :

# cd $PCP_PMDAS_DIR/libvirt
# ./Remove

pmdalibvirt est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/libvirt/libvirt.conf
fichier de configuration pour l'agent pmdalibvirt
$PCP_PMDAS_DIR/libvirt/connect
outil d'aide au test de connexion utilisant la configuration de l'agent pmdalibvirt
$PCP_PMDAS_DIR/libvirt/Install
script d'installation pour l'agent pmdalibvirt
$PCP_PMDAS_DIR/libvirt/Remove
script d'annulation d'installation pour l'agent pmdalibvirt
$PCP_LOG_DIR/pmcd/libvirt.log
fichier journal par défaut pour les messages de l'agent pmdalibvirt

ENVIRONNEMENT PCP

Les variables d'environnement dont le préfixe est PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).
