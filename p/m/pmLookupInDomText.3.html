PMLOOKUPINDOMTEXT(3) Manuel des fonctions de bibliothèque PMLOOKUPINDOMTEXT(3)

NOM

pmLookupInDomText - renvoie un texte décrivant un domaine d'instance de métriques de performance

C SYNTAXE

#include <pcp/pmapi.h>

int pmLookupInDomText(pmInDom indom,
int level, char **buffer);

cc ... -lpcp

DESCRIPTION

Récupère le texte descriptif du domaine d'instance de métriques de performance identifié par indom.

La valeur du domaine d'instance indom est typiquement extraite d'une structure pmDesc, suite à un appel à pmLookupDesc(3) pour une métrique de performance particulière.

L'argument level doit être PM_TEXT_ONELINE pour un résumé en une ligne, sinon PM_TEXT_HELP pour une description plus détaillée, adaptée à une boîte de dialogue d'aide.

L'espace pointé par buffer aura été alloué par pmLookupInDomText avec malloc(3), et il est de la responsabilité de l'appelant de free(3) cet espace lorsqu'il n'est plus requis.

pmLookupInDomText renvoie zéro en cas de succès.

DIAGNOSTICS

PM_ERR_NOTHOST
Pour les archives créées avec des versions de PCP antérieures à la 4.0, si le contexte PMAPI actuel est une archive (le texte d'aide et le texte sur une ligne n'étaient pas précédemment maintenus dans les archives)
