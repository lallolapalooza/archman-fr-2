PMLOGPASTE(1) Manuel des commandes générales PMLOGPASTE(1)

NOM

pmlogpaste - coller du texte dans une métrique d'une archive PCP

SYNOPIS

pmlogpaste [-?] [-f fichier] [-h nom_hote] [-l etiquette] [-m metrique] [-o fichier_sortie] [-t fuseau_horaire]

DESCRIPTION

pmlogpaste prend un texte d'entrée à partir d'un fichier ou de la ligne de commande, et l'écrit comme une valeur métrique dans une nouvelle archive PCP. Cette valeur métrique est horodatée avec l'heure actuelle, et est stockée comme une métrique de type chaîne de caractères.

Le but principal de cet outil est de prendre des sorties capturées et de les conserver dans une archive PCP. Cela permet, par exemple, de stocker la sortie d'une exécution de benchmark aux côtés des métriques de performance capturées pendant cette exécution, dans une seule archive. Les archives peuvent être fusionnées à l'aide de l'utilitaire pmlogextract(1).

pmlogpaste utilise en interne les interfaces de la bibliothèque LOGIMPORT(3), qui supporte la création d'archives à partir de sources externes de données de performance.

OPTIONS

Les options de ligne de commande disponibles sont :

-f fichier, --file=fichier
Fichier contenant le texte d'entrée à archiver, ou ``-'' pour l'entrée standard.
-h nom_hote, --hostname=nom_hote
Nom de l'hôte source pour l'archive. La valeur par défaut est le nom de l'hôte local, ou ``localhost'' si celui-ci ne peut être obtenu.
-l etiquette, --label=etiquette
Ajoute des étiquettes de contexte à l'archive générée. Cette option peut être utilisée plusieurs fois pour produire plusieurs étiquettes dans l'archive. L'étiquette doit être sous la forme nom:valeur.
-m metrique, --metric=metrique
Nom de la métrique pour l'archive. Le nom de métrique par défaut est paste.value.
-o fichier_sortie, --outfile=fichier_sortie
Fichier de sortie de l'archive. Le nom de l'archive par défaut est paste.
-t fuseau_horaire, --timezone=fuseau_horaire
Fuseau horaire source pour l'archive. La valeur par défaut est le fuseau horaire local.
-?, --help
Affiche le message d'utilisation et quitte.

ENVIRONNEMENT PCP

Les variables d'environnement préfixées par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI
