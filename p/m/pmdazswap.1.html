NOM

pmdazswap - PMDA de zswap (swap compressé)

DESCRIPTION

pmdazswap est un agent de domaine de métriques de performance (PMDA) qui exporte des valeurs métriques concernant les opérations de swap compressé, telles que suivies par le module noyau zswap de Linux.

Zswap est un cache compressé léger pour les pages de swap. Il prend les pages en cours de swap et tente de les compresser dans un pool de mémoire basé sur la RAM alloué dynamiquement. Zswap échange des cycles CPU contre une réduction potentielle des entrées/sorties de swap. Cet échange peut également entraîner une amélioration des performances si les lectures depuis le cache compressé sont plus rapides que les lectures depuis un périphérique de swap.

Ce PMDA exporte des métriques sur la taille du pool, le nombre de pages stockées et divers compteurs expliquant les raisons pour lesquelles les pages sont rejetées.

INSTALLATION

Installez le PMDA zswap en utilisant le script Install en tant que root :

# cd $PCP_PMDAS_DIR/zswap
# ./Install

Pour désinstaller, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/zswap
# ./Remove

pmdazswap est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou désinstallé.

FICHIERS

$PCP_PMDAS_DIR/zswap/Install
script d'installation de l'agent pmdazswap
$PCP_PMDAS_DIR/zswap/Remove
script d'annulation de l'installation de l'agent pmdazswap
$PCP_LOG_DIR/pmcd/zswap.log
fichier journal par défaut pour les messages d'erreur de pmdazswap

ENVIRONNEMENT PCP

Les variables d'environnement préfixées par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).
