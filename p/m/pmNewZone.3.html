PMNEWZONE(3) Manuel des fonctions de bibliothèque PMNEWZONE(3)

NOM

pmNewZone - établir un fuseau horaire de reporting

C SYNTAXE

#include <pcp/pmapi.h>

int pmNewZone(const char *tz);

cc ... -lpcp

DESCRIPTION

Le fuseau horaire de reporting actuel affecte le fuseau horaire utilisé par pmCtime(3) et pmLocaltime(3).

L'argument tz définit une chaîne de fuseau horaire, dans le format décrit pour la variable d'environnement TZ, voir environ(7).

pmNewZone définit le fuseau horaire de reporting actuel, et retourne une valeur qui peut être utilisée dans un appel ultérieur à pmUseZone(3) pour restaurer ce fuseau horaire de reporting.

DIAGNOSTICS

Une valeur de retour inférieure à zéro indique une erreur fatale d'un appel système, très probablement malloc(3).

VOIR AUSSI

PMAPI(3), pmCtime(3), pmGetConfig(3), pmLocaltime(3), pmNewContextZone(3), pmUseZone(3), pmWhichZone(3), pcp.conf(5), pcp.env(5) et environ(7).
