PMDADSO(3) Manuel des fonctions de bibliothèque PMDADSO(3)

NOM

pmdaDSO - initialiser le PMDA pour qu'il s'exécute en tant que DSO

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaDSO(pmdaInterface *dispatch,
int interface, char *name, char *helptext);

cc ... -lpcp_pmda -lpcp

DESCRIPTION

pmdaDSO initialise la structure pmdaInterface pour utiliser les extensions d'interface, en supposant que le PMDA(3) doit s'exécuter en tant que DSO. La structure pmdaInterface est initialisée avec :

name
Le nom de l'agent.
helptext
Le chemin par défaut vers le texte d'aide (voir pmdaText(3)). Si aucun texte d'aide n'est installé, ou si vous n'utilisez pas pmdaText(3), ceci doit être défini à NULL, sinon helptext sera copié, de sorte que l'espace associé à helptext pourra être libéré après l'appel à pmdaDSO.

Les rappels (callbacks) sont initialisés à pmdaProfile(3), pmdaFetch(3), pmdaDesc(3), pmdaText(3), pmdaInstance(3) et pmdaStore(3).

La structure interface contient également le domain du PMDA(3), qui est défini dans le fichier de configuration de pmcd(1). Le domain est utilisé pour initialiser les descripteurs de métriques et d'instances (voir pmdaInit(3)).

ATTENTION

Le PMDA doit utiliser PMDA_INTERFACE_2 ou une version ultérieure.

Une fois que pmdaDSO a été appelé, il est attendu que la structure pmdaInterface pointée par dispatch reste accessible aux routines de libpcp_pmda (ne pas la récupérer de la pile, ne pas la libérer ou la supprimer autrement, etc.). Si l'appelant a besoin de déplacer ou de relocaliser la structure pmdaInterface pour quelque raison que ce soit, alors après le déplacement, pmdaInterfaceMoved(3) doit être appelé pour rétablir l'intégrité interne de la structure pmdaInterface au nouvel emplacement avant que toute autre routine de libpcp_pmda ne soit appelée.

DIAGNOSTICS

Version incompatible de pmcd détectée
Lorsque pmcd(1) crée la structure pmdaInterface, le champ dispatch.comm.version est défini au protocole le plus élevé que pmcd(1) comprend. Ce message indique que le processus pmcd(1) ne comprend pas le protocole utilisé par pmdaDSO.
Impossible d'allouer de la mémoire pour la structure pmdaExt
De plus, dispatch->status est défini à une valeur inférieure à zéro.

VOIR AUSSI

pmcd(1), PMAPI(3), PMDA(3), pmdaDaemon(3), pmdaInit(3), pmdaInterfaceMoved(3) et pmdaText(3).
