PMDABONDING(1) Manuel des commandes générales PMDABONDING(1)

NOM

pmdabonding - Agent de domaine de métriques de performance (PMDA) pour les interfaces réseau agrégées (bonding) sous Linux

DESCRIPTION

pmdabonding est un agent de domaine de métriques de performance (PMDA) qui exporte les valeurs des métriques des interfaces réseau agrégées (bonding) du noyau Linux.

INSTALLATION

Installez le PMDA de bonding en utilisant le script d'installation en tant que root :

# cd $PCP_PMDAS_DIR/bonding
# ./Install

Pour désinstaller, les actions suivantes doivent être effectuées en tant que root :

# cd $PCP_PMDAS_DIR/bonding
# ./Remove

pmdabonding est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/bonding/Install
script d'installation de l'agent pmdabonding
$PCP_PMDAS_DIR/bonding/Remove
script d'annulation de l'installation de l'agent pmdabonding
$PCP_LOG_DIR/pmcd/bonding.log
fichier de journalisation par défaut pour les messages d'erreur de pmdabonding

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, tel que décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1), pmcd(1) et ifenslave(8).
