PMAGETLOG(3) Manuel des fonctions de bibliothèque PMAGETLOG(3)

NOM

pmaGetLog - lecture directe du prochain enregistrement à partir d'un fichier archive

C SYNTAXE

#include <pcp/pmapi.h>
#include <pcp/libpcp.h>
#include <pcp/archive.h>

int pmaGetLog(__pmArchCtl *acp,
int vol, __int32_t **rbuf);

cc ... -lpcp_archive -lpcp

AVERTISSEMENT

Cette documentation est destinée à un usage interne par les développeurs de Performance Co-Pilot (PCP).

Ces interfaces ne font pas partie des API PCP garanties pour rester fixes entre les versions et peuvent ne pas fonctionner, ou avoir des sémantiques différentes à l'avenir.

DESCRIPTION

Il s'agit d'une version réduite de __pmLogRead(3) de libpcp, qui lit le prochain enregistrement physique du volume vol de l'archive identifiée par acp.

Si vol est PM_LOG_VOL_META, alors le prochain enregistrement de métadonnées est lu, sinon le prochain enregistrement du volume de données vol est lu.

L'enregistrement est renvoyé dans rbuf qui est alloué ici ; l'appelant devra donc appeler free(3) lorsqu'il ne sera plus nécessaire.

La longueur de l'en-tête et de la fin de l'enregistrement est vérifiée, mais sinon rbuf n'est pas traité, et en particulier l'enregistrement reste en ordre d'octets réseau.

DIAGNOSTICS ET VALEURS DE RETOUR

La valeur de retour est 0 si tout va bien, sinon PM_ERR_EOL pour fin de fichier, sinon un autre code d'erreur inférieur à zéro.

VOIR AUSSI

free(3), pmaPutLog(3), PMAPI(3) et __pmLogRead(3).
