PMLOGSIZE(1) Manuel des commandes générales PMLOGSIZE(1)

NOM

pmlogsize - signaler les tailles pour des parties d'archives PCP

SYNOPIS

pmlogsize [-drv?] [-D débogage] [-x seuil] archive [...]

DESCRIPTION

pmlogsize affiche des informations sur la taille de l'index, des métadonnées et des sections de données d'une archive PCP (Performance Co-Pilot). La sortie est destinée à guider les améliorations du format d'encodage des archives pour les développeurs de PCP et à aider à réduire les fichiers de configuration de pmlogger(1) pour supprimer les métriques qui gonflent les archives PCP avec des données de faible valeur en production.

Les arguments archive peuvent être un mélange quelconque de noms des fichiers physiques d'une archive PCP ou du nom de base commun à tous les fichiers physiques composants d'une seule archive. Dans ce dernier cas, archive est remplacé par une liste de tous les noms de fichiers composants correspondants.

Notez que la sémantique est un peu différente des autres outils PCP, dans le sens où foo.meta signifie **uniquement** le fichier foo.meta, et non foo.index, foo.meta, foo.0, etc.

OPTIONS

Les options de ligne de commande disponibles sont :

-d, --detail
Active le rapport détaillé. Cela signifie l'espace par domaine d'instance dans un fichier de métadonnées et l'espace par métrique (pour les valeurs) dans un fichier de données.
-r, --replication
Affiche des informations supplémentaires sur les valeurs potentiellement répliquées dans le fichier de données et les instances répliquées dans le fichier de métadonnées. Cette option implique -d.
-x seuil, --threshold=seuil
Avec -d (ou -r), coupe le rapport après qu'au moins seuil pour cent de l'espace associé (valeurs de métriques ou domaines d'instances) a été rapporté. Le comportement par défaut équivaut à un seuil défini à **100**.
-v, --verbose
Active le mode verbeux. Cette option peut être fournie plus d'une fois pour une verbosité supplémentaire.
-?, --help
Affiche le message d'utilisation et quitte.

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active l'affichage de diagnostics supplémentaires sur stderr pour aider à dépanner les problèmes, bien que les informations soient parfois cryptiques et principalement destinées aux développeurs plutôt qu'aux utilisateurs finaux. débogage est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).
