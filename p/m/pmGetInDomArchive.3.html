NOM

pmGetInDomArchive - obtenir les identifiants d'instance pour un domaine d'instance de métriques de performance

C SYNTAXE

#include <pcp/pmapi.h>

int pmGetInDomArchive(pmInDom indom,
int **instlist, char ***namelist);

cc ... -lpcp

DESCRIPTION

À condition que le contexte actuel de l'interface de programmation d'applications de métriques de performance (PMAPI) soit associé à un ensemble d'archives, pmGetInDomArchive parcourra l'union de tous les métadonnées de domaine d'instance pour le domaine d'instance indom, et retournera via instlist les identifiants d'instance internes pour toutes les instances, et via namelist les identifiants externes complets pour toutes les instances.

Cette routine est une version spécialisée de la routine PMAPI plus générale pmGetInDom.

Le nombre d'instances trouvées est retourné comme valeur de la fonction (sinon moins de zéro pour indiquer une erreur).

La valeur du domaine d'instance indom est généralement extraite d'une structure pmDesc, suite à un appel à pmLookupDesc(3) pour une métrique de performance particulière.

Les listes résultantes d'identifiants d'instance (instlist et namelist), et les noms auxquels les éléments de namelist pointent, auront été alloués par pmGetInDomArchive avec deux appels à malloc(3), et il est de la responsabilité de l'appelant de libérer free(instlist) et free(namelist) pour libérer l'espace lorsqu'il n'est plus requis.

Lorsque le résultat de pmGetInDomArchive est inférieur à un, instlist et namelist sont indéfinis (aucun espace n'aura été alloué, et donc appeler free(3) est une très mauvaise idée).

DIAGNOSTICS

PM_ERR_NOTARCHIVE
le contexte PMAPI actuel n'est pas associé à un ensemble d'archives
PM_ERR_INDOM_LOG
indom n'est pas un identifiant de domaine d'instance défini pour l'ensemble des archives

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5). Les valeurs pour ces variables peuvent être obtenues par programmation en utilisant la fonction pmGetConfig(3).

VOIR AUSSI

PMAPI(3), pmGetConfig(3), pmGetInDom(3), pmLookupDesc(3), pmLookupInDomArchive(3), pmNameInDomArchive(3), pcp.conf(5) et pcp.env(5).
