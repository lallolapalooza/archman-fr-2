NOM

pmprintf, pmflush - imprimer une sortie formatée dans une fenêtre ou vers la sortie d'erreur standard

SYNTAXE C

#include <pcp/pmapi.h>

int pmprintf(const char *fmt, ... /*args*/);
int pmflush(void);

cc ... -lpcp

DESCRIPTION

La combinaison de pmprintf et pmflush produit une sortie soit dans une fenêtre xconfirm(1), soit sur le flux d'erreur standard, soit vers un fichier d'une manière similaire à fprintf(3). L'argument fmt est utilisé pour contrôler la conversion, le formatage et l'impression de la liste d'arguments args de longueur variable. La technique de sortie est contrôlée via une variable d'environnement.

pmprintf ajoute la chaîne de message formatée à un tampon interne partagé par les deux routines, sans produire réellement de sortie.

pmflush provoque l'affichage du tampon interne dans une fenêtre, son impression sur la sortie d'erreur standard, ou son envoi vers un fichier et la suppression du tampon interne.

DIAGNOSTICS

En cas de succès, pmprintf retourne le nombre de caractères transmis, tandis que pmflush retourne la valeur zéro en cas de succès.

Pour l'une ou l'autre routine, une valeur négative est retournée si une erreur est rencontrée, et celle-ci peut être passée à pmErrStr(3) pour obtenir le message d'erreur associé.

FICHIERS

pmprintf utilise la fonction mkstemp(3) pour créer un fichier temporaire. Ce fichier temporaire est supprimé lorsque pmflush est appelé.

ENVIRONNEMENT

La variable d'environnement PCP_STDERR contrôle la technique de sortie utilisée par pmflush :

Si PCP_STDERR n'est pas définie, le texte est écrit sur le flux stderr de l'appelant.

Si PCP_STDERR est définie à la valeur littérale réservée DISPLAY, le texte sera affiché sous forme de dialogue graphique en utilisant xconfirm(1).

Si PCP_STDERR est définie à toute autre valeur, pmflush interprète la valeur comme un nom de fichier et ajoute le texte à ce fichier. Le fichier est créé s'il n'existe pas déjà, et dans ce cas, si la création du fichier échoue, stderr est utilisé à la place).

VOIR AUSSI

pmdbg(1), fprintf(3), mkstemp(3), pmErrStr(3) et PMAPI(3).
