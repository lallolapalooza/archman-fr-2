NOM

pmdajson - PMDA JSON

DESCRIPTION

pmdajson est un agent de domaine de métriques de performance (PMDA) qui exporte des métriques à partir de sources arbitraires générant de la syntaxe JavaScript Object Notation (JSON).

Au moins une paire d'entrées JSON est requise pour que pmdajson fournisse des métriques aux clients PCP ; l'une décrivant les métadonnées des métriques et l'autre contenant les données de valeurs des métriques. Les métadonnées sont lues une fois à partir d'un fichier au démarrage du PMDA, tandis que les données sont lues chaque fois qu'une requête de valeurs de métriques est faite par un client PCP. Les données sont lues soit à partir d'un fichier JSON, soit d'une commande externe générant une sortie JSON. Plus d'une paire d'entrées JSON peut être utilisée pour supporter un nombre arbitraire de sources de métriques dans différents répertoires configurés.

La description globale du format JSON se trouve sur http://www.json.org/.

SOURCES DE DONNÉES JSON

pmdajson lit un fichier de configuration JSON obligatoire

$PCP_PMDAS_DIR/json/config.json

Ce fichier peut contenir les options PMDA suivantes en utilisant la syntaxe JSON :

  • directory_list
  • trusted_directory_list

pmdajson recherche dans les répertoires listés pour ces options des fichiers nommés metadata.json et (par défaut) data.json. Les fichiers de métadonnées JSON décrivent les noms des métriques, leurs types et d'autres détails des données JSON associées. Le nom du fichier de données JSON est configurable et peut également être une commande externe au lieu d'un fichier de données mis à jour périodiquement (par des outils externes).

Chaque paire de fichiers/commandes JSON trouvée forme une source de données JSON.

Par exemple, supposons le fichier de données JSON simple suivant qui contient les valeurs de deux métriques, l'une de type chaîne et l'autre numérique :

  {
    "string_value": "test, 1, 2, 3",
    "read_count": 0
  }

Pour ces métriques, le fichier de métadonnées requis par pmdajson serait :

  {
    "metrics": [
      {
        "name": "string_value",
        "pointer": "/string_value",
        "type": "string"
      },
      {
        "name": "read_count",
        "pointer": "/read_count",
        "type": "integer",
        "description": "Nombre de lectures de valeurs"
      }
    ]
  }

Pour plus de détails sur le format des métadonnées JSON et les options, consultez le fichier README inclus dans l'installation de pmdajson.

MODÈLE DE SÉCURITÉ

Les sources de données JSON listées pour l'option directory_list ne sont pas fiables, ce qui signifie que si des commandes externes sont utilisées pour générer les données JSON nécessaires, ces commandes sont exécutées sous l'utilisateur nobody.

Les sources de données JSON listées pour l'option trusted_directory_list sont fiables, ce qui signifie que si des commandes externes sont utilisées pour générer les données JSON nécessaires, ces commandes sont exécutées sous l'utilisateur root.

Pour plus de détails sur la sécurité et sur l'exécution de commandes externes, consultez le fichier README inclus dans l'installation de pmdajson.

INSTALLATION

Installez le PMDA JSON en utilisant le script d'installation en tant que root :

# cd $PCP_PMDAS_DIR/json
# ./Install

Pour désinstaller, faites ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/json
# ./Remove

pmdajson est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/json/README
documentation supplémentaire pour les fichiers JSON utilisés par pmdajson
$PCP_PMDAS_DIR/json/config.json
fichier de configuration pour l'agent pmdajson
$PCP_PMDAS_DIR/json/Install
script d'installation pour l'agent pmdajson
$PCP_PMDAS_DIR/json/Remove
script d'annulation d'installation pour l'agent pmdajson
$PCP_LOG_DIR/pmcd/json.log
fichier journal par défaut pour les messages de l'agent pmdajson

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).
