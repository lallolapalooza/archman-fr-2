PMDAHELP(3) Manuel des fonctions de bibliothèque PMDAHELP(3)

NOM

pmdaOpenHelp, pmdaGetHelp, pmdaGetInDomHelp, pmdaCloseHelp - prise en charge du texte d'aide pour un PMDA

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaOpenHelp(const char *fname);
char *pmdaGetHelp(int handle, pmID pmid, int type);
char *pmdaGetInDomHelp(int handle, pmInDom indom, int type);
void pmdaCloseHelp(int handle);

cc ... -lpcp_pmda -lpcp

DESCRIPTION

Dans le cadre de l'API du domaine de métriques de performance (PMDA) (voir PMDA(3)), ce groupe de routines est utilisé pour implémenter le traitement des informations d'aide des métriques d'un PMDA.

Ces routines sont en réalité destinées à un usage interne et ne devraient pas avoir besoin d'être appelées directement depuis le code d'un PMDA.

Bref, le nom de base du fichier texte d'aide (tel que créé par newhelp(1)) est passé via une option de ligne de commande -h pour un PMDA démon ou en tant qu'argument de pmdaDaemon(3) ou pmdaDSO(3). Ensuite, pmdaOpenHelp est appelée depuis pmdaInit(3) et retourne un handle qui est utilisé dans les appels ultérieurs pour identifier une collection de texte d'aide particulière (chaque PMDA n'a généralement qu'une seule collection de ce type).

Les requêtes de texte d'aide sont transmises à pmdaText(3) qui appelle pmdaGetHelp ou pmdaGetInDomHelp selon les besoins.

À l'exception des cas d'erreur dans pmdaOpenHelp, pmdaCloseHelp n'est pas appelée.

AVERTISSEMENT

Le PMDA doit utiliser PMDA_INTERFACE_2 ou une version ultérieure, comme spécifié dans l'appel à pmdaDSO(3) ou pmdaDaemon(3).

DIAGNOSTICS

pmdaOpenHelp retourne une valeur négative en cas d'échec, appropriée pour être décodée avec pmErrStr(3). pmdaGetHelp et pmdaGetInDomHelp retournent NULL si le texte d'aide correspondant n'existe pas.

VOIR AUSSI

newhelp(1), PMAPI(3), PMDA(3), pmdaDaemon(3), pmdaDSO(3), pmdaInit(3), pmdaText(3) et pmErrStr(3).
