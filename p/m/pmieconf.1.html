PMIECONF(1) Manuel des commandes générales PMIECONF(1)

NOM

pmieconf - affiche et configure les variables de règles configurables de pmie

SYNOPSIS

pmieconf [-cFv?] [-f fichier] [-r chemin_regles] [commande [args...]]

DESCRIPTION

pmieconf est un utilitaire permettant de visualiser et de configurer les variables des règles généralisées de pmie(1). L'ensemble des règles généralisées est lu à partir de chemin_regles, et le fichier de sortie fichier produit par pmieconf est un fichier d'entrée valide pour pmie.

OPTIONS

Les options de ligne de commande disponibles sont les suivantes :

-c
Lorsqu'il est exécuté à partir de processus de configuration pmie automatisés, cette option est utilisée pour ajouter un message spécifique et un horodatage indiquant qu'il s'agit de ce cas. Sauf indication contraire du drapeau -f, le fichier de configuration par défaut à écrire ou mettre à jour lorsque le drapeau -c est donné et que pmieconf est exécuté par l'utilisateur root, est $PCP_VAR_DIR/config/pmie/config.default. C'est également le fichier de configuration par défaut utilisé par le service pmie, voir pmie_daily(1). Ce drapeau n'est pas approprié lors de l'utilisation de l'outil de manière interactive.
-f fichier, --config=fichier
Toutes les modifications de règles résultant de la manipulation des valeurs de variables par pmieconf seront écrites dans fichier. La valeur par défaut de fichier dépend de l'ID utilisateur - pour l'utilisateur root (lorsque le drapeau -c n'est PAS également donné, voir ci-dessus), le fichier est $PCP_SYSCONF_DIR/pmie/config.default. Pour les autres utilisateurs, la valeur par défaut est $HOME/.pcp/pmie/config.pmie.
-F, --force
Force la création (ou la mise à jour) du fichier de sortie fichier de pmieconf, après quoi pmieconf se quitte immédiatement.
-r chemin_regles, --rules=chemin_regles
Permet de changer la source des règles généralisées pmie - chemin_regles est une liste séparée par des deux-points de fichiers de règles pmieconf(5) et/ou de sous-répertoires. La valeur par défaut pour chemin_regles est $PCP_VAR_DIR/config/pmieconf. L'utilisation de cette option remplace la variable d'environnement PMIECONF_PATH qui a une fonction similaire.
-v, --verbose
Active le mode verbeux. Les variables associées seront affichées. C'est la liste complète des variables qui affectent une règle donnée (par défaut, les variables globales ne sont pas affichées avec la règle).
-?, --help
Affiche le message d'utilisation et quitte.

Les commandes pmieconf permettent d'afficher ou de modifier des informations relatives aux différentes règles et variables configurables. Si aucune commande pmieconf n'est présentée sur la ligne de commande, pmieconf invite l'utilisateur à entrer des commandes de manière interactive.

LANGAGE DES COMMANDES

Le langage de commandes pmieconf est décrit ici :

aide [ { . | all | global | <regle> | <groupe> } [<variable>] ]
Sans arguments, la commande aide affiche la syntaxe de toutes les commandes pmieconf disponibles. Avec un argument, une description d'une ou plusieurs des règles généralisées est affichée. Avec deux arguments, une description d'une variable spécifique relative à une ou plusieurs des règles généralisées est affichée.
regles [ activées | désactivées ]
Affiche le nom et un bref résumé de toutes les règles généralisées trouvées sur chemin_regles. Chaque nom de règle peut être utilisé à la place du mot-clé <regle> dans la description de la syntaxe de cette commande. Les options activées et désactivées peuvent être utilisées pour filtrer l'ensemble des règles affichées afin de n'inclure que celles qui sont activées ou désactivées respectivement.
groupes
Affiche le nom de tous les groupes de règles trouvés sur chemin_regles. Chaque nom de groupe peut être utilisé à la place du mot-clé <groupe> dans la description de cette syntaxe de commande, ce qui applique la commande à toutes les règles du groupe de règles.
statut
Affiche les informations de statut relatives à la session pmieconf actuelle, y compris une liste des processus pmie en cours d'exécution qui utilisent actuellement fichier.
activer { . | all | <regle> | <groupe> }
Active la règle ou le groupe de règles spécifié(e). Une règle activée est une règle qui sera incluse dans le fichier de configuration pmie généré par pmieconf. Toutes les "actions" activées seront ajoutées au "prédicat" de la règle, d'une manière conforme à la syntaxe pmie (les "actions" peuvent être visualisées en utilisant la commande lister global, décrite ci-dessous).
désactiver { . | all | <regle> | <groupe> }
Désactive la règle ou le groupe de règles spécifié(e). Si la règle était précédemment activée, elle sera supprimée du fichier de configuration pmie généré par pmieconf, et donc plus évaluée lorsque pmie sera redémarré (l'utilisation de pmieconf n'affecte pas les processus pmie existants utilisant fichier).
lister { . | all | global | <regle> | <groupe> } [<variable>]
Affiche les valeurs d'une variable de règle spécifique ; ou pour toutes les variables d'une règle, d'un groupe de règles, de toutes les règles, ou des variables globales.
modifier { . | all | global | <regle> | <groupe> } <variable> <valeur>
Active, désactive ou modifie autrement la valeur d'une ou plusieurs variables de règle. Cette valeur doit être cohérente avec le type de la variable, qui peut être déduit du format de la valeur affichée - par exemple, les chaînes de caractères seront entourées de guillemets doubles, les pourcentages auront le symbole '%' ajouté, etc. Notez que certaines variables de règle ne peuvent pas être modifiées via pmieconf - "prédicat" et "aide", par exemple.
annuler { . | all | global | <regle> | <groupe> } [<variable>]
Applicable uniquement à une variable dont la valeur a été modifiée - cette commande revient simplement à la valeur par défaut pour la variable donnée.
quitter
Sauvegarde les modifications apportées à fichier puis quitte pmieconf.
abandonner
Quitte pmieconf immédiatement sans sauvegarder les modifications apportées à fichier.

Chacune des commandes ci-dessus peut être raccourcie en utilisant simplement le premier caractère du nom de la commande, ainsi que " ?" pour l'aide.

L'utilisation du mot-clé all provoque l'application de la commande à toutes les règles. Le mot-clé global fait référence aux variables qui sont appliquées à chaque règle. Ces variables peuvent être modifiées globalement ou localement, par exemple :

  pmieconf> modifier global delta "5 minutes"
  pmieconf> modifier memoire delta "1 minute"

ce qui fait que toutes les règles sont maintenant évaluées toutes les cinq minutes, sauf pour les règles du groupe "mémoire" qui doivent être évaluées une fois par minute.

Le caractère "." est spécial pour pmieconf - il fait référence à la dernière valeur utilisée avec succès de all, global, <regle> ou <groupe>.

EXEMPLES

Spécifier que toutes les règles du groupe "mémoire" doivent être évaluées :

  pmieconf> modifier memoire activée oui

Changer d'avis et revenir à l'utilisation des seules règles "mémoire" qui étaient activées par défaut :

  pmieconf> annuler memoire activée

Spécifier que les notifications des règles qui s'évaluent à vrai doivent être envoyées à syslogd(1) :

  pmieconf> modifier global syslog_action oui

Spécifier que les règles du groupe "per_cpu" doivent utiliser un délai de garde différent des autres règles :

pmieconf(5) | pmie(1) | pmie_daily(1)

pmieconf(5) — Performance Co-Pilot — man pages

COMMAND LANGUAGE

The pmieconf utility uses a simple command language to interact with the Performance Metrics Investigator Daemon (PMID) configuration.

pmieconf commands

The available commands are:

append
Append a new rule definition.
copy
Copy an existing rule definition.
delete
Delete a rule definition.
dump
Dump the current configuration.
help
Display help for a given command or variable.
list
List existing rule definitions.
modify
Modify an existing rule definition.
quit
Exit the pmieconf utility.
rename
Rename a rule definition.
set
Set a global configuration variable.
source
Read and execute commands from a file.

EXAMPLES

To display help for the global variable holdoff:

  pmieconf> help global holdoff
    rule: global  [generic parameters applied to all rules]
     var: holdoff
    help: Once the predicate is true and the action is executed,
	  this variable allows suppression of further action
	  execution until the specified interval has elapsed.
	  A value of zero enables execution of the action if
	  the rule predicate is true at the next sample. Default
	  units are seconds and common units are "second", "sec",
	  "minute", "min" and "hour".
  pmieconf> modify per_cpu holdoff "1 hour"

Lower the threshold associated with a particular variable for a specified rule:

  pmieconf> l cpu.syscall predicate
    rule: cpu.syscall  [High aggregate system call rate]
      predicate =
	      some_host (
		  ( kernel.all.syscall $hosts$ )
		    > $threshold$ count/sec * hinv.ncpu $hosts$
	      )
  pmieconf> m . threshold 7000
  pmieconf> l . threshold
    rule: cpu.syscall  [High aggregate system call rate]
	    threshold = 7000

FILES

$PCP_VAR_DIR/config/pmieconf/*/*
generalized system resource monitoring rules
$PCP_SYSCONF_DIR/pmie/config.pmie
default super-user settings for system resource monitoring rules
$HOME/.pcp/pmie/config.pmie
default user settings for system resource monitoring rules

ENVIRONMENT

The environment variable PMIECONF_PATH has a similar function to the -r option described above, and if set will be used provided no -r option is presented.

PCP ENVIRONMENT

Environment variables with the prefix PCP_ are used to parameterize the file and directory names used by PCP. On each installation, the file /etc/pcp.conf contains the local values for these variables. The $PCP_CONF variable may be used to specify an alternative configuration file, as described in pcp.conf(5).
