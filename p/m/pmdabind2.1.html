PMDABIND2(1) Manuel des commandes générales PMDABIND2(1)

NOM

pmdabind2 - Agent de domaine de métriques de performance BIND (PMDA)

DESCRIPTION

Ce PMDA extrait les données de performance de BIND (Berkeley Internet Name Domain). Il permet la collecte de la plupart des métriques statistiques depuis le serveur Bind version 9 ou plus récent, incluant :

•
statistiques mémoire globales
•
statistiques globales par requête (requêtes générales, réponses EDNS/tronquées, messages Update/Notify/AXFR/IXFR)
•
statistiques d'erreurs globales (Rejetées, SERVFAIL, erreurs Update/XFR ...)
•
statistiques globales par protocole de transport, EDNS et par version du protocole IP
•
statistiques du résolveur (succès, erreurs, temps aller-retour dans plusieurs plages)
•
statistiques détaillées par socket concernant le protocole de transport et la version IP, y compris les erreurs
•
statistiques détaillées par descripteur de fichier, y compris les erreurs

Le PMDA effectue une collecte par seconde de l'ensemble des données (148 métriques dans l'environnement de test) avec des exigences modestes (2% d'utilisation CPU sur Intel i7-4700MQ @2.4 GHz, environ 30 Mo de RAM).

Si plus d'une requête par seconde est effectuée, les valeurs mises en mémoire cache sont utilisées afin de ne pas surcharger l'interface statistique du serveur Bind.

INSTALLATION

Configurer BIND pour exporter les statistiques XML via son interface REST. Ceci nécessite la configuration de BIND pour activer l'exportation des statistiques localement (au minimum).

statistics-channels {
    inet 127.0.0.1 port 8080 allow { 127.0.0.1; };
}
options { zone-statistics yes; }
# ./Install

Le nom d'hôte (localhost), le port (8080 ci-dessus) et d'autres informations de configuration doivent être spécifiés à la fois dans le fichier de configuration BIND et dans le fichier $PCP_PMDAS_DIR/bind2/bind2.conf.

# cd $PCP_PMDAS_DIR/bind2
# [ éditer bind2.conf ]
  host=localhost.localdomain:8080

Une fois cela configuré, vous pouvez accéder aux noms et valeurs des métriques de performance bind2 en faisant ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/bind2
# ./Install

Pour désinstaller, les actions suivantes doivent être effectuées en tant que root :

# cd $PCP_PMDAS_DIR/bind2
# ./Remove

pmdabind2 est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou retiré.

FICHIERS

$PCP_PMDAS_DIR/bind2/bind2.conf
fichier de configuration obligatoire listant les instances bind2 surveillées
$PCP_PMDAS_DIR/bind2/Install
script d'installation de l'agent pmdabind2
$PCP_PMDAS_DIR/bind2/Remove
script d'annulation d'installation de l'agent pmdabind2
$PCP_LOG_DIR/pmcd/bind2.log
fichier journal par défaut pour les messages d'erreur de pmdabind2

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).
