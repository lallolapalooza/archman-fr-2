pmSearchTextSuggest(3)

PMSEARCHTEXTSUGGEST(3) Manuel des fonctions de bibliothèque PMSEARCHTEXTSUGGEST(3)

NOM

pmSearchTextSuggest - rechercher des suggestions de noms de métriques ou d'instances à l'aide des services de recherche PCP

C SYNTAXE

#include <pcp/pmwebapi.h>

int pmSearchTextSuggest(pmSearchSettings *settings,
pmSearchTextRequest *request, void *arg);

cc ... -lpcp_web

DESCRIPTION

Exécute une recherche plein texte pour les noms de métriques ou d'instances adaptés à l'auto-complétion, spécifiés par request :

query
Chaîne de requête qui sera utilisée pour la recherche.
count
Limite le nombre de résultats. Par défaut, 10.

Les mots de moins de 2 caractères sont omis.

Cette recherche correspond aux termes dans le nom d'entité qui ont soit le préfixe query, soit sont à une distance de Levenshtein de 1, les premiers ayant une priorité légèrement supérieure aux seconds.

Chaque entité correspondante à la request ci-dessus sera passée à la fonction de rappel on_text_result fournie par settings.

DIAGNOSTICS

Cette fonction retourne toujours zéro en cas de succès. En cas d'échec, un code d'erreur négatif PMAPI est retourné.

VOIR AUSSI

pmproxy(1), pmlogger(1), pmsearch(1), pmSearchSetup(3), PMAPI(3) et PMWEBAPI(3).
