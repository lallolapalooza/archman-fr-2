PMDAPMID(3) Manuel des fonctions de bibliothèque PMDAPMID(3)

NOM

pmdaPMID - traduire un nom de métrique de performance dynamique en un PMID

SYNTAXE EN C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaPMID(char *name, pmID *pmid, pmdaExt *pmda);

cc ... -lpcp_pmda -lpcp

DESCRIPTION

Dans le cadre de l'API du domaine des métriques de performance (PMDA) (voir PMDA(3)), pmdaPMID est le rappel générique pour traduire un nom de métrique dynamique name en un PMID (pmid).

Étant donné que l'implémentation des métriques de performance dynamiques nécessite un support PMDA spécifique, et que cette fonctionnalité est un composant optionnel d'un PMDA (la plupart des PMDA ne supportent PAS les métriques de performance dynamiques), pmdaPMID est une implémentation squelette qui renvoie PM_ERR_NAME.

Un PMDA qui supporte les métriques de performance dynamiques fournira un rappel privé qui remplacera pmdaPMID (par affectation à version.four.pmid de la structure pmdaInterface) et implémentera la traduction d'un nom de métrique de performance dynamique en son pmid associé.

AVERTISSEMENT

Le PMDA doit utiliser PMDA_INTERFACE_4 ou une version ultérieure, comme spécifié dans l'appel à pmdaDSO(3) ou pmdaDaemon(3).

DIAGNOSTICS

pmdaPMID renvoie PM_ERR_NAME si le nom n'est pas reconnu ou ne peut être traduit, sinon renvoie 0.

VOIR AUSSI

PMAPI(3), PMDA(3), pmdaDaemon(3), pmdaDSO(3), pmdaMain(3) et pmLookupName(3).
