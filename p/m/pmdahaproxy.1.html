NOM

pmdahaproxy - Agent du domaine de métriques HAProxy

DESCRIPTION

pmdahaproxy est un agent du domaine de métriques (PMDA) qui extrait les données de performance en direct du socket de statistiques HAProxy ou de l'URL.

Par défaut, le socket de statistiques HAProxy est utilisé pour récupérer la métrique, mais si l'option URL optionnelle est définie (voir ci-dessous), l'URL HAProxy est utilisée à la place.

Consultez la documentation HAProxy pour une description détaillée de chaque métrique.

INSTALLATION

pmdahaproxy lit un fichier de configuration optionnel de style ini

$PCP_PMDAS_DIR/haproxy/haproxy.conf

Ce fichier peut contenir dans sa section [pmda] des valeurs remplaçant les options PMDA suivantes :

•
user
•
socket

Par défaut, root et /var/lib/haproxy/stats sont utilisés comme valeurs pour ces options, respectivement.

La section peut également contenir les paramètres suivants :

  • url
  • auth
  • pass

Lorsque l'option url est définie, une connexion via URL à HAProxy est utilisée. pmdahaproxy attend des données CSV de l'URL HAProxy ; un exemple d'URL compatible est http://127.0.0.1:9000/?stats;csv.

Notez que le socket de statistiques HAProxy et/ou l'URL doivent être activés séparément dans le fichier de configuration HAProxy ; veuillez vous reporter à la documentation de configuration HAProxy pour plus de détails. Selon le système et la configuration HAProxy, l'utilisation d'un utilisateur non root peut également être possible, en particulier avec les connexions basées sur l'URL.

Une fois la configuration nécessaire prête, vous pouvez tester la connexion et installer le PMDA pour activer l'accès aux noms et valeurs des métriques de performance HAProxy. Pour installer, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/haproxy
# ./connect
# ./Install

Pour désinstaller, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/haproxy
# ./Remove

pmdahaproxy est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove informent pmcd(1) lorsque l'agent est installé ou désinstallé.

FICHIERS

$PCP_PMDAS_DIR/haproxy/haproxy.conf
fichier de configuration de l'agent pmdahaproxy
$PCP_PMDAS_DIR/haproxy/connect
utilitaire de test de connexion utilisant la configuration de l'agent pmdahaproxy
$PCP_PMDAS_DIR/haproxy/Install
script d'installation de l'agent pmdahaproxy
$PCP_PMDAS_DIR/haproxy/Remove
script d'annulation d'installation de l'agent pmdahaproxy
$PCP_LOG_DIR/pmcd/haproxy.log
fichier journal par défaut pour les messages de l'agent pmdahaproxy

ENVIRONNEMENT PCP

Les variables d'environnement commençant par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1), haproxy(1) et pmcd(1).
