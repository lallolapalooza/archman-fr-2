PMNOTIFYERR(3) Manuel des fonctions de bibliothèque PMNOTIFYERR(3)

NOM

pmNotifyErr, pmSyslog - gestion standard des messages d'erreur

SYNTAXE C

#include <pcp/pmapi.h>

void pmNotifyErr(int priority, const char *message, ...);
void pmSyslog(int onoff);

cc ... -lpcp

DESCRIPTION

Ces routines fournissent une gestion standard des messages d'erreur depuis l'intérieur des démons de Performance Co-Pilot (PCP) et des agents de domaine de métriques de performance (PMDA).

pmNotifyErr est une fonction de style printf(3) qui formatera message (et tous les arguments suivants) avec un préfixe incluant la date et l'heure actuelles de ctime(3), le nom de l'application de pmGetProgname(3), l'identifiant du processus de getpid(2) et la priority.

priority doit être l'un des macros de niveau LOG_ définis pour syslog(3). Le plus souvent, il s'agirait de LOG_INFO, LOG_WARNING ou LOG_ERR.

pmNotifyErr écrit sur la sortie d'erreur standard, qui pour les démons et les PMDA a très probablement été redirigée vers un fichier journal en utilisant pmOpenLog(3). De plus, message (et tous les arguments suivants) peut être transmis à syslog(3) si pmSyslog a précédemment été appelée avec onoff ayant une valeur non nulle.

La transmission à syslog(3) peut être désactivée à tout moment en appelant pmSyslog avec onoff ayant une valeur nulle, et c'est l'état de départ pour chaque application PCP.

Dans le style de syslog(3), message n'a pas besoin d'inclure un caractère de nouvelle ligne de fin (un sera ajouté si nécessaire).

VOIR AUSSI

getpid(2), ctime(3), PMAPI(3), pmGetProgname(3), pmOpenLog(3), printf(3) et syslog(3).
