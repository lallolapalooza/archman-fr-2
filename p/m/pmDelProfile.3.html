PMDELPROFILE(3) Manuel des fonctions de bibliothèque PMDELPROFILE(3)

NOM

pmDelProfile - supprimer des instances du profil d'instance PMAPI actuel

SYNTAXE C

#include <pcp/pmapi.h>

int pmDelProfile(pmInDom indom, int numinst, int *instlist);

cc ... -lpcp

DESCRIPTION

L'ensemble des instances pour les métriques de performance retournées par un appel à pmFetch(3) peut être filtré ou restreint à l'aide d'un profil d'instance. Il existe un profil d'instance pour chaque contexte que l'application crée auprès de l'API d'application des métriques de performance (PMAPI), et chaque profil d'instance peut inclure des instances d'un ou plusieurs domaines d'instance (voir pmLookupDesc(3)).

pmDelProfile peut être utilisé pour supprimer des spécifications d'instance du profil d'instance du contexte PMAPI actuel.

Dans la variante la plus simple, la liste des instances identifiées par l'argument instlist pour le domaine d'instance indom est supprimée du profil d'instance. La liste des identificateurs d'instance contient numinst valeurs.

La valeur indom serait normalement extraite d'un appel à pmLookupDesc(3) pour une métrique de performance particulière, et les instances dans instlist seraient typiquement déterminées par des appels à pmGetInDom(3) ou pmLookupInDom(3).

Si indom est égal à PM_INDOM_NULL et numinst est zéro, alors tous les domaines d'instance sont sélectionnés pour la suppression. Si instlist est NULL, alors toutes les instances dans les domaines sélectionnés sont supprimées du profil.

Pour désactiver toutes les instances disponibles dans tous les domaines, utilisez pmDelProfile(PM_INDOM_NULL, 0, NULL). C'est la seule situation dans laquelle indom peut être PM_INDOM_NULL.

MISE EN GARDE

Il est possible de supprimer des domaines d'instance non existants et des instances non existantes d'un profil d'instance. Aucune des routines qui utilisent le profil d'instance n'émettra jamais d'erreur si vous le faites. Le coût de la vérification, lorsque la vérification est possible, dépasse les bénéfices éventuels.

DIAGNOSTICS

PM_ERR_PROFILESPEC
indom était PM_INDOM_NULL et instlist n'était pas vide

VOIR AUSSI

pmAddProfile(3), PMAPI(3), pmFetch(3), pmGetInDom(3), pmLookupDesc(3), pmLookupInDom(3), pmNewContext(3), pmUseContext(3) et pmWhichContext(3).
