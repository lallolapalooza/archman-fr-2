PMCONFIG(1) Manuel des commandes générales PMCONFIG(1)

NOM

pmconfig - paramètres de configuration de Performance Co-Pilot

SYNTAXE

$PCP_BINADM_DIR/pmconfig [-alLs?] [nom ...]

DESCRIPTION

pmconfig affiche les valeurs de certains ou de tous les paramètres de configuration de l'installation locale de la boîte à outils Performance Co-Pilot.

OPTIONS

Les options de ligne de commande disponibles sont :

-a, --all
Rapporte tous les paramètres de configuration dans le format par défaut.
-l, --list
Synonyme de l'option -a, rapporte le même format (par défaut).
-L, --library
Cette option change le mode de rapport par défaut afin que les capacités de la bibliothèque PCP soient rapportées, plutôt que l'environnement PCP.
-s, --shell
Un format de sortie adapté à l'importation dans des scripts shell, qui garantit que les informations de configuration sont mises entre guillemets et précédées d'une instruction d'exportation. Lorsqu'il ne rapporte pas les capacités de la bibliothèque, ce mode produira une instruction qui ne remplacera pas un paramètre existant dans l'environnement pour les variables de configuration PCP.
-?, --help
Affiche le message d'utilisation et quitte.

Dans le mode de fonctionnement par défaut, pmconfig est souvent utilisé en conjonction avec la variable d'environnement $PCP_DIR pour configurer des scripts exécutés sous le système d'exploitation Windows, où la hiérarchie du système de fichiers diffère grandement de celle des systèmes d'exploitation basés sur Linux/UNIX.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

pmGetConfig(3), pcp.conf(5) et pcp.env(5).
