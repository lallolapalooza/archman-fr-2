PMTRIMNAMESPACE(3) Manuel des fonctions de bibliothèque PMTRIMNAMESPACE(3)

NOM

pmTrimNameSpace - élaguer un espace de noms de métriques de performance

SYNTAXE C

#include <pcp/pmapi.h>

int pmTrimNameSpace(void);

cc ... -lpcp

DESCRIPTION

Dans certains cas (rares), il est utile d'élaguer l'espace de noms des métriques de performance (PMNS) pour correspondre aux métriques disponibles.

Le PMNS par défaut accessible à un client de l'API des métriques de performance (PMAPI) est fourni par le contexte PMAPI actuel :

  • pour un contexte PMAPI de type PM_CONTEXT_HOST, le PMNS est fourni par pmcd(1) sur l'hôte associé et aucun élagage n'est requis
  • pour un contexte PMAPI de type PM_CONTEXT_ARCHIVE, le PMNS est stocké dans l'archive Performance Co-Pilot (PCP) associée et aucun élagage n'est requis
  • pour un contexte PMAPI de type PM_CONTEXT_LOCAL, lors du premier appel à la PMAPI nécessitant un accès au PMNS, celui-ci est chargé depuis l'emplacement local par défaut $PCP_VAR_DIR/pmns/root (ou $PMNS_DEFAULT) et aucun élagage n'est requis.

Si le PMNS par défaut est en vigueur, l'appel à pmTrimNameSpace est une opération vide (no-op) et retourne zéro sans modifier le PMNS.

Les clients PMAPI ont également la possibilité de remplacer le PMNS par défaut en chargeant un PMNS local à partir d'un fichier (voir PMNS(5) pour le format) en appelant pmLoadASCIINameSpace(3) ou pmLoadNameSpace(3), et c'est là que certains élagages de PMNS *peuvent* être utiles.

Si un PMNS local est en vigueur lors de l'appel à pmTrimNameSpace, la première action consiste à restaurer le PMNS à l'état qu'il avait à la fin du dernier appel à pmLoadASCIINameSpace(3) ou pmLoadNameSpace(3), de sorte que les effets des appels consécutifs à pmTrimNameSpace ne soient **pas** cumulatifs.

Les actions ultérieures de pmTrimNameSpace dépendent du type du contexte PMAPI actuel.

  • Pour un contexte de type PM_CONTEXT_ARCHIVE, le PMNS local est élagué pour exclure les métriques pour lesquelles aucune description ne peut être trouvée dans l'archive PCP. Le PMNS est ensuite élagué pour supprimer les sous-arborescences vides qui ne contiennent aucune métrique de performance. Comme les archives PCP contiennent généralement un sous-ensemble des métriques nommées dans un PMNS, pmTrimNameSpace élague effectivement le PMNS de l'application pour ne contenir que les noms des métriques de l'archive.
  • Pour un contexte de type PM_CONTEXT_HOST ou PM_CONTEXT_LOCAL, aucune action supplémentaire n'est requise.

En cas de succès, pmTrimNameSpace retourne zéro.

DIAGNOSTICS

PM_ERR_NOPMNS
il y a eu un problème antérieur lors de l'établissement du PMNS pertinent
PM_ERR_NOCONTEXT
le contexte PMAPI actuel est invalide

VOIR AUSSI

pmlogger(1), PMAPI(3), pmLoadASCIINameSpace(3), pmLoadNameSpace(3), pmNewContext(3) et PMNS(5).
