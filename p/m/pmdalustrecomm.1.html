PMDALUSTERCOMM(1) Manuel général des commandes PMDALUSTERCOMM(1)

NOM

pmdalustrecomm - agent de domaine de métriques de performance de communication du système de fichiers Lustre (PMDA)

SYNTAXE

$PCP_PMDAS_DIR/lustrecomm/pmdalustrecomm [-D debug] [-d domaine] [-l logfile] [-U username]

DESCRIPTION

pmdalustrecomm est un agent de domaine de métriques de performance (PMDA) qui extrait des métriques de performance du système de fichiers procfs Linux concernant l'état de divers aspects du système de fichiers Lustre.

Le PMDA lustrecomm exporte des métriques axées sur la communication distribuée dans le système de fichiers, y compris des métriques liées aux timeouts, aux pertes de réseau, aux informations d'envoi/réception et aux longueurs de routes. Cependant, il couvre également l'utilisation de la mémoire de certains composants du système de fichiers Lustre.

Une brève description des options de ligne de commande de pmdalustrecomm suit :

-d
Il est absolument crucial que le numéro de domaine des métriques de performance spécifié ici soit unique et cohérent. C'est-à-dire que domaine doit être différent pour chaque PMDA sur un hôte, et le même numéro de domaine doit être utilisé pour le même PMDA sur tous les hôtes.
-l
Emplacement du fichier journal. Par défaut, un fichier journal nommé lustrecomm.log est écrit dans le répertoire courant de pmcd(1) lorsque pmdalustrecomm est démarré, c'est-à-dire $PCP_LOG_DIR/pmcd. Si le fichier journal ne peut pas être créé ou n'est pas accessible en écriture, la sortie est redirigée vers la sortie d'erreur standard.
-U
Compte utilisateur sous lequel exécuter l'agent. Par défaut, c'est le compte non privilégié "pcp" dans les versions actuelles de PCP, mais dans les versions antérieures, le compte superutilisateur ("root") était utilisé par défaut.

INSTALLATION

Si vous souhaitez accéder aux noms, aux textes d'aide et aux valeurs des métriques de performance lustrecomm, faites ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/lustrecomm
# ./Install

Si vous souhaitez annuler l'installation, faites ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/lustrecomm
# ./Remove

pmdalustrecomm est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMCDCONF_PATH
options de ligne de commande utilisées pour lancer pmdalustrecomm
$PCP_PMDAS_DIR/lustrecomm/help
fichier d'aide par défaut pour les métriques lustrecomm
$PCP_PMDAS_DIR/lustrecomm/Install
script d'installation pour l'agent pmdalustrecomm
$PCP_PMDAS_DIR/lustrecomm/Remove
script d'annulation d'installation pour l'agent pmdalustrecomm
$PCP_LOG_DIR/pmcd/lustrecomm.log
fichier journal par défaut pour les messages d'erreur et autres informations de pmdalustrecomm

ENVIRONNEMENT PCP

Les variables d'environnement commençant par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur la sortie d'erreur standard (stderr) pour aider à résoudre les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

VOIR AUSSI

PCPIntro(1), pmcd(1), pcp.conf(5) et pcp.env(5).
