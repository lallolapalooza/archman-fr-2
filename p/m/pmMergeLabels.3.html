PMMERGELABELS(3) Manuel des fonctions de bibliothèque PMMERGELABELS(3)

NOM

pmMergeLabels, pmMergeLabelSets - fusionner des ensembles d'étiquettes de métriques de performance

SYNOPSIS C

#include <pcp/pmapi.h>

int pmMergeLabels(char **sets,
int nsets, char *buffer, int length);

int pmMergeLabelSets(pmLabelSet **sets,
int nsets, char *buffer, int length, int (*filter) (const pmLabel *, const char *, void *), void *arg);

cc ... -lpcp

SYNOPSIS PYTHON

from pcp import pmapi

buffer = pmapi.pmContext().pmMergeLabels(sets)
buffer = pmapi.pmContext().pmMergeLabelSets(sets, filter)

DESCRIPTION

pmMergeLabels prend plusieurs (nsets) ensembles d'étiquettes de métriques de performance sets et les fusionne en un seul buffer résultat de length octets. Les deux, les ensembles d'entrée sets et le buffer résultant, sont des paires nom:valeur au format "JSONB" décrit dans pmLookupLabels(3).

L'interface pmMergeLabelSets sert le même objectif, mais permet de fusionner des ensembles indexés d'étiquettes. Le format de la structure de données pmLabelSet est décrit en détail dans pmLookupLabels(3).

Bien que les noms puissent se répéter dans les ensembles d'étiquettes fournis, les noms en double ne sont pas autorisés dans le buffer final. Tous les noms d'étiquettes apparaissant dans plus d'un des ensembles d'étiquettes d'entrée sont réduits à un seul en utilisant les règles décrites dans la section "PRÉCÉDENCE" de pmLookupLabels. La position de chaque élément dans le tableau sets est significative en termes de règles de précédence - les positions antérieures sont considérées comme ayant une précédence inférieure aux positions ultérieures.

Les valeurs doivent être des entités JSON primitives (par exemple, nombres, chaînes), des tableaux unidimensionnels ou des maps (c'est-à-dire des tableaux associatifs simples).

En plus d'utiliser des ensembles d'étiquettes indexés, l'interface pmMergeLabelSets fournit une fonction de rappel filter optionnelle. Si elle n'est pas NULL, cette fonction sera appelée pour chaque étiquette qui serait ajoutée au buffer de sortie, permettant un contrôle plus fin sur l'ensemble fusionné final. Ce mécanisme peut être utilisé pour *filtrer* des étiquettes individuelles en fonction de leur nom, de leur valeur, et/ou de leurs indicateurs. Si la fonction filter retourne zéro (faux), alors l'étiquette donnée est filtrée de l'ensemble résultant. Toute valeur de retour non nulle indique que l'étiquette doit être incluse dans le buffer.

EXEMPLE PYTHON

import sys
import json
from pcp import pmapi
import cpmapi as c_api
def merge_callback(label, jsondata, data=None):
    d = json.loads(jsondata)
    labelsD.update(d)
    return 0
ctx = pmapi.pmContext()
for metric in sys.argv[1:]:
    pmid = ctx.pmLookupName(metric)[0]
    lset = ctx.pmLookupLabels(pmid)
    labelsD = {}
    ctx.pmMergeLabelSets(lset, merge_callback)
    print("== %s ===" % metric)
    for n,v in labelsD.items():
        print("    %s = %s" % (n,v))
    ctx.pmFreeLabelSets(lset)

DIAGNOSTICS

En cas de succès, pmMergeLabels et pmMergeLabelSets renvoient le nombre d'octets écrits dans le buffer fourni.

Un échec lors de l'analyse des chaînes d'entrée, un échec d'allocation mémoire, ou toute incohérence interne détectée entraînera un code de retour négatif.

VOIR AUSSI

pminfo(1), PMAPI(3) et pmLookupLabels(3).
