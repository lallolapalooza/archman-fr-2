PMDAFARM(1) Manuel des commandes générales PMDAFARM(1)

NOM

pmdafarm - PMDA de log FARM Seagate

SYNTAXE

$PCP_PMDAS_DIR/farm/pmdafarm [-D debug]

DESCRIPTION

pmdafarm est un agent de domaine de métriques de performance (PMDA) qui exporte les valeurs des métriques pour Device Mapper sur le système local.

Ce PMDA collecte ses données via l'utilitaire smartctl(8) et nécessite que le programme soit installé pour fonctionner.

Vous trouverez plus de détails sur smartctl et smartmontools sur https://smartmontools.org.

INSTALLATION

Installez le PMDA SMART en utilisant le script Install en tant que root :

# cd $PCP_PMDAS_DIR/farm
# ./Install

Pour désinstaller, faites ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/farm
# ./Remove

pmdafarm est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/farm/help
fichier d'aide par défaut pour les métriques smart
$PCP_PMDAS_DIR/farm/Install
script d'installation de l'agent pmdafarm
$PCP_PMDAS_DIR/smart/Remove
script d'annulation d'installation de l'agent pmdafarm
$PCP_LOG_DIR/pmcd/farm.log
fichier journal par défaut pour les messages d'erreur de pmdafarm

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à résoudre les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à fournir des indications aux développeurs plutôt qu'aux utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

VOIR AUSSI

PCPIntro(1), pmcd(1) et smartctl(8).
