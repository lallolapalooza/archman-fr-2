NOM

pmaRewriteMeta - essayer de changer la version d'un enregistrement de métadonnées d'archive

C SYNTAXE

#include <pcp/pmapi.h>
#include <pcp/libpcp.h>
#include <pcp/archive.h>

int pmaRewriteMeta(__pmLogCtl *inlcp,
__pmLogCtl *outlcp, __int32_t *rbuf);

cc ... -lpcp_archive -lpcp

AVERTISSEMENT

Cette documentation est destinée à un usage interne par les développeurs de Performance Co-Pilot (PCP).

Ces interfaces ne font pas partie des API PCP garanties comme étant stables entre les versions, et elles pourraient ne pas fonctionner, ou avoir des sémantiques différentes à l'avenir.

DESCRIPTION

Un enregistrement de métadonnées physique de l'archive d'entrée identifié par inlcp est passé via rbuf et est reformaté si nécessaire pour produire l'enregistrement de métadonnées équivalent pour l'archive de sortie identifiée par outlcp.

Combinés aux versions des archives d'entrée et de sortie, le type de l'enregistrement de métadonnées (tel qu'extrait de rbuf) est utilisé pour décider si, pour certains types d'enregistrements et certains changements de version, aucune réécriture n'est nécessaire.

pmaRewriteMeta est destiné à être utilisé dans les cas où les versions d'archive de inlcp et outlcp sont différentes. Le seul choix sensé des versions d'archive actuellement est PM_LOG_VERS02 pour inlcp et PM_LOG_VERS03 pour outlcp, ce qui demanderait une réécriture du format de la version 2 d'archive vers le format de la version 3 d'archive (car seules les versions 2 et 3 sont actuellement prises en charge).

Si une réécriture a lieu, l'ancien rbuf aura été libéré et un nouveau rbuf alloué avec malloc(3). Il incombe à l'appelant de s'assurer que cette libération et réallocation potentielles seront sûres, par exemple, aucune référence pendante dans le contenu de rbuf, ou de passer une copie de l'enregistrement s'il est précieux.

DIAGNOSTICS ET VALEURS DE RETOUR

Dans plusieurs endroits, des erreurs fatales déclencheront un message d'erreur et forceront l'application à se terminer.

S'il n'y a pas de traduction définie pour les versions de inlcp et outlcp, pmaRewriteMeta renvoie PM_ERR_APPVERSION (une légère perversion de ce code d'erreur).

Si aucune réécriture n'est effectuée, la valeur de retour est 0, sinon une valeur de retour de 1 indique qu'une réécriture a eu lieu et que rbuf a été réalloué.

VOIR AUSSI

free(3), malloc(3), PMAPI(3), et pmaRewriteData(3).
