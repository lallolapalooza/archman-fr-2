PMSEARCHTEXTQUERY(3) Manuel des fonctions de bibliothèque PMSEARCHTEXTQUERY(3)

NOM

pmSearchTextQuery - Recherche plein texte des métriques, instances et domaines d'instance fournis par les services de recherche PCP

C SYNTAXE

#include <pcp/pmwebapi.h>

int pmSearchTextQuery(pmSearchSettings *settings,
pmSearchTextRequest *request, void *arg);

cc ... -lpcp_web

DESCRIPTION

Exécute une recherche plein texte dans le nom, l'aide en ligne, le texte d'aide (lorsqu'il est disponible) comme spécifié par request :

query
Chaîne de requête qui sera utilisée pour la recherche.
count
Limite le nombre de résultats. La valeur par défaut est 10.
offset
Décalage de la recherche. La valeur par défaut est 0.
type_metric, type_indom, type_inst
Indicateurs binaires qui limitent la requête à ne prendre en compte que des types d'entités spécifiques. La valeur par défaut est tous.
highlight_name, highlight_oneline, highlight_helptext
Indicateurs binaires qui spécifient si oui ou non les termes correspondants doivent être mis en surbrillance dans les résultats. La valeur par défaut est aucun. Les termes mis en surbrillance sont entourés de `<b>' et `</b>'.
infields_name, infields_oneline, infields_helptext
Indicateurs binaires qui permettent de limiter la correspondance de la requête de recherche plein texte uniquement aux champs spécifiés. La valeur par défaut est tous.
return_name, return_indom, return_oneline, return_helptext, return_type
Indicateurs binaires pour omettre des champs spécifiques du résultat. La valeur par défaut est tous. Les champs peuvent être omis dans les deux sens si la valeur d'un champ n'existe pas pour un enregistrement donné.

Chaque entité correspondant à la request ci-dessus sera passée au rappel on_text_result fourni par settings.

DIAGNOSTICS

Cette fonction retourne toujours zéro en cas de succès. En cas d'échec, un code d'erreur PMAPI négatif est retourné.
