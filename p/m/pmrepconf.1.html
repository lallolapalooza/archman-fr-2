NOM

pmrepconf - créer/éditer un fichier de configuration pmrep

SYNTAXE

pmrepconf [-crvV?] [-D debug] [-d groupesdir] [-g taggroupe] [-o option] [-h hôte] fichierconfig

DESCRIPTION

pmrepconf peut être utilisé pour créer et modifier un fichier de configuration générique pour pmrep(1) et les utilitaires associés, dans le format pmrep.conf(5).

Si fichierconfig n'existe pas, pmrepconf créera un fichier de configuration générique avec un ensemble de métriques découvertes dans une section [metrics].

Une fois créé, fichierconfig peut être utilisé avec l'option -c de pmrep(1) et des utilitaires associés tels que pcp2elasticsearch(2) et pcp2spark(2).

Si fichierconfig existe, pmrepconf demandera à l'utilisateur d'activer ou de désactiver des groupes de métriques de performance liées.

La sélection de groupe nécessite une simple réponse o (oui) ou n (non) à la demande Enregistrer ce groupe ?.

D'autres réponses à ce stade peuvent être utilisées pour sélectionner des fonctions de contrôle supplémentaires comme suit :

m
Afficher les noms des métriques du groupe actuel.
q
Terminer la sélection de groupe (quitter) et ne pas apporter d'autres modifications à ce groupe ou à tout groupe suivant.
/motif
Ne pas modifier ce groupe mais rechercher un groupe contenant motif dans la description du groupe ou les noms des métriques associées.

Lorsqu'il est exécuté par des processus de configuration automatisés, l'option -c est utilisée pour indiquer que pmrepconf est en mode de création automatique et qu'aucun dialogue interactif n'a lieu. Le fichier de configuration de sortie fichierconfig contient un message de commentaire supplémentaire et un horodatage indiquant ce fait, afin qu'il puisse être identifié et mis à jour ultérieurement en utilisant à nouveau -c. Cette option n'est pas appropriée pour une utilisation interactive de l'outil.

Une sortie plus détaillée peut être activée avec l'option -v.

FICHIERS GROUPES DE CONFIGURATION

Lorsqu'un fichier de configuration initial fichierconfig est créé, les spécifications par défaut proviennent d'un ensemble de fichiers de groupe situés sous le répertoire groupesdir spécifié avec l'option -d (le répertoire groupesdir par défaut est $PCP_VAR_DIR/config/pmlogconf, ce qui est le plus souvent correct, donc l'option -d est rarement utilisée en pratique).

La structure des répertoires et le format des fichiers sous groupesdir sont partagés avec l'utilitaire pmlogconf(1), et décris en détail dans cette page de manuel. Lorsqu'ils sont utilisés par pmrepconf, tous les paramètres d'intervalle sont ignorés.

OPTIONS

Les options de ligne de commande disponibles sont :

-c
Active le mode de création automatique non interactif.
-d groupesdir, --groups=groupesdir
Spécifie le chemin d'accès au répertoire groupesdir.
-g taggroupe, --group=taggroupe
Interroge l'état d'enregistrement pour le groupe spécifique nommé taggroupe.
-h hôte, --host=hôte
La source des métriques de performance est pmcd(1) sur hôte, plutôt que sur localhost par défaut.
-o option, --option=option
Spécifie une option à ajouter à la section [option] du fichier pmrep.conf(5) généré. Cette option de ligne de commande peut être présentée plusieurs fois afin d'ajouter plusieurs lignes dans la section [option].
-r, --reprobe
Reconsidère chaque groupe pour inclusion dans le fichierconfig.
-v, --verbose
Active le mode verbeux.
-V, --version
Affiche le numéro de version et quitte.
-?, --help
Affiche le message d'utilisation et quitte.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

pmrepconf remplace toute variable d'environnement $PCP_DERIVED_CONFIG par une chaîne vide, pour des raisons de performance.

pmrepconf respecte la variable d'environnement $PMCD_WAIT_TIMEOUT lors de l'exploration et de la création de nouveaux fichiers de configuration pmrep. Il utilise une valeur de délai d'attente par défaut de 10 secondes pour cela, en l'absence d'un paramètre d'environnement.

OPTIONS DE DEBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à résoudre les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à fournir des indications aux développeurs plutôt qu'aux utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.
