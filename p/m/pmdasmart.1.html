PMDASMART(1) Manuel des commandes générales PMDASMART(1)

NOM

pmdasmart - PMDA de données S.M.A.R.T

SYNTAXE

$PCP_PMDAS_DIR/smart/pmdasmart [-D debug]

DESCRIPTION

pmdasmart est un agent de domaine de métriques de performance (PMDA) qui exporte les valeurs de métriques pour Device Mapper sur le système local.

Ce PMDA collecte ses données via l'utilitaire smartctl(8) et requiert que le programme soit installé pour fonctionner.

Plus de détails sur smartctl et smartmontools sont disponibles sur https://smartmontools.org.

INSTALLATION

Installez le PMDA SMART en utilisant le script Install en tant que root :

# cd $PCP_PMDAS_DIR/smart
# ./Install

Pour désinstaller, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/smart
# ./Remove

pmdasmart est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMDAS_DIR/smart/help
fichier d'aide par défaut pour les métriques smart
$PCP_PMDAS_DIR/smart/Install
script d'installation pour l'agent pmdasmart
$PCP_PMDAS_DIR/smart/Remove
script d'annulation d'installation pour l'agent pmdasmart
$PCP_LOG_DIR/pmcd/smart.log
fichier journal par défaut pour les messages d'erreur de pmdasmart

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active l'affichage de diagnostics supplémentaires sur stderr pour aider à résoudre les problèmes, bien que les informations soient parfois cryptiques et principalement destinées aux développeurs plutôt qu'aux utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

VOIR AUSSI

PCPIntro(1), pmcd(1) et smartctl(8).
