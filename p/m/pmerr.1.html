PMERR(1) Manuel des commandes générales PMERR(1)

NOM

pmerr - traduit les codes d'erreur Performance Co-Pilot en messages d'erreur

SYNTAXE

pmerr [-?] code ...
pmerr -l

DESCRIPTION

pmerr accepte les codes d'erreur standard de Performance Co-Pilot (PCP) via l'argument code et génère le texte d'erreur correspondant.

Chaque code peut être un entier, une valeur hexadécimale ou une valeur hexadécimale préfixée par ``0x'' ou ``0X''.

Les codes d'erreur doivent être négatifs. Ainsi, si code est un nombre positif, un message d'avertissement est produit et la valeur négativée est utilisée.

OPTIONS

Les options de ligne de commande disponibles sont :

-l, --list
Cette invocation alternative permet de lister tous les codes d'erreur connus, ainsi que leurs noms symboliques et leur texte d'erreur.
-?, --help
Affiche le message d'utilisation et quitte.

ENVIRONNEMENT PCP

Les variables d'environnement préfixées par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PMAPI(3), pmErrStr(3), pcp.conf(5) et pcp.env(5).
