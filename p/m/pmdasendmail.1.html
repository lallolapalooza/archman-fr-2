PMDASENDMAIL(1) Manuel des commandes générales PMDASENDMAIL(1)

NOM

pmdasendmail - agent de domaine de métriques de performance sendmail (PMDA)

SYNOPSIS

$PCP_PMDAS_DIR/sendmail/pmdasendmail [-D debug] [-d domaine] [-l fichier_log] [-U nom_utilisateur]

DESCRIPTION

pmdasendmail est un agent de domaine de métriques de performance sendmail (PMDA) qui exporte les statistiques de trafic de courrier collectées par sendmail(1).

Avant que le PMDA sendmail ne puisse exporter de métriques, sendmail(1) doit avoir la collecte de statistiques activée. Cela implique de vérifier le nom du fichier de statistiques, tel que donné par les lignes de contrôle OS ou O StatusFile dans /etc/sendmail.cf, puis de créer ce fichier s'il n'existe pas déjà. La suppression du fichier arrêtera la collecte de statistiques par sendmail(1) et donc le PMDA sendmail.

Une brève description des options de ligne de commande de pmdasendmail suit :

-d
Il est absolument crucial que le numéro de domaine de métriques de performance spécifié ici soit unique et cohérent. C'est-à-dire que domaine doit être différent pour chaque PMDA sur le même hôte, et le même numéro de domaine doit être utilisé pour le même PMDA sur tous les hôtes.
-l
Emplacement du fichier journal. Par défaut, un fichier journal nommé sendmail.log est écrit dans le répertoire courant de pmcd(1) lorsque pmdasendmail est démarré, c'est-à-dire $PCP_LOG_DIR/pmcd. Si le fichier journal ne peut pas être créé ou n'est pas accessible en écriture, la sortie est écrite dans la sortie d'erreur standard à la place.
-U
Compte utilisateur sous lequel exécuter l'agent. Par défaut, c'est le compte non privilégié "pcp" dans les versions actuelles de PCP, mais dans les anciennes versions, le compte superutilisateur ("root") était utilisé par défaut.

Il n'y a pas d'options de communication, car le script Install assure que le PMDA sendmail sera connecté à PMCD par un tube.

INSTALLATION

Si vous souhaitez accéder aux noms, aux textes d'aide et aux valeurs des métriques de performance sendmail, faites ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/sendmail
# ./Install

Si vous souhaitez annuler l'installation, faites ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/sendmail
# ./Remove

pmdasendmail est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMCDCONF_PATH
options de ligne de commande utilisées pour lancer pmdasendmail
$PCP_PMDAS_DIR/sendmail/help
fichier d'aide par défaut pour les métriques sendmail
$PCP_PMDAS_DIR/sendmail/Install
script d'installation pour l'agent pmdasendmail
$PCP_PMDAS_DIR/sendmail/Remove
script d'annulation d'installation pour l'agent pmdasendmail
$PCP_LOG_DIR/pmcd/sendmail.log
fichier journal par défaut pour les messages d'erreur et autres informations provenant de pmdasendmail
/etc/sendmail.cf
fichier de configuration de sendmail pour identifier le nom du fichier de statistiques

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à diagnostiquer les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

Les options de débogage spécifiques à pmdasendmail sont les suivantes :

Option Description
appl0 diagnostics verbeux, particulièrement issus de map_stats()
