PMDANVIDIA(1) Manuel des commandes générales PMDANVIDIA(1)

NOM

pmdanvidia - agent de domaine de métriques GPU NVIDIA (PMDA)

SYNTAXE

$PCP_PMDAS_DIR/nvidia/pmdanvidia [-D debug] [-d domaine] [-l logfile] [-t intervalle]

DESCRIPTION

pmdanvidia est un agent de domaine de métriques (PMDA) qui extrait les métriques de performance disponibles sur les cartes GPU NVIDIA via la bibliothèque NVML.

Le PMDA nvidia exporte des métriques qui mesurent l'activité GPU, l'utilisation de la mémoire, la vitesse du ventilateur, etc. sur les cartes NVIDIA Tesla et Quadro. Les métriques sont peu susceptibles d'être disponibles pour les cartes de classe grand public.

Une brève description des options de ligne de commande de pmdanvidia suit :

-d
Il est absolument crucial que le numéro de domaine des métriques de performance spécifié ici soit unique et cohérent. C'est-à-dire, domaine doit être différent pour chaque PMDA sur le même hôte, et le même numéro de domaine doit être utilisé pour le même PMDA sur tous les hôtes.
-l
Emplacement du fichier journal. Par défaut, un fichier journal nommé nvidia.log est écrit dans le répertoire courant de pmcd(1) lors du démarrage de pmdanvidia, c'est-à-dire $PCP_LOG_DIR/pmcd. Si le fichier journal ne peut être créé ou n'est pas inscriptible, la sortie est envoyée à la sortie d'erreur standard à la place.
-t
Active et définit un intervalle d'échantillonnage pour l'actualisation automatique des valeurs de métriques. La fonctionnalité est désactivée par défaut, cependant cette option permet de spécifier un intervalle de temps sur lequel toutes les valeurs sont échantillonnées - ceci a pour effet de mettre à jour constamment les métriques cumulatives, dans le but d'aider les outils clients tels que pcp-atop(1) et pmlogger(1) à observer les changements d'état du GPU et des processus à l'intérieur de l'intervalle d'échantillonnage. Typiquement, ces outils ont des intervalles d'échantillonnage plus longs et peuvent donc "manquer" l'activité se produisant pendant leur intervalle d'échantillonnage.

INSTALLATION

Le PMDA nvidia n'est pas installé et disponible par défaut. Si vous souhaitez annuler l'installation, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/nvidia
# ./Remove

Si vous souhaitez rétablir l'accès aux noms, aux textes d'aide et aux valeurs des métriques de performance NVIDIA, après suppression, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/nvidia
# ./Install

pmdanvidia est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove informent pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMCDCONF_PATH
options de ligne de commande utilisées pour lancer pmdanvidia
$PCP_PMDAS_DIR/nvidia/help
fichier d'aide par défaut pour les métriques NVIDIA
$PCP_PMDAS_DIR/nvidia/Install
script d'installation pour l'agent pmdanvidia
$PCP_PMDAS_DIR/nvidia/Remove
script d'annulation d'installation pour l'agent pmdanvidia
$PCP_LOG_DIR/pmcd/nvidia.log
fichier journal par défaut pour les messages d'erreur et autres informations de pmdanvidia

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, tel que décrit dans pcp.conf(5).

OPTIONS DEBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à diagnostiquer les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

Les options de débogage spécifiques à pmdanvidia sont les suivantes :

Option Description
appl0 interaction avec pmcd(1)
appl1 chargement de la DSO libnvidia-ml
appl2 trace des appels select(2)

VOIR AUSSI

PCPIntro(1), pcp-atop(1), pmcd(1), pmlogger(1), pcp.conf(5) et pcp.env(5).
