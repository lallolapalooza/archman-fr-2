PMSETPROGNAME(3) Manuel des fonctions de bibliothèque PMSETPROGNAME(3)

NOM

pmSetProgname, pmGetProgname - services de nom d'application

C SYNTAXE

#include <pcp/pmapi.h>

void pmSetProgname(const char *program);
char *pmGetProgname(void);

cc ... -lpcp

DESCRIPTION

Au sein des bibliothèques d'exécution du Performance Co-Pilot (PCP), le nom d'une application en cours d'exécution est maintenu pour être utilisé dans les messages d'erreur et de diagnostic.

Le nom d'application par défaut est pcp.

pmSetProgname peut être utilisé pour définir le nom de l'application à program après avoir supprimé tous les composants de début qui commencent par le séparateur de nom de chemin du système de fichiers (``/'' pour les systèmes de type Unix).

Il est de la responsabilité de l'appelant de s'assurer que la mémoire pointée par program reste disponible pendant toute la durée de vie de l'application. Typiquement, la valeur passée comme program pour un programme C serait argv[0]. Si program est NULL, le nom d'application par défaut est restauré.

pmGetProgname peut être utilisé pour retourner le nom d'application actuel.
