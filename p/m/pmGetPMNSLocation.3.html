PMGETPMNSLOCATION(3) Manuel des fonctions de bibliothèque PMGETPMNSLOCATION(3)

NOM

pmGetPMNSLocation - déterminer l'emplacement de l'espace de noms PMNS actuellement utilisé

SYNTAXE C

#include <pcp/pmapi.h>

int pmGetPMNSLocation(void);

cc ... -lpcp

DESCRIPTION

Si une application a besoin de savoir d'où provient l'espace de noms des métriques de performance (PMNS), pmGetPMNSLocation retournera s'il provient d'une archive, PMNS_ARCHIVE, ou d'un fichier PMNS local, PMNS_LOCAL, ou d'un pmcd distant, PMNS_REMOTE.

Ces informations peuvent être utiles pour déterminer un message d'erreur approprié en fonction de l'emplacement du PMNS.

DIAGNOSTICS

PM_ERR_NOPMNS
S'il n'est pas possible de déterminer où se trouve l'emplacement du PMNS. Cela pourrait être dû à des problèmes avec le contexte actuel ou à l'incapacité de charger un PMNS local.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5). Les valeurs de ces variables peuvent être obtenues par programme en utilisant la fonction pmGetConfig(3).

VOIR AUSSI

PMAPI(3), pmGetConfig(3), pmLoadASCIINameSpace(3), pmLoadNameSpace(3), pmTrimNameSpace(3), pcp.conf(5), pcp.env(5) et PMNS(5).
