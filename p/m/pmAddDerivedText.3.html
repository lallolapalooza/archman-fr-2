pmAddDerivedText(3)

Paquet: pcp

PMADDDERIVEDTEXT(3) Manuel des fonctions de bibliothèque PMADDDERIVEDTEXT(3)

NOM

pmAddDerivedText - ajouter du texte d'aide pour une métrique dérivée

SYNTAXE C

#include <pcp/pmapi.h>

int pmAddDerivedText(const char *name,
int type, const char *text);

cc ... -lpcp

DESCRIPTION

Les métriques dérivées offrent un moyen d'étendre l'espace de noms des métriques de performance (PMNS) avec de nouvelles métriques définies côté client PCP en utilisant des expressions sur les métriques de performance existantes. Les métriques dérivées globales sont définies à l'aide de pmRegisterDerived(3) ou pmRegisterDerivedMetric(3) ou pmLoadDerivedConfig(3), et les métriques dérivées par contexte sont définies à l'aide de pmAddDerived(3) ou pmAddDerivedMetric(3).

Une fois qu'une métrique dérivée a été définie, pmAddDerivedText peut être utilisée pour associer le text d'aide à la métrique dérivée identifiée par name.

Le texte d'aide peut être un résumé « en une ligne » ou un bloc de texte plus détaillé « multi-lignes », et type doit être PM_TEXT_ONELINE ou PM_TEXT_HELP respectivement. Pour associer les deux styles de texte d'aide à une métrique dérivée, pmAddDerivedText devrait être appelée deux fois avec des valeurs différentes pour type.

Une fois qu'un type particulier de texte d'aide a été associé à une métrique dérivée, il ne peut pas être supprimé ou redéfini.

Les applications utilisant l'interface de programmation d'applications de métriques de performance (PMAPI) sont capables de récupérer le texte d'aide pour des métriques spécifiques en utilisant pmLookupText(3).

DIAGNOSTICS

pmAddDerivedText retourne zéro en cas de succès, sinon un code d'erreur.

La valeur de retour PM_ERR_NAME indique que name ne correspond pas à une métrique dérivée précédemment définie.

Des appels répétés pour le même name et type entraîneront une valeur de retour de PM_ERR_TEXT.

Une valeur de retour de PM_ERR_ARG indique que type n'est pas l'une des valeurs attendues.

VOIR AUSSI

PCPIntro(1), pmAddDerived(3), pmAddDerivedMetric(3), PMAPI(3), pmLoadDerivedConfig(3), pmLookupText(3), pmRegisterDerived(3), pmRegisterDerivedMetric(3) et PMNS(5).
