Paquet: pcp

PMDALABEL(3) Manuel des fonctions de bibliothèque PMDALABEL(3)

NOM

pmdaLabel, pmdaSetLabelCallBack - remplir les structures pmLabelSet avec des étiquettes de métrique

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaLabel(int ident,
int type, pmLabelSet **sets, pmdaExt *pmda);

int pmdaSetLabelCallBack(pmdaInterface *dispatch,
pmdaLabelCallBack callback);

cc ... -lpcp_pmda -lpcp

DESCRIPTION

Dans le cadre de l'API du Domain Agent de Métriques de Performance (PMDA) (voir PMDA(3)), pmdaLabel utilise les structures de données standard PMDA(3) pour retourner les étiquettes pour le domaine de performance, le domaine d'instance, la métrique ou les instances individuelles au format « JSONB » dans la structure de données sets fournie.

L'argument type détermine l'interprétation de ident et la forme d'étiquette demandée, comme suit :

PM_LABEL_DOMAIN
lorsque ident est un identifiant de domaine PMDA,
PM_LABEL_CLUSTER
lorsque ident est un identifiant de métrique et que les étiquettes du cluster contenant cette métrique sont demandées.
PM_LABEL_ITEM
lorsque ident est un identifiant de métrique,
PM_LABEL_INDOM
lorsque ident est un identifiant de domaine d'instance, ou
PM_LABEL_INSTANCES
lorsque ident est un identifiant de métrique et que les étiquettes de toutes les instances de cette métrique sont demandées.

Le pointeur d'étiquettes sets doit être initialisé à NULL avant d'appeler pmdaLabel et l'espace ne doit être alloué que lorsque des étiquettes sont présentes et retournées. Dans ce cas, le code de retour doit indiquer le nombre d'étiquettes sets qui ont été allouées. Ceci ne sera jamais supérieur à un dans le cas PM_LABEL_INSTANCES.

Ceci est l'un des rares callbacks génériques de libpcp_pmda (voir PMDA(3)) qui est incomplet, nécessitant une méthode pmdaLabelCallBack supplémentaire de sa propre part. Le callback additionnel doit être enregistré en utilisant pmdaSetLabelCallBack et la méthode pmdaLabelCallBack a le prototype suivant :

int func(pmInDom indom, unsigned int inst, pmLabelSet **set)

Le but de la routine pmdaLabelCallBack est de retourner l' (les) étiquette (s) pour une instance individuelle inst d'un domaine d'instance donné, indom. Son code de retour réussi diffère significativement de pmdaLabel, comme décrit ci-dessous.

ATTENTION

Le PMDA doit utiliser PMDA_INTERFACE_7 ou une version ultérieure, tel que spécifié dans l'appel à pmdaDSO(3) ou pmdaDaemon(3).

DIAGNOSTICS

En cas de succès, pmdaLabel retourne le nombre de sets d'étiquettes créés. Ceci est généralement zéro ou un, sauf dans le cas de PM_LABEL_INSTANCES où plus d'un set d'étiquettes sera souvent retourné, un pour chaque instance de la métrique demandée.

En revanche, en cas de succès de la routine pmdaLabelCallBack, le nombre d'étiquettes ajoutées avec succès au pointeur de set d'étiquettes fourni doit être retourné (et non le nombre total de sets d'étiquettes).

Si les étiquettes pour l'entité demandée n'ont pas pu être obtenues en raison d'une défaillance catastrophique, telle qu'un manque de mémoire, ces routines retourneront un code d'erreur négatif.

VOIR AUSSI

pminfo(1), malloc(3), PMAPI(3), PMDA(3), pmdaDaemon(3), pmdaDSO(3), pmdaInit(3) et pmLookupLabels(3).
