PMPRINTVALUE(3) Manuel des fonctions de bibliothèque PMPRINTVALUE(3)

NOM

pmPrintValue - imprimer la valeur d'une métrique de performance

SYNTAXE C

#include <stdio.h>
#include <pcp/pmapi.h>

void pmPrintValue(FILE *f,
int valfmt, int type, const pmValue *val, int minwidth);

cc ... -lpcp

DESCRIPTION

La valeur d'une métrique de performance unique (identifiée par val) est imprimée sur le flux d'E/S standard identifié par f.

La valeur de la métrique de performance est interprétée selon le format de val tel que défini par valfmt (provenant d'un pmValueSet dans une structure pmResult ; voir pmFetch(3)) et la description générique du type de métrique passée via type.

La valeur pour type est typiquement extraite d'une structure pmDesc, suite à un appel à pmLookupDesc(3) pour une métrique de performance particulière.

La sortie sera éventuellement complétée pour avoir au moins minwidth caractères de large.

pmPrintValue est particulièrement utile pour afficher les valeurs des métriques de performance de pmFetch(3) (qui renvoie un ensemble de paires valfmt et val pour chaque métrique demandée), sur la base du type de métrique renvoyé par pmLookupDesc(3).

ENVIRONNEMENT

La sortie des valeurs de métriques de type chaîne peut être contrôlée en outre par PCP_SQUASH_NEWLINES. Lorsqu'elle est définie dans l'environnement du processus appelant, et que type est défini sur PM_TYPE_STRING ou PM_TYPE_AGGREGATE, la valeur de sortie est garantie d'être exempte de caractères de nouvelle ligne intégrés. Si la valeur donnée contenait de tels caractères, ils auront été remplacés par un espace avant d'être imprimés.

VOIR AUSSI

PMAPI(3), pmAtomStr(3), pmConvScale(3), pmExtractValue(3), pmFetch(3), pmLookupDesc(3), pmTypeStr(3) et pmUnitsStr(3).
