PMCD_WAIT(1) Manuel des commandes générales PMCD_WAIT(1)

NOM

pmcd_wait - attendre que PMCD accepte les connexions clients

SYNTAXE

$PCP_BINADM_DIR/pmcd_wait [-v?] [-D debug] [-h hote] [-t delai]

DESCRIPTION

pmcd_wait attend que le démon de collecte des métriques de performance (PMCD) soit en cours d'exécution et accepte les connexions clients.

Sauf indication contraire sur un autre hôte par l'option -h, pmcd_wait essaiera de contacter pmcd(1) sur l'hôte local.

pmcd_wait expirera et abandonnera la tentative de connexion à pmcd après 60 secondes. Cet intervalle de délai d'attente par défaut peut être modifié à l'aide de l'option -t, où l'argument delai suit la syntaxe décrite dans PCPIntro(1) et peut, sous sa forme la plus simple, être un entier non signé (les unités implicites dans ce cas sont les secondes).

En cas de connexion réussie à pmcd, un code de sortie de zéro est retourné.

Si une erreur ou un délai d'attente se produit, un code de sortie non nul est retourné, comme décrit ci-dessous.

OPTIONS

Les options de ligne de commande disponibles sont les suivantes :

-h hote, --host=hote
Connecte pmcd(1) sur hote, plutôt que celui par défaut sur localhost.
-t delai, --interval=delai
Expire après delai secondes si la connexion n'est pas établie. La valeur de délai par défaut est de 60 secondes.
-v, --verbose
Cette option active le mode verbeux. Lorsque le mode verbeux est désactivé (ce qui est le cas par défaut), aucune sortie ne sera générée. En mode verbeux, les messages d'erreur seront affichés sur stderr.
-?, --help
Affiche le message d'utilisation et quitte.

DIAGNOSTICS

Les messages d'erreur seront affichés sur stderr uniquement si le mode verbeux est activé.

Les codes de sortie suivants sont retournés :

0
pmcd_wait a réussi à se connecter à pmcd dans le délai imparti.
1
Une erreur d'utilisation s'est produite, utilisez -v pour plus de détails.
2
Aucune connexion n'a été établie dans le délai imparti. Cela se produit si pmcd est en cours d'exécution mais prend trop de temps pour établir la connexion client, ou si pmcd n'est pas en cours d'exécution et que toutes les tentatives de connexion dans le délai imparti ont échoué avec l'erreur ECONNREFUSED.
3
Une erreur UNIX s'est produite, utilisez -v pour plus de détails.
4
Une erreur PCP s'est produite, utilisez -v pour plus de détails.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider au dépannage, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

VOIR AUSSI

PCPIntro(1), pmcd(1), pcp.conf(5) et pcp.env(5).
