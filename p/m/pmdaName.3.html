PMDANAME(3) Manuel des fonctions de bibliothèque PMDANAME(3)

NOM

pmdaName - traduire un PMID en un ensemble de noms de métriques de performance dynamiques

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaName(pmID pmid, char ***nameset, pmdaExt *pmda);

cc ... -lpcp_pmda -lpcp

DESCRIPTION

Dans le cadre de l'API de l'Agent de Domaine de Métriques de Performance (PMDA) (voir PMDA(3)), pmdaName est le rappel générique pour traduire un pmid en un ou plusieurs noms de métriques dynamiques (nameset).

Étant donné que l'implémentation des métriques de performance dynamiques nécessite un support PMDA spécifique, et que cette fonctionnalité est un composant optionnel d'un PMDA (la plupart des PMDA ne supportent **pas** les métriques de performance dynamiques), pmdaName est une implémentation squelette qui retourne PM_ERR_NAME.

Un PMDA qui supporte les métriques de performance dynamiques fournira un rappel privé qui remplace pmdaName (par assignation à version.four.name de la structure pmdaInterface) et implémente la traduction d'un pmid en un ensemble de noms de métriques de performance dynamiques retournés via nameset. Le comportement, les valeurs de retour et les règles d'allocation mémoire pour nameset sont les mêmes que pour pmNameAll(3).

ATTENTION

Le PMDA doit utiliser PMDA_INTERFACE_4 ou une version ultérieure, comme spécifié dans l'appel à pmdaDSO(3) ou pmdaDaemon(3).

DIAGNOSTICS

pmdaName retourne PM_ERR_PMID si le nom n'est pas reconnu ou ne peut pas être traduit, sinon le nombre de noms de métriques trouvés (le plus souvent 1).

VOIR AUSSI

PMAPI(3), PMDA(3), pmdaDaemon(3), pmdaDSO(3), pmdaMain(3), pmNameAll(3) et pmNameID(3).
