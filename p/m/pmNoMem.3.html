PMNOMEM(3) Manuel des fonctions de bibliothèque PMNOMEM(3)

NOM

pmNoMem - signaler les conditions de manque de mémoire

C SYNTAXE

#include <pcp/pmapi.h>

void pmNoMem(const char *where, size_t size, int fatal);

cc ... -lpcp

DESCRIPTION

pmNoMem est une méthode pratique qui peut être utilisée lorsque malloc(3) ou un service d'allocation mémoire connexe échoue.

Un message standard est émis en utilisant pmNotifyErr(3) avec where utilisé comme préfixe de message et la taille size de l'allocation défaillante est également signalée.

Si fatal est zéro (et PM_RECOV_ERR est zéro), pmNoMem retourne (l'échec de l'allocation est supposé être récupérable par l'appelant), sinon (et PM_FATAL_ERR est une bonne valeur à utiliser dans ce cas) exit(2) est appelé avec l'argument 1.

VOIR AUSSI

exit(2), malloc(3), PMAPI(3) et pmNotifyErr(3).
