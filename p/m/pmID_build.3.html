PMID_BUILD(3) Manuel des fonctions de bibliothèque PMID_BUILD(3)

NOM

pmID_build, pmID_domain, pmID_cluster, pmID_item - méthodes d'assistance pour la manipulation des pmID

C SYNTAXE

#include <pcp/pmapi.h>

pmID pmID_build(unsigned int domain,
unsigned int cluster, unsigned int item);

unsigned int pmID_domain(pmID pmid);
unsigned int pmID_cluster(pmID pmid);
unsigned int pmID_item(pmID pmid);

cc ... -lpcp

DESCRIPTION

Au sein du Performance Co-Pilot (PCP), chaque métrique se voit attribuer un identifiant unique de métrique de performance (pmID). Interne à PCP, un pmID est construit à partir de 3 champs : le numéro de domaine (de l'agent de domaine de métriques de performance associé, ou PMDA), le numéro de cluster et le numéro d'élément (les deux derniers sont assignés par le PMDA).

pmID_build construit un pmID à partir de domain, cluster et item.

pmID_domain, pmID_cluster et pmID_item renvoient les champs respectifs à partir de pmid.

VOIR AUSSI

PMAPI(3) et pmIDStr(3).
