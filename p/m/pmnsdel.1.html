PMNSDEL(1) Manuel des commandes générales PMNSDEL(1)

NOM

pmnsdel - supprimer un sous-arbre de noms de l'espace de noms des métriques de performance (PMNS)

SYNTAXE

$PCP_BINADM_DIR/pmnsdel [-?] [-D debug] [-n espace de noms] cheminmetric [...]

DESCRIPTION

pmnsdel supprime des sous-arbres de noms d'un espace de noms de métriques de performance (PMNS), tel qu'utilisé par les composants de Performance Co-Pilot (PCP).

Normalement, pmnsdel opère sur l'espace de noms des métriques de performance (PMNS) par défaut, cependant, si l'option -n est spécifiée, un espace de noms alternatif est utilisé à partir du fichier espace de noms.

Le PMNS par défaut se trouve dans le fichier $PCP_VAR_DIR/pmns/root à moins que la variable d'environnement PMNS_DEFAULT ne soit définie, auquel cas la valeur est supposée être le chemin d'accès au fichier contenant le PMNS par défaut.

Les noms de métriques à supprimer sont tous ceux pour lesquels l'un des arguments cheminmetric est un préfixe dans le PMNS, voir PMNS(5).

Tous les fichiers définissant le PMNS doivent être situés dans le répertoire contenant la racine du PMNS, et cela impliquerait typiquement l'exécution de pmnsdel en tant que root.

À condition que certaines vérifications d'intégrité initiales soient satisfaites, pmnsdel mettra à jour les fichiers PMNS nécessaires. En cas d'erreur, l'espace de noms d'origine est restauré. Notez que tous les fichiers PMNS qui ne sont plus référencés par l'espace de noms modifié ne seront pas supprimés, même si leur contenu ne fait pas partie du nouvel espace de noms.

OPTIONS

Les options de ligne de commande disponibles sont :

-n fichier pmns, --namespace=fichier pmns
Charge un espace de noms de métriques de performance (PMNS) alternatif à partir du fichier fichier pmns.
-?, --help
Affiche le message d'utilisation et quitte.

ATTENTION

Une fois l'écriture du nouveau fichier espace de noms commencée, les signaux SIGINT, SIGHUP et SIGTERM seront ignorés pour protéger l'intégrité des nouveaux fichiers.

FICHIERS

$PCP_VAR_DIR/pmns/root
le PMNS par défaut, lorsque la variable d'environnement PMNS_DEFAULT est désactivée

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à résoudre les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à fournir des indications aux développeurs plutôt qu'aux utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

VOIR AUSSI

pmnsadd(1), pmnsmerge(1), pcp.conf(5), pcp.env(5) et PMNS(5).
