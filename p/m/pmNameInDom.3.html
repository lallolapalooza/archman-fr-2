PMNAMEINDOM(3) Manuel des fonctions de bibliothèque PMNAMEINDOM(3)

NOM

pmNameInDom - traduire un identifiant d'instance en nom d'instance

SYNTAXE

#include <pcp/pmapi.h>

int pmNameInDom(pmInDom indom, int inst, char **name);

cc ... -lpcp

DESCRIPTION

Pour le domaine d'instances indom, dans le contexte actuel de l'Interface de Programmation d'Applications de Métriques de Performance (PMAPI), localise l'instance avec l'identifiant d'instance interne donné par inst, et retourne l'identification externe complète de l'instance via name.

La valeur pour le domaine d'instances indom est typiquement extraite d'une structure pmDesc, suite à un appel à pmLookupDesc(3) pour une métrique de performance particulière.

L'espace pour la valeur de name aura été alloué dans pmNameInDom avec malloc(3), et il incombe à l'appelant de free(3) l'espace lorsqu'il n'est plus nécessaire.

pmNameInDom retourne zéro en cas de succès.

DIAGNOSTICS

PM_ERR_INDOM
indom n'est pas un identifiant de domaine d'instances valide
PM_ERR_INST
L'identifiant d'instance inst n'est pas connu pour le domaine d'instances indom dans le contexte PMAPI actuel

VOIR AUSSI

PMAPI(3), pmGetConfig(3), pmGetInDom(3), pmLookupInDom(3), pmNameInDomArchive(3), pcp.conf(5) et pcp.env(5).
