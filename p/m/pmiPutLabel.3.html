PMIPUTLABEL(3) Manuel des fonctions de bibliothèque PMIPUTLABEL(3)

NOM

pmiPutLabel - ajouter des étiquettes à l'archive de sortie

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiPutLabel(unsigned int type,
unsigned int id, unsigned int instance, const char *name, const char *value);

cc ... -lpcp_import -lpcp

SYNTAXE Perl

use PCP::LogImport;

pmiPutLabel($type,
$id, $instance, $name, $value);

DESCRIPTION

Dans le cadre de l'API d'importation de journaux de Performance Co-Pilot (voir LOGIMPORT(3)), pmiPutLabel ajoute une étiquette pour le contexte global ou pour un domaine, cluster, item, domaine d'instance ou instance donné.

Le type doit être l'un des PM_LABEL_CONTEXT, PM_LABEL_DOMAIN, PM_LABEL_CLUSTER, PM_LABEL_ITEM, PM_LABEL_INDOM, ou PM_LABEL_INSTANCES.

Si type est PM_LABEL_CONTEXT, alors id et instance sont ignorés. Sinon, id doit correspondre à un domaine, un cluster, une métrique ou un domaine d'instance défini précédemment dans un appel à pmiAddMetric(3).

Si type est PM_LABEL_INSTANCES, alors instance doit correspondre à un numéro d'instance du domaine sélectionné. Sinon instance est ignoré.

name est une chaîne contenant le nom de l'étiquette à ajouter.

value est une chaîne contenant la valeur de l'étiquette à ajouter.

Aucune donnée ne sera écrite tant que pmiWrite(3) n'est pas appelée. Ainsi, plusieurs appels à pmiPutLabel sont généralement utilisés pour accumuler plusieurs étiquettes avant d'appeler pmiWrite(3).

DIAGNOSTICS

pmiPutLabel retourne zéro en cas de succès, sinon une valeur négative qui peut être transformée en message d'erreur en appelant pmiErrStr(3).

VOIR AUSSI

LOGIMPORT(3), pmiAddInstance(3), pmiAddMetric(3), pmiErrStr(3), pmiPutResult(3), pmiPutValue(3), pmiPutValueHandle(3), pmiPutText(3) et pmiWrite(3).
