PMAFM(1) Manuel des commandes générales PMAFM(1)

NOM

pmafm - Gestionnaire de folios d'archives Performance Co-Pilot

SYNTAXE

pmafm nom_folio [commande [arg ...]]

DESCRIPTION

Une collection d'une ou plusieurs archives Performance Co-Pilot (PCP) peut être combinée avec un fichier de contrôle pour produire un folio d'archives PCP. Les folios d'archives sont créés à l'aide de mkaf(1) ou des services de mode d'enregistrement interactif des clients PCP comme pmchart(1).

pmafm fournit un certain nombre de services qui peuvent être utilisés pour traiter les folios. En particulier, il prend en charge l'exécution d'outils PCP en utilisant une ou plusieurs des archives composantes d'un folio d'archives.

L'archive cible est identifiée par le fichier de contrôle du folio nom_folio. La syntaxe d'un fichier de contrôle de folio est décrite dans mkaf(1).

Si elles sont présentes, la commande et les arguments suivant nom_folio sont interprétés et exécutés comme une seule commande, sinon les commandes sont lues depuis l'entrée standard.

Les commandes suivantes sont prises en charge.

archives
Les commandes suivantes s'appliquent à toutes les archives du folio.
archives N[,...]
Les archives au sein d'un folio sont numérotées 1, 2, etc. Les commandes suivantes sont limitées à s'appliquer uniquement aux archives désignées.
archives nom[,...]
Les archives au sein d'un folio ont des noms uniques. Les commandes suivantes sont limitées à s'appliquer uniquement aux archives désignées.
check
Valide la présence et le format de chaque fichier du folio et des archives composantes.
help

Un bref rappel de la syntaxe de la commande. ? est un synonyme de help.
hosts

Les commandes suivantes s'appliquent à toutes les archives du folio.
hosts nom_hote[,...]
Les commandes suivantes sont limitées à s'appliquer uniquement aux archives qui correspondent aux noms d'hôtes désignés.
list [verbose]
Affiche le contenu du folio. Par défaut, l'en-tête de contrôle et le numéro ordinal, le nom d'hôte et le nom de base de l'archive pour chaque archive du folio. L'option verbose amène pmafm à déverser l'enregistrement d'étiquette de chaque archive en utilisant pmlogdump -l.
La première archive nommée dans le folio est supposée être associée à l'hôte par défaut pour tout outil essayant de rejouer plusieurs archives du folio.
quit

Quitte pmafm.
remove

Écho sur la sortie standard des commandes sh(1) requises pour supprimer tous les fichiers physiques associés à ce folio d'archives.
repeat outil [arg ...]
Exécute l'outil PCP connu une fois par archive sélectionnée. Par exemple, la commande
repeat pmval -t60 kernel.all.load
exécuterait pmval(1) une fois par archive, avec un argument -a approprié.
replay

Certains folios d'archives sont créés par des outils (par exemple, pmchart(1)) qui fournissent suffisamment d'informations pour permettre la relecture de toutes les informations de toutes les archives d'un folio.
[run] outil [arg ...]
Exécute l'outil PCP connu sur les archives sélectionnées. Certains outils PCP sont capables de traiter plusieurs archives simultanément, et dans ce cas l'outil est exécuté une fois avec la liste de toutes les archives sélectionnées passée via un argument -a. Sinon, cette commande est synonyme de repeat.
selections
Affiche les archives qui seraient sélectionnées pour le traitement avec une commande repeat, replay ou run.

Les restrictions via les commandes hosts et archives sont conjointes. Ces restrictions servent à limiter les archives spécifiques traitées dans les commandes repeat, replay ou run et selections suivantes. Par défaut, toutes les archives sont sélectionnées.

Les mots clés des commandes peuvent être abrégés à condition qu'aucune ambiguïté ne soit introduite, par exemple, help, hel et he sont synonymes, mais h est ambigu.

FICHIERS

$PCP_VAR_DIR/config/pmafm/*
fichiers de contrôle qui définissent le comportement de chaque outil PCP connu de pmafm. Ces informations peuvent être personnalisées ou étendues, voir $PCP_VAR_DIR/config/pmafm/pcp pour la documentation de la syntaxe et sémantique de ces fichiers.
$HOME/.pcp/pmafm/*
Personnalisation par l'utilisateur des fichiers de contrôle. Tous les fichiers de ce répertoire sont traités de la même manière que les fichiers de contrôle dans le répertoire $PCP_VAR_DIR/config/pmafm.

ENVIRONNEMENT PCP

Les variables d'environnement commençant par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, tel que décrit dans pcp.conf(5).

VOIR AUSSI
