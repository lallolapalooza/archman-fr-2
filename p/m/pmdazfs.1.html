PMDAZFS(1) Manuel des commandes générales PMDAZFS(1)

NOM

pmdazfs - Agent de domaine de métriques de performance ZFS (PMDA) pour Linux

SYNTAXE

$PCP_PMDAS_DIR/linux_zfs/pmdazfs [-D debug] [-d domaine] [-l fichier_log]

DESCRIPTION

pmdazfs est un agent de domaine de métriques de performance (PMDA) qui extrait des métriques de performance décrivant l'état du système de fichiers ZFS à partir des fichiers de statistiques situés dans /proc.

Le PMDA zfs exporte des métriques qui mesurent des informations sur la mise en cache (ARC, L2ARC, ZIL, VDEV), la mise en tampon, RAIDZ, les opérations de dnode et les E/S de pools.

Une brève description des options de ligne de commande de pmdazfs suit :

-d
Le numéro du domaine de métriques de performance doit être défini sur une valeur unique.
-l
Emplacement du fichier journal. Par défaut, un fichier journal nommé zfs.log est écrit dans le répertoire courant de pmcd(1) lorsque pmdazfs est démarré, c'est-à-dire $PCP_LOG_DIR/pmcd. Si le fichier journal ne peut pas être créé ou n'est pas accessible en écriture, la sortie est redirigée vers la sortie d'erreur standard.

INSTALLATION

OpenZFS n'est pas inclus dans PCP et doit être installé sur le système à partir des paquets disponibles ou des sources. Une fois OpenZFS installé et configuré, les fichiers de statistiques devraient apparaître dans /proc et le PMDA peut être ajouté à PMCD en utilisant le script d'installation :

# cd $PCP_PMDAS_DIR/zfs
# ./Install

Pour désinstaller le PMDA, utilisez le script de suppression :

# cd $PCP_PMDAS_DIR/zfs
# ./Remove

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à résoudre les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

Les options de débogage spécifiques à pmdazfs sont les suivantes :

Option Description
appl0 Avertit si l'un des fichiers de statistiques ZFS ne peut pas être trouvé

VOIR AUSSI

PCPIntro(1), pmcd(1), pcp.conf(5) et pcp.env(5).
