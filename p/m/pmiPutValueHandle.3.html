PMIPUTVALUEHANDLE(3) Manuel des fonctions de bibliothèque PMIPUTVALUEHANDLE(3)

NOM

pmiPutValueHandle - ajouter une valeur pour une paire métrique-instance via un descripteur

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiPutValueHandle(int handle, const char *value);

cc ... -lpcp_import -lpcp

SYNTAXE Perl

use PCP::LogImport;

pmiPutValueHandle($handle, $value);

DESCRIPTION

Dans le cadre de l'API d'importation de logs du Performance Co-Pilot (voir LOGIMPORT(3)), pmiPutValueHandle ajoute une seule valeur à l'enregistrement de sortie courant pour une métrique et une instance données, en utilisant le handle défini par un appel antérieur à pmiGetHandle(3).

La value doit être dans un format cohérent avec le type de la métrique tel que défini lors de l'appel à pmiAddMetric(3).

Aucune donnée ne sera écrite tant que pmiWrite(3) n'aura pas été appelé. Ainsi, plusieurs appels à pmiPutValueHandle ou pmiPutValue(3) sont généralement utilisés pour accumuler les valeurs de données pour plusieurs paires métrique-instance avant d'appeler pmiWrite(3).

DIAGNOSTICS

pmiPutValueHandle renvoie zéro en cas de succès, sinon une valeur négative qui peut être transformée en message d'erreur en appelant pmiErrStr(3).

VOIR AUSSI

LOGIMPORT(3), pmiErrStr(3), pmiGetHandle(3), pmiPutResult(3), pmiPutValue(3), pmiPutText(3), pmiPutLabel(3) et pmiWrite(3).
