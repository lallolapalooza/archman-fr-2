PMNAMEID(3) Manuel des fonctions de bibliothèque PMNAMEID(3)

NOM

pmNameID - traduire un PMID en nom de métrique de performance

SYNTAXE C

#include <pcp/pmapi.h>

int pmNameID(pmID pmid, char **name);

cc ... -lpcp

DESCRIPTION

Étant donné un identifiant de métrique de performance (PMID) via pmid, pmNameID déterminera le nom de métrique correspondant, le cas échéant, dans l'espace de noms des métriques de performance (PMNS), et le retournera via name.

Si le PMNS contient plusieurs noms associés au PMID demandé, l'un d'eux sera retourné via name, mais il n'y a aucun moyen de déterminer lequel des noms dupliqués il s'agira. Voir pmNameAll(3) si tous les noms correspondants sont requis.

Depuis la version 3.10.3 de PCP, les noms dupliqués pour le même PMID sont autorisés dans le PMNS, il est donc recommandé d'utiliser pmNameAll(3) plutôt que pmNameID.

name est une chaîne terminée par un octet nul, allouée par pmNameID en utilisant malloc(3) et il est de la responsabilité de l'appelant d'appeler free(3) pour libérer le stockage lorsque la valeur n'est plus requise.

En l'absence d'erreurs, pmNameID renvoie zéro.

DIAGNOSTICS

PM_ERR_NOPMNS
Échec d'accès à un PMNS pour l'opération. Notez que si l'application n'a pas appelé au préalable pmLoadNameSpace(3) et souhaite utiliser le PMNS distribué, alors un appel à pmNameID doit être effectué après la création d'un contexte (voir pmNewContext(3)).
PM_ERR_PMID
pmid ne correspond à aucun PMID défini dans le PMNS.
PM_ERR_*
D'autres diagnostics concernent les échecs de protocole lors de l'accès au PMNS distribué.
