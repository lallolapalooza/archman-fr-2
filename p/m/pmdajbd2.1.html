PMDAJBD2(1) Manuel des commandes générales PMDAJBD2(1)

NOM

pmdajbd2 - agent de domaine de métriques de performance (PMDA) pour le périphérique de bloc journalisé (JBD)

SYNTAXE

$PCP_PMDAS_DIR/jbd2/pmdajbd2 [-D debug] [-d domaine] [-l logfile] [-j chemin] [-U nomutilisateur]

DESCRIPTION

pmdajbd2 est un agent de domaine de métriques de performance (PMDA) qui extrait les métriques de performance du sous-système de périphérique de bloc journalisé (JBD) (version 2) du noyau Linux. Ces métriques sont exportées par le noyau dans des fichiers procfs, un fichier par périphérique de bloc. Le sous-système JBD2 est utilisé par plusieurs systèmes de fichiers, notamment ext3, ext4 et ocfs2.

Le PMDA jbd2 exporte des métriques qui mesurent des informations détaillées sur les transactions du journal, telles que le temps passé en attente et verrouillé, les taux de requêtes, les blocs utilisés, etc.

Une brève description des options de ligne de commande de pmdajbd2 suit (celles-ci ne sont pertinentes que lorsque le PMDA est exécuté en tant que démon, et non en tant que bibliothèque partagée) :

-d
Il est absolument crucial que le numéro de domaine des métriques de performance spécifié ici soit unique et cohérent. C'est-à-dire que domaine doit être différent pour chaque PMDA sur un même hôte, et le même numéro de domaine doit être utilisé pour le même PMDA sur tous les hôtes.
-l
Emplacement du fichier journal. Par défaut, lors de l'exécution en tant que démon, un fichier journal nommé jbd2.log est écrit dans le répertoire courant lors du lancement de pmdajbd2, c'est-à-dire $PCP_LOG_DIR/pmcd. Si le fichier journal ne peut pas être créé ou n'est pas accessible en écriture, la sortie est redirigée vers la sortie standard d'erreur. Lors de l'exécution en mode bibliothèque partagée, les informations de diagnostic seront écrites dans le fichier journal de pmcd, à savoir $PCP_LOG_DIR/pmcd/pmcd.log.
-j
Permet de spécifier un chemin alternatif vers les fichiers de statistiques jbd2. Le chemin par défaut est /proc/fs/jbd2.
-U
Compte utilisateur sous lequel exécuter l'agent. Par défaut, il s'agit du compte non privilégié « pcp » dans les versions actuelles de PCP, mais dans les versions plus anciennes, le compte superutilisateur (« root ») était utilisé par défaut.

INSTALLATION

Ce PMDA est installé par défaut et en mode bibliothèque partagée (plutôt qu'en tant que démon séparé de pmcd(1)). Par conséquent, les noms, les textes d'aide et les valeurs pour les métriques de performance jbd2 devraient toujours être disponibles.

Si vous n'utilisez pas ces métriques, vous pouvez supprimer ce PMDA en procédant comme suit en tant que root :

# cd $PCP_PMDAS_DIR/jbd2
# ./Remove

Si vous souhaitez réactiver l'installation, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/jbd2
# ./Install

pmdajbd2 est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou supprimé.

FICHIERS

$PCP_PMCDCONF_PATH
options de ligne de commande utilisées pour lancer pmdajbd2
$PCP_PMDAS_DIR/jbd2/help
fichier d'aide par défaut pour les métriques jbd2
$PCP_PMDAS_DIR/jbd2/Install
script d'installation pour l'agent pmdajbd2
$PCP_PMDAS_DIR/jbd2/Remove
script d'annulation de l'installation pour l'agent pmdajbd2
$PCP_LOG_DIR/pmcd/jbd2.log
fichier journal par défaut pour les messages d'erreur et autres informations provenant de pmdajbd2

ENVIRONNEMENT PCP

Les variables d'environnement commençant par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE DÉBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à résoudre les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

VOIR AUSSI
