PMDAOPENVSWITCH(1) Manuel des commandes générales PMDAOPENVSWITCH(1)

NOM

pmdaopenvswitch - PMDA OpenvSwitch

DESCRIPTION

pmdaopenvswitch est un agent de domaine de métriques de performance (PMDA) qui exporte les valeurs métriques pour chaque commutateur virtuel openvswitch configuré sur le système local.

INSTALLATION

Installez le PMDA openvswitch en utilisant le script d'installation en tant que root :

# cd $PCP_PMDAS_DIR/openvswitch
# ./Install

Pour désinstaller, procédez comme suit en tant que root :

# cd $PCP_PMDAS_DIR/openvswitch
# ./Remove

pmdaopenvswitch est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts d'installation et de désinstallation notifient pmcd(1) lorsque l'agent est installé ou désinstallé.

FICHIERS

$PCP_PMDAS_DIR/openvswitch/Install
script d'installation pour l'agent pmdaopenvswitch
$PCP_PMDAS_DIR/openvswitch/Remove
script d'annulation d'installation pour l'agent pmdaopenvswitch
$PCP_LOG_DIR/pmcd/openvswitch.log
fichier journal par défaut pour les messages d'erreur de pmdaopenvswitch

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1), pmcd(1), pminfo(1) et pmpython(1).
