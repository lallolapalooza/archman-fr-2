pmUnpackHighResEventRecords(3)

Paquet: pcp

Licences: GPL-2.0-or-later, LGPL-2.1-or-later, CC-BY-3.0

PMUNPACKEVENTRECORDS(3) Manuel des fonctions de bibliothèque PMUNPACKEVENTRECORDS(3)

NOM

pmUnpackHighResEventRecords, pmUnpackEventRecords - dépaqueter les enregistrements d'événements

SYNTAXE C

#include <pcp/pmapi.h>

int pmUnpackHighResEventRecords(pmValueSet *vsp,
int idx, pmResult ***hrap);

int pmUnpackEventRecords(pmValueSet *vsp,
int idx, pmResult_v2 ***rap);

cc ... -lpcp

DESCRIPTION

Les enregistrements d'événements sont codés sous forme d'un tableau compacté d'enregistrements dans un pmResult en utilisant une métrique conteneur avec une valeur de type PM_TYPE_HIGHRES_EVENT et un pmResult_v2 lors de l'utilisation d'une métrique avec une valeur de type PM_TYPE_EVENT.

pmUnpackHighResEventRecords et pmUnpackEventRecords peuvent être utilisés pour dépaqueter les enregistrements d'événements à partir d'une valeur métrique identifiée par vsp et idx. Si la métrique a une valeur singulière, idx doit être 0, sinon la valeur d'instance ordinale identifiée par idx sera dépaquetée, c'est-à-dire vsp->vlist[idx]. Les enregistrements dépaquetés sont transformés en structures pmResult ou pmResult_v2, une par enregistrement d'événement et une métrique par paramètre d'événement, et hrap ou rap est retourné comme pointeur vers un tableau (terminé par un pointeur NULL) de pointeurs vers les structures de résultat.

La seule différence entre les deux types de résultats est l'échelle de l'horodatage ; le pmResult permet une précision nanoseconde, tandis que pmResult_v2 permet une résolution microseconde.

Certaines informations de contrôle des enregistrements d'événements compactés sont dépaquetées en métriques « anonymes » supplémentaires comme suit :

1.
Si l'enregistrement d'événement a une valeur de drapeaux non nulle, alors le pmResult/pmResult_v2 correspondant aura la valeur des drapeaux codée avec la métrique supplémentaire event.flags qui est insérée avant tous les autres paramètres d'événement.
2.
Si le drapeau d'enregistrement d'événement est défini sur PM_EVENT_FLAG_MISSED, alors le pmResult/pmResult_v2 correspondant aura une métrique event.missed avec une valeur égale au nombre d'enregistrements d'événements « manqués » parce que le PMDA n'a pas pu suivre, ou le client PMAPI n'a pas collecté les enregistrements d'événements assez rapidement.

pmUnpackHighResEventRecords retourne le nombre de structures pmResult comme valeur de retour, qui est >= 0 en cas de succès. De même, pmUnpackEventRecords retourne le nombre de structures pmResult_v2 comme valeur de retour, qui est >= 0 en cas de succès.

hrap et les structures pmResult associées peuvent être libérés en utilisant la fonction de commodité pmFreeHighResEventResult(3).

De même, rap et les structures pmResult_v2 associées peuvent être libérés en utilisant la fonction de commodité pmFreeEventResult(3).

VALEUR DE RETOUR

Les erreurs suivantes sont possibles :

PM_ERR_CONV
Les valeurs associées à vsp ne sont pas codées en utilisant le format PM_VAL_DPTR ou PM_VAL_SPTR, ou les drapeaux en tête de l'enregistrement d'événement ont une valeur inattendue.
PM_ERR_INST
La valeur associée à vsp n'est pas singulière comme prévu.
PM_ERR_TYPE
vsp n'est pas une valeur de type PM_TYPE_HIGHRES_EVENT pour pmUnpackHighResEventRecords ou PM_TYPE_EVENT pour pmUnpackEventRecords.
PM_ERR_TOOSMALL
La valeur identifiée par vsp n'est pas légale car la longueur de la valeur est inférieure à la taille minimale, ou le nombre d'enregistrements d'événements codés dans la structure (en-tête de valeur) pmHighResEventArray/pmEventArray est négatif, ou le nombre d'enregistrements d'événements manqués dans le tableau est négatif.
PM_ERR_TOOBIG
Soit vsp indique que plus d'une valeur est présente (tous les enregistrements d'événements sont attendus dans une seule valeur métrique), soit lors du dépaquetage des enregistrements d'événements, le traitement se poursuit au-delà de la fin de la valeur englobante. Indique une corruption de l'enregistrement d'événement compacté.
PM_ERR_TYPE
Les paramètres d'événement doivent avoir l'un des types arithmétiques, sinon PM_TYPE_AGGREGATE, PM_TYPE_STRING ou PM_TYPE_AGGREGATE_STATIC.
autres valeurs < 0
se référer à pmErrStr(3).
