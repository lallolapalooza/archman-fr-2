pmdaDesc(3)

PMDADESC(3) Manuel des fonctions de bibliothèque PMDADESC(3)

NOM

pmdaDesc - obtenir la description d'une métrique à partir d'un PMDA

SYNTAXE C

#include <pcp/pmapi.h>
#include <pcp/pmda.h>

int pmdaDesc(pmID pmid, pmDesc *desc, pmdaExt *pmda);

cc ... -lpcp_pmda -lpcp

DESCRIPTION

pmdaDesc utilise les structures de données standard de PMDA(3) pour retourner la description pmDesc dans desc pour la métrique identifiée par pmid.

AVERTISSEMENT

Le PMDA doit utiliser PMDA_INTERFACE_2 ou une version ultérieure, comme spécifié dans l'appel à pmdaDSO(3) ou pmdaDaemon(3).

DIAGNOSTICS

Si le pmid ne correspond à aucune métrique prise en charge par ce PMDA, pmdaDesc retourne PM_ERR_PMID.

VOIR AUSSI

PMAPI(3), PMDA(3), pmdaDaemon(3), pmdaDSO(3) et pmLookupDesc(3).
