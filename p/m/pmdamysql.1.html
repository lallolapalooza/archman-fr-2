PMDAMYSQL(1) Manuel des commandes générales PMDAMYSQL(1)

NOM

pmdamysql — PMDA pour les bases de données MySQL et MariaDB

DESCRIPTION

pmdamysql est un PMDA Performance Co-Pilot qui extrait les données de performance en temps réel d'une base de données MySQL ou MariaDB en cours d'exécution.

INSTALLATION

pmdamysql utilise un fichier de configuration parmi (dans cet ordre) :

  • /etc/pcpdbi.conf
  • $PCP_PMDAS_DIR/mysql/mysql.conf

Ce fichier peut contenir des valeurs remplacées (code Perl) pour les paramètres listés au début de pmdamysql.pl, à savoir :

  • nom de la base de données (voir DBI(3) pour plus de détails, par défaut "DBI:mysql:mysql")
  • nom d'utilisateur de la base de données (par défaut "dbmonitor")
  • mot de passe de la base de données (par défaut "dbmonitor")
  • compte de connexion (par défaut "pcp")

Sur certaines versions de MariaDB (10+), le schéma de performance est désactivé par défaut et doit être activé pour que le PMDA fonctionne. Ceci est réalisé en ajoutant la chaîne "performance_schema" dans la section "[mysqld]" du fichier de configuration MariaDB (soit my.cnf, soit my.ini). L'instruction SQL "SHOW ENGINES" montre la prise en charge du schéma de performance.

Une fois ces actions de configuration initiales terminées, vous pouvez accéder aux noms et valeurs des métriques de performance mysql en faisant ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/mysql
# ./Install

Pour désinstaller, il faut faire ce qui suit en tant que root :

# cd $PCP_PMDAS_DIR/mysql
# ./Remove

pmdamysql est lancé par pmcd(1) et ne devrait jamais être exécuté directement. Les scripts Install et Remove notifient pmcd(1) lorsque l'agent est installé ou désinstallé.

Valeurs binaires de statut en texte

Certaines valeurs de statut sont sous la forme OUI/NON ou ACTIVÉ/DÉSACTIVÉ.

Comme celles-ci ne peuvent pas être interprétées par des outils tels que pmie(1), elles ont été dupliquées avec une extension _num et les valeurs 1 (OUI/ACTIVÉ) ou 0 (NON/DÉSACTIVÉ).

Ex:

  • mysql.slave_status.slave_io_running
  • mysql.slave_status.slave_io_running_num

FICHIERS

/etc/pcpdbi.conf
fichier de configuration pour tous les moniteurs de base de données PCP
$PCP_PMDAS_DIR/mysql/mysql.conf
fichier de configuration pour pmdamysql
$PCP_PMDAS_DIR/mysql/Install
script d'installation pour l'agent pmdamysql
$PCP_PMDAS_DIR/mysql/Remove
script d'annulation d'installation pour l'agent pmdamysql
$PCP_LOG_DIR/pmcd/mysql.log
fichier journal par défaut pour les messages d'erreur de pmdamysql

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1), pmcd(1), pmdadbping(1), pmie(1) et DBI(3).
