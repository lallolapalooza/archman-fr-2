pmParseInterval(3)

PMPARSEINTERVAL(3) Manuel des fonctions de bibliothèque PMPARSEINTERVAL(3)

NOM

pmParseInterval - convertir une chaîne d'intervalle en structure de temps binaire

SYNTAXE C

#include <pcp/pmapi.h>

int pmParseInterval(const char *string,
struct timespec *rslt, char **errmsg);

cc ... -lpcp

DESCRIPTION

pmParseInterval analyse l'argument string spécifiant un intervalle de temps et remplit les composantes tv_sec et tv_nsec de la structure rslt pour représenter cet intervalle (précision nanoseconde).

La chaîne d'entrée string est le plus souvent l'argument suivant une option de ligne de commande -t d'une application PCP, et la syntaxe est entièrement décrite dans PCPIntro(1).

DIAGNOSTICS

pmParseInterval retourne 0 et errmsg n'est pas défini si l'analyse est réussie.

Si la chaîne string donnée ne respecte pas la syntaxe requise, pmParseInterval retourne -1 et un message d'erreur alloué dynamiquement dans errmsg. Le message d'erreur est terminé par un saut de ligne et inclut le texte de la chaîne d'entrée string ainsi qu'un indicateur de la position à laquelle l'erreur a été détectée, par exemple :

4minutes 30mumble
^ -- valeur inattendue

En cas d'erreur, l'appelant est responsable d'appeler free(3) pour libérer l'espace alloué pour errmsg.

COMPATIBILITÉ

Avant PCP 7.0, l'argument rslt était une struct timeval. Pour prendre en charge la transition PMAPI, l'ancienne interface et sémantique peuvent être utilisées si les applications sont recompilées avec -DPMAPI_VERSION=2.

Pendant un temps dans PCP 6.x, il existait une routine avec la même sémantique que l'actuelle pmParseInterval appelée pmParseHighResInterval, bien que celle-ci soit maintenant dépréciée et que le support de compilation pour pmParseHighResInterval sera supprimé dans une future version.

VOIR AUSSI

PCPIntro(1), free(3), PMAPI(3) et pmParseTimeWindow(3).
