NOM

pmdabpf - PMDA eBPF

SYNTAXE

$PCP_PMDAS_DIR/bpf/pmdabpf [-D debug]

DESCRIPTION

pmdabpf est un Agent de Domaine de Métriques de Performance (PMDA) de Performance Co-Pilot (PCP) qui extrait des données de performance en direct des programmes eBPF en utilisant BPF CO-RE (libbpf et BTF).

pmdabpf charge et agit comme un pont pour un nombre quelconque de modules PMDA bpf distincts et configurés. Les outils libbpf existants devraient pouvoir être utilisés avec les modules PMDA bpf avec un effort raisonnable.

Voir la documentation eBPF, libbpf et BPF CO-RE pour des descriptions détaillées.

CONFIGURATION

pmdabpf lit un fichier de configuration obligatoire de style ini :

$PCP_PMDAS_DIR/bpf/bpf.conf

Chaque section du fichier correspond à un module PMDA bpf. Les options globales suivantes sont disponibles pour chaque module (leurs valeurs par défaut sont indiquées entre parenthèses) :

enabled (absent)
Une valeur booléenne pour spécifier si ce module PMDA bpf doit être démarré ou non.

Les modules peuvent également prendre en charge des options de configuration supplémentaires spécifiques au module. Reportez-vous au fichier de configuration par défaut pour connaître les options prises en charge.

INSTALLATION

Pour installer, les opérations suivantes doivent être effectuées en tant que root :

# cd $PCP_PMDAS_DIR/bpf
# ./Install

Pour désinstaller, les opérations suivantes doivent être effectuées en tant que root :

# cd $PCP_PMDAS_DIR/bpf
# ./Remove

pmdabpf est lancé par pmcd(1) et ne doit jamais être exécuté directement. Les scripts Install et Remove informent pmcd(1) lorsque l'agent est installé ou désinstallé.

Certains modules ne commenceront à fournir des valeurs qu'après avoir collecté des données sur l'activité système associée.

FICHIERS

$PCP_PMDAS_DIR/bpf/bpf.conf
fichier de configuration de l'agent pmdabpf
$PCP_PMDAS_DIR/bpf/modules/*.{o,so}
modules PMDA bpf disponibles pour l'agent pmdabpf
$PCP_PMDAS_DIR/bpf/Install
script d'installation de l'agent pmdabpf
$PCP_PMDAS_DIR/bpf/Remove
script d'annulation de l'installation de l'agent pmdabpf
$PCP_LOG_DIR/pmcd/bpf.log
fichier journal par défaut pour les messages de l'agent pmdabpf

Notez que la valeur usuelle/par défaut pour $PCP_PMDAS_DIR est /var/lib/pcp/pmdas et la valeur par défaut pour $PCP_LOG_DIR est /var/log/pcp, mais ces paramètres dépendent de la plateforme.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. À chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

OPTIONS DE BONNE EXÉCUTION

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à diagnostiquer les problèmes, bien que les informations soient parfois cryptiques et principalement destinées à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

VOIR AUSSI

PCPIntro(1), bpf(1) et pmcd(1).
