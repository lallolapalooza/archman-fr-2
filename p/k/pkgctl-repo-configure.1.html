NOM

pkgctl-repo-configure - Configurer un clone selon les spécifications de la distribution

SYNTAXE

pkgctl repo configure [OPTIONS] [PATH...]

DESCRIPTION

Configure les dépôts d'empaquetage Git conformément aux spécifications de la distribution et aux réglages de makepkg.conf.

Les informations d'auteur Git et la clé de signature utilisée sont configurées à partir de makepkg.conf, lu depuis n'importe quel emplacement valide tel que /etc ou XDG_CONFIG_HOME.

Le protocole distant est automatiquement déterminé à partir de l'adresse e-mail de l'auteur, en choisissant SSH pour toutes les identités de mainteneurs officiels et HTTPS en lecture seule sinon.

Les exclusions et les hooks Git par défaut sont appliqués au dépôt configuré.

OPTIONS

--protocol https

Configure l'URL distante pour utiliser https

-j, --jobs N

Exécute jusqu'à N jobs en parallèle. Par défaut, le nombre de jobs est égal au nombre d'unités de traitement disponibles. Pour un traitement séquentiel, cette option doit être passée avec 1.

-h, --help

Afficher un texte d'aide
