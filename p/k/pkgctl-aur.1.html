NOM

pkgctl-aur - Interagir avec le Arch User Repository (AUR)

SYNTAXE

pkgctl aur [OPTIONS] [SOUS-COMMANDE]

DESCRIPTION

Fournit une suite d'outils conçus pour gérer et interagir avec le Arch User Repository (AUR). Il simplifie diverses tâches liées à l'AUR, notamment l'importation de dépôts, la gestion des paquets et la transition des paquets entre les dépôts officiels et l'AUR.

OPTIONS

-h, --help

Afficher le texte d'aide

SOUS-COMMANDES

pkgctl aur drop-from-repo

Retirer un paquet du dépôt officiel vers l'AUR

VOIR AUSSI

pkgctl-aur-drop-from-repo(1)
