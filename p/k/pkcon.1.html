PKCON(1) Commandes utilisateur PKCON(1)

NOM

pkcon - Client console de PackageKit

SYNTAXE

pkcon [OPTION...] [COMMANDE]

DESCRIPTION

Cette page de manuel documente brièvement la commande pkcon.

pkcon est le client en ligne de commande pour PackageKit.

COMMANDES

pkcon connaît les commandes suivantes. Selon le backend utilisé, toutes ne sont pas forcément disponibles.

backend-details

Affiche des informations sur le backend PackageKit utilisé.

get-roles

Liste les rôles qu'une transaction peut avoir.

get-groups

Liste les groupes de paquets disponibles.

get-filters

Liste les filtres disponibles.

get-transactions

Liste les transactions connues.

get-time ROLE

Affiche le temps écoulé depuis la dernière transaction avec le rôle donné.

search [name|details|group|file] DATA

Recherche un paquet correspondant aux données fournies. La recherche s'effectue dans les informations du paquet indiquées par le premier argument : nom, détails, groupe ou fichiers.

install PACKAGES

Installe les paquets donnés depuis les dépôts.

install-local FILES

Installe les paquets donnés depuis le système de fichiers local.

download DIRECTORY PACKAGES

Télécharge les paquets donnés depuis les dépôts et les stocke dans le répertoire donné.

install-sig TYPE KEY_ID PACKAGE

Installe une signature de paquet. Seules les signatures GPG sont supportées pour le moment.

remove PACKAGE

Supprime le paquet donné.

update [PACKAGES]

Met à jour le système en installant les mises à jour disponibles. Si une liste de paquets est spécifiée, installe uniquement les mises à jour pour ces paquets.

refresh [force]

Rafraîchit les informations mises en cache sur les mises à jour disponibles.

resolve PACKAGE

Résout le nom de paquet donné et affiche des informations sur les paquets installés ou disponibles et les mises à jour.

upgrade-system DISTRIBUTION [minimal|default|complete]

Met à niveau le système vers la distribution donnée.

get-updates

Liste les mises à jour disponibles.

get-distro-upgrades

Liste les mises à niveau de distribution disponibles.

depends-on PACKAGE

Liste les dépendances du paquet donné.

required-by PACKAGE

Liste les paquets qui nécessitent le paquet donné.

get-details PACKAGE

Affiche les détails sur le paquet disponible ou installé avec le nom donné.

get-details-local FILE

Affiche les détails sur le paquet local.

get-files PACKAGE

Liste les fichiers contenus dans le paquet donné.

get-files-local FILE

Liste les fichiers contenus dans le paquet local.

get-update-detail PACKAGE

Affiche le journal des modifications du paquet pour le paquet donné.

get-packages

Liste tous les paquets disponibles et installés.

repo-list

Liste tous les dépôts de paquets configurés.

repo-enable REPOSITORY

Active le dépôt donné.

repo-disable REPOSITORY

Désactive le dépôt donné.

repo-set-data REPOSITORY PARAMETER DATA

Définit le paramètre donné à la valeur donnée pour le dépôt.

repo-remove REPOSITORY PARAMETER

Supprime le dépôt et éventuellement tous les paquets qui en ont été installés.

what-provides STRING

Liste les paquets qui fournissent la chaîne donnée.

accept-eula EULA_ID

Accepte le CLUF (Contrat de Licence d'Utilisateur Final) avec l'identifiant donné.

get-categories

Liste les catégories disponibles.

repair

Tente de réparer la base de données des paquets du système.

offline-get-prepared

Affiche les informations sur la mise à jour hors ligne préparée. Si aucune mise à jour hors ligne n'est préparée, quitte avec le code de sortie 1.

offline-trigger

Déclenche une mise à jour hors ligne.

offline-status

Affiche les informations sur le résultat de la dernière mise à jour hors ligne.

OPTIONS

Les options suivantes peuvent être utilisées pour influencer le comportement de pkcon.

--version

Affiche la version du programme et quitte.

-h, --help

Affiche les options d'aide.

--help-all

Affiche toutes les options d'aide.

--filter FILTER

Définit le filtre à utiliser.

-y, --noninteractive

Installe les paquets sans demander de confirmation.

--only-download

Prépare la transaction en téléchargeant uniquement les paquets.

-n, --background

Exécute la commande en utilisant la bande passante réseau inactive et également en utilisant moins d'énergie.

-p, --plain

Affiche à l'écran une sortie lisible par machine, plutôt que d'utiliser des widgets animés.

-v, --verbose

Affiche les informations de débogage.

-c, --cache-age AGE

Définit l'âge maximum acceptable des métadonnées mises en cache, en secondes. Utilisez -1 pour 'jamais'.

--allow-untrusted

Autorise l'installation de paquets non fiables.

--allow-downgrade

Autorise la rétrogradation des paquets pendant la transaction.

--allow-reinstall

Autorise la réinstallation des paquets pendant la transaction.

VALEURS DE RETOUR

0

Succès

1

Échec avec une erreur interne diverse.

3

Échec dû à une erreur de syntaxe, ou incapacité à analyser la commande.

4

Échec car un fichier ou un répertoire n'a pas été trouvé.

5

Rien d'utile n'a été fait.

6

L'initialisation a échoué, par exemple la configuration du proxy réseau.

7

La transaction a échoué, consultez l'erreur détaillée pour plus d'informations.
