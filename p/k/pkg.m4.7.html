NOM

pkg.m4 — macros autoconf pour l'utilisation de pkgconf

SYNTAXE

PKG_PREREQ

PKG_PROG_PKG_CONFIG

PKG_CHECK_MODULES

PKG_CHECK_MODULES_STATIC

PKG_INSTALLDIR

PKG_NOARCH_INSTALLDIR

PKG_CHECK_VAR

PKG_WITH_MODULES

PKG_HAVE_WITH_MODULES

PKG_HAVE_DEFINE_WITH_MODULES

DESCRIPTION

pkg.m4 est une collection de macros autoconf qui aident à configurer les indicateurs du compilateur et de l'éditeur de liens pour les bibliothèques de développement. Cela permet aux systèmes de construction de détecter d'autres dépendances et de les utiliser avec la chaîne d'outils système.

MACROS AUTOCONF

PKG_PREREQ(VERSION-MINIMALE)

Vérifie que la version des macros autoconf pkg.m4 en cours d'utilisation est au moins VERSION-MINIMALE. Ceci peut être utilisé pour s'assurer qu'une macro pkg.m4 particulière sera disponible.

PKG_PROG_PKG_CONFIG([VERSION-MINIMALE])

Recherche une implémentation de pkg-config qui est au moins VERSION-MINIMALE ou plus récente.

PKG_CHECK_MODULES(PREFIXE-VARIABLE, MODULES [,ACTION-SI-TROUVE [,ACTION-SI-NON-TROUVE]])

PKG_CHECK_MODULES_STATIC(PREFIXE-VARIABLE, MODULES [,ACTION-SI-TROUVE [,ACTION-SI-NON-TROUVE]])

Vérifie si un ensemble de modules donné existe et, si c'est le cas, définit les variables CFLAGS et LIBS précédées par PREFIXE-VARIABLE avec la sortie de --cflags et --libs respectivement.

Les arguments optionnels ACTION-SI-TROUVE et ACTION-SI-NON-TROUVE sont des fragments de shell qui doivent être exécutés si l'ensemble de modules est trouvé ou non trouvé.

Si $PKG_CONFIG n'est pas défini, la macro PKG_PROG_PKG_CONFIG sera exécutée pour localiser une implémentation de pkg-config.

La macro PKG_CHECK_MODULES_STATIC offre le même comportement que PKG_CHECK_MODULES avec la liaison statique activée via l'indicateur --static.

PKG_INSTALLDIR(RÉPERTOIRE)

Définit la variable $pkgconfigdir comme l'emplacement où un paquet doit installer les fichiers .pc de pkg-config.

Par défaut, le répertoire est $libdir/pkgconfig, mais la valeur par défaut peut être modifiée en passant le paramètre RÉPERTOIRE.

Cette valeur peut être remplacée par le paramètre de configuration --with-pkgconfigdir.

PKG_NOARCH_INSTALLDIR(RÉPERTOIRE)

Définit la variable $noarch_pkgconfigdir comme l'emplacement où un paquet doit installer les fichiers .pc de pkg-config.

Par défaut, le répertoire est $datadir/pkgconfig, mais la valeur par défaut peut être modifiée en passant le paramètre RÉPERTOIRE.

Cette valeur peut être remplacée par le paramètre de configuration --with-noarch-pkgconfigdir.

PKG_CHECK_VAR(VARIABLE, MODULE, VARIABLE-CONFIG, [ACTION-SI-TROUVE], [ACTION-SI-NON-TROUVE])

Récupère la valeur de la variable pkg-config VARIABLE-CONFIG à partir de MODULE et la stocke dans la variable VARIABLE.

Notez que l'utilisation répétée de VARIABLE n'est pas recommandée car la vérification sera ignorée si la variable est déjà définie.

PKG_WITH_MODULES(PREFIXE-VARIABLE, MODULES, [ACTION-SI-TROUVE],[ACTION-SI-NON-TROUVE], [DESCRIPTION], [DÉFAUT])

Prépare une option de configuration "--with-" en utilisant le nom en minuscules PREFIXE-VARIABLE, fusionnant le comportement de AC_ARG_WITH et PKG_CHECK_MODULES en une seule macro.

PKG_HAVE_WITH_MODULES(PREFIXE-VARIABLE, MODULES, [DESCRIPTION], [DÉFAUT])

Macro de commodité pour déclencher AM_CONDITIONAL après une vérification PKG_WITH_MODULES. PREFIXE-VARIABLE est exporté comme variable make.

PKG_HAVE_DEFINE_WITH_MODULES(PREFIXE-VARIABLE, MODULES, [DESCRIPTION], [DÉFAUT])

Macro de commodité pour déclencher AM_CONDITIONAL et AC_DEFINE après une vérification PKG_WITH_MODULES. PREFIXE-VARIABLE est exporté comme variable make.
