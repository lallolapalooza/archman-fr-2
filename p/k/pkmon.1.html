NOM

pkmon - Client console de PackageKit

SYNTAXE

pkmon [search] [debug install] [remove]

DESCRIPTION

Cette page de manuel documente brièvement la commande pkmon.

pkmon est le client en ligne de commande pour PackageKit.

VALEURS DE RETOUR

0

Succès
