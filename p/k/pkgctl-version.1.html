NOM

pkgctl-version - Vérifier et gérer les versions des paquets par rapport à l'amont

SYNTAXE

pkgctl version [OPTIONS] [SOUS-COMMANDE]

DESCRIPTION

Commandes liées aux versions des paquets, y compris la vérification des paquets obsolètes.

Utilise nvchecker(1) et un fichier .nvchecker.toml situé à côté du PKGBUILD.

CONFIGURATION

Le fichier .nvchecker.toml doit contenir une section correspondant au pkgbase du paquet. La section pkgbase dans le fichier .nvchecker.toml spécifie la source et la méthode pour vérifier la dernière version du paquet correspondant.

Utilisez pkgctl-version-setup(1) pour détecter et configurer automatiquement un fichier de configuration nvchecker de base basé sur le tableau source du PKGBUILD.

Pour des informations détaillées sur les diverses options de configuration disponibles pour le fichier .nvchecker.toml, reportez-vous à la section des fichiers de configuration dans nvchecker(1). Cette documentation fournit des informations sur les options possibles qui peuvent être utilisées pour personnaliser le processus de vérification des versions.

Pour fournir des jetons GitHub ou GitLab à nvchecker, un fichier keyfile.toml doit être placé dans le répertoire $XDG_CONFIG_HOME/nvchecker`. Ce fichier clé est utilisé pour fournir les jetons d'authentification nécessaires pour accéder à l'API GitHub ou GitLab.

OPTIONS

-h, --help

Affiche le texte d'aide

SOUS-COMMANDES

pkgctl version check

Compare les versions locales des paquets à l'amont

pkgctl version setup

Détecte et configure automatiquement un fichier de configuration nvchecker de base

pkgctl version upgrade

Ajuste le PKGBUILD pour correspondre à la dernière version amont

VOIR AUSSI

pkgctl-version-check(1) pkgctl-version-setup(1) pkgctl-version-upgrade(1)
