NOM

pktopbm - convertir une police au format packed (PK) en PBM

SYNTAXE

pktopbm fichier_pk[.pk] [ -x largeur ] [ -y hauteur ] [-c num] fichier_pbm ...

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pktopbm lit un fichier de police packed (PK) en entrée et produit des images PBM en sortie. Si le nom de fichier '-' est utilisé pour l'un des noms de fichiers, le flux d'entrée standard (ou la sortie standard le cas échéant) sera utilisé. Si la largeur ou la hauteur est spécifiée, cette valeur sera utilisée pour tous les bitmaps produits. De plus, si une ou les deux valeurs sont spécifiées, le bitmap sera repositionné avec le hoffset et le voffset donnés dans le fichier pk. Le point de base sera placé dans le coin inférieur gauche du bitmap. Si le bitmap est plus grand que la taille spécifiée, il sera tronqué en haut ou à droite.

OPTIONS

-c num
Définit le numéro du caractère du prochain bitmap écrit à num.
-x largeur
Définit la largeur de l'image en colonnes.
-y hauteur
Définit la hauteur de l'image en lignes.
