NOM

pk2bm - créer une image bitmap à partir d'une police pk TeX

SYNTAXE:

pk2bm [-bh] [-Wlargeur] [-Hhauteur] -ccaractère pkfont

pk2bm [-bh] [-Wlargeur] [-Hhauteur] -ocaractère octal pkfont

DESCRIPTION

Ce programme génère une image bitmap (fichier ASCII) utilisable pour créer des applications X11. Le fichier bitmap contient tous les pixels du caractère spécifié (via l'option -c ou -o) du pkfont donné. Le format est décrit dans bitmap(X11).

Le pkfont est un fichier de police compressé généré par gftopk(TeX) à partir d'un gffont. Un gffont est la sortie de METAFONT, un programme de conception de polices de manière indépendante du périphérique.

Avec l'option -b, une image bitmap est générée où tous les pixels noirs sont dessinés comme un `*' et tous les bits blancs comme un `.'. Avec l'option -h, une vidange hexadécimale de l'image bitmap est générée.

Les options -W et/ou -H peuvent être utilisées pour créer une image bitmap d'une `largeur' et/ou d'une `hauteur' de pixels respectives. Le bitmap-pk sera dans ce cas centré selon ces nouvelles dimensions.

La sortie est écrite sur la sortie standard.
