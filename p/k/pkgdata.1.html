NOM

pkgdata - données de paquets pour utilisation par ICU

SYNOPSIS

pkgdata [ -h, -?, --help ] [ -v, --verbose ] [ -c, --copyright | -C, --comment commentaire ] [ -m, --mode mode ] -p, --name nom -O, --bldopt options [ -e, --entrypoint nom ] [ -r, --revision version ] [ -F, --rebuild ] [ -I, --install ] [ -s, --sourcedir source ] [ -d, --destdir destination ] [ -T, --tempdir répertoire ] [ fichier ... ]

DESCRIPTION

pkgdata prend un ensemble de fichiers de données et les conditionne pour une utilisation par ICU ou par des applications qui utilisent ICU. La raison typique de conditionner des fichiers en utilisant pkgdata est de faciliter leur distribution et d'accélérer leur chargement par ICU tout en réduisant la consommation de ressources système limitées telles que les descripteurs de fichiers. Les données conditionnées permettent également de distribuer les applications avec moins de fichiers de ressources, voire avec aucun si elles sont liées directement aux données conditionnées.

pkgdata prend en charge plusieurs méthodes de conditionnement de données qui servent à des fins différentes.

Le mode de conditionnement par défaut est common, ou archive. Dans ce mode, les différents fichiers de données sont regroupés dans un fichier dépendant de l'architecture qui peut ensuite être mappé en mémoire pour être utilisé par ICU. Les données conditionnées de cette manière seront recherchées dans le répertoire de données ICU. Un tel conditionnement est facile à utiliser pour les bundles de ressources des applications, par exemple, tant que l'application peut installer le fichier conditionné dans le répertoire de données ICU.

Un autre mode de conditionnement est le mode dll, ou library, où les fichiers de données sont compilés en une bibliothèque partagée. ICU était capable de charger dynamiquement ces bibliothèques partagées, mais depuis ICU 2.0, ce support a été supprimé. Ce mode reste utile pour deux raisons principales : construire ICU lui-même, car les données ICU sont conditionnées en une bibliothèque partagée par défaut ; et construire des bundles de ressources qui sont liés à l'application qui les utilise. Ces bundles de ressources peuvent ensuite être placés n'importe où où le chargeur dynamique du système recherche des bibliothèques partagées, au lieu d'être contraints de résider dans le répertoire de données ICU.

Le mode de conditionnement static est similaire à celui de la bibliothèque partagée, sauf qu'il produit une bibliothèque statique.

Enfin, pkgdata prend en charge un mode files qui copie simplement les fichiers de données au lieu de les conditionner en un seul fichier ou une seule bibliothèque. Ce mode est principalement destiné à supporter la compilation d'ICU avant qu'il ne soit conditionné en paquets séparés et petits pour la distribution avec des systèmes d'exploitation comme Debian GNU/Linux, par exemple. Veuillez vous référer à la documentation de conditionnement dans la distribution source d'ICU pour plus d'informations sur l'utilisation de ce mode.

pkgdata construit, conditionne, installe ou nettoie les données appropriées en fonction des options données, sans qu'il soit nécessaire d'appeler GNU make anymore.

OPTIONS

-h, -?, --help
Affiche l'aide sur l'utilisation et quitte.
-v, --verbose
Affiche des messages informatifs supplémentaires pendant l'exécution.
-c, --copyright
Inclut une notice de copyright dans les données binaires.
-C, --comment commentaire
Inclut le commentaire spécifié dans les données résultantes au lieu de la notice de copyright ICU.
-m, --mode mode
Définit le mode de conditionnement à utiliser par pkgdata. Les différents modes et leur signification sont expliqués dans la section DESCRIPTION ci-dessus. Les noms de modes valides sont common (ou archive), dll (ou library), et files.
-O, --bldopt options
Spécifie les options pour le constructeur. Le constructeur est utilisé en interne par pkgdata pour générer le fichier conditionné correct. Ces options comprennent, sans s'y limiter, la définition de variables utilisées par make(1) pendant la construction du fichier conditionné. Remarque : Si icu-config est disponible, cette option n'est pas nécessaire.
-p, --name nom
Définit le nom du fichier conditionné à nom. Ce nom est également utilisé comme nom d'entrée par défaut après avoir été transformé en un identifiant C valide.
-e, --entrypoint nom
Définit le point d'entrée des données (utilisé pour le lien avec les données sous forme de bibliothèque partagée) à nom. Le nom d'entrée par défaut est le nom défini par l'option -n, --name.
-r, --revision version
Active la gestion des versions de la bibliothèque partagée produite en mode dll ou library. Le numéro de version a le format majeur.mineur.niveau_correctif et toutes les parties sauf majeur sont facultatives. Si seul majeur est fourni, la version est supposée être majeur.0 à des fins de versioning.
-F, --rebuild
Force la reconstruction de toutes les données et leur reconditionnement.
-I, --install
Installe le fichier conditionné (ou tous les fichiers en mode files). Si la variable DESTDIR est définie, elle sera utilisée pour l'installation.
-s, --sourcedir source
Définit le répertoire source à source. Le répertoire source par défaut est le répertoire courant.
-d, --destdir destination
Définit le répertoire de destination à destination. Le répertoire de destination par défaut est le répertoire courant.
-T, --tempdir répertoire
Définit le répertoire utilisé pour générer les fichiers temporaires à répertoire. Le répertoire temporaire par défaut est le même que le répertoire de destination tel que défini par l'option -d, --destdir.

NOM

pkgdata - Outil d'interrogation des métadonnées des paquets

SYNOPSIS

pkgdata [OPTIONS] [QUERY...]

DESCRIPTION

pkgdata est un outil de ligne de commande conçu pour interroger les métadonnées des paquets installés sur votre système Arch Linux.

Il permet d'accéder à diverses informations sur les paquets, telles que leur nom, leur version, leur description, leurs dépendances, leur taille, etc.

OPTIONS

-h, --help : Affiche ce message d'aide et quitte.

-v, --version : Affiche les informations de version et quitte.

-a, --arch : Spécifie l'architecture pour laquelle interroger les paquets (par défaut : architecture actuelle).

-i, --installed : Affiche uniquement les paquets installés.

-o, --optional : Affiche uniquement les paquets optionnels.

--no-optional : N'affiche pas les paquets optionnels.

-k, --search-key KEY : Recherche les paquets en utilisant la clé KEY.

-f, --field FIELD : Spécifie le champ à afficher pour chaque paquet correspondant (par défaut : nom).

--json : Affiche la sortie au format JSON.

--yaml : Affiche la sortie au format YAML.

AUTHORS

La liste complète des auteurs est disponible dans le code source du paquet.

VERSION

La version actuelle de pkgdata est disponible via l'option --version.
