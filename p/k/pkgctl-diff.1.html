NOM

pkgctl-diff - Compare les fichiers de paquets en utilisant différents modes.

SYNTAXE

pkgctl diff [OPTIONS] [MODES] [FICHIER|NOMPAQUET...]

DESCRIPTION

Recherche un paquet construit localement correspondant au PKGBUILD, et télécharge la dernière version de ce paquet depuis les dépôts Pacman. Il compare ensuite les archives de paquets en utilisant différents modes tout en utilisant par défaut une simple liste de contenu tar.

Lorsque deux paquets sont donnés, les compare l'un par rapport à l'autre. Lorsque un seul paquet est donné, l'utilise pour diff par rapport à celui construit localement.

Dans tous les cas, un nom de paquet sera converti en un nom de fichier depuis le cache ou le pool, et pkgctl diff procédera comme si ce nom de fichier avait été spécifié initialement.

OPTIONS

-M, --makepkg-config

Définit un fichier de configuration makepkg alternatif

-P, --pool=DIR

Recherche la cible de diff dans le répertoire du pool (par défaut '/srv/ftp/pool')

-v, --verbose

Fournit une sortie plus détaillée/non filtrée

-h, --help

Affiche un texte d'aide

OPTIONS DE SORTIE

--color[=QUAND]

Colore la sortie ; QUAND est 'jamais', 'toujours', ou 'auto' ; --color seul signifie --color=auto

-u, -U, --unified

Affiche 3 lignes de contexte unifié

-y, --side-by-side

Affiche en deux colonnes

-W, --width[=NUM]

Affiche au maximum NUM colonnes d'impression (par défaut 'auto') ; NUM peut être 'auto', 'columns' ou un nombre. 'auto' sera résolu à la longueur maximale de ligne des deux fichiers, garantissant que le diff ne sera pas tronqué.

MODES

-l, --list

Active le mode diff de liste de contenu tar (par défaut)

-d, --diffoscope

Active le mode diff diffoscope

-p, --pkginfo

Active le mode diff .PKGINFO

-b, --buildinfo

Active le mode diff .BUILDINFO
