NOM

pkgctl-issue - Gérer les problèmes de paquetage GitLab

SYNOPSIS

pkgctl issue [SOUS-COMMANDE] [OPTIONS]

DESCRIPTION

Gérer les problèmes de paquetage GitLab.

OPTIONS

-h, --help

Afficher un message d'aide

SOUS-COMMANDES

pkgctl issue close

Fermer un problème

pkgctl issue comment

Commenter un problème

pkgctl issue create

Créer un nouveau problème

pkgctl issue edit

Modifier et mettre à jour un problème

pkgctl issue list

Lister les problèmes de projet ou de groupe

pkgctl issue move

Déplacer un problème vers un autre projet

pkgctl issue reopen

Rouvrir un problème fermé

pkgctl issue view

Afficher les informations sur un problème

VOIR AUSSI

pkgctl-issue-close(1) pkgctl-issue-comment(1) pkgctl-issue-create(1) pkgctl-issue-edit(1) pkgctl-issue-list(1) pkgctl-issue-move(1) pkgctl-issue-reopen(1) pkgctl-issue-view(1)
