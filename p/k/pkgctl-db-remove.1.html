NOM

pkgctl-db-remove - Supprimer des paquets des dépôts binaires

SYNOPIS

pkgctl db remove [OPTIONS] [DÉPÔT] [PKGBASE]...

DESCRIPTION

Supprime des paquets des dépôts pacman. Par défaut, passer un pkgbase supprime tous les paquets divisés, les paquets de débogage ainsi que les entrées du dépôt d'état pour toutes les architectures existantes.

Soyez prudent lorsque vous utilisez l'option --partial, car elle peut très probablement entraîner des effets indésirables en laissant les paquets de débogage derrière, ainsi que des entrées orphelines dans le dépôt d'état.

OPTIONS

--partial

Supprime uniquement les noms de paquets partiels d'un paquet divisé. Cela laisse les paquets de débogage et les entrées pkgbase dans le dépôt d'état.

-a, --arch ARCH

Supprime uniquement une architecture spécifique (désactive la détection automatique). Par défaut, toutes les architectures sont supprimées lorsque cette option n'est pas utilisée.

--noconfirm

Ignore tous les messages de confirmation, ne doit être utilisé qu'avec prudence.

-h, --help

Affiche un texte d'aide
