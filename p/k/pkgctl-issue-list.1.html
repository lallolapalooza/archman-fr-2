NOM

pkgctl-issue-list - Lister les problèmes des projets ou groupes

SYNTAXE

pkgctl issue list [OPTIONS] [PKGBASE]

DESCRIPTION

La commande pkgctl issue list est utilisée pour lister les problèmes associés à un projet d'empaquetage spécifique ou au groupe d'empaquetage entier dans Arch Linux. Cette commande facilite la gestion efficace des problèmes en permettant aux utilisateurs de lister et de filtrer les problèmes en fonction de divers critères.

Les résultats peuvent également être affichés directement dans un navigateur web pour faciliter la navigation et la révision.

La commande offre des options de filtrage pour affiner les résultats. Les utilisateurs peuvent inclure les problèmes fermés, filtrer exclusivement pour les problèmes non confirmés, ou se concentrer sur les problèmes avec des étiquettes spécifiques telles que la priorité, la confidentialité, la résolution, la portée, la gravité et le statut.

De plus, les utilisateurs peuvent rechercher dans les titres ou les descriptions des problèmes et filtrer les problèmes par l'assigné ou l'auteur. Il existe également des raccourcis pratiques pour filtrer les problèmes assignés ou créés par l'utilisateur actuel.

Cette commande est particulièrement utile pour les mainteneurs de paquets et les contributeurs de la communauté Arch Linux qui ont besoin de suivre et de gérer efficacement les problèmes. Elle offre une vue complète du paysage des problèmes du projet ou du groupe, permettant aux mainteneurs de traiter et de prioriser efficacement les problèmes.

OPTIONS

-g, --group

Obtenir les problèmes de l'ensemble du sous-groupe d'empaquetage

-w, --web

Afficher les résultats dans un navigateur

-h, --help

Afficher un texte d'aide

OPTIONS DE FILTRE

-A, --all

Obtenir tous les problèmes, y compris les problèmes fermés

-c, --closed

Obtenir uniquement les problèmes fermés

-U, --unconfirmed

Raccourci pour filtrer par l'étiquette de statut non confirmé

--search RECHERCHE

Rechercher <chaîne> dans les champs définis par --in

--in EMPLACEMENT

Rechercher dans le titre ou la description (défaut : tout)

-l, --label NOM

Filtrer le problème par étiquette <nom>

--confidentiality TYPE

Filtrer par confidentialité

--priority PRIORITÉ

Raccourci pour filtrer par étiquette de priorité

--resolution RAISON

Raccourci pour filtrer par étiquette de résolution

--scope PORTÉE

Raccourci pour filtrer par étiquette de portée

--severity GRAVITÉ

Raccourci pour filtrer par étiquette de gravité

--status STATUT

Raccourci pour filtrer par étiquette de statut

--assignee NOMUTILISATEUR

Filtrer les problèmes assignés au nom d'utilisateur donné

--assigned-to-me

Raccourci pour filtrer les problèmes qui vous sont assignés

--author NOMUTILISATEUR

Filtrer les problèmes rédigés par le nom d'utilisateur donné

--created-by-me

Raccourci pour filtrer les problèmes créés par vous
