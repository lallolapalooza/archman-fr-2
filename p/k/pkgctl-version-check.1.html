NOM

pkgctl-version-check - Compare les versions locales des paquets avec celles d'amont

SYNTAXE

pkgctl version check [OPTIONS] [PKGBASE...]

DESCRIPTION

Compare les versions des paquets dans le dépôt d'empaquetage local avec leurs dernières versions d'amont.

Lors de l'exécution, il génère une liste groupée qui fournit des informations détaillées sur l'état de chaque paquet. Pour chaque paquet, il affiche la version locale actuelle aux côtés de la dernière version disponible en amont.

Affiche un résumé des paquets à jour, des paquets obsolètes et de toute erreur de vérification.

Cela simplifie la maintenance des fichiers PKGBUILD, réduisant l'effort manuel requis pour suivre les changements de version des sources d'amont.

CONFIGURATION

Utilise nvchecker(1) et un fichier .nvchecker.toml situé à côté du PKGBUILD. Référez-vous à la section de configuration de pkgctl-version(1).

OPTIONS

-h, --help

Afficher un texte d'aide

OPTIONS DE FILTRAGE

-v, --verbose

Afficher tous les résultats, y compris les versions à jour

OPTIONS DE SORTIE

--json

Activer l'affichage en JSON ; Raccourci pour '--format json'

-F, --format FORMAT

Contrôle le format de sortie des résultats ; FORMAT est 'pretty' ou 'json' (par défaut pretty)

CODES DE SORTIE

À la sortie, retourne l'un des codes suivants :

0

Condition de sortie normale, toutes les versions vérifiées sont à jour

1

Cause inconnue de l'échec

2

Condition de sortie normale, mais il y a des versions obsolètes

3

Échec de l'exécution de certaines vérifications de version
