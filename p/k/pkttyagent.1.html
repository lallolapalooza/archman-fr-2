NOM

pkttyagent - Aide d'authentification textuelle

SYNTAXE

pkttyagent [--version] [--help]

pkttyagent [--process { pid | pid,pid-start-time } | --system-bus-name busname] [--notify-fd fd] [--fallback]

DESCRIPTION

pkttyagent est utilisé pour démarrer un agent d'authentification textuel pour le sujet spécifié par --process ou --system-bus-name. Si aucune de ces options n'est donnée, le processus parent est utilisé.

Pour être notifié lorsque l'agent d'authentification a été enregistré, écoutez le signal D-Bus Changed ou utilisez --notify-fd pour passer le numéro d'un descripteur de fichier qui a été passé au programme. Ce descripteur de fichier sera alors fermé lorsque l'agent d'authentification aura été enregistré avec succès.

Si --fallback est utilisé, l'agent d'authentification textuel ne remplacera pas un agent d'authentification existant.

VALEUR DE RETOUR

Si l'agent d'authentification n'a pas pu être enregistré, pkttyagent se termine avec un code de sortie de 127. Des messages diagnostiques sont affichés sur la sortie standard d'erreur.

Si une ou plusieurs des options fournies sont malformées, pkttyagent se termine avec un code de sortie de 126. Si l'entrée standard est un tty, alors cette page de manuel est également affichée.

Si l'agent d'authentification a été enregistré avec succès, pkttyagent continuera de s'exécuter, interagissant avec l'utilisateur au besoin. Lorsque ses services ne seront plus nécessaires, le processus pourra être arrêté.

NOTES

Étant donné que les identifiants de processus peuvent être recyclés, l'appelant doit toujours utiliser pid,pid-start-time lors de l'utilisation de l'option --process. La valeur de pid-start-time peut être déterminée en consultant par exemple le système de fichiers proc(5) en fonction du système d'exploitation. Si seul pid est passé à l'option --process, alors pkttyagent cherchera lui-même l'heure de démarrage, mais notez que cela peut être sujet à une course.
