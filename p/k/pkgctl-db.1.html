NOM

pkgctl-db - Utilitaire de modification de base de données Pacman pour les mises à jour de paquets, les transferts et plus encore.

SYNTAXE

pkgctl db [OPTIONS] [SOUS-COMMANDE]

DESCRIPTION

Gère la base de données Pacman et facilite la modification des paquets et de leurs métadonnées dans la base de données.

OPTIONS

-h, --help

Affiche les informations d'utilisation et les options disponibles.

SOUS-COMMANDES

pkgctl db update

Met à jour le dépôt binaire comme étape finale de publication.

pkgctl db move

Déplace des paquets entre dépôts binaires.

pkgctl db remove

Supprime des paquets des dépôts binaires.

VOIR AUSSI

pkgctl-db-update(1) pkgctl-db-move(1) pkgctl-db-remove(1)
