NOM

pkgctl-issue-create - Créer un nouveau ticket

SYNOPIS

pkgctl issue create [OPTIONS]

DESCRIPTION

La commande create est utilisée pour créer un nouveau ticket pour un paquet Arch Linux. Cette commande est adaptée pour signaler des bugs, des régressions, des demandes de fonctionnalités ou tout autre problème lié à un paquet. Elle offre un moyen flexible de documenter et de suivre les nouveaux tickets dans le système de suivi des tickets du projet.

Par défaut, la commande opère dans le répertoire courant, mais les utilisateurs peuvent spécifier une base de paquet différente si nécessaire.

Les utilisateurs peuvent fournir un titre pour le ticket directement via la ligne de commande. La description du ticket peut être fournie à partir d'un fichier ou éditée à l'aide d'un éditeur de texte. Alternativement, les utilisateurs peuvent choisir de continuer le processus de création de ticket en utilisant l'interface web pour une expérience plus interactive.

La commande permet de définir diverses étiquettes et attributs pour le ticket, tels que la confidentialité, la priorité, la portée, la gravité et le statut. Ces options aident à catégoriser et prioriser le ticket de manière appropriée au sein du système de suivi.

En cas d'échec, la commande peut se récupérer automatiquement pour garantir que le processus de création de ticket soit terminé sans perte de données.

Cette commande est essentielle pour les mainteneurs, les contributeurs et les utilisateurs qui ont besoin de signaler de nouveaux problèmes liés aux paquets Arch Linux.

OPTIONS

-p, --package PKGBASE

Interagir avec PKGBASE au lieu du répertoire courant

-t, --title TITLE

Utiliser le titre fourni pour le ticket

-F, --file FILE

Prendre la description du ticket à partir de <file>

-e, --edit

Éditer la description du ticket à l'aide d'un éditeur

-w, --web

Continuer la création du ticket avec l'interface web

--recover

Se récupérer automatiquement d'un échec

--confidentiality TYPE

Définir la confidentialité du ticket

--priority PRIORITY

Définir l'étiquette de priorité

--scope SCOPE

Définir l'étiquette de portée

--severity SEVERITY

Définir l'étiquette de gravité

--status STATUS

Définir l'étiquette de statut

-h, --help

Afficher un texte d'aide
