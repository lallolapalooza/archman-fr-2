PKCS15-TOOL(1) Outils OpenSC PKCS15-TOOL(1)

NOM

pkcs15-tool - utilitaire pour manipuler les structures de données PKCS #15 sur des cartes à puce et des jetons de sécurité similaires

SYNTAXE

pkcs15-tool [OPTIONS]

DESCRIPTION

L'utilitaire pkcs15-tool est utilisé pour manipuler les structures de données PKCS #15 sur des cartes à puce et des jetons de sécurité similaires. Les utilisateurs peuvent lister et lire les codes PIN, les clés et les certificats stockés sur le jeton. L'authentification du code PIN utilisateur est effectuée pour les opérations qui l'exigent.

OPTIONS

--version

Affiche la version de la sortie du paquet OpenSC.

--aid aid

Spécifie sous forme hexadécimale l'AID de l'application PKCS#15 sur la carte à lier.

--auth-id id, -a id

Spécifie l'ID d'authentification du code PIN à utiliser pour l'opération. Ceci est utile avec l'opération --change-pin.

--change-pin

Modifie un code PIN ou un PUK stocké sur le jeton. L'authentification de l'utilisateur est requise pour cette opération.

--dump, -D

Liste tous les objets de la carte.

--list-info

Liste les objets de la carte.

--list-applications

Liste les applications PKCS#15 sur la carte.

--list-certificates, -c

Liste tous les certificats stockés sur le jeton.

--list-data-objects, -C

Liste tous les objets de données stockés sur le jeton. Pour certaines cartes, les attributs PKCS#15 des objets de données privées sont protégés en lecture et nécessitent une authentification avec le code PIN utilisateur. Dans ce cas, l'option --verify-pin doit être utilisée.

--list-keys, -k

Liste toutes les clés privées stockées sur le jeton. Des informations générales sur chaque clé privée sont listées (par exemple, nom de la clé, ID et algorithme). Les valeurs réelles des clés privées ne sont pas affichées. Pour certaines cartes, les attributs PKCS#15 des clés privées sont protégés en lecture et nécessitent une authentification avec le code PIN utilisateur. Dans ce cas, l'option --verify-pin doit être utilisée.

--list-secret-keys

Liste toutes les clés secrètes (symétriques) stockées sur le jeton. Des informations générales sur chaque clé secrète sont listées (par exemple, nom de la clé, ID et algorithme). Les valeurs réelles des clés secrètes ne sont pas affichées. Pour certaines cartes, les attributs PKCS#15 des clés privées sont protégés en lecture et nécessitent une authentification avec le code PIN utilisateur. Dans ce cas, l'option --verify-pin doit être utilisée.

--list-pins

Liste tous les codes PIN stockés sur le jeton. Des informations générales sur chaque code PIN sont listées (par exemple, nom du code PIN). Les valeurs réelles des codes PIN ne sont pas affichées.

--list-public-keys

Liste toutes les clés publiques stockées sur le jeton, y compris les informations sur le nom de la clé, l'ID, l'algorithme et la longueur.

--short, -s

Affiche les listes dans un format compact.

--no-cache

Désactive la mise en cache des données du jeton.

--clear-cache

Supprime le répertoire de cache de l'utilisateur. Sous Windows, cette option supprime également le répertoire de cache du système (nécessite des privilèges d'administrateur).

--output nom_fichier, -o nom_fichier

Spécifie où la sortie de la clé doit être écrite. Si nom_fichier existe déjà, il sera écrasé. Si cette option n'est pas fournie, les clés seront imprimées sur la sortie standard.

--raw

Modifie la façon dont --read-data-object affiche le contenu sur la sortie standard. Par défaut, lorsque --raw n'est pas fourni, il affiche le contenu en notation hexadécimale. Si --raw est défini, il affiche directement les données binaires. Cela n'affecte pas la sortie écrite dans le fichier spécifié par l'option --output. Les données écrites dans un fichier seront toujours en binaire brut.

--read-certificate cert

Lit le certificat avec l'ID donné.

--read-data-object data, -R data

Lit l'objet de données avec OID, nom d'application ou étiquette. Le contenu est affiché sur la sortie standard en notation hexadécimale, sauf si l'option --raw est fournie. Si un fichier de sortie est donné avec l'option --output, le contenu est également écrit dans le fichier. La sortie vers le fichier est toujours écrite en mode binaire brut, l'option --raw n'affecte que le comportement de la sortie standard.

--read-public-key id

Lit la clé publique avec l'ID id, permettant à l'utilisateur d'extraire et de stocker ou d'utiliser la clé publique.

--read-ssh-key id

Lit la clé publique avec l'ID id, en écrivant la sortie dans un format adapté à $HOME/.ssh/authorized_keys.

L'étiquette de la clé, le cas échéant, sera affichée dans le champ 'Comment'.

--rfc4716

Lorsqu'il est utilisé conjointement avec l'option --read-ssh-key, le format de sortie de la clé publique suit la norme rfc4716.

Le format de sortie par défaut est une seule ligne (openssh).

--test-update, -T

Teste si la carte nécessite une mise à jour de sécurité.

--update, -U

Met à jour la carte avec une mise à jour de sécurité.

--reader arg

Numéro du lecteur à utiliser. Par défaut, le premier lecteur avec une carte présente est utilisé. Si arg est un ATR, le lecteur avec une carte correspondante sera choisi.

--unblock-pin, -u

Débloque un code PIN stocké sur le jeton. La connaissance de la clé de déblocage de code PIN (PUK) est requise pour cette opération.

--verbose, -v

Rend pkcs15-tool plus verbeux. Spécifiez ce drapeau plusieurs fois pour activer la sortie de débogage dans la bibliothèque OpenSC.

--pin pin, --new-pin newpin, --puk puk

Ces options peuvent être utilisées pour spécifier les valeurs PIN/PUK sur la ligne de commande. Si la valeur est définie sur env:VARIABLE, la valeur de la variable d'environnement spécifiée est utilisée. Par défaut, le code est invité sur la ligne de commande si nécessaire.

Notez que sur la plupart des systèmes d'exploitation, n'importe quel utilisateur peut afficher la ligne de commande de n'importe quel processus sur le système en utilisant des utilitaires tels que ps(1). Par conséquent, vous devriez préférer passer les codes via une variable d'environnement sur un système non sécurisé.

--new-pin pin

Spécifie le nouveau code PIN (lors du changement ou du déblocage).

--verify-pin

Vérifie le code PIN après la liaison de la carte et avant d'émettre toute commande (sans 'auth-id', le premier code PIN non-SO, non-Unblock sera vérifié).

--test-session-pin

Équivalent à --verify-pin avec génération supplémentaire de code PIN de session.

--wait, -w

Fait en sorte que pkcs15-tool attende l'insertion d'une carte.

--use-pinpad

Ne pas inviter l'utilisateur ; si aucun code PIN n'est fourni, le pavé numérique sera utilisé.

VOIR AUSSI

pkcs15-init(1), pkcs15-crypt(1)
