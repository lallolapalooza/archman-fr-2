NOM

pkgctl - Interface en ligne de commande unifiée pour devtools

SYNTAXE

pkgctl [SOUS-COMMANDE] [OPTIONS]

DESCRIPTION

Utilité en ligne de commande servant d'interface unifiée pour plusieurs outils de développement. Cet outil vise à simplifier et optimiser les interactions avec devtools en offrant diverses sous-commandes pour exécuter des tâches liées à la gestion des paquets, à la gestion des dépôts, au contrôle de version, entre autres.

L'utilisation de pkgctl permet aux utilisateurs d'administrer efficacement leurs flux de travail de développement.

OPTIONS

-V, --version

Affiche les informations de version de pkgctl

-h, --help

Affiche un message d'aide

SOUS-COMMANDES

pkgctl aur

Interagit avec l'Arch User Repository

pkgctl auth

Authentifie auprès de services comme GitLab

pkgctl build

Construit des paquets dans un chroot propre

pkgctl db

Modification de la base de données Pacman pour la mise à jour, le déplacement etc. des paquets

pkgctl diff

Compare les fichiers de paquets en utilisant différents modes

pkgctl issue

Travaille avec les problèmes de paquetage GitLab

pkgctl release

Étape de publication pour commiter, taguer et télécharger les artefacts de construction

pkgctl repo

Gère les dépôts de paquets Git et leur configuration

pkgctl search

Recherche une expression dans le groupe de paquets GitLab

pkgctl version

Vérifie et gère les versions des paquets par rapport à l'amont
