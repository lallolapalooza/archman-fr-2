NOM

pkgctl-release - Étape de publication pour commiter, taguer et téléverser les artefacts de construction

SYNOPSIS

pkgctl release [OPTIONS] [PATH...]

DESCRIPTION

Les fichiers modifiés contrôlés par version seront d'abord préparés pour le commit, puis une balise Git correspondant au pkgver sera créée, et enfin tous les artefacts de construction seront téléversés.

Par défaut, le dépôt pacman cible sera automatiquement détecté en interrogeant le dépôt dans lequel il est actuellement publié. Lors de l'ajout initial d'un nouveau paquet aux dépôts, le dépôt cible doit être spécifié manuellement.

OPTIONS

-m, --message MSG

Utilise le message <msg> donné comme message de commit

-r, --repo REPO

Spécifie le dépôt cible pour les nouveaux paquets n'appartenant à aucun dépôt officiel. L'utilisation de cette option est interdite si le paquet est déjà publié, car elle contournerait la protection de détection automatique.

-s, --staging

Construit par rapport au homologue de staging du dépôt détecté automatiquement

-t, --testing

Construit par rapport à l'homologue de testing du dépôt détecté automatiquement

-u, --db-update

Met automatiquement à jour la base de données pacman après le téléversement

-h, --help

Affiche un texte d'aide
