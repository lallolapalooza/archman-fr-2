NOM

pki --gen - Générer une nouvelle clé privée RSA ou ECDSA

SYNTAXE

pki --gen [--type type] [--size bits] [--safe-primes] [--shares n] [--threshold l] [--outform encodage] [--debug niveau]
pki --gen --options fichier
pki --gen -h | --help

DESCRIPTION

Cette sous-commande de pki(1) est utilisée pour générer une nouvelle clé privée RSA ou ECDSA.

OPTIONS

-h, --help
Imprimer les informations d'utilisation avec un résumé des options disponibles.
-v, --debug niveau
Définir le niveau de débogage, par défaut : 1.
-+, --options fichier
Lire les options de la ligne de commande à partir du fichier.
-t, --type type
Type de clé à générer. Soit rsa, ecdsa, ed25519, ou ed448, par défaut rsa.
-s, --size bits
Longueur de la clé en bits. Par défaut 2048 pour rsa et 384 pour ecdsa. Pour ecdsa seuls trois valeurs sont actuellement supportées : 256, 384 et 521.
-p, --safe-primes
Générer des nombres premiers sûrs RSA.
-f, --outform encodage
Encodage de la clé privée générée. Soit der (ASN.1 DER) ou pem (PEM Base64), par défaut der.

Cryptographie à seuil RSA

-n, --shares <n>
Nombre de parts de clé privée RSA.
-l, --threshold <l>
Nombre minimum de parts de clé RSA participantes.

PROBLEMES SUR LES SYSTEMES AVEC FAIBLE ENTROPIE

Si le plugin gmp est utilisé pour générer des clés privées RSA, le matériel de la clé est lu à partir de /dev/random (via le plugin random). Par conséquent, la commande peut se bloquer si le pool d'entropie du système est vide. Pour éviter cela, utilisez soit un générateur de nombres aléatoires matériel pour alimenter /dev/random, soit OpenSSL (via le plugin openssl ou la ligne de commande) qui est moins strict quant à la qualité du matériel de clé (il lit à partir de /dev/urandom si nécessaire). Il est également possible de configurer les périphériques utilisés par le plugin random dans strongswan.conf(5). Définir libstrongswan.plugins.random.random sur /dev/urandom force le plugin à traiter les octets lus depuis /dev/urandom comme des données aléatoires de haute qualité, évitant ainsi le blocage. Bien sûr, cela ne change rien au fait que le matériel de clé généré de cette manière est de moindre qualité.

EXEMPLES

pki --gen --size 3072 > rsa_key.der
Génère une clé privée RSA de 3072 bits.
pki --gen --type ecdsa --size 256 > ecdsa_key.der
Génère une clé privée ECDSA de 256 bits.
