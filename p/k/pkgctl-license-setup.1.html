NOM

pkgctl-license-setup - Détecte et configure automatiquement une configuration REUSE de base

SYNTAXE

pkgctl license setup [OPTIONS] [PKGBASE...]

DESCRIPTION

Cette sous-commande automatise la création du fichier de licence de paquet 0BSD d'Arch Linux ainsi qu'une configuration REUSE de base en appliquant des heuristiques simples. Elle est particulièrement utile lors de la configuration initiale des licences pour un paquet, sans avoir besoin d'écrire manuellement un fichier REUSE.toml.

Si des fichiers .patch sont détectés et que le PKGBUILD(5) ne contient qu'une seule entrée dans le tableau license=(), cette sous-commande suppose que les correctifs sont sous licence avec cette licence et génère des annotations pour eux.

En l'absence de correctifs, aucune annotation supplémentaire n'est générée.

Des annotations manuelles sont nécessaires si la sous-commande ne peut pas générer une configuration qui prend en compte tous les fichiers. Dans ce cas, reuse lint échouera avec une erreur descriptive des fichiers pour lesquels aucune annotation n'a été trouvée.

Si aucun PKGBASE n'est spécifié, la commande utilise par défaut le répertoire de travail courant.

OPTIONS

-f, --force

Écrase la configuration reuse(1) existante

--no-check

N'exécute pas pkgctl-license-check(1) après la configuration

-h, --help

Affiche un texte d'aide
