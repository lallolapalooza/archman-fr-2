NOM

pkgfiled - synchronise automatiquement les bases de données .files de pacman avec le cache pkgfile

SYNTAXE

Utilisation : pkgfiled [options] pacman_dbpath pkgfile_cache

DESCRIPTION

pkgfiled est un petit démon qui surveille les changements dans les bases de données pacman(8) .files et les reconditionne pour être utilisés par pkgfile. Cela permet aux données de rester synchronisées entre pacman et pkgfile.

L'invocation de pkgfiled nécessite deux arguments -- un répertoire source pour lire les fichiers de base de données pacman (typiquement sous /var/lib/pacman/sync), et un répertoire de destination que pkgfile lira (typiquement /var/cache/pkgfile). Une unité systemd facilite la gestion du démon.

Au démarrage, pkgfiled comparera le contenu de la base de données pacman avec le cache pkgfile et rattrapera tout ce qui est désynchronisé. Après cela, il ne se réveillera que lorsque des changements surviendront dans la base de données pacman.

OPTIONS

-f, --force
Lors de la synchronisation initiale, ignore les comparaisons d'horodatage et réécrit toutes les bases de données trouvées.
-o, --oneshot
Quitte après la synchronisation initiale de pkgfiled, au lieu de continuer à écouter les changements.
-z, --compress[=COMPRESSION]
Reconditionne les dépôts avec la méthode de compression éventuellement fournie, qui peut être l'une des suivantes : none, gzip, bzip2, lzop, lz4, lzma, xz ou zstd. Si cette option est passée sans méthode de compression, elle utilise gzip par défaut. Si cette option n'est pas passée du tout, aucune compression ne sera appliquée. L'application de toute forme de compression diminuera les performances, mais peut être souhaitable pour des raisons d'espace disque.
-h, --help
Affiche l'aide et quitte.
-V, --version
Affiche la version et quitte.

SIGNALS

SIGINT, SIGTERM
Lorsqu'il est exécuté de manière interactive, pkgfiled s'arrête gracieusement à la réception de SIGINT. Sinon, SIGTERM est utilisé pour indiquer un arrêt gracieux.
SIGUSR1, SIGUSR2
À la réception de ces signaux, pkgfiled réanalysera le répertoire de la base de données pacman pour détecter les changements et effectuera les mises à jour nécessaires. Contrairement à SIGUSR1, SIGUSR2 ignorera les vérifications d'horodatage et réécrira toutes les bases de données trouvées.
