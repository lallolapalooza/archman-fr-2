NOM

pkgctl-repo - Gérer les dépôts de paquets Git et leur configuration

SYNOPIS

pkgctl repo [OPTIONS] [SOUS-COMMANDE]

DESCRIPTION

Gère les dépôts de paquets Git et aide à leur configuration conformément aux spécifications de la distribution.

Les informations d'auteur Git et la clé de signature utilisée sont configurées à partir de makepkg.conf, lu à partir de tout emplacement valide tel que /etc ou XDG_CONFIG_HOME. La commande configure peut être utilisée pour synchroniser les spécifications de la distribution et les paramètres de makepkg.conf pour les dépôts précédemment clonés.

L'option non privilégiée peut être utilisée pour cloner des dépôts de paquets sans accès SSH en utilisant HTTPS en lecture seule.

OPTIONS

-h, --help

Afficher un texte d'aide

SOUS-COMMANDES

pkgctl repo clean

Supprimer les fichiers non suivis du répertoire de travail

pkgctl repo clone

Cloner un dépôt de paquets

pkgctl repo configure

Configurer un clone selon les spécifications de la distribution

pkgctl repo create

Créer un nouveau dépôt de paquets GitLab

pkgctl repo switch

Changer un dépôt de paquets vers une version spécifiée

pkgctl repo web

Ouvrir le site web du dépôt de paquets
