NOM

pki --self - Créer un certificat auto-signé

SYNTAXE

pki --self [--in fichier|--keyid hex] [--type t] --dn nom-distinctif [--san nomAlternatifSujet] [--lifetime jours] [--not-before date-heure] [--not-after date-heure] [--serial hex] [--flag indicateur] [--digest hachage] [--rsa-padding remplissage] [--ca] [--ocsp uri] [--pathlen longueur] [--addrblock bloc] [--nc-permitted nom] [--nc-excluded nom] [--critical oid] [--policy-mapping mappage] [--policy-explicit longueur] [--policy-inhibit longueur] [--policy-any longueur] [--cert-policy oid [--cps-uri uri] [--user-notice texte]] [--outform encodage] [--debug niveau]
pki --self --options fichier
pki --self -h | --help

DESCRIPTION

Cette sous-commande de pki(1) est utilisée pour créer un certificat auto-signé.

OPTIONS

-h, --help
Affiche les informations d'utilisation avec un résumé des options disponibles.
-v, --debug niveau
Définit le niveau de débogage, par défaut : 1.
-+, --options fichier
Lit les options de la ligne de commande depuis fichier.
-i, --in fichier
Fichier d'entrée de la clé privée. Si non fourni, la clé est lue depuis STDIN.
-x, --keyid hex
Handle de l'objet de clé privée de carte à puce ou de TPM au format hexadécimal avec un préfixe 0x optionnel.
-t, --type type
Type de la clé d'entrée. Soit priv, rsa, ecdsa, ed25519 ou ed448, par défaut priv.
-d, --dn nom-distinctif
Nom distinctif (DN) du sujet et de l'émetteur. Obligatoire.
-a, --san nomAlternatifSujet
Extension subjectAltName à inclure dans le certificat. Peut être utilisée plusieurs fois.
-l, --lifetime jours
Nombre de jours pendant lesquels le certificat est valide, par défaut : 1095. Ignoré si une heure de début et de fin absolues sont fournies.
-F, --not-before date-heure
Heure absolue à laquelle commence la validité du certificat. Le format de la date et de l'heure est défini par l'option --dateform.
-T, --not-after date-heure
Heure absolue à laquelle se termine la validité du certificat. Le format de la date et de l'heure est défini par l'option --dateform.
-D, --dateform format
Format strptime(3) pour les options --not-before et --not-after, par défaut : %d.%m.%y %T
-s, --serial hex
Numéro de série en hexadécimal. Il est alloué aléatoirement par défaut.
-e, --flag indicateur
Ajoute un indicateur extendedKeyUsage. Un parmi serverAuth, clientAuth, crlSign, ou ocspSigning. Peut être utilisé plusieurs fois.
-g, --digest hachage
Hachage à utiliser pour la création de la signature. Un parmi md5, sha1, sha224, sha256, sha384, ou sha512. Le défaut est déterminé en fonction du type et de la taille de la clé de signature.
-R, --rsa-padding remplissage
Remplissage à utiliser pour les signatures RSA. Soit pkcs1 ou pss, par défaut pkcs1.
-f, --outform encodage
Encodage du fichier de certificat créé. Soit der (ASN.1 DER) ou pem (PEM Base64), par défaut der.
-b, --ca
Inclut l'extension CA basicConstraint dans le certificat.
-o, --ocsp uri
URI AuthorityInfoAccess OCSP à inclure dans le certificat. Peut être utilisée plusieurs fois.
-p, --pathlen longueur
Définit la contrainte de longueur de chemin.
-B, --addrblock bloc
Bloc d'adresses RFC 3779 à inclure dans le certificat. bloc est soit un sous-réseau CIDR (tel que 10.0.0.0/8) soit une plage d'adresses arbitraire (192.168.1.7-192.168.1.13). Peut être répété pour inclure plusieurs blocs. Veuillez noter que les blocs fournis sont inclus tels quels dans le certificat, donc pour la conformité aux normes, plusieurs blocs doivent être fournis dans le bon ordre et les blocs adjacents doivent être combinés. Référez-vous à la RFC 3779 pour plus de détails.
-n, --nc-permitted nom
Ajoute une extension NameConstraint autorisée au certificat. Pour les contraintes DNS ou email, le type d'identité n'est pas toujours détectable par le nom donné. Utilisez le préfixe dns: ou email: pour forcer un type de contrainte.
-N, --nc-excluded nom
Ajoute une extension NameConstraint exclue au certificat. Pour les contraintes DNS ou email, le type d'identité n'est pas toujours détectable par le nom donné. Utilisez le préfixe dns: ou email: pour forcer un type de contrainte.
-X, --critical oid
Ajoute une extension critique avec l'OID donné.
-M, --policy-mapping oid-émetteur:oid-sujet
Ajoute un policyMapping de l'OID de l'émetteur à celui du sujet.
-E, --policy-explicit longueur
Ajoute une contrainte requireExplicitPolicy.
-H, --policy-inhibit longueur
Ajoute une contrainte inhibitPolicyMapping.
-A, --policy-any longueur
Ajoute une contrainte inhibitAnyPolicy.

Politique de Certificat

Plusieurs extensions certificatePolicy peuvent être ajoutées. Chacune avec les informations suivantes :

-P, --cert-policy oid
OID à inclure dans l'extension certificatePolicy. Obligatoire.
-C, --cps-uri uri
URI de la déclaration de pratique de certification pour certificatePolicy.
-U, --user-notice texte
Avis utilisateur pour certificatePolicy.

EXEMPLES

Générer un certificat auto-signé en utilisant la clé RSA donnée :

  pki --self --in key.der --dn "C=CH, O=strongSwan, CN=moon" \
      --san moon.strongswan.org > cert.der

NAME

pki -- Import and manage X.509 certificates and RSA private keys

SYNOPSIS

pki command [arguments]

DESCRIPTION

The pki(8) utility supports importing and exporting X.509 certificates, and RSA private keys. Supported formats include PEM, DER, and PKCS#12.

OPTIONS

This command does not support any options.

EXAMPLES

pki --print --in ca.crt --type CERT
    Prints the CA certificate in PEM format.

pki --print --in server.key --type RSA
    Prints the RSA private key in PEM format.

pki --print --in server.p12 --format pkcs12 --password secret
    Prints the contents of a PKCS#12 archive.

pki --import --in server.crt --type CERT
    Imports a certificate and prints it in PEM format.

pki --import --in server.key --type RSA
    Imports a private key and prints it in PEM format.

pki --import --in server.p12 --format pkcs12 --password secret
    Imports a PKCS#12 archive and prints its contents.

pki --export --in server.crt --type CERT
    Exports a certificate and prints it in PEM format.

pki --export --in server.key --type RSA
    Exports a private key and prints it in PEM format.

pki --x509 --issue --cacert ca.crt --cakey ca.key \
    --in client.csr --type CERT \
    --serial 13 \
    --lifetime 1825
    Issues a new certificate based on a Certificate Signing Request (CSR).
    The new certificate is printed in PEM format.
