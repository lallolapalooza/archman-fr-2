NOM

pkgctl-issue-reopen - Rouvrir un ticket fermé

SYNTAXE

pkgctl issue reopen [OPTIONS] [IID]

DESCRIPTION

La commande reopen est utilisée pour rouvrir un ticket précédemment fermé dans les projets de paquets Arch Linux. Cette commande est utile lorsqu'un ticket doit être revu ou qu'un travail supplémentaire est requis après sa fermeture initiale.

Pour modifier un ticket, les utilisateurs doivent spécifier l'identifiant du ticket (IID). Par défaut, la commande opère dans le répertoire courant, mais les utilisateurs peuvent spécifier une base de paquets différente si nécessaire.

Les utilisateurs peuvent fournir un message directement via la ligne de commande pour expliquer la raison de la réouverture du ticket. Pour des explications plus détaillées ou pour fournir un contexte supplémentaire, les utilisateurs ont la possibilité de modifier le commentaire de réouverture à l'aide d'un éditeur de texte avant de le soumettre.

OPTIONS

-p, --package PKGBASE

Interagir avec PKGBASE au lieu du répertoire courant

-m, --message MSG

Utiliser le message fourni comme commentaire

-e, --edit

Modifier le commentaire à l'aide d'un éditeur

-h, --help

Afficher le texte d'aide
