NOM

pkgctl-issue-edit - Modifier et mettre à jour un problème

SYNTAXE

pkgctl issue edit [OPTIONS] [IID]

DESCRIPTION

La commande pkgctl issue edit est utilisée pour modifier un problème existant dans les projets de paquets Arch Linux. Cette commande permet aux utilisateurs de mettre à jour le titre, la description et divers attributs du problème, garantissant ainsi que les informations du problème restent exactes et à jour. Elle fournit également une facilité simplifiée aux responsables des corrections de bugs pour catégoriser et prioriser efficacement les problèmes.

Pour modifier un problème, les utilisateurs doivent spécifier son identifiant (IID). Par défaut, la commande opère dans le répertoire courant, mais les utilisateurs peuvent spécifier une base de paquets différente si nécessaire.

La commande permet des mises à jour directes du titre et de la description du problème. Pour des changements plus importants, les utilisateurs peuvent modifier ces détails à l'aide d'un éditeur de texte. La commande fournit diverses options pour définir ou mettre à jour des étiquettes et des attributs tels que la confidentialité, la priorité, la résolution, la portée, la sévérité et le statut. Ces options contribuent à maintenir une gestion des problèmes claire et organisée.

En cas d'échec de l'exécution, la commande peut récupérer automatiquement pour garantir que le processus d'édition est terminé sans perte de données.

Cette commande est particulièrement utile pour les mainteneurs et les contributeurs qui ont besoin de mettre à jour les détails d'un problème pour refléter de nouvelles informations ou des changements de statut. Elle garantit que tous les détails du problème sont maintenus avec précision, facilitant ainsi le suivi et la résolution efficaces.

OPTIONS

-p, --package PKGBASE

Interagir avec PKGBASE au lieu du répertoire courant

-t, --title TITRE

Utiliser le titre fourni pour le problème

-e, --edit

Modifier le titre et la description du problème à l'aide d'un éditeur

--recover

Récupérer automatiquement d'une exécution échouée

--confidentiality TYPE

Définir la confidentialité du problème

--priority PRIORITÉ

Définir l'étiquette de priorité

--resolution RAISON

Définir l'étiquette de résolution

--scope PORTÉE

Définir l'étiquette de portée

--severity GRAVITÉ

Définir l'étiquette de gravité

--status STATUT

Définir l'étiquette de statut

-h, --help

Afficher un texte d'aide
