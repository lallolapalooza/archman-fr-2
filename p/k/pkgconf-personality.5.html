PKGCONF-PERSONALITY(5) Manuel des formats de fichiers PKGCONF-PERSONALITY(5)

NOM

fichier.personality — Format de fichier de personnalité pour la compilation croisée de pkgconf

DESCRIPTION

Les fichiers de personnalité pour la compilation croisée de pkgconf offrent un mécanisme utile pour stocker diverses informations sur les chaînes d'outils système. Les informations stockées par les fichiers .personality incluent des informations sur les chemins utilisés par une chaîne d'outils de compilation croisée, tels que le répertoire sysroot et les chemins par défaut pour les includes et les bibliothèques. pkgconf utilise ces informations pour déterminer quelles informations sont nécessaires pour utiliser les bibliothèques.

SYNTAXE DU FICHIER

Le fichier .personality suit un format inspiré par le RFC822. Les commentaires sont précédés d'un signe dièse (#) et l'affectation de variables est similaire au shell POSIX. Les propriétés sont définies à l'aide de sections de style RFC822.

PROPRIÉTÉS

Les propriétés sont définies à l'aide de sections de style RFC822 qui consistent en un mot-clé, suivi d'un deux-points (:) puis de la valeur à laquelle la propriété doit être définie. La substitution de variables est toujours effectuée, quel que soit le type de propriété.

Il existe trois types de propriétés :

Littéral
La propriété sera définie sur le texte de la valeur.
Liste de fragments
La propriété sera définie sur une liste de fragments analysés à partir du texte. Le texte d'entrée doit être dans un format approprié pour être passé à un shell POSIX sans aucune expansion de shell après que la substitution de variables ait été effectuée. Les éléments sont délimités par un deux-points.
Booléen
La propriété sera définie sur vrai si la valeur est l'une des suivantes : true, yes ou 1. Sinon, elle sera définie sur faux.

MOTS CLÉS DES PROPRIÉTÉS

Triplet
Le triplet utilisé par la chaîne d'outils de compilation croisée. (obligatoire ; littéral)
SysrootDir
Le répertoire utilisé par la racine système de la chaîne d'outils de compilation croisée. (obligatoire ; littéral)
DefaultSearchPaths
Une liste de répertoires dans lesquels rechercher les fichiers pc(5). (obligatoire ; liste de fragments)
SystemIncludePaths
Une liste de répertoires qui sont inclus par défaut dans le chemin de recherche des fichiers d'inclusion. (obligatoire ; liste de fragments)
SystemLibraryPaths
Une liste de répertoires qui sont inclus par défaut dans le chemin de recherche des bibliothèques. (obligatoire ; liste de fragments)
WantDefaultPure
Si vrai, pkgconf privilégiera par défaut un graphe de dépendances pur. (optionnel ; booléen ; défaut est faux)
WantDefaultStatic
Si vrai, pkgconf fonctionnera par défaut en mode de liaison statique. (optionnel ; booléen ; défaut est faux)

EXEMPLES

Un exemple de fichier .personality :

# Ceci est un commentaire
Triplet: x86_64-pc-linux-gnu
SysrootDir: /home/kaniini/sysroot/x86_64-pc-linux-gnu
DefaultSearchPaths: /home/kaniini/sysroot/x86_64-pc-linux-gnu/lib/pkgconfig:/home/kaniini/sysroot/x86_64-pc-linux-gnu/share/pkgconfig
SystemIncludePaths: /home/kaniini/sysroot/x86_64-pc-linux-gnu/include
SystemLibraryPaths: /home/kaniini/sysroot/x86_64-pc-linux-gnu/lib
