NOM

pkcs11-register - Outil simple pour installer des modules PKCS#11 auprès des applications connues.

SYNOPSIS

pkcs11-register [OPTIONS]

DESCRIPTION

L'utilitaire pkcs11-register peut être utilisé depuis la ligne de commande pour enregistrer des modules PKCS#11 auprès de diverses applications.

OPTIONS

--help, -h

Affiche le message d'aide à l'écran.

--version, -V

Affiche la version du paquet OpenSC.

--module nom_fichier, -m nom_fichier

Chemin vers le module PKCS#11 à charger. Par défaut, il s'agit du module PKCS#11 d'OpenSC.

--skip-chrome

N'installe pas le module pour le navigateur Chrome. Par défaut, l'outil tente d'installer le module pour le navigateur Chrome.

--skip-firefox

N'installe pas le module pour le navigateur Firefox. Par défaut, l'outil tente d'installer le module pour le navigateur Firefox.

--skip-thunderbird

N'installe pas le module pour le client de messagerie Thunderbird. Par défaut, l'outil tente d'installer le module pour le client de messagerie Thunderbird.

--skip-seamonkey

N'installe pas le module pour Seamonkey. Par défaut, l'outil tente d'installer le module pour Seamonkey.

VOIR AUSSI

pkcs11-tool(1) opensc.conf(5)
