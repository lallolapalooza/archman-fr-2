PKTSETUP(8) Manuel du gestionnaire système PKTSETUP(8)

NOM

pktsetup - configurer et supprimer les associations de périphériques de paquets

SYNTAXE

pktsetup périphérique_paquet périphérique_bloc
pktsetup -d périphérique_paquet
pktsetup -s

DESCRIPTION

Pktsetup est utilisé pour associer des périphériques de paquets à des périphériques bloc CD ou DVD, afin que le périphérique de paquet puisse ensuite être monté et potentiellement utilisé comme système de fichiers en lecture/écriture. Cela nécessite le support du noyau pour le périphérique de paquet et le système de fichiers UDF.

Voir : HOWTO.udf (dans le répertoire des documents udftools)

STATUT DE SORTIE

Pktsetup renvoie 0 en cas de succès, une valeur non nulle en cas d'échec.

OPTIONS

-d périphérique-paquet
Supprime l'association entre le périphérique-paquet spécifié et son périphérique bloc.
-s
Affiche le mappage actuel des périphériques, un périphérique par ligne, au format
nom : pktdevid -> blkdevid
(par exemple « 0 : 253:0 -> 22:0 »)

EXEMPLE

Les commandes suivantes fournissent un exemple d'utilisation du périphérique de paquet.

cdrwtool -d /dev/sr0 -q
pktsetup 0 /dev/sr0
mount -t udf /dev/pktcdvd0 /mnt
 ...
umount /dev/pktcdvd0
pktsetup -d 0

FICHIERS

/dev/pktcdvd0,/dev/pktcdvd1,...  Périphériques de paquets CD/DVD
