NOM

pkgctl-issue-view - Afficher les informations sur un problème

SYNTAXE

pkgctl issue view [OPTIONS]

DESCRIPTION

Cette commande est conçue pour afficher des informations détaillées sur un problème spécifique dans les projets de paquets Arch Linux. Elle recueille et affiche joliment toutes les données pertinentes concernant le problème, fournissant une vue complète qui inclut la description du problème, son statut ainsi que ses étiquettes et sa date de création.

Par défaut, la commande opère dans le répertoire courant, mais les utilisateurs ont la possibilité de spécifier une base de paquet différente. De plus, les utilisateurs peuvent choisir de voir le problème dans un navigateur web pour une expérience plus interactive.

Pour ceux qui ont besoin d'informations plus approfondies, la commande peut également afficher tous les commentaires et activités liés au problème, fournissant un contexte historique complet et les discussions en cours.

OPTIONS

-p, --package PKGBASE

Interagir avec PKGBASE au lieu du répertoire courant

-c, --comments

Afficher les commentaires et activités du problème

-w, --web

Ouvrir le problème dans un navigateur

-h, --help

Afficher un texte d'aide
