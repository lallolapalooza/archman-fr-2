NOM

pkgctl-license - Vérifier et gérer la conformité des licences de paquets

SYNTAXE

pkgctl license [OPTIONS] [SOUS-COMMANDE]

DESCRIPTION

Commandes relatives aux licences de paquets, y compris les vérifications de conformité.

Utilise reuse(1) et un fichier REUSE.toml situé à côté du PKGBUILD(5).

CONFIGURATION

Le fichier REUSE.toml doit contenir des annotations pour tous les fichiers réguliers attendus dans un dépôt de paquets Arch Linux.

Utilisez pkgctl-license-setup(1) pour détecter et configurer automatiquement un fichier de configuration REUSE de base basé sur les fichiers du dépôt de paquets.

Pour des informations détaillées sur les différentes options de configuration disponibles pour le fichier REUSE.toml, référez-vous à la Spécification REUSE ( https://reuse.software/spec).

OPTIONS

-h, --help

Afficher un message d'aide

SOUS-COMMANDES

pkgctl license check

Vérifie la conformité des licences des paquets à l'aide de REUSE

pkgctl license setup

Détecte et configure automatiquement un REUSE de base

VOIR AUSSI

pkgctl-license-check(1) pkgctl-license-setup(1) reuse(1) PKGBUILD(5)
