NOM

pkgctl-repo-switch - Changer un dépôt de paquets vers une version spécifiée

SYNTAXE

pkgctl repo switch [OPTIONS] [VERSION] [PKGBASE]...

DESCRIPTION

Change le dépôt source d'un paquet vers une version, une étiquette (tag) ou une branche spécifiée. L'arbre de travail et l'index sont mis à jour pour correspondre à la référence spécifiée.

Si un identifiant de version est spécifié dans le format de version de pacman, cet identifiant est automatiquement traduit en nom d'étiquette Git en conséquence.

Le répertoire de travail courant est utilisé si aucun PKGBASE n'est spécifié.

OPTIONS

--discard-changes

Poursuivre même si l'index ou l'arbre de travail diffère de HEAD. L'index et l'arbre de travail seront restaurés pour correspondre à la cible du changement.

-f, --force

Un alias pour --discard-changes.

-h, --help

Afficher un texte d'aide
