NOM

pkgctl-version-setup - Détecte et configure automatiquement une configuration de base pour nvchecker

SYNTAXE

pkgctl version setup [OPTIONS] [PKGBASE...]

DESCRIPTION

Cette sous-commande automatise la création d'un fichier de configuration nvchecker.toml de base en analysant le tableau `source` spécifié dans le fichier PKGBUILD(1) d'un paquet. Cette commande détecte intelligemment diverses plateformes et API (par exemple, GitHub, GitLab, PyPI) utilisées par les sources du paquet et génère une configuration .nvchecker.toml correspondante basée sur sa meilleure estimation.

Ceci est particulièrement utile pour initialiser les paramètres de nvchecker(1) pour un paquet sans avoir à créer manuellement le fichier .nvchecker.toml. Cela simplifie le processus de mise en place des vérifications de version, en particulier lors de la transition de la surveillance d'un paquet d'une plateforme source à une autre ou lors du démarrage des vérifications de version pour un nouveau paquet.

Si aucun PKGBASE n'est spécifié, la commande utilise par défaut le répertoire de travail actuel.

Pour obtenir une liste des sources prises en charge et de leurs formats d'URL attendus, veuillez consulter la section sources.

OPTIONS

-f, --force

Écrase la configuration nvchecker(1) existante

--prefer-platform-api

Préfère l'API spécifique à la plateforme GitHub/GitLab plutôt que Git pour les cas complexes

--url URL

Dérive la cible de vérification de l'URL donnée au lieu des entrées du tableau source

--no-check

Ne pas exécuter pkgctl-version-check(1) après la configuration

--no-upstream

Configure un fichier vide pour les paquets sans sources en amont, comme les méta-paquets. Ceci ne doit être utilisé que pour les cas sans source en amont. Veuillez contacter l'équipe de développement pour des conseils concernant les sources en amont difficiles à configurer.

-h, --help

Affiche un texte d'aide

EXEMPLES

pkgctl version setup

Détecte la source à partir du répertoire courant et configure un .nvchecker.toml de base.

pkgctl version setup --url https://github.com/example/project

Génère un .nvchecker.toml pour le PKGBUILD(1) actuel, mais remplace l'URL source par le projet GitHub spécifié.
