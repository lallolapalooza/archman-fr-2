PKI --ISSUE(1) strongSwan PKI --ISSUE(1)

NOM

pki --issue - Émet un certificat à l'aide d'un certificat et d'une clé CA

SYNTAXE

pki --issue [--in fichier] [--type type] --cakey fichier|--cakeyid hex --cacert fichier [--dn nom-distinctif-sujet] [--san nom-alternatif-sujet] [--lifetime jours] [--not-before date-heure] [--not-after date-heure] [--serial hex] [--flag flag] [--digest digest] [--rsa-padding padding] [--ca] [--crl uri [--crlissuer émetteur]] [--ocsp uri] [--pathlen len] [--addrblock bloc] [--nc-permitted nom] [--nc-excluded nom] [--critical oid] [--policy-mapping mapping] [--policy-explicit len] [--policy-inhibit len] [--policy-any len] [--cert-policy oid [--cps-uri uri] [--user-notice texte]] [--outform encodage] [--debug niveau]
pki --issue --options fichier
pki --issue -h | --help

DESCRIPTION

Cette sous-commande de pki(1) est utilisée pour émettre un certificat à l'aide d'un certificat et d'une clé privée CA.

OPTIONS

-h, --help
Affiche les informations d'utilisation avec un résumé des options disponibles.
-v, --debug niveau
Définit le niveau de débogage, par défaut : 1.
-+, --options fichier
Lit les options de la ligne de commande depuis le fichier fichier.
-i, --in fichier
Fichier de clé publique ou de demande de certificat PKCS#10 à émettre. S'il n'est pas fourni, la clé/demande est lue depuis STDIN.
-t, --type type
Type de l'entrée. L'un des types suivants : pub (clé publique), priv (clé privée), rsa (clé privée RSA), ecdsa (clé privée ECDSA), ed25519 (clé privée Ed25519), ed448 (clé privée Ed448) ou pkcs10 (demande de certificat PKCS#10), par défaut pub.
-k, --cakey fichier
Fichier de clé privée CA. L'un des deux (--cakey ou --cakeyid) est requis.
-x, --cakeyid hex
Identifiant de l'objet de clé privée CA sur carte à puce ou TPM au format hexadécimal avec un préfixe 0x optionnel. L'un des deux (--cakey ou --cakeyid) est requis.
-c, --cacert fichier
Fichier de certificat CA. Requis.
-d, --dn nom-distinctif-sujet
Nom distinctif (DN) du sujet du certificat émis.
-a, --san nom-alternatif-sujet
Extension subjectAltName à inclure dans le certificat. Peut être utilisée plusieurs fois.
-l, --lifetime jours
Nombre de jours pendant lesquels le certificat est valide, par défaut : 1095. Ignoré si une date de début et une date de fin absolues sont fournies.
-F, --not-before date-heure
Heure absolue à laquelle la validité du certificat commence. Le format de la date et de l'heure est défini par l'option --dateform.
-T, --not-after date-heure
Heure absolue à laquelle la validité du certificat se termine. Le format de la date et de l'heure est défini par l'option --dateform.
-D, --dateform format
Format strptime(3) pour les options --not-before et --not-after, par défaut : %d.%m.%y %T
-s, --serial hex
Numéro de série en hexadécimal. Il est alloué aléatoirement par défaut.
-e, --flag flag
Ajoute un indicateur extendedKeyUsage. L'un des éléments suivants : serverAuth, clientAuth, crlSign, ocspSigning ou msSmartcardLogon. Peut être utilisé plusieurs fois. Sans modificateurs, cela remplace les indicateurs des demandes de certificat PKCS#10. Préfixer un indicateur avec + l'ajoute à l'ensemble des indicateurs lus depuis la demande, le préfixer avec - le retire de cet ensemble.
-g, --digest digest
Digest à utiliser pour la création de la signature. L'un des éléments suivants : md5, sha1, sha224, sha256, sha384 ou sha512. Le digest par défaut est déterminé en fonction du type et de la taille de la clé de signature.
-R, --rsa-padding padding
Padding à utiliser pour les signatures RSA. Soit pkcs1 soit pss, par défaut pkcs1.
-f, --outform encodage
Encodage du fichier de certificat créé. Soit der (ASN.1 DER) soit pem (PEM Base64), par défaut der.
-b, --ca
Inclut l'extension basicConstraint CA dans le certificat.
-u, --crl uri
URI du point de distribution CRL à inclure dans le certificat. Peut être utilisée plusieurs fois.
-I, --crlissuer émetteur
Émetteur CRL optionnel pour le CRL au point de distribution précédent.
-o, --ocsp uri
URI AuthorityInfoAccess OCSP à inclure dans le certificat. Peut être utilisée plusieurs fois.
-p, --pathlen len
Définit la contrainte de longueur de chemin.
-B, --addrblock bloc
Bloc d'adresses RFC 3779 à inclure dans le certificat. bloc est soit un sous-réseau CIDR (tel que 10.0.0.0/8) soit une plage d'adresses arbitraire (192.168.1.7-192.168.1.13). Peut être répété pour inclure plusieurs blocs. Veuillez noter que les blocs fournis sont inclus tels quels dans le certificat, donc pour la conformité aux normes, plusieurs blocs doivent être fournis dans le bon ordre et les blocs adjacents doivent être combinés. Se référer à la RFC 3779 pour les détails.
-n, --nc-permitted nom
Ajoute une extension NameConstraint autorisée au certificat. Pour les contraintes DNS ou email, le type d'identité n'est pas toujours détectable par le nom fourni. Utilisez le préfixe dns: ou email: pour forcer un type de contrainte.
-N, --nc-excluded nom
Ajoute une extension NameConstraint exclue au certificat. Pour les contraintes DNS ou email, le type d'identité n'est pas toujours détectable par le nom fourni. Utilisez le préfixe dns: ou email: pour forcer un type de contrainte.
-X, --critical oid
Ajoute une extension critique avec l'OID donné.
-M, --policy-mapping oid-émetteur:oid-sujet
Ajoute un policyMapping de l'émetteur vers l'OID sujet.
-E, --policy-explicit len
Ajoute une contrainte requireExplicitPolicy.
-H, --policy-inhibit len
Ajoute inhibitPolicyMap

pki(1) — pki --issue

NAME

pki --issue - issue certificate

SYNOPSIS

pki [--help] [--options file] [--keyid id] [--lifetime days] [--digest alg] [--type type] [--flag flags] [--require-policy oid] [--inhibit-policy oid] [--inhibit-any] [--cert-policy oid] [--cps-uri uri] [--user-notice text] [--issue] [--cacert file] [--cakey file] [--in file] [--out file] [--] [args]

DESCRIPTION

The pki --issue command creates a certificate based on a given PKCS#10 certificate request and the CA key specified with --cakey. The certificate is signed with the CA key and the validity period is specified with --lifetime.

The --in option specifies the PKCS#10 certificate request file (defaults to stdin). The certificate is written to stdout by default, or to the file specified with --out.

Options can be read from a file using --options to avoid repetitive typing.

OPTIONS

The following options are available:

--help
Print usage information and exit.
--options file
Read command line options from file.
--keyid id
Set certificate subject key identifier.
--lifetime days
Set certificate validity period in days. Defaults to 365.
--digest alg
Set digest algorithm (e.g. sha1, sha256). Defaults to sha1.
--type type
Set certificate type. Supported types are pkcs10, issuer, subject, any. Defaults to pkcs10.
--flag flags
Set certificate flags. Supported flags are serverAuth, clientAuth, crlSign, keyEncipherment, dataEncipherment, subordinateSign, nameConstraints, ocspSigning.
--require-policy oid
Add requireAnyPolicy constraint.
--inhibit-policy oid
Add inhibitPolicy constraint.
--inhibit-any
Add inhibitAnyPolicy constraint.
-P, --cert-policy oid
OID to include in certificatePolicy extension. Required.
-C, --cps-uri uri
Certification Practice statement URI for certificatePolicy.
-U, --user-notice text
User notice for certificatePolicy.
--issue
Issue certificate.
--cacert file
CA certificate file.
--cakey file
CA private key file.
--in file
Input PKCS#10 certificate request file.
--out file
Output certificate file.

Politique de certificat

Plusieurs extensions de certificatPolicy peuvent être ajoutées. Chacune avec les informations suivantes :

-P, --cert-policy oid
OID à inclure dans l'extension certificatePolicy. Obligatoire.
-C, --cps-uri uri
URI de la déclaration de pratique de certification pour certificatePolicy.
-U, --user-notice text
Avis utilisateur pour certificatePolicy.

EXEMPLES

Pour éviter de taper des commandes répétitives, les options de ligne de commande peuvent être stockées dans des fichiers. Supposons que pki.opt contienne le contenu suivant :

  --cacert ca_cert.der --cakey ca_key.der --digest sha256
  --flag serverAuth --lifetime 1460 --type pkcs10

Ensuite, la commande suivante peut être utilisée pour émettre un certificat basé sur une requête de certificat PKCS#10 donnée et les options ci-dessus :

  pki --issue --options pki.opt --in req.der > cert.der
