NOM

pkgctl-issue-move - Déplacer un ticket vers un autre projet

SYNTAXE

pkgctl issue move [OPTIONS] [IID] [PAQUET_DESTINATION]

DESCRIPTION

La commande move permet aux utilisateurs de transférer un ticket d'un projet à un autre au sein du groupe d'empaquetage d'Arch Linux. Ceci est utile lorsqu'un ticket est identifié comme étant plus pertinent ou mieux géré dans un projet différent.

Par défaut, la commande opère dans le répertoire courant, mais les utilisateurs peuvent spécifier une base de paquet différente à partir de laquelle déplacer le ticket.

Les utilisateurs doivent spécifier l'identifiant du ticket (IID) et le paquet de destination vers lequel le ticket doit être déplacé. Un message de commentaire expliquant la raison du déplacement peut être fourni directement via la ligne de commande. Pour des explications plus détaillées ou un contexte supplémentaire, les utilisateurs ont la possibilité d'éditer le commentaire de déplacement à l'aide d'un éditeur de texte avant de le soumettre.

OPTIONS

-p, --package PKGBASE

Déplace à partir de PKGBASE au lieu du répertoire courant

-m, --message MSG

Utilise le message fourni comme commentaire

-e, --edit

Édite le commentaire à l'aide d'un éditeur

-h, --help

Affiche un message d'aide
