NOM

pki --dn - Extraire le DN du sujet d'un certificat X.509

SYNTAXE

pki --dn [--in fichier] [--format format] [--debug niveau]
pki --dn --options fichier
pki --dn -h | --help

DESCRIPTION

Cette sous-commande de pki(1) extrait le DistinguishedName (DN) encodé en ASN.1 d'un certificat X.509 et l'exporte dans différents formats. Cela peut être utile lorsque l'analyseur d'identité de strongSwan ne parvient pas à produire le bon encodage binaire à partir d'une chaîne de caractères.

OPTIONS

-h, --help
Affiche les informations d'utilisation avec un résumé des options disponibles.
-v, --debug niveau
Définit le niveau de débogage, par défaut : 1.
-+, --options fichier
Lit les options de la ligne de commande depuis fichier.
-i, --in fichier
Fichier d'entrée. Si non spécifié, l'entrée est lue depuis STDIN.
-t, --format format
Format de sortie. L'un des choix suivants : config (compatible avec la configuration strongSwan), hex (encodage hexadécimal, sans préfixe), base64 (encodage Base64, sans préfixe), bin (données binaires brutes), par défaut : config.
