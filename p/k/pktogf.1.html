NOM

pktogf - convertir les fichiers de polices compressés en fichiers de polices génériques

SYNTAXE

pktogf [-v] nom_fichier_pk [nom_fichier_gf]

DESCRIPTION

Cette page de manuel n'est pas censée être exhaustive. La documentation complète pour cette version de TeX se trouve dans le fichier info ou le manuel Web2C : Une implémentation TeX.

Le programme pktogf convertit un fichier de police compressé (pk) en un fichier de police générique (gf). Les fichiers de polices compressés sont beaucoup plus petits que les fichiers gf correspondants, mais certains lecteurs DVI ne comprennent que les fichiers gf.

Le nom_fichier_pk sur la ligne de commande doit être complet. Comme la résolution fait partie de l'extension, il n'aurait pas de sens d'ajouter une extension par défaut comme le font les logiciels de lecture TeX ou DVI. Le nom_fichier_gf est par défaut le même nom (tronqué) que le nom_fichier_pk, et il est placé dans le répertoire de travail courant avec le suffixe gf remplaçant pk. Par exemple, le fichier d'entrée io.300pk deviendrait io.300gf.

OPTIONS

À moins que l'option -v ne soit donnée, pktogf fonctionne silencieusement. Avec -v, le numéro de version du programme et les statistiques sur le décompressage sont affichés sur stdout.

ENVIRONNEMENT

pktogf recherche nom_fichier_pk en utilisant la variable d'environnement PKFONTS. Si celle-ci n'est pas définie, il utilise la variable TEXPKS. Si celle-ci n'est pas définie, il utilise TEXFONTS. Si celle-ci n'est pas définie, il utilise la valeur par défaut du système.

Voir tex(1) pour les détails de la recherche.

VOIR AUSSI

gftopk(1), gftype(1), pktype(1).
Donald E. Knuth et al., Metafontware.

AUTEURS

Tomas Rokicki a écrit le programme. Pierre MacKay l'a adapté pour la compilation avec web2c.
