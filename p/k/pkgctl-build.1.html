NOM

pkgctl-build - Compiler des paquets dans un environnement chroot propre

SYNTAXE

pkgctl build [OPTIONS] [PATH...]

DESCRIPTION

Compile des paquets dans un environnement chroot propre, offrant diverses options et fonctionnalités pour personnaliser le processus de compilation des paquets.

Par défaut, les environnements chroot se trouvent dans /var/lib/archbuild/.

OPTIONS DE COMPILATION

--arch ARCH

Spécifie les architectures pour lesquelles compiler (désactive la détection automatique)

--repo REPO

Spécifie le dépôt cible pour les nouveaux paquets n'appartenant à aucun dépôt officiel. Rebascule sur 'extra' lors de la compilation des paquets qui ne sont pas encore présents dans un dépôt officiel. L'utilisation de cette option est interdite si le paquet est déjà publié, car cela contournerait la protection de détection automatique.

-s, --staging

Compile par rapport à la contrepartie de staging du dépôt détecté automatiquement

-t, --testing

Compile par rapport à la contrepartie de testing du dépôt détecté automatiquement

-o, --offload

Compile sur un serveur distant et transfère les artefacts par la suite

-c, --clean

Recrée le chroot avant la compilation

--inspect QUAND

Lance un shell interactif pour inspecter le chroot après la compilation. Utile pour faciliter le débogage d'une compilation de paquet.
Les valeurs possibles pour QUAND sont 'never', 'always' ou 'failure'

-w, --worker SLOT

Nom de l'emplacement de travail, utile pour les compilations simultanées. Par défaut, l'emplacement est automatiquement attribué au numéro pts du terminal actuel. Si l'appelant n'est pas un terminal, choisit un emplacement aléatoire entre 1 et le nombre d'unités de traitement disponibles.

--nocheck

Ne pas exécuter la fonction check() dans le PKGBUILD

OPTIONS D'INSTALLATION

-I, --install-to-chroot FICHIER

Installe un paquet dans la copie de travail du chroot

-i, --install-to-host MODE

Installe les paquets compilés sur le système hôte. Utile lorsque l'on veut vérifier que le paquet fonctionne comme prévu.
•Lorsque MODE est all, cela installe tous les paquets compilés
•Lorsque MODE est auto, cela installe tous les paquets compilés qui sont actuellement installés

OPTIONS PKGBUILD

--pkgver=PKGVER

Définit pkgver, réinitialise pkgrel et met à jour les sommes de contrôle

--pkgrel=PKGREL

Définit pkgrel à une valeur donnée

--rebuild

Incrémente la variable pkgrel actuelle

--update-checksums

Force le calcul et la mise à jour des sommes de contrôle en désactivant la détection automatique.
Ne doit être utilisé que dans des circonstances particulières, comme lors de l'ajout de nouveaux fichiers de patch au tableau source. Lors des opérations d'empaquetage régulières, les sommes de contrôle sont soit automatiquement mises à jour lors de la mise à niveau d'un paquet à l'aide de --pkgver, soit elles doivent rester immuables pendant les reconstructions.

-e, --edit

Modifie le PKGBUILD avant de compiler

OPTIONS DE PUBLICATION

-r, --release

Valide, étiquette et publie automatiquement après la compilation
Spécifier cette option est requis lors de l'utilisation de l'une des options suivantes dans cette section

-m, --message MSG

Utilise le <msg> donné comme message de commit

-u, --db-update

Met à jour automatiquement la base de données pacman comme dernière action

OPTIONS

-h, --help

Affiche le texte d'aide

VOIR AUSSI
