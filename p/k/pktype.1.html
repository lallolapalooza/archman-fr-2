PKTYPE(1) Manuel des commandes générales PKTYPE(1)

NOM

pktype - vérifier et traduire un fichier bitmap de police packée en texte brut

SYNTAXE

pktype pk_file[pk]

DESCRIPTION

Cette page de manuel n'est pas censée être exhaustive. La documentation complète de cette version de TeX se trouve dans le fichier info ou le manuel Web2C : Une implémentation de TeX.

Le programme pktype traduit un fichier de police packée (pk) (produit, par exemple, par gftopk(1) en un fichier que les humains peuvent lire. Il sert également de programme de validation de fichiers pk (c'est-à-dire que si pktype peut le lire, il est correct) et d'exemple de programme de lecture de pk pour d'autres logiciels souhaitant lire des fichiers pk.

Le fichier d'entrée pk_file dans la ligne de commande peut omettre le suffixe « pk. La traduction en texte brut est toujours écrite sur la sortie standard.

Le fichier de sortie donne un codage compact du codage packé, en utilisant les conventions décrites dans le code source. Les séries de pixels noirs alternent avec des séries de pixels blancs entre parenthèses, et des crochets sont utilisés pour indiquer quand une ligne doit être répétée.

ENVIRONNEMENT

pktype recherche pk_file aux endroits habituels selon Kpathsea.

Voir tex(1) pour les détails de la recherche.

VOIR AUSSI

dvitype(1), gftopk(1), gftype(1).
Donald E. Knuth et al., Metafontware.

AUTEURS

Tomas Rokicki a écrit le programme, Donald E. Knuth l'a initialement porté sous Unix, Pierre MacKay l'a initialement adapté pour être compilé avec Web2c.
