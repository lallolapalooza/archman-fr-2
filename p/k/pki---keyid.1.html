NOM

pki --keyid - Calculer les identifiants de clé d'une clé ou d'un certificat

SYNTAXE

pki --keyid [--in fichier|--keyid hex] [--type type] [--id type-id] [--format format] [--debug niveau]
pki --keyid --options fichier
pki --keyid -h | --help

DESCRIPTION

Cette sous-commande de pki(1) calcule les identifiants de clé des clés privées et des certificats.

OPTIONS

-h, --help
Affiche les informations d'utilisation avec un résumé des options disponibles.
-v, --debug niveau
Définit le niveau de débogage, par défaut : 1.
-+, --options fichier
Lit les options de la ligne de commande à partir du fichier.
-i, --in fichier
Fichier d'entrée. S'il n'est pas fourni, l'entrée est lue à partir de STDIN.
-x, --keyid hex
Handle de l'objet clé privée de la carte à puce ou du TPM au format hexadécimal avec un préfixe 0x optionnel.
-t, --type type
Type d'entrée. L'un des choix suivants : priv (clé privée), rsa (clé privée RSA), ecdsa (clé privée ECDSA), pub (clé publique), pkcs10 (demande de certificat PKCS#10), x509 (certificat X.509), par défaut priv.
-I, --id type-id
Type d'identifiant. L'un des choix suivants : all (tous les identifiants), spk (hash SHA-1 de subjectPublicKey), spki (hash SHA-1 de subjectPublicKeyInfo), par défaut all.
-f, --format format
Format de sortie. L'un des choix suivants : pretty (sortie lisible par l'utilisateur), hex (encodage hexadécimal), base64 (encodage Base64), bin (données binaires brutes), par défaut pretty.

EXEMPLES

Calculer les identifiants de clé d'une clé privée RSA :

  $ pki --keyid --in key.der
  subjkey (SHA-1 de subjectPublicKey) :
               6a:9c:74:d1:f8:89:79:89:f6:5a:94:e9:89:f1...
  keyid (SHA-1 de subjectPublicKeyInfo) :
               6e:55:dc:7e:9c:a5:58:d9:5b:e3:c7:13:14:e1...

Calculer les identifiants de clé d'un certificat X.509 :

  $ pki --keyid --in cert.der --type x509
  subjkey (SHA-1 de subjectPublicKey) :
               6a:9c:74:d1:f8:89:79:89:f6:5a:94:e9:89:f1...
  keyid (SHA-1 de subjectPublicKeyInfo) :
               6e:55:dc:7e:9c:a5:58:d9:5b:e3:c7:13:14:e1...

Calculer le keyid au format hexadécimal simple d'un certificat X.509 :

  $ pki --keyid --in cert.der --type x509 --id spki --format hex
  6e55dc7e9ca558d95be3c71314e1...
