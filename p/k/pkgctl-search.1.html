NOM

pkgctl-search - Rechercher une expression dans le groupe de paquets GitLab

SYNTAXE

pkgctl search [OPTIONS] REQUÊTE

DESCRIPTION

Rechercher une expression dans le groupe de paquets GitLab.

Pour utiliser un filtre, incluez-le dans votre requête. Vous pouvez utiliser des caractères génériques (*) pour utiliser la correspondance glob.

Filtres disponibles pour la portée des blobs : chemin, extension

Toute utilisation de la commande de recherche doit être authentifiée. Consultez la commande 'pkgctl auth' pour vous authentifier auprès de GitLab ou pour afficher l'état d'authentification.

ASTUCES DE RECHERCHE

Syntaxe  Description    Exemple
───────────────────────────────────────
"       Recherche exacte   "gem sidekiq"
~       Recherche floue   J~ Doe
|       Ou             display | banner
+       Et             display +banner
-       Exclure        display -banner
*       Partiel        bug error 50*
\       Échapper       \*md
#       ID du ticket   #23456
!       Requête de fusion  !23456

OPTIONS

-h, --help

Afficher un texte d'aide

OPTIONS DE FILTRE

--no-default-filter

N'applique pas le filtre par défaut (comme -path:keys/pgp/*.asc)

OPTIONS DE SORTIE

--json

Active l'affichage en JSON ; Raccourci pour '--format json'

-F, --format FORMAT

Contrôle le formatage des résultats ; FORMAT est 'pretty', 'plain', ou 'json' (par défaut pretty)

-N, --no-line-number

N'affiche pas les numéros de ligne lors du formatage des résultats
