NOM

pkgctl-issue-comment - Commenter un problème

SYNTAXE

pkgctl issue comment [OPTIONS] [IID]

DESCRIPTION

Cette commande permet aux utilisateurs d'ajouter des commentaires à un problème dans les projets de paquets Arch Linux. Cette commande est utile pour fournir des retours d'information, des mises à jour ou toute information supplémentaire relative à un problème directement dans le système de suivi des problèmes du projet.

Par défaut, la commande interagit avec le répertoire courant, mais les utilisateurs peuvent spécifier une base de paquet différente si nécessaire.

Les utilisateurs peuvent fournir un message de commentaire directement via la ligne de commande, assurant une communication rapide et efficace. De plus, pour des commentaires plus détaillés ou formatés, les utilisateurs ont la possibilité d'éditer leur commentaire à l'aide d'un éditeur de texte avant de le soumettre.

OPTIONS

-p, --package PKGBASE

Interagir avec PKGBASE au lieu du répertoire courant

-m, --message MSG

Utiliser le message fourni comme commentaire

-e, --edit

Éditer le commentaire à l'aide d'un éditeur

-h, --help

Afficher le texte d'aide

PAGE D'ACCUEIL

https://gitlab.archlinux.org/archlinux/devtools

Veuillez signaler les bugs et les demandes de fonctionnalités dans le suivi des problèmes. Veuillez faire de votre mieux pour fournir un cas de test reproductible pour les bugs.
