NOM

pkgctl-license-check - Vérifie la conformité des licences des paquets avec REUSE

SYNTAXE

pkgctl license check [OPTIONS] [PKGBASE...]

DESCRIPTION

Vérifie la conformité des licences des paquets avec REUSE et vérifie également si un fichier LICENSE avec le texte de licence spécifique 0BSD d'Arch Linux est présent.

CONFIGURATION

Utilise reuse(1) et un fichier REUSE.toml situé à côté du PKGBUILD(5). Voir la section de configuration dans pkgctl-license(1).

Si aucun PKGBASE n'est spécifié, la commande utilise par défaut le répertoire de travail actuel.

OPTIONS

-h, --help

Affiche un message d'aide

CODES DE SORTIE

À la sortie, retourne l'un des codes suivants :

0

Condition de sortie normale, tous les paquets vérifiés sont conformes

1

Cause inconnue de l'échec

2

Condition de sortie normale, mais certains paquets ne sont pas conformes
