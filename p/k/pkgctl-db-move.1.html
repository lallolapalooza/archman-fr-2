NOM

pkgctl-db-move - Déplace les paquets entre dépôts binaires.

SYNTAXE

pkgctl db move [OPTIONS] [DEPOT_SOURCE] [DEPOT_CIBLE] [PAQUETBASE]...

DESCRIPTION

Déplace les paquets entre dépôts binaires, par exemple de extra-testing vers extra.

OPTIONS

-h, --help
