pcre_get_substring_list(3)

Paquet: pcre

Licences: BSD

PCRE_GET_SUBSTRING_LIST(3) Manuel des fonctions de bibliothèque PCRE_GET_SUBSTRING_LIST(3)

NOM

PCRE - expressions régulières compatibles Perl

SYNTAXE

#include <pcre.h>

int pcre_get_substring_list(const char *subject,
     int *ovector, int stringcount, const char ***listptr);

int pcre16_get_substring_list(PCRE_SPTR16 subject,
     int *ovector, int stringcount, PCRE_SPTR16 **listptr);

int pcre32_get_substring_list(PCRE_SPTR32 subject,
     int *ovector, int stringcount, PCRE_SPTR32 **listptr);

DESCRIPTION

Ceci est une fonction utilitaire pour extraire une liste de tous les sous-chaînes capturées. Les arguments sont :


subject Sujet qui a correspondu avec succès
ovector Vecteur d'offset que pcre[16|32]_exec a utilisé
stringcount Valeur retournée par pcre[16|32]_exec
listptr Où placer un pointeur vers la liste

La mémoire dans laquelle les sous-chaînes et la liste sont placées est obtenue en appelant pcre[16|32]_malloc(). La fonction utilitaire pcre[16|32]_free_substring_list() peut être utilisée pour la libérer lorsqu'elle n'est plus nécessaire. Un pointeur vers une liste de pointeurs est placé dans la variable dont l'adresse est dans listptr. La liste est terminée par un pointeur NULL. Le résultat de la fonction est zéro en cas de succès ou PCRE_ERROR_NOMEMORY si suffisamment de mémoire n'a pas pu être obtenue.

Il y a une description complète de l'API native de PCRE dans la page pcreapi et une description de l'API POSIX dans la page pcreposix.
