NOM

pcap_set_promisc - définir le mode promiscuous pour un descripteur de capture pas encore activé

SYNTAXE

#include <pcap/pcap.h>
int pcap_set_promisc(pcap_t *p, int promisc);

DESCRIPTION

pcap_set_promisc() définit si le mode promiscuous doit être activé sur un descripteur de capture lorsque celui-ci est activé. Si promisc est différent de zéro, le mode promiscuous sera activé, sinon il ne le sera pas.

VALEUR DE RETOUR

pcap_set_promisc() retourne 0 en cas de succès ou PCAP_ERROR_ACTIVATED si appelé sur un descripteur de capture qui a déjà été activé.

VOIR AUSSI

pcap(3PCAP), pcap_create(3PCAP), pcap_activate(3PCAP)
