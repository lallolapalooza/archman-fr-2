PCSCD(8) PC/SC Lite PCSCD(8)

NOM

pcscd - Démon PC/SC pour cartes à puce

SYNTAXE

pcscd [-acfTdeCvHSI] [--apdu] [--config dir] [--foreground] [--color] [--debug] [--info] [--error] [--critical] [--force-reader-polling] [-t nombre] [--max-thread nombre] [-s nombre] [--max-card-handle-per-thread nombre] [-r nombre] [--max-card-handle-per-reader nombre] [--version] [--hotplug] [--reader-name-no-serial] [--reader-name-no-interface] [--disable-polkit]
pcscd -h
pcscd --help

OPTIONS

-a, --apdu
enregistre les APDU et SW en utilisant la méthode de débogage (voir --debug).
-c, --config dir
Spécifie le répertoire dir comme emplacement alternatif pour /etc/reader.conf.d/. L'argument peut aussi être un seul fichier de configuration (pour la compatibilité descendante).
-f, --foreground
Exécute pcscd au premier plan et envoie les messages de log vers stderr au lieu de syslog(3).
-T, --color
force l'utilisation de logs en couleur.
-d, --debug
utilise le niveau de log le plus bas. Tout message de log de ce niveau ou supérieur sera envoyé vers stderr ou syslog(3) selon l'utilisation de --foreground.
--info
utilise le niveau de log info. C'est le niveau de log par défaut.
-e, --error
utilise le niveau de log error.
-C, --critical
utilise le niveau de log critical.

Les niveaux de log sont ordonnés comme suit : debug < info < error < critical. Utiliser un niveau de log l enregistrera ce niveau et tous les niveaux supérieurs.

--force-reader-polling
ignore la capacité du lecteur IFD_GENERATE_HOTPLUG
-t, --max-thread nombre
nombre maximum de threads (par défaut 200).

C'est le nombre maximum de clients (SCardEstablishContext) que pcscd peut gérer.

-s, --max-card-handle-per-thread nombre
nombre maximum de descripteurs de carte par thread (par défaut : 200).

C'est le nombre maximum de descripteurs de carte (SCardConnect) par client (SCardEstablishContext).

-r, --max-card-handle-per-reader nombre
nombre maximum de descripteurs de carte par lecteur (par défaut : 200)

C'est le nombre maximum de descripteurs de carte (SCardConnect) par lecteur.

-h, --help
Affiche les informations sur la ligne de commande de pcscd.
-v, --version
Affiche le numéro de version du programme.
-H, --hotplug
Demande à pcscd de relire les fichiers /etc/reader.conf.d/my_reader.conf pour détecter les lecteurs non USB ajoutés ou supprimés (série ou PCMCIA).
-x, --auto-exit
pcscd se quittera après 60 secondes d'inactivité suite à la libération du dernier contexte PC/SC. Ceci est utilisé lorsque pcscd est démarré à la demande par systemd.
-S, --reader-name-no-serial
N'inclut pas le numéro de série USB dans le nom du lecteur.
-I, --reader-name-no-interface
N'inclut pas le nom de l'interface USB dans le nom du lecteur.
--disable-polkit
Ignore les règles polkit. Tous les accès sont autorisés.

DESCRIPTION

pcscd est le programme démon de pcsc-lite. C'est un gestionnaire de ressources qui coordonne les communications avec les lecteurs de cartes à puce et les cartes à puce et les jetons cryptographiques connectés au système.

Il permet aux applications d'accéder aux cartes à puce et aux lecteurs en utilisant l'API WinSCard mais sans connaître les détails de la carte ou du lecteur.

pcscd coordonne le chargement des pilotes pour les lecteurs de cartes.

PILOTES DE LECTEURS DE CARTES À PUCE SERIE

Les pilotes de lecteurs de cartes à puce sont placés dans le répertoire /usr/lib/pcsc/drivers. Chaque pilote est simplement un fichier .so. pcscd localise le pilote en utilisant les fichiers /etc/reader.conf.d/my_reader.conf. Voir la page de manuel de reader.conf(5) pour plus d'informations.

Certains pilotes sont disponibles à https://muscle.apdu.fr/musclecard.com/drivers.html.

PILOTES DE LECTEURS DE CARTES À PUCE USB

Les pilotes de lecteurs de cartes à puce USB sont situés dans le répertoire /usr/lib/pcsc/drivers sous forme de bundle. Vous ne devez PAS ajouter un pilote USB dans un fichier /etc/reader.conf.d/my_reader.conf.

FICHIER DE CONFIGURATION

Il est possible de définir des arguments qui seront utilisés par pcscd avec le fichier de configuration /etc/default/pcscd. Par exemple, vous pouvez augmenter le niveau de débogage en utilisant :

PCSCD_ARGS=--debug

Ou définir des variables d'environnement comme :

PCSCLITE_FILTER_IGNORE_READER_NAMES="Twin"
PCSCLITE_FILTER_EXTEND_READER_NAMES=" $HOSTNAME"

Voir https://blog.apdu.fr/posts/2021/08/pcsc-lite-configuration-using/ pour plus de détails.

FILTRAGE DES LECTEURS USB PAR UDEV (LINUX UNIQUEMENT)

Si le support udev est activé, le réglage de la propriété udev PCSCLITE_IGNORE=1 sur un périphérique USB fera que ce lecteur sera ignoré. Par exemple, pour ignorer tout lecteur connecté au port USB 3 du bus 1, ajoutez ce qui suit dans un fichier foobar.rules du répertoire /etc/udev/rules.d/ :

ACTION!="remove|unbind", SUBSYSTEM=="usb", KERNEL=="1-3", ENV{PCSCLITE_IGNORE}="1"

FICHIERS

/etc/default/pcscd : fichier de configuration du démon

/etc/reader.conf.d/* : fichiers de configuration des lecteurs série

/run/pcscd/pcscd.pid : identifiant du processus pcscd en cours d'exécution

/usr/lib/pcsc/drivers/ : répertoire contenant les bundles pour les pilotes USB

VOIR AUSSI

reader.conf(5), syslog(3), udev(7)
