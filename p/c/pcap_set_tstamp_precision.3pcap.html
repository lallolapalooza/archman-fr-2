NOM

pcap_set_tstamp_precision - définir la précision de l'horodatage renvoyée dans les captures

SYNOPSIS

#include <pcap/pcap.h>
int pcap_set_tstamp_precision(pcap_t *p, int tstamp_precision);

DESCRIPTION

pcap_set_tstamp_precision() définit la précision de l'horodatage souhaitée pour les paquets capturés sur le descripteur pcap au type spécifié par tstamp_precision. Elle doit être appelée sur un descripteur pcap créé par pcap_create(3PCAP) qui n'a pas encore été activé par pcap_activate(3PCAP). Deux précisions d'horodatage sont prises en charge, les microsecondes et les nanosecondes. On peut utiliser les options PCAP_TSTAMP_PRECISION_MICRO et PCAP_TSTAMP_PRECISION_NANO pour demander la précision souhaitée. Par défaut, les horodatages sont en microsecondes.

VALEUR DE RETOUR

pcap_set_tstamp_precision() renvoie 0 en cas de succès si la précision d'horodatage spécifiée est susceptible d'être prise en charge par le périphérique de capture, PCAP_ERROR_TSTAMP_PRECISION_NOTSUP si le périphérique de capture ne prend pas en charge la précision d'horodatage demandée, PCAP_ERROR_ACTIVATED si elle est appelée sur un handle de capture qui a été activé.

COMPATIBILITÉ ASCENDANTE

Cette fonction est devenue disponible dans la version 1.5.1 de libpcap. Dans les versions précédentes, les horodatages d'un périphérique de capture ou d'un fichier de sauvegarde sont toujours donnés en secondes et en microsecondes.
