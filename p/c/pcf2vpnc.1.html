NOM

pcf2vpnc - convertit les fichiers de configuration VPN de pcf au format vpnc

SYNTAXE

pcf2vpnc <fichier pcf> [fichier vpnc]

DESCRIPTION

Ce script accompagne vpnc. Il tente de convertir les fichiers de configuration *.pcf souvent distribués avec les clients VPN propriétaires (en lecture Cisco) en fichiers de configuration vpnc, généralement nommés *.conf.

Si [fichier vpnc] n'est pas spécifié, le résultat sera affiché sur STDOUT. S'il est spécifié, il sera écrit dans ce fichier. Assurez-vous que les permissions sont appropriées car il peut contenir des données sensibles !
