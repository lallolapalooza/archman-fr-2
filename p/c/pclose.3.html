popen(3) Manuel des fonctions de bibliothèque popen(3)

NOM

popen, pclose - ouvrir un flux vers ou depuis un processus

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdio.h>
FILE *popen(const char *command, const char *type);
int pclose(FILE *stream);
Exigences relatives aux macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

popen(), pclose():

    _POSIX_C_SOURCE >= 2
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

La fonction popen() ouvre un processus en créant un tube (pipe), en faisant un fork et en invoquant le shell. Puisqu'un tube est par définition unidirectionnel, l'argument type ne peut spécifier que la lecture ou l'écriture, pas les deux ; le flux résultant est en conséquence en lecture seule ou en écriture seule.

L'argument command est un pointeur vers une chaîne terminée par un caractère nul contenant une ligne de commande shell. Cette commande est passée à /bin/sh en utilisant l'option -c ; l'interprétation, le cas échéant, est effectuée par le shell.

L'argument type est un pointeur vers une chaîne terminée par un caractère nul qui doit contenir soit la lettre 'r' pour la lecture, soit la lettre 'w' pour l'écriture. Depuis glibc 2.9, cet argument peut également inclure la lettre 'e', qui fait que le descripteur de fichier sous-jacent se voit attribuer l'indicateur FD_CLOEXEC (fermeture lors de l'exécution) ; voir la description du drapeau O_CLOEXEC dans open(2) pour les raisons pour lesquelles cela peut être utile.

La valeur de retour de popen() est un flux I/O standard normal à tous égards, sauf qu'il doit être fermé avec pclose() plutôt qu'avec fclose(3). L'écriture dans un tel flux écrit dans l'entrée standard de la commande ; la sortie standard de la commande est la même que celle du processus qui a appelé popen(), sauf si cela est modifié par la commande elle-même. Inversement, la lecture depuis le flux lit la sortie standard de la commande, et l'entrée standard de la commande est la même que celle du processus qui a appelé popen().

Notez que les flux de sortie popen() sont mis en mémoire tampon par bloc par défaut.

La fonction pclose() attend que le processus associé se termine et renvoie le code de sortie de la commande tel que renvoyé par wait4(2).

VALEUR DE RETOUR

popen(): en cas de succès, renvoie un pointeur vers un flux ouvert qui peut être utilisé pour lire ou écrire dans le tube ; si les appels fork(2) ou pipe(2) échouent, ou si la fonction ne peut allouer de mémoire, NULL est renvoyé.

pclose(): en cas de succès, renvoie le code de sortie de la commande ; si wait4(2) renvoie une erreur, ou si une autre erreur est détectée, -1 est renvoyé.

En cas d'échec, les deux fonctions définissent errno pour indiquer l'erreur.

ERREURS

La fonction popen() ne définit pas errno si l'allocation de mémoire échoue. Si le fork(2) ou le pipe(2) sous-jacent échoue, errno est défini pour indiquer l'erreur. Si l'argument type est invalide et que cette condition est détectée, errno est défini à EINVAL.

Si pclose() ne peut pas obtenir le statut de l'enfant, errno est défini à ECHILD.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
popen (), pclose () Sécurité des threads MT-Safe

VERSIONS

La valeur 'e' pour type est une extension Linux.

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

MISE EN GARDE

Lisez attentivement les mises en garde dans system(3).

BOGUES

Comme l'entrée standard d'une commande ouverte en lecture partage son décalage de recherche avec le processus qui a appelé popen(), si le processus d'origine a effectué une lecture mise en mémoire tampon, la position d'entrée de la commande peut ne pas être celle attendue. De même, la sortie d'une commande ouverte en écriture peut s'entremêler avec celle du processus d'origine. Ce dernier point peut être évité en appelant fflush(3) avant popen().

L'échec d'exécution du shell est indiscernable de l'échec d'exécution de la commande par le shell, ou d'une sortie immédiate de la commande. Le seul indice est un code de sortie de 127.
