PCP-UPTIME(1) Manuel des commandes générales PCP-UPTIME(1)

NOM

pcp-uptime - indique depuis combien de temps le système est en cours d'exécution

SYNOPIS

pcp [options_pcp] uptime [-V?]

DESCRIPTION

pcp-uptime affiche sur une seule ligne les informations suivantes : l'heure actuelle, la durée de fonctionnement du système, le nombre d'utilisateurs actuellement connectés, et les moyennes de charge du système pour les 1, 5 et 15 dernières minutes.

Lorsqu'il est appelé via la commande pcp(1), les options -h/--host, -a/--archive, -O/--origin, -Z/--timezone et plusieurs autres options pcp deviennent indirectement disponibles.

OPTIONS

Les options de ligne de commande disponibles sont :

-V, --version
Affiche le numéro de version et quitte.
-?, --help
Affiche le message d'utilisation et quitte.

Lors de la relecture à partir d'une archive en utilisant l'option -a, les informations requises peuvent ne pas être disponibles à l'heure de départ par défaut, auquel cas les valeurs rapportées seront ``?''. Dans ce cas, utilisez les options -S ou -O pour déplacer l'heure de départ vers un point de l'archive où les informations requises sont disponibles.

NOTES

pcp-uptime est inspiré de la commande uptime(1) et vise à être compatible avec elle en termes de ligne de commande et de sortie.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

Pour les variables d'environnement affectant les outils PCP, voir pmGetOptions(3).

VOIR AUSSI

PCPIntro(1), pcp(1), uptime(1) et environ(7).
