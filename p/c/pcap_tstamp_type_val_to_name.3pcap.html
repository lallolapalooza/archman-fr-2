PCAP_TSTAMP_TYPE_VAL_TO_NAME(3PCAP) PCAP_TSTAMP_TYPE_VAL_TO_NAME(3PCAP)

NOM

pcap_tstamp_type_val_to_name, pcap_tstamp_type_val_to_description - obtenir un nom ou une description pour une valeur de type d'horodatage

SYNTAXE

#include <pcap.h>
const char *pcap_tstamp_type_val_to_name(int tstamp_type);
const char *pcap_tstamp_type_val_to_description(int tstamp_type);

DESCRIPTION

pcap_tstamp_type_val_to_name() traduit une valeur de type d'horodatage en son nom de type d'horodatage correspondant. NULL est retourné en cas d'échec.

pcap_tstamp_type_val_to_description() traduit une valeur de type d'horodatage en une courte description de ce type d'horodatage. NULL est retourné en cas d'échec.

COMPATIBILITÉ ASCENDANTE

Ces fonctions sont devenues disponibles dans la version 1.2.1 de libpcap.

VOIR AUSSI
