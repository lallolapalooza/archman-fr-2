PCP-ROCESTAT(1) Manuel des commandes générales PCP-ROCESTAT(1)

NOM

pcp-rocestat - Rapport des statistiques pour les périphériques RoCE nVidia.

SYNTAXE

pcp [options pcp] rocestat [--hw_stats|--lane_stats]

DESCRIPTION

L'outil pcp-rocestat utilise les compteurs ethtool pour chaque périphérique et rapporte le débit par file d'attente de priorité. Par défaut, pcp-rocestat rapporte des données en direct pour l'hôte local. Il peut également analyser des données provenant d'archives PDP.

OPTIONS

--hw_stats
Affiche les compteurs matériels.
--lane_stats
Affiche les statistiques des voies (lanes).
-a archive, --archive=archive
Spécifie l'archive PCP à examiner.
-s échantillons, --samples=échantillons
Spécifie le nombre d'échantillons à rapporter.
-S heure_début, --start=heure_début
Rapporte les échantillons de l'archive à partir de l'heure donnée.
-T heure_fin, --finish=heure_fin
Rapporte les échantillons de l'archive jusqu'à l'heure donnée.
-V, --version
Affiche le numéro de version et quitte.
-?, --help
Affiche le message d'utilisation et quitte.

ENVIRONNEMENT PCP

Les variables d'environnement préfixées par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

Pour connaître les variables d'environnement affectant les outils PCP, voir pmGetOptions(3).
