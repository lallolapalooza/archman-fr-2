NOM

pcap_setfilter - définir le filtre

SYNOPSIS

#include <pcap/pcap.h>
int pcap_setfilter(pcap_t *p, struct bpf_program *fp);

DESCRIPTION

pcap_setfilter() est utilisé pour spécifier un programme de filtre. fp est un pointeur vers une structure bpf_program, généralement le résultat d'un appel à pcap_compile(3PCAP).

VALEUR DE RETOUR

pcap_setfilter() retourne 0 en cas de succès, PCAP_ERROR_NOT_ACTIVATED si appelé sur un handle de capture qui a été créé mais non activé, ou PCAP_ERROR en cas d'autres erreurs. Si PCAP_ERROR est retourné, pcap_geterr(3PCAP) ou pcap_perror(3PCAP) peuvent être appelés avec p comme argument pour récupérer ou afficher le message d'erreur.
