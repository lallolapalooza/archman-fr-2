PCRE2_JIT_COMPILE(3) Manuel des fonctions de bibliothèque PCRE2_JIT_COMPILE(3)

NOM

PCRE2 - Expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

int pcre2_jit_compile(pcre2_code *code, uint32_t options);

DESCRIPTION

Cette fonction demande la compilation JIT, qui, si le compilateur juste-à-temps est disponible, traite davantage un motif compilé en code machine qui s'exécute beaucoup plus rapidement que la fonction de correspondance interprétée pcre2_match(). Les détails complets sont donnés dans la documentation pcre2jit.

La disponibilité du support JIT peut être testée en appelant pcre2_compile_jit() avec une seule option PCRE2_JIT_TEST_ALLOC (l'argument code est ignoré, donc une valeur NULL est acceptée). Un tel appel retourne zéro si JIT est disponible et dispose d'un allocateur fonctionnel. Sinon, il retourne PCRE2_ERROR_NOMEMORY si JIT est disponible mais ne peut pas allouer de mémoire exécutable, ou PCRE2_ERROR_JIT_UNSUPPORTED si le support JIT n'est pas compilé.

Sinon, le premier argument doit être un pointeur retourné par un appel réussi à pcre2_compile(), et le second doit contenir un ou plusieurs des bits suivants :


PCRE2_JIT_COMPLETE compile le code pour une correspondance complète
PCRE2_JIT_PARTIAL_SOFT compile le code pour une correspondance partielle douce
PCRE2_JIT_PARTIAL_HARD compile le code pour une correspondance partielle stricte

Il existe également une option obsolète appelée PCRE2_JIT_INVALID_UTF, qui a été remplacée par l'option PCRE2_MATCH_INVALID_UTF de pcre2_compile(). L'ancienne option est dépréciée et pourrait être supprimée à l'avenir.

Le résultat de la fonction lorsqu'elle est appelée avec l'une des trois options ci-dessus est 0 en cas de succès, ou un code d'erreur négatif sinon. En particulier, PCRE2_ERROR_JIT_BADOPTION est retourné si JIT n'est pas pris en charge ou si un bit inconnu est défini dans options. La fonction peut également retourner PCRE2_ERROR_NOMEMORY si JIT ne parvient pas à allouer de mémoire exécutable pour le compilateur, même si c'est à cause d'une restriction de sécurité du système. Dans quelques cas, la fonction peut retourner PCRE2_ERROR_JIT_UNSUPPORTED pour des fonctionnalités non prises en charge.

Il existe une description complète de l'API native de PCRE2 dans la page pcre2api et une description de l'API POSIX dans la page pcre2posix.
