NOM

pcap_activate - activer un descripteur de capture

SYNTAXE

#include <pcap/pcap.h>
int pcap_activate(pcap_t *p);

DESCRIPTION

pcap_activate() est utilisée pour activer un descripteur de capture de paquets afin d'analyser les paquets sur le réseau, en tenant compte des options qui ont été définies sur le descripteur.

VALEUR DE RETOUR

pcap_activate() retourne 0 en cas de succès sans avertissements, une valeur positive non nulle en cas de succès avec avertissements, et une valeur négative en cas d'erreur. Une valeur de retour non nulle indique la condition d'avertissement ou d'erreur qui s'est produite.

Les valeurs d'avertissement possibles sont :

PCAP_WARNING_PROMISC_NOTSUP
Le mode promiscuous a été demandé, mais la source de capture ne prend pas en charge ce mode.
PCAP_WARNING_TSTAMP_TYPE_NOTSUP
Le type d'horodatage spécifié dans un appel précédent à pcap_set_tstamp_type(3PCAP) n'est pas pris en charge par la source de capture (le type d'horodatage reste celui par défaut),
PCAP_WARNING
Une autre condition d'avertissement s'est produite ; pcap_geterr(3PCAP) ou pcap_perror(3PCAP) peut être appelée avec p comme argument pour récupérer ou afficher un message décrivant la condition d'avertissement.

Les valeurs d'erreur possibles sont :

PCAP_ERROR_ACTIVATED
Le descripteur a déjà été activé.
PCAP_ERROR_NO_SUCH_DEVICE
La source de capture spécifiée lors de la création du descripteur n'existe pas.
PCAP_ERROR_PERM_DENIED
Le processus n'a pas l'autorisation d'ouvrir la source de capture.
PCAP_ERROR_PROMISC_PERM_DENIED
Le processus a l'autorisation d'ouvrir la source de capture mais n'a pas l'autorisation de la mettre en mode promiscuous.
PCAP_ERROR_RFMON_NOTSUP
Le mode moniteur a été spécifié mais la source de capture ne prend pas en charge ce mode.
PCAP_ERROR_IFACE_NOT_UP
Le périphérique source de capture n'est pas actif.
PCAP_ERROR_CAPTURE_NOTSUP
La capture de paquets n'est pas prise en charge sur la source de capture.
PCAP_ERROR
Une autre erreur s'est produite. pcap_geterr() ou pcap_perror() peut être appelée avec p comme argument pour récupérer ou afficher un message décrivant l'erreur.

Si PCAP_WARNING_PROMISC_NOTSUP, PCAP_ERROR_NO_SUCH_DEVICE, PCAP_ERROR_PERM_DENIED, ou PCAP_ERROR_CAPTURE_NOTSUP est retourné, pcap_geterr() ou pcap_perror() peut être appelé avec p comme argument pour récupérer ou afficher un message fournissant des détails supplémentaires sur le problème, ce qui peut être utile pour le débogage si le problème est inattendu.

Des codes d'avertissement et d'erreur supplémentaires peuvent être ajoutés à l'avenir ; un programme doit vérifier les codes de retour positifs, négatifs et nuls, et traiter tous les codes de retour positifs comme des avertissements et tous les codes de retour négatifs comme des erreurs. pcap_statustostr(3PCAP) peut être appelé, avec un code d'avertissement ou d'erreur comme argument, pour récupérer un message décrivant le code d'avertissement ou d'erreur.

Si pcap_activate() échoue, le pcap_t * n'est pas fermé ni libéré ; il doit être fermé à l'aide de pcap_close(3PCAP).
