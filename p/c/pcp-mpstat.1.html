PCP-MPSTAT(1) Manuel des commandes générales PCP-MPSTAT(1)

NOM

pcp-mpstat - Rapport des statistiques relatives au CPU et aux interruptions.

SYNOPHIS

pcp [options pcp] mpstat [ -A ] [ -u ] [ -V ] [ -I { SOMME | CPU | SCPU | TOUT } ] [ -P { cpu1,cpu2 [,...] | SUR | TOUT } ] [ -t intervalle ] [ -s compte ] [ -a archive ] [ -? ]

DESCRIPTION

La commande pcp-mpstat écrit sur la sortie standard les activités de chaque processeur disponible, le processeur 0 étant le premier. Si aucune activité/option n'a été sélectionnée, le rapport par défaut est le rapport d'utilisation du CPU (-u).

Le paramètre intervalle spécifie la durée en secondes entre chaque rapport. La valeur par défaut est une seconde. La valeur du paramètre compte détermine le nombre d'échantillons à afficher. La valeur par défaut est continue.

OPTIONS

Lorsqu'elle est invoquée via la commande pcp(1), les options -h/--host, -a/--archive, -O/--origin, -s/--samples, -t/--interval, -Z/--timezone et plusieurs autres options pcp deviennent indirectement disponibles; référez-vous à PCPIntro(1) pour une description complète de ces options.

Les options supplémentaires de ligne de commande disponibles pour pcp-mpstat sont:

-A
Cette option est équivalente à spécifier -u -I TOUT -P TOUT
-I { SOMME | CPU | SCPU | TOUT }
Rapporte les statistiques d'interruption.
Avec le mot-clé SOMME, la commande pcp-mpstat rapporte le nombre total d'interruptions par processeur. Les valeurs suivantes sont affichées:

CPU

Numéro du processeur. Le mot-clé tout indique que les statistiques sont calculées comme des moyennes entre tous les processeurs.

intr/s

Affiche le nombre total d'interruptions reçues par seconde par le(s) CPU.

Avec le mot-clé CPU, le nombre de chaque interruption individuelle reçue par seconde par le(s) CPU est affiché. Les interruptions sont celles sous l'arbre métrique kernel.percpu.interrupts.

Avec le mot-clé SCPU, le nombre de chaque interruption logicielle individuelle reçue par seconde par le(s) CPU est affiché. Les interruptions logicielles sont celles sous l'arbre kernel.percpu.softirqs.

Le mot-clé TOUT est équivalent à spécifier tous les mots-clés ci-dessus et donc toutes les statistiques d'interruption sont affichées.

-P { cpu1,cpu2[,...] | SUR | TOUT }
Indique le numéro du processeur pour lequel les statistiques doivent être rapportées. cpu1 et cpu2 sont les numéros de processeur. Une liste de numéros de processeur requis peut être fournie. Notez que le processeur 0 est le premier processeur.

Le mot-clé SUR indique que les statistiques doivent être rapportées pour chaque processeur en ligne, tandis que le mot-clé TOUT indique que les statistiques doivent être rapportées pour tous les processeurs.

-u
Rapporte l'utilisation du CPU. Les valeurs suivantes sont affichées:

CPU

Numéro du processeur. Le mot-clé TOUT indique que les statistiques sont calculées comme des moyennes entre tous les processeurs.

%usr

Affiche le pourcentage d'utilisation du CPU qui s'est produit pendant l'exécution au niveau utilisateur (application).

%nice

Affiche le pourcentage d'utilisation du CPU qui s'est produit pendant l'exécution au niveau utilisateur avec une priorité nice.

%sys

Affiche le pourcentage d'utilisation du CPU qui s'est produit pendant l'exécution au niveau système (noyau). Notez que cela n'inclut pas le temps passé à gérer les interruptions matérielles et logicielles.

%iowait

Affiche le pourcentage de temps pendant lequel le(s) CPU étaient inactifs alors que le système avait une demande d'E/S disque en attente.

%irq

Affiche le pourcentage de temps passé par le(s) CPU pour gérer les interruptions matérielles.

%soft

Affiche le pourcentage de temps passé par le(s) CPU pour gérer les interruptions logicielles.

%steal

Affiche le pourcentage de temps passé en attente involontaire par le(s) CPU virtuel(s) pendant que l'hyperviseur gérait un autre processeur virtuel.

%guest

Affiche le pourcentage de temps passé par le(s) CPU pour exécuter un processeur virtuel.

%gnice

Affiche le pourcentage de temps passé par le(s) CPU pour exécuter un invité niced.

%idle

Affiche le pourcentage de temps pendant lequel le(s) CPU étaient inactifs et le système n'avait pas de demande d'E/S disque en attente.

Note: Sur les machines SMP, un processeur qui n'a aucune activité est un processeur désactivé (hors ligne).

-s N , --samples = N
Définit le nombre d'échantillons à afficher. Comme le premier échantillon est utilisé pour la conversion du taux de certaines métriques, le nombre total d'échantillons rapportés est inférieur de un à N. Par défaut, c'est continu.
-t DELTA , --interval = DELTA
Définit l'intervalle entre deux échantillons. La valeur par défaut est une seconde.
-a FICHIER , --archive = FICHIER
Demande à pcp-mpstat d'utiliser l'archive spécifiée plutôt que de se connecter à PMCD. L'argument de -a est une liste de noms séparés par des virgules, chacun pouvant être le nom de base d'une archive ou le nom d'un répertoire contenant une ou plusieurs archives.
-V , --version
Affiche le numéro de version puis quitte.
-? , --help
Affiche le message d'utilisation puis quitte.

EXEMPLES

pcp-mpstat -t 2 -s 5

Affiche quatre rapports de statistiques globales parmi tous les processeurs à intervalles de deux secondes.

pcp mpstat -P TOUT -t 2 -s 5

Affiche quatre rapports de statistiques pour tous les processeurs à intervalles de deux secondes.

NOTES

pcp-mpstat est inspiré de la commande mpstat(1) et vise à être compatible avec elle en termes de ligne de commande et de sortie.

ENVIRONNEMENT

Les variables d'environnement TZ et LC_TIME peuvent être utilisées pour remplacer le format d'affichage de la date par défaut pour pcp-mpstat.

ENVIRONNEMENT PCP

Les variables d'environnement commençant par le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

Pour les variables d'environnement affectant les outils PCP, voir pmGetOptions(3).
