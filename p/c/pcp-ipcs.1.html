PCP-IPCS(1) Manuel des commandes générales PCP-IPCS(1)

NOM

pcp-ipcs - fournit des informations sur les facilités IPC

SYNTAXE

pcp [options pcp] ipcs [-luV?] [format-de-sortie]

DESCRIPTION

pcp-ipcs fournit des informations sur les facilités de communication inter-processus pour lesquelles le processus appelant a un droit de lecture.

OPTIONS

Lorsqu'il est invoqué via la commande pcp(1), les options -h/--host, -a/--archive, -O/--origin, -Z/--timezone et plusieurs autres options pcp deviennent indirectement disponibles ; référez-vous à PCPIntro(1) pour une description complète de ces options.

Les options de ligne de commande supplémentaires disponibles pour pcp-ipcs sont :

-V, --version
Affiche les informations de version et quitte.
-?, --help
Affiche le message d'utilisation et quitte.

Formats de sortie

-l, --limits
Affiche les limites de ressources.
-u, --summary
Affiche un résumé de l'état.

ENVIRONNEMENT PCP

Les variables d'environnement commençant par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

Pour les variables d'environnement affectant les outils PCP, voir pmGetOptions(3).
