NOM

pcap_set_protocol_linux - définir le protocole de capture pour une poignée de capture non encore activée

SYNTAXE

#include <pcap/pcap.h>
int pcap_set_protocol_linux(pcap_t *p, int protocol);

DESCRIPTION

Sur les périphériques d'interface réseau sous Linux, pcap_set_protocol_linux() définit le protocole à utiliser dans l'appel socket(2) pour créer un socket de capture lorsque la poignée est activée. L'argument est une valeur de protocole de niveau liaison, telle que les valeurs dans le fichier d'en-tête <linux/if_ether.h>, spécifiée en ordre d'octets hôte. Si protocol est non nul, les paquets de ce protocole seront capturés lorsque la poignée est activée, sinon, tous les paquets seront capturés. Cette fonction n'est fournie que sous Linux, et si elle est utilisée sur un périphérique autre qu'une interface réseau, elle n'aura aucun effet.

Elle ne doit pas être utilisée dans du code portable ; à la place, un filtre doit être spécifié avec pcap_setfilter(3PCAP).

Si une interface réseau donnée fournit un en-tête de niveau liaison standard, avec un type de paquet standard, mais fournit certains types de paquets avec un type de protocole de niveau socket différent de celui de l'en-tête de niveau liaison, ce type de paquet ne peut pas être filtré avec un filtre spécifié avec pcap_setfilter() mais peut être filtré en spécifiant le type de protocole de niveau socket à l'aide de pcap_set_protocol_linux().

VALEUR DE RETOUR

pcap_set_protocol_linux() renvoie 0 en cas de succès ou PCAP_ERROR_ACTIVATED si appelée sur une poignée de capture qui a été activée.

COMPATIBILITÉ ASCENDANTE

Cette fonction est devenue disponible dans la version 1.9.0 de libpcap.

VOIR AUSSI

pcap(3PCAP), pcap_create(3PCAP), pcap_activate(3PCAP)
