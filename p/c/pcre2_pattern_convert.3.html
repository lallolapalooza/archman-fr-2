pcre2_pattern_convert(3)

Paquet: pcre2

Licences: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_PATTERN_CONVERT(3) Manuel de fonctions de bibliothèque PCRE2_PATTERN_CONVERT(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

int pcre2_pattern_convert(PCRE2_SPTR pattern, PCRE2_SIZE length,
  uint32_t options, PCRE2_UCHAR **buffer,
  PCRE2_SIZE *blength, pcre2_convert_context *cvcontext);

DESCRIPTION

Cette fonction fait partie d'un ensemble expérimental de fonctions de conversion de motifs. Elle convertit un motif étranger (par exemple, un glob) en un motif d'expression régulière PCRE2. Ses arguments sont :


pattern Le motif étranger
length La longueur du motif d'entrée ou PCRE2_ZERO_TERMINATED
options Bits d'options
buffer Pointeur vers un pointeur vers le tampon de sortie, ou NULL
blength Pointeur vers le champ de longueur de sortie
cvcontext Pointeur vers un contexte de conversion ou NULL

La longueur du motif converti (hors le zéro terminateur) est renvoyée via blength. Si buffer est NULL, la fonction renvoie simplement la longueur de sortie. Si buffer pointe vers un pointeur NULL, une mémoire du tas est obtenue pour le motif converti, en utilisant l'allocateur du contexte s'il est présent (sinon malloc()), et le champ pointé par buffer est mis à jour. Si buffer pointe vers un champ non-NULL, celui-ci doit pointer vers un tampon dont la taille est dans la variable pointée par blength. Cette valeur est mise à jour.

Les bits d'options sont :


PCRE2_CONVERT_UTF L'entrée est en UTF
PCRE2_CONVERT_NO_UTF_CHECK Ne pas vérifier la validité UTF
PCRE2_CONVERT_POSIX_BASIC Convertir un motif POSIX de base
PCRE2_CONVERT_POSIX_EXTENDED Convertir un motif POSIX étendu
PCRE2_CONVERT_GLOB ) Convertir
PCRE2_CONVERT_GLOB_NO_WILD_SEPARATOR ) divers types
PCRE2_CONVERT_GLOB_NO_STARSTAR ) de glob

La valeur de retour de pcre2_pattern_convert() est zéro en cas de succès ou un code d'erreur PCRE2 non nul.

Les fonctions de conversion de motifs sont décrites dans la documentation pcre2convert.
