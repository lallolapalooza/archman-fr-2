NOM

pcp-htop - fichier de configuration pcp-htop

DESCRIPTION

pcp-htop est un outil personnalisable de rapport sur les métriques de performance. Il a une architecture dynamique, où un ensemble de fichiers de configuration fournissent des compteurs et des colonnes supplémentaires, optionnels, pour étendre l'ensemble fixe d'options d'affichage fournies par le htop régulier.

Ces fichiers de configuration peuvent être fournis à partir d'emplacements système (d'abord /etc/pcp/htop puis /usr/share/pcp/htop) et à partir du répertoire personnel de l'utilisateur (généralement ~/.config/htop). Dans ces emplacements, les compteurs et les colonnes sont analysés pour les spécifications dynamiques de Compteurs et Colonnes.

Les compteurs sont affichés dans la partie supérieure de la fenêtre pcp-htop, et les colonnes dans la partie inférieure. Les compteurs tendent à afficher des métriques globales du système, et les colonnes affichent des métriques sur les processus individuels.

Les formats sont similaires mais ont des exigences légèrement différentes. Les deux formats suivent le style ini commun. Les lignes vides sont ignorées. Les lignes commençant par le caractère "#" sont traitées comme des commentaires.

COMPTEURS

Voici un exemple de configuration pour un nouveau compteur Redis :

[redisclient]
caption = Clients Redis
type = bar
blocked.metric = redis.blocked_clients
blocked.color = blue
blocked.label = blk
clients.metric = redis.connected_clients
clients.color = green
clients.label = conn

Un fichier de configuration peut contenir plusieurs définitions de compteur. Chaque définition commence par un nom d'identification entre crochets - redisclient dans cet exemple. Le nom est utilisé en interne dans pcp-htop et doit être unique, doit commencer par un caractère alphabétique, et ne peut contenir ensuite que des caractères alphanumériques ou le caractère de soulignement. Aucun espace blanc ou autre caractère n'est autorisé.

Il existe plusieurs paramètres qui définissent la façon dont le compteur sera affiché à l'utilisateur.

caption
Cette valeur est affichée dans l'écran de configuration une fois que le compteur a été sélectionné. Une version tronquée de la caption sera également affichée (suivie de deux points) sur l'affichage principal pendant que le compteur se met à jour.
description
Ceci peut être utilisé pour fournir plus de détails pendant le processus de sélection du compteur sur l'écran de configuration, et s'il est présent, il est affiché dans la colonne "Compteurs disponibles". S'il n'est pas présent, la caption sera utilisée pour cela. Si aucun des deux n'est présent, le nom interne (obligatoire) sera utilisé.
type
Ce paramètre permet de spécifier un type de compteur par défaut préféré. La valeur associée doit être l'une des suivantes : bar, text, graph ou led. Si aucune valeur n'est fournie pour un compteur dynamique, la valeur par défaut text sera utilisée.
maximum
Une valeur numérique peut également être définie pour dimensionner le compteur, de sorte que les valeurs (par exemple, pour un affichage de type bar) soient mises à l'échelle dans la plage zéro à maximum.

La syntaxe de définition restante décrit les métriques individuelles qui seront utilisées pour animer le compteur. Une ou plusieurs métriques doivent être spécifiées pour chaque compteur et plusieurs propriétés y sont associées. Encore une fois, ces métriques doivent être nommées (les mêmes règles décrites ci-dessus pour les compteurs s'appliquent ici) et les propriétés suivantes peuvent être configurées :

name.metric
C'est le seul champ obligatoire et il associe une métrique PCP au compteur. Les valeurs échantillonnées pour chaque métrique à l'exécution fournissent l'animation visible dans l'affichage pcp-htop. La spécification de la métrique peut être soit un nom de métrique PCP tel que listé par pminfo(1), soit une expression de métrique "dérivée". Le format des expressions de métriques dérivées est décrit dans la page de manuel pmRegisterDerived(3).
name.color
Définit la couleur à utiliser lors du rendu des valeurs de métriques. Les valeurs possibles sont red, green, blue, cyan, magenta, yellow, gray, darkgray ou white.
name.label
Une étiquette courte et optionnelle à afficher avant la valeur de la métrique. Le caractère ":" sera ajouté à l'label avant la partie valeur de la métrique de l'affichage.
name.suffix
Un suffixe court et optionnel à afficher après la valeur de la métrique. Couramment utilisé pour indiquer des valeurs en pourcentage en utilisant une valeur de suffix "%" et pour fournir l'unité de mesure de base. Notez que comme PCP maintient les unités pour les métriques, pour les métriques qui ont une dimension d'"espace" (octets, kilo-octets, méga-octets, etc.), un suffixe sera automatiquement ajouté.

COLONNES

Voici un exemple de configuration pour une nouvelle colonne affichant les descripteurs de fichiers ouverts pour chaque processus :

[openfds]
heading = FDS
caption = FDCOUNT
description = Nombre de descripteurs de fichiers ouverts
metric = proc.fd.count
width = 3

Un fichier de configuration peut contenir plusieurs définitions de colonne. Chaque définition commence par un nom d'identification entre crochets - openfds dans cet exemple, et les mêmes règles s'appliquent que celles décrites ci-dessus pour les noms de compteurs.

Chaque colonne doit spécifier une métrique. Des paramètres optionnels peuvent également être définis.

metric
Comme pour les compteurs, la valeur de la métrique doit être soit un nom de métrique PCP tel que listé par pminfo(1), soit une métrique dérivée. La métrique doit avoir un domaine d'instance (ensemble de valeurs) et ce domaine d'instance doit se mapper à l'ensemble des processus, l'identifiant d'instance étant les PID (identifiants de processus). Typiquement, il s'agira de métriques de l'espace de noms proc ou hotproc (pmdaproc(1)), mais les métriques d'autres domaines (pmdabpf(1), etc.) ayant des valeurs par processus sont tout aussi applicables.
width
Largeur de colonne à utiliser lors de l'affichage des valeurs pour la métrique. Une valeur négative peut être utilisée pour spécifier l'alignement à gauche. Une limite supérieure de colonne de 28 caractères est appliquée. La largeur de colonne par défaut est de 5 caractères.
heading
Le titre court qui sera affiché en tête de colonne - généralement une chaîne courte, cryptique, tout en majuscules.
caption
Un court mot d'identification présenté aux utilisateurs dans l'écran de configuration, sous les listes Colonnes disponibles et Colonnes actives.
description
Texte qui aide les utilisateurs à comprendre la signification de cette colonne lorsqu'elle est présentée via l'écran de configuration dans la liste Colonnes disponibles.
