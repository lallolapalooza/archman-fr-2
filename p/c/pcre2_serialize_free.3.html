pcre2_serialize_free(3)

Paquet: pcre2

Licences: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SERIALIZE_FREE(3) Manuel des fonctions de bibliothèque PCRE2_SERIALIZE_FREE(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

void pcre2_serialize_free(uint8_t *bytes);

DESCRIPTION

Cette fonction libère la mémoire qui a été obtenue par pcre2_serialize_encode() pour contenir un flux d'octets sérialisé. L'argument doit pointer vers un tel flux d'octets ou être NULL, auquel cas la fonction retourne sans rien faire.

Il existe une description complète de l'API native de PCRE2 dans la page pcre2api et une description des fonctions de sérialisation dans la page pcre2serialize.
