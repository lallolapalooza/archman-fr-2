pcre2_jit_stack_create(3)

Paquet: pcre2

Licences: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_JIT_STACK_CREATE(3) Manuel des fonctions de bibliothèque PCRE2_JIT_STACK_CREATE(3)

NOM

PCRE2 - Expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

pcre2_jit_stack *pcre2_jit_stack_create(size_t startsize,
  size_t maxsize, pcre2_general_context *gcontext);

DESCRIPTION

Cette fonction est utilisée pour créer une pile à utiliser par le code compilé par le compilateur JIT. Les deux premiers arguments sont une taille de départ pour la pile, et une taille maximale à laquelle elle est autorisée à croître. Le dernier argument est un contexte général, pour les fonctions d'allocation mémoire, ou NULL pour une allocation mémoire standard. Le résultat peut être passé au code d'exécution JIT en appelant pcre2_jit_stack_assign() pour associer la pile à un motif compilé, qui peut ensuite être traité par pcre2_match() ou pcre2_jit_match(). Une taille de pile maximale de 512 Ko à 1 Mo devrait être plus que suffisante pour n'importe quel motif. Si la pile n'a pas pu être allouée ou si les valeurs passées n'étaient pas raisonnables, NULL sera retourné. Pour plus de détails, consultez la page pcre2jit.

Il existe une description complète de l'API native de PCRE2 dans la page pcre2api et une description de l'API POSIX dans la page pcre2posix.
