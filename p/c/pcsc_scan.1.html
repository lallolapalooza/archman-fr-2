NOM

pcsc_scan - scanne régulièrement tous les lecteurs PC/SC connectés à l'hôte

SYNTAXE

pcsc_scan [options]

DESCRIPTION

Cette page de manuel documente la commande pcsc_scan.

pcsc_scan est un programme qui scanne régulièrement tous les lecteurs PC/SC connectés à l'hôte et affiche l'état des cartes insérées dans les lecteurs.

La façon normale de quitter le programme est d'utiliser Control-C.

Lorsque pcsc_scan est démarré, il demande à la **couche PC/SC** la liste des lecteurs de cartes à puce disponibles. La liste est imprimée. Un numéro de séquence est imprimé avant chaque lecteur.

Exemple :
Scanner de périphériques PC/SC
V 1.6.2 (c) 2001-2022, Ludovic Rousseau <ludovic.rousseau@free.fr>
Scan des lecteurs présents...
0 : Gemalto PC Twin Reader

Lorsqu'une carte est insérée dans un lecteur, des informations sont affichées :

date et heure :
Lun Oct 2 21:01:40 2023
nom du lecteur :
Lecteur 0 : Gemalto PC Twin Reader
état de la carte et événement survenu :
État de la carte : Carte insérée,
ATR en cas d'insertion de carte :
ATR : 3B 82 00 86 1E
imprimer une analyse ATR si la commande ATR_analysis est disponible :

ATR : 3B 82 00 86 1E
+ TS = 3B --> Convention directe
+ T0 = 82, Y(1): 1000, K: 2 (octets historiques)
TD(1) = 00 --> Y(i+1) = 0000, Protocole T = 0
-----
+ Octets historiques : 86 1E

OPTIONS

-h
afficher l'aide
-V
afficher le numéro de version
-n
ne pas imprimer l'analyse ATR. Utiliser cette option si ATR_analysis n'est pas disponible, par exemple.
-r
imprime la liste des lecteurs puis quitte.
-c
imprime la liste des cartes puis quitte.
-s
mode stress. Envoie des commandes APDU à la carte indéfiniment (jusqu'à ce que la carte ou le lecteur soit retiré).
-t secs
spécifie le temps pendant lequel le programme doit s'exécuter, en secondes. Le programme se terminera lorsque ce temps sera écoulé.
-q
silencieux : affiche un minimum de messages.
-v
verbeux : affiche des messages supplémentaires (par défaut).
-d
débogage : affiche ce qui a changé entre les champs .dwCurrentState et .dwEventState pour chaque lecteur.
-p
Plug and Play : force l'utilisation du lecteur spécifique "\\?PnP?\Notification".

VOIR AUSSI

pcscd(8), ATR_analysis(1)
