pcre2_serialize_encode(3)

Paquet: pcre2

Licences: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SERIALIZE_ENCODE(3) Manuel des fonctions de bibliothèque PCRE2_SERIALIZE_ENCODE(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNOPSIS

#include <pcre2.h>

int32_t pcre2_serialize_encode(const pcre2_code **codes,
  int32_t number_of_codes, uint8_t **serialized_bytes,
  PCRE2_SIZE *serialized_size, pcre2_general_context *gcontext);

DESCRIPTION

Cette fonction encode une liste de motifs compilés en un flux d'octets qui peut être sauvegardé sur disque ou ailleurs. Notez qu'il ne s'agit pas d'un format abstrait comme Java ou .NET. La conversion du flux d'octets en motifs compilés utilisables ne peut se produire que sur un hôte exécutant la même version de PCRE2, avec la même largeur d'unité de code, et l'hôte doit également avoir la même endianness, largeur de pointeur et type PCRE2_SIZE. Les arguments de pcre2_serialize_encode() sont :


codes pointeur vers un vecteur contenant la liste
number_of_codes nombre d'emplacements dans le vecteur
serialized_bytes défini pour pointer vers le flux d'octets sérialisé
serialized_size défini pour le nombre d'octets dans le flux d'octets
gcontext pointeur vers un contexte général ou NULL

L'argument de contexte est utilisé pour obtenir de la mémoire pour le flux d'octets. Lorsque les données sérialisées ne sont plus nécessaires, elles doivent être libérées en appelant pcre2_serialize_free(). Le rendement de la fonction est le nombre de motifs sérialisés, ou l'un des codes d'erreur négatifs suivants :


PCRE2_ERROR_BADDATA number_of_codes est zéro ou moins
PCRE2_ERROR_BADMAGIC discordance des octets d'identification dans l'un des motifs
PCRE2_ERROR_MEMORY échec d'allocation de mémoire
PCRE2_ERROR_MIXEDTABLES les motifs n'utilisent pas tous les mêmes tables
PCRE2_ERROR_NULL un argument autre que gcontext est NULL

PCRE2_ERROR_BADMAGIC signifie soit que le code d'un motif a été corrompu, soit qu'un emplacement dans le vecteur ne pointe pas vers un motif compilé.

Il existe une description complète de l'API native de PCRE2 dans la page pcre2api et une description des fonctions de sérialisation dans la page pcre2serialize.
