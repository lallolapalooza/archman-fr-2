NOM

pcp-numastat - rapport sur l'allocation mémoire NUMA

SYNTAXE

pcp [options pcp] numastat [-mnV?] [-w largeur]

DESCRIPTION

pcp-numastat affiche les statistiques d'allocation NUMA du gestionnaire de mémoire du noyau. Chaque processus possède des politiques NUMA qui spécifient sur quel nœud les pages sont allouées. Les compteurs de performance du noyau suivent sur quels nœuds la mémoire est allouée et ces valeurs sont échantillonnées et rapportées par pcp-numastat.

Des compteurs sont maintenus individuellement pour chaque nœud NUMA. Les détails de la sémantique de chaque métrique rapportée peuvent être récupérés en utilisant la commande suivante :

# pminfo ‐dt mem.numa.alloc

OPTIONS

Lorsqu'elle est invoquée via la commande pcp(1), les options pcp -h/--host, -a/--archive, -O/--origin, -Z/--timezone et plusieurs autres deviennent indirectement disponibles ; référez-vous à PCPIntro(1) pour une description complète de ces options.

Les options de ligne de commande supplémentaires disponibles pour pcp-numastat sont :

-m, --meminfo
Affiche l'utilisation mémoire globale de type meminfo.
-n, --numastat
Affiche les informations de statistiques numastat.
-V, --version
Affiche la version actuelle de la commande.
-w largeur, --width=largeur
Limite l'affichage à largeur.
-?, --help
Affiche le message d'utilisation et quitte.

NOTES

pcp-numastat est inspiré de la commande numastat(1) et produit exactement la même sortie.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

Pour les variables d'environnement affectant les outils PCP, voir pmGetOptions(3).

VOIR AUSSI

PCPIntro(1), pcp(1) et numastat(1).
