PCAP_LIST_TSTAMP_TYPES(3PCAP) PCAP_LIST_TSTAMP_TYPES(3PCAP)

NOM

pcap_list_tstamp_types, pcap_free_tstamp_types - obtenir une liste des types d'horodatage pris en charge par un périphérique de capture, et libérer cette liste

SYNTAXE

#include <pcap/pcap.h>
int pcap_list_tstamp_types(pcap_t *p, int **tstamp_typesp);
void pcap_free_tstamp_types(int *tstamp_types);

DESCRIPTION

pcap_list_tstamp_types() est utilisé pour obtenir la liste des types d'horodatage pris en charge par l'interface associée au descripteur pcap. pcap_list_tstamp_types() alloue un tableau pour contenir la liste et définit *tstamp_typesp pour pointer vers ce tableau. Voir pcap-tstamp(7) pour une liste de tous les types d'horodatage.

L'appelant est responsable de la libération du tableau avec pcap_free_tstamp_types(), qui libère la liste pointée par tstamp_types.

VALEUR DE RETOUR

pcap_list_tstamp_types() renvoie le nombre de types d'horodatage dans le tableau en cas de succès et PCAP_ERROR en cas d'échec. Une valeur de retour de un signifie que le seul type d'horodatage pris en charge est celui de la liste, qui est le type d'horodatage par défaut du périphérique de capture. Une valeur de retour de zéro signifie que le seul type d'horodatage pris en charge est PCAP_TSTAMP_HOST, qui est le type d'horodatage par défaut du périphérique de capture (seules les anciennes versions de libpcap renverront cela ; les versions plus récentes renverront toujours un ou plusieurs types). Si PCAP_ERROR est renvoyé, pcap_geterr(3PCAP) ou pcap_perror(3PCAP) peut être appelé avec p comme argument pour récupérer ou afficher le texte d'erreur.

COMPATIBILITÉ ASCENDANTE

Ces fonctions sont disponibles depuis la version 1.2.1 de libpcap. Dans les versions précédentes, le type d'horodatage ne peut pas être défini ; seul le type d'horodatage par défaut offert par une source de capture est disponible.
