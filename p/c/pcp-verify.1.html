PCP-VERIFY(1) Manuel des commandes générales PCP-VERIFY(1)

NOM

pcp-verify - vérifier certains aspects d'une installation PCP

SYNTAXE

pcp verify [-a archive] [-D debug] [-h hôte] [-csvV?]

DESCRIPTION

pcp-verify inspecte divers aspects d'une installation de collecteur PCP et indique s'il est correctement configuré pour certains modes de fonctionnement.

Par défaut, pcp-verify vérifie que PMCD est en cours d'exécution et qu'aucun agent n'est en état d'échec. Ces vérifications peuvent être étendues et affinées à l'aide des options de ligne de commande.

OPTIONS

Les options de ligne de commande disponibles sont :

-a archive, --archive=archive
Utiliser l'archive pour la vérification.
-c, --containers
Vérifier l'installation du collecteur pour la surveillance des conteneurs.
-h hôte, --host=hôte
Se connecter à PMCD sur hôte pour la vérification.
-s, --secure
Vérifier que les composants requis pour la communication cryptée sont en place.
-v, --verbose
Augmenter la verbosité et rendre compte de chaque vérification effectuée. En l'absence de problèmes, pcp-verify fonctionne silencieusement.
-V, --version
Afficher le numéro de version et quitter.
-?, --help
Afficher le message d'utilisation et quitter.

DIAGNOSTICS

pcp-verify se terminera avec un statut non nul s'il trouve quelque chose à signaler, sinon il sera silencieux et retournera zéro.

ENVIRONNEMENT PCP

Les variables d'environnement préfixées par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

Pour les variables d'environnement affectant les outils PCP, voir pmGetOptions(3).

OPTIONS DE DEBOGAGE

L'option -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à trier les problèmes, bien que les informations soient parfois cryptiques et destinées principalement à guider les développeurs plutôt que les utilisateurs finaux. debug est une liste d'options de débogage séparées par des virgules ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

VOIR AUSSI

PCPIntro(1) et pcp(1).
