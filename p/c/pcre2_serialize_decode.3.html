pcre2_serialize_decode(3)

Paquet: pcre2

Licences: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SERIALIZE_DECODE(3) Manuel des fonctions de bibliothèque PCRE2_SERIALIZE_DECODE(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

int32_t pcre2_serialize_decode(pcre2_code **codes,
  int32_t number_of_codes, const uint8_t *bytes,
  pcre2_general_context *gcontext);

DESCRIPTION

Cette fonction décode un ensemble sérialisé de motifs compilés pour les remettre dans une liste de motifs individuels. Ceci n'est possible que sur un hôte qui exécute la même version de PCRE2, avec la même largeur d'unité de code, et l'hôte doit également avoir la même endianness, largeur de pointeur et type PCRE2_SIZE. Les arguments de pcre2_serialize_decode() sont :


codes pointeur vers un vecteur dans lequel construire la liste
number_of_codes nombre d'emplacements dans le vecteur
bytes le flux d'octets sérialisé
gcontext pointeur vers un contexte général ou NULL

L'argument bytes doit pointer vers un bloc de données qui a été initialement créé par pcre2_serialize_encode(), bien qu'il puisse avoir été enregistré sur disque ou ailleurs entre-temps. S'il y a plus de codes dans les données sérialisées que d'emplacements dans la liste, seuls les motifs compilés qui rentrent sont décodés. Le résultat de la fonction est le nombre de motifs décodés, ou l'un des codes d'erreur négatifs suivants :


PCRE2_ERROR_BADDATA number_of_codes est zéro ou moins
PCRE2_ERROR_BADMAGIC non-concordance des octets d'identification dans bytes
PCRE2_ERROR_BADMODE non-concordance de la taille d'unité variable ou de la version PCRE
PCRE2_ERROR_NOMEMORY échec d'allocation mémoire
PCRE2_ERROR_NULL codes ou bytes est NULL

PCRE2_ERROR_BADMAGIC peut signifier que les données sont corrompues, ou qu'elles ont été compilées sur un système avec une endianness différente.

Il y a une description complète de l'API native PCRE2 dans la page pcre2api et une description des fonctions de sérialisation dans la page pcre2serialize.
