pcre2_jit_stack_assign(3)

PCRE2_JIT_STACK_ASSIGN(3) Manuel des fonctions de bibliothèque PCRE2_JIT_STACK_ASSIGN(3)

NOM

PCRE2 - Expressions régulières compatibles Perl (API révisée)

SYNOPSIS

#include <pcre2.h>

void pcre2_jit_stack_assign(pcre2_match_context *mcontext,
  pcre2_jit_callback callback_function, void *callback_data);

DESCRIPTION

Cette fonction contrôle la mémoire utilisée par le JIT comme une pile d'exécution lorsque pcre2_match() ou pcre2_jit_match() est appelée avec un motif qui a été traité avec succès par le compilateur JIT. Les informations qui déterminent quelle pile est utilisée sont placées dans un contexte de correspondance qui est ensuite passé à une fonction de correspondance. Les arguments de cette fonction sont :


mcontext un pointeur vers un contexte de correspondance
callback une fonction de rappel
callback_data une pile JIT ou une valeur à passer à la fonction de rappel

Si mcontext est NULL, la fonction retourne immédiatement, sans rien faire.

Si callback est NULL et callback_data est NULL, un bloc interne de 32 Ko sur la pile de la machine est utilisé.

Si callback est NULL et callback_data n'est pas NULL, callback_data doit être une pile JIT valide, le résultat de l'appel de pcre2_jit_stack_create().

Si callback n'est pas NULL, il est appelé avec callback_data comme argument au début de la correspondance, afin de configurer une pile JIT. Si le résultat est NULL, la pile interne de 32 Ko est utilisée ; sinon, la valeur de retour doit être une pile JIT valide, le résultat de l'appel de pcre2_jit_stack_create().

Vous pouvez utiliser en toute sécurité la même pile JIT pour plusieurs motifs, tant qu'ils sont tous mis en correspondance dans le même thread. Dans une application multithread, chaque thread doit utiliser sa propre pile JIT. Pour plus de détails, voir la page pcre2jit.

Il existe une description complète de l'API native de PCRE2 dans la page pcre2api et une description de l'API POSIX dans la page pcre2posix.
