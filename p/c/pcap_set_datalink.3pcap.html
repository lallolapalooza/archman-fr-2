NOM

pcap_set_datalink - définir le type d'en-tête de la couche liaison à utiliser par un périphérique de capture

SYNTAXE

#include <pcap/pcap.h>
int pcap_set_datalink(pcap_t *p, int dlt);

DESCRIPTION

pcap_set_datalink() est utilisé pour définir le type d'en-tête de la couche liaison actuel du descripteur pcap au type spécifié par dlt.

VALEUR DE RETOUR

pcap_set_datalink() retourne 0 en cas de succès, PCAP_ERROR_NOT_ACTIVATED si appelé sur un descripteur de capture qui a été créé mais pas activé, ou PCAP_ERROR en cas d'autres erreurs. Si PCAP_ERROR est retourné, pcap_geterr(3PCAP) ou pcap_perror(3PCAP) peuvent être appelés avec p comme argument pour récupérer ou afficher le texte d'erreur.

VOIR AUSSI

pcap(3PCAP), pcap_datalink_name_to_val(3PCAP)
