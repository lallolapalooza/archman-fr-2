PCAP_SETNONBLOCK(3PCAP) PCAP_SETNONBLOCK(3PCAP)

NOM

pcap_setnonblock, pcap_getnonblock - définir ou obtenir l'état du mode non bloquant sur un périphérique de capture

SYNTAXE

#include <pcap/pcap.h>
char errbuf[PCAP_ERRBUF_SIZE];
int pcap_setnonblock(pcap_t *p, int nonblock, char *errbuf);
int pcap_getnonblock(pcap_t *p, char *errbuf);

DESCRIPTION

pcap_setnonblock() met un descripteur de capture en mode ``non bloquant'', ou le retire du mode ``non bloquant'', selon que l'argument nonblock est différent de zéro ou est zéro. Il n'a aucun effet sur les ``fichiers de sauvegarde''. errbuf est un tampon suffisamment grand pour contenir au moins PCAP_ERRBUF_SIZE caractères.

En mode ``non bloquant'', une tentative de lecture depuis le descripteur de capture avec pcap_dispatch(3PCAP) et pcap_next_ex(3PCAP) retournera 0 immédiatement si aucun paquet n'est actuellement disponible pour être lu, plutôt que de bloquer en attendant que des paquets arrivent.

pcap_loop(3PCAP) bouclera indéfiniment, consommant du temps CPU lorsqu'aucun paquet n'est actuellement disponible ; pcap_dispatch() devrait être utilisé à la place. pcap_next(3PCAP) retournera NULL s'il n'y a actuellement aucun paquet disponible à lire ; ceci est indiscernable d'une erreur, donc pcap_next_ex() devrait être utilisé à la place.

Lorsqu'il est activé pour la première fois avec pcap_activate(3PCAP) ou ouvert avec pcap_open_live(3PCAP), un descripteur de capture n'est pas en mode ``non bloquant'' ; un appel à pcap_setnonblock() est requis pour le mettre en mode ``non bloquant''.

VALEUR DE RETOUR

pcap_setnonblock() retourne 0 en cas de succès, PCAP_ERROR_NOT_ACTIVATED si appelé sur un descripteur de capture qui a été créé mais non activé, et PCAP_ERROR pour d'autres erreurs. pcap_getnonblock() retourne l'état ``non bloquant'' actuel du descripteur de capture en cas de succès ; il retourne toujours 0 sur les ``fichiers de sauvegarde''. Il retourne PCAP_ERROR_NOT_ACTIVATED s'il est appelé sur un descripteur de capture qui a été créé mais non activé, et PCAP_ERROR pour d'autres erreurs. Si PCAP_ERROR est retourné, errbuf est rempli avec un message d'erreur approprié.

VOIR AUSSI

pcap(3PCAP), pcap_next_ex(3PCAP), pcap_geterr(3PCAP)
