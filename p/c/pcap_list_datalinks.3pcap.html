PCAP_LIST_DATALINKS(3PCAP) PCAP_LIST_DATALINKS(3PCAP)

NOM

pcap_list_datalinks, pcap_free_datalinks - obtenir une liste des types d'en-tête de couche liaison pris en charge par un périphérique de capture, et libérer cette liste

SYNTAXE

#include <pcap/pcap.h>
int pcap_list_datalinks(pcap_t *p, int **dlt_buf);
void pcap_free_datalinks(int *dlt_list);

DESCRIPTION

pcap_list_datalinks() est utilisée pour obtenir une liste des types d'en-tête de couche liaison pris en charge par l'interface associée au descripteur pcap. pcap_list_datalinks() alloue un tableau pour contenir la liste et définit *dlt_buf pour pointer vers ce tableau.

L'appelant est responsable de la libération du tableau avec pcap_free_datalinks(), qui libère la liste des types d'en-tête de couche liaison pointée par dlt_list.

Elle ne doit pas être appelée sur un descripteur pcap créé par pcap_create(3PCAP) qui n'a pas encore été activé par pcap_activate(3PCAP).

VALEUR DE RETOUR

pcap_list_datalinks() renvoie le nombre de types d'en-tête de couche liaison dans le tableau en cas de succès, PCAP_ERROR_NOT_ACTIVATED si elle est appelée sur un handle de capture qui a été créé mais pas activé, et PCAP_ERROR en cas d'autres erreurs. Si PCAP_ERROR est renvoyé, pcap_geterr(3PCAP) ou pcap_perror(3PCAP) peut être appelé avec p comme argument pour récupérer ou afficher le message d'erreur.

VOIR AUSSI

pcap(3PCAP), pcap_datalink_val_to_name(3PCAP), pcap-linktype(7)
