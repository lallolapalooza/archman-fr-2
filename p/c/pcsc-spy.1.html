NOM

pcsc-spy - Une commande d'espionnage PC/SC

SYNTAXE

pcsc-spy [-n|--nocolor] [-d|--diffable] [-h|--help] [-v|--version] [-t|--thread] [nom_fichier_fifo]

DESCRIPTION

pcsc-spy affiche les appels PC/SC d'une application. Il doit être utilisé avec la bibliothèque libpcscspy.so.0.

Pour pouvoir espionner la couche PC/SC, le flux de l'application doit être modifié à l'aide de "LIBPCSCLITE_DELEGATE" afin que tous les appels PC/SC soient redirigés.

OPTIONS

-d, --diffable
Supprime les parties variables (comme les valeurs de gestionnaire) de la sortie afin que deux exécutions puissent être comparées plus facilement.
-h, --help
Affiche un court texte d'aide.
-n, --nocolor
Désactive la colorisation de la sortie (si vous voulez rediriger la sortie dans un fichier, par exemple).
-v, --version
Affiche la version du programme pcsc-spy ainsi qu'un copyright, une liste des auteurs.
-t, --thread
Ajoute un numéro de thread avant chaque ligne de log pour identifier les appels provenant des mêmes threads.

EXEMPLES

Nous utiliserons la variable d'environnement "LIBPCSCLITE_DELEGATE" pour charger notre bibliothèque d'espionnage.

Exemple :

sh /usr/share/doc/libpcsclite-dev/setup_spy.sh
export LIBPCSCLITE_DELEGATE=/lib/x86_64-linux-gnu/libpcscspy.so.0
LIBPCSCLITE_DELEGATE=/lib/x86_64-linux-gnu/libpcscspy.so.0 mon_application

Démarrage de l'outil d'espionnage

pcsc-spy

Si un argument de commande est passé, nous l'utilisons à la place du fichier FIFO par défaut ~/pcsc-spy. Il est alors possible d'enregistrer un journal d'exécution et d'utiliser pcsc-spy plusieurs fois sur le même journal.

Pour créer le fichier journal, faites simplement :

mkfifo ~/pcsc-spy
cat ~/pcsc-spy > fichier_journal

et lancez votre application PC/SC.

FICHIERS

Le fichier FIFO ~/pcsc-spy est utilisé par libpcscspy.so.0 pour envoyer les lignes brutes du journal.
