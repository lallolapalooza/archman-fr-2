PCAP_OPEN_LIVE(3PCAP) PCAP_OPEN_LIVE(3PCAP)

NOM

pcap_open_live - ouvrir un périphérique pour la capture

SYNTAXE

#include <pcap/pcap.h>
char errbuf[PCAP_ERRBUF_SIZE];
pcap_t *pcap_open_live(const char *device, int snaplen,
    int promisc, int to_ms, char *errbuf);

DESCRIPTION

pcap_open_live() est utilisé pour obtenir une poignée de capture de paquets afin d'examiner les paquets sur le réseau. device est une chaîne de caractères qui spécifie le périphérique réseau à ouvrir ; sur tous les systèmes Linux pris en charge, ainsi que sur les versions récentes de macOS et Solaris, un argument device de "any" ou NULL peut être utilisé pour capturer des paquets de toutes les interfaces réseau. Ce dernier ne doit pas être confondu avec tous les périphériques de capture disponibles tels qu'ils sont vus par pcap_findalldevs(3PCAP), qui peuvent également inclure D-Bus, USB, etc.

snaplen spécifie la longueur du cliché (snapshot) à définir sur la poignée. Si les données des paquets ne doivent pas être tronquées à la fin, une valeur de 262144 devrait suffire pour la plupart des périphériques, mais les périphériques D-Bus nécessitent une valeur de 128 Mo (128*1024*1024).

promisc spécifie si l'interface doit être mise en mode promiscueux. Si promisc est différent de zéro, le mode promiscueux sera activé, sinon il ne le sera pas.

to_ms spécifie le délai d'attente du tampon de paquets, en tant que valeur non négative, en millisecondes. (Voir pcap(3PCAP) pour une explication du délai d'attente du tampon de paquets.)

errbuf est un tampon suffisamment grand pour contenir au moins PCAP_ERRBUF_SIZE caractères.

VALEUR DE RETOUR

pcap_open_live() retourne un pcap_t * en cas de succès et NULL en cas d'échec. Si NULL est retourné, errbuf est rempli d'un message d'erreur approprié. errbuf peut également être défini avec un texte d'avertissement lorsque pcap_open_live() réussit ; pour détecter ce cas, l'appelant doit stocker une chaîne de longueur nulle dans errbuf avant d'appeler pcap_open_live() et afficher l'avertissement à l'utilisateur si errbuf n'est plus une chaîne de longueur nulle.
