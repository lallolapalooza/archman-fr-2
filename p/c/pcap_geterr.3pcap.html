pcap_geterr.3pcap

Paquet: libpcap

Licences: BSD-3-Clause

PCAP_GETERR(3PCAP) PCAP_GETERR(3PCAP)

NOM

pcap_geterr, pcap_perror - obtenir ou imprimer le texte d'un message d'erreur de libpcap

SYNTAXE

#include <pcap/pcap.h>
char *pcap_geterr(pcap_t *p);
void pcap_perror(pcap_t *p, const char *prefix);

DESCRIPTION

pcap_geterr() renvoie le texte d'erreur relatif à la dernière erreur de la bibliothèque pcap. NOTE : le pointeur qu'elle renvoie ne pointera plus vers un message d'erreur valide après la fermeture du pcap_t qui lui est passé ; vous devez utiliser ou copier la chaîne avant de fermer le pcap_t.

pcap_perror() imprime le texte de la dernière erreur de la bibliothèque pcap sur stderr, précédé par prefix.
