NOM

pcap_get_tstamp_precision - obtenir la précision de l'horodatage retournée dans les captures

SYNTAXE

#include <pcap/pcap.h>
int pcap_get_tstamp_precision(pcap_t *p);

DESCRIPTION

pcap_get_tstamp_precision() retourne la précision de l'horodatage retourné dans les captures de paquets sur le descripteur pcap.

VALEUR DE RETOUR

pcap_get_tstamp_precision() retourne PCAP_TSTAMP_PRECISION_MICRO ou PCAP_TSTAMP_PRECISION_NANO, indiquant que les captures pcap contiennent des horodatages en microsecondes ou nanosecondes respectivement.

COMPATIBILITÉ ASCENDANTE

Cette fonction est devenue disponible dans la version 1.5.1 de libpcap. Dans les versions précédentes, les horodatages d'un périphérique de capture ou d'un fichier de sauvegarde sont toujours donnés en secondes et microsecondes.

VOIR AUSSI
