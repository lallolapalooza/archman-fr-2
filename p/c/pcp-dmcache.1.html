NOM

pcp-dmcache, pcp-lvmcache - rapport sur les caches de périphériques de stockage logique

SYNTAXE

pcp [options pcp] dmcache [-iRV?] [périphérique ...]

DESCRIPTION

pcp-dmcache rapporte l'activité de toutes les cibles de cache configurées pour le Device Mapper. Les informations rapportées incluent les IOPs du périphérique, l'utilisation des périphériques de cache et de métadonnées, ainsi que les taux de succès et d'échec des lectures et écritures pour chaque périphérique de cache.

pcp-lvmcache (cache du Logical Volume Manager) est un synonyme exact de pcp-dmcache (cache du Device Mapper).

Par défaut, pcp-dmcache rapporte sur tous les périphériques de cible de cache disponibles (une ligne chacun, par échantillon), mais cela peut être restreint à des périphériques spécifiques sur la ligne de commande.

OPTIONS

Lorsqu'il est invoqué via la commande pcp(1), les options -h/--host, -a/--archive, -O/--origin, -s/--samples, -t/--interval, -Z/--timezone et plusieurs autres options pcp deviennent indirectement disponibles ; référez-vous à PCPIntro(1) pour une description complète de ces options.

Les options supplémentaires disponibles en ligne de commande pour pcp-dmcache sont :

-i, --iops
affiche le nombre total d'opérations de lecture et d'écriture au lieu du taux de succès du cache par défaut.
-R, --repeat
modifie la fréquence d'affichage de l'en-tête de colonne. Par défaut, un en-tête est affiché après chaque dixième échantillon.
-V, --version
Affiche le numéro de version et quitte.
-?, --help
Affiche le message d'utilisation et quitte.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

Pour les variables d'environnement affectant les outils PCP, voir pmGetOptions(3).

VOIR AUSSI

PCPIntro(1), pcp(1), pmdadm(1), dmsetup(1) et lvmcache(7).
