NOM

pcp-slabinfo - Rapport des statistiques pour l'allocateur noyau slab

SYNTAXE

pcp [options pc p] slabinfo [-a archive] [-s échantillons] [-Z fuseau horaire]

DESCRIPTION

La commande pcp-slabinfo est utilisée pour visualiser différentes statistiques relatives au slab. Elle aide les utilisateurs à analyser des informations utiles concernant l'allocateur slab. Les informations comprennent le nombre total d'objets actuellement actifs, les objets alloués, les pages par slab, etc. Par défaut, pcp-slabinfo rapporte les données en direct pour l'hôte local.

Les statistiques affichées sont les suivantes :

EN-TÊTE DESCRIPTION
active_objs Le nombre d'objets actuellement actifs (c'est-à-dire utilisés)
num_objs Le nombre total d'objets alloués (c'est-à-dire les objets en cours d'utilisation et non utilisés).
objsize La taille des objets dans ce slab, en octets.
objperslab Le nombre d'objets stockés dans chaque slab.
pagesperslab Le nombre de pages allouées pour chaque slab
active_slabs Le nombre de slabs actifs.
num_slabs Le nombre total de slabs.

OPTIONS

-a fichier, --archive=fichier
Récupère /proc/slabinfo pour un fichier d'archive spécifié
-s compte, --samples=compte
Obtient les statistiques slabinfo pour le compte d'échantillons spécifié
-V, --version
Affiche le numéro de version et quitte.
-z, --hostzone
Utilise le fuseau horaire local de l'hôte qui est la source des métriques de performance, tel qu'identifié par les options -h ou -a. Par défaut, utilise le fuseau horaire de l'hôte local.
-Z fuseau horaire, --timezone=fuseau horaire
Utilise fuseau horaire pour la date et l'heure. Fuseau horaire est au format de la variable d'environnement TZ tel que décrit dans environ(7).
-?, --help
Affiche le message d'utilisation et quitte.

NOTES

pcp-slabinfo collecte des informations à partir de /proc/slabinfo.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, tel que décrit dans pcp.conf(5).

Pour les variables d'environnement affectant les outils PCP, voir pmGetOptions(3).

VOIR AUSSI

PCPIntro(1), pcp(1), pmParseInterval(3), environ(7).
