pcre_get_substring(3)

Paquet: pcre

Licences: BSD

PCRE_GET_SUBSTRING(3) Manuel des fonctions de bibliothèque PCRE_GET_SUBSTRING(3)

NOM

PCRE - expressions régulières compatibles Perl

SYNTAXE

#include <pcre.h>

int pcre_get_substring(const char *subject, int *ovector,
     int stringcount, int stringnumber,
     const char **stringptr);

int pcre16_get_substring(PCRE_SPTR16 subject, int *ovector,
     int stringcount, int stringnumber,
     PCRE_SPTR16 *stringptr);

int pcre32_get_substring(PCRE_SPTR32 subject, int *ovector,
     int stringcount, int stringnumber,
     PCRE_SPTR32 *stringptr);

DESCRIPTION

C'est une fonction utilitaire pour extraire une sous-chaîne capturée. Les arguments sont :


subject Sujet qui a été correspondant avec succès
ovector Vecteur de décalages que pcre[16|32]_exec() a utilisé
stringcount Valeur retournée par pcre[16|32]_exec()
stringnumber Numéro de la sous-chaîne requise
stringptr Où placer le pointeur de chaîne

La mémoire dans laquelle la sous-chaîne est placée est obtenue en appelant pcre[16|32]_malloc(). La fonction utilitaire pcre[16|32]_free_substring() peut être utilisée pour la libérer lorsqu'elle n'est plus nécessaire. Le résultat de la fonction est la longueur de la sous-chaîne, PCRE_ERROR_NOMEMORY si suffisamment de mémoire n'a pas pu être obtenue, ou PCRE_ERROR_NOSUBSTRING si le numéro de chaîne est invalide.

Il existe une description complète de l'API native de PCRE dans la page pcreapi et une description de l'API POSIX dans la page pcreposix.
