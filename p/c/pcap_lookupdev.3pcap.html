NOM

pcap_lookupdev - trouver le périphérique par défaut sur lequel capturer

SYNTAXE

#include <pcap/pcap.h>
char errbuf[PCAP_ERRBUF_SIZE];
[OBSOLÈTE] char *pcap_lookupdev(char *errbuf);

DESCRIPTION

Cette interface est obsolète par pcap_findalldevs(3PCAP). Pour trouver un périphérique par défaut sur lequel capturer, appelez pcap_findalldevs() et, si la liste qu'il renvoie n'est pas vide, utilisez le premier périphérique de la liste. (Si la liste est vide, aucun périphérique ne permet la capture.) errbuf est un tampon suffisamment grand pour contenir au moins PCAP_ERRBUF_SIZE caractères.

Si pcap_init(3PCAP) a été appelé, cette interface renvoie toujours NULL.

pcap_lookupdev() renvoie un pointeur vers une chaîne indiquant le nom d'un périphérique réseau approprié pour une utilisation avec pcap_create(3PCAP) et pcap_activate(3PCAP), ou avec pcap_open_live(3PCAP), et avec pcap_lookupnet(3PCAP). En cas d'erreur, ou si pcap_init(3PCAP) a été appelé, NULL est renvoyé et errbuf est rempli avec un message d'erreur approprié.

VOIR AUSSI

pcap(3PCAP)

BOGUES

Le pointeur renvoyé par pcap_lookupdev() pointe vers un tampon statique ; des appels ultérieurs à pcap_lookupdev() dans le même thread, ou des appels à pcap_lookupdev() dans un autre thread, peuvent écraser ce tampon.

Dans WinPcap et Npcap, cette fonction peut renvoyer une chaîne UTF-16 plutôt qu'une chaîne ASCII ou UTF-8.
