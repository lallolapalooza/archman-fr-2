NOM

pcap_datalink - obtenir le type d'en-tête de la couche liaison

SYNTAXE

#include <pcap/pcap.h>
int pcap_datalink(pcap_t *p);

DESCRIPTION

pcap_datalink() retourne le type d'en-tête de la couche liaison pour la capture en direct ou le « fichier de sauvegarde » spécifié par p.

Elle ne doit pas être appelée sur un descripteur pcap créé par pcap_create(3PCAP) qui n'a pas encore été activé par pcap_activate(3PCAP).

https://www.tcpdump.org/linktypes.html liste les valeurs que pcap_datalink() peut retourner et décrit les formats de paquets qui correspondent à ces valeurs.

Ne présumez PAS que les paquets pour une capture donnée ou un « fichier de sauvegarde » auront un type d'en-tête de couche liaison donné, tel que DLT_EN10MB pour Ethernet. Par exemple, le périphérique « any » sous Linux aura un type d'en-tête de couche liaison de DLT_LINUX_SLL ou DLT_LINUX_SLL2 même si tous les périphériques du système au moment où le périphérique « any » est ouvert ont un autre type de liaison de données, tel que DLT_EN10MB pour Ethernet.

VALEUR DE RETOUR

pcap_datalink() retourne le type d'en-tête de la couche liaison en cas de succès et PCAP_ERROR_NOT_ACTIVATED si elle est appelée sur un descripteur de capture qui a été créé mais pas activé.

VOIR AUSSI

pcap(3PCAP), pcap-linktype(7)
