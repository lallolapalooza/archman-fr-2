pcre_jit_exec(3)

Paquet: pcre

Licences: BSD

PCRE_EXEC(3) Manuel des fonctions de bibliothèque PCRE_EXEC(3)

NOM

PCRE - expressions régulières compatibles Perl

SYNOPSIS

#include <pcre.h>

int pcre_jit_exec(const pcre *code, const pcre_extra *extra,
     const char *subject, int length, int startoffset,
     int options, int *ovector, int ovecsize,
     pcre_jit_stack *jstack);

int pcre16_jit_exec(const pcre16 *code, const pcre16_extra *extra,
     PCRE_SPTR16 subject, int length, int startoffset,
     int options, int *ovector, int ovecsize,
     pcre_jit_stack *jstack);

int pcre32_jit_exec(const pcre32 *code, const pcre32_extra *extra,
     PCRE_SPTR32 subject, int length, int startoffset,
     int options, int *ovector, int ovecsize,
     pcre_jit_stack *jstack);

DESCRIPTION

Cette fonction fait correspondre une expression régulière compilée qui a été étudiée avec succès avec l'une des options JIT à une chaîne de sujet donnée, en utilisant un algorithme de correspondance similaire à celui de Perl. C'est une interface de « chemin rapide » vers JIT, et elle contourne certaines des vérifications de sécurité que pcre_exec() applique. Elle renvoie les décalages des sous-chaînes capturées. Ses arguments sont :


code Pointeur vers le motif compilé
extra Pointeur vers une structure pcre[16|32]_extra associée,
ou est NULL
subject Pointeur vers la chaîne de sujet
length Longueur de la chaîne de sujet, en octets
startoffset Décalage en octets dans le sujet où commencer la
correspondance
options Bits d'options
ovector Pointeur vers un vecteur d'entiers pour les décalages de résultat
ovecsize Nombre d'éléments dans le vecteur (un multiple de 3)
jstack Pointeur vers une pile JIT

Les options autorisées sont :


PCRE_NOTBOL La chaîne de sujet n'est pas le début d'une ligne
PCRE_NOTEOL La chaîne de sujet n'est pas la fin d'une ligne
PCRE_NOTEMPTY Une chaîne vide n'est pas une correspondance valide
PCRE_NOTEMPTY_ATSTART Une chaîne vide au début du sujet
n'est pas une correspondance valide
PCRE_NO_UTF16_CHECK Ne pas vérifier la validité UTF-16 du sujet
(uniquement pertinent si PCRE_UTF16
a été défini lors de la compilation)
PCRE_NO_UTF32_CHECK Ne pas vérifier la validité UTF-32 du sujet
(uniquement pertinent si PCRE_UTF32
a été défini lors de la compilation)
PCRE_NO_UTF8_CHECK Ne pas vérifier la validité UTF-8 du sujet
(uniquement pertinent si PCRE_UTF8
a été défini lors de la compilation)
PCRE_PARTIAL ) Renvoyer PCRE_ERROR_PARTIAL pour une correspondance partielle
PCRE_PARTIAL_SOFT ) si aucune correspondance complète n'est trouvée
PCRE_PARTIAL_HARD Renvoyer PCRE_ERROR_PARTIAL pour une correspondance partielle
si celle-ci est trouvée avant une correspondance complète

Cependant, les options PCRE_NO_UTF[8|16|32]_CHECK n'ont aucun effet, car cette vérification n'est jamais appliquée. Pour plus de détails sur la correspondance partielle, consultez la page pcrepartial. Une structure pcre_extra contient les champs suivants :


flags Bits indiquant quels champs sont définis
study_data Données opaques de pcre[16|32]_study()
match_limit Limite d'utilisation des ressources internes
match_limit_recursion Limite de profondeur de récursion interne
callout_data Données opaques renvoyées aux appels
tables Pointeur vers des tables de caractères ou NULL
mark Pour renvoyer un pointeur *MARK
executable_jit Données opaques de la compilation JIT

Les bits d'indicateur sont PCRE_EXTRA_STUDY_DATA, PCRE_EXTRA_MATCH_LIMIT, PCRE_EXTRA_MATCH_LIMIT_RECURSION, PCRE_EXTRA_CALLOUT_DATA, PCRE_EXTRA_TABLES, PCRE_EXTRA_MARK et PCRE_EXTRA_EXECUTABLE_JIT.

Il existe une description complète de l'API native PCRE dans la page pcreapi et une description de l'API JIT dans la page pcrejit.
