PCRE2_SET_COMPILE_EXTRA_OPTIONS(3) Manuel des fonctions de bibliothèque PCRE2_SET_COMPILE_EXTRA_OPTIONS(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

int pcre2_set_compile_extra_options(pcre2_compile_context *ccontext,
  uint32_t extra_options);

DESCRIPTION

Cette fonction définit des bits d'option supplémentaires pour pcre2_compile() qui sont logés dans un contexte de compilation. Elle remplace complètement tous les bits. Les options supplémentaires sont :


PCRE2_EXTRA_ALLOW_LOOKAROUND_BSK Permet \K dans les lookarounds
PCRE2_EXTRA_ALLOW_SURROGATE_ESCAPES Permet \x{d800} à \x{dfff}
en modes UTF-8 et UTF-32
PCRE2_EXTRA_ALT_BSUX Gestion étendue alternative de \u, \U, et
\x
PCRE2_EXTRA_ASCII_BSD \d reste ASCII en mode UCP
PCRE2_EXTRA_ASCII_BSS \s reste ASCII en mode UCP
PCRE2_EXTRA_ASCII_BSW \w reste ASCII en mode UCP
PCRE2_EXTRA_ASCII_DIGIT Les classes POSIX [:digit:] et [:xdigit:]
restent ASCII en mode UCP
PCRE2_EXTRA_ASCII_POSIX Les classes POSIX restent ASCII en
mode UCP
PCRE2_EXTRA_BAD_ESCAPE_IS_LITERAL Traite toutes les échappées invalides comme
un caractère littéral suivant
PCRE2_EXTRA_CASELESS_RESTRICT Désactive le pliage de casse ASCII/non-ASCII mixte
PCRE2_EXTRA_ESCAPED_CR_IS_LF Interprète \r comme \n
PCRE2_EXTRA_MATCH_LINE Les motifs correspondent à des lignes entières
PCRE2_EXTRA_MATCH_WORD Les motifs correspondent à des « mots »
PCRE2_EXTRA_NEVER_CALLOUT Interdit les callouts dans le motif
PCRE2_EXTRA_NO_BS0 Interdit \0 (mais pas \00 ou \000)
PCRE2_EXTRA_PYTHON_OCTAL Utilise les règles de Python pour l'octal
PCRE2_EXTRA_TURKISH_CASING Utilise le pliage de casse turc I

Il y a une description complète de l'API native de PCRE2 dans la page pcre2api et une description de l'API POSIX dans la page pcre2posix.
