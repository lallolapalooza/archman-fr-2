pcre2_substring_number_from_name(3)

PCRE2_SUBSTRING_NUMBER_FROM_NAME(3) Manuel des fonctions de bibliothèque PCRE2_SUBSTRING_NUMBER_FROM_NAME(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

int pcre2_substring_number_from_name(const pcre2_code *code,
  PCRE2_SPTR name);

DESCRIPTION

Cette fonction pratique recherche le numéro d'une parenthèse de capture de sous-chaîne nommée dans un motif compilé, à condition que le nom soit unique. Les arguments de la fonction sont :


code Expression régulière compilée
name Nom dont le numéro est requis

La fonction renvoie le numéro de la parenthèse si le nom est trouvé, ou PCRE2_ERROR_NOSUBSTRING s'il n'est pas trouvé. Lorsque les noms dupliqués sont autorisés (PCRE2_DUPNAMES est défini), si le nom n'est pas unique, PCRE2_ERROR_NOUNIQUESUBSTRING est renvoyé. Vous pouvez obtenir la liste des numéros portant le même nom en appelant pcre2_substring_nametable_scan().

Il existe une description complète de l'API native de PCRE2 dans la page pcre2api et une description de l'API POSIX dans la page pcre2posix.
