NOM

pcdovtoppm - créer une image d'index pour un CD photo

SYNTAXE

pcdovtoppm [-m largeur] [-s taille] [-a largeur] [-c couleurs] [-f police] [-b|-w] [fichier_pcd]

DESCRIPTION

Ce programme fait partie de Netpbm(1)

Ce programme génère une image d'index au format PPM pour un CD photo, basée sur le fichier d'aperçu du CD photo.

Vous pouvez obtenir un résultat similaire avec hpcdtoppm -Overview suivi de pnmindex -black sur les images PPM générées.

OPTIONS

-mlargeur
Largeur maximale de l'image résultat (par défaut : 1152).
-staille
Taille maximale de chacune des images (par défaut : 192).
-alargeur
Nombre maximal d'images en largeur (par défaut : 6).
-ccouleurs
Nombre maximal de couleurs, ou n

pour signifier aucune quantification

-fpolice
Police à utiliser pour l'annotation (par défaut : police interne).
-b
Couleur de fond noir (par défaut).
-w
Couleur de fond blanc.

EXEMPLES

pcdovtoppm -m 768 -s 96 -f smallfont.pbm overview.pcd > overview.ppm
pcdovtoppm /cdrom/photo_cd/overview.pcd | ppmtojpeg > overview.jpg

HISTORIQUE

Ce programme s'appelait auparavant pcdindex, ce qui ne correspondait pas aux conventions de nommage de Netpbm.
