pcre2_pattern_info(3)

Paquet: pcre2

Licences: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_PATTERN_INFO(3) Manuel des fonctions de bibliothèque PCRE2_PATTERN_INFO(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNOPSIS

#include <pcre2.h>

int pcre2_pattern_info(const pcre2_code *code, uint32_t what,
   void *where);

DESCRIPTION

Cette fonction renvoie des informations sur un motif compilé. Ses arguments sont :


code Pointeur vers un motif d'expression régulière compilé
what Quelles informations sont requises
where Où placer les informations

Les valeurs reconnues pour l'argument what, et les informations qu'elles demandent sont les suivantes :


PCRE2_INFO_ALLOPTIONS Options finales après compilation
PCRE2_INFO_ARGOPTIONS Options passées à pcre2_compile()
PCRE2_INFO_BACKREFMAX Nombre de la plus haute référence arrière
PCRE2_INFO_BSR Ce que \R correspond :
PCRE2_BSR_UNICODE : fins de ligne Unicode
PCRE2_BSR_ANYCRLF : uniquement CR, LF, ou CRLF
PCRE2_INFO_CAPTURECOUNT Nombre de sous-motifs capturants
PCRE2_INFO_DEPTHLIMIT Limite de profondeur de backtracking si définie,
sinon PCRE2_ERROR_UNSET
PCRE2_INFO_EXTRAOPTIONS Options supplémentaires qui ont été passées dans le
contexte de compilation
PCRE2_INFO_FIRSTBITMAP Bitmap des premières unités de code, ou NULL
PCRE2_INFO_FIRSTCODETYPE Type des informations de début de correspondance
0 rien défini
1 première unité de code définie
2 début de chaîne ou après nouvelle ligne
PCRE2_INFO_FIRSTCODEUNIT Première unité de code lorsque le type est 1
PCRE2_INFO_FRAMESIZE Taille de la trame de backtracking
PCRE2_INFO_HASBACKSLASHC Renvoie 1 si le motif contient \C
PCRE2_INFO_HASCRORLF Renvoie 1 si des correspondances CR ou LF explicites
existent dans le motif
PCRE2_INFO_HEAPLIMIT Limite de mémoire du tas si définie,
sinon PCRE2_ERROR_UNSET
PCRE2_INFO_JCHANGED Renvoie 1 si (?J) ou (?-J) a été utilisé
PCRE2_INFO_JITSIZE Taille du code compilé JIT, ou 0
PCRE2_INFO_LASTCODETYPE Type des informations de présence obligatoire
0 rien défini
1 unité de code définie
PCRE2_INFO_LASTCODEUNIT Dernière unité de code lorsque le type est 1
PCRE2_INFO_MATCHEMPTY 1 si le motif peut correspondre à une
chaîne vide, 0 sinon
PCRE2_INFO_MATCHLIMIT Limite de correspondance si définie,
sinon PCRE2_ERROR_UNSET
PCRE2_INFO_MAXLOOKBEHIND Longueur (en caractères) de la plus longue
assertion de regard arrière
PCRE2_INFO_MINLENGTH Borne inférieure de la longueur des chaînes correspondantes
PCRE2_INFO_NAMECOUNT Nombre de sous-motifs nommés
PCRE2_INFO_NAMEENTRYSIZE Taille des entrées de la table de noms
PCRE2_INFO_NAMETABLE Pointeur vers la table de noms
PCRE2_CONFIG_NEWLINE Code de la séquence de nouvelle ligne :
PCRE2_NEWLINE_CR
PCRE2_NEWLINE_LF
PCRE2_NEWLINE_CRLF
PCRE2_NEWLINE_ANY
PCRE2_NEWLINE_ANYCRLF
PCRE2_NEWLINE_NUL
PCRE2_INFO_RECURSIONLIMIT Synonyme obsolète de PCRE2_INFO_DEPTHLIMIT
PCRE2_INFO_SIZE Taille du motif compilé

Si where est NULL, la fonction renvoie la quantité de mémoire nécessaire pour les informations demandées, en octets. Sinon, l'argument where doit pointer vers un entier non signé de 32 bits (uint32_t), sauf pour les valeurs what suivantes, où il doit pointer vers une variable du type indiqué :


PCRE2_INFO_FIRSTBITMAP const uint8_t *
PCRE2_INFO_JITSIZE size_t
PCRE2_INFO_NAMETABLE PCRE2_SPTR
PCRE2_INFO_SIZE size_t

Le rendement de la fonction est zéro en cas de succès ou :


PCRE2_ERROR_NULL l'argument code est NULL
PCRE2_ERROR_BADMAGIC le "nombre magique" n'a pas été trouvé
PCRE2_ERROR_BADOPTION la valeur de what est invalide
PCRE2_ERROR_BADMODE le motif a été compilé dans le mauvais mode
PCRE2_ERROR_UNSET l'information demandée n'est pas définie

Il y a une description complète de l'API native PCRE2 dans la page pcre2api et une description de l'API POSIX dans la page pcre2posix.
