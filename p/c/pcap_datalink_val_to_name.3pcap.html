pcap_datalink_val_to_name.3pcap

Paquet: libpcap

Licences: BSD-3-Clause

PCAP_DATALINK_VAL_TO_NAME(3PCAP) PCAP_DATALINK_VAL_TO_NAME(3PCAP)

NOM

pcap_datalink_val_to_name, pcap_datalink_val_to_description, pcap_datalink_val_to_description_or_dlt - obtenir un nom ou une description pour une valeur de type d'en-tête de couche de liaison

SYNTAXE

#include <pcap.h>
const char *pcap_datalink_val_to_name(int dlt);
const char *pcap_datalink_val_to_description(int dlt);
const char *pcap_datalink_val_to_description_or_dlt(int dlt);

DESCRIPTION

pcap_datalink_val_to_name() traduit une valeur de type d'en-tête de couche de liaison en le nom correspondant du type d'en-tête de couche de liaison, qui est le nom DLT_ pour la valeur du type d'en-tête de couche de liaison, avec le préfixe DLT_ retiré. NULL est retourné si la valeur du type ne correspond à aucune valeur DLT_ connue.

pcap_datalink_val_to_description() traduit une valeur de type d'en-tête de couche de liaison en une courte description de ce type d'en-tête de couche de liaison. NULL est retourné si la valeur du type ne correspond à aucune valeur DLT_ connue.

pcap_datalink_val_to_description_or_dlt() traduit une valeur de type d'en-tête de couche de liaison en une courte description de ce type d'en-tête de couche de liaison, tout comme pcap_datalink_val_to_description(). Si la valeur du type ne correspond à aucune valeur DLT_ connue, la chaîne "DLT n" est retournée, où n est la valeur de l'argument dlt.

COMPATIBILITÉ ASCENDANTE

La fonction pcap_datalink_val_to_description_or_dlt() est apparue pour la première fois dans la version 1.9.1 de libpcap. Dans les versions précédentes, il fallait appeler pcap_datalink_val_to_description() et, s'il retournait NULL, construire une chaîne par défaut.
