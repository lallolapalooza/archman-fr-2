NOM

PCManFM-Qt - un gestionnaire de fichiers léger basé sur Qt pour X Window.

SYNTAXE

pcmanfm-qt [OPTION]... [FICHIER1, FICHIER2,...]

DESCRIPTION

PCMan File Manager Qt (PCManFM-Qt) est un gestionnaire de fichiers extrêmement rapide, léger, mais riche en fonctionnalités avec navigation par onglets. C'est le gestionnaire de fichiers par défaut pour l'environnement de bureau léger LXQt.

OPTIONS

Options d'aide :

-h, --help
Affiche les options d'aide

Options de l'application :

-p, --profile=PROFIL
Définit le nom du profil de configuration
-d, --daemon-mode
Lance PCManFM en mode démon
--quit
Quitte PCManFM
--desktop
Lance le gestionnaire de bureau
--desktop-off
Désactive le gestionnaire de bureau s'il est en cours d'exécution
--desktop-pref=NOM
Ouvre la boîte de dialogue des préférences du bureau sur la page spécifiée par NOM
-w, --set-wallpaper=FICHIER
Définit le fond d'écran du bureau à partir de l'image FICHIER
--wallpaper-mode=MODE
Définit le mode du fond d'écran du bureau. MODE=(couleur|étirer|adapter|centrer|mosaïque)
--show-pref=NOM
Ouvre la boîte de dialogue des préférences sur la page spécifiée par NOM
-n, --new-window
Ouvre une nouvelle fenêtre
-f, --find-files
Ouvre l'utilitaire Rechercher des fichiers
