pcre2_code_copy_with_tables(3)

PCRE2_CODE_COPY(3) Manuel de fonctions de bibliothèque PCRE2_CODE_COPY(3)

NOM

PCRE2 - Expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

pcre2_code *pcre2_code_copy_with_tables(const pcre2_code *code);

DESCRIPTION

Cette fonction crée une copie de la mémoire utilisée pour un modèle compilé, excluant toute mémoire utilisée par le compilateur JIT. Sans un appel ultérieur à pcre2_jit_compile(), la copie ne peut être utilisée que pour la correspondance sans JIT. Contrairement à pcre2_code_copy(), une copie séparée des tables de caractères est également créée, et le nouveau code pointe vers celle-ci. Cette mémoire sera automatiquement libérée lorsque pcre2_code_free() sera appelé. Le résultat de la fonction est NULL si code est NULL ou si une mémoire suffisante ne peut être obtenue.

Une description complète de l'API native PCRE2 se trouve sur la page pcre2api et une description de l'API POSIX se trouve sur la page pcre2posix.
