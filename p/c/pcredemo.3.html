/*************************************************
*           PROGRAMME DE DÉMONSTRATION PCRE           *
*************************************************/
/* Ceci est un programme de démonstration pour illustrer les moyens les plus simples
d'appeler la bibliothèque d'expressions régulières PCRE à partir d'un programme C. Voir la
documentation de pcresample pour une brève discussion ("man pcresample" si vous avez
les pages de manuel PCRE installées).
Dans les environnements de type Unix, si PCRE est installé dans vos bibliothèques système standard, vous devriez pouvoir compiler ce programme en utilisant cette commande :
gcc -Wall pcredemo.c -lpcre -o pcredemo
Si PCRE n'est pas installé dans un endroit standard, il est probable qu'il soit installé avec
la prise en charge du mécanisme pkg-config. Si vous avez pkg-config, vous pouvez compiler
ce programme en utilisant cette commande :
gcc -Wall pcredemo.c `pkg-config --cflags --libs libpcre` -o pcredemo
Si vous n'avez pas pkg-config, vous devrez peut-être utiliser ceci :
gcc -Wall pcredemo.c -I/usr/local/include -L/usr/local/lib \
  -R/usr/local/lib -lpcre -o pcredemo
Remplacez "/usr/local/include" et "/usr/local/lib" par l'emplacement des fichiers include et
bibliothèque pour PCRE sur votre système. Seuls certains systèmes d'exploitation (par ex. Solaris) utilisent l'option -R.
Compilation sous Windows :
Si vous souhaitez lier statiquement ce programme à un fichier .a non-dll, vous devez
définir PCRE_STATIC avant d'inclure pcre.h, sinon les fonctions exportées pcre_malloc() et
pcre_free() seront déclarées __declspec(dllimport), avec
des résultats indésirables. Donc, dans cet environnement, décommentez la ligne suivante. */
/* #define PCRE_STATIC */
#include <stdio.h>
#include <string.h>
#include <pcre.h>
#define OVECCOUNT 30    /* doit être un multiple de 3 */
int main(int argc, char **argv)
{
pcre *re;
const char *error;
char *pattern;
char *subject;
unsigned char *name_table;
unsigned int option_bits;
int erroffset;
int find_all;
int crlf_is_newline;
int namecount;
int name_entry_size;
int ovector[OVECCOUNT];
int subject_length;
int rc, i;
int utf8;
/**************************************************************************
* Premièrement, traitons la ligne de commande. Il n'y a qu'une seule option possible à *
* l'heure actuelle, "-g" pour demander une correspondance répétée afin de trouver toutes les occurrences, *
* comme l'option /g de Perl. Nous définissons la variable find_all à une valeur non nulle *
* si l'option -g est présente. Outre cela, il doit y avoir exactement deux *
* arguments.                                                              *
**************************************************************************/
find_all = 0;
for (i = 1; i < argc; i++)
  {
  if (strcmp(argv[i], "-g") == 0) find_all = 1;
    else break;
  }
/* Après les options, nous avons besoin de exactement deux arguments, qui sont le motif,
et la chaîne sujet. */
if (argc - i != 2)
  {
  printf("Deux arguments requis : une regex et une chaîne sujet\n");
  return 1;
  }
pattern = argv[i];
subject = argv[i+1];
subject_length = (int)strlen(subject);
/*************************************************************************
* Maintenant, nous allons compiler l'expression régulière, et gérer *
* les erreurs qui sont détectées.                                          *
*************************************************************************/
re = pcre_compile(
  pattern,              /* le motif */
  0,                    /* options par défaut */
  &error,               /* pour le message d'erreur */
  &erroffset,           /* pour le décalage de l'erreur */
  NULL);                /* utiliser les tables de caractères par défaut */
/* La compilation a échoué : afficher le message d'erreur et quitter */
if (re == NULL)
  {
  printf("La compilation PCRE a échoué à l'offset %d : %s\n", erroffset, error);
  return 1;
  }
/*************************************************************************
* Si la compilation a réussi, nous appelons PCRE à nouveau, afin de faire une *
* correspondance de motif sur la chaîne sujet. Ceci fait UNE seule correspondance. Si *
* d'autres correspondances sont nécessaires, elles seront effectuées ci-dessous.                     *
*************************************************************************/
rc = pcre_exec(
  re,                   /* le motif compilé */
  NULL,                 /* pas de données supplémentaires - nous n'avons pas étudié le motif */
  subject,              /* la chaîne sujet */
  subject_length,       /* la longueur du sujet */
  0,                    /* démarrer à l'offset 0 dans le sujet */
  0,                    /* options par défaut */
  ovector,              /* vecteur de sortie pour les informations sur les sous-chaînes */
  OVECCOUNT);           /* nombre d'éléments dans le vecteur de sortie */
/* La correspondance a échoué : gérer les cas d'erreur */
if (rc < 0)
  {
  switch(rc)
    {
    case PCRE_ERROR_NOMATCH: printf("Aucune correspondance\n"); break;
    /*
    Gérer d'autres cas spéciaux si vous le souhaitez
    */
    default: printf("Erreur de correspondance %d\n", rc); break;
    }
  pcre_free(re);     /* Libérer la mémoire utilisée pour le motif compilé */
  return 1;
  }
/* Correspondance réussie */
printf("\nCorrespondance réussie à l'offset %d\n", ovector[0]);
/*************************************************************************
* Nous avons trouvé la première correspondance dans la chaîne sujet. Si le vecteur de sortie *
* n'était pas assez grand, nous le disons. Ensuite, nous affichons les sous-chaînes qui ont été *
* capturées.                                                              *
*************************************************************************/
/* Le vecteur de sortie n'était pas assez grand */
if (rc == 0)
  {
  rc = OVECCOUNT/3;
  printf("ovector n'a de place que pour %d sous-chaînes capturées\n", rc - 1);
  }
/* Afficher les sous-chaînes stockées dans le vecteur de sortie par numéro. Clairement, dans une application réelle
vous pourriez vouloir faire autre chose que de les imprimer. */
for (i = 0; i < rc; i++)
  {
  char *substring_start = subject + ovector[2*i];
  int substring_length = ovector[2*i+1] - ovector[2*i];
  printf("%2d: %.*s\n", i, substring_length, substring_start);
  }
/**************************************************************************
* Ceci conclut la partie de base de ce programme de démonstration. Nous avons    *
* compilé un motif, et effectué une seule correspondance. Le code qui suit *
* montre d'abord comment accéder aux sous-chaînes nommées, puis comment coder *
* pour des correspondances répétées sur le même sujet.                                   *
**************************************************************************/
/* Voyons s'il y a des sous-chaînes nommées, et si oui, affichons-les par nom. D'abord
nous devons extraire le nombre de na
/* Récupérer le nombre de sous-chaînes nommées. */
(void)pcre_fullinfo(
  re,                   /* le motif compilé */
  NULL,                 /* pas de données supplémentaires - nous n'avons pas étudié le motif */
  PCRE_INFO_NAMECOUNT,  /* nombre de sous-chaînes nommées */
  &namecount);          /* où mettre la réponse */
if (namecount <= 0) printf("Aucune sous-chaîne nommée\n"); else
  {
  unsigned char *tabptr;
  printf("Sous-chaînes nommées\n");
  /* Avant de pouvoir accéder aux sous-chaînes, nous devons extraire la table pour
  traduire les noms en numéros, et la taille de chaque entrée dans la table. */
  (void)pcre_fullinfo(
    re,                       /* le motif compilé */
    NULL,                     /* pas de données supplémentaires - nous n'avons pas étudié le motif */
    PCRE_INFO_NAMETABLE,      /* adresse de la table */
    &name_table);             /* où mettre la réponse */
  (void)pcre_fullinfo(
    re,                       /* le motif compilé */
    NULL,                     /* pas de données supplémentaires - nous n'avons pas étudié le motif */
    PCRE_INFO_NAMEENTRYSIZE,  /* taille de chaque entrée dans la table */
    &name_entry_size);        /* où mettre la réponse */
  /* Maintenant, nous pouvons parcourir la table et, pour chaque entrée, afficher le numéro, le nom,
  et la sous-chaîne elle-même. */
  tabptr = name_table;
  for (i = 0; i < namecount; i++)
    {
    int n = (tabptr[0] << 8) | tabptr[1];
    printf("(%d) %*s: %.*s\n", n, name_entry_size - 3, tabptr + 2,
      ovector[2*n+1] - ovector[2*n], subject + ovector[2*n]);
    tabptr += name_entry_size;
    }
  }
/*************************************************************************
* Si l'option "-g" a été donnée sur la ligne de commande, nous voulons continuer  *
* à rechercher des correspondances supplémentaires dans la chaîne sujet, de manière similaire *
* à l'option /g de Perl. Cela s'avère plus délicat que ce que l'on pourrait penser, en raison de la possibilité de faire correspondre une chaîne vide. *
* Ce qui se passe est le suivant :                                            *
*                                                                        *
* Si la correspondance précédente N'ÉTAIT PAS une chaîne vide, nous pouvons simplement commencer *
* la correspondance suivante à la fin de la précédente.                         *
*                                                                        *
* Si la correspondance précédente ÉTAIT une chaîne vide, nous ne pouvons pas faire cela, car cela *
* mènerait à une boucle infinie. Au lieu de cela, un appel spécial de pcre_exec() *
* est effectué avec les drapeaux PCRE_NOTEMPTY_ATSTART et PCRE_ANCHORED définis.    *
* Le premier de ces drapeaux indique à PCRE qu'une chaîne vide au début du *
* sujet n'est pas une correspondance valide ; d'autres possibilités doivent être essayées. Le *
* second drapeau limite PCRE à une seule tentative de correspondance à la position initiale de la chaîne.  *
* Si cette correspondance réussit, une alternative à la correspondance de la chaîne vide a été trouvée, et nous pouvons l'afficher et continuer la boucle, *
* en avançant de la longueur de ce qui a été trouvé. Si cette correspondance n'a pas *
* réussi, nous restons dans la boucle, en avançant d'un seul caractère.   *
* En mode UTF-8, qui peut être défini par (*UTF8) dans le motif, cela peut être *
* plus d'un octet.                                                    *
*                                                                        *
* Cependant, il y a une complication concernant les sauts de ligne. Lorsque la     *
* convention de saut de ligne est telle que CRLF est un saut de ligne valide, nous devons       *
* avancer de deux caractères au lieu d'un. La convention de saut de ligne peut  *
* être définie dans l'expression régulière par (*CR), etc. ; sinon, nous devons trouver la valeur par défaut.  *
*************************************************************************/
if (!find_all)     /* Vérifier si -g a été donné */
  {
  pcre_free(re);   /* Libérer la mémoire utilisée pour le motif compilé */
  return 0;        /* Terminer sauf si -g a été donné */
  }
/* Avant de lancer la boucle, vérifier l'UTF-8 et si CRLF est une séquence de saut de ligne valide
des sauts de ligne. D'abord, trouver les options avec lesquelles l'expression régulière a été compilée ; extraire
l'état UTF-8, et masquer toutes les options sauf celles des sauts de ligne. */
(void)pcre_fullinfo(re, NULL, PCRE_INFO_OPTIONS, &option_bits);
utf8 = option_bits & PCRE_UTF8;
option_bits &= PCRE_NEWLINE_CR|PCRE_NEWLINE_LF|PCRE_NEWLINE_CRLF|
               PCRE_NEWLINE_ANY|PCRE_NEWLINE_ANYCRLF;
/* Si aucune option de saut de ligne n'a été définie, trouver la convention de saut de ligne par défaut à partir de la
configuration de construction. */
if (option_bits == 0)
  {
  int d;
  (void)pcre_config(PCRE_CONFIG_NEWLINE, &d);
  /* Notez que ces valeurs sont toujours les valeurs ASCII, même dans
  les environnements EBCDIC. CR = 13, NL = 10. */
  option_bits = (d == 13)? PCRE_NEWLINE_CR :
          (d == 10)? PCRE_NEWLINE_LF :
          (d == (13<<8 | 10))? PCRE_NEWLINE_CRLF :
          (d == -2)? PCRE_NEWLINE_ANYCRLF :
          (d == -1)? PCRE_NEWLINE_ANY : 0;
  }
/* Voir si CRLF est une séquence de saut de ligne valide. */
crlf_is_newline =
     option_bits == PCRE_NEWLINE_ANY ||
     option_bits == PCRE_NEWLINE_CRLF ||
     option_bits == PCRE_NEWLINE_ANYCRLF;
/* Boucle pour la deuxième et les correspondances suivantes */
for (;;)
  {
  int options = 0;                 /* Normalement pas d'options */
  int start_offset = ovector[1];   /* Commencer à la fin de la correspondance précédente */
  /* Si la correspondance précédente était pour une chaîne vide, nous avons terminé si nous sommes
  à la fin du sujet. Sinon, arrangez-vous pour lancer une autre correspondance au
  même point pour voir si une correspondance non vide peut être trouvée. */
  if (ovector[0] == ovector[1])
    {
    if (ovector[0] == subject_length) break;
    options = PCRE_NOTEMPTY_ATSTART | PCRE_ANCHORED;
    }
  /* Lancer la prochaine opération de correspondance */
  rc = pcre_exec(
    re,                   /* le motif compilé */
    NULL,                 /* pas de données supplémentaires - nous n'avons pas étudié le motif */
    subject,              /* la chaîne sujet */
    subject_length,       /* la longueur du sujet */
    start_offset,         /* décalage de départ dans le sujet */
    options,              /* options */
    ovector,              /* vecteur de sortie pour les informations de sous-chaîne */
    OVECCOUNT);           /* nombre d'éléments dans le vecteur de sortie */
  /* Cette fois, un résultat de NOMATCH n'est pas une erreur. Si la valeur dans "options"
  est zéro, cela signifie simplement que toutes les correspondances possibles ont été trouvées, donc la boucle se termine.
  Sinon, cela signifie que nous n'avons pas réussi à trouver une correspondance non vide à un *
  point où il y avait une correspondance vide précédente. Dans ce cas, nous faisons ce que *
  Perl fait : avancer la position de correspondance d'un caractère, et continuer. Nous *
  faisons cela en définissant le décalage de "fin de la correspondance précédente", car cela est récupéré *
  en haut de la boucle comme point de départ. *
  Il y a deux complications : (a) Lorsque CRLF est un saut de ligne valide, et *
  que la position actuelle est juste avant, avancer d'un octet supplémentaire. (b) *
  Sinon, nous devons nous assurer que nous sautons un caractère UTF-8 entier si nous sommes en *
  mode UTF-8. */
  if (rc == PCRE_ERROR_NOMATCH)
    {
    if (options == 0) break;                    /* Toutes les correspondances trouvées */
    ovector[1] = start_offset + 1;              /* Avancer d'un octet */
    if (crlf_is_newline &&                      /* Si CRLF est un saut de ligne & */
        start_offset < subject_length - 1 &&    /* nous sommes à CRLF, */
        subject[start_offset] == '\r' &&
        subject[start_offset + 1] == '\n')
      ovector[1] += 1;                          /* Avancer d'un de plus. */
    else if (utf8)                              /* Sinon, s'assurer que nous */
      {                                         /* avançons un caractère UTF-8 entier */
      while (ovector[1] < subject_length)       /* . */
        {
        if ((subject[ovector[1]] & 0xc0) != 0x80) break;
        ovector[1] += 1;
        }
      }
    continue;    /* Revenir en haut de la boucle */
    }
  /* Les autres erreurs de correspondance ne sont pas récupérables. */
  if (rc < 0)
    {
    printf("Erreur de correspondance %d\n", rc);
    pcre_free(re);    /* Libérer la mémoire utilisée pour le motif compilé */
    return 1;
    }
  /* Correspondance réussie */
  printf("\nCorrespondance réussie à nouveau au décalage %d\n", ovector[0]);
  /* La correspondance a réussi, mais le vecteur de sortie n'était pas assez grand. */
  if (rc == 0)
    {
    rc = OVECCOUNT/3;
    printf("ovector n'a de place que pour %d sous-chaînes capturées\n", rc - 1);
    }

pcredemo(3)




NAME


pcredemo - demonstration program for the PCRE library



SYNOPSIS


pcredemo [options] [pattern [subject...]]



DESCRIPTION


pcredemo est un programme de démonstration qui utilise la bibliothèque PCRE. Il est utile pour tester des expressions régulières et comprendre leur comportement.


Le programme peut être utilisé de différentes manières :


    

  • Si aucun motif et aucun sujet ne sont fournis, il utilise les valeurs par défaut définies dans le code source.
    • 

  • Si un motif est fourni mais aucun sujet, il lit les sujets depuis l'entrée standard jusqu'à la fin du fichier.
    • 

  • Si un motif et un ou plusieurs sujets sont fournis, il traite chaque sujet comme une entrée distincte.
    • 

  • Des options peuvent être passées pour modifier le comportement de la correspondance d'expressions régulières (par exemple, sensibilité à la casse, multiligne, etc.).
    • 




OPTIONS


Les options suivantes peuvent être utilisées pour modifier la façon dont PCRE traite le motif et les correspondances :




-a
Désactive la correspondance des données vides ((?an)).


-b
Désactive la mise en mémoire tampon des données vides ((?bn)).


-c
Désactive la correspondance des caractères ASCII vides ((?cn)).


-d
Désactive la correspondance des lignes vides ((?dn)).


-e
Désactive la correspondance des caractères d'échappement vides ((?en)).


-f
Désactive la correspondance des caractères de fin de ligne vides ((?fn)).


-g
Désactive la correspondance des caractères de début de ligne vides ((?gn)).


-h
Désactive la correspondance des caractères d'espacement vides ((?hn)).


-i
Sensible à la casse.


-m
Mode multiligne.


-n
Mode nominado.


-p
Mode début de chaîne.


-s
Mode "dotall".


-u
Mode Unicode.


-w
Mode mot.


-x
Mode verbeux.





EXEMPLES


Pour rechercher le motif "test" dans la chaîne "This is a test string":


pcredemo "test" "This is a test string"



Pour rechercher le motif "abc" dans plusieurs chaînes, en lisant depuis l'entrée standard:


pcredemo "abc" << EOF
This is the first line.
abc is here.
Another line.
EOF
