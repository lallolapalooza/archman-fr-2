NOM

pcap_set_tstamp_type - définir le type d'horodatage à utiliser par un périphérique de capture

SYNTAXE

#include <pcap/pcap.h>
int pcap_set_tstamp_type(pcap_t *p, int tstamp_type);

DESCRIPTION

pcap_set_tstamp_type() définit le type d'horodatage souhaité pour les paquets capturés sur le descripteur pcap au type spécifié par tstamp_type. Il doit être appelé sur un descripteur pcap créé par pcap_create(3PCAP) qui n'a pas encore été activé par pcap_activate(3PCAP). pcap_list_tstamp_types(3PCAP) fournira une liste des types d'horodatage pris en charge par un périphérique de capture donné. Voir pcap-tstamp(7) pour une liste de tous les types d'horodatage.

VALEUR DE RETOUR

pcap_set_tstamp_type() renvoie 0 en cas de succès si le type d'horodatage spécifié est censé être pris en charge par le périphérique de capture, PCAP_WARNING_TSTAMP_TYPE_NOTSUP si le type d'horodatage spécifié n'est pas pris en charge par le périphérique de capture, PCAP_ERROR_ACTIVATED s'il est appelé sur un descripteur de capture qui a été activé, et PCAP_ERROR_CANTSET_TSTAMP_TYPE si le périphérique de capture ne prend pas en charge la définition du type d'horodatage (seules les anciennes versions de libpcap retourneront cela ; les versions plus récentes autoriseront toujours la définition du type d'horodatage au type par défaut).

COMPATIBILITE ASCENDANTE

Cette fonction est devenue disponible dans la version 1.2.1 de libpcap. Dans les versions précédentes, le type d'horodatage ne peut pas être défini ; seul le type d'horodatage par défaut proposé par une source de capture est disponible.
