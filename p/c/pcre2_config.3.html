PCRE2_CONFIG(3) Manuel des fonctions de bibliothèque PCRE2_CONFIG(3)

NOM

PCRE2 - Expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

int pcre2_config(uint32_t what, void *where);

DESCRIPTION

Cette fonction permet à un programme client de savoir quelles fonctionnalités optionnelles sont disponibles dans la version de la bibliothèque PCRE2 qu'il utilise. Les arguments sont les suivants :


what Un code spécifiant les informations requises
where Pointeur vers l'emplacement où stocker les informations

Si where est NULL, la fonction retourne la quantité de mémoire nécessaire pour les informations demandées. Lorsque les informations sont une chaîne de caractères, la valeur est en unités de code ; pour d'autres types de données, elle est en octets.

Si where n'est pas NULL, pour PCRE2_CONFIG_JITTARGET, PCRE2_CONFIG_UNICODE_VERSION, et PCRE2_CONFIG_VERSION il doit pointer vers un tampon suffisamment grand pour contenir la chaîne. Pour tous les autres codes, il doit pointer vers une variable entière de type uint32_t. Les codes disponibles sont :


PCRE2_CONFIG_BSR Indique ce que \R correspond par défaut :
PCRE2_BSR_UNICODE
PCRE2_BSR_ANYCRLF
PCRE2_CONFIG_COMPILED_WIDTHS Quelles parmi les 8/16/32 ont été compilées
PCRE2_CONFIG_DEPTHLIMIT Limite de retour arrière par défaut
PCRE2_CONFIG_EFFECTIVE_LINKSIZE Nombre d'octets utilisés pour la taille de lien
PCRE2_CONFIG_HEAPLIMIT Limite de mémoire du tas par défaut
PCRE2_CONFIG_JIT Disponibilité du compilateur just-in-time (JIT)
support (1=oui 0=non)
PCRE2_CONFIG_JITTARGET Informations (une chaîne) sur l'architecture cible
pour le compilateur JIT
PCRE2_CONFIG_LINKSIZE Taille de lien interne configurée (2, 3, 4)
PCRE2_CONFIG_MATCHLIMIT Limite de ressources interne par défaut
PCRE2_CONFIG_NEVER_BACKSLASH_C Si \C est désactivé ou non
PCRE2_CONFIG_NEWLINE Code pour la séquence de nouvelle ligne par défaut :
PCRE2_NEWLINE_CR
PCRE2_NEWLINE_LF
PCRE2_NEWLINE_CRLF
PCRE2_NEWLINE_ANY
PCRE2_NEWLINE_ANYCRLF
PCRE2_NEWLINE_NUL
PCRE2_CONFIG_PARENSLIMIT Limite d'imbrication des parenthèses par défaut
PCRE2_CONFIG_RECURSIONLIMIT Obsolète : utiliser PCRE2_CONFIG_DEPTHLIMIT
PCRE2_CONFIG_STACKRECURSE Obsolète : retourne toujours 0
PCRE2_CONFIG_UNICODE Disponibilité du support Unicode
(1=oui 0=non)
PCRE2_CONFIG_UNICODE_VERSION La version Unicode (une chaîne)
PCRE2_CONFIG_VERSION La version PCRE2 (une chaîne)

La fonction retourne une valeur non négative en cas de succès ou la valeur négative PCRE2_ERROR_BADOPTION sinon. C'est également le résultat pour le code PCRE2_CONFIG_JITTARGET si le support JIT n'est pas disponible. Lorsqu'une chaîne est demandée, la fonction retourne le nombre d'unités de code utilisées, y compris le zéro terminateur.

Il y a une description complète de l'API native PCRE2 dans la page pcre2api et une description de l'API POSIX dans la page pcre2posix.
