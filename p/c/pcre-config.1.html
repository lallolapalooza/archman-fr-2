PCRE-CONFIG(1) Manuel des commandes générales PCRE-CONFIG(1)

NOM

pcre-config - programme pour retourner la configuration de PCRE

SYNTAXE

pcre-config [--prefix] [--exec-prefix] [--version] [--libs]
            [--libs16] [--libs32] [--libs-cpp] [--libs-posix]
            [--cflags] [--cflags-posix]

DESCRIPTION

pcre-config retourne la configuration des bibliothèques PCRE installées et les options requises pour compiler un programme afin de les utiliser. Certaines des options s'appliquent uniquement aux bibliothèques 8 bits, 16 bits ou 32 bits, respectivement, et ne sont pas disponibles si une seule de ces bibliothèques a été compilée. Si une option indisponible est rencontrée, les informations d'utilisation sont affichées.

OPTIONS

--prefix
Écrit le préfixe du répertoire utilisé dans l'installation de PCRE pour les fichiers indépendants de l'architecture (/usr sur de nombreux systèmes, /usr/local sur certains systèmes) sur la sortie standard.
--exec-prefix
Écrit le préfixe du répertoire utilisé dans l'installation de PCRE pour les fichiers dépendants de l'architecture (normalement identique à --prefix) sur la sortie standard.
--version
Écrit le numéro de version des bibliothèques PCRE installées sur la sortie standard.
--libs
Écrit sur la sortie standard les options de ligne de commande requises pour lier avec la bibliothèque PCRE 8 bits (-lpcre sur de nombreux systèmes).
--libs16
Écrit sur la sortie standard les options de ligne de commande requises pour lier avec la bibliothèque PCRE 16 bits (-lpcre16 sur de nombreux systèmes).
--libs32
Écrit sur la sortie standard les options de ligne de commande requises pour lier avec la bibliothèque PCRE 32 bits (-lpcre32 sur de nombreux systèmes).
--libs-cpp
Écrit sur la sortie standard les options de ligne de commande requises pour lier avec la bibliothèque d'enrobage C++ de PCRE (-lpcrecpp -lpcre sur de nombreux systèmes).
--libs-posix
Écrit sur la sortie standard les options de ligne de commande requises pour lier avec la bibliothèque d'enrobage API POSIX de PCRE (-lpcreposix -lpcre sur de nombreux systèmes).
--cflags
Écrit sur la sortie standard les options de ligne de commande requises pour compiler des fichiers qui utilisent PCRE (cela peut inclure des options -I, mais est vide sur de nombreux systèmes).
--cflags-posix
Écrit sur la sortie standard les options de ligne de commande requises pour compiler des fichiers qui utilisent la bibliothèque d'enrobage API POSIX de PCRE (cela peut inclure des options -I, mais est vide sur de nombreux systèmes).
