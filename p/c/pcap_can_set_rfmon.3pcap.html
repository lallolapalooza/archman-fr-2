NOM

pcap_can_set_rfmon - vérifier s'il est possible de définir le mode moniteur pour un descripteur de capture non encore activé

SYNTAXE

#include <pcap/pcap.h>
int pcap_can_set_rfmon(pcap_t *p);

DESCRIPTION

pcap_can_set_rfmon() vérifie s'il serait possible de définir le mode moniteur sur un descripteur de capture lors de son activation.

VALEUR DE RETOUR

pcap_can_set_rfmon() renvoie 0 si le mode moniteur ne peut pas être défini, 1 si le mode moniteur peut être défini, et une valeur négative en cas d'erreur. Une valeur de retour négative indique quelle condition d'erreur s'est produite. Les valeurs d'erreur possibles sont :

PCAP_ERROR_NO_SUCH_DEVICE
La source de capture spécifiée lors de la création du descripteur n'existe pas.
PCAP_ERROR_PERM_DENIED
Le processus n'a pas la permission de vérifier si le mode moniteur peut être pris en charge.
PCAP_ERROR_ACTIVATED
Le descripteur de capture a déjà été activé.
PCAP_ERROR
Une autre erreur s'est produite. pcap_geterr(3PCAP) ou pcap_perror(3PCAP) peuvent être appelés avec p comme argument pour récupérer ou afficher un message décrivant l'erreur.

Des codes d'erreur supplémentaires peuvent être ajoutés à l'avenir ; un programme doit vérifier les valeurs de retour 0, 1 et les valeurs négatives, et traiter tous les codes de retour négatifs comme des erreurs. pcap_statustostr(3PCAP) peut être appelé, avec un avertissement ou un code d'erreur comme argument, pour récupérer un message décrivant l'avertissement ou le code d'erreur.

VOIR AUSSI

pcap(3PCAP), pcap_create(3PCAP), pcap_activate(3PCAP), pcap_set_rfmon(3PCAP)
