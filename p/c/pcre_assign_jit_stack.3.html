pcre_assign_jit_stack(3)

Paquet: pcre

Licences: BSD

PCRE_ASSIGN_JIT_STACK(3) Manuel des fonctions de bibliothèque PCRE_ASSIGN_JIT_STACK(3)

NOM

PCRE - Expressions régulières compatibles Perl

SYNTAXE

#include <pcre.h>

void pcre_assign_jit_stack(pcre_extra *extra,
     pcre_jit_callback callback, void *data);

void pcre16_assign_jit_stack(pcre16_extra *extra,
     pcre16_jit_callback callback, void *data);

void pcre32_assign_jit_stack(pcre32_extra *extra,
     pcre32_jit_callback callback, void *data);

DESCRIPTION

Cette fonction permet de contrôler la mémoire utilisée comme pile d'exécution par un appel à pcre[16|32]_exec() avec un motif qui a été compilé avec succès avec l'optimisation JIT. Les arguments sont :


extra le pointeur de données retourné par pcre[16|32]_study()
callback une fonction de rappel
data une pile JIT ou une valeur à passer au rappel
function

Si callback est NULL et data est NULL, un bloc interne de 32 Ko sur la pile de la machine est utilisé.

Si callback est NULL et data n'est pas NULL, data doit être une pile JIT valide, résultat de l'appel à pcre[16|32]_jit_stack_alloc().

Si callback n'est pas NULL, il est appelé avec data comme argument au début de la mise en correspondance, afin de configurer une pile JIT. Si le résultat est NULL, la pile interne de 32 Ko est utilisée ; sinon, la valeur de retour doit être une pile JIT valide, résultat de l'appel à pcre[16|32]_jit_stack_alloc().

Vous pouvez affecter en toute sécurité la même pile JIT à plusieurs motifs, tant qu'ils sont tous mis en correspondance dans le même thread. Dans une application multithread, chaque thread doit utiliser sa propre pile JIT. Pour plus de détails, voir la page pcrejit.

Il existe une description complète de l'API native de PCRE dans la page pcreapi et une description de l'API POSIX dans la page pcreposix.
