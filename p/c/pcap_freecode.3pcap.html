NOM

pcap_freecode - libérer un programme BPF

SYNTAXE

#include <pcap/pcap.h>
void pcap_freecode(struct bpf_program *);

DESCRIPTION

La fonction pcap_freecode() est utilisée pour libérer la mémoire allouée pointée par la structure bpf_program générée par pcap_compile(3PCAP) lorsque ce programme BPF n'est plus nécessaire, par exemple après qu'il a été défini comme programme de filtrage pour une structure pcap par un appel à pcap_setfilter(3PCAP).
