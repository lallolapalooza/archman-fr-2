pcre_get_named_substring(3)

Paquet: pcre

Licences: BSD

PCRE_GET_NAMED_SUBSTRING(3) Manuel des fonctions de bibliothèque PCRE_GET_NAMED_SUBSTRING(3)

NOM

PCRE - expressions régulières compatibles Perl

SYNTAXE

#include <pcre.h>

int pcre_get_named_substring(const pcre *code,
     const char *subject, int *ovector,
     int stringcount, const char *stringname,
     const char **stringptr);

int pcre16_get_named_substring(const pcre16 *code,
     PCRE_SPTR16 subject, int *ovector,
     int stringcount, PCRE_SPTR16 stringname,
     PCRE_SPTR16 *stringptr);

int pcre32_get_named_substring(const pcre32 *code,
     PCRE_SPTR32 subject, int *ovector,
     int stringcount, PCRE_SPTR32 stringname,
     PCRE_SPTR32 *stringptr);

DESCRIPTION

Ceci est une fonction utilitaire pour extraire une sous-chaîne capturée par son nom. Les arguments sont :


code Motif compilé
subject Sujet qui a correspondu avec succès
ovector Vecteur d'offsets que pcre[16|32]_exec() a utilisé
stringcount Valeur retournée par pcre[16|32]_exec()
stringname Nom de la sous-chaîne requise
stringptr Emplacement pour placer le pointeur de la chaîne

La mémoire dans laquelle la sous-chaîne est placée est obtenue en appelant pcre[16|32]_malloc(). La fonction utilitaire pcre[16|32]_free_substring() peut être utilisée pour la libérer lorsqu'elle n'est plus nécessaire. Le résultat de la fonction est la longueur de la sous-chaîne extraite, PCRE_ERROR_NOMEMORY si une mémoire suffisante n'a pas pu être obtenue, ou PCRE_ERROR_NOSUBSTRING si le nom de la chaîne est invalide.

Il y a une description complète de l'API native de PCRE dans la page pcreapi et une description de l'API POSIX dans la page pcreposix.
