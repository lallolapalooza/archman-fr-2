NOM

pcp-python - exécute un script python en utilisant une variante python préférée

SYNTAXE

pcp python [SCRIPT [ARG] ...]

DESCRIPTION

pcp-python a été remplacé par pmpython(1) qui est préféré, cependant pcp-python est toujours installé pour assurer la compatibilité descendante.

pcp-python fournit un moyen d'exécuter des scripts python en utilisant un binaire python personnalisable, plutôt que d'intégrer une version particulière de python dans chaque script.

Cela peut être utile car cela permet d'exécuter du code python indépendant de la version n'importe où. Tous les modules python fournis avec PCP prennent en charge les versions 2.6 et ultérieures (dans la série python2), et 3.3 et ultérieures (dans la série de versions python3).

Étant donné que les scripts de surveillance et de collecte python dans PCP sont relativement simples (ne nécessitant pas de nouveaux modules, de fonctionnalités linguistiques, etc.), il a été possible de garantir leur fonctionnement pour toutes les versions de python ci-dessus. Ainsi, il est courant que les scripts python PCP utilisent une ligne « shebang » qui appelle pcp-python comme suit :


#!/usr/bin/pcp python

Cela permet d'injecter le paramètre personnalisé au lieu d'une version python codée en dur, tout en permettant à l'utilisateur de remplacer la version python comme suit :


$ PCP_PYTHON_PROG=python3 /usr/bin/pcp python --version
Python 3.3.2
$ PCP_PYTHON_PROG=python2 /usr/bin/pcp python --version
Python 2.7.5

Ceci est pratique pour distribuer des scripts identiques sur plusieurs plateformes, et pour tester différentes versions de python avec le même script (par exemple, dans le cas où plusieurs versions de python sont installées, PCP_PYTHON_PROG peut être défini dans l'environnement local pour remplacer le paramètre global).

Par défaut, la valeur de PCP_PYTHON_PROG de /etc/pcp.conf sera utilisée. La valeur par défaut de ce paramètre de configuration est définie en fonction d'heuristiques concernant la plateforme de construction cible. Ces heuristiques privilégient l'utilisation de python3 dans toutes les versions récentes de PCP, pour les plateformes qui le supportent.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. À chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1) et pcp(1).
