PCRE2_SERIALIZE_GET_NUMBER_OF_CODES(3) Manuel des fonctions de bibliothèque PCRE2_SERIALIZE_GET_NUMBER_OF_CODES(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNOPSIS

#include <pcre2.h>

int32_t pcre2_serialize_get_number_of_codes(const uint8_t *bytes);

DESCRIPTION

L'argument bytes doit pointer vers un flux d'octets sérialisé qui a été initialement créé par pcre2_serialize_encode() (bien qu'il ait pu être sauvegardé sur disque ou ailleurs entre-temps). La fonction retourne le nombre de motifs sérialisés dans le flux d'octets, ou l'un des codes d'erreur négatifs suivants :


PCRE2_ERROR_BADMAGIC discordance des octets d'identification dans bytes
PCRE2_ERROR_BADMODE discordance de la taille des unités variables ou de la version PCRE
PCRE2_ERROR_NULL l'argument est NULL

PCRE2_ERROR_BADMAGIC peut signifier que les données sont corrompues, ou qu'elles ont été compilées sur un système avec une endianness différente.

Il existe une description complète de l'API native de PCRE2 dans la page pcre2api et une description des fonctions de sérialisation dans la page pcre2serialize.
