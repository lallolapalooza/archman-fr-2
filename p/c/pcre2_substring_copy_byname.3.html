pcre2_substring_copy_byname(3)

Paquet: pcre2

Licences: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SUBSTRING_COPY_BYNAME(3) Manuel des fonctions de bibliothèque PCRE2_SUBSTRING_COPY_BYNAME(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

int pcre2_substring_copy_byname(pcre2_match_data *match_data,
  PCRE2_SPTR name, PCRE2_UCHAR *buffer, PCRE2_SIZE *bufflen);

DESCRIPTION

Ceci est une fonction utilitaire pour extraire une sous-chaîne capturée, identifiée par son nom, dans un tampon donné. Les arguments sont :


match_data Le bloc de données de correspondance pour la correspondance
name Nom de la sous-chaîne requise
buffer Tampon pour recevoir la chaîne
bufflen Longueur du tampon (unités de code)

La variable bufflen est mise à jour pour contenir la longueur de la chaîne extraite, à l'exclusion du zéro final. Le résultat de la fonction est zéro en cas de succès ou l'un des nombres d'erreur suivants :


PCRE2_ERROR_NOSUBSTRING il n'y a pas de groupes de ce nom
PCRE2_ERROR_UNAVAILBLE l'ovector était trop petit pour ce groupe
PCRE2_ERROR_UNSET le groupe n'a pas participé à la correspondance
PCRE2_ERROR_NOMEMORY le tampon n'est pas assez grand

S'il y a plus d'un groupe portant le nom donné, le premier qui est défini est retourné. Dans cette situation, PCRE2_ERROR_UNSET signifie qu'aucun groupe portant ce nom n'était défini.

Il existe une description complète de l'API native de PCRE2 dans la page pcre2api et une description de l'API POSIX dans la page pcre2posix.
