pcre2_substring_nametable_scan(3)

Paquet: pcre2

Licences: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SUBSTRING_NAMETABLE_SCAN(3) Manuel des fonctions de bibliothèque PCRE2_SUBSTRING_NAMETABLE_SCAN(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNOPSIS

#include <pcre2.h>

int pcre2_substring_nametable_scan(const pcre2_code *code,
  PCRE2_SPTR name, PCRE2_SPTR *first, PCRE2_SPTR *last);

DESCRIPTION

Cette fonction utilitaire trouve, pour un motif compilé, la première et la dernière entrée pour un nom donné dans la table qui traduit les noms des groupes de capture en numéros.


code Expression régulière compilée
name Nom dont les entrées sont requises
first Où retourner un pointeur vers la première entrée
last Où retourner un pointeur vers la dernière entrée

Lorsque le nom est trouvé dans la table, si first est NULL, la fonction retourne un numéro de groupe, mais s'il y a plus d'une entrée correspondante, laquelle est retournée n'est pas définie. Sinon, lorsque les deux pointeurs ont été définis, le résultat de la fonction est la longueur de chaque entrée en unités de code. Si le nom n'est pas trouvé, PCRE2_ERROR_NOSUBSTRING est retourné.

Il y a une description complète de l'API native de PCRE2, y compris le format des entrées de la table, dans la page pcre2api, et une description de l'API POSIX dans la page pcre2posix.
