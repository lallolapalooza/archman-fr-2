PCAP_DUMP_FLUSH(3PCAP) PCAP_DUMP_FLUSH(3PCAP)

NOM

pcap_dump_flush - vider dans un fichier de sauvegarde les paquets sauvegardés

SYNOPSIS

#include <pcap/pcap.h>
int pcap_dump_flush(pcap_dumper_t *p);

DESCRIPTION

pcap_dump_flush() vide le tampon de sortie dans le ``fichier de sauvegarde'', de sorte que tous les paquets écrits avec pcap_dump(3PCAP) mais pas encore écrits dans le ``fichier de sauvegarde'' soient écrits.

VALEUR DE RETOUR

pcap_dump_flush() retourne 0 en cas de succès et PCAP_ERROR en cas d'échec.

VOIR AUSSI

pcap(3PCAP), pcap_dump_open(3PCAP)
