Paquet: libpcap

Licences: BSD-3-Clause

PCAP_OPEN_OFFLINE(3PCAP) PCAP_OPEN_OFFLINE(3PCAP)

NOM

pcap_open_offline, pcap_open_offline_with_tstamp_precision, pcap_fopen_offline, pcap_fopen_offline_with_tstamp_precision - ouvrir un fichier de capture sauvegardé pour lecture

SYNTAXE

#include <pcap/pcap.h>
char errbuf[PCAP_ERRBUF_SIZE];
pcap_t *pcap_open_offline(const char *fname, char *errbuf);
pcap_t *pcap_open_offline_with_tstamp_precision(const char *fname,
    u_int precision, char *errbuf);
pcap_t *pcap_fopen_offline(FILE *fp, char *errbuf);
pcap_t *pcap_fopen_offline_with_tstamp_precision(FILE *fp,
    u_int precision, char *errbuf);

DESCRIPTION

pcap_open_offline() et pcap_open_offline_with_tstamp_precision() sont appelées pour ouvrir un « fichier de sauvegarde » pour lecture.

fname spécifie le nom du fichier à ouvrir. Le fichier peut avoir le format de fichier pcap tel que décrit dans pcap-savefile(5), qui est le format de fichier utilisé par, entre autres programmes, tcpdump(1) et tcpslice(1), ou peut avoir le format de fichier pcapng, bien que tous les fichiers pcapng ne puissent pas être lus. Le nom "-" est un synonyme de stdin.

pcap_open_offline_with_tstamp_precision() prend un argument supplémentaire precision spécifiant la précision de l'horodatage désirée ; si PCAP_TSTAMP_PRECISION_MICRO est spécifié, les horodatages des paquets seront fournis en secondes et en microsecondes, et si PCAP_TSTAMP_PRECISION_NANO est spécifié, les horodatages des paquets seront fournis en secondes et en nanosecondes. Si les horodatages dans le fichier n'ont pas la même précision que la précision demandée, ils seront mis à l'échelle vers le haut ou vers le bas selon les besoins avant d'être fournis.

Alternativement, vous pouvez appeler pcap_fopen_offline() ou pcap_fopen_offline_with_tstamp_precision() pour lire les données capturées à partir d'un flux existant et ouvert fp. pcap_fopen_offline_with_tstamp_precision() prend un argument supplémentaire precision comme décrit ci-dessus. Notez que sous Windows, ce flux doit être ouvert en mode binaire.

errbuf est un tampon suffisamment grand pour contenir au moins PCAP_ERRBUF_SIZE caractères.

VALEUR DE RETOUR

pcap_open_offline(), pcap_open_offline_with_tstamp_precision(), pcap_fopen_offline(), et pcap_fopen_offline_with_tstamp_precision() retournent un pcap_t * en cas de succès et NULL en cas d'échec. Si NULL est retourné, errbuf est rempli avec un message d'erreur approprié.

COMPATIBILITE ASCENDANTE

pcap_open_offline_with_tstamp_precision() et pcap_fopen_offline_with_tstamp_precision() sont disponibles depuis la version 1.5.1 de libpcap. Dans les versions précédentes, les horodatages d'un fichier de sauvegarde sont toujours donnés en secondes et en microsecondes.
