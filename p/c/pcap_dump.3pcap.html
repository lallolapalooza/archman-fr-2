NOM

pcap_dump - écrire un paquet dans un fichier de capture

SYNTAXE

#include <pcap/pcap.h>
void pcap_dump(u_char *user, struct pcap_pkthdr *h,
    u_char *sp);

DESCRIPTION

pcap_dump() écrit un paquet dans le ``fichier de sauvegarde'' ouvert avec pcap_dump_open(3PCAP). Notez que ses arguments d'appel sont adaptés pour être utilisés avec pcap_dispatch(3PCAP) ou pcap_loop(3PCAP). S'il est appelé directement, le paramètre user est de type pcap_dumper_t tel que retourné par pcap_dump_open().
