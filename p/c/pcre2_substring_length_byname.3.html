pcre2_substring_length_byname(3)

Paquet: pcre2

Licences: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SUBSTRING_LENGTH_BYNAME(3) Manuel de la bibliothèque PCRE2_SUBSTRING_LENGTH_BYNAME(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

int pcre2_substring_length_byname(pcre2_match_data *match_data,
  PCRE2_SPTR name, PCRE2_SIZE *length);

DESCRIPTION

Cette fonction retourne la longueur d'une sous-chaîne correspondante, identifiée par son nom. Les arguments sont :


match_data Bloc de données de correspondance pour la correspondance
name Nom de la sous-chaîne
length Emplacement où retourner la longueur, ou NULL

Le troisième argument peut être NULL si tout ce que vous voulez savoir est si une sous-chaîne est définie ou non. Le retour est zéro en cas de succès, ou un code d'erreur négatif sinon.

Une description complète de l'API native de PCRE2 se trouve sur la page pcre2api et une description de l'API POSIX se trouve sur la page pcre2posix.
