NOM

pcap_lookupnet - trouver le numéro de réseau et le masque IPv4 d'un périphérique

SYNTAXE

#include <pcap/pcap.h>
char errbuf[PCAP_ERRBUF_SIZE];
int pcap_lookupnet(const char *device, bpf_u_int32 *netp,
    bpf_u_int32 *maskp, char *errbuf);

DESCRIPTION

pcap_lookupnet() est utilisé pour déterminer le numéro de réseau IPv4 et le masque associés au périphérique réseau device. Les pointeurs netp et maskp sont de type bpf_u_int32. errbuf est un tampon suffisamment grand pour contenir au moins PCAP_ERRBUF_SIZE caractères.

Cette fonction n'est pas disponible sous Windows. Elle ne prend en charge ni l'IPv6 ni plusieurs adresses IPv4 par interface, ce qui n'est évidemment pas pratique dans les réseaux modernes. Voir pcap_findalldevs(3PCAP) pour une solution plus élaborée au problème.

VALEUR DE RETOUR

pcap_lookupnet() retourne 0 en cas de succès et PCAP_ERROR en cas d'échec. Si PCAP_ERROR est retourné, errbuf est rempli avec un message d'erreur approprié.
