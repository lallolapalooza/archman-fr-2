PCP-ATOPRC(5) Manual des formats de fichiers PCP-ATOPRC(5)

NOM

pcp-atoprc - Fichier de ressources pcp-atop et pcp-atopsar

DESCRIPTION

Cette page de manuel documente le fichier de ressources des commandes pcp-atop et pcp-atopsar. Ces commandes peuvent être utilisées pour surveiller la charge du système et des processus sur un système.

Le fichier pcp-atoprc contient les paramètres par défaut. Ces paramètres sont lus au démarrage, d'abord à partir du fichier rc système /etc/atoprc, puis à partir du fichier rc spécifique à l'utilisateur ~/.atoprc (les paramètres système peuvent donc être outrepassés par un utilisateur individuel). Les options des deux fichiers rc sont identiques.

OPTIONS

Le fichier rc contient des paires mot-clé-valeur, une par ligne (les lignes vides et celles commençant par un signe # sont ignorées).
Les mots-clés suivants peuvent être spécifiés :

flags
Une liste d'indicateurs par défaut pour pcp-atop peut être définie ici. Les indicateurs autorisés sont 'B', 'H', 'g', 'm', 'd', 'n', 'u', 'p', 's', 'c', 'v', 'C', 'M', 'D', 'N', 'A', 'a', 'y', 'f', 'F', 'G', 'R', '1', 'e', 'E' et 'x'.
interval
La valeur de l'intervalle par défaut en secondes.
linelen
La longueur d'une ligne d'écran lors de l'envoi de la sortie vers un fichier ou un tube (par défaut 80).
username
L'expression régulière par défaut pour les utilisateurs dont les processus actifs seront affichés.
procname
L'expression régulière par défaut pour les noms de processus à afficher.
maxlinecpu
Le nombre maximum de CPU actifs qui seront affichés.
maxlinegpu
Le nombre maximum de GPU actifs qui seront affichés.
maxlinelvm
Le nombre maximum de volumes logiques actifs qui seront affichés.
maxlinemdd
Le nombre maximum de périphériques multiples actifs qui seront affichés.
maxlinedisk
Le nombre maximum de disques actifs qui seront affichés.
maxlinenfsm
Le nombre maximum de montages NFS qui seront affichés sur un client NFS.
maxlineintf
Le nombre maximum d'interfaces réseau actives qui seront affichés.
maxlinecont
Le nombre maximum de conteneurs actifs qui seront affichés.
cpucritperc
Le pourcentage d'utilisation considéré comme critique pour un processeur (voir la section COULEURS dans la page de manuel de la commande pcp-atop). Ce pourcentage est utilisé pour déterminer un pourcentage pondéré pour la coloration des lignes et le tri des processus actifs en mode texte. Lorsque cette valeur est nulle, aucune coloration de ligne ou tri automatique n'est effectué pour cette ressource.
dskcritperc
Le pourcentage d'utilisation considéré comme critique pour un disque (voir la section COULEURS dans la page de manuel de la commande pcp-atop). Ce pourcentage est utilisé pour déterminer un pourcentage pondéré pour la coloration des lignes et le tri des processus actifs en mode texte. Lorsque cette valeur est nulle, aucune coloration de ligne ou tri automatique n'est effectué pour cette ressource.
netcritperc
Le pourcentage d'utilisation considéré comme critique pour une interface réseau (voir la section COULEURS dans la page de manuel de la commande pcp-atop). Ce pourcentage est utilisé pour déterminer un pourcentage pondéré pour la coloration des lignes et le tri des processus actifs en mode texte. Lorsque cette valeur est nulle, aucune coloration de ligne ou tri automatique n'est effectué pour cette ressource.
memcritperc
Le pourcentage d'utilisation considéré comme critique pour la mémoire (voir la section COULEURS dans la page de manuel de la commande pcp-atop). Ce pourcentage est utilisé pour déterminer un pourcentage pondéré pour la coloration des lignes et le tri des processus actifs en mode texte. Lorsque cette valeur est nulle, aucune coloration de ligne ou tri automatique n'est effectué pour cette ressource.
swpcritperc
Le pourcentage d'occupation considéré comme critique pour l'espace d'échange (swap) (voir la section COULEURS dans la page de manuel de la commande pcp-atop). Ce pourcentage est utilisé pour déterminer un pourcentage pondéré pour la coloration des lignes et le tri des processus actifs. Lorsque cette valeur est nulle, aucune coloration de ligne ou tri automatique n'est effectué pour cette ressource.
swoutcritsec
Le nombre de pages échangées par seconde considéré comme critique pour l'utilisation de la mémoire (voir la section COULEURS dans la page de manuel de la commande pcp-atop). Ce seuil est utilisé en combinaison avec 'memcritperc' pour déterminer un pourcentage pondéré pour la coloration des lignes et le tri des processus actifs. Lorsque cette valeur est nulle, aucune coloration de ligne ou tri automatique n'est effectué pour cette ressource.
almostcrit
Un pourcentage du pourcentage critique pour déterminer si la ressource est presque critique (voir la section COULEURS dans la page de manuel de la commande pcp-atop). Lorsque cette valeur est nulle, aucune coloration de ligne pour 'presque critique' n'est effectuée.
cpubarwidth
Nombre de colonnes utilisées par barre dans le graphique en barres des processeurs. La valeur par défaut est 0, ce qui signifie que la largeur de la barre sera mise à l'échelle automatiquement (plus le terminal est large, plus il y a de colonnes par barre, jusqu'à un maximum de trois). Avec les valeurs 1, 2 ou 3, le nombre de barres peut être fixé statiquement à ce nombre de colonnes, avec une colonne d'espaces blancs entre les barres.
colorinfo
Définition du nom de couleur pour les messages d'information (par défaut : vert) en mode texte.
Les couleurs autorisées sont : rouge vert jaune bleu magenta cyan noir blanc.
colorthread
Définition du nom de couleur pour les lignes spécifiques aux threads lors de l'utilisation de l'option 'y' (par défaut : jaune).
Les couleurs autorisées sont : rouge vert jaune bleu magenta cyan noir blanc.
coloralmost
Définition du nom de couleur pour les ressources presque critiques (par défaut : cyan) en mode texte.
Les couleurs autorisées sont : rouge vert jaune bleu magenta cyan noir blanc.
colorcritical
Définition du nom de couleur pour les ressources critiques (par défaut : rouge) en mode texte.
Les couleurs autorisées sont : rouge vert jaune bleu magenta cyan noir blanc.
pcp-atopsarflags
Une liste d'indicateurs par défaut pour pcp-atopsar peut être définie ici. Les indicateurs autorisés sont 'S', 'x', 'C', 'M', 'H', 'a', 'A' ainsi que les indicateurs pour sélectionner un ou plusieurs rapports spécifiques.

Un exemple du fichier /etc/atoprc ou ~/.atoprc :

 

flags         Aaf
interval      5
username
procname
maxlinecpu    4
maxlinedisk   10
maxlineintf   5
cpucritperc   80
almostcrit    90
pcp-atopsarflags  CMH
ownprocline   PID:50 VGROW:40 RGROW:45 COMMAND-LINE:50
ownpagline    PAGSCAN:3 BLANKBOX:0 PAGSWIN:3 PAGSWOUT:7

Les mots-clés 'ownprocline' et 'ownpagline' sont expliqués dans la section suivante.

définir la disposition d'une ligne avec des informations de processus avec le mot-clé 'ownprocline' (à sélectionner avec la touche 'o' ou l'indicateur -o) et vous pouvez redéfinir toutes les lignes avec des informations système.

La disposition d'une ligne de sortie peut être définie comme suit (notez que cela doit être spécifié sur une seule ligne dans le fichier rc) :

   mot-clé   <idcolonne>:<prio> [<idcolonne>:<prio> ...]

L'idcolonne est le nom symbolique d'une colonne qui doit être affichée à cette position dans la ligne de sortie.
La prio est un entier positif qui détermine quelles colonnes ont la priorité lorsque toutes les colonnes spécifiées ne rentrent pas dans la largeur actuelle de l'écran. Plus la valeur est élevée, plus la priorité est élevée.
Les spécifications de colonnes doivent être séparées par un espace. L'ordre dans lequel les colonnes ont été spécifiées est l'ordre dans lequel elles seront affichées, par rapport à leur priorité (les colonnes qui ne rentrent pas seront supprimées dynamiquement).

Un idcolonne spécial pour les lignes système est 'BLANKBOX'. Cela indique qu'une colonne vide est requise à cette position. Cet idcolonne spécial est également suivi d'une priorité (généralement faible).

La définition suivante peut être spécifiée pour les informations de processus :

ownprocline
Les idcolonnes sont les noms des colonnes qui sont affichées dans la sortie normale des lignes relatives aux processus affichées par pcp-atop, telles que 'PID', 'CMD', 'S', .... La seule exception est l'idcolonne spécial 'SORTITEM' qui est utilisé pour afficher l'une des colonnes CPU%/DSK%/MEM%/NET%, en fonction du critère de tri choisi.
Un exemple de ligne de processus définie par l'utilisateur :
 
ownprocline   PID:20 PPID:10 SYSCPU:15 USRCPU:15 VGROW:14 VSIZE:12 RGROW:14 RSIZE:12 ST:8 EXC:7 S:11 SORTITEM:18 CMD:20

Les définitions suivantes sont utilisées en interne par pcp-atop comme lignes système par défaut (vous pouvez redéfinir chacune d'elles dans le fichier rc sur une seule ligne) :

ownsysprcline
Redéfinition de la ligne étiquetée 'PRC' :
 
ownsysprcline   PRCSYS:8 PRCUSER:8 BLANKBOX:0 PRCNPROC:7 PRCNZOMBIE:5 PRCCLONES:4 BLANKBOX:0 PRCNNEXIT:6
ownallcpuline
Redéfinition de la ligne étiquetée 'CPU' pour l'utilisation totale du CPU :
 
ownallcpuline   CPUSYS:8 CPUUSER:7 CPUIRQ:4 BLANKBOX:0 CPUIDLE:5 CPUWAIT:6 BLANKBOX:0 CPUSTEAL:1 CPUGUEST:3
ownonecpuline
Redéfinition de la ligne étiquetée 'CPU' pour l'utilisation d'un seul CPU :
 
ownonecpuline   CPUISYS:8 CPUIUSER:7 CPUIIRQ:4 BLANKBOX:0 CPUIIDLE:5 CPUIWAIT:6 BLANKBOX:0 CPUISTEAL:1 CPUIGUEST:3
owncplline
Redéfinition de la ligne étiquetée 'CPL' :
 
owncplline   CPLAVG1:4 CPLAVG5:3 CPLAVG15:2 BLANKBOX:0 CPLCSW:6 CPLINTR:5 BLANKBOX:0 CPLNUMCPU:1
ownmemline
Redéfinition de la ligne étiquetée 'MEM' :
 
ownmemline   MEMTOT:2 MEMFREE:5 MEMCACHE:3 MEMDIRTY:1 MEMBUFFER:3 MEMSLAB:3 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0
ownswpline
Redéfinition de la ligne étiquetée 'SWP' :
 
ownswpline   SWPTOT:3 SWPFREE:4 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 SWPCOMMITTED:5 SWPCOMMITLIM:6
ownpagline
Redéfinition de la ligne étiquetée 'PAG' :
 
ownpagline   PAGSCAN:3 PAGSTALL:1 BLANKBOX:0 PAGSWIN:4 PAGSWOUT:3
owndskline
Redéfinition des lignes étiquetées 'LVM', 'MDD' et 'DSK' :
 
owndskline   DSKNAME:8 DSKBUSY:7 DSKNREAD:6 DSKNWRITE:6 DSKKBPERRD:4 DSKKBPERWR:4 DSKMBPERSECRD:5 DSKMBPERSECWR:5 DSKAVQUEUE:1 DSKAVIO:5
ownnettrline
Redéfinition de la ligne étiquetée 'NET' pour le transport :
 
ownnettrline   NETTRANSPORT:9 NETTCPI:8 NETTCPO:8 NETUDPI:8 NETUDPO:8 NETTCPACTOPEN:6 NETTCPPASVOPEN:5 NETTCPRETRANS:4 NETTCPINERR:3 NETTCPORESET:20 NETUDPNOPORT:1 NETUDPINERR:3
ownnetnetline
Redéfinition de la ligne étiquetée 'NET' pour le réseau :
 
ownnetnetline   NETNETWORK:5 NETIPI:4 NETIPO:4 NETIPFRW:4 NETIPDELIV:4 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 NETICMPIN:1 NETICMPOUT:1
ownnetifline
Redéfinition de la ligne étiquetée 'NET' pour les interfaces :
 
ownnetifline   NETNAME:8 NETPCKI:7 NETPCKO:7 NETSPEEDIN:6 NETSPEEDOUT:6 NETCOLLIS:3 NETMULTICASTIN:2 NETRCVERR:5 NETSNDERR:5 NETRCVDROP:4 NETSNDDROP:4

Les lignes ci-dessus sont affichées dans l'ordre défini par pcp-atop en combinaison avec l'option -f (dans une fenêtre très large, vous devriez pouvoir voir toutes les colonnes).
