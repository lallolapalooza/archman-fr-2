PCRE2_DFA_MATCH(3) Manuel des fonctions de bibliothèque PCRE2_DFA_MATCH(3)

NOM

PCRE2 - Expressions régulières compatibles Perl (API révisée)

SYNOPSIS

#include <pcre2.h>

int pcre2_dfa_match(const pcre2_code *code, PCRE2_SPTR subject,
  PCRE2_SIZE length, PCRE2_SIZE startoffset,
  uint32_t options, pcre2_match_data *match_data,
  pcre2_match_context *mcontext,
  int *workspace, PCRE2_SIZE wscount);

DESCRIPTION

Cette fonction met en correspondance une expression régulière compilée avec une chaîne de sujet donnée, en utilisant un algorithme de correspondance alternatif qui analyse la chaîne de sujet une seule fois (sauf lors du traitement des assertions de regard). Cette fonction n'est *pas* compatible avec Perl (la fonction de correspondance compatible avec Perl est pcre2_match()). Les arguments de cette fonction sont :


code Pointeur vers le motif compilé
subject Pointeur vers la chaîne de sujet
length Longueur de la chaîne de sujet
startoffset Décalage dans le sujet où commencer la correspondance
options Bits d'options
match_data Pointeur vers un bloc de données de correspondance, pour les résultats
mcontext Pointeur vers un contexte de correspondance, ou est NULL
workspace Pointeur vers un vecteur d'entiers utilisé comme espace de travail
wscount Nombre d'éléments dans le vecteur

La taille du vecteur de sortie nécessaire pour contenir tous les résultats dépend du nombre de correspondances simultanées, et non du nombre de parenthèses dans le motif. L'utilisation de pcre2_match_data_create_from_pattern() pour créer le bloc de données de correspondance n'est donc pas conseillée lors de l'utilisation de cette fonction.

Un contexte de correspondance n'est nécessaire que si vous souhaitez configurer une fonction d'appel (callout function) ou spécifier la limite du tas (heap limit) ou la limite de profondeur de correspondance ou de récursion. Les valeurs length et startoffset sont des unités de code, pas des caractères. Les options sont :


PCRE2_ANCHORED Ne faire correspondre qu'à la première position
PCRE2_COPY_MATCHED_SUBJECT
En cas de succès, faire une copie privée du sujet
PCRE2_ENDANCHORED Le motif ne peut correspondre qu'à la fin du sujet
PCRE2_NOTBOL Le sujet n'est pas le début d'une ligne
PCRE2_NOTEOL Le sujet n'est pas la fin d'une ligne
PCRE2_NOTEMPTY Une chaîne vide n'est pas une correspondance valide
PCRE2_NOTEMPTY_ATSTART Une chaîne vide au début du sujet
n'est pas une correspondance valide
PCRE2_NO_UTF_CHECK Ne pas vérifier la validité UTF du sujet
(uniquement pertinent si PCRE2_UTF
a été défini lors de la compilation)
PCRE2_PARTIAL_HARD Retourner PCRE2_ERROR_PARTIAL pour une correspondance partielle
même s'il existe une correspondance complète
PCRE2_PARTIAL_SOFT Retourner PCRE2_ERROR_PARTIAL pour une correspondance partielle
si aucune correspondance complète n'est trouvée
PCRE2_DFA_RESTART Redémarrer après une correspondance partielle
PCRE2_DFA_SHORTEST Retourner uniquement la correspondance la plus courte

Il existe des restrictions sur ce qui peut apparaître dans un motif lors de l'utilisation de cette fonction de correspondance. Les détails sont donnés dans la documentation pcre2matching. Pour les détails sur la correspondance partielle, voir la page pcre2partial. Une description complète de l'API native de PCRE2 se trouve sur la page pcre2api et une description de l'API POSIX se trouve sur la page pcre2posix.
