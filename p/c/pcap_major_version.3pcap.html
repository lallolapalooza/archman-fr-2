NOM

pcap_major_version, pcap_minor_version - obtenir le numéro de version d'un fichier de sauvegarde

SYNTAXE

#include <pcap/pcap.h>
int pcap_major_version(pcap_t *p);
int pcap_minor_version(pcap_t *p);

DESCRIPTION

Si p fait référence à un « fichier de sauvegarde », pcap_major_version() renvoie le numéro majeur du format de fichier du « fichier de sauvegarde » et pcap_minor_version() renvoie le numéro mineur du format de fichier du « fichier de sauvegarde ». Le numéro de version est stocké dans le « fichier de sauvegarde » ; notez que le sens de ses valeurs dépend du type de « fichier de sauvegarde » (par exemple, pcap ou pcapng).

Si p fait référence à une capture en direct, les valeurs renvoyées par pcap_major_version() et pcap_minor_version() ne sont pas significatives.
