PCP-PS(1) Manuel des commandes générales PCP-PS(1)

NOM

pcp-ps - Rapport de statistiques pour les processus Linux.

SYNTAXE

pcp [options pcp] ps [-e] [-U [nom_utilisateur]] [-V --version] [-c nom_commande] [-P pid1,pid2..] [-p pid1,pid2..] [-o col1,col2... ou TOUT] [-Z fuseau_horaire] [-z] [-?]

DESCRIPTION

La commande pcp-ps est utilisée pour surveiller les processus individuels en cours d'exécution sur le système. Grâce à diverses options, elle aide l'utilisateur à afficher des informations utiles relatives aux processus. Ces informations comprennent le pourcentage d'utilisation du CPU, l'utilisation de la mémoire et de la pile, la planification et la priorité. Par défaut, pcp-ps affiche des données en direct pour l'hôte local.

OPTIONS

Lorsqu'elle est invoquée via la commande pcp(1), les options -h/--host, -O/--origin, -t/--interval, -Z/--timezone et plusieurs autres options pcp sont indirectement disponibles ; référez-vous à PCPIntro(1) pour une description complète de ces options.

Les options de ligne de commande supplémentaires disponibles pour pcp-ps sont :

-e
Afficher tous les processus.
PID Identifiant du processus.
TTY Le terminal associé au processus.
TIME Le temps CPU cumulé au format [JJ-]HH:MM:SS (temps=TIME).
CMD Le nom de la tâche ainsi que ses arguments complets.
-c [nom_commande]
Afficher le nom réel de la commande des tâches surveillées au lieu de l'UID. Si nom_commande est spécifié, seules les tâches appartenant à la commande spécifiée sont affichées.
-U [nom_utilisateur], --nom-utilisateur[=nom_utilisateur]
Afficher le nom réel de l'utilisateur des tâches surveillées au lieu de l'UID. Si nom_utilisateur est spécifié, seules les tâches appartenant à l'utilisateur spécifié sont affichées.
-V, --version
Afficher le numéro de version puis quitter.
-p pid1,pid2.., --liste-pid=pid1,pid2..
Afficher uniquement les processus avec les PID listés.
-P ppid1,ppid2.., --liste-ppid=ppid1,ppid2..
Afficher uniquement les processus avec les PPID listés.
-o
Format défini par l'utilisateur.

C'est un argument unique sous la forme d'une liste séparée par des espaces ou des virgules, offrant un moyen de spécifier les colonnes de sortie individuelles.

Les arguments de -o sont les suivants :

COL EN-TÊTE DESCRIPTION

args COMMANDE Pour afficher le nom complet du programme avec ses arguments (utiliser en dernière position dans la liste -o pour voir la commande complète)

ppid PPID Identifiant du processus parent
pri PRI Priorité du processus

SPÉCIFICATEURS DE FORMAT STANDARDS

Voici les différents mots-clés qui peuvent être utilisés pour contrôler le format de sortie (par exemple avec l'option -o) ou pour trier les processus sélectionnés

Par exemple : pcp-ps -o pid,user,args

CODE EN-TÊTE DESCRIPTION
pid PID un nombre représentant l'identifiant du processus
%cpu %CPU utilisation %cpu du processus au format « ##.# ». Actuellement, il s'agit du temps CPU utilisé divisé par le temps pendant lequel le processus s'exécute (ratio tempscpu/tempsréel), exprimé en pourcentage.
%mem %MEM % de la taille du jeu résident du processus par rapport à la mémoire physique de la machine, exprimé en pourcentage.
args COMMANDE Commande avec tous ses arguments sous forme de chaîne. Des modifications aux arguments peuvent être affichées. La sortie dans cette colonne peut contenir des espaces. Un processus marqué <défunt> est partiellement mort, attendant d'être complètement détruit par son parent. Parfois, les arguments du processus ne seront pas disponibles ; lorsque cela se produit, le nom de l'exécutable sera affiché entre crochets.
class CLS classe de planification du processus. Les valeurs possibles du champ sont : - non rapporté TS SCHED_OTHER FF SCHED_FIFO RR SCHED_RR B SCHED_BATCH ISO SCHED_ISO IDL SCHED_IDLE DLN SCHED_DEADLINE ? valeur inconnue
s S affichage minimal de l'état. Voir aussi state si vous souhaitez afficher des informations supplémentaires.
euid EUID identifiant d'utilisateur effectif.
vsz VSZ taille de la mémoire virtuelle du processus en KiB (unités de 1024 octets). Les mappings de périphériques sont actuellement exclus ; ceci est sujet à changement.
euser EUSER nom d'utilisateur effectif. Ce sera l'ID utilisateur textuel, s'il peut être obtenu et que la largeur du champ le permet, ou une représentation décimale sinon.
All N/A Cette option affiche UTILISATEUR, PID, PPID, PRI, %CPU, %MEM, VSZ, RSS, S, DÉBUT, TEMPS, WCHAN et COMMANDE.
-Z fuseau_horaire, --fuseau-horaire=fuseau_horaire

NOTES

pcp-ps est inspiré de la commande ps(1) et vise à être compatible avec celle-ci en termes de ligne de commande et de sortie.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

Pour les variables d'environnement affectant les outils PCP, voir pmGetOptions(3).
