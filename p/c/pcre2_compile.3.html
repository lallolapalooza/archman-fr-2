pcre2_compile(3)

Paquet: pcre2

Licences: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_COMPILE(3) Manuel des fonctions de bibliothèque PCRE2_COMPILE(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

pcre2_code *pcre2_compile(PCRE2_SPTR pattern, PCRE2_SIZE length,
  uint32_t options, int *errorcode, PCRE2_SIZE *erroroffset,
  pcre2_compile_context *ccontext);

DESCRIPTION

Cette fonction compile une expression régulière en une forme interne. Ses arguments sont :


pattern Chaîne contenant l'expression à compiler
length Longueur de la chaîne ou PCRE2_ZERO_TERMINATED
options Bits d'options primaires
errorcode Où placer un code d'erreur
erroffset Où placer un décalage d'erreur
ccontext Pointeur vers un contexte de compilation ou NULL

La longueur du motif et tout décalage d'erreur retourné sont en unités de code, pas en caractères. Un motif NULL de longueur zéro est traité comme une chaîne vide. Un contexte de compilation n'est nécessaire que si vous souhaitez fournir des fonctions d'allocation de mémoire personnalisées, ou pour fournir une fonction externe pour la vérification de la taille de la pile système (voir pcre2_set_compile_recursion_guard()), ou pour modifier un ou plusieurs des paramètres suivants :


Ce que \R correspond (nouvelles lignes Unicode, ou CR, LF, CRLF uniquement) ;
Tables de caractères de PCRE2 ;
Séquence de caractères de nouvelle ligne ;
Limite de parenthèses imbriquées au moment de la compilation ;
Longueur maximale du motif (en unités de code) autorisée ;
Bits d'options supplémentaires.

Les bits d'options primaires sont :


PCRE2_ANCHORED Force l'ancrage du motif
PCRE2_ALLOW_EMPTY_CLASS Autorise les classes vides
PCRE2_ALT_BSUX Gestion alternative de \u, \U et \x
PCRE2_ALT_CIRCUMFLEX Gestion alternative de ^ en mode multiligne
PCRE2_ALT_EXTENDED_CLASS Syntaxe alternative de classes de caractères étendues
PCRE2_ALT_VERBNAMES Traite les antislashs dans les noms de verbes
PCRE2_AUTO_CALLOUT Compile les appels automatiques
PCRE2_CASELESS Recherche insensible à la casse
PCRE2_DOLLAR_ENDONLY $ ne correspond pas à la nouvelle ligne à la fin
PCRE2_DOTALL . correspond à tout, y compris NL
PCRE2_DUPNAMES Autorise les noms dupliqués pour les sous-motifs
PCRE2_ENDANCHORED Le motif ne peut correspondre qu'à la fin du sujet
PCRE2_EXTENDED Ignore les espaces blancs et les commentaires #
PCRE2_FIRSTLINE Force la correspondance avant la nouvelle ligne
PCRE2_LITERAL Les caractères du motif sont tous littéraux
PCRE2_MATCH_INVALID_UTF Active la prise en charge de la correspondance des UTF invalides
PCRE2_MATCH_UNSET_BACKREF Correspond aux contre-références non définies
PCRE2_MULTILINE ^ et $ correspondent aux nouvelles lignes dans les données
PCRE2_NEVER_BACKSLASH_C Verrouille l'utilisation de \C dans les motifs
PCRE2_NEVER_UCP Verrouille PCRE2_UCP, par exemple via (*UCP)
PCRE2_NEVER_UTF Verrouille PCRE2_UTF, par exemple via (*UTF)
PCRE2_NO_AUTO_CAPTURE Désactive les parenthèses capturantes numérotées
(les nommées sont disponibles)
PCRE2_NO_AUTO_POSSESS Désactive la possessification automatique
PCRE2_NO_DOTSTAR_ANCHOR Désactive l'ancrage automatique pour .*
PCRE2_NO_START_OPTIMIZE Désactive les optimisations de démarrage au moment de la correspondance
PCRE2_NO_UTF_CHECK Ne vérifie pas la validité UTF du motif
(ne s'applique que si PCRE2_UTF est défini)
PCRE2_UCP Utilise les propriétés Unicode pour \d, \w, etc.
PCRE2_UNGREEDY Inverse la gourmandise des quantificateurs
PCRE2_USE_OFFSET_LIMIT Active la limite de décalage pour les correspondances non ancrées
PCRE2_UTF Traite les motifs et les sujets comme des chaînes UTF

PCRE2 doit être compilé avec le support Unicode (par défaut) pour pouvoir utiliser PCRE2_UTF, PCRE2_UCP et les options associées.

Des options supplémentaires peuvent être définies dans le contexte de compilation via la fonction pcre2_set_compile_extra_options.

Si l'un des arguments errorcode ou erroroffset est NULL, la fonction retourne NULL immédiatement. Sinon, le résultat de cette fonction est un pointeur vers une structure de données privée contenant le motif compilé, ou NULL si une erreur a été détectée. En cas d'erreur, un message d'erreur textuel peut être obtenu en passant la valeur retournée via l'argument errorcode à la fonction pcre2_get_error_message(). Le décalage (en unités de code) où l'erreur a été rencontrée est retourné via l'argument erroroffset.

En l'absence d'erreur, la valeur passée via errorcode retourne le message "no error" si elle est passée à pcre2_get_error_message(), et la valeur passée via erroroffset est zéro.

Il existe une description complète de l'API native de PCRE2, avec plus de détails sur chaque option, dans la page pcre2api, et une description de l'API POSIX dans la page pcre2posix.
