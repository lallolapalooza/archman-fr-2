pcre_config(3)

Paquet: pcre

Licences: BSD

PCRE_CONFIG(3) Manuel des fonctions de bibliothèque PCRE_CONFIG(3)

NOM

PCRE - Expressions régulières compatibles Perl

SYNTAXE

#include <pcre.h>

int pcre_config(int what, void *where);

int pcre16_config(int what, void *where);

int pcre32_config(int what, void *where);

DESCRIPTION

Cette fonction permet à un programme client de savoir quelles fonctionnalités optionnelles sont disponibles dans la version de la bibliothèque PCRE qu'il utilise. Les arguments sont les suivants :


what Un code spécifiant les informations demandées
where Pointeur vers l'emplacement où stocker les données

L'argument where doit pointer vers une variable entière, sauf pour PCRE_CONFIG_MATCH_LIMIT, PCRE_CONFIG_MATCH_LIMIT_RECURSION et PCRE_CONFIG_PARENS_LIMIT, où il doit pointer vers un entier non signé long, et pour PCRE_CONFIG_JITTARGET, où il doit pointer vers un char* constant. Les codes disponibles sont :


PCRE_CONFIG_JIT Disponibilité du compilateur juste-à-temps
(1=oui, 0=non)
PCRE_CONFIG_JITTARGET Chaîne contenant des informations sur
l'architecture cible pour le compilateur JIT,
ou NULL s'il n'y a pas de support JIT
PCRE_CONFIG_LINK_SIZE Taille interne des liens : 2, 3 ou 4
PCRE_CONFIG_PARENS_LIMIT Limite de profondeur de nidification des parenthèses
PCRE_CONFIG_MATCH_LIMIT Limite de ressources internes
PCRE_CONFIG_MATCH_LIMIT_RECURSION
Limite de profondeur de récursion interne
PCRE_CONFIG_NEWLINE Valeur de la séquence de nouvelle ligne par défaut :
13 (0x000d) pour CR
10 (0x000a) pour LF
3338 (0x0d0a) pour CRLF
-2 pour ANYCRLF
-1 pour ANY
PCRE_CONFIG_BSR Indique ce que \R correspond par défaut :
0 toutes les fins de ligne Unicode
1 CR, LF, ou CRLF uniquement
PCRE_CONFIG_POSIX_MALLOC_THRESHOLD
Seuil de slots de retour, au-dessus duquel
malloc() est utilisé par l'API POSIX
PCRE_CONFIG_STACKRECURSE Implémentation de la récursion (1=pile, 0=tas)
PCRE_CONFIG_UTF16 Disponibilité du support UTF-16 (1=oui,
0=non) ; option pour pcre16_config()
PCRE_CONFIG_UTF32 Disponibilité du support UTF-32 (1=oui,
0=non) ; option pour pcre32_config()
PCRE_CONFIG_UTF8 Disponibilité du support UTF-8 (1=oui, 0=non) ;
option pour pcre_config()
PCRE_CONFIG_UNICODE_PROPERTIES
Disponibilité du support des propriétés Unicode
(1=oui, 0=non)

La fonction retourne 0 en cas de succès ou PCRE_ERROR_BADOPTION sinon. Cette erreur est également donnée si PCRE_CONFIG_UTF16 ou PCRE_CONFIG_UTF32 est passé à pcre_config(), si PCRE_CONFIG_UTF8 ou PCRE_CONFIG_UTF32 est passé à pcre16_config(), ou si PCRE_CONFIG_UTF8 ou PCRE_CONFIG_UTF16 est passé à pcre32_config().

Il y a une description complète de l'API native de PCRE dans la page pcreapi et une description de l'API POSIX dans la page pcreposix.
