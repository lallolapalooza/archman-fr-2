pcre_get_stringtable_entries(3)

Paquet: pcre

Licences: BSD

PCRE_GET_STRINGTABLE_ENTRIES(3) Manuel des fonctions de bibliothèque PCRE_GET_STRINGTABLE_ENTRIES(3)

NOM

PCRE - expressions régulières compatibles Perl

SYNTAXE

#include <pcre.h>

int pcre_get_stringtable_entries(const pcre *code,
     const char *name, char **first, char **last);

int pcre16_get_stringtable_entries(const pcre16 *code,
     PCRE_SPTR16 name, PCRE_UCHAR16 **first, PCRE_UCHAR16 **last);

int pcre32_get_stringtable_entries(const pcre32 *code,
     PCRE_SPTR32 name, PCRE_UCHAR32 **first, PCRE_UCHAR32 **last);

DESCRIPTION

Cette fonction pratique recherche, pour un motif compilé, la première et la dernière entrée pour un nom donné dans la table qui traduit les noms des parenthèses de capture en nombres. Lorsque les noms doivent être uniques (PCRE_DUPNAMES n'est *pas* défini), il est généralement plus facile d'utiliser pcre[16|32]_get_stringnumber() à la place.


code Expression régulière compilée
name Nom dont les entrées sont requises
first Où retourner un pointeur vers la première entrée
last Où retourner un pointeur vers la dernière entrée

Le résultat de la fonction est la longueur de chaque entrée, ou PCRE_ERROR_NOSUBSTRING si aucune n'est trouvée.

Il y a une description complète de l'API native de PCRE, y compris le format des entrées de la table, dans la page pcreapi, et une description de l'API POSIX dans la page pcreposix.
