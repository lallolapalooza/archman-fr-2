PCAP-CONFIG(1) Manuel des commandes générales PCAP-CONFIG(1)

NOM

pcap-config - écrit les indicateurs du compilateur et de l'éditeur de liens de libpcap sur la sortie standard

SYNTAXE

pcap-config [ --help ] [ --version ] [ --cflags ] [ --libs | --additional-libs ] [ --static | --static-pcap-only ]

DESCRIPTION

pcap-config écrit sur la sortie standard divers indicateurs du compilateur et de l'éditeur de liens requis pour construire un programme utilisateur avec libpcap. Par défaut, il écrit des indicateurs appropriés pour la construction avec une version liée dynamiquement de libpcap ; voir ci-dessous pour le lien statique. Selon la manière dont libpcap est installé, certaines options ou leurs combinaisons peuvent produire une sortie vide - ceci est intentionnel.

OPTIONS

--help
Produit un message d'aide et quitte.
--version
Produit la version de libpcap et quitte. La version est le contenu du fichier VERSION dans l'arborescence source de libpcap plutôt que le résultat de pcap_lib_version(3PCAP).
--cflags
Produit l'indicateur du compilateur -I requis pour inclure les fichiers d'en-tête de libpcap.
--libs
Produit les indicateurs de l'éditeur de liens -L et -l requis pour lier avec libpcap, y compris les indicateurs -l pour les bibliothèques requises par libpcap.
--additional-libs
Produit les indicateurs de l'éditeur de liens -L et -l pour les bibliothèques requises par libpcap, mais pas l'indicateur -l pour lier avec libpcap lui-même.
--static
Cette option fait en sorte que --libs et --additional-libs produisent des indicateurs d'éditeur de liens appropriés pour le lien statique avec libpcap.
--static-pcap-only
Cette option fait en sorte que --libs et --additional-libs produisent des indicateurs d'éditeur de liens appropriés pour le lien statique avec libpcap et le lien dynamique avec toutes les autres bibliothèques, y compris les bibliothèques requises par libpcap.

STATUT DE SORTIE

pcap-config quitte avec un statut non nul lorsqu'il est invoqué avec une option de ligne de commande invalide, et avec le statut 0 sinon.

COMPATIBILITÉ ASCENDANTE

Avant la sortie 1.10.2 de libpcap, pcap-config ne traitait pas les options de ligne de commande invalides comme une erreur. L'indicateur --static-pcap-only est devenu disponible dans la sortie 1.10.2 de libpcap. L'indicateur --static est devenu disponible dans la sortie 1.1.0 de libpcap.
