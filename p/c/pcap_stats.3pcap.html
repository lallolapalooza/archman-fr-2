NOM

pcap_stats - obtenir des statistiques de capture

SYNTAXE

#include <pcap/pcap.h>
int pcap_stats(pcap_t *p, struct pcap_stat *ps);

DESCRIPTION

La fonction pcap_stats() remplit la structure pcap_stat pointée par son deuxième argument. Les valeurs représentent les statistiques des paquets depuis le début de l'exécution jusqu'au moment de l'appel.

La fonction pcap_stats() n'est prise en charge que pour les captures en direct, pas pour les ``savefiles'' ; aucune statistique n'est stockée dans les ``savefiles'', donc aucune statistique n'est disponible lors de la lecture d'un ``savefile''.

Une structure pcap_stat contient les membres suivants :

ps_recv
nombre de paquets reçus ;
ps_drop
nombre de paquets abandonnés parce qu'il n'y avait pas assez de place dans le tampon du système d'exploitation lorsqu'ils sont arrivés, car les paquets n'étaient pas lus assez rapidement ;
ps_ifdrop
nombre de paquets abandonnés par l'interface réseau ou son pilote.

Les statistiques ne se comportent pas de la même manière sur toutes les plateformes. ps_recv peut compter les paquets qu'ils aient passé un filtre défini avec pcap_setfilter(3PCAP) ou non, ou il peut ne compter que les paquets qui passent le filtre. Il peut également, ou non, compter les paquets abandonnés parce qu'il n'y avait pas assez de place dans le tampon du système d'exploitation lorsqu'ils sont arrivés. ps_drop n'est pas disponible sur toutes les plateformes ; il vaut zéro sur les plateformes où il n'est pas disponible. Si le filtrage des paquets est effectué dans libpcap, plutôt que dans le système d'exploitation, il compterait les paquets qui ne passent pas le filtre. ps_recv et ps_drop peuvent, ou non, compter les paquets non encore lus par le système d'exploitation et donc pas encore vus par l'application. ps_ifdrop peut, ou non, être implémenté ; s'il vaut zéro, cela peut signifier qu'aucun paquet n'a été abandonné par l'interface, ou cela peut signifier que la statistique n'est pas disponible, elle ne doit donc pas être considérée comme une indication que l'interface n'a abandonné aucun paquet.

VALEUR RENVOYÉE

La fonction pcap_stats() renvoie 0 en cas de succès, PCAP_ERROR_NOT_ACTIVATED si elle est appelée sur un descripteur de capture qui a été créé mais non activé, ou PCAP_ERROR s'il y a une autre erreur ou si p ne prend pas en charge les statistiques de paquets. Si PCAP_ERROR est renvoyé, pcap_geterr(3PCAP) ou pcap_perror(3PCAP) peut être appelé avec p comme argument pour récupérer ou afficher le texte d'erreur.
