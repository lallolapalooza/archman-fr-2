pcre_copy_substring(3)

Paquet: pcre

Licences: BSD

PCRE_COPY_SUBSTRING(3) Manuel des fonctions de bibliothèque PCRE_COPY_SUBSTRING(3)

NOM

PCRE - Expressions régulières compatibles Perl

SYNTAXE

#include <pcre.h>

int pcre_copy_substring(const char *subject, int *ovector,
     int stringcount, int stringnumber, char *buffer,
     int buffersize);

int pcre16_copy_substring(PCRE_SPTR16 subject, int *ovector,
     int stringcount, int stringnumber, PCRE_UCHAR16 *buffer,
     int buffersize);

int pcre32_copy_substring(PCRE_SPTR32 subject, int *ovector,
     int stringcount, int stringnumber, PCRE_UCHAR32 *buffer,
     int buffersize);

DESCRIPTION

Ceci est une fonction pratique pour extraire une sous-chaîne capturée dans un tampon donné. Les arguments sont :


subject Sujet qui a été correctement mis en correspondance
ovector Vecteur de décalage que pcre[16|32]_exec() a utilisé
stringcount Valeur renvoyée par pcre[16|32]_exec()
stringnumber Numéro de la sous-chaîne requise
buffer Tampon pour recevoir la chaîne
buffersize Taille du tampon

Le résultat est la longueur de la chaîne, PCRE_ERROR_NOMEMORY si le tampon était trop petit, ou PCRE_ERROR_NOSUBSTRING si le numéro de chaîne est invalide.

Il existe une description complète de l'API native de PCRE dans la page pcreapi et une description de l'API POSIX dans la page pcreposix.
