PCRE2_SET_SUBSTITUTE_CASE_CALLOUT(3) Manuel des fonctions de bibliothèque PCRE2_SET_SUBSTITUTE_CASE_CALLOUT(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

int pcre2_set_substitute_case_callout(pcre2_match_context *mcontext,
  PCRE2_SIZE (*callout_function)(PCRE2_SPTR, PCRE2_SIZE,
                                 PCRE2_UCHAR *, PCRE2_SIZE,
                                 int, void *),
  void *callout_data);

DESCRIPTION

Cette fonction définit les champs de l'appel de substitution de casse dans un contexte de correspondance (le premier argument). Le deuxième argument spécifie une fonction d'appel et le troisième argument est un élément de données opaque qui lui est passé. Le résultat de cette fonction est toujours zéro.

Il y a une description complète de l'API native de PCRE2 dans la page pcre2api et une description de l'API POSIX dans la page pcre2posix.
