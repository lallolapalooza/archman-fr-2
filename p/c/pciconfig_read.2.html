pciconfig_read(2) Manuel des appels système pciconfig_read(2)

NOM

pciconfig_read, pciconfig_write, pciconfig_iobase - Gestion des informations des périphériques PCI

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <pci.h>
int pciconfig_read(unsigned long bus, unsigned long dfn,
                   unsigned long off, unsigned long size,
                   unsigned char *buf);
int pciconfig_write(unsigned long bus, unsigned long dfn,
                   unsigned long off, unsigned long size,
                   unsigned char *buf);
int pciconfig_iobase(int which, unsigned long bus,
                   unsigned long devfn);

DESCRIPTION

La plupart des interactions avec les périphériques PCI sont déjà gérées par la couche PCI du noyau, et donc ces appels ne devraient normalement pas être accédés depuis l'espace utilisateur.

pciconfig_read()
Lit depuis le périphérique dev à l'offset off et écrit la valeur dans buf.
pciconfig_write()
Écrit depuis buf vers le périphérique dev à l'offset off et écrit la valeur.
pciconfig_iobase()
Vous lui passez une paire bus/devfn et vous obtenez une adresse physique soit pour l'offset mémoire (pour des choses comme prep, c'est 0xc0000000), soit pour les cycles d'E/S PIO, soit pour les trous ISA le cas échéant.

VALEUR RETOUR

pciconfig_read()
En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.
pciconfig_write()
En cas de succès, zéro est retourné. En cas d'erreur, -1 est retourné et errno est défini pour indiquer l'erreur.
pciconfig_iobase()
Retourne des informations sur les emplacements de diverses régions d'E/S en mémoire physique selon la valeur de which. Les valeurs pour which sont : IOBASE_BRIDGE_NUMBER, IOBASE_MEMORY, IOBASE_IO, IOBASE_ISA_IO, IOBASE_ISA_MEM.

ERREURS

EINVAL
La valeur de size est invalide. Ceci ne s'applique pas à pciconfig_iobase().
EIO
Erreur d'E/S.
ENODEV
Pour pciconfig_iobase(), la valeur "hose" est NULL. Pour les autres appels, impossible de trouver un emplacement.
ENOSYS
Le système n'a pas implémenté ces appels (CONFIG_PCI non défini).
EOPNOTSUPP
Cette valeur de retour n'est valide que pour pciconfig_iobase(). Elle est retournée si la valeur de which est invalide.
EPERM
L'utilisateur ne possède pas la capacité CAP_SYS_ADMIN. Ceci ne s'applique pas à pciconfig_iobase().

NORMES

Linux.

HISTORIQUE

Linux 2.0.26/2.1.11.
