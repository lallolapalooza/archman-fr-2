pcre2_set_newline(3)

Paquet: pcre2

Licences: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SET_NEWLINE(3) Manuel des fonctions de bibliothèque PCRE2_SET_NEWLINE(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

int pcre2_set_newline(pcre2_compile_context *ccontext,
  uint32_t value);

DESCRIPTION

Cette fonction définit la convention de saut de ligne dans un contexte de compilation. Cela spécifie quel(s) caractère(s) sont reconnus comme des sauts de ligne lors de la compilation et de la correspondance des motifs. Le second argument doit être l'une des valeurs suivantes :


PCRE2_NEWLINE_CR Retour chariot seul
PCRE2_NEWLINE_LF Saut de ligne seul
PCRE2_NEWLINE_CRLF CR suivi de LF uniquement
PCRE2_NEWLINE_ANYCRLF N'importe lequel des précédents
PCRE2_NEWLINE_ANY Toute séquence de saut de ligne Unicode
PCRE2_NEWLINE_NUL Le caractère NUL (zéro binaire)

Le résultat est zéro en cas de succès ou PCRE2_ERROR_BADDATA si le second argument est invalide.

Il existe une description complète de l'API native de PCRE2 dans la page pcre2api et une description de l'API POSIX dans la page pcre2posix.
