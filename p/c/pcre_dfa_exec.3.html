pcre_dfa_exec(3)

Paquet: pcre

Licences: BSD

PCRE_DFA_EXEC(3) Manuel des fonctions de bibliothèque PCRE_DFA_EXEC(3)

NOM

PCRE - expressions régulières compatibles Perl

SYNTAXE

#include <pcre.h>

int pcre_dfa_exec(const pcre *code, const pcre_extra *extra,
     const char *subject, int length, int startoffset,
     int options, int *ovector, int ovecsize,
     int *workspace, int wscount);

int pcre16_dfa_exec(const pcre16 *code, const pcre16_extra *extra,
     PCRE_SPTR16 subject, int length, int startoffset,
     int options, int *ovector, int ovecsize,
     int *workspace, int wscount);

int pcre32_dfa_exec(const pcre32 *code, const pcre32_extra *extra,
     PCRE_SPTR32 subject, int length, int startoffset,
     int options, int *ovector, int ovecsize,
     int *workspace, int wscount);

DESCRIPTION

Cette fonction compare une expression régulière compilée à une chaîne de caractères sujet donnée, en utilisant un algorithme de correspondance alternatif qui analyse la chaîne sujet une seule fois (pas* compatible Perl). Notez que la fonction de correspondance principale, compatible Perl, est pcre[16|32]_exec(). Les arguments de cette fonction sont :


code Pointeur vers le motif compilé
extra Pointeur vers une structure pcre[16|32]_extra associée,
ou est NULL
subject Pointeur vers la chaîne sujet
length Longueur de la chaîne sujet
startoffset Décalage dans le sujet où commencer la correspondance
options Bits d'option
ovector Pointeur vers un vecteur d'entiers pour les décalages de résultat
ovecsize Nombre d'éléments dans le vecteur
workspace Pointeur vers un vecteur d'entiers utilisé comme espace de travail
wscount Nombre d'éléments dans le vecteur

Les unités pour length* et startoffset* sont des octets pour pcre_exec(), des éléments de données de 16 bits pour pcre16_exec(), et des éléments de 32 bits pour pcre32_exec(). Les options sont :


PCRE_ANCHORED Ne correspond qu'à la première position
PCRE_BSR_ANYCRLF \R ne correspond qu'à CR, LF, ou CRLF
PCRE_BSR_UNICODE \R correspond à toutes les fins de ligne Unicode
PCRE_NEWLINE_ANY Reconnaît toute séquence de fin de ligne Unicode
PCRE_NEWLINE_ANYCRLF Reconnaît CR, LF, & CRLF comme séquences de fin de ligne
PCRE_NEWLINE_CR Reconnaît CR comme seule séquence de fin de ligne
PCRE_NEWLINE_CRLF Reconnaît CRLF comme seule séquence de fin de ligne
PCRE_NEWLINE_LF Reconnaît LF comme seule séquence de fin de ligne
PCRE_NOTBOL Le sujet n'est pas le début d'une ligne
PCRE_NOTEOL Le sujet n'est pas la fin d'une ligne
PCRE_NOTEMPTY Une chaîne vide n'est pas une correspondance valide
PCRE_NOTEMPTY_ATSTART Une chaîne vide au début du sujet
n'est pas une correspondance valide
PCRE_NO_START_OPTIMIZE Ne pas faire d'optimisations de "début de correspondance"
PCRE_NO_UTF16_CHECK Ne pas vérifier la validité du sujet UTF-16
(uniquement pertinent si PCRE_UTF16
a été défini lors de la compilation)
PCRE_NO_UTF32_CHECK Ne pas vérifier la validité du sujet UTF-32
(uniquement pertinent si PCRE_UTF32
a été défini lors de la compilation)
PCRE_NO_UTF8_CHECK Ne pas vérifier la validité du sujet UTF-8
(uniquement pertinent si PCRE_UTF8
a été défini lors de la compilation)
PCRE_PARTIAL ) Retourne PCRE_ERROR_PARTIAL pour une correspondance partielle
PCRE_PARTIAL_SOFT ) si aucune correspondance complète n'est trouvée
PCRE_PARTIAL_HARD Retourne PCRE_ERROR_PARTIAL pour une correspondance partielle
même s'il existe une correspondance complète en plus
PCRE_DFA_SHORTEST Ne retourne que la correspondance la plus courte
PCRE_DFA_RESTART Redémarrer après une correspondance partielle

Il existe des restrictions sur ce qui peut apparaître dans un motif lors de l'utilisation de cette fonction de correspondance. Les détails sont donnés dans la documentation pcrematching. Pour les détails sur la correspondance partielle, voir la page pcrepartial.

Une structure pcre[16|32]_extra contient les champs suivants :


flags Bits indiquant quels champs sont définis
study_data Données opaques de pcre[16|32]_study()
match_limit Limite d'utilisation des ressources internes
match_limit_recursion Limite de profondeur de récursion interne
callout_data Données opaques renvoyées aux appels externes
tables Pointeur vers des tables de caractères ou NULL
mark Pour renvoyer un pointeur *MARK
executable_jit Données opaques de la compilation JIT

Les bits de drapeau sont PCRE_EXTRA_STUDY_DATA, PCRE_EXTRA_MATCH_LIMIT, PCRE_EXTRA_MATCH_LIMIT_RECURSION, PCRE_EXTRA_CALLOUT_DATA, PCRE_EXTRA_TABLES, PCRE_EXTRA_MARK et PCRE_EXTRA_EXECUTABLE_JIT. Pour cette fonction de correspondance, les champs match_limit* et match_limit_recursion* ne sont pas utilisés et ne doivent pas être définis. Le drapeau PCRE_EXTRA_EXECUTABLE_JIT et la variable correspondante sont ignorés.

Il y a une description complète de l'API native PCRE dans la page pcreapi et une description de l'API POSIX dans la page pcreposix.
