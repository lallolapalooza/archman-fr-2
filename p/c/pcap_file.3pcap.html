NOM

pcap_file - obtenir le flux d'E/S standard pour un fichier de capture lu

SYNTAXE

#include <pcap/pcap.h>
FILE *pcap_file(pcap_t *p);

DESCRIPTION

pcap_file() renvoie le flux d'E/S standard du « fichier de capture », si un « fichier de capture » a été ouvert avec pcap_open_offline(3PCAP), ou NULL, si un périphérique réseau a été ouvert avec pcap_create(3PCAP) et pcap_activate(3PCAP), ou avec pcap_open_live(3PCAP).

Notez que la bibliothèque Packet Capture est généralement construite avec le support des fichiers volumineux, donc le flux d'E/S standard du « fichier de capture » peut faire référence à un fichier de plus de 2 gigaoctets ; les applications qui utilisent pcap_file() devraient, si possible, utiliser des appels qui supportent les fichiers volumineux sur la valeur renvoyée par pcap_file() ou la valeur renvoyée par fileno(3) lorsqu'elle est passée à la valeur renvoyée par pcap_file().
