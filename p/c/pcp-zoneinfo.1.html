PCP-ZONEINFO(1) Manuel des commandes générales PCP-ZONEINFO(1)

NOM

pcp-zoneinfo - Rapport des statistiques des zones NUMA

SYNTAXE

pcp [options pcp] zoneinfo [-Vz?] [-s échantillons] [-a archive] [-S heure_début] [-T heure_fin] [-Z fuseau_horaire]

DESCRIPTION

La commande pcp-zoneinfo est utilisée pour visualiser les différentes sortes de statistiques liées aux nœuds NUMA. En utilisant diverses options, elle aide l'utilisateur à analyser des informations utiles relatives à la disponibilité des zones pour différents nœuds NUMA. Ceci est utile pour analyser le comportement de la mémoire virtuelle. Par défaut, pcp-zoneinfo rapporte les données en direct pour l'hôte local.

OPTIONS

-a fichier, --archive=fichier
Récupérer /proc/zoneinfo pour un fichier d'archive spécifié
-s compte, --samples=compte
Obtenir les statistiques de zoneinfo pour le nombre d'échantillons compte spécifié
-S, --start=heure
Filtrer les échantillons de l'archive à partir de l'heure donnée
-T, --finish=heure
Filtrer les échantillons de l'archive jusqu'à l'heure donnée
-V, --version
Afficher le numéro de version et quitter.
-z, --hostzone
Utiliser le fuseau horaire local de l'hôte qui est la source des métriques de performance, tel qu'identifié par les options -h ou -a. La valeur par défaut est d'utiliser le fuseau horaire de l'hôte local.
-Z fuseau_horaire, --timezone=fuseau_horaire
Utiliser le fuseau_horaire pour la date et l'heure. Le fuseau_horaire est au format de la variable d'environnement TZ tel que décrit dans environ(7).
-?, --help
Afficher le message d'utilisation et quitter.

NOTES

pcp-zoneinfo collecte des informations à partir de /proc/zoneinfo.

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

Pour les variables d'environnement affectant les outils PCP, voir pmGetOptions(3).

VOIR AUSSI

PCPIntro(1), pcp(1), pmParseInterval(3) et environ(7).
