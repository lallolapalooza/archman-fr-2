pcre2_get_match_data_size(3)

Paquet: pcre2

Licences: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_GET_MATCH_DATA_SIZE(3) Manuel des fonctions de bibliothèque PCRE2_GET_MATCH_DATA_SIZE(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

PCRE2_SIZE pcre2_get_match_data_size(pcre2_match_data *match_data);

DESCRIPTION

Cette fonction renvoie la taille, en octets, du bloc de données de correspondance qui lui est passé en argument.

Une description complète de l'API native de PCRE2 se trouve sur la page pcre2api et une description de l'API POSIX se trouve sur la page pcre2posix.
