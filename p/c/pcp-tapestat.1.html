PCP-TAPESTAT(1) Manuel des commandes générales PCP-TAPESTAT(1)

NOM

pcp-tapestat - rapport des statistiques d'E/S de bande

SYNTAXE

pcp [options pcp] tapestat [-u?] [-G méthode] [-P précision] [-R motif] [-x [t][,h][,noidle]]

DESCRIPTION

pcp-tapestat rapporte les statistiques d'E/S pour les périphériques de bande.

OPTIONS

Lorsqu'il est appelé via la commande pcp(1), les options pcp -A/--align, -a/--archive, -h/--host, -O/--origin, -S/--start, -s/--samples, -t/--interval, -T/--finish, -V/--version, -Z/--timezone et -z/--hostzone deviennent indirectement disponibles ; reportez-vous à PCPIntro(1) pour une description complète de ces options.

Les options de ligne de commande supplémentaires disponibles pour pcp-tapestat sont :

-G méthode, --aggregate=méthode
Spécifie que les statistiques pour les noms de périphériques correspondant à l'expression régulière spécifiée avec l'option -R regex doivent être agrégées selon la méthode. Notez qu'il s'agit d'une agrégation basée sur les noms de périphériques correspondants (pas une agrégation temporelle). Lorsque -G est utilisé, la colonne du nom de périphérique est rapportée comme méthode(regex), par exemple si -G sum -R 'st(0|1)$' est spécifié, la colonne du périphérique sera sum(st(0|1)$) et les statistiques sommées pour st0 et st1 seront rapportées dans les colonnes restantes. Si -G est spécifié mais que -R n'est pas spécifié, alors le regex par défaut est .*, c'est-à-dire correspondant à tous les noms de périphériques. Si méthode est sum alors les statistiques sont sommées. Si méthode est avg alors les statistiques sont sommées puis moyennées en divisant par le nombre de noms de périphériques correspondants. Si méthode est min ou max, les statistiques minimales ou maximales pour les périphériques correspondants sont rapportées, respectivement.
-P N, --precision=N
Indique la précision (nombre de décimales) à rapporter. La précision par défaut N peut être définie sur autre chose que la valeur par défaut (2). Notez que les champs avgrq-sz et avgqu-sz sont toujours rapportés avec N+1 décimales de précision. Ces champs ont généralement des valeurs inférieures à 1.
-R motif, --regex=motif
Restreint le rapport aux noms de périphériques correspondant à une expression régulière motif. Le motif donné est recherché comme une expression régulière de style perl, et correspondra à toute partie d'un nom de périphérique. Par exemple, '^st[0-9]+' correspondra à tous les noms de périphériques commençant par 'st' suivi d'un ou plusieurs chiffres. Par exemple, '^st(0|1)$' ne correspondra qu'à 'st0' et 'st1'. Par exemple, 'st0$' correspondra à 'st0' mais pas à 'st1'. Voir également l'option -G pour les options d'agrégation.
-u, --no-interpolation
Lors de la relecture d'un ensemble d'archives, les valeurs sont par défaut rapportées conformément à l'intervalle d'échantillonnage demandé (option -t), et non conformément à l'intervalle réel enregistré dans les archives. Sans cette option, PCP interpole les valeurs à rapporter en se basant sur les enregistrements de l'ensemble d'archives, ce qui est particulièrement utile lorsque l'option -t est utilisée pour rejouer un ensemble d'archives avec un intervalle d'échantillonnage plus long que celui avec lequel l'archive a été enregistrée à l'origine. Avec l'option -u, la génération de rapports sans interpolation est activée - chaque valeur est rapportée conformément à l'intervalle d'enregistrement natif de l'ensemble d'archives. Lorsque l'option -u est spécifiée, l'option -t n'a aucun sens et est incompatible car l'intervalle de relecture est toujours le même que l'intervalle d'enregistrement de l'ensemble d'archives. De plus, -u n'a de sens que lors de la relecture d'archives, voir l'option -a sur PCPIntro(1), et donc si -u est spécifié alors -a doit également être spécifié.
-V, --version
Affiche le numéro de version et quitte.
-x options-séparées-par-des-virgules
Spécifie une liste, séparée par des virgules, d'une ou plusieurs options de rapport étendues comme suit :
t - préfixe chaque ligne du rapport avec un horodatage au format ctime(3),
h - omet l'en-tête, qui est autrement rapporté toutes les 24 échantillons,
noidle - N'affiche pas les statistiques pour les périphériques inactifs.
-?, --help
Affiche le message d'utilisation et quitte.

RAPPORT

Les colonnes du rapport pcp-tapestat ont l'interprétation suivante :

Horodatage
Lorsque l'option -x t est spécifiée, cette colonne est l'horodatage au format ctime(3).
Périphérique
Spécifie le nom du périphérique de bande. Lorsque -G est spécifié, il est remplacé par la méthode d'agrégation et l'expression régulière - voir les options -G et -R ci-dessus.
r/s
Le nombre de lectures émises exprimé en nombre par seconde moyenné sur l'intervalle.
w/s
Le nombre d'écritures émises exprimé en nombre par seconde moyenné sur l'intervalle.
ko_r/s
La quantité de données lues exprimée en kilo-octets par seconde moyennée sur l'intervalle.
ko_w/s
La quantité de données écrites exprimée en kilo-octets par seconde moyennée sur l'intervalle.
r_pct
Pourcentage d'attente en lecture - le pourcentage de temps sur l'intervalle passé à attendre la fin des requêtes de lecture. Le temps est mesuré depuis que la requête est envoyée à la couche intermédiaire SCSI jusqu'à ce qu'elle signale son achèvement.
w_pct
Pourcentage d'attente en écriture - le pourcentage de temps sur l'intervalle passé à attendre la fin des requêtes d'écriture. Le temps est mesuré depuis que la requête est envoyée à la couche intermédiaire SCSI jusqu'à ce qu'elle signale son achèvement.
o_pct
Pourcentage d'attente global - le pourcentage de temps sur l'intervalle passé à attendre la fin de toute requête d'E/S (lecture, écriture et autre).
Rs/s
Le nombre d'E/S, exprimé en nombre par seconde moyenné sur l'intervalle, pour lesquelles une valeur résiduelle non nulle a été rencontrée.
o_cnt
Le nombre d'E/S, exprimé en nombre par seconde moyenné sur l'intervalle, qui ont été incluses comme "autres". Les E/S autres incluent les appels ioctl effectués au pilote de bande et les opérations implicites effectuées par le pilote de bande telles que la rembobinage à la fermeture (pour les périphériques de bande qui implémentent le rembobinage à la fermeture). Cela n'inclut aucune E/S effectuée en dehors du pilote de bande (par exemple, via les ioctls sg).

ENVIRONNEMENT PCP

Les variables d'environnement préfixées par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Lors de chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

Pour les variables d'environnement affectant les outils PCP, voir pmGetOptions(3).

OPTIONS DE DÉBOGAGE

L'option pcp -D ou --debug active la sortie de diagnostics supplémentaires sur stderr pour aider à résoudre les problèmes, bien que les informations soient parfois cryptiques et visent principalement à fournir des indications aux développeurs plutôt qu'aux utilisateurs finaux.

ers. debug est une liste séparée par des virgules d'options de débogage ; utilisez pmdbg(1) avec l'option -l pour obtenir une liste des options de débogage disponibles et leur signification.

VOIR AUSSI

PCPIntro(1), pcp(1), pmcd(1), pmchart(1), pmlogger(1), pcp.conf(5) et pcp.env(5).
