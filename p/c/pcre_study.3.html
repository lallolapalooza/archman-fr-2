pcre_study(3)

Paquet: pcre

Licences: BSD

PCRE_STUDY(3) Manuel des fonctions de bibliothèque PCRE_STUDY(3)

NOM

PCRE - expressions régulières compatibles Perl

SYNTAXE

#include <pcre.h>

pcre_extra *pcre_study(const pcre *code, int options,
     const char **errptr);

pcre16_extra *pcre16_study(const pcre16 *code, int options,
     const char **errptr);

pcre32_extra *pcre32_study(const pcre32 *code, int options,
     const char **errptr);

DESCRIPTION

Cette fonction étudie un motif compilé, afin de voir si des informations supplémentaires peuvent être extraites pour accélérer la correspondance. Ses arguments sont :


code Une expression régulière compilée
options Options pour pcre[16|32]_study()
errptr Emplacement pour placer un message d'erreur

Si la fonction réussit, elle renvoie une valeur qui peut être passée à pcre[16|32]_exec() ou pcre[16|32]_dfa_exec() via leurs arguments extra.

Si la fonction renvoie NULL, soit elle n'a pas pu trouver d'informations supplémentaires, soit il y a eu une erreur. Vous pouvez faire la différence en regardant la valeur d'erreur. Elle est NULL dans le premier cas.

La seule option est PCRE_STUDY_JIT_COMPILE. Elle demande une compilation juste-à-temps si possible. Si PCRE a été compilé sans prise en charge JIT, cette option est ignorée. Voir la page pcrejit pour plus de détails.

Il existe une description complète de l'API native de PCRE sur la page pcreapi et une description de l'API POSIX sur la page pcreposix.
