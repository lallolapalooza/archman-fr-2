NOM

pcap_dump_file - obtenir le flux d'E/S standard pour un fichier de sauvegarde en cours d'écriture

SYNTAXE

#include <pcap/pcap.h>
FILE *pcap_dump_file(pcap_dumper_t *p);

DESCRIPTION

pcap_dump_file() renvoie le flux d'E/S standard du ``fichier de sauvegarde'' ouvert par pcap_dump_open(3PCAP).
