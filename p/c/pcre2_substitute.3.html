PCRE2_SUBSTITUTE(3) Manuel des fonctions de bibliothèque PCRE2_SUBSTITUTE(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

int pcre2_substitute(const pcre2_code *code, PCRE2_SPTR subject,
  PCRE2_SIZE length, PCRE2_SIZE startoffset,
  uint32_t options, pcre2_match_data *match_data,
  pcre2_match_context *mcontext, PCRE2_SPTR replacement,
  PCRE2_SIZE rlength, PCRE2_UCHAR *outputbuffer,
  PCRE2_SIZE *outlengthptr);

DESCRIPTION

Cette fonction correspond à une expression régulière compilée par rapport à une chaîne sujet donnée, en utilisant un algorithme de correspondance qui est similaire à celui de Perl. Elle effectue ensuite une copie du sujet, en substituant une chaîne de remplacement à ce qui a été trouvé. Ses arguments sont :


code Pointeur vers le motif compilé
subject Pointeur vers la chaîne sujet
length Longueur de la chaîne sujet
startoffset Décalage dans le sujet où commencer la correspondance
options Bits d'options
match_data Pointeur vers un bloc de données de correspondance, ou est NULL
mcontext Pointeur vers un contexte de correspondance, ou est NULL
replacement Pointeur vers la chaîne de remplacement
rlength Longueur de la chaîne de remplacement
outputbuffer Pointeur vers le tampon de sortie
outlengthptr Pointeur vers la longueur du tampon de sortie

Un bloc de données de correspondance n'est nécessaire que si vous souhaitez inspecter les données de la dernière correspondance renvoyée dans ce bloc ou si PCRE2_SUBSTITUTE_MATCHED est défini. Un contexte de correspondance n'est nécessaire que si vous souhaitez :


Configurer une fonction d'appel (callout)
Définir une limite de décalage de correspondance
Modifier la limite de correspondance du backtracking
Modifier la limite de profondeur du backtracking
Définir une gestion de mémoire personnalisée dans le contexte de correspondance

Les valeurs length, startoffset et rlength sont des unités de code, pas des caractères, tout comme le contenu de la variable pointée par outlengthptr. Cette variable doit contenir la longueur du tampon de sortie lorsque la fonction est appelée. Si la fonction réussit, la valeur est modifiée pour indiquer la longueur de la nouvelle chaîne, excluant le zéro final qui est automatiquement ajouté.

Les longueurs du sujet et du remplacement peuvent être fournies comme PCRE2_ZERO_TERMINATED pour les chaînes terminées par un zéro. Les options sont :


PCRE2_ANCHORED Ne correspond qu'à la première position
PCRE2_ENDANCHORED Ne correspond qu'à la fin du sujet
PCRE2_NOTBOL Le sujet n'est pas le début d'une ligne
PCRE2_NOTEOL Le sujet n'est pas la fin d'une ligne
PCRE2_NOTEMPTY Une chaîne vide n'est pas une correspondance valide
PCRE2_NOTEMPTY_ATSTART Une chaîne vide au début du sujet n'est pas une correspondance valide
PCRE2_NO_JIT Ne pas utiliser la correspondance JIT
PCRE2_NO_UTF_CHECK Ne pas vérifier la validité UTF dans le sujet ou le remplacement (uniquement pertinent si PCRE2_UTF a été défini lors de la compilation)
PCRE2_SUBSTITUTE_EXTENDED Effectuer un traitement de remplacement étendu
PCRE2_SUBSTITUTE_GLOBAL Remplacer toutes les occurrences dans le sujet
PCRE2_SUBSTITUTE_LITERAL La chaîne de remplacement est littérale
PCRE2_SUBSTITUTE_MATCHED Utiliser les données de correspondance préexistantes pour la première correspondance
PCRE2_SUBSTITUTE_OVERFLOW_LENGTH En cas de débordement, calculer la longueur nécessaire
PCRE2_SUBSTITUTE_REPLACEMENT_ONLY Retourner uniquement la ou les chaînes de remplacement
PCRE2_SUBSTITUTE_UNKNOWN_UNSET Traiter les groupes inconnus comme non définis
PCRE2_SUBSTITUTE_UNSET_EMPTY Insertion d'un élément non défini simple = chaîne vide

Si PCRE2_SUBSTITUTE_LITERAL est défini, PCRE2_SUBSTITUTE_EXTENDED, PCRE2_SUBSTITUTE_UNKNOWN_UNSET et PCRE2_SUBSTITUTE_UNSET_EMPTY sont ignorés.

Si PCRE2_SUBSTITUTE_MATCHED est défini, match_data doit être non NULL ; son contenu doit être le résultat d'un appel à pcre2_match() (ou pcre2_jit_match()) en utilisant le même motif, pointeur sujet, longueur sujet effective, décalage de début et options de correspondance.

La fonction renvoie le nombre de substitutions, qui peut être zéro s'il n'y a pas de correspondances. Le résultat peut être supérieur à un uniquement lorsque PCRE2_SUBSTITUTE_GLOBAL est défini. En cas d'erreur, un code d'erreur négatif est renvoyé.

Il y a une description complète de l'API native de PCRE2 dans la page pcre2api et une description de l'API POSIX dans la page pcre2posix.
