PCRE2-CONFIG(1) Manuel des commandes générales PCRE2-CONFIG(1)

NOM

pcre2-config - programme pour obtenir la configuration de PCRE2

SYNTAXE

pcre2-config [--prefix] [--exec-prefix] [--version]
             [--libs8] [--libs16] [--libs32] [--libs-posix]
             [--cflags] [--cflags-posix]

DESCRIPTION

pcre2-config renvoie la configuration des bibliothèques PCRE2 installées et les options requises pour compiler un programme afin de les utiliser. Certaines options ne s'appliquent qu'aux bibliothèques 8 bits, 16 bits ou 32 bits, respectivement, et ne sont pas disponibles pour les bibliothèques qui n'ont pas été compilées. Si une option indisponible est rencontrée, les informations d'utilisation sont affichées.

OPTIONS

--prefix
Écrit le préfixe de répertoire utilisé dans l'installation de PCRE2 pour les fichiers indépendants de l'architecture (/usr sur de nombreux systèmes, /usr/local sur certains systèmes) sur la sortie standard.
--exec-prefix
Écrit le préfixe de répertoire utilisé dans l'installation de PCRE2 pour les fichiers dépendants de l'architecture (normalement identique à --prefix) sur la sortie standard.
--version
Écrit le numéro de version des bibliothèques PCRE2 installées sur la sortie standard.
--libs8
Écrit sur la sortie standard les options de ligne de commande requises pour lier avec la bibliothèque PCRE2 8 bits (-lpcre2-8 sur de nombreux systèmes).
--libs16
Écrit sur la sortie standard les options de ligne de commande requises pour lier avec la bibliothèque PCRE2 16 bits (-lpcre2-16 sur de nombreux systèmes).
--libs32
Écrit sur la sortie standard les options de ligne de commande requises pour lier avec la bibliothèque PCRE2 32 bits (-lpcre2-32 sur de nombreux systèmes).
--libs-posix
Écrit sur la sortie standard les options de ligne de commande requises pour lier avec la bibliothèque d'enveloppement de l'API POSIX de PCRE2 (-lpcre2-posix -lpcre2-8 sur de nombreux systèmes).
--cflags
Écrit sur la sortie standard les options de ligne de commande requises pour compiler les fichiers qui utilisent PCRE2 (cela peut inclure des options -I, mais est vide sur de nombreux systèmes).
--cflags-posix
Écrit sur la sortie standard les options de ligne de commande requises pour compiler les fichiers qui utilisent la bibliothèque d'enveloppement de l'API POSIX de PCRE2 (cela peut inclure des options -I, mais est vide sur de nombreux systèmes).
