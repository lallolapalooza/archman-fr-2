PCP.ENV(5) Manuel des formats de fichiers PCP.ENV(5)

NOM

pcp.env - script pour définir les variables d'environnement d'exécution de Performance Co-Pilot

SYNTAXE

/etc/pcp.env

DESCRIPTION

Le script pcp.env est interprété (sourdé) par divers scripts et utilitaires de Performance Co-Pilot (PCP) pour définir les variables d'environnement d'exploitation de PCP. L'équivalent pour les programmes exécutables utilisant les bibliothèques PCP est la fonction pmGetConfig(3).

L'utilisation typique de pcp.env dans un script est la suivante :


#! /bin/sh


# sourcer les variables d'environnement PCP
. /etc/pcp.env
reste du script ...

La syntaxe complète et la sémantique du fichier pcp.conf et de la fonction pmGetConfig sont décrites dans leurs pages de manuel respectives.

Si le fichier $HOME/.pcp/pcp.conf existe, il sera traité après le fichier pcp.conf global. Cela fournit un mécanisme pour modifier ou compléter sélectivement les paramètres d'environnement pour les scripts PCP, ce qui peut être utile si les scripts sont exécutés avec sudo(1) qui nettoie l'environnement de paramètres importants requis pour assurer l'exécution correcte des scripts PCP, par exemple $PATH ou $PERL5LIB.

ENVIRONNEMENT

La variable d'environnement PCP_CONF spécifie un chemin alternatif vers le fichier pcp.conf.

VOIR AUSSI

PCPIntro(1), sudo(1), PCPIntro(3), PMAPI(3), pmGetConfig(3) et pcp.conf(5).
