pcre_fullinfo(3)

Paquet: pcre

Licences: BSD

PCRE_FULLINFO(3) Manuel des fonctions de bibliothèque PCRE_FULLINFO(3)

NOM

PCRE - Expressions régulières compatibles Perl

SYNTAXE

#include <pcre.h>

int pcre_fullinfo(const pcre *code, const pcre_extra *extra,
     int what, void *where);

int pcre16_fullinfo(const pcre16 *code, const pcre16_extra *extra,
     int what, void *where);

int pcre32_fullinfo(const pcre32 *code, const pcre32_extra *extra,
     int what, void *where);

DESCRIPTION

Cette fonction retourne des informations sur un motif compilé. Ses arguments sont :


code Expression régulière compilée
extra Résultat de pcre[16|32]_study() ou NULL
what Quelles informations sont requises
where Où placer les informations

Les informations suivantes sont disponibles :


PCRE_INFO_BACKREFMAX Nombre de références arrière les plus élevées
PCRE_INFO_CAPTURECOUNT Nombre de sous-motifs capturant
PCRE_INFO_DEFAULT_TABLES Pointeur vers les tables par défaut
PCRE_INFO_FIRSTBYTE Première unité de données fixe pour une correspondance, ou
-1 pour le début de la chaîne
ou après un retour à la ligne, ou
-2 sinon
PCRE_INFO_FIRSTTABLE Table des premières unités de données (après étude)
PCRE_INFO_HASCRORLF Retourne 1 si des correspondances CR ou LF explicites existent
PCRE_INFO_JCHANGED Retourne 1 si (?J) ou (?-J) a été utilisé
PCRE_INFO_JIT Retourne 1 après une compilation JIT réussie
PCRE_INFO_JITSIZE Taille du code compilé JIT
PCRE_INFO_LASTLITERAL Dernière unité de données littérale requise
PCRE_INFO_MINLENGTH Borne inférieure de la longueur des chaînes correspondantes
PCRE_INFO_MATCHEMPTY Retourne 1 si le motif peut correspondre à une chaîne vide,
0 sinon
PCRE_INFO_MATCHLIMIT Limite de correspondance si définie, sinon PCRE_RROR_UNSET
PCRE_INFO_MAXLOOKBEHIND Longueur (en caractères) de la plus longue assertion de regard en arrière
PCRE_INFO_NAMECOUNT Nombre de sous-motifs nommés
PCRE_INFO_NAMEENTRYSIZE Taille d'une entrée de table de noms
PCRE_INFO_NAMETABLE Pointeur vers la table de noms
PCRE_INFO_OKPARTIAL Retourne 1 si une correspondance partielle peut être essayée
(retourne toujours 1 après la version 8.00)
PCRE_INFO_OPTIONS Bits d'options utilisés pour la compilation
PCRE_INFO_SIZE Taille du motif compilé
PCRE_INFO_STUDYSIZE Taille des données d'étude
PCRE_INFO_FIRSTCHARACTER Première unité de données fixe pour une correspondance
PCRE_INFO_FIRSTCHARACTERFLAGS Retourne
1 s'il existe un jeu de caractères de première donnée, qui peut
ensuite être récupéré à l'aide de PCRE_INFO_FIRSTCHARACTER,
2 si le premier caractère se trouve au début de la chaîne
de données ou après un retour à la ligne, et
0 sinon
PCRE_INFO_RECURSIONLIMIT Limite de récursion si définie, sinon PCRE_ERROR_UNSET
PCRE_INFO_REQUIREDCHAR Dernière unité de données littérale requise
PCRE_INFO_REQUIREDCHARFLAGS Retourne 1 si le dernier caractère de données est défini (qui peut ensuite
être récupéré à l'aide de PCRE_INFO_REQUIREDCHAR) ; 0 sinon

L'argument where doit pointer vers une variable entière, sauf pour les valeurs what suivantes :


PCRE_INFO_DEFAULT_TABLES const uint8_t *
PCRE_INFO_FIRSTCHARACTER uint32_t
PCRE_INFO_FIRSTTABLE const uint8_t *
PCRE_INFO_JITSIZE size_t
PCRE_INFO_MATCHLIMIT uint32_t
PCRE_INFO_NAMETABLE PCRE_SPTR16 (bibliothèque 16 bits)
PCRE_INFO_NAMETABLE PCRE_SPTR32 (bibliothèque 32 bits)
PCRE_INFO_NAMETABLE const unsigned char * (bibliothèque 8 bits)
PCRE_INFO_OPTIONS unsigned long int
PCRE_INFO_SIZE size_t
PCRE_INFO_STUDYSIZE size_t
PCRE_INFO_RECURSIONLIMIT uint32_t
PCRE_INFO_REQUIREDCHAR uint32_t

Le retour de la fonction est zéro en cas de succès ou :


PCRE_ERROR_NULL l'argument code était NULL
l'argument where était NULL
PCRE_ERROR_BADMAGIC le "nombre magique" n'a pas été trouvé
PCRE_ERROR_BADOPTION la valeur de what était invalide
PCRE_ERROR_UNSET l'option n'était pas définie

Il y a une description complète de l'API native PCRE dans la page pcreapi et une description de l'API POSIX dans la page pcreposix.
