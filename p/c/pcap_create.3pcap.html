NOM

pcap_create - créer un descripteur de capture en direct

SYNTAXE

#include <pcap/pcap.h>
char errbuf[PCAP_ERRBUF_SIZE];
pcap_t *pcap_create(const char *source, char *errbuf);

DESCRIPTION

pcap_create() est utilisé pour créer un descripteur de capture de paquets afin d'examiner les paquets sur le réseau. source est une chaîne de caractères qui spécifie le périphérique réseau à ouvrir ; sur les systèmes Linux avec le noyau 2.2 ou ultérieur, une valeur source de "any" ou NULL peut être utilisée pour capturer des paquets de toutes les interfaces.

Le descripteur retourné doit être activé avec pcap_activate(3PCAP) avant de pouvoir capturer des paquets avec lui ; les options de capture, telles que le mode promiscuous, peuvent être définies sur le descripteur avant son activation.

VALEUR RENVOYÉE

pcap_create() renvoie un pcap_t * en cas de succès et NULL en cas d'échec. Si NULL est renvoyé, errbuf est rempli avec un message d'erreur approprié.
