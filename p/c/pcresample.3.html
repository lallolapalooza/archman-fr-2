PCRE PROGRAMME EXEMPLE

Un programme de démonstration simple et complet, pour vous aider à démarrer avec PCRE, est fourni dans le fichier pcredemo.c de la distribution PCRE. Une liste de ce programme est donnée dans la documentation de pcredemo. Si vous n'avez pas de copie de la distribution PCRE, vous pouvez enregistrer cette liste pour recréer pcredemo.c.

Le programme de démonstration, qui utilise la bibliothèque PCRE originale 8 bits, compile l'expression régulière qui est son premier argument, et la fait correspondre à la chaîne sujet dans son deuxième argument. Aucune option PCRE n'est définie, et les tables de caractères par défaut sont utilisées. Si la correspondance réussit, le programme affiche la partie du sujet qui a correspondu, ainsi que le contenu de toute sous-chaîne capturée.

Si l'option -g est donnée sur la ligne de commande, le programme continue alors à rechercher d'autres correspondances de la même expression régulière dans la même chaîne sujet. La logique est un peu délicate en raison de la possibilité de faire correspondre une chaîne vide. Les commentaires dans le code expliquent ce qui se passe.

Si PCRE est installé dans les répertoires d'inclusion et de bibliothèque standard de votre système d'exploitation, vous devriez pouvoir compiler le programme de démonstration en utilisant cette commande :


gcc -o pcredemo pcredemo.c -lpcre

Si PCRE est installé ailleurs, vous devrez peut-être ajouter des options supplémentaires à la ligne de commande. Par exemple, sur un système de type Unix où PCRE est installé dans /usr/local, vous pouvez compiler le programme de démonstration en utilisant une commande comme celle-ci :


gcc -o pcredemo -I/usr/local/include pcredemo.c \
-L/usr/local/lib -lpcre

Dans un environnement Windows, si vous souhaitez lier statiquement le programme à un fichier pcre.a non DLL, vous devez décommenter la ligne qui définit PCRE_STATIC avant d'inclure pcre.h, car sinon les fonctions exportées pcre_malloc() et pcre_free() seront déclarées __declspec(dllimport), avec des résultats indésirables.

Une fois que vous avez compilé et lié le programme de démonstration, vous pouvez exécuter des tests simples comme ceux-ci :


./pcredemo 'chat|chien' 'le chat était assis sur le tapis'
./pcredemo -g 'chat|chien' 'le chien était assis sur le chat'

Notez qu'il existe un programme de test beaucoup plus complet, appelé pcretest, qui prend en charge de nombreuses autres fonctionnalités pour tester les expressions régulières et les deux bibliothèques PCRE. Le programme pcredemo est fourni comme exemple de codage simple.

Si vous essayez d'exécuter pcredemo alors que PCRE n'est pas installé dans le répertoire de bibliothèque standard, vous pourriez obtenir une erreur comme celle-ci sur certains systèmes d'exploitation (par exemple, Solaris) :


ld.so.1: a.out: fatal: libpcre.so.0: open failed: No such file or directory

Cela est causé par le fonctionnement du support des bibliothèques partagées sur ces systèmes. Vous devez ajouter


-R/usr/local/lib

(par exemple) à la commande de compilation pour contourner ce problème.
