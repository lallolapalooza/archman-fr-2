pcre_free_substring_list(3)

Paquet: pcre

Licences: BSD

PCRE_FREE_SUBSTRING_LIST(3) Manuel des fonctions de bibliothèque PCRE_FREE_SUBSTRING_LIST(3)

NOM

PCRE - expressions régulières compatibles Perl

SYNTAXE

#include <pcre.h>

void pcre_free_substring_list(const char **stringptr);

void pcre16_free_substring_list(PCRE_SPTR16 *stringptr);

void pcre32_free_substring_list(PCRE_SPTR32 *stringptr);

DESCRIPTION

C'est une fonction utilitaire pour libérer la mémoire obtenue par un appel précédent à pcre[16|32]_get_substring_list(). Son seul argument est un pointeur vers la liste des pointeurs de chaînes.

Il existe une description complète de l'API native PCRE dans la page pcreapi et une description de l'API POSIX dans la page pcreposix.
