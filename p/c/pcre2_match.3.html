pcre2_match(3)

Paquet: pcre2

Licences: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_MATCH(3) Manuel de fonctions de bibliothèque PCRE2_MATCH(3)

NOM

PCRE2 - Expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

int pcre2_match(const pcre2_code *code, PCRE2_SPTR subject,
  PCRE2_SIZE length, PCRE2_SIZE startoffset,
  uint32_t options, pcre2_match_data *match_data,
  pcre2_match_context *mcontext);

DESCRIPTION

Cette fonction recherche une expression régulière compilée dans une chaîne sujet donnée, en utilisant un algorithme de correspondance similaire à celui de Perl. Elle retourne les décalages de ce qui a été trouvé et des sous-chaînes capturées via le bloc match_data, qui peut être traité par des fonctions dont les noms commencent par pcre2_get_ovector_...() ou pcre2_substring_...(). Le retour de pcre2_match() est un de plus que la paire capturée numérotée la plus élevée qui a été définie (par exemple, 1 s'il n'y a pas de captures), zéro si le vecteur des décalages est trop petit, ou un code d'erreur négatif en cas de non-correspondance et d'autres erreurs. Les arguments de la fonction sont :


code Pointeur vers le motif compilé
subject Pointeur vers la chaîne sujet
length Longueur de la chaîne sujet
startoffset Décalage dans le sujet où commencer la recherche
options Bits d'options
match_data Pointeur vers un bloc de données de correspondance, pour les résultats
mcontext Pointeur vers un contexte de correspondance, ou NULL

Un contexte de correspondance n'est nécessaire que si vous souhaitez :


Configurer une fonction d'appel (callout)
Définir une limite de décalage de correspondance
Modifier la limite de mémoire du tas
Modifier la limite de retour arrière de la correspondance
Modifier la limite de profondeur du retour arrière
Définir une gestion de mémoire personnalisée spécifiquement pour la correspondance

Les valeurs length et startoffset sont des unités de code, pas des caractères. La longueur peut être donnée comme PCRE2_ZERO_TERMINATED pour un sujet terminé par une unité de code binaire zéro. Les options sont :


PCRE2_ANCHORED Correspondance uniquement à la première position
PCRE2_COPY_MATCHED_SUBJECT
En cas de succès, créer une copie privée du sujet
PCRE2_DISABLE_RECURSELOOP_CHECK
Utile seulement dans de rares cas ; à utiliser avec précaution
PCRE2_ENDANCHORED Le motif ne peut correspondre qu'à la fin du sujet
PCRE2_NOTBOL La chaîne sujet n'est pas le début d'une ligne
PCRE2_NOTEOL La chaîne sujet n'est pas la fin d'une ligne
PCRE2_NOTEMPTY Une chaîne vide n'est pas une correspondance valide
PCRE2_NOTEMPTY_ATSTART Une chaîne vide au début du sujet
n'est pas une correspondance valide
PCRE2_NO_JIT Ne pas utiliser la correspondance JIT
PCRE2_NO_UTF_CHECK Ne pas vérifier la validité UTF du sujet
(uniquement pertinent si PCRE2_UTF
a été défini lors de la compilation)
PCRE2_PARTIAL_HARD Retourner PCRE2_ERROR_PARTIAL pour une correspondance
partielle même s'il existe une correspondance complète
PCRE2_PARTIAL_SOFT Retourner PCRE2_ERROR_PARTIAL pour une correspondance
partielle si aucune correspondance complète n'est trouvée

Pour plus de détails sur la correspondance partielle, voir la page pcre2partial. Il existe une description complète de l'API native de PCRE2 sur la page pcre2api et une description de l'API POSIX sur la page pcre2posix.
