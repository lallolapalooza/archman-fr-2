pcre_utf32_to_host_byte_order(3)

Paquet: pcre

Licences: BSD

PCRE_UTF32_TO_HOST_BYTE_ORDER(3) Manuel des fonctions de bibliothèque PCRE_UTF32_TO_HOST_BYTE_ORDER(3)

NOM

PCRE - expressions régulières compatibles Perl

SYNTAXE

#include <pcre.h>

int pcre32_utf32_to_host_byte_order(PCRE_UCHAR32 *output,
     PCRE_SPTR32 input, int length, int *host_byte_order,
     int keep_boms);

DESCRIPTION

Cette fonction, qui n'existe que dans la bibliothèque 32 bits, convertit une chaîne UTF-32 dans l'ordre correct pour l'hôte actuel, en tenant compte des marques d'ordre des octets (BOM) dans la chaîne. Ses arguments sont :


output pointeur vers le tampon de sortie, peut être le même que input
input pointeur vers le tampon d'entrée
length nombre d'unités 32 bits dans l'entrée, ou négatif pour
une chaîne terminée par zéro
host_byte_order une valeur NULL ou une valeur non nulle pointée signifie
commencer dans l'ordre des octets de l'hôte
keep_boms si non nul, les BOM sont copiés dans la chaîne de sortie

Le résultat de la fonction est le nombre d'unités 32 bits placées dans le tampon de sortie, y compris le terminateur zéro si la chaîne était terminée par zéro.

Si host_byte_order n'est pas NULL, il est défini pour indiquer l'ordre des octets actuel à la fin de la chaîne.

Il existe une description complète de l'API native de PCRE dans la page pcreapi et une description de l'API POSIX dans la page pcreposix.
