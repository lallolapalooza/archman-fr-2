PCRE2_SET_OPTIMIZE(3) Manuel des fonctions de bibliothèque PCRE2_SET_OPTIMIZE(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNOPSIS

#include <pcre2.h>

int pcre2_set_optimize(pcre2_compile_context *ccontext,
  uint32_t directive);

DESCRIPTION

Cette fonction contrôle quelles optimisations de performance seront appliquées par pcre2_compile(). Elle peut être appelée plusieurs fois avec le même contexte de compilation ; les effets sont cumulatifs, les effets des appels ultérieurs prenant le pas sur les précédents.

Le résultat est zéro en cas de succès, PCRE2_ERROR_NULL si ccontext est NULL, ou PCRE2_ERROR_BADOPTION si directive est inconnue. Ce dernier cas peut être utile pour détecter si une optimisation particulière est disponible.

La liste des valeurs possibles pour le paramètre directive est la suivante :


PCRE2_OPTIMIZATION_FULL Active toutes les optimisations (par défaut)
PCRE2_OPTIMIZATION_NONE Désactive toutes les optimisations
PCRE2_AUTO_POSSESS Active l'auto-possessivité
PCRE2_AUTO_POSSESS_OFF Désactive l'auto-possessivité
PCRE2_DOTSTAR_ANCHOR Active l'ancrage implicite par dotstar
PCRE2_DOTSTAR_ANCHOR_OFF Désactive l'ancrage implicite par dotstar
PCRE2_START_OPTIMIZE Active les optimisations de démarrage au moment de la correspondance
PCRE2_START_OPTIMIZE_OFF Désactive les optimisations de démarrage au moment de la correspondance

Il existe une description complète de l'API native de PCRE2, y compris des descriptions détaillées des valeurs du paramètre directive, dans la page pcre2api.
