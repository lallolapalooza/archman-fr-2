PCT2RGB(1) GDAL PCT2RGB(1)

NOM

pct2rgb - Convertir une image 8 bits à palette en RGB 24 bits.

SYNTAXE

pct2rgb [--help] [--help-general]
           [-of format] [-b bande] [-rgba] [-pct fichier_palette] <fichier_source> <fichier_destination>

DESCRIPTION

Cet utilitaire convertira une bande pseudo-couleur du fichier d'entrée en un fichier RGB de sortie du format désiré.

REMARQUE :

pct2rgb est un utilitaire Python, et n'est disponible que si les liaisons Python de GDAL sont disponibles.
--help
Afficher ce message d'aide et quitter
--help-general
Donne un bref message d'utilisation pour les options génériques de ligne de commande GDAL et quitte.
-of <format>
Sélectionner le format de sortie. Si non spécifié, le format est deviné à partir de l'extension. Utiliser le nom court du format.
-b <bande>
Bande à convertir en RGB, par défaut 1.
-rgba
Générer un fichier RGBA (au lieu d'un fichier RGB par défaut).
-pct <fichier_palette>
Extraire la table de couleurs de <fichier_palette> au lieu de la récupérer de <fichier_source>. Peut être utilisé pour avoir une table de couleurs cohérente pour plusieurs fichiers. Le <fichier_palette> doit être soit un fichier raster dans un format supporté par GDAL avec une palette, soit un fichier de couleurs dans un format supporté (txt, qml, qlr).
<fichier_source>
Le fichier d'entrée.
<fichier_destination>
Le fichier RGB de sortie qui sera créé.

L'option '-expand rgb|rgba' de gdal_translate rend cet utilitaire obsolète.
