NOM

pcp-meminfo - Rapporter les statistiques de la mémoire système.

SYNTAXE

pcp [options pcp] meminfo [-s échantillons] [-a archive] [-S heure_début] [-T heure_fin]

DESCRIPTION

La commande pcp-meminfo est utilisée pour visualiser les différentes sortes de statistiques relatives à la mémoire. En utilisant diverses options, elle aide l'utilisateur à analyser des informations utiles concernant la disponibilité de la mémoire. Ces informations incluent la mémoire totale, la mémoire disponible, la mémoire partagée, etc. Par défaut, pcp-meminfo rapporte des données en direct pour l'hôte local.

OPTIONS

-a, --archive
Récupérer /proc/meminfo pour un fichier archive spécifié.
-s, --samples
Obtenir les informations de mémoire pour un nombre spécifié d'échantillons.
-S, --start HEURE
Filtrer les échantillons de l'archive à partir de l'heure donnée.
-T, --finish HEURE
Filtrer les échantillons de l'archive jusqu'à l'heure donnée.
-V, --version
Afficher le numéro de version et quitter.
-?, --help
Afficher le message d'utilisation et quitter.

NOTES

pcp-meminfo collecte des informations à partir de /proc/meminfo et vise à être compatible avec lui en termes de ligne de commande et de sortie.

ENVIRONNEMENT PCP

Les variables d'environnement commençant par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales de ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

Pour les variables d'environnement affectant les outils PCP, voir pmGetOptions(3).

VOIR AUSSI

PCPIntro(1), pcp(1), pmParseInterval(3) et environ(7).
