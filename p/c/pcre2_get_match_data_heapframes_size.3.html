PCRE2_GET_MATCH_DATA_HEAPFRAMES_SIZE(3) Manuel des fonctions de bibliothèque PCRE2_GET_MATCH_DATA_HEAPFRAMES_SIZE(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNOPSIS

#include <pcre2.h>

PCRE2_SIZE pcre2_get_match_data_heapframes_size(
  pcre2_match_data *match_data);

DESCRIPTION

Cette fonction renvoie la taille, en octets, du bloc de données heapframes qui lui est propre.

La page pcre2api décrit complètement l'API native de PCRE2, et la page pcre2posix décrit l'API POSIX.
