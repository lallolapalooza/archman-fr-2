PCP-DSTAT(1) Manuel des commandes générales PCP-DSTAT(1)

NOM

pcp-dstat - outil polyvalent pour générer des statistiques de ressources système

SYNTAXE

pcp [options pcp] dstat [-acdfghilmnpqrstuvVy?] [-C cpus] [-G gpus] [-D disks] [-L dispositifs DM] [-M dispositifs MD] [-P partitions] [-I interrupts] [-N interfaces] [-o fichier-sortie] [-S dispositifs-swap] [--bits] [--bw] [--color] [--float] [--integer] [--nocolor] [--noheaders] [--nomissed] [--noupdate] [--list] [--pidfile fichier-pid] [--plugin] [--all-plugins] [delai [compte]]

DESCRIPTION

pcp-dstat est un outil général d'analyse de performance qui permet de visualiser plusieurs ressources système instantanément. Par exemple, vous pouvez comparer l'utilisation du disque en combinaison avec les interruptions d'un contrôleur de disque, ou comparer directement les débits réseau avec le débit du disque (dans le même intervalle).

Il fournit également de manière astucieuse les informations les plus détaillées en colonnes et indique clairement la magnitude et l'unité dans lesquelles les résultats sont affichés. Moins de confusion, moins d'erreurs, plus d'efficacité.

Le delai est le délai en secondes entre chaque mise à jour, et le compte est le nombre de mises à jour à afficher avant de quitter. Le delai par défaut est de 1 seconde et le compte n'est pas spécifié (exécution jusqu'à interruption ou fin de l'archive).

Cette dernière génération de Dstat, pcp-dstat, permet l'analyse des données de performance historiques (dans le format d'archive PCP créé par pmlogger(1)), ainsi que l'analyse des systèmes distribués de données de performance en direct depuis des hôtes distants exécutant le processus pmcd(1).

La notion originale de « plugins » de Dstat est remplacée par l'utilisation de métriques nommées dans un espace de noms de métriques de performance (PMNS(5)) fourni par des agents de domaine de métriques de performance (PMDA). Les métriques et autres informations de formatage sont maintenant spécifiées sous forme de fichiers de configuration de plugin au format pcp-dstat(5). Ce nouveau style de plugin est soit intégré (reporting temporel uniquement), soit sourcé depuis l'emplacement système ($PCP_SYSCONF_DIR/dstat) et/ou sourcé depuis un ensemble de plugins personnels d'un utilisateur individuel ($HOME/.pcp/dstat).

La liste de tous les plugins disponibles peut être consultée à l'aide de l'option de ligne de commande --list de dstat.

OPTIONS

NOM

pcp-dstat — Collecte et affiche des statistiques de performance système en temps réel.

SYNOPSIS

pcp-dstat [options] [-p | -P] [-l | pmcd | pmlogger] [-t] [-S] [-h pmcd] [-i pmcd] [-s pmlogger] [-a pmlogger] [-o pmcd] [-c pmcd] [-C pmcd] [-N] [delay [count]]

DESCRIPTION

pcp-dstat est un outil qui collecte et affiche des statistiques de performance système en temps réel. Il est basé sur l'outil dstat et utilise les métriques du Performance Co-Pilot (PCP) pour récupérer les informations. Il offre une grande flexibilité pour choisir les métriques à afficher et comment les afficher.

OPTIONS

Les options suivantes contrôlent le comportement de pcp-dstat :

Arguments de ligne de commande
L'ordre des arguments de ligne de commande n'a pas d'importance, sauf pour le `delay` et le `count` qui doivent être les derniers arguments.
-a
Collecte les données d'une archive PCP spécifiée par l'option -a.
-c
Option spécifique aux archives PCP.
-C
Option spécifique aux archives PCP.
-h
Spécifie l'hôte PCP à interroger.
-i
Option spécifique aux archives PCP.
-l
Permet l'utilisation de plugins optionnels.
-N
Permet d'utiliser des noms spécifiques pour les interfaces réseau.
-o
Option spécifique aux archives PCP.
-p
Indique de ne pas réinitialiser les compteurs après la lecture.
-P
Permet d'afficher les processus liés aux métriques.
-s
Option spécifique aux archives PCP.
-S
Indique de ne pas afficher l'en-tête.
-t
Indique de ne pas mettre à jour l'affichage.
count
Spécifie le nombre d'échantillons à collecter. Si non spécifié, il s'exécute indéfiniment.
delay
Spécifie l'intervalle en secondes entre chaque échantillon. Si non spécifié, il est de 1 seconde.

MISES À JOUR INTERMÉDIAIRES

Lorsque vous invoquez pcp-dstat avec un délai supérieur à 1 seconde et sans l'option --noupdate, il affichera des mises à jour intermédiaires. La première mise à jour montrera une moyenne de 1 seconde, la deuxième une moyenne de 2 secondes, etc., jusqu'à ce que le délai soit atteint.

Ainsi, si vous spécifiez un délai de 10, les 9 mises à jour intermédiaires ne sont PAS des instantanés, ce sont des moyennes sur le temps écoulé depuis la dernière mise à jour finale. Le résultat est que vous obtenez une moyenne de 10 secondes sur une nouvelle ligne, comme avec vmstat(1).

EXEMPLES

Utiliser pcp-dstat pour corréler le débit disque avec l'utilisation réseau (eth0), l'utilisation CPU totale et les compteurs système :

$ pcp dstat -dnyc -N eth0 -C total -f 5

Utiliser le plugin temps avec les plugins cpu, net, disk, system, load et proc :

$ pcp dstat -tcndylp

Ceci est identique à :

$ pcp dstat --time --cpu --net --disk --sys --load --proc

Utiliser pcp-dstat pour rapporter 10 échantillons à partir de métriques enregistrées dans une archive PCP 20180729 à partir de 2h30 du matin :

$ pcp --origin '@02:30' -a 20180729 dstat --time --cpu-adv --sys 1 10

Examiner les mêmes métriques en direct depuis un hôte distant :

$ pcp --host www.acme.com dstat --time --cpu-adv --sys 1 10

ENVIRONNEMENT

Le comportement des plugins internes peut être modifié via les variables d'environnement.

DSTAT_TIMEFMT
Chaîne de format strftime(3) pour le rapportage de l'heure (voir --time).

ENVIRONNEMENT PCP

Les variables d'environnement avec le préfixe PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

Pour les variables d'environnement affectant les outils PCP, voir pmGetOptions(3).
