NOM

pcap_datalink_name_to_val - obtenir la valeur du type d'en-tête de couche de liaison correspondant à un nom de type d'en-tête

SYNTAXE

#include <pcap/pcap.h>
int pcap_datalink_name_to_val(const char *name);

DESCRIPTION

pcap_datalink_name_to_val() traduit un nom de type d'en-tête de couche de liaison, qui est un nom DLT_ sans le préfixe DLT_, en la valeur correspondante du type d'en-tête de couche de liaison. La traduction est insensible à la casse.

VALEUR DE RETOUR

pcap_datalink_name_to_val() retourne la valeur du type en cas de succès et PCAP_ERROR si le nom n'est pas un nom de type connu.
