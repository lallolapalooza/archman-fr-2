pcre_compile(3)

Paquet: pcre

Licences: BSD

PCRE_COMPILE(3) Manuel des fonctions de bibliothèque PCRE_COMPILE(3)

NOM

PCRE - expressions régulières compatibles Perl

SYNTAXE

#include <pcre.h>

pcre *pcre_compile(const char *pattern, int options,
     const char **errptr, int *erroffset,
     const unsigned char *tableptr);

pcre16 *pcre16_compile(PCRE_SPTR16 pattern, int options,
     const char **errptr, int *erroffset,
     const unsigned char *tableptr);

pcre32 *pcre32_compile(PCRE_SPTR32 pattern, int options,
     const char **errptr, int *erroffset,
     const unsigned char *tableptr);

DESCRIPTION

Cette fonction compile une expression régulière sous une forme interne. C'est identique à pcre[16|32]_compile2(), à l'exception de l'absence de l'argument errorcodeptr. Ses arguments sont :


pattern Une chaîne terminée par zéro contenant
l'expression régulière à compiler
options Zéro ou plusieurs bits d'options
errptr Où placer un message d'erreur
erroffset Décalage dans le motif où l'erreur a été trouvée
tableptr Pointeur vers des tables de caractères, ou NULL pour
utiliser la valeur par défaut intégrée

Les bits d'options sont :


PCRE_ANCHORED Ancre le motif en début de chaîne
PCRE_AUTO_CALLOUT Compile des appels automatiques
PCRE_BSR_ANYCRLF \R correspond uniquement à CR, LF, ou CRLF
PCRE_BSR_UNICODE \R correspond à toutes les fins de ligne Unicode
PCRE_CASELESS Correspondance insensible à la casse
PCRE_DOLLAR_ENDONLY $ ne correspond pas à un saut de ligne en fin de
chaîne
PCRE_DOTALL . correspond à n'importe quel caractère, y compris NL
PCRE_DUPNAMES Autorise les noms de sous-motifs en double
PCRE_EXTENDED Ignore les espaces blancs et les commentaires #
PCRE_EXTRA Fonctionnalités PCRE supplémentaires
(peu d'utilité actuellement)
PCRE_FIRSTLINE Force la correspondance avant un saut de ligne
PCRE_JAVASCRIPT_COMPAT Compatibilité JavaScript
PCRE_MULTILINE ^ et $ correspondent aux sauts de ligne dans les données
PCRE_NEVER_UTF Bloque UTF, par ex. via (*UTF)
PCRE_NEWLINE_ANY Reconnaît n'importe quelle séquence de fin de ligne Unicode
PCRE_NEWLINE_ANYCRLF Reconnaît CR, LF, et CRLF comme séquences de fin de
ligne
PCRE_NEWLINE_CR Définit CR comme séquence de fin de ligne
PCRE_NEWLINE_CRLF Définit CRLF comme séquence de fin de ligne
PCRE_NEWLINE_LF Définit LF comme séquence de fin de ligne
PCRE_NO_AUTO_CAPTURE Désactive les parenthèses numérotées de capture
(les parenthèses nommées sont disponibles)
PCRE_NO_AUTO_POSSESS Désactive la posséssification automatique
PCRE_NO_START_OPTIMIZE Désactive les optimisations de départ au moment de la correspondance
PCRE_NO_UTF16_CHECK Ne vérifie pas la validité du motif pour UTF-16
(uniquement pertinent si
PCRE_UTF16 est défini)
PCRE_NO_UTF32_CHECK Ne vérifie pas la validité du motif pour UTF-32
(uniquement pertinent si
PCRE_UTF32 est défini)
PCRE_NO_UTF8_CHECK Ne vérifie pas la validité du motif pour UTF-8
(uniquement pertinent si
PCRE_UTF8 est défini)
PCRE_UCP Utilise les propriétés Unicode pour \d, \w, etc.
PCRE_UNGREEDY Inverse la gourmandise des quantificateurs
PCRE_UTF16 Exécute en mode UTF-16 dans pcre16_compile()
PCRE_UTF32 Exécute en mode UTF-32 dans pcre32_compile()
PCRE_UTF8 Exécute en mode UTF-8 dans pcre_compile()

PCRE doit être compilé avec le support UTF pour pouvoir utiliser PCRE_UTF8/16/32 et PCRE_NO_UTF8/16/32_CHECK, et avec le support UCP si PCRE_UCP est utilisé.

Le résultat de la fonction est un pointeur vers une structure de données privée contenant le motif compilé, ou NULL si une erreur a été détectée. Notez que la compilation d'expressions régulières avec une version de PCRE pour une utilisation avec une autre version n'est pas garantie de fonctionner et peut causer des plantages.

Il y a une description complète de l'API native PCRE dans la page pcreapi et une description de l'API POSIX dans la page pcreposix.
