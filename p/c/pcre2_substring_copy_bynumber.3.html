pcre2_substring_copy_bynumber(3)

PCRE2_SUBSTRING_COPY_BYNUMBER(3) Manuel de fonctions de bibliothèque PCRE2_SUBSTRING_COPY_BYNUMBER(3)

NOM

PCRE2 - Expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

int pcre2_substring_copy_bynumber(pcre2_match_data *match_data,
  uint32_t number, PCRE2_UCHAR *buffer,
  PCRE2_SIZE *bufflen);

DESCRIPTION

Ceci est une fonction pratique pour extraire une sous-chaîne capturée dans un tampon donné. Les arguments sont :


match_data Bloc de données de correspondance pour la correspondance
number Numéro de la sous-chaîne requise
buffer Tampon pour recevoir la chaîne
bufflen Longueur du tampon

La variable bufflen est mise à jour avec la longueur de la chaîne extraite, en excluant le zéro final. Le résultat de la fonction est zéro en cas de succès ou l'un des numéros d'erreur suivants :


PCRE2_ERROR_NOSUBSTRING il n'y a pas de groupes de ce numéro
PCRE2_ERROR_UNAVAILBLE l'ovector était trop petit pour ce groupe
PCRE2_ERROR_UNSET le groupe n'a pas participé à la correspondance
PCRE2_ERROR_NOMEMORY le tampon est trop petit

Il y a une description complète de l'API native de PCRE2 dans la page pcre2api et une description de l'API POSIX dans la page pcre2posix.
