pcre_maketables(3)

Paquet: pcre

Licences: BSD

PCRE_MAKETABLES(3) Manuel des fonctions de bibliothèque PCRE_MAKETABLES(3)

NOM

PCRE - expressions régulières compatibles Perl

SYNTAXE

#include <pcre.h>

const unsigned char *pcre_maketables(void);

const unsigned char *pcre16_maketables(void);

const unsigned char *pcre32_maketables(void);

DESCRIPTION

Cette fonction construit un ensemble de tables de caractères pour les valeurs de caractères inférieures à 256. Celles-ci peuvent être passées à pcre[16|32]_compile() pour remplacer les tables internes intégrées de PCRE (qui ont été créées par pcre[16|32]_maketables() lors de la compilation de PCRE). Vous pourriez vouloir faire cela si vous utilisez une locale non standard. La fonction renvoie un pointeur vers les tables.

Il existe une description complète de l'API native de PCRE dans la page pcreapi et une description de l'API POSIX dans la page pcreposix.
