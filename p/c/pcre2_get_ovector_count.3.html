pcre2_get_ovector_count(3)

Paquet: pcre2

Licences: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_GET_OVECTOR_COUNT(3) Manuel de fonctions de bibliothèque PCRE2_GET_OVECTOR_COUNT(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

uint32_t pcre2_get_ovector_count(pcre2_match_data *match_data);

DESCRIPTION

Cette fonction renvoie le nombre de paires d'indices dans l'ovector qui fait partie du bloc de données de correspondance donné.

Il y a une description complète de l'API native PCRE2 dans la page pcre2api et une description de l'API POSIX dans la page pcre2posix.
