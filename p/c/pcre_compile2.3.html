pcre_compile2(3)

Paquet: pcre

Licences: BSD

PCRE_COMPILE2(3) Manuel des fonctions de bibliothèque PCRE_COMPILE2(3)

NOM

PCRE - expressions régulières compatibles Perl

SYNTAXE

#include <pcre.h>

pcre *pcre_compile2(const char *pattern, int options,
     int *errorcodeptr,
     const char **errptr, int *erroffset,
     const unsigned char *tableptr);

pcre16 *pcre16_compile2(PCRE_SPTR16 pattern, int options,
     int *errorcodeptr,
     const char **errptr, int *erroffset,
     const unsigned char *tableptr);

pcre32 *pcre32_compile2(PCRE_SPTR32 pattern, int options,
     int *errorcodeptr,£
     const char **errptr, int *erroffset,
     const unsigned char *tableptr);

DESCRIPTION

Cette fonction compile une expression régulière dans une forme interne. Elle est identique à pcre[16|32]_compile(), à l'exception de l'ajout de l'argument errorcodeptr. Les arguments sont :


pattern Une chaîne terminée par un zéro contenant
l'expression régulière à compiler
options Zéro ou plusieurs bits d'option
errorcodeptr Où placer un code d'erreur
errptr Où placer un message d'erreur
erroffset Décalage dans le motif où l'erreur a été trouvée
tableptr Pointeur vers les tables de caractères, ou NULL pour
utiliser la valeur par défaut intégrée

Les bits d'option sont :


PCRE_ANCHORED Forcer l'ancrage du motif
PCRE_AUTO_CALLOUT Compiler des auto-appels
PCRE_BSR_ANYCRLF \R correspond uniquement à CR, LF, ou CRLF
PCRE_BSR_UNICODE \R correspond à toutes les fins de ligne Unicode
PCRE_CASELESS Correspondance insensible à la casse
PCRE_DOLLAR_ENDONLY $ ne correspond pas aux nouvelles lignes en fin
PCRE_DOTALL . correspond à tout, y compris NL
PCRE_DUPNAMES Autoriser les noms dupliqués pour les sous-motifs
PCRE_EXTENDED Ignorer les espaces et les commentaires #
PCRE_EXTRA Fonctionnalités supplémentaires de PCRE
(pas très utile actuellement)
PCRE_FIRSTLINE Forcer la correspondance avant une nouvelle ligne
PCRE_JAVASCRIPT_COMPAT Compatibilité JavaScript
PCRE_MULTILINE ^ et $ correspondent aux nouvelles lignes dans les données
PCRE_NEVER_UTF Verrouiller UTF, par ex. via (*UTF)
PCRE_NEWLINE_ANY Reconnaître toute séquence de nouvelle ligne Unicode
PCRE_NEWLINE_ANYCRLF Reconnaître CR, LF et CRLF comme séquences de nouvelle ligne
PCRE_NEWLINE_CR Définir CR comme séquence de nouvelle ligne
PCRE_NEWLINE_CRLF Définir CRLF comme séquence de nouvelle ligne
PCRE_NEWLINE_LF Définir LF comme séquence de nouvelle ligne
PCRE_NO_AUTO_CAPTURE Désactiver les parenthèses de capture numérotées
(nommées disponibles)
PCRE_NO_AUTO_POSSESS Désactiver la possessivisation automatique
PCRE_NO_START_OPTIMIZE Désactiver les optimisations de démarrage au moment de la correspondance
PCRE_NO_UTF16_CHECK Ne pas vérifier la validité de l'UTF-16 du motif
(uniquement pertinent si
PCRE_UTF16 est défini)
PCRE_NO_UTF32_CHECK Ne pas vérifier la validité de l'UTF-32 du motif
(uniquement pertinent si
PCRE_UTF32 est défini)
PCRE_NO_UTF8_CHECK Ne pas vérifier la validité de l'UTF-8 du motif
(uniquement pertinent si
PCRE_UTF8 est défini)
PCRE_UCP Utiliser les propriétés Unicode pour \d, \w, etc.
PCRE_UNGREEDY Inverser la gourmandise des quantificateurs
PCRE_UTF16 Exécuter pcre16_compile() en mode UTF-16
PCRE_UTF32 Exécuter pcre32_compile() en mode UTF-32
PCRE_UTF8 Exécuter pcre_compile() en mode UTF-8

PCRE doit être compilé avec le support UTF pour pouvoir utiliser PCRE_UTF8/16/32 et PCRE_NO_UTF8/16/32_CHECK, et avec le support UCP si PCRE_UCP est utilisé.

Le résultat de la fonction est un pointeur vers une structure de données privée contenant le motif compilé, ou NULL si une erreur a été détectée. Notez que la compilation d'expressions régulières avec une version de PCRE pour une utilisation avec une version différente n'est pas garantie de fonctionner et peut entraîner des plantages.

Il existe une description complète de l'API native de PCRE dans la page pcreapi et une description de l'API POSIX dans la page pcreposix.
