pcre_jit_stack_alloc(3)

Paquet: pcre

Licences: BSD

PCRE_JIT_STACK_ALLOC(3) Manuel des fonctions de bibliothèque PCRE_JIT_STACK_ALLOC(3)

NOM

PCRE - expressions régulières compatibles Perl

SYNOPSIS

#include <pcre.h>

pcre_jit_stack *pcre_jit_stack_alloc(int startsize,
     int maxsize);

pcre16_jit_stack *pcre16_jit_stack_alloc(int startsize,
     int maxsize);

pcre32_jit_stack *pcre32_jit_stack_alloc(int startsize,
     int maxsize);

DESCRIPTION

Cette fonction est utilisée pour créer une pile à utiliser par le code compilé par l'optimisation JIT de pcre[16|32]_study(). Les arguments sont une taille de départ pour la pile, et une taille maximale à laquelle elle est autorisée à croître. Le résultat peut être passé au code d'exécution JIT par pcre[16|32]_assign_jit_stack(), ou cette fonction peut définir un rappel pour obtenir une pile. Une taille maximale de pile de 512 Ko à 1 Mo devrait être plus que suffisante pour n'importe quel motif. Pour plus de détails, voir la page pcrejit.

Il y a une description complète de l'API native de PCRE dans la page pcreapi et une description de l'API POSIX dans la page pcreposix.
