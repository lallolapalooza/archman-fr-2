PCAP_DUMP_OPEN(3PCAP) PCAP_DUMP_OPEN(3PCAP)

NOM

pcap_dump_open, pcap_dump_open_append, pcap_dump_fopen - ouvrir un fichier pour y écrire des paquets

SYNTAXE

#include <pcap/pcap.h>

pcap_dumper_t *pcap_dump_open(pcap_t *p, const char *fname);
pcap_dumper_t *pcap_dump_open_append(pcap_t *p, const char *fname);
pcap_dumper_t *pcap_dump_fopen(pcap_t *p, FILE *fp);

DESCRIPTION

pcap_dump_open() est appelée pour ouvrir un « fichier de sauvegarde » (savefile) en écriture. fname spécifie le nom du fichier à ouvrir. Le fichier aura le même format que ceux utilisés par tcpdump(1) et tcpslice(1). Si le fichier n'existe pas, il sera créé ; s'il existe, il sera tronqué et écrasé. Le nom « - » est un synonyme pour stdout.

pcap_dump_fopen() est appelée pour écrire des données dans un flux existant fp ; ce flux sera fermé par un appel ultérieur à pcap_dump_close(3PCAP). Le flux est supposé être au début d'un fichier nouvellement créé ou tronqué, de sorte que les écritures commenceront au début du fichier. Notez que sous Windows, ce flux doit être ouvert en mode binaire.

p est une poignée de capture ou de « fichier de sauvegarde » retournée par un appel antérieur à pcap_create(3PCAP) et activée par un appel antérieur à pcap_activate(3PCAP), ou retournée par un appel antérieur à pcap_open_offline(3PCAP), pcap_open_live(3PCAP), ou pcap_open_dead(3PCAP). La précision de l'horodatage, le type de lien de données et la longueur de la capture de p sont utilisés comme type de lien de données et longueur de la capture du fichier de sortie.

pcap_dump_open_append() est similaire à pcap_dump_open() mais, si le fichier existe déjà, et est un fichier pcap avec le même ordre d'octets que l'hôte ouvrant le fichier, et a la même précision d'horodatage, le même type d'en-tête de lien de données et la même longueur de capture que p, il écrira les nouveaux paquets à la fin du fichier.

VALEUR DE RETOUR

Un pointeur vers une structure pcap_dumper_t à utiliser dans les appels ultérieurs à pcap_dump(3PCAP) et pcap_dump_close(3PCAP) est retourné en cas de succès. NULL est retourné en cas d'échec. Si NULL est retourné, pcap_geterr(3PCAP) peut être utilisé pour obtenir le message d'erreur.

COMPATIBILITÉ ASCENDANTE

La fonction pcap_dump_open_append() est devenue disponible dans la version 1.7.2 de libpcap. Dans les versions précédentes, il n'y avait pas de support pour ajouter des paquets à un fichier de sauvegarde existant.
