NOM

pcap-linktype - types d'en-têtes de couche de liaison pris en charge par libpcap

DESCRIPTION

Pour une capture en direct ou un « savefile », libpcap fournit, comme valeur de retour de la routine pcap_datalink(3PCAP), une valeur qui indique le type d'en-tête de couche de liaison au début des paquets qu'elle fournit. Ce n'est pas nécessairement le type d'en-tête de couche de liaison que les paquets capturés ont sur le réseau d'où ils sont capturés ; par exemple, les paquets d'un réseau IEEE 802.11 peuvent être fournis par libpcap avec des en-têtes Ethernet générés par la carte réseau ou le pilote de la carte réseau à partir des en-têtes 802.11. Les noms de ces valeurs commencent par DLT_, elles sont donc parfois appelées « valeurs DLT_ ».

Les valeurs stockées dans le champ de type d'en-tête de couche de liaison dans l'en-tête du fichier de sauvegarde sont, dans la plupart des cas, identiques aux valeurs renvoyées par pcap_datalink(). Les noms de ces valeurs commencent par LINKTYPE_.

Les types d'en-tête de couche de liaison pris en charge par libpcap sont décrits sur https://www.tcpdump.org/linktypes.html.
