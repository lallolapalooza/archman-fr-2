NOM

profile-cleaner - Réduit la taille des profils des navigateurs et de certains programmes de messagerie en organisant leurs bases de données sqlite en utilisant les fonctions `vacuum` et `reindex` de sqlite3. Le terme « navigateur » est utilisé de manière informelle car profile-cleaner fonctionne également avec certains clients de messagerie.

SYN。 
profile-cleaner [option]

DESCRIPTION

Profile-cleaner est un script shell très simple qui invoquera sqlite3 pour `vacuum` et `reindex` les bases de données appartenant aux navigateurs et aux clients de messagerie pris en charge. Il est compatible avec profile-sync-daemon, donc les utilisateurs n'ont pas besoin d'arrêter psd avant d'appeler profile-cleaner. En fait, les profils seront nettoyés beaucoup plus rapidement lorsqu'ils seront synchronisés avec tmpfs via psd.

FICHIER DE CONFIGURATION

Profile-cleaner créera $HOME/.config/profile-cleaner.conf la première fois qu'il sera invoqué. Les utilisateurs peuvent y définir un schéma de couleurs basé sur la couleur de fond de leur terminal. La valeur par défaut est un schéma sombre pour les terminaux aux couleurs sombres. Le fichier est commenté et auto-explicatif.

EXEMPLES

Nettoyer tous les profils firefox : 

 $ profile-cleaner f
Nettoyer le profil chromium :
 $ profile-cleaner c
Nettoyer le profil défini par l'utilisateur :
 $ profile-cleaner p /chemin/vers/profil

NAVIGATEURS ET CLIENTS DE MESSAGERIE SUPPORTÉS

Actuellement, les suivants sont pris en charge :

  • Brave (stable, beta, dev et nightly)
  • Chromium (stable, beta, dev)
  • Conkeror
  • Edge
  • Firefox (stable, beta, aurora)
  • Google-chrome (stable, beta, dev)
  • La version d'Aurora de Heftig (https://bbs.archlinux.org/viewtopic.php?id=117157)
  • Inox (https://bbs.archlinux.org/viewtopic.php?id=198763)
  • Midori
  • Newsbeuter
  • Opera (stable, next et developer)
  • Seamonkey
  • Thunderbird
  • Tor-browser
  • Vivaldi (stable et snapshot)
