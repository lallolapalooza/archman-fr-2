PCAP_COMPILE(3PCAP) PCAP_COMPILE(3PCAP)

NOM

pcap_compile - compiler une expression de filtre

SYNTAXE

#include <pcap/pcap.h>
int pcap_compile(pcap_t *p, struct bpf_program *fp,
    const char *str, int optimize, bpf_u_int32 netmask);

DESCRIPTION

pcap_compile() est utilisé pour compiler la chaîne str en un programme de filtre. Voir pcap-filter(7) pour la syntaxe de cette chaîne. fp est un pointeur vers une structure bpf_program et est rempli par pcap_compile(). optimize contrôle si l'optimisation du code résultant est effectuée. netmask spécifie le masque de réseau IPv4 du réseau sur lequel les paquets sont capturés ; il n'est utilisé que lors de la vérification des adresses de diffusion IPv4 dans le programme de filtre. Si le masque de réseau du réseau sur lequel les paquets sont capturés n'est pas connu du programme, ou si des paquets sont capturés sur l'interface pseudo "any" de Linux qui peut capturer sur plusieurs réseaux, une valeur de PCAP_NETMASK_UNKNOWN peut être fournie ; les tests pour les adresses de diffusion IPv4 échoueront à la compilation, mais tous les autres tests du programme de filtre seront corrects.

NOTE : dans libpcap 1.8.0 et les versions ultérieures, pcap_compile() peut être utilisé dans plusieurs threads au sein d'un même processus. Cependant, dans les versions antérieures de libpcap, il n'est pas sûr d'utiliser pcap_compile() dans plusieurs threads d'un même processus sans une forme d'exclusion mutuelle autorisant un seul thread à l'appeler à un moment donné.

VALEUR DE RETOUR

pcap_compile() retourne 0 en cas de succès et PCAP_ERROR en cas d'échec. Si PCAP_ERROR est retourné, pcap_geterr(3PCAP) ou pcap_perror(3PCAP) peuvent être appelés avec p comme argument pour récupérer ou afficher le message d'erreur.

COMPATIBILITÉ ASCENDANTE

La constante PCAP_NETMASK_UNKNOWN est devenue disponible dans la version 1.1.0 de libpcap.

VOIR AUSSI

pcap(3PCAP), pcap_setfilter(3PCAP), pcap_freecode(3PCAP)
