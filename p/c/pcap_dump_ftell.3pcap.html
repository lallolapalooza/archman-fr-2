PCAP_DUMP_FTELL(3PCAP) PCAP_DUMP_FTELL(3PCAP)

NOM

pcap_dump_ftell, pcap_dump_ftell64 - obtenir le décalage de fichier actuel pour un fichier de sauvegarde en cours d'écriture

SYNTAXE

#include <pcap/pcap.h>
long pcap_dump_ftell(pcap_dumper_t *p);
int64_t pcap_dump_ftell64(pcap_dumper_t *p);

DESCRIPTION

pcap_dump_ftell() renvoie la position actuelle dans le ``fichier de sauvegarde'', représentant le nombre d'octets écrits par pcap_dump_open(3PCAP) et pcap_dump(3PCAP). PCAP_ERROR est renvoyé en cas d'erreur. Si la position actuelle du fichier ne tient pas dans un long, elle sera tronquée ; cela peut se produire sur les systèmes de type UNIX 32 bits avec prise en charge des gros fichiers et sur Windows. pcap_dump_ftell64() renvoie la position actuelle du fichier dans un int64_t, donc si les décalages de fichier qui ne tiennent pas dans un long mais qui tiennent dans un int64_t sont pris en charge, celle-ci renverra le décalage du fichier sans troncature. PCAP_ERROR est renvoyé en cas d'erreur.

COMPATIBILITÉ ASCENDANTE

La fonction pcap_dump_ftell64() est devenue disponible dans la version 1.9.0 de libpcap. Dans les versions précédentes, il n'y avait aucun mécanisme pour obtenir un décalage de fichier trop grand pour tenir dans un long.
