PCP-SHPING(1) Manuel des commandes générales PCP-SHPING(1)

NOM

pcp-shping - rapport sur la disponibilité et la réponse du service shell

SYNTAXE

pcp [options de pcp] shping [-cl?] tag ...

DESCRIPTION

pcp-shping échantillonne et rapporte les métriques du service shell-ping exportées par l'agent pmdashping(1).

Le rapport par défaut de pcp-shping affiche deux colonnes pour chaque tag de service, la première montrant l'état du service (zéro indiquant le succès) et la seconde le temps de réponse du service, pour le dernier cycle de rafraîchissement de la commande pmdashping.

Lorsqu'il est invoqué via la commande pcp(1), les options -h/--host, -a/--archive, -O/--origin, -s/--samples, -t/--interval, -Z/--timezone et plusieurs autres options de pcp deviennent indirectement disponibles, voir PCPIntro(1) pour leurs descriptions.

OPTIONS

Les options de ligne de commande disponibles sont :

-c, --status
Affiche un résumé du collecteur shell-ping actuel, incluant des informations sur l'intervalle de rafraîchissement du service, le réglage de temps d'attente de la commande actuel, le nombre de rafraîchissements, et la ligne de commande complète associée à chaque tag.
-l, --tags
Affiche les tags valides.
-?, --help
Affiche le message d'utilisation et quitte.

ENVIRONNEMENT PCP

Les variables d'environnement dont le préfixe est PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).

VOIR AUSSI

PCPIntro(1), pcp(1) et pmdashping(1).
