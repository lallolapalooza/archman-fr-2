PCRE2 PROGRAMME EXEMPLE

Un programme de démonstration simple et complet pour vous aider à démarrer avec PCRE2 est fourni dans le fichier pcre2demo.c du répertoire src de la distribution PCRE2. Une liste de ce programme est donnée dans la documentation pcre2demo. Si vous n'avez pas de copie de la distribution PCRE2, vous pouvez enregistrer cette liste pour recréer le contenu de pcre2demo.c.

Le programme de démonstration compile l'expression régulière qui est son premier argument, et la fait correspondre à la chaîne sujet dans son deuxième argument. Aucune option PCRE2 n'est définie, et les tables de caractères par défaut sont utilisées. Si la correspondance réussit, le programme affiche la partie du sujet qui a correspondu, ainsi que le contenu de toutes les sous-chaînes capturées.

Si l'option -g est donnée sur la ligne de commande, le programme continue ensuite à rechercher d'autres correspondances de la même expression régulière dans la même chaîne sujet. La logique est un peu délicate en raison de la possibilité de faire correspondre une chaîne vide. Les commentaires dans le code expliquent ce qui se passe.

Le code de pcre2demo.c est un programme 8 bits qui utilise la bibliothèque PCRE2 8 bits. Il gère les chaînes et les caractères stockés dans des unités de code 8 bits. Par défaut, un caractère correspond à une unité de code, mais si le motif commence par "(*UTF)", le motif et le sujet sont traités comme des chaînes UTF-8, où les caractères peuvent occuper plusieurs unités de code.

Si PCRE2 est installé dans les répertoires d'inclusion et de bibliothèque standard de votre système d'exploitation, vous devriez pouvoir compiler le programme de démonstration en utilisant une commande comme celle-ci :


cc -o pcre2demo pcre2demo.c -lpcre2-8

Si PCRE2 est installé ailleurs, vous devrez peut-être ajouter des options supplémentaires à la ligne de commande. Par exemple, sur un système de type Unix qui a PCRE2 installé dans /usr/local, vous pouvez compiler le programme de démonstration en utilisant une commande comme celle-ci :


cc -o pcre2demo -I/usr/local/include pcre2demo.c \
-L/usr/local/lib -lpcre2-8

Une fois que vous avez construit le programme de démonstration, vous pouvez effectuer des tests simples comme ceux-ci :


./pcre2demo 'chat|chien' 'le chat était assis sur le tapis'
./pcre2demo -g 'chat|chien' 'le chien était assis sur le chat'
./pcre2demo -i 'chat' 'le chien était assis sur le CHAT'

Notez qu'il existe un programme de test beaucoup plus complet, appelé pcre2test, qui prend en charge de nombreuses autres installations pour tester les expressions régulières à l'aide des trois bibliothèques PCRE2 (8 bits, 16 bits et 32 bits, bien que les trois ne doivent pas nécessairement être installées). Le programme pcre2demo est fourni comme exemple de code relativement simple.

Si vous essayez d'exécuter pcre2demo alors que PCRE2 n'est pas installé dans le répertoire de bibliothèque standard, vous pourriez obtenir une erreur comme celle-ci sur certains systèmes d'exploitation (par exemple, Solaris) :


ld.so.1: pcre2demo: fatal: libpcre2-8.so.0: open failed: No such file or directory

Ceci est causé par la façon dont le support des bibliothèques partagées fonctionne sur ces systèmes. Vous devez ajouter


-R/usr/local/lib

(par exemple) à la commande de compilation pour résoudre ce problème.
