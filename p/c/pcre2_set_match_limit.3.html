pcre2_set_match_limit(3)

Licences: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SET_MATCH_LIMIT(3) Manuel des fonctions de bibliothèque PCRE2_SET_MATCH_LIMIT(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

int pcre2_set_match_limit(pcre2_match_context *mcontext,
  uint32_t value);

DESCRIPTION

Cette fonction définit le champ de limite de correspondance dans un contexte de correspondance. Le résultat est toujours zéro.

Il existe une description complète de l'API native de PCRE2 dans la page pcre2api et une description de l'API POSIX dans la page pcre2posix.
