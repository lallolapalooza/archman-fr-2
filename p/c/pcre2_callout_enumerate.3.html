pcre2_callout_enumerate(3)

PCRE2_COMPILE(3) Manuel des fonctions de bibliothèque PCRE2_COMPILE(3)

NOM

PCRE2 - expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

int pcre2_callout_enumerate(const pcre2_code *code,
  int (*callback)(pcre2_callout_enumerate_block *, void *),
  void *callout_data);

DESCRIPTION

Cette fonction analyse une expression régulière compilée et appelle la fonction callback() pour chaque appel (callout) dans le motif. Le résultat de la fonction est zéro en cas de succès et non nul sinon. Les arguments sont :


code Pointeur vers le motif compilé
callback La fonction de rappel
callout_data Données utilisateur passées à la fonction de rappel

La fonction callback() reçoit un pointeur vers un bloc de données contenant les champs suivants (pas nécessairement dans cet ordre) :


uint32_t version Numéro de version du bloc
uint32_t callout_number Numéro pour les appels numérotés
PCRE2_SIZE pattern_position Décalage vers l'élément suivant dans le motif
PCRE2_SIZE next_item_length Longueur de l'élément suivant dans le motif
PCRE2_SIZE callout_string_offset Décalage de la chaîne dans le motif
PCRE2_SIZE callout_string_length Longueur de la chaîne d'appel
PCRE2_SPTR callout_string Pointeur vers la chaîne d'appel ou NULL

Le second argument passé à la fonction callback() est les données d'appel passées à pcre2_callout_enumerate(). La fonction callback() doit retourner zéro en cas de succès. Toute autre valeur provoque l'arrêt de l'analyse du motif, la valeur étant renvoyée comme résultat de pcre2_callout_enumerate().

Il existe une description complète de l'API native PCRE2 dans la page pcre2api et une description de l'API POSIX dans la page pcre2posix.
