PCP.CONF(5) Manuel des formats de fichiers PCP.CONF(5)

NOM

pcp.conf - fichier de configuration et d'environnement Performance Co-Pilot

SYNTAXE

/etc/pcp.conf

DESCRIPTION

Lorsque les outils et utilitaires Performance Co-Pilot (PCP) sont utilisés et lors de l'appel de fonctions de bibliothèque PCP, un ensemble standard de variables d'environnement sont définies dans /etc/pcp.conf. Ces variables sont généralement utilisées pour spécifier l'emplacement de diverses composantes PCP dans le système de fichiers et peuvent être chargées dans des scripts shell en sourçant le script shell /etc/pcp.env(5) et interrogées par des programmes C/C++ à l'aide de la fonction de bibliothèque pmGetConfig(3). Si une variable est déjà définie dans l'environnement, les valeurs de pcp.conf ne remplacent pas ces valeurs, c'est-à-dire que les valeurs de pcp.conf servent uniquement de valeurs par défaut d'installation.

Les fichiers pcp.env et pcp.conf sont attendus par défaut dans /etc. Si nécessaire, le fichier pcp.conf peut être déplacé et PCP_CONF défini dans l'environnement pour spécifier le chemin complet du nouvel emplacement. Le fichier pcp.env ne peut pas être déplacé (c'est le seul chemin codé en dur requis par PCP).

Les règles de syntaxe pour pcp.conf sont les suivantes :

1.
la syntaxe générale est

NOM_VARIABLE_PCP=valeur de la variable jusqu'à la fin de la ligne
2.
les lignes commençant par # et toutes les lignes vides sont ignorées.
3.
toutes les variables doivent être préfixées par PCP_. C'est une question de sécurité - les variables qui n'ont pas ce préfixe seront ignorées silencieusement.
4.
il ne doit pas y avoir d'espace entre le nom de la variable et le signe = littéral, ni d'espace entre le signe = et la valeur de la variable (sauf si la valeur commence réellement par un espace). Ceci est nécessaire car le fichier pcp.conf peut être sourcé directement par des Makefiles ainsi qu'interprété par le script pcp.env et la fonction pmGetConfig.
5.
les valeurs des variables peuvent contenir des espaces et ne doivent pas être mises entre guillemets. Le script pcp.env met automatiquement entre guillemets toutes les valeurs de variables à partir du caractère suivant le signe = jusqu'à la fin de la ligne.

Pour plus de détails et une explication de l'utilisation de chaque variable, voir les commentaires dans le fichier /etc/pcp.conf lui-même.

ENVIRONNEMENT

La variable d'environnement PCP_CONF spécifie un chemin alternatif vers le fichier pcp.conf.

VOIR AUSSI

PCPIntro(1), pmconfig(1), PCPIntro(3), PMAPI(3), pmGetConfig(3) et pcp.env(5).
