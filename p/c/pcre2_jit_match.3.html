pcre2_jit_match(3)

PCRE2_JIT_MATCH(3) Manuel des fonctions de bibliothèque PCRE2_JIT_MATCH(3)

NOM

PCRE2 - Expressions régulières compatibles Perl (API révisée)

SYNTAXE

#include <pcre2.h>

int pcre2_jit_match(const pcre2_code *code, PCRE2_SPTR subject,
  PCRE2_SIZE length, PCRE2_SIZE startoffset,
  uint32_t options, pcre2_match_data *match_data,
  pcre2_match_context *mcontext);

DESCRIPTION

Cette fonction compare une expression régulière compilée qui a été traitée avec succès par le compilateur JIT à une chaîne de sujet donnée, en utilisant un algorithme de comparaison similaire à celui de Perl. C'est une interface de "voie rapide" vers le JIT, et elle évite certaines des vérifications de validité que pcre2_match() applique.

En mode UTF, la chaîne de sujet n'est pas vérifiée pour sa validité UTF. À moins que PCRE2_MATCH_INVALID_UTF n'ait été défini lors de la compilation du motif, passer une chaîne UTF invalide entraîne un comportement indéfini. Votre programme peut planter, boucler ou donner des résultats incorrects. En l'absence de PCRE2_MATCH_INVALID_UTF, vous ne devriez appeler pcre2_jit_match() en mode UTF que si vous êtes sûr que le sujet est valide.

Les arguments de pcre2_jit_match() sont exactement les mêmes que ceux de pcre2_match(), à l'exception que la chaîne de sujet doit être spécifiée avec une longueur ; PCRE2_ZERO_TERMINATED n'est pas pris en charge.

Les options prises en charge sont PCRE2_NOTBOL, PCRE2_NOTEOL, PCRE2_NOTEMPTY, PCRE2_NOTEMPTY_ATSTART, PCRE2_PARTIAL_HARD et PCRE2_PARTIAL_SOFT. Les options non prises en charge sont ignorées.

Les valeurs de retour sont les mêmes que pour pcre2_match() plus PCRE2_ERROR_JIT_BADOPTION si un mode de correspondance (partiel ou complet) est demandé et n'a pas été compilé. Pour plus de détails sur la correspondance partielle, voir la page pcre2partial.

Il existe une description complète de l'API native PCRE2 dans la page pcre2api et une description de l'API JIT dans la page pcre2jit.
