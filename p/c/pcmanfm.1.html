NOM

PCManFM - Un gestionnaire de fichiers léger basé sur Gtk+ pour X Window.

SYNTAXE

pcmanfm [ options ] [ répertoires ]

DESCRIPTION

PCMan File Manager (PCManFM) est un gestionnaire de fichiers extrêmement rapide, léger, mais riche en fonctionnalités avec navigation par onglets. C'est le gestionnaire de fichiers par défaut de l'environnement de bureau léger, LXDE.
Fonctionnalités :
* Extrêmement rapide et léger
* Peut démarrer en une seconde sur une machine normale
* Navigation par onglets (similaire à Firefox)
* Gestion du glisser-déposer avec prise en charge XDS (X direct save)
* Les fichiers peuvent être glissés entre les onglets
* Charge les grands répertoires dans un temps raisonnable
* Prise en charge des associations de fichiers (avec configuration de l'application par défaut)
* Prise en charge basique des miniatures avec prise en charge optionnelle des métadonnées EXIF
* Prise en charge des signets
* Gère correctement les noms de fichiers encodés en dehors de UTF-8
* Fournit une vue par icônes et une vue détaillée en liste
* Conforme aux standards (suit les spécifications FreeDesktop.org)
* Interface propre et conviviale (GTK+ 2.0)
* Gestion complète du bureau
* Peut définir des fonds d'écran individuels pour chaque espace de travail
* Prise en charge du montage des médias amovibles
* Accès transparent aux systèmes de fichiers distants tels que sftp, smb et ftp
* Prise en charge de la corbeille

OPTIONS

Options globales :

-d, --daemon-mode
lance PCManFM en mode démon (ignoré si un autre PCManFM est déjà en cours d'exécution)
-p profil, --profile=profil
charge un autre profil de configuration au lieu de "default"
--no-desktop
pour la compatibilité avec Nautilus

Options par instance :

--desktop
lance le gestionnaire de bureau (ignore -d)
--desktop-off
désactive le gestionnaire de bureau s'il est en cours d'exécution
--desktop-pref
ouvre la boîte de dialogue des préférences du bureau
--one-screen
gère le bureau uniquement sur l'écran X actuel (uniquement si --desktop est utilisé)
-n, --new-win
ouvre les répertoires dans une nouvelle fenêtre
--role
définit le rôle X pour la fenêtre (uniquement si -n est utilisé)
--wallpaper-mode=mode
Définit le mode du fond d'écran du bureau, mode peut être :
color (remplir avec une couleur unie),
stretch (étirer pour remplir tout le moniteur),
fit (étirer pour s'adapter à la taille du moniteur),
center (placer au centre du moniteur),
tile (mettre en mosaïque pour remplir tout le moniteur),
crop (étirer et recadrer pour remplir le moniteur), ou
screen (étirer pour remplir tout l'écran)
-w fichier, --set-wallpaper=fichier
définit le fond d'écran du bureau à partir du fichier image fichier
--show-pref n
ouvre la boîte de dialogue des préférences à la page n
-f, --find-files
ouvre une fenêtre de recherche de fichiers
répertoires
répertoires à ouvrir

GESTION DU BUREAU

Le gestionnaire de fichiers PCMan peut gérer votre bureau. Cela inclut le dessin d'un fond d'écran et l'affichage des icônes du dossier Bureau. Pour activer la gestion du bureau, pcmanfm doit être exécuté avec l'option --desktop. Une autre option qui affecte ce mode est --one-screen. Vous pouvez modifier les paramètres du gestionnaire de bureau en cours d'exécution en exécutant pcmanfm avec l'option --desktop-pref qui ouvre une fenêtre avec les préférences, ou en utilisant les paramètres de ligne de commande pour les options --set-wallpaper ou --wallpaper-mode. L'exécution de pcmanfm --desktop-off termine la gestion du bureau.

Pendant que pcmanfm gère le bureau, il affiche des icônes sur le bureau. Le comportement des icônes ressemble à la vue des dossiers dans la fenêtre principale de pcmanfm, mais les icônes sur le bureau peuvent « se souvenir » de leur position. Si vous avez deux moniteurs ou plus, le fond d'écran et l'ensemble des icônes seront affichés sur chacun d'eux. Les positions des icônes seront mémorisées individuellement pour chaque moniteur.

ENVIRONNEMENT

XDG_CURRENT_DESKTOP
L'environnement de bureau actuel. Cette variable affecte les éléments qui seront affichés dans le dossier menu://applications/.
XDG_MENU_PREFIX
Le préfixe pour le fichier XML de définition du menu XDG. Cette variable affecte la disposition des éléments affichés dans le dossier menu://applications/.

FICHIERS

~/.config/pcmanfm/default
Le répertoire du profil de configuration par défaut
~/.config/pcmanfm/default/pcmanfm.conf
Le fichier de configuration principal
~/.config/pcmanfm/default/desktop-items-0.conf
La disposition des éléments du bureau pour l'écran 0 (écran principal)
