PLTOTF(1) Manuel des commandes générales PLTOTF(1)

NOM

pltotf - convertir des fichiers de liste de propriétés au format TeX font metric (tfm)

SYNTAXE

pltotf [-verbose] nom_fichier_pl[.pl] [nom_fichier_tfm[.tfm]]

DESCRIPTION

Cette page de manuel n'est pas destinée à être exhaustive. La documentation complète pour cette version de TeX se trouve dans le fichier info ou le manuel Web2C: A TeX implementation.

Le programme pltotf traduit un fichier de liste de propriétés (orienté humain) en un fichier de métrique de police TeX (orienté programme). Ainsi, après avoir modifié le fichier de liste de propriétés, un fichier TFM peut être généré pour être utilisé avec, par exemple, tex(1).

Le nom_fichier_pl est prolongé par .pl s'il manque un suffixe. Aucune recherche de chemin n'est effectuée.

Si aucun nom_fichier_tfm n'est donné, le nom de base de nom_fichier_pl avec le suffixe .tfm est utilisé ; sinon, nom_fichier_tfm est prolongé par .tfm s'il manque un suffixe.

OPTIONS

Sans l'option -verbose, pltotf fonctionne silencieusement. Avec elle, une bannière et un rapport de progression sont affichés sur stdout.
