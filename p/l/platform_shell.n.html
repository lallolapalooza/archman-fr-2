NOM

platform::shell - Code et utilitaires de support pour l'identification du système

SYNTAXE

package require platform::shell ?1.1.4?

platform::shell::generic shell
platform::shell::identify shell
platform::shell::platform shell

DESCRIPTION

Le paquet platform::shell fournit plusieurs commandes utilitaires utiles pour l'identification de l'architecture d'un interpréteur Tcl spécifique.

Ce paquet permet d'identifier l'architecture d'un interpréteur Tcl spécifique différent de celui qui exécute le paquet. La seule exigence est que l'autre interpréteur (identifié par son chemin), soit effectivement exécutable sur la machine actuelle.

Bien que pour la plupart des plateformes, cela signifie que l'architecture de l'interpréteur interrogé est identique à l'architecture de l'interpréteur exécutant, ce n'est pas toujours le cas. Un contre-exemple concerne toutes les plateformes qui ont des variantes 32 et 64 bits et où un système 64 bits est capable d'exécuter du code 32 bits. Pour celles-ci, les interpréteurs exécutant et interrogé peuvent avoir des paramètres 32/64 bits différents et donc des identifiants différents.

Pour des applications telles qu'un dépôt de code, il est important d'identifier l'architecture de l'interpréteur qui exécutera réellement les paquets installés, par opposition à l'architecture de l'interpréteur exécutant le logiciel de dépôt.

COMMANDES

platform::shell::identify shell
Cette commande effectue la même identification que platform::identify, pour l'interpréteur Tcl spécifié, par opposition à l'interpréteur exécutant.
platform::shell::generic shell
Cette commande effectue la même identification que platform::generic, pour l'interpréteur Tcl spécifié, par opposition à l'interpréteur exécutant.
platform::shell::platform shell
Cette commande retourne le contenu de tcl_platform(platform) pour l'interpréteur Tcl spécifié.
