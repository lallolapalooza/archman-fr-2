plex(1) Générateur d'analyseur lexical Pascal plex(1)

NOM

plex - Le générateur d'analyseur lexical Pascal.

UTILISATION

lex [options] fichier-lex[.l] [fichier-sortie[.pas]]

OPTIONS

-v
Verbeux : plex génère une description lisible de l'analyseur lexical généré, écrite dans le fichier-lex avec la nouvelle extension .lst
-o
Optimiser : plex optimise les tables DFA pour produire un DFA minimal.

DESCRIPTION

plex est un générateur de programmes utilisé pour générer le code source Turbo Pascal d'une sous-routine d'analyseur lexical à partir de la spécification d'un langage d'entrée par une grammaire d'expressions régulières.

plex analyse la grammaire source contenue dans le fichier-lex (avec le suffixe par défaut .l) et écrit la sous-routine d'analyseur lexical construite dans le fichier de sortie spécifié (avec le suffixe par défaut .pas) ; si aucun fichier de sortie n'est spécifié, la sortie va dans le fichier-lex avec le nouveau suffixe .pas. Si des erreurs sont trouvées pendant la compilation, des messages d'erreur sont écrits dans le fichier liste (fichier-lex avec le nouveau suffixe .lst).

Le fichier de sortie généré contient une routine d'analyseur lexical, yylex, implémentée comme suit :


function yylex : Integer;

Cette routine doit être appelée par votre programme principal pour exécuter l'analyseur lexical. La valeur de retour de la routine yylex dénote généralement le numéro d'un jeton reconnu par l'analyseur lexical (voir la routine de retour dans l'unité LexLib). En fin de fichier, la routine yylex retourne normalement 0.

Le modèle de code pour la routine yylex peut être trouvé dans le fichier yylex.cod. Ce fichier est nécessaire à TP Lex lors de la construction du fichier de sortie. Il doit être présent soit dans le répertoire courant, soit dans le répertoire à partir duquel TP Lex a été exécuté (TP Lex recherche ces répertoires dans l'ordre indiqué). (NB : Pour la version Linux/Free Pascal, le modèle de code est recherché dans un répertoire défini à la compilation au lieu du chemin d'exécution, généralement /usr/lib/fpc/lexyacc.)

L'unité de bibliothèque TP Lex (LexLib) est requise par les programmes utilisant des analyseurs lexicaux générés par Lex ; vous devrez donc ajouter une clause uses appropriée à votre programme ou unité contenant la routine d'analyseur lexical. L'unité LexLib fournit également diverses routines utilitaires utiles ; voir le fichier lexlib.pas pour plus d'informations.
