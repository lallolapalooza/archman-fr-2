planarity(1) Manuel des commandes générales planarity(1)

NOM

planarity - La suite de planéité par ajout d'arêtes

SYNTAXE

Obtenir de l'aide

planarity -h|-help [-menu]

planarity -i|-info

Mode interactif par menu

planarity

Modes batch

planarity -s [-q] COMMANDE ENTREE SORTIE [COMPLEMENT]

planarity -r [-q] COMMANDE K N [SORTIE]

planarity -rm [-q] N SORTIE [COMPLEMENT]

planarity -rn [-q] N SORTIE [COMPLEMENT]

planarity -x [-q] -(gam) ENTREE SORTIE

planarity -t [-q] COMMANDE ENTREE SORTIE

DESCRIPTION

Invoque l'outil en ligne de commande Edge Addition Planarity Suite, soit en mode interactif, soit en mode batch.

Sans paramètre, l'outil présente une interface interactive pilotée par menu.

Lorsqu'un paramètre est donné, il s'exécute en mode batch et renvoie 0 ou 1 pour un résultat réussi et -1 en cas d'erreur.

OPTIONS

-h, -help [-menu]
Affiche une aide, avec -menu déclenchant une sortie encore plus détaillée.
-i, -info
Affiche la version, le copyright, la licence et les articles de référence.
-q
Modificateur optionnel du mode silencieux (quiet), voir ci-dessous quelles options l'acceptent.
-s [-q] COMMANDE ENTREE SORTIE [COMPLEMENT]
Exécute la COMMANDE (voir ci-dessous) sur un graphe spécifique donné dans le fichier ENTREE, avec la sortie dans le fichier primaire SORTIE et des informations complémentaires, le cas échéant, dans le fichier secondaire COMPLEMENT (par exemple, une représentation en art ASCII pour la commande de dessin de graphe planaire). La valeur de retour est 0 si le graphe spécifique est intégrable (par exemple, s'il est planaire ou ne contient pas de sous-graphe homéomorphe) et 1 s'il n'est pas intégrable (par exemple, non planaire ou s'il contient un sous-graphe homéomorphe).
-r [-q] COMMANDE K N [SORTIE]
Exécute la COMMANDE (voir ci-dessous) sur K graphes aléatoires avec N sommets. Optionnellement, écrit tous les graphes générés dans le fichier .g6 SORTIE.
-rm [-q] N SORTIE [COMPLEMENT]
Génère un graphe planaire maximal aléatoire avec N sommets, puis écrit son embedding planaire dans le fichier primaire SORTIE et optionnellement le graphe généré dans le fichier COMPLEMENT.
-rn [-q] N SORTIE [COMPLEMENT]
Génère un graphe non planaire aléatoire (planaire maximal plus une arête) avec N sommets, puis écrit un sous-graphe de Kuratowski du graphe généré dans le fichier primaire SORTIE et optionnellement le graphe généré dans le fichier COMPLEMENT.
[-q] -(gam) ENTREE SORTIE
Transforme un seul graphe du fichier ENTREE (dans n'importe quel format supporté) au format .g6 (g), liste d'adjacence (a), ou matrice d'adjacence (m) et écrit dans le fichier SORTIE.
[-q] COMMANDE ENTREE SORTIE
Exécute la COMMANDE (voir ci-dessous) sur les graphes du fichier ENTREE codé en .g6, puis écrit des statistiques récapitulatives dans le fichier SORTIE.

COMMANDES

Détermine quelle implémentation d'algorithme exécuter :

-p
Embedding planaire et isolement du sous-graphe de Kuratowski
-d
Dessin de graphe planaire par représentation de visibilité (et rendu optionnel en art ASCII)
-o
Embedding outerplanaire et isolement des obstructions
-2
Recherche d'un sous-graphe homéomorphe à K_{2,3}
-3
Recherche d'un sous-graphe homéomorphe à K_{3,3}
-4
Recherche d'un sous-graphe homéomorphe à K_4

EXEMPLES

planarity -s -q -p infile.txt embedding.out [obstruction.out]
Traite infile.txt en mode silencieux (-q), plaçant l'embedding planaire dans embedding.out ou (optionnellement) un sous-graphe de Kuratowski dans obstruction.out. Le processus retourne 0=planaire, 1=non planaire, -1=erreur
planarity -s -q -d infile.txt embedding.out [drawing.out]
Si le graphe dans infile.txt est planaire, place alors l'embedding dans embedding.out et (optionnellement) un dessin en art ASCII dans drawing.out. Le processus retourne 0=planaire, 1=non planaire, -1=erreur
