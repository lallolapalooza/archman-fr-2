NOM

plasmaengineexplorer - Fournit un accès direct aux moteurs de données Plasma

SYNOPSIS

plasmaengineexplorer [-v, --version] [-h, --help] [--list] [--heightpixels] [--widthpixels] [-xpixels] [-ypixels] [--enginemoteur de données] [--sourcemoteur de données] [--intervalms] [--appapplication]

plasmaengineexplorer [Options génériques KDE ] [Options génériques Qt ]

DESCRIPTION

plasmaengineexplorer est un outil graphique permettant aux développeurs de tester les moteurs de données Plasma sans écrire d'applet Plasma.

Si aucune option n'est donnée, il démarre sans aucun moteur de données sélectionné. Le moteur de données requis peut être sélectionné dans une liste déroulante.

Seuls les moteurs de données installés seront trouvés. kbuildsycoca4 pourrait devoir être exécuté pour que les moteurs de données nouvellement installés soient trouvés.

OPTIONS

-v, --version

Affiche les informations de version.

-h, --help

Affiche cette aide.

--list pixels

Affiche une liste des moteurs connus et de leurs descriptions.

--height

Définit la hauteur de la fenêtre, en pixels.

--width pixels

Définit la largeur de la fenêtre, en pixels.

-x pixels

Définit la coordonnée x (horizontale) du coin supérieur gauche de la fenêtre, en pixels.

-y pixels

Définit la coordonnée y (verticale) du coin supérieur gauche de la fenêtre, en pixels.

--engine moteur de données

Démarre plasmaengineexplorer avec le moteur de données donné sélectionné. moteur de données est le nom interne du moteur de données indiqué par la clé X-KDE-PluginInfo-Name du fichier de bureau.

--source moteur de données

Valide uniquement en conjonction avec --engine. Demande une source spécifique du moteur de données lorsque plasmaengineexplorer est démarré.

--interval temps

Définit l'intervalle de mise à jour par défaut pour les sources demandées à temps millisecondes. S'il n'est pas défini, la source sera mise à jour sur demande (pour certaines sources, ce sera lorsque de nouvelles données seront disponibles).

Si --source est spécifié, c'est l'intervalle de mise à jour qui sera utilisé lors de la demande de cette source.

--app application

N'affiche que les moteurs associés à l'application parente ; correspond à l'entrée X-KDE-ParentApp dans le fichier .desktop du DataEngine.

VOIR AUSSI

Une documentation utilisateur plus détaillée est disponible depuis help:/plasma-desktop (entrez cette URL dans Konqueror, ou exécutez khelpcenter help:/plasma-desktop).

EXEMPLES

Charger le moteur de données `time`, afficher l'heure locale et mettre à jour chaque seconde :

plasmaengineexplorer --engine time --source Local --interval 1000
