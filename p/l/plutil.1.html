NOM

plutil — Utilitaire de listes de propriétés

SYNTAXE

nom_programme [-commande] [-options] fichier

DESCRIPTION

L'utilitaire plutil peut être utilisé pour modifier des listes de propriétés, vérifier leur syntaxe ou les convertir d'un format à un autre. Si ‘-’ est donné comme chemin de fichier, l'entrée standard et la sortie standard sont utilisées.

La première partie est l'action à effectuer, l'une des suivantes :

-p
Affiche la liste de propriétés entière sur la sortie standard, dans le format lisible par l'homme GNUStep.
-lint
Vérifie que la liste de propriétés peut être analysée.
-convert FMT
Convertit la liste de propriétés dans un autre format. ‘FMT’ peut être l'un des formats suivants :
xml1
XML Apple.
binary1
Binaire Apple.
openstep
OpenStep (lisible par l'homme sans typage).
gnustep
GNUStep (lisible par l'homme avec typage).
json
JSON (lisible par l'homme avec perte d'informations).
Les noms de format NSPropertyListFormat sont également acceptés.
-insert CHEMIN CLE Valeur
 
L'action par défaut est ‘-lint.’

Les options générales sont :

Le « chemin de clé » de plutil est une chaîne de clés séparées par des points pour parcourir un objet de liste de propriétés. Un chemin de clé vide fait référence à l'objet lui-même. Le format des clés est conforme à celui des littéraux de chaînes des listes de propriétés GNUStep.

NOTES D'IMPLÉMENTATION

  • Les chaînes entre guillemets dans le chemin de clé sont une extension GNUStep.
  • Les formats de sortie littéraux Objective-C et Swift ne sont pas encore implémentés.
