int LIBMTP_Create_New_Playlist (LIBMTP_mtpdevice_t * device, LIBMTP_playlist_t *const metadata)

Cette routine crée une nouvelle liste de lecture basée sur les métadonnées fournies. Si le champ des pistes de métadonnées contient une liste de pistes, ces pistes seront ajoutées à la liste de lecture.

Paramètres

device un pointeur vers le périphérique sur lequel créer la nouvelle liste de lecture.
metadata les métadonnées de la nouvelle liste de lecture. Si la fonction se termine avec succès, le champ playlist_id de cette structure contiendra le nouvel identifiant de la liste de lecture.
  • metadata->parent_id doit être défini sur le parent (par exemple, le dossier) dans lequel stocker cette piste. Comme certains appareils sont un peu pointilleux sur l'emplacement des fichiers, un dossier par défaut sera choisi si libmtp a détecté un pour le type de fichier actuel et que ce paramètre est défini à 0. Si c'est 0 et qu'aucun dossier par défaut ne peut être trouvé, le fichier sera stocké dans le dossier racine.
  • metadata->storage_id doit être défini sur le stockage souhaité (par exemple, la carte mémoire ou ce que votre appareil présente) pour stocker cette piste. Le définir à 0 stockera la piste sur le stockage principal.

Retourne

0 en cas de succès, toute autre valeur signifie échec.

LIBMTP_playlist_t * LIBMTP_new_playlist_t (void )

Ceci crée une nouvelle structure de métadonnées de liste de lecture et alloue de la mémoire pour celle-ci. Notez que si vous ajoutez des chaînes de caractères à cette structure, elles seront libérées par l'opération correspondante LIBMTP_destroy_playlist_t ultérieurement, alors soyez prudent lors de l'utilisation de strdup() lors de l'affectation de chaînes, par exemple :

LIBMTP_playlist_t *pl = LIBMTP_new_playlist_t();
pl->name = strdup(str);
....
LIBMTP_destroy_playlist_t(pl);

int LIBMTP_Set_Playlist_Name (LIBMTP_mtpdevice_t * device, LIBMTP_playlist_t * playlist, const char * newname)

Cette fonction renomme un seul conteneur de fichier objet de liste de lecture. Cela signifie simplement que la propriété PTP_OPC_ObjectFileName est mise à jour, si cela est pris en charge par l'appareil. Le nom de fichier de la liste de lecture devrait nominalement se terminer par une extension telle que '.pla'.

NOTE: si vous souhaitez modifier les métadonnées affichées par l'appareil concernant une liste de lecture, vous ne devez *pas* utiliser cette fonction, utilisez à la place LIBMTP_Update_Playlist() !

Paramètres

device un pointeur vers le périphérique qui contient le fichier.
playlist les métadonnées de la liste de lecture à renommer. En cas de succès, le membre name est mis à jour. Soyez conscient que ce nom peut être différent de newname en fonction des restrictions de l'appareil.
newname le nouveau nom pour cet objet.

Retourne

0 en cas de succès, toute autre valeur signifie échec.

Cette routine met à jour une playlist en fonction des métadonnées fournies. Si le champ des pistes (tracks) des métadonnées contient une liste de pistes, ces pistes seront ajoutées à la playlist à la place de celles déjà présentes, c'est-à-dire que la liste de pistes précédente sera supprimée. Pour les appareils Samsung, l'identifiant de la playlist (metadata->playlist_id) est susceptible de changer.

Paramètres

device un pointeur vers le périphérique sur lequel créer la nouvelle playlist.
metadata les métadonnées de la playlist à mettre à jour. Notez que le champ playlist_id doit contenir l'identifiant approprié de la playlist. L'identifiant de la playlist peut être modifié vers un nouvel identifiant de playlist au moment où la fonction retourne, car la modification sur place n'est pas toujours possible.

Retour

0 en cas de succès, toute autre valeur signifie un échec.
