platform(n) Paquets groupés Tcl platform(n)

NOM

platform - Code et utilitaires de support d'identification de système

SYNOPIS

package require platform ?1.0.10?

platform::generic
platform::identify
platform::patterns identifier

DESCRIPTION

Le paquet platform fournit plusieurs commandes utilitaires utiles pour l'identification de l'architecture d'une machine exécutant Tcl.

Bien que Tcl fournisse le tableau tcl_platform pour identifier l'architecture actuelle (en particulier, les éléments platform et machine), cela n'est pas toujours suffisant. En effet, (sur les machines Unix) tcl_platform reflète les valeurs retournées par la commande uname et celles-ci ne sont pas standardisées sur toutes les plateformes et architectures. De plus, sur au moins une plateforme (AIX), tcl_platform(machine) contient le numéro de série du CPU.

Par conséquent, les applications individuelles doivent manipuler les valeurs dans tcl_platform (ainsi que la sortie des utilitaires spécifiques au système) - ce qui est à la fois gênant pour les développeurs et introduit un risque d'incohérences dans l'identification des architectures et dans les conventions de nommage.

Le paquet platform évite une telle fragmentation - c'est-à-dire qu'il établit une convention de nommage standard pour les architectures exécutant Tcl et permet aux développeurs d'identifier plus facilement l'architecture sur laquelle un programme Tcl s'exécute.

COMMANDES

platform::identify
Cette commande retourne un identifiant décrivant la plateforme sur laquelle le noyau Tcl s'exécute. L'identifiant retourné a le format général OS-CPU. La partie OS de l'identifiant peut contenir des détails tels que la version du noyau, la version de la libc, etc., et ces informations peuvent également contenir des tirets. La partie CPU ne contiendra pas de tirets, faisant du tiret précédent le dernier tiret du résultat.
platform::generic
Cette commande retourne un identifiant simplifié décrivant la plateforme sur laquelle le noyau Tcl s'exécute. Contrairement à platform::identify, elle omet les détails tels que la version du noyau, la version de la libc, etc. L'identifiant retourné a le format général OS-CPU.
platform::patterns identifier
Cette commande prend un identifiant tel que retourné par platform::identify et retourne une liste d'identifiants décrivant les architectures compatibles.

EXEMPLE

Ceci peut être utilisé pour permettre à une application d'être livrée avec plusieurs versions d'une bibliothèque partagée, de sorte que le même paquet fonctionne sur de nombreuses versions d'un système d'exploitation. Par exemple :

package require platform
# Supposons que le script d'application soit .../theapp/bin/theapp.tcl
set binDir [file dirname [file normalize [info script]]]
set libDir [file join $binDir .. lib]
set platLibDir [file join $libDir [platform::identify]]
load [file join $platLibDir support[info sharedlibextension]]
