PLASMOIDVIEWER(1) Manuel de l'utilisateur de plasmoidviewer PLASMOIDVIEWER(1)

NOM

plasmoidviewer - Lance des widgets Plasma dans leur propre fenêtre

SYNTAXE

plasmoidviewer [-v, --version] [-c, --containmentnom] [-a, --appletnom] [-f, --formfactornom] [-l, --locationnom] [-x, --xPositionpositionX] [-y, --yPositionpositionY] [-s, --sizelargeurXhauteur] [-p, --pixmapcachetaille] [-t, --themenom] [-h, --help] [arguments]

DESCRIPTION

plasmoidviewer est un outil graphique permettant aux développeurs de tester des applets Plasma.

Seuls les applets installés seront trouvés. kbuildsycoca5 pourrait devoir être exécuté pour que les applets nouvellement installés soient trouvés.

OPTIONS

-v, --version

Affiche les informations de version.

-c, --containment nom

Le nom du plugin de conteneur.

-a, --applet nom

Le nom du plugin d'applet.

-f, --formfactor nom

Le facteur de forme à utiliser (horizontal, vertical, mediacenter, plan ou application).

-l, --location nom

La contrainte d'emplacement pour démarrer le conteneur (flottant, bureau, plein écran, bord supérieur, bord inférieur, bord gauche, bord droit).

-x, --xPosition positionX

Définit la position x du plasmoidviewer sur le bureau Plasma.

-y, --yPosition positionY

Définit la position y du plasmoidviewer sur le bureau Plasma.

-s, --size largeurXhauteur

Définit la taille de la fenêtre du plasmoidview.

-p, --pixmapcache taille

La taille en Ko du cache de pixmaps.

-t, --theme nom

Le nom du thème que le shell utilisera.

-h, --help

Affiche cette aide.

arguments

Données qui doivent être passées à l'applet en tant qu'événement 'externalData'.

VOIR AUSSI

Une documentation utilisateur plus détaillée est disponible sur help:/plasma-desktop (entrez cette URL dans Konqueror, ou exécutez khelpcenter help:/plasma-desktop).
