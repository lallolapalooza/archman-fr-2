NOM

Plank - Stupidement simple.

DESCRIPTION

Plank se veut le dock le plus simple de la planète. Le but est de ne fournir que ce dont un dock a besoin et absolument rien de plus. C'est, cependant, une bibliothèque qui peut être étendue pour créer d'autres programmes de dock avec des fonctionnalités plus avancées. Ainsi, Plank est la technologie sous-jacente pour Docky (à partir de la version 3.0.0) et vise à fournir toutes les fonctionnalités de base tandis que Docky l'étend pour ajouter des choses plus sophistiquées comme des Docklets, des peintres, des boîtes de dialogue de configuration, etc.

Utilisation :

plank [OPTION]

Options d'aide :

-h, --help
Afficher les options d'aide
--help-all
Afficher toutes les options d'aide
--help-gapplication
Afficher les options GApplication
--help-gtk
Afficher les options GTK+

Options d'application :

-d, --debug
Activer la journalisation de débogage
-v, --verbose
Activer la journalisation détaillée
-n, --name
Le nom de ce dock. Par défaut : "dock1".
--preferences
Afficher la boîte de dialogue des préférences de l'instance qui vient d'être démarrée ou qui est déjà en cours d'exécution
-V, --version
Afficher la version de l'application
--display=DISPLAY
Affichage X à utiliser
