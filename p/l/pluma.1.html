PLUMA(1) Manuel des commandes générales PLUMA(1)

NOM

Pluma - L'éditeur de texte MATE

SYNTAXE

pluma [OPTIONS...] [FICHIERS...]

DESCRIPTION

Pluma est l'éditeur de texte officiel de l'environnement de bureau MATE. Tout en visant la simplicité et la facilité d'utilisation, Pluma est un éditeur de texte polyvalent et puissant. Il peut être utilisé pour créer et modifier toutes sortes de fichiers texte.

Pluma dispose d'un système de plugins flexible qui peut être utilisé pour ajouter dynamiquement de nouvelles fonctionnalités avancées à Pluma lui-même.

Cette page de manuel documente brièvement la commande pluma.

OPTIONS

nom_du_fichier(s)...
Spécifie le fichier à ouvrir lorsque pluma démarre. Si cela n'est pas spécifié, pluma démarrera un nouveau fichier vierge avec une étiquette "Document non sauvegardé". Plusieurs fichiers peuvent être chargés s'ils sont séparés par des espaces. pluma prend également en charge la manipulation de fichiers distants.
--display=DISPLAY
Affichage X à utiliser.
--encoding
Définit le codage de caractères à utiliser pour ouvrir les fichiers listés sur la ligne de commande.
--new-window
Crée une nouvelle fenêtre de premier niveau dans une instance existante de pluma.
--new-document
Crée un nouveau document dans une instance existante de pluma, sur la dernière fenêtre Pluma qui avait le focus.
+[num]
Pour le premier fichier, va à la ligne spécifiée par "num" (ne pas insérer d'espace entre le signe "+" et le nombre). Si "num" est manquant, va à la dernière ligne.
--list-encodings
Affiche la liste des valeurs possibles pour l'option d'encodage et quitte
--version
Affiche les informations de version et quitte
-?, -h, --help
Affiche les options standard de la ligne de commande.
--help-all
Affiche toutes les options de la ligne de commande.

Ce programme accepte également les options GTK standard.

EXEMPLES

pluma --encoding WINDOWS-1252 ftp://ftp.kernel.org/pub/linux/kernel/README

Ouvre le fichier README du serveur FTP de kernel.org (noyau Linux) en utilisant le codage de caractères Windows-1252.

pluma +156 http://mate-desktop.org/

Ouvre la page web principale de mate-desktop.org et saute à la ligne 156.

pluma --new-window ~/.bashrc ~/.bash_history

Ouvre les fichiers .bashrc et .bash_history de l'utilisateur courant dans une nouvelle fenêtre Pluma.
