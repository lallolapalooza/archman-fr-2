PLASTIC(1) Manuel général des commandes PLASTIC(1)

NOM


plastic - Émulateur NES avec interfaces graphique (GUI) et en terminal (TUI).

SYNTAXE


plastic [fichier-rom]
plastic_tui [fichier-rom] [-a]

DESCRIPTION


plastic est un émulateur NES écrit en Rust, conçu pour exécuter des jeux NES avec une interface graphique (GUI) et une interface en mode terminal (TUI).


L'interface graphique (plastic) peut être lancée sans aucun argument (bien qu'elle puisse être démarrée depuis le terminal avec un fichier ROM) et offre une expérience graphique conviviale.


L'interface en mode terminal (plastic_tui) permet aux utilisateurs d'exécuter l'émulateur dans le terminal avec des options facultatives pour un contrôle supplémentaire.


Les états sauvegardés sont stockés dans le chemin suivant :
~/.local/share/plastic/saved_states

OPTIONS


plastic [fichier-rom]
Lance l'émulateur avec l'interface graphique. Bien que les arguments soient facultatifs, spécifier un fichier ROM comme argument est recommandé pour un jeu immédiat.


plastic_tui [fichier-rom] [-a]
Lance l'émulateur avec l'interface en mode terminal. Les options suivantes sont disponibles :
- fichier-rom : Spécifie le fichier ROM NES à charger.
- -a : Désactive la sortie audio lors de l'exécution en mode TUI.

INSTALLATION


Les dernières versions de plastic et plastic_tui peuvent être installées en utilisant Cargo :


cargo install plastic
cargo install plastic_tui

EXEMPLES


Exécuter plastic avec l'interface graphique :


plastic


plastic chemin/vers/rom.nes


Exécuter plastic_tui avec un fichier ROM spécifique :


plastic_tui chemin/vers/rom.nes


Exécuter plastic_tui sans audio :


plastic_tui chemin/vers/rom.nes -a
