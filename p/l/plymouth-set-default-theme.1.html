NOM

plymouth-set-default-theme - Définir le thème plymouth

SYNTAXE

plymouth-set-default-theme [OPTION...] [THÈME]

DESCRIPTION

Lorsqu'il est appelé avec un argument THÈME, la commande plymouth-set-default-theme change le thème de démarrage préféré et effectue également la régénération nécessaire du disque RAM initial (initrd) car plymouth est chargé à partir du chargeur de démarrage depuis l'initrd avant le montage du système de fichiers racine.

Si plymouth-set-default-theme est invoqué sans options ni paramètres, il affiche par défaut le thème actuellement sélectionné. Cette sortie est utilisée par les scripts d'aide plymouth-generate-initrd et plymouth-update-initrd pour définir le thème approprié dans le disque RAM initial.

OPTIONS

Les options suivantes sont comprises :

-h, --help

Affiche un résumé des options.

-l, --list

Liste les thèmes disponibles.

-r, --reset

Rétablit le thème par défaut.

-R, --rebuild-initrd

Reconstruit l'initrd (nécessaire après avoir changé de thème).
