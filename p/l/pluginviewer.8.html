PLUGINVIEWER(8) Manuel du gestionnaire système PLUGINVIEWER(8)

NOM

pluginviewer - lister les plugins SASL chargeables et leurs propriétés

SYNTAXE

pluginviewer [-a] [-s] [-c] [-b min=N,max=N] [-e ssf=N,id=ID] [-m MECHS] [-x AUXPROP_MECHS] [-f FLAGS] [-p PATH]

DESCRIPTION

pluginviewer peut être utilisé par un administrateur système pour le dépannage des installations SASL. Cet utilitaire permet de lister les plugins clients et serveurs chargeables (correctement configurés), ainsi que les plugins auxprop.

OPTIONS

-a
Lister les plugins auxprop.
-s
Lister les plugins d'authentification serveur (SASL).
-c
Lister les plugins d'authentification client (SASL).
-b min=N1,max=N2
Lister les plugins d'authentification client (SASL). Force de la couche de sécurité SASL en bits. min=N1 spécifie la force minimale à utiliser (1 => protection d'intégrité). max=N2 spécifie la force maximale à utiliser. Seuls les mécanismes SASL qui supportent une couche de sécurité d'une force M telle que N1 <= M <= N2 seront affichés.
-e ssf=N,id=ID
Suppose qu'une couche de sécurité externe (par exemple TLS) d'une force N bits est installée. L'ID est l'identité d'authentification utilisée par la couche de sécurité externe.
-m MECHS
Limiter les plugins SASL listés à ceux inclus dans la liste MECHS (séparés par des espaces).
-x AUXPROP_MECHS
Limiter les plugins auxprop listés à ceux inclus dans la liste AUXPROP_MECHS (séparés par des espaces).
-f FLAGS
Définir les indicateurs de sécurité. FLAGS est une liste d'un ou plusieurs des indicateurs de sécurité suivants, séparés par des virgules : noplain (le mécanisme SASL n'envoie pas le mot de passe en clair pendant l'authentification), noactive (exiger une protection contre les attaques actives), nodict (exiger des mécanismes sécurisés contre les attaques par dictionnaire passif), forwardsec (exiger la confidentialité persistante), passcred (exiger des mécanismes qui peuvent déléguer les identifiants du client), maximum (exiger tous les indicateurs de sécurité).
-p PATH
Spécifie un chemin de recherche pour les plugins, séparé par des deux-points.

VOIR AUSSI

10 avril 2006 CMU SASL
