plistutil(1) Manuel des commandes générales plistutil(1)

NOM

plistutil - Convertir un FICHIER plist entre les formats binaire, XML et JSON

SYNTAXE

plistutil [OPTIONS] [-i FICHIER] [-o FICHIER]

DESCRIPTION

plistutil permet de convertir un fichier de liste de propriétés entre les formats binaire, XML et JSON.

OPTIONS

-i, --infile FICHIER
FICHIER d'entrée à convertir. Si cet argument est omis ou si - est passé en nom de fichier, plistutil lira depuis stdin.
-o, --outfile FICHIER
FICHIER de sortie à convertir. Si cet argument est omis ou si - est passé en nom de fichier, plistutil écrira sur stdout.
-f, --format [bin|xml|json|openstep]
Forcer le format de sortie, quel que soit le type d'entrée. Ceci est utile si le format d'entrée n'est pas connu, mais que le format de sortie doit toujours être dans un format spécifique (comme xml ou json).

Si omis, les données plist XML seront converties en binaire et vice-versa. Pour convertir vers/depuis JSON ou OpenStep, le format de sortie doit être spécifié.

-p, --print FICHIER
Afficher le PList dans un format lisible par l'homme.
-c, --compact
Uniquement pour JSON et OpenStep : Afficher la sortie sous forme compacte. Par défaut, la sortie sera joliment formatée.
-s, --sort
Trier tous les nœuds de dictionnaire par ordre lexicographique selon la clé avant de convertir au format de sortie.
-h, --help
Affiche les informations d'utilisation.
-d, --debug
Active la sortie de débogage étendue.
-v, --version
Affiche les informations de version

EXEMPLES

plistutil -i test.plist -o out.plist
Convertir test.plist et écrire dans out.plist. Si test.plist est au format XML, out.plist sera au format binaire. Si test.plist est au format binaire, out.plist sera au format XML.
plistutil -i test.plist -o out.plist -f bin
Identique à ci-dessus, mais la sortie sera toujours au format binaire.
plistutil -i test.plist -f xml
Afficher test.plist en tant que plist XML, quel que soit le format d'entrée.
plistutil -i test.plist -f xml -o -
Identique à ci-dessus.
plistutil -i test.plist -f json
Afficher test.plist en tant que plist JSON, quel que soit le format d'entrée.
cat test.plist |plistutil -f xml
Prendre les données plist depuis stdin - transmises via cat - et écrire la sortie en XML sur stdout.
