LIBIEC61883(1) LIBIEC61883(1)

NOM

plugctl - un programme pour obtenir ou définir la valeur de n'importe quel registre MPR ou PCR

SYNTAXE

plugctl [-p port] [-n nœud] prise.attribut[=valeur]

DESCRIPTION

plugctl est un programme permettant d'obtenir ou de définir la valeur d'un attribut de prise.

prise est l'un de oMPR, iMPR, oPCR[n] ou iPCR[n] (insensible à la casse). Veuillez fournir un index numérique pour [n].

Cette page de manuel a été écrite pour la distribution Debian car le programme original ne dispose pas de page de manuel.

OPTIONS

Ces programmes suivent la syntaxe habituelle des lignes de commande GNU. Un résumé des options est inclus ci-dessous.

-p port
Obtenir ou définir la valeur d'un attribut de prise dans ce port.
-n nœud
Obtenir ou définir la valeur d'un attribut de prise dans ce nœud.
