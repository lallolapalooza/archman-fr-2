pfm_get_pmu_info(3)

Paquet: libpfm

Licences: MIT

LIBPFM(3) Manuel du programmeur Linux LIBPFM(3)

NOM

pfm_get_pmu_info - obtenir des informations sur le PMU

SYNTAXE

#include <perfmon/pfmlib.h>

int pfm_get_pmu_info(pfm_pmu_t pmu, pfm_pmu_info_t *info);

DESCRIPTION

Cette fonction renvoie dans info des informations sur un modèle de PMU désigné par son identifiant dans pmu.

La structure pfm_pmu_info est définie comme suit :

typedef struct {
        const char              *name;
        const char              *desc;
        pfm_pmu_t               pmu;
        pfm_pmu_type_t          type;
        int                     size;
        int                     nevents;
        int                     first_event;
        int                     max_encoding;
        int                     num_cntrs;
        int                     num_fixed_cntrs;
        struct {
                int             is_present:1;
                int             is_arch_default:1;
                int             is_core:1;
                int             is_uncore:1;
                int             reserved:28;
        };
} pfm_pmu_info_t;

Les champs de cette structure sont définis comme suit :

name
C'est le nom symbolique du PMU. Ce nom peut être utilisé comme préfixe dans une chaîne d'événements. C'est une chaîne en lecture seule.
desc
C'est la description du PMU. C'est une chaîne en lecture seule.
pmu
C'est le code d'identification unique du PMU. Il est identique à la valeur passée dans pmu et il est fourni uniquement pour des raisons de complétude.
type
Ce champ contient le type du PMU. Les types suivants sont définis :
PFM_PMU_TYPE_UNKNOWN
Le type du PMU n'a pas pu être déterminé.
PFM_PMU_TYPE_CORE
Ce champ est mis à un si le PMU est implémenté par le cœur du processeur.
PFM_PMU_TYPE_UNCORE
Ce champ est mis à un si le PMU est implémenté sur la puce du processeur mais au niveau du socket, c'est-à-dire qu'il capture les événements pour tous les cœurs.
nevents
C'est le nombre d'événements disponibles pour ce modèle de PMU en fonction du processeur hôte. Il n'est valide que si le champ is_present est mis à 1. Les identifiants d'événements ne sont pas garantis contigus. En d'autres termes, ce n'est pas parce que nevents est égal à 100 que les identifiants d'événements vont de 0 à 99. La fonction itératrice pfm_get_event_next() doit être utilisée pour passer d'un identifiant à l'autre.
first_event
Ce champ renvoie l'index opaque du premier événement pour ce modèle de PMU. L'index peut être utilisé avec les fonctions pfm_get_event_info() ou pfm_get_event_next(). S'il n'y a pas d'événement disponible, ce champ contient -1.
num_cntrs
Ce champ contient le nombre de compteurs génériques pris en charge par le PMU. Un compteur est générique s'il peut compter plus d'un événement. Lorsqu'il n'est pas possible de déterminer le nombre de compteurs génériques, ce champ contient -1.
num_fixed_cntrs
Ce champ contient le nombre de compteurs fixes pris en charge par le PMU. Un compteur est fixe s'il est câblé pour compter un seul événement. Lorsqu'il n'est pas possible de déterminer le nombre de compteurs génériques, ce champ contient -1.
size
Ce champ contient la taille de la structure passée. Ce champ est utilisé pour permettre l'extensibilité de la structure sans compromettre la compatibilité ascendante. La valeur doit être définie à sizeof(pfm_pmu_info_t). Si, au lieu de cela, une valeur de 0 est spécifiée, la bibliothèque suppose que la structure passée est identique à la première version de l'ABI dont la taille est PFM_PMU_INFO_ABI0. Ainsi, si des champs ont été ajoutés après la première ABI, ils ne seront pas définis par la bibliothèque. La bibliothèque vérifie que les octets au-delà de ce qui est implémenté sont mis à zéro.
max_encoding
Ce champ renvoie le nombre de codes d'événements retournés par pfm_get_event_encoding().
is_present
Ce champ est mis à un si le modèle de PMU a été détecté sur le système hôte.
is_dfl
Ce champ est mis à un si le PMU est le PMU par défaut pour cette architecture. Sinon, ce champ est à zéro.

RETOUR

En cas de succès, la fonction retourne PFM_SUCCESS et les informations du PMU dans info, sinon elle retourne un code d'erreur.

ERREURS

PFMLIB_ERR_NOINIT
La bibliothèque n'a pas été initialisée correctement.
PFMLIB_ERR_NOTSUPP
Le modèle de PMU n'est pas pris en charge par la bibliothèque.
PFMLIB_ERR_INVAL
L'argument pmu est invalide ou info est NULL ou la valeur de size n'est pas zéro.
