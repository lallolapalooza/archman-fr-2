Paquet: libpfm

Licences: MIT

LIBPFM(3) Manuel du programmeur Linux LIBPFM(3)

NOM

pfm_get_event_info - obtenir des informations sur un événement

SYNOPSIS

#include <perfmon/pfmlib.h>

int pfm_get_event_info(int idx, pfm_os_t os, pfm_event_info_t *info);

DESCRIPTION

Cette fonction renvoie dans info des informations sur un événement spécifique désigné par son identifiant unique opaque dans idx pour le système d'exploitation spécifié dans os.

La structure pfm_event_info_t est définie comme suit :

typedef struct {
        const char              *name;
        const char              *desc;
        const char              *equiv;
        size_t			size;
        uint64_t                code;
        pfm_pmu_t               pmu;
        pfm_dtype_t             dtype
        int                     idx;
        int                     nattrs;
        struct {
          unsigned int is_precise:1;
          unsigned int reserved_bits:31;
        };
} pfm_event_info_t;

Les champs de cette structure sont définis comme suit :

name
C'est le nom de l'événement. Il s'agit d'une chaîne en lecture seule.
desc
C'est la description de l'événement. Il s'agit d'une chaîne en lecture seule. Elle peut contenir plusieurs phrases.
equiv
Certains événements peuvent n'être que des variations d'événements réels. Ils peuvent être fournis comme raccourcis pratiques pour éviter de fournir une longue liste d'attributs. Pour ces événements, ce champ n'est pas NULL et contient la chaîne d'événement équivalente complète.
code
C'est le code brut de l'événement. Il ne faut pas le confondre avec le codage de l'événement. Ce champ ne représente que le code de sélection de l'événement, il n'inclut aucune unité de masque ou réglage d'attribut.
pmu
C'est l'identification du modèle PMU auquel appartient cet événement. Il est de type pfm_pmu_t. En utilisant cette valeur et la fonction pfm_get_pmu_info, il est possible d'obtenir des informations PMU.
dtype
Ce champ renvoie la représentation des données de l'événement. Par défaut, c'est PFM_DATA_UINT64.

idx C'est l'identifiant unique opaque de l'événement. Il est identique à l'idx passé à l'appel et est fourni pour la complétude.

nattrs
C'est le nombre d'attributs pris en charge par cet événement. Les attributs peuvent être des unités de masques ou des modificateurs. Si l'événement n'a pas d'attribut, alors la valeur de ce champ est simplement 0.
size
Ce champ contient la taille de la structure passée. Ce champ est utilisé pour assurer l'extensibilité de la structure sans compromettre la compatibilité descendante. La valeur doit être définie à sizeof(pfm_event_info_t). Si au lieu de cela, une valeur de 0 est spécifiée, la bibliothèque suppose que la structure passée est identique à la première version ABI dont la taille est PFM_EVENT_INFO_ABI0. Ainsi, si des champs ont été ajoutés après la première ABI, ils ne seront pas définis par la bibliothèque. La bibliothèque vérifie que les octets au-delà de ce qui est implémenté sont à zéro.
is_precise
Ce champ de bits indique si l'événement prend en charge l'échantillonnage précis. L'échantillonnage précis est un mécanisme matériel qui évite le décalage d'adresse d'instruction lors de l'utilisation de l'échantillonnage basé sur interruption. Lorsque l'événement a des unités de masques, ce champ signifie qu'au moins une unité de masque prend en charge l'échantillonnage précis. Sur les processeurs Intel X86, cela indique si l'événement prend en charge l'échantillonnage précis basé sur événements (PEBS).
is_speculative
Ce champ de bits indique si l'événement inclut des occurrences se produisant lors de l'exécution spéculative, à la fois pour le chemin incorrect et correct. Étant donné que ce type d'informations d'événement n'est pas toujours disponible auprès des fournisseurs, ce champ utilise plusieurs bits. Une valeur de PFM_EVENT_INFO_SPEC_NA indique que les informations de spéculation ne sont pas disponibles. Une valeur de PFM_EVENT_INFO_SPEC_TRUE indique que l'événement est compté pendant l'exécution spéculative. Une valeur de PFM_EVENT_INFO_SPEC_FALS indique que l'événement n'est pas compté pendant l'exécution spéculative.

L'énumération pfm_os_t fournit les choix suivants :

PFM_OS_NONE
Les informations renvoyées concernent uniquement ce que le matériel PMU exporte. Aucun attribut de système d'exploitation n'est pris en compte.
PFM_OS_PERF_EVENT
Les informations renvoyées incluent le matériel PMU réel et les attributs supplémentaires exportés par l'interface du noyau perf_events. Les attributs perf_event concernent uniquement le matériel PMU. Dans le cas où perf_events n'est pas détecté, une erreur est renvoyée.
PFM_OS_PERF_EVENT_EXT
Les informations renvoyées incluent tout ce qui est déjà fourni par PFM_OS_PERF_EVENT plus tous les attributs logiciels contrôlés par perf_events, tels que la période d'échantillonnage, l'échantillonnage précis.

RETOUR

En cas de succès, la fonction renvoie PFM_SUCCESS et les informations sur l'événement dans info, sinon elle renvoie un code d'erreur.

ERREURS

PFMLIB_ERR_NOINIT
La bibliothèque n'a pas été initialisée correctement.
PFMLIB_ERR_INVAL
L'argument idx est invalide ou info est NULL ou size n'est pas zéro.
PFMLIB_ERR_NOTSUPP
Le os demandé n'est pas détecté ou pris en charge.
