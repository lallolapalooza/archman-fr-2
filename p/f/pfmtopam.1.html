NOM

pamtopfm - Convertir une image PFM (Portable Float Map) au format Netpbm

SYNTAXE

pfmtopam [-maxval=n] [-verbose] [fichierimage]

Toutes les options peuvent être abrégées à leur plus courte forme unique. Vous pouvez utiliser deux traits d'union au lieu d'un. Vous pouvez séparer un nom d'option et sa valeur par un espace blanc au lieu d'un signe égal.

DESCRIPTION

Ce programme fait partie de Netpbm(1)

pfmtopam lit une image PFM (Portable Float Map) et la convertit en PAM.

Voir pamtopfm(1)
pour une description du PFM.

Si vous souhaitez l'un des anciens formats Netpbm plus portables, exécutez la sortie à travers pamtopnm.

pamtopfm crée un PAM avec le type de tuple 'RGB' ou 'GRAYSCALE' selon que le PFM est dans le sous-format couleur ou non.

Utilisez pamtopfm(1)
pour convertir une image PFM au format Netpbm.

OPTIONS

-maxval=n

Ceci spécifie la valeur maximale pour le PAM. La valeur par défaut est 255.

-verbose

Ceci fait afficher à pfmtopam des messages décrivant
le fichier d'entrée PFM.
