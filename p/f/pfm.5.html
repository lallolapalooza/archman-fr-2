PFM Format Description(5) Manuel des formats de fichiers PFM Format Description(5)

NOM

PFM - Format de fichier d'image graphique PFM

DESCRIPTION

Ce document décrit le format de fichier d'image graphique PFM tel qu'il est compris par les convertisseurs Netpbm pamtopfm(1) et pfmtopam(1).

Il existe plusieurs formats similaires connus sous le nom de PFM dans le monde, aucun d'entre eux n'est documenté de manière faisant autorité. Le format décrit ici est celui que Bryan Henderson a déduit d'un programme qu'il a trouvé quelque part et qui traitait d'un format 'PFM'.

Le format PFM est inspiré des formats Netpbm, et vous y verrez de nombreuses similitudes. Ce n'est cependant pas un format Netpbm officiel. Son objectif n'est pas conforme à celui des formats Netpbm.

Le format

Une image PFM est un flux d'octets. Le flux se compose d'un en-tête suivi immédiatement d'un raster. Ces deux composants sont décrits ci-dessous. Il n'y a pas de délimiteurs avant ou après les sections décrites.

En-tête PFM

L'en-tête PFM est constitué de 3 'lignes' consécutives de texte ASCII. Après chaque ligne se trouve un caractère d'espacement. Ce caractère est généralement un caractère de nouvelle ligne, d'où le terme 'ligne', mais il n'est pas obligé de l'être.

pamtopfm utilise une nouvelle ligne dans le PFM qu'il génère.

Ligne d'identifiant

La ligne d'identifiant contient les caractères 'PF' ou 'Pf'. PF signifie qu'il s'agit d'un PFM couleur. Pf signifie qu'il s'agit d'un PFM en niveaux de gris.

Ligne des dimensions

La ligne des dimensions contient deux entiers décimaux positifs, séparés par un espace. Le premier est la largeur de l'image ; le second est la hauteur. Les deux sont en pixels.

Facteur d'échelle / Boutisme

La ligne Facteur d'échelle / Boutisme est une ligne étrange qui intègre des informations de boutisme dans une description d'échelle par ailleurs logique. La ligne se compose d'un nombre décimal non nul, pas nécessairement un entier. Si le nombre est négatif, cela signifie que le raster PFM est little endian. Sinon, il est big endian. La valeur absolue du nombre est le facteur d'échelle de l'image.

Le facteur d'échelle indique les unités des échantillons dans le raster. Vous l'utilisez d'une manière ou d'une autre, conjointement avec des informations d'unité comprises séparément, pour transformer une valeur d'échantillon en quelque chose de significatif, comme des watts par mètre carré.

Raster PFM

Le raster est une séquence de pixels, empilés les uns après les autres, sans aucun délimiteur. Ils sont groupés par ligne, avec les pixels de chaque ligne ordonnés de gauche à droite et les lignes ordonnées de bas en haut.

Chaque pixel se compose de 1 ou 3 échantillons, empilés les uns après les autres, sans aucun délimiteur. 1 échantillon pour un PFM en niveaux de gris et 3 pour un PFM couleur (voir la ligne d'identifiant de l'en-tête PFM).

Chaque échantillon se compose de 4 octets consécutifs. Les octets représentent une chaîne de 32 bits, au format big endian ou little endian, selon ce qui est déterminé par la ligne Facteur d'échelle / Boutisme de l'en-tête PFM. Cette chaîne est un code de nombre flottant IEEE 32 bits. Comme c'est le même format que la plupart des CPU et compilateurs utilisent, vous pouvez généralement faire en sorte qu'un programme utilise directement les octets comme un nombre flottant, après avoir géré la variation du boutisme.
