pfm_get_event_encoding(3)

Paquet: libpfm

Licences: MIT

LIBPFM(3) Manuel du programmeur Linux LIBPFM(3)

NOM

pfm_get_event_encoding - obtenir le codage brut d'un événement

SYNTAXE

#include <perfmon/pfmlib.h>

int pfm_get_event_encoding(const char *str,int dfl_plm, char **fstr, int *idx, uint64_t *code, int *count);

DESCRIPTION

Cette fonction est utilisée pour récupérer le codage brut de l'événement correspondant à la chaîne d'événement dans str. Un seul événement par appel peut être codé. Ainsi, str ne peut contenir qu'un seul nom d'événement symbolique. La chaîne peut contenir des masques d'unité et des modificateurs. Le masque de niveau de privilège par défaut est passé dans dfl_plm. Il peut être utilisé en fonction de l'événement.

Cette fonction est dépréciée. Elle est remplacée par pfm_get_os_event_encoding() où l'OS est défini sur PFM_OS_NONE. Le codage est récupéré via la structure pfm_pmu_encode_arg_t.

Les exemples suivants illustrent la transition :

   int i, count = 0;
   uint64_t *codes;
   ret = pfm_get_event_encoding("RETIRED_INSTRUCTIONS", PFM_PLM3, NULL, &codes, &count);
   if (ret != PFM_SUCCESS)
      err(1", cannot get encoding %s", pfm_strerror(ret));
   for(i=0; i < count; i++)
      printf("count[%d]=0x%"PRIx64"\n", i, codes[i]);

est équivalent à :

   pfm_pmu_encode_arg_t arg;
   int i;
   memset(&arg, 0, sizeof(arg));
   arg.size = sizeof(arg);
   ret = pfm_get_os_event_encoding("RETIRED_INSTRUCTIONS", PFM_PLM3, PFM_OS_NONE, &arg);
   if (ret != PFM_SUCCESS)
      err(1", cannot get encoding %s", pfm_strerror(ret));
   for(i=0; i < arg.count; i++)
      printf("count[%d]=0x%"PRIx64"\n", i, arg.codes[i]);
   free(arg.codes);
Le codage peut nécessiter plusieurs entiers de 64 bits. La fonction peut utiliser le tableau passé dans code si le nombre
d'entrées passées dans count est suffisant. Cependant, si à la fois *codes est NULL et count
est 0, la fonction alloue la mémoire nécessaire pour stocker le codage. Il incombe à l'appelant de
libérer la mémoire éventuellement allouée. Le nombre d'entrées de 64 bits dans codes est reflété dans *count au retour,
que codes ait été alloué ou utilisé tel quel. Si le nombre d'entiers de 64 bits est
supérieur à un, alors l'ordre dans lequel chaque composant est retourné est spécifique au modèle PMU.
Référez-vous à la page man spécifique au PMU.
Le codage brut signifie le codage tel que requis par le modèle PMU sous-jacent. Il peut ne pas être directement utilisable
pour être passé à une API du noyau. Vous pourriez vouloir utiliser des appels de fonction spécifiques à l'API pour garantir
que le codage correct est passé.
Si fstr n'est pas NULL, il pointera vers la chaîne d'événement entièrement qualifiée lors d'un retour réussi. La chaîne
contient le nom de l'événement, tous les masques d'unité définis et la valeur de tous les modificateurs. Elle reflète ce que le codage mesurera réellement.
La fonction alloue la mémoire pour stocker la chaîne. L'appelant doit éventuellement libérer la chaîne.
Voici un exemple de la façon dont cette fonction pourrait être utilisée :
#include <inttypes.h>
#include <err.h>
#include <perfmon/pfmlib.h>
int main(int argc, char **argv)
{
   uint64_t *codes 0;
   int count = 0;
   int ret;
   ret = pfm_initialize();
   if (ret != PFMLIB_SUCCESS)
      err(1", cannot initialize library %s", pfm_strerror(ret));
   ret = pfm_get_event_encoding("RETIRED_INSTRUCTIONS", PFM_PLM3, NULL, &codes, &count);
   if (ret != PFM_SUCCESS)
      err(1", cannot get encoding %s", pfm_strerror(ret));
   for(i=0; i < count; i++)
      printf("count[%d]=0x%"PRIx64"\n", i, codes[i]);
   free(codes);
   return 0;
}

RETOUR

La fonction retourne dans *codes le codage de l'événement et dans *count le nombre d'entiers de 64 bits pour supporter ce codage. En cas de succès, PFM_SUCCESS est retourné, sinon un code d'erreur spécifique est retourné.

ERREURS

PFM_ERR_TOOSMALL
L'argument code est trop petit pour le codage.
PFM_ERR_INVAL
L'argument code ou count est NULL ou la chaîne str contient plus d'un événement symbolique.
PFM_ERR_NOMEM
Pas assez de mémoire.
PFM_ERR_NOTFOUND
Événement non trouvé.
PFM_ERR_ATTR
Attribut d'événement invalide (masque d'unité ou modificateur)
PFM_ERR_ATTR_VAL
Valeur de modificateur invalide.
PFM_ERR_ATTR_SET
Attribut déjà défini, ne peut pas être modifié.
PFM_ERR_ATTR_UMASK
Masque d'unité manquant.
PFM_ERR_ATTR_FEATCOMB
Les masques d'unité ou les fonctionnalités ne peuvent pas être combinés en un seul événement.
