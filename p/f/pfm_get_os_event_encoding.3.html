pfm_get_os_event_encoding(3)

Paquet: libpfm

Licences: MIT

LIBPFM(3) Manuel du programmeur Linux LIBPFM(3)

NOM

pfm_get_os_event_encoding - obtenir l'encodage d'un événement pour un système d'exploitation spécifique

SYNOPSIS

#include <perfmon/pfmlib.h>

int pfm_get_os_event_encoding(const char *str, int dfl_plm, pfm_os_t os,  void *arg);

DESCRIPTION

C'est la fonction clé pour récupérer l'encodage d'un événement pour une interface de système d'exploitation spécifique. La chaîne d'événement passée dans str est analysée et encodée pour le système d'exploitation spécifié par os. Un seul événement par appel peut être encodé. En tant que tel, str ne peut contenir qu'un seul nom d'événement symbolique. L'événement est encodé pour être surveillé aux niveaux de privilège spécifiés par le masque dfl_plm, si cela est pris en charge, sinon ce paramètre est ignoré. Les arguments d'entrée et de sortie spécifiques au système d'exploitation sont passés dans arg.

La chaîne d'événement, str, peut contenir des masques de sous-événements (umask) et tout autre modificateur pris en charge. Un seul événement est analysé à partir de la chaîne. Par commodité, il est possible de passer une liste d'événements séparés par des virgules dans str, mais seul le premier événement est encodé.

Les valeurs suivantes sont prises en charge pour os:

PFM_OS_NONE
Cette valeur permet d'encoder l'événement purement tel que spécifié par le matériel PMU. L'argument arg doit être un pointeur vers une structure pfm_pmu_encode_arg_t qui est définie comme suit : 
typedef struct {
    uint64_t    *codes;
    char        **fstr;
    size_t      size;
    int         count;
    int         idx;
} pfm_pmu_encode_arg_t;

Les champs sont définis comme suit :

codes
Un pointeur vers un tableau de valeurs 64 bits. En entrée, si codes est NULL, la bibliothèque alloue ce qui est nécessaire pour stocker l'encodage de l'événement. Si codes n'est pas NULL en entrée, alors count doit refléter son nombre réel d'éléments. Si count est suffisamment grand, la bibliothèque stocke l'encodage à l'adresse fournie. Sinon, une erreur est retournée.
count
En entrée, le champ contient le nombre maximum d'éléments dans le tableau codes. Au retour, il contient le nombre d'entrées réelles dans codes. Si codes est NULL, alors count doit être zéro.
fstr
Si l'appelant souhaite récupérer la chaîne d'événement entièrement qualifiée où tous les masques d'unité utilisés et tous les modificateurs sont épelés, ce champ doit être défini à une adresse non nulle d'un pointeur vers une chaîne (char **). Au retour, si fstr n'était pas NULL, alors le pointeur de chaîne passé à l'entrée pointe vers la chaîne d'événement. La chaîne est allouée dynamiquement et doit éventuellement être libérée par l'appelant. Si fstr était NULL à l'entrée, alors rien n'est retourné dans ce champ. La séquence d'appel typique ressemble à ceci : 
   char *fstr = NULL
   pfm_pmu_encode_arg_t arg;
   arg.fstr = &fstr;
   ret = pfm_get_os_event_encoding("event",
                                   PFM_PLM0|PFM_PLM3,
                                   PFM_OS_NONE,
                                   &e);
   if (ret == PFM_SUCCESS) {
      printf("fstr=%s\n", fstr);
      free(fstr);
   }
size
Ce champ contient la taille de la structure passée. Ce champ est utilisé pour assurer l'extensibilité de la structure sans compromettre la compatibilité ascendante. La valeur doit être définie à sizeof(pfm_pmu_encode_arg_t). Si, au lieu de cela, une valeur de 0 est spécifiée, la bibliothèque suppose que la structure passée est identique à la première version ABI dont la taille est PFM_RAW_ENCODE_ABI0. Ainsi, si des champs ont été ajoutés après la première ABI, ils ne seront pas définis par la bibliothèque. La bibliothèque vérifie que les octets au-delà de ce qui est implémenté sont des zéros.
idx
Au retour, ce champ contient l'identifiant unique opaque pour l'événement décrit dans str. Cet index peut être utilisé pour récupérer des informations sur l'événement à l'aide de pfm_get_event_info(), par exemple.
PFM_OS_PERF_EVENT, PFM_OS_PERF_EVENT_EXT
Cette valeur permet d'encoder l'événement pour l'interface du noyau Linux perf_event (disponible depuis 2.6.31). L'argument arg doit être un pointeur vers une structure pfm_perf_encode_arg_t. La couche PFM_OS_PERF_EVENT fournit les modificateurs exportés par le matériel PMU sous-jacent, dont certains peuvent en fait être remplacés par l'interface perf_event, tels que les niveaux de privilèges de surveillance. PFM_OS_PERF_EVENT_EXT étend PFM_OS_PERF_EVENT pour ajouter des modificateurs contrôlés uniquement par l'interface perf_event, tels que la période d'échantillonnage (period), la fréquence (freq) et l'accès exclusif aux ressources (excl). 
typedef struct {
    struct perf_event_attr *attr;
    char **fstr;
    size_t size;
    int idx;
    int cpu;
    int flags;
} pfm_perf_encode_arg_t;
Les champs sont définis comme suit :
attr
Un pointeur vers une structure perf_event_attr telle que définie dans perf_event.h. Ce champ ne peut pas être NULL à l'entrée. La structure n'est pas complètement écrasée par l'appel. La bibliothèque ne modifie que les champs qu'elle connaît, permettant ainsi des incompatibilités d'ABI perf_event entre l'appelant et la bibliothèque.
fstr
Même comportement que celui décrit pour PFM_OS_NONE ci-dessus.
size
Ce champ contient la taille de la structure passée. Ce champ est utilisé pour assurer l'extensibilité de la structure sans compromettre la compatibilité ascendante. La valeur doit être définie à sizeof(pfm_perf_encode_arg_t). Si, au lieu de cela, une valeur de 0 est spécifiée, la bibliothèque suppose que la structure passée est identique à la première version ABI dont la taille est PFM_PERF_ENCODE_ABI0. Ainsi, si des champs ont été ajoutés après la première ABI, ils ne seront pas définis par la bibliothèque. La bibliothèque vérifie que les octets au-delà de ce qui est implémenté sont des zéros.
idx
Au retour, ce champ contient l'identifiant unique opaque pour l'événement décrit dans str. Cet index peut être utilisé pour récupérer des informations sur l'événement à l'aide de pfm_get_event_info(), par exemple.
cpu
Non utilisé pour le moment.
flags
Non utilisé pour le moment.

Voici un exemple de la manière dont cette fonction pourrait être utilisée avec PFM_OS_NONE :

#include <inttypes.h>
#include <err.h>
#include <perfmon/pfmlib.h>
int main(int argc, char **argv)
{
   pfm_pmu_encode_arg_t arg;
   int i, ret;
   ret = pfm_initialize();
   if (ret != PFM_SUCCESS)
      errx(1, "cannot initialize library %s", pfm_strerror(ret));
   memset(&arg, 0, sizeof(arg));
   ret = pfm_get_os_event_encoding("RETIRED_INSTRUCTIONS", PFM_PLM3, PFM_OS_NONE, &arg);
   if (ret != PFM_SUCCESS)
      err(1, "cannot get encoding %s", pfm_strerror(ret));
   for(i = 0; i < arg.count; i++)
      printf("count[%d]=0x%"PRIx64"\n", i, arg.codes[i]);
   free(arg.codes);
   return 0;
}

RETOUR

La fonction retourne dans arg l'encodage de l'événement pour le os passé dans os. Le contenu de arg dépend de l'argument os. En cas de succès, PFM_SUCCESS est retourné, sinon un code d'erreur spécifique est retourné.

ERREURS

PFM_ERR_TOOSMALL
L'argument code est trop petit pour l'encodage.
PFM_ERR_INVAL
L'argument code ou count est NULL ou le str contient plus d'un événement symbolique.
PFM_ERR_NOMEM
Pas assez de mémoire.
PFM_ERR_NOTFOUND
Événement non trouvé.
PFM_ERR_ATTR
Erreur interne lors de la manipulation de la structure perf_event_attr.
malink" href="#PFM_ERR_ATTR">PFM_ERR_ATTR
Attribut d'événement invalide (masque d'unité ou modificateur)
PFM_ERR_ATTR_VAL
Valeur du modificateur invalide.
PFM_ERR_ATTR_SET
L'attribut est déjà défini, il ne peut pas être modifié.
PFM_ERR_ATTR_UMASK
Masque d'unité manquant.
PFM_ERR_ATTR_FEATCOMB
Les masques d'unité ou les caractéristiques ne peuvent pas être combinés en un seul événement.
