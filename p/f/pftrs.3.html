CPFTRS

Objectif :

!>
!> CPFTRS résout un système d'équations linéaires A*X = B avec une matrice A
!> hermitienne définie positive en utilisant la décomposition de Cholesky
!> A = U**H*U ou A = L*L**H calculée par CPFTRF.
!>

Paramètres

TRANSR 
!>          TRANSR est CHARACTER*1
!>          = 'N' : La TRANSR Normale de A RFP est stockée ;
!>          = 'C' : La TRANSR Conjuguée-Transposée de A RFP est stockée.
!>

UPLO

!>          UPLO est CHARACTER*1
!>          = 'U' : Le triangle supérieur de A RFP est stocké ;
!>          = 'L' : Le triangle inférieur de A RFP est stocké.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de colonnes
!>          de la matrice B. NRHS >= 0.
!>

A

!>          A est un tableau de type COMPLEX, de dimension ( N*(N+1)/2 ) ;
!>          Le facteur triangulaire U ou L de la décomposition de Cholesky
!>          de A RFP = U**H*U ou A RFP = L*L**H, tel que calculé par CPFTRF.
!>          Voir la note ci-dessous pour plus de détails sur A RFP.
!>

B

!>          B est un tableau de type COMPLEX, de dimension (LDB,NRHS)
!>          En entrée, la matrice second membre B.
!>          En sortie, la matrice solution X.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : succès de l'exécution
!>          < 0 : si INFO = -i, le i-ème argument était illégal

SYNOPSIS

                    
SUBROUTINE ZPFTRS( UPLO, TRANSR, N, NRHS, A, LDA, B, LDB, INFO )
  CHARACTER(LEN=1) UPLO
  CHARACTER(LEN=1) TRANSR
  INTEGER N
  INTEGER NRHS
  COMPLEX*16, DIMENSION( N*(N+1)/2 ) :: A
  INTEGER LDA
  COMPLEX*16, DIMENSION( LDB, NRHS ) :: B
  INTEGER LDB
  INTEGER INFO
                    

                

                

                    
Detailed Description

                    
UPLO    (input) CHARACTER*1
        = 'U': Upper triangle of RFP A is stored;
        = 'L': Lower triangle of RFP A is stored.

TRANSR  (input) CHARACTER*1
        = 'N': Non-conjugated transpose of RFP A is stored;
        = 'C': Conjugated transpose of RFP A is stored.

N       (input) INTEGER
        The order of the matrix A. N >= 0.

NRHS    (input) INTEGER
        The number of right hand sides, i.e., the number of columns
        of the matrix B. NRHS >= 0.

A       (output) COMPLEX*16 array, dimension ( N*(N+1)/2 );
        The triangular factor U or L from the Cholesky factorization
        of RFP A = U**H*U or RFP A = L*L**H, as computed by ZPFTRF.
        See note below for more details about RFP A.

LDA     (input) INTEGER
        The leading dimension of the array A.
        If TRANSR = 'N', LDA >= max(1,N).
        If TRANSR = 'C', LDA >= max(1,N).

B       (input/output) COMPLEX*16 array, dimension (LDB,NRHS)
        On entry, the right hand side matrix B.
        On exit, the solution matrix X.

LDB     (input) INTEGER
        The leading dimension of the array B. LDB >= max(1,N).

INFO    (output) INTEGER
        = 0:  successful exit
        < 0:  if INFO = -i, the i-th argument had an illegal value
                    

                

                

                    
Function Documentation

                    
ZPFTRS   solves a system of equations
      A*X = B
      where A is a general matrix, and X and B are general matrices.

      A is a triangular matrix, and is stored in RFP format.
      RFP stands for Rectangular Full Packed format. RFP format is a
      standard packed format storage scheme for matrix that are
      conventionally stored in rectangular full format.

      The library routines that use RFP format have the two-character
      name ZxxxRFP. The first two characters indicate the level of
      precision and the computational routine.

      The data type of the matrix is COMPLEX*16.

Arguments
    UPLO    (input) CHARACTER*1
            Specifies whether the triangle of RFP A is upper or lower.
            = 'U': Upper triangle of RFP A is stored;
            = 'L': Lower triangle of RFP A is stored.

    TRANSR  (input) CHARACTER*1
            Specifies whether RFP A is stored in conjugate-transposed
            form.
            = 'N': Non-conjugated transpose of RFP A is stored;
            = 'C': Conjugated transpose of RFP A is stored.

    N       (input) INTEGER
            The order of the matrix A. N >= 0.

    NRHS    (input) INTEGER
            The number of right hand sides, i.e., the number of columns
            of the matrix B. NRHS >= 0.

    A       (output) COMPLEX*16 array, dimension ( N*(N+1)/2 );
            The triangular factor U or L from the Cholesky factorization
            of RFP A = U**H*U or RFP A = L*L**H, as computed by ZPFTRF.
            See note below for more details about RFP A.

    LDA     (input) INTEGER
            The leading dimension of the array A.
            If TRANSR = 'N', LDA >= max(1,N).
            If TRANSR = 'C', LDA >= max(1,N).

    B       (input/output) COMPLEX*16 array, dimension (LDB,NRHS)
            On entry, the right hand side matrix B.
            On exit, the solution matrix X.

    LDB     (input) INTEGER
            The leading dimension of the array B. LDB >= max(1,N).

    INFO    (output) INTEGER
            = 0:  successful exit
            < 0:  if INFO = -i, the i-th argument had an illegal value

    Further Details:
        We first consider Standard Packed Format when N is even.
        We give an example where N = 6.

            AP is Upper             AP is Lower

          00 01 02 03 04 05       00
             11 12 13 14 15       10 11
                22 23 24 25       20 21 22
                   33 34 35       30 31 32 33
                      44 45       40 41 42 43 44
                         55       50 51 52 53 54 55


        Let TRANSR = 'N'. RFP holds AP as follows:
        For UPLO = 'U' the upper trapezoid A(0:5,0:2) consists of the last
        three columns of AP upper. The lower triangle A(4:6,0:2) consists of
        conjugate-transpose of the first three columns of AP upper.
        For UPLO = 'L' the lower trapezoid A(1:6,0:2) consists of the first
