NOM

pfm_get_event_next - itérer sur les événements

SYNTAXE

#include <perfmon/pfmlib.h>

int pfm_get_event_next(int idx);

DESCRIPTION

Les événements sont identifiés de manière unique par des identifiants entiers opaques. Il n'y a pas d'ordre garanti entre les identifiants. Par conséquent, pour lister tous les événements, il est nécessaire d'utiliser des itérateurs.

Les événements sont regroupés en tables au sein de la bibliothèque. Une table correspond généralement à un modèle ou une famille de PMU. La bibliothèque prend en charge plusieurs modèles de PMU, elle possède donc plusieurs tables. En fonction du matériel hôte et de l'environnement logiciel, les tables sont activées lorsque la bibliothèque est initialisée via pfm_initialize(). Les événements des tables activées sont appelés événements actifs. Les événements des tables non activées sont appelés événements supportés.

Les identifiants d'événements sont généralement récupérés via pfm_find_event() ou lors de l'encodage d'événements.

Pour itérer sur une liste d'événements pour un modèle PMU donné, il suffit d'avoir un identifiant initial pour le PMU. Le premier identifiant d'événement est généralement obtenu via pfm_get_pmu_info().

La fonction pfm_get_event_next() renvoie l'identifiant du prochain événement supporté après celui passé dans idx. Cet itérateur s'arrête lorsque le dernier événement pour le PMU est passé en argument, auquel cas la fonction renvoie -1.

void list_pmu_events(pfm_pmu_t pmu)
{
   struct pfm_event_info info;
   struct pfm_pmu_info pinfo;
   int i, ret;
   memset(&info, 0, sizeof(info));
   memset(&pinfo, 0, sizeof(pinfo));
   info.size = sizeof(info);
   pinfo.size = sizeof(pinfo);
   ret = pfm_get_pmu_info(pmu, &pinfo);
   if (ret != PFM_SUCCESS)
      errx(1, "impossible d'obtenir les informations du pmu");
   for (i = pinfo.first_event; i != -1; i = pfm_get_event_next(i)) {
      ret = pfm_get_event_info(i, &info);
      if (ret != PFM_SUCCESS)
        errx(1, "impossible d'obtenir les informations de l'événement");
        printf("%s Événement: %s::%s\n",
               pinfo.present ? "Actif" : "Supporté",
               pinfo.name, info.name);
  }
}

RETOUR

La fonction renvoie l'identifiant du prochain événement supporté. Elle renvoie -1 lorsque l'argument est déjà le dernier événement pour le PMU.

ERREURS

Aucun code d'erreur, autre que -1, n'est renvoyé par cette fonction.
