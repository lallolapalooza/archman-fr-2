NOM

pfm_get_version - obtenir la version de la bibliothèque

SYNOPSIS

#include <perfmon/pfmlib.h>

int pfm_get_version(void);

DESCRIPTION

Cette fonction peut être appelée à tout moment pour obtenir le niveau de révision de la bibliothèque. Il n'est pas nécessaire d'avoir appelé pfm_initialize() avant d'appeler cette fonction.

Le numéro de révision est composé de deux champs : un numéro majeur et un numéro mineur. Les deux peuvent être extraits à l'aide de macros fournies dans le fichier d'en-tête :

PFMLIB_MAJ_VERSION(v)
retourne le numéro majeur encodé dans v.
PFMLIB_MIN_VERSION(v)
retourne le numéro mineur encodé dans v.

RETOUR

La fonction réussit toujours, c'est-à-dire qu'elle retourne toujours le numéro de version 32 bits.
