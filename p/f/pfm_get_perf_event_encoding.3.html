pfm_get_perf_event_encoding(3)

Paquet: libpfm

Licences: MIT

LIBPFM(3) Manuel du programmeur Linux LIBPFM(3)

NOM

pfm_get_perf_event_encoding - code d'événement pour l'API perf_event

SYNOPIS

#include <perfmon/pfmlib_perf_event.h>

int pfm_get_perf_event_encoding(const char *str, int dfl_plm, struct perf_event_attr *attr, char **fstr, int *idx);

DESCRIPTION

Cette fonction peut être utilisée en conjonction avec l'API noyau Linux perf_events qui fournit un accès aux compteurs de performance matériels, aux compteurs logiciels du noyau et aux points de trace. La fonction prend une chaîne d'événement dans str et un masque de niveau de privilège par défaut dans dfl_plm et remplit les parties pertinentes de la structure de données spécifique perf_events dans attr.

Cette fonction est obsolète. Elle est remplacée par pfm_get_os_event_encoding() avec l'argument OS défini sur PFM_OS_PERF_EVENT ou PFM_OS_PERF_EVENT_EXT. L'utilisation de cette fonction offre un support étendu pour perf_events. Certaines options de configuration de perf_event ne sont disponibles que via cette nouvelle interface.

Les exemples suivants illustrent la transition :

   struct perf_event_attr attr;
   int i, count = 0;
   uint64_t *codes;
   memset(&attr, 0, sizeof(attr));
   ret = pfm_get_perf_event_encoding("RETIRED_INSTRUCTIONS", PFM_PLM3, &attrs, NULL, NULL);
   if (ret != PFM_SUCCESS)
      err(1, "cannot get encoding %s", pfm_strerror(ret));

est équivalent à :

   #include <perfmon/pfmlib_perf_event.h>
   struct perf_event_attr attr;
   pfm_perf_encode_arg_t arg;
   memset(&arg, 0, sizeof(arg));
   arg.size = sizeof(arg);
   arg.attr = &attr;
   ret = pfm_get_os_event_encoding("RETIRED_INSTRUCTIONS", PFM_PLM3, PFM_OS_PERF, &arg);
   if (ret != PFM_SUCCESS)
      err(1, "cannot get encoding %s", pfm_strerror(ret));
Le dfl_plm ne peut pas être zéro, bien qu'il ne soit pas nécessairement utilisé
par l'événement. Selon l'événement, une combinaison des niveaux de privilège
suivants peut être utilisée :
PFM_PLM3
Mesure au niveau de privilège 3. Cela correspond généralement au niveau utilisateur. Sur X86, il correspond
aux niveaux de privilège 3, 2, 1. Consultez la page man spécifique PMU pour vérifier si ce niveau
est pris en charge par votre modèle PMU.
PFM_PLM2
Mesure au niveau de privilège 2. Consultez la page man spécifique PMU pour vérifier si ce niveau
est pris en charge par votre modèle PMU.
PFM_PLM1
Mesure au niveau de privilège 1. Consultez la page man spécifique PMU pour vérifier si ce niveau
est pris en charge par votre modèle PMU.
PFM_PLM0
Mesure au niveau de privilège 0. Cela correspond généralement au niveau noyau. Consultez la page man
spécifique PMU pour vérifier si ce niveau est pris en charge par votre modèle PMU.
PFM_PLMH
Mesure au niveau de privilège hyperviseur. Ceci est utilisé en conjonction avec la virtualisation matérielle.
Consultez la page man spécifique PMU pour vérifier si ce niveau est pris en charge par votre modèle PMU.
Si fstr n'est pas NULL, la fonction fera pointer celui-ci vers la chaîne d'événement qualifiée complète,
c'est-à-dire une chaîne avec le nom de l'événement, tous les masques d'unité définis, et la valeur de tous les modificateurs.
La bibliothèque allouera de la mémoire pour stocker la chaîne d'événement, mais il est de la responsabilité de
l'appelant de libérer cette chaîne en utilisant free().
Si idx n'est pas NULL, il renvoie l'identifiant d'événement unique correspondant.
Seuls certains champs sont modifiés par la fonction, les autres ne sont pas touchés.
Les champs suivants dans attr sont modifiés :
type
Le type de l'événement
config
L'encodage de l'événement
exclude_user
Si l'exécution au niveau utilisateur doit être exclue de la surveillance ou non. La définition
de utilisateur est spécifique au modèle PMU.
exclude_kernel
Si l'exécution au niveau noyau doit être exclue de la surveillance ou non. La définition
de noyau est spécifique au modèle PMU.
exclude_hv
Si l'exécution au niveau hyperviseur doit être exclue de la surveillance ou non. La définition
de hyperviseur est spécifique au modèle PMU.
Par défaut, si aucun modificateur de niveau de privilège n'est spécifié dans la chaîne d'événement, la bibliothèque efface
exclude_user, exclude_kernel et exclude_hv, ce qui a pour effet que l'événement est mesuré à tous les niveaux,
sous réserve de la prise en charge matérielle.
La fonction ne peut traiter qu'un seul événement à la fois. Pour plus de commodité, elle accepte
des chaînes d'événements avec des virgules. Dans ce cas, elle traduira le premier événement jusqu'à la
première virgule. C'est utile si les outils reçoivent des événements sous forme de liste séparée par des virgules.

RETOUR

La fonction renvoie dans attr l'encodage perf_event qui correspond à la chaîne d'événement. Si idx n'est pas NULL, il contiendra l'identifiant d'événement unique en cas de retour réussi. La valeur PFM_SUCCESS est renvoyée en cas de succès, sinon un code d'erreur négatif est renvoyé.

ERREURS

PFM_ERR_TOOSMALL
L'argument code est trop petit pour l'encodage.
PFM_ERR_INVAL
L'argument attr est NULL.
PFM_ERR_NOMEM
Pas assez de mémoire.
PFM_ERR_NOTFOUND
Événement non trouvé.
PFM_ERR_ATTR
Attribut d'événement invalide (masque d'unité ou modificateur)
PFM_ERR_ATTR_VAL
Valeur de modificateur invalide.
PFM_ERR_ATTR_SET
l'attribut est déjà défini, ne peut pas être modifié.
PFM_ERR_ATTR_UMASK
Masque d'unité manquant.
PFM_ERR_ATTR_FEATCOMB
Les masques d'unité ou les fonctionnalités ne peuvent pas être combinés en un seul événement.
