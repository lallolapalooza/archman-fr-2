NOM

pf2afm - Créer un fichier AFM à partir de fichiers de polices Postscript (PFB/PFA/PFM) en utilisant ghostscript

SYNTAXE

pf2afm nom_fichier_police

DESCRIPTION

Ce script invoque gs(1) pour créer un fichier AFM à partir de fichiers PFB / PFA et (optionnellement) PFM. La sortie est dirigée vers nom_fichier_police.afm, qui ne doit pas exister au préalable.

VOIR AUSSI

gs(1)
pf2afm.ps dans le répertoire lib de Ghostscript.

VERSION

Ce document a été révisé pour la dernière fois pour la version Ghostscript 10.04.0.
