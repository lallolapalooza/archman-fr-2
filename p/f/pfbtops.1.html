pfbtops(1) Manuel des commandes générales pfbtops(1)

Nom

pfbtops - traduire les fichiers PostScript Printer Font Binary en Printer Font ASCII

Synopsis

pfbtops [fichier-pfb]
pfbtops --help
pfbtops -v
pfbtops --version

Description

pfbtops traduit une police PostScript Type 1 au format Printer Font Binary (PFB) en format Printer Font ASCII (PFA), en divisant les lignes trop longues des paquets texte en morceaux plus petits. Si fichier-pfb est omis, le fichier PFB sera lu depuis le flux d'entrée standard. La police PFA sera écrite sur le flux de sortie standard. Les polices PostScript pour MS-DOS étaient historiquement fournies au format PFB. L'utilisation d'une police PostScript Type 1 avec groff nécessite la conversion de ses métriques (fichier AFM) en un fichier de description de police groff ; voir afmtodit(1).

L'option --help affiche un message d'utilisation, tandis que -v et --version affichent les informations de version ; toutes quittent ensuite.
