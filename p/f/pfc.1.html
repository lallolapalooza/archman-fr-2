PFC(1) Manuel des commandes générales PFC(1)

NOM

pfc - générateur de filtres précompilés actifs

SYNTAXE

pfc <expression> >/etc/ppp/votre.filtre.actif

DESCRIPTION

Cette page de manuel documente brièvement la commande pfc.

pfc est le compilateur de filtres précompilés (Precompiled Filter Compiler) - un outil pour générer des « filtres précompilés actifs ». Si votre pppd supporte cette fonctionnalité, vous pouvez utiliser cet utilitaire pour générer les fichiers de filtre. Le filtre actif permet à un pppd à la demande de déterminer le trafic « intéressant » et de lancer ensuite la session PPP. L'outil vous permet de créer les filtres, au format libpcap, à utiliser par pppd. Des filtres courants sont utilisés pour ignorer le trafic (c'est-à-dire ntp, divers keepalives de protocole, etc.) afin que les sessions PPP ne soient pas initiées tant que le trafic « réel » ne le nécessite pas.

Notez que l'expression de filtre compilée générée est spécifique aux liaisons point à point et diffère du format généré par tcpdump -ddd.

(spécifiez precompiled-active-filter=/etc/ppp/votre.filtre.actif dans le fichier d'options ppp)

EXEMPLE

/usr/bin/pfc ntp and ldap > /etc/ppp/votre.filtre.actif
