NOM

pfb2pfa - convertir un fichier pfb de type 1 (MSDOS binaire) en pfa (ASCII)

SYNTAXE

pfb2pfa [-v] pfbfile [pfafile]

DESCRIPTION

Programme convertissant une représentation MSDOS binaire d'une police PostScript de type 1 en une version ASCII lisible. Le saut de ligne MSDOS (\r) est converti en saut de ligne UNIX (\n). La sortie est écrite dans un fichier dont le nom est celui fourni sur la ligne de commande ou le nom de base du fichier d'entrée avec l'extension ".pfa".

Avec l'option -v, vous obtiendrez des informations sur ce que le programme fait.
