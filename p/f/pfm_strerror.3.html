NOM

pfm_strerror - retourne une chaîne constante décrivant un code d'erreur

SYNTAXE

#include <perfmon/pfmlib.h>

const char *pfm_strerror(int code);

DESCRIPTION

Cette fonction retourne une chaîne de caractères qui décrit la valeur d'erreur libpfm dans code. La chaîne retournée par l'appel est en lecture seule.

La fonction ne doit être utilisée qu'avec des appels à libpfm documentés pour retourner des codes d'erreur spécifiques. La valeur -1 n'est pas considérée comme un code d'erreur spécifique. Les chaînes et les valeurs de retour de pfm_pmu_t ne peuvent pas être utilisées avec cette fonction. Typiquement, NULL est retourné en cas d'erreur pour les valeurs de chaînes, et PFM_PMU_NONE est retourné pour les valeurs de pfm_pmu_t.

La fonction n'est pas non plus conçue pour gérer les erreurs d'appels système du système d'exploitation, c'est-à-dire les valeurs errno.

RETOUR

La fonction retourne un pointeur vers la chaîne constante décrivant le code d'erreur. La chaîne est en anglais. Si le code est invalide, un message d'erreur par défaut est retourné.

ERREURS

Si le code d'erreur est invalide, la fonction retourne un pointeur vers une chaîne qui dit « unknown error code ».
