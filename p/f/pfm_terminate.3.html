NOM

pfm_terminate - libérer les ressources utilisées par la bibliothèque

SYNOPSIS

#include <perfmon/pfmlib.h>

int pfm_terminate(void);

DESCRIPTION

C'est la dernière fonction qu'un programme doit appeler pour libérer toutes les ressources allouées par la bibliothèque, par exemple la mémoire. La fonction n'est pas réentrante, l'appelant doit s'assurer qu'un seul thread à la fois l'exécute.

VALEUR DE RETOUR

Il n'y a pas de valeur de retour pour cette fonction.
