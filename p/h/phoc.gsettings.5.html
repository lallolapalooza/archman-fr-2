Nom

phoc.gsettings - Gsettings utilisés par phoc

DESCRIPTION

Phoc utilise gsettings pour la majeure partie de sa configuration. Vous pouvez utiliser la commande gsettings(1) pour les modifier ou obtenir des détails sur l'option. Pour obtenir plus de détails sur une option, utilisez gsettings describe, par exemple :

gsettings describe sm.puri.phoc auto-maximize

Ce sont le schéma et les clés gsettings actuellement utilisés :
