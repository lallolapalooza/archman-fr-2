PHAR(1) Commandes utilisateur PHAR(1)

NOM

phar, phar.phar - Outil en ligne de commande pour les archives PHAR (PHP)

SYNTAXE

phar <commande> [options] ...

DESCRIPTION

Le format de fichier PHAR offre un moyen de regrouper des applications PHP entières dans un fichier unique appelé "phar" (archive PHP) pour une distribution et une installation faciles.

Avec la commande phar, vous pouvez créer, mettre à jour ou extraire des archives PHP.

Commandes : add compress delete extract help help-list info list meta-del meta-get meta-set pack sign stub-get stub-set tree version

commande add

Ajoute des entrées à un paquet PHAR.

Arguments requis :

-f fichier
Spécifie le fichier phar à traiter.
...
Un nombre quelconque de fichiers et répertoires d'entrée. Si -i est utilisé, SEULEMENT les fichiers correspondant à l'expression régulière donnée sont empaquetés. Si -x est donné, les fichiers correspondant à cette expression régulière NE SONT PAS empaquetés.

Arguments optionnels :

-a alias
Fournit un nom d'alias pour le fichier phar.
-c algo
Algorithme de compression (voir COMPRESSION )
-i regex
Spécifie une expression régulière pour les fichiers d'entrée.
-l niveau
Nombre de répertoires parents à supprimer des entrées de fichier.
-x regex
Expression régulière pour les fichiers d'entrée à exclure.

commande compress

Compresse ou décompresse tous les fichiers ou une entrée sélectionnée.

Arguments requis :

-c algo
Algorithme de compression (voir COMPRESSION )
-f fichier
Spécifie le fichier phar à traiter.

Arguments optionnels :

-e entrée
Nom de l'entrée à traiter (doit inclure le nom du répertoire interne du PHAR s'il y en a un).

commande delete

Supprime une entrée d'une archive PHAR.

Arguments requis :

-e entrée
Nom de l'entrée à traiter (doit inclure le nom du répertoire interne du PHAR s'il y en a un).
-f fichier
Spécifie le fichier phar à traiter.

commande extract

Extrait un paquet PHAR dans un répertoire.

Arguments requis :

-f fichier
Spécifie le fichier phar à traiter.

Arguments optionnels :

-i regex
Spécifie une expression régulière pour les fichiers d'entrée.
-x regex
Expression régulière pour les fichiers d'entrée à exclure.
...
Répertoire dans lequel extraire (par défaut '.').

commande help

Cette aide ou l'aide pour une commande sélectionnée.

Arguments optionnels :

...
Commande optionnelle pour laquelle récupérer l'aide.

commande help-list

Liste les commandes disponibles.

commande info

Obtient des informations sur un paquet PHAR.

En utilisant -k, il est possible de retourner une seule valeur.

Arguments requis :

-f fichier
Spécifie le fichier phar à traiter.

Arguments optionnels :

-k index
Indice de souscription à traiter.

commande list

Liste le contenu d'une archive PHAR.

Arguments requis :

-f fichier
Spécifie le fichier phar à traiter.

Arguments optionnels :

-i regex
Spécifie une expression régulière pour les fichiers d'entrée.
-x regex
Expression régulière pour les fichiers d'entrée à exclure.

commande meta-del

Supprime les métadonnées d'une entrée PHAR ou d'un paquet PHAR.

Si -k est donné, les métadonnées sont censées être un tableau et l'index donné est supprimé.

Si quelque chose a été supprimé, la valeur de retour est 0, sinon elle est 1.

Arguments requis :

-f fichier
Spécifie le fichier phar à traiter.

Arguments optionnels :

-e entrée
Nom de l'entrée à traiter (doit inclure le nom du répertoire interne du PHAR s'il y en a un).
-k index
Indice de souscription à traiter.

commande meta-get

Récupère les métadonnées d'une entrée PHAR ou d'un paquet PHAR sous forme sérialisée. Si aucun fichier de sortie n'est spécifié pour les métadonnées, stdout est utilisé. Vous pouvez également spécifier un index particulier avec -k. Dans ce cas, les métadonnées sont censées être un tableau et la valeur de l'index donné est retournée en utilisant echo plutôt qu'en utilisant serialize. Si cet index n'existe pas ou si aucune métadonnée n'est présente, la valeur de retour est 1.

Arguments requis :

-f fichier
Spécifie le fichier phar à traiter.

Arguments optionnels :

-e entrée
Nom de l'entrée à traiter (doit inclure le nom du répertoire interne du PHAR s'il y en a un).
-k index
Indice de souscription à traiter.

commande meta-set

Définit les métadonnées d'une entrée PHAR ou d'un paquet PHAR à l'aide d'une entrée sérialisée. Si aucun fichier d'entrée n'est spécifié pour les métadonnées, stdin est utilisé. Vous pouvez également spécifier un index particulier avec -k. Dans ce cas, les métadonnées sont censées être un tableau et la valeur de l'index donné est définie. Si les métadonnées ne sont pas présentes ou sont vides, un nouveau tableau sera créé. Si les métadonnées sont présentes et sont une valeur plate, la valeur de retour est 1. Également en utilisant -k, l'entrée est prise directement plutôt que d'être sérialisée.

Arguments requis :

-f fichier
Spécifie le fichier phar à traiter.
-m meta
Métadonnées à stocker avec l'entrée (données PHP sérialisées).

Arguments optionnels :

-e entrée
Nom de l'entrée à traiter (doit inclure le nom du répertoire interne du PHAR s'il y en a un).
-k index
Indice de souscription à traiter.

commande pack

Empaquette des fichiers dans une archive PHAR.

Lorsque vous utilisez -s <stub>, le fichier stub est exclu de la liste des fichiers/répertoires d'entrée. Pour créer une archive contenant la classe PEAR PHP_Archive, pointez l'argument -p vers PHP/Archive.php.

Arguments requis :

-f fichier
Spécifie le fichier phar à traiter.
...
Un nombre quelconque de fichiers et répertoires d'entrée. Si -i est utilisé, SEULEMENT les fichiers correspondant à l'expression régulière donnée sont empaquetés. Si -x est donné, les fichiers correspondant à cette expression régulière NE SONT PAS empaquetés.

Arguments optionnels :

-a alias
Fournit un nom d'alias pour le fichier phar.
-b bang
Ligne hash-bang pour démarrer l'archive (par exemple #!/usr/bin/php). La marque hash elle-même '#!' et le nouveau ligne

phar(1) - Arch Linux man pages

pack command

Create a PHAR archive.

Required arguments:

-f file
Specifies the PHAR archive file to create.

Optional arguments:

-a
Set the stub to be executable. The stub is written to the metadata of the phar archive and can be set using the stub-set command.
-c algo
Compression algorithm (see COMPRESSION ). The default algorithm is 'gz'. The setting of the PHP_INI php.ini-directive phar.compress
-d key=value
Add metadata to the phar archive. The metadata can be accessed at run-time using Phar::getMetadata(). Metadata is stored in the phar archive and is serialized using PHP's serialize() function. The key and value are required.
-e
Set the Phar archive to be executable. The stub is written to the metadata of the phar archive and can be set using the stub-set command. The hash mark '#!' and the newline character are optional.
-h hash
Selects the hash algorithm (see HASH ). The default algorithm is 'sha1'. The setting of the PHP_INI php.ini-directive phar.hash
-i regex
Specifies a regular expression for input files.
-l level
Number of preceding subdirectories to strip from file entries
-m
Set the stub to be executable. The stub is written to the metadata of the phar archive and can be set using the stub-set command.
-p loader
Location of PHP_Archive class file (pear list-files PHP_Archive).You can use '0' or '1' to locate it automatically using the mentioned pear command. When using '0' the command does not error out when the class file cannot be located. This switch also adds some code around the stub so that class PHP_Archive gets registered as phar:// stream wrapper if necessary. And finally this switch will add the file phar.inc from this package and load it to ensure class Phar is present.
-s stub
Select the stub file. The stub is the file that is executed when the phar archive is run. The hash mark '#!' and the newline character are optional.
-x regex
Regular expression for input files to exclude.
-y key
Private key for OpenSSL signing.

sign command

Set signature hash algorithm.

Required arguments:

-f file
Specifies the phar file to work on.
-h hash
Selects the hash algorithm (see HASH )

Optional arguments:

-y key
Private key for OpenSSL signing.

stub-get command

Get the stub of a PHAR file. If no output file is specified as stub then stdout is being used.

Required arguments:

-f file
Specifies the phar file to work on.

Optional arguments:

-s stub
Select the stub file.

stub-set command

Set the stub of a PHAR file. If no input file is specified as stub then stdin is being used.

Required arguments:

-f file
Specifies the phar file to work on.

Optional arguments:

-b bang
Hash-bang line to start the archive (e.g. #!/usr/bin/php). The hash mark itself '#!' and the newline character are optional.
-p loader
Location of PHP_Archive class file (pear list-files PHP_Archive).You can use '0' or '1' to locate it automatically using the mentioned pear command. When using '0' the command does not error out when the class file cannot be located. This switch also adds some code around the stub so that class PHP_Archive gets registered as phar:// stream wrapper if necessary. And finally this switch will add the file phar.inc from this package and load it to ensure class Phar is present.
-s stub
Select the stub file.

tree command

Get a directory tree for a PHAR archive.

Required arguments:

-f file
Specifies the phar file to work on.

Optional arguments:

-i regex
Specifies a regular expression for input files.
-x regex
Regular expression for input files to exclude.
