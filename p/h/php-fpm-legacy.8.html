PHP-FPM(8) Langage de script PHP-FPM(8)

NOM

php-fpm - Gestionnaire de processus PHP FastCGI 'PHP-FPM'

SYNTAXE

php-fpm [options]

DESCRIPTION

PHP est un langage de script généraliste largement utilisé, particulièrement adapté au développement Web et pouvant être intégré dans du HTML. Ceci est une variante de PHP qui s'exécutera en arrière-plan en tant que démon, en attente de requêtes CGI. La sortie est enregistrée dans /var/log/php-fpm.log.

La plupart des options sont définies dans le fichier de configuration. Le fichier de configuration est /etc/php-legacy/php-fpm.conf. Par défaut, php-fpm répondra aux requêtes CGI en écoutant sur localhost, port HTTP 9000. Par conséquent, php-fpm s'attend à ce que votre serveur Web transfère toutes les requêtes pour les fichiers '.php' au port 9000 et vous devriez modifier en conséquence le fichier de configuration de votre serveur Web.

OPTIONS

-C
Ne pas changer de répertoire vers celui du script
--php-ini chemin|fichier
-c chemin|fichier
Rechercher le fichier php.ini dans le répertoire chemin ou utiliser le fichier spécifié
--no-php-ini
-n
Aucun fichier php.ini ne sera utilisé
--define foo[=bar]
-d foo[=bar]
Définir l'entrée INI foo avec la valeur bar
-e
Générer des informations étendues pour le débogueur/profiler
--help
-h
Cette aide
--info
-i
Informations et configuration PHP
--modules
-m
Afficher les modules compilés
--version
-v
Numéro de version
--prefix chemin
-p
Spécifier un chemin préfixe alternatif (le défaut est /usr)
--pid fichier
-g
Spécifier l'emplacement du fichier PID.
--fpm-config fichier
-y
Spécifier un chemin alternatif pour le fichier de configuration du gestionnaire de processus FastCGI (le défaut est /etc/php-legacy/php-fpm.conf)
--test
-t
Tester le fichier de configuration FPM et quitter. Si appelé deux fois (-tt), la configuration est déversée avant de quitter.
--daemonize
-D
Forcer l'exécution en arrière-plan et ignorer l'option daemonize du fichier de configuration.
--nodaemonize
-F
Forcer à rester au premier plan et ignorer l'option daemonize du fichier de configuration.
--force-stderr
-O
Forcer la sortie vers stderr en nodaemonize, même si stderr n'est pas un TTY.
--allow-to-run-as-root
-R
Permettre au pool de s'exécuter en tant que root (désactivé par défaut)

FICHIERS

php-fpm.conf
Le fichier de configuration du démon php-fpm.
php.ini
Le fichier de configuration standard de php.

EXEMPLES

Pour tous les systèmes Unix qui utilisent init.d pour leur gestionnaire de processus principal, vous devriez utiliser le script init fourni pour démarrer et arrêter le démon php-fpm.

sudo /etc/init.d/php-fpm start
Pour tous les systèmes Unix qui utilisent systemd pour leur gestionnaire de processus principal, vous devriez utiliser le fichier d'unité fourni pour démarrer et arrêter le démon php-fpm.
sudo systemctl start php-fpm.service
Si votre installation n'a pas de script init approprié, lancez php-fpm sans arguments. Il sera lancé en tant que démon (processus d'arrière-plan) par défaut. Le fichier /var/run/php-fpm.pid détermine si php-fpm est déjà en cours d'exécution. Une fois démarré, php-fpm répond à plusieurs signaux POSIX :
SIGINT,SIGTERM terminaison immédiate
SIGQUIT arrêt gracieux
SIGUSR1 rouvrir le fichier journal
SIGUSR2 rechargement gracieux de tous les workers + rechargement de la conf/du binaire fpm

CONSEILS

Le démon CGI PHP-FPM fonctionnera bien avec la plupart des serveurs Web populaires, y compris Apache2, lighttpd et nginx.
