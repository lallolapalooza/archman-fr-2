NOM

php-config - obtenir des informations sur la configuration de PHP et les options de compilation

SYNTAXE

php-config [options]

DESCRIPTION

php-config est un script shell simple pour obtenir des informations sur la configuration de PHP installée.

OPTIONS

--prefix
Préfixe du répertoire où PHP est installé, par exemple /usr/local
--includes
Liste des options -I avec tous les fichiers d'inclusion
--ldflags
Flags LD avec lesquels PHP a été compilé
--libs
Bibliothèques supplémentaires avec lesquelles PHP a été compilé
--man-dir
Le préfixe du répertoire où les pages de manuel sont installées
--extension-dir
Répertoire où les extensions sont recherchées par défaut
--include-dir
Préfixe du répertoire où les fichiers d'en-tête sont installés par défaut
--lib-dir
Répertoire où les bibliothèques sont installées par défaut
--lib-embed
Nom de la bibliothèque d'intégration PHP
--php-binary
Chemin complet du binaire PHP CLI ou CGI
--php-sapis
Afficher tous les modules SAPI disponibles
--configure-options
Options de configuration pour recréer la configuration de l'installation PHP actuelle
--ini-path
Répertoire à partir duquel PHP lit son fichier de configuration INI (php.ini)
--ini-dir
Répertoire à partir duquel PHP recherche les fichiers de configuration INI supplémentaires
--version
Version de PHP
--vernum
Version de PHP sous forme d'entier
