phpdbg(1) Langage de script phpdbg(1)

NOM

phpdbg - Le débogueur PHP interactif

SYNTAXE

phpdbg [options] [fichier] [args...]

DESCRIPTION

phpdbg est une plateforme de débogage légère, puissante et facile à utiliser pour PHP.

OPTIONS

-c chemin|fichier
Recherche le fichier php.ini dans le répertoire chemin ou utilise le fichier spécifié
-d foo[=bar]
Définit l'entrée INI foo avec la valeur bar
-n
Aucun fichier php.ini ne sera utilisé
-z fichier
Charge l'extension Zend fichier
-q
N'affiche pas la bannière au démarrage
-v
Active la sortie des oplog
-b
Désactive l'utilisation des couleurs sur la console
-i chemin|fichier
Remplace l'emplacement de .phpgdbinit (implique -I)
-I
Ignore .phpdbginit (fichier d'initialisation par défaut)
-r
Accède directement à l'exécution
-e
Génère des informations étendues pour le débogueur/profiler
-E
Active le pas à pas à travers eval()
-s délimiteur
Lit le code à exécuter depuis l'entrée standard avec un délimiteur optionnel
-S nom_sapi
Remplace le nom du SAPI
-p opcode
Affiche les opcodes et quitte
-h
Affiche le résumé de l'aide
-V
Numéro de version
args...
Arguments passés au script. Utilisez '--' args lorsque le premier argument commence par '-' ou que le script est lu depuis l'entrée standard

NOTES

L'option -rr fera quitter phpdbg après l'exécution, au lieu de retourner à la console.

FICHIERS

php.ini
Le fichier de configuration standard
.phpdbginit
Le fichier d'initialisation
