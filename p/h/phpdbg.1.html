phpdbg(1) Langage de script phpdbg(1)

NOM

phpdbg - Le débogueur PHP interactif

SYNTAXE

phpdbg [options] [fichier] [args...]

DESCRIPTION

phpdbg est une plateforme de débogage légère, puissante et facile à utiliser pour PHP.

OPTIONS

-c chemin|fichier
Rechercher le fichier php.ini dans le répertoire chemin ou utiliser le fichier spécifié.
-d foo[=bar]
Définir l'entrée INI foo avec la valeur bar.
-n
Aucun fichier php.ini ne sera utilisé.
-z fichier
Charger l'extension Zend fichier.
-q
Ne pas afficher la bannière au démarrage.
-v
Activer la sortie oplog.
-b
Désactive l'utilisation des couleurs sur la console.
-i chemin|fichier
Remplace l'emplacement de .phpgdbinit (implique -I).
-I
Ignore .phpdbginit (fichier d'initialisation par défaut).
-r
Aller directement à l'exécution.
-e
Générer des informations étendues pour le débogueur/profileur.
-E
Activer le passage pas à pas dans eval().
-s délimiteur
Lire le code à exécuter depuis stdin avec un délimiteur optionnel.
-S nom_sapi
Remplace le nom SAPI.
-p opcode
Afficher les opcodes et quitter.
-h
Afficher l'aperçu de l'aide.
-V
Numéro de version.
args...
Arguments passés au script. Utiliser '--' args lorsque le premier argument commence par '-' ou que le script est lu depuis stdin.

NOTES

Passer -rr fera quitter phpdbg après l'exécution, au lieu de retourner à la console.

FICHIERS

php.ini
Le fichier de configuration standard.
.phpdbginit
Le fichier d'initialisation.
