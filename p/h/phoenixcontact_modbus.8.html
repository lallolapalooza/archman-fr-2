NOM

phoenixcontact_modbus - Pilote pour Phoenix Contact

SYNOPSIS

phoenixcontact_modbus -h

phoenixcontact_modbus -a NOM_APPAREIL [OPTIONS]


Note

Cette page de manuel ne documente que les fonctionnalités matérielles spécifiques du pilote phoenixcontact_modbus. Pour plus d'informations sur le pilote principal, voir nutupsdrv(8).

MATÉRIEL SUPPORTÉ

Ce pilote devrait supporter l'onduleur industriel DC PhoenixContact QUINT-UPS, modèle 2320461 et tous les modèles compatibles. Plus d'informations sur cet onduleur peuvent être trouvées dans les ressources Internet ci-dessous.

phoenixcontact_modbus utilise le projet libmodbus pour l'implémentation Modbus.

COMMENT CONFIGURER L'ONDULEUR

Remarque : cet onduleur et son manuel font référence à "Low-Batt" comme "Shutdown Event" (événement d'arrêt).

Vous avez besoin du câble "IFS-RS232-DATACABLE" pour communiquer avec l'onduleur sous Linux, car le câble IFS-USB ne semble pas être supporté. Pour information, les paramètres de communication sont : 115200,E,8,1.

Vous avez également besoin du logiciel UPS-CONF pour Windows (gratuit ; téléchargeable sur leur site) pour configurer les signaux et les minuteries de l'onduleur.

1.Lancez UPS-CONF
2.Allez dans Paramètres→Réglage de l'heure
3.Choisissez "délai d'arrêt basé sur l'état de charge"
4.Choisissez Démarrage à distance Arrêt PC en mode secteur et batterie
5.Dans Arrêt PC, entrez la valeur maximale (5 minutes)
6.Dans délai de redémarrage PC, entrez le temps pendant lequel vous souhaitez que l'onduleur laisse la sortie désactivée avant de redémarrer (par exemple, 60 secondes), une fois le courant secteur rétabli.
7.Sur l'onduleur, tournez la vis en position "PC-MODE"

La configuration de cette manière garantit que :

•Lorsque le courant est perdu, l'onduleur calcule en permanence le temps de batterie restant
•Lorsque le temps de batterie restant est inférieur à 5 minutes (réglage d'arrêt PC), il déclenchera l'événement "Arrêt" (vu comme LOW-BATT dans NUT)
•À partir de ce moment, même si le courant d'entrée est rétabli, l'onduleur coupera la sortie de sa charge après 5 minutes
•Lorsque le courant d'entrée est rétabli, l'onduleur rétablira la sortie de puissance après 60 secondes (réglage du délai de redémarrage PC).

Signification des paramètres :

•Arrêt PC : Combien de temps avant la coupure de sortie l'onduleur déclenchera le signal "événement d'arrêt". La valeur maximale est de 5 minutes. Le PC devrait donc pouvoir s'arrêter en moins de 5 minutes.
•Redémarrage PC : Combien de temps retarder la sortie de puissance après le rétablissement du courant. Le maximum est de 60 secondes.

ARGUMENTS SUPPLÉMENTAIRES

Ce pilote ne supporte aucun paramètre optionnel.

INSTALLATION

Ce pilote peut ne pas être compilé par défaut. Vous pouvez le compiler en installant libmodbus et en exécutant configure --with-modbus=yes.

Vous devez également accorder les permissions appropriées sur le fichier du port série local (/dev/ttyS0 par exemple) pour permettre à l'utilisateur NUT d'y accéder.

COMMANDES INSTANTANÉES

Ce pilote ne supporte aucune commande instantanée.

VARIABLES CONFIGURABLES

Les variables suivantes peuvent être définies dans la configuration de NUT comme valeurs default.* pour remplacer ou surveiller le comportement de l'onduleur en utilisant le pilote phoenixcontact_modbus.


Note

À partir de NUT v2.8.4, il n'y a actuellement aucun support pour la configuration de ces valeurs à l'exécution (par exemple avec upsrw(8)). Actuellement, elles ne sont considérées qu'une seule fois, lors de l'initialisation du pilote.

battery.energysave.delay=num

Temps après l'entrée en mode batterie avant que le signal d'arrêt du PC ne soit déclenché par l'onduleur (en secondes).

ups.timer.shutdown=num

Temps accordé au PC pour s'arrêter (en secondes). Le maximum est de 300 secondes.

ups.timer.start=num

Durée pendant laquelle la sortie de puissance reste désactivée avant de redémarrer le système PC (en secondes).

ups.delay.start=num

Délai avant de revenir au secteur après le rétablissement du courant (en secondes). La tension du secteur doit être dans le seuil pendant ce temps pour initier le redémarrage automatique du PC.

experimental.ups.mode.selector=num

Mode de fonctionnement de l'onduleur. Par exemple, 9 correspond au mode PC (défini par le fournisseur).

experimental.battery.warning_soh=num

Seuil d'alerte de batterie pour l'état de santé, en pourcentage.

input.voltage.low.critical=num

Tension seuil (en V) en dessous de laquelle l'onduleur passera en mode batterie.

input.voltage.high.critical=num

Seuil de tension (en V) au-dessus duquel l'onduleur considérera que le courant secteur est rétabli (voir aussi ci-dessous).
