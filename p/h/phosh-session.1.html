Nom

phosh-session - Script de démarrage de session pour phosh

Syntaxe

phosh-session [OPTIONS...]

Description

phosh-session est le script qui démarre phosh, y compris les composants requis tels que le compositeur Wayland phoc et un clavier à l'écran comme stevia ou squeekboard. Le script est rarement exécuté par un utilisateur, mais plutôt activé par un gestionnaire d'affichage ou une unité systemd. Cependant, il est tout à fait valide, par exemple, de se connecter à un tty et d'exécuter phosh-session pour lancer phosh et les composants nécessaires.

Options

-h, --help
Affiche l'aide et quitte.
--version
Affiche la version et quitte.

Fichiers de configuration

Le script de session examine les fichiers de configuration suivants :

  • /usr/share/phosh/phoc.ini : Configuration passée au compositeur.
  • /etc/phosh/phoc.ini : Utilisé à la place du fichier ci-dessus s'il est présent.

Variables d'environnement

phosh-session respecte les variables d'environnement suivantes :

•
WLR_BACKENDS : Les backends que la bibliothèque wlroots doit utiliser lors du lancement de phoc. Voir https://gitlab.freedesktop.org/wlroots/wlroots/-/blob/master/docs/env_vars.md

À des fins de débogage, vous pouvez placer des variables d'environnement dans ~/.phoshdebug, qui est lu au démarrage de la session.
