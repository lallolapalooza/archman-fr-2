NOM

photoflare - Éditeur d'images simple mais puissant et multiplateforme

DESCRIPTION

Ceci est un effort pour apporter une édition d'images rapide, simple mais puissante aux masses. Photoflare est inspiré de l'éditeur d'images actuellement disponible uniquement sous Microsoft Windows – PhotoFiltre. Cependant, ce ne sera pas un clone direct. Il est construit à partir de zéro pour être beaucoup amélioré et multiplateforme également !
