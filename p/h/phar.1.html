PHAR(1) Commandes utilisateur PHAR(1)

NOM

phar, phar.phar - Outil en ligne de commande pour l'archive PHAR (PHP)

SYNTAXE

phar <commande> [options] ...

DESCRIPTION

Le format de fichier PHAR fournit un moyen de regrouper des applications PHP entières dans un seul fichier appelé "phar" (Archive PHP) pour une distribution et une installation faciles.

Avec la commande phar, vous pouvez créer, mettre à jour ou extraire des archives PHP.

Commandes : add compress delete extract help help-list info list meta-del meta-get meta-set pack sign stub-get stub-set tree version

commande add

Ajoute des entrées à un paquet PHAR.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.
...
Un nombre quelconque de fichiers et de répertoires d'entrée. Si -i est utilisé, SEULEMENT les fichiers correspondant à l'expression régulière donnée sont packagés. Si -x est utilisé, les fichiers correspondant à cette expression régulière NE sont PAS packagés.

Arguments optionnels :

-a alias
Fournit un nom d'*alias* pour le fichier phar.
-c algo
Algorithme de compression (voir COMPRESSION).
-i regex
Spécifie une expression régulière pour les fichiers d'entrée.
-l niveau
Nombre de sous-répertoires précédents à supprimer des entrées de fichier.
-x regex
Expression régulière pour les fichiers d'entrée à exclure.

commande compress

Compresse ou décompresse tous les fichiers ou une entrée sélectionnée.

Arguments requis :

-c algo
Algorithme de compression (voir COMPRESSION).
-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-e entrée
Nom de l'*entrée* sur laquelle travailler (doit inclure le nom du répertoire interne PHAR s'il y en a un).

commande delete

Supprime une entrée d'une archive PHAR.

Arguments requis :

-e entrée
Nom de l'*entrée* sur laquelle travailler (doit inclure le nom du répertoire interne PHAR s'il y en a un).
-f fichier
Spécifie le fichier phar sur lequel travailler.

commande extract

Extrait un paquet PHAR dans un répertoire.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-i regex
Spécifie une expression régulière pour les fichiers d'entrée.
-x regex
Expression régulière pour les fichiers d'entrée à exclure.
...
Répertoire dans lequel extraire (par défaut '.').

commande help

Cette aide ou l'aide pour une commande sélectionnée.

Arguments optionnels :

...
Commande optionnelle pour laquelle récupérer l'aide.

commande help-list

Liste les commandes disponibles.

commande info

Obtient des informations sur un paquet PHAR.

En utilisant -k, il est possible de retourner une seule valeur.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-k index
L'*index* de souscription sur lequel travailler.

commande list

Liste le contenu d'une archive PHAR.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-i regex
Spécifie une expression régulière pour les fichiers d'entrée.
-x regex
Expression régulière pour les fichiers d'entrée à exclure.

commande meta-del

Supprime les métadonnées d'une entrée PHAR ou d'un paquet PHAR.

Si -k est donné, alors les métadonnées sont attendues comme un tableau et l'index donné est supprimé.

Si quelque chose a été supprimé, la valeur de retour est 0 sinon elle est 1.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-e entrée
Nom de l'*entrée* sur laquelle travailler (doit inclure le nom du répertoire interne PHAR s'il y en a un).
-k index
L'*index* de souscription sur lequel travailler.

commande meta-get

Récupère les métadonnées d'une entrée PHAR ou d'un paquet PHAR sous forme sérialisée. Si aucun fichier de sortie n'est spécifié pour les métadonnées, stdout est utilisé. Vous pouvez également spécifier un index particulier à l'aide de -k. Dans ce cas, les métadonnées sont attendues comme un tableau et la valeur de l'index donné est retournée en utilisant echo plutôt qu'en utilisant la sérialisation. Si cet index n'existe pas ou si aucune métadonnée n'est présente, la valeur de retour est 1.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-e entrée
Nom de l'*entrée* sur laquelle travailler (doit inclure le nom du répertoire interne PHAR s'il y en a un).
-k index
L'*index* de souscription sur lequel travailler.

commande meta-set

Définit les métadonnées d'une entrée PHAR ou d'un paquet PHAR en utilisant une entrée sérialisée. Si aucun fichier d'entrée n'est spécifié pour les métadonnées, stdin est utilisé. Vous pouvez également spécifier un index particulier à l'aide de -k. Dans ce cas, les métadonnées sont attendues comme un tableau et la valeur de l'index donné est définie. Si les métadonnées ne sont pas présentes ou sont vides, un nouveau tableau sera créé. Si les métadonnées sont présentes et constituent une valeur plate, la valeur de retour est 1. En utilisant également -k, l'entrée est prise directement plutôt que d'être sérialisée.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.
-m meta
Métadonnées à stocker avec l'entrée (données php sérialisées).

Arguments optionnels :

-e entrée
Nom de l'*entrée* sur laquelle travailler (doit inclure le nom du répertoire interne PHAR s'il y en a un).
-k index
L'*index* de souscription sur lequel travailler.

commande pack

Pack des fichiers dans une archive PHAR.

Lorsque vous utilisez -s <stub>, le fichier stub est exclu de la liste des fichiers/répertoires d'entrée. Pour créer une archive contenant la classe PEAR PHP_Archive, pointez l'argument -p vers PHP/Archive.php.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.
...
Un nombre quelconque de fichiers et de répertoires d'entrée. Si -i est utilisé, SEULEMENT les fichiers correspondant à l'expression régulière donnée sont packagés. Si -x est utilisé, les fichiers correspondant à cette expression régulière NE sont PAS packagés.

Arguments optionnels :

-a alias
Fournit un nom d'*alias* pour le fichier phar.
-b bang
Ligne hash-bang pour démarrer l'archive (par exemple, #!/usr/bin/php). La marque hash elle-même '#!' et le caractère de nouvelle ligne

commande sign

Signe une archive PHAR avec une clé privée.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.
-k fichier_clé
Chemin vers le fichier de clé privée.

Arguments optionnels :

-p passphrase
Mot de passe de la clé privée.
-t type_signature
Type de signature (par défaut 'SHA1'). D'autres options sont 'SHA256', 'SHA512', 'MD5'.

commande stub-get

Récupère le stub d'une archive PHAR.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-o fichier_sortie
Écrit le stub dans fichier_sortie au lieu de stdout.

commande stub-set

Définit le stub d'une archive PHAR.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.
-s stub
Le nouveau stub de l'archive PHAR.

commande tree

Affiche le contenu d'une archive PHAR sous forme d'arbre.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-i regex
Spécifie une expression régulière pour les fichiers d'entrée.
-x regex
Expression régulière pour les fichiers d'entrée à exclure.

commande version

Affiche la version de l'outil PHAR.
