Nom

phoc - Un compositeur Wayland pour appareils mobiles

SYNTAXE

phoc [OPTIONS...]

DESCRIPTION

phoc est un compositeur Wayland pour appareils mobiles utilisant la bibliothèque wlroots. Il est souvent utilisé avec l'environnement mobile phosh mais fonctionne parfaitement seul.

OPTIONS

-h, --help
Affiche l'aide et quitte.
-C, --config FICHIER
Chemin vers le fichier de configuration. (par défaut : phoc.ini).
-E, --exec EXECUTABLE
Exécutable (session) qui sera lancé au démarrage.
--socket
Socket Wayland sur lequel écouter les connexions des clients.
-S, --shell
Indique s'il faut attendre qu'un shell se connecte.
-X, --xwayland
Indique s'il faut lancer XWayland.
--no-xwayland
Indique s'il faut désactiver XWayland.
--version
Affiche les informations de version.

CONFIGURATION

La configuration est lue depuis phoc.ini, hwdb, gsettings et $XDG_STATE_HOME/outputs.gvdb. Pour plus de détails sur la configuration des sorties, voir phoc.ini(5), pour plus de détails sur la configuration des touches de réveil via hwdb, voir gmobile.udev(5), pour plus de détails sur les paramètres gsettings gérés par phoc, voir phoc.gsettings(5). Pour plus de détails sur les états des sorties, voir phoc-outputs-states.

VARIABLES D'ENVIRONNEMENT

phoc prend en compte les variables d'environnement suivantes :

  • WLR_BACKENDS : Les backends que la bibliothèque wlroots doit utiliser lors du lancement de phoc. Voir https://gitlab.freedesktop.org/wlroots/wlroots/-/blob/master/docs/env_vars.md
  • WLR_RENDERER : Le rendu que la bibliothèque wlroots doit utiliser lors du lancement de phoc. Voir https://gitlab.freedesktop.org/wlroots/wlroots/-/blob/master/docs/env_vars.md
  • G_MESSAGES_DEBUG, G_DEBUG et d'autres variables d'environnement supportées par glib. https://docs.gtk.org/glib/running.html
  • PHOC_DEBUG : Liste des indicateurs de débogage séparés par des virgules :
  • help : Affiche une liste des indicateurs de débogage disponibles.
  • auto-maximize : Maximise les fenêtres de premier niveau.
  • damage-tracking : Débogage du suivi des dommages.
  • damage-whole : Dommage complet de la sortie à chaque image.
  • no-quit : Ne quitte pas lorsque la session se termine.
  • touch-points : Débogage des points tactiles.
  • layer-shell : Débogage du layer-shell.
  • cutouts : Débogage des découpes et encoches d'affichage.
  • disable-animations : Désactive les animations.
  • force-shell-reveal : Révèle toujours le shell par-dessus les applications en plein écran.
  • ignore-state : Ignore tout état de sortie sauvegardé.

PROPRIÉTÉS UDEV

En plus des propriétés udev pour les touches de réveil documentées dans gmobile.udev(5), phoc utilise ID_INPUT_KEYBOARD pour identifier les claviers matériels. Vous pouvez utiliser hwdb pour les remplacer.

INTERFACE DBUS

phoc permet d'activer et de désactiver certains indicateurs de débogage en temps réel via DBus. Pour voir une liste des indicateurs disponibles, utilisez :

busctl --user introspect mobi.phosh.Phoc.DebugControl /mobi/phosh/Phoc/DebugControl mobi.phosh.Phoc.DebugControl

Pour basculer des valeurs individuelles :

busctl --user set-property mobi.phosh.Phoc.DebugControl /mobi/phosh/Phoc/DebugControl mobi.phosh.Phoc.DebugControl TouchPoints b true
busctl --user set-property mobi.phosh.Phoc.DebugControl /mobi/phosh/Phoc/DebugControl mobi.phosh.Phoc.DebugControl DamageTracking b true
busctl --user set-property mobi.phosh.Phoc.DebugControl /mobi/phosh/Phoc/DebugControl mobi.phosh.Phoc.DebugControl LogDomains as 1 all
busctl --user set-property mobi.phosh.Phoc.DebugControl /mobi/phosh/Phoc/DebugControl mobi.phosh.Phoc.DebugControl LogDomains as 2 phoc-seat phoc-layer-surface

Notez que les indicateurs ne sont pas considérés comme une API stable et peuvent changer entre les versions.
