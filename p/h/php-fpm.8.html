NOM

php-fpm - Gestionnaire de processus PHP FastCGI 'PHP-FPM'

SYNOPIS

php-fpm [options]

DESCRIPTION

PHP est un langage de script général largement utilisé qui est particulièrement adapté au développement Web et peut être intégré dans HTML. Ceci est une variante de PHP qui s'exécutera en arrière-plan en tant que démon, en attente de requêtes CGI. La sortie est enregistrée dans /var/log/php-fpm.log.

La plupart des options sont définies dans le fichier de configuration. Le fichier de configuration est /etc/php/php-fpm.conf. Par défaut, php-fpm répondra aux requêtes CGI en écoute sur localhost port HTTP 9000. Par conséquent, php-fpm attend que votre serveur Web redirige toutes les requêtes pour les fichiers '.php' vers le port 9000 et vous devez modifier votre fichier de configuration de serveur Web en conséquence.

OPTIONS

-C
Ne pas changer de répertoire vers celui du script
--php-ini chemin|fichier
-c chemin|fichier
Rechercher le fichier php.ini dans le répertoire chemin ou utiliser le fichier spécifié
--no-php-ini
-n
Aucun fichier php.ini ne sera utilisé
--define foo[=bar]
-d foo[=bar]
Définir l'entrée INI foo avec la valeur bar
-e
Générer des informations étendues pour le débogueur/profileur
--help
-h
Cette aide
--info
-i
Informations et configuration PHP
--modules
-m
Afficher les modules compilés
--version
-v
Numéro de version
--prefix chemin
-p
Spécifier un chemin de préfixe alternatif (par défaut /usr)
--pid fichier
-g
Spécifier l'emplacement du fichier PID.
--fpm-config fichier
-y
Spécifier un chemin alternatif vers le fichier de configuration du gestionnaire de processus FastCGI (par défaut /etc/php/php-fpm.conf)
--test
-t
Tester le fichier de configuration FPM et quitter. Si appelé deux fois (-tt), la configuration est vidée avant de quitter.
--daemonize
-D
Forcer l'exécution en arrière-plan et ignorer l'option daemonize du fichier de configuration.
--nodaemonize
-F
Forcer le maintien au premier plan et ignorer l'option daemonize du fichier de configuration.
--force-stderr
-O
Forcer la sortie vers stderr en mode nodaemonize même si stderr n'est pas un TTY.
--allow-to-run-as-root
-R
Autoriser le pool à s'exécuter en tant que root (désactivé par défaut)

FICHIERS

php-fpm.conf
Le fichier de configuration du démon php-fpm.
php.ini
Le fichier de configuration standard de PHP.

EXEMPLES

Pour tous les systèmes Unix qui utilisent init.d pour leur gestionnaire de processus principal, vous devez utiliser le script d'initialisation fourni pour démarrer et arrêter le démon php-fpm.

sudo /etc/init.d/php-fpm start
Pour tous les systèmes Unix qui utilisent systemd pour leur gestionnaire de processus principal, vous devez utiliser le fichier d'unité fourni pour démarrer et arrêter le démon php-fpm.
sudo systemctl start php-fpm.service
Si votre installation n'a pas de script d'initialisation approprié, lancez php-fpm sans arguments. Il se lancera en mode démon (processus d'arrière-plan) par défaut. Le fichier /var/run/php-fpm.pid détermine si php-fpm est déjà en cours d'exécution. Une fois démarré, php-fpm répond à plusieurs signaux POSIX :
SIGINT,SIGTERM terminaison immédiate
SIGQUIT arrêt gracieux
SIGUSR1 rouvrir le fichier journal
SIGUSR2 rechargement gracieux de tous les workers + rechargement de la configuration/du binaire fpm

CONSEILS

Le démon CGI PHP-FPM fonctionnera bien avec la plupart des serveurs Web populaires, y compris Apache2, lighttpd et nginx.

PHP-FPM man page

NOM

php-fpm — FastCGI Process Manager for PHP

SYNOPSIS

php-fpm [options]

DESCRIPTION

PHP-FPM (FastCGI Process Manager) is an alternative PHP FastCGI implementation with some additional features useful for sites that are heavily loaded. PHP-FPM provides a master process manager which can spawn multiple child processes to handle FastCGI requests. It can be configured to listen on a TCP socket or a Unix domain socket.

OPTIONS

PHP-FPM has a number of command-line options:

-y, --config-file=FILE
Use configuration file FILE.
-q, --quiet
No is_message output.
-d, --define=<key>[=value]
Set a PHP .ini directive. If no value is passed, it will be set to a. Can be used multiple times.
-e, --expose-php
This option is deprecated and will be removed in a future version. Enable the expose_php directive.
-v, --version
Output version information and exit.
-h, --help
Output usage information and exit.

FILES

/etc/php/php-fpm.conf
Main configuration file.
/etc/php/php-fpm.d/*.conf
Pool configuration files.
