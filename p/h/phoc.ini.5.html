Nom

phoc.ini - Fichier de configuration pour phoc

DESCRIPTION

La majeure partie de la configuration de phoc est lue à partir de GSettings. La sortie et les paramètres principaux sont lus à partir de phoc.ini. Le fichier de configuration est recherché dans le répertoire de travail courant de phoc. Son chemin peut également être indiqué en ligne de commande via l'option -C.

Le fichier phoc.ini est composé de plusieurs sections qui peuvent être dans n'importe quel ordre. Si des valeurs ne sont pas fournies, les valeurs par défaut intégrées sont utilisées. Le but principal de phoc.ini est de spécifier la configuration de sortie et les dispositions. Chaque section a la forme :

[En-tête de section]
clé1 = valeur1
clé2 = valeur2

Les lignes commençant par # sont considérées comme des commentaires et sont ignorées. Les en-têtes de section peuvent contenir un deux-points, auquel cas la partie après le deux-points spécifie l'élément de configuration, par exemple :

[output:DSI-1]

est la section de configuration pour la sortie DSI-1.

Les en-têtes de section disponibles sont :

  • core : options principales
  • output : configuration de la sortie

Les modifications apportées à ce fichier nécessitent un redémarrage du compositeur pour prendre effet.

SECTION CORE

La section principale ne peut apparaître qu'une seule fois et a une seule option :

•
xwayland=[true|immediate|false] : Indique si XWayland doit être activé. Avec true, XWayland est activé lorsque nécessaire. immediate le lance immédiatement et false le désactive.

SECTION OUTPUT

La section de sortie peut apparaître plusieurs fois avec différents éléments de configuration

[output:ITEM]

ITEM est soit le nom du connecteur DRM comme DSI-1 ou DP-2, soit la marque, le modèle et le numéro de série tels qu'obtenus à partir d'EDID, séparés par % : [output:A Vendor%The Model%Serial]. La marque, le modèle et le numéro de série peuvent être spécifiés comme * pour correspondre à n'importe quelle valeur. Les options de configuration sont :

  • enable=[true|false] : Indique si la sortie doit être activée
  • x, y : La position x et y dans la disposition de la sortie. Ceci peut être utilisé pour organiser les sorties. Par défaut, la disposition automatique est utilisée (les nouvelles sorties sont ajoutées à droite de la disposition actuelle).
  • scale : L'échelle de la sortie. Par défaut, auto calcule l'échelle en fonction de la taille de l'écran.
  • rotate : La rotation. Les valeurs valides sont normal, 90, 180, 270, flipped, flipped-90, flipped-180 et flipped-270. Par défaut, l'orientation normale est utilisée.
  • mode : Le mode à utiliser. Le mode doit être un mode valide pour cette sortie. Voir, par exemple, la sortie de wlr-randr. Par défaut, le mode préféré de la sortie est utilisé.
  • modeline : Un mode vidéo personnalisé. Ceci n'est valide que pour le backend DRM.
  • scale-filter : Filtre à utiliser pour réduire les textures. Les valeurs valides sont bilinear, nearest et auto. Ce dernier sélectionne automatiquement bilinear pour les échelles fractionnaires et nearest pour les échelles entières. S'il n'est pas défini, auto est supposé.
  • drm-panel-orientation : Si true, applique l'orientation du panneau lue à partir du connecteur DRM (si disponible). La valeur par défaut est true.
  • phys_width, phys_height : Les dimensions physiques de l'affichage en mm.
  • adaptive-sync : Si défini sur enabled, active le taux de rafraîchissement variable, disabled ou absent le désactive.

Exemple :

[output:DSI-1]
scale = 2
[output:Some Vendor%Some Model%*]
scale = 1
rotate = 90
x = 300
