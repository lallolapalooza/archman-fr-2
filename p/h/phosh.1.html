Nom

phosh - Phosh - Un shell pour téléphone

Syntaxe

phosh [OPTIONS...]

Description

phosh est un shell Wayland pour appareils mobiles utilisant les technologies GNOME.

Options

-h, --help
Affiche l'aide et quitte
-U, --unlocked
Ne démarre pas avec l'écran verrouillé
-L, --locked
Démarre avec l'écran verrouillé, quoi qu'il arrive
--version
Affiche les informations de version

Configuration

phosh est configuré via GSettings, voir phosh-config(5).

Plugins

Les plugins sont configurés via le schéma gsettings mobi.phosh.plugins et sm.puri.phosh.plugins. La clé lock-screen active les plugins sur l'écran de verrouillage, par exemple :

gsettings set  sm.puri.phosh.plugins lock-screen "['ticket-box', 'upcoming-events']"

Variables d'environnement

phosh prend en compte les variables d'environnement suivantes à des fins de débogage :

•
PHOSH_DEBUG: Une liste de drapeaux séparés par des virgules :
  • always-splash: Utilise toujours l'écran de démarrage lors du lancement d'applications (même en mode ancré)
  • fake-builtin: Simule un écran intégré lors de l'utilisation d'une sortie virtuelle, comme dans une session Wayland imbriquée.
  • PHOSH_FAKE_CLOCK: Les valeurs autorisées sont des chaînes formatées ISO8601 ou now. Définir cette variable fixe l'horloge du shell à la valeur spécifiée. Pour le format de l'horloge, voir g_date_time_new_from_iso8601().
  • G_MESSAGES_DEBUG, G_DEBUG et d'autres variables d'environnement prises en charge par glib. https://docs.gtk.org/glib/running.html
  • GTK_DEBUG et d'autres variables d'environnement prises en charge par GTK, voir https://docs.gtk.org/gtk3/running.html
