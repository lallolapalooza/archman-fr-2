phpize(1) Langage de script phpize(1)

NOM

phpize - prépare une extension PHP pour la compilation

SYNTAXE

phpize [options]

DESCRIPTION

phpize est un script shell pour préparer une extension PHP à la compilation.

OPTIONS

--clean
Supprime tous les fichiers créés
--help
Affiche les informations d'utilisation
--version
-v
Affiche les informations sur la version de l'API
