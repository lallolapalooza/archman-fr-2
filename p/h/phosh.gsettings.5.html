Nom

phosh.gsettings - GSettings utilisés par phosh

DESCRIPTION

Phosh utilise gsettings pour la plupart de ses configurations. Vous pouvez utiliser la commande gsettings(1) pour les modifier ou pour obtenir des détails sur les options. Pour obtenir plus de détails sur une option, utilisez gsettings describe, par exemple :

gsettings describe mobi.phosh.shell.cell-broadcast enabled

Voici les schémas et clés gsettings actuellement utilisés :

GSettings

Ces gsettings sont utilisés par phosh :

•
mobi.phosh.shell.cell-broadcast
•
enabled: Indique si la réception des diffusions cellulaires est activée
•
sm.puri.phosh
•
app-filter-mode: Filtrage des applications dans l'aperçu. Ceci affiche toutes les applications :
gsettings set sm.puri.phosh app-filter-mode '[]'
  • automatic-high-contrast-threshold: Le seuil de luminosité pour déclencher le contraste élevé automatique
  • automatic-high-contrast: Indique si le contraste élevé automatique est activé
  • enable-suspend: Indique si la mise en veille est activée dans le menu système :
  • favorites: Liste des applications favorites
  • force-adaptive: Liste des ID d'applications que phosh considère comme adaptatives (elles sont donc toujours affichées) :
gsettings set sm.puri.phosh force-adaptive "['chromium.desktop', 'firefox-esr.desktop']"
  • osk-unfold-delay: Durée pendant laquelle il faut appuyer sur la pilule de la barre inférieure pour que le clavier virtuel (OSK) se déplie
  • quick-silent: Silence le périphérique en appuyant sur Vol- lors d'appels entrants
  • shell-layout: Comment disposer les éléments de l'interface utilisateur de la shell autour des découpes et encoches. device: Automatique basé sur les paramètres du périphérique, none: Pas de disposition automatique.
  • wwan-backend: Backend WWAN à utiliser
•
sm.puri.phosh.emergency-calls
•
enabled: Indique si les appels d'urgence sont activés. Ceci est expérimental, veuillez vérifier si cela fonctionne pour votre fournisseur / dans votre pays / pour votre carte SIM avant de vous y fier.
•
sm.puri.phosh.lockscreen
  • require-unlock: Indique si le déverrouillage par mot de passe/code PIN est requis
  • shuffle-keypad: Mélange les touches sur le pavé numérique
•
sm.puri.phosh.plugins
  • lockscreen: Les plugins d'écran de verrouillage activés
  • quick-settings: Les réglages rapides personnalisés activés
•
sm.puri.phosh.notifications
  • wakeup-screen-categories: Catégories de notifications qui déclenchent le réveil de l'écran
  • wakeup-screen-triggers: Quelles propriétés d'une notification déclenchent le réveil de l'écran
  • wakeup-screen-urgency: L'urgence la plus basse qui déclenche le réveil de l'écran (si via wakeup-screen-triggers)
•
sm.puri.phosh.plugins.launcher-box
•
folder
•
sm.puri.phosh.plugins.ticket-box
•
folder: Le dossier contenant les tickets à présenter sur l'écran de verrouillage.
•
sm.puri.phosh.plugins.upcoming-events
•
days
  • org.gnome.desktop.app-folders.folder: Support des dossiers
  • org.gnome.desktop.background: Fond d'écran
  • picture-uri
  • picture-uri-dark
  • primary-color
Par exemple, pour retrouver l'aperçu "classique" noir, utilisez :
gsettings set org.gnome.desktop.background picture-options none
gsettings set org.gnome.desktop.background primary-color '#000000'
•
org.gnome.desktop.interface1
•
show-battery-percentage
•
org.gnome.desktop.media-handling
•
automount
•
org.gnome.desktop.notifications
  • show-banners : Indique si les bannières de notification doivent être affichées
  • show-in-lockscreen : Indique si les notifications doivent être affichées sur l'écran de verrouillage
•
org.gnome.desktop.peripherals.touchscreen: Mappages tactile vers sortie. Exemple pour NexDock 360 :
gsettings set org.gnome.desktop.peripherals.touchscreen:/org/gnome/desktop/peripherals/touchscreens/27c0:0819/ output "\['Unknown', 'NexDock', '8R33926O00Q'\]"
•
org.gnome.desktop.screensaver:
  • lock-delay
  • lock-enabled
  • picture-uri: Image de fond de l'écran de verrouillage / papier peint
  • picture-options: none désactive l'image de l'écran de verrouillage
•
org.gnome.shell.keybindings
  • toggle-message-tray
  • toggle-overview
