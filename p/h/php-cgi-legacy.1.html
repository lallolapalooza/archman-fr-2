php(1) Langage de script php(1)

NOM

php - Interface en ligne de commande 'CLI' de PHP

php-cgi - Commande 'CGI' Common Gateway Interface de PHP

SYNTAXE

php [options] [ -f ] fichier [[--] arguments...]

php [options] -r code [[--] arguments...]

php [options] [-B code_debut] -R code [-E code_fin] [[--] arguments...]

php [options] [-B code_debut] -F fichier [-E code_fin] [[--] arguments...]

php [options] -- [ arguments...]

php [options] -a

php [options] -S adresse:port [-t racine_doc]

DESCRIPTION

PHP est un langage de script polyvalent largement utilisé, particulièrement adapté au développement Web et pouvant être intégré dans du HTML. C'est l'interface en ligne de commande qui vous permet de faire ce qui suit :

Vous pouvez analyser et exécuter des fichiers en utilisant le paramètre -f suivi du nom du fichier à exécuter.

En utilisant le paramètre -r, vous pouvez exécuter directement du code PHP, comme vous le feriez à l'intérieur d'un fichier .php en utilisant la fonction eval().

Il est également possible de traiter l'entrée standard ligne par ligne en utilisant soit le paramètre -R soit -F. Dans ce mode, chaque ligne d'entrée séparée provoque l'exécution du code spécifié par -R ou du fichier spécifié par -F. Vous pouvez accéder à la ligne d'entrée via $argn. Pendant le traitement des lignes d'entrée, $argi contient le numéro de la ligne en cours de traitement. De plus, les paramètres -B et -E peuvent être utilisés pour exécuter du code (voir -r) avant et après le traitement de toutes les lignes d'entrée, respectivement. Notez que l'entrée est lue depuis STDIN et, par conséquent, la lecture depuis STDIN modifie explicitement la ligne d'entrée suivante ou saute des lignes d'entrée.

PHP contient également un serveur Web intégré à des fins de développement d'applications. En utilisant l'option -S où adresse:port pointe vers une adresse et un port locaux, PHP écoutera les requêtes HTTP sur cette adresse et ce port et servira les fichiers du répertoire de travail actuel ou de la racine_doc passée via l'option -t.

Si un fichier PHP est fourni à la ligne de commande lorsque le serveur Web intégré est utilisé, il sera utilisé comme script routeur. Ce script sera démarré à chaque requête HTTP. La sortie du script est renvoyée au navigateur, sauf si le script routeur renvoie la valeur false. Dans ce cas, le serveur intégré revient au comportement par défaut, renvoyant la ressource demandée telle quelle, en recherchant les fichiers relatifs à la racine du document spécifiée par l'option -t, si elle est fournie.

Si aucun des paramètres -r, -f, -B, -R, -F, -E ou -S n'est présent mais qu'un seul paramètre est donné, alors ce paramètre est considéré comme le nom du fichier à analyser et exécuter (identique à -f). S'il n'y a aucun paramètre, l'entrée standard est lue et exécutée.

OPTIONS

--interactive
-a
Exécute PHP en mode interactif. Cela vous permet d'entrer des extraits de code PHP qui sont directement exécutés. Lorsque le support readline est activé, vous pouvez éditer les lignes et bénéficier d'un historique.
--bindpath adresse:port|port
-b adresse:port|port
Chemin de liaison pour le mode serveur FASTCGI externe (CGI uniquement).
--no-chdir
-C
Ne pas changer de répertoire vers le répertoire du script (CGI uniquement).
--no-header
-q
Mode silencieux. Supprime la sortie des en-têtes HTTP (CGI uniquement).
--timing compteur
-T compteur
Mesure le temps d'exécution du script répété 'compteur' fois (CGI uniquement).
--php-ini chemin|fichier
-c chemin|fichier
Recherche le fichier php.ini dans le répertoire chemin ou utilise le fichier spécifié.
--no-php-ini
-n
Aucun fichier php.ini ne sera utilisé.
--define foo[=bar]
-d foo[=bar]
Définit l'entrée INI foo avec la valeur bar.
-e
Génère des informations étendues pour le débogueur/profiler.
--file fichier
-f fichier
Analyse et exécute le fichier.
--help
-h
Cette aide.
--hide-args
-H
Masque le nom du script (fichier) et les paramètres (arguments...) visibles par les outils externes. Par exemple, vous pourriez vouloir l'utiliser lorsqu'un script PHP est lancé comme démon et que la ligne de commande contient des données sensibles comme des mots de passe.
--info
-i
Informations et configuration PHP.
--syntax-check
-l
Vérification de syntaxe uniquement (lint).
--modules
-m
Affiche les modules compilés.
--run code
-r code
Exécute le code PHP sans utiliser les balises de script '<?..?>'.
--process-begin code
-B code_debut
Exécute le code_debut PHP avant de traiter les lignes d'entrée.
--process-code code
-R code
Exécute le code PHP pour chaque ligne d'entrée.
--process-file fichier
-F fichier
Analyse et exécute le fichier pour chaque ligne d'entrée.
--process-end code
-E code_fin
Exécute le code_fin PHP après le traitement de toutes les lignes d'entrée.
--syntax-highlight
-s
Affiche le code source avec la coloration syntaxique HTML.
--server adresse:port
-S adresse:port
Démarre le serveur Web intégré sur l'adresse et le port locaux spécifiés.
--docroot racine_doc
-t racine_doc
Spécifie la racine du document à utiliser par le serveur Web intégré.
--version
-v
Numéro de version.
--strip
-w
Affiche le code source avec les commentaires et les espaces blancs supprimés.
--zend-extension fichier
-z fichier
Charge l'extension Zend fichier.
arguments...
Arguments passés au script. Utilisez '--' arguments lorsque le premier argument commence par '-' ou que le script est lu depuis stdin.
--rfunction
nom
--rf
nom Affiche des informations sur la fonction nom.
--rclass
nom
--rc
nom Affiche des informations sur la classe nom.
--rextension
nom
--re
nom Affiche des informations sur l'extension nom.
--rzendextension
nom
--rz
nom Affiche des informations sur l'extension Zend nom.
--rextinfo
nom
--ri
nom Affiche la configuration de l'extension nom.
--ini
Affiche les noms des fichiers de configuration.

FICHIERS

php-cli.ini
Le fichier de configuration pour la version CLI de PHP.
php.ini

EXEMPLES

php -r 'echo "Bonjour le Monde\n";'
Cette commande écrit simplement le texte "Bonjour le Monde" sur la sortie standard.
php -r 'print_r(gd_info());'
Ceci affiche la configuration de votre extension gd. Vous pouvez l'utiliser pour vérifier facilement quels formats d'image vous pouvez utiliser. Si vous avez des modules dynamiques, vous pourriez vouloir utiliser le même fichier ini que PHP utilise lorsqu'il est exécuté depuis votre serveur Web. Il existe plusieurs extensions qui ont une telle fonction. Pour dba utilisez :
php -r 'print_r(dba_list_keys());'

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

>php -r 'print_r(dba_handlers(1));'
php -R 'echo strip_tags($argn)."\n";'
Cette commande PHP supprime les balises HTML ligne par ligne et affiche le résultat. Pour voir comment cela fonctionne, vous pouvez d'abord examiner la commande PHP suivante : ´php -d html_errors=1 -i´ qui utilise PHP pour afficher des informations de configuration au format HTML. Si vous combinez ensuite ces deux commandes ´php ...|php ...´, vous verrez ce qui se passe.
php -E 'echo "Lignes : $argi\n";'
En utilisant cette commande PHP, vous pouvez compter les lignes entrantes.
php -R '@$l+=count(file($argn));' -E 'echo "Lignes:$l\n";'
Dans cet exemple, PHP s'attend à ce que chaque ligne d'entrée soit un fichier. Il compte toutes les lignes des fichiers spécifiés par chaque ligne d'entrée et affiche le résultat résumé. Vous pouvez combiner cela avec des outils comme find et modifier le scriptlet php.
php -R 'echo "$argn\n"; fgets(STDIN);'
Étant donné que vous avez accès à STDIN depuis -B -R -F et -E, vous pouvez ignorer certaines lignes d'entrée avec votre code. Mais notez que dans de tels cas, $argi compte seulement les lignes traitées par php lui-même. Après avoir lu ceci, vous devinerez ce que fait le programme ci-dessus : ignorer toutes les deux lignes d'entrée.

CONSEILS

#!/bin/php

<?php


// votre script

?>
