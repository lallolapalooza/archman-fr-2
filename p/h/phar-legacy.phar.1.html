PHAR(1) Commandes utilisateur PHAR(1)

NOM

phar, phar.phar - Outil en ligne de commande pour les archives PHAR (PHP archive)

SYNTAXE

phar <commande> [options] ...

DESCRIPTION

Le format de fichier PHAR permet de rassembler des applications PHP entières dans un seul fichier appelé "phar" (PHP Archive) pour une distribution et une installation faciles.

Avec la commande phar, vous pouvez créer, mettre à jour ou extraire des archives PHP.

Commandes : add compress delete extract help help-list info list meta-del meta-get meta-set pack sign stub-get stub-set tree version

COMMANDE add

Ajoute des entrées à un paquet PHAR.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.
...
Un nombre quelconque de fichiers et de répertoires d'entrée. Si -i est utilisé, SEULS les fichiers correspondant à l'expression régulière donnée sont archivés. Si -x est donné, les fichiers correspondant à cette expression régulière ne sont PAS archivés.

Arguments optionnels :

-a alias
Fournit un alias pour le fichier phar.
-c algo
Algorithme de compression (voir COMPRESSION)
-i regex
Spécifie une expression régulière pour les fichiers d'entrée.
-l niveau
Nombre de sous-répertoires précédents à supprimer des entrées de fichiers
-x regex
Expression régulière pour exclure les fichiers d'entrée.

COMMANDE compress

Compresse ou décompresse tous les fichiers ou une entrée sélectionnée.

Arguments requis :

-c algo
Algorithme de compression (voir COMPRESSION)
-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-e entree
Nom de l'entrée sur laquelle travailler (doit inclure le nom du répertoire interne du PHAR s'il y en a un).

COMMANDE delete

Supprime une entrée d'une archive PHAR

Arguments requis :

-e entree
Nom de l'entrée sur laquelle travailler (doit inclure le nom du répertoire interne du PHAR s'il y en a un).
-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments requis :

Spécifie une expression régulière pour les fichiers d'entrée.
-x regex
Expression régulière pour exclure les fichiers d'entrée.
...
Répertoire vers lequel extraire (par défaut '.').

COMMANDE help

Aide générale ou aide pour une commande sélectionnée.

Arguments optionnels :

...
Commande optionnelle pour laquelle récupérer l'aide.

COMMANDE help-list

Liste les commandes disponibles.

COMMANDE info

Obtient des informations sur un paquet PHAR.

En utilisant -k, il est possible de retourner une seule valeur.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-k index
Index d'abonnement sur lequel travailler.

COMMANDE list

Liste le contenu d'une archive PHAR.

-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-i regex
Spécifie une expression régulière pour les fichiers d'entrée.
-x regex
Expression régulière pour exclure les fichiers d'entrée.

COMMANDE meta-del

Supprime les métadonnées d'une entrée PHAR ou d'un paquet PHAR.

Si -k est donné, les métadonnées sont attendues sous forme de tableau et l'index donné est supprimé.

Si quelque chose a été supprimé, la valeur de retour est 0, sinon c'est 1.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-e entree
Nom de l'entrée sur laquelle travailler (doit inclure le nom du répertoire interne du PHAR s'il y en a un).
-k index
Index d'abonnement sur lequel travailler.

COMMANDE meta-get

Obtient les métadonnées d'une entrée PHAR ou d'un paquet PHAR sous forme sérialisée. Si aucun fichier de sortie n'est spécifié pour les métadonnées, la sortie standard est utilisée. Vous pouvez également spécifier un index particulier avec -k. Dans ce cas, les métadonnées sont attendues sous forme de tableau et la valeur de l'index donné est retournée en utilisant echo plutôt qu'en sérialisant. Si cet index n'existe pas ou si aucune métadonnée n'est présente, la valeur de retour est 1.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-e entree
Nom de l'entrée sur laquelle travailler (doit inclure le nom du répertoire interne du PHAR s'il y en a un).
-k index
Index d'abonnement sur lequel travailler.

COMMANDE meta-set

Définit les métadonnées d'une entrée PHAR ou d'un paquet PHAR en utilisant une entrée sérialisée. Si aucun fichier d'entrée n'est spécifié pour les métadonnées, l'entrée standard est utilisée. Vous pouvez également spécifier un index particulier avec -k. Dans ce cas, les métadonnées sont attendues sous forme de tableau et la valeur de l'index donné est définie. Si les métadonnées ne sont pas présentes ou sont vides, un nouveau tableau sera créé. Si les métadonnées sont présentes et sont une valeur plate, la valeur de retour est 1. En utilisant également -k, l'entrée est traitée directement plutôt que d'être sérialisée.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.
-m meta
Métadonnées à stocker avec l'entrée (données PHP sérialisées).

Arguments optionnels :

-e entree
Nom de l'entrée sur laquelle travailler (doit inclure le nom du répertoire interne du PHAR s'il y en a un).
-k index
Index d'abonnement sur lequel travailler.

COMMANDE pack

Archive des fichiers dans une archive PHAR.

Lorsque vous utilisez -s <stub>, le fichier stub est exclu de la liste des fichiers/répertoires d'entrée. Pour créer une archive contenant la classe PEAR PHP_Archive, pointez l'argument -p vers PHP/Archive.php.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.
...
Un nombre quelconque de fichiers et de répertoires d'entrée. Si -i est utilisé, SEULS les fichiers correspondant à l'expression régulière donnée sont archivés. Si -x est donné, les fichiers correspondant à cette expression régulière ne sont PAS archivés.

Arguments optionnels :

-a alias
Fournit un alias pour le fichier phar.
-b bang
Ligne hash-bang pour démarrer l'archive (par exemple #!/usr/bin/php). Le signe dièse lui-même '#!' et le saut de ligne

add command

Ajoute des fichiers à une archive PHAR. Ces fichiers seront ensuite supprimés de la partition du système de fichiers.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments facultatifs :

-c algo
Algorithme de compression (voir COMPRESSION )
-d fichier
Fichier à ajouter à l'archive. Les caractères génériques comme * et ? sont pris en charge. Le caractère de fin de ligne est facultatif.
-h hash
Sélectionne l'algorithme de hash (voir HASH )
-i regex
Spécifie une expression régulière pour les fichiers d'entrée.
-l level
Nombre de sous-répertoires précédents à supprimer des entrées de fichier
-p loader
Emplacement du fichier de classe PHP_Archive (pear list-files PHP_Archive). Vous pouvez utiliser '0' ou '1' pour le localiser automatiquement à l'aide de la commande pear mentionnée. Lorsque vous utilisez '0', la commande ne génère pas d'erreur lorsque le fichier de classe ne peut pas être trouvé. Ce commutateur ajoute également du code autour du stub afin que la classe PHP_Archive soit enregistrée en tant qu'enveloppeur de flux phar:// si nécessaire. Et enfin, ce commutateur ajoutera le fichier phar.inc de ce package et le chargera pour garantir que la classe Phar est présente.
-s stub
Sélectionne le fichier stub.
-x regex
Expression régulière pour les fichiers d'entrée à exclure.
-y key
Clé privée pour la signature OpenSSL.
