php(1) Langage de script php(1)

NOM

php - Interface en ligne de commande PHP 'CLI'

php-cgi - Commande CGI 'Common Gateway Interface' PHP

SYNTAXE

php [options] [ -f ] fichier [[--] arguments...]

php [options] -r code [[--] arguments...]

php [options] [-B code_debut] -R code [-E code_fin] [[--] arguments...]

php [options] [-B code_debut] -F fichier [-E code_fin] [[--] arguments...]

php [options] -- [ arguments...]

php [options] -a

php [options] -S addr:port [-t racine_doc]

DESCRIPTION

PHP est un langage de script polyvalent largement utilisé, particulièrement adapté au développement Web et pouvant être intégré dans du HTML. Ceci est l'interface en ligne de commande qui vous permet de faire ce qui suit :

Vous pouvez analyser et exécuter des fichiers en utilisant le paramètre -f suivi du nom du fichier à exécuter.

En utilisant le paramètre -r, vous pouvez exécuter directement du code PHP comme vous le feriez dans un fichier .php en utilisant la fonction eval().

Il est également possible de traiter l'entrée standard ligne par ligne en utilisant le paramètre -R ou -F. Dans ce mode, chaque ligne d'entrée séparée provoque l'exécution du code spécifié par -R ou du fichier spécifié par -F. Vous pouvez accéder à la ligne d'entrée par $argn. Lors du traitement des lignes d'entrée, $argi contient le numéro de la ligne en cours de traitement. De plus, les paramètres -B et -E peuvent être utilisés pour exécuter du code (voir -r) avant et après le traitement de toutes les lignes d'entrée, respectivement. Notez que l'entrée est lue depuis STDIN et donc lire depuis STDIN explicitement modifie la prochaine ligne d'entrée ou saute des lignes d'entrée.

PHP contient également un serveur Web intégré à des fins de développement d'applications. En utilisant l'option -S où addr:port pointe vers une adresse et un port locaux, PHP écoutera les requêtes HTTP sur cette adresse et ce port et servira les fichiers du répertoire de travail actuel ou de la racine_doc passée par l'option -t.

Si un fichier PHP est fourni à la ligne de commande lorsque le serveur Web intégré est utilisé, il sera utilisé comme script de routage. Ce script sera lancé à chaque requête HTTP. La sortie du script est renvoyée au navigateur, à moins que le script de routage ne renvoie la valeur false. Dans ce cas, le serveur intégré revient à son comportement par défaut, renvoyant la ressource demandée telle quelle en recherchant les fichiers relativement à la racine du document spécifiée par l'option -t, si elle est fournie.

Si aucun des paramètres -r, -f, -B, -R, -F, -E ou -S n'est présent mais qu'un seul paramètre est donné, alors ce paramètre est considéré comme le nom du fichier à analyser et exécuter (comme avec -f). S'il n'y a aucun paramètre, l'entrée standard est lue et exécutée.

OPTIONS

--interactive
-a
Exécute PHP de manière interactive. Ceci vous permet d'entrer des extraits de code PHP qui sont directement exécutés. Lorsque le support readline est activé, vous pouvez modifier les lignes et avoir un historique.
--bindpath adresse:port|port

Chemin de liaison pour le mode serveur FASTCGI externe (CGI seulement).
--no-chdir
-C
Ne pas changer de répertoire vers celui du script (CGI seulement).
--no-header
-q
Mode silencieux. Supprime la sortie des en-têtes HTTP (CGI seulement).
--timing compte
-T compte
Mesure le temps d'exécution du script répété 'compte' fois (CGI seulement).
--php-ini chemin|fichier

Recherche le fichier php.ini dans le répertoire chemin ou utilise le fichier spécifié.
--no-php-ini
-n
Aucun fichier php.ini ne sera utilisé.
--define foo[=bar]

Définit l'entrée INI foo avec la valeur bar.
-e
Génère des informations étendues pour le débogueur/profileur.
--file fichier

Analyse et exécute le fichier.

Masque le nom du script (fichier) et les paramètres (arguments...) des outils externes. Par exemple, vous voudrez peut-être l'utiliser lorsqu'un script PHP est lancé comme démon et que la ligne de commande contient des données sensibles comme des mots de passe.
--info
-i
Informations et configuration de PHP.
--syntax-check
-l
Vérification de syntaxe seulement (lint).
--modules
-m
Affiche les modules compilés.
--run code

Exécute le code PHP sans utiliser les balises de script '<?..?>'.
--process-begin code
-B code_debut
Exécute le code_debut PHP avant le traitement des lignes d'entrée.
--process-code code
-R code
Exécute le code PHP pour chaque ligne d'entrée.
--process-file fichier
-F fichier
Analyse et exécute le fichier pour chaque ligne d'entrée.
--process-end code
-E code_fin
Exécute le code_fin PHP après le traitement de toutes les lignes d'entrée.
--syntax-highlight
-s
Affiche le code source avec surlignage de la syntaxe HTML.
--server addr:port
-S addr:port
Démarre le serveur Web intégré sur l'adresse et le port locaux donnés.
--docroot racine_doc

Spécifie la racine du document à utiliser par le serveur Web intégré.
--version
-v
Numéro de version.
--strip
-w
Affiche le code source avec les commentaires et les espaces blancs supprimés.
--zend-extension fichier
-z fichier
Charge l'extension Zend fichier.
arguments...
Arguments passés au script. Utilisez '--' arguments lorsque le premier argument commence par '-' ou que le script est lu depuis stdin.
--rfunction
nom
--rf
nom Affiche les informations sur la fonction nom.
--rclass
nom
--rc
nom Affiche les informations sur la classe nom.
--rextension
nom
--re
nom Affiche les informations sur l'extension nom.
--rzendextension
nom
--rz
nom Affiche les informations sur l'extension Zend nom.
--rextinfo
nom
--ri
nom Affiche la configuration de l'extension nom.
--ini
Affiche les noms des fichiers de configuration.

FICHIERS

php-cli.ini
Le fichier de configuration pour la version CLI de PHP.
php.ini
Le fichier de configuration standard ne sera utilisé que si php-cli.ini ne peut pas être trouvé.

EXEMPLES

php -r 'echo "Bonjour le Monde\n";'
Cette commande écrit simplement le texte "Bonjour le Monde" sur la sortie standard.
php -r 'print_r(gd_info());'
Ceci affiche la configuration de votre extension gd. Vous pouvez l'utiliser pour vérifier facilement quels formats d'image vous pouvez utiliser. Si vous avez des modules dynamiques, vous voudrez peut-être utiliser le même fichier ini que PHP utilise lorsqu'il est exécuté depuis votre serveur Web. Il existe d'autres extensions qui ont une telle fonction. Pour dba utilisez :
php -r

NAME

php

a web development framework and programming language

SYNOPSIS

php [options] [-f file] [--] [args...]
php [options] [-r code] [--] [args...]
php [options] -i
php [options] -m
php [options] -v

DESCRIPTION

PHP is a popular general-purpose scripting language that is especially suited for web development. It can be embedded into HTML.

The PHP command line interpreter (CLI) can be used to execute PHP scripts outside of a web server environment. This is useful for system administration tasks, cron jobs, and general scripting.

OPTIONS

The php command accepts a wide range of options. Some of the most common ones include:

-d foo[=bar]
Sets a PHP configuration directive. For example, `-d html_errors=1` enables HTML error messages.
-f file
Parses and executes the specified file.
-i
Outputs information about the current PHP configuration.
-m
Outputs a list of parsed modules.
-v
Outputs the version of PHP.
-r code
Runs PHP code without a file using.
-B code
Runs PHP code before any input is processed.
-E code
Runs PHP code after all input is processed.
-F file
Parses and executes the specified file for each input line.
-q
Quiet mode. Do not output HTTP headers.
-n
No php.ini configuration file will be used.
-c path
Look for php.ini file in this directory.
-z file
Load this Zend extension file.
-h
This help message.

FILES

The PHP configuration file is typically located at /etc/php/php.ini.

EXAMPLES

Displaying the PHP version:

php -v

Executing a PHP script file:

php -f myscript.php

Running a short piece of PHP code:

php -r 'echo "Hello, world!\n";'

Running code before and after processing input:

php -B 'echo "Starting...\n";' -r 'echo "Processing: $argn\n";' -E 'echo "Finished.\n";' < input.txt

Using PHP to process input line by line:

echo "Hello world" | php -R 'echo strtoupper($argn)."\n";'

The following examples demonstrate the usage of the `-B`, `-R`, `-E`, and `-F` options, which allow for processing input streams.

php -r 'print_r($argv);' test.php -- arg1 arg2
This command executes the PHP script test.php and makes the arguments passed after -- available in the $argv array.
php -r 'print_r(dba_handlers());'
This command prints a list of available database handlers.
php -r 'print_r(dba_handlers(1));'
This command prints a list of available database handlers with flags.
php -R 'echo strip_tags($argn)."\n";'
This PHP command strips off the HTML tags line by line and outputs the result. To see how it works you can first look at the following PHP command ´php -d html_errors=1 -i´ which uses PHP to output HTML formatted configuration information. If you then combine those two ´php ...|php ...´ you'll see what happens.
php -E 'echo "Lines: $argi\n";'
Using this PHP command you can count the lines being input.
php -R '@$l+=count(file($argn));' -E 'echo "Lines:$l\n";'
In this example PHP expects each input line being a file. It counts all lines of the files specified by each input line and shows the summarized result. You may combine this with tools like find and change the php scriptlet.
php -R 'echo "$argn\n"; fgets(STDIN);'
Since you have access to STDIN from within -B -R -F and -E you can skip certain input lines with your code. But note that in such cases $argi only counts the lines being processed by php itself. Having read this you will guess what the above program does: skipping every second input line.

TIPS

You can use a shebang line to automatically invoke php from scripts. Only the CLI version of PHP will ignore such a first line as shown below:

#!/bin/php

<?php


// your script

?>
