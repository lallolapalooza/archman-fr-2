Nom

phoc-outputs-states - Inspecter les états des sorties enregistrés par phoc

SYNTAXE

phoc-outputs-states [OPTIONS...]

DESCRIPTION

phoc-outputs-states est un outil pour lister les états des sorties enregistrés connus de phoc. Ces états sont mis à jour par phoc chaque fois que la configuration des sorties change et sont appliqués lorsque phoc détecte cet ensemble spécifique de sorties.

Notez que la configuration des sorties dans phoc.ini a toujours priorité sur les états des sorties enregistrés.

OPTIONS

-h, --help
Afficher l'aide et quitter
-d, --db FICHIER
Chemin vers le fichier de base de données des états des sorties enregistrés. Si omis, la valeur par défaut intégrée à phoc sera utilisée.
-r, --raw
Utiliser une sortie brute, utile lors du traitement de la sortie dans des scripts
--list
Lister les identifiants des états des sorties dans la base de données. Les identifiants retournés sont basés sur les descriptions de sortie de wlroots.
-show=IDENTIFIANT
Afficher les détails de l'état de sortie enregistré pour l'identifiant donné.

EXEMPLES

Obtenir la liste actuelle des identifiants :

$ phoc-outputs-states --list
Identifiers
-----------
…
'(null) (null) (DSI-1)'
…

Obtenir les détails de l'identifiant (null) (null) (DSI-1) :

$ phoc-outputs-states --show '(null) (null) (DSI-1)'
(null) (null) (DSI-1)
---------------------
  Enabled: yes
     Mode: 1080x2340@60000000.00
    Scale: 2.500000
Transform: normal
