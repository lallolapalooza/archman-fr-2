PHAR(1) Commandes utilisateur PHAR(1)

NOM

phar, phar.phar - Outil en ligne de commande pour les archives PHAR (PHP)

SYNTAXE

phar <commande> [options] ...

DESCRIPTION

Le format de fichier PHAR offre un moyen de regrouper des applications PHP entières dans un seul fichier appelé "phar" (archive PHP) pour une distribution et une installation faciles.

Avec la commande phar, vous pouvez créer, mettre à jour ou extraire des archives PHP.

Commandes : add compress delete extract help help-list info list meta-del meta-get meta-set pack sign stub-get stub-set tree version

ADD COMMANDE

Ajoute des entrées à un paquet PHAR.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.
...
N'importe quel nombre de fichiers et de répertoires d'entrée. Si -i est utilisé, SEULS les fichiers correspondant à l'expression régulière donnée sont empaquetés. Si -x est donné, les fichiers correspondant à cette expression régulière NE SONT PAS empaquetés.

Arguments optionnels :

-a alias
Fournit un nom d'alias pour le fichier phar.
-c algorithme
Algorithme de compression (voir COMPRESSION)
-i regex
Spécifie une expression régulière pour les fichiers d'entrée.
-l niveau
Nombre de sous-répertoires précédents à supprimer des entrées de fichiers
-x regex
Expression régulière pour les fichiers d'entrée à exclure.

COMPRESS COMMANDE

Compresse ou décompresse tous les fichiers ou une entrée sélectionnée.

Arguments requis :

-c algorithme
Algorithme de compression (voir COMPRESSION)
-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-e entrée
Nom de l'entrée sur laquelle travailler (doit inclure le nom du répertoire interne PHAR s'il y en a un).

DELETE COMMANDE

Supprime une entrée d'une archive PHAR

Arguments requis :

-e entrée
Nom de l'entrée sur laquelle travailler (doit inclure le nom du répertoire interne PHAR s'il y en a un).
-f fichier
Spécifie le fichier phar sur lequel travailler.

Extrait un paquet PHAR vers un répertoire.

Arguments requis :

Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-i regex
Spécifie une expression régulière pour les fichiers d'entrée.
-x regex
Expression régulière pour les fichiers d'entrée à exclure.
...
Répertoire d'extraction (par défaut '.').

Ceci est l'aide ou l'aide pour une commande sélectionnée.

Arguments optionnels :

...
Commande optionnelle pour laquelle récupérer l'aide.

Liste les commandes disponibles.

Obtient des informations sur un paquet PHAR.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-k index
Index de souscription sur lequel travailler.

LIST COMMANDE

Liste le contenu d'une archive PHAR.

Arguments requis :

Spécifie le fichier phar sur lequel travailler.

-i regex
Spécifie une expression régulière pour les fichiers d'entrée.
-x regex
Expression régulière pour les fichiers d'entrée à exclure.

META-DEL COMMANDE

Supprime les métadonnées d'une entrée PHAR ou d'un paquet PHAR.

Si -k est donné, les métadonnées sont attendues comme un tableau et l'index donné est supprimé.

Si quelque chose a été supprimé, la valeur de retour est 0, sinon elle est de 1.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-e entrée
Nom de l'entrée sur laquelle travailler (doit inclure le nom du répertoire interne PHAR s'il y en a un).
-k index
Index de souscription sur lequel travailler.

META-GET COMMANDE

Récupère les métadonnées d'une entrée PHAR ou d'un paquet PHAR sous forme sérialisée. Si aucun fichier de sortie n'est spécifié pour les métadonnées, stdout est utilisé. Vous pouvez également spécifier un index particulier avec -k. Dans ce cas, les métadonnées sont attendues comme un tableau et la valeur de l'index donné est retournée en utilisant echo plutôt qu'en sérialisant. Si cet index n'existe pas ou si aucune métadonnée n'est présente, la valeur de retour est 1.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.

Arguments optionnels :

-e entrée
Nom de l'entrée sur laquelle travailler (doit inclure le nom du répertoire interne PHAR s'il y en a un).
-k index
Index de souscription sur lequel travailler.

META-SET COMMANDE

Définit les métadonnées d'une entrée PHAR ou d'un paquet PHAR en utilisant une entrée sérialisée. Si aucun fichier d'entrée n'est spécifié pour les métadonnées, stdin est utilisé. Vous pouvez également spécifier un index particulier avec -k. Dans ce cas, les métadonnées sont attendues comme un tableau et la valeur de l'index donné est définie. Si les métadonnées ne sont pas présentes ou sont vides, un nouveau tableau sera créé. Si les métadonnées sont présentes et sont une valeur plate, la valeur de retour est 1. En utilisant également -k, l'entrée est prise directement plutôt que d'être sérialisée.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.
-m meta
Métadonnées à stocker avec l'entrée (données PHP sérialisées).

Arguments optionnels :

-e entrée
Nom de l'entrée sur laquelle travailler (doit inclure le nom du répertoire interne PHAR s'il y en a un).
-k index
Index de souscription sur lequel travailler.

PACK COMMANDE

Empaquette des fichiers dans une archive PHAR.

Lors de l'utilisation de -s <stub>, le fichier stub est exclu de la liste des fichiers/répertoires d'entrée. Pour créer une archive contenant la classe PEAR PHP_Archive, pointez l'argument -p vers PHP/Archive.php.

Arguments requis :

-f fichier
Spécifie le fichier phar sur lequel travailler.
...
N'importe quel nombre de fichiers et de répertoires d'entrée. Si -i est utilisé, SEULS les fichiers correspondant à l'expression régulière donnée sont empaquetés. Si -x est donné, les fichiers correspondant à cette expression régulière NE SONT PAS empaquetés.

Arguments optionnels :

-a alias
Fournit un nom d'alias pour le fichier phar.
-b bang
Ligne de hachage pour démarrer l'archive (par exemple #!/usr/bin/php). Le caractère de hachage lui-même '#!' et le caractère de nouvelle ligne

Signe une archive PHAR avec une clé privée.

Arguments requis :

Spécifie le fichier phar sur lequel travailler.
-k clé
Nom du fichier de clé privée.

Arguments optionnels :

-p passphrase
La phrase secrète pour la clé privée.

Arguments requis :

-s stub

Arguments optionnels :

-x regex
Expression régulière pour les fichiers d'entrée à exclure.

VERSION COMMANDE

Affiche la version de l'outil PHAR.

COMPRESSION

Les algorithmes de compression pris en charge sont : GZ, BZ2, et ZIP.

Utilisez simplement le nom de l'algorithme pour le spécifier.

Par exemple :

phar pack -f my-app.phar -c GZ src/
phar pack -f my-app.phar -c BZ2 src/
phar pack -f my-app.phar -c ZIP src/

COMPILATION

Pour pouvoir utiliser cet outil, vous devez activer l'extension Phar dans votre fichier php.ini. Les archives PHAR sont créées en utilisant l'extension Phar. Vous pouvez soit utiliser le code qui se trouve dans l'archive de la bibliothèque Phar, soit créer une archive PHAR à partir de zéro.

EXEMPLES

Empaqueter des fichiers dans une archive phar sans compression :

phar pack -f my-archive.phar file1.php include/

Empaqueter des fichiers dans une archive phar avec compression gzip :

phar pack -f my-archive.phar -c GZ file1.php include/

Lister le contenu d'une archive phar :

phar list -f my-archive.phar

Extraire une archive phar dans le répertoire courant :

phar extract -f my-archive.phar

Extraire une archive phar dans un répertoire spécifique :

phar extract -f my-archive.phar /chemin/vers/extraction/

Obtenir des informations sur une archive phar :

phar info -f my-archive.phar

Obtenir la valeur d'une clé de métadonnées spécifique :

phar info -f my-archive.phar -k version

Définir des métadonnées :

echo 'a:2:{s:5:"color";s:3:"red";s:4:"size";i:2;}' | phar meta-set -f my-archive.phar


phar meta-set -f my-archive.phar -m 'a:2:{s:5:"color";s:3:"red";s:4:"size";i:2;}'

Définir une clé de métadonnées spécifique :

phar meta-set -f my-archive.phar -k color -m blue

Supprimer une clé de métadonnées spécifique :

phar meta-del -f my-archive.phar -k color

Obtenir le stub d'une archive phar et le sauvegarder dans un fichier :

phar stub-get -f my-archive.phar -o stub.php

Définir un nouveau stub pour une archive phar :

phar stub-set -f my-archive.phar -s new-stub.php

Compresser une archive phar avec gzip :

phar compress -f my-archive.phar -c GZ

Compresser une entrée spécifique d'une archive phar avec bzip2 :

phar compress -f my-archive.phar -e src/file.php -c BZ2

Signer une archive phar avec une clé privée :

phar sign -f my-archive.phar -k private.key

Signer une archive phar avec une clé privée et une phrase secrète :

phar sign -f my-archive.phar -k private.key -p mysecretphrase

Signer une archive phar avec une clé privée et une phrase secrète et la sauvegarder dans un nouveau fichier :

phar sign -f my-archive.phar -k private.key -p mysecretphrase -o signed-archive.phar
