php(1) Langage de script php(1)

NOM

php - Interface de ligne de commande PHP 'CLI'

php-cgi - Commande CGI (Common Gateway Interface) PHP

SYNOPSIS

php [options] [ -f ] fichier [[--] args...]

php [options] -r code [[--] args...]

php [options] [-B code_debut] -R code [-E code_fin] [[--] args...]

php [options] [-B code_debut] -F fichier [-E code_fin] [[--] args...]

php [options] -- [ args...]

php [options] -a

php [options] -S addr:port [-t docroot]

DESCRIPTION

PHP est un langage de script polyvalent largement utilisé, particulièrement adapté au développement Web et pouvant être intégré dans du HTML. C'est l'interface de ligne de commande qui vous permet de faire ce qui suit :

Vous pouvez analyser et exécuter des fichiers en utilisant le paramètre -f suivi du nom du fichier à exécuter.

En utilisant le paramètre -r, vous pouvez exécuter directement du code PHP, tout comme vous le feriez à l'intérieur d'un fichier .php avec la fonction eval().

Il est également possible de traiter l'entrée standard ligne par ligne en utilisant soit le paramètre -R, soit -F. En mode, chaque ligne d'entrée distincte provoque l'exécution du code spécifié par -R ou du fichier spécifié par -F. Vous pouvez accéder à la ligne d'entrée via $argn. Pendant le traitement des lignes d'entrée, $argi contient le numéro de la ligne en cours de traitement. De plus, les paramètres -B et -E peuvent être utilisés pour exécuter du code (voir -r) avant et après le traitement de toutes les lignes d'entrée respectivement. Notez que l'entrée est lue depuis STDIN et donc lire depuis STDIN modifie explicitement la ligne d'entrée suivante ou saute des lignes d'entrée.

PHP contient également un serveur Web intégré à des fins de développement d'applications. En utilisant l'option -S où addr:port pointe vers une adresse et un port locaux, PHP écoutera les requêtes HTTP sur cette adresse et ce port et servira des fichiers depuis le répertoire de travail courant ou le docroot passé avec l'option -t.

Si un fichier PHP est fourni à la ligne de commande lorsque le serveur Web intégré est utilisé, il sera utilisé comme script routeur. Ce script sera démarré à chaque requête HTTP. La sortie du script est retournée au navigateur, à moins que le script routeur ne retourne la valeur false. Dans ce cas, le serveur intégré revient à son comportement par défaut, retournant la ressource demandée telle quelle en recherchant les fichiers relatifs au répertoire racine du document spécifié par l'option -t, si elle est fournie.

Si aucun des paramètres -r, -f, -B, -R, -F, -E ou -S n'est présent mais qu'un seul paramètre est donné, alors ce paramètre est considéré comme le nom du fichier à analyser et exécuter (comme avec -f). Si aucun paramètre n'est présent, alors l'entrée standard est lue et exécutée.

FICHIERS

php-cli.ini
Le fichier de configuration pour la version CLI de PHP.
php.ini
Le fichier de configuration standard ne sera utilisé que si php-cli.ini ne peut pas être trouvé.

EXEMPLES

php -r 'echo "Bonjour le Monde\n";'
Cette commande écrit simplement le texte "Bonjour le Monde" en sortie standard.
php -r 'print_r(gd_info());'
Ceci affiche la configuration de votre extension gd. Vous pouvez l'utiliser pour vérifier facilement quels formats d'image vous pouvez utiliser. Si vous avez des modules dynamiques, vous voudrez peut-être utiliser le même fichier ini que php utilise lorsqu'il est exécuté depuis votre serveur Web. Il existe d'autres extensions qui ont une telle fonction. Pour dba:
php -r 'print_r(dba_list_keys());'
php(1) - Page de manuel d'Arch Linux

NOM

php - Interpréteur PHP en ligne de commande

SYNTAXE

php [options] [-f] fichier [argument...]
php [options] [-r code] [-B code] [-E code] [-R code] [-F code] [-D] [-i]

DESCRIPTION

Le programme php est l'interface en ligne de commande (CLI) de PHP. Il peut être utilisé pour exécuter des scripts PHP, interpréter du code PHP directement depuis la ligne de commande, ou pour évaluer des portions de code PHP.

L'interpréteur CLI est différent de l'interface du serveur web. Par exemple, les variables d'environnement comme $_SERVER["REMOTE_ADDR"] ne sont pas définies, car il n'y a pas de client distant.

Toutes les options standard de PHP, telles que définies dans php.ini, peuvent être surchargées en utilisant l'option -d.

OPTIONS

-d key[=value]
Définit la valeur d'une directive de configuration PHP. Par exemple, -d memory_limit=128M.
-f fichier
Exécute le script PHP spécifié par fichier.
-r code
Exécute le code PHP spécifié sans encapsuler le code dans les balises <?php ?>. Le code doit être valide PHP.
-B code
Exécute le code PHP spécifié avant le traitement des entrées standard (STDIN). Utilisé avec -R ou -F.
-E code
Exécute le code PHP spécifié après le traitement des entrées standard (STDIN). Utilisé avec -R ou -F.
-R code
Exécute le code PHP spécifié pour chaque ligne d'entrée standard (STDIN). La variable $argn contient la ligne d'entrée actuelle.
-F code
Exécute le code PHP spécifié pour chaque ligne d'entrée standard (STDIN). Cette option est similaire à -R, mais elle lit également le reste de l'entrée standard après le traitement de chaque ligne. La variable $argn contient la ligne d'entrée actuelle.
-i
Affiche des informations détaillées sur la configuration de PHP, y compris les directives de configuration, les variables d'environnement et les extensions chargées. Le format de sortie est du HTML par défaut.
-q
Mode silencieux. Ne publie pas d'informations sur la sortie Web.
-v
Affiche la version de PHP et quitte.
-h
Affiche un message d'aide et quitte.

FICHIERS

php.ini
Fichier de configuration principal de PHP. Le chemin est déterminé lors de la compilation.

EXEMPLES

Afficher les gestionnaires DBA disponibles :

php -r 'print_r(dba_handlers(1));'
php -R 'echo strip_tags($argn)."\n";'
Cette commande PHP supprime les balises HTML ligne par ligne et affiche le résultat. Pour voir comment cela fonctionne, vous pouvez d'abord consulter la commande PHP suivante : ´php -d html_errors=1 -i´, qui utilise PHP pour afficher des informations de configuration formatées en HTML. Si vous combinez ensuite ces deux commandes ´php ...|php ...´, vous verrez ce qui se passe.
php -E 'echo "Lignes: $argi\n";'
En utilisant cette commande PHP, vous pouvez compter les lignes d'entrée.
php -R '@$l+=count(file($argn));' -E 'echo "Lignes:$l\n";'
Dans cet exemple, PHP suppose que chaque ligne d'entrée est un fichier. Il compte toutes les lignes des fichiers spécifiés par chaque ligne d'entrée et affiche le résultat résumé. Vous pouvez combiner cela avec des outils comme find et modifier le scriptlet PHP.
php -R 'echo "$argn\n"; fgets(STDIN);'
Comme vous avez accès à STDIN depuis -B, -R, -F et -E, vous pouvez sauter certaines lignes d'entrée avec votre code. Mais notez que dans de tels cas, $argi ne compte que les lignes traitées par PHP lui-même. Après avoir lu ceci, vous devinerez ce que fait le programme ci-dessus : sauter une ligne d'entrée sur deux.

CONSEILS

Vous pouvez utiliser une ligne shebang pour invoquer automatiquement PHP depuis les scripts. Seule la version CLI de PHP ignorera une telle première ligne, comme indiqué ci-dessous :

#!/bin/php

<?php


// votre script

?>
