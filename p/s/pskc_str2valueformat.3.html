NOM

pskc_str2valueformat - Fonction de l'API

SYNOPSIS

#include <pskc.h>

pskc_valueformat pskc_str2valueformat(const char * valueformat);

ARGUMENTS

const char * valueformat
une chaîne décrivant une utilisation de clé.

DESCRIPTION

Convertit une chaîne en type pskc_valueformat. Par exemple, pskc_str2valueformat("DECIMAL") renverra PSKC_VALUEFORMAT_DECIMAL.

RETOURNE

La valeur pskc_valueformat correspondante.
