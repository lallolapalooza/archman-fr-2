CPSTF2 calcule la factorisation de Cholesky avec pivotement complet d'une matrice complexe hermitienne semi-définie positive A.

Objectif :

!>
!> CPSTF2 calcule la factorisation de Cholesky avec pivotement
!> complet d'une matrice complexe hermitienne semi-définie positive A.
!>
!> La factorisation a la forme
!>    P**T * A * P = U**H * U ,  si UPLO = 'U',
!>    P**T * A * P = L  * L**H,  si UPLO = 'L',
!> où U est une matrice triangulaire supérieure et L est triangulaire inférieure, et
!> P est stocké sous forme de vecteur PIV.
!>
!> Cet algorithme ne tente pas de vérifier si A est semi-définie positive.
!> Cette version de l'algorithme utilise BLAS de niveau 2.
!>

Paramètres

UPLO 
!>          UPLO est CHARACTER*1
!>          Spécifie si la partie triangulaire supérieure ou inférieure de la
!>          matrice symétrique A est stockée.
!>          = 'U':  Triangulaire supérieure
!>          = 'L':  Triangulaire inférieure
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX, de dimension (LDA,N)
!>          À l'entrée, la matrice symétrique A. Si UPLO = 'U', la partie
!>          supérieure triangulaire de A de taille n par n contient la partie
!>          triangulaire supérieure de la matrice A, et la partie strictement
!>          inférieure triangulaire de A n'est pas référencée. Si UPLO = 'L', la
!>          partie inférieure triangulaire de A de taille n par n contient la partie
!>          triangulaire inférieure de la matrice A, et la partie strictement
!>          supérieure triangulaire de A n'est pas référencée.
!>
!>          À la sortie, si INFO = 0, le facteur U ou L de la factorisation de Cholesky
!>          comme ci-dessus.
!>

PIV

!>          PIV est un tableau INTEGER, de dimension (N)
!>          PIV est tel que les entrées non nulles sont P( PIV(K), K ) = 1.
!>

RANK

!>          RANK est INTEGER
!>          Le rang de A donné par le nombre d'étapes que l'algorithme
!>          a complétées.
!>

TOL

!>          TOL est REAL
!>          Tolérance définie par l'utilisateur. Si TOL < 0, alors N*U*MAX( A( K,K ) )
!>          sera utilisé. L'algorithme se termine à l'étape (K-1) si le pivot <= TOL.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

WORK

!>          WORK est un tableau REAL, de dimension (2*N)
!>          Espace de travail.
!>

INFO

!>          INFO est INTEGER
!>          < 0 : Si INFO = -K, le K-ième argument était invalide,
!>          = 0 : l'algorithme s'est terminé avec succès, et
!>          > 0 : la matrice A est soit de rang déficient avec un rang calculé
!>               tel que retourné dans RANK, soit n'est pas semi-définie positive. Voir
!>               la Section 7 de la Note de travail LAPACK #161 pour plus
!>               d'informations.
!>

NAME

pstf2, spstf2, zpstf2 — factorisation de Cholesky avec pivotement complet d'une matrice symétrique/Hermitienne positive semi-définie.

SYNOPSIS

      SUBROUTINE PSTF2( UPLO, N, A, LDA, PIV, RANK, TOL, WORK, INFO )

      SUBROUTINE SPSTF2( UPLO, N, A, LDA, PIV, RANK, TOL, WORK, INFO )

      SUBROUTINE ZPSTF2( UPLO, N, A, LDA, PIV, RANK, TOL, WORK, INFO )

Detailed Description

PSTF2 calcule la factorisation de Cholesky avec pivotement complet d'une matrice réelle symétrique/Hermitienne positive semi-définie.

La factorisation a la forme

   P**T * A * P = U**T * U ,  si UPLO = 'U',
   P**T * A * P = L  * L**T,  si UPLO = 'L',

où U est une matrice triangulaire supérieure et L est triangulaire inférieure, et P est stocké sous forme de vecteur PIV.

Cet algorithme ne tente pas de vérifier que A est positive semi-définie. Cette version de l'algorithme appelle BLAS de niveau 2.
