NOM

pskc_get_key_algparm_chall_checkdigits - Fonction d'API

SYNTAXE

#include <pskc.h>

int pskc_get_key_algparm_chall_checkdigits(pskc_key_t * key, int * present);

ARGUMENTS

pskc_key_t * key
un handle pskc_key_t, obtenu via pskc_get_keypackage().
int * present
variable de sortie indiquant si des données ont été fournies ou non.

DESCRIPTION

Obtient la valeur de l'attribut PSKC KeyPackage Key AlgorithmParameters ChallengeFormat CheckDigits. Cet attribut indique si un appareil doit vérifier le chiffre de contrôle Luhn ajouté, tel que défini dans [ISOIEC7812], contenu dans un défi. Ceci n'est valide que si l'attribut 'Encoding' est réglé sur 'DECIMAL'. Une valeur TRUE indique que l'appareil vérifiera le chiffre de contrôle Luhn ajouté dans un défi fourni. Une valeur FALSE indique que l'appareil ne vérifiera pas le chiffre de contrôle Luhn ajouté dans le défi.

Si present n'est pas NUL, il sera égal à 0 si le champ n'est pas présent ou 1 s'il était présent.

RETOURNE

1 pour indiquer une valeur CheckDigits à vrai, ou 0 pour indiquer faux.
