NOM

pskc_get_device_issueno - Fonction d'API

SYNTAXE

#include <pskc.h>

const char * pskc_get_device_issueno(pskc_key_t * key);

ARGUMENTS

pskc_key_t * key
un handle pskc_key_t, issu de pskc_get_keypackage().

DESCRIPTION

Obtient le numéro d'émission (IssueNo) des informations de l'appareil (DeviceInfo) du PSKC KeyPackage. Cet élément contient le numéro d'émission au cas où il y aurait des appareils avec le même numéro de série, afin qu'ils puissent être distingués par différents numéros d'émission.

RETOURNE

Une chaîne constante (ne doit pas être libérée) contenant le contenu, ou NULL si non défini.
