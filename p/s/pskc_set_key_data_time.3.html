pskc_set_key_data_time(3) libpskc pskc_set_key_data_time(3)

NOM

pskc_set_key_data_time - Fonction d'API

SYNTAXE

#include <pskc.h>

void pskc_set_key_data_time(pskc_key_t * key, uint32_t datatime);

ARGUMENTS

pskc_key_t * key
un handle pskc_key_t, obtenu par pskc_get_keypackage().
uint32_t datatime
la valeur de l'heure des données à définir.

DESCRIPTION

Définit la valeur de l'heure des données de la clé (Key Data Time) du PSKC KeyPackage. Cet élément contient l'heure pour les algorithmes OTP basés sur le temps. (Si des intervalles de temps sont utilisés, cet élément porte le nombre d'intervalles de temps écoulés depuis un point de départ spécifique, normalement il dépend de l'algorithme).
