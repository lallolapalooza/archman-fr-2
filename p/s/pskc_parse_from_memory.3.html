NOM

pskc_parse_from_memory - fonction API

SYNTAXE

#include <pskc.h>

int pskc_parse_from_memory(pskc_t * container, size_t len, const char * buffer);

ARGUMENTS

pskc_t * container
un handle pskc_t, issu de pskc_init().
size_t len
longueur de buffer.
const char * buffer
données XML à analyser.

DESCRIPTION

Cette fonction analysera les données XML dans buffer d'une taille de len dans container. Si PSKC_PARSE_ERROR est renvoyé, l'analyse de certains éléments a échoué mais le container est toujours valide et contient des informations partiellement analysées. Dans ce cas, vous pouvez continuer mais émettre un avertissement.

RETOURNE

En cas de succès, PSKC_OK (zéro) est renvoyé, en cas d'erreurs d'allocation mémoire PSKC_MALLOC_ERROR est renvoyé, en cas d'erreurs de la bibliothèque XML PSKC_XML_ERROR est renvoyé, en cas d'erreurs d'analyse PSKC PSKC_PARSE_ERROR est renvoyé.
