NOM

pskc_get_key_id - Fonction d'API

SYNOPIS

#include <pskc.h>

const char * pskc_get_key_id(pskc_key_t * key);

ARGUMENTS

pskc_key_t * key
un handle pskc_key_t, issu de pskc_get_keypackage().

DESCRIPTION

Récupère la valeur de l'attribut d'identifiant de clé (Key Id) du PSKC KeyPackage. Il est syntaxiquement incorrect que cet attribut ne soit pas disponible.

RETOURNE

Une chaîne de caractères constante (ne doit pas être libérée) contenant le contenu, ou NULL si non défini.
