NOM

psl-make-dafsa - générer un DAFSA compact et optimisé à partir d'une Public Suffix List

SYNTAXE

psl-make-dafsa [options] fichier_entree fichier_sortie

DESCRIPTION

psl-make-dafsa produit du code C/C++ ou un objet binaire indépendant de l'architecture qui représente un automate fini déterministe acyclique (DAFSA) à partir d'une représentation textuelle d'une Public Suffix List. Les fichiers d'entrée et de sortie doivent être spécifiés sur la ligne de commande.

Cette représentation compacte permet des requêtes optimisées de la liste, économisant ainsi du temps et de l'espace par rapport aux recherches de représentations lisibles par l'homme.

OPTIONS

Le format des données lues et écrites par psl-make-dafsa dépend des options qui lui sont passées.

--output-format=[cxx|cxx+|binary]
cxx : (par défaut) la sortie est du code C/C++
cxx+ : la sortie est du code C/C++ plus des affectations statistiques (utilisé par le processus de construction de libpsl)
binary : la sortie est un format binaire indépendant de l'architecture
--encoding=[utf-8|ascii]
utf-8 : (par défaut) mode UTF-8 (la sortie contient UTF-8 + punycode)
ascii : (obsolète) mode ASCII 7 bits (la sortie ne contient que du punycode)
