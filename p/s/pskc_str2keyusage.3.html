NOM

pskc_str2keyusage - Fonction API

SYNTAXE

#include <pskc.h>

pskc_keyusage pskc_str2keyusage(const char * keyusage);

ARGUMENTS

const char * keyusage
une chaîne décrivant une utilisation de clé.

DESCRIPTION

Convertit une chaîne en un type pskc_keyusage. Par exemple, pskc_str2keyusage("KeyWrap") retournera PSKC_KEYUSAGE_KEYWRAP.

RETOURNE

La valeur correspondante pskc_keyusage.
