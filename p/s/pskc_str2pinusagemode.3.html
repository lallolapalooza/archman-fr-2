NOM

pskc_str2pinusagemode - Fonction API

SYNOPSIS

#include <pskc.h>

pskc_pinusagemode pskc_str2pinusagemode(const char * pinusagemode);

ARGUMENTS

const char * pinusagemode
une chaîne décrivant une utilisation de clé.

DESCRIPTION

Convertit une chaîne en type pskc_pinusagemode. Par exemple, pskc_str2pinusagemode("Local") renverra PSKC_PINUSAGEMODE_LOCAL.

RETOURNE

La valeur pskc_pinusagemode correspondante.
