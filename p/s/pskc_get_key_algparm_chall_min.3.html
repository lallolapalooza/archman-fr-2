NOM

pskc_get_key_algparm_chall_min - fonction API

SYNTAXE

#include <pskc.h>

uint32_t pskc_get_key_algparm_chall_min(pskc_key_t * key, int * present);

ARGUMENTS

pskc_key_t * key
un handle pskc_key_t, obtenu par pskc_get_keypackage().
int * present
variable de sortie indiquant si des données ont été fournies ou non.

DESCRIPTION

Obtient la valeur minimale de la taille du défi (ChallengeFormat Min) des Paramètres Algorithmiques de la Clé (Key AlgorithmParameters) du Paquet de Clé (KeyPackage) PSKC. Cet attribut définit la taille minimale du défi accepté par l'appareil pour le mode CR et DOIT être inclus. Si l'attribut 'Encoding' est défini sur 'DECIMAL', 'HEXADECIMAL' ou 'ALPHANUMERIC', cette valeur indique le nombre minimum de chiffres/caractères. Si l'attribut 'Encoding' est défini sur 'BASE64' ou 'BINARY', cette valeur indique le nombre minimum d'octets de la valeur non encodée.

Si present n'est pas NULL, il sera à 0 si le champ est absent ou à 1 s'il était présent.

RETOURNE

un entier contenant le contenu.
