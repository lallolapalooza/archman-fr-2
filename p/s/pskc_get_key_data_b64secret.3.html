NOM

pskc_get_key_data_b64secret - fonction API

SYNTAXE

#include <pskc.h>

const char * pskc_get_key_data_b64secret(pskc_key_t * key);

ARGUMENTS

pskc_key_t * key
un handle pskc_key_t, obtenu par pskc_get_keypackage().

DESCRIPTION

Obtient la valeur du secret de données de clé PSKC KeyPackage en base64 sous forme de chaîne terminée par un zéro.

RETOUR

une chaîne constante (ne doit pas être désallouée) contenant le contenu de longueur *len, ou NULL si non défini.
