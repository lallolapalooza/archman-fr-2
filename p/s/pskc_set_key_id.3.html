NOM

pskc_set_key_id - Fonction API

SYNTAXE

#include <pskc.h>

void pskc_set_key_id(pskc_key_t * key, const char * keyid);

ARGUMENTS

pskc_key_t * key
un handle pskc_key_t, obtenu par pskc_get_keypackage().
const char * keyid
la chaîne d'identité de la clé à définir.

DESCRIPTION

Définit la valeur de l'attribut d'identifiant de clé (Key Id) du paquet de clés PSKC (KeyPackage). Il est considéré comme une erreur de syntaxe si cet attribut n'est pas disponible.

Le pointeur est stocké dans le conteneur, pas une copie des données, vous ne devez donc pas désallouer les données avant un autre appel à cette fonction ou le dernier appel à toute fonction utilisant le conteneur.
