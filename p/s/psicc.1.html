PSICC(1) Manuel des commandes générales PSICC(1)

NOM

psicc - convertisseur PostScript de little cms.

SYNTAXE

psicc [options]

DESCRIPTION

lcms est un moteur CMM autonome, qui gère la gestion des couleurs. Il implémente une transformation rapide entre les profils ICC. psicc est un convertisseur PostScript de little cms.

OPTIONS

-b
Compensation du point noir (CRD uniquement).
-c précision
Précision (0=Basse résolution, 1=Normale, 2=Haute résolution) (CRD uniquement) [par défaut 1].
-i profil
Profil d'entrée : Génère un tableau d'espace colorimétrique (CSA).
-n points_grille
Autre façon de définir la précision, nombre de points CLUT (CRD uniquement).
-o profil
Profil de sortie : Génère un dictionnaire de rendu des couleurs (CRD).
-t rendu
Intention de rendu (0=Perceptuel, 1=Colorimétrique, 2=Saturation, 3=Absolu) [par défaut 0].
-u
NE PAS générer de nom de ressource sur le CRD.

NOTES

Pour des suggestions, commentaires, rapports de bugs etc. envoyez un mail à info@littlecms.com.
