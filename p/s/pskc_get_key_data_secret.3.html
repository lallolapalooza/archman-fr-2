NOM

pskc_get_key_data_secret - fonction d'API

SYNTAXE

#include <pskc.h>

const char * pskc_get_key_data_secret(pskc_key_t * key, size_t * len);

ARGUMENTS

pskc_key_t * key
un handle pskc_key_t, obtenu via pskc_get_keypackage().
size_t * len
pointeur vers la variable de sortie contenant la longueur des données retournées.

DESCRIPTION

Obtient la valeur du secret des données de la clé (Key Data Secret) du PSKC KeyPackage. Si len n'est pas défini, l'appelant ne peut utiliser la valeur retournée que pour une comparaison avec NULL afin de vérifier si le champ est présent ou non.

RETOUR

Une chaîne de caractères constante (ne doit pas être libérée) contenant le contenu de longueur *len, ou NULL si non défini.
