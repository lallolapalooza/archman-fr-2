pskc_get_key_policy_pinminlength(3) libpskc pskc_get_key_policy_pinminlength(3)

NOM

pskc_get_key_policy_pinminlength - Fonction API

SYNTAXE

#include <pskc.h>

uint32_t pskc_get_key_policy_pinminlength(pskc_key_t * key, int * present);

ARGUMENTS

pskc_key_t * key
un handle pskc_key_t, obtenu via pskc_get_keypackage().
int * present
variable de sortie indiquant si des données ont été fournies ou non.

DESCRIPTION

Récupère la valeur PSKC KeyPackage Key Policy PINPolicy MinLength. Cet attribut indique la longueur minimale d'un code PIN pouvant être défini pour protéger la clé associée. Il ne DOIT PAS être possible de définir un code PIN plus court que cette valeur. Si l'attribut 'PINFormat' est défini sur 'DECIMAL', 'HEXADECIMAL' ou 'ALPHANUMERIC', cette valeur indique le nombre de chiffres/caractères. Si l'attribut 'PINFormat' est défini sur 'BASE64' ou 'BINARY', cette valeur indique le nombre d'octets de la valeur non codée.

Si present n'est pas NUL, il sera 0 si le champ n'est pas présent ou 1 s'il était présent.

RETOURNE

un entier contenant le contenu.
