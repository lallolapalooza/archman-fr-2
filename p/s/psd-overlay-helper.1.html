NOM

psd-overlay-helper - Script pour utiliser le système de fichiers overlay pour profile-sync-daemon.

DESCRIPTION

Profile-sync-daemon (psd) est un petit pseudo-démon conçu pour gérer les profils de navigateur dans tmpfs et les synchroniser périodiquement avec le disque physique (HDD/SSD). Ceci est accompli par une utilisation innovante de rsync pour maintenir la synchronisation entre une copie tmpfs et une sauvegarde liée aux médias du/des profil(s) de navigateur. De plus, psd dispose de plusieurs fonctionnalités de récupération après crash.

Le script psd-overlay-helper est utilisé en interne pour activer l'utilisation du système de fichiers overlay. Il ne doit pas être appelé directement par l'utilisateur.
