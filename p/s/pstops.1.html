PSTOPS(1) Commandes utilisateur PSTOPS(1)

NOM

pstops

SYNTAXE

pstops [OPTION...] [FICHIER_ENTREE [FICHIER_SORTIE]]

DESCRIPTION

Réorganise les pages d'un document PDF ou PostScript. Les fichiers PostScript doivent suivre les conventions de structuration de documents Adobe.

Pstops peut être utilisé pour effectuer des réorganisations arbitraires de documents. Pour de nombreuses tâches, il est plus simple d'utiliser les autres utilitaires de la suite PSUtils : voir psutils(1).

FICHIER_ENTREE
`-' ou aucun argument FICHIER_ENTREE signifie l'entrée standard
FICHIER_SORTIE
`-' ou aucun argument FICHIER_SORTIE signifie la sortie standard

OPTIONS

-S SPEC, --specs SPEC
spécifications de pages (voir ci-dessous)
-R PLAGE, --pages PLAGE
sélectionne les plages de pages données
-e, --even
sélectionne les pages de sortie paires
-o, --odd
sélectionne les pages de sortie impaires
-r, --reverse
inverse l'ordre des pages de sortie
-p PAPIER, --paper PAPIER
nom de papier de sortie ou dimensions (LARGEURxHAUTEUR)
-P PAPIER_ENTREE, --inpaper PAPIER_ENTREE
nom de papier d'entrée ou dimensions (LARGEURxHAUTEUR)
-d [DIMENSION], --draw [DIMENSION]
dessine une ligne de largeur donnée (relative à la page d'origine) autour de chaque page [l'argument vaut 1pt par défaut ; par défaut, pas de ligne ; la largeur est fixe pour le PDF]
-v, --version
affiche le numéro de version du programme et quitte
-q, --quiet
ne montre pas la progression

COMMENTAIRES

PAGES est une liste de pages et de plages de pages séparées par des virgules.

SPEC est une liste de spécifications de pages [par défaut "0", qui sélectionne chaque page dans son ordre normal].

Les spécifications de pages ont la syntaxe suivante :

pagespecs
= [modulo:]specs
specs
= spec[+specs|,specs]
spec
= [-]num_page[transform...][@echelle][(decalx,decale)]
transform
= L|R|U|H|V

modulo est le nombre de pages dans chaque bloc. La valeur de modulo doit être supérieure à 0 ; la valeur par défaut est 1.

specs sont les spécifications de pages pour les pages de chaque bloc. La valeur de num_page dans chaque spec doit être comprise entre 0 (pour la première page du bloc) et modulo-1 (pour la dernière page de chaque bloc) inclusivement. S'il n'y a qu'une seule spécification de page, le num_page (0) peut être omis.

Les dimensions optionnelles decalx et decale décalent la page de la quantité spécifiée. decalx et decale peuvent être soit des longueurs (voir psutils(1)) soit suivies de w ou h pour indiquer un multiple de la largeur ou de la hauteur de la page de sortie.

Les transformations optionnelles L, R, U, H et V font pivoter la page vers la gauche, la droite, ou la retournent, autour de son coin inférieur gauche, et la retournent horizontalement ou verticalement respectivement. Le paramètre d'échelle optionnel echelle met à l'échelle la page par le facteur spécifié. Si le signe moins optionnel est spécifié, le numéro de page est relatif à la fin du document, au lieu du début.

Les pages dont les specs sont séparées par + seront fusionnées en une seule page ; sinon, elles resteront comme des pages séparées.

Le décalage, la rotation et la mise à l'échelle sont appliqués à la matrice de transformation PostScript dans cet ordre, quelle que soit l'ordre dans lequel ils apparaissent sur la ligne de commande.

Les noms de format de papier sont convertis en dimensions à l'aide de paper(1). La taille de la page de sortie, si elle est définie, est utilisée (après mise à l'échelle) pour définir le chemin de découpe de chaque page.

EXEMPLES

Pour placer deux pages de série A ou B (par exemple A4 ou B5) sur une feuille de papier, la spécification de page à utiliser est :


2:0L@.7(1w,0)+1L@.7(1w,0.5h)


Pour sélectionner toutes les pages impaires dans l'ordre inverse, utilisez :


2:-0


Pour réorganiser les pages pour l'impression de livrets 2 par page, utilisez


4:-3L@.7(1w,0h)+0L@.7(1w,0.5h)


pour les recto, et


4:1L@.7(1w,0h)+-2L@.7(1w,0.5h)


pour les verso, ou, pour une impression en duplex sur le grand côté, joignez les deux spécifications ainsi :


4:-3L@.7(1w,0h)+0L@.7(1w,0.5h),1L@.7(1w,0h)+-2L@.7(1w,0.5h)


Pour le duplex sur le petit côté, l'incantation est :


4:-3L@.7(1w,0h)+0L@.7(1w,0.5h),1R@.7(0w,0.5h)+-2R@.7(0w,1h)


AUTEUR

BOGUES

pstops n'accepte pas tous les commentaires DSC.
