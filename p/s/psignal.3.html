psignal(3) Manuel des fonctions de bibliothèque psignal(3)

NOM

psignal, psiginfo - afficher la description d'un signal

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <signal.h>
void psignal(int sig, const char *s);
void psiginfo(const siginfo_t *pinfo, const char *s);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

psignal() :

    Depuis glibc 2.19 :
            _DEFAULT_SOURCE
    glibc 2.19 et versions antérieures :
        _BSD_SOURCE || _SVID_SOURCE

psiginfo() :

    _POSIX_C_SOURCE >= 200809L

DESCRIPTION

La fonction psignal() affiche un message sur stderr composé de la chaîne s, deux-points, un espace, une chaîne décrivant le numéro de signal sig, et un saut de ligne final. Si la chaîne s est NULL ou vide, les deux-points et l'espace sont omis. Si sig est invalide, le message affiché indiquera un signal inconnu.

La fonction psiginfo() est similaire à psignal(), sauf qu'elle affiche des informations sur le signal décrit par pinfo, qui doit pointer vers une structure siginfo_t valide. En plus de la description du signal, psiginfo() affiche des informations sur l'origine du signal, et d'autres informations pertinentes pour le signal (par exemple, l'adresse mémoire pertinente pour les signaux générés par le matériel, l'ID du processus enfant pour SIGCHLD, et l'ID utilisateur et l'ID de processus de l'expéditeur, pour les signaux définis à l'aide de kill(2) ou sigqueue(3)).

VALEUR DE RETOUR

Les fonctions psignal() et psiginfo() ne renvoient aucune valeur.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
psignal (), psiginfo () Thread safety MT-Safe locale

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.10. POSIX.1-2008, 4.3BSD.

BOGUES

Jusqu'à glibc 2.12, psiginfo() présentait les bogues suivants :

•
Dans certaines circonstances, un saut de ligne final n'est pas imprimé.
•
Des détails supplémentaires ne sont pas affichés pour les signaux temps réel.

VOIR AUSSI

sigaction(2), perror(3), strsignal(3), signal(7)
