NOM

pskc_get_cryptomodule_id - Fonction d'API

SYNTAXE

#include <pskc.h>

const char * pskc_get_cryptomodule_id(pskc_key_t * key);

ARGUMENTS

pskc_key_t * key
un handle pskc_key_t, obtenu depuis pskc_get_keypackage().

DESCRIPTION

Obtient la valeur de l'identifiant du module cryptographique (CryptoModule Id) du PSKC KeyPackage. Cet élément porte un identifiant unique pour le module cryptographique et est spécifique à l'implémentation. En tant que tel, il aide à identifier un module cryptographique spécifique auquel la clé est en cours de provisionnement ou a été provisionnée.

RETOURNE

Une chaîne de caractères constante (ne doit pas être libérée) contenant le contenu, ou NULL si elle n'est pas définie.
