NOM

pskc_set_key_algparm_resp_checkdigits - Fonction de l'API

SYNTAXE

#include <pskc.h>

void pskc_set_key_algparm_resp_checkdigits(pskc_key_t * key, int checkdigit);

ARGUMENTS

pskc_key_t * key
un descripteur pskc_key_t, obtenu avec pskc_get_keypackage().
int checkdigit
une valeur non nulle pour indiquer la définition de CheckDigit à vrai, 0 sinon.

DESCRIPTION

Définit la valeur CheckDigits du format de réponse des paramètres d'algorithme de clé (Key AlgorithmParameters ResponseFormat) du paquet de clé PSKC (KeyPackage). Cet attribut indique si l'appareil doit ajouter un chiffre de contrôle Luhn, tel que défini dans [ISOIEC7812], à la réponse. Ceci n'est valide que si l'attribut 'Encoding' est défini sur 'DECIMAL'. Si la valeur est VRAI, l'appareil ajoutera un chiffre de contrôle Luhn à la réponse. Si la valeur est FAUX, l'appareil n'ajoutera pas de chiffre de contrôle Luhn à la réponse.
