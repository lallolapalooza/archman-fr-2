NOM

pskc_set_device_userid - Fonction API

SYNTAXE

#include <pskc.h>

void pskc_set_device_userid(pskc_key_t * key, const char * userid);

ARGUMENTS

pskc_key_t * key
un handle pskc_key_t, provenant de pskc_get_keypackage().
const char * userid
une chaîne de caractères avec l'identité utilisateur à définir.

DESCRIPTION

Définit la valeur Userid du DeviceInfo du PSKC KeyPackage. Ceci indique l'utilisateur auquel le périphérique est associé.

Le pointeur est stocké dans container, et non une copie des données. Vous ne devez donc pas désallouer les données avant un autre appel à cette fonction ou le dernier appel à toute fonction utilisant container.
