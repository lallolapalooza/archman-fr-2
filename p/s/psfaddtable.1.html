NOM

psfaddtable - ajouter une table de caractères Unicode à une police de console

SYNTAXE

psfaddtable fichierpolice fichiertable fichierde saída

DESCRIPTION

psfaddtable prend une police de console au format .psf donnée par fichierpolice et la fusionne avec la table de caractères Unicode donnée par fichiertable pour produire un fichier de police avec une table de caractères intégrée, qui est écrit dans fichierde saída. Un nom de fichier d'entrée de "-" indique l'entrée standard, et un nom de fichier de sortie de "-" indique la sortie standard. Si le fichierpolice contient déjà une table de caractères intégrée, elle est ignorée.

FORMAT DU FICHIER TABLE

Chaque ligne du fichiertable doit être soit vide, contenir un commentaire (précédé de #), soit contenir une séquence de nombres au format décimal (par défaut), octal (précédé de 0) ou hexadécimal (précédé de 0x), séparés par des espaces ou des tabulations. Le premier nombre sur chaque ligne indique l'emplacement du glyphe dans la police auquel il est fait référence, compris entre 0 et 0xff pour une police de 256 caractères et 0 et 0x1ff pour une police de 512 caractères. Tous les nombres suivants sur la même ligne sont des Unicodes associés à cet emplacement de glyphe spécifique. Au lieu d'un seul Unicode, on peut avoir une séquence d'Unicodes séparés par des virgules, pour indiquer que le glyphe représente le symbole composé correspondant. Il est permis d'avoir plusieurs lignes pour le même glyphe.
