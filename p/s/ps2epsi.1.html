PS2EPSI(1) Outils Ghostscript PS2EPSI(1)

NOM

ps2epsi - générer un PostScript encapsulé conforme

SYNTAXE

ps2epsi fichier_entree.ps [ fichier_sortie.epsi ] (Unix)
ps2epsi fichier_entree.ps [ fichier_sortie.epi ] (DOS)

DESCRIPTION

ps2epsi utilise gs(1) pour traiter un fichier PostScript(tm) et générer en sortie un nouveau fichier conforme au format Encapsulated PostScript Interchange (EPSI) d'Adobe. EPSI est une forme spéciale de PostScript encapsulé (EPS) qui ajoute au début du fichier, sous forme de commentaires PostScript, une version bitmap de la page finale affichée. Les programmes qui comprennent l'EPSI (généralement les traitements de texte ou les programmes de PAO) peuvent utiliser cette image bitmap pour fournir une prévisualisation à l'écran du PostScript. La qualité affichée n'est souvent pas très bonne (par exemple, faible résolution, pas de couleurs), mais la version imprimée finale utilise le vrai PostScript, et a donc la qualité PostScript normale.

UTILISATION

Sur les systèmes Unix, lancez ps2epsi comme suit :

ps2epsi fichier_entree.ps [ fichier_sortie.epsi ]

où "fichier_entree.ps" est le fichier d'entrée et "fichier_sortie.epsi" est le fichier EPSI résultant. Si le nom de fichier de sortie est omis, il est généré à partir du nom de fichier d'entrée. Lorsqu'une extension standard (".ps", ".cps", ".eps" ou ".epsf") est utilisée, elle est remplacée par l'extension de sortie ".epsi". Sur les systèmes DOS, la commande est :

ps2epsi fichier_entree.ps fichier_sortie.epi

où "fichier_entree.ps" est le fichier PostScript original, et "fichier_sortie.epi" est le nom du fichier de sortie.

LIMITATIONS

Tous les fichiers PostScript ne peuvent pas être encapsulés avec succès, car il existe des restrictions sur les constructions PostScript qu'un fichier encapsulé correct peut contenir. ps2epsi effectue un petit travail supplémentaire pour essayer d'aider à l'encapsulation, et il calcule automatiquement la boîte englobante requise pour tous les fichiers PostScript encapsulés, donc la plupart du temps, il fait un travail assez bon. Il y aura certainement des cas, cependant, où l'encapsulation ne fonctionnera pas en raison du contenu du fichier PostScript original.

COMPATIBILITE

Le système de PAO Framemaker est une application qui comprend les fichiers EPSI, et ps2epsi a été testé sur un certain nombre de diagrammes PostScript provenant de diverses sources, en utilisant Framemaker 3.0 sur une station de travail Sun. Framemaker sur d'autres plateformes devrait pouvoir utiliser ces fichiers, bien que je n'aie pas pu le tester.

FICHIERS

ps2epsi script shell Unix
ps2epsi.bat fichier batch DOS
ps2epsi.ps le programme Ghostscript qui effectue le travail

VOIR AUSSI

gs(1)
