NOM

ps2pdfwr - Convertir PostScript en PDF sans spécifier de CompatibilityLevel, en utilisant ghostscript

SYNTAXE

ps2pdfwr [options...] {input.[e]ps|-} [output.pdf|-]

DESCRIPTION

Ce script wrapper invoque gs(1) avec les arguments suivants


-q -dNOPAUSE -dBATCH -sDEVICE=pdfwrite

ainsi que l'argument -dOutputFile approprié, tous précédés et suivis par les arguments de ligne de commande. Finalement, l'option de sécurité -dSAFER est ajoutée avant toutes les autres options (Ceci est maintenant redondant car "SAFER" est maintenant le défaut, mais l'option ne nuit pas).

Les scripts ps2pdf spécifiques à la version invoquent tous celui-ci avec l'ajout de l'option de niveau de compatibilité respective.

VOIR AUSSI

gs(1), ps2pdf(1)

VERSION
