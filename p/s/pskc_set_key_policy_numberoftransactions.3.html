NOM

pskc_set_key_policy_numberoftransactions - Fonction de l'API

SYNOPSIS

#include <pskc.h>

void pskc_set_key_policy_numberoftransactions(pskc_key_t * key, uint64_t uses);

ARGUMENTS

pskc_key_t * key
un handle pskc_key_t, obtenu avec pskc_get_keypackage().
uint64_t uses
le nombre de transactions à définir.

DESCRIPTION

Définit la valeur NumberOfTransactions de la politique de clé du KeyPackage PSKC. La valeur de cet élément indique le nombre maximum de fois qu'une clé contenue dans le document PSKC peut être utilisée par une application après l'avoir reçue. Lorsque cet élément est omis, il n'y a aucune restriction concernant le nombre de fois qu'une clé peut être utilisée.

Notez que bien que la spécification PSKC utilise le type de données XML "nonNegativeInteger" pour cette variable, cette implémentation limite la taille de la valeur aux entiers 64 bits.
