NOM

pskc_global_done - fonction d'API

SYNTAXE

#include <pskc.h>

void pskc_global_done( void);

ARGUMENTS

void

DESCRIPTION

Cette fonction désinitialise la bibliothèque PSKC, qui avait été initialisée à l'aide de pskc_global_init(). Après avoir appelé cette fonction, aucune autre fonction de la bibliothèque PSKC ne peut être appelée, sauf pour réinitialiser la bibliothèque en utilisant pskc_global_init().
