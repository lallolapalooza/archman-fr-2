pskc_add_keypackage(3) libpskc pskc_add_keypackage(3)

NOM

pskc_add_keypackage - Fonction API

SYNOPIS

#include <pskc.h>

int pskc_add_keypackage(pskc_t * container, pskc_key_t ** key);

ARGUMENTS

pskc_t * container
un handle pskc_t, issu de pskc_init().
pskc_key_t ** key
pointeur vers le handle du paquet de clés pskc_key_t.

DESCRIPTION

Ajoute un nouveau paquet de clés PSKC au container et retourne un handle pskc_key_t.

VALEUR DE RETOUR

PSKC_MALLOC_ERROR en cas d'erreur d'allocation mémoire, ou PSKC_OK en cas de succès.

DEPUIS

2.2.0
