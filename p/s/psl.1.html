NOM

psl - Explorer la Public Suffix List

SYNTAXE

psl [options] <domaines...>

DESCRIPTION

`psl' explore la Public Suffix List. Il prend une liste de domaines sur la ligne de commande, ou s'il n'y a pas de domaines présents sur la ligne de commande, il lit un domaine par ligne depuis l'entrée standard. Il imprime ses résultats sur la sortie standard, chaque ligne contenant un domaine suivi d'un deux-points, suivi des informations pertinentes pour ce domaine.

MODES

Les informations imprimées par domaine changent en fonction du mode sélectionné.
Les modes disponibles sont :

--is-public-suffix
vérifie si les domaines sont des suffixes publics. [défaut]
Données retournées : 1 si le domaine est un suffixe public, 0 sinon.
Cette option peut être combinée avec --no-star-rule. Son utilisation désactivera la 'règle de l'étoile dominante' de la PSL, de sorte que tous les TLDs non explicitement listés dans la PSL retourneront 0 (pas un suffixe public).
--is-cookie-domain-acceptable <domaine-cookie>
vérifie si le domaine-cookie est acceptable pour les domaines.
Données retournées : 1 si le domaine-cookie est acceptable pour le domaine, 0 sinon.
--print-unreg-domain
Données retournées : la partie du suffixe public la plus longue pour chaque domaine.
--print-reg-domain
Données retournées : la partie du suffixe privé la plus courte pour chaque domaine.

INFORMATIONS SUR LA VERSION

`psl' peut également être utilisé pour rapporter des informations sur la version de la bibliothèque et ses données de Public Suffix intégrées :

--version
affiche les informations sur la version de la bibliothèque
--print-info
affiche des informations sur les données intégrées de la PSL

DONNÉES DU SUFFIXE PUBLIC

Par défaut, `psl' utilisera les données les plus récentes disponibles de la Public Suffix.
Vous pouvez également lui indiquer d'utiliser un fichier différent :

--use-latest-data
utilise les données les plus récentes de la PSL disponibles [défaut]
--use-builtin-data
utilise les données intégrées de la PSL
--load-psl-file <nom-fichier>
charge les données de la PSL depuis un fichier
