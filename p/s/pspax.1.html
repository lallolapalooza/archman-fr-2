NOM

pspax - lister les informations ELF/PaX sur les processus en cours d'exécution

SYNTAXE

pspax [options] ELFs

DESCRIPTION

pspax est un utilitaire en espace utilisateur qui analyse le répertoire proc et liste les types ELF, ainsi que leurs drapeaux PaX respectifs et leurs noms de fichiers et attributs. Selon les options de compilation, il peut également afficher l'ensemble des capacités en cours d'exécution du processus.

OPTIONS

-a, --all

Afficher tous les processus

-e, --header

Afficher les marquages GNU_STACK/PT_LOAD

-i, --ipaddr

Afficher les informations ipaddr si pris en charge

-p, --pid PID

Traiter uniquement l'identifiant de processus spécifié

-u, --user UID

Traiter l'utilisateur/uid #

-g, --group GID

Traiter le groupe/gid #

-n, --nx

Afficher uniquement les processus w^x

-w, --wx

Afficher uniquement les processus w|x

-v, --verbose

Être verbeux (peut être utilisé plusieurs fois)

-B, --nobanner

Ne pas afficher l'en-tête

-h, --help

Afficher l'utilisation condensée et quitter

-V, --version

Afficher la version et quitter
