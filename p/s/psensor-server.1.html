NOM

psensor-server - Serveur Web de surveillance de la température et du système

SYNTAXE

psensor-server [OPTION]...

DESCRIPTION

psensor-server est un serveur HTTP pour surveiller les capteurs matériels à distance.

Il fournit un service Web JSON qui peut être utilisé par psensor(1) pour surveiller à distance les capteurs matériels d'un ordinateur.

Il peut fournir des informations sur :
* la température des capteurs de la carte mère et du CPU (en utilisant lm-sensors).
* la température des disques durs (en utilisant hddtemp).
* la vitesse de rotation des ventilateurs (en utilisant lm-sensors).

Il est également possible de se connecter à psensor-server avec un navigateur ; une simple page Web affiche les informations des capteurs et l'utilisation du CPU.

L'URL http://hostname:3131/api/1.0/sensors/[id] renvoie un objet JSON contenant toutes les informations sur un capteur. [id] est l'identifiant unique du capteur.

Voici un exemple d'objet JSON de type 'capteur' :

{ "id": "lmsensor acpitz-virtual-0 temp1",
"name": "temp1",
"type": 257,
"min": 47.800000,
"max": 60.800000,
"measures": [ { "value": 47.800000, "time": 1311374873 },
{ "value": 49.800000, "time": 1311374878 },
{ "value": 49.800000, "time": 1311374883 } ],
"last_measure": { "value": 49.800000, "time": 1311374883 } }

Champs du type 'capteur' :


* id : l'identifiant unique du capteur.
* name : un nom lisible par l'homme pour le capteur (peut ne pas être unique).
* type : le type de capteur. Voir src/lib/psensor.h pour les
différents types.
* min : la valeur minimale du capteur.
* max : la valeur maximale du capteur.
* measures : toutes les mesures du capteur.
* last_measure : la dernière valeur du capteur.
* time : l'heure d'une mesure en nombre de secondes depuis
le 01/01/1970.

L'URL http://hostname:3131/api/1.0/sensors renvoie un tableau JSON contenant tous les objets JSON de type 'capteur'.

psensor-server peut être arrêté en envoyant une requête HTTP avec l'URL 'http://hostname:port/api/1.0/server/stop'.

OPTIONS

-h, --help
affiche cette aide et quitte
-v, --version
affiche les informations de version et quitte
-p,--port=PORT
port du serveur Web
-w,--wdir=DIR
répertoire contenant les pages du serveur Web
-d, --debug=NIVEAU
définit le niveau de débogage, un entier entre 0 et 3
-l, --log-file=CHEMIN
définit le fichier journal sur CHEMIN

--sensor-log-file=CHEMIN définit le fichier journal des capteurs sur CHEMIN

--sensor-log-interval=S définit l'intervalle du journal des capteurs à S (secondes)

FICHIER JOURNAL CAPTEURS

Les capteurs peuvent être enregistrés en utilisant l'option --sensor-log-file.

Il utilise un format texte, chaque ligne se terminant par un caractère NOUVELLE LIGNE.

La première ligne est : I,%D,%V

%D est l'heure de début du journal exprimée en nombre de secondes depuis l'ÉPOQUE.

%V est la version de psensor-server.

Les lignes suivantes donnent la liste ordonnée des capteurs : S,%I,%T

%I est l'identifiant unique du capteur.

%T est la représentation hexadécimale du type de capteur.

Ensuite, les valeurs de tous les capteurs sont écrites : %D,%V...

%D est le nombre de secondes écoulées depuis l'heure de début du journal.

%V... est la liste séparée par une virgule de la valeur actuelle de tous les capteurs. L'ordre est le même que celui de la liste des identifiants de capteurs.

La valeur est exprimée en flottant avec une précision d'un chiffre. Les températures sont en degrés Celsius.

La valeur n'est écrite que si elle a changé.

Exemple : I,1345974927,0.7.0.4 S,lmsensor coretemp-isa-0000 Physical id 0,101 S,lmsensor coretemp-isa-0000 Core 0,101 S,lmsensor coretemp-isa-0000 Core 1,101 0,37.0,37.0,36.0 5,36.0,,36.0

Cinq secondes après le début du journal, la température du deuxième capteur (Core 0) est toujours de 37 °C.

ATTENTION

psensor-server ne fournit aucun moyen de restreindre la connexion au serveur HTTP ; pire encore, aucun effort n'a été fait pour se prémunir contre les attaques HTTP malveillantes. Vous devriez rendre le port psensor-server disponible uniquement à un réseau ou à un ordinateur de confiance en utilisant les outils de sécurité réseau habituels du système (par exemple, iptables(8)).
