NOM

psensor - Application de surveillance de température

SYNTAXE

psensor [OPTION]...

DESCRIPTION

Psensor est une application GTK+ pour surveiller les capteurs matériels, y compris les températures et les vitesses de ventilateur.

OPTIONS

-h, --help
afficher cette aide et quitter
-v, --version
afficher les informations de version et quitter
-u, --url=URL
l'URL du psensor-server, exemple : http://hostname:3131
-n, --new-instance
forcer la création d'une nouvelle instance de l'application Psensor
-d, --debug=NIVEAU
définir le niveau de débogage, un entier entre 0 et 3
