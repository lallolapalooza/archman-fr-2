PSPELL-CONFIG(1) Manuel abrégé de l'utilisateur Aspell PSPELL-CONFIG(1)

NOM

pspell-config - affiche des informations sur une installation de libpspell

SYNTAXE

pspell-config [options]

DESCRIPTION

pspell-config affiche des informations sur l'installation de libpspell, principalement pour être utilisé dans des scripts de compilation. Notez que ce script est fourni pour des raisons de compatibilité descendante avec les programmes qui utilisent pspell. Ne l'utilisez pas car il finira par disparaître.

OPTIONS

--version
affiche les informations de version de pspell installé
--datadir
affiche le répertoire des données
--pkgdatadir
affiche le répertoire des paquets aspell
