NOM

pst2ldif - extraire les contacts d'un fichier .pst de MS Outlook au format .ldif

SYNTAXE

pst2ldif [-V] [-b base-ldap] [-c classe] [-d fichier-debug] [-l ligne-supplementaire] [-o] [-h] nom-fichier-pst

OPTIONS

-V

Affiche la version du programme. Les options suivantes sont alors ignorées.

-b base-ldap

Définit la valeur de base ldap utilisée dans les enregistrements dn. Vous voudrez probablement utiliser quelque chose comme « o=organization, c=US ».

-c classe

Définit les valeurs objectClass pour les éléments de contact. Cette classe doit être définie dans le schéma utilisé par votre serveur LDAP, et au minimum, elle doit contenir les attributs ldap donnés ci-dessous. Cette option peut être spécifiée plusieurs fois pour générer des entrées avec plusieurs classes d'objets.

-d fichier-debug

Spécifie le nom du fichier journal de débogage. Le fichier journal est maintenant un fichier ASCII, au lieu du fichier binaire utilisé dans les versions précédentes.

-l ligne-supplementaire

Spécifie une ligne supplémentaire à ajouter à chaque entrée ldap. Cette option peut être spécifiée plusieurs fois pour ajouter plusieurs lignes à chaque entrée ldap.

-o

Utilise l'ancien schéma ldap, plutôt que le nouveau schéma ldap par défaut. L'ancien schéma génère plusieurs attributs postalAddress pour une seule entrée. Le nouveau schéma génère un seul attribut postalAddress (et homePostalAddress quand disponible) avec des délimiteurs $ comme spécifié dans la RFC4517. L'utilisation de l'ancien schéma génère également deux entrées principales supplémentaires, une pour « dn: base-ldap » et une pour « dn: cn=root, base-ldap ».

-h

Affiche un résumé des options. Les options suivantes sont alors ignorées.

DESCRIPTION

pst2ldif lit les informations de contact d'un fichier .pst de MS Outlook et produit un fichier .ldif qui peut être utilisé pour importer ces contacts dans une base de données LDAP. Les attributs ldap suivants sont générés pour l'ancien schéma ldap :

cn
givenName
sn
personalTitle
company
mail
postalAddress
l
st
postalCode
c
homePhone
telephoneNumber
facsimileTelephoneNumber
mobile
description
Les attributs suivants sont générés pour le nouveau schéma ldap :
cn
givenName
sn
title
o
mail
postalAddress
homePostalAddress
l
st
postalCode
c
homePhone
telephoneNumber
facsimileTelephoneNumber
mobile
description
labeledURI
