NOM

pskctool - Outil Portable Symmetric Key Container (PSKC)

SYNTAXE

pskctool [OPTION]... [FICHIER]...

DESCRIPTION

Manipule les données Portable Symmetric Key Container (PSKC).

Cet outil vous permet d'analyser, d'afficher, de valider, de signer et de vérifier des données PSKC. L'entrée est fournie dans FICHIER ou sur l'entrée standard.

-h, --help
Affiche l'aide et quitte
-V, --version
Affiche la version et quitte
--strict
Échoue en cas d'erreur d'analyse PSKC (par défaut=désactivé)
-d, --debug
Affiche les messages de débogage sur stderr (par défaut=désactivé)
-q, --quiet
Opération silencieuse (par défaut=désactivé)
-v, --verbose
Produire plus de sorties (par défaut=désactivé)

La sélection de l'un des modes suivants est requise :

Mode : info
-i, --info
Analyse et affiche un résumé lisible par l'homme de l'entrée PSKC (par défaut=désactivé)
Mode : validate
-e, --validate
Valide l'entrée PSKC par rapport au schéma XML (par défaut=désactivé)
Mode : sign
Signe numériquement les données PSKC
--sign
Signe l'entrée PSKC (par défaut=désactivé)
--sign-key=FICHIER
Clé privée pour signer
--sign-crt=FICHIER
Certificat X.509 pour signer
Mode : verify
Vérifie les données PSKC signées numériquement
--verify
Vérifie l'entrée PSKC signée (par défaut=désactivé)
--verify-crt=FICHIER
Certificat X.509 de confiance pour la vérification
