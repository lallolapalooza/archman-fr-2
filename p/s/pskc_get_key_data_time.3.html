NOM

pskc_get_key_data_time - fonction d'API

SYNTAXE

#include <pskc.h>

uint32_t pskc_get_key_data_time(pskc_key_t * key, int * present);

ARGUMENTS

pskc_key_t * key
un handle pskc_key_t, issu de pskc_get_keypackage().
int * present
variable de sortie indiquant si des données ont été fournies ou non.

DESCRIPTION

Obtient la valeur de l'heure des données de clé (Key Data Time) du PSKC KeyPackage. Cet élément contient l'heure pour les algorithmes OTP basés sur le temps. (Si des intervalles de temps sont utilisés, cet élément transporte le nombre d'intervalles de temps écoulés depuis un point de départ spécifique, il dépend normalement de l'algorithme).

Si present n'est pas NULL, il sera à 0 si le champ n'est pas présent ou à 1 s'il était présent.

RETOURNE

un entier contenant le contenu.
