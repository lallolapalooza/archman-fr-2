NOM

pskc_validate - Fonction API

SYNTAXE

#include <pskc.h>

int pskc_validate(pskc_t * container, int * isvalid);

ARGUMENTS

pskc_t * container
un handle pskc_t, issu de pskc_init().
int * isvalid
variable de sortie contenant le résultat de la validation, non-0 pour valide.

DESCRIPTION

Cette fonction valide le handle PSKC container selon le schéma XML PSKC.

RETOUR

En cas de succès, PSKC_OK (zéro) est retourné, ou un code d'erreur.
