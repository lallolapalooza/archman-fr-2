PSCAP:(8) Utilitaires d'administration système PSCAP:(8)

NOM

pscap - un programme pour voir les capacités

SYNTAXE

pscap [ -a | -p pid ]

DESCRIPTION

pscap est un programme qui affiche un rapport sur les capacités des processus. Si l'application a des capacités, elle sera dans le rapport, à l'exception de init. En donnant l'option de ligne de commande -a, init sera également inclus. En donnant un pid avec l'option de ligne de commande -p, seul le processus spécifié par le pid est rapporté. Si un processus n'est pas dans le rapport, il a abandonné toutes ses capacités. Si le processus a des capacités partielles, il est examiné plus en détail pour voir s'il a un ensemble de bornes ouvertes. Si cela s'avère vrai, un symbole '+' est ajouté. Si le processus a des capacités ambiantes, un symbole '@' est ajouté.

Le nom de la commande dans la sortie peut être suivi d'un astérisque (*). Cette marque indique les processus qui s'exécutent dans des espaces de noms d'utilisateurs enfants (par rapport à l'espace de noms d'utilisateurs de pscap lui-même).

VOIR AUSSI

netcap(8), filecap(8), capabilities(7), ps(8).
