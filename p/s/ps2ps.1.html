PS2PS(1) Outils Ghostscript PS2PS(1)

NOM

ps2ps, eps2eps - "Distilleur" PostScript de Ghostscript

SYNTAXE

ps2ps [ options ] entrée sortie.ps
eps2eps [ options ] entrée sortie.eps

DESCRIPTION

ps2ps utilise gs(1) pour convertir le fichier PostScript(tm) ou PDF(tm) "entrée" en un PostScript plus simple, normalisé et (généralement) plus rapide dans "sortie.ps". La sortie est du PostScript conforme au niveau 2 DSC 3.0.

eps2eps effectue une optimisation équivalente, créant des fichiers Encapsulated PostScript (EPS). NB : malgré le nom, l'entrée n'a pas besoin d'être un fichier EPS ; les fichiers PostScript ou même PDF sont également acceptables.

Les deux acceptent toutes les options générales de ligne de commande de Ghostscript, ainsi que les options spécifiques aux périphériques ps2write et eps2write.

FICHIERS

Exécutez "gs -h" pour trouver l'emplacement de la documentation Ghostscript sur votre système, à partir de laquelle vous pourrez obtenir plus de détails.

VOIR AUSSI

ps2pdf(1), ps2ascii(1), ps2epsi(1)
