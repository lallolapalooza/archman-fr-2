NOM

pskc_init - Fonction API

SYNOPSIS

#include <pskc.h>

int pskc_init(pskc_t ** container);

ARGUMENTS

pskc_t ** container
pointeur vers un descripteur pskc_t à initialiser.

DESCRIPTION

Cette fonction initialise le descripteur de conteneur container PSKC. La mémoire allouée peut être libérée en appelant pskc_done().

RETOURNE

En cas de succès, PSKC_OK (zéro) est retourné, en cas d'erreurs d'allocation mémoire PSKC_MALLOC_ERROR est retourné.
