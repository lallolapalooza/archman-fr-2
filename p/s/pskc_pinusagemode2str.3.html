pskc_pinusagemode2str(3) libpskc pskc_pinusagemode2str(3)

NOM

pskc_pinusagemode2str - Fonction de l'API

SYNTAXE

#include <pskc.h>

const char * pskc_pinusagemode2str(pskc_pinusagemode pinusagemode);

ARGUMENTS

pskc_pinusagemode pinusagemode
un type d'énumération pskc_pinusagemode

DESCRIPTION

Convertit pskc_pinusagemode en une chaîne de caractères. Par exemple, pskc_pinusagemode2str(PSKC_PINUSAGEMODE_LOCAL) retournera "Local". La chaîne retournée ne doit pas être désallouée.

RETOURNE

Chaîne de caractères correspondant à pskc_pinusagemode.
