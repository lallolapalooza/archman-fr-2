NOM

pskc_get_device_manufacturer - fonction d'API

SYNTAXE

#include <pskc.h>

const char * pskc_get_device_manufacturer(pskc_key_t * key);

ARGUMENTS

pskc_key_t * key
un descripteur pskc_key_t, provenant de pskc_get_keypackage().

DESCRIPTION

Récupère la valeur du fabricant (Manufacturer) des informations de l'appareil (DeviceInfo) du PSKC KeyPackage. Cet élément indique le fabricant de l'appareil.

VALEUR DE RETOUR

une chaîne de caractères constante (ne doit pas être libérée) contenant le contenu, ou NULL si non définie.

SIGNALEMENT DE BOGUES
