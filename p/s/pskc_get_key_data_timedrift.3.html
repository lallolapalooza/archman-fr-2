NOM

pskc_get_key_data_timedrift - fonction API

SYNTAXE

#include <pskc.h>

uint32_t pskc_get_key_data_timedrift(pskc_key_t * key, int * present);

ARGUMENTS

pskc_key_t * key
un handle pskc_key_t, obtenu via pskc_get_keypackage().
int * present
variable de sortie indiquant si des données ont été fournies ou non.

DESCRIPTION

Obtient la valeur PSKC KeyPackage Key Data TimeDrift. Cet élément contient la dérive de l'horloge de l'appareil pour les algorithmes OTP basés sur le temps. La valeur entière (dérive positive ou négative) qui indique le nombre d'intervalles de temps que le serveur de validation a établi comme ayant dérivé l'horloge de l'appareil après la dernière authentification réussie. Ainsi, par exemple, si la dernière authentification réussie a établi une valeur de temps de l'appareil de 8 intervalles à partir d'une date de début spécifique, mais que le serveur de validation détermine que la valeur de temps est à 9 intervalles, le serveur DEVRAIT enregistrer la dérive comme -1.

Si present n'est pas NUL, il sera 0 si le champ n'est pas présent ou 1 s'il était présent.

RETOURNE

un entier contenant le contenu.
