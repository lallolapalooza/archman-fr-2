NOM

ps2ascii - Traducteur Ghostscript de PostScript ou PDF vers texte

SYNTAXE

ps2ascii [ entrée.ps [ sortie.txt ] ]
ps2ascii entrée.pdf [ sortie.txt ]

DESCRIPTION

ps2ascii utilise gs(1) pour extraire le texte des fichiers PostScript(tm) ou Portable Document Format (PDF) d'Adobe. Si aucun fichier n'est spécifié sur la ligne de commande, gs lit depuis l'entrée standard. Si aucun fichier de sortie n'est spécifié, le texte ASCII est écrit sur la sortie standard.

L'ancien programme ps2ascii.ps était obsolète et a été supprimé il y a quelques années ; les scripts utilisent maintenant le périphérique txtwrite pour extraire le texte de l'entrée. Cela donne généralement de meilleurs résultats que l'ancien programme PostScript et peut extraire de l'Unicode, pas seulement de l'ASCII. Cependant, il ne prend plus en charge la fonctionnalité COMPLEX.

VOIR AUSSI

Une documentation plus approfondie sur le périphérique txtwrite est disponible à https://ghostscript.readthedocs.io/en/latest/Devices.html#text-output

VERSION

Ce document a été révisé pour la dernière fois pour la version Ghostscript 10.04.0.
