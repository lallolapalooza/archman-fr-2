psktool(1) Commandes utilisateur psktool(1)

NOM

psktool - Outil PSK de GnuTLS

SYNTAXE

psktool [-flags] [-flag [valeur]] [--option-name[[=| ]valeur]]

Tous les arguments doivent être des options.

DESCRIPTION

Programme qui génère des clés aléatoires pour une utilisation avec TLS-PSK. Les clés sont stockées au format hexadécimal dans un fichier de clés.

OPTIONS

-d num, --debug=num

Active le débogage. Cette option prend un nombre entier comme argument. La valeur de num est contrainte à être : 
dans l'intervalle de 0 à 9999

Spécifie le niveau de débogage.

-s num, --keysize=num

Spécifie la taille de la clé en octets (par défaut 32 octets ou 256 bits). Cette option prend un nombre entier comme argument. La valeur de num est contrainte à être : 
dans l'intervalle de 0 à 512

-u str, --username=str

Spécifie le nom d'utilisateur à utiliser.
-p str, --pskfile=str

Spécifie un fichier de clé pré-partagée.

Cette option spécifiera le fichier de clé pré-partagée pour stocker les clés générées.

--passwd

Ceci est un alias pour l'option --pskfile.

NOTE : CETTE OPTION EST DÉPRÉCIÉE

-v arg, --version=arg

Affiche la version du programme et quitte. Le mode par défaut est `v', une version simple. Le mode `c' affichera les informations de copyright et `n' affichera l'avis de copyright complet.
-h, --help

Affiche les informations d'utilisation et quitte.
-!, --more-help

Passe les informations d'utilisation étendues à travers un pager.

EXEMPLES

Pour ajouter un utilisateur 'psk_identity' dans keys.psk pour une utilisation avec GnuTLS, exécutez : 

$ ./psktool -u psk_identity -p keys.psk
Génération d'une clé aléatoire pour l'utilisateur 'psk_identity'
Clé stockée dans keys.psk
$ cat keys.psk
psk_identity:88f3824b3e5659f52d00e959bacab954b6540344
$

Cette commande créera keys.psk s'il n'existe pas et ajoutera l'utilisateur 'psk_identity'.

STATUT DE SORTIE

L'une des valeurs de sortie suivantes sera retournée :

0 (EXIT_SUCCESS)

Exécution réussie du programme.
1 (EXIT_FAILURE)

L'opération a échoué ou la syntaxe de la commande était invalide.
