PS2PDF(1) Ghostscript PS2PDF(1)

NOM

ps2pdf - Convertir PostScript en PDF en utilisant ghostscript
ps2pdf12 - Convertir PostScript en PDF 1.2 (compatible Acrobat 3 et versions ultérieures) en utilisant ghostscript
ps2pdf13 - Convertir PostScript en PDF 1.3 (compatible Acrobat 4 et versions ultérieures) en utilisant ghostscript
ps2pdf14 - Convertir PostScript en PDF 1.4 (compatible Acrobat 5 et versions ultérieures) en utilisant ghostscript

SYNTAXE

ps2pdf [options...] {input.[e]ps|-} [output.pdf|-]
ps2pdf12 [options...] {input.[e]ps|-} [output.pdf|-]
ps2pdf13 [options...] {input.[e]ps|-} [output.pdf|-]
ps2pdf14 [options...] {input.[e]ps|-} [output.pdf|-]

DESCRIPTION

Les scripts ps2pdf sont des équivalents fonctionnels (mais pas en termes d'interface utilisateur) du produit Acrobat(TM) Distiller(TM) d'Adobe : ils convertissent des fichiers PostScript en fichiers Portable Document Format (PDF).

Si le nom de fichier de sortie n'est pas spécifié, la sortie est placée dans un fichier du même nom avec une extension '.pdf' dans le répertoire de travail courant. Le nom du fichier d'entrée ou de sortie peut être '-' pour demander la lecture depuis stdin ou l'écriture vers stdout, respectivement, lorsqu'ils sont utilisés comme filtres.

Les trois scripts diffèrent comme suit :

–
ps2pdf12 produira toujours une sortie PDF 1.2 (compatible Acrobat 3 et versions ultérieures).
–
ps2pdf13 produira toujours une sortie PDF 1.3 (compatible Acrobat 4 et versions ultérieures).
–
ps2pdf14 produira toujours une sortie PDF 1.4 (compatible Acrobat 5 et versions ultérieures).
–
ps2pdf produit actuellement une sortie PDF 1.4. Cependant, cela peut changer à l'avenir. Si le niveau de compatibilité de la sortie vous importe, utilisez ps2pdf12, ps2pdf13 ou ps2pdf14, ou utilisez l'option -dCompatibilityLevel=1.x dans la ligne de commande.

Il existe certaines limitations dans la conversion de ps2pdf. Voir la documentation HTML pour plus d'informations. Un grand nombre de paramètres Adobe Distiller(TM) qui peuvent être utilisés pour contrôler la conversion y sont également documentés, y compris les instructions pour générer des documents PDF/X et PDF/A.

OPTIONS

Les scripts ps2pdf utilisent les mêmes options que gs(1).

EXEMPLES

Conversion d'un figure.ps en figure.pdf :

ps2pdf figure.ps

Une conversion avec plus de détails :

ps2pdf -dPDFSETTINGS=/prepress figure.ps proof.pdf

Conversion dans le cadre d'un pipe :

make_report.pl -t ps | ps2pdf -dCompatibilityLevel=1.3 - - | lpr
