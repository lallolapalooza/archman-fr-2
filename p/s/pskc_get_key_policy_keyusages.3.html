NOM

pskc_get_key_policy_keyusages - Fonction API

SYNTAXE

#include <pskc.h>

int pskc_get_key_policy_keyusages(pskc_key_t * key, int * present);

ARGUMENTS

pskc_key_t * key
un handle pskc_key_t, obtenu à partir de pskc_get_keypackage().
int * present
variable de sortie indiquant si des données ont été fournies ou non.

DESCRIPTION

Obtient les valeurs de la politique de clé des usages de clé du paquet de clé PSKC. L'élément impose des contraintes sur l'utilisation prévue de la clé. Le destinataire du document PSKC DOIT faire respecter l'utilisation de la clé.

Si present n'est pas NULL, il sera 0 si le champ est absent ou 1 s'il était présent.

RETOURNE

un entier contenant un ensemble de valeurs pskc_keyusage ORées ensemble.
