NOM

psftp - client interactif SFTP (protocole de transfert de fichiers sécurisé)

SYNTAXE

psftp [options] [utilisateur@]hote

DESCRIPTION

psftp est un client interactif basé sur du texte pour le protocole SFTP (protocole de transfert de fichiers sécurisé) basé sur SSH.

OPTIONS

Les options en ligne de commande prises en charge par psftp sont les suivantes :

-V
Affiche les informations de version et quitte.
-pgpfp
Affiche les empreintes digitales des clés maîtres PGP de PuTTY et quitte, afin d'aider à vérifier les nouveaux fichiers publiés par l'équipe PuTTY.
-b fichier_lot
Utilise le fichier lot spécifié.
-bc
Affiche les commandes du fichier lot.
-be
N'arrête pas le traitement du fichier lot en cas d'erreurs.
-v
Affiche les messages détaillés.
-load session
Charge les paramètres à partir de la session sauvegardée.
-P port
Se connecte au port port.
-proxycmd commande
Au lieu d'établir une connexion TCP, utilise commande comme proxy ; le trafic réseau sera redirigé vers l'entrée et la sortie standard de commande. commande doit être un seul mot, il faudra donc probablement le mettre entre guillemets par le shell.

Les chaînes spéciales %host et %port dans commande seront remplacées par le nom d'hôte et le numéro de port auxquels vous souhaitez vous connecter ; pour obtenir un signe % littéral, entrez %%.

Les échappements de barre oblique inverse sont également pris en charge, tels que les séquences comme \n étant remplacées par un saut de ligne littéral ; pour obtenir une barre oblique inverse littérale, entrez \\. (Un échappement supplémentaire peut être requis par le shell.)

(Consultez le manuel principal de PuTTY pour connaître tous les détails sur les jetons pris en charge délimités par % et par barre oblique inverse, bien que la plupart d'entre eux ne soient probablement pas très utiles dans ce contexte.)

-l utilisateur
Définit le nom d'utilisateur distant sur utilisateur.
-batch
Désactive les invites interactives.
-no-sanitise-stderr
Par défaut, PSFTP filtrera les caractères de contrôle du canal d'erreur standard du serveur, afin d'éviter que des processus distants n'envoient des séquences d'échappement confuses. Cette option force le canal d'erreur standard à ne pas être filtré.
-pwfile nomfichier
Ouvre le fichier spécifié et utilise la première ligne de texte lue à partir de celui-ci comme mot de passe distant.
-pw motdepasse
Définit le mot de passe distant sur motdepasse. ATTENTION : cela rendra probablement le mot de passe visible aux autres utilisateurs de la machine locale (via des commandes telles que `ps' ou `w'). Utilisez plutôt -pwfile.
-1
Force l'utilisation du protocole SSH version 1.
-2
Force l'utilisation du protocole SSH version 2.
-ssh-connection
Force l'utilisation du protocole `bare ssh-connection'. Ceci est seulement susceptible d'être utile lors de la connexion à un serveur psusan(1), très probablement avec un chemin absolu vers un socket de domaine Unix à la place de hote.
-ssh
Force l'utilisation du protocole SSH. (Ce n'est généralement pas nécessaire ; c'est seulement susceptible d'être utile si vous avez besoin de remplacer une autre configuration du protocole `bare ssh-connection'.)
-4, -6
Force l'utilisation d'IPv4 ou d'IPv6 pour les connexions réseau.
-C
Active la compression SSH.
-i fichierclé
Fichier de clé privée pour l'authentification utilisateur. Pour les clés SSH-2, ce fichier clé doit être au format PPK de PuTTY, pas au format OpenSSH ou à tout autre format.

Si vous utilisez un agent d'authentification, vous pouvez également spécifier une clé publique ici (au format RFC 4716 ou OpenSSH), pour identifier quelle clé de l'agent utiliser.

-noagent
N'essaie pas d'utiliser un agent d'authentification.
-agent
Permet l'utilisation d'un agent d'authentification. (Cette option n'est nécessaire que pour remplacer un paramètre dans une session sauvegardée.)
-no-trivial-auth
Se déconnecte de tout serveur SSH qui accepte l'authentification sans jamais avoir demandé de mot de passe, de signature ou de jeton. (Vous pourriez vouloir activer cela pour un serveur qui est censé vous demander une authentification, par exemple pour vous assurer de ne pas taper accidentellement le mot de passe de votre fichier clé dans un serveur compromis se faisant passer pour l'invite de mot de passe de PSFTP.)
-hostkey clé
Spécifie une clé publique d'hôte acceptable. Cette option peut être spécifiée plusieurs fois ; chaque clé peut être soit une empreinte digitale (SHA256:AbCdE..., 99:aa:bb:..., etc.) soit un blob encodé en base64 au format d'une ligne d'OpenSSH.

La spécification de cette option remplace la gestion automatisée des clés d'hôte ; uniquement les clés spécifiées sur la ligne de commande seront acceptées (sauf si une session sauvegardée remplace également les clés d'hôte, auquel cas celles-ci seront ajoutées), et le cache des clés d'hôte ne sera pas écrit.

-sshlog fichierjournal
-sshrawlog fichierjournal
Ces options font que psftp enregistre les détails du protocole dans un fichier. (Certains de ces détails peuvent être sensibles, bien que par défaut un effort soit fait pour supprimer les mots de passe évidents.)

-sshlog enregistre les paquets SSH décodés et d'autres événements (ceux que -v imprimerait). -sshrawlog enregistre en plus les données brutes des paquets chiffrés.

-logoverwrite
Si PSFTP est configuré pour écrire dans un fichier journal qui existe déjà, supprimez le fichier existant.
-logappend
Si PSFTP est configuré pour écrire dans un fichier journal qui existe déjà, ajoutez les nouvelles données du journal au fichier existant.

COMMANDES

Pour obtenir une liste des commandes disponibles dans psftp, tapez help à l'invite psftp>.
