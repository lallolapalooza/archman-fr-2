NOM

pskc_sign_x509 - fonction API

SYNTAXE

#include <pskc.h>

int pskc_sign_x509(pskc_t * container, const char * key_file, const char * cert_file);

ARGUMENTS

pskc_t * container
un descripteur pskc_t, obtenu à partir de pskc_init().
const char * key_file
nom de fichier contenant la clé privée.
const char * cert_file
nom de fichier contenant le certificat X.509 correspondant.

DESCRIPTION

Signe les données PSKC en utilisant un certificat X.509 et une clé privée.

RETOUR

En cas de succès, PSKC_OK (zéro) est retourné, sinon un code d'erreur.
