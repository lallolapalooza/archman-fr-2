NOM

pskc_get_id - Fonction API

SYNTAXE

#include <pskc.h>

const char * pskc_get_id(pskc_t * container);

ARGUMENTS

pskc_t * container
un handle pskc_t, issu de pskc_init().

DESCRIPTION

Obtenir l'attribut d'identifiant du conteneur de clé PSKC.

RETOUR

une chaîne constante (ne doit pas être libérée) contenant le contenu, ou NULL si non défini.

SIGNALEMENT DE BOGUES
