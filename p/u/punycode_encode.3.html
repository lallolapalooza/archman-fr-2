NOM

punycode_encode - Fonction d'API

SYNTAXE

#include <punycode.h>

int punycode_encode(size_t input_length, const punycode_uint [] input, const unsigned char [] case_flags, size_t * output_length, char [] output);

ARGUMENTS

size_t input_length
Le nombre de points de code dans le tableau input et le nombre d'indicateurs dans le tableau case_flags.
const punycode_uint [] input
Un tableau de points de code. Ils sont considérés comme des points de code Unicode, mais ce n'est pas strictement requis. Le tableau contient des points de code, pas des unités de code. UTF-16 utilise les unités de code D800 à DFFF pour faire référence aux points de code 10000..10FFFF. Les points de code D800..DFFF n'apparaissent dans aucune chaîne Unicode valide. Les points de code qui peuvent apparaître dans les chaînes Unicode (0..D7FF et E000..10FFFF) sont également appelés valeurs scalaires Unicode.
const unsigned char [] case_flags
Un pointeur NULL ou un tableau de valeurs booléennes parallèle au tableau input. Une valeur non nulle (vrai, signalée) suggère que le caractère Unicode correspondant doit être forcé en majuscules après décodage (si possible), et une valeur nulle (faux, non signalée) suggère qu'il doit être forcé en minuscules (si possible). Les points de code ASCII (0..7F) sont encodés littéralement, sauf que les lettres ASCII sont forcées en majuscules ou minuscules selon les indicateurs de casse correspondants. Si case_flags est un pointeur NULL, les lettres ASCII sont laissées telles quelles, et les autres points de code sont traités comme non signalés.
size_t * output_length
L'appelant indique le nombre maximum de points de code ASCII qu'il peut recevoir. En cas de succès, il contiendra le nombre de points de code ASCII effectivement produits.
char [] output
Un tableau de points de code ASCII. Il n'est *pas* terminé par un zéro ; il contiendra des zéros si et seulement si l'input contient des zéros. (Bien sûr, l'appelant peut laisser de la place pour un terminateur et en ajouter un si nécessaire.)

DESCRIPTION

Convertit une séquence de points de code (supposés être des points de code Unicode) en Punycode.

Valeur de retour : La valeur de retour peut être l'une des valeurs Punycode_status définies ci-dessus, à l'exception de PUNYCODE_BAD_INPUT. Si la valeur n'est pas PUNYCODE_SUCCESS, alors output_size et output peuvent contenir des données incohérentes.
