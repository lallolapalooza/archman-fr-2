pulse-client.conf(5) Manuel des formats de fichiers pulse-client.conf(5)

NOM

pulse-client.conf - Fichier de configuration du client PulseAudio

SYNTAXE

~/.config/pulse/client.conf

~/.config/pulse/client.conf.d/*.conf

/etc/pulse/client.conf

/etc/pulse/client.conf.d/*.conf

DESCRIPTION

La bibliothèque client PulseAudio lit les directives de configuration à partir d'un fichier de configuration lors du démarrage. Si le fichier spécifique à l'utilisateur ~/.config/pulse/client.conf existe, il est utilisé, sinon le fichier de configuration système /etc/pulse/client.conf est utilisé. En plus de ces fichiers principaux, des directives de configuration peuvent également être placées dans des fichiers sous les répertoires ~/.config/pulse/client.conf.d/ et /etc/pulse/client.conf.d/. Ces fichiers doivent avoir l'extension de fichier .conf, mais sinon les noms de fichiers peuvent être choisis librement. Les fichiers sous client.conf.d sont traités dans l'ordre alphabétique. Si la même option est définie dans plusieurs fichiers, le dernier fichier à définir une option remplace les fichiers précédents. Le fichier principal client.conf est traité en premier, donc les options définies dans les fichiers sous client.conf.d remplacent le fichier principal.

Le fichier de configuration est une simple collection de déclarations de variables. Si l'analyseur de fichier de configuration rencontre ; ou #, il ignore le reste de la ligne jusqu'à sa fin.

Pour les paramètres qui prennent un argument booléen, les valeurs true, yes, on et 1 sont équivalentes, respectivement false, no, off, 0.

DIRECTIVES

default-sink= Le sink par défaut auquel se connecter. S'il est spécifié, il remplace le réglage du démon. Cependant, la variable d'environnement $PULSE_SINK a la priorité.
default-source= La source par défaut à laquelle se connecter. S'il est spécifié, il remplace le réglage du démon. Cependant, la variable d'environnement $PULSE_SOURCE a la priorité.
default-server= Le serveur par défaut auquel se connecter. La variable d'environnement $PULSE_SERVER a la priorité.
autospawn= Lance automatiquement un démon PulseAudio si nécessaire. Prend une valeur booléenne, par défaut à yes. Notez que le réglage sur « no » ne désactive pas le service systemd. L'option autospawn est uniquement destinée à être utilisée sur des systèmes sans systemd. Si vous utilisez systemd pour démarrer PulseAudio, utilisez « systemctl --user stop pulseaudio.service pulseaudio.socket » pour arrêter le démon temporairement, ou « systemctl --user mask pulseaudio.service pulseaudio.socket » pour désactiver définitivement les unités (la commande « disable » de systemctl ne fonctionnera probablement pas, car l'unité pulseaudio.socket est souvent installée dans /usr/lib/systemd/user/sockets.target.wants/, ce qui rend impossible la désactivation de l'unité avec la commande « disable »).
daemon-binary= Chemin d'accès au démon PulseAudio à exécuter lors de l'autolancement. Par défaut, un chemin configuré lors de la compilation.
extra-arguments= Arguments supplémentaires à passer au démon PulseAudio lors de l'autolancement. Par défaut, --log-target=syslog
cookie-file= Spécifie le chemin d'accès au cookie d'authentification PulseAudio. Par défaut, ~/.config/pulse/cookie.
enable-shm= Active le transfert de données via la mémoire partagée POSIX ou memfd. Prend un argument booléen, par défaut à yes. S'il est défini sur no, la communication avec le serveur se fera exclusivement par copie de données sur les sockets.
enable-memfd=. Active le transfert de données via la mémoire partagée memfd. Prend un argument booléen, par défaut à yes.
shm-size-bytes= Définit la taille du segment de mémoire partagée pour les clients, en octets. S'il est laissé non spécifié ou réglé sur 0, il utilisera une valeur par défaut spécifique au système, généralement 64 MiB. Veuillez noter qu'il n'est généralement pas nécessaire de modifier cette valeur, à moins que vous n'utilisiez un noyau de système d'exploitation qui ne fait pas d'oversubscription de mémoire.
auto-connect-localhost= Tente automatiquement de se connecter à localhost via IP. L'activation de cette option représente un trou de sécurité potentiel car les connexions ne sont authentifiées que dans un sens et un serveur malveillant pourrait donc tromper un client pour lui envoyer ses données privées (par exemple, appel VoIP). Cette option était activée par défaut dans les versions 0.9.21 et antérieures de PulseAudio. Par défaut, à no.
auto-connect-display= Tente automatiquement de se connecter à l'hôte spécifié par la variable $DISPLAY de X11. Les mêmes problèmes de sécurité s'appliquent que pour auto-connect-localhost=. Par défaut, à no.
