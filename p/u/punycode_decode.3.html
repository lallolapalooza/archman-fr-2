punycode_decode(3)

Paquet: libidn

Licences: GPL3, LGPL

punycode_decode(3) libidn punycode_decode(3)

NOM

punycode_decode - Fonction d'API

SYNTAXE

#include <punycode.h>

int punycode_decode(size_t input_length, const char [] input, size_t * output_length, punycode_uint [] output, unsigned char [] case_flags);

ARGUMENTS

size_t input_length
Le nombre de points de code ASCII dans le tableau input.
const char [] input
Un tableau de points de code ASCII (0..7F).
size_t * output_length
L'appelant indique le nombre maximum de points de code qu'il peut recevoir dans le tableau output (ce qui est également le nombre maximum d'indicateurs qu'il peut recevoir dans le tableau
case_flags , si case_flags n'est pas un pointeur NULL ). En cas de succès, il contiendra le nombre de points de code réellement produits (ce qui est également le nombre d'indicateurs réellement produits, si case_flags n'est pas un pointeur nul). Le décodeur n'aura jamais besoin de produire plus de points de code que le nombre de points de code ASCII en entrée, en raison de la façon dont l'encodage est défini. Le nombre de points de code produits ne peut pas dépasser la valeur maximale possible d'un punycode_uint, même si
output_length fourni est supérieur à celle-ci.
punycode_uint [] output
Un tableau de points de code comme l'argument d'entrée de punycode_encode() (voir ci-dessus).
unsigned char [] case_flags
Un pointeur NULL (si les indicateurs ne sont pas nécessaires à l'appelant) ou un tableau de valeurs booléennes parallèle au tableau output . Une valeur non nulle (vrai, marqué) suggère que le caractère Unicode correspondant doit être forcé en majuscules par l'appelant (si possible), et zéro (faux, non marqué) suggère qu'il doit être forcé en minuscules (si possible). Les points de code ASCII (0..7F) sont produits déjà dans la casse appropriée, mais leurs indicateurs seront définis de manière appropriée afin que l'application des indicateurs soit harmless.

DESCRIPTION

Convertit le Punycode en une séquence de points de code (présumés être des points de code Unicode).

Valeur de retour : La valeur de retour peut être n'importe laquelle des valeurs Punycode_status définies ci-dessus. Si ce n'est pas
PUNYCODE_SUCCESS , alors output_length , output , et case_flags peuvent contenir des données incorrectes.
