pump(1) Manuel des commandes générales pump(1)

NOM

pump - accélère la compilation à distance avec distcc

SYNTAXE

pump COMMANDE-DE-COMPILATION [ARGUMENTS] ...

eval ` pump --startup `; COMMANDE-DE-COMPILATION [ARGUMENTS] ... ; pump --shutdown

DESCRIPTION

pump fait partie de distcc. Il est utilisé pour le mode pompe de distcc. Le mode pompe de Distcc accélère la compilation à distance avec distcc en distribuant également le prétraitement aux serveurs.

Pour une description détaillée du mode pompe, y compris notamment quelques restrictions importantes, consultez la page de manuel distcc(1), en particulier la section COMMENT FONCTIONNE LE MODE POMPE et la section RESTRICTIONS SUR LE MODE POMPE.

L'utilisation la plus simple est la forme

pump COMMANDE [ARGUMENT] ...
Ceci lancera un serveur d'inclusion pour le mode "pompe" de distcc ; exécutera éventuellement lsdistcc pour calculer la liste des hôtes distcc ; définira certaines variables d'environnement auxiliaires ; modifiera PATH pour utiliser le client distcc dans le même répertoire que le script "pump" ; exécutera COMMANDE avec le(s) ARGUMENT(s) spécifié(s) ; et enfin arrêtera le serveur d'inclusion. La COMMANDE est typiquement une commande de compilation parallèle, telle que "make -j80", qui effectuera de nombreuses invocations concurrentes de distcc.

Une autre manière d'invoquer pump est d'invoquer explicitement "pump --startup" pour démarrer le serveur d'inclusion et "pump --shutdown" pour l'arrêter. La commande "pump --startup" démarrera le serveur d'inclusion et affichera des paramètres de variables d'environnement. Ces variables d'environnement sont utilisées pour la communication entre le client distcc en mode pompe et le serveur d'inclusion, ainsi qu'entre "pump --startup" et "pump --shutdown". L'appelant de "pump --startup" est responsable de la définition de ces variables d'environnement avant d'invoquer "distcc" ou "pump --shutdown".

Par exemple :

eval `pump --startup`
make -j80
pump --shutdown

Notez que le mode pompe de distcc suppose que les fichiers sources ne seront pas modifiés pendant la durée de vie du serveur d'inclusion. Par conséquent, modifier les fichiers sources pendant une compilation peut entraîner des résultats incohérents.

INVOCATION DE LSDISTCC

Lorsqu'il est invoqué soit sous la forme simple " pump COMMANDE [ARGUMENT] ... ", soit sous la forme " pump --startup ", le script pump invoquera lsdistcc chaque fois que DISTCC_POTENTIAL_HOSTS sera défini et que DISTCC_HOSTS ne le sera pas. Il transmettra la valeur de DISTCC_POTENTIAL_HOSTS à lsdistcc et utilisera la sortie de lsdistcc pour définir DISTCC_HOSTS.

OPTIONS

--help
Affiche un résumé des instructions.
--startup
Démarre un serveur d'inclusion et affiche les paramètres des variables d'environnement nécessaires pour que distcc(1) ou pump --shutdown y accèdent.
--shutdown
Arrête un serveur d'inclusion démarré par pump --startup.

VARIABLES D'ENVIRONNEMENT

Les variables d'environnement suivantes sont toutes optionnelles.

DISTCC_LOCATION
L'emplacement du répertoire bin de distcc, qui est normalement déduit du nom du répertoire résolu par lien symbolique de argv[0]. Si cet emplacement est en fait le répertoire bin à l'intérieur d'une installation (ce qui sera le cas lorsque le script pump de l'installation s'exécute), alors les exécutables Python et distcc lui-même seront récupérés à partir du répertoire parent de l'emplacement.
DISTCC_MAX_DISCREPANCY
voir la page de manuel distcc(1).
DISTCC_POTENTIAL_HOSTS
Les serveurs distcc qui seront interrogés par lsdistcc afin de produire une valeur pour DISTCC_HOSTS. Cette valeur peut être non définie ou nulle. Dans de tels cas, lsdistcc ne sera pas invoqué, et distcc utilisera DISTCC_HOSTS ou le fichier de configuration des hôtes distcc, comme décrit dans la section "Spécifications des hôtes" de distcc(1).
DISTCC_HOSTS
Cette variable est transmise à distcc mais uniquement si DISTCC_POTENTIAL_HOSTS n'est pas défini.
LSDISTCC_ARGS
Arguments supplémentaires à passer à lsdistcc. Voir lsdistcc --help pour plus de détails.
INCLUDE_SERVER_ARGS
Arguments supplémentaires à passer au serveur d'inclusion.
PYTHONOPTIMIZE
Si défini sur "", alors l'optimisation Python est désactivée.

EXEMPLE

pump make -j20
