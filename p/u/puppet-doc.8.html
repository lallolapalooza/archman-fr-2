NOM

puppet-doc - Génère des références Puppet

SYNOPSIS

Génère une référence pour tous les types Puppet. Principalement destiné à un usage interne de Puppet Inc. (Obsolète)

UTILISATION

puppet doc [-h|--help] [-l|--list] [-r|--reference nom-référence]

DESCRIPTION

Cette commande obsolète génère un document Markdown vers la sortie standard décrivant tous les types Puppet installés ou tous les arguments autorisés pour les exécutables Puppet. Elle est principalement destinée à un usage interne et est utilisée pour générer le document de référence disponible sur le site web de Puppet Inc.

Pour la documentation des modules Puppet (et tous les autres cas d'utilisation), cette commande a été remplacée par le module « puppet-strings » ; voir https://github.com/puppetlabs/puppetlabs-strings pour plus d'informations.

Cette commande (puppet-doc) sera supprimée une fois que le pipeline de traitement de la documentation interne de puppetlabs sera entièrement basé sur puppet-strings.

OPTIONS

--help
Imprime ce message d'aide
--reference
Crée une référence particulière. Obtenez une liste de références en exécutant « puppet doc --list ».

EXEMPLE

$ puppet doc -r type > /tmp/type_reference.markdown
