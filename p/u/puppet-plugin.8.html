NOM

puppet-plugin - Interagir avec le système de plugins Puppet.

SYNTAXE

puppet plugin action

DESCRIPTION

Cette sous-commande fournit un accès réseau au magasin de plugins du maître Puppet.

Le maître Puppet sert du code Ruby collecté à partir des répertoires lib de ses modules. Ces plugins peuvent être utilisés sur les nœuds agents pour étendre Facter et implémenter des types et des fournisseurs personnalisés. Les plugins sont normalement téléchargés par l'agent Puppet au cours d'une exécution.

OPTIONS

Notez que tout paramètre valide dans le fichier de configuration est également un argument long valide, bien qu'il puisse être pertinent ou non pour l'action en cours. Par exemple, server et run_mode sont des paramètres valides, vous pouvez donc spécifier --server <nomserveur>, ou --run_mode <modedexecution> comme argument.

Voir la documentation du fichier de configuration sur https://puppet.com/docs/puppet/latest/configuration.html pour la liste complète des paramètres acceptables. Une liste commentée de toutes les options de configuration peut également être générée en exécutant puppet avec --genconfig.

--render-as FORMAT
Le format dans lequel afficher la sortie. Les formats les plus courants sont json, s (chaîne), yaml et console, mais d'autres options telles que dot sont parfois disponibles.
--verbose
Faut-il afficher des messages détaillés.
--debug
Faut-il afficher des informations de débogage.

ACTIONS

download - Télécharger les plugins depuis le maître Puppet.
SYNTAXE
puppet plugin download
DESCRIPTION
Télécharge les plugins depuis le maître Puppet configuré. Tous les plugins téléchargés de cette manière seront utilisés dans toutes les activités Puppet ultérieures. Cette action modifie des fichiers sur le disque.
RETOURNE
Une liste des fichiers téléchargés, ou une confirmation qu'aucun fichier n'a été téléchargé. Lorsqu'elle est utilisée depuis l'API Ruby, cette action retourne un tableau des fichiers téléchargés, qui sera vide s'il n'y en a aucun.

EXEMPLES

download

Récupérer les plugins depuis le maître Puppet :

$ puppet plugin download

Récupérer les plugins depuis le maître Puppet (exemple d'API) :

$ Puppet::Face[:plugin, ´0.0.1´].download
