putgrent(3) Manuel des fonctions de bibliothèque putgrent(3)

NOM

putgrent - écrire une entrée de la base de données des groupes dans un fichier

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#define _GNU_SOURCE         /* Voir feature_test_macros(7) */
#include <grp.h>
int putgrent(const struct group *restrict grp, FILE *restrict stream);

DESCRIPTION

La fonction putgrent() est le pendant de fgetgrent(3). La fonction écrit le contenu de la structure struct group fournie dans le stream. La liste des membres du groupe doit être terminée par NULL ou initialisée à NULL.

La structure struct group est définie comme suit :


struct group {
    char   *gr_name;      /* nom du groupe */
    char   *gr_passwd;    /* mot de passe du groupe */
    gid_t   gr_gid;       /* identifiant du groupe */
    char  **gr_mem;       /* membres du groupe */
};

VALEUR DE RETOUR

La fonction renvoie zéro en cas de succès, et une valeur non nulle en cas d'erreur.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
putgrent () Sécurité des threads MT-Safe

NORMES

GNU.

VOIR AUSSI

fgetgrent(3), getgrent(3), group(5)
