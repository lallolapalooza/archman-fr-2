pulse-cli-syntax(5) Manuel des formats de fichiers pulse-cli-syntax(5)

NOM

pulse-cli-syntax - Syntaxe de l'interface en ligne de commande PulseAudio

SYNTAXE

~/.config/pulse/default.pa

/etc/pulse/default.pa

/etc/pulse/system.pa

DESCRIPTION

PulseAudio fournit un langage simple en ligne de commande utilisé par les scripts de configuration, le shell interactif pacmd, et les modules module-cli et module-cli-protocol-{unix,tcp}. Les lignes vides et les lignes commençant par une dièse (#) sont ignorées silencieusement. Plusieurs commandes sont prises en charge.

Notez que tout argument booléen peut être donné positivement comme '1', 't', 'y', 'true', 'yes' ou 'on'. De même, les valeurs négatives peuvent être données comme '0', 'f', 'n', 'false', 'no' ou 'off'. La casse est ignorée.

COMMANDES GÉNÉRALES

help
Affiche une aide rapide sur les commandes disponibles.

COMMANDES STATUT

list-modules
Affiche tous les modules actuellement chargés avec leurs arguments.
list-cards
Affiche toutes les cartes actuellement enregistrées
list-sinks ou list-sources
Affiche tous les puits (resp. sources) actuellement enregistrés.
list-clients
Affiche tous les clients actuellement actifs.
list-sink-inputs ou list-source-outputs
Affiche toutes les entrées de puits actives, alias flux de lecture (resp. sorties de sources, alias flux d'enregistrement).
stat
Affiche quelques statistiques simples sur les blocs mémoire alloués et l'espace qu'ils utilisent.
info ou ls ou list
Une combinaison de toutes les commandes de statut décrites ci-dessus (les trois commandes sont synonymes).

GESTION MODULE

load-module nom [arguments...]
Charge un module spécifié par son nom et ses arguments. Pour la plupart des modules, il est acceptable de les charger plus d'une fois.
unload-module index|nom
Décharge un module, spécifié soit par son index dans la liste des modules, soit par son nom.
describe-module nom
Donne des informations sur un module spécifié par son nom.

COMMANDES VOLUME

set-sink-volume|set-source-volume index|nom volume
Définit le volume du puits (resp. source) spécifié. Vous pouvez spécifier le puits (resp. la source) soit par son index dans la liste des puits/sources, soit par son nom. Le volume doit être une valeur entière supérieure ou égale à 0 (muet). Le volume 65536 (0x10000) correspond au volume 'normal' soit 100%. Les valeurs supérieures à cela amplifient le signal audio (avec écrêtage).
set-sink-mute|set-source-mute index|nom booléen
Active ou désactive le muet du puits (resp. de la source) spécifié. Vous pouvez spécifier le puits (resp. la source) soit par son index, soit par son nom. La valeur du muet est soit 0 (non muet) soit 1 (muet).
set-sink-input-volume|set-source-output-volume index volume
Définit le volume d'une entrée de puits (resp. sortie de source) spécifiée par son index. Les mêmes règles de volume s'appliquent qu'avec set-sink-volume.
set-sink-input-mute|set-source-output-mute index booléen
Active ou désactive le muet d'une entrée de puits (resp. sortie de source) spécifiée par son index. Les mêmes règles de muet s'appliquent qu'avec set-sink-mute.

COMMANDES CONFIGURATION

set-default-sink|set-default-source index|nom
Fait d'un puits (resp. d'une source) le puits (resp. la source) par défaut. Vous pouvez spécifier le puits (resp. la source) par son index dans la liste des puits (resp. sources) ou par son nom. Utilisez le nom spécial @NONE@ pour désactiver le puits ou la source par défaut défini par l'utilisateur. Dans ce cas, pulseaudio reviendra à la sélection du puits ou de la source par défaut basée sur la priorité.

Notez que les valeurs par défaut peuvent être outrepassées par divers modules de politique ou par des configurations de flux spécifiques.

set-card-profile index|nom nom-profil
Change le profil d'une carte.
set-sink-port|set-source-port index|nom nom-port
Change le profil d'un puits (resp. d'une source).
set-port-latency-offset index-carte|nom-carte nom-port décalage
Change le décalage de latence d'un port appartenant à la carte spécifiée
suspend-sink|suspend-source nom|index vrai|faux
Suspend ou reprend le puits ou la source spécifié (qui peut être spécifié soit par son nom soit par son index), en fonction de si vrai (suspendre) ou faux (reprendre) est passé comme dernier argument. Suspendre un puits mettra en pause toute lecture et suspendre une source mettra en pause toute capture. Selon le module implémentant le puits ou la source, cela pourrait avoir pour effet de fermer le périphérique sous-jacent, le rendant disponible pour d'autres applications. Le comportement exact dépend du module.
suspend booléen
Suspend tous les puits et sources.

DÉPLACER FLUX

move-sink-input|move-source-output index index-puits|nom-puits
Déplace l'entrée de puits (resp. la sortie de source) vers un autre puits (resp. une autre source).

LISTES PROPRIÉTÉS

update-sink-proplist|update-source-proplist index|nom propriétés
Met à jour les propriétés d'un puits (resp. d'une source) spécifié par son nom ou son index. La propriété est spécifiée comme par exemple device.description="Mon Nom Préféré"
update-sink-input-proplist|update-source-output-proplist index propriétés
Met à jour les propriétés d'une entrée de puits (resp. sortie de source) spécifiée par son index. Les propriétés sont spécifiées comme ci-dessus.

CACHE ÉCHANTILLONS

list-samples
Liste le contenu du cache d'échantillons.
play-sample nom index-puits|nom-puits
Joue une entrée du cache d'échantillons vers un puits.

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

pacmd(1) — PulseAudio command-line interface

SAMPLE CACHE

remove-sample name
Supprime une entrée du cache d'échantillons.
load-sample name filename
Charge un fichier audio dans le cache d'échantillons.
load-sample-lazy name filename
Crée une nouvelle entrée dans le cache d'échantillons, mais ne charge pas l'échantillon immédiatement. L'échantillon n'est chargé que lorsqu'il est utilisé pour la première fois. Après un certain temps d'inactivité, il est libéré à nouveau.
load-sample-dir-lazy path
Charge toutes les entrées du répertoire spécifié dans le cache d'échantillons en tant qu'entrées paresseuses. Une expression de globbing de shell (par exemple, *.wav) peut être ajoutée au chemin du répertoire à ajouter.

KILLING CLIENTS/STREAMS

kill-client index
Supprime de force un client du serveur. Il n'y a aucune protection contre la reconnexion immédiate du client.
kill-sink-input|kill-source-output index
Supprime de force une entrée de sortie (resp. une sortie source) du serveur. Cela ne supprimera pas le client propriétaire ni aucun autre flux ouvert par le même client du serveur.

LOG COMMANDS

set-log-level numeric-level
Change le niveau de journalisation.
set-log-meta boolean
Affiche l'emplacement du code source dans les messages de journal.
set-log-target target
Change la cible de journalisation (null, auto, journal, syslog, stderr, file:PATH, newfile:PATH).
set-log-time boolean
Affiche les horodatages dans les messages de journal.
set-log-backtrace num-frames
Affiche la trace de la pile dans les messages de journal.

MISCELLANEOUS COMMANDS

play-file filename sink-index|sink-name
Joue un fichier audio vers une sortie.
dump
Affiche la configuration actuelle du démon sous forme de commandes CLI.
dump-volumes
Débogage : Affiche l'état actuel de tous les volumes.
shared
Débogage : Affiche les propriétés partagées.
send-message recipient message message_parameters
Envoie un message à l'objet destinataire spécifié. Si applicable, une chaîne supplémentaire contenant les paramètres du message peut être spécifiée. Une chaîne est retournée en réponse au message. Pour les messages disponibles, voir https://cgit.freedesktop.org/pulseaudio/pulseaudio/tree/doc/messaging_api.txt.
exit
Termine le démon. Si vous voulez terminer une connexion CLI ("déconnexion"), vous pouvez utiliser ctrl+d

META COMMANDS

En plus des commandes décrites ci-dessus, quelques directives méta sont prises en charge par l'interpréteur de ligne de commande.

.include filename|folder
Exécute les commandes du fichier script spécifié ou de tous les fichiers *.pa dans le dossier.
.fail et .nofail
Active (resp. désactive) que les commandes suivantes qui échouent annulent l'exécution du fichier script actuel. Ceci est ignoré lorsqu'il est utilisé sur la ligne de commande interactive.
.ifexists filename
Exécute le bloc de commandes suivant uniquement si le fichier spécifié existe. Typiquement, filename indique un module. Les chemins relatifs sont résolus en utilisant le répertoire du module comme base. En utilisant un chemin absolu, l'existence d'autres fichiers peut également être vérifiée.
.else et .endif
Un bloc de commandes est délimité par une commande méta .else ou .endif. Les commandes conditionnelles imbriquées ne sont pas prises en charge.
