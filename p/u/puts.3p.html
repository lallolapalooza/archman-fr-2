PUTS(3P) Manuel du programmeur POSIX PUTS(3P)

PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NAME

puts — écrire une chaîne sur la sortie standard

SYNOPSIS

#include <stdio.h>
int puts(const char *s);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est conforme à la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

La fonction puts() écrit la chaîne pointée par s, suivie d'un <saut de ligne>, sur le flux de sortie standard stdout. Le caractère nul de terminaison n'est pas écrit.

Les horodatages de la dernière modification des données et du dernier changement d'état de fichier sont marqués pour mise à jour entre l'exécution réussie de puts() et l'achèvement réussi suivant d'un appel à fflush() ou fclose() sur le même flux, ou un appel à exit() ou abort().

VALEUR RENVOYÉE

En cas de succès, puts() renvoie un nombre non négatif. Sinon, elle renvoie EOF, définit un indicateur d'erreur pour le flux et errno est défini pour indiquer l'erreur.

ERREURS

Se référer à fputc().

Les sections suivantes sont informatives.

EXEMPLES

Impression sur la sortie standard

L'exemple suivant obtient l'heure actuelle, la convertit en chaîne à l'aide de localtime() et asctime(), et l'imprime sur la sortie standard à l'aide de puts(). Il imprime ensuite le nombre de minutes avant un événement pour lequel il attend.

#include <time.h>
#include <stdio.h>
...
time_t now;
int minutes_to_event;
...
time(&now);
printf("L'heure est ");
puts(asctime(localtime(&now)));
printf("Il reste %d minutes avant l'événement.\n",
    minutes_to_event);
...

USAGE APPLICATION

La fonction puts() ajoute un <saut de ligne>, tandis que fputs() ne le fait pas.

Ce volume de POSIX.1‐2017 exige qu'une complétion réussie renvoie simplement un entier non négatif. Il existe au moins trois conventions d'implémentation différentes connues pour cette exigence :

*
Renvoie une valeur constante.
*
Renvoie le dernier caractère écrit.
*
Renvoie le nombre d'octets écrits. Notez que cette convention d'implémentation ne peut pas être respectée pour les chaînes plus longues que {INT_MAX} octets car la valeur ne serait pas représentable dans le type de retour de la fonction. Par souci de compatibilité ascendante, les implémentations peuvent renvoyer le nombre d'octets pour les chaînes jusqu'à {INT_MAX} octets, et renvoyer {INT_MAX} pour toutes les chaînes plus longues.
