NOM

purge-old-kernels - supprime les anciens paquets de noyau et d'en-têtes du système

SYNTAXE

purge-old-kernels

DESCRIPTION

Cet utilitaire est maintenant obsolète. La fonctionnalité qu'il fournissait devrait être intégrée à apt(8).

Si vous avez toujours d'anciens noyaux qui traînent après cela, veuillez créer un rapport de bug contre apt : https://bugs.launchpad.net/ubuntu/+source/apt/+filebug

Ce programme nécessite un accès administrateur.

EXEMPLE

sudo purge-old-kernels

VOIR AUSSI

apt-get(8)
