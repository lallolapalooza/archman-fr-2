NOM

punycode_strerror - Fonction d'API

SYNTAXE

#include <punycode.h>

const char * punycode_strerror(Punycode_status rc);

ARGUMENTS

Punycode_status rc
un code de retour Punycode_status.

DESCRIPTION

Convertit un code d'erreur entier en chaîne de caractères. Cette chaîne peut être utilisée pour afficher un message diagnostique à l'utilisateur.

PUNYCODE_SUCCESS

Opération réussie. Cette valeur est garantie d'être toujours zéro, les autres sont garanties de contenir des valeurs non nulles, à des fins de comparaison logique.

PUNYCODE_BAD_INPUT

L'entrée est invalide.

PUNYCODE_BIG_OUTPUT

La sortie dépasserait l'espace fourni.

PUNYCODE_OVERFLOW

L'entrée nécessite des entiers plus larges pour être traitée.

Valeur de retour : Renvoie un pointeur vers une chaîne allouée statiquement contenant une description de l'erreur correspondant au code de retour rc.
