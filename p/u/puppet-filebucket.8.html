NOM

puppet-filebucket - Stocker et récupérer des fichiers dans un filebucket

SYNOPSIS

Un client puppet filebucket autonome.

UTILISATION

puppet filebucket mode [-h|--help] [-V|--version] [-d|--debug] [-v|--verbose] [-l|--local] [-r|--remote] [-s|--server serveur] [-f|--fromdate date] [-t|--todate date] [-b|--bucket répertoire] fichier fichier ...

Puppet filebucket peut fonctionner dans trois modes, un seul mode par appel :

backup : Envoie un ou plusieurs fichiers vers le filebucket spécifié. Chaque fichier envoyé est affiché avec sa somme sha256 résultante.

get : Retourne le texte associé à une somme sha256. Le texte est affiché sur stdout, et un seul fichier peut être récupéré à la fois.

restore : Étant donné un chemin de fichier et une somme sha256, stocke le contenu associé à la somme dans le chemin de fichier spécifié. Vous pouvez spécifier un chemin entièrement nouveau à cet argument ; vous n'êtes pas limité à restaurer le contenu à son emplacement d'origine.

diff : Affiche une différence au format unifié entre deux sommes de contrôle dans le filebucket ou entre une somme de contrôle et son fichier correspondant.

list : Liste tous les fichiers dans le filebucket local actuel. La liste des filebuckets distants n'est pas autorisée.

DESCRIPTION

Ceci est un client filebucket autonome pour envoyer des fichiers vers un filebucket local ou central.

Notez que ´filebucket´ utilise par défaut un filebucket basé sur le réseau disponible sur le serveur nommé ´puppet´. Pour l'utiliser, vous devrez l'exécuter en tant qu'utilisateur avec des certificats Puppet valides. Alternativement, vous pouvez utiliser votre file bucket local en spécifiant ´--local´, ou en spécifiant ´--bucket´ avec un chemin local.

Important : Lorsque vous activez et utilisez l'option de sauvegarde, et par extension la ressource filebucket, vous devez vous assurer qu'un espace disque suffisant est disponible pour les sauvegardes de fichiers. Généralement, vous pouvez prévoir l'espace disque en utilisant l'une des deux options suivantes :

•
Utilisez une commande find et une entrée crontab pour conserver seulement les X derniers jours de sauvegardes de fichiers. Par exemple :
  find /opt/puppetlabs/server/data/puppetserver/bucket -type f -mtime +45 -atime +45 -print0 | xargs -0 rm
•
Restreignez le répertoire à une taille maximale après laquelle les éléments les plus anciens sont supprimés.

OPTIONS

Notez que tout paramètre valide dans le fichier de configuration est également un argument long valide. Par exemple, ´ssldir´ est un paramètre valide, vous pouvez donc spécifier ´--ssldir répertoire´ comme argument.

Consultez la documentation du fichier de configuration sur https://puppet.com/docs/puppet/latest/configuration.html pour la liste complète des paramètres acceptables. Une liste commentée de toutes les options de configuration peut également être générée en exécutant puppet avec ´--genconfig´.

--bucket
Spécifie un chemin de filebucket local. Cela remplace le chemin par défaut défini dans ´$clientbucketdir´.
--debug
Active le débogage complet.
--fromdate
(list seulement) Sélectionne les fichiers du bucket à partir de ´fromdate´.
--help
Affiche ce message d'aide.
--local
Utilise le filebucket local. Cela utilise les informations de configuration par défaut et le bucket situé à l'adresse ´$clientbucketdir´ par défaut. Si ´--bucket´ est défini, puppet utilise ce chemin à la place.
--remote
Utilise un filebucket distant. Cela utilise les informations de configuration par défaut et le bucket situé à l'adresse ´$bucketdir´ par défaut.
--server_list
Une liste de serveurs séparés par des virgules ; seule la première entrée est utilisée pour le stockage des fichiers. Ce paramètre a priorité sur server.
--server
Le serveur à utiliser pour le stockage des fichiers. Ce paramètre n'est utilisé que si server_list n'est pas défini.
--todate
(list seulement) Sélectionne les fichiers du bucket jusqu'à ´todate´.
--verbose
Affiche des informations supplémentaires.
--version
Affiche les informations de version.

EXEMPLES

## Sauvegarder un fichier dans le filebucket, puis le restaurer dans un répertoire temporaire
$ puppet filebucket backup /etc/passwd
/etc/passwd: 429b225650b912a2ee067b0a4cf1e949
$ puppet filebucket restore /tmp/passwd 429b225650b912a2ee067b0a4cf1e949
## Différence entre deux fichiers dans le filebucket
$ puppet filebucket -l diff d43a6ecaa892a1962398ac9170ea9bf2 7ae322f5791217e031dc60188f4521ef
1a2
> again
## Différence entre le fichier dans le filebucket et un fichier local
$ puppet filebucket -l diff d43a6ecaa892a1962398ac9170ea9bf2 /tmp/testFile
1a2
> again
## Sauvegarder un fichier dans le filebucket et observer qu'il conserve chaque sauvegarde séparément
$ puppet filebucket -l list
d43a6ecaa892a1962398ac9170ea9bf2 2015-05-11 09:27:56 /tmp/TestFile
$ echo again >> /tmp/TestFile
$ puppet filebucket -l backup /tmp/TestFile
/tmp/TestFile: 7ae322f5791217e031dc60188f4521ef
$ puppet filebucket -l list
d43a6ecaa892a1962398ac9170ea9bf2 2015-05-11 09:27:56 /tmp/TestFile
7ae322f5791217e031dc60188f4521ef 2015-05-11 09:52:15 /tmp/TestFile
## Lister les fichiers dans un filebucket dans des plages de dates
$ puppet filebucket -l -f 2015-01-01 -t 2015-01-11 list
<Empty Output>
$ puppet filebucket -l -f 2015-05-10 list
d43a6ecaa892a1962398ac9170ea9bf2 2015-05-11 09:27:56 /tmp/TestFile
7ae322f5791217e031dc60188f4521ef 2015-05-11 09:52:15 /tmp/TestFile
$ puppet filebucket -l -f "2015-05-11 09:30:00" list
7ae322f5791217e031dc60188f4521ef 2015-05-11 09:52:15 /tmp/TestFile
$ puppet filebucket -l -t "2015-05-11 09:30:00" list
d43a6ecaa892a1962398ac9170ea9bf2 2015-05-11 09:27:56 /tmp/TestFile
## Gérer les fichiers dans un filebucket local spécifique
$ puppet filebucket -b /tmp/TestBucket backup /tmp/TestFile2
/tmp/TestFile2: d41d8cd98f00b204e9800998ecf8427e
$ puppet filebucket -b /tmp/TestBucket list
d41d8cd98f00b204e9800998ecf8427e 2015-05-11 09:33:22 /tmp/TestFile2
## Depuis un serveur Puppet, lister les fichiers dans le bucketdir du serveur
$ puppet filebucket -b $(puppet config print bucketdir --section server) list
d43a6ecaa892a1962398ac9170ea9bf2 2015-05-11 09:27:56 /tmp/TestFile
7ae322f5791217e031dc60188f4521ef 2015-05-11 09:52:15 /tmp/TestFile

    puppet-filebucket(8)

    puppet-filebucket — puppet-filebucket

    DESCRIPTION

    The puppet-filebucket resource type provides a mechanism for managing file buckets. A file bucket is a backend for storing file objects.

    OPTIONS

    The puppet-filebucket resource type supports the following arguments:

    • path: The path to the file bucket. This is a required argument.
    • uri: The URI of the file bucket. This is an optional argument.

    EXAMPLES

    
                    filebucket { '/var/lib/puppet/filebucket':
                        ensure => present,
                    }

    puppet-filebucket — puppet-filebucket

    DESCRIPTION

    Le type de ressource puppet-filebucket fournit un mécanisme pour gérer les buckets de fichiers. Un bucket de fichiers est un backend pour stocker des objets de fichiers.

    OPTIONS

    Le type de ressource puppet-filebucket prend en charge les arguments suivants :

    • path : Le chemin d'accès au bucket de fichiers. C'est un argument requis.
    • uri : L'URI du bucket de fichiers. C'est un argument optionnel.

    EXEMPLES

    
                    filebucket { '/var/lib/puppet/filebucket':
                        ensure => present,
                    }
