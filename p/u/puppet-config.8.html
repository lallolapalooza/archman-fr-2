NOM

puppet-config - Interagit avec les paramètres de Puppet.

SYNTAXE

puppet config action [--section SECTION_NAME]

DESCRIPTION

Cette sous-commande peut inspecter et modifier les paramètres du fichier de configuration ´puppet.conf´ de Puppet. Pour la documentation sur les paramètres individuels, consultez https://puppet.com/docs/puppet/latest/configuration.html.

OPTIONS

Notez que tout paramètre valide dans le fichier de configuration est également un argument long valide, bien qu'il puisse être pertinent ou non pour l'action en cours. Par exemple, server et run_mode sont des paramètres valides, vous pouvez donc spécifier --server <nom_serveur> ou --run_mode <mode_exécution> comme argument.

Consultez la documentation du fichier de configuration à l'adresse https://puppet.com/docs/puppet/latest/configuration.html pour la liste complète des paramètres acceptables. Une liste commentée de toutes les options de configuration peut également être générée en exécutant puppet avec --genconfig.

--render-as FORMAT
Le format dans lequel rendre la sortie. Les formats les plus courants sont json, s (chaîne de caractères), yaml et console, mais d'autres options telles que dot sont parfois disponibles.
--verbose
Indique s'il faut enregistrer les informations de manière verbeuse.
--debug
Indique s'il faut enregistrer les informations de débogage.
--section NOM_SECTION
La section du fichier de configuration puppet.conf avec laquelle interagir.
Les trois sections les plus couramment utilisées sont ´main´, ´server´ et ´agent´. ´Main´ est le défaut, et est utilisé par toutes les applications Puppet. D'autres sections peuvent remplacer les valeurs de ´main´ pour des applications spécifiques — la section ´server´ affecte Puppet Server, et la section ´agent´ affecte puppet agent.
Moins couramment utilisée est la section ´user´, qui affecte puppet apply. Toute autre section sera traitée comme le nom d'un environnement hérité (une fonctionnalité dépréciée) et ne peut contenir que les paramètres ´manifest´ et ´modulepath´.

ACTIONS

supprimer - Supprime un paramètre Puppet.
SYNTAXE
puppet config supprimer [--section NOM_SECTION] paramètre
DESCRIPTION
Supprime un paramètre de la section spécifiée. (Le défaut est la section ´main´).
NOTES
Par défaut, cette action supprime le paramètre de configuration du domaine de configuration ´main´. Utilisez l'indicateur ´--section´ pour supprimer les paramètres d'autres domaines de configuration.
imprimer - Examine les paramètres actuels de Puppet.
SYNTAXE
puppet config imprimer [--section NOM_SECTION] all | paramètre [paramètre ...]
DESCRIPTION
Affiche la valeur d'un seul paramètre ou d'une liste de paramètres.
Cette action est une interface de remplacement pour les informations disponibles avec puppet <sous-commande> --configprint.
NOTES
Par défaut, cette action lit la configuration générale dans la section ´main´. Utilisez les indicateurs ´--section´ et ´--environment´ pour examiner d'autres domaines de configuration.
définir - Définit les paramètres de Puppet.
SYNTAXE
puppet config définir [--section NOM_SECTION] [nom_paramètre] [valeur_paramètre]
DESCRIPTION
Met à jour les valeurs dans le fichier de configuration puppet.conf.
NOTES
Par défaut, cette action manipule la configuration dans la section ´main´. Utilisez l'indicateur ´--section´ pour manipuler d'autres domaines de configuration.

EXEMPLES

supprimer

Supprime le paramètre ´nom_paramètre´ du domaine de configuration ´main´ :

$ puppet config supprimer nom_paramètre

Supprime le paramètre ´nom_paramètre´ du domaine de configuration ´server´ :

$ puppet config supprimer nom_paramètre --section server

imprimer

Obtenir le répertoire d'exécution de puppet :

$ puppet config imprimer rundir

Obtenir une liste des répertoires importants de la configuration du serveur :

$ puppet config imprimer all --section server | grep -E "(path|dir)"

définir

Définit le répertoire d'exécution de puppet :

$ puppet config définir rundir /var/run/puppetlabs

Définit le vardir uniquement pour l'agent :

$ puppet config définir vardir /opt/puppetlabs/puppet/cache --section agent
