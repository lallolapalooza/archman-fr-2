NOM

puppet-resource - L'interface shell de la couche d'abstraction de ressources

SYNTAXE

Utilise la RAL de Puppet pour interagir directement avec le système.

UTILISATION

puppet resource [-h|--help] [-d|--debug] [-v|--verbose] [-e|--edit] [-p|--param paramètre] [-t|--types] [-y|--to_yaml] type [nom] [attribut=valeur ...]

DESCRIPTION

Cette commande fournit des installations simples pour convertir l'état actuel du système en code Puppet, ainsi qu'une certaine capacité à modifier l'état actuel à l'aide de la RAL de Puppet.

Par défaut, vous devez au moins fournir un type à lister, auquel cas puppet resource vous indiquera tout ce qu'il sait sur toutes les ressources de ce type. Vous pouvez éventuellement spécifier un nom d'instance, et puppet resource ne décrira que cette seule instance.

Si un type, un nom et une série de paires attribut=valeur sont fournis, puppet resource modifiera l'état de la ressource spécifiée. Alternativement, si un type, un nom et l'indicateur ´--edit´ sont fournis, puppet resource écrira sa sortie dans un fichier, ouvrira ce fichier dans un éditeur, puis appliquera le fichier enregistré comme une transaction Puppet.

OPTIONS

Notez que tout paramètre valide dans le fichier de configuration est également un argument long valide. Par exemple, ´ssldir´ est un paramètre valide, vous pouvez donc spécifier ´--ssldir répertoire´ comme argument.

Voir la documentation du fichier de configuration à https://puppet.com/docs/puppet/latest/configuration.html pour la liste complète des paramètres acceptables. Une liste commentée de toutes les options de configuration peut également être générée en exécutant puppet avec ´--genconfig´.

--debug
Activer le débogage complet.
--edit
Écrit les résultats de la requête dans un fichier, ouvre le fichier dans un éditeur et le relit comme un manifeste Puppet exécutable.
--help
Imprime ce message d'aide.
--param
Ajouter des paramètres supplémentaires à afficher lors des requêtes.
--types
Lister tous les types disponibles.
--verbose
Imprimer des informations supplémentaires.
--to_yaml
Afficher les ressources trouvées au format yaml, approprié pour une utilisation avec Hiera et create_resources.
--fail
Échoue et renvoie un code de sortie de 1 si la ressource n'a pas pu être modifiée.

EXEMPLE

Cet exemple utilise puppet resource pour retourner une configuration Puppet pour l'utilisateur luke :

$ puppet resource user luke
user { ´luke´:
 home => ´/home/luke´,
 uid => ´100´,
 ensure => ´present´,
 comment => ´Luke Kanies,,,´,
 gid => ´1000´,
 shell => ´/bin/bash´,
 groups => [´sysadmin´,´audio´,´video´,´puppet´]
}
