NOM

puppet-describe - Afficher l'aide sur les types de ressources

SYNOPSIS

Affiche l'aide concernant les types de ressources, les fournisseurs et les méta-paramètres de Puppet.

USAGE

puppet describe [-h|--help] [-s|--short] [-p|--providers] [-l|--list] [-m|--meta]

OPTIONS

--help
Imprimer ce texte d'aide
--providers
Décrire les fournisseurs en détail pour chaque type
--list
Lister tous les types
--meta
Lister tous les méta-paramètres
--short
Lister uniquement les paramètres sans détails

EXEMPLE

$ puppet describe --list
$ puppet describe file --providers
$ puppet describe user -s -m
