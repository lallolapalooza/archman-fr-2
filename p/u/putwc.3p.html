PUTWC(3P) Manuel du programmeur POSIX PUTWC(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

putwc — écrire un caractère large sur un flux

SYNTAXE

#include <stdio.h>
#include <wchar.h>
wint_t putwc(wchar_t wc, FILE *stream);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 renvoie à la norme ISO C.

La fonction putwc() sera équivalente à fputwc(), sauf que si elle est implémentée sous forme de macro, elle peut évaluer stream plus d'une fois, de sorte que l'argument ne devrait jamais être une expression avec des effets de bord.

VALEUR DE RETOUR

Voir fputwc().

ERREURS

Voir fputwc().

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION APPLICATIVE

Comme elle peut être implémentée sous forme de macro, putwc() peut traiter de manière incorrecte un argument stream avec des effets de bord. En particulier, putwc(wc,*f++) n'est pas censé fonctionner correctement. Par conséquent, l'utilisation de cette fonction n'est pas recommandée ; fputwc() devrait être utilisé à la place.
