NOM

puppet-script - Exécute un manifeste puppet comme un script sans compiler de catalogue

SYNOPIS

Exécute un script en langage puppet sans compiler de catalogue.

UTILISATION

puppet script [-h|--help] [-V|--version] [-d|--debug] [-v|--verbose] [-e|--execute] [-l|--logdest syslog|eventlog|FICHIER|console] [--noop] fichier

DESCRIPTION

Il s'agit d'un outil autonome pour exécuter des scripts puppet ; utilisez-le pour exécuter du code puppet sans compiler de catalogue.

Lorsqu'un modulepath est fourni, via la ligne de commande ou le fichier de configuration, puppet script peut charger des fonctions, des types, des tâches et des plans à partir des modules.

OPTIONS

Notez que tout paramètre valide dans le fichier de configuration est également un argument long valide. Par exemple, ´environment´ est un paramètre valide, vous pouvez donc spécifier ´--environment mytest´ comme argument.

Consultez la documentation du fichier de configuration à l'adresse https://puppet.com/docs/puppet/latest/configuration.html pour la liste complète des paramètres acceptables. Une liste commentée de toutes les options de configuration peut également être générée en exécutant puppet avec ´--genconfig´.

--debug
Active le débogage complet.
--help
Imprime ce message d'aide
--logdest
Où envoyer les messages de journal. Choisissez entre ´syslog´ (le service syslog POSIX), ´eventlog´ (le journal des événements Windows), ´console´, ou le chemin d'un fichier journal. Par défaut : ´console´. Plusieurs destinations peuvent être définies à l'aide d'une liste séparée par des virgules (par ex. : /chemin/fichier1,console,/chemin/fichier2)"
Un chemin se terminant par ´.json´ recevra une sortie structurée au format JSON. Le fichier journal n'aura pas de ´]´ ajouté automatiquement en raison de la nature d'ajout de la journalisation. Il doit être ajouté manuellement pour rendre le contenu JSON valide.
Un chemin se terminant par ´.jsonl´ recevra une sortie structurée au format JSON Lines.
--noop
Utilise le mode ´noop´ où Puppet s'exécute en mode sans exécution ou d'essai. Ceci est utile pour voir quelles modifications Puppet apportera sans réellement exécuter les modifications. S'applique uniquement aux tâches.
--execute
Exécute un morceau spécifique de code Puppet
--verbose
Imprime des informations supplémentaires.

EXEMPLE

$ puppet script -l /tmp/manifest.log manifest.pp
$ puppet script --modulepath=/root/dev/modules -e ´notice("bonjour le monde")´
