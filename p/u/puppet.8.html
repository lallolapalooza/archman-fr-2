NOM

puppet - un outil automatisé de gestion de configuration

SYNOPSIS

puppet sous-commande [options] action [options]

DESCRIPTION

Puppet, un moteur administratif automatisé pour vos systèmes Linux, Unix et Windows, effectue des tâches administratives (telles que l'ajout d'utilisateurs, l'installation de paquets et la mise à jour des configurations de serveurs) basées sur une spécification centralisée.

COMMANDES

Courantes

apply
    Applique les manifestes Puppet localement

agent
    Le démon agent de Puppet

config
    Interagit avec les paramètres de Puppet.

help
    Affiche l'aide de Puppet.

lookup
    Recherche Hiera interactive

module
    Crée, installe et recherche des modules sur le Puppet Forge.

resource
    Le shell de la couche d'abstraction des ressources

Spécialisées

strings
    Génère la documentation Puppet avec YARD.

catalog
    Compile, enregistre, affiche et convertit les catalogues.

describe
    Affiche l'aide sur les types de ressources

device
    Gère les périphériques réseau distants

doc
    Génère les références Puppet

epp
    Interagit directement avec l'analyseur/rendeur de modèles EPP.

facts
    Récupère et stocke les facts.

filebucket
    Stocke et récupère des fichiers dans un filebucket

generate
    Génère du code Puppet à partir de définitions Ruby.

node
    Affiche et gère les définitions de nœuds.

parser
    Interagit directement avec l'analyseur.

plugin
    Interagit avec le système de plugins de Puppet.

script
    Exécute un manifeste puppet comme un script sans compiler de catalogue

ssl
    Gère les clés et certificats SSL pour les clients SSL de Puppet

VOIR AUSSI

Voir puppet help <sous-commande> pour obtenir de l'aide sur une sous-commande spécifique.

Voir puppet help <sous-commande> <action> pour obtenir de l'aide sur une action de sous-commande spécifique.
