fputwc(3) Manuel des fonctions de bibliothèque fputwc(3)

NOM

fputwc, putwc - écrire un caractère large dans un flux FILE

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <stdio.h>
#include <wchar.h>
wint_t fputwc(wchar_t wc, FILE *stream);
wint_t putwc(wchar_t wc, FILE *stream);

DESCRIPTION

La fonction fputwc() est l'équivalent caractère large de la fonction fputc(3). Elle écrit le caractère large wc dans stream. Si ferror(stream) devient vrai, elle renvoie WEOF. Si une erreur de conversion de caractère large se produit, elle définit errno à EILSEQ et renvoie WEOF. Sinon, elle renvoie wc.

La fonction ou macro putwc() fonctionne de manière identique à fputwc(). Elle peut être implémentée comme une macro et peut évaluer son argument plus d'une fois. Il n'y a aucune raison de l'utiliser.

Pour les homologues non-verrouillables, voir unlocked_stdio(3).

VALEUR DE RETOUR

En cas de succès, la fonction fputwc() renvoie wc. Sinon, WEOF est renvoyé, et errno est défini pour indiquer l'erreur.

ERREURS

Outre les erreurs habituelles, il y a

EILSEQ
La conversion de wc vers le codage du flux échoue.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
fputwc (), putwc () Sécurité thread MT-Safe

NORMES

C11, POSIX.1-2008.

HISTORIQUE

C99, POSIX.1-2001.

NOTES

Le comportement de fputwc() dépend de la catégorie LC_CTYPE de la locale courante.

En l'absence d'informations supplémentaires transmises à l'appel fopen(3), il est raisonnable de s'attendre à ce que fputwc() écrive réellement la séquence multibyte correspondant au caractère large wc.

VOIR AUSSI

fgetwc(3), fputws(3), unlocked_stdio(3)
