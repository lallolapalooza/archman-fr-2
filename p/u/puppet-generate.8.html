NOM

puppet-generate - Génère du code Puppet à partir de définitions Ruby.

SYNOPSIS

puppet generate action

OPTIONS

Notez que tout réglage valide dans le fichier de configuration est également un argument long valide, bien qu'il puisse être pertinent ou non pour l'action en cours. Par exemple, server et run_mode sont des réglages valides, vous pouvez donc spécifier --server <nomServeur>, ou --run_mode <modeExecution> comme argument.

Consultez la documentation du fichier de configuration sur https://puppet.com/docs/puppet/latest/configuration.html pour la liste complète des paramètres acceptables. Une liste commentée de toutes les options de configuration peut également être générée en exécutant puppet avec --genconfig.

--render-as FORMAT
Le format dans lequel rendre la sortie. Les formats les plus courants sont json, s (chaîne), yaml et console, mais d'autres options comme dot sont parfois disponibles.
--verbose
Si la journalisation doit être verbeuse.
--debug
Si les informations de débogage doivent être journalisées.

ACTIONS

types - Génère du code Puppet pour les types personnalisés
SYNOPSIS
puppet generate types [--format format] [--force]
DESCRIPTION
Génère des définitions pour les types de ressources personnalisés en utilisant du code Puppet.
Les types définis en code Puppet peuvent être utilisés pour isoler les définitions de types personnalisés entre différents environnements.
OPTIONS --force - Force la génération des fichiers de sortie (saute les vérifications de mise à jour).
--format <format> - Le format de sortie de génération à utiliser. Formats supportés : pcore.

EXEMPLES

types

Générer les définitions de types Puppet pour toutes les ressources personnalisées de l'environnement actuel :

$ puppet generate types

Générer les définitions de types Puppet pour toutes les ressources personnalisées de l'environnement spécifié :

$ puppet generate types --environment development
