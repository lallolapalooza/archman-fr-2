PULSEVIEW(1) Manuel des commandes générales PULSEVIEW(1)

NOM

PulseView - GUI Qt pour analyseur logique/oscilloscope/MSO pour sigrok

SYNTAXE

pulseview [OPTIONS] [FICHIER]

DESCRIPTION

PulseView est une interface graphique multiplateforme basée sur Qt pour la suite logicielle sigrok d'équipements de test et de mesure tels que les analyseurs logiques, les oscilloscopes, les MSO, etc.

OPTIONS

PulseView a très peu d'options en ligne de commande, car la plupart des éléments de configuration sont disponibles depuis l'interface graphique elle-même.

Si l'argument optionnel FICHIER est fourni, PulseView essaie d'ouvrir le fichier spécifié. Il doit être au format "session libsigrok" (.sr) sauf si -I est utilisé pour spécifier le format du fichier d'entrée.

-l, --loglevel
Définit le niveau de journalisation de libsigrok et libsigrokdecode. Pour le moment, PulseView ne prend pas en charge la définition indépendante des deux niveaux de journalisation. Plus le chiffre est élevé, plus la sortie de débogage sera importante. Les niveaux de journalisation valides sont :

0 Aucun
1 Erreur
2 Avertissements
3 Informationnel
4 Débogage
5 Verbeux

-h, -?, --help
Affiche un message d'aide et quitte.
-V, --version
Affiche les informations de version et quitte.
-d, --driver <nom_pilote>
Spécifie le périphérique de capture auquel se connecter. Si l'option --driver n'est pas fournie, PulseView tente de se reconnecter au périphérique le plus récemment utilisé, ou de détecter automatiquement les périphériques disponibles.
-D, --dont-scan
Habituellement, PulseView analyse automatiquement tous les pilotes pour trouver les périphériques appropriés lors du démarrage du programme. Cette option désactive l'analyse automatique. Les utilisateurs peuvent soit spécifier l'option --driver pour choisir un périphérique au démarrage, soit analyser interactivement les périphériques après le démarrage de PulseView.
-i, --input-file <nom_fichier>
Charge l'entrée à partir d'un fichier. Si l'option --input-format n'est pas fournie, PulseView tente de charger le fichier en tant que fichier de session sigrok.
-I, --input-format <format>
Spécifie le format du fichier d'entrée à charger.
-s, --settings <nom_fichier>
Charge la configuration de session PulseView à utiliser avec le fichier d'entrée. Le fichier de configuration doit être au format "configuration de session PulseView" (.pvs).
-c, --clean
Empêche la restauration des sessions précédemment utilisées à partir du stockage des paramètres. Ceci est utile si vous ne voulez qu'une seule session avec le fichier donné sur la ligne de commande au lieu de restaurer également toutes les sessions précédemment utilisées.

RACCOURCIS CLAVIER

f
Zoom pour ajuster.
s
Activer / désactiver le défilement fixe. Lorsqu'il est activé, le bord droit de l'écran affiche toujours les données capturées les plus récentes.
.
Afficher / masquer les points d'échantillonnage.
g
Afficher / masquer la grille mineure analogique (en plus de la grille vdiv).
c
Afficher / masquer les curseurs.
d
Afficher / masquer le sélecteur de décodeur de protocole.
b
Basculer entre les fonds de trace colorés et les fonds de trace gris clair/foncé alternés.
ESPACE
Démarrer / arrêter une acquisition.
Touches fléchées gauche/droite
Faire défiler vers la gauche/droite.
+/-
Zoom avant/arrière.
Touches fléchées haut/bas
Zoom avant/arrière.
Home/End
Aller au début/fin des données échantillonnées.
1/2
Attacher les curseurs gauche/droite à la souris.
CTRL+o
Ouvrir un fichier.
CTRL+s
Enregistrer sous...
CTRL+r
Enregistrer la plage sélectionnée sous...
CTRL+g
Regrouper toutes les traces actuellement sélectionnées dans un groupe de traces.
CTRL+u
Dissocier les traces du groupe de traces actuellement sélectionné.
Touches fléchées CTRL+haut/bas
Faire défiler vers le bas/haut.
CTRL+q
Quitter, c'est-à-dire fermer PulseView (en fermant tous les onglets de session).
CTRL+w
Fermer l'onglet de session actuel.

STATUT DE SORTIE

PulseView se termine avec 0 en cas de succès, 1 dans la plupart des cas d'échec.
