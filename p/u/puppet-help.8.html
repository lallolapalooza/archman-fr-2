NOM

puppet-help - Afficher l'aide de Puppet.

SYNTAXE

puppet help action

OPTIONS

Notez que tout paramètre valide dans le fichier de configuration est également un argument long valide, bien qu'il puisse être ou non pertinent pour l'action présente. Par exemple, server et run_mode sont des paramètres valides, vous pouvez donc spécifier --server <nom_serveur> ou --run_mode <mode_exécution> comme argument.

Voir la documentation du fichier de configuration à https://puppet.com/docs/puppet/latest/configuration.html pour la liste complète des paramètres acceptables. Une liste commentée de toutes les options de configuration peut également être générée en exécutant puppet avec --genconfig.

--render-as FORMAT
Le format dans lequel afficher la sortie. Les formats les plus courants sont json, s (string), yaml, et console, mais d'autres options telles que dot sont parfois disponibles.
--verbose
Si l'on doit afficher des informations détaillées.
--debug
Si l'on doit afficher des informations de débogage.

ACTIONS

help - Afficher l'aide sur les sous-commandes de Puppet et leurs actions.
SYNTAXE
puppet help [--version VERSION] [--ronn] [sous-commande] [action]
DESCRIPTION
Affiche l'aide sur les sous-commandes de Puppet et leurs actions.
OPTIONS --ronn - Si l'on doit afficher le texte d'aide au format ronn.
--version VERSION - La version du sous-commande pour lequel afficher l'aide.
RETOURS
Texte d'aide court pour le sous-commande ou l'action spécifié(e).

EXEMPLES

help

Obtenir de l'aide pour une action :

$ puppet help
