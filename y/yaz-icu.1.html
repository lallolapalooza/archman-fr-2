NOM

yaz-icu - Utilitaire YAZ ICU

SYNTAXE

yaz-icu [-c config] [-p opt] [-s] [-x] [infile]

DESCRIPTION

yaz-icu est un utilitaire qui démontre le module ICU chain de yaz. (yaz/icu.h).

L'utilitaire peut être utilisé de deux manières. Il peut lire du texte en utilisant une configuration XML pour configurer ICU et afficher l'analyse du texte. Ce mode est déclenché par l'option -c qui spécifie la configuration à utiliser. Le fichier d'entrée est lu depuis l'entrée standard ou depuis un fichier si infile est spécifié.

L'utilitaire peut également afficher des informations ICU. Ceci est déclenché par l'option -p.

OPTIONS

-c config

Spécifie le fichier contenant la configuration de la chaîne ICU, basée sur XML.

-p type

Spécifie des informations supplémentaires à imprimer sur le système ICU. Si type est c, les convertisseurs ICU sont imprimés. Si type est l, les locales disponibles sont imprimées. Si type est t, les translittérateurs disponibles sont imprimés.

-s

Spécifie que la sortie doit également inclure la clé de tri. Notez que la clé de tri diffère selon les versions d'ICU.

-x

Spécifie que la sortie doit être basée sur XML plutôt que sur du texte.

CONFIGURATION DE LA CHAÎNE ICU

La configuration de la chaîne ICU spécifie une ou plusieurs règles pour convertir les données textuelles en jetons. Le format de configuration est basé sur XML.

L'élément racine doit s'appeler icu_chain. L'élément icu_chain a un attribut requis locale qui spécifie la locale ICU à utiliser dans les étapes de conversion.

L'élément icu_chain doit inclure des éléments où chaque élément spécifie une étape de conversion. La conversion est effectuée dans l'ordre où les étapes de conversion sont spécifiées. Chaque élément de conversion prend un attribut: rule qui sert d'argument à l'étape de conversion.

Les éléments de conversion suivants sont disponibles :

casemap

Convertit la casse (et la règle spécifie comment) :

l

Casse inférieure en utilisant la fonction ICU u_strToLower.

u

Casse supérieure en utilisant la fonction ICU u_strToUpper.

t

Mise en majuscule en utilisant la fonction ICU u_strToTitle.

f

Mélange des cas en utilisant la fonction ICU u_strFoldCase.

display

Ceci est une méta-étape qui spécifie qu'un terme/jeton doit être affiché. Ce terme est récupéré dans une application en utilisant la fonction icu_chain_token_display (yaz/icu.h).

transform

Spécifie une règle de transformation ICU à l'aide d'un identifiant de translittérateur. L'attribut rule est l'identifiant du translittérateur. Voir Transformations ICU[1] pour plus d'informations.

transliterate

Spécifie un translittérateur basé sur des règles. L'attribut rule est la règle de transformation personnalisée à utiliser. Voir Transformations ICU[1] pour plus d'informations.

tokenize

Divise / découpe une chaîne en composants en utilisant les fonctions ICU ubrk_open, ubrk_setText, ... . La règle est l'une des suivantes :

l

Ligne. ICU : UBRK_LINE.

s

Phrase. ICU : UBRK_SENTENCE.

w

Mot. ICU : UBRK_WORD.

c

Caractère. ICU : UBRK_CHARACTER.

t

Titre. ICU : UBRK_TITLE.

join

Joint les jetons en une seule chaîne. L'attribut rule est la chaîne de jonction, qui peut être vide. L'élément de conversion join a été ajouté dans YAZ 4.2.49.

EXEMPLES

La commande suivante analyse le texte du fichier text en utilisant la configuration de chaîne ICU chain.xml :

    cat text | yaz-icu -c chain.xml

chain.xml pourrait ressembler à ceci :

<icu_chain locale="en">
  <transform rule="[:Control:] Any-Remove"/>
  <tokenize rule="w"/>
  <transform rule="[[:WhiteSpace:][:Punctuation:]] Remove"/>
  <transliterate rule="xy > z;"/>
  <display/>
  <casemap rule="l"/>
</icu_chain>
