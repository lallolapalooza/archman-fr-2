NOM

yaz-config - Script pour obtenir des informations sur YAZ.

SYNTAXE

yaz-config [--prefix[=DIR]] [--version] [--libs] [--lalibs] [--cflags] [--include] [--comp] [-V] [bibliothèques...]

DESCRIPTION

yaz-config est un script qui renvoie les informations que votre propre logiciel doit utiliser pour compiler un logiciel utilisant YAZ.

Les bibliothèques suivantes sont supportées :

threads

Utilise la version multithread de YAZ.

OPTIONS

--prefix[=DIR]

Renvoie le préfixe de YAZ ou suppose un préfixe différent si DIR est spécifié.

--version

Renvoie la version de YAZ.

--libs

Spécification de la bibliothèque à utiliser lors de l'utilisation de YAZ.

--lalibs

Renvoie la spécification de la bibliothèque.

--cflags

Renvoie les indicateurs du compilateur C.

--include

Renvoie les inclusions du compilateur C pour les fichiers d'en-tête YAZ (-Ichemin).

--comp

Renvoie le chemin complet du compilateur ASN.1 de YAZ : yaz-asncomp.

-V

Renvoie l'identifiant SHA1 de YAZ (depuis Git) et la version.

FICHIERS

/usr/bin/yaz-config

/usr/lib/libyaz*.a

/usr/include/yaz/*.h
