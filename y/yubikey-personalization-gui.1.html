NOM

yubikey-personalization-gui - personnaliser les jetons OTP YubiKey

SYNTAXE

yubikey-personalization-gui

DESCRIPTION

Interface graphique pour la configuration des jetons OTP YubiKey. L'aide est disponible depuis le programme.

BOGUES

Signaler les bogues de yubikey-personalization-gui dans le suivi des problèmes ⟨URL : https://github.com/Yubico/yubikey-personalization-gui/issues ⟩

VOIR AUSSI

Les YubiKeys peuvent être obtenus auprès de Yubico ⟨URL : https://www.yubico.com/ ⟩.
