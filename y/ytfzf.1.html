NOM

ytfzf - rechercher et lire des vidéos

SYNTAXE

ytfzf [options] [requête-de-recherche]
ytfzf [options] -

DESCRIPTION

ytfzf est un script POSIX qui vous aide à trouver des vidéos sur Youtube, Peertube ou Odysee (sans API) et à les ouvrir/télécharger en utilisant mpv/youtube-dl.

OPERATEURS DE RECHERCHE

Les opérateurs de recherche sont des requêtes de recherche spéciales.

Les opérateurs de recherche standard incluent :

:aide
Affiche une description, potentiellement brève, de la manière d'utiliser le scraper.

Les scrapers additionnels peuvent avoir plus ou moins d'opérateurs de recherche.

RACCOURCIS

Ces raccourcis s'appliqueront dans n'importe quel menu qui les prend en charge.
Le seul menu qui les prend actuellement en charge est fzf.
Les raccourcis commençant par alt, quitteront le menu, les raccourcis commençant par ctrl ne le feront pas.
Pour modifier l'un des paramètres par défaut, définissez la variable correspondante dans votre fichier de configuration.

télécharger
alt-d (raccourci_telecharger)
regarder la vidéo
alt-v (raccourci_video)
audio seulement
alt-m (raccourci_audio)
détacher
alt-e (raccourci_detacher)
imprimer le lien
alt-l (raccourci_imprimer_lien)
afficher les formats
alt-f (raccourci_afficher_formats)
afficher toutes les informations
alt-i (raccourci_info)
nouvelle recherche
alt-s (raccourci_rechercher_a_nouveau)
scraper page suivante
ctrl-p (raccourci_action_page_suivante)

OPTIONS

Informations

-h, --aide
Affiche le texte d'aide.
--version
Affiche la version de ytfzf.

Comment lire les vidéos sélectionnées.

-d, --telecharger
Télécharge les vidéos sélectionnées. Ceci peut aussi être défini dans le fichier de configuration avec is_telecharger.
-m, --audio-seulement
Lit l'audio seulement. Ceci peut aussi être défini dans le fichier de configuration avec is_audio_seulement.
-f, --formats
Affiche les formats disponibles avant de continuer.
--selection-formats=ecran
Le type d'écran de sélection de format à utiliser.
Types :
normal
simple
Ceci peut aussi être défini dans le fichier de configuration avec ecran_selection_formats.
--tri-formats=tri
Le --tri-formats à utiliser dans ytdl. Ceci peut aussi être défini dans le fichier de configuration avec tri_selection_formats.
--pref-video=pref
Définit le format vidéo ytdl à pref. Ceci peut aussi être défini dans le fichier de configuration avec pref_video.
--pref-audio=pref
Définit le format audio ytdl à pref. Ceci peut aussi être défini dans le fichier de configuration avec pref_audio.
--pref-ytdl=pref
Définit le format ytdl à pref. Ceci peut aussi être défini dans le fichier de configuration avec pref_ytdl.
--detacher
Détache le lecteur vidéo du terminal. Ceci peut aussi être défini dans le fichier de configuration avec is_detacher.
-u, --gestionnaire-url=gestionnaire
La fonction/programme à utiliser comme gestionnaire d'URL. Ceci peut aussi être défini dans le fichier de configuration en ajoutant charger_gestionnaire_url <gestionnaire>.
-I option
Au lieu de lire les vidéos sélectionnées, obtenir des informations à leur sujet dans le format sélectionné. Les options disponibles sont :
L|l|lien
Imprime l'URL des vidéos sélectionnées.
VJ|vj|video-json
Imprime le json des vidéos sélectionnées.
J|j|json
Imprime le json de toutes les vidéos dans les résultats de recherche.
F|f|format
Imprime le format vidéo utilisé.
R|r|brut
Imprime les données des vidéos sélectionnées, telles qu'elles apparaissent dans le menu.
-L
Alias pour -I L
--action-info=action_info
L'action à effectuer lorsque --attendre-info est à 1. action_attendre_info.
--attendre-info=nombre
Indique s'il faut attendre après avoir imprimé les informations demandées avec -I ou -L. Ceci peut aussi être défini dans le fichier de configuration avec attendre_info.
--opts-gestionnaire-url=opts
Options à passer au gestionnaire d'URL, par défaut cela passera des options supplémentaires à mpv. Ceci peut aussi être défini dans le fichier de configuration avec opts_gestionnaire_url.

Options de menu

-l, --boucle
Rouvre le menu lorsque la vidéo s'arrête. Ceci peut aussi être défini dans le fichier de configuration avec is_boucle.
-s, --rechercher-a-nouveau
Après avoir fermé fzf, effectue une nouvelle recherche. Ceci peut aussi être défini dans le fichier de configuration avec rechercher_a_nouveau.
-t, --afficher-miniatures
Affiche les miniatures. Ne fonctionne pas avec -D ou -H. Ceci peut aussi être défini dans le fichier de configuration avec afficher_miniatures.
--miniatures-asynchrones
Indique s'il faut télécharger les miniatures de manière asynchrone.
Le téléchargement asynchrone ouvrira le menu avant que toutes les miniatures ne soient téléchargées. Ceci peut aussi être défini dans le fichier de configuration avec miniatures_asynchrones.
--ignorer-telechargement-miniatures
Indique s'il faut ignorer le téléchargement des miniatures. Ceci est utilisé si vous ne voulez pas de miniatures, ou si vous voulez utiliser des miniatures personnalisées dans le répertoire $YTFZF_REPERTOIRE_MINIATURES_PERSONNALISEES.
Pour plus d'informations, voir MINIATURES PERSONNALISÉES dans ytfzf(5)
Ceci peut aussi être défini dans le fichier de configuration avec ignorer_telechargement_miniatures.
--notifier-en-cours
Affiche des notifications lorsqu'une vidéo est sur le point d'être lue, et d'autres notifications relatives à la lecture de vidéos. Ceci peut aussi être défini dans le fichier de configuration avec notifier_en_cours.
--cote-apercu=cote
Le côté de l'aperçu dans fzf.
Options :
gauche
droite
haut
bas
Ceci peut également être modifié dans le fichier de configuration avec fzf_preview_side.
-T, --thumb-viewer=programme
Utilise le programme pour afficher les miniatures.
Programmes intégrés :
chafa,chafa-16,chafa-tty
chafa, chafa avec 16 couleurs, chafa avec 4 couleurs.
catimg,catimg-256
catimg, catimg avec 256 couleurs.
imv
Bon avec les gestionnaires de fenêtres en mosaïque.
mpv
Similaire à imv.
swayimg
Fonctionne uniquement sur le compositeur Wayland sway.
swayimg-hyprland
Fonctionne uniquement sur le compositeur Hyprland. Utilise swayimg pour rendre une image.
<personnalisé>
Des visionneuses supplémentaires peuvent être placées dans $YTFZF_THUMBNAIL_VIEWERS_DIR.
Ceci peut également être modifié dans le fichier de configuration en ajoutant
load_thumbnail_viewer <visionneuse>.
-D, --external-menu
Utilise un menu externe au lieu de fzf. La valeur par défaut est dmenu. Ceci peut également être défini dans le fichier de configuration avec interface="ext".
-i, --interface=interface
Utilise un script d'interface personnalisé, qui se trouverait dans $YTFZF_CUSTOM_INTERFACES_DIR. Ceci peut également être défini dans le fichier de configuration en ajoutant load_interface <interface>.
--sort
Trie les vidéos (après le scraping) par date de mise en ligne. Ceci peut également être défini dans le fichier de configuration en ajoutant is_sort.
--sort-name=nom
Appelle une fonction définie dans $YTFZF_CONFIG_FILE. Ou source un script dans $YTFZF_SORT_NAMES_DIR (s'il existe). Voir SORT NAMES dans ytfzf(5) pour plus d'informations.
--fancy-subs
Indique s'il faut avoir un séparateur entre chaque abonnement. Lorsque cette option est utilisée, elle désactive automatiquement --sort car cela perturberait cette option.
Ceci peut également être défini dans le fichier de configuration avec fancy_subs.
--disable-back
Indique s'il faut désactiver le bouton retour dans les sous-menus.
Ceci peut également être défini dans le fichier de configuration avec enable_back_button. --disable-actions Indique s'il faut désactiver les actions telles que les sous-menus et le bouton retour.
Ceci peut également être défini dans le fichier de configuration avec enable_actions.
--disable-submenus
Indique s'il faut désactiver les sous-menus.
Les sous-menus sont les menus qui apparaissent après qu'une playlist ou une chaîne (actuellement uniquement pris en charge par youtube/invidious) a été sélectionnée
Ceci peut également être défini dans le fichier de configuration avec enable_submenus.
--keep-vars
Indique si les options passées à ytfzf doivent également être passées aux sous-menus. Ceci peut également être défini dans le fichier de configuration avec keep_vars.
--submenu-opts=opts
Les options à utiliser dans le sous-menu.
Ceci peut également être défini dans le fichier de configuration avec submenu_opts.
--submenu-scraping-opts=opts
OBSOLÈTE (utilisez --submenu-opts à la place) Fait la même chose que --submenu-opts.
Ceci peut également être défini dans le fichier de configuration avec submenu_scraping_opts.

Sélection automatique

-a, --auto-select
Joue automatiquement le premier résultat.
-A, --select-all
Sélectionne tous les résultats.
-r, --random-select
Joue automatiquement un résultat aléatoire.
-S adresse sed, --select=adresse sed
Joue automatiquement une vidéo spécifique.
Exemples :
2
Sélectionne la deuxième vidéo
$
Sélectionne la dernière vidéo
/^h/
Sélectionne toutes les vidéos commençant par h
-n nombre, --link-count=nombre
Le nombre de vidéos à sélectionner avec -a ou -r.

Scrapers

-c scrapers, --scrape=scrapers
Définit le scraper à utiliser. Plusieurs scrapers peuvent être séparés par une virgule (,). Les scrapers intégrés actuellement pris en charge sont :
youtube|Y
Scrape l'API d'Invidious avec une requête de recherche
youtube-channel
Scrape une chaîne YouTube avec YouTube
invidious-channel
Scrape une chaîne YouTube avec $invidious_instance
Lorsque ce scraper est actif, la requête de recherche est le lien vers une chaîne.
video-recommended|R
Scrape les vidéos recommandées à partir d'un lien vidéo Invidious
youtube-playlist|invidious-playlist
Scrape une playlist YouTube
Lorsque ce scraper est actif, la requête de recherche est le lien vers une playlist.
youtube-trending|T
Scrape l'API d'Invidious pour obtenir les tendances YouTube.
Lorsque ce scraper est actif, la requête de recherche est l'onglet des tendances à scraper.
from-cache
Scrape un scrape précédent qui s'est produit en utilisant --keep-cache depuis le cache enregistré.
M|multi
Utilise ytfzf récursivement pour scraper plusieurs choses avec plusieurs options différentes
Voir ytfzf -c M :help pour plus d'informations
Onglets :
gaming
music
movies
youtube-subscriptions|S|SI
SI Scrape Invidious pour des chaînes au lieu de YouTube. Le scraping de YouTube peut entraîner une limitation de débit.
scrape-list|SL
Utilise votre $YTFZF_SCRAPELIST_FILE comme entrée de scrape et de recherche. Voir "listes de scrapes" ytfzf(5) pour plus d'informations.
peertube|P
odysee|lbry|O
history|H
(Uniquement si $enable_hist est activé)
url|U
Ouvre l'URL dans le lecteur vidéo et quitte
u
Traite l'URL comme un élément et ouvrira fzf, ou le menu externe.
comments
Scrape les commentaires d'un lien vidéo de YouTube
-H, --history
Alias pour -c H.
Scrape le fichier d'historique.
--scrape+=scrapers
Identique à -c, mais conserve également le scraper par défaut.
--scraper-=scrapers
Supprime un scraper de la liste des scrapers à utiliser
--multi-search
Indique s'il faut utiliser la recherche multiple.
Pour utiliser la recherche multiple, séparez chaque recherche par une virgule, cela fonctionne bien lorsque vous utilisez plusieurs scrapers.
Ceci peut également être défini dans le fichier de configuration avec multi_search.
--force-youtube
Lors de l'utilisation du scraper youtube, convertit les liens Invidious en liens YouTube avant de jouer/télécharger.
--force-invidious
Lors de l'utilisation du scraper youtube, utilise l'instance Invidious choisie au lieu de convertir en liens YouTube.

Options des scrapers

Actuellement, --video-duration, --type, --thumbnail-quality, et --features ne s'appliquent qu'au scraper : youtube/Y

--pages=amount
Quantité de pages à scraper sur YouTube/Invidious, et le scraper de commentaires. Ceci peut également être défini dans le fichier de configuration avec pages_to_scrape.
--pages-start=page
La page de départ. Ceci peut également être défini dans le fichier de configuration avec pages_start.
--max-threads=amount
Quantité de threads qui peuvent être utilisés pour scraper la recherche YouTube, les playlists, et les chaînes. (cela ne s'applique pas au scraper d'abonnements).
Ceci peut également être défini dans le fichier de configuration avec max_thread_count.
--single-threaded
Définit max_thread_count à 1, cela a le même effet que de rendre tout mono-thread. (cela ne s'applique pas au scraper d'abonnements).
Ceci peut également être défini dans le fichier de configuration avec max_thread_count=1.
--odysee-video-count=amount
Quantité de vidéos à scraper sur Odysee. Ceci peut également être défini dans le fichier de configuration avec odysee_video_search_count.
--nsfw
Indique s'il faut rechercher des vidéos nsfw.
Fonctionne uniquement avec Odysee/O Ceci peut également être défini dans le fichier de configuration avec nsfw.
--sort-by=sort
Fonctionne avec You T
ube/Y et odysee/O.
Pour utiliser un tri différent pour chaque scrape, utilisez une virgule (,) pour séparer les tris.
Contrairement à --sort, cela se produit pendant la recherche, pas après. Les résultats devraient être triés par :
pertinence
note (youtube uniquement)
date_de_mise_en_ligne
les plus anciens d'abord (odysee uniquement)
nombre_de_vues (youtube uniquement)
--date-mise-en-ligne=intervalle
Fonctionne avec youtube/Y et odysee/O
Pour utiliser une période de tri différente pour chaque scrape, utilisez une virgule (,) pour séparer les dates.
Rechercher des vidéos dans le dernier :
heure
aujourd'hui
semaine
mois
année
--duree-video=duree
Indique s'il faut rechercher des vidéos longues ou courtes. Options possibles :

--type=type
Le type de résultats à obtenir.

--qualite-vignette=qualite
Sélectionne la qualité des vignettes. Options disponibles :

La région (code pays) à rechercher.
Pris en charge par les scrapes youtube/Y et youtube-trending/T

CONFIGURATION

Le comportement par défaut de ytfzf peut être modifié en ajustant le fichier de configuration. Voir ytfzf(5) pour plus d'informations.

MODULES

Il existe quelques types de modules,
interfaces (-i, --interface)
scrapers (-c, --scrape)
noms-de-tri (--sort-name)
afficheur-vignettes (-T, --thumb-viewer)
gestionnaires-urls (-u, --url_handler)
extensions (-e, --ext)

Pour installer un module, placez le module dans $YTFZF_SYSTEM_ADDON_DIR/<type_module>/nom_module

Pour utiliser un module, utilisez l'une des options listées ci-dessus, ou ajoutez
load_interface <interface>
scrape=<scraper>
load_sort_name <nom-de-tri>
load_thumbnail_viewer <afficheur>
load_url_handler <gestionnaire-url>
load_extension <ext>
Dans votre fichier de configuration

3

CACHE

Chaque instance de ytfzf possède son propre répertoire dans $YTFZF_TEMP_DIR. Si $keep_cache est activé, il utilise $cache_dir à la place.
La structure de chaque dossier d'instance ressemble à ceci : (<> représente un espace réservé, ? signifie optionnel)
Si un scraper d'add-on est utilisé, il peut utiliser des fichiers non documentés.

$cache_dir
| -- watch_hist
| -- <recherche>-<pid>
|  | -- created-at
|  | -- searches.list
|  | -- post-scrape
|  | -- <submenu-recherche>-<submenu-pid>?
|  | -- thumbnails?
|  | -- environment
|  | -- tmp
|  |  | -- curl_config
|  |  | -- <scrape>.html
|  |  | -- <scrape>.json
|  |  | -- <scrape>.json.final?
|  |  | -- menu_keypress
|  |  | -- all-ids.list
|  |  | -- downloaded-ids.list
|  | -- ids
|  | -- videos_json

Explication de chaque répertoire/fichier :

created-at
Contient le timestamp Unix de la création du dossier.
searches.list
Une liste de toutes les recherches.
Si --multi-search est activé, chaque recherche est séparée par un saut de ligne.
watch_hist
Le fichier d'historique de visionnage.
<recherche>-<pid>
Le dossier parent d'une instance.
Si aucune recherche n'a été donnée, il utilise le nom "SCRAPE-<scrape>-<pid>" à la place.
post-scrape
Un dossier contenant les fichiers relatifs au scraping d'un résultat sélectionné.
<submenu-recherche>-<submenu-pid>
Créé lorsqu'un sous-menu est ouvert (par exemple, lorsqu'une chaîne/playliste est sélectionnée).
thumbnails
Stocke les miniatures pour l'instance (uniquement avec -t).
environment
Toutes les variables définies et leurs valeurs, dans cette instance de ytfzf.
tmp
Stocke des fichiers temporaires moins importants.
curl_config
Le fichier de configuration de curl pour télécharger les miniatures (uniquement avec -t).
<scrape>.html
Pour les scrapers qui doivent parcourir des sites web, c'est la sortie de curl.
<scrape>.json
Le JSON récupéré à partir d'un site web.
<scrape>.json.final
Le JSON final récupéré à partir d'un site web. (Utilisé lorsque plusieurs threads sont utilisés pour le scraping).
menu_keypress
La touche pressée dans fzf.
all-ids.json
Fichier contenant tous les IDs récupérés. Principalement pour comparer avec downloaded-ids.json.
downloaded-ids.json
Fichier contenant quelles miniatures ont été téléchargées.
ids
Le fichier qui stocke l'ID de chaque vidéo sélectionnée.
videos_json
Le fichier qui stocke un JSON de toutes les vidéos affichées dans fzf.
Ce fichier est très utile pour créer des playlists car il est dans le même format.
