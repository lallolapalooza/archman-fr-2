YACC(1) Commandes utilisateur YACC(1)

NOM

yacc - Générateur d'analyseurs syntaxiques du projet GNU

SYNTAXE

yacc [OPTION]... FICHIER

DESCRIPTION

Yacc (Yet Another Compiler Compiler) est un générateur d'analyseurs syntaxiques. Cette version est un simple wrapper autour de bison(1). Elle passe l'option -y, --yacc pour activer le mode de compatibilité ascendante. Voir bison(1) pour plus d'informations.
