y0(3) Manuel des fonctions de bibliothèque y0(3)

NOM

y0, y0f, y0l, y1, y1f, y1l, yn, ynf, ynl - fonctions de Bessel de seconde espèce

BIBLIOTHÈQUE

Bibliothèque mathématique (libm, -lm)

SYNTAXE

#include <math.h>
double y0(double x);
double y1(double x);
double yn(int n, double x);
float y0f(float x);
float y1f(float x);
float ynf(int n, float x);
long double y0l(long double x);
long double y1l(long double x);
long double ynl(int n, long double x);
Exigences pour les macros de test de fonctionnalité dans glibc (voir feature_test_macros(7)):

y0(), y1(), yn():

    _XOPEN_SOURCE
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _SVID_SOURCE || _BSD_SOURCE

y0f(), y0l(), y1f(), y1l(), ynf(), ynl():

    _XOPEN_SOURCE >= 600
        || (_ISOC99_SOURCE && _XOPEN_SOURCE)
        || /* Depuis glibc 2.19 : */ _DEFAULT_SOURCE
        || /* glibc <= 2.19 : */ _SVID_SOURCE || _BSD_SOURCE

DESCRIPTION

Les fonctions y0() et y1() retournent les fonctions de Bessel de x de seconde espèce d'ordres 0 et 1, respectivement. La fonction yn() retourne la fonction de Bessel de x de seconde espèce d'ordre n.

La valeur de x doit être positive.

Les fonctions y0f(), y1f() et ynf() sont des versions qui acceptent et retournent des valeurs float. Les fonctions y0l(), y1l() et ynl() sont des versions qui acceptent et retournent des valeurs long double.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent la valeur de Bessel de seconde espèce appropriée pour x.

Si x est un NaN, un NaN est retourné.

Si x est négatif, une erreur de domaine se produit, et les fonctions retournent -HUGE_VAL, -HUGE_VALF, ou -HUGE_VALL, respectivement. (POSIX.1-2001 autorise également un retour NaN pour ce cas.)

Si x est 0.0, une erreur de pôle se produit, et les fonctions retournent -HUGE_VAL, -HUGE_VALF, ou -HUGE_VALL, respectivement.

Si le résultat sous-dépasse, une erreur de plage se produit, et les fonctions retournent 0.0

Si le résultat dépasse, une erreur de plage se produit, et les fonctions retournent -HUGE_VAL, -HUGE_VALF, ou -HUGE_VALL, respectivement. (POSIX.1-2001 autorise également un retour 0.0 pour ce cas.)

ERREURS

Voir math_error(7) pour des informations sur la manière de déterminer si une erreur s'est produite lors de l'appel de ces fonctions.

Les erreurs suivantes peuvent se produire :

Erreur de domaine : x est négatif
errno est mis à EDOM. Une exception à virgule flottante non valide (FE_INVALID) est levée.
Erreur de pôle : x est 0.0
errno est mis à ERANGE et une exception FE_DIVBYZERO est levée (mais voir BUGS).
Erreur de plage : le résultat sous-dépasse
errno est mis à ERANGE. Aucune exception FE_UNDERFLOW n'est retournée par fetestexcept(3) pour ce cas.
Erreur de plage : le résultat dépasse
errno est mis à ERANGE (mais voir BUGS). Une exception à virgule flottante de dépassement (FE_OVERFLOW) est levée.

BOGUES

Avant glibc 2.19, ces fonctions diagnostiquaient mal les erreurs de pôle : errno était mis à EDOM au lieu de ERANGE et aucune exception FE_DIVBYZERO n'était levée.

Avant glibc 2.17, errno n'était pas défini pour "erreur de plage : sous-dépassement du résultat".

Dans glibc 2.3.2 et versions antérieures, ces fonctions ne lèvent pas d'exception à virgule flottante non valide (FE_INVALID) lorsqu'une erreur de domaine se produit.
