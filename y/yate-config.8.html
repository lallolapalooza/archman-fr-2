NOM

yate-config - récupérer des métadonnées sur le moteur de téléphonie YATE

SYNOPSIS

yate-config [options]

DESCRIPTION

Le programme yate-config est utilisé pour récupérer des informations sur le moteur YATE installé. Il est généralement utilisé pour compiler et lier des modules contre la bibliothèque du moteur.

Voici un scénario d'utilisation typique dans un Makefile :

module.yate: module.cpp
g++ `yate-config --c-all --ldflags` module.cpp `yate-config --libs`

OPTIONS

Version et chemins

--version
Rapporte la version installée de YATE (au format x.y.z)
--release
Rapporte le statut du code YATE installé (si ce n'est pas une version officielle) et le numéro de version
--config
Retourne le répertoire des fichiers de configuration
--modules
Retourne le répertoire des modules
--share
Retourne le répertoire de base des données partagées
--scripts
Retourne le répertoire des scripts
--skins
Retourne le répertoire de base des skins

Options du compilateur

--cflags
Diverses options du compilateur C++
--includes
Option d'inclusion et chemin vers les fichiers d'en-tête
--c-all
Toutes les options du compilateur - les deux précédentes concaténées

Options du linkeur

--ldflags
Diverses options du linkeur
--libs
Option de bibliothèque et noms des bibliothèques
--ld-all
Toutes les options du linkeur - les deux précédentes concaténées
