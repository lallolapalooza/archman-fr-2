YRD(1) Commandes utilisateur YRD(1)

NOM

yrd - couteau suisse pour cjdns

SYNTAXE

yrd [--aide] <commande> [<arguments>]

DESCRIPTION

yrd est une interface inspirée d'iproute2 pour cjdroute.

OPTIONS

--aide

Affiche l'aide de yrd

COMMANDES

demarrer
Démarre cjdroute et le configure après son démarrage. Les pairs sont tirés de /etc/yrd/peers.d et envoyés au cjdroute en cours d'exécution. Utilisez --attacher pour configurer un cjdroute déjà en cours d'exécution.
a, adresse
Affiche votre adresse cjdns. Utilisez -i pour la formater en adresse IPv6.
n, voisins
Affiche vos voisins avec lesquels vous êtes directement pairé. Utilisez -n pour afficher également leurs voisins. Utilisez -i pour les formater en adresses IPv6.
r, route
Affiche les adresses dans votre nodestore. Utilisez -f pour un comportement de type tailf. Utilisez -i pour les formater en adresses IPv6.
ping
Ping un nœud via cjdns, sans utiliser icmp. Utilisez --switch pour effectuer un ping de type switch ou -c pour spécifier le nombre de pings à envoyer.
top
Beaucoup de couleurs.
mon
Affiche les informations de débogage de cjdroute.

-l, --niveau filtre par niveau de journalisation

-f, --fichier filtre par fichier source

-n, --ligne filtre par numéro de ligne

uplinks
Affiche les liens connus à partir d'un nœud donné sur le réseau.
