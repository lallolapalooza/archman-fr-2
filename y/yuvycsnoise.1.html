NOM

yuvycsnoise - Filtre de bruit spécialisé pour le bruit de séparation NTSC Y/C

SYNTAXE

yuvycsnoise [-t] [-m t|b|i|c] [-S MIN] [-T ERRT[,MAXT]] [-B ERRB[,MAXB]] [-I ERRI[,MAXI]] [-C ERRC[,MAXC]]

DESCRIPTION

Si le matériel de capture vidéo ne dispose que d'un mauvais séparateur Y/C, des bruits apparaissent sur les bandes verticales (en particulier rouge/bleu), qui ressemblent à un damier et s'inversent en luminosité/obscurité toutes les 1 image. yuvycsnoise réduit ce type de bruit.

OPTIONS

yuvycsnoise accepte les options suivantes :

-t
test. Au lieu de réduire le bruit, le bruit sera marqué par un pixel noir.
-m MÉTHODE
(par défaut : tbic).
Sélectionne la méthode. MÉTHODE est une chaîne de caractères dans laquelle chaque caractère représente une méthode.
t : méthode 'triframe' de réduction du bruit de luminance.
b : méthode 'biframe' de réduction du bruit de luminance.
i : méthode 'infield' de réduction du bruit de luminance.
c : réduction du bruit de chrominance. utilise 3 images comme 'triframe'.
-S MIN
(par défaut : 4).
Définit le seuil minimum de différence de luminance/chrominance traité comme du bruit.
-T ERRT[,MAXT]
(par défaut : 32,255).
-B ERRB[,MAXB]
(par défaut : 32,255).
-I ERRI[,MAXI]
(par défaut : 16,255).
-C ERRC[,MAXC]
(par défaut : 12,255).
Définit le seuil de différence de luminance/chrominance pour chaque méthode. ERRx est l'erreur maximale de luminance/chrominance des pixels autour du pixel cible, qui devrait être la même si la cible contient du bruit. MAXx est le seuil maximal de différence de luminance/chrominance du pixel cible par rapport à la luminance/chrominance après réduction du bruit.
