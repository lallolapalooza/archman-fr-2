NOM

yaz-record-conv - Utilitaire de conversion d'enregistrements YAZ

SYNTAXE

yaz-record-conv [-v niveau_log] [config] [nom_fichier...]

DESCRIPTION

yaz-record-conv est un programme qui exerce le sous-système de conversion d'enregistrements. Voir l'en-tête record_conv.h.

OPTIONS

-v niveau

Définit le niveau de LOG à niveau. Le niveau est une séquence de jetons séparés par des virgules. Chaque jeton est un entier ou un élément LOG nommé - l'un des suivants : fatal, debug, warn, log, malloc, all, none.

EXEMPLES

La configuration backend suivante convertit les enregistrements MARC (ISO2709) en XML Dublin-Core.

    <backend name="F" syntax="usmarc">
      <marc inputcharset="marc-8" inputformat="marc" outputformat="marcxml"/>
      <xslt stylesheet="../etc/MARC21slim2DC.xsl"/>
    </backend>

Nous pouvons convertir l'un des enregistrements d'exemple du répertoire de test de YAZ avec :

$ ../util/yaz-record-conv record-conv-conf.xml marc6.marc
<?xml version="1.0"?>
<dc:dc xmlns:dc="http://purl.org/dc/elements/1.1/">
  <dc:title>How to program a computer</dc:title>
  <dc:creator>
    Jack Collins
  </dc:creator>
  <dc:type>text</dc:type>
  <dc:publisher>Penguin</dc:publisher>
  <dc:language>eng</dc:language>
</dc:dc>
