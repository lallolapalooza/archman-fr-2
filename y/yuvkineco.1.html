NOM

yuvkineco - rétablit un film en 2-3 pulldown

SYNOPSIS

yuvkineco [options] [-C CHEMIN]
yuvkineco [options] -O|N CHEMIN

DESCRIPTION

yuvkineco rétablit les images originales non entrelacées, à partir de vidéo NTSC dont la source était un film et qui a été traitée en 2-3 pulldown. Le code d'image par seconde (fps) d'entrée doit être 4 (29.97fps), le code d'image par seconde de sortie peut être sélectionné de 1 (23.97fps) à 4 (29.97fps). Si 2, 3 ou 4 est sélectionné, les images dupliquées subsistent mais elles sont rétablies en non entrelacées. Si l'entrée était non entrelacée, seuls les doublons d'images sont supprimés. La détection d'images entrelacées peut échouer dans des conditions telles que :
Cycle de pull down modifié (montage vidéo).
Pull down de mauvaise qualité.
Scène sans mouvement.
Si -C CHEMIN a été spécifié, yuvkineco écrit la liste du cycle de 2-3 pull down dans le fichier. Vous pouvez éditer ce fichier manuellement et le donner à yuvkineco avec l'option -O ou -N pour corriger une éventuelle erreur du premier appel à yuvkineco. Essayez -C et regardez la liste des cycles.
EXEMPLE #1 : pour un film 24p / automatiquement
lav2yuv 60i.eli | \
yuvkineco -F 1 | yuv2lav -f a -I 0 -o 24p.avi
EXEMPLE #2 : pour un mélange 30p/24p / automatiquement
lav2yuv 60i.eli | \
yuvkineco -F 4 | yuv2lav -f a -I 0 -o 30p.avi
EXEMPLE #3 : pour un film 24p / vérification et réparation
lav2yuv 60i.eli | \
yuvkineco -F 1 -C 60i.23c | \
yuv2lav -f a -I 1 -o take1.avi
glav -F +n take1.avi  # vérifier et éditer 60i.23c
lav2yuv take1.avi | \
yuvkineco -F 1 -N 60i.23c | \
yuv2lav -f a -I 0 -o take2.avi
EXEMPLE #4 : pour un film 24p / vérification et nouvelle tentative
lav2yuv 60i.eli | \
yuvkineco -F 1 -C 60i.23c | \
yuv2lav -f a -I 0 -o take1.avi
glav -F +n take1.avi  # vérifier et éditer 60i.23c
lav2yuv 60i.eli | \
yuvkineco -F 1 -O 60i.23c | \
yuv2lav -f a -I 0 -o take2.avi

OPTIONS

yuvkineco accepte les options suivantes :

-F CODEFPS
Définit le code fps de sortie (par défaut : identique à l'entrée).
-C CHEMIN
Spécifie le nom du fichier de liste de cycles de 2-3 pull down à écrire.
-O CHEMIN
Spécifie le nom du fichier de liste de cycles à lire avec le flux yuv précédent pour retenter.
-N CHEMIN
Spécifie le nom du fichier de liste de cycles à lire avec le nouveau flux yuv pour réparer.
-n NIVEAU
Spécifie le niveau de bruit de l'entrée (par défaut : 10). Cela affecte à la fois la détection du cycle de pulldown et le désentrelacement.
-c SEUIL
Spécifie le seuil pour décider si les images de 2 images sont identiques (par défaut : 4). yuvkineco compare plusieurs images, recherche une paire d'images contenant des images identiques, pour décider quelle image doit être supprimée. Si SEUIL est 0, la paire ayant la plus petite différence sera sélectionnée. Si 16, la sélection se fait parmi les paires dont les différences sont inférieures à la moyenne.
-i PERMILLE
yuvkineco désentrelace chaque image après le processus de rétablissement du 2-3 pulldown, spécifie le pourcentage de pixels désentrelacés pour décider d'utiliser ou non le résultat du désentrelacement (par défaut : 10). Si PERMILLE est 10 et que 1 % ou plus des pixels sont désentrelacés, le résultat du désentrelacement sera utilisé. Si 0, le résultat du désentrelacement sera toujours utilisé. Si 1000, le résultat du désentrelacement ne sera pas utilisé, mais le processus de désentrelacement s'exécutera sur toutes les images. Pour désactiver le processus de désentrelacement, spécifiez une valeur négative.
-u
Définit l'information d'entrelacement dans l'en-tête de la sortie sur inconnu (par défaut : non entrelacé).
