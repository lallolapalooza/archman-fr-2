YAD(1) Commandes utilisateur YAD(1)

NOM

yad - affiche des boîtes de dialogue GTK+ depuis des scripts shell ou la ligne de commande

SYNTAXE

yad [OPTIONS]

DESCRIPTION

YAD est un programme qui affiche des boîtes de dialogue GTK+ et retourne (soit dans le code de retour, soit sur la sortie standard) les entrées de l'utilisateur. Cela vous permet de présenter des informations et de demander des informations à l'utilisateur, à partir de toutes sortes de scripts shell.

YAD est un fork du programme Zenity.

OPTIONS

Ce programme suit la syntaxe habituelle des lignes de commande GNU, avec des options longues commençant par deux tirets (`-').

Options générales

Définit l'icône de la fenêtre.

Définit la largeur de la fenêtre de dialogue.

Définit la position X de la fenêtre de dialogue. NOMBRE peut être négatif.
--posy=NOMBRE
Définit la position Y de la fenêtre de dialogue. NOMBRE peut être négatif.

Utilise la notation de géométrie standard de X Window pour placer la boîte de dialogue. Lorsque cette option est utilisée, les options width, height, posx, posy, mouse et center sont ignorées.

Définit le délai d'expiration de la boîte de dialogue en secondes.
--timeout-indicator=POSITION
Affiche un indicateur de délai d'expiration dans la position donnée. Les positions sont top, bottom, left ou right. Le style de l'indicateur peut être défini via les styles CSS de l'utilisateur.
--kill-parent=[SIGNAL]
Envoie le SIGNAL au processus parent. La valeur par défaut de SIGNAL est SIGTERM. SIGNAL peut être spécifié par son numéro ou son nom symbolique avec ou sans préfixe SIG. Voir signal(7) pour plus de détails sur les signaux.
--print-xid=[FICHIER]
Affiche l'ID de la fenêtre X de la fenêtre yad dans le fichier spécifié ou sur stderr.
--plug=CLÉ
Exécute la boîte de dialogue en mode greffon pour l'intégration comme onglet dans un carnet. Voir la section CARNET pour plus d'informations.
--tabnum=NOMBRE

--text=CHAÎNE
Définit le texte de la boîte de dialogue.
--text-width=NOMBRE
Définit la largeur maximale du texte de la boîte de dialogue en caractères.
--text-align=TYPE
Définit le type de justification du texte de la boîte de dialogue. TYPE peut être left, right, center ou fill.
--image=IMAGE
Définit l'image de la boîte de dialogue qui apparaît sur le côté gauche du texte de la boîte de dialogue. IMAGE peut être un nom de fichier ou un nom d'icône du thème d'icônes actuel.
--icon-theme=THÈME
Utilise le thème d'icônes GTK spécifié au lieu du thème par défaut.
--keep-icon-size
Ne pas redimensionner les icônes. Cette option affecte les icônes en dehors du thème d'icônes.
--expander=[TEXTE]
Masque le widget principal avec un expandeur. TEXTE est un argument optionnel avec l'étiquette de l'expander.
--button=BOUTON:ID
Ajoute le bouton de la boîte de dialogue. Peut être utilisé plusieurs fois. ID est un code de sortie ou une commande. BOUTON peut être un nom d'élément stock de yad pour les boutons prédéfinis (comme yad-close ou yad-ok) ou du texte sous la forme LIBELLÉ[!ICÔNE[!INFO-BULLE]] où `!' est un séparateur d'éléments. La liste complète des éléments stock se trouve dans la section ÉLÉMENTS STOCK. Si aucun bouton n'est spécifié, les boutons OK et Annuler sont utilisés. Voir la section CODE DE RETOUR pour plus d'informations. Si ID a une valeur non numérique, il est traité comme une commande et cliquer sur un tel bouton ne ferme pas la boîte de dialogue.
--no-buttons
Ne pas afficher de boutons.
--buttons-layout=TYPE
Définit le type de disposition des boutons. Les types possibles sont : spread, edge, start, end ou center. Par défaut, c'est end.

Ne pas utiliser de balisage pango dans le texte de la boîte de dialogue.
--no-escape

Affiche le résultat pour n'importe lequel des codes de retour. Cette option ne fonctionne pas si le délai d'expiration a été atteint ou si la touche Échap a été pressée.

--uri-handler=CMD
Utilise CMD comme gestionnaire d'URI. Par défaut, yad utilise le paramètre open-command des paramètres. L'URI remplace %s dans la chaîne de commande.

--borders=NUM

--sticky
Rend la fenêtre visible sur tous les bureaux.
--fixed

Place la fenêtre sous le curseur de la souris.

Exécute la fenêtre de dialogue en mode maximisé.
--fullscreen
Exécute la fenêtre de dialogue en mode plein écran. Cette option peut ne pas fonctionner sur tous les gestionnaires de fenêtres.
--splash (Obsolète)
Ouvre la fenêtre avec les indications de fenêtre "écran de démarrage". Pour plus de détails, voir la description de _NET_WM_WINDOW_TYPE_SPLASH dans la spécification EWMH. Le comportement du dialogue avec cette option dépend FORTEMENT des paramètres de votre gestionnaire de fenêtres.

Crée une fenêtre avec le type de fenêtre spécifié. TYPE peut être l'un des suivants : normal, dialog, utility, dock, desktop, tooltip, notification ou splash. Le comportement de chaque type de fenêtre dépend de votre gestionnaire de fenêtres. Voir la spécification EWMH pour plus de détails.

NOTE : Les gestionnaires de fenêtres en mosaïque considéreront souvent une fenêtre "dialog" comme flottante, mais une fenêtre "normal" comme carrelée.

Ferme la fenêtre de dialogue lorsqu'elle perd le focus.

Si activé, l'utilisateur peut sélectionner le texte du dialogue et le copier dans le presse-papiers. Cette option affecte également les champs de libellé dans le dialogue de formulaire.

Ajoute le chemin spécifié à la liste standard des répertoires pour la recherche d'icônes. Cette option peut être utilisée plusieurs fois.

Lit les arguments supplémentaires à partir du fichier donné au lieu de la ligne de commande. Chaque ligne d'un fichier est traitée comme un argument unique.

Définit le code de sortie par défaut à NUMBER au lieu de 0.

Lit et analyse des styles CSS GTK+ supplémentaires à partir des données fournies. Si STRING est un nom de fichier, le contenu du fichier est chargé. Sinon, STRING est traité comme des données CSS.

Lit et analyse des styles CSS GTK+ supplémentaires à partir du fichier donné. Cette option est obsolète. Utilisez --css à la place.
--hscroll-policy=TYPE
Définit le type de politique pour les barres de défilement horizontales. TYPE peut être auto, always ou never. La valeur par défaut est auto.
--vscroll-policy=TYPE
Définit le type de politique pour les barres de défilement verticales. TYPE peut être auto, always ou never. La valeur par défaut est auto.
--enable-spell

--spell-lang=LANGUAGE
Définit la langue de la vérification orthographique à LANGUAGE. Par défaut, la langue est devinée à partir des paramètres régionaux actuels. Utilisez yad-tools(1) pour obtenir la liste de toutes les langues possibles.
--bool-fmt=TYPE
Définit le type de sortie des valeurs booléennes à TYPE. Les types possibles sont T, t, Y, y, O, o et 1.
T et t - pour la paire true/false dans la casse appropriée.
Y et y - pour la paire yes/no dans la casse appropriée.
O et o - pour la paire on/off dans la casse appropriée.
1 - pour la paire 1/0.

Options de sélection d'application

Afficher les applications de repli.

Afficher les autres applications.

Afficher des informations étendues sur l'application choisie. Par défaut, seul l'exécutable est affiché. Sous forme étendue, les champs de sortie sont le nom, le nom d'affichage, la description, l'icône et l'exécutable.

Options de calendrier

--day=NUMBER
Définit le jour du calendrier.
--month=NUMBER
Définit le mois du calendrier.
--year=NUMBER
Définit l'année du calendrier.
--date-format=PATTERN
Définit le format de la date retournée. Par défaut, c'est `%x`. Voir strftime(3) pour plus de détails.
--show-weeks
Affiche les numéros de semaine sur le côté gauche du calendrier.

Lit la description des jours à partir de FILENAME.

Le fichier contenant les détails des jours doit être au format suivant :

<date> <description>

Le champ date est la date au format spécifié par l'option --date-format. La description est une chaîne contenant les détails de la date, qui peut inclure du balisage Pango.

Options de saisie de texte

--entry-label=STRING
Définit le texte de l'étiquette de saisie.
--entry-text=STRING
Définit le texte initial de la saisie ou l'élément par défaut dans un menu déroulant.
--hide-text
Masque le texte de la saisie.
--completion
Utilise la complétion au lieu d'un menu déroulant.
--complete=TYPE
Utilise un type spécifique pour la complétion étendue. TYPE peut être any pour correspondre à n'importe quel mot tapé, all pour correspondre à tous les mots tapés ou regex lorsque le texte tapé est traité comme une expression régulière.
--editable
Permet de modifier le texte dans le menu déroulant.
--numeric
Utilise un bouton de sélection numérique au lieu d'une saisie de texte. Les paramètres supplémentaires sur la ligne de commande sont traités comme la valeur minimale, la valeur maximale, la valeur de pas et la précision (dans cet ordre). Toutes ces valeurs sont facultatives. La plage par défaut est de 0 à 65535 avec un pas de 1.
--float-precision=NUMBER
Définit la précision des nombres à virgule flottante. Par défaut, la précision est de trois chiffres après la virgule.
--licon=IMAGE
Définit une icône sur le côté gauche de la saisie.
--licon-action=CMD
Spécifie une commande qui sera exécutée lorsque l'icône de gauche est cliquée. La sortie de la commande sera définie comme texte de saisie.
--ricon=IMAGE
Définit une icône sur le côté droit de la saisie.
--ricon-action=CMD
Spécifie une commande qui sera exécutée lorsque l'icône de droite est cliquée. La sortie de la commande sera définie comme texte de saisie.
--num-output
Affiche l'index de l'élément actif au lieu du texte pour une saisie de type menu déroulant.

Toute donnée supplémentaire spécifiée sur la ligne de commande est ajoutée comme éléments de la saisie de type menu déroulant, sauf en mode numérique.

Si une icône est spécifiée et qu'une action d'icône n'est pas fournie, un clic sur l'icône efface simplement la saisie. Les champs numériques ignoreront les icônes.

Options de formulaire

--field=LABEL[!TOOLTIP][:TYPE]
Ajoute un champ au formulaire. Le type peut être H, RO, NUM, CHK, CB, CBE, CE, FL, SFL, DIR, CDIR, FN, MFL, MDIR, DT, SCL, SW, APP, ICON, CLR, BTN, FBTN, LINK, LBL ou TXT.
H - type de champ caché. Tous les caractères sont affichés comme des caractères invisibles.
RO - le champ est en lecture seule.
NUM - le champ est numérique. Le format de la valeur initiale pour ce champ est VALEUR[!PLAGE[!PAS![PREC]]], où PLAGE doit être sous la forme MIN..MAX. `!' est le séparateur d'éléments par défaut. PREC est la précision pour les décimales.
CHK - champ de case à cocher. La valeur initiale est une constante booléenne insensible à la casse (TRUE ou FALSE).
CB - champ de menu déroulant. La valeur initiale est une liste VAL1!VAL2!.... Le séparateur est le même que pour le champ NUM. Les valeurs commençant par `^' sont traitées comme la valeur par défaut du menu déroulant.
CBE - champ de menu déroulant éditable. La valeur initiale est la même que pour le menu déroulant.
CE - saisie avec complétion. La valeur initiale est la même que pour le menu déroulant.
FL - bouton de sélection de fichier.
SFL - champ pour créer un fichier.
DIR - bouton de sélection de répertoire.
CDIR - champ pour créer un dossier.
FN - bouton de sélection de police. La valeur initiale est la même que dans la boîte de dialogue des polices.
MFL - sélection de plusieurs fichiers. La valeur de ce champ est une liste de fichiers séparés par le séparateur d'éléments.
MDIR - sélection de plusieurs répertoires. La valeur de ce champ est une liste de répertoires séparés par le séparateur d'éléments.
DT - champ de date.
SCL - champ de curseur. La valeur de ce champ est comprise entre 0 et 100.
SW - champ de commutateur. La valeur initiale est une constante booléenne insensible à la casse (TRUE ou FALSE).
APP - bouton de sélection d'application. La valeur d'entrée pour ce champ est un type mime. La valeur de sortie est l'exécutable de l'application sélectionnée.
ICON - champ d'icône. Comme un champ de saisie moyen mais avec deux icônes. L'icône de gauche affiche l'icône actuelle et celle de droite est cliquable et appelle yad-con-browser pour choisir une icône.
CLR - bouton de sélection de couleur. Les valeurs de sortie pour ce champ sont générées de la même manière que pour la boîte de dialogue des couleurs.
BTN - champ de bouton. L'étiquette peut être sous la forme de texte dans un formulaire LABEL[!ICON[!TOOLTIP]], où `!' est un séparateur d'éléments. LABEL est le texte de l'étiquette du bouton ou un identifiant de stockage yad. ICON est l'icône du bouton (identifiant de stockage ou nom de fichier). TOOLTIP est un texte facultatif pour une aide contextuelle. La valeur initiale est une commande qui est exécutée lorsque le bouton est cliqué. Les symboles spéciaux %N dans la commande sont remplacés par la valeur du champ N. Si la commande commence par @, la sortie de la commande sera analysée et les lignes commençant par un nombre suivi d'un deux-points seront traitées comme de nouvelles valeurs de champ. Le style de quotation pour la valeur lorsque sh -c est utilisé est des guillemets simples autour de la commande et des guillemets doubles autour de l'argument -c.
FBTN - identique au champ bouton, mais avec un relief complet du bouton.
LINK - champ de bouton de lien.

Add a filename filter. NAME is a displayed filter name, PATTERN is a shell-style filename pattern (for example *.txt). This option may be used multiple times.
--mime-filter=NAME | MIME1 MIME2 ...
Add a mime-type filter. NAME is a displayed filter name, PATTERN is a name of mime type (for example text/plain). This option may be used multiple times.
--image-filter=[NAME]
Add filter for images supported by gdk-pixbuf library. NAME in as optional name for this filter.
This options applies to all of yad's file chooser dialogs.

File preview options

--add-preview
Add preview widget. Preview images loads from normal (default) or large thumbnails according to XDG Thumbnails specification v0.8.0 (http://standards.freedesktop.org/thumbnail-spec/latest/) or creates by yad for image files and saves as normal or large thumbnails.
--large-preview
Use large previews by default. This option can be permanently turned on through yad settings.
This options applies to all of yad's file chooser dialogs.
NOTE: YAD doesn't check mtime for thumbnailed images and doesn't updates preview if origial file was changed after thumbnail was created.

Miscellaneous options

-?, --help
Show summary of options.
--about
Display an about dialog.
--version
Show version of program.

Also the standard GTK+ options are accepted.

NOTEBOOK and PANED

Notebook is a complex dialog which swallow other dialogs in his tabs. Dialogs identifies by unique key (integer) and must be runs in a special plug mode (--plug option). Following example runs notebook dialog with two tabs, first has a simple text and second is an entry dialog.

#! /bin/sh

yad --plug=12345 --tabnum=1 --text="first tab with text" &> res1 &
yad --plug=12345 --tabnum=2 --text="second tab" --entry &> res2 &
yad --notebook --key=12345 --tab="Tab 1" --tab="Tab 2"

NOTE: The order of output results for tabs is undefined!

Paned works in a same manner as a notebook with one restriction - only first and second plug dialogs will be swallowed to panes.

NOTIFICATION

Allows commands to be sent to yad in the form command:args. Possible commands are icon, tooltip, visible, action, menu and quit.

icon:ICONNAME
Set notification icon to ICONNAME.
tooltip:STRING
Set notification tooltip.
visible:[true|false]
Set notification icon to visible or invisible state.
action:COMMAND
Specify the command running when click on the icon. There are two special commands - menu for popup user defined menu and quit for exit the program.
menu:STRING
Set popup menu for notification icon. STRING must be in form name1[!action1[!icon1]]|name2[!action2[!icon2]].... Empty name add separator to menu. Separator character for values (e.g. `|') sets with --separator argument. Separator character for menu items (e.g. `!') sets with --item-separator argument.
quit
Exit the program. Middle click on icon also send quit command.

ENVIRONMENT VARIABLES

YAD_OPTIONS
This variable can holds some default options for yad. All options in this variable may be redefined from command line.
YAD_PID
This variable sets to the value of current dialog's pid and accessible in all dialog children.
YAD_XID
This variable sets to the value of current dialog's X Window ID and accessible in all dialog children. This variable is not set in print and notification dialogs, and in a dialogs which acts as a notebook or paned children.

USER DEFINED SIGNALS

SIGUSR1
Close dialog with 0 exit code.
SIGUSR2
Close dialog with 1 exit code.

EXIT STATUS

0
The user has pressed OK button
1
The user has pressed Cancel button
70
The dialog has been closed because the timeout has been reached.
252
The dialog has been closed by pressing Esc or used the window functions to close the dialog
Exit codes for user-specified buttons must be specified in command line. Even exit code mean to print result, odd just return exit code.

RÉGLAGES

YAD conserve les réglages dans la base de données gsettings. Utilisez gsettings list-keys yad.settings pour obtenir la liste des réglages disponibles. Les valeurs des réglages peuvent être obtenues par gsettings get yad.settings <clé> et modifiées par gsettings set yad.settings <clé> <nouvelle-valeur>

EXEMPLES

Affiche un sélecteur de fichiers avec le titre Sélectionner un fichier à supprimer. Le fichier sélectionné est renvoyé sur la sortie standard.

yad --title="Sélectionner un fichier à supprimer" --file-selection

Affiche une boîte de dialogue d'entrée de texte avec le titre Sélectionner l'hôte et le texte Sélectionnez l'hôte que vous souhaitez pinger intensivement. Le texte saisi est renvoyé sur la sortie standard.

yad --title "Sélectionner l'hôte" --entry --text "Sélectionnez l'hôte que vous souhaitez pinger intensivement"

Affiche une boîte de dialogue demandant Microsoft Windows a été trouvé ! Souhaitez-vous le supprimer ?. Le code de retour sera 0 (vrai dans le shell) si OUI est sélectionné, et 1 (faux) si NON est sélectionné.

yad --image "dialog-question" --title "Alerte" --button=gtk-yes:0 --button=gtk-no:1 --text "Microsoft Windows a été trouvé ! Souhaitez-vous le supprimer ?"

Affiche les résultats de la recherche dans une boîte de dialogue de liste avec le titre Résultats de la recherche et le texte Recherche de tous les fichiers d'en-tête....

find . -name '*.h' | yad --list --title "Résultats de la recherche" --text "Recherche de tous les fichiers d'en-tête..." --column "Fichiers"

Affiche une icône dans la zone de notification

yad --notification --image=update.png --text "Mise à jour du système nécessaire !" --command "xterm -e apt-get upgrade"

Affiche une liste de courses hebdomadaire dans une boîte de dialogue de liste de contrôle avec Pommes et Oranges présélectionnées.

yad --list --checklist --column "Acheter" --column "Article" TRUE Pommes TRUE Oranges FALSE Poires FALSE Dentifrice

Affiche une boîte de dialogue de progression lors de la recherche de tous les fichiers postscript dans votre répertoire personnel.

find $HOME -name '*.ps' | yad --progress --pulsate

Affiche une boîte avec toutes les applications de bureau installées.

yad --icons --read-dir=/usr/share/applications

Affiche une liste en mode arborescence.

yad --list --tree --column "Articles" f Fruits 1:f Pomme 2:f Citron v Légumes 3:v Pomme de terre 4:o Oignon

DÉVELOPPEMENT

YAD propose certaines fonctionnalités pour les développeurs.

Le navigateur d'icônes YAD est un outil graphique permettant de découvrir les icônes dans un thème d'icônes GTK+ actuel ou spécifié par l'utilisateur. Lancez-le comme suit :
yad-icon-browser [thème]

Lorsque vous utilisez autoconf, vous pouvez utiliser la macro m4 spéciale AM_PATH_YAD pour rechercher yad et vérifier sa version. L'utilisation de cette macro est la suivante :

AM_PATH_YAD([VERSION-MINIMALE],\ [ACTION-SI-TROUVÉ],\ [ACTION-SI-NON-TROUVÉ])
