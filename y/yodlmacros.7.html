NOM

yodlmacros - Macros pour les convertisseurs Yodl

SYNOPIS

Cette page de manuel liste les macros standard du paquet Yodl.

DESCRIPTION

La liste suivante montre les macros définies par les convertisseurs Yodl et qui peuvent être utilisées dans les documents Yodl. Référez-vous au guide de l'utilisateur Yodl, distribué avec le paquet Yodl, pour une description complète.

La liste suivante montre toutes les macros du paquet par ordre alphabétique.

`abstract(texte)’
Définit un résumé pour un article ou un rapport. Les résumés ne sont pas implémentés pour les livres ou les pages de manuel. Doit apparaître avant le début du document en utilisant la macro `article' ou `report'.
`addntosymbol(symbole)(n)(texte)’
Ajoute `texte' `n' fois à `symbole'. La valeur `n' peut aussi être le nom d'un compteur défini (qui n'est pas modifié).
`affiliation(site)’
Définit une affiliation, à faire apparaître sur la page de titre du document sous le champ auteur. Doit apparaître avant le début du document avec `article', `report' ou `book'. L'affiliation n'est imprimée que lorsque le champ auteur n'est pas vide. Lors de la conversion en html, la manière dont l'affiliation est affichée peut être ajustée à l'aide de spécifications de sélecteurs d'ID CSS. L'affiliation a `id="affiliation"'.
`AfourEnlarged()’
Agrandit la hauteur utilisable du papier A4 de 2 cm : la marge supérieure est réduite de 2 cm. Cette macro doit être appelée dans le préambule. La macro n'est disponible que pour les conversions LaTeX.
Cette macro est quelque peu obsolète. Il est plutôt conseillé d'utiliser `PageEnlarged'.
`appendix()’
Démarre les appendices.
`article(titre)(auteur)(date)’
Démarre un article. La commande de sectionnement de niveau supérieur est `(n)sect'. Dans les conversions HTML, un seul fichier de sortie est écrit, tandis que la manière dont les en-têtes sont affichés peut être ajustée à l'aide de spécifications de sélecteurs d'ID CSS : le titre a `id="title"', l'auteur `id="author"', et la date `id="date"'.
`attrib(texte)’
En html, insère `texte' comme attribut pour la prochaine balise html supportant `attrib'. Par exemple, pour définir une couleur bleue et une marge gauche de 30 pixels pour une section, utilisez 
    attrib(style="color:blue;margin-left:30px;")\ 
    sect(Nom de la section)
Ceci résulte en le balisage html 
    <h1 style="color:blue;margin-left:30px;">Nom de la section</h1>
Cette macro n'est effective qu'avec les conversions html. Elle est appliquée de manière empilée : lorsque plusieurs appels `attrib' sont utilisés, la chaîne d'attributs la plus haute est ajoutée à la première macro appelant la macro `attribinsert', les macros suivantes utilisant les éléments suivants de la pile d'attributs.
Les attributs couramment utilisés sont `id="idname"', attendant un label CSS `#idname' dans des spécifications CSS internes ou externes, ou `style="spécification"' (comme montré dans l'exemple).
Exemple : lors de l'utilisation de 
    attrib(width = "100" height = "100")
    attrib(id = "#fig")
    figure(fichierimg)(Légende)(IMG)
alors l'attribut `#id' est appliqué à `<figure>', et les attributs `width' et `height' sont appliqués à `<img>', dont le balisage html est inséré par la macro `figure'.
La macro `attrib' est supportée par les macros prédéfinies suivantes (entre parenthèses le nombre de chaînes d'attributs insérées par ces macros ; s'il n'y a qu'une seule chaîne d'attribut insérée, aucun nombre n'est affiché) :
`bf cell cells center chapter code dashes dit em figure(3) file htmltag itdesc lheader lchapter link lref lsect lsubsect lsubsubsect nchapter npart nsect nsubsect nsubsubsect paragraph part quote row sc sect strong subs subsect subsubsect subsubsubsect sups tableatt tbl tac tc tnac tnc tr tt ttbegin url verb verborg verbinclude'.
`attribclear()’
Supprime tout contenu existant de la pile d'attributs. Cette macro n'est active que lors de la conversion en html.
`attribinsert()’
En html, si la pile d'attributs n'est pas vide, insère la valeur au sommet de la pile d'attributs puis retire la valeur supérieure. Si la pile d'attributs est vide, rien ne se passe.
`bf(texte)’
Met `texte' en gras.
`bind(texte)’
Génère un espace insécable après le texte.
`book(titre)(auteur)(date)’
Démarre un document de type livre. La commande de sectionnement de niveau supérieur est `(n)chapter', `(n)part' étant optionnel. Dans la sortie HTML, des fichiers sont créés pour chaque chapitre, tandis que la manière dont les en-têtes sont affichés peut être ajustée à l'aide de spécifications de sélecteurs d'ID CSS : le titre a `id="title"', l'auteur `id="author"', et la date `id="date"'.
`cell(contenu)’
Définit une cellule de tableau, c'est-à-dire un élément dans une ligne. Avec les convertisseurs man/ms, plusieurs espaces entre les appels de la macro `cell()' sont fusionnés en un seul espace.
Au lieu d'utiliser `cell' dans `table', envisagez d'utiliser `tc' dans `tbl'.
`cells(nColonnes)(contenu)’
Définit une cellule de tableau s'étendant sur `nColonnes' colonnes. Avec LaTeX et xml, les informations des cellules combinées sont centrées.
Avec les conversions man/ms, la macro `cells()' appelle simplement la macro `cell()', mais ici la macro `setmanalign()' peut être utilisée pour déterminer l'alignement de plusieurs cellules.
Avec html, la macro `attrib' peut être utilisée, mais si elle contient une spécification `style', le `style="text-align: center"' par défaut de la macro est ignoré (mais il peut être spécifié optionnellement en utilisant la macro `attrib').
Au lieu d'utiliser `cells' dans `table', envisagez d'utiliser `tnc' dans `tbl'.
`cellsline(depuis)(compte)’
Définit une ligne horizontale commençant à la colonne numéro `depuis' sur `compte' colonnes dans une ligne. Si `depuis' est inférieur au nombre de colonnes déjà ajoutées à une ligne, il est ignoré. Cette macro doit être intégrée dans une macro `row' définissant une ligne de tableau. Pour mettre une ligne sur toute la largeur du tableau, utilisez `rowline'. Pour définir des lignes horizontales sur les colonnes 1 à 2 et 4 à 5 d'un tableau, utilisez 
    row(cellsline(1)(2)cellsline(4)(2))
La combinaison de `cellsline()' et des appels `cell()' ou `cells()' dans une même ligne produit des résultats indéfinis.
Au lieu d'utiliser `cellsline' dans `table', envisagez d'utiliser `tline' dans `tbl'.
`center(texte)’
Centre `texte'. Utilisez `nl()' dans le texte pour sauter des lignes. En html, la macro `attrib' n'est pas supportée, mais une division (`div') avec la définition de style `text-align: center' est utilisée. Pour centrer un tableau en html, utilisez la macro `tableatt'. Si une macro `table' ou `tableatt' est utilisée à l'intérieur d'une macro `center', alors le contenu des colonnes est centré colonne par colonne.
Dans un contexte `center(...)', le compteur `XXcenter' est différent de 0.
`chapter(titre)’
Démarre un nouveau chapitre dans les livres ou les rapports.
`cindex()’
Génère une entrée d'index pour les c-indices LaTex() ou texinfo. Son argument est l'entrée d'index. Voir aussi la macro `[fptv]index'.
`cite(texte)’
Définit `texte' comme citation ou référence.
`clearpage()’
Démarre une nouvelle page, lorsque le format de sortie le permet. Sous HTML, une ligne horizontale est dessinée.
`code(texte)’
Met `texte' en police de code, et empêche son expansion. Pour les listes de paramètres déséquilibrées, utilisez `CHAR(40)' pour obtenir `(' et `CHAR(41)' pour obtenir `)'.
`columnline(depuis)(jusqu'à)’
Définit une ligne horizontale sur certaines colonnes dans une ligne. Notez que `columnline' définit une ligne par elle-même, consistant seulement en une ligne horizontale s'étendant sur certaines de ses colonnes, plutôt que sur toute la largeur du tableau, comme `rowline'. Les deux arguments représentent des numéros de colonne. Il incombe à l'auteur de s'assurer que les valeurs `depuis' et `jusqu'à' sont sensées. C'est-à-dire, 
    1 <= depuis <= jusqu'à <= ncolonnes
Pour définir une ligne horizontale dans une seule colonne, sélectionnez `jusqu'à' égal à `depuis'.

Ce site n'est en aucun cas associé à Arch Linux ni affilié à ce projet. Le contenu est uniquement une traduction des pages de manuel d'Arch publiées sur man.archlinux.org.

>: cette macro ne peut pas être utilisée si plusieurs lignes doivent être définies dans une seule ligne. Dans ces cas, les macros `tline, tskip’ et `tendline’ doivent être utilisées.
Au lieu d'utiliser `columnline’ dans `table’, considérez l'utilisation de `tline’ dans `tbl’.
`dashes()’
Insère deux tirets en police télétype, et empêche leur expansion.
En HTML, la macro `attrib’ est reconnue par la balise `<code>’ qui est utilisée pour intégrer les deux tirets.
`def(macroname)(nrofargs)(redefinition)’
Définit `macroname’ comme une macro, ayant `nrofargs’ arguments, et s'étendant à `redefinition’. Cette macro est un raccourci pour `DEFINEMACRO’. Une erreur se produit lorsque la macro est déjà définie. Utilisez `redef()’ pour définir ou redéfinir inconditionnellement une macro.
`description(list)’
Définit `list’ comme une liste de description. Utilisez `dit(item)’ pour indiquer les éléments de la liste.
`dit(itemname)’
Démarre un élément nommé `itemname’ dans une liste de description. La liste doit être utilisée dans les macros `description’. Avec les conversions `html’, le contenu d'un élément de description est séparé de l'élément lui-même. La macro `dit’ définit uniquement l'élément, et non la description elle-même. Cette macro définit l'élément en gras (`strong’). La macro `itdesc’, disponible depuis Yodl 3.05, peut être utilisée pour définir un élément et sa description, en utilisant son format suggéré (c'est-à-dire en décalant la description par rapport à l'élément).
`eit()’
Indique un élément dans une liste numérotée. La macro `eit’ doit être utilisée comme argument dans les macros `enumeration’.
`ellipsis()’
Définit les points de suspension (...).
`em(text)’
Définit `text’ comme accentué, généralement en italique.
`email(address)’
En HTML, cette macro place l'`address’ dans un localisateur `<a href="mailto=..">’. Dans d'autres formats de sortie, l'`address’ est envoyée à la sortie. La macro `email’ est un cas spécial de `url’.
`enumeration(list)’
`enumeration()’ démarre une liste numérotée. Utilisez `eit()’ dans la liste pour indiquer les éléments de la liste.
`euro()’
Définit le symbole de la monnaie euro en latex, html, (et potentiellement sgml et xml). Dans toutes les autres conversions, EUR, qui est l'abréviation textuelle officielle (cf. http://ec.europa.eu/euro/entry.html), est affiché. Notez que LaTeX peut nécessiter le paquet latexpackage()(eurosym).
`evalsymbol(symbol)(expression)’
Le symbole symbol reçoit la valeur résultant de l'évaluation de expression. Par exemple, si `sym’ est un symbole défini, alors 
    evalsymbol(sym)(SUBSTR(hello world)(3)(2))
assigne la valeur `lo’ à `sym’.
`fig(label)’
Cette macro est un raccourci pour `figure ref(label)’ et rend simplement la frappe plus courte, comme dans `voir fig(schematic) pour ..’ Voir `getfigurestring()’ et `setfigurestring()’ pour le texte `figure’.
`figure(file)(caption)(label)’
Définit l'image dans `file’ comme une figure dans le document courant, en utilisant le texte descriptif `caption’. Le `label’ est défini comme un espace réservé pour le numéro de figure et peut être utilisé dans une instruction `ref’ correspondante. Notez que `file’ doit être le nom de fichier sans extension : Par défaut, Yodl ajoutera `.gif’ en mode HTML, ou `.ps’ en mode LaTeX. Les figures dans d'autres modes peuvent ne pas (encore) avoir été implémentées.
Lors de la conversion en html, cette macro utilise trois chaînes d'attributs (si disponibles). La chaîne poussée en premier à l'aide d'un appel d'attrib définit les attributs pour son balisage html `<figcaption>’; la chaîne poussée ensuite définit les attributs pour son balisage html `<img>’; la chaîne poussée en dernier définit les attributs pour son balisage html `<figure>’. La sortie html de la macro `figure’ est organisée comme suit : 
    <figure -chaîne d'attribut poussée en dernier (si présente)>
        <img ... -chaîne d'attribut poussée avant-dernière>
        <figcaption -chaîne d'attribut poussée avant-dernière>
            ...
        </figcaption>
    </figure>
À partir de Yodl 3.07.00, plus aucun attribut `alt="La Figure # est affichée ici..."’ n'est défini pour le balisage `img’ : un attribut `alt’ peut être facilement défini lors du dernier appel d'attribut, en utilisant `getfigurestring()’ pour obtenir `Figure’ ou sa traduction dans la langue appropriée, et `COUNTERVALUE(XXfigurecounter)’ pour obtenir le numéro d'ordre de la figure affichée dans le prochain appel de macro `figure’.
`file(text)’
Définit `text’ comme nom de fichier, généralement en gras. En HTML, la macro `attrib’ s'applique à la balise `<strong>’.
`findex()’
Génère une entrée d'index pour les indices f de LaTex() ou texinfo. Son argument est l'entrée d'index. Voir aussi la macro `[cptv]index’.
`footnote(text)’
Définit `text’ comme une note de bas de page, ou entre parenthèses lorsque le format de sortie ne permet pas les notes de bas de page.
`gagmacrowarning(name name ...)’
Empêche le programme `yodl’ d'afficher le message impossible d'étendre une macro utilisateur potentielle. Par exemple, si vous avez dans votre document `les fichiers sont ..’, vous pourriez vouloir mettre avant cela : `gagmacrowarning(file)’. Appelle `NOUSERMACRO’.
`getaffilstring()’
S'étend à la chaîne qui définit le nom des Informations d'affiliation, par défaut INFORMATIONS D'AFFILIATION. Peut être redéfini pour le support des langues nationales par `setaffilstring()’. Actuellement, il n'est pertinent que pour le texte.
`getauthorstring()’
S'étend à la chaîne qui définit le nom des Informations d'auteur, par défaut INFORMATIONS D'AUTEUR. Peut être redéfini pour le support des langues nationales par `setauthorstring()’. Actuellement, il n'est pertinent que pour le texte.
`getchapterstring()’
S'étend à la chaîne qui définit une entrée `chapter’, par défaut Chapitre. Peut être redéfini pour le support des langues nationales par `setchapterstring()’.
`getdatestring()’
S'étend à la chaîne qui définit le nom des Informations de date, par défaut INFORMATIONS DE DATE. Peut être redéfini pour le support des langues nationales par `setdatestring()’. Actuellement, il n'est pertinent que pour le texte.
`getfigurestring()’
Retourne la chaîne qui définit le texte d'une `figure’, dans les légendes ou dans la macro `fig()’. La chaîne peut être redéfinie en utilisant la macro `setfiguretext()’.
`getpartstring()’
S'étend à la chaîne qui définit une entrée `part’, par défaut Partie. Peut être redéfini pour le support des langues nationales par `setpartstring()’.
`gettitlestring()’
S'étend à la chaîne qui définit le nom des Informations de titre, par défaut INFORMATIONS DE TITRE. Peut être redéfini pour le support des langues nationales par `settitlestring()’. Actuellement, il n'est pertinent que pour le texte.
`gettocstring()’
S'étend à la chaîne qui définit le nom de la table des matières, par défaut Table des matières. Peut être redéfini pour le support des langues nationales par `settocstring()’.
`htmlcommand(cmd)’
Écrit `cmd’ dans la sortie lors de la conversion en HTML. Le `cmd’ n'est pas davantage développé par Yodl.
`htmlheadfile(file)’
Ajoute le contenu de `file’ à la section `head’ d'un document HTML. Le contenu du fichier n'est pas interprété et doit contenir du texte HTML brut. Cette option peut être utile lorsque de grands blocs de texte, comme le contenu des sections `<script>’, doivent être inclus dans la section head des documents HTML. Cette macro n'est active que dans le préambule, ne doit être spécifiée qu'une seule fois, et n'est interprétée que pour les conversions HTML.
`htmlheadopt(option)’
Ajoute le texte littéral `option’ aux informations actuelles dans la section `head’ d'un document HTML. `Option’ peut (ou: devrait) contenir du texte HTML brut. Une option de tête fréquemment rencontrée est `link’, définissant, par exemple, une feuille de style. Comme cette option est fréquemment utilisée, elle a reçu une macro dédiée : `htmlstylesheet’. Lorsque de grands blocs de texte HTML doivent être ajoutés aux documents HTML, la macro `htmlheadfile’ doit être utilisée. Cette macro n'est active que dans le préambule et n'est interprétée que pour les conversions HTML.
`htmlnewfile()’
En sortie HTML, démarre un nouveau fichier. Tous les autres formats ne sont pas affectés. Notez que vous devez prendre vos propres dispositions pour accéder au nouveau fichier ; par exemple, via des liens. De plus, il est prudent de démarrer un nouveau fichier juste avant d'ouvrir une nouvelle section, car les sections sont accessibles depuis la table des matières cliquable. Le convertisseur HTML ne démarre normalement de nouveaux fichiers qu'avant une définition de `chapter’.
`htmlstyle(tag)(definition)’
Ajoute un élément `<style type="text/css"> ... </style>’ à la section head d'un document HTML.
Utilisez `htmlstyle’ pour spécifier une ou plusieurs définitions CSS qui sont finalement insérées aux points de suspension (`...’) dans la définition générique `style’ montrée ci-dessus. Par exemple, (en utilisant `#rrggbb’ pour spécifier une couleur, où `rr’ sont deux chiffres hexadécimaux spécifiant le composant rouge de la couleur, `gg’ deux chiffres hexadécimaux spécifiant le composant vert de la couleur, et `bb’ deux chiffres hexadécimaux spécifiant le composant bleu de la couleur) en spécifiant 
    htmlstyle(body)(color: #rrggbb; background-color: #rrggbb)
    htmlstyle(h1)(color: blue; text-align: center)
    htmlstyle(h2)(color: green)
résulte en l'élément 
    <style type="text/css">
        body {color: #rrggbb; background-color: #rrggbb;}
        h1 {color: blue; text-align: center;} 
        h2 {color: green;}
    </style>
Les macros `htmlheadopt’ et `htmlstylesheet’ pourraient également être utilisées pour insérer des informations dans la section head d'un document HTML, mais `htmlheadopt’ est de nature beaucoup plus générale, tandis que `htmlstylesheet’ fait référence à des éléments CSS stockés dans un fichier externe. La macro `attrib’ peut être utilisée pour définir des styles en ligne.
La macro `htmlstyle’ n'est active que dans le préambule et n'est interprétée que pour les conversions HTML.
Référez-vous aux spécifications CSS disponibles (cf. http://www.w3schools.com/cssref/ pour un aperçu de la façon dont les spécifications CSS sont utilisées, et quelles spécifications CSS sont disponibles).
Par défaut, la spécification de style interne
`figure {text-align: center;} img {vertical-align: center;}’
est utilisée. Si ce n'est pas approprié, spécifiez `nohtmlimgstyle()’ dans le préambule.
`htmlstylesheet(url)’
Ajoute un élément `<link rel="stylesheet" type="text/css" ...>’ à la section head d'un document HTML, en utilisant `url’ dans son champ `href’. L'argument `url’ n'est pas développé, et doit être du texte HTML brut, sans guillemets. La macro `htmlheadopt’ peut également être utilisée pour placer des informations dans la section head d'un document HTML, mais `htmlheadopt’ est de nature beaucoup plus générale. Cette macro n'est active que dans le préambule et n'est interprétée que pour les conversions html.
`htmltag(tagname)(start)’
Définit `tagname’ comme une balise HTML, entourée par `<’ et `>’. Lorsque `start’ est zéro, `tagname’ est préfixé par `/’. Comme toutes les balises html ne sont pas disponibles via des macros Yodl prédéfinies (elles sont trop nombreuses, certaines sont très rarement utilisées, et vous pouvez facilement définir des macros pour les balises pour lesquelles Yodl n'offre pas de macros prédéfinies), la macro `htmltag’ peut être utilisée pour gérer votre propre ensemble de macros. En html, la macro `attrib’ est prise en charge. Par exemple : 
attrib(title="Organisation Mondiale de la Santé")    htmltag(abbr)()OMS+htmltag(abbr)(0)
`ifnewparagraph(truelist)(falselist)’
La macro `ifnewparagraph’ doit être appelée depuis la macro `PARAGRAPH’, si elle est définie. Elle insérera `truelist’ si un nouveau paragraphe est inséré, sinon `falselist’ est inséré (par exemple, suite à deux appels consécutifs de PARAGRAPH). Cette macro peut être utilisée pour éviter la sortie de plusieurs lignes vides.
`includefile(file)’
Inclut `file’. L'extension par défaut `.yo’ est fournie si nécessaire.
Depuis la version 3.00.0 de Yodl, le comportement par défaut d'inclusion de fichiers de Yodl a changé. Le répertoire de travail courant ne reste plus fixe dans le répertoire où Yodl est appelé, mais est volatile, changeant pour le répertoire où se trouve un fichier yodl. Ceci a l'avantage que le comportement d'inclusion de fichiers de Yodl correspond désormais à la façon dont la directive `#include’ de **C** fonctionne. Le comportement d'inclusion de fichiers initialement implémenté est utilisé lorsque l'option `-L’ (`--legacy-include’) de Yodl est utilisée.
`includeverbatim(file)’
Inclut `file’ dans la sortie. Aucun traitement n'est effectué, `file’ doit être sous forme préformatée, par exemple : 
whenhtml(includeverbatim(foo.html))
`it()’
Indique un élément dans une liste d'éléments. Les éléments dans les macros `it’ sont des arguments de macros `itemization’.
`itdesc(itemname)(contents)’
Démarre un élément et sa description dans une liste de description. Son nom est `itemname’, le contenu de l'élément est défini par `contents’. Le `itemname’ est défini en utilisant la macro `dit’.
Avec les conversions `html’, le contenu est entouré de balises `<dd>’ et `</dd>’, résultant en un contenu indiqué par rapport au nom de l'élément. Lorsque la macro `attrib’ est utilisée, elle s'applique au nom de l'élément (balises `<dt>’).
Avec d'autres conversions, le `contents’ est cité (comme s'il utilisait `quote(contents)’).
`itemization(list)’
Définit `list’ comme une liste d'itemisation. Utilisez `it()’ pour indiquer les éléments de la liste.
`kindex()’
Génère une entrée d'index pour les k-indices LaTex() ou texinfo. Son argument est l'entrée d'index. Voir aussi la macro `[cfptv]vindex’.
`label(labelname)’
Définit `labelname’ comme une ancre pour une commande `link’, ou pour représenter la dernière numérotation d'une section ou d'une figure dans une commande `ref’.
`langle()’
Caractère <
`languagedutch()’
Définit les en-têtes spécifiques à la langue néerlandaise. Activez cette macro via setlanguage(dutch).
`languageenglish()’
Définit les en-têtes spécifiques à la langue anglaise. Activez cette macro via setlanguage(english).
`languageportugese()’
Définit les en-têtes spécifiques à la langue portugaise. Activez cette macro via setlanguage(portugese).
`LaTeX()’
Le symbole LaTeX.
`latexaddlayout(arg)’
Cette macro est fournie pour ajouter du texte interprété par Yodl à vos propres commandes de mise en page LaTeX. La commande se termine par une fin de ligne. Voir aussi la macro `latexlayoutcmds()’
`latexcommand(cmd)’
Écrit `cmd’ suivi d'un espace dans la sortie lors de la conversion en LaTeX. `cmd’ n'est pas davantage développé par Yodl.
`latexdocumentclass(class)’
Force le paramètre LaTeX `\documentclass{...}’ à `class’. Normalement, la classe est définie par les macros `article’, `report’ ou `book’. Cette macro est une solution de contournement au cas où vous auriez besoin de spécifier votre propre classe de document pour LaTeX. Cette option est un modificateur et doit apparaître *avant* les macros `article’, `report’ ou `book’.
`latexlayoutcmds(NOTRANSs)’
Cette macro est fournie au cas où vous voudriez insérer vos propres commandes de mise en page LaTeX dans la sortie LaTeX. Les `NOTRANSs’ sont collés juste après la section `\documentclass’. Le défaut est, bien sûr, aucune commande LaTeX locale. Notez que cette macro ne remplace **pas** ma mise en page LaTeX préférée. Utilisez `nosloppyhfuzz()’ et `standardlayout()’ pour désactiver ma mise en page LaTeX préférée.
`latexoptions(options)’

`tac(alignement)(contenu)’
Cette macro est l'une des quatre macros qui peuvent être utilisées pour définir le contenu des colonnes des lignes de tableaux définis par la macro `tbl’. Alternativement, `tc, tnc’, et `tnac’ peuvent être utilisés.
La macro `tac’ est utilisée comme argument de la macro `tr’. L'alignement de la cellule est défini par la spécification `alignement’, contenant au plus deux spécifications d'alignement : un alignement horizontal (l'un de c, l, r (centré, aligné à gauche, aligné à droite)) et un alignement vertical (l'un de t, b (alignement vertical haut et bas)) (tous les types de conversion ne peuvent pas prendre en charge tous les types d'alignement, par exemple, la conversion man ne prend pas en charge l'alignement vertical bas). Le résultat de la spécification d'alignements conflictuels (par exemple, `lr’ ou `tb’) n'est pas défini.

Comme la plupart des tableaux n'utilisent pas cela, un bloc de texte n'est pas généré par défaut. La macro `tac’ reconnaît `attrib’.
`tao(type)(spécification)’

Elle n'est active que pour le prochain appel `tc, tnc, tac,’ ou `tnac’. Son premier argument définit le type de conversion pour lequel le remplacement doit être utilisé, son second argument définit la spécification d'alignement à utiliser.

        tc(aligné à droite)

    tr(
        tao(html)(c)
          tc(aligné à gauche, centré avec html)
        tao(latex)(l)
        tao(man)(l)
          tac(c)(centré, LaTeX et man : aligné à gauche)

)

La macro `tbl’ est actuellement disponible pour les conversions `html, man/ms, latex’ et `txt’.

Utilisez `l’ pour l'alignement à gauche, `c’ pour l'alignement centré et `r’ pour l'alignement à droite. Lors de la définition de tableaux `tbl’, il est conseillé de présenter clairement la spécification du tableau. Pour éviter d'introduire involontairement de nouvelles lignes, les lignes doivent se terminer par une barre oblique inverse (ou la macro `tbl’ reconnaît `attrib’.
`tc(contenu)’

`tline(debutNr)(finNr)’
Cette macro est utilisée pour insérer une ligne horizontale couvrant une ou plusieurs colonnes d'un tableau défini par la macro `tbl’.
Si `finNr’ n'est pas spécifié, et que l'appel `tline’ ne suit pas un appel `line’ précédent dans lequel `finNr’ a été spécifié, alors une ligne horizontale couvrant toute la largeur du tableau est définie (sauf lors de la conversion en texte brut, auquel cas une ligne de caractères `beginNr’ - (moins) est écrite ; si `beginNr’ n'est pas spécifié, alors une ligne de 60 - caractères est écrite).
Si `finNr’ n'est pas spécifié, mais que l'appel `tline’ suit des appels `tline’ précédents qui ont spécifié `finNr’, alors la ligne actuelle est terminée.
Si `finNr’ est spécifié, alors une ligne horizontale est définie, commençant à la colonne numéro `beginNr’ et se poursuivant jusqu'à la colonne numéro `endNr’. Notez qu'il s'agit de numéros, et non de décalages : `beginNr’ doit être au moins 1, `endNr’ doit au moins être égal à `beginNr’ et doit être
at most equal to the number of columns in the table. The `beginNr’ values of subsequent `tline’ calls refer to the same row as the first `tline’ call, and must exceed `endNr’ of the previous `tline’ call.
Exemples : 
    tline()()       définit une ligne couvrant toute la largeur du tableau
    tline(1)(1)     définit une ligne dans la colonne 1
    tline(3)(4)     définit une autre ligne dans les colonnes 3 et 4
    tline()()       termine la ligne précédente
    tline()()       définit une ligne couvrant toute la largeur du tableau

`tt(text)’
Définit `text' en police machine à écrire, et empêche son expansion. Lors de la conversion en man, `text' est entouré d'une apostrophe inversée et d'une apostrophe simple.

`xmlcommand(cmd)’
Écrit `cmd’ dans la sortie lors de la conversion vers xml. Le `cmd’ n’est pas davantage développé par Yodl.
`xmlmenu(order)(title)(menulist)’
Démarre un menu xml. Utilisez itemization() pour définir les éléments. Uniquement disponible en conversion xml. Le titre du menu apparaît dans le menu comme en-tête du menu. La liste de menus est une série d’éléments xit(), contenant le nom du fichier auquel le menu fait référence comme argument (y compris un / final). Le préfixe de chaque élément xit() est la valeur de XXdocumentbase.
L’ordre est l’ `ordre’ du menu. S’il est omis, aucun ordre n’est défini.
`xmlnewfile()’
En sortie XML, démarre un nouveau fichier. Tous les autres formats ne sont pas affectés. Notez que vous devez prendre vos propres dispositions pour accéder au nouveau fichier ; par exemple, via des liens. De plus, il est sûr de démarrer un nouveau fichier juste avant d’ouvrir une nouvelle section, car les sections sont accessibles depuis la table des matières cliquable. Le convertisseur XML démarre normalement de nouveaux fichiers uniquement avant une définition de `chapter’.
`xmlsetdocumentbase(name)’
Définit `name’ comme base de document XML. Pas de valeur par défaut. Uniquement interprété avec les conversions xml. Il est utilisé avec les macros figure et xmlmenu.
`xmltag(tag)(onoff)’
Similaire à `htmltag’, mais utilisé dans le convertisseur XML.
