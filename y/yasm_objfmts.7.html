YASM_OBJFMTS(7) Formats d'objet pris en charge par Yasm YASM_OBJFMTS(7)

NOM

yasm_objfmts - Formats d'objet pris en charge par Yasm

SYNTAXE

yasm -f objfmt ...

DESCRIPTION

La distribution standard de Yasm comprend un certain nombre de modules pour différents formats d'objet (la sortie principale de Yasm).

Le format d'objet est sélectionné sur la ligne de commande yasm(1) en utilisant l'option de ligne de commande -f objfmt.

BIN

Le format d'objet « bin » produit un fichier binaire de format plat, non relocable. Il est approprié pour produire des exécutables .COM DOS ou des éléments tels que des blocs d'amorçage. Il ne prend en charge que 3 sections et ces sections sont écrites dans un ordre prédéfini dans le fichier de sortie.

COFF

Le format d'objet COFF est un ancien format d'objet relocable utilisé sur les anciens systèmes Unix et compatibles, et aussi (plus récemment) sur le système de développement DJGPP pour DOS.

DBG

Le format d'objet « dbg » n'est pas un format d'objet « réel » ; le fichier de sortie qu'il crée décrit simplement la séquence d'appels qui lui sont faits par Yasm et les informations finales sur l'objet et la table des symboles dans un format texte lisible par l'homme (qui, dans un format d'objet normal, serait traité pour obtenir la représentation binaire particulière de ce format d'objet). Ce format d'objet n'est pas destiné à une utilisation réelle, mais plutôt au débogage des détails internes de Yasm.

ELF

Le format d'objet ELF existe en réalité en trois variantes : « elf32 » (pour les cibles 32 bits), « elf64 » (pour les cibles 64 bits et « elfx32 » (pour les cibles x32). ELF est un format d'objet standard couramment utilisé sur les systèmes Unix modernes et compatibles (par exemple, Linux, FreeBSD). ELF a un support complexe pour les objets relocables et partagés.

MACHO

Le format d'objet Mach-O existe en réalité en deux variantes : « macho32 » (pour les cibles 32 bits) et « macho64 » (pour les cibles 64 bits). Mach-O est utilisé comme format d'objet sur MacOS X. Comme Yasm ne prend actuellement en charge que les jeux d'instructions x86 et AMD64, il ne peut générer que des objets Mach-O pour les Mac basés sur Intel.

RDF

Le format d'objet RDOFF2 est un format simple multi-sections conçu initialement pour NASM. Il prend en charge les références de segment mais pas les références WRT. Il a été conçu principalement pour sa simplicité et possède des en-têtes minimalistes pour faciliter le chargement et la liaison. Une chaîne d'outils complète (éditeur de liens, bibliothécaire et chargeur) est distribuée avec NASM.

WIN32

Le format d'objet Win32 produit des fichiers objet compatibles avec les compilateurs Microsoft (tels que Visual C++) ciblant la plateforme Windows 32 bits x86. Le format d'objet lui-même est une version étendue de COFF.

WIN64

Le format d'objet Win64 produit des fichiers objet compatibles avec les compilateurs Microsoft ciblant la plateforme Windows 64 bits « x64 ». Ce format est très similaire au format d'objet win32, mais produit des objets 64 bits.

XDF

Le format d'objet XDF est essentiellement une version simplifiée de COFF. C'est un format relocable multi-sections qui prend en charge les adresses physiques et virtuelles 64 bits.
