NOM

yuvfps - Convertit vers une fréquence d'images différente

SYNTAXE

yuvfps [-r Num:Den] [-s Num:Den] [-i Entrelacement] [-I Entrelacement] [-c] [-n] [-w] [-v 0-2] [-h]

DESCRIPTION

yuvfps est un utilitaire général de rééchantillonnage (EN HAUT ou EN BAS) fourni pour permettre la génération de flux vidéo avec les fréquences d'images requises pour chaque format vidéo standard. yuvfps lit un flux YUV4MPEG depuis l'entrée standard et produit un flux YUV4MPEG sur la sortie standard dans lequel des images sont sautées (sous-échantillonnage) ou dupliquées (sur-échantillonnage) par rapport aux images originales. Cela permet à d'autres outils mjpegtools qui nécessitent une fréquence d'images spécifique de traiter le flux.

yuvfps utilise par défaut l'algorithme de Bresenham pour effectuer le rééchantillonnage afin que le nouveau flux vidéo soit similaire à l'original. Notez cependant que le sous-échantillonnage est une opération non réversible car des images sont supprimées. De plus, le flux vidéo résultant peut ne pas avoir exactement la même durée que l'original si la nouvelle fréquence d'images n'est pas un multiple entier du taux d'origine.

En alternative à la simple suppression ou duplication des images, chaque image/champ de sortie peut être produit comme une moyenne pondérée des deux images/champs d'entrée temporellement les plus proches. Dans ce mode, yuvfps peut également changer le mode d'entrelacement du flux.

yuvfps peut également « corriger » la fréquence d'images spécifiée dans l'en-tête YUV4MPEG. Ceci permet la génération d'effets (avance rapide, ralenti) et aussi lorsque le flux source a une fréquence d'images très proche, mais pas exactement, du taux requis pour une vidéo standard (par exemple, 24.9 vs 25).

OPTIONS

-r Num:Den
Spécifie la fréquence d'images du flux résultant.
-s Num:Den
Ignore la fréquence d'images dans le flux d'entrée et suppose cette fréquence d'images pour le flux d'entrée.
-i Entrelacement
Spécifie le mode d'entrelacement du flux résultant. Le mode d'entrelacement ne peut être changé qu'en utilisant le mode de rééchantillonnage par moyenne pondérée (l'option -w).
p - progressif (non entrelacé)
t - champ supérieur d'abord
b - champ inférieur d'abord
-I Entrelacement
Ignore les informations de mode d'entrelacement dans le flux d'entrée et suppose ce mode d'entrelacement pour le flux d'entrée. Les valeurs possibles sont les mêmes que pour l'option -i.
-c
Modifie la fréquence d'images et le mode d'entrelacement de l'en-tête du flux dans le flux de sortie, mais copie les images du flux original sans modifications. Les options -r et -i spécifient la fréquence d'images et le mode d'entrelacement pour l'en-tête du flux de sortie.
-n
Par défaut, yuvfps essaie de trouver une fréquence d'images normalisée. Certains programmes créent des fréquences d'images comme : 29969909:1000000 qui est en fait la fréquence d'images NTSC typique de 30000:1001. yuvfps affiche les valeurs normalisées et l'original au démarrage. Si vous pensez que la valeur normalisée n'est pas correcte et que vous voulez que yuvfps utilise le nombre original donné, vous devez ajouter cette option. Ainsi, yuvfps n'essaie pas de normaliser les valeurs.
-w
Produit chaque image/champ de sortie comme une moyenne pondérée des deux images/champs d'entrée temporellement les plus proches au lieu de simplement supprimer ou dupliquer des images. Le mélange de deux images/champs adjacents réduit les sauts visibles par rapport à l'algorithme de suppression/duplication par défaut, mais en contrepartie, il rend les objets en mouvement rapide flous et est beaucoup plus lent.
-v [0,1,2]
Définit le niveau de verbosité.
0 = messages d'avertissement et d'erreur uniquement.
1 = ajoute des messages informatifs, comme les informations de conversion de fréquence d'images.
2 = ajoute également des messages de débogage bavards.
