YAPS(1) Manuel des commandes générales YAPS(1)

NOM

YAPS - convertit un fichier abc en un fichier PostScript

SYNTAXE

yaps abc fichier [-d] [-e <liste>] [-E] [-l] [-M XXXxYYY] [-N] [-k nn] [-o nom de fichier] [-P -ss] [-s XX] [-V][-ver] [-x] [-OCC]

OPTIONS

-d
Pour le débogage uniquement. Affiche les structures de données internes utilisées par le programme.
-e <liste>
Dessine les airs avec des numéros de référence dans une liste séparée par des virgules. Les espaces ne sont pas autorisés mais une plage de numéros de référence peut être spécifiée. Par exemple, 1,3,7-10.
-E
Génère une sortie PostScript encapsulée.
-M XXXxYYY
Définit les marges en points, où 28,3 points = 1 cm et 72 points = 1 pouce.
-N
Ajoute la pagination.
-k [nn]
Ajoute la numérotation des mesures. Si le nombre nn est inclus, alors toutes les nn mesures sont numérotées. Sinon, toutes les mesures sont numérotées.
-o nomdefichier
Spécifie le nom du fichier postscript de sortie.
-P ss
Spécifie la taille du papier où 0 est A4 et 1 est US Letter, ou XXXxYYY définit la taille du papier en points.
unités.
-s XX
Spécifie le facteur d'échelle (par défaut 0,7)
-V
Les voix sont imprimées séparément pour un air multi-voix. Sinon, elles sont
entrelacées.
-ver
Affiche le numéro de version et quitte.
-x
Imprime le numéro de l'air dans le champ X :
-OCC
Requis si l'air utilise l'ancienne convention pour les accords délimités par +..+ au lieu de [...].

FONCTIONNALITÉS

* Utilise le code d'analyse de abc2midi, donc la compatibilité avec abc2midi devrait être bonne.

* Mesure la largeur du texte des paroles pour la mise en page des paroles.

* Utilise des structures de données dynamiquement extensibles dans la plupart des cas, vous ne devriez donc pas être limité par des limites pré-compilées.

* Plusieurs voix dessinées avec des notes jouées en même temps sont alignées.

* Prend en charge les caractères spéciaux en utilisant la police ISO Latin 1. Les caractères spéciaux sont créés avec un code de type TeX, par exemple ´E ou un code octal à 3 chiffres, par exemple 315.

* Prend en charge les clés suivantes : baryton, ténor, alto, mezzo, soprano, clé de sol, basse. L'utilisation recommandée est

* Les silences invisibles (x) sont affichés comme des silences normaux.

* Les identifiants de voix non numériques, par exemple V : soprano, sont acceptés.


I:clef=bass

Pour faciliter la saisie des airs dans des clés autres que la clé de sol, yaps prend en charge I:octave=-1 pour indiquer qu'un Do dans l'air représente la note une octave en dessous de la hauteur définie dans la norme abc. Celles-ci peuvent être combinées dans une seule instruction I: par exemple

I:clef=bass octave=-2

Vous pouvez également utiliser des clés qui sont une, deux ou trois octaves plus hautes ou plus basses que la normale en utilisant par exemple treble-8, treble+15, treble-22. La clé est dessinée avec un petit 8, 15 ou 22 au-dessus ou en dessous du symbole de clé. Les commandes clef= et octave= peuvent également être placées dans le champ K:, par exemple

K:G clef=bass-8 octave=-3

Notez qu'il existe une incompatibilité entre le comportement de yaps et celui d'abc2ps 1.3.3. abc2ps 1.3.3 ne prend pas en charge la commande I:octave=N, mais la sélection de certaines clés le fait transposer automatiquement de plusieurs octaves. Vous pouvez produire de l'abc qui fonctionne pour les deux en faisant suivre le changement de clé par une commande I:octave=N pour effectuer la transposition qu'abc2ps fait automatiquement.

* Produit des étiquettes de parties encadrées.

* Prend en charge le symbole segno avec !segno! et coda avec !coda!. D'autres instructions musicales comme !fine! et !D.C.! apparaissent comme du texte. * Prend en charge le champ U: pour abréger les symboles en caractères uniques. par exemple

U:S = !segno!

permet d'utiliser S pour produire le symbole segno. Actuellement, cela ne permet que de définir de nouveaux symboles et ne permet pas de modifier les symboles prédéfinis existants M, L, R, H et T.

* Prend en charge les instructions !red! et !black! pour passer du noir au rouge ou vice versa.

* Prend en charge les extensions abc2ps à abc suivantes :


%%newpage - commence une nouvelle page,
%%vskip N - ajoute un espace vertical de N points. Si N est suivi de
'cm' ou 'in', les unités sont prises comme des centimètres ou
pouces au lieu de points, par exemple 4cm.
%%text - imprime du texte
%%centre (ou %%center pour les Américains) - imprime du texte centré.
Si %%text ou %%centre apparaissent dans l'en-tête, le texte apparaît au-dessus
de l'air.


%%staffsep SIZE - définit l'espace blanc vertical entre 2 portées musicales
consécutives.


%%titleleft N - sélectionne le titre placé à gauche ou centré. N = 1
place le titre à gauche tandis que N = 0 le centre.
%%titlecaps - le titre est affiché en majuscules.
%%textfont NAME SIZE - sélectionne la police appelée NAME et la taille en points SIZE
pour le texte produit par %%text ou %%centre. Si seul NAME est donné, la
police reste de la même taille. De même, si '-' est donné comme NAME,
seule la taille de la police change.
%%titlefont NAME SIZE - sélectionne la police pour le titre.
%%subtitlefont NAME SIZE - sélectionne la police pour les titres après le premier
titre.
%%composerfont NAME SIZE - sélectionne la police pour les mots dans les champs C: et O:
et le spécificateur de partie (P: dans l'en-tête).
%%wordsfont NAME SIZE - sélectionne la police pour les mots dans les champs W:.
%%partsfont NAME SIZE - sélectionne la police pour les parties encadrées et
!instruction!.
%%vocalfont NAME SIZE - sélectionne la police pour les mots dans les champs w:.
%%gchordfont NAME SIZE - sélectionne la police pour les accords de guitare dans la musique.
(Il est conseillé de ne pas changer le nom de la police pour ces deux derniers, car
le programme calcule la largeur des chaînes en utilisant les polices par défaut)
%%titlespace, %%subtitlespace, %%textspace, %%composerspace,
%%wordsspace, %%partsspace, %%vocalspace et %%gchordspace
déterminent la quantité d'espace laissée au-dessus du type correspondant
de texte. Chacun d'eux doit être suivi d'une taille en points
ou d'une valeur en centimètres ou en pouces.
par exemple %%composerfont 3
%%titlefont 2cm

* Prend en charge le placement des accords d'accompagnement au-dessus ou en dessous de la
portée.


%%chordsabove - place les accords d'accompagnement au-dessus de la portée
(par défaut).
%%chordsbelow - place les accords d'accompagnement en dessous de la portée.

* Prend en charge le texte optionnel entre guillemets avant et après la
spécification du tempo dans le champ Q:. Cette extension provient de
abc2ps.
