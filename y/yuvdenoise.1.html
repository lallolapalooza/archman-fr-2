NOM

yuvdenoise - Réducteur de bruit spatio-temporel pour YUV4MPEG2

SYNTAXE

yuvdenoise [options] </dev/stdin >/dev/stdout

DESCRIPTION

yuvdenoise est un filtre de bruit spatio-temporel pour les flux YUV4MPEG2. Ceci est utile pour réduire le débit binaire nécessaire pour encoder vos films capturés pour la création de VCD et SVCD.

OPTIONS

yuvdenoise accepte les options suivantes :

-g y,u,v [0..255] Seuils du filtre Gaussien
Ceci définit les seuils pour le filtre Gaussien. Une valeur de 0 désactive le filtrage pour un composant spécifique et 0,0,0 désactive/ignore complètement le filtre. Ce filtre est appliqué avant le filtre temporel (-t).
(par défaut=0,0,0)
-m y,u,v [0..255] Seuils du filtre Médian 3D pré-traitement
Ceci définit les seuils pour le filtre médian 3D de pré-traitement. Une valeur de 0 désactive le filtrage médian pour un composant spécifique et 0,0,0 désactive/ignore complètement le filtre. Ce filtre est appliqué avant le filtre temporel (-t).
(par défaut=0,0,0)
-r y,u,v [0..255] Seuils du filtre de ré-bruitage
Ceci définit les seuils pour l'ajout de bruit aléatoire dans le flux vidéo. Par défaut, il est désactivé (aucun bruit aléatoire ajouté). Ce filtre, s'il est activé, est exécuté comme filtre Blast (après les filtres médian et temporel). Une valeur raisonnable est 4,8,8 mais si vous travaillez avec un film monochrome (noir et blanc), alors 4,0,0 accélérera le processus en ne traitant pas les plans de chrominance.
(par défaut=0,0,0)
-t y,u,v [0..255] Seuils du filtre de bruit temporel
Ceci définit les seuils pour le filtre de bruit temporel. Les valeurs supérieures à 12 peuvent introduire des artefacts fantômes (ghosting). La valeur par défaut pour Y' (y) est souvent un peu élevée et il peut être nécessaire de la réduire à 4 ou 5. Si la chrominance présente des traînées ou des artefacts fantômes, essayez d'utiliser les valeurs 5 ou 6 au lieu de la valeur par défaut (12). Une valeur de 0 désactive le filtrage temporel pour le composant spécifié (0,0,0 désactive/ignore tout filtrage temporel). Ainsi, pour les films noir et blanc, 4,0,0 sera plus rapide en ne réduisant pas le bruit des plans de chrominance.
(par défaut=4,8,8)
-M y,u,v [0..255] Seuils du filtre Médian 3D post-traitement
Ceci définit les seuils pour le filtre médian 3D de post-traitement. Une valeur de 0 désactive le filtrage médian pour un composant spécifique et 0,0,0 désactive/ignore complètement le filtre. Ce filtre est appliqué après le filtre temporel (-t). Une valeur raisonnable est 4,8,8 mais si vous travaillez avec un film monochrome (noir et blanc), alors 4,0,0 accélérera le processus en ne traitant pas les plans de chrominance.
(par défaut=0,0,0)

USAGE TYPIQUE ET CONSEILS

Comme il s'auto-adapte à la situation de bruit trouvée dans le flux, vous pouvez normalement vous passer de toute option définie :

lav2yuv my-video.avi | yuvdenoise | mpeg2enc -t 1 -o my-video.m1v
