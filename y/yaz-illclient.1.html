NOM

yaz-illclient - Client ILL

SYNTAXE

yaz-illclient [-f nom_fichier] [-v niveau_log] [-D nom=valeur...] [-o] [-u utilisateur] [-p mot_de_passe] [-V] [adresse_serveur]

DESCRIPTION

yaz-illclient est un client qui envoie une requête ISO ILL à un serveur distant et décode la réponse de celui-ci. Une seule adresse de serveur ( adresse_serveur ) doit être spécifiée.

OPTIONS

-f nom_fichier]

Spécifie le nom du fichier.

-v niveau_log]

Spécifie le niveau de journalisation.

-D nom=valeur]

Définit un couple nom et valeur.

-o

Active l'authentification OCLC.

-u utilisateur]

Spécifie l'utilisateur.

-p mot_de_passe]

Spécifie le mot de passe.

-V

Affiche la version de yaz-illclient.
