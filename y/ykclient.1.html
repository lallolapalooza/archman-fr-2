NOM

ykclient - Client de validation de mot de passe à usage unique YubiCloud

SYNOPIS

ykclient [OPTION]... CLIENTID MOTDEPASSEUNIQUE

DESCRIPTION

Valide le mot de passe à usage unique YUBIKEYOTP contre le YubiCloud en utilisant CLIENTID comme identifiant du client.

Les arguments obligatoires pour les options longues sont également obligatoires pour les options courtes.

--help
Affiche cet écran d'aide
--version
Affiche les informations de version
--debug
Affiche les informations de débogage
--url URL
URL du service de validation, par exemple, "https://api.yubico.com/wsapi/2.0/verify"
--ca REPERTOIRE_CA
Chemin vers le répertoire contenant l'autorité de certification, par exemple, "/usr/local/etc/CERTS"
--cai FICHIER_CA
Chemin vers un fichier contenant un ou plusieurs certificats pour vérifier le pair
--apikey CLE
Clé API pour la validation HMAC de la requête/réponse
--proxy ip:port
Se connecter au service de validation via un proxy, par exemple, "socks5h://utilisateur:motdepasse@127.0.0.1:1080"

Le code de sortie est 0 en cas de succès, 1 en cas d'échec critique, 2 si le mot de passe à usage unique a été rejoué, 3 pour d'autres échecs liés au mot de passe à usage unique.

SIGNALER LES BOGUES

Signalez les bogues sur https://github.com/Yubico/yubico-c-client.
