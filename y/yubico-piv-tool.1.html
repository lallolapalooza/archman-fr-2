YUBICO-PIV-TOOL(1) Commandes utilisateur YUBICO-PIV-TOOL(1)

NOM

yubico-piv-tool - Outil de gestion des identifiants de vérification d'identité personnelle (PIV) sur les Yubikeys

SYNTAXE

yubico-piv-tool [OPTION]...

DESCRIPTION

-h, --help
Affiche l'aide et quitte
--full-help
Affiche l'aide, y compris les options cachées, et quitte
-V, --version
Affiche la version et quitte
-v, --verbose[=INT]
Affiche plus d'informations (par défaut=`0')
-r, --reader=CHAÎNE
Utilise uniquement un lecteur correspondant (par défaut=`Yubikey')
-k, --key[=CHAÎNE]
Clé de gestion à utiliser, si aucune valeur n'est spécifiée, la clé sera demandée (par défaut=`010203040506070801020304050607080102030405060708')
-a, --action=ENUM
Action à effectuer (valeurs possibles="version", "generate", "set-mgm-key", "reset", "pin-retries", "import-key", "import-certificate", "set-chuid", "request-certificate", "verify-pin", "verify-bio", "change-pin", "change-puk", "unblock-pin", "selfsign-certificate", "delete-certificate", "read-certificate", "read-public-key", "status", "test-signature", "test-decipher", "list-readers", "set-ccc", "write-object", "read-object", "attest", "move-key", "delete-key")
Plusieurs actions peuvent être données à la fois et seront exécutées dans l'ordre, par exemple --action=verify-pin --action=request-certificate
-s, --slot=ENUM
Quel slot de clé opérer (valeurs possibles="9a", "9c", "9d", "9e", "82", "83", "84", "85", "86", "87", "88", "89", "8a", "8b", "8c", "8d", "8e", "8f", "90", "91", "92", "93", "94", "95", "f9")
9a est pour l'authentification PIV, 9c pour la signature numérique (PIN toujours vérifié), 9d pour la gestion des clés, 9e pour l'authentification de carte (PIN jamais vérifié), 82-95 pour la gestion des clés retirées, f9 pour l'attestation.
--to-slot=ENUM
Dans quel slot déplacer une clé existante (valeurs possibles="9a", "9c", "9d", "9e", "82", "83", "84", "85", "86", "87", "88", "89", "8a", "8b", "8c", "8d", "8e", "8f", "90", "91", "92", "93", "94", "95", "f9")
9a est pour l'authentification PIV, 9c pour la signature numérique (PIN toujours vérifié), 9d pour la gestion des clés, 9e pour l'authentification de carte (PIN jamais vérifié), 82-95 pour la gestion des clés retirées, f9 pour l'attestation.
-A, --algorithm=ENUM
Quel algorithme utiliser (valeurs possibles="RSA1024", "RSA2048", "RSA3072", "RSA4096", "ECCP256", "ECCP384", "ED25519", "X25519" par défaut=`RSA2048')
-H, --hash=ENUM
Hash à utiliser pour les signatures (valeurs possibles="SHA1", "SHA256", "SHA384", "SHA512" par défaut=`SHA256')
-n, --new-key=CHAÎNE
Nouvelle clé de gestion à utiliser pour l'action set-mgm-key, si omis la clé sera demandée
--pin-retries=INT
Nombre de tentatives avant que le code PIN ne soit bloqué
--puk-retries=INT
Nombre de tentatives avant que le code PUK ne soit bloqué
-i, --input=CHAÎNE
Nom de fichier à utiliser comme entrée, - pour stdin (par défaut=`-')
-o, --output=CHAÎNE
Nom de fichier à utiliser comme sortie, - pour stdout (par défaut=`-')
-K, --key-format=ENUM
Format de la clé lue/écrite (valeurs possibles="PEM", "PKCS12", "GZIP", "DER", "SSH" par défaut=`PEM')
--compress
Compresse un certificat volumineux avec GZIP avant l'importation (par défaut=désactivé)
--global
Réinitialise tout l'appareil sur toutes les applications (par défaut=désactivé)
-p, --password=CHAÎNE
Mot de passe pour le déchiffrement du fichier de clé privée, si omis le mot de passe sera demandé
-S, --subject=CHAÎNE
Le sujet à utiliser pour la demande de certificat
Le sujet doit être écrit comme suit : /CN=host.example.com/OU=test/O=example.com/
--serial=INT
Numéro de série du certificat auto-signé
--valid-days=INT
Temps (en jours) avant l'expiration du certificat auto-signé (par défaut=`365')
-P, --pin=CHAÎNE
Code PIN/PUK pour la vérification, si omis le PIN/PUK sera demandé
-N, --new-pin=CHAÎNE
Nouveau code PIN/PUK pour le changement, si omis le PIN/PUK sera demandé
--pin-policy=ENUM
Définit la politique de PIN pour l'action generate ou import-key. Uniquement disponible sur YubiKey 4 ou plus récent (valeurs possibles="never", "once", "always", "matchonce", "matchalways")
--touch-policy=ENUM
Définit la politique de toucher pour l'action generate, import-key ou set-mgm-key. Uniquement disponible sur YubiKey 4 ou plus récent (valeurs possibles="never", "always", "cached")
--id=INT
Identifiant de l'objet pour write/read object
-f, --format=ENUM
Format des données pour write/read object (valeurs possibles="hex", "base64", "binary" par défaut=`hex')
--attestation
Ajoute une signature croisée d'attestation (par défaut=désactivé)
-m, --new-key-algo=ENUM
Nouvel algorithme de clé de gestion à utiliser pour l'action set-mgm-key (valeurs possibles="TDES", "AES128", "AES192", "AES256" par défaut=`TDES')
--scp11
La communication avec la YubiKey se fait via un canal crypté. OBSOLÈTE ! Veuillez utiliser l'indicateur '--enc' à la place (par défaut=désactivé)
--enc
La communication avec la YubiKey se fait via un canal crypté (par défaut=désactivé)
