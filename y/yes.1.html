YES(1) Commandes utilisateur YES(1)

NOM

yes - répète une chaîne de caractères jusqu'à interruption

SYNTAXE

yes [CHAÎNE]...
yes OPTION

DESCRIPTION

Répète indéfiniment une ligne contenant toutes les CHAÎNE(s) spécifiées, ou 'y' par défaut.

--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte
