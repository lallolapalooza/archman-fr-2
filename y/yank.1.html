NOM

yank — copier la sortie du terminal dans le presse-papiers

SYNOPIS

yank [-1ilxv] [-d delim] [-g motif] [-- commande [argument ...]]

DESCRIPTION

Lire l'entrée depuis stdin et afficher une interface de sélection qui permet de sélectionner un champ et de le copier dans le presse-papiers. Les champs sont reconnus soit par une expression régulière à l'aide de l'option -g, soit en divisant l'entrée selon une séquence de délimiteurs à l'aide de l'option -d, voir DELIMITEURS.

L'utilisation des touches fléchées déplacera le champ sélectionné, voir COMMANDES. Appuyer sur la touche retour invoquera commande et écrira le champ sélectionné dans son stdin. La commande est par défaut xsel(1x) mais pourrait être n'importe quoi qui accepte l'entrée sur stdin, voir EXEMPLES.

Les options sont les suivantes :

-1
S'il n'y a qu'un seul champ reconnu, le sélectionner et invoquer commande sans afficher l'interface de sélection.
-d delim
Tous les caractères d'entrée non présents dans delim seront reconnus comme champs, voir DELIMITEURS.
-g motif
Utiliser motif pour reconnaître les champs, exprimé comme une expression régulière étendue POSIX.
-i
Ignorer les différences de casse entre motif et l'entrée.
-l
Utiliser les délimiteurs par défaut sauf l'espace, voir DELIMITEURS.
-v
Affiche la version.
-x
Utiliser l'écran alternatif.
-- commande [argument ...]
Utiliser commande avec zéro ou plusieurs args comme commande de copie.

COMMANDES

Ctrl-A | g
Déplacer la sélection vers le premier champ.
Ctrl-C | Ctrl-D
Quitter sans invoquer la commande de copie.
Ctrl-E | G
Déplacer la sélection vers le dernier champ.
Ctrl-P/Ctrl-N | Gauche/Droite | h/l
Déplacer la sélection vers la gauche ou la droite.
Haut/Bas | j/k
Déplacer la sélection vers la ligne suivante ou précédente.
Entrée
Quitter en utilisant le champ sélectionné.

DELIMITEURS

Si les options -d et -g sont omises, les caractères suivants sont reconnus comme délimiteurs par défaut :

\f
saut de page
\n
nouvelle ligne
\r
retour chariot
\s
espace
\t
tabulation horizontale

Si l'option -d est présente, l'espace n'est pas reconnu comme délimiteur.

EXEMPLES

Copier une clé ou une valeur de variable d'environnement :

$ env | yank -d =

Copier un champ d'un fichier CSV :

$ yank -d \", <fichier.csv

Copier une ligne entière en utilisant l'option -l :

$ make 2>&1 | yank -l

Si stdout n'est pas un terminal, le champ sélectionné sera écrit dans stdout et la commande se terminera sans invoquer la commande de copie. Tuer le PID sélectionné :

$ ps ux | yank -g [0-9]+ | xargs kill

Copier le champ sélectionné dans le presse-papiers, par opposition au presse-papiers principal par défaut :

$ yank — xsel -b

DIAGNOSTICS

L'utilitaire yank se termine avec le code  0 en cas de succès, et  >0 en cas d'erreur.

CAVEATS

Reconnaître les champs entre crochets nécessite que ‘]’ soit présent avant ‘[’ dans l'argument donné à l'option -d, voir re_format(7).
