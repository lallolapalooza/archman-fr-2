yodlverbinsert(1) Your Own Document Language yodlverbinsert(1)

NOM

yodlverbinsert - Générer des sections de verbes à partir de parties d'un fichier

SYNTAXE

yodlverbinsert [OPTIONS] [marqueur] fichier

DESCRIPTION

Verbinsert est un programme de support simple en C++ utilisé pour générer des sections verb() dans les fichiers Yodl à partir de sections de fichiers existants. Les fichiers dont des sections sont incluses sont généralement des fichiers sources C ou Cpp, acceptant soit le style de commentaire // soit /*. Voir la section EXEMPLES pour des illustrations.

Verbinsert offre la possibilité d'indenter à la fois l'instruction verb initiale et le contenu du fichier inséré. De plus, une ligne vide supplémentaire peut être insérée avant la première ligne réellement insérée.

Les lignes vides au début et à la fin des fichiers sont ignorées.

o
marqueur
L'argument marqueur doit commencer dans la première colonne de fichier et doit commencer comme un commentaire standard C ou C++ : // ou /* doivent être utilisés. Après cela, le reste de l'argument est utilisé comme étiquette, par exemple //étiquette, /*étiquette*/. À l'exception des deux premiers caractères et de leurs emplacements, et des deux derniers caractères d'un marqueur de style C, aucune restriction spéciale n'est imposée aux noms d'étiquettes. Une section étiquetée se termine au prochain //= (pour les étiquettes commençant par //) ou au prochain /**/ (pour les étiquettes commençant par /*). Comme les marqueurs, les marqueurs de fin doivent également commencer dans les premières colonnes des lignes.
Alternativement, des paires de //+étiquette, ou /*+étiquette*/ peuvent être utilisées. Pour de tels marqueurs, la copie commence à la première ligne suivant la première occurrence de l'étiquette, et se termine lorsque l'étiquette est rencontrée à nouveau. Lorsque ces marqueurs sont utilisés, toute ligne de marqueur supplémentaire rencontrée est simplement ignorée et non écrite dans le flux de sortie. Cela permet d'imbriquer les sections étiquetées.
o
fichier
L'argument fichier doit être un fichier existant.

Verbinsert écrit sa section sélectionnée sur son flux de sortie standard.

Lorsque les fichiers contiennent des sections de marqueurs identiques, le contenu de chacune de ces sections de marqueurs est inclus dans la section verb générée. Cela permet l'inclusion de lignes non consécutives de fichiers source dans une section verb.

OPTIONS

Les valeurs par défaut des options sont listées avec chaque option entre crochets. Les valeurs par défaut ont été choisies de manière à ce que yodlverbinsert effectue le comportement d'une version antérieure de ce programme, qui n'était pas distribuée avec Yodl.

o
-a
Traiter toutes les lignes de fichier (sauf les lignes vides initiales et finales). L'argument marqueur ne doit pas être spécifié.
o
-A
Identique à l'option -a, mais en ignorant toutes les lignes qui peuvent être considérées comme des lignes de marqueur yodlverbinsert (de fin).
o
-k
Garder les sauts de ligne après 
 et avant
. Ces sauts de ligne entraînent des lignes vides supplémentaires avant la première et après la dernière ligne de code source. Depuis la version 4.02.00, ces lignes sont supprimées par défaut.
o
-n
Immédiatement après l'indentation : les lignes sont préfixées par des numéros, occupant 2 colonnes, suivis d'un deux-points et d'un espace.
o
-N
Ne pas écrire de saut de ligne immédiatement après la parenthèse ouvrante de l'instruction verb. Par défaut, elle est écrite, ce qui provoque l'insertion d'une ligne supplémentaire avant la première ligne réellement insérée depuis un fichier.
o
-s nEspaces [0]
commencer chaque ligne écrite dans la section verb avec nEspaces espaces supplémentaires.
o
-S nEspaces [8]
préfixer le verb de la section verb avec nEspaces espaces supplémentaires.
o
-t nTabs [0]
commencer chaque ligne écrite dans la section verb avec nTabs tabulations supplémentaires. Si -s et -t sont spécifiés, les tabulations sont insérées en premier.
o
-T nTabs [0]
préfixer le verb de la section verb avec nTabs tabulations supplémentaires. Si -S et -T sont spécifiés, les tabulations sont insérées en premier.

EXEMPLE

Supposons que le fichier demo contienne le texte suivant :

texte précédent
//+imbriquer
//un
un 1
//=
/*deux*/
    deux
/**/
//+imbriquer
texte suivant

Alors les commandes suivantes écrivent la sortie montrée sur la sortie standard du programme :

o
yodlverbinsert //un demo 
        verb(
un 1
)
o
yodlverbinsert -N //un demo 
        verb(un 1
)
o
yodlverbinsert -n -s4 ’/*deux*/’ demo 
        verb(
        1: deux
)
o
yodlverbinsert -n //+imbriquer demo 
        verb(
 1: un 1
 2:
 3:
 4:
 5:     deux
)
