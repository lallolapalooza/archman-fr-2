NOM

yaz-marcdump - utilitaire pour extraire les enregistrements MARC

SYNTAXE

yaz-marcdump [-i format] [-o format] [-f de] [-t à] [-l spéc] [-c fichier_c] [-s préfixe] [-C taille] [-O décalage] [-L limite] [-n] [-p] [-r] [-v] [-V] [fichier...]

DESCRIPTION

yaz-marcdump lit les enregistrements MARC à partir d'un ou plusieurs fichiers. Il analyse chaque enregistrement et prend en charge la sortie en format ligne, ISO2709, MARCXML[1], MARC-in-JSON[2], MarcXchange[3] ainsi que la sortie Hex.

Cet utilitaire analyse les enregistrements aux formats ISO2709 (MARC brut), format ligne, MARC-in-JSON ainsi que XML s'il est structuré en MARCXML/MarcXchange.

L'encodage/décodage MARC-in-JSON est pris en charge dans YAZ 5.0.5 et versions ultérieures.


Note

Depuis YAZ 2.1.18, MARC OAI n'est plus pris en charge. MARC OAI est obsolète. Utilisez MARCXML à la place.

Par défaut, chaque enregistrement est écrit sur la sortie standard en format ligne avec un retour à la ligne pour chaque champ, $x pour chaque sous-champ x. Le format de sortie peut être modifié avec l'option -o,

yaz-marcdump peut également être utilisé pour effectuer la conversion de jeux de caractères de chaque enregistrement.

OPTIONS

-i format

Spécifie le format d'entrée. Doit être l'un des suivants : marcxml, marc (ISO2709), marcxchange (ISO25577), line (MARC en mode ligne), turbomarc (Turbo MARC), ou json (MARC-in-JSON).

-o format

Spécifie le format de sortie. Doit être l'un des suivants : marcxml, marc (ISO2709), marcxchange (ISO25577), line (MARC en mode ligne), turbomarc (Turbo MARC), ou json (MARC-in-JSON).

-f de

Spécifie le jeu de caractères de l'enregistrement MARC d'entrée. Doit être utilisé conjointement avec l'option -t. Se référer à la page de manuel yaz-iconv pour les jeux de caractères pris en charge.

-t à

Spécifie le jeu de caractères de sortie. Doit être utilisé conjointement avec l'option -f. Se référer à la page de manuel yaz-iconv pour les jeux de caractères pris en charge.

-l spec_leader

Spécifie une chaîne de modification simple pour le leader MARC. La spec_leader est une liste de paires position=valeur, où position est un décalage entier (0 - 23) pour le leader. La valeur est soit une chaîne entre guillemets, soit un entier (valeur de caractère en décimal). Les paires sont séparées par des virgules. Par exemple, pour définir le leader au décalage 9 à 'a', utilisez 9='a'.

-s préfixe

Écrit un lot d'enregistrements dans un fichier séparé avec le préfixe donné, c'est-à-dire qu'il divise un lot d'enregistrements en fichiers ne contenant au plus que "taille_lot" enregistrements ISO2709 par fichier. Par défaut, la taille de lot est 1 (un enregistrement par fichier). Voir l'option -C.

-C taille_lot

Spécifie la taille du lot ; à utiliser en conjonction avec l'option -s.

-O décalage

Décalage entier indiquant la position à laquelle les enregistrements doivent être écrits. 0=premier enregistrement, 1=deuxième, .. Avec l'option -L, cela permet de traiter une plage spécifique d'enregistrements.

-L limite

Limite entière indiquant le nombre maximum d'enregistrements qui doivent être écrits. Avec l'option -O, cela permet de traiter une plage spécifique d'enregistrements.

-p

Demande à yaz-marcdump d'afficher le numéro d'enregistrement et le décalage de fichier d'entrée de chaque enregistrement lu.

-n

La sortie MARC est omise de sorte que seule l'entrée MARC soit vérifiée.

-r

Écrit sur stderr un résumé du nombre d'enregistrements lus par yaz-marcdump.

-v

Affiche plus d'informations sur le processus d'analyse. Utile si vous avez des enregistrements ISO2709 mal formatés en entrée.

-V

Affiche la version YAZ.

EXEMPLES

La commande suivante convertit MARC21/USMARC en encodage MARC-8 en MARC21/USMARC en encodage UTF-8. Le décalage du leader 9 est défini sur 'a'. Les enregistrements d'entrée et de sortie sont encodés en ISO2709.

    yaz-marcdump -f MARC-8 -t UTF-8 -o marc -l 9=97 marc21.raw >marc21.utf8.raw

Les mêmes enregistrements peuvent être convertis en MARCXML en UTF-8 :

    yaz-marcdump -f MARC-8 -t UTF-8 -o marcxml marc21.raw >marcxml.xml

Turbo MARC est une notation XML compacte avec la même sémantique que MARCXML, mais qui permet un traitement plus rapide via XSLT. Pour générer des enregistrements Turbo MARC encodés en UTF-8 à partir de MARC21 (ISO), on peut utiliser :

    yaz-marcdump -f MARC8 -t UTF8 -o turbomarc -i marc marc21.raw >out.xml
