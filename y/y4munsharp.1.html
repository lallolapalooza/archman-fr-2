NOM

y4munsharp - Filtre de netteté pour les flux YUV4MPEG2

SYNTAXE

y4munsharp [options]

DESCRIPTION

y4munsharp est une implémentation du filtre de netteté de GIMP pour les flux YUV4MPEG2. Les 3 paramètres habituels pour le traitement du masque de netteté (rayon, quantité et seuil) sont spécifiés en ligne de commande. Par défaut, seul le composant Y' (luminance) est traité, bien que le traitement de CbCr (chrominance) puisse être demandé par une option en ligne de commande. La sortie doit être dirigée vers un tube ou un fichier. Laisser la sortie standard ouverte sur un terminal entraînera une erreur et le programme se terminera.

OPTIONS

y4munsharp accepte les options suivantes :

-v num
Définit le niveau de verbosité (0 = silencieux, 1 = normal, 2 = débogage) (défaut : 1)
-h
Affiche un résumé de l'utilisation et quitte.
-L rayon,quantité,seuil
Paramètres de netteté pour Y' (luminance). Les arguments rayon et quantité sont des nombres flottants. L'argument seuil est un entier. (défaut : 3.0,0.3,4) -C rayon,quantité,seuil Paramètres de netteté pour CbCr (chrominance). La chrominance n'est pas traitée sauf si cette option est fournie. Les arguments sont du même type que pour l'option -L ci-dessus. (défaut : aucun)
-N
Le filtrage peut produire des sorties en dehors de la plage 16 à 240 pour Y' et 16 à 235 pour CbCr. Par défaut, les valeurs hors de la plage légale sont écrêtées/tronquées (les valeurs supérieures à 240 pour Y' sont mises à 240 par exemple). Avec -N, les limites 0 et 255 sont utilisées à la place.

EXEMPLES

Un réglage doux :

y4munsharp -L 2.0,0.3,0

Un réglage agressif :
y4munsharp -L 5.0,0.5,0

NOTES

Les paramètres rayon, quantité, seuil ont la même signification que le plugin unsharp de GIMP. Cela signifie que vous pouvez utiliser GIMP sur des images fixes sélectionnées pour déterminer des réglages appropriés pour y4munsharp. La chose importante à retenir est d'être subtil - vous voulez à peine remarquer l'effet de netteté. Si l'effet est évident ("saute aux yeux"), alors les paramètres sont réglés trop agressivement.

La chrominance n'est pas traitée pour plusieurs raisons : 1) l'œil est beaucoup plus sensible aux changements de luminosité, 2) la chrominance est généralement sous-échantillonnée et ne contribue pas beaucoup à la netteté perçue d'une image - donc ne pas traiter la chrominance offre un gain de vitesse dans le traitement de l'image, et 3) artefacts possibles - les changements dans Y' rendent juste une image plus lumineuse/plus sombre mais les changements dans Cb ou Cr peuvent modifier les couleurs et potentiellement entraîner des changements de teinte. Utilisez l'option -C pour activer le traitement des plans de chrominance.

BOGUES

Seuls les formats YUV4MPEG2 à 3 plans sont pris en charge.

Seuls les flux entrelacés progressifs, première trame supérieure ou première trame inférieure sont gérés. Le format de flux entrelacés mixtes n'est pas pris en charge.
