YDOTOOL(1) Manuel des commandes générales YDOTOOL(1)

NOM

ydotool - outil d'automatisation en ligne de commande pour /dev/uinput

SYNTAXE

ydotool cmd args

ydotool cmd --help

DESCRIPTION

ydotool vous permet de simuler par programmation (ou manuellement) des entrées clavier et des activités de souris, etc. Le démon ydotoold(8) doit être en cours d'exécution.

Commandes actuellement implémentées :

type

Tape une chaîne de caractères
key
Appuie sur des touches
mousemove
Déplace le pointeur de la souris vers une position absolue
click
Clique sur les boutons de la souris

COMMANDES CLAVIER

key [-d,--key-delay <ms>] [<KEYCODE:PRESSED> ...]

Tape un code de touche donné.

par ex. 28:1 28:0 signifie appuyer sur le bouton Entrée sur un clavier américain standard. (où :1 pour pressé signifie que la touche est enfoncée et :0 signifie que la touche est relâchée)

42:1 38:1 38:0 24:1 24:0 38:1 38:0 42:0 - "LOL"

Les valeurs non interprétables, telles que 0, aaa, l0l, ne provoqueront qu'un délai.

Voir `/usr/include/linux/input-event-codes.h' pour les codes de touche disponibles (KEY_*).

Vous pouvez trouver le nom/numéro de la touche que votre clavier envoie à libinput en exécutant `sudo libinput record` puis en sélectionnant votre clavier dans la liste qui affichera le nom et le numéro de la touche libinput pour chaque touche que vous appuyez.

Options : -d,--key-delay <ms>

Temps de délai entre les frappes. Par défaut 12ms.

type [-D,--next-delay <ms>] [-d,--key-delay <ms>] [-f,--file <chemin_fichier>] "texte"

Tape du texte comme si vous l'aviez tapé au clavier.

Options :

-d,--key-delay <ms>

Temps de délai entre les événements clavier (appui/relâchement). Par défaut 12ms.

-D,--next-delay <ms>

Délai entre les chaînes de caractères. Par défaut 0ms.

-f,--file <chemin_fichier>

Spécifiez un fichier, dont le contenu sera tapé comme s'il était passé en argument. Le chemin du fichier peut également être '-' pour lire depuis stdin.

Exemple : pour taper 'Bonjour le monde !' vous feriez :

ydotool type 'Bonjour le monde !'

COMMANDES SOURIS

mousemove [-a,--absolute] <x> <y>

Déplace la souris vers les coordonnées X et Y relatives à l'écran.

Options : --absolute

Utiliser la position absolue

Exemple : pour déplacer le curseur vers les coordonnées absolues (100,100) :

ydotool mousemove --absolute 100 100

click [-d,--next-delay <ms>] [-r,--repeat N ] [bouton ...]

Envoie un clic.

Options : -d,--next-delay <ms>

Délai entre les événements d'entrée (appui/relâchement, un clic complet signifie un temps doublé). Par défaut 25ms.

-r,--repeat N

Répéter toute la séquence N fois

Tous les boutons de la souris sont représentés par des valeurs numériques hexadécimales, avec un masque de bits optionnel pour spécifier si l'appui/relâchement de la souris doit être omis.

  • 0x00 - GAUCHE
  • 0x01 - DROIT
  • 0x02 - MILIEU
  • 0x03 - LATÉRAL
  • 0x04 - EXTR
  • 0x05 - AVANT
  • 0x06 - ARRIÈRE
  • 0x07 - TÂCHE
  • 0x40 - Bouton souris enfoncé
  • 0x80 - Bouton souris relâché
Exemples :
  • 0x00 : choisit le bouton gauche, mais ne fait rien (vous pouvez l'utiliser pour implémenter des délais supplémentaires)
  • 0xC0 : clic bouton gauche (enfoncé puis relâché)
  • 0x41 : bouton droit enfoncé
  • 0x82 : bouton du milieu relâché

Le préfixe '0x' peut être omis si vous le souhaitez.

SOCKET YDOTOOL

Le socket sur lequel écrire pour ydotoold(8) peut être modifié par la variable d'environnement YDOTOOL_SOCKET.
