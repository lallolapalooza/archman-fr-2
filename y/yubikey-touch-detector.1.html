yubikey-touch-detector(1) Manuel des commandes générales yubikey-touch-detector(1)

NOM

yubikey-touch-detector - détecter quand une YubiKey attend un toucher

SYNTAXE

yubikey-touch-detector [options...]

OPTIONS

-libnotify

Affiche des notifications de bureau utilisant libnotify.

-no-socket

Désactive le notifier par socket Unix.

-stdout

Imprime les notifications sur la sortie standard.

-v

Active la journalisation de débogage.

-version

Affiche les informations de version et quitte.

DESCRIPTION

yubikey-touch-detector détecte quand une YubiKey attend une configuration de toucher. Il est conçu pour être intégré à d'autres composants d'interface utilisateur afin d'afficher un indicateur visuel.

ENVIRONNEMENT

YUBIKEY_TOUCH_DETECTOR_VERBOSE

Équivalent à spécifier -v.

YUBIKEY_TOUCH_DETECTOR_LIBNOTIFY

Équivalent à spécifier -libnotify.

YUBIKEY_TOUCH_DETECTOR_STDOUT

Équivalent à spécifier -stdout.

YUBIKEY_TOUCH_DETECTOR_NOSOCKET

Équivalent à spécifier -no-socket.

FICHIERS

$XDG_RUNTIME_DIR/yubikey-touch-detector.socket

Le socket exposant les événements sera créé à cet emplacement.

ÉVÉNEMENTS

Les événements suivants sont émis sur le socket :

GPG_1

Lorsqu'une opération GPG commence à attendre un toucher.

GPG_0

Lorsqu'une opération GPG cesse d'attendre un toucher.

U2F_1

Lorsqu'une opération U2F commence à attendre un toucher.

U2F_0

Lorsqu'une opération U2F cesse d'attendre un toucher.

MAC_1

Lorsqu'une opération HMAC commence à attendre un toucher.

MAC_0

Lorsqu'une opération HMAC cesse d'attendre un toucher.

VOIR AUSSI

ykman, pam_u2f(8)
