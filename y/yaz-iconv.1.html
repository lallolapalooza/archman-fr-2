NOM

yaz-iconv - Utilitaire de conversion de jeu de caractères YAZ

SYNTAXE

yaz-iconv [-f from] [-t to] [-v] [fichier...]

DESCRIPTION

yaz-iconv convertit les données dans le jeu de caractères spécifié par from pour une sortie dans le jeu de caractères spécifié par to.

Cet utilitaire yaz-iconv est similaire à l'utilitaire iconv que l'on trouve sur de nombreux systèmes POSIX (Glibc, Solaris, etc.).

Si aucun fichier n'est spécifié, yaz-iconv lit depuis l'entrée standard.

OPTIONS

-ffrom]

Spécifie le jeu de caractères from du fichier d'entrée. Doit être utilisé en conjonction avec l'option -t.

-tto]

Spécifie le jeu de caractères de sortie. Doit être utilisé en conjonction avec l'option -f.

-v

Affiche plus d'informations sur le processus de conversion.

ENCODAGES

La commande yaz-iconv et l'API telle que définie dans yaz/yaz-iconv.h sont un wrapper pour l'appel système iconv de la bibliothèque. Mais l'utilitaire iconv de YAZ implémente également des conversions par lui-même. Le tableau ci-dessous liste les jeux de caractères (ou encodages) pris en charge par YAZ. Chaque jeu de caractères est marqué soit avec encode, soit avec decode. Si un encodage est activé pour l'encodage, YAZ peut convertir vers l'encodage désigné. Si un encodage est activé pour le décodage, YAZ peut convertir depuis l'encodage désigné.

marc8 (encode, decode)

L'encodage MARC8[1] tel que défini par la Bibliothèque du Congrès. La plupart des enregistrements MARC21/USMARC utilisent cet encodage.

marc8s (encode, decode)

Comme MARC8 mais la conversion privilégie les caractères non combinés dans le plan Latin-1 par rapport aux caractères combinés.

marc8lossy (encode)

Encodage avec perte de MARC-8.

marc8lossless (encode)

Encodage sans perte de MARC8.

utf8 (encode, decode)

L'encodage UNICODE le plus couramment utilisé sur Internet.

iso8859-1 (encode, decode)

ISO-8859-1, alias Latin-1.

iso5426 (decode)

ISO 5426. Certains enregistrements MARC (UNIMARC) utilisent cet encodage.

iso5428:1984 (encode, decode)

ISO 5428:1984.

advancegreek (encode, decode)

Un encodage pour le grec utilisé par certains fournisseurs (Advance).

danmarc (decode)

Danmarc (en danois)[2] est un encodage basé sur UNICODE utilisé pour les enregistrements DanMARC2.

EXEMPLES

La commande suivante convertit de ISO-8859-1 (Latin-1) vers UTF-8.

    yaz-iconv -f ISO-8859-1 -t UTF-8 <input.lst >output.lst
