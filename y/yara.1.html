yara(1) Manuel des commandes générales yara(1)

NOM

yara - trouver des fichiers correspondant à des motifs et des règles écrits dans un langage à usage spécifique.

SYNTAXE

yara [OPTION]... [ESPACE_NOM:]FICHIER_REGLES... FICHIER | RÉPERTOIRE | PID

DESCRIPTION

yara analyse le FICHIER donné, tous les fichiers contenus dans le répertoire RÉPERTOIRE, ou le processus identifié par PID à la recherche de correspondances de motifs et de règles fournies dans un langage à usage spécifique. Les règles sont lues à partir d'un ou plusieurs FICHIERS_REGLES.

Les options de yara(1) sont :

--atom-quality-table
Chemin vers un fichier contenant la table de qualité des atomes.
-C --compiled-rules
FICHIER_REGLES contient des règles déjà compilées avec yarac.
-c --count
Afficher uniquement le nombre de correspondances.
-d --define=identifiant=valeur
Définir une variable externe. Cette option peut être utilisée plusieurs fois.
--fail-on-warnings
Traiter les avertissements comme des erreurs. N'a aucun effet si utilisé avec --no-warnings.
-f --fast-scan
Accélère l'analyse en recherchant uniquement la première occurrence de chaque motif.
-i identifiant --identifier=identifiant
Afficher les règles nommées identifiant et ignorer les autres. Cette option peut être utilisée plusieurs fois.
--max-process-memory-chunk=taille
Lors de l'analyse de la mémoire du processus, lire les données par blocs de la taille spécifiée en octets.
-l nombre --max-rules=nombre
Arrêter l'analyse après qu'un nombre de règles ait été trouvé.
--max-strings-per-rule=nombre
Définir le nombre maximum de chaînes par règle (par défaut=10000)
-x --module-data=module=fichier
Transmettre le contenu du fichier comme données supplémentaires au module. Cette option peut être utilisée plusieurs fois.
-n --negate
Afficher les règles qui ne s'appliquent pas (négatif).
-w --no-warnings
Désactiver les avertissements.
-m --print-meta
Afficher les métadonnées associées à la règle.
-D --print-module-data
Afficher les données des modules.
-M --module-names
Afficher les noms des modules.
-e --print-namespace
Afficher l'espace de noms associé à la règle.
-S --print-stats
Afficher les statistiques des règles.
-s --print-strings
Afficher les chaînes trouvées dans le fichier.
-L --print-string-length
Afficher la longueur des chaînes trouvées dans le fichier.
-X --print-xor-key
Afficher la clé XOR des chaînes correspondantes.
-g --print-tags
Afficher les étiquettes associées à la règle.
-r --recursive
Analyser récursivement les fichiers dans les répertoires. Suit les liens symboliques.
--scan-list
Analyser les fichiers listés dans FICHIER, un par ligne.
-z taille --skip-larger=taille
Ignorer les fichiers plus grands que la taille spécifiée en octets lors de l'analyse d'un répertoire.
-k slots --stack-size=slots
Définir la taille maximale de la pile au nombre spécifié de slots.
--strict-escape
Afficher des avertissements si les règles contiennent des instructions d'échappement ambiguës.
-t tag --tag=tag
Afficher les règles étiquetées comme tag et ignorer les autres. Cette option peut être utilisée plusieurs fois.
-p nombre --threads=nombre
Utiliser le nombre spécifié de threads pour analyser un répertoire.
-a secondes --timeout=secondes
Arrêter l'analyse après l'expiration d'un nombre de secondes.
-v --version
Afficher les informations de version.

EXEMPLES

$ yara /foo/bar/rules .

Appliquer les règles de /foo/bar/rules à tous les fichiers du répertoire courant. Les sous-répertoires ne sont pas analysés.

$ yara -t Packer -t Compiler /foo/bar/rules bazfile

Appliquer les règles de /foo/bar/rules à bazfile. Ne signale que les règles étiquetées Packer ou Compiler.

$ cat /foo/bar/rules | yara -r /foo

Analyser tous les fichiers du répertoire /foo et de ses sous-répertoires. Les règles sont lues depuis l'entrée standard.

$ yara -d mybool=true -d myint=5 -d mystring="my string" /foo/bar/rules bazfile

Définit trois variables externes : mybool, myint et mystring.

$ yara -x cuckoo=cuckoo_json_report /foo/bar/rules bazfile

Appliquer les règles de /foo/bar/rules à bazfile tout en passant le contenu de cuckoo_json_report au module cuckoo.
