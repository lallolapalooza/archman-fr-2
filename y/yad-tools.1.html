YAD-TOOLS(1) Commandes utilisateur YAD-TOOLS(1)

NOM

yad-tools - affiche diverses choses.

SYNTAXE

yad-tools [OPTIONS] CHAÎNE

DESCRIPTION

yad-tools est un petit utilitaire en ligne de commande pour obtenir des informations qui peuvent être utiles dans des scripts.

OPTIONS

Options générales

-f, --pfd
Ce mode est destiné à transformer les noms de polices de pango vers la spécification xft et vice versa. L'argument supplémentaire est le nom de la police.
-i, --icon
Ce mode est destiné à obtenir le chemin complet du fichier d'icône à partir du nom de l'icône. L'argument supplémentaire est le nom de l'icône.
-c, --color
Ce mode est destiné à travailler avec les couleurs.
--show-langs
Affiche la liste des langues disponibles pour la vérification orthographique. Ne fonctionne que si yad est compilé avec le support de GSpell.
--show-themes
Affiche la liste des thèmes GtkSourceView disponibles. Ne fonctionne que si yad est compilé avec le support de GtkSourceView.

Options du mode PFD

-x, --xft
Imprime le nom de la police au format xft. C'est le mode par défaut.
-p, --pango
Imprime le nom de la police au format pango.

Options du mode icône

-s, --size=TAILLE
Utilise la taille d'icône spécifiée. La taille par défaut est 24.
-t, --type=TYPE
Obtient la taille de l'icône à partir de l'un des types GTK+ prédéfinis. TYPE est l'un des éléments suivants : menu, button, small_toolbar, large_toolbar, dnd ou dialog.
-m, --mime
Obtient le nom générique de l'icône pour le type MIME spécifié.
--theme=THÈME
Utilise le thème d'icônes spécifié au lieu du thème par défaut.

Options du mode couleur

--pick
S'élève la couleur de l'écran.
