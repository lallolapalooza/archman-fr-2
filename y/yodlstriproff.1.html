NOM

yodlstriproff - supprimer les caractères de contrôle ASCII

SYNTAXE

commande | yodlstriproff > fichier_sortie

DESCRIPTION

Le programme yodlstriproff est un outil très simple pour supprimer les caractères de contrôle ASCII d'un flux, de sorte qu'il ne reste que de l'ASCII « brut ». Les séquences de contrôle supprimées sont ^H (retour arrière) suivi d'un caractère ; ce mécanisme est utilisé pour souligner ou mettre en gras du texte sur les terminaux qui le prennent en charge.

yodlstriproff est couramment utilisé avec les convertisseurs Yodl yodl2msless et yodl2manless.
