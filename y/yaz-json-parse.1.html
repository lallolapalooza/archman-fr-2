NOM

yaz-json-parse - Analyseur JSON YAZ

SYNTAXE

yaz-json-parse [-p]

DESCRIPTION

yaz-json-parse est un utilitaire qui démontre l'API JSON de YAZ. (yaz/json.h).

Le programme tente d'analyser un JSON depuis l'entrée standard (stdin). Il retournera le code de sortie 1 si l'analyse échoue et le message d'erreur d'analyse sera imprimé sur la sortie d'erreur standard (stderr). Le programme retourne le code de sortie 0 si l'analyse réussit, et ne retourne aucune sortie sauf si -p est donné (voir ci-dessous).

OPTIONS

-p

Permet à l'analyseur JSON d'afficher la chaîne de résultat JSON sur la sortie standard, si l'analyse depuis stdin a réussi. Si -p est donné deux fois, alors la sortie est une sortie multiligne avec indentation (pretty print).
