YKPAMCFG(1) Manuel du module PAM Yubico YKPAMCFG(1)

NOM

ykpamcfg - Gérer les paramètres utilisateur du module PAM Yubico

SYNTAXE

ykpamcfg [-1 | -2] [-A] [-p] [-i] [-v] [-V] [-h]

OPTIONS

-1

Utiliser le slot 1. C'est le mode par défaut.

-2

Utiliser le slot 2.

-A action

Choisir l'action à effectuer. Voir ACTIONS ci-dessous.

-p chemin

Spécifier le fichier de sortie, le défaut est ~/.yubico/challenge.

-i itérations

Nombre d'itérations à utiliser pour PBKDF2 de la réponse attendue.

-v

Activer le mode verbeux.

-V

Afficher la version et quitter.

-h

Afficher l'aide et quitter.

ACTIONS

add_hmac_chalresp

Le module PAM peut utiliser le mode Défi-Réponse HMAC-SHA1 (C/R) trouvé dans les YubiKeys à partir de la version 2.2 pour l'authentification hors ligne. Cette action crée les informations d'état initiales avec le C/R qui sera émis lors de la prochaine connexion.

L'utilitaire affiche actuellement les informations d'état dans un fichier dans le répertoire personnel de l'utilisateur actuel (~/.yubico/challenge-123456 pour une YubiKey avec lecture de numéro de série activée, et ~/.yubico/challenge pour une sans).

Le module PAM supporte un répertoire système pour ces fichiers d'état (au cas où les répertoires personnels des utilisateurs sont chiffrés), mais dans un répertoire système, la partie challenge devrait être remplacée par le nom d'utilisateur. Exemple : /var/yubico/challenges/alice-123456

Pour utiliser le mode système, vous devez actuellement déplacer manuellement les fichiers d'état générés et configurer le module PAM en conséquence.

EXEMPLES

D'abord, programmez une YubiKey pour le défi-réponse sur le slot 2 :

$ ykpersonalize -2 -ochal-resp -ochal-hmac -ohmac-lt64 -oserial-api-visible
...
Commit? (y/n) [n]: y

Maintenant, configurez l'utilisateur actuel pour exiger cette YubiKey pour la connexion :

$ ykpamcfg -2 -v
...
Stored initial challenge and expected response in '/home/alice/.yubico/challenge-123456'.

Ensuite, configurez l'authentification avec PAM par exemple comme ceci (faites une sauvegarde d'abord) :

/etc/pam.d/common-auth (d'Ubuntu 10.10) :

auth  required        pam_unix.so nullok_secure try_first_pass
auth  [success=1 new_authtok_reqd=ok ignore=ignore default=die] pam_yubico.so mode=challenge-response
auth  requisite       pam_deny.so
auth  required        pam_permit.so
auth  optional        pam_ecryptfs.so unwrap
