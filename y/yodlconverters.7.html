NOM

yodl2... - convertisseurs divers pour Yodl

SYNTAXE

yodl2... [OPTION]... FICHIER

DESCRIPTION

Cette page de manuel décrit les différents scripts shell qui convertissent des documents en langage Yodl vers d'autres formats. Les convertisseurs de base sont :

o
yodl2html(1) : convertit en HTML, écrit un fichier avec l'extension .html.
o
yodl2man(1) : convertit au format `man’ de nroff, écrit .man. Peut être traité ultérieurement avec, par exemple, nroff -Tascii -man fichier.man.
o
yodl2latex(1) : convertit en sortie LaTeX, écrit .latex. Peut être traité ultérieurement avec, par exemple, latex fichier.latex.
o
yodl2txt(1) : convertit en texte ASCII brut, écrit .txt. C'est un convertisseur très rudimentaire, en dernier recours.

OPTIONS

Les options sont identiques à celles du programme yodl(1).

En outre, les options suivantes sont disponibles :

o
`--no-warnings’ :
Par défaut, les convertisseurs appellent yodl(1) en utilisant l'option `-w’. L'option `--no-warnings’ supprime cette option.
o
`--intermediate=<nomdefichier>’ :
Par défaut, les fichiers utilisés pour la communication entre yodl et yodlpost sont supprimés après la conversion. L'option `--intermediate=<nomdefichier>’ peut être fournie pour conserver ces fichiers, nommés `<nomdefichier>’ et `<nomdefichier>.idx’.

FICHIERS

Chaque convertisseur yodl2format nécessite un fichier format.yo dans le chemin d'inclusion de Yodl (par exemple, `tmp/wip/macros’). Ce fichier est chargé automatiquement avant le chargement de `FICHIER’ (voir la syntaxe), pour rendre possible la conversion en format.

La sortie est écrite dans un ou plusieurs fichiers portant l'extension .format.
