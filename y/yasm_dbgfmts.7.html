YASM_DBGFMTS(7) Formats de débogage pris en charge par Yasm YASM_DBGFMTS(7)

NOM

yasm_dbgfmts - Formats de débogage pris en charge par Yasm

SYNTAXE

yasm -g format_debogage ...

DESCRIPTION

La distribution standard de Yasm inclut un certain nombre de modules pour différents formats de débogage. Les informations de débogage sont intégrées dans le fichier objet. L'utilisation d'un format de débogage non nul provoque également Yasm à sortir tous les symboles dans le fichier objet (y compris les symboles locaux).

Le format de débogage est sélectionné sur la ligne de commande yasm(1) à l'aide de l'option de ligne de commande -g format_debogage.

CV8

Le format de débogage CV8 est utilisé par Microsoft Visual Studio 2005 (version 8.0) et est complètement non documenté, bien qu'il présente des similarités fortes avec les formats CodeView antérieurs. Le support de Yasm pour le format de débogage CV8 est actuellement limité à la génération d'informations sur les numéros de ligne au niveau de l'assembleur (pour permettre un certain niveau de débogage au niveau source). Les informations de débogage CV8 sont stockées dans les sections .debug$S et .debug$T du fichier objet Win64.

DWARF2

Le format de débogage DWARF 2 est une norme complexe et bien documentée pour les informations de débogage. Il a été créé pour surmonter les lacunes de STABS, permettant des descriptions beaucoup plus détaillées et compactes des structures de données, du mouvement des variables de données et des structures linguistiques complexes comme en C++. Les informations de débogage sont stockées dans des sections (comme les sections de programme normales) dans le fichier objet. Yasm prend en charge le transfert complet des informations de débogage DWARF2 (par exemple, d'un compilateur C++) et peut également générer des informations sur les numéros de ligne au niveau de l'assembleur.

NULL

Le format de débogage « nul » est un espace réservé ; il n'ajoute aucune information de débogage au fichier de sortie.

STABS

Le format de débogage STABS est un format semi-standard, mal documenté, pour les informations de débogage dans les fichiers objets COFF et ELF. Les informations de débogage sont stockées dans la table des symboles du fichier objet et sont donc limitées en complexité et en portée. Malgré cela, STABS est un format de débogage courant sur les anciens systèmes Unix et compatibles, ainsi que DJGPP.
