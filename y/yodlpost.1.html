NOM

yodlpost - Post-processeur Yodl

SYNTAXE

yodlpost [options] index yodlout [out]

DESCRIPTION

Le post-processeur Yodl est utilisé pour résoudre les références dans le texte converti, et pour diviser (lorsque cela est approprié) le texte Yodl converti en parties. Certaines conversions ne nécessitent pas de post-traitement, comme LaTeX, mais la plupart en ont besoin. Par conséquent, dans la plupart des cas, une conversion Yodl se compose de deux phases :

o
Premièrement, yodl(1) est appelé, produisant un fichier de sortie brut et un fichier index associé ;
o
Ensuite, yodlpost(1) est appelé, convertissant ces deux fichiers en un document final. Normalement, les scripts yodl2...(1) sont utilisés pour effectuer des conversions Yodl complètes.

OPTIONS

-x ext : extension de out-s si différente de l'extension de out elle-même. Si omis, et si out n'a pas d'extension, ypp (Yodl Post Processor) est utilisé.
