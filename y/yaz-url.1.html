NOM

yaz-url - Utilitaire de récupération d'URL YAZ

SYNTAXE

yaz-url [-H nom:valeur] [-m méthode] [-O nomfichier] [-p nomfichier] [-R num] [-u utilisateur/motdepasse] [-v] [-x proxy] [url...]

DESCRIPTION

yaz-url est un utilitaire pour obtenir du contenu web. Ses fonctionnalités sont très limitées par rapport à des programmes tels que curl, wget.

Les options doivent précéder l'URL donnée sur la ligne de commande pour prendre effet.

Le contenu HTTP récupéré est écrit sur la sortie standard, sauf si l'option -O est donnée.

OPTIONS

-H nom:valeur

Spécifie le contenu de l'en-tête HTTP avec le nom et la valeur. Cette option peut être donnée plusieurs fois (pour des noms différents, bien sûr).

-m méthode

Spécifie la méthode HTTP à utiliser pour l'URL suivante. La méthode par défaut est "GET". Cependant, l'option -p la définit à "POST".

-O nomfichier

Définit le nom du fichier de sortie pour le contenu HTTP.

-p nomfichier

Définit un fichier à envoyer via POST à l'URL suivante.

-R num

Définit le nombre maximum de redirections HTTP à suivre. Une valeur de zéro désactive le suivi des redirections HTTP.

-u utilisateur/motdepasse

Spécifie un utilisateur et un mot de passe à utiliser dans l'authentification HTTP de base lors de la récupération de l'URL suivante. L'utilisateur et le mot de passe doivent être séparés par une barre oblique (il n'est donc pas possible de spécifier un utilisateur contenant une barre oblique).

-v

Fait en sorte que yaz-url affiche chaque requête/réponse HTTP sur la sortie standard.

-x proxy

Spécifie un proxy à utiliser pour la récupération de l'URL.
