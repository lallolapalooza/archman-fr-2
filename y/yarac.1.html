YARAC(1) règles de compilation vers yara YARAC(1)

NOM

yarac - compile les règles vers yara

SYNTAXE

yarac [OPTION]... [FICHIER_REGLES]... FICHIER_SORTIE

DESCRIPTION

Pour utiliser YARA, vous aurez besoin de deux choses : un fichier contenant les règles que vous souhaitez utiliser (sous forme de code source ou compilée) et la cible à analyser. La cible peut être un fichier, un dossier ou un processus.

Les fichiers de règles peuvent être passés directement sous forme de code source, ou peuvent être préalablement compilés avec l'outil yarac. Vous pourriez préférer utiliser vos règles sous forme compilée si vous prévoyez d'invoquer YARA plusieurs fois avec les mêmes règles. Vous gagnerez ainsi du temps, car il est plus rapide pour YARA de charger des règles compilées que de compiler les mêmes règles encore et encore.

Les règles seront appliquées à la cible spécifiée comme dernier argument de YARA. Si cet argument est un chemin vers un répertoire, tous les fichiers qu'il contient seront analysés.

OPTIONS

-d <identifiant>=<valeur>
définit une variable externe.
-w --pas-d-avertissements
Désactive les avertissements.
--traiter-avertissements-comme-erreurs
Traite les avertissements comme des erreurs. N'a aucun effet lorsqu'il est utilisé avec --pas-d-avertissements.
-v --version
Affiche les informations de version.

EXEMPLE

L'option -d est utilisée pour définir des variables externes. Par exemple :

-d flag=true

-d beast=666

-d name="James Bond"
