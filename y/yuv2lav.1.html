NOM

yuv2lav - encode les flux bruts de trames YUV de lavtool en fichiers MJPEG

SYNTAXE

yuv2lav [-f a|A|q|m] [-q num] [-b num] [-I num] [-m num] [-v num] [-w fichier] -o fichier-sortie

DESCRIPTION

yuv2lav est un encodeur MJPEG simple pour les flux bruts de trames YUV tels qu'ils sont émis par lav2yuv(1) ou lavpipe(1), par exemple. Il lit son entrée depuis stdin et est capable d'écrire en AVI et Quicktime.

OPTIONS

Les options de ligne de commande permettent de spécifier le nom du fichier de sortie, la qualité d'encodage JPEG et la quantité de mémoire qui sera allouée pour les données compressées JPEG.

-o fichier-sortie
Cette option (obligatoire) définit le nom du fichier dans lequel yuv2lav écrira sa sortie. Si le fichier de sortie contient un % (par exemple, fichier%02d.avi), la sortie sera écrite dans plusieurs fichiers si cela est nécessaire (fichier00.avi, fichier01.avi, etc.).
-f a|A|q
Ceci définit le format du fichier de sortie, qui doit être l'un des suivants :
 a - pour la sortie de fichier AVI,
 A - pour AVI avec champs inversés,
 q - pour la sortie Quicktime ou
AVI avec champs inversés n'a de sens que si le flux de yuv2lav est une source vidéo entrelacée et ne devrait être nécessaire que si vous rencontrez des problèmes d'inversion de trames dans votre sortie. Si vous n'utilisez pas cette option, yuv2lav définira le format de sortie sur AVI si les 3 derniers caractères sont avi, ou sur Quicktime si vous utilisez mov. Si vous utilisez l'option -f, elle remplace le paramètre dans le nom de fichier 
-q num
Cette option spécifie la qualité d'encodage JPEG telle que transmise à libjpeg. La valeur par défaut est 80. num doit être compris entre 24 et 100 inclus (pensez-y comme à des valeurs en pourcentage, bien qu'avec un algorithme de compression avec perte comme JPEG, conserver 100 % de la qualité d'origine ne soit bien sûr pas vraiment possible).
-b num
Cette option spécifie la taille du tampon (en Ko) que yuv2lav alloue pour stocker les données compressées JPEG. La valeur par défaut (256 Ko) est parfaitement suffisante pour PAL/NTSC pleine résolution à 100 % de qualité, mais si vous voulez compresser du Super-Mega-HDTV ou si vous avez peu de mémoire, vous pouvez utiliser cette option pour répondre à vos besoins.
-m num
C'est la taille maximale (en Mo) par fichier. Normalement, cela dépend du type de fichier de sortie.
-I num
Force un type d'entrelacement spécifique. 0 signifie pas d'entrelacement, 1 signifie champ supérieur en premier, 2 signifie champ inférieur en premier.
-w fichier
C'est le fichier WAV contenant les données audio à combiner avec le flux vidéo dans le fichier de sortie.
-v num
Niveau de verbosité. 0 signifie afficher uniquement les messages d'erreur, 2 affiche une sortie de débogage complète.
-?
Affiche une synthèse de la syntaxe de la commande.

EXEMPLES

lav2yuv movie.avi | yuv2lav -fq -q 30 lowbitrate.qt
recompresserait movie.avi en un fichier Quicktime à faible débit binaire.
lavpipe input.pli | yuv2lav -q80 output.avi
enregistrerait le film assemblé par lavpipe en un seul fichier AVI.
