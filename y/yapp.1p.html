NOM

yapp - Un frontal Perl pour le module Parse::Yapp

SYNTAXE

yapp [options] grammaire[.yp]

yapp -V

yapp -h

DESCRIPTION

yapp est un frontal pour le module Parse::Yapp, qui vous permet de compiler des fichiers d'entrée de grammaire Parse::Yapp en modules analyseurs Perl OO LALR(1).

OPTIONS

Les options, à ce jour, sont toutes optionnelles :-)

-v
Crée un fichier grammaire.output décrivant votre analyseur. Il vous affichera un résumé des conflits, des règles, les états du DFA (Automate Fini Déterministe) et l'utilisation globale de l'analyseur.
-s
Crée un module autonome dans lequel le pilote est inclus. Notez que si vous avez plus d'un module d'analyseur appelé depuis un programme, pour qu'il soit autonome, vous avez besoin de cette option uniquement pour un de vos modules d'analyseur.
-n
Désactive la numérotation des lignes du fichier source intégrée dans votre module d'analyseur. Je ne sais pas pourquoi on en aurait besoin, mais elle est là.
-m module
Donne à votre module d'analyseur le nom de package (ou espace de noms ou nom de module ou nom de classe ou quoi-que-tu-appelles-ça) de module. Il prend par défaut le nom de la grammaire.
-o outfile
Le fichier de sortie compilé sera nommé outfile pour votre module d'analyseur. Il prend par défaut grammaire.pm ou, si vous avez spécifié l'option -m A::Module::Name (voir ci-dessous), Name.pm, dans le répertoire de travail courant.
-t filename
L'option -t filename vous permet de spécifier un fichier qui sera utilisé comme modèle pour générer la sortie de l'analyseur. Par défaut, on utilise le modèle interne défini dans Parse::Yapp::Output.pm. Pour savoir comment écrire votre propre modèle et quelles substitutions sont disponibles, regardez le module Parse::Yapp::Output.pm : cela devrait être évident.
-b shebang
Si vous travaillez sur des systèmes qui comprennent les shebangs, et que votre analyseur généré est directement un script exécutable, vous pouvez en spécifier un avec l'option -b, c'est-à-dire : 
yapp -b '/usr/local/bin/perl -w' -o myscript.pl myscript.yp

Cela générera un fichier nommé myscript.pl dont la toute première ligne sera :

#!/usr/local/bin/perl -w

L'argument est obligatoire, mais si vous spécifiez une chaîne vide, la valeur de $Config{perlpath} sera utilisée à la place.

grammaire
Le fichier de grammaire d'entrée. Si aucun suffixe n'est donné et que le fichier n'existe pas, une tentative d'ouverture du fichier avec un suffixe de .yp est faite avant de sortir.
-V
Affiche la version actuelle de Parse::Yapp et quitte proprement.
-h
Affiche l'écran d'aide.
