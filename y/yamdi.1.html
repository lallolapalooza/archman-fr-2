YAMDI(1) Manuel des commandes générales YAMDI(1)

NOM

yamdi - injecteur de métadonnées (encore) (flv)

SYNTAXE

yamdi -i fichier d'entrée [-x fichier xml | -o fichier de sortie [-x fichier xml]] [-t fichier temporaire] [-c créateur] [-a intervalle] [-skMXw] [-h]

DESCRIPTION

yamdi signifie Yet Another MetaData Injector et est un injecteur de métadonnées pour les fichiers FLV. Il ajoute l'événement onMetaData à vos fichiers FLV.

OPTIONS

-i
Le fichier FLV source. Si le nom du fichier est '-', le fichier d'entrée sera lu depuis l'entrée standard. Utilisez l'option -t pour spécifier un fichier temporaire.
-o
Le fichier FLV résultant avec les métadonnées. Si le fichier de sortie est '-', le fichier FLV sera écrit sur la sortie standard.
-x
Un fichier XML contenant les informations de métadonnées résultantes. Si le fichier de sortie est omis, seules les métadonnées seront générées.
-t
Un fichier temporaire pour stocker le fichier FLV source si le fichier d'entrée est lu depuis l'entrée standard.
-c
Une chaîne de caractères qui sera écrite dans la balise creator.
-s, -l
Ajouter l'événement onLastSecond. L'option -l est obsolète et sera supprimée dans une future version.
-k
Ajouter l'événement onLastKeyframe.
-M
Supprimer toutes les métadonnées du FLV. Les options -s et -k seront ignorées.
-X
Omettre la balise keyframes dans la sortie XML.
-a
Temps en millisecondes entre les images clés s'il n'y a que de l'audio. Cette option sera ignorée s'il y a un flux vidéo. Aucune image clé ne sera ajoutée si cette option est omise.
-w
Remplacer le fichier d'entrée par le fichier de sortie. -i et -o sont requis pour être des fichiers différents, sinon cette option sera ignorée.
-h
Afficher un résumé des options.

STATUT DE SORTIE

yamdi se termine avec 0 en cas de succès, et >0 si une erreur se produit.
