YTFZF(5) Manuel des formats de fichiers YTFZF(5)

NOM

ytfzf - le fichier de configuration pour ytfzf.

SYNTAXE

~/.config/ytfzf/conf.sh

DESCRIPTION

Le fichier de configuration est un fichier .sh et peut être utilisé comme tel. Le fichier peut être complètement vide et ytfzf fonctionnera toujours avec les paramètres par défaut. Les options doivent être définies comme variables d'environnement et fonctions.

FICHIERS DE CONFIGURATION

Les fichiers de configuration sont stockés dans $XDG_CONFIG_HOME/ytfzf (ou $HOME/.config/ytfzf).

conf.sh

Un script shell qui est sourcé dans ytfzf lorsque ytfzf est exécuté.

abonnements

Un fichier qui contient une liste de liens vers la page vidéo de chaînes YouTube, comme ceci :

https://www.youtube.com/channel/UCtMVHI3AJD4Qk4hcbZnI9ZQ

Chaque lien doit être séparé par un saut de ligne.

Si une chaîne ressemble à "https://www.youtube.com/c/SomeOrdinaryGamers", exécutez
ytfzf --channel-link="https://www.youtube.com/c/SomeOrdinaryGamers"
avant de l'ajouter à votre fichier d'abonnements

Un commentaire peut être créé en plaçant '#comment' sur sa propre ligne ou après un lien. Par exemple :

lien-vers-la-chaine
#commentaire
lien-vers-la-chaine #meilleure chaine

scrapers

Un dossier contenant des fichiers exécutables qui scrapent des sites web. Voir SCRAPERS PERSONNALISÉS pour plus d'informations.

OPTIONS DE CONFIGURATION

VARIABLES

conf.sh est principalement utilisé pour définir des variables pour ytfzf. Si une variable n'a pas de valeur par défaut, cela signifie qu'elle est initialisée à une chaîne vide.
Pour définir une variable dans conf.sh, assurez-vous d'utiliser
nom_variable="valeur"
laissez le $ au début du nom de la variable.

Fichiers et répertoires

$cache_dir
Le répertoire pour stocker les fichiers de cache.
Il est fortement recommandé de ne changer ceci que si $__is_submenu est 0, ou des choses étranges pourraient arriver.
par défaut: $XDG_CACHE_HOME/ytfzf (ou $HOME/.cache/ytfzf)
$hist_file
Le fichier où écrire l'historique de visionnage si $enable_hist est 1.
Il est fortement recommandé de ne changer ceci que si $__is_submenu est 0, ou des choses étranges pourraient arriver.
par défaut: $cache_dir/watch_hist
$search_hist_file
Le fichier où écrire l'historique de recherche si $enable_search_hist est 1.
par défaut: $cache_dir/search_hist

Comment lire les vidéos sélectionnées.

$is_detach
Indique si le lecteur vidéo doit être détaché du terminal ou non.
par défaut: 0
$is_audio_only
Indique si seul l'audio doit être lu.
par défaut: 0
$url_handler
La fonction/les programmes pour gérer les vidéos sélectionnées.
Il est recommandé de ne pas définir cette variable directement, mais plutôt d'utiliser la commande load_url_handler.
Voir Gestionnaires d'URL pour une liste des gestionnaires d'URL intégrés. par défaut: multimedia_player
$yt_video_link_domain
Le domaine à utiliser pour lire les vidéos YouTube (ne s'applique pas aux playlists Odysee et PeerTube ou YouTube).
Si laissé vide, la valeur sera celle de l'instance Invidious choisie par ytfzf.
par défaut: https://www.youtube.com
$info_to_print
Les informations à imprimer au lieu de lire une vidéo. Les options disponibles pour cette variable sont :
L | l | link
Imprime l'URL des vidéos sélectionnées.
VJ | vj | video-json
Imprime le JSON de la vidéo sélectionnée.
J | j | json
Imprime le JSON de toutes les vidéos des résultats de recherche.
F | f | format
Imprime le format de la vidéo utilisé.
R | r | raw
Imprime les données de la vidéo sélectionnée, telles qu'elles apparaissent dans le menu.
$info_wait_action
L'action à effectuer lorsque $info_wait est 1.
Actions valides :
q
quitter (reviendra au menu, si $is_loop est 1).
Q
quitter, que la boucle soit activée ou non.
m
retourner au menu.
par défaut: q
$info_wait
Indique s'il faut attendre une entrée après avoir affiché les informations.
par défaut: 0
$video_pref
La préférence vidéo à utiliser pour youtube-dl dans mpv.
par défaut: bestvideo
$audio_pref
La préférence audio à utiliser pour youtube-dl dans mpv.
par défaut: bestaudio
$ytdl_pref
La préférence à utiliser pour youtube-dl dans mpv.
par défaut: $video_pref+$audio_pref/best/$video_pref/$audio_pref
$url_handler_opts
Options à passer au gestionnaire d'URL, par défaut cela passera des options supplémentaires à mpv. Ceci peut également être défini dans le fichier de configuration avec url_handler_opts

Analyse des options

$long_opt_char
Le caractère à utiliser pour les options longues.
par défaut: -
$optstring
La chaîne d'options à utiliser pour la fonction getopts.
Il est fortement déconseillé de modifier cette variable, sauf si vous savez ce que vous faites.
par défaut: ac:de:fhi:lmn:qrstu:xADHI:LS:T:W:$long_opt_char:
$YTFZF_CHECK_VARS_EXISTS
Si oui ou non vérifier si les variables de l'environnement existent déjà lors de la définition des options par défaut.
Cette option ne peut pas être définie dans la configuration, elle doit être définie dans votre shell de démarrage avec export, ou avant d'exécuter ytfzf, par exemple : YTFZF_CHECK_VARS_EXISTS=0 ytfzf ...

FONCTIONS

Parfois, une variable ne suffit pas, il faut plutôt définir des fonctions. Pour connaître la valeur par défaut de celles-ci, consultez le code source en recherchant function_exists "<function_you_are_looking_for>".

Si une miniature personnalisée et la miniature officielle n'existent pas, ytfzf essaiera d'utiliser $YTFZF_CUSTOM_THUMBNAILS_DIR/YTFZF:DEFAULT.jpg .

FORMAT JSON VIDÉO

C'est le format utilisé pour les playlists et les scrapers personnalisés.
Les vidéos doivent être des objets dans une liste.

Clés d'objet requises :

ID (string): un identifiant unique pour la vidéo
url (string): l'URL de la vidéo
title (string): le titre de la vidéo
scraper (string): Le scraper qui a créé le json (utilisé pour les miniatures)
thumbs (string): une URL vers une miniature/image
channel (string): le nom de la chaîne
duration (string): durée de la vidéo (standard : [HH:]MM:SS)
views (string): nombre de vues d'une vidéo
date (string): date de mise en ligne (standard : la date est relative au jour actuel, par ex : il y a 3 jours)
action (string): une action au format "action [clé=valeur clé2=valeur2...]"

Exemple JSON :

[
    {
	"ID": "dQw4w9WgXcQ",
	"url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
	"title": "definitely not never gonna give you up"
    }
]

EXTENSIONS

Les extensions sont essentiellement des fichiers de configuration supplémentaires que vous pouvez charger dans votre propre fichier de configuration.

Les extensions doivent se trouver soit dans $YTFZF_EXTENSIONS_DIR, soit dans $YTFZF_SYSTEM_ADDON_DIR/extensions.

Une extension peut faire tout ce qu'un fichier de configuration peut faire, y compris modifier les fonctions utilitaires par défaut de ytfzf (ce qui pourrait casser le script).

Les extensions recevront une variable appelée $__loaded_path qui est le chemin complet de l'extension chargée.
Ceci est utile pour déterminer le chemin d'exécution actuel de l'extension.

Pour charger une extension, ajoutez load_extension nom-de-l-extension à $YTFZF_CONFIG_FILE.

Il existe deux extensions chargées automatiquement : __ytfzf__ et __ytfzf_multisearch__
__ytfzf_multisearch__ n'est chargée que si $multi_search est 1.

Fonctions pour les extensions, où <ext> est remplacé par le nom de l'extension, et tous les - sont remplacés par _.
