GRDCTL(1) Commandes utilisateur GRDCTL(1)

NOM

grdctl - Outil en ligne de commande pour configurer le bureau à distance GNOME

SYNTAXE

grdctl [OPTION...] [COMMANDE] [SOUS-COMMANDE...]

DESCRIPTION

grdctl fournit des méthodes pour configurer le service de bureau à distance GNOME, par exemple pour définir les identifiants.

OPTIONS

--help

Afficher le texte d'aide.

COMMANDES GÉNÉRALES

status

Afficher le statut actuel.

COMMANDES RDP

rdp enable

Activer le backend RDP.

rdp disable

Désactiver le backend RDP.

rdp set-tls-cert CERT-TLS

Définir le chemin du certificat TLS.

rdp set-tls-key CLE-TLS

Définir le chemin de la clé TLS.

rdp set-credentials NOMUTILISATEUR MOTDEPASSE

Définir le nom d'utilisateur et le mot de passe.

rdp clear-credentials

Supprimer le nom d'utilisateur et le mot de passe.

rdp enable-view-only

Désactiver le contrôle à distance des périphériques d'entrée.

rdp disable-view-only

Activer le contrôle à distance des périphériques d'entrée.

COMMANDES VNC

vnc enable

Activer le backend VNC.

vnc disable

Désactiver le backend VNC.

vnc set-password MOTDEPASSE

Définir le mot de passe VNC.

vnc clear-password

Supprimer le mot de passe VNC.

vnc set-auth-method METHODE-AUTH

Définir la méthode d'authentification utilisée pour les nouvelles connexions VNC. Peut être soit password soit prompt.

vnc enable-view-only: Désactiver le contrôle à distance des périphériques d'entrée.

vnc disable-view-only

Activer le contrôle à distance des périphériques d'entrée.

BOGUES

Le traqueur de bogues est accessible en visitant le site web https://gitlab.gnome.org/GNOME/gnome-remote-desktop/issues. Avant d'envoyer un rapport de bogue, veuillez vérifier que vous disposez de la dernière version de gnome-remote-desktop. De nombreux bogues (majeurs et mineurs) sont corrigés à chaque version, et si la vôtre est obsolète, le problème peut déjà être résolu.
