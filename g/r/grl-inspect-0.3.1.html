grl-inspect(1) Manuel des commandes générales grl-inspect(1)

NOM

grl-inspect - afficher des informations sur les sources et clés Grilo

SYNTAXE

grl-inspect [options] [source|clé]

DESCRIPTION

Cette page de manuel documente brièvement la commande grl-inspect.

grl-inspect est un outil qui affiche des informations sur les sources et les clés de métadonnées Grilo disponibles. Lorsqu'il est exécuté sans argument SOURCE, grl-inspect affiche la liste de tous les plugins et sources. Lorsqu'il est exécuté avec une SOURCE, grl-inspect affiche des informations sur cette source.

Alternativement, l'utilisation de -k affiche des informations sur les clés de métadonnées disponibles.

OPTIONS

-h, --help
Afficher un résumé des options de grl-inspect.
--help-grl
Afficher un résumé des options Grilo.
--help-all
Afficher un résumé de toutes les options.
-k
Afficher des informations sur les clés de métadonnées
-d, --delay secondes
Attendre quelques secondes avant d'afficher les résultats. Utile lorsque les plugins peuvent avoir besoin de temps pour le processus de découverte de la source (exemple : UPnP). Si non spécifié, par défaut, il attend 1 seconde.
-c, --config fichier-config
Fichier de configuration à utiliser avec les plugins.
