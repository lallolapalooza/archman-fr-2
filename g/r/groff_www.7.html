Cette page manuelle décrit le paquet de macros GNU www, qui fait partie du système de mise en forme de documents groff(7). Ce fichier de macros est chargé automatiquement par le fichier par défaut troffrc lorsque le formateur (généralement groff(1)) est appelé avec l'une des options -Thtml ou -Txhtml. Pour voir les liens hypertexte en action, formatez cette page manuelle avec l'une de ces

options.

Ce document est un guide basique ; le pilote de sortie HTML (grohtml) est encore à l'état alpha. Il a été inclus dans la distribution pour encourager les

tests.

.IMG [-R|-L|-C] fichier [largeur]

Inclure une image dans le document. Le premier argument est la position horizontale : droite, gauche ou centre (-R, -L ou -C). L'alignement est centré par défaut (-C).
