grantpt(3) Manuel des fonctions de bibliothèque grantpt(3)

NOM

grantpt - accorder l'accès au pseudo-terminal esclave

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#define _XOPEN_SOURCE
#include <stdlib.h>
int grantpt(int fd);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

grantpt() :

    Depuis glibc 2.24 :
        _XOPEN_SOURCE >= 500
    glibc 2.23 et versions antérieures :
        _XOPEN_SOURCE

DESCRIPTION

La fonction grantpt() modifie le mode et le propriétaire du périphérique pseudo-terminal esclave correspondant au pseudo-terminal maître référencé par le descripteur de fichier fd. L'identifiant utilisateur de l'esclave est défini sur l'UID réel du processus appelant. L'identifiant du groupe est défini sur une valeur non spécifiée (par ex., tty). Le mode de l'esclave est défini sur 0620 (crw--w----).

Le comportement de grantpt() est non spécifié si un gestionnaire de signaux est installé pour intercepter les signaux SIGCHLD.

VALEUR DE RETOUR

En cas de succès, grantpt() retourne 0. Sinon, elle retourne -1 et définit errno pour indiquer l'erreur.

ERREURS

EACCES
Le pseudo-terminal esclave correspondant n'a pas pu être accédé.
EBADF
L'argument fd n'est pas un descripteur de fichier ouvert valide.
EINVAL
L'argument fd est valide mais n'est pas associé à un pseudo-terminal maître.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
grantpt () Sécurité des threads MT-Safe locale

NORMES

POSIX.1-2008.

HISTORIQUE

glibc 2.1. POSIX.1-2001.

Ceci fait partie du support des pseudo-terminaux UNIX 98, voir pts(4).

Les systèmes historiques implémentaient cette fonction via un binaire auxiliaire set-user-ID appelé « pt_chown ». glibc sur Linux avant glibc 2.33 pouvait également le faire, afin de supporter des configurations avec uniquement des pseudo-terminaux BSD ; ce support a été supprimé. Sur les systèmes modernes, il s'agit soit d'un no-op — avec les permissions configurées lors de l'allocation de pty, comme c'est le cas sous Linux — soit d'un ioctl(2).

VOIR AUSSI

open(2), posix_openpt(3), ptsname(3), unlockpt(3), pts(4), pty(7)
