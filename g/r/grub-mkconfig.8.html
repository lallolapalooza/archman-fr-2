NOM

grub-mkconfig - générer un fichier de configuration GRUB

SYNOPSIS

grub-mkconfig [OPTION]

DESCRIPTION

Génère un fichier de configuration grub

-o, --output=FICHIER
écrit la configuration générée dans FICHIER [défaut=stdout]
-h, --help
affiche ce message et quitte
-V, --version
affiche les informations de version et quitte

SIGNALER LES BOGUES

Signalez les bogues à <bug-grub@gnu.org>.

VOIR AUSSI

grub-install(8)

La documentation complète de grub-mkconfig est maintenue sous la forme d'un manuel Texinfo. Si les programmes info et grub-mkconfig sont correctement installés sur votre site, la commande

info grub-mkconfig

devrait vous donner accès au manuel complet.
