GRAB_PARTIAL_IMAGE(1) Commandes utilisateur GRAB_PARTIAL_IMAGE(1)

NOM

grab_partial_image - capture une image partielle à l'aide de libdc1394

SYNTAXE

grab_partial_image

DESCRIPTION

Capture une image partielle de la caméra. La caméra doit être compatible avec le format 7 (taille d'image évolutive). L'image sera enregistrée sous forme de carte en niveaux de gris portable dans Part.pgm.

OPTIONS

aucune

BOGUES

Le nom de fichier devrait être un argument de ligne de commande.
