NOM

grub-bios-setup - configurer un périphérique pour démarrer avec GRUB

SYNTAXE

grub-bios-setup [OPTION...] PÉRIPHÉRIQUE

DESCRIPTION

Configurer les images pour démarrer depuis PÉRIPHÉRIQUE.

Vous ne devriez normalement pas exécuter ce programme directement. Utilisez grub-install à la place.

-a, --allow-floppy
rendre le disque également amorçable en tant que disquette (par défaut pour les périphériques fdX). Peut causer des problèmes sur certains BIOS.
-b, --boot-image=FICHIER
utiliser FICHIER comme image de démarrage [défaut=boot.img]
-c, --core-image=FICHIER
utiliser FICHIER comme image principale [défaut=core.img]
-d, --directory=RÉPERTOIRE
utiliser les fichiers GRUB dans le répertoire RÉPERTOIRE [défaut=//boot/grub]
-f, --force
installer même si des problèmes sont détectés
-m, --device-map=FICHIER
utiliser FICHIER comme carte des périphériques [défaut=//boot/grub/device.map]
--no-rs-codes
N'appliquer aucun code reed-solomon lors de l'intégration de core.img. Cette option n'est disponible que sur les cibles BIOS x86.
-s, --skip-fs-probe
ne pas sonder pour les systèmes de fichiers sur PÉRIPHÉRIQUE
-v, --verbose
afficher des messages détaillés.
-?, --help
afficher cette liste d'aide
--usage
afficher un court message d'utilisation
-V, --version
afficher la version du programme

Les arguments obligatoires ou optionnels pour les options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.

PÉRIPHÉRIQUE doit être un périphérique du système d'exploitation (par exemple, /dev/sda).

SIGNALER DES BOGUES

Signalez les bogues à <bug-grub@gnu.org>.

VOIR AUSSI

grub-install(8), grub-mkimage(1), grub-mkrescue(1)

devrait vous donner accès au manuel complet.
