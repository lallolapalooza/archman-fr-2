GRUB-SET-DEFAULT(8) Utilitaires d'administration système GRUB-SET-DEFAULT(8)

NOM

grub-set-default - définit l'entrée de démarrage par défaut sauvegardée pour GRUB

SYNTAXE

grub-set-default [OPTION] ENTRÉE_MENU

DESCRIPTION

Définit l'entrée du menu de démarrage par défaut pour GRUB. Cela nécessite de définir GRUB_DEFAULT=saved dans /etc/default/grub.

-h, --help
affiche ce message et quitte
-V, --version
affiche les informations de version et quitte
--boot-directory=DIR
attend les images GRUB dans le répertoire DIR/grub au lieu du répertoire /boot/grub

ENTRÉE_MENU est un numéro, un titre d'élément de menu ou un identifiant d'élément de menu.

SIGNIFICATION DES BOGUES

Signalez les bogues à <bug-grub@gnu.org>.

VOIR AUSSI

grub-reboot(8), grub-editenv(1)

La documentation complète de grub-set-default est maintenue sous forme de manuel Texinfo. Si les programmes info et grub-set-default sont correctement installés sur votre site, la commande

info grub-set-default

devrait vous donner accès au manuel complet.
