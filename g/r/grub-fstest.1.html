GRUB-FSTEST(1) Commandes utilisateur GRUB-FSTEST(1)

NOM

grub-fstest - outil de débogage pour les pilotes de système de fichiers GRUB

SYNTAXE

grub-fstest [OPTION...] CHEMIN_IMAGE COMMANDES

DESCRIPTION

Outil de débogage pour le pilote de système de fichiers.

Commandes :
liste-blocs FICHIER
Affiche la liste des blocs de FICHIER.
cat FICHIER
Copie FICHIER vers la sortie standard.
cmp FICHIER LOCAL
Compare FICHIER avec le fichier local LOCAL.
cp FICHIER LOCAL
Copie FICHIER vers le fichier local LOCAL.
crc FICHIER
Obtient la somme de contrôle crc32 de FICHIER.
hex FICHIER
Affiche le contenu de FICHIER en hexadécimal.
ls CHEMIN
Liste les fichiers dans CHEMIN.
xnu_uuid PÉRIPHÉRIQUE
Calcule l'UUID XNU du périphérique.
zfs-bootfs ZFS_DATASET
Calcule le chemin de démarrage du jeu de données ZFS.
-c, --diskcount=NOMBRE
Spécifie le nombre de fichiers d'entrée.
-C, --crypto
Monte les périphériques de chiffrement.
-d, --debug=CHAÎNE
Définit la variable d'environnement de débogage.
-K, --zfs-key=FICHIER|prompt
Charge la clé de chiffrement ZFS.
-n, --length=NOMBRE
Gère N octets dans le fichier de sortie.
-r, --root=NOM_PÉRIPHÉRIQUE
Définit le périphérique racine.
-s, --skip=NOMBRE
Saute N octets du fichier de sortie.
-u, --uncompress
Décompresse les données.
-v, --verbose
Affiche des messages détaillés.
-?, --help
Donne cette liste d'aide
--usage
Donne un court message d'utilisation
-V, --version
Affiche la version du programme

Les arguments obligatoires ou facultatifs des options longues sont également obligatoires ou facultatifs pour toutes les options courtes correspondantes.

VOIR AUSSI
