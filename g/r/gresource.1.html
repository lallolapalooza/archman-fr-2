gresource(1)

Paquet: glib2-devel

Licences: LGPL-2.1-or-later

gresource() gresource()

Nom

gresource - Outil GResource

SYNTAXE

gresource [--section SECTION] list FICHIER [CHEMIN]
gresource [--section SECTION] details FICHIER [CHEMIN]
gresource [--section SECTION] extract FICHIER CHEMIN
gresource sections FICHIER
gresource help [COMMANDE]

DESCRIPTION

gresource offre une interface en ligne de commande simple pour GResource. Il vous permet de lister et d'extraire les ressources qui ont été compilées dans un fichier de ressources ou incluses dans un fichier ELF (un binaire ou une bibliothèque partagée).

Le fichier sur lequel opérer est spécifié par l'argument FICHIER.

Si un fichier ELF inclut plusieurs sections avec des ressources, il est possible de sélectionner celle sur laquelle opérer avec l'option --section. Utilisez la commande sections pour trouver les sections disponibles.

COMMANDES

list

Liste les ressources. Si SECTION est donnée, ne liste que les ressources de cette section. Si CHEMIN est donné, ne liste que les ressources correspondantes.

details

Liste les ressources avec détails. Si SECTION est donnée, ne liste que les ressources de cette section. Si CHEMIN est donné, ne liste que les ressources correspondantes. Les détails incluent la section, la taille et la compression de chaque ressource.

extract

Extrait la ressource nommée par CHEMIN vers stdout. Notez que les ressources peuvent contenir des données binaires.

sections

Liste les sections contenant des ressources. Ceci n'est intéressant que si FICHIER est un fichier ELF.

help

Affiche l'aide et quitte.
