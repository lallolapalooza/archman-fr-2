GROUPS(1) Commandes utilisateur GROUPS(1)

NOM

groups - affiche les groupes auxquels un utilisateur appartient

SYNTAXE

groups [OPTION]... [NOMUTILISATEUR]...

DESCRIPTION

Affiche les appartenances aux groupes pour chaque NOMUTILISATEUR ou, si aucun NOMUTILISATEUR n'est spécifié, pour le processus courant (ce qui peut différer si la base de données des groupes a changé).

--help
affiche cette aide et quitte
--version
affiche les informations de version et quitte
