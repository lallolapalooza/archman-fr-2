GREATERTHANEQUAL(3G) [FIXME: manuel] GREATERTHANEQUAL(3G)

NOM

greaterThanEqual - effectue une comparaison composant par composant de deux vecteurs supérieure ou égale

DÉCLARATION

bvec greaterThanEqual(vec x, vec y);

bvec greaterThanEqual(ivec x, ivec y);

bvec greaterThanEqual(uvec x, uvec y);

PARAMÈTRES

x

Spécifie le premier vecteur à utiliser dans l'opération de comparaison.

y

Spécifie le second vecteur à utiliser dans l'opération de comparaison.

DESCRIPTION

greaterThanEqual retourne un vecteur booléen dans lequel chaque élément i est calculé comme x[i] ≥ y[i].
