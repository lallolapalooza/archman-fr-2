grap2graph(1) Manuel des commandes générales grap2graph(1)

Nom

grap2graph - convertir un diagramme grap en une image rognée

Synopsis

grap2graph [-unsafe] [-format format-sortie] [argument-conversion ...]
grap2graph --help
grap2graph -v
grap2graph --version

Description

grap2graph lit un programme grap(1) depuis l'entrée standard et écrit un fichier image, par défaut au format Portable Network Graphics (PNG), vers la sortie standard.

Le code GRAP d'entrée ne doit pas être entouré des macros .G1 et .G2 qui le protègent normalement dans les documents groff(1).

Les arguments non reconnus par grap2graph sont passés au programme ImageMagick ou GraphicsMagick convert(1). En spécifiant ces derniers, vous pouvez ajouter une bordure à votre image, définir la densité de pixels de l'image, ou effectuer d'autres transformations utiles.

L'image de sortie est rognée à l'aide de l'option -trim de convert, de manière à obtenir la plus petite boîte englobante possible contenant tous les pixels noirs.

Options

--help affiche un message d'utilisation, tandis que -v et --version affichent des informations sur la version ; tous quittent ensuite.

-format format-sortie
Écrit l'image dans format-sortie, qui doit être compris par convert ; le format par défaut est PNG.
-unsafe
Exécute groff en mode unsafe, permettant à la commande PIC sh d'exécuter des commandes shell Unix arbitraires. Le défaut de groff est d'interdire cela.

Environnement

GROFF_TMPDIR
TMPDIR
TMP
TEMP
Ces variables d'environnement sont recherchées dans l'ordre donné pour déterminer le répertoire où les fichiers temporaires seront créés. Si aucune n'est définie, /tmp est utilisé.

Auteurs

grap2graph a été écrit par Eric S. Raymond, basé sur une recette pour pic2graph(1), par W. Richard Stevens.

Voir aussi

pic2graph(1), eqn2graph(1), grap(1), pic(1), groff(1), convert(1)
