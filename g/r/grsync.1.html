NOM

GRSYNC - interface GTK+ pour rsync

SYNTAXE

grsync [-e] [-s] [nom_session]

grsync -i nom_fichier_session

DESCRIPTION

GRSYNC est une interface graphique utilisant GTK2 pour le programme en ligne de commande rsync. Il prend actuellement en charge les fonctionnalités les plus importantes de rsync et peut être utilisé efficacement pour la synchronisation de répertoires locaux.

OPTIONS

Vous pouvez spécifier une session à charger au lieu de celle par défaut, en la tapant comme option en ligne de commande. L'option en ligne de commande "-e" exécute automatiquement la session et ferme grsync une fois terminée, sauf si une erreur a été rencontrée. Vous pouvez faire en sorte que grsync reste ouvert de toute façon en utilisant l'option "-s" (même si l'exécution de la session a été un succès).

La syntaxe alternative, utilisant le commutateur "-i", ouvrira la boîte de dialogue "importer session" sur le fichier que vous avez spécifié comme argument.
