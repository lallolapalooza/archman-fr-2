DESCRIPTIO

N

Gramps est un programme de généalogie libre et open source. Il est écrit en Python et utilise l'interface GTK+/GNOME. Gramps devrait sembler famili

er à toute personne ayant déjà utilisé d'autres programmes de généalogie tels que Family Tree Maker™, Personal Ancestral Files™ ou GNU Geneweb. Il
prend en charge l'importation du format GEDCOM, très populaire et utilisé dans le monde entier par presque tous les autres logiciels de généalogie.

Si FICHIER est un format de fichier compris par Gramps, un arbre généalogique vide est créé dont le nom est basé sur le FICHIER nom, et les données y sont importées. OPÉRATIO

N

Si le premier argument sur la ligne de commande ne commence pas par un tiret (c'est-à-dire aucun indicateur), gramps essaiera d'ouvrir le fichier portant le nom donné par le premier argument et démarrera une session interactive, en ignorant le reste des arguments de la ligne de

commande.

Si l'indicateur -O est donné, gramps essaiera d'ouvrir la base de données fournie puis travaillera avec ces données, comme indiqué par les paramètres suivants de la ligne de

commande.

Avec ou sans l'indicateur -O, des importations, exportations et actions supplémentaires peuvent être spécifiées sur la ligne de commande en utilisant les indicateurs -i, -e, et -a

.

L'ordre des options -i, -e, ou -a n'a pas d'importance. L'ordre réel de leur traitement est toujours : toutes les importations (le cas échéant) → toutes les actions (le cas échéant) → tous les exports (le cas échéant). Mais l'ouverture doit toujours être en premier

!

Si aucune option -O ou -i n'est donnée, gramps lancera sa fenêtre principale et démarrera la session interactive habituelle avec une base de données vide, puisqu'il n'y a de toute façon aucune donnée à

traiter.

Si aucune option -e ou -a n'est donnée, gramps lancera sa fenêtre principale et démarrt la session interactive habituelle avec la base de données résultant de toutes les importations. Cette base de données se trouve dans le import_db.grgrdb sous le ~/.gramps/import ré

pertoire.

Toute erreur rencontrée lors de l'importation, de l'exportation ou de l'action sera envoyée soit vers stdout (si ce sont des exceptions gérées par gramps) soit vers stderr (si ce ne sont pas des exceptions gérées). Utilisez les redirections habituelles du shell pour stdout et stderr afin de sauvegarder les messa

ges et les erreurs
dans des fichiers.
