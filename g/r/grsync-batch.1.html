NOM

GRSYNC-BATCH - Exécuteur de session par lots Grsync

SYNTAXE

grsync-batch [-f] [-d] [nom_session|nom_fichier]

DESCRIPTION

GRSYNC-BATCH est un script qui peut être utilisé pour automatiser les exécutions rsync en utilisant des sessions grsync (voir man grsync). Par exemple, il peut être placé dans crontab pour une exécution planifiée sur le terminal, et pour recevoir les résultats par e-mail.

OPTIONS

GRSYNC-BATCH charge par défaut la session que vous spécifiez sur la ligne de commande à partir de votre fichier de configuration par défaut grsync.ini. Si vous spécifiez l'option -f, elle sera traitée comme un nom de fichier à charger à la place. Dans ce cas, une seule session peut être présente dans le fichier, il n'est donc pas nécessaire de spécifier la session. L'option -d effectue un essai à blanc, c'est-à-dire une simulation (exécuter mais sans apporter de modifications).
