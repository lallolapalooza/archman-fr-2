GRUB-EDITENV(1) Commandes utilisateur GRUB-EDITENV(1)

NOM

grub-editenv - éditer le bloc d'environnement GRUB

SYNTAXE

grub-editenv [OPTION...] FICHIER COMMANDE

DESCRIPTION

Outil pour éditer le bloc d'environnement.

Commandes :
créer
Créer un fichier bloc d'environnement vide.
lister
Lister les variables actuelles.
définir [NOM=VALEUR ...]
Définir des variables.
supprimer [NOM ...]
Supprimer des variables.
Options :
-?, --help
afficher cette liste d'aide
--usage
afficher un bref message d'utilisation
-v, --verbose
afficher des messages détaillés.
-V, --version
afficher la version du programme

Si FICHIER est `-', la valeur par défaut //boot/grub/grubenv est utilisée.

Il n'y a pas de commande `supprimer' ; si vous voulez supprimer l'intégralité du bloc d'environnement, utilisez `rm //boot/grub/grubenv'.

SIGNALS DE BOGUES

Signaler les bogues à <bug-grub@gnu.org>.

VOIR AUSSI

grub-reboot(8), grub-set-default(8)

La documentation complète de grub-editenv est maintenue sous forme de manuel Texinfo. Si les programmes info et grub-editenv sont correctement installés sur votre site, la commande

info grub-editenv

devrait vous donner accès au manuel complet.
