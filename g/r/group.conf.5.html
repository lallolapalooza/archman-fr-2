NOM

group.conf - fichier de configuration pour le module pam_group

DESCRIPTION

Le module PAM pam_group n'authentifie pas l'utilisateur, mais il accorde des appartenances à des groupes (dans la phase de définition des identifiants du module d'authentification) à l'utilisateur. Ces appartenances sont basées sur le service pour lequel il postule.

Pour que ce module fonctionne correctement, il doit y avoir un fichier /etc/security/group.conf correctement formaté. Les espaces sont ignorés et les lignes peuvent être prolongées avec '\' (nouvelles lignes échappées). Le texte suivant un '#' est ignoré jusqu'à la fin de la ligne.

La syntaxe des lignes est la suivante :

services;ttys;utilisateurs;heures;groupes

Le premier champ, le champ services, est une liste logique de noms de services PAM auxquels la règle s'applique.

Le deuxième champ, le champ tty, est une liste logique de noms de terminaux auxquels cette règle s'applique.

Le troisième champ, le champ utilisateurs, est une liste logique d'utilisateurs, ou un groupe UNIX, ou un netgroup d'utilisateurs auxquels cette règle s'applique. Les noms de groupes sont précédés d'un symbole '%', tandis que les noms de netgroups sont précédés d'un symbole '@'.

Une liste logique signifie des jetons individuels qui sont optionnellement préfixés par '!' (non logique) et séparés par '&' (et logique) et '|' (ou logique).

Pour ces éléments, le simple caractère générique '*' peut être utilisé une seule fois. Avec les groupes UNIX ou les netgroups, aucun caractère générique ni opérateur logique n'est autorisé.

Le champ heures est utilisé pour indiquer "quand" ces groupes doivent être donnés à l'utilisateur. Le format ici est une liste logique d'entrées de jour/plage horaire. Les jours sont spécifiés par une séquence d'entrées de deux caractères, par exemple MoTuSa est lundi mardi et samedi. Notez que les jours répétés sont désactivés MoMo = aucun jour, et MoWk = tous les jours de semaine sauf lundi. Les combinaisons de deux caractères acceptées sont Mo Tu We Th Fr Sa Su Wk Wd Al, les deux derniers étant respectivement les jours de week-end et les 7 jours de la semaine. Comme dernier exemple, AlFr signifie tous les jours sauf vendredi.

Chaque jour/plage horaire peut être préfixé par '!' pour indiquer "tout sauf". La partie plage horaire est constituée de deux heures au format 24 heures HHMM, séparées par un trait d'union, indiquant l'heure de début et de fin (si l'heure de fin est inférieure à l'heure de début, elle est considérée comme s'appliquant le jour suivant).

Le champ groupes est une liste de groupes séparés par des virgules ou des espaces auxquels l'utilisateur hérite de l'appartenance. Ces groupes sont ajoutés si les champs précédents sont satisfaits par la demande de l'utilisateur.

Pour qu'une règle soit active, TOUS les services+ttys+utilisateurs doivent être satisfaits par le processus en cours.

EXEMPLES

Voici quelques lignes d'exemple qui pourraient être spécifiées dans /etc/security/group.conf.

Exécution de 'xsh' sur tty* (tout appareil ttyXXX), l'utilisateur 'us' se voit accorder l'accès à la disquette (par appartenance au groupe floppy)

xsh;tty*&!ttyp*;us;Al0000-2400;floppy

Exécution de 'xsh' sur tty* (tout appareil ttyXXX), les utilisateurs 'sword', 'pike' et 'shield' se voient accorder l'accès aux jeux (par appartenance au groupe floppy) après les heures de travail.

xsh; tty* ;sword|pike|shield;!Wk0900-1800;games, sound
xsh; tty* ;*;Al0900-1800;floppy

Tout membre du groupe 'admin' exécutant 'xsh' sur tty*, se voit accorder l'accès (à tout moment) au groupe 'plugdev'

xsh; tty* ;%admin;Al0000-2400;plugdev
