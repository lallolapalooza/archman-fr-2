GRC(1) Manuel des commandes générales GRC(1)

NOM

grc - interface pour coloriseur générique grcat(1)

SYNTAXE

grc [options] commande [arguments]

DESCRIPTION

grc exécutera la commande avec les paramètres optionnels [arguments] en redirigeant sa sortie standard (stdout) ou ses erreurs (stderr) vers grcat, avec un fichier de configuration approprié.

Le fichier de configuration pour grc est déterminé par le fichier /etc/grc.conf.

Format de /etc/grc.conf : chaque entrée se compose de 2 lignes, entre les entrées il peut y avoir n'importe quel nombre de lignes vides ou de lignes commençant par # (commentaires)

La première ligne est une expression régulière, la seconde ligne est le nom du fichier de configuration pour grcat.

Le fichier de configuration correspondant à la première expression régulière qui correspond à commande [arguments] sera passé à grcat comme son fichier de configuration.

OPTIONS

--help
Affiche un résumé des options.
--version
Affiche la version.
-e --stderr
Redirige la sortie d'erreur. Sauf si -s est également sélectionné, cela annule la redirection de la sortie standard via grcat.
-s --stdout
Redirige la sortie standard. Utilisé pour rediriger la sortie standard conjointement avec l'option --stderr.
--colour=x
x est l'une des valeurs : on, off, auto

--colour=on colorisera (par défaut)

--colour=off exécutera simplement commande sans colorisation.

--colour=auto testera si la sortie standard est un tty, et colorisera uniquement dans ce cas.
