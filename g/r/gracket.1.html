NOM

gracket - l'implémentation graphique de Racket

SYNTAXE

gracket [ option ... ] [ argument ... ]

DESCRIPTION

GRacket est la variante application graphique de racket.

Exécutez


gracket --help

pour obtenir une liste des options en ligne de commande et d'autres informations de démarrage.

Fournir aucun argument à gracket est équivalent à fournir l'option -i pour une évaluation interactive.

Fournir des arguments qui ne sont ni des commutateurs ni des options de configuration à gracket est équivalent à placer -u avant les arguments pour exécuter le premier argument comme un script basé sur les modules.

PLUS D'INFORMATIONS

Pour plus d'informations, exécutez


raco docs

pour ouvrir la documentation installée dans votre navigateur Web.

Alternativement, consultez la documentation en ligne et d'autres informations disponibles sur


http://racket-lang.org/
