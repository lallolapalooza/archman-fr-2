NOM

grub-mount - exporter le système de fichiers GRUB avec FUSE

SYNOPSIS

grub-mount [OPTION...] IMAGE1 [IMAGE2 ...] POINT_DE_MONTAGE

DESCRIPTION

Outil de débogage pour le pilote de système de fichiers.

-C, --crypto
Monter les périphériques cryptés.
-d, --debug=CHAÎNE
Définir la variable d'environnement de débogage.
-K, --zfs-key=FICHIER|invite
Charger la clé de chiffrement zfs.
-r, --root=NOM_PÉRIPHÉRIQUE
Définir le périphérique racine.
-v, --verbose
afficher des messages détaillés.
-?, --help
donner cette liste d'aide
--usage
donner un bref message d'utilisation
-V, --version
afficher la version du programme

Les arguments obligatoires ou optionnels pour les options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.

VOIR AUSSI

La documentation complète de grub-mount est maintenue sous forme de manuel Texinfo. Si les programmes info et grub-mount sont correctement installés sur votre site, la commande

info grub-mount

devrait vous donner accès au manuel complet.
