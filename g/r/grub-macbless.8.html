GRUB-MACBLESS(8) Utilitaires d'administration système GRUB-MACBLESS(8)

NOM

grub-macbless - rendre visible un fichier/répertoire Mac

SYNTAXE

grub-macbless [OPTION...] --ppc CHEMIN|--x86 FICHIER

DESCRIPTION

Rend visible un fichier/répertoire de style Mac sur HFS ou HFS+

-p, --ppc
rendre visible pour les macs basés sur ppc
-v, --verbose
afficher des messages détaillés.
-x, --x86
rendre visible pour les macs basés sur x86
-?, --help
afficher cette liste d'aide
--usage
afficher un court message d'utilisation
-V, --version
afficher la version du programme

SIGNALER LES BOGUES

Signalez les bogues à <bug-grub@gnu.org>.

VOIR AUSSI

grub-install(1)

La documentation complète de grub-macbless est maintenue sous forme de manuel Texinfo. Si les programmes info et grub-macbless sont correctement installés sur votre site, la commande

info grub-macbless

devrait vous donner accès au manuel complet.
