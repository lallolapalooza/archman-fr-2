group(5) Manuel des formats de fichiers group(5)

NOM

group - fichier des groupes d'utilisateurs

DESCRIPTION

Le fichier /etc/group est un fichier texte qui définit les groupes du système. Il y a une entrée par ligne, avec le format suivant :


nom_groupe:mot_de_passe:GID:liste_utilisateurs

Les champs sont les suivants :

nom_groupe
le nom du groupe.
mot_de_passe
le mot de passe du groupe (chiffré). Si ce champ est vide, aucun mot de passe n'est requis.
GID
l'identifiant numérique du groupe.
liste_utilisateurs
une liste des noms d'utilisateur qui sont membres de ce groupe, séparés par des virgules.

FICHIERS

/etc/group

BOGUES

Comme le dit la page de manuel de 4.2BSD initgroups(3) : personne ne semble garder /etc/group à jour.

VOIR AUSSI

chgrp(1), gpasswd(1), groups(1), login(1), newgrp(1), sg(1), getgrent(3), getgrnam(3), gshadow(5), passwd(5), vigr(8)
