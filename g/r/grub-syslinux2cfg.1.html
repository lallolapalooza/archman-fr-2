GRUB-SYSLINUX2CFG(1) Commandes utilisateur GRUB-SYSLINUX2CFG(1)

NOM

grub-syslinux2cfg - transformer une configuration syslinux en grub.cfg

SYNTAXE

grub-syslinux2cfg [OPTION...] FICHIER

DESCRIPTION

Transformer une configuration syslinux en une configuration GRUB.

-c, --cwd=RÉPERTOIRE
répertoire courant de syslinux [par défaut, le répertoire parent du fichier d'entrée].
-i, --isolinux
supposer que l'entrée est un fichier de configuration isolinux.
-o, --output=FICHIER
écrire la sortie dans FICHIER [par défaut, la sortie standard].
-p, --pxelinux
supposer que l'entrée est un fichier de configuration pxelinux.
-r, --root=RÉPERTOIRE
répertoire racine du disque syslinux [par défaut, /].
-s, --syslinux
supposer que l'entrée est un fichier de configuration syslinux.
-t, --target-root=RÉPERTOIRE
répertoire racine tel qu'il sera vu à l'exécution [par défaut, /].
-T, --target-cwd=RÉPERTOIRE
répertoire courant de syslinux tel qu'il sera vu à l'exécution [par défaut, le répertoire parent du fichier d'entrée].
-v, --verbose
afficher des messages détaillés.
-?, --help
afficher cette liste d'aide
--usage
afficher un court message d'utilisation
-V, --version
afficher la version du programme

Les arguments obligatoires ou optionnels des options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.

SIGNALLER DES BOGUES

Signaler les bogues à <bug-grub@gnu.org>.

VOIR AUSSI
