GRUB-INSTALL(8) Utilitaires d'administration système GRUB-INSTALL(8)

NOM

grub-install - installer GRUB sur un périphérique

SYNTAXE

grub-install [OPTION...] [OPTION] [PÉRIPHÉRIQUE_INSTALLATION]

DESCRIPTION

Installe GRUB sur votre disque.

--appended-signature-size=TAILLE
Ajoute un segment de note réservant TAILLE octets pour une signature ajoutée
--compress=non|xz|gz|lzo
compresse les fichiers GRUB [optionnel]
--disable-cli
désactive l'accès à l'interface en ligne de commande
--disable-shim-lock
désactive le vérificateur shim_lock
--dtb=FICHIER
intègre un DTB spécifique
-d, --directory=RÉPERTOIRE
utilise les images et modules sous RÉPERTOIRE [défaut=/usr/lib/grub/<plateforme>]
--fonts=POLICES
installe POLICES [défaut=unicode]
--install-modules=MODULES
installe seulement MODULES et leurs dépendances [défaut=tout]
-k, --pubkey=FICHIER
intègre FICHIER comme clé publique pour la vérification de signature
--directory-locale=RÉPERTOIRE utilise les traductions sous RÉPERTOIRE
[défaut=/usr/share/locale]
--locales=LOCALES
installe seulement LOCALES [défaut=tout]
--modules=MODULES
préchauffe les modules spécifiés MODULES
--sbat=FICHIER
métadonnées SBAT
--themes=THÈMES
installe THÈMES [défaut=starfield]
-v, --verbose
affiche des messages détaillés.
-x, --x509key=FICHIER
intègre FICHIER comme certificat x509 pour la vérification de signature ajoutée
--allow-floppy
rend le périphérique également démarrable en tant que disquette (par défaut pour les périphériques fdX). Peut causer des problèmes sur certains BIOS.
--boot-directory=RÉPERTOIRE
installe les images GRUB sous le répertoire RÉPERTOIRE/grub au lieu du répertoire /boot/grub
--bootloader-id=ID
l'ID du chargeur de démarrage. Cette option n'est disponible que sur EFI et Macs.
--core-compress=xz|none|auto
choisit la compression à utiliser pour l'image cœur
--disk-module=MODULE
module disque à utiliser (biosdisk ou native). Cette option n'est disponible que sur la cible BIOS.
--efi-directory=RÉPERTOIRE
utilise RÉPERTOIRE comme racine de la partition système EFI.
--force
installe même si des problèmes sont détectés
--force-file-id
utilise le fichier identificateur même si l'UUID est disponible
--label-bgcolor=COULEUR
utilise COULEUR pour l'arrière-plan du label
--label-color=COULEUR
utilise COULEUR pour le label
--label-font=FICHIER
utilise FICHIER comme police pour le label

--macppc-directory=RÉPERTOIRE utilise RÉPERTOIRE pour l'installation PPC MAC.

--no-bootsector
n'installe pas le secteur de démarrage
--no-nvram
ne met pas à jour les variables NVRAM `boot-device'/`Boot*'. Cette option n'est disponible que sur les cibles EFI et IEEE1275.
--no-rs-codes
N'applique aucun code reed-solomon lors de l'intégration de core.img. Cette option n'est disponible que sur les cibles BIOS x86.
--product-version=CHAÎNE
utilise CHAÎNE comme version du produit
--recheck
supprime la carte du périphérique si elle existe déjà
--removable
le périphérique d'installation est amovible. Cette option n'est disponible que sur EFI.
-s, --skip-fs-probe
ne pas sonder les systèmes de fichiers sur PÉRIPHÉRIQUE
--target=CIBLE
installe GRUB pour la plateforme CIBLE [défaut=x86_64-efi] ; cibles disponibles : arm-coreboot, arm-efi, arm-uboot, arm64-efi, i386-coreboot, i386-efi, i386-ieee1275, i386-multiboot, i386-pc, i386-qemu, i386-xen, i386-xen_pvh, ia64-efi, loongarch64-efi, mips-arc, mips-qemu_mips, mipsel-arc, mipsel-loongson, mipsel-qemu_mips, powerpc-ieee1275, riscv32-efi, riscv64-efi, sparc64-ieee1275, x86_64-efi, x86_64-xen
-?, --help
affiche cette liste d'aide
--usage
affiche un court message d'utilisation
-V, --version
affiche la version du programme

Les arguments obligatoires ou optionnels des options longues sont aussi obligatoires ou optionnels pour les options courtes correspondantes.

PÉRIPHÉRIQUE_INSTALLATION doit être le nom de fichier du périphérique système. grub-install copie les images GRUB dans /boot/grub. Sur certaines plateformes, il peut également installer GRUB dans le secteur de démarrage.

SIGNALEMENT DES BOGUES

Signaler les bogues à <bug-grub@gnu.org>.

VOIR AUSSI

grub-mkconfig(8), grub-mkimage(1), grub-mkrescue(1)

La documentation complète de grub-install est maintenue sous forme de manuel Texinfo. Si les programmes info et grub-install sont correctement installés sur votre site, la commande

info grub-install

devrait vous donner accès au manuel complet.

grub-install.8.en.html

NAME

grub-install - Install GRUB to a drive or partition

SYNOPSIS

grub-install [OPTION...] [INSTALL_TO]

DESCRIPTION

This manual page documents the grub-install utility. grub-install is a tool for installing the GRUB boot loader to a drive or partition.

The INSTALL_TO argument specifies the drive or partition where GRUB should be installed. For example, /dev/sda or /dev/sda1.

[OPTION...] can be used to specify various installation options. Some common options include:

  • --target=TARGET: Specifies the architecture for which GRUB is being installed (e.g., i386-pc, x86_64-efi).
  • --boot-directory=DIR: Sets the directory where GRUB's boot files will be installed. Defaults to /boot/grub.
  • --efi-directory=DIR: Sets the directory where GRUB's EFI boot files will be installed.
  • --bootloader-id=ID: Sets the identifier for the bootloader entry (e.g., GRUB).
  • --modules=MODULES: Specifies a comma-separated list of GRUB modules to load.
  • --no-nvram: Do not register the bootloader with the UEFI firmware's NVRAM.
  • --removable: Install GRUB to the first available removable device.

REPORTING BUGS

Report bugs to bug-grub@gnu.org.

SEE ALSO

grub-mkconfig(8), grub.cfg(5)
