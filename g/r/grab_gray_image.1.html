GRAB_GRAY_IMAGE(1) Commandes utilisateur GRAB_GRAY_IMAGE(1)

NOM

grab_gray_image - capture une image en utilisant libdc1394

SYNTAXE

grab_gray_image

DESCRIPTION

Récupère une image en niveaux de gris à l'aide de libdc1394 et la stocke dans le format portable de carte de niveaux de gris dans Image.pgm

OPTIONS

aucune

BOGUES

Le nom de fichier devrait être un argument de ligne de commande

AUTEUR
