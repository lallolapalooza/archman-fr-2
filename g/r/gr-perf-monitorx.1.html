GR-CTRLPORT-MONITOR(1) Commandes utilisateur GR-CTRLPORT-MONITOR(1)

NOM

gr-ctrlport-monitor - GUI de contrôle des ports gnuradio

SYNTAXE

gr-ctrlport-monitor [options]

OPTIONS

-h, --help
afficher ce message d'aide et quitter
-H HÔTE, --host=HÔTE
Nom d'hôte du serveur ControlPort.
-p PORT, --port=PORT
Numéro de port du point d'accès ControlPort de l'hôte.
-i INTERFACES, --interfaces=INTERFACES
Interfaces à utiliser. [défaut=['lo']]
-P PROTOCOLE, --protocol=PROTOCOLE
Type de protocole à utiliser (généralement tcp). [défaut=tcp]
-a APP, --app=APP
Nom de l'application [défaut=gnuradio]

gr-ctrlport-monitor: erreur : option inexistante : --version

VOIR AUSSI

La documentation complète de Usage: est maintenue sous forme de manuel Texinfo. Si les programmes info et Usage: sont correctement installés sur votre site, la commande

info Usage:

devrait vous donner accès au manuel complet.
