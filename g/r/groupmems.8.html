GROUPMEMS(8) Commandes de gestion système GROUPMEMS(8)

NOM

groupmems - administrer les membres du groupe primaire d'un utilisateur

SYNTAXE

groupmems -a nom_utilisateur | -d nom_utilisateur | [-g nom_groupe] | -l | -p

DESCRIPTION

La commande groupmems permet à un utilisateur d'administrer sa propre liste de membres de groupe sans nécessiter les privilèges de superutilisateur. L'utilitaire groupmems est destiné aux systèmes qui configurent leurs utilisateurs pour qu'ils soient dans leur propre groupe primaire éponyme (c'est-à-dire, guest / guest).

Seul le superutilisateur, en tant qu'administrateur, peut utiliser groupmems pour modifier les appartenances d'autres groupes.

OPTIONS

Les options qui s'appliquent à la commande groupmems sont :

-a, --add nom_utilisateur

Ajouter un utilisateur à la liste des membres du groupe.

Si le fichier /etc/gshadow existe, et que le groupe n'a pas d'entrée dans le fichier /etc/gshadow, une nouvelle entrée sera créée.

-d, --delete nom_utilisateur

Supprimer un utilisateur de la liste des membres du groupe.

Si le fichier /etc/gshadow existe, l'utilisateur sera retiré de la liste des membres et administrateurs du groupe.

Si le fichier /etc/gshadow existe, et que le groupe n'a pas d'entrée dans le fichier /etc/gshadow, une nouvelle entrée sera créée.

-g, --group nom_groupe

Le superutilisateur peut spécifier quelle liste de membres de groupe modifier.

-h, --help

Afficher le message d'aide et quitter.

-l, --list

Lister la liste des membres du groupe.

-p, --purge

Supprimer tous les utilisateurs de la liste des membres du groupe.

Si le fichier /etc/gshadow existe, et que le groupe n'a pas d'entrée dans le fichier /etc/gshadow, une nouvelle entrée sera créée.

-R, --root REPERTOIRE_CHROOT

Appliquer les modifications dans le répertoire REPERTOIRE_CHROOT et utiliser les fichiers de configuration du répertoire REPERTOIRE_CHROOT. Seuls les chemins absolus sont pris en charge.

CONFIGURATION

La commande groupmems doit être en mode 2710 en tant qu'utilisateur root et dans le groupe groups. L'administrateur système peut ajouter des utilisateurs au groupe groups pour leur permettre ou leur refuser d'utiliser l'utilitaire groupmems pour gérer leur propre liste de membres de groupe.

	$ groupadd -r groups
	$ chmod 2710 groupmems
	$ chown root:groups groupmems
	$ groupmems -g groups -a gk4

FICHIERS DE CONFIGURATION

Les variables de configuration suivantes dans /etc/login.defs modifient le comportement de cet outil :

MAX_MEMBERS_PER_GROUP (nombre)

Nombre maximal de membres par entrée de groupe. Lorsque le maximum est atteint, une nouvelle entrée de groupe (ligne) est créée dans /etc/group (avec le même nom, le même mot de passe et le même GID).

La valeur par défaut est 0, ce qui signifie qu'il n'y a aucune limite au nombre de membres dans un groupe.

Cette fonctionnalité (groupes divisés) permet de limiter la longueur des lignes dans le fichier de groupe. Ceci est utile pour s'assurer que les lignes de groupes NIS ne dépassent pas 1024 caractères.

Si vous avez besoin de faire respecter une telle limite, vous pouvez utiliser 25.

Note : les groupes divisés peuvent ne pas être pris en charge par tous les outils (même dans la suite d'outils Shadow). Vous ne devriez pas utiliser cette variable à moins d'en avoir vraiment besoin.
