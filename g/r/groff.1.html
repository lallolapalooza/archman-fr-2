Description

groff est l'interface principale du système de mise en forme de documents GNU roff . GNU roff est un système de composition typographique qui lit des fichiers de texte brut contenant des commandes de mise en forme pour produire une sortie au format PostScript, PDF, HTML, DVI ou d'autres formats, ou pour l'affichage sur un terminal. Les commandes de mise en forme peuvent être des primitives typographiques de bas niveau, des macros d'un paquet fourni ou des macros définies par l'utilisateur. Les trois approches peuvent être combinées. Si aucun file n'est spécifié, ou si file est «-», groff lit le flux d'entrée standard.

Réimplémentation et extension du composeur typographique d'AT&T Unix, groff est présent sur la plupart des systèmes POSIX en raison de sa longue association avec les manuels Unix (y compris les pages man). Lui et son prédécesseur sont remarquables pour la production de plusieurs ouvrages de génie logiciel à succès. groff est capable de produire des documents typographiquement sophistiqués tout en consommant des ressources système minimales.

La commande groff orchestre l'exécution des préprocesseurs, la transformation des documents d'entrée en un langage de description de page indépendant de l'appareil, et la production de la sortie à partir de ce langage.

Options

-h et --help affichent un message d'utilisation et se terminent.

Comme groff est destiné à remplacer la plupart des invocations directes de troff(1) par les utilisateurs, les deux programmes partagent un ensemble d'options. Cependant, groff a des options que troff ne partage pas, et d'autres que groff interprète différemment. En même temps, toutes les options troff valides ne peuvent pas être données à groff.

Postprocesseurs

Tout programme qui interprète la sortie de GNU troff est un postprocesseur. Les postprocesseurs fournis par GNU roff sont des pilotes de sortie, qui préparent un document pour l'affichage ou l'impression. Des postprocesseurs à d'autres fins, comme le réordonnancement des pages ou la mesure statistique d'un document, sont concevables.

Un pilote de sortie prend en charge un ou plusieurs périphériques de sortie, chacun avec son propre fichier de description de périphérique. Un périphérique détermine son postprocesseur avec la directive postpro dans son fichier de description de périphérique ; voir groff_font(5). L'option -X remplace cette sélection, faisant que gxditview sert de pilote de sortie.

Code de retour

groff se termine avec un code d'échec s'il y a eu un problème lors de l'analyse de ses arguments, et un code de succès si l'une des options -h ou --help a été spécifiée. Sinon, groff exécute un pipeline pour traiter son entrée ; si toutes les commandes du pipeline se terminent avec succès, groff en fait de même. Sinon, groffencode dans son code de retour un résumé des problèmes rencontrés, en définissant le bit 0 si une commande s'est terminée avec un code d'échec, le bit 1 si une commande a été terminée par un signal, et le bit 2 si une commande n'a pas pu être exécutée. (Ainsi, si les trois malheurs frappaient un pipeline, groff se terminerait avec le code 2^0 + 2^1 + 2^2 = 1+2+4 = 7.) Pour dépanner les problèmes de pipeline, vous pouvez relancer la commande groff avec l'option -V et décomposer le pipeline rapporté en étapes séparées, en inspectant le code de retour et les messages de diagnostic émis par chaque commande.

Environnement

Normalement, le séparateur de chemin dans les variables d'environnement se terminant par PATH est le deux-points ; cela peut varier selon le système d'exploitation. Par exemple, Windows utilise un point-virgule à la place.

GROFF_BIN_PATH
Ce chemin de recherche, suivi de PATH, est utilisé pour localiser les commandes exécutées par groff. S'il n'est pas défini, le répertoire d'installation des exécutables GNU roff , /usr/bin, est recherché avant PATH.
GROFF_COMMAND_PREFIX
GNU roff peut être configuré à la compilation pour appliquer un préfixe aux noms des programmes qu'il fournis qui avaient un équivalent dans AT&T troff, afin d'éviter les collisions de noms à l'exécution. Le préfixe par défaut est vide.
Lorsqu'il est utilisé, ce préfixe est conventionnellement la lettre « g ». Par exemple, GNU troff serait installé comme gtroff. En plus de troff, le préfixe s'applique au formateur nroff; aux préprocesseurs eqn, grn, pic, refer, tblet soelim; et aux utilitaires indxbib et lookbib.

La valeur de cette variable est passée à l'option preconv(1) du préprocesseur -e pour sélectionner l'encodage de caractères des fichiers d'entrée. L'existence de cette variable implique l'option groff -k. Si définie mais vide, groff appelle preconv sans option -e . L'optionde -K de groffremplace

Rechercher le répertoire des fichiers de description de périphérique et de polices du périphérique de sortie sélectionné dans cette liste de répertoires. Voir troff(1) et groff_font(5).
GROFF_TMAC_PATH
Rechercher les fichiers de macro dans cette liste de répertoires. Voir troff(1) et groff_tmac(5).
GROFF_TMPDIR
