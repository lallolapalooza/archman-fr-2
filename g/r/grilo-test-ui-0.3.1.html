NOM

grilo-test-ui - Interface utilisateur de test Grilo

SYNTAXE

grilo-test-ui [options]

DESCRIPTION

Cette page de manuel documente brièvement la commande grilo-test-ui.

grilo-test-ui est une interface graphique pour Grilo qui permet à l'utilisateur d'effectuer des requêtes et de voir leurs résultats.

OPTIONS

-h, --help
Affiche un résumé des options de grilo-test-ui.
--help-grl
Affiche un résumé des options de Grilo.
--help-all
Affiche un résumé de toutes les options.
