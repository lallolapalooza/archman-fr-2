Le pilote de sortie PDF GNU roff traduit la sortie de troff(1) en Portable Document Format. Normalement, gropdf est invoqué par groff(1) lorsque ce dernier reçoit l'option «-T pdf ». (Dans cette installation, ps est le périphérique de sortie par défaut.) Utilisez l'option -P de groff pour transmettre à gropdf toute option indiquée ci-dessus. Si aucun argument fichier n'est donné, ou si fichier vaut « - », gropdf lit le flux d'entrée standard. La sortie est écrite dans le flux de sortie

standard.

Utilisati

on

L'entrée de gropdf doit être au format produit par troff(1). Ceci est décrit dans groff_out(5). De plus, les fichiers de description du périphérique et des polices pour le périphérique utilisé doivent satisfaire certaines exigences : la résolution doit être un multiple entier de 72 fois le sizescale. Le périphérique pdf utilise une résolution de 72000 et un sizescale de

1000.

Le fichier de description du périphérique doit contenir un format de papier valide ; voir groff_font(5). gropdf utilise les mêmes polices Adobe PostScript Type 1 que le pilote de périphérique grops. Bien que la norme PDF autorise l'utilisation d'autres types de polices (comme TrueType), cette implémentation n'accepte que la police PostScript Type 1. Moins de polices Type 1 sont prises en charge nativement dans les documents PDF que les 35 polices standard prises en charge par grops et toutes les imprimantes PostScript, mais toutes les polices sont disponibles car celles qui ne sont pas prises en charge nativement sont automatiquement intégrées dans le

PDF.

gropdf prend en charge le concept de fonderies, c'est-à-dire différentes versions de fondamentalement la même police. Lors de l'installation, un fichier Foundry contrôle l'emplacement où les polices sont trouvées et construit les polices groff à partir des fichiers qu'il découvre sur votre

système.

Chaque fichier de description de police doit contenir une

commande

Le code de chaque caractère donné dans le fichier de police doit correspondre au code dans l'encodage par défaut de la police. Ce code peut être utilisé avec la séquence d'échappement \N dans troff pour sélectionner le caractère, même si le caractère n'a pas de nom groff. Chaque caractère du fichier de police doit exister dans la police PostScript, et les largeurs données dans le fichier de police doivent correspondre aux largeurs utilisées dans la police

PostScript.

Notez que gropdf n'est actuellement capable d'afficher que les 256 premiers glyphes d'une police. Cette restriction sera levée dans une version

ultérieure.

gropdf peut inclure automatiquement les polices téléchargeables nécessaires à l'impression du document. Les polices peuvent être au format PFA ou

PFB.

\X'pdf: background cmd left top right bottom weight'

produit un rectangle d'arrière-plan sur la page, où
cmd
est la commande, qui peut être l'une des options “page|fill|box” en combinaison. Ainsi, “pagefill” dessinera un rectangle qui couvre la totalité de la taille de la page actuelle (auquel cas le reste des paramètres peut être omis car les dimensions de la boîte sont prises à partir de la taille des médias actuelle). “boxfill”, en revanche, nécessite les dimensions données pour placer la boîte. Inclure “fill” dans la commande peindra le rectangle avec la couleur de remplissage actuelle (comme avec \M[]) et inclure “box” donnera au rectangle une bordure dans la couleur de contournement actuelle (comme avec \m[]).

Si vous avez spécifié une couleur de page avec “pagefill”, c'est toujours la première boîte dans la pile, et si vous la spécifiez à nouveau, elle remplacera la première entrée. Sachez que la boîte “pagefill” rend la page opaque, donc les outils qui “marquent à l'eau” les pages PDF risquent de ne pas réussir. Pour rendre l'arrière-plan transparent, émettez une commande “off” sans autres boîtes ouvertes.

Ceci afin de laisser de la place pour les zones de notes de bas de page qui grandissent pendant le traitement d'une page (pour accueillir plusieurs notes de bas de page, par exemple). (Si la valeur est négative, elle est utilisée comme un décalage par rapport au bas de la page.)

Macros

Les macros de support de gropdf dans pdf.tmac définissent les macros de commodité décrites ci-dessus. Certaines fonctionnalités n'ont pas d'équivalent direct dans les commandes de contrôle de périphérique.

.pdfinfo /champ contenu ...
Définit les métadonnées PDF. champ peut être Title, Author, Subject, Keywords, ou toute autre donnée prise en charge par la norme PDF ou votre lecteur. champ doit être précédé d'une barre oblique.

Importation de graphiques

gropdf ne prend en charge que l'inclusion d'autres fichiers PDF pour les images en ligne. Un tel fichier PDF peut, cependant, contenir n'importe lequel des formats graphiques pris en charge par la norme PDF, tels que JPEG/JFIF, PNG et GIF. Toute application qui produit du PDF peut ainsi être utilisée pour préparer des fichiers à intégrer dans des documents traités par groff et gropdf.

Le fichier PDF que vous souhaitez insérer doit être une seule page et le dessin doit juste s'adapter à la taille des médias du fichier PDF. Dans inkscape(1) ou gimp(1), par exemple, assurez-vous que la taille de la toile correspond juste à l'image.

Le parseur PDF implémenté par gropdf n'a pas été rigoureusement testé avec toutes les applications qui produisent du PDF. Si vous trouvez un PDF d'une seule page qui ne s'importe pas correctement, essayez de le traiter avec le programme pdftk(1).

pdftk 
fichier-existant 
output 
nouveau-fichier
Vous pourriez constater que nouveau-fichier s'importe correctement.

TrueType et autres formats de polices

gropdf ne prend pas encore en charge d'autres formats de polices que Adobe Type 1 (PFA ou PFB).

Installation des polices

Voici un guide étape par étape pour l'installation des polices pour gropdf.

•
Convertissez votre police dans un format que groff comprend. Il s'agit d'une police PostScript Type 1 au format PFA ou PFB, avec un fichier AFM. Un fichier PFA commence comme suit.
%!PS-AdobeFont-1.0:
Un fichier PFB contient également cette chaîne, précédée de quelques octets non imprimables. Dans les étapes suivantes, nous considérerons l'utilisation de la police BrushScriptX-Italic de CTAN au format PFA.
•
Convertissez le fichier AFM en un fichier de description de police groff avec le programme afmtodit(1). Par exemple,
$
afmtodit BrushScriptX-Italic.afm text.map BSI
convertit le fichier Adobe Font Metric BrushScriptX-Italic.afm en le fichier de description de police groff BSI.
Si vous avez une famille de polices qui fournit des styles régulier (roman), gras, italique et gras-italique, (où “italique” peut être “oblique” ou “penché”), nous vous recommandons d'utiliser R, B, I et BI, respectivement, comme suffixes du nom de famille de police groff pour activer les fonctionnalités de sélection de famille et de style de police de groff. Un exemple est le support intégré de groff pour Times : le nom de la famille de polices est abrégé en T, et les noms de polices groff sont donc TR, TB, TI et TBI. Dans notre exemple, cependant, la police BrushScriptX n'est disponible que dans un seul style, italique.
•
