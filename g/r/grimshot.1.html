grimshot(1) Manuel des commandes générales grimshot(1)

NOM

grimshot - une aide pour les captures d'écran dans sway

SYNTAXE

grimshot [--notify] [--cursor] [--wait N] (copy|save) [TARGET] [FILE]
grimshot check
grimshot usage

OPTIONS

--notify

Affiche des notifications à l'utilisateur qu'une capture d'écran a été effectuée.

--cursor

Inclut les curseurs dans la capture d'écran.

--wait N

Attend N secondes avant de prendre une capture d'écran. Attend après toute sélection manuelle. Il est recommandé de combiner avec --notify afin de savoir quand la capture d'écran a été prise.

save

Enregistre la capture d'écran dans un fichier normal. Grimshot écrira les fichiers image dans XDG_SCREENSHOTS_DIR si celui-ci est défini (ou défini dans user-dirs.dir), sinon il utilisera XDG_PICTURES_DIR. Définissez FILE à '-' pour rediriger la sortie vers STDOUT. Définissez la variable d'environnement GRIMSHOT_FILENAME_FORMAT pour remplacer le nom de fichier par défaut.

copy

Copie les données de la capture d'écran (en tant qu'image/png) dans le presse-papiers.

savecopy

Enregistre la capture d'écran dans un fichier normal (voir la documentation save) et copie les données de la capture d'écran dans le presse-papiers (voir la documentation copy).

DESCRIPTION

Grimshot est un utilitaire de capture d'écran facile à utiliser pour sway. Il fournit une interface pratique sur grim, slurp et jq, et prend en charge le stockage de la capture d'écran soit directement dans le presse-papiers à l'aide de wl-copy, soit dans un fichier.

EXEMPLES

Un exemple d'utilisation consiste à ajouter ces liaisons à votre configuration sway :

# Captures d'écran :
# Super+P : Fenêtre actuelle
# Super+Shift+p : Sélectionner une zone
# Super+Alt+p : Sortie actuelle
# Super+Ctrl+p : Sélectionner une fenêtre
bindsym Mod4+p       exec grimshot save active
bindsym Mod4+Shift+p exec grimshot save area
bindsym Mod4+Mod1+p  exec grimshot save output
bindsym Mod4+Ctrl+p  exec grimshot save window

Et/ou ajoutez ces variables d'environnement à votre configuration de shell :

export GRIMSHOT_FILENAME_FORMAT="$(date --iso-8601=ns | tr ':' -)"

CIBLES

Grimshot peut capturer les cibles nommées suivantes :

active

Capture la fenêtre actuellement active.

screen

Capture tout l'écran. Cela inclut toutes les sorties visibles.

area

Permet de sélectionner manuellement une région rectangulaire et la capture.

window

Permet de sélectionner manuellement une seule fenêtre (en cliquant dessus) et la capture.

output

Capture la sortie actuellement active.

anything

Permet de sélectionner manuellement une seule fenêtre (en cliquant dessus), une sortie (en cliquant en dehors de toutes les fenêtres, par exemple sur la barre d'état), ou une zone (en utilisant le clic et le glisser).

SORTIE

Grimshot affichera le nom de fichier de la capture d'écran capturée sur la sortie standard s'il est appelé avec les sous-commandes save ou savecopy.
