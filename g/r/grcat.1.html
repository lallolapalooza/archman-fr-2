GRCAT(1) Manuel des commandes générales GRCAT(1)

NOM

grcat - lire depuis l'entrée standard, la coloriser et l'écrire sur la sortie standard

SYNTAXE

grcat configuration

DESCRIPTION

configuration est le nom d'un fichier de configuration. Les répertoires ~/.grc/, /usr/local/share/grc/, /usr/share/grc/ sont recherchés pour trouver le fichier (dans cet ordre).

Si le fichier n'est pas trouvé, il est supposé être le chemin absolu d'un fichier de configuration situé ailleurs.

Le fichier de configuration est constitué d'entrées, une par expression régulière, les entrées étant séparées par des lignes dont le premier caractère est non alphanumérique (sauf #). Les lignes commençant par # ou les lignes vides sont ignorées.

Chaque entrée est constituée de plusieurs lignes. Chaque ligne a la forme : mot-clé=valeur où le mot-clé est l'un des suivants : regexp, colours, command, concat, skip, count. Seul regexp est obligatoire, mais il n'a pas beaucoup de sens par lui-même à moins de spécifier au moins un mot-clé colour ou command également.

regexp est l'expression régulière à faire correspondre

colours est la liste des couleurs, séparées par des virgules (vous ne pouvez spécifier qu'une couleur), chaque couleur par groupe d'expression régulière spécifié dans l'expression régulière.

command est la commande à exécuter lorsque l'expression régulière correspond. Sa sortie sera mélangée avec la sortie standard normale, utilisez des redirécteurs ( >/dev/null) si vous voulez la supprimer.

replace signifie que la correspondance de l'expression régulière sera remplacée par la valeur, toutes les expressions régulières précédentes seront évaluées par rapport au texte original, toutes les expressions régulières suivantes seront évaluées par rapport au texte remplacé.

skip peut être soit yes, soit no, si yes, la ligne correspondante sera ignorée et ne sera pas affichée en sortie. La valeur par défaut est no.

count est l'un des mots : once, more, ou stop.

once signifie que si l'expression régulière correspond, sa première occurrence est colorisée et le programme continuera avec les autres expressions régulières.

more signifie que s'il y a plusieurs correspondances de l'expression régulière dans une ligne, toutes seront colorisées.

stop signifie que l'expression régulière sera colorisée et le programme passera à la ligne suivante (c'est-à-dire en ignorant les autres expressions régulières).

Les expressions régulières sont évaluées de haut en bas, cela permet des expressions imbriquées et chevauchantes. (par exemple : vous colorisez tout ce qui est entre parenthèses avec une couleur, et si une expression suivante correspond au texte à l'intérieur des parenthèses, il sera également colorisé).

OPTIONS

Aucune pour l'instant.
