Considérez-le

comme étant de qualité bêta, voire alpha. grandvizier est un outil d'interface

graphique

destiné à superviser et contrôler le programme dtrealms de DNSSEC-Tools. Il affiche des informations sur l'état actuel des royaumes (realms) gérés par dtrealms. L'utilisateur peut contrôler certains aspects de l'exécution de dtrealms en utilisant les commandes de menu de grandvizier. grandvizier crée une

fenêtre

dans laquelle afficher des informations sur chaque royaume. (Ces royaumes sont ceux du fichier realms actuel de dtrealms.) Pour chaque royaume, il affiche le nom du royaume et le nombre de zones dans chacun de ces quatre états : normal, rotation de ZSK, rotation de KSK, et état d'attente de phase 6 de KSK. Lorsque l'état de rotation des zones dans chaque royaume change, grandvizier mettra à jour son affichage pour ce royaume. Les royaumes inactifs, c'est-à-dire les royaumes listés dans le fichier realms mais qui ne sont pas en cours d'exécution, sont affichés mais ne possèdent pas d'informations utiles à afficher. L'utilisateur peut

également

masquer des royaumes de l'affichage. Ces royaumes, s'ils sont dans l'état actif, continueront de s'exécuter ; cependant, leurs informations ne seront pas affichées. L'état d'affichage de chaque royaume persistera entre les exécutions de grandvizier. Des commandes de

menu

sont disponibles pour un certain contrôle sur dtrealms. Les options d'affichage et d'exécution pour grandvizier sont également disponibles via les commandes de menu. Plus d'informations sur les commandes de menu sont disponibles dans la section COMMANDES DE

MENU.

grandvizier n'est destiné qu'à être démarré par dtrealms, et non directement par un utilisateur. Il existe deux façons de faire démarrer grandvizier par dtrealms. Premièrement, realmctl peut recevoir l'option -display. Deuxièmement, l'option -display peut être donnée sur la ligne d

FICHIER DE

CONFIGURATION

Plusieurs aspects du comportement de grandvizier peuvent être contrôlés à partir de fichiers de configuration. La valeur de configuration peut être spécifiée dans le fichier de configuration des DNSSEC-Tools ou dans un fichier plus spécifique rc.grandvizier. Le fichier de configuration de grandvizier au niveau du système se trouve dans le répertoire de configuration des DNSSEC-Tools et est nommé grandvizier.conf. Plusieurs fichiers rc.grandvizier peuvent exister sur un système, mais seul celui du répertoire dans lequel grandvizier est exécuté est

utilisé.

Les valeurs de configuration disponibles sont les suivantes

: 
colors              Activer/désactiver l'utilisation des couleurs sur les bandes de royaume.
fontsize            La taille de la police dans la fenêtre de sortie.
inactivecolor       La couleur d'arrière-plan utilisée pour les zones inactives.
maxrealms           Le nombre de royaumes à afficher.
modify              Activer/désactiver l'exécution des commandes de modification de dtrealms.
showinactive        Activer/désactiver l'affichage des zones
inactives.

Le fichier rc.grandvizier n'est recherché que dans le répertoire dans lequel grandvizier est exécuté. Les problèmes potentiels inhérents à cela peuvent amener ces fichiers de configuration spécifiques à grandvizier à être supprimés à

l'avenir.

Ce fichier est au format « champ valeur », où champ spécifie l'aspect de la sortie et value définit la valeur pour ce champ. Les champs reconnus sont les suivants

:

Les lignes vides et les commentaires sont ignorés. Les lignes de commentaire sont les lignes qui commencent par un dièse ('#')
