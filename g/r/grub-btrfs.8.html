DESCRIPTIO

N

Améliore grub en ajoutant les « instantanés btrfs » au menu

grub.

Vous pouvez démarrer votre système sur un « instantané » depuis le menu grub. Prend en charge les instantanés manuels, snapper et timeshift. Fonctionnalités de grub-btrfs

:
—
Liste automatiquement les instantanés existants sur la partition racine (btrfs)
.
—
Détecte automatiquement si /boot est sur une partition
séparée.
—
Détecte automatiquement le noyau, l'initramfs et le microcode intel/amd dans le répertoire /boot des
instantanés.
—
Crée automatiquement les « menuentry » correspondants dans grub.
cfg
—
Détecte automatiquement le type/les étiquettes et les descriptions/commentaires des instantanés snapper/timeshi
ft.
—
Génère automatiquem
ent grub.cfg si vou
s utilisez le serv
ice systemd fourni.

PARAMÈTRES DÉP

ENDANTS DE L
A DISTRIBUTION

GRUB_BTRFS_BOOT_DIRNAM

E

Emplacement des noyaux/initramfs/microcodes. Utilisé par « grub-btrfs » pour détecter la partition de démarrage et l'emplacement des noyaux, initramfs et

microcodes.
—
Par défaut : « /boot »
—
Exemple : GRUB_BTRFS_BOOT_DIRNAME="/"

GRUB_BTRFS_GRUB_DIRNAME

Emplacement du dossier contenant le fichier « grub.cfg ». Cela peut être grub2 sur certains systèmes. Par exemple, sur Fedora avec EFI : « /boot/efi/EFI/fedora »

—
Par défaut : « /boot/grub »
—
Exemple : GRUB_BTRFS_GRUB_DIRNAME="/boot/grub2"

GRUB_BTRFS_GBTRFS_DIRNAME

Emplacement où grub-btrfs.cfg doit être enregistré. Certaines distributions (comme OpenSuSE) stockent ce fichier dans le répertoire des instantanés plutôt que dans boot. Assurez-vous que ce répertoire est accessible pour grub lors du démarrage du système.

—
Par défaut : $GRUB_BTRFS_GRUB_DIRNAME
—
Exemple : GRUB_BTRFS_GBTRFS_DIRNAME="/.snapshots"

GRUB_BTRFS_GBTRFS_SEARCH_DIRNAME

Emplacement du répertoire où Grub recherche le fichier grub-btrfs.cfg. Certaines distributions (comme OpenSuSE) stockent ce fichier dans le répertoire des instantanés plutôt que dans boot. Assurez-vous que ce répertoire est accessible pour grub lors du démarrage du système.

—
Par défaut : « prefix} » (Ceci est une variable grub qui se résout à l'endroit où grub est

installé. (comme /boot/grub, /boot/efi/grub))

—
REMARQUE : Si des variables de grub sont utilisées ici comme ${prefix}, elles doivent être échappées

avec `$` avant le `$`

—
Exemple : GRUB_BTRFS_GBTRFS_SEARCH_DIRNAME="prefix}"

GRUB_BTRFS_MKCONFIG

Nom/chemin de la commande pour générer le menu grub, utilisé par « grub-btrfs.service ». Cela peut être ’grub2-mkconfig’ sur certains systèmes (p. ex. Fedora). Les chemins par défaut sont /sbin:/bin:/usr/sbin:/usr/bin, si votre chemin est manquant, signalez-le sur le projet amont. Vous pouvez utiliser uniquement le nom de la commande ou le chemin complet.

—
Par défaut : grub-mkconfig
—
Exemple : GRUB_BTRFS_MKCONFIG=/sbin/grub2-mkconfig

GRUB_BTRFS_SCRIPT_CHECK

Nom de la commande grub-script-check, utilisé par « grub-btrfs ». Cela peut être ’grub2-script-check’ sur certains systèmes (p. ex. Fedora)

—
Par défaut : grub-script-check
—
Exemple : GRUB_BTRFS_SCRIPT_CHECK=grub2-script-check

GRUB_BTRFS_MKCONFIG_LIB

Chemin du fichier grub-mkconfiglib, utilisé par « grub-btrfs » Cela peut être ’/usr/share/grub2/grub-mkconfiglib’ sur certains systèmes (p. ex. Opensuse)

—
Par défaut : /usr/share/grub/grub-mkconfiglib
—
Exemple : GRUB_BTRFS_MKCONFIG_LIB=/usr/share/grub2/grub-mkconfig_lib

SÉCURITÉ

GRUB_BTRFS_PROTECTION_AUTHORIZED_USERS

Gestion de la protection par mot de passe pour les sous-menus et les instantanés. Consultez la documentation de Grub https://www.gnu.org/software/grub/manual/grub/grub.html#Authentication-and-authorisation et ce commentaire https://github.com/Antynea/grub-btrfs/issues/95#issuecomment-682295660 Ajoutez les noms d'utilisateurs autorisés séparés par des virgules (userfoo,userbar). Lorsque la protection par mot de passe de Grub est activée, le superutilisateur est autorisé par défaut, il n'est pas nécessaire de l'ajouter

—
Par défaut : « »
—
Exemple : GRUB_BTRFS_PROTECTION_AUTHORIZED_USERS="userfoo,userbar"

GRUB_BTRFS_DISABLE_PROTECTION_SUBMENU

Désactive la prise en charge de l'authentification uniquement pour le sous-menu de Grub-btrfs (--unrestricted) ne fonctionne pas si GRUBBTRFSPROTECTIONAUTHORIZEDUSERS n'est pas vide

—
Par défaut : « false »
—
Exemple : GRUB_BTRFS_DISABLE_PROTECTION_SUBMENU="true"
