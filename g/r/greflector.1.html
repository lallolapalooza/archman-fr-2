NOM

greflector - Un programme qui renvoie les données vers toutes les connexions

SYNTAXE

greflector [-c] [-t] <accepteur gensio> [<accepteur gensio> [...]]

DESCRIPTION

Le programme greflector accepte les connexions gensio sur les accepteurs donnés. Pour toutes les connexions, si des données arrivent, elles seront envoyées à toutes les autres connexions.

Ceci est utile pour le débogage. Par exemple, si vous vouliez simuler une connexion TNC KISS AX25 et la liaison aérienne qui les connecte, et que vous vouliez observer les données, vous pourriez faire :

$ greflector -t kiss,tcp,1234

Si vous voulez établir une connexion au lieu d'en accepter une, utilisez le gensio conacc. Voir gensio(5) pour plus de détails.

OPTIONS

-c
Lorsque toutes les connexions sont fermées, arrête le réflecteur.
-t
Trace toutes les connexions et les données entrantes vers la sortie standard.
