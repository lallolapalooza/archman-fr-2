grim(1) Manuel des commandes générales grim(1)

NOM

grim - saisir des images depuis un compositeur Wayland

SYNTAXE

grim [options...] [fichier-de-sortie]

DESCRIPTION

grim est un utilitaire en ligne de commande pour prendre des captures d'écran de bureaux Wayland. Pour l'instant, il nécessite le support du protocole screencopy pour fonctionner. Le support du protocole xdg-output est facultatif, mais améliore la prise en charge de la mise à l'échelle fractionnée.

grim écrira une image dans fichier-de-sortie, ou dans un nom de fichier horodaté dans $GRIM_DEFAULT_DIR si non spécifié. Si $GRIM_DEFAULT_DIR n'est pas défini, il se rabattra d'abord sur $XDG_PICTURES_DIR, puis sur le répertoire de travail courant. Si fichier-de-sortie est -, grim écrira l'image sur la sortie standard à la place.

OPTIONS

-h

Afficher le message d'aide et quitter.

-s <facteur>

Définir le facteur d'échelle de l'image de sortie sur facteur. Par défaut, le facteur d'échelle est défini sur la plus haute valeur parmi toutes les sorties.

-g "<x>,<y> <largeur>x<hauteur>"

Définir la région à capturer, dans les coordonnées de la disposition.

Si défini à -, lire la région depuis l'entrée standard à la place.

-t <type>

Définir le format du fichier image de sortie sur type. Par défaut, le type de fichier est png, les valeurs valides sont png, jpeg ou ppm.

-q <qualité>

Définir le taux de compression du fichier jpeg de sortie sur qualité. Par défaut, la qualité jpeg est de 80, les valeurs valides sont comprises entre 0 et 100.

-l <niveau>

Définir le niveau de compression du fichier PNG de sortie sur niveau. Par défaut, le niveau de compression PNG est 6 sur une échelle de 0 à 9. Le niveau 9 donne le taux de compression le plus élevé, mais peut être lent ; le niveau 1 donne un taux de compression plus faible, mais est plus rapide. Le niveau 0 ne compresse pas du tout, et produit des fichiers très volumineux ; il peut être utile lorsque grim est utilisé dans un pipeline avec d'autres commandes.

-o <sortie>

Définir le nom de la sortie à capturer.

-c

Inclure les curseurs dans la capture d'écran.

-T <identifiant>

Définir l'identifiant d'un handle toplevel étranger à capturer.
