GRUB-MKSTANDALONE(1) Commandes utilisateur GRUB-MKSTANDALONE(1)

NOM

grub-mkstandalone - créer une image GRUB basée sur memdisk

SYNOPSIS

grub-mkstandalone [OPTION...] [OPTION] SOURCE...

DESCRIPTION

Générer une image autonome (contenant tous les modules) dans le format sélectionné.

--appended-signature-size=TAILLE
Ajouter un segment de note réservant TAILLE octets pour une signature ajoutée.
--compress=aucun|xz|gz|lzo
Compresser les fichiers GRUB [optionnel].
--disable-cli
Désactiver l'accès à l'interface en ligne de commande.
--disable-shim-lock
Désactiver le vérificateur shim_lock.
--dtb=FICHIER
Incorporer un DTB spécifique.
-d, --directory=DIR
Utiliser les images et modules sous DIR [défaut=/usr/lib/grub/<plateforme>].
--fonts=POLICES
Installer POLICES [défaut=unicode].
--install-modules=MODULES
Installer uniquement MODULES et leurs dépendances [défaut=tout].
-k, --pubkey=FICHIER
Incorporer FICHIER comme clé publique pour la vérification de signature.
--locale-directory=DIR Utiliser les traductions sous DIR
[défaut=/usr/share/locale].
--locales=LOCALES
Installer uniquement LOCALES [défaut=tout].
--modules=MODULES
Pré-charger les modules spécifiés MODULES.
--sbat=FICHIER
Métadonnées SBAT.
--themes=THEMES
Installer THEMES [défaut=starfield].
-v, --verbose
Afficher les messages détaillés.
-x, --x509key=FICHIER
Incorporer FICHIER comme certificat x509 pour la vérification de signature ajoutée.
--core-compress=xz|none|auto
Choisir la compression à utiliser pour l'image noyau.
-o, --output=FICHIER
Enregistrer la sortie dans FICHIER [requis].
-O, --format=FICHIER
Générer une image dans le FORMAT formats disponibles : i386-coreboot, i386-multiboot, i386-pc, i386-xen_pvh, i386-pc-pxe, i386-pc-eltorito, i386-efi, i386-ieee1275, i386-qemu, x86_64-efi, i386-xen, x86_64-xen, mipsel-yeeloong-flash, mipsel-fuloong2f-flash, mipsel-loongson-elf, powerpc-ieee1275, sparc64-ieee1275-raw, sparc64-ieee1275-cdcore, sparc64-ieee1275-aout, ia64-efi, mips-arc, mipsel-arc, mipsel-qemu_mips-elf, mips-qemu_mips-flash, mipsel-qemu_mips-flash, mips-qemu_mips-elf, arm-uboot, arm-coreboot-vexpress, arm-coreboot-veyron, arm-efi, arm64-efi, loongarch64-efi, riscv32-efi, riscv64-efi
-?, --help
Donner cette liste d'aide.
--usage
Donner un court message d'utilisation.
-V, --version
Afficher la version du programme.

Les arguments obligatoires ou optionnels pour les options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.

La syntaxe des points de greffage (par ex. /boot/grub/grub.cfg=./grub.cfg) est acceptée.

SIGNALER LES BOGUES

Signaler les bogues à <bug-grub@gnu.org>.

VOIR AUSSI
