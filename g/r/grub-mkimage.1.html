GRUB-MKIMAGE(1) Commandes utilisateur GRUB-MKIMAGE(1)

NOM

grub-mkimage - créer une image bootable de GRUB

SYNTAXE

grub-mkimage [OPTION...] [OPTION]... [MODULES]

DESCRIPTION

Crée une image bootable de GRUB.

-c, --config=FICHIER
intègre FICHIER comme configuration précoce
-C, --compression=(xz|none|auto)
choisir la compression à utiliser pour l'image noyau
--disable-cli
désactiver l'accès à l'interface en ligne de commande
--disable-shim-lock
désactiver le vérificateur shim_lock
-d, --directory=RÉPERTOIRE
utiliser les images et modules sous RÉPERTOIRE [défaut=/usr/lib/grub/<plateforme>]
-D, --dtb=FICHIER
intègre FICHIER comme arbre de périphériques (DTB)
-k, --pubkey=FICHIER
intègre FICHIER comme clé publique pour la vérification de signature PGP
-m, --memdisk=FICHIER
intègre FICHIER comme image memdisk

Implique `-p (memdisk)/boot/grub' et surcharge

tout préfixe fourni précédemment, mais le préfixe
lui-même peut être surchargé par des options ultérieures
-n, --note
ajoute un segment NOTE pour CHRP IEEE1275
-o, --output=FICHIER
génère une image dans FICHIER [défaut=stdout]
-O, --format=FORMAT
génère une image dans le format FORMAT ; formats disponibles : i386-coreboot, i386-multiboot, i386-pc, i386-xen_pvh, i386-pc-pxe, i386-pc-eltorito, i386-efi, i386-ieee1275, i386-qemu, x86_64-efi, i386-xen, x86_64-xen, mipsel-yeeloong-flash, mipsel-fuloong2f-flash, mipsel-loongson-elf, powerpc-ieee1275, sparc64-ieee1275-raw, sparc64-ieee1275-cdcore, sparc64-ieee1275-aout, ia64-efi, mips-arc, mipsel-arc, mipsel-qemu_mips-elf, mips-qemu_mips-flash, mipsel-qemu_mips-flash, mips-qemu_mips-elf, arm-uboot, arm-coreboot-vexpress, arm-coreboot-veyron, arm-efi, arm64-efi, loongarch64-efi, riscv32-efi, riscv64-efi
-p, --prefix=RÉPERTOIRE
définit le répertoire préfixe
-s, --sbat=FICHIER
métadonnées SBAT
-S, --appended-signature-size=TAILLE
ajoute un segment de note réservant TAILLE octets pour une signature ajoutée
-v, --verbose
affiche des messages détaillés.
-x, --x509key=FICHIER
intègre FICHIER comme certificat x509 pour la vérification de signature ajoutée
-?, --help
affiche cette liste d'aide
--usage
affiche un bref message d'utilisation
-V, --version
affiche la version du programme

Les arguments obligatoires ou optionnels des options longues sont aussi obligatoires ou optionnels pour toute option courte correspondante.

RAPPORTER DES BOGUES

Signalez les bogues à <bug-grub@gnu.org>.

VOIR AUSSI

grub-install(8), grub-mkrescue(1), grub-mknetdir(8)

La documentation complète de grub-mkimage est maintenue sous la forme d'un manuel Texinfo. Si les programmes info et grub-mkimage sont correctement installés sur votre système, la commande

info grub-mkimage

devrait vous donner accès au manuel complet.
