group_member(3) Manuel des fonctions de bibliothèque group_member(3)

NOM

group_member - teste si un processus appartient à un groupe

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <unistd.h>
int group_member(gid_t gid);
Exigences pour le macro de test de fonctionnalité de glibc (voir feature_test_macros(7)) :

group_member() :

    _GNU_SOURCE

DESCRIPTION

La fonction group_member() teste si l'un des ID de groupe supplémentaires de l'appelant (tel que retourné par getgroups(2)) correspond à gid.

VALEUR DE RETOUR

La fonction group_member() retourne une valeur non nulle si l'un des ID de groupe supplémentaires de l'appelant correspond à gid, et zéro sinon.

NORMES

GNU.

VOIR AUSSI

getgid(2), getgroups(2), getgrouplist(3), group(5)
