GRUB-MKNETDIR(1) Commandes utilisateur GRUB-MKNETDIR(1)

NOM

grub-mknetdir - prépare un répertoire de démarrage réseau GRUB.

SYNTAXE

grub-mknetdir [OPTION...]

DESCRIPTION

Prépare les images de démarrage réseau GRUB dans net_directory/subdir en supposant que net_directory est la racine TFTP.

--taille-signature-ajoutee=TAILLE
Ajoute un segment de note réservant TAILLE octets pour une signature ajoutée
--compression=non|xz|gz|lzo
compresse les fichiers GRUB [optionnel]
--desactivation-interface
désactive l'accès à l'interface en ligne de commande
--desactivation-verrou-shim
désactive le vérificateur shim_lock
--dtb=FICHIER
incorpore un DTB spécifique
-d, --repertoire=REP
utilise les images et modules sous REP [défaut=/usr/lib/grub/<plateforme>]
--polices=POLICES
installe POLICES [défaut=unicode]
--modules-installation=MODULES
installe uniquement MODULES et leurs dépendances [défaut=tous]
-k, --cle-publique=FICHIER
incorpore FICHIER comme clé publique pour la vérification de signature
--repertoire-locale=REP utilise les traductions sous REP
[défaut=/usr/share/locale]
--locales=LOCALES
installe uniquement LOCALES [défaut=toutes]
--modules=MODULES
préchauffe les modules spécifiés MODULES
--sbat=FICHIER
métadonnées SBAT
--themes=THEMES
installe THEMES [défaut=starfield]
-v, --verbeux
affiche des messages verbeux.
-x, --cle-x509=FICHIER
incorpore FICHIER comme certificat x509 pour la vérification de signature ajoutée
--compression-core=xz|aucun|auto
choisit la compression à utiliser pour l'image principale
--repertoire-net=REP
répertoire racine du serveur TFTP
--sous-repertoire=REP
sous-répertoire relatif sur le serveur réseau
-?, --aide
donne cette liste d'aide
--usage
donne un court message d'utilisation
-V, --version
affiche la version du programme

Les arguments obligatoires ou optionnels pour les options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.

Prépare les images de démarrage réseau GRUB dans net_directory/subdir en supposant que net_directory est la racine TFTP.

Signaler les bogues à <bug-grub@gnu.org>.
