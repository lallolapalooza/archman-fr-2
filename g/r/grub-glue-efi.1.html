NOM

grub-glue-efi - génère un binaire fat pour EFI

SYNTAXE

grub-glue-efi [OPTION...] [OPTIONS]

DESCRIPTION

grub-glue-efi traite les images EFI ia32 et amd64 et les assemble selon le format Apple.

Assemble les binaires 32 bits et 64 bits en un seul binaire universel Apple.

-3, --input32=FICHIER
définit le nom du fichier d'entrée pour la partie 32 bits.
-6, --input64=FICHIER
définit le nom du fichier d'entrée pour la partie 64 bits.
-o, --output=FICHIER
définit le nom du fichier de sortie. La valeur par défaut est la sortie standard (STDOUT)
-v, --verbose
affiche des messages détaillés.
-?, --help
affiche cette liste d'aide
--usage
affiche un bref message d'utilisation
-V, --version
affiche la version du programme

Les arguments obligatoires ou optionnels des options longues sont également obligatoires ou optionnels pour toutes les options courtes correspondantes.

SIGNALEMENT DES BOGUES

Signaler les bogues à <bug-grub@gnu.org>.

VOIR AUSSI

La documentation complète de grub-glue-efi est maintenue sous forme de manuel Texinfo. Si les programmes info et grub-glue-efi sont correctement installés sur votre site, la commande

info grub-glue-efi

devrait vous donner accès au manuel complet.
