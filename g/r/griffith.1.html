NOM

griffith - gestionnaire de collection de films

SYNTAXE


griffith

DESCRIPTION

Griffith est un gestionnaire de collection de films. Ajouter des éléments à la collection de films est aussi rapide et facile que de taper le titre du film et de sélectionner une source supportée. Griffith essaiera alors de récupérer toutes les informations relatives sur le Web.

OPTIONS

-h --help
Afficher les informations d'utilisation.
-D --debug
Exécuter en mode débogage.
-C --clean
Trouver et supprimer les fichiers orphelins dans le répertoire des affiches.
--check-dep
vérifier les dépendances - si tous les modules Python nécessaires sont installés, il ne produit rien.
--sqlecho
Affiche toutes les requêtes SQL sur la sortie standard.
--home DIR
Définir le répertoire personnel de Griffith. Utilisez cette option si vous voulez changer le répertoire par défaut ~/.griffith

Impression de la liste des films :

-c <expr> --cast=<expr>
le champ casting doit contenir <expr>
-d <expr> --director=<expr>
le champ réalisateur doit contenir <expr>
-o <expr> --original_title=<expr>
le champ titre original doit contenir <expr>
-t <expr> --title=<expr>
le champ titre doit contenir <expr>
-y <number> --year=<number>
le film doit être sorti en l'an <number>
-s <colonnes> --sort=<colonnes>
définir les colonnes de tri sur <colonnes>. Exemple : --sort=o_title,number,director
