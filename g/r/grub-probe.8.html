NOM

grub-probe — sonder les informations de périphérique pour GRUB

SYNTAXE

grub-probe [OPTION...] [OPTION]... [CHEMIN|PÉRIPH]

DESCRIPTION

Sonde les informations de périphérique pour un chemin donné (ou un périphérique, si l'option -d est utilisée).

-0
séparer les éléments de la sortie par des caractères NUL ASCII
-d, --device
l'argument donné est un périphérique système, pas un chemin
-m, --device-map=FICHIER
utiliser FICHIER comme carte des périphériques [par défaut=//boot/grub/device.map]
-t, --target=CIBLE
imprimer les cibles disponibles pour TARGET : abstraction, arc_hints, baremetal_hints, bios_hints, compatibility_hint, cryptodisk_uuid, device, disk, drive, efi_hints, fs, fs_label, fs_uuid, gpt_parttype, hints_string, ieee1275_hints, msdos_parttype, partmap, partuuid, zero_check [par défaut=fs]
-v, --verbose
imprimer des messages détaillés (passer deux fois pour activer l'impression de débogage).
-?, --help
donner cette liste d'aide
--usage
donner un bref message d'utilisation
-V, --version
imprimer la version du programme

Les arguments obligatoires ou optionnels des options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.

SIGNALER LES BOGUES

Signaler les bogues à <bug-grub@gnu.org>.

VOIR AUSSI

grub-fstest(1)

La documentation complète de grub-probe est maintenue sous forme de manuel Texinfo. Si les programmes info et grub-probe sont correctement installés sur votre site, la commande

info grub-probe

devrait vous donner accès au manuel complet.
