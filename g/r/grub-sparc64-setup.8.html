NOM

grub-sparc64-setup - configurer un périphérique pour démarrer avec GRUB

SYNOPIS

grub-sparc64-setup [OPTION...] PÉRIPHÉRIE

DESCRIPTION

Configure les images pour démarrer depuis PÉRIPHÉRIE.

Normalement, vous ne devriez pas exécuter ce programme directement. Utilisez grub-install à la place.

-a, --allow-floppy
rend le disque également amorçable en tant que disquette (par défaut pour les périphériques fdX). Peut ne pas fonctionner sur certains BIOS.
-b, --boot-image=FICHIER
utilise FICHIER comme image d'amorçage [défaut=boot.img]
-c, --core-image=FICHIER
utilise FICHIER comme image principale [défaut=core.img]
-d, --directory=REP
utilise les fichiers GRUB dans le répertoire REP [défaut=//boot/grub]
-f, --force
installe même si des problèmes sont détectés
-m, --device-map=FICHIER
utilise FICHIER comme carte des périphériques [défaut=//boot/grub/device.map]
--no-rs-codes
N'applique aucun code reed-solomon lors de l'intégration de core.img. Cette option n'est disponible que sur les cibles BIOS x86.
-s, --skip-fs-probe
ne sonde pas les systèmes de fichiers sur PÉRIPHÉRIE
-v, --verbose
affiche des messages détaillés.
-?, --help
affiche cette liste d'aide
--usage
affiche un court message d'utilisation
-V, --version
affiche la version du programme

Les arguments obligatoires ou optionnels des options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.

PÉRIPHÉRIE doit être un périphérique du système d'exploitation (par exemple, /dev/sda).

SIGNALEMENT DES BUGS

Signalez les bugs à <bug-grub@gnu.org>.

VOIR AUSSI

grub-install(8), grub-mkimage(1), grub-mkrescue(1)

La documentation complète de grub-sparc64-setup est maintenue sous forme de manuel Texinfo. Si les programmes info et grub-sparc64-setup sont correctement installés sur votre système, la commande

info grub-sparc64-setup

devrait vous donner accès au manuel complet.
