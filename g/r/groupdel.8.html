GROUPDEL(8) Commandes de gestion système GROUPDEL(8)

NOM

groupdel - supprimer un groupe

SYNTAXE

groupdel [options] GROUPE

DESCRIPTION

La commande groupdel modifie les fichiers de compte système, en supprimant toutes les entrées qui font référence à GROUPE. Le groupe nommé doit exister.

OPTIONS

Les options qui s'appliquent à la commande groupdel sont :

-f, --force

Cette option force la suppression du groupe, même s'il existe certains utilisateurs qui ont ce groupe comme groupe principal.

-h, --help

Affiche un message d'aide et quitte.

-R, --root REPERTOIRE_CHROOT

Applique les modifications dans le répertoire REPERTOIRE_CHROOT et utilise les fichiers de configuration du répertoire REPERTOIRE_CHROOT. Seuls les chemins absolus sont pris en charge.

-P, --prefix PREFIX_DIR

Applique les modifications dans le répertoire PREFIX_DIR et utilise les fichiers de configuration du répertoire PREFIX_DIR. Cette option n'effectue pas de chroot et est destinée à la préparation d'une cible de compilation croisée. Certaines limitations : les utilisateurs/groupes NIS et LDAP ne sont pas vérifiés. L'authentification PAM utilise les fichiers hôtes. Pas de support SELinux.

ATTENTION

Vous ne pouvez pas supprimer le groupe principal d'un utilisateur existant. Vous devez supprimer l'utilisateur avant de supprimer le groupe.

Vous devez vérifier manuellement tous les systèmes de fichiers pour vous assurer qu'aucun fichier n'appartient plus à ce groupe.

CONFIGURATION

Les variables de configuration suivantes dans /etc/login.defs modifient le comportement de cet outil :

MAX_MEMBERS_PER_GROUP (nombre)

Nombre maximum de membres par entrée de groupe. Lorsque le maximum est atteint, une nouvelle entrée de groupe (ligne) est créée dans /etc/group (avec le même nom, le même mot de passe et le même GID).

La valeur par défaut est 0, ce qui signifie qu'il n'y a pas de limite au nombre de membres dans un groupe.

Cette fonctionnalité (groupes divisés) permet de limiter la longueur des lignes dans le fichier de groupes. Ceci est utile pour s'assurer que les lignes pour les groupes NIS ne dépassent pas 1024 caractères.

Si vous avez besoin d'imposer une telle limite, vous pouvez utiliser 25.

Remarque : les groupes divisés ne sont peut-être pas pris en charge par tous les outils (même dans la suite d'outils Shadow). Vous ne devez pas utiliser cette variable à moins d'en avoir vraiment besoin.

FICHIERS

/etc/group

Informations sur les comptes de groupe.

/etc/gshadow

Informations sécurisées sur les comptes de groupe.

VALEURS DE RETOUR

La commande groupdel se termine avec les valeurs suivantes :

0

succès

2

syntaxe de commande invalide

6

le groupe spécifié n'existe pas

8

impossible de supprimer le groupe principal d'un utilisateur

10

impossible de mettre à jour le fichier de groupe

VOIR AUSSI

chfn(1), chsh(1), passwd(1), gpasswd(8), groupadd(8), groupmod(8), useradd(8), userdel(8), usermod(8).
