GRUB-FILE(1) Commandes utilisateur GRUB-FILE(1)

NOM

grub-file - vérifier le type de fichier

SYNTAXE

file OPTIONS FICHIER

DESCRIPTION

Vérifie si FICHIER est du type spécifié.

--est-i386-xen-pae-domu
Vérifie si FICHIER peut être démarré comme un invité Xen i386 PAE non privilégié
--est-x86_64-xen-domu
Vérifie si FICHIER peut être démarré comme un invité Xen x86_64 non privilégié
--est-x86-xen-dom0
Vérifie si FICHIER peut être utilisé comme un noyau d'invité Xen x86 privilégié
--est-x86-multiboot
Vérifie si FICHIER peut être utilisé comme un noyau x86 multiboot

--est-x86-multiboot2 Vérifie si FICHIER peut être utilisé comme un noyau x86 multiboot2

--est-arm-linux
Vérifie si FICHIER est un Linux ARM
--est-arm64-linux
Vérifie si FICHIER est un Linux ARM64
--est-ia64-linux
Vérifie si FICHIER est un Linux IA64
--est-mips-linux
Vérifie si FICHIER est un Linux MIPS
--est-mipsel-linux
Vérifie si FICHIER est un Linux MIPSEL
--est-sparc64-linux
Vérifie si FICHIER est un Linux SPARC64
--est-powerpc-linux
Vérifie si FICHIER est un Linux POWERPC
--est-x86-linux
Vérifie si FICHIER est un Linux x86
--est-x86-linux32
Vérifie si FICHIER est un Linux x86 supportant le protocole 32 bits
--est-x86-kfreebsd
Vérifie si FICHIER est un kFreeBSD x86
--est-i386-kfreebsd
Vérifie si FICHIER est un kFreeBSD i386
--est-x86_64-kfreebsd
Vérifie si FICHIER est un kFreeBSD x86_64
--est-x86-knetbsd
Vérifie si FICHIER est un kNetBSD x86
--est-i386-knetbsd
Vérifie si FICHIER est un kNetBSD i386

--est-x86_64-knetbsd Vérifie si FICHIER est un kNetBSD x86_64

--est-i386-efi
Vérifie si FICHIER est un fichier EFI i386
--est-x86_64-efi
Vérifie si FICHIER est un fichier EFI x86_64
--est-ia64-efi
Vérifie si FICHIER est un fichier EFI IA64
--est-arm64-efi
Vérifie si FICHIER est un fichier EFI ARM64
--est-arm-efi
Vérifie si FICHIER est un fichier EFI ARM
--est-riscv32-efi
Vérifie si FICHIER est un fichier EFI RISC-V 32 bits
--est-riscv64-efi
Vérifie si FICHIER est un fichier EFI RISC-V 64 bits
--est-hibernated-hiberfil
Vérifie si FICHIER est hiberfil.sys en état hiberné
--est-x86_64-xnu
Vérifie si FICHIER est XNU x86_64 (noyau Mac OS X)
--est-i386-xnu
Vérifie si FICHIER est XNU i386 (noyau Mac OS X)
--est-xnu-hibr
Vérifie si FICHIER est une image hibernée XNU (noyau Mac OS X)
--est-x86-bios-bootsector
Vérifie si FICHIER est un secteur d'amorçage BIOS

-h, --help Affiche cette aide et quitte. -u, --usage Affiche l'utilisation de cette commande et quitte.

VOIR AUSSI

La documentation complète de grub-file est maintenue sous forme de manuel Texinfo. Si les programmes info et grub-file sont correctement installés sur votre système, la commande

info grub-file

devrait vous donner accès au manuel complet.
