GR_PLOT_TIME(1) Commandes utilisateur GR_PLOT_TIME(1)

NOM

gr_plot_time - applications de traçage dans le domaine temporel de gnuradio

SYNTAXE

gr_plot_time [options]

DESCRIPTION

Trace une liste de fichiers sur un graphique d'oscilloscope. Les fichiers sont une liste binaire de nombres complexes flottants.

OPTIONS

-h, --help
afficher ce message d'aide et quitter
-N NSAMPLES, --nsamples=NSAMPLES
Définir le nombre d'échantillons à afficher [défaut=1000000]
-S START, --start=START
Numéro de l'échantillon de départ [défaut=0]
-r SAMPLE_RATE, --sample-rate=SAMPLE_RATE
Définir le taux d'échantillonnage du signal [défaut=1.0]
--no-auto-scale
Ne pas mettre à l'échelle automatiquement le graphique [défaut=False]

gr_plot_time: error: option non reconnue : --version

VOIR AUSSI
