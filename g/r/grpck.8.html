GRPCK(8) Commandes de gestion système GRPCK(8)

NOM

grpck — vérifier l'intégrité des fichiers de groupes

SYNTAXE

grpck [options] [groupe [ ombre ]]

DESCRIPTION

La commande grpck vérifie l'intégrité des informations de groupes. Elle vérifie que toutes les entrées dans /etc/group et /etc/gshadow ont le format correct et contiennent des données valides. L'utilisateur est invité à supprimer les entrées mal formatées ou qui présentent d'autres erreurs non corrigeables.

Des vérifications sont effectuées pour s'assurer que chaque entrée possède :

•le nombre correct de champs
•un nom de groupe unique et valide
•un identifiant de groupe valide (/etc/group uniquement)
•une liste valide de membres et d'administrateurs
•une entrée correspondante dans le fichier /etc/gshadow (respectivement /etc/group pour les vérifications gshadow)

Les vérifications du nombre correct de champs et du nom de groupe unique sont fatales. Si une entrée a un nombre incorrect de champs, l'utilisateur sera invité à supprimer toute la ligne. Si l'utilisateur ne répond pas affirmativement, toutes les vérifications ultérieures sont ignorées. Une entrée avec un nom de groupe dupliqué est invitée à être supprimée, mais les vérifications restantes seront toujours effectuées. Toutes les autres erreurs sont des avertissements et l'utilisateur est encouragé à exécuter la commande groupmod pour corriger l'erreur.

Les commandes qui opèrent sur les fichiers /etc/group et /etc/gshadow ne sont pas capables de modifier les entrées corrompues ou dupliquées. grpck doit être utilisé dans ces circonstances pour supprimer les entrées fautives.

OPTIONS

Les options -r et -s ne peuvent pas être combinées.

Les options qui s'appliquent à la commande grpck sont :

-h, --help

Afficher le message d'aide et quitter.

-r, --read-only

Exécuter la commande grpck en mode lecture seule. Cela fait que toutes les questions concernant les modifications reçoivent une réponse *non* sans intervention de l'utilisateur.

-R, --root REPERTOIRE_CHROOT

Appliquer les modifications dans le répertoire REPERTOIRE_CHROOT et utiliser les fichiers de configuration du répertoire REPERTOIRE_CHROOT. Seuls les chemins absolus sont pris en charge.

-s, --sort

Trier les entrées dans /etc/group et /etc/gshadow par GID.

-S, --silence-warnings

Supprimer les avertissements les plus controversés, en particulier les avertissements concernant l'incohérence entre les membres de groupe listés dans /etc/group et /etc/ghadow.

Par défaut, grpck opère sur /etc/group et /etc/gshadow. L'utilisateur peut sélectionner des fichiers alternatifs avec les paramètres groupe et ombre.

CONFIGURATION

Les variables de configuration suivantes dans /etc/login.defs changent le comportement de cet outil :

MAX_MEMBERS_PER_GROUP (nombre)

Nombre maximum de membres par entrée de groupe. Lorsque le maximum est atteint, une nouvelle entrée de groupe (ligne) est créée dans /etc/group (avec le même nom, le même mot de passe et le même GID).

La valeur par défaut est 0, ce qui signifie qu'il n'y a pas de limite au nombre de membres dans un groupe.

Cette fonctionnalité (groupe divisé) permet de limiter la longueur des lignes dans le fichier de groupes. C'est utile pour s'assurer que les lignes de groupes NIS ne dépassent pas 1024 caractères.

Si vous devez imposer une telle limite, vous pouvez utiliser 25.

Remarque : les groupes divisés peuvent ne pas être pris en charge par tous les outils (même dans la suite d'outils Shadow). Vous ne devriez pas utiliser cette variable sauf si vous en avez vraiment besoin.

FICHIERS

/etc/group

Informations sur les comptes de groupe.

/etc/gshadow

Informations sécurisées sur les comptes de groupe.

/etc/passwd

Informations sur les comptes utilisateur.

VALEURS DE RETOUR

La commande grpck se termine avec les valeurs suivantes :

0

succès

1

syntaxe de commande invalide

2

une ou plusieurs entrées de groupe erronées

3

impossible d'ouvrir les fichiers de groupe

4

impossible de verrouiller les fichiers de groupe

5

impossible de mettre à jour les fichiers de groupe
