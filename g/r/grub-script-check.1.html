GRUB-SCRIPT-CHECK(1) Commandes utilisateur GRUB-SCRIPT-CHECK(1)

NOM

grub-script-check - vérifie la syntaxe des fichiers de script grub

SYNTAXE

grub-script-check [OPTION...] [CHEMIN]

DESCRIPTION

Vérifie la syntaxe du fichier de configuration de script GRUB.

-v, --verbose
affiche les messages détaillés.
-?, --help
donne cette liste d'aide
--usage
donne un court message d'utilisation
-V, --version
affiche la version du programme

RAPPORTER DES BOGUES

Signaler les bogues à <bug-grub@gnu.org>.

VOIR AUSSI

grub-mkconfig(8)

La documentation complète de grub-script-check est maintenue sous forme de manuel Texinfo. Si les programmes info et grub-script-check sont correctement installés sur votre site, la commande

info grub-script-check

devrait vous donner accès au manuel complet.
