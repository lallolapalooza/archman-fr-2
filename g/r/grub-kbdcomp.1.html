GRUB-KBDCOMP(1) Commandes utilisateur GRUB-KBDCOMP(1)

NOM

grub-kbdcomp - générer un fichier de disposition clavier GRUB

SYNOPSIS

grub-kbdcomp -o SORTIE ARGUMENTS_CKBMAP...

DESCRIPTION

grub-kbdcomp traite une description de disposition clavier X au format keymaps(5) dans un format pouvant être utilisé par la commande keymap de GRUB.

Crée un fichier de disposition clavier pour GRUB.

-h, --help
affiche ce message et quitte
-V, --version
affiche les informations de version et quitte
-o, --output=FICHIER
enregistre la sortie dans FICHIER [requis]

grub-kbdcomp génère une disposition clavier pour GRUB en utilisant ckbcomp

SIGNALER LES BOGUES

Signaler les bogues à <bug-grub@gnu.org>.
