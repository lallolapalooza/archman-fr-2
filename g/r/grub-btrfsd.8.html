NOM

grub-btrfsd - Un démon OpenRC pour mettre à jour automatiquement le menu grub avec grub-btrfs(8)

lorsqu'un nouveau snapshot btrfs est créé.

SYNTAXE

grub-btrfsd [-h, --help] [-c, --no-color] [-l, --log-file FICHIER_LOG] [-r, --recursive] [-s, --syslog] [-t, --timeshift-auto] [-o, --timeshift-old] [-v, --verbose] REPERTOIRES_SNAPSHOTS

DESCRIPTION

Grub-btrfsd est un script shell destiné à être exécuté en tant que démon. Grub-btrfsd surveille un répertoire où les snapshots btrfs sont créés ou supprimés via inotifywait et exécute grub-mkconfig (si grub-mkconfig n'a jamais été exécuté depuis l'installation de grub-btrfs) ou /etc/grub.d/41_snapshots-btrfs (lorsque grub-mkconfig a été exécuté auparavant avec grub-btrfs installé) lorsque quelque chose change dans ce répertoire.

OPTIONS

REPERTOIRES_SNAPSHOTS

Cet argument spécifie les chemins (séparés par des espaces) où grub-btrfsd recherche les nouveaux snapshots créés et les suppressions de snapshots. Il est généralement défini par le programme utilisé pour créer les snapshots. Par exemple, pour Snapper, ce serait /.snapshots. Il est possible de définir plusieurs répertoires ici, tous les répertoires hériteront des mêmes paramètres (récursif, etc.). Cet argument n'est pas nécessaire si --timeshift-auto est défini.

-c / --no-color

Désactive les couleurs dans la sortie.

-l / --log-file

Cet argument spécifie un fichier où grub-btrfsd devrait écrire les messages de journalisation.

-r / --recursive

Surveille le répertoire des snapshots de manière récursive.

-s / --syslog

Écrit dans le journal système (syslog).

-t / --timeshift-auto

Ceci est un drapeau pour activer la détection automatique du chemin où Timeshift stocke les snapshots. Les versions plus récentes (>=22.06) de Timeshift montent leurs snapshots dans /run/timeshift/$PID/backup/timeshift-btrfs. Où $PID est l'ID du processus de la session Timeshift en cours. Le PID change à chaque fois que Timeshift est ouvert. grub-btrfsd peut automatiquement prendre en charge la détection du PID et du répertoire corrects si ce drapeau est activé. Dans ce cas, l'argument REPERTOIRES_SNAPSHOTS n'a aucun effet.

-o / --timeshift-old

Recherche les snapshots dans /run/timeshift/backup/timeshift-btrfs au lieu de /run/timeshift/$PID/backup/timeshift-btrfs. Ceci doit être utilisé pour les versions de Timeshift <22.06.

-v / --verbose

Rend la journalisation du démon plus détaillée.

-h / --help

Affiche un court message d'aide.

CONFIGURATION

Le démon est généralement configuré via le fichier /etc/conf.d/grub-btrfsd sur les systèmes avec initialisation openrc et via sudo systemctl edit --full grub-btrfsd sur les systèmes systemd. Dans ce fichier, les arguments (voir OPTIONS), que OpenRC passe au démon lors de son démarrage, peuvent être configurés.

NOTES

Une configuration courante pour Snapper serait de définir SNAPSHOTS_DIR à /.snapshots et de ne pas définir --timeshift-auto. Pour Timeshift, --timeshift-auto est défini sur true et SNAPSHOTS_DIR peut être laissé tel quel.
