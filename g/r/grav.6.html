NOM

grav - Dessine une simulation orbitale simple

SYNTAXE

grav [--display hôte:écran.numéro] [--foreground couleur] [--background couleur] [--window] [--root] [--window-id numéro][--mono] [--install] [--visual visuel] [--ncolors entier] [--delay microsecondes] [--count entier] [--decay] [--no-decay] [--trail] [--no-trail]

[--fps]

DESCRIPTION

Le programme grav dessine une simulation orbitale simple.

OPTIONS

grav accepte les options suivantes :

--window
Dessiner dans une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--mono
Sur un écran couleur, fait comme si l'on était sur un écran monochrome.
--install
Installer une palette de couleurs privée pour la fenêtre.
--visual visuel
Spécifier quel visuel utiliser. Les valeurs valides sont le nom d'une classe visuelle, ou le numéro (décimal ou hexadécimal) d'un visuel spécifique.
--ncolors entier
Combien de couleurs utiliser (si possible). Par défaut 64. Les couleurs sont choisies aléatoirement.
--count entier
Par défaut 12.
--decay
--no-decay
Si les orbites doivent décliner.
--trail
--no-trail
Si les objets doivent laisser des traces derrière eux (ce qui donne l'apparence d'une chambre à brouillard.
--fps
Afficher le taux d'images par seconde actuel et la charge CPU.

ENVIRONNEMENT

DISPLAY
Pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
Pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'ID de la fenêtre à utiliser avec --root.

VOIR AUSSI

X(1), xscreensaver(1), xlock(1)
