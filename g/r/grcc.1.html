GRCC(1) Commandes utilisateur GRCC(1)

NOM

grcc - Compilateur Gnu Radio Companion

DESCRIPTION

Compile simplement un flowgraph Gnu Radio Companion sans invoquer l'interface graphique.

Étant donné un fichier GRC d'entrée et un répertoire de sortie, crée une application exécutable dans le répertoire de sortie.
