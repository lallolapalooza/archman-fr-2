Descriptio

n

Le support HTML du système GNU roff se compose d'un préprocesseur, pre-grohtml, et d'un pilote de sortie, post-grohtml ; ensemble, ils traduisent les documents roff(7) en HTML. Comme un préprocesseur est (uniquement) requis pour ce pilote de sortie, les utilisateurs doivent invoquer grohtml via la commande groff(1) avec les options -Thtml ou -Txhtml. (Dans cette installation, ps est le périphérique de sortie par défaut.) Utilisez l'option -P de groff pour passer toutes les options montrées ci-dessus à grohtml. Si aucun opérande n'est donné, ou si fichier est «- », grohtml lit le flux d'entrée standard. La sortie est écrite dans le flux de sortie

standard.

grohtml invoque groff deux fois. Au premier passage, le préprocesseur pre-grohtml rend les images, les équations et les tableaux sous forme d'images au format PostScript en utilisant le périphérique de sortie ps. Au second passage, le pilote de sortie post-grohtml traduit la sortie de troff(1) en

HTML.

grohtml écrit une sortie encodée en UTF-8 et possède des entités HTML intégrées pour tous les caractères Unicode non composites. Malgré cela, groff peut émettre des avertissements concernant des caractères spéciaux inconnus s'ils ne peuvent pas être trouvés lors du premier passage. Ces avertissements peuvent être ignorés en toute sécurité, sauf si les caractères spéciaux apparaissent dans un tableau ou une

équation.
