NOM

grub-mkpasswd-pbkdf2 - générer un mot de passe haché pour GRUB

SYNOPSIS

grub-mkpasswd-pbkdf2 [OPTION...] [OPTIONS]

DESCRIPTION

Génère un hachage de mot de passe PBKDF2.

-c, --iteration-count=NOMBRE
Nombre d'itérations PBKDF2
-l, --buflen=NOMBRE
Longueur du hachage généré
-s, --salt=NOMBRE
Longueur du sel
-?, --help
donner cette liste d'aide
--usage
donner un court message d'utilisation
-V, --version
afficher la version du programme

Les arguments obligatoires ou optionnels des options longues sont également obligatoires ou optionnels pour toutes les options courtes correspondantes.

SIGNALER LES BOGUES

Signaler les bogues à <bug-grub@gnu.org>.

VOIR AUSSI

grub-mkconfig(8)

La documentation complète de grub-mkpasswd-pbkdf2 est maintenue sous forme de manuel Texinfo. Si les programmes info et grub-mkpasswd-pbkdf2 sont correctement installés sur votre site, la commande

info grub-mkpasswd-pbkdf2

devrait vous donner accès au manuel complet.
