NOM

grub-mklayout - génère un fichier de disposition de clavier pour GRUB

SYNTAXE

grub-mklayout [OPTION...] [OPTIONS]

DESCRIPTION

grub-mklayout traite une description de disposition de clavier au format keymaps(5) dans un format utilisable par la commande keymap de GRUB.

Génère la disposition du clavier GRUB à partir de celle de la console Linux.

-i, --input=FICHIER
définit le nom du fichier d'entrée. Par défaut : STDIN
-o, --output=FICHIER
définit le nom du fichier de sortie. Par défaut : STDOUT
-v, --verbose
affiche des messages détaillés.
-?, --help
affiche cette liste d'aide
--usage
affiche un bref message d'utilisation
-V, --version
affiche la version du programme

Les arguments obligatoires ou optionnels aux options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.

SIGNALER LES BOGUES

Signalez les bogues à <bug-grub@gnu.org>.

VOIR AUSSI

grub-mkconfig(8)

La documentation complète de grub-mklayout est maintenue sous forme de manuel Texinfo. Si les programmes info et grub-mklayout sont correctement installés sur votre système, la commande

info grub-mklayout

devrait vous donner accès au manuel complet.
