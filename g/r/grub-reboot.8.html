NOM

grub-reboot - définit l'entrée de démarrage par défaut pour GRUB, pour le prochain démarrage seulement

SYNTAXE

grub-reboot [OPTION] ENTRÉE_MENU

DESCRIPTION

Définit l'entrée du menu de démarrage par défaut pour GRUB, pour le prochain démarrage seulement.

-h, --help
affiche ce message et quitte
-V, --version
affiche les informations de version et quitte
--boot-directory=DIR
attend les images GRUB sous le répertoire DIR/grub au lieu du répertoire /boot/grub

L'ENTRÉE_MENU est un nombre, un titre d'élément de menu ou un identifiant d'élément de menu. Veuillez noter que les éléments de menu dans les sous-menus ou sous-sous-menus nécessitent de spécifier les composants du sous-menu, puis le composant de l'élément de menu. Les titres doivent être séparés par le caractère supérieur à (>) sans espaces supplémentaires. Selon votre shell, certains caractères, y compris >, peuvent nécessiter d'être échappés. Plus d'informations à ce sujet sont disponibles dans le Manuel GRUB dans la section concernant la commande 'default'.

NOTE : Dans les cas où GRUB ne peut pas écrire dans le bloc d'environnement, par exemple lorsqu'il est stocké sur un périphérique MDRAID ou LVM, l'entrée du menu de démarrage choisie restera la valeur par défaut même après le redémarrage.

SIGNALER LES BOGUES

Signalez les bugs à <bug-grub@gnu.org>.

VOIR AUSSI

grub-set-default(8), grub-editenv(1)

La documentation complète de grub-reboot est maintenue sous forme de manuel Texinfo. Si les programmes info et grub-reboot sont correctement installés sur votre site, la commande

info grub-reboot

devrait vous donner accès au manuel complet.
