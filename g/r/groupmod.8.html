    NOM

    groupmod — modifier un groupe

    SYNOPSIS

    groupmod [ -g | -n ] [ -o ] GROUPE

    groupmod [ -h ]

    DESCRIPTION

    La commande groupmod est utilisée pour modifier une entrée de groupe existante dans le fichier de base de données des groupes (généralement /etc/group).

    Le nom du groupe à modifier est spécifié par l'argument GROUPE. Les modifications sont spécifiées à l'aide d'options.

    Seuls les utilisateurs root sont autorisés à exécuter la commande groupmod.

    OPTIONS

    -g, --gid GID
    Modifier le Group ID (GID) du GROUPE à GID. Le GID doit être un entier positif.
    -n, --new-name NouveauNom
    Modifier le nom du GROUPE à NouveauNom.
    -o, --non-unique
    Permettre la création d'un groupe avec un GID non unique. Normalement, chaque groupe doit avoir un GID unique. Cette option permet de modifier un groupe pour qu'il ait le même GID qu'un autre groupe existant.
    -h, --help
    Afficher un message d'aide et quitter.

    FICHIERS

    /etc/group Fichier contenant les informations sur les groupes.

    /etc/gshadow Fichier contenant les informations de mot de passe crypté pour les groupes.
