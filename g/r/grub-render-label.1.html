GRUB-RENDER-LABEL(1) Commandes utilisateur GRUB-RENDER-LABEL(1)

NOM

grub-render-label - générer un fichier .disk_label pour les Mac Apple.

SYNTAXE

grub-render-label [OPTION...] [OPTIONS]

DESCRIPTION

Rendre un .disk_label Apple.

-b, --bgcolor=COULEUR
utiliser COULEUR pour l'arrière-plan
-c, --color=COULEUR
utiliser COULEUR pour le texte
-f, --font=FICHIER
utiliser FICHIER comme police (PF2).
-i, --input=FICHIER
lire le texte depuis FICHIER.
-o, --output=FICHIER
définir le nom du fichier de sortie. Par défaut, il s'agit de STDOUT
-t, --text=CHAINE
définir le texte à rendre
-v, --verbose
afficher les messages détaillés.
-?, --help
afficher cette liste d'aide
--usage
afficher un bref message d'utilisation
-V, --version
afficher la version du programme

Les arguments obligatoires ou optionnels des options longues sont également obligatoires ou optionnels pour les options courtes correspondantes.

SIGNALER LES BOGUES

Signaler les bogues à <bug-grub@gnu.org>.

VOIR AUSSI

La documentation complète de grub-render-label est maintenue sous forme de manuel Texinfo. Si les programmes info et grub-render-label sont correctement installés sur votre site, la commande

info grub-render-label

devrait vous donner accès au manuel complet.
