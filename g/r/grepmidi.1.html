GREPMIDI(1) Manuel des commandes générales GREPMIDI(1)

NOM

grepmidi - affiche la structure des fichiers MIDI

SYNTAXE

grepmidi [ -f ] fichier [ ... ]

DESCRIPTION

L'utilitaire grepmidi fournit un analyseur simple pour les fichiers au format MIDI brut. Il est loin d'être complet, mais permet de saisir la structure de base de la chanson dans fichier. C'est-à-dire qu'il n'affiche pas de notes individuelles, mais seulement des méta-informations intégrées dans le fichier MIDI. grepmidi peut également être utile pour vérifier si un fichier MIDI donné contient des erreurs.

Plusieurs fichiers peuvent être indiqués sur la ligne de commande. L'option -f demande à grepmidi de préfixer chaque ligne de sortie avec le nom du fichier en cours de vérification.

grepmidi est distribué avec MusE, un éditeur de musique MIDI complet.
