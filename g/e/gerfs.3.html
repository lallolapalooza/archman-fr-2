sous-routine cgerfs (character trans, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldx, * ) x, integer ldx, real, dimension( * ) ferr, real, dimension( * ) berr, complex, dimension( * ) work, real, dimension( * ) rwork, integer

info)

CGERF

S

But

: 
!>
!> CGERFS améliore la solution calculée d'un système d'équations
!> linéaires et fournit des bornes d'erreur et des estimations
!> d'erreur arrière pour la solution.
!
>

Paramètre

s
TRANS 
!>          TRANS est CHARACTER*1
!>          Spécifie la forme du système d'équations :
!>          = 'N' :  A * X = B     (Pas de transposition)
!>          = 'T' :  A**T * X = B  (Transposition)
!>          = 'C' :  A**H * X = B  (Transposition conjuguée)
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!
>

NRH

S 
!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes des matrices B et X.  NRHS >= 0.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          La matrice A originale de dimension N par N.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!
>

A

F 
!>          AF est un tableau COMPLEX, dimension (LDAF,N)
!>          Les facteurs L et U de la factorisation A = P*L*U
!>          tels que calculés par CGETRF.
!
>

LDA

F 
!>          LDAF est INTEGER
!>          La dimension principale du tableau AF.  LDAF >= max(1,N).
!
>

IPI

V 
!>          IPIV est un tableau INTEGER, dimension (N)
!>          Les indices de pivot de CGETRF ; pour 1<=i<=N, la ligne i de la
!>          matrice a été interchangée avec la ligne IPIV(i).
!
>

B 
!>          B est un tableau COMPLEX, dimension (LDB,NRHS)
!>          La matrice du second membre B.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B.  LDB >= max(1,N).
!
>

X 
!>          X est un tableau COMPLEX, dimension (LDX,NRHS)
!>          À l'entrée, la matrice solution X, telle que calculée par CGETRS.
!>          À la sortie, la matrice solution améliorée X.
!
>

LD

X 
!>          LDX est INTEGER
!>          La dimension principale du tableau X.  LDX >= max(1,N).
!
>

FER

R 
!>          FERR est un tableau REAL, dimension (NRHS)
!>          La borne d'erreur avant estimée pour chaque vecteur solution
!>          X(j) (la j-ième colonne de la matrice solution X).
!>          Si XTRUE est la solution réelle correspondant à X(j), FERR(j)
!>          est une borne supérieure estimée pour la magnitude du plus
!>          grand élément de (X(j) - XTRUE) divisée par la magnitude du
!>          plus grand élément de X(j).  L'estimation est aussi fiable
!>          que l'estimation pour RCOND, et est presque toujours une
!>          légère surestimation de l'erreur réelle.
!
>

BER

R 
!>          BERR est un tableau REAL, dimension (NRHS)
!>          L'erreur arrière relative composante par composante de chaque
!>          vecteur solution X(j) (c'est-à-dire le plus petit changement
!>          relatif dans n'importe quel élément de A ou B qui rend X(j)
!>          une solution exacte).
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (2*N)
!
>

RWOR

K 
!>          RWORK est un tableau REAL, dimension (N)
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!
>

Paramètres internes

: 
!>  ITMAX est le nombre maximal d'étapes de raffinement itératif.
!
