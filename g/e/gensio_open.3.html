gensio_open(3) Manuel des fonctions de bibliothèque gensio_open(3)

NOM

gensio_open, gensio_open_s, gensio_open_nochild, gensio_open_nochild_s - Démarrer une connexion gensio

SYNTAXE

#include <gensio/gensio.h>

typedef void (*gensio_done_err)(struct gensio *io, int err,

void *open_data);
int gensio_open(struct gensio *io, gensio_done_err open_done,

void *open_data);
int gensio_open_s(struct gensio *io);
int gensio_open_nochild(struct gensio *io, gensio_done_err open_done,

void *open_data);
int gensio_open_nochild_s(struct gensio *io);

DESCRIPTION

gensio_open démarre le gensio. Les gensios reçus d'un accepteur sont ouverts à la réception, mais les gensios de connexion sont initiés fermés et doivent être ouverts avant utilisation. Si aucune erreur n'est renvoyée, la fonction de rappel open_done sera appelée ; si la valeur d'erreur err dans la fonction de rappel est nulle, le gensio sera ouvert. Cela ouvrira également tous les enfants.

Notez que la fonction de rappel open_done sera toujours appelée, même si vous fermez le gensio avant que la fonction de rappel open_done ne se produise ou si une erreur survient. Ceci est garanti.

gensio_open_s est similaire à gensio_open, mais attend que l'ouverture soit terminée. Le traitement normal de gensio se produira pendant l'attente. Notez que vous devez faire attention à ne pas appeler cela depuis une fonction de rappel ; vous ne devriez appeler cela que depuis un thread qui n'est pas une fonction de rappel ou depuis un exécuteur (voir gensio_os_funcs(3) pour les détails sur les exécuteurs).

gensio_open_nochild est similaire à gensio_open, mais suppose que les éventuels gensios enfants sont déjà ouverts et n'ouvre que ce gensio. Cela peut être utile si vous avez un gensio déjà ouvert (par exemple, si vous l'avez reçu d'un accepteur) et que vous souhaitez empiler un autre gensio par-dessus. Seuls les gensios de filtrage prendront en charge cela.

gensio_open_nochild_s est similaire à gensio_open_nochild, mais attend que l'ouverture soit terminée. Voir les notes sur gensio_open_s ci-dessus pour les avertissements.

VALEURS RENVOYÉES

Zéro est renvoyé en cas de succès, ou une erreur gensio en cas d'échec.
