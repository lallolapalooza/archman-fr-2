CGETSQRHR

T

But

: 
!>
!> CGETSQRHRT calcule une factorisation QR par blocs de colonnes de taille NB2
!> d'une matrice complexe M-par-N A avec M >= N,
!>
!>    A = Q * R.
!>
!> La routine utilise en interne une factorisation TSQR par blocs de colonnes de taille NB1 et par blocs de lignes de taille MB1
!> et effectue la reconstruction
!> des vecteurs Householder à partir de la sortie TSQR. La routine convertit également
!> le facteur R_tsqr de la sortie de la factorisation TSQR en
!> le facteur R correspondant à la factorisation QR de Householder,
!>
!>    A = Q_tsqr * R_tsqr = Q * R.
!>
!> Les facteurs Q et R de sortie sont stockés dans le même format que dans CGEQRT
!> (Q est en représentation compacte WY par blocs). Voir la documentation
!> de CGEQRT pour plus de détails sur le format.
!
>

Paramètre

s
M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!
>

N 
!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. M >= N >= 0.
!
>

MB

1 
!>          MB1 est INTEGER
!>          La taille des blocs de lignes à utiliser dans le TSQR par blocs.
!>          MB1 > N.
!
>

NB

1 
!>          NB1 est INTEGER
!>          La taille des blocs de colonnes à utiliser dans le TSQR par blocs.
!>          N >= NB1 >= 1.
!
>

NB

2 
!>          NB2 est INTEGER
!>          La taille des blocs à utiliser dans le QR par blocs qui est
!>          produit. NB2 >= 1.
!
>

A 
!>          A est un tableau COMPLEX*16, dimension (LDA,N)
!>
!>          À l'entrée : une matrice A M-par-N.
!>
!>          À la sortie :
!>           a) les éléments sur et au-dessus de la diagonale
!>              du tableau contiennent la matrice R triangulaire supérieure
!>              N-par-N correspondant au QR de Householder ;
!>           b) les éléments sous la diagonale représentent Q par
!>              les colonnes de V par blocs (représentation compacte WY).
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!
>

T 
!>          T est un tableau COMPLEX, dimension (LDT,N))
!>          Les réflecteurs triangulaires supérieurs stockés sous forme compacte
!>          comme une séquence de blocs triangulaires supérieurs.
!
>

LD

T 
!>          LDT est INTEGER
!>          La dimension principale du tableau T.  LDT >= NB2.
!
>

WOR

K 
!>          (espace de travail) tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!
>

LWOR

K 
!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          Si MIN(M,N) = 0, LWORK >= 1, sinon
!>          LWORK >= MAX( 1, LWT + LW1, MAX( LWT+N*N+LW2, LWT+N*N+N ) ),
!>          où
!>             NUM_ALL_ROW_BLOCKS = CEIL((M-N)/(MB1-N)),
!>             NB1LOCAL = MIN(NB1,N).
!>             LWT = NUM_ALL_ROW_BLOCKS * N * NB1LOCAL,
!>             LW1 = NB1LOCAL * N,
!>             LW2 = NB1LOCAL * MAX( NB1LOCAL, ( N - NB1LOCAL ) ).
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est supposée.
!>          La routine calcule uniquement la taille optimale du tableau WORK,
!>          renvoie cette valeur comme première entrée du tableau WORK,
!>          et aucun message d'erreur lié à LWORK n'est émis
!>          par XERBLA.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale

SGETSQRHRT

Purpose:

!>
!> SGETSQRHRT computes a NB2-sized column blocked QR-factorization
!> of a complex M-by-N matrix A with M >= N,
!>
!>    A = Q * R.
!>
!> The routine uses internally a NB1-sized column blocked and MB1-sized
!> row blocked TSQR-factorization and perfors the reconstruction
!> of the Householder vectors from the TSQR output. The routine also
!> converts the R_tsqr factor from the TSQR-factorization output into
!> the R factor that corresponds to the Householder QR-factorization,
!>
!>    A = Q_tsqr * R_tsqr = Q * R.
!>
!> The output Q and R factors are stored in the same format as in SGEQRT
!> (Q is in blocked compact WY-representation). See the documentation
!> of SGEQRT for more details on the format.
!>

Parameters

M 
!>          M is INTEGER
!>          The number of rows of the matrix A.  M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix A. M >= N >= 0.
!>

MB1

!>          MB1 is INTEGER
!>          The row block size to be used in the blocked TSQR.
!>          MB1 > N.
!>

NB1

!>          NB1 is INTEGER
!>          The column block size to be used in the blocked TSQR.
!>          N >= NB1 >= 1.
!>

NB2

!>          NB2 is INTEGER
!>          The block size to be used in the blocked QR that is
!>          output. NB2 >= 1.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>
!>          On entry: an M-by-N matrix A.
!>
!>          On exit:
!>           a) the elements on and above the diagonal
!>              of the array contain the N-by-N upper-triangular
!>              matrix R corresponding to the Householder QR;
!>           b) the elements below the diagonal represent Q by
!>              the columns of blocked V (compact WY-representation).
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!>

T

!>          T is REAL array, dimension (LDT,N))
!>          The upper triangular block reflectors stored in compact form
!>          as a sequence of upper triangular blocks.
!>

LDT

!>          LDT is INTEGER
!>          The leading dimension of the array T.  LDT >= NB2.
!>

WORK

!>          (workspace) REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          If MIN(M,N) = 0, LWORK >= 1, else
!>          LWORK >= MAX( 1, LWT + LW1, MAX( LWT+N*N+LW2, LWT+N*N+N ) ),
!>          where
!>             NUM_ALL_ROW_BLOCKS = CEIL((M-N)/(MB1-N)),
!>             NB1LOCAL = MIN(NB1,N).
!>             LWT = NUM_ALL_ROW_BLOCKS * N * NB1LOCAL,
!>             LW1 = NB1LOCAL * N,
!>             LW2 = NB1LOCAL * MAX( NB1LOCAL, ( N - NB1LOCAL ) ).
!>
!>          If LWORK = -1, then a workspace query is assumed.
!>          The routine only calculates the optimal size of the WORK
!>          array, returns this value as the first entry of the WORK
!>          array, and no error message related to LWORK is issued
!>          by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
