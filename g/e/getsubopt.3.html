getsubopt(3) Manuel des fonctions de bibliothèque getsubopt(3)

NOM

getsubopt - analyser les arguments de sous-option à partir d'une chaîne

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <stdlib.h>
int getsubopt(char **restrict optionp, char *const *restrict tokens,
              char **restrict valuep);
Conditions de test de fonctionnalité pour glibc (voir feature_test_macros(7)):

getsubopt():

    _XOPEN_SOURCE >= 500
        || /* Depuis glibc 2.12 : */ _POSIX_C_SOURCE >= 200809L

DESCRIPTION

getsubopt() analyse la liste des sous-options séparées par des virgules fournies dans optionp. (Une telle liste de sous-options est typiquement générée lorsque getopt(3) est utilisée pour analyser une ligne de commande ; voir par exemple l'option -o de mount(8).) Chaque sous-option peut inclure une valeur associée, qui est séparée du nom de la sous-option par un signe égal. L'exemple suivant montre le type de chaîne qui pourrait être passée dans optionp :


ro,name=xyz

L'argument tokens est un pointeur vers un tableau terminé par NULL de pointeurs vers les jetons que getsubopt() recherchera dans optionp. Les jetons doivent être des chaînes distinctes, terminées par un caractère nul, contenant au moins un caractère, sans signes égal ou virgules incorporés.

Chaque appel à getsubopt() renvoie des informations sur la prochaine sous-option non traitée dans optionp. Le premier signe égal dans une sous-option (le cas échéant) est interprété comme un séparateur entre le nom et la valeur de cette sous-option. La valeur s'étend jusqu'à la prochaine virgule, ou (pour la dernière sous-option) jusqu'à la fin de la chaîne. Si le nom de la sous-option correspond à un nom connu de tokens, et qu'une chaîne de valeur a été trouvée, getsubopt() définit *valuep à l'adresse de cette chaîne. La première virgule dans optionp est remplacée par un octet nul, de sorte que *valuep est précisément la "chaîne de valeur" pour cette sous-option.

Si la sous-option est reconnue, mais qu'aucune chaîne de valeur n'a été trouvée, *valuep est défini à NULL.

Lorsque getsubopt() renvoie, optionp pointe vers la prochaine sous-option, ou vers l'octet nul ('\0') à la fin de la chaîne si la dernière sous-option vient d'être traitée.

VALEUR DE RETOUR

Si la première sous-option dans optionp est reconnue, getsubopt() renvoie l'index de l'élément de sous-option correspondant dans tokens. Sinon, -1 est renvoyé et *valuep est toute la chaîne nom[=valeur].

Comme *optionp est modifié, la première sous-option avant l'appel à getsubopt() n'est pas (nécessairement) la même que la première sous-option après getsubopt().

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001.

NOTES

Comme getsubopt() écrase toutes les virgules qu'il trouve dans la chaîne *optionp, cette chaîne doit être inscriptible ; elle ne peut pas être une chaîne constante.

EXEMPLES

Le programme suivant attend des sous-options après une option "-o".

#define _XOPEN_SOURCE 500
#include <stdio.h>
#include <stdlib.h>
#include <assert.h>
int
main(int argc, char *argv[])
{
    enum {
        RO_OPT = 0,
        RW_OPT,
        NAME_OPT
    };
    char *const token[] = {
        [RO_OPT]   = "ro",
        [RW_OPT]   = "rw",
        [NAME_OPT] = "name",
        NULL
    };
    char *subopts;
    char *value;
    int opt;
    int readonly = 0;
    int readwrite = 0;
    char *name = NULL;
    int errfnd = 0;
    while ((opt = getopt(argc, argv, "o:")) != -1) {
        switch (opt) {
        case 'o':
            subopts = optarg;
            while (*subopts != '\0' && !errfnd) {
                switch (getsubopt(&subopts, token, &value)) {
                case RO_OPT:
                    readonly = 1;
                    break;
                case RW_OPT:
                    readwrite = 1;
                    break;
                case NAME_OPT:
                    if (value == NULL) {
                        fprintf(stderr,
                                "Valeur manquante pour la sous-option '%s'\n",
                                token[NAME_OPT]);
                        errfnd = 1;
                        continue;
                    }
                    name = value;
                    break;
                default:
                    fprintf(stderr,
                            "Aucune correspondance trouvée pour le jeton : /%s/\n", value);
                    errfnd = 1;
                    break;
                }
            }
            if (readwrite && readonly) {
                fprintf(stderr,
                        "Seulement l'une des options '%s' et '%s' peut être spécifiée\n",
                        token[RO_OPT], token[RW_OPT]);
                errfnd = 1;
            }
            break;
        default:
            errfnd = 1;
        }
    }
    if (errfnd || argc == 1) {
        fprintf(stderr, "\nUtilisation : %s -o <chaîne_sous_options>\n", argv[0]);
        fprintf(stderr,
                "les sous-options sont 'ro', 'rw', et 'name=<valeur>'\n");
        exit(EXIT_FAILURE);
    }
    /* Reste du programme...  */
    exit(EXIT_SUCCESS);
}
