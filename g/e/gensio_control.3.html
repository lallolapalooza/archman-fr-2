CONTRÔLES DE PORT

SÉRIE

Ce qui suit définit diverses valeurs de port

série.

Sur le client, cela définit la valeur ou demande la valeur à l'autre extrémité. Lors de la récupération, la valeur de données n'est pas utilisée. Lors de la définition, la valeur de données est une chaîne avec un nombre ou un paramètre. La réponse dans le rappel done rapporte une chaîne avec la valeur définie (qui peut être différente de la valeur demandée) dans le même format que la

requête.

Sur le serveur, ceux-ci sont utilisés pour répondre à un événement client. Le rappel done est

ignoré.

GENSIO_ACONTROL_SER_BAUD
est le débit en bauds sous forme de nombre. Par exemple, définir à "1200" définit 1200 bauds. Tous les gensios ne prennent pas en charge tous les débits en

bauds.

GENSIO_ACONTROL_SER_DATASIZE
est la taille des données, un nombre de "5" à "8". Tous les gensios ne prennent pas en charge toutes les tailles de

données.

GENSIO_ACONTROL_SER_PARITY
définit la parité, l'une de "none", "odd", "even", "mark" ou "space". Vous pouvez utiliser gensio_parity_to_str et gensio_str_to_parity pour convertir entre les valeurs chaîne et numérique. gensio_parity_to_str renvoie NULL si le nombre n'est pas valide, gensio_str_to_parity renvoie -1 si la chaîne n'est pas

valide.

GENSIO_ACONTROL_SER_STOPBITS
définit le nombre de bits d'arrêt, "1", ou

"2".

GENSIO_ACONTROL_SER_FLOWCONTROL
définit le type de contrôle de flux, l'un de "none", "xonxoff", ou "rtscts". Vous pouvez utiliser gensio_flowcontrol_to_str et gensio_str_to_flowcontrol pour convertir entre les valeurs chaîne et numérique . gensio_flowcontrol_to_str renvoie NULL si le nombre n'est pas valide, gensio_str_to_flowcontrol renvoie -1 si la chaîne n'est pas

valide.

GENSIO_ACONTROL_SER_IFLOWCONTROL
définit l'état du flux d'entrée, l'un de "none", "dcd", "dtr", ou "dsr". Vous utilisez les mêmes fonctions de conversion que GENSIO_ACONTROL_SER_FLOWCONTROL pour convertir entre chaînes et

entiers.

GENSIO_ACONTROL_SER_SBREAK
Active ou désactive la condition de break sur un port série. L'un de "on" ou "off". Vous pouvez utiliser gensio_onoff_to_str et gensio_str_to_onoff pour convertir entre les valeurs chaîne et numérique . gensio_onoff_to_str renvoie NULL si le nombre n'est pas valide, gensio_str_to_onoff renvoie -1 si la chaîne n'est pas

valide.

chaîne/entier.

Active ou désactive la ligne RTS sur un port série. L'un de "on" ou "off". Voir GENSIO_ACONTROL_SER_SBREAK pour les conversions
