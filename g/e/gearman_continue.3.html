gearman_continue(3)

Paquet: gearmand

Licences: BSD-3-Clause

GEARMAN_CONTINUE(3) Gearmand GEARMAN_CONTINUE(3)

NOM

gearman_continue - Documentation Gearmand, https://gearman.org/gearmand/

SYNOPSIS

#include <libgearman/gearman.h>

type gearman_return_t
const char *gearman_strerror(gearman_return_t rc)
bool gearman_success(gearman_return_t rc)
bool gearman_failed(gearman_return_t rc)
bool gearman_continue(gearman_return_t rc)

Compiler et lier avec -lgearman

DESCRIPTION

gearman_return_t est utilisé comme type de retour/erreur pour tous les appels utilisant gearman_client_st et gearman_worker_st. GEARMAN_SUCCESS est retourné en cas de succès, sinon une erreur est retournée. gearman_failed() peut être utilisé pour voir si la valeur de retour est une valeur d'échec. Vous pouvez imprimer une version textuelle du message d'erreur avec gearman_strerror().

gearman_success() retourne vrai si GEARMAN_SUCCESS ou si GEARMAN_NO_PENDING_TASKS est vrai.

gearman_failed() retourne vrai si une valeur autre que GEARMAN_SUCCESS a été fournie.

gearman_continue() retourne vrai si une erreur liée à des opérations d'E/S non bloquantes s'est produite. Ceci doit être utilisé pour les boucles de test.

Valeurs possibles de gearman_return_t :

type GEARMAN_NO_PENDING_TASKS
gearman_client_run_tasks() a été appelé et a terminé toutes les tâches assignées au client.
type GEARMAN_IO_WAIT
Des opérations d'E/S bloquantes ont été rencontrées. gearman_continue() peut être utilisé pour tester ceci.
type GEARMAN_ERRNO
Une erreur système s'est produite. Utilisez soit gearman_client_errno() soit gearman_worker_errno().
type GEARMAN_NO_ACTIVE_FDS
Aucune connexion active n'était disponible. gearman_continue() peut être utilisé pour tester ceci.
type GEARMAN_GETADDRINFO
La résolution de nom a échoué pour un hôte.
type GEARMAN_NO_SERVERS
Aucun serveur n'a été fourni pour le client/worker.
type GEARMAN_LOST_CONNECTION
La connexion au serveur donné a été perdue.
type GEARMAN_MEMORY_ALLOCATION_FAILURE
L'allocation de mémoire a échoué.
type GEARMAN_SERVER_ERROR
Une erreur s'est produite sur le serveur.
type GEARMAN_NOT_CONNECTED
Le client/worker n'est pas actuellement connecté au serveur.
type GEARMAN_COULD_NOT_CONNECT
Le nom du serveur était valide, mais une connexion n'a pas pu être établie.
type GEARMAN_ECHO_DATA_CORRUPTION
Soit gearman_client_echo() soit gearman_worker_echo() a échoué car les données retournées par gearmand étaient corrompues.
type GEARMAN_UNKNOWN_STATE
La valeur gearman_return_t n'a jamais été définie.
type GEARMAN_FLUSH_DATA
État interne, ne devrait jamais être vu par le client ou le worker.
type GEARMAN_SEND_BUFFER_TOO_SMALL
Le tampon d'envoi était trop petit.
type GEARMAN_TIMEOUT
Un délai d'attente s'est produit lors d'une requête au serveur.
type GEARMAN_ARGUMENT_TOO_LARGE
L'argument était trop grand pour le tampon actuel.
type GEARMAN_INVALID_ARGUMENT
L'un des arguments de l'appel API donné était invalide. EINVAL sera défini si gearman_client_error() ou gearman_worker_error() n'ont pas pu être définis. Ceci peut aussi être retourné si GEARMAN_CLIENT_UNBUFFERED_RESULT a été défini, mais que le client ne gère pas correctement les données.

CLIENT UNIQUEMENT

type GEARMAN_NEED_WORKLOAD_FN
Un client a demandé un travail, mais aucune fonction de rappel gearman_workload_fn n'a été spécifiée. Voir gearman_client_set_workload_fn().
type GEARMAN_WORK_FAIL
Une tâche a échoué, et le worker s'est terminé avec une erreur ou a appelé gearman_job_send_fail().
type GEARMAN_IN_PROGRESS
gearman_client_job_status() a été appelé pour un gearman_job_handle_t et la tâche est actuellement exécutée par un worker.
type GEARMAN_JOB_EXISTS
gearman_client_job_status() a été appelé pour un gearman_job_handle_t et la tâche est actuellement connue d'un serveur, mais n'est pas exécutée par un worker.

WORKER UNIQUEMENT

type GEARMAN_INVALID_FUNCTION_NAME
Un worker a reçu une requête pour un travail pour lequel il n'avait pas de fonction valide.
type GEARMAN_INVALID_WORKER_FUNCTION
Aucune fonction de rappel n'a été fournie par le worker pour une fonction donnée.
type GEARMAN_NO_REGISTERED_FUNCTION
Une requête pour supprimer une fonction donnée d'un worker était invalide car cette fonction n'existait pas.
type GEARMAN_NO_REGISTERED_FUNCTIONS
Le worker n'a enregistré aucune fonction.
type GEARMAN_NO_JOBS
Aucun travail n'a été trouvé pour le worker. Ce code d'erreur n'est retourné qu'en cas d'appel à gearman_worker_get_job().
