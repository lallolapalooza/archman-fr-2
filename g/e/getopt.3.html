La fonction

Un élément de argv qui commence par « - » (et qui n'est pas exactement « - » ou « -- ») est un élément d'option. Les caractères de cet élément (à part le « - » initial) sont des caractères d'option. Si getopt() est appelée de manière répétée, elle retourne successivement chacun des caractères d'option de chacun des éléments d'option. La variable optind est l'index de l'élément suivant à traiter dans argv.

Le

système initialise cette valeur à 1. L'appelant peut la réinitialiser à 1 pour redémarrer l'analyse du même argv, ou lors de l'analyse d'un nouveau vecteur d'arguments. Si getopt() trouve un autre caractère d'option, elle retourne ce

caractère,

If en mettant à jour la variable externe optind et une variable statique nextchar afin que l'appel suivant à getopt() puisse reprendre l'analyse avec le caractère d'option suivant ou l'élément de argv suivant. S'il n'y a plus de caractères d'option, getopt()

retourne

-1. Alors optind est l'index dans argv du premier élément de argv qui n'est pas une option. optstring est une chaîne contenant les caractères d'option

légitimes.

Un caractère d'option légitime est tout caractère ascii(7) visible d'un octet (pour lequel isgraph(3) retournerait une valeur non nulle) qui n'est ni « - » , ni « : », ni « ; ». Si un tel caractère est suivi d'un deux-points, l'option requiert un argument, donc getopt() place un pointeur vers le texte suivant dans le même élément de argv, ou le texte du suivant élément de argv, dans optarg. Deux deux-points signifient qu'une option prend un argument optionnel ; s'il y a du texte dans l'élément de argv courant (c'est-à-dire dans le même mot que le nom de l'option elle-même, par exemple « -oarg »), alors il est retourné dans optarg, sinon optarg est mis à zéro. Ceci est une extension GNU. Si optstring contient W suivi d'un point-virgule, alors -W foo est traité comme l'option longue --foo. (L'option -W est réservée par POSIX.2 pour les extensions d'implémentation.) Ce comportement est une extension GNU, non disponible avec les bibliothèques antérieures à glibc 2. Par défaut,

getopt()

permute le contenu de argv au fur et à mesure de son analyse, de sorte qu'à la fin tous les non-options soient à la fin. Deux autres modes d'analyse sont également implémentés. Si le premier caractère de optstring est « + » ou si la variable d'environnement POSIXLY_CORRECT est définie, alors le traitement des options s'arrête dès qu'un argument non-option est rencontré. Si « + » n'est pas le premier caractère de optstring, il est traité comme une option normale. Si un comportement POSIXLY_CORRECT est requis dans ce cas, optstring contiendra deux symboles « + ». Si le premier caractère de optstring est « - », alors chaque élément de argv non-option est traité comme s'il s'agissait de l'argument d'une option avec le code de caractère 1. (Ceci est utilisé par des programmes écrits pour s'attendre à des options et d'autres éléments de argv dans n'importe quel ordre et qui se soucient de l'ordre des deux.) L'argument spécial « -- » force la fin de l'analyse des

options

quel que soit le mode d'analyse. Lors du traitement de la liste des options, getopt() peut détecter deux types d'erreurs : (1) un caractère d'option qui n'a pas été spécifié dans optstring et (2) un argument d'option manquant (c'est-à-dire une option à la fin de la ligne de commande sans l'argument attendu). Dans certaines implémentations plus anciennes, getopt() était déclaré dans <stdio.h>. SUSv1 permettait à la déclaration d'apparaître soit dans <unistd.h> soit dans <stdio.h>. POSIX.1-1996 a marqué l'utilisation de <stdio.h> à cette fin comme LEGACY. POSIX.1-2001 ne requiert pas que la déclaration apparaisse dans <stdio.h>

.

Les très anciennes versions de glibc étaient affectées par une _PID_GNU_nonoption_argv_flags_ var

iable d'env
ironnement.

NOTE

S

Un programme qui parcourt plusieurs vecteurs d'arguments, ou rescanne le même vecteur plus d'une fois, et souhaite utiliser des extensions GNU telles que '+' et '-' au début de optstring, ou change la valeur de POSIXLY_CORRECT entre les scans, doit réinitialiser getopt() en réinitialisant optind à 0, plutôt qu'à la valeur traditionnelle de 1. (Réinitialiser à 0 force l'invocation d'une routine d'initialisation interne qui revérifie POSIXLY_CORRECT et vérifie les extensions GNU dans optstri

ng.)

Les arguments de ligne de commande sont analysés dans l'ordre strict, ce qui signifie qu'une option nécessitant un argument consommera l'argument suivant, que cet argument soit l'argument d'option correctement spécifié ou simplement l'option suivante (dans le scénario où l'utilisateur spécifie incorrectement la ligne de commande). Par exemple, si optstring est spécifié comme "1n:" et que l'utilisateur spécifie les arguments de la ligne de commande incorrectement comme prog -n -1, l'option -n recevra la valeur optarg "-1", et l'option -1 sera considérée comme

n'ayant pas
été spécifiée.

EXEMPLE

S

getopt(

)

Le programme d'exemple trivial suivant utilise getopt() pour gérer deux options de programme : -n, sans valeur associée ; et -t val, qui attend une valeur

associée. 
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    int flags, opt;
    int nsecs, tfnd;
    nsecs = 0;
    tfnd = 0;
    flags = 0;
    while ((opt = getopt(argc, argv, "nt:")) != -1) {
        switch (opt) {
        case 'n':
            flags = 1;
            break;
        case 't':
            nsecs = atoi(optarg);
            tfnd = 1;
            break;
        default: /* '?' */
            fprintf(stderr, "Usage: %s [-t nsecs] [-n] name\n",
                    argv[0]);
            exit(EXIT_FAILURE);
        }
    }
    printf("flags=%d; tfnd=%d; nsecs=%d; optind=%d\n",
           flags, tfnd, nsecs, optind);
    if (optind >= argc) {
        fprintf(stderr, "Expected argument after options\n");
        exit(EXIT_FAILURE);
    }
    printf("name argument = %s\n", argv[optind]);
    /* Other code omitted */
    exit(EXIT_SUCCESS);
}

getopt_long(

)

Le programme d'exemple suivant illustre l'utilisation de getopt_long() avec la plupart de ses fonctionnalités

. 
#include <getopt.h>
#include <stdio.h>     /* for printf */
#include <stdlib.h>    /* for exit */
int
main(int argc, char *argv[])
{
    int c;
    int digit_optind = 0;
    while (1) {
        int this_option_optind = optind ? optind : 1;
        int option_index = 0;
        static struct option long_options[] = {
            {"add",     required_argument, 0,  0 },
            {"append",  no_argument,       0,  0 },
            {"delete",  required_argument, 0,  0 },
            {"verbose", no_argument,       0,  0 },
            {"create",  required_argument, 0, 'c'},
            {"file",    required_argument, 0,  0 },
            {0,         0,                 0,  0 }
        };
        c = getopt_long(argc, argv, "abc:d:012",
                        long_options, &option_index);
        if (c == -1)
            break;
        switch (c) {
        case 0:
            printf("option %s", long_options[option_index].name);
            if (optarg)
                printf(" with arg %s", optarg);
            printf("\n");
            break;
        case '0':
        case '1':
        case '2':
            if (digit_optind != 0 && digit_optind != this_option_optind)
              printf("digits occur in two different argv-elements.\n");
            digit_optind = this_option_optind;
            printf("option %c\n", c);
            break;
        case 'a':
            printf("option a\n");
            break;
        case 'b':
            printf("option b\n");
            break;
        case 'c':
            printf("option c with value '%s'\n", optarg);
            break;
        case 'd':
            printf("option d with value '%s'\n", optarg);
            break;
        case '?':
            break;
        default:
            printf("?? getopt returned character code 0%o ??\n", c);
        }
    }
    if (optind < argc) {
        printf("non-option ARGV-elements: ");
        while (optind < argc)
            printf("%s ", argv[optind++]);
        printf("\n");
    }
    exit(EXIT_SUCCESS)
;
}
