gearman_verbose_name(3)

Paquet: gearmand

Licences: BSD-3-Clause

GEARMAN_VERBOSE_NAME(3) Gearmand GEARMAN_VERBOSE_NAME(3)

NOM

gearman_verbose_name - Documentation Gearmand, https://gearman.org/gearmand/

SYNTAXE

#include <libgearman/gearman.h>

type gearman_verbose_t
const char *gearman_verbose_name(gearman_verbose_t verbose)

Lier avec -lgearman

DESCRIPTION

gearman_verbose_name() prend un gearman_verbose_t et retourne une représentation caractère de celui-ci.

Valeurs possibles de gearman_verbose_t :

type GEARMAN_VERBOSE_FATAL

Erreurs fatales.

type GEARMAN_VERBOSE_ERROR

Toutes les erreurs.

type GEARMAN_VERBOSE_INFO

État d'informations générales sur tous les événements.

type GEARMAN_VERBOSE_DEBUG

Appels d'informations laissés dans le code pour le débogage des événements.

VALEUR DE RETOUR

Une chaîne de caractères représentant le niveau de verbosité.

ACCUEIL

Pour plus d'informations, veuillez consulter : https://gearman.org/gearmand/
