getusershell(3) Manuel des fonctions de bibliothèque getusershell(3)

NOM

getusershell, setusershell, endusershell — obtenir les shells utilisateur autorisés

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <unistd.h>
char *getusershell(void);
void setusershell(void);
void endusershell(void);
Exigences de macros de test de fonctionnalité pour glibc (voir feature_test_macros(7)) :

getusershell(), setusershell(), endusershell() :

    Depuis glibc 2.21 :
        _DEFAULT_SOURCE
    En glibc 2.19 et 2.20 :
        _DEFAULT_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)
    Jusqu'à et y compris glibc 2.19 :
        _BSD_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)

DESCRIPTION

La fonction getusershell() renvoie la ligne suivante du fichier /etc/shells, en ouvrant le fichier si nécessaire. La ligne doit contenir le chemin d'accès d'un shell utilisateur valide. Si /etc/shells n'existe pas ou n'est pas lisible, getusershell() se comporte comme si /bin/sh et /bin/csh étaient listés dans le fichier.

La fonction setusershell() rembobine /etc/shells.

La fonction endusershell() ferme /etc/shells.

VALEUR DE RETOUR

La fonction getusershell() renvoie NULL en fin de fichier.

FICHIERS

/etc/shells

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
getusershell (), setusershell (), endusershell () Thread safety MT-Unsafe

NORMES

Aucune.

HISTORIQUE

4.3BSD.
