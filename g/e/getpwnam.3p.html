GETPWNAM(3P) Manuel du programmeur POSIX GETPWNAM(3P)

PROLOGUE

Cette page manuelle fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page manuelle Linux correspondante pour les détails du comportement de Linux), ou l'interface peut ne pas être implémentée sur Linux.

NOM

getpwnam, getpwnam_r — rechercher un nom dans la base de données des utilisateurs

SYNOPSIS

#include <pwd.h>
struct passwd *getpwnam(const char *name);
int getpwnam_r(const char *name, struct passwd *pwd, char *buffer,
    size_t bufsize, struct passwd **result);

DESCRIPTION

La fonction getpwnam() doit rechercher dans la base de données des utilisateurs une entrée correspondant au name.

La fonction getpwnam() n'a pas besoin d'être sûre pour les threads.

Les applications souhaitant vérifier les situations d'erreur doivent définir errno à 0 avant d'appeler getpwnam(). Si getpwnam() retourne un pointeur nul et que errno est non nul, une erreur s'est produite.

La fonction getpwnam_r() doit mettre à jour la structure passwd pointée par pwd et stocker un pointeur vers cette structure à l'endroit pointé par result. La structure doit contenir une entrée de la base de données des utilisateurs correspondant au name. Le stockage référencé par la structure est alloué à partir de la mémoire fournie avec le paramètre buffer , qui fait bufsize octets de taille. Un appel à sysconf(_SC_GETPW_R_SIZE_MAX) retourne soit -1 sans changer errno , soit une valeur initiale suggérée pour la taille de ce tampon. Un pointeur nul doit être retourné à l'endroit pointé par result en cas d'erreur ou si l'entrée demandée est introuvable.

VALEUR RETOURNÉE

La fonction getpwnam() doit retourner un pointeur vers une struct passwd avec la structure telle que définie dans <pwd.h> contenant l'entrée correspondante si elle est trouvée. Un pointeur nul doit être retourné si l'entrée demandée est introuvable ou si une erreur se produit. Si l'entrée demandée n'a pas été trouvée, errno ne doit pas être modifié. En cas d'erreur, errno doit être défini pour indiquer l'erreur.

L'application ne doit pas modifier la structure vers laquelle pointe la valeur retournée, ni aucune zone de stockage pointée par des pointeurs à l'intérieur de la structure. Le pointeur retourné, et les pointeurs à l'intérieur de la structure, peuvent être invalidés, ou la structure ou les zones de stockage peuvent être écrasées par un appel subséquent à getpwent(), getpwnam(), ou getpwuid(). Le pointeur retourné, et les pointeurs à l'intérieur de la structure, peuvent également être invalidés si le thread appelant est terminé.

La fonction getpwnam_r() doit retourner zéro en cas de succès ou si l'entrée demandée n'a pas été trouvée et qu'aucune erreur ne s'est produite. Si une erreur s'est produite, un numéro d'erreur doit être retourné pour indiquer l'erreur.

ERREURS

Ces fonctions peuvent échouer si :

EIO
Une erreur d'entrée/sortie s'est produite.
EINTR
Un signal a été capturé pendant getpwnam().
EMFILE
Tous les descripteurs de fichiers disponibles pour le processus sont actuellement ouverts.
ENFILE
Le nombre maximum de fichiers autorisés est actuellement ouvert dans le système.

La fonction getpwnam_r() peut échouer si :

ERANGE
Un stockage insuffisant a été fourni via buffer et bufsize pour contenir les données à référencer par la structure passwd résultante.

EXEMPLES

Notez que sysconf(_SC_GETPW_R_SIZE_MAX) peut retourner -1 s'il n'y a pas de limite stricte sur la taille du tampon nécessaire pour stocker tous les groupes retournés. Cet exemple montre comment une application peut allouer un tampon de taille suffisante pour travailler avec getpwnam_r().

long int initlen = sysconf(_SC_GETPW_R_SIZE_MAX);
size_t len;
if (initlen == -1)
    /* Longueur initiale par défaut. */
    len = 1024;
else
    len = (size_t) initlen;
struct passwd result;
struct passwd *resultp;
char *buffer = malloc(len);
if (buffer == NULL)
    ...gérer l'erreur...
int e;
while ((e = getpwnam_r("someuser", &result, buffer, len, &resultp))
        == ERANGE)
    {
    size_t newlen = 2 * len;
    if (newlen < len)
        ...gérer l'erreur...
    len = newlen;
    char *newbuffer = realloc(buffer, len);
    if (newbuffer == NULL)
        ...gérer l'erreur...
    buffer = newbuffer;
    }
if (e != 0)
    ...gérer l'erreur...
free (buffer);

Obtenir une entrée pour le nom de connexion

L'exemple suivant utilise la fonction getlogin() pour retourner le nom de l'utilisateur qui s'est connecté ; cette information est passée à la fonction getpwnam() pour obtenir l'entrée de la base de données des utilisateurs pour cet utilisateur.

#include <sys/types.h>
#include <pwd.h>
#include <unistd.h>
#include <stdio.h>
#include <stdlib.h>
...
char *lgn;
struct passwd *pw;
...
if ((lgn = getlogin()) == NULL || (pw = getpwnam(lgn)) == NULL) {
    fprintf(stderr, "Get of user information failed.\n"); exit(1);
}
...

UTILISATION PAR LES APPLICATIONS

Trois noms associés au processus courant peuvent être déterminés : getpwuid(geteuid()) retourne le nom associé à l'identifiant d'utilisateur effectif du processus ; getlogin() retourne le nom associé à l'activité de connexion courante ; et getpwuid(getuid()) retourne le nom associé à l'identifiant d'utilisateur réel du processus.

La fonction getpwnam_r() est sûre pour les threads et retourne les valeurs dans un tampon fourni par l'utilisateur au lieu d'utiliser éventuellement une zone de données statique qui peut être écrasée à chaque appel.

Les applications portables doivent prendre en compte qu'il est courant qu'une implémentation retourne -1 depuis sysconf() indiquant qu'il n'y a pas de maximum pour _SC_GETPW_R_SIZE_MAX.
