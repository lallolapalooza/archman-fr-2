CGESVDX calcule la décomposition en valeurs singulières (SVD) pour les matrices GE

But :

!>
!>  CGESVDX calcule la décomposition en valeurs singulières (SVD) d'une matrice
!>  complexe A de dimension M par N, en calculant éventuellement les vecteurs
!>  singuliers gauche et/ou droit. La SVD est écrite
!>
!>      A = U * SIGMA * transpose(V)
!>
!>  où SIGMA est une matrice M par N qui est nulle à l'exception de ses
!>  min(m,n) éléments diagonaux, U est une matrice unitaire M par M, et
!>  V est une matrice unitaire N par N. Les éléments diagonaux de SIGMA
!>  sont les valeurs singulières de A ; elles sont réelles et non négatives, et
!>  sont renvoyées par ordre décroissant. Les premières colonnes min(m,n) de
!>  U et V sont les vecteurs singuliers gauche et droit de A.
!>
!>  CGESVDX utilise un problème de valeurs propres pour obtenir la SVD, ce qui
!>  permet le calcul d'un sous-ensemble de valeurs singulières et
!>  de vecteurs. Voir SBDSVDX pour plus de détails.
!>
!>  Notez que la routine renvoie V**T, et non V.
!>

Paramètres

JOBU 
!>          JOBU est CHARACTER*1
!>          Spécifie les options pour calculer tout ou partie de la matrice U :
!>          = 'V' : les premières colonnes min(m,n) de U (les vecteurs singuliers
!>                  gauche) ou telles que spécifiées par RANGE sont renvoyées dans
!>                  le tableau U ;
!>          = 'N' : aucune colonne de U (aucun vecteur singulier gauche) n'est
!>                  calculée.
!>

JOBVT

!>          JOBVT est CHARACTER*1
!>           Spécifie les options pour calculer tout ou partie de la matrice
!>           V**T :
!>           = 'V' : les premières lignes min(m,n) de V**T (les vecteurs singuliers
!>                   droit) ou telles que spécifiées par RANGE sont renvoyées dans
!>                   le tableau VT ;
!>           = 'N' : aucune ligne de V**T (aucun vecteur singulier droit) n'est
!>                   calculée.
!>

RANGE

!>          RANGE est CHARACTER*1
!>          = 'A' : toutes les valeurs singulières seront trouvées.
!>          = 'V' : toutes les valeurs singulières dans l'intervalle semi-ouvert (VL,VU]
!>                 seront trouvées.
!>          = 'I' : les valeurs singulières de la ième à la IU-ième seront trouvées.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A. N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice A de dimension M par N.
!>          À la sortie, le contenu de A est détruit.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

VL

!>          VL est REAL
!>          Si RANGE='V', la borne inférieure de l'intervalle dans
!>          lequel rechercher les valeurs singulières. VU > VL.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

VU

!>          VU est REAL
!>          Si RANGE='V', la borne supérieure de l'intervalle dans
!>          lequel rechercher les valeurs singulières. VU > VL.
!>          Non référencé si RANGE = 'A' ou 'I'.
!>

IL

!>          IL est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus petite valeur singulière à renvoyer.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

IU

!>          IU est INTEGER
!>          Si RANGE='I', l'indice de la
!>          plus grande valeur singulière à renvoyer.
!>          1 <= IL <= IU <= min(M,N), si min(M,N) > 0.
!>          Non référencé si RANGE = 'A' ou 'V'.
!>

NS

!>          NS est INTEGER
!>          Le nombre total de valeurs singulières trouvées,
!>          0 <= NS <= min(M,N).
!>          Si RANGE = 'A', NS = min(M,N) ; si RANGE = 'I', NS = IU-IL+1.
!>

S

!>          S est un tableau REAL, dimension (min(M,N))
!>          Les valeurs singulières de A, triées de sorte que S(i) >= S(i+1).
!>

U

!>          U est un tableau COMPLEX, dimension (LDU,UCOL)
!>          Si JOBU = 'V', U contient les colonnes de U (les vecteurs singuliers
!>          gauche, stockés par colonnes) telles que spécifiées par RANGE ; si
!>          JOBU = 'N', U n'est pas référencé.
!>          Note : L'utilisateur doit s'assurer que UCOL >= NS ; si RANGE = 'V',
!>          la valeur exacte de NS n'est pas connue à l'avance et une borne
!>          supérieure doit être utilisée.
!>

LDU

!>          LDU est INTEGER
!>          La dimension principale du tableau U. LDU >= 1 ; si
!>          JOBU = 'V', LDU >= M.
!>

VT

!>          VT est un tableau COMPLEX, dimension (LDVT,N)
!>          Si JOBVT = 'V', VT contient les lignes de V**T (les vecteurs singuliers
!>          droit, stockés par lignes) telles que spécifiées par RANGE ; si JOBVT = 'N',
!>          VT n'est pas référencé.
!>          Note : L'utilisateur doit s'assurer que LDVT >= NS ; si RANGE = 'V',
!>          la valeur exacte de NS n'est pas connue à l'avance et une borne
!>          supérieure doit être utilisée.
!>

LDVT

!>          LDVT est INTEGER
!>          La dimension principale du tableau VT. LDVT >= 1 ; si
!>          JOBVT = 'V', LDVT >= NS (voir ci-dessus).
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= MAX(1,MIN(M,N)*(MIN(M,N)+4)) pour les chemins (voir
!>          les commentaires dans le code) :
!>             - CHEMIN 1  (M beaucoup plus grand que N)
!>             - CHEMIN 1t (N beaucoup plus grand que M)
!>          LWORK >= MAX(1,MIN(M,N)*2+MAX(M,N)) pour les autres chemins.
!>          Pour de bonnes performances, LWORK devrait généralement être plus grand.
!>
!>          Si LWORK = -1, une interrogation de l'espace de travail est supposée ; la routine
!>          ne calcule que la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!> >

RWORK


!>          RWORK est un tableau REEL, de dimension (MAX(1,LRWORK))
!>          LRWORK >= MIN(M,N)*(MIN(M,N)*2+15*MIN(M,N)).
!> 


IWORK


!>          IWORK est un tableau ENTIER, de dimension (12*MIN(M,N))
!>          Si INFO = 0, les premiers NS éléments de IWORK sont nuls. Si INFO > 0,
!>          alors IWORK contient les indices des vecteurs propres qui n'ont pas
!>          convergé dans SBDSVDX/SSTEVX.
!> 


INFO


!>     INFO est ENTIER
!>           = 0:  sortie réussie
!>           < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>           > 0:  si INFO = i, alors i vecteurs propres n'ont pas convergé
!>                 dans SBDSVDX/SSTEVX.
!>                 si INFO = N*2 + 1, une erreur interne s'est produite dans
!>                 SBDSVDX
!>

subroutine   sgesvdx (character jobu, character jobvt, character range, integer m, integer   n, real, dimension( lda, * ) a, integer lda, real vl, real vu, integer il,   integer iu, integer ns, real, dimension( * ) s, real, dimension( ldu, * )   u, integer ldu, real, dimension( ldvt, * ) vt, integer ldvt, real, dimension(   * ) work, integer lwork, integer, dimension( * ) iwork, integer info)


 SGESVDX computes the singular value decomposition (SVD) of a real
    M-by-N matrix A, optionally computing the left and/or right singular
    vectors. The SVD is written


Purpose:




!>
!>  SGESVDX computes the singular value decomposition (SVD) of a real
!>  M-by-N matrix A, optionally computing the left and/or right singular
!>  vectors. The SVD is written
!>
!>      A = U * SIGMA * transpose(V)
!>
!>  where SIGMA is an M-by-N matrix which is zero except for its
!>  min(m,n) diagonal elements, U is an M-by-M orthogonal matrix, and
!>  V is an N-by-N orthogonal matrix.  The diagonal elements of SIGMA
!>  are the singular values of A; they are real and non-negative, and
!>  are returned in descending order.  The first min(m,n) columns of
!>  U and V are the left and right singular vectors of A.
!>
!>  SGESVDX uses an eigenvalue problem for obtaining the SVD, which
!>  allows for the computation of a subset of singular values and
!>  vectors. See SBDSVDX for details.
!>
!>  Note that the routine returns V**T, not V.
!> 




Parameters


JOBU

!>          JOBU is CHARACTER*1
!>          Specifies options for computing all or part of the matrix U:
!>          = 'V':  the first min(m,n) columns of U (the left singular
!>                  vectors) or as specified by RANGE are returned in
!>                  the array U;
!>          = 'N':  no columns of U (no left singular vectors) are
!>                  computed.
!> 


JOBVT


!>          JOBVT is CHARACTER*1
!>           Specifies options for computing all or part of the matrix
!>           V**T:
!>           = 'V':  the first min(m,n) rows of V**T (the right singular
!>                   vectors) or as specified by RANGE are returned in
!>                   the array VT;
!>           = 'N':  no rows of V**T (no right singular vectors) are
!>                   computed.
!> 


RANGE


!>          RANGE is CHARACTER*1
!>          = 'A': all singular values will be found.
!>          = 'V': all singular values in the half-open interval (VL,VU]
!>                 will be found.
!>          = 'I': the IL-th through IU-th singular values will be found.
!> 


M


!>          M is INTEGER
!>          The number of rows of the input matrix A.  M >= 0.
!> 


N


!>          N is INTEGER
!>          The number of columns of the input matrix A.  N >= 0.
!> 


A


!>          A is REAL array, dimension (LDA,N)
!>          On entry, the M-by-N matrix A.
!>          On exit, the contents of A are destroyed.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!> 


VL


!>          VL is REAL
!>          If RANGE='V', the lower bound of the interval to
!>          be searched for singular values. VU > VL.
!>          Not referenced if RANGE = 'A' or 'I'.
!> 


VU


!>          VU is REAL
!>          If RANGE='V', the upper bound of the interval to
!>          be searched for singular values. VU > VL.
!>          Not referenced if RANGE = 'A' or 'I'.
!> 


IL


!>          IL is INTEGER
!>          If RANGE='I', the index of the
!>          smallest singular value to be returned.
!>          1 <= IL <= IU <= min(M,N), if min(M,N) > 0.
!>          Not referenced if RANGE = 'A' or 'V'.
!> 


IU


!>          IU is INTEGER
!>          If RANGE='I', the index of the
!>          largest singular value to be returned.
!>          1 <= IL <= IU <= min(M,N), if min(M,N) > 0.
!>          Not referenced if RANGE = 'A' or 'V'.
!> 


NS


!>          NS is INTEGER
!>          The total number of singular values found,
!>          0 <= NS <= min(M,N).
!>          If RANGE = 'A', NS = min(M,N); if RANGE = 'I', NS = IU-IL+1.
!> 


S


!>          S is REAL array, dimension (min(M,N))
!>          The singular values of A, sorted so that S(i) >= S(i+1).
!> 


U


!>          U is REAL array, dimension (LDU,UCOL)
!>          If JOBU = 'V', U contains columns of U (the left singular
!>          vectors, stored columnwise) as specified by RANGE; if
!>          JOBU = 'N', U is not referenced.
!>          Note: The user must ensure that UCOL >= NS; if RANGE = 'V',
!>          the exact value of NS is not known in advance and an upper
!>          bound must be used.
!> 


LDU


!>          LDU is INTEGER
!>          The leading dimension of the array U.  LDU >= 1; if
!>          JOBU = 'V', LDU >= M.
!> 


VT


!>          VT is REAL array, dimension (LDVT,N)
!>          If JOBVT = 'V', VT contains the rows of V**T (the right singular
!>          vectors, stored rowwise) as specified by RANGE; if JOBVT = 'N',
!>          VT is not referenced.
!>          Note: The user must ensure that LDVT >= NS; if RANGE = 'V',
!>          the exact value of NS is not known in advance and an upper
!>          bound must be used.
!> 


LDVT


!>          LDVT is INTEGER
!>          The leading dimension of the array VT.  LDVT >= 1; if
!>          JOBVT = 'V', LDVT >= NS (see above).
!> 


WORK


!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK;
!> 


LWORK

 ZGESVDX computes the singular value decomposition (SVD) for GE
    matrices


Purpose:




!>
!>  ZGESVDX computes the singular value decomposition (SVD) of a complex
!>  M-by-N matrix A, optionally computing the left and/or right singular
!>  vectors. The SVD is written
!>
!>      A = U * SIGMA * transpose(V)
!>
!>  where SIGMA is an M-by-N matrix which is zero except for its
!>  min(m,n) diagonal elements, U is an M-by-M unitary matrix, and
!>  V is an N-by-N unitary matrix.  The diagonal elements of SIGMA
!>  are the singular values of A; they are real and non-negative, and
!>  are returned in descending order.  The first min(m,n) columns of
!>  U and V are the left and right singular vectors of A.
!>
!>  ZGESVDX uses an eigenvalue problem for obtaining the SVD, which
!>  allows for the computation of a subset of singular values and
!>  vectors. See DBDSVDX for details.
!>
!>  Note that the routine returns V**T, not V.
!>
