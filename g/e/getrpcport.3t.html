NOM

getrpcport — obtenir le numéro de port RPC

SYNTAXE

int
getrpcport(char *host, int prognum, int versnum, int proto);

DESCRIPTION

La fonction getrpcport() retourne le numéro de port pour la version versnum du programme RPC prognum exécuté sur host et utilisant le protocole proto. Elle retourne 0 si elle ne peut pas contacter le portmapper, ou si prognum n'est pas enregistré. Si prognum est enregistré mais pas avec la version versnum, elle retournera toujours un numéro de port (pour une certaine version du programme) indiquant que le programme est bien enregistré. La non-concordance de version sera détectée lors du premier appel au service.

DISPONIBILITÉ

La fonction getrpcport() fait partie de libtirpc.
