GEARMAN_CLIENT_ADD_TASK_STATUS(3) Gearmand GEARMAN_CLIENT_ADD_TASK_STATUS(3)

NOM

gearman_client_add_task_status - Documentation Gearmand, https://gearman.org/gearmand/

SYNOPSIS

#include <libgearman/gearman.h>

gearman_task_st *gearman_client_add_task_status(gearman_client_st *client, gearman_task_st *task, void *context, const char *job_handle, gearman_return_t *ret_ptr)

Lier avec -lgearman

DESCRIPTION

gearman_client_add_task_status() crée une gearman_task_st qui peut être utilisée pour surveiller une tâche précédemment créée.

AVERTISSEMENT :

Vous pourriez vouloir éviter d'utiliser gearman_client_add_task() avec une gearman_task_st allouée sur la pile. Les problèmes les plus courants liés à la sécurité ABI concernent les structures allouées sur la pile. Si vous utilisez une gearman_task_st basée sur la pile, vous devez la libérer avec gearman_task_free().

VALEUR DE RETOUR

La gearman_task_st est créée et un pointeur vers celle-ci est retourné. En cas d'erreur, NULL est retourné et ret_ptr est défini avec une gearman_return_t.

Pour plus d'informations, veuillez consulter : https://gearman.org/gearmand/
