GEOIPLOOKUP(1) Manuel des commandes générales GEOIPLOOKUP(1)

NOM

geoiplookup - rechercher le pays à partir d'une adresse IP ou d'un nom d'hôte

SYNTAXE

geoiplookup [-d répertoire] [-f fichier] [-v] <adresse IP|nom d'hôte>

DESCRIPTION

geoiplookup utilise la bibliothèque GeoIP et la base de données pour trouver le pays d'origine d'une adresse IP ou d'un nom d'hôte.

Par exemple

geoiplookup 80.60.233.195

trouvera le pays d'origine de 80.60.233.195, dans le format suivant :

NL, Pays-Bas

OPTIONS

-f
Spécifiez un chemin personnalisé vers un fichier de données GeoIP unique.
-d
Spécifiez un répertoire personnalisé contenant des fichiers de données GeoIP. Par défaut, geoiplookup recherche dans /usr/share/GeoIP
-v
Liste la date et le numéro de build pour le(s) fichier(s) de données GeoIP.
