gearman_client_add_servers(3)

Paquet: gearmand

Licences: BSD-3-Clause

GEARMAN_CLIENT_ADD_SERVERS(3) Gearmand GEARMAN_CLIENT_ADD_SERVERS(3)

NOM

Documentation Gearmand, https://gearman.org/gearmand/

SYNTAXE

#include <libgearman/gearman.h>

gearman_return_t gearman_client_add_server(gearman_client_st *client, const char *host, in_port_t port)
gearman_return_t gearman_client_add_servers(gearman_client_st *client, const char *servers)
void gearman_client_remove_servers(gearman_client_st *client)

DESCRIPTION

gearman_client_add_server() ajoutera un serveur gearmand supplémentaire à la liste des serveurs à partir desquels le client prendra du travail.

gearman_client_remove_servers() supprimera tous les serveurs de gearman_client_st.

gearman_client_add_servers() prend une liste de serveurs gearmand qui sera analysée pour fournir des serveurs au client. Le format est SERVER[:PORT][,SERVER[:PORT]]...

Exemples de ceci sont :
10.0.0.1,10.0.0.2,10.0.0.3 localhost234,jobserver2.domain.com:7003,10.0.0.3

VALEUR DE RETOUR

gearman_client_add_server() et gearman_client_remove_servers() retournent gearman_return_t.

Pour en savoir plus, veuillez consulter : https://gearman.org/gearmand/
