sous-routine cgeqrfp (integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer lwork, integer info)

CGEQRFP

But :

!>
!> CGEQR2P calcule une factorisation QR d'une matrice complexe A de taille M par N :
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> où :
!>
!>    Q est une matrice orthogonale M par M ;
!>    R est une matrice triangulaire supérieure N par N dont les entrées
!>    diagonales sont non négatives ;
!>    0 est une matrice nulle (M-N) par N, si M > N.
!>
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille M par N.
!>          À la sortie, les éléments sur et au-dessus de la diagonale du tableau
!>          contiennent la matrice trapézoïdale supérieure R de taille min(M,N) par N (R est
!>          triangulaire supérieure si m >= n). Les entrées diagonales de R
!>          sont réelles et non négatives ; les éléments sous la diagonale,
!>          avec le tableau TAU, représentent la matrice unitaire Q sous la
!>          forme d'un produit de min(m,n) réflecteurs élémentaires (voir Détails
!>          supplémentaires).
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau COMPLEX, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires (voir Détails
!>          supplémentaires).
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.
!>          LWORK >= 1, si MIN(M,N) = 0, et LWORK >= N, sinon.
!>          Pour des performances optimales, LWORK >= N*NB, où NB est
!>          la taille de bloc optimale.
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Auteur

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Détails supplémentaires :

!>
!>  La matrice Q est représentée comme un produit de réflecteurs élémentaires
!>
!>     Q = H(1) H(2) . . . H(k), où k = min(m,n).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**H
!>
!>  où tau est un scalaire complexe, et v est un vecteur complexe avec
!>  v(1:i-1) = 0 et v(i) = 1 ; v(i+1:m) est stocké à la sortie dans A(i+1:m,i),
!>  et tau dans TAU(i).
!>
!> Voir Lapack Working Note 203 pour plus de détails
!>
