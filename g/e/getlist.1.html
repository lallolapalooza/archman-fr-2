NOM

getlist - Obtenir une liste d'un serveur NNTP

SYNTAXE

getlist [-AR] [-h hôte] [-p port] [liste [motif [types]]]

DESCRIPTION

getlist récupère une liste d'un serveur NNTP et l'envoie à la sortie standard. liste peut être l'une des valeurs suivantes : "active" (qui est la valeur par défaut), "active.times", "distrib.pats" ou "newsgroups". "active" contient une liste de tous les newsgroups gérés par le serveur avec les numéros d'articles les plus hauts et les plus bas du groupe, et le champ d'état du groupe. "active.times" est une liste de newsgroups, leurs heures de création (en secondes depuis l'époque), et le créateur du groupe. "distrib.pats" est une liste des distributions pertinentes et des newsgroups auxquels elles s'appliquent. "newsgroups" est une liste de newsgroups accompagnée de leurs courtes descriptions.

Pour plus d'informations sur les formats de ces fichiers, voir active(5), active.times(5), distrib.pats(5) et newsgroups(5).

Les fichiers de liste autres que le fichier active sont des extensions courantes du protocole NNTP et peuvent ne pas être disponibles sur tous les serveurs. Par exemple, "counts", "distributions", "headers", "moderators", "motd", "overview.fmt" et "subscriptions", entre autres, peuvent être disponibles. De plus, un motif uwildmat motif peut également être utilisable pour certains de ces fichiers de liste.

Pour plus d'informations sur les formats de ces fichiers, voir distributions(5), moderators(5), motd.news(5) et subscriptions(5). Les champs d'aperçu obtenus avec "overview.fmt" sont ceux pour lesquels la base de données d'aperçu est cohérente (voir extraoverviewadvertised dans inn.conf pour plus d'informations). La liste obtenue avec "headers" contient les champs qui peuvent être récupérés à l'aide de la commande HDR (motif peut alors être soit "msgid", soit "range"). La liste obtenue avec "counts" est similaire à celle de "active", sauf que le nombre d'articles dans un newsgroup est mentionné juste avant l'indicateur de ce newsgroup.

Le paramètre motif peut être utilisé avec une valeur de liste de "active", "active.times" ou "newsgroups" pour limiter la sortie. S'il est fourni, seules les entrées correspondant aux newsgroups qui correspondent au motif uwildmat motif seront imprimées.

Si le paramètre liste est "active", un troisième paramètre, types, peut également être utilisé pour restreindre la liste. S'il est fourni, seules les entrées correspondant aux newsgroups dont le mode de newsgroup se trouve dans types seront imprimées. Par exemple, une valeur de types de "y" ne montrerait que les groupes non modérés, et une valeur de types de "ym" montrerait tous les groupes non modérés et modérés, mais pas les groupes alias ou les groupes qui interdisent les publications.

OPTIONS

-A
Essayer de s'authentifier en utilisant les informations de nom d'utilisateur et de mot de passe dans passwd.nntp(5) avant d'émettre la commande LIST.
-h hôte
Se connecter au serveur hôte plutôt qu'à la valeur de server dans inn.conf ou à la valeur de la variable d'environnement NNTPSERVER.
-p port
Se connecter au port port, qui est par défaut 119.
-R
Essayer de passer à nnrpd avec une commande MODE READER avant d'émettre la requête LIST. Cela peut être utile si un accès de distribution existe pour le serveur de news : plus d'informations peuvent être récupérées depuis nnrpd, par rapport à innd.

EXEMPLES

La commande suivante obtiendra les descriptions sur une seule ligne de tous les newsgroups trouvés sur UUNET :

getlist -h news.uu.net newsgroups

La commande suivante affichera les entrées du fichier active pour tous les groupes comp.* modérés sur le serveur par défaut :

getlist active 'comp.*' m

La commande suivante liste tous les groupes pour lesquels les publications locales sont autorisées, sont modérées ou sont alias :

getlist active '*' ym=

Notez que le caractère générique "*" doit être protégé par des guillemets simples pour le protéger du shell.
