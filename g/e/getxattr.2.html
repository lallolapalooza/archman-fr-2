getxattr(2) Manuel des appels système getxattr(2)

NOM

getxattr, lgetxattr, fgetxattr - récupérer la valeur d'un attribut étendu

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/xattr.h>
ssize_t getxattr(size_t size;
                 const char *chemin, const char *nom,
                 void valeur[size], size_t taille);
ssize_t lgetxattr(size_t size;
                 const char *chemin, const char *nom,
                 void valeur[size], size_t taille);
ssize_t fgetxattr(size_t size;
                 int fd, const char *nom,
                 void valeur[size], size_t taille);

DESCRIPTION

Les attributs étendus sont des paires nom:valeur associées aux inodes (fichiers, répertoires, liens symboliques, etc.). Ce sont des extensions des attributs normaux qui sont associés à tous les inodes du système (c'est-à-dire les données de stat(2)). Un aperçu complet des concepts d'attributs étendus se trouve dans xattr(7).

getxattr() récupère la valeur de l'attribut étendu identifié par nom et associé au chemin donné dans le système de fichiers. La valeur de l'attribut est placée dans le tampon pointé par valeur ; taille spécifie la taille de ce tampon. La valeur de retour de l'appel est le nombre d'octets placés dans valeur.

lgetxattr() est identique à getxattr(), sauf dans le cas d'un lien symbolique, où le lien lui-même est interrogé, pas le fichier auquel il fait référence.

fgetxattr() est identique à getxattr(), seul le fichier ouvert référencé par fd (tel que retourné par open(2)) est interrogé à la place du chemin.

Un nom d'attribut étendu est une chaîne terminée par un octet nul. Le nom inclut un préfixe d'espace de noms ; il peut y avoir plusieurs espaces de noms disjoints associés à un inode individuel. La valeur d'un attribut étendu est un bloc de données textuelles ou binaires arbitraires qui a été attribué à l'aide de setxattr(2).

Si taille est spécifié comme zéro, ces appels retournent la taille actuelle de l'attribut étendu nommé (et laissent valeur inchangé). Cela peut être utilisé pour déterminer la taille du tampon qui devrait être fournie dans un appel ultérieur. (Cependant, gardez à l'esprit qu'il est possible que la valeur de l'attribut change entre les deux appels, de sorte qu'il est toujours nécessaire de vérifier le statut de retour du second appel.)

VALEUR DE RETOUR

En cas de succès, ces appels retournent une valeur non négative qui est la taille (en octets) de la valeur de l'attribut étendu. En cas d'échec, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

E2BIG
La taille de la valeur de l'attribut est supérieure à la taille maximale autorisée ; l'attribut ne peut pas être récupéré. Cela peut se produire sur les systèmes de fichiers qui prennent en charge des valeurs d'attribut très grandes, comme NFSv4, par exemple.
ENODATA
L'attribut nommé n'existe pas, ou le processus n'a pas accès à cet attribut.
ENOTSUP
Les attributs étendus ne sont pas pris en charge par le système de fichiers, ou sont désactivés.
ERANGE
La taille du tampon valeur est trop petite pour contenir le résultat.

En outre, les erreurs documentées dans stat(2) peuvent également se produire.

NORMES

Linux.

HISTORIQUE

Linux 2.4, glibc 2.3.

EXEMPLES

Voir listxattr(2).
