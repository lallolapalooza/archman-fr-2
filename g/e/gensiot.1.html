gensiotool(1) Manuel des commandes générales gensiotool(1)

NOM

gensiotool - Outil pour établir des connexions gensio

SYNTAXE

gensiotool [options] io2

DESCRIPTION

Le programme gensiotool permet d'établir des connexions en utilisant gensios. Il crée deux gensios nommés io1 et io2. io1 est par défaut le terminal local et io2 doit être spécifié.

Par défaut, gensiotool crée deux gensios normaux et établit des connexions à chacun d'eux. Toutes les données entrantes sur un gensio sont transmises sur l'autre.

Pour une description de la façon de spécifier un gensio, voir la documentation de gensio.

OPTIONS

-i|--input io1
Par défaut, io1 est le terminal local ( /dev/tty ) pour une entrée standard tty, ou l'entrée/sortie standard du programme pour une entrée standard non-tty. Ceci permet de spécifier un autre gensio comme périphérique à connecter à io2.
-a|--accepter
Par défaut, io2 établit une connexion sortante. Ceci modifie io2 pour en faire un accepteur de gensio et attend une connexion entrante. Une fois la connexion établie, l'accepteur est fermé et les opérations continuent normalement.
--signature
Signature du serveur série rapportée à l'extrémité distante. Si un accepteur est spécifié (actuellement seulement un serveur telnet RFC2217), la signature fournie est utilisée à la place de "gensiotool".
-d|--debug
Génère une sortie de débogage. Spécifier plusieurs fois augmente la quantité de sortie.
-e|--escchar char
Spécifie un caractère à utiliser comme caractère d'échappement. Le régler à -1 désactive le caractère d'échappement. Il peut s'agir d'un nombre décimal ou hexadécimal, ou de ^x pour définir un caractère de contrôle. Par défaut, c'est ^\ si io1 est le défaut et l'entrée standard est une tty, ou désactivé sinon. Voir ESCAPES ci-dessous pour plus de détails sur le caractère d'échappement. Géré uniquement sur io1.
-p|--printacc
Si -a est spécifié, affiche toutes les adresses d'acceptation choisies par le programme.
-n|--extra-threads <n>
Lance <n> threads supplémentaires pour gérer les opérations gensio. Utile pour la scalabilité avec --server.
--server
Lorsqu'une acceptation se produit, ne désactive pas l'acceptation, mais continue à accepter les connexions, et ne se ferme pas si toutes les connexions disparaissent. Si ce n'est pas spécifié, l'accepteur est fermé lorsqu'une connexion arrive et le programme se termine lorsque cette connexion se ferme.
--version
Affiche le numéro de version et quitte.
-h|--help
Aide

ESCAPES

Si le caractère d'échappement est reçu sur io1, le caractère n'est pas transféré et le programme attend un autre caractère. Si l'autre caractère est également le caractère d'échappement, un seul caractère d'échappement est envoyé. Si l'autre caractère n'est pas reconnu comme un échappement valide, il est ignoré et non transféré. Les majuscules et minuscules sont équivalentes.

Les caractères d'échappement sont :

q
Quitter le programme.
b
Envoyer une rupture (break) à io2. Ignoré si io2 ne supporte pas la rupture.
d
Afficher les données série pour io2. Ignoré si io2 n'est pas un gensio série.
s
Définir le débit (vitesse) du port série pour io2. Ignoré si io2 n'est pas un gensio série. Après cela, la vitesse du port série doit être tapée, terminée par un saut de ligne. Les vitesses invalides sont ignorées, utilisez escchar-d pour savoir si vous l'avez réglé correctement.
n, o, e
Définir la parité sur io2 à aucune, impaire, ou paire. Ignoré si io2 n'est pas un gensio série.
5, 6, 7, 8
Définir la taille des données sur io2 au nombre de bits. Ignoré si io2 n'est pas un gensio série.
1, 2
Définir le nombre de bits d'arrêt à 1 ou 2 sur io2 bits. Ignoré si io2 n'est pas un gensio série.
x, r, f
Définit le contrôle de flux à xonxoff, rtscts, ou aucun.
