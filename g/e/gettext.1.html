GETTEXT(1) Commandes utilisateur GETTEXT(1)

NOM

gettext - traduire un message

SYNTAXE

gettext [OPTION] [[DOMAINE] MSGID]
gettext [OPTION] -s [MSGID]...

DESCRIPTION

Le programme gettext traduit un message en langue naturelle vers la langue de l'utilisateur, en recherchant la traduction dans un catalogue de messages.

Affiche la traduction dans la langue native d'un message textuel.

Options et arguments :

-d, --domain=DOMAINE
récupère les messages traduits du DOMAINE
-c, --context=CONtexte
spécifie le contexte pour MSGID
-e
active l'expansion de certaines séquences d'échappement
-n
supprime le retour à la ligne final
-E
(ignoré pour des raisons de compatibilité)
[DOMAINE] MSGID
récupère le message traduit correspondant à MSGID du DOMAINE

Sortie informative :

-h, --help
affiche cette aide et quitte
-V, --version
affiche les informations sur la version et quitte

Si le paramètre DOMAINE n'est pas fourni, le domaine est déterminé à partir de la variable d'environnement TEXTDOMAIN. Si le catalogue de messages n'est pas trouvé dans le répertoire habituel, un autre emplacement peut être spécifié avec la variable d'environnement TEXTDOMAINDIR. Lorsqu'il est utilisé avec l'option -s, le programme se comporte comme la commande 'echo'. Mais il ne copie pas simplement ses arguments vers la sortie standard. Au lieu de cela, les messages trouvés dans le catalogue sélectionné sont traduits. Répertoire de recherche standard : /usr/share/locale
