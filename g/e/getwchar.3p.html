GETWCHAR(3P) Manuel du programmeur POSIX GETWCHAR(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

getwchar — lire un caractère large depuis un flux stdin

SYNTAXE

#include <wchar.h>
wint_t getwchar(void);

DESCRIPTION

Les fonctionnalités décrites sur cette page de référence sont alignées sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

La fonction getwchar() est équivalente à getwc(stdin).

VALEUR DE RETOUR

Se référer à fgetwc().

ERREURS

Se référer à fgetwc().

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION APPLICATIVE

Si la valeur wint_t retournée par getwchar() est stockée dans une variable de type wchar_t puis comparée à la macro wint_t WEOF, le résultat peut être incorrect. Seul le type wint_t est garanti de pouvoir représenter n'importe quel caractère large et WEOF.
