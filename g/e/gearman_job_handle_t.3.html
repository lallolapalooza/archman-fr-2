gearman_job_handle_t(3)

Paquet: gearmand

Licences: BSD-3-Clause

GEARMAN_JOB_HANDLE_T(3) Gearmand GEARMAN_JOB_HANDLE_T(3)

NOM

gearman_job_handle_t - Documentation Gearmand, https://gearman.org/gearmand/

SYNOPSIS

#include <libgearman/gearman.h>

type gearman_job_handle_t

DESCRIPTION

Un gearman_job_handle_t représente un « gestionnaire de tâche ». Un gestionnaire de tâche est une chaîne de caractères qui représente le nom d'une tâche (en réalité gearman_job_handle_t est un alias de type char[GEARMAN_JOB_HANDLE_SIZE]).

gearman_client_job_status() utilise les gestionnaires pour trouver le statut des tâches. Lorsqu'il est passé à gearman_client_do_background(), il sera rempli avec le gestionnaire de tâche.

VALEUR DE RETOUR

Aucune.

ACCUEIL

Pour plus d'informations, veuillez consulter : https://gearman.org/gearmand/
