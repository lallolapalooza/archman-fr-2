getpt(3) Manuel des fonctions de bibliothèque getpt(3)

NOM

getpt - ouvrir un nouveau maître de pseudo-terminal

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#define _GNU_SOURCE             /* Voir feature_test_macros(7) */
#include <stdlib.h>
int getpt(void);

DESCRIPTION

getpt() ouvre un nouveau périphérique de pseudo-terminal et renvoie un descripteur de fichier qui se réfère à ce périphérique. Il est équivalent à ouvrir le périphérique multiplexeur de pseudo-terminal


open("/dev/ptmx", O_RDWR);

sur les systèmes Linux, bien que le périphérique multiplexeur de pseudo-terminal se trouve ailleurs sur certains systèmes qui utilisent la bibliothèque C GNU.

VALEUR RENVOYÉE

getpt() renvoie un descripteur de fichier ouvert en cas de succès. Sinon, il renvoie -1 et définit errno pour indiquer l'erreur.

ERREURS

getpt() peut échouer avec diverses erreurs décrites dans open(2).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
getpt () Sécurité des threads MT-Safe

VERSIONS

Utilisez plutôt posix_openpt(3).

NORMES

GNU.

HISTORIQUE

glibc 2.1.

VOIR AUSSI

grantpt(3), posix_openpt(3), ptsname(3), unlockpt(3), ptmx(4), pty(7)
