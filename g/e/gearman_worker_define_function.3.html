gearman_worker_define_function(3)

Paquet: gearmand

Licences: BSD-3-Clause

GEARMAN_WORKER_DEFINE_FUNCTION(3) Gearmand GEARMAN_WORKER_DEFINE_FUNCTION(3)

NOM

gearman_worker_define_function - Documentation Gearmand, https://gearman.org/gearmand/

SYNTAXE

#include <libgearman/gearman.h>

type gearman_function_t
gearman_return_t gearman_worker_define_function(gearman_worker_st *worker, const char *function_name, const size_t function_name_length, const gearman_function_t function, const uint32_t timeout, void *context)
type gearman_function_fn
type gearman_aggregator_fn

Lier avec -lgearman

DESCRIPTION

gearman_worker_define_function() définit les fonctions pour un worker.

L'interface est basée sur des rappels (callbacks). Lorsque le serveur a un travail pour le worker, gearman_function_fn est appelée avec une structure gearman_job_st représentant le travail, et le contexte qui a été défini à l'origine lors de la définition de la fonction.

Les résultats sont renvoyés au client en appelant gearman_job_send_data().

Si le client a spécifié une fonction de réduction, alors la sortie de gearman_function_fn sera envoyée à cette fonction. Vous pouvez diviser le travail vers la fonction de réduction en envoyant des données plusieurs fois avec gearman_job_send_data().

Si des erreurs sont détectées, alors le travail entier est annulé. La fonction gearman_aggregator_fn sera appelée une fois que tous les travaux mappés seront terminés. Le résultat de cette fonction sera ce qui sera renvoyé au client.

La fonction de rappel doit renvoyer l'une des erreurs suivantes :

GEARMAN_SUCCESS

La fonction a réussi.

GEARMAN_FAIL

Une erreur s'est produite, le travail n'a pas été traité et le worker ne peut pas continuer.

GEARMAN_ERROR

Une erreur transitoire s'est produite, comme une défaillance réseau, et le travail peut être redémarré.

Si une valeur autre que celles ci-dessus est retournée, elle est convertie en GEARMAN_FAIL et gearman_worker_work() retourne GEARMAN_INVALID_ARGUMENT.

gearman_job_send_complete() et gearman_job_send_fail() ne peuvent pas être utilisés avec des fonctions créées avec gearman_worker_define_function().

VALEUR DE RETOUR

gearman_return_t
