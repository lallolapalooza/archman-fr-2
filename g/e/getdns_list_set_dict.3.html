getdns_list_set_dict(3)

Paquet: getdns

Licences: BSD

getdns_list_set(3) getdns getdns_list_set(3)

NOM

getdns_list_set, getdns_list_set_bindata, getdns_list_set_dict, getdns_list_set_int, getdns_list_set_list, -- définir une valeur par index à partir d'une liste getdns

BIBLIOTHÈQUE

Bibliothèque de résolution DNS (libgetdns, -lgetdns)

SYNTAXE

#include <getdns.h>

getdns_return_t
getdns_list_set_bindata (getdns_list *this_list,

size_t index,
getdns_bindata *child_bindata)

getdns_return_t
getdns_list_set_dict (getdns_list *this_list,

size_t index,
getdns_dict *child_dict)

getdns_return_t
getdns_list_set_int (getdns_list *this_list,

size_t index,
uint32_t child_uint32_t)

getdns_return_t
getdns_list_set_list (getdns_list *this_list,

size_t index,
getdns_list *child_list)

DESCRIPTION

Le type getdns_list est utilisé pour gérer une liste indexée hétérogène de valeurs comprenant :


getdns_bindata
getdns_dict
getdns_list
uint32_t

this_list la liste dans laquelle ajouter/mettre à jour l'élément indexé.

index l'index dont la valeur associée doit être définie. Si l'index existe dans la liste, la valeur associée à cet index est remplacée ; si l'index n'existe pas dans la liste, un nouvel élément est ajouté à la liste à l'index spécifié.

child_bindata child_dict child_list child_uint32 valeur à attribuer à l'élément indexé.

VALEURS DE RETOUR

En cas de succès, les fonctions renvoient GETDNS_RETURN_GOOD, sinon les valeurs d'erreur suivantes sont renvoyées :

GETDNS_RETURN_NO_SUCH_LIST_ITEM si l'index est hors limites.

GETDNS_RETURN_GENERIC_ERROR si this_list n'est pas une liste valide.
