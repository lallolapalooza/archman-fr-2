NOM

gensio_add_default, gensio_set_default, gensio_get_default, gensio_get_defaultaddr, gensio_del_default, gensio_reset_defaults - Gérer les valeurs par défaut pour les gensios

SYNOPSIS

#include <gensio/gensio.h>
struct gensio_enum_val {
char *name;
int val;
};

int gensio_add_default(struct gensio_os_funcs *o,

const char *name,
enum gensio_default_type type,
const char *strval, int intval,
int minval, int maxval,
const struct gensio_enum_val *enums);
int gensio_set_default(struct gensio_os_funcs *o,

const char *class, const char *name,
const char *strval, int intval);
int gensio_get_default(struct gensio_os_funcs *o,

const char *class, const char *name,
bool classonly,
enum gensio_default_type type,
char **strval, int *intval);
int gensio_get_defaultaddr(struct gensio_os_funcs *o,

const char *class, const char *name,
bool classonly,
int iprotocol, bool listen,
bool require_port,
struct addrinfo **rai);
int gensio_del_default(struct gensio_os_funcs *o,

const char *class, const char *name,
bool delclasses);
int gensio_reset_defaults(struct gensio_os_funcs *o);

DESCRIPTION

Les valeurs par défaut fournissent un moyen de définir des valeurs par défaut globales ou spécifiques à une classe pour les options des gensios (ou vous pouvez les utiliser vous-même pour créer vos propres valeurs par défaut). Les diverses options pour les gensios sont décrites dans gensio(5).

Pour les valeurs par défaut, chaque classe utilisera gensio_get_default avec sa *class* (serialdev, telnet, ssl, etc.) et le *name* comme nom de l'option donnée. Si une valeur a été définie pour sa classe, cette valeur sera utilisée. Si une valeur a été définie avec la classe définie à NULL (une valeur par défaut "globale"), alors la valeur sera utilisée à partir de là. Sinon, le code utilisera sa propre valeur par défaut interne.

Toute option fournie dans la chaîne gensio remplacera toute valeur par défaut, bien sûr.

Le paramètre *classonly* signifie de ne pas rechercher dans les valeurs par défaut globales. Si vous utilisez ceci pour vos propres valeurs par défaut, il est recommandé d'utiliser votre propre *class* et de définir *classonly* à vrai.

Les valeurs par défaut se présentent dans l'un des quatre formats définis par *type*: *GENSIO_DEFAULT_INT*, *GENSIO_DEFAULT_BOOL*, *GENSIO_DEFAULT_ENUM*, *GENSIO_DEFAULT_STR*, *GENSIO_DEFAULT_DATA*. int et bool sont assez explicites. Sauf que si vous passez un strval non NULL lors de la définition de l'un d'eux, le code tentera d'obtenir la valeur à partir du strval et retournera NULL si la valeur n'est pas valide. Il tentera de traduire "true" et "false" pour les valeurs booléennes. Si la valeur est *<minval* ou *>maxval*, *GE_OUTOFRANGE* est retourné par toute opération de définition.

Lors de la définition d'une chaîne, la valeur est copiée, vous n'avez pas besoin de conserver la copie vous-même.

Lors de la récupération d'une valeur de chaîne, la valeur est dupliquée avec gensio_strdup, vous devez la libérer avec o->free().

Data est comme les chaînes, sauf que la longueur est passée dans *intval* et est retournée de la même manière. Cela contiendra des données brutes arbitraires. Comme pour les chaînes, lorsque vous obtenez une valeur de type données, vous devez la libérer avec o->free().

S'il s'agit d'une énumération, lors de la définition de la valeur, vous passerez une chaîne et un tableau de valeurs possibles dans *enum* (terminé par un nom NULL). Le code recherchera la chaîne que vous passez dans le tableau des énumérations et définira la valeur à la valeur entière. Si la chaîne n'est pas dans le tableau des énumérations, il retournera *GE_INVAL*. Lorsque vous obtenez la valeur, elle sera retournée dans intval.

Lors de la récupération de la valeur, le type doit correspondre à ce qui est défini dans l'appel de définition. Si le nom n'est pas trouvé, *GE_NOTFOUND* est retourné. Si le type ne correspond pas, *GE_INVAL* est retourné. Notez que si vous enregistrez une valeur en tant qu'énumération, vous pouvez la récupérer en tant qu'entier.

Définir à nouveau la même valeur par défaut remplacera l'ancienne valeur.

gensio_del_default supprime la valeur par défaut donnée. Vous ne pouvez supprimer que les valeurs par défaut ajoutées par l'utilisateur, pas celles créées par la bibliothèque gensio. S'il existe des valeurs par défaut spécifiques à une classe enregistrées contre la valeur par défaut, cet appel échouera avec *GE_INUSE* sauf si *delclasses* est vrai, ce qui provoquera également la suppression de toutes les valeurs par défaut de classe.

gensio_reset_defaults réinitialisera toutes les valeurs par défaut à la valeur définie lors de l'appel de gensio_add_default pour créer la valeur par défaut, ou la valeur par défaut intégrée.

gesnio_get_defaultaddr récupère une adresse à partir de la chaîne de valeur par défaut donnée. Voir gensi_scan_network_port dans gensio/gensio.h pour les détails sur le format de la chaîne, la signification des paramètres et comment gérer la structure addrinfo.

VALEUR DE RETOUR

Zéro est retourné en cas de succès, ou une erreur gensio en cas d'échec.
