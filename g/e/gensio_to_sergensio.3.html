gensio_to_sergensio.3(3) Manuel des fonctions de bibliothèque gensio_to_sergensio.3(3)

NOM

gensio_to_sergensio, sergensio_to_gensio, sergensio_get_user_data, sergensio_is_client - Informations générales et routines de conversion pour un sergensio

SYNTAXE

#include <gensio/sergensio.h>

struct sergensio *gensio_to_sergensio(struct gensio *io);
struct gensio *sergensio_to_gensio(struct sergensio *serio);
void *sergensio_get_user_data(struct sergensio *serio);
bool sergensio_is_client(struct sergensio *serio);

DESCRIPTION

gensio_to_sergensio renvoie l'objet sergensio pour un gensio. Il renvoie NULL s'il n'y a pas de sergensio pour le gensio. Notez qu'il peut s'agir d'un objet sergensio pour un enfant du gensio passé. Si le gensio passé n'est pas un sergensio, il recherche parmi les enfants un gensio qui est également un sergensio. De cette façon, par exemple, si vous avez un gensio conacc fonctionnant sur un serialdev, et que vous recevez un événement série, vous pouvez simplement appeler gensio_to_sergensio pour l'objet passé et il vous donnera le sergensio avec lequel vous devriez travailler. La première fois que cette fonction est appelée sur un gensio, elle associe le sergensio au gensio passé.

sergensio_to_gensio renvoie le gensio pour un sergensio donné. Elle ne peut pas échouer. Notez que cela renvoie le gensio passé à gensio_to_sergensio et non le gensio directement associé au sergensio passé.

sergensio_get_user_data renvoie les données utilisateur du gensio associé.

sergensio_is_client renvoie true si le sergensio est un client ou false s'il s'agit d'un serveur.
