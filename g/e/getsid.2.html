getsid(2) Manuel des appels système getsid(2)

NOM

getsid - obtenir l'identifiant de session

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <unistd.h>
pid_t getsid(pid_t pid);
Exigences de macro de test de fonctionnalité pour glibc (voir feature_test_macros(7)) :

getsid() :

    _XOPEN_SOURCE >= 500
        || /* Depuis glibc 2.12 : */ _POSIX_C_SOURCE >= 200809L

DESCRIPTION

getsid() retourne l'identifiant de session du processus dont l'identifiant de processus est pid. Si pid est 0, getsid() retourne l'identifiant de session du processus appelant.

VALEUR DE RETOUR

En cas de succès, un identifiant de session est retourné. En cas d'erreur, (pid_t) -1 est retourné, et errno est défini pour indiquer l'erreur.

ERREURS

EPERM
Un processus avec l'identifiant de processus pid existe, mais il n'est pas dans la même session que le processus appelant, et l'implémentation considère cela comme une erreur.
ESRCH
Aucun processus avec l'identifiant de processus pid n'a été trouvé.

VERSIONS

Linux ne retourne pas EPERM.

NORMES

POSIX.1-2024.

HISTORIQUE

POSIX.1-2001, SVr4. Linux 2.0.

NOTES

Voir credentials(7) pour une description des sessions et des identifiants de session.

VOIR AUSSI

getpgid(2), setsid(2), credentials(7)
