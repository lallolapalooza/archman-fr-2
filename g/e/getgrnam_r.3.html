DESCRIPTIO

N

La fonction getgrnam() renvoie un pointeur vers une structure contenant les champs décomposés de l'enregistrement dans la base de données des groupes (par exemple, le fichier de groupes local /etc/group, NIS et LDAP) correspondant au nom de groupe name

.

La fonction getgrgid() renvoie un pointeur vers une structure contenant les champs décomposés de l'enregistrement dans la base de données des groupes correspondant à l'identifiant de groupe gid

.

La structure group est définie dans <grp.h> comme suit

: 


struct group {
    char   *gr_name;        /* nom du groupe */
    char   *gr_passwd;      /* mot de passe du groupe */
    gid_t   gr_gid;         /* identifiant de groupe */
    char  **gr_mem;         /* tableau de pointeurs terminé par NULL
                               vers les noms des membres du groupe */
}
;

Pour plus d'informations sur les champs de cette structure, voir group(

5).

Les fonctions getgrnam_r() et getgrgid_r() obtiennent les mêmes informations que getgrnam() et getgrgid(), mais stockent la structure group récupérée dans l'espace pointé par grp. Les champs de chaîne pointés par les membres de la structure group sont stockés dans le tampon buf de taille size. Un pointeur vers le résultat (en cas de succès) ou NULL (si aucune entrée n'a été trouvée ou en cas d'erreur) est stocké dans *result

.

on plus grand.)

VALEUR

RENVOYÉE

Les fonctions getgrnam() et getgrgid() renvoient un pointeur vers une structure group, ou NULL si l'entrée correspondante n'est pas trouvée ou si une erreur se produit. Si une erreur se produit, errno est défini pour indiquer l'erreur. Si l'on souhaite vérifier errno après l'appel, il devrait être mis à zéro avant

l'appel.

La valeur renvoyée peut pointer vers une zone statique et peut être écrasée par des appels ultérieurs à getgrent(3), getgrgid() ou getgrnam(). (Ne pas passer le pointeur renvoyé à free(3).

)

En cas de succès, getgrnam_r() et getgrgid_r() renvoient zéro et définissent *result sur grp. Si aucun enregistrement de groupe correspondant n'a été trouvé, ces fonctions renvoient 0 et stockent NULL dans *result. En cas d'erreur, un numéro d'erreur est renvoyé et NULL est stocké dans *res

VERSION

S

La formulation donnée ci-dessus sous « VALEUR RENVOYÉE » provient de POSIX.1. Elle n'appelle pas « non trouvé » une erreur et ne spécifie donc pas quelle valeur errno pourrait avoir dans cette situation. Mais cela rend impossible la reconnaissance des erreurs. On pourrait soutenir que selon POSIX errno devrait rester inchangé si une entrée n'est pas trouvée. Des expériences sur divers systèmes de type UNIX montrent que de nombre

uses valeurs différentes surviennent dans cette situation : 0, EN
OENT, EBADF, ESRCH, EWOULDBLOCK, EPERM, et probablement d'autres.
