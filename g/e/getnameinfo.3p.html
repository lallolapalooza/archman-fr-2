DESCRIPTIO

N

La fonction getnameinfo() doit traduire une adresse de socket en un nom de nœud et un emplacement de service, tous définis comme dans freeaddrinf

o().

L'argument sa pointe vers une structure d'adresse de socket à traduire. L'argument salen contient la longueur de l'adresse pointée par sa

.

Si la structure d'adresse de socket contient une adresse IPv6 mappée IPv4 ou une adresse IPv6 compatible IPv4, l'implémentation doit extraire l'adresse IPv4 embarquée et rechercher le nom de nœud pour cette adresse

IPv4.

Si l'adresse est l'adresse IPv6 non spécifiée ("::"), aucune recherche ne doit être effectuée et le comportement doit être le même que lorsque le nom du nœud ne peut pas être

localisé.

Si l'argument node est non NULL et que l'argument nodelen est non nul, alors l'argument node pointe vers un tampon pouvant contenir jusqu'à nodelen octets qui reçoit le nom du nœud sous forme de chaîne terminée par un octet nul. Si l'argument node est NULL ou que l'argument nodelen est nul, le nom du nœud ne doit pas être retourné. Si le nom du nœud ne peut pas être localisé, la forme numérique de l'adresse contenue dans la structure d'adresse de socket pointée par l'argument sa est retournée à la place de son

nom.

Si l'argument service est non NULL et que l'argument servicelen est non nul, alors l'argument service pointe vers un tampon pouvant contenir jusqu'à servicelen octets qui reçoit le nom du service sous forme de chaîne terminée par un octet nul. Si l'argument service est NULL ou que l'argument servicelen est nul, le nom du service ne doit pas être retourné. Si le nom du service ne peut pas être localisé, la forme numérique de l'adresse du service (par exemple, son numéro de port) doit être retournée à la place de son

nom.

L'argument flags est un drapeau qui modifie les actions par défaut de la fonction. Par défaut, le nom de domaine entièrement qualifié (FQDN) de l'hôte doit être retourné, mais

:
*
Si le bit de drapeau NI_NOFQDN est défini, seule la partie nom de nœud du FQDN doit être retournée pour les hôtes
locaux.
*
Si le bit de drapeau NI_NUMERICHOST est défini, la forme numérique de l'adresse contenue dans la structure d'adresse de socket pointée par l'argument sa doit être retournée à la place de son
nom.
*
Si le bit de drapeau NI_NAMEREQD est défini, une erreur doit être retournée si le nom de l'hôte ne peut pas être
localisé.
*
Si le bit de drapeau NI_NUMERICSERV est défini, la forme numérique de l'adresse du service doit être retournée (par exemple, son numéro de port) à la place de son
nom.
*
Si le bit de drapeau NI_NUMERICSCOPE est défini, la forme numérique de l'identifiant de portée doit être retournée (par exemple, l'index d'interface) à la place de son nom. Ce drapeau doit être ignoré si l'argument sa n'est pas une adresse
IPv6.
*
Si le bit de drapeau NI_DGRAM est défini, cela indique que le service
est un service de datagrammes (SOCK_DGRAM). Le comportement par défa
ut doit supposer que le service est un service de flux (SOCK_STREAM).

Une valeur de retour nulle pour getnameinfo() indique une exécution réussie ; une valeur de retour non nulle indique un échec. Les valeurs possibles pour les échecs sont listées dans la section

ERREURS.

retournés sont toujours des cha

APPLICATIONS

Si les valeurs retournées doivent être utilisées dans le cadre d'une résolution de nom ultérieure (par exemple, passées à getaddrinfo()), les applications doivent fournir des tampons suffisamment grands pour stocker tout résultat possible sur le

4".
