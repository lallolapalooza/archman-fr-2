getline(3) Manuel des fonctions de bibliothèque getline(3)

NOM

getline, getdelim - entrée de chaînes délimitées

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdio.h>
ssize_t getline(char **restrict lineptr, size_t *restrict n,
                FILE *restrict stream);
ssize_t getdelim(char **restrict lineptr, size_t *restrict n,
                int delim, FILE *restrict stream);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

getline(), getdelim():

    Depuis glibc 2.10:
        _POSIX_C_SOURCE >= 200809L
    Avant glibc 2.10:
        _GNU_SOURCE

DESCRIPTION

getline() lit une ligne entière à partir de stream, stockant l'adresse du tampon contenant le texte dans *lineptr. Le tampon est terminé par un caractère nul et inclut le caractère de fin de ligne, s'il a été trouvé.

Si *lineptr est défini à NULL avant l'appel, alors getline() allouera un tampon pour stocker la ligne. Ce tampon doit être libéré par le programme utilisateur même si getline() a échoué.

Alternativement, avant d'appeler getline(), *lineptr peut contenir un pointeur vers un tampon alloué par malloc(3) de *n octets de taille. Si le tampon n'est pas assez grand pour contenir la ligne, getline() le redimensionnera avec realloc(3), mettant à jour *lineptr et *n si nécessaire.

Dans les deux cas, lors d'un appel réussi, *lineptr et *n seront mis à jour pour refléter l'adresse du tampon et la taille allouée respectivement.

getdelim() fonctionne comme getline(), sauf qu'un délimiteur de ligne autre que la fin de ligne peut être spécifié comme argument delim. Comme avec getline(), un caractère délimiteur n'est pas ajouté s'il n'était pas présent dans l'entrée avant que la fin du fichier ne soit atteinte.

VALEUR DE RETOUR

En cas de succès, getline() et getdelim() retournent le nombre de caractères lus, y compris le caractère délimiteur, mais pas incluant l'octet nul de terminaison ('\0'). Cette valeur peut être utilisée pour gérer les octets nuls intégrés dans la ligne lue.

À la fin du fichier, les deux fonctions retournent -1 avec l'indicateur de fin de fichier du flux de fichier défini. En cas d'erreur, les deux fonctions retournent -1 avec l'indicateur d'erreur du flux de fichier défini, et errno est défini pour indiquer l'erreur.

Si *lineptr a été défini à NULL avant l'appel, alors le tampon doit être libéré par le programme utilisateur même en cas d'échec.

ERREURS

EINVAL
Arguments invalides (n ou lineptr est NULL, ou stream n'est pas valide).
ENOMEM
L'allocation ou la réallocation du tampon de ligne a échoué.

EXEMPLES

#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    FILE *stream;
    char *line = NULL;
    size_t size = 0;
    ssize_t nread;
    if (argc != 2) {
        fprintf(stderr, "Usage: %s <fichier>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    stream = fopen(argv[1], "r");
    if (stream == NULL) {
        perror("fopen");
        exit(EXIT_FAILURE);
    }
    while ((nread = getline(&line, &size, stream)) != -1) {
        printf("Ligne lue de longueur %zd:\n", nread);
        fwrite(line, nread, 1, stdout);
    }
    free(line);
    fclose(stream);
    exit(EXIT_SUCCESS);
}
