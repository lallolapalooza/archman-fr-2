NOM

genrb - compiler un paquet de ressources

SYNTAXE

genrb [ -h, -?, --help ] [ -V, --version ] [ -v, --verbose ] [ -e, --encoding encodage ] [ -j, --write-java [ encodage ] ] [ -s, --sourcedir source ] [ -d, --destdir destination ] [ -i, --icudatadir répertoire ] paquet ...

DESCRIPTION

genrb convertit les fichiers source de paquet de ressources (bundle) passés en ligne de commande dans leur forme binaire ou dans un fichier source Java pour utilisation avec ICU4J. Les fichiers binaires résultants ont une extension .res tandis que les fichiers source de paquets de ressources ont typiquement une extension .txt. Les fichiers source Java ont une extension java et suivent les conventions de nommage d'ICU4J.

Il est d'usage de nommer les paquets de ressources par leur nom de locale, c'est-à-dire d'utiliser un identifiant de locale pour le nom de fichier du paquet, par exemple ja_JP.txt pour les données Japonaises (Japon), ou root.txt pour le paquet racine. Dans tous les cas, genrb produira un fichier dont le nom de base est le nom de la locale trouvée dans le fichier de ressources, et non le nom de base du fichier de ressources lui-même.

Les fichiers binaires peuvent être lus directement par ICU, ou utilisés par pkgdata(1) pour être incorporés dans une archive ou une bibliothèque plus grande.

OPTIONS

-h, -?, --help
Affiche l'aide sur l'utilisation et quitte.
-V, --version
Affiche la version de genrb et quitte.
-v, --verbose
Affiche des messages d'information supplémentaires pendant l'exécution.
-e, --encoding encodage
Définit l'encodage utilisé pour lire les fichiers d'entrée à encodage. L'encodage par défaut est la page de codes invariante (sous-ensemble d'ASCII ou EBCDIC) du système (voir la section CARACTÈRES INVARIANTS). Les encodages UTF-8, UTF-16BE et UTF-16LE sont automatiquement détectés si une marque d'ordre des octets (BOM) est présente.
-j, --write-java [ encodage ]
Génère un code source Java pour utilisation avec ICU4J. Un encodage optionnel pour le fichier Java peut être donné.
-s, --sourcedir source
Définit le répertoire source à source. Le répertoire source par défaut est spécifié par la variable d'environnement ICU_DATA, ou l'emplacement défini lors de la compilation d'ICU si ICU_DATA n'est pas défini.
-d, --destdir destination
Définit le répertoire de destination à destination. Le répertoire de destination par défaut est spécifié par la variable d'environnement ICU_DATA ou est l'emplacement défini lors de la compilation d'ICU si ICU_DATA n'est pas défini.
-i, --icudatadir répertoire
Recherche tous les fichiers de données ICU nécessaires dans répertoire. Par exemple, lors du traitement des remplacements de collation, le fichier ucadata.dat doit être localisé. Le répertoire de données ICU par défaut est spécifié par la variable d'environnement ICU_DATA.

CARACTÈRES INVARIANTS

L'ensemble de caractères invariants comprend l'ensemble de caractères suivant, exprimé comme une expression régulière POSIX standard : [a-z]|[A-Z]|[0-9]|_| |+|-|*|/. C'est l'ensemble qui est garanti d'être disponible indépendamment de la page de codes.

ENVIRONNEMENT

ICU_DATA
Spécifie le répertoire contenant les données ICU. Par défaut ${prefix}/share/icu/78.1/. Certains outils dans ICU dépendent de la présence de la barre oblique finale. Il est donc important de s'assurer qu'elle est présente si ICU_DATA est défini.
