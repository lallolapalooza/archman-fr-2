PROLOG

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

getpgid — obtenir l'ID du groupe de processus pour un processus

SYNOPSIS

#include <unistd.h>
pid_t getpgid(pid_t pid);

DESCRIPTION

La fonction getpgid() renvoie l'ID du groupe de processus du processus dont l'ID de processus est égal à pid. Si pid est égal à 0, getpgid() renvoie l'ID du groupe de processus du processus appelant.

VALEUR RENVOYÉE

En cas de succès, getpgid() renvoie un ID de groupe de processus. Sinon, elle renvoie (pid_t)-1 et définit errno pour indiquer l'erreur.

ERREURS

La fonction getpgid() échoue si :

EPERM
Le processus dont l'ID de processus est égal à pid ne se trouve pas dans la même session que le processus appelant, et l'implémentation n'autorise pas l'accès à l'ID du groupe de processus de ce processus depuis le processus appelant.
ESRCH
Il n'existe aucun processus avec un ID de processus égal à pid.

La fonction getpgid() peut échouer si :

EINVAL
La valeur de l'argument pid est invalide.
