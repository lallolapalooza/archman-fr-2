DESCRIPTIO

N

La fonction getservent() lit l'entrée suivante de la base de données des services (voir services(5)) et renvoie une structure servent contenant les champs décomposés de l'entrée. Une connexion est ouverte à la base de données si

nécessaire.

La fonction getservbyname() renvoie une structure servent pour l'entrée de la base de données correspondant au service name en utilisant le protocole proto. Si proto est NULL, n'importe quel protocole sera accepté. Une connexion est ouverte à la base de données si

nécessaire.

La fonction getservbyport() renvoie une structure servent pour l'entrée de la base de données correspondant au port port (donné dans l'ordre des octets réseau) en utilisant le protocole proto. Si proto est NULL, n'importe quel protocole sera accepté. Une connexion est ouverte à la base de données si

nécessaire.

La fonction setservent() ouvre une connexion à la base de données et définit l'entrée suivante comme la première entrée. Si stayopen est non nul, la connexion à la base de données ne sera pas fermée entre les appels à l'une des fonctions getserv*()

.

La fonction endservent() ferme la connexion à la base de

données.

La structure servent est définie dans <netdb.h> comme suit

: 


struct servent {
    char  *s_name;       /* official service name */
    char **s_aliases;    /* alias list */
    int    s_port;       /* port number */
    char  *s_proto;      /* protocol to use */
}
