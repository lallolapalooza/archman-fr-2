getloadavg(3) Manuel des fonctions de bibliothèque getloadavg(3)

NOM

getloadavg - obtenir les moyennes de charge système

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <stdlib.h>
int getloadavg(double loadavg[], int n);
Exigences concernant les macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

getloadavg():

    Depuis glibc 2.19 :
        _DEFAULT_SOURCE
    Dans glibc jusqu'à et y compris 2.19 :
        _BSD_SOURCE

DESCRIPTION

La fonction getloadavg() renvoie le nombre de processus dans la file d'attente d'exécution du système, moyenné sur différentes périodes. Jusqu'à n échantillons sont récupérés et assignés aux éléments successifs de loadavg[]. Le système impose un maximum de 3 échantillons, représentant les moyennes sur les 1, 5 et 15 dernières minutes, respectivement.

VALEUR DE RETOUR

Si la moyenne de charge n'a pas pu être obtenue, -1 est retourné ; sinon, le nombre d'échantillons réellement récupérés est retourné.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
getloadavg () Thread safety MT-Safe

NORMES

BSD.

HISTORIQUE

4.3BSD-Reno, Solaris. glibc 2.2.

VOIR AUSSI

uptime(1), proc(5)
