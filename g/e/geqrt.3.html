sous-routine cgeqrt (integer m, integer n, integer nb, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( * ) work, integer info)

CGEQRT

But:

!>
!> CGEQRT calcule une factorisation QR bloquée d'une matrice complexe M par N, A,
!> en utilisant la représentation WY compacte de Q.
!>

Paramètres

M 
!>          M est un INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!>

N

!>          N est un INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

NB

!>          NB est un INTEGER
!>          La taille du bloc à utiliser dans la QR bloquée.  MIN(M,N) >= NB >= 1.
!>

A

!>          A est un tableau COMPLEX, de dimension (LDA,N)
!>          À l'entrée, la matrice A de M par N.
!>          À la sortie, les éléments sur et au-dessus de la diagonale du tableau
!>          contiennent la matrice trapézoïdale supérieure de R de taille min(M,N)-par-N (R est
!>          triangulaire supérieure si M >= N) ; les éléments sous la diagonale
!>          sont les colonnes de V.
!>

LDA

!>          LDA est un INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

T

!>          T est un tableau COMPLEX, de dimension (LDT,MIN(M,N))
!>          Les réflecteurs de bloc triangulaires supérieurs stockés sous forme compacte
!>          en tant que séquence de blocs triangulaires supérieurs. Voir ci-dessous
!>          pour plus de détails.
!>

LDT

!>          LDT est un INTEGER
!>          La dimension principale du tableau T.  LDT >= NB.
!>

WORK

!>          WORK est un tableau COMPLEX, de dimension (NB*N)
!>

INFO

!>          INFO est un INTEGER
!>          = 0 :  sortie réussie
!>          < 0 :  si INFO = -i, le i-ème argument avait une valeur illégale
!>

Auteur

Univ. du Tennessee

Univ. de Californie à Berkeley

Univ. du Colorado à Denver

NAG Ltd.

Détails supplémentaires:

!>
!>  La matrice V stocke les réflecteurs élémentaires H(i) dans la i-ème colonne
!>  sous la diagonale. Par exemple, si M=5 et N=3, la matrice V est
!>
!>               V = (  1       )
!>                   ( v1  1    )
!>                   ( v1 v2  1 )
!>                   ( v1 v2 v3 )
!>                   ( v1 v2 v3 )
!>
!>  où les vi représentent les vecteurs qui définissent H(i), qui sont retournés
!>  dans la matrice A. Les 1 le long de la diagonale de V ne sont pas stockés dans A.
!>
!>  Soit K=MIN(M,N). Le nombre de blocs est B = ceiling(K/NB), où chaque
!>  bloc est d'ordre NB sauf le dernier bloc, qui est d'ordre
!>  IB = K - (B-1)*NB. Pour chacun des B blocs, un facteur de réflecteur de bloc
!>  triangulaire supérieur est calculé : T1, T2, ..., TB. Les T de NB-par-NB
!>  (et IB-par-IB pour le dernier bloc) sont stockés dans la matrice T de NB-par-K comme
!>
!>               T = (T1 T2 ... TB).
!>
