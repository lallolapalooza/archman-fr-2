Lier avec -lgearman

DESCRIPTION

gearman_execute() est utilisé pour créer une nouvelle gearman_task_st qui est exécutée par rapport à la fonction trouvée via l'argument function_name.

gearman_work_t peut être utilisé pour décrire le travail qui sera exécuté, il est construit avec gearman_argument_make(). L'argument unique_str est optionnel, mais s'il est fourni, il est utilisé pour la coalescence par gearmand.

gearman_argument_t est le travail que le client enverra au serveur

Si gearman_execute() reçoit un gearman_work_t construit avec un réducteur, il prend le gearman_argument_t et l'exécute par rapport à une function comme il le ferait normalement, mais il indique à la fonction de traiter ensuite les résultats via une fonction reducer avec laquelle le gearman_work_t a été créé.

Ce qui se passe, c'est que la fonction mappe/divise le travail en unités, puis envoie chacune d'elles à la fonction réductrice. Une fois que tout le travail est terminé, la fonction mapper agrège le travail via une fonction agrégatrice, gearman_aggregator_fn, et renvoie un résultat.

Si l'une des unités de travail échoue, la tâche sera abandonnée. La valeur résultante sera stockée dans la gearman_task_st.

Le résultat peut être obtenu à partir de la tâche en appelant gearman_task_result() pour obtenir la gearman_result_st.

VALEUR RENVOYÉE

gearman_execute() renvoie une c:type:gearman_task_st.

EXEMPLE

/*
  Exemple de code pour montrer comment envoyer une chaîne à une fonction appelée "reverse" et imprimer les résultats.
*/
/*
# Serveur et bibliothèque Gearman
# Copyright (C) 2012 Data Differential, http://datadifferential.com/
# Tous droits réservés.
#
# Utilisation et distribution autorisées sous la licence BSD. Voir
# le fichier COPYING dans ce répertoire pour le texte intégral.
*/
#include <string.h>
#include <stdlib.h>
#include <stdio.h>
#include <libgearman/gearman.h>
int main(void)
{
  gearman_client_st *client= gearman_client_create(NULL);
  gearman_return_t ret= gearman_client_add_server(client, "localhost", 0);
  if (gearman_failed(ret))
  {
    return EXIT_FAILURE;
  }
  gearman_argument_t value= gearman_argument_make(0, 0, "Reverse Me", strlen("Reverse Me"));
  gearman_task_st *task= gearman_execute(client,
                                         "reverse", strlen("reverse"),  // fonction
                                         NULL, 0,  // aucune valeur unique fournie
                                         NULL,
                                         &value, 0);
  if (task == NULL) // Si gearman_execute() peut renvoyer NULL en cas d'erreur
  {
    fprintf(stderr, "Erreur : %s\n", gearman_client_error(client));
    gearman_client_free(client);
    return EXIT_FAILURE;
  }
  // S'assurer que la tâche a été exécutée avec succès
  if (gearman_success(gearman_task_return(task)))
  {
    // Utiliser la valeur
    gearman_result_st *result= gearman_task_result(task);
    printf("%.*s\n", (int)gearman_result_size(result), gearman_result_value(result));
  }
  gearman_client_free(client);
  return EXIT_SUCCESS;
}
