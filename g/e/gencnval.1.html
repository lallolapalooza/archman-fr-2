NOM

gencnval - compile le fichier d'alias des convertisseurs

SYNTAXE

gencnval [ -h, -?, --help ] [ -v, --verbose ] [ -c, --copyright ] [ -s, --sourcedir source ] [ -d, --destdir destination ] [ fichier_convertisseur ]

DESCRIPTION

gencnval convertit le fichier d'alias ICU fichier_convertisseur en fichier binaire cnvalias.icu. Ce fichier binaire peut ensuite être lu directement par ICU, ou utilisé par pkgdata(1) pour être incorporé dans une archive ou une bibliothèque plus grande.

Si fichier_convertisseur n'est pas fourni, le fichier ICU par défaut convrtrs.txt est utilisé.

OPTIONS

-h, -?, --help
Affiche l'aide sur l'utilisation et quitte.
-v, --verbose
Affiche une sortie détaillée. Ces informations peuvent inclure des détails sur les alias conflictuels et les convertisseurs vers lesquels les alias mènent.
-c, --copyright
Inclut une notice de copyright dans les données binaires.
-s, --sourcedir source
Définit le répertoire source sur source. Le répertoire source par défaut est spécifié par la variable d'environnement ICU_DATA.
-d, --destdir destination
Définit le répertoire de destination sur destination. Le répertoire de destination par défaut est spécifié par la variable d'environnement ICU_DATA.

ENVIRONNEMENT

ICU_DATA
Spécifie le répertoire contenant les données ICU. Par défaut, il s'agit de ${prefix}/share/icu/78.1/. Certains outils dans ICU dépendent de la présence de la barre oblique finale. Il est donc important de s'assurer qu'elle est présente si ICU_DATA est défini.

FICHIERS

icu/source/data/mappings/convrtrs.txt
Description des convertisseurs ICU et de leurs alias. Ce fichier de données n'est normalement pas installé et est disponible dans le code source d'ICU.
