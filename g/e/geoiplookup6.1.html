GEOIPLOOKUP6(1) Manuel des commandes générales GEOIPLOOKUP6(1)

NOM

geoiplookup6 - rechercher le pays à l'aide d'une adresse IP ou d'un nom d'hôte

SYNTAXE

geouplookup6 [-d répertoire] [-f fichier] [-v] <adresseip|nomhôte>

DESCRIPTION

geouplookup6 utilise la bibliothèque et la base de données GeoIP pour trouver le Pays d'origine d'une adresse IP ou d'un nom d'hôte. Vous devez installer une base de données adaptée à geoiplookup6. Par exemple : GeoIPv6.dat

Par exemple :

geouplookup6 2001:4860:0:1001::68

geoiplookup6 ipv6.google.com

trouveront le pays d'origine de 2001:4860:0:1001::68, dans le format suivant :

US, États-Unis

OPTIONS

-f
Spécifie un chemin personnalisé vers un seul fichier de données GeoIP.
-d
Spécifie un répertoire personnalisé contenant des fichiers de données GeoIP. Par défaut, geouplookup6 recherche dans /usr/share/GeoIP
-v
Affiche la date et le numéro de build des fichiers de données GeoIP.
