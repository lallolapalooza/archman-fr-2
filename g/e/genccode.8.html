NOM

genccode - génère du code C ou assembleur spécifique à la plateforme à partir d'un fichier de données ICU.

SYNOPIS

genccode [ -h, -?, --help ] [ -a, --assembly nom ] [ -d, --destdir destination ] [ -n, --name nom ] [ -e, --entrypoint nom ] [ -f, --filename nom ] [ fichier ... ]

DESCRIPTION

genccode lit chaque fichier fourni et écrit un fichier C contenant une définition compilable des données du fichier de données. Le nom du fichier C est obtenu en prenant le nom de base du fichier de données, en remplaçant les points par des underscores, et en ajoutant une extension de fichier .c.

Si l'option -a est utilisée, du code assembleur spécifique à la plateforme est généré à la place du code C. La plupart des compilateurs C acceptent les fichiers C et les fichiers assembleur. Au lieu d'écrire un nom de fichier avec une extension .c, un nom de fichier avec une extension .s sera écrit.

Si genccode est appelé sans fichier, il se termine gracieusement.

OPTIONS

-h, -?, --help
Imprime l'aide sur l'utilisation et quitte.
-a, --assembly nom
Produit du code assembleur au lieu du code C. Utilisez -h pour voir la liste des types d'assembleur disponibles à générer et à spécifier pour cette option.
-d, --destdir destination
Définit le répertoire de destination à destination. Le répertoire de destination par défaut est le répertoire courant.
-n, --name nom
Définit le nom des données à nom au lieu de la valeur par défaut. Ce nom est également utilisé comme nom de base pour la sortie. Le nom par défaut est constitué du préfixe icudt, suivi d'un numéro de version à deux chiffres correspondant à la version actuelle de la sortie ICU, et d'une seule lettre indiquant l'endianness des données (la lettre b indique des données big endian, et la lettre l indique des données little endian).
-f, --filename nom
Normalement, un fichier de données ICU tel que mydata.icu sera transformé en mydata_icu.c et mydata_icu.o. Cependant, si ce paramètre était défini sur "somedata", les fichiers de sortie seront respectivement somedata.o et somedata.c.
-e, --entrypoint nom
Définit le point d'entrée des données (utilisé pour lier les données sous forme de bibliothèque partagée) à nom. Le nom du point d'entrée par défaut est constitué des données (définies par l'option -n, --name) suivi d'un underscore et du type des données (défini par l'option -t, --type).
