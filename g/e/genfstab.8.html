NOM

genfstab - génère une sortie adaptée pour être ajoutée à un fichier fstab

SYNTAXE

genfstab [options] root

DESCRIPTION

genfstab aide à remplir un fichier fstab en détectant automatiquement tous les montages actuels sous un point de montage donné et en les imprimant dans un format compatible fstab vers la sortie standard. Il peut être utilisé pour persister une hiérarchie de systèmes de fichiers montée manuellement et est souvent utilisé lors de l'installation et de la configuration initiales d'un OS.

OPTIONS

-f <filtre>

Restreint la sortie aux points de montage correspondant au préfixe filtre.

-L

Utilise les labels pour les identifiants source (raccourci pour -t LABEL).

-p

Exclut les montages pseudofs (comportement par défaut).

-P

Inclut les montages pseudofs.

-t <tag>

Utilise tag pour les identifiants source (doit être l'un de : LABEL, UUID, PARTLABEL, PARTUUID).

-U

Utilise les UUID pour les identifiants source (raccourci pour -t UUID).

-h

Syntaxe de sortie et options de ligne de commande.
