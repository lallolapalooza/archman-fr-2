NOM

getdnskeys - Gère les listes de DNSKEYs à partir de zones DNS

SYNTAXE

getdnskeys [-i fichier] [-o fichier] [-k] [-T] [-t] [-v] [zones]

DESCRIPTION

getdnskeys gère les listes de DNSKEYs à partir de zones DNS. Il peut être utilisé pour récupérer et comparer des DNSKEYs. La sortie de getdnskeys peut être incluse (directement ou indirectement) dans un fichier named.conf.

OPTIONS

getdnskeys accepte les options suivantes :

-i chemin
Lit chemin comme un fichier named.conf avec lequel comparer les listes de clés.
-k
Ne recherche que les clés de signature de clés (KSK); toutes les autres clés sont ignorées.
-o fichier
Écrit les résultats dans fichier.
-T
Vérifie la liste actuelle des clés de confiance de named.conf.
-t
Encadre la sortie dans les marqueurs de syntaxe named.conf nécessaires.
-v
Active le mode verbeux pour une sortie supplémentaire.
-Version
Affiche les informations de version pour getdnskeys et le paquet DNSSEC-Tools.
-h
Donne un message d'aide.

EXEMPLES

Ce getdnskeys récupérera la KSK pour example.com :

getdnskeys -o /etc/named.trustkeys.conf -k -v -t example.com

Ce getdnskeys vérifiera les clés enregistrées par rapport à un ensemble de clés actif :

getdnskeys -i /etc/named.trustkeys.conf -T -k -v -t

Ce getdnskeys mettra automatiquement à jour un ensemble de clés enregistrées :

getdnskeys -i /etc/named.trustkeys.conf -k -t -T -v
           -o /etc/named.trustkeys.conf

PROBLEMES DE SECURITE

Actuellement, cela ne valide pas les nouvelles clés placées dans le fichier de quelque manière que ce soit, ni ne valide les changements sur les clés qui ont été ajoutées.

Il ne gère pas non plus la révocation des clés.

Il devrait vous demander avant d'ajouter une nouvelle clé afin que vous puissiez toujours utiliser la fonction de mise à jour automatique.
