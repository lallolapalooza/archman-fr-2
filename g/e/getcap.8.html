NOM

getcap - examiner les capacités de fichier

SYNTAXE

getcap [-v] [-n] [-r] [-h] nom_fichier [ ... ]

DESCRIPTION

getcap affiche le nom et les capacités de chaque fichier spécifié.

OPTIONS

-h
affiche une aide rapide.
-n
affiche toute valeur d'ID utilisateur non nulle de l'espace de noms utilisateur trouvée associée aux capacités d'un fichier.
-r
active la recherche récursive.
-v
affiche toutes les entrées recherchées, même si elles n'ont pas de capacités de fichier.

NOTE : une valeur vide de '=' n'est pas équivalente à une capacité omise (ou supprimée) sur un fichier. C'est particulièrement significatif en ce qui concerne le vecteur de capacité ambiante, car un processus ayant des capacités ambiantes les perdra lors de l'exécution d'un fichier ayant des capacités '=', mais conservera l'héritage ambiant de privilèges lors de l'exécution d'un fichier avec une capacité de fichier omise. Ce réglage spécial vide peut être utilisé pour empêcher un binaire de s'exécuter avec des privilèges. Pendant un certain temps, le noyau a honoré cette suppression pour root exécutant le fichier, mais les développeurs du noyau ont décidé après plusieurs années que ce comportement était inattendu pour le superutilisateur et l'ont annulé uniquement pour cette identité utilisateur. La suppression des privilèges root, pour une arborescence de processus, est possible en utilisant l'option --mode de capsh(1).

nom_fichier
Un fichier par ligne.
