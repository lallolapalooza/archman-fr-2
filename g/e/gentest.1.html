GENTEST(1) Suite de tests GENTEST(1)

NOM

gentest - Exécute des opérations SMB génériques aléatoires contre deux serveurs SMB et montre les différences de comportement

SYNTAXE

gentest {//serveur1/partage1} {//serveur2/partage2} {-U utilisateur%motdepasse} {-U utilisateur%motdepasse} [-s graine] [-o nbops] [-a] [-A] [-i FICHIER] [-O] [-S FICHIER] [-L] [-F] [-C] [-X]

DESCRIPTION

gentest est un utilitaire pour détecter des différences de comportement entre serveurs SMB. Il exécutera un ensemble aléatoire d'opérations génériques contre //serveur1/partage1 puis le même ensemble aléatoire contre //serveur2/partage2 et affichera les différences dans les réponses obtenues.

Cet utilitaire est utilisé par l'équipe Samba pour trouver des différences de comportement entre les serveurs Samba et Windows.

OPTIONS

-U utilisateur%motdepasse

Spécifiez l'utilisateur et le mot de passe à utiliser lors de la connexion aux partages. Ce paramètre est obligatoire et doit être spécifié deux fois.

-s graine

Initialise le générateur de nombres aléatoires avec la valeur spécifiée.

-o nbops

Définit le nombre d'opérations à effectuer.

-a

Affiche les opérations effectuées.

-A

Retourne en arrière pour trouver le nombre minimal d'opérations requises pour que la réponse à un appel donné diffère.

-i FICHIER

Spécifiez un fichier contenant les noms des champs à ignorer (tels que les champs de date/heure). Voir ci-dessous pour une description du format de fichier.

-O

Active les oplocks.

-S FICHIER

Définit un fichier de graines prédéfinies. Par défaut, il s'agit de gentest_seeds.dat.

-L

Utilise des graines prédéfinies.

-F

Reconnexion rapide (ferme juste les fichiers).

-C

Mode d'analyse continue.

-X

Analyse même lorsque le test a réussi.

VERSION

Cette page de manuel est correcte pour la version 4.0 de la suite Samba.
