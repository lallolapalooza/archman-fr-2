DESCRIPTIO

N

Les fonctions getgrent_r() et fgetgrent_r() sont les versions réentrantes de getgrent(3) et fgetgrent(3). La première lit l'entrée de groupe suivante depuis le flux initialisé par setgrent(3). La seconde lit l'entrée de groupe suivante depuis stream

.

La structure group est définie dans <grp.h> comme suit

: 


struct group {
    char   *gr_name;        /* nom du groupe */
    char   *gr_passwd;      /* mot de passe du groupe */
    gid_t   gr_gid;         /* identifiant du groupe */
    char  **gr_mem;         /* tableau de pointeurs terminé par NULL
                               vers les noms des membres du groupe */
}
;

Pour plus d'informations sur les champs de cette structure, voir group(

5).

Les fonctions non réentrantes renvoient un pointeur vers un stockage statique, où ce stockage statique contient d'autres pointeurs vers le nom du groupe, le mot de passe et les membres. Les fonctions réentrantes décrites ici renvoient tout cela dans des tampons fournis par l'appelant. Tout d'abord, il y a le tampon gbuf qui peut contenir une struct group. Et ensuite le tampon buf de taille size qui peut contenir des chaînes supplémentaires. Le résultat de ces fonctions, la struct group lue depuis le flux, est stocké dans le tampon fourni *gbuf, et un pointeur vers cette struct group est renvoyé dans *gbu

f
p.

EXEMPLE

S 
#define _GNU_SOURCE
#include <grp.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#define BUFLEN 4096
int
main(void)
{
    struct group grp;
    struct group *grpp;
    char buf[BUFLEN];
    int i;
    setgrent();
    while (1) {
        i = getgrent_r(&grp, buf, sizeof(buf), &grpp);
        if (i)
            break;
        printf("%s (%jd):", grpp->gr_name, (intmax_t) grpp->gr_gid);
        for (size_t j = 0; ; j++) {
            if (grpp->gr_mem[j] == NULL)
                break;
            printf(" %s", grpp->gr_mem[j]);
        }
        printf("\n");
    }
    endgrent();
    exit(EXIT_SUCCESS);
}
