DESCRIPTION

Callbacks pour les états des tâches d'exécution du client.

gearman_client_set_data_fn() définit la fonction de rappel qui sera appelée si le serveur doit demander au client de fournir des données supplémentaires.

gearman_client_do_job_handle() récupère le handle de tâche pour la tâche en cours. Ceci doit être utilisé entre les appels répétés à gearman_client_do() (et les fonctions associées) pour obtenir des informations.

gearman_client_clear_fn() peut être appelé pour supprimer toutes les gearman_actions_t existantes qui ont été définies.

gearman_client_set_created_fn(), gearman_client_set_data_fn(), gearman_client_set_warning_fn(), gearman_client_set_status_fn(), gearman_client_set_complete_fn(), gearman_client_set_exception_fn(), et gearman_client_set_fail_fn(), définissent des fonctions de rappel pour les différents états d'exécution d'une requête client. Chaque requête, c'est-à-dire la création d'une gearman_task_st, conserve une copie des rappels lorsqu'elle est créée.

gearman_client_set_exception_fn() ne sera appelé que si les exceptions sont activées sur le serveur. Vous pouvez le faire en appelant gearman_client_set_server_option().

Un exemple de ceci :

const char *EXCEPTIONS="exceptions";
gearman_client_set_server_option(client, EXCEPTIONS, strlen(EXCEPTIONS));
