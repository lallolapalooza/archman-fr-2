getfsent(3) Manuel des fonctions de bibliothèque getfsent(3)

NOM

getfsent, getfsspec, getfsfile, setfsent, endfsent - gérer les entrées fstab

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <fstab.h>
int setfsent(void);
struct fstab *getfsent(void);
void endfsent(void);
struct fstab *getfsfile(const char *mount_point);
struct fstab *getfsspec(const char *special_file);

DESCRIPTION

Ces fonctions lisent le fichier /etc/fstab. La struct fstab est définie par :


struct fstab {
    char       *fs_spec;       /* nom du périphérique bloc */
    char       *fs_file;       /* point de montage */
    char       *fs_vfstype;    /* type de système de fichiers */
    char       *fs_mntops;     /* options de montage */
    const char *fs_type;       /* option rw/rq/ro/sw/xx */
    int         fs_freq;       /* fréquence de vidage, en jours */
    int         fs_passno;     /* numéro de passage sur vidage parallèle */
};

Ici, le champ fs_type contient (sur un système *BSD) l'une des cinq chaînes « rw », « rq », « ro », « sw », « xx » (lecture-écriture, lecture-écriture avec quotas, lecture seule, swap, ignorer).

La fonction setfsent() ouvre le fichier si nécessaire et le positionne sur la première ligne.

La fonction getfsent() analyse la ligne suivante du fichier. (Après l'avoir ouvert si nécessaire.)

La fonction endfsent() ferme le fichier si nécessaire.

La fonction getfsspec() recherche le fichier depuis le début et renvoie la première entrée trouvée pour laquelle le champ fs_spec correspond à l'argument special_file.

La fonction getfsfile() recherche le fichier depuis le début et renvoie la première entrée trouvée pour laquelle le champ fs_file correspond à l'argument mount_point.

VALEUR DE RETOUR

En cas de succès, les fonctions getfsent(), getfsfile() et getfsspec() renvoient un pointeur vers une struct fstab, tandis que setfsent() renvoie 1. En cas d'échec ou de fin de fichier, ces fonctions renvoient NULL et 0 respectivement.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
endfsent (), setfsent () Sécurité des threads MT-Unsafe race:fsent
getfsent (), getfsspec (), getfsfile () Sécurité des threads MT-Unsafe race:fsent locale

VERSIONS

Plusieurs systèmes d'exploitation disposent de ces fonctions, par exemple, *BSD, SunOS, Digital UNIX, AIX (qui a également une fonction getfstype()). HP-UX a des fonctions des mêmes noms, qui utilisent cependant une struct checklist au lieu d'une struct fstab, et considère ces fonctions comme obsolètes, remplacées par getmntent(3).

NORMES

Aucune.

HISTORIQUE

La fonction getfsent() est apparue dans 4.0BSD ; les quatre autres fonctions sont apparues dans 4.3BSD.

NOTES

Ces fonctions ne sont pas thread-safe.

Comme Linux permet de monter un périphérique spécial bloc à plusieurs endroits, et comme plusieurs périphériques peuvent avoir le même point de montage, où le dernier périphérique avec un point de montage donné est le plus intéressant, tandis que getfsfile() et getfsspec() ne renvoient que la première occurrence, ces deux fonctions ne conviennent pas à une utilisation sous Linux.

VOIR AUSSI

getmntent(3), fstab(5)
