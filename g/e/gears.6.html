gears(6) Manuel XScreenSaver gears(6)

NOM

gears - dessine des engrenages imbriqués, pour xscreensaver.

SYNTAXE

gears [--display hôte:écran.numéro] [--window] [--root] [--window-id numéro][--install] [--visual visuel] [--delay usecs] [--speed float] [--no-spin] [--no-wander] [-count entier] [-wireframe] [-fps]

DESCRIPTION

Dessine un ensemble d'engrenages rotatifs.

OPTIONS

gears accepte les options suivantes :

--window
Dessiner sur une nouvelle fenêtre. C'est le comportement par défaut.
--root
Dessiner sur la fenêtre racine.
--window-id numéro
Dessiner sur la fenêtre spécifiée.
--install
Installer une carte de couleurs privée pour la fenêtre.
--visual visuel
Spécifie quel visuel utiliser. Les valeurs légales sont le nom d'une classe visuelle, ou le numéro d'identifiant (décimal ou hexadécimal) d'un visuel spécifique.
--delay usecs
Le délai entre chaque image de l'animation, en microsecondes. Par défaut : 30000 (0.03 secondes).
--speed float
Des nombres plus grands signifient une exécution plus rapide. Par défaut : 1.0.
--no-spin
Ne pas faire tourner l'objet.
--no-wander
Ne pas faire errer l'objet sur l'écran.
--count entier
Combien d'engrenages dessiner. Par défaut : 0 pour aléatoire.
--wireframe
Rendu en fil de fer au lieu de solide.
--fps
Afficher le taux d'images par seconde actuel, la charge CPU et le nombre de polygones.

ENVIRONNEMENT

DISPLAY
pour obtenir l'hôte et le numéro d'écran par défaut.
XENVIRONMENT
pour obtenir le nom d'un fichier de ressources qui remplace les ressources globales stockées dans la propriété RESOURCE_MANAGER.
XSCREENSAVER_WINDOW
L'identifiant de la fenêtre à utiliser avec --root.

VOIR AUSSI

X(1), xscreensaver(1)
