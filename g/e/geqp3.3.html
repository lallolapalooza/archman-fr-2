CGEQP3

But :

!>
!> CGEQP3 calcule une factorisation QR avec pivotement de colonnes d'une
!> matrice A :  A*P = Q*R  en utilisant des BLAS de niveau 3.
!>

Paramètres

M 
!>          M est un INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est un INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX de dimension (LDA,N)
!>          À l'entrée, la matrice M-par-N A.
!>          À la sortie, le triangle supérieur du tableau contient la
!>          matrice trapézoïdale supérieure R de dimensions min(M,N)-par-N ; les éléments sous
!>          la diagonale, ainsi que le tableau TAU, représentent la
!>          matrice unitaire Q comme un produit de min(M,N) réflecteurs
!>          élémentaires.
!>

LDA

!>          LDA est un INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

JPVT

!>          JPVT est un tableau INTEGER de dimension (N)
!>          À l'entrée, si JPVT(J).ne.0, la colonne J de A est permutée
!>          au début de A*P (une colonne de tête) ; si JPVT(J)=0,
!>          la colonne J de A est une colonne libre.
!>          À la sortie, si JPVT(J)=K, alors la colonne J de A*P était la
!>          la colonne K de A.
!>

TAU

!>          TAU est un tableau COMPLEX de dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires.
!>

WORK

!>          WORK est un tableau COMPLEX de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO=0, WORK(1) contient la valeur optimale de LWORK.
!>

LWORK

!>          LWORK est un INTEGER
!>          La dimension du tableau WORK. LWORK >= N+1.
!>          Pour des performances optimales, LWORK >= ( N+1 )*NB, où NB
!>          est la taille de bloc optimale.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message d'erreur
!>          relatif à LWORK n'est émis par XERBLA.
!>

RWORK

!>          RWORK est un tableau REAL de dimension (2*N)
!>

INFO

!>          INFO est un INTEGER
!>          = 0 : sortie réussie.
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>

Auteur

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Détails supplémentaires :

!>
!>  La matrice Q est représentée comme un produit de réflecteurs élémentaires
!>
!>     Q = H(1) H(2) . . . H(k), où k = min(m,n).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**H
!>
!>  où tau est un scalaire complexe, et v est un vecteur réel/complexe
!>  avec v(1:i-1) = 0 et v(i) = 1 ; v(i+1:m) est stocké à la sortie dans
!>  A(i+1:m,i), et tau dans TAU(i).
!>

geqp3(3)

LAPACK routine (version 3.12.0)

NAME

geqp3 - compute a preliminary QR factorization of a matrix with column pivoting

SYNOPSIS

call sgeqp3(m, n, a, lda, jpvt, tau, work, lwork, info)
call dgeqp3(m, n, a, lda, jpvt, tau, work, lwork, info)
call cgeqp3(m, n, a, lda, jpvt, tau, work, lwork, rwork, info)
call zgeqp3(m, n, a, lda, jpvt, tau, work, lwork, rwork, info)

Detailed Description

The routines compute a preliminary QR factorization of a matrix A with column pivoting. That is,:

 A*P = Q*R

where P is a permutation matrix, Q is an orthogonal matrix, and R is upper trapezoidal.

This routine is called by the LAPACK routines, and not is not expected to be passed by the user directly.

Function Documentation

subroutine dgeqp3 (integer m, integer n, double precision, dimension( lda, * ) a, integer lda, integer, dimension( * ) jpvt, double precision, dimension( * ) tau, double precision, dimension( * ) work, integer lwork, integer info)

DGEQP3

Purpose:

!>
!> DGEQP3 computes a QR factorization with column pivoting of a
!> matrix A:  A*P = Q*R  using Level 3 BLAS.
!>

Parameters

M 
!>          M is INTEGER
!>          The number of rows of the matrix A. M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix A.  N >= 0.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          On entry, the M-by-N matrix A.
!>          On exit, the upper triangle of the array contains the
!>          min(M,N)-by-N upper trapezoidal matrix R; the elements below
!>          the diagonal, together with the array TAU, represent the
!>          orthogonal matrix Q as a product of min(M,N) elementary
!>          reflectors.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,M).
!>

JPVT

!>          JPVT is INTEGER array, dimension (N)
!>          On entry, if JPVT(J).ne.0, the J-th column of A is permuted
!>          to the front of A*P (a leading column); if JPVT(J)=0,
!>          the J-th column of A is a free column.
!>          On exit, if JPVT(J)=K, then the J-th column of A*P was the
!>          the K-th column of A.
!>

TAU

!>          TAU is DOUBLE PRECISION array, dimension (min(M,N))
!>          The scalar factors of the elementary reflectors.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK))
!>          On exit, if INFO=0, WORK(1) returns the optimal LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= 3*N+1.
!>          For optimal performance LWORK >= 2*N+( N+1 )*NB, where NB
!>          is the optimal blocksize.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit.
!>          < 0: if INFO = -i, the i-th argument had an illegal value.
!>

Author

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Further Details:

!>
!>  The matrix Q is represented as a product of elementary reflectors
!>
!>     Q = H(1) H(2) . . . H(k), where k = min(m,n).
!>
!>  Each H(i) has the form
!>
!>     H(i) = I - tau * v * v**T
!>
!>  where tau is a real scalar, and v is a real/complex vector
!>  with v(1:i-1) = 0 and v(i) = 1; v(i+1:m) is stored on exit in
!>  A(i+1:m,i), and tau in TAU(i).
!>

Contributors:

G. Quintana-Orti, Depto. de Informatica, Universidad Jaime I, Spain X. Sun, Computer Science Dept., Duke University, USA
