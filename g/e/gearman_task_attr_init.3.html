NOM

gearman_task_attr_init - Documentation Gearmand, https://gearman.org/gearmand/

SYNOPSIS

#include <libgearman/gearman.h>

type gearman_work_t
type gearman_job_priority_t
gearman_work_t gearman_work(gearman_job_priority_t priority)
gearman_work_t gearman_work_epoch(time_t epoch, gearman_job_priority_t priority)
gearman_work_t gearman_work_background(gearman_job_priority_t priority)

Compiler et lier avec -lgearman

DESCRIPTION

gearman_work_t décrit le travail pour gearman_execute().

gearman_work() crée une gearman_work_t avec une priorité.

gearman_work_epoch() crée une gearman_work_t qui indique à gearman_execute() d'exécuter le workload au moment spécifié par epoch.

gearman_work_background() crée une gearman_work_t qui indique à gearman_execute() d'exécuter le workload en tant que tâche d'arrière-plan.
