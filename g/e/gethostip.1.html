NOM

gethostip — convertir une adresse IP en divers formats

SYNTAXE

gethostip [-dxnf] [NOM_HOTE|IP]

DESCRIPTION

Cette page de manuel documente brièvement la commande gethostip.

L'utilitaire gethostip convertit le nom d'hôte ou l'adresse IP donnés dans divers formats. Il est fourni par le paquet syslinux pour faciliter le calcul des noms appropriés pour les fichiers de configuration pxelinux. Ces noms de fichiers peuvent être la représentation hexadécimale complète d'une adresse IP donnée, ou une représentation hexadécimale partielle pour correspondre à une plage d'adresses IP.

OPTIONS

Un résumé des options est inclus ci-dessous.

-d
Afficher l'adresse IP en format décimal.
-x
Afficher l'adresse IP en format hexadécimal.
-n
Afficher le nom canonique de l'hôte.
-f
Sortie complète. Affiche l'adresse IP dans tous les formats supportés. Identique à -xdn.
