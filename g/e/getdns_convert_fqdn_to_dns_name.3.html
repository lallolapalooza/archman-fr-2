getdns_convert_fqdn_to_dns_name(3)

Paquet: getdns

Licences: BSD

getdns_convert(3) getdns getdns_convert(3)

NOM

getdns_convert, getdns_convert_dns_name_to_fqdn, getdns_convert_fqdn_to_dns_name -- convertir le nom DNS entre les formats de présentation et de fil d'exécution

BIBLIOTHÈQUE

Bibliothèque de résolution DNS (libgetdns, -lgetdns)

SYNOPSIS

#include <getdns.h>

getdns_return_t
getdns_convert_dns_name_to_fqdn (const getdns_bindata *dns_name_wire_fmt,

char **fqdn_as_string)

getdns_return_t
getdns_convert_fqdn_to_dns_name (char *fqdn_as_string,

const getdns_bindata **dns_name_wire_fmt)

DESCRIPTION

Les noms dans les champs DNS sont stockés d'une manière très différente du format de présentation normal normalement utilisé dans les applications. Le format DNS est décrit dans le premier paragraphe de la section 3.1 de la RFC 1035 ; le format de présentation ici est une chaîne terminée par un caractère nul avec des points intérieurs. Ces fonctions d'aide ne fonctionnent qu'avec des noms au format DNS qui ne sont pas compressés. Elles sont utiles pour convertir les noms de domaine dans l'arbre des réponses vers et depuis le format de présentation FQDN.

getdns_convert_dns_name_to_fqdn() convertit un nom de domaine au format DNS vers le format de présentation. Par exemple, la séquence hexadécimale 03 77 77 77 07 65 78 61 6d 70 6c 65 03 63 6f 6d 00 serait convertie en "www.example.com". getdns_convert_fqdn_to_dns_name() fait l'inverse : elle convertit une chaîne terminée par un caractère nul au format FQDN en octets au format DNS.

dns_name_wire_fmt Le nom au format fil d'exécution DNS non compressé (selon RFC 1035) dans une structure bindata qui sera convertie vers/depuis un fqdn. Dans getdns_convert_fqdn_to_dns_name, le stockage est alloué en utilisant l'allocateur système (malloc) et doit être libéré par l'appelant.

fqdn_as_string une chaîne terminée par un caractère nul à convertir vers/depuis un nom au format fil d'exécution DNS non compressé (selon RFC 1035). Dans getdns_convert_dns_name_to_fqdn, le stockage est alloué en utilisant l'allocateur système (malloc) et doit être libéré par l'appelant.

VALEURS DE RETOUR

En cas de succès, la fonction retourne GETDNS_RETURN_GOOD
