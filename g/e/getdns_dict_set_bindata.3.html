Paquet: getdns

Licences: BSD

getdns_dict_set(3) getdns getdns_dict_set(3)

NOM

getdns_dict_set, getdns_dict_set_bindata, getdns_dict_set_dict, getdns_dict_set_int, getdns_dict_set_list, -- définir une valeur par nom dans un dictionnaire getdns

BIBLIOTHÈQUE

Bibliothèque de résolution DNS (libgetdns, -lgetdns)

SYNTAXE

#include <getdns.h>

getdns_return_t
getdns_dict_set_bindata (getdns_dict *this_dict,

char *name,
getdns_bindata *child_bindata)

getdns_return_t
getdns_dict_set_dict (getdns_dict *this_dict,

char *name,
getdns_dict *child_dict)

getdns_return_t
getdns_dict_set_int (getdns_dict *this_dict,

char *name,
uint32_t child_uint32_t)

getdns_return_t
getdns_dict_set_list (getdns_dict *this_dict,

char *name,
getdns_list *child_list)

DESCRIPTION

Le type getdns_dict est utilisé pour gérer des paires nom/valeur dans lesquelles les noms sont des chaînes de caractères et les types de données des valeurs sont hétérogènes et incluent


getdns_bindata
getdns_dict
getdns_list
uint32_t

this_dict le dictionnaire dans lequel ajouter/mettre à jour la paire nom/valeur

name le nom dont la valeur associée doit être définie. Si le nom existe dans le dictionnaire, la valeur associée à ce nom est remplacée ; si le nom n'existe pas dans le dictionnaire, un nouvel élément est ajouté au dictionnaire.

child_bindata child_dict child_list child_uint32 valeur à attribuer au nom

VALEURS DE RETOUR

En cas de succès, les fonctions retournent GETDNS_RETURN_GOOD, sinon les valeurs d'erreur suivantes sont retournées :

GETDNS_RETURN_GENERIC_ERROR si this_dict n'est pas un dictionnaire valide
