getdents(2) Manuel des appels système getdents(2)

NOM

getdents, getdents64 - obtenir les entrées de répertoire

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/syscall.h>      /* Définition des constantes SYS_* */
#include <unistd.h>
long syscall(SYS_getdents, unsigned int fd, struct linux_dirent *dirp,
             unsigned int count);
#define _GNU_SOURCE           /* Voir feature_test_macros(7) */
#include <dirent.h>
ssize_t getdents64(size_t count;
                   int fd, void dirp[count], size_t count);

Note : glibc ne fournit pas d'enveloppe pour getdents(), nécessitant l'utilisation de syscall(2).

Note : Il n'y a pas de définition de struct linux_dirent dans glibc ; voir NOTES.

DESCRIPTION

Ce ne sont pas les interfaces qui vous intéressent. Regardez readdir(3) pour l'interface de la bibliothèque C conforme POSIX. Cette page documente les interfaces des appels système nus du noyau.

getdents()

L'appel système getdents() lit plusieurs structures linux_dirent du répertoire référencé par le descripteur de fichier ouvert fd dans le tampon pointé par dirp. L'argument count spécifie la taille de ce tampon.

La structure linux_dirent est déclarée comme suit :


struct linux_dirent {
    unsigned long  d_ino;     /* Numéro d'inode */
    unsigned long  d_off;     /* Pas un décalage ; voir ci-dessous */
    unsigned short d_reclen;  /* Longueur de ce linux_dirent */
    char           d_name[];  /* Nom de fichier (terminé par un octet nul) */
                      /* la longueur est en fait (d_reclen - 2 -
                         offsetof(struct linux_dirent, d_name)) */
    /*
    char           pad;       // Octet de remplissage zéro
    char           d_type;    // Type de fichier (depuis Linux
                              // 2.6.4 seulement) ; le décalage est (d_reclen - 1)
    */
}

d_ino est un numéro d'inode. d_off est une valeur spécifique au système de fichiers n'ayant pas de signification particulière pour l'espace utilisateur, bien que sur les anciens systèmes de fichiers il s'agisse du décalage par rapport au début du répertoire jusqu'au début du prochain linux_dirent ; voir readdir(3). d_reclen est la taille de ce linux_dirent entier. d_name est un nom de fichier terminé par un octet nul.

d_type est un octet à la fin de la structure qui indique le type de fichier. Il contient l'une des valeurs suivantes (définies dans <dirent.h>) :

DT_BLK
Ceci est un périphérique bloc.
DT_CHR
Ceci est un périphérique caractère.
DT_DIR
Ceci est un répertoire.
DT_FIFO
Ceci est un tube nommé (FIFO).
DT_LNK
Ceci est un lien symbolique.
DT_REG
Ceci est un fichier régulier.
DT_SOCK
Ceci est un socket de domaine UNIX.
DT_UNKNOWN
Le type de fichier est inconnu.

Le champ d_type est implémenté depuis Linux 2.6.4. Il occupe un espace qui était auparavant un octet de remplissage rempli de zéros dans la structure linux_dirent. Ainsi, sur les noyaux jusqu'à et incluant Linux 2.6.3, tenter d'accéder à ce champ renvoie toujours la valeur 0 (DT_UNKNOWN).

Actuellement, seuls certains systèmes de fichiers (parmi eux : Btrfs, ext2, ext3 et ext4) supportent pleinement le renvoi du type de fichier dans d_type. Toutes les applications doivent gérer correctement un retour de DT_UNKNOWN.

getdents64()

L'appel système Linux original getdents() ne gérait pas les grands systèmes de fichiers et les grands décalages de fichiers. Par conséquent, Linux 2.4 a ajouté getdents64(), avec des types plus larges pour les champs d_ino et d_off. De plus, getdents64() supporte un champ d_type explicite.

L'appel système getdents64() est similaire à getdents(), sauf que son deuxième argument est un pointeur vers un tampon contenant des structures du type suivant :


struct linux_dirent64 {
    ino64_t        d_ino;    /* Numéro d'inode 64 bits */
    off64_t        d_off;    /* Pas un décalage ; voir getdents() */
    unsigned short d_reclen; /* Taille de ce dirent */
    unsigned char  d_type;   /* Type de fichier */
    char           d_name[]; /* Nom de fichier (terminé par un octet nul) */
};

VALEUR DE RETOUR

En cas de succès, le nombre d'octets lus est renvoyé. À la fin du répertoire, 0 est renvoyé. En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

EBADF
Descripteur de fichier fd invalide.
EFAULT
L'argument pointe en dehors de l'espace d'adressage du processus appelant.
EINVAL
Le tampon de résultat est trop petit.
ENOENT
Aucun répertoire de ce type.
ENOTDIR
Le descripteur de fichier ne fait pas référence à un répertoire.

NORMES

Aucune.

HISTORIQUE

SVr4.

getdents64()

NOTES

glibc ne fournit pas d'enveloppe pour getdents ; appelez getdents() en utilisant syscall(2). Dans ce cas, vous devrez définir vous-même la structure linux_dirent ou linux_dirent64.

Probablement, vous voulez utiliser readdir(3) au lieu de ces appels système.

Ces appels remplacent readdir(2).

EXEMPLES

Le programme ci-dessous démontre l'utilisation de getdents(). La sortie suivante montre un exemple de ce que nous voyons lorsque nous exécutons ce programme sur un répertoire ext2 :


$ ./a.out /testfs/
--------------- nread=120 ---------------
inode#    file type  d_reclen  d_off   d_name
       2  directory    16         12  .
       2  directory    16         24  ..
      11  directory    24         44  lost+found
      12  regular      16         56  a
  228929  directory    16         68  sub
   16353  directory    16         80  sub2
  130817  directory    16       4096  sub3

Source du programme

#define _GNU_SOURCE
#include <dirent.h>     /* Définit les constantes DT_* */
#include <err.h>
#include <fcntl.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/syscall.h>
#include <sys/types.h>
#include <unistd.h>
struct linux_dirent {
    unsigned long  d_ino;
    off_t          d_off;
    unsigned short d_reclen;
    char           d_name[];
};
#define BUF_SIZE 1024
int
main(int argc, char *argv[])
{
    int                  fd;
    char                 d_type;
    char                 buf[BUF_SIZE];
    long                 nread;
    struct linux_dirent  *d;
    fd = open(argc >
1 ? argv[1] : ".", O_RDONLY | O_DIRECTORY); if (fd == -1) err(EXIT_FAILURE, "open"); for (;;) { nread = syscall(SYS_getdents, fd, buf, BUF_SIZE); if (nread == -1) err(EXIT_FAILURE, "getdents"); if (nread == 0) break; printf("--------------- nread=%ld ---------------\n", nread); printf("inode# file type d_reclen d_off d_name\n"); for (size_t bpos = 0; bpos < nread;) { d = (struct linux_dirent *) (buf + bpos); printf("%8lu ", d->d_ino); d_type = *(buf + bpos + d->d_reclen - 1); printf("%-10s ", (d_type == DT_REG) ? "regular" : (d_type == DT_DIR) ? "directory" : (d_type == DT_FIFO) ? "FIFO" : (d_type == DT_SOCK) ? "socket" : (d_type == DT_LNK) ? "symlink" : (d_type == DT_BLK) ? "block dev" : (d_type == DT_CHR) ? "char dev" : "???"); printf("%4d %10jd %s\n", d->d_reclen, (intmax_t) d->d_off, d->d_name); bpos += d->d_reclen; } } exit(EXIT_SUCCESS); }
