gearman_client_has_option(3)

Paquet: gearmand

GEARMAN_CLIENT_HAS_OPTION(3) Gearmand GEARMAN_CLIENT_HAS_OPTION(3)

NOM

gearman_client_has_option - Documentation Gearmand, https://gearman.org/gearmand/

SYNOPSIS

#include <libgearman/gearman.h>

type gearman_client_options_t
gearman_client_options_t gearman_client_options(const gearman_client_st *client)
void gearman_client_set_options(gearman_client_st *client, gearman_client_options_t options)
void gearman_client_add_options(gearman_client_st *client, gearman_client_options_t options)
void gearman_client_remove_options(gearman_client_st *client, gearman_client_options_t options)
bool gearman_client_has_option(gearman_client_st *client, gearman_client_options_t option)

Liez avec -lgearman

DESCRIPTION

gearman_client_options() retourne le gearman_client_options_t pour gearman_client_st. Vous activez les options via gearman_client_add_options() et désactivez les options via gearman_client_remove_options().

gearman_client_set_options() est DÉPRÉCIÉ.

Les options actuellement supportées sont :

type GEARMAN_CLIENT_NON_BLOCKING

Exécute le client en mode non bloquant.

type GEARMAN_CLIENT_FREE_TASKS

Libère automatiquement les objets de tâche une fois qu'ils sont terminés.

type GEARMAN_CLIENT_UNBUFFERED_RESULT

Permet au client de lire les données par morceaux plutôt que de laisser la bibliothèque mettre en tampon tout le résultat de données et le passer en retour.

type GEARMAN_CLIENT_GENERATE_UNIQUE

Génère un identifiant unique pour chaque tâche créée en générant un UUID.
