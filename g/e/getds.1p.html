NOM

getds - Créer un enregistrement DS à partir d'informations DNSKEYing

SYNTAXE

getds <domaine>

DESCRIPTION

getds créera un enregistrement DS à partir des DNSKEYs pour le domaine DNS spécifié. Il y parvient en convertissant les DNSKEYs en enregistrements DS en utilisant l'algorithme de hachage spécifié. Les résultats peuvent ensuite être transmis aux parents de niveau supérieur prenant en charge DNSSEC ou aux registres DLV.

getds récupérera également les enregistrements DS publiés du parent et les comparera aux clés existantes. Il listera ensuite tous les enregistrements DS non publiés chez le parent, ainsi que tous les enregistrements DS qui sont publiés chez le parent mais qui ne correspondent à aucune clé existante.

OPTIONS

getds prend les options suivantes :

-a ALGORITHMS
--hash-algorithm algorithm ALGORITHMS
Cette option spécifie l'algorithme de hachage à utiliser lors de la conversion des DNSKEYs en enregistrements DS. Il peut s'agir d'une liste séparée par des virgules si plusieurs algorithmes sont souhaités. Les algorithmes possibles sont SHA256 ou SHA1.

Par défaut : SHA256,SHA1

-f FICHIER_CLE
--read-key-file FICHIER_CLE
Cette option spécifie un fichier contenant une DNSKEY (tel que créé par le programme dnssec-keygen de bind). Ceci est utile pour comparer un fichier clé connu comme étant correct avec quelque chose qui est réellement publié.
-z
--print-zsks
Cette option amène getds à afficher les enregistrements DS ZSK (Zone Signing Key), ainsi que les enregistrements KSK (Key Signing Key).
-p
--dont-check-parent
Instruit getds à ne pas vérifier les enregistrements du parent pour ses enregistrements DS publiés.
-q
--quiet
Produit une sortie silencieuse sans en-têtes explicatifs. Autrement dit, il imprime uniquement les enregistrements DS générés à partir des DNSKEYs.

Remarque : L'exécution avec -q implique -p.

CONSIDÉRATIONS DE SÉCURITÉ

Par défaut, getds récupère les données du DNS en direct. Si votre résolveur DNS n'est pas configuré pour que cela soit récupéré de manière sécurisée, alors les résultats ne peuvent pas être fiables.
