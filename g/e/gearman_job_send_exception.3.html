#include <libgearman/gearman.h>

type gearman_job_st

Lier avec -lgearman

DESCRIPTION

gearman_job_st sont passés aux fonctions de travail pour représenter les tâches en cours d'exécution par gearman_worker_work().

gearman_job_free() est utilisé pour libérer une tâche. Cela ne doit être fait que si une tâche a été créée avec une structure pré-allouée.

gearman_job_handle() renvoie le handle de la tâche (voir gearman_job_handle_t pour plus d'informations).

gearman_job_function_name() renvoie le nom de la fonction sur laquelle la tâche a été définie pour s'exécuter.

gearman_job_unique() renvoie la valeur unique utilisée pour gearman_job_st.

gearman_job_take_workload renvoie la charge de travail de gearman_job_st. Sa taille peut être déterminée avec gearman_job_workload_size(). gearman_job_take_workload() est identique à gearman_job_workload() à l'exception près que le résultat doit être free(3) par l'appelant.

gearman_job_use_client renvoie un gearman_client_st configuré à partir de gearman_job_st. Le gearman_client_st peut être utilisé pour communiquer les commandes de l'API client au serveur. Vous ne devez pas, et ne devriez pas, appeler gearman_client_free() sur le gearman_client_st. Il est nettoyé lorsque la tâche est nettoyée.

VALEUR DE RETOUR

Une valeur de type gearman_return_t est retournée. En cas de succès, cette valeur sera :c:type::GEARMAN_SUCCESS. Utilisez gearman_strerror() pour traduire cette valeur en une chaîne imprimable.
