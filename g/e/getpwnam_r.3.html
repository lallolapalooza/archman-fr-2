getpwnam(3) Manuel des fonctions de la bibliothèque getpwnam(3)

NOM

getpwnam, getpwnam_r, getpwuid, getpwuid_r - obtenir une entrée du fichier de mots de passe

BIBLIOTHÈQUE

Bibliothèque C standard (libc,-lc)

SYNOPSIS

#include <sys/types.h>
#include <pwd.h>
struct passwd *getpwnam(const char *name);
struct passwd *getpwuid(uid_t uid);
int getpwnam_r(size_t size;
               const char *restrict name,
               struct passwd *restrict pwd,
               char buf[restrict size], size_t size,
               struct passwd **restrict result);
int getpwuid_r(size_t size;
               uid_t uid,
               struct passwd *restrict pwd,
               char buf[restrict size], size_t size,
               struct passwd **restrict result);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

getpwnam_r(), getpwuid_r() :

    _POSIX_C_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

La fonction getpwnam() renvoie un pointeur vers une structure contenant les champs décomposés de l'enregistrement dans la base de données de mots de passe (par ex. le fichier de mots de passe local /etc/passwd, NIS et LDAP) qui correspond au nom d'utilisateur name.

La fonction getpwuid() renvoie un pointeur vers une structure contenant les champs décomposés de l'enregistrement dans la base de données de mots de passe qui correspond à l'identifiant utilisateur uid.

La structure passwd est définie dans <pwd.h> comme suit :


struct passwd {
    char   *pw_name;       /* username */
    char   *pw_passwd;     /* user password */
    uid_t   pw_uid;        /* user ID */
    gid_t   pw_gid;        /* group ID */
    char   *pw_gecos;      /* user information */
    char   *pw_dir;        /* home directory */
    char   *pw_shell;      /* shell program */
};

Voir passwd(5) pour plus d'informations sur ces champs.

Les fonctions getpwnam_r() et getpwuid_r() obtiennent les mêmes informations que getpwnam() et getpwuid(), mais stockent la structure passwd récupérée dans l'espace pointé par pwd. Les champs de chaînes pointés par les membres de la structure passwd sont stockés dans le tampon buf de taille size. Un pointeur vers le résultat (en cas de succès) ou NULL (si aucune entrée n'a été trouvée ou si une erreur s'est produite) est stocké dans *result.

L'appel


sysconf(_SC_GETPW_R_SIZE_MAX)

renvoie soit -1, sans modifier errno, soit une taille initiale suggérée pour buf. (Si cette taille est trop petite, l'appel échoue avec ERANGE, auquel cas l'appelant peut réessayer avec un tampon plus grand.)

VALEUR RENVOYÉE

Les fonctions getpwnam() et getpwuid() renvoient un pointeur vers une structure passwd , ou NULL si l'entrée correspondante n'est pas trouvée ou si une erreur se produit. Si une erreur se produit, errno est défini pour indiquer l'erreur. Si l'on souhaite vérifier errno après l'appel, il doit être mis à zéro avant l'appel.

La valeur renvoyée peut pointer vers une zone statique et peut être écrasée par des appels ultérieurs à getpwent(3), getpwnam() ou getpwuid(). (Ne pas passer le pointeur renvoyé à free(3).)

En cas de succès, getpwnam_r() et getpwuid_r() renvoient zéro et définissent *result sur pwd. Si aucun enregistrement de mot de passe correspondant n'a été trouvé, ces fonctions renvoient 0 et stockent NULL dans *result. En cas d'erreur, un numéro d'erreur est renvoyé et NULL est stocké dans *result.

ERREURS

0 ou ENOENT ou ESRCH ou EBADF ou EPERM ou ...
Le name ou uid donné n'a pas été trouvé.
EINTR
Un signal a été capturé ; voir signal(7).
EIO
Erreur d'E/S.
EMFILE
La limite par processus sur le nombre de descripteurs de fichiers ouverts a été atteinte.
ENFILE
La limite du système sur le nombre total de fichiers ouverts a été atteinte.
ENOMEM
Mémoire insuffisante pour allouer la structure passwd .
ERANGE
Espace de tampon fourni insuffisant.

FICHIERS

/etc/passwd
fichier de base de données de mots de passe local

VERSIONS

Le champ pw_gecos n'est pas spécifié dans POSIX, mais est présent dans la plupart des implémentations.

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, SVr4, 4.3BSD.

NOTES

La formulation donnée ci-dessus sous « VALEUR RENVOYÉE » provient de POSIX.1-2001. Elle ne qualifie pas « non trouvé » comme une erreur et ne spécifie donc pas quelle valeur errno pourrait avoir dans cette situation. Mais cela rend impossible la reconnaissance des erreurs. On pourrait soutenir que selon POSIX, errno devrait rester inchangé si une entrée n'est pas trouvée. Des expériences sur divers systèmes de type UNIX montrent que de nombreuses valeurs différentes surviennent dans cette situation : 0, ENOENT, EBADF, ESRCH, EWOULDBLOCK, EPERM, et probablement d'autres.

Le champ pw_dir contient le nom du répertoire de travail initial de l'utilisateur. Les programmes de connexion utilisent la valeur de ce champ pour initialiser la variable d'environnement HOME pour le shell de connexion. Une application qui souhaite déterminer le répertoire personnel de son utilisateur doit examiner la valeur de HOME (plutôt que la valeur getpwuid(getuid())->pw_dir) car cela permet à l'utilisateur de modifier sa notion de « répertoire personnel » pendant une session de connexion. Pour déterminer le répertoire personnel (initial) d'un autre utilisateur, il est nécessaire d'utiliser getpwnam("username")->pw_dir ou similaire.

EXEMPLES

Le programme ci-dessous illustre l'utilisation de getpwnam_r() pour trouver le nom d'utilisateur complet et l'identifiant utilisateur pour le nom d'utilisateur fourni en argument de ligne de commande.

#include <errno.h>
#include <pwd.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    struct passwd pwd;
    struct passwd *result;
    char *buf;
    long bufsize;
    int s;
    if (argc != 2) {
        fprintf(stderr, "Usage: %s username\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    bufsize = sysconf(_SC_GETPW_R_SIZE_MAX);
    if (bufsize == -1)          /* Value was indeterminate */
        bufsize = 16384;        /* Should be more than enough */
    buf = malloc(bufsize);
    if (buf == NULL) {
        perror("malloc");
        exit(EXIT_FAILURE);
    }
    s = getpwnam_r(argv[1], &pwd, buf, bufsize, &result);
 if (result == NULL) {
        if (s == 0)
            printf("Introuvable\n");
        else {
            errno = s;
            perror("getpwnam_r");
        }
        exit(EXIT_FAILURE);
    }
    printf("Nom : %s; UID : %jd\n", pwd.pw_gecos,
           (intmax_t) pwd.pw_uid);
    exit(EXIT_SUCCESS);
}
