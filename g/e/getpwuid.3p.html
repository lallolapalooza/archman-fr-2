DESCRIPTIO

N

La fonction getpwuid() doit rechercher dans la base de données des utilisateurs une entrée correspondant à l' uid

.

La fonction getpwuid() n'a pas besoin d'être sûre pour les

threads.

Les applications souhaitant vérifier les situations d'erreur doivent définir errno à 0 avant d'appeler getpwuid(). Si getpwuid() renvoie un pointeur nul et que errno est défini à une valeur non nulle, une erreur s'est

produite.

La fonction getpwuid_r() doit mettre à jour la structure passwd pointée par pwd et stocker un pointeur vers cette structure à l'emplacement pointé par result. La structure doit contenir une entrée de la base de données des utilisateurs correspondant à l' uid. Le stockage référencé par la structure est alloué à partir de la mémoire fournie avec le paramètre buffer, dont la taille est de bufsize octets. Un appel à sysconf(_SC_GETPW_R_SIZE_MAX) renvoie soit -1 sans modifier errno, soit une valeur initiale suggérée pour la taille de ce tampon. Un pointeur nul doit être renvoyé à l'emplacement pointé par result en cas d'erreur ou si l

'entrée demandée
est introuvable.

VALEUR DE

RETOUR

La fonction getpwuid() doit renvoyer un pointeur vers une struct passwd dont la structure est définie dans <pwd.h> avec une entrée correspondante si elle est trouvée. Un pointeur nul doit être renvoyé si l'entrée demandée est introuvable ou si une erreur se produit. Si l'entrée demandée n'a pas été trouvée, errno ne doit pas être modifié. En cas d'erreur, errno doit être défini pour indiquer

l'erreur.

L'application ne doit pas modifier la structure vers laquelle pointe la valeur de retour, ni aucune zone de stockage pointée par des pointeurs à l'intérieur de la structure. Le pointeur renvoyé, ainsi que les pointeurs à l'intérieur de la structure, peuvent être invalidés ou la structure ou les zones de stockage peuvent être écrasées par un appel ultérieur à getpwent(), getpwnam() ou getpwuid(). Le pointeur renvoyé, ainsi que les pointeurs à l'intérieur de la structure, peuvent également être invalidés si le thread appelant est

terminé.

En cas de succès, la fonction getpwuid_r() doit renvoyer zéro ; sinon, un

numéro d'erreur doit être ren
voyé pour indiquer l'erreur.

UTILISATION PAR

L'APPLICATION

Trois noms associés au processus courant peuvent être déterminés : getpwuid(geteuid()) renvoie le nom associé à l'identifiant d'utilisateur effectif du processus ; getlogin() renvoie le nom associé à l'activité de connexion courante ; et getpwuid(getuid()) renvoie le nom associé à l'identifiant d'utilisateur réel du

processus.

La fonction getpwuid_r() est sûre pour les threads et renvoie les valeurs dans un tampon fourni par l'utilisateur au lieu d'utiliser éventuellement une zone de données statique qui peut être écrasée à chaque

appel.

Les applications portables doivent prendre en compte qu'il est courant qu'une implémentation renvoie -1 depuis sysconf() indiquant qu'il n'y a pas de maximum pour _SC_GETPW_R_SIZE_MA

X
