sous-routine cgeqr2p (integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer info)

CGEQR2P calcule la factorisation QR d'une matrice rectangulaire complexe de taille m x n avec des éléments diagonaux non négatifs en utilisant un algorithme non bloqué.

Objectif:

!>
!> CGEQR2P calcule une factorisation QR d'une matrice complexe A de taille m x n :
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> où :
!>
!>    Q est une matrice orthogonale de taille m x m ;
!>    R est une matrice triangulaire supérieure de taille n x n avec des entrées diagonales non négatives ;
!>    0 est une matrice nulle de taille (m-n) x n, si m > n.
!>
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          En entrée, la matrice A de taille m x n.
!>          En sortie, les éléments sur et au-dessus de la diagonale du tableau
!>          contiennent la matrice trapézoïdale supérieure R de taille min(m,n) x n (R est
!>          triangulaire supérieure si m >= n). Les entrées diagonales de R sont
!>          réelles et non négatives ; les éléments en dessous de la diagonale,
!>          avec le tableau TAU, représentent la matrice unitaire Q comme un
!>          produit de réflecteurs élémentaires (voir Détails supplémentaires).
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

TAU

!>          TAU est un tableau COMPLEX, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires (voir Détails
!>          supplémentaires).
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (N)
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Auteur

Univ. du Tennessee

Univ. de Californie Berkeley

Univ. du Colorado Denver

NAG Ltd.

Détails supplémentaires:

!>
!>  La matrice Q est représentée comme un produit de réflecteurs élémentaires
!>
!>     Q = H(1) H(2) . . . H(k), où k = min(m,n).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**H
!>
!>  où tau est un scalaire complexe, et v est un vecteur complexe avec
!>  v(1:i-1) = 0 et v(i) = 1 ; v(i+1:m) est stocké en sortie dans A(i+1:m,i),
!>  et tau dans TAU(i).
!>
!> Voir la note de travail Lapack 203 pour les détails.
!>
