sous-routine cgeesx (character jobvs, character sort, external select, character sense, integer n, complex, dimension( lda, * ) a, integer lda, integer sdim, complex, dimension( * ) w, complex, dimension( ldvs, * ) vs, integer ldvs, real rconde, real rcondv, complex, dimension( * ) work, integer lwork, real, dimension( * ) rwork, logical, dimension( * ) bwork, integer info)

cgeesx calcule les valeurs propres, la forme de Schur et, éventuellement, la matrice des vecteurs de Schur pour les matrices GE

But :

!>
!> CGEESX calcule pour une matrice complexe non symétrique N-par-N A, les
!> valeurs propres, la forme de Schur T et, éventuellement, la matrice des
!> vecteurs de Schur Z. Ceci donne la factorisation de Schur A = Z*T*(Z**H).
!>
!> Éventuellement, elle ordonne également les valeurs propres sur la diagonale de la
!> forme de Schur afin que les valeurs propres sélectionnées soient en haut à gauche ;
!> calcule un nombre conditionnel réciproque pour la moyenne des
!> valeurs propres sélectionnées (RCONDE) ; et calcule un nombre conditionnel réciproque
!> pour le sous-espace invariant à droite correspondant aux
!> valeurs propres sélectionnées (RCONDV). Les colonnes principales de Z forment une
!> base orthonormée pour ce sous-espace invariant.
!>
!> Pour plus d'explication sur les nombres conditionnels réciproques RCONDE
!> et RCONDV, voir la section 4.10 du LAPACK Users' Guide (où
!> ces quantités sont appelées s et sep respectivement).
!>
!> Une matrice complexe est sous forme de Schur si elle est triangulaire supérieure.
!>

Paramètres

JOBVS 
!>          JOBVS est CHARACTER*1
!>          = 'N': les vecteurs de Schur ne sont pas calculés ;
!>          = 'V': les vecteurs de Schur sont calculés.
!>

SORT

!>          SORT est CHARACTER*1
!>          Spécifie si les valeurs propres doivent être ordonnées ou non sur la
!>          diagonale de la forme de Schur.
!>          = 'N': les valeurs propres ne sont pas ordonnées ;
!>          = 'S': les valeurs propres sont ordonnées (voir SELECT).
!>

SELECT

!>          SELECT est une FONCTION LOGIQUE d'un argument COMPLEXE
!>          SELECT doit être déclarée EXTERNE dans la sous-routine appelante.
!>          Si SORT = 'S', SELECT est utilisée pour sélectionner les valeurs propres à ordonner
!>          en haut à gauche de la forme de Schur.
!>          Si SORT = 'N', SELECT n'est pas référencée.
!>          Une valeur propre W(j) est sélectionnée si SELECT(W(j)) est vraie.
!>

SENSE

!>          SENSE est CHARACTER*1
!>          Détermine quels nombres conditionnels réciproques sont calculés.
!>          = 'N': Aucun n'est calculé ;
!>          = 'E': Calculé uniquement pour la moyenne des valeurs propres sélectionnées ;
!>          = 'V': Calculé uniquement pour le sous-espace invariant à droite sélectionné ;
!>          = 'B': Calculé pour les deux.
!>          Si SENSE = 'E', 'V' ou 'B', SORT doit être égal à 'S'.
!>

N

!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau COMPLEXE, dimension (LDA, N)
!>          En entrée, la matrice N-par-N A.
!>          En sortie, A est écrasée par sa forme de Schur T.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!>

SDIM

!>          SDIM est INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = nombre de valeurs propres pour lesquelles
!>                         SELECT est vraie.
!>

W

!>          W est un tableau COMPLEXE, dimension (N)
!>          W contient les valeurs propres calculées, dans le même ordre
!>          qu'elles apparaissent sur la diagonale de la forme de Schur T en sortie.
!>

VS

!>          VS est un tableau COMPLEXE, dimension (LDVS,N)
!>          Si JOBVS = 'V', VS contient la matrice unitaire Z des vecteurs de Schur.
!>          Si JOBVS = 'N', VS n'est pas référencé.
!>

LDVS

!>          LDVS est INTEGER
!>          La dimension principale du tableau VS. LDVS >= 1, et si
!>          JOBVS = 'V', LDVS >= N.
!>

RCONDE

!>          RCONDE est REAL
!>          Si SENSE = 'E' ou 'B', RCONDE contient le nombre conditionnel réciproque
!>          pour la moyenne des valeurs propres sélectionnées.
!>          Non référencé si SENSE = 'N' ou 'V'.
!>

RCONDV

!>          RCONDV est REAL
!>          Si SENSE = 'V' ou 'B', RCONDV contient le nombre conditionnel réciproque
!>          pour le sous-espace invariant à droite sélectionné.
!>          Non référencé si SENSE = 'N' ou 'E'.
!>

WORK

!>          WORK est un tableau COMPLEXE, dimension (MAX(1,LWORK))
!>          En sortie, si INFO = 0, WORK(1) renvoie la taille optimale LWORK.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,2*N).
!>          De plus, si SENSE = 'E' ou 'V' ou 'B', LWORK >= 2*SDIM*(N-SDIM),
!>          où SDIM est le nombre de valeurs propres sélectionnées calculées par
!>          cette routine. Notez que 2*SDIM*(N-SDIM) <= N*N/2. Notez également
!>          qu'une erreur n'est retournée que si LWORK < max(1,2*N), mais si
!>          SENSE = 'E' ou 'V' ou 'B', cela peut ne pas être suffisant.
!>          Pour de bonnes performances, LWORK doit généralement être plus grand.
!>
!>          Si LWORK = -1, alors une requête d'espace de travail est supposée ; la routine
!>          calcule uniquement la borne supérieure de la taille optimale du
!>          tableau WORK, renvoie cette valeur comme première entrée du tableau WORK,
!>          et aucun message d'erreur lié à LWORK n'est émis par
!>          XERBLA.
!>

RWORK

!>          RWORK est un tableau REAL, dimension (N)
!>

BWORK

!>          BWORK est un tableau LOGICAL, dimension (N)
!>          Non référencé si SORT = 'N'.
!>

INFO

!>          INFO est INTEGER
!>          = 0: sortie réussie
!>          < 0: si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0: si INFO = i, et i est
!>             <= N: l'algorithme QR n'a pas réussi à calculer toutes les
!>                   valeurs propres ; les éléments 1:ILO-1 et i+1:N de W
!>                   contiennent les valeurs propres qui ont convergé ; si
!>                   JOBVS = 'V', VS contient la transformation qui
!>                   réduit A à sa forme de Schur partiellement convergée.
!>             = N+1: les valeurs propres n'ont pas pu être réordonnées car certaines
!>                   valeurs propres étaient trop proches pour être séparées (le problème
!>                   est très mal conditionné) ;
!>             = N+2: après réordonnancement, les erreurs d'arrondi ont modifié les valeurs de certaines

!> valeurs propres, la forme de Schur réelle T, et, éventuellement, la matrice des
!> vecteurs de Schur Z. Cela donne la factorisation de Schur A = Z*T*(Z**T).

ZGEESX calcule les valeurs propres, la forme de Schur et, éventuellement, la matrice des vecteurs de Schur pour les matrices GE

But :

!>
!> ZGEESX calcule pour une matrice complexe non symétrique A de dimension N par N, les
!> valeurs propres, la forme de Schur T, et, optionnellement, la matrice des vecteurs de Schur
!> Z.  Cela donne la factorisation de Schur A = Z*T*(Z**H).
!>
!> Optionnellement, elle ordonne aussi les valeurs propres sur la diagonale de la
!> forme de Schur de sorte que les valeurs propres sélectionnées soient en haut à

!> valeurs propres sélectionnées (RCONDE) ; et calcule un nombre de condition
!> réciproque pour le sous-espace invariant droit correspondant aux
!> valeurs propres sélectionnées (RCONDV). Les colonnes principales de Z forment
!> une base orthonormale pour ce sous-espace invariant.
!>
!> Pour une explication plus détaillée des nombres de condition réciproques RCONDE
!> et RCONDV, voir la section 4.10 du Guide de l'utilisateur de LAPACK (où
!> ces quantités sont appelées s et sep respectivement).
