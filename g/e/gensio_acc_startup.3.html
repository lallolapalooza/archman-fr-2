NOM

gensio_acc_startup - Démarrer un accepteur gensio

SYNOPSIS

#include <gensio/gensio.h>

int gensio_acc_startup(struct gensio_accepter *acc);

DESCRIPTION

gensio_acc_startup démarre l'accepteur gensio. Un accepteur gensio est démarré non exécuté, vous devez appeler cette fonction pour le démarrer.

Contrairement à gensio_open, ceci active également les événements de l'accepteur gensio.

VALEURS DE RETOUR

Zéro est retourné en cas de succès, ou une erreur gensio en cas d'échec.

VOIR AUSSI

gensio_err(3), gensio(5), gensio_open(3)
