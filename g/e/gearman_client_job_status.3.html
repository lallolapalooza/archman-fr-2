NOM

gearman_client_job_status - Documentation Gearmand, https://gearman.org/gearmand/

SYNTAXE

#include <libgearman/gearman.h>

gearman_return_t gearman_client_job_status(gearman_client_st *client, gearman_job_handle_t job_handle, bool *is_known, bool *is_running, uint32_t *numerator, uint32_t *denominator)

Lier avec -lgearman

DESCRIPTION

gearman_client_job_status() est utilisée pour trouver le statut d'un travail via son gearman_job_handle_t. Les arguments is_known, is_running, numerator, et denominator sont tous optionnels. À moins qu'un travailleur Gearman n'ait envoyé les numérateur/dénominateur via gearman_job_send_status(), ces valeurs seront nulles.

Si les arguments is_known et is_running sont omis, la fonction renvoie les données d'état via gearman_return_t.

VALEUR DE RETOUR

gearman_return_t sera retourné. GEARMAN_SUCCESS sera retourné en cas de succès de la mise à jour du statut. Si les arguments is_known et is_running sont omis, gearman_client_job_status() renverra GEARMAN_JOB_EXISTS si le gearman_job_handle_t est connu sur le serveur, et GEARMAN_IN_PROGRESS s'il est en cours d'exécution. Savoir si le travail est en cours d'exécution ou non a une priorité plus élevée. gearman_continue() peut être utilisé pour les boucles où vous souhaitez sortir de la boucle une fois que le travail est terminé.

ATTENTION :

Pour les boucles, vous devriez toujours vérifier gearman_return_t avec gearman_continue() même si vous spécifiez les arguments is_known ou is_running. Un appel IO non bloquant peut renvoyer autre chose que GEARMAN_SUCCESS ; dans certains cas, vous voudrez traiter ces valeurs non pas comme des erreurs.
