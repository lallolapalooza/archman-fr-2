getdns_service(3)

Paquet: getdns

Licences: BSD

getdns_service(3) getdns getdns_service(3)

NOM

getdns_service, getdns_service_sync -- récupération de service getdns

BIBLIOTHÈQUE

Bibliothèque de résolution DNS (libgetdns, -lgetdns)

SYNTAXE

#include <getdns.h>

getdns_return_t
getdns_service (getdns_context *context,

const char *name,
getdns_dict *extensions,
void *userarg,
getdns_transaction_t *transaction_id,
getdns_callback_t callbackfn)

getdns_return_t
getdns_service_sync (getdns_context *context,

const char *name,
getdns_dict *extensions,
getdns_dict **response)

DESCRIPTION

Les fonctions getdns_service(3) et getdns_service_sync fournissent des points d'entrée publics dans la bibliothèque d'API getdns pour récupérer les informations SRV étant donné un nom.

context Un pointeur vers le contexte DNS précédemment créé qui doit être utilisé avec cette requête DNS. voir getdns_context(3)

name le nom du service à résoudre

extensions extensions pour cette requête, NULL si aucune extension, voir libgetdns(3) pour une description détaillée des extensions

userarg retourné à la fonction de rappel intact, peut être NULL

transaction_id rempli par l'API et utilisé pour identifier le rappel (par exemple pour getdns_cancel_callback), peut être NULL, défini à 0 si la fonction échoue

callbackfn pointeur non-NULL vers une fonction de rappel définie par l'application, typiquement utilisée pour traiter la réponse. Seule la signature asynchrone accepte une fonction de rappel, la signature synchrone n'inclut pas de rappel. Voir libgetdns(3) pour une discussion plus détaillée des fonctions de rappel.

response Un type getdns_dict est retourné en réponse et contient toujours au moins trois noms : replies_full (une liste contenant la réponse DNS sous forme de données binaires), replies_tree (une liste contenant les données de réponse DNS parsées) et status (un entier). Le stockage associé à cela doit être libéré par un appel à getdns_free_sync_request_memory(3).

VALEURS DE RETOUR

En cas de succès, les fonctions retournent GETDNS_RETURN_GOOD , sinon les valeurs d'erreur suivantes sont retournées :

GETDNS_RETURN_BAD_CONTEXT si le pointeur de contexte est invalide ou si le contexte présente des déficiences internes

GETDNS_RETURN_BAD_DOMAIN_NAME si le nom de domaine passé à la fonction est invalide

GETDNS_RETURN_EXTENSION_MISFORMAT si le type de données spécifié dans une ou plusieurs des extensions ne correspond pas aux spécifications

GETDNS_RETURN_GENERIC_ERROR si un problème est survenu dans la fonction non couvert par l'un des codes de retour plus spécifiques

GETDNS_RETURN_INVALID PARAMETER si un ou plusieurs paramètres ont une valeur invalide

GETDNS_RETURN_MEMORY_ERROR si la mémoire requise n'a pas pu être allouée

GETDNS_RETURN_NO_SUCH_EXTENSION si une ou plusieurs des chaînes spécifiées dans les extensions ne sont pas valides

Les valeurs de status incluses dans le paramètre response sont :

GETDNS_RESPSTATUS_GOOD si au moins une réponse a été retournée

GETDNS_RESPSTATUS_NO_NAME si les requêtes pour le nom ont produit toutes des réponses négatives

GETDNS_RESPSTATUS_ALL_TIMEOUT si toutes les requêtes pour le nom ont expiré

GETDNS_RESPSTATUS_NO_SECURE_ANSWERS si seules les réponses sécurisées ont été acceptées (par contexte) et qu'au moins une réponse a été reçue mais aucune réponse DNS n'était sécurisée via DNSSEC

Pour une explication plus détaillée de l'objet response, voir libgetdns(3)
