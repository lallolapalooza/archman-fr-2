CGEES calcule les valeurs propres, la forme de Schur et, éventuellement, la matrice des vecteurs de Schur pour les matrices

GE

But

: 
!>
!> CGEES calcule pour une matrice complexe non symétrique A de taille N par N,
!> les valeurs propres, la forme de Schur T et, éventuellement, la matrice des
!> vecteurs de Schur Z. Cela donne la factorisation de Schur A = Z*T*(Z**H).
!>
!> Éventuellement, il ordonne aussi les valeurs propres sur la diagonale de la
!> forme de Schur de sorte que les valeurs propres sélectionnées soient en haut
!> à gauche. Les colonnes principales de Z forment alors une base orthonormale
!> pour le sous-espace invariant correspondant aux valeurs propres sélectionnées.
!>
!> Une matrice complexe est en forme de Schur si elle est triangulaire supérieure.
!
>

Paramètre

s
JOBVS 
!>          JOBVS est CHARACTER*1
!>          = 'N' : les vecteurs de Schur ne sont pas calculés ;
!>          = 'V' : les vecteurs de Schur sont calculés.
!
>

SOR

T 
!>          SORT est CHARACTER*1
!>          Indique si les valeurs propres doivent être ordonnées sur la
!>          diagonale de la forme de Schur.
!>          = 'N' : les valeurs propres ne sont pas ordonnées :
!>          = 'S' : les valeurs propres sont ordonnées (voir SELECT).
!
>

SELEC

T 
!>          SELECT est une fonction LOGICAL prenant un argument COMPLEX
!>          SELECT doit être déclarée EXTERNAL dans la sous-routine appelante.
!>          Si SORT = 'S', SELECT est utilisée pour sélectionner les valeurs
!>          propres à ordonner en haut à gauche de la forme de Schur.
!>          Si SORT = 'N', SELECT n'est pas référencée.
!>          La valeur propre W(j) est sélectionnée si SELECT(W(j)) est vraie.
!
>

N 
!>          N est INTEGER
!>          L'ordre de la matrice A. N >= 0.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille N par N.
!>          À la sortie, A a été écrasée par sa forme de Schur T.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!
>

SDI

M 
!>          SDIM est INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = le nombre de valeurs propres pour lesquelles
!>                         SELECT est vraie.
!
>

W 
!>          W est un tableau COMPLEX, dimension (N)
!>          W contient les valeurs propres calculées, dans le même ordre que
!>          celles apparaissant sur la diagonale de la forme de Schur de sortie T.
!
>

V

S 
!>          VS est un tableau COMPLEX, dimension (LDVS,N)
!>          Si JOBVS = 'V', VS contient la matrice unitaire Z des vecteurs
!>          de Schur.
!>          Si JOBVS = 'N', VS n'est pas référencée.
!
>

LDV

S 
!>          LDVS est INTEGER
!>          La dimension principale du tableau VS. LDVS >= 1 ; si
!>          JOBVS = 'V', LDVS >= N.
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) renvoie la valeur optimale de LWORK.
!
>

K 
!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= max(1,2*N).

RWOR

>

K 
!>          BWORK est un tableau LOGICAL, dimension (N)
!>          Non référencé si SORT = 'N'.
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale.
!>          > 0 : si INFO = i, et i est
!>               <= N : l'algorithme QR a échoué à calculer toutes les
!>                      valeurs propres ; les éléments 1:ILO-1 et i+1:N de W
!>                      contiennent les valeurs propres qui ont convergé ;
!>                      si JOBVS = 'V', VS contient la matrice qui
!>                      réduit A à sa forme de Schur partiellement convergée.
!>               = N+1 : les valeurs propres n'ont pas pu être réordonnées car
!>                      certaines valeurs propres étaient trop proches pour être
!>                      séparées (le problème est très mal conditionné) ;
!>               = N+2 : après réordonnancement, l'arrondi a modifié les valeurs
!>                      de certaines valeurs propres complexes de sorte que les
!>                      valeurs propres principales dans la forme de Schur ne
!>                      satisfassent plus SELECT = .TRUE.. Cela peut aussi être
!>                      causé par un débordement dû à la mise à l'échelle.
!

sous-routine zgees (character jobvs, character sort, external select, integer n, complex*16, dimension( lda, * ) a, integer lda, integer sdim, complex*16, dimension( * ) w, complex*16, dimension( ldvs, * ) vs, integer ldvs, complex*16, dimension( * ) work, integer lwork, double precision, dimension( * ) rwork, logical, dimension( * ) bwork, integer info)

ZGEES calcule les valeurs propres, la forme de Schur, et, facultativement, la matrice des vecteurs de Schur pour les matrices GE

Objectif :

!>
!> ZGEES calcule pour une matrice complexe N-par-N non symétrique A, les
!> valeurs propres, la forme de Schur T, et, facultativement, la matrice des vecteurs de Schur Z.  Ceci donne la factorisation de Schur A = Z*T*(Z**H).
!>
!> Facultativement, elle ordonne également les valeurs propres sur la diagonale de la
!> forme de Schur de sorte que les valeurs propres sélectionnées soient en haut à gauche.
!> Les colonnes principales de Z forment alors une base orthonormée pour le
!> sous-espace invariant correspondant aux valeurs propres sélectionnées.
!>
!> Une matrice complexe est en forme de Schur si elle est triangulaire supérieure.
!>

Paramètres

JOBVS 
!>          JOBVS est de type CHARACTER*1
!>          = 'N': les vecteurs de Schur ne sont pas calculés;
!>          = 'V': les vecteurs de Schur sont calculés.
!>

SORT

!>          SORT est de type CHARACTER*1
!>          Spécifie si les valeurs propres doivent être ordonnées ou non sur la
!>          diagonale de la forme de Schur.
!>          = 'N': les valeurs propres ne sont pas ordonnées:
!>          = 'S': les valeurs propres sont ordonnées (voir SELECT).
!>

SELECT

!>          SELECT est une FONCTION LOGIQUE d'un argument COMPLEX*16
!>          SELECT doit être déclarée EXTERNAL dans la sous-routine appelante.
!>          Si SORT = 'S', SELECT est utilisé pour sélectionner les valeurs propres à ordonner
!>          en haut à gauche de la forme de Schur.
!>          Si SORT = 'N', SELECT n'est pas référencé.
!>          La valeur propre W(j) est sélectionnée si SELECT(W(j)) est vrai.
!>

N

!>          N est de type INTEGER
!>          L'ordre de la matrice A. N >= 0.
!>

A

!>          A est un tableau de type COMPLEX*16, de dimension (LDA,N)
!>          À l'entrée, A contient la matrice N-par-N A.
!>          À la sortie, A a été écrasée par sa forme de Schur T.
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

SDIM

!>          SDIM est de type INTEGER
!>          Si SORT = 'N', SDIM = 0.
!>          Si SORT = 'S', SDIM = nombre de valeurs propres pour lesquelles
!>                         SELECT est vrai.
!>

W

!>          W est un tableau de type COMPLEX*16, de dimension (N)
!>          W contient les valeurs propres calculées, dans le même ordre que
!>          celui où elles apparaissent sur la diagonale de la forme de Schur de sortie T.
