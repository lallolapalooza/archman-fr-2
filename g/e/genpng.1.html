genpng(1) Manuel de l'utilisateur genpng(1)

NOM

genpng - Générer une image de synthèse à partir d'un fichier source

SYNTAXE

genpng [-h|--help] [-v|--version]


[-t|--tab-size taille_tabulation] [-w|--width largeur] [-d|--dark-mode]
[-o|--output-filename nom_fichier_sortie]
fichier_source

DESCRIPTION

genpng crée une image de synthèse pour un fichier source donné, soit en texte brut, soit au format .gcov.

Notez que le module Perl GD.pm doit être installé pour que ce script fonctionne (il peut être obtenu sur http://www.cpan.org).

Notez également que genpng est appelé depuis genhtml, il n'est donc généralement pas nécessaire de l'appeler directement.

OPTIONS

-h
--help

Affiche un court message d'aide, puis quitte.

-v
--version

Affiche le numéro de version, puis quitte.

-t taille_tabulation
--tab-size taille_tabulation

Utilise taille_tabulation espaces à la place des tabulations.

Toutes les occurrences de caractères de tabulation dans le fichier source seront remplacées par le nombre d'espaces défini par taille_tabulation (la valeur par défaut est 4).

-w largeur
--width largeur

Définit la largeur de l'image de sortie à largeur pixel.

L'image résultante aura exactement largeur pixel de large (la valeur par défaut est 80).

Notez que les lignes de code source plus longues que largeur seront tronquées.

-d
--dark-mode

Utilise un schéma de couleurs avec affichage clair sur fond sombre plutôt que le schéma par défaut d'affichage sombre sur fond clair.

-o nom_fichier
--output-filename nom_fichier

Écrit l'image dans nom_fichier.

Spécifie un nom pour le fichier image résultant (la valeur par défaut est fichier_source.png).
