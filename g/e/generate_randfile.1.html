generate_randfile(1) Manuel des commandes générales generate_randfile(1)

NOM

generate_randfile - un programme pour générer un fichier de données aléatoires

SYNTAXE

generate_randfile [ -s seed] [ -f fichier] compte

DESCRIPTION

Produit un fichier composé d'entiers aléatoires en ordre d'octet réseau provenant de l'appel à la librairie rand(3).

OPTIONS

-s
la graine à utiliser pour créer les nombres aléatoires.
-f
le fichier à créer pour écrire la sortie (par défaut, utiliser la sortie standard).
compte
le nombre d'entiers à écrire.

VOIR AUSSI

rand(3)
