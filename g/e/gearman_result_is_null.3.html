Compiler et lier avec -lgearman

DESCRIPTION

Le type gearman_result_st représente un jeu de résultats. gearman_aggregator_fn est passé à ces types qu'il utilise pour créer un résultat final qui est retourné au client.

gearman_task_result() retourne gearman_result_st à partir d'un gearman_task_st.

Un gearman_result_st peut retourner la valeur résultante soit sous forme de pointeur char, booléen, gearman_string_t, ou int64_t.
