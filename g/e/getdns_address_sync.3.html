getdns_address(3) getdns getdns_address(3)

NOM

getdns_address, getdns_address_sync -- obtenir des adresses IP pour un nom

BIBLIOTHÈQUE

Bibliothèque de résolution DNS (libgetdns, -lgetdns)

SYNTAXE

#include <getdns.h>

getdns_return_t
getdns_address (getdns_context *context,

const char *name,
getdns_dict *extensions,
void *userarg,
getdns_transaction_t *transaction_id,
getdns_callback_t callbackfn)

getdns_return_t
getdns_address_sync (getdns_context *context,

const char *name,
getdns_dict *extensions,
getdns_dict **response)

DESCRIPTION

Les fonctions getdns_address(3) et getdns_address_sync fournissent des points d'entrée publics dans la bibliothèque API getdns pour récupérer l'adresse étant donné un nom d'hôte. Elles renvoient toujours les adresses IPv4 et IPv6. Cette fonction utilisera tous les espaces de noms du contexte (pour mieux émuler getaddrinfo (3)).

context Un pointeur vers le contexte DNS précédemment créé qui doit être utilisé avec cette requête DNS. voir getdns_context (3)

name le nom d'hôte à résoudre en une adresse (notez qu'une adresse IP est considérée comme invalide)

extensions extensions pour cette requête, NULL s'il n'y a pas d'extensions, voir libgetdns (3) pour une description détaillée des extensions

userarg renvoyé à la fonction de rappel sans modification, peut être NULL

transaction_id rempli par l'API et utilisé pour identifier le rappel (par exemple pour getdns_cancel_callback), peut être NULL, mis à 0 si la fonction échoue

callbackfn pointeur non NULL vers une fonction de rappel définie par l'application, généralement utilisée pour traiter la réponse. Seule la signature asynchrone accepte une fonction de rappel, la signature synchrone n'inclut pas de rappel. Voir libgetdns (3) pour une discussion plus détaillée sur les fonctions de rappel.

response Un type getdns_dict est renvoyé en réponse et contient toujours au moins trois noms : replies_full (une liste contenant la réponse DNS sous forme de données binaires), replies_tree (une liste contenant les données de réponse DNS analysées) et status (un entier). Le stockage associé à ceci doit être libéré par un appel à getdns_free_sync_request_memory (3).

VALEURS DE RETOUR

En cas de succès, les fonctions renvoient GETDNS_RETURN_GOOD , sinon les valeurs d'erreur suivantes sont renvoyées :

GETDNS_RETURN_BAD_CONTEXT si le pointeur de contexte est invalide ou si le contexte présente des lacunes internes

GETDNS_RETURN_BAD_DOMAIN_NAME si le nom de domaine passé à la fonction est invalide

GETDNS_RETURN_EXTENSION_MISFORMAT si le type de données spécifié dans une ou plusieurs extensions ne correspond pas aux spécifications

GETDNS_RETURN_GENERIC_ERROR si un problème est survenu dans la fonction et qui n'est pas couvert par l'un des codes de retour plus spécifiques

GETDNS_RETURN_INVALID PARAMETER si un ou plusieurs paramètres ont une valeur invalide

GETDNS_RETURN_MEMORY_ERROR si la mémoire requise n'a pas pu être allouée

GETDNS_RETURN_NO_SUCH_EXTENSION si une ou plusieurs des chaînes spécifiées dans les extensions ne sont pas valides

Les valeurs de status incluses dans le paramètre de réponse sont :

GETDNS_RESPSTATUS_GOOD si au moins une réponse a été renvoyée

GETDNS_RESPSTATUS_NO_NAME si les requêtes pour le nom ont produit toutes des réponses négatives

GETDNS_RESPSTATUS_ALL_TIMEOUT si toutes les requêtes pour le nom ont expiré

GETDNS_RESPSTATUS_NO_SECURE_ANSWERS si seules les réponses sécurisées sont acceptées (par contexte) et qu'au moins une réponse a été reçue mais qu'aucune réponse DNS n'était sécurisée via DNSSEC

Pour une explication plus détaillée de l'objet réponse, voir libgetdns (3)
