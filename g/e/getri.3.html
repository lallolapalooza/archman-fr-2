Documentation de la fonction

subroutine cgetri (integer n, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( * ) work, integer lwork, integer info)

CGETRI

But :

!>
!> CGETRI calcule l'inverse d'une matrice en utilisant la factorisation LU
!> calculée par CGETRF.
!>
!> Cette méthode inverse U puis calcule inv(A) en résolvant le système
!> inv(A)*L = inv(U) pour inv(A).
!>

Paramètres

N 
!>          N est INTEGER
!>          L'ordre de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, les facteurs L et U de la factorisation
!>          A = P*L*U telle que calculée par CGETRF.
!>          À la sortie, si INFO = 0, l'inverse de la matrice originale A.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV est un tableau INTEGER, dimension (N)
!>          Les indices de pivot de CGETRF ; pour 1<=i<=N, la ligne i de la
!>          matrice a été échangée avec la ligne IPIV(i).
!>

WORK

!>          WORK est un tableau COMPLEX, dimension (MAX(1,LWORK))
!>          À la sortie, si INFO=0, alors WORK(1) renvoie le LWORK optimal.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK.  LWORK >= max(1,N).
!>          Pour des performances optimales LWORK >= N*NB, où NB est
!>          la taille de bloc optimale renvoyée par ILAENV.
!>
!>          Si LWORK = -1, une interrogation d'espace de travail est supposée ; la routine
!>          ne calcule que la taille optimale du tableau WORK, renvoie
!>          cette valeur comme première entrée du tableau WORK, et aucun message
!>          d'erreur lié à LWORK n'est émis par XERBLA.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie
!>          < 0:  si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0:  si INFO = i, U(i,i) est exactement zéro ; la matrice est
!>                singulière et son inverse n'a pas pu être calculé.
!>
