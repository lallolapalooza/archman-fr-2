DESCRIPTIO

N

La fonction getaddrinfo_a() effectue la même tâche que getaddrinfo(3), mais permet d'effectuer plusieurs recherches de noms de manière asynchrone, avec une notification facultative à la fin des opérations de

recherche.

L'argument mode peut prendre l'une des valeurs suivantes

:
GAI_WA
IT
Effectue les recherches de manière synchrone. L'appel se bloque jusqu'à ce que les recherches soient
terminées.
GAI_NOWA
IT
Effectue les recherches de manière asynchrone. L'appel retourne immédiatement et les requêtes sont résolues en arrière-plan. Voir la discussion de l'argument sevp ci-
dess
ous.

Le tableau list spécifie les requêtes de recherche à traiter. L'argument n spécifie le nombre d'éléments dans list. Les opérations de recherche demandées sont lancées en parallèle. Les éléments NULL dans list sont ignorés. Chaque requête est décrite par une structure gaicb définie comme suit

: 


struct gaicb {
    const char            *ar_name;
    const char            *ar_service;
    const struct addrinfo *ar_request;
    struct addrinfo       *ar_result;
}
;

Les éléments de cette structure correspondent aux arguments de getaddrinfo(3). Ainsi, ar_name correspond à l'argument node et ar_service à l'argument service, identifiant un hôte Internet et un service. L'élément ar_request correspond à l'argument hints, spécifiant les critères de sélection des structures d'adresse de socket retournées. Enfin, ar_result correspond à l'argument res ; vous n'avez pas besoin d'initialiser cet élément, il sera défini automatiquement lorsque la requête sera résolue. La structure addrinfo référencée par les deux derniers éléments est décrite dans getaddrinf

o(3).

Lorsque mode est spécifié comme GAI_NOWAIT, des notifications sur les requêtes résolues peuvent être obtenues en utilisant la structure sigevent pointée par l'argument sevp. Pour la définition et les détails généraux de cette structure, voir sigevent(3type). Le champ sevp->sigev_notify peut prendre les valeurs suivantes

:
SIGEV_NO
NE
Ne fournit aucune
notification.
SIGEV_SIGN
AL
Lorsqu'une recherche se termine, génère le signal sigev_signo pour le processus. Voir sigevent(3type) pour les détails généraux. Le champ si_code de la structure siginfo_t sera défini à SI_ASYNCN
L.
SIGEV_THRE
AD
Lorsqu'une recherche se termine, appelle sigev_notify_function comme s'il s'agissait de la fonction de démarrage d'un nouveau fil. Voir sigevent(3type) pour
le
s détails.

Pour SIGEV_SIGNAL et SIGEV_THREAD, il peut être utile de faire pointer sevp->sigev_value.sival_ptr vers list

.

La fonction gai_suspend() suspend l'exécution du fil appelant, attendant la fin d'une ou plusieurs requêtes dans le tableau list. L'argument n spécifie la taille du tableau list. L'appel se bloque jusqu'à ce que l'un des événements suivants se produise

:
•
L'une ou plusieurs des opérations dans list se
terminent.
•
L'appel est interrompu par un signal qui est
capté.
•
L'intervalle de temps spécifié dans timeout s'écoule. Cet argument spécifie un délai d'attente en secondes plus nanosecondes (voir nanosleep(2) pour les détails de la structure timespec). Si timeout est NULL, l'appel se bloque indéfiniment (jus
qu'à ce que l'un des événemen
ts ci-dessus se produise).

Aucune indication explicite n'est donnée sur la requête qui s'est terminée ; vous devez déterminer quelles requêtes se sont terminées en itérant avec gai_error() sur la liste des

requêtes.

La fonction gai_error() retourne l'état de la requête req : soit EAI_INPROGRESS si la requête n'est pas encore terminée, 0 si elle a été traitée avec succès, ou un code d'erreur si la requête n'a pas pu être

résolue.

La fonction gai_cancel() annule la requête req. Si la requête a été annulée avec succès, l'état d'erreur de la requête sera défini à EAI_CANCELED et la notification asynchrone normale sera effectuée. La requête ne peut pas être annulée si elle est en cours de traitement ; dans ce cas, elle sera traitée comme si gai_cancel() n'avait jamais été appelé. Si req est NULL, une tentative est faite pour annuler tou

tes les requêtes en attente q
ue le processus a émises.

NAME

getaddrinfo_a, gai_suspend, gai_error, gai_cancel - énumérer les interfaces réseau et adresses associées, de manière asynchrone

LIBRARY

Vérification de compatibilité C POSIX (libc), GNU extensions (libpthread)

SYNOPSIS

#include <netdb.h>
int getaddrinfo_a(int mode, struct gaicb *const gailist[], size_t nwait,
                  int *errcode_p);
int gai_suspend(const struct gaicb *const gailist[], size_t nwait,
                struct timespec *timeout);
int gai_error(const struct gaicb *req);
int gai_cancel(struct gaicb *req);

DESCRIPTION

Ces interfaces, introduites par glibc, fournissent une interface asynchrone pour la résolution de noms d'hôte et de services, similaire à l'interface de sous-programmes de saisie/sortie groupée.

La structure gaicb est utilisée pour représenter une requête de résolution. Ses champs principaux sont :

ar_name
Nom d'hôte ou chaîne de service à résoudre.
ar_socktype
Type de socket désiré (par exemple, SOCK_STREAM).
ar_family
Famille d'adresses désirée (par exemple, AF_INET).
ar_protocol
Protocole désiré (par exemple, IPPROTO_TCP).
ar_addrconfig
Indicateurs de configuration d'adresse.
ar_result
Pointeur vers un pointeur où sera stocké le résultat de getaddrinfo.
ar_service
Pointeur vers une chaîne représentant le service, utilisé pour obtenir des informations sur les services.
ar_flags
Indicateurs supplémentaires pour la résolution.

getaddrinfo_a : Lance une ou plusieurs requêtes de résolution d'adresses. Le mode peut être :

GAI_WAIT
Attend que toutes les requêtes spécifiées soient terminées.
GAI_NOWAIT
Lance les requêtes et retourne immédiatement. Les résultats doivent être interrogés plus tard à l'aide de gai_error.

gai_suspend : Attend que l'une des requêtes spécifiées dans gailist soit terminée. Le paramètre timeout spécifie la durée maximale d'attente.

gai_error : Récupère le code d'erreur pour une requête gaicb spécifique.

gai_cancel : Annule une requête gaicb en cours.

RETURN VALUE

Les fonctions getaddrinfo_a et gai_suspend retournent 0 en cas de succès, ou un code d'erreur POSIX. Les erreurs spécifiques à getaddrinfo peuvent être récupérées à l'aide de gai_strerror.

gai_error retourne le code d'erreur pour la requête.

gai_cancel retourne 0 si l'annulation a réussi, EAI_NOTCANCELED si la requête était déjà terminée ou annulée, ou un autre code d'erreur.

EXAMPLES

Deux exemples sont fournis : un exemple simple qui résout plusieurs requêtes en parallèle de manière synchrone, et un exemple complexe montrant certaines des capacités asynchrones.

Exemple synchrone

Le programme ci-dessous résout simplement plusieurs noms d'hôtes en parallèle, offrant un gain de vitesse par rapport à la résolution des noms d'hôtes séquentiellement à l'aide de getaddrinfo(3). Le programme peut être utilisé comme suit :


$ ./a.out mirrors.kernel.org enoent.linuxfoundation.org gnu.org;
mirrors.kernel.org: 139.178.88.99
enoent.linuxfoundation.org: Nom ou service inconnu
gnu.org: 209.51.188.116

Voici le code source du programme

#define _GNU_SOURCE
#include <err.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define MALLOC(n, type)  ((type *) reallocarray(NULL, n, sizeof(type)))
int
main(int argc, char *argv[])
{
    int ret;
    struct gaicb *reqs[argc - 1];
    char host[NI_MAXHOST];
    struct addrinfo *res;
    if (argc < 2) {
        fprintf(stderr, "Usage: %s HOST...\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    for (size_t i = 0; i < argc - 1; i++) {
        reqs[i] = MALLOC(1, struct gaicb);
        if (reqs[i] == NULL)
            err(EXIT_FAILURE, "malloc");
        memset(reqs[i], 0, sizeof(*reqs[0]));
        reqs[i]->ar_name = argv[i + 1];
    }
    ret = getaddrinfo_a(GAI_WAIT, reqs, argc - 1, NULL);
    if (ret != 0) {
        fprintf(stderr, "getaddrinfo_a() failed: %s\n",
                gai_strerror(ret));
        exit(EXIT_FAILURE);
    }
    for (size_t i = 0; i < argc - 1; i++) {
        printf("%s: ", reqs[i]->ar_name);
        ret = gai_error(reqs[i]);
        if (ret == 0) {
            res = reqs[i]->ar_result;
            ret = getnameinfo(res->ai_addr, res->ai_addrlen,
                              host, sizeof(host),
                              NULL, 0, NI_NUMERICHOST);
            if (ret != 0) {
                fprintf(stderr, "getnameinfo() failed: %s\n",
                        gai_strerror(ret));
                exit(EXIT_FAILURE);
            }
            puts(host);
        } else {
            puts(gai_strerror(ret));
        }
    }
    exit(EXIT_SUCCESS);
}

Exemple asynchrone

Cet exemple montre une interface simple et interactive pour getaddrinfo_a(). La fonctionnalité de notification n'est pas démontrée.

Une session d'exemple pourrait ressembler à ceci :


$ ./a.out;

> c 2

> w 0 1
[00] mirrors.kernel.org: Terminé
> l

[01] enoent.linuxfoundation.org: Traitement de la requête en cours
[02] gnu.org: 209.51.188.116
> l
[00] mirrors.kernel.org: 139.178.88.99
[01] enoent.linuxfoundation.org: Nom ou service inconnu
[02] gnu.org: 209.51.188.116

La source du programme est la suivante :

#define _GNU_SOURCE
#include <assert.h>
#include <err.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define CALLOC(n, type)  ((type *) calloc(n, sizeof(type)))
#define REALLOCF(ptr, n, type)                                          \
({                                                                      \
    static_assert(__builtin_types_compatible_p(typeof(ptr), type *));   \
                                                                        \
    (type *) reallocarrayf(ptr, n, sizeof(type));                       \
})
static struct gaicb **reqs = NULL;
static size_t nreqs = 0;
static inline void *
reallocarrayf(void *p, size_t n, size_t size)
{
    void  *q;
    q = reallocarray(p, n, size);
    if (q == NULL && n != 0 && size != 0)
        free(p);
    return q;
}
static char *
getcmd(void)
{
    static char buf[256];
    fputs("> ", stdout);
    fflush(stdout);
    if (fgets(buf, sizeof(buf), stdin) == NULL)
        return NULL;
    if (buf[strlen(buf) - 1] == '\n')
        buf[strlen(buf) - 1] = 0;
    return buf;
}
/* Ajoute des requêtes pour les noms d'hôtes spécifiés.  */
static void
add_requests(void)
{
    size_t nreqs_base = nreqs;
    char *host;
    int ret;
    while ((host = strtok(NULL, " "))) {
        nreqs++;
        reqs = REALLOCF(reqs, nreqs, struct gaicb *);
        if (reqs == NULL)
            err(EXIT_FAILURE, "reallocf");
        reqs[nreqs - 1] = CALLOC(1, struct gaicb);
        if (reqs[nreqs - 1] == NULL)
            err(EXIT_FAILURE, "calloc");
        reqs[nreqs - 1]->ar_name = strdup(host);
    }
    /* Met en file d'attente les requêtes nreqs_base..nreqs.  */
    ret = getaddrinfo_a(GAI_NOWAIT, &reqs[nreqs_base],
                        nreqs - nreqs_base, NULL);
    if (ret) {
        fprintf(stderr, "getaddrinfo_a() failed: %s\n",
                gai_strerror(ret));
        exit(EXIT_FAILURE);
    }
}
/* Attend qu'au moins une des requêtes spécifiées soit terminée.  */
static void
wait_requests(void)
{
    char *id;
    int ret;
    size_t n;
    struct gaicb const **wait_reqs;
    wait_reqs = CALLOC(nreqs, const struct gaicb *);
    if (wait_reqs == NULL)
        err(EXIT_FAILURE, "calloc");
                /* Les éléments NULL sont ignorés par gai_suspend().  */
    while ((id = strtok(NULL, " ")) != NULL) {
        n = atoi(id);
        if (n >= nreqs) {
            printf("Mauvais numéro de requête : %s\n", id);
            return;
        }
        wait_reqs[n] = reqs[n];
    }
    ret = gai_suspend(wait_reqs, nreqs, NULL);
    if (ret) {
        printf("gai_suspend(): %s\n", gai_strerror(ret));
        return;
    }
    for (size_t i = 0; i < nreqs; i++) {
        if (wait_reqs[i] == NULL)
            continue;
        ret = gai_error(reqs[i]);
        if (ret == EAI_INPROGRESS)
            continue;
        printf("[%02zu] %s: %s\n", i, reqs[i]->ar_name,
               ret == 0 ? "Terminé" : gai_strerror(ret));
    }
}
/* Annule les requêtes spécifiées.  */
static void
cancel_requests(void)
{
    char *id;
    int ret;
    size_t n;
    while ((id = strtok(NULL, " ")) != NULL) {
        n = atoi(id);
        if (n >= nreqs) {
            printf("Mauvais numéro de requête : %s\n", id);
            return;
        }
        ret = gai_cancel(reqs[n]);
        printf("[%s] %s: %s\n", id, reqs[atoi(id)]->ar_name,
               gai_strerror(ret));
    }
}
/* Liste toutes les requêtes.  */
static void
list_requests(void)
{
    int ret;
    char host[NI_MAXHOST];
    struct addrinfo *res;
    for (size_t i = 0; i < nreqs; i++) {
        printf("[%02zu] %s: ", i, reqs[i]->ar_name);
        ret = gai_error(reqs[i]);
        if (!ret) {
            res = reqs[i]->ar_result;
            ret = getnameinfo(res->ai_addr, res->ai_addrlen,
                              host, sizeof(host),
                              NULL, 0, NI_NUMERICHOST);
            if (ret) {
                fprintf(stderr, "getnameinfo() failed: %s\n",
                        gai_strerror(ret));
                exit(EXIT_FAILURE);
            }
            puts(host);
        } else {
            puts(gai_strerror(ret));
        }
    }
}
int
main(void)
{
    char *cmdline;
    char *cmd;
    while ((cmdline = getcmd()) != NULL) {
        cmd = strtok(cmdline, " ");
        if (cmd == NULL) {
            list_requests();
        } else {
            switch (cmd[0]) {
            case 'a':
                add_requests();
                break;
            case 'w':
                wait_requests();
                break;
            case 'c':
                cancel_requests();
                break;
            case 'l':
                list_requests();
                break;
            default:
                fprintf(stderr, "Mauvaise commande : %c\n", cmd[0]);
                break;
            }
        }
    }
    exit(EXIT_SUCCESS);
}
