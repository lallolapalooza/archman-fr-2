gearman_client_add_task_low_background(3)

GEARMAN_CLIENT_ADD_TASK_LOW_BACKGROUND(3) Gearmand GEARMAN_CLIENT_ADD_TASK_LOW_BACKGROUND(3)

NOM

gearman_client_add_task_low_background - Documentation Gearmand, https://gearman.org/gearmand/

SYNTAXE

#include <libgearman/gearman.h>

gearman_task_st *gearman_client_add_task_background(gearman_client_st *client, gearman_task_st *task, void *context, const char *function_name, const char *unique, const void *workload, size_t workload_size, gearman_return_t *ret_ptr)
gearman_task_st *gearman_client_add_task_high_background(gearman_client_st *client, gearman_task_st *task, void *context, const char *function_name, const char *unique, const void *workload, size_t workload_size, gearman_return_t *ret_ptr)
gearman_task_st *gearman_client_add_task_low_background(gearman_client_st *client, gearman_task_st *task, void *context, const char *function_name, const char *unique, const void *workload, size_t workload_size, gearman_return_t *ret_ptr)

Lier avec -lgearman

DESCRIPTION

gearman_client_add_task_background() crée une tâche d'arrière-plan et l'ajoute au gearman_client_st donné. L'exécution de la tâche ne commence que lorsque gearman_client_run_tasks() est appelé.

Si la valeur unique n'est pas définie, une valeur unique sera attribuée.

gearman_client_add_task_high_background() et gearman_client_add_task_low_background() sont identiques à gearman_client_do(), mais elles définissent la priorité à élevée ou basse.

ATTENTION :

Vous pourriez vouloir éviter d'utiliser gearman_client_add_task_background() avec un gearman_task_st alloué sur la pile. Les problèmes les plus courants liés à la sécurité de l'ABI impliquent des structures allouées sur la pile. Si vous utilisez un gearman_task_st alloué sur la pile, vous devez le libérer avec gearman_task_free().

VALEUR DE RETOUR

Le gearman_task_st est créé et un pointeur vers celui-ci est retourné. En cas d'erreur, NULL est retourné et ret_ptr est défini avec une gearman_return_t.
