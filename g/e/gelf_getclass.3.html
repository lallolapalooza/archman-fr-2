NOM

gelf_getclass - renvoie la classe ELF (32 bits ou 64 bits) d'un objet

SYNTAXE

#include <gelf.h>
int gelf_getclass(Elf *elf);

DESCRIPTION

gelf_getclass() renvoie la classe de l'objet ELF référencé par elf. La classe d'un fichier ELF valide sera l'une des suivantes :

ELFCLASS32
L'objet est une classe ELF 32 bits.
ELFCLASS64
L'objet est une classe ELF 64 bits.

Si elf ne désigne pas un objet ELF valide, ou si la classe ne peut pas être déterminée, ELFCLASSNONE est renvoyé.

VALEUR DE RETOUR

Renvoie ELFCLASS32 ou ELFCLASS64 en cas de succès. Si elf est NULL ou ne fait pas référence à un binaire ELF valide avec le type ELF_K_ELF, alors ELFCLASSNONE est renvoyé.

VOIR AUSSI

elf_kind(3), libelf(3), elf(5)
