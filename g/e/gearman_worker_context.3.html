DESCRIPTION

gearman_worker_st est utilisé pour la communication des travailleurs avec le serveur.

gearman_worker_context() et gearman_worker_set_context() peuvent être utilisés pour stocker un objet arbitraire pour l'utilisateur.

gearman_worker_set_task_context_free_fn() définit un déclencheur qui sera appelé lorsqu'une gearman_task_st est libérée.

gearman_worker_timeout() et gearman_worker_set_timeout() obtiennent et définissent la valeur de timeout actuelle, en millisecondes, pour le travailleur.

gearman_worker_function_exist() est utilisé pour déterminer si un travailleur donné a une fonction spécifique.

gearman_worker_work() fait exécuter au travailleur des tâches jusqu'à ce qu'une erreur survienne.

gearman_worker_grab_job() prend un travail à partir de l'un des serveurs de travaux. Il incombe à l'appelant de libérer le travail une fois terminé. Cette interface est utilisée dans les tests et est très rarement l'interface correcte sur laquelle programmer.

Normalement, malloc(3) et free(3) sont utilisés pour l'allocation et la libération des charges de travail. gearman_worker_set_workload_malloc_fn() et gearman_worker_set_workload_free_fn() peuvent être utilisés pour les remplacer par des fonctions personnalisées.

Si vous avez besoin de supprimer une fonction du serveur, vous pouvez appeler soit gearman_worker_unregister_all() pour supprimer toutes les fonctions dont le travailleur a informé le serveur gearmand, soit utiliser gearman_worker_unregister() pour supprimer une seule fonction.
