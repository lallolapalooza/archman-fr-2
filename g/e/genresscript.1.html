GENRESSCRIPT(1) Manuel des commandes générales GENRESSCRIPT(1)

NOM

genresscript - générer un script de ressources à partir de binaires PE et NE

SYNTAXE

genresscript [FICHIER]...

DESCRIPTION

Cette page de manuel documente brièvement la commande genresscript. Cette page de manuel a été écrite pour la distribution Debian GNU car le programme original ne possède pas de page de manuel.

Genresscript prend un ou plusieurs binaires PE ou NE, et génère un script de ressources avec toutes les ressources des binaires listées. (Tout, sauf le nom de fichier de destination, sera rempli dans le script.) Ceci est utile lorsque vous avez déjà extrait des images et que vous souhaitez créer un script de ressources pour elles.

OPTIONS

-t
--type=ID
lister les ressources de ce type au lieu de group_icon
-b
--base=CHEMIN
le nom d'extraction par défaut de toutes les ressources
-s
--sort
trier alphabétiquement au lieu d'utiliser l'ordre dans le binaire
--help
afficher cette aide et quitter
--version
afficher les informations de version et quitter

VOIR AUSSI

extresso(1), icotool(1), wrestool(1).
