GEARADMIN(1) Gearmand GEARADMIN(1)

NOM

gearadmin - Documentation Gearmand, https://gearman.org/gearmand/

Exécute des commandes administratives contre un serveur.

SYNTAXE

--help
Fournit de l'aide sur le programme.
--create-function
Crée une fonction depuis le serveur.
-h [ --host ] argument (=localhost)i
Se connecte à l'hôte.
-p [ --port ] argument (=4730)
Numéro de port ou service à utiliser pour la connexion.
--drop-function
Supprime une fonction du serveur.
--server-version
Récupère le numéro de version du serveur.
--server-verbose
Récupère le réglage de verbosité du serveur.
--status
Statut du serveur.
--workers
Travailleurs pour le serveur.
--cancel-job
Supprime un travail donné de la file d'attente du serveur.
--show-unique-jobs
Affiche les identifiants uniques des travaux sur le serveur.
--show-jobs
Affiche tous les travaux sur le serveur.
--getpid
Récupère l'ID de processus pour le serveur.
--priority-status
Statut des travaux mis en file d'attente par priorité.
-S [ --ssl ]
Active les connexions SSL.

DESCRIPTION

Outil en ligne de commande pour manipuler les serveurs gearmand.

ACCUEIL

Pour plus d'informations, veuillez consulter : https://gearman.org/gearmand/
