NOM

gensio_write - Écrire des données dans un gensio

SYNTAXE

#include <gensio/gensio.h>

int gensio_write(struct gensio *io, gensiods *count,

const void *buf, gensiods buflen,
const char *const *auxdata);

struct gensio_sg {

const void *buf;
gensiods buflen;
};
int gensio_write_sg(struct gensio *io, gensiods *count,

const struct gensio_sg *sg, gensiods sglen,
const char *const *auxdata);

DESCRIPTION

Écrit des données dans le gensio donné. Les données se trouvent dans buf et la longueur des données est dans buflen. Notez que gensio_write peut ne pas écrire toutes les données fournies, en fonction du type de gensio et de l'espace tampon interne. Il retournera le nombre d'octets effectivement écrits dans count, qui peut être NULL si cela ne vous intéresse pas. (Indice : cela devrait presque toujours vous intéresser.)

Si gensio_write ne parvient pas à écrire la totalité de la quantité de données, vous devez généralement mettre en tampon les données non écrites et appeler gensio_set_write_callback_enable(3) pour savoir quand vous pouvez écrire le reste des données. De nombreuses applications mettent toujours les données en tampon et activent la fonction de rappel d'écriture pour effectuer l'écriture, puis désactivent la fonction de rappel d'écriture une fois toutes les données écrites, pour des raisons de cohérence.

gensio_write ne bloquera jamais ; s'il ne peut pas écrire toutes les données, il écrira ce qu'il peut et retournera.

auxdata est utilisé pour passer des données auxiliaires spécifiques au gensio, telles que le numéro de flux pour SCTP ou si les données sont des données hors bande pour SCTP ou TCP.

gensio_write_sg est similaire à gensio_write, mais il prend une structure scatter-gather pour vous permettre de combiner plusieurs blocs de données sans copie. Notez que si vous obtenez une écriture partielle, vous devez déterminer où l'écriture s'est terminée dans votre liste scatter-gather et commencer la prochaine écriture à partir de là.

VALEURS DE RETOUR

Zéro est retourné en cas de succès, ou une erreur gensio en cas d'échec.

VOIR AUSSI

gensio_err(3), gensio(5)
