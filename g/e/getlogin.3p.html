GETLOGIN(3P) Manuel du programmeur POSIX GETLOGIN(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consulter la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

getlogin, getlogin_r — obtenir le nom de connexion

SYNTAXE

#include <unistd.h>
char *getlogin(void);
int getlogin_r(char *name, size_t namesize);

DESCRIPTION

La fonction getlogin() renvoie un pointeur vers une chaîne contenant le nom d'utilisateur associé par l'activité de connexion au terminal de contrôle du processus courant. Si getlogin() renvoie un pointeur non nul, ce pointeur pointe vers le nom sous lequel l'utilisateur s'est connecté, même s'il existe plusieurs noms de connexion avec le même identifiant utilisateur.

La fonction getlogin() n'est pas nécessairement thread-safe.

La fonction getlogin_r() place le nom associé par l'activité de connexion au terminal de contrôle du processus courant dans le tableau de caractères pointé par name. Le tableau a une taille de namesize caractères et doit avoir de la place pour le nom et le caractère nul de fin. La taille maximale du nom de connexion est {LOGIN_NAME_MAX}.

Si getlogin_r() réussit, name pointe vers le nom que l'utilisateur a utilisé lors de la connexion, même s'il existe plusieurs noms de connexion avec le même identifiant utilisateur.

Les fonctions getlogin() et getlogin_r() peuvent utiliser les descripteurs de fichiers 0, 1 et 2 pour trouver le terminal de contrôle du processus courant, en examinant chacun à tour de rôle jusqu'à ce que le terminal soit trouvé. Si, dans ce cas, aucun de ces trois descripteurs de fichiers n'est ouvert sur le terminal de contrôle, ces fonctions peuvent échouer. La méthode utilisée pour trouver le terminal associé à un descripteur de fichier peut dépendre du fait que le descripteur de fichier soit ouvert sur le périphérique de terminal réel, et non sur /dev/tty.

VALEUR DE RETOUR

En cas de succès, getlogin() renvoie un pointeur vers le nom de connexion ou un pointeur nul si le nom de connexion de l'utilisateur ne peut être trouvé. Sinon, elle renvoie un pointeur nul et définit errno pour indiquer l'erreur.

L'application ne doit pas modifier la chaîne renvoyée. Le pointeur renvoyé pourrait être invalidé ou le contenu de la chaîne pourrait être écrasé par un appel ultérieur à getlogin(). Le pointeur renvoyé et le contenu de la chaîne pourraient également être invalidés si le thread appelant est terminé.

En cas de succès, la fonction getlogin_r() renvoie zéro ; sinon, un numéro d'erreur est renvoyé pour indiquer l'erreur.

ERREURS

Ces fonctions peuvent échouer si :

EMFILE
Tous les descripteurs de fichiers disponibles pour le processus sont actuellement ouverts.
ENFILE
Le nombre maximal de fichiers autorisés est actuellement ouvert dans le système.
ENOTTY
Aucun des descripteurs de fichiers 0, 1 ou 2 n'est ouvert sur le terminal de contrôle du processus courant.
ENXIO
Le processus appelant n'a pas de terminal de contrôle.

La fonction getlogin_r() peut échouer si :

ERANGE
La valeur de namesize est inférieure à la longueur de la chaîne à renvoyer, y compris le caractère nul de fin.

Les sections suivantes sont informatives.

EXEMPLES

Obtenir le nom de connexion de l'utilisateur S

L'exemple suivant appelle la fonction getlogin() pour obtenir le nom de l'utilisateur associé au processus appelant, et passe ces informations à la fonction getpwnam() pour obtenir les informations associées de la base de données utilisateur.

#include <unistd.h>
#include <sys/types.h>
#include <pwd.h>
#include <stdio.h>
...
char *lgn;
struct passwd *pw;
...
if ((lgn = getlogin()) == NULL || (pw = getpwnam(lgn)) == NULL) {
    fprintf(stderr, "Échec de l'obtention des informations utilisateur.\n"); exit(1);
    }

USAGE APPLICATIF

Trois noms associés au processus courant peuvent être déterminés : getpwuid(geteuid()) renvoie le nom associé à l'identifiant utilisateur effectif du processus ; getlogin() renvoie le nom associé à l'activité de connexion courante ; et getpwuid(getuid()) renvoie le nom associé à l'identifiant utilisateur réel du processus.

La fonction getlogin_r() est thread-safe et renvoie les valeurs dans un tampon fourni par l'utilisateur au lieu d'utiliser éventuellement une zone de données statique qui peut être écrasée à chaque appel.

JUSTIFICATION

La fonction getlogin() renvoie un pointeur vers le nom de connexion de l'utilisateur. Le même identifiant utilisateur peut être partagé par plusieurs noms de connexion. S'il est souhaité obtenir l'entrée de la base de données utilisateur utilisée lors de la connexion, le résultat de getlogin() doit être utilisé pour fournir l'argument à la fonction getpwnam(). (Cela pourrait être utilisé pour déterminer le shell de connexion de l'utilisateur, en particulier lorsqu'un utilisateur unique a plusieurs shells de connexion avec des noms de connexion distincts, mais le même identifiant utilisateur.)

Les informations fournies par la fonction cuserid(), qui était initialement définie dans la norme POSIX.1-1988 et supprimée par la suite, peuvent être obtenues par :

getpwuid(geteuid())

tandis que les informations fournies par les implémentations historiques de cuserid() peuvent être obtenues par :

getpwuid(getuid())

La version thread-safe de cette fonction place le nom d'utilisateur dans un tampon fourni par l'utilisateur et renvoie une valeur non nulle en cas d'échec. La version non thread-safe peut renvoyer le nom dans une zone de données statique qui peut être écrasée à chaque appel.
