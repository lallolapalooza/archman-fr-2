gearman_string_t(3)

Paquet: gearmand

Licences: BSD-3-Clause

GEARMAN_STRING_T(3) Gearmand GEARMAN_STRING_T(3)

NOM

gearman_string_t - Documentation Gearmand, https://gearman.org/gearmand/

SYNOPSIS

#include <libgearman/gearman.h>

type gearman_string_t
gearman_size(string)
Retourne la taille de la chaîne.
gearman_c_str(string)
Retourne la représentation en chaîne C.

Compiler et lier avec -lgearman.

DESCRIPTION

Le type gearman_string_t est un type simple représentant une "chaîne". Une fois créées, les gearman_string_t ne sont pas mutables. Elles pointent uniquement vers les chaînes qui les définissent et ne nécessitent aucune désallocation.
