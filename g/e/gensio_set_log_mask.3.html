NOM

gensio_set_log_mask, gensio_get_log_mask, gensio_log_level_to_str, - Journalisation et définition des logs gensio à transmettre ou ignorer

SYNTAXE

#include <gensio/gensio.h>

void gensio_set_log_mask(unsigned int mask);
unsigned int gensio_get_log_mask(void);
const char *gensio_log_level_to_str(enum gensio_log_levels level);
void gensio_vlog(struct gensio_os_funcs *o,

enum gensio_log_levels level,
const char *str, va_list args);
void gensio_log(struct gensio_os_funcs *o,

enum gensio_log_levels level,
const char *str, ...);

DESCRIPTION

Le masque de journalisation est une variable globale de la bibliothèque gensio qui définit le niveau des logs transmis via le pointeur de fonction vlog dans gensio_os_funcs. Les niveaux de journalisation sont :

GENSIO_LOG_FATAL GENSIO_LOG_ERR GENSIO_LOG_WARNING GENSIO_LOG_INFO GENSIO_LOG_DEBUG

avec des significations évidentes. Il y a aussi :

GENSIO_LOG_MASK_ALL

qui est un masque de bits de tous les niveaux de journalisation.

Le masque de journalisation par défaut est (1 << GENSIO_LOG_FATAL | 1 << GENSIO_LOG_ERR). La définition d'autres valeurs de journalisation peut être utile pour déboguer des problèmes avec les gensios.

gensio_log_level_to_str convertit un niveau de journalisation en sa représentation textuelle.

gensio_vlog et gensio_log sont les fonctions utilisées pour générer les logs. Elles sont principalement destinées à l'usage dans la bibliothèque gensio, bien que vous puissiez les utiliser également si vous le souhaitez.
