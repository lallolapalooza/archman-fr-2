GEARMAN_SUCCESS(3) Gearmand GEARMAN_SUCCESS(3)

NOM

gearman_success - Documentation de Gearmand, https://gearman.org/gearmand/

SYNOPSISSE

#include <libgearman/gearman.h>

type gearman_return_t
const char *gearman_strerror(gearman_return_t rc)
bool gearman_success(gearman_return_t rc)
bool gearman_failed(gearman_return_t rc)
bool gearman_continue(gearman_return_t rc)

Compiler et lier avec -lgearman

DESCRIPTION

gearman_return_t est utilisé comme type de retour/erreur pour tous les appels utilisant gearman_client_st et gearman_worker_st. GEARMAN_SUCCESS est retourné en cas de succès, sinon une erreur est retournée. gearman_failed() peut être utilisé pour vérifier si la valeur de retour est une valeur d'échec. Vous pouvez imprimer une version textuelle du message d'erreur avec gearman_strerror().

gearman_success() retourne true si GEARMAN_SUCCESS ou si GEARMAN_NO_PENDING_TASKS est vrai.

gearman_failed() retourne true si une valeur autre que GEARMAN_SUCCESS a été fournie.

gearman_continue() retourne true si une erreur liée à l'IO non bloquante s'est produite. Cela devrait être utilisé pour les boucles de test.

Valeurs possibles de gearman_return_t:

type GEARMAN_NO_PENDING_TASKS
gearman_client_run_tasks() a été appelé et il a terminé toutes les tâches assignées au client.
type GEARMAN_IO_WAIT
Un IO bloquant a été détecté. gearman_continue() peut être utilisé pour tester cela.
type GEARMAN_ERRNO
Une erreur système s'est produite. Utilisez soit gearman_client_errno() ou gearman_worker_errno()
type GEARMAN_NO_ACTIVE_FDS
Aucune connexion active n'était disponible. gearman_continue() peut être utilisé pour tester cela.
type GEARMAN_GETADDRINFO
La résolution de nom a échoué pour un hôte.
type GEARMAN_NO_SERVERS
Aucun serveur n'a été fourni pour le client/l'ouvrier.
type GEARMAN_LOST_CONNECTION
La connexion au serveur donné a été perdue.
type GEARMAN_MEMORY_ALLOCATION_FAILURE
L'allocation de mémoire a échoué.
type GEARMAN_SERVER_ERROR
Une erreur s'est produite sur le serveur.
type GEARMAN_NOT_CONNECTED
Le client/l'ouvrier n'est pas actuellement connecté au serveur.
type GEARMAN_COULD_NOT_CONNECT
Le nom du serveur était valide, mais une connexion n'a pas pu être établie.
type GEARMAN_ECHO_DATA_CORRUPTION
Soit gearman_client_echo() ou gearman_worker_echo() echo a échoué parce que les données ont été retournées depuis gearmand corrompues.
type GEARMAN_UNKNOWN_STATE
Le gearman_return_t n'a jamais été défini.
type GEARMAN_FLUSH_DATA
État interne, ne devrait jamais être vu par le client ou l'ouvrier.
type GEARMAN_SEND_BUFFER_TOO_SMALL
Le tampon d'envoi était trop petit.
type GEARMAN_TIMEOUT
Un délai d'attente s'est produit lors d'une requête au serveur.
type GEARMAN_ARGUMENT_TOO_LARGE
L'argument était trop grand pour le tampon actuel.
type GEARMAN_INVALID_ARGUMENT
L'un des arguments de l'appel API donné était invalide. EINVAL sera défini si gearman_client_error() ou gearman_worker_error() n'ont pas pu être définis. Cela peut aussi être retourné si GEARMAN_CLIENT_UNBUFFERED_RESULT a été défini, mais le client ne gère pas les données correctement.

CLIENT UNIQUEMENT

type GEARMAN_NEED_WORKLOAD_FN
Un client a demandé du travail, mais aucune gearman_workload_fn fonction de rappel n'a été spécifiée. Voir gearman_client_set_workload_fn()
type GEARMAN_WORK_FAIL
Une tâche a échoué, et l'ouvrier est sorti avec une erreur ou a appelé gearman_job_send_fail()
type GEARMAN_IN_PROGRESS
gearman_client_job_status() a été appelé pour un gearman_job_handle_t et le travail est actuellement en cours d'exécution par un ouvrier.
type GEARMAN_JOB_EXISTS
gearman_client_job_status() a été appelé pour un gearman_job_handle_t et le travail est actuellement connu par un serveur, mais n'est pas exécuté par un ouvrier.

OUVRIER UNIQUEMENT

type GEARMAN_INVALID_FUNCTION_NAME
Un ouvrier a reçu une requête pour un travail pour lequel il n'avait pas de fonction valide.
type GEARMAN_INVALID_WORKER_FUNCTION
Aucune fonction de rappel n'a été fournie par l'ouvrier pour une fonction donnée.
type GEARMAN_NO_REGISTERED_FUNCTION
Une requête pour supprimer une fonction donnée d'un ouvrier était invalide car cette fonction n'existait pas.
type GEARMAN_NO_REGISTERED_FUNCTIONS
L'ouvrier n'a enregistré aucune fonction.
type GEARMAN_NO_JOBS
Aucun travail n'a été trouvé pour l'ouvrier. Ce code d'erreur n'est retourné si le travailleur vient de faire une demande de tâches.

TRAVAILLEUR VERS CLIENT

Client qui a enregistré une gearman_actions_t personnalisée peut utiliser ces valeurs comme valeurs de retour pour le client appelant.

type GEARMAN_WORK_DATA
Le travailleur a envoyé une donnée fragmentée au client via gearman_job_send_data()
type GEARMAN_WORK_WARNING
Le travailleur a émis un avertissement au client via gearman_job_send_warning()
type GEARMAN_WORK_STATUS
Le statut a été mis à jour par le travailleur via gearman_job_send_status()
type GEARMAN_WORK_EXCEPTION
Le travailleur a envoyé une exception au client via gearman_job_send_exception()
type GEARMAN_WORK_ERROR
Une tâche a rencontré une erreur et sera réessayée.
type GEARMAN_PAUSE
Utilisé uniquement dans une application personnalisée pour le retour du client basé sur GEARMAN_WORK_DATA, GEARMAN_WORK_WARNING, GEARMAN_WORK_EXCEPTION, GEARMAN_WORK_FAIL, ou GEARMAN_WORK_STATUS. gearman_continue() peut être utilisé pour vérifier cette valeur.

TRAVAILLEUR VERS CLIENT

Toute fonction définie par gearman_worker_define_function() peut, et ne peut, retourner que les valeurs suivantes de gearman_return_t .

type GEARMAN_FATAL
type GEARMAN_FAIL
La fonction n'a pas réussi à compléter la tâche. GEARMAN_FATAL est le nom déprécié de GEARMAN_FAIL
type GEARMAN_ERROR
Une tâche a rencontré une erreur et sera réessayée.
type GEARMAN_SHUTDOWN
GEARMAN_SHUTDOWN est un cas particulier. S'il est retourné, le client recevra GEARMAN_SUCCESS, mais gearman_worker_work() se terminera avec GEARMAN_SHUTDOWN.

TÂCHE UNIQUEMENT

type GEARMAN_NOT_FLUSHING
gearman_task_send_workload() a échoué, il n'était pas dans l'état correct.
type GEARMAN_DATA_TOO_LARGE
gearman_task_send_workload() a échoué, les données étaient trop volumineuses pour être envoyées.
type GEARMAN_UNKNOWN_OPTION
État par défaut de la valeur de retour de la tâche.

PROTOCOLE

Si l'une de ces erreurs s'est produite, la connexion sera interrompue/réinitialisée.

type GEARMAN_INVALID_MAGIC
type GEARMAN_INVALID_COMMAND
type GEARMAN_INVALID_PACKET
type GEARMAN_UNEXPECTED_PACKET
type GEARMAN_TOO_MANY_ARGS

DÉPRÉCIÉ

type GEARMAN_IGNORE_PACKET
type GEARMAN_MAX_RETURN

VOIR AUSSI
