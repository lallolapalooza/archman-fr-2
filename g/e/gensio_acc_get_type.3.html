gensio_acc_get_type(3)

Paquet: gensio

Licences: GPL

gensio_acc_get_type(3) Manuel des fonctions de bibliothèque gensio_acc_get_type(3)

NOM

gensio_acc_get_type, gensio_acc_is_reliable, gensio_acc_is_packet, gensio_acc_is_message, gensio_acc_is_mux - Retourne des informations générales sur un accepteur gensio

SYNOPSIS

#include <gensio/gensio.h>

const char *gensio_acc_get_type(struct gensio *io,

unsigned int depth);
bool gensio_acc_is_reliable(struct gensio *io);
bool gensio_acc_is_packet(struct gensio *io);
bool gensio_acc_is_mux(struct gensio *io);

DESCRIPTION

gensio_acc_get_type retourne la chaîne de type pour l'accepteur gensio (si depth est 0) ou l'un de ses enfants (depth > 0). Retourne NULL si la profondeur est supérieure au nombre d'enfants.

gensio_acc_is_reliable retourne vrai si les genios produits par cet accepteur sont fiables. Voir gensio_is_reliable(3) pour plus de détails.

gensio_acc_is_packet retourne si les genios produits par cet accepteur sont orientés paquet. Voir gensio_is_packet(3) pour plus de détails.

gensio_acc_is_message retourne si les genios produits par cet accepteur sont orientés message. Voir gensio_is_message(3) pour plus de détails.

gensio_acc_is_mux retourne si les genios produits par cet accepteur sont capables de multiplexage. Voir gensio_is_mux(3) pour plus de détails.
