GETTIMEOFDAY(3P) Manuel du programmeur POSIX GETTIMEOFDAY(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

gettimeofday — obtenir la date et l'heure

SYNTAXE

#include <sys/time.h>
int gettimeofday(struct timeval *restrict tp, void *restrict tzp);

DESCRIPTION

La fonction gettimeofday() doit obtenir l'heure actuelle, exprimée en secondes et en microsecondes depuis l'Epoch, et la stocker dans la structure timeval pointée par tp. La résolution de l'horloge système n'est pas spécifiée.

Si tzp n'est pas un pointeur nul, le comportement n'est pas spécifié.

VALEUR DE RETOUR

La fonction gettimeofday() doit retourner 0 et aucune valeur ne doit être réservée pour indiquer une erreur.

ERREURS

Aucune erreur n'est définie.

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION PAR L'APPLICATION

Les applications doivent utiliser la fonction clock_gettime() à la place de la fonction obsolète gettimeofday().

RATIONALE

Aucun.

DIRECTIONS FUTURES

La fonction gettimeofday() pourrait être supprimée dans une version future.

VOIR AUSSI

clock_getres(), ctime()
