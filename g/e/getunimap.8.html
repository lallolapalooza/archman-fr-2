NOM

getunimap - exporter la table de correspondance unicode de la console actuelle vers la sortie standard

SYNTAXE

getunimap [options]

DESCRIPTION

Le programme getunimap est ancien et obsolète. Il fait maintenant partie de setfont (1).

Le programme getunimap exporte la table de correspondance unicode (également appelée « Table de correspondance des polices d'écran ») pour la console actuelle vers la sortie standard.

L'option -C peut être utilisée avec Linux 2.6.1 et versions ultérieures pour obtenir la table de correspondance d'une console autre que l'actuelle. Son argument est un nom de chemin.

La sortie de getunimap est du format

0xAA U+1234 # commentaire

où 0xAA est le code du caractère de la police et U+1234 est un caractère unicode qui, s'il est affiché, sera affiché à l'aide du glyphe 0xAA dans la police. De nombreux caractères unicode peuvent être mappés au même glyphe.
le symbole dièse # est utilisé comme délimiteur de commentaire ; les caractères après un signe dièse (jusqu'à la fin de la ligne) sont des commentaires.

L'option -s triera et fusionnera les éléments, en triant par caractère de police. Par conséquent, elle produira une sortie du format :

0x22 U+1234 U+5678 U+3456
0x23 U+0023

etc., listant les caractères unicode multiples qui correspondent à un glyphe de police.

La sortie de getunimap est dans un format accepté par setfont et psfaddtable

OPTIONS

-s, --sort
trier et fusionner les éléments.
-C, --console=DEV
le périphérique console à utiliser.
-V, --version
afficher le numéro de version.
-h, --help
afficher ce message d'aide.

VOIR AUSSI

psfaddtable(1), setfont(1).
