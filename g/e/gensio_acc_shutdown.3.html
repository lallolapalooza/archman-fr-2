gensio_acc_shutdown(3)

Paquet: gensio

Licences: GPL

gensio_acc_shutdown(3) Manuel des fonctions de bibliothèque gensio_acc_shutdown(3)

NOM

gensio_acc_shutdown, gensio_acc_shutdown_s, gensio_acc_disable, gensio_acc_free - Arrêter/libérer un accepteur gensio qui a été démarré

SYNTAXE

#include <gensio/gensio.h>

typedef void (*gensio_acc_done)(struct gensio_accepter *acc,

void *cb_data);
int gensio_acc_shutdown(struct gensio_accepter *accepter,

gensio_acc_done shutdown_done,
void *shutdown_data);
int gensio_acc_shutdown_s(struct gensio_accepter *accepter);
void gensio_acc_disable(struct gensio_accepter *accepter);
void gensio_acc_free(struct gensio_accepter *accepter);

DESCRIPTION

gensio_acc_shutdown ferme toutes les sockets et désactive tout dans l'accepteur gensio. shutdown_done() sera appelé en cas de succès une fois l'arrêt terminé, si ce n'est pas NULL. Renvoie GE_INUSE si l'accepteur est déjà arrêté, zéro sinon.

gensio_acc_shutdown_s arrête le gensio et attend que l'arrêt soit terminé. Voir les notes dans gensio_close_s(3) pour un avertissement concernant son utilisation.

gensio_acc_disable est similaire à gensio_disable(3), mais pour les accepteurs. Voir gensio_disable(3) pour plus de détails.

gensio_acc_free libère l'accepteur réseau. Si l'accepteur réseau est démarré, il est arrêté au préalable et shutdown_done() N'EST PAS appelé.

VALEURS DE RETOUR

Zéro est renvoyé en cas de succès, ou une erreur gensio en cas d'échec.

VOIR AUSSI

gensio_err(3), gensio(5)
