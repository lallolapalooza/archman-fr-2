GETNETPATH(3) Manuel des fonctions de bibliothèque GETNETPATH(3)

NOM

getnetpath, setnetpath, endnetpath — obtenir l'entrée /etc/netconfig correspondant au composant NETPATH

SYNTAXE

#include <netconfig.h>

struct netconfig *
getnetpath(void *handlep);

void *
setnetpath(void);

int
endnetpath(void *handlep);

DESCRIPTION

Les routines décrites dans cette page fournissent à l'application l'accès à la base de données de configuration réseau du système, /etc/netconfig, telle qu'elle est « filtrée » par la variable d'environnement NETPATH (voir environ(7)). Voir getnetconfig(3) pour d'autres routines qui accèdent également directement à la base de données de configuration réseau. La variable NETPATH est une liste d'identificateurs réseau séparés par des deux-points.

La fonction getnetpath() renvoie un pointeur vers l'entrée de la base de données netconfig correspondant au premier composant NETPATH valide. L'entrée netconfig est formatée comme une struct netconfig. À chaque appel subséquent, getnetpath() renvoie un pointeur vers l'entrée netconfig qui correspond au composant NETPATH valide suivant. La fonction getnetpath() peut donc être utilisée pour rechercher dans la base de données netconfig tous les réseaux inclus dans la variable NETPATH. Lorsque NETPATH est épuisé, getnetpath() renvoie NULL.

Un appel à setnetpath() « lie » ou « rembobine » NETPATH. La fonction setnetpath() doit être appelée avant le premier appel à getnetpath() et peut être appelée à tout autre moment. Elle renvoie un handle qui est utilisé par getnetpath().

La fonction getnetpath() ignore silencieusement les composants NETPATH invalides. Un composant NETPATH est invalide s'il n'y a pas d'entrée correspondante dans la base de données netconfig.

Si la variable NETPATH n'est pas définie, getnetpath() se comporte comme si NETPATH était définie à la séquence des réseaux « par défaut » ou « visibles » dans la base de données netconfig, dans l'ordre où ils sont listés.

La fonction endnetpath() peut être appelée pour se « détacher » de NETPATH une fois le traitement terminé, libérant les ressources pour une réutilisation. Les programmeurs doivent cependant être conscients que endnetpath() libère toute mémoire allouée par getnetpath() pour la structure de données struct netconfig.

VALEURS DE RETOUR

La fonction setnetpath() renvoie un handle qui est utilisé par getnetpath(). En cas d'erreur, setnetpath() renvoie NULL.

La fonction endnetpath() renvoie 0 en cas de succès et -1 en cas d'échec (par exemple, si setnetpath() n'a pas été appelée précédemment). La fonction nc_perror() ou nc_sperror() peut être utilisée pour afficher la raison de l'échec. Voir getnetconfig(3).

Lors du premier appel, getnetpath() renvoie un pointeur vers l'entrée de la base de données netconfig correspondant au premier composant NETPATH valide. Lorsque NETPATH est épuisé, getnetpath() renvoie NULL.

DISPONIBILITE

Ces fonctions font partie de libtirpc.

VOIR AUSSI

getnetconfig(3), netconfig(5), environ(7)
