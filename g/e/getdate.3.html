getdate(3) Manuel des fonctions de bibliothèque getdate(3)

NOM

getdate, getdate_r - convertir une chaîne date-plus-heure en heure décomposée

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <time.h>
struct tm *getdate(const char *string);
extern int getdate_err;
int getdate_r(const char *restrict string, struct tm *restrict res);
Macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

getdate():

    _XOPEN_SOURCE >= 500

getdate_r():

    _GNU_SOURCE

DESCRIPTION

La fonction getdate() convertit une représentation sous forme de chaîne d'une date et d'une heure, contenue dans le tampon pointé par string, en une heure décomposée. L'heure décomposée est stockée dans une structure tm, et un pointeur vers cette structure est renvoyé comme résultat de la fonction. Cette structure tm est allouée dans un espace statique et sera par conséquent écrasée par des appels ultérieurs à getdate().

Contrairement à strptime(3) (qui a un argument format), getdate() utilise les formats trouvés dans le fichier dont le chemin complet est donné par la variable d'environnement DATEMSK. La première ligne du fichier qui correspond à la chaîne d'entrée donnée est utilisée pour la conversion.

La correspondance est effectuée sans tenir compte de la casse. Les espaces superflus, que ce soit dans le modèle ou dans la chaîne à convertir, sont ignorés.

Les spécifications de conversion qu'un modèle peut contenir sont celles données pour strptime(3). Une spécification de conversion supplémentaire est spécifiée dans POSIX.1-2001 :

%Z
Nom du fuseau horaire. Ceci n'est pas implémenté dans glibc.

Lorsque %Z est donné, la structure contenant l'heure décomposée est initialisée avec des valeurs correspondant à l'heure actuelle dans le fuseau horaire spécifié. Sinon, la structure est initialisée à l'heure décomposée correspondant à l'heure locale actuelle (comme par un appel à localtime(3)).

Lorsque seul le jour de la semaine est donné, le jour est considéré comme le premier jour de ce type à partir d'aujourd'hui.

Lorsque seul le mois est donné (et pas d'année), le mois est considéré comme le premier mois de ce type égal ou postérieur au mois actuel. Si aucun jour n'est donné, c'est le premier jour du mois.

Lorsque ni l'heure, ni les minutes, ni les secondes ne sont données, l'heure, les minutes et les secondes actuelles sont utilisées.

Si aucune date n'est donnée, mais que nous connaissons l'heure, alors cette heure est considérée comme la première heure de ce type égale ou postérieure à l'heure actuelle.

getdate_r() est une extension GNU qui fournit une version réentrante de getdate(). Plutôt que d'utiliser une variable globale pour signaler les erreurs et un tampon statique pour renvoyer l'heure décomposée, elle renvoie les erreurs via la valeur de retour de la fonction et renvoie l'heure décomposée résultante dans le tampon alloué par l'appelant et pointé par l'argument res.

VALEUR DE RETOUR

En cas de succès, getdate() renvoie un pointeur vers une struct tm. Sinon, elle renvoie NULL et définit la variable globale getdate_err à l'un des numéros d'erreur indiqués ci-dessous. Les changements apportés à errno ne sont pas spécifiés.

En cas de succès, getdate_r() renvoie 0 ; en cas d'erreur, elle renvoie l'un des numéros d'erreur indiqués ci-dessous.

ERREURS

Les erreurs suivantes sont renvoyées via getdate_err (pour getdate()) ou comme résultat de la fonction (pour getdate_r()):

1
La variable d'environnement DATEMSK n'est pas définie, ou sa valeur est une chaîne vide.
2
Le fichier modèle spécifié par DATEMSK ne peut pas être ouvert en lecture.
3
Échec de l'obtention des informations d'état du fichier.
4
Le fichier modèle n'est pas un fichier régulier.
5
Une erreur s'est produite lors de la lecture du fichier modèle.
6
Échec de l'allocation mémoire (pas assez de mémoire disponible).
7
Il n'y a aucune ligne dans le fichier qui corresponde à l'entrée.
8
Spécification d'entrée invalide.

ENVIRONNEMENT

DATEMSK
Fichier contenant les modèles de format.
TZ
LC_TIME
Variables utilisées par strptime(3).

ATTRIBUTS

Interface Attribut Valeur

getdate_r () Thread safety MT-Safe env locale

VERSIONS

La spécification POSIX.1 pour strptime(3) contient des spécifications de conversion utilisant le modificateur %E ou %O, tandis que de telles spécifications ne sont pas fournies pour getdate(). Dans glibc, getdate() est implémentée en utilisant strptime(3), de sorte que les mêmes conversions sont prises en charge par les deux.

$ echo '%T' >> $TFILE      # Heure (HH:MM:SS)

$ date
$ export DATEMSK=$TFILE

main(int argc, char *argv[])
{
    struct tm *tmp;
