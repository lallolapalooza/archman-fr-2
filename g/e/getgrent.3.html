DESCRIPTIO

N

La fonction getgrent() renvoie un pointeur vers une structure contenant les champs décomposés d'un enregistrement dans la base de données des groupes (par ex., le fichier de groupes local /etc/group, NIS et LDAP). La première fois que getgrent() est appelée, elle renvoie la première entrée ; ensuite, elle renvoie les entrées

suivantes.

La fonction setgrent() revient au début de la base de données des groupes, pour permettre des balayages

répétés.

La fonction endgrent() est utilisée pour fermer la base de données des groupes après que tout le traitement a été

effectué.

La structure group est définie dans <grp.h> comme suit

: 


struct group {
    char   *gr_name;        /* nom du groupe */
    char   *gr_passwd;      /* mot de passe du groupe */
    gid_t   gr_gid;         /* ID du groupe */
    char  **gr_mem;         /* tableau de pointeurs terminé par NULL
                               vers les noms des membres du groupe */
}
;

Pour plus d'informations sur les champs de cette structure, voir grou

p(5
).

VALEUR

RENVOYÉE

La fonction getgrent() renvoie un pointeur vers une structure group, ou NULL s'il n'y a plus d'entrées ou si une erreur se

produit.

En cas d'erreur, errno peut être défini. Si l'on souhaite vérifier errno après l'appel, il doit être défini à zéro avant

l'appel.

La valeur renvoyée peut pointer vers une zone statique, et peut être écrasée par des appels ultérieurs à getgrent(), getgrgid(3) ou getgrnam(3). (Ne pas passer le pointeur renvoyé à free

(3)
.)
