GENPMDA(1) Manuel des commandes générales GENPMDA(1)

NOM

genpmda - Générateur de PMDA Performance Co-Pilot

SYNTAXE

genpmda [-dv] [-D domaine] [-n pmns] [-o rép] [-s stdpmid] [-t rép-racine] -c config -i IAM

DESCRIPTION

genpmda est un outil de développement rapide d'applications pour créer de nouveaux agents de domaine de métriques de performance (PMDA), voir PMDA(3). Il offre un moyen très simple et efficace d'étendre le Performance Co-Pilot (PCP) avec de nouvelles métriques de performance sans avoir besoin de comprendre les détails de bas niveau de la construction des PMDAs.

genpmda lit un fichier de configuration contenant un espace de noms de métriques de performance augmenté, voir PMNS(5), et génère automatiquement la quasi-totalité du code source pour implémenter un PMDA fonctionnel, y compris le Makefile, l'espace de noms, les scripts de support pour la configuration du nouveau PMDA, et le texte d'aide des métriques. Les PMDAs relativement simples peuvent être générés automatiquement à partir du fichier de configuration sans écrire de code supplémentaire. Les PMDAs plus complexes, par exemple ceux contenant plusieurs domaines d'instance, nécessitent seulement que les méthodes de rafraîchissement des domaines d'instance soient écrites manuellement.

Un exemple du format de fichier de configuration accepté par genpmda est donné ci-dessous.

OPTIONS

Options requises :
-c config
fichier d'entrée config, voir l'exemple ci-dessous
-i IAM
nom du PMDA IAM, doit apparaître dans stdpmid ou l'option -D doit être utilisée pour spécifier un domaine.
Autres options :
-d
générer un script d'installation pour un PMDA démon (par défaut, DSO)
-D domaine
utiliser le numéro de domaine dans le fichier pmns généré et domain.h (si -s n'est pas donné)
-n pmns
utiliser pmns comme racine de l'espace de noms (par défaut, correspond à l'indicateur -i)
-o rép
utiliser rép pour le code source généré, par défaut ./generated
-s stdpmid
chemin vers stdpmid (par défaut ../../pmns/stdpmid)
-t rép-racine
utiliser rép-racine dans le GNUmakefile généré, par défaut ../../..
-v
afficher des messages détaillés sur ce que fait genpmda.

Exemple :
Générer un PMDA "example" en utilisant le domaine 99 :


genpmda -D 99 -v -i EXAMPLE -c example.conf

Voici le fichier de configuration example.conf (pour l'option requise -c) : 

example {
    metric
}
example.metric {
    ##  metric            string
    ##  pmid              EXAMPLE:CLUSTER:0
    ##  indom             PM_INDOM_NULL
    ##  type              PM_TYPE_STRING
    ##  units             PMDA_PMUNITS(0,0,0,0,0,0)
    ##  semantics         PM_SEM_DISCRETE
    ##  briefhelptext     one line help text for example.metric.string
    ##  helptext          long help text for example.metric.string
    ##  helptext          This is the second line of the long help text
    ##  helptext          and this is the third line.
    ##  fetch             function example_string_fetch_callback
    ##  code              atom->cp = "hello world";
    ##  code              return 1;
    ##  endmetric
}

ENVIRONNEMENT PCP

Les variables d'environnement préfixées par PCP_ sont utilisées pour paramétrer les noms de fichiers et de répertoires utilisés par PCP. Sur chaque installation, le fichier /etc/pcp.conf contient les valeurs locales pour ces variables. La variable $PCP_CONF peut être utilisée pour spécifier un fichier de configuration alternatif, comme décrit dans pcp.conf(5).
