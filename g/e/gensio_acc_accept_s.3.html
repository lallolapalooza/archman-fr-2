gensio_acc_accept_s(3) Manuel des fonctions de bibliothèque gensio_acc_accept_s(3)

NOM

gensio_acc_set_sync, gensio_acc_accept_s, gensio_acc_accept_s_intr - Opérations d'E/S synchrones sur un accepteur gensio

SYNOPIS

#include <gensio/gensio.h>

int gensio_acc_set_sync(struct gensio_accepter *acc);
int gensio_acc_accept_s(struct gensio_accepter *acc,

struct gensio_time *timeout,
struct gensio **new_io);
int gensio_acc_accept_s_intr(struct gensio_accepter *acc,

struct gensio_time *timeout,
struct gensio **new_io);

DESCRIPTION

Le fonctionnement normal d'un accepteur gensio est basé sur des rappels asynchrones. Cela convient à la plupart des programmes, surtout s'ils doivent gérer plusieurs acceptations sur le même accepteur ou sur différents accepteurs.

Cependant, il est parfois nécessaire d'effectuer des opérations synchrones avec l'exécution du programme, surtout s'il s'agit d'un programme simple qui n'accepte qu'une seule connexion puis effectue une action.

gensio_acc_set_sync configure l'accepteur gensio pour des acceptations synchrones. Si vous faites cela, le rappel d'événement actuellement enregistré ne recevra plus les événements de nouvelle connexion. Il recevra *d'autres* rappels. Vous devez appeler cette fonction avant de démarrer l'accepteur gensio, et une fois que vous l'avez appelée, l'accepteur gensio est en mode synchrone jusqu'à son arrêt.

gensio_accept_s attend une connexion entrante sur l'accepteur gensio. Cette fonction attend pendant la durée spécifiée dans timeout. timeout est mis à jour avec le temps restant à attendre. Si timeout est NULL, l'attente est indéfinie. Si aucune erreur n'est retournée, la nouvelle connexion entrante est retournée dans new_io.

gensio_accept_s_intr est similaire à gensio_accept_s, mais elle retourne immédiatement si une interruption de signal se produit. Sur les systèmes sans signaux, c'est la même chose que gensio_accept_s.

VALEUR DE RETOUR

Zéro est retourné en cas de succès, ou une erreur gensio en cas d'échec.

VOIR AUSSI

gensio_err(3), gensio_set_sync(3), gensio(5)
