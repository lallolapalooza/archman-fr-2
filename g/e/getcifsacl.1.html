GETCIFSACL(1) Manuel des commandes générales GETCIFSACL(1)

NOM

getcifsacl - Aide utilisateur pour afficher une ACL dans un descripteur de sécurité pour le système de fichiers Common Internet File System (CIFS)

SYNTAXE

getcifsacl [-v|-r] {objet du système de fichiers}

DESCRIPTION

Cet outil fait partie de la suite cifs-utils.

getcifsacl est un programme d'aide utilisateur pour le système de fichiers client CIFS de Linux. Il est destiné à afficher un descripteur de sécurité, y compris le DACL et le SACL pour un objet du système de fichiers.

Ce programme utilise un plugin pour gérer la correspondance des SID avec les noms d'utilisateur et de groupe. /etc/cifs-utils/idmap-plugin doit être un lien symbolique qui pointe vers le plugin correct à utiliser.

Les champs d'une ACE tels que le SID, le type, les drapeaux et le masque sont affichés séparés par /. Les valeurs numériques du type, des drapeaux et du masque sont affichées au format hexadécimal.

OPTIONS

-v
Affiche le numéro de version et quitte.
-r
Affiche un descripteur de sécurité en mode brut. Les valeurs telles que le type et les drapeaux sont affichées au format hexadécimal, un SID n'est pas mappé à un nom.
-R
Liste les ACL de tous les fichiers et répertoires de manière récursive.

NOTES

Le support du noyau pour les utilitaires getcifsacl/setcifsacl a été initialement introduit dans le noyau 2.6.37.

VOIR AUSSI

mount.cifs(8), setcifsacl(1)
