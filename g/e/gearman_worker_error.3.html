GEARMAN_WORKER_ERROR(3) Gearmand GEARMAN_WORKER_ERROR(3)

NOM

gearman_worker_error - Documentation Gearmand, https://gearman.org/gearmand/

SYNTAXE

#include <libgearman/gearman.h>

const char *gearman_worker_error(const gearman_worker_st *worker)
int gearman_worker_errno(gearman_worker_st *worker)

Lier avec -lgearman

DESCRIPTION

gearman_worker_error() et gearman_worker_errno() rapportent les dernières erreurs que le worker a rapportées/stockées dans gearman_worker_st. Si vous souhaitez enregistrer toutes les erreurs, veuillez consulter gearman_worker_set_log_fn().

VALEUR DE RETOUR

gearman_worker_errno() renvoie le dernier errno que le worker a enregistré.

ACCUEIL

Pour plus d'informations, veuillez consulter : https://gearman.org/gearmand/
