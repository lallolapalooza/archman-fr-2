sous-routine cgetsls (character trans, integer m, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * ) work, integer lwork, integer info)

CGETSLS

Objectif :

!>
!> CGETSLS résout des systèmes linéaires complexes surdéterminés ou sous-déterminés
!> impliquant une matrice A de taille M par N, en utilisant une factorisation QR
!> étroite et longue ou LQ courte et large de A.
!>
!> On suppose que A a un rang plein, et seule une protection rudimentaire contre
!> les matrices de rang déficient est fournie. Cette sous-routine ne détecte
!> que la déficience de rang exacte, où un élément diagonal du facteur triangulaire
!> de A est exactement zéro.
!>
!> Il est concevable que l'un (ou plusieurs) des éléments diagonaux du facteur
!> triangulaire de A soient des nombres anormalement petits sans que cette sous-routine
!> ne signale une erreur. Les solutions calculées pour de telles matrices presque
!> singulières peuvent être moins précises en raison d'une perte de précision numérique.
!>
!>
!> Les options suivantes sont fournies :
!>
!> 1. Si TRANS = 'N' et m >= n : trouver la solution des moindres carrés d'un
!>    système surdéterminé, c'est-à-dire résoudre le problème des moindres carrés
!>                 minimiser || B - A*X ||.
!>
!> 2. Si TRANS = 'N' et m < n : trouver la solution de norme minimale d'un
!>    système sous-déterminé A * X = B.
!>
!> 3. Si TRANS = 'C' et m >= n : trouver la solution de norme minimale d'un
!>    système sous-déterminé A**T * X = B.
!>
!> 4. Si TRANS = 'C' et m < n : trouver la solution des moindres carrés d'un
!>    système surdéterminé, c'est-à-dire résoudre le problème des moindres carrés
!>                 minimiser || B - A**T * X ||.
!>
!> Plusieurs vecteurs de second membre b et vecteurs solution x peuvent être
!> gérés en un seul appel ; ils sont stockés sous forme de colonnes des
!> matrices B (M par NRHS) et X (N par NRHS) de second membre et de solution.
!>

Paramètres

TRANS 
!>          TRANS est CHARACTER*1
!>          = 'N' : le système linéaire implique A ;
!>          = 'C' : le système linéaire implique A**H.
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice A. M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A. N >= 0.
!>

NRHS

!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes des matrices B et X. NRHS >= 0.
!>

A

!>          A est un tableau COMPLEX, de dimension (LDA,N)
!>          À l'entrée, la matrice A de taille M par N.
!>          À la sortie,
!>          A est écrasé par les détails de sa factorisation QR ou LQ
!>          renvoyée par CGEQR ou CGELQ.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,M).
!>

B

!>          B est un tableau COMPLEX, de dimension (LDB,NRHS)
!>          À l'entrée, la matrice B des vecteurs de second membre, stockés
!>          par colonnes ; B est de taille M par NRHS si TRANS = 'N', ou
!>          N par NRHS si TRANS = 'C'.
!>          À la sortie, si INFO = 0, B est écrasé par les vecteurs solution,
!>          stockés par colonnes :
!>          si TRANS = 'N' et m >= n, les lignes 1 à n de B contiennent les vecteurs
!>          solution des moindres carrés.
!>          si TRANS = 'N' et m < n, les lignes 1 à N de B contiennent les
!>          vecteurs solution de norme minimale ;
!>          si TRANS = 'C' et m >= n, les lignes 1 à M de B contiennent les
!>          vecteurs solution de norme minimale ;
!>          si TRANS = 'C' et m < n, les lignes 1 à M de B contiennent les
!>          vecteurs solution des moindres carrés.
!>

LDB

!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= MAX(1,M,N).
!>

WORK

!>          (espace de travail) Tableau COMPLEX, de dimension (MAX(1,LWORK))
!>          À la sortie, si INFO = 0, WORK(1) contient la taille LWORK optimale
!>          (ou minimale, si la requête était supposée).
!>          Voir LWORK pour les détails.
!>

LWORK

!>          LWORK est INTEGER
!>          La dimension du tableau WORK. LWORK >= 1.
!>          Si LWORK = -1 ou -2, une requête d'espace de travail est supposée.
!>          Si LWORK = -1, la routine calcule la taille optimale de WORK pour
!>          une performance optimale et renvoie cette valeur dans WORK(1).
!>          Si LWORK = -2, la routine calcule la taille minimale de WORK et
!>          renvoie cette valeur dans WORK(1).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO =  i, le i-ème élément diagonal du
!>                facteur triangulaire de A est exactement zéro, donc A n'a pas
!>                de rang plein ; la solution des moindres carrés n'a pas pu être
!>                calculée.
!>
