getdns_context_set_context_update_callback(3) getdns getdns_context_set_context_update_callback(3)

NOM

getdns_context_set_context_update_callback -- être informé des mises à jour du contexte getdns

BIBLIOTHÈQUE

Bibliothèque de résolution DNS (libgetdns, -lgetdns)

SYNTAXE

#include <getdns.h>

getdns_return_t
getdns_context_set_context_update_callback (getdns_context ** context,


void (*cbfun)(getdns_context *context, getdns_context_code_t changed_item)

DESCRIPTION

Les modifications apportées au contexte, par exemple en réponse à des fichiers système qui affectent le contexte (/etc/resolv.conf etc.), déclenchent un appel à la fonction de rappel spécifiée comme cbfun.

context un contexte préalablement initialisé

cbfun fonction de rappel à invoquer lorsque le contexte spécifié change. Si cet argument est NULL, les mises à jour du contexte n'invoqueront pas de rappel.

VALEURS DE RETOUR

En cas de succès, chacune de ces fonctions renvoie GETDNS_RETURN_GOOD, sinon les valeurs d'erreur suivantes sont renvoyées :

GETDNS_RETURN_GENERIC_ERROR échec d'allocation mémoire ou quelque chose d'autre s'est mal passé.

GETDNS_RETURN_BAD_CONTEXT si le pointeur de contexte est invalide.
