setnetgrent(3) Manuel des fonctions de bibliothèque setnetgrent(3)

NOM

setnetgrent, endnetgrent, getnetgrent, getnetgrent_r, innetgr - gérer les entrées de groupe réseau

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <netdb.h>
int setnetgrent(const char *netgroup);
void endnetgrent(void);
int getnetgrent(char **restrict host,
            char **restrict user, char **restrict domain);
int getnetgrent_r(size_t size;
            char **restrict host,
            char **restrict user, char **restrict domain,
            char buf[restrict size], size_t size);
int innetgr(const char *netgroup, const char *host,
            const char *user, const char *domain);

        _DEFAULT_SOURCE
    glibc 2.19 et versions antérieures :

DESCRIPTION

Le netgroup est une invention de SunOS. Une base de données de netgroup est une liste de triplets de chaînes (nom d'hôte, nom d'utilisateur, nom de domaine) ou d'autres noms de netgroup. N'importe lequel des éléments d'un triplet peut être vide, ce qui signifie que tout correspond. Les fonctions décrites ici permettent d'accéder aux bases de données de netgroup. Le fichier /etc/nsswitch.conf définit quelle base de données est recherchée.

L'appel setnetgrent() définit le netgroup qui sera recherché par les appels ultérieurs à getnetgrent(). La fonction getnetgrent() récupère la prochaine entrée de netgroup et renvoie des pointeurs dans host, user, domain. Un pointeur nul signifie que l'entrée correspondante correspond à n'importe quelle chaîne. Les pointeurs ne sont valides que tant qu'il n'y a pas d'appel à d'autres fonctions liées aux netgroup. Pour éviter ce problème, vous pouvez utiliser la fonction GNU getnetgrent_r() qui stocke les chaînes dans le tampon fourni. Pour libérer tous les tampons alloués, utilisez endnetgrent().

Dans la plupart des cas, vous souhaitez uniquement vérifier si le triplet (nom d'hôte, nom d'utilisateur, nom de domaine) est membre d'un netgroup. La fonction innetgr() peut être utilisée à cette fin sans appeler les trois fonctions ci-dessus. Encore une fois, un pointeur nul est un joker et correspond à n'importe quelle chaîne. La fonction est thread-safe.

VALEUR DE RETOUR

Ces fonctions renvoient 1 en cas de succès et 0 en cas d'échec.

FICHIERS

/etc/netgroup
/etc/nsswitch.conf

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
setnetgrent (), getnetgrent_r (), innetgr () Sécurité des threads MT-Unsafe race:netgrent locale
endnetgrent () Sécurité des threads MT-Unsafe race:netgrent
getnetgrent () Sécurité des threads MT-Unsafe race:netgrent race:netgrentbuf locale

Dans le tableau ci-dessus, netgrent dans race:netgrent signifie que si l'une des fonctions setnetgrent(), getnetgrent_r(), innetgr(), getnetgrent(), ou endnetgrent() est utilisée en parallèle dans différents threads d'un programme, des courses de données pourraient se produire.

VERSIONS

Dans l'implémentation BSD, setnetgrent() renvoie void.

NORMES

Aucune.

HISTORIQUE

setnetgrent(), endnetgrent(), getnetgrent(), et innetgr() sont disponibles sur la plupart des systèmes UNIX. getnetgrent_r() n'est pas largement disponible sur d'autres systèmes.
