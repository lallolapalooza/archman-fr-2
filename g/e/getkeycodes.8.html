NOM

getkeycodes - affiche la table de mappage scancode-vers-keycode du noyau

SYNTAXE

getkeycodes [options]

DESCRIPTION

La commande getkeycodes affiche la table de mappage scancode-vers-keycode du noyau.

OPTIONS

-V, --version
affiche le numéro de version ;
-h, --help
affiche ce message d'utilisation.
