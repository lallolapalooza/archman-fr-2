JUSTIFICATIO

N

Le besoin initial pour cette utilitaire, et pour la fonction confstr(), était de fournir un moyen de trouver la valeur par défaut définie par la configuration pour la variable d'environnement PATH. Puisque PATH peut être modifiée par l'utilisateur pour inclure des répertoires qui pourraient contenir des utilitaires remplaçant les utilitaires standard, les scripts de shell ont besoin d'un moyen de déterminer la valeur de la variable d'environnement PATH fournie par le système qui contient le chemin de recherche correct pour les utilitaires standard. Il a été suggéré plus tard que l'accès aux autres variables décrites dans ce volume de POSIX.1‐2017 pourrait également être utile aux

applications.

Cette fonctionnalité de getconf ne serait pas adéquatement englobée par une autre commande telle que 

: 
grep var /e
tc/c
onf

car une telle stratégie ne fournirait pas de valeurs correctes pour les variables qui peuvent varier à l'exécution, ni pour celles qui peuvent varier en fonction du

chemin.

Les versions initiales de la proposition de getconf spécifiaient le code de retour 1 lorsque la variable spécifiée était valide, mais n'était pas définie sur le système. La chaîne de sortie "undefined" est maintenant utilisée pour spécifier ce cas avec le code de retour 0, car t

ant de choses dépendent d'un code de retour
de zéro lorsque l'utilitaire invoqué réussit.
