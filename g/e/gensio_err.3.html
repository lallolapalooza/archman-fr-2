NOM

gensio_err - Valeurs de rapport d'erreurs pour les fonctions gensio

SYNTAXE

#include <gensio/gensio_err.h>
const char *gensio_err_to_str(int err)

DESCRIPTION

Les valeurs de retour des fonctions gensio qui retournent des erreurs et les valeurs rapportées dans les rappels de la bibliothèque gensio sont toutes des erreurs gensio. Les valeurs possibles sont :

GE_NOERR Pas d'erreur
GE_NOMEM Pas assez de mémoire
GE_NOTSUP Opération non supportée
GE_INVAL Données invalides en paramètre
GE_NOTFOUND Valeur ou fichier introuvable
GE_EXISTS Valeur existe déjà
GE_OUTOFRANGE Valeur hors de portée
GE_INCONSISTENT Paramètres incohérents dans l'appel
GE_NODATA Aucune donnée n'était disponible pour la fonction
GE_OSERR Erreur du système d'exploitation, voir les logs
GE_INUSE Objet déjà utilisé
GE_INPROGRESS Opération en cours
GE_NOTREADY Objet non prêt pour l'opération
GE_TOOBIG Valeur trop grande pour les données
GE_TIMEDOUT Opération expirée
GE_RETRY Réessayer l'opération plus tard
GE_KEYNOTFOUND Impossible de trouver la clé donnée
GE_CERTREVOKED Clé révoquée
GE_CERTEXPIRED Clé expirée
GE_KEYINVALID Clé invalide
GE_NOCERT Certificat non fourni
GE_CERTINVALID Certificat invalide
GE_PROTOERR Erreur de protocole
GE_COMMERR Erreur de communication
GE_IOERR Erreur d'E/S interne
GE_REMCLOSE Extrémité distante a fermé la connexion
GE_HOSTDOWN Hôte injoignable
GE_CONNREFUSE Connexion refusée
GE_DATAMISSING Données manquantes
GE_CERTNOTFOUND Impossible de trouver le certificat donné
GE_AUTHREJECT Jetons d'authentification rejetés
GE_ADDRINUSE Adresse déjà utilisée
GE_INTERRUPTED Opération interrompue par un signal
GE_SHUTDOWN Opération sur un descripteur de fichier fermé
GE_LOCALCLOSED Côté local a fermé la connexion
GE_PERM Permission refusée
GE_APPERR Erreur d'application
GE_UNKNOWN_NAME_ERROR Erreur inconnue de résolution de nom de serveur
GE_NAME_ERROR Impossible de trouver un nom valide sur le serveur de noms
GE_NAME_SERVER_FAILURE Grave défaillance du serveur de noms
GE_NAME_INVALID Informations de serveur de noms invalides
GE_NAME_NET_NOT_UP L'adresse réseau pour le nom donné n'est pas disponible

gensio_err_to_str convertit une valeur d'erreur entière en la chaîne donnée.

VOIR AUSSI

gensio(5), gensio_err(3), gensio_log(3)
