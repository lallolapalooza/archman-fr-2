NOM

gencfu - Génère les fichiers de données de caractères trompeurs Unicode

SYNTAXE

gencfu [ -h, -?, --help ] [ -V, --version ] [ -c, --copyright ] [ -v, --verbose ] [ -d, --destdir destination ] [ -i, --icudatadir répertoire ] -r, --rules fichier-règles -w, --wsrules fichier-règles-script-entier -o, --out fichier-sortie

DESCRIPTION

gencfu lit les définitions de caractères trompeurs dans le fichier d'entrée, qui sont des fichiers texte brut contenant des définitions de caractères trompeurs dans le format d'entrée défini par Unicode UAX39 pour les fichiers confusables.txt et confusablesWholeScript.txt. Ce format source (.txt) est également accepté par les détecteurs d'usurpation d'ICU. Les fichiers doivent être encodés en utf-8, avec ou sans BOM. Normalement, le fichier de données de sortie a l'extension .cfu.

OPTIONS

-h, -?, --help
Affiche l'aide sur l'utilisation et quitte.
-V, --version
Affiche la version de gencfu et quitte.
-c, --copyright
Intègre les droits d'auteur standard d'ICU dans le fichier-sortie.
-v, --verbose
Affiche des messages informatifs supplémentaires pendant l'exécution.
-d, --destdir destination
Définit le répertoire de destination du fichier-sortie à destination.
-i, --icudatadir répertoire
Recherche les fichiers de données ICU nécessaires dans répertoire. Par exemple, le fichier pnames.icu doit être trouvé lorsque les données d'ICU ne sont pas compilées en bibliothèque partagée. Le répertoire de données ICU par défaut est spécifié par la variable d'environnement ICU_DATA. La plupart des configurations d'ICU ne nécessitent pas cet argument.
-r, --rules fichier-règles
Le fichier source à lire.
-w, --wsrules fichier-règles-script-entier
Le fichier source du script entier à lire.
-o, --out fichier-sortie
Le fichier de données de sortie à écrire.
