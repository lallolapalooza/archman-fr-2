getgrnam(3) Manuel des fonctions de bibliothèque getgrnam(3)

NOM

getgrnam, getgrnam_r, getgrgid, getgrgid_r - obtenir une entrée du fichier des groupes

BIBLIOTHÈQUE

Bibliothèque C standard (libc,-lc)

SYNOPSIS

#include <sys/types.h>
#include <grp.h>
struct group *getgrnam(const char *name);
struct group *getgrgid(gid_t gid);
int getgrnam_r(size_t size;
               const char *restrict name, struct group *restrict grp,
               char buf[restrict size], size_t size,
               struct group **restrict result);
int getgrgid_r(size_t size;
               gid_t gid, struct group *restrict grp,
               char buf[restrict size], size_t size,
               struct group **restrict result);
Exigences des macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)) :

getgrnam_r(), getgrgid_r() :

    _POSIX_C_SOURCE
        || /* glibc <= 2.19 : */ _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

La fonction getgrnam() renvoie un pointeur vers une structure contenant les champs décomposés de l'enregistrement dans la base de données des groupes (par exemple, le fichier des groupes local /etc/group, NIS et LDAP) qui correspond au nom de groupe name.

La fonction getgrgid() renvoie un pointeur vers une structure contenant les champs décomposés de l'enregistrement dans la base de données des groupes qui correspond à l'identifiant de groupe gid.

La structure group est définie dans <grp.h> comme suit :


struct group {
    char   *gr_name;        /* nom du groupe */
    char   *gr_passwd;      /* mot de passe du groupe */
    gid_t   gr_gid;         /* identifiant de groupe */
    char  **gr_mem;         /* tableau de pointeurs terminé par NULL
                               vers les noms des membres du groupe */
};

Pour plus d'informations sur les champs de cette structure, voir group(5).

Les fonctions getgrnam_r() et getgrgid_r() obtiennent les mêmes informations que getgrnam() et getgrgid(), mais stockent la structure group récupérée dans l'espace pointé par grp. Les champs de chaîne pointés par les membres de la structure group sont stockés dans le tampon buf de taille size. Un pointeur vers le résultat (en cas de succès) ou NULL (si aucune entrée n'a été trouvée ou si une erreur s'est produite) est stocké dans *result.

L'appel


sysconf(_SC_GETGR_R_SIZE_MAX)

renvoie soit -1, sans modifier errno, soit une taille initiale suggérée pour buf. (Si cette taille est trop petite, l'appel échoue avec ERANGE, auquel cas l'appelant peut réessayer avec un tampon plus grand.)

VALEUR RENVOYÉE

Les fonctions getgrnam() et getgrgid() renvoient un pointeur vers une structure group , ou NULL si l'entrée correspondante n'est pas trouvée ou si une erreur se produit. Si une erreur se produit, errno est défini pour indiquer l'erreur. Si l'on souhaite vérifier errno après l'appel, il devrait être mis à zéro avant l'appel.

La valeur renvoyée peut pointer vers une zone statique et peut être écrasée par des appels ultérieurs à getgrent(3), getgrgid() ou getgrnam(). (Ne pas passer le pointeur renvoyé à free(3).)

En cas de succès, getgrnam_r() et getgrgid_r() renvoient zéro et définissent *result sur grp. Si aucun enregistrement de groupe correspondant n'a été trouvé, ces fonctions renvoient 0 et stockent NULL dans *result. En cas d'erreur, un numéro d'erreur est renvoyé et NULL est stocké dans *result.

ERREURS

0 ou ENOENT ou ESRCH ou EBADF ou EPERM ou ...
Le name ou gid donné n'a pas été trouvé.
EINTR
Un signal a été capturé ; voir signal(7).
EIO
Erreur d'E/S.
EMFILE
La limite par processus sur le nombre de descripteurs de fichiers ouverts a été atteinte.
ENFILE
La limite du système sur le nombre total de fichiers ouverts a été atteinte.
ENOMEM
Mémoire insuffisante pour allouer la structure group .
ERANGE
Espace de tampon fourni insuffisant.

FICHIERS

/etc/group
fichier de la base de données des groupes locale

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
getgrnam () Sécurité des threads MT-Unsafe race:grnam locale
getgrgid () Sécurité des threads MT-Unsafe race:grgid locale
getgrnam_r (), getgrgid_r () Sécurité des threads MT-Safe locale

VERSIONS

La formulation donnée ci-dessus sous « VALEUR RENVOYÉE » provient de POSIX.1. Elle ne qualifie pas « non trouvé » comme une erreur et ne spécifie donc pas quelle valeur errno pourrait avoir dans cette situation. Mais cela rend impossible la reconnaissance des erreurs. On pourrait soutenir que, selon POSIX, errno devrait rester inchangé si une entrée n'est pas trouvée. Des expériences sur divers systèmes de type UNIX montrent que de nombreuses valeurs différentes surviennent dans cette situation : 0, ENOENT, EBADF, ESRCH, EWOULDBLOCK, EPERM, et probablement d'autres.
