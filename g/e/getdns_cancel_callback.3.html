getdns_cancel_callback(3) getdns getdns_cancel_callback(3)

NOM

getdns_cancel_callback -- annuler une requête getdns asynchrone en attente

BIBLIOTHÈQUE

Bibliothèque de résolution DNS (libgetdns, -lgetdns)

SYNOPSIS

#include <getdns.h>

getdns_return_t
getdns_cancel_callback (getdns_context_t context,


getdns_transaction_t *transaction_id)

DESCRIPTION

Pour annuler une fonction de rappel en attente, utilisez getdns_cancel_callback. Ceci amène l'API à appeler la fonction de rappel avec un type de rappel GETDNS_CALLBACK_CANCEL si la fonction de rappel pour cet transaction_id n'a pas encore été appelée. Le code de rappel pour l'annulation doit nettoyer toute mémoire liée à l'appel identifié, par exemple pour désallouer la mémoire de userarg. getdns_cancel_callback() peut retourner immédiatement, même avant que la fonction de rappel n'ait terminé son travail et ne retourne.

context voir getdns_context (3)

transaction_id peuplé par l'API et utilisé pour identifier la fonction de rappel (par exemple pour getdns_cancel_callback), peut être NULL, défini à 0 si la fonction échoue

VALEURS DE RETOUR

En cas de succès, les fonctions retournent GETDNS_RETURN_GOOD, sinon les valeurs d'erreur suivantes sont retournées:

GETDNS_RETURN_INVALID_PARAMETER si context == NULL

GETDNS_RETURN_UNKNOWN_TRANSACTION si le transaction_id est inconnu ou appartient à une fonction de rappel qui a déjà été appelée
