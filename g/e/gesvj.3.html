Documentation de la fonction

subroutine cgesvj (character*1 joba, character*1 jobu, character*1 jobv, integer m, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( n ) sva, integer mv, complex, dimension( ldv, * ) v, integer ldv, complex, dimension( lwork ) cwork, integer lwork, real, dimension( lrwork ) rwork, integer lrwork, integer info)

CGESVJ

But :

!>
!> CGESVJ calcule la décomposition en valeurs singulières (SVD) d'une matrice
!> complexe A de dimensions M par N, où M >= N. La SVD de A est écrite comme
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^*,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> où SIGMA est une matrice diagonale de dimensions N par N, U est une matrice
!> orthonormale de dimensions M par N, et V est une matrice unitaire de
!> dimensions N par N. Les éléments diagonaux de SIGMA sont les valeurs
!> singulières de A. Les colonnes de U et de V sont respectivement les vecteurs
!> singuliers gauche et droit de A.
!>

Paramètres

JOBA 
!>          JOBA est de type CHARACTER*1
!>          Spécifie la structure de A.
!>          = 'L' : la matrice d'entrée A est triangulaire inférieure ;
!>          = 'U' : la matrice d'entrée A est triangulaire supérieure ;
!>          = 'G' : la matrice d'entrée A est une matrice générale de
!>                  dimensions M par N, M >= N.
!>

JOBU

!>          JOBU est de type CHARACTER*1
!>          Spécifie s'il faut calculer les vecteurs singuliers gauche
!>          (les colonnes de U) :
!>          = 'U' ou 'F' : les vecteurs singuliers gauche correspondant aux
!>                 valeurs singulières non nulles sont calculés et renvoyés
!>                 dans les colonnes de tête de A. Voir plus de détails dans
!>                 la description de A.
!>                 Le seuil d'orthogonalité numérique par défaut est fixé à
!>                 approximativement TOL=CTOL*EPS, CTOL=SQRT(M), EPS=SLAMCH('E').
!>          = 'C' : analogue à JOBU='U', sauf que l'utilisateur peut contrôler
!>                 le niveau d'orthogonalité numérique des vecteurs singuliers
!>                 gauche calculés. TOL peut être défini à TOL = CTOL*EPS, où
!>                 CTOL est donné en entrée dans le tableau WORK.
!>                 Aucune valeur de CTOL inférieure à ONE n'est autorisée. Une
!>                 valeur de CTOL supérieure à 1 / EPS est sans signification.
!>                 L'option 'C' peut être utilisée si M*EPS est un niveau
!>                 d'orthogonalité satisfaisant pour les vecteurs singuliers
!>                 gauche calculés, de sorte que CTOL=M pourrait économiser
!>                 quelques balayages de rotations de Jacobi.
!>                 Voir les descriptions de A et WORK(1).
!>          = 'N' : la matrice U n'est pas calculée. Cependant, voir la
!>                 description de A.
!>

JOBV

!>          JOBV est de type CHARACTER*1
!>          Spécifie s'il faut calculer les vecteurs singuliers droit, c'est-à-
!>          dire la matrice V :
!>          = 'V' ou 'J' : la matrice V est calculée et renvoyée dans le
!>                         tableau V
!>          = 'A' :  les rotations de Jacobi sont appliquées au tableau V de
!>                  dimensions MV par N. En d'autres termes, la matrice des
!>                  vecteurs singuliers droits V n'est pas calculée
!>                  explicitement ; au lieu de cela, elle est appliquée à une
!>                  matrice de dimensions MV par N initialement stockée dans
!>                  les MV premières lignes de V.
!>          = 'N' :  la matrice V n'est pas calculée et le tableau V n'est pas
!>                  référencé
!>

M

!>          M est de type INTEGER
!>          Le nombre de lignes de la matrice d'entrée A. 1/SLAMCH('E') > M >= 0.
!>

N

!>          N est de type INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!>

A

!>          A est un tableau COMPLEX, de dimensions (LDA,N)
!>          À l'entrée, la matrice A de dimensions M par N.
!>          À la sortie,
!>          Si JOBU = 'U' .OR. JOBU = 'C' :
!>                 Si INFO = 0 :
!>                 RANKA colonnes orthonormales de U sont renvoyées dans les
!>                 RANKA colonnes de tête du tableau A. Ici RANKA <= N
!>                 est le nombre de valeurs singulières calculées de A qui sont
!>                 au-dessus du seuil de débordement inférieur SLAMCH('S'). Les
!>                 vecteurs singuliers correspondant aux valeurs singulières
!>                 sous-flux ou nulles ne sont pas calculés. La valeur de RANKA
!>                 est renvoyée dans le tableau RWORK sous la forme
!>                 RANKA=NINT(RWORK(2)). Voir aussi les descriptions de SVA et
!>                 RWORK. Les colonnes calculées de U sont mutuellement
!>                 numériquement orthogonales jusqu'à approximativement
!>                 TOL=SQRT(M)*EPS (par défaut) ; ou TOL=CTOL*EPS (JOBU = 'C'),
!>                 voir la description de JOBU.
!>                 Si INFO > 0,
!>                 la procédure CGESVJ n'a pas convergé dans le nombre donné
!>                 d'itérations (balayages). Dans ce cas, les colonnes
!>                 calculées de U peuvent ne pas être orthogonales jusqu'à TOL.
!>                 La sortie U (stockée dans A), SIGMA (donnée par les valeurs
!>                 singulières calculées dans SVA(1:N)) et V reste une
!>                 décomposition de la matrice d'entrée A dans le sens où le
!>                 résidu
!>                 || A - SCALE * U * SIGMA * V^* ||_2 / ||A||_2 est petit.
!>          Si JOBU = 'N' :
!>                 Si INFO = 0 :
!>                 Notez que les vecteurs singuliers gauche sont 'gratuits' dans
!>                 l'algorithme de SVD de Jacobi unilatéral. Cependant, si
!>                 seules les valeurs singulières sont nécessaires, le niveau
!>                 d'orthogonalité numérique de U n'est pas un problème et les
!>                 itérations s'arrêtent lorsque les colonnes de la matrice
!>                 itérée sont numériquement orthogonales jusqu'à
!>                 approximativement M*EPS. Ainsi, à la sortie, A contient les
!>                 colonnes de U mises à l'échelle avec les valeurs singulières
!>                 correspondantes.
!>                 Si INFO > 0 :
!>                 la procédure CGESVJ n'a pas convergé dans le nombre donné
!>                 d'itérations (balayages).
!>

LDA

!>          LDA est de type INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

SVA

!>          SVA est un tableau REAL, de dimensions (N)
!>          À la sortie,
!>          Si INFO = 0 :
!>          selon la valeur SCALE = RWORK(1), nous avons :
!>                 Si SCALE = ONE :
!>                 SVA(1:N) contient les valeurs singulières calculées de A.
!>                 Pendant le calcul, SVA contient les normes euclidiennes des
!>                 colonnes des matrices itérées dans le tableau A.
!>                 Si SCALE .NE. ONE :
!>                 Les valeurs singulières de A sont SCALE*SVA(1:N), et cette
!>                 représentation factorisée est due au fait que certaines des
!>                 valeurs singulières de A pourraient déborder ou sous-fluer.
!>
!>          Si INFO > 0 :
!>          la procédure CGESVJ n'a pas convergé dans le nombre donné
!>          d'itérations (balayages) et SCALE*SVA(1:N) peut ne pas être précis.
!>

MV

!>          MV est de type INTEGER
!>          Si JOBV = 'A', alors le produit des rotations de Jacobi dans CGESVJ
!>          est appliqué aux MV premières lignes de V. Voir la description de
!>          JOBV.
!>

V

!>          V est un tableau COMPLEX, de dimensions (LDV,N)
!>          Si JOBV = 'V', alors V contient à la sortie la matrice de dimensions
!>                         N par N des vecteurs singuliers droit vecteurs;
!>          Si JOBV = 'A', alors V contient le produit de la matrice des vecteurs
!>                         singuliers droits calculés et de la matrice initiale
!>                         dans le tableau V.
!>          Si JOBV = 'N', alors V n'est pas référencé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V, LDV >= 1.
!>          Si JOBV = 'V', alors LDV >= max(1,N).
!>          Si JOBV = 'A', alors LDV >= max(1,MV) .
!>

CWORK

!>          CWORK est un tableau COMPLEX, dimension (max(1,LWORK))
!>          Utilisé comme espace de travail.
!>

LWORK

!>          LWORK est INTEGER.
!>          Longueur de CWORK.
!>          LWORK >= 1, si MIN(M,N) = 0, et LWORK >= M+N, sinon.
!>
!>          Si à l'entrée LWORK = -1, alors une interrogation d'espace de travail
!>          est supposée et aucun calcul n'est effectué ; CWORK(1) est défini à la
!>          longueur minimale (et optimale) de CWORK.
!>

RWORK

!>          RWORK est un tableau REAL, dimension (max(6,LRWORK))
!>          À l'entrée,
!>          Si JOBU = 'C' :
!>          RWORK(1) = CTOL, où CTOL définit le seuil de convergence.
!>                    Le processus s'arrête si toutes les colonnes de A sont
!>                    mutuellement orthogonales jusqu'à CTOL*EPS, EPS=SLAMCH('E').
!>                    Il est requis que CTOL >= ONE, c'est-à-dire qu'il n'est pas
!>                    autorisé de forcer la routine à obtenir une orthogonalité
!>                    en dessous d'EPSILON.
!>          À la sortie,
!>          RWORK(1) = SCALE est le facteur d'échelle tel que SCALE*SVA(1:N)
!>                    sont les valeurs singulières calculées de A.
!>                    (Voir la description de SVA().)
!>          RWORK(2) = NINT(RWORK(2)) est le nombre de valeurs singulières
!>                    non nulles calculées.
!>          RWORK(3) = NINT(RWORK(3)) est le nombre de valeurs singulières
!>                    calculées qui sont plus grandes que le seuil de débordement
!>                    inférieur.
!>          RWORK(4) = NINT(RWORK(4)) est le nombre de balayages de rotations
!>                    de Jacobi nécessaires pour la convergence numérique.
!>          RWORK(5) = max_{i.NE.j} |COS(A(:,i),A(:,j))| dans le dernier
!>                    balayage. Ceci est une information utile dans les cas où
!>                    CGESVJ n'a pas convergé, car cela peut être utilisé pour
!>                    estimer si la sortie est encore utile et pour une analyse
!>                    a posteriori.
!>          RWORK(6) = la plus grande valeur absolue de tous les sinus des
!>                    angles de rotation de Jacobi dans le dernier balayage.
!>                    Cela peut être utile pour une analyse a posteriori.
!>

LRWORK

!>         LRWORK est INTEGER
!>         Longueur de RWORK.
!>         LRWORK >= 1, si MIN(M,N) = 0, et LRWORK >= MAX(6,N), sinon
!>
!>         Si à l'entrée LRWORK = -1, alors une interrogation d'espace de travail
!>         est supposée et aucun calcul n'est effectué ; RWORK(1) est défini à la
!>         longueur minimale (et optimale) de RWORK.
!>

INFO

!>          INFO est INTEGER
!>          = 0:  sortie réussie.
!>          < 0:  si INFO = -i, alors le i-ème argument avait une valeur illégale
!>          > 0:  CGESVJ n'a pas convergé dans le nombre maximal autorisé
!>                (NSWEEP=30) de balayages. La sortie peut encore être utile.
!>                Voir la description de RWORK.
!>

Détails supplémentaires:

!>
!> La matrice orthogonale N par N V est obtenue comme un produit de rotations
!> planes de Jacobi. Dans le cas de débordement inférieur de la tangente de
!> l'angle de Jacobi, une transformation de Jacobi modifiée de Drmac [3] est
!> utilisée. La stratégie de pivotement utilise des échanges de colonnes de
!> de Rijk [1]. La précision relative des valeurs singulières calculées et la
!> précision des vecteurs singuliers calculés (en métrique d'angle) est telle
!> que garantie par la théorie de Demmel et Veselic [2]. Le nombre de condition
!> qui détermine la précision dans le cas de rang complet est essentiellement
!> min_{D=diag} kappa(A*D), où kappa(.) est le nombre de condition spectral.
!> Les meilleures performances de cette procédure SVD de Jacobi sont obtenues
!> si elle est utilisée dans une version accélérée de Drmac et Veselic [4,5],
!> et c'est la routine noyau dans la bibliothèque SIGMA [6].
!> Certains paramètres d'ajustement (marqués avec [TP]) sont disponibles pour
!> l'implémenteur.
!> La plage de calcul pour les valeurs singulières non nulles est l'intervalle
!> de nombres machine ( UNDERFLOW , OVERFLOW ). Dans les cas extrêmes, même
!> des valeurs singulières dénormalisées peuvent être calculées avec la perte
!> correspondante de chiffres significatifs.
!>

subroutine dgesvj (character*1 joba, character*1 jobu, character*1 jobv, integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( n ) sva, integer mv, double precision, dimension( ldv, * ) v, integer ldv, double precision, dimension( lwork ) work, integer lwork, integer info)

DGESVJ

But:

!>
!> DGESVJ calcule la décomposition en valeurs singulières (SVD) d'une matrice
!> réelle M par N A, où M >= N. La SVD de A est écrite comme
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^t,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> où SIGMA est une matrice diagonale N par N, U est une matrice M par N
!> orthonormale, et V est une matrice orthogonale N par N. Les éléments
!> diagonaux de SIGMA sont les valeurs singulières de A. Les colonnes de U
!> et V sont les vecteurs singuliers gauches et droits de A, respectivement.
!> DGESVJ peut parfois calculer des valeurs singulières très petites et leurs
!> vecteurs singuliers avec beaucoup plus de précision que d'autres routines
!> SVD, voir ci-dessous sous Détails supplémentaires.
!>

Paramètres

JOBA 
!>          JOBA est CHARACTER*1
!>          Spécifie la structure de A.
!>          = 'L': La matrice d'entrée A est triangulaire inférieure;
!>          = 'U': La matrice d'entrée A est triangulaire supérieure;
!>          = 'G': La matrice d'entrée A est une matrice générale M par N, M >= N.
!>

JOBU

!>          JOBU est CHARACTER*1
!>          Spécifie s'il faut calculer les vecteurs singuliers gauches
!>          (colonnes de U):
!>          = 'U': Les vecteurs singuliers gauches correspondant aux valeurs
!>                 singulières non nulles sont calculés et retournés dans les
!>                 colonnes principales de A. Voir plus de détails dans la
!>                 description de A.
!>                 Le seuil d'orthogonalité numérique par défaut est défini à
!>                 approximativement TOL=CTOL*EPS, CTOL=DSQRT(M), EPS=DLAMCH('E').
!>          = 'C': Analogue à JOBU='U', sauf que l'utilisateur peut contrôler le
!>                 niveau d'orthogonalité numérique des vecteurs singuliers
!>                 gauches calculés. TOL peut être défini à TOL = CTOL*EPS, où
!>                 CTOL est donné à l'entrée dans le tableau WORK.
!>                 Aucun CTOL plus petit que ONE n'est autorisé. Un CTOL plus
!>                 grand que 1 / EPS est sans signification. L'option 'C'
!>                 peut être utilisée si M*EPS est une orthogonalité satisfaisante
!>                 des vecteurs singuliers gauches calculés, de sorte que CTOL=M
!>                 pourrait économiser quelques balayages de rotations de Jacobi.
!>                 Voir les descriptions de A et WORK(1).
!>          = 'N': La matrice U n'est pas calculée. Cependant, voir la
!>                 description de A.
!>

JOBV

!>          JOBV est CHARACTER*1
!>          Spécifie s'il faut calculer les vecteurs singuliers droits, c'est-à-dire
!>          la matrice V:
!>          = 'V':  la matrice V est calculée et retournée dans le tableau V
!>          = 'A':  les rotations de Jacobi sont appliquées au tableau V de
!>                  dimension MV par N. En d'autres termes, la matrice des
!>                  vecteurs singuliers droits V n'est pas calculée explicitement,
!>                  mais est appliquée à une matrice MV par N initialement
!>                  stockée dans les MV premières lignes de V.
!>          = 'N':  la matrice V n'est pas calculée et le tableau V n'est pas
!>                  référencé
!>

M

!>          M est INTEGER
!>          Le nombre de lignes de la matrice d'entrée A. 1/DLAMCH('E') > M >= 0.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice d'entrée A.
!>          M >= N >= 0.
!>

A

!>          A est un tableau DOUBLE PRECISION, dimension (LDA,N)
!>          À l'entrée, la matrice M par N A.
!>          À la sortie :
!>          Si JOBU = 'U' .OR. JOBU = 'C' :
!>                 Si INFO = 0 :
!>                 RANKA colonnes orthonormales de U sont retournées dans les
!>                 RANKA colonnes principales du tableau A. Ici RANKA <= N
!>                 est le nombre de valeurs singulières calculées de A qui sont
!>                 au-dessus du seuil de débordement inférieur DLAMCH('S'). Le singular
!>                 vectors corresponding to underflowed or zero singular
!>                 values are not computed. The value of RANKA is returned
!>                 in the array WORK as RANKA=NINT(WORK(2)). Also see the
!>                 descriptions of SVA and WORK. The computed columns of U
!>                 are mutually numerically orthogonal up to approximately
!>                 TOL=DSQRT(M)*EPS (default); or TOL=CTOL*EPS (JOBU = 'C'),
!>                 see the description of JOBU.
!>                 If INFO > 0 :
!>                 the procedure DGESVJ did not converge in the given number
!>                 of iterations (sweeps). In that case, the computed
!>                 columns of U may not be orthogonal up to TOL. The output
!>                 U (stored in A), SIGMA (given by the computed singular
!>                 values in SVA(1:N)) and V is still a decomposition of the
!>                 input matrix A in the sense that the residual
!>                 ||A-SCALE*U*SIGMA*V^t||_2 / ||A||_2 is small.
!>
!>          If JOBU = 'N' :
!>                 If INFO = 0 :
!>                 Note that the left singular vectors are 'for free' in the
!>                 one-sided Jacobi SVD algorithm. However, if only the
!>                 singular values are needed, the level of numerical
!>                 orthogonality of U is not an issue and iterations are
!>                 stopped when the columns of the iterated matrix are
!>                 numerically orthogonal up to approximately M*EPS. Thus,
!>                 on exit, A contains the columns of U scaled with the
!>                 corresponding singular values.
!>                 If INFO > 0 :
!>                 the procedure DGESVJ did not converge in the given number
!>                 of iterations (sweeps).
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!>

SVA

!>          SVA is DOUBLE PRECISION array, dimension (N)
!>          On exit :
!>          If INFO = 0 :
!>          depending on the value SCALE = WORK(1), we have:
!>                 If SCALE = ONE :
!>                 SVA(1:N) contains the computed singular values of A.
!>                 During the computation SVA contains the Euclidean column
!>                 norms of the iterated matrices in the array A.
!>                 If SCALE .NE. ONE :
!>                 The singular values of A are SCALE*SVA(1:N), and this
!>                 factored representation is due to the fact that some of the
!>                 singular values of A might underflow or overflow.
!>          If INFO > 0 :
!>          the procedure DGESVJ did not converge in the given number of
!>          iterations (sweeps) and SCALE*SVA(1:N) may not be accurate.
!>

MV

!>          MV is INTEGER
!>          If JOBV = 'A', then the product of Jacobi rotations in DGESVJ
!>          is applied to the first MV rows of V. See the description of JOBV.
!>

V

!>          V is DOUBLE PRECISION array, dimension (LDV,N)
!>          If JOBV = 'V', then V contains on exit the N-by-N matrix of
!>                         the right singular vectors;
!>          If JOBV = 'A', then V contains the product of the computed right
!>                         singular vector matrix and the initial matrix in
!>                         the array V.
!>          If JOBV = 'N', then V is not referenced.
!>

LDV

!>          LDV is INTEGER
!>          The leading dimension of the array V, LDV >= 1.
!>          If JOBV = 'V', then LDV >= max(1,N).
!>          If JOBV = 'A', then LDV >= max(1,MV) .
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK))
!>          On entry :
!>          If JOBU = 'C' :
!>          WORK(1) = CTOL, where CTOL defines the threshold for convergence.
!>                    The process stops if all columns of A are mutually
!>                    orthogonal up to CTOL*EPS, EPS=DLAMCH('E').
!>                    It is required that CTOL >= ONE, i.e. it is not
!>                    allowed to force the routine to obtain orthogonality
!>                    below EPS.
!>          On exit :
!>          WORK(1) = SCALE is the scaling factor such that SCALE*SVA(1:N)
!>                    are the computed singular values of A.
!>                    (See description of SVA().)
!>          WORK(2) = NINT(WORK(2)) is the number of the computed nonzero
!>                    singular values.
!>          WORK(3) = NINT(WORK(3)) is the number of the computed singular
!>                    values that are larger than the underflow threshold.
!>          WORK(4) = NINT(WORK(4)) is the number of sweeps of Jacobi
!>                    rotations needed for numerical convergence.
!>          WORK(5) = max_{i.NE.j} |COS(A(:,i),A(:,j))| in the last sweep.
!>                    This is useful information in cases when DGESVJ did
!>                    not converge, as it can be used to estimate whether
!>                    the output is still useful and for post festum analysis.
!>          WORK(6) = the largest absolute value over all sines of the

Further Details:

!>
!>  The orthogonal N-by-N matrix V is obtained as a product of Jacobi plane
!>  rotations. The rotations are implemented as fast scaled rotations of
!>  Anda and Park [1]. In the case of underflow of the Jacobi angle, a
!>  modified Jacobi transformation of Drmac [4] is used. Pivot strategy uses
!>  column interchanges of de Rijk [2]. The relative accuracy of the computed
!>  singular values and the accuracy of the computed singular vectors (in
!>  angle metric) is as guaranteed by the theory of Demmel and Veselic [3].
!>  The condition number that determines the accuracy in the full rank case
!>  is essentially min_{D=diag} kappa(A*D), where kappa(.) is the
!>  spectral condition number. The best performance of this Jacobi SVD
!>  procedure is achieved if used in an  accelerated version of Drmac and
!>  Veselic [5,6], and it is the kernel routine in the SIGMA library [7].
!>  Some tuning parameters (marked with [TP]) are available for the
!>  implementer.
!>  The computational range for the nonzero singular values is the  machine
!>  number interval ( UNDERFLOW , OVERFLOW ). In extreme cases, even
!>  denormalized singular values can be computed with the corresponding
!>  gradual loss of accurate digits.

Purpose:

!>
!> SGESVJ computes the singular value decomposition (SVD) of a real
!> M-by-N matrix A, where M >= N. The SVD of A is written as
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^t,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> where SIGMA is an N-by-N diagonal matrix, U is an M-by-N orthonormal
!> matrix, and V is an N-by-N orthogonal matrix. The diagonal elements
!> of SIGMA are the singular values of A. The columns of U and V are the
!> left and the right singular vectors of A, respectively.
!> SGESVJ can sometimes compute tiny singular values and their singular vectors much
!> more accurately than other SVD routines, see below under Further Details.
!>

Détails supplémentaires :

La matrice orthogonale N par N V est obtenue comme un produit de rotations planes de Jacobi. Les rotations sont implémentées comme des rotations mises à l'échelle rapides de Anda et Park [1]. Dans le cas de débordement inférieur de l'angle de Jacobi, une transformation de Jacobi modifiée de Drmac [4] est utilisée. La stratégie de pivotement utilise des échanges de colonnes de de Rijk [2]. La précision relative des valeurs singulières calculées et la précision des vecteurs singuliers calculés (en métrique angulaire) est telle que garantie par la théorie de Demmel et Veselic [3]. Le nombre de condition qui détermine la précision dans le cas de rang complet est essentiellement min_{D=diag} kappa(A*D), où kappa(.) est le nombre de condition spectral. Les meilleures performances de cette procédure de SVD de Jacobi sont obtenues si elle est utilisée dans une version accélérée de Drmac et Veselic [5,6], et c'est la routine noyau de la bibliothèque SIGMA [7]. Certains paramètres de réglage (marqués avec [TP]) sont disponibles pour l'implémenteur.
La plage de calcul pour les valeurs singulières non nulles est l'intervalle des nombres machine ( UNDERFLOW , OVERFLOW ). Dans des cas extrêmes, même des valeurs singulières dénormalisées peuvent être calculées avec la perte correspondante d'ordres de grandeur précis.

!>          d'itérations (passages) et SCALE*SVA(1:N) peut ne pas être précis.
!>

MV

!>          MV est INTEGER
!>          Si JOBV = 'A', alors le produit des rotations de Jacobi dans ZGESVJ
!>          est appliqué aux MV premières lignes de V. Voir la description de JOBV.
!>

V

!>          V est un tableau COMPLEX*16, dimension (LDV,N)
!>          Si JOBV = 'V', alors V contient en sortie la matrice N par N des
!>                         vecteurs singuliers droits ;
!>          Si JOBV = 'A', alors V contient le produit de la matrice des vecteurs singuliers droits calculée et de la matrice initiale dans
!>                         le tableau V.
!>          Si JOBV = 'N', alors V n'est pas référencé.
!>

LDV

!>          LDV est INTEGER
!>          La dimension principale du tableau V, LDV >= 1.
!>          Si JOBV = 'V', alors LDV >= MAX(1,N).
!>          Si JOBV = 'A', alors LDV >= MAX(1,MV).
!>

CWORK

!>          CWORK est un tableau COMPLEX*16, dimension (MAX(1,LWORK))
!>          Utilisé comme espace de travail.
!>

!>          LWORK est INTEGER.
!>          Longueur de CWORK.
!>          LWORK >= 1, si MIN(M,N) = 0, et LWORK >= M+N sinon.
!>
!>          Si à l'entrée LWORK = -1, alors une requête d'espace de travail est supposée et
!>          aucun calcul n'est effectué ; CWORK(1) est défini à la longueur minimale (et optimale)
!>          de CWORK.
!>

RWORK

!>          RWORK est un tableau DOUBLE PRECISION, dimension (max(6,LRWORK))
!>          En entrée,
!>          Si JOBU = 'C' :
!>          RWORK(1) = CTOL, où CTOL définit le seuil de convergence.
!>                    Le processus s'arrête si toutes les colonnes de A sont mutuellement
!>                    orthogonales jusqu'à CTOL*EPS, EPS=DLAMCH('E').
!>                    Il est requis que CTOL >= UN, c'est-à-dire qu'il n'est pas
!>                    autorisé de forcer la routine à obtenir une orthogonalité
!>                    inférieure à EPSILON.
!>          En sortie,
!>          RWORK(1) = SCALE est le facteur d'échelle tel que SCALE*SVA(1:N)
!>                    sont les valeurs singulières calculées de A.
!>                    (Voir la description de SVA().)
!>          RWORK(2) = NINT(RWORK(2)) est le nombre de valeurs singulières non nulles
!>                    calculées.
!>          RWORK(3) = NINT(RWORK(3)) est le nombre de valeurs singulières
!>                    calculées qui sont supérieures au seuil de sous-débordement.
!>          RWORK(4) = NINT(RWORK(4)) est le nombre de passages de rotations de Jacobi
!>                    nécessaires pour la convergence numérique.
!>          RWORK(5) = max_{i.NE.j} |COS(A(:,i),A(:,j))| lors du dernier passage.
!>                    C'est une information utile dans les cas où ZGESVJ
!>                    n'a pas convergé, car elle peut être utilisée pour estimer si
!>                    la sortie est toujours utile et pour une analyse post-mortem.
!>          RWORK(6) = le plus grand a
valeur absolue sur tous les sinus des !> angles de rotation de Jacobi lors du dernier balayage. Cela peut être !> utile pour une analyse a posteriori. !>

LRWORK

!>         LRWORK est un INTEGER
!>         Longueur de RWORK.
!>         LRWORK >= 1, si MIN(M,N) = 0, et LRWORK >= MAX(6,N), sinon.
!>
!>         Si à l'entrée LRWORK = -1, alors une interrogation d'espace de travail est supposée et
!>         aucun calcul n'est effectué ; RWORK(1) est défini à la longueur minimale (et optimale)
!>         de RWORK.

Détails supplémentaires :

!>
!> La matrice orthogonale N par N V est obtenue comme un produit de rotations
!> planes de Jacobi. Dans le cas d'un débordement (underflow) de la tangente de
!> l'angle de Jacobi, une transformation de Jacobi modifiée de Drmac [3] est
!> utilisée. La stratégie de pivotement utilise les permutations de colonnes de
!> de Rijk [1]. La précision relative des valeurs singulières calculées et la
!> précision des vecteurs singuliers calculés (en métrique angulaire) sont
!> garanties par la théorie de Demmel et Veselic [2].
!> Le nombre de condition qui détermine la précision dans le cas de rang
!> complet est essentiellement min_{D=diag} kappa(A*D), où kappa(.) est le
!> nombre de condition spectral. Les meilleures performances de cette procédure
!> SVD Jacobi sont obtenues si elle est utilisée dans une version accélérée de
!> Drmac et Veselic [4,5], et c'est la routine noyau de la bibliothèque SIGMA [6].
!> Certains paramètres d'ajustement (marqués avec [TP]) sont disponibles pour
!> l'implémenteur.
!> La plage de calcul pour les valeurs singulières non nulles est l'intervalle
!> de nombres machine ( UNDERFLOW , OVERFLOW ). Dans des cas extrêmes, même
!> des valeurs singulières dénormalisées peuvent être calculées avec la perte
!> correspondante de chiffres significatifs.
!>
