NOM

get_auditfail_action - Obtenir la valeur tunable failure_action

SYNOPSIS

#include <libaudit.h>
int get_auditfail_action(auditfail_t *failmode);

DESCRIPTION

Cette fonction obtient la valeur tunable failure_action stockée dans /etc/libaudit.conf. get_auditfail_action doit être appelée après qu'un appel à audit_open retourne une erreur pour voir quelle action l'administrateur préfère.

La valeur failure_action trouvée dans /etc/libaudit.conf est copiée dans l'argument failmode lors du retour de la fonction. Cette valeur doit ensuite être utilisée par l'application appelante pour déterminer quelle action doit être effectuée lorsque le sous-système d'audit n'est pas disponible.

VALEUR DE RETOUR

En cas de succès, get_auditfail_action retourne zéro, et l'argument failmode contiendra la valeur failure_action. Les valeurs possibles pour failure_action sont : FAIL_IGNORE (0), FAIL_LOG (1), et FAIL_TERMINATE (2). En cas d'échec, get_auditfail_action retourne un code de retour de un.

ERREURS

Une erreur est retournée s'il y a une erreur lors de la lecture de /etc/libaudit.conf ou si la tunable failure_action n'est pas trouvée dans le fichier.

EXEMPLES


/* Exemple de code */
auditfail_t failmode;


if ((fd = audit_open() ) < 0 ) {
fprintf (stderr, "Impossible d'ouvrir le socket d'audit netlink");


/* Obtenir la failure_action */
if ((rc = get_auditfail_action(&failmode)) == 0) {
if (failmode == FAIL_LOG)
fprintf (stderr, "Sous-système d'audit indisponible");
else if (failmode == FAIL_TERMINATE)
exit (1);
/* Si failmode == FAIL_IGNORE, ne rien faire */
}
}

VOIR AUSSI

audit_open(3), auditd(8).
