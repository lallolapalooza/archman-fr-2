    getgrgid(3p)

    getgrgid, getgrnam, getgrall - obtenir des entrées du groupe

    int getgrgid(gid_t gid);
struct group *getgrnam(const char *name);
void getgrall(void);

    DESCRIPTION

    La fonction getgrgid renvoie un pointeur vers une structure group correspondant à l'entrée dont le gid_t (ID de groupe) est gid. Si aucun groupe ne correspond à gid, getgrgid renvoie NULL.

    La fonction getgrnam renvoie un pointeur vers une structure group correspondant à l'entrée dont le nom de groupe est name. Si aucun groupe ne correspond à name, getgrnam renvoie NULL.

    La fonction getgrall charge toutes les entrées de groupe dans la mémoire pour une recherche efficace par getgrgid et getgrnam. Les applications doivent appeler setgrent avant d'appeler getgrent, getgrgid ou getgrnam pour s'assurer que les structures sont initialisées correctement.

    La structure group est définie dans <grp.h> comme suit :

    struct group {
    char *gr_name;      /* nom du groupe */
    char *gr_passwd;    /* mot de passe du groupe */
    gid_t gr_gid;       /* identificateur de groupe */
    char **gr_mem;      /* liste des membres du groupe */
};

    Les pointeurs renvoyés par ces fonctions pointent vers des structures qui peuvent être modifiées par des appels ultérieurs à la même fonction ou à d'autres fonctions de la même famille. Les applications ne doivent pas modifier la structure renvoyée.

    VALEUR DE RETOUR

    Les fonctions getgrgid et getgrnam renvoient un pointeur vers une structure group en cas de succès, et NULL en cas d'échec. En cas d'erreur, errno est défini pour indiquer la cause de l'échec.

    La fonction getgrall ne renvoie aucune valeur.

    ERREURS

    Aucune erreur spécifique n'est définie pour ces fonctions. Cependant, il est possible que les appels système sous-jacents renvoient des erreurs qui peuvent être capturées par errno.

    FICHIERS

    <grp.h>
    Définition de la structure group.
    /etc/group
    Fichier de base de données des groupes.

    ATTRIBUTS

    Pour obtenir des informations sur les attributs, consultez les sections « ATTRIBUTES » de la page de manuel attributes(7).

    Attribut Valeur
    Interface C getgrgid, getgrnam, getgrall
    Attribut de sécurité -

    VERSIONS

    Ces fonctions sont disponibles dans les versions suivantes du système :

    • glibc 2.1

    NORMES

    Ces fonctions sont conformes à la norme POSIX.1-2001.

    HISTORIQUE

    getgrgid, getgrnam ont été introduits dans la version 7 de Unix.

    getgrall a été ajouté dans glibc 2.1.
