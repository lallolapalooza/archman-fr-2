NOM

gets - Lire une ligne d'un canal

SYNOPSIS

gets channelId ?varName?

DESCRIPTION

Cette commande lit la prochaine ligne de channelId, retourne tout dans la ligne jusqu'aux caractères de fin de ligne (sans les inclure) et supprime les caractères de fin de ligne.

ChannelId doit être un identifiant pour un canal ouvert tel que le canal d'entrée standard Tcl (stdin), la valeur de retour d'une invocation de open ou socket, ou le résultat d'une commande de création de canal fournie par une extension Tcl. Le canal doit avoir été ouvert en lecture.

Si varName est omis, la ligne est retournée comme résultat de la commande. Si varName est spécifié, la ligne est placée dans la variable du nom indiqué et la valeur de retour est un compte du nombre de caractères retournés.

Si la fin du fichier survient pendant la recherche d'une fin de ligne, la commande retourne toute entrée disponible jusqu'à la fin du fichier. Si channelId est en mode non bloquant et qu'il n'y a pas assez de données complètes disponibles, la commande retourne une chaîne vide et ne consomme aucune entrée. Si varName est spécifié et qu'une chaîne vide est retournée dans varName en raison de la fin du fichier ou d'un manque de données en mode non bloquant, le compte de retour est -1. Notez que si varName n'est pas spécifié, les cas de fin de fichier et de données insuffisantes peuvent produire les mêmes résultats que s'il y avait une ligne d'entrée consistant uniquement en les caractères de fin de ligne. Les commandes eof et fblocked peuvent être utilisées pour distinguer ces trois cas.

EXEMPLE

Cet exemple lit un fichier ligne par ligne et l'affiche avec le numéro de ligne courant attaché au début de chaque ligne.

set chan [open "some.file.txt"]
set lineNumber 0
while {[gets $chan line] >= 0} {
    puts "[incr lineNumber]: $line"
}
close $chan
