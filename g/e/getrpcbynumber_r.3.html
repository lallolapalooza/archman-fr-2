getrpcent_r(3) Manuel des fonctions de bibliothèque getrpcent_r(3)

NOM

getrpcent_r, getrpcbyname_r, getrpcbynumber_r - obtenir une entrée RPC (réentrant)

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <netdb.h>
int getrpcent_r(size_t size;
                struct rpcent *result_buf, char buf[size],
                size_t size, struct rpcent **result);
int getrpcbyname_r(size_t size;
                const char *name,
                struct rpcent *result_buf, char buf[size],
                size_t size, struct rpcent **result);
int getrpcbynumber_r(size_t size;
                int number,
                struct rpcent *result_buf, char buf[size],
                size_t size, struct rpcent **result);
Conditions de test de fonctionnalité pour glibc (voir feature_test_macros(7)) :

getrpcent_r(), getrpcbyname_r(), getrpcbynumber_r() :

    Depuis glibc 2.19 :
        _DEFAULT_SOURCE
    glibc 2.19 et antérieur :
        _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Les fonctions getrpcent_r(), getrpcbyname_r() et getrpcbynumber_r() sont les équivalents réentrants de, respectivement, getrpcent(3), getrpcbyname(3) et getrpcbynumber(3). Elles diffèrent par la manière dont la structure rpcent est retournée, ainsi que par la signature d'appel de fonction et la valeur de retour. Cette page de manuel décrit uniquement les différences par rapport aux fonctions non réentrantes.

Au lieu de retourner un pointeur vers une structure rpcent statiquement allouée comme résultat de la fonction, ces fonctions copient la structure dans l'emplacement pointé par result_buf.

Le tableau buf est utilisé pour stocker les champs de chaîne pointés par la structure rpcent retournée. (Les fonctions non réentrantes allouent ces chaînes dans une mémoire statique.) La taille de ce tableau est spécifiée dans size. Si buf est trop petit, l'appel échoue avec l'erreur ERANGE, et l'appelant doit réessayer avec un tampon plus grand. (Un tampon de 1024 octets devrait être suffisant pour la plupart des applications.)

Si l'appel de fonction obtient avec succès un enregistrement RPC, alors *result est défini pour pointer vers result_buf ; sinon, *result est défini à NULL.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent 0. En cas d'erreur, elles retournent l'un des numéros d'erreur positifs listés dans ERREURS.

En cas d'erreur, d'enregistrement non trouvé (getrpcbyname_r(), getrpcbynumber_r()), ou de fin d'entrée (getrpcent_r()), *result est défini à NULL.

ERREURS

ENOENT
(getrpcent_r()) Aucun autre enregistrement dans la base de données.
ERANGE
buf est trop petit. Réessayez avec un tampon plus grand (et size augmenté).

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
getrpcent_r (), getrpcbyname_r (), getrpcbynumber_r () Sécurité des threads MT-Safe locale

VERSIONS

Des fonctions aux noms similaires existent sur d'autres systèmes, bien que généralement avec des signatures d'appel différentes.

NORMES

GNU.

VOIR AUSSI
