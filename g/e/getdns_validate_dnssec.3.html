NOM

getdns_validate_dnssec -- Valide le DNSSEC d'un enregistrement getdns donné

BIBLIOTHÈQUE

Bibliothèque de résolution DNS (libgetdns, -lgetdns)

SYNTAXE

#include <getdns.h>

getdns_return_t
getdns_validate_dnssec (getdns_list *record_to_validate,

getdns_list *bundle_of_support_records,
getdns_list *trust_anchor_records)

DESCRIPTION

Si une application souhaite que l'API effectue la validation DNSSEC sans utiliser les extensions, elle peut utiliser la fonction d'aide getdns_validate_dnssec(). L'API utilisera les enregistrements de ressources dans bundle_of_support_records pour construire la chaîne de validation et les enregistrements DNSKEY ou DS dans trust_anchor_records comme ancres de confiance. La liste par défaut des enregistrements d'ancres de confiance utilisée par la bibliothèque pour valider le DNSSEC peut être récupérée en utilisant la fonction d'aide getdns_root_trust_anchor.

record_to_validate l'enregistrement de ressources en cours de validation

bundle_of_support_records enregistrements utilisés pour construire la chaîne de validation

trust_anchor_records enregistrements d'ancres de confiance à utiliser pour la validation

VALEURS DE RETOUR

GETDNS_DNSSEC_BOGUS la signature DNSSEC est invalide

GETDNS_DNSSEC_INDETERMINATE la validation n'a pas pu être achevée

GETDNS_DNSSEC_INSECURE une ou plusieurs pièces de la chaîne de validation sont manifestement incorrectes

GETDNS_DNSSEC_SECURE la validation a réussi

GETDNS_RETURN_MEMORY_ERROR une tentative d'allocation de mémoire a échoué
