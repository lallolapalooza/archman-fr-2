NOM

Geany — un environnement de développement intégré petit et léger

SYNTAXE

geany [option] [+nombre] [fichiers ...]

DESCRIPTION

Geany est un éditeur petit et rapide avec les fonctionnalités de base d'un environnement de développement intégré.

Certaines de ses caractéristiques : coloration syntaxique, complétion de code, pliage de code, listes de symboles/tags et de nombreux types de fichiers supportés comme C(++), Java, PHP, HTML, DocBook, Perl et plus.

Page d'accueil : https://www.geany.org/

OPTIONS

fichiers ...
Une liste séparée par des espaces de noms de fichiers. Des noms de fichiers absolus et relatifs peuvent être utilisés. Geany reconnaît également les informations de ligne et de colonne lorsqu'elles sont ajoutées au nom du fichier avec des deux-points, par exemple "geany foo.bar:10:5" ouvrira le fichier foo.bar et placera le curseur à la ligne 10 à la colonne 5.
Les projets peuvent également être ouverts mais un fichier de projet (*.geany) doit être le premier argument ne correspondant pas à une option. Tous les fichiers donnés en plus seront ignorés.
+nombre
Définit le nombre de ligne initial pour le premier fichier ouvert (identique à --line, ne pas mettre d'espace entre le signe + et le nombre). Par exemple, "geany +7 foo.bar" ouvrira le fichier foo.bar et placera le curseur à la ligne 7.
--colonne
Définit le numéro de colonne initial pour le premier fichier ouvert (utile en conjonction avec --ligne).
-c, --config
Utilise un répertoire de configuration alternatif. Le répertoire de configuration par défaut est ~/.config/geany/ et contient geany.conf et quelques fichiers de modèle.
--ft-names
Affiche une liste des noms de types de fichiers internes de Geany (utile pour la configuration des snippets).
-g, --generate-tags
Génère un fichier de tags global (voir la documentation).
-P, --no-preprocessing
Ne préprocesse pas les fichiers C/C++ lors de la génération des tags.
-i, --new-instance
N'ouvre pas les fichiers dans une instance en cours d'exécution, force l'ouverture d'une nouvelle instance. Uniquement disponible si Geany a été compilé avec le support des Sockets.
-l, --line
Définit le numéro de ligne initial pour le premier fichier ouvert.
--list-documents
Retourne une liste des documents ouverts dans une instance Geany en cours d'exécution. Ceci peut être utilisé pour lire les documents actuellement ouverts dans Geany à partir d'un script ou outil externe. La liste retournée est séparée par des sauts de ligne (LF) et consiste en des noms de fichiers complets, encodés en UTF-8, des documents. Uniquement disponible si Geany a été compilé avec le support des Sockets.
-m, --no-msgwin
N'affiche pas la fenêtre des messages. Utilisez cette option si vous n'avez pas besoin des messages du compilateur ou du support VTE.
-n, --no-ctags
Ne charge pas les données de complétion de symboles et d'astuces d'appel. Utilisez cette option si vous ne souhaitez pas les utiliser. Pour plus d'informations, veuillez consulter la documentation.
-p, --no-plugins
Ne charge pas le support des plugins.
--print-prefix
Affiche le préfixe d'installation, le répertoire des données, le répertoire lib et le répertoire des locales (dans cet ordre) sur la sortie standard, un par ligne. Ceci est principalement destiné aux auteurs de plugins pour détecter les chemins d'installation.
-r, --read-only
Ouvre tous les fichiers donnés sur la ligne de commande en mode lecture seule. Ceci s'applique uniquement aux fichiers ouverts explicitement depuis la ligne de commande, donc les fichiers des sessions précédentes ou les fichiers de projet ne sont pas affectés.
-s, --no-session
Ne charge pas les fichiers de la session précédente.
-t, --no-terminal
Ne charge pas le support du terminal. Utilisez cette option si vous ne souhaitez pas charger le widget émulateur de terminal virtuel au démarrage. Si vous n'avez pas libvte.so.4 installé, le support du terminal est automatiquement désactivé. Uniquement disponible si Geany a été compilé avec le support VTE.
--socket-file
Utilise ce nom de fichier socket pour la communication avec une instance Geany en cours d'exécution
--vte-lib
Spécifie explicitement le chemin incluant le nom de fichier ou seulement le nom de fichier de la bibliothèque VTE, par exemple /usr/lib/libvte.so ou libvte.so. Cette option n'est nécessaire que lorsque la détection automatique ne fonctionne pas. Uniquement disponible si Geany a été compilé avec le support VTE.
-v, --verbose
Soyez bavard (affichez des messages d'état utiles).
-V, --version
Affiche les informations de version et quitte.
-?, --help
Affiche les informations d'aide et quitte.

Geany prend en charge toutes les options GTK génériques, une liste est disponible sur l'écran d'aide.
