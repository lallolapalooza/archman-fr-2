gearman_failed(3)

Paquet: gearmand

Licences: BSD-3-Clause

GEARMAN_FAILED(3) Gearmand GEARMAN_FAILED(3)

NOM

gearman_failed - Documentation de Gearmand, https://gearman.org/gearmand/

SYNOPSIS

#include <libgearman/gearman.h>

type gearman_return_t
const char *gearman_strerror(gearman_return_t rc)
bool gearman_success(gearman_return_t rc)
bool gearman_failed(gearman_return_t rc)
bool gearman_continue(gearman_return_t rc)

Compiler et lier avec -lgearman

DESCRIPTION

gearman_return_t est utilisé comme type de retour/erreur pour tous les appels utilisant gearman_client_st et gearman_worker_st. GEARMAN_SUCCESS est renvoyé en cas de succès, sinon une erreur est renvoyée. gearman_failed() peut être utilisé pour vérifier si la valeur de retour est une valeur d'échec. Vous pouvez afficher une version textuelle du message d'erreur avec gearman_strerror().

gearman_success() renvoie true si GEARMAN_SUCCESS ou si GEARMAN_NO_PENDING_TASKS est vrai.

gearman_failed() renvoie true si une valeur autre que GEARMAN_SUCCESS a été fournie.

gearman_continue() renvoie true si une erreur liée à l'entrée/sortie non bloquante s'est produite. Cela devrait être utilisé pour les boucles de test.

Valeurs possibles de gearman_return_t:

type GEARMAN_NO_PENDING_TASKS
gearman_client_run_tasks() a été appelé et il a terminé toutes les tâches assignées au client.
type GEARMAN_IO_WAIT
Une entrée/sortie bloquante a été détectée. gearman_continue() peut être utilisé pour tester cela.
type GEARMAN_ERRNO
Une erreur système s'est produite. Utilisez soit gearman_client_errno() ou gearman_worker_errno()
type GEARMAN_NO_ACTIVE_FDS
Aucune connexion active n'était disponible. gearman_continue() peut être utilisé pour tester cela.
type GEARMAN_GETADDRINFO
La résolution de nom a échoué pour un hôte.
type GEARMAN_NO_SERVERS
Aucun serveur n'a été fourni pour le client/l'ouvrier.
type GEARMAN_LOST_CONNECTION
La connexion au serveur donné a été perdue.
type GEARMAN_MEMORY_ALLOCATION_FAILURE
L'allocation de mémoire a échoué.
type GEARMAN_SERVER_ERROR
Une erreur s'est produite sur le serveur.
type GEARMAN_NOT_CONNECTED
Le client/l'ouvrier n'est pas actuellement connecté au serveur.
type GEARMAN_COULD_NOT_CONNECT
Le nom du serveur était valide, mais une connexion n'a pas pu être établie.
type GEARMAN_ECHO_DATA_CORRUPTION
Soit gearman_client_echo() ou gearman_worker_echo() l'écho a échoué car les données ont été renvoyées depuis gearmand corrompues.
type GEARMAN_UNKNOWN_STATE
Le gearman_return_t n'a jamais été défini.
type GEARMAN_FLUSH_DATA
État interne, ne devrait jamais être vu par le client ou l'ouvrier.
type GEARMAN_SEND_BUFFER_TOO_SMALL
Le tampon d'envoi était trop petit.
type GEARMAN_TIMEOUT
Un délai d'attente s'est produit lors de la réalisation d'une requête au serveur.
type GEARMAN_ARGUMENT_TOO_LARGE
L'argument était trop grand pour le tampon actuel.
type GEARMAN_INVALID_ARGUMENT
L'un des arguments de l'appel API donné était invalide. EINVAL sera défini si gearman_client_error() ou gearman_worker_error() n'ont pas pu être définis. Cela peut aussi être renvoyé si GEARMAN_CLIENT_UNBUFFERED_RESULT a été défini, mais le client ne gère pas les données correctement.

CLIENT UNIQUEMENT

type GEARMAN_NEED_WORKLOAD_FN
Un client a demandé du travail, mais aucune gearman_workload_fn fonction de rappel n'a été spécifiée. Voir gearman_client_set_workload_fn()
type GEARMAN_WORK_FAIL
Une tâche a échoué, et l'ouvrier est sorti avec une erreur ou a appelé gearman_job_send_fail()
type GEARMAN_IN_PROGRESS
gearman_client_job_status() a été appelé pour un gearman_job_handle_t et le travail est actuellement en cours d'exécution par un ouvrier.
type GEARMAN_JOB_EXISTS
gearman_client_job_status() a été appelé pour un gearman_job_handle_t et le travail est actuellement connu par un serveur, mais n'est pas en cours d'exécution par un ouvrier.

OUVRIER UNIQUEMENT

type GEARMAN_INVALID_FUNCTION_NAME
Une requête a été envoyée à un ouvrier pour un travail pour lequel il n'avait pas de fonction valide.
type GEARMAN_INVALID_WORKLOAD_FUNCTION
Aucune fonction de rappel n'a été fournie par l'ouvrier pour une fonction donnée.
type GEARMAN_NO_REGISTERED_FUNCTION
Une requête de suppression d'une fonction donnée d'un ouvrier était invalide car cette fonction n'existait pas.
type GEARMAN_NO_REGISTERED_FUNCTIONS
L'ouvrier n'a enregistré aucune fonction.
type GEARMAN_NO_JOBS
Aucun travail n'a été trouvé pour l'ouvrier. Ce code d'erreur n'est renvoyé que si gearman_failed.3.en - Manuel

NAME

gearman_failed - A list of return codes that may be returned from a gearman job.

SYNOPSIS

#include <libgearman/gearman.h>

DESCRIPTION

The following return values are used by Gearman for various operations.

CLIENT TO SERVER

These return codes are used by the client when making requests to the server.

type GEARMAN_GET_EPS
Client is requesting a list of available functions from the server.
type GEARMAN_GET_OPTIONS
Client is requesting options from the server.
type GEARMAN_GET_STATUS
Client is requesting status from the server.
type GEARMAN_GET_JOBS
Client is requesting a list of jobs from the server.
type GEARMAN_GET_ALL_JOBS
Client is requesting a list of all jobs from the server.
type GEARMAN_GET_CLIENT_ID
Client is requesting its unique ID from the server.
type GEARMAN_CAN_DO
Worker is telling the server that it can do a specific function.
type GEARMAN_CANT_DO
Worker is telling the server that it cannot do a specific function.
type GEARMAN_RESET_ABILITIES
Worker is telling the server to reset its list of functions it can do.
type GEARMAN_PRESLEEP
Worker is telling the server that it is going to sleep.
type GEARMAN_SLEEP
Worker is telling the server that it is sleeping.
type GEARMAN_WORK_USER_ID
Worker is sending a workload to the server.
type GEARMAN_WORK_GEARMAN_JOB_MAX
Worker is sending a workload to the server.
type GEARMAN_WORK_QUIT
Worker is telling the server that it is quitting.
type GEARMAN_SUBMIT_JOB
Client is submitting a job to the server.
type GEARMAN_SUBMIT_JOB_BG
Client is submitting a background job to the server.
type GEARMAN_SUBMIT_JOB_HIGH
Client is submitting a high priority job to the server.
type GEARMAN_SUBMIT_JOB_HIGH_BG
Client is submitting a high priority background job to the server.
type GEARMAN_SUBMIT_JOB_LOW
Client is submitting a low priority job to the server.
type GEARMAN_SUBMIT_JOB_LOW_BG
Client is submitting a low priority background job to the server.
type GEARMAN_JOB_CREATED
Server has created a job.
type GEARMAN_JOB_ASSIGNED
Server has assigned a job to a worker.
type GEARMAN_JOB_FAIL
Job has failed.
type GEARMAN_JOB_COMPLETE
Job has been completed.
type GEARMAN_JOB_REDELIVERED
Job has been redelivered.
type GEARMAN_STATUS_COMPLETE
Status update for a job that is complete.
type GEARMAN_STATUS_FAILED
Status update for a job that has failed.
type GEARMAN_NEW_JOB_SCHEDULING
The worker has just made a request for jobs.

WORKER TO CLIENT

Client which have registed a custom gearman_actions_t may use these value as return values to the calling client.

type GEARMAN_WORK_DATA
Worker has sent a chunked piece of data to the client via gearman_job_send_data()
type GEARMAN_WORK_WARNING
Worker has issued a warning to the client via gearman_job_send_warning()
type GEARMAN_WORK_STATUS
Status has been updated by the worker via gearman_job_send_status()
type GEARMAN_WORK_EXCEPTION
Worker has sent an exception the client via gearman_job_send_exception()
type GEARMAN_WORK_ERROR
A task has had an error and will be retried.
type GEARMAN_PAUSE
Used only in custom application for client return based on GEARMAN_WORK_DATA, GEARMAN_WORK_WARNING, GEARMAN_WORK_EXCEPTION, GEARMAN_WORK_FAIL, or GEARMAN_WORK_STATUS. gearman_continue() can be used to check for this value.

WORKER TO CLIENT

Any function defined by gearman_worker_define_function() may, and can only, return the following gearman_return_t values.

type GEARMAN_FATAL
type GEARMAN_FAIL
The function failed to complete the job. GEARMAN_FATAL is the deprecated name for GEARMAN_FAIL
type GEARMAN_ERROR
A task has had an error and will be retried.
type GEARMAN_SHUTDOWN
GEARMAN_SHUTDOWN is a special case. If it is returned the client will be sent GEARMAN_SUCCESS, but gearman_worker_work() will exit with GEARMAN_SHUTDOWN.

TASK ONLY

type GEARMAN_NOT_FLUSHING
gearman_task_send_workload() failed, it was not in the correct state.
type GEARMAN_DATA_TOO_LARGE
gearman_task_send_workload() failed, the data was too large to be sent.
type GEARMAN_UNKNOWN_OPTION
Default state of task return value.

PROTOCOL

If any of these errors occurred the connection will be dropped/reset.

type GEARMAN_INVALID_MAGIC
type GEARMAN_INVALID_COMMAND
type GEARMAN_INVALID_PACKET
type GEARMAN_UNEXPECTED_PACKET
type GEARMAN_TOO_MANY_ARGS

DEPRECATED

type GEARMAN_IGNORE_PACKET
type GEARMAN_MAX_RETURN

VOIR AUSSI

gearmand(8) libgearman(3) gearman_client_error() ou gearman_worker_error()
