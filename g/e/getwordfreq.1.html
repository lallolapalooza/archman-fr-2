NOM

getwordfreq - affiche les informations de fréquence des mots à partir d'un modèle de langue

SYNTAXE

getwordfreq [option]... -m fichier-slm -l lexique

DESCRIPTION

getwordfreq affiche la chaîne de mots et sa fréquence pour tous les mots d'un modèle de langue.

OPTIONS

-s taille-corpus Spécifie la taille du corpus d'entraînement. La taille-corpus par défaut est de 300000000 si elle n'est pas donnée.
-v
Être bavard, afficher d'autres informations après le mot et la fréquence pour chaque ligne.
-e
Donner le format pour ervin.
-m fichier-slm
Spécifie le fichier du modèle de langue.
-l lexique
Spécifie le fichier du lexique. Un lexique par défaut peut être trouvé à l'adresse /usr/share/sunpinyin-slm/dict.utf8.
