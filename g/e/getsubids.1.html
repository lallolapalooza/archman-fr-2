GETSUBIDS(1) Commandes utilisateur GETSUBIDS(1)

NOM

getsubids - obtenir les plages d'identifiants subordonnés pour un utilisateur

SYNTAXE

getsubids [options] UTILISATEUR

DESCRIPTION

La commande getsubids liste les plages d'identifiants utilisateur subordonnés pour un utilisateur donné. Les identifiants de groupe subordonnés peuvent être listés en utilisant l'option -g.

OPTIONS

Les options qui s'appliquent à la commande getsubids sont :

-g

Liste les plages d'identifiants de groupe subordonnés.

-h

Affiche le message d'aide et quitte.

EXEMPLE

Par exemple, pour obtenir les UID subordonnés de l'utilisateur de test :

$ getsubids testuser
0: testuser 100000 65536

La sortie de cette commande fournit (par ordre de gauche à droite) l'indice de la liste, le nom d'utilisateur, le début de la plage d'UID et le nombre d'UID dans la plage.
