getdns_display_ip_address(3) getdns getdns_display_ip_address(3)

NOM

getdns_display_ip_address -- convertir une adresse IP getdns en chaîne de caractères

BIBLIOTHÈQUE

Bibliothèque de résolution DNS (libgetdns, -lgetdns)

SYNTAXE

#include <getdns.h>

char *
getdns_display_ip_address (const getdns_bindata *ipv4_or_ipv6_addr)

DESCRIPTION

Cette fonction d'aide renvoie une représentation textuelle formatée de l'adresse IPv4 ou IPv6. La longueur de la structure bindata est utilisée pour déterminer si l'adresse est IPv4 ou IPv6.

ipv4_or_ipv6_addr structure bindata de l'adresse à afficher

VALEURS DE RETOUR

Renvoie une représentation textuelle de l'adresse IP (allouée en utilisant l'allocateur système - malloc), l'appelant est responsable de libérer la mémoire en utilisant free().
