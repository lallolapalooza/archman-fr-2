getprogname(3bsd)

Paquet: libbsd

Licences: custom

getprogname(3bsd) 3bsd getprogname(3bsd)

NOM

getprogname, setprogname — obtenir et définir le nom du programme

BIBLIOTHÈQUE

bibliothèque “libbsd”

SYNTAXE

#include <stdlib.h> (Voir libbsd(7) pour l'utilisation des includes.)
const char *
getprogname(void);

void
setprogname(const char *progname);

DESCRIPTION

La fonction getprogname() retourne une chaîne de caractères avec le nom du programme courant, sans le composant répertoire. La fonction retournera NULL si elle n'a pas pu obtenir le nom du programme à partir d'une source connue.

La fonction setprogname() définit le nom du programme courant, en supprimant tout préfixe de composant répertoire. La fonction conservera une référence au pointeur de chaîne passé, donc celui-ci ne doit pas être libéré ou modifié tant que ces fonctions pourraient être appelées.

Les implémentations sur la plupart des BSD essaieront d'initialiser le nom du programme au démarrage du programme, et libbsd essaiera de l'inférer à partir de diverses sources connues en fonction du système cible. Mais il n'est pas garanti de manière portable que le nom du programme sera défini sans appeler setprogname(), donc les programmes portables devraient toujours l'appeler après leur démarrage.

VOIR AUSSI

setproctitle(3bsd).

HISTORIQUE

Les fonctions setprogname() et getprogname() sont apparues pour la première fois dans NetBSD 1.6, FreeBSD 4.4, DragonFly 2.1 et OpenBSD 5.4.
