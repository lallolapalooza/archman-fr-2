Les catalogues de messages produits par gencat sont encodés en binaire, ce qui signifie que leur portabilité ne peut être garantie entre différents types de machine. Ainsi, tout comme les programmes C doivent être recompilés pour chaque type de machine, les catalogues de messages doivent être recréés via genc
