getdns_dict_get_data_type(3)

Paquet: getdns

Licences: BSD

getdns_dict_get(3) getdns getdns_dict_get(3)

NOM

getdns_dict_get, getdns_dict_get_bindata, getdns_dict_get_data_type, getdns_dict_get_dict, getdns_dict_get_int, getdns_dict_get_list, getdns_dict_get_names -- obtenir la valeur par nom d'un dictionnaire getdns

BIBLIOTHÈQUE

Bibliothèque de résolution DNS (libgetdns, -lgetdns)

SYNOPSIS

#include <getdns.h>

getdns_return_t
getdns_dict_get_bindata (getdns_dict *this_dict,

char *name,
getdns_bindata **answer)

getdns_return_t
getdns_dict_get_data_type (getdns_dict *this_dict,

char *name,
getdns_data_type *answer)

getdns_return_t
getdns_dict_get_dict (getdns_dict *this_dict,

char *name,
getdns_dict **answer)

getdns_return_t
getdns_dict_get_int (getdns_dict *this_dict,

char *name,
uint32_t *answer)

getdns_return_t
getdns_dict_get_list (getdns_dict *this_dict,

char *name,
getdns_list **answer)

getdns_return_t
getdns_dict_get_names (getdns_dict *this_dict,

getdns_list **answer)

DESCRIPTION

Le type getdns_dict est utilisé pour gérer des paires nom/valeur dans lesquelles les noms sont des chaînes de caractères et les types de données des valeurs sont hétérogènes et incluent


getdns_bindata
getdns_dict
getdns_list
uint32_t

this_dict le dictionnaire à partir duquel récupérer la liste des noms

name le nom dont la valeur associée doit être retournée dans answer

answer la liste de tous les noms dans le dictionnaire. Notez que l'appelant doit libérer la mémoire allouée pour la liste via un appel à getdns_list_destroy(3)

VALEURS DE RETOUR

En cas de succès, les fonctions retournent GETDNS_RETURN_GOOD, sinon les valeurs d'erreur suivantes sont retournées :

GETDNS_RETURN_GENERIC_ERROR si this_dict n'est pas un dictionnaire valide

GETDNS_RETURN_NO_SUCH_DICT_NAME si l'argument name n'existe pas dans le dictionnaire

GETDNS_RETURN_WRONG_TYPE_REQUESTED si le type de données demandé ne correspond pas au contenu de l'argument indexé ou du nom
