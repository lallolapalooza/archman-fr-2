NOM

get-oui - Récupère le fichier OUI d'arp-scan depuis le site web de l'IEEE

SYNTAXE

get-oui [options]

DESCRIPTION

get-oui récupère les données du registre MAC/Vendeur depuis le site web de l'IEEE et les convertit dans le format utilisé par arp-scan. Le contenu des registres suivants est téléchargé et traité :

MA-L 24 bits Le registre OUI original
MA-M 28 bits Registre des blocs d'adresses moyennes
MA-S 36 bits Registre des blocs d'adresses petites (OUI-36)
IAB 36 bits Le registre IAB (fermé aux nouvelles applications)

Ce script crée ieee-oui.txt à partir des données les plus récentes sur le site web de l'IEEE. Vous pouvez exécuter get-oui occasionnellement pour maintenir le fichier OUI à jour.

Les données OUI sont récupérées depuis les URL spécifiées dans le script get-oui et le fichier de sortie est enregistré dans le fichier ieee-oui.txt dans le répertoire courant. Le nom du fichier de sortie peut être modifié avec l'option -f.

Le fichier ieee-oui.txt produit par ce script est utilisé par arp-scan pour déterminer le vendeur de la carte Ethernet à partir de son adresse matérielle.

arp-scan recherchera d'abord ieee-oui.txt dans le répertoire courant. Si cela échoue, il utilisera le fichier système /usr/share/arp-scan/ieee-oui.txt.

OPTIONS

-h
Affiche un bref message d'utilisation et quitte.
-f <nom_fichier>
Écrit la sortie dans le fichier spécifié au lieu du fichier par défaut ieee-oui.txt.
-v
Affiche des messages de progression détaillés.

FICHIERS

ieee-oui.txt
Le fichier de sortie par défaut.

NOTES

get-oui est implémenté en Perl, vous devez donc avoir l'interpréteur Perl installé sur votre système pour l'utiliser.

get-oui utilise les modules Perl LWP::UserAgent et Text::CSV pour récupérer et traiter les données du registre IEEE. Vous devez avoir ces modules installés sur votre système pour que cela fonctionne. Ces modules sont disponibles sur la plupart des distributions, souvent appelés libwww-perl et libtext-csv-perl. Ils sont également disponibles sous forme source depuis CPAN.

Vous pouvez utiliser un serveur proxy en définissant la variable d'environnement http_proxy.
