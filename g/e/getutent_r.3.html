pututline(3) — man pages

NAME

pututline, pututent — add or replace a utmp file entry

LIBRARY

Security Attributes (libsecure, -lsecure)

SYNOPSIS

#include <utmp.h>

int
pututline(const struct utmp *utmp);

DESCRIPTION

The pututline() function writes the structure pointed to by utmp to the current position in the utmp file. The utmp file is updated by using setutent() to open and position it, pututline() to write the record, and endutent() to close it. See utmp(5) for more information about the utmp file structure.

The utmp structure must be filled with valid data. Most fields are handled by the caller. For a list of fields, see utmp(5).

The utmpname() function can be used to specify an alternative utmp file name. The default file is typically /var/run/utmp.

RETURN VALUE

On success, pututline() returns a pointer to the written structure. On failure, it returns NULL.

ERRORS

No specific errors are documented for pututline(). However, system errors can occur if the utmp file cannot be opened or written to.

FILES

/var/run/utmp
The default utmp file.

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7).

| Attribute | Value |
| --------- | ----- |
| Interface Stability | Uncommitted |

STANDARDS

This function is non-standard and is specific to some older Unix systems. It is not part of POSIX or any other major Unix standard.

HISTORY

This function first appeared in BSD.

NOTES

This function is part of a set of functions for manipulating the utmp file. The modern and preferred way to interact with utmp is through the login_tty(3) family of functions, or by directly manipulating the file if necessary, although this is generally discouraged.

Modifying the utmp file directly can have security implications and may lead to inconsistencies if not done carefully. It is generally recommended to use higher-level abstractions if available.

The following example adds and removes a utmp record, assuming it is run from within a pseudo terminal. For usage in a real application, you should check the return values of getpwuid(3) and ttyname(3).

#include <err.h>
#include <pwd.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#include <unistd.h>
#include <utmp.h>
int
main(void)
{
    struct utmp entry;
    if (system("echo before adding entry:;who") == -1)
        err(EXIT_FAILURE, "system");
    entry.ut_type = USER_PROCESS;
    entry.ut_pid = getpid();
    strcpy(entry.ut_line, ttyname(STDIN_FILENO) + strlen("/dev/"));
    /* only correct for ptys named /dev/tty[pqr][0-9a-z] */
    strcpy(entry.ut_id, ttyname(STDIN_FILENO) + strlen("/dev/tty"));
    entry.ut_time = time(NULL);
    strcpy(entry.ut_user, getpwuid(getuid())->pw_name);
    memset(entry.ut_host, 0, UT_HOSTSIZE);
    entry.ut_addr = 0;
    setutent();
    if (pututline(&entry) == NULL)
        err(EXIT_FAILURE, "pututline");
    if (system("echo after adding entry:;who") == -1)
        err(EXIT_FAILURE, "system");
    entry.ut_type = DEAD_PROCESS;
    memset(entry.ut_line, 0, UT_LINESIZE);
    entry.ut_time = 0;
    memset(entry.ut_user, 0, UT_NAMESIZE);
    setutent();
    if (pututline(&entry) == NULL)
        err(EXIT_FAILURE, "pututline");
    if (system("echo after removing entry:;who") == -1)
        err(EXIT_FAILURE, "system");
    endutent();
    exit(EXIT_SUCCESS);
}
