gearman_worker_clone(3)

Paquet: gearmand

Licences: BSD-3-Clause

GEARMAN_WORKER_CLONE(3) Garmand GEARMAN_WORKER_CLONE(3)

NOM

gearman_worker_clone - Documentation Gearmand, https://gearman.org/gearmand/

SYNTAXE

#include <libgearman/gearman.h>

gearman_worker_st *gearman_worker_create(gearman_worker_st *client)
gearman_worker_st *gearman_worker_clone(gearman_worker_st *client, const gearman_worker_st *from)
void gearman_worker_free(gearman_worker_st *client)

Lier avec -lgearman

DESCRIPTION

gearman_worker_create() est utilisé pour créer une structure gearman_worker_st qui sera ensuite utilisée par d'autres fonctions client de libgearman(3) pour communiquer avec le serveur. Vous devriez soit passer une structure gearman_worker_st déclarée statiquement à gearman_worker_create() soit NULL. Si NULL est passé, une structure est allouée pour vous.

gearman_worker_clone() est similaire à gearman_worker_create() mais il copie les valeurs par défaut et la liste des serveurs à partir de la structure source gearman_worker_st. Si vous passez NULL comme argument pour la source à cloner, cela est équivalent à un appel à gearman_worker_create(). Si l'argument de destination est NULL, une structure gearman_worker_st sera allouée pour vous.

Pour nettoyer la mémoire associée à une structure gearman_worker_st, vous devriez la passer à gearman_worker_free() lorsque vous avez terminé de l'utiliser. gearman_worker_free est le seul moyen de s'assurer que toute la mémoire est désallouée lorsque vous terminez d'utiliser la structure.

Vous pourriez souhaiter éviter d'utiliser gearman_worker_create() ou gearman_worker_clone() avec une allocation sur la pile, c'est-à-dire le premier paramètre. Les problèmes les plus courants liés à la sécurité ABI impliquent des structures allouées sur le tas.

VALEUR DE RETOUR

gearman_worker_create() renvoie un pointeur vers la structure gearman_worker_st qui a été créée (ou initialisée). En cas d'échec d'allocation, elle renvoie NULL.

gearman_worker_clone() renvoie un pointeur vers la structure gearman_worker_st qui a été créée (ou initialisée). En cas d'échec d'allocation, elle renvoie NULL.
