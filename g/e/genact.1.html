genact(1) Manuel des commandes générales genact(1)

NOM

genact - Générateur d'activités absurdes

SYNTAXE

genact [-l|--list-modules] [-m|--modules] [-s|--speed-factor] [-i|--instant-print-lines] [--exit-after-time] [--exit-after-modules] [--print-completions] [--print-manpage] [-h|--help] [-V|--version]

DESCRIPTION

Générateur d'activités absurdes

OPTIONS

-l, --list-modules
Lister les modules disponibles
-m, --modules=MODULES
Exécuter uniquement ces modules

[valeurs possibles : ansible, bootlog, botnet, bruteforce, cargo, cc, composer, cryptomining, docker_build, docker_image_rm, download, julia, kernel_compile, memdump, mkinitcpio, rkhunter, simcity, terraform, weblog]

-s, --speed-factor=SPEED_FACTOR [défaut : 1]
Facteur de vitesse global
-i, --instant-print-lines=INSTANT_PRINT_LINES [défaut : 0]
Imprimer instantanément ce nombre de lignes
--exit-after-time=EXIT_AFTER_TIME
Quitter après avoir fonctionné pendant cette durée (exemple de format : 2h10min)
--exit-after-modules=EXIT_AFTER_MODULES
Quitter après avoir exécuté ce nombre de modules
--print-completions=shell
Générer un fichier de complétion pour un shell

[valeurs possibles : bash, elvish, fish, powershell, zsh]

--print-manpage
Générer la page de manuel
-h, --help
Imprimer l'aide
-V, --version
Imprimer la version

VERSION

v1.4.2
