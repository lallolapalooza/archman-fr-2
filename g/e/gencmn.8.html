NOM

gencmn - génère un fichier de données ICU mappable en mémoire

SYNTAXE

gencmn [ -h, -?, --help ] [ -v, --verbose ] [ -c, --copyright | -C, --comment commentaire ] [ -d, --destdir destination ] [ -n, --name nom ] [ -t, --type extfichier ] [ -S, --source ] [ -e, --entrypoint nom ] taillemax [ fichierliste ]

DESCRIPTION

gencmn prend un ensemble de fichiers et les regroupe dans un fichier de données ICU mappable en mémoire. Le fichier de données résultant peut ensuite être utilisé directement par ICU.

gencmn lit une liste de fichiers à regrouper à partir du fichier fichierliste fourni, ou de sa sortie standard. Il regroupe tous les fichiers de la liste qui ne sont pas plus grands que taillemax octets, sauf si taillemax est 0, ce qui indique qu'il n'y a pas de limite de taille pour les fichiers.

OPTIONS

-h, -?, --help
Affiche l'aide sur l'utilisation et quitte.
-v, --verbose
Affiche des messages d'information supplémentaires pendant l'exécution.
-c,--copyright
Inclut l'avis de droit d'auteur d'ICU dans les données résultantes.
-C, --comment commentaire
Inclut le commentaire spécifié dans les données résultantes au lieu de l'avis de droit d'auteur d'ICU.
-d, --destdir destination
Définit le répertoire de destination sur destination. Le répertoire de destination par défaut est spécifié par la variable d'environnement ICU_DATA.
-n, --name nom
Définit le nom des données sur nom au lieu du nom par défaut. Ce nom est également utilisé comme nom de base de la sortie. Le nom par défaut est composé du préfixe icudt, suivi d'un numéro de version à deux chiffres correspondant à la version actuelle de la sortie ICU, et d'une seule lettre indiquant l'endianness des données (la lettre b indique des données big endian, et la lettre l indique des données little endian).
-t, --type type
Utilise type comme type des données. Ce type est également utilisé comme extension du fichier de données généré. Le type par défaut est dat.
-S, --source
Écrit un fichier source C avec la table des matières des données.
-e, --entrypoint nom
Définit le point d'entrée des données (utilisé pour la liaison des données sous forme de bibliothèque partagée) sur nom. Le nom du point d'entrée par défaut est composé des données (définies par l'option -n, --name) suivies d'un trait de soulignement et du type des données (défini par l'option -t, --type).

ENVIRONNEMENT

ICU_DATA
Spécifie le répertoire contenant les données ICU. Par défaut, il s'agit de ${prefix}/share/icu/78.1/. Certains outils d'ICU dépendent de la présence de la barre oblique finale. Il est donc important de s'assurer qu'elle est présente si ICU_DATA est défini.
