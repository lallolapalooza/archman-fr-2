getdpi(1) Commandes utilisateur getdpi(1)

NOM

getdpi - obtenir le DPI moyen

SYNTAXE

getdpi Affiche le DPI moyen de tous les moniteurs connectés.

DESCRIPTION

getdpi peut récupérer des informations sur tous les moniteurs connectés, pour X ou Wayland, et renvoyer le DPI moyen (points par pouce).

OPTIONS

-a, -l ou --all
Affiche les informations DPI pour tous les moniteurs disponibles.
-b ou --both
Affiche les DPI moyens horizontaux et verticaux.
-V ou --version
Affiche la version actuelle.

VERSION

5.14.3
