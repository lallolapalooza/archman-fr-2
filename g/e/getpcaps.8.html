NOM

getpcaps - afficher les capacités d'un processus

SYNTAXE

getpcaps [arguments optionnels] pid...

DESCRIPTION

getpcaps affiche les capacités sur les processus indiqués par la ou les valeurs pid fournies en ligne de commande. Un pid de 0 affiche les capacités du processus qui exécute getpcaps lui-même.

L'ensemble de capacités du processus est affiché dans la représentation textuelle décrite ici : cap_text_formats(7).

Arguments optionnels :

--help ou --usage
Affiche les informations d'utilisation et quitte.
--ugly ou --legacy
Affiche la sortie dans un format hérité un peu laid.
--verbose
Affiche l'utilisation dans un format similaire à l'hérité, mais pas tout à fait aussi laid dans les polices de terminaux modernes par défaut.
--iab
Affiche les capacités des tuples IAB du processus. Le format de sortie est également décrit dans cap_text_formats(7). Des guillemets doubles encadrent les capacités régulières du processus et des crochets encadrent le tuple IAB. Ce format est également utilisé par captree(8).
