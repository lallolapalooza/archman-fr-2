getpwent_r(3) Manuel des fonctions de bibliothèque getpwent_r(3)

NOM

getpwent_r, fgetpwent_r - obtenir une entrée du fichier passwd de manière réentrante

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <pwd.h>
int getpwent_r(size_t size;
               struct passwd *restrict pwbuf,
               char buf[restrict size], size_t size,
               struct passwd **restrict pwbufp);
int fgetpwent_r(size_t size;
               FILE *restrict stream, struct passwd *restrict pwbuf,
               char buf[restrict size], size_t size,
               struct passwd **restrict pwbufp);
Exigences de macro de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

getpwent_r(),

    Depuis glibc 2.19 :
        _DEFAULT_SOURCE
    glibc 2.19 et antérieur :
        _BSD_SOURCE || _SVID_SOURCE

fgetpwent_r():

    Depuis glibc 2.19 :
        _DEFAULT_SOURCE
    glibc 2.19 et antérieur :
        _SVID_SOURCE

DESCRIPTION

Les fonctions getpwent_r() et fgetpwent_r() sont les versions réentrantes de getpwent(3) et fgetpwent(3). La première lit la prochaine entrée passwd du flux initialisé par setpwent(3). La seconde lit la prochaine entrée passwd de stream.

La structure passwd est définie dans <pwd.h> comme suit :


struct passwd {
    char    *pw_name;      /* nom d'utilisateur */
    char    *pw_passwd;    /* mot de passe utilisateur */
    uid_t    pw_uid;       /* ID utilisateur */
    gid_t    pw_gid;       /* ID groupe */
    char    *pw_gecos;     /* informations utilisateur */
    char    *pw_dir;       /* répertoire personnel */
    char    *pw_shell;     /* programme de shell */
};

Pour plus d'informations sur les champs de cette structure, voir passwd(5).

Les fonctions non réentrantes renvoient un pointeur vers une zone statique, où cette zone statique contient d'autres pointeurs vers le nom d'utilisateur, le mot de passe, le champ gecos, le répertoire personnel et le shell. Les fonctions réentrantes décrites ici renvoient tout cela dans des tampons fournis par l'appelant. Tout d'abord, il y a le tampon pwbuf qui peut contenir une struct passwd. Ensuite, le tampon buf de taille size qui peut contenir des chaînes supplémentaires. Le résultat de ces fonctions, la struct passwd lue à partir du flux, est stocké dans le tampon fourni *pwbuf, et un pointeur vers cette struct passwd est renvoyé dans *pwbufp.

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient 0 et *pwbufp est un pointeur vers la struct passwd. En cas d'erreur, ces fonctions renvoient une valeur d'erreur et *pwbufp est NULL.

ERREURS

ENOENT
Plus d'entrées.
ERANGE
Espace tampon insuffisant fourni. Essayez à nouveau avec un tampon plus grand.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
getpwent_r () Sécurité des threads MT-Unsafe race:pwent locale
fgetpwent_r () Sécurité des threads MT-Safe

Dans le tableau ci-dessus, pwent dans race:pwent signifie que si l'une des fonctions setpwent(), getpwent(), endpwent(), ou getpwent_r() est utilisée en parallèle dans différents threads d'un programme, des courses de données pourraient survenir.

VERSIONS

D'autres systèmes utilisent le prototype


struct passwd *
getpwent_r(struct passwd *pwd, char buf[.size], int size);

ou, mieux,


int
getpwent_r(struct passwd *pwd, char buf[.size], int size,
           FILE **pw_fp);

NORMES

Aucune.

HISTORIQUE

Ces fonctions sont réalisées dans un style rappelant la version POSIX des fonctions telles que getpwnam_r(3).

NOTES

La fonction getpwent_r() n'est pas réellement réentrante car elle partage la position de lecture dans le flux avec tous les autres threads.

EXEMPLES

#define _GNU_SOURCE
#include <pwd.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#define BUFLEN 4096
int
main(void)
{
    struct passwd pw;
    struct passwd *pwp;
    char buf[BUFLEN];
    int i;
    setpwent();
    while (1) {
        i = getpwent_r(&pw, buf, sizeof(buf), &pwp);
        if (i)
            break;
        printf("%s (%jd)\tHOME %s\tSHELL %s\n", pwp->pw_name,
               (intmax_t) pwp->pw_uid, pwp->pw_dir, pwp->pw_shell);
    }
    endpwent();
    exit(EXIT_SUCCESS);
}
