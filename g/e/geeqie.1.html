Tous les autres paramètres de ligne de commande sont utilisés comme fichiers simples s'ils existent, ou comme URL ou dossier. Le nom d'une collection, avec ou sans chemin ou extension (.gqv) peut être
utilisé.
Si plus d'un dossier est sur la ligne de commande, seul le dernier sera
utilisé.
Si plus d'un fichier est sur la ligne de commande
:
S'ils sont dans le même dossier, ce dossier sera ouvert et ces fichiers seront sélectés. S'ils ne sont pas dans le même dossier, une nouvelle Collection contenant ces fichiers sera
ouverte.
Pour exécuter Geeqie comme une nouvelle instance, utilisez : GQ_NEW_INSTANCE=y[es] geeqie Normalement, un seul ensemble de fichiers de configuration est utilisé pour toutes les instances. Cependant, les variables d'environnement XDG_CONFIG_HOME, XDG_CACHE_HOME, XDG_DATA_HOME peuvent être utilisées pour modifier ce comportement au cas par cas, par exemple : XDG_CONFIG_HOME=/tmp/a XDG_CACHE_HOME=/tmp/b GQ_NEW_INSTANCE=y
geeqie
Pour désactiver Clutter, utilisez : GQ_DISABLE_CLUTTER=y[es]
geeqie
Pour exécuter ou arrêter Geeqie en mode maintenance du cache (sans interface graphique), utilisez : GQ_CACHE_MAINTENANCE=y[es] geeqie --he
