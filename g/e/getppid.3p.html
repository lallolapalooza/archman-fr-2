GETPPID(3P) Manuel du programmeur POSIX GETPPID(3P)

PREAMBULE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

getppid — obtenir l'ID du processus parent

SYNTAXE

#include <unistd.h>
pid_t getppid(void);

DESCRIPTION

La fonction getppid() renvoie l'identifiant du processus parent du processus appelant.

VALEUR DE RETOUR

La fonction getppid() réussit toujours et aucune valeur de retour n'est réservée pour indiquer une erreur.

ERREURS

Aucune erreur n'est définie.
