NOM

gendict - Compile une liste de mots en dictionnaire tri d'ICU

SYNTAXE

gendict [ --uchars | --bytes --transform transformation ] [ -h, -?, --help ] [ -V, --version ] [ -c, --copyright ] [ -v, --verbose ] [ -i, --icudatadir répertoire ] fichier-entrée fichier-sortie

DESCRIPTION

gendict lit la liste de mots du fichier-dictionnaire et crée un fichier dictionnaire tri. Normalement, ce fichier de données a l'extension .dict.

Les mots commencent au début d'une ligne et sont terminés par le premier espace blanc. Les lignes qui commencent par un espace blanc sont ignorées.

OPTIONS

-h, -?, --help
Affiche l'aide sur l'utilisation et quitte.
-V, --version
Affiche la version de gendict et quitte.
-c, --copyright
Intègre le copyright standard d'ICU dans le fichier-sortie.
-v, --verbose
Affiche des messages informatifs supplémentaires pendant l'exécution.
-i, --icudatadir répertoire
Recherche les fichiers de données ICU nécessaires dans répertoire. Par exemple, le fichier pnames.icu doit être trouvé si les données ICU ne sont pas compilées en bibliothèque partagée. Le répertoire de données ICU par défaut est spécifié par la variable d'environnement ICU_DATA. La plupart des configurations d'ICU ne nécessitent pas cet argument.
--uchars
Définit le type de tri de sortie sur UChar. Exclusivement avec --bytes.
--bytes
Définit le type de tri de sortie sur Bytes. Exclusivement avec --uchars.
--transform
Définit le type de transformation. Ne doit être spécifié qu'avec --bytes. Les transformations actuellement prises en charge sont : offset-<nombre-hexadécimal>, qui spécifie un décalage à soustraire de tous les caractères d'entrée. Il convient de noter que la transformation par décalage mappe également U+200D en 0xFF et U+200C en 0xFE, afin d'offrir une compatibilité avec les langues qui nécessitent ces caractères. Une transformation doit être spécifiée pour un tri par octets, et lorsqu'elle est appliquée aux caractères non-valeurs dans le fichier-entrée, elle doit produire une sortie comprise entre 0x00 et 0xFF.
fichier-entrée
Le fichier source à lire.
fichier-sortie
Le fichier où écrire le dictionnaire de sortie.

MISE EN GARDE

Le fichier-entrée est supposé être encodé en UTF-8. Les entiers dans le fichier-entrée utilisés comme valeurs doivent être constitués de chiffres ASCII. Ils peuvent être spécifiés soit en hexadécimal, en utilisant un préfixe 0x, soit en décimal. Soit --bytes, soit --uchars doit être spécifié.

ENVIRONNEMENT

ICU_DATA
Spécifie le répertoire contenant les données ICU. Par défaut, il s'agit de ${prefix}/share/icu/78.1/. Certains outils d'ICU dépendent de la présence de la barre oblique finale. Il est donc important de s'assurer qu'elle est présente si ICU_DATA est défini.
