NOM

gensio_acc_control - Effectuer des actions spécifiques à l'accepteur gensio

SYNTAXE

#include <gensio/gensio.h>

int gensio_acc_control(struct gensio_accepter *acc, int depth,

bool get, unsigned int option,
char *data, gensiods *datalen);

DESCRIPTION

gensio_acc_control effectue une opération spécifique à l'accepteur gensio sur l'accepteur gensio. Ceci fonctionne exactement comme gensio_control(3), consultez celui-ci pour plus de détails sur get, depth, et sur le fonctionnement de data et datalen.

Les opérations de contrôle gensio dans option dépendent du gensio particulier. Ci-dessous, certaines sont documentées, mais d'autres contrôles peuvent être disponibles. Voir la documentation gensio dans gensio(5) pour plus de détails.

GENSIO_ACC_CONTROL_LADDR

Retourne l'adresse locale donnée pour le gensio donné. Puisqu'un seul gensio peut avoir plus d'une adresse locale, ce contrôle fournit un moyen de savoir laquelle. La chaîne data passée en argument devrait être la représentation textuelle du nombre (comme créé avec snprintf()) pour l'index particulier que vous souhaitez récupérer. Si vous spécifiez un nombre supérieur au nombre de sockets d'écoute ouverts, GE_NOTFOUND est retourné. La donnée de retour est une chaîne contenant l'adresse.

Notez qu'une seule chaîne récupérée peut contenir plus d'une adresse. Celles-ci seront séparées par des points-virgules. Dans certains cas, les adresses peuvent changer dynamiquement (comme avec SCTP), vous obtenez donc un seul ensemble d'adresses.

GENSIO_ACC_CONTROL_LPORT

Retourne le port pour l'adresse locale donnée pour le gensio donné. Puisqu'un seul gensio peut avoir plus d'une adresse locale, ce contrôle fournit un moyen de savoir laquelle. La chaîne data passée en argument devrait être la représentation textuelle du nombre (comme créé avec snprintf()) pour l'index particulier que vous souhaitez récupérer. Si vous spécifiez un nombre supérieur au nombre de sockets d'écoute ouverts, GE_NOTFOUND est retourné. La donnée de retour est une chaîne contenant le numéro de port.

GENSIO_ACC_CONTROL_TCPDNAME

Obtenir ou définir le nom TCPD pour le gensio, uniquement pour les gensios TCP.

VALEURS DE RETOUR

Zéro est retourné en cas de succès, ou une erreur gensio en cas d'échec.

VOIR AUSSI

gensio_err(3), gensio(5), gensio_control(3)
