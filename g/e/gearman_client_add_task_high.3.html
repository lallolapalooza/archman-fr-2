gearman_client_add_task_high(3)

GEARMAN_CLIENT_ADD_TASK_HIGH(3) Gearmand GEARMAN_CLIENT_ADD_TASK_HIGH(3)

NOM

gearman_client_add_task_high - Documentation Gearmand, https://gearman.org/gearmand/

SYNTAXE

#include <libgearman/gearman.h>

gearman_task_st *gearman_client_add_task(gearman_client_st *client, gearman_task_st *task, void *context, const char *function_name, const char *unique, const void *workload, size_t workload_size, gearman_return_t *ret_ptr)
gearman_task_st *gearman_client_add_task_high(gearman_client_st *client, gearman_task_st *task, void *context, const char *function_name, const char *unique, const void *workload, size_t workload_size, gearman_return_t *ret_ptr)
gearman_task_st *gearman_client_add_task_low(gearman_client_st *client, gearman_task_st *task, void *context, const char *function_name, const char *unique, const void *workload, size_t workload_size, gearman_return_t *ret_ptr)

Lier avec -lgearman

DESCRIPTION

gearman_client_add_task() crée une tâche et l'ajoute au gearman_client_st donné. L'exécution de la tâche ne commence pas tant que gearman_client_run_tasks() n'est pas appelée.

Si la valeur unique n'est pas définie, une valeur unique sera attribuée.

gearman_client_add_task_high() et gearman_client_add_task_low() sont identiques à gearman_client_do(), mais elles définissent la priorité à haute ou basse.

VALEUR DE RETOUR

La structure gearman_task_st est créée et un pointeur vers celle-ci est retourné. En cas d'erreur, NULL est retourné et ret_ptr est défini avec une valeur de type gearman_return_t.
