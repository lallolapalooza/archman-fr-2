NOM

gendesc - Générer un fichier de description de cas de test

SYNTAXE

gendesc [-h|--help] [-v|--version]


[-o|--output-filename nom_de_fichier]
fichier_entree

DESCRIPTION

Convertit les descriptions de cas de test en texte brut dans un format compréhensible par genhtml. Le fichier fichier_entree doit respecter le format suivant :

Pour chaque cas de test :

-
une ligne contenant le nom du cas de test, commençant au début de la ligne

-
une ou plusieurs lignes contenant la description du cas de test, indentées avec au moins un espace blanc (tabulation ou espace)

Exemple de fichier d'entrée :

test01

Une description d'exemple de cas de test.
Description continue

test42

Supposément la réponse à la plupart de vos questions

Remarque : les noms de test valides peuvent contenir des lettres, des chiffres décimaux et le caractère underscore ('_').

OPTIONS

-h
--help

Affiche un court message d'aide, puis quitte.

-v
--version

Affiche le numéro de version, puis quitte.

-o nom_de_fichier
--output-filename nom_de_fichier

Écrit les données de description dans nom_de_fichier.

Par défaut, la sortie est écrite sur STDOUT.
