GEARMAN_WORKER_OPTIONS(3) Gearmand GEARMAN_WORKER_OPTIONS(3)

NOM

gearman_worker_options - Documentation Gearmand, https://gearman.org/gearmand/

SYNOPSIS

#include <libgearman/gearman.h>

type gearman_worker_options_t
gearman_worker_options_t gearman_worker_options(const gearman_worker_st *worker)
void gearman_worker_add_options(gearman_worker_st *worker, gearman_worker_options_t options)
void gearman_worker_remove_options(gearman_worker_st *worker, gearman_worker_options_t options)
void gearman_worker_set_options(gearman_worker_st *worker, gearman_worker_options_t options)

Déprécié depuis la version 0.21.

DESCRIPTION

gearman_worker_options() renvoie le gearman_worker_options_t pour gearman_worker_st. Vous activez les options via gearman_worker_add_options() et désactivez les options via gearman_worker_remove_options().

Les options actuellement supportées sont :

Active l'E/S non bloquante pour le worker.

type GEARMAN_WORKER_GRAB_UNIQ

Ne prend que les jobs qui ont été assignés des valeurs uniques. Ceci est utile pour les workers qui veulent seulement travailler avec des jobs en arrière-plan.

type GEARMAN_WORKER_TIMEOUT_RETURN

Indique si un délai d'attente de retour a été défini pour le worker.

VALEUR DE RETOUR

Divers
