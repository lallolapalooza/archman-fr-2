gethostid(3) Manuel des fonctions de bibliothèque gethostid(3)

NOM

gethostid, sethostid — obtenir ou définir l'identifiant unique de l'hôte courant

BIBLIOTHQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <unistd.h>
long gethostid(void);
int sethostid(long hostid);
Exigences de macro de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

gethostid():

    Depuis glibc 2.20 :
        _DEFAULT_SOURCE || _XOPEN_SOURCE >= 500
    Jusqu'à et y compris glibc 2.19 :
        _BSD_SOURCE || _XOPEN_SOURCE >= 500

sethostid():

    Depuis glibc 2.21 :
        _DEFAULT_SOURCE
    Dans glibc 2.19 et 2.20 :
        _DEFAULT_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)
    Jusqu'à et y compris glibc 2.19 :
        _BSD_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)

DESCRIPTION

gethostid() et sethostid() obtiennent ou définissent respectivement un identifiant unique de 32 bits pour la machine courante. L'identifiant de 32 bits était destiné à être unique parmi tous les systèmes UNIX existants. Ceci ressemble normalement à l'adresse Internet de la machine locale, telle que retournée par gethostbyname(3), et par conséquent n'a généralement jamais besoin d'être défini.

L'appel sethostid() est réservé au superutilisateur.

VALEUR DE RETOUR

gethostid() renvoie l'identifiant de 32 bits de l'hôte courant tel que défini par sethostid().

En cas de succès, sethostid() renvoie 0 ; en cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

sethostid() peut échouer avec les erreurs suivantes :

EACCES
L'appelant n'avait pas la permission d'écrire dans le fichier utilisé pour stocker l'ID hôte.
EPERM
L'ID utilisateur effectif ou l'ID groupe du processus appelant n'est pas le même que son ID réel correspondant.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
gethostid () Sécurité des threads MT-Safe hostid env locale
sethostid () Sécurité des threads MT-Unsafe const:hostid

VERSIONS

Dans l'implémentation glibc, l'hostid est stocké dans le fichier /etc/hostid. (Avant glibc 2.2, le fichier /var/adm/hostid était utilisé.)

Dans l'implémentation glibc, si gethostid() ne parvient pas à ouvrir le fichier contenant l'ID hôte, il obtient alors le nom d'hôte en utilisant gethostname(2), transmet ce nom d'hôte à gethostbyname_r(3) afin d'obtenir l'adresse IPv4 de l'hôte, et renvoie une valeur obtenue par manipulation de bits de l'adresse IPv4. (Cette valeur peut ne pas être unique.)

NORMES

gethostid()
POSIX.1-2008.
sethostid()
Aucune.

HISTORIQUE

4.2BSD ; supprimé dans 4.4BSD. SVr4 et POSIX.1-2001 incluent gethostid() mais pas sethostid().

BOGUES

Il est impossible de garantir que l'identifiant est globalement unique.

VOIR AUSSI

hostid(1), gethostbyname(3)
