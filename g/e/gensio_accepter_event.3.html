NOM

gensio_accepter_event - Gestionnaire d'événements pour les événements provenant d'un gensio

SYNTAXE

#include <gensio/gensio.h>

typedef int (*gensio_accepter_event)(struct gensio_accepter *acc,

void *user_data,
int event, void *data);

DESCRIPTION

Lorsqu'un événement se produit sur un accepteur gensio qui est rapporté à l'utilisateur, la bibliothèque gensio appelle le gestionnaire de type gensio_accepter_event qui a été enregistré auprès de l'accepteur gensio.

L'utilisation des différents paramètres dépend de l'événement particulier. Les paramètres qui ne varient pas sont :

acc
- L'accepteur gensio pour lequel l'événement est rapporté.
user_data
- Les données utilisateur fournies lors de l'enregistrement du gestionnaire d'événements.
event
- L'événement particulier rapporté.
data
- Données spécifiques à l'événement (peuvent ne pas être utilisées).

Événements ci-dessous.

GENSIO_ACC_EVENT_NEW_CONNECTION

Nouvelle connexion reçue sur l'accepteur. data pointe vers le nouveau gensio.

GENSIO_ACC_EVENT_LOG

struct gensio_loginfo {
enum gensio_log_levels level;
char *str;
va_list args;
};

L'accepteur gensio a eu un problème qui ne serait pas autrement rapporté comme une erreur. data pointe vers une struct gensio_loginfo.

GENSIO_ACC_EVENT_PRECERT_VERIFY

Appelé juste avant la vérification du certificat sur une nouvelle connexion entrante. Voir GENSIO_EVENT_PRECERT_VERIFY dans gensio_event(3) pour plus de détails. data pointe vers le nouvel objet gensio. Notez que ce gensio n'a pas encore été rapporté dans une nouvelle connexion.

GENSIO_ACC_EVENT_AUTH_BEGIN

Appelé au début d'un processus d'autorisation pour une nouvelle connexion. Voir GENSIO_EVENT_AUTH_BEGIN dans gensio_event(3) pour plus de détails. data pointe vers le nouvel objet gensio. Notez que ce gensio n'a pas encore été rapporté dans une nouvelle connexion.

GENSIO_ACC_EVENT_PASSWORD_VERIFY

struct gensio_acc_password_verify_data {
struct gensio *io;
char *password;
gensiods password_len;
};

Un gensio serveur a reçu un mot de passe qui nécessite une vérification. Les gestionnaires de gensio ne vérifient pas réellement les mots de passe, ils les transfèrent et les fournissent à l'utilisateur pour vérification. data pointe vers une struct gensio_acc_password_verify_data qui contient le nouveau gensio et les informations du mot de passe. Voir GENSIO_EVENT_PASSWORD_VERIFY dans gensio_event(3) pour plus de détails.

GENSIO_ACC_EVENT_REQUEST_PASSWORD

Un gensio serveur distant a demandé qu'un mot de passe soit envoyé pour vérification. data pointe vers une struct gensio_acc_password_verify_data qui contient le nouveau gensio et les informations du mot de passe. Voir GENSIO_EVENT_REQUEST_PASSWORD dans gensio_event(3) pour plus de détails.

GENSIO_ACC_EVENT_POSTCERT_VERIFY

struct gensio_acc_postcert_verify_data {
struct gensio *io;
int err;
const char *errstr;
};

Un gensio serveur a terminé la vérification du certificat (et n'a effectué aucune vérification de mot de passe). data pointe vers une struct gensio_acc_postcert_verify_data qui contient le nouveau gensio et les informations d'erreur. Voir GENSIO_EVENT_POSTCERT_VERIFY dans gensio_event(3) pour plus de détails.

AUTRES ÉVÉNEMENTS

D'autres accepteurs gensio qui ne font pas partie de la bibliothèque gensio elle-même peuvent avoir leurs propres événements.

VALEURS DE RETOUR

Voir les événements individuels pour les valeurs que vous devez retourner. Si un événement n'est pas géré par le gestionnaire d'événements, le gestionnaire doit retourner GE_NOTSUP, sauf dans le cas de GENSIO_ACC_EVENT_NEW_CONNECTION qui doit être géré.
