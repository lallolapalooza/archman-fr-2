getprotoent(3) Manuel des fonctions de bibliothèque getprotoent(3)

NOM

getprotoent, getprotobyname, getprotobynumber, setprotoent, endprotoent - obtenir une entrée de protocole

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <netdb.h>
struct protoent *getprotoent(void);
struct protoent *getprotobyname(const char *name);
struct protoent *getprotobynumber(int proto);
void setprotoent(int stayopen);
void endprotoent(void);

DESCRIPTION

La fonction getprotoent() lit l'entrée suivante de la base de données des protocoles (voir protocols(5)) et retourne une structure protoent contenant les champs décomposés de l'entrée. Une connexion à la base de données est ouverte si nécessaire.

La fonction getprotobyname() retourne une structure protoent pour l'entrée de la base de données qui correspond au nom de protocole name. Une connexion à la base de données est ouverte si nécessaire.

La fonction getprotobynumber() retourne une structure protoent pour l'entrée de la base de données qui correspond au numéro de protocole number. Une connexion à la base de données est ouverte si nécessaire.

La fonction setprotoent() ouvre une connexion à la base de données et définit l'entrée suivante à la première entrée. Si stayopen est différent de zéro, la connexion à la base de données ne sera pas fermée entre les appels à l'une des fonctions getproto*().

La fonction endprotoent() ferme la connexion à la base de données.

La structure protoent est définie dans <netdb.h> comme suit :


struct protoent {
    char  *p_name;       /* nom officiel du protocole */
    char **p_aliases;    /* liste des alias */
    int    p_proto;      /* numéro du protocole */
}

Les membres de la structure protoent sont :

p_name
Le nom officiel du protocole.
p_aliases
Une liste terminée par NULL de noms alternatifs pour le protocole.
p_proto
Le numéro du protocole.

VALEUR DE RETOUR

Les fonctions getprotoent(), getprotobyname() et getprotobynumber() retournent un pointeur vers une structure protoent allouée statiquement, ou un pointeur NULL si une erreur se produit ou si la fin du fichier est atteinte.

FICHIERS

/etc/protocols
fichier de base de données des protocoles

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
getprotoent () Sécurité des threads MT-Unsafe race:protoent race:protoentbuf locale
getprotobyname () Sécurité des threads MT-Unsafe race:protobyname locale
getprotobynumber () Sécurité des threads MT-Unsafe race:protobynumber locale
setprotoent (), endprotoent () Sécurité des threads MT-Unsafe race:protoent locale

Dans le tableau ci-dessus, protoent dans race:protoent signifie que si l'une des fonctions setprotoent(), getprotoent() ou endprotoent() est utilisée en parallèle dans différents threads d'un programme, des courses de données peuvent se produire.

NORMES

POSIX.1-2008.

HISTORIQUE

POSIX.1-2001, 4.3BSD.

VOIR AUSSI

getnetent(3), getprotoent_r(3), getservent(3), protocols(5)
