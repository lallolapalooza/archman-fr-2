DESCRIPTIO

N

La fonction getpwent() renvoie un pointeur vers une structure contenant les champs décomposés d'un enregistrement de la base de données de mots de passe (par ex. le fichier de mots de passe local /etc/passwd, NIS et LDAP). La première fois que getpwent() est appelée, elle renvoie la première entrée ; ensuite, elle renvoie les entrées

successives.

La fonction setpwent() revient au début de la base de données de mots de

passe.

La fonction endpwent() est utilisée pour fermer la base de données de mots de passe après que tout le traitement a été

effectué.

La structure passwd est définie dans <pwd.h> comme suit

: 


struct passwd {
    char   *pw_name;       /* username */
    char   *pw_passwd;     /* user password */
    uid_t   pw_uid;        /* user ID */
    gid_t   pw_gid;        /* group ID */
    char   *pw_gecos;      /* user information */
    char   *pw_dir;        /* home directory */
    char   *pw_shell;      /* shell program */
}
;

Pour plus d'informations sur les champs de cette structure, voir passw

d(5
).

VALEUR

RENVOYÉE

La fonction getpwent() renvoie un pointeur vers une structure passwd, ou NULL s'il n'y a plus d'entrées ou si une erreur s'est produite. Si une erreur se produit, errno est défini pour indiquer l'erreur. Si on souhaite vérifier errno après l'appel, il doit être défini à zéro avant

l'appel.

La valeur renvoyée peut pointer vers une zone statique, et peut être écrasée par des appels ultérieurs à getpwent(), getpwnam(3) ou getpwuid(3). (Ne pas passer le pointeur renvoyé à free

(3)
.)
