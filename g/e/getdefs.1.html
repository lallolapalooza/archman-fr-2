getdefs(1) Commandes utilisateur getdefs(1)

NOM

getdefs - Outil d'extraction de définitions AutoGen

SYNTAXE

getdefs [nom-option valeur]

Tous les arguments sont des options nommées.

Si aucun argument input n'est fourni ou s'il est défini simplement sur "-", et si l'entrée standard (stdin) n'est pas un tty, alors la liste des fichiers d'entrée sera lue depuis stdin.

DESCRIPTION

Ce programme extrait les définitions AutoGen à partir d'une liste de fichiers sources. Les définitions sont délimitées par /*=<type-entrée> <nom-entrée>0fP et =*/0fP.

OPTIONS

Spécifier quelles définitions sont intéressantes et ce qu'il faut en dire

defs-à-obtenir=ex-rég

Expression régulière à rechercher après "/*=".

Si vous ne souhaitez que des définitions d'une catégorie particulière, ou même avec des noms correspondant à des motifs particuliers, spécifiez cette expression régulière pour le texte qui doit suivre le /*=.

sous-bloc=déf-sous

Noms de définitions de sous-blocs. Cette option peut apparaître un nombre illimité de fois.

Cette option est utilisée pour créer des entrées raccourcies pour les définitions imbriquées. Par exemple, avec :

en utilisant sous-bloc ainsi --sous-bloc=arg=nomarg,type,null

et en définissant un arg ainsi arg: ceci, char *

cela se développera alors en : arg = { nomarg = ceci; type = "char *"; @;}
La chaîne "ceci, char *" est séparée par des virgules, avec les espaces blancs supprimés. Vous pouvez utiliser des caractères autres que les virgules en commençant la chaîne de valeur par un caractère de ponctuation autre qu'une apostrophe ou un guillemet. Vous pouvez également omettre des valeurs intermédiaires en plaçant les virgules les unes à côté des autres sans espace blanc intermédiaire. Par exemple, "+bidule++oui+" se développera en :
arg = { nomarg = bidule; null = "oui"; @;}.

attribut-liste=déf

Attribut avec liste de valeurs. Cette option peut apparaître un nombre illimité de fois.

Cette option est utilisée pour créer des entrées raccourcies pour des définitions qui apparaissent généralement plusieurs fois. C'est-à-dire qu'elles ont tendance à être une liste de valeurs. Par exemple, avec :
attribut-liste=foo défini, le texte :
foo: ceci, est, une, multi-liste se développera alors en :
foo = 'ceci', 'est', 'une', 'multi-liste';
Les textes sont séparés par les virgules, avec les espaces blancs supprimés. Vous pouvez utiliser des caractères autres que les virgules en commençant la chaîne de valeur par un caractère de ponctuation autre qu'une apostrophe ou un guillemet.

spécifier comment numéroter les définitions

ordonnancement [=nom-fichier], --no-ordonnancement

Alphabetiser ou utiliser un fichier nommé. La forme no-ordonnancement désactivera l'option. Cette option est activée par défaut.

Par défaut, l'ordre est alphabétique par le nom d'entrée. Utilisez no-ordonnancement si l'ordre n'est pas important. Utilisez ordonnancement sans argument pour ordonner sans tenir compte de la casse. Utilisez ordonnancement=<nom-fichier> si l'ordre chronologique est important. getdefs maintiendra le contenu texte de nom-fichier. nom-fichier n'a pas besoin d'exister.

premier-index=premier-index

Le premier index à appliquer aux groupes. Cette option prend un nombre entier comme argument. Le premier-index par défaut pour cette option est :
0

Par défaut, la première occurrence d'une définition nommée aura un index de zéro. Parfois, cela doit être une valeur réservée. Fournissez cette option pour spécifier un point de départ différent.

Options d'insertion de définition

liste-fichiers [=fichier]

Insérer les noms de fichiers sources dans les defs.

Insère le nom de chaque fichier d'entrée dans les définitions de sortie. Si aucun argument n'est fourni, le format sera :

    fichier_entree = '%s';
Si un argument est fourni, cette chaîne sera utilisée pour le nom d'entrée à la place de fichier_entree.
assignation=déf-ag

Assignations globales. Cette option peut apparaître un nombre illimité de fois.

L'argument de chaque copie de cette option sera inséré dans les définitions de sortie, avec seulement un point-virgule attaché.

assignation-commune=déf-ag

Assignations communes à tous les blocs. Cette option peut apparaître un nombre illimité de fois.

L'argument de chaque copie de cette option sera inséré dans chaque définition de sortie, avec seulement un point-virgule attaché.

copie=fichier

Fichier(s) à copier dans les définitions. Cette option peut apparaître un nombre illimité de fois.

Le contenu de chaque fichier nommé par ces options sera inséré dans les définitions de sortie.

fichier-source [=fichier]

Insérer le nom du fichier source dans chaque def.

Insère le nom du fichier d'entrée où une définition a été trouvée dans la définition de sortie. Si aucun argument n'est fourni, le format sera :

    fichier_source = '%s';
Si un argument est fourni, cette chaîne sera utilisée pour le nom d'entrée à la place de fichier_source.
numero-ligne [=nom-déf]

Insérer le numéro de ligne source dans chaque def.

Insère le numéro de ligne dans le fichier d'entrée où une définition a été trouvée dans la définition de sortie. Si aucun argument n'est fourni, le format sera :

    numero_ligne = '%s';
Si un argument est fourni, cette chaîne sera utilisée pour le nom d'entrée à la place de numero-ligne.

spécifier quels fichiers rechercher les marqueurs

entree=fichier-source

Fichier d'entrée à rechercher pour les defs. Cette option peut apparaître un nombre illimité de fois. C'est l'option par défaut.

Tous les fichiers qui doivent être recherchés pour les définitions doivent être nommés sur la ligne de commande ou lus depuis stdin. S'il n'y a qu'une seule option entree et qu'elle est la chaîne "-", alors la liste des fichiers d'entrée est lue depuis stdin. Si un argument de ligne de commande n'est pas un nom d'option et ne contient pas d'opérateur d'assignation (=), alors il est défini par défaut comme un nom de fichier d'entrée. Au moins un fichier d'entrée doit être spécifié.

Options de disposition de sortie des définitions :

sortie=fichier

Fichier de sortie à ouvrir. Cette option est membre de la classe d'options autogen.

Si vous n'envoyez pas la sortie à un processus AutoGen, vous pouvez nommer un fichier de sortie à la place.

autogen [=cmd-ag], --no-autogen

Invoquer AutoGen avec les defs. La forme no-autogen désactivera l'option. Cette option est activée par défaut. C'est membre de la classe d'options autogen.

C'est le mode de sortie par défaut. Spécifier no-autogen équivaut à sortie=-. Si vous fournissez un argument à cette option

, ce programme sera lancé comme s'il s'agissait d'AutoGen et son entrée standard sera définie sur les définitions de sortie de ce programme.

template=fichier

Nom du modèle.

Spécifie le nom du modèle à utiliser pour générer la sortie finale.

agarg=ag-opt

Argument AutoGen. Cette option peut apparaître un nombre illimité de fois. Cette option ne doit pas apparaître en combinaison avec aucune des options suivantes : output.

Il s'agit d'un argument de passage. Il vous permet de spécifier tout argument arbitraire à passer à AutoGen.

base-name=nom

Nom de base pour les fichiers de sortie. Cette option ne doit pas apparaître en combinaison avec aucune des options suivantes : output.

Lorsque la sortie est destinée à AutoGen, un nom de base doit soit être fourni, soit être dérivé. Si cette option n'est pas fournie, elle est extraite de l'option template. Si celle-ci n'est pas non plus fournie, elle est définie sur le nom de base du répertoire courant.

help

Affiche les informations d'utilisation et quitte.
more-help

Passe les informations d'utilisation étendues à un paginator.
save-opts [=fichier-cfg]

Enregistre l'état des options dans fichier-cfg. Le défaut est le dernier fichier de configuration listé dans la section OPTION PRESETS, ci-dessous. La commande se terminera après la mise à jour du fichier de configuration.
load-opts=fichier-cfg, no-load-opts

Charge les options depuis fichier-cfg. La forme no-load-opts désactivera le chargement des fichiers de configuration/rc/ini précédents. --no-load-opts est traité tôt, hors séquence.
version [{v|c|n}]

Affiche la version du programme et quitte. Le mode par défaut est `v', une version simple. Le mode `c' affichera les informations de copyright et `n' affichera l'avis de copyright complet.

OPTION PRESETS

Toute option non marquée comme non présélectionnable peut être présélectionnée en chargeant des valeurs à partir de fichiers de configuration ("RC" ou ".INI"). Le fichier homerc est "/dev/null", sauf si c'est un répertoire. Dans ce cas, le fichier ".getdefsrc" est recherché dans ce répertoire.

FILES

Voir OPTION PRESETS pour les fichiers de configuration.

EXIT STATUS

L'une des valeurs de sortie suivantes sera retournée :

0 (EXIT_SUCCESS)

Exécution réussie du programme.
1 (EXIT_FAILURE)

L'opération a échoué ou la syntaxe de la commande n'était pas valide.
2 (EXIT_INVALID_INPUT)

Un fichier spécifié n'est pas un fichier
3 (EXIT_NO_MEM)

Mémoire insuffisante pour l'opération
66 (EX_NOINPUT)

Un fichier de configuration spécifié n'a pas pu être chargé.
70 (EX_SOFTWARE)
