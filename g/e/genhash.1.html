NOM

genhash - outil de génération de hash md5 pour les pages web distantes

SYNTAXE

keepalived --genhash [options] [-s adresse-serveur] [-p port] [-u url]

DESCRIPTION

genhash est un outil utilisé pour générer les sommes md5sum de pages web distantes. genhash peut utiliser HTTP ou HTTPS pour se connecter à la page web. La sortie de cet utilitaire inclut l'en-tête HTTP, les données de la page et la md5sum des données. Cette md5sum peut ensuite être utilisée dans le programme keepalived(8), pour surveiller les services HTTP et HTTPS.

OPTIONS

--use-ssl, -S
Utilise SSL pour se connecter au serveur.
--server <hôte>, -s
Spécifie l'adresse IP à laquelle se connecter.
--port <port>, -p
Spécifie le port à utiliser pour la connexion.
--url <url>, -u
Spécifie le chemin du fichier pour lequel générer le hash.
--use-virtualhost <hôte>, -V
Spécifie l'hôte virtuel à envoyer avec les en-têtes HTTP.
--protocol <version_protocole>, -P
Spécifie la version du protocole HTTP à utiliser. version_protocole peut être 1.0, 1.1 ou 1.0c. 1.0c signifie version du protocole 1.0 mais avec une ligne "Connection: close" ; ceci est inclus par défaut dans la version 1.1.
--timeout <délai>, -t
Spécifie le délai de connexion en secondes.
--fwmark <marque>, -m
Définit la marque de pare-feu spécifiée sur la socket.
--verbose, -v
Soit verbeux dans la sortie.
--help, -h
Affiche l'écran d'aide du programme et quitte.
