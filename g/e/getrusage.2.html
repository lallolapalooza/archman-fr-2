DESCRIPTIO

N

getrusage() renvoie des mesures d'utilisation des ressources pour who, qui peut être l'une des valeurs suivantes

:
RUSAGE_SE
LF
Renvoie les statistiques d'utilisation des ressources pour le processus appelant, qui correspond à la somme des ressources utilisées par tous les threads du
processus.
RUSAGE_CHILD
REN
Renvoie les statistiques d'utilisation des ressources pour tous les enfants du processus appelant qui se sont terminés et ont été attendus. Ces statistiques incluront les ressources utilisées par les petits-enfants, et les descendants plus éloignés, si tous les descendants intermédiaires ont attendu leurs enfants
terminés.
RUSAGE_THREAD (depuis Linux 2.6.
26)
Renvoie les statistiques d'utilisation des ressources pour le thread appelant. La macro de test de fonctionnalité _GNU_SOURCE doit être définie (avant d'inclure n'importe quel fichier d'en-tête) afin d'obtenir la définition de cette constante depuis <sys/res
ource
.h>.

Les utilisations des ressources sont renvoyées dans la structure pointée par usage, qui a la forme suivante

: 


struct rusage {
    struct timeval ru_utime; /* temps CPU utilisateur utilisé */
    struct timeval ru_stime; /* temps CPU système utilisé */
    long   ru_maxrss;        /* taille maximale du jeu résident */
    long   ru_ixrss;         /* taille intégrale de la mémoire partagée */
    long   ru_idrss;         /* taille intégrale des données non partagées */
    long   ru_isrss;         /* taille intégrale de la pile non partagée */
    long   ru_minflt;        /* récupérations de pages (défauts de page légers) */
    long   ru_majflt;        /* défauts de page (défauts de page lourds) */
    long   ru_nswap;         /* échanges */
    long   ru_inblock;       /* opérations d'entrée de bloc */
    long   ru_oublock;       /* opérations de sortie de bloc */
    long   ru_msgsnd;        /* messages IPC envoyés */
    long   ru_msgrcv;        /* messages IPC reçus */
    long   ru_nsignals;      /* signaux reçus */
    long   ru_nvcsw;         /* changements de contexte volontaires */
    long   ru_nivcsw;        /* changements de contexte involontaires */
}
;

Tous les champs ne sont pas remplis ; les champs non maintenus sont mis à zéro par le noyau. (Les champs non maintenus sont fournis pour la compatibilité avec d'autres systèmes, et parce qu'ils pourraient un jour être pris en charge sur Linux.) Les champs sont interprétés comme suit

HISTORIQU

E

POSIX.1-2001, SVr4, 4.

3BSD.

Avant Linux 2.6.9, si la disposition de SIGCHLD est définie sur SIG_IGN, alors les utilisations des ressources des processus enfants sont automatiquement incluses dans la valeur renvoyée par RUSAGE_CHILDREN, bien que POSIX.1-2001 interdise explicitement cela. Cette non-conformité est corrigée dans Linux 2.6.9 et versions

ultérieures.

La définition de structure montrée au début de cette page a été prise depuis 4.3BSD

Reno.

Les anciens systèmes fournissaient une fonction vtimes() ayant un objectif similaire à getrusage(). Pour la compatibilité ascendante, glibc (jusqu'à Linux 2.32) fournit également vtimes(). Toutes les nouvelles applications doivent être écrites en utilisant getrusage(). (Depuis Linux 2.33, glibc ne fournit plus d'implémentation de vtime

s()
.)
