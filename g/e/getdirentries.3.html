getdirentries(3) Manuel des fonctions de bibliothèque getdirentries(3)

NOM

getdirentries - obtenir les entrées de répertoire dans un format indépendant du système de fichiers

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNOPSIS

#include <dirent.h>
ssize_t getdirentries(size_t size;
                      int fd, char buf[restrict size], size_t size,
                      off_t *restrict basep);
Conditions de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

getdirentries():

    Depuis glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 et versions antérieures:
        _BSD_SOURCE || _SVID_SOURCE

DESCRIPTION

Lit les entrées du répertoire spécifié par fd dans buf. Au plus size octets sont lus. La lecture commence à l'octet *basep, et *basep est mis à jour avec la nouvelle position après la lecture.

VALEUR DE RETOUR

getdirentries() renvoie le nombre d'octets lus ou zéro lorsque la fin du répertoire est atteinte. En cas d'erreur, -1 est renvoyé, et errno est défini pour indiquer l'erreur.

ERREURS

Voir le code source de la bibliothèque Linux pour les détails.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
getdirentries () Sécurité des threads MT-Safe

NORMES

BSD.

NOTES

Utilisez plutôt opendir(3) et readdir(3).

VOIR AUSSI

lseek(2), open(2)
