NOM

gearman - Documentation Gearmand, https://gearman.org/gearmand/

Client en ligne de commande pour Gearmand

SYNOPIS

Options communes

-f <fonction>
Nom de la fonction à utiliser pour les tâches (peut en spécifier plusieurs)
-h <hôte>
Hôte du serveur de tâches
-H
Afficher ce menu d'aide
-p <port>
Port du serveur Gearman
-t <délai>
Délai en millisecondes
-i <pidfile>
Créer un fichier pid pour le processus
-n
En mode client, exécute une tâche par ligne ; en mode worker, envoie un paquet de données pour chaque ligne
-N
Identique à -n, mais supprime le saut de ligne

Options client

-b
Exécuter les tâches en arrière-plan
-I
Exécuter les tâches avec une priorité élevée
-L
Exécuter les tâches avec une priorité basse
-P
Précéder toutes les lignes de sortie avec les noms des fonctions
-s
Envoyer la tâche sans lire depuis l'entrée standard
-u <unique>
Clé unique à utiliser pour la tâche

Options worker*

-c <nombre>
Nombre de tâches que le worker doit exécuter avant de se terminer
-w
Exécuter en mode worker

DESCRIPTION

Avec gearman, vous pouvez exécuter des fonctions client et worker depuis la ligne de commande.

La variable d'environnement GEARMAN_SERVER peut être utilisée pour spécifier plusieurs serveurs gearmand. Veuillez consulter la c:func:'gearman_client_add_servers' pour une explication de la syntaxe requise.

ACCUEIL

Pour plus d'informations, veuillez consulter : https://gearman.org/gearmand/
