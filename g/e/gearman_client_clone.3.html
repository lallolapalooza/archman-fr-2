gearman_client_clone(3)

Paquet: gearmand

Licences: BSD-3-Clause

GEARMAN_CLIENT_CLONE(3) Gearmand GEARMAN_CLIENT_CLONE(3)

NOM

gearman_client_clone - Documentation Gearmand, https://gearman.org/gearmand/

SYNTAXE

#include <libgearman/gearman.h>

gearman_client_st *gearman_client_create(gearman_client_st *client)
gearman_client_st *gearman_client_clone(gearman_client_st *client, const gearman_client_st *from)
void gearman_client_free(gearman_client_st *client)

Lier avec -lgearman

DESCRIPTION

gearman_client_create() est utilisé pour créer une structure c:type:gearman_client_st qui sera ensuite utilisée par d'autres fonctions client de libgearman pour communiquer avec le serveur. Vous devriez soit passer une gearman_client_st déclarée statiquement à gearman_client_create(), soit NULL. Si NULL est passé, une structure est allouée pour vous.

gearman_client_clone() est similaire à gearman_client_create() mais copie les valeurs par défaut et la liste des serveurs de la gearman_client_st source. Si vous passez NULL comme argument pour la source à cloner, cela équivaut à un appel à gearman_client_create. Si l'argument de destination est NULL, une gearman_client_st sera allouée pour vous.

Pour nettoyer la mémoire associée à une structure gearman_client_st, vous devriez la passer à gearman_client_free lorsque vous avez fini de l'utiliser. gearman_client_free() est la seule façon de s'assurer que toute la mémoire est désallouée lorsque vous avez fini d'utiliser la structure.

AVERTISSEMENT :

Vous pourriez vouloir éviter d'utiliser gearman_client_create() ou gearman_client_clone() avec une allocation sur la pile, c'est-à-dire le premier paramètre. Les problèmes les plus courants liés à la sécurité de l'ABI concernent les structures allouées sur la pile.

VALEUR DE RETOUR

gearman_client_create retourne un pointeur vers la gearman_client_st qui a été créée (ou initialisée). En cas d'échec d'allocation, elle retourne NULL.

gearman_client_clone retourne un pointeur vers la gearman_client_st qui a été créée (ou initialisée). En cas d'échec d'allocation, elle retourne NULL.
