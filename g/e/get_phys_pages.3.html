get_phys_pages(3) Manuel des fonctions de bibliothèque get_phys_pages(3)

NOM

get_phys_pages, get_avphys_pages - obtenir les nombres total et disponible de pages physiques

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <sys/sysinfo.h>
long get_phys_pages(void);
long get_avphys_pages(void);

DESCRIPTION

La fonction get_phys_pages() renvoie le nombre total de pages physiques de mémoire disponibles sur le système.

La fonction get_avphys_pages() renvoie le nombre de pages physiques de mémoire actuellement disponibles sur le système.

VALEUR DE RETOUR

En cas de succès, ces fonctions renvoient une valeur non négative comme indiqué dans DESCRIPTION. En cas d'échec, elles renvoient -1 et définissent errno pour indiquer l'erreur.

ERREURS

ENOSYS
Le système n'a pas pu fournir les informations requises (possiblement parce que le système de fichiers /proc n'était pas monté).

NORMES

GNU.

HISTORIQUE

Avant glibc 2.23, ces fonctions obtenaient les informations requises en analysant les champs MemTotal et MemFree de /proc/meminfo. Depuis glibc 2.23, ces fonctions obtiennent les informations requises en appelant sysinfo(2).

NOTES

Les appels sysconf(3) suivants fournissent un moyen portable d'obtenir les mêmes informations que les fonctions décrites sur cette page.


total_pages = sysconf(_SC_PHYS_PAGES);    /* pages totales */
avl_pages = sysconf(_SC_AVPHYS_PAGES);    /* pages disponibles */

EXEMPLES

L'exemple suivant montre comment get_phys_pages() et get_avphys_pages() peuvent être utilisés.

#include <stdio.h>
#include <stdlib.h>
#include <sys/sysinfo.h>
int
main(void)
{
    printf("Ce système dispose de %ld pages de mémoire physique et "
            "%ld pages de mémoire physique disponibles.\n",
            get_phys_pages(), get_avphys_pages());
    exit(EXIT_SUCCESS);
}
