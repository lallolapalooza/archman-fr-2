NOM

ges-launch-1.0 - crée et rend des chronologies multimédias

SYNOPIS

ges-launch-1.0 [OPTION...]

DESCRIPTION

ges-launch-1.0 crée une chronologie multimédia et la lit, ou la rend dans le format spécifié.

Il peut charger une chronologie à partir d'un projet existant, ou en créer une à partir des commandes spécifiées.

Vous pouvez en apprendre davantage sur les commandes individuelles de ges-launch-1.0 avec "ges-launch-1.0 help commande".

Par défaut, ges-launch-1.0 est en "mode lecture".

OPTIONS

Pour la liste complète des options de ges-launch-1.0, voir l'aide en ligne de commande :

-h, --help
Affiche les options d'aide
--help-all
Affiche toutes les options d'aide
--help-gst
Affiche les options GStreamer
--help-GES
Affiche les options GES
--help-project
Affiche les options relatives aux projets
--help-rendering
Affiche les options de rendu
--help-playback
Affiche les options de lecture
--help-informative
Affiche les options informatives
