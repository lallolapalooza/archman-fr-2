gearman_client_do(3)

GEARMAN_CLIENT_DO(3) Gearmand GEARMAN_CLIENT_DO(3)

NOM

gearman_client_do - Documentation Gearmand, https://gearman.org/gearmand/

SYNOPSIS

#include <libgearman/gearman.h>

void *gearman_client_do(gearman_client_st *client, const char *function_name, const char *unique, const void *workload, size_t workload_size, size_t *result_size, gearman_return_t *ret_ptr)

Modifié dans la version 0.21: GEARMAN_PAUSE ne sera plus retourné. Une opération do s'exécutera maintenant jusqu'à complétion ou erreur.

void *gearman_client_do_high(gearman_client_st *client, const char *function_name, const char *unique, const void *workload, size_t workload_size, size_t *result_size, gearman_return_t *ret_ptr)
void *gearman_client_do_low(gearman_client_st *client, const char *function_name, const char *unique, const void *workload, size_t workload_size, size_t *result_size, gearman_return_t *ret_ptr)

DESCRIPTION

gearman_client_do() exécute une seule requête vers le serveur gearmand et attend une réponse.

gearman_client_do_high() et gearman_client_do_low() sont identiques à gearman_client_do(), elles définissent seulement la priorité à haute ou basse.

Toutes les fonctions bloqueront jusqu'à ce qu'une réponse ou une erreur soit retournée.

VALEUR DE RETOUR

gearman_client_do() retourne un pointeur vers une valeur que l'appelant doit libérer. Si ret_ptr est fourni, toute erreur survenue sera stockée dedans. Comme une valeur NULL/zéro est une valeur valide, vous devrez toujours vérifier ret_ptr si vous êtes préoccupé par les erreurs.

EXEMPLE

/*
# Serveur et bibliothèque Gearman
# Copyright (C) 2012 Data Differential, http://datadifferential.com/
# Tous droits réservés.

# Utilisation et distribution autorisées sous la licence BSD. Voir

#include <string.h>
#include <stdlib.h>
#include <libgearman/gearman.h>
int main(void)
{
  gearman_client_st *client= gearman_client_create(NULL);
  gearman_return_t ret= gearman_client_add_server(client, "localhost", 0);
  if (gearman_failed(ret))
  {
    return EXIT_FAILURE;
  }
  size_t result_size;
  gearman_return_t rc;
  void *value= gearman_client_do(client, "reverse_function", "unique_value", 
                                 "my string to reverse", strlen("my string to reverse"), 
                                 &result_size, &rc);
  if (gearman_success(rc))
  {
    // Utiliser la valeur
  }
  free(value);
  gearman_client_free(client);
  return 0;
}
