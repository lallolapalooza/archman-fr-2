getnetent_r(3) Manuel des fonctions de bibliothèque getnetent_r(3)

NOM

getnetent_r, getnetbyname_r, getnetbyaddr_r - obtenir une entrée réseau (réentrante)

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <netdb.h>
int getnetent_r(size_t size;
                struct netent *restrict result_buf,
                char buf[restrict size], size_t size,
                struct netent **restrict result,
                int *restrict h_errnop);
int getnetbyname_r(size_t size;
                const char *restrict name,
                struct netent *restrict result_buf,
                char buf[restrict size], size_t size,
                struct netent **restrict result,
                int *restrict h_errnop);
int getnetbyaddr_r(size_t size;
                uint32_t net, int type,
                struct netent *restrict result_buf,
                char buf[restrict size], size_t size,
                struct netent **restrict result,
                int *restrict h_errnop);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

getnetent_r(), getnetbyname_r(), getnetbyaddr_r():

DESCRIPTION

Les fonctions getnetent_r(), getnetbyname_r() et getnetbyaddr_r() sont les équivalents réentrants de, respectivement, getnetent(3), getnetbyname(3) et getnetbynumber(3). Elles diffèrent de la manière dont la structure netent est retournée, ainsi que de la signature d'appel de fonction et de la valeur de retour. Cette page de manuel décrit uniquement les différences par rapport aux fonctions non réentrantes.

Au lieu de retourner un pointeur vers une structure netent statiquement allouée comme résultat de la fonction, ces fonctions copient la structure à l'emplacement pointé par result_buf.

Le tableau buf est utilisé pour stocker les champs de chaîne de caractères pointés par la structure netent renvoyée. (Les fonctions non réentrantes allouent ces chaînes dans un stockage statique.) La taille de ce tableau est spécifiée dans size. Si buf est trop petit, l'appel échoue avec l'erreur ERANGE, et l'appelant doit réessayer avec un tampon plus grand. (Un tampon de 1024 octets devrait suffire pour la plupart des applications.)

Si l'appel de fonction obtient avec succès un enregistrement réseau, alors *result est défini pointant vers result_buf ; sinon, *result est défini sur NULL.

Le tampon pointé par h_errnop est utilisé pour retourner la valeur qui serait stockée dans la variable globale h_errno par les versions non réentrantes de ces fonctions.

VALEUR DE RETOUR

En cas de succès, ces fonctions retournent 0. En cas d'erreur, elles retournent l'un des numéros d'erreur positifs listés dans ERREURS.

En cas d'erreur, d'enregistrement non trouvé (getnetbyname_r(), getnetbyaddr_r()) ou de fin de fichier (getnetent_r()), result est défini sur NULL.

ERREURS

ENOENT
(getnetent_r()) Aucun autre enregistrement dans la base de données.
ERANGE
buf est trop petit. Réessayez avec un tampon plus grand (et une size augmentée).
