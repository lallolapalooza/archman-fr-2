NOM

geoipupdate - Programme de mise à jour GeoIP2 et GeoLite2

SYNTAXE

geoipupdate [-Vvh] [-f FICHIER_CONFIG] [-d REPERTOIRE_CIBLE]

DESCRIPTION

geoipupdate met à jour automatiquement les bases de données GeoIP2 et GeoLite2. Le programme se connecte au serveur GeoIP Update de MaxMind pour vérifier l'existence de nouvelles bases de données. Si une nouvelle base de données est disponible, le programme la téléchargera et l'installera.

Si vous utilisez un pare-feu, vous devez avoir les ports DNS et HTTPS ouverts.

OPTIONS

-d, --database-directory
Installer les bases de données dans un répertoire personnalisé. Ceci est facultatif. Si spécifié, cela remplace la valeur DatabaseDirectory du fichier de configuration et la variable d'environnement GEOIPUPDATE_DB_DIR.
-f, --config-file
Le fichier de configuration à utiliser. Voir GeoIP.conf et sa documentation pour plus d'informations. Ceci est facultatif. La valeur par défaut est la variable d'environnement GEOIPUPDATE_CONF_FILE si elle est définie, sinon /etc/GeoIP.conf.
--parallelism
Définit le nombre de téléchargements de bases de données parallèles.
-h, --help
Affiche l'aide et quitte.
--stack-trace
Affiche une trace de pile en cas de message d'erreur. Ceci est principalement utile pour le débogage.
-V, --version
Affiche les informations de version et quitte.
-v, --verbose
Active le mode verbeux. Affiche les étapes suivies par geoipupdate. Si spécifié, cela remplace toute variable d'environnement GEOIPUPDATE_VERBOSE.
-o, --output
Affiche les résultats de téléchargement/mise à jour au format JSON.

STATUT DE SORTIE

geoipupdate renvoie 0 en cas de succès et 1 en cas d'erreur.

NOTES

En général, vous devriez exécuter geoipupdate au moins deux fois par semaine. Consultez notre calendrier de publication des bases de données pour plus d'informations.

Sur la plupart des systèmes de type Unix, cela peut être réalisé en utilisant cron. Vous pouvez trouver un exemple de fichier crontab sur notre portail développeur.

Pour utiliser avec un serveur proxy, mettez à jour votre fichier GeoIP.conf comme spécifié dans la page de manuel de GeoIP.conf. Alternativement, définissez la variable d'environnement GEOIPUPDATE_PROXY ou http_proxy.
