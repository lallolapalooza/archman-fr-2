gensio_get_type(3) Manuel des fonctions de bibliothèque gensio_get_type(3)

NOM

gensio_get_type, gensio_get_child, gensio_is_client, gensio_is_reliable, gensio_is_packet, gensio_is_authenticated, gensio_is_encrypted, gensio_is_message, gensio_is_mux - Retourner des informations générales sur un gensio

SYNTAXE

#include <gensio/gensio.h>

const char *gensio_get_type(struct gensio *io,

unsigned int depth);
struct gensio *gensio_get_child(struct gensio *io,

unsigned int depth);
bool gensio_is_client(struct gensio *io);
bool gensio_is_reliable(struct gensio *io);
bool gensio_is_packet(struct gensio *io);
bool gensio_is_authenticated(struct gensio *io);
bool gensio_is_encrypted(struct gensio *io);
bool gensio_is_message(struct gensio *io);
bool gensio_is_mux(struct gensio *io);

DESCRIPTION

gensio_get_type renvoie la chaîne de type pour le gensio (si depth est 0) ou un de ses enfants (depth > 0). Renvoie NULL si la profondeur est supérieure au nombre d'enfants.

gensio_get_child renvoie l'enfant donné du gensio, renvoie NULL si la profondeur est supérieure au nombre d'enfants.

gensio_is_client renvoie vrai si le gensio est un client ou faux s'il est un serveur.

gensio_is_reliable renvoie vrai si le gensio est fiable (ne perdra pas de données). Les périphériques série ne sont pas considérés comme fiables, pas plus que l'UDP. Presque tout le reste l'est, car ils ne perdront pas de données et sont contrôlés par flux.

gensio_is_packet renvoie si le gensio est orienté paquet. Dans un gensio orienté paquet, si un côté écrit un bloc de données, lorsque l'autre côté effectue une lecture, il obtiendra le même bloc de données comme une seule unité, à condition que la taille de son tampon soit correctement définie.

gensio_is_authenticated renvoie vrai si l'extrémité distante est authentifiée, faux sinon. Dans le cas SSL, cela signifie que le certificat distant a été reçu et vérifié (client et serveur, voir la section SSL de gensio(5) pour plus de détails). Pour le serveur certauth, cela signifie que l'authentification a réussi à authentifier le client certauth par certificat ou par mot de passe.

gensio_is_encrypted renvoie vrai si la connexion est cryptée, faux sinon.

gensio_is_message renvoie si le gensio est orienté message. Dans un gensio orienté message, une écriture peut explicitement marquer les limites de message, celles-ci sont livrées au lecteur avec ces limites définies. Voir gensio(5) pour plus de détails sur le fonctionnement.

gensio_is_mux renvoie vrai si le gensio est capable de multiplexage, ce qui signifie qu'il accepte un appel gensio_alloc_channel().

Notez que pour les requêtes de type "gensio_is_xxx", la propriété est généralement héritée de l'enfant. Ainsi, si vous exécutez un gensio telnet par-dessus un gensio SSL, le gensio telnet renverra vrai pour gensio_is_encrypted car SSL est crypté.
