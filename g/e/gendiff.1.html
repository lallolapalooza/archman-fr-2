NOM

gendiff - utilitaire pour faciliter la génération de fichiers diff sans erreur

SYNOPIS

gendiff <répertoire> <extension-diff>

DESCRIPTION

gendiff est un script plutôt simple qui aide à générer un fichier diff à partir d'un seul répertoire. Il prend un nom de répertoire et une "extension-diff" comme seuls arguments. L'extension-diff doit être une séquence unique de caractères ajoutée à la fin de tous les fichiers originaux non modifiés. La sortie du programme est un fichier diff qui peut être appliqué avec le programme patch pour recréer les modifications.

La séquence habituelle d'événements pour créer un diff consiste à créer deux répertoires identiques, à apporter des modifications dans l'un des répertoires, puis à utiliser l'utilitaire diff pour créer une liste des différences entre les deux. L'utilisation de gendiff élimine le besoin de la copie supplémentaire, originale et non modifiée du répertoire. Au lieu de cela, seuls les fichiers individuels qui sont modifiés doivent être enregistrés.

Avant d'éditer un fichier, copiez le fichier en ajoutant l'extension que vous avez choisie au nom du fichier. Par exemple, si vous alliez éditer somefile.cpp et que vous aviez choisi l'extension "fix", copiez-le vers somefile.cpp.fix avant de l'éditer. Ensuite, éditez la première copie (somefile.cpp).

Après avoir édité tous les fichiers nécessaires de cette manière, entrez dans le répertoire un niveau au-dessus de celui où résident vos codes sources, puis tapez

    $ gendiff somedirectory .fix > mydiff-fix.patch

Vous devriez rediriger la sortie vers un fichier (comme illustré) sauf si vous voulez voir les résultats sur stdout.

VOIR AUSSI

diff(1), patch(1)
