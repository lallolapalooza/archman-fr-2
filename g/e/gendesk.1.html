NOM

gendesk - générer des fichiers .desktop basés sur les arguments de la ligne de commande (ou un fichier PKGBUILD)

SYNTAXE

gendesk [indicateurs ou fichier PKGBUILD]

DESCRIPTION

Variables PKGBUILD supportées qui seront incluses dans le fichier généré :

_name

_genericname

_comment

_mimetype

_exec

_categories

Gendesk essaiera de trouver l'icône correcte dans la Bibliothèque d'icônes Open ou sinon se rabattra sur l'icône par défaut.

La catégorie d'application correcte sera devinée si elle n'est pas fournie. Variables d'environnement supportées :

pkgname

pkgdesc

EXEMPLES

gendesk
Se termine avec le code d'erreur 1 si ../PKGBUILD n'est pas trouvé et que pkgname n'est pas donné et que $pkgname n'est pas défini. Tentera d'utiliser $pkgname et $pkgdesc.

gendesk PKGBUILD
Recherche un PKGBUILD dans le répertoire courant et génère un fichier .desktop.

gendesk --pkgname test --pkgdesc test
Génère un fichier .desktop pour le nom « test » avec la description « test ».

gendesk /home/user/archpackages/mypackage/PKGBUILD
Génère un fichier .desktop à partir du PKGBUILD donné.

Un nom de paquet doit être donné, soit en spécifiant un fichier PKGBUILD, en utilisant --pkgname, soit en définissant une variable d'environnement $pkgname.

Notez qu'un suffixe « -bin », « -git », « -hg » ou « -svn » dans un nom de paquet sera ignoré, s'il est présent.

OPTIONS

--version
affiche les informations de version actuelles
-h ou --help
affiche des informations d'utilisation brèves
-n
ne tente pas de télécharger une icône, si elle est manquante
--nocolor
n'utilise pas de texte coloré
-q
silencieux ; ne pas afficher de texte
-f
forcer ; écraser les fichiers si nécessaire
-wm
génère un petit fichier desktop pour lancer un gestionnaire de fenêtres à la place
--pkgname
utilise ce nom de paquet pour l'application (c.-à-d. emacs)
--pkgdesc
utilise cette description de paquet pour décrire l'application et tenter de trouver une catégorie appropriée
--name
utilise ce nom pour le raccourci du bureau (c.-à-d. Emacs)
--genericname
utilise ce nom générique pour le raccourci du bureau (c.-à-d. Éditeur de texte)
--comment
utilise ce commentaire pour le raccourci du bureau (c.-à-d. Utiliser ceci pour éditer des fichiers)
--exec
spécifie un exécutable alternatif, (c.-à-d. /usr/bin/emacs)
--path
spécifie un chemin de départ pour le programme, (c.-à-d. /usr/share/kotlin)
--icon
spécifie un nom de fichier icône (par défaut le nom du paquet)
--categories
spécifie les catégories (c.-à-d. Utilitaires ;ÉditeurDeTexte ;)
--terminal
spécifie si l'application doit être exécutée dans un terminal (par défaut false)
--mimetypes
spécifie les types mime
--startupnotify
spécifie si une notification de démarrage doit apparaître lorsque l'application démarre (par défaut false)
--custom
spécifie une ligne supplémentaire (ou plusieurs lignes) à ajouter à la fin

POURQUOI

Vise à faciliter l'ajout d'entrées de menu pour les applications que les mainteneurs de paquets tentent d'empaqueter, sans inclure quoi que ce soit qui n'ait pas été fourni par le code source dans le paquet lui-même.

BOGUES

Seuls des bogues inconnus jusqu'à présent. Les bogues peuvent être signalés sur https://github.com/xyproto/gendesk/issues.
