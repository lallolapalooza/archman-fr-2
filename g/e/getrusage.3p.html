GETRUSAGE(3P) Manuel du programmeur POSIX GETRUSAGE(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page de manuel Linux correspondante pour les détails du comportement Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

getrusage — obtenir des informations sur l'utilisation des ressources

SYNOPIS

#include <sys/resource.h>
int getrusage(int who, struct rusage *r_usage);

DESCRIPTION

La fonction getrusage() fournit des mesures des ressources utilisées par le processus courant ou par ses processus fils terminés et attendus. Si la valeur de l'argument who est RUSAGE_SELF, des informations sur les ressources utilisées par le processus courant sont retournées. Si la valeur de l'argument who est RUSAGE_CHILDREN, des informations sur les ressources utilisées par les processus fils terminés et attendus du processus courant sont retournées. Si le processus fils n'est jamais attendu (par exemple, si le processus parent a SA_NOCLDWAIT défini ou configure SIGCHLD en SIG_IGN), les informations de ressources pour le processus fils sont ignorées et non incluses dans les informations de ressources fournies par getrusage().

L'argument r_usage est un pointeur vers un objet de type struct rusage dans lequel les informations retournées sont stockées.

VALEUR DE RETOUR

En cas de succès, getrusage() retourne 0 ; sinon, -1 est retourné et errno est défini pour indiquer l'erreur.

ERREURS

La fonction getrusage() échouera si :

EINVAL
La valeur de l'argument who n'est pas valide.

Les sections suivantes sont informatives.

EXEMPLES

Utilisation de getrusage()

L'exemple suivant retourne des informations sur les ressources utilisées par le processus courant.

#include <sys/resource.h>
...
int who = RUSAGE_SELF;
struct rusage usage;
int ret;
ret = getrusage(who, &usage);
