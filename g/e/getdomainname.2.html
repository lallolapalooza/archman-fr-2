getdomainname(2) Manuel des appels système getdomainname(2)

NOM

getdomainname, setdomainname - obtenir/définir le nom de domaine NIS

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <unistd.h>
int getdomainname(size_t size;
                  char name[size], size_t size);
int setdomainname(size_t size;
                  const char name[size], size_t size);
Exigences relatives aux macros de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

getdomainname(), setdomainname():

    Depuis glibc 2.21 :
        _DEFAULT_SOURCE
    Dans glibc 2.19 et 2.20 :
        _DEFAULT_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)
    Jusqu'à et incluant glibc 2.19 :
        _BSD_SOURCE || (_XOPEN_SOURCE && _XOPEN_SOURCE < 500)

DESCRIPTION

Ces fonctions sont utilisées pour accéder ou modifier le nom de domaine NIS du système hôte. Plus précisément, elles opèrent sur le nom de domaine NIS associé à l'espace de noms UTS du processus appelant.

setdomainname() définit le nom de domaine à la valeur fournie dans le tableau de caractères name. L'argument size spécifie le nombre d'octets dans name. (Ainsi, name ne nécessite pas d'octet nul de terminaison.)

getdomainname() renvoie le nom de domaine terminé par un octet nul dans le tableau de caractères name, qui a une taille de size octets. Si le nom de domaine terminé par un octet nul nécessite plus de len octets, getdomainname() renvoie les len premiers octets (glibc) ou génère une erreur (libc).

VALEUR DE RETOUR

En cas de succès, zéro est renvoyé. En cas d'erreur, -1 est renvoyé et errno est défini pour indiquer l'erreur.

ERREURS

setdomainname() peut échouer avec les erreurs suivantes :

EFAULT
name pointait en dehors de l'espace d'adressage utilisateur.
EINVAL
size était négatif ou trop grand.
EPERM
L'appelant n'avait pas la capacité CAP_SYS_ADMIN dans l'espace de noms utilisateur associé à son espace de noms UTS (voir namespaces(7)).

getdomainname() peut échouer avec les erreurs suivantes :

EINVAL
Pour getdomainname() sous libc : name est NULL ou name est égal ou plus long que size octets.

VERSIONS

Sur la plupart des architectures Linux (y compris x86), il n'existe pas d'appel système getdomainname() ; à la place, glibc implémente getdomainname() comme une fonction de bibliothèque qui renvoie une copie du champ domainname obtenu lors d'un appel à uname(2).

NORMES

Aucune.

HISTORIQUE

Depuis Linux 1.0, la limite de taille d'un nom de domaine, y compris l'octet nul de terminaison, est de 64 octets. Dans les noyaux plus anciens, elle était de 8 octets.

VOIR AUSSI

gethostname(2), sethostname(2), uname(2), uts_namespaces(7)
