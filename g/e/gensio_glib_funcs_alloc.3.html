NOM

gensio_glib_funcs_alloc - Abstraction de certaines fonctions du système d'exploitation réalisée avec glib

SYNOPSIS

#include <gensio/gensio_glib.h>

int gensio_glib_funcs_alloc(struct gensio_os_funcs **o)

DESCRIPTION

Cette structure fournit une abstraction pour la bibliothèque gensio qui lui permet de fonctionner sur glib. Voir la page de manuel gensio_os_funcs.3 pour les détails sur ce que cela fait. Ceci peut être utilisé si vous avez un projet basé sur glib auquel vous souhaitez intégrer gensio.

Malheureusement, elle présente certaines limitations en raison des faiblesses de l'interface glib.

Si vous utilisez ceci, vous voudrez vraiment utiliser les fonctions d'attente de gensio, pas g_cont_wait..() vous-même. Vous n'êtes pas obligé de le faire, surtout si votre application est monothread, mais surtout dans les applications multithread, vous ne pouvez pas mélanger les appels aux fonctions d'attente des fonctions du système d'exploitation et aux fonctions d'attente de glib. Cela signifie que vous ne pouvez pas utiliser les fonctions bloquantes, qui utilisent toutes des attentes des fonctions du système d'exploitation.

Les performances devraient être correctes pour un seul thread. Pour plusieurs threads, cependant, une seule chose à la fois peut attendre sur le thread principal de glib. C'est une faiblesse de glib. Pour plusieurs threads, une fonction se trouve dans le contexte principal et les autres attendent sur des variables de condition. Lorsque le thread en attente sur le contexte principal se réveille, il réveille un autre thread en attente pour prendre le relais.

Si les performances sont importantes, il pourrait être préférable de mettre glib au-dessus des fonctions du système d'exploitation de gensio avec g_main_context_set_poll_func(). Je laisse cela comme exercice au lecteur.

VALEUR DE RETOUR

Une erreur gensio renvoie une erreur gensio standard.
