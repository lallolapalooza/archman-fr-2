subroutine cgeqrt2 (integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldt, * ) t, integer ldt, integer info)

CGEQRT2 calcule une factorisation QR d'une matrice réelle ou complexe générale en utilisant la représentation WY compacte de Q.

But :

!>
!> CGEQRT2 calcule une factorisation QR d'une matrice complexe A de taille M par N,
!> en utilisant la représentation WY compacte de Q.
!>

Paramètres

M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= N.
!>

N

!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!>

A

!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice complexe A de taille M par N.  À la sortie, les éléments sur et
!>          au-dessus de la diagonale contiennent la matrice triangulaire supérieure R de taille N par N ; les
!>          éléments sous la diagonale sont les colonnes de V.  Voir ci-dessous pour
!>          plus de détails.
!>

LDA

!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!>

T

!>          T est un tableau COMPLEX, dimension (LDT,N)
!>          Le facteur triangulaire supérieur de taille N par N du réflecteur de bloc.
!>          Les éléments sur et au-dessus de la diagonale contiennent le réflecteur de
!>          bloc T ; les éléments sous la diagonale ne sont pas utilisés.
!>          Voir ci-dessous pour plus de détails.
!>

LDT

!>          LDT est INTEGER
!>          La dimension principale du tableau T.  LDT >= max(1,N).
!>

INFO

!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>

Auteur

Univ. of Tennessee

Univ. of California Berkeley

Univ. of Colorado Denver

NAG Ltd.

Détails supplémentaires :

!>
!>  La matrice V stocke les réflecteurs élémentaires H(i) dans la i-ème colonne
!>  sous la diagonale. Par exemple, si M=5 et N=3, la matrice V est
!>
!>               V = (  1       )
!>                   ( v1  1    )
!>                   ( v1 v2  1 )
!>                   ( v1 v2 v3 )
!>                   ( v1 v2 v3 )
!>
!>  où les vi représentent les vecteurs qui définissent H(i), qui sont renvoyés
!>  dans la matrice A.  Les 1 le long de la diagonale de V ne sont pas stockés dans A.  Le
!>  réflecteur de bloc H est alors donné par
!>
!>               H = I - V * T * V**H
!>
!>  où V**H est la transposée conjuguée de V.
!>
