GEARMAN_ARGUMENT_MAKE(3) Gearmand GEARMAN_ARGUMENT_MAKE(3)

NOM

gearman_argument_make - Documentation Gearmand, https://gearman.org/gearmand/

SYNTAXE

#include <libgearman/gearman.h>

type gearman_argument_t
gearman_argument_t gearman_argument_make(const char *name, const size_t name_length, const char *value, const size_t value_size)

Compiler et lier avec -lgearman

DESCRIPTION

La fonction gearman_argument_make() initialise gearman_argument_t.

gearman_argument_t est une abstraction utilisée pour passer des arguments à gearman_execute(). Les arguments ne sont pas copiés, donc tout objet utilisé pour initialiser gearman_argument_t doit continuer d'exister pendant toute la durée de vie/utilisation de la structure.

VOIR AUSSI

gearmand(8) libgearman(3) gearman_client_error() ou gearman_worker_error()
