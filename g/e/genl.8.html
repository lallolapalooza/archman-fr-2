NOM

genl - interface utilisateur générique netlink

SYNTAXE


genl [ -s[tatistics] ] [ -d[etails] ] [ -r[aw] ] OBJET

genl { -V[ersion] | -h[elp] }

OBJET := { ctrl CTRL_OPTS }

CTRL_OPTS := { help | list | monitor | get PARMS }

PARMS := { name NOM | id ID }

DESCRIPTION

L'utilitaire genl fournit une interface utilisateur simple à la bibliothèque générique netlink. Bien qu'il soit conçu pour prendre en charge plusieurs OBJETs, pour l'instant seul l'objet ctrl est disponible, qui est utilisé pour interroger le contrôleur netlink générique.

ctrl

Le contrôleur netlink générique peut être interrogé de diverses manières :

help
Cette commande affiche simplement un texte d'aide pour l'objet ctrl.
list
Affiche les utilisateurs netlink enregistrés.
monitor
Écoute les notifications netlink génériques.
get
Interroge le contrôleur pour un utilisateur donné, identifié par son nom ou son id.

OPTIONS

genl prend en charge les options suivantes.

-h, -help
Affiche un résumé des options.
-V, -Version
Affiche la version du programme.
-s, -stats, -statistics
Affiche les statistiques de l'objet.
-d, -details
Affiche les détails de l'objet.
-r, -raw
N'affiche que la sortie brute.
