NOM

getdns_root_trust_anchor -- renvoie la liste getdns des ancres de confiance racines par défaut

BIBLIOTHEQUE

Bibliothèque de résolution DNS (libgetdns, -lgetdns)

SYNTAXE

#include <getdns.h>

getdns_list *
getdns_root_trust_anchor (time_t *utc_date_of_anchor)

DESCRIPTION

Si une application souhaite que l'API effectue la validation DNSSEC sans utiliser les extensions, elle peut utiliser la fonction d'aide getdns_validate_dnssec(). L'API utilisera les enregistrements de ressources dans bundle_of_support_records pour construire la chaîne de validation et les enregistrements DNSKEY ou DS dans trust_anchor_records comme ancres de confiance. La liste par défaut des enregistrements d'ancres de confiance utilisée par la bibliothèque pour valider DNSSEC peut être récupérée en utilisant la fonction d'aide getdns_root_trust_anchor.

utc_date_of_anchor représente l'heure d'obtention des ancres de confiance en secondes epoch (en cas de succès)

VALEURS DE RETOUR

Renvoie la liste par défaut des enregistrements d'ancres de confiance utilisés par la bibliothèque pour valider DNSSEC ou NULL si aucune ancre de confiance par défaut n'est disponible.
