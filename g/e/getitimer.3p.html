GETITIMER(3P) Manuel du programmeur POSIX GETITIMER(3P)

PROLOGUE

Cette page manuelle fait partie du Manuel du programmeur POSIX. L'implémentation Linux de cette interface peut différer (consultez la page manuelle Linux correspondante pour les détails du comportement de Linux), ou l'interface peut ne pas être implémentée sur Linux.

NOM

getitimer, setitimer — obtenir et définir la valeur d'un minuteur d'intervalle

SYNOPSIS

#include <sys/time.h>
int getitimer(int which, struct itimerval *value);
int setitimer(int which, const struct itimerval *restrict value,
    struct itimerval *restrict ovalue);

DESCRIPTION

La fonction getitimer() doit stocker la valeur actuelle du minuteur spécifié par which dans la structure pointée par value. La fonction setitimer() doit définir le minuteur spécifié par which à la valeur spécifiée dans la structure pointée par value, et si ovalue n'est pas un pointeur nul, stocker la valeur précédente du minuteur dans la structure pointée par ovalue.

La valeur d'un minuteur est définie par la structure itimerval , spécifiée dans <sys/time.h>. Si it_value est non nul, il doit indiquer le temps jusqu'à la prochaine expiration du minuteur. Si it_interval est non nul, il doit spécifier une valeur à utiliser lors du rechargement de it_value lorsque le minuteur expire. Définir it_value à 0 doit désactiver un minuteur, quelle que soit la valeur de it_interval. Définir it_interval à 0 doit désactiver un minuteur après sa prochaine expiration (en supposant que it_value est non nul).

Les implémentations peuvent imposer des limitations sur la granularité des valeurs de minuteurs. Pour chaque minuteur d'intervalle, si la valeur de minuteur demandée nécessite une granularité plus fine que ce que l'implémentation prend en charge, la valeur réelle du minuteur doit être arrondie à la valeur prise en charge suivante.

Une implémentation conforme XSI fournit à chaque processus au moins trois minuteurs d'intervalle, qui sont indiqués par l'argument which :

ITIMER_PROF
Décrémente à la fois en temps virtuel du processus et lorsque le système fonctionne pour le compte du processus. Il est conçu pour être utilisé par les interpréteurs pour le profilage statistique de l'exécution des programmes interprétés. Chaque fois que le minuteur ITIMER_PROF expire, le signal SIGPROF est délivré.
ITIMER_REAL
Décrémente en temps réel. Un signal SIGALRM est délivré lorsque ce minuteur expire.
ITIMER_VIRTUAL
Décrémente en temps virtuel du processus. Il ne s'exécute que lorsque le processus est en cours d'exécution. Un signal SIGVTALRM est délivré lorsqu'il expire.

L'interaction entre setitimer() et alarm() ou sleep() n'est pas spécifiée.

VALEUR RENVOYÉE

Lors de l'achèvement réussi, getitimer() ou setitimer() doit renvoyer 0 ; sinon, -1 doit être renvoyé et errno défini pour indiquer l'erreur.

ERREURS

La fonction setitimer() doit échouer si :

EINVAL
L'argument value n'est pas sous forme canonique. (Sous forme canonique, le nombre de microsecondes est un entier non négatif inférieur à 1000000 et le nombre de secondes est un entier non négatif.)

Les fonctions getitimer() et setitimer() peuvent échouer si :

EINVAL
L'argument which n'est pas reconnu.

EXEMPLES

Aucun.

UTILISATION PAR LES APPLICATIONS

Les applications devraient utiliser les fonctions timer_gettime() et timer_settime() à la place des fonctions obsolètes getitimer() et setitimer(), respectivement.

JUSTIFICATION

Aucune.

PERSPECTIVES

Les fonctions getitimer() et setitimer() peuvent être supprimées dans une version future.
