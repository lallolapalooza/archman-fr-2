CGESV calcule la solution du système d'équations linéaires A * X = B pour les matrices GE (pilote

simple)

DGESV calcule la solution du système d'équations linéaires A * X = B pour les matrices

GE

simple)

Documentation de la fonction/sous-routin

e

subroutine cgesv (integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( ldb, * ) b, integer ldb, integer

info)

But

: 
!>
!> CGESV calcule la solution d'un système d'équations linéaires complexes
!>    A * X = B,
!> où A est une matrice N×N et X et B sont des matrices N×NRHS.
!>
!> La décomposition LU avec pivot partiel et échanges de lignes est
!> utilisée pour factoriser A comme
!>    A = P * L * U,
!> où P est une matrice de permutation, L est triangulaire inférieure
!> unitaire et U est triangulaire supérieure. La forme factorisée de A est
!> ensuite utilisée pour résoudre le système d'équations A * X = B.
!
>

Paramètre

s
N 
!>          N est INTEGER
!>          Le nombre d'équations linéaires, c'est-à-dire l'ordre de la
!>          matrice A. N >= 0.
!
>

NRH

S 
!>          NRHS est INTEGER
!>          Le nombre de seconds membres, c'est-à-dire le nombre de
!>          colonnes de la matrice B. NRHS >= 0.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice de coefficients A de taille N×N.
!>          À la sortie, les facteurs L et U de la factorisation
!>          A = P*L*U ; les éléments diagonaux unitaires de L ne sont pas stockés.
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A. LDA >= max(1,N).
!
>

IPI

V 
!>          IPIV est un tableau INTEGER, dimension (N)
!>          Les indices de pivot qui définissent la matrice de permutation P ;
!>          la ligne i de la matrice a été échangée avec la ligne IPIV(i).
!
>

B 
!>          B est un tableau COMPLEX, dimension (LDB,NRHS)
!>          À l'entrée, la matrice de seconds membres B de taille N×NRHS.
!>          À la sortie, si INFO = 0, la matrice solution X de taille N×NRHS.
!
>

LD

B 
!>          LDB est INTEGER
!>          La dimension principale du tableau B. LDB >= max(1,N).
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!>          > 0 : si INFO = i, U(i,i) est exactement nul. La factorisation
!>                a été complétée, mais le facteur U est exactement
!>                singulier, la solution n'a donc pas pu être calculée.
!
>
