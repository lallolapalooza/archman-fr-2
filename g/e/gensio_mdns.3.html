DESCRIPTION

Ces fonctions et ce type traitent de la découverte de services mDNS (Multicast DNS) sur un réseau local. Elles peuvent être utilisées pour annoncer des services ou en trouver. Elles fournissent une interface puissante et facile à utiliser pour les fonctionnalités mDNS.

Pour faire ces choses, vous devez d'abord utiliser gensio_alloc_mdns pour allouer une structure mdns avec la structure standard de fonctions d'exploitation gensio. Vous devez, bien sûr, effectuer les boucles d'attente standard des fonctions d'exploitation et ainsi de suite. Lorsque vous avez terminé, vous devez libérer la structure mdns avec gensio_free_mdns. Notez que du code peut encore se trouver dans les rappels mDNS lorsque la libération retourne, vous devez vous assurer d'attendre que le rappel de fin soit appelé pour savoir que le code est sorti de tous les rappels. Le rappel de fin est facultatif si cela ne vous préoccupe pas. Notez également que le mdns ne sera pas libéré (et le rappel de fin non plus) tant que tous les services et surveillances associés n'ont pas été libérés.

Pour les fonctions restantes, le paramètre interface est le numéro d'interface système du périphérique réseau, et peut être -1 pour spécifier toutes les interfaces. Le paramètre ipdomain est l'une des valeurs suivantes :

GENSIO_NETTYPE_UNSPEC
À la fois IPV4 et IPV6
GENSIO_NETTYPE_IPV4
IPV4 uniquement
GENSIO_NETTYPE_IPV6
IPV6 uniquement

Les paramètres name, type, domain et host sont les champs mDNS standard, voir la documentation sur mDNS pour plus de détails. Le paramètre txt est pour les champs de texte mDNS, et est un tableau standard de type argv.

Une fois que vous avez une structure mdns, vous pouvez annoncer un service sur le réseau avec elle en utilisant gensio_mdns_add_service2. Ce service continuera à être annoncé jusqu'à ce que vous appeliez gensio_mdns_remove_service dessus ou que votre programme se termine. Les paramètres domain et host doivent généralement être NULL pour utiliser les valeurs par défaut du système. Le paramètre txt peut être NULL si vous n'en avez pas.

gensio_mdns_add_service2 prend un rappel, il sera appelé lorsque le service aura été enregistré, et éventuellement avec un nouveau nom s'il y a eu un conflit de noms. Vous pouvez passer NULL pour le rappel si cela ne vous préoccupe pas. Le paramètre de rappel peut prendre les valeurs suivantes :

GENSIO_MDNS_SERVICE_READY
Le service est maintenant enregistré, et le nom est le même que celui que vous avez passé.
GENSIO_MDNS_SERVICE_READY_NEW_NAME
Le service est maintenant enregistré, mais le nom a été changé, il sera dans le paramètre info.
GENSIO_MDNS_SERVICE_REMOVED
Vous avez demandé la suppression du service, la suppression est maintenant terminée et le rappel ne sera plus appelé.
GENSIO_MDNS_SERVICE_ERROR
Une erreur s'est produite dans le cadre de l'enregistrement du service.

Il existe une fonction gensio_mdns_add_service pour la rétrocompatibilité, elle est équivalente à appeler gensio_mdns_add_service2 avec un rappel NULL. Ne l'utilisez pas dans un nouveau code.

Pour trouver des services sur le réseau, vous ajoutez une surveillance avec gensio_mdns_add_watch. Tout service correspondant à votre requête sera signalé avec les fonctions de rappel et tous les champs seront fournis dans le rappel. Une fois que vous avez terminé avec une surveillance, vous pouvez appeler gensio_mdns_remove_watch Notez que du code peut encore se trouver dans les rappels mDNS lorsque la suppression retourne, vous devez vous assurer d'attendre que le rappel de fin soit appelé pour savoir que le code est sorti de tous les rappels. Le rappel de fin est facultatif si cela ne vous préoccupe pas.

Certaines bibliothèques MDNS ne prennent pas en charge un type type NULL pour la surveillance, et d'autres le font. Pour un code portable, spécifiez toujours le type de surveillance. Si la bibliothèque ne prend pas en charge un type type nul, la fonction retournera GE_INCONSISTENT.

L'état du rappel de surveillance a trois valeurs possibles :

GENSIO_MDNS_WATCH_NEW_DATA
Ceci est une nouvelle entrée qui est signalée.
GENSIO_MDNS_WATCH_DATA_GONE
Une entrée qui a été signalée précédemment comme disparue.
GENSIO_MDNS_WATCH_ALL_FOR_NOW
Ceci est appelé une fois après la création de la surveillance, il signale que toutes les entrées actuellement connues ont été signalées. De nouvelles entrées peuvent être signalées à l'avenir, mais celles-ci auront été ajoutées dynamiquement plus tard.

Dans le rappel de surveillance, vous devez faire des copies de toutes les chaînes et adresses qui vous sont passées pour les conserver. Leur existence continue n'est pas garantie.

Dans les surveillances, tous les champs de chaîne peuvent être NULL, signifiant que vous voulez prendre n'importe quoi dans ce champ. Donc si toutes les chaînes sont NULL et que l'interface est -1 et que l'ipdomain est GENSIO_NETTYPE_UNSPEC vous obtiendrez tous les champs.

VALEURS DE CHAÎNE POUR LES SURVEILLANCES

Les valeurs de chaîne pour la fonction d'ajout de surveillance peuvent utiliser des expressions rationnelles. Si la chaîne commence par '%', les données qui suivent sont traitées comme une expression rationnelle et les champs sont comparés à celle-ci. Voir la page de manuel regex(7) pour plus de détails.>

Les globules sont pris en charge sur certaines plateformes, mais leur utilisation est déconseillée car ils ne sont pas disponibles sur certaines plateformes. Si la chaîne commence par '@', les données suivantes sont traitées comme un glob standard. Voir la page de manuel glob(7) pour plus de détails. Une erreur sera retournée si la plateforme ne prend pas en charge la correspondance par glob.

Si la chaîne commence par '=', une comparaison exacte est effectuée avec les données qui suivent.

Si la chaîne commence par a-z0-9_ ou un espace, une comparaison exacte de chaîne est effectuée, y compris le premier caractère.

Le comportement de la correspondance pour tout autre caractère de début est indéfini. En général, vous devriez toujours utiliser '@', '%' ou '=' comme caractère de début de toutes vos chaînes de requête pour être sûr.

VALEURS RETOURNÉES

Zéro est retourné en cas de succès, ou une erreur gensio en cas d'échec.
