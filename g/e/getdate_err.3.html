DESCRIPTIO

N

La fonction getdate() convertit une représentation textuelle d'une date et d'une heure, contenue dans le buffer pointé par string, en heure décomposée. L'heure décomposée est stockée dans une structure tm, et un pointeur vers cette structure est renvoyé comme résultat de la fonction. Cette structure tm est allouée dans un stockage statique, et par conséquent elle sera écrasée par les appels ultérieurs à getdate

().

Contrairement à strptime(3) (qui possède un argument format ), getdate() utilise les formats trouvés dans le fichier dont le chemin complet est donné dans la variable d'environnement DATEMSK. La première ligne du fichier qui correspond à la chaîne d'entrée donnée est utilisée pour la

conversion.

La correspondance est effectuée sans tenir compte de la casse. Les espaces superflus, que ce soit dans le motif ou dans la chaîne à convertir, sont

ignorés.

Les spécifications de conversion qu'un motif peut contenir sont celles données pour strptime(3). Une spécification de conversion supplémentaire est spécifiée dans POSIX.1-2001

:
%
Z
Nom du fuseau horair
e. Ceci n'est pas im
plémenté dans glibc.

Lorsque %Z est spécifié, la structure contenant l'heure décomposée est initialisée avec des valeurs correspondant à l'heure actuelle dans le fuseau horaire donné. Sinon, la structure est initialisée à l'heure décomposée correspondant à l'heure locale actuelle (comme par un appel à localtime(3))

.

Lorsque seul le jour de la semaine est donné, le jour est considéré comme étant le premier tel jour à partir

d'aujourd'hui.

Lorsque seul le mois est donné (et pas l'année), le mois est considéré comme étant le premier tel mois égal ou postérieur au mois courant. Si aucun jour n'est donné, c'est le premier jour du

mois.

Lorsqu'aucune heure, minute et seconde ne sont données, l'heure, la minute et la seconde courantes sont

utilisées.

Si aucune date n'est donnée, mais que l'heure est connue, alors cette heure est considérée comme la première telle heure égale ou postérieure à l'heure

courante.

getdate_r() est une extension GNU qui fournit une version réentrante de getdate(). Plutôt que d'utiliser une variable globale pour signaler les erreurs et un buffer statique pour renvoyer l'heure décomposée, elle renvoie les erreurs via la valeur de résultat de la fonction, et renvoie l'heure décomposée résultante dans le buffer alloué par l'appelant pointé par l'argument re

s
.

#define _GNU_SOURCE
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
int
main(int argc, char *argv[])
{
    struct tm *tmp;
    for (size_t j = 1; j < argc; j++) {
        tmp = getdate(argv[j]);
        if (tmp == NULL) {
            printf("Call %zu failed; getdate_err = %d\n",
                   j, getdate_err);
            continue;
        }
        printf("Call %zu (\"%s\") succeeded:\n", j, argv[j]);
        printf("    tm_sec   = %d\n", tmp->tm_sec);
        printf("    tm_min   = %d\n", tmp->tm_min);

        printf("    tm_mday  = %d\n", tmp->tm_mday);
