GETC(3P) Manuel du programmeur POSIX GETC(3P)

PROLOGUE

Cette page de manuel fait partie du Manuel du programmeur POSIX. L'implémentation de cette interface sous Linux peut différer (consultez la page de manuel Linux correspondante pour connaître les détails du comportement sous Linux), ou l'interface peut ne pas être implémentée sous Linux.

NOM

getc — lire un octet d'un flux

SYNTAXE

#include <stdio.h>
int getc(FILE *stream);

DESCRIPTION

La fonctionnalité décrite sur cette page de référence est alignée sur la norme ISO C. Tout conflit entre les exigences décrites ici et la norme ISO C est involontaire. Ce volume de POSIX.1‐2017 s'en remet à la norme ISO C.

La fonction getc() sera équivalente à fgetc(), sauf que si elle est implémentée sous forme de macro, elle peut évaluer stream plus d'une fois, donc l'argument ne devrait jamais être une expression avec des effets de bord.

VALEUR DE RETOUR

Voir fgetc().

ERREURS

Voir fgetc().

Les sections suivantes sont informatives.

EXEMPLES

Aucun.

UTILISATION DANS LES APPLICATIONS

Si la valeur entière renvoyée par getc() est stockée dans une variable de type char puis comparée à la constante entière EOF, la comparaison pourrait ne jamais réussir, car l'extension de signe d'une variable de type char lors de son élargissement en entier est définie par l'implémentation.

Comme elle peut être implémentée sous forme de macro, getc() peut mal interpréter un argument stream avec des effets de bord. En particulier, getc(*f++) ne fonctionnera pas nécessairement comme prévu. Par conséquent, l'utilisation de cette fonction devrait être précédée de "#undefgetc" dans de telles situations ; fgetc() pourrait également être utilisée.
