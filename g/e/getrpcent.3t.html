GETRPCENT(3) Manuel des fonctions de bibliothèque GETRPCENT(3)

NOM

getrpcent, getrpcbyname, getrpcbynumber, endrpcent, setrpcent — obtenir une entrée RPC

SYNTAXE

#include <rpc/rpc.h>

struct rpcent *
getrpcent(void);

struct rpcent *
getrpcbyname(char *nom);

struct rpcent *
getrpcbynumber(int nombre);

void
setrpcent(int resteouvert);

void
endrpcent(void);

DESCRIPTION

Les fonctions getrpcent(), getrpcbyname(), et getrpcbynumber() retournent chacune un pointeur vers un objet avec la structure suivante contenant les champs décomposés d'une ligne de la base de données des numéros de programme RPC, /etc/rpc :

struct rpcent {
	char	*r_name;	/* nom du serveur pour ce programme rpc */
	char	**r_aliases;	/* liste d'alias */
	long	r_number;	/* numéro de programme rpc */
};

Les membres de cette structure sont :

r_name
Le nom du serveur pour ce programme rpc.
r_aliases
Une liste terminée par zéro de noms alternatifs pour le programme rpc.
r_number
Le numéro de programme rpc pour ce service.

La fonction getrpcent() lit la ligne suivante du fichier, ouvrant le fichier si nécessaire.

La fonction setrpcent() ouvre et rembobine le fichier. Si le drapeau resteouvert n'est pas nul, la base de données réseau ne sera pas fermée après chaque appel à getrpcent() (directement ou indirectement par le biais d'un autre appel “getrpc”).

La fonction endrpcent() ferme le fichier.

Les fonctions getrpcbyname() et getrpcbynumber() parcourent séquentiellement le fichier depuis le début jusqu'à ce qu'un nom de programme rpc ou un numéro de programme correspondant soit trouvé, ou jusqu'à la fin du fichier.

FICHIERS

/etc/rpc
 

DISPONIBILITÉ

Ces fonctions font partie de libtirpc.

VOIR AUSSI

rpc(5), rpcinfo(8)

DIAGNOSTICS

Un pointeur NULL est retourné en cas de EOF ou d'erreur.

BOGUES
