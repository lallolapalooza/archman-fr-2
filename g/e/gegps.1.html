NOM

gegps - Client Google Earth pour gpsd

SYNTAXE

gegps [OPTIONS] [serveur[:port[:périphérique]]]

gegps -h

gegps -V

DESCRIPTION

Le programme gegps collecte les corrections de gpsd et les transmet à une instance en cours d'exécution de Google Earth pour le suivi de localisation en direct.

OPTIONS

-?, -h, --help

Affiche un résumé des options puis quitte.

-d DIR, --kmldir DIR

Spécifie l'emplacement du répertoire d'installation de Google Earth. S'il n'est pas spécifié, il prend par défaut le répertoire courant.

-D LVL, --debug LVL

Définit le niveau de débogage ; il est principalement destiné aux développeurs de GPSD. Il active divers messages de progression sur la sortie standard d'erreur.

--device PÉRIPHÉRIQUE

Se connecte au périphérique PÉRIPHÉRIQUE sur l'hôte gpsd.

--host HÔTE

Se connecte à gpsd sur l'hôte HÔTE.

-i, --initialize

Si vous possédez la version gratuite (sans abonnement), commencez par exécuter l'option -i pour déposer un indice dans le répertoire d'installation de Google Earth, sous le nom 'Open_in_Google_Earth_RT_GPS.kml', puis ouvrez ce fichier dans Lieux (Fichier > Ouvrir...). Exécutez ensuite gegps normalement.

--port PORT

Se connecte à gpsd sur le port PORT.

-V, --version

Affiche la version du paquet puis quitte.

gegps ne nécessite pas de privilèges root, il doit être exécuté par le même utilisateur que celui sous lequel votre client Google Earth est exécuté.

ARGUMENTS

Par défaut, les clients collectent les données du démon local gpsd exécuté sur localhost, en utilisant le port GPSD par défaut 2947. L'argument optionnel à tout client peut modifier ce comportement : [serveur[:port[:périphérique]]]

Pour plus d'explications et d'exemples, voir la section ARGUMENTS de la page de manuel gps(1)

VALEURS DE RETOUR

0

en cas de succès.

1

en cas d'échec.
