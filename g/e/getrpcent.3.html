getrpcent(3) Manuel des fonctions de bibliothèque getrpcent(3)

NOM

getrpcent, getrpcbyname, getrpcbynumber, setrpcent, endrpcent - obtenir une entrée RPC

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <netdb.h>
struct rpcent *getrpcent(void);
struct rpcent *getrpcbyname(const char *name);
struct rpcent *getrpcbynumber(int number);
void setrpcent(int stayopen);
void endrpcent(void);

DESCRIPTION

Les fonctions getrpcent(), getrpcbyname() et getrpcbynumber() retournent chacune un pointeur vers un objet de la structure suivante contenant les champs décomposés d'une entrée dans la base de données des numéros de programme RPC.


struct rpcent {
    char  *r_name;     /* nom du serveur pour ce programme RPC */
    char **r_aliases;  /* liste d'alias */
    long   r_number;   /* numéro de programme RPC */
};

Les membres de cette structure sont :

r_name
Le nom du serveur pour ce programme RPC.
r_aliases
Une liste se terminant par NULL des noms alternatifs pour le programme RPC.
r_number
Le numéro de programme RPC pour ce service.

La fonction getrpcent() lit l'entrée suivante de la base de données. Une connexion à la base de données est ouverte si nécessaire.

La fonction setrpcent() ouvre une connexion à la base de données et positionne l'entrée suivante à la première entrée. Si stayopen est différent de zéro, la connexion à la base de données ne sera pas fermée entre les appels à l'une des fonctions getrpc*().

La fonction endrpcent() ferme la connexion à la base de données.

Les fonctions getrpcbyname() et getrpcbynumber() parcourent séquentiellement depuis le début du fichier jusqu'à ce qu'un nom de programme RPC ou un numéro de programme correspondant soit trouvé, ou jusqu'à ce que la fin du fichier soit atteinte.

VALEUR DE RETOUR

En cas de succès, getrpcent(), getrpcbyname() et getrpcbynumber() retournent un pointeur vers une structure rpcent allouée statiquement. NULL est retourné en cas de fin de fichier ou d'erreur.

FICHIERS

/etc/rpc
Base de données des numéros de programme RPC.

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
getrpcent (), getrpcbyname (), getrpcbynumber () Sécurité des threads MT-Unsafe
setrpcent (), endrpcent () Sécurité des threads MT-Safe locale

NORMES

BSD.

HISTORIQUE

BSD, Solaris.

BOGUES
