DESCRIPTIO

N

Les fonctions getprotoent_r(), getprotobyname_r() et getprotobynumber_r() sont les équivalents réentrants de, respectivement, getprotoent(3), getprotobyname(3) et getprotobynumber(3). Elles diffèrent dans la manière dont la structure protoent est retournée, ainsi que dans la signature d'appel de la fonction et sa valeur de retour. Cette page de manuel décrit uniquement les différences par rapport aux fonctions non

réentrantes.

Au lieu de retourner un pointeur vers une structure protoent allouée statiquement en tant que résultat de la fonction, ces fonctions copient la structure à l'emplacement pointé par result_buf

.

Le tableau buf est utilisé pour stocker les champs de chaîne pointés par la structure protoent retournée. (Les fonctions non réentrantes allouent ces chaînes dans un stockage statique.) La taille de ce tableau est spécifiée dans size. Si buf est trop petit, l'appel échoue avec l'erreur ERANGE, et l'appelant doit réessayer avec un tampon plus grand. (Un tampon de 1024 octets devrait être suffisant pour la plupart des applications.

)

Si l'appel de fonction obtient avec succès un enregistrement de protocole, alors *result est défini pour pointer vers result_buf ; sinon, *result est d

éfini à
NULL.

EXEMPLE

S

Le programme ci-dessous utilise getprotobyname_r() pour récupérer l'enregistrement de protocole pour le protocole nommé dans son premier argument de ligne de commande. Si un deuxième argument (entier) est fourni sur la ligne de commande, il est utilisé comme valeur initiale pour size ; si getprotobyname_r() échoue avec l'erreur ERANGE, le programme réessaie avec des tailles de tampon plus grandes. La session shell suivante montre quelques exécutions d'exemple

: 


$ ./a.out tcp 1
ERANGE! Retrying with larger buffer
getprotobyname_r() returned: 0 (success)  (size=78)
p_name=tcp; p_proto=6; aliases=TCP
$ ./a.out xxx 1
ERANGE! Retrying with larger buffer
getprotobyname_r() returned: 0 (success)  (size=100)
Call failed/record not
found

Source du

programme 
#define _GNU_SOURCE
#include <ctype.h>
#include <errno.h>
#include <netdb.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#define MAX_BUF 10000
int
main(int argc, char *argv[])
{
    int size, erange_cnt, s;
    struct protoent result_buf;
    struct protoent *result;
    char buf[MAX_BUF];
    if (argc < 2) {
        printf("Usage: %s proto-name [size]\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    size = 1024;
    if (argc > 2)
        size = atoi(argv[2]);
    if (size > MAX_BUF) {
        printf("Exceeded buffer limit (%d)\n", MAX_BUF);
        exit(EXIT_FAILURE);
    }
    erange_cnt = 0;
    do {
        s = getprotobyname_r(argv[1], &result_buf,
                             buf, size, &result);
        if (s == ERANGE) {
            if (erange_cnt == 0)
                printf("ERANGE! Retrying with larger buffer\n");
            erange_cnt++;
            /* Increment a byte at a time so we can see exactly
               what size buffer was required.  */
            size++;
            if (size > MAX_BUF) {
                printf("Exceeded buffer limit (%d)\n", MAX_BUF);
                exit(EXIT_FAILURE);
            }
        }
    } while (s == ERANGE);
    printf("getprotobyname_r() returned: %s  (size=%d)\n",
           (s == 0) ? "0 (success)" : (s == ENOENT) ? "ENOENT" :
           strerror(s), size);
    if (s != 0 || result == NULL) {
        printf("Call failed/record not found\n");
        exit(EXIT_FAILURE);
    }
    printf("p_name=%s; p_proto=%d; aliases=",
           result_buf.p_name, result_buf.p_proto);
    for (char **p = result_buf.p_aliases; *p != NULL; p++)
        printf("%s ", *p);
    printf("\n");
    exit(EXIT_SUCCESS)
;
}
