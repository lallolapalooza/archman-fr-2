NOM

genl-ctrl-list - Lister les familles Generic Netlink côté noyau disponibles

SYNTAXE

genl-ctrl-list [-d]

DESCRIPTION

Interroge le contrôleur Generic Netlink du noyau et affiche une liste de toutes les familles Generic Netlink enregistrées, y compris la version de l'interface qui a été enregistrée.

OPTIONS

-h ou --help
Affiche l'aide sur la console et quitte.
-v ou --version
Affiche les informations de version sur la console et quitte.
-d ou --details
Inclut des informations détaillées supplémentaires pour chaque famille Generic Netlink qui est affichée.

Les informations comprennent :

hdrsize N
La taille de l'en-tête spécifique à l'utilisateur.
maxattr N
L'identifiant d'attribut Netlink maximum attendu par l'interface.
op NOM (ID) <FLAGS>
Une liste des opérations disponibles, y compris leur nom, leur identifiant numérique et les indicateurs indiquant les capacités de l'opération.

Indicateurs disponibles :

admin-perm
Nécessite des privilèges administratifs
has-doit
La commande peut gérer une requête
has-dump
La commande peut gérer une requête de vidage (dump)
has-policy
La commande applique une politique de validation d'attribut
grp NOM (ID)
Une liste des groupes multicast enregistrés, y compris le nom (si disponible) et l'identifiant.
Exemple :
0x0010 nlctrl version 2

hdrsize 0 maxattr 7

op GETFAMILY (0x03) <has-doit,has-dump,has-policy>

grp notify (0x10)

EXEMPLE

$ genl-ctrl-list
0x0010 nlctrl version 2
0x0011 NLBL_MGMT version 3
0x0012 NLBL_CIPSOv4 version 3
0x0013 NLBL_UNLBL version 3
0x0014 acpi_event version 1
0x0015 thermal_event version 1
0x0016 VFS_DQUOT version 1
0x0017 TASKSTATS version 1
0x0018 NET_DM version 2
