subroutine cgeqr2 (integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer

info)

CGEQR2 calcule la factorisation QR d'une matrice rectangulaire générale en utilisant un algorithme non par

blocs.

But

: 
!>
!> CGEQR2 calcule une factorisation QR d'une matrice complexe A de taille m par n :
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> où :
!>
!>    Q est une matrice orthogonale de taille m par m ;
!>    R est une matrice triangulaire supérieure de taille n par n ;
!>    0 est une matrice nulle de taille (m-n) par n, si m > n.
!>
!
>

Paramètre

s
M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!
>

N 
!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice A de taille m par n.
!>          À la sortie, les éléments sur et au-dessus de la diagonale du tableau
!>          contiennent la matrice trapézoïdale supérieure R de taille min(m,n) par n (R est
!>          triangulaire supérieure si m >= n) ; les éléments sous la diagonale,
!>          avec le tableau TAU, représentent la matrice unitaire Q sous la
!>          forme d'un produit de réflecteurs élémentaires (voir Détails supplémentaires).
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!
>

TA

U 
!>          TAU est un tableau COMPLEX, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires (voir Détails
!>          supplémentaires).
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (N)
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!
>

Détails supplémentaires

: 
!>
!>  La matrice Q est représentée comme un produit de réflecteurs élémentaires
!>
!>     Q = H(1) H(2) . . . H(k), où k = min(m,n).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**H
!>
!>  où tau est un scalaire complexe, et v est un vecteur complexe avec
!>  v(1:i-1) = 0 et v(i) = 1 ; v(i+1:m) est stocké à la sortie dans A(i+1:m,i),
!>  et tau dans TAU(i).
!
>

NAME

                
geqr2 — computes the QR factorization of a
                    general rectangular matrix using an unblocked algorithm

Detailed Description

                
Purpose:

                

                    
!>
!> SGEQR2 computes a QR factorization of a real m-by-n matrix A:
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> where:
!>
!>    Q is a m-by-m orthogonal matrix;
!>    R is an upper-triangular n-by-n matrix;
!>    0 is a (m-n)-by-n zero matrix, if m > n.
!>
!>

subroutine sgeqr2 (integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) tau, real, dimension( * ) work, integer info)

                    
SGEQR2 computes the QR factorization of a general
                        rectangular matrix using an unblocked algorithm.

                    
Purpose:

                    

                        
!>
!> SGEQR2 computes a QR factorization of a real m-by-n matrix A:
!>
!>    A = Q * ( R ),
!>            ( 0 )
!>
!> where:
!>
!>    Q is a m-by-m orthogonal matrix;
!>    R is an upper-triangular n-by-n matrix;
!>    0 is a (m-n)-by-n zero matrix, if m > n.
!>
!> 

                    

                    
Parameters

                    
M
                        
!>          M is INTEGER
!>          The number of rows of the matrix A.  M >= 0.
!> 

                        
N

                        
!>          N is INTEGER
!>          The number of columns of the matrix A.  N >= 0.
!> 

                        
A

                        
!>          A is REAL array, dimension (LDA,N)
!>          On entry, the m by n matrix A.
!>          On exit, the elements on and above the diagonal of the array
!>          contain the min(m,n) by n upper trapezoidal matrix R (R is
!>          upper triangular if m >= n); the elements below the diagonal,
!>          with the array TAU, represent the orthogonal matrix Q as a
!>          product of elementary reflectors (see Further Details).
!> 

                        
LDA

                        
!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!> 

                        
TAU

                        
!>          TAU is REAL array, dimension (min(M,N))
!>          The scalar factors of the elementary reflectors (see Further
!>          Details).
!> 

                        
WORK

                        
!>          WORK is REAL array, dimension (N)
!> 

                        
INFO

                        
!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!> 

                    

                    
Author

                    
Univ. of Tennessee
                        
Univ. of California Berkeley

                        
Univ. of Colorado Denver

                        
NAG Ltd.

                    

                    
Further Details:

                    

                        
!>
!>  The matrix Q is represented as a product of elementary reflectors
!>
!>     Q = H(1) H(2) . . . H(k), where k = min(m,n).
!>
!>  Each H(i) has the form
!>
!>     H(i) = I - tau * v * v**T
!>
!>  where tau is a real scalar, and v is a real vector with
!>  v(1:i-1) = 0 and v(i) = 1; v(i+1:m) is stored on exit in A(i+1:m,i),
!>  and tau in TAU(i).
!>
