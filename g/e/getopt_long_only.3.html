DESCRIPTIO

N

La fonction getopt() analyse les arguments de la ligne de commande. Ses arguments argc et argv sont le nombre d'arguments et le tableau tels que transmis à la fonction main() lors de l'invocation du programme. Un élément de argv qui commence par « - » (et qui n'est pas exactement « - » ou « -- ») est un élément d'option. Les caractères de cet élément (à part le « - » initial) sont des caractères d'option. Si getopt() est appelé de manière répétée, il retourne successivement chacun des caractères d'option de chacun des éléments

d'option.

La variable optind est l'index de l'élément suivant à traiter dans argv. Le système initialise cette valeur à 1. L'appelant peut la réinitialiser à 1 pour relancer le balayage du même argv, ou lorsqu'il balaye un nouveau vecteur

d'arguments.

Si getopt() trouve un autre caractère d'option, il retourne ce caractère, en mettant à jour la variable externe optind et une variable statique nextchar afin que l'appel suivant à getopt() puisse reprendre le balayage avec le caractère d'option suivant ou l'élément de argv

suivant.

S'il n'y a plus de caractères d'option, getopt() retourne -1. Alors optind est l'index dans argv du premier élément de argv qui n'est pas une

option.

optstring est une chaîne contenant les caractères d'option autorisés. Un caractère d'option autorisé est tout caractère ascii(7) visible d'un seul octet (pour lequel isgraph(3) retournerait une valeur non nulle) qui n'est pas « - », « : » ou « ; ». Si un tel caractère est suivi d'un deux-points, l'option requiert un argument, donc getopt() place un pointeur vers le texte suivant dans le même élément de argv, ou le texte du élément de argv suivant, dans optarg. Deux deux-points signifient que l'option prend un argument optionnel ; s'il y a du texte dans l'élément de argv courant (c'est-à-dire dans le même mot que le nom de l'option lui-même, par exemple « -oarg »), alors il est retourné dans optarg, sinon optarg est défini à zéro. Ceci est une extension GNU. Si optstring contient W suivi d'un point-virgule, alors -W foo est traité comme l'option longue --foo. (L'option -W est réservée par POSIX.2 pour les extensions d'implémentation.) Ce comportement est une extension GNU, non disponible avec les bibliothèques antérieures à glibc

2.

Par défaut, getopt() permute le contenu de argv au fur et à mesure de son balayage, de sorte qu'à la fin toutes les non-options soient à la fin. Deux autres modes de balayage sont également implémentés. Si le premier caractère de optstring est « + » ou si la variable d'environnement POSIXLY_CORRECT est définie, alors le traitement des options s'arrête dès qu'un argument non-option est rencontré. Si « + » n'est pas le premier caractère de optstring, il est traité comme une option normale. Si le comportement POSIXLY_CORRECT est requis dans ce cas, optstring contiendra deux symboles « + ». Si le premier caractère de optstring est « - », alors chaque élément de argv non-option est traité comme s'il s'agissait de l'argument d'une option avec le code caractère 1. (Ceci est utilisé par des programmes écrits pour s'attendre à des options et d'autres éléments de argv dans n'importe quel ordre et qui se soucient de l'ordre des deux.) L'argument spécial « -- » force la fin du balayage des options quel que soit le mode de

balayage.

Lors du traitement de la liste des options, getopt() peut détecter deux types d'erreurs : (1) un caractère d'option qui n'était pas spécifié dans optstring et (2) un argument d'option manquant (c'est-à-dire une option à la fin de la ligne de commande sans l'argument attendu). De telles erreurs sont traitées et signalées comme suit

:
•
Par défaut, getopt() imprime un message d'erreur sur la sortie d'erreur standard, place le caractère d'option erroné dans optopt et retourne « ? » comme résultat de la
fonction.
•
Si l'appelant a défini la variable globale opterr à zéro, alors getopt() n'imprime pas de message d'erreur. L'appelant peut déterminer qu'une erreur s'est produite en testant si la valeur de retour de la fonction est « ? ». (Par défaut, opterr a une valeur non nulle.
)
•
Si le premier caractère (après tout « + » ou « - » optionnel décrit ci-dessus) de optstring est un deux-points (« : »), alors getopt() n'imprime pas non plus de message d'erreur. De plus, il retourne « : » au lieu de « ? » pour indi
quer un argument d'option manquant. Cela permet à l'appela
nt de distinguer les deux types d'erreurs différents.

getopt_long() et getopt_long_only(

)

La fonction getopt_long() fonctionne comme getopt() sauf qu'elle accepte aussi les options longues, commençant par deux tirets. (Si le programme n'accepte que des options longues, alors optstring doit être spécifié comme une chaîne vide (« »), et non NULL.) Les noms d'options longues peuvent être abrégés si l'abréviation est unique ou correspond exactement à une option définie. Une option longue peut prendre un paramètre, de la forme --arg=param ou --arg pa

ram.

VALEUR DE

RETOUR

Si une option a été trouvée avec succès, alors getopt() retourne le caractère d'option. Si toutes les options de la ligne de commande ont été analysées, alors getopt() retourne -1. Si getopt() rencontre un caractère d'option qui n'était pas dans optstring, alors « ? » est retourné. Si getopt() rencontre une option avec un argument manquant, alors la valeur de retour dépend du premier caractère dans optstring : si c'est ':', alors ':' est renvoyé ; sinon '?' est

renvoyé.

getopt_long() et getopt_long_only() renvoient également le caractère d'option lorsqu'une option courte est reconnue. Pour une option longue, ils renvoient val si flag est NULL, et 0 sinon. Les retours d'erreur et -1 sont les mêmes que pour getopt(), plus '?' pour une correspondan

ce ambiguë ou un
paramètre superflu.

Sur certaines implémentations plus anciennes, getopt() était déclaré dans <stdio.h>. SUSv1 permettait à la déclaration d'apparaître dans <unistd.h> ou <stdio.h>. POSIX.1-1996 a marqué l'utilisation de <stdio.h> à cette fin comme LEGACY. POSIX.1-2001 ne requiert pas que la déclaration apparaisse dans <stdio.h>

.

De très anciennes versions de glibc étaient affectées par une _PID_GNU_nonoption_argv_flags_ var

iable d'env
ironnement.

NOTE

S

Un programme qui analyse plusieurs vecteurs d'arguments, ou ré-analyse le même vecteur plus d'une fois, et souhaite faire usage des extensions GNU telles que '+' et '-' au début de optstring, ou change la valeur de POSIXLY_CORRECT entre les analyses, doit réinitialiser getopt() en réinitialisant optind à 0, plutôt que la valeur traditionnelle de 1. (Réinitialiser à 0 force l'invocation d'une routine d'initialisation interne qui revérifie POSIXLY_CORRECT et vérifie les extensions GNU dans optstri

ng.)

Les arguments de ligne de commande sont analysés dans un ordre strict, ce qui signifie qu'une option nécessitant un argument consommera l'argument suivant, que cet argument soit l'argument d'option correctement spécifié ou simplement l'option suivante (dans le scénario où l'utilisateur spécifie incorrectement la ligne de commande). Par exemple, si optstring est spécifié comme "1n:" et que l'utilisateur spécifie les arguments de ligne de commande incorrectement comme prog -n -1, l'option -n recevra la valeur optarg "-1", et l'option -1 sera considérée comme

n'ayant pas
été spécifiée.

EXEMPLE

S

getopt(

)

Le programme d'exemple trivial suivant utilise getopt() pour gérer deux options de programme : -n, sans valeur associée ; et -t val, qui attend une valeur

associée. 
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    int flags, opt;
    int nsecs, tfnd;
    nsecs = 0;
    tfnd = 0;
    flags = 0;
    while ((opt = getopt(argc, argv, "nt:")) != -1) {
        switch (opt) {
        case 'n':
            flags = 1;
            break;
        case 't':
            nsecs = atoi(optarg);
            tfnd = 1;
            break;
        default: /* '?' */
            fprintf(stderr, "Usage: %s [-t nsecs] [-n] name\n",
                    argv[0]);
            exit(EXIT_FAILURE);
        }
    }
    printf("flags=%d; tfnd=%d; nsecs=%d; optind=%d\n",
           flags, tfnd, nsecs, optind);
    if (optind >= argc) {
        fprintf(stderr, "Expected argument after options\n");
        exit(EXIT_FAILURE);
    }
    printf("name argument = %s\n", argv[optind]);
    /* Other code omitted */
    exit(EXIT_SUCCESS);
}

getopt_long(

)

Le programme d'exemple suivant illustre l'utilisation de getopt_long() avec la plupart de ses fonctionnalités

. 
#include <getopt.h>
#include <stdio.h>     /* for printf */
#include <stdlib.h>    /* for exit */
int
main(int argc, char *argv[])
{
    int c;
    int digit_optind = 0;
    while (1) {
        int this_option_optind = optind ? optind : 1;
        int option_index = 0;
        static struct option long_options[] = {
            {"add",     required_argument, 0,  0 },
            {"append",  no_argument,       0,  0 },
            {"delete",  required_argument, 0,  0 },
            {"verbose", no_argument,       0,  0 },
            {"create",  required_argument, 0, 'c'},
            {"file",    required_argument, 0,  0 },
            {0,         0,                 0,  0 }
        };
        c = getopt_long(argc, argv, "abc:d:012",
                        long_options, &option_index);
        if (c == -1)
            break;
        switch (c) {
        case 0:
            printf("option %s", long_options[option_index].name);
            if (optarg)
                printf(" with arg %s", optarg);
            printf("\n");
            break;
        case '0':
        case '1':
        case '2':
            if (digit_optind != 0 && digit_optind != this_option_optind)
              printf("digits occur in two different argv-elements.\n");
            digit_optind = this_option_optind;
            printf("option %c\n", c);
            break;
        case 'a':
            printf("option a\n");
            break;
        case 'b':
            printf("option b\n");
            break;
        case 'c':
            printf("option c with value '%s'\n", optarg);
            break;
        case 'd':
            printf("option d with value '%s'\n", optarg);
            break;
        case '?':
            break;
        default:
            printf("?? getopt returned character code 0%o ??\n", c);
        }
    }
    if (optind < argc) {
        printf("non-option ARGV-elements: ");
        while (optind < argc)
            printf("%s ", argv[optind++]);
        printf("\n");
    }
    exit(EXIT_SUCCESS)
;
}
