sous-routine cgelq2 (integer m, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( * ) tau, complex, dimension( * ) work, integer

info)

CGELQ2 calcule la factorisation LQ d'une matrice rectangulaire générale en utilisant un algorithme non

bloqué.

But

: 
!>
!> CGELQ2 calcule une factorisation LQ d'une matrice complexe A de dimensions m par n :
!>
!>    A = ( L 0 ) *  Q
!>
!> où :
!>
!>    Q est une matrice orthogonale de dimensions n par n ;
!>    L est une matrice triangulaire inférieure de dimensions m par m ;
!>    0 est une matrice nulle de dimensions m par (n-m), si m < n.
!>
!
>

Paramètre

s
M 
!>          M est INTEGER
!>          Le nombre de lignes de la matrice A.  M >= 0.
!
>

N 
!>          N est INTEGER
!>          Le nombre de colonnes de la matrice A.  N >= 0.
!
>

A 
!>          A est un tableau COMPLEX, dimension (LDA,N)
!>          À l'entrée, la matrice A de dimensions m par n.
!>          À la sortie, les éléments sur et sous la diagonale du tableau
!>          contiennent la matrice trapézoïdale inférieure L de dimensions m par min(m,n)
!>          (L est triangulaire inférieure si m <= n) ; les éléments au-dessus de la diagonale,
!>          avec le tableau TAU, représentent la matrice unitaire Q sous la forme
!>          d'un produit de réflecteurs élémentaires (voir Détails supplémentaires).
!
>

LD

A 
!>          LDA est INTEGER
!>          La dimension principale du tableau A.  LDA >= max(1,M).
!
>

TA

U 
!>          TAU est un tableau COMPLEX, dimension (min(M,N))
!>          Les facteurs scalaires des réflecteurs élémentaires (voir Détails
!>          supplémentaires).
!
>

WOR

K 
!>          WORK est un tableau COMPLEX, dimension (M)
!
>

INF

O 
!>          INFO est INTEGER
!>          = 0 : sortie réussie
!>          < 0 : si INFO = -i, le i-ème argument avait une valeur illégale
!
>

Détails supplémentaires

: 
!>
!>  La matrice Q est représentée comme un produit de réflecteurs élémentaires
!>
!>     Q = H(k)**H . . . H(2)**H H(1)**H, où k = min(m,n).
!>
!>  Chaque H(i) a la forme
!>
!>     H(i) = I - tau * v * v**H
!>
!>  où tau est un scalaire complexe, et v est un vecteur complexe avec
!>  v(1:i-1) = 0 et v(i) = 1 ; conjg(v(i+1:n)) est stocké à la sortie dans
!>  A(i,i+1:n), et tau dans TAU(i).
!
>
