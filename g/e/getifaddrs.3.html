DESCRIPTIO

N

La fonction getifaddrs() crée une liste chaînée de structures décrivant les interfaces réseau du système local, et stocke l'adresse du premier élément de la liste dans *ifap. La liste est constituée de structures ifaddrs, définies comme suit

: 


struct ifaddrs {
    struct ifaddrs  *ifa_next;    /* Élément suivant de la liste */
    char            *ifa_name;    /* Nom de l'interface */
    unsigned int     ifa_flags;   /* Drapeaux provenant de SIOCGIFFLAGS */
    struct sockaddr *ifa_addr;    /* Adresse de l'interface */
    struct sockaddr *ifa_netmask; /* Masque réseau de l'interface */
    union {
        struct sockaddr *ifu_broadaddr;
                         /* Adresse de diffusion de l'interface */
        struct sockaddr *ifu_dstaddr;
                         /* Adresse de destination point à point */
    } ifa_ifu;
#define              ifa_broadaddr ifa_ifu.ifu_broadaddr
#define              ifa_dstaddr   ifa_ifu.ifu_dstaddr
    void            *ifa_data;    /* Données spécifiques à l'adresse */
}
;

Le champ ifa_next contient un pointeur vers la structure suivante de la liste, ou NULL s'il s'agit du dernier élément de la

liste.

Le champ ifa_name pointe vers le nom de l'interface terminé par un octet

nul.

Le champ ifa_flags contient les drapeaux de l'interface, tels que renvoyés par l'opération ioctl(2) SIOCGIFFLAGS (voir netdevice(7) pour une liste de ces drapeaux)

.

Le champ ifa_addr pointe vers une structure contenant l'adresse de l'interface. (Le sous-champ sa_family doit être consulté pour déterminer le format de la structure d'adresse.) Ce champ peut contenir un pointeur

nul.

Le champ ifa_netmask pointe vers une structure contenant le masque réseau associé à ifa_addr, si cela s'applique à la famille d'adresses. Ce champ peut contenir un pointeur

nul.

Selon que le bit IFF_BROADCAST ou IFF_POINTOPOINT est défini dans ifa_flags (un seul peut être défini à la fois), soit ifa_broadaddr contiendra l'adresse de diffusion associée à ifa_addr (si cela s'applique à la famille d'adresses), soit ifa_dstaddr contiendra l'adresse de destination de l'interface point à

point.

Le champ ifa_data pointe vers un tampon contenant des données spécifiques à la famille d'adresses ; ce champ peut être NULL s'il n'existe pas de telles données pour cette

interface.

Les données renvoyées par getifaddrs() sont allouées dynamiquement et doivent être libérées à l'aide de freeifaddrs() lorsqu'elles

ne sont plus
nécessaires.

HISTORIQU

E

Cette fonction est apparue pour la première fois dans BSDi et est présente sur les systèmes BSD, mais avec des sémantiques légèrement différentes documentées — renvoyant une entrée par interface, et non par adresse. Cela signifie que ifa_addr et d'autres champs peuvent en fait être NULL si l'interface n'a pas d'adresse, et aucune adresse de niveau liaison n'est renvoyée si l'interface a une adresse IP assignée. De plus, la manière de choisir soit ifa_broadaddr soit ifa_dstaddr diffère selon les

systèmes.

getifaddrs() est apparue pour la première fois dans glibc 2.3, mais avant glibc 2.3.3, l'implémentation ne prenait en charge que les adresses IPv4 ; la prise en charge de

l'IPv6 a été ajoutée dans glibc 2.3.3. La prise en charge des familles d'adresses a
utres que l'IPv4 n'est disponible que sur les noyaux qui prennent en charge netlink.

NOTE

S

Les adresses renvoyées sur Linux seront généralement les adresses IPv4 et IPv6 assignées à l'interface, mais aussi une adresse AF_PACKET par interface contenant des détails de niveau inférieur sur l'interface et sa couche physique. Dans ce cas, le champ ifa_data peut contenir un pointeur vers une struct rtnl_link_stats, définie dans <linux/if_link.h> (dans Linux 2.4 et antérieur, struct net_device_stats, définie dans <linux/netdevice.h>), qui contient diver

s attributs et statis
tiques de l'interface.

#define _GNU_SOURCE     /* Pour obtenir les définitions de NI_MAXSERV et NI_MAXHOST */
#include <arpa/inet.h>
#include <sys/socket.h>
#include <netdb.h>
#include <ifaddrs.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <linux/if_link.h>
int main(int argc, char *argv[])
{
    struct ifaddrs *ifaddr;
    int family, s;
    char host[NI_MAXHOST];
    if (getifaddrs(&ifaddr) == -1) {
        perror("getifaddrs");
        exit(EXIT_FAILURE);
    }
    /* Parcourir la liste chaînée, en maintenant un pointeur sur la tête pour
       pouvoir libérer la liste plus tard.  */
    for (struct ifaddrs *ifa = ifaddr; ifa != NULL;
             ifa = ifa->ifa_next) {
        if (ifa->ifa_addr == NULL)
            continue;
        family = ifa->ifa_addr->sa_family;
        /* Afficher le nom de l'interface et la famille (y compris la
           forme symbolique de cette dernière pour les familles courantes).  */
        printf("%-8s %s (%d)\n",
               ifa->ifa_name,
               (family == AF_PACKET) ? "AF_PACKET" :
               (family == AF_INET) ? "AF_INET" :
               (family == AF_INET6) ? "AF_INET6" : "???",
               family);
        /* Pour une adresse d'interface AF_INET*, afficher l'adresse.  */
        if (family == AF_INET || family == AF_INET6) {
            s = getnameinfo(ifa->ifa_addr,
                    (family == AF_INET) ? sizeof(struct sockaddr_in) :
                                          sizeof(struct sockaddr_in6),
                    host, NI_MAXHOST,
                    NULL, 0, NI_NUMERICHOST);
            if (s != 0) {
                printf("getnameinfo() a échoué : %s\n", gai_strerror(s));
                exit(EXIT_FAILURE);
            }
            printf("\t\taddress: <%s>\n", host);
        } else if (family == AF_PACKET && ifa->ifa_data != NULL) {
            struct rtnl_link_stats *stats = ifa->ifa_data;
            printf("\t\ttx_packets = %10u; rx_packets = %10u\n"
                   "\t\ttx_bytes   = %10u; rx_bytes   = %10u\n",
                   stats->tx_packets, stats->rx_packets,
                   stats->tx_bytes, stats->rx_bytes);
        }
    }
    freeifaddrs(ifaddr);
    exit(EXIT_SUCCESS)
;
}
