NOM

getdns_list_get, getdns_list_get_bindata, getdns_list_get_data_type, getdns_list_get_dict, getdns_list_get_length, getdns_list_get_list, getdns_list_get_int -- obtenir une valeur par son index à partir d'une liste getdns

BIBLIOTHÈQUE

Bibliothèque du résolveur DNS (libgetdns, -lgetdns)

SYNOPSIS

#include <getdns.h>

getdns_return_t
getdns_list_get_bindata (getdns_list *this_list,

size_t index,
getdns_bindata **answer)

size_t *answer)

getdns_return_t
getdns_list_get_list (getdns_list *this_list,

size_t index,
getdns_list **answer)

getdns_return_t
getdns_list_get_int (getdns_list *this_list,

size_t index,
uint32_t *answer)

DESCRIPTION

Le type getdns_list est utilisé pour gérer des listes hétérogènes dans lesquelles les objets sont de chacun des types de données suivants :


getdns_bindata
getdns_dict
getdns_list
uint32_t

this_list la liste à partir de laquelle récupérer l'objet

index l'index numérique (commençant à 0) de l'élément dans la liste que vous souhaitez copier dans answer

answer une copie de l'objet dans la liste est placée dans answer, l'appelant est responsable de libérer le stockage associé à cet objet en appelant la fonction de destruction appropriée.

VALEURS DE RETOUR

En cas de succès, les fonctions retournent GETDNS_RETURN_GOOD, sinon les valeurs d'erreur suivantes sont retournées :

GETDNS_RETURN_GENERIC_ERROR si this_list n'est pas une liste valide

GETDNS_RETURN_NO_SUCH_LIST_ITEM si l'index est hors limites

GETDNS_RETURN_WRONG_TYPE_REQUESTED si le type de données demandé ne correspond pas au contenu de l'argument indexé
