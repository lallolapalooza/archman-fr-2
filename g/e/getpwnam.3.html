NOTE

S

La formulation donnée ci-dessus sous « VALEUR RENVOYÉE » provient de POSIX.1-2001. Elle ne qualifie pas le « non trouvé » d'erreur, et ne spécifie donc pas quelle valeur errno pourrait avoir dans cette situation. Mais cela rend impossible la reconnaissance des erreurs. On pourrait soutenir que selon POSIX errno devrait rester inchangé si une entrée n'est pas trouvée. Des expériences sur divers systèmes de type UNIX montrent que de nombreuses valeurs différentes surviennent dans cette situation : 0, ENOENT, EBADF, ESRCH, EWOULDBLOCK, EPERM, et probablement

d'autres.

Le champ pw_dir contient le nom du répertoire de travail initial de l'utilisateur. Les programmes de connexion utilisent la valeur de ce champ pour initialiser la variable d'environnement HOME pour le shell de connexion. Une application qui souhaite déterminer le répertoire personnel de son utilisateur devrait inspecter la valeur de HOME (plutôt que la valeur getpwuid(getuid())->pw_dir) car cela permet à l'utilisateur de modifier sa notion de « répertoire personnel » pendant une session de connexion. Pour déterminer le répertoire personnel (initial) d'un autre utilisateur, il est nécessaire d'utiliser getpwnam("username")-

>pw_dir ou
similaire.

EXEMPLE

S

Le programme ci-dessous démontre l'utilisation de getpwnam_r() pour trouver le nom d'utilisateur complet et l'identifiant utilisateur pour le nom d'utilisateur fourni en argument de la ligne de

commande. 
#include <errno.h>
#include <pwd.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    struct passwd pwd;
    struct passwd *result;
    char *buf;
    long bufsize;
    int s;
    if (argc != 2) {
        fprintf(stderr, "Usage: %s username\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    bufsize = sysconf(_SC_GETPW_R_SIZE_MAX);
    if (bufsize == -1) /* La valeur était indéterminée */
        bufsize = 16384; /* Devrait être plus que suffisant */
    buf = malloc(bufsize);
    if (buf == NULL)
    {
        perror("malloc");
        exit(EXIT_FAILURE);
    }
    s = getpwnam_r(argv[1], &pwd, buf, bufsize, &result);
    if (result == NULL)
    {
        if (s == 0)
            printf("Non trouvé\n");
        else
        {
            errno = s;
            perror("getpwnam_r");
        }
        exit(EXIT_FAILURE);
    }
    printf("Nom : %s ; UID : %jd\n", pwd.pw_gecos, (intmax_t)pwd.pw_uid);
    exit(EXIT_SUCCESS);
}
