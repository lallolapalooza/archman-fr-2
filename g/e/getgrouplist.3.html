getgrouplist(3) Manuel des fonctions de bibliothèque getgrouplist(3)

NOM

getgrouplist - obtenir la liste des groupes auxquels un utilisateur appartient

BIBLIOTHÈQUE

Bibliothèque C standard (libc, -lc)

SYNTAXE

#include <grp.h>
int getgrouplist(const char *user, gid_t group,
                 gid_t *groups, int *ngroups);
Conditions de test de fonctionnalités pour glibc (voir feature_test_macros(7)):

getgrouplist():

    Depuis glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 et antérieur:
        _BSD_SOURCE

DESCRIPTION

La fonction getgrouplist() parcourt la base de données des groupes (voir group(5)) pour obtenir la liste des groupes auxquels user appartient. Jusqu'à *ngroups de ces groupes sont retournés dans le tableau groups.

Si group n'était pas parmi les groupes définis pour user dans la base de données des groupes, alors group est inclus dans la liste des groupes retournés par getgrouplist(); typiquement, cet argument est spécifié comme l'ID de groupe provenant de l'enregistrement du mot de passe pour user.

L'argument ngroups est un argument valeur-résultat : au retour, il contient toujours le nombre de groupes trouvés pour user, y compris group ; cette valeur peut être supérieure au nombre de groupes stockés dans groups.

VALEUR DE RETOUR

Si le nombre de groupes dont user est membre est inférieur ou égal à *ngroups, alors la valeur *ngroups est retournée.

Si l'utilisateur est membre de plus de *ngroups groupes, alors getgrouplist() retourne -1. Dans ce cas, la valeur retournée dans *ngroups peut être utilisée pour redimensionner le tampon passé à un nouvel appel de getgrouplist().

ATTRIBUTS

Pour une explication des termes utilisés dans cette section, voir attributes(7).

Interface Attribut Valeur
getgrouplist () Sécurité des threads MT-Safe locale

NORMES

Aucune.

HISTORIQUE

glibc 2.2.4.

BOGUES

Avant glibc 2.3.3, l'implémentation de cette fonction contenait un bogued'écrasement de tampon : elle retournait la liste complète des groupes pour user dans le tableau groups, même lorsque le nombre de groupes dépassait *ngroups.

EXEMPLES

Le programme ci-dessous affiche la liste des groupes pour l'utilisateur nommé dans son premier argument de ligne de commande. Le second argument de ligne de commande spécifie la valeur ngroups à fournir à getgrouplist(). La session shell suivante montre des exemples d'utilisation de ce programme :


$ ./a.out cecilia 0
getgrouplist() returned -1
ngroups = 3
$ ./a.out cecilia 3
ngroups = 3
16 (dialout)
33 (video)
100 (users)

Source du programme

#include <errno.h>
#include <grp.h>
#include <pwd.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    int            ngroups;
    gid_t          *groups;
    struct group   *gr;
    struct passwd  *pw;
    if (argc != 3) {
        fprintf(stderr, "Usage: %s <user> <ngroups>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    ngroups = atoi(argv[2]);
    groups = malloc(sizeof(*groups) * ngroups);
    if (groups == NULL) {
        perror("malloc");
        exit(EXIT_FAILURE);
    }
    /* Récupérer la structure passwd (contient le premier ID de groupe pour l'utilisateur).  */
    errno = 0;
    pw = getpwnam(argv[1]);
    if (pw == NULL) {
        if (errno)
            perror("getpwnam");
        else
            fprintf(stderr, "no such user\n");
        exit(EXIT_FAILURE);
    }
    /* Récupérer la liste des groupes.  */
    if (getgrouplist(argv[1], pw->pw_gid, groups, &ngroups) == -1) {
        fprintf(stderr, "getgrouplist() returned -1\n");
        fprintf(stderr, "ngroups = %d\n", ngroups);
        exit(EXIT_FAILURE);
    }
    /* Afficher la liste des groupes récupérés, ainsi que les noms des groupes.  */
    fprintf(stderr, "ngroups = %d\n", ngroups);
    for (int j = 0; j < ngroups; j++) {
        printf("%d", groups[j]);
        gr = getgrgid(groups[j]);
        if (gr != NULL)
            printf(" (%s)", gr->gr_name);
        printf("\n");
    }
    exit(EXIT_SUCCESS);
}
